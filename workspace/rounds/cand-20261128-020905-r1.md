### 第 5 轮灵感驱动研究记录

**灵感词**：并发推理、主动交互

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM，FFA 联邦）之上追加价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3·η_val·η_bal；Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。v4 自陈的最大风险是「VACK/BCK 串行计算打破 1 kHz 实时性」。本轮不推翻 v4：以「并发推理」直接回应实时性、以「主动交互」把「事后教师回退」升级为「事前信息获取」，形成 CADVS-v5（IP-493~496），执行集升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **并发推理：把「串行证书门」重构为「证书依赖 DAG + 推测执行」**。v4 的七个硬门被隐式串行评估，VACK（~10–50 ms）与 BCK（~1–5 ms）落在关键路径上。并发推理的核心直觉是：把彼此无依赖的门（覆盖/物理/末点/平衡）并行求值，把慢门（VACK/BCK）用**校准的快速代理模型**先做「推测」，在控制环内先执行可逆动作，等真值到达再「提交或回滚」——如同 CPU 的投机执行。安全前提有二：动作必须落在**可逆安全包络** R_safe 内（能在 T_s 内无硬门违例地回滚），且代理模型必须**校准**（下置信界高于推测阈值）。由此引入推测证书核 SCK 与硬门 kc_spec（新鲜性 ∧ 可逆性 ∧ 校准），把「实时性」从工程补丁上升为「带安全不变量的并发证书演算」。并发同时带来新风险：不同 worker 产出的证书时刻不一，可能读到陈旧或相互矛盾的证书，故 kc_spec 必须含新鲜性/一致性约束。

2. **主动交互：把「被动否决 / 事后教师」升级为「价值信息驱动的主动询问」**。v4 的 HICK 只在人类显式干预时 veto，VACK 只在准入时被动评估，遇到高不确定（意图模糊、λ_vec 后验发散、接触参数未知）时系统仍可能「带着不确定行动」。主动交互的核心直觉是：不确定性本身是可度量、可主动降低的状态；系统应计算**信息价值** VoI(q) = I(θ;Z_q|D) − c(q)，在行动前主动提问/澄清/探测/请求示范，并在不确定性超过阈值时**强制不行动**（除非动作落在已证安全不变量集 R_inv 内）。由此引入主动信息获取核 PIAK 与硬门 kc_clar，把「安全」扩展为「认识论安全」：不确知则不擅动。

3. **理论凝练：并发证书演算 + 信息价值理论**。将 (a) 证书依赖 DAG 与临界路径调度、(b) 推测提交的可靠性/回滚不变量、(c) 主动交互的 VoI 次模性与最优停止、(d) 认识论门与 Fano 下界，整合为可发表的理论块，证明并发与主动交互**不削弱 fail-closed**，反而在相同安全界下降低时延与不确定性。

**关键洞见**：v4 用「更多硬门」换安全，代价是串行时延与不确定性残留；v5 用「并发 + 推测」把新增门摊到并行关键路径，用「主动交互」把不确定性在行动前消解。二者共同回答一个新问题：**安全不只是「已证合法才执行」，还是「在不确定与时限约束下，如何用最少的信息与最少的不可逆动作换取可证的合法性」**。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_spec ∧ kc_clar，fail-closed；软评分 ECS_v5 = ECS_v4·η_spec·η_info。

**形式化目标（增量）**：
1. 定义证书依赖 DAG G_C=(V,E)，V={kc_*}，边 (i→j) 表示 kc_j 依赖 kc_i 的证据；并行调度 π 的时延 L(π)=临界路径长度。
2. 定义可逆安全包络 R_safe ⊆ State×Action 与回滚策略 ρ；kc_rev(x,a) = (x,a)∈R_safe ∧ rollback_verified。
3. 定义校准代理 ŝ_i，满足 |ŝ_i−score_i| ≤ ε_s 以概率 ≥ 1−δ_s；kc_spec = fresh(cert) ∧ (¬spec ∨ (kc_rev ∧ LCB(ŝ) ≥ κ_spec))。
4. 定义信念后验 θ=(intent, λ_vec, physics, contact)，熵 H(θ|D)；VoI(q)=I(θ;Z_q|D)−c(q)；kc_clar = H ≤ H_max ∨ clarified ∨ a∈R_inv。
5. 证明推测提交可靠性定理、临界路径时延界、VoI 次模 (1−1/e) 近似与最优停止、Fano 认识论门必要性。
6. 定义 EFA-v5 九硬门 + 软评分 ECS_v5 = ECS_v4·η_spec·η_info。
7. 定义 Exec_CADVS-v5 ⊆ Exec_CADVS-v4：v5 在 v4 每条路径上追加 kc_spec 与 kc_clar，故只缩不涨。

**本轮最大风险**：**推测执行在代理模型过度自信或回滚实际不可行时会击穿 fail-closed**——若校准界被分布漂移破坏、或接触/柔性任务在 T_s 内无法无碰撞无过载地回滚，系统会在「以为可逆」的幻觉下提交不可逆动作，而真值验证到达时已无法撤销。

### IP-493 SCK：推测证书核（并发调度 + 可逆推测，控制环内 < 1 ms 增量）

```python
@dataclass
class SpeculativeCertificateKernel:
    """SCK：证书依赖 DAG + 临界路径调度 + 校准代理推测 + 可逆回滚；kc_spec 硬门"""
    T_s: float = 0.005                 # 推测时窗（s）
    kappa_spec: float = 0.80           # 代理下置信界阈值
    eps_s: float = 0.05                # 校准误差上界
    delta_s: float = 1e-3              # 校准置信度
    n_workers: int = 4

    def build_dag(self, gate_ids, evidence_deps) -> CertDAG:
        """V={kc_*}；(i→j) 表示 kc_j 需要 kc_i 的证据。无依赖门可并行。"""
        ...

    def schedule(self, dag: CertDAG) -> ParallelSchedule:
        """Hwang 列表调度：按到汇点的最长路径设优先级，贪心分配 worker。
           关键性质：L(π) ≥ L_cp，且列表调度在 p 充分时逼近 L_cp。"""
        ...

    def surrogate(self, gate_id: str, evidence) -> Surrogate:
        """返回 (score_hat, lcb, ucb)。
           VACK→蒸馏小 Transformer/线性头；BCK→Wrench 锥查表 + 线性化 QP 早停。"""
        ...

    def speculate(self, x, action, dag: CertDAG, t_now: float) -> SpecPlan:
        """仅对 LCB(ŝ)≥κ_spec 且 action∈R_safe 的慢门开启推测"""
        plan = SpecPlan(active=False, speculated=set(), action=action, t=t_now)
        for g in self.schedule(dag).slow_gates():
            s = self.surrogate(g, self._evidence(g))
            if s.lcb >= self.kappa_spec and self._in_safe_envelope(action):
                plan.speculated.add(g)
        plan.active = len(plan.speculated) > 0
        plan.rollback_verified = self._verify_rollback(action)  # ρ 在 T_s 内可达
        return plan

    def kc_spec(self, cert: Cert, plan: SpecPlan, t_now: float) -> bool:
        """引理 43：通过 ⟹ 证书新鲜，且任何推测动作可逆、代理已校准"""
        if not self._fresh(cert, t_now):        # 并发/缓存下禁止陈旧证书
            return False
        if not plan.active:
            return True
        return (self._in_safe_envelope(plan.action)
                and plan.rollback_verified
                and plan.calibrated(self.eps_s, self.delta_s)
                and all(self.surrogate(g, self._evidence(g)).lcb >= self.kappa_spec
                        for g in plan.speculated))

    def commit_or_rollback(self, plan: SpecPlan, true_pass: dict[str, bool]) -> str:
        """真值到达：被推测门全部通过→COMMIT；任一失败→执行 ρ 回滚到 Exec_v4"""
        if all(true_pass[g] for g in plan.speculated):
            return "COMMIT"
        self._execute_rollback(plan)            # 保证落点 ∈ Exec_v4
        return "ROLLBACK"

    def _fresh(self, cert, t_now) -> bool: ...
    def _in_safe_envelope(self, action) -> bool: ...
    def _verify_rollback(self, action) -> bool: ...
    def _execute_rollback(self, plan) -> None: ...
```

### IP-494 PIAK：主动信息获取核（异步，秒级；查询可并发批推理）

```python
@dataclass
class ProactiveInformationAcquisitionKernel:
    """PIAK：信念熵 + VoI 查询选择 + 认识论门；kc_clar 硬门"""
    H_max: float = 1.5                 # 认识论熵阈值（nats）
    c_cost: float = 0.05               # 单位交互成本
    n_particles: int = 2048
    belief: Belief = field(default_factory=Belief.particle_filter)  # θ=(intent,λ,physics,contact)

    def entropy(self) -> float:
        return self.belief.entropy()   # H(θ|D)

    def voi(self, q: Query) -> float:
        """信息价值 = 期望熵减 − 成本；粒子互信息估计"""
        return self.belief.mutual_information(q) - self.c_cost * q.cost

    def select(self, candidates: list[Query], ctx) -> Query:
        """并发评估候选查询（批推理），取 VoI 最大且交互本身安全者"""
        safe = [q for q in candidates if self.kc_ia_safe(q)]
        return max(safe, key=self.voi, default=Query.none())

    def kc_clar(self, action, ctx) -> bool:
        """引理 46：高熵未澄清且动作不在不变量集 → 拒绝（fail-closed）"""
        if self.entropy() <= self.H_max:
            return True
        if ctx.clarification_done:
            return True
        return self._in_invariant_set(action)   # R_inv ⊆ R_safe

    def kc_ia_safe(self, q: Query) -> bool:
        """交互行为本身必须安全：复用 SCK/kc_ee/kc_bal 判定查询动作"""
        return q.is_informative and self._act_safe(q)

    def update(self, q: Query, z) -> PIC:
        h0 = self.entropy()
        self.belief.update(z)
        h1 = self.entropy()
        return PIC(voi=self.voi(q), q=q, c=q.cost, H_before=h0, H_after=h1,
                   kc_ia_safe=self.kc_ia_safe(q), t=now())
```

**查询类型（与既有锚点闭环）**：

| 查询 q | 降低的不确定性 | 关联锚点 | 安全约束 kc_ia_safe |
|---|---|---|---|
| 偏好比较「A 还是 B」 | λ_vec 后验 | VACK | 提问不阻塞安全监控 |
| 意图澄清「你要我抓哪个」 | intent | HICK | 澄清期间保持 S_stop/保持位 |
| 接触探测微动作 | physics/contact | BCK | 探测动作 ∈ R_safe |
| 请求示范 | 规则先验 | LTEM/DAKI | 示范期间机器人保持安全位 |
| 请求联邦先验 | 跨站分布 | FFA | 仅传输统计量，不离站 |

### IP-495 CCC：并发证书演算与核心定理（离线理论，不在控制环）

```python
def theorem_speculative_commit() -> str:
    """
    定理 5（推测提交可靠性 / 并发不削弱 fail-closed）：
    设代理校准 P(|ŝ_i−s_i|≤ε_s) ≥ 1−δ_s，R_safe 内回滚 ρ 在 T_s 内无硬门违例，
    验证器无假接受。则任一推测路径要么 COMMIT 到「全门真通过」的状态，
    要么 ROLLBACK 到 Exec_v4 内的状态；故推测不产生 v4 之外的提交，
    Exec_v5 ⊆ Exec_v4，且推测只改变时延不改变安全界。
    证明：COMMIT 条件为所有被推测门 true_pass；未推测门本就串行真验证；
    ROLLBACK 由 ρ 的不变量保证落点 ∈ Exec_v4。校准仅影响「是否敢推测」，不影响提交真值。
    """

def theorem_critical_path() -> str:
    """
    定理 6（并发时延界）：
    对依赖 DAG，p 个 worker 的列表调度时延满足 L_cp ≤ L(π) ≤ L_cp + max_i l_i·(1−1/p)。
    对慢门集 S 采用推测，期望时延
      E[L] ≤ L_cp + Σ_{i∈S∖CP} (1−q_i)(l_i + l_ρ) − Σ_{i∈S∩CP} q_i·l_i
    其中 q_i=代理命中率，l_ρ=回滚开销。当 q_i→1 且 S∩CP≠∅，E[L]→L_cp（串行和变为并行 max）。
    """

def theorem_voi() -> str:
    """
    定理 7（主动交互近似最优）：
    若信息增益 I(θ;Z_q|D) 对查询集次模，则贪心选择达 (1−1/e)·OPT；
    在线性交互成本下，停止规则「边际 VoI ≤ c」使期望净效用最优（最优停止/ Wald）。
    推论：kc_clar 的 H_max 可视为「继续询问的边际 VoI < 风险成本」的停止点。
    """

def lemma_epistemic() -> str:
    """
    引理 46（认识论门的必要性，Fano 下界）：
    对任意决策器，P_e ≥ (H(θ|D) − 1) / log|Θ|。
    故当 H(θ|D) > H_max := 1 + ε·log|Θ| 时，任何「直接行动」的错误率下界 > ε，
    违反风险预算；因此 fail-closed 必须拒绝或先主动降熵（kc_clar）。
    注意：低熵只是必要条件，残余错误仍由校准/PAC 界另行控制（不宣称低熵⇒低错）。
    """
```

```python
                  traj: Trajectory, context: Context) -> tuple[bool, str]:
        # 优先级：HIC veto > 其余八硬门（DAG 并行评估，任一失败即拒）
        if self.hic.veto_active(hic):           return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):  return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):             return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc):            return False, 'BALANCE_UNSTABLE'
        pass_mem, eta_mem, novelty = self.ltem.query(object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                        return False, 'MEMORY_REJECT'
        vac = self.vack.evaluate(traj, context, t_now)
        if not self.vack.kc_val(vac):           return False, 'VALUE_MISALIGNED'
        if not self.sck.kc_spec(cert, spec, t_now):   # 新增：新鲜/可逆/校准
            return False, 'SPEC_UNSAFE_OR_STALE'
        if not self.piak.kc_clar(action, ctx):        # 新增：认识论门
            return False, 'EPISTEMIC_UNCERTAIN'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5, eta_spec=0.5, eta_info=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        return base * eta_mem * eta_val * eta_bal * eta_spec * eta_info
```

## 4. 正确性论证（增量更新）

### 引理 43（推测证书硬门的安全性）

**陈述**：设代理校准 P(|ŝ_i−s_i|≤ε_s) ≥ 1−δ_s，回滚策略 ρ 在 R_safe 上于 T_s 内不触发任何硬门违例。若 kc_spec 通过且推测路径最终 COMMIT，则所有门（含被推测门）真实通过；若未 COMMIT，则 ρ 将状态带回 Exec_v4。

**证明**：kc_spec 通过要求证书新鲜、动作 ∈ R_safe、回滚已验证、代理校准；COMMIT 仅在被推测门 `true_pass` 全真时发生，未推测门本就真验证，故提交状态满足全部 v4 硬门。未 COMMIT 时 ρ 的不变量保证落点 ∈ Exec_v4。校准只决定「是否敢推测」，不改变提交真值，故不引入假接受。∎

**工程含义**：并发/推测是**时延优化而非安全放宽**；任何校准异常或回滚不可达都使 kc_spec 失败并退回串行，fail-closed 保持。

### 引理 44（临界路径时延界）

**陈述**：p 个 worker 的列表调度满足 L_cp ≤ L(π) ≤ L_cp + max_i l_i·(1−1/p)。对慢门集 S 推测后，期望时延满足 E[L] ≤ L_cp + Σ_{i∈S∖CP}(1−q_i)(l_i+l_ρ) − Σ_{i∈S∩CP} q_i·l_i。

**证明**：L_cp 为任何调度的下界；列表调度是 (2−1/p)-近似，在等长任务上更紧。推测将 CP 上慢门的期望耗时从 l_i 降为 (1−q_i)(l_i+l_ρ)，非 CP 慢门仅增加失败回滚的期望惩罚。∎

### 引理 45（主动交互的近似最优与停止）

**陈述**：若 I(θ;Z_q|D) 对查询集次模，贪心 `select` 达 (1−1/e)·OPT；在线性成本下，边际 VoI ≤ c 即停止使期望净效用最优。

**证明**：次模函数贪心近似为经典结果（Nemhauser–Wolsey–Fisher）；最优停止由 Wald 方程/鞅停止定理得，阈值即边际收益等于边际成本处。∎

### 引理 46（认识论门的必要性）

**陈述**：对任意决策器 P_e ≥ (H(θ|D)−1)/log|Θ|（Fano）。故 H > H_max := 1+ε log|Θ| 时任何直接行动的错误率下界 > ε，违反风险预算，fail-closed 必须拒绝或先降熵。

**证明**：Fano 不等式 H(θ|D) ≤ H_b(P_e)+P_e log(|Θ|−1)，H_b ≤ 1，整理即得。∎

**诚实声明**：低熵仅为必要条件，不蕴含低错误（错误仍受模型/校准影响）；故 kc_clar 之后仍需 kc_val/kc_bal 等门。VoI 次模性在非线性价值交互下可能失效（见 R56）。

### 定理 v5（执行集严格收缩与并发-主动交互安全）

**陈述**：在 (B1)~(B6) 继承 v4 假设，并新增 (B7) 代理校准界成立、(B8) R_safe 回滚可行、(B9) 信念后验可表示 下：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29（严格收缩）；
(ii) 推测提交不产生 v4 之外的接受（引理 43）；
(iii) 并发时延由引理 44 界，命中率越高越接近 L_cp；
(iv) 主动交互近似最优且高熵拒绝必要性由引理 45/46；
(v) 九硬门合取仍为证书格的最大下界，fail-closed 保持。

**证明**：(i) v5 在 v4 每条路径追加 kc_spec（新鲜/可逆/校准）与 kc_clar（认识论），故只缩不涨；两门非恒真（存在陈旧证书、存在高熵未澄清状态）保证严格性。(ii)~(v) 分别由引理 43、44、45/46 与 v4 定理 1/2 继承。∎

## 7. 本轮最大风险（最终确认）

**一句话**：**推测执行在代理模型过度自信或回滚实际不可行时会击穿 fail-closed**——若校准界被分布漂移破坏、或接触/柔性任务在 T_s 内无法无碰撞无过载地回滚，系统会在「以为可逆」的幻觉下提交不可逆动作，而真值验证到达时已无法撤销。
