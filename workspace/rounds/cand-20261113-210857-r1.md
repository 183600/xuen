# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉定位」×「场景泛化」）

> R69 把不确定性一分为二（aleatoric / epistemic），并教会系统「问」。但 FLUID-RAS 有一条从未写进不变式的隐藏前提——**观测所在的坐标系本身是可信的**。U_ale、U_epi、流似然、模态聚类，全部在一个被默认正确的帧里计算。视觉定位提醒我们：帧不是给定的，它是推断出来的——会多峰（我在 A 还是 B？）、会漂移、会在换场景后整片失效。场景泛化则补上第二刀：定位误差的分布在场景之间不是同分布的，而是 **group 结构**——大多数场景很准，少数自相似场景会「高置信地错」。
>
> 一旦帧错，R69 的整个不确定性二分都在错误的世界里进行：它会把「地图翻了个面」读成「任务有歧义」，然后很有礼貌地去问一个根本不该问的问题；或者把「换了个世界」读成「噪声变大」，把 λ 一路收紧到停摆。**R69 问「该向谁求证」，却没有先确认「我是不是站在我以为的那个世界里」。**
>
> 本轮主张：在交互层**之下**再插一层**帧层**：先回答「我在哪、这是不是同一个场景」，再谈「我该做什么、问什么」。命名 **LOCUS-RAS**（Localization-grounded, Cross-scene Uncertainty-Separating Risk-Adaptive Safety）。一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该问谁」，R70 问「**我问的对象，和我共处同一个世界吗**」——问错世界，比不问更危险。

## 0. 直觉与动机

**灵感 1（视觉定位 → 帧是一个被遗忘的隐藏状态变量）**
直觉：R68 把「测量准不准」标定出来了，R69 把「动作怎么选、该问谁」学出来了，但两者都把 `o_t` 当成漂浮在真空里的观测，从不追问它挂在哪个坐标系上。真实系统里，`o_t` 永远以某个位姿/地点为先验被组织：检测框在哪个地标附近、局部地图对齐到哪一段、动作在哪个房间的走廊里执行。视觉定位把这个先验变成一个**可推断、可多峰、可带协方差的随机变量** `(b(ℓ), {T_i, w_i, Σ_i})`。帧一旦进入状态，R69 的 `U_ale/U_epi` 就必须写成 `U_ale^{T}, U_epi^{T}`——不确定性是有坐标系的。

**灵感 2（场景泛化 → 误差是 group 结构的，不是平均的）**
直觉：R69 的所有保证都是「同一分布内」的平均承诺。但定位恰恰是**换场景就换误差分布**的典型模块：走廊、森林、仓库、雪地、玻璃幕墙，纹理重复导致感知别名；白天到夜晚、夏到冬导致外观漂移。危险不在于平均变差，而在于**少数场景灾难性地差**——少数自相似场景会「高置信地错」，一条错误轨迹可以主导尾部风险。所以泛化保证必须是**场景条件（group-conditional）**的，而且系统必须能检测「我不在任何已认证的场景群里」。逐帧 OOD（R69 E298）不够：没见过一个新杯子 ≠ 换了一个世界。

**灵感 3（归因恒等式 → 动作多峰有三种来源，R69 只认两种）**
直觉：这是本轮最关键的一步。R69 看到 K 个动作模态，就把熵 `H(M)` 全记在「任务歧义」账上。但多峰其实有三个来源：(a) 真任务歧义（绕左还是绕右）；(b) 噪声（模态内方差）；(c) **帧歧义**（我以为在 A，其实在 B，于是两个动作都「合理」）。第三类在 R69 里被误记成 (a)。用条件熵做一次干净拆分：

`H(M) = I(M; L) + H(M | L)`，

其中 `L` 是地点/帧假设。`I(M;L)` 是**帧可归因歧义**，`H(M|L)` 才是**真任务歧义**。前者问人没用（人会基于同一个错世界回答），只能靠重定位消解；后者才是 R69 的看/问/触。R69 高估了多少任务歧义？正好是 `I(M;L)`。这个恒等式让「该重定位还是该提问」从直觉变成一次信息分解。

**灵感 4（帧优先 → 为什么重定位必须排在提问前面）**
直觉：所有下游决策都条件于帧。花一份预算去消解 `U_frame`，会让后续所有条件熵一起下降；花同一份预算去消解 `H(M|L)`，只在当前帧内有效——如果帧是错的，这份钱花在错误的世界里。因此交互预算应有一个**优先级**：帧未认证时先重定位，任务未消解时再提问。这不是拍脑袋，而是条件依赖结构决定的：帧是「共同原因」，对其做信息获取的边际收益支配对下游细枝末节的获取（定理 19）。

**灵感 5（自信的错误 → 别名让帧高置信地错，必须有一条吸收不了的通道）**
直觉：感知别名（perceptual aliasing）制造最阴险的失败：系统 `H(b)` 很低、局部匹配残差很低，却稳稳地站在错误的地方。这与 R68 的慢变故障**同构**——局部计量把错误解释掉了。R68/R69 用「行为似然」做第二意见，本轮用**全局一致性**做帧的第二意见：错误但自信的匹配局部处处自洽，但会破坏长时程**闭环/拓扑/共视**一致性（引理 20）。局部通道测「这一帧像不像」，闭环通道测「整条轨迹能不能闭合成一个世界」；别名只能骗前者。

**灵感 6（泛化证书 → 只对已认证场景群承诺，未认证就冻结）**
直觉：给「所有场景」发性能保证是自欺。正确姿态是**分群承诺**：对每个已认证场景群用 split conformal 给出群条件覆盖；对新场景，只在场景嵌入距离 `d_scene` 足够近时给迁移界（引理 21），否则**不发证书**。没有证书就不许用 R69 的 resolution bonus——退回「帧冻结 + 最保守 + 请求接管」。泛化不是一句「模型很强」，而是一张能说清「我在哪些世界里有资格快跑」的证书。

**灵感 7（新攻击面 → 骗你重定位，比骗你提问更致命）**
直觉：一旦系统会主动重定位，攻击面就升级了。对抗路标/二维码可以把系统引到一个「更一致但错误」的平行地点；场景伪装可以把 A 布置成 B；别名诱导可以让「重定位」这一动作本身成为攻击入口。R69 的投毒会骗到一句错回答，R70 的投毒能骗到一个错**世界**——此后所有推理、所有交互、所有证书都在错误前提上盖章。所以本轮必须交付：重定位动作的安全认证、全局一致性反吸收、「单源帧证据不得定案」、以及场景门误报/漏报的审计。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LOCUS-RAS 总览）** LOCUS-RAS = (VLM, FUD, RLA, GCA, FSA, SGO, SGC, RAS-WM‡)。四不变式：
(i) **继承 FLUID 三不变式**（零学习写操作、交互预算硬约束、证据纪律）；
(ii) **帧优先序**：单位预算内，若帧未认证/存疑，交互预算必须先用于重定位，不得先用于任务提问；
(iii) **场景泛化门**：仅当当前场景落入已认证群（或 `d_scene ≤ τ_gen` 且有迁移界）时，R69 的 resolution bonus 才可用；否则进入帧冻结/最保守；
(iv) **严格包含**：帧退化为点质量且场景已认证时，LOCUS 逐指令退化为 FLUID-RAS。

**定义 311（多假设定位状态）** 地点信念 `b ∈ Δ(ℒ)`（ℒ 为地标/place 集），位姿假设集 `𝒯 = {(T_i, w_i, Σ_i)}_{i=1}^N`，`T_i ∈ SE(3)`、`w_i ∈ [0,1]`、`Σ_i ∈ Sym⁺(6)`，`Σ_i w_i = 1`。定位后验 `p(T, ℓ | o_{1:t}, map)`，由 VLM 输出（粒子/位姿图/多假设匹配）。

**定义 312（帧不确定性与别名间距）** `U_loc = H(b) + Σ_i w_i · tr(Σ_i)`；`Δ_place = min_{i≠j} d_geo(T_i, T_j)`（SE(3) 测地距离，或 place 图最短路）。关键警句：**`U_loc` 低 ≠ 帧可信**——别名时 `b` 尖锐却可能是错的（定义 316）。

**定义 313（帧归因分解）** 设动作模态随机变量 `M`、帧假设 `L`。恒等式 `H(M) = I(M;L) + H(M|L)`。定义**帧可归因歧义** `U_frame ≜ I(M;L)`、**真任务歧义** `U_epi^task ≜ H(M|L)`。退化性质：`L = δ_{ℓ*}` 时 `I(M;L)=0`、`H(M|L)=H(M)`，精确回到 R69 定义 297。估计用 plugin / 交叉拟合，偏差界见引理 19。

**定义 314（帧优先 VoI 仲裁 RLA）** 两级 VoI：先 `VoI_frame(g) = U_frame − E_{y~p(·|g)}[U_frame | y]`，再 `VoI_task(g) = U_epi^task − E[U_epi^task | y]`。规则：`g* = argmax` 按「帧级 → 任务级」的字典序在安全/预算内选取；任一级 `VoI − c ≤ 0` 即下沉到下一级，全部无利可图则走 R68 纯保守。定序依据见定理 19。

**定义 315（重定位动作空间）** `g_reloc = (look_landmark, revisit_loop, request_map_tile, climb_for_view, wait_for_parallax)`，与 R69 的 `(g_gaze, g_probe, g_ask)` 并列为信息动作，统一记为 `g ∈ 𝒜_info⁺`。全部须过 C-RAS-WM 认证；新增约束：不得为看得更清而越出安全走廊，不得进入未认证区域。

**定义 316（全局一致性残差与吸收判据）** `ρ_loop =` 长时程闭环残差 `+` 拓扑/共视违背量。判据：若局部匹配/传感器残差 `ρ_local` 低而 `ρ_loop` 高 ⇒ **自信别名疑**。这是 R68 慢变故障 `(r_res↓)` 在帧层的镜像，但独立于 R69 的 `(r_res, Δa)` 通道。

**定义 317（帧第二意见 FSA）** `Δa_frame = a_score(o_{t:t+k} | T_bel) − min_{T_alt∈𝒯} a_score(o_{t:t+k} | T_alt)`，其中 `a_score` 复用 R69 FMA 的策略密度通道，仅把条件从「观测校正」换成「帧假设」。`Δa_frame > 0` ⇒ 备选帧更解释观测。联合模式：**`(ρ_loop↑, Δa_frame↑)` ⇒ 自信别名/被劫持**。

**定义 318（场景嵌入与泛化间隙 SGO）** 场景特征 `φ_scene(o)`（外观/纹理/几何/动态统计），已认证场景集 `{φ_s}`。`d_scene = min_s W_1(φ_scene, φ_s)`（或 MMD）。场景新颖判据 `d_scene > τ_gen`。语义区分：逐帧 OOD 问「这个物体见过吗」，**场景 OOD 问「这个世界的生成机制变了吗」**——后者才是定位失效的根因。

**定义 319（场景群 conformal 证书 SGC）** 对每个已认证场景群 `s`，用 split conformal 得群条件覆盖 `P(R_s ≤ r_s) ≥ 1−α`。新场景：若 `d_scene ≤ τ_gen` 给迁移界（引理 21）；否则**不发证书**（no guarantee），直接触发定义 320 最保守级。

**定义 320（三级保守退避 + 帧冻结）** 优先级：**帧未认证/别名疑 > 场景未认证 > 任务 epistemic 未消解 > 纯 aleatoric**。
- 帧可疑：冻结为「最后认证帧」，`λ = λ_max`，仅允许重定位/停车/请求接管；
- 场景未认证：禁用 resolution bonus，`λ = λ_floor(U_ale + U_epi^task + U_frame)`；
- 任务歧义可解：走 R69 交互，`λ = λ_floor(U_ale)`；
- 仅噪声：`λ = λ_floor(U_ale)`。
每级单调、可审计、可逐指令比对。

**定义 321（重定位安全）** `g_reloc` 过 C-RAS-WM 认证；重定位期间任务动作收缩至安全集；失败/超时 ⇒ 帧保持未认证、`λ` 单调不降；不得用「多走两步看清」交换安全包络。

**定义 322（参与式审计 VQAuditor-F）** 审计帧决策：该重定位却去提问、自相似场景过度自信、重定位被对抗路标诱导、场景门误报/漏报、帧切换抖振。结论回灌 AuditBuf，成为下一轮 RLA 的成本/先验。

**定义 323（威胁模型 AIC-LOCUS）** `ℰ_LOCUS = ℰ_FLUID × ℰ_landmark × ℰ_alias × ℰ_spoof`：对抗路标/二维码、场景伪装（把 A 布置成 B）、别名诱导（骗到一个「更一致但错误」的平行地点）、地图投毒。

**定义 324（证书 J_LOCUS）** `J_LOCUS = (J_FLUID, l_bel_hash, U_loc, U_frame, Δ_place, d_scene, ρ_loop, Δa_frame, scene_cert_id, locus_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ (帧已认证 ∨ 已入帧冻结) ∧ (场景已认证 ∨ 未声明 bonus) ∧ 审计通过`。

**定义 325（严格包含边界）** 当 `b = δ_{ℓ*}`、`Σ_i → 0`、`d_scene ≤ τ_gen`、`ρ_loop < τ`、`Δa_frame < τ` 时，LOCUS 与 FLUID 逐指令相同（定理 18）。故 LOCUS 是 FLUID 的严格泛化，安全侧不让步。

**定义 326（时标与反抖振）** 重定位有独立预算与冷却期；帧切换需连续 `m` 帧一致 + 闭环证据；自适应 `K` 同时由 `H_mode` 与 `H(b)` 驱动，防「帧一跳就狂采样」。

# IP-264 VLM：多假设视觉定位（输出地点信念 + 位姿假设，而非单一位姿）
class MultiHypLoc:
    def infer(self, o_t, prior_b):
        b = self.place_head(o_t, prior_b)          # b(l)，多峰地点信念
        poses = self.pose_sampler(o_t, b)          # {(T_i, w_i, Sigma_i)} on SE(3)
        return b, poses

    def update(self, b, g_reloc, obs_new):         # 重定位后验更新
        return bayes_update(b, self.likelihood(obs_new, g_reloc))

# IP-265 FUD：把动作模态熵按「帧来源」归因（本轮核心恒等式）
def frame_attribute(samples, b, poses):
    modes, w = cluster_trajectories(samples)       # 复用 R69 定义 296
    H_M   = entropy(w)
    I_ML  = mutual_info(mode_identity, place_hypothesis)  # = U_frame
    H_task= max(H_M - I_ML, 0.0)                   # = H(M|L) = U_epi^task
    U_loc = entropy(b) + expected_pose_trace(poses)
    return U_loc, I_ML, H_task, modes

# IP-266 RLA：帧优先的 VoI 仲裁（先重定位，再提问）
def frame_first_voi(U_loc, U_frame, H_task, budget):
    if U_loc > TAU_LOC or U_frame > TAU_ATTR:      # 帧级
        best = None
        for g in reloc_candidates():
            if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
            score = (U_frame - expected_frame_entropy(g)) - cost(g)
            if best is None or score > best.score: best = (g, score)
        if best and best[1] > 0: return ('reloc', best[0])
    if H_task > TAU_TASK:                          # 任务级
        best = None
        for g in task_info_candidates():
            if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
            score = (H_task - expected_task_entropy(g)) - cost(g)
            if best is None or score > best.score: best = (g, score)
        if best and best[1] > 0: return ('task', best[0])
    return (None, None)

# IP-267 GCA：全局一致性——局部匹配/标定吸收不了的帧通道
def global_consistency(traj, map, b):
    rho_loop = loop_closure_residual(traj, map)     # 长时程闭环残差
    rho_topo = topological_mismatch(traj, map)      # 拓扑/共视违背
    return max(rho_loop, rho_topo)

# IP-268 FSA：帧第二意见——备选帧下观测的似然
def frame_second_opinion(policy, o_win, T_bel, T_alt):
    a_bel = -policy.log_likelihood(o_win, cond=T_bel)
    a_alt = -policy.log_likelihood(o_win, cond=T_alt)
    return a_bel - a_alt                            # >0：备选帧更解释观测

# IP-269 SGO：场景级泛化观测（不是逐帧 OOD）
def scene_gap(scene_feat, certified_feats):
    d = min(wasserstein1(scene_feat, f) for f in certified_feats)
    return d, (d > TAU_GEN)

# IP-274 主闭环
def LOCUS_RAS_round(M, obs):

    b, poses = M.vlm.infer(obs.o, M.last_b)
    z, o     = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)

    K = 4 if (M.fmp.mode_head(z) > TAU_MODE or entropy(b) > TAU_LOC) else 1
    samples = M.fmp.sample(o, K)

    d_scene, novel = M.sgo.scene_gap(M.scene_feat(obs), M.certified_scenes)
    rho      = M.gca.global_consistency(M.traj, M.map, b)
    da_frame = M.fsa.frame_second_opinion(M.fmp, obs.window, M.frame_bel, M.frame_alt)
    alias    = (rho > TAU_LOOP) or (da_frame > TAU_FRAME)
    # 3) 帧优先仲裁；不可信/新颖则强制重定位
    if novel or alias:

        U_loc, U_frame, H_task, _ = M.fud.recompute(...)

    elif novel:

    else:

        frozen = False
    # 5) 认证前缀 + 执行（帧冻结时任务动作收缩到安全集）
    A = M.ach.propose(M.x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if frozen: k = min(k, M.safe_stop_prefix())
    mode = M.select_mode(modes, H_task, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 审计 + 证书（帧决策与场景证书一并入账）
    M.vqa_f.submit_async(kind, g, U_loc, U_frame, d_scene, rho, da_frame, frozen)
    return k, lam, mode, (U_ale, U_frame, H_task), frozen
```

## 3. 推导

**引理 19（帧归因恒等式与可估性）** 对任意动作模态 `M` 与帧假设 `L`，恒有 `H(M) = I(M;L) + H(M|L)`。以 plugin 估计三者，在样本量 `N`、`|ℳ|,|ℒ|` 有限时，估计误差 `O(√(log N / N))`；系：**R69 的 `H_mode` 恰以 `I(M;L)` 的量高估任务歧义**，所以「多峰但都是帧造成的」会被 R69 误判为「该提问」。推论：`U_frame` 为 0 时归因退化为 R69，二者不冲突，只是多了一项可加分解。

**引理 20（自信别名的可检测性）** 设真实帧 `L*`、被信帧 `L̂`，二者处在自相似结构上（`Δ_place` 大、视觉局部特征近似）。错误但自信时 `H(b)≈0`、`ρ_local≈0`（局部通道失效，与 R68 引理 13 同构）；但在窗口 `k` 内，闭环/拓扑残差期望满足 `E[ρ_loop] ≥ c₁·d_geo(L̂, L*) − √(var)`，且 `E[Δa_frame] ≥ c₂·d_geo(L̂,L*) − √(trΣ_flow)`（A99：帧距离到全局残差的下界）。故 **`(ρ_loop↑, Δa_frame↑)` 是「自信别名/帧劫持」的判别性联合模式**。**重要边界**：该下界要求别名区非全局自洽；若整个别名区被整体平移复制（自相似走廊），`d_geo` 与 `ρ_loop` 可同时退化——这是本轮最大风险的数学根（见第 6 节）。

**引理 21（场景泛化间隙界）** 对新场景 `s'`，设已认证最近场景 `s*`、场景特征间 `W_1` 距离 `d_scene`，任务风险对场景特征 `L`-Lipschitz。则 w.h.p. `R_{s'} ≤ R_{s*} + L·d_scene + B·√(log(1/δ)/n_{s*})`。当 `d_scene > τ_gen` 时**不存在**此类界（新群可任意不同）。系：**泛化是群性质，边际平均保证会骗人**——一个灾难场景即可吞掉平均收益，故必须用定义 319 的群条件证书 + 定义 318 的场景门。

**定理 18（LOCUS 严格包含 FLUID）** 在 A99–A101 下，LOCUS 的任意状态期望风险 ≤ FLUID；当帧为点质量、场景已认证、`ρ_loop/Δa_frame` 均低于阈值时，两者**逐指令相同**（定义 325）。即 R69 是 LOCUS 在「帧永远可信」边界上的退化：安全侧不做让步，效率侧只在帧/场景证书允许时才提速。

**定理 19（帧优先的预算最优性）** 设任务证据在给定帧下与帧证据条件独立，且两级 VoI 关于证据集自适应次模。则按「帧→任务」的字典序贪心分配预算，对最优分配达到 `(1−1/e)` 近似；且当 `U_frame > 0` 时，帧优先在单位成本上消解的期望歧义严格支配任务优先（后者把钱花在条件于错误帧的世界里）。系：**先定位，再提问**不是保守，而是信息论上更划算。

**定理 20（重定位安全与无突变）** 信息/重定位动作经 C-RAS-WM 认证（定义 315、321）后，其物理风险 ≤ `ε_loc`；重定位只改变「在哪个世界里条件」，不改变安全包络；失败/超时/被投毒时 `λ` 单调不降地回到帧冻结；R68 的提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：LOCUS-RAS 把「全局闭环/拓扑一致性」当作标定与局部匹配都吸收不了的帧层第二意见，但在**自相似场景**（平行走廊、雷同仓库、森林/雪地、玻璃幕墙）里，一个错误帧同样可以全局自洽——整条轨迹被整体平移到一条平行通道，`ρ_loop` 与 `Δa_frame` 同时沉默，系统会**自信地重定位到一个错误的世界**，这比它出发时「诚实地不知道自己在哪」更危险。

**次级风险与缓解**：
1. **场景门误报/漏报**（新场景被当旧场景快跑，或反之过度冻结）→ 群 conformal + `d_scene` 双门 + E306/E307 校准；
2. **重定位动作越界**（为看清而走出安全走廊）→ 定义 315/321 认证 + 定理 20；
3. **帧抖振**（两个相似地点来回跳）→ 冷却期 + 连续 `m` 帧一致 + 闭环证据（定义 326）；
4. **归因估计噪声**（`I(M;L)` 小样本偏差）→ 交叉拟合 + 保守偏置 + E302；
5. **对抗路标/场景伪装**（帧层投毒）→ `ℰ_spoof` 对抗训练 + 「单源帧证据不得定案」+ VQAuditor-F 审计。

# IP-264 VLM：多假设视觉定位（地点信念 + SE(3) 位姿假设）
class MultiHypLoc:
    def infer(self, o_t, prior_b):
        b     = self.place_head(o_t, prior_b)       # b(l)，多峰
        poses = self.pose_sampler(o_t, b)           # {(T_i, w_i, Sigma_i)}
        return b, poses
    def update(self, b, g_reloc, obs_new):
        return bayes_update(b, self.likelihood(obs_new, g_reloc))

# IP-265 FUD：帧归因恒等式 H(M)=I(M;L)+H(M|L)
def frame_attribute(samples, b, poses):
    modes, w   = cluster_trajectories(samples)      # R69 定义 296
    H_M        = entropy(w)
    U_frame    = mutual_info(mode_identity, place_hypothesis)   # I(M;L)
    H_task     = max(H_M - U_frame, 0.0)            # H(M|L)
    U_loc      = entropy(b) + expected_pose_trace(poses)
    return U_loc, U_frame, H_task, modes

# IP-266 RLA：帧优先的 VoI 仲裁
def frame_first_voi(U_loc, U_frame, H_task, budget):
    if U_loc > TAU_LOC or U_frame > TAU_ATTR:
        best = argmax_safe(reloc_candidates(), lambda g: frame_voi(g) - cost(g))
        if best and best.score > 0: return ('reloc', best.g)
    if H_task > TAU_TASK:
        best = argmax_safe(task_info_candidates(), lambda g: task_voi(g) - cost(g))
        if best and best.score > 0: return ('task', best.g)
    return (None, None)

# IP-267 GCA：局部/标定吸收不了的帧通道
def global_consistency(traj, map, b):
    return max(loop_closure_residual(traj, map),
               topological_mismatch(traj, map))

def frame_second_opinion(policy, o_win, T_bel, T_alt):
    return (-policy.log_likelihood(o_win, cond=T_bel)
            + policy.log_likelihood(o_win, cond=T_alt))   # >0：备选帧更解释

    d = min(wasserstein1(scene_feat, f) for f in certified_feats)
    return d, (d > TAU_GEN)

        U_loc, U_frame, H_task, _ = M.fud.recompute(...)
    elif kind == 'task' and g is not None:
        H_task = M.cia.update_belief(modes, M.cia.execute(g))
    if U_loc > TAU_LOC or alias:                    # 帧冻结
        lam, frozen = M.efs.lam_max(), True
    elif novel:
        lam, frozen = M.efs.lam_floor(U_ale + U_frame + H_task), False
    else:
        lam = max(M.efs.risk_scale(...),
                  M.efs.lam_floor(U_ale + (H_task if kind != 'task' else 0.0)))
        frozen = False
    A = M.ach.propose(M.x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if frozen: k = min(k, M.safe_stop_prefix())
    mode = M.select_mode(modes, H_task, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_f.submit_async(kind, g, U_loc, U_frame, d_scene, rho, da_frame, frozen)
    return k, lam, mode, (U_ale, U_frame, H_task), frozen
```

## 4. 推导

**引理 19（帧归因恒等式）** `H(M)=I(M;L)+H(M|L)` 恒成立；plugin/交叉拟合估计误差 `O(√(log N/N))`。系：R69 的 `H_mode` 以 `I(M;L)` 高估任务歧义，「多峰但由帧造成」会被误判为「该提问」。

**引理 20（自信别名的可检测性）** 错误但自信时 `H(b)≈0`、`ρ_local≈0`（局部通道失效，同 R68 引理 13）；但 `E[ρ_loop] ≥ c₁d_geo(L̂,L*) − √var`、`E[Δa_frame] ≥ c₂d_geo(L̂,L*) − √(trΣ_flow)`。故 `(ρ_loop↑,Δa_frame↑)` 判别自信别名。**边界**：整体平移复制的自相似场景可使两通道同时沉默——本轮最大风险之根。

**引理 21（场景泛化间隙界）** `R_{s'} ≤ R_{s*} + L·d_scene + B√(log(1/δ)/n_{s*})`（`d_scene≤τ_gen` 时）；`d_scene>τ_gen` 时无此类界。系：泛化是群性质，边际保证会被单个灾难场景吞掉，必须群条件证书 + 场景门。

**定理 18（LOCUS 严格包含 FLUID）** 任意状态期望风险 ≤ FLUID；帧点质量 + 场景认证 + 双通道低时逐指令相同（定义 325）。R69 = 「帧永远可信」边界。

**定理 19（帧优先预算最优性）** 给定帧下任务证据条件独立、两级 VoI 自适应次模时，帧→任务字典序贪心对最优分配达 `(1−1/e)`；`U_frame>0` 时帧优先在单位成本上严格支配任务优先。

**定理 20（重定位安全与无突变）** 认证后物理风险 ≤ `ε_loc`；重定位只改条件不改安全包络；失败/超时/投毒时 `λ` 单调不降到帧冻结；换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：LOCUS-RAS 把「全局闭环/拓扑一致性」当成标定与局部匹配都吸收不了的帧层第二意见，但在**自相似场景**（平行走廊、雷同仓库、森林/雪地、玻璃幕墙）里，一个错误帧同样可以全局自洽——整条轨迹被整体平移到一条平行通道，`ρ_loop` 与 `Δa_frame` 同时沉默，系统会**自信地重定位到一个错误的世界**，这比它出发时「诚实地不知道自己在哪」更危险。

**次级风险与缓解**：场景门误报/漏报（群 conformal + `d_scene` 双门 + E306/E307）；重定位动作越界（定义 315/321 认证 + 定理 20）；帧抖振（冷却期 + 连续 m 帧一致 + 闭环证据）；归因估计噪声（交叉拟合 + 保守偏置 + E302）；对抗路标/场景伪装（`ℰ_spoof` 对抗训练 + 单源帧证据不得定案 + VQAuditor-F）。
