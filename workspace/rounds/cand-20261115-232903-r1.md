# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「用户画像」×「开放词汇」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**可溯源的开放语义 + 不降安全的个性化**。两个灵感分别治理 v10 的两种债：**封闭词表债**（STF 的 ν_ℓ 以固定类原型为参照，长尾/未知语义只能表现为"看起来像已知类"，这正是上轮自认的最大风险：ν≤τ_sem 但语义已变）、**千人一面债**（规范、阈值、词汇对所有人相同，个性化只能靠人工配置，且画像本身无治理）。必须保持 v10 铁律：OVG 失效 ⇒ 回到封闭词表 C_base（严格等价 v10）；UPP 失效/过期/未同意 ⇒ 中性画像 π_∅（严格等价 v10）；未知类一律受限（行为支配 v10，不新增任何不安全物理动作）。

## 0. 直觉与动机

**灵感 1（开放词汇 → 从"封闭类距离"到"显式未知"）**

直觉：v10 的风险根子不是阈值没调好，而是**参照系是封闭的**。把语义创新度定义成"与若干已知类原型的距离"，等于假设世界上只有那几类；于是长尾物体会被最近的已知类吸收，得到很低的 ν——这就是"看起来熟、其实不同"。开放词汇提供两件东西：(i) 文本锚定的连续概念空间，使"未知"成为一个**显式、可检索**的类别，而不是被最近已知类吸收；(ii) 概念注册表使每个参与控制的概念都有来源、校准覆盖与有效期——把"词汇"从模型的隐式知识变成可审计的数据行。

核心创新：**开放词汇语义接地（OpenVocabularyGrounding, OVG）**。概念空间 C = C_base ∪ C_user ∪ C_open；创新度从标量升级为**双因子**：认知新颖度 ν^epi（到整个概念支撑集的最大匹配余量，回答"我见过吗"）与语义不一致度 ν^sem（观测与预测概念的冲突/多视角分歧，回答"它像我以为的那个吗"），任一越阈即触发守卫。关键一步：v10 把"未知"压进标量 τ_sem 的盲区；v11 把"未知"显式化为**受限默认**（P16），于是长尾新颖不再需要靠阈值"恰好"捕获——它默认进入受限剖面 Π_unk，只有通过溯源与校准覆盖的概念才被允许进入乐观决策。

**灵感 2（用户画像 → 个性化先验，但画像不降安全）**

直觉：家庭/赛场的规范与词汇高度依赖具体的人——"我的杯子"、可接受的接近距离、禁入房间、习惯手势。v10 的 NRB 规范表是全局的，STF 的地标图对所有用户同构。用户画像提供**个性化先验**：别名把用户的词接到地标、偏好把软规范实例化、能力限制调整交互节奏。但画像本身是新一轮风险：隐私、偏见、过期、投毒。因此核心创新不是"用画像调参"，而是**画像不降安全律（Profile-Never-Loosen, P17）**：画像只能**收紧**安全裕量、降低能力上限、提升消歧，不得放松任何硬不变式；所有画像化参数先投影到安全集 S_safe，投影后的物理可行集 ⊆ v10 可行集。

核心创新：**用户画像先验（UserProfilePrior, UPP）** + **画像同意台账（ProfileConsentLedger, PCL）**：字段级同意、最小化、TTL、可验证遗忘、DP 合并；中性画像 π_∅ 严格等价 v10。

**两者咬合（接在 v10 的五脏上）**

OVG 把"未知"从盲区变受限区，并让"私有长尾"（用户特有物/词）有合法入口；UPP/PCL 让这个入口不被投毒、不被滥用。二者共同把 v10 的"显著/非显著"标量分割升级为**三态判定**：

| 态 | 判定 | 行为 | 依据 |
|---|---|---|---|
| 已知-可信 | 概念可溯源、覆盖充分、ν^epi/ν^sem 均低 | 正常乐观规划 | v10 证书 + β_STF |
| 已知-需谨慎 | 双因子之一越阈 | 1 帧内切中止点/收缩 K_eff | v10 守卫 + 引理 92 |
| 未知-受限 | 不匹配任何可采纳概念，或覆盖/溯源不足 | Π_unk：禁抓、距增、K=1、请求确认 | P16 + 引理 93 |

这不是"再加两个模块"，而是把 v10 最难证明的前提——"τ_sem 能分开显著与非显著"——替换成两个**更弱、可逐概念测量**的命题：未知检测率与概念覆盖。前者即使失败也落到受限默认，而非 v10 的乐观盲区。

## 1. 研究问题（轮次升级版）

- **Q1（开放词汇信任）**：如何把 ν 从"到封闭类原型的距离"升级为"认知新颖度 + 语义不一致度"的双因子可测判定，使长尾未知默认受限、已知类校准覆盖 ≥99%，且 50Hz 守卫新增开销 ≤0.3ms（总预算 ≤0.5ms）？
- **Q2（可溯词汇）**：每个参与控制的概念/别名如何携带来源、同意、校准覆盖与 TTL，使未溯源概念（含文本标签注入）不能进入控制回路，且注册表变更 100% 留痕、篡改可检出？
- **Q3（不降安全画像）**：用户画像如何在安全投影下实例化规范/阈值/别名，使画像失效或过期时严格等价 v10，画像投毒与隐私外泄有可证界，多机共享画像有 DP 保障？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 未知即受限律（Unknown-Restrictive, OVG）**
不在注册表、校准覆盖 < τ_cov、或已过期的概念 ⇒ 视作未知；未知邻域内动作空间收缩至 Π_unk（禁抓、距增 d_unk、K_eff=1、语音请求确认），不得做乐观假设。Π_unk ⊆ Π_r（嵌套收缩，失效组合不相互抵消）。

**P17 画像不降安全律（Profile-Never-Loosen, UPP）**
画像只能收紧裕量、降低能力上限、提升消歧；任何画像化参数先经 Proj_{S_safe} 投影，硬不变式与 d_safe/d_eth 下界不可被画像修改。画像失效/过期/未同意 ⇒ π_∅，行为严格等价 v10。

**P18 开放词汇可溯源律（Vocabulary Provenance, CR/PCL）**
每个参与控制的概念/别名必须有来源层级（factory/user/discovered）、同意凭证、校准覆盖与 TTL；文本标签是数据不是指令；未溯源者不得影响控制。新增/删除/合并概念与别名均写入台账。

## 3. 与基线的接口（如何退化）

- **OVG/CR 失效**（注册表不可用、文本编码超时、检索超预算）⇒ C←C_base、ν^epi 退化为 v10 的 ν、U^ov≡U^sem ⇒ 严格等价 v10（失去未知默认，保守性回到 v10 前提）；
- **单个概念覆盖不足/过期** ⇒ 该概念移出可采纳集并视作未知（Π_unk），其余行为不变；
- **UPP 失效/过期/未同意** ⇒ π_u←π_∅ ⇒ 规范、阈值、别名严格等价 v10；
- **PCL 失效** ⇒ 冻结画像写入与别名新增，已有项按 TTL 衰减至中性（保守）；
- **STF/NRB/LS/AC/ID/MW/v8 失效** ⇒ 沿 v10 六级退化链（Level-1…Level-6）；Π_unk 与 Π_r 取交（收缩可叠加）。

## 4. 预期贡献

1. **开放词汇双因子信任**：把 v10 最大风险（长尾/未知在 ν≤τ_sem 下隐身）从"调阈值"改为"显式未知默认受限"；失败模式从"不安全地乐观"转为"保守地过度中止"（引理 92–93）；
2. **可溯语义治理**：概念/别名的来源、同意、覆盖、TTL 全程留痕；文本注入被限制为嵌入空间攻击，不能直接改写控制谓词（引理 94）；
3. **不降安全个性化**：画像安全投影 + 中性回退 + 可验证遗忘 + DP 合并，个性化收益不以物理或规范安全为代价（引理 95–96）；
4. **E591–E610** 覆盖概念标定、长尾注入、嵌入欺骗、别名/标签注入、画像投毒/过期/遗忘、多用户冲突、预算与竞赛。

## 5. 本轮最大风险

**一句话**：开放词汇把安全前提从"有限类上的校准"换成"无界词表上的覆盖声明"——对抗性文本标签或嵌入空间欺骗可把未知伪装成已校准的已知概念（或把已知误判为未知而拖垮活性），而用户画像恰是注入别名/意图的高价值入口；一旦画像被投毒或陈旧，"未知"集合会被悄悄改写，证书的保守性依赖一个原则上无法穷举验证的覆盖命题。

## 1. 符号体系增量（定义 549–557）

| 符号 | 含义 |

**新增定义 549（概念空间与开放词汇检索）** 概念 c 由文本锚点集合 {t_{c,i}}_{i≤4} 定义，e_c = normalize(mean_i φ_text(t_{c,i}))。观测匹配 m_ℓ = max_{c∈A_t} cos(o,e_c)。文本编码器与图像编码器固定、版本化；标签字符串只经 φ_text 进入系统，任何情况下不作为指令、路径或谓词代码执行。

**新增定义 550（双因子语义创新度）** 对空间位置 ℓ：
```
ν^epi_ℓ = clip(1 − m_ℓ, 0, 1)
H_k     = −Σ_{c∈topk} p_c log p_c / log k,   p_c ∝ exp(cos(o,e_c)/T)
ν^sem_ℓ = max( H_k, 1 − cos(o, e_{ĉ_pred}) ),  ĉ_pred = F̂_q 预测的交互类
```
三态判定：`admissible=(m_ℓ≥τ_in ∧ c*∈A_t)`；`unknown=¬admissible`；`dangerous=max(ν^epi,ν^sem)>τ_sem`。显著语义突变不再只由单一距离定义，而由"不匹配任何可采纳概念"或"匹配但与预测冲突"共同捕获。

**新增定义 551（开放词汇信任域与三态守卫）** U_t^ov = [∀ℓ∈N_k(走廊): admissible(ℓ)] ∧ [sup_{ℓ∈N_k} max(ν^epi,ν^sem) < τ_sem] ∧ freshness(CR)≤T_fresh。守卫逐帧执行三态：可信⇒continue；需谨慎⇒切最近中止点；未知⇒进入 Π_unk 并请求确认（不执行抓取）。

**新增定义 552（概念注册表与覆盖准入）** CR 条目 c=(t_c, prov, ξ_c, cov_c, ttl_c, sig_c)。准入条件：prov 合法 ∧ ξ_c 有效 ∧ cov_c≥τ_cov（E591 估计）∧ 未过期 ∧ 签名可验。`discovered` 概念默认**不进入 A_t**，只能作为"候选未知"请求用户确认；`user` 概念须用户显式同意；`factory` 概念须出厂标定。条目变更（增/删/合并/TTL 延长）全部写 PCL。

**新增定义 553（未知限制剖面 Π_unk）** Π_unk 在 Π_r 基础上再收缩：K_eff=1；禁止对未知目标抓取/递交；对未知实体保持 d_unk=d_eth+δ_unk；语音请求确认（"这是 X 吗？"）；在 Λ/PCL 标记 unknown。Π_unk 只减动作、增裕量，故其物理可行集 ⊆ v10 可行集。

**新增定义 554（用户画像）** π_u=(u_hash, Pref, Cap, Alias, Consent, RiskTol, t_upd, sig)。`Pref` 只作用于软规范与交互风格；`Cap` 只能降低速度/伸展/负载上限；`Alias` 为用户词到概念/地标的有同意凭证的映射；`Consent` 为字段-用途位图；`RiskTol` 仅用于**收紧**裕量（高风险用户 → 更大 d_eth、更短 K_eff），不得放宽。原始身份不入库，仅存加盐哈希。

**新增定义 555（安全投影实例化）** 设 v10 规范表 N 与基线参数 θ₀=(K_max,d_safe,d_eth,β_base,…)。
```
θ_u = Proj_{S_safe}( instantiate(N, Pref, Cap, Alias) )
S_safe = {θ : 硬不变式(θ)=硬不变式(θ₀) ∧ d_safe(θ)≥d_safe(θ₀)
              ∧ d_eth(θ)≥d_eth(θ₀) ∧ K_max(θ)≤K_max(θ₀)
              ∧ speed(θ)≤speed(θ₀) ∧ β(θ)≥β_base }
```
Proj 为逐参数 clamp，幂等。π_∅ ⇒ θ_u=θ₀（严格等价 v10）。

**新增定义 556（画像-词汇接地接口）** `Alias` 的解析结果为概念/地标引用，必须落在 A_t 且带同意凭证；解析只影响**软字段**（偏好、服务目标、称呼），硬规范 φ_j 独立于别名求值。别名歧义或多义 ⇒ 视作未知（Π_unk）而非猜测。

**新增定义 557（画像同意台账与可验证遗忘）** PCL 记录 grant/revoke/write/erase/merge，字段级用途绑定。原始画像以每用户密钥加密存储；删除 = 销毁密钥 + 写 erase receipt（含密钥指纹与时间），使旧数据在 T_erase 后不可恢复。多机共享只交换 (ε,δ)-DP 统计量，组合隐私预算显式记账。

# IP-361 OpenVocabularyGrounder：开放词汇接地（复用 v8 感知骨干）
class OpenVocabularyGrounder:
    def __init__(self, registry, tau_in=0.62, tau_epi=0.35,
                 tau_sem=0.35, k=5, T=0.07, T_fresh=2.0):
        self.reg = registry                 # IP-362
        self.tau_in, self.tau_epi, self.tau_sem = tau_in, tau_epi, tau_sem
        self.k, self.T, self.T_fresh = k, T, T_fresh

    def admissible(self, now):
        return [c for c in self.reg.entries()
                if c.signed and c.consent_ok and c.cov >= TAU_COV
                and now - c.t_added <= c.ttl]

    def frame_update(self, detections, pred_cls):
        A = self.admissible(now())
        for d in detections:
            o = normalize(d.img_embed)      # 感知侧已算，缓存
            sims = {c: cos(o, c.e) for c in A}
            m = max(sims.values(), default=-1.0)
            topk = sorted(sims.values(), reverse=True)[:self.k]
            H = entropy_softmax(topk, self.T)
            s_pred = sims.get(pred_cls, -1.0)
            d.nu_epi = clip(1.0 - m, 0.0, 1.0)
            d.nu_sem = max(H / log(self.k), 1.0 - s_pred)
            d.state = ('unknown' if m < self.tau_in or self.reg.get(argmax(sims)) not in A
                       else 'dangerous' if max(d.nu_epi, d.nu_sem) > self.tau_sem
                       else 'trusted')
            d.concept = argmax(sims) if d.state == 'trusted' else None
        return detections

    def unknown_near(self, pose, k=8):
        if not self.reg.fresh(self.T_fresh):
            return True                     # 新鲜度破坏 ⇒ 保守视作未知
        return any(l.state == 'unknown' for l in self.reg.k_nearest(pose, k))

    def trust_ok(self, ctx):
        return (ctx.sup_nu_epi <= self.tau_epi
                and ctx.sup_nu_sem <= self.tau_sem
                and not self.unknown_near(ctx.pose))


# IP-362 ConceptRegistry：来源/覆盖/TTL/签名，准入即留痕
class ConceptRegistry:
    def __init__(self, pcl, C_max=256, tau_cov=0.99):
        self.entries_, self.pcl, self.C_max = {}, pcl, C_max
        self.tau_cov = tau_cov

    def admit(self, concept, cov, ttl, provenance, consent, sig):
        if provenance == 'discovered':
            return 'candidate'              # 只能请求确认，不进 A_t
        if provenance == 'user' and not consent:
            return 'denied'
        if cov < self.tau_cov or len(self.entries_) >= self.C_max:
            return 'denied'
        c = concept.with_(cov=cov, ttl=ttl, prov=provenance, consent=consent, sig=sig)
        self.entries_[c.id] = c
        self.pcl.append(('concept_admit', c.id, provenance, cov, ttl))
        return 'admitted'

    def maintain(self, now):
        for cid, c in list(self.entries_.items()):
            if now > c.ttl or c.cov < self.tau_cov:
                del self.entries_[cid]        # 移出 ⇒ 视作未知，触发 Π_unk
                self.pcl.append(('concept_retire', cid, now))


# IP-364 UserProfilePrior：只收紧不放松
class UserProfilePrior:
    def __init__(self, pcl, theta0):
        self.pcl, self.theta0, self.pi = pcl, theta0, None

    def load(self, pi, now):
        if pi is None or now - pi.t_upd > T_PROF or not pi.sig_ok:
            self.pi = None                    # ⇒ π_∅，等价 v10
            return
        self.pi = pi

    def resolve_alias(self, term, A_t):
        if self.pi is None:
            return None
        hits = [a for a in self.pi.alias if a.term == term and a.consent]
        if len(hits) != 1 or hits[0].concept not in A_t:
            return None                       # 歧义/未授权/未知 ⇒ Π_unk
        return hits[0].concept

    def instantiate(self, norms):
        if self.pi is None:
            return self.theta0                # 严格等价 v10
        theta = norms.with_soft_prefs(self.pi.pref, self.pi.alias)
        theta = theta.with_caps(self.pi.cap)  # 只能降低能力
        theta = theta.with_risk(self.pi.risk) # 只能收紧裕量
        return safe_project(theta, self.theta0)

## 4. 推导

**引理 92（双因子覆盖与长尾受限——v10 最大风险的正面拆除）**
设 (A1) 对 c∈A_t，在校准集上"接纳为 c"的假接受率 ≤ ε_in，且 cov(c)≥τ_cov；(A2) 真实概念 c*∉A_t 的观测满足 ν^epi>τ_epi 或 ν^sem>τ_sem 的概率 ≥1−ε_unk（E592）；(A3) 若真实语义与最近可采纳概念不同，则多视角/预测冲突使 ν^sem>τ_sem 的概率 ≥1−ε_sem（E593）；(A4) 可采纳且双因子均低时，v10 的 β_STF 覆盖误差的概率 ≥1−ε_β（E574）。则任一涉及语义的中块危险事件 e 以概率 ≥1−(ε_in+ε_unk+ε_sem+ε_β) 满足三选一：
(i) **未知**：实体不在 A_t ⇒ Π_unk 生效 ⇒ 禁抓、距增、K=1、请求确认；其物理动作集 ⊆ v10 可行集（引理 93），故 e 不可能以不安全方式发生；
(ii) **需谨慎**：未知判定漏报但 ν^sem>τ_sem ⇒ 五检守卫之 3b 在 1 帧（20ms）内切中止点；
(iii) **可信**：双因子均低且概念可采纳 ⇒ 由 A4 与 v10 引理 87(ii)/88 同构，β_STF 覆盖误差，证书保守。
证明：(i) 由 A2 取补、Π_unk 的收缩性（引理 93）；(ii) 由 A3，守卫逐帧比较缓存嵌入，无额外延迟，沿 v10 定义 534 机制中止；(iii) 由 A4 与 v10 引理 87 的同构论证。并集界收尾。
**与 v10 的关键差别**：v10 只有 (ii)(iii)，且 (ii) 依赖单一标量 ν，长尾/未知会落入 (iii) 的乐观分支；v11 增加了 (i) 这一**受限失败分支**，把"未知漏检"从"不安全乐观"改写为"保守过度中止"。代价是活性（E594/E578），不是安全性。∎

**引理 93（Π_unk 支配、嵌套与活性代价）**
(i) **支配性**：Π_unk 的每条约束（K≤1、禁抓、d≥d_unk≥d_eth、请求确认）都只收缩动作集或加严裕量；v10 引理 82/86 的停车不变式与证书前提在收缩下单调保持 ⇒ Π_unk 下可能发生的物理行为 ⊆ v10 下可能行为。
(ii) **嵌套**：Π_unk ⊆ Π_r（Π_unk 含 Π_r 全部约束且更严），故 Π_unk∩Π_r=Π_unk；任何失效组合取交，不会相互抵消或放宽。
(iii) **活性代价**：未知误报导致过度中止的速率上界为未知误报率 ≤ τ_fp（E594）；可调 d_unk/确认流程降低代价，但"真未知不抓"不可移除；故活性与安全性的折中是单调的、可预注册的。
证明：(i) 对收缩序的单调性逐条核对；(ii) 定义直接比较；(iii) 误报率界定过度中止频率，真未知约束固定。∎

**引理 94（溯源与文本注入隔离）**
(i) 任何进入控制的 c/alias 必须满足 prov 合法、ξ 有效、cov≥τ_cov、签名可验；未满足者进入"候选未知"，不能进入 A_t。注册表变更写入哈希链 PCL，篡改被离线检出概率 ≥1−2^{−κ}。
(ii) 文本标签只经固定 φ_text 进入系统，长度 ≤L、无 URL/路径/指令语义；标签不是代码，也不拼接为谓词或工具调用。因此"标签注入"最多改变嵌入空间的匹配结果，不能直接改写控制谓词的真值。
(iii) 别名解析只作用于软字段；硬规范 φ_j 独立求值，别名无法覆盖 Π_r/Π_unk。故标签/别名层攻击被归约为嵌入空间攻击，其成功率由引理 92 的 ε_in 界定，而非任意代码执行。∎

**引理 95（画像安全投影与中性回退）**
(i) Proj_{S_safe} 幂等且逐参数单调：∀π_u，θ_u∈S_safe ⇒ 安全参数不劣于 θ₀ ⇒ 物理可行集 ⊆ v10。
(ii) π_u=π_∅ ⇒ instantiate 输出 θ₀ ⇒ 规范/阈值/词汇严格等价 v10。
(iii) 过期回退：定义权重 w(age)=clip((T_prof−age)/T_prof,0,1)，θ(w)=(1−w)θ₀+wθ_u；age≥T_prof ⇒ θ=θ₀，且 w 连续 ⇒ 无参数跳变（继承 v10 E575 平滑纪律）。
(iv) Cap 只能降低 speed/reach；RiskTol 只进入"收紧方向"的映射，故个性化永不扩张安全集。
证明：(i) 投影定义与 clamp 幂等；(ii) 代入；(iii) 连续性；(iv) 各字段的偏序方向检查。∎

**引理 96（最小化、遗忘与 DP 合并）**
(i) **用途绑定**：每字段有 consent 位图，未授权字段的控制路径不存在（读取即审计失败）。
(ii) **可验证遗忘**：原始画像以每用户密钥加密；erase 销毁密钥并写 receipt，旧密文在 T_erase 后不可恢复（密码学删除），PCL 可离线验证 receipt 链。
(iii) **DP 合并**：多机只交换 SHARED_FIELDS 的 (ε,δ)-DP 统计量；N 次合并的组合预算按 RDP/矩会计记账，偏差界随 ε 显式给出；不共享别名原文与原始交互。
(iv) **投毒有界**：画像更新需用户签名且限速 Δπ/窗口；安全参数对 π 的敏感度经 Proj 有界，故单次投毒对 θ 的影响 ≤Δπ，异常更新被 PCL 审计标记。
证明：(i)-(iv) 由用途绑定表、密钥销毁语义、DP 组合定理与投影 Lipschitz 性直接得到。∎

## 8. 本轮最大风险

**一句话**：开放词汇把安全前提从"有限类上的校准"换成"无界词表上的覆盖声明"——对抗性文本标签或嵌入空间欺骗可把未知伪装成已校准的已知概念（或把已知误判为未知而拖垮活性），而用户画像恰是注入别名/意图的高价值入口；一旦画像被投毒或陈旧，"未知"集合会被悄悄改写，证书的保守性依赖一个原则上无法穷举验证的覆盖命题。
