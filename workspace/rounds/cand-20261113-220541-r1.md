# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「自监督学习」×「自主导航」）

> 第 68 轮把「标定」从离线常数升为一等公民在线潜变量，系统第一次能问「我的测量还准吗」。但它自陈的最大风险点破了一个**结构性盲点**：判别漂移与故障只用了「时间频率」这一个维度，于是**落进标定带宽 ω_cal 的缓变故障（老化、慢泄漏、缓慢松动）会被当成漂移「标好」**——标定越强，慢故障越隐形。这不是把阈值调小能解决的；只要判别维度仍是一维（快/慢），慢故障就必然与漂移同频、不可分。
>
> 本轮两个灵感给出的是正交的第二、第三个判别维度：
> - 「自主导航」提醒我们：**可辨识性从来不是「数据够多」，而是「激励够丰富」**（持续激励，persistent excitation）。机器人的运动本身就是最便宜的激励源；R68 的「静态段自标定」只覆盖静止时可观的零偏方向，外参旋转、焦距尺度、时间同步在静止时**根本不可观**。
> - 「自监督学习」提醒我们：**自身动作与里程计是零成本标签**。给定指令与位姿，「标定正确时传感器应该读出什么」在几何上可预测；预测残差就是免费监督，而且它比 R68 的「预测世界」更干净——预测自己不受世界随机性污染。
>
> 核心命题：**把「导航」从「位移到目标」升级为「一次受安全约束的主动实验」——用主动激励把慢故障在「激励响应」维度上显形，用自身动作作零标签自监督，用信任预算把「测量不可信」翻译成更小的可行域，用计量锚点为「结构不可辨识」兜底。CALM-Nav（Calibration-Aware, active-excitation, Label-free, Multi-task Navigation）。**
>
> 一句话定位：R68 问「测量准不准」，R69 问「**我能不能动一动，把不准测出来**」——能激励时主动把不确定度买下来，不能激励时收缩可行域，绝不拿安全换信息。

## 0. 直觉与动机

**灵感 1（自主导航 → 运动是激励源；静止的机器人对漂移是「瞎」的）**
直觉：系统辨识的第一课是——**你只能辨识你的轨迹所激励的参数**。R68 的静态段自标定覆盖的是「零偏/静态外参」这类静止即可观的方向；外参旋转、焦距尺度、时间同步这些参数在静止时位于 Fisher 信息矩阵的零空间，在匀速直线运动时也只在极弱子空间里可观。R68 把标定做成了「停车检查」，但很多故障只有「开起来」才暴露。自主导航给了我们**主动设计轨迹**的自由：让机器人在安全前提下走一条「信息量最大」的路。关键不是乱动，而是把导航目标从 `min 路径长度` 改成 `min(路径长度 − β·可分离信息增益)`，且信息增益只能在安全集内兑现。导航第一次不只是「到达」，而是「**做实验**」。

**灵感 2（自监督学习 → 预测自己，比预测世界更干净）**
直觉：R68 的 WM 残差是「预测世界下一步」，混入了世界本身的随机性。更强的自监督信号是**预测自己**：给定已知的指令 / 里程计 `a_t` 与位姿 `ξ_t`，标定正确的传感器读数在几何上可预测——外参误差让跨模态残差随位姿做刚体协变，力零偏是体坐标系常量，时间同步误差是运动速度的函数。于是「运动条件下的残差预测」给出零标签监督；在 `r_t − Φ(a_t, ξ_t; c)` 中，「标定能解释的部分」是漂移，「解释不了且随激励出现」的才是故障。**自监督在这里不是多学一个任务，而是把「漂移 vs 故障」从单帧猜测变成可检验的预测误差分解**，并额外提供刚体等变、重访一致、近锚点一致三类免费约束。

**灵感 3（R68 风险的正解：频域不可分 ≠ 激励响应不可分）**
直觉：R68 靠「慢变量 vs 快变量」在频域分离漂移与故障，于是缓变故障与漂移同频，被标定吸收——这是**单一判别维度**的必然失败。但两个都「慢」的信号，在**对激励的响应方向**上可以完全不同：外参漂移在体坐标系里是常量，随位姿做刚体协变；慢泄漏 / 老化则可能随负载、温度、运动历史演化，对同样激励给出不同的雅可比方向。用 Fisher 信息矩阵把这个差异量化：只要「漂移子空间」与「故障子空间」的**激励分离角 θ ≥ θ_min**，主动激励后二者就可联合辨识，且所需机动幅度 ∝ 1/sin θ。**频域把路堵死了，激励响应把路打开了。** 这是本轮最核心的一击；而当 θ ≈ 0（故障在几何上就是一次标定偏移）时，我们说它**结构不可辨识**——任何数据与激励都救不了，只能靠外部计量锚点。

**灵感 4（合流 → CALM-Nav 七组件）**
1. **PEM Persistent Excitation Monitor**：在线算 Fisher 信息矩阵 FIM(θ)，给出每个标定/故障维度的激励覆盖与**不可观子空间** N_t；识别「激励饥饿」（长期静止、重复直线、狭窄通道）。
2. **AIE Active Information Excitation planner**：在安全集内做信息增益最优的轨迹规划（D-最优实验设计），把「去目标」「去激励」「去锚点」统一进同一导航目标；安全集为空则**不激励**。
3. **MCR Motion-Conditioned Residual SSL**：用自身动作/里程计做标签，把残差预测分解为「标定可解释」与「故障残差」；附刚体等变、重访一致、近锚点一致；只在可观子空间内更新。
4. **MA Metrology Anchor**：当分离角 ≈ 0 或激励饥饿时，导航去已知真值的计量锚点（对接站/标定板/已知力静止位）取绝对参照；锚点访问由「激励赤字」自适应调度，使导航同时是计量。
5. **TBN Trust-Budgeted Navigation**：把 U 与激励覆盖 ρ 映射为信任预算 B，收缩速度/净空/前瞻时域；硬下限：U 高或 ρ 低 → 禁止激励动作、降级/停车。
6. **EAC Excitation-Aware Certification**：在 R68 五关外增第六关「分离性保持关」——影子适配器不得把慢故障「标定掉」，也不得降低漂移/故障的激励分离度（用激励丰富的慢故障 canary 注入检验）。
7. **CALM† 继承核**：MTM/SSG/COF/CFA/CAC 全保留；COF 带宽只准向下自适应，MCR 更新投影到可辨识子空间，CFA 增加显式「未知」假设 H_unk。

**灵感 5（对症下药）**
- 对 R68「慢故障被标定吸收」：激励分离角（引理 17）+ EAC 第六关 + 锚点，三重防线；
- 对 R68「标定红线本身依赖出厂标定」：MA 把「绝对真值」从一次性出厂变成**可周期性复访的在线锚**；
- 对 R68「表征坍缩 / 伪标签自毒」：MCR 明确「激励不足则冻结 / 只更新可观子空间」（引理 19），不信没有激励的伪标签；
- 对过度放宽：TBN 把 R68 的 λ_floor 思想搬到导航——**不确定 → 更小的可行域**，信息永远不能反过来扩大安全集。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（CALM-Nav 总览）** CALM-Nav = (PEM, AIE, MCR, MA, TBN, EAC) ⊕ CALM†。三不变式升级：
(i) **信息-安全单向性**：任何信息增益都不得扩大当前信任预算下的可行域；不可观 ⇒ 收缩；
(ii) **激励只在安全集内**：AIE 的候选轨迹必须先过 TBN 硬约束，安全激励集为空则放弃激励；
(iii) **可辨识性诚实原则**：系统必须显式报告不可观子空间 N_t，不可观方向一律按「未知」处理，禁止用先验收缩伪造低不确定度。

**定义 294（联合参数与 Fisher 信息）** 令 θ = (c, f) ∈ ℝ^{d_θ}，c 为定义 278 的 12 维标定潜变量，f 为故障参数（候选故障模式集）。观测模型 o_t = h(a_t, ξ_t; θ) + n_t，n ~ 𝒩(0,R)。滑动窗累积信息矩阵与持续激励指数：
`I_t = Σ_{τ=t−T+1}^{t} J_τ^T R_τ^{−1} J_τ`，`J_τ = ∂h/∂θ`，`ρ_t = λ_min(I_t)/λ_min^req`。
窗口 T = 2 s（导航 20 Hz ⇒ 40 帧），带遗忘因子 1/T。

**定义 295（可辨识子空间与不可观子空间）** 对方向 v ∈ ℝ^{d_θ}，若 `v^T I_t v ≥ γ‖v‖²` 则可辨识。P_t 为 I_t 值域投影，N_t = I − P_t 为不可观子空间投影。θ 分解为 `P_t θ ⊕ (I−P_t)θ`：**只有 P_t θ 允许被在线更新**，正交补方向冻结并计入 TBN 的不确定性预算；`n_unk = rank(N_t)`。

**定义 296（运动条件残差模型）** `h = h_geo + h_sync + h_zero`：
- `h_geo(a,ξ;c) = R(δR_ext)·g^tac(ξ) − g^vis(ξ)`：外参误差下的刚体协变预测；
- `h_sync = v(ξ)·Δt_sync`：速度对时间同步误差的响应；
- `h_zero = b_F + G_load·a`：力零偏 + 负载相关项（G_load 为已知灵敏度）。
「标定可解释残差」= 落在 `span{∂h/∂c}` 的残差；「故障残差」= 其正交补投影。

**定义 297（漂移-故障激励分离角与条件信息）** 令 `A_c = ∂h/∂c`、`A_f = ∂h/∂f`。分离角 `θ_cf = arcsin(σ_min(Π_{A_c}^⊥ A_f)/‖A_f‖)`，其中 `Π_{A_c}^⊥` 为到 A_c 列空间正交补的投影。消去 δc 后故障的条件信息 `I_{f|c} = A_f^T R^{−1} Π_{A_c}^⊥ A_f = ‖A_f‖² sin²θ_cf / σ²`。θ_cf ≥ θ_min ⇒ 激励后联合可辨识；θ_cf ≈ 0 ⇒ **结构不可辨识**，只能靠 MA。

**定义 298（信息增益与安全激励集）** 对候选动作序列 A_{t:t+H}，高斯 D-最优近似的信息增益
`IG(A) ≈ ½[log det(I_t + I(A)) − log det(I_t)]`（≈ I(θ; z_{t:t+H} | A)）。
安全激励集 `S_exc(B_t) = {A : Risk(A|B_t) ≤ ε_safe ∧ IG_sep(A) ≥ ig_min}`，其中 IG_sep 只计分离方向（A_f 正交补分量）上的信息。AIE 解
`A* = argmax_{A∈S_exc} [IG_sep(A) − β·Cost(A)]`；S_exc = ∅ ⇒ 进入降级（定义 310）。

**定义 299（运动条件自监督损失族）**
`L_mcr = λ_geo‖Π⊥(r − h(a,ξ;ĉ))‖² + λ_eq‖r(ξ∘T) − T·r(ξ)‖² + λ_rev‖r(visit₁) − r(visit₂)‖² + λ_anchor‖r − r_anchor‖² + λ_pred‖r_{t+1} − h(a_t,ξ_t;ĉ)‖² + λ_var·VICReg(z)`。
全部零人工标签：a_t / ξ_t 来自指令与里程计，T 为已知刚体变换。Π⊥ 表示剔除标定可解释分量。

**定义 300（信任预算与导航包络）** `B_t = clip(1 − κ_U·Ũ + κ_ρ·ρ̃ − κ_n·1[n_unk>0], B_min, 1)`，其中 Ũ = U/τ_cal、ρ̃ = min(ρ,1)。包络：`v_max = v0·B`、`d_min = d0 + c_d(1−B)`、`H = H0·B`、`allow_exc = 1[ρ<ρ_req ∧ S_exc≠∅ ∧ B≥B_exc]`。硬规则：`U > τ_cal ∨ ρ < ρ_min ⇒ B ≤ 0.4、禁激励、请求人工或靠边停车`。

**定义 301（激励感知归因 CFA†）** `P(H,E | r,face,ĉ,U,P,N) ∝ p(r | H,ĉ,P)·p(face | E,ĉ)·P(H)·P(E|H)`。对落在 N_t 的故障方向，似然设为**平坦**（不提供证据），并新增显式假设 `H_unk`（「存在当前实验无法排除的故障」）；`P(H_unk)` 高 ⇒ λ 抬升。CFA 的输入从「标定后残差」升级为「标定后 + 激励可解释后的残差」。

**定义 302（EAC 六关）** R68 五关 + 第六关**分离性保持关**：在激励丰富 canary 集 D_sep（含慢速 ramp 故障注入）上，提交后 `σ_ratio = θ̂_cf^{(new)}/θ̂_cf^{(old)} ≥ 0.98`，且 ramp 故障检出延迟增加 ≤ 10%。任一不满足即一票否决。

**定义 303（计量锚 MA）** 锚点集 𝒜 = {a_1..a_K}，每个锚点给出绝对参照 z_abs（几何标定板 / 对接 / 已知力静止位）。锚点残差 `r_abs = z − z_abs` 直接观测 θ 的绝对分量。调度：当激励赤字 `∫(ρ_req − ρ)dt > D_anchor` 或 `n_unk > 0` 持续超过 T_unk，AIE 把最近锚点加入目标集。锚点刷新给出**外部可溯源**的 θ 真值，打破「标定红线依赖出厂标定」的悖论。

**定义 304（AIC-NAV 干扰集）** `ℰ_NAV = ℰ_CALM × ℰ_exc × ℰ_nav`；`ℰ_exc = {激励饥饿陷阱、激励诱导危险、错误激励归因、伪标签自毒}`；`ℰ_nav = {感知退化下碰撞、锚点被遮挡/欺骗、信任预算振荡、锚点被对手污染}`。

**定义 305（J_NAV 证书）** `J_NAV = (J_CALM, FIM_hash, ρ_t, N_t, excitation_log, anchor_age, trust_budget_trace, eac_verdict)`。`Valid ⇔ Valid(J_CALM) ∧ (ρ ≥ ρ_min ∨ anchor_age < τ_anchor) ∧ EAC = PASS ∧ 全程 Risk ≤ ε_safe`。

**定义 306（激励-安全对偶与激励饥饿）** 对给定环境 ℰ 与信任预算 B，记可安全激励集 S_exc(B)。若 `S_exc(B) = ∅ ∧ N_t ≠ ∅`，称环境**激励饥饿**。此时**不存在**同时满足「全参数可辨识」与「碰撞概率 ≤ ε」的策略——必须在「盲目但安全」与「可辨识但冒险」之间选，CALM-Nav 强制选前者并降级。

**定义 307（导航即实验 / 导航即计量）** 导航目标 `J_nav = J_task + β·IG_sep − γ·Risk + 1[anchor_needed]·J_anchor`，使「去目标」「去激励」「去锚点」成为同一优化问题的三种模式，由 (B_t, ρ_t, n_unk) 切换。

**定义 308（激励诱导风险约束）** 任何激励动作的额外风险满足 `ΔRisk_exc ≤ ε_exc·(1−B)²`（信任越低，允许的激励越少），且激励动作不得进入 d_min 包络或关节/速度硬限。

**定义 309（自监督投影更新与冻结规则）** MCR 的梯度更新强制投影到可辨识子空间：`Δθ = −η·P_t·J^T e`。若 `ρ < ρ_freeze`，只允许更新 P_t 方向并冻结 N_t 方向；若 `n_unk > 0` 且无新鲜锚点，则完全冻结参数更新。目的：阻断「标定越偏 → 伪标签越偏 → 越标定越偏」的正反馈。

**定义 310（激励饥饿降级协议）** `S_exc = ∅` 或 `ρ < ρ_min` 且无新鲜锚点：`B ← B_min`、`v_max ← v_safe`、禁激励，导航退化为「保守到达最近安全点或锚点」，CFA 由 H_unk 主导，`λ → 1`（最大保守），J_NAV 记为 **Degraded**（非 Valid）。

## 2. 关键算法骨架

```python
# IP-253 PEM：持续激励监控（Fisher 信息 + 不可观子空间）
class PersistentExcitationMonitor:
    def __init__(self, d_theta=18, T=40, gamma=1e-3):
        self.I = np.zeros((d_theta, d_theta)); self.T, self.gamma = T, gamma

    def update(self, h_fn, a, xi, r, R, theta_hat):
        J = numeric_jacobian(lambda th: h_fn(a, xi, th), theta_hat)  # ∂h/∂θ
        self.I = (1 - 1/self.T) * self.I + J.T @ np.linalg.inv(R) @ J
        w, V = np.linalg.eigh(self.I)
        excited = w >= self.gamma
        self.P = V[:, excited] @ V[:, excited].T          # 可辨识投影 P_t
        self.N = np.eye(len(w)) - self.P                   # 不可观子空间
        return float(w.min()), self.P, self.N


# IP-254 AIE：信息增益最优的安全激励规划
class ActiveInformationExcitation:
    def __init__(self, N=256, H=8, beta=1.0, ig_min=0.05):
        self.N, self.H, self.beta, self.ig_min = N, H, beta, ig_min

    def plan(self, x0, goal, B, pem, tbn):
        best, best_score = None, -1e9
        for A in self.sample_sequences(x0, goal, self.N, self.H):  # MPPI/栅格
            if not tbn.safe(A, B):                 # 硬安全约束先过滤
                continue
            I_new = pem.predict_fim(A)             # 沿候选轨迹预测 FIM
            ig_sep = 0.5 * (logdet(pem.I + I_new) - logdet(pem.I))
            score = self.beta * ig_sep - self.cost(A)
            if score > best_score:
                best, best_score = A, score
        if best is None or best_score < self.ig_min:
            return None                            # S_exc = ∅ → 降级
        return best


# IP-255/309 MCR：运动条件残差自监督（子空间投影，防自毒）
class MotionConditionedResidualSSL:
    def train_step(self, batch, pem):
        e = batch.r - self.h(batch.a, batch.xi, self.theta_hat)
        e_perp = e - self.jac_c(batch) @ np.linalg.pinv(self.jac_c(batch)) @ e
        grad = pem.P @ self.jac_theta(batch).T @ e_perp   # 只更新可观方向
        self.opt.step(grad)
        return self.mcr_loss(e, batch, pem)               # 定义 299


# IP-257 TBN：信任预算 → 导航包络
class TrustBudgetedNavigation:
    def envelope(self, U, rho, n_unk, s_exc_nonempty):
        B = np.clip(1 - K_U*(U/TAU_CAL) + K_R*min(rho, 1) - K_N*(n_unk > 0),
                    self.B_min, 1.0)
        allow_exc = (rho < self.rho_req) and (B >= self.B_exc) and s_exc_nonempty
        if U > TAU_CAL or rho < self.rho_min:
            B = min(B, 0.4); allow_exc = False; self.request_human()
        return B, dict(v_max=self.v0*B, d_min=self.d0 + self.c_d*(1-B),
                       H=int(self.H0*B), allow_exc=allow_exc)


# IP-264 主闭环：CALM-Nav round（继承 CALM-RAS，加激励/导航/锚点）
def CALM_Nav_round(M, obs):
    # 1) 继承 CALM-RAS：一次前向、残差、标定滤波
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    r = residuals(M.x_prime, o, M.wm_residual_cache)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))

    # 2) 激励监控：FIM / 不可观子空间
    rho, P, N = M.pem.update(M.h, M.a_prev, M.xi, r, M.R, M.theta_hat)

    # 3) 信任预算 → 导航包络（不确定只收紧，绝不放宽）
    B, env = M.tbn.envelope(U, rho, M.pem.null_dim, M.s_exc_nonempty)

    # 4) 导航规划：任务 + 激励 + 锚点（导航即实验 / 导航即计量）
    A = M.aie.plan(M.x, M.goal, B, M.pem, M.tbn) if env['allow_exc'] else None
    if A is None and (M.pem.null_dim > 0 or M.anchor_deficit > D_anchor):
        A = M.aie.plan_to_anchor(M.x, M.nearest_anchor(), B)   # 去锚点取真值
    if A is None:
        A = M.aie.plan_goal(M.x, M.goal, B)                    # 纯保守到达
    M.base_controller.track(A, env)                            # 20Hz 导航子环

    # 5) CFA†：不可观方向 → H_unk，条件于激励
    joint = M.cfa_exc(r, o, c, U, P, N)
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
              1.0 if M.pem.null_dim > 0 else 0.6)               # 只收紧

    # 6) EAC 六关 + 激励日志/锚点年龄入证书
    M.eac.maybe_commit(M.shadow, dt=M.dt, sep_canary=M.d_sep)
    M.j_nav.update(FIM_hash=M.pem.hash, rho=rho, N=N, B=B,
                   anchor_age=M.anchor_age, verdict=M.eac.last)
    return A, lam, joint, (c, U, rho)
```

## 3. 推导

**引理 16（持续激励 ⇒ 可辨识界；无激励的 U 是伪自信）** 对线性参数化 `o = Φθ + n`，`I_T = Σ Φ^T R^{−1} Φ`。Cramér-Rao 给出 `Cov(θ̂) ⪰ I_T^{−1}`；若 `v ∈ N(I_T)`，则 `Var(v^Tθ̂) = ∞`。**系**：R68 的 EKF 协方差在没有激励时也会因先验与时间更新而变小，但 `I_T` 仍秩亏——此时 `U(ĉ)` 是「对错误参数很自信」，必须用 `U_eff = max(U, f(I_T))` 纠正，且不可观方向不得更新。

**引理 17（激励响应分离界——R68 风险的结构性修复）** 两参数残差 `r = A_c δc + A_f δf + n`。消去 δc 后 `I_{f|c} = ‖Π_{A_c}^⊥ A_f‖²_{R^{−1}} = ‖A_f‖² sin²θ_cf / σ²`，故 `Var(δ̂_f) ≥ σ²/(‖A_f‖² sin²θ_cf)`。令激励幅度为 s（`A_f ∝ s`），则分离信噪比
`SNR_sep = s·‖ā_f‖·sin θ_cf / σ`。
于是：θ_cf ≥ θ_min 时，存在最小机动幅度 `s_min = z_α·σ/(‖ā_f‖·sin θ_cf)` 使慢故障可检出；**θ_cf = 0 ⇒ I_{f|c} = 0，任何激励都不可分，必须靠 MA 的绝对参照**。

**引理 18（信任预算的安全单调性）** 导航包络 (v_max, d_min, H) 对 B 单调：B 越高，速度上限越高、净空越小、前瞻越长。碰撞/近失概率满足 `P(collision | B) ≤ g(B)` 且 g 单调递减；而 `∂B/∂U ≤ 0`、`∂B/∂ρ ≥ 0`、`∂B/∂n_unk ≤ 0`。**系**：不确定度或不可观维度上升 ⇒ B 下降 ⇒ 可行域只会变小；信息增益只能在使用同一 B 的安全集内兑现，不能反向扩大 B。

**引理 19（无激励不更新 ⇒ 阻断伪标签自毒）** 设伪标签误差 `e = r − h(ĉ) ≈ J(θ* − ĉ)`。全参数梯度步 `Δĉ ∝ −J^T e ≈ −I_T(ĉ − θ*)`：在可观方向收敛，但在 `v ∈ N(I_T)` 上 `J v = 0`，梯度对 `v` 分量的偏差完全不提供纠错，且伪标签的偏置项在该方向无约束地累积。投影更新 `Δθ = −η P_t J^T e` 使 N_t 分量严格不变，从而误差不会在不可观方向发散；当 `n_unk > 0` 且无锚点时完全冻结，避免「标定越偏 → 标签越偏」的正反馈。

**定理 16（CALM-Nav 端到端风险一致性）** 在 A87–A94 与 A96（激励模型）下，输出 τ_cmd 满足：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + α_exc`，其中 `α_exc = P(θ 落在 N_t)` 由引理 16 控制；
2. `n_unk > 0 ∨ U > τ_cal ⇒ λ ≥ 1（或 ≥0.8）∧ 可行域收缩 ∧ 禁激励`——不可辨识永远导向保守，绝不导向放行；
3. 慢故障可检出条件：`s ≥ s_min(θ_cf)`（引理 17）；θ_cf = 0 时通过 MA 锚点把绝对分量重新可观，`anchor_age < τ_anchor` 期间 `α_exc` 有界；
4. 激励饥饿（S_exc = ∅）时进入定义 310 降级：`λ = 1`、J_NAV = Degraded，**不以安全换可辨识性**。

**定理 17（激励-安全不可兼得 / 对偶）** 若 `S_exc(B) = ∅` 且 `N_t ≠ ∅`，则不存在策略同时保证「全参数可辨识」与「碰撞概率 ≤ ε」：任何使 `I_T` 满秩的动作序列必不在安全集内，违反 `Risk ≤ ε_safe`。CALM-Nav 的裁决是强制选择安全并显式声明 Degraded——这是一个**可证明的取舍**，而非工程妥协。

**定理 18（EAC 保持慢故障可检出性）** 若影子适配器通过第六关，则 `θ̂_cf^{(new)} ≥ 0.98·θ̂_cf^{(old)}` 且 ramp 故障检出延迟增幅 ≤ 10%；结合引理 17，慢故障的分离 SNR 不降。故 CAC 认证不会通过「把慢故障标定掉」来换取表面的一致性，直接封堵 R68 的 canary 盲点。

## 6. 本轮最大风险

**次级风险与缓解**：
1. **激励诱导危险**：AIE 为信息增益做机动 → 必须以 TBN 硬约束先过滤，`ΔRisk_exc ≤ ε_exc(1−B)²`，E298 对抗测试；
2. **伪标签自毒**：无激励方向更新会发散 → 投影更新 + 冻结规则 + 锚点解冻（引理 19）；
3. **信任预算振荡**：B 随 U/ρ 快速跳变 → 迟滞带 + 最小驻留时间 + 速率限制；
4. **锚点被污染/遮挡**：绝对参照变成攻击面 → 多锚点交叉校验 + 锚点残差进入 AIC-NAV 干扰集；
5. **结构不可辨识的残余**：θ_cf≈0 的故障无法靠数据分离 → 只能靠 MA 与外部计量溯源，必须在证书中显式标记而非假装解决。

**【本轮最大风险 · 一句话】**：CALM-Nav 把「为了看清而运动」与「为了安全而运动」塞进同一个优化器，而这两者在信任最低时恰好最对立——一个只会最大化 Fisher 信息的策略会被环境或对手诱导去做高风险的激励机动，一个禁止激励的策略又会在激励饥饿环境里永久对缓变故障失明；真正的失败模式不是某一类故障漏检，而是系统在「盲目但安全」与「可辨识但冒险」之间反复横跳，并用自监督伪标签把一次错误的激励归因固化成「越来越准」的假象。

**定义 299（MCR 损失族）** 标定可解释残差剔除项的几何预测 + 刚体等变 + 重访一致 + 近锚点一致 + WM 预测 + VICReg；全部零人工标签（动作/里程计为标签）。

**定义 300（信任预算）** `B = clip(1 − κ_U·Ũ + κ_ρ·ρ̃ − κ_n·1[n_unk>0], B_min, 1)`；`v_max=v0·B`、`d_min=d0+c_d(1−B)`、`H=H0·B`；`U>τ_cal ∨ ρ<ρ_min ⇒ B≤0.4、禁激励、请求人工`。

**定义 301–302（CFA† / EAC 六关）** CFA† 对 N_t 方向似然平坦化并启用 H_unk；EAC 第六关在 D_sep（ramp 慢故障 canary）上要求 σ_ratio ≥ 0.98 且检出延迟增幅 ≤ 10%，否则一票否决。

**定义 303–305（MA / AIC-NAV / J_NAV）** 锚点提供绝对参照并按激励赤字调度；`ℰ_NAV = ℰ_CALM × ℰ_exc × ℰ_nav`；J_NAV Valid ⇔ J_CALM 有效 ∧ (ρ≥ρ_min ∨ anchor_age<τ_anchor) ∧ EAC=PASS ∧ Risk≤ε_safe。

**定义 306–308（对偶 / 导航即实验 / 激励风险约束）** 激励饥饿时「可辨识」与「安全」不可兼得，强制选安全并降级；`J_nav = J_task + β·IG_sep − γ·Risk + 1[anchor]·J_anchor`；`ΔRisk_exc ≤ ε_exc(1−B)²`。

**定义 309–310（投影更新 / 降级协议）** `Δθ = −η P_t J^T e`，ρ<ρ_freeze 只更新 P_t，n_unk>0 且无新锚点则冻结；激励饥饿时 B←B_min、禁激励、H_unk 主导、λ→1、J_NAV=Degraded。

# IP-253 PEM：Fisher 信息 + 不可观子空间
class PersistentExcitationMonitor:
    def update(self, h_fn, a, xi, r, R, theta_hat):
        J = numeric_jacobian(lambda th: h_fn(a, xi, th), theta_hat)
        self.I = (1 - 1/self.T) * self.I + J.T @ np.linalg.inv(R) @ J
        w, V = np.linalg.eigh(self.I)
        excited = w >= self.gamma
        self.P = V[:, excited] @ V[:, excited].T          # 可辨识投影
        self.N = np.eye(len(w)) - self.P                   # 不可观子空间
        return float(w.min()), self.P, self.N

# IP-254 AIE：安全集内信息增益最优
class ActiveInformationExcitation:
    def plan(self, x0, goal, B, pem, tbn):
        best, best_score = None, -1e9
        for A in self.sample_sequences(x0, goal, self.N, self.H):
            if not tbn.safe(A, B): continue
            I_new = pem.predict_fim(A)
            ig_sep = 0.5*(logdet(pem.I + I_new) - logdet(pem.I))
            score = self.beta*ig_sep - self.cost(A)
            if score > best_score: best, best_score = A, score
        return best if best_score >= self.ig_min else None   # None ⇒ 降级

# IP-255/309 MCR：运动条件残差自监督 + 投影更新
class MotionConditionedResidualSSL:
    def train_step(self, batch, pem):
        e = batch.r - self.h(batch.a, batch.xi, self.theta_hat)
        e_perp = e - self.jac_c(batch) @ np.linalg.pinv(self.jac_c(batch)) @ e
        self.opt.step(pem.P @ self.jac_theta(batch).T @ e_perp)  # 只更新可观方向
        return self.mcr_loss(e, batch, pem)

# IP-257 TBN：信任预算包络（不确定只收紧）
class TrustBudgetedNavigation:
    def envelope(self, U, rho, n_unk, s_exc_nonempty):
        B = np.clip(1 - K_U*(U/TAU_CAL) + K_R*min(rho,1) - K_N*(n_unk>0),
                    self.B_min, 1.0)
        allow = (rho < self.rho_req) and (B >= self.B_exc) and s_exc_nonempty
        if U > TAU_CAL or rho < self.rho_min:
            B, allow = min(B, 0.4), False; self.request_human()
        return B, dict(v_max=self.v0*B, d_min=self.d0+self.c_d*(1-B),
                       H=int(self.H0*B), allow_exc=allow)

# IP-264 主闭环：CALM-Nav round
def CALM_Nav_round(M, obs):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)   # CALM† 一次前向
    r = residuals(M.x_prime, o, M.wm_residual_cache)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))       # COF†
    rho, P, N = M.pem.update(M.h, M.a_prev, M.xi, r, M.R, M.theta_hat)
    B, env = M.tbn.envelope(U, rho, M.pem.null_dim, M.s_exc_nonempty)
    A = M.aie.plan(M.x, M.goal, B, M.pem, M.tbn) if env['allow_exc'] else None
    if A is None and (M.pem.null_dim > 0 or M.anchor_deficit > D_anchor):
        A = M.aie.plan_to_anchor(M.x, M.nearest_anchor(), B) # 导航即计量
    if A is None:
        A = M.aie.plan_goal(M.x, M.goal, B)                   # 保守到达
    M.base_controller.track(A, env)
    joint = M.cfa_exc(r, o, c, U, P, N)                       # CFA†：H_unk
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
              1.0 if M.pem.null_dim > 0 else 0.6)
    M.eac.maybe_commit(M.shadow, dt=M.dt, sep_canary=M.d_sep) # EAC 六关
    M.j_nav.update(FIM_hash=M.pem.hash, rho=rho, N=N, B=B,
                   anchor_age=M.anchor_age, verdict=M.eac.last)
    return A, lam, joint, (c, U, rho)

## 4. 推导

**引理 16（持续激励 ⇒ 可辨识界）** `Cov(θ̂) ⪰ I_T^{−1}`；若 `v ∈ N(I_T)` 则 `Var(v^Tθ̂)=∞`。**系**：无激励时 EKF 的 Σ 仍会因时间更新缩小，但 `I_T` 秩亏——R68 的 `U(ĉ)` 是伪自信，必须用 `U_eff` 纠正且冻结不可观方向。

**引理 17（激励响应分离界）** `r = A_c δc + A_f δf + n`；消去 δc 后 `I_{f|c} = ‖A_f‖² sin²θ_cf/σ²`，故 `Var(δ̂_f) ≥ σ²/(‖A_f‖² sin²θ_cf)`。激励幅度 s 下 `SNR_sep = s·‖ā_f‖·sinθ_cf/σ`，最小机动幅度 `s_min = z_α·σ/(‖ā_f‖·sinθ_cf)`；**θ_cf=0 ⇒ 结构不可辨识，任何激励无效，只能靠 MA**。这直接修复 R68「慢故障被标定吸收」：频域同频不再致命，激励响应可分即可。

**引理 18（信任预算安全单调性）** v_max、d_min、H 对 B 单调；碰撞/近失 `P(collision|B) ≤ g(B)` 且 g 递减；`∂B/∂U ≤ 0`、`∂B/∂ρ ≥ 0`、`∂B/∂n_unk ≤ 0`。**系**：不确定度或不可观维度上升 ⇒ 可行域只会变小；信息增益不得反向扩大 B。

**引理 19（无激励不更新 ⇒ 阻断伪标签自毒）** `e ≈ J(θ*−ĉ)`，全参数更新在 `v∈N(I_T)` 上 `Jv=0`，偏差无纠错地累积；投影更新 `Δθ = −η P_t J^T e` 使 N_t 分量严格不变。故 ρ<ρ_freeze 时只更新 P_t，n_unk>0 且无锚点时完全冻结。

**定理 16（端到端风险一致性）** `P(|τ_cmd−τ*|>ε) ≤ Σ(α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal) + α_exc`，`α_exc = P(θ∈N_t)`；`n_unk>0 ∨ U>τ_cal ⇒ λ 抬升 ∧ 可行域收缩 ∧ 禁激励`；慢故障可检出需 `s ≥ s_min(θ_cf)`，θ_cf=0 时由 MA 重新可观；激励饥饿进入定义 310 降级，**不以安全换可辨识性**。

**定理 17（激励-安全不可兼得）** `S_exc(B)=∅ ∧ N_t≠∅` 时，任何使 I_T 满秩的动作必不在安全集内，违反 Risk≤ε_safe；故「全参数可辨识」与「安全」不可兼得，CALM-Nav 强制选安全并显式 Degraded——可证明的取舍而非工程妥协。

**定理 18（EAC 保持慢故障可检出性）** 第六关通过 ⇒ `θ̂_cf^{(new)} ≥ 0.98·θ̂_cf^{(old)}` 且 ramp 检出延迟增幅 ≤ 10%；结合引理 17，慢故障分离 SNR 不降，封堵 R68 的 canary 盲点。

## 7. 本轮最大风险

**次级风险与缓解**：激励诱导危险（TBN 硬约束 + `ΔRisk_exc ≤ ε_exc(1−B)²` + E298）；伪标签自毒（投影更新 + 冻结 + 锚点解冻，引理 19）；信任预算振荡（迟滞带 + 最小驻留 + 速率限制）；锚点被污染/遮挡（多锚点交叉校验 + 入 AIC-NAV）；结构不可辨识残余（θ_cf≈0 只能靠 MA 与外部计量溯源，必须在证书中显式标记而非假装解决）。

**【本轮最大风险 · 一句话】**：CALM-Nav 把「为了看清而运动」与「为了安全而运动」塞进同一个优化器，而这两者在信任最低时恰好最对立——一个只会最大化 Fisher 信息的策略会被环境或对手诱导去做高风险的激励机动，一个禁止激励的策略又会在激励饥饿环境里永久对缓变故障失明；真正的失败模式不是某一类故障漏检，而是系统在「盲目但安全」与「可辨识但冒险」之间反复横跳，并用自监督伪标签把一次错误的激励归因固化成「越来越准」的假象。
