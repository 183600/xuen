# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；本轮灵感：「激光雷达」×「流匹配策略」）

> R69 把不确定性一分为二，并让系统学会「问」。但它的 epistemic 仍然是**离散、语义、且依赖被怀疑对象**的：U_epi 由模态熵 H_mode 计算，而模态权重正是 R69 自陈的最大风险——若权重未校准，VoI 就在错误信念上计算，系统会自信地追问一个幻影。更根本的是，R69 把「不知道」理解成「该选哪个模态」，却忽略了机器人最常见的不知道是**空间性**的：这块地方我到底看没看过？没看到，是因为它不存在，还是因为它被挡住了？
>
> 本轮两个灵感补上这一维：
> - **激光雷达**是天然**主动**且有**几何测量模型**的传感器：每一束光都是一次可计算的 time-of-flight / ray-casting 询问；命中 = 有面，无返回 = 自由 / 透射 / 超量程的**三义歧义**；自由空间沿射线被「雕刻」出来。它把 R69 的 epistemic 从「哪个模态」扩展成一张**占据 / 覆盖 / 遮挡场**，并给出一个**解析的、不依赖学习模态权重的 VoI**——恰好是 R69 最需要的第二意见。
> - **流匹配策略**从「生成动作块」升级为「生成连续的扫描 / 观察轨迹」：把光束指向看成一条滑顺的轨迹 (pan,tilt,t)，用同一个速度场联合生成「看哪里 + 做什么」，让「看」成为可认证、可审计、受 slew-rate 约束的连续动作。
>
> 核心命题：**epistemic 有两种几何——可扫的（未覆盖）与需移动才能解的（被遮挡）；前者靠原地扫、后者靠位移 / 询问；用解析几何 VoI 与学习模态 VoI 做双通道仲裁，两者不一致就退回 R69；只有材料歧义（玻璃 / 镜面 / 雨雾）击穿传感器模型时，才一路退化 R69 → R68。** 命名 **BEAM-RAS**（Beam-Evidence Active Mapping with Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67「未来怎样」，R68「我的测量还准吗」，R69「我该向谁求证、还能问什么」，R70 问「**我看向了哪里、哪里还没看见、没看见是因为没有还是因为挡着**」——不确定性不只是一句提问，也是一束光的方向。

## 0. 直觉与动机

**灵感 1（激光雷达 → 「未知」有空间结构）**
直觉：人进黑屋先扫一圈，不是因为「犹豫选哪个动作」，而是因为「有一片地方没被光照到」。LiDAR 把这种「没照到」变成可计算对象：沿射线做 free-space carving，命中点前为自由、命中点为占据、超过量程或被遮挡为未知；累计每条体素被多少束光穿过，就得到覆盖率 c(x) 与占据熵 u(x)。R69 的 U_epi 是一个数，这里它是一张图。关键区分：**未覆盖（un-swept）** 与 **遮挡（occluded）** 是两种不同的可约性——前者原地转头即可，后者必须移动或询问。

**灵感 2（解析 VoI → 一条不信任模态权重的第二意见）**
直觉：R69 的 VoI 用 H(M|o) 算，而 M 的权重正是它最不可信的部分。LiDAR 的测量模型是解析的：给定候选光束路径 G 与当前占据信念 b，期望信息增益 AVOI(G) 可由 ray-casting 传感器模型 Monte Carlo 估计，完全绕过学习到的模态分布。于是有了两条**近正交**的 VoI：学习模态 VoI（语义歧义）与解析几何 VoI（空间覆盖）。二者都高才交互；只有一条高则说明其中一条渠道可疑，退保守。这是 R69 用 FMA 给标定做第二意见的同一招，只是换到「该看哪」上。

**灵感 3（流匹配 → 「看」是一条连续轨迹）**
直觉：R69 的信息动作 g 是注视方向 / 探针 / 问句的瞬时量；但真实扫描是连续轨迹，受平台角速度、slew-rate、曝光 / 驻留约束。把光束轨迹 ξ_beam=(pan,tilt,t) 当作流匹配的生成对象 x_1，条件在占据场 ô 与认知场 E(x) 上，同一个 v_θ 就同时生成任务动作与观察轨迹——「边扫边做」成为一条联合轨迹。多峰性也保留：可能「先扫左再前进」或「先退后扫右」；聚类后仍走 AUD/VoI，只是模态现在是轨迹。

**灵感 4（材料歧义 → 光会撒谎）**
直觉：LiDAR 最深的脆弱不是噪声，而是**透射与镜面**：玻璃让光束穿过，系统把「墙后空」当真；镜面把光束折走，系统得到幽灵点；雨雾 / 高反让强度失真。R69 的「无返回」在 LiDAR 里是三义的：真空、透明、超量程。若把「没返回」当「空」，主动扫描会**高效地把无知采集成了虚假的确定**。因此本轮必须引入材料感知的返回模型与「无返回不作自由证据」的纪律，否则覆盖越多越自信地错。

**灵感 5（确认偏误 → 主动感知会放大自己的偏见）**
直觉：主动感知不是中立的：它按当前信念挑最「值钱」的视角，于是会反复去看它相信有东西的地方、绕过它以为空的地方。若信念已被投毒或漂移，主动扫描会把错误**系统性采样成证据**——比被动观测更危险。所以 BEAM-RAS 必须带**反确认偏误**机制：强制探索项（novelty / coverage floor）、几何覆盖的可审计下限、以及「无返回不得单独证空」的证据纪律。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（BEAM-RAS 总览）** BEAM-RAS = (GEM, BFT, AVOI, VOA, NBV, BEA, MIR, ASC, RAS-WM‡)。继承 FLUID 全部不变式，另加三条：
(i) **几何证据纪律**：无返回 / 单束命中不得单独判定自由或占据，需至少两种独立证据（几何 + 另一模态，或双向重扫）；
(ii) **主动感知安全**：扫描轨迹过 ASC 认证（slew / 位姿 / 眼安全 / 社交包络）；
(iii) **降级单调**：解析 VoI 不可用、材料歧义高、或双 VoI 冲突 ⇒ 依次退回 FLUID（R69）→ R68，安全侧 λ 单调不降。

**定义 311（占据场与射线雕刻）** 占据场 o: ℝ³→[0,1]。传感器位姿 p_t，光束方向 d（由 (pan,tilt) 给出），量程 [ρ_min, ρ_max]。返回 z=(ρ, ι, n_echo)。对射线 r(p,d)：
- 命中 ρ<ρ_max：对 s∈[ρ_min, ρ−ε] 记自由证据，s≈ρ 记占据证据，s>ρ 记被遮挡未知；
- 无返回：s∈[ρ_min, ρ_max] 只记**低占据置信**，**不得记自由**（材料歧义，定义 319）。
占据信念 b(x) 由证据对数几率累加，输出均值 ô(x) 与熵 u(x)=H(b(x))。

**定义 312（几何认知场 GEM）** 认知场 E(x)=u(x)·κ(x)，κ(x)∈[0,1] 为可见 / 可达因子。按可约性分解：
- E_sweep(x)：视线未被遮挡、仅因未扫而未知 ⇒ 原地扫可降；
- E_occl(x)：视线被已知表面遮挡 ⇒ 需移动 / 询问才可降。
总几何 epistemic：U_geo=∫E(x)dx；可扫比 r_sweep=∫E_sweep / ∫E。

**定义 313（流匹配光束轨迹 BFT）** 光束轨迹 ξ_beam={(pan_i,tilt_i,t_i)}_{i=1..B} 或连续方向轨迹 d(t)∈S²；x_1=ξ_beam，条件 c_t=(z_t, ô(·), E(·))。速度场 v_φ(x_s,s|c_t) 用流匹配训练。采样 K 条轨迹，约束 slew(ξ_beam) ≤ ω_max 与眼安全 / 位姿包络；轨迹聚类得扫描模态 {m_k^beam}。

**定义 314（解析 VoI，AVOI）** 候选光束路径 G（一组射线 / 轨迹）在传感器模型 p(z|o,G) 下的期望信息增益
AVOI(G)=E_{z~p(·|o,G)}[H(o|b)−H(o|b,G,z)]，
用 ray-casting 前向模型 + 对 b 的体素 Monte Carlo 估计。**AVOI 不使用学习模态权重**，因而与 R69 的 VoI 近正交，作为第二意见。

**定义 315（双 VoI 仲裁 VOA）** 学习 VoI(g)（R69 定义 298，语义歧义）与解析 AVOI(G)（空间覆盖）。规则：
- 两者均超阈 ⇒ interaction_permit=go；
- 仅一条超阈 ⇒ **conflict**，不交互，λ 走 R69 保守；
- 均不超 ⇒ idle，不交互。

**定义 316（Next-Best-View 流规划 NBV）** 在 BFT 的 K 条轨迹上选 G*=argmax_G[AVOI(G)−c_scan(G)]，s.t. ASC 认证、slew 约束、扫描预算 B_max，且含强制探索项 ε_novel（定义 321）。G* 与任务动作模态联合重排序：预期观测会改变模态后验时，优先执行能判别模态的扫描。

**定义 317（光束预算路由 BAR）** 单位时间光束 / 扫描次数预算硬约束；按「单位光束 AVOI 边际增益」分配：先扫 E_sweep 高、且对模态判别力大的区域；为长期未覆盖区保留 ε_novel 配额，防止饿死。

**定义 318（光束回波异常 BEA）** 每条射线残差 b_res(ρ,ι)=观测回波与「其他模态 / WM 预测表面」的几何-强度不一致度。判别模式：
- 预测有面、无返回 ⇒ 疑似透明 / 吸收；
- 预测自由、有回波 ⇒ 疑似幽灵 / 镜面 / 多径；
- 强度-距离关系偏离标定 ⇒ 疑似雨雾 / 高反 / 污损。
b_score=p95(b_res)。三通道对偶：(r_res 标定残差, Δa 流似然, b_score 光束回波)。

**定义 319（材料感知返回模型 MIR）** 为每条射线赋材料后验 m∈{opaque, transparent, specular, diffuse, scattering}；返回模型 p(z|o,m)。透明 / 镜面时「无返回 / 异常回波」不更新占据；材料后验高熵 ⇒ 标 material_ambiguous，其 E(x) 不得当自由，且禁止单独证空（定义 310-i）。

**定义 320（主动感知安全 ASC）** 扫描轨迹需满足：角速度 / slew ≤ ω_max、平台位姿不越安全包络、眼安全等级（人邻近区降功率 / 避直视）、社交打扰 ≤ c_max。任一不过 ⇒ 该扫描作废，退回「不扫」或 R69 的保守注视。ASC 复用 C-RAS-WM 前缀认证，但作用在光束轨迹的前缀上。

**定义 321（反确认偏误 ACB）** 选视角分 = AVOI−c+β·novelty(x)+ε_novel·1[长期未覆盖]；对「无返回证空」施加证据纪律与双向重扫（从两个视角看同一点）。审计统计「被高置信判空、后被证占」的比例，即 false_free_rate。

**定义 322（三路几何证书 J_BEAM）** J_BEAM=(J_FLUID, geo_coverage, r_sweep, AVOI_ratio, BEA_p95, material_ambiguous_ratio, false_free_rate, beam_log_hash, beam_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖与遮挡可审计 ∧ material_ambiguous_ratio ≤ τ_mat ∧ false_free_rate ≤ τ_ff。

**定义 323（三级降级链）** 正常：双 VoI 一致 ⇒ 交互 / 扫描 + resolution bonus；冲突或材料歧义高 ⇒ 退回 FLUID（不扫、只做 R69 动作）；FLUID 亦不可信（ECE 越界 / slow_fault / BEA 异常且无法归因）⇒ 退回 R68 纯保守。安全侧 λ 单调不降，效率侧逐级放弃 bonus。

**定义 324（时空耦合与扫描前瞻）** LiDAR 周期较长（~100ms），扫描规划与 2.6ms 控制环解耦：控制环仍用 R69 的 K=1/2.6ms；扫描规划在 LiDAR 节拍上异步运行（前瞻 1–2 帧），以「已批准的未来观察」喂给下一次决策。

**定义 325（第三意见的独立性边界）** AVOI 与 BEA 虽不依赖学习权重，但与 R69 共享传感器输入；若材料 / 环境同时对几何与回波撒谎（镜面 + 高反 + 透明组合），两通道可同时失效。故定义独立域 𝒟_ind：仅当第二模态（视觉深度 / 触觉 / 人类回答）与几何通道一致时，才把它计入正交证据。

```python
# IP-264 GEM：占据 / 覆盖 / 遮挡场（LiDAR 帧节拍上更新）
class GeometricEpistemicMap:
    def update(self, pose, scan):                     # scan: [(pan,tilt,rho,intensity,n_echo)]
        for ray in scan:
            material = self.mir.infer(ray)            # 定义 319
            if ray.hit:
                self.b.carve_free(pose, ray.dir, ray.rho)   # 命中前自由
                self.b.mark_occupied(pose, ray.dir, ray.rho, w=material.opaque_p)
            elif material.ambiguous:
                self.b.weak_unknown(pose, ray.dir)    # 无返回 ≠ 自由
            else:
                self.b.weak_unknown(pose, ray.dir)
            self.coverage.add(pose, ray.dir, ray.rho)
        self.E_sweep, self.E_occl = self.decompose_E()  # 定义 312
        return self.b, self.E_sweep, self.E_occl

# IP-265 BFT：流匹配生成连续扫描 / 观察轨迹
class BeamFlowPolicy:
    def sample(self, o_t, z_t, K=4, N_step=2):
        cond = (z_t, self.gem.occupancy_mean(), self.gem.epistemic_field())
        xs = randn(K, D_beam)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, cond)
        return [self.project_slew(x) for x in xs]     # 投影到 slew/位姿可行集

# IP-266 AVOI：解析几何期望信息增益（不信任模态权重）
def analytic_voi(gem, beam_path, n_mc=64):
    H0 = gem.occupancy_entropy()
    gains = []
    for _ in range(n_mc):
        z = gem.sensor_model.sample(gem.b, beam_path)   # ray casting 前向
        b2 = gem.b.clone().carve(z)
        gains.append(H0 - b2.entropy())
    return mean(gains)

# IP-267 VOA：双 VoI 仲裁
def arbitrate(voi_learned, voi_analytic, tau):
    a, b = voi_learned > tau, voi_analytic > tau
    if a and b:  return 'go'
    if a != b:   return 'conflict'        # 一条渠道可疑 → 走 R69 保守
    return 'idle'

# IP-268 NBV：在流采样轨迹上做 next-best-view
def next_best_view(beam_modes, gem, budget):
    best = None
    for G in beam_modes:
        if not budget.allow(G) or not asc.certify_beam(G): continue
        score = analytic_voi(gem, G) - scan_cost(G) \
                + BETA * novelty(G, gem) + EPS_NOVEL * long_uncovered(G, gem)
        if best is None or score > best.score: best = (G, score)
    return best if best and best.score > 0 else None

# IP-270 BEA + IP-271 MIR：回波异常与材料歧义
def beam_echo_anomaly(scan, wm_pred, other_depth):
    res = []
    for ray in scan:
        pred = wm_pred.surface_along(ray) or other_depth.along(ray)
        if pred is None: continue
        res.append(residual(ray.rho, ray.intensity, pred))
    return p95(res), material_ambiguous_ratio(scan)

# IP-275 主闭环：R69 FLUID + 几何层（扫描异步、控制同步）
def BEAM_RAS_round(M, obs, scan):
    # ---- LiDAR 节拍（异步）----
    b, Es, Eo = M.gem.update(M.pose, scan)
    K = 1 if M.aud.mode_head(M.z) < TAU_MODE else 4
    beam_modes = M.bft.sample(M.o, M.z, K)
    G = M.nbv.next_best_view(beam_modes, M.gem, M.budget)
    avoi = M.avoi.analytic_voi(M.gem, G) if G else 0.0
    b_score, mat_amb = M.bea.beam_echo_anomaly(scan, M.wm.pred, M.other_depth)
    # ---- 控制环（同步，继承 R69/FLUID）----
    U_ale, U_epi, modes = M.fluid.decompose(M.fluid.sample(M.o))
    voi_learned = M.fluid.voi(modes) if M.mcg.ok else 0.0
    permit = M.voa.arbitrate(voi_learned, avoi, TAU_VOI)
    if mat_amb > TAU_MAT or b_score > TAU_BEA:
        permit = 'conflict'                    # 材料歧义可同时污染两通道
    g = (M.fluid.choose_interaction(modes, M.o, M.budget)
         if permit == 'go' else None)
    if g is not None:
        U_epi = M.fluid.cia.update_belief(modes, M.fluid.cia.execute(g))
        M.bft.commit(G)                        # 已认证的扫描轨迹下发执行
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.fluid.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if permit == 'conflict':                   # 定义 323：退回 FLUID/R68
        lam = max(lam, M.fluid.conservative_lam())
    mode = M.fluid.select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_b.submit_async(G, permit, U_epi, avoi, b_score, mat_amb)
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（几何 epistemic 的可约性分解）** 设认知场 E(x)=u(x)κ(x)。原地扫描最多只能消去「视线未被遮挡」的 E_sweep 质量；被已知表面遮挡的 E_occl 质量只能通过改变位姿（位移 / 探针 / 绕行）或外部回答来降低。故「扫一扫」与「走过去看」是在攻击两个不相交的未知集合；R69 把它们合并成一个标量 U_epi，因而无法决定该转头还是该迈步。系：AVOI 中应把 E_sweep 与 E_occl 分开计价，NBV 才能区分「原地扫」与「移动」。

**引理 20（AVOI 对模态权重的独立性）** 在 A99（传感器模型经标定、材料不歧义）下，AVOI(G) 仅是占据信念 b 与光束路径 G 的函数，不含学习到的模态权重 w。故当 w 被投毒而 b 仍干净时，学习 VoI 失效但 AVOI 仍有效；且 AVOI 关于「预期新雕刻的自由 / 占据证据量」单调，上界为 H(o|b)−E[H_min]。注意边界：AVOI 与 b 共享传感器输入，若输入本身被材料谎言污染，两通道可同时失效（定义 325）——独立性只对「权重投毒」成立，不对「传感器欺骗」成立。

**引理 21（双 VoI 仲裁的投毒上界）** 设学习 VoI 因权重投毒而误报的概率为 δ_L，解析 VoI 因材料歧义而误报的概率为 δ_A。若两失效事件近独立（不一致性成立时），要求双通道同时超阈才交互，则虚假交互率 ≤ δ_L·δ_A+ε_σ。系：VOA 把两个弱检查合成一个强检查；但当材料/环境同时欺骗几何与回波（相关失效），δ_L、δ_A 同升，上界退化——此时必须靠第二模态（视觉深度 / 触觉 / 人类回答）进入 𝒟_ind 才能恢复独立性。

**引理 22（无返回的三义性下界）** 在材料不可辨时，一条无返回射线的似然在 {自由, 透明, 超量程} 三假设下近似相同，其对「自由」的证据量有上界 O(material_prior)；故单视角由无返回判自由，其 false-free 概率 ≥ f(material_prior)。这直接给出定义 310-i 与 321 的必要性：无返回不得单独证空，须双向重扫或第二模态。

**定理 18（BEAM 严格包含 FLUID 包含 R68）** 在 A99–A100 下，令探索项 β=ε_novel=0 且 AVOI 不可用或双 VoI 冲突，则 BEAM 逐步退化为 FLUID，且当 VoI(g*)≤c、ECE>τ_ece 或 slow_fault_suspect 时进一步与 R68 逐指令相同。正常态下 BEAM 仅在「两通道一致且安全认证通过」时获得覆盖 / 消歧 bonus；安全侧 λ 沿三级降级链单调不降，故期望风险 ≤ R69 ≤ R68 的安全界。

**定理 19（主动感知安全与无突变）** 经 ASC 认证的扫描轨迹其物理 / 眼安全 / 社交风险 ≤ ε_beam；主动感知只改变「观测什么 / 选哪个模态」，不扩大控制权限；扫描失败 / 超时 / 材料歧义 / 冲突时 λ 单调不降地退回 R69 → R68；C-RAS-WM 前缀认证与提交 / 换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：BEAM-RAS 的核心卖点是「用几何解析 VoI 给学习模态 VoI 做一条近正交的第二意见」，但这两条通道**共享同一组光子**——当世界对光撒谎（玻璃透射、镜面反射、雨雾散射、对抗性回反射），几何与回波会**同时**被欺骗；更糟的是主动感知会按错误信念去覆盖它「以为空」的地方，把「没看见」系统性地采集为「空」，于是**看错比不看更危险：覆盖得越多，越自信地错**。

**次级风险与缓解**：
1. **无返回被当自由** → 定义 310-i 证据纪律 + 引理 22 + 双向重扫 + false_free 审计；
2. **材料相关失效击穿双通道独立性** → MIR 材料后验 + 𝒟_ind 第二模态门槛（定义 319、325）；
3. **确认偏误放大** → ACB 探索项 / coverage floor + 覆盖与遮挡可审计（定义 321–322）；
4. **扫描本身不安全或不礼貌** → ASC 前缀认证（slew / 眼安全 / 社交）+ 定理 19 无突变；
5. **异步规划的时空错配**（规划用的地图已过期）→ 前瞻 1–2 帧 + 扫描承诺的可用性校验 + 定义 323 降级。

```python
    def update(self, pose, scan):
        for ray in scan:
            material = self.mir.infer(ray)

                self.b.mark_occupied(pose, ray.dir, ray.rho, w=material.opaque_p)

    lam = max(M.fluid.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if permit == 'conflict': lam = max(lam, M.fluid.conservative_lam())
    mode = M.fluid.select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_b.submit_async(G, permit, U_epi, avoi, b_score, mat_amb)
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（几何 epistemic 的可约性分解）** E(x)=u(x)κ(x)。原地扫描最多消去 E_sweep；E_occl 需改位姿或外部回答。二者是不相交未知集合；R69 合并为标量 U_epi，无法决定「转头」还是「迈步」。系：AVOI 须分别计价 E_sweep 与 E_occl，NBV 才能区分扫 / 走。

**引理 20（AVOI 对模态权重的独立性）** A99（模型标定、材料不歧义）下 AVOI(G) 仅是 b 与 G 的函数，不含学习权重 w；当 w 被投毒而 b 干净时学习 VoI 失效、AVOI 仍有效。AVOI 关于预期新雕刻证据量单调，上界 H(o|b)−E[H_min]。边界：AVOI 与 b 共享传感器输入，传感器被材料谎言污染时两通道可同失效（定义 325）。

**引理 21（双 VoI 仲裁的投毒上界）** 学习 / 解析通道误报概率 δ_L、δ_A 近独立时，双超阈才交互的虚假交互率 ≤ δ_L·δ_A+ε_σ。系：VOA 把两个弱检查合成一个强检查；材料 / 环境相关欺骗使 δ 同升，须 𝒟_ind 第二模态恢复正交。

**引理 22（无返回的三义性下界）** 材料不可辨时，无返回射线对 {自由, 透明, 超量程} 三假设似然近同，对「自由」的证据有上界 O(material_prior)；单视角由无返回判自由的 false-free 概率 ≥ f(material_prior)。⇒ 无返回不得单独证空，须双向重扫或第二模态。

**定理 18（BEAM ⊃ FLUID ⊃ R68）** A99–A100 下，令 β=ε_novel=0 且 AVOI 不可用或双 VoI 冲突，则 BEAM 逐步退化为 FLUID；再满足 R69 退化条件时与 R68 逐指令相同。正常态仅在双通道一致且认证通过时获 bonus；安全侧 λ 沿三级链单调不降，期望风险 ≤ R69 ≤ R68 安全界。

**定理 19（主动感知安全与无突变）** ASC 认证后扫描物理 / 眼安全 / 社交风险 ≤ ε_beam；主动感知只改「观测什么 / 选哪个模态」，不扩控制权限；失败 / 超时 / 材料歧义 / 冲突时 λ 单调不降退回 R69→R68；C-RAS-WM 前缀与提交 / 换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：BEAM-RAS 押在「用几何解析 VoI 给学习模态 VoI 做近正交第二意见」上，但两条通道**共享同一组光子**——玻璃透射、镜面反射、雨雾散射、对抗性回反射会让几何与回波**同时**被欺骗；而主动感知又会按错误信念去覆盖它「以为空」的地方，把「没看见」系统性采集为「空」——**看错比不看更危险：覆盖越多，越自信地错**。

**次级风险与缓解**：无返回被当自由（定义 310-i + 引理 22 + 双向重扫 + false_free 审计）；材料相关失效击穿独立性（MIR 材料后验 + 𝒟_ind 第二模态门槛）；确认偏误放大（ACB 探索项 / coverage floor + 可审计覆盖）；扫描不安全不礼貌（ASC 前缀认证 + 定理 19）；异步规划时空错配（前瞻 1–2 帧 + 承诺可用性校验 + 三级降级）。
