# 第 72 轮（承接第 71 轮「GAUGE-RAS 计量审计层」IP-275~286；灵感循环第 1 轮；本轮灵感：「多机评测」×「碰撞检测」）

> R71 把单机的「不确定性读数」升级为有构造效度、有不确定度预算、有反指标对偶、有密封审计的测量系统。但它有一个从未被检验的前提：**审计是单机的、证据源彼此独立**。当 RAS 从一台机器人变成一个舰队，这个前提同时从两个方向崩塌。
>
> **多机评测（many-body evaluation）**说：一个机器人的成功率不是它自己的属性，而是它与同伴策略的**联合属性**。固定同伴测出的排行榜，换一组同伴可能整体反转；「K 个独立证据源」在同一张地图、同一个时钟、同一套检测器下其实只算**一次观测**。评价本身是一个有干扰、有共池、会被被试者反作用的多体实验——R71 的 SEAL 与反 Goodhart 对偶默认 SUTVA 与独立性，而这两条在多机部署中被系统性违反。
>
> **碰撞检测（collision detection）**说：安全谓词不是对称指标，而是**单侧证明**。漏检一次是灾难，误报一次只是低效；离散时间的检测器可以「隧穿」过薄障碍——这是任何校准（ECE）都抓不到的结构性假阴性。更关键的是：**两两无碰撞不等于舰队无碰撞**；共享地图/时钟/定位误差让所有机器人的碰撞事件相关，R71 的「乘性独立界」会把相关的风险乘成零。
>
> 两个灵感合起来给出一条新命题：**审计的单位不是「某个指标」，而是「产生所有指标的那块共享基底」；评测的单位不是「某台机器」，而是「整队列 + 同伴分布 + 评测协议」。** 命名 **COHORT-RAS**（Cohort-conditional, One-sided, Hereditary-substrate, Open-ledger, Reflexive, Traceable）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我该信哪个状态」，R71 问「尺子可信吗、测量是否改变了被测者」，R72 问「**当很多把尺子共用同一个刻度、很多台机器共用同一个世界时，它们的一致究竟是共识，还是同一个错误被数了很多遍**」。

## 0. 直觉与动机

**灵感 1（多机评测 → 排名是「多体问题」，单机排行榜不可识别）**
直觉：单机 benchmark 隐含一个假设——「这台机器的水平」是一个只属于它的数。可在一群机器人里，我的成功率取决于队友让不让路、对手抢不抢道、通信堵不堵。把同伴固定住测出一个分数，就像在只有一个对手的棋谱上给棋手排名。换一组同伴，名次可以整体翻转（协作型策略在协作队列里更强、在对抗队列里更弱）。这不是噪声，是**干扰（interference）**。跨学科对应：临床试验的 SUTVA（每个受试者的结果不依赖他人的处置）、网络实验的 peer effects、生态学的频率依赖选择、社会科学里的 Simpson 悖论。**结论：没有声明「同伴分布」的排行榜不是一个估计量，只是一个点观测。**

**灵感 2（SUTVA 失效 → 干扰是结构性的，不能当作方差）**
直觉：如果干扰只是随机噪声，多测几次取平均就能消掉。但干扰是**策略对策略**的：同伴会学习、会适应、会对「正在被评测」做出反应。于是评测环境本身是内生的。R71 的 SEAL 靠「在线不可见」来密封测试集；在多机里，测试场景由其他智能体的策略生成，**隐藏集通过交互泄漏**。一个评测感知的同伴可以故意配合或故意使坏，让被评机器人在无人看见时和有人评测时表现不同。**SEAL 在含学习型同伴的环境里无法真正密封**，除非用预注册 + 承诺 + 未公开的同伴策略池。

**灵感 3（碰撞检测 → 安全是单侧证明，不是对称统计量）**
直觉：碰撞检测的代价极不对称。把「有碰撞」误判成「无碰撞」（假阴性）是灾难；把「无碰撞」误判成「有碰撞」（假阳性）只是多绕一段路。所以安全谓词的正确形态不是「准确率 95%」，而是「**只有在能证明分离时才说 SAFE，否则说 ABSTAIN**」。这与 R71 的 veto 精神一致，但 R71 把 veto 当成一个可校准的布尔量；碰撞检测的实际威胁是**结构性**的：10Hz 检测器面对薄墙，若一步位移超过特征厚度就会「隧穿」，这种漏检不会因为 ECE 变小而消失。**校准是给对称误差用的，安全需要覆盖性证明（保守几何 / 连续碰撞 / 可达集）。**

**灵感 4（相关失效 → n 台机器不等于 n 个独立证据）**
直觉：100 台机器人一致说「这里没障碍」，如果它们共用同一张地图和同一个定位系统，那这 100 票其实是同一票的 100 个副本。统计上，相关证据的等效独立样本量会塌缩：`n_eff = n / (1 + (n−1)ρ)`；当 ρ→1，n_eff→1。R71 的「K 个偏差近似独立的对偶提升检测功效」在舰队里要换成 K_eff = n_eff。更严重的是安全侧：若共享地图把误差相关起来，则「每台机器碰撞概率 1e-6，所以舰队 1e6 台仍安全」是**数学上错误的**。Fréchet–Hoeffding 给出真区间：舰队碰撞概率至少在 [max ε_i, min(1, Σ ε_i)] 内，乘积界可以落在区间之外。

**灵感 5（共池评测/提问 → 「多问一句」变成公地悲剧）**
直觉：R71 让每个机器人问「再问一句值不值」，并给单个信任账户设预算。但在舰队里，人类监督者的注意力、通信带宽、重规划算力都是**共享且会拥塞**的。每个机器人只享受自己提问的私人收益，却分担（或忽略）全体提问造成的公共成本 → 系统性过度提问（tragedy of the commons / 无政府状态）。**把 R71 的 B_reflex 从「每个账户一个」改成「一个共池」，最优解就必须带边际成本定价，否则个体理性的 VoI 会杀死集体信任。**

**灵感 6（严格包含 → N=1、无共享基底、检测器可证健全时退回 GAUGE）**
直觉：新层不能要求「更相信一个新模型」。当队列只有一台、没有共享基底、碰撞检测可证健全、评测协议平凡时，COHORT 必须**逐指令等于 R71 GAUGE**；再按 R71 定理 20 退化为 BELIEF/FLUID/R68。并且当共享基底图不确定时，保守做法是「把所有机器并成一组」，**只会收缩可行域，不会扩张**。

## 1. 形式化定义（增量：定义 349–362）

**定义 349（COHORT-RAS 总览与不变式）** COHORT-RAS = (CEM, ICP, RID, OCS, CCS, SDG, ESS, FCR, FVOI, ELD, J_COHORT, COHORT-PIPE, GAUGE-RAS†)。六不变式：
(i) **零在线学习写操作**（继承 R71 定义 331-i）；
(ii) **队列条件有效性**：任何比较性指标必须声明并随机化「同伴分布 Q」，未声明的点评测不得进入排行榜；
(iii) **单侧健全性**：只有可证分离时才允许输出 SAFE；无法证明即 ABSTAIN，**绝不允许用校准统计量推断「无碰撞」**；
(iv) **依赖感知风险聚合**：聚合必须尊重共享基底依赖图 G_S，未审计的独立性不得假设（继承并强化 R71 定义 334 的非补偿性）；
(v) **共池预算**：舰队共享交互/算力/人类注意力预算，须按边际成本定价（定义 359）；
(vi) **可回溯与预注册**：评测协议、同伴池、种子、分析计划在见结果前哈希承诺（定义 360）。

**定义 350（队列配置与条件估计量）** 队列配置 c = (N, π_{-i}, E, T)，含 N 台机器人、其余机器人联合策略 π_{-i}、环境 E、任务 T。机器人 i 的指标 M_i(π_i; π_{-i}) = E_{ξ~P_E}[ m(τ_i) ]，其中轨迹 τ_i 由联合策略 π=(π_i,π_{-i}) 与 E 共同决定。策略 π 在同伴分布 Q 上的**队列条件估计量**为
θ_Q(π) = E_{π_{-i}~Q}[ M(π; π_{-i}) ]。
只报告 M(π; π_{-i}^0) 对某个固定 π_{-i}^0 的值，称为**点评测**，不是队列估计量。

**定义 351（SUTVA 违反与干扰强度）** 单机评测默认 SUTVA：i 的结果与 π_{-i} 无关。舰队中一般违反。定义**干扰强度**
I(π) = sup_{Q,Q'} |θ_Q(π) − θ_{Q'}(π)|（或 Q 上 θ 的标准差）。
I>0 时，任何跨策略比较都依赖 Q。**同伴暴露随机化（peer-exposure randomization）**：每台被评机器人从声明分布 Q 中随机抽取同伴花名册，用暴露加权（Horvitz–Thompson 型）估计 θ_Q。**同伴策略池必须在评测前固定并隐藏。**

**定义 352（评测感知与泄漏）** 若评测环境包含学习型同伴，其策略可依赖对「正在评测」的观测，则泄漏量
L = I(协议; 隐藏测试 | 交互历史) > 0。
此时 SEAL 的「在线不可见」被交互通道绕过。对策：预注册协议 + 隐藏同伴池 + 承诺哈希 + 对「同伴自适应」做对抗审计（E344/E358）。**在含学习型同伴的舰队里，密封不是保密问题，而是内生性问题。**

**定义 353（单侧碰撞谓词）** 碰撞检测器 D: (state, trajectory, map) → {SAFE, COLLISION, ABSTAIN}。**健全性（soundness of SAFE）**：D 输出 SAFE ⇒ 真实无碰撞。**完备性（no false negatives）**：真实碰撞 ⇒ D 输出 COLLISION。定义
α = P(D=COLLISION | 真安全)（误报，浪费），
β = P(D=SAFE | 真碰撞)（漏报，灾难）。
安全要求本质上是 **β = 0**（或在有界数值容差下可证 β ≤ b）。**校准（ECE）只约束对称误差，无法约束未观测尾部的 β**——这是 R71 把碰撞 veto 当作「可校准布尔量」的根本错配。

**定义 354（时间参数化分离与隧穿健全条件）** 离散检测周期 Δt 下，检测器可能漏过「一步跨过薄障碍」的隧穿。定义扫掠体过近似
S(t_0,t_1) = ⋃_{t∈[t_0,t_1]} ( q(t) ⊕ B(r) )，
其中 q(t) 为位形轨迹、B(r) 为机器人半径球、⊕ 为 Minkowski 和。健全条件：
(a) 障碍 O ⊆ ⋃_k S_k 被配置空间扫掠单元保守覆盖，且留几何裕度 ε_geo；
(b) 单步最大相对位移 max_rel_disp(Δt, v_max) < ½·d_min（d_min 为环境中最小特征厚度）；
(c) 用保守推进 / 连续碰撞检测（CCD）得到的时间区间不相交。
**隧穿漏检概率满足 P(miss) ≤ 1{max_rel_disp ≥ ½ d_min}：它主要由结构条件决定，而不是统计校准。**

**定义 355（共享基底依赖图 SDG）** 二部图 G_S = (R ∪ S, E_S)，R 为机器人集合，S = {map, localization, clock, collision-detector, calibration, model-weights, training-data, power/comms, human-supervisor-attention} 为共享基底；边 (r,s)∈E_S 当且仅当 r 的决策依赖 s。两机器人的证据在给定**不相交的基底邻域**下条件独立。**依赖团（dependency clique）**：共享同一基底分量的极大机器人集合；团内风险相关，不可乘。**未建模的共同原因（隐藏耦合）是 G_S 不完备的风险，见第 6 节。**

**定义 356（有效独立样本量 ESS）** 设 n 个证据源的相关矩阵为 R（对角 1，非对角 ρ_ij），则等效独立样本量
n_eff = n² / (1ᵀ R 1) = n / (1 + (n−1) ρ̄)，
其中 ρ̄ 为平均非对角相关（Kish design effect）。等相关的极端 ρ̄→1 时 n_eff→1。**GAP/SEAL 的检测功效随 n_eff 而非 n 增长；共享基底使「K 个独立对偶」塌缩为 K_eff = n_eff。** 这是 R71 与 R72 的定量接缝。

**定义 357（舰队证书 J_COHORT）** J_COHORT = ( {J_GAUGE^i}_{i∈R}, G_S, n_eff, collision_soundness_proofs, cohort_contract, eval_ledger_hash, fleet_voi_ledger, rank_identifiability, ver )。
Valid ⇔ 每台 J_GAUGE^i 有效 ∧ 所有共享空间的两两/多体碰撞健全性成立 ∧ 按 G_S 聚合的舰队风险 ≤ ε_fleet ∧ 队列契约（Q 已声明且随机化）成立 ∧ 共池预算未超。

**定义 358（相关风险聚合与独立性红利）** 将机器人划分为独立基底组 g_1,…,g_m（组间无共享节点）。则
P(任一碰撞) ≤ Σ_{g} P(组 g 内碰撞) ≤ Σ_g ε_g（并集界）。
组内**不可乘**：由 Fréchet–Hoeffding，P(∩_{i∈g} safe_i) ≤ min_{i∈g} P(safe_i)，故
P(任一碰撞) ≥ 1 − min_i P(safe_i) = max_i ε_i。
因此真实舰队风险落在 [ max_i ε_i , min(1, Σ_i ε_i) ]；乘积界 ∏(1−ε_i) 在高相关时可落在区间**之外（过于乐观）**。若全部共享一个基底，m=1，增加机器数量**不降低**每台所需的 ε——安全必须在基底层改进，不能靠机器人冗余。定义**独立性红利** = ∏(1−ε_i) 与 Σ_g ε_g 的差；声称乘积界而无独立性证明，等同于签发一张未经验证的证书。

**定义 359（共池舰队 VoI 与拥塞定价）** 每台机器人选择查询 g_i，私人收益 B_i(g_i)，共享成本 C(Σ_i g_i) 为凸（人类注意力/带宽/算力）。社会福利 W = Σ_i B_i(g_i) − C(Σ_i g_i)。若成本被平均分摊，每个个体的边际成本被低估，产生**过度查询的纳什均衡**。边际成本定价 p = C'(Σ_i g_i) 可把纳什均衡对齐到社会最优。**R71 的 B_reflex 是每账户预算；R72 把它变成共池，必须定价。**

**定义 360（评测账本与预注册 ELD）** 只追加、哈希承诺的账本，记录：假设、队列条件指标定义、同伴分布 Q、种子、纳入/排除标准、分析计划、时间戳，且必须在见结果前写入。任何事后修改生成新版本而非静默改写。**这是多机评测的 CONSORT：没有预注册，就没有可识别的比较。**

**定义 361（排名可识别性 RID）** 对策略 π, π'，若在同伴分布类 Q 上 sign(θ_Q(π) − θ_Q(π')) 恒定，则排名在 Q 上**可识别**；否则发生**排名反转**，必须报告集合值排名或分区排名，而不是单一榜单。定义可识别性间隙
g_id = sup_{Q∈Q} θ_Q(π) − inf_{Q∈Q} θ_Q(π)。
**这是 R71「有效性域 D」在多机评测轴上的对应物：指标的有效性域不只关于状态，也关于同伴分布。**

**定义 362（退化与包含）** 当 N=1、G_S 平凡（无共享基底）、碰撞检测可证健全、队列契约平凡、C 无拥塞时，COHORT-RAS 逐指令等于 GAUGE-RAS；再按 R71 定理 20 退化为 BELIEF/FLUID/R68。**SDG 不确定时一律把所有机器并成一组（最保守），可行域只减不增。**

```python
# IP-287 CEM：队列条件评测（同伴暴露随机化 + 暴露加权）
def cohort_eval(policy, peer_dist, env, M):
    est = []
    for _ in range(M):
        roster = sample_peers(peer_dist)          # 随机同伴花名册
        est.append(rollout(policy, roster, env))  # 联合 rollout
    return mean(est), bootstrap_ci(est), spread(est)

# IP-288 RID：排名可识别性诊断（反转即拒绝单一榜单）
def rank_identifiable(theta_A, theta_B, Q_grid):
    signs = {sign(theta_A(Q) - theta_B(Q)) for Q in Q_grid}
    return ('identified' if len(signs) == 1 and 0 not in signs
            else 'NON-IDENTIFIABLE -> report set-valued ranking', signs)

# IP-289 OCS/CCS：单侧碰撞健全性（保守推进 + 隧穿守卫）
def collision_cert(robot, traj, world, dt, v_max):
    for q0, q1 in consecutive(traj):
        sweep = swept_volume(q0, q1, robot.radius)          # C-space 过近似
        if not world.covers(sweep, margin=EPS_GEO): return ABSTAIN
        if max_rel_disp(dt, v_max) >= 0.5 * world.min_feature_thickness():
            return ABSTAIN                                # 隧穿守卫：结构性
    return SAFE                                           # 仅在可证分离时

# IP-290 SDG：共享基底依赖图与独立组
def substrate_groups(robots, substrates):
    G = bipartite(robots, substrates, edges=depends_on)
    return [c.robots for c in connected_components(G)]    # 共享即同组

# IP-291 ESS：等效独立证据数
def effective_n(corr):
    n = len(corr); rho_bar = offdiag_mean(corr)
    return max(1.0, n / (1 + (n - 1) * rho_bar))          # Kish design effect

# IP-292 FCR：依赖感知的舰队证书（组间并集界，组内最坏情形）
def fleet_cert(Js, groups, eps):
    if not all(J.valid and J.collision_sound for J in Js): return FAIL
    eps_fleet = sum(max(eps[i] for i in g) for g in groups)  # 不是乘积
    return OK if eps_fleet <= EPS_FLEET else FAIL

# IP-293 FVOI：共池舰队 VoI（边际成本定价）
def fleet_query_alloc(agents, C, budget):
    g = solve_convex([a.B for a in agents], C, budget)    # 社会最优
    price = C.derivative(sum(g))                          # 拥塞价格
    return g, price                                       # 定价后纳什=社会最优

def preregister(plan):

    ledger.append(('preregister', h, now())); return h

# IP-295 COHORT 主闭环：单机高频控制 + 舰队低频审计
def COHORT_round(fleet, obs, audio):
    for r in fleet: r.J = GAUGE_RAS_round(r.M, obs[r], audio[r])   # R71 原样
    for r in fleet: r.cs = collision_cert(r, r.traj, fleet.world, DT, V_MAX)
    if eval_clock.due():                                  # 低频/异步
        fleet.theta, fleet.ci, _ = cohort_eval(fleet.policy, fleet.Q, fleet.env, M)
        fleet.rank = rank_identifiable(..., fleet.Q_grid)
    groups = substrate_groups(fleet.robots, fleet.substrates)       # 中频
    n_eff  = effective_n(correlation_of_evidence(fleet))
    J = fleet_cert([r.J for r in fleet], groups, [r.eps for r in fleet])
    g, price = fleet_query_alloc(fleet.agents, fleet.C, fleet.budget)  # 事件触发
    return J
```

## 3. 推导

**引理 28（干扰 ⇒ 排名不可识别）** 存在策略 π_A、π_B 与同伴分布 Q1、Q2，使 θ_{Q1}(π_A) > θ_{Q1}(π_B) 而 θ_{Q2}(π_A) < θ_{Q2}(π_B)。证明由构造：令协作型策略在协作队列中收益高、在对抗队列中收益低，对抗型相反（频率依赖 / 非传递竞争），取 Q1、Q2 为两端点分布即可。故**固定同伴的点评测不识别队列排名**；单一榜单在 I>0 时没有估计量意义。系：这与多中心临床试验中「疗效随中心构成反转」的 Simpson 悖论同构；RID 是 R71 有效性域在同伴轴上的推广。

**引理 29（相关证据的等效样本量塌缩）** 等相关 ρ 下，样本均值的方差 Var = (σ²/n)[1+(n−1)ρ]。令其等于 σ²/n_eff 得 n_eff = n/(1+(n−1)ρ)。ρ→1 ⇒ n_eff→1；ρ=0 ⇒ n_eff=n。由于 GAP/SEAL 的检测功效是 n_eff 的单调函数，**共享地图/时钟/检测器的舰队其「K 个独立对偶」实际只有 K_eff = n_eff 个**。系：R71 引理 23 的「K 个偏差近似独立对偶」必须把 K 替换为 n_eff；否则会高估对 gaming 的检测能力，正是 R71 最大风险在多机上的放大。

**引理 30（相关碰撞风险不可乘）** 令 A_i 为「机器人 i 安全」。Fréchet–Hoeffding 上界给出 P(∩_i A_i) ≤ min_i P(A_i)，故 P(任一碰撞) ≥ max_i P(¬A_i) = max_i ε_i；并集界给出上界 ≤ Σ_i ε_i。因此相关情形下乘积 ∏(1−ε_i) 不是合法上界，且可低于下界 max_i ε_i。**N 台共享基底的机器人不会把舰队风险降到单台以下；乘积界是「用相关性换来的假安全感」。**

**引理 31（单侧健全性不可由校准获得）** β = P(SAFE | 真碰撞) 针对稀有尾部事件。任何仅基于有限样本 M 的分布无关校准，在未见分布上对 β 的估计在 β ≪ 1/M 时不可区分于零（稀有事件不可由经验频率定界）；分布移下更失效。因此碰撞 veto 必须依赖**结构性覆盖证明**（保守几何、CCD、可达集）或对抗覆盖，而不能依赖 ECE/sharpness。系：R71 的 GAP 把「校准」当作通用反 Goodhart 工具，但**校准是对称误差的工具，安全需要单侧证明**——两者不可互换。

**引理 32（共池过度查询与定价）** 设 C(S)=½cS²、B_i(g_i)=b_i g_i−½k g_i²。社会最优满足 b_i−k g_i = C'(S)=cS；若成本平均分摊，个体只承担 C(S)/n 的份额，其一阶条件低估边际成本，得 g_i^Nash ≥ g_i*。对二次成本可证 PoA = W*/W^Nash < 1 且随 n 增大而恶化；边际成本定价 p=C'(S) 使纳什一阶条件与社会最优一致。**舰队若不给人/带宽/注意力定价，就必然过度提问，最终耗尽 R71 的信任账户。**

**定理 23（严格包含）** 在 N=1、G_S 平凡、碰撞检测可证健全、队列契约平凡、C 无拥塞且满足 R71 定理 20 的条件下，COHORT 的每条控制指令与 GAUGE 相同；又 GAUGE ⊂ BELIEF ⊂ FLUID ⊂ R68。故安全侧不弱于 R71，效率侧只在「队列可识别 + 单侧健全 + 预算可控」时获得收益。

**定理 24（依赖感知舰队安全界；对乘积界的否定）** 在定义 355/358 下，对任意独立基底组划分，P(舰队碰撞) ∈ [max_g ε_g, min(1, Σ_g ε_g)]，其中 ε_g 为组 g 的碰撞概率；组内不可乘，乘积界在正相关时落在可行区间之外。故**任何未证明独立性就乘概率的证书都是不健全的**。系：增加机器人不能把每台所需的 ε 降低；要降低 ε_fleet，必须改进共享基底（地图/时钟/检测器）或增大组间独立性。

**定理 25（随机化下的队列可识别性）** 在声明分布 Q 上做同伴暴露随机化并预注册协议，则 θ_Q(π) 有暴露加权无偏估计，方差 ∝ 1/M_eval；排名可识别性可由对 Q 的 bootstrap 检验符号稳定性判定。无随机化时干扰与策略混淆，一般不可识别。**点榜单不是队列估计量；随机化 + 预注册 + 集合值报告是可识别性的充要工程条件。**

**定理 26（舰队包含与无发散）** COHORT 在每台机器人上只做两类收缩：单侧碰撞 ABSTAIN 与共池预算约束；舰队证书是非补偿合取。故 COHORT 接受的任一动作轨迹也被其 R71 兜底接受；λ 单调不降；回退路径连续无突变（延伸 R68 定理 15、R71 定理 22）。当 G_S 不确定时并成单组只会进一步收缩。**安全侧只增不减，且对依赖图的不确定性是保守的。**

## 6. 本轮最大风险

**一句话**：COHORT-RAS 的全部安全性都押在共享基底依赖图 G_S 的**完备性**上——若存在未建模的共同原因（同一张地图、同一个时钟、同一段无线信道，甚至同一位人类监督者的注意力），却被当作独立组，并集界就会把相关的风险乘成零，舰队会用一张「各自独立」的假证书给自己发安全通行证；这正是 R71「两把尺子一起歪」在舰队尺度上的放大版，**而且这次错误的单位从「一台机器」变成了「整支舰队」。**

**次级风险与缓解**：
1. **G_S 不完备（隐藏共同原因）** → 默认并成单组（最保守）+ 独立性的可证伪审计（E343/E349）+ 显式列出基底清单；无法证明独立即按相关处理。
2. **碰撞单侧证明的数值/覆盖漏洞** → 保守几何 + CCD + 隧穿结构守卫 + ABSTAIN；绝不用校准统计量替代证明（引理 31）。
3. **队列评测不可识别却假装可识别** → 强制预注册 + 同伴随机化 + 集合值排名 + RID 门控（定义 361、定理 25）。
4. **共池定价机制被规避/不公平** → 边际成本定价 + 硬预算 + 审计账本；定价失败即退回每机器人 R71 预算。
5. **过度保守导致任务失败** → 只在安全侧收缩；性能层保留排序；E347/E351 量化代价。
6. **实时预算被舰队审计击穿** → 三频分离：控制/碰撞高频、SDG/ESS 中频、CEM/ELD 低频异步；审计永不进控制快路径（E356）。

# 第 72 轮产物 · 创新点清单 v2：COHORT-RAS（Cohort-conditional, One-sided, Hereditary-substrate, Open-ledger, Reflexive, Traceable：队列条件评测 × 单侧碰撞健全 × 共享基底审计 × 共池定价 × 预注册账本；CEM×ICP×RID×OCS×CCS×SDG×ESS×FCR×FVOI×ELD×GAUGE-RAS†）

> 本轮两位一体补齐：
> - **多机评测（CEM/ICP/RID/ELD）**：把「排行榜」升级为「声明同伴分布 Q 的队列条件估计量」，用同伴暴露随机化识别干扰，用预注册账本封住分析路径，用可识别性诊断拒绝不可识别的单一榜单。对应 SUTVA/interference、多中心试验的 Simpson 悖论、网络实验的 peer effects。

>
> 核心命题：**审计的单位从「指标」上移到「共享基底」，评测的单位从「机器」上移到「队列 + 同伴分布 + 协议」。** 所有新能力只在「队列可识别 + 单侧健全 + 依赖图已审计」时启用，否则逐指令退化为 GAUGE → BELIEF → FLUID → R68。

## 2. 形式化定义（要点版）

**定义 349（总览与六不变式）** 继承 GAUGE 全部组件（† 升级），新增队列评测层（CEM/ICP/RID/ELD）、单侧碰撞层（OCS/CCS）与共享基底层（SDG/ESS/FCR/FVOI）。六不变式：(i) 零在线学习写操作；(ii) 队列条件有效性（比较必须声明并随机化 Q）；(iii) 单侧健全性（无证明即 ABSTAIN，不得用校准推断无碰撞）；(iv) 依赖感知聚合（未审计独立性不得假设）；(v) 共池预算定价；(vi) 预注册与可回溯。

**定义 350（队列配置与条件估计量）** c=(N,π_{-i},E,T)；M_i(π_i;π_{-i})=E_{ξ~P_E}[m(τ_i)]；θ_Q(π)=E_{π_{-i}~Q}[M(π;π_{-i})]。固定 π_{-i}^0 的单值称为点评测，**不是估计量**。

**定义 351（SUTVA 违反与干扰）** 单机评测默认结果与 π_{-i} 无关；舰队中 I(π)=sup_Q θ_Q − inf_Q θ_Q >0。同伴暴露随机化：每台从声明 Q 抽同伴，暴露加权估计 θ_Q；同伴池预注册并隐藏。

**定义 352（评测感知与泄漏）** 学习型同伴使 L=I(协议;隐藏测试|交互历史)>0，SEAL 被交互通道绕过。对策：预注册 + 隐藏同伴池 + 哈希承诺 + 对抗审计。**这是内生性问题，不是保密问题。**

**定义 353（单侧碰撞谓词）** D→{SAFE,COLLISION,ABSTAIN}；健全性指 SAFE⇒真无碰撞；α=P(COLLISION|真安全)，β=P(SAFE|真碰撞)。安全要求 β=0（或有界容差）。**校准只约束对称误差，无法约束尾部 β。**

**定义 354（时间参数化分离与隧穿条件）** S(t0,t1)=⋃_t(q(t)⊕B(r))；健全条件：(a) 障碍被扫掠单元保守覆盖且留 ε_geo；(b) max_rel_disp(Δt,v_max)<½d_min；(c) CCD 时间区间不相交。P(miss)≤1{max_rel_disp≥½d_min}：**结构决定，不是统计决定。**

**定义 355（SDG）** 二部图 G_S=(R∪S,E_S)，S={map, localization, clock, detector, calibration, model, data, comms, human-attention,…}；边=依赖。给定不相交基底邻域时条件独立；依赖团内相关，不可乘。**G_S 不完备=隐藏共同原因=本轮最大风险。**

**定义 356（ESS）** n_eff=n²/(1ᵀR1)=n/(1+(n−1)ρ̄)；ρ̄→1 时 n_eff→1。GAP/SEAL 检测功效随 n_eff，R71 的 K 个独立对偶须换成 K_eff=n_eff。

**定义 357（J_COHORT）** 见符号表；Valid ⇔ 每台 J_GAUGE^i 有效 ∧ 共享空间碰撞健全性成立 ∧ 按 G_S 聚合 ε_fleet≤ε_fleet^max ∧ 队列契约成立 ∧ 共池预算未超。

**定义 358（相关风险聚合）** 独立基底组 g_1..g_m 时 P(任一碰撞)≤Σ_g ε_g（并集界）；组内 P(∩safe)≤min safe ⇒ P(任一碰撞)≥max ε_i（Fréchet）。真区间 [max_i ε_i, min(1,Σ_i ε_i)]；乘积界 ∏(1−ε_i) 可落在区间外。**全共享时 m=1，加机器不降每条所需 ε。**

**定义 359（共池 VoI 与拥塞定价）** W=ΣB_i(g_i)−C(Σg_i)，C 凸。平均分摊→纳什过度查询；边际成本 p=C'(Σg) 对齐社会最优。**R71 的 B_reflex 从每账户预算升级为共池。**

**定义 360（ELD 预注册）** 只追加、哈希承诺账本，记录假设/指标/Q/种子/纳入排除/分析计划，见结果前写入；事后修改记为新版本。**多机评测的 CONSORT。**

**定义 361（RID）** sign(θ_Q(π)−θ_Q(π')) 在 Q 类上恒定才可识别；否则排名反转，须报集合值/分区排名。g_id=sup_Q θ_Q−inf_Q θ_Q。**R71 有效性域 D 在同伴轴上的推广。**

**定义 362（退化与包含）** N=1、G_S 平凡、检测器可证健全、契约平凡、无拥塞 ⇒ 逐指令等于 GAUGE；再按 R71 定理 20 退化。SDG 不确定时并成单组（最保守），可行域只减不增。

## 3. 关键算法伪代码

```python
# IP-287 CEM：队列条件评测（同伴暴露随机化 + 暴露加权）
def cohort_eval(policy, peer_dist, env, M):
    est = []
    for _ in range(M):
        roster = sample_peers(peer_dist)
        est.append(rollout(policy, roster, env))
    return mean(est), bootstrap_ci(est), spread(est)

# IP-288 RID：排名可识别性诊断
def rank_identifiable(theta_A, theta_B, Q_grid):
    signs = {sign(theta_A(Q) - theta_B(Q)) for Q in Q_grid}
    return ('identified' if len(signs) == 1 and 0 not in signs
            else 'NON-IDENTIFIABLE -> set-valued ranking', signs)

# IP-289/290/291 OCS+CCS：单侧碰撞健全性
def collision_cert(robot, traj, world, dt, v_max):
    for q0, q1 in consecutive(traj):
        sweep = swept_volume(q0, q1, robot.radius)
        if not world.covers(sweep, margin=EPS_GEO): return ABSTAIN
        if max_rel_disp(dt, v_max) >= 0.5 * world.min_feature_thickness():
            return ABSTAIN                         # 隧穿守卫：结构性
    return SAFE                                    # 仅在可证分离时

# IP-292 SDG：共享基底依赖组
def substrate_groups(robots, substrates):
    G = bipartite(robots, substrates, edges=depends_on)
    return [c.robots for c in connected_components(G)]

# IP-293 ESS：等效独立证据数
def effective_n(corr):
    n = len(corr); rho_bar = offdiag_mean(corr)
    return max(1.0, n / (1 + (n - 1) * rho_bar))

# IP-294 FCR：依赖感知舰队证书（组间并集界，组内最坏）
def fleet_cert(Js, groups, eps):
    if not all(J.valid and J.collision_sound for J in Js): return FAIL
    eps_fleet = sum(max(eps[i] for i in g) for g in groups)   # 不是乘积
    return OK if eps_fleet <= EPS_FLEET else FAIL

# IP-295 FVOI：共池舰队 VoI（边际成本定价）
def fleet_query_alloc(agents, C, budget):
    g = solve_convex([a.B for a in agents], C, budget)        # 社会最优
    price = C.derivative(sum(g))
    return g, price                                           # 定价后纳什=社会最优

# IP-296 ELD：预注册账本
def preregister(plan):
    h = hash_canonical(plan)
    ledger.append(('preregister', h, now())); return h

# IP-298 COHORT 主闭环
def COHORT_round(fleet, obs, audio):
    for r in fleet: r.J = GAUGE_RAS_round(r.M, obs[r], audio[r])      # R71 原样
    for r in fleet: r.cs = collision_cert(r, r.traj, fleet.world, DT, V_MAX)
    if eval_clock.due():                                               # 低频/异步
        fleet.theta, fleet.ci, _ = cohort_eval(fleet.policy, fleet.Q, fleet.env, M)
        fleet.rank = rank_identifiable(..., fleet.Q_grid)
    groups = substrate_groups(fleet.robots, fleet.substrates)          # 中频
    n_eff  = effective_n(correlation_of_evidence(fleet))
    J = fleet_cert([r.J for r in fleet], groups, [r.eps for r in fleet])
    g, price = fleet_query_alloc(fleet.agents, fleet.C, fleet.budget)  # 事件触发
    return J
```

## 4. 推导

**引理 28（干扰 ⇒ 排名不可识别）** 存在 π_A,π_B 与 Q1,Q2 使 θ_{Q1}(A)>θ_{Q1}(B) 而 θ_{Q2}(A)<θ_{Q2}(B)（协作型/对抗型的频率依赖、非传递竞争）。故固定同伴的点评测不识别队列排名，单一榜单在 I>0 时无估计量意义。**与多中心试验 Simpson 悖论、生态频率依赖选择同构；RID 是 R71 有效性域的同伴轴推广。**

**引理 29（相关证据塌缩）** 等相关 ρ 下 Var(mean)=(σ²/n)[1+(n−1)ρ]，令等于 σ²/n_eff 得 n_eff=n/(1+(n−1)ρ)。ρ→1 ⇒ n_eff→1。GAP/SEAL 功效随 n_eff，故舰队「K 个独立对偶」实际 K_eff=n_eff。**R71 引理 23 必须把 K 换成 n_eff，否则高估抗 gaming 能力。**

**引理 30（相关碰撞不可乘）** A_i=「i 安全」；Fréchet 上界 P(∩A_i)≤min P(A_i) ⇒ P(任一碰撞)≥max ε_i；并集界 ⇒ ≤Σ ε_i。乘积 ∏(1−ε_i) 非合法上界。**N 台共享基底不把风险降到单台以下；乘积界是用相关性换来的假安全感。**

**引理 31（单侧健全不可由校准获得）** β 针对稀有尾部；有限样本 M 的分布无关校准在 β≪1/M 时不可与零区分，分布移下更失效。故碰撞 veto 须依赖结构性覆盖（保守几何/CCD/可达集）或对抗覆盖，不能依赖 ECE/sharpness。**校准是对称误差工具，安全是单侧证明，二者不可互换。**

**引理 32（共池过度查询与定价）** C=½cS²、B_i=b_i g_i−½k g_i² 时，社会最优 b_i−k g_i=cS；平均分摊使个体低估边际成本 ⇒ g_i^Nash≥g_i*，二次成本下 PoA<1 且随 n 恶化；p=C'(S) 使纳什一阶条件与社会最优一致。**不给人/带宽/注意力定价，必然过度提问并耗尽 R71 信任账户。**

**定理 23（严格包含）** N=1、G_S 平凡、检测器可证健全、契约平凡、无拥塞且满足 R71 定理 20 时，COHORT 每条控制指令等于 GAUGE；又 GAUGE⊂BELIEF⊂FLUID⊂R68。**安全侧不弱于 R71。**

**定理 24（依赖感知舰队安全界；否定乘积界）** 定义 355/358 下，任意独立基底组划分，P(舰队碰撞)∈[max_g ε_g, min(1,Σ_g ε_g)]；组内不可乘，乘积界在正相关时落在可行区间外。故**未证独立性就乘概率的证书不健全**。系：增加机器人不降低每台所需 ε；须改进共享基底或增大组间独立。

**定理 25（随机化下可识别性）** 声明 Q 上做同伴暴露随机化并预注册，则 θ_Q(π) 有暴露加权无偏估计，方差 ∝1/M_eval；排名可识别性由对 Q 的 bootstrap 符号稳定性检验。无随机化时干扰与策略混淆，一般不可识别。**点榜单不是队列估计量。**

**定理 26（舰队包含与无发散）** COHORT 每台只做两类收缩：单侧碰撞 ABSTAIN 与共池预算；舰队证书为非补偿合取。故 COHORT 接受的动作也被 R71 兜底接受；λ 单调不降，回退连续（延伸 R68 定理 15、R71 定理 22）。G_S 不确定时并成单组只会进一步收缩。**安全侧只增不减，且对依赖图不确定性保守。**

## 7. 本轮最大风险

**一句话**：COHORT-RAS 的全部安全性都押在共享基底依赖图 G_S 的**完备性**上——若存在未建模的共同原因（同一张地图、同一个时钟、同一段无线信道，甚至同一位人类监督者的注意力），却被当作独立组，并集界就会把相关的风险乘成零，舰队会用一张「各自独立」的假证书给自己发安全通行证；这正是 R71「两把尺子一起歪」在舰队尺度上的放大版，**而且错误的单位从「一台机器」变成了「整支舰队」。**

次级风险与缓解：
1. **G_S 不完备** → 默认并成单组（最保守）+ 独立性可证伪审计（E343/E349）+ 显式基底清单；无法证明独立即按相关处理；
2. **碰撞单侧证明的数值/覆盖漏洞** → 保守几何 + CCD + 隧穿结构守卫 + ABSTAIN；绝不用校准统计量替代证明（引理 31）；
3. **队列不可识别却假装可识别** → 强制预注册 + 同伴随机化 + 集合值排名 + RID 门控（定义 361、定理 25）；
4. **共池定价被规避/不公平** → 边际成本定价 + 硬预算 + 审计账本；定价失败退回每机器人 R71 预算；
5. **过度保守导致任务失败** → 只在安全侧收缩，性能层保留排序；E347/E351 量化代价；
6. **实时预算被击穿** → 三频分离：控制/碰撞高频、SDG/ESS 中频、CEM/ELD 低频异步；审计永不进控制快路径（E356）。
