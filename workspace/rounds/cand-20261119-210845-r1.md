# 第 14 轮（新灵感循环第 5 轮；本轮灵感：「闭环控制」×「机器人基础模型」）

> **基线**：第 13/14 轮产物 MetricVoiceGauge-NCD-HUTDH（v14：SCD/DSD/DCA/EDC；定义 607–626；引理 125–130；实验 E661–E670）。
> 本轮纪律：**不把基础模型当策略，只当意图源；安全只住在可证反馈控制器里；一切授权都要过闭环证书**。不推倒 v14：v13 的 AIO/CPD/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。六个新组件——FIP（基础模型意图投影）、CLAC（闭环授权证书）、RSG（参考切换驻留时间调速）、LICM（闭环创新共形监视）、EGC（具身间隙证书）、PCTR（提议—认证—跟踪路由）——一律以**中立元**接入，失效即严格退回 v14，再沿 v14→v13→…→v6 退化链回退。本轮只做三件事：把"基础模型输出"从可执行动作改写为**带集合的意图**、把"安全"从单步动作证书改写为**闭环管与驻留时间证书**、把"开环演示训练"与"闭环部署"之间那条被忽视的缝显式证书化。

## 0. 直觉与动机

**灵感 1（闭环控制 → 基础模型必须从"策略"降格为"参考"，安全住在反馈里）**
直觉：机器人基础模型（VLA/RFM）几乎都在开环演示上训练、用动作预测误差评估，却在闭环里部署。开环误差小绝不等于闭环稳定：一个每步只偏 1cm 的动作，在接触/柔性/负载下会被反馈回路逐帧放大，最后撞墙。闭环控制给我们的第一性原理是：**稳定性是闭环性质，不是开环预测精度**。因此核心降格：FM 不再输出"要执行的动作"，而只输出**意图参考** `g_t`（路点、SE(3) 目标、技能潜变量、语言子目标）；真正落到电机的是**带证书的反馈跟踪器** `π_c`。安全不再问"FM 这一步对不对"，而问"FM 给的参考，反馈器能不能在管子里闭住、并且管子收缩"。核心创新：**闭环授权证书（Closed-Loop Authorization Certificate, CLAC）**：对每个意图计算闭环可达管 `Cl(x,g)`，只有当管落在安全集内、且加权误差 `‖e‖_M` 按 `ρ<1` 收缩时才授权。

**灵感 2（闭环控制 → 参考切换是切换系统，快切会毁掉逐档稳定）**
直觉：v14 的技能扩散把技能当成可嵌套的档，但 FM 每 100–200ms 就重规划一次，每次重规划都让参考 `g_t` 跳一下。逐档都稳定的系统，在**任意快切换**下可以发散——这是切换系统理论的基本事实。把"每帧重新问一次 FM"当成免费操作，是隐藏的稳定性漏洞。核心创新：**参考切换驻留时间调速器（Reference-Switching Dwell-time Governor, RSG）**：要么存在对所有候选意图共同的收缩度量 `M`（共同 Lyapunov，任意切换稳定），要么强制参考切换满足驻留时间 `τ_dwell` 与跳变预算 `B_g`，使误差几何级数收敛到 `B_g/(1−ρ^{τ_dwell})`。这把"FM 多久能改主意"从一个工程超参变成一个**证书量**。

**灵感 3（机器人基础模型 → 黑箱、跨具身、语义误差，必须集合化 + 间隙证书）**
直觉：FM 是黑箱、跨具身迁移、且带语义先验；它的错不是高斯噪声，而是"把杯子理解成碗""把插孔认成螺丝"这种**语义级、集合级**的错。逐点预测置信度对此无能为力。核心创新：**基础模型意图投影（Foundation-Intent Projector, FIP）+ 具身间隙证书（Embodiment-Gap Certificate, EGC）**：FIP 把 FM 原始输出投影成一个**意图集合** `Ĝ_t`（而不是一个点），并只把这个集合交给 CLAC；EGC 把总间隙分解为语义 `δ_sem`、具身 `δ_emb`、观测 `δ_obs`、校准 `δ_cal` 四项，用三角不等式合成 `U_eg`，任何一项未测量就置 `∞` 并强制回退。再加**闭环创新共形监视（Loop-Innovation Conformal Monitor, LICM）**：比较 FM 的开环预测 `x̂_{t+1}` 与闭环实际 `x_{t+1}`，把创新 `ξ_t` 喂给共形集；一旦落在集外，说明 FM 已经"出环"，立即塌缩。

**四者如何统一**
统一为 **v14 语义/技能层之上的闭环执行层**：v14 回答"哪些技能组合在语义上被允许"（`Exec_v14`），v15 回答"在真实闭环里，FM 的意图能否被反馈器闭住、以多快频率切换、在跨具身间隙下还剩多少授权"（`Exec_v15`）。FIP 把点变成集合；CLAC 把集合变成闭环管与收缩证书；RSG 给集合切换加上驻留时间；LICM 用闭环创新做在线证伪；EGC 给跨具身迁移记账；PCTR 在"提议—认证—跟踪—回退"之间路由。共享状态 `Γ_cl = (r_t, M, ρ, τ_dwell, B_g, Ĝ_t, Ĉ_ξ, U_eg, mode)`。**FIP 回答"FM 到底在要求什么"，CLAC 回答"这个要求能不能被安全地闭住"，RSG 回答"多久允许改一次主意"，LICM 回答"它是不是已经不在环里了"**。

## 1. 研究问题（轮次升级版）

- **Q1（闭环授权的可证语义）**：如何定义 `Cl(x,g)` 才使"授权 = 闭环可闭住"而非"单步动作安全"？收缩度量 `M` 与 CBF `h` 如何联合？参考切换如何进入可达管而不破坏归纳？
- **Q2（参考切换稳定性）**：驻留时间与共同 Lyapunov 两条路如何统一？FM 的自适应重规划（事件触发、置信度触发）如何映射到 dwell-time 证书？跳变预算 `B_g` 如何从意图集合 `Ĝ_t` 的直径得到？
- **Q3（跨具身与语义间隙）**：`δ_sem/δ_emb/δ_obs/δ_cal` 如何分别共形校准并合成？黑箱 FM 的语义错误如何在集合层面被 CLAC 拒绝，而不是在动作层面被平均掉？
- **Q4（与 v14 兼容与活性）**：`Exec_v15 ⊆ Exec_v14` 如何保证？LICM 的误报率与 CLAC 的保守性叠加会不会让系统只会 `a_ask`？p99≤22ms 是否守得住？全失效是否严格退回 v14？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P28）

**P25 意图—授权分离律（Intent ≠ Authorization）**
FM 只产生意图集合，永不直接产生被执行的电机动作；执行动作只能来自带证书的反馈跟踪器 `π_c`。FM 的置信度、语义标签、语言指令都不能提升授权，只能收缩授权。

**P26 闭环闭合律（Loop Closure）**
每个被授权意图必须携带 CLAC：闭环管 `Cl ⊆ C`、误差 `‖e‖_M` 收缩、且参考切换满足 RSG 的 dwell-time 或共同 Lyapunov 条件。任一条件不满足只能执行认证回退，不得执行"开环看起来对"的意图。

**P27 间隙显式律（Explicit Gap）**
跨具身/跨任务/跨观测的总间隙 `U_eg` 必须显式测量并合取进授权；未测量的间隙按 `∞` 处理。FM 换本体、换相机、换语言，默认全部间隙失效，必须重新认证。

**P28 反馈优先律（Feedback Priority）**
安全关键路径由反馈跟踪器与 CBF 独占；FM 只能在已认证的管子里改变参考。LICM 一旦判"出环"，PCTR 必须优先塌缩到 v14 最低档，而不是继续相信 FM 的下一帧。

## 3. 与基线的接口（如何退化）

- FIP 失效 ⇒ 意图集合退化为单点教师参考，等价 v14 技能扩散的确定性参考；
- CLAC 失效 ⇒ 不新增闭环授权，直接使用 v14 的 `Exec_v14` 证书，等价 v14 + 固定跟踪器；
- RSG 失效 ⇒ 令 `τ_dwell=0`、`B_g=∞`，退化为"每帧可重规划"，等价 v14 的逐帧调度（但此时引理 132 不再成立，必须在风险区标注）；
- LICM 失效 ⇒ 无闭环创新监视，等价 v14 的分布漂移检测；
- EGC 失效 ⇒ `U_eg=0` 且只允许同具身/同任务，等价 v14 单域部署；
- PCTR 失效 ⇒ v14 固定技能扩散调度 + 事后跟踪；
- 全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v14，再沿 v14→v13→…→v6 退化链回退；
- **安全继承**：FIP 只做集合投影、CLAC 只做收缩、RSG 只做限速、LICM 只做证伪、EGC 只做间隙合取、PCTR 只做路由；六端口均不能新增授权或放宽阈值，`Exec_v15⊆Exec_v14` 由引理 138 保证。

## 4. 预期贡献

1. 把机器人基础模型从"策略"降格为"意图源"，用闭环授权证书把安全从单步动作语义搬到闭环管与收缩语义；
2. 首次把 FM 的重规划频率显式建模为切换系统驻留时间/共同 Lyapunov 问题，给出可证稳定条件；
3. 给出开环—闭环分歧的定量反例，说明"开环动作误差小"不能作为闭环安全证据；
4. 用集合化意图 + 四项具身间隙证书 + 闭环创新监视，填上跨具身迁移"无证书"的空白；
5. E671–E682 覆盖闭环安全、切换稳定、创新覆盖、开环/闭环分歧、跨具身、退化与端到端。

## 5. 本轮最大风险

**一句话**：CLAC 的收缩度量 `M`、RSG 的 dwell-time、LICM 的共形创新集都来自同一个仿真/校准分布，而真实闭环里被控对象本身变了（负载、柔性、摩擦、延迟）；此时 FM 意图、收缩假设、创新覆盖三者同向失效，系统会给出一个"跟踪得很平滑、切换很守规矩、创新也在集内"的闭环，却是一个物理上已经发散的闭环——即**闭环自洽的、证书齐备的、却绝对错误的控制**。

# IP-402 Foundation-Intent Projector：把点预测投影成意图集合
class FoundationIntentProjector:
    def __init__(self, fm, intent_encoder, intent_cal, H=8):
        self.fm = fm                      # 黑箱基础模型（VLA / RFM）
        self.encoder = intent_encoder     # 原始输出 -> 意图空间 G
        self.cal = intent_cal             # 意图共形校准集
        self.H = H                        # 证书时域

    def propose(self, obs_history, task):
        raw = self.fm(obs_history, task)          # logits / waypoints / latent
        g_hat = self.encoder(raw)                 # 点意图
        r_int = self.cal.quantile(alpha=self.cal.alpha)  # 共形半径
        G_hat = IntentSet(center=g_hat, radius=r_int)
        # 关键：只返回集合；不返回可执行动作
        return Intent(g=g_hat, G=G_hat, conf=self.cal.score(g_hat), H=self.H)


# IP-403 Closed-Loop Authorization Certificate：闭环管 + 收缩 + CBF
class ClosedLoopAuthorizationCertificate:
    def __init__(self, controller, M, rho, h, L_h, w_bar, L_g, eta=0.05):
        self.pi_c = controller
        self.M = M
        self.rho = rho
        self.h = h
        self.L_h = L_h
        self.w_bar = w_bar        # 扰动上界 ||w||_M
        self.L_g = L_g            # 参考到误差的增益
        self.eta = eta

    def _r_now(self, x, g):
        return norm_M(x - self.reference(g), self.M)

    def _error_recursion(self, r0, refs):
        """r_k = rho*r_{k-1} + L_g*||Delta g_k||_M + w_bar"""
        rs = [r0]
        for k in range(1, len(refs)):
            dg = norm_M(refs[k] - refs[k-1], self.M)
            rs.append(self.rho * rs[-1] + self.L_g * dg + self.w_bar)
        return rs

    def closure_tube(self, x, intent):
        refs = intent.rollout(self.H)             # 由意图展开的参考轨迹
        r0 = self._r_now(x, intent.g)
        rs = self._error_recursion(r0, refs)
        # 管安全：h(x_k^ref) - L_h*r_k >= eta
        safe = all(self.h(refs[k]) - self.L_h * rs[k] >= self.eta
                   for k in range(len(refs)))
        # 收缩：末端误差严格小于起点
        contractive = (rs[-1] <= (1.0 - self.eta) * max(r0, 1e-9))
        return Certificate(auth=(safe and contractive),
                           tube=rs, margin=min(
                               self.h(refs[k]) - self.L_h * rs[k]
                               for k in range(len(refs))))

    def authorize(self, x, intent):
        cert = self.closure_tube(x, intent)
        return cert.auth, cert


# IP-404 Reference-Switching Dwell-time Governor：切换系统稳定门
class ReferenceSwitchingGovernor:
    def __init__(self, rho, B_g, r_bar, candidates, M=None):
        self.rho = rho
        self.B_g = B_g
        self.r_bar = r_bar
        self.candidates = candidates          # v14 技能阶梯 / 候选模式
        self.M_common = M or self._find_common_lyapunov()

    def _find_common_lyapunov(self):
        """尝试求共同 M 使所有模式 A_i^T M A_i <= rho^2 M。
        失败返回 None，退回 dwell-time 路线。"""
        for M in lyapunov_candidates(self.candidates):
            if all(contracts(A_i, M, self.rho) for A_i in self.candidates):
                return M
        return None

    def _min_dwell(self):
        # 求最小 tau 使 B_g <= (1 - rho^tau) * r_bar
        tau = 0
        while (1 - self.rho ** tau) * self.r_bar < self.B_g:
            tau += 1
        return tau

    def allow_switch(self, t_now, t_last, g_new, g_old):
        if self.M_common is not None:
            return True, 'common_lyapunov'      # 任意切换稳定
        tau_dwell = self._min_dwell()
        if t_now - t_last < tau_dwell:
            return False, 'dwell_violation'
        if norm_M(g_new - g_old, self.M) > self.B_g:
            return False, 'jump_budget'
        return True, 'dwell_ok'


# IP-405 Loop-Innovation Conformal Monitor：闭环创新证伪
class LoopInnovationConformalMonitor:
    def __init__(self, xi_cal, alpha=0.05, window=50, alpha_max=0.10):
        self.cal = xi_cal
        self.alpha = alpha
        self.window = window
        self.alpha_max = alpha_max
        self.buf = []

    def update(self, x_pred, x_real):
        xi = x_real - x_pred
        self.buf.append(xi)
        if len(self.buf) > self.window:
            self.buf.pop(0)
        in_set = self.cal.contains(xi, self.alpha)
        return in_set, self.cal.score(xi)

    def out_of_loop(self):
        if len(self.buf) < self.window:
            return False
        viol = sum(0 if self.cal.contains(x, self.alpha) else 1
                   for x in self.buf) / len(self.buf)
        return viol > self.alpha_max


# IP-406 Embodiment-Gap Certificate：四项间隙三角合成
class EmbodimentGapCertificate:
    def __init__(self, cal_sem, cal_emb, cal_obs, cal_cal):
        self.cals = {'sem': cal_sem, 'emb': cal_emb,
                     'obs': cal_obs, 'cal': cal_cal}

    def compose(self, domain):
        parts, measured = {}, True
        for name, cal in self.cals.items():
            if cal.covers(domain):
                parts[name] = cal.upper(domain)   # 共形单侧上界
            else:
                parts[name] = float('inf')        # 未测量 = 无界
                measured = False
        return sum(parts.values()), measured, parts

    def authorize(self, U_eg, remaining_margin):
        return U_eg <= remaining_margin


# IP-407 Propose–Certify–Track Router：提议—认证—跟踪—回退
class ProposeCertifyTrackRouter:
    def __init__(self, fip, clac, rsg, licm, egc, v14_ladder):
        self.fip, self.clac, self.rsg = fip, clac, rsg
        self.licm, self.egc = licm, egc
        self.v14 = v14_ladder

    def step(self, x, obs_history, task, t_now, t_last_switch, g_prev):
        # 1) 提议：只拿意图集合
        intent = self.fip.propose(obs_history, task)

        # 2) 间隙：跨具身/跨任务先记账
        U_eg, measured, _ = self.egc.compose(domain=task.domain)
        if not measured:
            return self.v14.fallback('gap_unmeasured')

        # 3) 证伪：FM 是否已出环
        if self.licm.out_of_loop():
            return self.v14.fallback('out_of_loop')

        # 4) 切换门：多久允许改主意
        ok, why = self.rsg.allow_switch(t_now, t_last_switch,
                                        intent.g, g_prev)
        if not ok:
            return self.v14.hold_reference(why)   # 保持上一个已认证参考

        # 5) 闭环授权：管安全 + 收缩 + 间隙余量
        auth, cert = self.clac.authorize(x, intent)
        if auth and self.egc.authorize(U_eg, cert.margin):
            u = self.clac.pi_c(x, intent.g)       # 唯一执行出口
            return Exec(u, intent, cert, 'certified')

        # 6) 任一失败：沿 v14 阶梯塌缩
        return self.v14.degrade(cert.margin)

## 3. 推导

**引理 131（闭环授权管的安全闭合）** 设 CLAC 使用收缩度量 `M`、收缩率 `ρ∈(0,1)`，参考跳变满足 `‖Δg_k‖_M ≤ B_g`，扰动满足 `‖w_k‖_M ≤ w̄`。若授权时 `r_0 ≤ r̄`，且对所有 `k≤H` 有 `h(x_k^{ref}) ≥ L_h r_k + η`，其中 `r_k = ρ r_{k-1} + L_g B_g + w̄`，则闭环状态对所有 `k≤H` 满足 `x_k ∈ C = {h ≥ 0}`，概率至少 `1−α`（`α` 为噪声/创新共形失效率）。
证明：由 `e_k = x_k − x_k^{ref}` 与收缩性得 `‖e_k‖_M ≤ r_k`。由 `h` 的 `L_h`-Lipschitz 性，`h(x_k) ≥ h(x_k^{ref}) − L_h‖e_k‖_M ≥ η > 0`，对 `k` 归纳即得。概率由共形覆盖与 union bound 给出。∎
推论：**安全只依赖"管是否闭住"，不依赖 FM 动作是否逐点最优**；FM 可以很笨，只要反馈器能在管内闭住。

**引理 132（参考切换的驻留时间稳定界）** 在引理 131 的误差递推下，若相邻切换间隔至少 `τ`、每次跳变 `≤ B_g`，则任意时刻 `r_t ≤ ρ^τ r_{t−τ} + B_g + w̄`；若 `ρ^τ < 1` 且 `B_g + w̄ ≤ (1−ρ^τ) r̄`，则 `sup_t r_t ≤ r̄`。若存在共同 `M` 使所有模式 `A_iᵀMA_i ⪯ ρ²M`，则可去掉 dwell-time，任意切换稳定。
证明：把参考切换视为脉冲；两脉冲之间误差按 `ρ^τ` 收缩，脉冲注入 `B_g+w̄`；对脉冲时刻求几何级数和得上界。共同 Lyapunov 情形由标准切换系统结论直接得到。∎
推论：`τ_dwell` 是证书量；FM 重规划越快，所需 `B_g` 越小，二者必须显式交换。

**引理 133（开环—闭环分歧反例）** 存在被控对象与 FM，使其在演示分布上的开环动作误差为 0，而闭环从任意非零初值发散。
证明：取标量系统 `x_{t+1} = 1.1 x_t + u_t`，演示分布 `D = {0}`，FM 策略 `π(0)=0`（开环误差 0）且 `π(x)=0, ∀x`。闭环为 `x_{t+1}=1.1x_t`，从任意 `x_0≠0` 指数发散。∎
推论：**开环动作误差/演示拟合度不能作为闭环安全证据**；必须在部署闭环上认证，这正是 CLAC 存在的理由。

**引理 134（闭环创新共形的安全覆盖）** 若 `ξ_t ∈ Ĉ_ξ` 以概率 `≥1−α`，CLAC 授权以概率 `≥1−β`，则单步闭环安全概率 `≥1−α−β`，`H` 步 `≥1−H(α+β)`。
证明：安全事件包含 `{ξ_t∈Ĉ_ξ} ∩ {CLAC 授权且管闭}`；对补集用 union bound。∎
推论：创新集与 CLAC 必须**联合校准**，任一单独覆盖都不足。

**引理 135（具身间隙的三角合成）** 设意图误差可分解为 `δ_sem+δ_emb+δ_obs+δ_cal`，则总误差 `≤ U_eg = Σδ`。若 `U_eg ≤ r̄ − r_t`（管子剩余余量），跨具身意图仍满足引理 131；若任一项未测量，置 `U_eg=∞`，授权为空。
证明：三角不等式逐项相加；未测量项无上界，不能授权。∎
推论：跨具身不是"微调一下"，而是重做四项间隙认证；**缺一项就等于没有证书**。

**引理 136（中立元与严格退化）** 若 FIP 返回单点、EGC 全测且 `U_eg=0`、LICM 恒真、RSG 令 `τ=0, B_g=∞`、CLAC 关闭、PCTR 直通，则 v15 执行路径与 v14 技能扩散逐帧相同，故 `Exec_v15 = Exec_v14`。
证明：逐组件代入中立元，闭环管退化为 v14 单步证书，路由退化为固定调度。∎
推论：新层是**纯保守扩展**，不引入任何新授权。

**引理 137（闭环三难下界）** 对任意 FM/被控对象/安全集，若要求闭环安全、低假拒绝、高切换频率三者同时最优，则至少一项付出代价：
```
FRR ≥ Ω(B_g / r̄)
  或  τ_dwell = Ω( (1/|log ρ|) · log( B_g / ((1−ρ) r̄) ) )
  或  安全余量 ↓ Ω(B_g) .
```
证明：由引理 132 的几何级数，稳态误差下界 `B_g/(1−ρ^τ)` 随切换频率上升而上升；要达到安全阈值只能增大 `τ_dwell`、增大 `FRR` 或压缩 `B_g`。∎
推论：**"随时听 FM 的"与"永远安全"不可兼得**，必须显式选择。

**引理 138（v15 对 v14 的单侧包含）** 在引理 136 的中立元下 `Exec_v15 = Exec_v14`；在非中立元下，CLAC/RSG/EGC 只做合取与收缩，LICM 只做否决，PCTR 只在 v14 阶梯内路由，故 `Exec_v15 ⊆ Exec_v14`。
证明：执行动作 = 反馈器跟踪已授权意图；授权 = `v14 授权 ∧ CLAC ∧ RSG ∧ EGC ∧ ¬LICM 否决`。合取只会缩小集合，路由不新增档位。∎

## 7. 已知风险与失效模式

1. **收缩度量 `M` 与真实对象不匹配**：`M` 在校准对象上求，负载/柔性变化后不再满足 `AᵀMA ⪯ ρ²M`，闭环管变成乐观预测。缓解：在线辨识 + `ρ` 保守化、鲁棒收缩、对象变更即失效重认证。

2. **参考切换驻留时间被绕过**：FM 自适应重规划（事件触发/置信度触发）可能绕过固定 dwell-time。缓解：把事件触发频率也纳入切换计数、用共同 Lyapunov 优先、对触发式重规划单独校准。

3. **共同 Lyapunov 不存在**：多技能/多模式可能不存在共同 `M`，只能走 dwell-time，导致高延迟任务频繁保持旧参考。缓解：分模式族求 M、增加中间档、把保持旧参考的代价显式计入预算。

4. **CBF 与跟踪误差的 Lipschitz 常数低估**：`L_h` 在接触/非光滑场景可能被低估，安全余量 `η` 被吃掉。缓解：非光滑 CBF、分段 Lipschitz、硬件在环压力测试。

5. **意图集合半径过窄（假自信）**：共形分位在语义边界样本稀缺时低估 `r_int`，CLAC 误以为管很窄。缓解：边界主动采样、EVT 尾部分位、集合半径下限、对抗意图注入。

6. **创新集漂移**：LICM 的 `Ĉ_ξ` 在校准分布上覆盖 1−α，但真实闭环被控对象变了，创新整体偏移，LICM 持续误报或持续漏报。缓解：滑动窗口重校准、双阈值、对象变更检测、与 v14 漂移检测联动。

7. **四项间隙的联合低估**：`δ_sem/δ_emb/δ_obs/δ_cal` 可能同向偏低（同一批校准数据、同一偏差）。缓解：分域独立校准、三角界加余量、任一项跨域即置 ∞、定期对抗审计。

8. **反馈器本身的单点故障**：`π_c` 是唯一执行出口，一旦其实现有 bug，所有证书失效。缓解：多反馈器冗余、watchdog、硬件限位、纯硬件安全层。

9. **保守性叠加导致活动性塌缩**：CLAC ∧ RSG ∧ EGC ∧ LICM 四重合取可能让系统几乎只 `a_ask`。缓解：把假拒绝显式计入任务预算、分档放宽（先宽后窄）、人机共享自治。

10. **"闭环自洽的假安全"**：FM、收缩度量、创新集共享同一仿真/校准分布；真实对象变化时三者同向失效，系统仍能"平滑跟踪 + 守规矩切换 + 创新在集内"。缓解：独立物理审计、真实硬件影子测试、对象参数在线辨识、证书与实测的双轨监控。

## 8. 本轮最大风险

**一句话**：CLAC 的收缩度量 `M`、RSG 的 dwell-time、LICM 的共形创新集都来自同一个仿真/校准分布，而真实闭环里被控对象本身变了（负载、柔性、摩擦、延迟）；此时 FM 意图、收缩假设、创新覆盖三者同向失效，系统会给出一个"跟踪得很平滑、切换很守规矩、创新也在集内"的闭环，却是一个物理上已经发散的闭环——即**闭环自洽的、证书齐备的、却绝对错误的控制**。
