# 第 65 轮（承接第 64 轮「GRIP 接触接地四层闭环」IP-204~213；灵感循环 II 第 4 轮；本轮灵感：「参数高效微调」×「通用机器人平台」）

> 第 64 轮用接触接地把几何先验变成可证伪假设，并把安全从"不撞"扩展到"不滑、不压伤"，但其自述的最大风险一针见血：**力/触觉的偏置、漂移、饱和与错误接触模型，会让 CGG 把"传感器/模型错误"误判为"几何幻觉"——力觉从接地真值反变为新的单点故障与物理伤害源**。本轮从机器学习工程里最"轻"的技术——**参数高效微调（PEFT）**——切入一个最"重"的问题：**如何让这套越堆越厚的鲁棒性栈，安全地迁移到形态各异的通用机器人平台，而不必为每台机器人重训、重证、重信？** 核心命题是：
>
> **把 PEFT 从"省算力的训练技巧"重新理解为"可认证的部署原语"——适配不是改变模型，而是给模型叠加一个范数有界、可版本化、可审计的低秩扰动；正因为有界，第 63/64 轮的证书可以被"传输"到新平台，而不是"从零重证"。**

## 0. 直觉与动机

**灵感 1（参数高效微调 → 有界扰动即可审计：把 LoRA 当作安全原语）**
直觉：LoRA 的更新形如 W = W₀ + BA，rank r ≪ d，且算子范数满足 ‖ΔW‖₂ ≤ ‖B‖₂‖A‖₂。这意味着**适配对原模型输出的改变量有显式上界**。而第 64 轮的每一条安全裕度（ρ_rob、ρ_slip、ρ_force）本质上都是策略/世界模型输出的 Lipschitz 函数。两者一咬合：**适配器范数直接给出裕度衰减的可计算上界** ρ' ≥ ρ − L·β·C。于是"一个新平台能不能上线"不再需要重跑全套认证，而只需要一次算术 + 一次轻量探针。PEFT 的真正价值不是省参数，而是**把"未知的跨具身迁移风险"压缩成一个可读、可审计的标量**。

**灵感 2（通用机器人平台 → 能力卡 + 适配器族：一个核心，多种具身）**
直觉：通用机器人平台不是"一台万能机器人"，而是**一族共享语义、异构本体**的平台（不同自由度、夹爪、底盘、F/T 规格、触觉阵列、标定误差）。第 64 轮的 GRIP 栈把这些差异全部硬编码进单一模型，导致"换一台机器人就要重来"。本轮把系统因子化为：**冻结的、平台无关的认证核心 Ω_c**（CGG 检验逻辑、SLD/FCS 安全规则、证书验证器）+ **每平台一组低秩适配器 Ω_a**（感知编码器、OLP 投影头、TSL 技能头、FPE 力标定头）。部署到新平台 = 装配合适配器包 + 传输证书，而不是重训全栈。**通用性来自"核心共享"，可移植性来自"适配器轻量"。**

**灵感 3（通用机器人平台 → 证书传输：把"重证"变成"算一次"）**
直觉：第 63/64 轮的证书 J_grip 是"在参考平台上、对参考分布"签发的。换平台后，机器人动力学、传感器噪声、力限几何都变了，直觉上必须重证。但若适配器的扰动有界、且平台差异被能力卡参数化，则**证书可以像误差棒一样被"搬运"**：基准裕度减去适配器引起的 Lipschitz 膨胀、再减去平台固有差异项，得到新平台上的保守裕度。只要搬运后的裕度仍非负，证书就仍有效。这把"安全迁移"从**经验重训**变成**可组合的证书演算**。

**灵感 4（参数高效微调 → 可辨识性守卫：适配不能"解释掉"幻觉）**
直觉：第 64 轮最大的隐患是"力标定把头偏置吸收掉，从而掩盖真实的几何幻觉"。PEFT 让问题更尖锐：只要给标定适配器足够的秩，它几乎可以拟合任何系统误差——包括真实的几何幻觉。**于是适配本身会"洗白"故障**：证书显示"新平台已适配、裕度为正"，而系统其实在自信地错。本轮引入**可辨识性守卫 IGR**：把已知的几何幻觉模态张成一个子空间 H（法向翻转、虚假接触面、尺度错觉），强制力标定适配器的作用落在 H 的正交补（或其在 H 上的投影被严格限幅）。这样，**真幻觉（落在 H 内）无法被标定适配器吸收，CGG 的检出力被结构性保留**。这是本轮把 PEFT 变成"安全原语"的关键补丁。

**灵感 5（组件原位升级 + PACE 闭环）**
- **认证核心 Ω_c 冻结**：CGG/SLD/FCS/证书验证器不参与适配；它们只在"传输后的裕度"上工作。
- **OLP → OLP-A**：投影头 W = W₀ + BA，冻结 W₀，只训练低秩 A/B；遗憾界多一项 L_ad·β。
- **TSL → TSL-A**：技能库共享，每平台挂低秩技能残差头；pre/eff 力条件不变。
- **FPE → FPE-A**：力标定适配器吸收平台间偏置/尺度差，但受 IGR 约束。
- **RSC/WCV → RSC-T/WCV-T**：球半径与搜索域按传输后的裕度重新夹紧，不再重估。
- **AIC → AIC-T**：干扰集增"适配器扰动 ℰ_ad"与"指纹欺骗"，ρ_dir 在传输裕度上取最坏。
- **J_grip → J_peft**：证书增 (adapter_manifest_hash, envelope, transport_margins, igr_witness, platform_fingerprint)。

## 1. 形式化定义（增量：定义 217–227）

- **定义 217（通用平台族与能力卡）**：平台族 𝒫 = {p_i}。每个平台 p 携带能力卡 C_p = (dof, sensor_suite, ft_spec = (σ_F, σ_τ, b_max, sat), tactile_res, dyn_envelope = (m_max, v_max, a_max), calib_hash)。"通用"指共享语义与技能、异构本体与传感；平台差异被压缩为 C_p 的有限维描述。
- **定义 218（低秩适配器与认证包络）**：对可适配层 l，适配器 A_l = (B_l, A_l)，B_l ∈ ℝ^{d_out×r_l}、A_l ∈ ℝ^{r_l×d_in}，ΔW_l = B_l A_l。认证包络 E(A_l) = (β_l, r_l)，β_l = ‖B_l‖₂‖A_l‖₂ ≥ ‖ΔW_l‖₂。整包 A = {A_l}，其包络 β(A) = Σ_l β_l。包络是适配器上线前由谱范数计算/上界的**可审计量**，不是训练中隐含量。
- **定义 219（冻结认证核心 / 可适配层）**：模块划分为 Ω_c（CGG、SLD、FCS、J_peft 验证器、安全截断逻辑）与 Ω_a（感知编码器 E_p、OLP-A 头、TSL-A 技能残差、FPE-A 标定头）。硬约束：**Ω_c 不含可训练参数；Ω_a 的任何更新不得改变 Ω_c 的接口契约与阈值语义**。适配器只在部署/低频线程生效，实时路径只做冻结前向。
- **定义 220（证书传输算子 T_ad）**：给定参考平台 p₀ 的证书 J_grip（裕度 ρ_i^base）与目标平台 p 的适配包 A、能力卡 C_p，定义传输裕度
  ρ_i'(A, p) = ρ_i^base − L_i·Δ_ad(A) − Δ_plat,i(C_p, C_{p₀}) − ε_cert(N_cert)，
  其中 Δ_ad(A) = Σ_l β_l X_l Π_{k>l} L_k 为适配器输出扰动上界（引理 7），Δ_plat,i 为能力卡差异引起的固有裕度差（如 F/T 噪声、力限几何、质量上界），ε_cert 为认证探针的统计误差。T_ad 输出 J_peft 或 ⊥（不可传输）。
- **定义 221（平台指纹与适配路由）**：平台指纹 z_p = Φ(calib_probe_response, ft_noise_spectrum, kinematic_signature) ∈ ℝ^{d_fp}。路由算子 g: z_p → (A_set, rank_budget)，由已知平台字典 {(z_i, A_i)} 的最近邻/回归给出；若 dist(z_p, dict) > τ_fp 判为 OOD，返回**保守默认**（A=∅，退回第 64 轮 GRIP 的最保守配置）并请求一次标定/监督。
- **定义 222（可辨识性守卫 IGR）**：设 H ⊂ ℝ⁶ 为几何幻觉模态子空间（由历史 CGG 残差 / 已知幻觉类型张成），Π_H 为其正交投影。对标定适配器施加约束
  ‖Π_H · J_cal · Δφ_cal(A_cal)‖ ≤ δ_guard，
  等价于要求力标定对预测旋量的影响尽量落在 H^⊥。IGR 见证 igr_witness = ‖Π_H J_cal Δφ_cal‖ 写入证书；超界即拒绝该标定适配器。
- **定义 223（适配器合成 / 合并）**：给定若干源平台适配器 {A^{(i)}}，合并 A_merge = Σ_i w_i A^{(i)}（逐层），并对 ΔW_merge 做秩-r 截断 SVD（误差 ≤ σ_{r+1}(ΔW_merge)）。包络满足 β(A_merge) ≤ Σ_i |w_i|β(A^{(i)}) + 截断误差。用于从相似平台"热启动"，降低新平台所需探针数。
- **定义 224（认证探针 CCP）**：在目标平台上执行 N_cert 条经 D-最优选择的探针（选使裕度对适配参数的敏感度最高者），估计真实裕度 ρ̂_i 及置信下界 ρ_i^LB = ρ̂_i − c_δ·σ̂_ρ/√N_cert。仅当 ρ_i^LB ≥ 0 才签发 J_peft。CCP 是"轻量重证"，只验证传输假设，不重训。
- **定义 225（适配器清单与回滚）**：adapter_manifest = {(module_id, A_hash, β, r, igr_witness, trained_on, valid_platforms)}。部署时按哈希装载；任何运行时异常（裕度跌破 0、指纹漂移、传感器失效）触发**原子回滚**到上一份 manifest 或保守默认。清单使"适配"成为可追溯工件而非代码补丁。
- **定义 226（J_peft 扩展证书）**：J_peft = (J_grip, adapter_manifest_hash, β(A), {ρ_i'}, igr_witness, platform_fingerprint, ccp_log_hash, transport_version)。Valid(J_peft) ⇔ Valid(J_grip on p₀) ∧ min_i ρ_i' ≥ 0 ∧ igr_witness ≤ δ_guard ∧ dist(z_p, dict) ≤ τ_fp ∧ CCP 下界全部非负 ∧ manifest 哈希一致。审计链：从 J_peft 可反查到"哪一组低秩适配器、在什么包络下、把哪个基准证书搬运到了哪台平台"。
- **定义 227（PACE 闭环算子）**：部署时语义流 [能力卡/指纹 → 适配路由 g → 装载 A → CCP 探针 → T_ad 传输 → 冻结核心在线]；运行时语义流 [第 64 轮 GRIP 全流程（用 Ω_a 适配后的前向）→ RSC-T/OLP-A → DIR → AIC-T → FCS]；实时流 [锚点读 → 冻结核心前向 → CGG 残差/SLD/FCS → WCV-T 编译 → 首技能派发]。不变式：**实时路径无适配器训练、无证书重算；所有 PEFT 写操作只发生在部署与低频线程。**

## 2. 关键算法骨架

```python
# T_ad：证书传输（部署时一次，算术 + 统计，不重训）
def transport_certificate(J_base, adapter_pack, C_ref, C_new, N_cert):
    D_ad = sum(b * X[l] * downstream_lip(l) for l, b in adapter_pack.beta.items())
    rho_new = {}
    for i, rho in J_base.margins.items():
        d_plat = platform_gap(i, C_ref, C_new)          # 能力卡差异
        eps = ccp_error_bound(N_cert, delta=1e-3)
        rho_new[i] = rho - L_margin[i]*D_ad - d_plat - eps
    if min(rho_new.values()) < 0:
        return None                                      # 不可传输：升秩或回退
    return J_peft(J_base, adapter_pack.manifest, rho_new, ...)

# 路由 + IGR 守卫
z = fingerprint(calib_probe_response, ft_noise, kinematics)
A, r_budget = router.select(z)
if dist(z, router.dict) > TAU_FP:
    A = EMPTY_ADAPTER; mode = 'conservative'              # OOD：退回 GRIP 保守档
if igr_projection(A.cal, H_subspace) > DELTA_GUARD:
    A.cal = project_out(A.cal, H_subspace)               # 只保留 H^⊥ 分量
    if igr_projection(A.cal, H_subspace) > DELTA_GUARD:
        A.cal = None                                      # 放弃标定适配
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（低秩适配的 Lipschitz 传播）**：若模块 l 为 L_l-Lipschitz、输入界 ‖x‖≤X_l，适配器谱范数 ≤ β_l，则它对最终输出的扰动 ≤ Σ_l β_l X_l Π_{k>l} L_k =: Δ_ad。**适配器的"改变量"可解析上界，且对下游 Lipschitz 常数线性放大。**
- **引理 8（证书传输的保守性）**：各裕度 ρ_i 对策略输出 L_i-Lipschitz、对世界模型残差 L_i^m-Lipschitz 时，真实裕度 ≥ ρ_i^base − L_iΔ_ad − L_i^mΔ_model − Δ_plat,i；CCP 以 N_cert 条探针估计，误判概率 ≤ δ_ccp。
- **定理 7（PEFT 可认证迁移）**：若基准证书 J_grip 在 p₀ 有效、适配包范数 β、能力卡 C_p、IGR 见证 ≤ δ_guard 均成立，则 min_i ρ_i' ≥ 0 ⇒ J_peft 在 p 上有效，安全违规概率 ≤ α_base + δ_ccp + α_fp。**这把"每平台重证"降为"一次传输 + 一次轻量探针"。**
- **定理 8（适配的参数/样本复杂度）**：若平台差异落在有效秩 r 的子空间内，则每模块只需 Θ(r(d_in+d_out)) 参数、N = O((rd + log(1/δ))/ε²) 样本即可使裕度退化 ≤ ε，显著优于全量微调 Θ(d_in d_out)、N_full = O(d²/ε²)。**有效秩同时控制参数量与安全风险的收敛速度。**
- **命题（IGR 保留 CGG 检出力）**：若幻觉旋量扰动 δ_hall 满足 Π_H δ_hall ≠ 0，且标定适配器作用落在 ker(H)（Π_H ΔW_cal = 0），则 CGG 残差在 H 子空间上的能量不被适配抵消，检测统计量期望 ≥ 6 + ‖Π_H δ_hall‖²/σ_w²；反之移除守卫，存在范数 ≤ β 的适配器吸收 δ_hall 使 T ≈ 6（不可检出）。**守卫是"认证"与"被洗白的错误"之间唯一的结构隔板。**
- **实时性**：认证核心与第 64 轮实时路径同量级（≤2.1ms）；适配器前向只增 m·r 级矩阵乘，≤0.1ms；证书传输/CCP/路由全部在部署与低频线程，实时路径零新增。

## 5. 本轮最大风险

**一句话**：低秩标定适配器本身可能把真实的系统性错误——尤其是"看起来像几何幻觉的力传感器偏置/平台动力学错配"——**吸收进它的低维子空间并被证书判定为"已适配、裕度为正"**，即适配把故障"洗白"；IGR 是唯一的结构性防线，但一旦 H 子空间建模不全或守卫阈值过松，系统就会进入"认证通过却自信地错"的最危险状态，这比第 64 轮的力觉单点故障更隐蔽，因为它藏在一张合法的证书后面。

## 2. 形式化定义（完整版）

**定义 217（通用平台族与能力卡）** 平台族 𝒫 = {p_i}。每个平台 p 携带能力卡
C_p = (dof, sensor_suite, ft_spec = (σ_F, σ_τ, b_max, sat), tactile_res, dyn_envelope = (m_max, v_max, a_max), calib_hash)。
"通用"指共享语义与技能、异构本体与传感；平台差异被压缩为 C_p 的有限维描述。能力卡是证书传输的输入契约，任何未声明差异视为不可信（走 OOD 保守档）。

**定义 218（低秩适配器与认证包络）** 对可适配层 l，A_l = (B_l, A_l)，B_l ∈ ℝ^{d_out×r_l}、A_l ∈ ℝ^{r_l×d_in}，ΔW_l = B_l A_l。认证包络 E(A_l) = (β_l, r_l)，β_l = ‖B_l‖₂‖A_l‖₂。整包 A = {A_l}，β(A) = Σ_l β_l。包络在上线前由谱范数计算或上界给出，是证书字段，而非训练隐含量；若训练中 β 越界，则按 β 缩放（B_l ← B_l·min(1, β_max/β_l)）或拒绝。

**定义 219（冻结认证核心 / 可适配层）** 模块划分为
- Ω_c = {CGG 残差与 χ² 检验、SLD 滑移判定、FCS 力限截断、J_peft 验证器、safe_idle/compliant_retreat 逻辑}；
- Ω_a = {感知编码器 E_p、OLP-A 投影头、TSL-A 技能残差头、FPE-A 力标定头、WCV-T 的尾部采样器参数}。
硬约束：Ω_c 不含可训练参数；Ω_a 的更新不得改变 Ω_c 的接口契约、阈值语义与失败方向（拒绝仍只膨胀球）。适配器只在部署/低频线程生效，实时路径只做冻结前向。

**定义 220（证书传输算子 T_ad）** 给定参考平台 p₀ 的 J_grip（裕度 ρ_i^base）、目标平台 p 的适配包 A 与能力卡 C_p：
1. 计算适配扰动上界 Δ_ad(A) = Σ_l β_l X_l Π_{k>l} L_k（引理 7）；
2. 计算能力卡差异 Δ_plat,i(C_p, C_{p₀})：对力限裕度用 F/T 噪声/量程差与力限几何差；对鲁棒裕度用质量/速度/加速度包络差；对滑移裕度用触觉分辨率与摩擦辨识误差差；
3. 计算认证探针统计误差 ε_cert(N_cert, δ)（引理 8）；
4. 传输裕度 ρ_i'(A,p) = ρ_i^base − L_i·Δ_ad(A) − Δ_plat,i − ε_cert；
5. 若 min_i ρ_i' ≥ 0 且 IGR 见证达标且指纹非 OOD，返回 J_peft；否则返回 ⊥，并给出"需升秩 / 需补探针 / 需回退"的原因码。

**定义 221（平台指纹与适配路由）** 平台指纹
z_p = Φ(calib_probe_response, ft_noise_spectrum, kinematic_signature) ∈ ℝ^{d_fp}。
路由 g(z_p) 在已知平台字典 {(z_i, A_i)} 上做 k-NN / 轻量回归，输出 (A_set, rank_budget)。若 dist(z_p, dict) > τ_fp 判为 OOD：A = ∅、mode = 'conservative'（退回第 64 轮 GRIP 的最保守配置），并请求一次标定/监督。指纹哈希写入 J_peft，防止"换平台冒用旧证书"。

**定义 222（可辨识性守卫 IGR）** 设 H ⊂ ℝ⁶ 为几何幻觉模态子空间（由历史 CGG 残差的主成分与已知幻觉类型——法向翻转、虚假接触面、尺度错觉——张成）。对标定适配器施加约束
‖Π_H · J_cal · Δφ_cal(A_cal)‖ ≤ δ_guard，
其中 J_cal = ∂Ŵ/∂φ 为力标定对预测旋量的雅可比。IGR 见证 igr_witness = ‖Π_H J_cal Δφ_cal‖ 写入证书；超界即拒绝该标定适配器，或将其投影到 H^⊥ 后再验证。几何直觉：**标定只能解释"幻觉看不到的方向"，不能解释"幻觉正落在的方向"**，否则真幻觉会被当作传感器偏置吸收，CGG 失效。

**定义 223（适配器合成 / 合并）** 给定源平台适配器 {A^{(i)}}，逐层合并 A_merge = Σ_i w_i A^{(i)}，对 ΔW_merge 做秩-r 截断 SVD，截断误差 ≤ σ_{r+1}(ΔW_merge)。包络满足 β(A_merge) ≤ Σ_i |w_i|β(A^{(i)}) + σ_{r+1}。用途：从相似平台热启动，降低目标平台所需 CCP 探针数；若合并后传输裕度反而更差（负迁移），回退到单源或空适配。

**定义 224（认证探针 CCP）** 在目标平台执行 N_cert 条经 D-最优选择的探针（选使裕度对适配参数敏感度 ∂ρ/∂θ 最大者），估计真实裕度 ρ̂_i 与置信下界
ρ_i^LB = ρ̂_i − c_δ·σ̂_ρ/√N_cert。
仅当所有 ρ_i^LB ≥ 0 才签发 J_peft。CCP 是"轻量重证"：它只验证传输假设（Lipschitz 界、能力卡差异、IGR），不重训、不重估 φ。探针分布须覆盖能力卡声明的工况包络，否则视为未验证。

**定义 225（适配器清单与回滚）** adapter_manifest = {(module_id, A_hash, β, r, igr_witness, trained_on, valid_platforms)}。部署时按哈希装载；运行时任一异常（ρ 跌破 0、指纹漂移、传感器失效、manifest 哈希不符）触发原子回滚到上一份 manifest 或保守默认。回滚日志写入 ccp_log_hash 的审计链。清单使"适配"成为可追溯工件，而非不可审计的代码补丁。

**定义 226（J_peft 扩展证书）** J_peft = (J_grip, adapter_manifest_hash, β(A), {ρ_i'}, igr_witness, platform_fingerprint, ccp_log_hash, transport_version)。
Valid(J_peft) ⇔ Valid(J_grip on p₀) ∧ min_i ρ_i' ≥ 0 ∧ igr_witness ≤ δ_guard ∧ dist(z_p, dict) ≤ τ_fp ∧ 所有 CCP 下界非负 ∧ manifest 哈希与装载一致 ∧ transport_version 与能力卡兼容。
审计链：J_peft → manifest → 每个适配器的 β/r/训练来源 → 传输裕度 → CCP 探针日志 → 平台指纹，全链路可反查。

**定义 227（PACE 闭环算子）** 三流分离：
- **部署流（一次性/低频）**：[能力卡 C_p → 指纹 z_p → 路由 g → 装载 A → IGR 投影/见证 → CCP 探针 → T_ad 传输 → 签发 J_peft → 冻结]；
- **运行语义流（10–100Hz）**：[第 64 轮 GRIP 全流程（用 Ω_a 适配后的前向）→ RSC-T 夹紧球 → OLP-A 在线投影 → DIR → AIC-T 认证 → FCS]；
- **实时流（≤2ms）**：[锚点读 → 冻结核心前向 → CGG 残差 → SLD 滑移 → FCS 力限 → WCV-T 编译 → 首技能派发 → J_peft 状态位读取]。
不变式：**实时路径无适配器训练、无证书重算、无学习写操作；所有 PEFT 写操作只发生在部署与低频线程；Ω_c 永不更新。**

    """冻结认证核心：只读接口，无训练参数。"""

class LowRankAdapterPack:
    def __init__(self, modules, rank_budget):
        self.adapters = {m: (B, A) for m, (B, A) in modules.items()}
        self.r = rank_budget
    def beta(self):
        return {m: np.linalg.norm(B, 2) * np.linalg.norm(A, 2)
                for m, (B, A) in self.adapters.items()}
    def apply(self, m, x):
        B, A = self.adapters[m]
        return x + B @ (A @ x)                      # W0 x + B A x


def transport_certificate(J_base, pack, C_ref, C_new, N_cert, delta=1e-3):
    beta = pack.beta()
    D_ad = sum(b * X[m] * downstream_lip(m) for m, b in beta.items())
    eps = ccp_error_bound(N_cert, delta)            # O(sigma_rho * sqrt(log(1/delta)/N))
    rho_new, reasons = {}, []
    for i, rho in J_base.margins.items():
        d_plat = platform_gap(i, C_ref, C_new)
        rho_new[i] = rho - L_margin[i] * D_ad - d_plat - eps

### IP-217/218 指纹路由 + 可辨识性守卫

```python
class PlatformRouter:
    def __init__(self, platform_dict, tau_fp=0.35):
        self.dict, self.tau_fp = platform_dict, tau_fp
    def select(self, z_p):
        d, idx = nearest(self.dict, z_p)
        if d > self.tau_fp:
            return None, 0, 'OOD'                    # 保守默认，退回 GRIP
        return self.dict[idx].adapter, self.dict[idx].rank_budget, 'known'


def igr_guard(cal_adapter, J_cal, H_basis, delta_guard):
    """强制标定适配器作用落在幻觉子空间 H 的正交补。"""
    P_H = H_basis @ H_basis.T                        # 正交投影
    effect = J_cal @ cal_adapter.delta_phi()
    witness = np.linalg.norm(P_H @ effect)
    if witness <= delta_guard:
        return cal_adapter, witness
    # 投影到 H^⊥：只保留 (I - P_H) 分量
    cal_adapter = cal_adapter.project(orthogonal_to=H_basis)
    witness = np.linalg.norm(P_H @ (J_cal @ cal_adapter.delta_phi()))
    if witness <= delta_guard:
        return cal_adapter, witness
    return None, witness                             # 放弃标定适配，退回基准标定
```

### IP-220/223 认证探针 + 适配器合并

```python
def certified_probe(core, pack, platform, budget=32, delta=1e-3):
    probes = d_optimal_select(core.margin_jacobian(pack), budget)
    rho_hat = []
    for a in probes:
        obs = platform.execute(a)
        rho_hat.append(core.margin(obs, pack))
    rho_hat = np.array(rho_hat)
    sigma = rho_hat.std(ddof=1) + 1e-9
    c_delta = np.sqrt(2 * np.log(1 / delta))
    rho_lb = rho_hat.mean() - c_delta * sigma / np.sqrt(len(rho_hat))
    return rho_lb, len(probes)


def merge_adapters(adapters, weights, target_rank):
    merged = {}
    for m in adapters[0].keys():
        dW = sum(w * (B @ A) for w, ad in zip(weights, adapters)
                 for (B, A) in [ad.adapters[m]])
        U, S, Vt = np.linalg.svd(dW, full_matrices=False)
        r = min(target_rank, len(S))
        merged[m] = (U[:, :r] * S[:r], Vt[:r, :])    # 秩截断
    return LowRankAdapterPack(merged, target_rank)
```

## 4. 推导

**引理 7（低秩适配的 Lipschitz 传播）** 设网络由模块 1..K 复合，模块 k 为 L_k-Lipschitz，输入界 ‖x_k‖ ≤ X_k。仅在第 l 层叠加适配器 ΔW_l = B_lA_l，β_l = ‖B_l‖₂‖A_l‖₂。对同一输入，输出差
‖Δo‖ = ‖f_K∘…∘f_{l+1}(W_l x_l + ΔW_l x_l) − f_K∘…∘f_{l+1}(W_l x_l)‖
≤ (Π_{k>l} L_k)·‖ΔW_l x_l‖ ≤ (Π_{k>l} L_k)·β_l·X_l。
对多层适配求和（一阶界，交叉项为 O(β²)），得 Δ_ad(A) = Σ_l β_l X_l Π_{k>l} L_k。故适配对输出的改变量**对包络线性、对下游 Lipschitz 常数乘性放大**。∎

**引理 8（证书传输的保守性）** 设裕度 ρ_i = g_i(o, m) 对策略输出 o 与模型残差 m 分别 L_i、L_i^m-Lipschitz。适配使 o 变化 ≤ Δ_ad，平台差异使 m 变化 ≤ Δ_model（由能力卡差异与接触模型误差界定）。则
ρ_i^true ≥ ρ_i^base − L_iΔ_ad − L_i^mΔ_model − Δ_plat,i。
CCP 用 N_cert 条 i.i.d. 探针估计 ρ̂_i，由 Hoeffding/Bernstein（裕度有界或次高斯），
P[|ρ̂_i − Eρ_i| ≥ ε] ≤ 2exp(−2N_cert ε²/B²) ⇒ ε = O(B√(log(1/δ)/N_cert))。
若探针分布覆盖能力卡声明的工况包络，则 Eρ_i ≥ ρ_i^true − Δ_cov，得下界 ρ_i^LB。∎

**定理 7（PEFT 可认证迁移）** 设 J_grip 在参考平台 p₀ 上 Valid，裕度 ρ_i^base ≥ 0。给定适配包 A（包络 β）、目标平台能力卡 C_p、IGR 见证 ≤ δ_guard、指纹非 OOD。由引理 7/8，传输裕度 ρ_i' = ρ_i^base − L_iΔ_ad − Δ_plat,i − ε_cert 是真实裕度的下界，误差概率 ≤ δ_ccp。若 min_i ρ_i' ≥ 0，则 J_peft 的全部验证条件成立，目标平台上发生安全违规的概率
P[violation] ≤ P[violation | p₀ 基准] + P[传输下界失效] + P[指纹误判]
≤ α_base + δ_ccp + α_fp。
故 J_peft 是 p 上的有效证书；且因 Ω_c 冻结、失败方向固定为保守，"认证通过"不会放大风险。∎

**定理 8（适配的参数/样本复杂度）** 设平台差异在每模块权重空间的有效秩为 r（即 ΔW_l 近似落在秩 r 子空间，尾部能量 ≤ ε_r）。则每模块可训练参数 Θ(r(d_in+d_out))。在线性高斯模型下，估计 ΔW 的均方误差 ~ σ²·r(d_in+d_out)/N；要使裕度退化 ≤ ε，需 N = O((r d + log(1/δ))/ε²)（d = d_in+d_out）。全量微调需 Θ(d_in d_out) 参数、N_full = O(d²/ε²)。故**有效秩 r 同时控制参数量与达到给定安全裕度所需样本数**；r 越小，适配越省、证书越紧。∎

**命题（IGR 保留 CGG 检出力）** 设几何幻觉使预测旋量产生 δ_hall，且 Π_H δ_hall ≠ 0（幻觉在 H 子空间有非零分量）。CGG 残差 e = η + δ_hall，检测统计量 T = ‖Σ_w^{-1/2}e‖²，在 H 子空间上的分量能量为 ‖Π_H δ_hall‖²/σ_w²。若标定适配器满足 Π_H J_cal Δφ_cal = 0，则它不改变 e 在 H 上的分量，E[T] ≥ 6 + ‖Π_H δ_hall‖²/σ_w²，检出力与无适配时相同。反之若移除 IGR，取 Δφ_cal = (Π_H J_cal)^+ Π_H δ_hall，则 ‖ΔW_cal‖ ≤ β 可把 H 分量抵消到 0，T ≈ 6，幻觉不可检出。故 IGR 是"认证"与"被洗白的错误"之间的结构隔板。∎

**命题（合并的包络与负迁移）** 合并 A_merge = Σ_i w_i A^{(i)} 的包络满足 β(A_merge) ≤ Σ_i |w_i|β(A^{(i)}) + σ_{r+1}。若合并后传输裕度 min_i ρ_i' 下降，说明源平台差异在目标平台上不同向（负迁移），此时应回退单源或空适配；该判据可由 CCP 的 ρ_i^LB 直接检测，无需额外实验。∎

## 7. 已知风险

**一句话**：低秩标定适配器本身可能把真实的系统性错误——尤其是"看起来像几何幻觉的力传感器偏置/平台动力学错配"——**吸收进它的低维子空间并被证书判定为"已适配、裕度为正"**，即适配把故障"洗白"；IGR 是唯一的结构性防线，但一旦 H 子空间建模不全或守卫阈值过松，系统就会进入"认证通过却自信地错"的最危险状态，这比第 64 轮的力觉单点故障更隐蔽，因为它藏在一张合法的证书后面。

**次级风险与缓解**：
1. **H 子空间不完备**：未知幻觉模态不在 H 内，IGR 形同虚设。缓解：用历史 CGG 残差主成分 + 主动注入已知幻觉类型持续扩张 H；IGR 见证只覆盖已建模模态，J_peft 显式标注 `H_coverage`，未覆盖部分靠 CCP 的异常探针兜底。
2. **证书传输过于保守**：Lipschitz 界乘性放大，导致新平台永远 ρ'<0、无法上线。缓解：按模块分组求紧界、用实测 Lipschitz 替代最坏界、允许升秩换紧致；同时把"传输失败"作为触发补数据的信号而非终点。
3. **指纹欺骗 / 平台冒用**：改标定哈希或换传感器后冒用旧指纹。缓解：指纹含物理探针响应（不可仅靠元数据伪造）+ calib_hash 签名 + J_peft 绑定指纹哈希。
4. **适配器负迁移与干扰**：多源合并或在线微调让一个模块的适配破坏另一个模块已认证的行为。缓解：模块级包络隔离、合并前后 CCP 对比、负迁移自动回退单源。
5. **秩不足 / 平台差异不在低秩子空间**：ΔW 尾部能量大，传输裕度失真。缓解：残差谱监测（σ_{r+1} 超阈即拒绝）、自动升秩或退回全量重训流程（而非强行适配）。
6. **CCP 探针分布漂移**：探针未覆盖真实工况，统计下界失效。缓解：探针分布按能力卡包络分层采样 + 运行时 OOD 监测 + 触发补探针。
7. **证书/适配器版本错配**：manifest 与运行时权重不一致，审计链断裂。缓解：装载时哈希校验、transport_version 与能力卡兼容性检查、原子回滚。
8. **实时预算**：LoRA-A 前向叠加第 64 轮 2.1ms 路径逼近 2ms 契约。缓解：仅对关键模块启用适配、共享编码、r 上限约束、必要时把非关键适配下沉到低频线程。
