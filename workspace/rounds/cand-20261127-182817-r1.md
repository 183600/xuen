### 第 4 轮灵感驱动研究记录

**灵感词**：通用操作、视觉定位

**直觉解释（先讲人话）**：

前几轮把系统做成了「证书驱动的分布式视觉伺服」：每一个控制动作都要带一张「合格证」。但证书回答的是「这一步安不安全、量准不准」，并没有回答「我到底在操作什么、这个任务我有没有资格做」。本轮两个灵感词正好补上这一层——

- **通用操作**问的是「覆盖面」：一个策略能否在没见过的新物体、新指令上仍然把动作组合出来。它天然活在**语义/任务空间**里：语言指令、技能、可供性、目标状态。
- **视觉定位**问的是「接地」：物体到底在哪、朝向如何、位姿误差多大。它天然活在**度量/几何空间**里：6-DoF 位姿、协方差、内点率、对称性。

关键洞见：**通用性只有在被度量接地之后才是安全的**。一个通用策略可以「自信地」把「把红色杯子放进水槽」分解成技能序列，但如果视觉定位把杯子的位姿估错（尤其是对称物体、透明/反光物体），那么每一张下游证书都会「合规地」建立在错误的物理指称上。于是我们把证书体系从「动作级」提升为**「任务—契约级」**：每个技能是一段带前置/后置证书契约的程序，视觉定位是解释这些契约的「状态断言」。

一句话概括：**通用操作 = 在技能契约上做程序组合；视觉定位 = 为契约提供可证伪的度量断言；证书 = 两者之间的类型检查器。**

**严谨定义**：

1. **任务规格** τ = (ℓ, O, G)：ℓ 为语言/技能指令，O = {o_1,…,o_n} 为指称物体集，G 为目标状态谓词。
2. **视觉定位证书** VLC(o) = (T_{w←o}, Σ_pose, ρ_inlier, S_o, amb)：T ∈ SE(3) 为物体位姿，Σ ∈ ℝ^{6×6} 为切空间协方差，ρ 为 PnP/匹配内点率，S_o ⊆ SE(3) 为物体对称群，amb 为对称歧义标志。
3. **接地算子** Γ: (τ, {VLC(o)}) → C(τ) = {c_1,…,c_m}，把语义谓词映射为几何证书（存在性、可达性、抓取稳定性、无碰撞、目标区域位姿）。
4. **技能契约** {C_pre} s {C_post}：技能 s 的前置证书集与后置证书集；执行 s 后必须由新的视觉定位重新证明 C_post，而非静态信任旧证书。
5. **泛化覆盖度** cov(τ) = E_{o∈O}[ 1{VLC(o).valid ∧ novelty(o) ≤ ν_max} ]，novelty 为视觉嵌入到训练支撑集的马氏距离（或集成分歧）。
6. **通用执行集** Exec_GM：只有同时满足 CADVS 证书、任务接地证书、覆盖阈值 γ_cov 的执行轨迹才被允许。

**形式化目标（增量）**：
1. 定义任务接地证书编译器 TGCC，把 τ 编译为 C(τ)。
2. 定义对称感知定位核 SORLK，输出对 S_o 不变的位姿协方差（对称方向协方差下界 σ_sym²）。
3. 定义可供性—证书绑定器 ACB，把抓取/接触候选过滤为满足可达、力封闭、净空、对称一致的证书。
4. 定义技能证书路由器 GSCR 与覆盖估计 GCE，实现「域内走通用策略、域外回落教师/遥操作」。
5. 证明证书契约组合的可靠性（Hoare 式组合引理）与 Exec_GM ⊆ Exec_v30（更严格的包容），并保持域内任务成功率不退化。

**本轮最大风险（一句话）**：**语义—度量错位**——通用策略对新颖物体的语义泛化速度会超过视觉定位的度量可靠性，导致「证书全部合规、物理指称却错误」的接地幻觉；这种失败比证书过期更隐蔽，因为所有门禁都显示绿色。

### IP-478 Task-Grounded Certificate Compiler (TGCC)

```python
@dataclass
class TaskGroundedCertificateCompiler:
    """把语义任务 τ 编译为几何证书束 C(τ)；不可接地则整体不可满足。"""
    localizer: "SORLK"
    rho_min: float = 0.30
    tr_max: float = 0.05          # 位姿协方差迹上界

    # 语义谓词 -> 几何谓词的显式接地表（可审计、可扩展）
    GROUNDING_TABLE = {
        'object_present':  lambda p, sc, L: L.locate(p.obj, sc).valid,
        'reachable':       lambda p, sc, L: sc.robot.ik_margin(p.obj, sc) > p.eps,
        'clear_path':      lambda p, sc, L: sc.planner.min_clearance(p.obj, p.goal) > p.d_min,
        'goal_region':     lambda p, sc, L: L.locate(p.goal_ref, sc).valid,
    }

    def compile(self, tau: "Task", scene: "Scene") -> "CertBundle":
        certs = []
        # 1) 物体接地：每个指称物体都必须被视觉定位证明存在且位姿可信
        for o in tau.O:
            vlc = self.localizer.locate(o, scene)
            if not vlc.valid:
                return CertBundle(satisfiable=False, reason=f'ungrounded:{o.id}')
            certs.append(Cert(kind='vlc', pred=vlc, src='sorlk'))
        # 2) 目标区域接地
        if tau.G is not None:
            gvlc = self.localizer.locate(tau.G.ref, scene)
            if not gvlc.valid:
                return CertBundle(satisfiable=False, reason='ungrounded:goal')
            certs.append(Cert(kind='goal_vlc', pred=gvlc, src='sorlk'))
        # 3) 语义谓词逐条接地；未知谓词一律拒绝（闭世界假设）
        for p in tau.predicates:
            fn = self.GROUNDING_TABLE.get(p.kind)
            if fn is None:
                return CertBundle(satisfiable=False, reason=f'unknown_pred:{p.kind}')
            if not fn(p, scene, self.localizer):
                return CertBundle(satisfiable=False, reason=f'pred_fail:{p.kind}')
            certs.append(Cert(kind=p.kind, pred=p, src='tgcc'))
        return CertBundle(certs=certs, satisfiable=True)
```

### IP-479 Symmetry-Aware Object-Relative Localization Kernel (SORLK)

```python
@dataclass
class SymmetryAwareObjectLocalizationKernel:
    """6-DoF 物体定位 + 对称群感知协方差；防止『假精度』证书。"""
    sigma_sym: float = 0.02       # 对称方向协方差下界（rad²/m² 混合标量）
    chi2_gate: float = 16.27      # 6 自由度 99% 门限
    rho_min: float = 0.30

    def locate(self, obj: "Object", scene: "Scene") -> "VLC":
        kps, desc = self._extract(obj, scene.image)
        matches = self._match(kps, obj.model_desc)
        rho = len(matches) / max(1, len(kps))
        T, Sigma, H = self._robust_pnp(matches, obj.model_points)
        # 1) 对称方向协方差膨胀：信息矩阵在 S_o 李代数方向为零/极弱
        Sigma = self._inflate_symmetry(Sigma, obj.symmetry_group)
        # 2) 对称歧义：只观测到部分对称面 -> 位姿在 S_o 下不可区分
        amb = self._detect_ambiguity(T, Sigma, obj.symmetry_group)
        # 3) 校准门控：Σ 必须能覆盖真实残差（χ² 一致性）
        calibrated = self._chi2_consistent(matches, T, Sigma)
        valid = (rho > self.rho_min) and calibrated and (np.trace(Sigma) < 1e9)
        return VLC(T=T, Sigma=Sigma, rho=rho,
                   S_o=obj.symmetry_group, amb=amb, valid=valid)

    def _inflate_symmetry(self, Sigma: np.ndarray, S_o) -> np.ndarray:
        B = lie_basis(S_o)                       # 6×k
        if B.shape[1] == 0:
            return Sigma
        P = B @ np.linalg.pinv(B.T @ B) @ B.T    # 6×6 对称投影
        lam_min = np.min(np.linalg.eigvalsh(P @ Sigma @ P))
        if lam_min < self.sigma_sym ** 2:
            Sigma = Sigma + (self.sigma_sym ** 2 - lam_min) * P
        return Sigma

    def _detect_ambiguity(self, T, Sigma, S_o) -> bool:
        # 若存在 s∈S_o 使 T 与 s∘T 都高似然，则标记歧义，交由下游规范化处理
        return any(self._pose_likelihood(s @ T) > self._pose_likelihood(T) * 0.9
                   for s in discrete_generators(S_o))
```

### IP-480 Affordance-Certificate Binder (ACB)

```python
@dataclass
class AffordanceCertificateBinder:
    """把抓取/接触候选过滤为满足几何+统计证书的可行集。"""
    d_min: float = 0.02
    q_fc_min: float = 0.10
    sigma_g_max: float = 0.03     # 抓取帧协方差迹上界

    def bind(self, vlc: "VLC", affordances: list, robot: "Robot") -> list:
        out = []
        for g in affordances:                         # g ∈ SE(3)
            # 1) 在对称群下规范化：只保留 S_o-不变的代表元
            g_c = canonicalize_under_symmetry(g, vlc.S_o)
            # 2) 可达性
            if robot.ik_margin(g_c) <= 0.0:
                continue
            # 3) 净空
            if self._clearance(g_c, vlc) < self.d_min:
                continue
            # 4) 力封闭（摩擦锥 / ε 度量）
            q_fc = self._force_closure_quality(g_c, vlc)
            if q_fc < self.q_fc_min:
                continue
            # 5) 位姿协方差传播到抓取帧
            Sigma_g = self._propagate_cov(vlc.Sigma, g_c)
            if np.trace(Sigma_g) > self.sigma_g_max:
                continue
            out.append(AffordanceCert(g=g_c, q_fc=q_fc, Sigma_g=Sigma_g))
        return out
```

### IP-481 Generalist Skill Certificate Router (GSCR)

```python
@dataclass
class GeneralistSkillCertificateRouter:
    """域内走通用技能，域外回落教师/遥操作；双重门控。"""
    gamma_cov: float = 0.85
    nu_max: float = 3.0
    tgcc: "TGCC" = None
    gce: "GCE" = None
    scr: "SCR" = None

    def route(self, tau, scene) -> "RouteDecision":
        cov = self._coverage(tau, scene)
        if cov < self.gamma_cov:
            return RouteDecision(Route.DELEGATE_TEACHER, reason='low_coverage', cov=cov)
        bundle = self.tgcc.compile(tau, scene)
        if not bundle.satisfiable:
            return RouteDecision(Route.DELEGATE_TEACHER, reason='ungrounded', cov=cov)
        plan = self.generalist.propose_skills(tau)
        if not self.scr.verify_plan(plan, bundle):
            return RouteDecision(Route.DELEGATE_TEACHER, reason='contract_fail', cov=cov)
        return RouteDecision(Route.GENERALIST, plan=plan, bundle=bundle, cov=cov)

    def _coverage(self, tau, scene) -> float:
        vals = []
        for o in tau.O:
            vlc = self.tgcc.localizer.locate(o, scene)
            nu = self.gce.novelty(o, scene)
            vals.append(1.0 if (vlc.valid and nu <= self.nu_max) else 0.0)
        return float(np.mean(vals)) if vals else 0.0
```

### IP-482 Skill Contract Runtime (SCR)

```python
@dataclass
class SkillContractRuntime:
    """Hoare 式契约运行时：每步重新接地前置/后置，拒绝静态信任。"""
    tgcc: "TGCC" = None

    def verify_plan(self, plan: list, initial: "CertBundle") -> bool:
        cur = initial
        for s in plan:
            if not entails(cur, s.pre):     # 当前证书必须蕴含前置
                return False
            cur = s.post                     # 符号验证阶段用后置断言推进
        return entails(cur, plan.goal)

    def execute_step(self, s, scene) -> "StepResult":
        pre = self.tgcc.compile(s.pre_task, scene)
        if not pre.satisfiable:
            return StepResult(skip=True, reason='pre_ungrounded')
        u = s.run()                          # 底层仍走 CADVS 证书控制
        post = self.tgcc.compile(s.post_task, scene)
        if not post.satisfiable:
            return StepResult(abort=True, reason='post_ungrounded')
        return StepResult(u=u, certs=post, ok=True)
```

```python
def general_manipulation_step(tau, scene, robot) -> "ControlOutput":
    # 0) CADVS 既有证书门控（v30 不变）
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)
    if cert_agg is None or not cert_agg.all_passed:
        return fallback_to_teacher(reason='cadavs_cert_fail')

    # 1) 任务接地：语义 -> 几何
    bundle = TGCC.compile(tau, scene)
    if not bundle.satisfiable:
        return fallback_to_teacher(reason='task_ungrounded')

    # 2) 泛化路由：覆盖度 + 新颖度
    decision = GSCR.route(tau, scene)
    if decision.route != Route.GENERALIST:
        return fallback_to_teacher(reason=decision.reason)

    # 3) 契约执行：每步重新接地，底层复用 CADVS 控制
    for s in decision.plan:
        step = SCR.execute_step(s, scene)
        if step.abort or step.skip:
            return fallback_to_teacher(reason=step.reason)
    return ControlOutput(path='generalist+grounded', certs=bundle)
```

## 4. 正确性论证（增量更新）

### 引理 32（对称方向协方差膨胀的可靠性）

**陈述**：设物体 o 具有对称群 S_o，PnP 代价在 S_o 李代数方向上的 Fisher 信息为零（或低于 ε）。若某定位器报告的协方差 Σ 在对称方向满足 λ_min(P_sym Σ P_sym) < σ_sym²，则存在一个下游证书（如需要破坏对称性的抓取/接触位姿）不可靠；反之，将 Σ 沿 P_sym 膨胀至 σ_sym²，并把抓取位姿在 S_o 下规范化为代表元，则所有 S_o-不变的证书是可靠的。

**证明**：由 Cramér–Rao 下界，若 Fisher 信息在方向 d 为零，则任何无偏估计器在该方向的方差无界，声称 σ_d² < σ_sym² 的精度没有信息论依据，属「假精度」。抓取/接触证书依赖物体坐标系下的位姿；若物体沿对称方向移动后物理构型不变，则证书必须只依赖 S_o-不变量。规范化把 g 映射到商空间 SE(3)/S_o 的代表元，使证书在等价类上良定义，从而消除歧义。∎

**工程含义**：SORLK 的 `_inflate_symmetry` 与 ACB 的 `canonicalize_under_symmetry` 是同一数学事实的两端——前者不撒谎，后者不误用。

### 引理 33（证书契约的组合传递性）

**陈述**：若 {C_0} s_1 {C_1}，{C_1} s_2 {C_2}，…，{C_{n−1}} s_n {C_n}，且证书束在蕴含关系下封闭（C ⊨ C' 可在证书格上判定），则 {C_0} s_1;…;s_n {C_n}。

**证明**：Hoare 组合规则的标准归纳：执行 s_1 后由后置条件得 C_1，而 C_1 蕴含 s_2 的前置，故可执行 s_2，依此类推。唯一新增要求是每个 C_i 必须由视觉定位在运行时重新接地；这保证符号后置条件不会因环境漂移而失效。∎

**工程含义**：SCR 的 `verify_plan` 是静态类型检查，`execute_step` 是运行时的动态断言，二者缺一不可。

### 引理 34（覆盖阈值对 OOD 的拒绝保证）

**陈述**：设新颖度 ν(o) ≤ ν_max 时，真实位姿误差落在标定协方差 Σ 内的概率 ≥ 1−δ（共形/χ² 校准保证）。若要求 cov(τ) ≥ γ_cov，则一次任务执行中至少一个指称物体接地失败的概率被 γ_cov 与 δ 共同约束。

**证明**：由并集界，P(存在 o 未接地) ≤ |O|·[P(ν(o) > ν_max) + P(误差超出 Σ)]。覆盖度要求把「ν 过大」的物体直接排除出可执行集合，从而把失败概率上界压到 |O|·δ / γ_cov 量级。∎

**诚实声明**：共形保证依赖校准集与部署集的**可交换性**；新颖物体、新相机、新光照会破坏可交换性，此时 δ 只是名义值。GCE 必须用在线残差监控持续检验这一假设。

### 定理（通用操作执行集的收缩与泛化保持）

**陈述**：在以下假设下：
(A1) CADVS 证书链路有效（v30 的 TCVM/FQC/DLC/MRCC 均通过）；
(A2) VLC 的 Σ 经 χ² 校准且对称方向已膨胀（引理 32）；
(A3) 覆盖度 cov(τ) ≥ γ_cov（引理 34）；
(A4) 技能计划通过证书契约验证（引理 33）；
则 Exec_GM ⊆ Exec_v30，且在域内任务上任务成功率 ≥ v30 基线 − ε（ε 为接地开销引入的可忽略退化）。

**证明**：
- **包含性**：`general_manipulation_step` 首先要求 `cert_agg.all_passed`（即 v30 全部证书），随后才追加任务接地、覆盖、契约三类约束。执行集是这些约束的交集，故为 v30 执行集的子集。
- **组合可靠性**：由引理 33，计划级契约正确；由引理 32，抓取/接触证书在对称物体上良定义；由引理 34，OOD 物体被覆盖门控排除，不进入执行集。
- **泛化保持**：域内任务上 (A1)–(A4) 以高概率成立，新增约束仅拒绝极少数边界样本，故成功率相对 v30 的退化由 ε 界定；域外任务被显式路由到教师/遥操作，不拉低通用路径的统计。∎

**边界**：定理的「高概率」完全依赖 (A2) 的校准与 (A3) 的可交换性；这正是下一节风险的核心。

## 5. 实验设计

**仿真（Isaac Gym / PyBullet + YCB）**：
- 物体集：20 类 YCB 物体，含对称物体（瓶子、碗、圆柱）与透明/反光物体（玻璃杯、金属罐）。
- 任务：语言指令驱动的抓取—放置（"pick the X and place it in Y"），随机化位姿、遮挡、光照。
- 指标：位姿误差（平移/旋转）、证书通过率、**误接受率**（证书通过但真实位姿误差 > 阈值）、OOD 拒绝率、任务成功率、误拒率。

**真机（Franka / Aloha 双臂）**：
- 任务：桌面整理、抽屉开合、杯具归位；含未见过物体 10 类。
- 标定：手眼标定 + CECC 在线监控；故意注入相机松动以测试降级。

**基线与消融**：
- B1：v30 CADVS（无任务接地）。
- B2：通用策略直接执行（无证书）。
- A1：−SORLK 对称膨胀；A2：−GSCR 覆盖门控；A3：−ACB；A4：−SCR 运行时重接地。

**预期结果**：
- 误接受率相对 B1 降低 > 60%（对称/透明物体是主要贡献）。
- OOD 拒绝率 > 90%，域内成功率相对 B1 退化 < 3%。
- 去掉 SORLK 对称膨胀后，对称物体误接受率显著回升（验证引理 32）。
- 去掉 SCR 重接地后，长程任务后置条件漂移导致失败率上升（验证引理 33 的运行时必要性）。

## 7. 本轮最大风险（最终确认）

**一句话**：**语义—度量错位**——通用操作的「泛化自信」与视觉定位的「度量可靠」是两个不同空间的属性，前者可以在没见过物体的语义上正确、后者却在其几何上失效；一旦二者错位，整条证书链会以全绿的状态把动作锚定到错误的物理指称上，形成比证书过期更隐蔽的「接地幻觉」，这是通用操作能否被证书体系安全接纳的生死线。
