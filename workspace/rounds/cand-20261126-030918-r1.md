# 灵感驱动研究循环·新灵感第 1 轮；本轮灵感：「虚实迁移」×「传感器标定」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23+IP-431–439（云边协同证书体系 CESC / FSVC / IPAM / HPC-E+ / CFC+++；其上承 v22 分层 PGEV / ACSC / DCSC，v21 语义-规范层 SDC / CAC / DCL / GIC，v20 联邦感知 PCA / CTS / CFC / HPC / CFCtrl，以及 v19 / v17 各模块）。
> **本轮纪律**：**仿真只提供可折价的先验与对抗探针，绝不提供真值；标定是被证书携带的状态变量，不是被默认正确的前提**。本轮不推倒 v23：CESC / FSVC / IPAM / HPC-E+ / CFC+++ 全部保留。本轮只做一件事：**在 v23 之上加一层"现实差距 + 标定不确定度"的可迁移证书层（TCL）**，把 v23 里三个**未言明的隐含前提**——"真实分布 = 校准分布"、"当前坐标系 = 标定坐标系"、"各模态的标定相互独立"——显式化为可测量、可失效安全、可审计的量，并用它们修复 v23 的两个致命软肋：**缺席幻觉**与**共模标定伪造的模态一致性**。

## 0. 直觉与动机

### 灵感 1（虚实迁移 → 仿真不是真值，而是"稀有事件的对撞机"）

**直觉。** v23 的全部统计承诺——conformal 覆盖 1−α、召回下界 κ_c、少样本原型漂移 Δ_proto——都来自真实数据。但真实数据里"儿童、轮椅、蹲姿、强逆光、半遮挡"恰恰稀缺且昂贵，而这些正是漏检的重灾区。第一反应是"用仿真批量生成、扩充校准集"。**这个第一反应是错的。** 仿真的价值不在"更多同分布样本"，而在两点：(i) 作为**受控对抗探针**，去暴露真实数据采样不到的系统性盲区；(ii) 作为**可折价的先验**，只能收紧真实证书、不能放宽。原因很简单：仿真与真实之间存在现实差距 G_gap，且这个差距在**尾部（稀有体态、极端光照）最大**——恰好在最需要它的地方最不可信。

**严谨定义（可迁移可靠性）。** 设仿真分布 P_sim、真实分布 P_real、检测器假设 h，类别 c 的漏检风险 R_c(h) = P(h 漏检 | c)。由 Ben-David 域适应界：

```
R_c^real(h) ≤ R_c^sim(h) + d_HΔH(P_sim^c, P_real^c) + λ_c
```

其中 d_HΔH 是两分布在被假设类打散下的 ⊕-差异，可由**无标签**数据估计（域分类器 / MMD）；而

```
λ_c = min_{h'∈H} [ R_c^sim(h') + R_c^real(h') ]
```

是**共享误差项（shared error）**，只能由真实标签估计。于是可迁移召回下界：

```
κ_c^real ≥ κ_c^sim − d_HΔH − λ_c − δ_finite
```

**要点**：d_HΔH 可测，λ_c 不可测。任何"用仿真认证真实安全"的论证，只要回避 λ_c，就是把不可观测的共享盲区偷渡成零。这正是本轮最大风险的数学根源。仿真能把稀有类从"无校准样本"变成"有校准样本"从而抬高 κ_c^sim，也能通过对抗探针**主动找出**本会漏掉的体态从而调低 κ_c^sim（更保守、甚至直接令该类 κ_c^real := 0）；但它**永远不能把 λ_c 降下来**。这就是"只收紧、不放松"的精确定义。

**迁移 conformal。** 跨域覆盖用加权 conformal：令似然比 w(x) = dP_real/dP_sim，若 w 有界或 TV(P_sim,P_real) ≤ ε_TV，则 1−α 覆盖可迁移，只需多付一个 ε_TV（或权重估计误差）的保守项。域分类器给出 ŵ 与其置信区间；权重估计越差，付的税越高，信息趋于零时退化为"不可迁移"。

### 灵感 2（传感器标定 → 标定是坐标系的协变量漂移，不是普通参数误差）

**直觉。** v23 的 CertBox 用 inflate(b, ε_loc)，Cov_t 用传感器视锥求并，CFC 用"模态独立"仲裁。这三件事都**默默假设**外参 / 内参 / 时钟是对的。但标定会漂移（振动、温度、轻微碰撞、长期运行）。漂移不是"某个检测框偏了几厘米"，而是**整个坐标坐标系被协变量漂移了**：于是所有条件于该坐标系的 conformal 误差界，在真实世界坐标里**不再成立**。更隐蔽的是：多个传感器若共享同一外参标定流程或同一时钟源，它们的标定误差是**相关的**——CFC 的"≥2 模态独立佐证"会被**共模标定漂移伪造出一致性**，这正是典型的"共模失效击败多样性防御"。

**严谨定义（标定携带证书）。** 标定状态

```
C_t = (T_ext ∈ SE(3), K_int, τ_clock, Σ_C)
```

其中 Σ_C 是标定后验协方差（由靶标残差、传感器间自洽性、时间同步残差估得）。几何映射 g_{C_t} 把检测框 b 映到世界坐标。对距离 r 处的点，标定引入的定位误差满足 Lipschitz 界：

```
ε_calib(r, C_t) ≤ κ_C · r + b_C
κ_C = sqrt(λ_max(Σ_C^{rot})),   b_C = sqrt(tr(Σ_C^{trans})) + v_max · σ_clock
```

于是所有几何证书必须携带标定：

```
CertBox_k = inflate(b_k, ε_loc(s_k) + ε_calib(r_k, C_t))
Cov_t     = Cov_t^sensor(C_t) ⊖ OcclusionMask(C_t)
```

**关键反直觉点**：对标定的正确响应不是"再标一次"，而是把标定变成**带 TTL 与漂移检测的持续证书**。两次见证靶标之间没有新信息，标定后验只能**单调变宽**（信息随时间退化）；漂移未被见证确认时，ε_calib 必须按已知的退化律增长，直到下一次见证把它重置。这把 v23 的"标定是常量"变成"标定是状态变量 ζ_cal"。

### 两者如何统一：把"隐含前提"变成"显式证书"

v23 的三条最强承诺各自隐含一个未言明的前提：

1. **AbsCert 的 κ_c** 隐含"真实分布 = 校准分布" → 需要 G_gap 折价；
2. **CertBox 的 ε_loc** 隐含"当前坐标系 = 标定坐标系" → 需要 ε_calib 膨胀；
3. **CFC 的模态独立** 隐含"各模态标定溯源互不相交" → 需要 prov(·) 与 ρ_cal。

本轮把它们统一为**可迁移-标定证书层 (Transfer-Calibration Layer, TCL)**，把三前提显式化为三个可测状态 (G_gap, C_t, prov)，统一准入门：

```
HPC-TC = HPC-E+ ∧ GapOK ∧ CalibOK ∧ ProvIndep
```

共享状态扩展为 `ζ_tc = ζ_ce ∪ (G_gap, d_HΔH, λ_c^upper, C_t, Σ_C, prov(·), ρ_cal, κ_c^real-bound, ε_calib)`。

**安全纪律的修订（本轮最重要的概念贡献）。** 前几轮坚持 `Exec_v ⊆ Exec_{v−1}` 的**时间单调**。但这一轮必须点破：那条纪律与"用标定信息恢复活性"在数学上**不相容**——如果标定信息只能收紧，那测量标定就毫无价值。正确的健全基线不是"完美标定 + 仿真=真实"下的 v23（那是不健全的），而是 **v23^wc**：worst-case 标定 + κ_c=0 的 v23。本轮证明的是：

```
lim_{Σ_C→∞, G_gap→∞} Exec_v24(C_t, G_gap) = Exec_v23^wc ⊆ Exec_v23
```

即在**信息为零**时逐字坍缩回 v23^wc；信息越多，v24 可以在**已签发证据的范围内**赎回 v23^wc 为未知差距与未知标定**不得不预扣**的保守性。这把"集合包含"升级为**"信息单调 + 证据支配"**：安全不再靠"时间上只能变小"，而靠"任何放宽都携带一张 v23 没有的新证据，且信息归零时证明坍缩"。这是本轮相对 v23 的范式转变。

## 2. 设计原则（在 P31–P42 基础上新增 P43–P46）

**P43 差距折价迁移律（Gap-Discounted Transfer）**
任何源自仿真的保证都必须折价：`κ_c^real ≥ κ_c^sim − d_HΔH − λ̄_c − δ_finite`。`λ̄_c` 是可观测的真实审计上界；若无法给出有限上界，则该类 `κ_c^real := 0`（禁止签发缺席证书）。仿真只能通过 (i) 生成对抗探针**降低** κ_c^sim、(ii) 在有限差距下提供加权 conformal 样本，来改变证书；它**永不单独抬高** κ_c^real。任何仿真到真实的信息，先扣税、后使用。

**P44 标定携带几何律（Calibration-Carrying Geometry）**
每个几何证书显式携带 ε_calib(r, C_t)：`CertBox = inflate(b, ε_loc + ε_calib)`，`Cov_t = Cov^sensor(C_t) ⊖ Occ(C_t)`，`CertBox_arm` 同样叠加。Σ_C 在两次见证之间**单调变宽**（信息退化律），见证到来时按贝叶斯收缩；ε_calib 超阈值或 Σ_C 发散 ⇒ 膨胀、限速、撤销缺席证书三级响应。标定不确定度只能让几何证书更保守，绝不会被"上次标定过"这一历史事实抵消。

**P45 标定溯源独立律（Provenance-Aware Independence）**
模态 m 的独立性以标定溯源 prov(m) 为前提：`indep(m_i, m_j) ⇔ prov(m_i) ∩ prov(m_j) = ∅`。共享溯源（同外参、同时钟、同靶标批次）的模态合并为一个**有效故障模式**，计数只算一次。CFC+++ 的仲裁条件升级为 `count ≥ N−F ∧ n_eff = |{prov(m)}| ≥ 2 ∧ ρ_cal ≤ ρ̄`。共模标定相关性 ρ_cal 由残差在线估计，超过 ρ̄ 即视为单一模态。

**P46 信息单调执行律（Information-Monotone Execution）**
`Exec_v24` 对信息量单调不增（Σ_C 越小、G_gap 越小，执行集越大），且

```
lim_{Σ_C→∞, G_gap→∞} Exec_v24 = Exec_v23^wc ⊆ Exec_v23
```

任意新模块失效 ⇒ 信息归零 ⇒ 坍缩到 v23^wc（比 v23 更保守）。成功签发时，放宽仅限"证据已覆盖"的部分，且每张放宽票据都可机械复核到 (d_HΔH, λ̄_c, Σ_C, prov) 四元证据。时间单调被替换为信息单调，但**零信息极限仍严格包含于 v23**，安全继承以极限形式保留。

## 3. 与基线的接口（如何退化）

- **SRTC 失效**（域分类器不可信 / 无真实审计）⇒ d_HΔH 视为 ∞ 或 λ̄_c 视为 ∞ ⇒ κ_c^real = 0 ⇒ 不签发 AbsCert ⇒ 回退 v23 的保守人距假设；
- **OCC 失效**（Σ_C 发散 / 标定见证过期）⇒ ε_calib → ∞ ⇒ CertBox 膨胀到保守域、Cov_t 收缩、AbsCert 撤销 ⇒ 等价 v23^wc（比 v23 更保守）；
- **CPC 失效**（溯源不可辨）⇒ 全部模态合并为单溯源 ⇒ n_eff = 1 ⇒ 无仲裁 ⇒ 退回 v23 的 CFC（更严：v23 的模态计数此时被视为相关）；
- **仿真不可用** ⇒ 仅用真实校准集，κ_c 取 v23 原值 ⇒ 等价 v23（但缺对抗探针，盲区未暴露，故按 P43 不能再抬高）；
- **TCL 全失效** ⇒ `Exec_v24 = Exec_v23^wc ⊆ Exec_v23`，链式包含仍成立；
- **信息量非零** ⇒ v24 可能大于 v23^wc，但每张放宽票据附带 TCL 证据，且当 Σ_C→∞、G_gap→∞ 时数值上逐点坍缩回 v23^wc（P46），不存在"无证据放宽"的路径。
- **与 CESC 对接**：五元组 (v_m, v_c, v_p, v_r, v_pt) 的 v_c 细化为标定子版本；标定见证哈希进入 rule_root 的 Merkle 叶，任何标定更新都是一次可回滚的版本事件。

## 4. 预期贡献

1. **可迁移可靠性证书**：首次把"仿真到真实"从"多加数据"改写为**带显式折价的统计迁移**（Ben-David 界 + 加权 conformal），并把不可观测的共享误差 λ_c 摆到台面上，禁止用分布距离小来冒充共享盲区小；
2. **仿真作为对抗探针**：给出稀有体态/极端光照的定向生成以**暴露**而非掩盖漏检的策略，把 v23 的"缺席幻觉"风险转化为"主动找盲区 + 无法界则 κ_c=0"的可审计纪律；
3. **标定携带证书**：把标定从常量前提升级为带后验 Σ_C、TTL、漂移检测与信息退化律的状态变量，并严格传播到 CertBox / Cov_t / ACSC / 能量账本；
4. **共模标定防御**：识别出"共享标定溯源会伪造模态独立"，给出 prov-感知的 n_eff 仲裁与 ρ_cal 估计，修补 CFC+++ 的结构性盲点；
5. **信息单调范式**：用"零信息极限坍缩到 v23^wc"取代脆弱的"时间集合包含"，使"用信息恢复活性"与"安全继承"第一次不矛盾；
6. **TCL 统一门**：HPC-TC = HPC-E+ ∧ GapOK ∧ CalibOK ∧ ProvIndep，五元组细化标定子版本并接入 CESC 的原子切换与 Merkle 审计。

## 5. 本轮最大风险

**一句话**：若仿真与真实**共享同一个系统性盲区**（同一检测架构、同一渲染/采集偏差、同一套标定流程），则分布距离测度 d_HΔH 会很小、而共享误差 λ_c 很大——迁移会为"共同错误"签发"彼此印证"的证书，机器人将带着两份互相佐证的证据，撞上那个**两边都看不见的人**。

# ============================================================
# IP-440 SimReal Transfer Certificate (SRTC)
# ============================================================
@dataclass
class GapBudget:
    d_HdH: float          # 无标签可估
    lambda_upper: float   # 真实审计给出的 lambda 上界；inf 表示不可界
    delta_finite: float
    d_bar: float = 0.15
    lambda_bar: float = 0.10

    def gap_ok(self) -> bool:
        return (math.isfinite(self.lambda_upper)
                and self.d_HdH <= self.d_bar
                and self.lambda_upper <= self.lambda_bar)


class SimRealTransferCertificate:
    def __init__(self, backbone, alpha=0.01, delta_gap=1e-3):
        self.backbone = backbone
        self.alpha = alpha
        self.delta_gap = delta_gap

    def estimate_discrepancy(self, phi_sim, phi_real) -> float:
        """无标签估计 d_HΔH：域分类器 AUC 映射 + 有限样本修正。
        也可用 MMD^2 的无偏估计；两者都只度量“差异”，不度量“共同错误”。"""
        auc = train_domain_classifier_cv(phi_sim, phi_real)
        d = 2.0 * abs(auc - 0.5)          # AUC=0.5 → d=0
        return d + math.sqrt(math.log(1 / self.delta_gap) / (2 * min(len(phi_sim), len(phi_real))))

    def audit_lambda_upper(self, detector, D_audit, delta=1e-3) -> float:
        """用极小真实审计集给 lambda_c 上界；只在下界方向上保守。"""
        per_class = defaultdict(list)
        for x, y, c in D_audit:
            miss = int(detector.predict(x).misses(y))
            per_class[c].append(miss)
        worst = 0.0
        for c, vals in per_class.items():
            n = len(vals)
            emp = sum(vals) / n
            # Clopper-Pearson 上界：lambda 是共享误差的一部分，直接用漏检率上界兜底
            worst = max(worst, clopper_pearson_upper(emp, n, 1 - delta))
        return worst

    def transferable_kappa(self, kappa_sim_c: float, gap: GapBudget) -> float:
        """P43：差距折价迁移。不可界 → 该类禁止缺席证书。"""
        if not gap.gap_ok():
            return 0.0
        return max(0.0, kappa_sim_c - gap.d_HdH - gap.lambda_upper - gap.delta_finite)

    def weighted_conformal_quantile(self, scores_sim, w_hat, alpha):
        """加权 conformal：w 有界 / TV 受限时的 1-alpha 分位数。"""
        w = np.clip(w_hat, 1e-6, None)
        order = np.argsort(scores_sim)
        scores, w = np.asarray(scores_sim)[order], w[order]
        cdf = np.cumsum(w) / np.sum(w)
        idx = int(np.searchsorted(cdf, 1 - alpha))
        return float(scores[min(idx, len(scores) - 1)])

# IP-441 Online Calibration Certificate (OCC)
# ============================================================
class OnlineCalibrationCertificate:
    def __init__(self, sigma_growth=1e-4, T_calib=60.0, eps_calib_bar=0.05,
                 v_max=1.5, sigma_clock=1e-3, kappa_bar=0.01):
        self.Sigma_C = np.eye(6) * 1e-6     # 初始：刚标定，极小
        self.t_witness = time.now()
        self.sigma_growth = sigma_growth    # 信息退化律（每 sqrt(s)）
        self.T_calib = T_calib              # 标定 TTL
        self.eps_calib_bar = eps_calib_bar
        self.v_max = v_max
        self.sigma_clock = sigma_clock
        self.kappa_bar = kappa_bar
        self.witness_hash = []

    def cov_now(self, t):
        """两次见证之间无新信息 → 协方差单调变宽（信息退化）。"""
        dt = max(0.0, t - self.t_witness)
        return self.Sigma_C + (self.sigma_growth * dt) ** 2 * np.eye(6)

    def epsilon_calib(self, r, t):
        S = self.cov_now(t)
        kappa = math.sqrt(max(np.linalg.eigvalsh(S[:3, :3])[-1], 0.0))
        b = math.sqrt(max(np.trace(S[3:, 3:]), 0.0)) + self.v_max * self.sigma_clock
        return kappa * r + b

    def calib_ok(self, t) -> bool:
        S = self.cov_now(t)
        kappa = math.sqrt(max(np.linalg.eigvalsh(S[:3, :3])[-1], 0.0))
        return (np.all(np.isfinite(S)) and (t - self.t_witness) <= self.T_calib
                and kappa <= self.kappa_bar
                and self.epsilon_calib(1.0, t) <= self.eps_calib_bar)

    def witness_update(self, residual, J, t, witness_id):
        """一次有效见证：对 C_t 做 EKF 式收缩；重置信息年龄。"""
        S = self.cov_now(t)
        K = S @ J.T @ np.linalg.inv(J @ S @ J.T + np.eye(len(residual)) * 1e-9)
        self.Sigma_C = (np.eye(6) - K @ J) @ S
        self.t_witness = t
        self.witness_hash.append(sha256(f"{witness_id}:{t}:{self.Sigma_C.tobytes()}"))

    def detect_drift(self, residuals) -> bool:
        """CUSUM：区分“物体在动”与“标定在漂移”。标定漂移是残差的持续单向偏移。"""
        s_pos = s_neg = 0.0
        for r in residuals:
            z = (r - np.mean(residuals)) / (np.std(residuals) + 1e-9)
            s_pos = max(0.0, s_pos + z - 0.5)
            s_neg = max(0.0, s_neg - z - 0.5)
        return max(s_pos, s_neg) > 5.0

    def fail_safe_level(self, t) -> int:
        """0=正常, 1=膨胀, 2=限速, 3=撤销缺席证书/停机。"""
        if not np.all(np.isfinite(self.cov_now(t))):
            return 3
        if self.epsilon_calib(2.0, t) > self.eps_calib_bar:
            return 3 if (t - self.t_witness) > self.T_calib else 2
        if self.epsilon_calib(2.0, t) > 0.5 * self.eps_calib_bar:
            return 1
        return 0

# IP-442 Gap-Calibrated Absence Gate (GCAG)
# ============================================================
class GapCalibratedAbsenceGate:
    def __init__(self, srtc: SimRealTransferCertificate, occ: OnlineCalibrationCertificate,
                 kappa_min=0.90, gesture_channel=None):
        self.srtc, self.occ = srtc, occ
        self.kappa_min = kappa_min
        self.gesture_channel = gesture_channel   # v21 GIC 的在场通道

    def issue(self, c, kappa_sim_c, gap: GapBudget, region, t) -> Optional['AbsCert']:
        # 1) 差距折价
        kappa_real = self.srtc.transferable_kappa(kappa_sim_c, gap)
        if kappa_real < self.kappa_min:
            return None                          # 不可界 / 折价后不足 → 拒绝
        # 2) 标定必须有效，且 ε_calib 有界
        if not self.occ.calib_ok(t) or self.occ.fail_safe_level(t) >= 2:
            return None
        # 3) v21 手势通道是独立召回冗余：有人在场证据 → 拒绝缺席
        if self.gesture_channel is not None and self.gesture_channel.presence_evidence():
            return None
        # 4) 覆盖区必须远大于误差半径，否则“看不见”可能只是标定把视锥挪走了
        if region.radius <= 2.0 * self.occ.epsilon_calib(region.radius, t):
            return None
        return AbsCert(region=region, kappa=kappa_real,
                       gap_evidence=gap, calib_hash=self.occ.witness_hash[-1:],
                       issued_at=t)

# IP-443 Calibration-Provenance Consensus (CFC++++)
# ============================================================
class CalibrationProvenanceConsensus:
    def __init__(self, N, F, rho_bar=0.5, M_MIN_PROV=2):
        self.N, self.F = N, F
        self.rho_bar = rho_bar
        self.M_MIN_PROV = M_MIN_PROV

    def provenance_of(self, modality) -> frozenset:
        return frozenset(modality.calib_provenance)   # {extrinsic_id, clock_id, fiducial_batch, temp_comp_v}

    def estimate_rho_cal(self, residuals_by_modality) -> float:
        if len(residuals_by_modality) < 2:
            return 1.0
        keys = list(residuals_by_modality)[:2]
        r = np.corrcoef(residuals_by_modality[keys[0]],
                        residuals_by_modality[keys[1]])[0, 1]
        return float(abs(r)) if np.isfinite(r) else 1.0

    def consensus_round(self, votes, residuals_by_modality, layer_ok=True):
        results = {}
        for key, vs in votes.items():
            if len(vs) < self.N - self.F:
                results[key] = "CI"; continue
            provs = {self.provenance_of(v.modality) for v in vs.values()}
            # 溯源取“公共标定祖先”的并查集：共享外参/时钟即合并
            n_eff = merge_shared_provenance(provs)
            rho = self.estimate_rho_cal(residuals_by_modality)
            prov_ok = (n_eff >= self.M_MIN_PROV) and (rho <= self.rho_bar)
            # 相关性把有效票数打折：相关模态不算独立佐证
            effective = sum(1 for v in vs.values() if v.agrees)
            effective_discounted = effective - math.floor(rho * (len(vs) - n_eff))
            count_ok = effective_discounted >= self.N - self.F
            if count_ok and prov_ok and layer_ok:
                results[key] = self._majority_with_outlier_filter(vs)
            else:
                results[key] = "CI"      # cannot-issue：回退上游证书，绝不伪造一致
        return results

# IP-444 SimAdversarial Probe Generator (SAPG)
# ============================================================
class SimAdversarialProbeGenerator:
    """只用于暴露盲区与下界估计，不产生真值证书。"""
    def __init__(self, sim_env, detector, strategy=("rare_pose", "backlight", "occlusion")):
        self.sim_env, self.detector, self.strategy = sim_env, detector, strategy

    def generate(self, c, n=200, seed=0):
        probes = []
        for s in self.strategy:
            probes += self.sim_env.sample(c, condition=s, n=n // len(self.strategy), seed=seed)
        return probes

    def expose_blindspots(self, c, kappa_sim_c) -> tuple[float, list]:
        probes = self.generate(c)
        misses = [p for p in probes if self.detector.predict(p).misses(p.gt)]
        # 用命中率给出 κ_c^sim 的保守下界；只可能下调
        kappa_sim_lower = 1.0 - len(misses) / max(len(probes), 1) - hoeffding(len(probes), 1e-3)
        return min(kappa_sim_c, kappa_sim_lower), misses

# IP-445 HPC-TC 统一门
# ============================================================
@dataclass
class HPCTC:
    hpce_plus: 'HPCEPlus'
    srtc: SimRealTransferCertificate
    occ: OnlineCalibrationCertificate
    cpc: CalibrationProvenanceConsensus
    gcag: GapCalibratedAbsenceGate

    def admits(self, plan, x, v, z, E_res, margin_req, modules, gap, t, votes,
               residuals_by_modality) -> bool:
        # 1) v23 四证
        if not self.hpce_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2) 差距可折价（否则 AbsCert 已撤销，仅剩保守几何）
        gap_ok = gap.gap_ok()
        # 3) 标定有效：失效则膨胀/限速/停机，并可能否决
        calib_level = self.occ.fail_safe_level(t)
        if calib_level >= 3:
            return False
        # 4) 溯源独立仲裁（共模标定不得伪造一致）
        cons = self.cpc.consensus_round(votes, residuals_by_modality)
        if any(val == "CI" for val in cons.values()):
            return False
        # 5) 几何证书按 ε_calib 膨胀后必须仍然 SAFE
        eps = self.occ.epsilon_calib(z, t)
        if not plan.is_clear_with_inflation(eps):
            return False
        return gap_ok or plan.uses_no_absence()

    def effective_exec(self, t, gap):
        """信息单调：Σ_C 与 gap 决定放宽额度；零信息极限 = v23^wc。"""
        if not self.occ.calib_ok(t) or not gap.gap_ok():
            return self.hpce_plus.v23_worst_case_exec()
        return self.hpce_plus.v23_worst_case_exec() | self._certified_relaxation(t, gap)

## 4. 正确性论证

### 引理 1（差距折价召回界，P43 的严格形式）
**陈述**：若真实审计集给出 λ̄_c ≥ λ_c 且 δ_finite 为有限样本项，则
`κ_c^real ≥ κ_c^sim − d_HΔH − λ̄_c − δ_finite`；若 λ̄_c = ∞ 或 G_gap 不可折价，则 GCAG 令 `κ_c^real := 0`（不签发缺席证书）。

**证明**：
1. Ben-David 域适应界给出 `R_real ≤ R_sim + d_HΔH + λ`；对类别 c 取补得 κ 方向的不等式。
2. `κ_c^sim` 由 SAPG 与真实校准集取 **min**（只降不升），故右端仍是保守下界。
3. λ̄_c 是 λ 的置信上界（Clopper-Pearson），用上界代入只会让 κ 更小，方向安全。
4. 若 λ̄_c 无有限上界，"仿真与真实共享误差"无法被数据排除，唯一 fail-safe 是禁止缺席（κ=0）；这直接对应 v23 最大风险（缺席幻觉）的闭环封堵。
∎

### 引理 2（标定误差传播与信息退化，P44 的严格形式）
**陈述**：对距离 r 的点，标定映射误差 ≤ κ_C·r + b_C；两次见证之间 Σ_C(t) 单调变宽，故 ε_calib 单调不减，`CertBox = inflate(b, ε_loc + ε_calib)` 在真实世界坐标中的覆盖不劣于不膨胀时。

**证明**：
1. 对 se(3) 扰动 ξ∼N(0,Σ_C)，一阶展开给点误差 `δp ≈ (I, −[p]_×)ξ`，其协方差 `J Σ_C Jᵀ`；取最大特征值即 `κ_C² r² + b_C²` 的平方根上界，整理得 Lipschitz 界。
2. `cov_now(t)=Σ_C(t_w)+σ_g²(t−t_w)²I` 对 t 单调（σ_g²≥0），特征值单调不减，故 κ_C、b_C、ε_calib 单调不减——这正是"无新信息则信息退化"。
3. 见证到来时 EKF 收缩 Σ_C 且重置 t_w，ε_calib 回到小值；两次见证之间任何时刻的膨胀都覆盖该时刻的标定不确定性。
∎

### 引理 3（共模标定会伪造模态独立，P45 的必要性）
**陈述**：若 m_i, m_j 共享外参/时钟溯源，则其标定误差完全相关（ρ_cal≈1）；此时"模态数≥2"不构成独立证据，必须用 n_eff=|{prov}| 且 ρ_cal≤ρ̄ 才健全。

**证明**：
1. 共享外参意味着两者对同一次标定漂移做同一个坐标变换，误差向量是同一随机变量的线性像，故相关系数为 1。
2. 在共模误差下，"两票一致"的事件等价于"单票"的事件（同一个错误被数了两次），独立同分布假设被违反。
3. CPC 将共享溯源的模态用并查集合并，n_eff 只数独立溯源；ρ_cal>ρ̄ 时进一步把相关票打折。因此 v23 CFC+++ 的"模态≥2"在共享溯源下是不健全的，CPC 恢复其健全性（且更保守）。
∎

### 引理 4（零信息极限坍缩，P46 / 安全继承）
**陈述**：`lim_{Σ_C→∞, G_gap→∞} Exec_v24 = Exec_v23^wc ⊆ Exec_v23`。因此任意模块失效 ⇒ 信息归零 ⇒ 回到（比 v23 更保守的）健全基线；非零信息下即使 v24 大于 v23^wc，每张放宽票据都携带 (d_HΔH, λ̄_c, Σ_C, prov) 四元证据。

**证明**：
1. Σ_C→∞ ⇒ ε_calib→∞ ⇒ 对任意固定半径的 CertBox 都膨胀到覆盖全空间/被 GCAG 撤销 ⇒ 无缺席、无限速以上的路径，几何执行集收缩到 v23^wc。
2. G_gap→∞ ⇒ κ_c^real=0 ⇒ GCAG 拒绝全部 AbsCert ⇒ 回退 v23 的人距保守假设。
3. CP 在 prov 不可辨时把全部模态合并，n_eff=1 ⇒ 无仲裁 ⇒ 退回 v23 CFC 的保守行为。
4. 三者叠加即 v23^wc；又 v23^wc 是 v23 在更坏标定与 κ_c=0 下的特例，故 ⊆ Exec_v23。
5. 非零信息下 `_certified_relaxation` 仅在 `gap_ok ∧ calib_ok ∧ prov_ok` 时非空，且其每张票据可机械复核；这保证"放宽"不是无证据的，而是信息换来的。∎

### 定理（HPC-TC 的差距-标定-溯源完备性）
**陈述**：对任意计划 π，`HPCTC.admits(π)=True` ⟺ π 同时满足：
(1) v23 的物理/合规/能量/云边/IP 五重条件；
(2) 若 π 依赖缺席证书，则 κ_c^real 已按差距折价且 ≥κ_min，且 λ_c 有有限上界；
(3) 所有几何证书已按 ε_calib(C_t) 膨胀且标定未过期/未越阈；
(4) 仲裁只使用溯源不相交（n_eff≥2）且 ρ_cal≤ρ̄ 的模态。

**证明**：必要性由 admits 的四段连言直接给出：任一为假即拒证。充分性：四条件成立时，引理 1 给缺席可靠性、引理 2 给几何覆盖、引理 3 给仲裁独立性、v23 五证给物理-规范-能量-部署-保护；四者联合覆盖"看见/看不见/坐标系/证据独立性"四类不确定性，且由引理 4，信息归零时自动退回 v23^wc，不存在无证据放宽路径。∎

## 7. 本轮最大风险（最终确认）

**一句话**：仿真与真实若共享同一个系统性盲区，分布距离 d_HΔH 会很小而共享误差 λ_c 会很大——于是"可迁移证书"会给同一个错误发两张互相印证的通行证，机器人将带着这份双份一致的证据，撞上那个**仿真和真实都看不见的人**。
