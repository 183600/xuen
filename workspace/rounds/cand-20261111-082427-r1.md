# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「轨迹优化」×「语音交互」）

> 第 54 轮把技能组合推进到动作空间剖面 α_S、组合图 SCOM 与云边双证书。本轮引入 **语音作为人类意图的低带宽、含噪、可澄清规范通道**，并与 **连续轨迹优化** 结合。核心矛盾：H22：语音意图（离散、歧义、语义）与轨迹（连续、动力学约束、可执行）处在不同空间——语言上合法的指令可能动力学不可行，轨迹最优解也可能偏离人的语义承诺，形成 **语义-动力学错配**；H23：语音噪声、延迟与澄清成本使“把语音直接翻译成约束”不可靠，必须把语音建模为 **意图分布** 并显式决定 **何时澄清、澄清什么**，否则会把 ASR 的一次误识别固化成一条危险轨迹。

## 0. 直觉与动机

**灵感 1（语音不是一条指令，而是一个意图分布）**
直觉：用户说“把杯子轻轻放到桌边”，ASR 可能给出多个候选，语义也可能有“桌边=近沿/远沿”“轻轻=低速/低冲击”等歧义。与其取 top-1 硬翻译成约束，不如保留后验 `p(ι|u,c)`。歧义熵 `H(ι|u,c)` 高时，轨迹优化的可行域本身就模糊；此时“执行”与“追问”应是同一个决策问题的两个动作。这样语音从一次性解析变成 **带不确定性的规范信号**。

**灵感 2（轨迹优化是意图条件下的约束优化，不是独立的运动规划）**
直觉：第 54 轮的动作序列 `A_T` 只是离散骨架，真正落到机器人上是一条连续轨迹 `ξ(t)`。每个意图 `ι` 诱导一个轨迹约束集 `Ξ_ι`（终点、速度剖面、交互距离、禁入区、时序）。轨迹优化应在 `Ξ_ι` 上做，而不是先规划轨迹再“解释成”语音意图。关键产物不是单条最优轨迹，而是 **带可行性裕度与语义一致性的轨迹证书**：能证明这条轨迹在动力学上留有余量，且在行为签名上确实是用户要的那件事。

**灵感 3（语义-动力学一致性：把轨迹投影回“用户能看懂的行为”）**
直觉：判断轨迹是否符合语音意图，不能只看状态误差，而要把轨迹投影成行为签名 `B(ξ)`（终点、峰值速度、最小交互距离、停留时长、路径曲率/绕行）。`B(ξ)` 与意图允许的签名集 `B(Ξ_ι)` 的相似度就是语义-动力学一致性 `SD`。这形成 **意图空间 𝔏 — 轨迹空间 𝔗 — 动作空间 𝔄** 的三角：`G: 𝔏→2^𝔗` 是接地，`Π: 𝔗→𝔄` 是动作投影，`B` 是可解释回读。只有三角闭合（执行轨迹回读后仍匹配意图），语音指令才算真正被理解。

**灵感 4（主动澄清：用期望信息增益换取安全裕度）**
直觉：追问不是失败，而是一种有成本的动作。只有当歧义高且不同意图对应的轨迹在安全/任务上差异大时，追问才值得。定义澄清问题 `q` 的期望信息增益 `IG(q)`，再减去打断成本与延迟惩罚，得到净收益。于是“是否问、问哪个槽位”变成一个可判定的期望效用决策，而不是固定阈值。这也是语音交互与轨迹优化真正的耦合点：**澄清的价值由它对轨迹决策的影响来定价**。

**灵感 5（语言鲁棒性 + 云边分工：慢想全局轨迹，快想局部重规划）**
直觉：云端做全局、慢速、含人类偏好的意图条件轨迹优化（ICTO），边端做高频 MPC 局部重规划并承接语音澄清事件。对意图后验做 Wasserstein 球内最坏情形优化（DRLT），得到 **语言鲁棒性谱 `ρ_lang`**，与第 53 轮的 `ρ` 拼接。云端承诺“意图-轨迹证书”，边端在局部扰动下验证语义一致性与动力学裕度；一旦边端发现 `SD` 跌落或裕度耗尽，就触发澄清或回退，而不是硬执行。

**灵感 6（把当前层嵌进金字塔）**
直觉：在第 54 轮 `𝔸`（动作空间协同层）之上增加 **语音-轨迹层 `𝕋`**：`𝕋_0` 动力学极限，`𝕋_1` 意图约束轨迹族，`𝕋_2` 云边轨迹映射与重规划，`𝕋_3` 澄清交互协议。跨层证书需同时携带 `ρ, A_cert, γ_ce, δ_a` 与本轮的 `p_ι, ξ*, m_dyn, SD, ρ_lang, clarify_trace`。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（语音意图分布）**
给定语音观测 `u`（含 ASR n-best、韵律、对话上下文 `c`），意图后验为 `p(ι|u,c)`，`ι ∈ 𝔏` 为结构化意图（目标 `g`、对象 `o`、方式 `m`、约束 `C`、时序 `τ`）。歧义熵
```
H(ι|u,c) = -Σ_ι p(ι|u,c) log p(ι|u,c)
```
校准可信度 `conf(u) = 1 - H(ι|u,c)/log|𝔏_eff|`。只有当后验 **校准**（ECE ≤ ε_cal）时，下游证书才可 sound 使用。

**定义 122（意图约束集与行为签名）**
意图 `ι` 诱导轨迹约束集
```
Ξ_ι = { ξ ∈ 𝔗 | goal(ξ)=g_ι ∧ style(ξ)∈C_ι ∧ safe(ξ) ∧ dyn(ξ) }
```
行为签名 `B: 𝔗 → 𝔅` 把轨迹投影为可解释特征向量（终点、峰值速度、最小交互距离、停留时长、绕行度、路径曲率）。`B(Ξ_ι) = {B(ξ) | ξ∈Ξ_ι}` 为意图允许的行为签名集。

**定义 123（意图条件轨迹优化 ICTO）**
在意图后验下求解分布鲁棒轨迹：
```
min_ξ  E_{ι~p(ι|u,c)}[ J(ξ;ι) ] + λ_w · W_1(p, p̂)
s.t.   P_{ι}( safe(ξ) ∧ dyn(ξ) ) ≥ 1 - ε_safe
       E_{ι}[ dist(B(ξ), B(Ξ_ι)) ] ≤ δ_sem
       ξ(0)=x_0, ξ(T)∈G_goal,  ξ∈𝒳_free
```
其中 `W_1` 为意图分布到名义分布 `p̂` 的 1-Wasserstein 距离，`λ_w` 为鲁棒半径价格。输出不是单点，而是 **轨迹族 `Ξ*_{u}` 与可行性裕度 `m_dyn`**。

**定义 124（语义-动力学一致性 SD）**
```
SD(ξ,u) = E_{ι~p(ι|u,c)}[ sim( B(ξ), B(Ξ_ι) ) ] ∈ [0,1]
```
`sim` 可取签名空间上的归一化高斯核或负距离指数。语义违背率 `1-SD`。当 `SD(ξ,u) ≥ θ_sem` 且 `m_dyn(ξ) ≥ 0` 时，称 `ξ` 对 `u` **语义-动力学可接受**。

**定义 125（澄清决策与期望信息增益）**
澄清问题 `q ∈ Q`（槽位/二选一/指代确认），回答 `a` 后后验更新为 `p(·|u,q,a)`。定义
```
IG(q) = H(ι|u,c) - E_{a~p(a|u,q)}[ H(ι|u,q,a) ]
Net(q) = IG(q)·V_dec - c_ask(q) - λ_lat·τ(q)
```
其中 `V_dec` 为轨迹决策价值（不同意图导致轨迹差异的代价），`c_ask` 为打断成本。决策规则：
```
若 max_q Net(q) > 0 且 H(ι|u,c) > θ_H：主动澄清 argmax_q Net(q)
否则：执行 argmax_ι p(ι|u,c) 的 ICTO 轨迹，并保留后验作为监督信号
```

**定义 126（轨迹-语音联合证书 TVC）**
```
TVC = (p_ι, ξ*, m_dyn, SD, ρ_lang, clarify_trace, evidence)
```
- `p_ι` 意图后验与校准误差；
- `ξ*` 执行轨迹族/代表轨迹；
- `m_dyn` 动力学可行性裕度（约束松弛量最小值）；
- `SD` 语义-动力学一致性；
- `ρ_lang` 语言鲁棒性谱（意图扰动/ASR 噪声下的性能保持）；
- `clarify_trace` 澄清轨迹（问了什么、答案如何更新后验）；
- `evidence` 至少含云端 ICTO 日志、边端 MPC 重规划记录、反事实轨迹（若理解错会怎样）。
部署条件：`p_ι` 校准通过 ∧ `SD ≥ θ_sem` ∧ `m_dyn ≥ 0` ∧ `ρ_lang(d) ≥ ρ_min ∀d`。

## 2. 关键算法 伪代码

### IP-121 VIP（Voice Intent Profiling）

```python
def voice_intent_profile(u, asr_nbest, context, parser):
    candidates = []
    for hyp, w in asr_nbest:
        for intent in parser.parse(hyp, context):
            candidates.append((intent, w * intent.score))
    p = normalize(candidates)                 # 意图后验
    H = entropy(p)                            # 歧义熵
    return p, H, calibration_check(p, u)
```

### IP-122 ICTO（Intent-Conditioned Trajectory Optimization）

```python
def icto(p_intent, x0, goal, dyn_model, constraints, delta_sem):
    # 1) 约束收紧：按后验分位数做鲁棒化
    tightened = tighten_by_quantile(constraints, p_intent, beta=0.95)
    # 2) 对每个高概率意图求约束最优轨迹（暖启动共享）
    seeds = [solve_constrained(x0, goal, B_of_intent(i), tightened)
             for i,_ in topk(p_intent, k=3)]
    # 3) 分布鲁棒精修：Wasserstein 球内最坏情形
    xi = polish_dro(seeds, p_intent, radius=rho_ball, lambda_w=1.0)
    m_dyn = min_constraint_slack(xi, dyn_model, tightened)
    return xi, m_dyn, trajectory_family(seeds, p_intent)
```

### IP-123 SDC（Semantic-Dynamic Consistency）

```python
def semantic_dynamic_check(xi, p_intent):
    b = behavior_signature(xi)                # 终点/速度/距离/停留/绕行
    sd = 0.0
    for intent, prob in p_intent.items():
        sd += prob * similarity(b, behavior_set(intent))
    violation = 1.0 - sd
    return sd, violation, counterfactual_bad_trajectories(xi, p_intent)
```

### IP-124 CIA（Clarification Interaction Algorithm）

```python
def should_clarify(p_intent, xi_candidates, H, cost_model):
    if H <= theta_H:
        return (False, argmax(p_intent))
    best = (None, -inf)
    for q in feasible_questions(p_intent):
        ig = expected_information_gain(p_intent, q)
        value = decision_value_of_intent_split(p_intent, q, xi_candidates)
        net = ig * value - cost_model.ask(q) - cost_model.latency(q)
        best = max(best, (q, net))
    q, net = best
    if net > 0:
        return (True, q)          # 主动澄清
    return (False, argmax(p_intent))  # 带监督执行
```

### IP-125 DRLT（Distributionally Robust Language-Trajectory）

```python
def language_robustness(xi_fn, p_intent, perturbations, rho_min):
    rho_lang = {}
    for d, pert in perturbations.items():
        worst = 0.0
        for p_worst in wasserstein_ball(p_intent, radius=rho_ball):
            xi = xi_fn(p_worst)
            score = evaluate(xi, d, pert)
            worst = min(worst, score) if worst else score
        rho_lang[d] = worst
    return ('ok' if all(v >= rho_min for v in rho_lang.values())
            else 'reject', rho_lang)
```

### IP-126 TVC（Trajectory-Voice Joint Certificate）

```python
def trajectory_voice_certificate(u, p_intent, xi, m_dyn, rho_lang, trace):
    sd, viol, cf = semantic_dynamic_check(xi, p_intent)
    cal = calibration_check(p_intent, u)
    if not cal.ok:
        return ('reject', 'intent_uncalibrated', tv=cal.error)
    if sd < theta_sem or m_dyn < 0:
        return ('reject', 'semantic_dynamic_mismatch', sd, m_dyn, cf)
    if any(v < rho_min for v in rho_lang.values()):
        return ('reject', 'language_robustness_fail', rho_lang)
    return ('ok', TVC(p_intent, xi, m_dyn, sd, rho_lang, trace,
                      evidence=(cloud_log, edge_mpc_log, cf)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| VIP | O(|n-best|·|𝔏| + \|𝔏\|log\|𝔏\|) | O(|𝔏|) | 后验校准、n-best 覆盖 |
| ICTO | O(k·T_opt + T_dro) | O(\|ξ\|·k) | 约束收紧 sound、Wasserstein 半径有界 |
| SDC | O(\|𝔏\|·\|B\|) | O(\|B\|) | B 可解释、sim 有界 |
| CIA | O(\|Q\|·\|𝔏\|) | O(\|𝔏\|) | 信息增益估计校准、成本模型 |
| DRLT | O(\|𝔇_ρ\|·N_W·T_opt) | O(\|𝔇_ρ\|) | 球半径覆盖真实漂移 |
| TVC | O(\|𝔏\|·\|B\| + \|𝔇_ρ\|·N_W) | O(\|𝔏\|+\|B\|) | 证书各分量 sound |

**正确性定理（Voice-Conditioned Trajectory Soundness）**
在 (A22)–(A28) 承接第 53–54 轮之外，假设：**(A29)** 意图后验在观测分布上校准（ECE ≤ ε_cal）；**(A30)** 行为签名 `B` 在轨迹度量下 Lipschitz，常数 `L_B`；**(A31)** 约束收紧量覆盖后验估计误差与执行扰动；**(A32)** 澄清回答真实，回传延迟 ≤ τ_ask。则对任意语音观测 `u`，若 `TVC` 返回 `ok`，执行成功概率满足
```
P_success ≥ 1 - ε_safe - δ_sem - Σ_d (1-ρ_min(d)) - P(δ_a > Θ_a)
            - P(H(ι|u,c) > θ_H 且未澄清)
```
关键：**语义可行不蕴含动力学可行，动力学可行不蕴含语义正确**；证书必须同时闭合两条边，澄清是唯一能在闭环内降低语义不确定性的算子。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 意图后验校准 | ECE / n-best 覆盖 | ECE ≤ 0.05；覆盖 ≥ 95% |
| E163 语义-动力学一致性 | SD、语义违背率 | SD ≥ 0.85；违背 ≤ 5% |
| E164 轨迹可行性鲁棒性 | 扰动下成功率、m_dyn 分布 | 成功率 ≥ 95%；P(m_dyn<0) ≤ 2% |
| E165 澄清策略效率 | 任务成功率 vs 平均追问次数 | 成功率 +15%；≤ 1.2 次/任务 |
| E166 端到端语音任务 | 任务成功率、P95 延迟 | 较基线 +18%；P95 ≤ 200ms |
| E167 语言鲁棒性 | ASR 噪声/口音/复述下性能保持 | 退化 ≤ 8%；ρ_lang ≥ ρ_min |

**消融**：去掉意图分布（top-1 硬解析）→ 预期 H22 错配率上升；去掉澄清 → 预期高歧义任务失败率上升；去掉 DRLT → 预期噪声语音下 SD 方差增大。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 意图后验欠校准导致证书虚高 | 高 | 温度标定 + 分布外检测 + 拒识 |
| 语义签名 B 与真实意图错位 | 高 | 人类可读签名 + 反事实轨迹人工抽检 |
| 澄清打断过多、体验差 | 中 | 净收益阈值 + 批量槽位确认 + 学习成本模型 |
| 轨迹优化非凸/局部极小 | 中 | 多暖启动 + 约束松弛诊断 + 回退安全轨迹 |
| 云边轨迹映射漂移 | 高 | 边端 MPC 在线校验 + 语义一致性绊线 |
| 噪声语音造成后验震荡 | 中 | 时序平滑 + 对话状态机 + 澄清锚点 |

## 6. 本轮最大风险

**一句话**：把语音建模为意图分布并做意图条件轨迹优化，能把“听懂”和“做到”统一进一张证书，但其 soundness 依赖 **意图后验校准、行为签名可解释、约束收紧覆盖真实扰动** 三者同时成立；一旦后验过度自信或签名把“危险但像对”的轨迹判成高 SD，系统会把一次误识别固化为一条动力学上流畅、语义上错误的轨迹，故必须以 **校准+拒识、反事实轨迹审计、以及语义一致性绊线** 为硬护栏，宁可多问一句，也不让“听起来对”的轨迹获得部署证书。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（VIP×ICTO×SDC×CIA×DRLT×TVC）

> 承接第 54 轮产物 v31。本轮在 **动作空间剖面 + 云边动作双证书** 之上，增加 **语音意图分布、意图条件轨迹优化、语义-动力学一致性、主动澄清、语言鲁棒性与轨迹-语音联合证书** 六个算子：
> - **VIP（Voice Intent Profiling）**：把语音解析为校准的意图后验 `p(ι|u,c)` 与歧义熵；
> - **ICTO（Intent-Conditioned Trajectory Optimization）**：在意图约束集上做分布鲁棒轨迹优化，输出轨迹族与动力学裕度；
> - **SDC（Semantic-Dynamic Consistency）**：把轨迹投影回行为签名，度量语义一致性；
> - **CIA（Clarification Interaction Algorithm）**：以期望信息增益×决策价值决定是否/如何追问；
> - **DRLT（Distributionally Robust Language-Trajectory）**：Wasserstein 球内的语言鲁棒性谱 `ρ_lang`；
> - **TVC（Trajectory-Voice Joint Certificate）**：`(p_ι,ξ*,m_dyn,SD,ρ_lang,clarify_trace,evidence)` 联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/117/118 以纳入语音-轨迹维度。
> 定位：第 54 轮解决“动作能不能组合”，本轮解决“语音要求的那条轨迹到底是不是用户要的、并且做得到”。

### IP-121 VIP

```python
def voice_intent_profile(u, asr_nbest, context, parser):
    candidate = []
    for hyp, w in asr_nbest:
        for intent in parser.parse(hyp, context):
            candidate.append((intent, w * intent.score))
    p = normalize_weights(candidate)
    H = -sum(q * log(q) for q in p.values())
    conf = 1.0 - H / log(max(2, len(p)))
    return IntentPosterior(p=p, entropy=H, confidence=conf,
                           calibrated=calibration_check(p, u))
```

### IP-122 ICTO

```python
def icto(p_intent, x0, goal, dyn_model, constraints, delta_sem):
    tightened = tighten_by_quantile(constraints, p_intent, beta=0.95)
    seeds = []
    for intent, _ in topk(p_intent, k=3):
        seeds.append(solve_constrained(x0, goal,
                                       behavior_set(intent),
                                       tightened, dyn_model))
    xi = polish_dro(seeds, p_intent,
                    radius=wasserstein_radius(p_intent),
                    lambda_w=1.0)
    m_dyn = min_constraint_slack(xi, dyn_model, tightened)
    while m_dyn < 0:                       # 可行域收缩重试
        tightened = shrink_style_box(tightened, factor=0.9)
        xi, m_dyn = polish_dro(seeds, p_intent, ...), min_constraint_slack(xi, dyn_model, tightened)
    return TrajectoryFamily(seeds, xi, p_intent), m_dyn
```

### IP-123 SDC

```python
def semantic_dynamic_check(xi, p_intent):
    b = behavior_signature(xi)             # 可解释低维签名
    sd, per_intent = 0.0, {}
    for intent, prob in p_intent.items():
        s = similarity(b, behavior_set(intent))   # 核/负距离→[0,1]
        per_intent[intent] = s
        sd += prob * s
    return SemanticReport(sd=sd, violation=1.0 - sd,
                          per_intent=per_intent,
                          counterfactuals=worst_intent_trajectories(xi, p_intent))
```

### IP-124 CIA

```python
def clarification_decision(p_intent, H, xi_family, cost_model):
    if H <= theta_H:
        return Decision(ask=False, intent=argmax(p_intent))
    best = None
    for q in feasible_questions(p_intent):
        ig = expected_information_gain(p_intent, q)
        v = decision_value(p_intent, q, xi_family)   # 意图分裂对轨迹代价的影响
        net = ig * v - cost_model.ask(q) - cost_model.latency(q)
        if best is None or net > best.net:
            best = Clarify(q=q, net=net, ig=ig)
    if best and best.net > 0:
        return Decision(ask=True, question=best)
    return Decision(ask=False, intent=argmax(p_intent), monitor=True)
```

### IP-125 DRLT

```python
def language_robustness(traj_policy, p_intent, perturbations, rho_min):
    rho_lang = {}
    for dim, pert in perturbations.items():
        worst = None
        for p_w in wasserstein_ball(p_intent, radius=rho_ball, n_samples=N_W):
            xi = traj_policy(p_w)
            s = evaluate(xi, dim, pert)     # 成功率/跟踪误差/安全裕度
            worst = s if worst is None else min(worst, s)
        rho_lang[dim] = worst
    ok = all(v >= rho_min for v in rho_lang.values())
    return ('ok' if ok else 'reject'), rho_lang
```

### IP-126 TVC

```python
def trajectory_voice_certificate(u, p_intent, xi, m_dyn, rho_lang, trace):
    report = semantic_dynamic_check(xi, p_intent)
    if not p_intent.calibrated:
        return Reject('intent_uncalibrated', p_intent.calibration_error)
    if report.sd < theta_sem:
        return Reject('semantic_mismatch', report.sd, report.counterfactuals)
    if m_dyn < 0:
        return Reject('dynamic_infeasible', m_dyn)
    bad = {d: v for d, v in rho_lang.items() if v < rho_min}
    if bad:
        return Reject('language_robustness_fail', bad)
    return Ok(TVC(p_intent=p_intent, xi=xi, m_dyn=m_dyn, sd=report.sd,
                  rho_lang=rho_lang, clarify_trace=trace,
                  evidence=(cloud_icto_log, edge_mpc_log, report.counterfactuals)))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VIP | O(\|n-best\|·\|𝔏\|+\|𝔏\|log\|𝔏\|) | O(\|𝔏\|) | 后验校准、n-best 覆盖 ≥95% |
| ICTO | O(k·T_opt+N_W·T_dro) | O(\|ξ\|·k) | 分位收紧 sound、鲁棒半径有界 |
| SDC | O(\|𝔏\|·\|B\|) | O(\|B\|) | `B` Lipschitz、`sim∈[0,1]` |
| CIA | O(\|Q\|·\|𝔏\|) | O(\|𝔏\|) | IG 估计校准、成本非负 |
| DRLT | O(\|𝔇_ρ\|·N_W·T_opt) | O(\|𝔇_ρ\|) | 球覆盖真实漂移 |
| TVC | O(\|𝔏\|·\|B\|+\|𝔇_ρ\|·N_W) | O(\|𝔏\|+\|B\|) | 各分量独立可审计 |

**正确性定理（Voice-Conditioned Trajectory Soundness）**
在第 53–54 轮 (A22)–(A28) 基础上假设：**(A29)** 意图后验校准（ECE ≤ ε_cal）；**(A30)** 行为签名 `B` 为 `L_B`-Lipschitz；**(A31)** 约束收紧覆盖后验误差与执行扰动；**(A32)** 澄清回答真实且延迟 ≤ τ_ask。则 `TVC.ok` 蕴含
```
P_success ≥ 1 - ε_safe - δ_sem - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a)
            - P(H>θ_H 且未澄清)
```
且 `TVC.reject` 的原因可归因到四类之一：意图未校准、语义不匹配、动力学不可行、语言鲁棒性不足。

## 5. 三角闭合与工程接口

```
        𝔏 意图空间
       /   p(ι|u,c)
      / G          ↖ B（回读）
     ↓               \
    𝔗 轨迹空间 ──Π──→ 𝔄 动作空间
        ξ(t)            α_S(a|ι)
```
- `G`（接地）：意图 → 约束轨迹族（ICTO）；
- `Π`（前向）：轨迹 → 动作序列/剖面（与 IP-115+ 联动）；
- `B`（回读）：轨迹 → 行为签名 → 语义一致性（SDC）。
工程接口：云端输出 `TVC` 草案 + `ξ*`；边端 MPC 每 `Δt` 重算 `SD` 与 `m_dyn` 的在线下界，跌破阈值即冻结执行并携带 `clarify_trace` 请求澄清。所有 `Reject` 必须附反事实轨迹，便于人类审计“到底哪句没听懂”。

## 7. 本轮最大风险

**一句话**：意图分布 + 意图条件轨迹优化 + 联合证书把“听懂”和“做到”统一成可审计闭环，但其 soundness 依赖 **意图后验校准、行为签名可解释、约束收紧覆盖真实扰动** 同时成立；一旦后验过度自信或签名把“危险但像对”的轨迹判成高 `SD`，系统会把一次误识别固化为动力学流畅、语义错误的轨迹，故必须以 **校准+拒识、反事实轨迹审计、语义一致性绊线** 为硬护栏，宁可多问一句，也不让“听起来对”的轨迹拿到部署证书。
