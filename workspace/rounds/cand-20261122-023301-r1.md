# 第 1 轮（新灵感循环第 1 轮；基线 v20；本轮灵感：「手眼标定」×「运动规划」）

> **基线**：v20 产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（感知层：PCA / CTS / CFC / HPC / CFCtrl；定义 767–820；引理 151–156；实验 E751–E770）。
> 本轮纪律：**标定不是常量，而是规划状态；运动不是标定的敌人，而是标定的实验**。不推倒 v20：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v19 的 DCM/OGCC/CCV/DRS/OGC、v20 的 PCA/CTS/CFC/HPC/CFCtrl 全部保留。本轮只做一件事：**把手眼标定误差从「离线一次性常量 + 固定安全裕度」改写为「随规划演化的置信集」，并让运动规划同时承担任务与标定可观测性**。

## 0. 直觉与动机

**灵感 1（手眼标定 → 误差不是一个数，而是从光心张开的一个锥）**

直觉：手眼标定给出 `T_EC`，但真实值永远带误差。工程上通常「标定一次 + 加固定 1cm 裕度」。这个做法有两个隐含错误：(a) 旋转误差对点的影响随距离 `r` 线性增长（`r·ω`），远处点的位置误差远大于近处；(b) 深度尺度误差也随距离增长（`r·s`）。所以真正该膨胀的不是一个常数，而是**从相机光心张开的不确定锥**。核心创新：**标定感知碰撞证书 (Calibration-Aware Collision Certificate, CACC)**。把碰撞查询从配置空间 `Q` 提升到 `Q×Δ`（配置 × 标定置信集），用与距离相关的膨胀半径 `ε(r)=b_max+r(ω_max+s_max)` 包住观测面；只要机器人离「被 `ε(r)` 膨胀后的观测面」有正间隙，就对**所有** `δ∈Δ` 安全。关键反直觉点：**更好的标定不等于更安全，更「诚实」的标定误差模型才更安全**——把误差当成距离函数，比把误差当成常数更保守，却反而更少牺牲活性（近处几乎不膨胀，远处才张开）。

**灵感 2（运动规划 → 轨迹既是任务，也是标定实验）**

直觉：eye-in-hand 的手眼标定本来就要「动起来」才能辨识 `T_EC`；纯平移不激励旋转参数，绕光轴旋转也可能退化。传统流水线是「先标定、再规划」，把两者切成两段，于是标定精度与任务活性互相争夺时间预算。核心创新：**自标定运动规划 (Self-Calibrating Motion Planning, SCMP)**。规划器在满足「当前 `Δ` 下绝对安全」的硬约束下，额外最大化轨迹的**标定可观测性** `O(ξ)=λ_min(I_0+Σ_e I_e(ξ_e))`；Fisher 信息对独立观测可加，因此可以像路径长度一样沿边累加进 RRT* 的代价。关键反直觉点：**为了更安全，反而要主动走入「信息更丰富」的区域**——因为观测让 `Δ` 收缩，`Δ` 收缩让未来安全集变大；安全不是靠「远离未知」，而是靠「在已知安全的前提下把未知变小」。

**灵感 3（二者统一 → 标定是一个随规划单调收缩的置信序列）**

直觉：若把标定当成一次性常量，那么所有误差都必须一次性用裕度吃掉；若把标定当成**随观测更新的状态**，误差就可以被「分期偿付」：每一步只用当前 `Δ_t` 认证安全，观测只允许往 `Δ_t` 上再交一个置信集（`Δ_{t+1}⊆Δ_t`），于是不确定性单调收缩，而安全集只在**真实安全集的上界内**随收缩而扩张。统一状态 `ζ_cal=(b_t(δ), Δ_t, I_t, drift_stat, mode_cal)`。CACC 回答「当前标定不确定下 `q` 是否鲁棒安全」，SCMP 回答「哪条安全轨迹能最快缩小 `Δ`」，CDM 回答「`Δ` 是否已漂移到不可信」。统一接口：**若 CACC 通过且 CDM 未报警，SCMP 的边进入 v20 的 CCV/CSC；否则退回 v20 的固定裕度路径**。

**为什么这不是又一个「加裕度」**

v19/v20 回答的是：给定几何与感知，参数 `θ`（或计划）是否安全。v21 回答的是：给定**标定潜变量**及其在运动下的演化，**整条轨迹**是否对当前置信集内的一切标定都安全，以及执行这条轨迹能否在不越出已认证安全集的前提下缩小该置信集。这是**规划层**而非碰撞检查层的贡献：它把「误差」从要一次性吃掉的成本，变成可以被轨迹主动管理的状态。

## 1. 研究问题（轮次升级版）

- **Q1（CACC 的保守性与紧致性）**：锥形膨胀 `ε(r)` 如何同时保证 soundness（不漏掉真实碰撞）与紧致性（不在近场过度保守）？旋转二阶项、深度尺度、观测面法向各向异性如何进入界？如何在 v20 的盲区保守包络之上叠加而不重复膨胀？

- **Q2（SCMP 的可观测性与安全耦合）**：Fisher 信息如何沿 RRT* 的边可加并保持最优子结构？纯平移、绕光轴旋转等退化如何被显式排除？信息增益目标会不会诱导规划器进入「信息多但危险」的区域，硬安全约束如何保证不越界？

- **Q3（置信序列的有效性）**：如何构造 anytime-valid 且单调嵌套的 `Δ_t`，使序列更新后仍以高概率包含真值？在非高斯、离群、系统偏差下如何保持有效，而不是把真值排除在收缩后的置信集外？

- **Q4（漂移与联邦共模）**：标定漂移是跨机器人的**共模误差**，会直接破坏 v20 CFC 的独立性假设；CDM 如何检测？如何用异构标定/多传感器冗余恢复共识独立性，而不只是增加投票者数量？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 标定锥保守律（Calibration Cone Conservatism）**

对 `δ=(ω,b,s)∈Δ`，观测点 `p_s`（距光心 `r=||p_s||`）在标定扰动下的世界坐标位移满足
`||Δp_w|| ≤ b_max + r·(ω_max+s_max) + O(r·ω_max²)`。
定义 `ε(r)=b_max+r·(ω_max+s_max)`，`Obs_cal=⋃_{p∈Obs} Ball(p, ε(||p||))`。
CACC 的安全判据为 `clearance(q, Obs_cal) > 0`（并叠加 v20 的盲区/联邦约束）。则 `∀δ∈Δ, Safe(q;δ)` 成立。**证书只能因 `ε` 而收缩，不能因标定点估计而扩张**。

**P35 可观测—安全分离律（Observability-Safety Separation）**

规划目标 `J(ξ)=J_task(ξ)+λ·J_info(ξ)`，其中 `J_info(ξ)=-logdet(I_0+Σ_e I_e(ξ_e))`，`I_e` 为边 `e` 的 Fisher 信息。安全是**硬约束**（CACC 在 `Δ_t` 下通过），信息是**软目标**。因此信息增益不能把执行集推出认证安全集。**可观测性只能在安全集内部重排序轨迹，不能扩大安全集**。

**P36 嵌套置信序列律（Nested Confidence Sequence）**

维护 anytime-valid 的置信集族 `{Δ_t}`，并强制 `Δ_{t+1}⊆Δ_t`（对椭球约束取交集）。每段重规划只用当前 `Δ_t` 认证；因 `δ*∈Δ_t`（以概率 `≥1-α`），该段安全。**不确定性单调收缩；安全集只在其真实上界内随收缩而扩张，绝不越过 `Safe_true`**。冻结 `Δ` 时，v21 退化为 v20。

## 3. 与基线的接口（如何退化）

- CACC 失效（无协方差/无标定先验）⇒ 退化为 v20 的固定裕度碰撞检查 ⇒ 等价 v20；
- SCMP 失效（Fisher 不可用）⇒ 只做任务规划 + CACC ⇒ 等价「v20 + 锥形膨胀」；
- CDM 失效（漂移不可检测）⇒ 退回固定 `Δ_0`，活性下降但保守；
- CRF 失效（联邦不可用）⇒ 只用本地观测的 `Δ` ⇒ 等价 v20 的本地保守；
- 全部失效 ⇒ 完全回退到 v20 的 PCA/CCV ⇒ 等价 v20；
- **安全继承**：CACC 只做膨胀、SCMP 只在安全集内重排、CDM 只做回退、CRF 只做鲁棒化；任一时段的执行计划都 ⊆ `Safe_true`，冻结 `Δ` 时 `Exec_v21 = Exec_v20`（引理 162）。

## 4. 预期贡献

1. **标定锥**：首次把手眼误差写成随距离张开的锥形不确定集，给出 sound 且紧致的碰撞膨胀，避免「近场过度保守、远场仍然不安全」的固定裕度悖论；
2. **自标定运动规划**：任务轨迹兼作标定实验，Fisher 信息沿 RRT* 边可加，硬安全约束下用信息增益换取活性；
3. **嵌套置信序列**：给出 anytime-valid、单调收缩的 `Δ_t`，把「安全集扩张」严格封顶在真实安全集，区分「不确定性收缩」与「安全被削弱」；
4. **漂移与共模故障**：把标定漂移识别为跨机器人共模误差，直接修补 v20 CFC 的相关性盲点，并用异构标定恢复独立性；
5. **标定鲁棒的联邦感知/谱系**：用 `Δ` 包裹 v20 的 PCA/CTS，得到 calibration-robust HPC 与 `γ_robust`；
6. **可验证的「标定—规划」闭环**：CACC/SCMP/CDM/CRF 嵌入 v20 的 APS/CFCtrl，`Exec_v21` 的安全性与活性来源都可审计。

## 5. 本轮最大风险

**一句话**：整套保证都建立在「`δ*` 以高概率落在 `Δ_t` 内」之上；若真实标定误差含未建模的系统偏差（非零均值、非高斯、非刚性安装、深度尺度漂移），则 `Δ_t` 会过度自信地收缩，CACC 从保守退化为不安全——**越主动地「标定得更准」，越可能把真值排除在置信集外**。

# IP-426 Calibration Uncertainty Set (CUS)
class CalibrationUncertaintySet:
    """
    Δ 表示为一组椭球约束的交集：
        Δ = ∩_i { δ : (δ-δ̂_i)^T Σ_i^{-1} (δ-δ̂_i) ≤ c_i }
    交集保证嵌套：新增约束只会缩小 Δ。
    """
    def __init__(self, constraints):
        # constraints: list[(delta_hat(7), Sigma(7x7), chi2)]
        self.constraints = list(constraints)

    def block_radii(self):
        """交集 ⊆ 每个椭球，故取各椭球分块半径的最小值作为保守上界。"""
        w = b = s = float("inf")
        for delta_hat, Sigma, c in self.constraints:
            w = min(w, math.sqrt(c * np.linalg.eigvalsh(Sigma[0:3, 0:3]).max()))
            b = min(b, math.sqrt(c * np.linalg.eigvalsh(Sigma[3:6, 3:6]).max()))
            s = min(s, math.sqrt(c * Sigma[6, 6]))
        return w, b, s

    def cone_radius(self, r):
        w, b, s = self.block_radii()
        return b + r * (w + s)

    def update_nested(self, delta_hat, Sigma, chi2):
        """单调嵌套更新：只加约束、不删约束。"""
        return CalibrationUncertaintySet(
            self.constraints + [(delta_hat, Sigma, chi2)])

    def add_drift_ball(self, radius):
        """漂移只会让 Δ 变大；为安全起见，膨胀量进入 b_max 的加性项。"""
        return CalibrationUncertaintySet(
            self.constraints + [(np.zeros(7), radius**2 * np.eye(7), 1.0)])


# IP-425 Calibration-Aware Collision Certificate (CACC)
class CalibrationAwareCollisionCertificate:
    def __init__(self, v20_cert, cus, observed_points, fk, T_ec, robot_sdf):
        self.v20 = v20_cert                 # v20 的盲区/联邦/谱系约束
        self.cus = cus
        self.observed_points = observed_points
        self.fk = fk
        self.T_ec = T_ec
        self.robot_sdf = robot_sdf

    def clearance(self, q):
        T = self.fk(q) @ self.T_ec
        min_clear = float("inf")
        for p_s in self.observed_points:
            r = float(np.linalg.norm(p_s))
            eps = self.cus.cone_radius(r)          # 距离相关锥
            p_w = T @ p_s
            d = self.robot_sdf.distance(p_w)       # 机器人表面到观测点
            min_clear = min(min_clear, d - eps)
        return min_clear

    def check(self, q):
        # 硬约束：v20 证书 + 标定锥，二者都过才算安全
        return self.v20.check(q) and self.clearance(q) > 0.0

    def lipschitz_constant(self):
        # ||∂clearance/∂q|| ≤ ||∂FK/∂q|| · max_r(1 + dε/dr)
        w, b, s = self.cus.block_radii()
        jac_fk = self.fk.jacobian_bound()          # max_q ||∂FK/∂q||
        r_max = max(float(np.linalg.norm(p)) for p in self.observed_points)
        return jac_fk * (1.0 + (w + s) * r_max)

    def edge_safe(self, q0, q1, K=16):
        """连续边认证：采样 + Lipschitz 下界。"""
        L = self.lipschitz_constant()
        seg = float(np.linalg.norm(q1 - q0)) / K
        c_min = float("inf")
        for i in range(K + 1):
            q = q0 + (q1 - q0) * (i / K)
            c_min = min(c_min, self.clearance(q))
        return c_min - 0.5 * L * seg > 0.0


# IP-428 Calibration Observability Estimator (COE)
class CalibrationObservabilityEstimator:
    def __init__(self, sigma_obs):
        self.sigma_obs_inv = np.linalg.inv(sigma_obs)

    def edge_information(self, q0, q1, steps=4):
        """沿边数值积分残差对 δ 的 Jacobian，返回 Fisher 信息 I_e。"""
        I_e = np.zeros((7, 7))
        for i in range(steps + 1):
            q = q0 + (q1 - q0) * (i / steps)
            J = self._residual_jacobian(q)          # d residual / d delta
            I_e += J.T @ self.sigma_obs_inv @ J / (steps + 1)
        return I_e

    def index(self, I_total):
        return float(np.linalg.eigvalsh(I_total).min())

    def is_degenerate(self, I_total, eps=1e-3):
        # 纯平移 / 绕光轴旋转会使 I 秩亏，λ_min→0
        return self.index(I_total) < eps


# IP-427 Self-Calibrating Motion Planner (SCMP)
class SelfCalibratingMotionPlanner:
    def __init__(self, cacc, coe, lam=0.1, gamma=0.9):
        self.cacc = cacc
        self.coe = coe
        self.lam = lam                 # 信息项权重
        self.gamma = gamma             # 信息折扣

    def plan(self, q_start, q_goal, I_prior, budget=2000):
        nodes = [Node(q=q_start, parent=None, I=I_prior, cost=0.0)]
        for _ in range(budget):
            q_rand = self._sample()
            near = self._nearest(nodes, q_rand)
            if not self.cacc.edge_safe(near.q, q_rand):
                continue
            I_e = self.coe.edge_information(near.q, q_rand)
            I_new = near.I + I_e
            info_cost = -self.lam * math.log(max(1e-12, np.linalg.det(I_new)))
            new = Node(q=q_rand, parent=near, I=I_new,
                       cost=near.cost + np.linalg.norm(q_rand - near.q) + info_cost)
            # 退化保护：可观测性不足时拒绝该扩展
            if self.coe.is_degenerate(I_new):
                continue
            nodes.append(new)
            self._rewire(nodes, new)   # 标准 RRT* 重连，代价含 info_cost
        return self._extract_path(nodes, q_goal)


# IP-429 Calibration Drift Monitor (CDM)
class CalibrationDriftMonitor:
    def __init__(self, cus, kappa=0.01, h=5.0, k=0.5, ttl_cal=2.0):
        self.cus = cus
        self.kappa = kappa
        self.h = h
        self.k = k
        self.ttl_cal = ttl_cal
        self.cusum = 0.0

    def drift_radius(self, dt):
        return self.kappa * dt

    def update(self, residual, Sigma_res, dt):
        z = float(residual.T @ np.linalg.inv(Sigma_res) @ residual)
        self.cusum = max(0.0, self.cusum + (z - 1.0) - self.k)
        if self.cusum > self.h:
            return "DRIFT_DETECTED"
        return "OK"

    def integrate_with_cfctrl(self, plan, hpc, now):
        # 与 v20 CFCtrl 的 TTL 对齐：标定认证过期即回退 v20
        if now - hpc.tau_cal > self.ttl_cal:
            return "V20_CAL_EXPIRED"
        return "NORMAL"


# IP-430 Calibration-Robust Federation (CRF)
class CalibrationRobustFederation:
    def __init__(self, pca, cts, cus):
        self.pca = pca
        self.cts = cts
        self.cus = cus

    def robust_hull(self, contributions, node, obj):
        """用 Δ 膨胀每个贡献的观测面，再交给 v20 PCA 聚合。"""
        inflated = []
        for c in contributions:
            eps = max(self.cus.cone_radius(float(np.linalg.norm(p)))
                      for p in c.points)
            inflated.append(c.with_obstacle_dilation(eps))
        return self.pca.aggregate(inflated, node, obj)

    def robust_similarity(self, o1, o2):
        """γ_robust = min over Δ；用椭球极端点/区间算术求下界。"""
        gammas = [self.cts.similarity(o1, o2, delta=d)
                  for d in self.cus.extreme_points()]
        return min(gammas) if gammas else 0.0

    def robust_transfer(self, node, theta_src, obj_src, obj_tgt):
        gamma = self.robust_similarity(obj_src, obj_tgt)
        if gamma < self.cts.gamma_threshold:
            return None, "SPECTRUM_MISMATCH_ROBUST"
        return self.cts.transfer_domain(node, theta_src, obj_src, obj_tgt)

## 3. 推导

**引理 157（标定锥的 soundness）**
对 `δ=(ω,b,s)∈Δ`，令 `R=Rot(T_EC)`、`p=R p_s`。一阶展开 `Δp_w ≈ p×ω + b + s·p`，故 `||Δp_w|| ≤ r·||ω|| + ||b|| + r|s| + O(r||ω||²) ≤ ε(r)`。若 `clearance(q,Obs_cal)>0`，则机器人到每个观测点的距离大于 `ε(r)`，即对任意 `δ∈Δ` 观测点都不可能进入机器人几何。故 `Safe_robust(q;o)` 成立，且 `ColDom_cacc ⊆ Safe_true`（当 `δ*∈Δ`）。∎

**引理 158（锥形膨胀的近场紧致性）**
当 `r→0` 时 `ε(r)→b_max`，膨胀只由平移误差决定；当 `r` 增大时 `ε` 线性张开。对比固定裕度 `ε_0`：若要覆盖最远点需 `ε_0 ≥ b_max+r_max(ω_max+s_max)`，则在近场 `r≪r_max` 处锥形膨胀比固定裕度小 `r_max(ω_max+s_max)-r(ω_max+s_max)`。故 CACC 在近场严格更紧致，且不牺牲远场 soundness。∎

**引理 159（SCMP 的安全分离）**
SCMP 的每条接受边先通过 `cacc.edge_safe`（硬约束），信息项只进入 `cost` 的排序，不进入可行性判定。因此 `Exec_v21 = {ξ : ξ 的每条边均 CACC-safe}`，与信息项无关；信息项只在同一可行集内改变路径选择。故信息增益不能扩大安全集。∎

**引理 160（Fisher 可加与退化）**
独立观测的 Fisher 信息相加：`I_total=I_0+Σ_e I_e`。`logdet` 在正定锥上单调（`A⪰B≻0 ⇒ logdet A≥logdet B`），故沿边累加 `I_e` 与累加路径长度同样保持 RRT* 的最优子结构。若 `λ_min(I_total)→0`，则存在非零 `δ` 方向不被任何观测约束（如纯平移不激励旋转、绕光轴旋转退化），COE 判为 `DEGENERATE` 并拒绝该扩展。∎

**引理 161（嵌套置信序列的 soundness）**
设 `{Δ_t}` 为 anytime-valid 置信序列，`P(∀t: δ*∈Δ_t) ≥ 1-α`，且 `Δ_{t+1}⊆Δ_t`。第 `t` 段计划只在 `Δ_t` 下认证，故若 `δ*∈Δ_t`，该段执行安全。由 anytime-valid 性质，整段执行以概率 `≥1-α` 安全，无需对时间做 union bound。∎

**引理 162（v21 的继承与活性）**
若冻结 `Δ_t=Δ_0`，CACC 退化为 v20 的固定裕度碰撞检查，SCMP 的信息项不改变可行集，故 `Exec_v21=Exec_v20`。若 `Δ_t⊊Δ_0`，CACC 的膨胀变小，`Exec_v21` 可在 `Safe_true` 内大于 `Exec_v20`，但由引理 157 恒有 `Exec_v21(t)⊆Safe_true`。故**安全性始终成立，活性只在已认证信息收缩后、且不越过真实安全集时增加**。∎

**引理 163（漂移的可检测性，条件性）**
设真实漂移使残差均值偏移 `μ_d`，噪声协方差 `Σ_res`。则 `E[z_t] ≈ 1 + μ_d^T Σ_res^{-1} μ_d`。CUSUM 的期望检测延迟约为 `h/(μ_d^T Σ_res^{-1} μ_d - k)`（当该量 `>0`）。若漂移落在噪声底 `μ_d^T Σ_res^{-1} μ_d ≤ k`，则不可检测；此时 CDM 只能依赖 `TTL_cal` 回退。∎

## 7. 已知风险与失效模式

1. **置信集过度自信**：`Δ_t` 假设误差零均值/高斯/刚性安装；真实系统存在非零均值偏差、深度尺度漂移、非刚性支架时，`Δ_t` 会收缩到不含真值，CACC 从保守变为不安全。缓解：偏差项显式建模、保守先验、`TTL_cal` 硬回退、在线残差检验。

2. **锥界过松**：`ε(r)=b_max+r(ω_max+s_max)` 用分块最大范数，忽略方向与协方差耦合，在高各向异性场景会过度保守。缓解：支撑函数/椭球方向投影、按观测面法向的分向膨胀。

3. **Fisher 模型失配**：`I_e` 依赖噪声模型与残差 Jacobian；若观测存在离群或相关噪声，Fisher 会高估信息，导致 SCMP 误以为可观测性足够。缓解：鲁棒 Fisher、Huber 权重、退化检测双阈值。

4. **信息项诱导风险**：虽然安全是硬约束，但信息项可能把轨迹推向安全边界附近（信息丰富区常在遮挡/近障碍处），增加对 CACC 界精度的依赖。缓解：在安全集内再加一层 `η`-margin，限制信息项的最大影响。

5. **嵌套更新导致过度保守**：对椭球取交集会使 `Δ_t` 在模型不匹配时收缩过慢或过快。缓解：按约束可信度加权、定期用新数据重置序列、显式检测「交集为空」。

6. **漂移检测的噪声底盲区**：慢漂移低于 CUSUM 参考值 `k` 时不可检测（引理 163），只能靠 `TTL_cal`。缓解：多时间尺度 CUSUM、温度/电流等外因相关变量辅助、定期主动标定。

7. **共模误差破坏联邦独立性**：v20 CFC 的 `F=⌊(N-1)/3⌋` 假设故障独立；标定误差是跨机器人共模变量，会让所有机器人同向误判。缓解：异构安装/传感器、共模检测器、把标定偏差作为显式共识维度而非独立投票。

## 8. 本轮最大风险

**一句话**：整套保证都建立在「`δ*` 以高概率落在 `Δ_t` 内」之上；若真实标定误差含未建模的系统偏差（非零均值、非高斯、非刚性安装、深度尺度漂移），则 `Δ_t` 会过度自信地收缩，CACC 从保守退化为不安全——**越主动地「标定得更准」，越可能把真值排除在置信集外**。
