# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「云边协同」×「安全交互」）

> R69 教会系统「问」：aleatoric 收紧、epistemic 交给主动多模态交互消解。但它默认**回答者就在身边、回答瞬时到达、回答天然可信**。真实部署里，最有能力回答「这是什么、这句话什么意思、这类场景通常怎么办」的往往不在边上，而在云上；可一旦把问题送出设备，代价与风险同时出现——延迟让答案过期，链路让答案可被篡改/重放，远端模型可能与端侧版本不一致，原始观测外传还会泄露隐私。于是 R69 的「问对了吗」必须升级为 R70 的「**该在哪里问、什么时候到的答案还算数、当答案来自别处时谁说了算**」。
>
> 本轮两个灵感各补一块：
> - **云边协同**：给不确定性增加一条与 aleatoric/epistemic 正交的轴——**信息半衰期 λ_info**。快变的动态歧义留在边缘（低延迟、本地闭环），慢变的语义/全局歧义送上云（大模型、全局先验）。分工不是「算力不够就上云」，而是按「答案在多久内仍然为真」来分。
> - **安全交互**：把 R69 面向人的证据纪律（k 源一致、投毒集）延伸到面向基础设施的交互——**互相认证、新鲜性、证明携带、通道正交、最小披露**。云端不是一个「可信答案」，而是一个必须被验证的证据源。
>
> 核心命题：**以「信息半衰期」划分云边认知劳动，以「截止期-时滞折扣 VoI」决定是否/何时把问题送出，以「证明携带 + 通道多样性」保证送回来的答案可验证；控制权始终留在边缘，云端只有建议权。任何网络失败/过期/不可信/版本偏斜都逐指令退化为 R69，再退化为 R68。** 命名 **LATTICE-RAS**（Latency-Aware Trusted Tandem Interaction for Cloud-Edge disambiguation）。
>
> 一句话定位：R66 问「谁控制」，R69 问「该向谁求证」，R70 问「**该在哪里求证、迟到的答案是否还算答案、权威是否随答案一起转移**」。本轮最锋利的洞见：**认证保证「是谁说的」，保证不了「现在还对不对」。**

## 0. 直觉与动机

**灵感 1（云边协同 → 按信息半衰期分工，而不是按算力分工）**
直觉：不是所有「不知道」都一样「耐放」。门后是谁（动态、快变，半衰期几十毫秒）只能在边缘靠注视/探针当场解决；这个物体属于哪一类、这句含混指令在人类惯例里通常指什么（语义、慢变，半衰期数小时到数年）适合交给云的大模型与全局先验。若把快变问题送上云，等答案回来世界已经变了；若把慢变问题全压在边缘，则本地样本永远不够。于是 R69 的 U_epi 被进一步按**信息半衰期 λ_info** 分解为 U_epi^fast 与 U_epi^slow，云边分工由 λ_info 与往返时延 τ_RTT 的比值决定，而不是由「云算力更强」这一模糊直觉决定。这把「云边协同」从部署话题变成一个有判据的**认知分工**问题。

**灵感 2（时间进入证据 → 时滞折扣 VoI 与截止期）**
直觉：R69 的 VoI(g) 假设答案一到就能用。但云端答案要经过 τ_RTT 才回来，而当前动作模态可能必须在 H_dec 内提交/锁定。**一个在截止期之后到达的正确答案，对当前决策不是零收益，而是负收益**——它诱使系统在已经不该切换的时刻切换模态，制造突变。所以 VoI 必须乘上「用到时仍然为真」的概率 S(τ)，再减去通信与验证成本：VoI_τ(g) = S(τ|λ_info)·VoI_local(g) − c_comm − c(g)。当 τ_RTT > H_dec 时，云端答案只能转为**后台预取 + 用时再验证**，绝不进入当前决策。这把「延迟」从工程指标提升为**证据有效性的一等维度**。

**灵感 3（权责分离 → 控制权必须在边缘，云端只有建议权）**
直觉：R66 花了很大力气回答「谁控制」，R69 又把「提问」引进来。云边协同会把这个老问题以新形式重新打开：如果云端能返回动作/轨迹，谁对执行负责？答案必须毫不含糊：**执行器只有一个写者——边缘**。云端的输出是观测/证据，不是指令；它必须经过与本地证据相同的模态选择、C-RAS-WM 认证与证据纪律。这样「把问题送出去」不会把「权威」也一起送出去。形式上要求单写者不变式：任何 actuator 命令都由边缘本地认证前缀产生，网络不在实时控制回路中。

**灵感 4（安全交互 → 认证、新鲜、携带证明、通道正交）**
直觉：R69 已经知道人会撒谎，所以要求 k 个正交证据源一致。云端同样会「撒谎」——不是恶意，而是**过期、版本偏斜、幻觉、被投毒**。安全交互因此有四件事：①互相认证，防冒充；②新鲜性（nonce + 单调计数器 + 时间戳），防重放与降级；③**证明携带**——云端返回 y 的同时返回模型哈希、标定统计、输入承诺、时间戳与不确定度，边缘验完才用；④**通道正交**——云语义证据、边缘物理一致性、R69 的行为似然、人的确认，是四条不同通道，云端只能算其中一条，单靠它不得定案。这直接继承 R69 引理 18，但把「投毒」从人扩展到基础设施。

**灵感 5（新裂缝 → 认证不等于新鲜，也不等于仍然为真）**
直觉：这是本轮最重要的自我批判。密码学能保证「这条消息确实来自那台已认证的云、且未被篡改」，但**它保证不了这条消息现在仍然为真**。一个完美签名、完整无损、低延迟返回的答案，可能来自一个落后三个版本的模型，或描述的是 200ms 前的世界，或语义本身已漂移。更糟的是，「已认证」会给系统一种虚假的安全感，让它比「未知」时更大胆。因此本轮把新鲜性、版本一致性与半衰期校准从「工程细节」提升为一等公民，并给出「认证 ≠ 时效」的分离引理。这与 R69 的「问错比不问更危险」构成同构：**信一个过期但认证通过的正确答案，比承认不知道更危险**。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（LATTICE-RAS 总览）** LATTICE-RAS = (S-FMP, HLD, SAV, PCV, AST, TG, EBD, DGX, RAS-WM†)。三不变式：
(i) **单写者与边缘自治**：执行器唯一写者是边缘；网络/云端不在实时控制回路；断网不影响安全闭环；
(ii) **可验证证据**：任何云端证据必须通过 AST 认证、PCV 证明校验、并在新鲜窗口内，否则视为不可用；
(iii) **截止期约束与严格退化**：云端证据仅当 τ_RTT + τ_margin ≤ H_dec 才允许影响当前决策；任一失效则逐指令退化为 R69，再退化为 R68。

**定义 311（信息半衰期与折旧）** 每个信息项 x 具有半衰期 λ_info(x) > 0；定义存活函数 S(τ|x) = exp(−τ/λ_info(x))（或等价的 P(x 在 t+τ 仍为真)），折旧比 ρ(x) = τ_RTT/λ_info(x)。λ_info 由信息类型先验 + 在线估计（定义 322）共同给出，且始终取保守下界。

**定义 312（云边认知分工 HLD）** 把 R69 的 epistemic 不确定性再分解为 U_epi = U_epi^fast ⊕ U_epi^slow：fast = {x : λ_info(x) ≲ H_dec} 留边缘，slow = {x : λ_info(x) ≫ H_dec} 可上云。分配规则 α*(x)：α*(x)=cloud ⇔ S(τ_RTT|x)·ΔH_cloud(x) − c_comm(x) > ΔH_edge(x)，其中 ΔH 为对应通道消解的后验熵降。分工由「耐放 × 更可分」共同决定，而非算力大小。

**定义 313（决策时域与提交窗口）** H_dec(t) 为当前模态在不重新认证前提下可保持的最长时间（由 R68 C-RAS-WM 前缀长度与动作块共同决定）；τ_margin 为验证与执行的安全裕量。云端答案可影响 t 时刻决策 ⇔ τ_RTT + τ_margin ≤ H_dec(t)；否则只能进入 pre-fetch，禁止用于当前提交。

**定义 314（时滞感知 VoI SAV）** VoI_τ(g) = S(τ_RTT(g)|λ_info(g))·[H(M|o) − E_{y~p(·|g,o)}H(M|o,y)] − c_comm(g) − c(g)。选择 g* = argmax_g VoI_τ(g)，s.t. deadline、risk(g) ≤ ε_int、预算未超。若 max VoI_τ ≤ 0 或截止期不满足：不送云，退回 R69 本地交互；本地交互也无利可图则走 R68。

**定义 315（证明携带回答 PCV）** 云端回答 y 附带证明 π = (model_hash, ver, calib_stats, ts, nonce, input_commit, unc, sig)。边缘逐项验证：签名与输入承诺、时间戳新鲜度、版本兼容、标定统计在界内；任一失败 ⇒ y 不可用。云端返回的是「证据 + 证明」，不是「真理」。

**定义 316（认证安全传输 AST）** 会话提供双向认证 + nonce + 单调计数器（防重放/降级）+ 完整性；云端**不得下发执行指令**，仅能返回建议性证据。通道状态 c ∈ {SYNC, DEGRADED, DOWN}；降级攻击（强制边缘接受旧答案）由单调计数器与最小新鲜度门限拒绝。

**定义 317（信任梯度 TG）** T_c ∈ [0,1]，由证明有效性、历史一致性、标定误差、版本、在线时长累积更新；云端回答权重上限为 T_c。T_c < τ_trust ⇒ 视为敌对源（并入 ℰ_cloud），而非简单降权——因为低信任源的「一条看似合理的错误」与 R69 的投毒同构。

**定义 318（通道多样性证据纪律 EBD）** 证据通道 ℰ_ch = {cloud_semantic, edge_physical, flow_likelihood(R69 FMA), human_confirm}。定案需 ≥2 条通道正交一致，或单通道 VoI 增益超过高置信阈值；且**至少一条必须是物理接地通道**（edge_physical 或 flow_likelihood），以防云端与人类相关共谋。R69 的 k 源一致是 EBD 在「无云」时的特例。

**定义 319（单写者与权责分离）** actuator 命令仅由边缘 C-RAS-WM 认证前缀生成：a_t = Edge_Certify(SelectMode(evidence))，且对云端下发内容的直接控制通道为零（∂a/∂cloud_cmd = 0）。云证据只能改变「选哪个模态 / 是否交互」，不能写执行器。

**定义 320（优雅降级状态机 DGX）** 状态 CLOUD_SYNC → EDGE_LOCAL → CONSERVATIVE。触发条件：断链 / τ_RTT 超期 / 证明或认证失败 / T_c 越界 / 版本偏斜 / 隐私预算耗尽。转移时 λ 单调不降；EDGE_LOCAL 与 R69 逐指令一致，CONSERVATIVE 与 R68 一致；禁止从 DOWN 未经一致性重同步直接跳回 SYNC。

**定义 321（版本偏斜与一致性）** 版本偏斜 Δv = |v_e − v_c| 覆盖模型权重、特征 schema、动作归一化。若 Δv > v_max 或 schema 不兼容 ⇒ 云端证据无效。定义跨版本一致率 κ(v_e, v_c) 为共享校准集上的模态一致率；κ 低 ⇒ 下调 T_c、触发重同步或蒸馏，而非静默使用。

**定义 322（信息半衰期估计器 IHE）** 在线估计 λ̂_info：由重复查询一致性、漂移检测与预测误差衰减速率给出，并取高置信保守下界；估计不可靠时默认短半衰期（更保守）。半衰期校准误差 ECE_λ 越界 ⇒ 禁用云证据参与当前决策（R69 MCG 的时间版）。

**定义 323（隐私最小披露 PDP）** 上送的不是原始观测，而是最小充分编码 enc(o)（特征/承诺）；隐私预算 ε_p 逐次消耗，超预算即拒绝上送并回退本地。门控判据：I(enc; M)/L(enc; raw) > γ（信息增益与泄露之比）。

**定义 324（分离式流匹配 S-FMP / 云引导）** 边缘运行快速 ODE；云端可选提供粗模态先验、蒸馏引导或重采样，引导权重 β 受 T_c 与新鲜度约束。云端只提供**分布级先验**，不得提供逐点动作轨迹；边缘必须能完全独立运行（自包含 fallback），以保证边缘自治。

**定义 325（参与式审计 VQAuditor-X 与证书 J_LATTICE）** 审计：上送是否最小披露、答案是否新鲜/认证/被正交验证、权威是否被尊重、版本是否偏斜、半衰期估计是否校准。J_LATTICE = (J_FLUID, session_auth, freshness_age, rtt_p95, half_life_ece, version_hash, privacy_spent, authority_ok)。Valid ⇔ Valid(J_FLUID) ∧ 认证/证明通过 ∧ freshness_age ≤ τ_fresh ∧ authority_ok ∧ ECE_λ ≤ τ_λ。

```python
# IP-264 S-FMP：分离式流匹配（边缘保底，云端只给分布级先验）
class SplitFlowPolicy:
    def sample_edge(self, o_t, K):
        z, xs = self.trunk(o_t), randn(K, D)
        for i in range(2):
            xs = xs + 0.5 * self.v_edge(xs, i/2, z)        # 自包含，断网可用
        return [self.decode(x) for x in xs]

    def sample_with_cloud(self, o_t, K, prior, t_c):
        z, xs = self.trunk(o_t), randn(K, D)
        beta = min(1.0, t_c) * self.prior_freshness(prior)  # 信任×新鲜度双重封顶
        for i in range(2):
            v = self.v_edge(xs, i/2, z) + beta * self.v_guide(xs, i/2, prior)
            xs = xs + 0.5 * v
        return [self.decode(x) for x in xs]

# IP-265 HLD：按信息半衰期把 epistemic 分成 fast/slow
def split_by_half_life(modes, lam_info, H_dec):
    fast = [x for x in modes if lam_info[x] <= H_dec]        # 边缘当场解决
    slow = [x for x in modes if lam_info[x] >  H_dec]        # 可上云
    return fast, slow

# IP-266 SAV：时滞折扣 VoI + 截止期门控
def choose_cloud_query(modes, w, o_t, rtt, lam_info, H_dec, t_c, budget):
    if rtt + TAU_MARGIN > H_dec or t_c < TAU_TRUST: return None   # 不许进当前决策
    best = None
    for g in cloud_query_candidates(modes):
        if not budget.allow(g) or not privacy_ok(g): continue
        S = exp(-rtt / lam_info[g])                        # 答案到用时仍为真的概率
        score = S * local_voi(w, g, o_t) - comm_cost(g) - social_cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None       # 无利可图/不新鲜 → R69

# IP-267 PCV + IP-268 AST：先认证新鲜，再谈内容
def verify_answer(ans, session, now):
    if not session.authenticated or not session.fresh(now): return None
    if ans.counter <= session.last_counter: return None    # 重放/降级
    if not verify_sig(ans.sig, ans.model_hash, ans.input_commit): return None
    if not compatible_version(ans.ver, EDGE_VER): return None
    if now - ans.ts > TAU_FRESH: return None
    return ans

# IP-270 EBD：云语义必须与物理接地通道一致才可定案
def adjudicate(modes, evidence):
    chans = {e.channel for e in evidence}
    if not (chans & {'edge_physical', 'flow_likelihood'}):
        return 'undecided'                                 # 只有语义证据 → 不定案
    if count_orthogonal_agree(evidence) < 2:
        return 'undecided'
    return maximally_consistent_mode(modes, evidence)

# IP-271 IHE：在线半衰期估计（保守下界）
def update_half_life(x, prev_pred, now_obs, dt):
    err = prediction_error(now_obs, prev_pred)
    lam = fit_decay(err, dt)                               # 误差随 dt 的衰减速率
    return conservative_lower_bound(lam, conf=0.95)

# IP-274 主闭环（继承 R69，云只在“耐放且可分且未过期”处插入）
def LATTICE_round(M, obs, now):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    fast, slow = M.hld.split_by_half_life(M.modes, M.lam_info, M.H_dec)
    # 1) 边缘先解决快变歧义（R69 本地交互，永不停摆）
    g_loc = M.mint.choose_interaction(fast, o, M.budget)
    if g_loc is not None: slow = M.cia.update_belief(slow, M.cia.execute(g_loc))
    # 2) 仅当“耐放、可分、截止期内、可信”才考虑上云
    g_cloud = M.sav.choose_cloud_query(slow, o, M.rtt_est, M.lam_info, M.H_dec,
                                       M.tg.score(), M.budget)
    if g_cloud is not None:
        ans = M.ast.request(g_cloud, M.pdp.encode(o))      # 最小披露上送
        ans = M.pcv.verify_and_fresh(ans, M.ast.session, now)
        if ans is not None:
            slow = M.ebd.adjudicate(slow, local_evidence(o) + [ans])
    # 3) 失效/过期/越界 → 逐指令退化为 R69，再退化为 R68
    state = M.dgx.transition(M.ast.state, ans, M.tg.score(), M.ihe.ece())
    U_epi_after = residual_epistemic(fast, slow, state)
    U_floor = U_ale + (U_epi_after if state != 'SYNC' else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(M.modes, U_epi_after, lam)          # 只有边缘写执行器
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_x.submit_async(g_cloud, ans, state, M.ihe.lam_hat, M.pdp.spent)
    return k, lam, mode, (U_ale, U_epi_after, state)
```

## 3. 推导

**引理 19（时滞-有效性上界）** 设答案在年龄 τ 被使用，其为真的概率不超过 S(τ)=exp(−τ/λ_info)。若以过期答案替换本地答案，则期望任务后悔增量 ≤ L_reg·(1 − S(τ))，其中 L_reg 为模态误选损失（R69 引理 16 的 c·Δ_min 项）。系：云证据只在 τ_RTT ≪ λ_info·ln(1/(1−δ)) 的窗口内值钱；与 R69 引理 16 相乘，得到「**可分且耐放**才值得上云」——这正是否定「云算力强所以总该上云」的形式化依据。

**引理 20（半衰期分工的最优性）** 在截止期 H_dec 约束下，把 λ_info ≲ H_dec 的信息分配给边缘、λ_info ≫ H_dec 的分配给云，使「延迟惩罚后的期望误差」最小；分界阈值由 S(τ_RTT|x) = ΔH_edge(x)/ΔH_cloud(x) 给出。直觉：边缘胜在零延迟，云端胜在 ΔH 更大；只有当「云端多出来的辨识力」足以补偿「过期损耗」时才值得越界。

**引理 21（认证 ≠ 时效的分离）** 存在一对云端回答 y₁、y₂，二者都能通过 AST 与 PCV（签名有效、内容完整、到达及时），但 y₂ 在 t 时刻已过期或因版本偏斜而语义漂移；仅凭密码学验证无法区分二者。故安全交互**必须**叠加独立的新鲜性 / 版本 / 半衰期通道。这解释了本轮为何把「安全」与「正确」拆成两个正交维度：安全解决「谁说谎」，时效解决「话是否还成立」。

**引理 22（拜占庭云与共谋上界）** 设云投毒率 δ_c、与本地通道相关 ρ<1，则 EBD（k 条通道正交、至少一条物理接地）下错误采纳率 ≤ δ_c·ρ^{k−1} + ε_σ；但若云与人类共谋使 ρ→1，上界退化为 δ_c，此时只有物理接地通道能拦截。系：定义 318 强制物理接地，不是保守洁癖，而是共谋攻击下的唯一可证屏障。

**定理 18（LATTICE 严格包含 R69 与 R68）** 当 AST 不可用、τ_RTT + τ_margin > H_dec、T_c < τ_trust、证明/认证失败、版本偏斜或隐私预算耗尽时，LATTICE 逐指令退化为 FLUID-RAS；当 VoI_τ ≤ 0 时进一步退化为 R68 的纯保守。故安全侧永不弱于 R69/R68；效率收益只在「耐放、可分、可验证」的歧义上取得，且每一次收益都被 freshness 与 ECE_λ 双重门控。

**定理 19（单写者与无远程突变）** 在单写者不变式（定义 319）与截止期约束（定义 313）下，云证据只能改变已认证包络内的模态选择；任何云端答案的到达、丢失或过期都不直接改变 actuator 命令，故控制连续、无突变（继承 R68 定理 15、R69 定理 17）。系：网络抖动无法击穿实时安全闭环；最坏情况是「退回 R69」，不是「失去控制」。

## 6. 本轮最大风险

**一句话**：LATTICE 的全部收益押在「信息半衰期估计与版本一致性判断是可信的」这一前提上——**密码学只能保证答案「来自谁、未被篡改」，保证不了「现在还对不对」；一旦 λ_info 估错或云端/边缘版本悄悄偏斜，系统会自信地把一个已认证、已签名、低延迟、但语义上已经过期的答案当成当前事实，并据此切换模态**。这比 R69 的「问错」更隐蔽：R69 的错误至少有一个人在场，R70 的错误带着完整证书——**认证给过期答案镀了金，让系统比「不知道」时更敢行动**。

**次级风险与缓解**：
1. **半衰期误估导致过期误用** → IHE 保守下界 + ECE_λ 门控 + 超界即禁用云证据（定义 322、307 式退避）；
2. **版本偏斜静默漂移** → 版本哈希 + 跨版本一致率 κ + 超界即失效并重同步（定义 321）；
3. **云端/人类共谋绕过语义一致性** → EBD 强制物理接地通道（定义 318、引理 22）；
4. **重放/降级/冒充** → AST 双向认证 + 单调计数器 + nonce（定义 316、E305）；
5. **隐私泄露与上送依赖** → PDP 最小披露 + 预算硬约束 + 边缘自包含 fallback（定义 323–324）；
6. **权威被网络窃取** → 单写者不变式 + DGX 单调退化 + 红队 E313（定义 319–320、定理 19）。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** 单写者与边缘自治（执行器唯一写者是边缘、网络不在实时回路）；可验证证据（AST 认证 + PCV 证明 + 新鲜窗口）；截止期约束与严格退化（τ_RTT+τ_margin ≤ H_dec 才可影响当前决策；失效逐指令退 R69→R68）。

**定义 311–312（半衰期与分工）** `S(τ)=exp(−τ/λ_info)`；`U_epi^fast`（λ≲H_dec）留边缘、`U_epi^slow`（λ≫H_dec）可上云；`α*(x)=cloud ⇔ S(τ)·ΔH_cloud − c_comm > ΔH_edge`。分工由「耐放 × 更可分」决定，不由算力决定。

**定义 313–314（提交窗口与时滞 VoI）** `H_dec` 为当前模态可保持时间；只有 `τ_RTT+τ_margin ≤ H_dec` 才可影响当前决策；否则 pre-fetch。`VoI_τ = S(τ)·VoI_local − c_comm − c`；`VoI_τ ≤ 0` 或超期 ⇒ 退 R69 本地交互 / R68 保守。

**定义 315–316（证明携带与安全传输）** 回答 y 必须附 `π`；验签、输入承诺、时间戳新鲜、版本兼容、标定在界，任一失败即弃。AST：双向认证 + nonce + 单调计数器 + 完整性；云端不得下发执行指令。

**定义 317–318（信任梯度与通道多样性）** `T_c` 封顶回答权重，低于 `τ_trust` 按敌对源；定案需 ≥2 条正交通道且至少一条物理接地（edge_physical / flow_likelihood），防云端与人类共谋。R69 的 k 源一致是「无云」特例。

**定义 319（单写者）** `a_t = Edge_Certify(SelectMode(evidence))`，且 `∂a/∂cloud_cmd = 0`。云证据只改模态选择，不写执行器。

```python
class SplitFlowPolicy:
    def sample_edge(self, o_t, K):
        z, xs = self.trunk(o_t), randn(K, D)
        for i in range(2): xs = xs + 0.5 * self.v_edge(xs, i/2, z)

    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(M.modes, U_epi_after, lam)                 # 只有边缘写执行器
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_x.submit_async(g_cloud, ans, state, M.ihe.lam_hat, M.pdp.spent)
    return k, lam, mode, (U_ale, U_epi_after, state)
```

## 4. 推导

**引理 19（时滞-有效性上界）** 答案在年龄 τ 被使用时为真的概率 ≤ `S(τ)=exp(−τ/λ_info)`；用过答案替换本地答案的期望后悔增量 ≤ `L_reg·(1−S(τ))`。系：云证据只在 `τ_RTT ≪ λ_info·ln(1/(1−δ))` 内值钱；与 R69 引理 16 相乘得「可分且耐放才值得上云」。

**引理 20（半衰期分工最优性）** 在 `H_dec` 约束下，`λ_info≲H_dec` 交边缘、`λ_info≫H_dec` 交云，最小化延迟惩罚后的误差；分界阈值 `S(τ_RTT)=ΔH_edge/ΔH_cloud`。云端只有「多出来的辨识力足以补偿过期损耗」时才值得越界。

**引理 21（认证 ≠ 时效的分离）** 存在 y₁、y₂ 均通过 AST/PCV（签名有效、完整、及时），但 y₂ 已过期或版本偏斜；密码学验证无法区分。故安全交互必须叠加独立的新鲜性/版本/半衰期通道——「安全」解决谁说谎，「时效」解决话是否还成立。

**引理 22（拜占庭云与共谋上界）** 云投毒率 `δ_c`、与本地通道相关 `ρ<1` 时，EBD（k 正交 + 至少一条物理接地）错误采纳率 ≤ `δ_c·ρ^{k−1}+ε_σ`；若云与人类共谋使 `ρ→1`，上界退化为 `δ_c`，只有物理接地通道能拦。系：定义 318 的物理接地要求是共谋攻击下的唯一可证屏障。

**定理 18（LATTICE 严格包含 R69/R68）** 当 AST 不可用、`τ_RTT+τ_margin>H_dec`、`T_c<τ_trust`、证明/认证失败、版本偏斜或隐私预算耗尽时，逐指令退化为 FLUID-RAS；`VoI_τ≤0` 再退化为 R68。安全侧永不弱于 R69/R68，效率收益仅在「耐放、可分、可验证」的歧义上取得。

**定理 19（单写者与无远程突变）** 在定义 319 单写者不变式与定义 313 截止期约束下，云证据只改已认证包络内的模态选择；答案到达/丢失/过期均不直接改 actuator，故控制连续、无突变（继承 R68 定理 15、R69 定理 17）。系：网络抖动最多退回 R69，不会失去控制。

## 7. 本轮最大风险

**一句话**：LATTICE 的全部收益押在「信息半衰期估计与版本一致性判断可信」这一前提上——**密码学只保证答案「来自谁、未被篡改」，保证不了「现在还对不对」；一旦 λ_info 估错或边云版本悄悄偏斜，系统会自信地把一个已认证、已签名、低延迟、但语义已过期的答案当成当前事实并据此切换模态**。这比 R69 的「问错」更隐蔽：R69 的错误至少有人在场，R70 的错误带着完整证书——**认证给过期答案镀了金，让系统比「不知道」时更敢行动**。

**次级风险与缓解**：半衰期误估 → IHE 保守下界 + ECE_λ 门控 + 超界禁用云证据；版本偏斜静默漂移 → 版本哈希 + κ 一致率 + 超界失效重同步；云人共谋 → EBD 强制物理接地（引理 22）；重放/降级/冒充 → AST 双向认证 + 单调计数器 + nonce；隐私与上送依赖 → PDP 最小披露 + 预算硬约束 + 边缘自包含 fallback；权威被窃取 → 单写者不变式 + DGX 单调退化 + 红队 E313。
