# 第 64 轮（承接第 63 轮「LIRO」IP-193~203；灵感循环 III 第 1 轮；本轮灵感：「多模态交互」×「嵌入式系统」）

> 第 63 轮的 LIRO 给 ROSE 补上了**稠密几何（LSF）**、**技能抽象（USL/CSP）**、**干扰免疫（DIR/AIC）**三层，并把实时路径压进 ≤2ms。但 LIRO 仍建立在两个未被触碰的根假设之上：
> 1. **交互是单向且一次性的**：`L` 只是 DMS 解析出的静态语言意图，系统没有澄清、指代消解、纠正反馈，也没有任何回传给人的低带宽通道。「多模态」只体现为**输入侧融合**（RGB+触觉+本体+语言+点云），没有体现为**人机双向闭环**——真实操作里语言几乎总是欠定的（"把那个拿过来"），必须靠注视/指向/手势在时间上对齐来消解；人也常在执行中给出纠正。
> 2. **算力充裕且时序中性**：语义流/实时流隐含 GPU 级集中算力，证书 `J_liro` 只含空间鲁棒性 `(ρ_rob, ρ_dir)`，**不含任何时间维度**——没有输入新鲜度、没有最坏执行时间（WCET）、没有截止期冗余。可在真实嵌入式平台（MCU + 边缘 SoC + 共享总线 + 功耗/热约束）上，**时序本身就是安全变量**：输入过期、任务错过截止期、总线仲裁抖动，都会让 `J_liro` 在「陈旧输入」上被**错误签发**。
>
> 本轮把「人」提升为低带宽、高价值的信息源与兜底执行器，把「时间」提升为一等证书变量，提出 **MERIT：Multimodal-Embedded Real-time Interaction-certified operaTions**。

## 0. 直觉与动机

**灵感 1（多模态交互 → MIB：Multimodal Interaction Bus + TAG：Temporal Alignment & Grounding）**
直觉：与其把语音、手势、注视、触觉、肌电当作各自独立的分类器，不如把它们统一成一条**带硬件时间戳、带置信度、带来源**的交互事件流 `ℐ = {e_k = (m_k, t_k, c_k, σ_k, s_k)}`。欠定语言的消解本质上是一个**跨模态时序接地**问题：对每个指代表达 `r`，在语言发出时刻 `t_u` 附近的时间窗 `W_a` 内，用注视落点、指向射线、历史共指去给场景物体打分，取最大者作为接地目标；若 top-1 与 top-2 的边际不足，则显式标记 `ambiguous` 并交给 VoI 决策是否反问。关键不是「融合得更多」，而是**每种模态有自己的时钟与延迟契约 `τ_m`**——接地只在所有被用模态都新鲜时有效。

**灵感 2（嵌入式系统 → EMC：Embedded Mixed-Criticality runtime + TPD：Tiny Partitioned Deployment）**
直觉：嵌入式平台的资源是**硬约束**而非软开销。把 LIRO 的作业按关键性分层：**HI 关键性** = 控制律（1–10kHz）、WCV-T 编译、证书签发、安全屏蔽（硬截止期，绝不可丢）；**LO 关键性** = 重感知、DIR 在线更新、CSP 规划、TAG、学习（可降级、可丢）。用 **AMC（自适应混合关键性）** 调度：常态按 LO 的 WCET 预算调度（多接纳 LO 作业）；一旦 HI 作业出现超时征兆，切到 HI 模式、丢弃全部 LO 作业、按 HI 的 WCET 调度。再用**模型分区 + 混合精度量化 + TinyML 蒸馏**把模块布到 MCU / 边缘 SoC / 云，形成可实测的 `(WCET, SRAM, flash, power, 总线带宽)` 资源画像，让「能不能跑」变成可判定的约束而不是祈祷。

**灵感 3（二者咬合 → DAC：Deadline-Aware Certificate + VoI：Value-of-Information）**
直觉：交互带来新的时间语义——人回答问题需要延迟 `τ_h`，机器人等待期间系统是在「信息更陈旧」的状态下运行。因此**截止期与不确定性必须显式耦合**：若模态 `m` 的数据年龄 `a_m(t)` 超过契约 `τ_m`，有效不确定球按 Lipschitz 常数膨胀
`r_eff(t) = r(t) + Σ_m L_m·[a_m(t) − τ_m]_+ (+ 调度抖动项)`，
证书必须用 `r_eff` 而非 `r` 签发。反过来，人又是**不确定性的廉价削减器**：当 `r_eff` 过大使 `ρ < 0` 时，一次针对性提问能把球显著缩小。**何时值得问**？用信息价值（VoI）决策：仅当期望裕度增益 `E[Δρ]` 超过交互代价 `λ(c_h + c_c)` 且截止期可行时才问。`HUC` 触觉通道则把机器人裕度 `ρ` 以低带宽振动编码回传给操作员，作为强噪声/无屏幕环境下的兜底回传。

**灵感 4（合流 → MERIT 闭环）**
三者咬合：MIB/TAG 把「人的意图 + 时序」接进 DMS/CSP；EMC/TPD 把 LIRO 压进嵌入式实时预算；DAC 把「数据年龄」写成证书里的显式项，VoI/HUC 把「人」变成可调度的安全资源；HIL-CF 让人工纠正反过来校验第 63 轮的几何幻觉。闭环：交互事件 → 接地目标 → 技能规划 → 实时展开 → 执行证据 + 时间戳 →（若 `r_eff` 过大）VoI 提问 / 触觉回传 → 人纠正 → 更新 `φ̂`/USL/证书。**第 63 轮是「算法层的鲁棒闭环」，MERIT 是「时间-交互-算力联合约束下的可部署鲁棒闭环」**。

**灵感 5（LIRO 组件原位升级）**
- **OLP-Geo → OLP-T**：投影头输入加入时间特征 `(a_m(t), freshness mask)`，对陈旧样本重加权，遗憾界增加时序项 `G̃_T`。
- **WCV-Geo → WCV-T**：球半径用 `r_eff(t)` 而非 `r`；任一模态超期即拒绝签发，回退到保守基线。
- **USL/CSP → USL-I / CSP-I**：`pre/eff` 增加交互谓词（如 `pre_handover` 需 `human_ready`），CSP 目标直接消费 TAG 的接地结果。
- **Shield-Skill → Shield-Interaction**：除前置条件投影外，增加「人机共驾一致性」约束——高风险技能未获人确认则禁止执行。
- **OCB-Skill → OCB-I**：臂空间扩为 `{交互模式} × {嵌入式降级模式} × {USL模式}`，奖励含交互代价与截止期惩罚。
- **AIC → DTC (Deadline-Timing Certifier)**：空间干扰认证与时间陈旧认证统一。
- **SSB → eSSB**：场景签名增入「交互上下文指纹」（最近指代对象、人手位置、延迟分布）。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（MERIT 闭环）**：MERIT = (LIRO, MIB, TAG, EMC, TPD, DAC, VoI, HUC, HIL-CF, CSP-I, OCB-I, J_merit)。定位：LIRO 的「可部署性 × 双向交互 × 时序证书」升级，全部为挂载式新增或原位替换，不推翻既有接口。
- **定义 202（MIB 多模态交互总线）**：交互事件 `e_k = (m_k, t_k, c_k, σ_k, s_k)`，`m_k ∈ {speech, gesture, gaze, haptic, emg}`，`t_k` 为硬件时钟时间戳，`σ_k ∈ [0,1]` 置信度，`s_k` 来源（操作员 ID）。流 `ℐ(t) = {e_k : t_k ≤ t}`。总线保证：时间戳单调、传输延迟 `≤ L_bus`、每模态新鲜度契约 `a_m(t) = t − t_m^{last} ≤ τ_m`。
- **定义 203（TAG 时序接地）**：给定欠定语言 `u`、`ℐ(t)`、场景对象集 `O` 与联合表征 `x'`，接地目标 `G* = (pred, obj_refs, spatial_refs, temporal_constraints)`。对指代表达 `r` 的物体打分 `s(o) = α·sim(E_lang(r), E_obj(o)) + β·gaze(o) + γ·point(o) + δ·history(o)`，其中注视/指向只在对齐窗 `[t_u − W_a, t_u + W_a]` 内计分。若 `max s(o) < θ_ground` 或 top-2 边际 `< θ_margin`，标记 `ambiguous=True` 并触发 VoI 反问；若任一被用模态 `a_m > τ_m`，接地结果标记 `stale=True`、不可直接驱动 HI 技能。
- **定义 204（EMC 混合关键性作业模型）**：作业 `j = (C_j^LO, C_j^HI, T_j, D_j, crit_j)`，`crit_j ∈ {HI, LO}`。HI 作业 = 控制律、WCV-T 编译、证书签发、安全屏蔽；LO 作业 = 重感知、TAG、CSP、DIR 更新、学习。AMC 调度：LO 模式按 `C^LO` 接纳、可接纳较多 LO 作业；任一 HI 作业运行超 `C^LO` 触发切换，进入 HI 模式、丢弃全部 LO 作业、按 `C^HI` 调度。可调度条件 `U_HI = Σ_{j∈HI} C_j^HI/T_j ≤ 1`。
- **定义 205（TPD 分区嵌入式部署）**：部署 `d = (π, q, p, f)`，`π` 把模块映射到 `{MCU, EdgeSoC, Cloud}`，`q` 为每模块精度 `{int8, fp16, fp32}`，`p` 为放置、`f` 为频率。资源画像 `R(d) = (WCET, SRAM, flash, power, bus_BW)`。可行集 `𝒟_feas = {d : ∀j∈HI, WCET_j ≤ D_j; SRAM ≤ M_MCU; power ≤ P_max; bus ≤ B_max}`。
- **定义 206（DAC 截止期感知证书）**：`J_merit = (J_liro|_{r_eff}, timing_cert, interaction_cert, deployment_hash, merkle_root)`；`timing_cert = (a_m(t), τ_m, r_eff(t), {slack_j}_{j∈HI}, sched_mode)`；`interaction_cert = (G*, ground_conf, ask_log, human_ack)`。
- **定义 207（陈旧膨胀有效半径）**：`r_eff(t) = r(t) + Σ_m L_m·[a_m(t) − τ_m]_+ + L_sched·[overrun(t)]_+`，`L_m` 为不确定半径对模态 `m` 信息年龄的 Lipschitz 常数，`L_sched` 为调度抖动敏感度，`[z]_+ = max(0,z)`。`r_eff` 对年龄与超时单调非降。
- **定义 208（VoI 交互门控）**：查询集 `Q` = {问指代、确认动作、请求接管}。`VoI(q) = E_{o∼belief}[ρ(τ | do(q)) − ρ(τ)] − λ(c_h(q)+c_c(q)) − λ_D·D(q)/D_rem`。仅当 `q* = argmax_q VoI(q)` 满足 `VoI(q*) > 0` 且 `D(q*) ≤ D_rem` 时才提问，否则保持静默；人答后更新 belief。
- **定义 209（HUC 触觉不确定性通道）**：把裕度 `ρ ∈ [ρ_min, ρ_max]` 与当前模式编码为 `K` 级振动模式（频率/幅度组合）`Q_K(ρ)`；人解码延迟 `τ_h`、误差 `ε_h`。失真 `D_K = E[(ρ − Q_K(ρ))²]`，传输 `B = ⌈log₂ K⌉` bit；选 `K` 使 `D_K ≤ ε_h` 且模式可分辨。
- **定义 210（HIL-CF 人在回路纠正与交叉校验）**：人纠正算子 `H` 输出 `(纠正指代, 纠正动作, 置信度)`，以信任权重写入 `φ̂` 球心/半径与 USL 偏好；并经 Shield-Interaction 校验后才可执行。**交叉校验**：若人的指代与 `GeoInit` 的几何对象冲突，则标记 `geo_conflict=True` 并抬高 `r_geo`（直接对冲第 63 轮的几何幻觉单点假设）。
- **定义 211（CSP-I 交互接地技能规划）**：CSP 的目标谓词来自 TAG 的 `G*`；技能 `pre/eff` 增加交互谓词（`human_ready`, `handover_ack`, `gaze_on_target`, `ask_resolved`）；硬约束新增「高风险技能需 `human_ack ∨ ρ_dir ≥ ρ_ack`」。
- **定义 212（OCB-I 交互-嵌入式预算老虎机）**：臂 = `{ask_allowed, silent, haptic_only} × {full, distilled, degraded} × USL_模式`；奖励 `r_t = progress − κ(compute + c_int + deadline_penalty + switch_penalty)`，`deadline_penalty = [missed]·κ_D`。EXP3 在该臂空间上更新。
- **定义 213（交互代价与风险模型）**：`c_int(q) = c_h(q) + c_c(q)`（人的时间 + 机算力），等待期间任务风险 `R_wait(q) = ∫ [ρ(τ_s) < 0] ds` 的期望；`R_noask = P(act under r_eff unsafe)`。VoI 本质是 `R_noask − R_wait − c_int` 的符号判定。
- **定义 214（降级阶梯）**：`L0 全交互` → `L1 触觉-only`（语音/手势通道失效）→ `L2 静默安全`（无交互，保守 `r_eff`，仅执行已认证技能）→ `L3 停止/请求接管`。切换由 `J_merit` 失效原因驱动：空间失效 → L2，时序失效 → 降采样/减技能，交互通道失效 → L1。
- **定义 215（J_merit 证书）**：`Valid(J_merit) ⇔ Valid(J_liro at r_eff(t)) ∧ (∀m, a_m ≤ τ_m ∨ 已进入对应降级级) ∧ (∀j∈HI, slack_j ≥ 0) ∧ interaction_consistent`。审计链：`deployment_hash` 追溯 TPD 版本、`geo_hash` 追溯几何、`ask_log` 追溯交互决策。
- **定义 216（MERIT 闭环算子）**：语义流 = [MIB 汇聚 → TAG 接地 → USR/MEL → CSP-I → Shield-Interaction → OCB-I 选臂 → DTC 认证]；实时流 = [锚点读 → OLP-T 前向 + freshness 重加权 → WCV-T 以 `r_eff` 编译 → π_σ1 展开派发 → 记录 `a_m/slack` → J_merit 构建]；HI 作业由 EMC 独占保障，LO 作业可被丢弃后于下一语义流恢复。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# TAG：跨模态时序接地（语义流，LO）
G_star, amb = tag.ground(u, I_bus.window(t_u, W_a), scene_objects, history)
# VoI：是否值得反问/请求确认（语义流，LO）
q = voi.select(G_star, belief, r_eff, D_rem)
if q and voi.value(q) > 0:  I_bus.emit(ask(q))
# EMC：HI/LO 分层 + AMC 调度（运行时）
emc.admit(jobs);  emc.tick()          # HI 作业独占，LO 超时即丢
# TPD：离线求解可行部署
d = tpd.solve(modules, budgets={WCET, SRAM, power, bus})
# DAC：时序耦合证书（每控制周期）
r_eff = r + sum(L[m]*max(0, a[m]-tau[m]) for m in modalities)
J_merit = dac.issue(J_liro(r_eff), a, tau, slack, sched_mode)
# 失效：按原因进入降级阶梯
if not valid(J_merit):  degrade(reason(J_merit))
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（陈旧膨胀的可靠性）**：若单步状态估计误差半径 `≤ r(t)`，且误差半径对模态 `m` 信息年龄的增长率 `≤ L_m`，则真实不确定半径 `≤ r_eff(t)`——**输入年龄可被显式折算为不确定球增量**，证书在「陈旧输入」上不再虚高。
- **引理 6（AMC 保 HI 可调度）**：若 `U_HI = Σ C_j^HI/T_j ≤ 1` 且 LO 作业可丢，则 AMC 在 LO/HI 两模式下的 HI 作业均满足截止期，模式切换开销至多一个控制周期——**降级不破坏安全环**。
- **定理 4（VoI 门控安全不降、交互代价有界）**：设查询只会缩小不确定球（`E[Δρ] ≥ 0`）且阈值 `λ > 0`，则 VoI 门控策略的期望安全不低于非交互基线，且单位回合期望交互代价 `≤ E[总不确定性削减]/λ + O(1)`——**「该问才问」既保安全又控交互开销**。
- **定理 5（J_merit 可靠性）**：在 LIRO 假设 + 引理 5/6 下，`Valid(J_merit) ⇒` 真实空间干扰 `η*` 与真实时序误差下安全概率 `≥ 1 − α_dir − δ_cert − δ_time`；任一 HI 截止期被违反时，`J_merit` 在**一个控制周期内**失效并触发降级。
- **实时性**：HI 环只做 OLP-T 前向、WCV-T 编译（`r_eff`）、π_σ1 展开与调度记账；TAG/CSP/学习全在 LO 侧可丢——**时间可调度性由 WCET 预算而非平均值保证**（承接并强化第 63 轮 A82）。

## 5. 本轮最大风险

**一句话**：整套时序证书建立在**嵌入式目标机上的 WCET 估计**之上——一旦 WCET 被低估（缓存/总线争用、DVFS 与热降频、中断风暴），调度器可能在 `J_merit` 仍报告「有效」时已经错过 HI 截止期，**「时间」于是变成新的单点幻觉，恰好是第 63 轮几何幻觉在时序维度上的镜像**。

# 第 64 轮产物 · 创新点清单 v4：MERIT（Multimodal-Embedded Real-time Interaction-certified operaTions —— 多模态交互总线 × 嵌入式混合关键性运行时 × 时序耦合证书）

> 承接第 63 轮 IP-193~203（LIRO：LSF×USL×CSP×DIR×AIC×SSB×OLP-Geo×WCV-Geo×Shield-Skill×OCB-Skill）。本轮不推倒 LIRO，而是给它补上**两个可部署性缺口**：① **双向多模态交互**（欠定语言的时序接地、人在回路纠正、触觉回传、VoI 反问）；② **嵌入式实时执行底座**（HI/LO 混合关键性调度、模型分区与量化、WCET 预算）。核心主张：**时间是一等安全变量**——把输入年龄/调度抖动显式折算进不确定球 `r_eff`，让证书 `J_merit` 在陈旧输入与资源过载下仍然可靠，并在失效时按原因进入降级阶梯。
>
> IP 编号：IP-204~IP-216（共 13 个），全部为第 63 轮组件的新增挂载或原位升级。

## 2. 形式化定义（完整版）

**定义 201（MERIT 闭环）** MERIT 是 LIRO 的「可部署性 × 双向交互 × 时序证书」升级：在 LIRO 的「语义流 ∘ 实时流」骨架上挂载 MIB/TAG（多模态交互与接地）、EMC/TPD（混合关键性运行时与嵌入式部署）、VoI/HUC/HIL-CF（交互决策与人在回路），并原位升级 OLP→OLP-T、WCV→WCV-T、CSP→CSP-I、Shield→Shield-Interaction、OCB→OCB-I、AIC→DTC。不变式：**HI 关键性作业（控制律、WCV-T 编译、证书签发、安全屏蔽）永不被 LO 作业抢占或丢弃；LO 作业（TAG、CSP、DIR 更新、学习）可随时丢弃并在下一语义流恢复**。时间戳 `t_k` 一律取硬件单调时钟。

**定义 202（MIB 多模态交互总线）** 交互事件 `e_k = (m_k, t_k, c_k, σ_k, s_k)`：
- `m_k ∈ {speech, gesture, gaze, haptic, emg}`；`c_k` 为结构化内容（ASR 文本/意图槽、手势类别+射线、注视点+视锥、触觉回执、肌电激活向量）；
- `t_k` 为采集端硬件时间戳，总线内**时间戳单调**、传输延迟上界 `L_bus`（典型 `< 10ms`）；
- 流 `ℐ(t) = {e_k : t_k ≤ t}`；每模态缓存最近事件并维护 `a_m(t) = t − t_m^{last}`；
- 新鲜度契约：`a_m(t) ≤ τ_m`（语音 `τ_sp=400ms`、手势 `τ_ge=150ms`、注视 `τ_gz=100ms`、触觉回执 `τ_ha=100ms`、肌电 `τ_em=50ms`，可按任务标定）；
- 来源 `s_k` 用于多操作员/共享工作区下的归属与权限（仅授权 `s_k` 的确认可解除高风险锁定）。

**定义 203（TAG 时序接地）** 给定欠定语言 `u`（发出时刻 `t_u`）、交互流 `ℐ(t)`、场景对象集 `O` 及联合表征 `x'`（第 63 轮 LSF 输出）：
1. 指代打分：`s(o) = α·sim(E_lang(r), E_obj(o)) + β·gaze(o) + γ·point(o) + δ·history(o)`，其中 `gaze(o)` 为对齐窗 `[t_u−W_a, t_u+W_a]` 内注视落在 `o` 视锥的时长占比，`point(o)` 为手部指向射线与 `o` 的命中/角度核，`history(o)` 为最近共指先验；权重 `α+β+γ+δ=1`。
2. 决策：`o* = argmax_o s(o)`；若 `max_o s(o) < θ_ground` 或 `s(o*) − s(o_2) < θ_margin`，置 `ambiguous=True`。
3. 时序有效性：若任一被用模态 `a_m(t) > τ_m`，置 `stale=True`。`G*` 仅在 `¬stale` 时可直接驱动 HI 技能；`stale` 时只能触发 L1/L2 或 VoI 反问。
4. 输出 `G*` 交给 CSP-I（定义 211）作为目标谓词；歧义与置信度进入 VoI（定义 208）。

**定义 204（EMC 混合关键性作业模型）** 作业 `j = (C_j^LO, C_j^HI, T_j, D_j, crit_j)`。HI 作业：控制律（`T=0.1–1ms`）、WCV-T 编译、DTC 证书签发、Shield-Interaction；LO 作业：TAG、CSP-I 规划、MEL 重推理、DIR 更新、SSB 挖掘、学习。AMC 调度规则：
- LO 模式：按 `C_j^LO` 做可行性判定并接纳 LO 作业；HI 作业按 `C^LO` 预算运行；
- 任一次 HI 作业实际执行超过 `C_j^LO` → 触发**模式切换**：进入 HI 模式，立即丢弃所有 LO 作业，HI 作业按 `C_j^HI` 重新调度；
- HI 模式持续至一个「平静窗口」`T_calm` 后方可回到 LO 模式；
- 可调度判据：`U_HI = Σ_{j∈HI} C_j^HI/T_j ≤ 1`（含模式切换预留 `C_switch`）；LO 利用率仅需 `U_LO^LO ≤ 1 − U_HI` 才被接纳，否则拒绝新 LO 作业。
- **红线**：控制律与证书签发共享同一 HI 预算，证书永远不借用控制预算（否则证书自身成为时序风险）。

**定义 205（TPD 分区嵌入式部署）** 部署 `d = (π, q, p, f)`，`π: Modules → {MCU, EdgeSoC, Cloud}`，`q: Modules → {int8, fp16, fp32}`，`p` 为进程/核绑定，`f` 为频率档。资源画像 `R(d) = (WCET_j(d), SRAM(d), flash(d), power(d), bus_BW(d))`，其中 WCET 由静态分析 + 目标机实测标定给出（非平均延迟）。可行集
`𝒟_feas = {d : ∀j∈HI, WCET_j(d) ≤ D_j ; SRAM(d) ≤ M_MCU ; power(d) ≤ P_max ; bus_BW(d) ≤ B_max}`。
部署目标：在 `𝒟_feas` 内最大化任务精度（或最小化蒸馏损失），并保留安全裕度 `WCET_j(d) ≤ (1−η_j)D_j`（`η_j` 为 WCET 不确定度预留，见风险节）。**硬约束**：HI 环不经 Cloud（网络不可靠），Cloud 仅承接 LO 学习/回放。

**定义 206（DAC/DTC 截止期感知证书）** `J_merit = (J_liro|_{r_eff}, timing_cert, interaction_cert, deployment_hash, merkle_root)`：
- `timing_cert = (a_m(t), τ_m, r_eff(t), {slack_j}_{j∈HI}, sched_mode)`，`slack_j = D_j − (release-to-finish 上界)`；
- `interaction_cert = (G*, ground_conf, ask_log, human_ack)`；
- `deployment_hash` 追溯 TPD 版本与量化配置；
- `Valid(J_merit) ⇔ Valid(J_liro at r_eff(t)) ∧ (∀m a_m ≤ τ_m ∨ 已进入对应降级级) ∧ (∀j∈HI slack_j ≥ 0) ∧ interaction_consistent`，`interaction_consistent` 要求高风险技能满足 `human_ack ∨ ρ_dir ≥ ρ_ack` 且 `G*` 未标记 `ambiguous`（除非已由反问消解）。

**定义 207（陈旧膨胀有效半径）** 
`r_eff(t) = r(t) + Σ_m L_m·[a_m(t) − τ_m]_+ + L_sched·[overrun(t)]_+`。
`r(t)` 为第 63 轮 RSC 维护的物理参数球半径；`L_m` 为「单位信息年龄导致的状态估计误差增长」上界，可由观测模型/执行器动力学标定；`overrun(t)` 为最近的调度超时量。性质：`r_eff ≥ r`，对 `a_m` 与 `overrun` 单调非降；当所有模态新鲜且无超时，`r_eff = r`，退化为第 63 轮 LIRO。

**定义 208（VoI 交互门控）** 查询集 `Q = {ask_referent, confirm_action, request_takeover}`。在 belief `b = (φ̂, r, G* 分布)` 上：
`VoI(q) = E_{o∼b}[ρ(τ | do(q)) − ρ(τ)] − λ·c_int(q) − λ_D·D(q)/D_rem`，
`c_int(q) = c_h(q) + c_c(q)`。执行规则：`q* = argmax_{q∈Q} VoI(q)`；若 `VoI(q*) > 0` 且 `D(q*) ≤ D_rem` 则提问，否则静默。`D(q)` 为查询占用时间（含人反应 `τ_h` 与解析），`D_rem` 为当前任务剩余截止期。人答后按贝叶斯/加权规则更新 `b`。**安全优先**：若当前策略在 `r_eff` 下 `ρ < 0` 且无可行查询（`Q` 全为负 VoI 或超期），直接进入降级阶梯。

**定义 209（HUC 触觉不确定性通道）** 将裕度 `ρ ∈ [ρ_min, ρ_max]` 与模式 `mode ∈ {L0..L3}` 编码为 `K` 级振动模式 `Q_K(ρ)`（频率/幅度/节奏三元组）。人解码延迟 `τ_h`、误差 `ε_h`。失真 `D_K = E[(ρ − Q_K(ρ))²]`，传输 `B = ⌈log₂ K⌉` bit。设计目标：`D_K ≤ ε_h`、相邻模式可分辨（人误判率 `≤ δ_h`）、`B` 最小。若均匀量化达不到 `ε_h`，用 Lloyd-Max 非均匀量化（在 `ρ` 危险区加密）。HUC 是**单向**通道（机器人→人），不占用语音/手势的上行带宽。

**定义 210（HIL-CF 人在回路纠正与交叉校验）** 人纠正是算子 `H: (纠正指代, 纠正动作, 置信度)`：
- 指代纠正：更新 `G*` 的 `obj_refs` 并对 `φ̂` 增加观测约束；
- 动作纠正：以偏好/约束形式写入 CSP-I（软代价）或直接覆盖 `θ_bind`（须 Shield-Interaction 复核）；
- **几何交叉校验**：若人的指代与 `GeoInit(g)` 给出的几何对象冲突（`geo_conflict=True`），则 `r_geo ← r_geo·(1+β_g)` 并标记 `J_merit.geo_conflict`，同时降低 LSF 该区域的置信度权重。此机制直接对冲第 63 轮最大风险（几何幻觉注入确定性错误）。
- 人纠正的可信度按来源历史校准（`σ_H`），防止误纠正污染：仅当 `σ_H ≥ θ_trust` 才改写 `φ̂`，否则只记录为软偏好。

**定义 211（CSP-I 交互接地技能规划）** CSP 的目标谓词来自 TAG 的 `G*`；技能 `pre/eff` 增加交互谓词：`pre_handover ≡ human_ready ∧ gaze_on_target`，`pre_high_risk ≡ human_ack ∨ ρ_dir ≥ ρ_ack`，`eff_ask_resolve ≡ ask_resolved`。硬约束新增「高风险技能需人确认」；软代价新增交互代价 `c_int`。实时路径仍仅展开首技能 `π_σ1`，后续在下一语义流依 `G*` 更新重规划。

**定义 212（OCB-I 交互-嵌入式预算老虎机）** 臂 = `InteractionMode × DeploymentMode × USL_Mode`：
- `InteractionMode ∈ {ask_allowed, silent, haptic_only}`；
- `DeploymentMode ∈ {full, distilled, degraded}`；
- `USL_Mode` 继承第 63 轮 `{full_seq, single_skill, cached_seq, frozen}`。
聚合后 `K=12`（3×4，必要时再乘 2 对齐开关为 `K=24`）。奖励
`r_t = clip(progress − κ(compute_cost + c_int + switch_penalty) − κ_D·[missed deadline], 0, 1)`。
EXP3 更新；硬降级规则作为安全下界（不得突破当前算力允许的最高模式）。

**定义 213（交互代价与风险模型）** `c_int(q) = c_h(q) + c_c(q)`；等待期任务风险 `R_wait(q) = E[∫_0^{τ_h} 1{ρ(τ_s) < 0} ds]`；不问而行动的风险 `R_noask = P(在 r_eff 下不安全)`。VoI 的符号判定等价于 `R_noask − R_wait(q) − c_int(q) > 0`（在把 `ρ` 视为负风险时）。该等价用于给 VoI 阈值 `λ` 一个可解释的物理标定：`λ ≈ ΔR_noask/Δc_int`。

**定义 214（降级阶梯）** `L0 全交互` → `L1 触觉-only` → `L2 静默安全` → `L3 停止/请求接管`。切换由 `J_merit` 失效原因驱动：
- 空间失效（`ρ_rob < 0` 或 `geo_conflict`）→ L2；
- 时序失效（`a_m > τ_m` 或 `slack_j < 0`）→ 降采样/减技能，必要时 L2；
- 交互通道失效（语音/手势断流）→ L1（HUC 仍可回传）；
- 关键硬件故障/人缺席且风险未消 → L3。
降级与恢复均记录到 `J_merit` 的 `sched_mode` 与 `interaction_cert.ask_log`，形成可审计轨迹。

**定义 215（J_merit 证书）** 见定义 206。审计链：`deployment_hash`（TPD 版本/量化）、`geo_hash`（几何嵌入版本）、`csp_plan_hash`（规划器与输入）、`skill_seq_hash`（实际执行序列）、`ask_log`（交互决策与 VoI 值）、`sched_mode`（调度模式）。任一哈希不一致 → `J_merit` 失效。

**定义 216（MERIT 闭环算子）** 语义流（LO，可丢）：`[MIB 汇聚 → TAG 接地 → USR/MEL → CSP-I → Shield-Interaction → OCB-I 选臂 → DTC 认证]`；实时流（HI，独占）：`[锚点读 → OLP-T 前向 + freshness 重加权 → WCV-T 以 r_eff 编译 → π_σ1 展开派发 → 记录 a_m/slack → J_merit 构建]`。LO 作业被丢弃时，下一语义流用最新事件补齐；HI 环绝不读取未完成写入的 LO 结果（双缓冲 + 版本号校验）。

## 3. 关键算法伪代码

### IP-204/205 MIB + TAG（多模态交互总线 + 时序接地）

```python
class MultimodalInteractionBus:
    """带硬件时间戳的事件流；每模态新鲜度契约 tau_m。"""
    TAU = {'speech': 0.40, 'gesture': 0.15, 'gaze': 0.10,
           'haptic': 0.10, 'emg': 0.05}

    def __init__(self):
        self.last = {}            # m -> (t, content)
        self.history = deque(maxlen=512)

    def push(self, m, t, content, conf=1.0, source='op0'):
        assert all(t >= e[0] for e in []) or True
        self.last[m] = (t, content)
        self.history.append((m, t, content, conf, source))

    def age(self, m, t):
        return float('inf') if m not in self.last else t - self.last[m][0]

    def fresh(self, m, t):
        return self.age(m, t) <= self.TAU[m]

    def window(self, t_center, half_width):
        lo, hi = t_center - half_width, t_center + half_width
        return [e for e in self.history if lo <= e[1] <= hi]


class TemporalAligner:
    """TAG：时间窗内跨模态指代消解 + 歧义/陈旧标记。"""
    def __init__(self, alpha=0.45, beta=0.25, gamma=0.20, delta=0.10,
                 theta_ground=0.55, theta_margin=0.08, W_a=1.2):
        self.a, self.b, self.c, self.d = alpha, beta, gamma, delta
        self.theta_g, self.theta_m = theta_ground, theta_margin
        self.W_a = W_a

    def ground(self, u, events, objects, x_prime, bus, t_now):
        used = [e[0] for e in events]
        stale = any(not bus.fresh(m, t_now) for m in used)
        gaze_dur = defaultdict(float); point_hit = defaultdict(float)
        for m, t, content, conf, src in events:
            if m == 'gaze':
                gaze_dur[content['obj_id']] += conf * (2 * self.W_a)
            elif m == 'gesture' and content['type'] == 'point':
                ray = content['ray']
                for o in objects:
                    if ray_hits(ray, o) and angle(ray, o.center) < 0.25:
                        point_hit[o.id] += conf
        scores = {}
        for o in objects:
            sim = cos(E_lang(u), E_obj(o, x_prime))
            scores[o.id] = (self.a * sim
                            + self.b * gaze_dur[o.id]
                            + self.c * point_hit[o.id]
                            + self.d * self._history_prior(u, o))
        ranked = sorted(scores.items(), key=lambda kv: kv[1], reverse=True)
        best, best_s = ranked[0]
        ambiguous = (best_s < self.theta_g or
                     len(ranked) > 1 and best_s - ranked[1][1] < self.theta_m)
        G_star = GroundedGoal(pred=parse_predicate(u), obj_refs=[best],
                              spatial_refs=extract_spatial(u),
                              temporal_constraints=extract_temporal(u))
        return G_star, {'ambiguous': ambiguous, 'stale': stale,
                        'conf': best_s, 'ranked': ranked[:3]}
```

```python
class MixedCriticalityRuntime:
    """AMC：LO 模式按 C^LO 调度；HI 超时 -> 切 HI 模式丢 LO。"""
    def __init__(self, jobs, T_calm=0.2):
        self.hi = [j for j in jobs if j.crit == 'HI']
        self.lo = [j for j in jobs if j.crit == 'LO']
        self.mode = 'LO'
        self.T_calm = T_calm
        self.overrun = 0.0
        assert sum(j.C_hi / j.T for j in self.hi) <= 1.0, 'HI 不可调度'

    def admit_lo(self, extra=0.0):
        u_lo = sum(j.C_lo / j.T for j in self.lo) + extra
        return self.mode == 'LO' and u_lo <= 1.0 - sum(j.C_hi / j.T for j in self.hi)

    def tick(self, executed, job):
        budget = job.C_lo if self.mode == 'LO' else job.C_hi
        if job.crit == 'HI' and self.mode == 'LO' and executed > budget:
            self.mode = 'HI'; self.overrun = executed - job.C_lo
            self.lo = []                      # 丢弃所有 LO 作业
        elif self.mode == 'HI' and self._calm():
            self.mode = 'LO'; self.overrun = 0.0
        return self.mode

    def _calm(self):
        return self.cpu_idle_fraction() >= 0.2


class WCETGuard:
    """在 release 前用保守 WCET 做准入，保证 slack_j >= 0。"""
    def __init__(self, wcet, eta=0.15):
        self.wcet, self.eta = wcet, eta     # WCET 估计不确定度预留

    def slack(self, job, t_release):
        worst = self.wcet[job.id] * (1.0 + self.eta)
        return job.D - (worst + job.priority_blocking)
```

```python
class TinyPartitionedDeployment:
    """模块分区 + 混合精度；在资源可行域内最小化精度损失。"""
    PLACES = ('MCU', 'EdgeSoC', 'Cloud')
    PREC = ('int8', 'fp16', 'fp32')

        self.modules, self.budgets = modules, budgets   # budgets: WCET/SRAM/power/bus

    def solve(self):

        for assign in product(self.PLACES, repeat=len(self.modules)):
            for prec in product(self.PREC, repeat=len(self.modules)):
                d = Deployment(partition=dict(zip(self.modules, assign)),
                               precision=dict(zip(self.modules, prec)))

                if best is None or loss < best[0]:

                R.power <= self.budgets.power and
```

### IP-211 VoI（信息价值门控）

```python
class ValueOfInformation:
    def __init__(self, lam=1.0, lam_d=0.05):
        self.lam, self.lam_d = lam, lam_d

    def value(self, q, belief, r_eff, d_rem):
        gain = self._expected_margin_gain(q, belief)     # E[rho(after) - rho(now)]
        cost = self.lam * (q.c_human + q.c_compute)
        return gain - cost - self.lam_d * q.duration / max(d_rem, 1e-6)

    def select(self, belief, r_eff, d_rem):
        candidates = self._feasible_queries(belief, d_rem)
        if not candidates:
            return None
        scored = [(self.value(q, belief, r_eff, d_rem), q) for q in candidates]
        v, q = max(scored, key=lambda z: z[0])
        return q if (v > 0 and q.duration <= d_rem) else None

    def _expected_margin_gain(self, q, belief):
        # 用 belief 的粒子近似：比较 do(q) 前后 rho 的期望
        rho_now = expected_margin(belief, belief.r_eff)
        rho_after = np.mean([expected_margin(belief.observe(q, ans),
                                             belief.r_eff_after(ans))
                             for ans in belief.possible_answers(q)])
        return rho_after - rho_now
```

## 4. 推导

**引理 5（陈旧膨胀的可靠性）** 设时刻 `t` 的真实物理参数为 `φ*(t)`，RSC 在全部输入新鲜时的估计误差满足 `‖φ*(t) − φ̂(t)‖ ≤ r(t)`。设模态 `m` 的观测对状态估计的 Lipschitz 常数为 `L_m`（单位：参数误差/秒信息年龄），调度超时对状态传递的扰动强度为 `L_sched`。则在输入年龄 `a_m(t)` 与超时 `overrun(t)` 下，
`‖φ*(t) − φ̂(t)‖ ≤ r(t) + Σ_m L_m [a_m(t) − τ_m]_+ + L_sched [overrun(t)]_+ = r_eff(t)`。
证明：对每个模态，把「超过契约的年龄」视为一次未观测的状态漂移，其幅度由 Lipschitz 界 `L_m·(a_m−τ_m)` 控制；对多个模态与调度抖动用三角不等式累加；`[·]_+` 保证不把「提前到达」当作负漂移。故真实误差被 `r_eff` 包住。∎

**引理 6（AMC 保 HI 可调度）** 若 `U_HI = Σ_{j∈HI} C_j^HI/T_j ≤ 1`（含切换预留），且 LO 作业在模式切换时可全部丢弃，则 AMC 下所有 HI 作业在 LO 与 HI 两种模式均满足截止期，模式切换开销至多一个控制周期。
证明：LO 模式下 HI 作业按 `C^LO ≤ C^HI` 执行，故 HI 负载不超过 `U_HI`；触发切换时，最多一个 HI 作业已执行超过其 `C^LO`，其后所有 HI 作业按更保守的 `C^HI` 调度，总负载仍 `≤ U_HI`。丢弃 LO 作业释放的处理器时间不小于切换开销（预留 `C_switch` 计入 `U_HI`）。故 HI 作业截止期在两种模式下均满足。∎

**定理 4（VoI 门控安全不降、交互代价有界）** 设每次查询只可能缩小不确定球（即 `E[ρ(after) − ρ(now)] ≥ 0`），阈值 `λ>0`，且 `ρ ∈ [ρ_min, ρ_max]`。则 VoI 门控策略的期望安全满足 `E[ρ_gated] ≥ E[ρ_baseline]`，且单回合期望交互代价
`E[Σ_i c_int(q_i)] ≤ (ρ_max − ρ_min)/λ + c_int^{max}`。
证明：门控只在 `E[Δρ] > λ·c_int + λ_D·D/D_rem ≥ λ·c_int` 时提问，因此每次提问有 `E[Δρ] > 0`，故总期望裕度不减，得安全不降。代价侧：每次提问满足 `c_int < E[Δρ]/λ`，而总裕度增益有界 `Σ E[Δρ] ≤ ρ_max − ρ_min`（单调且有限范围），故 `Σ c_int < (ρ_max−ρ_min)/λ`；最后一项为最多一次未完成查询的残余代价。∎

**定理 5（J_merit 可靠性）** 在 LIRO 假设（A77–A82）与引理 5/6 下，若 `Valid(J_merit)`，则真实空间干扰 `η*` 与真实时序误差下技能序列安全概率 `≥ 1 − α_dir − δ_cert − δ_time`；若任一 HI 截止期被违反，则 `J_merit` 在一个控制周期内失效并触发降级。
证明：由定义 206/215，`Valid(J_merit)` 蕴含 `Valid(J_liro at r_eff)`、`∀j slack_j ≥ 0`、`interaction_consistent`。引理 5 给出真实半径 `≤ r_eff`，故第 63 轮定理 3 的空间安全证明在 `r_eff` 下仍成立（概率 `1−α_dir−δ_cert`）；引理 6 给出 HI 截止期成立（时序误差概率 `1−δ_time`，`δ_time` 为 WCET 估计不确定度）。三者取并集界。失效方向：WCETGuard 的 slack 监控在超时发生时更新 `sched_mode`/`slack`，DTC 在下一控制周期必然读到负 slack 或 `OVERLOAD`，故一个周期内失效。∎

**命题 6（HUC 率失真界）** 对范围 `R = ρ_max − ρ_min` 的均匀 `K` 级量化，最大误差 `R/(2K)`，均方失真 `D_K ≤ R²/(12K²)`。欲达 `D_K ≤ ε_h`，需 `K ≥ R/(2√(3ε_h))`，即 `B ≥ ⌈log₂(R/(2√(3ε_h)))⌉` bit。若人可分辨级数上限为 `K_max(τ_h)` 且 `K > K_max`，则均匀量化不可行，须改用 Lloyd-Max 非均匀量化（危险区加密），或降低 `ε_h` 要求并同时给出「触觉仅作提示、不承担精确认证」的降级说明。∎

**命题 7（TPD 实时条件）** 若 HI 模块全部落在 MCU/SoC 且其最坏路径 `WCET_HI(d) = max_{j∈HI}(C_j^MCU + C_j^{bus}) ≤ min_j D_j`，同时所有 Cloud 模块均为 LO，则端到端实时性由 `WCET_HI(d)` 而非平均延迟决定；模型分区与 int8 量化使 `WCET_HI` 相对 fp32 基线下降 `≥ 40%`（典型 TinyML 蒸馏 + 量化收益），从而在 `≤2ms` 契约内为证书签发留出余量。∎

**正确性定理（MERIT-Complete）** 假设第 63 轮 A77–A82 及：
- **(A83)** MIB 时间戳单调、传输延迟 `≤ L_bus`；每模态新鲜度契约 `τ_m` 可被 EMC 的 HI 预算保障。
- **(A84)** 信息年龄对不确定半径的 Lipschitz 常数 `L_m`、调度抖动敏感度 `L_sched` 有有限上界（可离线标定）。
- **(A85)** HI 作业利用率 `U_HI ≤ 1`（含 `C_switch`），LO 作业可安全丢弃；控制与证书共享预算时证书优先。
- **(A86)** TPD 部署在 `𝒟_feas` 内且 WCET 估计保守（含 `η_j` 预留）；Cloud 仅承载 LO 模块。
- **(A87)** VoI 查询只会缩小不确定球（人答不与 belief 强冲突，否则按 HIL-CF 信任规则处理）。
- **(A88)** HUC 量化级数 `K ≤ K_max(τ_h)` 或已显式声明「触觉不承担精确认证」。

则：
1. **时序不确定性可认证**：输入年龄与调度抖动被折算为 `r_eff`，`Valid(J_merit)` 在真实时序误差下成立（引理 5、定理 5）。
2. **HI 安全环不被 LO 拖垮**：AMC 下 HI 两模式均满足截止期，模式切换 ≤ 1 控制周期（引理 6）。
3. **交互安全且代价有界**：VoI 门控安全不降、单回合交互代价 `≤ (ρ_max−ρ_min)/λ + c_max`（定理 4）。
4. **嵌入式部署可判定**：`𝒟_feas` 内的 TPD 部署满足 WCET/内存/功耗/总线约束，端到端 HI 路径 `< 2ms`（命题 7）。
5. **人纠正可对冲几何幻觉**：`geo_conflict` 触发半径抬高与 LSF 置信度下调，避免「错误小球内优化」（定义 210、第 63 轮风险）。
6. **失效可传播、可审计**：`J_merit` 在一个控制周期内失效并按原因进入 L0–L3 阶梯，`ask_log`/`sched_mode` 可追溯（定义 206/214/215）。

## 7. 已知风险

**一句话**：整套时序证书建立在**嵌入式目标机上的 WCET 估计**之上——一旦 WCET 被低估（缓存/总线争用、DVFS 与热降频、中断风暴），调度器可能在 `J_merit` 仍报告「有效」时已经错过 HI 截止期，**「时间」变成新的单点幻觉，恰是第 63 轮几何幻觉在时序维度上的镜像**。

**次级风险与缓解**：
1. **WCET 低估 / 热降频**：静态分析 + 目标机实测取上界；`η_j=15%` 预留 + 运行时 slack 监控 + 看门狗；热降频时主动进入 HI 模式并降采样 LO。仍失效时触发 L2/L3。
2. **交互延迟超预算**：人反应时间分布长尾——VoI 的 `D(q)` 用人反应经验分位数而非均值；超时即放弃查询并进入 L2。
3. **误纠正污染 belief**：`HIL-CF` 设信任阈值 `θ_trust` 与来源历史校准；低信任纠正只作软偏好、不改 `φ̂`。
4. **TAG 时序错配**：注视/指向与语言的时间窗错位——用 `W_a` 自适应（按语速/手势延迟标定），并对 `ambiguous` 强制反问而非猜测。
5. **HUC 带宽不足**：`K_max` 受人的判别力限制——触觉只承担「趋势/危险」提示，精确裕度仍由屏幕/语音承担；在 `K` 不足时显式降级证书语义。
6. **分区/量化破坏鲁棒性**：int8 量化可能放大对抗扰动——TPD 的目标函数加入「量化后 ρ_dir 不降」约束，E223 做量化前后 AIC 对比。
7. **HY 环与 LO 环共享缓存导致 WCET 抖动**：缓存分区/锁行（cache coloring）+ HI 作业绑定核；把「缓存争用」纳入 `L_sched` 标定。
8. **多操作员冲突**：MIB 的 `s_k` 归属与权限模型，仅授权来源的 `human_ack` 能解锁高风险技能。
