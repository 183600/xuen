# 第 10 轮（本轮灵感：「LoRA」×「价值对齐」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**低秩价值转向 + 安全零空间投影 + 矫正式撤销**。两个灵感治理 v9 的三种债：价值债（六层指标只是人类价值的代理，Goodhart 风险从未被正视）、权威债（任何在线学习都可能无界改写策略）、诚实债（块证书把 β 当假设而非可测项）。核心约束：价值适配只拥有「低秩、有界、可撤销」的转向权限；撤销即注入 ΔW=0（恒等适配器），严格逐位退回 v9。

## 0. 直觉与动机

**灵感 1（LoRA → 有界的价值转向权限）**
直觉：LoRA 把微调写成 ΔW=BA，秩 r≪d。工程上它省显存；但对我们更重要的是它的**语义**：低秩 = 低维、可审计、可加、可合并/可撤销。于是可以把「价值对齐」从「重训一个对齐策略」降级为「在冻结基座上叠加一个小的价值方向盘」。这个方向盘的**秩 r 与谱范数 ρ 就是价值权威预算**：它能转向，但不能把系统扳出安全盆。撤销 = 把 ΔW 置零 = 精确回到基座。

**灵感 2（价值对齐 → 安全零空间内的价值投影 + 矫正性 + 诚实）**
直觉：机器人优化的是代理指标（六层 M），而不是人类真正在意的价值（安全、体贴、诚实、尊重操作员权威）。朴素做法是加罚项，但罚项既不保安全也不可审计。更严谨的做法：把安全不变式 g(W) 线性化为 J_g，要求价值适配**只住在 J_g 的零空间里**——一阶上完全不改变安全输出；再用二阶余项与范数预算兜底。同时引入「影响预算」（任何单一价值维度/操作员不能独占转向权）、「矫正性」（随时可撤销）、「诚实」（证书必须公开自身误差，不得过度宣称）。

**灵感 3（交叉 → 用 LoRA 把 v9 最大的风险变成可测量项）**
直觉：v9 的最大风险是「β 是假设，且域偏移时 β 最不可信」。LoRA 的范数天然给出误差增量界：对前向模型做秩 r_f、范数 ρ_f 的在线低秩适配，则模型误差可写成 β(t)=β₀+L_f‖ΔW_f‖+δ_cal——一个**可测、有界、可回退**的量。诚实证书由此落地：系统不再「假定」误差，而是「声明」误差；信任域破坏时冻结适配、δ→0，退回 β₀。

## 1. 研究问题（轮次升级版）

- **Q1（安全零空间可靠性）**：在什么光滑性与范数预算下，把价值适配投影到 J_g 零空间能保证真实安全函数一阶不变、且二阶余项 ≤ ε_safe？当域偏移使 J_g 失真时，证书如何失效而非误报？
- **Q2（价值表达力 vs 权威预算）**：秩预算 R_max 与影响预算 C_value 如何同时约束「单一价值维度的支配」与「整体对齐的非空洞性」？存在可判定的非空洞判据吗？
- **Q3（矫正性与诚实性）**：合并/撤销能否做到与 v9 策略逐位等价？价值漂移（Goodhart）如何在触发真实价值违背前被检出并自动撤销？
- **Q4（诚实证书）**：TrustLoRA 的范数界能否把 v9 的 β 假设转为可测上界，并在域偏移中收紧 K_eff 的误缩/漏缩？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P17）

**P13 低秩价值转向律（Low-rank Value Steering, LoVA）** 价值适配只以 ΔW=BA（rank r≤R_max）叠加于冻结基座 W₀；秩与谱范数是价值权威预算，不是超参。

**P14 安全零空间投影律（Safety-Null-Space Projection, SNSP）** 价值适配先投影到安全雅可比的零空间：vec(ΔW̃)=P_⊥ vec(ΔW)，P_⊥=I−J_g⁺J_g。要求 ‖J_g vec(ΔW̃)‖≤ε_g 且二阶余项 r₂≤ε₂，安全一阶不变、二阶可控。

**P15 可撤销矫正律（Corrigible Unmerge, CU）** 合并是加法、撤销是精确还原：unmerge 逐位恢复 W₀，行为与 v9 策略逐位等价；价值漂移或证书失效时自动 unmerge。

**P16 价值影响预算律（Value Influence Budget, VIB）** 组合适配器满足 Σr_i≤R_max、Σ|λ_i|‖ΔW̃_i‖₂≤C_value、单维 |λ_i|‖ΔW̃_i‖₂≤c_i；任一价值维度/操作员不能独占转向权。

**P17 诚实证书律（Honest Certificate, HC）** 前向模型在线低秩适配受信任域门控，误差界 β(t)=β₀+L_f‖ΔW_f‖₂+δ_cal 必须写入块证书；信任域破坏时冻结适配、δ→0、β→β₀，退回 v9 证书语义。

## 3. 与基线的接口（如何退化）

- VC 失效（秩/权威/零空间/二阶/输出任一越界）⇒ λ 投影到证书包络 E；仍失效 ⇒ unmerge，ΔW≡0，逐位等于 v9；
- SNSP 失效（J_g 病态/过期）⇒ 标量收缩 s↓ 直到认证，仍不行为 unmerge（恒等适配器）；
- VDA 失效/漂移 ⇒ 自动 unmerge 并冻结适配器，价值中立 = v9；
- CMC 失效 ⇒ 参数快照还原（非 LoRA 路径，代码保留），等价 v9；
- TrustLoRA 失效 ⇒ β←β₀、冻结 ΔW_f，K_eff 退回 v9 默认门控；
- v9 的 AC/MW/ID 失效 ⇒ 走 v9 五级链；
- 全部失效 ⇒ v8 → v7 → v6。

关键结构性保证：λ=0 恒在包络 E 内（ΔW=0 使所有约束取零），故「退回路径不可达/不可行」问题不存在——这是 P14/P15 的代数性质，不是容错约定。

## 4. 预期贡献

1. **有界价值转向**框架：把价值对齐量化为低秩、有范数界、可合并/可撤销的适配器代数码；
2. **安全零空间证书**：价值适配的「不动安全」从经验调参升级为一阶精确 + 二阶可界的形式化条件；
3. **矫正性 by construction**：撤销 = 恒等元，退化链不是「容错」而是「代数恒等式」；
4. **诚实证书 + TrustLoRA**：把 v9 的 β 假设变成可测上界，直接作用于其最大风险；E571–E592 覆盖秩扫描、零空间功效、撤销等价、漂移检测、多操作员与端到端。

## 5. 本轮最大风险

**一句话**：安全零空间与价值证书都建立在 W₀ 处对安全函数 g 的局部线性化 J_g 之上，而域偏移与长时运行恰恰让 J_g 失真——于是出现两个对称失败：要么「已认证」的适配器在真实安全函数上越界（假安全），要么零空间过严使可表达的价值变化坍缩为 0（假对齐、空证书）。

## 1. 符号体系增量（定义 540–552）

**新增定义 540（价值适配器 ValueAdapter）** 对价值维度 i，ΔW_i = B_i A_i，秩 r_i = rank(ΔW_i) ≤ R_max，谱范数 ρ_i = ‖ΔW_i‖₂。基座 W₀ 冻结；仅适配器参与价值训练/选择。价值维度基（定义 550）至少含：安全余量、速度-体贴、社交距离、诚实/不确定性表达、操作员权威。

**新增定义 541（安全泛函与零空间 SafetyFunctional）** g: ℝ^d→ℝ^m 聚合各硬/软安全证书余量；在 W₀ 处线性化 g(W₀+δW) = g₀ + J_g vec(δW) + R₂(δW)，其中 ‖R₂(δW)‖ ≤ ½ L_g‖δW‖²（L_g 为 J_g 的 Lipschitz 常数）。保留 ‖J_g 行‖≥τ_J 的行为安全关键行，得 J_g^c；零空间投影 P_⊥ = I_d − (J_g^c)⁺ J_g^c。

**新增定义 542（零空间投影适配器 ProjectedAdapter）** ΔW̃_i = mat(P_⊥ vec(ΔW_i))；投影误差 ε_i^⊥ = ‖J_g vec(ΔW̃_i)‖。要求 ε_i^⊥ ≤ ε_g（一阶安全不变）。若 P_⊥ 退化为 0 投影（零空间为空），则该适配器不可用——这正是「假对齐」风险的来源，必须显式暴露。

**新增定义 543（价值证书 ValueCertificate, VC）** 组合系数 λ∈ℝ^n 的证书五条：
```
(i)   秩预算      Σ_i r_i ≤ R_max
(ii)  权威预算    ‖Σ_i λ_i ΔW̃_i‖₂ ≤ C_value
(iii) 零空间      ‖J_g vec(Σ_i λ_i ΔW̃_i)‖ ≤ ε_g
(iv)  二阶余项    r₂(ΔW_λ) := sup_{‖δW‖≤ρ} |g(W₀+δW) − g₀ − J_g vec(δW)| ≤ ε₂
(v)   输出偏差    S_π(x)·‖vec(ΔW_λ)‖ ≤ ε_out   （S_π 为策略对权重的局部敏感度上界）
```
有效 ⇔ 五条全部成立。注意 (iv)(v) 是「兜底」而非「装饰」：它们把「一阶零空间 + 实际非线性」的缝隙显式量化。

**新增定义 544（组合与合并 Composition/Merge）** W_λ = W₀ + Σ_i λ_i ΔW̃_i。合并为加法；撤销为移除加项并恢复 W₀。λ 分量非负时若 ΔW̃_i 沿正价值方向，则价值坐标对 λ_i 单调（引理 91 的元素）。

**新增定义 545（价值影响预算 ValueInfluenceBudget）** 全局 Σ_i |λ_i|ρ_i ≤ C_value；单维 |λ_i|ρ_i ≤ c_i；总秩 Σ_i r_i ≤ R_max。预算的作用不是「省算力」，而是**限制任何单一价值维度或单一操作员能施加的行为改变量**（反价值捕获，引理 90/91）。

**新增定义 546（矫正性算子 CorrigibilityOperator）** unmerge: W_λ ↦ W₀，逐位精确（保留基座快照）。merge 与 unmerge 均为 O(d·r)；合并后推理零开销（LoRA 标准合并），unmerge 延迟 ≤1 控制周期。unmerge 后策略与 v9 逐位等价（引理 89）。

**新增定义 547（价值漂移/Goodhart 检测器 ValueDriftAuditor）** 设偏好探针集 D_pref，参考价值分 V_ref；对部署中的 λ 测行为价值分 V_π(λ) 与代理指标 J_proxy(λ)。发散统计
```
D_t = EMA_τ( div( V_π(λ_t) − V_π(0),  J_proxy(λ_t) − J_proxy(0) ) )
```
若 D_t > τ_drift 持续 H_drift 周期 ⇒ 自动 unmerge + 冻结适配器。直觉：代理涨、价值不涨（或反降）= Goodhart 的签名。

**新增定义 548（诚实前向模型适配 TrustLoRA & HonestBeta）** 对 F̂ 做低秩增量 ΔW_f，秩 r_f≤R_f，范数 ‖ΔW_f‖₂≤ρ_f，仅在信任域 U_t（v9 定义）内更新。误差界 β(t)=β₀+L_f‖ΔW_f‖₂+δ_cal 必须写入块证书（升级定义 533）。信任域破坏或证书连续失效 ⇒ 冻结 ΔW_f（β→β₀），退回 v9 证书语义。

**新增定义 549（价值一致动作选择 ValueAlignedSelection）** 在通过 VC 与 v9 块证书的候选中，选择 argmax 偏好分 V(ζ)，并列时取最小影响 ‖vec(ΔW_λ)‖₂（最小侵入原则）。**安全证书是先决过滤，不是可交易项**——价值分不能补偿安全违约。

**新增定义 550（价值维度基 ValueDimensionBasis）** v = (v₁,…,v₅) 对应（安全余量、速度-体贴、社交距离、诚实、操作员权威），每维附独立探针与适配器。价值状态报告为 v 向量，供操作员审计；维度间冲突由影响预算仲裁（定义 545）。

**新增定义 551（价值不可行性拒止 ValueInfeasibleRefusal）** 若 E 内的最优 λ 仍达不到操作员指令的最低价值分（δ_val 门槛），系统选择 base 行为并**显式输出不确定性/拒绝信号**（诚实），而非越界迎合。即「对齐失败必须可被看见」，不得静默降级。

**新增定义 552（价值证书包络 ValueEnvelope）** E = {λ : VC(λ) 成立}；因 (i)(ii)(iii)(v) 为范数/仿射约束、(iv) 在 ρ 域内为二次约束，E 为凸集且 0∈E。部署取 λ* = Π_E(λ_target)（欧氏投影）。恒含 0 是「永远可安全退回 v9」的结构性保证（引理 94）。

## 2. 对 v9 定义的升级

**升级定义 533（块证书，v10）** β 由常量变为诚实值 β(t)，证书同时携带「β(t) 来源（ΔW_f 范数）」与「当前活动适配器 λ 的 VC 见证」。证书有效 ⇔ ĝ_min ≥ d_safe ∧ ê_max ≤ τ_eff ∧ γ̂_grasp valid ∧ VC(λ) ∧ (β(t) 为当前值)。

**升级定义 539（有效块长，v10）** 信任域门控追加 β 项：
```
K_eff(t) = 1                                          若 U_t 不成立 ∨ VC(λ) 不成立
         = max(1, ⌊K_max·(1 − Δ_dom/τ_dom)·β₀/β(t)⌋)    否则
```
模型误差越大块越短：把 v9「β 假设失效」的风险转成 K_eff 的主动收缩（引理 93 联合 82）。

**升级定义 496/531（软证书与软硬衔接，v10）** δ_trigger 追加条件「VC(λ) 成立」；价值适配不得绕过 M₀ 硬检查，unmerge 是唯一的价值层熔断动作，且与 v9 退化动作可交换（先安全后价值）。

## 4. 推导

**引理 87（零空间一阶安全不变 + 二阶可控）** 设 vec(ΔW) ∈ null(J_g)，则 g(W₀+ΔW) = g₀ + R₂(ΔW)，‖R₂‖ ≤ ½L_g‖ΔW‖²。含投影误差时 g(W₀+ΔW̃) = g₀ + J_g vec(ΔW̃) + R₂，故真实安全偏差 ≤ ε_g + ½L_gρ²。当 ε_g + ½L_g C_value² ≤ ε_safe 时安全不越界。证明：线性化定义 541 直接给出；用 P_⊥ 的像含于 null(J_g^c) 得 J_g^c vec(ΔW̃)=0 至 ε_g；二阶项由 Jensen/Taylor 余项界。∎

**引理 88（价值证书的输出偏差界）** 若策略对权重的局部敏感度为 S_π(x)，则 ‖π(x;W_λ) − π(x;W₀)‖ ≤ S_π(x)‖vec(ΔW_λ)‖。由定义 545 的权威预算，输出偏差 ≤ S_π(x)·C_value；组合系数满足三角不等式：‖ΔW_λ‖ ≤ Σ|λ_i|ρ_i。故价值适配的行为改变有可证上界。∎

**引理 89（撤销的精确等价 / 矫正性）** unmerge 恢复基座快照 W₀ 逐位相同 ⇒ 对任意输入，策略输出与 v9 逐位等价（在相同确定性执行下）。merge 仅是「恢复 W₀ 后再加 ΔW_λ」，不累积浮点漂移。故价值层任何失效都能严格退化为 v9，而非统计近似。∎

**引理 90（秩预算限制价值表达力与捕获）** ΔW_λ = Σλ_i B_i A_i 的秩 ≤ Σr_i ≤ R_max；其对任意输入的作用 ΔW_λ x 落在一个维数 ≤R_max 的子空间。故单一适配器或单一价值维度最多改变 R_max 维策略方向，无法无界捕获整个策略。∎

**引理 91（影响预算 ⇒ 无单维/单操作员越权）** 对任一价值探针 p（梯度范数 ≤L_p），|p(W_λ) − p(W₀)| ≤ L_p‖vec(ΔW_λ)‖ ≤ L_pΣ|λ_i|ρ_i ≤ L_p C_value；单维贡献 ≤ L_p c_i。因此任一价值维度/操作员的行为影响被 c_i 封顶，且价值坐标（沿正方向）对 λ_i 单调。∎

**引理 92（漂移检测的条件可靠性）** 设偏好探针集在行为相关价值空间上 ε_cover-稠密。若真实价值分下降而 D_t ≤ τ_drift，则未被检出的价值违背量 ≤ ε_cover + 探针噪声；若 D_t > τ_drift 则 H_drift 周期内触发 unmerge。故在覆盖假设下，Goodhart 在造成 > (ε_cover+噪声) 价值损失前被熔断；无覆盖保证时检测器不构成安全证书（仅作附加保护）。∎

**引理 93（TrustLoRA 的有界 β 与诚实性）** 前向模型低秩适配输出变化 ≤ L_f‖ΔW_f‖₂；故 β(t)=β₀+L_f‖ΔW_f‖₂+δ_cal 是保守误差上界，v9 引理 82 的前提从「假设」变为「可测」。冻结（ΔW_f↛ 更新）或归零使 β→β₀，K_eff 按升级定义 539 保守收缩。域偏移下 β(t) 增大先于 K_eff 收缩，故不会出现 v9 的「证书已失效仍取大块」。∎

**引理 94（包络非空与退回存在性；非空洞性待检）** 0∈E：λ=0 ⇒ ΔW=0，五条约束分别取 0≤R_max、0≤C_value、0≤ε_g、0≤ε₂、0≤ε_out，全部成立。故 Π_E 总有解，unmerge 永远可行。但 E 可能恰为 {0}（零空间为空或预算过紧）——此时「对齐」是空的。故**非空洞性不是定理，而是必须由 E574/E578 实测的经验命题**：∃λ≠0∈E 使探针价值提升 ≥ δ_val。∎

## 8. 本轮最大风险

**一句话**：安全零空间与价值证书都建立在 W₀ 处对安全函数 g 的局部线性化 J_g 之上，而域偏移与长时运行恰恰让 J_g 失真——于是出现两个对称失败：要么「已认证」的适配器在真实安全函数上越界（假安全），要么零空间过严使可表达的价值变化坍缩为 0（假对齐、空证书）。
