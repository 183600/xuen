### 第 1 轮灵感驱动研究记录（新循环 · 继承 CADVS-v4 / IP-489~492）

**灵感词**：热管理、动作空间

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点之上加入价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3·η_val·η_bal；执行集 Exec_v4 ⊆ Exec_v3 ⊆ Exec_v2 ⊆ Exec_v1 ⊆ Exec_v29。本轮为新灵感循环的第 1 轮，不推翻 v4，而是沿「热管理」「动作空间」两个方向补强，形成 CADVS-v5（IP-493~496），执行集嵌套升级为 Exec_v5 ⊆ Exec_v4 ⊆ Exec_v3 ⊆ Exec_v2 ⊆ Exec_v1 ⊆ Exec_v29。

**直觉与动机**：

1. **热管理：物理合法性有时间维度，慢变量会杀死快系统**。v1~v4 的所有锚点都默认「执行器可以无限期提供当前力矩」。真实机器人不是：电机绕组、减速器、电池与计算单元都有热上限；铜损 ≈ τ²R_w/k_t(T)² 随力矩平方增长，而 k_t(T) 又随温度升高而下降（NdFeB 约 −0.1%/°C），形成「温度↑ → 同力矩需更大电流 → 损耗↑ → 温度↑」的正反馈。结果是：控制环每个周期都通过 kc_bal/kc_ee，但连续高强度作业几分钟后 τ_max 被热降额，Wrench 锥与动作空间悄然收缩，最终丢力、触发保护甚至退磁。热失效的隐蔽性正在于其时标是分钟级，而现有全部硬门是毫秒级。引入热安全核 TSK：集总热模型在线预测各节点温度 T_i 与到限时间 t_lim，硬门 kc_therm 要求温度留余量、t_lim 覆盖前瞻窗口、施加力矩不超降额包络 τ_max(T)；软因子 η_therm 度量热余量。关键工程红利：热是慢时标，可在 ~1 Hz 更新并缓存 τ_max，1 kHz 控制环只读缓存，几乎零额外开销——这反而部分缓解 v4 的实时性风险。

2. **动作空间：把「证书通过」几何化为「动作落在认证集合内」**。v1~v4 反复使用「执行集 Exec」「Wrench 锥 W」，却从未显式回答：策略当下提出的动作 a，是否落在所有证书允许的动作空间内？引入动作空间证书核 ASCK：把每个硬门解释为状态-动作空间中的一个安全集 S_i(x)，其交集即**认证动作空间** CAS(x,t) = ∩_i S_i(x)。对策略动作 a_prop 做投影 a_safe = Proj_{CAS}(a_prop)，得到动作空间证书 ASC = (a_prop, a_safe, d_proj, ρ_reach, t)。硬门 kc_action 要求 CAS 非空、投影距离 d_proj ≤ δ_max、可达性/控制障碍函数边际 ρ_reach ≥ 0；软因子 η_action = 1 − d_proj/δ_max。这把抽象的证书格变成了可求解的凸集（多面体 ∩ 二阶锥），使安全过滤（QP/CBF）第一次拥有证书语义。

3. **二者耦合：热是 CAS 的慢时变收缩源，动作空间是 CAS 的每周期成员检查**。热降额直接改写 CAS 的一条边（A_therm: |τ| ≤ τ_max(T)），而动作空间投影把热、平衡、覆盖、末端、动力学约束统一成一个凸投影问题。于是 v5 的核心洞见是**证书-动作空间对偶**：Exec 是证书格的语义，CAS 是 Exec 在动作空间的截面；每新增一个硬门，就是在 CAS 上多切一刀。热管理贡献慢时变的那一刀，动作空间锚负责每周期检查点是否还在多面体内。

**关键洞见**：v4 回答「证据是否充分」；v5 回答「在热约束下，当前动作是否仍在证据允许的动作空间内」。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_therm ∧ kc_action，fail-closed；软评分 ECS_v5 = ECS_v4 · η_therm · η_action。

**形式化目标（增量）**：

1. 集总热模型：C_i·Ṫ_i = P_i^loss − (T_i − T_amb,i)/R_i，P_i^loss = τ_i²R_{w,i}/k_{t,i}(T_i)² + b_i|ω_i| + P_{0,i}；k_{t,i}(T) = k_{t,i}^0·(1 − α_m(T − T_0))。
2. 热降额包络 τ_max,i(T_i) = τ_rated,i·g_i(T_i)，g_i 为分段线性；到限时间 t_lim,i = inf{t : T_i(t) ≥ T_max,i}；局部热失控裕度 Λ_run,i = 1/R_i − ∂P_i^loss/∂T_i。
3. 热证书 TSC = (T_vec, k_t_vec, τ_max_vec, t_lim_vec, Λ_run_vec, t)；kc_therm = (∀i T_i ≤ T_max,i − ΔT_m) ∧ (∀i t_lim,i ≥ H_therm) ∧ (∀i |τ_i| ≤ τ_max,i) ∧ (∀i Λ_run,i > 0)；η_therm = min_i clip((T_max,i − T_i)/(T_max,i − T_warn,i), 0, 1)。
4. 认证动作空间 CAS(x,t) = ∩_{S∈{therm,dyn,bal,ee,cover,safe}} A_S(x,t)；动作证书 ASC = (a_prop, a_safe, d_proj, ρ_reach, t)；kc_action = (CAS ≠ ∅) ∧ (d_proj ≤ δ_max) ∧ (ρ_reach ≥ 0)；η_action = 1 − d_proj/δ_max。
5. 证书-动作空间对偶定理：Exec_k(x,t) = ∩_{i≤k} S_i(x,t) = CAS_k(x,t)，且 Exec_{k+1} ⊆ Exec_k ⇒ CAS_{k+1}(x) ⊆ CAS_k(x)；各动作型 S_i 凸 ⇒ CAS 凸、投影唯一。
6. 双时标引理：热时标 τ_th = min_i R_iC_i ≫ dt；以 δt_s = 1 s 缓存 τ_max 相对 1 kHz 控制环的降额误差 ≤ L_g·(P_max/C)·δt_s，被 ΔT_m 吸收。
7. 定义 EFA-v5 九硬门 + 软评分 ECS_v5 = ECS_v4·η_therm·η_action；定义 Exec_v5 ⊆ Exec_v4（在 v4 每条路径上追加 kc_therm 与 kc_action，只缩不涨）。

**本轮最大风险**：**热降额、平衡与覆盖三类约束在 CAS 上交叠，可能使认证动作空间退化为空集或过窄，安全过滤器被迫频繁投影/接管，出现「安全但不可用」的可行死锁；而热模型失配（k_t(T) 正反馈、未建模热源）会同时污染 τ_max 与 CAS，导致误拒或误放。**

### IP-493 TSK：热安全核（慢时域，~1 Hz；控制环只读缓存）

```python
@dataclass
class ThermalSafetyKernel:
    """TSK：集总热模型 + k_t(T) 正反馈 + 降额包络 + 到限保守预测；kc_therm 硬门"""
    R_th: np.ndarray            # 每节点热阻 [K/W]
    C_th: np.ndarray            # 每节点热容 [J/K]
    R_w: np.ndarray             # 绕组电阻 [Ω]
    kt0: np.ndarray             # 标称转矩常数 [Nm/A]
    alpha_m: float = 1e-3       # k_t 温度系数 [/K]（NdFeB ~1e-3）
    T0: float = 298.15
    T_amb: np.ndarray = None
    T_warn: np.ndarray = None   # 降额起点
    T_max: np.ndarray = None    # 绝对上限
    tau_rated: np.ndarray = None
    b: np.ndarray = None
    P0: np.ndarray = None
    dT_margin: float = 5.0      # K，温度安全余量
    H_therm: float = 60.0       # s，前瞻窗口

    def update(self, tau_applied, omega, dt_slow: float, t_now: float) -> TSC:
        # 1) 温变转矩常数（正反馈源）
        kt = self.kt0 * (1.0 - self.alpha_m * (self.T - self.T0))
        # 2) 损耗：铜损随 1/kt² 增长，摩擦/铁损随 |ω|
        P_cu = tau_applied**2 * self.R_w / kt**2
        P_loss = P_cu + self.b * np.abs(omega) + self.P0
        # 3) 集总热 ODE：C Ṫ = P_loss − (T − T_amb)/R
        dT = (P_loss - (self.T - self.T_amb) / self.R_th) / self.C_th
        self.T = self.T + dt_slow * dT            # 慢时标，显式积分稳定
        # 4) 分段降额包络
        g = np.clip((self.T_max - self.T) / (self.T_max - self.T_warn), 0.0, 1.0)
        tau_max = self.tau_rated * g
        # 5) 到限时间保守下界：在 T_max 处取最坏 k_t（最小），使损耗最大
        kt_worst = self.kt0 * (1.0 - self.alpha_m * (self.T_max - self.T0))
        P_worst = tau_applied**2 * self.R_w / kt_worst**2 \
                  + self.b * np.abs(omega) + self.P0
        T_ss = self.T_amb + self.R_th * P_worst
        t_lim = self._time_to_limit(self.T, T_ss, self.T_max)  # 见引理 43
        # 6) 局部热失控裕度
        dPcu_dT = 2.0 * tau_applied**2 * self.R_w * self.alpha_m / kt**3
        runaway = 1.0 / self.R_th - dPcu_dT
        return TSC(self.T.copy(), kt, tau_max, t_lim, runaway, t_now)

    def kc_therm(self, tsc: TSC, tau_applied) -> bool:
        """引理 43：通过 ⟹ 前瞻窗口内不越热上限且力矩在降额包络内"""
        return bool(np.all(tsc.T <= self.T_max - self.dT_margin)
                    and np.all(tsc.t_lim >= self.H_therm)
                    and np.all(np.abs(tau_applied) <= tsc.tau_max)
                    and np.all(tsc.runaway > 0.0))

    def eta_therm(self, tsc: TSC) -> float:
        return float(np.min(np.clip(
            (self.T_max - tsc.T) / (self.T_max - self.T_warn), 0.0, 1.0)))

    @staticmethod
    def _time_to_limit(T0, T_ss, T_max) -> float:
        # T(t)=T_ss+(T0−T_ss)e^{−t/(RC)}，解 T(t)=T_max 得保守下界
        if T_ss <= T_max:
            return np.inf
        return -np.log((T_max - T_ss) / (T0 - T_ss))  # 乘以 R·C 在调用处
```

> 注：`_time_to_limit` 的返回需乘 `R_th·C_th`；此处略写以突出结构。

### IP-494 ASCK：动作空间证书核（控制环内，投影 QP 目标 < 0.5 ms）

```python
@dataclass
class ActionSpaceCertificateKernel:
    """ASCK：CAS = ∩ 动作安全集；凸投影求 a_safe；kc_action 硬门"""
    delta_max: float = 0.15        # 归一化投影距离上限
    solver: str = "osqp"

    def certify(self, x, a_prop, t_now, tsc, bcc, eec, ctx) -> ASC:
        # 1) 逐锚点构造动作安全集（线性化后均为盒/多面体/SOC）
        A_therm = self._box(-tsc.tau_max, tsc.tau_max)          # 热降额
        A_dyn   = self._dyn_constraints(x)                      # 关节/加速度限
        A_bal   = self._balance_constraints(x, bcc)             # Wrench 锥/ZMP/被动性
        A_ee    = self._ee_constraints(x, eec)                  # 末端力/位姿
        A_cover = self._coverage_constraints(x, ctx)            # 线性化可达集 ⊆ Γ_3D
        A_safe  = self._cbf_constraints(x)                      # CBF h(x,a) ≥ 0
        A_val   = self._value_constraints(x, ctx)               # VACK 缓存的不可行域
        CAS = intersect(A_therm, A_dyn, A_bal, A_ee,
                        A_cover, A_safe, A_val)
        # 2) 任一状态型硬门失败 ⇒ CAS = ∅（fail-closed）
        if CAS.is_empty():
            return ASC(a_prop, None, np.inf, -np.inf, t_now, feasible=False)
        # 3) 凸投影 QP：min ½‖a−a_prop‖²  s.t. a ∈ CAS（温启动）
        a_safe = CAS.project(a_prop, solver=self.solver, warm_start=True)
        d_proj = float(np.linalg.norm(a_prop - a_safe)) / self._diam(CAS)
        rho = CAS.min_slack(a_safe)                            # 符号距离/最小松弛
        return ASC(a_prop, a_safe, d_proj, rho, t_now, feasible=True)

    def kc_action(self, asc: ASC) -> bool:
        """引理 44/定理 5：通过 ⟹ 存在认证动作且投影误差有界、在安全集内部"""
        return (asc.feasible and asc.d_proj <= self.delta_max
                and asc.rho_reach >= 0.0)

    def eta_action(self, asc: ASC) -> float:
        if not asc.feasible:
            return 0.0
        return float(np.clip(1.0 - asc.d_proj / self.delta_max, 0.0, 1.0))
```

# 定理 5（证书-动作空间对偶）
def theorem_cert_action_duality() -> str:
    """
    设 S_i(x)={a: kc_i(x,a)=⊤}，CAS_k(x)=∩_{i≤k}S_i(x)。则：
    (i)  Exec_k(x) = CAS_k(x)（Exec 在 x 的动作截面恰为 CAS）；
    (ii) kc_evidence_forged_v5(x,a)=⊤ ⟺ a ∈ CAS(x)；

def lemma_two_timescale() -> str:

### IP-496 EFA-v5：九硬门 + 软评分 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；ECS_v5 = ECS_v4·η_therm·η_action"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    tsk: ThermalSafetyKernel
    asck: ActionSpaceCertificateKernel
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, a_prop, t_now, rule_id, hic, eec, bcc, tsc,
                  object_class, geo_sig, theta_domain_fp,
                  traj, context) -> tuple[bool, str, ASC]:
        # 优先级：HIC veto 最高；其余并行评估，任一失败即拒（fail-closed）
        if self.hic.veto_active(hic):                 return False, 'HIC_STOP', None
        if not self.scf.kc_coverage(x, t_now):        return False, 'COVERAGE_BLIND', None
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN', None
        if not self.eek.kc_ee(eec):                   return False, 'EE_UNPROVEN', None
        if not self.bck.kc_bal(bcc):                  return False, 'BALANCE_UNSTABLE', None
        pass_mem, eta_mem, novelty = self.ltem.query(
            object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                              return False, 'MEMORY_REJECT', None
        vac = self.vack.evaluate(traj, context, t_now)
        if not self.vack.kc_val(vac):                 return False, 'VALUE_MISALIGNED', None
        # --- v5 新增：先慢时域热门，再动作空间投影门 ---
        if not self.tsk.kc_therm(tsc, a_prop):        return False, 'THERMAL_LIMIT', None
        asc = self.asck.certify(x, a_prop, t_now, tsc, bcc, eec, context)
        if not self.asck.kc_action(asc):              return False, 'ACTION_INFEASIBLE', asc
        return True, 'FORGED' + ('|NOVELTY' if novelty else ''), asc

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5, eta_therm=0.5, eta_action=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        return base * eta_mem * eta_val * eta_bal * eta_therm * eta_action
```

## 4. 正确性论证（增量更新）

### 引理 43（热降额的单调性与到限时间下界）

**陈述**：设 P_i^loss 关于 T_i 单调不减（α_m>0 且 T<T_0+1/α_m），则降额因子 g_i(T) 关于 T 单调不增，τ_max,i(T) 单调不增。若在 T_max 处取最坏 k_t（最小）得到 T_ss^max = T_amb + R·P_loss(T_max)，则真实到限时间满足 t_lim ≥ −R C·ln((T_max−T_ss^max)/(T_0−T_ss^max))（当 T_0 < T_max < T_ss^max）；若 T_ss^max ≤ T_max 则 t_lim = ∞。

**证明**：P_loss 关于 T 递增，故用 T_max 处损耗构造的常系数 ODE 是真实温度的上解（比较原理）；解上解触及 T_max 的时刻不晚于真实系统，取其负号得下界。g_i 的分段线性形式对 T 单调不增，复合保持单调。∎

**工程含义**：kc_therm 用保守下界，不会因模型低估而误放；k_t(T) 正反馈被显式纳入，避免「冷态标定、热态失控」。

### 引理 44（CAS 凸性与投影唯一性）

**陈述**：若每个动作型安全集 A_S(x,t) 为闭凸集（盒、多面体或二阶锥），则 CAS = ∩_S A_S 闭凸；若 CAS 非空，则 Proj_CAS(a_prop) = argmin_{a∈CAS} ½‖a−a_prop‖² 存在且唯一，且 a_safe 满足变分不等式 ⟨a_prop−a_safe, a−a_safe⟩ ≤ 0, ∀a∈CAS。

**证明**：闭凸集之交闭凸；严格凸二次目标在非空闭凸集上有唯一极小元（Hilbert 投影定理）；变分不等式为一阶最优性条件。∎

**工程含义**：CAS 可行性可用 QP 判定；投影是确定性的，不引入随机性；不可行即 kc_action=⊥，fail-closed。

### 定理 5（证书-动作空间对偶）

**陈述**：定义 S_i(x) = {a : kc_i(x,a) = ⊤}，CAS_k(x) = ∩_{i≤k} S_i(x)。则 (i) Exec_k(x) = CAS_k(x)；(ii) kc_evidence_forged_v5(x,a)=⊤ ⟺ a ∈ CAS(x)；(iii) Exec_{k+1} ⊆ Exec_k ⇒ ∀x, CAS_{k+1}(x) ⊆ CAS_k(x)；(iv) 动作型 S_i 凸且 CAS 非空闭 ⇒ 投影唯一。

**证明**：(i)(ii) 由「九硬门是合取」与截面定义直接展开：a 通过全部硬门 ⟺ a 属于每个 S_i ⟺ a∈CAS。(iii) 交集随集合数增加只缩不涨。(iv) 引理 44。∎

**工程含义**：抽象的「证据铸造」第一次有了几何对应物——认证动作空间多面体；安全过滤（QP/CBF）与证书语义统一，可解释、可审计。

### 引理 45（双时标误差界）

**陈述**：热时标 τ_th = min_i R_iC_i，控制周期 dt=1 ms，慢更新周期 δt_s。若区间内损耗有界 P_max,i，则 |ΔT_i| ≤ (P_max,i/C_i)δt_s，|Δτ_max,i| ≤ L_g,i(P_max,i/C_i)δt_s =: ε_derate。当 ε_derate ≤ ΔT_m·L_g,i 时，1 Hz 缓存 τ_max 与连续更新在安全判定上等价。

**证明**：由 Ṫ_i = (P_loss − (T−T_amb)/R)/C 的右端有界性与比较原理得温度变化界；g_i 为 1/(T_max−T_warn) Lipschitz，复合得降额变化界；缓存滞后被温度安全余量 ΔT_m 吸收。∎

**工程含义**：热管理不进入 1 kHz 环，反哺 v4 的实时性风险；但快速热瞬变（堵转、猛加速）下 τ_th 局部变小，需在堵转检测时临时提高 TSK 更新频率。

### 定理 6（热感知严格收缩与九锚点声张）

**陈述**：在 v4 假设 (B1)~(B6) 之外追加 (B7) 热模型误差有界且 α_m 已知、(B8) CAS 各安全集凸近似包含真实安全集，则：
(i) Exec_v5 ⊂ Exec_v4（严格）；
(ii) 热越限通过率由引理 43 的保守 t_lim 与 ΔT_m 界；
(iii) 任一通过 kc_action 的动作满足 a_safe∈CAS 且 d_proj≤δ_max；
(iv) 证书-动作空间对偶成立（定理 5）；
(v) ECS_v5 = ECS_v4·η_therm·η_action ∈ [0, ECS_v4]。

**证明**：(i) v5 在 v4 每条路径/状态上追加 kc_therm 与 kc_action，只缩不涨；严格性由定理 6 的反例构造。(ii) 引理 43。(iii) 引理 44。(iv) 定理 5。(v) 各 η∈[0,1] 乘性。∎

**诚实声明**：(B7) 集总热模型忽略空间梯度与节点间耦合，τ_th 在堵转/强对流下可能偏差一个量级；(B8) 凸近似（尤其摩擦锥线性化与可达集线性化）是内近似，可能把真实可行动作误判为不可行（保守），反之若线性化方向错误则可能外近似（危险）。缓解：摩擦锥用内接多面体（保守）；热参数在线 RLS 辨识并放大 ΔT_m；CAS 不可行时回退到保守盒投影而非放行。

**一句话**：**热降额、平衡与覆盖三类约束在 CAS 上交叠，可能使认证动作空间退化为空集或过窄，安全过滤器被迫频繁投影/接管，出现「安全但不可用」的可行死锁；而热模型失配（k_t(T) 正反馈、未建模热源）会同时污染 τ_max 与 CAS，导致误拒或误放。**
