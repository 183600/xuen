# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「跨物体泛化」×「比赛策略」）

> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**泛化有界 + 策略不越权**。两个灵感分别治理 v10 的两种债：**泛化债**（τ_sem/β_STF 只在"见过的类别"上标定，而比赛恰恰用未见物体；STF 的类原型嵌入把"类别相似"误当"动力学相似"）、**策略债**（v10 把世界当平稳分布，安全预算近似均匀分摊；对手会挑最难物体/时刻，均匀裕量可被利用，审查预算也没有按威胁分配）。铁律不变：任一新模块失效 ⇒ 严格**等价**（几何/证书路径）或**支配**（新证据只许收缩、只许加严）于 v10，绝不行为漂移。

## 0. 直觉与动机

### 灵感 1（跨物体泛化 → 泛化的单位不是类别，而是可供性）

直觉：v10 的 STF 用 16 维类原型 e_{c_ℓ} 衡量"这个观测离已知类多远"。这在同分布内很好，但在比赛中会以两种方式失效：(i) 未见类别没有原型，只能落到最近已见类——距离小则被当作"非显著"放行，距离大则误杀；(ii) 更危险的是**可供性别名（affordance aliasing）**——两个物体在语义嵌入里很近（都是"杯子"），但质量、摩擦、易碎性、重心完全不同，前向模型误差可能相差一个量级。也就是说，"类别相似"不是"误差可控"的充分统计量。

跨物体泛化给的正确抽象是：**把物体商掉（quotient）到可供性空间**。只要两个物体在"质量、摩擦、柔顺、接触几何、危险/抓取可供性"上接近，前向模型的误差就应该接近，与它们是不是同一类无关。于是"未见物体"不再是不可知的，而是"已知可供性锚点 + 一段距离"；误差界随这段距离**线性膨胀**——这是一个可证的**泛化半径**。再把校准从"点阈值"升级为**按可供性分层的保形预测**：对新物体给出有限样本、分布无关的覆盖保证，而不是继续相信一个在已见类上调出来的 τ_sem。最后，对手会主动挑选物体分布；用**可供性-Wasserstein 球内的分布鲁棒保形**把"对手能把物体分布移动多远"变成显式预算 ε，覆盖保证对球内任意对手分布成立。

一句话对照：v10 说"τ_sem 在测试集上覆盖 99%"；v11 说"对任何与校准集在可供性度量下 Wasserstein 距离 ≤ε 的对手分布，覆盖 ≥1−α−δ(ε)"——把不可证的"分割召回"换成了可证、可调的泛化保证。

### 灵感 2（比赛策略 → 安全预算是稀缺资源，对手会挑最优点）

直觉：比赛里三个事实改变优化问题：(i) 评分是**名次**而非绝对分，灾难性失败比平庸更伤；(ii) 对手会观察你、挑选你覆盖最薄的物体/时刻/扰动；(iii) 审查（NRB 5Hz 全审、教师查询、人工复核）是**有限预算**，v10 却近似均匀地花。均匀裕量 = 可预测 = 可利用。

比赛策略给的正确抽象是：把部署写成**两方零和博弈**。对手在"威胁集/新颖度预算"内选场景混合 τ；我们在**已经逐条认证过的配置集** C_cert 上选混合 σ（K 上限、守卫频率、审查配额、β 膨胀档、回退模式）。关键安全论证：**随机化只在已认证配置之间进行，不随机化任何安全裕量**——所以任何一次实现出来的配置都满足硬证书，随机化只重新分配"保守—激进"的性能权衡，不产生新的不安全动作（P17）。这既消除了可被对手预测的固定模式，又保住了 v10 的硬不变式。有限审查预算用**威胁加权索引**分配：严重度 × 违约概率上置信 / 成本；若目标对审查集合单调子模，则贪心达到 (1−1/e) 近似——"把审查花在刀刃上"有可证的近似界。名次目标以字典序/CVaR 进入损失，安全永远是第一约束，而非可交换项。

### 灵感 3（交叉 → 两个灵感其实是同一个测度）

直觉：起初我以为"泛化"和"博弈"是两件事，写到一半发现它们是同一个东西的两面：**对手选择物体分布，就是分布偏移；而跨物体泛化提供的可供性度量，正好是这个偏移的搬运代价（ground metric）**。于是 DR-保形的 Wasserstein 球半径 ε 不是拍脑袋的正则，而是"对手能付得起的物体改造预算"；泛化半径 r(o) 是"单个物体离已知锚点多远"；博弈的威胁集就是球内的分布。三者共用一套度量，理论上自洽，工程上只多一张可供性表、一张分层分位数表和一个小型博弈求解器。

三者咬合：AQ/CGR 出**单物体泛化半径**，OUCC/DRC 出**分布级覆盖保证**，SCG/TWRS 出**资源与对抗下的策略**——共同把 v10 的结构化证书升级为**跨物体策略证书 Ĉ^× = (Ĉ⁺, A(o), r(o), β_DR, q̂, σ_t, c_t)**。

## 1. 研究问题（轮次升级版）

- **Q1（可证泛化）**：如何用可供性商 + Lipschitz 前向模型 + 保形/DR-保形，把"未见物体"的误差界变成可测、可证、随新颖度自动膨胀的量，使覆盖不再依赖 τ_sem 在已见类上的经验标定？
- **Q2（策略不越权）**：如何在有限审查/算力预算与自适应对手下选择混合策略，使任何 realized 配置仍逐条满足硬证书（不出现新物理行为），同时名次目标的 CVaR 不劣于 v10？
- **Q3（预算与可部署）**：可供性表、分层保形、博弈求解与索引调度需要多少内存/时延/能耗，才能在 50Hz、p99≤20ms、25W、控制侧内存 ≤+0.5MB 内运行？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 泛化有界律（Generalization-Must-Be-Bounded, AQ/CGR/OUCC）**
任何对未见物体的放行必须携带可测泛化半径 r(o) 与分布无关覆盖（保形/DR-保形）；"类原型距离小"不得单独作为放行依据；r(o) > r_max 自动降 K_eff≤2 或要求主动探测；分位数越界 q̂>q_max 即 K=1。泛化保证只许表现为"加严/降 K"，不许表现为"放松裕量"。

**P17 策略不造新行为律（Strategy-Cannot-Create-Behavior, SCG）**
随机化/博弈只许在已认证配置集 C_cert 上混合；任何安全裕量、阈值、证书条件不得随机化；realized 配置必须逐条满足 v10 硬证书。混合只重分配性能（速度/能耗/任务收益），不重分配安全。博弈保证只对**声明威胁集**成立；集外由 P16 的半径/保形门收缩，不冒充覆盖。

**P18 威胁加权审查律（Threat-Weighted Scrutiny, TWRS）**
有限审查预算按 严重度×违约上置信/成本 排序分配，不得均匀分配；须给出相对最优的近似界（子模贪心 (1−1/e) 或 LP 对偶界），否则只能退回 v10 均匀审查。

## 3. 与基线的接口（如何退化）

- AQ 不可用（可供性估计器缺失/超时）⇒ r(o)←r_max（最大保守）且 K_eff≤2；若显式选择 v10 类别校准，则该路径逐字等价 v10；
- CGR 失效（L̂_A 无高置信上界）⇒ 取 L̂_A=L_max 的最坏膨胀，K_eff≤2；不产生放松；
- OUCC/DRC 不可用（校准集缺失/分位数越界 q̂>q_max）⇒ K=1（等价 v10 Level-1 信任破坏）；绝不"无分位数放行"；
- SCG 无解/超时 ⇒ 取 C_cert 中最保守的纯配置（minimax 上界，等价 v10 Π_r 方向），不松弛、不随机；
- TWRS 失效 ⇒ 均匀审查（逐字回退 v10）；
- STF/NRB/LS/Λ/AC/ID/MW/v8 失效 ⇒ 完全沿用 v10 六级退化链。

## 4. 预期贡献

1. **跨物体泛化证书**：可供性-Lipschitz + 泛化半径（引理 92）、物体一致保形（引理 93）、对抗选择下的 DR-保形（引理 94）；
2. **策略安全**：认证配置集上的混合策略不产生新不安全行为（引理 95）；
3. **审查调度**：威胁加权索引的子模近似界（引理 96）；
4. **预算可行**：控制侧 ≤+0.6ms、≤+0.42MB、≤+65mW，50Hz/p99≤20ms 不升（引理 97）；
5. **E591–E610** 覆盖可供性标定、跨物体 gap、可供性别名对抗、分层覆盖、DR 偏移、博弈均衡、非平稳后悔、审查预算、名次目标、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：可供性-Lipschitz 前提与 Wasserstein 半径 ε 本身是在有限物体池上估的——对手可构造"可供性贴近良性锚点、动力学却完全不同"的**可供性别名物体**，它落在球内却击穿前向模型，于是 DR-保形给出的是"有保证的错误覆盖"；泛化度量既是保证的工具又是被攻击的面，而博弈层可能把这种虚假信心放大成更激进的混合。

**新增定义 549（可供性描述子与商空间）** 对物体 o，A(o)=(m̂, μ̂, κ̂, c_com, g_contact, h_hazard, q_grasp) 由感知（位姿/尺寸/材质分类/交互探测）估计，输出区间 [A⁻,A⁺]；无探测时用先验并加宽区间（δ_A↑）。定义等价 o ~_ε o′ ⇔ d_A(A(o),A(o′)) ≤ ε。商空间 O/~_ε 是证书与校准的基本单位：同一等价类的物体共用同一条证书路径，与语义类别无关。可供性表以锚点集合存储（≤2048 条、16KB，E576 容量消融）。

**新增定义 550（可供性-Lipschitz 前向模型）** 在同一任务族内，存在 L_A≥0 使
```
sup_{z,a} ‖F(o,z,a) − F(o′,z,a)‖ ≤ L_A·d_A(A(o),A(o′)).
```
L̂_A 由留出物体对上的经验 Lipschitz 商取单侧置信上界（bootstrap/保形上界，E591）；所有证书使用 L̂_A 而非 L_A，故 L̂_A≥L_A 时结论保守。该前提是**可测的弱命题**，替代 v10"τ_sem 覆盖一切长尾"的不可证强命题。

**新增定义 551（泛化半径与膨胀余量）** 由三角不等式与定义 550：
```
error(o) ≤ error(anchor) + L_A·d_A(A(o),A(anchor)) + L_A·2δ_A
        ≤ β_base + λ·sup_{x∈Φ}T(x) + L̂_A·r(o) + ρ_A =: β_COG(o).
```
门控：r(o)≤r_max 才允许 K>2；r_max<r(o)≤r_abort ⇒ K≤2 且强制主动探测（轻触/短推）；r(o)>r_abort ⇒ K=1 或拒绝。r_max、r_abort 由 E597 标定。

**新增定义 552（物体一致保形证书 OUCC）** 非一致性分数 s(o)=|F̂(o)−F(o)|/β_COG(o)。校准物体按分层 g 分组；对每层取分位数
```
q̂_{α,g} = Quantile_{1−α}({s(o_i): g(o_i)=g}).
```
若该层样本 < n_min，则向上合并父层并加有限样本修正（Clopper–Pearson 上界或 (n+1) 修正）。在层内可交换性下，对新物体
```
P(error(o) ≤ max(1, q̂_{α,g})·β_COG(o) | g) ≥ 1−α.
```
**关键角色**：q̂ 是 L̂_A 前提的在线证伪器——若 β_COG 实际低估，校准分数会出现 s>1，q̂>1 并自动膨胀；若 q̂>q_max，则判前提失效并拒绝高 K（P16）。因此 v11 不宣称"覆盖必然成立"，而是把"前提失效"变成可观测、可门控的事件。

**新增定义 553（分布鲁棒保形 DRC）** 设对手可把物体分布从校准分布移动至多 ε（以 d_A 为搬运代价）：
```
B_ε(P_cal) = { Q : W_{d_A}(P_cal, Q) ≤ ε }.
q̂^ε_{α,g} = sup_{Q∈B_ε} Quantile_{1−α,Q}(s | g).
```
有限维下用 Wasserstein DRO 的对偶重加权（或离散运输 LP）求解；对 d_A 为 1 维时退化为单调似然比重加权。结论：对任意 Q∈B_ε，
```
P_Q(error(o) ≤ max(1,q̂^ε_{α,g})·β_COG(o)) ≥ 1−α−δ_n,
```
δ_n 为 Wasserstein 半径的有限样本估计误差。若对手只能选**单个物体**而非分布，则用定义 551 的逐物体半径给出最坏界；两者互补：单物体最坏 vs 分布平均。ε 的解释不是正则系数，而是"对手可付的物体改造预算"，由 E596 标定。

**新增定义 554（策略认证博弈 SCG）** 防御纯策略 c∈C_cert，每个 c 对声明威胁集 A_threat 内所有场景逐条满足 v10 硬证书（K 上限、守卫频率、审查配额、β 膨胀档、回退模式）。对手纯策略 a∈A_threat，权重 w(a)。损失
```
ℓ(c,a) = w(a)·1[violation(c,a)] + λ_e·E(c) + λ_t·T(c) − u(c,a),
V* = min_{σ∈ΔC_cert} max_{τ∈ΔA_threat} σᵀLτ.
```
离线 |C|,|A|≤32 时用零和 LP（对偶给出对手混合）；在线对手非平稳时用 Exp3.S，对最优固定配置的期望切换后悔 O(√(T·m·log m))，m=|C_cert|。实现时 c_t~σ_t 采样；若采样配置不在 C_cert 或与 σ_t 不一致 ⇒ 立即回退最保守纯配置并记台账。**安全性质（引理 95）**：随机化只在 C_cert 上，任何 realized c_t 仍逐条满足硬证书，故不产生新的不安全动作；博弈只对 A_threat 声明覆盖，集外由定义 551/552 收缩。

**新增定义 555（威胁加权审查调度 TWRS）** 每窗口审查预算 B。对 chunk ζ，违约概率后验 p̂(ζ) 与标准差 σ̂(ζ)，UCB p̄=p̂+κσ̂。索引
```
π(ζ) = sev_max(ζ)·p̄(ζ)/cost(ζ).
```
取 π 最大的 B 个。若期望严重度削减 R(S) 对审查集合 S 单调子模（chunk 间共享威胁 ⇒ 边际递减），预算为均匀拟阵，则贪心满足 R(S_greedy) ≥ (1−1/e)·R(S*)（引理 96）。未审查 chunk 的残余风险由子模间隙显式记账。

**新增定义 556（跨物体策略证书 Ĉ^×）** Ĉ^×=(Ĉ⁺, A(o), r, β_DR, q̂^ε, g, σ_t, c_t, AdvVer)。valid ⇔ Ĉ⁺ 在把 β 替换为 β_DR 后 valid（v10 定义 543）∧ max(1,q̂^ε_{α,g})≤q_max ∧ (r≤r_max ∨ K≤2) ∧ c_t∈C_cert ∧ realized 配置与 σ_t 一致。任一失败 ⇒ abort/Π_r；**不使用未经分位数验证的放行**。

**新增定义 557（名次感知目标 RAO）** 比赛效用 U=P(rank≤r) 由对赛场分数分布的信念估计；损失中的 −u(c,a) 取 CVaR_β 的负值（β 为尾部水平），并以字典序约束使用：(1) 硬安全可行，(2) 最大化 CVaR，(3) 最小化能耗。RAO 只影响博弈的收益项 u（定义 554），**不进入任何安全阈值**；因此名次优化不能换安全。

**新增定义 558（跨物体台账 XΛ）** Λ^× 在 v10 Λ 上增记 (H(A(o)), r, g, q̂^ε, ε, σ_t 向量, c_t id, AdvVer, 审查分配向量)。仍为 append-only 哈希链、块边界批量写、每 C_w=64 块链头校验；缺口 ⇒ 下一块强制 Π_r 直至重验（v10 定义 548 原样）。新增字段只增不减、只审计不回灌控制。

# IP-361 AffordanceQuotient：可供性商（复用感知栈，不新增重组件）
class AffordanceQuotient:
    def __init__(self, d=16, delta_A=0.05, anchor_cap=2048):
        self.d, self.delta_A, self.cap = d, delta_A, anchor_cap
        self.anchors = AffordanceTable(self.cap)     # 定义 549：16KB
        self.metric  = Mahalanobis(d)                # d_A 权重由 E591 回归

    def describe(self, obs, o):
        A = self.estimator(obs, o)                   # 质量/摩擦/柔顺/几何/危险/抓取
        return A                                     # 带区间 [A-, A+]

    def radius(self, A):
        a0, g = self.anchors.nearest(A, self.metric) # O(log n) KD-tree
        return self.metric(A, a0), g                 # r(o), stratum g


# IP-362 CertifiedGeneralizationRadius：可证泛化半径
class CertifiedGeneralizationRadius:
    def __init__(self, L_hat, beta_base, lam, rho_A, r_max, r_abort):
        self.L_hat, self.beta_base, self.lam = L_hat, beta_base, lam
        self.rho_A, self.r_max, self.r_abort = rho_A, r_max, r_abort

    def margin(self, r, T_sup):
        return self.beta_base + self.lam * T_sup + self.L_hat * r + self.rho_A

    def gate(self, r):
        if r > self.r_abort: return 'abort'          # K=1/拒绝
        if r > self.r_max:   return 'shrink'         # K<=2 + 主动探测
        return 'ok'


# IP-363 + IP-364：物体一致 / 分布鲁棒保形
class ObjectUniformConformal:
    def __init__(self, alpha=0.01, q_max=1.5, n_min=64):
        self.alpha, self.q_max, self.n_min = alpha, q_max, n_min
        self.q = {}                                   # g -> q_hat

    def calibrate(self, scores_by_stratum):
        for g, s in scores_by_stratum.items():
            if len(s) < self.n_min:
                self.q[g] = self.q.get(self.parent(g), float('inf'))
            else:
                self.q[g] = empirical_quantile(s, 1 - self.alpha)
        return self.q

    def gate(self, g):
        return max(1.0, self.q.get(g, float('inf'))) <= self.q_max

    def margin(self, beta_cog, g):
        return max(1.0, self.q.get(g, float('inf'))) * beta_cog   # 只许膨胀


class DRC:

        w = solve_dro_weights(scores[g], self.eps, metric)

# IP-366 ThreatWeightedReviewScheduler：威胁加权审查

## 4. 推导

**引理 92（单物体泛化半径与膨胀余量）** 设定义 550 成立、L̂_A≥L_A、可供性估计误差 ≤δ_A。则对任意 o，
```
error(o) ≤ β_COG(o) = β_base + λ·sup_{x∈Φ}T(x) + L̂_A·r(o) + ρ_A.
```
证明：锚点误差由 v10 引理 87/88 给出 ≤β_base+λ·sup T；在可供性空间中 d_A(A(o),A(anchor)) ≤ r(o)+2δ_A（估计区间）；由定义 550 的 Lipschitz 性与 L̂_A≥L_A 得误差增量 ≤L̂_A(r+2δ_A)；合并即得。**推论**：未见物体的余量随可供性距离线性膨胀，无需按类别重标；`r` 与 `L̂_A` 均为留出集上可测量（E591/E592），把 v10 的不可证前提换成可测弱命题。∎

**引理 93（物体一致保形覆盖）** 在层 g 内校准与测试物体可交换时，
```
P(error(o) ≤ max(1,q̂_{α,g})·β_COG(o) | g) ≥ 1−α.
```
证明：split-conformal 在层内应用；Mondrian 分层使覆盖逐层成立；max(1,·) 只增大右端，故保守。**推论（前提证伪器）**：若 β_COG 低估（可供性别名），校准分数出现 s>1 ⇒ q̂>1 ⇒ 余量自动膨胀；若 q̂>q_max，则定义 539 把 K 降为 1。故 v11 不隐藏前提失效，而是把它转成可观测、可门控的膨胀事件。∎

**引理 94（DR 覆盖与对抗选择）** 对任意 Q∈B_ε(P_cal)（定义 553 的 d_A-Wasserstein 球），
```
P_Q(error(o) ≤ max(1,q̂^ε_{α,g})·β_COG(o)) ≥ 1−α−δ_n,
```
其中 δ_n 为 Wasserstein 半径估计的有限样本误差。证明：Wasserstein DRO 分位数的最坏情形重加权，加上半径估计的标准浓度界；ground metric 取 d_A，故"泛化距离"与"对手移动分布的成本"是同一度量。**注**：若对手可选单个物体而非分布，用引理 92 的逐物体 r(o) 界；分布保证与逐点保证互补，不相互冒充。∎

**引理 95（策略不越权与博弈值）** (i) 对任意支撑于 C_cert 的 σ，任一 realized c_t 对声明威胁集 A_threat 逐条满足 v10 硬证书，故随机化不产生新的不安全动作；(ii) V* 由混合策略达到；若博弈存在纯鞍点，σ 退化为该纯策略（恢复 v10 行为）；(iii) Exp3.S 对自适应对手的期望切换后悔 ≤O(√(T·m·log m))，m=|C_cert|，非平稳仅带来该界内损失。证明：(i) 由 C_cert 定义与支撑；(ii) 零和 LP 对偶与鞍点存在性；(iii) Exp3.S 标准界。**边界**：保证只对 A_threat 声明；集外由定义 551/552 的门控降 K，不宣称覆盖。∎

**引理 96（威胁加权审查的近似界）** 若期望严重度削减 R(S) 单调子模、预算为均匀拟阵，则 TWRS 的贪心选择满足
```
R(S_greedy) ≥ (1 − 1/e)·R(S*).
```
证明：子模函数在基数约束下的标准贪心近似（Nemhauser–Wolstenholzer）；索引 π 正是贪心的边际收益/成本排序（UCB 为 p̂ 的乐观估计）。**推论**：均匀审查在最坏情形可任意差（当某一 chunk 集中了稀有高严重度威胁时），TWRS 给出可证的最坏情形比。∎

**引理 97（预算与可部署性）** AQ 每检测 O(d_A)（d_A≤16）；CGR 给定锚点 O(1)；OUCC/DRC 在线 O(1) 查表（校准离线 O(n log n)/层；DRO LP 离线 O(n²)，n≤4096）；SCG 离线 LP O(mn)（m,n≤32）、在线 Exp3.S O(m)/5Hz 周期；TWRS O(|ζ| log B)。控制侧新增 WCET ≤0.6ms、内存 ≤+0.42MB（16KB 锚点+128KB 分位表+8KB 博弈+16KB 调度+256KB 台账环形）、能耗均值 ≤+65mW；均在 v10 的 50Hz、p99≤20ms、25W 预算内（E604–E605 实测）。∎

## 8. 本轮最大风险

**一句话**：可供性-Lipschitz 前提与 Wasserstein 半径 ε 本身是在有限物体池上估的——对手可构造"可供性贴近良性锚点、动力学却完全不同"的**可供性别名物体**，它落在球内却击穿前向模型，于是 DR-保形给出的是"有保证的错误覆盖"；泛化度量既是保证的工具又是被攻击的面，而博弈层可能把这种虚假信心放大成更激进的混合。
