# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「联邦学习」×「推理延迟」）

> **基线**：第 13 轮产物 MetricVoiceGauge-NCD-HUTDH v14（SCD/DSD/DCA/EDC；定义 607–626；引理 125–130；实验 E661–E670）。
> 本轮纪律：**联邦的是证书证据而非模型权重 + 证书是易腐品 + 通信与验证进入同一截止期预算**。不推倒 v14：v14 的 SCD/DSD/DCA/EDC、v13 的 AIO/CPD/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。四个新组件——FBX/FEC（联邦边界交换与联邦证据证书）、SBC/ACL（陈旧有界证书与年龄账本）、LCR/LVG（延迟—证书路由与本地验证门）、NPA（非 IID 与投毒审计）——一律以**中立元**接入，失效即严格退回 v14，再沿 v14→v13→v12→…→v6 退化链回退。本轮只做三件事：把"联邦"从权重平均改写为**隐私受控的边界证据交换**、把"延迟"从本机计算改写为**证据年龄加通信预算**、把二者合成"越旧越保守、越不可验证越退化"的单调证书预算。

## 0. 直觉与动机

**灵感 1（联邦学习 → 联邦的是证书证据，不是模型权重）**
直觉：v14 的尾部分位、薄边界覆盖与罕见组合，受单机校准集规模硬约束；最缺的恰恰是"接触边界的一条窄带、一个新场景、一次险情"。多站点（多家庭、多机器人、多工厂、多医院）天然持有互补的边界样本，但原始观测因隐私、带宽与责任不能上传。普通联邦学习聚合权重，既不能保证聚合后的证书仍落在每个站点的教师授权集内，又会在非 IID 下把局部边界"平均掉"。核心创新：**联邦边界交换（Federated Boundary Exchange, FBX）+ 联邦证据证书（Federated Evidence Certificate, FEC）**。站点只交换**边界见证**——经差分隐私处理的投影、动作、证书余量、残差、时间戳与站点签名——不交换原始观测、不交换完整权重；聚合对象是**证据账本**而非模型。关键反直觉点：**联邦只能收紧经验不确定性，不能扩张语义授权**：`Acc_fed(x) ⊆ Acc_v14(x)` 恒成立。联邦的价值是把"本地样本太少而误拒"、但其实仍在 v14 语义授权内的动作**补回来**，而不是让系统做 v14 没授权的事。

**灵感 2（推理延迟 → 证书是易腐品，年龄必须进入证书）**
直觉：联邦证书不是常量。它会随通信轮次、断网、排队、漂移而变旧。v13 的随时推理只处理"本帧算多久"，v14 的 DSD 只处理"本帧扩散几步"，都没有处理"证据本身有多旧"。一条上周的全局证据，今天可能已经因分布漂移而失真；若把它当作永久有效，就会在"证书还在、数据变了"的缝隙里放行。核心创新：**陈旧有界证书（Staleness-Bounded Certificate, SBC）+ 证书年龄账本（Age-of-Certificate Ledger, ACL）**。每个 `(动作,查询域)` 都带 `AoC`（距最后一条支持见证的时间）与保质期 `T_exp`；授权所需的余量阈值随 `AoC` **单调上升**，超过 `T_exp` 的证书只能做预筛、不能授权。关键点：**新鲜度只影响保守性，不改变正确性方向**——越旧只能越保守；绝不允许旧证书因"噪声小、覆盖高"而放宽。

**灵感 3（联邦×延迟 → 把通信、验证、推理放进同一个截止期预算）**
直觉：联邦推理的延迟不只是本机 forward，还包括上传、排队、聚合、下载，以及**本地验证**——安全关键系统不能盲信远端证据。v13 的 `B_time` 只覆盖本机 anytime，v14 的 `B_skill` 只覆盖技能扩散，都没有给"等一个更新但更慢的站点"留位置。核心创新：**延迟—证书路由器（Latency-Certificate Router, LCR）+ 本地验证门（Local Verification Gate, LVG）+ 非 IID/投毒审计（Non-IID Poisoning Audit, NPA）**。每帧在四种模式之间选：**本地**（最快、最保守）、**缓存**（中等、带年龄惩罚）、**新鲜**（较慢、需通信预算）、**卸载**（把重证书计算交给空闲站点，但结果必须本地验证）。`B_time = B_local + B_comm + B_verify + B_safe`；任何模式的 p99 若不满足 `≤ B_time − B_safe` 即不可采纳，只能沿阶梯向更保守模式单调塌缩。这把"联邦学习"与"推理延迟"合成同一个对象：**一条按通信延迟定价、随时间腐坏、只能向下退化的证书预算**。

**三者如何统一**
统一为 **v14 之上的联邦证据层**：v14 回答"本地证书内哪些动作被允许"（`Exec_v14`），v15 回答"在隐私、陈旧与通信预算约束下，能否借助他站证据把误拒补回来，同时永不越过 v14"（`Exec_v15`）。FBX/FEC 提供证据与单侧证书；SBC/ACL 给证据加年龄与保质期；LCR/LVG/NPA 在 `B_time` 内选模式、拒绝不可验证的远端结果、审计共同盲区。共享状态 `ζ_fed = (t, AoC, κ, n_eff, Div, U_dp, Δ_noniid, Δ_stale, mode, B_time, B_comm, B_verify, audit_ok, div_ok)`。**FBX/FEC 回答"他站能提供什么证据、这些证据最多能证明到哪"，SBC/ACL 回答"这条证据今天还值多少"，LCR/LVG/NPA 回答"这一帧到底该用哪一档、敢不敢用"**。三者不是三个分布式补丁，而是"证据—时效—预算"的证书链。

## 1. 研究问题（轮次升级版）

- **Q1（联邦证据的可证语义）**：如何定义边界见证与证据账本，才使 DP 噪声、站点异构与部分覆盖下的聚合仍给出**单侧**证书 `Acc_fed ⊆ Acc_v14`？交集/并集/法定人数在非 IID 下分别意味着什么？"补回误拒"与"不得扩张授权"如何在同一形式化里同时成立？
- **Q2（证书时效的可证边界）**：`AoC` 如何进入共形分位而不破坏覆盖保证？"越旧越保守"的单调性在分布漂移、站点退出、重新校准后是否保持？过期证书只做预筛的"无复活"性质如何证明？DP 预算跨轮组合后 `Δ_dp` 如何随轮次增长？
- **Q3（延迟—新鲜度—覆盖的三难）**：在 `B_time` 固定、通信 p99 未知且突发时，如何在本地/缓存/新鲜/卸载间在线选档，使"超时率—新鲜度—误拒"最优？卸载到空闲站点何时才真正降低端到端延迟而不是制造无谓等待？本地验证预算如何分配？
- **Q4（联邦失效与活性）**：站点投毒、Sybil、共同盲区、来源相关性会不会同时骗过 quorum、DP 审计与本地审计？联邦证书与 v14 的 DCA/EDC 误差是否会同向叠加？全局证书收缩到空集时是否频繁 `a_ask`？能否守住 50Hz/p99≤22ms 并严格退回 v14？

## 2. 设计原则（在 P22–P27 基础上新增 P28–P30）

**P28 证据主权律（Evidence Sovereignty）**
只有能在本地审计集上复核的证据才可授权；远端权重、远端动作、远端"已认证"标记一律不能直接执行。联邦层只能收窄或补回 v14 语义授权内的误拒，恒有 `Acc_fed(x; ζ_fed) ⊆ Acc_v14(x)`。任何聚合、卸载、缓存都不得替代或放宽 v14 的 SCD/DCA/EDC 与 v12 的 TGC/UC。

**P29 证书易腐律（Certificates Are Perishable）**
每个联邦证书必须携带 `AoC`、`T_exp`、DP 与非 IID 修正项；授权阈值随年龄单调不减，过期证书只能预筛不能授权。禁止"一条全局证书永久有效"，禁止用旧证书的窄区间去覆盖新分布；重新校准前，陈旧只能导致更多假拒绝，不能导致任何新增授权。

**P30 通信即预算律（Communication Is a Budget）**
上传、排队、聚合、下载与本地验证的延迟必须与推理延迟计入同一 `B_time`；`B_safe` 不得被通信挤占。若在截止期内没有足够预算完成"取回 + 本地验证"，则该远端结果不可采纳，必须沿模式阶梯单调退化到缓存、本地或 `a_ask`，**不得执行迟到却看似新鲜的联邦结果**。

## 3. 与基线的接口（如何退化）

- FBX/FEC 失效 ⇒ 无见证、无账本：`κ≡0`、`Acc_fed≡Acc_v14`，只保留本地证书，**等价 v14 证书路径**；
- SBC/ACL 失效 ⇒ `AoC≡0`、`T_exp≡∞`，不做时效惩罚，退化为"静态联邦证据"，再受 P28 约束，**等价 v14 + 一次性本地审计**；
- LCR/LVG 失效 ⇒ 固定"本地模式"，不接受新鲜/卸载结果，**等价 v14 单机路径**；
- NPA 失效 ⇒ 只接受单站证据或最保守中位数，quorum 退化为 1，**等价"v14 + 单站证据"**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v14，再沿 v14→v13→v12→…→v6 退化链回退；
- **安全继承**：FBX/FEC 只产生 `Acc_v14` 的子集，SBC/ACL 只加年龄惩罚，LCR 只在已认证模式间选档，LVG 只删不增，NPA 只删不增。五端口互不相交，均不能新增授权或放宽任何教师阈值；`Exec_v15 ⊆ Exec_v14` 由引理 131 保证。

## 4. 预期贡献

1. **证书级联邦学习**：把联邦从"权重平均"改写为"隐私受控的边界见证交换"，在不共享原始观测的前提下补回单机校准的尾部误拒，并保持 `Acc_fed ⊆ Acc_v14` 的单侧性；
2. **易腐证书语义**：把 `AoC`、`T_exp`、DP 组合与非 IID 间隙写进证书阈值，证明"越旧越保守、过期不复活"，填补"联邦证书跨时间不可证"的空白；
3. **通信—验证—推理统一预算**：四模式路由与本地验证门，把"等远端"变成可定价、可拒绝、可单调退化的预算决策，而不是隐藏的截止期风险；
4. **语义层—证据层分离**：v14 管"允许什么"，v15 管"能借到多少他站证据、值多少时间、是否敢用"，用 `Exec_v15 ⊆ Exec_v14` 把联邦加速与安全解耦；E671–E690 覆盖 DP 覆盖、非 IID、时效单调、路由 p99、投毒审计、端到端与消融。

## 5. 本轮最大风险

**一句话**：真正致命的不是单站投毒，而是多个站点共享同一种系统性偏差——每个站都"独立地"同意、DP 噪声掩盖了相关性、quorum 与有效样本量都满足、证书新鲜、本地审计又因同源偏差而通过，最终在"隐私合规、样本充足、证书新鲜、本地可验证"的表象下执行了一个所有站点共同错判的安全决定——即**联邦一致的、新鲜的、可验证的、却共同错误的安全决定**。

# IP-382–405 v15 新增核心模块（联邦证据层）

| 编号 | 名称 | 类型 | 关键改进（相对 MetricVoiceGauge-NCD-HUTDH v14） |
|---|---|---|---|
| IP-382 | Federated Boundary Exchange (FBX) | 新增核心模块 | 只交换 DP 边界见证，不交换原始观测与完整权重；输出带站点签名、来源与时间戳的证据账本 |
| IP-383 | Federated Evidence Certificate (FEC) | 新增核心模块 | 把证据账本折成单侧证书 `Acc_fed ⊆ Acc_v14`；联邦只补回误拒，绝不扩张语义授权 |
| IP-384 | Staleness-Bounded Certificate (SBC) | 新增核心模块 | 把证书年龄写成授权惩罚，定义保质期 `T_exp`；过期只可预筛、不可授权 |
| IP-385 | Age-of-Certificate Ledger (ACL) | 新增状态模块 | 按 `(查询域, 动作)` 记录最后支持见证时间，支撑逐动作年龄与逐动作过期 |
| IP-386 | Latency-Certificate Router (LCR) | 新增核心模块 | 在本地/缓存/新鲜/卸载四模式间按 `B_time` 选档；不可采纳即单调塌缩 |
| IP-387 | Local Verification Gate (LVG) | 新增在线检查模块 | 远端证据/卸载结果必须通过本地审计集方可授权，否则只能预筛 |

# IP-382 Federated Boundary Exchange：只交换 DP 边界见证
class FederatedBoundaryExchange:
    def __init__(self, site_id, embed, eps_dp, delta_dp, quorum, n_min,
                 max_witness_age=2.0):
        self.site = site_id
        self.embed = embed                    # phi: X -> R^d；原始 x 不出站
        self.eps_dp = eps_dp
        self.delta_dp = delta_dp
        self.quorum = quorum
        self.n_min = n_min
        self.sigma_dp = math.sqrt(2 * math.log(1.25 / delta_dp)) / eps_dp
        self.max_witness_age = max_witness_age

    def witness(self, x, a, margin, residual, now):
        h = self.embed(x)
        h = h + np.random.normal(0, self.sigma_dp, size=h.shape)
        m = margin + np.random.normal(0, self.sigma_dp)
        r = residual + np.random.normal(0, self.sigma_dp)
        return Witness(h=h, action=a, margin=m, residual=r,
                       t=now, site=self.site,
                       sig=sign(self.site, h, a, m, r, now))

    def ingest(self, inbox, now):
        fresh = [w for w in inbox
                 if now - w.t <= self.max_witness_age and verify_sig(w)]
        # 稳健聚合：按 (action, projection-bucket) 分组取站点中位数
        grouped = group_by_action_bucket(fresh)
        ledger = FederatedLedger(now=now, witnesses=grouped)
        ledger.n_eff = effective_sites(grouped)          # 定义 632
        ledger.div = provenance_diversity(grouped)       # 定义 633
        ledger.w1_max = estimate_w1_to_agg(grouped)      # 定义 636
        return ledger


# IP-383 Federated Evidence Certificate：折成单侧证书
class FederatedEvidenceCertificate:
    def __init__(self, acc_v14, alpha, sigma_dp, delta_dp,
                 lambda_stale, tau_c, delta_max,
                 c_dp=1.0, c_noniid=1.0, alpha_audit=0.05):
        self.acc_v14 = acc_v14
        self.alpha = alpha
        self.sigma_dp = sigma_dp
        self.delta_dp = delta_dp
        self.lambda_stale = lambda_stale
        self.tau_c = tau_c
        self.delta_max = delta_max
        self.c_dp = c_dp
        self.c_noniid = c_noniid
        self.alpha_audit = alpha_audit

    def dp_penalty(self, n_eff):
        if n_eff < 1:
            return float("inf")
        return self.c_dp * self.sigma_dp * math.sqrt(
            2 * math.log(2 / self.delta_dp)) / math.sqrt(n_eff)

    def noniid_penalty(self, ledger):
        return self.c_noniid * ledger.w1_max

    def stale_penalty(self, aoc):
        if aoc == float("inf"):
            return float("inf")
        return self.lambda_stale * (1.0 - math.exp(-max(0.0, aoc) / self.tau_c))

    def expiry(self):
        r = self.delta_max / self.lambda_stale
        return float("inf") if r >= 1.0 else -self.tau_c * math.log(1.0 - r)

    def authorize(self, x, a, ledger, aoc, audit_ok, div_ok, now):
        # P28：语义授权永远先取 v14 的子集
        if a not in self.acc_v14(x):
            return False
        if not audit_ok or not div_ok:
            return False
        if ledger.coverage(x) < ledger.quorum:
            return False
        if aoc > self.expiry():
            return False
        U = conformal_lower(ledger.margins(a), self.alpha)
        U -= self.dp_penalty(ledger.n_eff)
        U -= self.noniid_penalty(ledger)
        U += self.stale_penalty(aoc)
        return ledger.margin(x, a) >= U


# IP-385 Age-of-Certificate Ledger：逐动作年龄
class AgeOfCertificateLedger:
    def __init__(self):
        self.last_support = {}       # (bucket(x), a) -> t_last

    def touch(self, x, a, now):
        self.last_support[(bucket(x), a)] = now

    def age(self, x, a, now):
        key = (bucket(x), a)
        if key not in self.last_support:
            return float("inf")
        return now - self.last_support[key]

# IP-386 Latency-Certificate Router：四模式选档
class LatencyCertificateRouter:
    MODES = ("local", "cached", "fresh", "offload")
    CONSERVATIVE_RANK = {"local": 0, "cached": 1, "fresh": 2, "offload": 3}

    def __init__(self, p99_local, p99_comm, p99_verify,
                 p99_offload, p99_screen, safe_margin):
        self.p99 = {
            "local": p99_local,
            "cached": p99_local + p99_screen,
            "fresh": p99_local + p99_comm + p99_verify,
            "offload": p99_offload + p99_comm + p99_verify,
        }
        self.safe = safe_margin

    def admissible(self, mode, B_time, quorum_ok, div_ok, aoc, T_exp):
        if self.p99[mode] > B_time - self.safe:
            return False
        if mode == "local":
            return True
        if not (quorum_ok and div_ok):
            return False
        if aoc > T_exp:
            return False
        if mode in ("fresh", "offload"):
            return B_time >= self.p99["fresh"] + self.safe
        return True

    def choose(self, B_time, quorum_ok, div_ok, aoc, T_exp, progress):
        cand = [m for m in self.MODES
                if self.admissible(m, B_time, quorum_ok, div_ok, aoc, T_exp)]
        if not cand:
            return "fallback", 0.0
        # 只有预期增益显著时才升级模式，否则停在更保守档
        best = max(cand, key=lambda m: (progress.get(m, 0.0),
                                        -self.CONSERVATIVE_RANK[m]))
        if progress.get(best, 0.0) <= 0.0:
            best = "local"
        return best, self.p99[best]


# IP-387 Local Verification Gate：远端证据必须本地复核
class LocalVerificationGate:
    def __init__(self, audit_set, acc_v14, alpha_audit):
        self.audit_set = audit_set
        self.acc_v14 = acc_v14
        self.alpha_audit = alpha_audit

    def verify(self, evidence, now):
        for x in self.audit_set:
            for a in evidence.authorized_actions(x):
                if a not in self.acc_v14(x):

                                       self.alpha_audit)

            return False, risk_ub, "audit_risk"
        return True, risk_ub, "ok"


# IP-388 Non-IID Poisoning Audit：共同盲区与投毒审计
class NonIIDPoisoningAudit:
    def __init__(self, n_eff_min, c_prov_min, rho_c, max_byz):
        self.n_eff_min = n_eff_min
        self.c_prov_min = c_prov_min
        self.rho_c = rho_c
        self.max_byz = max_byz

    def audit(self, ledger):
        if ledger.n_eff < self.n_eff_min:
            return False, {"reason": "n_eff", "n_eff": ledger.n_eff}
        c_prov, rho_max = ledger.div
        if c_prov < self.c_prov_min:
            return False, {"reason": "diversity", "c_prov": c_prov}
        if rho_max > self.rho_c:
            return False, {"reason": "correlation", "rho_max": rho_max}
        # Byzantine 稳健裁剪；Krum/median 在离线聚合侧执行
        ledger.witnesses = krum_or_median(ledger.witnesses, self.max_byz)
        return True, {"reason": "ok", "n_eff": ledger.n_eff,
                      "c_prov": c_prov, "rho_max": rho_max}

## 3. 推导

**引理 131（证据主权的单侧包含）** 若 (i) `Acc_fed(x;ζ_fed)` 按定义 634 先与 `Acc_v14(x)` 取交；(ii) LVG 只做删除、不产生新动作；(iii) LCR 只在已通过 (i)(ii) 的候选间选档；(iv) NPA 只裁剪见证、不新增见证；则对任意 `ζ_fed` 与任意模式 `m`，`Exec_v15(ζ_fed,m) ⊆ Exec_v14`。

证明：任一被执行动作 `a` 必须同时通过 `fec.authorize` 的 `a ∈ Acc_v14(x)` 检查（定义 634），并可能再经 LVG 删除与 NPA 删除；LCR 与选择器不改变动作集合的成员关系，只做筛选。因此 `a ∈ Acc_v14(x)` 恒成立，故 `Exec_v15 ⊆ Exec_v14`。∎
推论：**联邦层买到的只是"v14 内更少的误拒"，不是任何新权限**；即使远端证据完全可信，也无法让系统执行 v14 未授权的动作。

**引理 132（DP 修正下的一次性覆盖）** 设每个站点的见证由标准差 `σ_dp` 的高斯机制发布，站点数 `n_eff`。令 `Δ_dp^max = σ_dp · Φ^{-1}(1 − δ_dp/(2K))`。若 `U_dp = Q_{1−α}({m_i}) − Δ_dp^max / sqrt(n_eff)`，则在概率至少 `1 − δ_dp` 下，`P(m_true ≥ U_dp) ≥ 1 − α − δ_dp`。

证明：由高斯机制尾界，单个站点被噪声推动超过 `Δ_dp^max` 的概率至多 `δ_dp/(2K)`；对 `K` 个站点取并集界，全部噪声位移不超过 `Δ_dp^max` 的概率至少 `1 − δ_dp/2`。在无噪声分位 `Q_{1−α}` 上减去最大位移，覆盖至少 `1−α`；再与噪声事件取交，得到 `1−α−δ_dp`。有效独立样本按 `sqrt(n_eff)` 折算（定义 632），因为重复/同源站点不提供独立信息。∎
推论：`Δ_dp = O(σ_dp sqrt(log(1/δ_dp))/sqrt(n_eff))`；**站多不等于信息多，`n_eff` 才是分母**。

**引理 133（证书年龄的单调保守性）** 若 `Δ_stale(·)` 非减，则对 `AoC_1 ≤ AoC_2`，有 `Acc_fed(AoC_2) ⊆ Acc_fed(AoC_1)`；且若 `AoC > T_exp`，该证书不产生任何授权，只能预筛。

证明：`U_total` 中只有 `Δ_stale` 随 `AoC` 变化且非减，故 `AoC` 越大，通过 `m_agg ≥ U_total` 的动作集合越小（或不变）；交集运算对子集保持单调。超过 `T_exp` 时 `Δ_stale > Δ_max`，按定义 638 与 P29 关闭授权端口。∎
推论：**陈旧只会导致更多假拒绝，绝不会导致相对新鲜证书的新增授权**；不存在"旧证书因统计量更漂亮而复活"的路径。

**引理 134（非 IID 间隙的三角传导）** 对目标分布 `P_t`，`W_1(P_t,P_agg) ≤ W_1(P_t,P_k) + W_1(P_k,P_agg)`。若 `Δ_noniid ≥ c_n · max_k W_1(P_k,P_agg)`，且共形估计误差为 `ε_est`，则站点证据迁移到目标分布上的剩余覆盖误差不超过 `Δ_noniid + ε_est`。

证明：由 Wasserstein 三角不等式，目标到聚合分布的距离被"目标到站点"与"站点到聚合"两项控制；第二项由 `Δ_noniid` 覆盖，第一项由目标域共形校准的 `ε_est` 覆盖。两项相加即得。∎
推论：**增加更多同源站点不能降低共同的系统偏差**；`Δ_noniid` 衡量的是站点与聚合之间的差异，不是站点与真实目标之间的差异——这正是联邦不能替代目标域校准的原因。

**引理 135（延迟—新鲜度—覆盖三难）** 设证书刷新到达为速率 `r` 的泊松过程，若要 `P(AoC ≤ T) ≥ 1−β`，必要条件是 `r ≥ −ln β / T`。每次刷新至少要花 `B_comm + B_verify`。若
```
B_time ≥ B_local + B_safe + r · (B_comm + B_verify)
```
不成立，则不存在同时满足 (i) 本地 p99 截止期、(ii) 新鲜度 `1−β`、(iii) 新鲜/覆盖模式的策略；必须至少牺牲其中之一。

证明：每帧用于通信与验证的期望时间至少为 `r(B_comm+B_verify)`（刷新次数 × 单次成本）。若预算不足以覆盖该项，则要么降低刷新率（新鲜度失败），要么在帧内等待（截止期失败），要么退回本地/缓存（覆盖或新鲜度失败）。三者不可同时成立。∎
推论：**通信延迟是硬货币**；"等一个更好的站点"必须显式从 `B_time` 扣款，不能隐藏在"反正网络很快"的假设里。

**引理 136（共同盲区下的法定人数下界）** 设所有站点共享同一共同模式错误事件 `E`，`P(E)=p`，且站点错误完全相关（`ρ=1`）。则对任意 quorum `q`，只要 `E` 发生，所有站点同时错判，故 `P(false accept) ≥ p`。在 Gaussian copula 相关 `ρ<1` 下，`P(全部 q 个站点同时错判) ≥ ρ·p`。

证明：`ρ=1` 时站点错误是 comonotone 的，`E` 发生时每个站点的见证都朝同一错误方向，任何"多数/中位数"都选中错误值，法定人数不改变事件概率下界。`ρ<1` 时用 Gaussian copula 的联合尾界给出 `ρ p` 的一阶下界。∎
推论：**quorum 计数不是证据多样性**；没有 `Div`/NPA 的联邦会在"每个站都同意"时给出最强的错误信心。

## 7. 已知风险与失效模式

1. **共同盲区（共同模式错误）**：所有站点共享同一种系统性偏差，quorum、DP 与本地审计同时通过。缓解：来源多样性 `c_prov`、相关性上限 `ρ_max`、独立数据族强制、教师影子抽查、关键场景保留纯本地路径。

2. **Sybil 与女巫攻击**：大量伪造站点抬高 `n_eff` 与 quorum。缓解：站点身份与来源证明、按来源簇而非站点计数、Krum/median、权重上限、审计通过率加权的 `n_eff`。

3. **DP 噪声掩盖相关性**：DP 噪声让不同来源的见证看起来独立，实际误差同向。缓解：在加噪前做来源分层、记录加噪前的簇内相关、对 `ρ_max` 做保守上界、DP 组合预算显式扣减。

4. **陈旧证书与漂移同相**：断网时既拿不到新证据，分布又在漂移，旧证书仍在保质期内。缓解：`AoC` 与漂移检测联动提前过期、缩短 `T_exp`、漂移时强制只预筛、本地重校准。

5. **通信延迟突发**：排队、带宽抖动、跨域路由使 `p99_comm` 远超离线测量。缓解：硬件在环压力测试、watchdog、`B_safe` 预留、非阻塞发布、只在 slack 中同步、超预算即退回本地。

6. **本地审计集同源偏差**：LVG 的审计集与训练集来自同一采集族，无法发现共同盲区。缓解：审计集按来源分层、保留外部/对抗样本、与联邦 `Div` 交叉检查、必要时引入第三方审计。

7. **语义越界的"补回"风险**：FEC 以 `Acc_v14` 为硬上界，但若 `acc_v14(x)` 的查询实现有 bug，补回会放大错误。缓解：`Acc_v14` 查询做形式化单测与影子执行、每帧只读不可变证书对象、全量轨迹断言。

8. **DP 预算耗尽的活性塌缩**：长期运行后 `ε_total` 用尽，`Δ_dp=∞`，联邦层关闭，误拒回升。缓解：预算节奏化分配、低频聚合、差分隐私的隐私放大（子采样）、预算耗尽前预校准本地证书。

9. **卸载模式的"更快"幻觉**：远端空闲但通信更慢，端到端反而超时。缓解：端到端 p99 而非远端单机 p99 做采纳判据、预设 offload 收益阈值、默认 local、只有实测增益才升级。

10. **全局证书与 v14 误差同向叠加**：`Δ_dp`、`Δ_noniid`、`Δ_stale` 与 v14 的 DCA/EDC 误差在同一新颖场景同时偏低。缓解：联合三角界（定义 645）、四项加性预算、双重漂移检测、任一间隙失效即退回本地。

11. **隐私—效用—安全三难**：更强的 DP 降低效用、更多聚合提高相关性风险、更严格 quorum 提高误拒。缓解：显式三维预算、预注册权衡曲线、按场景选择工作点、绝不把隐私参数当作免费的正则。

## 8. 本轮最大风险

**一句话**：真正致命的不是单站投毒，而是多个站点共享同一种系统性偏差——每个站都"独立地"同意、DP 噪声掩盖了相关性、quorum 与有效样本量都满足、证书新鲜、本地审计又因同源偏差而通过，最终在"隐私合规、样本充足、证书新鲜、本地可验证"的表象下执行了一个所有站点共同错判的安全决定——即**联邦一致的、新鲜的、可验证的、却共同错误的安全决定**。
