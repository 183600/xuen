# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环第 3 轮；本轮灵感：「碰撞避免」×「角色一致性」）

> R69 把不确定性拆成 aleatoric 与 epistemic，并让系统第一次学会「问」：看、问、触。但它仍站在**单主体视角**——世界里只有「我」在动，「对方」只是一个被动的答案源，或一个会撒谎的投毒者。碰撞避免戳破了这个假设：**在共享空间里，安全从来不是我一个人算出来的，而是我们共同生产的**；「对向走来的人会不会侧让」既不是噪声（aleatoric，问也问不出来），也不是可观测的世界事实（epistemic，看一眼就知道），而是**战略的**——它取决于对方的角色、意图，以及它对我意图的预期，答案本身就是一个策略动作。
>
> 角色一致性补上另一半：要让「互惠」可计算，必须先有稳定的身份与义务——**你是谁、我该让多少、你会不会守约、你的回答是否有权被采信**。没有角色，交互只是「问答」；有了角色，交互才变成「协调」。
>
> 核心命题：**在 R69 的 (U_ale, U_epi) 之外加入第三类「战略不确定性 U_strat」；把「角色 τ」作为将战略不确定性转化为可计算互惠的枢纽；把「角色一致性」作为互惠信任的抵押品——角色一致则分摊避碰责任（reciprocity bonus），角色不可信/未知/被伪装则取全责 maximin，逐指令退化为 R69。** 命名 **ROAM-RAS**（Role-Obligation Aware Multi-agent reciprocal avoidance）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们在同一个空间里各自扮演什么、谁该让、凭什么信**」。

## 0. 直觉与动机

**灵感 1（碰撞避免 → 有一种不确定性是「博弈的」，不在 R69 的二分里）**
直觉：R69 的 epistemic 不确定性假设「世界有一个真值，观测/询问能逼近它」。但「对向的人会不会让」没有一个独立于我们双方决策的真值：它取决于对方怎么看我、我怎么看对方、以及我们各自敢不敢赌。把它塞进 epistemic 会犯两个错：以为「多问一句」就能知道（对方可能撒谎，或问完才决定），以及以为「收紧」就安全（双方都收紧会在窄道里对停）。这类不确定性的正确对象不是「世界的状态」，而是**类型与最佳响应**，必须用角色 + 博弈来解释，而不是用熵 + 观测。

**灵感 2（角色一致性 → 角色是让互惠可计算的不变量）**
直觉：人类在共享空间里靠的不是实时求解纳什均衡，而是**读角色**：推婴儿车的人、穿制服的人、低头看手机的人、牵着导盲犬的人——角色一读出来，行为先验、让行义务、可信度就同时到位。角色把「无限种可能的意图」压成「有限种可协调的身份」。更关键的是，角色一致性（慢变、跨通道自洽、对新颖情境仍成立）是**互惠的抵押品**：正因为我预期你会持续扮演这个角色，我才敢只承担 α<1 的避碰责任。没有一致性，任何责任分摊都是空的。

**灵感 3（严格包含 → maximin 全责就是 R69）**
直觉：当角色未知、不可信、或刚被检测到违约时，最安全的做法是**假设对方完全不让，由我承担全部避碰责任**（α_self=1）。这恰好就是 R69 的单机保守行为：把自己当作世界里唯一的行动者，把对方当作移动障碍。于是 R70 不是推翻 R69，而是把它作为「信任 β=0」的边界严格包含进来：安全侧永不让步，效率侧只在角色一致性证据充分时领取**互惠红利**（少制动、少停顿、更高通行率）。这是本轮的理论姿态：**新层必须是旧层的严格泛化**。

**灵感 4（三通道 → 角色一致性是第三条独立的证据通道）**
直觉：R69 有两条通道——传感器残差 r_res（测「传感器自洽」）与行为似然 Δa（测「行为自洽」）。但它们都只回答「我这边有没有问题」。R70 加第三条**关系通道** r_role：对方的行为是否与其声称/被推断的角色一致。三通道联合才有判别力：r_res 高而其余正常 = 我的传感器坏了；Δa 高而其余正常 = 我的策略被喂了坏输入；r_role 高而 r_res/Δa 正常 = **对方换了角色或正在伪装**——这正是 R69 两通道会误诊为「我自己坏了」的情形。角色一致性让系统第一次能审计「关系」，而不只是审计「自己」。

**灵感 5（角色的双刃剑 → 互惠是新的攻击面）**
直觉：角色一旦能换取信任，就会有人伪造角色。冒充权威（「我是医生，让我过」）、责任转嫁（装成更脆弱的一方逼你全责避让）、僵局诱导（故意挡在窄道口等你先动）、角色标签投毒（训练期污染角色先验）、多源共谋（几个人一起演同一个角色）。**互惠会把 R69 的「诚实的不知道」升级成「礼貌地把安全交给一个演得很像的人」**。所以本轮必须同时交付：角色信任的不可伪造性（跨正交通道 + 时间累积 + 可撤销）、turn-taking 的责任纪律、僵局/活锁的破除机制、以及「角色授权证据」——不是谁回答都算数。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（ROAM-RAS 总览）** ROAM-RAS = (RGM, MJF, SUD, RCC, RCM, RNI, RDE, RAA, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **角色包络硬约束**：自身动作 ∈ 𝒜_{τ_self}，越出角色义务（超额让行、越权决策、越界承诺）即违规；
(iii) **互惠安全不变式**：角色信任不足时责任份额 α_self=1（maximin 全责），绝不弱于 R69；仅当角色一致性证据充分才降到 α<1；
(iv) **角色授权证据纪律**：证据按 (来源角色, 查询域) 授权矩阵加权，未授权来源即使 k 个一致也不得单独定案。

**定义 311（角色类型与角色语义）** τ ∈ 𝕋。角色签名 sig(τ) = (π_τ, o_τ, I_τ, A_τ)：
- 行为先验 π_τ(a|o)（可预测性）；
- 义务向量 o_τ = (α_τ, v_max, d_min, Δt_resp)：让行份额、速度上限、最小间距、响应时延；
- 交互协议 I_τ ⊆ Q × Y：该角色可发/可答的查询与语义映射；
- 授权矩阵 A_τ[q,e] ∈ [0,1]：该角色对查询域 q 的证据 e 的采信权。
角色一致性由慢变核 P(τ'|τ) 定义：停留时间 T_dwell 长、切换率 λ_role 小。一致性 = 「慢 + 跨通道自洽 + 对新情境仍成立」，**不是**「永远不变」。

**定义 312（角色条件联合流 MJF）** 联合动作块 ξ_J = (ξ_1,…,ξ_N) ∈ 𝒜_+^N；角色条件速度场 v_θ(x_s, s | o, τ_{1:N})。训练联合、执行边际：每个 i 只用自己的角色与对他人角色的信念采样 ξ_i，联合可行性由 RCC 过滤兜底。这样既不要求中心化执行，也不假设他人的策略已知。

**定义 313（战略不确定性 SUD）** 令 b 为对他人角色的信念，BR_τ 为其最佳响应，a_i^rec 为互惠最优动作，a_i^max 为 maximin 最优动作：
U_strat = 𝔼_{τ~b}[ Risk(a_i^rec, BR_τ(a_i^rec)) − Risk(a_i^max, BR_τ(a_i^max)) ]。
关键：**只有会改变最优动作的角色差异才计入不确定性**；若所有可能角色的最佳响应都导致同一安全动作，则 U_strat = 0——**决策无关的歧义不值得协商**。工程上用「后果加权熵」H_c(τ) = H(τ)·1[argmax 分歧] 近似。

**定义 314（三分不确定性与三通道处置）** U = (U_ale, U_epi, U_strat)。U_ale → R68 的 λ floor；U_epi → R69 的主动交互（看/问/触）；U_strat → R70 的角色协商或 maximin 回退。三者不简单加和，各入不同通道；只有 U_strat 未解且角色信任不足时，才按 U_epi→U_ale 的规则并入 λ floor。

**定义 315（角色残差与 CUSUM 监测 RCM）** 角色残差取负对数似然比：r_role,i(t) = −[ ℓ_i(τ_i; a_{i,t−W:t}, o) − max_{τ'≠τ_i} ℓ_i(τ'; ·) ]（r_role 越小越一致）。用 CUSUM：S_t = max(0, S_{t−1} + r_role(t) − k_δ)，S_t > h ⇒ 报角色切换/违约。给出虚警率 α（ARL0）与检测延迟（ARL1）的界；`switched` 是「对方已换角色」的硬信号。

**定义 316（互惠责任分配 RCC）** pairwise 安全函数 h_ij(x) ≥ 0，需求避碰控制 u_req。责任映射 ρ: (τ_i, τ_j) → (α_i, α_j)，α_i, α_j ∈ [0,1]，α_i + α_j ≥ 1。互惠 CBF 条件：α_i·u_i + α_j·u_j ≥ u_req。角色把「谁更该让」从模糊的社会规范变成**可计算的义务向量**（谁更脆弱、谁速度更高、谁在干道上）。

**定义 317（角色一致下的互惠避碰前置条件）** A100：角色平稳，T_dwell ≫ τ_d（检测延迟）；A101：共同角色分配近似公共知识（通过可读信号 + 一致性验证，而非读心）；A102：双方在 τ_d 内兑现义务。满足时，互惠过滤在 τ_d 内可能有 ≤ δ(τ_d) 的暂时违规，之后恢复；安全裕度随 τ_d 单调收窄。

**定义 318（maximin 全责回退）** 当角色信任 trust < β_min，或 CUSUM 触发 switched，或授权缺失：α_self=1，速度 ≤ v_max^{R69}，动作集收缩到 R69 的保守集合。逐指令与 R69 相同 ⇒ **R69 = ROAM 在 β=0 边界的严格退化**。

**定义 319（角色协商交互 RNI）** 候选查询 q 按「授权 × 响应性 × 判别力」排序：
VoI_role(q) = I(τ_{−i}/joint mode; y | q) · Auth(src, q) · Resp(τ_{−i}, q) − c(q)。
未授权来源或「对方角色本就不响应」时 VoI 折减而非清零——**沉默本身也是证据**，多次无响应累积降低 trust。若 max VoI_role ≤ 0：不协商，取 maximin。

**定义 320（角色信任分与不可伪造性）** trust_i ∈ [0,1]：trust ← clamp(trust + η·consistency − ζ·violation − ξ·staleness)。不可伪造性由三件事保证：(a) 跨正交通道一致（行为、时序、授权、对新颖情境的预测）；(b) 时间累积（伪装成本随持续时长上升）；(c) 撤销（单次严重违约立即清零）。给出「伪装可持续时长」上界（引理 21）。

**定义 321（僵局/活锁与角色承诺）** 对称走廊中纯互惠让行会 **deadlock**；角色优先序 ≺_τ 提供全序破对称。角色承诺：一旦发出角色/优先信号，在 T_commit 内粘滞，主动切换付代价 c_switch。**活锁 = 角色振荡**（commit 期内反复改主意）；粘滞承诺 + 全序优先 ⇒ 有限时间内消解。

**定义 322（自身角色漂移包络 RDE）** τ_self(t) ∈ T_allowed；自身行为对角色签名的偏离 d_self(t) = D(π_actual, π_{τ_self})。区分三件事：
- 真实角色切换（外部授权、显式 re-role）→ 更新 τ_self 与证书；
- 角色漂移（无授权的缓慢偏离）→ 报警并收紧回角色包络；
- 角色内适应（能力改进而角色不变）→ d_self 不增，不报警。
判别用 r_role 趋势 + r_res + Δa 三通道（定义 323）。

**定义 323（三通道异常判别）** 联合统计 (r_res, Δa, r_role) 的四象限：
- r_res↑, Δa 正常 → 传感器故障（R68）；
- Δa↑, r_res 正常 → 输入/策略异常（R69 FMA）；
- r_role↑（对方）, r_res/Δa 正常 → **对方角色切换/伪装**（R70 新增）；
- r_role↑（自身）且长时程 → **自身角色漂移**（R70 新增）。
用似然比给出象限边界与误判界。

**定义 324（角色授权审计 RAA）** 审计对象新增：角色声明是否有证据、证据来源是否授权、责任分配是否被遵守、是否出现责任转嫁/僵局诱导/角色冒充。结论回灌 trust 与 AuditBuf，成为下一轮 RNI 的授权与成本先验。

**定义 325（威胁模型 ℰ_ROAM）** ℰ_ROAM = ℰ_FLUID × ℰ_role，其中 ℰ_role = {角色伪装（冒充权威/专业人员）、责任转嫁（装脆弱逼对方全责）、僵局诱导（故意挡路/假动作）、角色标签投毒（训练期污染）、授权伪造、多源共谋（一起演同一角色）}。每条威胁对应一条防线（RCM/引理 21、α 下限、承诺机制、数据审计、A 矩阵、正交通道）。

**定义 326（证书 J_ROAM）** J_ROAM = (J_FLUID, role_trust, r_role_p95, alpha_alloc_hash, reciprocal_margin, deadlock_free, role_drift_ok, roam_ver)。Valid ⇔ Valid(J_FLUID) ∧ trust ≥ β_min ∧ 四不变式满足 ∧ 三通道无未解释异常。

**定义 327（两级信任退避 + 互惠红利）** 角色可信 → α_self<1，领取 **reciprocity bonus**（更少制动、更高通行效率）；角色不可信/未知/被伪装/自身漂移 → α_self=1，逐指令 = R69。安全侧永不弱于 R69；效率侧仅在证据充分时获益。R69 是 β=0 边界。

**定义 328（角色组合与层级）** 复合角色 τ = τ_1 ⊗ τ_2（如「护士」⊗「在医生授权下」）。义务取交（更严者胜），授权取并但受上级约束，一致性须在组合层同时保持。用于多人层级场景：**谁有权定案**本身是角色问题，不是置信度问题。

## 2. 关键算法骨架

```python
# IP-264 RGM/RCM：角色推断 + 一致性 CUSUM（负对数似然比）
class RoleMonitor:
    def __init__(self, role_lib, k_delta=0.5, h=5.0, W=2.0):
        self.roles, self.k, self.h, self.W = role_lib, k_delta, h, W
        self.S = defaultdict(float)              # 每智能体 CUSUM 统计量
        self.trust = defaultdict(lambda: 0.5)
    def residual(self, i, hist, o):              # 越小越一致
        lls = {tau: self.roles[tau].loglik(hist, o) for tau in self.roles}
        t_hat = max(lls, key=lls.get)
        return t_hat, -(lls[t_hat] - max(v for k, v in lls.items() if k != t_hat))
    def update(self, i, hist, o):
        tau_hat, r = self.residual(i, hist, o)
        self.S[i] = max(0.0, self.S[i] + r - self.k)
        switched = self.S[i] > self.h
        if switched: self.S[i] = 0.0
        return tau_hat, r, switched

# IP-265 SUD：战略不确定性（只算决策相关部分）
def strategic_uncertainty(belief, a_rec, br_fn, risk_fn):
    r_rec = risk_fn(a_rec, br_fn(belief.map))
    return max(risk_fn(a, br_fn(tau)) for tau, a in br_fn.actions(belief)) - r_rec

# IP-266 RCC：角色诱导的责任分配 + 互惠 CBF
def reciprocal_filter(x, a_nom, roles, trust, pair_h, alpha_map):
    a = a_nom.copy()
    for (i, j) in unsafe_pairs(x, pair_h):
        u_req = required_avoidance(x, i, j)
        alpha = alpha_map(roles[i], roles[j])            # 角色义务向量
        if min(trust[i], trust[j]) < BETA_MIN:           # 不可信 → maximin 全责
            alpha = (1.0, 0.0)
        a[i] = project_cbf(a[i], share=alpha[0] * u_req)
        a[j] = project_cbf(a[j], share=alpha[1] * u_req)
    return a

# IP-267 RNI：角色协商交互（授权 × 响应性 × 判别力）
def role_negotiated_query(belief, sources, domain, budget):
    best = None
    for src, q in candidate_queries(belief, sources):
        if not budget.allow(q): continue
        voi = (mutual_info(belief.others_role, q.answer)
               * src.authority(domain) * responsiveness(belief, src, q) - cost(q))
        if best is None or voi > best.voi: best = (src, q, voi)
    return best if best and best.voi > 0 else None      # 无利可图 → maximin

# IP-268 RDE：自身角色漂移包络（三通道联合）
def role_drift_ok(self_role, hist, res_ch, flow_ch):
    d = behavior_divergence(hist, self_role)
    return (d <= D_MAX) and not (res_ch.high and flow_ch.high)

# IP-276 主闭环（继承 R69，插入角色/互惠层）
def ROAM_RAS_round(M, obs, others):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 1) R69：多模态分解 + 三分不确定性
    K = 4 if M.fmp.mode_head(z) > TAU_MODE else 1
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    # 2) R70：角色推断 + 一致性 + 战略不确定性
    role_hat, r_role, switched = M.rcm.update_all(others, M.hist, o)
    U_strat = M.sud.strategic_uncertainty(M.role_belief, M.last_a, M.br, M.risk)
    # 3) 自身角色包络与漂移
    if not M.rde.ok(M.self_role, M.hist, M.res_ch, M.flow_ch):
        M.self_role = M.rde.shrink_envelope(M.self_role); M.audit.flag_role_drift()
    # 4) 战略歧义：先协商（授权+响应性），无利可图则 maximin
    g = None
    trust_ok = min(M.rcm.trust.values()) >= BETA_MIN and not switched.any()
    if U_strat > TAU_STRAT and trust_ok:
        g = M.rni.choose(M.role_belief, M.sources, M.domain, M.budget)
        if g is not None:
            ans = g.src.execute(g.q)                     # 角色授权证据
            M.role_belief = bayes_update_role(M.role_belief, ans, auth=g.src.authority)
            M.rcm.trust[g.src.id] = update_trust(M.rcm.trust[g.src.id], ans, g.src.authority)
    alpha_self = (1.0 if (min(M.rcm.trust.values()) < BETA_MIN or switched.any())
                  else M.rcc.share(M.self_role, role_hat))
    # 5) 风险缩放（R69 的 λ 仍是基础）+ 互惠过滤
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if alpha_self >= 1.0: lam = max(lam, 0.8)            # maximin = R69 边界
    a_nom = M.ach.propose(x_prime, H=M.vista.H)
    a_safe = M.rcc.reciprocal_filter(M.state, a_nom, role_hat, M.rcm.trust,
                                     M.pair_h, M.alpha_map)
    # 6) 角色承诺信号（可读、粘滞）防活锁 + 认证 + 审计
    M.commit.signal(role_hat, M.self_role, ttl=T_COMMIT)
    k = M.c_ras_wm.certified_prefix(a_safe, ..., wm_preds)
    M.vqa_r.submit_async(role_hat, alpha_self, r_role, U_strat)
    return k, lam, a_safe, (U_ale, U_epi, U_strat), alpha_self
```

## 3. 推导

**引理 19（角色一致性的预测信息价值）** 设他人未来行为 Y、角色 τ。角色越一致（Y|τ 条件熵越低）且越可辨识（I(τ;history) 越大），则
H(Y|history, τ) ≤ H(Y|history) − I(τ;Y|history)。
系：**角色的价值 = 约束力 × 可辨识度**；角色越一致、越可读，互惠预测越准、U_strat 越低。角色不是标签，是可压缩的行为先验。

**引理 20（互惠安全的责任充分条件）** 若 α_i + α_j ≥ 1 且双方在 τ_d 内兑现义务，则 pairwise CBF 条件可满足，碰撞概率 ≤ δ(τ_d)。若一方少兑现 δ_α，另一方需额外裕度 g(δ_α)=δ_α·u_req/κ；超阈值即触发 RCM 并转 maximin。系：**责任分配不是道德问题，是安全裕度的账本**；「谁该让」可以算，让多少必须兑付。

**引理 21（角色伪装的可检测性与损害上界）** 伪装者要在 m 个正交通道上同时一致才能压低 r_role；每增加一个通道，伪装成本指数上升（模仿多个互不相关的行为/授权/时序特征）。更关键：在检测延迟 τ_d 内，由于 trust<β_min 即全责，**损害 ≤ R69 级最大风险**。系：ROAM 不要求「识破所有伪装」，只要求「伪装期间也只损失 R69 级的效率，不损失 R69 级以上的安全」。

**引理 22（角色承诺破除活锁）** 全序优先 ≺_τ + 粘滞承诺 T_commit > 2τ_d ⇒ 对称走廊不再振荡；deadlock 在有限步内由高优先者先动消解。系：**角色一致性本身是活锁的解药**——来回改主意才是不一致的根源，稳定角色反而让系统敢动。

**定理 18（ROAM 严格包含 R69）** 在 A100–A102 下，当 β=0（角色不可信）、U_strat=0（战略歧义决策无关）、或自身漂移报警时，ROAM 逐指令退化为 R69：α_self=1、λ 与 k 与 R69 相同、无角色协商；故安全侧风险 ≤ R69，效率侧仅在角色一致性证据充分时获得 reciprocity bonus。**R69 = ROAM 的「信任为零」边界。**

**定理 19（互惠避碰的安全-效率前沿）** 在 A100–A102 且共同角色分配近似公共知识下，碰撞概率 ≤ δ，且期望通行效率 ≥ maximin + c·(1−α_self)·Δ_eff；前沿由信任 β 参数化：β↑ → 效率↑、对角色违约的暴露↑。最优 β* 由违约率 p_v 与检测延迟 τ_d 决定：β* ≈ argmax_β [(1−p_v)·eff(β) − p_v·exp(β,τ_d)]。

**定理 20（自身角色漂移的可检测性）** 若角色漂移超过包络 d_self > D_MAX 且持续，则三通道联合检测在期望延迟 ≤ W·(D_MAX/δ_d) 内以虚警 ≤ α 报出；而角色内适应（d_self 不增）时不误报。系：**角色一致性不只用于读别人，也用于审计自己**——R68 的标定漂移在语义层的镜像。

**定理 21（角色授权证据的投毒界）** 单源未授权不能定案；k 个授权源一致且角色可信时，错误采纳率 ≤ δ_p·ρ^{k−1} + ε_auth。授权伪造需同时伪造角色信任，受引理 21 约束。系：R69 的「k 个正交证据源」升级为「k 个**正交且授权**的证据源」——**不是谁回答都算数**。

## 6. 本轮最大风险

**一句话**：ROAM-RAS 的全部效率收益押在「角色一致性可以被可靠估计、且不能被低成本伪装」这一前提上——**若角色推断被分布偏移、伪装或角色标签投毒污染，系统就可能把攻击者当成可信的合作者而主动让出责任份额（α<1），用「互惠」把 R69 的「诚实的不知道」升级成「礼貌地把安全交给一个演得很像的人」**；互惠于是成了责任转嫁的通道。

**次级风险与缓解**：
1. **角色伪装/授权伪造** → 正交通道一致性 + 时间累积信任 + 单次违约清零（定义 320、引理 21）；
2. **共同角色分配不是公共知识** → 可读信号 + 一致性验证 + A101 显式假设；不满足即退 maximin；
3. **死锁/活锁** → 角色承诺 + 全序优先（定义 321、引理 22）；
4. **自身角色漂移/越权** → 角色包络硬约束 + 三通道漂移检测（定义 322–323、定理 20）；
5. **角色协商 VoI 被高估** → 授权 × 响应性折减 + 沉默也算证据 + E311 校准。

## 3. 关键算法伪代码

```python
# IP-264 RCM：角色残差 + CUSUM
class RoleMonitor:
    def residual(self, i, hist, o):
        lls = {tau: self.roles[tau].loglik(hist, o) for tau in self.roles}
        t_hat = max(lls, key=lls.get)
        return t_hat, -(lls[t_hat] - max(v for k, v in lls.items() if k != t_hat))
    def update(self, i, hist, o):
        tau_hat, r = self.residual(i, hist, o)
        self.S[i] = max(0.0, self.S[i] + r - self.k)
        switched = self.S[i] > self.h
        if switched: self.S[i] = 0.0
        return tau_hat, r, switched

# IP-265 SUD：只算会改变最优动作的战略差异
def strategic_uncertainty(belief, a_rec, br_fn, risk_fn):
    r_rec = risk_fn(a_rec, br_fn(belief.map))
    return max(risk_fn(a, br_fn(tau)) for tau, a in br_fn.actions(belief)) - r_rec

# IP-266 RCC：角色诱导责任份额 + 互惠 CBF（不可信即全责）
def reciprocal_filter(x, a_nom, roles, trust, pair_h, alpha_map):
    a = a_nom.copy()
    for (i, j) in unsafe_pairs(x, pair_h):
        u_req = required_avoidance(x, i, j)
        alpha = alpha_map(roles[i], roles[j])
        if min(trust[i], trust[j]) < BETA_MIN: alpha = (1.0, 0.0)   # maximin
        a[i] = project_cbf(a[i], share=alpha[0] * u_req)
        a[j] = project_cbf(a[j], share=alpha[1] * u_req)
    return a

# IP-267 RNI：授权 × 响应性 × 判别力
def role_negotiated_query(belief, sources, domain, budget):
    best = None
    for src, q in candidate_queries(belief, sources):
        if not budget.allow(q): continue
        voi = (mutual_info(belief.others_role, q.answer)
               * src.authority(domain) * responsiveness(belief, src, q) - cost(q))
        if best is None or voi > best.voi: best = (src, q, voi)
    return best if best and best.voi > 0 else None                # → maximin

# IP-276 主闭环（继承 R69）
def ROAM_RAS_round(M, obs, others):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 4 if M.fmp.mode_head(z) > TAU_MODE else 1
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    role_hat, r_role, switched = M.rcm.update_all(others, M.hist, o)
    U_strat = M.sud.strategic_uncertainty(M.role_belief, M.last_a, M.br, M.risk)
    if not M.rde.ok(M.self_role, M.hist, M.res_ch, M.flow_ch):
        M.self_role = M.rde.shrink_envelope(M.self_role); M.audit.flag_role_drift()
    g = None
    trust_ok = min(M.rcm.trust.values()) >= BETA_MIN and not switched.any()
    if U_strat > TAU_STRAT and trust_ok:
        g = M.rni.choose(M.role_belief, M.sources, M.domain, M.budget)
        if g is not None:
            ans = g.src.execute(g.q)
            M.role_belief = bayes_update_role(M.role_belief, ans, auth=g.src.authority)
            M.rcm.trust[g.src.id] = update_trust(M.rcm.trust[g.src.id], ans, g.src.authority)
    alpha_self = (1.0 if (min(M.rcm.trust.values()) < BETA_MIN or switched.any())
                  else M.rcc.share(M.self_role, role_hat))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if alpha_self >= 1.0: lam = max(lam, 0.8)                     # = R69 边界
    a_nom = M.ach.propose(x_prime, H=M.vista.H)
    a_safe = M.rcc.reciprocal_filter(M.state, a_nom, role_hat, M.rcm.trust,
                                     M.pair_h, M.alpha_map)
    M.commit.signal(role_hat, M.self_role, ttl=T_COMMIT)          # 防活锁
    k = M.c_ras_wm.certified_prefix(a_safe, ..., wm_preds)
    M.vqa_r.submit_async(role_hat, alpha_self, r_role, U_strat)
    return k, lam, a_safe, (U_ale, U_epi, U_strat), alpha_self
```

## 4. 推导

**引理 19（角色一致性的预测信息价值）** 角色越一致（`H(Y|τ)` 低）且越可辨识（`I(τ;history)` 大），则 `H(Y|history,τ) ≤ H(Y|history) − I(τ;Y|history)`。系：角色价值 = 约束力 × 可辨识度；角色是可压缩的行为先验，不是标签。

**引理 20（互惠安全的责任充分条件）** `α_i+α_j≥1` 且 τ_d 内守约 ⇒ pairwise CBF 可满足，碰撞概率 ≤ `δ(τ_d)`。一方少兑现 `δ_α`，另一方需额外裕度 `g(δ_α)=δ_α·u_req/κ`；超阈触发 RCM 转 maximin。系：责任分配是安全裕度的账本。

**引理 21（角色伪装的可检测性与损害上界）** 伪装需在 m 个正交通道上同时一致，成本随 m 指数上升；更关键，τ_d 内 trust<β_min ⇒ 全责，**损害 ≤ R69 级最大风险**。系：不要求识破所有伪装，只要求伪装期间不损失 R69 以上的安全。

**引理 22（角色承诺破除活锁）** 全序优先 `≺_τ` + `T_commit>2τ_d` ⇒ 对称走廊不再振荡，deadlock 有限步消解。系：角色一致性本身是活锁的解药。

**定理 18（ROAM 严格包含 R69）** A100–A102 下，当 β=0、`U_strat=0`、或自身漂移报警时，ROAM 逐指令退化为 R69：`α_self=1`、λ 与 k 相同、无角色协商；安全侧 ≤ R69，效率侧仅在角色证据充分时获 reciprocity bonus。**R69 = 信任为零边界。**

**定理 19（互惠避碰的安全-效率前沿）** A100–A102 且共同角色分配近似公共知识下，碰撞概率 ≤ δ，效率 ≥ maximin + `c·(1−α_self)·Δ_eff`；前沿由 β 参数化，`β*≈argmax_β[(1−p_v)·eff(β) − p_v·exp(β,τ_d)]`。

**定理 20（自身角色漂移的可检测性）** `d_self>D_MAX` 持续时，三通道联合检测期望延迟 ≤ `W·(D_MAX/δ_d)`、虚警 ≤ α；角色内适应不误报。系：角色一致性也用于审计自己。

**定理 21（角色授权证据的投毒界）** 未授权单源不能定案；k 个授权源一致且角色可信时错误率 ≤ `δ_p·ρ^{k−1}+ε_auth`；授权伪造需同时伪造角色信任，受引理 21 约束。系：证据纪律从「k 个正交源」升级为「k 个正交且授权源」。

## 7. 本轮最大风险

**一句话**：ROAM-RAS 的全部效率收益押在「角色一致性可被可靠估计、且不能被低成本伪装」这一前提上——**若角色推断被分布偏移、伪装或角色标签投毒污染，系统就可能把攻击者当成可信合作者而主动让出责任份额（α<1），用「互惠」把 R69 的「诚实的不知道」升级成「礼貌地把安全交给一个演得很像的人」**；互惠于是成为责任转嫁的通道。

**次级风险与缓解**：角色伪装/授权伪造（正交通道 + 时间累积信任 + 违约清零，定义 320/引理 21）；共同角色分配非公共知识（可读信号 + 一致性验证 + 不满足即 maximin）；死锁/活锁（角色承诺 + 全序优先，定义 321/引理 22）；自身角色漂移/越权（角色包络 + 三通道检测，定义 322–323/定理 20）；VoI 高估（授权 × 响应性折减 + 沉默也算证据 + E311 校准）。
