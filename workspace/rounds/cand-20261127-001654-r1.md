> **基线**：第 9 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-436–439（CESC/FSVC/IPAM/HPC-E+），其上承 v22 PGEV/ACSC/DCSC/CFC++、v21 DCL/GIC/SDC/CAC、v20 PCA/CTS/CFC/HPC/CFCtrl。
> 本轮纪律：**标定是几何证书的根信任，隔离是证书链的边界**。不推倒 v23：CESC/FSVC/IPAM/HPC-E+ 全部保留，v22/v21/v20 各模块全部保留。本轮只做一件事：**给整条证书链补上"根信任证明 + 非干扰边界"——把此前被默认成立、却从未被认证的两个前提（传感器已标定、共享状态可信）升级为可审计、可退化、可机械复核的证书，并顺手封堵 v23 的最大风险（版本/统计覆盖在协同故障下的共振崩塌）**。

## 0. 直觉与动机

**灵感 1（传感器标定 → 几何证书的根信任）**
直觉：v20–v23 的 ε_loc、CertBox、conformal 覆盖、甚至 AbsCert 的覆盖图，全都默认"传感器已经标定好、时间已经同步好"。但外参漂移（振动/温度/负载）、时间同步漂移、内参/镜头漂移是**系统性偏差**，不是零均值噪声：它不满足 conformal 的交换性假设，而且会被同一标定谱系上的所有机器人共享。于是整条几何安全链建立在一个**从未被认证的根**上。核心创新：**标定证书 (Calibration Certificate, CalCert) + 标定漂移监视器 (Calibration Drift Monitor, CDM) + 标定感知 conformal (Calibration-Aware Conformal, CACF)**。关键反直觉点：**标定不确定度在一个标定纪元内只能单调不减**——用同一批数据重跑标定得到的"更小误差"是自我确认，不是新证据；重标定必须由独立锚点（跨模态/外部靶标/异谱系机器人）背书，否则拒绝。第二反直觉点：**多机器人投票只能平均随机误差，不能平均系统性的标定偏置**——N 台共享同一标定的机器人，其标定误差的有效证据数仍是 1。这直接改写联邦证书的误差合成公式。

**灵感 2（状态隔离 → 证书链的非干扰边界）**
直觉：v20–v23 的所有模块共享一个可变状态 ζ。一个模块的 bug、一次被污染的云端更新、一个慢模块的写-写竞争，都可能悄悄改写另一个模块的证书；更糟的是，语义/规范/云边状态是"慢而可变"的，控制环是"快而安全关键"的，二者共享状态意味着**时间耦合与数据竞争**。核心创新：**状态隔离内核 (State Isolation Kernel, SIK)**——每个模块独占一个状态格 ζ_i，能力作用域只允许写自己的格、只允许向只追加签名日志追加；跨模块通信只能通过不可变的证书记录；**双区运行时 (Two-Zone Runtime, TZR)**——语义区（≤10Hz、可变、可失败）与安全区（50Hz、只读密封快照、无锁无分配）。关键反直觉点：**隔离不只是安全（security）属性，它是安全（safety）属性**——"证书非干扰"保证一个被攻陷/出错的模块无法静默改写另一个模块的 SAFE 判定；隔离把"单点故障"限制为"单点可用性损失"，而不是"全局安全失效"。

**二者如何统一：根信任 + 信任边界 = 端到端信任链**
标定认证**输入**（传感器→几何），隔离认证**流向**（模块→模块→执行器）。二者合起来才让"从物理量到执行指令"的每一跳都可审计。统一状态扩展为 **ζ_trust = ζ_ce ∪ (CalCert, Σ_θ, τ_cal, λ_lineage, {ζ_i}, L, σ_sealed)**。统一准入门：**HPC-E++ = HPC-E+ ∧ CalCert 有效 ∧ IsolationCert 有效**，且几何项必须使用**标定条件化的 CertBox**。`Exec_v24 = Exec_v23 ∩ Fil_cal ∩ Fil_iso ⊆ Exec_v23`。任一失效只向更保守方向退化，绝不静默放宽。

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 标定根信任律（Calibration Root-of-Trust）**
任何几何证书必须携带 CalCert；`ε_cal ≥ 0` 在标定纪元内**单调不减**；`CertBox_k = inflate(b_k, ε_loc(s_k) + ε_cal(r_k, v_rel) + ε_sync)`。标定不确定度按 `ε_total = ε_random/√N_eff + ε_systematic` 合成，其中 `ε_systematic = max_λ ε_cal(λ) + ε_disagree`，**绝不除以 N**。失去可观测性 ⇒ τ_cal 按保守速率衰减 ⇒ ε_cal 增大 ⇒ 执行域收缩。新标定纪元只能由独立锚点闸门开启。

**P44 状态隔离非干扰律（State Isolation Non-interference）**
`ζ = ⊔_{i∈M} ζ_i ⊔ L`；模块 i 只能写 ζ_i、只能向 L 追加签名记录；跨模块只读不可变记录。证书记录 `rec=(author, type, payload, parent_hash, ttl, sig_i)` 构成哈希链。**非干扰**：把 ζ_j 替换为任意 ζ_j'，所有 i≠j 签发的证书逐位不变。拜占庭模块 j 只能让自己的证书被拒（可用性损失），不能伪造他人的 SAFE（安全性保持）。

**P45 双区时间隔离律（Two-Zone Temporal Isolation）**
安全区（50Hz）只读**密封快照** σ_active，无锁、无动态分配、无阻塞 I/O；语义区（≤10Hz）只写暂存区，屏障处由封印器校验不变量后**原子双缓冲翻转**。语义区错过截止期 ⇒ 保持上一 σ_active 并按 TTL 衰减；TTL 到期 ⇒ 触发快照内**预置的保守回退**（不是现场计算）。故语义区任何卡死/崩溃都不能放宽执行域。

**P46 标定多样性仲裁律（Calibration-Diversity Quorum）**
联邦票携带标定谱系 `λ_i = H(CalCert_i)`。投票只降低**随机**误差项（÷√N_eff）；**系统**误差取谱系上的最大值，共享谱系的有效证据数为 1。谱系间不一致超过 ε_agree ⇒ 触发共模/篡改告警并膨胀 ε_cal。若无法达成联邦仲裁，退化为**单机器人保守模式**（标定膨胀、非停机），绝不静默死锁。

## 3. 与基线的接口（如何退化）

- CalCert 过期/验签失败 ⇒ τ_cal=0、ε_cal=ε_max ⇒ 共享区停机、非共享区按静态人距上限 ⇒ ⊆ v23；
- CDM 不可观测 ⇒ τ_cal 按最快速率衰减 ⇒ ε_cal 单调增大 ⇒ ⊆；
- 重标定闸门拒绝 ⇒ 维持旧纪元 + 已膨胀 ε_cal，不回退到"更紧"的旧值 ⇒ ⊆；
- SIK 检测到隔离违规 ⇒ 冻结涉事模块的所有新证书，回退到最后密封快照并 TTL 衰减 ⇒ ⊆；
- TZR 错过屏障 ⇒ 保持 σ_active，TTL 到期触发预置保守回退 ⇒ ⊆；
- 标定多样性不足 ⇒ 不发放"多机器人缩小系统误差"的信用，只保留单谱系界 ⇒ ⊆（不是死锁）；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`（引理 10）。

## 4. 预期贡献

1. **标定根信任**：首次把传感器标定从"隐含前提"变成带协方差、有效期、谱系与单调不确定度的可审计证书，并给出随机/系统误差分离的误差合成；
2. **漂移可观测性理论**：给出"无报警 ≠ 健康"的失效安全规则与不可观测退化路径，封堵"标定盲区"；
3. **状态非干扰证书**：把隔离从工程实践升级为可证明的安全属性（非干扰 + 故障容纳），使证书链可独立审计；
4. **双区运行时**：给出 50Hz 安全区与 ≤10Hz 语义区的无锁密封快照协议与截止期缺失下的预置保守回退；
5. **标定多样性仲裁**：证明"投票不能缩小系统误差"，并把它变成 CFC 的显式仲裁维度，封堵 v23 的共模共振风险；
6. **端到端信任链**：CalCert → 几何/规范/能量证书 → 密封快照 → 执行器，`Exec_v24 ⊆ Exec_v23` 闭环。

## 5. 本轮最大风险

**一句话**：整套"根信任"依赖漂移**可观测**；在无纹理、退化几何、强雾/逆光等标定不可观测环境中，CDM 无法区分"已标定"与"静默漂移"，τ_cal 的衰减只是启发式下界——系统可能持有一张几何自洽、签名完整、却根信任已失效的证书，即"不可观测的标定盲区"。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Calibration Certificate (CalCert / SCC) — 几何根信任
# ============================================================
@dataclass
class CalibrationCertificate:
    epoch: int
    theta: np.ndarray            # (R_ext, t_ext, delta_t, xi_intr)
    Sigma_theta: np.ndarray      # 后验协方差
    eps_R: float                 # 旋转误差半径（rad）
    eps_t: float                 # 平移误差半径（m）
    eps_tau: float               # 时延误差半径（s）
    eps_intr: float              # 内参相对误差
    anchors: list                # 独立锚点摘要（跨模态/外部靶标）
    lineage: bytes               # H(CalCert) 标定谱系
    issued_at: float
    valid_until: float
    sig: bytes

    def verify(self, pk_robot) -> bool:
        if not verify_signature(pk_robot, self.payload_hash(), self.sig):
            return False
        if not (self.epoch >= 0 and self.valid_until > self.issued_at):
            return False
        # 协方差必须半正定，防止伪造"负不确定度"
        return np.all(np.linalg.eigvalsh(self.Sigma_theta) >= -1e-12)

    def epsilon_cal(self, r: float, v_rel: float) -> float:
        """Lipschitz 传播：r 放大旋转/内参误差，v_rel 放大时延误差"""
        return r * self.eps_R + self.eps_t + abs(v_rel) * self.eps_tau + r * self.eps_intr

    def payload_hash(self) -> bytes:
        return H(self.epoch, self.theta.tobytes(), self.Sigma_theta.tobytes(),
                 self.eps_R, self.eps_t, self.eps_tau, self.eps_intr,
                 sorted(self.anchors), self.issued_at, self.valid_until)


class CalibrationRootOfTrust:
    """管理当前纪元；任何几何证书签发前必须取用 active 证书。"""
    def __init__(self, pk_robot):
        self.pk = pk_robot
        self.active: CalibrationCertificate = None

    def current(self) -> CalibrationCertificate:
        return self.active

    def try_new_epoch(self, candidate: CalibrationCertificate,
                      gate: 'RecalibrationGate') -> bool:
        """新纪元只能经独立锚点闸门开启；否则维持旧纪元与已膨胀 ε_cal。"""
        if not candidate.verify(self.pk):
            return False
        if not gate.accept(self.active, candidate):
            return False
        self.active = candidate
        return True


# ============================================================
# IP-441 Calibration Drift Monitor (CDM) — 无报警≠健康
# ============================================================
class CalibrationDriftMonitor:
    def __init__(self, k=0.5, h=5.0, obs_min=8.0,
                 lam_unobs=1e-3, lam_alarm=1e-2, gamma_recover=1e-4):
        self.k, self.h, self.obs_min = k, h, obs_min
        self.lam_unobs, self.lam_alarm = lam_unobs, lam_alarm
        self.gamma_recover = gamma_recover
        self.S = 0.0
        self.tau_cal = 1.0
        self.last_t = now()

    def update(self, rho_t: float, obs_t: float, mu0: float, sigma0: float) -> str:
        dt = now() - self.last_t
        self.last_t = now()
        if obs_t < self.obs_min:
            # 不可观测：无证据 ≠ 健康，按保守速率衰减
            self.tau_cal *= math.exp(-self.lam_unobs * dt)
            return "UNOBSERVABLE"
        u = (rho_t - mu0) / max(sigma0, 1e-9)
        self.S = max(0.0, self.S + u - self.k)
        if self.S > self.h:
            self.tau_cal *= math.exp(-self.lam_alarm * dt)
            return "ALARM"
        # 可观测且无报警：允许极缓慢恢复，但绝不重置为 1
        self.tau_cal = min(1.0, self.tau_cal + self.gamma_recover * dt)
        return "OK"

    def epsilon_cal(self, cert: CalibrationCertificate, r: float,
                    v_rel: float, eps_max: float) -> float:
        base = cert.epsilon_cal(r, v_rel)
        return base + (1.0 - self.tau_cal) * eps_max   # 单调不减


# ============================================================
# IP-442 Calibration-Aware Conformal (CACF) — 覆盖与重标定闸门
# ============================================================
class CalibrationAwareConformal:
    def __init__(self, alpha=0.01):
        self.alpha = alpha
        self.calib_scores: list[float] = []   # 含标定残差的分数

    def score(self, det, cert: CalibrationCertificate, cdm: CalibrationDriftMonitor,
              eps_max: float) -> float:
        e_loc = det.localization_error
        e_cal = cdm.epsilon_cal(cert, det.range, det.v_rel, eps_max)
        return (e_loc + e_cal) / (det.scale + 1e-9)

    def quantile(self, s: float) -> float:
        if len(self.calib_scores) < 30:
            return float("inf")               # 样本不足 → 最保守
        return np.quantile(self.calib_scores, 1 - self.alpha)

    def recalibrate(self, dets, cert, cdm, eps_max):
        """仅在标定纪元内刷新分数；纪元切换必须走 RecalibrationGate。"""
        self.calib_scores = [self.score(d, cert, cdm, eps_max) for d in dets]


class RecalibrationGate:
    """独立锚点闸门：禁止同数据自证与锚点投毒。"""
    def __init__(self, eps_agree=0.02, min_anchor_gain=0.05):
        self.eps_agree = eps_agree
        self.min_anchor_gain = min_anchor_gain

    def accept(self, old: CalibrationCertificate,
               new: CalibrationCertificate) -> bool:
        # 1) 锚点集合必须与旧纪元独立（不同模态/外部靶标/异谱系机器人）
        if set(new.anchors) & set(old.anchors):
            return False
        # 2) 新证书的验证集必须与标定集不相交（由 anchors 摘要携带）
        if not new.anchors_disjoint_from_fit():
            return False
        # 3) 必须跨模态一致性通过，且留出残差有实质下降
        if not cross_modal_consistent(new, self.eps_agree):
            return False
        if new.holdout_residual > old.holdout_residual - self.min_anchor_gain:
            return False
        # 4) 不允许"以更紧的界"开启新纪元：新 ε 必须不小于旧纪元的已验证下界
        return new.epsilon_cal(1.0, 1.0) >= old.verified_lower_bound()

# IP-443 State Isolation Kernel (SIK) — 证书非干扰
# ============================================================
class StateCell:
    def __init__(self, owner: str):
        self.owner = owner
        self.state: dict = {}
        self.snapshot: dict = None

    def begin(self):
        self.snapshot = copy.deepcopy(self.state)

    def rollback(self):
        if self.snapshot is not None:
            self.state = self.snapshot
            self.snapshot = None


class StateIsolationKernel:
    MODULES = ["sdc", "cac", "dcl", "gic", "pgev", "acsc",
               "dcsc", "cesc", "fsvc", "ipam", "cal", "hpc_e_pp"]

    def __init__(self):
        self.cells = {m: StateCell(m) for m in self.MODULES}
        self.head = GENESIS_HASH
        self.log: list[Record] = []

    def write(self, module: str, key: str, value):
        # 能力作用域：只能写自己的格
        if key.startswith("_foreign_"):
            raise PermissionError("cross-cell write denied")
        self.cells[module].state[key] = value

    def append_record(self, module: str, rec_type: str, payload: dict,
                      ttl: float) -> Record:
        rec = Record(author=module, type=rec_type, payload=payload,
                     parent_hash=self.head, ttl=ttl,
                     sig=sign(module, payload, self.head))
        self.head = H(self.head, rec.digest())
        self.log.append(rec)
        return rec

    def verify_non_interference(self) -> bool:
        """结构校验：每条记录只由 author 的格 + 不可变前缀导出。"""
        prefix = GENESIS_HASH
        for rec in self.log:
            if rec.parent_hash != prefix:
                return False
            if not verify_signature(pubkey(rec.author), rec.payload_digest(), rec.sig):
                return False
            # 记录类型必须属于 author 的能力集合
            if rec.type not in CAPABILITIES[rec.author]:
                return False
            prefix = H(prefix, rec.digest())
        return prefix == self.head

    def freeze_module(self, module: str):
        """隔离违规：冻结该模块的新证书，不触碰其他格。"""
        self.cells[module].state["_frozen"] = True

# IP-444 Two-Zone Runtime (TZR) — 时间隔离与密封快照
# ============================================================
@dataclass
class SealedSnapshot:
    seq: int
    hpc_eff: dict
    dcl_state: dict
    gic_state: dict
    cal_cert: CalibrationCertificate
    tau_cal: float
    ttl: float
    sealed_at: float
    fallback: dict          # 预置保守回退，禁止现场计算

    def expired(self) -> bool:
        return now() > self.sealed_at + self.ttl


class TwoZoneRuntime:
    def __init__(self, conservative_default: dict):
        self.active = SealedSnapshot(0, {}, {}, {}, None, 0.0, 0.0,
                                     now(), conservative_default)
        self.next_slot: SealedSnapshot = None
        self.staging: dict = None

    # ---- 语义区（<=10Hz，可变、可失败、无实时保证）----
    def semantic_tick(self, proposal: dict):
        self.staging = proposal

    def seal_barrier(self, certs, dcl, gic, cal, tau_cal):
        cand = SealedSnapshot(
            seq=self.active.seq + 1,
            hpc_eff=certs, dcl_state=dcl, gic_state=gic,
            cal_cert=cal, tau_cal=tau_cal,
            ttl=TTL_SEMANTIC, sealed_at=now(),
            fallback=self.active.fallback)
        if not check_invariants(cand):     # 单调 ε、TTL、隔离、版本
            return False
        self.next_slot = cand
        # 原子双缓冲翻转（单字写 + release 语义；安全区只读 active）
        self.active, self.next_slot = self.next_slot, None
        return True

    # ---- 安全区（50Hz，无锁、无分配、无阻塞）----
    def safety_read(self) -> SealedSnapshot:
        s = self.active
        if s.expired():
            return SealedSnapshot(s.seq, s.hpc_eff, s.dcl_state, s.gic_state,
                                  s.cal_cert, 0.0, 0.0, now(), s.fallback)
        return s

# IP-445 Calibration-Diversity Consensus (CFC++++ / CDQ)
# ============================================================
class CalibrationDiversityConsensus(CFCPlusPlusPlus):
    def __init__(self, N, F, M_MIN=2, eps_agree=0.02, eps_penalty=0.05):
        super().__init__(N, F)
        self.M_MIN = M_MIN
        self.eps_agree = eps_agree
        self.eps_penalty = eps_penalty

    def consensus_round(self):
        results = {}
        for key, votes in self.votes.items():
            lineages = {v.lineage for v in votes.values()}
            N_eff = len(lineages)                       # 共享谱系只计一次
            eps_random = min(v.eps_random for v in votes.values()) / math.sqrt(N_eff)
            eps_sys = max(v.eps_systematic for v in votes.values())  # 绝不除 N
            eps_fed = eps_random + eps_sys
            agree = max_pairwise_lineage_diff(votes) <= self.eps_agree
            if not agree:
                self._alarm("COMMON_MODE_CALIBRATION", key)
                eps_fed += self.eps_penalty

            count_ok = len(votes) >= self.N - self.F
            modality_ok = len({v.modality for v in votes.values()}) >= self.M_MIN
            layer_ok = self._check_layer_consistency(votes)
            ce_ok = all(v.ce_version == next(iter(votes.values())).ce_version
                        for v in votes.values())
            fs_ok = all(v.few_shot_valid for v in votes.values())
            ip_ok = all(v.ip_attested for v in votes.values())

            if all([count_ok, modality_ok, layer_ok, ce_ok, fs_ok, ip_ok]):
                results[key] = self._majority(votes, eps_fed)
            else:
                # 不达成联邦仲裁 ≠ 死锁：退单机保守（标定膨胀）
                results[key] = self._single_robot_conservative(votes, eps_fed)
        return results

# IP-446 HPC-E++ 端到端信任链准入门
# ============================================================
@dataclass
class HPCETwoPlus:
    hpc_e_plus: HPCEPlus
    cal_root: CalibrationRootOfTrust
    cdm: CalibrationDriftMonitor
    sik: StateIsolationKernel
    tzr: TwoZoneRuntime
    tau_min: float = 0.2
    eps_max: float = 1.0

    def admits(self, plan, x, v, z, E_res, margin_req, modules) -> bool:
        # 1) v23 的六证基础
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2) 标定根信任
        cal = self.cal_root.current()
        if cal is None or not cal.verify(self.cal_root.pk):
            return False
        if now() > cal.valid_until or self.cdm.tau_cal < self.tau_min:
            return False
        # 3) 几何项必须是标定条件化的
        eps_cal = self.cdm.epsilon_cal(cal, plan.max_range, plan.max_v_rel,
                                       self.eps_max)
        if not plan.certbox_uses(eps_cal):
            return False
        # 4) 隔离非干扰
        if not self.sik.verify_non_interference():
            return False
        snap = self.tzr.safety_read()
        if snap.cal_cert is None or snap.expired():
            return False
        # 5) 密封快照与当前标定谱系一致
        return snap.cal_cert.lineage == cal.lineage


# ============================================================
# 端到端流水线：标定 → 感知 → 隔离 → 共识 → 密封 → 执行
# ============================================================
class TrustChainPipeline:
    def __init__(self, config):
        self.cal_root = CalibrationRootOfTrust(config["pk_robot"])
        self.cdm = CalibrationDriftMonitor()
        self.cacf = CalibrationAwareConformal(config["alpha"])
        self.sik = StateIsolationKernel()
        self.tzr = TwoZoneRuntime(config["conservative_default"])
        self.cfc = CalibrationDiversityConsensus(config["N"], config["F"])
        self.gate = HPCETwoPlus(config["hpc_e_plus"], self.cal_root,
                                self.cdm, self.sik, self.tzr)

    def step(self, sensor_data):
        # 语义区（<=10Hz）：标定监视 → 证书 → 共识 → 封印
        cal = self.cal_root.current()
        drift = self.cdm.update(sensor_data["rho"], sensor_data["obs"],
                                sensor_data["mu0"], sensor_data["sigma0"])
        if drift != "OK":
            self.sik.append_record("cal", "DRIFT", {"state": drift},
                                   ttl=TTL_SEMANTIC)
        certs = self._make_calibrated_certificates(sensor_data, cal)
        consensus = self.cfc.consensus_round()
        self.tzr.seal_barrier(certs, consensus["dcl"], consensus["gic"],
                              cal, self.cdm.tau_cal)
        # 安全区（50Hz）：只读密封快照，O(1)
        snap = self.tzr.safety_read()
        admitted = self.gate.admits(
            snap_to_plan(snap), sensor_data["x"], sensor_data["v"],
            sensor_data["z"], sensor_data["E_res"],
            sensor_data["margin_req"], snap_modules(snap))
        return admitted, {"snapshot": snap, "drift": drift,
                          "tau_cal": self.cdm.tau_cal, "consensus": consensus}

    def _make_calibrated_certificates(self, sensor_data, cal):
        eps_cal = self.cdm.epsilon_cal(cal, sensor_data["max_range"],
                                       sensor_data["max_v_rel"], self.cdm.eps_max)
        return {f"CertBox_{d.id}": inflate(d.box, d.eps_loc + eps_cal)
                for d in sensor_data["detections"]}
```

## 3. 正确性论证

### 引理 5（标定条件化的覆盖界）
**陈述**：若 CalCert 满足 `P(‖δθ‖ ≤ ε_θ) ≥ 1-δ_cal`，且 `ε_cal ≥ L_h·‖δθ‖`（L_h 为测量模型对 θ 的 Lipschitz 常数），则 `P(真物 ⊆ CertBox) ≥ 1 - δ_loc - δ_cal - δ_sync`。

**证明**：
1. 真实点与估计点的世界坐标差满足三角不等式 `‖x_true - x_est‖ ≤ ‖δx_loc‖ + ‖δx_cal‖ + ‖δx_sync‖`。
2. 由标定参数误差的 Lipschitz 界，`‖δx_cal‖ ≤ r·ε_R + ε_t + v_rel·ε_τ + r·ε_intr = ε_cal`。
3. 三个误差源各自以 1-δ_k 概率落在其界内，联合界给出 `P(任一越界) ≤ Σδ_k`。
4. 因此 `CertBox = inflate(b, ε_loc + ε_cal + ε_sync)` 以 ≥1-Σδ_k 覆盖真物。∎

### 引理 6（标定不确定度的纪元单调性）
**陈述**：在固定标定纪元内，`ε_cal(t)` 单调不减，故 `Exec` 单调不增；只有 RecalibrationGate 通过才允许开启新纪元。

**证明**：
1. `τ_cal` 在纪元内只被 `UNOBSERVABLE`/`ALARM` 降低，或按 `gamma_recover` 极缓慢上升但以 1 为上限；不可观测事件必使 τ_cal 下降。
2. `ε_cal(t) = ε_cal^0 + (1-τ_cal(t))·ε_cal^max`，故 ε_cal 与 τ_cal 反向单调；τ_cal 的下降或缓慢恢复都不使 ε_cal 低于纪元初值。
3. RecalibrationGate 要求独立锚点、验证集与标定集不相交、跨模态一致、留出残差下降，且 `new.ε_cal ≥ old.verified_lower_bound`，排除"用同数据自证出更紧界"。
4. `Exec ∝ 1/ε_cal`，故纪元内执行域单调不增。∎

### 引理 7（状态非干扰与故障容纳）
**陈述**：在能力作用域 + 只追加签名日志下，把 ζ_j 替换为任意 ζ_j'，所有 i≠j 签发的证书记录逐位不变；拜占庭模块 j 只能使其自身证书被拒，不能伪造 i 的 SAFE。

**证明**：
1. 对步数归纳。基态：各格互不引用，记录逐位相同。
2. 归纳步：模块 i 的转移函数只读 ζ_i 与 L 的不可变前缀 `L_{<k}`；替换 ζ_j（j≠i）不改变其输入，故新 ζ_i 与 rec_i 不变。
3. 能力作用域禁止 j 写 ζ_i；签名以模块私钥绑定 author，j 无法伪造 i 的 rec。
4. 门控校验 `rec.type ∈ CAPABILITIES[author]` 与签名，故 j 的非法记录被拒（可用性损失），但 i 的证书不受影响（安全性保持）。∎

### 引理 8（密封快照在截止期缺失下的安全性）
**陈述**：若安全区只读 σ_active，且 σ_active 携带预置保守回退 fallback，则语义区任何卡死/崩溃/超时都不能使 `Exec_v24` 增大。

**证明**：
1. 安全区决策是 σ_active 与实时几何安全输入的纯函数；语义参数（DCL/GIC/标定信任）只来自 σ_active。
2. 语义区停滞时 σ_active 不变，TTL 衰减；TTL 到期 `safety_read` 返回携带 fallback 的快照。
3. fallback 是预置的最保守策略（共享区停机/静态人距上限），其可达集不大于任何正常快照的可达集。
4. 因此语义区故障只能使执行域不变或收缩，绝不增大。∎

### 引理 9（系统误差不可被投票平均）
**陈述**：设每票误差 `ε_i = b_i + η_i`，`b_i` 为标定系统偏置、`η_i` 为零均值随机项。则 `N` 票平均后 `E[ε̄] = mean(b_i)`，系统偏置不随 N 缩小；故 `ε_fed` 必须用 `max_λ ε_systematic(λ)` 而非 `mean/√N`。

**证明**：
1. `ε̄ = (1/N)Σb_i + (1/N)Ση_i`；随机项方差为 σ²/N，随 N 缩小。
2. 系统项 `(1/N)Σb_i` 当所有 b_i=b 时恒为 b，与 N 无关；当 b_i 不同时，`|mean(b_i)| ≤ max|b_i|`，取 max 才给出最坏界。
3. 若用 `max|b_i|/√N`，会把共享偏置错误地压小，导致 CertBox 小于真实误差界 → 假自由空间。
4. 故随机项 ÷√N_eff、系统项取 max 且加谱系分歧项 ε_disagree 是唯一保持覆盖的合成。∎

### 引理 10（端到端单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：
- CalCert 失效/过期 → τ_cal=0、ε_cal=ε_max → 几何域收缩 → ⊆ v23。
- CDM 不可观测 → τ_cal 按最快速率下降 → ε_cal 单调增大 → ⊆。
- 重标定闸门拒绝 → 维持旧纪元与已膨胀 ε_cal，不回退到更紧界 → ⊆。
- SIK 隔离违规 → 冻结涉事模块、回退最后密封快照并 TTL 衰减 → ⊆。
- TZR 错过屏障 → 保持 σ_active，TTL 到期用 fallback → 由引理 8 ⊆。
- CDQ 谱系不足/分歧 → 不发放多机缩小系统误差的信用，退单机保守 → ⊆。
- 组合失效取交集，单调性保持；全失效回退 v23。∎

### 定理（HPC-E++ 端到端信任链的健全性）
**陈述**：对任意计划 π，`HPCETwoPlus.admits(π)=True` ⟹ π 同时满足：
(1) v23 的物理/规范/负信息/能量/云边/少样本/IP 七类条件；
(2) 标定根信任有效且几何界已含 ε_cal；
(3) 证书链非干扰且安全区读取的是未过期密封快照；
并且 `Exec_v24 ⊆ Exec_v23`。

**证明**：直接由 `admits` 的五个连言分支与引理 5–10 可得。必要性：任一分支失败即拒证，对应一类未被缓解的根信任或边界风险。充分性：五分支全过，由引理 5 得覆盖、引理 6 得标定单调、引理 7 得故障容纳、引理 8 得时间隔离、引理 9 得误差合成、引理 10 得单调链，构成端到端闭环。∎

| R8 | 隔离能力作用域配置错误导致"名义隔离、实际共享" | 高 | 1) 记录级 author/type 校验；2) 哈希链增量校验；3) 故障注入测试逐位验证非干扰 | 配置错误可能在测试覆盖不到的模块组合中潜伏 |
| R9 | 10Hz 密封快照相对 50Hz 控制环的陈旧性，导致对动态人的响应变慢 | 中 | 1) TTL 短、到期触发保守回退；2) 安全区内保留 O(1) 的实时几何安全兜底；3) 动态人优先级高于语义参数 | 高速突然闯入者仍可能落在语义刷新间隙 |
| R10 | 标定多样性信用被误用（谱系名义不同但物理同源） | 中 | 1) 谱系含锚点/硬件/温度等来源摘要；2) 分歧超阈即告警并膨胀；3) 系统项始终取 max | 同批次硬件+同流程标定可能被误判为独立 |

## 6. 本轮最大风险（最终确认）

**一句话**：整套"根信任"依赖漂移**可观测**；在无纹理、退化几何、强雾/逆光等标定不可观测环境中，CDM 无法区分"已标定"与"静默漂移"，τ_cal 的衰减只是启发式下界——系统可能持有一张几何自洽、签名完整、却根信任已失效的证书，即"不可观测的标定盲区"。
