# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据规模」×「机器人」）

> R69 把不确定性一分为二：aleatoric 交给保守铁律 λ_floor，epistemic 交给「流匹配多模态策略 + 主动交互」去问。它自陈的最大风险也很清楚——**模态权重一旦不可信，VoI 就在错误的信念上计算，「问错」比「不问」更危险**。但 R69 没回答一个更根本的问题：模态权重为什么不可信？答案往往不是「问得不够」，而是**模型没见过这种世界**。此时再问一百次，也问不出一个它根本表征不了的模态。R69 的 VoI 机器会把「数据匮乏」误诊为「当下歧义」，把宝贵的交互预算花在一个只能靠数据解决的问题上。
>
> 本轮两个灵感正好补上这一层：
> - **数据规模**告诉我们，模态权重不是点估计而是一个**随有效样本量收缩的后验**；而学习曲线的**平台期本身就是 aleatoric 底噪的经验估计**——规模同时提供了「可约性」与「不可约下界」两把尺子；
> - **机器人**告诉我们，数据不是天赐的静态属性，而是**具身系统可以去采集、可以跨机队汇聚的资源**；但机器人之间共享训练集、共享骨架、共享盲区，**同伴的一致不是正交证据，而是相关证据——规模买来的是共识，不一定是真相**。
>
> 核心命题：**把 R69 的 epistemic 再劈成两半——「问一下就能解决」的 U_int，和「只能靠更多数据解决」的 U_data；前者走 R69 的交互，后者走「数据获取 + 机队经验 + 慢时间尺度再标定」。只有在数据通道不可用/被投毒/越预算时，才把 U_data 折回 U_int、再折回 R68 的纯保守。** 命名 **SCALE-RAS**（Scale-aware Calibration & Allocation of Learning Evidence for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我缺的到底是一个答案，还是一批数据——该问谁、又该学什么**」——不确定性不只是刹车踏板，也不只是一句提问，还可以是一次主动探索、一条稀有 episode 的留存、一次向机队的经验调取。

## 0. 直觉与动机

**灵感 1（数据规模 → 存在「第三种」不确定性）**
直觉：R69 的世界里只有两种东西：噪声（问了也白问）和歧义（问一下就好）。但真实机器人经常卡在第三种状态——**世界它没见过**：一个从没训练过的地面材质、一种从没见过的物体、一次从没经历过的交互。此时模型可能自信地吐出**一个**模态（把没见过硬塞进见过的类里），也可能吐出一堆其实都是训练噪声的**假模态**。这两种都不是「问一下」能修的：前者要一次探索/一次标注，后者要一批覆盖该区域的数据。把它叫作 **U_data（由模型数据支撑不足导致、只可被数据削减的不确定性）**，与 U_int（由当下观测歧义导致、可被一次信息动作削减）严格区分，是 R70 的第一块基石。

**灵感 2（数据规模 → 模态权重本来就是个估计量）**
直觉：R69 用经验频率 ŵ_k 当模态权重，再据此算 H_mode 和 VoI。但 ŵ_k 是有限样本估计：在表征空间的低密度区，它的抽样方差极大——**点估计的 VoI 等于在一个噪声值上做决策**。数据规模给出的修正是直接的：把 ŵ 看成 Dirichlet 后验，其集中度由**有效样本量 n_eff(o)** 决定；n_eff 小就自动放大权重的不确定性。于是 R69 最脆弱的前提（「模态权重可信」）被改造成一个**可度量、可门控、可证书化**的量：不是问「权重准不准」，而是问「以当前 n_eff，我能不能证明它准到足以驱动交互」。证明不了，就不是更保守地交互，而是**转去补数据**。

**灵感 3（数据规模 → 学习曲线平台 = aleatoric 底噪的实测）**
直觉：R69 把 U_ale 定义成模态内协方差，是个模型内部的量，可能被低估。数据规模提供了一条**外部标定**通道：持续加数据，任务/似然误差会沿幂律下降，然后**在某个平台停住**。那个平台就是数据也压不下去的部分——**aleatoric 底噪的经验下界**。这让 U_ale 与 U_data 的划分不再是纯先验：U_data 是「还在下降的那段」，U_ale 是「已经平台的那段」。一个可估计的 β（局部幂律指数）不仅预测「再加多少数据能降多少风险」，还直接回答了 R70 的核心问题：**该等数据，还是该立即行动**。

**灵感 4（机器人 → 数据采集本身是一个可决策的动作）**
直觉：对静态数据集，数据规模是命定的；但具身机器人可以**自己去取数据**——主动走到信息量大的状态、把稀有/高惊讶 episode 留存上传、在安全的探索模式下补采样。这把「数据」从被动属性变成了**动作空间里的第三类动作**（任务动作 a、信息动作 g、数据动作 d）。关键工程纪律：数据动作只在**慢时间尺度**上改变模型，实时控制环仍然零学习写操作（继承 R68）。于是系统获得两条并行通道：快环「刹车/提问」，慢环「探索/留存/再标定」，二者用证书在**控制边界**上交换，绝不互相踩踏。

**灵感 5（机器人 → 机队是放大器，也是共谋者）**
直觉：机器人天然成队，机队是免费的数据规模放大器；一个机器人没见过的场景，另一个可能见过。但机队是**相关的**：它们共享训练集、共享仿真器、共享骨架，因此共享盲点。若把 m 个同伴当作 m 个独立证人，就会把「大家都这么认为」误当成「这是对的」——这正是 R69「k 个正交证据源一致」纪律在规模维度上的破口。必须给同伴按误差相关系数 ρ 打折，得到**有效独立源数 k_eff = m / (1 + (m−1)ρ)**；ρ→1 时 k_eff→1，机队再大也只等于一个证人。规模能买共识，买不到真相——这是本轮必须写进证书的清醒。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（SCALE-RAS 总览与四不变式）** SCALE-RAS = (FMP, AUD†, MINT, CIA, FMA, DAL, FEG, EVF, SLX, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；数据动作只在慢环）；
(ii) **双时间尺度隔离**：快环（控制/交互）不被任何数据操作阻塞，数据更新只在经认证的控制边界换装（定义 324）；
(iii) **数据出处纪律**：任何进入再标定的样本/模型必须携带可验证 provenance，未认证数据不得改变快环策略；
(iv) **相关证据纪律**：机队同伴、同源传感器、同训练集模型不自动计为正交证据，须按定义 317 折算出 k_eff 后再做一致性判定。

**定义 311（数据规模状态）** 在表征空间用核密度 K_h(z_i, z_o)（z = Φ(o)，复用 R68 trunk）定义局部有效样本量（Kish）：
n_eff(o) = (Σ_i K_h(z_i,z_o))² / Σ_i K_h(z_i,z_o)²，i 遍历机队记忆 M_fleet。
局部密度 D(o) = Σ_i K_h / (|M_fleet|·V_h)。两者共同刻画「这个观测在训练支撑集里有多孤立」。机队记忆附带 provenance 图 G_p（来源机器人、时间、认证签名、谱系）。

**定义 312（模态权重后验）** 给定经验模态权重 ŵ_k 与有效样本量 n_eff，令
p(w | o) = Dir(α₀ + n_eff(o)·ŵ)，
其均值为后验权重 w̄_k，熵 H(W|o) 度量「权重本身有多不确定」。R69 的 ŵ 是本定义在 n_eff→∞ 时的点质量退化。**离散集中度 α₀ 是保守先验**：n_eff 小时后验自动向均匀/先验回缩，禁止用不可信权重驱动 VoI。

**定义 313（不确定性三分）** 将 R69 的 epistemic 细分为：
- U_ale = Σ_k w̄_k tr(Σ_k)：模态内不可约噪声（继承 R69）；
- U_int = H(M|o) − E_{y~p(·|g*,o)}[H(M|o,y)]：**一次有界信息动作**可削减的部分（即 R69 的最优 VoI，是「可问」的歧义）；
- U_data = H(W|o) + E[H(M|o,y)] − H(M|o,D_∞)：**只能由更多数据削减**的部分（权重后验不确定 + 模型支撑不足）。操作性上以 bootstrap 模态不稳定性为主估计（定义 314）。
在数据充分（A100：n_eff ≥ n₀ 且模态稳定）下 U_data≈0，且 U_int = U_epi^{R69}；故 R69 是本三分在「数据管道关闭」边界上的截面，而非被取代。

**定义 314（可约性分类器 RRC）** 用训练集 D 的 B 次 bootstrap 重采样重估策略/模态头，得到聚类序列 {C_b}；以最优传输匹配模态原型，定义稳定性
S = 1 − (1/B)Σ_b W₂(C_b, C₀)/Δ̄，以及模态出现频率 f_k = (1/B)Σ_b 1[k ∈ C_b]。
判据：
- f_k < p_min ⇒ **幻影模态**（训练噪声产物，不是 U_int，不得追问）；
- S 高且 Δ_min 大 ⇒ 模态是数据支撑的真实结构 ⇒ 歧义属于 **U_int**，可交 R69 的 MINT；
- S 低 ⇒ 模态结构随数据重采样漂移 ⇒ **U_data**，交互无效，转数据通道。
RRC 可用合成扰动数据训练成一个廉价判别器，输出 (U_int, U_data) 的份额 β_share。

**定义 315（数据价值 VoD）** 对候选 episode x，定义
VoD(x) = E_{D'=D∪{x}}[R(π_{D'})] − R(π_D) ≈ −∇_D R · φ(x)（影响函数）或覆盖增益。
批量选择用子模覆盖目标 V(B)=VoD(∪_{x∈B}{x})，在字节/能量/隐私预算下最大化。

**定义 316（数据获取环 DAL）** 数据动作 d ∈ 𝒜_data：保留并上传当前 episode、定向探索（进入高 U_data 状态）、向机队调取近邻经验、请求一次**标注**（与 MINT 的**即时回答**严格区分：回答解决 U_int，标注/样本解决 U_data）。DAL 受数据预算 B_d（带宽/能量/隐私 ε_dp）与「每单位时间至多一个数据决策」约束，且异步执行。

**定义 317（机队证据治理 FEG）** 设 m 个同伴与自体的误差等相关系数 ρ∈[0,1]，则
k_eff = m / (1 + (m−1)ρ)（等价 k_eff = [ρ + (1−ρ)/m]^{-1}）。
证据一致性判定以 k_eff 替代 m；当 ρ 高时同伴共识饱和于 1/ρ，不足以越过 R69 的证据纪律阈值。ρ 由历史同伴-自体残差相关性在线估计。

**定义 318（具身有效性过滤 EVF）** 跨具身调取的模态须满足形态可执行性与残差 r_emb ≤ τ_emb：ξ 在自体运动学/动力学约束下可执行，且迁移残差未超阈。不过滤的跨具身模态一律作废，U_data 不因此被「假装消解」。

**定义 319（数据投毒威胁 ℰ_data）** 受污染的 episode、后门触发样本、sybil 机器人刷出的伪共识、被放大的虚假相关、伪造 provenance。并入 AIC：ℰ_SCALE = ℰ_FLUID × ℰ_data。数据规模会放大攻击面：投毒样本只需污染低密度区即可系统性带偏该区域的 U_data 估计。

**定义 320（规模律外推器 SLX）** 在子采样规模 N/2^j 上测风险/似然，拟合局部幂律
U_data(N) ≈ A·N^{−β(o)}，平台残差 Â_∞ 作为 U_ale 的独立经验下界估计；β̂ 由 bootstrap 斜率给出置信区间。用途：判断「等数据」是否比「立即行动/提问」更划算。

**定义 321（预算分配律 ALLOC）** 设总预算 B 可分给三通道（保守/交互/数据），各自边际风险削减递减（子模）。分配规则为注水：令各通道边际收益/成本相等，
argmax_{b_ale+b_int+b_data ≤ B} ΔR_ale(b_ale)+ΔR_int(b_int)+ΔR_data(b_data)。
因三通道子模，贪心边际分配达 ≥ (1−1/e) 最优；关键系理：**把交互预算花在 U_data 上是被支配的（任何交互对 U_data 的边际收益≈0）**。

**定义 322（证书 J_SCALE）** J_SCALE = (J_FLUID, n_eff_p05, provenance_root, bootstrap_S, f_min, U_int, U_data, β̂, k_eff_peer, VoD_batch, data_poison_audit, scale_ver)。
Valid ⇔ Valid(J_FLUID) ∧ provenance 完整 ∧ RRC 置信 ∧ (若走交互则 k_eff·一致性达标) ∧ (若走数据则 data_poison_audit 通过)。

**定义 323（失败安全折叠）** 若数据通道不可用/被投毒/越预算，则 U_data 整体折入 U_int（当作「也许能问出来」，走 R69）；若交互仍无法消解或 RRC 判为幻影模态，则折入 U_ale（走 R68 的 λ_floor）。即 U_data → U_int → U_ale 的单调折叠，安全侧永不弱于 R68。

**定义 324（双时间尺度换装不变式）** 数据环产出候选模型 θ'，仅在控制边界（切换点）经 J_SCALE 认证后原子换装；换装前后安全包络、C-RAS-WM 前缀认证语义不变。快环内绝不出现学习写操作。认证失败则 θ 保持不变，候选回滚。

# IP-264 AUD†：不确定性三分（在 R69 decompose 之后）
def tri_decompose(samples, z, D, mode_head, bootstrap_models):
    U_ale, U_epi, modes, _ = r69_decompose(samples, z, mode_head)  # R69
    n_eff = kish_neff(z, D)                                       # 定义 311
    w_post = dirichlet_posterior(empirical_weights(modes), n_eff, alpha0)
    S, f_min = bootstrap_stability(bootstrap_models, modes, D)    # 定义 314
    if S < S_MIN or f_min < P_MIN:                                # 数据支撑不足/幻影
        U_data = entropy(w_post) + U_epi
        U_int  = 0.0
    else:                                                         # 真实歧义，可问
        U_data = entropy(w_post)
        U_int  = U_epi
    return U_ale, U_int, U_data, modes, n_eff, S

# IP-265 DSA：数据规模感知的模态校准门
def mode_calibration_gate(w_post, n_eff, tau_ece):
    ece = finite_sample_ece(w_post, n_eff)     # 含 n_eff 的置信区间修正
    return (ece <= tau_ece) and (n_eff >= N0)  # 不过则不启用 VoI 驱动交互

# IP-267 DAL：数据获取决策（慢环，异步）
def data_acquisition(o, U_data, budget, fleet):
    if U_data <= TAU_DATA: return None
    cands = [
        ('retain', o),                                   # 留存稀有 episode
        ('retrieve', fleet.nearest(z=Phi(o), k=K_RET)),  # 调取机队近邻经验
        ('explore', propose_info_goal(o)),               # 定向探索（也是信息动作）
        ('label', request_annotation(o)),                # 请求标注（≠ 即时回答）
    ]
    return argmax(c for c in cands
                  if budget.allow(c) and evf.ok(c) and provenance.ok(c),
                  key=lambda c: vod(c, U_data) - cost(c))     # 定义 315

# IP-269 FEG：机队同伴不是独立证人
def effective_sources(m, rho):
    return m / (1.0 + (m - 1.0) * rho)                    # 定义 317

def fleet_consensus(answers, rho):
    k_eff = effective_sources(len(answers), rho)
    return (majority(answers), k_eff) if k_eff >= K_ORTHO else (None, k_eff)

# IP-274 SCALE-RAS 主闭环（快环 = R69 + 三分路由；数据动作只入队）
def SCALE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)

    samples = M.fmp.sample(o, K)
    U_ale, U_int, U_data, modes, n_eff, S = M.aud.tri_decompose(
        samples, z, M.memory, M.fmp.mode_head, M.boot)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)

    # 1) 先分诊：可问 -> R69 交互；只能靠数据 -> 入队，不浪费交互
    g = None
    if M.dsa.gate(n_eff) and U_int > TAU_INT and not slow:
        g = M.mint.choose_interaction(modes, o, M.budget)     # R69
    if g is not None:
        ans, k_eff = M.feg.fleet_consensus(M.cia.execute(g), M.rho_hat)
        U_int = M.cia.update_belief(modes, ans) if ans is not None else U_int
    else:
        d = M.dal.decide(o, U_data, M.data_budget, M.fleet)    # 异步入队
        M.dal.enqueue(d)

    # 2) 失败安全折叠 + R69/R68 兜底
    U_floor = U_ale + U_int + (U_data if not M.dsa.gate(n_eff) else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_int + U_data, lam)             # 只执行已认证模态
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, (U_ale, U_int, U_data), n_eff, a_hat)
    return k, lam, mode, (U_ale, U_int, U_data)

## 3. 推导

**引理 19（bootstrap 可约性辨识）** 设真实模态的支撑样本数 n_k，幻影模态由有限样本涨落产生。若 n_k ≥ n₀ 且模态间可分的条件（A95）成立，则 f_k → 1（随 B、n_eff 增大）；若某模态仅由 O(1) 个样本支撑，则其 bootstrap 出现频率 f_k → 0，被 RRC 判为幻影。故在 p_min 取 1/(2B) 量级时，RRC 以高概率把「数据噪声模态」与「真实歧义模态」分开；被误判为 U_int 的幻影模态，其交互后残留不确定性仍回落到 U_data（定义 323），不会进入安全关键决策。

**引理 20（机队相关的证据饱和）** m 个等相关（ρ）同伴的均值方差为 σ²[ρ+(1−ρ)/m] = σ²/k_eff，故 k_eff = m/(1+(m−1)ρ)。系：k_eff ≤ min(m, 1/ρ)；ρ→1 时机队任意大也只等价一个证人。**机队规模不能替代正交证据**；若要用机队，必须显式吃下 1/ρ 的天花板，或引入真正异构的传感/仿真源以降低 ρ。

**引理 21（数据价值的子模与贪心界）** 若 VoD 取覆盖/影响函数型增益，则批量价值 V(B) 单调且子模；在基数预算下贪心选择满足 V(B_greedy) ≥ (1−1/e)·OPT。系：稀有 episode 的边际价值随已覆盖度递减，DAL 不应平均采集，而应优先低密度、高 U_data 区域。

**定理 18（SCALE 严格包含 FLUID-RAS / R68）** 当数据预算 b_data=0（或 U_data ≤ τ、DAL 被禁用）且机队不可用时，SCALE 的三分退化为 R69 的二分（U_data 折入 U_int、k_eff 退回 m=1），主闭环逐指令等于 FLUID-RAS；当再叠加 VoI≤成本/ECE 越界，逐指令等于 R68。故安全侧不弱化，效率侧只在「数据通道真的能降低风险」时获得额外收益。

**定理 19（双时间尺度无突变）** 数据环仅在控制边界换装，且换装经 J_SCALE（含 provenance 与 RRC 置信）认证；实时环内零学习写操作。由 R68 定理 15 的提交/换装不变式，换装前后 C-RAS-WM 前缀认证语义与控制连续保持；认证失败则回滚，λ 单调不降。故数据更新不引入控制突变，也不给实时预算带来抖动。

**定理 20（分诊避免交互浪费）** 在定义 321 的子模假设与三元分诊正确的前提下，贪心预算分配达到 ≥(1−1/e) 的最优风险削减；且任何分配给 U_data 的**交互**预算边际收益为 0（U_data 对单次交互的互信息不敏感，定义 313），故最优分配把交互预算集中于 U_int、把数据预算集中于 U_data、把保守预算留给 U_ale。R69 相当于强制 b_int 覆盖全部 epistemic，是本定理在「数据通道关闭」时的可行但次优解。

**系（学习曲线平台的底噪估计）** 由定义 320，U_data(N)=A N^{−β} 的平台 Â_∞ 是 U_ale 的独立经验下界；当 Â_∞ 与模型内 Σ_k trΣ_k 不一致时，取两者上界作为 λ_floor 输入，避免模型内方差低估真实噪声。

## 6. 本轮最大风险

**一句话**：SCALE-RAS 想用「数据规模」来校准自己，却只能用**同样有限的、同样有偏的**那批数据去估计「我到底有多缺数据（n_eff、bootstrap 稳定性、规模律 β）」——这是一个自指估计问题；一旦低密度区的样本本身带有系统性偏置，规模增长只会**把错误模态训练得更自信、把机队的相关盲点聚合成伪共识**，让系统在「数据很多」的错觉下更果断地做错——**规模买来的是共识，不一定是真相**。

**次级风险与缓解**：(1) RRC 的 bootstrap 只测抽样稳定性、不测分布偏置 → 引入异源/反事实扰动与 provenance 多样性审计；(2) 机队共谋/sybil → FEG 的 k_eff 折扣 + ℰ_data 对抗训练 + 签名与谱系；(3) 跨具身迁移不可执行 → EVF 硬过滤，绝不把「借来的模态」当已消解；(4) 慢环换装与快环耦合引发抖动 → 定义 324 原子换装 + 定理 19；(5) 隐私预算迫使粗粒度统计 → DP 下用区间而非点估计驱动门控。

## 4. 推导

**引理 19（bootstrap 可约性辨识）** 真实模态（支撑 ≥ n₀）在重采样下出现频率 `f_k→1`；仅由 O(1) 样本支撑的幻影模态 `f_k→0`，被 RRC 与 `p_min` 剔除；误判为 U_int 的幻影，其交互后残余仍回落到 U_data（定义 323），不进入安全决策。

**引理 20（机队相关证据饱和）** m 个等相关（ρ）同伴的均值方差 `σ²[ρ+(1−ρ)/m]`，故 `k_eff=m/(1+(m−1)ρ)≤min(m,1/ρ)`。系：ρ→1 时机队任意大也只等价一个证人；规模不能替代正交证据。

**引理 21（VoD 子模与贪心界）** 覆盖/影响函数型 VoD 单调子模，基数预算下贪心 `V≥(1−1/e)OPT`；稀有 episode 应优先低密度高 U_data 区。

**定理 18（严格包含 FLUID-RAS / R68）** 数据预算为 0（或 `U_data≤τ` 且机队不可用）时，三分为 R69 二分、`k_eff→1`，主闭环逐指令等于 FLUID-RAS；再叠加 VoI≤成本/ECE 越界即逐指令等于 R68。安全侧不弱化，效率侧仅在数据确实能降风险时获益。

**定理 19（双时间尺度无突变）** 数据环只在控制边界经 J_SCALE 原子换装，快环零学习写；由 R68 定理 15 的提交/换装不变式，控制连续与控制包络不变；认证失败回滚，λ 单调不降。

**定理 20（分诊避免交互浪费）** 三通道子模假设下贪心分配 ≥(1−1/e) 最优；U_data 对单次交互互信息不敏感 ⇒ 交互在 U_data 上边际收益为 0，故最优把交互集中于 U_int、数据集中于 U_data、保守留给 U_ale；R69 是「只开交互通道」的次优特例。

**系（平台底噪）** `U_data(N)=A N^{−β}` 的平台 `Â_∞` 是 U_ale 独立经验下界；与模型内 `ΣtrΣ` 取上界进 `λ_floor`，防止模型内方差低估真实噪声。

## 7. 本轮最大风险

**一句话**：SCALE-RAS 想用「数据规模」来校准自己，却只能用**同样有限、同样有偏**的数据去估计「我到底有多缺数据（n_eff、bootstrap 稳定性、规模律 β）」——这是自指估计；一旦低密度样本本身带系统性偏置，规模增长只会**把错误模态训练得更自信、把机队相关盲点聚合成伪共识**，让系统在「数据很多」的错觉下更果断地做错——**规模买来的是共识，不一定是真相**。

**次级风险与缓解**：RRC 只测抽样稳定性不测分布偏置（→ 异源/反事实扰动 + 多样性审计 CMD）；机队共谋/sybil（→ FEG 的 k_eff 折扣 + ℰ_data 对抗训练 + 签名谱系）；跨具身迁移不可执行（→ EVF 硬过滤，不假装消解）；慢环换装耦合快环抖动（→ 定义 324 原子换装 + 定理 19）；隐私预算迫使粗粒度（→ DP 区间估计驱动门控，而非点估计）。
