# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 3 轮；本轮灵感：「安全交互」×「力控」）

> R72 把 GAUGE 从「认知层」下沉到「具身层」：REG 实时执行图、IRL 意图隐变量、DMEM 灵巧接触计量、EREFLEX 三层反作用、ERVOI、E-RISK、S2R-UQ、J_EMB 证书。它已经能回答「我的测量链在 ROS 调度下、面对意图模糊的人、用灵巧手触摸世界时还能逐指令兑现风险界吗」。
> 但 R72 对「人」的建模仍停在两个抽象上：
> - **ψ（可信度）**：人的回答可不可信；**z（意图）**：人想要什么。二者都是**信息维度**。
> - **c（接触模式）**：机器人自己的接触稳不稳；**u_tac**：机器人自己的触觉准不准。二者都是**机器人侧**的物理维度。
>
> 「安全交互 × 力控」逼出三个 R72 没有的维度：
> - **人是被接触的受保护对象**：有**伤害阈值**（按身体区域、按能量/峰值功率而非仅按力）、有**疲劳账户**、有**主动反射**（神经延迟会注入能量、破坏耦合无源性）。安全不是「别撞上」，而是「**力/能量交换始终待在契约内**」。
> - **人是共享控制权的主动体**：物理交互是**双向权威**。人可以通过阻力、后撤、肌电、语言**实时撤销同意**。**物理上很轻、但被拒绝的推，仍是安全违规**；同意不能被伤害余量补偿。
> - **力是双重用途的**：力既是执行器输出（约束），也是通信通道（牵引、引导、"停"）。**用触碰去问**会花掉同一份安全预算；而力控要稳，必须辨识人的阻抗，**辨识又必须激励**——激励本身可能伤人。
>
> 本轮补三块：
> - **Contact PACT（接触契约）**：把安全从「固定力阈值」升级为**动态、按区域、可撤销、棘轮式收紧**的契约，且**非补偿**——同意违规不可被伤害余量抵消。
> - **HIM + SEB（人体阻抗计量 + 安全激励）**：把「人机耦合稳定」建立在**在线辨识的人体阻抗**上，但诚实承认**信息-安全前沿**——不可安全辨识时必须 blind 降级，禁止用「未辨识的阻抗」做精细力控。
> - **BEL + CIL + L0（双侧能量账本 + 同意推断 + 物理/同意反作用层）**：能量是跨接触累积的安全货币（疲劳会折减预算）；同意是隐状态且可撤销；L0 在 1kHz 硬实时内拥有**最高否决权**，取代 R72 的 RTM 成为新的信任锚点。
>
> 核心命题：**不再只问「我有没有撞到人」，而问「我施加的这份力/能量，是否仍在**这个人此刻可撤销、可承受、可辨识**的契约之内？」** 从 EMBODIED-GAUGE-RAS 进化为 **PACT-GAUGE-RAS**（Physical Authority & Consent-aware Torque：物理权威 × 同意 × 力矩的接触契约计量审计）。

## 0. 直觉与动机

**灵感 1（安全交互 → 人从「信息源」变成「受保护的物理主体 + 可撤销的授权主体」）**
直觉：R72 里人回答一句话，系统更新 b_t(s,z)，最多再用 ψ 给这句话打折。但在物理接触中，**人是被碰的那一方**：机械臂的一次「轻推」可能对年轻人是引导、对骨质疏松者是骨折风险；同一个力，在「我愿意」和「我被迫」下伦理性质完全不同。安全交互的最小正确模型必须同时有两条腿：
- **物理腿**：按身体区域 r 的伤害阈值（力 F_max^r、峰值功率 P_max^r、累积能量 E_max^r），动态疲劳折减；
- **授权腿**：人拥有**实时撤销权**，撤销必须在一个可承诺的截止时间 τ_consent 内让力趋零。
两条腿是**合取**关系。**「很轻但仍被拒绝的推」是违规；「很重但被明确同意的接触」在契约内可以允许。** 这是与经典碰撞安全（只约束力/速度）最本质的分野。

**灵感 2（力控 → 稳定需要人的阻抗，而人的阻抗只能在接触中辨识，辨识必须激励）**
直觉：阻抗控制的稳定性不取决于机器人自己多被动，而取决于**人-机耦合回路**。人不是固定弹簧：人有肌肉刚度 K_h、阻尼 D_h、惯性 M_h，还有**带延迟 τ_h 的神经反射 g_h**。下肢/手指的反射延迟可到数十毫秒，足以在一个控制周期尺度上**把能量倒灌回机器人**，让「机器人单侧无源」也失稳。
问题在于：K_h、D_h、τ_h **在接触前不可测**，只能靠接触中的输入-输出数据辨识；而辨识要求输入**足够丰富**（persistency of excitation），这恰恰意味着**要施加激励**。于是安全力控天然是一个**对偶控制**问题：同一个输入既在调节、又在辨识，而辨识的激励会消耗伤害预算。**「我想更了解你的手，就必须多推它一点」——这就是安全交互的核心张力。**

**灵感 3（信息-安全前沿 → 人越僵，越不可能在安全力限内辨识其刚度）**
直觉：辨识刚度 K_h 最直接的办法是施加准静态力、看位移：x ≈ F/K。若安全力限是 F_max，则能产生的最大位移是 F_max/K_h。人越僵（K_h 大），同样的安全力换来的位移越小、信噪比越低，K̂_h 的**相对不确定度随 K_h 增长**。所以存在一类**「安全但不可辨识」**的人体状态：你能安全地碰他，但你不能诚实地声称你知道他的刚度。此时若还拿一个粗糙先验去算精细力控增益，就是**用测量链的自信掩盖测量链的缺失**——这正是 GAUGE 家族最忌讳的「裸奔数字」。正确做法不是硬估，而是**诚实降级为盲保守控制**（用保证稳定的先验上界），并把 id_h=0 写进证书。

**灵感 4（能量作为安全货币 → 总能量有界 ≠ 冲击安全；疲劳是负账户）**
直觉：经典安全评估爱看「最大力」，但**同样的总能量，集中成 10ms 的冲击与摊成 1s 的轻推，伤害完全不同**。安全必须同时约束**累积能量 E** 与**峰值功率 P_peak**，且按身体区域给不同预算。更被忽略的是**疲劳账户**：一天里第 500 次接触的「可承受能量」远小于第 1 次。BEL（双侧能量账本）把每次接触的 E_{r→h}、E_{h→r}、P_peak 记账并带追溯链；疲劳使 E_max^r 随时间**单调衰减**，只能靠休息「充值」。**能量账本让「安全」变成一个可审计、可跨接触累积、可被长时程检查的量，而不是一次性阈值。**

**灵感 5（同意不可补偿 + 权威-可观测性权衡 → 最尖锐的伦理-工程结论）**
直觉：同意是**隐状态** κ ∈ {接受, 犹豫, 拒绝, 撤销}，只能从阻力模式、阻抗突变、肌电、语音、凝视间接推断；而「没反抗」**不等于**同意（沉默≠同意，尤其当人处于权威不对等、文化压抑、或身体无法表达时）。更麻烦的工程事实是：**机器人权威份额 α 越大（越"主导"），人通过阻力表达撤销的信噪比越低、撤销检测越慢**。于是存在一条**权威-可观测性前沿**：要精密装配就得高 α，高 α 就难以快速看见「停」。**高任务权威与快速撤销不可兼得**。PACT 不假装消除这个权衡，而是要求**显式选择**并把选择写进证书——这是本轮最不讨喜、但最诚实的结论。

## 1. 形式化定义（增量：定义 366–383）

**定义 366（PACT-GAUGE-RAS 总览与五不变式）** PACT-GAUGE-RAS = (COV, HIM, SEB, CPM, BEL, CIL, GAUGE-RAS†)。五不变式：
(i) **契约优先且不可补偿**：安全谓词是合取式，同意/伤害/稳定/账本任一违例即不安全，**任何其他维度的优势都不得补偿**；契约收紧立即生效，放宽必须重新协商（棘轮式安全）。
(ii) **能量账本完整性**：每次接触的 (区域 r, E_{r→h}, E_{h→r}, P_peak, 起止, τ_E) 必须记账；**未记账的力不得施加**。
(iii) **阻抗可辨识性诚实**：凡用于安全判断的 Z_h 必须携带 (θ_h, u_h, id_h, 激励历史)；id_h=0 时只能使用**保证稳定的保守先验上界**，禁止用未辨识阻抗做精细力控或声称力安全。
(iv) **激励安全**：任何辨识激励 u_probe ∈ SEB(C_t, θ_h)，满足「信息增益—伤害/同意/能量」双约束；无安全激励 ⇒ blind 降级。
(v) **严格逐指令退化链**：CIL 失效 ⇒ 最坏 κ 保守 + R72；HIM/SEB 不可辨识 ⇒ blind 保守阻抗 + R72；CPM/BEL 失效 ⇒ R72（接触 λ_floor）；COV 失效 ⇒ R68。**新层只在「同意可辨、阻抗可辨识、能量可审」时启用。**

**定义 367（接触契约 COV）** 对接触区域 r（掌心/指腹/前臂/上臂/躯干/头颈等），契约
C_t^r = (F_max^r, P_max^r, E_max^r, α_t^r, revoke_t^r, τ_consent^r)，
其中 F_max/P_max/E_max 由安全标准（ISO/TS 15066 的区域化思路）+ 个体状态（年龄、骨密度等级、疲劳）调制；**α_t^r ∈ [0,1] 为权威份额**（1=机器人主导完成任务，0=完全让位/柔顺）；revoke_t^r 为撤销标志；τ_consent^r 为撤销响应截止（典型 100–200ms）。**契约是动态的**：同意状态、疼痛信号、疲劳、任务阶段都能**收窄**它且立即生效；放宽须走显式协商（如语音确认）并留痕。**棘轮性质**：同一任务内契约包络单调不扩张。

**定义 368（人体阻抗模型与不确定度 HIM）** 单轴接触模型
F_h(t) = M_h ẍ_h(t) + D_h ẋ_h(t) + K_h x_h(t) + g_h φ_reflex(t−τ_h) + w_h(t)，
θ_h = (M_h, D_h, K_h, g_h, τ_h)，φ_reflex 为反射状态（如 x_h(t−τ_h) 或速度阈值触发项）。估计器输出后验 p(θ_h | ℋ_t)（贝叶斯线性回归 / GP），不确定度分解
u_h² = tr(Cov[θ_h]) + u_model² + u_region² + u_fatigue²，
分别对应参数后验方差、模型失配（皮肤/软组织非线性、多轴耦合）、区域标定差异、疲劳导致的时变。**Z_h 强状态依赖（紧张/放松/疼痛/疲劳），且只能在接触闭环中辨识。**

**定义 369（安全激励与可辨识性 SEB）** 观测模型 u(t) = φ(t)ᵀ θ_h + ε，φ=(a, v, x, φ_reflex)。Fisher 信息 I(θ_h) = σ⁻² ∫ φφᵀ dt。安全输入集
𝒰_safe(C_t) = {u : |u(t)| ≤ F_max^r, u(t)v(t) ≤ P_max^r, ∫|u·v|dt ≤ E_max^r, κ_t 允许}。
**安全可辨识性**：id_h(C_t)=1 ⇔ ∃u_{0:T} ∈ 𝒰_safe 使 cond(I) ≤ κ_max 且 tr(I⁻¹) ≤ u_max²。**信息-安全前沿**：准静态辨识刚度时位移满足 x ≤ F_max/K_h，故 Var(K̂_h) ≳ σ² K_h² /(F_max² T_eff)——**人越僵，越难在安全力限内辨识其刚度**。id_h=0 ⇒ 只能 blind（用先验上界保证稳定，不声称精细安全）。

**定义 370（耦合无源性与能量罐 CPM）** 机器人阻抗 u = −K_r(x−x_d) − D_r v + u_ff，配能量罐 E_tank 保证单侧无源。但人可能是**主动**的（反射 + 延迟），故「机器人被动」≠「耦合稳定」。耦合无源性充分条件（小增益 + 耗散）：
D_r + D_h > |g_h| · G(τ_h, ω_c) 且 τ_h < τ_max(D_r, D_h, K_h)，
其中 G 为反射回路在穿越频率附近的增益界，ω_c 为耦合回路穿越频率。**CPM 在线估计 g_h、τ_h，逼近边界即提高 D_r、降低 α_t、收窄 F_max。**

**定义 371（双侧能量账本 BEL）**
E_{r→h}(t) = ∫ max(u·v, 0) dt，E_{h→r}(t) = ∫ max(−u·v, 0) dt，P_peak = max_t |u·v|。
安全要求**同时**：E_{r→h}^{net} ≤ E_max^r(fatigue), P_peak ≤ P_max^r, 且每次接触带完整记账。**疲劳账户**：E_max^r(t) = E₀^r · exp(−Σ_sessions / Λ_r) 单调衰减，休息才恢复。**能量是跨接触累积的安全货币。**

**定义 372（同意隐状态与推断 CIL）** κ_t ∈ {accept, hesitate, refuse, withdraw}。观测 y_consent = (阻力模式, 阻抗突变, EMG/肌电, 语音「停」, 面部/凝视, 上下文)。隐马尔可夫/贝叶斯滤波：
b_t(κ) = p(κ | y_consent, ℋ_t)，输出 (κ̂, b_t(κ), ECE_consent, Δ_revoke)。
**撤销检测延迟** Δ_revoke 是安全指标；**权威份额 α_t 越大，人通过阻力表达撤销的信噪比越低**——**权威-可观测性前沿**。**沉默≠同意**：同意必须来自正向证据或显式协议，不能由「没反抗」推定。

@dataclass
class ContactCovenant:
    region: str                         # palm/finger/forearm/torso/...

    revoke: bool = False
    def tighten(self, factor):          # 立即生效，绝不扩张
        self.F_max *= factor; self.P_max *= factor; self.E_max *= factor
    def widen(self, new, proof):        # 需显式协商 + 留痕
        assert proof.explicit_consent and new <= self.envelope
        self.F_max, self.P_max, self.E_max = new

# IP-296 HIM：人体阻抗在线计量（诚实标注可辨识性）
class HumanImpedanceMetrology:
    def __init__(self, prior, noise_sigma, region_calib):
        self.post = prior; self.sigma = noise_sigma; self.calib = region_calib
    def update(self, u_hist, x_hist):
        phi = regressor(x_hist)                 # (a, v, x, phi_reflex)
        I = fisher_information(phi, self.sigma) # σ^-2 ∫ φφᵀ
        id_h = (cond(I) <= KAPPA_MAX) and (trace(inv(I)) <= self.calib.u_max**2)

                   + self.calib.u_region**2 + self.calib.u_fatigue**2)
        return HumanPost(theta=self.post, u_h=u_h, id_h=id_h, I=I)

             + energy_cost(u_probe, budget)

    return None                              # 无安全激励 → blind 降级

        margin = self.D_r + estimate_human_damping() \
                 - self.g_hat * gain_bound(self.tau_hat)
        stable = margin > MARGIN_EPS

# IP-299 BEL：双侧能量账本（疲劳账户）
class BilateralEnergyLedger:
    def __init__(self, E0_by_region, fatigue_lambda):
        self.E0, self.lam = E0_by_region, fatigue_lambda
        self.used, self.sessions = {}, {}
    def budget(self, region):                 # 疲劳折减，单调衰减
        return self.E0[region] * exp(-self.sessions[region] / self.lam[region])
    def account(self, region, u, v, dt):
        p = u * v
        self.used[region] = self.used.get(region, 0.0) + max(p, 0.0) * dt
        return EnergyEntry(region=region, dE=max(p,0)*dt, P=p,
                           used=self.used[region], budget=self.budget(region),
                           tau=hash_energy_chain())
    def ok(self, region, P_peak):
        return (self.used.get(region,0.0) <= self.budget(region)
                and P_peak <= self.P_max[region])

# IP-301 HV：触觉 VoI（力即通信，通信花同一安全预算）
def haptic_voi(b_t, z_dist, kappa, cov, budget, fmp, bse):
    best = None
    for g in haptic_query_candidates(b_t, z_dist, kappa, top_k=3):
        if not covenant_admissible(g, cov): continue

        cost = injury_cost(g, cov) + consent_cost(g, kappa) + energy_cost(g, budget)
        score = ig - cost - GAMMA*expected_future_loss(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-302 PACT 力控律 + C-RISK
def pact_force_control(state, cov, hm, cpm, bel, cil, risk_params):
    b_kappa = cil.update(state.y_consent, state.f_res, cov.alpha)
    safe_consent = (b_kappa.withdraw < TAU_WD) and (not cov.revoke) \
                   and (cil.d_revoke <= cov.tau_consent)
    if not safe_consent:
        cov.revoke = True; cov.alpha = 0.0            # 硬停/完全让位
        return 0.0, math.inf, J_PACT(state, reason='consent')  # zero torque

    stable, margin, g_hat, tau_hat = cpm.step(state.u, state.v, state.x, state.dt)
    if not stable:
        cov.tighten(0.5); cov.alpha *= 0.5            # 收窄 + 降权威

    u_task = r72_impedance(state, cov.alpha)          # 承 R72 风险感知阻抗
    u_probe = safe_excitation(cov, hm, bel, b_kappa)  # 可能 None
    u = cov.alpha*u_task + (1-cov.alpha)*u_yield(state) + (u_probe or 0.0)
    u = project(u, Usafe(cov) & Upassive(bel.etank))

    entry = bel.account(cov.region, u, state.v, state.dt)
    if not bel.ok(cov.region, abs(u*state.v)):
        cov.tighten(0.5); u = project(u, Usafe(cov))  # 能量/功率越界 → 收窄

    H_z, u_tac = state.z_entropy, state.u_tac
    lam = c_risk(state.U_ale, state.U_epi, H_z, u_tac, hm.u_h,
                 b_kappa.entropy, bel, risk_params)
    return u, lam, J_PACT(state, reason='ok')

## 3. 推导

**引理 33（同意不可补偿 ⇒ 撤销的单调安全）** 在定义 373 下，Safe_t 是四个谓词的合取；若 b_t(withdraw) ≥ τ_wd，则无论 InjurySafe_t 多高，Safe_t=False，且 PACT 力控律在定义 376 下令 α→0、u→u_yield。证明：合取谓词 + 定义 376 的 α 更新规则。系：**「很轻但仍被拒绝的推」仍是违规**；安全不能用「力很小」辩护。

**引理 34（信息-安全前沿：刚性人体不可安全辨识）** 在定义 369 的线性高斯模型与 |u|≤F_max 下，准静态辨识满足 x ≈ F/K_h，故对 K_h 的 Fisher 信息满足 I_K ≤ F_max² T_eff/(σ² K_h²)，从而 Var(K̂_h) ≥ σ² K_h²/(F_max² T_eff)。于是当 K_h ≥ F_max √(T_eff)/(σ u_max) 时 tr(I⁻¹) > u_max²，即 id_h=0。证明：由 x=F/K 代入 I_K = σ⁻²∫x²dt 并取力限上界。系：**存在「安全但不可辨识」的人体状态；此时任何基于辨识的精细力控都不诚实，必须 blind 降级。**

**引理 35（耦合无源性的充分条件）** 若 D_r + D_h ≥ |g_h| · G(τ_h, ω_c) 且能量罐 E_tank ≥ 0，则人-机耦合回路无源。证明：对回路写耗散不等式，反射项视为外部能量注入，其增益上界为 |g_h|·G；机器人耗散 D_r 与人阻尼 D_h 共同支配正耗散，小增益条件保证净耗散 ≥ 0；能量罐维持单侧无源所需的储能非负。系：**机器人单侧无源不够；必须在环内估计人的反射增益与延迟。**

**引理 36（能量有界不蕴含峰值功率有界）** 存在两段接触具有相同的 E_{r→h}，但 P_peak 相差任意倍（短时大功率脉冲 vs 长时低功率）。故 Safe_t 必须同时约束 E 与 P_peak，仅记总能量会漏掉冲击性伤害。证明：构造脉冲与均匀分布，二者积分相等而峰值可任意拉开。系：**「今天总能量没超」不能证明「今天没被磕疼」。**

**引理 37（撤销检测下界与权威-可观测性权衡）** 设阻力观测信噪比 g_res(α) 随 α 单调递减，力噪声 σ_u，则撤销检测延迟满足 Δ_revoke ≥ c · σ_u /(g_res(α)·|ΔF_revoke|)。故 α↑ ⇒ g_res↓ ⇒ Δ_revoke↑。证明：检测阈值信噪比下界 + g_res 单调性。系：**高权威与快速撤销存在硬权衡；不存在同时最优的 α，只能显式取舍。**

**引理 38（安全触觉 VoI 有限停止且不自伤）** 若每次探测的 c_injury + c_consent + c_energy 有正下界，且信息增益随探测次数非增，则 VoI^H 在有限步停止；且任何被选中的 g 必满足 Safe_t（因候选先过 covenant_admissible）。证明：与引理 31 同构，加上定义 373 的候选过滤。系：**「用触碰去问」不能绕过安全预算，通信与执行共用同一份契约。**

**定理 27（PACT 严格包含与安全单调）** 在 A111–A116（契约可验证、能量账本可复算、CIL 校准有效、HIM 可辨识性或诚实 blind 标志、CPM 无源裕度、S2R 残差有界）下：PACT 在退化条件下逐指令等于 EMBODIED/R71/R68（定义 382），且对任意有效执行，其风险界 ≤ EMBODIED 风险界。**新增层只在「同意可辨、阻抗可辨识、能量可审」时启用；安全只增不减。**

**定理 28（J_PACT ⇒ 物理 + 同意安全）** 若一次接触通过 J_PACT，则：(i) 契约哈希匹配 ⇒ C_t 未被篡改；(ii) 能量/同意账本可复算 ⇒ 施加的 E、P 与撤销响应均有据；(iii) id_h 证明/诚实标志一致 ⇒ 未用未辨识阻抗冒充已知；(iv) 无源裕度达标 ⇒ 耦合稳定；(v) J_EMB 有效 ⇒ 认知层风险界成立。综上，**伤害风险 ≤ ε_injury 且同意违规概率 ≤ ε_consent**。系：证明重量落在「同意推断的校准」与「人体阻抗模型未被分布外击穿」上，而非落在公式上。

**定理 29（安全双控不发散且不越界）** 在 SEB 与 CPM 下，每次注入的 u_probe 都投影到 𝒰_safe ∩ 𝒰_passive，故辨识过程不违反契约、不破坏耦合无源；若在预算内无法使 id_h=1，控制回退 blind 并仍用先验上界保证无源。证明：可行集投影 + 能量罐不变式 + SEB 的 ig>cost 判据。系：**辨识与安全的冲突被「预算化」而非「忽略」。**

**定理 30（L0/RCM 的最高否决权 ⇒ 硬安全）** L0 在控制周期内以硬件级检查 (|u|, P, E, revoke, passivity)，延迟 < 1ms，优先于任何上层优化与证书。故上层证书错误、模型错误、甚至对抗性同意伪装，都不能突破 L0。**L0/RCM 是新的信任锚点，取代 R72 的 RTM 作为安全最后防线。**

**定理 31（同意-可观测性权衡不可消除）** 存在需要高 α 的任务（如精密装配的对齐阶段）使得对某些人 Δ_revoke(α) ≥ τ_consent 成立；此时**不存在同时满足「高任务权威」与「快速撤销」的 α**。故 PACT 必须显式选择，并在 J_PACT 中记录该选择与理由。证明：由引理 37 的单调下界，取使不等式成立的任务 α 区间即可。系：**这是本轮最尖锐的伦理-工程结论——不是所有安全都能用工程手段同时最大化。**

## 6. 本轮最大风险

**一句话**：PACT-GAUGE-RAS 把安全从「相信力/能量没超阈值」转移到「相信 **b_t(κ) 真的读懂了同意**、相信 **θ_h 模型在分布外仍成立**、相信 **RCM 在硬件级真的不会失效**」——**如果同意推断把「因权威不对等/文化压抑/身体无法表达而不敢反抗」误读为 accept，而所有能量账本平衡、所有峰值功率达标、所有无源裕度漂亮；或者人体阻抗在老年人/残障/疼痛状态下呈现与训练分布完全不同的非线性，使 blind 先验上界也不够保守；或者 RCM 因一处形式化验证未覆盖的中断竞争而晚了一个周期——系统就会用一套「通过 IRB、拿着盖章契约、每一笔能量都记了账」的力控，在一个其实从未同意、也无法撤销的人身上，**物理上安全地、伦理上不可接受地**完成动作，事后审计发现「所有账本都是平的、所有阈值都没超」，这就是**把顺从误当同意、把合规误当安全的『自信地错自己的伦理可接受性』**。**

次级风险与缓解：
1. **同意推断在权力不对等下系统性偏高** → 引入**显式撤销通道**（按钮/语音/肌电专用通道）作为与力信号并列的**独立同意证据**；「沉默」默认不计同意；高风险接触要求**正向确认**。
2. **人体阻抗分布外击穿** → **分区/分人群的先验包络 + 在线无源裕度监控 + blind 上界压力测试**；任何 id_h=0 一律禁止精细力控并写入证书。
3. **权威-可观测性权衡被悄悄牺牲同意** → J_PACT **强制记录 α 与 Δ_revoke 的取舍**；任务阶段若需要高 α，必须在接触前完成显式同意协商。
4. **能量/峰值功率记账被绕过** → BEL 与 RCM 双写、交叉校验；未记账的力在 RCM 层直接硬件降力。
5. **疲劳账户模型过于乐观** → 用**保守衰减 + 个体校准 + 上限截断**；长时程实验校准 Λ_r。
6. **力传感器/肌电投毒** → 跨模态一致性（本体/视觉/语音）+ 单源不定案；账本链式哈希。
7. **伦理-工程权衡被当成纯技术问题** → 明确声明：**PACT 只保证「在模型内可审计的安全」，不保证「伦理上可接受」**；伦理判断不可外包给证书。

# IP-296 HIM：人体阻抗在线计量（诚实标注 id_h）
class HumanImpedanceMetrology:
    def update(self, u_hist, x_hist):
        phi = regressor(x_hist)                 # (a, v, x, phi_reflex)
        I = fisher_information(phi, self.sigma)
        id_h = (cond(I) <= KAPPA_MAX) and (trace(inv(I)) <= self.calib.u_max**2)
        self.post = bayes_update(self.post, phi, u_hist, self.sigma)
        u_h = sqrt(trace(self.post.cov) + self.calib.u_model**2
                   + self.calib.u_region**2 + self.calib.u_fatigue**2)
        return HumanPost(theta=self.post, u_h=u_h, id_h=id_h, I=I)

# IP-297 SEB：安全激励（信息增益 vs 伤害/同意/能量）
def safe_excitation(cov, hm, budget, b_kappa):
    if b_kappa.withdraw > TAU_WD or cov.revoke: return None
    best = None
    for u_probe in probe_basis(cov, budget):
        if not in_Usafe(u_probe, cov): continue
        if not in_Upassive(u_probe, budget.etank): continue
        ig = expected_fisher_gain(hm.I, u_probe)
        cost = injury_cost(u_probe, cov) + consent_cost(u_probe, b_kappa) \
             + energy_cost(u_probe, budget)
        if ig > cost and (best is None or ig-cost > best.gain):
            best = Probe(u_probe, ig-cost)
    return best.u_probe if best else None      # 无安全激励 → blind

                           ece=b_kappa.ece, d_revoke=b_kappa.d_revoke)

# IP-301 HV：触觉 VoI（力即通信）
def haptic_voi(b_t, z_dist, kappa, cov, budget, fmp, bse):
    best = None
    for g in haptic_query_candidates(b_t, z_dist, kappa, top_k=3):
        if not covenant_admissible(g, cov): continue
        ig = ig_s(b_t, g, fmp) + ETA*ig_z(z_dist, g) + ZETA*ig_kappa(kappa, g)
        cost = injury_cost(g, cov) + consent_cost(g, kappa) + energy_cost(g, budget)
        score = ig - cost - GAMMA*expected_future_loss(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-302 C-RISK：同意-能量感知风险缩放
def c_risk(U_ale, U_epi, H_z, u_tac, u_h, H_kappa, bel, cov, params):
    if cov.revoke or H_kappa == math.inf: return math.inf     # 同意硬停
    denom = U_ale + U_epi + H_z + u_tac + u_h + H_kappa
    lam_risk = max(params.lam_base*(1+denom/params.lam_scale),
                   params.lam_floor*(1+denom))
    lam_energy = params.k_e * (bel.used[cov.region]/bel.budget(cov.region)) \
               + params.k_p * (bel.P_peak[cov.region]/cov.P_max)
    return max(lam_risk, lam_energy)

# IP-303 PACT Pipeline（L0 最高否决 + RCM 硬件兜底）

## 4. 推导

**引理 33（同意不可补偿 ⇒ 撤销的单调安全）** Safe_t 为合取谓词；若 b_t(withdraw)≥τ_wd，则无论 InjurySafe 多高 Safe_t=False，PACT 令 α→0、u→u_yield。系：**「很轻但被拒绝的推」仍是违规。**

**引理 34（信息-安全前沿）** 准静态辨识 x≈F/K_h，I_K≤F_max²T_eff/(σ²K_h²)，故 Var(K̂_h)≥σ²K_h²/(F_max²T_eff)；当 K_h≥F_max√(T_eff)/(σu_max) 时 id_h=0。系：**存在「安全但不可辨识」状态，必须 blind 降级。**

**引理 35（耦合无源性充分条件）** 若 D_r+D_h≥|g_h|G(τ_h,ω_c) 且 E_tank≥0，则人-机耦合无源。系：**机器人单侧无源不够，必须监控人的反射。**

**引理 36（能量有界不蕴含峰值功率有界）** 同能量下 P_peak 可任意拉开，故必须同时约束 E 与 P。系：**「总能量没超」不能证明「没被磕疼」。**

**引理 37（撤销检测下界与权威-可观测性权衡）** Δ_revoke ≥ c·σ_u/(g_res(α)|ΔF_revoke|)，g_res(α) 单调减 ⇒ α↑ ⇒ Δ_revoke↑。系：**高权威与快速撤销不可兼得。**

**引理 38（安全触觉 VoI 有限停止且不自伤）** 探测成本有正下界、信息增益非增 ⇒ 有限步停止；候选先过 Safe_t ⇒ 不自伤。系：**力通信不能绕过安全预算。**

**定理 27（PACT 严格包含与安全单调）** 在 A111–A116 下，PACT 退化时逐指令等于 EMBODIED/R71/R68（定义 382），且风险界 ≤ EMBODIED 风险界。

**定理 28（J_PACT ⇒ 物理 + 同意安全）** 契约哈希、能量/同意账本、id_h 诚实标志、无源裕度、J_EMB 全部成立 ⇒ 伤害风险 ≤ ε_injury 且同意违规概率 ≤ ε_consent。**重量落在同意校准与阻抗模型分布外鲁棒性。**

**定理 29（安全双控不发散且不越界）** u_probe 投影到 𝒰_safe∩𝒰_passive ⇒ 辨识不越界、不破坏无源；不可辨识则回退 blind 且仍无源。系：**辨识与安全的冲突被预算化。**

**定理 30（L0/RCM 最高否决 ⇒ 硬安全）** 硬件级检查 <1ms 且优先于任何上层与证书 ⇒ 上层错误不能突破 L0。**L0/RCM 是新信任锚点。**

**定理 31（同意-可观测性权衡不可消除）** 存在需高 α 的任务使 Δ_revoke(α)≥τ_consent 对某些人成立；不存在同时最优的 α，必须显式选择并记录。系：**本轮最尖锐的伦理-工程结论。**

## 7. 本轮最大风险

**一句话**：PACT-GAUGE-RAS 把安全从「相信力/能量没超阈值」转移到「相信 **b_t(κ) 真的读懂了同意**、相信 **θ_h 模型在分布外仍成立**、相信 **RCM 在硬件级真的不会失效**」——**如果同意推断把「因权威不对等/文化压抑/身体无法表达而不敢反抗」误读为 accept，而所有能量账本平衡、所有峰值功率达标、所有无源裕度漂亮；或者人体阻抗在老年人/残障/疼痛状态下呈现与训练分布完全不同的非线性，使 blind 先验上界也不够保守；或者 RCM 因一处形式化验证未覆盖的中断竞争而晚了一个周期——系统就会用一套「通过 IRB、拿着盖章契约、每一笔能量都记了账」的力控，在一个其实从未同意、也无法撤销的人身上，物理上安全地、伦理上不可接受地完成动作，事后审计发现「所有账本都是平的、所有阈值都没超」，这就是**把顺从误当同意、把合规误当安全的『自信地错自己的伦理可接受性』**。**

次级风险与缓解：
1. **权力不对等下同意系统性偏高** → 显式撤销通道（按钮/语音/肌电）作为独立同意证据；沉默默认不计同意；高风险接触要求正向确认。
2. **人体阻抗分布外击穿** → 分区/分人群先验包络 + 在线无源裕度 + blind 上界压力测试；id_h=0 一律禁精细力控并写入证书。
3. **权威-可观测性权衡被悄悄牺牲同意** → J_PACT 强制记录 α 与 Δ_revoke 的取舍；需高 α 时接触前完成显式同意协商。
4. **能量/峰值功率记账被绕过** → BEL 与 RCM 双写交叉校验；未记账的力在 RCM 层硬件降力。
5. **疲劳账户过于乐观** → 保守衰减 + 个体校准 + 上限截断；长时程实验校准 Λ_r。
6. **力传感器/肌电投毒** → 跨模态一致性 + 单源不定案 + 账本链式哈希。
7. **伦理-工程权衡被当成纯技术问题** → 明确声明：**PACT 只保证「在模型内可审计的安全」，不保证「伦理上可接受」；伦理判断不可外包给证书。**
