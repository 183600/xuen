# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 2 轮；本轮灵感：「视觉定位」×「迁移学习」）

> R73 把证据计量做成了可组合的契约：EC 声明预算/通道/有效域/否决，CCA 用 SER/PAR/VETO 组合，热替换定理把「换实现不改系统」从实验希望升为定理，CPB 把体系蒸馏为三条可证伪主张。R73 末尾追加的 ECG（证据因果图）与 MIC（形态无关契约）又补了因果与形态两维。但整套代数仍压在三个**未言明的假设**上，本轮两个灵感恰好把这三个假设逐一击穿：
> - **空间齐性假设**：EC 的有效域 D 是传感器状态域（距离、材质、互扰、接触模式），却默认校准在**整个工作空间**同质。视觉定位的证据质量本质上**由地点索引**：同一模型在已建图区域覆盖率可达 0.95，在未建图走廊、外观变化、重复纹理处可能只有 0.3。全局 conformal 的 (1−α) 是**对查询分布的平均**，不是**逐地点**的保证。R73 没有「在哪里可信」这一维度。
> - **迁移中性假设**：热替换定理要求同一 EC。迁移学习（域适应、微调、测试时自适应 TTA、持续学习）恰恰是**以不同实现获得同一 API** 的标准手段；它改变似然却不改签名。R73 的证书会被「同契约、异世界」的实现**洗白**：模块证书有效，目标域覆盖率却已崩。更危险的是，在线自适应让**证书所描述的模型本身在运行时变化**。
> - **地图无记忆假设**：R73 的外部锚点（自标定用本体/接触/已知几何）默认世界模型稳定。但视觉定位的参考是**地图**——一个由过去观测累积、会漂移、会过期的证据产物。用地图验证定位、再用定位更新地图，是**自举闭环**；地图+定位系统存在全局规范自由（gauge freedom），闭环内任何一致性审计都无法发现整体漂移。
>
> 本轮两个灵感正好把这三个假设变成研究对象：
> - **视觉定位** → **LOCEM（LOCalization Evidence Metrology）**：六分量定位不确定度（地图/别名/外观/视角/动态/学习）+ 地点条件 conformal + 多假设位姿信念；把「位置」变成证据的**索引**。
> - **迁移学习** → **TCT（Transfer Certificate Theory）**：校准传输代数、TV 传输不等式、三级迁移证据（T0 无标签筛查 / T1 小样本目标校准 / T2 全量重认证）、**负迁移否决 NTV**；把「迁移」从隐式实现细节升为**显式证书对象**。
> - **共同产物** → **ECM（Evidence Coverage Map）/ 认证操作包络**：系统证书不再是一个布尔值，而是**工作空间上的一个区域**；机器人能说出「我在哪里被认证、在哪里必须降级/求助」。
>
> 核心命题：**证据的可信度不是模块的属性，而是（地点，参考系，锚点，迁移证书，模型版本）的函数。** 提出 **TRANS-GAUGE-RAS**（TRansportable ANchored Spatial GAUGE）——空间化、可迁移、带锚点的证据计量学。

## 0. 直觉与动机

**灵感 1（视觉定位 → 位置是证据的索引，不是坐标）**
直觉：视觉定位的误差不是各向同性的平稳噪声，而是**地点条件**的。已建图、纹理丰富、光照稳定的房间，位姿误差小且校准良好；长走廊、玻璃幕墙、重复门牌、夜间/逆光、人群遮挡处，误差大、多峰、甚至完全错误。全局 conformal 只保证「对查询分布平均覆盖 1−α」，完全可以由 90% 的简单地点 + 10% 的灾难地点混合而成；而那 10% 正是安全关键区域。于是「平均可信」在空间上可以掩盖「局部不可信」。严格的修法是 **Mondrian/地点条件 conformal**：按地点分组校准、逐组给出覆盖率下界。但代价是样本复杂度：K 个地点组、每组要 ε 精度，需要 Ω(K/ε²) 量级的校准样本；没有样本的地点只能**弃权**。这不是缺陷，而是诚实的计量学：**证书是一张有洞的地图**。同时，感知别名会让位姿后验多峰，单个高斯协方差是对现实的谎言；必须用**多假设信念 + 显式 unknown 质量**表示，而不是把「两个都可能」压成一个大的 σ。

**灵感 2（迁移学习 → 校准不会免费迁移）**
直觉：迁移学习论文通常报告目标域**准确率**；但安全需要目标域**校准覆盖率**。两者可以背离：微调后 top-1 准确率上升，模型却变得更自信，conformal 集不再覆盖。Conformal 的覆盖保证依赖可交换性；在协变量偏移下，覆盖只能按总变差距离传输：`Cov_T ≥ Cov_S − d_TV(P_S,P_T)`。更根本的是**无标签不可识别性**：只给源域标签和目标域无标签观测，存在两个目标域联合分布，它们的观测边缘完全相同、但校准覆盖率相差任意大，任何只依赖这些数据的迁移方法都无法区分。因此**无标签 TTA 只能筛查，不能认证**；认证必须有目标域标签（哪怕很少）。这把迁移分成三级：T0 无标签筛查、T1 小样本目标校准、T2 全量重认证。负迁移也不是「比源域差」这么简单：正确对照是**回退锚点**（源模型 / 全局重定位 / 安全停止）。NTV 是非补偿的否决，不是把不确定度调大。

**灵感 3（地图作为证据产物 → 规范自由与自举）**
直觉：地图不是从天而降的坐标系，而是**被压缩的证据**：关键帧、路标、回环、外参、时间戳。地图和定位估计共享一个全局刚体变换的**规范自由**：把地图和所有估计位姿同时施加同一个 G，所有残差、回环误差、局部协方差完全不变。因此，任何只依赖「地图 + 定位 + 回环」的内部一致性审计，都**无法发现整体漂移**。这就是为什么「用地图验证定位」和「用定位更新地图」会形成自欺闭环。绝对位姿必须由**外部锚点**固定规范：已知基准、GNSS/UWB、已知起始位、重力方向、已知地面高度、人工确认。地图也有**寿命**：环境在变，地图在旧；没有新观测的区域，漂移下界随时间单调增长。地图必须携带来源契约（provenance），否则不可入图。

**灵感 4（空间组合 → 证书是一个区域，一个偏序，而不是一个布尔值）**
直觉：如果模块 A 只在区域 S_A 被认证、模块 B 只在 S_B 被认证，串联只能在 S_A ∩ S_B 上被认证；并联只有在**锚点独立**时才能把覆盖扩到 S_A ∪ S_B，共享同一张地图的两个模块「一致」只是共享了同一个错误。否决会从区域中挖洞。迁移可以把认证区域搬到新地点，但必须支付传输证书的代价。于是系统证书自然是一个**认证操作包络**（ECM）：工作空间上每一点标注「已认证 / 降级 / 禁止」及风险上界。机器人因此可以做出 R73 做不到的决定：**主动留在已认证区域，或主动去采集校准样本以扩张证书**（ACP）。组合不能凭空制造信任；信任在 SER 下单调不增，只能被迁移**搬移**或被独立锚点**扩展**。

## 1. 形式化定义（增量：定义 383–401）

**定义 383（TRANS-GAUGE-RAS 总览）** TRANS-GAUGE-RAS = (LEC, LOCEM, MPC, TCT, NTV, RLC, TCA, AQ, ACP, ECM, MODGAUGE-RAS†)。六不变式：
(i) **空间完整性**：每个模块声明支持区域 S 与参考系 frame，缺一不可入图；
(ii) **参考系相对性**：每个证书声明锚点集 anchor 与规范固定方式，绝对位姿主张必须指明外部锚点；
(iii) **传输可审计**：每个跨域实例化携带传输证书 J_T，或显式标注为 T0 条件证据（不可用于证书）；
(iv) **覆盖单调性**：串联/否决不能扩张认证区域；并联只有在锚点独立且一致性审计通过时才允许并集；迁移不能扩张到未校准区域；
(v) **自适应隔离**：运行时模型更新必须在影子模型中隔离，只有通过目标校准审计并原子提交的版本才能影响安全输出；
(vi) **严格退化**：当 S=全域、anchor=已知、T=恒等、模型冻结时，TRANS-GAUGE 逐指令退化为 MODGAUGE，再退化为 R72/R71/R68，安全侧只增不减。

**定义 384（LEC 局部化证据契约）** LEC = EC ⊕ (S, frame, anchor, T_cal, h_τ, model_hash, edge_inv)：
- S ⊆ 𝒲：支持区域（地图瓦片/地点流形/视角流形上的显式子集）；
- frame ∈ {世界系, 地图系, 任务系, 锚点系}：证据的参考系；
- anchor：规范固定锚点集（哪些外部约束固定全局位姿）；
- T_cal：校准传输记录（源校准集 id、目标适应集 id、TV 上界、迁移等级 T0/T1/T2、有效期）；
- h_τ：时间半衰期与漂移率上界 ρ_map；
- model_hash：实现+权重+适应状态的哈希（证书绑定到**具体模型版本**，而非 API）；
- edge_inv：ECG 中声明为**迁移不变**的因果边集合（其余边必须在目标域重审）。
直觉：EC 回答「我消耗什么、产生什么、噪声怎样」，LEC 追加回答「**在哪里、相对谁、由什么锚定、怎样迁移、哪一版、有效多久**」。

**定义 385（LOCEM 定位证据与多假设位姿信念）** 观测 y_loc=(图像序列, IMU, 可选深度)，地图 m；证据不是单峰高斯，而是
B = {(x_k, w_k, Σ_k)}_{k=1..K} ∪ {(∅, w_∅)},  Σ_k w_k + w_∅ = 1,
其中 x_k ∈ SE(3)，∅ 表示「无假设/被绑架」。有效条件：top-set 质量 ≥ 1−α、所有假设落在同一 frame、S 内、anchor 一致。别名场景下 top-1 可以错，但 top-set 必须覆盖；w_∅ 高意味着必须重定位，而不是「位姿不确定度大一点」。

**定义 386（定位六分量不确定度）**
u_loc² = u_map² + u_alias² + u_appear² + u_view² + u_dyn² + u_learn²
- u_map：地图漂移（**共模**，同一区域所有查询共享，增加查询次数不能降低）；
- u_alias：地点歧义（**多峰质量**，不是方差；用错误模式质量/熵表示）；
- u_appear：外观/域偏移（昼夜、季节、光照、传感器更换）；
- u_view：视角/遮挡/几何条件（距离、入射角、可见面）；
- u_dyn：动态场景（行人、移动物体、临时遮挡）；
- u_learn：模型/适应误差（版本、微调、TTA 带来的漂移）。
每分量独立追溯链；明确声明 u_map 与 u_alias 不能高斯化合并。**系**：R73 DPEM 的「六分量」在定位域不是类比，而是**空间化推广**——DPEM 的 v 是「眼与场景的关系」，LOCEM 的 (S, frame, anchor) 是「证据与世界的关系」。

**定义 387（地点条件 conformal）** 将支持区域划分为地点组 𝒢（瓦片/地点簇）。对每组 g 用独立校准集 D_g 构造预测集 C_{α,g}，要求逐组覆盖
P_{q∼P_g}(x_true ∈ C_{α,g}(q)) ≥ 1−α。
全局覆盖是各组的混合，不能替代逐组覆盖。定义**覆盖率地图** Cov(g) 与其置信下界 LCB(Cov(g))；认证区域 S_α = {g : LCB(Cov(g)) ≥ 1−α−tol ∧ n_g ≥ n_min}。样本不足的组进入弃权（stub），而不是用全局覆盖率外推。

**定义 388（MPC 地图来源契约）** MPC = (m, t_map, Σ_map, loop_set, anchor_set, provenance_hash, ρ_map, h_map)。地图误差是**共模**的；漂移上界 u_map(t) ≤ u_map(t_0) + ρ_map·(t−t_0)，超过 τ_map 触发重认证。无 provenance、无 anchor、无法复算的地图**不可入图**。地图本身是被审计对象，不是审计基准。

**定义 389（迁移算子与自适应算子）** T_{S→T}: LEC_S → LEC_T，携带数据 D_T、目标域标签量 n_T、迁移等级；A: (θ, D_adapt) → θ′，携带适应数据、计算预算、回滚哈希。T/A 都是**显式算子**，其输出必须重新声明 LEC 中所有非可迁移字段。**只有类型、否决语义、追溯合并函数可迁移；似然校准、支持区域、锚点、模型哈希不可默认迁移。**

**定义 390（校准传输间隙与传输证书）** 
Δ_cal(T) = sup_g |Cov_T(g) − Cov_S(g)|；
J_T = (源校准 id, 目标校准集, TV_UCB(P_S,P_T), 逐组覆盖 LCB, 迁移等级, 有效区域, 失效时间)。
**传输不等式**：对任意事件 E，|P_S(E)−P_T(E)| ≤ d_TV(P_S,P_T)，故 Cov_T(g) ≥ 1−α−d_TV^g−stat_slack。三级证据：
- **T0（无标签筛查）**：只用目标无标签数据估计位移；**只能否决，不能认证**（引理 42）；
- **T1（小样本目标校准）**：目标域少量标签，给逐组 LCB，允许认证但区域可能很小；
- **T2（全量重认证）**：目标域完整校准，认证区域最大、成本最高。

**定义 391（负迁移否决 NTV）** 候选迁移模块 f_T 的回退锚点为 a（源模型/全局重定位/安全停止）。NTV 触发条件（任一）：
(i) LCB(Cov_T(f_T)) < Cov_min；
(ii) E[risk(f_T)] > E[risk(a)] + margin；
(iii) TV_UCB > δ_max；
(iv) 目标域回退成功率低于回退锚点。
NTV 是**非补偿**的：直接把该模块置为 stub、S=∅，并向 ECM 报告「未覆盖区域」，而不是把 u 调大继续用。**边界声明**：T0 的 NTV 只能筛查，不能证明负迁移；证明需要 T1/T2。

**定义 392（RLC 重定位契约与锚点阶梯）** 四级：
- L0 局部跟踪：依赖地图瓦片与上一帧先验；
- L1 全局地点识别：依赖地图 provenance 与地点条件校准；
- L2 外部锚点：已知基准/GNSS/UWB/已知起始位/重力/地面高度/人工确认；
- L3 安全停止/求助。
规则：L_{k+1} **不得把 L_k 的输出当作真值**来验证自身（反循环）；锚点集必须与待认证对象**不相交**；回退只能向下（L0→L1→L2→L3），不得静默上升；每级有独立覆盖目标与有效期。

**定义 393（TCA 传输感知组合代数）** 扩展 CCA：
- **SER**：S_out = S_A ∩ S_B；frame 不同但变换已知（含协方差）时可组合，否则拒绝；u_out 单调传播；追溯合并。
- **PAR**：仅当 anchor_A ∩ anchor_B = ∅、跨模态一致性审计通过、且共享地图依赖 κ ≤ κ_max 时，S_out = S_A ∪ S_B；否则 S_out = S_A ∩ S_B 且 u_out = max(u_A,u_B)（保守并集）。**共享同一地图不得声称独立。**
- **VETO**：S_out = (S_A ∩ S_B) \ V，V 为否决区域（材质失效/互扰/地图过期/锚点冲突）；非补偿。
- **TRANS**：S_out = T(S_A) ∩ S_{T,cal}；u_out = u_in + Δ_cal；J_T 缺失或过期 ⇒ S_out = ∅（stub）。

**定义 394（ECM 认证操作包络）** ECM: 𝒲 → {certified, degraded, forbidden} × 风险上界。系统证书在 q 处有效当且仅当：q ∈ ∩ S_i、各 frame 变换已知、所有 J_T 有效、model_hash 与运行版本一致、未过期。ECM 可离线预计算、在线增量更新。证书**不是布尔值**，而是带风险标注的空间区域。

**定义 395（AQ 自适应隔离）** 运行时适应只能发生在影子模型 f_s；安全输出只来自冻结的活跃模型 f_a（哈希钉死）。f_s 必须通过目标校准审计、金丝雀测试、回滚演练后才能**原子提交**；任何自适应事件递增模型年龄，但 f_a 的证书保持有效；f_s 不得影响安全输出。绕过 AQ 的持续学习不享有任何证书。

**定义 396（ACP 主动校准规划）** 给定目标域校准预算，选择查询集 Q 最大化认证面积 |S_α(Q)|：
Q* = argmax_{|Q|≤B} |S_α(Q)|，s.t. 每瓦片样本数约束、安全探索约束。
在覆盖率增益单调且边际递减时，目标函数次模，贪心达到 (1−1/e) 近似。ACP 让「扩张认证区域」成为可规划行为，而不是碰运气。

**定义 397（系统证书 J_TRANS）** J_TRANS = ⊗_i J(module_i) ⊗ J_comp ⊗ J_MAP ⊗ J_T ⊗ J_ECM。Valid(J_TRANS) ⇒ 各模块证书有效 ∧ 组合校验通过 ∧ 地图 provenance 有效 ∧ 传输证书有效 ∧ ECM 非空；风险上界 ≤ ε_mod + Σδ_transfer + δ_map + δ_adapt。Valid(J_TRANS) ⇒ Valid(J_MOD)（当 T=恒等、地图完美、S=全域）。

**定义 398（传输感知 stub 与三类回退）** stub 输出：证据 ∅、S=∅、u=∞、I⊥=本模态全集、χ_R 平凡。但必须区分三种失效：
- **传感器失效** → 传感器 stub，其他模态补偿；
- **超出支持区域** → 重定位（RLC）或减速/停止，不得外推；
- **未校准迁移** → NTV 否决，回退到源模型/锚点/停止。
三者对应不同的安全动作；把它们都压成「u=∞」是 R73 的结构性遗漏。

**定义 399（复杂度结构上限）** |V_M|≤24、组合深度≤4、地点组 |𝒢|≤256、锚点≤8、每模块模型版本≤4、ECM 分辨率≤5 cm、每瓦片校准样本上限 4096——全部为可审计的图/数组性质（部署期 + 运行时增量校验）。

**定义 400（空间风险单调性与 E-IVG 扩展）** 失效/覆盖损失单调：删除模块不能扩张 S；无 J_T 的迁移不能扩张 S；未审计的适应不能降低认证风险。降级链扩展为：L0→L1→L2→L3，逐级安全侧只增不减。

**定义 401（CPB v2 扩展）** 新增三主张：
- **C4（空间条件校准）** ← (LOCEM, 定义 387) ← MB1s ← AB1s（逐地点 vs 全局 vs 单一最佳地点）；
- **C5（校准传输证书）** ← (TCT, NTV, AQ) ← MB2t ← AB2t（T0/T1/T2 vs 朴素微调 vs 仅源域）；
- **C6（地图锚定重定位）** ← (MPC, RLC, ECM) ← MB3m ← AB3m（地图-only vs 锚点-only vs RLC）。
非绑定组件仍为工程附件。

def transport_certificate(src_lec, tgt_data, level, alpha):

                              certifiable=False)

# IP-307 NTV：负迁移否决（非补偿）
def negative_transfer_veto(f_T, anchor_a, J_T, risk_params):

def compose_spatial(A, B, op, audit):

        return Ev(S=A.S & B.S, frame=compose_frames(A.frame, B.frame),
                  u=A.u + lipschitz(B, A.u), veto=A.veto | B.veto)

            return Ev(S=A.S | B.S, u=fuse(A.u, B.u, audit.corr(A, B)),
                      veto=A.veto | B.veto)
        return Ev(S=A.S & B.S, u=max(A.u, B.u),
                  veto=A.veto | B.veto | {'PAR_NOT_INDEPENDENT'})

def active_calibration_plan(candidate_tiles, budget, calib):

    while remaining > 0:

        if cost(g) > remaining: break
        S.add(g); remaining -= cost(g); calib.collect(g)
    return S

## 3. 推导

**引理 38（六分量的条件分解与共模项）** 给定同一瓦片、同一地图版本、同一外观类、同一视角区间，六分量由不同物理/统计机制产生（地图累积、地点歧义、域偏移、几何可见性、场景动态、模型版本），条件近似可分离；遗漏任一项导致系统性低估。**特别地**：u_map 是共模项，N 次查询不能把 u_map 降到 u_map/√N；u_alias 是多峰质量，不能用高斯方差表示。系：**定位证据的充分统计量不是协方差，而是（多假设信念，地点组，共模地图界，模型哈希）。**

**引理 39（校准传输 TV 不等式与样本复杂度）** 对任意事件 E，|P_S(E)−P_T(E)| ≤ d_TV(P_S,P_T)，故 Cov_T(g) ≥ 1−α−d_TV^g−stat_slack。逐组校准需要 n_g = Ω(ε^{−2} log(1/δ)) 样本；全局校准可构造一个 90% 简单瓦片 + 10% 覆盖 0 的灾难瓦片，使全局覆盖仍为 0.9(1−α)。系：**空间校准不是免费的——证书的分辨率直接由每瓦片样本数决定。**

**引理 40（地图规范自由与锚点必要性）** 地图+定位系统在全局刚体变换 G 下不变：`(m, x) → (Gm, Gx)` 保持所有残差、回环、局部协方差不变。故任何内部残差函数都无法识别 G；绝对位姿证书必须引入**不随系统一起变换**的外部锚点。系：**地图漂移存在一个从系统内部不可观测的分量；只有锚点交叉验证能给它上界。**

**引理 41（空间覆盖组合）** SER：S_out = S_A ∩ S_B；PAR：锚点独立时 S_out ⊆ S_A ∪ S_B，否则 S_out ⊆ S_A ∩ S_B（共享地图的共模使「一致」不增加信息）；VETO 只会挖洞。任何组合都不会超出输入支持的并集；没有独立锚点，任何组合都不会超出交集。系：**加模块不能治愈未建图区域。**

**引理 42（无标签迁移的不可识别性）** 存在两个目标域联合分布 P_T^1、P_T^2，其观测边缘 P_T(y) 完全相同但校准覆盖率相差任意大。只使用源域标签与目标域无标签数据的任何方法，对二者输出同一模型，故不能同时保证覆盖。系：**T0 只能筛查/否决，不能认证；T0 的「通过」不是安全证据。**（这是 Le Cam 式不可区分论证，不是工程限制。）

**引理 43（传输感知的温替换）** 若 impl′ 满足同一 LEC 且 J_T 有效、传输间隙为 δ、model_hash 纪律一致，则系统级性质在支持区域内保持，风险 ≤ ε+δ；认证成本 O(模块 + |𝒢_T|)（𝒢_T 为目标校准瓦片），不是 O(系统)。支持区域外 J_T 失效，S_out 收缩。系：**R73 的「热替换」应改名为「温替换」——跨域替换不是免费的，代价是传输证书与目标校准样本。**

**引理 44（自适应隔离不变式）** 在 AQ 下，活跃模型哈希与校准集 id 在两次审计之间不可变；影子适应不能影响安全输出。因此证书在适应期间保持有效，回滚恢复到精确的已认证状态。若绕过 AQ，存在一条适应序列使 API 与准确率不变、覆盖率崩溃。系：**AQ 不是工程洁癖，而是「证书绑定到模型版本」的必要条件。**

**引理 45（主动校准的次模性）** 在覆盖增益单调、边际递减的常规条件下，认证面积增益是次模函数，贪心 ACP 达到 (1−1/e) 近似；跨瓦片强相关时次模性失效，必须按传输证书分组后再贪心。系：**认证区域可以被主动、可证地扩张，但扩张速度受样本预算与相关性结构限制。**

**定理 30（TRANS-GAUGE 严格包含 MODGAUGE）** 当 S=全域、anchor=已知、T=恒等、地图完美、模型冻结、ECM={全域} 时，TRANS-GAUGE 逐指令等于 MODGAUGE（定理 27），再退化等于 R72/R71/R68。安全单调不减，效率仅在空间/迁移条件满足时获益。

**定理 31（传输证书有效性 ⇒ 风险上界）** Valid(J_TRANS) ⇒ 物理执行风险 ≤ ε_mod + Σ_i δ_i + δ_map + δ_adapt，相对于**已声明的参考系与锚点**。证明由引理 39（TV 覆盖）、引理 40（地图共模）、引理 43（温替换）、引理 44（适应隔离）与 R73 定理 28 组合。**证明重量落在 TV 上界的有效性、锚点确实独立、以及目标校准集的代表性上。**

**定理 32（重定位反循环/非自举）** 仅由（地图，定位器，适应）构成的证据闭环，若无外部锚点，不能建立绝对位姿或给出全局漂移上界；加入外部锚点后，规范被固定，漂移上界由锚点残差给出。系：**「地图验证定位、定位更新地图」在闭环内永远自洽，因此永远不能证明自己正确。**

**定理 33（ECM 正确性与空间完备）** 系统证书在 q 处有效 ⇔ q ∈ ∩S_i ∧ frame 变换已知 ∧ 所有 J_T 有效 ∧ model_hash 匹配 ∧ 未过期。若 q 不在 ECM 内，系统必须进入已声明回退（重定位/降级/停止），不得静默外推。证明由定义 393/394 与引理 41。

**定理 34（自适应安全）** 在 AQ 下，运行时适应不能降低活跃策略的已认证风险；任何提升必须产生新的 J_TRANS。无 AQ 时不存在此保证。系：**持续学习/TTA 只有在「影子 + 校准 + 原子提交」结构下才能进入安全认证路径。**

## 6. 本轮最大风险

**一句话**：TRANS-GAUGE 的诚实性以**认证区域收缩**为代价——最需要迁移的未知区域恰恰缺少目标域标注，严格证书会让 ECM 收缩甚至为空（不可用），放宽则退回未校准迁移；更隐蔽的是，在线自适应模型与在线构建地图可能互相提供「证据」，使系统用一套自洽、类型正确、证书齐全但**没有外部锚点**的闭环，自信地认证自己的漂移。

次级风险与缓解：
1. **ECM 空集/过度保守** → ACP 主动采样 + 分级证书（T0 筛查/T1 受限认证/T2 全认证）+ 显式风险预算，而不是二值可用/不可用。
2. **TV 上界不可估/两样本检验失效** → 用 e-value/序贯检验给单侧保证；高维场景用保守上界并在证书中显式声明「未证明」；T0 永不进入安全路径。
3. **锚点本身被投毒** → 锚点多样性 + 单源不定案（继承 E356/E357）+ 锚点 provenance + E417 对抗测试。
4. **地图与定位自举** → 强制外部锚点固定规范；内部一致性只作筛查；定理 32 作为认证前置检查。
5. **地点组爆炸/样本稀疏** → 层次化地点组（粗到细）+ 组间借力（仅在有传输证书时）+ 结构上限 |𝒢|≤256。
6. **在线适应绕过 AQ** → 模型哈希钉死 + 原子提交 + 回滚审计 + 运行时度量（任何未登记哈希的输出直接废弃）。
7. **温替换成本被低估** → 认证成本按「模块 + 目标瓦片」计费；C3 的 O(模块) 只在同域成立，跨域必须诚实地写 O(模块 + |𝒢_T|)。
8. **因果边迁移失效** → edge_inv 只声明可迁移边，其余边在目标域用干预/不变性检验重审（E411 附带）。

# IP-302 DAR：运行时分布感知器（计量域 50Hz，<0.5ms）
class DistributionAwareRuntime:
    def __init__(self, seal_train_sets, phi_kernels=64):
        self.ulsif = uLSIF(phi_kernels)           # 密度比估计器
        self.W_deploy = deque(maxlen=500)         # 部署滑动窗口
        self.tau_0 = 3.0; self.kappa = 0.01; self.eta = 0.5
        self.last_ood_time = -inf

    def monitor(self, modules, state, env_sensors):
        # 1. 构建监控特征向量（每模块 + 环境）
        feats = {}
        for m in modules.values():
            feats[m.name] = m.ec.extract_monitor_features(state[m])  # (u, breakdown, m_post, v, ...)
        feats['env'] = env_sensors

        # 2. 密度比估计（增量 uLSIF）
        X_deploy = np.array([f.flatten() for f in feats.values()])
        self.W_deploy.append(X_deploy)
        if len(self.W_deploy) >= 50:
            r_hat = self.ulsif.fit_incremental(self.seal_train_sets, self.W_deploy)
        else:
            r_hat = np.ones(len(feats))

        # 3. 一致性分数（复用 SEAL conformal 非一致性度量）
        conf_scores = {n: m.audit.conformal_score(feats[n]) for n, m in modules.items()}

        # 4. 契约残差（观测不确定度 vs χ_R 预测）
        contract_residuals = {}
        for n, m in modules.items():
            u_pred = m.ec.chi_R(state['last_action']).predicted_u(state[m])
            contract_residuals[n] = abs(feats[n].u - u_pred)

        # 5. 综合异常得分
        Phi = {}
        for n in feats:
            Phi[n] = max(r_hat[n], conf_scores[n], contract_residuals[n])

        # 6. 动态阈值（时间衰减 + 预算感知）
        B_remain = state['budget'].B - state['budget'].spent
        tau = self.tau_0 * math.exp(-self.kappa * (state['t'] - self.last_ood_time)) \
                    * (1 + self.eta * B_remain / state['budget'].B)

        # 7. OOD 判定与域收缩
        ood_flags = {}; D_t = {}; par_allow = {}
        for n, m in modules.items():
            ood = Phi[n] > tau
            ood_flags[n] = ood
            if ood:
                self.last_ood_time = state['t']
                # 单调收缩：D_t = D_{t-1} ∩ {x | Phi(x) ≤ tau}
                D_t[n] = m.ec.domain.intersect({x: Phi[n] <= tau})
                par_allow[n] = False  # 禁用 PAR 缩窄
            else:
                D_t[n] = m.ec.domain
                par_allow[n] = True
        return DAROutput(ood_flags, D_t, par_allow, Phi)

# IP-303 BC-MOD：契约感知行为克隆（部署期训练，推理 <2ms）
class BCModule:
    def __init__(self, ec_bc, seal_bc):
        self.ec = ec_bc
        self.policy = DiffusionPolicy(cond_dim=256, act_dim=16)  # Transformer + 扩散头
        self.seal = seal_bc
        self.pi_safe = SafeFallbackPolicy()  # 保守回退：关节空间 PD + 避障

    def train_step(self, batch):  # batch = (obs_evidence, action_expert, task_emb)
        o, a_exp, task = batch
        # 1. 标准 BC 损失
        a_pred = self.policy(o, task)
        loss_bc = F.mse_loss(a_pred, a_exp)

        # 2. 契约违反惩罚（需可微分代理）
        p_viol = self.predict_violation_prob(o, a_pred)  # 小型预测头
        loss_viol = (p_viol > self.ec.tau_viol).float().mean()

        # 3. 安全策略正则
        a_safe = self.pi_safe(o)
        loss_kl = F.kl_div(a_pred.log_softmax(-1), a_safe.softmax(-1), reduction='batchmean')

        loss = loss_bc + self.beta * loss_viol + self.gamma * loss_kl
        return loss

    def augment_evidence(self, o):  # 证据空间对抗增强
        o_aug = o.copy()
        for mod_name in ['depth', 'tactile', 'intent']:
            if mod_name in o:
                ev = o[mod_name]
                # 从契约噪声模型采样扰动
                delta_u = self.sample_contract_noise(mod_name, ev.v if hasattr(ev,'v') else None)
                o_aug[mod_name] = ev.apply_noise(delta_u)  # 修改 lik, u, breakdown, m_post
        return o_aug

    def warm_start(self, b_t, z_dist, task_emb, mods, K=8):
        # 生成 K 条候选轨迹，取成本最优者初始化 ROC-MOD
        trajs = []
        for _ in range(K):
            a_seq = self.policy.rollout(b_t, z_dist, task_emb, horizon=10)
            # 过滤：只保留满足 REG/有效域/预算的轨迹
            if self.check_contract_compliance(a_seq, mods):
                trajs.append(a_seq)
        return min(trajs, key=lambda t: self.estimate_cost(t)) if trajs else None

    def fallback_action(self, o, mods, budget):
        # ΣREFLEX 拒绝 / REG 违例 / 预算耗尽时的回退
        a = self.policy(o, task_emb=None).mode()
        return self.project_to_safe(a, mods, budget)

# IP-304 ROC-MOD：风险敏感契约最优控制（计量域 20Hz，<5ms）
class ROCOptimalControl:
    def __init__(self, mods, budget, risk_params):
        self.mods = mods
        self.budget = budget
        self.theta = risk_params.theta      # 风险敏感参数
        self.gamma = risk_params.gamma
        self.T = risk_params.horizon        # 10-20 步
        self.N = 64                         # PI 采样轨迹数
        self.V_net = ContractValueNet()     # 契约感知值函数

    def solve(self, b_t, z_dist, state, budget, mods, D_t, task_emb, warm_traj=None):
        # 状态增广：x = (s, b, {chi_R}, B_remain, {D_t})
        x0 = self.pack_state(b_t, z_dist, state, budget, D_t)

        # 初始化控制分布 q(u) = N(u; μ, Σ)
        if warm_traj is not None:
            mu = warm_traj[:self.T]
        else:
            mu = np.zeros((self.T, 16))  # 16 DoF

        # PI 迭代（通常 1-2 次迭代在 5ms 内）
        for _ in range(2):
            # 1. 采样 N 条轨迹
            trajs = []
            costs = []
            for _ in range(self.N):
                u_seq = self.sample_control(mu)
                # 采样噪声 w ~ p_w(·|s, chi_R(u)) —— 直接用契约声明的噪声模型
                x_seq, valid = self.rollout_contract(x0, u_seq, mods, D_t, budget)
                if not valid:  # 违反有效域/预算/REG
                    costs.append(np.inf)
                    continue
                c_seq = self.compute_costs(x_seq, u_seq, mods)
                costs.append(sum(self.gamma**t * c_seq[t] for t in range(self.T)) + self.V_net(x_seq[-1]))
            costs = np.array(costs)

            # 2. 重要性权重 w_i ∝ exp(-theta * cost_i)
            weights = np.exp(-self.theta * (costs - costs.min()))
            weights /= weights.sum()

            # 3. 更新控制均值（加权平均）
            mu = sum(weights[i] * trajs[i] for i in range(self.N))

        # 4. 返回首步动作 + 完整策略分布（供认证前缀用）
        pi_ROC = GaussianPolicy(mu=mu[0], Sigma=self.extract_Sigma(weights, trajs))
        return mu[0], pi_ROC

    def rollout_contract(self, x0, u_seq, mods, D_t, budget):
        x = x0
        B_remain = budget.B - budget.spent
        for t, u in enumerate(u_seq):
            # 反作用成本
            c_reflex_total = 0
            for m in mods.values():
                chi = m.ec.chi_R(u)
                c_i = m.reflex_cost(x[m.name], chi)
                if c_i is None: return None, False  # 稳态越界
                c_reflex_total += c_i
            if B_remain < c_reflex_total: return None, False
            B_remain -= c_reflex_total

            # 有效域检查
            for m in mods.values():
                if not D_t[m.name].contains(x[m.name]): return None, False

            # 动力学步进：采样 w ~ p_w(·|s, chi_R(u))
            w = self.sample_contract_noise(x, u, mods)
            x = self.dynamics_step(x, u, w, mods)
        return x, True

    def sample_contract_noise(self, x, u, mods):
        # 从每个模块的契约噪声模型采样
        w = {}
        for m in mods.values():
            chi = m.ec.chi_R(u)
            w[m.name] = m.noise_model.sample(x[m.name], chi)  # 可微分采样
        return w

## 4. 推导

**引理 38（DAR 收缩算子的单调性与组合兼容性）** ζ(D, Φ, τ) = D ∩ {x | Φ(x) ≤ τ}。对任意 τ_1 ≤ τ_2，ζ(D, Φ, τ_1) ⊆ ζ(D, Φ, τ_2)；对任意 D_1 ⊆ D_2，ζ(D_1, Φ, τ) ⊆ ζ(D_2, Φ, τ)。⇒ D_t 单调收缩（D_t ⊆ D_{t-1}）。结合引理 34（组合单调性）：有效域收缩 ⇒ 组合输出域单调收缩 ⇒ 系统级有效域单调收缩。**无「域反弹」路径**——符合安全单调不减。

**引理 39（BC-MOD 契约违反惩罚的泛化界）** 设 π_BC 由 L_BC 训练，β 由 SEAL-BC 校准使 E_{SEAL}[p_viol] ≤ τ_viol/2。则对任意部署分布 P_deploy，若密度比 r(x) ≤ R_max，有 E_{P_deploy}[p_viol] ≤ R_max · τ_viol/2 + ε_gen。**系**：DAR 的密度比估计 r̂ 直接给出 BC 违反率的**运行时上界**——当 r̂ 大时，DAR 已触发 OOD 降级，BC 回退动作经 C_RAS_WM 认证，安全不依赖 BC 质量。

**引理 40（契约噪声模型采样的无偏性）** PI 采样 w ~ p_w(·|s, χ_R(u)) 使用模块契约声明的噪声模型。若 A111 成立（契约噪声模型覆盖真实分布），则采样轨迹分布与真实执行分布在**契约有效域内**全概率匹配。若 A111 失效（分布外），DAR 已收缩 D_t 使采样域 ⊆ 覆盖域。**系**：PI 的无偏性**由契约+DAR 共同保证**——这是「契约最优控制」区别于普通 MPC 的核心。

**引理 41（ROC-MOD 值函数近似的契约正则效果）** L_V 含 max(0, V̂(x) − V_safe(x))。V_safe 为保守下界（如：假设所有不确定度取上界、所有反作用成本取最大、任务进展为 0）。则 V̂(x) ≤ V_safe(x) + ε_V。结合引理 40，PI 采样回报的期望 ≤ V_safe + ε_V + ε_PI。**系**：终端代价**不会高估真实值函数**——风险敏感控制的保守性由契约正则结构性保证。

**定理 30（DEPLOY-GAUGE 严格包含）** 在 A111–A114 + DAR 校准正确 + BC-MOD 契约合规 + ROC-MOD 差界成立下：MODGAUGE-RAS 是 DEPLOY-GAUGE 的特例——关闭 DAR（τ=∞）、移除 BC-MOD（π_BC=∅）、退化 ROC-MOD 为 PVOP（θ→0, V̂=0, c_reflex 只做预算检查）。由定义 383(v) 与引理 35，退化条件下逐指令等于 R73，再退化等于 R72/R71/R68。**安全单调不减，部署能力单调增强。**

**定理 31（部署证书有效性 ⇒ 真实世界风险界）** Valid(J_DEPLOY) ⇒ Valid(J_MOD) ∧ DAR 校准有效 ∧ BC-MOD 违反率界有效 ∧ ROC-MOD 差界 ε_opt 有效 ⇒ 物理执行风险 ≤ ε_mod + ε_opt（相对具身测量模型、契约表达力、分布偏移幅度、值函数近似）。**证明重量落在**：DAR 的密度比估计在长尾分布下的**有限样本覆盖保证**（需 R_max < ∞）、BC-MOD 证据空间增强的**物理合法性保证分布外泛化不崩**、ROC-MOD 契约噪声模型的**可微分覆盖假设 A111/A114 在分布外由 DAR 收缩保持**。

**定理 32（分层降级的零安全事故）** OOD 检出 ⇒ D_t 收缩 + PAR 禁用（引理 38 单调） ⇒ π_BC 回退（经 C_RAS_WM 认证） ⇒ 预算耗尽/持续 OOD ⇒ 人类接管 ⇒ R68。**每级降级都有结构化证书**（J_DAR 记录收缩链、J_BC 记录回退合规、J_ROC 记录预算耗尽轨迹），且**无级联失效**（引理 34 保守性 + C_RAS_WM 硬实时隔离）。**系**：真实世界部署的「长尾安全」由**证书链**而非「模型鲁棒性」保证。

**一句话**：DEPLOY-GAUGE 把真实世界泛化的证明负担从「模型在测试集准」转移到「**DAR 的密度比估计在长尾分布下有有限样本覆盖保证**」——若真实世界出现**零密度区**（r(x)=∞，即部署分布支撑集不在训练分布支撑集内，如全新材质类别、从未见过的传感器故障模式），uLSIF 会给出任意值、DAR 可能漏检或误触发、BC-MOD 证据空间增强无法覆盖、ROC-MOD 契约噪声模型 A111 彻底失效——系统会在**证书 J_DEPLOY 完全有效、所有组合校验通过、审计日志证明每一步合规**的情况下，**自信地走入一个契约表达力之外的世界并发生安全事故**，而事后根因分析只能指向「契约表达力不足」，无法在运行时捕获。

次级风险与缓解：
1. **uLSIF 高维特征下的诅咒** → 特征降维（契约摘要统计量：u 标量、breakdown 熵、m_post 熵、v 标量）而非原始证据向量；核数量 K=64 固定；定期离线重训练 SEAL 核中心。
2. **BC-MOD 扩散策略推理延迟抖动** → 导出 ONNX/TensorRT 定点推理；W=5ms 硬截止，超时即用 π_safe；部署期离线量化校准。
3. **ROC-MOD PI 采样在高维动作空间(16 DoF)的样本效率** → 用 π_BC 暖启动 + 契约约束缩小采样域 + 协方差自适应（CMA-ES 风格）；N=64 经消融验证足够。
4. **值函数 V̂ 灾难性遗忘（在线微调破坏契约结构）** → 只微调最后一层 + Elastic Weight Consolidation (EWC) 正则 + 离线重训练周期触发。
5. **证书链存储/传输开销** → 增量默克尔树 + 零知识证明片段（仅审计时展开）；控制域证书 <1KB。
6. **MB4 长时程部署的不可复现性** → 密封环境描述（光照/温度/振动日志哈希）+ 固定 OOD 注入时间表 + 三方复现只认预注册指标统计量而非单次运行。
