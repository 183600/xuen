# 第 44 轮（新循环第 4 轮，承接 v20）· Instance-Cert × Adapter-Cert：把「实例同一性」与「LoRA 适配」写进证书的版本与寿命（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约空集」，但它把整座证书大厦压在两个从未被检验的地基假设上：**(H1) 证书引用的实体是稳定的**——几何证书说「障碍物 O_17 在 x」，语义证书说「Person P_3 想开门」，却默认 O_17 / P_3 的**同一性**在时间、遮挡与重识别中不变；实例分割/跟踪的一次 ID 交换不会报错，只会让一张仍然「有效」的证书悄悄绑定到错误的物体。**(H2) 产生证书的模型是冻结的**——L0 查表、共形校准、CBF margin 都默认「感知/策略网络就是被验证过的那一个」；但 LoRA 让模型变成**可热插拔的适配器**，一次 rank-r 的微调就是对已认证映射的未认证打补丁，可以静默让旧证书失效。本轮灵感词「实例分割」「LoRA」精确命中：**实例分割**把「同一个物体」从像素集合提升为必须持证的**身份假设**；**LoRA**把「模型版本」从部署常量提升为必须持证的**变更事件**。二者共享同一结构——**绑定（binding）**：证书 ↔ 实体 ↔ 模型版本。真正的新问题是二者复合后的**再绑定陷阱**：适配器会改变用来识别实体的分割/跟踪输出，而实体分布漂移又正是换适配器的理由——模型用自己的输出证明自己适配得体，形成「身份-适配器自证成」。因此 v9 新增的不是一个感知模块，而是证书的**生命周期与版本层**：绑定可审计、变更可增量再认证、过期可回退。

## 0. 直觉与动机

**灵感 1（实例分割 → 同一性是假设，不是像素）**：实例分割给出的是「这些像素属于某个物体」，但下游证书需要的是「这个物体还是上一时刻那个物体」。后者靠关联/跟踪，而关联在遮挡、拥挤、外观相似时会失败——且失败是**静默**的：mask 依旧漂亮，ID 却换了人。直觉是：**身份必须像几何一样持证**。每条实例携带 (i) 共形 mask 集合 M̂_t^α（在可交换性下 P(真 mask ∈ M̂_t^α) ≥ 1−α）；(ii) 关联假设集 A_t（可能身份的集合，而非单点 argmax）；(iii) 遮挡/重识别状态 O_t；(iv) 溯源 prov_t。**身份不被认证时绝不猜**：把证书提升为对 A_t 中所有候选的并集（风险单调谓词取 union），代价是可用性单调下降，收益是 **ID 交换只可能降低可用性，绝不静默破坏 soundness**。

**灵感 2（LoRA → 适配器是给已认证映射打补丁，必须持证）**：LoRA 用 ΔW = (α/r)·B A 改动权重，rank 小但足以翻转决策。直觉：**不要只问「这个适配器好不好」，要问「它能把这个已认证系统的行为改变多少，以及这些改变是否还落在证书 margin 内」**。于是适配器证书 LAC 携带 (i) 有效域 Dom_A（它被训练/验证覆盖的输入与实例类别）；(ii) 数据溯源与质量 Q_A；(iii) **行为增量上界 ε_A**：对线性层 ||ΔW h|| ≤ (α/r)||B||₂||A||₂||h||₂，再经下游 Lipschitz 常数传播（或用 IBP/CROWN 收紧）；(iv) rank/能量预算 E_A；(v) 版本 v_A 与到期 T_A。**证书复用判据**：旧证书可继续使用，仅当输入 ∈ Dom_A、Q_A 达标且 **m − ε_A ≥ θ**（适配器吃掉的那部分 margin 被显式记账）；否则必须重认证或拒绝加载。**rank 与 scale 不是超参装饰，而是可认证的行为预算旋钮**。

**灵感 3（耦合 → 再绑定陷阱与「身份-适配器自证成」）**：真问题在环。分割漂移 → 触发换适配器（域自适应）→ 适配器又改变分割/跟踪输出 → 而该输出正是用来判定适配器「域是否仍有效」的证据。若用被适配的通道给适配器自己作证，就是模型版的自证成：**它把世界看成自己希望的样子，再据此宣布自己合格**。更隐蔽的是**后门适配器**：在认证域上 ε_A 很小、行为几乎不变，只在触发输入上翻转——行为增量界天然覆盖不到触发器。直觉是：**认证证据必须来自与被认证对象独立的影子通道**（冻结的参考分割器 + 独立几何），并显式估计耦合增益 γ_AI；γ_AI 超界或分歧率上升即冻结适配器更新（反自证成模式）。

**耦合升级**：IIC（实例同一性认证器）把「物体是谁」变成带共形 mask 与关联歧义的证书；ACM（适配器证书管理器）把「模型被谁改过、能改多少」变成带行为增量界与组合代数的证书；CRV（变更影响再认证器）用证书依赖图把一次换适配器/一次重绑定精确限定到受影响子图，做**增量再认证**而非全量重跑。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9 的「人格契约层 + 并发证书层 + **生命周期/版本层（实例同一性 × 适配器版本）**」。

## 1. 形式化定义（增量：定义 44–51）

**定义 44（实例同一性证书 IIC）**：对跟踪实例 i_t = (mask_t, id_t)，同一性证书 I_t = (M̂_t^α, A_t, O_t, prov_t)。M̂_t^α 为按类别 Mondrian 的共形 mask 集合，非一致性分数取 1−IoU，满足可交换性下 P(mask_true ∈ M̂_t^α) ≥ 1−α。A_t ⊆ 𝒪 为**关联假设集**：所有关联非一致性分数不超过阈值 q_assoc 的候选身份；O_t ∈ {visible, partial, occluded, reidentified}；prov_t 记录产生该实例的模型版本与帧证据。**同一性已认证**当且仅当 |A_t| = 1 且 O_t ≠ occluded；否则称**同一性歧义**，歧义度 h_t = log|A_t|。

**定义 45（保守绑定与同一性提升）**：设证书 c 引用实体 e，绑定函数 bind(c, i_t)：若 A_t = {e} 则保留；否则把 c **提升**为 lift(c, A_t) = ⊔_{e'∈A_t} c[e→e']，即对 A_t 中每个候选各持一份证书并取风险并集。对**风险单调谓词** P（障碍物区域、可达集、意图集合均属此类：候选实体集合变大，约束只会更保守），提升满足 P_true ⇒ lift(P) 安全。**定理（无静默错绑）**：只要每次绑定的支持集都落在已认证同一性集合内（否则提升），则任何 ID 交换都不能让证书在「有效」外观下保护错误实体；同一性错误的代价被严格限制为**可用性下降**，其量随 h_t 单调。**推论**：ID 交换检测器触发时，正确动作是**作废旧租约并提升**，而不是沿用旧绑定。

**定义 46（LoRA 适配器证书 LAC）**：适配器 A 作用于第 ℓ 层，ΔW_ℓ = (α/r)·B A，rank r，scale α。证书 L_A = (Dom_A, Q_A, ε_A, E_A, v_A, T_A)：Dom_A 为有效输入/实例类别域，Q_A 为数据溯源与质量画像，E_A 为 rank/能量预算，v_A 为版本哈希（含基座模型、目标模块、秩、scale、训练数据），T_A 为到期。**行为增量上界**：对 ||h||₂ ≤ H 的层输入，||ΔW_ℓ h||₂ ≤ (α/r)||B||₂||A||₂ H；经下游算子 Lipschitz 常数 L_{>ℓ} 传播得 ε_A ≤ L_{>ℓ}·(α/r)||B||₂||A||₂ H（更紧的用 IBP/CROWN）。**复用判据**：基座系统的旧证书可在加载 A 后继续使用，仅当 x ∈ Dom_A、Q_A 达标且 **m_cert − ε_A ≥ θ**；否则 A 必须重认证或加载被拒。**注**：ε_A 是**最坏行为偏差界**而非平均精度变化；后门/触发式适配器不在该界覆盖内，必须由定义 51 的独立通道另测。

**定义 47（适配器组合代数与干扰界）**：A⊕B 的 ΔW = ΔW_A + ΔW_B。**可加界** ε_{A⊕B} ≤ ε_A + ε_B（三角不等式）；但非线性网络中真实干扰可超可加，故定义**干扰项** I(A,B) = sup_{x∈Dom_A∩Dom_B} |δ_{A⊕B}(x) − δ_A(x) − δ_B(x)|。**组合可认证**当且仅当 Dom_A∩Dom_B ≠ ∅、ε_A + ε_B + I(A,B) ≤ m − θ，且 rank 总预算 Σr ≤ R_max。**定理**：若每个子证书 sound 且组合界 ≤ margin，则组合策略在交域内保持原证书；**警告**：只在各自证书上相加而不测 I(A,B) 是不 sound 的，组合必须在组合影子上实测。

**定义 48（版本绑定租约 v3）**：把 v20 定义 41 的租约 ℓ = (m, τ, λ, κ) 扩展为 ℓ = (m, τ, λ, κ, v_bind, h_bind)：v_bind = Hash(策略版本 ⊕ 适配器集合 ⊕ 感知/分割版本 ⊕ 地图版本)，h_bind = Hash(实体绑定)。**新鲜度判据**：m − λ(t−τ) ≥ θ ∧ v_bind = v_current ∧ h_bind = h_current。**定理（换版即失效）**：任何适配器热切换或实体重绑定都会使 v_bind / h_bind 失配，从而**即使时间上新鲜，租约也立即作废**；因此 v20 的「测量时刻—使用时刻」解耦被补全为「时间 × 版本 × 绑定」三重契约。**推论**：陈旧证书不可能跨过一次 swap 存活。

**定义 49（证书依赖图与增量再认证）**：证书依赖图 CDG = (V,E)，V 含证书、适配器、实体绑定、数据工件、基座模型；边表示 depends-on。对变更 δ（换适配器 / 重绑定 / 基座升级），**影响足迹** F(δ) = {v ∈ V : v 从 δ 可达的下游}。**增量再认证**：只重认证 F(δ)、作废触及 F(δ) 的租约，其余证书在版本未变且仍在 Dom 内时保留。**定理（增量 sound 性）**：若 (a) 未受影响证书的依赖与版本均未变、仍在有效域内；(b) F(δ) 内每条证书被重认证或单调降级；则全局不变式保持，且代价从 O(|V|) 降到 O(|F(δ)|)。**注**：CDG 必须含**动作-环境边**（机器人行为改变会反过来改变场景与实体分布），否则 F(δ) 会低估影响——这是本定义最脆的假设。

**定义 50（事务性适配器切换与双版本影子）**：切换 = 事务：(1) 新适配器在**影子里**对同一条实时输入流运行，产出影子证书；(2) 校验 ε_A、Dom_A、影子零违例、A/B 无回归；(3) 原子提交并递增 epoch（复用 v20 seqlock/epoch）；(4) 任一不满足则回滚。**定理（无混合版本可观测）**：若提交是 epoch 原子的且影子校验覆盖 Dom_A，则任何交错读者只会看到旧版或新版，不会看到混合版；结合 v20 定义 40 的非干扰，切换只改变 v_bind、不放松任何阈值。**反向规则**：切换只允许「换版本 + 显式记入 ε_A」，禁止借切换偷偷放宽 θ 或 m。

**定义 51（身份-适配器耦合与反自证成）**：适配器 A 可能改变分割/关联输出 y_seg，而 y_seg 又被用来判定 A 的域有效性——定义**耦合增益** γ_AI = P_{x~Dom_A}(适配器改变 y_seg 的实例身份标签且该改变翻转 Dom 判定的比例)。**独立性要求**：用于认证 A 的同一性证据必须来自**不经过 A 的冻结参考通道** R（冻结分割器 + 独立几何），或经交叉校验；否则 A 在用自己的输出给自己作证。**命题（反自证成）**：若认证通道与适配通道独立（R ⊥ A），则触发式后门无法通过改变自身认证证据来通过认证，只能表现为 R 与 A 的分歧，从而被分歧率检测。**回退**：γ_AI 超界或分歧率显著上升 → 冻结适配器更新（反自证成模式），保留基座证书。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 INSTANCE-IDENTITY-CERTIFIER（实例同一性认证器 IIC）
1. **共形 mask 证书**：按类别/距离 Mondrian 校准，1−IoU 非一致性分数，输出 M̂_t^α；mask 与点云/几何做保守融合（取包络），amodal 补全只用于扩大保守区域。
2. **遮挡感知关联**：外观 + 运动 + 几何三通道关联，输出关联假设集 A_t 与遮挡状态 O_t；低证据时保留多假设，不强行 argmax。
3. **保守绑定与提升**：把 v20/几何/语义证书绑定到实例；|A_t| > 1 时自动提升为候选并集，ID 交换事件即时作废租约并触发提升。
4. **身份 liveness**：可选主动消歧（换视角/追问/轻推）在预算内进行；无法消歧则维持歧义，绝不猜。

### 2.2 IP-61 ADAPTER-CERT-MANAGER（适配器证书管理器 ACM）
1. **适配器登记与溯源**：rank/scale/目标模块/训练数据/基座版本/到期全部哈希绑定；拒绝无溯源适配器。
2. **行为增量界**：谱范数零成本上界 + IBP/CROWN 收紧；计算 ε_A 与 rank/能量预算；给出可复用旧证书的 margin 判据。
3. **组合代数与干扰实测**：多适配器/多 persona 组合的交域、可加界、干扰项 I(A,B) 与 rank 总预算；组合必须实测。
4. **事务性热切换**：影子运行 + 原子 epoch 提交 + 回滚；与 v20 混合关键级联动（HI 模式禁止切换）。

### 2.3 IP-62 CHANGE-IMPACT-REVALIDATOR（变更影响再认证器 CRV）
1. **CDG 构建与维护**：证书/适配器/绑定/数据/基座为节点，依赖为边，含动作-环境边。
2. **足迹计算与增量再认证调度**：按关键级排序 F(δ)，只重认证足迹；与 v20 EDF/RTA 共用预算。
3. **绑定/版本审计与线性一致性**：换版/重绑定序列对监控器读的线性一致性，检出混合版本/陈旧绑定。
4. **反例回灌**：ID 交换、后门适配器、组合干扰反例回灌 CKB/SCV。

```
    ← IP-58 CCR(租约表 v3 + 事务性热切换 + 混合关键级)
    → IP-47 组合代数(适配器态射/干扰) → IP-39 规划 → IP-45 总线
    → IP-53 CMC(适配器版本绑定的监控器) → 监控快照(epoch 一致)
L4: IP-62 CRV(CDG + 足迹增量再认证) + IP-57 PCE(persona 适配器闸门)
    ← IP-59 ICV(身份对抗 + 后门/组合交错) + IP-54 SCV(遮挡/换版压力测试)
    → IP-55 CKB(实例本体 + 适配器指纹) → RCA 重颁 → 版本化热更新
运行期：分割/关联 → 同一性证书 → 绑定/提升 → 版本绑定租约 → 决策
        换适配器 → 影子校验 → 原子 epoch 提交 → 足迹再认证 → 作废旧租约
        歧义/后门/干扰超界 → 提升/冻结/回滚 → 反例回灌
```

## 5. 本轮最大风险

## 2. 关键算法（伪代码）

### IP-60 IIC：共形 mask、关联歧义与保守绑定
```
def instance_identity_cert(seg, track, calib, alpha):
    masks  = seg.predict(frame)                      # things + stuff
    scores = [1 - iou(m, calib.true_mask) for m in masks]
    q      = mondrian_quantile(calib.scores_by_class, 1 - alpha)
    M_hat  = MaskSet([m for m, s in zip(masks, scores) if s <= q])
    A_t    = track.association_hypotheses(q_assoc)   # 保留多假设，不 argmax
    O_t    = track.occlusion_state()                 # visible/partial/occluded/reidentified
    return IdentityCert(M_hat, A_t, O_t, prov=track.provenance())

def bind_or_lift(cert, identity):
    if len(identity.A_t) == 1 and identity.O_t != OCCLUDED:
        return bind(cert, only(identity.A_t)), identity
    # 同一性歧义 => 保守提升：对每个候选各持一份并取风险并集
    # 风险单调谓词（障碍区域/可达集/意图集）下，union 只会更保守
    return union_over(cert, identity.A_t), identity

def on_id_switch(old_binding, new_identity):
    void_leases(binding_hash=old_binding)            # 旧租约立即失效
    return bind_or_lift(old_binding.cert, new_identity)
```

### IP-61 ACM：适配器证书、增量界与组合
```
def adapter_cert(adapter, base, dom, data_q):
    assert data_q.ok and adapter.provenance.verifiable
    # 零成本谱范数上界；更紧可用 IBP/CROWN
    layer_bound = (adapter.alpha / adapter.r) * spectral_norm(adapter.B) \
                  * spectral_norm(adapter.A) * activation_bound(dom)
    eps = downstream_lipschitz(base, adapter.layer) * layer_bound
    return AdapterCert(dom, data_q, eps, E=rank_energy(adapter),
                       v=hash(base.v, adapter.spec, data_q.hash),
                       T=monotonic_now() + adapter.ttl)

def can_reuse(cert, adapter_cert, x, theta):
    # 适配器吃掉的那部分 margin 必须显式记账
    return (x in adapter_cert.Dom and adapter_cert.Q.ok
            and cert.m - adapter_cert.eps >= theta)

def compose_ok(A, B, margin, theta):
    if disjoint(A.Dom, B.Dom):       return False
    if A.r + B.r > R_MAX:           return False
    # 组合必须在组合影子上实测，不能只把各自 eps 相加
    I = measure_interference(A, B, A.Dom & B.Dom)
    return A.eps + B.eps + I <= margin - theta
```

### IP-62 CRV：依赖图、足迹与增量再认证
```
def footprint(cdg, change):
    # 反向可达：所有(传递)依赖 change 节点的证书/租约
    return reverse_reachable(cdg, change)

def revalidate_incremental(cdg, change, criticality):
    F = footprint(cdg, change)
    for cert in sort_by_criticality(F, criticality):
        new = recertify(cert)             # 失败则单调降级
        if not new.sound:
            void_leases(cert)
            downgrade(cert)
    # 未受影响证书：版本未变且仍在 Dom 内 => 原样保留
    return F

def on_identity_event(event):
    cdg.add_edge(event.instance_id, event.certificate)   # 动作-环境边也要建
    return revalidate_incremental(cdg, event, criticality)
```

```
def lease_v3(x, theta, kappa, model_set, entity_binding):
    b = cert_lookup_L0(x)
    v_bind = hash(model_set.policy, model_set.perception, model_set.map)

def lease_valid_v3(lease, theta, t, cur):
    return (lease.m - lease.lam * (t - lease.tau) >= theta
            and lease.v_bind == cur.v_bind      # 换版即时失效
            and lease.h_bind == cur.h_bind)     # 重绑定即时失效

def transactional_swap(new_adapter):
    shadow = run_shadow(new_adapter, live_input)      # 双版本影子，同一条输入流
    if not shadow.zero_violation() or not ab_no_regression():
        return ROLLBACK
    epoch = bump_epoch_atomic()                       # 原子提交（复用 seqlock/epoch）

    assert epoch == current.epoch                     # 无混合版本可观测
```
