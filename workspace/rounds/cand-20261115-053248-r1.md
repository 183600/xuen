# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语音交互」×「多机评测」）

> R69 把不确定性一分为二，让单机学会「问」：aleatoric 沿 R68 铁律收紧，epistemic 交给「流匹配多模态策略 + 主动交互（看/问/触/等）」去消解。但它交付的「问」藏着三个未经审视的假设：
> **（a）问是私有的**——一次交互由一台机器发起、只被这台机器消费；
> **（b）证据是正交的**——所谓 k 个正交源（r_geo、r_sync、r_zero、r_emo、r_wm）其实共享同一个 MTM trunk、同一套传感器、同一次标定，误差高度相关，是「纸面正交」；
> **（c）回答是一个字符串**——冻结 LLM 把 g_ask 解码成文本，人一开口，语气、停顿、犹豫、以及「是谁在说」，全被压成一个 token 序列。
>
> R69 自陈的最大风险恰好卡在（b）上：**若流模型的模态分布不可信，VoI 就在错误信念上计算，系统会自信地追问一个幻影、或把一句误导性回答盖上「已验证」的章**。单机内的「k-一致」挡不住这个——因为骗它的和给它作证的，是同一个大脑、同一份训练数据。
>
> 本轮两个灵感正好拆掉这三个假设：
> - **语音交互**：人的回答不是文本，而是**言语行为**（speech act）——内容、韵律、时序、声源四位一体；韵律（prosody）是**独立于文本**的置信通道（嘴上说「是」，声音在发抖）；而语音本质是**广播**：一句话，在场所有机器同时听见。这把 R69 的「私有提问」变成「公开求证」，把「单模态文本证据」升级为「内容 × 韵律 × 声源」三重证据。
> - **多机评测**：机群不是更多算力，是**独立测量**——不同视角、不同传感器、不同本体，听同一句话、看同一个场景。多机评测把「离线一次性标定」变成**在线分布式校准**，并给出一件天然工具：**一个幻影若只有一台机器看见，就大概率是幻觉**。
>
> 核心命题：**R69 的「k 个正交证据源」应从「单机内多模态」升级为「跨机独立复算」；把一次语音提问当成一次广播，让机群各自独立解码、独立接地、独立验证；只有当多机误差真的不相关（有效证据数 N_eff ≥ k）时，合唱才是证据；当相关性过高、声源不可信或广播被投毒时，按三级阶梯逐级退化为 R69 单机、再退化为 R68 纯保守。** 命名 **CHORUS-RAS**（Collective Hearing & Orchestration for Uncertainty Resolution across a Swarm）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我一个人听到的算数吗——我该和谁一起听，又如何知道我们不是一起听错**」。

## 0. 直觉与动机

**灵感 1（语音交互 → 回答是有形状的言语行为）**
直觉：R69 的 g_ask 是一个软提示，经冻结 LLM 解码成问句；回答被当成一段文本塞进贝叶斯更新。但人类对话的信息远不止字面：同样一句「在左边」，说得干脆还是在迟疑、停顿多久、音量多高、是不是被问的那个人在说，含义可以完全相反。语音把回答从一个点变成一个**带置信度的信号包**。更关键的是，韵律与内容**可以互相验证**：内容说「确定」而韵律显露犹豫，恰恰是最有信息量的「不诚实/不确定」线索——这是文本通道永远拿不到的正交证据，正好补 R69 定义 300 里跨模态证据集的盲区。

**灵感 2（语音是广播 → 一次提问天然是多方求证）**
直觉：R69 的信息动作是「私有探针」——只有发起者消费结果。但语音是**开放信道**：机器人在走廊里问一句「这是您的杯子吗？」，三台在场的机器都听到了，也都能各自看各自的视角。这不是设计上的浪费，而是 R69 求之不得的**冗余**：同一句问话、同一个场景，被 N 个异构观测者独立接收，就得到 N 份可能相关的证据。R69 拼命在单机内部找正交源，其实真正的正交源一直站在旁边。

**灵感 3（多机评测 → 机群是一张在线标定表，不是一堆算力）**
直觉：R69 在定义 306 用 MCG 做模态校准，但校准是**离线、单机、一次性**的，遇到分布漂移就失效。多机评测把评测本身搬进闭环：每台机器在每个上下文上都被机群这个「移动参照系」持续打分，谁的标定开始偏离，就被即时识别——而且这种偏离不必是「被多数否决」，可以是被**诊断为故障**（接回 R68/R69 的缓变故障检测）。评测从「赛后的排行榜」变成「赛中的体温计」。

**灵感 4（合题 → 有效证据数：合唱与回声的分界）**
直觉：R69 的错误在于把「k 个通道」当成「k 份独立证据」。真正的独立性要用**误差相关性**度量：N 台机器若错误完全相关（同一基础模型、同分布训练、同一仿真器），它们一致同意只等于**一台机器说了 N 遍**。定义有效证据数 N_eff = N / (1 + (N−1)ρ̄)：ρ̄→1 时 N_eff→1，再多的克隆也只是回声；ρ̄→0 时才是真合唱。本轮最重要的理论姿态是：**把「多机」从信仰变成可测量的量**——先估计 ρ̄，再决定这次共识到底值几票。

**灵感 5（双刃剑 → 新的攻击面与新的自欺）**
直觉：一旦会「广播着问」，攻击面同时放大：（i）一句投毒的话，全机群同时中招（广播放大）；（ii）重放/合成语音冒充权威；（iii）多机若同源，会以更高置信度**一起错**——「齐声错」比「单声错」更难被外部发现；（iv）多机评测本身会 Goodhart：机群以自身共识为标尺，可能收敛到共享的错信念，把回声室误认作真理。所以本轮必须同时交付：声源认证与防重放、误差相关性在线估计、跨机幻影判别、以及「评测不得以自身共识为唯一真值」的外部锚定纪律。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CHORUS-RAS 总览）** CHORUS-RAS = (FMP†, APD, CHOIR, CAL-F, FME, VOC, CON, RAS-WM†)。五条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **广播预算硬约束**：全机群单位时间至多一次语音提问、至多一台「指挥机」发言、物理位移 ≤ ε_g、社交打扰成本 ≤ c_max，信息动作仍过 C-RAS-WM 认证；
(iii) **声源纪律**：回答只有在声源被认证为「被问对象」时才可计入（定义 318），旁观者/重放/合成语音不计票；
(iv) **独立证据纪律**：至少 k 台机器独立解码且一致，且有效证据数 N_eff ≥ k（定义 314），否则视为单源、退化 R69；
(v) **外部锚定纪律**：多机评测的参照系不得仅为机群自身共识，必须周期性地对照外部真值/随机审计（定义 324）。

**定义 311（语音动作与言语行为）** 扩展 R69 定义 294 的增广动作。语音动作 g_voice = (q_content, q_prosody, q_addr)：q_content ∈ ℝ^{d_q}（问句内容软提示）、q_prosody ∈ 𝒫 ⊂ ℝ^4（音高、语速、能量、停顿，即「怎么问」）、q_addr ∈ Δ^N（在多主体场景中选择向谁问）。一次回答是言语行为 r = (r_text, r_prosody, r_speaker, r_time)：文本假设、韵律特征、声源指纹、到达时刻。ASR 给出同音后验 p(w | audio)，而非单一字符串。

**定义 312（语音不确定性二分 APD）** 在声学层镜像 R69 定义 297：U_ale^ASR = E_{w}[H(audio|w)]（不可约的声学噪声），U_epi^ASR = H(w|audio)（可约的同音/语境歧义，可由视唇、语义、跨机上下文消解）。另定义**韵律-内容一致性** κ = 1 − d(r_prosody, μ_prosody(r_text))，其中 μ_prosody 为该文本在训练语料上的典型韵律；κ 低 = 嘴上确定但声音犹豫。κ 是**文本之外的独立证据通道**，若 κ 低且 r_text 断言高置信，则触发「不诚/不确定」标记，不允许该回答单独定案。

**定义 313（多机接收模型）** 机群 𝔐 = {M_1,…,M_N}，每台机器有接收-解码算子 D_i（不同麦克风阵列、位置、ASR、视觉）。同一广播 r 得到 N 个假设 {r_i = D_i(audio, o_i)}。定义**逐对一致度** a_ij = 1[r_i ≈ r_j]，聚合一致度 A = (2/(N(N−1)))Σ_{i<j} a_ij。注意：一致不等于正确；A 只有在独立性成立时才是证据。

**定义 314（有效证据数 N_eff）** 由历史错误序列估计逐对误差相关 ρ̄ = mean_{i<j} Corr(err_i, err_j)。定义 N_eff = N / (1 + (N−1)ρ̄)，即流行病学中的设计效应（design effect）在证据计数上的对偶。**证据纪律升级为 N_eff ≥ k**：同样「N 台一致」，ρ̄=0.9、N=5 时 N_eff≈1.09，只值一票；ρ̄=0、N=3 时 N_eff=3。这条定义把「多机」从口号变成了可核验的量，也是本轮对 R69「纸面正交」的正面修正。

**定义 315（相关感知共识 CHOIR）** 给定各机对 R69 模态身份 M 的后验 {p_i(M)}，不直接朴素相乘（会重复计算相关证据），而引入共享潜变量 c（共同致错因子）：p_i(M) = Σ_c p_i(M|c) p(c)，在 c 上做层次贝叶斯聚合，输出**共识后验** p̄(M) 与**分歧图** Diss(i) = D_KL(p_i ‖ p̄)。分歧不是要被抹平的噪声，而是定位「哪台机器开始不可信」的指纹；Diss 高者进入 CAL-F 复核。

**定义 316（在线多机评测 CAL-F）** 维护每台机器在上下文类别 g 上的相对标定误差 ECE_i(g)，参照系为「扣除该机后的其余机群共识」（leave-one-out，避免自我参照）。机器 M_i 在 g 上「获证」⇔ ECE_i(g) ≤ τ_ece ∧ 其 Diss 在正常带内。获证是**按上下文分片**的，不搞全局一票通过——一台机器可以在「走廊」获证而在「手术灯下」失证。CAL-F 取代 R69 MCG 的一次性离线校准。

**定义 317（跨机幻影判别 FME）** R69 定义 301 的流似然第二意见只回答「行为是否自洽」。一个被流模型幻觉出的模态 m_k（幻影）是**物理上可被独立观测否证的**：若 m_k 真实存在，其他机器在各自视角上也应能以高于机会的置信度观测到它。定义跨机佐证分 C(m_k) = (1/(N−1))Σ_{i≠asker} conf_i(m_k | o_i)。**幻影判据：C(m_k) < τ_corr 且 flow 似然给出的模态权重高**。这是对 R69 最大风险的直接手术：单机幻觉在机群层面留下「孤立」的指纹。

**定义 318（声源认证与防重放 VOC）** 每个回答需通过：声纹匹配（r_speaker 是否为 q_addr 指定者）、活体检测（抗重放：随机挑战-应答、呼吸/微颤等）、空间一致性（声源方位与视觉/机群三角定位一致）。任一不过 ⇒ 该回答**不计票**，U_epi 保持未消解。VOC 把「谁在说」变成与「说了什么」「怎么说」并列的第一类证据。

**定义 319（语音信道攻击集 ℰ_VOICE）** 同音对抗措辞、录音重放、语音合成/深伪冒充、背景注入掩蔽、多人社交工程、耳语/偷听者冒认、**广播投毒**（一句污染全体）、**合唱劫持**（冒充权威指挥多机）。并入 AIC：ℰ_CHORUS = ℰ_FLUID × ℰ_VOICE × ℰ_fleet（同源相关失败 / 共识漂移 / 评测 Goodhart）。

**定义 320（指挥与轮次 CON）** 全机群同一时刻至多一台指挥机发言：asker* = argmax_i VoI_i(g) − c_i(g)，其余机器静默但**保持收听与观测**（静默不代表缺席，它们的独立解码正是证据）。指挥权按轮次与信道质量转移，避免固定单点成为攻击靶。轮次纪律：对同一问题不重复广播超过一次，除非出现 Diss 突增。

**定义 321（证书 J_CHORUS）** J_CHORUS = (J_FLUID, N_eff, ρ̄, A, κ, C(m_k), ECE_i(g)_{获证分片}, speaker_provenance, fleet_drift, anchor_ok, chorus_ver)。Valid ⇔ Valid(J_FLUID) ∧ 声源认证通过 ∧ N_eff ≥ k ∧ 外部锚定未过期 ∧ 三级退避未触发（定义 322）。

**定义 322（三级退避）** L0 全合唱：N_eff ≥ k 且声源可信 ⇒ 按 CHOIR 共识定案。L1 退 R69 单机：N_eff < k 或 ρ̄ 过高 ⇒ 放弃「多机」错觉，回到 R69 的单机多模态交互（此时明确只值一票）。L2 退 R68 纯保守：声源不可信/重放嫌疑/广播投毒嫌疑/共识不可得 ⇒ 不采纳任何语音证据，λ = λ_floor(U_ale + U_epi)，纯保守。退避方向单调：安全侧永不弱于上一级。

**定义 323（回声室检测）** 机群共识的独立性不能自证。定义回声室指标 E = N_eff / N。若 E 长期低于 τ_echo 而系统仍按「N 台一致」提高置信，即判定为回声室；此时强制注入异质证据源（不同模态、不同本体、或人类外部裁决），否则禁止提升置信。

**定义 324（Goodhart 防护与外部锚定）** 多机评测不得以「机群自身多数」为唯一真值。要求：（i）周期性对照**外部锚**（人工标注、物理测量、随机审计样本）；（ii）使用留一机评测与held-out上下文，防止机群对自身共识过拟合；（iii）评测指标包含**分歧率**与**N_eff**，而非只有一致率——一致但同源，是危险信号而非成绩。

**定义 325（时序与预算）** 默认 N=3、k=2。仅在 MINT 报高 VoI 时广播一次；VOC 与 ASR 解码并行（< 主导航预算）；CHOIR 聚合 O(N²) 仅在分歧时触发。广播是单次事件，接收是多机并行，故延迟由最慢的认证链决定，而非 N 倍。

**定义 326（单机-机群对偶）** R69 的「单机内 k 个正交模态」与 R70 的「机群内 N 台独立机器」构成对偶：前者以**模态**为证据轴，后者以**机器**为证据轴。R69 恰为 N=1 或 ρ̄=1（完全同源）时的退化，R70 在 N_eff → 1 时逐指令回到 R69；二者共享同一套 VoI、同一套 ale/epi 二分、同一套 C-RAS-WM 认证。这是本轮「新层必须是旧层严格泛化」的落点。

## 2. 关键算法骨架

```python
# IP-264 VOICE：语音动作与言语行为表示（扩展 R69 的 g_ask）
class SpeechAct:
    def __init__(self, asr, prosody_enc, speaker_id, liveness):
        self.asr, self.prosody = asr, prosody_enc      # 同音后验 + 韵律编码
        self.speaker, self.live = speaker_id, liveness # 声纹 + 活体

    def ask(self, q_content, q_prosody, q_addr):
        q = self.llm_decode(q_content)                 # 冻结 LLM，仅解码文本
        return self.tts(q, prosody=q_prosody), q_addr  # 广播：怎么问 + 问谁

    def receive(self, audio, o_i):                     # 每台机器独立执行
        w  = self.asr.posterior(audio)                 # p(w|audio)，非单串
        pr = self.prosody(audio)
        sp = self.speaker.verify(audio)
        lv = self.live.check(audio)                    # 抗重放/深伪
        return SpeechActResult(w, pr, sp, lv, o_i)

# IP-265 APD：声学层 aleatoric / epistemic 分解 + 韵律-内容一致性
def acoustic_decompose(res):
    U_ale = expected_entropy(res.w, res.audio)         # 不可约声学噪声
    U_epi = entropy(res.w)                             # 可约同音/语境歧义
    kappa = 1.0 - prosody_distance(res.pr, typical_prosody(res.w))
    return U_ale, U_epi, kappa                         # kappa 低 => 不诚/不确定嫌疑

# IP-266 CHOIR：相关感知的多机共识（不朴素相乘）
def choir_consensus(posteriors, rho_hat):
    N = len(posteriors)
    N_eff = N / (1.0 + (N - 1) * rho_hat)              # 定义 314 的设计效应
    # 层次贝叶斯：共享共同致错因子 c，避免相关证据被重复计票
    post_bar = hierarchical_aggregate(posteriors, shared_cause=c_latent)
    dissent  = {i: kl(posteriors[i], post_bar) for i in range(N)}
    return post_bar, N_eff, dissent

# IP-267 CAL-F：在线、留一机、按上下文分片的标定
def fleet_calibrate(machines, context):
    for i, m in enumerate(machines):
        ref = consensus(machines, exclude=i)           # 留一机参照
        ece = calibration_error(m, ref, context)
        m.certified[context] = (ece <= TAU_ECE) and (m.diss[context] < TAU_DISS)

# IP-268 FME：跨机幻影判别（补 R69 流似然的盲区）
def phantom_score(modality, asker, machines, o):
    corr = mean(conf_i(modality, o[i]) for i in machines if i is not asker)
    return corr < TAU_CORR                           # 只有 asker 看见 => 疑似幻影

# IP-269 VOC + 三级退避：声源可信度决定证据是否计票
def gate_and_fallback(answers, machines, rho_hat):
    valid = [a for a in answers if a.speaker_ok and a.live_ok and a.space_ok]
    if not valid:                     return 'L2', None        # 全部不可信
    post, N_eff, diss = choir_consensus([a.post for a in valid], rho_hat)
    if N_eff < K_REQ or rho_hat > RHO_MAX:  return 'L1', post  # 退 R69 单机
    return 'L0', post

# IP-274 CHORUS 主闭环（继承 R69，仅在「问」与「证据计数」两处替换）
def CHORUS_RAS_round(fleet, obs):
    asker = conductor_select(fleet, obs)               # 定义 320：唯一指挥机
    z, o  = asker.mtm.forward(obs)
    c, U_cal, thr = asker.cof.step(...)                # R68 标定
    K     = 1 if asker.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = asker.aud.decompose(asker.fmp.sample(o, K), z)
    # 1) 单机仍先做 R69 的 VoI；但只有高 VoI 才广播
    g = asker.mint.choose_interaction(modes, o, asker.budget)
    if g is not None:
        audio, q_addr = asker.voice.ask(g.content, g.prosody, g.addr)
        # 2) 广播：多机各自独立收、独立解（静默机也是证据）
        results = [m.voice.receive(audio, obs[i]) for i, m in enumerate(fleet)]
        results = [r for r in results if r.speaker_ok and r.live_ok]  # VOC 计票
        # 3) 声学二分 + 韵律一致性 + 跨机共识
        for r in results: r.U_ale, r.U_epi, r.kappa = acoustic_decompose(r)
        rho_hat = fleet.estimate_error_corr()
        level, post = gate_and_fallback(results, fleet, rho_hat)
        # 4) 幻影判别：只有一台看见的模态不许定案
        if any(phantom_score(mk, asker, fleet, obs) for mk in modes):
            level = 'L2'
        if level == 'L0':
            U_epi = post.entropy()
            U_epi = asker.cia.update_belief(modes, post, discipline='N_eff>=k')
        elif level == 'L1':
            U_epi = asker.cia.update_belief(modes, results[0].post, discipline='single')
        else:
            U_epi = U_epi                               # L2：完全不采纳语音证据
    # 5) 风险缩放：与 R69 定义 307 完全一致的退化式
    slow = asker.fma.flow_anomaly(...) > TAU_FMA and asker.last_r_res < TAU_RES
    U_floor = U_ale + (U_epi if g is None or U_epi > 0 else 0.0)
    lam = max(asker.efs.risk_scale(...), lam_floor(U_floor))
    if slow: lam = max(lam, 0.8)
    mode = select_mode(modes, U_epi, lam)
    tau  = asker.pi_sigma.prefix_dispatch(mode.a[:k_prefix]) * lam
    # 6) 审计：共识是否真独立？是否回声室？
    asker.echo_auditor.submit_async(level, rho_hat, N_eff, diss, results)
    return k_prefix, lam, mode, (U_ale, U_epi, level)

## 3. 推导

**引理 19（有效证据与相关失败的界）** 设 N 台机器对同一二元模态的判断，单机错误率 δ，逐对错误相关 ρ。则多数表决错误率 p_err(N, ρ) 满足：ρ=0 时 p_err 随 N 指数下降；ρ→1 时 p_err → δ（不下降）。而 N_eff = N/(1+(N−1)ρ) 恰为等效独立机数。要点：**多机只在 ρ < 1 时才买得到置信**；同源机群（ρ≈1）无论 N 多大都等价于单机。系：R69 的「k 个机械臂内模态」若共享 trunk，其 ρ 接近 1，所谓正交是幻觉；R70 必须先测 ρ 再谈取证。

**引理 20（韵律-内容正交增益）** 设内容通道与韵律通道对「不诚/不确定」的检测错误率分别为 ε_c、ε_p，二者条件独立（韵律不易被文本伪造）。则串联检测错误率 ≤ ε_c·ε_p + ε_σ；即使单通道很弱（ε=0.3），双通道也可把漏检压到 ~0.09。系：**κ（韵律-内容一致性）是文本之外唯一难以被语言模型幻觉伪造的通道**——它不经过 LLM 解码，直接来自声学。

**引理 21（声源认证的误纳上界）** 在活体挑战-应答 + 声纹 + 空间三角定位三重校验下，重放/合成语音的误纳率 ≤ ε_voc = ε_live + ε_spk + ε_geo（各判据近似独立时取乘积加残差）。系：VOC 把「谁在说」变成可证伪的第一类证据，堵住 R69 中「一句误导被盖章」的最短路径。

**定理 18（CHORUS 严格包含 R69）** 在 A99–A101 下，CHORUS 在任意状态的期望风险 ≤ R69；当 N=1、ρ̄ ≥ ρ_max（退 L1）、声源认证失败/广播投毒疑（退 L2）、或回声室检测告警时，CHORUS 与 R69 **逐指令一致**（定义 322、326）。因此 R69 是 CHORUS 在「无可用独立机群」边界上的退化：安全侧不做任何让步，效率侧只在 N_eff 真实时获得「多机置信」。证明要点：L1 直接调用 R69 单机路径；L2 把 U_epi 全部并入 λ_floor，等于 R68 的保守；L0 只改变模态选择的后验来源，不改变安全包络与认证前缀。

**定理 19（合唱放大与回声室不可自证）** 设机群共享共同致错因子 c 的方差占比为 γ。则合唱可将「共同错误」的置信从单机的 1−δ 抬到 1−δ^N（看似更强），但**该提升完全来自相关部分，是虚假置信**；当 E=N_eff/N < τ_echo 时，系统无法仅凭自身观测区分「N 台独立同意」与「N 台一起错」，必须引入外部锚（定义 324）。系：**合唱的风险不是「错」，而是「错得更自信、更一致、更难被外部察觉」**——这与 R69 的「问错比不问更危险」同构，却更隐蔽。

**定理 20（幻影的跨机否证性）** 若被流模型幻觉的模态 m_k 在物理场景中不存在，则其被其他机器独立观测到的期望置信度 ≤ 机会水平 + 噪声；故 C(m_k) < τ_corr 以高概率成立。反之真实模态在多视角下 C(m_k) 有下界。因此**跨机佐证是幻影的可证伪判据**，补上 R69 单机流似然只能测「行为自洽」、不能测「物理存在」的盲区。

## 6. 本轮最大风险

**一句话**：CHORUS-RAS 把全部增益押在「多机是独立的」这一前提上，而**独立性是一个需要被估计、却极易被高估的量**——当机群共享同一基础模型、同分布训练、同一场景数据时，ρ̄≈1、N_eff≈1，合唱退化为回声：系统会把「一群克隆互相印证」当成「多源验证」，在**共享幻觉**或**一次广播投毒**上以更高置信度做出更一致、更难被外部察觉的错误决定——**齐声错，比单声错更危险**。

**次级风险与缓解**：
1. **同源相关失败被误当独立** → 在线估计 ρ̄、以 N_eff 而非 N 计票、E=N_eff/N 回声室告警、强制异质证据源（定义 314、323）；

3. **多机评测 Goodhart / 共识漂移** → 外部锚定 + 留一机 + held-out 上下文 + 指标含分歧率（定义 324）；
4. **声学幻觉与同音误导** → APD 二分 + κ 韵律不一致标记 + 视唇/跨机上下文消歧（定义 312）；
5. **实时预算被广播认证链拖垮** → ASR/VOC/韵律并行 + CHOIR 仅分歧触发 + 默认 N=3, k=2（定义 325）。

class SpeechAct:
    def ask(self, q_content, q_prosody, q_addr):
        return self.tts(self.llm_decode(q_content), q_prosody), q_addr
    def receive(self, audio, o_i):
        return SpeechActResult(self.asr.posterior(audio),
                               self.prosody(audio),
                               self.speaker.verify(audio),
                               self.live.check(audio), o_i)   # 抗重放/深伪

# IP-265 APD：声学 ale/epi 二分 + 韵律-内容一致性
def acoustic_decompose(res):
    U_ale = expected_entropy(res.w, res.audio)
    U_epi = entropy(res.w)
    kappa = 1.0 - prosody_distance(res.pr, typical_prosody(res.w))
    return U_ale, U_epi, kappa

# IP-266 CHOIR：相关感知共识（不朴素相乘）
def choir_consensus(posteriors, rho_hat):
    N = len(posteriors)
    N_eff = N / (1.0 + (N - 1) * rho_hat)                    # 定义 314
    post_bar = hierarchical_aggregate(posteriors, shared_cause=c_latent)
    dissent  = {i: kl(posteriors[i], post_bar) for i in range(N)}
    return post_bar, N_eff, dissent

# IP-268 CAL-F：留一机、按上下文分片的在线标定
def fleet_calibrate(machines, context):
    for i, m in enumerate(machines):
        ref = consensus(machines, exclude=i)
        m.certified[context] = (calibration_error(m, ref, context) <= TAU_ECE
                                and m.diss[context] < TAU_DISS)

# IP-269 FME：跨机幻影判别（只有 asker 看见 ⇒ 疑似幻觉）
def phantom_score(modality, asker, machines, o):
    return mean(conf_i(modality, o[i]) for i in machines if i is not asker) < TAU_CORR

# IP-270/272 三级退避：声源可信度决定证据是否计票
def gate_and_fallback(results, machines, rho_hat):
    valid = [r for r in results if r.speaker_ok and r.live_ok and r.space_ok]
    if not valid: return 'L2', None
    post, N_eff, diss = choir_consensus([r.post for r in valid], rho_hat)
    if N_eff < K_REQ or rho_hat > RHO_MAX: return 'L1', post
    return 'L0', post

# IP-275 CHORUS 主闭环（继承 R69，仅替换「问」与「证据计数」）
def CHORUS_RAS_round(fleet, obs):
    asker = conductor_select(fleet, obs)                     # 唯一指挥机
    z, o = asker.mtm.forward(obs); asker.cof.step(...)
    K = 1 if asker.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = asker.aud.decompose(asker.fmp.sample(o, K), z)
    g = asker.mint.choose_interaction(modes, o, asker.budget)
    if g is not None:
        audio, q_addr = asker.voice.ask(g.content, g.prosody, g.addr)
        results = [m.voice.receive(audio, obs[i]) for i, m in enumerate(fleet)]
        for r in results: r.U_ale, r.U_epi, r.kappa = acoustic_decompose(r)
        rho_hat = fleet.estimate_error_corr()
        level, post = gate_and_fallback(results, fleet, rho_hat)
        if any(phantom_score(mk, asker, fleet, obs) for mk in modes): level = 'L2'
        if   level == 'L0': U_epi = asker.cia.update_belief(modes, post, 'N_eff>=k')
        elif level == 'L1': U_epi = asker.cia.update_belief(modes, results[0].post, 'single')
    slow = asker.fma.flow_anomaly(...) > TAU_FMA and asker.last_r_res < TAU_RES
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(asker.efs.risk_scale(...), lam_floor(U_floor))
    if slow: lam = max(lam, 0.8)
    mode = select_mode(modes, U_epi, lam)
    tau  = asker.pi_sigma.prefix_dispatch(mode.a[:k_prefix]) * lam
    asker.echo_auditor.submit_async(level, rho_hat, N_eff, diss, results)
    return k_prefix, lam, mode, (U_ale, U_epi, level)
```

## 4. 推导

**引理 19（有效证据与相关失败的界）** N 机对二元模态判断，单机错误率 δ、逐对错误相关 ρ。ρ=0 时多数表决错误随 N 指数下降；ρ→1 时错误 → δ（不下降）。`N_eff=N/(1+(N−1)ρ)` 恰为等效独立机数。系：多机只在 ρ<1 时才买得到置信；同源机群（ρ≈1）无论 N 多大都等价于单机，R69 的「机内 k 模态」若共享 trunk，其 ρ 接近 1，所谓正交是幻觉。

**引理 20（韵律-内容正交增益）** 内容通道与韵律通道对「不诚/不确定」检测错误率 ε_c、ε_p，条件独立时串联错误率 ≤ ε_c·ε_p + ε_σ。即使单通道 ε=0.3，双通道漏检可压到 ~0.09。系：κ 不经过 LLM 解码、直接来自声学，是文本之外最难被语言模型幻觉伪造的通道。

**引理 21（声源认证误纳上界）** 活体挑战-应答 + 声纹 + 空间三角定位三重校验下，重放/合成语音误纳率 ≤ ε_voc = ε_live + ε_spk + ε_geo（近似独立时取乘积加残差）。系：VOC 堵住 R69「一句误导被盖章」的最短路径。

**定理 18（CHORUS 严格包含 R69）** A99–A101 下，CHORUS 任意状态期望风险 ≤ R69；当 N=1、ρ̄≥ρ_max（L1）、声源失败/投毒疑（L2）、或回声室告警时，两者逐指令一致。R69 = 「无可用独立机群」边界；安全不让步，效率仅在 N_eff 真实时获得多机置信。

**定理 19（合唱放大与回声室不可自证）** 共享共同致错因子方差占比 γ 时，合唱把「共同错误」置信从 1−δ 抬到 1−δ^N（虚假置信），该提升完全来自相关部分；当 E=N_eff/N<τ_echo，系统无法仅凭自身观测区分「N 台独立同意」与「N 台一起错」，必须引入外部锚。系：合唱的风险不是「错」，而是「错得更自信、更一致、更难被外部察觉」。

**定理 20（幻影的跨机否证性）** 若幻觉模态 m_k 物理不存在，其被其他机器独立观测的期望置信 ≤ 机会水平+噪声，故 `C(m_k)<τ_corr` 以高概率成立；真实模态在多视角下有下界。因此跨机佐证是幻影的可证伪判据，补上 R69 单机流似然只能测「行为自洽」的盲区。

## 7. 本轮最大风险

**一句话**：CHORUS-RAS 把全部增益押在「多机是独立的」这一前提上，而**独立性是一个需要被估计、却极易被高估的量**——当机群共享同一基础模型、同分布训练、同一场景数据时，ρ̄≈1、N_eff≈1，合唱退化为回声：系统会把「一群克隆互相印证」当成「多源验证」，在**共享幻觉**或**一次广播投毒**上以更高置信度做出更一致、更难被外部察觉的错误决定——**齐声错，比单声错更危险**。

**次级风险与缓解**：同源相关失败被误当独立（在线估 ρ̄、以 N_eff 计票、E=N_eff/N 回声室告警、强制异质源）；广播投毒/合唱劫持（VOC 声源认证 + 指挥轮换 + 单次广播预算 + ℰ_VOICE 对抗训练）；多机评测 Goodhart/共识漂移（外部锚定 + 留一机 + held-out + 指标含分歧率）；声学幻觉与同音误导（APD 二分 + κ 不一致标记 + 视唇/跨机上下文消歧）；实时预算被认证链拖垮（ASR/VOC/韵律并行 + CHOIR 仅分歧触发 + 默认 N=3,k=2）。
