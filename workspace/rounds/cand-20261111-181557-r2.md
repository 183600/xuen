# 第 56 轮（承接第 55 轮 v32 GroundEdge-GenSim++++；灵感循环第 2 轮；本轮灵感：「快速原型」×「竞赛策略」）

> 第 55 轮把视角下探到“接触语义可信、全身可行”，产出了语义-接触证书体系。本轮把视角从“方案是否正确”拉回到 **“在有限竞赛窗口内，哪些正确性值得先做、做到什么程度、如何对对手与规则下注”**。核心矛盾：**H24**：证书体系越严密，原型迭代越慢（证据债累积），而竞赛的边际收益常来自“更早拿到可测原型 × 命中评分断崖”，soundness 在时间预算下会从资产变成负债；**H25**：竞赛得分是相对排名与评分函数（阈值/奖励/罚分）的函数，不是单机性能的单调函数，故“技能最优”不等于“竞赛最优”，策略必须对评分函数与对手行为同时鲁棒。

## 0. 直觉与动机

**灵感 1（快速原型 → 原型是“最小可证伪实验”，不是缩小版产品）**
直觉：原型的目的不是“先做个能跑的”，而是“用最小代价把某个证书条款打成假”。第 55 轮的每条假设（A29–A32）都能对应一个最小可证伪实验 MFE：针对“边界置信过度自信”，最小原型是“把脚掌压到合成边界上，测一次接触失败率”，而不是先搭一台完整全身机。于是原型的价值 = 单位时间内的证伪信息量，而非完成度；完成度应被视为“信息量的副产品”。

**灵感 2（快速原型 → 证书驱动的原型路由器 CPR）**
直觉：面对几十条待验证条款，人不会平均用力，而会把下一个原型投给“最可能错、错了最致命、且最便宜”的那一条。形式化为对证书条款做主动实验设计：以证据状态 `e` 为状态，以“期望信息增益 / 时间”为准则路由。这把上一轮充当“门禁”的证书改造成“原型导航仪”——证书不只说“不许上线”，更说“下一个该做哪个实验”。

**灵感 3（竞赛策略 → 评分函数反演与“得分断崖”）**
直觉：竞赛评分常是非光滑的——越过阈值有 bonus、超时有 penalty、单项满分封顶。最优不是把某项从 0.70 拉到 0.75，而是把另一项从 0.49 推到 0.51 以跨过低分断崖。需要在线反演评分函数 `S(y)` 的局部斜率与断崖位置，用“边际得分密度 MSD = ΔS / Δ(原型小时)”来分配精力，而非按“技术优雅度”分配。

**灵感 4（竞赛策略 → 对手感知的鲁棒原型组合）**
直觉：排名是相对的，对手会针对当前领跑方案调整。原型组合不该只最大化我方分数，而应在对手策略集合上做极小极大 / 最小后悔：`max_π min_o E[U(π,o)]`。同时规则可能微调（评分权重变化），组合要对“规则扰动球”稳健，避免把全部原型预算押在一条规则漏洞上——漏洞一旦被补，整套原型归零。

**灵感 5（快速原型 × 竞赛策略 → 原型-验证-部署三元调度）**
直觉：竞赛窗口 `T` 内只有三类动作争夺时间：**探索**（做新原型）、**验证**（用第 55 轮证书体系做 soundness 检查）、**部署**（打磨、联调、稳定性）。这本质是带安全约束的有限时域 MDP：早期多探索、临近截止多部署、核心安全项永远保留“验证保险”。第 55 轮的所有证书在此降格为“验证动作的代价与收益”，而不是贯穿全流程的硬门禁——这正是从“研究正确性”转向“竞赛可竞争性”的关键一步。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（最小可证伪实验 MFE）**
证书条款集 `Φ = {φ_i}`。原型 `p` 表示为实验三元组 `(x_p, E_p, c_p)`：输入分布、可观测量、成本（小时/算力）。对条款 `φ` 的判别信息量
`IG(p, φ) = H(e_φ) - E_{E_p}[H(e_φ | E_p)]`，
最小可证伪实验 `MFE(φ) = argmin_p c_p  s.t.  IG(p,φ) ≥ θ_IG`。原型价值密度 `v(p)=IG(p,φ)/c_p`。

**定义 128（证据状态与证据债）**
证据状态 `e: Φ → {unknown, supported, refuted, stale}`（带置信与时间戳）。证据债
`D(e) = Σ_i w_i · u(e_i)`，其中 `u` 为不确定性（unknown/stale 高，近期 supported/refuted 低），`w_i` 为条款的部署关键度。**可部署**当 `D(e) ≤ Θ_D` 且核心条款无 `refuted`。

**定义 129（竞赛评分反演）**
真实评分 `S: Y → ℝ`，`Y` 为性能向量。通过代理测试与排行榜查询得估计 `Ŝ`。边际得分密度
`MSD(p) = E[ (∂S/∂y)·(∂y/∂p) ] / c_p`。
得分断崖集 `𝒞 = { y | ∇S 不连续 或 |∇S| ≥ θ_cliff }`。

**定义 130（鲁棒原型组合与对手博弈）**
组合 `π ∈ Δ(𝒫)`，对手策略 `o ∈ O`，效用 `U(π,o)`（相对排名或分差）。鲁棒组合
`π* = argmax_π [ min_{o∈O} E[U(π,o)] - λ·Regret(π) ]`。
在规则扰动球 `B_rule(ε_r)` 上要求 `min_{r∈B_rule} U(π,r) ≥ ρ_comp`，得“可竞争性谱” `ρ_comp`。

**定义 131（原型-验证-部署三元调度 PVD）**
状态 `z=(e, Ŝ, t_left)`，动作 `a ∈ {explore, verify, exploit, stop}`，转移由实验与部署结果驱动，奖励为竞赛得分增量，安全约束沿用第 55 轮证书的违约预算：
`V(z) = max_a E[ r(z,a) + V(z') ]  s.t.  P(violation) ≤ δ_safe`。
验证动作 `verify` 直接调用第 55 轮的 `J_s` 门禁，其成本即证书计算开销。

**定义 132（可竞争性证书 CCC）**
`C_ccc = (π*, e_core, D(e_core), MSD_lb, Regret_ub, ρ_comp, evidence_log)`。
若 `e_core` 无核心 `refuted`、`D(e_core) ≤ Θ_D`、`MSD_lb > 0`、`Regret_ub ≤ Θ_R` 且 `ρ_comp ≥ ρ_min`，则称 **可竞争（competition-ready）**。它比“可部署”更弱、更面向排名：允许 `unknown`，但绝不允许核心条款已被证伪。

## 2. 关键算法 伪代码

### IP-127 MFE（Minimum Falsification Experiment）

```python
def minimal_falsification_experiment(phi, prototypes, theta_ig):
    best = None
    for p in prototypes:
        ig = expected_info_gain(p, phi)          # 由先验/历史证据估计
        if ig >= theta_ig and (best is None or p.cost < best.cost):
            best = p
    return best                                   # 单位成本最省的“能打假 phi”的原型
```

### IP-128 CPR（Certificate-driven Prototype Router）

```python
def certificate_router(evidence, clauses, prototypes, budget_t):
    while budget_t > 0:
        scores = {}
        for phi in clauses:
            if evidence[phi].state in ('supported', 'refuted') and not stale(phi):
                continue
            p = minimal_falsification_experiment(phi, prototypes, theta_ig)
            if p is not None:
                scores[phi] = relevance(phi) * expected_info_gain(p, phi) / p.cost
        if not scores:
            break
        phi = argmax(scores)
        p = minimal_falsification_experiment(phi, prototypes, theta_ig)
        run(p)
        evidence = update_evidence(evidence, p)
        budget_t -= p.cost
    return evidence
```

### IP-129 SCR（Score-Cliff Regression）

```python
def score_cliff_regression(proxy_results, leaderboard):
    S_hat, grad = fit_monotone_surrogate(proxy_results)
    cliffs = set()
    for y, s in leaderboard:
        if residual(S_hat, y, s) > theta_res:
            cliffs |= localize_discontinuity(S_hat, y)   # 阈值/bonus/penalty
    return S_hat, grad, cliffs
```

### IP-130 RPP（Robust Prototype Portfolio）

```python
def robust_prototype_portfolio(prototypes, opponents, rule_ball, lam):
    best, best_val = None, -float('inf')
    for pi in candidate_portfolios(prototypes):
        worst = min(expected_utility(pi, o) for o in opponents)
        val = worst - lam * regret(pi) - rule_penalty(pi, rule_ball)
        if val > best_val:
            best, best_val = pi, val
    return best
```

### IP-131 PVD（Prototype-Verify-Deploy Scheduler）

```python
def pvd_schedule(state, T_left, certificates, safety_budget):
    if T_left <= 0:
        return 'stop'
    values = {}
    for a in ('exploit', 'verify', 'explore', 'stop'):
        if a == 'verify' and not needs_verification(certificates):
            continue
        if a == 'explore' and state.evidence_debt < Theta_D:
            continue
        values[a] = value_estimate(state, a, T_left, safety_budget)
    return argmax(values)
```

### IP-132 CCC（Competitiveness Certificate）

```python
def competitiveness_certificate(evidence, portfolio, score_model, budgets):
    core = critical_clauses(evidence)
    if any(evidence[phi].state == 'refuted' for phi in core):
        return ('reject', 'core_refuted')
    D = evidence_debt(evidence)
    if D > budgets.Theta_D:
        return ('reject', 'evidence_debt', D)
    msd = lower_bound_msd(portfolio, score_model)
    if msd <= 0:
        return ('reject', 'no_marginal_score')
    reg = worst_case_regret(portfolio)
    if reg > budgets.Theta_R:
        return ('reject', 'regret_bound', reg)
    return ('ok', CompCert(portfolio, core, D, msd, reg, evidence_log(evidence)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MFE | O(|P|·|Φ|) | O(|P|) | 信息增益估计校准、成本可比 |
| CPR | O(B·|Φ|·|P|) | O(|Φ|) | 证据更新无偏、stale 判定 |
| SCR | O(N_proxy·d + N_lb) | O(d) | `Ŝ` 单调、断崖召回 |
| RPP | O(|Π|·|O|) | O(|Π|) | 对手集 ε_O-覆盖、规则球紧致 |
| PVD | O(T·|A|·|Z|) | O(|Z|) | 有限时域近似、安全预算闭合 |
| CCC | O(|Φ|+|Π|) | O(|Φ|) | 核心条款完备、后悔界可复现 |

**正确性定理（Competition-Readiness Soundness）**
假设第 55 轮 (A29)–(A32) 成立；新增：**(A33)** 证据更新经校准，support/refute 的假阳/假阴率上界为 `α_e`；**(A34)** 评分代理偏差 `||Ŝ-S||_∞ ≤ ε_S` 且断崖定位召回 `≥ θ_c`；**(A35)** 对手策略集 `O` 为真实对手的 `ε_O`-覆盖；**(A36)** PVD 在 `T` 内可执行且 `verify` 调用的证书 sound。则“可竞争”下真实得分的下界：
```
E[S] ≥ S(π*) - ε_S - α_e·ΔS - P(o∉O)·ΔU - β_sched
```
关键：**证书从“部署硬门禁”降格为“原型导航 + 排名风险预算”**——允许未知，但禁止核心条款已知为假；把有限时间押在信息密度最高、得分断崖最近的实验上。

## 6. 本轮最大风险

**一句话**：把证书降格为“原型导航 + 排名风险预算”能在竞赛窗口内显著加速迭代与得分，但其 soundness **三重依赖证据更新的校准、评分代理的反演精度、以及对手/规则集合的覆盖**；一旦证据被廉价原型系统性高估、或评分断崖定位偏到“假断崖”，调度器会把全部时间押在一个看似高收益实则不存在的方向上，临截止才发现核心安全条款已被证伪——因此必须保留 **核心安全条款白名单不可降级 + 断崖置信区间 + 对手最小后悔回退** 三重保险，宁可少做一个原型，也不把“快速”当作“正确”的替代。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SCG×WBV×SSF×SCC×SRS×CEB）

> 承接第 54 轮产物 v31。本轮把“动作空间剖面”继续下探到 **“动作所依赖的接触在语义上是否可信、全身耦合下是否仍然可行”**，在动作-协同层之上新增一层 **语义-接触层**：
> - **SCG（Semantic-Contact Grounding）**：把语义标签变成接触可供性 `κ(l,c)`，得到语义接触集 `C(Σ)`；
> - **WBV（Whole-Body Viability Kernel）**：语义条件化生存核 `K(Σ)`，并给出内外近似；
> - **SSF（Semantic Shield Filter）**：把感知不确定挡在不可逆接触之前的 QP 护盾；
> - **SCC（Semantic-Contact Certificate）**：`J_s=(Σ_core,C_core,K_margin,ρ_sem,δ_s,evidence)`；
> - **SRS（Semantic Robustness Spectrum）**：分割扰动球内全身可行性的最坏保持概率；
> - **CEB（Cloud-Edge Semantic Boundary Protocol）**：边界不一致回传触发语义-动作联合重剖分。

```python
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)
    C = set()
    for p in grid(rgbd):
        l = argmax(Sigma[p])
        if confidence(Sigma[p]) < theta_conf:
            continue
        for c in CONTACT_TYPES:
            if kappa[l][c] >= theta_k:
                C.add((p, c))
    M = boundary_margin(Sigma)
    return Sigma, C, M

def conservative_contacts(C, M, kappa, theta_m):
    return {(p, c) for (p, c) in C
            if M[p] >= theta_m(kappa[argmax_at(p)][c])}
```

```python
def viability_kernel(Sigma, C_plus, x0, horizon, eps):
```

```python
def semantic_robustness_spectrum(Sigma_hat, eps_s, sampler):
    worst = 1.0
```

**正确性定理（Whole-Body Semantic-Contact Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `Σ` 的置信经温度/分位数校准，ECE ≤ ε_cal；**(A30)** `K_in ⊆ K(Σ) ⊆ K_out` 且护盾在不可行时回退 `u_stop∈𝒳_safe`；**(A31)** 真实语义扰动 `||Σ-Σ̂||_∞ ≤ ε_s`；**(A32)** 云边边界回传延迟 ≤ τ_sem 且重分割收敛。则部署后单步安全概率：
```
P_safe ≥ 1 - P(||Σ-Σ̂||_∞ > ε_s) - P(κ miscalibrated)
            - P(K_out \ K_in ≠ ∅) - P(shield fallback fails)
```
关键：**语义不确定性进证书、生存核保守包含、护盾兜底**，三层任一层失守都不允许把“分割看起来很确定”当作“接触一定成立”。

## 5. 本轮最大风险

**一句话**：语义-接触接地与全身生存核把“感知标签”升级为“可执行的接触约束”，但其 soundness **三重依赖分割置信的校准、接触可供性的跨域迁移、以及生存核外近似的紧致性**；一旦边界处置信过度自信、或可供性在未见材质上系统偏移，护盾会在“自认为可行”的伪生存核内放行动作，让全身控制器把所有肢体压上虚假支撑面，造成不可逆的跌倒——因此必须以 **边界校准 + 在线 κ 更新 + 核保守度预算** 三重护栏，宁可保守制动，绝不把语义的“高置信”当作接触的“已证实”。
