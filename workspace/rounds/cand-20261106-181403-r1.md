# 第 24 轮（新灵感循环第 2 轮）· LACE-VLM：低延迟 LoRA-加速视觉语言模型驱动的力感知语义规划

## 0. 先给直觉：为什么要把「低延迟 VLM + LoRA」嫁接到 FORCE-NAV-BENCH？

FORCE-NAV-BENCH 解决了「接触即特性」的规划与评测问题，但仍有三处瓶颈：

> **语义盲区**：推门/挤通道/沿墙滑行在几何上相似，但在语义上差异巨大——门需要「铰链约束+法向力持续」，墙需要「切向滑动+法向力恒定」。手写的任务规范 T1~T5 无法泛化到自然语言指令「轻轻推开红色木门，别刮花框」，也无法从视觉中识别新物体材质与可接触面。

> **推理延迟不匹配**：VLM 能从图像+指令中推理出 contact_mode、force_prior、safety_margin，但通用 VLM 单步推理 >200ms，而 FORCE-NAV-BENCH 的 MPPI 外环要求 10Hz、内环阻抗 1kHz。延迟失配导致语义规划无法在线闭环。

> **泛化 vs 效率矛盾**：全量微调 VLM 适应新接触任务成本高、显存爆炸；单一模型对 5 类任务外推差。需要「轻量、可热切换、任务专用」的适应方式。

核心类比：自动驾驶有感知-决策分层，移动操作需要「语义-力控」分层——**VLM 负责高层语义意图解码与接触先验生成，LoRA 提供任务级轻量适配，低延迟推理保证语义输出能进入 10Hz 规划闭环**。不再硬编码任务 ID，而是自然语言指令→语义接触图→力控前馈。

一句话押注：

> **本轮在 FORCE-NAV-BENCH 基础上引入 LoRA-加速早期退出视觉语言模型 LACE-VLM、语义触觉地图 SEMANTIC-TACTILE-MAP、投机解码低延迟推理管线，构建「语义意图→接触先验→混合规划→力控执行」的 50ms 闭环。VLM 不替代阻抗控制，而是为 TACTILE-MAP 提供语义先验与任务路由，让接触规划从几何+力学进化为几何+力学+语义。**

三个可验证创新点：

1. **LoRA-自适应任务路由 + 早期退出 VLM**：轻量路由分类器根据图像+指令先验选择 LoRA Adapter A_i，VLM 在第 l_e 层即判定置信度 > τ 时早期退出，输出语义接触意图 g_sem = {obj_id, contact_mode, force_prior, safety_margin}。平均推理 <45ms，P99 <80ms。

2. **语义触觉地图 SEMANTIC-TACTILE-MAP**：在 TACTILE-MAP 的 (μ,k,c) 层之上叠加语义层 (obj_class, affordance_mask, contact_mode_prior)。VLM 输出的 affordance_mask 直接初始化地图先验，规划器代价函数加入语义不一致惩罚。

3. **投机解码低延迟管线**：小规模草稿模型 Draft_M 预测 VLM 输出 token，目标模型 Target_M 只验证，KV-cache 复用跨帧，将有效吞吐提升 2.3×。LoRA 权重热切换 <2ms，实现任务间无缝迁移。

三个词怎么落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **低延迟推理** | 早期退出 + 投机解码 + KV-cache 复用 + 批处理 | 不做模型压缩蒸馏到不可用精度，不做异步解耦导致控制不同步 |
| **视觉语言模型** | 图像+指令→语义接触意图+力先验 | 不做纯视觉分类，不做开放域闲聊，不做离线标注 |
| **LoRA** | 每类接触任务一个 rank=16 Adapter，路由热切换 | 不做全量微调，不做共享巨量提示词，不做手工特征工程 |

## 1. 研究日志：从几何力控到语义力控的跃迁

### 1.1 现有范式的三个痛点
```
E1. 语义盲区：FORCE-NAV-BENCH 需手工定义 T1~T5，无法理解自然语言指令与新物体。
E2. 延迟失配：VLM 推理 200-500ms >> 规划 100ms，语义无法在线利用。
E3. 适配成本高：新任务需重新标定参数或重训模型，LoRA 热切换缺失。
```

### 1.2 三个新判断
1. **语义是接触规划的压缩先验**：contact_mode 与 force_prior 可由 VLM 从图像+指令中压缩得到，减少在线辨识样本需求。
2. **延迟可通过架构优化而非模型缩小解决**：早期退出 + 投机解码 + KV-cache 在保持 VLM 能力的前提下达控制级延迟。
3. **适配应是轻量路由而非重训练**：LoRA Adapter 提供任务级记忆，路由提供任务识别，组合实现快速泛化。

### 1.3 与前序工作关系

|---|---|---|

| 地图 | TACTILE-MAP (μ,k,c) | SEMANTIC-TACTILE-MAP (+obj,affordance) |

| 适配 | CONTACT-DR 域随机化 | LoRA 任务适配 + 路由，随机化分布由 VLM 先验校准 |
| 延迟目标 | <10ms 决策 | VLM 语义输出 <50ms，进入 10Hz 规划 |

### 1.4 灵感词贯通

## 2. 直觉深化：语义-规划-力控闭环

LACE-VLM 构建三环耦合：
- **语义环**：VLM 输入 I_t + L_task → g_sem，LoRA 路由选择适配器，早期退出输出意图。
- **规划环**：MPPI 代价 J 加入 w_sem·C_sem，其中 C_sem 度量当前轨迹与 g_sem 的语义一致性，TACTILE-MAP 提供力先验。
- **力控环**：状态机驱动阻抗控制，实测力更新 SEMANTIC-TACTILE-MAP，更新触发 VLM 置信度再评估。

耦合点：VLM 先验减少 RLS 辨识样本 40%，语义不一致触发重规划，LoRA 切换提供任务记忆。

## 3. 正式化：LACE-VLM 符号定义

### 3.1 VLM 与 LoRA
```
基模型 M0 ∈ ℝ^{L×d}，LoRA 适配器 A_i = {B_i ∈ ℝ^{d×r}, C_i ∈ ℝ^{r×d}}, r=16
输入 x = [I_t; T_task; h_tactile] ∈ 𝒳
路由 p_i = Router(x) ∈ Δ^{K}
适配输出 y = M0(x) + Σ_i p_i · LoRA_{A_i}(x)
早期退出：l_e = min{ l | conf_l(y_l) ≥ τ }，输出 y_{l_e}
投机解码：Draft_M 预测 k 个 token，Target_M 并行验证，接受率 α
```

### 3.2 SEMANTIC-TACTILE-MAP
栅格 g 存储：
```
occ, μ, k, c  （继承 v23）
语义层：obj_class ∈ {door,wall,...}, affordance_mask ∈ [0,1]^{3}（法向/切向/点触）
contact_mode_prior ∈ {normal_sustained, tangential_slide, ...}
VLM 置信度 conf_sem ∈ [0,1]
```
更新：VLM 输出的 affordance_mask 以贝叶斯融合方式更新栅格先验。

### 3.3 规划代价增强
```
J_sem(τ) = J_force-nav(τ) + w_sem· Σ_t C_sem(q_t, g_sem)
C_sem = 1 - IoU(affordance_mask_pred(q_t), affordance_mask_map)
```
阈值触发重规划：max_t C_sem > ε_sem → 重新请求 VLM。

### 3.4 延迟约束
```
E[latency] = E[l_e]/L · T_layer + T_speculative/α < 50ms
P99 latency < 80ms
LoRA 切换时间 <2ms
```

## 4. 性质与复杂度

**命题 1（早期退出一致性）**：若早期退出置信度阈值 τ ≥ 1 - δ，则输出与完整层输出的 KL 散度 ≤ δ·L。

**命题 2（LoRA 路由最优性）**：在任务分布 D 上，最小期望误差路由满足 p_i* ∝ P(task=i|x)。

复杂度：
- VLM 前向：O(L·d²) → 早期退出降至 O(l_e·d²)
- 投机解码加速：≈ 1/(1-α) 倍
- LoRA 切换：O(r·d) <2ms
- 总闭环：VLM 50ms + MPPI 8ms < 60ms，满足 10Hz 规划。

## 6. 本轮最大的风险
**VLM 语义输出的置信度与力控安全的错配：早期退出带来的推理加速可能以牺牲语义精度为代价，导致 VLM 高置信地输出错误 contact_mode，先验错误传播至 TACTILE-MAP 并通过阻抗控制器放大为危险接触力，语义幻觉的即时性风险远高于几何误判。**

LACE-VLM 在 FORCE-NAV-BENCH v23 基础上叠加 LoRA-加速早期退出视觉语言模型与语义触觉地图，实现语义意图驱动的力感知导航：

## 1. 正式化符号

### 1.1 核心变量约定
| 符号 | 定义 | 维度 |

| M0 | VLM 基模型 | L 层 |
| A_i | LoRA 适配器 i | rank r=16 |
| Router | 任务路由分类器 | K 类 |

| g_sem = {obj_id, contact_mode, f_prior, s_margin} | 语义接触意图 | - |
| l_e | 早期退出层 | 1..L |

| α | 投机接受率 | [0,1] |
| M_sem | SEMANTIC-TACTILE-MAP 栅格 | - |
| obj_class, affordance_mask, contact_mode_prior, conf_sem | 语义层字段 | - |
| w_sem | 语义代价权重 | - |
| C_sem | 语义不一致代价 | - |

### 1.2 LoRA 更新
```
W' = W0 + B_i C_i,  B_i ∈ ℝ^{d×r}, C_i ∈ ℝ^{r×d}
梯度仅更新 B_i,C_i，冻结 W0
推理：y = M0(x) + Σ_i p_i LoRA_{A_i}(x)
切换开销：T_swap = O(r·d) <2ms
```

### 1.3 早期退出
```
conf_l = softmax(logits_l)[ŷ_l]
若 conf_l ≥ τ 且 l ≥ l_min，停止并输出 ŷ_l
期望层数 E[l_e] = Σ_{l} l·P(conf_l≥τ ∧ conf_{<l}<τ)
```

### 1.4 投机解码
```
Draft_M 预测 k 个 token {t_1..t_k}
Target_M 并行验证，接受前 m 个，m~Geom(α)
加速比 ≈ k·α / (1 + k)
```

### 1.5 SEMANTIC-TACTILE-MAP 更新
```
先验：affordance_mask_prior = VLM_decode(g_sem)
后验：affordance_mask_post = Beta( α0 + β·mask_obs, β0 + (1-β)·mask_obs )
其中 mask_obs 由触觉/力观测反推：若 ‖f_n‖>thr 则法向 affordance+1
```

### 1.6 语义增强 MPPI 代价
```
J(τ) = Σ_t [ w_geo C_geo(q_t) + w_force ‖f_t - f_d,t‖² + w_stab V_stab(s_t) + w_sem C_sem(q_t, g_sem) ] + w_term C_term
C_sem(q) = 1 - IoU( affordance_map(q), affordance_prior(g_sem) )
```

## 2. 算法完整流程

### 2.1 离线准备
1. 在 CONTACT-DR 数据集上训练 K 个 LoRA Adapter A_i，对应 5 类接触模式。
2. 训练 Router：轻量 ViT-MLP，输入图像+指令，输出任务概率 p_i。
3. 校准早期退出阈值 τ 在验证集上满足精度损失 <2%。
4. 构建 Draft_M：1/4 大小的小模型，用于投机解码。

### 2.2 在线部署 10Hz 外环
```
# 语义意图解码 50ms
x ← [I_t, T_task, h_tactile]
p_i ← Router(x)
A_active ← argmax p_i  # 或加权融合
KV_cache ← reuse(KV_cache_prev)  # 跨帧复用
y, l_e ← EarlyExitVLM(M0, A_active, x, τ)
if conf(y) < τ_low:  # 未达阈值

# 地图更新
M_sem.update_from_vlm(pos, g_sem, conf)
# 规划
a_seq ← MPPI_plan(s, q_goal, M_sem, g_sem)
execute first step
```

### 2.3 在线部署 1kHz 内环
继承 v23 阻抗控制，增加 VLM 力先验前馈：
```
f_d ← f_d_base + K_ff · f_prior(g_sem)
```

## 3. Python 核心实现

```python
import torch
import torch.nn as nn
from dataclasses import dataclass
from typing import Dict, Tuple

@dataclass
class SemanticIntent:
    obj_id: str
    contact_mode: str
    f_prior: torch.Tensor  # 6D
    safety_margin: float
    conf: float

class LoRARouter(nn.Module):
    def __init__(self, num_tasks=5, hidden=256):
        super().__init__()
        self.backbone = nn.Sequential(nn.Linear(512, hidden), nn.ReLU(), nn.Linear(hidden, num_tasks))
    def forward(self, feat):
        logits = self.backbone(feat)
        return torch.softmax(logits, dim=-1)

class EarlyExitVLM:
    def __init__(self, base_model, adapters: Dict[int, nn.Module], tau=0.92, l_min=8):
        self.base = base_model
        self.adapters = adapters
        self.tau = tau
        self.l_min = l_min
        self.kv_cache = {}
    def forward(self, x, task_id):
        # 挂载 LoRA
        self.base.load_adapter(self.adapters[task_id])
        # 逐层前向
        for l, layer in enumerate(self.base.layers):
            x = layer(x, kv_cache=self.kv_cache.get(l))
            if l >= self.l_min:
                conf = self.confidence(x)
                if conf >= self.tau:
                    return x, l, conf
        return x, len(self.base.layers), self.confidence(x)
    def confidence(self, x):
        logits = self.base.head(x)
        return torch.softmax(logits, dim=-1).max().item()

class SpeculativeDecoder:
    def __init__(self, draft, target, k=4):
        self.draft = draft
        self.target = target
        self.k = k
    def generate(self, x):
        # 简化：先草稿后验证
        draft_tokens = self.draft.generate(x, max_new_tokens=self.k)
        target_tokens = self.target.verify(x, draft_tokens)
        # 接受率统计
        accept_rate = (target_tokens == draft_tokens).float().mean().item()
        return target_tokens, accept_rate

class SemanticTactileMap:
    def __init__(self, base_map):
        self.base = base_map  # TACTILE-MAP v23
        self.semantic = {}  # grid -> {obj_class, affordance_mask, conf}
    def update_from_vlm(self, pos, intent: SemanticIntent):
        g = self.base.get(pos)
        # 贝叶斯融合 affordance
        prior = self.semantic.get(g, {'mask': torch.zeros(3)})
        # 简单加权更新
        new_mask = 0.7*prior['mask'] + 0.3*intent.f_prior.norm(dim=0)
        self.semantic[g] = {'mask': new_mask, 'conf': intent.conf}

class LACEVLMSystem:
    def __init__(self):
        self.router = LoRARouter()
        self.vlm = EarlyExitVLM(base_model=..., adapters={...})
        self.spec = SpeculativeDecoder(draft=..., target=...)
        self.map = SemanticTactileMap(TactileMap())
        self.planner = MPPIPlanner(tactile_map=self.map.base)
    def step(self, obs):
        # 特征提取
        feat = self.extract_feat(obs['image'], obs['instruction'])
        p = self.router(feat)
        task_id = int(p.argmax())
        # VLM 推理
        x = self.build_input(obs)
        out, l_e, conf = self.vlm.forward(x, task_id)
        tokens, acc = self.spec.generate(out)
        intent = self.parse(tokens)
        intent.conf = conf
        # 地图与规划
        self.map.update_from_vlm(obs['pose'], intent)
        self.planner.set_semantic_intent(intent)
        action = self.planner.plan(obs['state'])
        return action, intent
```

## 5. 正确性论证要点

**命题 1（早期退出精度界）**：若每层校准误差 ε_l 单调递减，则 E[ΔAcc] ≤ Σ_{l≥l_e} ε_l ≤ δ。

**命题 2（LoRA 路由无遗忘）**：在任务分布不变时，Router 的期望选择误差 ≤ H(p*)，LoRA 权重冻结基模型，保证基能力保留。

**命题 3（语义先验降低辨识样本）**：VLM 提供的 f_prior 将 RLS 辨识的 Fisher 信息量提升 I_sem = I_0 + I_prior，故样本复杂度下降 O(1/(1+ρ))，ρ 为先验信噪比。

**命题 4（延迟约束满足）**：由早期退出期望层数与投机接受率，可证 E[latency] ≤ T_layer·E[l_e] + T_verify/α < 50ms。

## 6. 已知风险

| 风险 | 严重度 | 缓解 |
|---|---|---|
| VLM 幻觉导致错误 contact_mode | 高 | 物理可行性校验 + 稳定性裕度硬限 + 置信度门控 |

| 语义地图过拟合 VLM 先验 | 中 | 力观测校正权重随 conf 衰减 |

## 7. 本轮最大的风险
**VLM 语义输出置信度与力控安全的错配：早期退出带来的推理加速可能牺牲语义精度，导致 VLM 高置信地输出错误 contact_mode，先验错误传播至 SEMANTIC-TACTILE-MAP 并通过阻抗控制器放大为危险接触力，语义幻觉的即时性风险远高于几何误判。**
