# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301，并纳入 R73.5 的因果/形态扩展 IP-302；灵感循环第 4 轮；本轮灵感：「运动控制」×「分布外泛化」）

> R73 用「证据契约 + 组合代数 + 热替换定理」把安全证明从全系统审计搬到了模块契约上，并诚实地指出：证明重量落在**契约表达力**与**组合审计的校准**上。R73 结尾的最大风险几乎就是本轮的两个灵感词：如果真实噪声/相关性**超出契约可表达的空间**（分布外），组合定理会在「所有证书有效、所有校验通过」时给出错误安全界。R73 把这件事当作「风险」记录，却从未把它当成**一等公民**来建模。
>
> 更尖锐地说，R73 的每一条安全定理都有一个**未声明的隐藏前提**：
> **系统实际运行分布 P_t 始终落在证书被校准的域 D 内（P_t ≡ P_0）**。
> 一旦 P_t ≠ P_0，定理的结论——物理风险 ≤ ε——就**不再有证明**，但系统的输出（证书、仪表盘、控制指令）没有任何一个字节会改变。这是「自信地合规」的最纯粹形式。R73.5 的 ECG/MIC/IP-302（因果证据图、形态无关契约）只补了结构，没有补「域何时失效、失效后主张如何自动收缩」。
>
> 本轮两个灵感正好补这一刀：
> - **分布外泛化** → 把「是否还在域内」从事后风险升级为**被在线计量、被分级认证、可被否决的运行时对象**：域证据契约 DEC、分布移位计量 SMM、安全层级格 T、可迁移性证书 J_TRANS。
> - **运动控制** → 运动既是**离开域的唯一执行器**，也是**测试自己是否仍在域内的唯一执行器**。于是运动控制不再只是证据的消费者：它必须同时 (i) 把域边界当作硬约束（域裕度控制屏障函数 DM-CBF），(ii) 把「探测域成员资格」当作可认证的信息增益目标（安全探索 ATC）。
>
> 核心命题：**不再问「这个证书是否有效」，而问「这个证书在多大程度上、在什么条件下、还能被搬运到此刻的世界里——以及当它不能时，系统是否会自动、单调地降低自己的主张？」** 把 R73 的 MODGAUGE-RAS 扩展为 **SHIFTGAUGE-RAS**（SHIFT-aware, metrology-governed motion control with GAUGE audits）——**可迁移计量与域感知运动控制**。

## 0. 直觉与动机

**灵感 1（分布外泛化 → 不是训练问题，而是在线域成员资格认证问题）**
直觉：ML 的 OOD 讨论几乎都在问「模型在未见分布上精度掉多少」。对一个**带安全证书的具身系统**，这个问法太弱。真正要问的是：「证书的前提还成立吗？如果不成立，系统知不知道？」所以 OOD 在本体系里不是数据集划分，而是**运行时的域成员资格**：每一时刻都有一个分布移位证书 S_t，它把「当前世界离校准域多远」拆成四个可测分量——协变量移位（输入分布变、条件不变、可重加权）、概念移位（p(y|x) 变、重加权救不了）、动力学移位（机器人自身的 f 或扰动律变）、开集新类（质量落到校准支撑外）。关键立场：**没有单一检测器有权单独宣布「仍在域内」**（继承 E356/E357 单源不定案），必须由**冗余检测器组做 PAR 一致性审计**——这和 R73 用跨模态审计决定并联能否缩窄，是同一套代数。

**灵感 2（运动控制 → 双用途执行器：越域风险与探域手段是同一个动作）**
直觉：机器人没有别的办法离开域，也没有别的办法确认自己是否还在域。走近、转视角、施加接触、加速——每个动作同时改变「我可能越过多远」和「我能看到多少」。于是运动控制的目标函数天然是三项：任务进展 + **信息增益（关于域成员资格）** − 风险/反作用。但有铁律：**探索只能在已认证的安全子集内进行**（U_safe ⊆ C_safe）。这把经典「探索-利用」三角升级为**探索-利用-认证三角**：不允许为了知道是否安全而先不安全。域边界本身是估计量、带不确定度，所以要用**鲁棒域裕度** m_rob = m − β·U_m 做 CBF，绝不用点估计。

**灵感 3（植物也是域 → R73 只计量世界，没计量自己）**
直觉：R73 有深度/接触/意图证据，却没有一张关于**机器人自身**的证据契约。而运动控制的 OOD 主要发生在自己身上：负载变了、关节磨损了、轮胎/足底换了、接触刚度变了、驱动器热降额了。于是需要 **DYM**：植物六分量（参数/未建模扰动/接触模式/热漂移/磨损回差/执行器饱和），与 DPEM 六分量严格同构。更妙的是：动作对植物参数的**可辨识性**本身是一个反作用通道 χ_p（持续激励 / Fisher 信息）。但它是**第一个边际成本可为负**的通道——动一动会*改善*证据。这直接击穿 R73 引理 36 的「边际成本正下界」，必须把预算拆账。

**灵感 4（分级证书 → 不是有效/无效，而是「在哪个层级上成立」）**
直觉：工程上最危险的二元证书是「PASS」。真实世界的正确输出是**带条件的等级**：T0 名义（分布内，全保证）、T1 移位容忍（有界协变量移位，加权 conformal 仍守住 1−α−δ）、T2 移位鲁棒（有界概念/动力学移位，鲁棒不变集仍非空）、T3 未知（无保证，退保守包络或安全停）。层级构成格，组合取 meet（最差者决定），**任何组合都不能抬高层级**。升级必须**慢且 anytime 有效**（e-process，Ville 界），降级必须**快且非补偿**（任何报警立即掉到 T3）。仪表盘只有在**对应检测器活着且校准有效**时才能显示高等级——检测器失活本身是 veto。这一条专门杀死「静默失效检测器 + 全绿仪表盘」这一最危险的失败模式。

**灵感 5（可迁移定理 → 严格包含 R73，把风险变成可度量的 δ）**
直觉：R73 的定理变成 SHIFTGAUGE 在 S=0、tier=T0 时的特例。于是「安全单调不减、退化链逐指令等价」的姿势得以保持；不同的是，δ(shift) 现在是**可测、可预算、可写进证书**的量，而不再是一句免责声明。论文主张也随之从三条扩到五条：C1 物理感知证据计量、C2 反作用预算组合、C3 契约式模块化（继承），新增 **C4 可迁移分级证书**、**C5 安全探索**。

## 1. 形式化定义（增量：定义 383–399）

**定义 383（域描述子与认证运行域 COD）** 域描述子 d = (φ_env, φ_self, φ_task, φ_shift)，分别刻画环境（几何/材质/光照/杂物）、自身/植物（负载/磨损/标定/驱动状态）、任务（意图/物体/交互）与已知移位轴。**COD** 𝔇_cert ⊆ 𝔇 是所有模块证书在层级 ≥ T0 下的有效域交集：𝔇_cert = ∩_i D_cert^i。域成员资格是一个**在线查询** mem(x_t) ∈ {in, out, unknown}，unknown 视为 out（保守）。

**定义 384（安全层级格 T）** T = {T0 ⊐ T1 ⊐ T2 ⊐ T3}，语义为**保证集合的包含**：G(T0) ⊇ G(T1) ⊇ G(T2) ⊇ G(T3)=∅。T0：名义，全部 R73 保证；T1：协变量移位有界，覆盖 ≥ 1−α−δ_w；T2：概念/动力学移位有界，鲁棒不变集非空；T3：δ 不可估或检测器失效或新类质量超限，**无覆盖保证**。组合取 meet：τ(A ⊕ B) = min(τ_A, τ_B)。**非补偿性**由 min 直接保证（继承 R73 定义 370 的 VETO 语义）。

**定义 385（域证据契约 DEC）** DEC = (EC, d, D_cert, τ, τ_transfer, Env, Det)：EC 为 R73 定义 367 的证据契约；d 为域描述子；D_cert 为认证域；τ ∈ T 为默认层级；τ_transfer: ShiftCert → (τ, CoverageBound) 为**可迁移函数**；Env: T → Envelope 给出各层级的速度/力/接触/工作空间包络；Det 为冗余检测器组（≥2 个独立检测器，用于 PAR 一致性审计）。

**定义 386（分布移位四分解 SMM）** 当前分布 P_t 相对校准分布 P_0 的总移位被分解为：
- Δ_cov（协变量移位）：p_t(x) = w(x)p_0(x)，密度比 w，界 Λ = ‖w‖_∞，估计误差 δ_w = ‖ŵ−w‖_1；
- Δ_con（概念移位）：sup_x TV(p_t(y|x), p_0(y|x)) ≤ ε_con；
- Δ_dyn（动力学移位）：‖f_t − f_0‖ + ‖disturbance 差‖ ≤ ρ（见定义 388）；
- Δ_nov（开集新类）：落入校准支撑外的质量 p_nov ≤ η。
**移位证书** S = (Δ̂_cov, Δ̂_con, Δ̂_dyn, Δ̂_nov, U(·), agree, alive, calib_ok)，其中 U(·) 为各分量不确定度，agree 为冗余检测器的 PAR 一致性审计（不一致 ⇒ 保守化），alive 为检测器存活，calib_ok 为检测器自身校准未漂移。

**定义 387（可迁移覆盖下界与层级赋值）** 设源域 P_0 上 conformal 校准给出边际覆盖 ≥ 1−α。则目标域上
δ(shift) = δ_w(Λ) + ε_con + η + L·ρ，
有效覆盖 ≥ 1−α−δ（各分量并集界，保守）。层级赋值：
δ ≤ δ_0 且全部检测器 alive∧agree∧calib_ok ⇒ T0；
δ ≤ δ_1 且支撑重叠、仅协变量移位 ⇒ T1；
δ ≤ δ_2 且存在非空鲁棒不变集 ⇒ T2；
δ 不可估 / 任一分量无上界 / 新类 η > η_max / 检测器失活或分歧 ⇒ **T3**。
δ→0 时覆盖回到 1−α，严格退化为 R73。

**定义 388（动力学计量 DYM 与植物证据契约 PEC）** 植物证据 y_p = (跟踪误差 e, 扰动观测残差 r, 接触阻抗 Z, 温度/磨损状态)。植物六分量：
u_dyn² = u_model²(负载/参数) + u_dist²(未建模扰动) + u_contact²(接触模式) + u_thermal²(热漂移) + u_wear²(磨损/回差) + u_act²(饱和/摩擦)。
每分量独立追溯链，与 DPEM 六分量**同构**（世界证据 vs 自我证据）。有效域 D_dyn 与层级 τ_dyn 同理。**L5 激励通道** χ_p(g) = 期望 Fisher 信息 / 持续激励度，其反作用成本 c_reflex^p = −κ·I_fish(g) **可为负**。

**定义 389（域裕度与鲁棒域裕度）** 域裕度 m(x) = min_i (slack_i(x))，slack_i 为第 i 个模块有效域的负对数密度比或约束松弛。**鲁棒裕度** m_rob(x) = m(x) − β·U_m(x)，β 为置信倍数。认证域 C_dom = {x : m_rob(x) ≥ 0}。未知域一律 m_rob = −∞。

**定义 390（域裕度控制屏障函数 DM-CBF）** 取 h_dom(x) = m_rob(x)。DM-CBF 条件：ḣ_dom ≥ −α(h_dom)，等价地 ∇m_rob·(f(x)+B(x)u) + α(m_rob) ≥ 0。控制器可行集 U_dom(x) = {u : DM-CBF ≥ 0} ∩ {u : 物理 CBF ≥ 0} ∩ Envelope(τ)。**分层不变性**：物理安全与域安全是两层硬约束，任一层不可满足即触发层级降级（先降包络，再安全停），绝不以牺牲物理安全换域安全，反之亦然。

**定义 391（域感知运动目标 DOM / 安全探索）** 
u* = argmax_u [ Progress(u) + κ·I_shift(u; u) − λ·Risk(u; τ) − Σ_m c_reflex^m(u) ]
s.t. u ∈ U_dom(x; τ)、预测时域内 m_rob(x') ≥ 0、REG 时序契约。
其中 I_shift(u; u) = I(S; y' | do(u)) 为「未来观测对移位证书」的互信息（BOED 风格），**只能在 U_dom 内取**。这是「运动即实验，但实验必须已认证」的形式化。

**定义 392（非对称层级认证 ATC）** 升级用 e-process：E_t = ∏_{s≤t} (p_1(o_s)/p_0(o_s))，仅当 E_t ≥ 1/α_u **且**检测器组 alive∧agree∧calib_ok 时允许升一级（Ville 不等式给出 anytime 假升级率 ≤ α_u）；降级为**立即且非补偿**：任一报警、任一检测器失活、任一域裕度预测越界 ⇒ 直接落到 T3 并重置 E。**降级快、升级慢**是不可交换的安全不对称。

**定义 393（SHIFTGAUGE 闭环与可迁移证书）** 在 R73 三域之外新增**移位域**（50Hz）：感知证据 → DYM 植物证据 → SMM 移位证书 → 层级赋值 → DOM/DM-CBF 规划 → 控制域鲁棒前缀。可迁移证书 J_SHIFT = J_MOD ⊗ J_TRANS(S, τ) ⊗ J_TIER(ATC 日志)，其中 J_TRANS 记录 δ 的分解、上界假设、检测器存活/校准证据与层级推导链。Valid(J_SHIFT) ⇒ Valid(J_MOD) ∧ 层级 τ 的保证在 δ(shift) 下成立。**严格包含**：S=0 且 τ=T0 时 J_SHIFT 逐指令等于 J_MOD。

**定义 394（移位因果归因，纳入 IP-302/ECG）** 当 SMM 报告移位时，用 R73.5 的证据因果图 ECG 做**归因**：哪条因果边（视角→深度质量、接触→状态估计、负载→跟踪误差）的机制发生了变化。归因产出「机制集合」M_shift，用于 (i) 定向降级（只降受影响的模块）、(ii) 反事实查询「若封锁该边，域裕度是否恢复」。因果链断裂本身触发 T3（继承 ECG 的断裂即拒绝语义）。这把「移位有多大」升级为「**哪条物理机制变了**」，从而让降级最小化、恢复可定向。

**定义 395（跨本体域契约，纳入 MIC）** 形态无关契约 MIC 扩展为**形态无关域契约**：域描述子中与形态相关的分量（关节数/手指数/传感器阵列）被抽象为「证据能力集」，而非具体硬件。跨本体迁移是一次**域外迁移的有界特例**：新形态若能声明同构的 EC+域特征，则按 DEC 的 τ_transfer 决定层级；不能则直接 T3 并以模块级重认证恢复。核心代码改动行数作为可证伪指标（<5 行）。

**定义 396（层级化失效与降级语义）** 降级是**先缩包络、后缩模态、最后安全停**的三级阶梯：(i) Envelope(τ) 收紧（速度/力/接触上限）而保留全部模态；(ii) 受影响模态置 stub（R73 定义 381）但物理 CBF 不变；(iii) T3 且域裕度不可恢复 ⇒ 认证安全停（非自由落体式的 abrupt stop）。**任何降级不得违反物理 CBF**；任何升级不得跳级。

**定义 397（MB4 移位/鲁棒基准）** MB4 =（受控四轴移位矩阵：协变量/概念/动力学/新类）×（突变/渐进/对抗三种时间剖面）×（3 个下游运动任务：抓取、装配、人机共融）。预注册脚本 + 固定种子 + 密封保持集 SEAL-MB4；各 ≤3h 单卡（或单机）可复现。核心指标：有效覆盖率、**假安全率**（真实越域但系统仍报 T0/T1 的比例）、恢复时间、任务可用率、层级抖振次数。

**定义 398（主张-证明绑定 v2，CPB v2）** 在 C1–C3 基线上新增：**C4 可迁移分级证书** ←（DEC,SMM,J_TRANS）← MB4 ← AB4（固定证书 vs 分级证书 vs 仅 OOD 检测器）←（假安全率、有效覆盖、任务可用率、恢复时间）；**C5 安全探索** ←（DYM,DOM,ATC）← MB4 ← AB5（安全探索 vs 贪心 vs 无探索）←（收敛到正确层级的步数、探测期违规率、任务收益）。**入图前置**：不服务任何主张的组件 = 工程附件，不进 MReg、不进正文（继承 R73 定义 374）。

**定义 399（可审计结构上限）** |T| = 4、每模块检测器组 ≤ 3、层级状态迁移图 ≤ 12 条边、δ 分解分量 ≤ 4、DYM 分量 ≤ 6——全部为部署期静态校验 + 运行时增量校验的**图性质**，而非文档纪律（继承 R73 定义 377 的姿势）。

## 2. 关键算法骨架

```python
# IP-303 DEC：域证据契约（EC 的域索引扩展）
@dataclass(frozen=True)
class DomainEvidenceContract:
    ec: EvidenceContract                       # R73 定义 367
    domain: DomainDescriptor                   # (env, self, task, shift_axes)
    cert_domain: Predicate                     # D_cert
    tau_default: str                           # 'T0'..'T3'
    transfer: Callable[[ShiftCert], TierBound] # δ(S) → (tier, coverage)
    envelope: Dict[str, Envelope]              # 每层级速度/力/接触上限
    detectors: Tuple[str, ...]                 # 冗余检测器组（≥2，PAR 审计）

# IP-304 SMM：分布移位计量（移位域，50Hz）
class ShiftMetrology:
    def update(self, batch, eco):
        cov = self.density_ratio(batch)        # Δ_cov, ŵ, Λ̂, δ_w
        con = self.concept_residual(batch)     # Δ_con：残差 vs 标签代理
        nov = self.open_set(batch, eco.calib)  # Δ_nov, η
        dyn = eco.dym.shift_estimate()         # Δ_dyn（来自 IP-305）
        agree = self.ensemble_agree(cov, con, nov, dyn)   # PAR 一致性审计
        alive = self.liveness()                # 检测器存活（挑战输入/漂移）
        calib = self.calib_ok()
        s = ShiftCert(cov, con, nov, dyn, agree, alive, calib)
        return s if agree and alive and calib else s.conservative()  # 不给高等级

# IP-305 DYM：动力学计量（植物证据契约，运动控制专用）
class DynamicsMetrology:
    def update(self, cmd, state, contact, temp):
        r = self.disturbance_observer(state, cmd)
        u_model   = self.param_unc()               # 负载/参数
        u_dist    = self.resid_unc(r)              # 未建模扰动
```

## 3. 推导

**引理 38（移位四分解的条件可识别性与检测器冗余）** 给定 SMM 的计量残差集（密度比估计、概念残差、开集分数、DYM 动力学残差），四分解在「每分量有独立观测机制」条件下近似可识别：Δ_cov 由密度比、Δ_con 由残差-标签代理、Δ_nov 由支撑外质量、Δ_dyn 由扰动观测器分别主导。若某分量不可识别（例如支撑完全无重叠 ⇒ w 不可估），则必须报 **unidentifiable** 而非默认 0——保守化为 T3。系：**「看不见的移位」必须显式编码为「看不见」，而不是当作「没有」——这是与 R73 引理 33 同型的方法论纪律。**

**引理 39（层级单调性与非补偿组合）** 由定义 384 的格与 min 组合：任何 SER/PAR/VETO 组合的层级 τ_out = min_i τ_i ≤ 任一输入层级；可迁移函数 τ_transfer 只依赖 S 与 DEC，不提升层级；升级仅由 ATC 的 e-process 触发。⇒ 组合与迁移都不产生「认知免费午餐」，与 R73 引理 34 同构。系：**R73 的单模块单调性被提升为「跨域也不凭空变好」的代数性质。**

**引理 40（可迁移覆盖下界，条件性——诚实版）** 设源域覆盖 ≥ 1−α。
(a) 协变量移位 w ≤ Λ 且 ŵ 估计误差 δ_w ⇒ 加权 conformal 覆盖 ≥ 1−α−δ_w；
(b) 概念移位 sup_x TV ≤ ε_con ⇒ 覆盖 ≥ 1−α−ε_con；
(c) 开集新类质量 η ⇒ 覆盖 ≥ 1−α−η；
(d) 动力学移位 ‖Δf‖ ≤ ρ 且有非空鲁棒不变集 ⇒ 轨迹级风险 ≤ ε(τ)+Lρ。
并集界得 δ = δ_w+ε_con+η+Lρ，覆盖 ≥ 1−α−δ；δ→0 时回到 R73 的 1−α。**若任一分量无上界或不可识别，δ=∞、τ=T3。** 系：**R73 的「契约表达力」从形而上风险变成可写进证书的一个数 δ——这是本轮最核心的降险动作。**

**引理 41（DM-CBF 的分层前向不变性）** 设 h_dom = m_rob 在认证域内 Lipschitz、相对度 1，物理 CBF h_phys 同理，且初值 m_rob(x_0) ≥ 0 ∧ h_phys(x_0) ≥ 0。若控制器 u ∈ U_dom 在每个控制周期求解可行，则闭环对所有 t 保持 x_t ∈ C_dom ∩ C_phys；若 U_dom 某时刻为空，则由定义 396 的阶梯先缩包络、再安全停，**不进入不可行区**。系：**「留在已认证域」从愿望变成硬约束；且域安全与物理安全是并联硬约束，不能互相补偿。**

**引理 42（安全探索的收益与有限停止，双账本）** L5 激励通道使 c_reflex^p 可为负，R73 引理 36 的「边际成本正下界」不再成立。拆分：
- **消耗账本** B_cons：所有非负安全维持成本，仍满足正下界；
- **认知账本** B_info：信息增益（可为负成本），用信息势 Φ_t = H(S | y_{1:t}) 记账，单调不增且 ≥0。
探测策略被 U_dom 硬约束 ⇒ 探测期违规率 ≤ 1−α（不因探索而牺牲安全）；e-process 的停止时间 T = inf{t : E_t ≥ 1/α_u} 在 H0 下满足 P(T<∞) ≤ α_u（Ville），且若存在持续激励（Fisher 信息正定）则 T 以概率 1 有限。系：**「层数/探索」增加不破坏安全与有限停止，但停止性来自信息势与 e-process，而不是单纯的成本下界——这是对 R73 引理 36 的必要修正。**

**定理 30（SHIFTGAUGE 严格包含 MODGAUGE）** 当 SMM 声明 S=0（δ=0、agree∧alive∧calib_ok）且层级固定 T0 时，DEC 退化为 EC、DYM 证据置 stub、DOM 退化为 R73 PVOP+ERVOI、ATC 恒等，J_SHIFT 逐指令等于 J_MOD（R73 定理 28）。再按 R73 定理 27 退化到 R72/R71/R68。**安全单调不减，效率仅在移位可忽略时获益。**

**定理 31（分级证书的安全语义，条件性）** 若层级 τ 被 **soundly** 赋值（检测器假「分布内」率 ≤ β_det，可迁移界（引理 40）在其假设内成立，ATC 假升级率 ≤ α_u），则物理风险 ≤ ε(τ) + L·δ(τ) + β_det。证明重量明确落在**检测器健全性 β_det 与迁移界假设**上——这把 R73 定理 28 的隐藏风险显式化为可审计的两个数。**若 β_det 不可估，则只能声明 T3（无保证）——不允许「未知地乐观」。**

**定理 32（运动即认证的不可抬高性）** 在引理 41–42 下：安全探索 (i) 不降低任何已成立的保证（U_dom 门控），(ii) 不能在检测器失活/分歧时抬高层级（ATC 条件），(iii) 在持续激励下以概率 1 有限时间把**正确**层级建立为可认证（e-process 一致性）。**但若真实移位落在检测器盲区，定理不保证——见本轮最大风险。**

## 6. 本轮最大风险

**一句话**：SHIFTGAUGE 把 R73 的「契约表达力」风险替换成了「**检测器健全性**」风险——整个分级安全语义都条件于移位检测器与可迁移界在其盲区外仍然可靠；一个**静默失效或存在系统性盲区的检测器**会让系统在真实世界已经越域时继续持有高等级证书，而这一次它甚至拥有一块「全绿」的仪表盘来证明自己合规，因此**检测器本身成为新的单点故障，而且可能比没有检测器更危险**。

次级风险与缓解：
1. **迁移界空洞（δ 过松）→ 安全但无用** → 用覆盖-尺寸 Pareto 而不是单点；域先验收紧 Λ/ε_con；δ 的逐分量追溯让「哪一项在拖后腿」可见，定向改进。
2. **检测器自证循环**（同一残差既检测移位又校准自身）→ 冗余独立检测器 + 外部基准（本体/接触/已知几何，继承 R73 定义 378）+ 周期性挑战输入；calib_ok 失效即降级。
3. **安全集过窄导致激励不足**（U_dom 内无法持续激励，无法升级）→ 允许「保持低层级」作为合法稳定态；分层激励；必要时用离线辨识补充而非强行在线探。
4. **渐进漂移的检测滞后** → CUSUM/漂移速率估计 + 域裕度导数项进入 DM-CBF；降级阈值随漂移速率自适应收紧。
5. **层级抖振** → 滞回 + 最小驻留时间，但**只延迟升级、绝不延迟降级**。
6. **探索动作诱发失稳** → 鲁棒 CBF 优先级严格高于信息增益；U_dom 内求解；激励强度受执行器包络约束。
7. **跨本体域描述子不完备** → MIC 能力集抽象 + 迁移失败即 T3 + 模块级重认证恢复，不做「希望式迁移」。
8. **MB4 过拟合** → 密封保持集 + 预注册 + 三方复现（E414）；对抗盲区地图单独冻结（E406）以防调参。

## 2. 形式化定义（要点版）

**定义 383（域描述子与 COD）** d=(env,self,task,shift_axes)；𝔇_cert=∩_i D_cert^i；mem 三值，unknown 保守视为 out。

**定义 384（安全层级格）** T0 名义 / T1 移位容忍 / T2 移位鲁棒 / T3 未知；保证集合包含序，组合 min（非补偿），任何组合不抬高层级。

**定义 385（DEC）** EC + 域描述子 + 认证域 + 默认层级 + 可迁移函数 + 层级包络 + 冗余检测器组；证书因此**域索引化**。

**定义 386（SMM 四分解）** Δ_cov（密度比/Λ/δ_w）、Δ_con（TV≤ε_con）、Δ_dyn（扰动球 ρ）、Δ_nov（新类质量 η）；输出移位证书 S；检测器组不一致即保守化。

**定义 387（可迁移界与层级赋值）** δ=δ_w+ε_con+η+Lρ；覆盖 ≥ 1−α−δ；按 δ 与检测器健康赋 T0/T1/T2，任一项不可估 ⇒ T3。

**定义 388（DYM/PEC）** 植物六分量，与 DPEM 同构；扰动观测器 + 参数/接触/热/磨损/执行器；L5 激励通道成本可为负。

**定义 389（域裕度）** m=min slack；m_rob=m−β·U_m；C_dom={m_rob≥0}；unknown ⇒ m_rob=−∞。

**定义 390（DM-CBF）** ḣ_dom ≥ −α(h_dom)；U_dom = 物理 CBF ∩ 域 CBF ∩ 层级包络；分层前向不变性；不可行即降级阶梯。

**定义 391（DOM 安全探索）** 目标含 κ·I_shift(S;y'|do(u))，硬约束 u∈U_dom、时域 m_rob≥0、REG 时序契约。**探索必须已认证。**

**定义 392（ATC）** 升级走 e-process（E_t≥1/α_u 且 liveness∧agree∧calib），降级立即非补偿到 T3 并重置 E。降级快、升级慢。

**定义 393（SHIFTGAUGE 与 J_SHIFT）** R73 三域 + 移位域；J_SHIFT=J_MOD⊗J_TRANS⊗J_TIER；S=0∧T0 时逐指令等于 R73。

**定义 394（移位因果归因，ECG）** 用 IP-302 的 ECG 判定哪条机制边变了（视角→深度、接触→位姿、负载→跟踪），定向降级 + 反事实查询；因果链断裂 ⇒ T3。

**定义 395（跨本体域契约，MIC）** 形态相关分量抽象为「证据能力集」；跨本体迁移是有界域移位的特例；失败即 T3 + 模块级重认证；核心改动 <5 行。

**定义 396（层级化降级阶梯）** ①缩包络 → ②受影响模态 stub → ③认证安全停；任何降级不违反物理 CBF；任何升级不跳级。

**定义 397（MB4）** 四轴移位 × 三时间剖面 × 三任务；预注册+固定种子+SEAL-MB4；指标：有效覆盖、假安全率、恢复时间、任务可用率、抖振次数。

**定义 398（CPB v2）** C4←(DEC,SMM,J_TRANS)←MB4←AB4←(假安全率,有效覆盖,可用率,恢复时间)；C5←(DYM,DOM,ATC)←MB4←AB5←(收敛步数,探测违规率,任务收益)；非绑定=附件。

**定义 399（可审计结构上限）** |T|=4、检测器组≤3、迁移图≤12 边、δ 分量≤4、DYM 分量≤6——部署期静态校验 + 运行时增量校验的图性质。

```python
        refl = sum(m.reflex_cost(msg) for m in mods)               # 可含负项(L5)
        return prog + params.kappa * info - risk - refl
```

## 4. 推导

**引理 38（移位四分解的条件可识别性与检测器冗余）** 各分量有独立观测机制时近似可识别（密度比/残差-标签代理/支撑外质量/扰动残差分别主导）；不可识别（如无支撑重叠 ⇒ w 不可估）必须报 unidentifiable 而非默认 0，并保守化为 T3。系：**「看不见的移位」必须编码为「看不见」，不是「没有」。**

**引理 39（层级单调性与非补偿组合）** τ_out = min τ_i ≤ 任一输入；τ_transfer 只依赖 S 与 DEC，不提升层级；升级仅由 ATC 触发。⇒ 组合与迁移都不产生认知免费午餐；R73 引理 34 被提升为跨域结论。

**引理 40（可迁移覆盖下界，条件性）** (a) w≤Λ、δ_w ⇒ 加权 conformal ≥1−α−δ_w；(b) sup TV≤ε_con ⇒ ≥1−α−ε_con；(c) 新类质量 η ⇒ ≥1−α−η；(d) ‖Δf‖≤ρ 且有非空鲁棒不变集 ⇒ 轨迹风险 ≤ε(τ)+Lρ。并集界 δ=δ_w+ε_con+η+Lρ，覆盖 ≥1−α−δ；δ→0 回到 R73。任一分量无上界/不可识别 ⇒ δ=∞、T3。系：**R73 的「契约表达力」变成一个可写进证书的数 δ。**

**引理 41（DM-CBF 分层前向不变性）** h_dom=m_rob 在认证域内 Lipschitz、相对度 1，h_phys 同理；初值双非负且每周期 U_dom 可行 ⇒ 闭环保持 x∈C_dom∩C_phys；U_dom 为空 ⇒ 按定义 396 阶梯先缩包络再安全停，不进不可行区。系：**域安全与物理安全是并联硬约束，不能互相补偿。**

**引理 42（安全探索收益与有限停止，双账本）** L5 使 c_reflex^p 可为负，R73 引理 36 的成本下界失效。拆 B_cons（非负安全维持成本，仍正下界）与 B_info（信息势 Φ_t=H(S|y_{1:t})，单调不增且 ≥0）。U_dom 门控 ⇒ 探测期违规率 ≤1−α；e-process 停止时间 T=inf{t:E_t≥1/α_u} 满足 P(T<∞)≤α_u，且在持续激励（Fisher 正定）下以概率 1 有限。系：**停止性来自信息势与 e-process，而非单纯成本下界——对 R73 引理 36 的必要修正。**

**定理 30（SHIFTGAUGE 严格包含 MODGAUGE）** S=0（δ=0、agree∧alive∧calib）且 τ=T0 时：DEC→EC、DYM→stub、DOM→PVOP+ERVOI、ATC→恒等，J_SHIFT 逐指令等于 J_MOD（R73 定理 28）；再按 R73 定理 27 退化到 R72/R71/R68。安全单调不减。

**定理 31（分级证书安全语义，条件性）** 若层级赋值 soundly（检测器假「分布内」率 ≤β_det、引理 40 界成立、ATC 假升级 ≤α_u），则物理风险 ≤ ε(τ)+Lδ(τ)+β_det。证明重量显式落在**检测器健全性 β_det 与迁移界假设**上；β_det 不可估只能声明 T3——不允许「未知地乐观」。

**定理 32（运动即认证的不可抬高性）** 在引理 41–42 下：安全探索 (i) 不降低已成立保证（U_dom 门控）；(ii) 检测器失活/分歧时不能抬高层级（ATC 条件）；(iii) 持续激励下以概率 1 有限时间建立可认证的**正确**层级（e-process 一致性）。**盲区移位不在保证内——见本轮最大风险。**

## 7. 本轮最大风险

**一句话**：SHIFTGAUGE 把 R73 的「契约表达力」风险替换成了「**检测器健全性**」风险——整个分级安全语义都条件于移位检测器与可迁移界在其盲区外仍然可靠；一个**静默失效或存在系统性盲区的检测器**会让系统在真实世界已经越域时继续持有高等级证书，而这一次它甚至拥有一块「全绿」的仪表盘来证明自己合规，因此**检测器本身成为新的单点故障，而且可能比没有检测器更危险**。

次级风险与缓解：
1. **迁移界空洞（δ 过松）→ 安全但无用** → 覆盖-尺寸 Pareto；域先验收紧 Λ/ε_con；δ 逐分量追溯定位「拖后腿项」。
2. **检测器自证循环** → 冗余独立检测器 + 外部基准（本体/接触/已知几何，R73 定义 378）+ 挑战输入；calib_ok 失效即降级。
3. **安全集过窄导致激励不足**（无法升级）→ 「保持低层级」为合法稳定态；分层激励；离线辨识补充。
4. **渐进漂移检测滞后** → CUSUM + 漂移速率估计 + 域裕度导数项进 DM-CBF；阈值随漂移速率自适应。
5. **层级抖振** → 滞回 + 最小驻留时间，但**只延迟升级、绝不延迟降级**。
6. **探索动作诱发失稳** → 鲁棒 CBF 优先级严格高于信息增益；U_dom 内求解；激励受执行器包络约束。
7. **跨本体域描述子不完备** → MIC 能力集抽象 + 迁移失败即 T3 + 模块级重认证恢复。
8. **MB4 过拟合** → 密封保持集 + 预注册 + 三方复现（E414）；盲区地图 E406 单独冻结。
