# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因闭环」IP-214~223；本轮灵感：「可扩展性」×「失败恢复」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因能力依赖「故障属于有限假设集」与「视觉/几何失效相互独立」两个假设；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——系统因「已经归因」而更自信地继续执行。** 本轮不再增加第 7 个假设，而是换两个问题：**当故障类型随物体/技能/机器人规模增长而开放时，如何不枚举地覆盖？当故障被检出后，如何安全地回来，而不是停在原地或慌乱回撤？** 本轮核心命题是：
>
> **把 VISTA 的「有限假设 + 一次性定向降级」升级为「可组合故障代数 + 可恢复执行闭环」：用故障基与稀疏潜码把覆盖从枚举变成组合，用分布无关新颖性检测拒绝强行归因，用恢复契约与可恢复性证书把「停下来」变成「安全地回来」，并用证书代数/缓存让认证成本随变化量而非总量增长。**

## 0. 直觉与动机

**灵感 1（可扩展性 → 故障不是清单，而是语法）**
直觉：VISTA 的 6 个假设像一张手写清单；每遇到新物体、新接触、新传感器，就要新增假设并重新标定 `p(ρ|H)`，标定成本随假设数线性增长，组合故障更是组合爆炸。更自然的看法是：故障由少量**基故障**组合而成——常值偏置、比例误差、时间滞后、饱和、接触刚度偏差、遮挡/透明、策略动作偏置——它们通过**叠加、调制、级联、相乘**组合。于是覆盖从「枚举 `O(|ℋ|)`」变成「组合 `O(B^d)`」；推断只需恢复一个稀疏的基系数向量与少量组合边，样本复杂度 `O(s log B)` 而不是 `O(B^d)`。但必须诚实：可组合性本身是假设，真实故障可能落在基张成之外；因此需要「残差新颖性」作为逃生门，而不是把一切都投影到基上。

**灵感 2（可扩展性 → 证书应像增量构建，而不是每次全量重证）**
直觉：VISTA 的 CSC/AIC 对「每个假设 × 每个技能 × 每步」逐一验证；当技能、物体、机器人数量上去，验证就是笛卡尔积。软件工程早已解决类似问题：**assume-guarantee 契约、内容寻址缓存、依赖图增量重编译**。证书也可以如此：技能证书只声明自己的前后条件与假设，组合时做契约匹配；缓存键是「组件 + 参数 + 故障基版本 + 环境」的哈希；只有变化的组件及其下游需要重证。这样规模增长时，成本随「变化量 `Δ`」而不是「总量 `N×M`」增长。风险是缓存失效与分布漂移：缓存必须绑定标定版本，漂移检测触发失效。

**灵感 3（失败恢复 → 恢复不是回滚，而是重新接地）**
直觉：VISTA 检出故障后主要是「膨胀球、缩短前缀、早停」，但没有回答「然后呢」。真实世界不可回滚（物体已移动、已形变、已洒出），所以恢复不是 undo，而是 **re-ground**：退到一个已知安全的锚点（预接触位姿/释放点/回撤点），重新估计几何与力，重新规划，必要时换技能。定义**恢复盆地**：从盆地内任意可达状态，存在一条恢复策略能在有界时间/风险内回到认证安全集或安全 idle。恢复因此是一个可被证书约束的规划问题，而不是 ad-hoc 的异常处理。

**灵感 4（失败恢复 → 恢复本身也可能是故障源）**
直觉：最危险的时刻往往不是第一次故障，而是「慌忙恢复」——在错误估计下回撤撞到障碍、抓取未释放时强行抬升、在人群上方松手。因此恢复动作必须与正常动作一样被认证；定义**恢复陷阱**：恢复动作的风险高于继续或等待的状态/动作。恢复证书必须排除陷阱集，并给出**有界重试阶梯**（重接地→重规划→回撤→safe idle→人），且证明不会无限循环。

**灵感 5（合流 → PHOENIX：Predictive Hypothesis cOmposition, Novelty detection, and Incremental eXecution recovery）**
闭环：**FAB** 故障基/组合语法 → **LFE** 潜码稀疏归因 → **NOD** 新颖性检测（未知故障不强行归类）→ **RCL** 恢复契约检索 → **RCC** 可恢复性证书 → **RAP** 恢复感知前缀（`k*=min(H,m,m_rec)`）→ **CAA** 证书代数与缓存（可扩展认证）→ **FAM** 故障图集记忆（语义流增量学习）→ **AIC-R** 对抗/级联/陷阱认证 → **J_phoenix**。VISTA 回答「谁坏了」，PHOENIX 回答「还会不会有没见过的坏、以及坏了怎么安全回来」。

**灵感 6（VISTA 组件的原位升级）**
- **FIR → FIR-C**：从 6 假设枚举升级为故障基稀疏编码 + 组合边检测；未知故障交给 NOD。
- **NOD 新增**：conformal 新颖性 p 值；novel 时禁止定向膨胀，走保守联合 + 数据采集。
- **CSC → RAP**：前缀约束从 `k*≤m` 扩为 `k*≤min(m,m_rec)`，并要求前缀内每步都在恢复盆地。
- **RSC-V → RSC-R**：不确定球增 `r_rec`（恢复能力不确定度）；恢复能力不足时优先缩短 k，而非盲目膨胀几何。
- **CSP-V → CSP-R**：技能图增「恢复边」（recovery skills），每条边带恢复契约与前后条件。
- **OLP / DIR / SSB**：在线学习增故障图集与恢复轨迹，仍只在语义流写。
- **AIC-V → AIC-R**：干扰集增级联故障、恢复陷阱、恢复诱导故障、延迟故障。
- **J_vista → J_phoenix**：证书增 `fault_code`、`composition_edges`、`novelty_pvalue`、`recovery_contract_id`、`recoverability_margin`、`recovery_trace_hash`、`atlas_version`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（PHOENIX 闭环）**：PHOENIX = (VISTA, FAB, LFE/FIR-C, NOD, RCL, RCC, RAP, CAA, FAM, AIC-R, J_phoenix)。定位：VISTA 的「故障覆盖可扩展 + 检出后可恢复」升级。不变式：**故障编码、组合边检测、恢复契约检索、证书代数/缓存、图集更新只在语义流；实时流只做阶段化残差采集、恢复盆地快速判定、恢复感知前缀执行与早停，零学习写操作。**
- **定义 234（故障代数基与组合语法）**：基故障 `ℬ={b_1,…,b_B}`，每个 `b_i` 是作用在名义转移/观测模型上的算子。故障表达式由语法生成：`f ::= θ_i b_i | f⊕f | f⊙g | f∘g | f⊗g`，分别表示叠加、状态/阶段调制、级联、相乘；深度 `d`。覆盖数 `|ℱ_d| = Θ(B^d)`，但推断只需稀疏系数与少量组合边。
- **定义 235（故障潜码与稀疏归因 FIR-C）**：观测签名 `ρ=Ψ(f)+ε`。在名义点线性化并用离线字典 `S=[s_1,…,s_B]` 与组合特征字典 `S_pair`，求解 `θ̂=argmin ||ρ−Sθ||²_Σ + λ||θ||_1 + μ||θ_pair||_{2,1}`；`f̂=Σθ̂_i b_i + Σθ̂_{ij}(b_i∘b_j)`。输出稀疏支撑 `supp(θ̂)`、组合边 `E_pair` 与残差 `r=||ρ−Sθ̂−S_pairθ̂_pair||_Σ`。
- **定义 236（组合可辨识性）**：字典互相关 `μ=max_{i≠j}|⟨s_i,s_j⟩|/(||s_i||·||s_j||)`。若故障在基下 `s`-稀疏且 `μ<1/(2s−1)`，则 OMP/BP 以高概率恢复支撑；组合裕度 `κ_comp=λ_min(SᵀΣ⁻¹S)/λ_max(·)`，`κ_comp` 由三阶段对比度与基近正交性控制。
- **定义 237（新颖性检测 NOD）**：用标定集残差 `{r_i}` 构造 conformal p 值 `p_nov(r)=(1+Σ_i 1[r_i≥r])/(n+1)`；若 `p_nov≤α_nov` 或潜码落在标定支撑之外（低密度），判 `novel`。**novel 时禁止 FIR-C 定向归因与定向膨胀**，只允许保守联合膨胀、safe_idle 与数据采集。分布无关保证：对可交换新样本，误报新颖率 `≤α_nov`。
- **定义 238（恢复锚点、恢复盆地与恢复视界）**：锚点集 `𝒜`（预接触位姿、释放点、回撤点、home）。恢复盆地 `B_rec={s | ∃π_rec: 从 s 执行 π_rec 能在 T_rec 内到达 𝒞∪Idle，且二次伤害≤ε_dmg}`。恢复视界 `m_rec(s)=max{k | Reach_k(s)⊆B_rec}`。
- **定义 239（恢复契约）**：`c=(pre, π_rec, post, T_rec, β_rec, ε_dmg, version)`；`pre` 含适用故障类/新颖性标志与资源前提，`post` 为认证安全集 `𝒞` 的子集或 `Idle`。契约可组合：若 `c_1.post⇒c_2.pre`，则 `c_2∘c_1` 合法。
- **定义 240（可恢复性证书 RCC）**：`RCC(s,k,c)` 成立 ⇔ 对前缀 `k` 内任意可达 `s'`：`s'∈B_rec` ∧ `c.pre` 在 `s'` 成立 ∧ `P[到达 c.post 于 T_rec 内]≥1−β_rec` ∧ 二次伤害 `≤ε_dmg` ∧ 恢复路径避开陷阱集 `𝒯`。若 `s'` 只能到达 `𝒯` 或 `c` 不适用，则 RCC 失败，必须缩短 k 或转 safe_idle。
- **定义 241（恢复感知前缀 RAP）**：`k*(A_t)=max{k≤min(H,m,m_rec) | ∀H∈supp_δ(post)∪{novel_fallback}: RCC(s_t,k,c_H)}`。执行 `k*` 步后**强制重接地与重归因**；若 `k*=0`，不执行块，进入恢复阶梯。
- **定义 242（证书代数 CAA）**：证书为判断 `C=(P,Q,A,G,E,ver)`（前条件、后条件、假设、保证、证据、版本）。顺序组合：`C_1∘C_2` 在 `Q_1⇒P_2` 时成立，后条件 `Q_2`；并行组合在资源不相交时成立；共享资源用 rely-guarantee 交叉假设。代数保证：组合证书的可靠性只依赖子证书可靠性与契约匹配，不依赖全局重证。
- **定义 243（证书缓存与增量验证）**：缓存键 `key=H(component_id, params, fault_basis_ver, env_ver, calib_ver)`；依赖图 `D` 记录证书间引用。参数/版本变化或漂移检测触发失效，失效沿 `D` 向下游传播；未变组件直接复用。增量成本 `O(Δ_components + Δ_edges)`，而非全量 `O(N·M)`。
- **定义 244（故障图集记忆 FAM）**：episode `e=(ρ, θ̂, E_pair, r, p_nov, recovery_trace, outcome)`；按潜码/签名最近邻检索，供 FIR-C 先验与 RCL 契约推荐。新颖故障进入隔离区，经离线验证后才可扩基/发新证书；实时流只读。
- **定义 245（恢复策略与有界重试阶梯）**：阶梯 `L0 重接地 → L1 重规划 → L2 回撤到锚点 → L3 safe_idle → L4 人/遥操作`。每级有 `T_i` 与风险预算；用势函数 `Φ_rec`（到 `𝒞∪Idle` 的保守距离）保证每次升级严格降低势或消耗有界预算，禁止无限重试。
- **定义 246（AIC-R 对抗认证）**：`ℰ_R=ℰ_V×ℰ_comp×ℰ_rec`；`ℰ_comp` 含级联/组合故障、基外故障、慢漂移；`ℰ_rec` 含恢复陷阱、恢复诱导故障（回撤撞障/松手/过载）、延迟故障（块边界后才显现）。`n_cert=160`，其中 32 给组合/恢复最坏；证书增 `recovery_cert_ver` 与 `trap_check_ver`。
- **定义 247（J_phoenix 证书）**：`J_phoenix=(J_vista, fault_code, composition_edges, novelty_pvalue, recovery_contract_id, recoverability_margin, k*, recovery_trace_hash, atlas_version, aic_r_ver)`。`Valid(J_phoenix) ⇔ Valid(J_vista) ∧ (p_nov>α_nov ∨ 已执行 novel 保守回退) ∧ RCC(s_t,k*,c) ∧ k*≥1 ∧ k*≤min(m,m_rec) ∧ 契约/缓存版本一致 ∧ 避开陷阱集`。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（组合覆盖与稀疏可辨识）**：若故障在基 `ℬ` 下 `s`-稀疏、字典互相关 `μ<1/(2s−1)`，则 OMP 以高概率恢复支撑，样本复杂度 `O(s log B)`；深度 `d` 的覆盖数为 `Θ(B^d)`，但推断仍只依赖 `O(s log B)` 个标定样本。这把「故障覆盖」从枚举成本变成组合成本。
- **引理 10（新颖性门的安全退化）**：conformal p 值对可交换新样本满足 `P[p_nov≤α_nov]≤α_nov`；因此未知故障不会被系统性强行归因，最坏情形退化为保守联合膨胀 + safe_idle，而不是「错误定向膨胀后更自信地执行」。
- **引理 11（可恢复性证书的安全性）**：若 `RCC(s,k,c)` 成立且恢复契约的执行满足其假设，则前缀 `k` 内任意状态都能在 `T_rec` 内以 `≥1−β_rec` 到达 `𝒞∪Idle`，二次伤害 `≤ε_dmg`，且不经过陷阱集；因此「恢复」不引入超出正常执行的新风险。
- **定理 9（PHOENIX 端到端：可扩展覆盖 + 可恢复安全）**：在 A94–A99 下，未知/组合故障被 `novel` 或稀疏组合正确分流；`Valid(J_phoenix) ⇒` 归因可扩展 ∧ 不强行归因 ∧ 前缀可恢复 ∧ 恢复契约有效 ∧ 陷阱已排除 ∧ 图集/证书版本一致。
- **定理 10（证书代数与增量成本）**：证书代数对顺序/并行/rely-guarantee 组合可靠；在依赖图 `D` 上，单组件变更后的重证成本为 `O(Δ)`，全量枚举为 `O(N·M)`；当 `Δ≪N·M` 时加速比 `Ω(NM/Δ)`。
- **定理 11（恢复感知前缀的近最优性）**：风险 `R(H,k)=c_1σ_π²/H + c_2·1[k>m] + c_3·1[k>m_rec] + c_4·1[recovery_trap]`；对 `k≤min(m,m_rec)`，风险关于 k 不增、关于 H 单调不增，故最优 `H` 取计算允许最大值、`k*=min(H,m,m_rec)`。这把第 65 轮「长预测、短执行」升级为「长预测、短执行、可恢复」。
- **实时性**：FIR-C/NOD/RCL/RCC/CAA/FAM 全在语义流；实时流只增稀疏编码残差（`<0.3ms`）、NOD 快速门（`<0.05ms`）、恢复盆地判定（`<0.1ms`）与 RAP 早停（`<0.03ms`），目标仍 `≤2.8ms`（A100 修订契约）。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（PHOENIX 闭环）** PHOENIX 是 VISTA 的「故障覆盖可扩展 + 检出后可恢复」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 FAB（故障代数基）、LFE/FIR-C（稀疏故障编码）、NOD（新颖性检测）、RCL（恢复契约库）、RCC（可恢复性证书）、RAP（恢复感知前缀）、CAA（证书代数与缓存）、FAM（故障图集）、AIC-R（恢复对抗认证），并原位升级 CSC→RAP、RSC-V→RSC-R、CSP-V→CSP-R、AIC-V→AIC-R、J_vista→J_phoenix。不变式：**故障编码、组合边检测、新颖性判定、恢复契约检索、证书代数/缓存、图集更新只在语义流与低频线程；实时路径只做阶段化残差采集、NOD 快速门、恢复盆地判定、恢复感知前缀执行与早停，零学习写操作。**

**定义 234（故障代数基与组合语法）** 基故障 `ℬ={b_1,…,b_B}`，每个 `b_i` 是作用在名义转移/观测模型 `(x_{t+1},y_t)=F(x_t,u_t)` 上的算子，例如：常值偏置 `b_bias`、比例误差 `b_scale`、时间滞后 `b_lag`、饱和 `b_sat`、接触刚度偏差 `b_stiff`、遮挡/透明 `b_occ`、策略动作偏置 `b_pol`。故障表达式由语法生成：
`f ::= θ_i b_i | f⊕f | f⊙g | f∘g | f⊗g`，
其中 `⊕` 为叠加（多故障并存）、`⊙` 为状态/阶段调制（故障幅度随载荷/位姿变化）、`∘` 为级联（一个故障诱发另一个）、`⊗` 为相乘（如力偏置 × 接触模型错）。表达式深度 `d`；覆盖数 `|ℱ_d|=Θ(B^d)`。**基与语法的价值不是假设真实世界一定可分解，而是把「新增故障」从「新增一个标定假设」变成「新增一个基/一条组合规则 + 稀疏先验」，从而让覆盖随规模组合增长。**

**定义 235（故障潜码与稀疏归因 FIR-C）** 观测签名 `ρ=Ψ(f)+ε`（`Ψ` 为第 65 轮定义 220 的三阶段特征映射）。在名义点线性化，用离线字典 `S=[s_1,…,s_B]` 与组合特征字典 `S_pair`（对 `b_i∘b_j`、`b_i⊗b_j` 的签名做离线采样）求解
`θ̂,θ̂_pair = argmin_{θ,θ_pair} ‖ρ−Sθ−S_pairθ_pair‖²_Σ + λ‖θ‖_1 + μ‖θ_pair‖_{2,1}`。
输出稀疏支撑 `supp(θ̂)`、组合边 `E_pair={(i,j):θ̂_{ij}≠0}`、残差 `r=‖ρ−Sθ̂−S_pairθ̂_pair‖_Σ` 与后验近似
`P(b_i|ρ) ∝ exp(−‖ρ−s_iθ̂_i‖²_Σ/2σ²)·π_i`（用于定向处置）；组合故障的后验在基支撑上做边缘化。FIR-C 不再枚举 `p(ρ|H)`，而是恢复「哪些基、以何种组合」——这把 VISTA 的 `O(|ℋ|)` 标定与 `O(|ℋ|)` 推断降为 `O(B)` 字典与稀疏求解。

**定义 236（组合可辨识性）** 设字典列归一化，互相关
`μ=max_{i≠j}|⟨s_i,s_j⟩|/(‖s_i‖‖s_j‖)`。
若故障在基下 `s`-稀疏且 `μ<1/(2s−1)`，则 OMP/BP 以高概率恢复支撑（压缩感知标准结论）；组合裕度
`κ_comp=λ_min(SᵀΣ_ρ⁻¹S)/λ_max(SᵀΣ_ρ⁻¹S)`。
三阶段（零力窗/轻触/加载）使不同基故障的签名列近正交：偏置在零力窗出现、几何在接近/轻触出现、刚度/模型在加载出现；因此 `κ_comp` 由阶段对比度控制。若组合项 `θ_pair` 不可忽略，则先恢复基支撑，再在固定支撑上对 `S_pair` 做 group-lasso 检测组合边；组合边可辨识条件为对应组合特征列与基列及彼此近正交。

**定义 237（新颖性检测 NOD）** 在标定集 `{ρ_i}` 上计算残差 `r_i`，对新签名 `ρ` 得 `r`，构造 conformal p 值
`p_nov(r)=(1+Σ_{i=1}^n 1[r_i≥r])/(n+1)`。
若 `p_nov≤α_nov`，或潜码 `θ̂` 落在标定支撑的低密度区（如马氏距离 `>χ²_{B,1−α}`），判 `novel`。**novel 时禁止 FIR-C 定向归因与定向膨胀**：只允许 (i) 保守联合膨胀 `r←r_geo+r_force+r_model+r_rec`，(ii) 进入恢复阶梯的 safe_idle/重接地，(iii) 将 `(ρ,θ̂,r,p_nov)` 送入 FAM 隔离区等待离线扩基。由 conformal 可交换性，`P[p_nov≤α_nov]≤α_nov`（对可交换新样本），因此未知故障不会被系统性强行归因；最坏情形是「保守但安全」而非「错误但自信」。

**定义 238（恢复锚点、恢复盆地与恢复视界）** 锚点集 `𝒜` 包含预接触位姿、释放点、回撤点、home 等**结构上可验证安全**的位姿。恢复盆地
`B_rec={s | ∃π_rec: 从 s 执行 π_rec 能在 T_rec 内到达 𝒞∪Idle，且二次伤害≤ε_dmg}`，
其中 `𝒞` 为 VISTA/GRIP 的认证安全集，`Idle` 为力/速度归零的安全静止集。恢复视界
`m_rec(s)=max{k | Reach_k(s)⊆B_rec}`，
`Reach_k(s)` 为在故障后验支持集下 `k` 步可达状态集。`m_rec` 是**执行承诺的第二道上界**：第 65 轮的 `m` 只保证「能在越过不可逆点前停下」，`m_rec` 进一步保证「停下之后能回来」。

**定义 239（恢复契约）** 恢复契约
`c=(pre, π_rec, post, T_rec, β_rec, ε_dmg, version)`：
`pre` 为适用前提（故障基/组合边/新颖性标志、资源、锚点可达性），`π_rec` 为恢复策略（可调用恢复技能），`post⊆𝒞∪Idle`，`T_rec` 为时间上界，`β_rec` 为失败概率上界，`ε_dmg` 为二次伤害上界。契约可顺序组合：若 `c_1.post⇒c_2.pre`，则 `c_2∘c_1` 合法，`T=T_1+T_2`，`β≤β_1+β_2`，`ε≤ε_1+ε_2`（联合界）。契约库按 `(fault_code, composition_edges, novelty_flag)` 检索；无匹配契约时只能用通用回撤/安全 idle 契约。

**定义 240（可恢复性证书 RCC）** `RCC(s,k,c)` 成立 ⇔ 对前缀 `k` 内任意可达 `s'∈Reach_k(s)`：
1. `s'∈B_rec`；
2. `c.pre` 在 `s'` 成立；
3. `P[执行 π_rec 于 T_rec 内到达 c.post]≥1−β_rec`；
4. 二次伤害 `≤ε_dmg`；
5. 恢复路径 `τ_rec` 避开陷阱集 `𝒯`（定义 246）。
若存在 `s'` 只能到达 `𝒯`、或 `c` 不适用、或 `k>m_rec`，则 RCC 失败。RCC 的验证在语义流用离线契约 + 在线可达集近似完成；实时流只做「是否仍在盆地」的快速判定与早停。

**定义 241（恢复感知前缀 RAP）** 对块 `A_t` 与后验支持集 `supp_δ(post)`（含 `novel_fallback`），
`k*(A_t)=max{k≤min(H,m,m_rec) | ∀H∈supp_δ(post)∪{novel}: RCC(s_t,k,c_H)}`。
执行 `k*` 步后**强制重接地与重归因**；若 `k*=0`，不执行任何块动作，直接进入恢复阶梯（定义 245）。这使「长预测、短执行」升级为「长预测、短执行、可恢复」：`H` 仍只用于前瞻与方差缩减，`k*` 同时受不可逆视界 `m` 与恢复视界 `m_rec` 约束。

**定义 242（证书代数 CAA）** 证书为判断 `C=(P,Q,A,G,E,ver)`：前条件 `P`、后条件 `Q`、假设 `A`、保证 `G`、证据 `E`（含 conformal 覆盖、标定版本、故障基版本）、版本 `ver`。
- **顺序组合**：`C_1=(P_1,Q_1)`，`C_2=(P_2,Q_2)`，若 `Q_1⇒P_2`，则 `C_1∘C_2=(P_1,Q_2)`。
- **并行组合**：资源不相交时 `C_1‖C_2=(P_1∧P_2, Q_1∧Q_2)`。
- **共享资源**：用 rely-guarantee，`C_1` 依赖 `C_2` 的保证作为其假设，反之亦然；组合可靠性要求双方保证互不矛盾。
- **可靠性**：若所有子证书在其假设下可靠、且契约匹配成立，则组合证书可靠；证明是对执行轨迹的归纳（每步满足当前子证书的前条件，终止时满足后条件）。

**定义 243（证书缓存与增量验证）** 缓存键
`key=H(component_id, params, fault_basis_ver, env_ver, calib_ver)`。
依赖图 `D` 的节点为证书，边为「引用/依赖」。当某组件参数、故障基版本、环境版本或标定版本变化，或漂移检测（`e_vis`/`ρ` 分位数漂移、NOD 新颖率异常）触发失效时，沿 `D` 向下游传播失效标记；未失效节点直接复用缓存证书。增量重证只覆盖「变化节点 + 其下游」，成本
`O(Δ_components + Δ_edges)`，
而全量枚举为 `O(N_skills·M_faults·steps)`。缓存键绑定版本是可靠性前提：**版本不一致的证书一律视为无效**。

**定义 244（故障图集记忆 FAM）** episode
`e=(ρ, θ̂, E_pair, r, p_nov, recovery_trace, outcome, ver)`。
FAM 支持：(i) 按潜码/签名最近邻检索，给 FIR-C 提供稀疏先验与组合边候选；(ii) 按故障码检索恢复契约；(iii) 新颖故障隔离区，只有离线验证（仿真 + 真机标定 + AIC-R）通过后才扩基或发新契约。**实时流只读，图集写入与扩基全在语义流/离线。**

**定义 245（恢复策略与有界重试阶梯）** 阶梯 `L0 重接地 → L1 重规划 → L2 回撤到锚点 → L3 safe_idle → L4 人/遥操作`。每级有预算 `(T_i, β_i, ε_i)`；用恢复势 `Φ_rec`（到 `𝒞∪Idle` 的保守距离）作为进展度量。规则：每次升级必须满足 `Φ_rec` 严格下降，或消耗该级预算并进入下一级；总预算 `ΣT_i≤T_max`。由良基归纳，阶梯在有界步内终止于 `𝒞∪Idle` 或 `L4`，不会无限重试。

**定义 246（AIC-R 对抗认证）** 干扰集
`ℰ_R=ℰ_V×ℰ_comp×ℰ_rec`：
- `ℰ_comp`：级联故障、基外故障、慢漂移、组合边误检、故障延迟到块边界后出现；
- `ℰ_rec`：恢复陷阱（回撤撞障、抓取未释放抬升、人群上方松手、过载回弹）、恢复诱导故障（恢复动作诱发新故障）、恢复契约版本错配；
- `ℰ_V`：沿用第 65 轮视觉/时序对抗。
`n_cert=160`，其中 32 给组合/恢复最坏；`ρ_dir` 在 `ℰ_R` 上重算；`J_phoenix` 增 `recovery_cert_ver`、`trap_check_ver`、`atlas_version`。**级联/基外故障下不要求归因正确，只要求 NOD 判 novel 或 RCC 拒绝认证，并安全降级。**

**定义 247（J_phoenix 证书）**
`J_phoenix=(J_vista, fault_code, composition_edges, novelty_pvalue, recovery_contract_id, recoverability_margin, k*, recovery_trace_hash, atlas_version, aic_r_ver)`。

### IP-225/226 FIR-C + NOD（稀疏故障编码与新颖性门）

```python
class SparseFaultEncoder:
    """故障基稀疏编码 + 组合边检测；只输出可解释的基/边，不枚举假设。"""
    def __init__(self, S, S_pair, Sigma_inv, lam=0.1, mu=0.1, delta_nov=0.05):
        self.S, self.S_pair, self.Sigma_inv = S, S_pair, Sigma_inv
        self.lam, self.mu, self.delta_nov = lam, mu, delta_nov

    def fit(self, rho):
        # 1) 基支撑：加权 Lasso / OMP
        theta = weighted_lasso(self.S, rho, self.Sigma_inv, self.lam)
        support = np.flatnonzero(np.abs(theta) > 1e-6)
        # 2) 固定支撑上检测组合边：group lasso
        resid = rho - self.S @ theta
        theta_pair = group_lasso(self.S_pair, resid, self.Sigma_inv, self.mu)
        edges = [(i, j) for (i, j), v in theta_pair.items() if abs(v) > 1e-6]
        r = float(np.sqrt(resid @ self.Sigma_inv @ resid))
        return theta, edges, r

    def attribute(self, theta, edges, prior, atlas):
        # 基故障后验 + 组合边证据；用图集先验平滑
        logp = {i: -0.5 * theta[i] ** 2 / prior.var[i] + prior.logp[i]
                for i in np.flatnonzero(np.abs(theta) > 1e-6)}
        post = softmax(logp)
        fault_code = frozenset(post)
        return post, fault_code, edges


class NoveltyDetector:
    """conformal p 值 + 潜码密度；novel 时禁止定向归因。"""
    def __init__(self, calib_residuals, alpha_nov=0.05):
        self.r_sorted = np.sort(np.asarray(calib_residuals))
        self.n = len(self.r_sorted)
        self.alpha_nov = alpha_nov

    def pvalue(self, r):
        return (1.0 + np.sum(self.r_sorted >= r)) / (self.n + 1.0)

    def is_novel(self, r, theta, code_density):
        return (self.pvalue(r) <= self.alpha_nov) or (code_density(theta) < DELTA_DENSITY)

    def conservative_fallback(self, balls):
        # 不猜是谁坏了：联合膨胀 + 恢复阶梯
        r = balls['r_geo'] + balls['r_force'] + balls['r_model'] + balls['r_rec']
        return {k: r for k in balls}, 'L0_reground'
```

### IP-227/228 RCL + RCC（恢复契约与可恢复性证书）

```python
class RecoveryContract:
    def __init__(self, pre, pi_rec, post, T_rec, beta_rec, eps_dmg, version):
        self.pre, self.pi_rec, self.post = pre, pi_rec, post
        self.T_rec, self.beta_rec, self.eps_dmg = T_rec, beta_rec, eps_dmg
        self.version = version

    def compose(self, other):
        assert implies(self.post, other.pre), 'contract pre/post mismatch'
        return RecoveryContract(
            self.pre, lambda s: other.pi_rec(self.pi_rec(s)), other.post,
            self.T_rec + other.T_rec,
            min(1.0, self.beta_rec + other.beta_rec),
            min(self.eps_dmg, other.eps_dmg), (self.version, other.version))


class RecoverabilityCertificate:
    def holds(self, s, k, contract, fault_support, trap_set, reach_fn):
        if k > self.m_rec(s):
            return False
        for s_prime in reach_fn(s, k, fault_support):
            if s_prime not in self.B_rec:          # 出盆地
                return False
            if not implies(s_prime, contract.pre):  # 契约不适用
                return False
            if self.recovery_path_hits_trap(s_prime, contract, trap_set):
                return False                         # 恢复陷阱
            if self.tail_risk(s_prime, contract) > contract.eps_dmg:
                return False
            if self.failure_prob(s_prime, contract) > contract.beta_rec:
                return False
        return True
```

class CertificateAlgebra:
    def compose(self, c1, c2):
        assert implies(c1.Q, c2.P), 'assume-guarantee mismatch'
        return Cert(P=c1.P, Q=c2.Q, A=(c1.A, c2.A),

    def parallel(self, c1, c2, disjoint):
        assert disjoint(c1.resources, c2.resources)
        return Cert(P=c1.P and c2.P, Q=c1.Q and c2.Q,
                    A=(c1.A, c2.A), G=(c1.G, c2.G),
                    E=(c1.E, c2.E), ver=hash((c1.ver, c2.ver)))


class CertificateCache:
    def get_or_verify(self, key, component, ctx):
        if key in self.cache and not self.invalidated(key):
            return self.cache[key]
        cert = verify_component(component, ctx)
        self.cache[key] = cert
        self.dag.add(key, deps=component.deps)
        return cert

    def invalidate(self, changed_key):
        # 只沿依赖图向下游传播；未变子树直接复用
        for key in self.dag.descendants(changed_key):
            self.cache.pop(key, None)

### IP-233 PHOENIX 闭环算子（整合）

```python
def PHOENIX_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流（10–100Hz）————
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)
    phi_hat_geo, *_ = M.mel.infer_by_mode(M.ocb_skill.choose().mel_mode,
                                          V, T, P, L, x_prime)
    A = M.ach.propose(x_prime, H=M.H)
    visual = M.vpg.verify_and_predict(y_vis, A, M.mws.last_contacts)
    phases = M.stage.split(M.residual_log, visual)

    # 1) FIR-C + NOD：组合归因或拒绝归因
    theta, edges, r = M.fir_c.fit(M.signature(phases))
    if M.nod.is_novel(r, theta, M.fam.code_density):
        post, fault_code, recovery_hint = None, 'H_novel', 'L0_reground'
        M.balls, _ = M.nod.conservative_fallback(M.balls)
        M.fam.quarantine(M.signature(phases), theta, r)
    else:
        post, fault_code, edges = M.fir_c.attribute(theta, edges, M.prior, M.fam)
        M.balls = M.rsc_r.directed_demote(fault_code, M.balls, edges)
        recovery_hint = M.fam.best_recovery(fault_code, edges)

    # 2) RCL + RCC：检索契约并验证可恢复性
    contract = M.rcl.retrieve(fault_code, edges, recovery_hint) or M.rcl.generic_retreat
    trap_set = M.aic_r.trap_set(x_prime, phi_hat_geo)

    # 3) 规划 + 恢复感知前缀
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.csp_r.plan_chunks(goal, x_prime, phi_hat_geo, M.balls, post,
                              recovery_edges=M.rcl.available())
    k_star = M.rap.certified_prefix(tau.A, post, M.m, M.rcc, contract, trap_set)

    # 4) 执行：先证明能回来，再决定走多远
    if k_star == 0:
        M.ladder.enter(recovery_hint)            # 不执行块
        return M, None, None, build_j_phoenix(M, post, fault_code, edges, r, None)

    K_safe, EV_exec, cert_exec = realtime_step_phoenix(
        M, delta_f_req, tau, k_star, x_prime)
    # 5) 重接地 + 重归因（强制）
    M.reground(x_prime, W_meas, tactile, visual)
    post2, fault_code2, edges2 = M.fir_c.reestimate(M.residual_log)

    # 6) 语义流更新：图集、证书缓存、对抗认证
    M.fam.record(M.signature(phases), theta, edges, r, M.last_recovery_trace)
    M.cert_cache.invalidate_on_drift(M.drift_detector)
    rho_dir = M.aic_r.certify(tau, x_prime, phi_hat_geo, M.balls, post2,
                              contract, trap_set)
    return M, K_safe, EV_exec, build_j_phoenix(
        M, post2, fault_code2, edges2, r, k_star,
        cert_exec=cert_exec, rho_dir=rho_dir)
```

## 4. 推导

**引理 9（组合覆盖与稀疏可辨识）** 设故障在基 `ℬ` 下 `s`-稀疏，字典 `S` 列归一化且互相关 `μ<1/(2s−1)`。由压缩感知/OMP 的标准结果，`s`-稀疏系数可被精确恢复，所需样本数 `O(s log B)`（相对基大小对数）。覆盖方面，深度 `d` 的表达式数 `|ℱ_d|=Θ(B^d)`，但推断与标定只针对 `B` 个基与 `O(B²)` 个组合特征，故**覆盖随 `d` 指数增长、成本随 `B` 多项式增长**。组合边检测在固定基支撑后对 `S_pair` 做 group-lasso；若组合特征列与基列及彼此近正交（三阶段对比度保证），则边支撑可辨识。若真实故障落在基张成外，残差 `r` 增大，交由 NOD 处理。∎

**引理 10（新颖性门的安全退化）** 对可交换的新样本，conformal p 值满足 `P[p_nov(r)≤α_nov]≤α_nov`（标准 split-conformal 结论）。因此未知故障被误判为「已知」的概率受 `α_nov` 控制；一旦判 novel，系统禁止定向膨胀与定向归因，改为联合膨胀 + 恢复阶梯。于是最坏情形从 VISTA 的「强行归因 + 更自信执行」变为「保守 + 可恢复 + 收集数据」。注意：conformal 只给边际覆盖，分布漂移下需在线重校准（`α_nov` 名不副实是已知风险）。∎

**引理 11（可恢复性证书的安全性）** 设 `RCC(s,k,c)` 成立。对前缀 `k` 内任意可达 `s'`，`s'∈B_rec` 且 `c.pre` 成立，故存在恢复策略 `π_rec` 在 `T_rec` 内以 `≥1−β_rec` 到达 `c.post⊆𝒞∪Idle`，二次伤害 `≤ε_dmg`，且路径避开陷阱 `𝒯`。由契约执行的可测性，恢复过程不引入超出 `ε_dmg` 的新伤害；若恢复失败（概率 `≤β_rec`），阶梯进入 `L3 safe_idle` 或 `L4`。因此前缀承诺的风险为 `α_chunk + δ_fi + α_vis + β_rec + δ_nov`（联合界），不高于正常执行的风险预算加上显式恢复预算。∎

**定理 9（PHOENIX 端到端：可扩展覆盖 + 可恢复安全）** 在 A94–A99 下：
1. **覆盖可扩展**：故障在基下稀疏时，FIR-C 以 `O(s log B)` 样本恢复支撑与组合边（引理 9）；深度 `d` 覆盖 `Θ(B^d)`，无需为每个组合新增假设。
2. **不强行归因**：未知/基外故障由 NOD 以 `≤α_nov` 误报率判 novel，进入保守回退而非最近假设（引理 10）。
3. **前缀可恢复**：`k*≤min(m,m_rec)` 且 `RCC` 对支持集逐假设成立，故前缀内任意状态都能安全回来（引理 11）。
4. **恢复受认证**：恢复契约需通过 RCC 与 AIC-R；陷阱集 `𝒯` 被显式排除，恢复诱导故障在 `ℰ_rec` 下最坏认证。
5. **认证可扩展**：证书代数组合可靠，缓存绑定版本，增量成本 `O(Δ)`（定理 10）。
6. **优雅降级**：NOD novel→联合膨胀 + 恢复阶梯；无匹配契约→通用回撤 + safe_idle；证书过期→拒绝执行并重证；实时路径 ≤2.8ms，零学习写操作（A100）。∎

**定理 10（证书代数与增量成本）** 证书代数：顺序组合的可靠性由 `Q_1⇒P_2` 与子证书可靠性归纳可得；并行组合在资源不相交时互不干扰；rely-guarantee 在保证互不矛盾时可靠。缓存：设依赖图 `D` 有 `N` 个节点，单组件变更影响下游集合 `Δ`。未变节点直接复用缓存，只有 `Δ` 内节点重证，故成本 `O(Δ)`；全量枚举为 `O(N·M)`。当 `Δ≪N·M` 时加速比 `Ω(NM/Δ)`。可靠性前提：缓存键包含 `fault_basis_ver/env_ver/calib_ver`，任何版本不一致或漂移失效都使缓存证书不可用。∎

**定理 11（恢复感知前缀的近最优性）** 定义风险
`R(H,k)=c_1σ_π²/H + c_2·1[k>m] + c_3·1[k>m_rec] + c_4·1[recovery_trap] + c_5·β_rec(k)`，
其中第一项为动作估计方差（时间集成 `∼σ_π²/H`），第二/三项为越过不可逆视界与恢复视界的伤害，第四项为恢复陷阱，第五项为恢复失败风险。对 `k≤min(m,m_rec)` 且避开 `𝒯`，后三项为 0，`R` 关于 `k` 不增、关于 `H` 单调不增；故最优为 `H` 取计算允许最大值、`k*=min(H,m,m_rec)`。这给出「长预测、短执行、可恢复」的严格理由：**长视界只用于方差缩减与前瞻一致性，执行承诺同时截断在不可逆视界与恢复视界内。** ∎

**命题（PHOENIX 相对 VISTA 的保守性收益）** VISTA 在未知复合故障下只能二选一：强行归因（错误定向膨胀）或全保守（单一球膨胀 `κ_infl^{d_φ}`）。PHOENIX 在 NOD 判 novel 时用联合膨胀，但**只在 novel 时**；对基内组合故障，稀疏编码给出基支撑，RSC-R 只膨胀被归因的基/组合对应的球，几何分量保持。若真实故障是「力偏置 + 接触模型错」的组合，VISTA 会归入单一 `H_force` 或 `H_model`，PHOENIX 恢复 `{b_bias,b_stiff}` 并只膨胀 `r_force+r_model`，避免把几何球也膨胀。∎

## 8. 已知风险

**一句话**：PHOENIX 的可扩展性依赖「真实故障在故障基下稀疏可组合」、可恢复性依赖「恢复契约的适用域被正确刻画」；一旦未知复合故障落在基外、而恢复契约仍被错误匹配，系统会把「一次被检出的故障」升级为「一次被证书背书的错误恢复」，恢复本身成为级联故障的主源——这是本轮组合覆盖、证书代数与可恢复性论证共同依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **基外/非稀疏故障**：真实故障可能不稀疏或需要高阶组合；缓解：NOD 显式拒绝归因，FAM 隔离后离线扩基/加组合规则；对非稀疏情形退化为联合膨胀 + 恢复阶梯，不强行解释。
2. **恢复契约错配**：契约 `pre` 被错误满足（估计偏差、版本错配）；缓解：RCC 用可达集与陷阱集显式验证，契约绑定版本，AIC-R 注入错配；无匹配时只用通用回撤。
3. **恢复陷阱与恢复诱导故障**：回撤撞障、未释放抬升、人群松手；缓解：陷阱集 `𝒯` 离线构建 + 在线检测，AIC-R 最坏认证；RCC 要求路径避开 `𝒯`，否则 `k*=0`。
4. **证书缓存失效/漂移**：缓存键未覆盖的分布漂移导致「旧证书背新环境」；缓解：缓存键含 `env_ver/calib_ver`，漂移检测触发全下游失效，定期全量抽检。
5. **稀疏编码组合边误检**：`S_pair` 与基列相关导致虚假组合边；缓解：三阶段对比度 + group-lasso + 图集先验，边数上限与显著性检验。
6. **恢复阶梯不终止/抖动**：在 L0–L2 间来回；缓解：势函数 `Φ_rec` 严格下降或消耗预算，总预算 `T_max`，超过即 `L3/L4`。
7. **图集负迁移/遗忘**：新故障覆盖旧恢复契约；缓解：隔离区 + 回放 + 版本化扩基，旧证书不删除只标记 superseded。
8. **实时预算**：稀疏编码 + 盆地判定逼近 2.8ms；缓解：字典降维、OMP 早停、盆地用轻量分类器 + conformal、世界模型全部留语义流。
9. **conformal 边际覆盖在漂移下失准**：`α_nov/α_chunk` 名不副实；缓解：在线重校准 + 漂移检测 + 分环境/分视界校准。
