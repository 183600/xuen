# 第 8 轮 · SAGE：安全交互是泛化的早期信号，自适应控制是有界响应

> 检索/复核日期：**2026-10-27（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1、32 项桌面任务、通才单模型、选手自部署 + 官方远程真机 API。本轮灵感词是「安全交互」「泛化能力」「自适应控制」。我先纠正上一轮遗留的三个事实错误，再把三个词钉到本轮核实到的官方规则上，最后合成主判断：**官方排名是成功率优先、每任务 10 次（5 轴×2）、单模型、跨机器人、单日一槽、安全终止不补测；因此最划算的研究不是再堆一个模块，而是让机器人"知道自己正在失效"——用示范校准的运行时异常监测（安全交互信号）做早期 OOD 探测，用有界、低延迟的执行调节器（自适应控制）把近失败 episode 转成成功，从而在五条泛化轴和隐藏的跨机器人轴上同时提成功率。** 我把这个方案叫 **SAGE-GPR**（Safety-Aware Generalized Execution）。

## 0. 先纠正三个前提（否则后面全错）

### 0.1 "榜首不到 30%"是占位数据，不是真实榜单

用户看到的"榜首 <30%"确实存在，但它是**脚本生成的占位榜**：`leaderboard_data.json` 的 `generated_from` 仍是 `gen_leaderboard.py`，8 个模型 256 条 task_metrics 是占位；榜首 MolmoAct2 29.7% / 39.0 分，底部标注「即将发布」[S8][S9]。`runs.html` 同样是 256/256 占位。**真实成绩尚未上线（页面仍是占位数据）**。所以：

- 不能用它判断"头部方案长什么样"、更不能反推轴级瓶颈；
- 唯一可用的弱先验是：若真实结构类似，8 个占位模型的"步骤分−成功率"约 +6.9~+10.4pp，说明失败者往往做完了部分步骤但没完成全部——这与"成功率优先、步骤分只做 tie-break"的官方规则并不矛盾，但不能用来定位失败步骤。

### 0.2 排名规则不是"成功率与步骤分综合"，而是成功率 > 步骤分 > 提交时间

官方手册 4.3 原文：**总平均成功率 > 总平均步骤分 > 提交时间**；榜单取多次完整计分评测中**总平均成功率最高的一次**，同分再取步骤分最高的一次，仍同分取提交时间最早的一次 [S1][S2]。

这条修正直接改变优化目标：

- 上一轮把"终局放置占 ~60% 步骤分"当作第一性依据，方向仍对（终局是成功闸门），但**步骤分只是 tie-break**；为步骤分做局部优化，不如为"整条 episode 成功"做恢复。
- 任何"把 0 分变 1 分"的近失败恢复，价值高于"把 60 分变 80 分"的部分分优化。
- 多次计分跑取最好成绩：**稳定性与低方差本身有战略价值**；但每次完整跑都占用一个测试时段，不能靠无限刷榜。

### 0.3 评测结构比上一轮假设更苛刻：10 次/任务、单模型、跨机器人、单日一槽

官方手册本轮补齐的关键规则 [S1][S2]：

- 每任务 **10 次独立运行**，5 类泛化（位置/干扰物/背景/未见物品/人为干扰）**各 2 次**；单次真机最长 **180s**，超时算失败，按完成情况给步骤分。
- 全部 32 任务必须用**同一模型**完成，不得混合多个模型；架构不限（World Model/VLA 均可）。
- 同一任务的不同泛化场景在**同一台真机**评测；不同任务在每次测评中**随机分布到各台机器人**；同一泛化场景的多次测试也可能换机器人——**跨机器人差异是官方评测的一部分**，不是异常。
- **每队每日仅可预约一个测试时段**（计分正式评测与不计分单任务调试都算）；未按时接入/测试失败视为机会已用；参赛方原因（网络、服务、推理超时、未按要求接入、动作有安全风险被现场终止）**均不补测**；平台侧故障才重新安排。
- 场景由赛事方多名测试人员**实时布置**；人为干扰是真人现场操作，不是固定脚本。
- 提交 README 明确：评测会记录每步 `get_action` 的**时延及其波动**、返回动作的**统计规律性**，并可能随成绩一起展示；要求时延平滑稳定、动作无异常离群 [S6]。

## 1. 三个灵感词，各自钉到官方事实上

### 1.1 安全交互：不是约束，是"保分 + 最早的 OOD 传感器"

官方规则把安全从"建议"变成了"直接扣分项"：动作存在安全风险可被现场终止，且**不予补测** [S1][S2]。这意味着一次碰撞/一次快速逼近人手，可能不只是丢一个 trial，而是浪费当天唯一时段。安全交互因此有三层价值：

1. **保分**：不终止 = 保留成功可能性；对 320 个 trial 的任何一个都成立。
2. **保资源**：单日一槽，一次鲁莽可能让整天的评测作废。
3. **保信号**：碰撞前的跟踪误差突增、接触 surprise、物体/人手运动、进度停滞，恰恰是分布偏移最早可见的迹象。**安全监测器天然就是一个 OOD 监测器**——这是本轮的核心类比。

证据链：VLSA/AEGIS 用 CBF 即插即用，成功率 +10%、避障 >50% [S19]；WBAG 用全身+附着几何把场景安全做到 97.38% [S20]；VLPSA 在动态人干扰下把避障从 23.1% 提到 91.2% [S21]；Knows 用注意力引导、无需训练，在动态场景 +43% [S22]；多连杆安全滤波 2.2ms CPU [S23]；COSMIK-MPPI 22ms、近距人环境 100% [S24]。这些工作共同说明：**安全层可以很轻、很快、即插即用**，不需要再训练一个大模型。

### 1.2 泛化能力：五轴之外还有"隐藏第六轴"，而且"知道自己失效"比"见过更多"更便宜

五轴（位置/干扰物/背景/未见物品/人为干扰）各 2 次，共 64 trial/轴；再加跨机器人（不同任务随机换机、同场景重复也可能换机）。后者是官方明说的**隐藏第六轴**：相机位姿、桌面高度、光照、夹爪标定、机器人个体差异都可能变 [S1][S2]。

这带来两个判断：

- **只靠数据覆盖不够**：33k 演示覆盖不了 5×2×32 的组合，更覆盖不了跨机器人硬件差异；背景/位置/未见物品轴本质上是"训练分布外的视觉/几何变化"。
- **"检测 + 恢复"比"预测 + 覆盖"更便宜**：一个只在成功演示上校准的监测器，可以检测"当前观测/动作/进度不在成功流形上"，然后触发减速、重定位、重抓、让行、重试。它不需要失败数据，不需要第二个模型，且对没见过的轴同样有效。这与 RC-NF（<100ms，回滚/重规划）[S25]、RAFAIL（关系感知、无需失败数据，73.4% balanced accuracy）[S26]、foundational world model + conformal（>9Hz）[S27] 的证据方向一致；但我们刻意选**训练免费/确定性信号**，以规避单模型合规与延迟风险。

Spa-Bench 的结论仍然重要：OOD 空间 grounding 是瓶颈（ID 67.5–73.3% → OOD 40.7–52.0%）[S38]。但本轮的补充是：**grounding 错了以后，模型往往"不知道自己错了"**；监测器 + 恢复器可以把"错了还继续做"变成"错了就重来"。这就是把泛化从"预测能力"扩展为"失效感知能力"。

### 1.3 自适应控制：固定 chunk、无力反馈、单日一槽，逼出"有界、确定性、延迟不变"的适应

接口约束很硬 [S6]：

- `action_chunk_size` 固定，`get_action` 返回 T_a 步；评测器执行完再调用下一次。
- 动作空间 joint/ee 二选一；观测只有 4 路 RGB + 双臂关节/EE 位姿 + 夹爪 + 下半身；**没有力/力矩/触觉/电流**。
- 时延与动作规律性会被记录；推理超时/服务异常不补测。
- 单日一槽，调试机会稀缺。

因此"自适应"不能是：运行时再训一个模型、切换到另一个 checkpoint、动态改 chunk 大小、调用一个独立的世界模型/安全模型。这些要么违反单模型解释，要么引入延迟尖峰，要么在 180s 内不可控。**可行的自适应是执行层的、有界的、确定性的**：

- 风险状态机（Nominal/Cautious/Protective/Recover/SafeStop）；
- EE 空间的安全滤波（桌面平面、工作空间、障碍/人手椭球、速度/加速度/ jerk 限制）；
- 速度缩放、保持/让行、重定位、重抓、重试；
- 放置位姿后验的在线更新（用 episode 内的成功/失败反馈，不跨 episode 学习）。

这与 VLA-ATTC（失败率 −50%）[S30]、Scale [S31]、GeoAAC（53.3→74.4%）[S32]、DREAM-Chunk（扰动下插入 10→65%）[S33]、CA3C（相对失败 −71.8%）[S34]、AAC [S35] 的方向一致；区别是我们把"适应"放在**执行器/安全层**，而不是再训练一个策略，从而同时满足单模型、低延迟和跨机器人。

## 2. 本轮主判断：从"放置优先"转向"近失败恢复优先"

### 2.1 一个更对齐评分结构的失败模型

成功率是主指标，意味着真正的杠杆是 **P(整条 episode 成功)**，不是 P(某一步完成)。把近失败分成三类：

| 类型 | 例子 | 现状 | SAGE 的转化动作 |
|---|---|---|---|
| T1 终局失败 | 叠碗没叠正、相框没摆正、插头没插到位、放置掉落 | 到达终局但 0 分 | 落点后验 + 缓放/稳定校验 + 重试 |
| T2 过程失败 | 抓空、碰撞、路径被挡、物体被人移走、插入卡住 | 中途 0 分 | 异常监测 + 减速/让行/重定位/重抓 |
| T3 验证失败 | 做完了但谓词没确认、假完成、被 undo | 以为成功实际 0 分 | SSG 谓词 + 回退 + 重做 |
| T4 系统失败 | 超时、服务异常、延迟尖峰、跨机器人标定漂移 | 直接 0 分/不补测 | 固定计算预算、soak、reset 自校准 |

上一轮只重攻 T1；本轮认为 **T2/T3/T4 的期望收益更大**，因为它们发生在更多任务、更多轴上，而且现有 VLA 普遍缺少"失败感知"。T1 仍然保留（它是成功闸门），但用 TTPA 做成"在线后验"而不是离线位姿迁移的单一动作。

### 2.2 为什么这比上一轮 PILOT-GPR 更该做

- 上一轮把"终局放置"当唯一闸门，逻辑对，但**步骤分权重的论据被官方排名规则降级**；为步骤分做几何优化，收益不如为成功率做恢复。
- 上一轮把 ICR/OPT/SAM/FoundationPose 当主路径，**单模型合规与延迟风险被低估**；本轮明确：推理期只有一个学习 checkpoint，其余是确定性几何/控制代码；SAM/FoundationPose 只用于离线标注/蒸馏，不进提交。
- 上一轮把"调试槽"当发布门，方向对，但**单日一槽**比想象更稀缺；本轮把离线失败注入 + 真机 3 次完整跑作为主验证，调试槽只用于高风险任务。
- 上一轮对"安全"只当约束；本轮把它升级为**运行时 OOD 信号 + 保分机制**，这是三个灵感词真正的交集。

### 2.3 与第 7 轮的关系

- **保留**：GPR-VLA 单 checkpoint、SSG、PGL（简化）、OPT（升级为 TTPA）、SVL（并入 AEG）、NRB（升级为 HAR）、TLE/ACP/GF、Endurance Governor、Compliance Compiler、FLEET 检查单。
- **升级**：安全从"约束"→"SCAN 信号 + AEG 状态机"；放置从"离线位姿迁移"→"离线先验 + 在线后验（TTPA）"；人类备注从"回放剧本"→"检测/让行/恢复（HAR）"；跨机器人从"工程差异"→"reset 自校准（RSC）"。
- **降级/砍**：ICR（延迟+合规风险，默认关，最多用手工关系键）；L2L（外部数据未明，默认 OFF）；TCLB（只做离线回放）；SAM/FoundationPose 推理期（改为经典 CV/模型自身头）；独立学习型安全监测器/世界模型（改用训练免费信号）；ensemble/多 checkpoint（违规风险）；动态 chunk（接口不支持）；全身 CBF（先用 2.5D 几何滤波，够用且轻）。

## 3. 方案轮廓：SAGE-GPR（细节在产物区）

```text
语言（160 条复述之一）→ SSG 评分步骤图 → 当前步骤 s、相位 φ
                                  │
  4×RGB + proprio ──► SCAN：示范校准的相位感知异常监测
                                  │  进度/谓词、动作不确定性、跟踪误差/接触、
                                  │  视觉 surprise、人手/人臂运动、检索距离
                                  ▼
                        风险分数 r_t → AEG 状态机
        Nominal → Cautious（减速/缩短前瞻/视觉伺服）
                → Protective（保持/让行/退避）
                → Recover（重定位/重抓/重试/TTPA 更新）
                → SafeStop（碰撞/人手过近）
                                  │
                                  ▼
        GPR-VLA（唯一 checkpoint，EE 动作 + 谓词/affordance/不确定性头）
                                  │
                                  ▼
        安全滤波：桌面平面/工作空间/障碍/人手椭球/速度加速度 jerk 限制
                                  │
                                  ▼
        TTPA：放置位姿后验（离线先验 + episode 内成功/失败更新）
                                  │
                                  ▼
        HAR：人手进入/移动/undo → 让行、回退、重做
```

一句话：**把"安全交互"做成运行时 OOD 探测器，把"自适应控制"做成有界执行调节器，把"泛化"做成"失效后能恢复"；单 checkpoint，零第二模型，延迟不变。**

## 4. 为什么这是研究贡献，而不只是工程

1. **SCAN：只用成功演示校准的相位感知异常监测**。不是"再训一个失败分类器"，而是把成功演示的每步信号分布（进度、动作不确定性、跟踪误差、视觉 surprise、人手运动）做成 per-task/per-phase 的校准阈值；风险分数 = 校准后的 max/加权和；用滞回+驻留时间防抖。它回答了"没有失败数据时，如何检测 OOD 失败"这个问题（与 RAFAIL/RC-NF 同类问题，但更轻、更适合真机时限）。
2. **AEG：风险条件化的有界执行**。把"安全滤波"从静态约束变成"风险状态相关的控制策略"：低风险不干预、中风险减速/缩短前瞻、高风险保持/让行、可恢复失败重定位/重抓。给出延迟预算、平滑性（jerk）和状态驻留的工程约束，并用真实 30Hz 评测验证。
3. **TTPA：episode 内的放置后验更新**。把"重试"从固定动作变成"用失败信息更新放置分布"：失败方向/滑移/错位 → 后验偏移/降权 → 下一次采样。它是无梯度的 test-time adaptation，直接利用评测器给的 180s 重试预算。
4. **HAR：把真人干扰当一阶扰动**。官方场景由真人实时布置，备注只是"意图剧本"；HAR 用运动/深度/光流检测人手/人臂，估计 TTC，执行让行/保持/回退，并在人离开后重定位/回退步骤。它把"human 轴"从"训练时见过的剧本"变成"运行时通用的安全交互"。
5. **RSC：reset 时的跨机器人自校准**。用双目/平面拟合/本体感觉估计桌面平面、工作空间、相机尺度、夹爪-物体尺度；不依赖固定外参。它直接对应官方"不同任务随机换机、同场景也可能换机"的规则。
6. **统计与协议**：320 trial 的幂分析、per-task 10 trial 的噪声、best-of-multiple 的方差策略、单日一槽的 release gate。这些不是"工程"，而是决定实验能否证伪的方法论。

## 6. 风险与合规（先立后破）

- **单模型解释**：官方原文是"不得混合使用多个模型一起进行测试"；FAQ/解释未在一手文档中确认"不同架构/训练阶段"的边界。我们按最保守解释：**推理期只有一个学习 checkpoint**；SCAN/AEG/TTPA/HAR/RSC 全是确定性代码/统计/几何；SAM/FoundationPose 只用于离线标注，不随提交运行；检索库是数据，不是模型，且键尽量手工化。
- **监测器误报**：会拖慢甚至打断正常任务 → 用成功演示的 p99/p99.9 校准、滞回、驻留时间；离线失败注入测 precision/recall；误报超阈值就回退到 Nominal。
- **安全滤波过保守**：180s 超时 → 只在高风险时干预；干预有最大持续时间；长程任务限重试次数；Endurance Governor 兜底。
- **人手误检/漏检**：用运动+深度+光流+机器人自身运动扣除；宁可保守减速，不快速退避；真人测试验证。
- **跨机器人标定失败**：平面拟合失败/透明桌面 → 回退到保守速度 + 视觉伺服，不用绝对度量位姿。
- **单日一槽**：离线门禁 + 3 次完整跑上限；调试槽只给 T27/T10/T19 这类高风险任务；不做"每日调参"。
- **占位榜**：只当弱先验，不据此调参；真实榜发布后重跑"终局闸门"假设。
- **统计噪声**：每任务只有 10 trial，per-task 比较几乎不可靠 → 任务级分层/部分池化 + 配对 bootstrap；不要用单任务 10 次结果做模型选择。
- **延迟尖峰**：固定计算预算、无额外模型调用、无动态 chunk；soak 测 p99；交互质量会被记录。
- **安全终止**：一次碰撞可能浪费整槽 → AEG 优先保持/让行，不快速穿越人手附近；速度上限保守。

## 7. 一句话押注

**官方规则奖励"知道自己快要失败"的机器人：用与安全交互同源的运行时信号（跟踪误差、接触 surprise、人手运动、进度回退）做示范校准的 OOD 监测，再用有界、延迟不变的自适应执行把近失败转成成功——这比再堆一个模型更能在五条泛化轴和隐藏的跨机器人轴上同时提成功率，且不违反单模型规则。**

## 1. 事实核对（本轮新增，全部一手；来源表见 §11）

### 1.1 评测协议：10 次/任务、5 轴×2、180s

官方手册 1.2 / 2.1 [S1][S2]；任务清单/说明见 [S3][S4][S12]：

- 成绩记录：可多次提交完整计分评测；取**总平均成功率最高的一次**；同分取步骤分最高；仍同分取提交时间最早。

## 2. 评分算术与统计功效

### 2.1 主/次/附加指标

```text
总平均成功率 = mean_{task=1..32} (success_count_task / 10)
总平均步骤分 = mean_{task=1..32} (mean_{run=1..10} step_score)
排名 = 成功率 ↓，然后步骤分 ↓，然后提交时间 ↑
```

**成功是二值闸门**；步骤分只在成功率相同的时候决定名次。因此：

- 优化目标首先是 `P(episode success)`，不是 `E[step_score]`。
- 一个“把 0 变 1”的恢复，价值高于“把 60 变 80”的部分分。
- 步骤分仍有诊断价值：它告诉我们失败发生在哪一步；但不要为了步骤分牺牲成功率（例如为了多做一个容易的步骤而冒碰撞风险）。

### 2.2 320 个 trial 的统计功效

每任务 10 trial × 32 = **320 trial**；每轴 64 trial；每任务 10 trial。

| 层级 | n | p=0.3 时 SE | 95% CI 半宽 | 最小可检测差异（80% power，独立两比例） | 配对 ρ=0.5 时 |
|---|---:|---:|---:|---:|---:|
| 总体 | 320 | 2.56pp | ±5.0pp | ≈10.1pp | ≈7.2pp |
| 单轴 | 64 | 5.73pp | ±11.2pp | ≈22.7pp | ≈16.0pp |
| 单任务 | 10 | 14.5pp | ±28.4pp | ≈57.4pp | ≈40.6pp |

结论：

- **总体 +5pp 在单次 320-trial 跑里不一定显著**；需要 3 次跑/配对分析/任务级分层。不要把一次 +3pp 当成胜利，也不要把一次 −3pp 当成失败。
- **单任务 10 trial 不能做模型选择**；per-task 差异噪声极大。用任务级 partial pooling、配对 bootstrap、离线数据做决策。
- **单轴 64 trial 只能检测大效应**；不要声称“某轴 +10pp”是稳的，除非跨任务一致。
- 真实榜单 best-of-multiple 会放大“运气”；内部决策看均值/方差，不只看最好一次。

### 2.3 近失败转化模型

设任务有 k 步，终局为最后一步：

```text
P(success) = P(完成前 k-1 步) × P(终局成功 | 到达终局)
           ≈ q × r
```

- `q` = 到达终局的比例（由策略/任务难度决定；需离线/真机测，不能从占位步骤分反推）。
- `r` = 到达终局后的成功率。
- 终局恢复把 `r` 提高 Δ，总体成功率提高 `q·Δ`。若 `q≈0.5–0.7`，+10pp 的终局恢复 ≈ +5–7pp 总体。
- 过程恢复（碰撞/抓空/人干扰）提高的是 `q` 或更早步骤的完成率，同样跨任务/跨轴。
- 步骤分与成功率的占位差 ≈+8.6pp **不能**直接反推 q 或 r；它只说明“部分完成”常见。必须用离线步骤级诊断。

### 2.4 best-of-multiple 的方差策略

官方取多次完整跑中成功率最高的一次。若每次跑的真实均值 μ、跑级标准差 σ，取 N 次的期望最大值 ≈ μ + σ·E[max Z_N]。这意味着：

- **提高均值**仍然最重要；
- **降低跑级方差**（稳定性、跨机器人鲁棒、无安全终止）在 best-of-N 下也有额外价值；
- 但不要为了“刷一次高分”而冒安全风险；一次终止可能浪费时段，且可能影响后续预约/声誉。
- 计划 2–3 次完整跑；内部报告均值±方差，不只报告最好一次。

### 2.5 预算分配（修订第 7 轮）

```text
SCAN + AEG（安全/恢复/监测）        35%
TTPA + PGL/SSG（终局与步骤）        20%
HAR + RSC（人干扰/跨机器人）         20%
GPR-VLA 训练/蒸馏/部署              15%
离线失败注入 + 统计/评测协议         10%
```

理由：成功率优先；T2/T3/T4 覆盖更多任务；T1 仍保留但不再吃掉全部预算。

### 3.2 SCAN：示范校准的相位感知异常监测

**目标**：在无失败数据、无第二模型的条件下，检测“当前 episode 偏离成功流形”。

**信号**（全部来自当前 obs + 短历史 + checkpoint 自身头；无额外模型）：

| 信号 | 计算 | 失败模式 | 备注 |
|---|---|---|---|
| 进度/谓词 | SSG 当前步谓词置信度；步内耗时 vs 演示分布；谓词 1→0 | T1/T3 | 谓词头在 checkpoint 内 |
| 动作不确定性 | flow-matching 多噪声样本的速度分歧/方差；chunk 内方差 | T1/T2 | 同一 checkpoint，多次前向；固定采样数 |
| 跟踪误差/接触 | `‖q_cmd−q_obs‖`、`‖EE_cmd−EE_obs‖`；自由空间突增=意外接触；插入时低误差但无进度=卡住 | T2 | 无力传感器，用位置残差 |
| 视觉 surprise | 任务相关区域光流幅度/方向 vs 演示；物体-容器相对位姿变化；背景颜色/纹理统计 | T2/T1 | 经典光流/颜色直方图 |
| 人手/人臂 | 运动分割（光流+深度）− 机器人自身运动（正运动学投影）；TTC | T2/HAR | 真人现场；不依赖学习检测器 |
| 放置稳定性 | 释放后物体位移/速度/谓词保持 | T1 | 腕部+头相机 |
| 检索距离 | 手工关系键到最近演示的距离（可选） | T1/T2 | 无独立编码器；默认关 |

**校准**：

- 只用**成功演示**；按 task×phase 计算每个信号的稳健分位数（p50/p95/p99/p99.9）。
- 归一化 `z_k = clip((x_k − p50_k)/(p99_k − p50_k), 0, 3)`；风险 `r_t = max_k w_k z_k`（安全关键信号用 max；进度/不确定性用加权和）。
- 阈值 `τ1<τ2<τ3` 由验证集成功演示的误报率标定（目标 <1%/episode；可按任务放宽到 <5%）。
- 滞回：进入高风险的阈值高于退出阈值；每个状态最小驻留 100–200ms，防抖。
- 失败注入用于测召回/延迟，不用于拟合阈值（避免过拟合合成失败）。

**为什么可行**：

- 成功演示充足（33k；每任务约 1k），足以估 per-phase 分布。
- 失败是“偏离成功流形”，不一定需要失败样本；RAFAIL（关系感知、无需失败数据）[S26]、RC-NF（<100ms 回滚/重规划）[S25]、world-model+conformal（>9Hz）[S27]、Foresight [S28]、CheckVLA [S29] 已验证同类思路。
- 信号是确定性的/轻量的；不引入第二模型，不破坏单模型合规。

**风险**：误报导致减速/超时；视觉信号在透明/布料任务上不稳；人手检测漏检。对策：分桶回退（透明/布料只用进度+跟踪误差）、保守速度、真人测试。

### 3.3 AEG：风险条件化的有界执行

**状态机**：

| 状态 | 触发 | 动作 | 退出 |
|---|---|---|---|
| Nominal | r < τ1 | 执行 chunk；速度上限 80%；正常重规划 | r ≥ τ1 |
| Cautious | τ1 ≤ r < τ2 | 平移/旋转增量缩放 α∈[0.3,0.7]；chunk 尾部向当前位姿 blend；提高视觉伺服增益；缩短有效前瞻 | r < τ1−h 且驻留 |
| Protective | τ2 ≤ r < τ3 或人手进入安全泡 | 保持当前位姿/夹持；人手危险时沿安全方向退避或冻结；等待 0.5s 稳定 | 风险下降且人手离开 |
| Recover | 进度回退/放置失败/抓空/插入失败 | 重定位物体/容器；SSG 回退一步；重抓/重试；TTPA 更新 | 成功或预算耗尽 |
| SafeStop | 碰撞 imminent / 人手过近 / 跟踪误差爆炸 | 停止运动，保持夹持；不再执行新 chunk | 人工/评测终止 |

**EE 安全滤波**（每步 chunk）：

```text
输入：当前 EE pose p0，chunk 目标 p_k (k=1..T_a)，桌面平面/工作空间/障碍/人手椭球
for k:
  d = p_k − p0
  d = clamp_norm(d, v_max·Δt)                 # 速度
  d = clamp_norm(d, a_max·Δt²)                # 加速度（近似）
  p = p0 + d
  p.z = max(p.z, table_z + clearance)         # 桌面
  p = clamp_workspace(p)                      # 工作空间
  if segment(p0,p) intersects obstacle/human ellipsoid(margin):
      p = project_to_tangent(p0,p,ellipsoid)  # 或 hold
  if IK(p) infeasible or joint limit:
      p = p0                                  # hold
  p0 = p
输出：滤波后的 chunk
```

- **2.5D 足够**：桌面平面 + 垂直圆柱/椭球（物体、容器、人手）；不做全身 CBF/全物理。
- **平滑**：滤波后加 jerk-limited 轨迹（五次多项式/临界阻尼），避免抖动；状态切换加驻留时间。
- **延迟**：`T_a` 建议 4（30Hz ≈133ms 开环）；若策略延迟低且平滑，可试 `T_a=2/1`。滤波 O(T_a·N_obs) <1ms；SCAN <10ms；总 p99 <20ms（不含策略本身）。
- **不动态改 chunk**：接口固定 `action_chunk_size`；AEG 只在 chunk 内缩放/保持/替换尾部，不改变 T_a。
- **恢复预算**：普通任务 ≤2 次重试；长程任务（T16/T17/T31）≤1 次；总时长守卫（Endurance Governor）在 180s 前留 10s 余量。

**证据与定位**：安全侧 VLSA/AEGIS（CBF 即插即用，+10% 成功率）[S19]、VLPSA（动态人干扰避障 23.1→91.2%）[S21]、Knows（无需训练，动态 +43%）[S22]、COSMIK-MPPI（22ms，近距人 100%）[S24] 说明轻量安全层可行；执行侧 VLA-ATTC（失败率 −50%）[S30]、Scale [S31]、GeoAAC（53.3→74.4%）[S32]、DREAM-Chunk（扰动下插入 10→65%）[S33]、CA3C（相对失败 −71.8%）[S34]、AAC [S35] 说明“测试时适应/重试”有稳定收益。我们的区别是把适应放在执行层，且不引入第二个学习模型。

**为什么不是“另一个模型”**：状态机/滤波/轨迹生成都是确定性代码；风险分数是统计校准；没有学习参数（除 checkpoint 自身的谓词/不确定性头）。

### 3.4 TTPA：放置位姿的在线后验

**离线先验**（沿用第 7 轮 OPT）：

```text
对任务 t 的演示 i：
  H_i = (T_B^{R_i})^{-1} · T_B^{G_i}(t_i^release)   # 容器系释放位姿
先验：{H_i} 的稳健均值/中位数 + 协方差；或多模态（K-means K=3–5）
容差 τ_task：演示间 H_i 的 95 分位差（叠碗大、插头小）
```

**在线更新**：

```text
初始化：用当前容器位姿 T̂_B^R 和先验得到候选分布 p(H)
for attempt in 1..budget:
    H ~ p(H)（或取最大后验 + 小扰动）
    执行放置；SCAN 观察结果
    if success and stable: return True
    reason = classify_failure()   # 滑移/错位/碰撞/错槽/未到位
    p(H) ← update(p(H), H, reason)  # 降权失败点；沿失败方向偏移；收缩/扩散
return False
```

- 更新规则可用简单的核密度/高斯：失败点周围降权，成功点周围升权；或多模态权重更新。
- **只在本 episode 内更新**；`reset()` 清空。不跨 episode 学习，不违反单模型。
- 适用于 T1（终局放置）；插入类（T10/T26）用视觉伺服/微动搜索，不依赖 TTPA 的位姿采样。
- 预算：1–2 次；每次 ≤3–5s；总时长守卫。

**为什么是研究点**：把“重试”从固定动作变成“用失败信息做贝叶斯/采样更新”；在 180s 内是可行的 test-time adaptation；无需梯度/外部数据。

### 3.5 HAR：真人干扰的检测、让行与恢复

**检测**（经典 CV，无学习检测器）：

- 运动分割：光流（Farneback/Lucas-Kanade）+ head stereo 深度；用正运动学把机器人自身投影/运动从光流中扣除；剩下的大运动 blob 候选人手/人臂。
- 深度/颜色：人手/人臂的深度不连续、颜色/纹理与背景差异；静态人手用深度+背景模型兜底。
- TTC：由光流/深度估计人手速度，算与机器人末端/持有物体的时间到碰撞；`TTC < 1s` 或距离 <10cm → Protective。
- 若人手遮挡目标/容器：更新物体位姿；若谓词 1→0（undo），SSG 回退并重做。

**让行/恢复**：

```text
if human_near(hold_object or target) or ttc < 1s:
    hold pose; keep gripper; do not move toward human
    if safe_retreat_direction exists: slow retreat (≤0.1 m/s)
    wait until human leaves safety bubble for 0.5s
    re-localize object/container; update SSG
    if predicate regressed: redo step
    else: resume
```

- 优先“保持/冻结”，不快速退避；退避只在有安全方向且不撞桌/不撞人时执行。
- 人手把物体移走：等待/重定位；若物体不再可得，继续剩余可做步骤（保步骤分）或安全失败。
- 官方备注（human_1/human_4）作为离线训练/验证剧本；运行时检测通用人手运动，不假设备注的精确时机。

**证据**：VLPSA（动态人干扰避障 23.1→91.2%）[S21]、Knows（动态 +43%，无需训练）[S22]、COSMIK-MPPI（近距人 100%，22ms）[S24]、VLSA/AEGIS（CBF 安全层）[S19] 都支持“感知到人 → 进入安全集 → 让行/恢复”的路线。

**风险**：人手光照/肤色差异；静态人手漏检；运动分割把机器人自身误检。对策：正运动学扣除、深度门限、保守速度、真人测试；宁可减速不漏检。

### 3.6 RSC：reset 时的跨机器人自校准

**目标**：不依赖固定外参/桌面高度；每个 episode 开始时用 1–2s 估计当前机器人/场景的几何尺度。

**步骤**：

1. **桌面平面**：head stereo 点云 → RANSAC 平面拟合；得到 `table_z`、平面法向、工作空间边界；多帧平均降噪。
2. **相机尺度/位姿**：用机器人本体（已知关节/EE）在画面中的投影 + 平面消失点/重力方向，估计相机相对 base 的旋转/尺度；若头部相机随机身 torso 运动，用 `state_torso`/`state_d435` 做补偿。
3. **夹爪-物体尺度**：腕部 RGB + 已知夹爪开度/物体尺寸 → 当前深度下的像素/米比例；用于单目尺度校正。
4. **安全包络**：桌面 + 工作空间 + 障碍/人手 margin；标定失败则用保守默认（低速、低抬升、短步长）。
5. **背景统计**：颜色/纹理直方图，供 SCAN 视觉 surprise 归一化。

**为什么可行**：G1 本体几何/关节可读；双目+平面拟合是经典方法；1–2s 在 180s 内可接受。**不假设**评测相机与数据集完全同参；只假设同一台机器人内部相机-本体关系相对稳定（即使不是，也用平面/本体投影兜底）。

**风险**：透明/无纹理桌面平面拟合失败；腕部遮挡；相机俯仰变化。对策：多方法兜底（平面/消失点/本体投影）、失败即保守、不要用绝对度量做精细放置。

### 3.7 SSG / PGL / SVL 的整合

**SSG（保留，升级）**：

- 输入官方 `score_steps`（32 任务，满分 100）+ 5 复述；构建线性步骤图 `s0→…→sk`，带权重。
- 谓词头在 checkpoint 内；用演示相位标签训练；`s_t` 只在谓词+事件确认后前进；`human undo` 触发回退。
- 作用：成功闸门、防假完成、给 SCAN 提供进度/相位、给 TTPA 提供放置步骤。

**PGL（保留，简化）**：

- 三级目标：槽位/区域（语言+关系）→ 2D 锚点（投影+渲染）→ 6D 位姿（容器系先验/TTPA）。
- 推理期**不用 SAM/FoundationPose**：用经典颜色/深度分割、平面/连通域、checkpoint 自身 affordance/attention 头；容器 6D 用 PnP/点云拟合；失败则退化为 2D 锚点视觉伺服。证据：AnySlot 的显式视觉目标优于 VLM 坐标输出（UR10e 82%）[S39]、SpaceVLA 的抓/放锚点把放置误差降到 0.7cm [S40]、ActGaze 的动作注意力监督（77.0→91.5%）[S41]、Pointing-VLA 的类型化空间 pointing [S48]、GeoPredict 的预测几何先验 [S49]。
- 锚点 overlay 训练/推理同管线；避免域差。

**SVL（并入 AEG）**：

- 落点 settle-verify 是 Recover 状态的特例：缓放→0.5s 稳定检测→nudge/regrasp/retry；预算与 AEG 共享。

### 3.8 单 checkpoint 接口与损失

**输出头**（同一 checkpoint）：

```text
action_chunk: T_a × (left_ee 6 + right_ee 6 + left_gripper 1 + right_gripper 1)
step_predicate: 当前步完成 logits（SSG）
affordance/placement: 可选热图/关键点（PGL）
uncertainty: flow 速度方差/熵（SCAN）
```

**损失**：

```text
L = L_flow + λ1 L_pred + λ2 L_affordance + λ3 L_uncertainty + λ4 L_smooth + λ5 L_safety
```

- `L_flow`：flow matching/行为克隆主损失。
- `L_pred`：SSG 谓词 BCE（演示相位标签）。
- `L_affordance`：可选；抓/放锚点/关键点监督。
- `L_uncertainty`：校准（使高方差对应失败/扰动）；可用注入扰动样本。
- `L_smooth`：jerk/加速度惩罚（动作规律性）。
- `L_safety`：在安全滤波后的动作上做辅助监督（可选）；不要用独立安全模型。

**训练数据**：官方 33k + 离线失败注入（图像/2.5D 扰动）+ 官方备注剧本；不做全孪生/仿真 RL。**不引入第二模型**；SAM/FoundationPose 只做离线标签。

### 3.9 伪代码

```python
class SAGEPolicy:
    def reset(self):
        self.ssg.reset()
        self.scan.reset()
        self.aeg.reset()
        self.ttpa.reset()
        self.rsc.reset()
        self.calibrated = False

    def get_action(self, obs):
        if not self.calibrated:
            self.rsc.calibrate(obs)          # 1–2s; may need first few frames
            self.calibrated = True

        task, step, phase = self.ssg.update(obs)
        signals = self.scan.compute(obs, step, phase, self.rsc)
        risk = self.scan.risk(signals, task, phase)

        state = self.aeg.state(risk, self.scan.human_hazard, self.ssg.regressed)
        if state == "SafeStop":
            return self.aeg.hold_chunk(obs)

        if state == "Recover":
            self.ssg.rollback_if_needed()
            self.ttpa.update_from_failure(self.scan.last_failure)

        chunk = self.model.act(obs, step, phase, self.ttpa.candidate, self.scan)
        chunk = self.aeg.filter(chunk, obs, risk, state)
        chunk = self.aeg.smooth(chunk, obs)
        return chunk
```

**注意**：`reset()` 无 obs，RSC 在首次 `get_action` 执行；若策略允许，可在 episode 开始做一个小幅标定动作（视线/腕部），但要在 180s 内且不违反任务语义。若不允许，纯观测标定。

### 3.10 延迟预算

| 模块 | 目标 p50 | 目标 p99 | 备注 |
|---|---:|---:|---|
| 网络/序列化 | 5ms | 20ms | 评测端到端 |
| GPR-VLA 前向 | 40ms | 80ms | 单卡，固定 batch/采样数 |
| SCAN（经典 CV+统计） | 5ms | 15ms | 无额外模型 |
| AEG 滤波/平滑 | <1ms | 2ms | CPU |
| TTPA 采样/更新 | <1ms | 2ms | 仅放置步 |
| 总 | <60ms | <120ms | 不含网络抖动；soak 验证 |

- 固定采样数/固定分辨率/无动态 batch；避免“按风险自适应算力”导致延迟尖峰。
- `T_a=4` 时 133ms 开环；若总延迟 p99 >100ms，考虑 `T_a=2` 或降低策略分辨率。
- 评测会记录时延波动；目标是 p99/p50 <3，且无长尾。

## 5. 离线标定与失败注入

### 5.1 成功演示校准

- 对 32 任务各抽样 200–500 条成功演示（共 ~10k；不必全量），按 SSG 相位切分。
- 计算每 task×phase 的信号分布：进度耗时、动作方差、跟踪误差、光流/视觉 surprise、物体-容器相对位姿、放置稳定性。
- 保存 `scan_stats/<task>/<phase>.npz`：分位数、阈值、权重、误报校准。
- 验证集：留出 20% 成功演示，测误报率；目标 <1%/episode（可放宽到 5% 对长程任务）。
- 透明/布料任务分桶：只用进度+跟踪误差+谓词，不依赖视觉 surprise/光流。

### 5.2 失败注入（离线，无真机）

| 注入 | 方法 | 目标信号 | 指标 |
|---|---|---|---|
| 物体位置偏移 | 图像/2.5D 平移目标 | 谓词、视觉 surprise、放置稳定性 | 检测延迟、重试成功率 |
| 容器/槽位偏移 | 平移容器/锚点 | 锚点偏离、放置失败 | TTPA 更新效果 |
| 背景替换 | 颜色/纹理替换 | 视觉 surprise、检索距离 | 误报率（背景轴） |
| 未见物体 | 颜色/形状替换（图像/资产） | 外观距离、谓词 | 检测/恢复 |
| 干扰物 | 路径旁插入刚体 | 跟踪误差/视觉 surprise | 避障/恢复 |
| 人手遮挡/移动 | 合成手/真人视频叠加 | 人手 blob/TTC | 检测延迟/让行 |
| 相机扰动 | 外参/焦距/桌面高度扰动 | RSC 残差、放置误差 | 标定误差/成功率 |
| 延迟尖峰 | 人为注入 100–500ms | 超时/动作规律性 | p99/超时率 |

**注意**：离线注入只能验证监测器的敏感性/误报，不能证明真机恢复成功率；真机结论只来自调试槽/完整跑。

### 5.3 回放/2.5D 而非全孪生

- 用演示的 RGB/EE/夹爪做闭环回放：策略输出动作 → 在 2.5D 桌面/物体模型上推进 → 渲染新观测（或用演示最近邻拼接）。
- 只用于相对比较/失败挖掘；不用于模型选择/真机校准。
- 透明/布料/拉链不做物理；只做相位/谓词回放。

### 5.4 评价指标

```text
检测：延迟（帧/秒）、TPR@FPR=1%、误报/Episode
恢复：重试成功率、恢复后完成率、总时长增量
安全：碰撞次数、安全终止次数、人手最小距离
控制：jerk、速度/加速度超限率、状态切换频率
系统：p50/p99 延迟、超时率、内存/显存、端口隔离
```

## 6. 真机评测协议（单日一槽）

### 6.1 预约与 release gate

- **单日一槽**：计分与调试都算；未按时接入/失败视为已用。
- 只在离线门禁通过后预约；不做“每日调参”。
- 每次预约前 24h：soak（N 端口、并发、状态隔离、p99）、模型卡、回滚包。
- 调试槽任务选择：T27（叠碗，T1 放置）、T10（插排，T2 接触/插入）、T19（拉链，T3/HAR undo）。一次只测一个。
- 完整跑：至少 2 次，目标 3 次；取最好；内部报告均值/方差。

### 6.2 计划（与 §10 对应）

| 周 | 类型 | 任务 | 目的 | Go/No-Go |
|---|---|---|---|---|
| W4 | 调试 | T27 | SCAN+AEG+TTPA 真机 | 终局成功 +10pp，无安全终止 |
| W5 | 调试 | T10 | 接触/插入监测 | 插入成功 +10pp，无误报超时 |
| W6 | 完整 | 32 | 第一次全量 | 无安全终止；成功率 ≥ 基线 |
| W7 | 完整 | 32 | best-of-2 | 成功率/步骤分提升；稳定性 |
| W8 | 完整 | 32 | best-of-3（可选） | 最终成绩；冻结 |

- 若 W6 出现特定失败，W7 可改用调试槽诊断；否则优先完整跑（best-of 更重要）。
- 每次完整跑可能数小时；确保服务端 endurance/thermal/内存稳定；不要在跑中更新模型。

### 6.3 soak 清单

- N 端口（按官方 N；未知时按 5 准备）连续 8h；每端口独立 reset/历史；并发请求；状态隔离。
- 观测尺寸/类型/键与 README 一致；`image_resize`/`obs_delta_indices` 边界；缺失帧 padding。
- token 双处；错误处理；超时/重连；日志不泄露 token。
- 延迟 p50/p99、内存/显存、线程/进程、GPU 温度；动作 jerk/超限。
- 回滚：上一版 checkpoint + 配置；一键切换。

### 6.4 统计

- 总体：32×10=320；报告 success 比例 + 95% CI（Wilson/beta-binomial）。
- 任务级：10 trial；用分层 beta-binomial/partial pooling，不单独下结论。
- 轴级：64 trial；描述性 + 跨任务配对；不宣称小效应。
- 多次完整跑：报告每次 + 均值/方差 + 最好；不只看最好。
- 消融：同一任务/种子配对；bootstrap CI；预先注册主指标（成功率）。

- 人干扰：检测延迟 vs 恢复率；误检 vs 超时。

## 8. 创新点清单（持续迭代）

> 状态：押注=主线；保留=沿用；升级=改造；降级=保留但非主回路；砍=不做。

### I1 SSG 评分步骤图门控（保留/升级）
- 动机：成功=全步骤；官方步骤/权重公开；防跳步/假完成。
- 差异：谓词头在唯一 checkpoint 内；给 SCAN 提供相位/进度；不再承担“步骤分大头”的主论据。
- 可行性：确定性图 + 学习谓词头；32×5 复述精确匹配。
- 资源：CPU；1 人周。
- 风险：谓词噪声 → 演示校准 + 事件校验。

### I2 PGL 放置目标阶梯（保留/简化）
- 动机：OOD 空间 grounding 是瓶颈；显式锚点/位姿可提放置精度。
- 差异：推理期不用 SAM/FoundationPose；用经典 CV + checkpoint 自身 affordance；锚点 overlay 同分布。证据：AnySlot [S39]、SpaceVLA [S40]、ActGaze [S41]、Pointing-VLA [S48]、GeoPredict [S49]。
- 可行性：投影/渲染确定性；接口允许 resize/overlay。
- 风险：透明/小件分割失败 → 回退 2D 锚点/视觉伺服。

### I3 OPT → TTPA（升级）
- 动机：33k 演示有释放位姿；180s 内可重试；失败信息可用。
- 差异：离线先验 + episode 内后验更新；不是固定轨迹复制。
- 可行性：EE base 位姿 + 容器位姿；采样/更新轻量。
- 风险：容器位姿估计失败 → 分桶回退；采样慢 → 预算。

### I4 ICR 上下文检索（降级/可选）
- 动机：检索式 VLA 证据一致；33k 是现成库。
- 差异：手工关系键 + checkpoint 自身编码；默认关；只在延迟允许时开。证据：ICI-VLA（相位检索/防复制，RoboTwin 2.0 60.4%）[S42]、RA-VLA（LIBERO +17.6pp、UR5e +20.8pp）[S43]、FlowRetrieval（光流检索，真机 3.7×）[S44]、HSR（真机 +21.3pp）[S45]、SAIL（测试时算力扩展，最高 95%）[S46]、Retrieval-VLA（无需训练、物件中心键）[S47]、Retrieve-then-Steer [S36]。
- 风险：独立编码器=第二模型；延迟 p99；透明任务键失效 → 默认关最安全。

### I5 SVL 落点闭环（并入 AEG）
- 动机：释放失败靠“放完就完”发现不了。
- 差异：settle-verify 作为 Recover 状态；预算共享。
- 风险：耗时/误判 → 双阈值 + 预算守卫。

### I6 NRB → HAR（升级）
- 动机：human 备注公开；真人现场布置；undo 常见。
- 差异：从“备注回放”升级为“通用人手检测/让行/恢复”；备注只做训练/验证。
- 风险：漏检/误检 → 保守速度 + 真人测试。

### I7 L2L 产学研数据（降级/条件）
- 动机：背景/位置轴多样性；高校 G1 网络。
- 差异：逐字段协议 + QA + 许可 + 署名；默认 OFF。
- 风险：外部数据规则未明；单日一槽降低数据农场优先级 → 赛后/合规后。

### I8 DebugLoop 平台调试回路（修订）
- 动机：真机反馈比离线可信；发布门。
- 差异：单日一槽；只做里程碑门；离线失败注入先筛。
- 风险：资源稀缺/规则变化 → 最多 2 次/月；失败即回滚。

### I9 GPR-VLA 主干（保留）
- 动机：单 checkpoint 合规；WLA 底座 Apache-2.0；多任务头。
- 差异：EE 动作 + 谓词/affordance/不确定性头；动作平滑损失。
- 风险：底座微调不足 → LoRA 分级；EE RPY 奇异性 → 四元数内部。

### I10 TLE/ACP/GF 数据引擎（保留/收窄）
- 动机：相位/谓词标签 + 失败注入是最便宜的数据。
- 差异：只服务 SSG/SCAN/TTPA；不做全孪生/仿真 RL。
- 风险：合成负迁移 → 真实混采 + 软权重。

### I11 AH-TP / Endurance / Compliance（保留/升级）

### I12 TCLB（降级）

### I13 FLEET 工程检查单（保留）

### I14 SCAN 异常监测（新增，押注）
- 动机：无失败数据/无第二模型；成功演示充足；安全信号=早期 OOD。
- 差异：per-task/phase 校准；max/加权风险；滞回/驻留；经典 CV。

### I15 AEG 自适应执行（新增，押注）
- 动机：安全终止不补测；近失败转化是成功率主杠杆；延迟/动作规律性被记录。
- 差异：风险状态机 + EE 安全滤波 + 平滑/驻留；固定 chunk；无第二模型。
- 可行性：几何/控制确定性；<2ms；2.5D 足够。
- 资源：1–2 人周；无额外数据。
- 步骤：状态机 → 滤波 → 平滑 → 延迟/soak → 真机。
- 风险：过度保守/超时 → 干预预算 + 只在高风险触发。

### I16 TTPA 放置后验（新增）
- 动机：T1 终局失败；180s 可重试；失败信息可用。
- 差异：在线贝叶斯/采样更新；episode 内；无梯度。证据：PDF 用延迟反馈做 test-time 调优 [S37]；Retrieve-then-Steer 的检索条件化 [S36] 说明“用历史经验条件化当前动作”有效。
- 可行性：离线先验 + 轻量采样；与 SSG/SCAN 接线。
- 风险：容器位姿/失败分类噪声 → 简单更新 + 预算。

### I17 HAR 人类感知恢复（新增）
- 动机：真人现场干扰；undo 备注；安全终止。
- 差异：光流+深度+正运动学扣除；TTC；让行/恢复；无学习检测器。证据：VLPSA [S21]、Knows [S22]、COSMIK-MPPI [S24]、VLSA/AEGIS [S19]。
- 风险：漏检/误检 → 保守速度 + 真人测试；静态人手 → 深度/背景兜底。

### I18 RSC 跨机器人自校准（新增）
- 动机：官方随机换机；固定外参不可靠。
- 差异：reset 时平面/尺度/工作空间估计；失败回退；无第二模型。
- 风险：透明/无纹理 → 多方法兜底/保守。

### 已砍/降级清单（跨轮）
- 独立学习型安全监测器/世界模型；推理期 SAM/FoundationPose/独立检索编码器；ensemble/多 checkpoint；动态 chunk；全身 CBF；全 32 任务高保真孪生；每任务 LoRA/模型合并；仿真 RL；WMA-0 主路径；外部数据默认开启；为步骤分牺牲成功率的局部优化。

## 9. 风险、合规与开关

| 风险 | 概率 | 影响 | 缓解 | 停止条件 |
|---|---|---|---|---|
| 单模型审计不过 | 中 | 高 | 单 checkpoint；确定性代码；模型卡披露；离线模型不进提交 | 审计要求额外学习模型 → 去掉 ICR/offline-only |
| SCAN 误报 | 高 | 中 | p99/p99.9 校准；滞回；分桶；离线误报 <1% | 误报 >5%/episode → 只保留跟踪误差/谓词 |
| AEG 过度保守/超时 | 中 | 高 | 只在高风险干预；最大持续时间；重试预算；Endurance | 超时率上升 → 降级为只减速 |
| 人手漏检/误检 | 中 | 高 | 光流+深度+正运动学；保守速度；真人测试 | 任一碰撞 → 冻结/停测整改 |
| RSC 标定失败 | 中 | 中 | 平面/消失点/本体投影多方法；失败保守 | 放置误差变大 → 关闭 RSC |
| TTPA 重试慢 | 中 | 中 | 1–2 次；每次 ≤5s；总时长守卫 | 总时长超限 → 关闭 TTPA |
| 跨机器人方差 | 高 | 中 | RSC；保守控制；多次跑；任务级分层 | 方差主导 → 增加完整跑/保守策略 |
| 占位榜误导 | 高 | 中 | 只当弱先验；真实榜后复核 | 真实数据推翻假设 → 重排优先级 |
| 统计噪声 | 高 | 中 | 320 trial；配对；分层；预先注册 | CI 跨 0 → 不宣称 |
| 外部数据违规 | 低 | 高 | 默认 OFF；邮件确认；L2L 仅赛后 | 明确禁止 → 关闭 |
| 延迟尖峰 | 中 | 高 | 固定预算；无动态模型；soak | p99 >120ms → 降分辨率/采样 |
| 立体深度粗 | 高 | 中 | 平面拟合；近场；腕部尺度；视觉伺服 | 依赖绝对深度 → 改为相对 |

- M1（W2）：SCAN 离线误报/检测达标。

**最小可运行版（若时间不够）**：


HAR/RSC/ICR/L2L 可后置；但 HAR/RSC 对官方规则很关键，至少做保守版（人手减速、桌面平面标定）。

## 12. 开放问题

1. 外部数据（自采/实验室数据）是否允许？手册只说“提供 32 任务全部真机数据”，未明确禁止；FAQ 未找到。默认 OFF。
2. 单模型边界：确定性代码、经典 CV、检索库、离线蒸馏是否算“模型”？官方原文只写“不得混合多个模型”；按最保守解释设计，提交前邮件确认。
3. 步骤分聚合公式：10 次平均？每次部分分平均？是否按任务归一化？需确认。
4. 成功判定：自动谓词/人工裁判/录像复核？影响 SSG 谓词设计。
5. N 台机器人准确数量；手册示例 N=5，README 示例 3；以官方通知为准。
6. 评测相机是否与数据集 head stereo 同参？API 不提供内参/外参；RSC 需运行时估计。
7. 评测中是否允许 episode 开始时的小幅标定动作？影响 RSC 的相机-本体标定。
8. 180s 内是否允许任意重试/自我中断？是否有隐藏上限？
9. 安全终止是终止单个 trial 还是整个时段？按最坏情况（整个时段）设计。
10. 动作 chunk 的执行节奏：T_a 步是否严格按 30Hz 开环执行？网络延迟如何计入 180s？
11. 真实榜单何时上线？上线后重跑“终局闸门/近失败”假设。
12. 透明/布料/拉链任务的视觉监测可靠性；是否需要专门的分桶回退。
13. 人手在相机中的可见性/遮挡；是否所有任务都能看到人手。
14. 评审是否接受“确定性安全层”作为模型的一部分；模型卡披露格式。

## 13. 一句话押注

**官方规则奖励“知道自己快要失败”的机器人：用与安全交互同源的运行时信号（跟踪误差、接触 surprise、人手运动、进度回退）做示范校准的 OOD 监测，再用有界、延迟不变的自适应执行把近失败转成成功——这比再堆一个模型更能在五条泛化轴和隐藏的跨机器人轴上同时提成功率，且不违反单模型规则。**
