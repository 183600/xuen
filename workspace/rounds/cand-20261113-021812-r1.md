# 第 3 轮迭代（灵感循环 v3：「深度学习」×「成功率」）—— 成功率不是尺子，而是一个需要被校准的随机变量

> 承接 v2 的 UIP-01′~15。本轮**不加新模块，先换问题**：v2 每一项都在回答"怎么更强"，却没有一项回答"强是按什么概率、在多少样本上被测量、又被谁在什么时刻打断"。「深度学习」和「成功率」这两个词，恰好把这个缺口逼了出来。
>
> 一句话方向：**深度学习的真正贡献不是更大的策略网络，而是把"成功率"从赛后统计变成赛前可校准的预测；成功率的真正难点不是均值，而是它由一串条件概率相乘、又只在极少数样本上被估计。**

---

## 0. 先给直觉：三句话

1. **成功率是乘性的，不是加性的。** 一个 K 步任务的成功率≈∏qᵢ。每步 0.8，5 步只剩 0.33；每步 0.9，5 步还有 0.59。修哪一步最值，不是看它"难不难"，而是看**其余步的乘积**——∂S/∂qᵢ=∏_{j≠i}qⱼ。这会把"救最差任务"的直觉反过来。
2. **成功率是在"暴露时间"里被对手消耗的。** 人为干扰按时间到达；策略越快、越早收工，暴露窗口越短。**实时性因此第一次成为成功率的自变量**，而不只是可信度指标。
3. **成功率是一个高方差估计量。** 若每任务只跑 n 次，p≈0.2、n=10 时 Wilson 95% 区间约为 [0.06, 0.51]。**离线实验若不做配对/序贯设计，就会在噪声里做决策。**

## 1. 把两个灵感词翻译成可工作的定义

### 1.1 「深度学习」= 可校准的后验 + 可迁移表征 + 可蒸馏的不确定性

**直觉**：如果只把深度学习理解成"更大的端到端网络"，在这场比赛里几乎一定输给"预训练 VLA + 少量适配"。因为 32 个任务总共约 3.3 万条演示（工作区 `exp/r16_task_profile.json` 的 `eps` 求和为 33276），平均每任务约 1000 条，而且**只有成功样本**。这个数据量不支持从零训练，却刚好够做**后验校准**。

**严谨定义**：本轮只取深度学习的三个可审计能力，其余一律视为工程细节：

- **C1 表征**：共享视觉-语言骨干 + 参数高效适配（PEFT），把 32 任务当多任务先验；对应 v2 的 UIP-14 骨架，但不再是叙事中心。
- **C2 不确定性**：deep ensemble / heteroscedastic head / split conformal，输出成功概率的**下界 q⁻**，而不是一个点估计。决策只吃 q⁻。
- **C3 蒸馏**：训练期用 ensemble + 仿真负样本当"教师"，部署期把均值与方差蒸回**单一骨干上的一个头**，满足"单模型多任务"合规。

**关键警告**：只用成功演示训练成功头，本质是 **positive-unlabeled (PU) 学习**，不是普通二分类。若直接当二分类训，q̂ 会系统性偏向 1，后续所有"搏末步"的决策都会过度自信。

### 1.2 「成功率」= 序贯乘性过程 × 估计问题 × 暴露过程

**直觉**：官方只给一个百分数，但那个百分数背后至少有三层——任务内（K 个计分步条件成功率相乘）、时间上（干扰按时间到达，越慢越容易被撤回）、统计上（n 个 episode 的二项抽样）。把三层拆开，才知道该修哪一步、该不该加速、实验要跑多少次。

**严谨定义**：见 §3。这三层分别对应三个可操作量：`q_i`（每步条件成功率）、`μ`（干扰到达率）、`n`（评测样本数）。

## 3. 严谨定义：这一轮真正新增的东西

### 3.1 序贯乘性模型：成功率为什么偏爱"最弱一步"

**直觉**：一个任务只要任何一步失败就结束，所以成功率是各步条件成功率的连乘；步骤分则是每一步的"到达概率 × 该步分值"之和。

**定义**：设任务有 K 个有序计分步，分值 `s₁..s_K>0`，`Σsᵢ=100`。令

```text
q_i = P(第 i 步完成 | 前 i-1 步已完成, 策略执行)
```

并假设失败吸收（未完成则后续不得分）。记到达概率 `R_i=∏_{j<i} q_j`，则

```text
S      = ∏_{i=1..K} q_i                       # 成功率
E[Step] = Σ_{i=1..K} s_i · ∏_{j≤i} q_j        # 期望步骤分
```

两条灵敏度是整轮的地基：

```text
∂S / ∂q_i        = ∏_{j≠i} q_j = S / q_i       # 绝对增益：其余步的乘积
∂lnE / ∂lnq_i    = s_i·∏_{j≤i}q_j / E  ≜ w_i   # 相对增益：该步贡献占比
```

**三条推论**：

1. **任务内**：修最小的 `q_i`，绝对成功率增益最大（`S/q_i` 在 `q_i` 最小时最大）。
2. **任务间（反直觉）**：边际收益是 `∏_{j≠i} q_j`——**"只有一处弱、其余都稳"的任务，比"处处都弱"的任务更值得投入**。这与"去救最差的任务"相反。
3. **两个指标会打架**：因为 `s_i` 递增（末步≥前序），`w_i` 未必随 i 递减，所以对成功率最优的投入点，未必是对步骤分最优的投入点。这正是必须输出 Pareto 前沿、而不是单点的原因。

**小账**：若所有 `q=0.8`，K=2 时 `S=0.64`，K=5 时 `S=0.33`（真实分布：2 步 11 个、3 步 14 个、4 步 5 个、5 步 2 个）。把其中一步从 0.8 提到 0.9：K=2 的 `ΔS=0.1×0.8=0.08`，K=5 的 `ΔS=0.1×0.8⁴=0.041`。所以同样的单步改进，在短任务上带来的每任务成功率增量更大；但长任务基础成功率更低。排序应按 **ΔS/成本**，不是按难度。

### 3.2 暴露模型：实时性第一次进入成功率

**直觉**：人为干扰不是"赛前摆好"的，而是**赛程中**发生的（v2 已从 `human_*` 证据确认"拉上后再拉开""叠好后翻开"）。策略跑得越久，撞上干预的机会越多。

**定义（风格化模型，三条显式假设）**：

```text
(A1) 干扰到达为齐次泊松过程，率 μ（单位 1/s）
(A2) 单步执行占据 τ_i，总墙钟时间 T = Σ τ_i
(A3) 到达后若未被恢复，则撤回最近完成的计分步
```

忽略恢复时：

```text
S(T) ≈ (∏ q_i) · exp(-μT)          ⇒   ∂lnS/∂T = -μ
```

若有恢复概率 `r`（UIP-09′/18 的能力），有效损失率降为 `μ(1-r)`。**可检验推论**：同一策略家族内，缩短 episode 墙钟时间会提高成功率，斜率≈`μ`。这把 UIP-13/08′ 从"可信度工程"升级为"成功率杠杆"。

**边界**：`μ` 未知且可能非齐次（人工干预常在关键步附近触发）。所以这是 **H2，不是定理**；必须用真机日志/仿真脚本扰动去估 `μ`，并检验"速度→成功率"的斜率是否显著。

### 3.3 估计模型：为什么离线实验会骗人

**直觉**：成功率是从有限次试验里数出来的比例，它本身有抽样误差；当 p 只有 0.2 时，10 次里成功 2 次和成功 4 次的差别，很可能只是运气。

**定义**：官方每任务 n 次，`p̂=X/n, X~Bin(n,p)`，`Var(p̂)=p(1-p)/n`。Wilson 95% 区间（工作区实算）：

| p | n=10 | n=20 | n=50 | n=100 |
|---|---|---|---|---|
| 0.1 | [0.018,0.404] | [0.028,0.301] | [0.043,0.214] | [0.055,0.174] |
| 0.2 | [0.057,0.510] | [0.081,0.416] | [0.112,0.330] | [0.133,0.289] |
| 0.3 | [0.108,0.603] | [0.145,0.519] | [0.191,0.438] | [0.219,0.396] |

**结论**：内部 A/B 必须用**配对/共同随机数（CRN）** + **序贯检验（SPRT）**；否则几十次试验根本分不清 5% 的差异。外部分数是随机变量，**不要根据单次榜单波动改方向**；优化真实 `p`，同时用小 n 的不确定性给结论加置信区间。

### 3.4 复合目标：为什么不猜权重，而是给 Pareto 前沿

**直觉**：官方说"按平均成功率与步骤分综合排序"，但没给权重。与其猜一个 λ，不如把"能同时做到的最好组合"整条曲线交出来。

**定义**：`J_λ = λ·S + (1-λ)·E/100`，`λ∈[0,1]`。不同 λ 对应不同执行哲学：λ→1 是"激进搏末步"，λ→0 是"保守保前缀"。本轮输出**Pareto 前沿**（一组不可支配的 (S,E) 配置），等手册/真实榜单披露后再选点。这样对未知聚合规则鲁棒。

### 3.5 复合误差：为什么块长不是纯工程参数

**直觉**：开环执行一个动作块，等于在这段时间里"闭着眼睛"；眼睛闭得越久，偏离越大，遇到干扰也反应越慢。但块太短，往返多、延迟高、暴露的通信开销大。

**定义（可检验的风格化模型）**：经典行为克隆的复合误差随开放环长度超线性增长（Ross–Bagnell 的 `O(εT²)` 一类结论；这里不假设其精确常数）。把每个块内的失败风险写成 `h(k)=h₀+c(k-1)`，块数 `T/k`，则

```text
S(k) ≈ [1 - h(k)]^(T/k)
```

存在最优 `k*`。这把 v2 的 UIP-13（按阶段拍脑袋选 k）变成"估计 `h₀,c` 后的最优块长"。注意：这是**假设**，用 E206 扫出来再决定是否采信。

## 4. 瓶颈假设（v3）

- **H1（最高杠杆）**：每任务最弱一步的 `q_i` 是瓶颈；但**"一处弱、其余稳"的任务边际收益最大**，而不是当前成功率最低的任务。
- **H2**：人为干扰按时间到达；缩短墙钟 `T` 与提高恢复率 `r` 都能提高成功率，速度是成功率的自变量。
- **H3**：成功头只能从成功演示训练；若不做负样本合成 / PU 校正，`q̂` 系统性偏高，导致过度搏步、反而丢掉已得步骤分。
- **H4**：`p_sim` 与 `p_real` 的偏差随任务/扰动变化；GSO 只能做结构代理，必须用真机锚点校准，否则"仿真刷分"就是伪进展。

## 1. 统一目标与成功率的严格定义（本轮地基）

### 1.1 序贯乘性模型

设任务有 K 个有序计分步，分值 `s₁..s_K>0`，`Σsᵢ=100`；`q_i` 为"前 i-1 步完成后，第 i 步完成"的条件概率；失败吸收。则

```text
R_i      = ∏_{j<i} q_j                       # 到达第 i 步的概率
S        = ∏_{i=1..K} q_i                    # 成功率
E[Step]  = Σ_{i=1..K} s_i · ∏_{j≤i} q_j      # 期望步骤分
```

灵敏度：

```text
∂S/∂q_i       = ∏_{j≠i} q_j = S/q_i          # 绝对增益由"其余步的乘积"决定
∂lnE/∂lnq_i   = s_i·∏_{j≤i}q_j / E ≜ w_i     # 相对增益由该步贡献占比决定
```

**直接结论**：任务内修最小 `q_i`；任务间优先"一处弱、其余稳"的任务；S 与 E 的最优投入点可能不同，故输出 Pareto 前沿。

### 1.2 暴露模型

在 `(A1) 泊松干扰率 μ`、`(A2) 单步停留 τ_i`、`(A3) 未恢复则撤回最近完成步` 下：

```text
S(T) ≈ (∏ q_i)·exp(-μT),   T=Στ_i
∂lnS/∂T = -μ     （有恢复概率 r 时降为 -μ(1-r)）
```

**含义**：缩短墙钟时间与提高恢复率是两条独立杠杆；实时性首次成为成功率的自变量。`μ` 需从真机日志/仿真扰动估计，列为 H2。

### 1.3 估计协议

`p̂=X/n, X~Bin(n,p)`，Wilson 95% 区间（实算）：

| p | n=10 | n=20 | n=50 | n=100 |
|---|---|---|---|---|
| 0.1 | [0.018,0.404] | [0.028,0.301] | [0.043,0.214] | [0.055,0.174] |
| 0.2 | [0.057,0.510] | [0.081,0.416] | [0.112,0.330] | [0.133,0.289] |
| 0.3 | [0.108,0.603] | [0.145,0.519] | [0.191,0.438] | [0.219,0.396] |

**协议**：内部 A/B 一律配对/共同随机数（同一初始状态、同一扰动种子），并用 SPRT 序贯停止；32 任务多重比较用 Benjamini–Hochberg 控制 FDR。**报告一律带区间，不报单点。**

### 1.4 复合目标与 Pareto

```text
J_λ = λ·S + (1-λ)·E/100,    λ∈[0,1] 未知
```

不猜 λ。对 `λ∈{0,0.25,0.5,0.75,1}` 各求一组执行配置，输出不可支配的 `(S,E)` 前沿；等官方权重披露后选点。

## 2. 旗舰：UIP-16 · SCORE（Success-Calibrated Ordered Risk Estimator）

**直觉**：v2 的 `regressed/done` 是硬规则；但"这一步到底有多大概率做成"才是决策真正需要的量。SCORE 就是给每个计分步输出一个**保守的成功概率**，让后续的"继续/收手/重做"都有统一货币。

**严谨定义**：在共享骨干 `f_θ(o)` 上挂一个分步成功头

```text
g_φ(f_θ(o_t), i, l) → q̂_i(t) ∈ [0,1]
```

- **训练期**：M=5 个不同种子/bootstrap 的头，得到均值 `μ_q` 与认知方差 `σ_q²`；Huber/温度缩放做概率校准。
- **校准期**：按任务与扰动组 `g`（未见物品 / 位移 / 撤回 / 背景）做 **Mondrian split conformal**，得到下界

```text
q⁻_i(t) = 1 - Quantile_{1-α}( {1 - q̂_i(x) : x ∈ 校准集_g} )
```

- **部署期**：把 ensemble 的均值与方差蒸回**单一骨干上的一个 heteroscedastic 头**（两个输出：`μ_q, log σ_q²`），推理只跑一个模型。ensemble 只存在于训练期，**不违反单模型**。

**为什么必须"下界"而不是"均值"**：ESPO 的 bank-or-push 是风险决策；用均值会在最该收手时继续搏步。下界把"我不确定"翻译成"保守地不搏"。

**验收**：held-out **任务**（不是 held-out episode）上的 ECE < 0.05；每个扰动组的 coverage 不低于 `1-α` 减去 3 个百分点；Brier skill score > 0.15。

**风险**：conformal 的交换性假设在分布偏移下会破；必须用分组校准 + 安全裕度，并报告覆盖率的跨组最差值。

## 3. 核心：UIP-17 · PULSE（Positive-Unlabeled Success Learning + Failure Mining）

**直觉**：公开数据只有成功演示。若把成功演示当正样本、把其余当负样本，模型学到的是"专家状态=成功"，而不是"哪些状态会导致失败"。它会在训练分布内很准，在人为干扰/未见物品上**自信地错**。

**严谨定义**：

1. **负样本合成**：用 UIP-11/GSO + UIP-12/DRF 生成失败 rollout（位移、撤回、遮挡、错序），并给每个计分步打上"完成/未完成"的仿真标签。这是**有标签负样本**，优先级高于 PU 假设。
2. **PU 风险（当只有 P 与 U 时）**：令 `π=P(y=+1)`，`R⁺_P`、`R⁻_P`、`R⁻_U` 分别为正样本上的正类损失、正样本上的负类损失、无标签集上的负类损失，使用非负 PU 风险

```text
R̂_PU = π·R⁺_P + max(0, R⁻_U - π·R⁻_P)
```

3. **Group-DRO**：把扰动类型当组，最小化**最差组**风险，而不是平均风险。目标：

```text
min_θ  max_g  E_{(x,y)~D_g}[ ℓ(g_φ(x), y) ]
```

4. **失败模式挖掘**：对失败 rollout 的成功头倒数第二层特征做聚类，得到失败模式及其质量占比；把 DRF 的生成预算按模式质量分配（见 UIP-21）。

**边界（必须写进报告）**：PU 的标准假设是 SCAR（正样本完全随机抽取），而专家演示显然不是随机的（它们集中在成功轨迹上）。因此**优先用仿真标签负样本，PU 只作补充**；不满足 SCAR 时，`q̂` 只能做相对排序，不能当绝对概率。

**验收**：在"人为撤回"与"未见物品"两组上，失败预测的 Average Precision 比朴素 BCE 至少高 0.15；最差组 ECE 不高于 pooled ECE + 0.03。

## 4. 核心：UIP-18 · ESPO（Expected-Score Policy Optimization / bank-or-push）

**直觉**：多做一个计分步，可能多拿 `s` 分；但只要还在动，已到手的分数就暴露在"被撤回"的风险里。**继续还是收手，应该由当前成功概率、已得分数、撤回风险三者共同决定**，而不是"能继续就继续"。

**严谨定义（单块最优停止）**：设已得分 `B`，下一步分值 `s`，下一步完成后的期权价值 `V_next`（含后续步与整单成功奖励），每块发生撤回事件的概率 `h`，撤回损失比例 `ρ`。继续的期望价值：

```text
V_cont = (1-h)·[ q·(B+s+V_next) + (1-q)·B ] + h·(1-ρ)·B
V_stop = B
```

`V_cont ≥ V_stop` 解得门槛：

```text
q* = h·ρ·B / [ (1-h)·(s + V_next) ]
```

**决策规则**：用校准下界 `q⁻` 比较——`q⁻ ≥ q*` 才继续；否则 bank & stop（或先恢复被撤回的步）。

**读法**：

- `h=0` 或 `ρ=0` ⇒ `q*=0`，永远继续（没有撤回落险）。
- `B` 越大、`h`/`ρ` 越大 ⇒ 门槛越高（保护已得分）。
- `s+V_next` 越大 ⇒ 门槛越低（末步值钱，值得搏）。
- 示例（示意）：`h=0.3, ρ=1, B=80, s=20, V_next=20` ⇒ `q* = 24/(0.7×40) ≈ 0.857`。即：若每块有 30% 概率把已得 80 分全部撤回，只有对下一步有 86% 把握才该继续。

**与 v2 的关系**：`regressed` 分支（UIP-09′）成为"撤回已发生"后的恢复动作；ESPO 负责"撤回发生前"是否值得暴露。两者一个防守、一个止损。

**Pareto 生成**：在门槛上加风险厌恶项 `q⁻ ≥ q* + ν·σ_q`，扫 `ν≥0` 得到不同保守程度的 `(S,E)` 点；这比猜 λ 更可控。

## 5. 支撑：UIP-19 · TTA-SR（Test-Time Adaptation for Success Robustness）

**直觉**：未见物品/背景是官方明确列出的泛化轴，但测试时没有标签。深度学习的可用信号是**自监督一致性**：同一场景在不同视角/时间应能互相重建；如果重建误差突然变大，说明"见到的不是训练分布"，此时应更保守。

**严谨定义**：在 episode 的前 N 帧上，只更新一个**极小适配器**（LayerNorm 仿射参数或低秩残差），目标为

```text
L_tta = L_masked_recon(o_t) + β·L_temporal_order(o_t, o_{t-1})
```

**护栏（必须）**：

- 只在 `N` 帧内、固定步数内适配，超预算立即回滚；
- 监控成功头的 `σ_q` 与熵：若适配后不确定性上升，回滚到冻结权重；
- 适配器参数在部署时并入骨干（仍是一个模型）。

**风险**：TTA 可能把"人为干扰导致的画面变化"误当成域偏移去适应，反而学会忽略干扰。因此**干扰组不参与 TTA 更新**，只更新视觉归一化类参数。

**验收**：在"未见物品/背景"组上 `ΔS>0`，延迟增量 < 10%，回滚率 < 5%。

## 6. 支撑：UIP-20 · CES（Compounding-Error Shield，合并 v2 的 UIP-13）

**直觉**：块长 `k` 同时决定三件事——往返次数（延迟）、块内开环漂移（失败风险）、对干扰的反应延迟（撤回损失）。它不是工程常数，而是一个有最优值的策略参数。

**严谨定义（风格化、可检验）**：设每块失败风险 `h(k)=h₀+c(k-1)`，剩余时间 `T`，块数 `T/k`：

```text
S(k) ≈ [1 - h(k)]^(T/k)
k* = argmax_k  S(k) - ν·Latency(k)     s.t. Latency(k) ≤ budget
```

`h₀,c` 从离线回放/仿真日志拟合；`c` 就是"开环漂移"的经验度量。若 `c≈0`，则大块更优；若 `c` 大，则小块更优。**这把 v2 的"按阶段拍脑袋选 k"变成可估计的优化。**

**护栏**：`k` 每次可返回 ≤ 元数据声明的 `K_MAX`，严格保持块形状与索引顺序；与 UIP-15 的延迟/抖动预算联动。

**验收**：`S(k)` 在扫描区间内有单峰；实测 `k*` 与拟合预测相差 ≤ 1；延迟方差下降 ≥ 30%。

## 7. 管理：UIP-21 · SPA（Success Portfolio Allocation）

**直觉**：32 个任务都计入平均成功率，所以每个任务提升 `Δp` 对总分贡献相同（`Δp/32`）。真正的差别在**每单位成本能换来多少 Δp**。而由 §1.1，提升某任务第 i 步的收益是

```text
ΔS = Δq_i · ∏_{j≠i} q_j
```

所以应该优先**"只有一处弱、其余都稳"**的任务：那里的 `∏_{j≠i}q_j` 大。

**严谨定义**：给定任务 t 的候选改进步 i、预估可达 `Δq_i` 与成本 `c_{t,i}`，按

```text
priority(t,i) = Δq_i·∏_{j≠i} q_{t,j} / c_{t,i}
```

排序分配数据/算力/真机时段。每轮用成功头的估计更新 `q`，形成**序贯分配带探索**（类似 bandit，但奖励是 ΔS）。

**反例**：把预算全押在"当前成功率最低"的任务上通常不优——如果它处处都弱，修一步的 `∏_{j≠i}q_j` 很小；反之，一个 90%/90%/60% 的三步任务，修最后一步的边际收益接近 0.81。

**验算表**（K=3，`s=(30,30,40)`）：

| 情形 | q 向量 | S | `∂S/∂q_weak` | 把 weak 0.6→0.7 的 ΔS |
|---|---|---|---|---|
| 一处弱、其余稳 | (0.6, 0.9, 0.9) | 0.486 | 0.81 | **+0.081** |
| 处处弱 | (0.6, 0.6, 0.6) | 0.216 | 0.36 | +0.036 |

前者是后者的 **2.25 倍**。这就是 SPA 的全部理由。

## 8. 关键伪代码（SCORE + ESPO + CES）

```python
class SCORE:
    """训练期 ensemble + 分组 conformal；部署期单骨干单头。"""
    def fit(self, D_pos, D_sim, groups):
        # D_pos: 成功演示（只有正样本）
        # D_sim: GSO/DRF 生成的扰动 rollout（含仿真失败标签）
        self.heads = [SuccessHead(seed=s) for s in range(5)]
        for h in self.heads:
            h.train_pulse(D_pos, D_sim, groups)   # nnPU + Group-DRO
    def calibrate(self, D_cal, groups, alpha=0.1):
        self.temp = fit_temperature(self.heads, D_cal)
        self.qlow = {g: mondrian_conformal(self.heads, D_cal[g], alpha)
                     for g in groups}
    def q_lower(self, obs, i, group):
        mu, sd = self.student(obs, i)             # 蒸馏后的单头
        return conformal_lower(mu, sd, self.qlow[group])


class ESPO:
    def reset(self):
        self.i, self.B, self.redo = 0, 0, 0
    def get_action(self, obs):
        if self.score.regressed(obs, self.i):          # UIP-09′ 撤回已发生
            self.redo += 1
            return self.policy.recover(obs, self.i)
        q = self.score.q_lower(obs, self.i, self.group)
        s = self.weights[self.i]
        V = self.option_value(self.i + 1, self.B + s)
        qstar = self.h * self.rho * self.B / ((1 - self.h) * (s + V) + 1e-9)
        if q >= qstar + self.nu * self.sigma_q:        # 风险厌恶门槛
            k = self.ces.choose_k(self.i, q)           # UIP-20
            return self.policy.get_action(obs, k)
        return self.policy.finish(obs)                 # bank & stop


class CES:
    def choose_k(self, i, q):
        best, kbest = -1e9, 1
        for k in range(1, self.K_MAX + 1):
            h = min(0.99, self.h0[i] + self.c[i] * (k - 1))
            S = (1 - h) ** (self.T_remaining[i] / k)
            if self.latency(k) > self.budget:
                break
            val = S - self.nu_lat * self.latency(k)
            if val > best:
                best, kbest = val, k
        return kbest
```

|---|---|---|---|---|

## 11. 合规与风险（v3 新增重点）

- **单模型红线**：ensemble 只在训练期；部署是"一个骨干 + 一个头"。TTA 适配器在 episode 结束后丢弃/合并，不在推理时调用外部大模型。外部 VLM 验证器仍视为高风险，不进入部署路径。
- **仿真偏差**：GSO/DRF 只用于生成负样本与结构代理；`p_sim` 与 `p_real` 的差必须用真机锚点估计（E203/E209）。禁止用 fixture 或仿真分数当真实排名。
- **校准偏移**：conformal 的分组覆盖在强扰动下可能失效；报告最差组覆盖率，必要时加大 `α` 的安全裕度。
- **PU 假设**：SCAR 在专家演示上大概率不成立；以仿真标签为主、PU 为辅，`q̂` 不满足校准时不作绝对概率使用。
- **统计诚实**：预注册 n 与停止规则；32 任务多重比较用 BH-FDR；所有结论带 Wilson/自助区间；不看单次榜单波动改方向。
- **接口红线**：块形状 `(T_a,…)`、索引 0 先执行、每端口状态隔离、延迟与动作规律性计入可信度（沿用 v2 的 UIP-08′/15）。

**与 v2 的接口**：UIP-01′ 的状态机保留为执行层；UIP-02′ 提供 `s_i`；UIP-09′ 成为 `regressed` 恢复动作；UIP-11/12 变成 SCORE/PULSE 的数据引擎；UIP-13 合并进 CES；UIP-14 降级为可选的技能头工程；UIP-15 作为运行时护栏。

## 13. 本轮最大风险 & 押注

**一句话**：最大的风险是**成功头在分布偏移下"自信地错"**——只用成功演示训练会让 `q̂` 系统性偏高，ESPO 于是在最该收手时继续搏步，反而把已到手的步骤分暴露给人为撤回；若不先做负样本合成、分组校准与真机锚点，整套"成功率优化"会精确地朝错误方向优化。

**→ 本轮押注：UIP-16 SCORE × UIP-18 ESPO 组成的"校准成功估计 → bank-or-push 决策"闭环**，由 UIP-17 PULSE 提供负样本、UIP-20 CES 控制暴露时间、UIP-21 SPA 决定投入顺序。它把 v2 的"检测-重做"从一条规则升级为**带概率依据的序贯风险决策**，且完全落在单模型与 API 权限之内。
