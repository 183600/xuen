# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「6D位姿估计」×「双臂协调」）

> R69 把不确定性拆成 aleatoric 与 epistemic，用流匹配策略显式呈现多模态动作，再用「看/问/触」主动消解歧义。它比 R68 进了一步，但仍默认两件事：
> - **歧义的模式是任意聚类出来的**——K 个采样、DTW/Fréchet 聚类、再算模态熵。可在 6D 位姿里，歧义不是任意多峰，而是**物体对称群生成的一个群轨道**：一只对称的杯子绕轴转 180° 后，观测似然完全一样，这不是策略幻觉，而是**坐标冗余**。把群轨道当成 K 个自由模态去聚类，既浪费样本，也可能把「同一条轨道上的两个代表」误判成两个物理假设。
> - **不确定性是单个智能体的标量/熵**——但双臂任务的成功不取决于左臂多准、右臂多准，而取决于**两臂对同一个物体的相对位姿**是否一致，以及**两臂是否还在同一个世界里**。两只手各自 1mm 精度，可能相对误差 2mm；也可能各自 5mm，却因为共享同一个错误先验而「完美对齐」。
>
> 本轮两个灵感正好各补一刀：
> - **6D 位姿估计**告诉我们：位姿活在 SE(3) 上，有对称商、有流形协方差、有由 CAD 先验给出的**可枚举模式**；真正要问的不是「有几个模态」，而是「**在哪个规范（gauge）里、对称性是否被任务打破**」。
> - **双臂协调**告诉我们：信息不只来自看和问，还来自**稳定—观察、换手、相对运动、力探针**这些只有两只手才做得出的物理探询；而危险也不只是撞到环境，还有**闭链内力**——两只手把同一个物体拧坏。
>
> 核心命题：**把 R69 的「抽象多模态 + 标量 epistemic」升级为「对称商上的 SE(3) 位姿信念 + 相对位姿协方差 + 跨臂规范一致性」；歧义先按物体对称群结构化并检查任务是否真的在乎它，再决定用双臂物理探询去消解，消解不了就把「刚性闭链」换成「顺从退避」，让不确定变成有界内力而不是灾难。** 命名 **GAUGE-RAS**（Gauge-consistent, Affordance-aware, Uncertainty-propagating Geometric Estimation for bimanual Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们是不是在同一个世界里、看着同一个姿态？**」——不确定性不只是刹车与提问，也可以是一次换手、一次顺从、一次对规范的声明。

## 0. 直觉与动机

**灵感 1（6D 位姿 → 对称不是噪声，是规范冗余）**
直觉：对称物体的位姿歧义不是「模型不确定」，而是「同一个物理姿态有多个坐标写法」。你看一个圆柱，绕轴转 90° 前后两帧图像可以逐像素相同；这不是两个世界，而是**你的坐标系选择有多余自由度**。R69 把这些等价解当成 K 个待消解的模态，相当于把「同一座山的两个名字」当成两座山去调查。
严谨说法：物体位姿 X ∈ SE(3)；物体对称群 G ≤ SE(3)（离散的 C_k、D_k，或连续的 SO(2)）使观测似然满足 p(y|X)=p(y|Xg)。后验因此是 **SE(3)/G 上的分布**，而不是 SE(3) 上一堆无关的峰。选一个模态 = 选商空间的一个**截面（gauge）**。于是「消歧」的正确对象是**规范选择**，不是峰计数。

**灵感 2（功能对称 vs 几何对称 → 歧义是任务相对的）**
直觉：一只带把手的杯子在几何上可能近似轴对称，但「倒水」这个任务在乎把手朝向。几何上等价的两个位姿，功能上不等价；反过来，抓一个无纹理圆球时，绕任意轴转都是同一件事，你再怎么「看」也消不掉——也不该消，因为任务根本不在乎。
严谨说法：给任务一个 affordance 场 A: SE(3)→ℝ^m（可抓性、插入轴、倾倒方向、把手方向……）。定义 **功能对称子群** G_task = {g ∈ G : A(Xg)=A(X), ∀X}。只有商 G_amb = G/G_task 才是**任务相关歧义**：观测分不开、任务却在意的那些对称。R69 的模态熵应当在这个商上算，而不是在原始样本上算。这个区分是 R70 的第一块理论地基。

**灵感 3（相对位姿 → 任务量不是两只手的误差之和）**
直觉：双手端一个托盘，左手的 5mm 和右手的 5mm 如果方向相同，托盘只是整体偏了 5mm，相对形状没变；如果方向相反，托盘被拉长 10mm——这才是会掉东西的量。更隐蔽的是：两只手共享同一个物体姿态先验时，它们会**一起错**，相对位姿反而看起来完美。
严谨说法：真正进入闭链的是相对位姿 Z = Y_L^{-1} Y_R（Y_i 为第 i 臂末端在物体系下的抓取位姿）。一阶传播下 Σ_Z 含 **交叉协方差项** Σ_LR；共享潜变量使 Σ_LR ≠ 0。Σ_Z 可以小于各自独立误差之和（抵消）也可以大于（放大）。因此「跨臂一致」只能证明相对一致性，**不能证明绝对位姿正确**。这是 R70 的第二块地基，也是本轮最大风险的来源。

**灵感 4（双臂 → 更强的信息动作，也更强的事故模式）**
直觉：R69 的信息动作是看、问、等。双臂还多了几种只有两只手才能做的事：一只手稳住物体、另一只手换视角；换手时接触约束改变，位姿的不可观自由度被迫暴露；沿某个方向做小幅相对运动，让几何/摩擦给出信息；用已知小力探测，让力/力矩读出刚性。它们比「看」更有效，因为**接触会制造可观测性**。
严谨说法：把信息动作空间扩为 𝒜_info^B = {稳定-观察, 换手/重抓, 相对运动探针, 力/顺从探针}，每个动作是**两臂联合动作**，必须过联合 C-RAS-WM 认证，并把「诱导内力」计入成本。信息动作从「读传感器」升级为「**改变物理约束以制造传感器读数**」。

**灵感 5（顺从 → 不确定性的第二个耗散通道）**
直觉：R68/R69 处理不确定性的唯一动作是「慢下来」（λ_floor）。可双臂刚性闭链里，慢并不防止内力：两只手都停住，但若都把物体估计错了 1cm，静止的夹持照样在拧。真正该随不确定性调节的是**刚度**：越不确定，越要软，让位姿误差变成小位移而不是大力。
严谨说法：闭链内力 ‖w_int‖ ≲ K_eff·‖δξ_Z‖。令顺从度（柔度）κ 随 U_task 增大，则 K=1/κ 下降，‖w_int‖ 被上界压住，代价是任务精度下降。于是安全工作点从一维 (λ) 变成二维 (λ, κ)：**不确定 → 既慢又软**。这是 R68「只收紧」在接触任务里的严格补全。

**灵感 6（共谋共识 → k 源一致不再充分）**
直觉：R69 用「k 个正交证据源一致」抵抗投毒。但在双臂里，两臂共享同一个物体先验、同一套外参、同一段训练分布，它们的错误是**相关**的。两个都被同一张纹理骗到的相机，会给出「高度一致」的错误答案；此时 k-一致不但不纠错，反而把错误盖章。更糟的是，这种共谋不需要攻击者——它是结构性的。
严谨说法：证据残差的协方差矩阵 R_eff 若不是满秩、且共同模分量大，则多数投票的错误率不再随 k 指数下降，甚至可能随 k 上升。必须用**共同模敏感度**和**有效独立秩**替代「数源个数」，并显式记录是否存在能打破共同模的**第三锚点**。

**灵感 7（严格包含 → 再次让新层是旧层的退化）**
直觉：单臂、非对称物体、无共享误差时，GAUGE 不应该比 FLUID 做任何额外的事。这样我们每加一层，不会多一个需要独立信任的黑箱；只是给旧层补了它看不见的几何与接触维度。
严谨说法：当 G_amb 平凡、Σ_LR=0、不使用跨臂闭环、退化为单臂刚性时，GAUGE 的位姿层、探询层、顺从层全部旁路，逐指令回到 FLUID；安全侧只增加「内力上界」这一条，永不放松 R69 已有的 λ 下界。层级关系：CALM ⊂ FLUID ⊂ GAUGE。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（GAUGE-RAS 总览）** GAUGE-RAS = (SE3B, SQ, TPU, RPU, BCC, IDE, BAP, CBS, CCC, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i，R69 定义 293-i）；
(ii) **规范纪律（gauge discipline）**：任何协调动作必须声明参考系/截面 σ（哪只臂、哪个世界系、选对称轨道的哪个代表）；禁止跨规范静默平均；规范交换、左右手混淆、镜像误判是一等故障（定义 319），必须被检测、审计与证书记录；
(iii) **内力安全**：只有在任务投影相对不确定度 U_task(Σ_Z) ≤ τ_rel 且联合前缀认证通过时，才允许建立刚性闭链；否则进入顺从退避（定义 317），保证 ‖w_int‖∞ ≤ w_max。

**定义 311（共享世界位姿信念 SE3B）** 物体在世界系 W 下的位姿 X_t ∈ SE(3) 是被两臂共同观测的**共享潜变量**：y_t^i = h_i(X_t, T_{B_i}^W) + ε_i，i ∈ {L,R}。后验 b_t(X) 是 SE(3) 上的混合：b_t = Σ_k w_k · MF(μ_k, Σ_k)，其中 MF 为矩阵 Fisher / SE(3) 上的集中高斯，μ_k 为测地位姿均值，Σ_k ⊂ se(3) 为切空间协方差。两臂共读同一 X，故由构造有交叉协方差 Σ_LR = Cov(δξ_L, δξ_R) ≠ 0（还叠加共享外参误差 δT_cal）。规范由三元组 σ = (W, B_ref, g_ref) 声明；换参考臂只是规范变换，不是新信息。

**定义 312（功能对称商 SQ）** 物体几何对称群 G = Stab(X_obj) ≤ SE(3)，离散部分记为 G^disc（|G^disc| ≤ 24），连续部分记为 G^cont（如回转体的 SO(2)）。affordance 场 A 定义功能对称子群 G_task = {g ∈ G : A(Xg)=A(X), ∀X}，以及任务相关歧义群 G_amb = G/G_task。SE(3) 位姿信念实际活在**主丛** SE(3) → SE(3)/G_task 上；选模态 = 选一个截面。注意方向：G_task 越大（任务越不在乎对称），待消歧越少；G_task={e} 时所有几何对称都变成任务相关歧义。

**定义 313（任务投影不确定度 TPU）** 给定任务关键方向集 𝒰_task（接近轴、插入轴、重力方向、闭链力旋量方向等），U_task(Σ) = max_{u∈𝒰_task} u^T Σ u。混合后验的 U_task(b) = Σ_k w_k·U_task(Σ_k) + H_task(w)，其中 H_task 只在 G_amb^disc 上取熵、连续部分解析积分。用最坏方向投影替代 trace，避免「平均很准、关键方向很糟」的假安全。

**定义 314（相对位姿协方差传播 RPU）** 令 Y_i = X^{-1}T_{E_i}^W 为第 i 臂末端在物体系下的抓取位姿，Z = Y_L^{-1}Y_R 为双臂相对抓取位姿。一阶误差 δξ_Z = J_L δξ_{Y_L} + J_R δξ_{Y_R}，故
Σ_Z = J_L Σ_L J_L^T + J_R Σ_R J_R^T + J_L Σ_LR J_R^T + J_R Σ_LR^T J_L^T。
定义**相对不确定度间隙** Γ = tr Σ_Z − ½(tr Σ_L + tr Σ_R)：Γ<0 表示共享误差在相对量上抵消（虚假安心），Γ>0 表示误差被放大（对拧风险）。Σ_LR 必须由共享潜变量与外参误差显式估计，禁止置零。

**定义 315（跨臂闭环残差与可辨识性 BCC）** 跨臂闭环残差
r_chain = log_{SE(3)}( T̂_L^O · (T̂_R^O)^{-1} · T_cal^{R←L} ) ∈ se(3)，
理想为 0。其中 T̂_i^O 为第 i 臂经物体估计得到的相对变换，T_cal 为标定外参。分解 r_chain = d_rel ⊕ d_cm（相对漂移与共同模漂移）。**只有 d_rel 可被双臂闭环观测**；d_cm 落在观测算子零空间（定理 20）。存在外部锚点（固定相机、世界标定板、与静态环境的接触）时，d_cm 才可辨识。IDE（IP-269）负责给出 (d_rel, d_cm, anchor_available) 三元组，供审计与证书使用。

**定义 316（双臂主动探询 BAP）** 信息动作空间 𝒜_info^B = {g_stab, g_regrasp, g_relmove, g_comply}，分别是稳定-观察（一臂固定物体、一臂改视角）、换手/重抓（改变接触约束）、相对运动探针（沿零空间/任务无关方向小位移）、力/顺从探针（施加已知小力旋量并读位移）。每个 g 是**两臂联合轨迹** ξ_g = (a_L, a_R, g)。信息增益在商空间上算：VoI_B(g) = H(M|b_t) − E_{y~p(·|g,b_t)}H(M|b_t,y)，M 为 G_amb^disc 上的模态身份。选择
g* = argmax_g [VoI_B(g) − c_phys(g) − c_wrench(g,U_task) − c_time(g) − c_social(g)]，
s.t. 联合 C-RAS-WM 认证、‖w_int‖∞ ≤ w_max、预算未超。若最优值 ≤ 0：不探询，退回 FLUID 的保守路径。

**定义 317（内力残差与顺从退避 CBS）** 闭链约束误差 e_Z = log_{SE(3)}(Z_actual^{-1}Z_cmd)，内力估计 w_int = K_p e_Z + K_d ė_Z，允许集 ‖w_int‖∞ ≤ w_max。顺从度 κ（柔度，m/N）按
κ_f = κ_0 · (1 + β·U_task(Σ_Z))
调度（越不确定越软），等效刚度 K_f = 1/κ_f。若 U_task(Σ_Z) > τ_rel：不建立刚性闭链，改为 leader–follower：leader 用 R68 的 λ 缩放速度，follower 用 κ_f 顺从并限力 F_max。由 e_Z ~ O(U_task) 得 ‖w_int‖ ≤ K_f·O(U_task) = O(1/β)（引理 21），即内力上界与不确定度解耦。

**定义 318（共谋共识检测 CCC）** 证据 e_1..e_n 的残差相关矩阵 R_eff 由共享标定、共享物体先验、共享训练分布估计。定义共同模敏感度 s_cm(R_eff) = λ_max(R_eff)/tr(R_eff)（或第一主成分解释比），有效独立秩 rank_eff(R_eff)。证据集可采纳 ⇔ rank_eff ≥ k_req ∧ s_cm ≤ s_max ∧（若要求绝对位姿）anchor_available。不满足时，把相关证据**降级为一个证据源**，不允许其投票凑数；对应证书字段 common_mode_suspect。

**定义 319（对称/规范/共链投毒 ℰ_GAUGE）** ℰ_GAUGE = ℰ_FLUID × ℰ_sym × ℰ_gauge × ℰ_chain。ℰ_sym：用纹理/遮挡/局部几何把物体伪装成另一个对称陪集，或让连续对称假装离散；ℰ_gauge：左右手交换、镜像件、基座系错配、把 g 与 g^{-1} 混用；ℰ_chain：向两臂外参同时注入同向漂移，使 r_chain 仍≈0（共同模攻击）。三者可与 R69 的 ℰ_poison（人类误导）叠加。

**定义 320（参与式审计 VQAuditor-G）** 审计对象新增：规范是否声明且一致、对称商是否按功能而非几何折叠、相对位姿协方差是否含交叉项、跨臂一致是否被误当绝对正确、探询是否诱发越界内力、共同模是否被当独立证据。结论回灌 AuditBuf，成为下一轮 BAP 的 c_wrench 与 CCC 的 s_max 先验。

**定义 321（证书 J_GAUGE）** J_GAUGE = (J_FLUID, G_task/G_amb, pose_geodesic_rmse, U_task, tr Σ_Z, Γ, r_chain, rank_eff, s_cm, anchor_available, ‖w_int‖_max, κ_used, gauge_ver)。Valid ⇔ Valid(J_FLUID) ∧ 对称商已认证 ∧（刚性闭链时 U_task(Σ_Z) ≤ τ_rel ∧ 内力有界）∧ 规范已声明 ∧ 共谋检查通过。

**定义 322（接触可观测性与力探针）** 对第 i 臂接触点施加力旋量 λ_i，位姿的局部可观测性由观测矩阵 O = [O_vision; O_contact(λ)] 的秩给出。若某方向仅靠视觉不可观（如圆柱绕轴、薄板绕法向），接触/摩擦可使 rank(O) 提升，从而把「不可辨」变成「可辨但需施力」。该增益必须与力上界、表面损伤风险一起计入 BAP 的 c_wrench；可观测性提升不足以抵消接触风险时不应探询。

**定义 323（层级退化与预算）** 退化条件 D = (G_amb 平凡) ∨ (单臂) ∨ (Σ_LR=0 ∧ 不用 BCC) ∨ (任务不接触)。在 D 上，GAUGE 的 SE3B 退化为 R69 的条件编码、BAP/CBS/CCC 旁路，逐指令回到 FLUID。预算：常规单臂路径总延迟 ≤ R69 的 2.6ms；双臂几何层额外 ≤ 0.9ms；仅当 U_task 或 r_chain 越界时才启动探询/多模态枚举，允许一次性超支 ≤ 1.2ms。

**定义 324（群轨道枚举与自适应 K）** G_amb = G_amb^disc × G_amb^cont。离散部分最多 |G_amb^disc| ≤ 24 个陪集，直接枚举；连续部分不采样，解析积分或沿任务关键方向取代表。因此无需 R69 的 DTW/Fréchet 聚类：K = |G_amb^disc|（常规为 1），mode_head 只预测「离散陪集是否 >1 以及是否有连续残余」。这把「用采样猜模态」换成「用群结构算模态」，同时给出模态的可证明完备性。

```python
# IP-264 SE3B：对称商位姿信念（共享潜变量，双臂共读，保留交叉协方差）
class SE3Belief:
    def update(self, obs_L, obs_R, prior, calib):
        comps = pose_posterior(obs_L, obs_R, self.sym_group, prior)
        Sigma_LR = cross_cov_from_shared_latent(comps, calib)
        return SE3Mixture(comps, Sigma_LR)       # (μ_k, Σ_k) on SE(3), cross terms

# IP-265/266 SQ + TPU：只按功能对称商折叠，再投影到任务方向
def quotient_and_project(mix, affordance, task_dirs):
    g_task = symmetry_subgroup(mix.G, affordance)      # 保任务不变的对称
    modes  = orbit_cosets(mix, g_task)                 # 轨道 = 真歧义（可枚举）
    U_task = mixture_task_uncertainty(modes, task_dirs) # 最坏方向投影
    return modes, U_task, g_task

# IP-267 RPU：相对位姿协方差（含共享潜变量诱导的交叉项）
def relative_cov(mix):
    A_L, A_R = adjoint_jacobians(mix)
    return (A_L @ mix.Sigma_L @ A_L.T + A_R @ mix.Sigma_R @ A_R.T
            + A_L @ mix.Sigma_LR @ A_R.T + A_R @ mix.Sigma_LR.T @ A_L.T)

# IP-268/269 BCC + IDE：闭环只见相对漂移；共同模需第三锚点
def chain_check(mix, calib, anchors):
    r = log_se3(mix.T_L_O @ inv(mix.T_R_O) @ calib.T_RL)
    d_rel = project_relative(r)
    d_cm  = project_common(r, anchors) if anchors else None   # 无锚点不可辨识
    return r, d_rel, d_cm

# IP-270 BAP：双臂信息动作（稳定-观察/换手/相对运动/力探）
def choose_bimanual_probe(modes, U_task, budget, anchors):
    best = None
    for g in bimanual_candidates(modes):              # 4 类，≤6 候选
        if not budget.allow(g): continue
        if not c_ras_wm.certify_joint(g): continue    # 两臂联合认证
        if wrench_risk(g, U_task) > w_max: continue
        voi = entropy(modes) - expected_entropy(modes, g)
        score = voi - cost(g) - wrench_cost(g, U_task)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-271 CBS：不确定 -> 变软，不只是变慢
def compliance_schedule(U_task, lam):
    if U_task <= tau_rel:
        return "rigid", 0.0, lam
    kappa_f = kappa0 * (1.0 + beta * U_task)          # 柔度随不确定度增大
    lam     = max(lam, lam_floor(U_task))             # 继承 R68/R69 的 λ 下界
    return "leader_follower", kappa_f, lam

# IP-272 CCC：共谋共识检查（相关证据不等于独立证据）
def consensus_ok(evidence, k_req, anchor_available):
    R     = estimate_residual_correlation(evidence)
    s_cm  = common_mode_susceptibility(R)
    return (effective_rank(R) >= k_req) and (s_cm <= s_max)

# IP-276 主闭环：R69 FLUID + 几何/共享世界层
def GAUGE_RAS_round(M, obs):
    mix = M.se3b.update(obs.L, obs.R, M.prior_O, M.calib)
    modes, U_task, g_task = quotient_and_project(mix, M.affordance, M.task_dirs)
    Sigma_rel = relative_cov(mix)
    r, d_rel, d_cm = chain_check(mix, M.calib, M.anchors)
    slow = (norm(d_rel) > tau_chain) and (M.last_r_res < tau_res)
    # 1) 先用双臂物理探询解除规范歧义；无利可图才交给 R69 动作层
    g = (choose_bimanual_probe(modes, U_task, M.budget, M.anchors)
         if (U_task > tau_pose and not slow) else None)
    if g is not None and consensus_ok(M.evidence, k_req=2,
                                      anchor_available=bool(M.anchors)):
        mix, modes, U_task = execute_probe_and_refit(M, g)
        Sigma_rel = relative_cov(mix)
    # 2) 选模态 + 顺从调度（不确定 -> 既慢又软）
    mode = select_mode(modes, U_task, M.gauge_section)
    state, kappa, lam = compliance_schedule(U_task, M.efs.risk_scale(...))
    # 3) 刚性闭链只在相对位姿可信时允许；否则 leader-follower 限力
    if state != "rigid":
        return M.cbs.leader_follower(mode, kappa_f=kappa, lam=lam,
                                     F_max=w_max)
    A  = M.ach.propose(mode.a, H=M.vista.H)
    k  = M.c_ras_wm.certified_joint_prefix(A, ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 4) 参与式审计 + 证书（规范/共谋/内力/锚点全部入账）
    M.vqa_g.submit_async(g, g_task, U_task, Sigma_rel, r, kappa,
                         anchor_available=bool(M.anchors))
    return k, lam, mode, (U_task, Sigma_rel, state)
```

## 3. 推导

**引理 19（功能对称商压缩歧义）** 设观测似然在 G 下不变，A 为 affordance 场，G_task 为保 A 不变的子群。则任务相关后验只依赖 G_amb = G/G_task 的陪集；H(M|o) ≤ log|G_amb^disc|，连续部分不产生离散模态。若 G_task = G，则 U_epi ≡ 0；若 G_task = {e}，则所有几何对称都是任务相关歧义。系：R69 在原始样本上聚类会同时犯两类错——把同一陪集内的采样分裂成假模态，以及把连续对称误当成无限多模态；群结构给出了可证明的模态完备性。

**引理 20（相对位姿的抵消/放大与虚假共识）** 由定义 314，Σ_Z 含交叉项。若两臂误差由同一物体潜变量主导（Σ_LR 在共同方向正相关），则相对误差在该方向**抵消**，tr Σ_Z 可显著小于 ½(tr Σ_L + tr Σ_R)，即 Γ<0；与此同时绝对位姿误差不减小。故 (r_chain≈0, Γ<0) 不能推出「位姿正确」，只能推出「两臂对同一个错误达成一致」。反之，若误差反相关（独立视角/独立先验），Γ>0，闭链更易产生内力。系：跨臂一致性必须与**绝对锚点**联合使用，否则是结构性共谋。

**引理 21（顺从对不确定度的耗散）** 设闭链约束误差 e_Z ~ O(U_task)，内力 w_int = K_f e_Z + K_d ė_Z。取 κ_f = κ_0(1+βU_task)（K_f=1/κ_f），则 ‖w_int‖ ≤ (1/κ_0)·U_task/(1+βU_task)·C + ‖K_d ė_Z‖ → C/(κ_0 β)（U_task→∞）。即内力上界与位姿不确定度**解耦**；代价是任务精度 ~ κ_f·w 随 U_task 变差。系：R68 的纯 λ 收缩在刚性双臂闭链中无法给出内力上界；顺从是接触任务里不可替代的第二保守轴。

**引理 22（相关证据下的共识失效）** 设单源错误率 δ_p，k 个证据的共同模相关系数 ρ_c。当 ρ_c→1 且错误源于共同模时，多数投票错误率 → δ_p（不随 k 下降），且若错误源在同一主成分上，k 增大只会放大置信度而非正确率。故 R69 的「k 源一致」上界仅在条件独立下成立；双臂场景必须用 rank_eff 与 s_cm 修正。系：`consensus_ok` 在 s_cm 超阈值时把相关证据降级为一个源，宁可回到单源保守，也不接受「共谋的一致」。

**定理 18（GAUGE 严格包含 FLUID）** 在退化条件 D（定义 323）下，SE3B 给出与 R69 条件编码相同的后验（G_amb 平凡时商不改变支撑集，Σ_LR=0 时相对协方差退化为独立和），BAP/CBS/CCC 不触发，故 GAUGE 与 FLUID 逐指令相同。一般情况下，GAUGE 只在 FLUID 之外增加「内力上界」与「规范一致性」两条安全约束，不放松任何 R69 的 λ 下界。因此可达风险集不比 FLUID 大；效率侧多出接触探询与任务投影带来的 resolution bonus。层级：CALM ⊂ FLUID ⊂ GAUGE。

**定理 19（双臂安全与无突变）** 若每个探询动作过联合 C-RAS-WM 认证且满足 ‖w_int‖ ≤ w_max，且刚性闭链仅在 U_task(Σ_Z) ≤ τ_rel 时启用，则任意时刻内力有界、控制连续；当探询失败/超时/共谋可疑/锚点缺失时，系统单调退化为 leader–follower 顺从或 R69 的保守路径，λ 不降、κ 不降（更软），故无刚度突变。规范在每轮显式声明并被审计，禁止隐性换系，故无坐标跳变。R68 的提交/换装不变式（定理 15）保持。

**定理 20（共同模不可辨识，负面结果）** 记两臂漂移 d = (d_L, d_R)，闭环只观测 r_chain = d_L − d_R（加噪声），其观测算子 O 的零空间恰为共同模子空间 {(d,d)}。因此在没有第三锚点/环境接触时，任何仅用两臂闭环的估计器都无法区分「共同外参漂移」与「物体真实运动」；共同模误差恒不可辨识。推论：J_GAUGE 在 anchor_available=False 时不得签发「绝对位姿正确」的结论，只能签发「相对一致」；这是证书语义的硬边界，也是本轮最大风险的数学表述。

| `U_task(Σ) = max_{u∈𝒰_task} u^TΣu` | 任务投影（最坏方向）不确定度 |
| `r_chain = d_rel ⊕ d_cm` | 跨臂闭环残差分解（相对漂移 / 共同模漂移） |
| `VoI_B(g) = H(M\|b) − E[H(M\|b,y)]` | 双臂信息动作增益（在商空间上算） |
| `κ`, `κ_f = κ_0(1+βU_task)` | 柔度（顺从度），越大越软；刚度 K=1/κ |

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** GAUGE-RAS = (SE3B,SQ,TPU,RPU,BCC,IDE,BAP,CBS,CCC,RAS-WM‡)。(i) 实时流零学习写操作继承；(ii) **规范纪律**：协调动作必须声明 σ，禁止跨规范静默平均，左右手/镜像/换系是一等故障；(iii) **内力安全**：刚性闭链仅当 U_task(Σ_Z) ≤ τ_rel 且联合认证通过，否则顺从退避，‖w_int‖∞ ≤ w_max。

**定义 311（共享世界位姿信念 SE3B）** X 为两臂共享潜变量；y_i=h_i(X,T_{B_i}^W)+ε_i；后验 b=Σ_k w_k·MF(μ_k,Σ_k)（矩阵 Fisher/SE(3) 集中高斯）。共享潜变量 ⇒ Σ_LR≠0；换参考臂只是规范变换。

**定义 312–313（功能对称商与任务投影）** G_task={g∈G:A(Xg)=A(X)}，G_amb=G/G_task；只在 G_amb 上取模态熵。U_task 用任务关键方向最坏投影，不用 trace。

**定义 314（相对位姿协方差 RPU）** `Σ_Z = J_LΣ_LJ_L^T+J_RΣ_RJ_R^T+J_LΣ_LRJ_R^T+J_RΣ_LR^TJ_L^T`；`Γ` 判抵消/放大。Σ_LR 禁止置零。

**定义 315（跨臂闭环与可辨识性 BCC/IDE）** `r_chain=log(T̂_L^O(T̂_R^O)^{-1}T_cal)`；分解 `d_rel⊕d_cm`。无第三锚点时 d_cm 不可辨识（定理 20）；IDE 输出 `(d_rel,d_cm,anchor_available)`。

**定义 316（双臂主动探询 BAP）** 𝒜_info^B={稳定-观察, 换手重抓, 相对运动, 力/顺从探针}；`g*=argmax[VoI_B−c_phys−c_wrench−c_time−c_social]`，s.t. 联合 C-RAS-WM、内力上界、预算；≤0 退回 FLUID。接触可提升观测矩阵秩（定义 322），但需计入损伤风险。

**定义 317（顺从退避 CBS）** `e_Z=log(Z_actual^{-1}Z_cmd)`，`w_int=K_p e_Z+K_d ė_Z`；`κ_f=κ_0(1+βU_task)`，`K_f=1/κ_f`。U_task>τ_rel ⇒ leader–follower 限力，速度仍按 λ 收缩。

**定义 318（共谋共识 CCC）** 用 `rank_eff`、`s_cm=λ_max/tr` 与 `anchor_available` 替代「数源个数」；不满足则把相关证据降级为一个源，禁止投票凑数。

**定义 319–321（干扰/审计/证书）** `ℰ_GAUGE=ℰ_FLUID×ℰ_sym×ℰ_gauge×ℰ_chain`；VQAuditor-G 审计规范、对称商、交叉协方差、共谋、内力；J_GAUGE 并入上述字段，刚性闭链与绝对位姿结论分别受 U_task/锚点约束。

**定义 322–324（接触可观测/层级退化/群枚举）** 接触可提升 `O=[O_vision;O_contact(λ)]` 的秩；退化条件 D=(G_amb 平凡)∨单臂∨(Σ_LR=0∧不用 BCC)∨不接触，在 D 上逐指令回 FLUID；K=|G_amb^disc|≤24 枚举，连续部分解析，无需 DTW 聚类（引理 19）。

## 3. 关键算法伪代码

```python
# IP-264 SE3B：共享潜变量、双臂共读、保留交叉协方差
class SE3Belief:
    def update(self, obs_L, obs_R, prior, calib):
        comps = pose_posterior(obs_L, obs_R, self.sym_group, prior)
        Sigma_LR = cross_cov_from_shared_latent(comps, calib)
        return SE3Mixture(comps, Sigma_LR)

# IP-265/266 SQ + TPU：按功能对称折叠、按任务方向投影
def quotient_and_project(mix, affordance, task_dirs):
    g_task = symmetry_subgroup(mix.G, affordance)
    modes  = orbit_cosets(mix, g_task)                  # 可枚举、完备
    U_task = mixture_task_uncertainty(modes, task_dirs)
    return modes, U_task, g_task

# IP-267 RPU：相对协方差（含交叉项）
def relative_cov(mix):
    A_L, A_R = adjoint_jacobians(mix)
    return (A_L @ mix.Sigma_L @ A_L.T + A_R @ mix.Sigma_R @ A_R.T
            + A_L @ mix.Sigma_LR @ A_R.T + A_R @ mix.Sigma_LR.T @ A_L.T)

# IP-268/269 BCC + IDE：闭环只见相对漂移
def chain_check(mix, calib, anchors):
    r = log_se3(mix.T_L_O @ inv(mix.T_R_O) @ calib.T_RL)
    d_rel = project_relative(r)
    d_cm  = project_common(r, anchors) if anchors else None
    return r, d_rel, d_cm

# IP-270 BAP：双臂物理探询（无利可图即退 FLUID）
def choose_bimanual_probe(modes, U_task, budget, anchors):
    best = None
    for g in bimanual_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_joint(g): continue
        if wrench_risk(g, U_task) > w_max: continue
        score = (entropy(modes) - expected_entropy(modes, g)
                 - cost(g) - wrench_cost(g, U_task))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-271 CBS：不确定 -> 变软，不只是变慢
def compliance_schedule(U_task, lam):
    if U_task <= tau_rel: return "rigid", 0.0, lam
    kappa_f = kappa0 * (1.0 + beta * U_task)
    lam     = max(lam, lam_floor(U_task))
    return "leader_follower", kappa_f, lam

# IP-272 CCC：相关证据 != 独立证据
def consensus_ok(evidence, k_req, anchor_available):
    R = estimate_residual_correlation(evidence)
    return effective_rank(R) >= k_req and common_mode_susceptibility(R) <= s_max

# IP-276 主闭环：R69 FLUID + 几何/共享世界层
def GAUGE_RAS_round(M, obs):
    mix = M.se3b.update(obs.L, obs.R, M.prior_O, M.calib)
    modes, U_task, g_task = quotient_and_project(mix, M.affordance, M.task_dirs)
    Sigma_rel = relative_cov(mix)
    r, d_rel, d_cm = chain_check(mix, M.calib, M.anchors)
    slow = (norm(d_rel) > tau_chain) and (M.last_r_res < tau_res)
    g = (choose_bimanual_probe(modes, U_task, M.budget, M.anchors)
         if (U_task > tau_pose and not slow) else None)
    if g is not None and consensus_ok(M.evidence, 2, bool(M.anchors)):
        mix, modes, U_task = execute_probe_and_refit(M, g)
        Sigma_rel = relative_cov(mix)
    mode = select_mode(modes, U_task, M.gauge_section)
    state, kappa, lam = compliance_schedule(U_task, M.efs.risk_scale(...))
    if state != "rigid":
        return M.cbs.leader_follower(mode, kappa_f=kappa, lam=lam, F_max=w_max)
    A  = M.ach.propose(mode.a, H=M.vista.H)
    k  = M.c_ras_wm.certified_joint_prefix(A, ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_g.submit_async(g, g_task, U_task, Sigma_rel, r, kappa,
                         anchor_available=bool(M.anchors))
    return k, lam, mode, (U_task, Sigma_rel, state)
```

## 4. 推导

**引理 19（功能对称商压缩歧义）** 似然 G-不变、G_task 保 affordance 不变时，任务相关后验只依赖 G_amb 陪集；H(M|o) ≤ log|G_amb^disc|，连续对称不产生离散模态。G_task=G ⇒ U_epi≡0；G_task={e} ⇒ 全部几何对称成为任务相关歧义。系：按群枚举给出可证明完备的模态，避免 R69 聚类的「假模态/无限模态」两类错。

**引理 20（相对位姿抵消/放大与虚假共识）** 共享潜变量使 Σ_LR 在共同方向正相关，则相对误差抵消，Γ<0，但绝对误差不变。故 `(r_chain≈0, Γ<0)` 只能说明「两臂对同一个错误一致」，不能说明位姿正确；反相关时 Γ>0，闭链更易产生内力。

**引理 21（顺从耗散）** `w_int=K_f e_Z+K_d ė_Z`，`K_f=1/[κ_0(1+βU_task)]`，`e_Z~O(U_task)` ⇒ `‖w_int‖ → C/(κ_0β)`，与 U_task 解耦；代价是精度随 κ_f 变差。系：刚性双臂里纯 λ 收缩无法给出内力上界，κ 是必需的第二个保守轴。

**引理 22（相关证据共识失效）** 共同模相关 ρ_c→1 时，多数投票错误率 →δ_p 且不随 k 下降；k 增大只放大错误置信度。故必须用 rank_eff/s_cm 修正 R69 的 k-一致上界。

**定理 18（GAUGE 严格包含 FLUID）** 退化条件 D 下 SE3B 与 R69 条件编码同后验，BAP/CBS/CCC 旁路，逐指令相同；一般情况下仅额外增加内力上界与规范一致性，不放松 λ 下界。CALM ⊂ FLUID ⊂ GAUGE。

**定理 19（双臂安全与无突变）** 联合认证 + 刚性门控 U_task≤τ_rel + 顺从限力 ⇒ 内力有界、控制连续；探询失败/共谋/无锚点时单调退化为 leader–follower 或 R69，λ、κ 单调不降（更软），无刚度突变；显式规范声明禁止隐性换系，无坐标跳变；R68 定理 15 保持。

**定理 20（共同模不可辨识，负结果）** 闭环只观测 `r_chain=d_L−d_R`，观测算子零空间为共同模子空间 `{(d,d)}`；无第三锚点/环境接触时，共同外参漂移与物体真实运动不可区分。故 `anchor_available=False` 时 J_GAUGE 不得签发「绝对位姿正确」，只能签发「相对一致」。

## 7. 本轮最大风险

**一句话**：GAUGE-RAS 的安全论证押在「正确识别任务相关对称群」与「跨臂一致不是共谋」上——**若把几何对称误当功能对称（或反之），系统会在错误规范里锁定一个等价但任务错误的姿态；若两臂共享同一先验/外参/训练分布，闭环会给出结构性虚假一致，把共同模错误盖上「已对齐」的章**；顺从只能把错误变成有界内力，不能把它变成正确——**两个人都看错成一样，比一个人看不见更危险**。

**次级风险与缓解**：规范漂移/左右手混淆（定义 310-ii + ℰ_gauge + E309）；共谋共识（CCC 的 rank_eff/s_cm + 第三锚点 + 引理 22 + E308）；内力/探询损伤（CBS + 联合认证 + 力上界 + E306）；SE(3) 协方差误建模（局部重线性化 + 测地残差 + E303）；共同模不可辨识（定理 20 硬边界，J_GAUGE 显式记录 anchor_available=False，禁止签发绝对位姿正确）。
