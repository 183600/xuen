# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC，IP-153~160；灵感循环第 7 轮；本轮灵感：「多机协同」×「人机交互」）

> 第 60 轮把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭合成 SERC，并用 SIC 三元组、CESC 联合决策、PCE++++ 四维认知预算把单机认知-执行闭环做严。但整个闭环仍建立在**四个单数假设**上：
> 1. **单场景信念**：SERC 假设只有一个场景后验 π_scene。多机协同时 N 个机器人各有一份场景信念，简单相乘会把「两台机器看见同一张桌子」当作两份独立证据——**相关证据被重复计数（double counting）**，后验方差虚假收缩，过度自信。
> 2. **单阻抗权威**：CESC 的 K_safe 是单机阻抗。多机刚性共持同一物体时，各机阻抗在物体上耦合成**闭链阻抗**，并产生**不驱动运动的内部力**；单机 K_safe 的并集既不等于联合安全，也无法约束内部力，轻则物体被夹坏，重则两机互相「顶牛」。
> 3. **单意图源 / 单权威**：CIEC 假设人的意图被正确理解且人始终是可靠裁判。真实 HRI 中人的**信任**是时变隐状态，会过度信任（overtrust，该接管时不接管）或信任不足（undertrust，绕过安全机制），而**权限**不能是单点——机器人不能把「人类命令」当作可以穿越安全包络的通行证。
> 4. **单证据日志**：EPIR 只保证单机 EV-exec 的因果顺序。多机协同时证据是分布的，且可能有掉队/故障/撒谎的节点；把「转发来的证据」当作「亲历证据」会让**共识放大单点错误**。
> 本轮的核心论点是：**多机协同不是把单机闭环复制 N 份，而是在「信念、阻抗、权限、证据」四个层面引入「联合算子」，且每个联合算子都必须显式处理「相关性 / 内部力 / 信任 / 故障」这四种耦合。**

## 0. 直觉与动机

**灵感 1（多机协同 → 相关感知的协同场景融合 CSBF）**
直觉：三个机器人围着同一张桌子看，它们看到的不是三张桌子，而是「同一张桌子的三个视角」。若把三份后验直接相乘，等于假装做了三次独立实验，后验会过度自信；一旦三份视角同时被同一块反光/阴影欺骗，**过度自信的错误信念会被整队共享**，形成共模失效。正确姿势是用**协方差交集（Covariance Intersection, CI）**做一致性融合：无论各机证据如何相关，融合结果都保持一致性（不会比真实更自信）；再叠加一个**冲突门控**：当两机场景后验的冲突质量超过阈值（用 Bhattacharyya 系数度量分歧），拒绝融合、退回接触探测，而不是强行折中。

**灵感 2（多机协同 → 内部力解耦的协作阻抗契约 CIC）**
直觉：两台机械臂刚性夹住一个箱子，每台各执行自己的 K_safe。问题在于：物体位移只由**合力矩**决定，而两臂施加的力中有一大部分落在**抓取矩阵的零空间（内部力）**里，只把箱子往中间挤，不产生任何运动。因此多机安全必须在**物体扳手空间**上编译，而不是在各自关节空间取并集；内部力必须单独用一个**内部阻抗 K_int** 来约束。关键洞见：**单机 K_safe 的联合可行域 ≠ 联合 K_safe**；正确的对象是「满足物体级阻抗 + 内部力上界 + 各机不饱和」的联合可行集，可行集为空时应降级抓取而非退回并集。

**灵感 3（人机交互 → 信任校准与共享权限 HTC + SAA）**
直觉：人对机器的信任像弹簧的阻尼——信任过高时人「松手」，系统一旦出错无人兜底；信任过低时人频繁接管或干脆绕过，安全机制形同虚设。机器应维护一个**信任后验**（Beta 分布），用接管率、响应时延、命令频率等行为代理来更新；并把「权限」α_auth 设计成**连续量**而非开关：α 随校准后的信任上升，但被机器人自身置信度（第 60 轮 SIC）和**硬安全包络**双重封顶。关键洞见：**人类命令不能穿越安全包络**，但机器人也不能用「安全」为名无限保守——过度保守会摧毁信任，反而诱发危险绕过（见灵感 5）。

**灵感 4（合流 → 混合倡议联盟闭环 MICL）**
直觉：把「人」当作联盟中的一个特殊节点，把「多机」当作可动态分工的执行体，形成混合倡议闭环：**人类意图 → 协同场景信念（CSBF）→ 协作阻抗契约（CIC）→ 共享权限仲裁（SAA）→ 分布式执行 → 分布式证据共识（DEC）→ 信任更新 → 角色重分配**。角色（leader / follower / observer / supervisor）不是固定的，而是按能力、邻近度、剩余预算和信任动态重排。这是第 60 轮 SERC 从「单机认知闭环」到「联盟认知闭环」的升维。

**灵感 5（多机协同 × 人机交互 → 社会-物理风险耦合 SPRC）**
直觉：只最小化物理风险会掉进「安全剧场」陷阱：机器人越保守，人越不信任、越容易绕过，最终实际物理风险反而上升。因此目标函数必须把**信任侵蚀 / 绕过风险**计入总风险，但**安全包络仍是硬约束**：在包络之上优化耦合风险，在包络之内绝不妥协。关键洞见：**安全是硬下界，信任是软目标**，二者不能混为一谈，也不能只优化其一。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（相关感知协同场景融合 CSBF）** 设 N 个机器人各自维护场景信念 `b_i = N(μ_i, Σ_i)`（阻抗空间）或类别后验 `p_i(z)`。融合算子 `⊕_CI`：
- **CI 融合（连续）**：`Σ_f^{-1} = ω Σ_1^{-1} + (1-ω) Σ_2^{-1}`，`μ_f = Σ_f(ω Σ_1^{-1} μ_1 + (1-ω) Σ_2^{-1} μ_2)`，`ω* = argmin_ω det(Σ_f(ω))`
- **一致性**：若每个 `b_i` 一致（真值落在其置信椭球内），则 `b_f` 对任意未知相关结构仍一致——CI 不假设独立。
- **类别融合（log-linear pooling）**：`p_f(z) ∝ ∏_i p_i(z)^{w_i}`，约束 `Σ_i w_i ≤ 1`；均匀取 `w_i = 1/N`。`Σ w_i > 1` 视为「重复计数」并禁止。
- **冲突门控**：`K_conf = max_{i≠j} (1 − Σ_z sqrt(p_i(z)·p_j(z)))`（1 − Bhattacharyya 系数）；若 `K_conf > τ_conf`，令 `b_f = ⊥`（融合失败），回退到第 60 轮单机 SSM 的接触探测，**禁止**把冲突后验下发给执行层。
- **有效独立证据数**：`n_eff = 1 / Σ_i w_i^2`（Kish 有效样本量），用于估计「名义 N 机」中真正独立的信息量；`n_eff < N` 时证据链只按 `n_eff` 计权。

**定义 162（内部力解耦协作阻抗契约 CIC）** 设 n 个机器人刚性抓取同一物体，抓取矩阵 `G_i`（`ẋ_i = G_i V_o`），堆叠 `G = [G_1; …; G_n]`，末端力 `f = [f_1; …; f_n]`，物体扳手 `w_o = G^T f`。
- **内部力子空间**：`F_int = null(G^T) = { f : G^T f = 0 }`；`f = f_motion + f_int`，`f_motion = G^{T†} w_o`。
- **物体级阻抗**：`K_o = Σ_i G_i^T K_i G_i`（刚性并行耦合下的刚度叠加）；契约要求 `K_o ∈ K_safe^object`（由 EEIS 在物体扳手空间编译）。
- **内部阻抗**：`f_int = −K_int (x_int − x_int^ref) − D_int ẋ_int`，要求 `||f_int||_∞ ≤ F_int^max`（防夹坏 / 防顶牛）。
- **联合编译**：`CIC.compile({K_i}) = argmin Σ_i ||K_i − K_i^0||²_F` s.t. `K_o ∈ K_safe^object`，`||f_int|| ≤ F_int^max`，`f_i ∈ F_range(e_i)`。若可行集为空 ⇒ 返回 `DEGRADE_GRASP`（松开 / 改抓取 / 求助人类），**绝不**退回各自 K_safe 并集。
- **契约证书**：`Cert_cic = (K_o, κ_G, F_int^max, {K_i}, 可行性证明)`，`κ_G = cond(G)` 度量抓取几何的病态程度。

**定义 163（人机信任校准 HTC）** 信任 `T_t ∈ [0,1]` 为隐状态，机器人维护 Beta 后验 `b_t(T)=Beta(a_t,b_t)`。
- **行为代理**：接管/覆盖事件 `o_t∈{0,1}`、响应时延 `ℓ_t`、命令频率 `c_t`、接近距离 `d_t`；观测模型 `P(o_t|T_t)` 单调递减于 T（越不信任越常接管）。
- **更新（带遗忘）**：`a_{t+1} = η a_t + o_t`，`b_{t+1} = η b_t + (1−o_t)`，`η<1` 允许信任漂移；`T̂_t = a_t/(a_t+b_t)`。
- **恰当信任基准**：`T*_t = g(reliability_t)`，`reliability_t` 由近期任务成功/安全事件估计。
- **校准误差**：`e_cal = T̂_t − T*_t`；`e_cal > τ_over` 为**过度信任**（危险，代价权重 `λ_over`），`e_cal < −τ_under` 为**信任不足**（代价 `λ_under`），且 `λ_over > λ_under`（不对称）。
- **可读性约束**：机器人轨迹 `ξ` 的可读性 `L(ξ)=E[log P(G|ξ)]`（观测者由轨迹反推目标 G 的似然），要求 `L(ξ) ≥ L_min`，以维持可预测性、抑制信任漂移。

**定义 164（共享权限仲裁 SAA）** 权限 `α_auth ∈ [0,1]`（0=人类全权，1=机器全自主），动作 `a_R`（机器提议）、`a_H`（人类提议）。
- **硬安全包络**：`S_safe` 为前向不变集；`a ∉ S_safe` 的动作对任何 `α_auth` 均不可执行（**人类命令亦不可穿越**）。
- **不可逆度**：`ρ(a)∈[0,1]`；所需权限阈值 `α_req(a) = α_0 + (1−α_0)·ρ(a)`（越不可逆越需要人类确认）。
- **仲裁规则**：
```
if a_R ∉ S_safe: reject_robot(); explain()
if a_H ∉ S_safe: refuse_human(); explain()          # 拒绝穿越安全包络
if ρ(a_H) > ρ_max ∧ α_auth < α_req(a_H): request_confirm()
else: a* = proj_{S_safe}( blend(a_R, a_H, α_auth) )  # α=0→a_H, α=1→a_R
```
- **最小干预原则**：当人类动作已在 `S_safe ∩ S_competent` 内且风险不增，`α_auth` 下调，机器人不抢权。
- **权限更新**：`α_auth ← clip(α_auth + μ·e_cal·conf_SIC, α_min, α_max)`，`conf_SIC` 为第 60 轮 SIC 置信度；**权限永远不能越过 `α_max<1` 与硬包络**。

**定义 165（混合倡议联盟闭环 MICL）** 联盟 `A = R ∪ {h}`（R 为机器人集合，h 为人类）。算子 `MICL(A, task, intent_h, Δf_req)`：
```
① CSBF: b_scene ← ⊕_CI{b_i}; if b_scene=⊥ → 接触探测回退
② CIC:  {K_i} ← CIC.compile(K_safe^object(b_scene), Δf_req)
③ HTC:  b(T) ← update(behavior_proxies); e_cal ← T̂ − T*
④ SAA:  α_auth ← arbitrate(conf_SIC, e_cal); a* ← shield(a_R, a_H, S_safe)
⑤ Role: σ ← assign_roles(capability, proximity, budget, trust)
⑥ Exec: distributed_impedance_control({K_i}, a*)
⑦ DEC:  EV_team ← evidence_consensus({EV-exec_i}); 冲突/掉队 → 降权
⑧ Trust: b(T) ← update(outcome); explain_if(refused/overrode)
⑨ Budget: 扣减 B_comm/B_trust/B_team; 任一耗尽 → 相应降级
⑩ Return: (b_scene, {K_i}, a*, EV_team, Cert_cic, b(T), σ)
```

**定义 166（分布式证据共识 DEC）** 每机 EPIR 扩展为 `S_i = (S_shadow_i, VC_i, DAG_i)`。
- **向量时钟**：`VC_i[j]` 为机器人 i 已知的 j 的事件计数；`e₁→e₂ ⇔ VC(e₁)<VC(e₂)`（因果先于）。
- **Merkle DAG**：每条 EV-exec 记录 `(timestamp, seq, VC, hash, prev_hashes)`，`prev_hashes` 指向因果前驱，形成可验证 DAG。
- **亲历优先**：证据分「亲历（local shadow）」与「转发（gossip）」两级；**转发证据不得单独作为安全关键断言的依据**。
- **法定人数**：安全关键断言（如「物体已夹稳」「场景已接地」）需 `q` 个**亲历**机器人佐证。取 `n ≥ 3f+1`、`q = 2f+1`（最多 f 个故障/撒谎节点）；任意两个 quorum 至少交于 `f+1` 个节点，其中至少一个诚实，故两条冲突的安全断言不可能同时获得法定人数（quorum intersection）。
- **通信预算**：gossip 轮数受 `B_comm` 限制；`B_comm` 耗尽 ⇒ 只保留亲历证据，安全断言降级为「待人工确认」。

**定义 167（社会-物理风险耦合 SPRC）** 总风险
```
R_total(a) = R_phys(a) + λ_soc · [ R_trust(e_cal) + R_bypass(T̂, a) ]
```
- `R_phys`：物理碰撞 / 过力 / 失稳风险（硬约束 `S_safe` 内）。
- `R_trust(e_cal)`：过度 / 不足信任的代价（不对称）。
- `R_bypass(T̂,a)`：人因不信任而绕过安全机制的期望风险，随 `T̂` 下降而上升。
- **安全地板**：`a ∈ S_safe` 为硬约束；SPRC 只在 `S_safe` 内优化，**不允许**用「提升信任」为理由放宽物理安全。
- **反安全剧场**：若 `∂R_total/∂conservatism > 0`（过度保守使总风险上升），则按耦合风险选择更主动但仍在包络内的行为。

**定义 168（联盟预算 PCE+++++）** `B_coal = (B_scene, B_intent, B_ros, B_exec, B_comm, B_trust, B_team)`。
- `B_comm = (Gossip_rounds, Quorum_messages, DAG_sync_bw)`
- `B_trust = (Explanation_budget, Proxy_sampling_rate, Calibration_window)`
- `B_team = (Role_switch_limit, Consensus_timeout, Reconfig_cost)`
- **降级链（可证回到第 60 轮安全基线）**：`B_comm` 耗尽 ⇒ 单机 EPIR + 人工确认；`B_trust` 耗尽 ⇒ 固定保守权限 `α=α_min`；`B_team` 耗尽 ⇒ 冻结角色、退回单机 SERC；任一认知预算耗尽 ⇒ 第 60 轮降级。

### IP-161 CSBF（协同场景融合）

```python
def csbf_fuse(beliefs):
    # beliefs: [(mu_i, Sigma_i, w_i)] 或 类别后验列表
    if categorical(beliefs):
        K_conf = max(1.0 - bhattacharyya(bi.p, bj.p)
                     for bi, bj in combinations(beliefs, 2))
        if K_conf > TAU_CONF:
            return None                      # 融合失败，回退接触探测
        return loglinear_pool([b.p for b in beliefs], [b.w for b in beliefs])

    # 连续：Covariance Intersection 两两融合
    mu, Sigma = beliefs[0].mu, beliefs[0].Sigma
    for b in beliefs[1:]:
        w = argmin_det(lambda w: ci_cov(Sigma, b.Sigma, w))
        Sigma = inv(w * inv(Sigma) + (1 - w) * inv(b.Sigma))
        mu = Sigma @ (w * inv(Sigma) @ mu + (1 - w) * inv(b.Sigma) @ b.mu)
    return Gaussian(mu, Sigma)

def effective_n(weights):
    return 1.0 / sum(w * w for w in weights)   # n_eff <= N
```

### IP-162 CIC（协作阻抗契约）

```python
def compile_cooperative_impedance(G_list, K_safe_object, F_int_max, K0_list):
    G = vstack(G_list)
    P_int = null_space(G.T)                    # 内部力子空间
    def objective(Ks):
        Ko = sum(Gi.T @ Ki @ Gi for Gi, Ki in zip(G_list, Ks))
        f  = force_of(Ks, G_list)
        return norm(Ko - K_safe_object) + LAMBDA_INT * norm(P_int.T @ f, inf)
    cons = [
        {'type': 'ineq',
         'fun': lambda Ks: F_int_max - norm(P_int.T @ force_of(Ks, G_list), inf)},
        {'type': 'ineq', 'fun': lambda Ks: actuator_margin(Ks, G_list)},
    ]
    res = minimize(objective, x0=K0_list, constraints=cons)
    if not res.success:
        return DEGRADE_GRASP                   # 绝不退回各机 K_safe 并集
    Ko = sum(Gi.T @ Ki @ Gi for Gi, Ki in zip(G_list, res.x))
    return Contract(Ks=res.x, Ko=Ko, kappa_G=cond(G))
```

### IP-163/164 HTC + SAA（信任校准与共享权限）

```python
class TrustAuthority:
    def __init__(self, a=2.0, b=2.0, alpha_min=0.1, alpha_max=0.9):
        self.a, self.b = a, b
        self.alpha = 0.5
        self.alpha_min, self.alpha_max = alpha_min, alpha_max

    def update_trust(self, override, reliability, eta=0.98):
        self.a = eta * self.a + (1.0 if override else 0.0)
        self.b = eta * self.b + (0.0 if override else 1.0)
        T_hat  = self.a / (self.a + self.b)
        T_star = reliability
        return T_hat, T_hat - T_star           # e_cal

    def arbitrate(self, a_R, a_H, conf_SIC, e_cal, rho, rho_max):
        if not in_safe_envelope(a_R):
            return REFUSE_ROBOT
        if not in_safe_envelope(a_H):
            return REFUSE_HUMAN                # 人类也不能穿越安全包络
        self.alpha = clip(self.alpha + MU * e_cal * conf_SIC,
                          self.alpha_min, self.alpha_max)
        if rho > rho_max and self.alpha < alpha_req(rho):
            return REQUEST_CONFIRM
        return project_safe(blend(a_R, a_H, self.alpha))
```

### IP-166 DEC（分布式证据共识）

```python
def evidence_consensus(ev_by_robot, n, f, budget):
    q = 2 * f + 1                              # n >= 3f+1
    dag = build_merkle_dag(ev_by_robot)        # VC + prev_hashes
    if not causal_consistent(dag):
        return DEC_INCONSISTENT
    claims = collect_safety_claims(dag)
    for claim in claims:
        witnesses = [i for i in ev_by_robot
                     if claim.hash in ev_by_robot[i].shadow]   # 只认亲历
        if len(witnesses) >= q and budget.consume(len(witnesses)):
            claim.certified = True
        else:
            claim.certified = False            # 转人工确认
    return dag, claims
```

```python
def mixed_initiative_coalition_loop(A, task, intent_h, delta_f_req):
    b_scene = csbf_fuse([r.scene_belief for r in A.robots])
    if b_scene is None:
```

```python
def csbf_fuse(beliefs):
    if categorical(beliefs):
        K_conf = max(1.0 - bhattacharyya(bi.p, bj.p)
                     for bi, bj in combinations(beliefs, 2))
        if K_conf > TAU_CONF:
            return None                      # 融合失败，回退接触探测
        return loglinear_pool([b.p for b in beliefs], [b.w for b in beliefs])

    mu, Sigma = beliefs[0].mu, beliefs[0].Sigma
    for b in beliefs[1:]:
        w = argmin_det(lambda w: ci_cov(Sigma, b.Sigma, w))
        Sigma = inv(w * inv(Sigma) + (1 - w) * inv(b.Sigma))
        mu = Sigma @ (w * inv(Sigma) @ mu + (1 - w) * inv(b.Sigma) @ b.mu)
    return Gaussian(mu, Sigma)

def effective_n(weights):
    return 1.0 / sum(w * w for w in weights)   # n_eff <= N
```

### IP-162 CIC（协作阻抗契约）

```python
def compile_cooperative_impedance(G_list, K_safe_object, F_int_max, K0_list):
    G = vstack(G_list)
    P_int = null_space(G.T)                    # 内部力子空间
    def objective(Ks):
        Ko = sum(Gi.T @ Ki @ Gi for Gi, Ki in zip(G_list, Ks))
        f  = force_of(Ks, G_list)
        return norm(Ko - K_safe_object) + LAMBDA_INT * norm(P_int.T @ f, inf)
    cons = [
        {'type': 'ineq',
         'fun': lambda Ks: F_int_max - norm(P_int.T @ force_of(Ks, G_list), inf)},
        {'type': 'ineq', 'fun': lambda Ks: actuator_margin(Ks, G_list)},
    ]
    res = minimize(objective, x0=K0_list, constraints=cons)
    if not res.success:
        return DEGRADE_GRASP                   # 绝不退回各机 K_safe 并集
    Ko = sum(Gi.T @ Ki @ Gi for Gi, Ki in zip(G_list, res.x))
    return Contract(Ks=res.x, Ko=Ko, kappa_G=cond(G))
```

```python
class TrustAuthority:
    def __init__(self, a=2.0, b=2.0, alpha_min=0.1, alpha_max=0.9):
        self.a, self.b = a, b
        self.alpha = 0.5
        self.alpha_min, self.alpha_max = alpha_min, alpha_max

    def update_trust(self, override, reliability, eta=0.98):
        self.a = eta * self.a + (1.0 if override else 0.0)
        self.b = eta * self.b + (0.0 if override else 1.0)
        T_hat  = self.a / (self.a + self.b)
        T_star = reliability
        return T_hat, T_hat - T_star           # e_cal

    def arbitrate(self, a_R, a_H, conf_SIC, e_cal, rho, rho_max):
        if not in_safe_envelope(a_R):
            return REFUSE_ROBOT
        if not in_safe_envelope(a_H):
            return REFUSE_HUMAN                # 人类也不能穿越安全包络
        self.alpha = clip(self.alpha + MU * e_cal * conf_SIC,
                          self.alpha_min, self.alpha_max)
        if rho > rho_max and self.alpha < alpha_req(rho):
            return REQUEST_CONFIRM
        return project_safe(blend(a_R, a_H, self.alpha))
```
