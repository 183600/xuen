## 1. 两个灵感的第一性原理

### 灵感 1 ·「对话管理」→ 执行栈本来就是一个「对话系统」，只是缺了对话管理的文法

**直觉**：把一次抓放 episode 当成一场对话——策略「说」出一个 chunk，世界「回」一帧观测，到点断言是「我们是否达成了共识（grounding）」，介入是「修复（repair）」，探测是「澄清提问（clarification）」，人为干扰是「打断（barge-in）」，松手/插入是「承诺（commit）」这一不可撤回的言语行为。第 3 轮已经把这些零件都摆出来了（IP-13 状态、IP-15 干扰、IP-02 介入、IP-09 断言、IP-14 探测），但它们是**按模块罗列的**，缺的正是对话管理提供的四样形式对象：**意图层信念、动作代数、发言权/轮次、修复文法**。把四者补齐，这些散件就变成一个可推理、可归因、可测的对话控制器。

- **信念状态有两层，过去只做了几何那层**：IP-13 的 `Σ` 是「物体在哪」的几何协方差；对话管理提醒我们还有一层「**世界处在哪个子目标、是否接受了我上一个动作**」——这是**任务/意图信念**（U19）。纯几何状态无法表达「我到了抓取位姿，但我不确定这一步是‘对齐’还是‘抓取’」，而错子目标的 commit 是当前矩阵里最难归因的一类失败。补上 `β_t(s)` 后，「我以为在 release、其实还在 transport」这种失败第一次变成可检测、可扣分的显式事件。
- **动作代数统一了词汇表**：定义对话动作 `A = {REQUEST, CONFIRM, CLARIFY, REPAIR, YIELD, COMMIT}`（U20）。IP-01 的 SkillToken 就是这个代数的「词库」，chunk 是动作的「发音实现」。统一之后，IP-06 的失败矩阵可以多出一根**动作类型轴**——失败到底是「REQUEST 没落地」还是「COMMIT 太早」，这是模块罗列永远给不出的诊断粒度。
- **Grounding = 断言，且承诺前必须先 grounding**：U17 卡方断言就是 grounding test；对话管理补上的规则是「**不可逆动作之前要有 read-back**」（P15 / L15）。release、insert、最终放置是「不可撤回的言语行为」，一旦执行就无法靠重试无痛撤销——这类动作前加一次低成本确认，是经过对话系统几十年验证的工程习惯。
- **修复文法按「每次成功成本」排序，而不是按「严重程度」排序**：IP-02 的介入家族（重抓/重对齐/换原语/重定位/换策略）过去凭直觉排优先级；L14 证明在一阶近似下，修复档位应按 `c/q`（单次成本 ÷ 成功率）升序尝试，且任何 `c/q` 高于「重启」的档位根本不该进白名单。这把「介入家族」从经验清单升级成可计算的文法。
- **发言权与打断（barge-in）**：IP-15 的四类干扰映射本质是「谁持有发言权」的切换（U21）。人类接触 → 发言权归人，机器人必须 `YIELD` 而非抢话；遮挡 → 世界暂时「沉默」，`HOLD` 等回话；目标位移 → 对话内容变了，`RELOCALIZE`。把「保持而非重启」（P11）重述为「**不抢发言权、不在对方说话时自说自话**」，原则就有了对话理论依据，也为「让步」动作的幅度上限提供了约束。
- **POMDP 对话策略**：给定任务信念 `β_t`，下一步选哪个动作是一个小规模 POMDP；动作空间只有 6 类、状态是子目标序，足以用查表/小网络解（IP-16），无需重训大模型——这是把「近零训练成本的规则协议」升级为「近零训练成本的最优规则」。

**策略含义**：第 3 轮把「现在在哪、目标是谁、卡没卡住」交给状态层；本轮把「**现在该说哪句话、对方听没听懂、听岔了怎么修**」交给交互层。状态层解决「信什么」，交互层解决「据此如何开口与何时闭嘴」。

### 灵感 2 ·「用户测试」→ 代理评测是「测量仪器」，必须先校准、再报告它分辨得了多大的差异

**直觉**：HCI 里没人会相信一个只在开发者自己机器上跑过的新设计——要拿**有代表性的用户**、**盲测**、**足够样本量**、并测**评分者一致性**。我们的 IP-06 代理评测就是一台「便宜的测量仪器」，它测的潜在量与官方榜单（「昂贵的仪器」）相同。用户测试的纪律说：先校准这台便宜仪器（斜率/截距），估计它的噪声（ICC/κ/SEM），然后**只相信大于最小可检测变化（MDC）的差异**。它同时提醒：测试集必须代表性抽样、评分必须盲、结论必须预注册。

- **要校准，不只是求相关**：`corr(proxy, true)` 高完全可能是「整体偏大 + 斜率≠1」；必须回归 `S_t = α + β·S_p + ε`，要求 `β→1, α→0`，并用 Bland–Altman 看一致性界限。第 1–3 轮反复用「与真机 |r| ≥ 0.5」当判据——**这只保证了排序，不保证幅度**，而我们恰恰按幅度（+1.0/+2.0 分）做接受/拒绝决策（U22）。
- **可靠性要先于有效性**：同一配置重测两次（test–retest）得到 ICC；两名评分者对同一回放判成功/失败得到 Cohen's κ。若重测 ICC 低，任何「改进」都可能是复跑噪声——这是用户测试的第一课，我们至今没做。
- **功效/MDC 是硬约束**：对成功率，独立 N 个 episode 下两配置差的标准误约 `√(2p(1−p)/N)`，`MDC = z·√(2p(1−p)/N)`（L16）。代入 p=0.3、N=320（≈每任务 10 次），`MDC₉₅ ≈ 7.1 分`——**我们写下的「+1.0 / +2.0 分」验收线，在这台仪器上根本不可分辨**。要辨 2 分，独立设计需 ≈4034 episode；但若改用**同一随机种子的配对（within-subject）设计**，配对相关 ρ=0.8 时同功效只需 ≈807——这把「换度量」变成「换实验设计」，是零成本买统计功效。
- **盲测 + 预注册**：评测时隐藏配置身份；接受阈值在看到结果前写死。用户测试里「不盲评」是方法学错误，不是小事。
- **「有声思维」= 失败归因矩阵**：用户测试靠 think-aloud 找出可用性 bug；IP-06 的六因子×五轴矩阵就是机器版的 think-aloud，本轮再乘一根「动作类型轴」（来自灵感 1），定位「哪句话没说对」。
- **人为干扰轴 = 真人用户测试**：五个泛化轴里的「人为干扰」本质就是**真人用户与机器人交互**。合成干扰（第 3 轮 IP-15）只是预演；真正的验证是招募 k 名真人、按受控脚本干扰、用配对设计测恢复率（IP-18 / E638），并测评分者 κ。这是本轮把「用户测试」字面落地的地方。

**综合（两条灵感是一对偶）**：**在线对话**是快回路（episode 内，毫秒到秒级，控制问题）；**离线测量**是慢回路（跨 episode，小时到周级，验证问题）。前者决定「单局打得好不好」，后者决定「我们**知道**自己变好了没有」。二者共享同一套事件词汇（动作类型 / 失败因子），所以能互相喂数据：对话产生结构化失败标签 → 仪器测量这些标签的分布 → 反过来门控下一轮该修哪句话。**最大的系统性风险不再是某个模块不行，而是两条回路的接口（标签口径）对不上。**

## 2. 研究问题（新增 Q13–Q16，接第 1–3 轮 Q1–Q12）

- **Q13（对话动作策略的收益）**：把在线控制重述为 6 类对话动作 + 承诺前确认后，在步骤分约束下能否降低修复成本、提升综合分？哪种动作类型的失败占比最高？（E634/E639）
- **Q14（任务信念/意图跟踪）**：能否用子目标信念 `β_t(s)`（U19）把「错子目标 commit」这类失败检出并把成功率提高，且不引入新的单点故障？（E635）
- **Q15（代理仪器的校准与功效）**：代理评测相对官方榜单的校准斜率 β、截距 α、重测 ICC、评分者 κ 各是多少？在给定 N 与配对设计下，最小可检测分数差 MDC 是多少，`+1/+2 分`需要多大 N？（E636/E637）
- **Q16（真人干扰用户研究）**：真人受控干扰下，IP-15/IP-16 的打断-让步协议恢复率如何？合成→真人的迁移损失多大？多名评分者对「恢复成功」的 κ 是否 ≥0.6？（E638）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（对话即控制）**：在线每一个 chunk 都必须可命名成 6 类对话动作之一（U20），并附显式 grounding 条件；不存在「无标签动作」。动作类型同时是失败归因的强制字段。
- **P14（先校准再相信）**：任何代理评测的分数增量，在报告校准（β、α、ICC/κ）与功效（MDC）之前不得作为接受/拒绝依据；只有 `|Δ| > MDC` 且通过校准回归的增量才可入账。
- **P15（不可逆先确认）**：release / insert / final-place 等不可撤回动作之前，默认插入一次低成本确认（read-back / 近距离复核），除非 L15 的确认经济学判定不划算（任务相位白名单）。

## 4. 清单处置（深化 / 修剪 / 新增）

- **深化**：IP-06（从「相关」升级为「**校准 + 可靠性 + 功效**」的测量仪器，增加动作类型轴）；IP-15（重述为 IP-16 的「打断-发言权」子模块，编号保留不归档，避免编号断裂）；IP-13（新增意图层信念 U19，几何层不变）；IP-02（介入家族按 L14 的 `c/q` 排序并设修复深度上限）；IP-09（到点断言明确为「grounding 条件」）；IP-01（SkillToken = 动作代数的词库，增加动作类型标签）；IP-14（探测 = CLARIFY 动作，过 L13 记账）。
- **新增**：**IP-16 DialogueController（P1，交互层）**、**IP-17 MeasurementHarness（P0，测量平面；不引入模型，纯 harness 与统计）**、**IP-18 HumanInterferenceUserStudy（P1，真人用户研究）**。
- **修剪**：不再把轮次花在 WAF 抓取（F6）；「+1.0/+2.0 分」这类单点验收线统一改为「**相对基线的配对增量 + 是否过 MDC**」，未过 MDC 的只记为「方向性观察」，不记为「达标」。
- **MVP 不变**：IP-06 + IP-02 + IP-09 + IP-03 + 通用基线；**IP-17 作为 MVP 的「验收门」先行落地**（零算力，只写统计与盲测协议），否则后续所有 +N 分结论都不可信；IP-16 作为 MVP 后第一扩展（NPC 规则版，不训大模型）。
- **退化链更新**：新增 **Level-1.7：对话控制器不可用 → 退回第 3 轮的事件规则表（IP-15 原形态），动作仍可执行**；Level-1.6 继续有效。

## 5. 本轮最大风险

**把噪声当信号（测量过拟合）**：IP-17 若揭示代理仪器的 MDC 高达数分、且校准斜率 β≠1，那么我们第 1–3 轮所有「+1.0/+2.0 分」的验收线都可能落在噪声里，团队会持续优化一个**不迁移到官方榜单的代理幻影**——这比某个模块失败更危险，因为它让「我们变好了」这句话本身失真。对冲：①一切结论改配对设计 + 盲测 + 预注册；②报告 MDC 与校准区间，未过门槛只记方向性；③保留一个完全留出的「守门任务子集」只在最终验收时用（绝不参与调参）；④IP-16 上线前先用「规则版 NPC」做零训练 A/B，避免模型噪声混入统计。

**一句话总结本轮最大风险：我们最大的敌人不是对手，而是一台我们从未校准、却一直拿它做决策的体温计。**

在线数据流：观测 → 状态层（几何信念）→ 交互层（任务信念 + 选动作）→ 若 `floor=ROBOT` 则执行，若被人打断则 `YIELD` → grounding 断言 → 升级/修复/承诺。对话控制器失效 → Level-1.7 退化到第 3 轮规则表；状态层失效 → Level-1.6；两级退化互不依赖。

## 3. 新增 IP 详述

### IP-17 · MeasurementHarness 测量仪器（P0，新）

- **动机**：第 1–3 轮所有接受/拒绝都建立在「代理评测 +N 分」上，但从没测过这台仪器的**校准、可靠性、功效**。当官方榜单不可读（F2）时，仪器质量就是我们唯一能主动改善的「真相质量」。
- **与现有方案差异**：IP-06 原本是「造评测集 + 出相关」；IP-17 是「**给 IP-06 出具计量学体检报告**」。不训任何模型，纯统计 + 协议，与竞赛接口零耦合，合规绝对安全。
- **四个测量学动作**：
  1. **校准（calibration）**：用可得的真机子集回归 `S_t = α + β·S_p + ε`，报 β、α、残差 σ，并做 Bland–Altman。判据 `β∈[0.8,1.2]`、`|α|≤2 分`。
  2. **可靠性（reliability）**：同一配置复跑（test–retest）→ ICC；两名评分者看回放判成功/失败 → Cohen's κ。判据 `ICC≥0.8`、`κ≥0.6`。
  3. **功效（power）**：按 L16 报 MDC/MDD；给每个「+Δ 分」主张标注「在 N 下可分辨/不可分辨」。默认上**配对设计**（同任务同种子）以降低方差。
  4. **盲测与预注册**：配置身份对评分者隐去；接受阈值在看到结果前写死并落盘哈希。
- **落地步骤**：①采集现有回放日志与已跑配置的分差；②写 calibration/ICC/κ/power 四个函数与报告模板；③把「守门任务子集」划出并冻结（永不参与调参）；④接入 CI：未过校准或未过 MDC 的 Δ 自动降级为「方向性观察」。
- **风险**：真机子集太小 → 校准区间宽（如实报告，不假装显著）；复跑成本被低估 → 先用配对设计 + 便宜代理度量（progress score）降低方差。

### IP-16 · DialogueController 对话控制器（P1，新）

- **动机**：在线栈已有全部零件，但缺对话管理的四个形式对象（意图信念/动作代数/发言权/修复文法）。补齐后，失败第一次能按「哪句话说错」归因，修复首次有了可计算的排序。
- **与现有方案差异**：不是新模型，而是一个**规则优先、可被小策略替代的外壳**：给定 U19 任务信念，按 U20 选动作；修复按 L14 的 `c/q` 排序；承诺前按 L15 决定是否 CONFIRM；发言权非 ROBOT 时只许 YIELD/HOLD。
- **技术可行性**：高。动作空间 6 类、状态是子目标序，可用查表/BAMDP 小策略；先上「规则版 NPC」（零训练），验证动作代数与归因口径后再考虑学习版。
- **资源**：近零训练；复用 IP-13 检测与 IP-15 事件分类；新增仅一个 6×状态数的策略表与日志字段。
- **落地步骤**：①把现有 chunk 全量打上动作类型标签（离线，从 IP-06 阶段标注导出）；②实现 `β_t(s)` 子目标信念（转移=grounding 通过；观测似然=U17 统计量 + 干扰事件）；③实现修复文法（c/q 排序 + 深度上限）；④实现发言权状态机（复用 IP-15 四类映射）；⑤承诺前确认白名单（insert/release/final-place）；⑥零训练 A/B（E634）。
- **风险**：动作标签口径不统一 → 与 IP-17 的失败矩阵接口错位（首要工程风险，先对齐 schema）；确认动作吃步骤分 → L15 白名单 + 步骤预算审计；意图信念误判 → 低置信退回仅几何层（Level-1.7）。

### IP-18 · HumanInterferenceUserStudy 真人干扰用户研究（P1，新）

- **动机**：「人为干扰」是五泛化轴之一，且大概率全场最弱；合成干扰（第 3 轮）只是预演。用户测试的字面落地 = 真人按受控脚本干扰，配对测恢复，并测评分者一致性。
- **与现有方案差异**：IP-15 是「合成干扰下的协议」；IP-18 是「**用真人验证协议并测迁移损失**」。不训模型，只做实验设计与数据采集。
- **设计（within-subject）**：同一任务在「无干扰 / 合成干扰 / 真人干扰」三条件下各跑配对回合；干扰脚本四类（遮挡/目标位移/新增干扰物/接触），强度分级；成功/恢复由 2 名评分者独立盲判 → κ。
- **资源**：需真人时段（最大约束）；合成条件复用回放器，真人条件需现场或遥操作。
- **步骤**：①冻结干扰脚本与伦理/安全边界（接触类幅度上限）；②合成保真度前置检查（合成 vs 真人的干扰事件分布距离）；③招募 k≥5 人，配对采集；④报恢复率增益、迁移损失、κ；⑤若迁移损失 >30%，协议只保留最保守动作集（保持/让步）。
- **风险**：真人不可复现 → within-subject + 固定脚本 + 多评分者；样本小 → 报效应量与置信区间而非 p 值；安全 → 接触类仅限轻触且机器人先 YIELD。

## 5. 符号与定义（新增 U19–U23；U1–U18 沿用第 1–3 轮）

- **定义 U19（任务/意图信念）**：`β_t(s) = P(子目标 = s | 观测史)`，`s ∈ S` 为有序子目标/路标集。转移：当 grounding 断言（U17）通过时 `s→s+1`；观测似然由 U17 统计量与干扰事件（U18）给出；与几何状态 `(x̂, Σ)` 正交维护。区别于几何信念：它回答「现在在做哪一步」，而非「物体在哪」。
- **定义 U20（对话动作代数）**：`a_t ∈ A = {REQUEST(w), CONFIRM(g), CLARIFY(q), REPAIR(r), YIELD, COMMIT}`；每个 chunk 映射到唯一动作；`grounding(a)` 为动作「落地」的判据（REQUEST 用 U17，CONFIRM 用复核统计量，COMMIT 需 P15 前置）。一次对话即 `(β_0, a_0, o_0, β_1, …)`。
- **定义 U21（发言权/轮次）**：`floor ∈ {ROBOT, WORLD, HUMAN}`；`floor=HUMAN` 表示 barge-in，机器人只能 YIELD/HOLD；`floor=WORLD` 表示等待世界响应（遮挡/延迟）；仅 `floor=ROBOT` 时可发起 REQUEST/COMMIT。一个「轮次」= 机器人持有一组动作直到让出发言权。
- **定义 U22（测量仪器）**：`I_p: config → Ŝ_p`、`I_t: config → Ŝ_t`；校准 `(α, β, σ)` 满足 `Ŝ_t = α + β·Ŝ_p + ε`；可靠性 ICC、评分者一致性 κ；一台「可信仪器」需 `β∈[0.8,1.2]、|α|≤2、ICC≥0.8、κ≥0.6`。
- **定义 U23（最小可检测变化 MDC）**：`MDC = z_{1−γ/2}·√2·SEM`；成功率情形 `SEM=√(p(1−p)/N)`（独立）或配对时 `SEM=√(2p(1−p)(1−ρ)/N)`（ρ 为配对相关系数）。`|Δ|>MDC` 才记为「可分辨」。

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（修复文法的 c/q 排序）** 设某修复档位单次成本 `c`、单次成功率 `q`（独立重试），则一直重试到成功的期望成本 `C(q)=c/q`。若先试低档 `(c,q)`、失败一次后改试高档 `(c′,q′)`，期望成本 `C_esc = c + (1−q)·c′/q′`。比较：`C(q) − C_esc = (1−q)(c/q − c′/q′)`。故**升级到高档严格占优 ⇔ `c′/q′ < c/q`**——修复档位应按「每次成功成本」升序尝试，而不是按「严重程度」；且任何 `c/q` 高于「重启全程」的档位不应进入介入白名单（深度自然有界）。∎

**引理 L15（承诺前确认的盈亏平衡）** 设不可逆动作（COMMIT）基础错误率 `p_e`，错误一旦承诺的恢复成本 `c_fail`（远大于动作本身），确认动作成本 `c_c`、漏报（有错却判通过）率 `β`，检测到错误后的低成本修复成本 `c_r`。不确认期望成本 `c_commit + p_e·c_fail`；确认后 `c_c + c_commit + p_e(1−β)c_r + p_eβ·c_fail`。故**确认占优 ⇔ `p_e(1−β)(c_fail − c_r) > c_c`**。⇒ 确认只对 `p_e` 大、`c_fail` 大的不可逆相位（insert/release/final-place）划算；其余相位跳过确认以省步骤（与 L13 的探测白名单同构）。∎

**引理 L16（代理仪器的可检测差异）** 成功率真值 `p`、N 个独立 episode 下，两配置差的标准误 `SE=√(2p(1−p)/N)`，`MDC=z√(2p(1−p)/N)`。若用同任务同种子的配对设计且两臂结果相关 `ρ`，则 `SE_pair=√(2p(1−p)(1−ρ)/N)`，方差按 `(1−ρ)` 收缩。记校准斜率 `β`，代理增量映射到真实增量的额外误差约 `SEM_p/β`（`SEM_p=σ√(1−ICC)`）。**可操作判据**：主张 `Δ` 为真 ⇔ `|Δ| > max(MDC, z·SEM_p/β)` 且 `β∈[0.8,1.2]`。**代入（p=0.3，独立）**：`N=320 → MDC₉₅≈7.1 分`；要辨 `2 分`需 `N≈4034`；改配对 `ρ=0.8` 则同功效只需 `N≈807`。⇒ **「+1.0/+2.0 分」在旧口径下多数不可分辨；无效力膨胀的改进主张在统计上不成立**。∎
