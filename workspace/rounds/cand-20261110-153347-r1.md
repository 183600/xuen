# 第 47 轮（承接第 46 轮 v11；本轮灵感：移动底盘 × 机器人基础模型） · WholeBody-FM：移动底盘全身证书与基础模型计划接地的联合过程保证（四层架构 v12）

> 承接第 46 轮 v11 StepCert-IL。v11 用步骤分下界与 OOD 门控把安全从终态下沉到中间步，但隐含假设 H6：底盘静止且任务分解来自可信示教/规划器。UniBot 是移动操作平台，底盘运动是姿态证书失效的最大来源（定位漂移、轮滑、倾覆、禁区、移动能耗），而步骤分解若改用机器人基础模型（VLA/通用策略）可规模化获得长程计划与语言接地，却引入不可校准的语义幻觉。两个灵感词精确命中 H6：**移动底盘**把姿态证书从“臂端点盒”升级为“底盘⊕机械臂全身盒”，并要求“移动即重认证”；**机器人基础模型**把步骤分解从人工示教升级为语言驱动的计划先验，但只能当 proposal 不能当 trust root。二者耦合出新问题：**当基础模型给出“先导航到货架再抓取”的看似合理计划时，底盘运动既改变了可观测性又放大了语义接地错误，如何保证全身姿态证书与计划接地证书在移动-操作交错中同时 sound，而不是用未接地的子目标推进步骤、用漂移的底盘位姿静默放行碰撞/倾覆**。

## 0. 直觉与动机

**灵感 1（移动底盘 → 全身证书与“移动即重认证”）**
直觉：v11 的姿态盒只覆盖机械臂，把底盘当成世界坐标系里的一个不动点。真实移动操作里，底盘一动，机械臂证书的参考系就漂了：轮式里程计累计误差、地面打滑、悬挂俯仰都会让 `P^arm` 在世界系里的真实位置偏离标称。安全不能靠“臂证书没超时”来判断，必须把底盘位姿不确定性与臂端盒做 Minkowski 和，得到**全身证书** `P^W = P^base ⊕ P^arm`，并对禁区/障碍做 `P^W ∩ O = ∅` 检查、对倾覆做支撑多边形裕度检查。核心原则：**移动即重认证**——任何超过阈值的底盘位移/协方差增长都让旧臂证书作废，必须重新定位后才签发新的全身证书。

**灵感 2（机器人基础模型 → 计划先验，而非信任根）**
直觉：基础模型能把自然语言指令拆成“去货架→对准→抓杯→搬到桌上→放置”这样的长程计划，并提供子目标与可供性，省掉大量人工步骤标注；但它会幻觉：可能把“杯子”接地到旁边的瓶子，或在没有支撑面的地方规划放置。v11 的步骤分评论家保证的是“完成度下界”，前提是 `φ_k` 语义正确；基础模型破坏的正是这个前提。因此必须把基础模型输出当作**不可信先验**：计划只作为候选分解，每个子目标都要经独立接地器映射为几何谓词，再用**语义共形校准**给出“接地为真”的覆盖保证。计划合理性 ≠ 谓词真实性，二者必须分开认证。

**灵感 3（耦合 → 移动-操作交错与联合过程证书）**
直觉：底盘移动会同时改变三件事：观测量（视角/遮挡/深度退化）、几何参考（位姿漂移）、资源（行走功耗与时间占用步骤租约）。基础模型计划天然包含“先移动后操作”，于是步骤推进必须与底盘状态耦合：移动过程中冻结操作证书，关键步（抓取/放置）要求底盘静止驻留 `τ_dwell` 并完成重认证；若基础模型计划的下一步未被接地，则不得因为“看起来该走了”而推进。移动-操作交错调度器负责在三类租约（姿态、能量、步骤）与底盘租约之间做联合放行。

**耦合升级**：在 v11 四层架构上插入 **全身证书层（Whole-Body Cert Layer）** 与 **计划接地层（Plan Grounding Layer）**，形成 v12：根信任层增加底盘租约 `ℓ_b` 与接地证书 `G_t`；L1 几何层把 `ω_t` 增加底盘定位退化层并输出全身盒 `P^W`；L2 上下文层预测“即将移动/即将进入退化区”；L2.5 步级层接受基础模型候选分解但必须接地；L3 CAR 守卫全身盒、禁区与倾覆裕度；L4 DCL 采集底盘漂移与接地幻觉样本。基础模型仅在计划接地证书有效且全身证书 sound 时获得执行权。

## 1. 形式化定义（增量：定义 58–61）

**定义 58（底盘状态、定位不确定性与底盘租约）**
底盘状态 `b_t=(x,y,θ)`，定位协方差 `Σ_b(t)`，轮滑移率 `s_t`，倾覆裕度 `η_t`（质心投影到支撑多边形的最小距离）。底盘租约
`ℓ_b=(b_t, Σ_b, v_max, τ_b, O, ε_slip, η_min)`。
**底盘可行判据**：`tr(Σ_b)≤σ_max` 且 `s_t≤ε_slip` 且 `d(P^W,O)≥0` 且 `η_t≥η_min`，其中 `O` 为禁区/动态障碍集合。任一失效则所有依赖 `b_t` 的全身/步骤证书级联失效（fail-closed）。

**定义 59（全身姿态证书与移动即重认证）**
机械臂证书 `P^a_t`，底盘证书 `P^b_t={b: ‖b-b_t‖_{Σ_b}≤κ}`。全身证书为 Minkowski 和
`P^W_t = P^b_t ⊕ P^a_t = { X_b+X_a : X_b∈P^b_t, X_a∈P^a_t }`。
**全身 soundness**：
`P( X^W_t∈P^W_t | b_t, Σ_b, ω_t, m_t ) ≥ 1-α_p`。
**移动即重认证**：若 `‖b_t-b_{t^-}‖>δ_move` 或 `tr(Σ_b(t))-tr(Σ_b(t^-))>δ_Σ`，则 `P^a_t` 立即作废，必须在 `τ_re` 内重定位并重签 `P^W_t`；作废期间 CAR 只允许停机保持。`ω_t` 新增底盘定位退化层 `ω_base`（弱纹理地面、长走廊、动态遮挡）。

**定义 60（基础模型计划与语义接地证书）**
基础模型 `F(q,o_t)` 输出候选计划 `Ŝ=(ℓ_1,…,ℓ_K)`，`ℓ_k` 为自然语言子目标与可供性 `a_k`。接地器 `H:(ℓ_k,o_t)↦φ̂_k` 把子目标映射为几何/逻辑谓词；独立验证器 `V(ℓ_k,φ̂_k,o_t)↦g_k∈{0,1}` 判定接地是否成立。用独立审计集做**语义共形校准**，取偏移 `q_g` 使
`P( g_k=1 ⇒ φ_k(X_t)=1 ) ≥ 1-α_g`。
计划证书 `G_t=(Ŝ, φ̂_{1:K}, g_{1:K}, q_g)`。**基础模型只作 proposal**：`g_k=0` 的步骤不可执行、不可推进，且不参与步骤分计算；幻觉样本回灌 DCL 并降低该计划族的先验权重。

**定义 61（全身-计划联合过程证书）**
联合证书 `J^W_t=(P^W_t, S_{t,k}, ℓ_p, ℓ_e, ℓ_s, ℓ_b, G_t, m_t)`。**联合 soundness**：
`P( X^W_t∈P^W_t ∧ z_{t,k}≤z^true_{t,k} ∧ (g_k=1⇒φ_k) | 各租约有效 ) ≥ 1-α_p-α_s-α_g`。
**过程推进判据**：仅当
`z_{t,k}≥θ_k ∧ P^W_{t,k}⊆Safe_k ∧ d(P^W,O)≥0 ∧ η_t≥η_min ∧ g_k=1 ∧ ℓ_b,ℓ_p,ℓ_e,ℓ_s 均有效` 时才允许 `k→k+1`。
**移动-操作互锁**：当 `‖v_b‖>0` 时冻结操作证书，只允许导航步；抓取/放置类关键步要求 `‖v_b‖=0` 持续 `τ_dwell` 且完成移动后重认证，否则进入保守驻留盒。

## 2. 三大新增产出与既有 IP 升级

**IP-69 WHOLE-BODY CERT ENGINE（底盘-机械臂全身证书引擎）**
- 底盘位姿协方差传播：轮式里程计 + 视觉/激光重定位 + 滑移监测的 EKF 融合
- Minkowski 全身盒构造与禁区/障碍的分离距离检查
- 倾覆裕度在线估计（支撑多边形 + 质心/负载），低速/坡道自适应限速
- 移动触发重认证状态机：`δ_move`/`δ_Σ` 阈值、`τ_re` 重定位窗口、作废期间停机保持
- 底盘租约 `ℓ_b` 签发/续期/级联失效

**IP-70 FM PLAN GROUNDER（基础模型计划接地器）**
- 解析基础模型计划：子目标、可供性、时序依赖，生成候选步骤边界
- 语义接地：语言子目标 → 几何/逻辑谓词 `φ̂_k`（物体身份、支撑面、可达性）
- 独立验证器 `V` 与语义共形校准 `q_g`，保证 `g_k=1⇒φ_k` 的覆盖率 ≥1-α_g
- 幻觉拒绝：接地失败/物体身份冲突/无支撑面放置 → 拒绝该步并回灌 DCL
- 计划证书 `G_t` 与“计划族先验权重”维护

**IP-71 WHOLE-BODY PROCESS GUARD（全身过程守卫 / 移动-操作交错调度器）**
- 以 `J^W_t` 为唯一放行依据，逐步推进并耦合底盘租约
- 移动-操作互锁：移动冻结操作、关键步静止驻留 `τ_dwell` + 重认证
- 行走时间与功耗计入步骤/能量租约，长距离移动前置预留
- 与 CAR 级联：底盘/接地/步骤任一失效 → 保守驻留盒或 fail-closed

**既有 IP 升级**
IP-66 Step-Cert Decomposer：接受基础模型候选分解，但 `φ_k` 必须由接地器确认，不直接信任
IP-67 IL Step-Critic：步骤分条件化于 `g_k` 与底盘定位层，接地失败样本不参与下界校准
IP-68 Process Guard：并入 IP-71 的全身/底盘检查，成为其子模块
IP-60 PSE：`ω_t` 增加 `ω_base`，输出 `P^W(m)`，半径按底盘定位质量分层
IP-61 DCL：采集底盘漂移/滑移样本与接地幻觉反例，护照新增 `base_cov` / `grounding_id`
IP-62 CCA：新增基础模型计划幻觉红队、轮滑/重定位失败注入、移动中操作越权测试
IP-63 ECPS：功耗模型加入行走功率 `P_base(v)`，能量预算按“移动+关键步”分配
IP-51 CAR：守卫升级为全身盒 + 禁区 + 倾覆裕度 + 接地证书一致性
IP-45 总线：新增 base-lease / whole-body-cert / fm-plan / grounding-cert 话题

## 3. 算法骨架

WholeBody-FM 每个控制周期：
1. 读 `o_t, b_t, Σ_b, s_t, η_t, k, ℓ_b, ℓ_p, ℓ_e, ℓ_s`
2. `F(q,o_t)→Ŝ`；接地器 `H,V` 输出 `φ̂_{1:K}, g_{1:K}`，校准得 `q_g`，构造 `G_t`
3. 若 `g_k=0` 或 `‖v_b‖>0` 且当前为操作步 → 冻结/拒绝，进入保守驻留盒
4. `IP-69` 由 `b_t,Σ_b` 构造 `P^W_t`；检查禁区距离与倾覆裕度；超阈则作废并在 `τ_re` 内重定位
5. `z_{t,k}` 条件化于 `g_k` 与 `ω_base` 计算共形下界
6. 若全部推进判据成立且能量/步骤租约有效 → `k→k+1`；否则冻结步骤
7. `CAR` 用 `J^W_t` 守卫；失效样本按采集效用回灌 DCL 并周期性重校准 `q_g`

## 4. 本轮最大风险

**一句话**：基础模型能生成“语义合理”但未接地的计划，而底盘运动又同时放大定位漂移与可观测性退化，若接地验证与底盘重认证没有硬门控，过程守卫会依据未接地子目标和漂移位姿放行全身盒，导致碰撞或倾覆在“计划看起来正确”的掩护下静默发生；因此必须以独立验证器 + 语义共形校准硬门控 `g_k`、以移动即重认证强制作废旧臂证书，并在任一租约失效时 fail-closed 到保守驻留盒。

## 2. 关键算法 伪代码

### IP-69 Whole-Body Cert Engine
```
def whole_body_cert(b_t, Sigma_b, arm_cert, kappa):
    P_b = ball(b_t, kappa, metric=Sigma_b)       # 底盘置信盒
    P_W = minkowski_sum(P_b, arm_cert.P)         # 全身盒
    return P_W

def base_lease_valid(lease_b, P_W, O, t):
    ok = (trace(lease_b.Sigma_b) <= sigma_max and
          lease_b.slip <= eps_slip and
          tipover_margin(P_W) >= eta_min and
          distance(P_W, O) >= 0.0 and
          (t - lease_b.tau) <= lease_b.life)
    return ok

def move_triggered_recert(b_t, b_prev, Sigma_b, Sigma_prev, P_arm):
    moved = norm(b_t - b_prev) > delta_move
    spread = trace(Sigma_b) - trace(Sigma_prev) > delta_sigma
    if moved or spread:
        invalidate(P_arm)                        # 旧臂证书作废
        return RecertPending(deadline=tau_re)    # τ_re 内重定位并重签 P_W
    return None
```

### IP-70 FM Plan Grounder
```
def fm_ground_plan(F, q, o_t, calib):
    plan = F(q, o_t)                             # 候选：[(ell_k, affordance_k)]
    steps, g = [], []
    for (ell_k, a_k) in plan:
        phi_hat = H(ell_k, o_t)                  # 语言→几何/逻辑谓词
        g_k = V(ell_k, phi_hat, o_t)             # 独立验证，0/1
        steps.append((ell_k, phi_hat, a_k))
        g.append(g_k)
    return PlanCert(plan=steps, g=g, q_g=calib.q_g)

def plan_grounding_sound(cert, k, calib):
    # 语义共形：g=1 ⇒ φ 为真的覆盖保证
    return cert.g[k] == 1 and coverage_calibrated(calib, alpha_g)

def reject_hallucination(cert, o_t):
    for k, (ell_k, phi_hat, a_k) in enumerate(cert.plan):
        if not cert.g[k] or identity_conflict(phi_hat, o_t) \
           or unsupported_placement(phi_hat, o_t):
            request_demo(('grounding', ell_k, o_t))   # 反例回灌 DCL
            return RejectStep(k)
    return Accept()
```

### IP-71 Whole-Body Process Guard（移动-操作交错）
```
def whole_body_process_guard(o, k, J, t):
    if not (pose_lease_valid(J.ell_p,t) and energy_lease_valid(J.ell_e,t,E_min)
            and step_lease_valid(J.ell_s,k,t)):
        cascade_invalidate('pose_energy_step'); return FailClosed()
    if not base_lease_valid(J.ell_b, J.P_W, J.O, t):
        cascade_invalidate('base'); return ConservativeDwellBox('base')
    recert = move_triggered_recert(o.b, o.b_prev, o.Sigma_b, o.Sigma_prev, J.P_arm)
    if recert is not None:
        return ConservativeDwellBox('recert_pending')     # 作废期间只停机保持

    moving = norm(o.v_b) > 0
    is_manip = (J.S.k in CriticalSteps)                     # 抓取/放置
    if moving and is_manip:
        return ConservativeDwellBox('move_manip_interlock')
    if is_manip and not (o.v_b == 0 and o.dwell >= tau_dwell):
        return ConservativeDwellBox('dwell_required')

    if not plan_grounding_sound(J.G, k, J.calib):           # 未接地不得推进
        return FreezeStep(k)
    if J.z[k] < theta[k] or not subset(J.P_W, Safe_k) \
       or distance(J.P_W, J.O) < 0 or tipover_margin(J.P_W) < eta_min:
        return FreezeStep(k)
    return Advance(k+1)

def travel_cost(ell_b, path, v, P_base):
    # 行走时间占用步骤租约，功率进入能量租约
    t_travel = path.length / v
    return dt=t_travel, de=P_base(v) * t_travel
```

def car_guard_v8(e,x,cert,persona,lease_p,lease_e,lease_s,lease_b,m_t,t):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| Whole-Body Cert Engine | O(1) 盒运算/周期 | O(V+E) | 协方差传播 + Minkowski 和 ⇒ 全身盒包住真实全身位姿 |
| 移动重认证状态机 | O(1) 检查 | O(1) | `δ_move/δ_Σ` 超阈作废旧证书，`τ_re` 内未重签即 fail-closed |
| FM Plan Grounder | O(K·d_o) 每计划 | O(K·d_o) | 语义共形 `q_g` ⇒ `P(g=1⇒φ)≥1-α_g` |
| Whole-Body Process Guard | O(K) 状态机 | O(K+E) | `J^W` 各租约 ∧ 接地 ⇒ 逐步 sound；否则保守驻留/fail-closed |
| 行走成本核算 | O(1) | O(1) | 行走时间/功率计入租约 ⇒ 能量-步骤可行域不超估 |

正确性定理：若底盘租约 `ℓ_b` 有效（`tr(Σ_b)≤σ_max`、`s_t≤ε_slip`、禁区距离≥0、`η_t≥η_min`）、全身证书 `P^W_t` 满足定义 59、步骤分下界满足 `z≤z^true`（覆盖率 ≥1-α_s）、计划接地满足 `g=1⇒φ`（覆盖率 ≥1-α_g）、且姿态/能量/步骤租约均有效，则联合证书 `J^W_t` 在移动-操作交错下保持 sound；任一条件失效或发生移动超阈未重认证，则冻结步骤并进入保守驻留盒或 fail-closed，不推进 `k+1`。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 全身证书 soundness | 实机全身位姿越界率；Minkowski 盒覆盖率 | 0 起；≥1-α_p |
| E116 移动即重认证 | 超阈移动后旧证书误用率；`τ_re` 内重签成功率 | 0 起；≥99% |
| E117 基础模型接地覆盖 | `g=1⇒φ` 条件覆盖率；语义校准误差 | ≥1-α_g(α_g=0.05)；<10% |
| E118 计划幻觉拦截 | 物体身份错接/无支撑放置拦截率；误拒率 | ≥98%；<5% |
| E119 移动-操作互锁 | 移动中操作越权次数；关键步驻留后重认证及时率 | 0 起；≥99.9% |
| E120 100h 移动长程闭环 | 碰撞/倾覆；过程违例；平均行走能耗；任务成功率 | 0 起；0 起；降低≥15%；下降<5% |

回退：E117 接地覆盖不足 → 关闭基础模型计划，回退 IP-66 示教步骤分解；E116 重认证失效 → 强制低速/停机保持并人工遥操作；E118 幻觉漏拦截 → 基础模型仅作离线建议，执行权回退脚本化 `π_safe`；E120 出现倾覆 → 回退 v11 固定底盘假设并锁定移动功能。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 基础模型计划语义幻觉被当真实谓词 | 高 | 独立验证器 + 语义共形校准 + 未接地硬门控 + 幻觉回灌 |
| 底盘定位漂移使全身盒高估/低估 | 高 | 移动即重认证 + 协方差在线传播 + 保守 `κ` 放大 + 重定位窗口 |
| 移动中执行操作导致倾覆/碰撞 | 高 | 移动-操作互锁 + 关键步静止驻留 `τ_dwell` + 倾覆裕度守卫 |
| 重认证频繁导致任务卡顿 | 中 | 自适应 `δ_move/δ_Σ` + 中继重定位 + 轨迹平滑减少启停 |
| 基础模型计划族偏差固化 | 中 | 计划族先验权重随接地失败下调 + 独立审计集再校准 |
| 行走能耗被低估导致能量租约透支 | 中 | `P_base(v)` 在线标定 + 行走成本前置预留 + 能量临界降速 |

## 6. 本轮最大风险

**一句话**：基础模型能生成“语义合理”但未接地的计划，而底盘运动又同时放大定位漂移与可观测性退化，若接地验证与底盘重认证没有硬门控，过程守卫会依据未接地子目标和漂移位姿放行全身盒，导致碰撞或倾覆在“计划看起来正确”的掩护下静默发生；因此必须以独立验证器 + 语义共形校准硬门控 `g_k`、以移动即重认证强制作废旧臂证书，并在任一租约失效时 fail-closed 到保守驻留盒。
