# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「语音交互」×「真机评测」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**把语音从「字符串输入」提升为「可认证的言语行为通道」，把真机评测从「论文最后一节」提升为「在线标定与证伪装置」**。两条灵感分别治理 v9 遗留的两个债：交互债（语音只被当作不确定的文本，没有语义契约、没有歧义处理、没有抢占时限）与外部效度债（E551–E570 几乎全在仿真，AC 的 β、MW 的 WCET、ID 的归因都缺真机证据）。任何新组件仍须满足 v9 的中立元退化纪律：失效 ⇒ 注入中立元 ⇒ 严格退回 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（语音交互 → 言语行为契约与澄清安全阀）**

直觉：v9 的 "Voice" 其实只活在系统名与 GCT 的指令文本里——语音被当成一个高延迟、低可靠的字符串输入。但语音交互的本质不是「传字符串」，而是**带言外之力的行为**：同一句话可能是命令、提问、确认、否认、中止，甚至是「我在跟旁边的人说话」（addressing）。把语音当命令字符串，等于把一个多轮、可歧义、可抢占的社会协议压缩成一个易被误触发的按钮。

两个关键洞察：

(a) **安全语义由言语行为类型决定，而非由文本内容决定。**「停」「等一下」「不是这个」属于 ABORT/DENY，必须走独立于 EDF 的最高优先级抢占路径；「把红杯子递给我」是 COMMAND，必须先通过指代 grounding 证书（"红杯子"到底指哪个实例）与确认策略。v9 把所有话语压成 goal，等于把"否决"和"中止"也塞进了同一条不可抢占的队列，这是交互层的隐性安全债。

(b) **不确定性应转化为澄清，而不是沉默或蛮干。** 当 SpatialCert/AC/DA 的自省不确定度升高时，系统主动用语音问一个**可回答、有时限、有选项上限**的问题（"你指的是左边那个红杯，还是右边那个？"），把内部不确定性外包给人类。但澄清本身有成本与风险（人可能答错、可能超时、可能被忽视、可能被恶意回答），因此必须是**受预算约束的安全阀**，回答失败时退回中立元（不动作），而不是继续执行。

**灵感 2（真机评测 → 评测即标定，证伪优先于叙事）**

直觉：v9 的引理 82 把 AC 的安全性建立在一个从未在真机上测过的 β 上；引理 86 的 WCET 表是工程估计；ID 的 c_m 是仿真消融。仿真里"全部成立"的结论，到真机上最常见的结果是"延迟分布更胖、前向模型误差更大、语音更吵"。真机评测若只作为最后的"演示"，它无法证伪任何东西——它只是给既有叙事补一张照片。

本轮的第二个核心：**把真机评测协议设计成闭环中的一等公民**。

(a) **成对试验 + 仿真-真机差证书 Δ_s2r。** 同一策略、同一初始条件、同一随机种子在仿真与真机各跑一遍，逐指标测差；Δ_s2r 不是"要消除的误差"，而是**要被显式测量并传播进置信区间**的量。

(b) **评测即标定（Evaluation-as-Calibration）。** 真机测得的 |F̂−F| 经验分位数直接替换 AC 的手调 β（β_cal）；真机语音延迟分布收紧 MW 的 D_voice；真机 ASR 错误率收紧 VAG 的确认阈值。评测不再只是"验收"，而是**下一轮参数的来源**。

(c) **非劣性与安全优先的统计协议。** 真机样本天然少、贵、不可完全复现，因此主判据不是"比 v9 高 15%"这种点估计，而是**安全指标的单侧非劣性检验**（置信上界 < δ_safety）+ 任务成功率的预注册等效界；所有比较做多重比较校正，并预注册停止规则，禁止"跑到显著为止"。

## 1. 研究问题（轮次升级版）

- **Q1（言语行为安全）**：如何用言语行为类型 + 指代 grounding 证书 + 确认策略，使"语音误识别/误触发导致的不安全动作概率"可被界定为 ε_voice，而 ABORT 类行为在任意负载下都能在 T_abort 内抢占？
- **Q2（澄清的收益边界）**：在什么不确定度区间、什么人类回答可靠度下，"主动澄清"严格优于"中立退化"与"继续执行"？如何把提问率、回答时限、选项数纳入预算，避免把自省误差转嫁成人的负担？
- **Q3（真机外部效度）**：如何在低样本、不可完全复现的真机上，给出可证伪的非劣性/等效结论？仿真-真机差 Δ_s2r 能否被测量、被传播进安全论证，并反过来标定 β_cal 与阈值？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 言语行为契约律（Voice-Act Contract, VAC）**
语音输入被解析为言语行为 u=(type, content, conf, addr, t_deadline)，type ∈ {COMMAND, QUERY, CONFIRM, DENY, ABORT, CLARIFY_ANSWER}。COMMAND 必须携带指代 grounding 证书 G 且通过确认策略 π_c 才可入队；ABORT/DENY 走独立最高优先级抢占路径（不占 EDF 预算、不可被降级）；QUERY 只读、不改状态。未授权说话人（addr 校验失败）的言语行为降级为 QUERY/忽略，绝不入命令队列。

**P14 澄清即安全阀律（Clarification-as-Safety-Valve, CSV）**
当综合不确定度 U_sys 越阈时，系统三选一：继续（U < τ_act）、澄清（τ_act ≤ U < τ_stop 且澄清期望收益为正）、中立退化（U ≥ τ_stop 或澄清预算耗尽）。澄清问题 q 必须满足：可回答类型受限、答案选项 ≤ n_q、时限 T_q、单位时间提问率 ≤ ρ_q；回答超时/无效 ⇒ 注入"不动作"中立元。澄清的期望收益须严格为正：E[风险|澄清] < min(E[风险|继续], E[风险|退化])。

**P15 评测即标定律（Evaluation-as-Calibration, EaC）**
任何真机结论以成对试验 + Δ_s2r 差证书表达；仿真结论在真机非劣性通过前一律标记为"临时（provisional）"。真机标定量（β_cal、语音延迟分位数、WER、意图错误率、Δ_s2r）写回 v9 的 AC/MW/VAG 参数，形成"评测→标定→再评测"闭环；参数更新须版本化并保留回滚点。

## 3. 与基线的接口（如何退化）

- VAG 失效（ASR/解析/授权任一不可用）⇒ 注入"无新命令"中立元：在途已确认目标继续执行，无新语音入队，行为严格等价 v9 的"无语音输入"；
- GroundingCert 失效 ⇒ 所有含指代的 COMMAND 一律拒绝（安全失败方向），等价"只接受已显式命名的目标"；
- 澄清调度器失效 ⇒ 停止提问，U 越阈一律走中立退化，等价 v9 的安全停驻/退化；
- VAC 的 ABORT 抢占路径失效 ⇒ 立即收紧速度上限并进入保守停驻（比 v9 更保守，绝不允许"假抢占"）；
- S2RC 标定失效 ⇒ β/阈值回退到 v9 手调值，并标记结论为 provisional；
- v9 的 AC/MW/ID 任一失效 ⇒ 沿用 v9 定义 532–539 的中立元退化链，退回 v8；
- 全部失效 ⇒ 退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 4. 预期贡献

1. **言语行为契约（Voice-Act Contract）**：把语音从字符串升级为带安全语义、指代 grounding 与确认策略的类型化行为；ABORT 独立抢占路径给出可证的 T_abort 上界；
2. **澄清安全阀**：不确定性触发的人类问答闭环，附提问预算、期望收益判据与失败退化，首次把"问人"纳入形式化安全论证；
3. **评测即标定协议**：成对试验 + Δ_s2r 差证书 + 非劣性统计 + 参数回写的真机评测框架，让外部效度成为可计算的量；
4. **语音×分块×契约的耦合分析**：语音中断对 AC 块执行的影响（中块 abort/replan）、语音延迟对 MW 预算的影响、真机 β_cal 对块证书覆盖率的修复。E571–E600 覆盖语音安全、澄清收益、真机外部效度与端到端任务。

## 5. 本轮最大风险

**一句话**：澄清安全阀的前提是系统能可靠地知道自己"有多不确定"，但 v9 的 DA/SLAM/AC 不确定度本身就在仿真里标定——若 U_sys 失真，系统会在真正危险时保持沉默、在安全时反复追问，把"自省误差"转化成"人类的安全负担与时延"，而真机低样本又让这一点极难被统计发现。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-VOX-RRE**（Voice-act Certified Interaction & Real-Robot Evaluation）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「语音交互」×「真机评测」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 全部保留。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元 ⇒ 严格退回 v9 行为（引理 93/87），不得行为漂移。v9 的仿真结论在真机非劣性通过前一律标注 **provisional**（定义 551）。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 MetricVoiceGauge-ACMD v9） |
|---|---|---|---|
| IP-340–356 | v9 全部模块 | 继承 | 语义不变；语音入口改由 VAG 类型化，AC 的 β 改由 S2RC 真机标定（可回退） |
| IP-354 | ActionChunkCertifier | 参数升级 | β ← β_cal（真机 |F̂−F| 的 1−ε 分位数 × 安全系数），其余不变；β_cal 缺失则用 v9 β |
| IP-357 | VoiceActGateway 言语行为网关 | 新增核心模块 | ASR + 言语行为类型化 + 说话人/寻址校验 + 确认策略；ABORT/DENY 走独立最高优先级抢占路径（非 EDF），给出 T_abort 上界 |
| IP-358 | GroundingCertifier 指代接地证书器 | 新增核心模块 | 把"那个红的/左边那个"绑定到场景实例集 E；输出 G=(E, amb, g)，valid ⇔ \|E\|=1 ∧ amb<τ_amb ∧ g≥τ_g；歧义 ⇒ 拒绝或触发澄清 |

| IP-360 | RealRobotEvalHarness 真机评测台 | 新增核心模块 | 成对试验、随机种子对齐、安全包络、预注册停止规则、指标采集（安全/任务/时延/人因）；产出可复现实验档案 |
| IP-361 | Sim2RealCalibrator 仿真-真机标定器 | 新增核心模块 | 逐指标差证书 Δ_s2r；β_cal、语音延迟分位数、WER/意图错误率真机分位数；版本化写回 v9 参数，附回滚点 |

**退化链声明（v10 六层，ABORT 路径例外不降级）：**
- Level-0（语音侧，新增）：VAG/ASR/授权异常 ⇒ 注入"无新命令"中立元（在途目标继续，等价 v9 无语音输入）；GroundingCert 异常 ⇒ 含指代命令一律拒绝；澄清器异常 ⇒ 停止提问并走中立退化；
- Level-1（AC，v9）：证书失效或信任域破坏（Δ_dom ≥ τ_dom ∨ risk_SLAM ≥ τ_SLAM）⇒ K_eff ← 1，逐步执行，等价 v8 决策粒度；
- Level-2（MW，v9）：中间件失效 ⇒ 切换 v8 手写网关代码路径；
- Level-3（ID，v9）：蒸馏失效 ⇒ 全模块 active、归因冻结，等价 v8；
- Level-4（v8 DA/SPR/Cal）：中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；
- Level-5（全失效）：完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。
- **例外（安全方向）**：ABORT 抢占路径若自检失败，系统不进入"假抢占"，而是**收紧速度上限并保守停驻**（比 v9 更保守，属安全失败方向）。

## 1. 符号体系增量（定义 540–551）

**新增定义 540（言语行为 SpeechAct）** 语音输入的类型化解释 u=(type, content, conf, addr, t_deadline)。COMMAND 的 content 含目标谓词与指代表达；DENY/ABORT 为**前馈安全行为**，其语义是"撤销/冻结当前目标或动作"，不是普通动作；QUERY 只读；ANS 是对系统澄清问题的回答。**同一文本在不同 type 下安全语义不同**，故 type 必须由解析器显式判定，禁止默认降级为 CMD。

**新增定义 541（语音契约 VoiceContract）** 在 v9 契约 κ_m 上增加语义字段：κ_v = (In, Out, D_v, Ŵ_v, v_v^⊥, type_sem, ground_req, π_c, addr_policy)。其中 v_v^⊥ = 空命令 ε（命令队列顺序合成下的恒等元：ε∘g = g∘ε = g），D_v 为端到端语音截止期，addr_policy 规定授权说话人集合。ABORT 端口不使用普通契约：它是**吸收元**（一旦触发，后续块不再执行），必须单独验证（定义 544）。

**新增定义 542（指代接地证书 GroundingCertificate）** 对含指代的 COMMAND，GroundingCertifier 输出 G=(E, amb, g)：E 为与指代表达一致的场景实例集，amb = 1 − max_j P(j\|ref)（歧义度），g 为绑定置信度。有效条件：|E|=1 ∧ amb < τ_amb ∧ g ≥ τ_g。无效时禁止直接执行，只能拒绝或走澄清。**方向律**：接地失败一律向"不动作"失败，绝不向"猜一个实例"失败。

**新增定义 543（澄清问题与预算 ClarificationQuery）** q=(question, A_q, T_q, n_q)，要求 A_q 为有限可枚举答案类型（是/否、二选一、≤n_q 的实例列表），T_q 为回答时限。预算约束：任意滑动窗内提问数 ≤ ρ_q；同一目标同一歧义不得重复提问超过一次（去重）。回答超时、超出 A_q、或说话人未授权 ⇒ 视为无回答，注入不动作中立元。

**新增定义 544（中止抢占界 AbortPreemption）** ABORT/DENY 由独立于 MW EDF 的最高优先级路径处理，其 WCET W_abort 与最长阻塞 B_abort（共享缓冲区的优先级天花板）须满足 W_abort + B_abort ≤ T_abort。ABORT 语义为吸收元：触发后所有在途块作废，进入安全停驻，直到新的已确认目标到达。**禁止**把 ABORT 放入普通命令队列（那会使其可被 EDF 延迟或蒸馏休眠）。

**新增定义 545（不确定度融合与三路决策 UncertaintyFusion）**
```
U_sys = w₁·Δ_dom/τ_dom + w₂·risk_SLAM/τ_SLAM
      + w₃·(1 − Ĉ_margin) + w₄·(1 − conf_voice),   Σwᵢ=1
```
三路决策：U<τ_act ⇒ 继续；τ_act≤U<τ_stop 且澄清期望收益为正且预算未耗尽 ⇒ 澄清；否则 ⇒ 中立退化。权重 w 与阈值由真机数据校准，校准前沿用 v9 缺省。

**新增定义 546（真机评测协议 RealRobotProtocol）** Π_eval = (T_tasks, S_strata, N, M_metrics, E_safety, R_stop, P_prereg)。任务按难度/物体/语音噪声分层；N 为成对样本数（同策略同初态仿真与真机各一次）；M_metrics 至少含：碰撞率、近失率、任务成功率、干预率、决策时延 p50/p99、语音端到端时延、澄清率、危险命令误接受率；E_safety 为速度/力/工作空间安全包络；R_stop 为预注册停止规则；P_prereg 为公开的预注册文档。协议在采集前冻结。

**新增定义 547（仿真-真机差证书 Sim2RealGapCertificate）** 对每个预注册指标 m，Δ_s2r,m = \|M_sim,m − M_real,m\|（成对试验，同种子/同初态，取配对差的稳健估计）。差证书需报告每项的点估计与置信区间，并声明哪些结论因 Δ_s2r 过大而不可从仿真外推。**Δ_s2r 不是噪声，而是需要被传播的系统偏差。**

**新增定义 548（真机标定余量 CalibratedMargin）** 令 D_real={|F̂(s,a)−F(s,a)|} 为真机采集的前向误差样本，β_cal = Q_{1−ε}(D_real)·s，s≥1 为安全系数。以 β_cal 替换定义 533 中的 β，可把引理 82 的"假设 β_true ≤ β"从信念变为**可检验的经验命题**（引理 91）。

**新增定义 549（非劣性/等效检验 NonInferiorityTest）** 对安全风险差 Δ_risk = risk(v10) − risk(v9)，原假设 H₀: Δ_risk ≥ δ_safety，备择 H₁: Δ_risk < δ_safety（单侧，α=0.05）；对任务成功率用等效界 δ_task 的双侧检验。样本量 N_min 由预实验方差、δ、α、power=0.8 反解，采集前冻结。所有多指标比较用 Holm–Bonferroni 校正。

**新增定义 550（语音安全预算 VoiceSafetyBudget）** 每小时不安全命令接受数 ≤ ε_voice（默认 0.01/h）。不安全接受定义为：COMMAND 在执行时违反 M₀ 硬检查、或目标实例与说话人意图不符、或未授权/重放命令被执行。该预算与 v8/v9 的碰撞预算独立记账、合并上报。

**新增定义 551（结论溯源与临时性 ClaimProvenance）** 每条实验结论携带三元标签 (evidence, Δ_s2r, status)：evidence ∈ {sim, real, mixed}，status ∈ {provisional, transferred, established}。仅当 real 证据通过非劣性检验且 Δ_s2r 有界时，status 可升为 established；否则一律 provisional，禁止在论文/报告中省略该标签。

**升级定义 496（软证书，v10）** δ_trigger 在原五条件（σ<τ_safe ∧ γ_grasp ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t valid）上增加两条**语音门**：`(u.type≠CMD ∨ G.valid)`（改变目标的命令必须有有效接地）与 `U_sys<τ_stop`（不确定度未到停驻阈）。ABORT 不参与 δ_trigger——它是抢先的、无条件的。

# IP-357 VoiceActGateway：言语行为网关（ABORT 走独立抢占路径）
@dataclass
class SpeechAct:
    type: str          # CMD/QRY/CFM/DENY/ABORT/ANS
    content: dict
    conf: float
    addr: str
    t_deadline: float

class VoiceActGateway:
    def __init__(self, asr, parser, auth, abort_detector,
                 confirm_policy, T_abort=0.1):
        self.asr, self.parser, self.auth = asr, parser, auth
        self.abort = abort_detector            # 独立的轻量关键词/韵律检测
        self.confirm = confirm_policy
        self.T_abort = T_abort
        self.expected_reply_of = None

    def poll(self, audio):
        # (1) 抢占路径先行：不等 ASR 大模型，不走 EDF
        if self.abort.fire(audio):             # 关键词 + 韵律，WCET ≤ 2ms
            return SpeechAct('ABORT', {}, 1.0, 'any', now() + self.T_abort)
        txt, conf = self.asr.transcribe(audio)
        if not self.auth.check(audio, txt):    # 说话人/寻址校验
            return SpeechAct('QRY', {'text': txt}, conf, 'unauth',
                             now() + 0.5)      # 未授权一律降级只读
        u = self.parser.parse(txt, conf)
        if u.type == 'CMD' and self.confirm.required(u.content):
            if not self.confirm.window_open(u):
                # 危险命令先请求确认，确认者须与请求者一致
                return self.confirm.issue(u)
        if u.type == 'ANS' and self.expected_reply_of is not None:
            u.content['answers'] = self.expected_reply_of
        return u


# IP-358 GroundingCertifier：指代接地证书（方向律：失败则不动作）
class GroundingCertifier:
    def __init__(self, tau_amb=0.2, tau_g=0.8):
        self.tau_amb, self.tau_g = tau_amb, tau_g

    def certify(self, content, scene):
        ref = content.get('ref')
        if ref is None:
            return GroundingCert(E=[], amb=0.0, g=1.0, valid=True)
        E = scene.resolve(ref)                  # 候选实例集
        amb = 1.0 - max((scene.posterior(j, ref) for j in E), default=0.0)
        g = scene.binding_conf(E, ref)
        return GroundingCert(E, amb, g,
                             valid=(len(E) == 1
                                    and amb < self.tau_amb and g >= self.tau_g))


# IP-359 ClarificationScheduler：澄清安全阀（期望收益为正才问）
class ClarificationScheduler:
    def __init__(self, tau_act=0.4, tau_stop=0.8, rho_q=0.2,
                 n_q=3, T_q=2.0):
        self.tau_act, self.tau_stop = tau_act, tau_stop
        self.rho_q, self.n_q, self.T_q = rho_q, n_q, T_q
        self.history = deque()                  # 提问时间戳（预算滑窗）

    def decide(self, U, options, R_continue, R_neutral,
               R_correct, R_wrong, p_human):
        if U < self.tau_act:
            return ('act', options[0])          # 继续
        # 引理 89：澄清只有在 p_human 超过盈亏平衡点时才划算
        denom = R_wrong - R_correct
        if denom <= 0:
            return ('neutral', None)            # 问人不可能更好
        p_star = (R_wrong - min(R_continue, R_neutral)) / denom
        if (U >= self.tau_stop or self._budget_exhausted()
                or p_human <= p_star):
            return ('neutral', None)            # 不动作，而非蛮干
        q = self.formulate(options)
        self.history.append(now())
        ans = self.ask(q, timeout=self.T_q)     # 阻塞 ≤ T_q，但只在低优先级带
        if ans is None or ans not in q.A_q:     # 超时/越界/未授权
            return ('neutral', None)
        return ('act', self.bind(ans))

    def _budget_exhausted(self):
        now_t = now()
        while self.history and now_t - self.history[0] > 60.0:
            self.history.popleft()
        return len(self.history) >= self.rho_q * 60.0


# IP-360 RealRobotEvalHarness：成对试验 + 安全包络 + 预注册
class RealRobotEvalHarness:
    def __init__(self, protocol, envelope, logger):
        self.protocol, self.envelope = protocol, envelope
        self.log = logger

    def paired_trial(self, policy, scenario, seed):
        assert self.envelope.check(scenario)     # 采集前安全包络
        sim = run_sim(policy, scenario, seed)    # 同策略、同初态、同种子
        real = run_real(policy, scenario, seed)
        self.log.record(scenario, seed, sim, real)
        return sim, real

    def run(self, policy):
        for stratum in self.protocol.strata:     # 分层，避免辛普森悖论
            for scenario, seed in self.protocol.sample(stratum,
                                                       self.protocol.N):
                if self.should_stop():           # 预注册停止规则
                    break
                self.paired_trial(policy, scenario, seed)
        return self.log.archive()                # 可复现实验档案


# IP-361 Sim2RealCalibrator：差证书与参数回写
class Sim2RealCalibrator:
    def __init__(self, metrics, eps=0.01, safety=1.2, version_store=None):
        self.metrics, self.eps = metrics, eps
        self.safety, self.store = safety, version_store

    def calibrate(self, sim_trials, real_trials):
        gap = {m: paired_gap(sim_trials, real_trials, m)
               for m in self.metrics}            # 定义 547
        errs = [abs(fh - f) for (fh, f) in real_trials.forward_errors]
        beta_cal = quantile(errs, 1 - self.eps) * self.safety   # 定义 548
        v = self.store.commit({
            'beta_cal': beta_cal,
            'voice_latency_q99': quantile(real_trials.voice_lat, 0.99),
            'wer': real_trials.wer,
            'intent_err': real_trials.intent_err,
            'gap': gap,
        })
        return CalibrationCertificate(gap, beta_cal, version=v,
                                      rollback=self.store.previous())

## 4. 推导

**引理 87（言语行为安全界）** 设 (i) 未授权命令被 addr_policy 拒绝；(ii) 危险 COMMAND 必须经 confirm（窗口 T_cfm、确认者与请求者一致）；(iii) 含指代 COMMAND 必须 G.valid。则单条语音导致不安全动作的概率满足
```
P(unsafe) ≤ P(ASR 误识) + P(intent 误判) + P(grounding 错绑|valid)
          + P(confirm 被绕过) ,
```
且在 ABORT 可被独立检测的前提下，任何时刻的"应停未停"概率 ≤ P(ABORT 漏检) + P(W_abort+B_abort > T_abort)。据此可把总预算约束为 P(unsafe)·λ_voice ≤ ε_voice（定义 550）。证明：不安全动作只可能来自四类漏洞之一；addr 与 confirm 把"未授权/未经确认"从事件集中剔除；接地失败走拒绝而非猜测（定义 542 方向律），故不会产生"错实例执行"；ABORT 路径独立于 EDF，其漏检与超时由定义 544 单独界定。四项事件可在互斥化后求并界。∎

**引理 88（ABORT 抢占上界）** 若 ABORT 处理路径的优先级严格高于所有 EDF 任务，且其访问的共享缓冲区均采用优先级天花板、最长阻塞为 B_abort，则从 ABORT 可检测事件发生到安全停驻指令下发的时延 ≤ T_abort，只需 W_abort + B_abort ≤ T_abort。证明：最高优先级 + 天花板协议排除无界优先级反转；路径不经过命令队列、不经过 ID 蒸馏（定义 544 明确禁止），故不受其延迟影响；停驻动作本身是预定义的常数时间序列。∎

**引理 89（澄清收益判据）** 记继续、退化、澄清后按人类回答行动的风险分别为 R_continue、R_neutral、R_ask，其中 R_ask = p·R_correct + (1−p)·R_wrong（p 为人类回答可靠度，R_wrong 为按错答行动的风险）。则澄清严格优于"继续"与"退化"当且仅当
```
p > p* = (R_wrong − min(R_continue, R_neutral)) / (R_wrong − R_correct),
```
并要求 R_wrong > R_correct。证明：R_ask < min(R_continue,R_neutral) ⇔ p·R_correct+(1−p)·R_wrong < min(·) ⇔ R_wrong − p(R_wrong−R_correct) < min(·) ⇔ p > p*。若 R_wrong ≤ R_correct，则问人不会比不问更差，提示模型设定有误，应退回中立。∎

**引理 90（澄清预算与实时性）** 在提问率上限 ρ_q、单次时限 T_q、且澄清在低优先级带执行的条件下，(i) 单位时间用于澄清的期望阻塞 ≤ ρ_q·T_q；(ii) 澄清不会导致 EDF 主环丢拍，只要 ρ_q·T_q + Σ_m Ŵ_m ≤ B_dec；(iii) 提问数在任意 60s 窗内 ≤ ρ_q·60，故无提问风暴。证明：(i) 由预算计数与超时截断；(ii) 澄清不在高优先级带，超时即让出，最坏增量即预算上界；(iii) 由 `_budget_exhausted` 的滑动窗计数直接得到。∎

**引理 91（β_cal 修复块证书覆盖）** 若真机误差样本 D_real 与部署分布同分布（或部署分布被 D_real 随机占优），且 β_cal = Q_{1−ε}(D_real)·s（s≥1），则 P(|F̂−F| ≤ β_cal) ≥ 1−ε。将其代入引理 82 的假设 β_true ≤ β，得块证书的有效覆盖率 ≥ 1−ε；v9 中"β 从未被检验"的缺口由此闭合，代价是 ε 与 s 的保守性。证明：由分位数定义直接得覆盖概率；s≥1 使 β_cal 随机占优于经验分位数；引理 82 仅用一致误差上界，替换后结论不变。∎

**引理 92（Δ_s2r 传播与非劣性转移）** 设同一指标 m 上 |M_sim − M_real| ≤ Δ_s2r,m（成对试验的高概率界）。若真机上 v10 相对 v9 的风险差单侧置信上界 < δ_safety，则仿真结论可携带误差界 δ_safety + Δ_s2r,m 转移到真机语境（保守合并）；反之，仅有仿真证据时，任何"真机安全"断言至少需额外承担 ±Δ_s2r,m 的不确定性，故在 Δ_s2r 未被界定前只能标 provisional（定义 551）。证明：由三角不等式 |M_sim(v10)−M_sim(v9)| ≤ |M_real(v10)−M_real(v9)| + 2Δ_s2r,m；非劣性给第一项上界 δ_safety，合并即得。∎

**引理 93（语音中立退化等价）** VAG 失效时注入空命令 ε，且 ε 是命令队列顺序合成的恒等元（ε∘g = g∘ε = g）；在途已确认目标不被清除；ABORT 路径独立自检，失效时转向更保守的停驻而非假抢占。故系统可观测行为与 v9"无语音输入"逐位等价（日志可审计）。证明：队列状态在注入 ε 前后相同；感知/决策模块不读取 VAG 之外的语音字段（v9 无语音语义）；ABORT 失效分支是安全方向上的加强而非等价，需在日志中显式标记为 Level-0-safe-degrade。∎

## 8. 本轮最大风险

**一句话**：澄清安全阀的前提是系统能可靠地知道自己"有多不确定"，但 v9 的 DA/SLAM/AC 不确定度本身就在仿真里标定——若 U_sys 失真，系统会在真正危险时保持沉默、在安全时反复追问，把"自省误差"转化成"人类的安全负担与时延"，而真机低样本又让这一点极难被统计发现。
