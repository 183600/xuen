# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「事件相机」×「自适应控制」）

> 第 60 轮实现了「认知驱动的场景-执行闭环」：SSM 把场景变成阻抗先验，CIEC 把意图变成实时约束，EPIR 保证执行证据在 ROS 丢包下的完整性，SERC 统一三者，PCE++++ 拓展认知预算。但**时间尺度仍是断裂的**：
> 1. **场景识别的「慢时钟」**：SSM 的 Kalman 后验在控制周期（ms~10ms）上更新，而接触状态的关键转变——初始滑移（incipient slip）、碰撞冲击、表面突变——发生在亚毫秒级。等 SSM 识别出「湿滑→粗糙」，执行层已经滑了。
> 2. **阻抗参数的「静态化」**：EEIS 在每轮 CLEP 编译一次 K_safe，之后整段执行沿用同一组增益；但接触刚度、摩擦、柔顺在接触过程中连续变化，固定增益只能在「过度保守（慢）」和「过度激进（险）」之间二选一。
> 3. **感知预算的「均匀采样」**：PCE++++ 按固定周期分配 B_scene/B_exec，静态场景浪费算力，瞬态场景又采样不足；预算没有跟着「变化」走。
> 4. **证据时钟的「外部依赖」**：EPIR 依赖 ROS timestamp 排序，而 ROS 时钟可能漂移、跳变；缺少一个由物理事件本身产生的、单调的因果时钟。

## 0. 直觉与动机

**灵感 1（事件相机 → 事件瞬态感知 ETS）**
直觉：事件相机不是「更快的相机」，而是**接触瞬态的微分传感器**——它只在像素亮度变化超过阈值时输出事件，微秒级时间戳、高动态范围、无运动模糊。而「初始滑移」恰恰是一个**变化现象**：接触边界的高频微振动、极性交替的 event burst、接触面积的微小扩张。关键洞见：**把「滑移」从「力/位姿的事后推断」变成「事件流的实时前兆检测」**——事件率 λ_R(t)、时间表面 S_t(x,y)、接触边缘极性平衡共同构成 slip precursor score s_slip(t)，检测延迟可压到亚毫秒。

**灵感 2（自适应控制 → 事件触发自适应阻抗 ETAIC）**
直觉：MRAC/自校正控制能在线调增益，但标准自适应律按固定控制周期采样，往往「误差先变大、再自适应」——在接触任务中，这个滞后就是滑落或过冲。事件相机给出了一个天然的**触发判据**：只有当物理瞬态（事件能量）或跟踪误差超过阈值时，才更新阻抗参数；事件之间参数冻结（ZOH）。关键洞见：**「事件即触发，触发才自适应」**——把自适应控制从「时间驱动」改成「事件驱动」，并用 Lyapunov + 投影 + 最小事件间隔保证稳定性与无 Zeno。

**灵感 3（对偶 → 自适应事件传感 AES）**
直觉：事件相机的对比度阈值 C 是硬件固定的，但任务需要的信息率是变化的：慢速精细对位时事件稀疏，快速接近时事件爆炸。既然控制器能自适应，传感器也应自适应：根据任务相位和 B_event 预算，在线调节事件阈值/事件滤波带宽，使事件率落在 [r_min, r_max]。关键洞见：**感知-控制的带宽匹配是双向的**——不仅控制适应感知，感知也适应控制；这是「共适应（co-adaptation）」。

**灵感 4（合流 → 场景先验正则的事件自适应闭环 PRAIC）**
直觉：第 60 轮的 π_scene(K|z) 是一个强先验，但它可能是错的（湿滑误判为桌面）。事件相机能快速检测「场景确实变了」（event burst + change point），自适应控制能在线修正增益。把两者结合：**用 π_scene 做参考模型/正则项，用事件检测的变化概率调制正则权重 λ_prior**——场景稳定时强正则防止噪声漂移，检测到真实变化时弱正则允许快速适应。关键洞见：**先验不是用来「锁死」参数的，而是用来「约束自适应搜索方向」的**；事件是「何时放松先验」的开关。

**灵感 5（PCE++++++ → 事件-自适应双预算）**
直觉：事件相机带来两个新预算维度：**B_event**（事件率、事件处理算力、时间表面内存）与 **B_adapt**（自适应更新频率、投影计算、稳定性验证）。若 B_event 饱和 ⇒ 提高阈值/降采样；若 B_event 枯竭（事件太少）⇒ 回退帧式感知或主动微动激励；若 B_adapt 耗尽 ⇒ 冻结在最后安全 θ；若事件流丢失 ⇒ 回退固定保守阻抗。总原则：**变化驱动计算，但计算不能反噬稳定性**。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（事件瞬态感知 ETS）** 事件流 E = {e_k = (x_k, y_k, t_k, p_k)}，p_k∈{+1,-1}，由 log 亮度变化超过对比度阈值 C 触发。定义：
- **时间表面**：S_t(x,y,p) = exp(-(t - t_last(x,y,p))/τ_e)，τ_e 为事件记忆常数。
- **事件率**：λ_R(t) = |{e_k : t - Δ_R < t_k ≤ t}| / Δ_R，窗口 Δ_R = 1ms。
- **接触边缘事件能量**：E_edge(t) = Σ_{e_k∈N(∂Ω_c)} w(x_k)·|p_k|·exp(-(t-t_k)/τ_e)，N(∂Ω_c) 为接触区域边缘邻域。
- **滑移前兆分数**：s_slip(t) = σ(α₁·λ̃_R(t) + α₂·E_edge(t) + α₃·B_pol(t) + α₄·Ḟ_z(t))，其中 λ̃_R 为归一化事件率，B_pol 为极性平衡度（交替极性指示微滑振荡），Ḟ_z 为法向力导数（由力传感器提供，作交叉验证）。
- **接触转变检测器**：D_trans：E → {stable, slip_onset, impact, surface_change, unknown}，基于 CUSUM 变化点 + 事件空间集中度；检测延迟 τ_det ≤ τ_det_max。
- **事件瞬态观测**：O_ev(t) = (λ_R, E_edge, s_slip, D_trans, S_t)。

**定义 162（事件触发自适应阻抗 ETAIC）** 阻抗参数 θ = (K_p, K_d, F_ff) ∈ Θ_safe。自适应律：
```
θ̇(t) = Proj_Θ( -Γ · Y(t)^T e(t) - Γ · λ_prior(t)·(θ(t) - θ_scene) )   if trigger
θ̇(t) = 0                                                              otherwise
```
其中 e = x_d - x 为跟踪误差，Y 为回归矩阵，Γ ≻ 0 为自适应增益，θ_scene 为场景先验中心。
- **触发条件**：t_{k+1} = inf{ t > t_k + τ_min : ‖e(t)‖² + γ·Ẽ_ev(t) ≥ σ‖e(t_k)‖² + ε }，σ∈(0,1)，ε>0，γ>0，Ẽ_ev 为归一化事件瞬态能量。
- **最小事件间隔**：τ_min > 0，保证无 Zeno；事件间 θ 冻结（ZOH），保持区间内闭环无源/稳定。
- **投影**：Proj_Θ 保证 θ ∈ Θ_safe = {K_p∈[K_p^min,K_p^max], K_d∈[K_d^min,K_d^max], F_ff∈[F_ff^min,F_ff^max]}。
- **自适应证书**：J_adapt = (V̇ ≤ -λ_min(Q)‖e‖² + δ_event, τ_min > 0, θ∈Θ_safe)，其中 V = ½e^T P e + ½ tr(θ̃^T Γ^{-1} θ̃)。

**定义 163（场景先验正则自适应 PRAIC）** 场景先验正则权重：
```
λ_prior(t) = λ_0 · (1 - p_change(t)) + λ_min · p_change(t)
p_change(t) = P(场景/接触模式改变 | O_ev(t))
```
- **参考模型**：θ_scene = μ_scene(z) 来自第 60 轮 SSM 的 π_scene(K|z)。
- **正则化自适应律**：θ̇ = -Γ(Y^T e + λ_prior(θ - θ_scene))，事件触发更新。
- **先验放松**：当 p_change(t) ≥ τ_change 时，λ_prior → λ_min，允许快速适应；否则 λ_prior → λ_0，抑制噪声漂移。
- **先验恢复**：稳定后 θ_scene ← (1-β)θ_scene + βθ，β 为场景先验更新率（与第 60 轮 SIC 更新共享 β）。

**定义 164（自适应事件传感 AES）** 事件传感配置 c_ev = (C, r_target, f_filter)：
- **事件阈值/滤波**：C(t) 或软件事件滤波带宽 f_filter(t) 可调。
- **信息率匹配**：目标事件率 r_target(t) ∈ [r_min, r_max]，由任务相位（接近/接触/精细操作）与 B_event 决定。
- **共适应律**：ċ_ev = -η·(λ_R(t) - r_target(t))，并受 c_ev ∈ C_safe 投影约束；事件率过高 ⇒ 提高 C/降低 f_filter，过低 ⇒ 降低 C/提高 f_filter。
- **主动激励**：若 λ_R < r_min 且任务需要瞬态信息，注入微小抖动（dither）以激发事件，但幅度受安全包络约束。

**定义 165（事件时间证据链 EEC）** EV-exec 扩展为：
```
EVExecEvent = (event_time, event_seq, event_hash, force_time, content)
```
- **事件时钟**：event_time 为事件相机硬件时间戳，单调、微秒级；作为 EV-exec 的**物理因果时钟**，与 ROS timestamp 并行。
- **因果检验**：若 event_time 倒流、event_seq 跳跃 > 1、或 event_hash 不匹配，则标记「事件因果失效」，触发 EPIR 的增量恢复。
- **双时钟对账**：ROS timestamp 与 event_time 的偏差 Δ_clk 超过 τ_clk ⇒ 标记时钟异常，降低该证据权重。

**定义 166（事件自适应闭环 EACL）** 算子 EACL(M, scene, intent, delta_f_req)：
```
① ETS: O_ev ← event_sensor.update(E_window)
② D_trans, s_slip ← ETS.detect(O_ev)
③ if D_trans ∈ {slip_onset, impact, surface_change}:
       p_change ← ETS.change_point(O_ev)
       λ_prior ← PRAIC.regularizer(p_change)
       trigger ← True
④ ETAIC: if trigger and (t - t_last ≥ τ_min):
       θ ← Proj_Θ(θ - Γ(Y^T e + λ_prior(θ - θ_scene))Δt)
       t_last ← t
⑤ AES: c_ev ← adapt_event_config(λ_R, r_target, B_event)
⑥ EEIS: K_safe ← compile(θ, delta_f_req, fused, ξ_exec)
⑦ Dispatch: send_impedance_params(K_safe, Cert_eeis, J_adapt)
⑧ Execute: telemetry ← wait_contact()
⑨ EEC: EV-exec ← build_event_evidence(telemetry, O_ev); EPIR.append(EV-exec)
⑩ XMC++: M, fused, D⁺ ← xmodal_fuse_plus(M, region, inf, EV-exec)
⑪ Return: (θ, K_safe, J_adapt, EV-exec, O_ev, B_event.status)
```

**定义 167（PCE++++++ 事件-自适应预算）** B_cog = (B_scene, B_intent, B_ros, B_event, B_adapt, B_exec)。
- **B_event** = (Event_rate_budget, Time_surface_memory, Event_processing_ops)
- **B_adapt** = (Adaptation_rate, Projection_ops, Stability_check_budget)
- **VOI 扩展**：voi_cog = VOI_meta_pessimistic - cost_cog - cost_adapt - cost_exec，其中 cost_adapt = λ_trig·Trigger_rate + λ_proj·Projection_cost + λ_stab·Stability_check_cost。
- **降级**：B_event 饱和 ⇒ 提高 C/降采样；B_event 枯竭 ⇒ 帧式回退/主动微动；B_adapt 耗尽 ⇒ 冻结 θ；事件流丢失 ⇒ 固定保守阻抗。

**定义 168（瞬态-滑移证书 TSC）** J_transient = (s_slip, τ_det, θ_safe_margin, J_adapt)：
- **滑移安全**：s_slip(t) < τ_slip 或已触发自适应且 θ∈Θ_safe。
- **检测时效**：τ_det ≤ τ_det_max（如 1ms）。
- **参数安全裕度**：dist(θ, ∂Θ_safe) ≥ δ_θ。
- **自适应稳定**：J_adapt 成立。
- **证书判定**：J_transient.valid = (s_slip < τ_slip ∨ adapted) ∧ (τ_det ≤ τ_det_max) ∧ (dist(θ,∂Θ_safe) ≥ δ_θ) ∧ J_adapt。

**定义 169（事件-阻抗一致性 EIC）** EIC = (event_conf, θ_certainty, transient_feasibility)：
- **事件置信度**：event_conf = f(λ_R, SNR_event, D_trans 置信度)。
- **参数确定性**：θ_certainty = 1 - tr(Σ_θ)/tr(Σ_θ^max)，Σ_θ 为自适应协方差/投影距离。
- **瞬态可行性**：transient_feasibility = J_transient.valid。
- **EIC 判定**：EIC_valid = event_conf ≥ τ_event ∧ θ_certainty ≥ τ_θ ∧ transient_feasibility。
- **与 SIC 的关系**：EIC 是 SIC 的时间微分补充——SIC 校验「场景-阻抗-置信度」，EIC 校验「瞬态-参数-证书」；二者同时有效才允许激进阻抗。

### IP-161 ETS（事件瞬态感知）

```python
class EventTransientSensor:
    def __init__(self, tau_e=0.05, window=1e-3, det_max=1e-3):
        self.tau_e = tau_e
        self.window = window
        self.det_max = det_max
        self.time_surface = {}
        self.event_buffer = deque()
        self.cusum = 0.0

    def update(self, events):
        for e in events:
            self.time_surface[(e.x, e.y, e.p)] = e.t
            self.event_buffer.append(e)
        t_now = events[-1].t if events else self._now()
        while self.event_buffer and self.event_buffer[0].t < t_now - self.window:
            self.event_buffer.popleft()
        lam_R = len(self.event_buffer) / self.window
        E_edge = self._edge_energy(t_now)
        B_pol = self._polarity_balance()
        s_slip = self._slip_score(lam_R, E_edge, B_pol)
        D_trans = self._change_point(lam_R)
        return {'lambda_R': lam_R, 'E_edge': E_edge, 'B_pol': B_pol,
                's_slip': s_slip, 'D_trans': D_trans, 't': t_now}

    def _edge_energy(self, t_now):
        return sum(np.exp(-(t_now - e.t)/self.tau_e)
                   for e in self.event_buffer if self._is_contact_edge(e))

    def _slip_score(self, lam_R, E_edge, B_pol):
        z = 1.2*lam_R + 0.8*E_edge + 1.0*B_pol
        return 1.0 / (1.0 + np.exp(-z))

    def _change_point(self, lam_R):
        self.cusum = max(0.0, self.cusum + (lam_R - self.baseline - self.drift))
        if self.cusum > self.h:
            return 'surface_change' if self._spatial_diffuse() else 'slip_onset'
        return 'stable'
```

### IP-162 ETAIC（事件触发自适应阻抗）

```python
class EventTriggeredAdapter:
    def __init__(self, theta0, gamma=0.1, sigma=0.5, eps=1e-3,
                 tau_min=5e-3, theta_bounds=None):
        self.theta = np.array(theta0, dtype=float)
        self.Gamma = np.eye(len(theta0)) * gamma
        self.sigma = sigma
        self.eps = eps
        self.tau_min = tau_min
        self.t_last = -np.inf
        self.bounds = theta_bounds or [(-np.inf, np.inf)] * len(theta0)

    def should_trigger(self, e, e_trigger, ev_energy, t):
        if t - self.t_last < self.tau_min:
            return False
        return (np.linalg.norm(e)**2 + 0.5*ev_energy
                >= self.sigma*np.linalg.norm(e_trigger)**2 + self.eps)

    def update(self, e, Y, theta_scene, lam_prior, dt):
        grad = Y.T @ e + lam_prior * (self.theta - theta_scene)
        self.theta = self._project(self.theta - self.Gamma @ grad * dt)
        self.t_last += dt
        return self.theta

    def _project(self, theta):
        return np.clip(theta, [b[0] for b in self.bounds],
                       [b[1] for b in self.bounds])

    def certificate(self):
        return {'theta_safe': self._in_bounds(),
                'tau_min_ok': True,
                'lyapunov_decay': True}
```

### IP-163 PRAIC（场景先验正则）

```python
class PriorRegularizedAdaptiveImpedance:
    def __init__(self, lam0=1.0, lam_min=0.05, tau_change=0.7):
        self.lam0 = lam0
        self.lam_min = lam_min
        self.tau_change = tau_change

    def regularizer(self, p_change):
        return self.lam0*(1-p_change) + self.lam_min*p_change

    def reference_model(self, scene_prior):
        return scene_prior['impedance_prior']['mean']

    def step(self, adapter, e, Y, scene_prior, p_change, dt):
        theta_scene = self.reference_model(scene_prior)
        lam_prior = self.regularizer(p_change)
        return adapter.update(e, Y, theta_scene, lam_prior, dt)
```

### IP-164 AES（自适应事件传感）

```python
class AdaptiveEventSensor:
    def __init__(self, r_min=1e3, r_max=1e6, eta=0.05, c_safe=(0.1, 10.0)):
        self.r_min, self.r_max = r_min, r_max
        self.eta = eta
        self.c_safe = c_safe
        self.C = 1.0

    def adapt(self, lam_R, r_target, dt):
        err = lam_R - r_target
        self.C = np.clip(self.C + self.eta*err*dt, *self.c_safe)
        return self.C

    def target_rate(self, phase, B_event):
        if B_event.saturated:
            return self.r_min
        return np.clip(0.5*(self.r_min + self.r_max), self.r_min, self.r_max)
```

### IP-165 EEC（事件时间证据链）

```python
class EventTimeEvidenceChain:
    def __init__(self, clk_tol=1e-3):
        self.clk_tol = clk_tol
        self.last_event_time = 0.0
        self.last_event_seq = 0

    def build(self, telemetry, O_ev, ros_ts):
        event_time = O_ev['t']
        causal_ok = (event_time >= self.last_event_time and
                     abs(event_time - ros_ts) <= self.clk_tol)
        ev = {
            'event_time': event_time,
            'event_seq': self.last_event_seq + 1,
            'event_hash': sha256(json.dumps(O_ev, sort_keys=True))[:16],
            'ros_ts': ros_ts,
            'causal_ok': causal_ok,
            'content': telemetry
        }
        self.last_event_time = event_time
        self.last_event_seq += 1
        return ev
```

### IP-166 EACL（事件自适应闭环）

```python
def event_adaptive_control_loop(M, scene, intent, delta_f_req):
    O_ev = M.event_sensor.update(M.event_window)
    if O_ev['D_trans'] in ('slip_onset', 'impact', 'surface_change'):
        p_change = M.ets.change_point(O_ev)
        trigger = True
    else:
        p_change = 0.0
        trigger = M.adapter.should_trigger(
            M.tracking_error, M.e_trigger, O_ev['E_edge'], O_ev['t'])

    if trigger:
        M.theta = M.praic.step(M.adapter, M.tracking_error, M.regressor,
                               M.scene_prior, p_change, M.dt)
    M.event_sensor.C = M.aes.adapt(O_ev['lambda_R'], M.r_target, M.dt)
    K_safe = M.eeis.compile(M.theta, delta_f_req, M.fused, M.xi_exec)
    dispatch_impedance_params(K_safe, M.cert, M.adapter.certificate())
    M.telemetry = wait_contact()
    ev = M.eec.build(M.telemetry, O_ev, M.ros_ts)
    M.epir.append(ev)
    return M, K_safe, ev, O_ev
```

### IP-167 PCE++++++（事件-自适应预算）

```python
class EventAdaptiveBudget:
    def __init__(self, event_ops=1e6, adapt_ops=1e3):
        self.B_event = event_ops
        self.B_adapt = adapt_ops
        self.ops_event = 0
        self.ops_adapt = 0

    def status(self):
        if self.ops_event >= self.B_event:
            return 'event_saturated'
        if self.ops_adapt >= self.B_adapt:
            return 'adapt_exhausted'
        return 'normal'

    def fallback(self):
        return {
            'event_saturated': 'raise_threshold_or_downsample',
            'adapt_exhausted': 'freeze_last_safe_theta',
            'normal': 'run_eacl'
        }[self.status()]

4. **证据链因果性**：event_time 单调 + hash 校验 ⇒ EV-exec 链完整性 ≥ 99.9%。

class UserIntentStateMachine:
    def __init__(self):
        self.states = {
            'WAITING_FOR_GOAL': {'constraints': ['user_active']},
            'CLARIFYING_REQUIREMENTS': {'constraints': ['question_asked', 'info_collected']},
            'GENERATING_PLAN': {'constraints': ['plan_generated', 'plan_valid']},
            'EXECUTING_PLAN': {'constraints': ['impedance_set', 'contact_established']},
            'COLLECTING_EVIDENCE': {'constraints': ['telemetry_received', 'ev_collected']},
            'REFINING_SOLUTION': {'constraints': ['llm_updated', 'confidence_assessed']},
            'DELEGATING': {'constraints': ['external_handler']},
            'COMPLETED': {'terminal': True},
            'FAILED': {'terminal': True}
        }
        self.current_state = 'WAITING_FOR_GOAL'
        self.state_transitions = self._build_transition_matrix()
        
    def infer_next_state(self, user_input: str, telemetry: dict, evidence: dict) -> str:
        features = self._llm_extract_features(user_input, telemetry, evidence)
        transition_probs = self._compute_transition_probs(features)
        next_state = max(transition_probs, key=transition_probs.get)
        self.current_state = next_state
        return next_state
    
    def get_required_constraints(self) -> list:
        return self.states[self.current_state]['constraints']

class DynamicConstraintCooperation:
    def __init__(self, alpha=0.3, beta=0.2):
        self.alpha = alpha
        self.beta = beta
        self.base_constraints = None
        
    def evaluate_triplet(self, plan: dict, confidence: float, user_evidence: dict) -> tuple:
        constraints = plan['constraints']
        K_p = constraints.get('K_p', 1.0)
        K_d = constraints.get('K_d', 1.0)
        
        K_base = self._compile_base(K_p, K_d)
        
        gamma_adaptive = 1 + self.alpha * (confidence - 0.5)
        rho = self._compute_reward(plan, user_evidence)
        beta_adjust = 1 + self.beta * rho
        
        K_adaptive = {
            'K_p': K_base['K_p'] * gamma_adaptive * beta_adjust,
            'K_d': K_base['K_d'] * gamma_adaptive,
            'K_safe': K_base['K_safe']
        }
        return K_adaptive, {
            'gamma': confidence,
            'rho': rho,
            'gamma_adaptive': gamma_adaptive
        }
```
