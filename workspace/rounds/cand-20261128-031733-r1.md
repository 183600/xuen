### 第 1 轮灵感驱动研究记录（新循环 · 继承 CADVS-v4 / IP-489~492）

**灵感词**：推理延迟、真实世界泛化

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（空间锚 3DCF、物理锚 MSRG、人因锚 HICK、末点锚 EEK、记忆锚 LTEM）与联邦锚 FFA 之上，追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3 · η_val · η_bal；执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。v4 自陈的最大风险是「VACK/BCK 的计算开销挤爆 1 kHz 控制环」，且其引理 41/42 与假设 (B4)(B5) 把「价值模型一致」「动力学准确」当作既定前提，未处理部署分布漂移。本轮不推翻 v4，而是把「延迟」与「泛化」从工程约束提升为一等证据锚：时限锚 LAES（kc_lat）与泛化锚 GEK（kc_gen），并用预算化调度器 LGCS（IP-495）把二者桥接，形成 CADVS-v5（IP-493~496）。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_lat ∧ kc_gen，fail-closed；执行集嵌套升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **推理延迟：从「算得更快」到「随时可停、停了更保守」**。安全证书不应建立在「一定能在 1 ms 内算完」这种脆弱假设上，而应保证**任何时刻被中断都返回一个仍然 sound 的保守证书**。做法是把昂贵锚的结论做成带 TTL 的「证书租约」：利用连续系统的时域 Lipschitz 性——若价值得分距阈值还有 margin m，且其变化率有界 |α̇_val| ≤ B，则未来 m/B 秒内该结论仍然成立。控制环绝大多数周期只做 O(1) 租约校验，只有租约临近到期或 margin 变小时才触发全量重算。若预算耗尽，则对未评估锚使用「保守代理」g_i^cons（满足 g_i^cons(x)=1 ⇒ f_i(x)=1），保证降级只会**缩小**执行集、绝不放大。这把 v4 的「延迟风险」转化为可证明的「降级安全」。

2. **真实世界泛化：从「仿真通过」到「带风险上界的分布外可用」**。真实世界泛化的敌人不是平均精度，而是分布漂移下的尾部风险。引入泛化证书 GEC：用加权保形预测（weighted conformal）在协变量漂移下给出部署风险上界 R_ucb，用批级 OOD/漂移分数 ŝ 检测「保形假设是否还成立」；硬门 kc_gen = (ŝ ≤ τ_shift) ∧ (R_ucb ≤ τ_risk)。若漂移超出可证范围，fail-closed 回退到更保守执行集并请求人类介入或再校准。诚实地讲：任意分布漂移下不存在免费的泛化保证，因此 kc_gen 是「条件保证 + 检测触发」，而非无条件泛化。

3. **二者耦合：预算化的泛化-认证调度**。直觉上，延迟预算和泛化能力是同一份预算的两种花法——花在「现在多算一个锚」还是「在线适配/重校准以降低漂移」。定义 LGCS：在每周期/每规则准入时，按「单位毫秒的边际安全增益」贪心分配预算给 认证 / 租约刷新 / 在线自适应 / 保守回退；在增益子模、代价模的假设下给出 1−1/e 近似。关键洞见：延迟不是必须消灭的敌人，而是可以与泛化显式交换的资源；只要交换规则 fail-closed 且可审计。

**关键洞见**：v4 的七锚点回答「证据是否充分」，却默认「证据来得及算、且算它时世界没变」。v5 追加时限锚（证据必须在预算内 sound 地产出）与泛化锚（证据在部署分布上仍有风险上界），并用预算调度把「算得完」与「算得准」统一为同一约束优化。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_lat ∧ kc_gen；软评分 ECS_v5 = ECS_v4 · η_lat · η_gen。

**形式化目标（增量）**：
1. 定义锚评估延迟 c_i(x)、截止预算 d_budget、随时证书 A_d(x) 与保守代理 g_i^cons，并要求 soundness：g_i^cons(x)=1 ⇒ f_i(x)=1。
2. 定义证书租约 L_i = (f_i, m_i, B_i, TTL_i = m_i/B_i, t_0, envelope) 与有效性判定；证明租约 soundness（引理 43）。
3. 定义时限证书 LatC 与硬门 kc_lat；证明降级单调性：A_d 随 d 单调增强、Exec(A_d) ⊆ Exec(F)（引理 44）。
4. 定义泛化证书 GEC = (R_emp, R_ucb, ŝ, coverage, domain_id, t)；加权保形 + 漂移项；kc_gen = (ŝ ≤ τ_shift ∧ R_ucb ≤ τ_risk)。
5. 定义软因子 η_lat、η_gen 与 ECS_v5 = ECS_v4 · η_lat · η_gen。
6. 定义 LGCS 预算分配（子模贪心）与近似比。
7. 定义 Exec_CADVS-v5 ⊆ Exec_CADVS-v4，并给出联合退化界（定理 v5）：延迟越紧、漂移越大，执行集越保守，但永不超过 v4。

**本轮最大风险**：把实时性从「算得快」改成「租约 + 随时降级」后，最大风险是**租约失真的静默不安全**——漂移界 B_i 或模型误差被低估时，已失效但看似有效的租约会继续放行旧证书，比单纯丢帧更隐蔽、更难检测。

## 2. 关键算法骨架

### IP-493 LAES：时限证据锚与证书租约（控制环内快路径 O(1)，慢路径按需）

```python
@dataclass
class Lease:
    anchor_id: str
    stat: float
    margin: float          # m_i = |stat - tau_i|
    rate_bound: float      # B_i
    ttl: float             # m_i / (kappa * B_i)
    t0: float
    envelope: dict         # 租约期间允许的状态包络（速度/加速度/接触模式）

    def valid(self, t_now: float, state: Any) -> bool:
        return (t_now - self.t0 < self.ttl) and self._in_envelope(state)


@dataclass
class LatencyAwareAnytimeEvidenceScheduler:
    """LAES：随时证书 + 租约 + 保守降级；kc_lat 硬门"""
    d_budget: float = 0.001          # 控制环 1 ms
    kappa: float = 1.5               # 租约鲁棒安全系数
    L_max: int = 1                   # 允许的最大降级等级（0=全量, 1=租约, 2=保守代理）
    leases: dict[str, Lease] = field(default_factory=dict)
    surrogates: dict[str, Callable] = field(default_factory=dict)

    def certificate(self, x, t_now: float, S_req: list[str],
                    evaluate: dict[str, Callable]) -> tuple[bool, LatC]:
        """按预算调度锚；任何时刻返回 sound 的 A_d(x)"""
        t_start = now_ms()
        S_eval, S_lease, S_cons, ok = [], [], [], True
        deg = 0
        # 1) 先验租约（零成本）：仍然有效的昂贵锚直接复用
        for i in S_req:
            L = self.leases.get(i)
            if L and L.valid(t_now, x):
                S_lease.append(i)
        # 2) 剩余锚按 margin 降序（越大越值得全量算）贪心全量评估
        rest = [i for i in S_req if i not in S_lease]
        rest.sort(key=lambda i: self._margin(i, x), reverse=True)
        for i in rest:
            if now_ms() - t_start + self._est_cost(i, x) > self.d_budget:
                break
            if evaluate[i](x):
                S_eval.append(i)
                self._refresh_lease(i, x, t_now)
            else:
                return False, LatC(now_ms()-t_start, self.d_budget,
                                   S_eval, S_lease, S_cons, deg, t_now)
        # 3) 预算耗尽：未评估锚用保守代理（sound，只会更严）
        for i in rest:
            if i in S_eval:
                continue
            g = self.surrogates.get(i)
            if g is not None and g(x):
                S_cons.append(i)
            elif i in S_lease:
                pass
            else:
                ok = False                 # 无可证 fallback：fail-closed
        deg = 0 if not S_cons else max(deg, 1)
        latc = LatC(now_ms()-t_start, self.d_budget, S_eval, S_lease, S_cons, deg, t_now)
        return ok and self.kc_lat(latc, S_req), latc

    def kc_lat(self, latc: LatC, S_req: list[str]) -> bool:
        covered = set(latc.S_eval) | set(latc.S_lease) | set(latc.S_cons)
        return (latc.d_used <= latc.d_budget
                and covered.issuperset(S_req)
                and latc.deg_level <= self.L_max)

    def _refresh_lease(self, i, x, t_now):
        m = self._margin(i, x); B = self._rate_bound(i, x)
        self.leases[i] = Lease(i, self._stat(i, x), m, B,
                               ttl=max(0.0, m / (self.kappa * max(B, 1e-9))),
                               t0=t_now, envelope=self._envelope(x))

    def _margin(self, i, x) -> float: ...
    def _rate_bound(self, i, x) -> float: ...
    def _est_cost(self, i, x) -> float: ...
    def _envelope(self, x) -> dict: ...
```

### IP-494 GEK：泛化证据锚（规则准入/周期批检，异步秒级）

```python
@dataclass
class GeneralizationEvidenceKernel:
    """GEK：加权保形 + 漂移检测 → 部署风险上界；kc_gen 硬门"""
    tau_risk: float = 0.05
    alpha_shift: float = 0.05
    delta: float = 0.05
    W_max: float = 10.0
    L_ell: float = 1.0
    calibration: Any = None          # (X, Y, weights) 校准集
    ood_detector: Any = None         # 轻量密度比/马氏距离/自编码器残差

    def evaluate(self, batch: Batch, domain_id: str, t_now: float) -> GEC:
        # 1) 批级漂移分数：MMD 或密度比高分位数
        s_hat = self._shift_score(batch.features)
        # 2) 加权经验风险（截断权重，控制方差）
        w = np.clip(self._density_ratio(batch.features), 0.0, self.W_max)
        R_emp = float(np.mean(w * self._loss(batch)))
        # 3) 风险上界：有限样本 + 漂移项
        n = len(self.calibration)
        R_ucb = (R_emp
                 + self.W_max * np.sqrt(np.log(1/self.delta) / (2*n))
                 + self.L_ell * self._tv_or_w1(batch.features, self.calibration.X))
        coverage = self._weighted_conformal_coverage(batch, self.alpha_shift)
        return GEC(R_emp, R_ucb, s_hat, coverage, domain_id, t_now)

    def kc_gen(self, gec: GEC) -> bool:
        """引理 45：通过 ⟹ 在 (B7) 漂移假设下部署风险以 1−δ 概率 ≤ τ_risk"""
        return gec.shift_score <= self.tau_shift() and gec.R_ucb <= self.tau_risk

    def tau_shift(self) -> float:
        return float(np.quantile(self.calibration.id_shift_scores, 1 - self.alpha_shift))

    def _shift_score(self, X) -> float: ...
    def _density_ratio(self, X) -> np.ndarray: ...
    def _loss(self, batch) -> np.ndarray: ...
    def _tv_or_w1(self, X, X_cal) -> float: ...
    def _weighted_conformal_coverage(self, batch, alpha) -> float: ...
```

### IP-495 LGCS：延迟–泛化联合预算调度（准入/周期边界，O(|A| log |A|)）

```python
@dataclass
class LatencyGeneralizationCoScheduler:
    """LGCS：把毫秒预算分配给 认证/租约刷新/在线自适应/保守回退"""
    def allocate(self, actions: list[Action], d_budget: float) -> list[Action]:
        # 动作 a = (type, target, cost_ms, safety_gain)
        # 贪心：按 gain/cost 降序取，直到预算耗尽
        ranked = sorted(actions, key=lambda a: a.safety_gain / max(a.cost_ms, 1e-6),
                        reverse=True)
        chosen, used = [], 0.0
        for a in ranked:
            if used + a.cost_ms <= d_budget:
                chosen.append(a); used += a.cost_ms
        return chosen
    # 命题 3：若 safety_gain 子模、cost 模，则贪心达到 (1−1/e)·OPT
```

### IP-496 EFA-v5：九硬门 + 软评分 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；ECS_v5 = ECS_v4 · η_lat · η_gen"""
    efa_v4: EvidenceForgingAssemblerV4
    laes: LatencyAwareAnytimeEvidenceScheduler
    gek: GeneralizationEvidenceKernel
    lgcs: LatencyGeneralizationCoScheduler

    def hard_gate(self, x, t_now, rule_id, hic, eec, bcc,
                  object_class, geo_sig, theta_domain_fp, traj, context,
                  S_req, evaluate, batch, domain_id) -> tuple[bool, str]:
        if self.efa_v4.hic.veto_active(hic):
            return False, 'HIC_STOP'
        ok_lat, latc = self.laes.certificate(x, t_now, S_req, evaluate)
        if not ok_lat:
            return False, 'DEADLINE_UNSOUND'
        ok_v4, why = self.efa_v4.hard_gate(
            x, t_now, rule_id, hic, eec, bcc, object_class,
            geo_sig, theta_domain_fp, traj, context)
        if not ok_v4:
            return False, why
        gec = self.gek.evaluate(batch, domain_id, t_now)
        if not self.gek.kc_gen(gec):
            return False, 'GENERALIZATION_UNPROVEN'
        return True, 'FORGED'

    def ecs_v5(self, latc: LatC, gec: GEC, S_req, **kw) -> float:
        eta_lat = max(0.0, 1 - latc.d_used/latc.d_budget) * (len(latc.S_eval)/max(len(S_req),1))
        eta_gen = max(0.0, min(1 - gec.R_ucb/self.gek.tau_risk,
                               1 - gec.shift_score/self.gek.tau_shift(), 1.0))
        return self.efa_v4.ecs_v4(**kw) * eta_lat * eta_gen
```

### 集成流水线（v4 → v5）

```
离线/慢时域（FFA + 泛化校准，不在控制环）：
```

## 3. 复杂度与实时性分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| LAES 租约校验 | **O(card(S_req)) = O(1)** | O(card(S_req)) | — | < 0.005 ms/周期 |
| LAES 租约刷新（VACK） | O(L·d_model) | O(d_model) | 异步，仅准入/低 margin | ~10–50 ms（不占控制环） |
| LAES 租约刷新（BCK） | O(n_dof³) 精确 | O(n_dof²) | 摊薄到 ~1/20–1/50 周期 | ~0.7 ms × 命中率 |
| GEK 漂移打分 | O(d) 轻量 / O(n²) MMD | O(d) | 批检异步 | ~0.01–0.05 ms（缓存查询） |
| GEK 保形查表 | **O(1)** | O(n_cal) | 分位数预计算 | < 0.001 ms |
| LGCS 贪心分配 | O(card(A) log card(A)) | O(card(A)) | 准入/周期边界 | ~0.01 ms |
| EFA-v5 硬门 | **O(1)** | O(1) | — | < 0.03 ms |
| 端到端控制环增量 | — | — | 租约命中率目标 ≥ 95% | **P99 目标 < 0.1 ms** |

**通信开销**：LatC/GEC 仅异常或准入时上报（低频，~数百 B）；FFA Δ_i 追加漂移统计与租约命中率（+~1 KB/站点）；原始感知与校准标签不离站。

**实时性缓解（相对 v4 的实质改进）**：
- 昂贵锚从「每周期全量」改为「租约 + 按需刷新」，把 v4 的 P99 0.8 ms 降到快路径 O(1)，慢路径被摊薄。
- 预算耗尽时不再「丢帧」，而是返回**保守但 sound** 的证书（降级只缩执行集）。
- 租约 TTL 由 margin/rate 自适应：margin 大时少算，margin 小时自动加密刷新（风险自适应）。

## 4. 正确性论证（增量更新）

### 引理 43（证书租约 soundness）

**陈述**：设 t_0 时刻 f_i(x_{t_0})=1，margin m_i = |stat_i − τ_i| > 0，且对 t∈[t_0, t_0+TTL] 有 |d stat_i/dt| ≤ B_i。若 TTL ≤ m_i/(κ_i B_i)，κ_i ≥ 1，则 ∀t∈[t_0, t_0+TTL] 仍有 f_i(x_t)=1。

**证明**：由 Lipschitz 性，stat_i(t) ≥ stat_i(t_0) − B_i(t−t_0) ≥ (τ_i + m_i) − B_i·TTL ≥ τ_i + m_i(1 − 1/κ_i) ≥ τ_i。同理对下侧阈值。∎

**工程含义**：昂贵锚的结论可在 margin 允许的时窗内复用；κ_i 吸收模型误差，κ_i 越大越保守、TTL 越短。

### 引理 44（随时证书的降级 soundness 与单调性）

**陈述**：若所有被使用的租约 valid、所有保守代理满足 g_i^cons ⇒ f_i，则对任意截止 d：(i) A_d(x)=1 ⇒ F(x)=1，即 Exec(A_d) ⊆ Exec(F)；(ii) d_1 ≤ d_2 ⇒ Exec(A_{d_1}) ⊆ Exec(A_{d_2}) ⊆ Exec(F)。

**证明**：(i) 对 i∈S_eval 有 f_i；对 i∈S_lease 由引理 43 得 f_i；对 i∈S_cons 由 g_i^cons ⇒ f_i。故 A_d ⇒ ∧_i f_i = F。(ii) 预算增大只可能把某个保守代理/租约替换为全量评估（更弱、更接近 F），或扩大 S_eval，故执行集单调不减且始终 ⊆ Exec(F)。∎

**工程含义**：延迟只会让系统更保守，不会让系统更冒险；这正式回答了 v4 的「丢帧引入新隐患」。

### 引理 45（泛化硬门的条件风险界）

**陈述**：设校准样本与部署样本在加权后可交换，密度比 w=dQ/dP ≤ W_max，损失 ℓ ∈ [0,L_ℓ]，且 Q 与 P 的 TV 距离 ≤ ρ。取 R_ucb = R_w + W_max√(log(1/δ)/(2n)) + L_ℓ ρ。则当 kc_gen 通过（R_ucb ≤ τ_risk）时，以概率 ≥ 1−δ 有 R_Q(h) ≤ τ_risk。

**证明**：加权经验风险 R_w 是 R_Q 的无偏估计（在 w 已知且可交换时）；由 Hoeffding 不等式，|R_w − R_Q| ≤ W_max√(log(1/δ)/(2n)) 以概率 ≥ 1−δ；协变量漂移项由风险对分布的 Lipschitz 性（TV 距离 × L_ℓ）给出。三项相加即得 R_Q ≤ R_ucb。∎

**诚实声明**：该界**条件于**密度比有界、可交换性、漂移可估。真实开放世界中这些假设会被违反；因此 kc_gen 用 ŝ ≤ τ_shift 先做「假设自检」，一旦检测到超界即 fail-closed，而不是继续宣称保证。任意漂移下的无条件下界是不可能的（no-free-lunch），本锚只承诺「在可证域内保证，在域外拒识」。

### 定理 v5（九硬门收缩、时限安全与泛化退化）

**陈述**：在 v4 假设 (B1)~(B6) 之外追加：(B7) 租约漂移界 B_i 有效、保守代理 sound；(B8) 泛化校准满足引理 45 的可交换性与有界密度比。则：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29（严格，若 kc_lat/kc_gen 非恒真）；
(ii) 对任意截止 d，实际部署执行集 ⊆ 全量认证执行集（时限安全）；
(iii) 若 kc_gen 通过，部署风险以概率 ≥ 1−δ 不超过 τ_risk（条件泛化）；
(iv) 预算越紧或漂移越大，η_lat/η_gen 越小，执行集单调更保守（优雅退化）；
(v) LGCS 在子模增益、模代价假设下达到 (1−1/e)·OPT。

**证明**：(i) v5 在 v4 每条路径上追加 kc_lat 与 kc_gen 合取项，只缩不涨；严格性由两门非恒真保证。(ii) 由引理 44。(iii) 由引理 45。(iv) 由引理 44 的单调性与 η 的定义。(v) 标准子模最大化贪心界。∎

## 5. 实验设计与初步结果（第 5 轮计划；仿真先行）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX（仿真）+ N 台实机 Panda（N=3~5）+ 延迟注入中间件（人为放大 VACK/BCK 计算时间，压测随时降级）+ 分布漂移测试床（光照/摩擦/载荷/物体类别/传感器噪声/人类行为）。
- **对照**：v4-full、v5-full、消融 A1（去租约，每周期全量）、A2（去随时降级，硬实时超时即丢帧）、A3（去 GEK，退回 v4 泛化）、A4（固定 TTL vs 自适应 TTL）、A5（LGCS 贪心 vs 均匀分配）。
- **协议**：
  (a) 延迟压测：1 kHz 控制环，注入 0.5–20 ms 的 VACK/BCK 延迟，测 P99/P99.9、丢帧率、降级等级分布；
  (b) 租约失真注入：故意低估 B_i 20%/50%，测「静默放行」违例率（这是本轮最大风险的直接检验）；
  (c) 分布漂移：协变量漂移（视觉/摩擦/载荷）+ 概念漂移（人类偏好变化），测保形覆盖率、OOD AUROC、kc_gen 误拒/误放；
  (d) 预算-泛化交换：固定 d_budget，扫 LGCS 中「认证 vs 自适应」分配比例，画安全-可用性前沿。
- **指标**：控制环 P99/P99.9 延迟、丢帧率、执行集可用率（accepted rules / total）、安全违例率、租约命中率、保形经验覆盖率 vs 名义覆盖率、OOD AUROC、漂移下任务成功率、ECS_v5 与失败 AUC。

## 7. 本轮最大风险（最终确认）

**一句话**：**租约失真的静默不安全**——把实时性从「算得快」改成「租约 + 随时降级」后，系统不再因丢帧而显性失败，而是可能在漂移界/模型误差被低估时，让已失效却看似有效的旧证书继续放行；这种「看起来一切正常」的隐性失效比 v4 的丢帧更难检测、更难归因。
