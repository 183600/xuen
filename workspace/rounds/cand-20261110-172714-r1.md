# 第 47 轮（承接第 46 轮 v23；本轮灵感：桌面操作 × 共享控制） · SharedDesk：桌面共享控制的权限租约与交接证书（四层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 已把语音、记忆、安全绑定接成闭环，但其隐含假设 H5 是：控制器唯一、指令离散、机器人独占执行权，人类只出现在"指令层"而不进入连续控制环路，桌面仅是语义背景而非几何/接触约束。真实 UniBot 的桌面操作恰好击穿 H5：人机同处一桌，人会手势比划、扶住杯子、捏住机械臂末端随时接管或放手，桌沿/杯壁/线缆/禁入区构成强几何约束，接触力与遮挡不可忽略。两个灵感词精确命中：**桌面操作**把问题从自由空间"感知—规划"改写为受支撑面、边界与接触约束的操作，几何先验强但接触安全风险高；**共享控制**把"谁在控制"从常量变成随时间演化的权限变量 a_t，带来权限租约、无扰切换与责任空窗。二者耦合出的新问题：**当控制权在人机之间连续转移时，姿态证书、能量租约与权限租约如何组成可交接的联合证书，保证切换瞬间不出现"无人负责"的安全空窗，且人的连续输入不会破坏证书的 soundness**。

## 0. 直觉与动机

**灵感 1（桌面操作 → 强几何先验 + 接触安全谓词）**
直觉：桌子是一块"免费的、巨大的标定板"。支撑平面给出重力方向与高度约束，桌沿给出越界禁入区，物体支撑关系给出可抓/可放区域，因而姿态证书可以在桌面坐标系里被显著收紧；但代价是机器人与桌、物、人发生接触，安全不再只是"位姿落在盒子里"，还包括"接触力在可行区间、无穿透、无越界悬空"。因此把桌面可操作契约 D 作为上下文的一部分，把证书从 P_t 收紧为 P_t^D = P_t ∩ Admissible(D)，并把安全谓词升级为位姿 ∧ 接触的合取。

**灵感 2（共享控制 → 权限是带租约的连续变量）**
直觉：共享控制不是"人按一个键接管"的离散事件，而是控制权的连续混合：u_t = a_t·u_R + (1-a_t)·u_H，a_t 是机器人控制份额。谁拥有多少份额必须有租约 ℓ_a 来背书（时限、死手开关、切换速率上限、责任人），否则"我以为你在控制"就是事故的起点。人类意图估计给出 P(i|X_t^H, c_t)，权限仲裁据此决定让权、收权或保持。

**灵感 3（耦合 → 交接必须"双人同时负责"）**
直觉：接力棒不能在两人都松手的瞬间落地。安全的权限切换要求存在长度为 δ_a 的重叠窗口：窗口内旧权限与新权限同时持有有效证书，且两者的可认证集合交集非空；新权限的证书必须覆盖旧证书在人类有界输入下的可达管，否则不允许切换。这样把"责任"做成可连续的 baton，而不是一个瞬时开关。

**耦合升级**：在 v10 四层架构上把根信任层的两条腿（姿态租约 ℓ_p、能量租约 ℓ_e）扩成三条腿，新增权限租约 ℓ_a；L1 几何层引入桌面可操作契约 D 与接触谓词 C_t；L3 CAR 守卫加入权限有效性与"无空窗"条件；L4 DCL 采集交接事件与接触事件。整体称 SharedDesk（共享桌面），保持 v10/v23 全部 IP 不推倒，只在链路上增量插入。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（权限租约与混合控制）**
设权限状态 a_t∈[0,1] 表示机器人控制份额（a_t=1 全机器人，0 全人类，中间为共享）。混合控制输入
u_t = a_t·u_R + (1-a_t)·u_H + u_ff(t)。
权限租约 ℓ_a=(a_t, τ_a, T_hold, v_max, δ_a, owner)。**有效判据**：t-τ_a≤T_hold、死手信号 h_t=1、|ȧ_t|≤v_max。失效 → 进入受控停止（不直接断电），并在 τ_override 内交还人类。

**定义 60（桌面可操作契约与接触谓词）**
桌面契约 D=(Π_support, ∂D_edge, O_occ(t), N_nogo, μ_s, f_min, f_max)，其中 Π_support 为支撑平面，O_occ 为占据集，μ_s 为摩擦。可操作集
Admissible(D)={X∈SE(3) | overhang(X)≤m_edge, dist(X,N_nogo)≥m_ng, contact_force∈[f_min,f_max], ¬penetrate(X,O_occ)}。
桌面收紧证书 P_t^D=P_t∩Admissible(D)。接触安全谓词 C_t=1[接触力与法向稳定且无滑移超界]。

**定义 61（交接联合证书与无空窗条件）**
联合证书 J_t^H=(P_t^D, ℓ_p, ℓ_e, ℓ_a, C_t)。**交接 soundness**：存在重叠窗口 [t_s, t_s+δ_a]，使得 ∀t∈窗口，
P_t^{H∩R}=P_t^{H}∩P_t^{R}≠∅，且安全谓词在位姿与接触两方面同时成立。
**无权限空窗（authority gap-free）**：a_t 连续、|ȧ_t|≤v_max，且窗口内始终存在唯一 owner 或双 owner 的有效租约。否则判定为 gap，触发保守停。

**定义 62（证书继承算子与拒绝回退）**
旧证书 P^H 到新证书 P^R 的继承算子
T_{H→R}(P^H)=Reach_{δ_a}^{u_H∈U_H}(P^H) ⊕ Ball(ε_H) ⊕ Tube(δ_a)。
**继承判据**：P^R ⊇ T_{H→R}(P^H) 才允许交接；否则保持旧权限或回退（abort→hold）。这给出"新控制者必须能覆盖旧证书在交接期一切可能演化"的充分条件。

**定义 63（意图-权限仲裁）**
人类意图分布 P(i|X_t^H,c_t)。仲裁策略
a_t=argmax_{a∈[0,1]} E_{i~P}[TaskProgress(a,i)] - λ_h·Risk_H(a) - λ_r·Risk_R(a)
s.t. J_t^H 满足定义 61 的 no-gap 与定义 62 的继承判据，且人类 override 延迟 ≤ τ_override。
**最小干预原则**：仅当人类意图分布在该区域接近危险（Risk 超阈）时才收权，避免与人类"抢方向盘"。

## 2. 新增产出与既有 IP 升级

**IP-69 ALA（Authority Lease Arbiter）**
- 权限状态机 R→S→H 与死手开关，连续混合 a_t
- 意图估计 → 仲裁 → 收权/让权/保持，带速率上限与超时
- 权限空窗检测：无有效 owner 或租约交叉失败立即受控停

**IP-70 TCC（Tabletop Constraint Certificate）**
- 桌面坐标系标定与支撑面/桌沿/禁入区几何先验
- 占据集 O_occ 在线更新（人移动物体时快速失效旧先验）
- 接触谓词 C_t：力区间、滑移、悬空越界
- 桌面收紧半径 r_ω^D 的条件共形校准

**IP-71 HCT（Handover Cert Transfer）**
- 继承算子 T_{H→R} 的可达管计算
- 重叠窗口调度与 δ_a 自适应
- 交接审计日志：谁在何时持有什么证书、是否发生 gap

**既有 IP 升级**
IP-68 SAB：绑定函数 B 增加权限项，B(v_t,P_t,a_t)；a_t<1 时对共享指令做保守折扣
IP-67 VAD：语音增加权限意图槽位（"我来/你来/停"），输出权限先验
IP-66 MVR：记忆键加入 authority 与 handover outcome，屏蔽曾导致 gap 的记忆
IP-63 ECPS：能量租约在人类接管期转入低功耗保持，深度按权限与桌面先验重调度
IP-61 DCL：采集交接事件、接触力、桌面遮挡样本
IP-62 CCA：新增突袭接管、对抗性人手移动、过期桌面先验红队
IP-51 CAR：守卫加入 ℓ_a 有效性与 C_t，无空窗失败即 fail-closed
IP-45 总线：authority-lease / handover / human-state / contact-event 话题

## 3. 算法骨架（每个控制周期）

1. 读 B_t, ℓ_e, ℓ_p, a_t, ℓ_a, X_t^H, D_t, C_t
2. 估计人类意图 P(i|X_t^H,c_t) 与 override 倾向
3. 计算桌面收紧证书 P_t^D 与接触谓词 C_t
4. 用定义 63 仲裁 a_t^*，检查 no-gap 与继承判据
5. 若需交接：进入 δ_a 重叠窗口，双证书并行，跑 T_{H→R} 覆盖校验
6. 校验通过则切换 owner 并更新 ℓ_a、ℓ_e；否则 hold/abort
7. CAR 用 J_t^H 守卫；任一租约失效或 gap 检测 → 受控停并交还人类

## 4. 本轮最大风险

**一句话**：若把权限交接建模成瞬时开关而忽略重叠窗口，人机双方会同时误以为对方持有证书，形成"责任空窗"，此时人的连续输入又不受姿态证书约束，极易在桌沿或人手附近发生碰撞/越界；因此必须把 ℓ_a 与 ℓ_p、ℓ_e 并列为根信任腿，强制 δ_a 重叠窗口、继承算子覆盖校验，并在检测到任何 gap 或桌面先验过期时受控停而非继续执行。

## 2. 关键算法 伪代码

### IP-69 ALA
```
def authority_arbitrate(X_h, c_t, B_t, a_prev, D_t, calib, dt):
    Pi = human_intent_dist(X_h, c_t, calib)
    best, best_val = a_prev, -inf
    for a in grid(0.0, 1.0, step=0.05):
        if abs(a - a_prev) > v_max * dt:      # 无扰切换速率约束
            continue
        J = expected_progress(Pi, a) \
            - lam_h * risk_human(a, D_t) \
            - lam_r * risk_robot(a, B_t)
        if J > best_val:
            best, best_val = a, J
    if deadman_ok() and lease_valid(ell_a, t+dt):
        ell_a.update(best)
        return best, Pi
    return 0.0, Pi          # 交还人类 / 受控停，不静默继续
```

### IP-70 TCC
```
def admissible(X, D, m_edge, m_ng, f_min, f_max):
    if overhang(X, D.Pi_support) > m_edge:   return False
    if dist(X, D.N_nogo) < m_ng:             return False
    if penetrates(X, D.O_occ):               return False
    if not (f_min <= X.force <= f_max):      return False
    return True

def desk_certify(P, D):
    P_D = P.intersect(Admissible(D))
    C   = contact_predicate(P_D, D)          # 力/滑移/悬空
    if P_D.radius > P.radius + eps:          # 先验与观测冲突
        D_t = mark_stale(D)                  # 强制失效，触发重标定
    return P_D, C
```

### IP-71 HCT
```
def handover_cert(P_h, P_r, U_h, delta_a, eps_h):
    tube = reach_tube(P_h, U_h, delta_a)
    required = inflate(tube, eps_h)          # T_{H->R}(P^H)
    return P_r.covers(required), required

def handover(P_h, P_r, U_h, delta_a, a_t):
    ok, req = handover_cert(P_h, P_r, U_h, delta_a, eps_h)
    if not ok:
        return 'abort_hold', req             # 新控制者无法覆盖 → 保持旧权限
    start_overlap_window(delta_a)
    if both_certs_valid(P_h, P_r, delta_a) and no_gap(a_t, delta_a):
        log_handover(P_h, P_r, delta_a, 'transfer')
        return 'transfer', req
    log_handover(P_h, P_r, delta_a, 'rollback')
    return 'rollback_human', req
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ALA 仲裁 | O(|A|·|Ω|) 每周期 | O(|Ω|) | 死手 + 租约有效 ⇒ a_t 不失控 |
| TCC 判定 | O(|O_occ|) | O(|D|) | P^D 收紧 + 四约束 ⇒ 桌沿/禁入/穿透/力可检测 |
| HCT 继承 | O(|P|·|U_h|·δ_a) | O(tube) | P^R ⊇ T(P^H) ⇒ 交接期证书覆盖 |
| 全局决策 | O(|A|·|Ω|+|M|) | O(|Q|+|M|) | 三租约 + C_t + no-gap ⇒ 无责任空窗 |

正确性定理：设权限仲裁满足定义 59 的租约有效性与速率约束，桌面契约 D 中的支撑面/边界先验在 T_stale 内未过期，且交接满足定义 62 的继承判据。若 ALA 输出 a_t、HCT 在 δ_a 窗口内保持 P_t^{H}∩P_t^{R}≠∅，则全局决策 Π_shared 在窗口内对任意人类有界输入 u_H∈U_H 均满足 X_t∈P_t^D 且 C_t=1；任一条件不成立时 Π_shared 返回 controlled_stop 或 rollback_human，不会继续执行。故共享控制闭环在交接期保持 fail-closed。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 权限交接无空窗 | gap 发生次数；交接延迟 | gap = 0；延迟 ≤ 100 ms |
| E116 桌面证书覆盖 | 经验覆盖率；桌沿越界次数 | 覆盖 ≥ 98%；越界 0 次 |
| E117 接触安全 | 力超界率；滑移检出率 | 超界 0；检出 ≥ 95% |
| E118 意图-权限仲裁 | 误收权率；任务完成率 | 误收权 ≤ 5%；完成 ≥ 95% |
| E119 继承算子 soundness | 经验覆盖；回退率 | 覆盖 ≥ 1-α；回退 ≤ 3% |
| E120 100h 桌面共享闭环 | 人接管成功率；碰撞次数 | 接管 ≥ 99%；碰撞 0 |

回退策略：E115 出现任何 gap → 退化为纯人类控制 + 机器人零力随动；E116 越界 → 收紧 m_edge / m_ng 并重标定桌面；E118 误收权 > 10% → 提高 λ_h、退到最小干预；E119 覆盖不足 → 增大 δ_a 或 ε_H 直至覆盖达标。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 权限交接瞬时化导致责任空窗 | 高 | 强制 δ_a 重叠窗口 + no-gap 检测 + 受控停 |
| 桌面先验过期（人移动物体） | 高 | O_occ 在线更新，P_D 半径膨胀即判 stale 并重标定 |
| 人手输入超界破坏证书 | 高 | 继承算子按 U_H 可达管膨胀；超界即 rollback_human |
| 意图误判导致误收权 | 中 | 最小干预原则 + λ_h 惩罚 + 语音/手势二次确认 |
| 交接期能量/算力抖动 | 中 | ℓ_e 与 ℓ_a 联合更新，接管期转低功耗保持 |
| 共享期绑定函数 B 过于乐观 | 中 | a_t<1 时对 B 做折扣，θ_safe 随 a_t 收紧 |

## 6. 本轮最大风险

**一句话**：把权限交接当成瞬时开关会使机器人误判"人已接管"而放松守卫、同时人也误判"机器人仍在负责"而加大动作，形成责任空窗并在桌沿或人手附近碰撞；因此必须以 ℓ_a 与 ℓ_p、ℓ_e 并列作为根信任腿，强制重叠窗口与继承覆盖校验，任何 gap 或桌面先验过期立即受控停并交还人类，而不是继续执行。
