# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「能耗优化」×「专利布局」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**能量预算化 + 声索预算化 + 同源证据治理**。两个灵感表面分属物理与法律两个宇宙，深层却是同一结构：**在硬底线下分配稀缺预算**。能量以焦耳计，专利以声索范围计；两者都不能平摊，都必须给安全关键模块留不可剥夺的保底。本轮要求二者共用 v9 的贡献归因 c_m 作为唯一证据源，但**必须做视界分离**，否则短期能耗归因会误杀长期专利价值。

## 0. 直觉与动机

**灵感 1（能耗优化 → 能量预算治理）**
直觉：v9 已把"算力预算"写进契约中间件（ΣŴ_m ≤ 20ms），但算力只是能量的代理变量——真正约束续航的是焦耳与热，不是毫秒。更危险的是 v9 只会"少算"，不会"按能量优先级算"。核心创新：**能量预算治理器（EnergyBudgetGovernor, EBG）**：把契约扩成能量契约 κ_m^E=(e_m^max, P_m^idle, f_m^min, ρ_m)，引入 DVFS 的"频率–能耗–WCET"帕累托位，给动作块加**能量证书** Ê_t ≤ E_slack(t)——必须留够返航/安全停驻的能量，而不是只留刹车距离。关键安全设计：**能量保底域**——安全关键模块挂独立功率域，任何降频/降功耗不得触碰；SoC 低于返航阈值时只削减非安全模块。把"能量"从 E560 的一个指标升格为**与 M₀ 并列的可行性约束**。

**灵感 2（专利布局 → 声索预算治理）**
直觉：研究循环每轮都在公开产物——我们自己就是自己的 prior art。若不明确定义"先申请还是防御性公开"，第 9 轮公开的 ACMD 会反过来破坏第 10 轮增量的新颖性。核心创新：**声索预算治理器（ClaimBudgetGovernor, CBG / PatentLayoutPlanner）**：给每个 IP 建主张树（独立项 + 从属项），用三元组 (N_m 新颖性, S_m 创造性, A_m 实用性) 与撞车概率 p_art 评估；在申请预算 B_claim（声索单元×成本）下做**预算约束下的子模覆盖最大化**，输出 file / file-narrow / defend / drop 四态决策。关键纪律：**安全关键 IP 不得因"显然"被降级放弃**，必须走人工法务复核；**公开前先算撞车**，把"自公开＝自毁新颖性"变成显式约束。

**灵感 3（两者的深层同构 → 同源证据与视界分离）**
直觉：能耗与专利不是两个模块，而是同一个 **BudgetGovernor** 抽象的两个实例——物理预算（焦耳/热）与法律预算（声索范围/申请费），都受硬底线保护，都呈帕累托权衡：DVFS 是"省能↔实时"，专利是"宽声索↔易无效/易规避"。二者共享 v9 ID 的贡献信号 c_m，但**时间视界不同**：能量是秒级/任务级，专利是年级/跨域。若直接用短期 c_m 同时驱动两者，一个"当前域闲置"的模块会同时被降频降功耗与被放弃声索，当域切换时系统恰好失去最该保留的东西——这是本轮的核心风险，也是"视界分离"设计的由来。核心创新：**同源分配器（CommonProvenanceAllocator, CPA）**：c_m^short 管能量、c_m^long 跨域管声索；frozen 触发"复核"而非"放弃"。

## 1. 研究问题（轮次升级版）

- **Q1（能量证书与返航可行性）**：如何把"能量最优"与"安全停驻/返航"耦合，使能量证书像块证书一样可局部验证？DVFS 降频抬高 WCET，会不会反噬 v9 的截止期守恒、制造新的虚假退化风暴？
- **Q2（声索组合与自公开）**：在"本循环持续公开"的约束下，如何形式化新颖性/创造性/可规避半径，使组合覆盖在预算下可近似最优，且不因短期贡献低而误弃安全关键或长期高价值 IP？
- **Q3（同源证据的视界分离）**：共享 c_m 的证据治理在什么条件下既避免"指标各自为政、各自被 Goodhart 化"，又不让短视归因造成"能耗＋声索双重饥饿"？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 能量保底律（Reserved-Energy Floor, EBG）**
安全关键模块独立功率域 + 返航能量下限；任何 governor 只能削减保底集之外的预算。DVFS 频率必须落在可行集 F_m = {f : Ŵ_m(f) ≤ D_m − slack_chain}；F_m 为空则强制 f=f_max，绝不以超时换省能。

**P14 声索保底律（Reserved-Claim Floor, CBG）**
φ^elig=false 的安全关键 IP 强制保留独立项；低 c_m 只允许"降级为从属项/防御性公开"，不得"放弃"。公开前做撞车检查（自公开防火墙）。

**P15 同源视界分离律（Common Provenance, Horizon-Separated, CPA）**
单一证据源 c_m，但两个积分视界（T_E ≪ T_P）；短视界不得写回长视界；跨域 frozen 只触发"声索复核"，不触发 drop。

## 3. 与基线的接口（如何退化）

- EBG 失效（能量契约/证书不可用）⇒ 恒定频率＋默认功率计划、能量证书忽略，等价 v9；
- CBG 失效（声索评估不可用）⇒ 全 IP 走"先公开后人工复盘"，不自动放弃，等价 v9 的纯叙事式 IP 清单；
- CPA 失效（同源协调不可用）⇒ 能量用 c_m^short、专利回退人工法务，二者解耦，等价 v9 + 人工；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 引理 83/84 逐级退回；
- 全部失效 ⇒ 退回 v8 / v7 / v6。

## 4. 预期贡献

1. **能量证书 + 返航可行性能量预算 + DVFS 帕累托位**：把能耗从"一个 KPI"升格为一等可行性约束，并把降频对截止期的影响纳入可验证条件；
2. **声索预算治理**：主张树 + 专利性三元组 + 预算子模覆盖 + 自公开防火墙，把"专利布局"从法务事后工作前移为在线决策；
3. **同源视界分离**：一个证据源、两套预算、四态决策，附"防双重饥饿"的形式条件；
4. **E571–E590** 覆盖能量/热/返航、专利检索/盲评/规避红队/申请时点，以及端到端任务与组合完整性审计。

## 5. 本轮最大风险

**一句话**：用短期能耗归因 c_m 同时驱动降功耗与声索取舍，会把"当前域闲置"误判为"长期无价值"——模块在被降频的同时被放弃声索，域切换时系统恰好失去它最该保留的能力。

## 1. 符号体系增量（定义 540–547）

**新增定义 540（能量契约 EnergyContract）** 每模块在契约表 535 基础上追加 κ_m^E=(e_m^max, P_m^idle, f_m^min, ρ_m)。部署期双重约束：
```
Σ_m e_m^max / T_cycle ≤ P_budget                      （总功率预算）
Σ_{m∈F} e_m^max / T_cycle ≤ P_floor_budget           （独立功率域保底预算）
```
弹性集 E = {m : ρ_m=elastic} 可被压缩到 0（dormant 或降频）；保底集 F 只读不写。

**新增定义 541（能量证书 EnergyCertificate）** 由前向模型 F̂ 顺带预测块内功耗轨迹 P̂，定义
```
Ê_t = Σ_{k=1}^{K} P̂(a^k, s^k)·Δt + β_E
证书有效 ⇔ Ê_t ≤ E_slack(t) = SoC(t)·C_batt − E_return(t) − E_stop(t) − E_reserve
```
与块证书 533 合并为**双分量证书** Ĉ_t = (ĝ_min, ê_max, γ̂_grasp ; Ê_t)。二者必须同时成立，缺一即视作证书失效（触发 K_eff←1 或中止）。β_E 由 E573 标定（块内功耗预测误差上界 ×1.2）。

**新增定义 542（频率–能耗–WCET 帕累托位 DVFS Pareto）** 对 f ∈ [f_m^min, f_m^max]：
```
e_m(f) ≈ α_m·f³ + β_m·f + γ_m      （动态 + 静态；实测非理想缩放）
Ŵ_m(f) = Ŵ_m(f_max)·f_max / f      （理想缩放，实测加修正项）
F_m = { f : Ŵ_m(f) ≤ D_m − slack_chain }
f_m* = argmin_{f ∈ F_m} e_m(f)；若 F_m = ∅ ⇒ f_m* = f_max（保底）
```
引理 87 证明：只要频率取自 F_m，降频不新增超时，v9 的 50Hz 守恒保持。

**新增定义 543（能量保底域 Reserved-Energy Floor）** 保底集 F（含 EBG 自身）挂独立功率域，governor 对其只读。SoC 三区策略：
```
SoC ≥ S_hi            : 全弹性（可降频、可 dormant）
S_lo ≤ SoC < S_hi     : 收缩弹性集（先 dormant 后降频，按 ρ_m 与 c_short 排序）
SoC < S_lo            : 关闭全部弹性，保底集 + 返航，任务降级到安全停驻
```
保底域的存在使"省能"永不消耗安全裕度（P13）。

**新增定义 544（主张树 ClaimTree）** 每个 IP m 的主张树 T_m=(c_m^0,{c_m^j})：独立项 c_m^0 覆盖最宽（必要技术特征集 F0），从属项 c_m^j 逐层加限定。每项标注：宽度 b、无效风险 v、**可规避半径 r**（红队用替代技术绕开所需的最小改动量）。从属项是"退守阵地"，用于在独立项被无效时保存部分覆盖。

**新增定义 545（专利性三元组 Patentability Triple）** (N_m, S_m, A_m) ∈ [0,1]³：N_m 新颖性 = 1 − 最近现有技术撞车度；S_m 创造性（非显然性）；A_m 工业实用性。撞车概率 p_art(m) 由检索给出。可申请度 Q_m = N_m·S_m·A_m·(1−p_art)。**纪律**：φ^elig=false 的安全关键 IP 令 S_m 下界 0.5（安全机制组合通常具非显然性，须人工确认），不得因 Q_m 低自动降级。

**新增定义 546（声索预算与四态决策 ClaimBudget）** 总预算 B_claim（声索单元×单价）。决策 x_m∈{file, file-narrow, defend, drop}，覆盖效用
```
U(x) = Σ_m u_m(x_m)
u_m(file)        = w_e · c_m^long · Q_m
u_m(file-narrow) = 0.6 · u_m(file)
u_m(defend)      = δ_prior            （阻止他人申请的防御价值）
u_m(drop)        = 0
约束：Σ_m cost_m(x_m) ≤ B_claim；且 ∀m∈F_safety: x_m ∈ {file, file-narrow}  （P14 保底）
```
u 关于选择集单调子模（覆盖边际递减）；带保底下界约束的预算背包。保底先行，剩余预算在弹性集上做子模贪心（引理 91 给近似界）。

**新增定义 547（同源视界分离 CommonProvenance / Horizon Separation）**
```
c_m^short(t) = EMA_{T_E}( 归一化能耗当量贡献 )        → EBG（降频/dormant 排序）
c_m^long(t)  = max_{d ∈ 已见域} EMA_{T_d}( 任务进展贡献 )  → CBG（声索价值）
写回规则：c_long 只增不减，除非离线证据；frozen 状态只触发「声索复核」事件，不触发 drop。
分离条件：T_P/T_E ≥ κ_h，且 c_long 按域分层聚合（分层 max / 上分位），非全局平均。
```

## 2. 形式化定义（要点与升级）

## 3. 关键算法骨架

```python
# IP-357 EnergyBudgetGovernor：能量预算治理器
class EnergyBudgetGovernor:
    def __init__(self, energy_contracts, S_hi, S_lo, beta_E=0.05):
        self.c = energy_contracts                 # m -> (e_max, P_idle, f_min, rho, D_m)
        self.S_hi, self.S_lo, self.beta_E = S_hi, S_lo, beta_E

    def feasible_freqs(self, m, chain_slack):
        D = self.c[m].D_m
        return [f for f in self.grid(m)
                if wcet_at(m, f) <= D - chain_slack]

    def choose_freq(self, m, soc, chain_slack):
        if self.c[m].rho == 'floor' or soc < self.S_lo:
            return self.c[m].f_max                 # 保底：永不为此降频
        Fm = self.feasible_freqs(m, chain_slack)
        if not Fm:                                 # 可行集空 → 不牺牲截止期
            return self.c[m].f_max
        return min(Fm, key=lambda f: energy_at(m, f))

    def energy_certificate(self, pred, soc, e_return, e_stop):
        E_hat = sum(pred.power) * DT + self.beta_E
        E_slack = soc * C_BATT - e_return - e_stop - E_RESERVE
        return E_hat <= E_slack, E_hat, E_slack

    def govern(self, soc, modules, c_short):
        if soc >= self.S_hi:
            mode = 'full'
        elif soc >= self.S_lo:
            mode = 'elastic_shed'
        else:
            mode = 'return'
        plan = {}
        for m in modules:
            if self.c[m].rho == 'floor':
                plan[m] = ('keep', self.c[m].f_max)
            elif mode == 'return':
                plan[m] = ('off', None)
            elif mode == 'elastic_shed':
                # 先休眠低贡献弹性模块，再对剩余模块降频
                plan[m] = ('dormant' if c_short[m] < TAU_SHED
                           else 'dvfs', self.choose_freq(m, soc, CHAIN_SLACK))
            else:
                plan[m] = ('dvfs', self.choose_freq(m, soc, CHAIN_SLACK))
        return mode, plan


# IP-358 ClaimBudgetGovernor / PatentLayoutPlanner：声索预算治理器
class ClaimBudgetGovernor:
    def __init__(self, prior_art_db, B_claim, tau_N=0.5):
        self.db, self.B_claim, self.tau_N = prior_art_db, B_claim, tau_N
        self.filed = set()

    def novelty(self, m):                          # 定义 545
        nearest = self.db.nearest(m.claim_features)
        return 1.0 - nearest.collision, nearest

    def patentability(self, m, red_team):
        N, art = self.novelty(m)
        S = red_team.inventive_step_score(m)       # 盲评/模拟审查员
        A = m.industrial_applicability
        Q = N * S * A * (1.0 - art.collision)
        return Q, (N, S, A), art

    def pre_publish_gate(self, m):
        """自公开防火墙：公开前必须已申请或转防御性公开（引理 92）"""
        if m in self.filed:
            return 'ok'
        N, art = self.novelty(m)
        if N < self.tau_N:
            return 'file-first'                    # 撞车但可通过从属项区分
        return 'defend-or-file'

    def allocate(self, ips, c_long, red_team):
        forced = [m for m in ips if not m.distill_eligible]   # P14 保底
        budget = self.B_claim - sum(cost(m, 'file') for m in forced)
        chosen = {m: 'file' for m in forced}
        elastic = [m for m in ips if m.distill_eligible]
        # 保底先行后，在弹性集上做预算子模贪心（单位成本 → 1-1/e）
        ranked = sorted(elastic,
                        key=lambda m: (c_long[m] * self.patentability(m, red_team)[0]
                                       / max(cost(m, 'file'), 1e-9)),
                        reverse=True)
        for m in ranked:
            Q = self.patentability(m, red_team)[0]
            if Q <= 0 or c_long[m] < TAU_CLAIM:
                chosen[m] = 'defend' if Q > 0 else 'drop'
            elif budget >= cost(m, 'file'):
                chosen[m] = 'file'; budget -= cost(m, 'file')
            elif budget >= cost(m, 'file-narrow'):
                chosen[m] = 'file-narrow'; budget -= cost(m, 'file-narrow')
            else:
                chosen[m] = 'defend'
        return chosen

    def review(self, m):
        """frozen 触发的复核：只升不降，绝不因短期低贡献 drop（定义 547）"""
        if m not in self.filed and not self.contracts[m].distill_eligible:
            return 'mandatory-file-review'
        return 'defer'


# IP-359 CommonProvenanceAllocator：同源证据 + 视界分离
class CommonProvenanceAllocator:
    def __init__(self, eb, cb, T_E=60, T_P_domains=8, kappa_h=50):
        self.eb, self.cb = eb, cb
        self.T_E, self.T_P, self.kappa_h = T_E, T_P_domains, kappa_h
        self.cs, self.cl = defaultdict(float), defaultdict(float)
        self.domain_ema = defaultdict(dict)        # m -> domain -> ema

    def update(self, m, j_progress, e_cost, domain):
        self.cs[m] = 0.9*self.cs[m] + 0.1*normalize_energy(j_progress/e_cost)
        d = self.domain_ema[m]
        d[domain] = 0.9*d.get(domain, 0.0) + 0.1*normalize(j_progress)
        # 长视界：跨域分层 max，只增不减（定义 547）
        self.cl[m] = max(self.cl[m], max(d.values()))

    def step(self, ctx):
        self.eb.set_priority(self.cs)              # 能量用短视界
        self.cb.set_value(self.cl)                 # 声索用长视界
        for m, st in ctx.distill_state.items():
            if st == 'frozen':
                self.cb.review(m)                  # 复核，不是放弃
```

## 4. 推导

**引理 87（DVFS–截止期守恒）** 若模块 m 的频率取自 F_m={f: Ŵ_m(f) ≤ D_m − slack_chain}，则其 WCET 满足链式截止期；若 F_m=∅ 则强制 f=f_max。故 EBG 的降频不新增任何超时，v9 引理 86 的 50Hz 守恒（每周期 ≤ 感知 2ms + 决策 20ms）保持。证明：由 F_m 定义直接得 Ŵ_m(f) ≤ D_m − slack_chain；链上各模块的松弛相加不超过 slack_chain；保底分支不改变 WCET。∎

**引理 88（能量证书安全性）** 设块内功耗预测误差 |P̂−P| ≤ β_E，则 Ê_t ≥ 真实块能耗；若 Ê_t ≤ E_slack(t)，则执行整块后 SoC·C_batt − 实际耗能 ≥ E_return + E_stop + E_reserve，即仍可安全返航或停驻。证明：Ê 为真实能耗上界；E_slack 定义已扣除返航、停驻与冗余三项，剩余不等式即所需结论。∎

**引理 89（能量保底安全不变式）** 对任意 SoC 与任意 governor 策略，保底集 F 的模块恒取 f_max 且功率域不掉电；弹性收缩只作用于 E=F^c；SoC<S_lo 时仍保留 F+返航。故省能不改变 M₀/SpatialCert/FaultCert/MW/AC 守卫的行为，安全性等价 v9。证明：定义 543 对 F 只读不写；三区策略的 return 分支仍优先保底集与返航。∎

**引理 90（视界分离防双重饥饿）** 若 c_m^long 按域分层取 max、只增不减，且 frozen 只触发复核，则对任意在某个已见域 d 使贡献 ≥ε 的模块 m，不会因当前域 c_m^short < τ_off 而被 drop；其能量可短期 dormant，但声索决策保留（file / file-narrow / defend）。证明：drop 需 CBG 的 x_m=drop 且 m∉F_safety；CBG 用 c_long，而 c_long ≥ 域 d 的分层贡献 ≥ ε，不因单域短视界低值而被淹没；frozen 分支仅 review，不置 drop。∎

**引理 91（声索组合的近似最优）** 覆盖效用 u 单调子模。保底集强制 file 后，弹性集上的预算背包：单位成本用密度贪心得 U ≥ (1−1/e)·OPT；一般成本用 Sviridenko 式部分枚举（枚举 ≤3 个元素）+ 贪心，仍得 (1−1/e)·OPT，代价 O(n³)。证明：标准子模最大化结果（无成本为 (1−1/e)，预算背包经部分枚举恢复同一比值）；保底项固定不改变弹性子问题的子模性。∎

**引理 92（自公开防火墙保持新颖性）** 若每个 IP 在公开前经 pre_publish_gate：未申请且撞车度超阈则 file-first 或转防御性公开，则本循环后续公开不会以"自己的在先公开"破坏该 IP 的新颖性（针对未公开增量）；已公开项的首次公开日锁定其新颖性，后续增量必须含与已公开内容可区分的必要特征。证明：新颖性以最早公开/申请日为界；防火墙把"公开"排在"申请"之后或将公开转为防御性（放弃独占但不产生阻碍他人的新颖性破坏）。∎

**引理 93（退化等价 v9）** EBG 失效 ⇒ 恒定频率、能量证书旁路；CBG 失效 ⇒ 声索转人工；CPA 失效 ⇒ 短/长视界解耦。三种情形下系统可观测行为与 v9 逐位等价（能量仅多一条被忽略的证书检查、声索仅多一份离线报告）。∎
