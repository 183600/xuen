# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「虚实迁移」×「竞品分析」）

> R68 用「在线标定 + 自监督 + 单模型多任务」把测量可信度装进了闭环，但它自陈的风险是范式级的：**慢故障与慢漂移在真实流里同频、同幅、同向，物理上不可辨识**。COF 的速率限制器只挡住了「快于 ω_cal」的故障；恰好落在标定带宽之内的缓变故障（渐进老化、慢泄漏、缓慢松动）会被 COF 当漂移「标好」，CFA 把 H_cal 后验推高——**标定能力越强，缓变故障越隐形**。这不是参数没调好，而是「只用真实流做辨识」的信息论下界（引理 16）。
>
> 本轮两个灵感恰好从「信息」与「决策」两侧补洞：
>
> - **虚实迁移不是数据增强，而是辨识性的来源**：真实世界不允许你做「同一轨迹、一个注入漂移、一个注入故障」的对照实验（不能为了标定故意弄坏机器人），但仿真可以。反事实孪生对给出真实流永远给不出的**方向性证据**——迁移的不是参数，而是「漂移轴 ⊥ 故障轴」这个**解耦结构**。
> - **竞品分析不是「我最好」，而是「我何时会输、我和对手差在哪」**：把每个解释假设当成一个竞品，用 held-out 反事实「竞价」，后验 = 市场份额；当两个竞品打平（不可辨识），系统不许强行选赢家，必须判「测量可疑」→ 收紧。再引入「廉价竞品」（经典阈值 / SPC / RLS）作金丝雀：当高级模型说没事、廉价竞品说有事，**分歧本身就是故障信号**。
>
> 核心命题：
>
> **用反事实仿真获得「可辨识的方向」，用竞品集市获得「不可辨识时的保守」，用迁移差账本防止盲信仿真——RIVAL-RAS（Real-sim Identifiability via Virtual counterfactuals + Attribution League）。**
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「**我的『准』是真的准，还是我把故障标成了准**」——不可辨识时，系统拒绝自证清白。

## 0. 直觉与动机

**灵感 1（虚实迁移 → 辨识性来自对照，不来自数据量）**
直觉：为什么真实数据再多也分不开慢漂移和慢故障？因为两者在真实观测上诱导的分布几乎相同——把传感器零点慢慢推 0.1% FS，和把执行器慢慢松动导致读数偏 0.1% FS，在只有一条真实时间序列时是同一件事。数据量解决的是「估计精度」，解决不了「结构性混淆」。仿真能提供的是**干预（intervention）**：在数字孪生里固定场景、固定动作、固定随机种子，生成 ξ^drift 与 ξ^fault 两条只在因果源上不同的孪生轨迹。这就是因果推断里的 do-算子：P(y | do(drift)) 与 P(y | do(fault))。有了对照，才谈得上把「漂移轴」与「故障轴」掰开。
但直接迁移有陷阱：仿真里学到的**幅度 / 参数**迁移到真实一定错（reality gap）。所以只迁移**结构**——漂移发生时哪些观测按什么**方向**协同变化（轴），故障发生时又是什么方向；这两个方向在域间应当近似不变（A95）。用 IRM / 因果迁移约束轴不变，用 TGL 账本量化残余 gap，gap 大就降权，绝不盲信。

**灵感 2（竞品分析 → 把假设变成必须自证的竞争者）**
直觉：R68 的 CFA 是「先标定后归因」，本质是让标定假设先手、故障假设后手——先手优势会让标定吸收一切。竞品分析的第一课是：**没有永远正确的竞品，只有当下的市场份额**。把 H_cal、H_fault、H_model、H_real 四个内部竞品放进一个集市，每个竞品用「在 held-out 反事实上的预测得分」竞价，市场份额 = 贝叶斯模型平均后验；谁预测得准谁份额高，而不是谁先验高谁赢。
第二课更关键：**竞品打平 = 市场无结论**。慢漂移竞品与慢故障竞品在真实流上预测几乎一样（引理 16），份额接近 50/50——此时正确动作不是「取 argmax 勉强选一个」，而是承认「不可辨识」，触发保守升级（λ ↑、k ↓、不放行）。R68 的失败正是把 50/50 的平局当成了标定方险胜。
第三课：**引入廉价竞品当金丝雀**。经典阈值 / SPC / RLS 这些「土办法」不校准、不学习，所以它们对缓变故障反而更敏感（不会把故障解释掉）。当花哨模型（份额高）与廉价竞品（份额低）产生大分歧，这个分歧本身就是「高级模型可能正在自我合理化」的证据。

**灵感 3（合流 → RIVAL-RAS 五组件）**
1. **CTD Counterfactual Transfer Disentangler**：孪生对照 + IRM + 轴不变，输出解耦三元 (δ̂, φ̂, η̂)；
2. **CEM Competitive Explainer Market**：内外部竞品竞价，市场份额 w，tie / 分歧检测；
3. **UAC Unidentifiability-Aware Conservatism**：tie / 分歧 → 只收紧不放宽，带滞回；
4. **TGL Transfer Gap Ledger**：量化仿真结构在真实的残余偏差，超界则下调仿真先验并回退 R68；
5. **RAS-WM† 继承核**：R68 的 MTM / SSG / COF / CFA / CAC 全保留，CFA 升级为「先辨识后归因」，阈值由 tie / TGL 二次重参数化。

**灵感 4（对 R68 风险的对症下药）**
- **慢故障被吸收**：CTD 给出故障轴方向证据；CEM 让「故障竞品」借廉价金丝雀持续发声；UAC 把 tie 判成不可辨识而非标定胜出；
- **盲信仿真**：TGL 超界 → 仿真先验降权 + UAC 灵敏度提高，仿真不得单独定罪（不变式 v）；
- **仿真负迁移**：CTD 只迁轴不迁幅；若轴在真实上不稳定（E288 监测角度漂移），退回 R68 的纯在线标定模式；
- **决策抖动**：tie 触发的是单调收紧，有滞回（hysteresis），不会在阈值附近来回横跳。

## 1. 形式化定义（增量：定义 293–305）

**定义 293（RIVAL-RAS 总览）** RIVAL-RAS = (CTD, CEM, UAC, TGL, RAS-WM†)。在 R68 三不变式之上加两条：
(iv) **不可辨识即保守**：tie 或大分歧 ⇒ λ_risk 单调不降、k 单调不增；
(v) **仿真不得单独定罪**：CTD / TGL 只提供方向与结构证据，任何 H 的后验不得仅由仿真证据越过判定阈，真实证据权重须占多数（α_sim < 0.5）。

**定义 294（反事实孪生对）** 对仿真轨迹 ξ，构造 (ξ^cal, ξ^fault)：除因果源外完全相同（同场景、同动作、同随机种子），且**难分匹配**——|c| ≈ |f|、ω_c ≈ ω_f、注入时刻相同。目的不是造容易的例子，而是造真实流里最易混淆的例子（辨识性压力测试）。另构造 ξ^real（环境真变）、ξ^model（模型漂移）作为其余竞品的对照。

**定义 295（解耦编码器与因果轴）** E_ψ: obs_{1:t} → (δ̂, φ̂, η̂) ∈ ℝ^{d_δ}×ℝ^{d_φ}×ℝ^{d_η}，分别对应漂移 / 故障 / 混淆（真变+模型漂移）坐标。轴学习目标：
- **交叉投影惩罚** L_sep = ‖Proj_φ(δ̂(ξ^cal) − δ̂(ξ^fault))‖² + ‖Proj_δ(φ̂(ξ^cal) − φ̂(ξ^fault))‖² − λ_s·(‖Δδ̂‖² + ‖Δφ̂‖²)（漂移只在 δ 轴变、故障只在 φ 轴变）；
- **域不变** L_irm = Σ_d ‖∇_{w=1} R_d(w)‖²（IRMv1）约束轴预测器跨仿真域不变；
- **轴不变** L_axis = 1 − cos(a_δ^sim, a_δ^probe) + 1 − cos(a_φ^sim, a_φ^probe)，其中 a^probe 由**真实微探针集**给出：在测试台上安全注入亚阈值微漂移（0.1% FS）与可逆微故障，只用于标定轴方向，不用于训练分类器。

**定义 296（竞品集市 CEM）** 竞品集合 K = {E_cal, E_fault, E_model, E_real} ∪ {C_spc, C_rls, C_sim}。每个竞品 k 对下一残差给预测分布 p_k(r_{t+1} | history)。市场份额：
w_k ∝ π_k · exp(−λ_mkt · S_k)，S_k = held-out 反事实 / 回放上的累积对数损失（proper scoring rule），在线 EWMA 更新以适配非平稳。w ∈ Δ^{K−1}。

**定义 297（tie 与分歧检测）**
- **tie**：max_k w_k < τ_share（默认 0.45）或 top-2 预测 KL < ε_tie；
- **分歧**：D_ext = max_{C∈外部} KL(p_{E*} ‖ p_C)，E* = argmax w；
- 任一触发 ⇒ 不可辨识旗标 u_tie = 1。

**定义 298（UAC 保守升级）** u_tie = 1 时：λ_risk ← max(λ_risk, λ_tie)，λ_tie = 0.85；k ← min(k, k_tie(U))；后验不坍缩到单一 H，保留 (H_cal, H_fault) 未决集并送 AuditBuf / 人工。带滞回：u_tie 持续 ≥ T_hold 才升级，份额回落 < τ_share − h 才解除（防抖）。

**定义 299（迁移差账本 TGL）** TGL = sup_{δ,φ} |P_real(y | δ, φ) − P_sim(y | δ, φ)|，用真实微探针 + 仿真同条件估计（TV / KL 上界）。仿真先验权重 α_sim(TGL) = α_sim⁰·exp(−γ_g·TGL)，且 α_sim ≤ 0.5（不变式 v）。若 TGL > τ_gap：CTD 降级为「仅参考」，CFA 回退 R68 在线标定先验，τ_share 下调（更易触发 tie）。

**定义 300（先辨识后归因 CFA-2）**
P(H, E | evidence) ∝ p(ρ | H, ĉ, δ̂, φ̂)^{1−α_sim} · p_sim(H | δ̂, φ̂)^{α_sim} · p(face | E, ĉ) · P(H) · P(E | H)。
p_sim 只给方向先验，α_sim 受 TGL 限制；若 u_tie = 1，后验按最坏情况保持 (H_cal, H_fault) 二值未决，不产生用于放行的单一 argmax。

**定义 301（阈值二次重参数化 CAR-2）** 在 R68 CAR 之上：τ_wm ← τ_wm·(1 + κ_tie·u_tie)（不可辨识 → 一致性检验更敏感，防漏报）；τ_risk ← τ_risk·(1 − κ_tie·u_tie)（更保守）；λ_floor ← max(λ_floor^R68, λ_tie·u_tie)。**方向差异**：R68 的 U（标定不确定）是「放宽一致性 + 收紧风险」；R69 的 u_tie 是「收紧一致性 + 收紧风险」——因为 tie 意味着「有故障竞品在叫」，不能放宽。

**定义 302（竞品金丝雀界）** 若廉价竞品对故障类有功效 β_base，解耦竞品有功效 β_ctd，则分歧检测下的联合检出功效 ≥ 1 − (1−β_base)(1−β_ctd)（两竞品错误弱相关假设 A96）。这给「廉价竞品」正式地位：它是覆盖 CTD 盲区的独立证据源。

**定义 303（J_RIVAL 证书）** J_RIVAL = (J_CALM, axis_hash, tgl, tie_flag, competitor_share_vec, rival_ver)。Valid ⇔ Valid(J_CALM) ∧ tgl ≤ τ_gap^hard ∧ (u_tie = 0 ∨ 已升级保守) ∧ 不变式 (iv)(v)。

**定义 304（管线）** 离线：仿真生成反事实孪生集 → 训练 CTD（轴分离 + IRM）→ 真实微探针标定轴方向 → 初始化竞品份额。在线：CTD 前向 → CEM 更新份额 → u_tie / TGL → CFA-2 / UAC → 继承 R68 的 CAC 提交（其 canary 关新增慢故障用例）。

**定义 305（慢故障 canary 用例）** CAC 第五关扩充：除快变 canary 外加入「慢故障 canary」——在影子回放注入 ω_f ≤ ω_cal 的故障，要求提交后模型对该 canary 的检出率不低于提交前；否则视为「新适配器让慢故障更隐形」，一票否决。直接封堵 R68 风险里「CAC 金标集未覆盖慢故障模式」。

## 2. 关键算法骨架

```python
# IP-253 CTD：反事实孪生解耦（离线训练，在线只前向解耦头）
class CounterfactualTransferDisentangler:
    def build_pairs(self, sim_rollout):
        base = sim_rollout.sample()
        return [(inject_drift(base, c), inject_fault(base, f))   # 难分匹配
                for c, f in matched_magnitudes(base)]            # |c|≈|f|, ω≈ω

    def train(self, pairs, probes):
        for xi_cal, xi_fault in pairs:
            d = self.enc(xi_cal); f = self.enc(xi_fault)
            L = self.sep(d.delta, f.delta, d.phi, f.phi)          # 交叉投影惩罚
            L += self.irm_penalty(pairs)                          # 轴预测器域不变
        L += self.axis_align(probes)                              # 真实微探针标轴
        return L

    def forward(self, obs):                                       # 在线 ~0.1ms
        return self.enc(obs)                                      # (δ̂, φ̂, η̂)


# IP-254 CEM：竞品集市（份额 = 贝叶斯模型平均后验）
class CompetitiveExplainerMarket:
    COMPETITORS = ['E_cal', 'E_fault', 'E_model', 'E_real',
                   'C_spc', 'C_rls', 'C_sim']

    def update(self, history, r_next):
        for k in self.COMPETITORS:
            self.score[k] = ewma(self.score[k], log_loss(self.p[k](history), r_next))
        self.w = softmax(self.log_prior - self.lam_mkt * self.score)
        return self.w

    def tie(self, w):
        top2 = sorted(w.values(), reverse=True)[:2]
        return max(w.values()) < self.tau_share or kl_top2(self.p, w) < self.eps_tie


# IP-255/256 UAC + TGL：不可辨识 → 保守；仿真先验按 gap 降权
class UnidentifiabilityAwareConservatism:
    def act(self, u_tie, lam, k, TGL):
        alpha_sim = min(0.5, self.alpha0 * np.exp(-self.gamma * TGL))
        if u_tie and self.hold >= self.T_hold:
            lam = max(lam, 0.85)                                  # 单调收紧
            k   = min(k, self.k_tie)
            self.pending = ('H_cal', 'H_fault')                   # 保留未决集
        if TGL > self.tau_gap:
            self.tau_share *= 0.8                                 # 更易触发 tie
        return lam, k, alpha_sim


# IP-257 CFA-2：先辨识后归因（升级 R68 CFA）
def identify_first_attribution(rho, face, c, U, delta, phi, w, TGL, u_tie):
    alpha = min(0.5, ALPHA0 * np.exp(-GAMMA * TGL))
    post_H = real_evidence(rho, c) ** (1 - alpha) * sim_prior(delta, phi) ** alpha
    post_E = face_evidence(face, c)
    joint  = normalize({(h, e): post_H[h] * post_E[e] * P_E_given_H[h][e]
                        for h in post_H for e in post_E})
    if u_tie or U > TAU_CAL:
        joint = worst_case_keep_ambiguous(joint, {'H_cal', 'H_fault'})
    return joint


# IP-258/262 主闭环：RIVAL-RAS round（R68 闭环 + 辨识层）
def RIVAL_RAS_round(M, obs):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)          # R68 MTM 保留
    r = residuals(z, o)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))             # R68 COF 保留

    delta, phi, eta = M.ctd.forward(obs_pack)                      # 1) 解耦坐标
    w = M.cem.update(M.history, r_next=r)                          # 2) 竞品份额
    u_tie = M.cem.tie(w) or M.cem.disagree(w, o)                   # 3) tie / 分歧
    TGL = M.tgl.estimate(delta, phi, M.probes)                     # 4) 迁移差

    joint_post = M.cfa2(r, o['pi'], c, U, delta, phi, w, TGL, u_tie)  # 5) 先辨识后归因
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint_post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.wm_preds)
    lam, k, alpha_sim = M.uac.act(u_tie, M.efs.risk_scale(joint_post), k, TGL)  # 6) UAC
    k = min(k, M.k_cal_shrink(A, U) if U > TAU_CAL else k)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau = emotion_response_shaping_wm(tau, joint_post, M.wm_preds)
    M.vqa_r.submit_async({'share': w, 'tie': u_tie, 'tgl': TGL, 'cal': (c, U)})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)         # 慢故障 canary 已入关
    return k, lam, joint_post, (c, U, w, u_tie, TGL)
```

## 3. 推导

**引理 16（真实流不可辨识下界）** 设慢漂移 c(t) 与慢故障 f(t) 难分匹配（定义 294），其诱导的真实观测分布满足 TV(P_c, P_f) ≤ ε_unid。则任何仅用真实流的判决器，最坏错误率 ≥ (1 − ε_unid)/2。⇒ R68 的「标定吸收慢故障」不是实现缺陷，而是信息论必然；ε_unid 越小，真实流越无解。

**引理 17（轴迁移误差）** 在 A95（轴方向域不变）下，用 n_sim 个孪生对训练、m 个真实微探针标轴，漂移 / 故障轴方向估计误差 ≤ C₁√(d/n_sim) + C₂√(d/m) + C₃·TGL。三项分别对应仿真样本量、真实探针量、reality gap。

**定理 16（反事实可辨识性）** 给定孪生对与 TGL ≤ τ_gap，存在判决器使慢故障 / 慢漂移分类错误率 ≤ ε_est + O(TGL)，ε_est 由引理 17 控制。⇒ 仿真把「不可辨识」变成「受 TGL 约束的可辨识」；TGL 是这条定理的命门。

**定理 17（不可辨识 → 保守的单调性）** 若 u_tie = 1，则 λ_risk 非降、k 非增，且 P(误放行 | u_tie) = 0——因为未决集不含「放行」动作。⇒ 慢故障即使无法判明，也绝不会被当成「已标定正常」而放行。

**定理 18（竞品金丝雀联合功效）** 由定义 302 与 A96，分歧触发时慢故障检出功效 ≥ 1 − (1−β_base)(1−β_ctd)。即使 β_ctd 因 TGL 退化，只要 β_base > 0 仍有正下界。⇒ 廉价竞品不是冗余，是 CTD 盲区的覆盖。

**定理 19（RIVAL 端到端）** 在 R68 假设 + A95–A97 下，τ_cmd 风险上界在定理 14 上增加 α_tie 项，但 α_tie 只进入保守方向；慢故障漏检率 ≤ (1−β_base)(1−β_ctd) + O(TGL)。

## 6. 本轮最大风险

**一句话**：RIVAL 的辨识性完全建立在「仿真轴方向可迁移」这一假设（A95）上——**若真实漂移 / 故障的因果轴与仿真系统性不一致（真实故障是仿真里没有的物理机制，或真实漂移与故障在观测上的耦合方式不同），CTD 会给出「自信但错误」的方向证据，而竞品集市里所有内部竞品共享同一个错误仿真先验，导致「共识性错误」：大家一致地把慢故障判成漂移，UAC 因无 tie 而保持沉默**——竞品集市防的是「内部不共识」，防不了「全体被同一个错误先验带偏」，这比 R68 的单一模型风险更隐蔽，因为它披着「多竞品共识」的外衣；次级风险是 TGL 的微探针集本身覆盖不到真实故障模式，账本把 gap 记成了「无」。

## 2. 形式化定义（要点版）

**定义 293（总览与五不变式）** 在 R68 三不变式上新增：(iv) 不可辨识即保守（tie / 分歧 ⇒ λ 单调不降、k 单调不增）；(v) 仿真不得单独定罪（α_sim < 0.5，仿真只给方向）。

**定义 294（反事实孪生对）** 同场景、同动作、同随机种子，仅因果源不同，且难分匹配（|c|≈|f|、ω_c≈ω_f、同注入时刻）——辨识性压力测试，而非容易样本。

**定义 295（解耦编码器）** `E_ψ: obs → (δ̂, φ̂, η̂)`；`L_sep` 交叉投影惩罚（漂移只在 δ 轴、故障只在 φ 轴）；`L_irm` 跨仿真域不变；`L_axis` 与真实微探针（0.1% FS 安全微注入）轴对齐。

**定义 296（竞品集市）** K = {E_cal, E_fault, E_model, E_real, C_spc, C_rls, C_sim}；`w_k ∝ π_k·e^{−λ_mkt·S_k}`，S_k 为 proper scoring 累积损失，EWMA 适配非平稳。

**定义 297（tie / 分歧）** `max_k w_k < τ_share` 或 top-2 预测 KL < ε_tie 判 tie；`D_ext = max_C KL(p_{E*}‖p_C)` 判分歧；任一 ⇒ u_tie=1。

**定义 298（UAC）** u_tie ⇒ `λ ← max(λ, 0.85)`、`k ← min(k, k_tie)`、后验保留 (H_cal,H_fault) 未决集；滞回 T_hold / h 防抖。

**定义 299（TGL）** `TGL = sup |P_real − P_sim|`（微探针 + 仿真同条件估计）；`α_sim = min(0.5, α⁰e^{−γ·TGL})`；TGL > τ_gap ⇒ CTD 降级、CFA 回退 R68、τ_share 下调。

**定义 300（CFA-2）** `P(H,E|·) ∝ p(ρ|H,ĉ,δ̂,φ̂)^{1−α_sim}·p_sim(H|δ̂,φ̂)^{α_sim}·p(face|E,ĉ)·P(H)·P(E|H)`；u_tie ⇒ 保持二值未决，不放行。

**定义 301（CAR-2）** `τ_wm·(1+κ_tie·u_tie)`、`τ_risk·(1−κ_tie·u_tie)`、`λ_floor ← max(λ_floor^R68, λ_tie·u_tie)`。注意：u_tie 使一致性检验更敏感（U 则放宽），因 tie 意味着有故障竞品在叫。

**定义 302（竞品金丝雀界）** 联合检出功效 ≥ `1 − (1−β_base)(1−β_ctd)`（A96 弱相关）；廉价竞品是 CTD 盲区的独立覆盖。

**定义 303–304（证书 / 管线）** `J_RIVAL = (J_CALM, axis_hash, tgl, tie_flag, share_vec, rival_ver)`；离线孪生解耦 → 微探针标轴 → 在线份额 + tie/UAC → 继承 R68 CAC。

**定义 305（慢故障 canary）** CAC 第五关加注入 `ω_f ≤ ω_cal` 的慢故障 canary，提交后检出率不得下降，否则一票否决——封堵 R68「金标集未覆盖慢故障」。

```python
# IP-253 CTD：反事实孪生解耦（离线训练，在线仅前向解耦头 ~0.1ms）
class CounterfactualTransferDisentangler:
    def build_pairs(self, sim_rollout):
        base = sim_rollout.sample()
        return [(inject_drift(base, c), inject_fault(base, f))       # 难分匹配
                for c, f in matched_magnitudes(base)]                # |c|≈|f|, ω≈ω

    def train(self, pairs, probes):
        for xi_cal, xi_fault in pairs:
            d, f = self.enc(xi_cal), self.enc(xi_fault)
            L = self.sep(d.delta, f.delta, d.phi, f.phi)             # 交叉投影惩罚
            L += self.irm_penalty(pairs)                             # 轴预测器域不变
        L += self.axis_align(probes)                                 # 真实微探针标轴
        return L

    def forward(self, obs): return self.enc(obs)                     # (δ̂, φ̂, η̂)

# IP-254 CEM：竞品集市（份额 = 贝叶斯模型平均后验）
class CompetitiveExplainerMarket:
    COMPETITORS = ['E_cal','E_fault','E_model','E_real','C_spc','C_rls','C_sim']
    def update(self, history, r_next):
        for k in self.COMPETITORS:
            self.score[k] = ewma(self.score[k], log_loss(self.p[k](history), r_next))
        self.w = softmax(self.log_prior - self.lam_mkt * self.score)
        return self.w
    def tie(self, w):
        top2 = sorted(w.values(), reverse=True)[:2]
        return max(w.values()) < self.tau_share or kl_top2(self.p, w) < self.eps_tie

# IP-255/256 UAC + TGL：不可辨识 → 保守；仿真先验按 gap 降权
class UnidentifiabilityAwareConservatism:
    def act(self, u_tie, lam, k, TGL):
        alpha_sim = min(0.5, self.alpha0 * np.exp(-self.gamma * TGL))
        if u_tie and self.hold >= self.T_hold:
            lam = max(lam, 0.85)                                     # 单调收紧
            k   = min(k, self.k_tie)
            self.pending = ('H_cal', 'H_fault')                      # 保留未决集
        if TGL > self.tau_gap:
            self.tau_share *= 0.8                                    # 更易触发 tie
        return lam, k, alpha_sim

# IP-257 CFA-2：先辨识后归因（升级 R68 CFA）
def identify_first_attribution(rho, face, c, U, delta, phi, w, TGL, u_tie):
    alpha = min(0.5, ALPHA0 * np.exp(-GAMMA * TGL))
    post_H = real_evidence(rho, c) ** (1 - alpha) * sim_prior(delta, phi) ** alpha
    joint  = normalize({(h, e): post_H[h] * face_evidence(face, c)[e] * P_E_given_H[h][e]
                        for h in post_H for e in ('E0','E1','E2','E3')})
    if u_tie or U > TAU_CAL:
        joint = worst_case_keep_ambiguous(joint, {'H_cal', 'H_fault'})
    return joint

# IP-258/262 主闭环：RIVAL-RAS round（R68 闭环 + 辨识层）
def RIVAL_RAS_round(M, obs):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)            # R68 MTM 保留
    r = residuals(z, o)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))               # R68 COF 保留
    delta, phi, eta = M.ctd.forward(obs_pack)                        # 1) 解耦坐标
    w = M.cem.update(M.history, r_next=r)                            # 2) 竞品份额
    u_tie = M.cem.tie(w) or M.cem.disagree(w, o)                     # 3) tie / 分歧
    TGL = M.tgl.estimate(delta, phi, M.probes)                       # 4) 迁移差
    joint_post = M.cfa2(r, o['pi'], c, U, delta, phi, w, TGL, u_tie) # 5) 先辨识后归因
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint_post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.wm_preds)
    lam, k, alpha_sim = M.uac.act(u_tie, M.efs.risk_scale(joint_post), k, TGL)  # 6) UAC
    if U > TAU_CAL: k = min(k, M.k_cal_shrink(A, U))
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau = emotion_response_shaping_wm(tau, joint_post, M.wm_preds)
    M.vqa_r.submit_async({'share': w, 'tie': u_tie, 'tgl': TGL, 'cal': (c, U)})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)           # 慢故障 canary 已入关
    return k, lam, joint_post, (c, U, w, u_tie, TGL)
```

## 4. 推导

**引理 16（真实流不可辨识下界）** 难分匹配的慢漂移 c 与慢故障 f 诱导的真实分布 TV(P_c,P_f) ≤ ε_unid，则任何仅用真实流的判决器最坏错误率 ≥ (1−ε_unid)/2。⇒ R68 的「标定吸收慢故障」是信息论必然，不是实现缺陷。

**引理 17（轴迁移误差）** A95 下，n_sim 孪生对 + m 真实微探针的轴方向误差 ≤ C₁√(d/n_sim) + C₂√(d/m) + C₃·TGL。

**定理 16（反事实可辨识性）** 孪生对 + TGL ≤ τ_gap ⇒ 慢故障/慢漂移分类错误率 ≤ ε_est + O(TGL)。仿真把不可辨识变成「受 TGL 约束的可辨识」；TGL 是命门。

**定理 17（不可辨识 → 保守单调性）** u_tie=1 ⇒ λ_risk 非降、k 非增，且 P(误放行 | u_tie)=0（未决集不含放行动作）。⇒ 慢故障无法判明时也绝不放行。

**定理 18（竞品金丝雀联合功效）** A96 下，分歧触发时慢故障检出功效 ≥ 1−(1−β_base)(1−β_ctd)；β_ctd 退化时只要 β_base>0 仍有正下界。

**定理 19（RIVAL 端到端）** R68 假设 + A95–A97 下，τ_cmd 风险上界在定理 14 上增加 α_tie，但 α_tie 只进保守方向；慢故障漏检率 ≤ (1−β_base)(1−β_ctd) + O(TGL)。

| E300 对抗竞品 | 某竞品被对抗性污染 | 份额鲁棒，tie 触发保守 |

## 7. 本轮最大风险

**一句话**：RIVAL 的辨识性完全建立在「仿真轴方向可迁移」这一假设（A95）上——**若真实漂移 / 故障的因果轴与仿真系统性不一致（真实故障是仿真里没有的物理机制，或真实漂移与故障在观测上的耦合方式不同），CTD 会给出「自信但错误」的方向证据，而竞品集市里所有内部竞品共享同一个错误仿真先验，导致「共识性错误」：大家一致地把慢故障判成漂移，UAC 因无 tie 而保持沉默**——竞品集市防的是「内部不共识」，防不了「全体被同一个错误先验带偏」，这比 R68 的单一模型风险更隐蔽，因为它披着「多竞品共识」的外衣。

**次级风险与缓解**：TGL 微探针覆盖不到真实故障模式（账本记成「无 gap」）→ 探针集纳入故障注入 + 定期对抗式补探针；轴不稳定 → E288 角度监控 + 超界回退 R68；竞品被污染 → 份额鲁棒统计（中位数/截尾）+ E300；滞回导致恢复慢 → T_hold 自适应；α_sim 上限过低使仿真失效 → 仅在 TGL 小时放宽（但始终 < 0.5）。
