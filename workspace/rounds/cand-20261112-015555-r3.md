# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环·本轮灵感：「模型量化」×「柔顺控制」）

> 第 57 轮把安全的赌注从"证据质量"押到"元先验质量"，再用共形保底、跨模态对账、单向信任机层层兜住；它自陈的最大风险是"坏先验普遍"——元模型在语料盲区之外自信地错，而一致性加成与授权加速让错误更快进入承诺。但还有一个更底层、此前从未被正面处理的问题：**整套 57 轮机制（元推断、对账、共形带、延迟验证）都要跑在边端控制回路里，算力、能耗、时延都不允许全精度运行；同时它的"不可逆接触"仍是二值的——要么不碰，要么承担不可逆后果。** 本轮两个灵感各解一半：**模型量化**把"认知分辨率"变成可声明、可校准、可按风险分配的有限资源（rate–distortion + 量化感知共形 + 边界延迟精算）；**柔顺控制**把"动作权限"变成连续可调、能量有界、物理可逆的量（阻抗/力限/无源性 ⇒ L1.5 能量认证接触）。二者合流给出本轮核心命题：**认知分辨率的每一次降低，必须由物理柔顺的相应降低来补偿**——存在一条可证明的"比特换牛顿"安全等价前沿；只要守住它，量化只换速度与能耗、不换安全。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"分辨率可声明的感知、权限可柔顺的动作、二者等价可证的安全"**。

核心矛盾：
- **H29（分辨率 vs 边界）**：量化误差不是均匀的，它集中在决策边界——两个本应区分的世界状态坍缩进同一量化格，制造"离散化假确定"。降比特省的是平均算力，赌的却是最危险的边界样本。
- **H30（柔顺 vs 可观测/覆盖）**：柔顺把"不可逆接触"变成"能量有界接触"，也把接触变成"温柔而聋"——低刚度下信噪比下降，早期滑移、尖锐边缘、以及完全非接触的危险（跌落、缠绕、动态失稳）都不在力限的管辖范围内。安全来自把失败变小，不是把危险变已知。
- **H31（证书 vs 博弈）**：量化失真证书与柔顺/无源性证书都只在建模工况下成立；一旦"我有证书"被用来把接触等级从 L2 降到 L1.5、或绕过证据门，就出现新的信任通胀——用软件声明替代硬件事实。

## 0. 直觉与动机

**灵感 1（模型量化 → 有证书的认知降分辨率）**
直觉：边端跑不动全精度元推断，量化不是"偷工减料"，而是"可声明的信息损失"。把信念表示 Q_b(θ) 看成有损压缩，误差界 ε_q(b) 就是压缩率–失真曲线上的一个点。安全绝不押在"量化后依然准"，而押在三件可检验的事上：① **量化感知共形**——共形区间必须按量化格半径外扩，否则名义覆盖当场失效；② **边界精算**——比特预算按风险分配，决策边界与不可逆接触区保高精度，其余降精度（mixed precision = risk-weighted bit allocation）；③ **点坍缩守卫**——两个不同判决标签落进同一格、且裕度小于格半径时判 τ_tie，禁止承诺、转延迟验证。于是量化只能经"区间更宽 / 动作更慢"影响系统。

**灵感 2（柔顺控制 → 有证书的动作降权限）**
直觉：刚性接触把"预测错"直接放大成"不可逆损伤"；柔顺接触把同一个预测错变成"有界力、有界能量、可撤回"的接触。定义 **L1.5 能量认证接触**：无源阻抗 (K,D_d) + 硬件级力/能量限制器独立监控，且交互能量 E_int≤E_safe ⇒ 接触可逆。更妙的是**接触本身即探针**：同一次柔顺接触既执行动作，又测刚度/摩擦/滑移，"探"与"做"合一，探针成本从"额外动作"降到"顺带的力曲线"；又因为失败有界，可以更激进地试——反过来缓解第 57 轮的少样本困境。注意方向：柔顺只降低动作权限，永不豁免证据。

**灵感 3（两灵感合流 → 量化-柔顺安全等价 QCE）**
直觉：量化与柔顺是同一个"分辨率预算"的两面——一个限制**认知分辨率**（比特），一个限制**物理权限**（牛顿）。接触力 F≈K·δx，而位置偏差 δx 的尾部由信念裕度、量化误差、格半径共同决定；要让 F≤F_safe，就必须 K≤F_safe/δ_max。于是得到显式交换率 **K_max(ε_q,m)=F_safe/(σ_B(m)+ε_q+ρ_q+δ_geo)**：比特越少 ⇒ 允许刚度越低。安全不再是一个点，而是一条**前沿**；工程师可以在前沿上选"更快更软"或"更慢更硬"。反过来问"想做多硬"，就得到最小比特需求 b_min(r)=D^{-1}(F_safe/K_des−σ_B−δ_geo)。

**灵感 4（合流进证据门 → 六类证据与 L1.5）**
直觉：新增 **EV-compliant**（无源+能量认证的 L1.5 接触结果）与 **EV-quant-safe**（声明 ε_q、无 τ_tie、边界已精算的量化推断）。二者都只能替代 L1 的佐证，绝不进入 L2 不可逆接触的必要证据集——柔顺让接触可逆，但"可逆"不等于"可信"。证据门从五类扩到六类，纵深再添"量化守门 ∧ 柔顺守门 ∧ 独立硬件监控"三层。

**灵感 5（PCE++ → 精度与刚度的联合规划）**
直觉：探-诺-演不再只选"探不探 / 走不走"，而是联合选 (b(r), K(r), F_max(r))：裕度小 / 精度低 → 低刚度、高阻尼、慢步态、按边界触发延迟验证；裕度大 → 提精度、增刚、提速。延迟验证失败（超时或算力不足）不是"硬着头皮上"，而是**就地软化**到 K_max(ε_q)。所有新机制仍只经两条安全通道起作用：**"信念更宽"**（量化感知加宽 / τ_tie 禁诺）与 **"动作更软"**（K/F 下降 / 验证失败软化）。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（量化信念证书 QBC）** 量化器 Q_b:Θ→𝒞_b（b 比特，格半径 ρ_q(b)），失真 ε_q(b)=sup_θ‖θ−Q_b(θ)‖_Q。契约：(i) 校准 ECE_Q(k)≤ε_meta(k)+δ_q(b)；(ii) 量化感知共形 C_cf^Q(r)=C_cf(r)⊕Ball(ρ_q(b))，覆盖 ≥1−α_conf；(iii) 点坍缩守卫 τ_tie(r)=1[∃θ,θ′: lbl(θ)≠lbl(θ′) ∧ Q_b(θ)=Q_b(θ′) ∧ margin(r)<ρ_q(b)]，τ_tie=1 ⇒ 禁诺并转 DVI。比特分配 b\*(r)=argmin Σ_r E[dist(Q_{b(r)}θ_r)] s.t. Σ_r b(r)≤B ∧ b(r)≥b_hi (r∈∂Θ 边界集) ∧ b(r)≥b_min。边界集 ∂Θ = {r: margin(r)≤τ_m ∨ lv(r)=L2 ∨ D(r)>θ_D}。

**定义 140（量化-柔顺安全等价 QCE）** 接触包络 E(r)=(K(r),D_d(r),F_max(r),E_safe)。柔顺证书 = (a) (K,D_d) 无源 + (b) 硬件级力/能量限制器独立监控（不经主控软件）。位置偏差尾部 δ_max(r,m,b)=σ_B(m)+ε_q(b)+ρ_q(b)+δ_geo。安全等价前沿：K_max(r)=F_safe(r)/δ_max(r,m,b)。控制约束 K(r)≤K_max(r)，于是 E_int≤F_max·δ_max≤E_safe 由构造成立。单调性：∂K_max/∂b>0（多给比特可更硬）、∂K_max/∂m>0（裕度大更硬）。逆式（最小比特需求）：b_min(r)=D^{-1}(F_safe/K_des−σ_B−δ_geo)。**"用比特换牛顿"**：Δb 比特的收益即 ΔK_max。

**定义 141（柔顺接触探询 CCP）** 探针 p 以柔顺力斜坡执行（F(t)≤F_max，能量 E_int(p)≤E_safe），观测 o=(F–x 迟滞、滑移起始、阻抗 |Z|、声学)。双用性：p 同时是动作与测量；信息效率 η(p)=IG(p)/E_int(p)。safe-to-fail：误判时 E_int≤E_safe ⇒ 接触可逆 ⇒ 允许执行刚性下本应属 L2 的试探。探询预算由 k_probes 改为能量预算 E_probe；若接触同时满足柔顺证书，可产出 EV-compliant。

**定义 142（信念条件阻抗控制 BIC）** 阻抗调度 Π:(m,ε_q,risk,lv)→(K,D_d,F_max,v_gait)，单调约束：m↓ / ε_q↑ / risk↑ / lv=L2 ⇒ K↓、D_d↑、F_max↓、v_gait↓。硬约束 K≤K_max。量化控制器加抖动与迟滞避免极限环；若量化策略仍抖动，柔顺把力振荡耗散为有界能量。BIC 是"动作更软"通道的唯一执行器。

**定义 143（延迟验证推断 DVI）** 边端量化模型 π_b 先给出候选 u_q；全精度验证器 f_full 仅当 margin(r)≤τ_m ∨ τ_tie(r)=1 ∨ D(r)>θ_D 时运行。预算：每检查点延迟次数 ≤N_defer，时延 τ_def≤τ_int。验证不可用 / 超时 ⇒ 软化 K←K_max(ε_q) 并降步态；**绝不因验证失败而软化证据门**。"算力按风险花"：期望算力=B_base+Σ_边界 C_verify。

**定义 144（量化-柔顺证据门 QCG 与证书 J_qc）** 证据类：EV-probe\*/EV-visit/EV-margin/EV-xmodal/EV-human 继承；新增 **EV-compliant**（L1.5：无源+能量证书+独立监控日志）与 **EV-quant-safe**（ε_q 已声明 ∧ ¬τ_tie ∧ 边界已精算）。关键硬规则：L2 不可逆接触必要证据集仍为 {EV-probe\*∨EV-margin}∪佐证，**不含** EV-xmodal / EV-compliant / EV-quant-safe。J_qc=(b(r),B,ε_q,ρ_q,τ_tie_log,K/F/E 包络,passivity_cert,deferral_log,monitor_log)，继承 J_p 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def qbc_infer(M, r, obs, meta, bits):               # IP-139
    post = meta.q_phi(obs, z=ctx(r)); post_q = quantize(post, bits[r])
    post_q = widen(post_q, rho_q(bits[r]))          # 量化感知加宽
    if tie_collapse(post_q, margin(M, r), rho_q(bits[r])):
        return Inf(tie=True, defer=True)            # 禁诺，转 DVI
    return Inf(post=post_q, eq=eps_q(bits[r]))

def qce_envelope(m, eps_q, risk, lv):               # IP-140
    delta = sigma_B(m) + eps_q + rho_q + delta_geo
    K_max = F_safe / delta
    return Envelope(K=min(K_des, K_max), F_max=min(F_cap, E_safe/delta), E_safe=E_safe)

def compliant_probe(p, env):                        # IP-141
    return execute_force_ramp(p, F_max=env.F_max, E_cap=env.E_safe)  # 动作+测量
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| QBC | O(b·d_θ)/推断；分配 O(\|V\|·B) 离线 | O(\|𝒞_b\|) | ε_q 声明诚实、量化感知覆盖、τ_tie 不隐瞒（A41） |
| QCE | O(1)/接触 | O(\|V\|) | 无源+独立限力、K≤K_max（A42） |
| CCP | O(1)/探针+O(E_probe/ē) | O(1) | 能量有界、可逆、双用记账 |
| BIC | O(1)/控制周期 | O(\|V\|) | 单调调度、抖动耗散 |
| DVI | O(C_verify·1[边界]) | O(N_defer) | τ_def≤τ_int、失败只软化（A43） |
| QCG | O(\|σ\|) | O(\|σ\|) | L2 必要集不含柔顺/量化证据（A44） |

**正确性定理（Quantization–Compliance Certified Safety, QCCS）** 在 A37–A40 之上加：(A41) 量化证书诚实——失真 ≤ε_q(b)、量化感知共形覆盖 ≥1−α_conf、τ_tie 不被隐瞒；(A42) 柔顺证书诚实且**独立监控**——(K,D_d) 无源、硬件力/能量限制器有效、且控制器强制 K≤K_max(ε_q,m)；(A43) 延迟验证有界——N_defer、τ_def≤τ_int，且任何验证失败只能触发软化；(A44) L1.5 := 能量认证可逆接触，EV-compliant/EV-quant-safe 永不得进入 L2 必要证据集。则：
1. **单接触失效界**：P(fail) ≤ δ_f+ε_meta(k)+ε_q(b)+δ_probe+ε_h(w_max)+δ_mon+δ_geo，其中 δ_mon 为独立监控失效、δ_geo 为未建模几何。
2. **安全等价**：若 K(r)≤K_max 且独立限力有效，则 P(E_int>E_safe)≤α_conf+δ_mon；因此固定 (F_safe,E_safe) 时 L2 风险不随 b 增大——**量化只换速度不换安全**；反之，降 b 却不降 K 即违反界（这正是 H29 的形式化）。
3. **交互单调性（强化）**：QBC 只能加宽区间或触发禁诺；BIC/CCP 只能降低 K、F_max、v_gait；DVI 失败只软化；柔顺只能降级接触等级、不得豁免证据。故不存在"升险"路径（τ_tie 守门保证量化不会以"假确定"升险）。
4. **终止/时延**：每检查点延迟 ≤N_defer、柔顺探针能量 ≤E_probe，PCE++ 在 {承诺,绕行,L2 协商,安全停} 内终止且 τ_def≤τ_int。

部署界（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + ε_q + δ_probe + ε_h + δ_mon + δ_geo)
             − P(证书过期未被隔离) − P(几何超出包络) − P(τ_def ∧ 软化 ∧ 安全停失效)
```
关键：**量化给速度、柔顺给可逆、独立监控给兜底**；安全等价把"精度降低"与"刚度降低"绑成一条可审计的约束，而不是两个各自为政的旋钮。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 量化误差与状态强相关、边界系统性偏差 | 高 | 风险加权比特 + 边界保精度 + 随机抖动/随机舍入 + 分层校准审计 |

| 量化控制抖动/极限环 | 中 | 抖动、迟滞、柔顺耗散、DVI 边界复核 |

## 6. 本轮最大风险

**一句话**：本轮把安全的一部分赌注重心从"证据"移到了"物理柔顺 + 数值分辨率"，风险也从"坏先验普遍"变成 **"证书幻觉"**——量化失真证书与柔顺/无源性证书都只在可建模、可测量的工况下成立，一旦遇到未建模几何（尖锐边缘、腿部缠绕、非接触动态失稳）或软接触所掩盖的早期危险，系统会因"我持有证书"而更快、更硬地进入承诺；根本原因是柔顺与量化都只是**把失败变小、变慢，而不是把无知变成已知**，因此必须以独立硬件监控、量化感知加宽+τ_tie 禁诺、以及"柔顺只能降级不能豁免证据"三重护栏守住，宁可在前沿上退到又软又慢的一端，也不拿证书去换一次不可逆接触。

# 第 58 轮产物 · 创新点清单 v34：Quant-Comp（量化可声明×柔顺可逆×证书等价，QBC×QCE×CCP×BIC×DVI×QCG）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"分辨率可声明的感知、权限可柔顺的动作、二者等价可证的安全"**：认知侧用有失真证书的量化（rate–distortion + 量化感知共形 + 风险加权比特 + 边界延迟精算）换边端算力/能耗/时延；动作侧用有能量证书的柔顺（无源阻抗 + 硬件独立限力 + L1.5 可逆接触 + 接触即探针）把"预测错"的后果从不可逆缩成可逆；两侧由一条显式安全等价前沿 **K_max=F_safe/(σ_B+ε_q+ρ_q+δ_geo)** 绑定，保证"降比特必须降刚度"。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-133/137/138 以纳入量化证书、柔顺证书与 L1.5 接触。

## 2. 关键算法伪代码

### IP-139 QBC（量化信念证书与风险加权比特）

```python
def allocate_bits(regions, B, boundary_set, b_hi, b_min):
    # 风险加权：边界/不可逆/分歧区保高精度，其余尽量降
    b = {r: b_min for r in regions}
    for r in boundary_set:
        b[r] = b_hi
    while sum(b.values()) > B:                  # 预算不足则按风险排序回收
        r = min((r for r in regions if r not in boundary_set),
                key=lambda r: risk(r))
        if b[r] <= b_min: break
        b[r] -= 1
    return b

def qbc_infer(M, r, obs, meta, bits):
    z = region_context(r, M)
    if ood_score(obs, z, meta) > meta.theta_ood:          # 继承 IP-133
        return Inf(cls='OOD', belt=conformal_belt(meta.res, z, alpha_conf))
    post = meta.q_phi(obs, z)
    post_q = quantize(post, bits[r])                       # 有损压缩
    post_q = widen(post_q, rho_q(bits[r]))                 # 量化感知加宽
    if tie_collapse(post_q, margin(M, r), rho_q(bits[r])): # 假确定检测
        return Inf(cls='ID', post=post_q, tie=True, defer=True)
    return Inf(cls='ID', post=post_q, eq=eps_q(bits[r]),
               ece=meta.ece_decl[len(obs)] + delta_q(bits[r]))

def tie_collapse(post_q, m, rho):
    # 同格内存在两个不同判决标签，且裕度小于格半径
    labels = distinct_labels_in_same_cell(post_q)
    return len(labels) > 1 and m < rho
```

### IP-140 QCE（量化-柔顺安全等价前沿）

```python
def qce_envelope(m, eps_q, rho, risk, lv, F_safe, E_safe, K_des, F_cap):
    delta = sigma_B(m) + eps_q + rho + delta_geo(r=lv)     # 偏差尾部
    K_max = F_safe / delta                                 # 交换率
    K = min(K_des * compliance_scale(risk, lv), K_max)     # 越界即软化
    F_max = min(F_cap, E_safe / delta)                     # 构造性能量界
    return Envelope(K=K, D_d=damping(K), F_max=F_max, E_safe=E_safe)

def min_bits_for_stiffness(K_des, F_safe, sigma_B, delta_geo):
    budget = F_safe / K_des - sigma_B - delta_geo           # 可容忍总误差
    return inverse_distortion(max(budget, 0.0))             # b_min = D^{-1}(·)
```

### IP-141 CCP（柔顺接触探询：动作+测量双用）

```python
def compliant_probe(p, env, budget):
    if budget.energy_left < p.e_est: return None
    o = execute_force_ramp(p, F_max=env.F_max, E_cap=env.E_safe)  # 力限执行
    ig = info_gain(o, p, belief)                          # 刚度/摩擦/滑移
    budget.spend(o.energy)
    return ProbeResult(o=o, ig=ig, eta=ig / max(o.energy, eps),
                       reversible=(o.energy <= env.E_safe),
                       ev=('EV-compliant' if passive(o) and
                           independent_monitor_ok(o) else None))

def compliant_contact_level(cp, env):
    # 刚性下为 L2 的接触，若能量认证可逆，降为 L1.5（但不豁免 L2 证据集）
    return 'L1.5' if env.energy_certified(cp) else 'L2'
```

### IP-142 BIC（信念条件阻抗控制）

```python
def bic_schedule(M, r, inf, lv, env):
    m = margin(M, r); eps = inf.eq if inf.cls == 'ID' else inf.belt.width
    risk = schedule_risk_estimate(M, r, lv)
    K = env.K * (1 - w1 * clip(-m, 0, 1)) \
              * (1 - w2 * eps) * (1 - w3 * clip(risk, 0, 1))
    K = min(K, env.K_max)                                  # QCE 硬约束
    D_d = damping_scale(K) / max(m, eps_min)               # 低裕度→高阻尼
    F_max = min(env.F_max, E_safe / delta_max)
    v_gait = gait_speed(K, lv)                             # L2 更慢
    return Impedance(K=K, D_d=D_d, F_max=F_max, v_gait=v_gait)

def bic_execute(u_q, imp):
    # 量化策略可能抖动；柔顺把力振荡耗散为有界能量
    return apply_impedance(dither(u_q, imp), imp)
```

### IP-143 DVI（延迟验证推断：算力按风险花）

```python
def deferred_infer(M, r, obs, meta, bits, budget):
    inf = qbc_infer(M, r, obs, meta, bits)
    need = (margin(M, r) <= tau_m) or inf.tie or (D(M, r) > theta_D)
    if not need:
        return inf, 'edge'                                  # 边界外只跑量化
    if budget.defer_left <= 0:
        return inf, 'soften'                                # 无算力→软化
    post_full = meta.q_phi_full(obs, ctx(r))                # 全精度精算
    budget.defer_left -= 1
    return Inf(cls=inf.cls, post=post_full, tie=False, eq=0.0), 'verified'

def apply_inference_result(inf, status, env):
    if status == 'soften':                                  # 验证失败只软化
        return env.soften_to(K_max=env.K_max)
    return env
```

### IP-144 QCG（量化-柔顺证据门 + 证书 J_qc）

```python
def quant_comp_evidence_gate(c, M, persona, ood_reg, env):
    if c.ev == 'EV-quant-safe':
        ok = (c.inf.cls == 'ID' and not c.inf.tie
              and c.inf.eq <= eps_q(c.bits) and boundary_verified(c))
    elif c.ev == 'EV-compliant':
        ok = (c.level == 'L1.5' and c.passivity_cert
              and c.energy <= E_safe and c.monitor_ok)
    elif c.ev in ('EV-probe*', 'EV-visit', 'EV-margin',
                  'EV-xmodal', 'EV-human'):
        ok = few_shot_evidence_gate(c, M, persona, ood_reg)[0] == 'ok'
    else:
        return ('reject', 'no_evidence_class', c)

    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-xmodal', 'EV-compliant',
                                   'EV-quant-safe'):
        return ('reject', 'soft_evidence_on_irreversible', c)   # 硬禁令
    if c.irreversible and not (c.ev in ('EV-probe*', 'EV-margin')):
        return ('reject', 'L2_evidence_set_incomplete', c)
    return ('ok', c)

def map_certificate_qc(sched, log, M, consent_log, auth_log, ood_reg,
                       alloc, env_log, defer_log, monitor_log):
    for c in contacts(sched):
        st = quant_comp_evidence_gate(c, M, persona_of(c), ood_reg,
                                      env_of(c))
        if st[0] != 'ok': return st
    if max(abs(env_log.K[r] - min(env_log.K_des[r], env_log.K_max[r]))
           for r in regions) > 1e-9:

    if not all(e.monitor_ok for e in monitor_log):
        return ('reject', 'independent_monitor_down')
    if any(d.latency > tau_int for d in defer_log):
        return ('reject', 'deferral_deadline')
    if not all(l2.resolved for l2 in consent_log):
        return ('reject', 'consent_open')
    return ('ok', Jqc(bits=alloc.b, eps_q=alloc.eps, tie_log=alloc.tie_log,
                      envelope=env_log, passivity=env_log.passivity,
                      deferral=defer_log, monitor=monitor_log,
                      base=Jp(...)))
```

### IP-138→PCE++（探-诺-演++：精度×刚度×柔顺联合规划）

```python
def probe_commit_evolve_plusplus(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    alloc = allocate_bits(route.regions, budget.B,
                          boundary_set(route, M), b_hi, b_min)
    sched, log = [], []
    for cp in route.checkpoints:
        inf, status = deferred_infer(M, cp.region, M.obs[cp.region],
                                     meta, alloc.b, budget)
        env = qce_envelope(margin(M, cp.region), inf.eq, rho_q(alloc.b),
                           schedule_risk_estimate(M, cp.region, cp.lv),
                           cp.lv, F_safe, E_safe, K_des, F_cap)
        env = apply_inference_result(inf, status, env)     # 失败→软化
        while select_gait(schedule_risk(M, cp, env)) == 'halt' \
              and not budget.exhausted():
            p = choose_probe(cp, M, inf, env)               # 含 EV-compliant 候选
            res = compliant_probe(p, env, budget.probe_energy)
            if res is None: break
            M = fuse_probe(M, cp.region, res)               # 动作+测量双用
            if res.ev == 'EV-compliant': log.append(res.ev)
            env = qce_envelope(margin(M, cp.region), inf.eq,
                               rho_q(alloc.b), schedule_risk_estimate(
                                   M, cp.region, cp.lv),
                               cp.lv, F_safe, E_safe, K_des, F_cap)
        imp = bic_schedule(M, cp.region, inf, cp.lv, env)
        g = select_gait(schedule_risk(M, cp, imp))
        lv = compliant_contact_level(cp, env)               # L2→L1.5（若认证）
        if g != 'halt' and quant_comp_evidence_gate(
                core_contact(cp, lv), M, personas, ood_reg, env)[0] == 'ok':
            sched.append(commit(imp, g)); log.append(tag_evidence_qc(inf, lv))
            continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(M, cp, env)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, imp, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QBC | O(b·d_θ)/推断；分配 O(\|V\|·B) 离线 | O(\|𝒞_b\|) | ε_q 诚实、量化感知覆盖、τ_tie 不隐瞒（A41） |
| QCE | O(1)/接触 | O(\|V\|) | 无源 + 独立限力、K≤K_max（A42） |
| CCP | O(1)+O(E_probe/ē) | O(1) | 能量有界、可逆、双用记账 |
| BIC | O(1)/控制周期 | O(\|V\|) | 单调调度、抖动耗散 |
| DVI | O(C_verify·1[边界]) | O(N_defer) | τ_def≤τ_int、失败只软化（A43） |
| QCG | O(\|σ\|) | O(\|σ\|) | L2 必要集硬排除柔顺/量化证据（A44） |
| PCE++ | O(\|CP\|·(N_defer·C_verify + E_probe/ē + d_φ)) | O(\|V\|+\|σ\|) | 双预算终止、四态完备 |

**正确性定理（Quantization–Compliance Certified Safety, QCCS）**
假设 A22–A36（第 53–57 轮）成立；**(A41)** 量化证书诚实：∀r，失真 ≤ε_q(b(r))，量化感知共形覆盖 ≥1−α_conf，τ_tie 不被隐瞒；**(A42)** 柔顺证书诚实且独立：接触阻抗无源，硬件力/能量限制器独立于主控软件有效，控制器强制 K(r)≤K_max(ε_q,m)=F_safe/δ_max；**(A43)** 延迟验证有界：每检查点延迟 ≤N_defer，τ_def≤τ_int，任何验证失败只触发软化（K←K_max）；**(A44)** L1.5 := 能量认证可逆接触；EV-xmodal/EV-compliant/EV-quant-safe 永不得进入 L2 不可逆接触必要证据集。则：

1. **单接触失效界**：`P(fail) ≤ δ_f + ε_meta(k) + ε_q(b) + δ_probe + ε_h(w_max) + δ_mon + δ_geo`，δ_mon 为独立监控失效，δ_geo 为未建模几何。
2. **安全等价（核心）**：若 K≤K_max 且独立限力有效，则 `P(E_int>E_safe) ≤ α_conf + δ_mon`；故固定 (F_safe,E_safe) 时 L2 风险不随 b 增大。**量化只换速度/能耗，不换安全**；反之，降 b 而不降 K 直接违反前沿（把 H29 形式化为可审计约束）。逆式给"想做多硬需要多少比特"：`b_min(r)=D^{-1}(F_safe/K_des−σ_B−δ_geo)`。
3. **交互单调性（再强化）**：QBC 只能加宽区间或触发禁诺；BIC/CCP 只能降低 K、F_max、v_gait；DVI 失败只软化；柔顺只能把 L2 降为 L1.5、绝不豁免证据。τ_tie 守门保证量化不会以"假确定"升险——不存在升险路径。
4. **终止/时延**：每检查点延迟 ≤N_defer、柔顺探针能量 ≤E_probe，PCE++ 在 {承诺, 绕行, L2 协商, 安全停} 内终止且 τ_def≤τ_int。

部署界（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + ε_q + δ_probe + ε_h + δ_mon + δ_geo)
             − P(证书过期未被隔离) − P(几何超出包络) − P(τ_def ∧ 软化 ∧ 安全停失效)
```

关键：**量化给速度、柔顺给可逆、独立监控给兜底**；三者由 qce_envelope 的 `K≤K_max` 一条硬约束统一，而不是三个各自为政的旋钮。安全不再依赖"量化后仍然准"，而依赖"就算不准，物理后果也有界可逆"。

云边协议 CEB++ → **CEB+++**：云端可下发**量化元模型增量 + 校准证书**，但模型（尤其低比特模型）与柔顺包络参数都要过隔离区——先以影子模式在边端探针流上并行运行，回归测试（ECE 不劣化 ∧ 共形覆盖不降 ∧ τ_tie 检出率不降 ∧ K≤K_max 无越界 ∧ 能量界审计通过）通过后才接管承诺判定；边端回传量化残差、τ_tie 事件、柔顺接触的能量/滑移统计与证伪事件，作为云端重训练、比特分配与包络漂移检测的依据。第 57 轮"一切判定器走隔离"在本轮扩展为 **"判定器 + 量化证书 + 柔顺包络三件套一起走隔离"**——因为本轮最强的新证据（EV-compliant / EV-quant-safe）恰恰来自最容易被证书通胀污染的通道。

## 6. 本轮最大风险

**一句话**：本轮把安全的一部分赌注重心从"证据"移到了"物理柔顺 + 数值分辨率"，风险也从"坏先验普遍"变为 **"证书幻觉"**——量化失真证书与柔顺/无源性证书都只在可建模、可测量的工况下成立，一旦遇到未建模几何（尖锐边缘、腿部缠绕、非接触动态失稳）或软接触所掩盖的早期危险，系统会因"我持有证书"而更快、更硬地进入承诺；根本原因是柔顺与量化都只是**把失败变小、变慢，而不是把无知变成已知**，因此必须以独立硬件监控、量化感知加宽 + τ_tie 禁诺、以及"柔顺只能降级不能豁免证据"三重护栏守住，宁可在安全等价前沿上退到又软又慢的一端，也不拿证书去换一次不可逆接触。
