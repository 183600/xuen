# 第 4 轮（新一轮灵感循环第 1 轮；承接第 3 轮 InstructGauge；本轮灵感：「协同控制」×「动力学」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。协同控制只升级「单机闭环 → 契约共识的探测编队」，动力学只升级「回执采样 → 瞬态稳态证书」；任一环节不可用都必须一键退回 InstructGauge。降级链：CoDynGauge ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

**灵感 1（协同控制 → 从「一个更聪明的探测器」到「一组可共识的探测器」）**
直觉：第 3 轮的闭环里只有一个「我」在探测；但真实计量/修复单元里常有多台设备——多机械臂、多传感器、人机协同——它们看同一工件、共享同一套契约。协同控制的价值不在于把 N 个动作并行起来「更快」，而在于把**共享契约、共享信念与安全责任**变成可协商、可审计的对象。关键抽象不是「多机轨迹」，而是**带角色与权限的团队契约 K**：各机只在自身能力闭包内提出候选，团队在「安全集取交、偏好集取平均」的算子下形成共识。把「谁有权动、谁的安全一票否决、谁的偏好只值多少权重」显式化，才可能在多机下保住第 3 轮「语言只改偏好、不改能力」的分层。

**灵感 2（动力学 → 回执不是一个数，而是一段瞬态过程的稳态极限）**
直觉：ToolGauge / InstructGauge 把一次探测的回执当作瞬时真值——动作执行完，`y_t` 就是答案。但接触力会过冲、结构会振动、热漂移要爬升、粘弹性要蠕变；在瞬态未衰减时采样，拿到的是**有偏的、且由上一动作激发的**读数。因此正确的语义是：回执只有在**沉降证书**（settling certificate）成立后才可入账——「没稳定，就不算证据」。这把动力学从「更难的控制问题」改写成「证据在时域上的有效性问题」，恰好接在 CVC 的提交边界上：块内每一步先问「稳了吗」，再问「准了吗」。

**灵感 3（两者耦合 → 共识会「洗白」错误，同步会放大串扰）**
直觉：最危险的组合既不是「多机」也不是「动力学」本身，而是**多机在共享动力学上同步动作**：一台设备的运动经工件/夹具耦合进另一台的测量通道，串扰被同时性放大；而共识算子又会把一台设备的有偏回执**平均进**所有人的共享信念，错误被「洗白」成共识。两条结构性对策最能对症：其一，**安全取交、偏好取平均**——安全是集合交，不能被平均掉，任一机的一票否决必须能阻断共享承诺；其二，**共激励屏障**——串扰超界就把冲突对串行化，不可逆动作仍强制独立交叉验证。再叠加**来源分层校准**（不同角色/耦合状态的证据不可随意合并）与 **κ_coop 块长夹逼**（并发度 × 耦合增益 × 语义熵越大，块越短），把「歧义 × 并发 × 时长」的乘积夹住。

## 1. 研究问题（本轮要回答什么）

- **Q1（可退化性）**：N=1、准静态、无耦合时，CoDynGauge 能否**逐指令精确**退回 InstructGauge，而不是「近似像」？
- **Q2（安全的可组合性）**：多机的局部安全集在动力学耦合下能否安全取交？取交在什么条件下失效，失效时如何降级？
- **Q3（证据的时域有效性）**：瞬态未稳的回执会造成多大偏差？沉降证书能否把偏差压到可入账的 `ε_s` 量级？
- **Q4（耦合放大）**：并发度与串扰增益是否把语义-时间放大从 `K` 步推到 `N_par·K` 步？`κ_coop` 与共激励屏障能否把它压回可界，并在不可认证处退化为单机单步？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–463）

**P1 单机可退化（Single-Agent Degradability）**
`N=1`、`G_ij≡0`、`τ_settle=0`、串扰图为空 ⇒ 团队契约退化为单机指令规格，D-CVC 退化为 CVC，来源分层退化为 SC-Cal。协同与动力学全部是**可关闭增强**；任何求解失败都退回 InstructGauge，而不是「降级成一个更差的多机控制器」。

**P2 安全取交、偏好取平均（Safety-Meet, Preference-Average）**
团队安全集 `S^team = ⋂_i S_i`，团队偏好 `p^team = Σ_i w_i^c p_i`。安全只能取交、必须附**组合证书**（证明耦合闭环下该交集仍不变）；偏好可取加权平均，但权重有上界、且只在 `≻_safe` 等价类内重排。任一机的一票否决（局部集空、硬约束违反、回执未稳）⇒ 不共享承诺，各机退回自己的 InstructGauge 契约。

**P3 未稳不入账（No Settled, No Evidence）**
每条回执必须携带沉降证书 `SettleCert`；未过证书的回执标记为 `provisional`，**不得进入共识、不得进入校准、不得触发热替换**。等待稳态的时间作为显式代价 `c_settle` 计入预算，而不是被隐藏——否则「多探」会靠偷采样时域来虚报收益。

**P4 共激励屏障（Co-Actuation Barrier）**
若两个动作在 `τ_settle` 内并发会突破串扰容差 `δ_tol`、共享非凸执行器/工作空间、或涉及不可逆动作，则在冲突图上连边，并发集必须是独立集。屏障是第 3 轮「不可逆屏障」的推广：不可逆只是冲突图里最硬的一类边，串行化则是一般的边。

## 3. 与基线的接口（如何退化）

- `N=1` / 无并发 / `G_ij≡0` ⇒ 团队退化为单机契约，逐指令等价 InstructGauge；
- 沉降证书不可得 / 动力学模型缺失 ⇒ 保守长驻留 + 只取已稳回执；仍不可得则 `K=1` 逐步（ToolGauge）；
- 串扰证书不可证 / 组合证书失败 ⇒ 冲突图强制串行，耦合对之间等价于 `K=1`；
- 安全取交为空 / 任一 veto ⇒ 不共享承诺，各机回到自己的 InstructGauge 契约；
- 来源分层样本不足 / 可交换性检验失败 ⇒ 逐机阈值 ⇒ SC-Cal 分层 ⇒ 全局共形（InstructGauge/ToolGauge）；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**团队契约 + 安全取交共识**的协调口径，把「多机并行」从轨迹拼接升级为可类型检查、可否决、可审计的契约协商；
2. 一个**沉降证书**驱动的证据有效性语义，把动力学瞬态从「测量噪声」提升为「是否算证据」的一等判定，并给出偏差上界；
3. 一个**串扰证书 + 共激励屏障**，把并发从无界风险压成「可证则并行、不可证则串行」的二元判决；
4. 一个**来源分层共形校准**，修正「跨机合并证据破坏可交换性」导致的逐机覆盖失效；
5. 一条完整可证伪路径：E457–E472 覆盖单机退化、取交安全、沉降偏差、串扰界、屏障进度、来源覆盖、κ_coop、拜占庭隔离、两阶段重配置与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：整套「安全取交」的可组合性依赖「各机局部安全集在耦合动力学下仍然成立」，而团队恰恰在最需要它的时刻——并发、共振、共享工件——让这个前提失效：局部证书相加并不自动等于全局安全，若组合证书被放松，交集会给出「看起来安全、实则耦合越界」的假保证。

## 2. 形式化定义（要点）

**定义 448（团队与团队契约 K）**
`A={1..N}`，通信图 `G_c=(A,E_c)`，第 `i` 机局部能力 `T_i⊆T₀`、`M_phys_i`。团队契约
`K=(g, ρ, Φ, B, ≻, r, sync)`，其中 `r: A → 2^{T₀}×𝒫` 为角色/权限映射，`sync ∈ {serial, parallel}`。
可行团队计划集
`Plan(K) = { (π_1,…,π_N) : ∀i, π_i ⊨ Φ_i ∧ π_i ∈ Plan_{InstructGauge}(ι_i) ∧ Σ_i cost(π_i)+c_comm+c_sync+c_settle ≤ B ∧ schedule(π) ⊨ Barrier ∧ (∀i≠j, role_i ∩ role_j = ∅ 于不可共享资源) }`。
关键性质：`N=1 ⇒ Plan(K)=Plan(ι)`（引理 59）。语言/协同只做**分布式子集选择与角色分配**，不扩张任何单机的物理可行域。

**定义 449（耦合动力学模型）**
`x_i(t+1) = f_i(x_i(t),u_i(t)) + Σ_{j≠i} G_ij(x(t)) u_j(t) + w_i(t)`，`y_i(t)=h_i(x_i(t))+v_i(t)`，`w_i∈W_i`、`v_i∈V_i` 有界。在操作点线性化得通道 `C_ij(z)=h_i(zI−A_i)^{-1}B_ij`，增益 `γ_ij=‖C_ij‖_{H∞}`，归一化 `Γ=Σ_{i≠j}γ_ij/γ_ref`。准静态/独立极限：`G_ij≡0` 且一步收敛 ⇒ 退化为 InstructGauge 的无耦合模型。

**定义 450（沉降证书 SettleCert）**
探测段结束于 `t_e`，常值 `u_i` 下的稳态 `x_i^∞(u_i)`，残差 `ρ_i(t)=‖x_i(t)−x_i^∞(u_i)‖_{P_i}`。证书
`SettleCert_i(t_e)=(t_e, τ_i, ε_s, ε_ov, λ_i, witness)` 成立当且仅当：
(i) `∀t∈[t_e−τ_i,t_e], ρ_i(t)≤ε_s`；
(ii) 衰减见证 `ρ_i(t_e) ≤ ρ_i(t_e−τ_i)e^{−λ_i τ_i}+ε_s`；
(iii) 过冲 `max_{t∈[t_e−τ_i,t_e]} ρ_i(t) ≤ ε_ov`。
它声明量测偏差界 `‖y_i(t_e)−y_i^∞‖ ≤ L_h·ε_s`。**未持证的回执一律 `provisional`，不得入共识/校准/热替换**（P3）。

**定义 451（安全取交共识与组合证书）**
各机提交局部不变集 `S_i` 与盾。团队安全集 `S^team=⋂_i S_i`。共享承诺允许当且仅当存在**组合证书** `CompositionCert` 使耦合闭环满足
`L_f S^team ⊕ (Σ_{i≠j} G_ij U_j ⊕ W) ⊆ S^team`。
若满足，则 `S^team⊆S_i, ∀i` 且团队安全不被平均掉。若 `S^team=∅`、任一机 `veto_i=1`（局部集空、硬约束违反、证据未稳、OOD），或 `CompositionCert` 失败 ⇒ **不共享承诺**：各机退回自身 InstructGauge 契约；组合证书失败时强制走定义 454 的串行化。该定义把「取交何时安全」的诚实前提显式化为一个必须验证的证书，而不是默认成立。

**定义 452（偏好共识与分歧预算）**
偏好 `p_i` 为安全等价类上的权重。`p^team=Σ_i w_i^c p_i`，`w_i^c≥0`、`Σw_i^c=1`、`w_i^c≤w_max`；只在 `≻_safe`（定义 442）等价类内重排，绝不改可行域。分歧 `D_dis=max_i TV(p_i,p^team)`；`D_dis>τ_dis` ⇒ 不共享偏好（各机保留自身偏好或升级人工），防止低置信机以平均权重绑架全队，同时保留定义 451 的安全否决权。

**定义 453（串扰证书 XCT）**
对并发集 `σ(t)⊆A`，第 `i` 机受扰界
`δ_i(σ)=Σ_{j∈σ(t)\{i}} γ_ij‖u_j‖+‖w_i‖`，
量测偏差 `‖Δy_i‖ ≤ L_h·δ_i/(1−L_f)`。`XCT(σ)` 成立当且仅当 `max_i δ_i(σ) ≤ δ_tol` 且 `max_i‖Δy_i‖ ≤ ε_ct`。`γ_ij` 由模型给出时用保守上界；只能估计时用共形上置信界（覆盖 `≥1−α`），不得用点估计冒充上界。

**定义 454（共激励屏障与冲突图）**
在动作槽 `(i,t)` 上建冲突图 `G_conf`：若 `|t−t'|<τ_settle` 且 `¬XCT({i,j})`，或两动作共享非凸执行器/工作空间，或任一为不可逆动作（继承定义 445），则连边 `(i,t)~(j,t')`。调度 `σ` 可采纳当且仅当每个并发集是 `G_conf` 的独立集。不可逆动作仍为**单例硬边**并要求独立回执交叉验证。屏障是定义 445 的推广：不可逆是硬边，串扰是软边（可证则并行、不可证则串行）。

**定义 455（D-CVC 动力学感知块证书）**
在提交边界 `t` 执行 `a_t` 前须同时满足：
(i) `φ_pre^C(σ_t)`；(ii) `still_grounded(ι,σ_t)`；(iii) `drift(σ_t,σ̂_t^C)≤δ_c`（以上继承定义 435）；
(iv) 该步用到的每条回执均持有效 `SettleCert`；
(v) 该步并发集满足 `XCT`；
(vi) 块前缀内不存在未串行化的冲突边。
任一失败 ⇒ 只执行**最长已稳安全前缀** `a_{1:t'-1}`，尾部回执标 `provisional`，并出证 `DChunkCert(C, verified_prefix=t', provisional_set, XCT)`。这把「块级承诺」进一步切成「逐格可否决 + 逐格可验稳」的承诺。

**定义 456（来源分层共形校准 PSC）**
`stratum(i,c,τ)=(role_i, c∈{isolated,parallel,safe-serialized}, tool/material family)`。每层校准集 `C_cal^s` 取分位 `q_s` 使层内覆盖 `P(h*∈H_s|s)≥1−α`。跨机合并仅在**可交换性检验**（双样本 KS / e-value）于水平 `β` 通过时允许，并计入间隙 `Δ_pool`；否则逐机独立校准。团队覆盖取 `min_i cov_i`（安全是短板，不是均值）。`|C_cal^s|<n_min` ⇒ 回退 SC-Cal 分层 ⇒ 全局共形（引理 64）。

**定义 457（协同放大因子 κ_coop 与团队块长）**
`κ_coop = N_par·(1+Γ)·K·H(ι|ℓ)`，`H(ι|ℓ)` 为接地槽位条件熵（继承定义 440），`N_par` 为最大并发数。
`K_MAX^team(ι,σ)=⌊K₀/(1+κ_coop)⌋`。并发越多、耦合越强、指令越含糊 ⇒ 块越短。精确退化：`N_par=1, Γ=0 ⇒ κ_coop=κ_sem` 且 `K_MAX^team=K_MAX`（定义 440）。

**定义 458（团队静默点与两阶段重配置）**
`q_quiesce^team`：所有机处于已稳边界、无在途块、无待处理不可逆动作、无 `provisional` 回执待决。共享契约/调度的热替换**只允许**发生在 `q_quiesce^team`，并经 `G_c` 上的两阶段提交：`prepare`（锁定新版本）→ 全部 `ack` 后 `commit`；任一缺失 `ack` ⇒ `abort` 并保留旧版本，绝不出现部分重配置。扩展定义 439。

**定义 459（团队预算准入）**
`B_split=Σ_i c(π_i)+c_comm+c_sync+c_settle`。准入当且仅当 `B_split≤B_left` 且团队期望信息增益/代价 `≥ρ_min`。`c_settle` 显式计入（等待稳态是**真实成本**），使「多探」不能靠压缩沉降时间虚报净收益。

**定义 460（证据来源与隔离）**
每条回执携带 `prov(r)=(agent_id, chunk_id, SettleCert, t, signature)`。**无来源或未过沉降证书 ⇒ 无证据**：不得入共识/校准。若同一动作被重复主张、或残差越出共形界 `>q_{1−α}` ⇒ 隔离该机 `Q`，在 `A_trusted\Q` 上重算共识；标准假设下 `|Q|<N/3` 时共识有效性保持。隔离与拒绝均写审计日志，绝不静默继续。

**定义 461（团队修复证书）**
`RepairCert^team=(K, σ, {C_i}, {SettleCert_i}, XCT, {PSC cert}, receipts, claims, veto_log, quarantine_log)`。五级审计链：团队契约 → 调度 → 逐机块 → 已稳回执 → 主张，使人类可复现一次多机修复。

**定义 462（退化映射 D_map）**
`D_map` 把每种失败条件映射到**语义恒等**的基线：`N=1∧Γ=0∧τ_settle=0 ⇒ InstructGauge`；`SettleCert` 不可得 ⇒ 保守驻留/`K=1`（ToolGauge）；`XCT`/`CompositionCert` 失败 ⇒ 串行化/`K=1`（ToolGauge）；取交空/veto ⇒ 逐机 InstructGauge；PSC 不足 ⇒ SC-Cal（引理 55）⇒ 全局（ToolGauge）；InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。`D_map` 不含近似超参，因而是构造性恒等而非「大致退回」。

**定义 463（团队信息价值与角色分配）**
对盲区集合 `B`，`assign(b)=argmax_i E[ΔH(b;i)]/(cost_i+c_settle,i)`，约束 `b∈capability_i` 且调度可采纳；`VoI^team(B)=Σ_b max_i E[ΔH(b;i)]`。这是小规模指派问题，可用共形下界贪心求解。`N=1` 时退化为 IAC 的 `ΔH(C)`。

class SettlingSupervisor:
    def certify(self, i, t_end, u_i):

        rho = self.residual_trace(i, t_end, x_inf)          # ρ_i(t)

              and max(rho[-tau:]) <= EPS_OV)

class CrossTalkScheduler:

                    + norm(self.w[i]) for i in sigma}
        ok = max(delta.values()) <= DELTA_TOL
        return XCT(sigma, delta, ok)

    def schedule(self, agents, actions, irreversibles):

                G.add_edge((i,ti),(j,tj))                   # 硬冲突
        return color_independent_sets(G)                    # 可采纳并发集

# IP-333 D-CVC：已稳安全前缀截断
class DCVC:
    def commit(self, C, env, iota, team):
        t, provisional = 0, set()
        while t < len(C.actions):
            step = C.actions[t]
            settled = all(team.settle.valid(r) for r in step.receipts)
            xt_ok   = team.sched.certify(team.concurrent_at(t), env.us)
            ok = (C.joint_pre(env.snapshot()) and still_grounded(iota, env)
                  and drift(env.snapshot(), C.pred[t]) <= C.delta_c
                  and settled and xt_ok and not team.conflict_within(C, t))
            if not ok:
                provisional |= set(range(t, len(C.actions)))
                C = C.truncate(t)                            # 只保留已稳安全前缀
                break
            env.apply(step); t += 1
        return C, DChunkCert(C, verified_prefix=t, provisional=provisional,
                             xct=team.sched.last)

## 4. 推导

**引理 59（单机/准静态退化等价）** 当 `N=1`、`G_ij≡0`、`τ_settle=0`（回执即时有效）、无并发时，`S^team=S_1`、`p^team=p_1`、`G_conf=∅`、`XCT` 恒真、`D-CVC≡CVC`、`PSC≡SC-Cal`；`CoDynGauge` 的整条执行路径与 InstructGauge **逐指令等价**。
*证明骨架*：对 9C 闭环与 7C 闭环作结构归纳。`N=1` 时定义 448 的 `Plan(K)` 逐条等于 `Plan(ι)`；定义 451 的交退化为 `S_1` 且组合证书退化为单机不变性；定义 457 的 `κ_coop` 化为 `κ_sem`，`K_MAX^team=K_MAX`；定义 455 的额外合取项（已稳、`XCT`、无冲突边）在假设下恒真。故每步 argmax 与截断规则一致。

**引理 60（安全取交的组合可靠性）** 若 `∀i, S_i` 是该机**独立**闭环的不变集，且存在 `CompositionCert` 使耦合闭环满足 `L_f S^team ⊕ (Σ_{i≠j}G_ij U_j ⊕ W) ⊆ S^team`，则 `S^team` 是耦合闭环的不变集，且 `S^team⊆S_i, ∀i`；因此团队执行不会出现「被平均掉的」安全违反。
*证明*：不变性定义直接给出前件；交集对任意集合有 `⋂S_i⊆S_j`。关键在于**只有**加上耦合项与扰动的包含关系，交集才仍是耦合闭环的不变集——这正是组合证书要检查的内容。反例：两台设备各自的安全集都允许在其邻域内独立运动，但耦合项使联合状态越出交集；此时 `CompositionCert` 失败，必须按定义 454 串行化。该引理是「局部证书不能自动相加」的正式表述。

**引理 61（沉降证书的偏差界）** 若 `SettleCert_i(t_e)` 成立且 `h_i` 为 `L_h`-Lipschitz，则 `‖y_i(t_e)−y_i^∞‖≤L_h ε_s`；在衰减见证下，若在 `t_e` 截断，额外偏差 `≤L_h ε_s e^{−λ_i τ_i}`。因此排除未稳回执等于删去一个随前一动作激励幅度增长的偏差项。
*证明*：Lipschitz 性与三角不等式给出即时界；衰减见证由离散比较引理（`ρ(t)≤e^{−λ(t−t_0)}ρ(t_0)+ε_s`）给出截断余项。若不做沉降判定，偏差上界只能由 `ε_ov` 给出，而 `ε_ov≫ε_s`。

**引理 62（串扰证书的偏差界）** 在线性耦合与有界扰动下，
`‖Δy_i‖ ≤ L_h(Σ_{j≠i}γ_ij‖u_j‖+‖w_i‖)/(1−L_f)`。
故 `XCT(σ)` 成立 ⇒ 并发探测的量测偏差 `≤ε_ct`。若 `γ` 为保守上界，判据是充分的；若 `γ` 为估计值，须用共形上置信界，否则不构成证书。
*证明*：叠加原理给出扰动上界，`(1−L_f)^{-1}` 由几何级数求和（`L_f<1`）；`h_i` Lipschitz 传递到输出。共形版本的覆盖由 split conformal 给出。

**引理 63（屏障的进度与 makespan）** 若冲突图 `G_conf` 的并发约束只要求「同色不并发」，则存在调度使 makespan `≤χ(G_conf)·max_i T_i`；串行贪心调度在有限步内完成，且不可逆槽永远为单例。
*证明*：图着色给出 `χ` 个独立集，逐轮执行；每轮内所有槽无冲突边，故 `XCT` 或资源约束满足。对称冲突关系下贪心着色有限终止。不可逆槽按定义 454 不与任何槽同组，故单例。无 livelock：调度是静态分轮的，不依赖运行时协商。

**引理 64（来源分层覆盖）** 层内可交换下逐机覆盖 `≥1−α`。跨机合并若未通过可交换性检验，覆盖可低至 `1−α−Δ_pool`；通过检验并加权共形时，覆盖 `≥1−α−(w_max−1)/(w_max+1)` 量级。团队覆盖是 `min_i cov_i`。低样本层回退 SC-Cal 时按引理 55 的 `−2η_global` 优雅降级。
*证明*：逐机 split conformal 的标准覆盖；合并间隙由总变差/密度比界给出；团队取 `min` 因安全约束必须对每台机成立（短板）。回退项直接引用引理 55。

**引理 65（协同放大界）** 已稳可逆动作的期望损失仍为线性 `D_rev≤p_gΣ_t c_t`；并发把「同时承诺的动作数」放大到 `N_par`，耦合把有效误差放大到 `(1+Γ)` 倍，故 `D_rev^team≤p_g(1+Γ)N_par Σ_{t=1}^{K}c_t`；不可逆部分按屏障与 `K=1` 解耦，`D_irr≤p_g c_irr` 与 `N_par,K` 无关。由 `K≤K_MAX^team`，放大被 `(1+κ_coop)` 夹住。`N_par=1,Γ=0` 时回到引理 56。
*证明*：对并发槽用并集界（联合错误概率至多线性相加）；耦合项由引理 62 的增益界进入单槽误差；不可逆由定义 454/445 隔离。最后代入 `κ_coop` 的定义即得块长夹逼。

**引理 66（两阶段重配置原子性与 50Hz 保全）** 若重配置只在 `q_quiesce^team` 且经 `2PC` 全 `ack` 才提交，则在途块不会观察到「混合契约」；`abort` 保留旧版本。团队编排、共识、校准均在异步路径；主循环新增同步工作仅为 `O(1)` 的静默点/版本检查，`<0.2ms`。
*证明*：标准两阶段提交的原子性；静默点排除并发读者/写者，故无块跨越版本切换。时序：同步段只有状态判读与一次原子指针交换，复杂度 `O(1)`；其余下沉到异步线程，继承 ToolGauge 引理 50 的硬实时结论。

## 8. 本轮最大风险

**一句话**：`SMC` 的安全取交与 `SSR` 的沉降证书各自都只在「局部、独立、已稳」的假设下成立，而 `XCT` 与并发恰恰让这两个假设同时失效——组合证书一旦被近似或放松，交集就会给出「局部安全、耦合越界」的假保证；真正的残余风险在**局部证书在耦合动力学下的可组合性**，而不在单机的任何组件。
