# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序」IP-214~223；灵感循环第 3 轮；本轮灵感：「中间件」×「状态估计」）

> 第 65 轮把“几何可证伪”升级为“故障可归因”，其自述的最大风险是：**归因依赖有限假设集与视觉/几何失效独立，而真实故障常是未知复合故障；透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，FIR 于是把未知故障强行归入最近假设，只膨胀错误的球，系统反而因“已经归因”而更自信地继续执行。** 本轮不再扩故障库，而是换问题：**不问“是哪一种故障”，改问“当前状态在哪些方向上被一致地确定、哪些方向根本不可观测，以及执行是否只发生在被认证的方向上”。** 核心命题：
>
> **把“故障归因”降级为“状态完整性契约”：用中间件把来源、时序、信任做成不可变包络与运行时契约，用状态估计的可观测性/一致性把“谁坏了”转成“哪些状态方向可信、哪些方向必须膨胀或禁止使用”，并用主动可观测性调度代替主动故障判别。**

## 0. 直觉与动机

**灵感 1（中间件 → 信任不应由单点归因器垄断）**
直觉：第 65 轮的 FIR 像一个“全知诊断中心”，所有模态都把残差交给它，它再宣布“谁坏了”。这既单点，又把“信任”变成了一个分类输出。中间件的真正价值不是消息转发，而是**拥有时间、来源、生命周期、QoS 与降级权**：它可以让每条观测携带不可篡改的来源 DAG、标定版本、采集时刻、有效期与健康令牌；一旦某组件越界，中间件负责隔离、切换与回滚，而不是让一个中心分类器猜。于是“共因失效”不再靠“假设独立”来祈祷，而可以被**来源重叠**直接看见。

**灵感 2（状态估计 → 可观测性决定“能不能知道”，不是“猜得准不准”）**
直觉：第 65 轮隐含假设“故障可被有限假设区分”。但状态估计的第一性事实是：**若故障方向落在观测矩阵的零空间里，任何滤波器和分类器都不可能把它与状态变化分开**；Cramér-Rao 下界直接发散。继续提高分类器容量只是把“不可辨识”包装成“高置信误判”。正确目标不是“一定说出谁坏了”，而是维护一个**一致的、方向性保守的**状态估计：可观测方向正常认证，不可观测/被障碍污染的方向做各向异性膨胀，若安全函数依赖该方向则直接禁止相应动作。

**灵感 3（二者合流 → 用“一致束的障碍”替代“故障假设集”）**
直觉：把每个模态/时间窗看成状态丛上的一个局部截面，把标定、时间、坐标变换看成限制映射。中间件的任务是把这些局部截面**粘合（gluing）**成全局状态。没有故障时粘合成功；有故障时，粘合在环路上留下**非零障碍（obstruction）**。障碍的支撑集直接指出“哪条关系不可信”，不需要预先枚举故障类型；而障碍落在哪个状态子空间，决定该方向是否可认证。这把第 65 轮的“有限假设分类”换成“稀疏障碍定位 + 可观测性认证”。

**灵感 4（LOOM：Layered Observability & Obstruction Middleware，分层可观测-障碍中间件）**
闭环：各模态发布估计包络 EPE → 中间件做来源共因检测 PCD 与时间对齐/固定滞后 TAC → 一致束估计器 LSE 做鲁棒融合并计算障碍 → 障碍定位 OCL 给出不可信关系集 → 一致性监控 CSM → 完整性契约 IC 签发“哪些方向可信” → 主动可观测性调度 AOS 只在必要时做低成本观测/运动 → 契约约束规划 CCP 只执行安全方向上的前缀 → 中间件故障隔离与纪元切换 MFC 保证不混入陈旧/重放消息 → J_loom 证书。第 65 轮问“该膨胀哪个球”，LOOM 问“**该禁止哪个方向**”。

**灵感 5（对 VISTA 组件的原位升级）**
- **FIR → OCL**：不再输出 6 类故障后验，而输出障碍支撑集与不可信关系；未知复合故障自然表现为“障碍无法被稀疏解释”。
- **AFA → AOS**：探针目标从“故障假设互信息”改为“安全相关状态方向的可观测性增益”；易损物体优先选择零接触的视角/运动视差。
- **RSC-V → 各向异性契约膨胀**：把 r_geo/r_force/r_model 三个标量球升级为 Σ_infl 的方向性膨胀；只在不可观测/被障碍污染的子空间膨胀，其余方向保持不变。
- **CSC → 契约认证前缀 k*_cert**：不仅验证力/滑移，还验证“前缀的每一步其安全相关分量都落在已认证子空间”。
- **WCV-V → 一致束约束搜索**：搜索域增加“与已认证全局截面一致”的约束，而非只加视觉可观测性。
- **CSP-V → 契约层规划**：技能边绑定“所需可观测方向集合”，规划器不得选择当前契约未覆盖的技能。
- **J_grip/J_vista → J_loom**：证书增加 contract、obstruction_support、provenance_independence、anchor_independence、delay_bound、observability_margin、epoch_id。
- **AIC-V → AIC-L**：干扰集增加伪造来源、重放、时钟偏移、共因故障与拜占庭估计器。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（LOOM 闭环）**：LOOM = (GRIP, VISTA, EPE, PCD, TAC, LSE, OCL, CSM, IC, AOS, CCP, MFC, AIC-L, J_loom)。不变式：**中间件是唯一有权签发/撤销“状态完整性契约”的组件；规划器只能读取契约允许的投影；所有估计包络不可变；实时流只做时间对齐、契约检查与派发，零学习写。**
- **定义 234（估计包络 EPE）**：每条观测封装为 m=(id, src, t_s, t_a, t_r, x̂, Σ, calib_id, model_id, prov, health, epoch, nonce)，其中 t_s 为源时刻、t_a 为采集时刻、t_r 为到达时刻，prov 为来源 DAG 的哈希根。包络不可变；接收方只能读取，不能就地修改。时间语义以 t_s 为准，t_a 用于延迟补偿，t_r 用于 QoS。
- **定义 235（来源 DAG 与共因重叠）**：P=(V,E) 为来源图，根节点为物理源、标定、模型、软件与**环境对象**；Anc(v) 为 v 的祖先集合。定义来源重叠 ω_ij=|Anc(i)∩Anc(j)|/|Anc(i)∪Anc(j)|，并假设 A94：误差相关系数 |ρ_ij|≤ω_ij。若 ω_ij>ω_0，二者视为同一共因簇，融合时不得使用朴素独立乘积。
- **定义 236（局部估计与归一化创新）**：模态 i 的观测模型 z_i=H_i x+b_i+f_i+n_i，n_i∼(0,Σ_i)，b_i 为偏置、f_i 为故障。创新 e_i=z_i−H_i x̂^−，归一化创新平方 NIS_i=e_i^T S_i^{−1} e_i，S_i=H_i P^− H_i^T+Σ_i。门限由 conformal 给出，不假设高斯。
- **定义 237（时间对齐与固定滞后）**：维护长度 L 的包络缓冲，时刻 t 的可用状态为 as-of 估计 x̂_{t|t−Δ}；延迟误差上界
  ε_delay(t,Δ)=v_max Δ+½ a_max Δ²。
  仅当 ε_delay 纳入契约不确定集且 Δ≤Δ_max 时，该估计可被认证；超期包络只进入固定滞后平滑器，不得进入当前滤波。定义纪元 epoch 与单调序号，旧纪元包络一律丢弃。
- **定义 238（估计一致束）**：底图 G=(V,E) 的顶点为“模态-时间窗”单元，每顶点有局部状态空间（stalk）F_v；每条边 e=(u,v) 有限制映射 R_{u←e}, R_{v←e} 与观测相对量 y_e。局部截面为 x_v，边上的不一致为
  z_e=R_{u←e}x_u−R_{v←e}x_v−y_e。
  若 ‖z_e‖_{W_e}≤τ_e 对所有边成立，则存在全局截面 x（粘合成功）；粘合算子记为 Glue({x_v})。
- **定义 239（障碍与稀疏定位）**：令 D 为从顶点状态到边不一致的 coboundary 算子，y=Dx+z。障碍类 [z] 属于 H^1(G;F)。当 z 稀疏时，求解
  E_bad=argmin_{E'} |E'|  s.t.  ∃x: supp(y−Dx)⊆E'，
  以最小不一致边集定位不可信关系。E_bad 是“哪条关系不可信”，**不是“哪个组件坏了”**；未知复合故障表现为 E_bad 无法被稀疏解释或障碍维度过高。
- **定义 240（束拉普拉斯、可观测性与认证子空间）**：束拉普拉斯 L_F=D^T W D。融合估计
  x̂=argmin_x ‖Dx−y‖_W²+‖x−x_prior‖_{P_prior^{−1}}²。
  对安全相关状态方向集合 S，计算可观测 Gramian W_o(S)=Σ_t Φ_t^T Π_S^T H_t^T Σ_t^{−1} H_t Π_S Φ_t。取 U_cert=span{u: λ_u(W_o)≥λ_min}，U_unc 为其正交补；可观测裕度 κ_obs=λ_min(W_o|_S)/λ_max(W_o|_S)。**故障方向 u∈U_unc 的 Cramér-Rao 下界为 1/(u^T W_o u)→∞，任何分类器都无法可靠区分。**
- **定义 241（一致性监控 CSM）**：对每条边与每个方向维护 NIS、白化残差与 CUSUM 统计量；一致性状态 c_t∈{consistent, degraded, obstructed}。阈值由 split-conformal 或分位数标定；CSM 只报告“哪些关系/方向不一致”，不输出故障标签。
- **定义 242（完整性契约 IC）**：C_t=(U_cert, Σ_infl, P_t, Δ_max, expiry, epoch, anchor_independence)。Π_cert 为到 U_cert 的投影；规划器只允许读取 x̂_cert=Π_cert x̂ 与 Σ_infl。契约有有效期，过期即失效；anchor_independence 表示至少存在一个与主融合状态来源不共享祖先的独立锚（运动学闭合、重力、准静态平衡、时间连续性等）。
- **定义 243（各向异性不确定膨胀）**：设 Σ 为融合协方差、{u_j} 为 U_unc 的正交基，则
  Σ_infl=Σ+Σ_{j∈U_unc} α_j u_j u_j^T，
  α_j 由 conformal 或最坏情形给出。若安全函数 g(x,a) 的梯度在 U_unc 上有非零分量且无法被 Σ_infl 界定，则**不是继续膨胀，而是禁止依赖该方向的动作**。这替代第 65 轮的标量 r_geo/r_force/r_model。
- **定义 244（主动可观测性调度 AOS）**：选择观测/运动/探针 a，使得
  a*=argmax_a λ_min(Π_S W_o(a) Π_S)  （或等价地最大化 I(x_S; z_{1:k}(a))），
  s.t. 预测力≤f_safe、形变≤ε_strain、延迟≤Δ_max、不增加未建模共因来源。AOS 的目标是“把安全相关状态方向变得可观测”，而不是“把故障标签变得可分”。
- **定义 245（契约约束规划 CCP）**：动作 a 可采纳当且仅当
  ‖Π_unc a‖≤ε_a  且  min_{x∈X_infl} g(x,a)≥0，
  其中 X_infl 由 x̂_cert 与 Σ_infl 构造。认证前缀 k*_cert 是满足“每一步都可采纳且安全相关分量均落在 U_cert”的最大前缀；k*_cert≤m（不可逆视界）。
- **定义 246（中间件故障隔离与纪元切换 MFC）**：每个组件有生命周期与健康状态；当契约失效或 CSM 进入 obstructed，中间件原子地切换到降级图 G'（例如移除被障碍污染的关系、替换为保守先验），并递增 epoch。切换满足：旧 epoch 包络全部丢弃、切换前快照可回滚、切换过程无部分写入。消息带 nonce 与 epoch，重放/陈旧消息在准入层被拒绝。
- **定义 247（AIC-L 认证）**：干扰集 ℰ_L=ℰ_V×ℰ_prov×ℰ_time×ℰ_byz，其中 ℰ_prov 含伪造来源/共享标定错误，ℰ_time 含时钟偏移/重放/乱序，ℰ_byz 含拜占庭估计器；并要求在最坏来源重叠 ω=1 下重算契约。**共因故障下不要求定位正确，只要求契约变为 unanchored 并禁止高风险动作。**
- **定义 248（J_loom 证书）**：J_loom=(J_vista, contract, obstruction_support, provenance_independence, anchor_independence, delay_bound, observability_margin, epoch_id, aic_l_ver)。Valid ⇔ Valid(J_vista) ∧ 契约未过期 ∧ (安全相关方向全部在 U_cert ∨ 对应动作被禁止) ∧ (来源独立性达标 ∨ 已按共因膨胀) ∧ 延迟在界内 ∧ 存在独立锚 ∧ epoch 一致。

## 2. 关键算法骨架

```python
# EPE：不可变包络 + 准入（中间件）
def admit(env):
    if env.epoch < current_epoch: return DROP          # 纪元围栏
    if not verify(env.nonce, env.src): return QUARANTINE
    if env.t_r - env.t_s > DELAY_MAX: return SMOOTHER   # 只进固定滞后
    buffer.insert(env, key=env.t_s); return ADMIT

# PCD：来源重叠 → 共因簇
def provenance_weight(src_a, src_b):
    a, b = ancestors(src_a), ancestors(src_b)
    return len(a & b) / max(len(a | b), 1)              # A94: |rho| <= omega

# OCL：一致束融合 + 稀疏障碍定位
def sheaf_localize(edges, y, W, lam=0.1):
    D = coboundary(edges)                                # y = D x + z
    x_hat = solve((D.T @ W @ D + lam * I), D.T @ W @ y)
    z_hat = basis_pursuit(D, y, x_hat)                   # min ||z||_1
    E_bad = {e for e, z in zip(edges, z_hat) if abs(z) > TAU_E}
    return x_hat, E_bad

# IC：可观测性分解 → 各向异性契约
def make_contract(x_hat, P, H, S_safe, E_bad):
    Wo = observability_gramian(H, P, S_safe)
    U_cert, U_unc = split_eigenspace(Wo, LAMBDA_MIN)
    Sigma_infl = inflate_anisotropic(P, U_unc, alpha=ALPHA_CONF)
    anchor_ok = has_independent_anchor(E_bad)
    return Contract(U_cert, Sigma_infl, E_bad, anchor_ok, epoch)

# CCP：只执行安全方向上的认证前缀
def certified_prefix(actions, contract):
    k = 0
    for a in actions:
        if not in_certified_subspace(a, contract.U_cert): break
        if robust_margin(a, contract.Sigma_infl) < 0: break
        k += 1
        if k >= m: break
    return k

# MFC：原子纪元切换 + 回滚
def switch_epoch(e_new, G_new):
    with epoch_lock:
        snap = snapshot()
        current_epoch, graph = e_new, G_new
        fence(e_new)                                    # 丢弃旧 epoch
        if not contract_valid(): restore(snap)          # 原子回滚
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（来源相关下的融合一致性）**：若 A94 成立，两个估计的误差相关被 ω_ij 上界，则协方差交集（CI）以权重 ω_ij 融合给出的 P_CI 是真实误差协方差的 PSD 上界；朴素独立融合在 ω_ij>0 时会低估协方差。故 LOOM 的“共因簇”不是启发式，而是防止过度自信的充分条件。
- **引理 10（障碍定位）**：若不一致 z 是 s-稀疏的，且束的环空间冗余矩阵满足 spark 条件（2s<spark），则最小不一致边集 E_bad 可由 ℓ1 基追踪唯一恢复；E_bad 的支撑定位不可信关系，而不需要故障标签。未知故障表现为 E_bad 过大或残余障碍非稀疏，契约自动降级。
- **定理 9（可观测性下界）**：对任意基于 z 的无偏故障估计器，若故障方向 u∈ker(W_o)，则 Cramér-Rao 下界 Var(f̂_u)≥1/(u^T W_o u)=∞；近不可观测方向的方差按 1/λ_min 发散。因此第 65 轮“有限假设归因”在不可观测方向上原理性不可行，LOOM 的契约式降级不是保守，而是唯一可证的选择。
- **定理 10（契约安全性）**：若动作只依赖 U_cert 投影、Σ_infl 覆盖真实误差（概率≥1−α）、延迟误差≤ε_delay、且存在独立锚，则安全事件 g(x*,a)≥0 的概率≥1−α−β−γ。证明把误差分解为认证误差、未认证膨胀误差与延迟误差，再用 g 的 Lipschitz 性与并集界。
- **定理 11（时间隔离/纪元围栏）**：若中间件丢弃所有 epoch<current 的包络、且估计器只消费同一 epoch 且 t_s 在延迟界内的包络，则 epoch e+1 的状态只依赖 e+1 及已提交历史，重放/乱序/陈旧消息不能污染新纪元。由 epoch 归纳与原子切换直接得证。
- **定理 12（AOS 的增益-风险权衡）**：在线性高斯模型下，AOS 选择使安全方向 λ_min(W_o) 增益最大的观测；在预算约束下其风险下降至少与 λ_min 的增量成正比。与第 65 轮 AFA 的故障互信息相比，AOS 不要求故障可辨识，因而在不可观测/共因场景仍能降低契约不确定度。
- **实时性**：包络准入、PCD 哈希比对、时间对齐、契约投影与 CCP 前缀检查在实时流，目标 ≤1.8ms；束融合、障碍定位、AOS、AIC-L 全在语义流。

## 5. 本轮最大风险

**一句话**：LOOM 的安全性依赖“来源 DAG 与限制映射是诚实且完备的”这一假设；若真实共因没有被记录（同一未建模物理、同一错误标定、同一 OOD 环境对象被所有模态共享），一致束会把**共同错误的局部截面粘成一个错误的全局截面**，而中间件的权威会让这个错误契约系统性地传播到规划与执行——**第 65 轮“归因错误的复合故障”由此升级为“被中间件正式认证的复合故障”**，这是本轮全部契约与可观测性论证共同依赖的隐藏假设（A94/A99）。

## 2. 形式化定义（完整版）

**定义 233（LOOM 闭环）** LOOM 是在 GRIP/VISTA 骨架上的“状态完整性中间件”升级。语义流：[LiDAR→LSF→USR/MEL→VPG 视觉前瞻→ACH 块生成→EPE 包络化→PCD 共因检测→TAC 时间对齐→LSE 一致束融合→OCL 障碍定位→CSM 一致性监控→AOS 主动可观测性调度→IC 契约签发→CSP-V 块规划→CCP 契约认证前缀→WCV-V/Shield→执行 k*_cert 步→EV_exec→RSC-V 方向膨胀→OLP→DIR→AIC-L]；实时流：[EPE 准入→PCD 哈希查表→TAC as-of 对齐→契约投影→CCP 前缀检查→π_σ 派发→J_loom 构建]。不变式：**中间件是唯一有权签发/撤销信任契约的组件；估计包络不可变；规划器不得绕过契约读取原始状态；实时流零学习写操作。**

**定义 234（估计包络 EPE）** 每条观测写为不可变包络
m=(id, src, t_s, t_a, t_r, x̂, Σ, calib_id, model_id, prov, health, epoch, nonce)，
其中 t_s 为源时刻、t_a 为采集时刻、t_r 为到达时刻，prov 为来源 DAG 根哈希，health 为组件健康令牌，epoch 为单调纪元，nonce 防重放。包络发布后只读；接收方只能基于包络做准入、对齐与融合，不得就地改写。时间语义以 t_s 为准，t_a 用于延迟补偿，t_r 用于 QoS 与超期判定。

**定义 235（来源 DAG 与共因重叠）** 来源图 P=(V,E) 的根节点包括物理传感器、标定过程、模型训练数据、软件版本与**环境对象**；Anc(v) 为 v 的全部祖先。定义来源重叠
ω_ij=|Anc(i)∩Anc(j)|/|Anc(i)∪Anc(j)|。
假设 A94：两估计误差的相关系数满足 |ρ_ij|≤ω_ij。若 ω_ij>ω_0，二者归入同一共因簇；簇内融合必须使用协方差交集或显式相关模型，禁止朴素独立高斯乘积。若来源 DAG 不完整，则由 AIC-L 将其视为 ω=1 的最坏情形。

**定义 236（局部估计与归一化创新）** 模态 i 的观测模型
z_i=H_i x+b_i+f_i+n_i，n_i∼(0,Σ_i)，
b_i 为未建模偏置，f_i 为故障。创新 e_i=z_i−H_i x̂^−，S_i=H_i P^− H_iᵀ+Σ_i，NIS_i=e_iᵀ S_i⁻¹ e_i。门限 τ_NIS 由 split-conformal 在健康标定集上取分位数，不假设高斯。NIS 只用于一致性判定，不直接解释为故障标签。

**定义 237（时间对齐与固定滞后）** 维护长度 L 的包络缓冲，时刻 t 可用 as-of 状态 x̂_{t|t−Δ}。延迟误差上界
ε_delay(t,Δ)=v_max Δ+½ a_max Δ²。
仅当 Δ≤Δ_max 且 ε_delay 被纳入 Σ_infl 时，该状态可参与认证；t_r−t_s>Δ_max 的包络只进入固定滞后平滑器，不得进入当前滤波。每个包络带 epoch 与单调序号；epoch 小于当前值的包络在准入层丢弃，序号倒退或 nonce 复用视为重放并隔离。

**定义 238（估计一致束）** 底图 G=(V,E) 的顶点为“模态-时间窗”单元，顶点 v 的 stalk F_v 为局部状态空间（位姿、接触几何、力/形变的切空间）；边 e=(u,v) 有限制映射 R_{u←e}, R_{v←e}（坐标变换、标定、时间对齐）与观测相对量 y_e。局部截面 x_v∈F_v，边不一致
z_e=R_{u←e}x_u−R_{v←e}x_v−y_e。
若对所有边 ‖z_e‖_{W_e}≤τ_e，则存在全局截面 x，称粘合成功，记为 Glue({x_v})。若不存在，则障碍类 [z]∈H¹(G;F) 非零，粘合失败。

**定义 239（障碍与稀疏定位）** 令 D 为 coboundary 算子，观测满足 y=Dx+z。当 z 稀疏时，最小不一致边集
E_bad=argmin_{E'} |E'|  s.t.  ∃x: supp(y−Dx)⊆E'。
实现上用 ℓ1 基追踪
min_z ‖z‖_1  s.t.  ‖P_cycle(y−z)‖≤ε，
其中 P_cycle 为到环空间的投影。E_bad 定位“哪条关系不可信”，**不声称“哪个组件坏了”**；未知复合故障表现为 E_bad 过大、残余障碍非稀疏或 H¹ 维度过高，此时契约进入 degraded/unanchored，而不是强行归因。

**定义 240（束拉普拉斯、可观测性与认证子空间）** 束拉普拉斯 L_F=DᵀWD，融合估计
x̂=argmin_x ‖Dx−y‖_W²+‖x−x_prior‖_{P_prior⁻¹}²。
对安全相关状态方向集合 S，可观测 Gramian
W_o(S)=Σ_t Φ_tᵀ Π_Sᵀ H_tᵀ Σ_t⁻¹ H_t Π_S Φ_t，
其中 Φ_t 为状态转移。取 U_cert=span{u: λ_u(W_o)≥λ_min}，U_unc=U_cert^⊥，可观测裕度
κ_obs=λ_min(W_o|_S)/λ_max(W_o|_S)。
若故障方向 u∈U_unc，则 uᵀW_o u=0，Cramér-Rao 下界 1/(uᵀW_o u)=∞：任何基于 z 的无偏估计器都无法可靠区分该故障与状态变化。

**定义 241（一致性监控 CSM）** 对每条边 e 与每个认证方向维护白化残差 r_e=W_e^{1/2}z_e、NIS_e=‖r_e‖²，以及双侧 CUSUM
g_e^+=max(0,g_e^+ + r_e−k)，g_e^−=max(0,g_e^− − r_e−k)。
若 NIS_e 超过 conformal 门限或 CUSUM 超过 h，标记该边/方向不一致。一致性状态 c_t∈{consistent, degraded, obstructed}：consistent 表示存在全局截面且所有安全方向在 U_cert；degraded 表示存在全局截面但有方向落入 U_unc；obstructed 表示障碍不可稀疏解释或关键边失效。CSM 不输出故障标签。

**定义 242（完整性契约 IC）** 契约
C_t=(U_cert, Σ_infl, P_t, Δ_max, expiry, epoch, anchor_independence)，
其中 U_cert 由定义 240 给出，Σ_infl 由定义 243 给出，P_t 为本轮实际参与融合的来源集合，expiry 为有效期，epoch 为签发纪元，anchor_independence 表示至少存在一个独立锚 a∉P_t 且其来源与 P_t 无共同祖先。规划器只能读取 x̂_cert=Π_cert x̂ 与 Σ_infl；契约过期或 epoch 不匹配即失效。

**定义 243（各向异性不确定膨胀 AUI）** 设 Σ 为融合协方差，{u_j} 为 U_unc 的正交基，则
Σ_infl=Σ+Σ_{j∈U_unc} α_j u_j u_jᵀ，
α_j 由 conformal 覆盖或最坏情形界给出。若安全函数 g(x,a) 在 U_unc 上存在非零梯度且 min_{x∈X_infl}g(x,a)<0，则**不是继续膨胀，而是禁止 a**。这替代第 65 轮的标量 r_geo/r_force/r_model：第 65 轮在任何拒绝时膨胀同一个球，LOOM 只膨胀不可认证方向，并在安全依赖该方向时直接切断动作。

**定义 244（主动可观测性调度 AOS）** 选择观测/运动/探针 a，使得
a*=argmax_{a∈A} λ_min(Π_S W_o(a) Π_S)
（或等价地最大化安全状态方向与观测的互信息 I(x_S; z_{1:k}(a))），
s.t. 预测力 f_n≤f_safe(φ̂,f̂_vis)、预测形变≤ε_strain、延迟≤Δ_max、且不引入新的未建模共因来源。与第 65 轮 AFA 不同，AOS 不要求故障假设可分；它把“分清楚谁坏了”换成“把安全相关状态方向变得可观测”。易损物体优先 `visual_probe`/运动视差；零接触不可行时退化为 `null_test`。

**定义 245（契约约束规划 CCP）** 动作 a 可采纳当且仅当
‖Π_unc a‖≤ε_a  且  min_{x∈X_infl} g(x,a)≥0，
其中 X_infl 由 x̂_cert 与 Σ_infl 构造。认证前缀
k*_cert=max{k≤min(H,m): ∀s≤k, a_s 可采纳且其安全相关分量∈U_cert}。
执行器只执行 k*_cert 步即强制重规划与重签契约；k*_cert≤m 沿用第 65 轮的不可逆视界约束。

**定义 246（中间件故障隔离与纪元切换 MFC）** 每个组件有生命周期与健康状态。当 CSM 进入 obstructed、契约失效或组件健康令牌过期，中间件原子地切换到降级图 G'（移除被障碍污染的关系、替换为保守先验、降低技能权限），并递增 epoch。切换满足：(i) 旧 epoch 包络全部丢弃；(ii) 切换前快照可回滚；(iii) 无部分写入（all-or-nothing）；(iv) nonce/序号单调，拒绝重放。降级图 G' 仍须通过 J_loom 的 Validity 检查，且必须保留至少一个独立锚；若无独立锚，只能进入 `safe_idle`/被动观测。

**定义 247（AIC-L 认证）** 干扰集
ℰ_L=ℰ_V×ℰ_prov×ℰ_time×ℰ_byz，
ℰ_prov 含伪造来源 DAG、共享标定错误、模型版本错配；ℰ_time 含时钟偏移、乱序、重放、30s 级延迟；ℰ_byz 含拜占庭估计器（发布虚假 x̂/Σ/health）。认证在最坏来源重叠 ω=1、最坏延迟 Δ_max、最坏视觉遮挡下重算契约与 k*_cert；n_cert 由 128 增至 160，其中 32 用于来源/时序/拜占庭/共因。J_dir 增 provenance_root_ver、clock_sync_ver、epoch_fence_ver。

**定义 248（J_loom 证书）** J_loom=(J_vista, contract, obstruction_support, provenance_independence, anchor_independence, delay_bound, observability_margin, epoch_id, aic_l_ver)。验证规则：
Valid(J_loom) ⇔ Valid(J_vista)
∧ 契约未过期且 epoch 一致
∧ (所有安全相关方向∈U_cert ∨ 对应动作已被禁止)
∧ (provenance_independence≥ω_0 ∨ 已按共因簇膨胀)

### IP-224/225 EPE 准入与来源共因检测

```python
class EnvelopeMiddleware:
    def __init__(self, delay_max, omega0=0.3):
        self.delay_max, self.omega0 = delay_max, omega0
        self.buffer, self.current_epoch = SortedBuffer(), 0

    def admit(self, env):
        if env.epoch < self.current_epoch:
            return 'drop_stale_epoch'
        if not self._verify(env.src, env.nonce):
            return 'quarantine_replay'
        if env.t_r - env.t_s > self.delay_max:
            self.smoother.push(env)                    # 只进固定滞后
            return 'late_to_smoother'
        self.buffer.insert(env, key=env.t_s)
        return 'admit'

    def provenance_overlap(self, a, b):
        A, B = ancestors(a.prov), ancestors(b.prov)
        return len(A & B) / max(len(A | B), 1)

    def clusters(self, envs):
        # 并查集：omega > omega0 的估计归入同一共因簇
        uf = UnionFind(len(envs))
        for i, j in combinations(range(len(envs)), 2):
            if self.provenance_overlap(envs[i], envs[j]) > self.omega0:
                uf.union(i, j)
        return uf.groups()
```

### IP-227/228/229 一致束融合、障碍定位与契约签发

```python
class SheafEstimator:
    def fuse_and_localize(self, edges, y, W, prior, S_safe, H):
        D = assemble_coboundary(edges)
        x_hat = solve_spd(D.T @ W @ D + prior.info, D.T @ W @ y + prior.info @ prior.mean)
        z_hat = self._basis_pursuit(D, y, x_hat)        # min ||z||_1, z 稀疏
        E_bad = {e for e, z in zip(edges, z_hat) if abs(z) > TAU_E}
        Wo = observability_gramian(H, prior.cov, S_safe)
        U_cert, U_unc = split_eigenspace(Wo, LAMBDA_MIN)
        Sigma_infl = self._inflate(prior.cov, U_unc, alpha=ALPHA_CONF)
        anchor_ok = self._has_independent_anchor(E_bad)
        contract = Contract(U_cert, Sigma_infl, E_bad, anchor_ok, epoch=CURRENT_EPOCH)
        return x_hat, E_bad, contract

    def _basis_pursuit(self, D, y, x0, iters=200):
        # 以 x0 为热启动，交替投影：残差稀疏 + 环空间一致性
        z = y - D @ x0
        for _ in range(iters):
            z = soft_threshold(z, LAMBDA_L1)
            z = project_to_cycle_space_complement(D, z, y)
        return z

    def _inflate(self, Sigma, U_unc, alpha):
        Sigma_inf = Sigma.copy()
        for j, u in enumerate(U_unc):
            alpha_j = conformal_quantile(j, alpha)
            Sigma_inf += alpha_j * np.outer(u, u)
        return Sigma_inf
```

class ActiveObservabilityScheduler:
    def choose(self, contract, phi_hat, f_safe, fragile):
        best, best_gain = None, 0.0
        for a in self.candidates(fragile):              # visual_probe / null_test / press / rub / tap / lift
            if fragile and a in ('press', 'rub', 'tap', 'lift'):

            gain /= (traj.cost + traj.time + 1e-9)

class ContractPlanner:
    def certified_prefix(self, A, contract, m, alpha_chunk):
        k_best = 0
        for k in range(1, min(len(A), m) + 1):
            if not all(in_certified_subspace(a, contract.U_cert) for a in A[:k]):
                break

                break

class EpochMiddleware:
    def switch(self, new_epoch, degraded_graph):
        with self.lock:
            snap = self.snapshot()
            self.current_epoch = new_epoch
            self.graph = degraded_graph

## 4. 推导

**引理 9（来源相关下的融合一致性）** 设两估计 x̂₁,x̂₂ 的误差协方差为 Σ₁,Σ₂，交叉协方差为 Σ₁₂，来源重叠 ω 满足 A94：‖Σ₁₂‖≤ω‖Σ₁‖^{1/2}‖Σ₂‖^{1/2}。协方差交集取
P_CI⁻¹=ωΣ₁⁻¹+(1−ω)Σ₂⁻¹，
x̂_CI=P_CI(ωΣ₁⁻¹x̂₁+(1−ω)Σ₂⁻¹x̂₂)。
由 CI 标准结论，对任意满足上述相关界的联合协方差，P_CI⪰Cov(x̂_CI)（PSD 序），即 CI 不会过度自信。若使用朴素独立融合 P_ind=(Σ₁⁻¹+Σ₂⁻¹)⁻¹，当 ω>0 时 P_ind 可能小于真实协方差，NIS 系统性偏大或偏小，导致误认证。故 PCD 的共因簇是“防止过度自信”的充分条件，而非启发式。∎

**引理 10（障碍定位）** 观测 y=Dx+z，z 为 s-稀疏边故障。若 D 在环空间上的限制满足 spark 条件 2s<spark(D_cycle)，则最小不一致边集 E_bad 是基追踪
min‖z‖₁ s.t. y−z∈im(D)
的唯一稀疏解。证明：将 y 投影到环空间，问题等价于用稀疏向量表示障碍类 [y]；spark 条件保证任意 2s 列的线性无关，故 ℓ1 与 ℓ0 解一致。E_bad 的支撑即不可信关系。若 z 非稀疏或 s 超过可定位上限，残余障碍无法被稀疏解释，CSM 判 obstructed，契约不签发强认证。∎

**定理 9（可观测性下界）** 设故障方向 u∈ker(H)（线性化后），即 H u=0。对任意基于 z=Hx+f+n 的无偏估计器 f̂_u，Fisher 信息 J_f=uᵀHᵀΣ⁻¹Hu=0，Cramér-Rao 下界 Var(f̂_u)≥1/J_f=∞。若 u 近不可观测，λ=uᵀHᵀΣ⁻¹Hu 很小，则 Var(f̂_u)≥1/λ 发散。故第 65 轮 FIR 在不可观测方向上不可能可靠归因；LOOM 不应尝试分类，而应把 u 放入 U_unc、膨胀 Σ_infl，并在安全函数依赖 u 时禁止动作。∎

**定理 10（契约安全性）** 设真实状态 x*=x̂_cert+e_cert+e_unc+e_delay，动作 a 只依赖 x̂_cert，且：
(i) P[‖e_cert‖≤δ_cert]≥1−α；
(ii) Σ_infl 以概率≥1−β 覆盖 e_unc；
(iii) ε_delay 以概率≥1−γ 覆盖 e_delay；
(iv) g 关于 x 的 Lipschitz 常数为 L_g，且在 X_infl 上 min g≥L_g(δ_cert+δ_unc+ε_delay)>0。
则 P[g(x*,a)≥0]≥1−α−β−γ。证明：在 (i)–(iii) 同时成立的事件上，x*∈X_infl，由 (iv) 得 g(x*,a)≥0；并集界给出概率下界。若 a 在 U_unc 上有非零分量，则 (iv) 不成立，CCP 直接禁止该动作。∎

**定理 11（时间隔离/纪元围栏）** 若中间件满足：(i) 所有包络带单调 epoch 与 nonce；(ii) 准入层丢弃 epoch<current 的包络并拒绝重复 nonce；(iii) 估计器只消费同一 epoch 且 t_s 在 Δ_max 内的包络；(iv) 纪元切换是原子的（旧快照或新状态，无混合）；则 epoch e+1 的状态只依赖 e+1 及已提交历史，重放/乱序/陈旧消息不能污染新纪元。证明：对 epoch 归纳。基础 epoch 0 无历史；切换原子性保证 e+1 的初始状态来自 e 的已提交快照；准入规则保证 e+1 期间不混入旧 epoch 包络；nonce 单调保证重放被拒。∎

**定理 12（AOS 的增益-风险权衡）** 在线性高斯模型下，安全方向的可观测 Gramian 为 W_o(a)=Σ_t Φ_tᵀΠ_SᵀH_tᵀΣ_t⁻¹H_tΠ_SΦ_t。AOS 选择使 λ_min(W_o(a)) 最大的观测。若当前契约的未认证方向方差为 σ²，则一次使 λ_min 增加 Δλ 的观测至多把该方向方差降低到 σ²/(1+Δλσ²)（信息形式的单调性）。因此 AOS 的风险下降与 λ_min 增量同向；与第 65 轮 AFA 的故障互信息不同，AOS 在故障不可辨识时仍能降低安全方向的不确定度。∎

**命题（各向异性膨胀的保守性收益）** 第 65 轮对任意拒绝把单一球半径膨胀 κ_infl 倍，在 d 维状态空间体积膨胀 κ_infl^d。LOOM 只膨胀 U_unc 的 |U_unc| 个方向，若真实故障只污染 k 个方向，则体积膨胀为 Π_{j=1}^k κ_j，其余 d−k 个方向保持原精度。当 k≪d 时，LOOM 的搜索域体积显著小于标量球，降低过度保守；当安全函数依赖被膨胀方向时，LOOM 直接禁止动作，避免“膨胀到安全”的假象。∎

**命题（未知复合故障的优雅降级）** 若真实故障不属于任何预定义类型，第 65 轮 FIR 仍会输出一个后验最大假设并定向处置；LOOM 不需要故障类型：若障碍可稀疏解释，则只移除对应关系；若不可稀疏解释，则 CSM 判 obstructed、契约 unanchored、MFC 切换到降级图或 safe_idle。故 LOOM 在未知故障下的失败模式是“保守降级”，而非“错误归因后更自信”。∎

## 7. 已知风险

**一句话**：LOOM 的安全性依赖“来源 DAG 与限制映射是诚实且完备的”这一假设；若真实共因没有被记录（同一未建模物理、同一错误标定、同一 OOD 环境对象被所有模态共享），一致束会把**共同错误的局部截面粘成一个错误的全局截面**，而中间件的权威会让这个错误契约系统性地传播到规划与执行——**第 65 轮“归因错误的复合故障”由此升级为“被中间件正式认证的复合故障”**，这是本轮全部契约与可观测性论证共同依赖的隐藏假设（A94/A99）。

**次级风险与缓解**：
1. **来源 DAG 不完整/可伪造**：未知共享祖先导致 ω 低估；缓解：AIC-L 以 ω=1 最坏情形认证，来源根哈希/签名，独立锚强制；无法证明独立性时进入 unanchored。
2. **共同错误的自洽粘合**：所有模态共享同一 OOD 物体时，边残差可能仍很小，束会成功粘合到错误截面；缓解：独立锚（运动学闭合、重力、准静态平衡、时间连续性）与共同模态残差监测；无独立锚则禁止高风险动作。
3. **障碍定位的可辨识性上限**：环空间冗余不足或故障非稀疏时 E_bad 不唯一；缓解：设计冗余传感器图、报告 E_bad 的等价类而非单点、契约降级而非强行定位。
4. **各向异性膨胀的 α_j 标定困难**：不可观测方向的 conformal 样本少；缓解：最坏情形界 + 在线漂移检测 + 安全关键方向直接禁止而非估计。
5. **AOS 在不可观测方向上的收益有限**：若动作无法激励该方向（如被遮挡/不可达），AOS 无法改善；缓解：检测不可激励性，切换任务/视角或 safe_idle。
6. **中间件自身成为单点**：契约签发与纪元切换若被攻击/崩溃，系统失去信任源；缓解：最小可信基、双签/只读审计、契约可被上层撤销、离线可验证日志。
7. **时间同步仍是物理假设**：纪元围栏解决逻辑时序，不解决时钟漂移；缓解：PTP/硬件触发 + 延迟界在线估计 + 超界即降级。
8. **束模型的线性化误差**：大形变/强非线性接触下限制映射不再线性；缓解：分片线性束、局部重线性化、只在局部窗口内粘合，跨窗口用独立锚校验。
