# 第 44 轮（新循环第 4 轮） · PoseSet-VLA-Cert：位姿集证书 × 语言约束编译——把「抓取位姿估计」的不确定性与「视觉-语言-动作模型」的语义先验焊成可认证的抽象接口（四层架构 v9）

> 承接第 43 轮 v20（CGC × SSCL × CGF）。v20 自陈最大风险是「mode confusion（模式误判后套用错误模式证书）+ 时间反演在准静态动作上失效」。本轮两个灵感词正好击中 v20 的两个**上游盲点**：**「抓取位姿估计」揭示了 v20 的 `pose_bucket` 只是一个过于粗糙的替身**——接触基元集合、力闭合矩阵 G(q)、可达性与碰撞都由 6/7-DoF 抓取位姿决定，位姿误差会同时污染「模式」与「余量」，而 v20 却把位姿压成离散桶；**「视觉-语言-动作模型（VLA）」提供了一个强泛化、懂指令、可跨物体迁移，却完全不可认证的高层策略**。二者耦合出「位姿集证书 + VLA 证书契约」：VLA 只产出**结构化提案**（部件、抓取类型、位姿混合、接近方向、动作块），位姿估计器把提案细化为**带有限样本覆盖保证的位姿集**，证书层在**整个位姿集**上做鲁棒力闭合/可达/碰撞验证，再用「语言约束保守编译 + 禁止静默替换」把语义与几何焊在一起。证书第一次成为「不可认证的高层语义」与「可认证的低层几何」之间的**带类型契约**（typed contract）。

## 0. 直觉与动机

**灵感 1（抓取位姿估计 → 证书必须从「单点位姿」搬到「标定位姿集」）**：v20 把接触模式定义为 (接触基元, grasp_type, **物体位姿桶**)，并在桶内证明 `|m_c(x)−m_c(x')| ≤ L_{m,c}‖x−x'‖`。但真正的自变量是抓取位姿 T ∈ SE(3)：G(q)、摩擦锥投影、接近走廊、可达性都是 T 的函数。**位姿估计稍有偏差，就会同时算错 G(q)、算错力闭合余量、把「接近」误判成「力闭合」**——v20 的 mode confusion 有一大半其实是位姿不确定性的下游症状。直觉上正确的对象不是「一个估计位姿 T̂」，而是**一个校准过的位姿集 P_δ**：用 conformal 把多假设位姿估计器的候选位姿裁剪成「以 ≥1−δ 概率包含真值」的集合；证书不再在 T̂ 上成立，而在整个 P_δ 上成立（`inf_{T∈P_δ} m_c(T) ≥ θ_c`）。更妙的是，位姿集的**半径本身就是模式混淆的预报器**：rad(P_δ) 大 ⇒ 接触几何本身歧义 ⇒ 可以在模式混淆发生**之前**主动门控，而不是事后靠 δ_mode 补救。

**灵感 2（VLA → 「提议—裁决」而非「端到端信任」）**：VLA 的价值在于读懂「把红色杯子放到盘子左边」这类语言、并把技能零样本迁移到新物体；但它没有任何 soundness 保证，且会把「语义合理」误当成「几何可行」。直觉是把它当成**投机执行里的提议器**：VLA 只负责产出受约束的结构化提案 π（部件 affordance、抓取类型、SE(3) 位姿混合、接近方向、动作块），由证书层做**裁决**（adjudication）。语言在这里有两种用法：其一，VLA 的指令理解把长程任务拆成**带契约的技能原语**（每个技能声明接触模式与位姿集需求）；其二，把语言编译成**只会收缩安全集的几何约束** C(ℓ)（禁抓区域、必需 affordance、朝向/保持竖直、物体身份）。关键性质：C(ℓ) 只做交、不做并，**即使语言接地（grounding）出错，最坏结果也只是过度保守/弃权，不可能凭空造出不安全动作**。这样 VLA 的泛化性与证书的可靠性各取所长。

**灵感 3（耦合 → 用「语义-几何一致性门」堵住证书的作用域漏洞）**：这里有一个极其隐蔽的陷阱——**位姿集证书只证明了「物理可行」，没有证明「任务意图正确」**。若系统允许「把 VLA 的位姿静默投影到最近的可行位姿」，就会出现「物理上稳、语义上错」的安全剧场：抓稳了，但抓的是刀刃、是别人的杯子、是错误部件。因此必须显式区分两个分数：物理证书分数与语义一致性分数 s_sem，并设立**禁止静默替换**规则（Δ_sem = s_sem(T_VLA) − max_{T∈可行} s_sem(T) ≤ τ_sem，否则弃权/澄清）。飞轮也随之升级：**弃权（abstention）不再被当成失败，而是最有价值的数据**——它精确指出 CKB 的空洞、位姿估计器的盲区与语言约束的冲突，定向触发 SCV 仿真与位姿重训；语言条件检索则可让熟悉指令直接命中已有位姿集模板，跳过 VLA 推理（降本）。

**与 v20 的差异（不推倒，只替换最粗的那一层）**：v20 的 `pose_bucket` → v9 的「标定位姿集 P_δ」；v20 的失败信号来自 SSL/时间反演 → v9 增加「位姿集 conformal 覆盖 + scenario 鲁棒证书」这一独立保险；v20 的 L2 只有 VLM 仲裁 → v9 增加「VLA 结构化提案 + 证书适配器」；v20 的 CKB 存接触图指纹 → v9 增加「指令嵌入 + 位姿集证书 + 弃权原因」；v20 的 ECR 只有模式/连续 margin → v9 增加「位姿集预检 + 语义门控」两条最小路径；v20 的保守兜底是模式无关包络 → v9 增加「弃权/澄清」这一**语义安全**兜底。

## 1. 形式化定义（增量：定义 45–51）

**定义 45（标定抓取位姿集）**：位姿估计器对观测 o 输出多假设 `{(T_k, w_k)}_{k=1..K}`。定义非一致性分数 `A(T;o)`（到最近高质量假设的加权位姿残差/能量），在校准集 `{(o_i, T_i^*)}` 上取 `q_δ = Quantile_{1−δ}({A(T_i^*;o_i)})`，则**位姿集**
`P_δ(o) = {T ∈ SE(3) : A(T;o) ≤ q_δ}`。
在可交换假设下 `P(T^* ∈ P_δ(o)) ≥ 1−δ`。用双不变度量 `d(T,T') = ‖log(T^{−1}T')‖` 定义半径 `rad(P_δ) = max_{T∈P_δ} d(Ĥ, T)`。多模态抓取时 P_δ 表示为 **k 个 SE(3) 切空间椭球的并**（每个椭球对应一个抓取族），保覆盖率、可 O(k) 求值。按 grasp_type / 物体类做 Mondrian 分层校准，避免大类淹没小类。

**定义 46（位姿集鲁棒证书）**：对模式 c 的证书 m_c（含力闭合余量 m_fc 与滑动余量 m_slip），定义
`m_c(P_δ) = inf_{T∈P_δ} m_c(T)`。
若 m_c 在模式内对位姿 L_T-Lipschitz，则 `m_c(P_δ) ≥ m_c(T̂) − L_T·rad(P_δ)` 给出可快速计算的下界；更紧的鲁棒力闭合用 **scenario 优化**：从 P_δ 采 K 个位姿求 `ε̂_fc = min_k ε_fc(T_k)`，则 `P(ε̂_fc ≤ ε_fc(P_δ) + ε_s) ≥ 1−β`（K 由 ε_s, β 定）。**模式 c 的位姿集证书成立** ⇔ `m_c(P_δ) ≥ θ_c ∧ reachable(P_δ) ∧ collision_free(P_δ)`。**命题 46**：若 P_δ 以 ≥1−δ 覆盖真位姿、且上述鲁棒下界 sound，则证书对真位姿成立的概率 ≥1−δ；这与 v20 的 SSL/conformal 是**相互独立**的两条保险（一条管位姿，一条管动力学失败信号）。

**定义 47（VLA 结构化提案与证书适配器）**：VLA 被约束输出
`π = (a_part, g_type, {(T_k, w_k)}, u_approach, ξ_chunk)`，
其中 a_part 为部件 affordance 掩码，g_type 为抓取类型（power/precision/pinch/…），u_approach 为接近方向，ξ_chunk 为动作块。**证书适配器**为
`Ad(π; o, ℓ) = {T ∈ P_δ(o) ∩ C(ℓ) ∩ S_{c,ε} : m_c(T) ≥ θ_c ∧ reachable(T) ∧ collision_free(T)}`。
提案**可采纳** ⇔ `Ad ≠ ∅` 且 `ξ_chunk` 诱导的接触图路径落在已认证的乘积自动机内（否则做前缀屏蔽）。可采纳时执行位姿 `T^* = argmax_{T∈Ad} s_sem(T; ℓ, o)`。

**定义 48（语言约束的保守编译）**：语言指令 ℓ 经 VLM 接地 + 受限 DSL 编译为 `C(ℓ) = (R_forbid, A_require, O_orient, id_obj)`（禁抓区域、必需 affordance、朝向约束、物体身份）。DSL **只允许收缩算子**（交/差/过滤），禁止任何扩张算子（并/补/放宽）。**单调性命题 48**：对任意安全集 S，`S ∩ C(ℓ) ⊆ S`；故语言接地错误最坏导致 Ad 为空（弃权），**不可能把不安全动作变安全**。C(ℓ) 需人类可审计、版本化，并记录其 grounder 置信度；冲突（如「抓杯子」与「杯子在禁区」）直接转澄清。

**定义 49（语义-几何一致性门与禁止静默替换）**：定义语义一致性分数 `s_sem(T; ℓ, o) ∈ [0,1]`（VLM 判官/指令接地的匹配度），以及**位姿替换鸿沟**
`Δ_sem = s_sem(T_VLA; ℓ, o) − max_{T∈Ad} s_sem(T; ℓ, o)`。
执行规则：仅当 `Ad ≠ ∅ ∧ Δ_sem ≤ τ_sem ∧ s_sem(T^*) ≥ s_min` 才执行；否则进入 ABSTAIN/CLARIFY。**禁止静默替换**：绝不在语义鸿沟超阈值时用几何可行的 T^* 悄悄替换 VLA 的意图位姿。**命题 49**：该规则把「物理证书」与「语义意图」显式分离；它不能证明语义正确（s_sem 是经验量），但能阻止证书被当成语义保证使用——这是 v20「证书作用域」漏洞的结构性补丁。

**定义 50（认证产出率、语义保持率与弃权成本）**：`Y = |{π : Ad(π)≠∅}| / |{π}|`（认证产出率，衡量可用性），`S = |{执行 ∧ Δ_sem ≤ τ_sem}| / |{执行}|`（语义保持率），弃权率 `Z = 1 − Y_exec`。安全隐患用「静默替换率」`Sub_silent` 度量（必须为 0）。COT 增加 `C_clarify·Z`。三者构成 (Y, S, Sub_silent) 的显式 Pareto 前沿：rad(P_δ)、τ_sem、θ_c 越保守，Sub_silent 越低但 Y 越低。

**定义 51（语言-位姿飞轮）**：CKB 记录扩展为 `(e_ℓ, ψ, P_δ-template, C(ℓ), π-embed, abstain_reason)`。语言条件检索 `R(e_ℓ, ψ)` 命中时可直接复用位姿集模板与已编译约束，**跳过 VLA 推理**（热启动）。弃权按原因聚类（pose-OOD / 约束冲突 / 低 s_sem / 无可行位姿），每类定向触发：SCV 在 P_δ 邻域与 C(ℓ) 边界重采样、位姿估计器以「已认证位姿为正样本、被拒位姿为硬负样本」增量重训、DSL 规则补丁入版本库。漂移监控（表征或语言嵌入）超阈值触发整轮重跑。

## 2. 产出设计（增量 IP-60/61/62 + 升级 IP-51/52/53/54/55/56/57/49/50/47）

### 2.1 IP-60 POSE-SET-CERTIFIER（位姿集证书器 PSC）
1. **多假设位姿集**：多抓取族估计器 + Mondrian conformal 分层校准（按 grasp_type/物体类），输出 k 椭球并集与覆盖率报告。
2. **鲁棒证书**：位姿 Lipschitz 下界（快路径）+ scenario 鲁棒力闭合/可达/碰撞（慢路径）；碰撞与可达用位姿集区间扩张。
3. **主动模式门控**：用 rad(P_δ) 预测接触几何歧义，`rad > R_max` 时在接触建立前就禁止模式条件证书（把 v20 的事后 δ_mode 门控前移）。
4. **位姿集指纹入库**：`(P_δ 的椭球参数 + grasp_type + 物体类)` 作为 CKB 新键，供语言条件检索复用。

### 2.2 IP-61 VLA-CERT-CONTRACT（VLA 证书契约 VCC）
1. **结构化提案头**：VLA 骨干 + 部件/抓取类型/位姿混合/接近方向/动作块五头，受约束解码（grasp_type 词表、SE(3) 混合分量数上限）。
2. **语言约束编译器**：VLM 接地 → 受限 DSL（只收缩）→ C(ℓ)；冲突检测、版本化、grounder 置信度标注。
3. **证书适配器**：`Ad = P_δ ∩ C(ℓ) ∩ S_cert`，鲁棒校验 + 动作块前缀屏蔽 + 接触图乘积自动机检查。
4. **语义一致性门**：s_sem 估计（VLM 判官 + 指令/部件匹配）+ Δ_sem 阈值 + 禁止静默替换 + ABSTAIN/CLARIFY。
5. **投机式执行**：VLA 一次提议动作块，证书器只认证可执行前缀；每个接触事件边界重新裁决。

### 2.3 IP-62 LANG-POSE-FLYWHEEL（语言-位姿飞轮 LPF）
1. **语言条件检索**：`e_ℓ` 与 `ψ` 联合嵌入，HNSW Top-k；命中即复用位姿集模板与约束（热启动，跳过 VLA）。
2. **弃权挖掘**：按原因聚类弃权样本，生成定向数据请求；把「澄清后的正确意图」回填入库。
3. **定向 SCV**：在 P_δ 邻域、C(ℓ) 边界、低 s_sem 区域做重要性采样压测。
4. **位姿重训**：已认证位姿为正样本、被拒/不可达位姿为硬负样本，迭代收紧 P_δ 半径。
5. **提案缓存与蒸馏**：高频 `(ℓ, o) → π` 缓存；可蒸馏为轻量检索策略，VLA 仅在长尾/新指令时调用。

```

    → IP-61 证书适配器(Ad = P_δ ∩ C(ℓ) ∩ S_cert) + 语义一致性门(Δ_sem)

    → IP-53 CMC(看门狗 = 模式分类 + 位姿集预检 + 语义门)

    ← IP-58 SSCL(自监督 + 时间反演 + conformal) ← IP-59 CGF(无标签抓取数据引擎)
    ← IP-62 LPF(弃权挖掘 + 语言条件检索 + 位姿重训)

运行期：位姿集预检(20μs) + 模式分类(50μs) + L0 查表(5μs) + 连续监控(100μs) + 语义门查表(5μs)
```

## 5. 本轮最大风险

**一句话**：位姿集证书只对「物理可行性」sound，却不对「语义意图」sound——一旦系统把 `Ad ≠ ∅` 误读成「VLA 指令已被验证」，就会发生**证书作用域蔓延**：物理上稳稳抓起的却是刀刃/错误部件/他人物体（安全剧场），且 conformal 位姿覆盖率依赖可交换性，新物体/新摩擦下 P_δ 可能系统性失准，使「集合内鲁棒」变成「集合外静默失效」；因此 E99（禁区零违例）与 E100（静默替换率必须为 0）是红线，任一不达标即禁止 VLA 直连，只允许检索命中模板执行或澄清。

### IP-60 PSC：位姿集校准与位姿集鲁棒证书
```
def calibrate_pose_set(calib, delta=0.05):
    # Mondrian：按 grasp_type / 物体类分层，避免大类淹没小类
    q = {}
    for stratum, items in group_by_stratum(calib).items():
        scores = [pose_nonconformity(T_star, o, proposals(o))
                  for (o, T_star) in items]
        q[stratum] = quantile(scores, 1 - delta)
    return q

def pose_set(o, q_stratum, k_max=8):
    props = grasp_pose_proposals(o)                 # 多假设：k 个抓取族
    keep  = [T for T in props
             if pose_nonconformity(T, o, props) <= q_stratum]
    ells  = fit_union_of_ellipsoids(keep, k_max)    # SE(3) 切空间椭球并
    return PoseSet(ells, radius=max_radius(ells))

def pose_lipschitz_lower(mode_cert, T_hat, P):
    # 快路径：m_c(P) >= m_c(T_hat) - L_T * rad(P)
    return mode_cert.m(T_hat) - mode_cert.L_T * P.radius

def scenario_robust_force_closure(mode_cert, P, K=64, beta=0.01):
    # 慢路径：从 P_δ 采样，取最小力闭合余量，scenario 界给概率保证
    eps = [mode_cert.force_closure(T) for T in sample_poses(P, K)]
    eps_hat = min(eps)
    eps_s = scenario_slack(K, beta)                 # 由 K,beta 定的松弛
    return eps_hat - eps_s

def pose_set_certified(mode_cert, P, theta_c, use_scenario=False):
    if P.radius > mode_cert.R_max:                  # 主动门控，而非事后
        return False, 'pose_ambiguity'
    m_lo = (scenario_robust_force_closure(mode_cert, P)
            if use_scenario else pose_lipschitz_lower(mode_cert, P.center, P))
    ok = (m_lo >= theta_c
          and reachable_over(P)
          and collision_free_over(P))
    return ok, m_lo

def proactive_mode_gate(P, delta_max):
    # 位姿歧义 → 预测接触模式歧义，接触建立前就禁用模式条件证书
    return P.radius <= R_MAX
```

### IP-61 VCC：VLA 结构化提案、语言约束编译与语义门

```
def vla_propose(ell, obs):
    z = vla_backbone(ell, obs)
    return Proposal(
        part      = part_head(z),                   # 部件 affordance 掩码
        g_type    = argmax(grasp_type_head(z)),     # 受限词表解码
        poses     = gmm_head(z),                    # {(T_k, w_k)}
        approach  = dir_head(z),
        chunk     = action_head(z)                  # 动作块 ξ
    )

def compile_language_constraints(ell, obs, dsl):
    g = vlm.ground(ell, obs)                        # 物体/部件/关系接地
    C = dsl.parse(ell, g)                           # 只允许收缩算子
    if has_conflict(C):                             # 如「抓杯子」∧「杯子在禁区」
        return None                                 # -> CLARIFY，不猜
    C.grounder_conf = g.conf
    C.version = dsl.version
    return C

def certify_proposal(pi, ell, obs, KB, delta=0.05):
    C = compile_language_constraints(ell, obs, KB.dsl)
    if C is None:
        return ABSTAIN('constraint_conflict')
    P = pose_set(obs, KB.q[pi.g_type])
    mode = KB.mode_classifier(obs)
    Ad = [T for T in P.candidates()
          if in_constraints(T, C)
          and certify_pose(mode, T, KB.cert[mode])]   # 鲁棒 + 可达 + 碰撞
    if not Ad:
        return ABSTAIN('no_certified_pose')

    T_vla  = pi.pose_point()
    T_star = max(Ad, key=lambda T: sem_score(T, ell, obs))
    s_best = sem_score(T_star, ell, obs)
    d_sem  = sem_score(T_vla, ell, obs) - s_best
    if d_sem > TAU_SEM or s_best < S_MIN:            # 禁止静默替换
        return ABSTAIN('semantic_substitution')
    if not contact_path_ok(mode, pi.chunk, KB.product_automaton):
        return ABSTAIN('contact_path_unverified')    # 前缀屏蔽
    return EXECUTE(T_star, pi.chunk, mode)

def shield_chunk(pi, ell, obs, KB):
    # 投机式执行：只认证可执行前缀，每个接触事件边界重新裁决
    decisions = []
    for seg in split_by_contact_event(pi.chunk):
        d = certify_proposal(pi.with_chunk(seg), ell, obs, KB)
        decisions.append(d)
        if not d.executable:
            break
    return decisions
```

### IP-62 LPF：弃权挖掘、语言条件检索与位姿重训
```
def lpf_step(logs, KB, SCV, ECR, delta=0.05):
    abstains = []
    for (ell, obs, outcome) in logs:
        if outcome.abstained:
            reason = classify_abstain(outcome)       # pose-OOD/冲突/低语义/无解
            abstains.append((ell, obs, reason))
            KB.insert_abstention(ell, obs, reason)

    # 1) 按原因聚类，定向请求仿真 / 约束补丁
    for cluster in cluster_abstentions(abstains):
        if cluster.reason == 'no_certified_pose':
            SCV.request_resim(pose_family=cluster.pose_family,
                              semantic_region=cluster.C_region)
        elif cluster.reason == 'constraint_conflict':
            KB.dsl.propose_patch(cluster)            # 人工审计后入库
        elif cluster.reason == 'semantic_substitution':
            KB.insert_hard_negative(cluster.T_vla, cluster.s_best)

    # 2) 语言条件检索：命中即热启动，跳过 VLA
    for (ell, obs) in logs:
        hit = KB.retrieve(e_ell(ell), psi(obs), k=3)
        if hit and hit.consistency > HIT_TAU:
            KB.mark_warm_start(hit, saved_vla_calls=1)

    # 3) 位姿估计器重训：认证位姿为正，被拒位姿为硬负
    retrain_pose_estimator(pos=KB.certified_poses, hard_neg=KB.rejected_poses)

    # 4) 覆盖率与漂移监控
    cov = empirical_coverage(KB.pose_set_valid, delta)
    if cov < 1 - delta - 0.02:
        KB.recalibrate(strata=low_coverage_strata(cov))
    if embedding_drift(logs, KB.reference_embedding) > TAU_EMB:
        SCV.request_resim(reason='language_pose_drift')

    # 5) 蒸馏轻量检索策略下发 ECR
    ECR.update(quantize_qat(distill(KB.retrieval_policy)),
               pose_set_table=KB.pose_set_templates,
               version=KB.version)
    return {'coverage': cov, 'abstain_clusters': len(abstains),
            'warm_start_rate': KB.warm_start_rate()}
```

| E100 语义-几何一致性门 | 静默替换率 Sub_silent；语义错抓率；弃权延迟 | **=0（红线）**；<1%；<200ms |
| E101 VLA+证书 vs 裸 VLA | 不安全事件；成功率保留比；干预率 | 0 起 vs >0；≥90%；≤20% |
| E102 语言条件长程飞轮 | 200 指令/50 物体/100h：不安全事件、成功率、弃权→澄清解决率 | 0 起；≥85%；≥80% |

回退：E95 不达标 → 增大校准集/降 δ/退回单点假设并放大 θ_c；E96 过保守 → 解析力闭合 + 局部 scenario 修正；E97 无增益 → 回退 v20 的 δ_mode 门控；E98 Y 过低 → 放宽到仅安全语义约束 / 扩大检索；E99 过度保守 → 人工审计 DSL；**E100 静默替换率非 0 → 立即禁止 VLA 直连，仅允许检索命中执行或澄清；E101/E102 任一安全事件 → 全链路回退 v20 模板检索执行**。

## 5. 风险与缓解（增量）

|---|---|---|
| 证书作用域蔓延：物理证书被误当语义保证，抓稳但抓错 | 高 | 语义-几何一致性门 + 禁止静默替换 + E100 红线；s_sem 与物理分数分账展示给人类 |

## 6. 本轮最大风险

**一句话**：位姿集证书只对「物理可行性」sound，却不对「语义意图」sound——一旦系统把 `Ad ≠ ∅` 误读成「VLA 指令已被验证」，就会发生**证书作用域蔓延**：物理上稳稳抓起的却是刀刃/错误部件/他人物体（安全剧场），且 conformal 位姿覆盖率依赖可交换性，新物体/新摩擦下 P_δ 可能系统性失准，使「集合内鲁棒」变成「集合外静默失效」；因此 E99（禁区零违例）与 E100（静默替换率必须为 0）是红线，任一不达标即禁止 VLA 直连，只允许检索命中模板执行或澄清。
