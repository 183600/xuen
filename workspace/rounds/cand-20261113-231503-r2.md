# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 2 轮；本轮灵感：「对话管理」×「长程任务」）

> R69 把「不确定性」一分为二，并给 epistemic 配了一个动作——看/问/触；但它默认了三件事：**交互是一次性的、共同基是静止的、问的时机无关紧要**。它每步独立算 VoI，用「单位时间 ≤1 次」的局部预算约束交互，并默认问到的答案在被使用时仍然有效。长程任务把这三条同时打破：一次澄清可能牵出下一次澄清；「那个」「刚才说的」所指会随轮次漂移；问得太早世界已变，问得太晚已过不归点；更糟的是，一旦你向人宣告了计划，你就**不能静默改主意**——承诺本身成了必须维护的状态。
>
> 对话管理恰好是研究这件事的学科：对话状态跟踪、轮次与主动权的分配、grounding 与 repair、澄清与确认、承诺的维护。它给出的核心直觉是——**「问」不是一个信息动作，而是一段有状态的对话轨迹**；其价值不取决于此刻的熵，而取决于「何时问、问给谁、问完之后双方是否仍然对齐」。
>
> 核心命题：**把交互从 R69 的单步 VoI 动作，升级为长程的、有状态的对话策略：用对话状态 d_t（信念/承诺/共同基/用户模型/进度）承载跨轮信息；用「最后责任时刻」（LRM，澄清窗口的右端点）调度澄清，把「何时问」变成一等决策；用全局交互预算 + 凸疲劳约束分配有限注意力；用承诺账本与修复控制器保证「宣告即约束」；用共同基第二意见（r_dia）检测感知无法发现的共同基漂移。** 命名 **TANDEM-RAS**（Turn-taking, Adaptive, Negotiated Dialogue & Evidence Management for long-horizon risk-adaptive systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我该在什么时候问、问过之后我们是否仍对同一件事达成一致**」——对话不是一次取证，而是一段需要维护的共同历史。

## 0. 直觉与动机

**灵感 1（对话管理 → 交互是有状态的）**
直觉：R69 的每个 g 都是「当场取一次证据」，回答被当作独立观测喂进贝叶斯更新。但真实的人机澄清是一个**对话**：你说「把那个红色的放左边」，我若问「哪个红色？」，你的回答可能引入新的指代；我若说「好，放左边」，这就成了一个承诺；你后来说「等等，不是那个左边」，我需要**修复**而不是重新开始。对话管理把这些叫作对话状态、共同基、承诺与修复。R69 缺的不是一个更好的问题，而是一个**记住之前问过什么、答应过什么、现在双方是否还对齐**的状态。

**灵感 2（长程任务 → 问的时机是决策，不是常数）**
直觉：R69 默认「有歧义且 VoI>成本就问」。但长程任务里，同一个歧义可能在第 3 步影响决策、也可能在第 30 步被计划自然绕开；现在问可能白问（世界会自己揭晓），也可能必须现在问（人马上要离开）。更尖锐的是**不归点**：一旦把鸡蛋放进篮子、一旦发出不可撤回的指令，再问就晚了。于是「何时问」不是实现细节，而是与「问什么」同等重要的决策。最优策略不是尽早问，也不是能拖就拖，而是**在「信息仍然新鲜」与「人仍然可用」的交窗内、尽可能靠近不归点地问**——这就是最后责任时刻（LRM）。

**灵感 3（对话状态 → 三类新坐标，而不是第四种标量）**
直觉：R69 的 U_epi 是「给定解释下的动作多峰」，是**同时刻**的。长程对话引入三种正交的量：(a) **时序相关性**——这个歧义还会不会影响后续决策；(b) **陈旧性**——之前确认的共同基现在还成立吗；(c) **承诺债**——我已经宣告过哪些必须兑现或显式收回的计划。它们不是同一个标量，也不该被并进 U_epi；它们分别进入调度（JIT）、第二意见（CGS）与一致性约束（CIM）。这是本轮的理论姿态：**不新增一个「第四种不确定性」去和 R69 拼盘，而是给已有不确定性加上时间和承诺两个坐标。**

**灵感 4（冻结 vs 泛化 → R69 是 H=1 的边界）**
直觉：把长程对话退化为单步：视界 H=1、无承诺、无共同基漂移、人永远在线且信息永不衰减。此时 LRM 就是当前步，JIT 永远「现在问」，全局预算退化为局部 ≤1 次，CIM 无约束，CGS 恒为低，TANDEM 逐指令等价于 FLUID。因此 R69 不是被替换，而是被**包含为「无记忆、无承诺、无时效」的边界情形**。这延续 R68→R69 的严格泛化链，防止每加一层就多一个要独立信任的黑箱。

**灵感 5（长程是攻击面的放大器 → 新的威胁模型）**
直觉：R69 已经担心「问错比不问更危险」。长程把这种危险**复利化**：(a) 重复确认可以让 k-正交证据纪律失效——三次「是的」其实共享同一个被投毒的共同基；(b) 攻击者可以**养疲劳**，先让你问很多无用问题耗尽预算，再在关键处让你问不出口；(c) **承诺陷阱**——诱导你说出「我会把它放左边」，再利用承诺一致性逼你做错；(d) **引用漂移**——让「那个」在轮次间悄悄换指。所以本轮必须交付：跨轮证据的**时序正交性**、疲劳/耐心的校准门、承诺的可撤回语义、以及共同基漂移检测。否则「记住对话」会变成「被对话记住」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TANDEM-RAS 总览与四不变式）** TANDEM-RAS = (DSM, JIT, HIB, CIM, REP, YLD, CGS, RAS-WM§)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **全局交互预算与疲劳单调**：视界 H 内信息动作总数 n_H ≤ B_H，疲劳代价 φ(n_H) 凸且单调不减；任何「把一次交互拆成多轮」的行为不得绕过预算（按轮次计费）；
(iii) **承诺完整性**：已宣告的承诺必须被执行，或在执行前通过显式修复（定义 317–318）撤回；禁止静默改主意；
(iv) **LRM 安全**：任何不可逆动作执行前，若其正确性依赖未消解的歧义且已越过 LRM，必须升级（R69 问询 → R68 保守 → 拒做），**绝不带着未消解歧义越过不归点**。

**定义 311（对话状态 DSM）** 对话状态 d_t = (b_t, c_t, κ_t, π_t^U, φ_t)：b_t 为任务/世界信念；c_t 为承诺账本；κ_t 为共同基（已验证的指代绑定、约定、偏好及其 provenance）；π_t^U 为用户模型（可用性、耐心、专长）；φ_t 为进度信念。转移 d_{t+1} = T(d_t, g_t, y_t, o_t)，其中 g_t 为对话/信息动作，y_t 为人话或回答。策略 π(g_t | d_t, o_t)。

**定义 312（共同基与共同基漂移）** 共同基 κ_t 是双方都默认成立的命题集合；每条带 provenance（谁在何时基于何证据断言）。真实共同基 κ_t^* 只可部分观测。**共同基漂移** δ_cg = d(κ_t, κ_t^*)；**接地缺口**是不一致命题的期望损害。漂移可由世界变化（用户改主意）、初始误接地、或恶意投毒引起，**感知残差通常对它不敏感**（世界仍与自身传感器自洽）。

**定义 313（澄清窗口与最后责任时刻 LRM）** 对歧义 α，令 t_D(α) = 依赖 α 的首个不可逆决策步；λ_info(α) 为信息陈旧率（澄清在 τ 取得、在 t 使用时仍有效的概率 ≈ e^{−λ_info(t−τ)}）；A_t(α) 为人可在 t 可靠回答的概率。定义**澄清窗口**
W(α) = { τ ≤ t_D : e^{−λ_info(t_D−τ)} ≥ 1−δ_stale 且 A_τ(α) ≥ 1−δ_avail }。
**最后责任时刻** LRM(α) = max W(α)；若 W 为空，则**不存在安全澄清时机**，必须改走保守/拒做，而不是硬问。

**定义 314（时序相关性与信息半衰）** 歧义 α 在 t 的**时序相关性** ρ_t(α) = P(α 影响 t 或之后的某个决策 | 历史)。ρ 随计划可能绕开 α 而下降，随逼近 t_D 而上升。**信息半衰** T_{1/2}(α)=ln2/λ_info 刻画「问了还能管多久」。相关性 × 新鲜度 × 可用性共同决定一次澄清是否值得占用预算。

**定义 315（延迟价值与 JIT 调度）** 现在问与在 τ>t 问的差：
V_def(t→τ) = P(α 在 τ 前自解或变无关)·c_q − P(窗口在 τ 前意外关闭)·L_irr(α) − 携带歧义的期望风险。
JIT 规则：只要 ρ_t·(1−p_self) > 0 且 t < LRM 且 V_def(t→LRM) > 0，就**延迟**；到达 LRM 或 V_def≤0 时立即澄清；若 t≥LRM 仍可澄清则立即澄清，否则升级。延迟只在**窗口仍开**时允许，把效率收益与不归点风险显式分开。

**定义 316（长程交互预算与疲劳 HIB）** n_H = Σ_t 1[g_t ∈ 𝒜_info]；疲劳代价 φ(n_H) 凸（边际疲劳递增），并带**短期冷却**（单位时间 ≤1 次，继承 R69）与**长期配额**（n_H ≤ B_H）。调度目标：
min E[任务损失] + λ_q·Σ c_q(g_t) + λ_f·φ(n_H)，s.t. 风险约束与 LRM 约束。
R69 的局部规则是 B_H=H、φ≡0 的退化特例。

**定义 317（承诺账本与承诺完整性 CIM）** 承诺账本 c_t = {(p_i, τ_i, prov_i, status_i)}，status ∈ {announced, executed, retracted, violated}。**承诺完整性**：任何将要执行的动作 a 必须满足 c_t ⊨ a，即不与任何 announced 且未 retracted 的承诺矛盾；否则必须先发出修复（定义 318）。承诺是可验证的，不是「我记得我说过」。

**定义 318（修复动作与修复代价 REP）** 修复动作 r ∈ {RESTATE, REASK, ROLLBACK, EXPLAIN, ESCALATE}：重述理解、重问、回滚到可逆点、解释为何偏离、升级到保守/拒做。修复代价 c_rep(r) = 时间 + 退回状态代价 + 信任损失。修复策略：选 r* = argmin E[不一致损害] + c_rep(r)，且 r* 本身须通过安全认证；修复失败/被拒绝则单向升级。

**定义 319（混合主动与让行 YLD）** 人可随时插话、打断、延迟纠正。让行策略 π_yield：当检测到 barge-in 且（任务关键度低 或 安全停机代价可接受）时让行并更新 d_t；否则维持控制但在下一个安全点响应。**延迟纠正**（人补充此前未说出的约束）必须能触发修复，而不是被当作噪声丢弃。

**定义 320（时间分解 TDS）** 在 R69 的 (U_ale, U_epi) 之上，为每个歧义 α 计算三元组 (ρ_t(α), staleness_t(α), ob_t(α))：时序相关性、共同基陈旧度、承诺义务。**关键约束**：三者不进 λ 的简单加和——ρ 进入「是否现在处理」的调度，staleness 进入「是否需要修复/重确认」，ob 进入「能否执行」的可行性。只有到达 LRM 仍无法消解时，才把其风险以 R68 方式折进 λ_floor。

**定义 321（共同基第二意见 CGS）** 对话一致性残差 r_dia = E[−log p(y_t | κ_t, history)]，即人话在「我以为的共同基」下的意外度（含复述、否认、指代失配、答非所问）。**对偶判据**：r_res 低（感知自洽）而 r_dia 高 ⇒ 疑似共同基漂移。CGS 与 R69 的 FMA（行为似然）构成两条互不吸收的第二意见：一个测「行为是否自洽」，一个测「对话是否仍对齐」。

**定义 322（证书 J_TANDEM）** J_TANDEM = (J_FLUID, common_ground_drift, lrm_margin, n_H/B_H, fatigue_ece, commitment_violations, repair_log_hash, temporal_orthogonality, tandem_ver)。Valid ⇔ Valid(J_FLUID) ∧ lrm_margin ≥ 0 ∧ commitment_violations = 0 ∧ fatigue_ece ≤ τ_fat ∧ 证据满足时序正交 ∧ 预算未越界。

**定义 323（威胁模型 AIC-TANDEM）** ℰ_TANDEM = ℰ_FLUID × ℰ_dialog × ℰ_horizon：跨轮重复确认制造**伪正交证据**、养疲劳耗尽预算、承诺陷阱、引用漂移、延迟纠正的隐藏约束、以及「拖延型」对抗（诱导系统一直延迟到窗口关闭）。其中**时序正交**要求：来自同一上下文簇（同一指代、同一时间窗、同一条被污染的共同基）的多次确认只计一个证据源。并入 AIC。

**定义 324（会话审计 VQAuditor-D）** 审计：澄清是否过早/过晚、是否越过 LRM、承诺是否被兑现或显式撤回、修复是否诚实、疲劳是否被低报、跨轮证据是否真的时序独立、「延迟」是否被对抗利用。结论回灌 HIB 的疲劳先验与 JIT 的窗口估计。

**定义 325（疲劳/耐心校准门 FCG）** 用户耐心与疲劳模型需校准：ECE_fat > τ_fat ⇒ 禁用学习式疲劳预测，退回固定保守配额 B_H^min，并优先保证安全关键澄清。这是 R69 MCG（模态校准门）在「人」这一侧的对应物——**不让不可信的用户模型驱动交互频率**。

**定义 326（长程实时预算与滚动视界）** 采用滚动时域（receding horizon）：只对 [t, t+H_r] 内的歧义做 LRM/调度，H_r 默认 8 步；DSM 常驻更新 <0.2ms，JIT/HIB/CIM/CGS 仅在触发时展开。长程不等于全知：调度是在有限预测视界上的近似，需显式报告 H_r 截断误差。

## 2. 关键算法骨架

```python
# IP-264 DSM：对话状态跟踪（信念 over 共同基 / 承诺 / 进度 / 用户模型）
class DialogueStateModel:
    def __init__(self, belief, user_model):
        self.b, self.U = belief, user_model
        self.c, self.kappa, self.phi = CommitmentLedger(), CommonGround(), Progress()

    def update(self, d, g, y, o):                     # y: 人话/回答（可空）
        d = d.copy()
        d.b     = bayes_update(d.b, o, g)
        d.kappa = ground(d.kappa, y, o)               # 指代绑定 + provenance
        d.c     = d.c.update_from(y)                  # 解析新承诺/撤回
        d.phi   = progress_update(d.phi, o)
        if y is not None: d.U.seen(d.U)               # 可用性/耐心后验
        return d

# IP-265 JIT：澄清窗口与最后责任时刻（把「何时问」变成一等决策）
def clarification_window(alpha, plan, avail, lam_info):
    tD = plan.first_irreversible_dependent_step(alpha)     # 不归点
    lo = tD - log(1.0/(1.0 - DELTA_STALE)) / lam_info      # 早于此会过期
    hi = avail.last_reliable_time(alpha)                   # 人还答得动的最后时刻
    return (lo, min(tD, hi))                               # W = {tau <= tD ...}

def last_responsible_moment(alpha, plan, avail, lam_info):
    lo, hi = clarification_window(alpha, plan, avail, lam_info)
    return hi if lo <= hi else None                        # None => 无安全窗口

def jit_decide(alpha, d, plan, budget):
    lrm = last_responsible_moment(alpha, plan, d.U, d.lam_info)
    if lrm is None:            return ESCALATE             # 只能保守/拒做
    if now < lrm and defer_value(alpha, now, lrm, d) > 0:
        return DEFER                                       # 窗口未关，先省一次问
    return ASK_NOW                                          # 到达 LRM 或延迟无利

# IP-266 HIB：全局预算 + 凸疲劳（按收益/成本排序，安全关键前置）
def allocate(ambiguities, B_H, phi):
    scored = sorted(ambiguities,
                    key=lambda a: (a.irreversible, a.voi / (a.cost + 1e-6)),
                    reverse=True)
    chosen, used = [], 0
    for a in scored:                                       # 贪心 + 疲劳边际
        if used + a.cost <= B_H and phi(used + a.cost) - phi(used) < a.voi:
            chosen.append(a); used += a.cost
    return chosen

# IP-267 CIM：承诺账本与完整性检查（宣告即约束）
class CommitmentLedger:
    def check(self, action):
        return all(not contradicts(p, action) for p,_,_,s in self.items
                   if s == 'announced')                    # False => 必须先修复

# IP-268 REP：修复控制器（RESTATE / REASK / ROLLBACK / EXPLAIN / ESCALATE）
def choose_repair(violation, d):
    best = None
    for r in [RESTATE, REASK, ROLLBACK, EXPLAIN, ESCALATE]:
        if not certified(r):              continue
        score = expected_mismatch_damage(d, violation) + repair_cost(r, d)
        if best is None or score < best.score: best = (r, score)
    return best[0]

# IP-269 YLD：混合主动 / 让行（插话、打断、延迟纠正）
def yield_policy(human, d, criticality):
    if human.barge_in and (criticality < CRIT_THRESH or safe_to_stop(d)):
        return YIELD                                       # 在下一个安全点交还控制
    return CONTINUE                                        # 记录纠正，下一安全点修复

# IP-270 CGS：共同基第二意见（感知吸收不了的对话异常）
def dialogue_residual(d, history, y):
    return surprise(d.kappa, history, y)                   # -log p(y | kappa, history)

# IP-275 主闭环（继承 R69，在交互调度与承诺处插入 TANDEM 层）
def TANDEM_RAS_round(M, obs, human):
    d = M.dsm.update(M.d, M.last_g, M.last_y, obs)
    # 1) R69 静态层：流匹配采样 + 不确定性二分
    samples = M.fmp.sample(obs, K=M.k())
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, M.z, M.fmp.mode_head)
    # 2) 时序层：相关性 / 陈旧 / LRM（何时问）
    alpha = M.tds.pick(modes, d)                            # 当前最该处理的歧义
    lrm   = M.jit.last_responsible_moment(alpha, M.plan, d.U, d.lam_info)
    action = M.jit.jit_decide(alpha, d, M.plan, M.budget)
    # 3) 全局预算门（不是每步独立算 VoI）
    if action == ASK_NOW and M.hib.allow(alpha, d):         # 问询也过 C-RAS-WM 认证
        g = M.mint.choose_interaction(modes, obs, M.budget)
        y = M.cia.execute(g); d = M.dsm.update(d, g, y, obs)
    elif action == ESCALATE or (lrm is None and unresolved(alpha)):
        return M.escalate(d, alpha)                        # R69 问询 / R68 保守 / 拒做
    # 4) 承诺完整性：宣告过就不能静默改
    if not M.cim.check(M.planned_action):
        r = M.rep.choose_repair(M.cim.violation(M.planned_action), d)
        return M.execute_repair(r)                         # 修复本身也认证
    # 5) 共同基第二意见（r_res 低 + r_dia 高 = 漂移）
    if M.cgs.residual(d, M.history, obs) > TAU_DIA:
        return M.execute_repair(REASK)
    # 6) 混合主动：人插话则让行，否则在安全点响应
    if M.yld.yield_policy(human, d, M.criticality):
        return M.pause_at_safe_point(d)
    # 7) 交由 R69 继续：风险缩放 + 认证执行
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + unresolved(U_epi)))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    return k, lam, M.select_mode(modes)
```

## 3. 推导

**引理 19（LRM 的存在性与 JIT 最优性）** 在 A104（ρ 单调、λ_info 与 A_t 已知）下，若澄清窗口 W(α) 非空，则「在 LRM(α) 澄清」在所有「窗口内澄清」策略中最小化期望成本：它最大化「歧义在澄清前自解或变无关」的概率，同时由 W 的定义保证信息在 t_D 时仍新鲜、且人仍可答。若 V_def>0 则延迟严格优于立即问；若 W 为空，则任何澄清策略都不能在 t_D 前提供有效信息，只能保守/拒做。系：**「问得太早」浪费的是预算，「问得太晚」浪费的是不可逆机会；LRM 正好是二者的分界。**

**引理 20（疲劳下的全局预算最优分配）** 设各候选澄清的期望收益 v_i 与成本 c_i，疲劳 φ 凸，则最优集合 S* 满足：对任意 i∈S*、j∉S*，v_i/c_i ≥ v_j/c_j，且边际疲劳 φ'(|S*|) 与预算的拉格朗日乘子一致。于是**按「不可逆性 × 收益/成本」排序并安全关键前置**是最优的贪心近似；R69 的逐步阈值（无全局预算、无视疲劳）会系统性地把预算花在早期低价值澄清上，缺口随 H 增大。系：长程交互不是「每步独立决定问不问」，而是**一个带凸成本的排序/配额问题**。

**引理 21（共同基漂移的对话可检测性）** 若 κ_t 相对 κ_t^* 漂移 δ_cg，且对话似然对共同基满足 Lipschitz（A105：常数 L_cg 有界），则 r_dia 的期望上升 ≥ L_cg·δ_cg − √(trΣ_dia)。因此 **(r_res 低, r_dia 高)** 是共同基漂移的可判别模式；它逃得过感知残差（世界仍自洽），逃不过对话一致性。这是 R69 引理 17（行为似然第二意见）在**共同基**上的镜像：标定吸收不了行为异常，感知也吸收不了对话异常。

**引理 22（时序正交证据与重复确认的失效）** 若 k 次「确认」条件在同一个已漂移的共同基上（命题相关 ρ_e≈1），则其错误相关性不随 k 下降：错误采纳率下界仍 ≥ δ_cg。只有当证据来自**上下文独立**的轮次（不同指代、不同来源、不同时间窗）且 ρ_e<1 时，才有 R69 引理 18 形式的 δ·ρ_e^{k−1} 上界。系：**跨轮累积不等于独立取证**；长程系统必须按「上下文簇」而非「对话轮数」计证据源。

**定理 18（TANDEM 对 FLUID 的严格泛化与 LRM 安全）** 在 A104–A106 下，TANDEM 在任意状态的任务期望风险 ≤ FLUID + λ_q·(延迟失败的期望成本)；且当 H=1、无承诺、κ 无漂移、A≡1、λ_info=0 时，TANDEM 逐指令等价于 FLUID（再当 VoI≤成本退化为 CALM）。安全侧：LRM 约束保证任何不可逆依赖动作前，未消解歧义已被消解或系统已升级（问询/保守/拒做），故 TANDEM **不会带着歧义越过不归点**；延迟只改变「何时问」，不改变「是否在承诺前问」，因此不引入额外的不可逆风险。

**定理 19（承诺一致性与修复的无突变）** 在承诺完整性（定义 317）与修复认证（定义 318）下，TANDEM 的执行动作序列与已宣告计划一致，除非发出显式修复；每次修复（除 ESCALATE）的状态偏差有界，ESCALATE 使 λ 单调不降；让行（定义 319）在安全点交接控制、保持控制连续；R68 的提交/换装不变式（定理 15）保持 ⇒ 长程拼接无突变、无静默改计划。

## 6. 本轮最大风险

**一句话**：TANDEM-RAS 把效率押在「我知道什么时候必须问」这一元认知上——**LRM 依赖对『未来哪一步不可逆、歧义何时真正影响决策、人何时还会在线』的预测；一旦高估 LRM（或多估了信息半衰、低估了共同基漂移），系统会把澄清一路推迟到不归点之后，用一次不可逆动作把「省下来的提问」一次性赔付——少问的收益与不可逆的损失，恰好是同一笔钱。**

**次级风险与缓解**：疲劳模型失准导致过问/欠问（FCG 校准门 + 固定保守配额，E305/E312）；共同基漂移漏检（CGS 第二条通道 + (r_res, r_dia) 对偶判据，E306）；跨轮伪正交证据（按上下文簇计源 + ℰ_dialog 对抗训练，引理 22）；承诺陷阱（账本 provenance + 显式撤回语义，E308/E314）；让行造成控制不连续（仅安全点交接，定理 19）；长程实时预算被调度展开击穿（滚动视域 H_r + 门控，定义 326，E315）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写操作继承；全局交互预算 + 凸疲劳（拆轮次不得绕过）；承诺完整性（宣告即约束，撤回须显式修复）；LRM 安全（未消解歧义绝不越过不归点，越界即升级）。

**定义 311–312（DSM 与共同基漂移）** `d_t=(b_t,c_t,κ_t,π_t^U,φ_t)`，`d_{t+1}=T(d_t,g_t,y_t,o_t)`；共同基 κ 带 provenance，真实共同基只可部分观测，`δ_cg=d(κ_t,κ_t^*)`；漂移常对感知残差不可见。

**定义 313–315（澄清窗口、LRM 与 JIT）** `W(α)={τ≤t_D : e^{−λ_info(t_D−τ)}≥1−δ_stale, A_τ≥1−δ_avail}`；`LRM=max W`，W 空则无安全澄清时机。`ρ_t(α)` 为时序相关性。延迟价值 `V_def=P(自解)·c_q−P(窗口关闭)·L_irr−携带风险`；JIT：窗口未关且延迟有正价值则延迟，到 LRM 立即问，错过则升级。

**定义 316（HIB）** `n_H≤B_H`，`φ` 凸，短期单位时间 ≤1 次；目标 `min E[任务损失]+λ_qΣc_q+λ_fφ(n_H)`；R69 局部规则是 `B_H=H, φ≡0` 的退化。

**定义 317–318（承诺与修复）** 账本 `c_t={(p_i,τ_i,prov_i,status_i)}`；执行动作须 `c_t⊨a`，否则先修复。修复 `r∈{RESTATE,REASK,ROLLBACK,EXPLAIN,ESCALATE}`，选 `argmin` 期望不一致损害 + 修复代价，且须过安全认证。

**定义 319–320（让行与时间分解）** 人可插话/延迟纠正；关键度低或可安全停机则让行，否则下一安全点响应。TDS 为每个歧义给出 `(ρ, staleness, ob)`，分别进调度/修复/可行性，**不做 λ 简单加和**；仅到 LRM 仍无解才折进 `λ_floor`。

**定义 321–322（CGS 与证书）** `r_dia=E[−log p(y_t|κ_t,history)]`；`(r_res低, r_dia高)` ⇒ 共同基漂移。`J_TANDEM` 并入 δ_cg、lrm_margin、预算比、fatigue_ece、承诺违规数、修复日志、时序正交。

**定义 323–326（威胁/审计/校准/实时）** `ℰ_TANDEM=ℰ_FLUID×ℰ_dialog×ℰ_horizon`（伪正交、养疲劳、承诺陷阱、引用漂移、拖延）；VQAuditor-D 审澄清早晚与承诺诚实度；FCG 在 `ECE_fat>τ_fat` 时退回固定保守配额；滚动视域 `H_r=8`，报告截断误差。

# IP-264 DSM：对话状态跟踪
class DialogueStateModel:
    def __init__(self, belief, user_model):
        self.b, self.U = belief, user_model
        self.c, self.kappa, self.phi = CommitmentLedger(), CommonGround(), Progress()
    def update(self, d, g, y, o):
        d = d.copy()
        d.b     = bayes_update(d.b, o, g)
        d.kappa = ground(d.kappa, y, o)          # 指代绑定 + provenance
        d.c     = d.c.update_from(y)             # 新承诺 / 撤回
        d.phi   = progress_update(d.phi, o)
        if y is not None: d.U.seen(d.U)          # 可用性/耐心后验
        return d

def clarification_window(alpha, plan, avail, lam_info):
    tD = plan.first_irreversible_dependent_step(alpha)     # 不归点
    lo = tD - log(1.0/(1.0 - DELTA_STALE)) / lam_info      # 早于此会过期
    hi = avail.last_reliable_time(alpha)                   # 人还答得动的最后时刻
    return (lo, min(tD, hi))

def last_responsible_moment(alpha, plan, avail, lam_info):
    lo, hi = clarification_window(alpha, plan, avail, lam_info)
    return hi if lo <= hi else None                        # None => 无安全窗口

def jit_decide(alpha, d, plan, budget):
    lrm = last_responsible_moment(alpha, plan, d.U, d.lam_info)
    if lrm is None:            return ESCALATE
    if now < lrm and defer_value(alpha, now, lrm, d) > 0:
        return DEFER                                       # 窗口未关，省一次问
    return ASK_NOW

# IP-266 HIB：全局预算 + 凸疲劳（安全关键前置）
def allocate(ambiguities, B_H, phi):
    scored = sorted(ambiguities,
                    key=lambda a: (a.irreversible, a.voi/(a.cost+1e-6)),
                    reverse=True)
    chosen, used = [], 0
    for a in scored:
        if used + a.cost <= B_H and phi(used+a.cost)-phi(used) < a.voi:
            chosen.append(a); used += a.cost
    return chosen

# IP-267 CIM：承诺完整性
class CommitmentLedger:
    def check(self, action):
        return all(not contradicts(p, action) for p,_,_,s in self.items
                   if s == 'announced')                    # False => 必须先修复

# IP-268 REP：修复选择
def choose_repair(violation, d):
    best = None
    for r in [RESTATE, REASK, ROLLBACK, EXPLAIN, ESCALATE]:
        if not certified(r): continue
        score = expected_mismatch_damage(d, violation) + repair_cost(r, d)
        if best is None or score < best.score: best = (r, score)
    return best[0]

# IP-269 YLD：混合主动 / 让行
def yield_policy(human, d, criticality):
    if human.barge_in and (criticality < CRIT_THRESH or safe_to_stop(d)):
        return YIELD
    return CONTINUE

# IP-270 CGS：共同基第二意见
def dialogue_residual(d, history, y):
    return surprise(d.kappa, history, y)                   # -log p(y | kappa, history)

# IP-275 主闭环（继承 R69）
def TANDEM_RAS_round(M, obs, human):
    d = M.dsm.update(M.d, M.last_g, M.last_y, obs)
    samples = M.fmp.sample(obs, K=M.k())
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, M.z, M.fmp.mode_head)
    alpha = M.tds.pick(modes, d)
    lrm   = M.jit.last_responsible_moment(alpha, M.plan, d.U, d.lam_info)
    act   = M.jit.jit_decide(alpha, d, M.plan, M.budget)
    if act == ASK_NOW and M.hib.allow(alpha, d):
        g = M.mint.choose_interaction(modes, obs, M.budget)
        y = M.cia.execute(g); d = M.dsm.update(d, g, y, obs)
    elif act == ESCALATE or (lrm is None and unresolved(alpha)):
        return M.escalate(d, alpha)
    if not M.cim.check(M.planned_action):
        return M.execute_repair(M.rep.choose_repair(
            M.cim.violation(M.planned_action), d))
    if M.cgs.residual(d, M.history, obs) > TAU_DIA:
        return M.execute_repair(REASK)
    if M.yld.yield_policy(human, d, M.criticality):
        return M.pause_at_safe_point(d)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + unresolved(U_epi)))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    return k, lam, M.select_mode(modes)

## 4. 推导

**引理 19（LRM 与 JIT 最优性）** 若澄清窗口 W(α) 非空，则在 LRM=右端点澄清最大化「歧义先自解/变无关」的概率，同时保证信息在 t_D 仍新鲜、人仍可答；`V_def>0` 时延迟严格优于立即问，W 为空则任何澄清都不能在 t_D 前提供有效信息、只能保守/拒做。系：问太早浪费预算，问太晚浪费不可逆机会，LRM 是分界。

**引理 20（凸疲劳下的全局预算）** 最优集合满足边际收益/成本相等（KKT）；按「不可逆性 × 收益/成本」排序并安全关键前置是最优贪心近似。R69 逐步阈值忽略全局预算与疲劳，会把预算花在早期低价值澄清上，缺口随 H 增大。系：长程交互是带凸成本的排序/配额问题。

**引理 21（共同基漂移的对话可检测性）** 若漂移 δ_cg 且对话似然对共同基 Lipschitz，则 `r_dia` 期望上升 ≥ `L_cg·δ_cg − √(trΣ_dia)`；故 `(r_res低, r_dia高)` 是漂移的可判别模式——感知吸收不了。与 R69 引理 17（行为似然第二意见）互为镜像。

**引理 22（时序正交证据）** 若 k 次确认条件在同一已漂移共同基上（`ρ_e≈1`），错误率不随 k 下降（下界 ≥ δ_cg）；只有上下文独立且 `ρ_e<1` 才有 `δ·ρ_e^{k−1}` 上界。系：跨轮累积 ≠ 独立取证，必须按「上下文簇」计源。

**定理 18（TANDEM 严格泛化 FLUID + LRM 安全）** A104–A106 下，TANDEM 任务期望风险 ≤ FLUID + λ_q·延迟失败成本；H=1、无承诺、κ 无漂移、A≡1、λ_info=0 时逐指令等价 FLUID（再退化 CALM）。LRM 约束保证不可逆动作前未消解歧义已消解或已升级，故永不带着歧义越过不归点；延迟只改「何时问」，不改「是否在承诺前问」，不引入额外不可逆风险。

**定理 19（承诺一致性与修复无突变）** 承诺完整性 + 修复认证下，执行序列与已宣告计划一致，除非显式修复；每次修复（除 ESCALATE）状态偏差有界，ESCALATE 使 λ 单调不降；让行只在安全点交接；R68 提交/换装不变式保持 ⇒ 长程拼接无突变、无静默改计划。

## 7. 本轮最大风险

**一句话**：TANDEM-RAS 把效率押在「我知道什么时候必须问」这一元认知上——**LRM 依赖对『未来哪一步不可逆、歧义何时真正影响决策、人何时还会在线』的预测；一旦高估 LRM（或多估信息半衰、低估共同基漂移），系统会把澄清一路推迟到不归点之后，用一次不可逆动作把「省下来的提问」一次性赔付——少问的收益与不可逆的损失，恰好是同一笔钱。**

**次级风险与缓解**：疲劳模型失准（FCG 校准门 + 固定保守配额，E305/E312）；共同基漂移漏检（CGS 第二通道 + 对偶判据，E306）；跨轮伪正交证据（按上下文簇计源 + ℰ_dialog 对抗训练，引理 22）；承诺陷阱（provenance + 显式撤回，E308/E314）；让行不连续（仅安全点交接，定理 19）；长程预算被展开击穿（滚动视域 + 门控，定义 326，E315）。
