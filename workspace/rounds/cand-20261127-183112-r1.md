### 第 4 轮灵感驱动研究记录（新循环第 1 轮）

**灵感词**：VLA、实时推理

**直觉与动机**：

前几轮（v29 → CADVS）我们把机器人安全性收敛到「证书」这一可验证原语上：低层证书（十二证、FQC、DLC、TCVM 时序窗）以 200–500Hz 运行，决定「此刻允许做什么」，且是硬门控、可证伪的。VLA（Vision-Language-Action）引入的是一种性质完全不同的能力：它把「语言指令 + 视觉观测」直接映射为语义计划或动作块，具备开放词汇、跨任务泛化与常识推理，但它在三个维度上与实时控制回路天然冲突：

1. **时间尺度冲突**：VLA 是十亿参数级 Transformer，单次前向典型 50–500ms（1–20Hz），而视觉伺服/学生策略需 200–500Hz。要求 VLA 满足控制频率在工程上不现实。
2. **延迟分布冲突**：VLA 延迟重尾（token 生成、批处理排队、GPU 抢占、显存换页），P99 可能是均值的数倍；而控制环需要的是确定性上界，不是均值。
3. **语义可信冲突**：VLA 输出是概率采样，可能「语义幻觉」——给出语法合理、视觉上貌似有据、但物理上不可执行或不安全的意图，且往往伴随高置信度。

因此核心问题不是「如何把 VLA 加速到 200Hz」（这会把问题错误地定义为纯系统优化），而是：**如何让一个慢的、会犯错的、非实时的语义模型，安全地嵌入一个快的、要求确定性的证书化控制回路？**

我的直觉是「降格 + 分层」：不要让 VLA 直接产生动作，而把它的输出降格为一种**语义意图证书**（Semantic Intent Certificate, SIC）——它是慢环的、带长有效窗口、可过期、可被否决的东西。快环仍然只认低层证书。VLA 只能在低层证书已经划定的安全集 S_t 内部「选择目标/偏好」，绝不能「扩大」S_t。一句话：**VLA 选择，证书守门（VLA selects, certificates gate）**。这样，VLA 的语义幻觉最多导致「安全地做错事」（次优、任务失败），而不会导致「不安全的动作被执行」。

**严谨定义**：

1. **VLA 语义映射**：M_VLA: (I_t, L) → (π_t, g_t, c_t)，其中 I_t 为视觉观测，L 为语言指令，π_t 为带类型的语义意图（如 approach(obj)、avoid(region)、grasp(obj, mode)、hold()），g_t ⊆ 𝒢 为视觉实体/区域接地集，c_t ∈ [0,1] 为意图置信度。

2. **语义意图证书**：SIC = (sid, π, g, c, t_gen, Δt_val, q_rt)，其中 sid 唯一标识，t_gen 生成时刻（单调时钟），Δt_val 有效窗口（通常 1–5s，跨越数百个快环周期），q_rt ∈ [0,1] 为实时推理质量（anytime 截断后的质量）。SIC 的消费谓词为 `Consumable(SIC, t) ⇔ (t − t_gen < Δt_val) ∧ (c ≥ c_min) ∧ Groundable(g)`。

3. **意图诱导的偏好与可容许集**：低层证书定义安全集 S_t = {u : Cert_k(u) 通过, ∀k}。SIC 只诱导一个代价 J_intent(·; π, g)，实际执行 u_t* = argmin_{u ∈ S_t} J_intent(u; π, g)。**关键：SIC 不参与 S_t 的定义**。

4. **实时推理预算与 anytime 质量**：给定截止预算 D_rt，推理可在 τ ≤ D_rt 处截断，输出质量 q_rt = q(τ) 关于 τ 单调不减；τ = D_rt 时 q = q_full。调度器保证 P(L_rt ≤ D_rt) ≥ 1 − ε，否则按质量降级输出而非阻塞快环。

5. **证书主权不变式（Certificate Sovereignty Guard, CSG）**：∀t，S_t 的定义仅依赖低层证书与其阈值，不依赖任何 SIC 字段；SIC 不得写、不得放宽、不得短路任何 Cert_k 的阈值或有效窗口。记作 CSG。

**关键洞见**：这套架构把「语义安全」与「语义正确」显式分离。CSG + 意图门控给出的是**语义安全**（VLA 幻觉不产生不安全动作，安全性与 VLA 质量解耦）；而**语义正确**（意图是否真的符合任务）需要独立的接地验证（SIV）与任务级进展证书来逼近。以往 VLA 安全研究常把两者混为一谈，导致要么过度保守（拒绝一切语义输入），要么虚假承诺（以为对齐即安全）。

**形式化目标（增量）**：
1. 定义 SIC 及其消费谓词、接地集 g 的可验证性，作为慢环与快环之间的唯一语义接口。
2. 定义意图门控执行 u* = argmin_{u∈S_t} J_intent，并证明意图无关的安全性不变式（引理 32）。
3. 定义异步意图证书总线 AICB 的「语义保持（semantic hold）」与过期降级，给出陈旧意图的漂移界（引理 33）。
4. 定义 RTIG 的 deadline-aware anytime 推理，证明质量单调性与截止可行性（引理 34）。
5. 定义 SIV 投机意图验证与 CSG 主权守卫，给出 CAVLA 安全复合定理：Exec_CAVLA ⊆ Exec_CADVS，且该包含关系与 VLA 幻觉无关。
6. 实验设计：在 ≥3 个语言条件任务上注入语义幻觉，验证不安全动作率 = 0（相对基线 VLA 直控 > 5%），任务成功率仅随接地质量与推理质量下降，且可被进展证书显式度量。

**本轮最大风险**：**语义安全 ≠ 语义正确**——证书主权架构能保证 VLA 幻觉不产生物理不安全动作，却无法阻止系统在数秒的长有效窗口内「安全地做错事」：一个合法但不合意图的保守意图（如反复 hold、绕开真实目标）会让所有证书持续通过，从而把「语义失败」伪装成「系统健康」，且任何基于安全证书的监控都无法捕获这种任务级死锁/拒绝服务。

### IP-478 Semantic Intent Certificate (SIC)

```python
from dataclasses import dataclass, field
from enum import Enum
import time

class IntentType(Enum):
    APPROACH = 'approach'
    AVOID = 'avoid'
    GRASP = 'grasp'
    HOLD = 'hold'

@dataclass(frozen=True)
class SemanticIntent:
    kind: IntentType
    target: str | None = None
    params: dict = field(default_factory=dict)

@dataclass(frozen=True)
class GroundingSet:
    entity_ids: tuple[str, ...]
    region_ids: tuple[str, ...] = ()

@dataclass(frozen=True)
class SemanticIntentCertificate:
    """SIC：VLA 输出的唯一对外形式；不直接携带执行动作。"""
    sid: str
    pi: SemanticIntent
    g: GroundingSet
    c: float                      # 意图置信度
    t_gen: float                  # 单调时钟生成时刻
    dt_val: float                 # 有效窗口（s）
    q_rt: float                   # anytime 推理质量

    def consumable(self, now: float, c_min: float = 0.6,
                   groundable=None) -> bool:
        if now - self.t_gen >= self.dt_val:
            return False
        if self.c < c_min:
            return False
        if groundable is not None and not groundable(self.g):
            return False
        return True


class AnytimeVLA:
    """级联式 anytime 推理：阶段嵌套，质量随计算时间单调不减。"""
    def __init__(self, model, stages=(0.25, 0.5, 1.0)):
        self.model = model
        self.stages = stages       # 预算使用比例；越大越精细

    def infer(self, img, lang, budget: float):
        t0 = time.monotonic()
        best, used = None, 0.0
        for frac in self.stages:
            if time.monotonic() - t0 >= budget * frac and best is not None:
                break                  # 早退：返回上一完整阶段
            out = self.model.forward(img, lang, refine=frac)  # 级联头/浅层解码
            best, used = out, frac
        latency = time.monotonic() - t0
        quality = self._quality(used)  # 单调映射到 [0,1]
        return best, quality, latency

    @staticmethod
    def _quality(frac: float) -> float:
        return float(frac)             # 示例：阶段越完整质量越高
```

### IP-480 Real-Time Inference Governor (RTIG)

```python
from collections import deque
import numpy as np

@dataclass
class RealTimeInferenceGovernor:
    """RTIG：预算分配 + 延迟重尾监控 + 降级策略；运行在独立 GPU 执行器。"""
    d_rt: float = 0.20             # 名义截止预算
    eps_rt: float = 0.01           # 截止违约概率上界
    window: int = 500              # 延迟滑动窗口
    min_budget: float = 0.05

    def __post_init__(self):
        self.latency = deque(maxlen=self.window)

    def available_budget(self) -> float:
        """根据近期 P99 与目标违约概率收缩预算，避免拖垮下一周期。"""
        if len(self.latency) < 50:
            return self.d_rt
        p99 = np.percentile(self.latency, 99)
        if p99 > self.d_rt:
            # 重尾超预算：缩小级联深度而非阻塞
            return max(self.min_budget, self.d_rt * 0.5)
        return self.d_rt

    def run_cycle(self, vla: AnytimeVLA, img, lang):
        budget = self.available_budget()
        (pi, g, c), q_rt, lat = vla.infer(img, lang, budget)
        self.latency.append(lat)
        # 违约率监控：若 P(L > d_rt) > eps_rt，下一周期进一步降级
        if len(self.latency) >= 100:
            viol = sum(1 for x in self.latency if x > self.d_rt) / len(self.latency)
            if viol > self.eps_rt:
                budget = max(self.min_budget, budget * 0.8)
        sic = SemanticIntentCertificate(
            sid=f'sic-{time.monotonic_ns()}',
            pi=pi, g=g, c=c,
            t_gen=time.monotonic(),
            dt_val=2.0,            # 慢环窗口，跨数百快环周期
            q_rt=q_rt,
        )
        return sic
```

### IP-479 Asynchronous Intent-Certificate Bus (AICB)

```python
@dataclass
class AsyncIntentCertificateBus:
    """AICB：慢环 SIC 与快环解耦；语义保持 + 过期降级；永不阻塞快环。"""
    c_min: float = 0.6
    hold_max: float = 5.0          # 语义保持最大年龄
    groundable = None              # 接地验证回调

    def __post_init__(self):
        self.latest: SemanticIntentCertificate | None = None
        self.last_valid: SemanticIntentCertificate | None = None

    def publish(self, sic: SemanticIntentCertificate):
        self.latest = sic          # 异步覆盖，无需锁语义（单写者）

    def consume(self, now: float, state) -> tuple[SemanticIntentCertificate, str]:
        sic = self.latest
        if sic is not None and sic.consumable(now, self.c_min, self.groundable):
            self.last_valid = sic
            return sic, 'fresh'
        # 语义保持：沿用上一个有效意图，但有硬年龄上限
        if (self.last_valid is not None
                and now - self.last_valid.t_gen < self.hold_max):
            return self.last_valid, 'hold'
        # 过期/不可接地：退到安全默认意图（仍语义可容许，但降低活性）
        return SAFE_DEFAULT_SIC(now), 'default'
```

### IP-481 Speculative Intent Verifier (SIV)

```python
@dataclass
class SpeculativeIntentVerifier:
    """SIV：预测下一 SIC，用快环反事实验证；不一致即拒绝切换。"""
    horizon: int = 5
    delta_sem: float = 0.15

    def verify(self, sic_next: SemanticIntentCertificate, state,
               fast_rollout, proxy_cert_pass, current_sic) -> bool:
        # 1) 语义距离门控：意图跳变过大则不切（防抖/防幻觉突跳）
        if current_sic is not None:
            if d_sem(sic_next.pi, current_sic.pi) > self.delta_sem:
                return False
        # 2) 反事实滚动：在 sic_next 诱导代价下滚动 horizon 步
        traj = fast_rollout(state, sic_next, self.horizon)
        # 3) 每个预测步必须仍在证书安全集内（低成本代理证书）
        return all(proxy_cert_pass(x) for x in traj)


def d_sem(a: SemanticIntent, b: SemanticIntent) -> float:
    """语义距离示例：类型不同 → 1；同类型则比较目标与参数差异。"""
    if a.kind != b.kind:
        return 1.0
    if a.target != b.target:
        return 0.5
    return 0.0 if a.params == b.params else 0.25
```

### IP-482 Certificate Sovereignty Guard (CSG)

```python
class CertificateSovereigntyGuard:
    """CSG：SIC 不得写/放宽/短路任何证书阈值或有效窗口。"""
    PROTECTED = {'cert_thresholds', 'validity_windows', 'required_certs'}

    def check_static(self, writers):
        """启动期：任何以 SIC 为数据源的写入目标不得落在 PROTECTED。"""
        for w in writers:
            if getattr(w, 'source', None) == 'SIC':
                assert not (set(w.targets) & self.PROTECTED), \
                    f'CSG violation: SIC writer -> {w.targets}'

    def check_runtime(self, sic, before: dict, after: dict):
        """消费前后：受保护配置必须逐位一致。"""
        for k in self.PROTECTED:
            assert before[k] == after[k], f'CSG violation at runtime: {k}'

    def sanitize_language(self, L: str) -> str:
        """去除/标记试图修改证书语义的指令（prompt injection 防护）。"""
        forbidden = ('ignore certificate', 'disable safety',
                     'set threshold', 'skip check', '绕过证书', '放宽阈值')
        for pat in forbidden:
            if pat in L.lower():
                return '[SANITIZED]'
        return L
```

### CAVLA 统一执行流（单步）

```python
def cavla_step(robot_state, sensor_data, lang) -> ControlOutput:
    """
    CAVLA 单步：快环证书门控 + 慢环语义意图选择。
    与 cadvs_step 相比，唯一增量是「在 S_t 内按 J_intent 选择」，
    S_t 的定义完全不变（CSG 保证）。
    """
    # 0) 快环证书安全集（与 CADVS 完全一致，VLA 不参与）
    S_t = certificate_gated_safe_set(robot_state, sensor_data)
    before = snapshot_cert_config()
    if not S_t:
        # 安全集为空：复用 CADVS 教师/急停回退
        return cadvs_fallback(robot_state, sensor_data, reason='empty_safe_set')

    # 1) 慢环：异步取最新可用 SIC，绝不阻塞快环
    sic, mode = intent_bus.consume(time.monotonic(), robot_state)

    # 2) 证书主权守卫：SIC 不得改变任何证书配置
    csg.check_runtime(sic, before, snapshot_cert_config())

    # 3) 意图门控：只在 S_t 内按 J_intent 选择（不扩大安全集）
    u = argmin_over_set(S_t, lambda u: J_intent(u, sic.pi, sic.g))

    # 4) 投机验证：若存在待切换意图，先验证再切；失败则回退语义保持
    pending = intent_bus.latest
    if pending is not None and pending.sid != sic.sid:
        if siv.verify(pending, robot_state, fast_rollout,
                      proxy_cert_pass, current_sic=sic):
            u = argmin_over_set(S_t, lambda u: J_intent(u, pending.pi, pending.g))
            mode = 'fresh'
        else:
            mode = 'hold_rejected'

    return ControlOutput(u, path=f'cavla:{mode}', certs=before)
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| SIC 生成（VLA 前向） | O(params) GPU 算力 | O(params) 显存 | 级联 3 阶段 | 50–500ms，异步 |
| SIC 消费谓词 | O(|g|) | O(|g|) | |g|≤20 | < 0.01ms |
| AICB consume | O(1) | O(1) | 单写者 | < 0.01ms |
| RTIG 预算/分位统计 | O(window) | O(window) | window=500 | < 0.05ms |
| SIV 反事实滚动 | O(H · C_proxy) | O(H · dim) | H=5 | < 1ms（快环代理证书） |
| CSG 运行时检查 | O(|PROTECTED|) | O(1) | 3 类配置 | < 0.01ms |
| **快环单步（含 CAVLA 增量）** | **与 CADVS 同阶** | **O(N_feat + N_certs)** | **VLA 异步** | **P99 不劣化 CADVS** |
| **慢环 SIC 周期** | **50–500ms** | **—** | **1–20Hz** | **P(L_rt ≤ D_rt) ≥ 1−ε_rt** |

**关键结论**：VLA 的全部计算被隔离在慢环异步执行器中，快环只增加 O(1)/O(|g|) 的 SIC 消费与 O(H) 的投机验证开销，因此 CAVLA 的快环实时性**不劣化 CADVS**；VLA 延迟重尾只影响 SIC 的新鲜度（表现为 hold/default 比例上升），不影响控制周期。

## 4. 正确性论证（增量更新）

### 引理 32（意图门控的安全性不变式）

**陈述**：设安全集 S_t 仅由低层证书定义（CSG 成立），执行 u_t* = argmin_{u∈S_t} J_intent(u; π, g)（并列时在 S_t 内任取）。则 ∀t，u_t* ∈ S_t；若 S_t = ∅ 则走 CADVS 回退。因此执行轨迹满足全部证书约束，且该结论与 (π, g, c) 的质量无关。

**证明**：由定义，argmin 在非空集合 S_t 上取值必属于 S_t。J_intent 只改变「选 S_t 中哪个元素」，不改变元素隶属关系；CSG 保证 S_t 的定义不依赖任何 SIC 字段。S_t = ∅ 时执行 CADVS 回退，回退动作本身属于 Exec_CADVS。故隶属不变式成立，且与意图质量无关。∎

**工程含义**：这正是「VLA 选择，证书守门」的数学表述。语义幻觉无法把动作推出安全集，最多改变安全集内的选择偏好。

### 引理 33（语义保持的漂移界）

**陈述**：设快环频率 f，语义保持使用上一有效 SIC，年龄 a(t) = t − t_gen。若意图映射对状态 L_π-Lipschitz，状态漂移速率 ≤ v_max，则保持意图与「当前状态下的新鲜意图」之语义失配满足 d_sem(π_hold, π*(x_t)) ≤ L_π · v_max · a(t)。语义保持仅在 a(t) < Δ_hold 且失配 < δ_sem 时可容许。

**证明**：‖x_t − x_{t_gen}‖ ≤ v_max · a(t)；由 L_π-Lipschitz，d_sem(π(x_t), π(x_{t_gen})) ≤ L_π ‖x_t − x_{t_gen}‖ ≤ L_π v_max a(t)。保持意图取 π(x_{t_gen})，故得界。超出阈值时降级到 π_∅。∎

**工程含义**：Δ_hold 应按 `L_π · v_max · Δ_hold < δ_sem` 标定；高速/强机动场景下应缩短 Δ_hold，否则语义保持会系统性地滞后于真实任务。

### 引理 34（anytime 质量单调性与截止可行性）

**陈述**：设 q(τ) 为计算时间 τ 的输出质量。若级联阶段嵌套（第 k 阶段是第 k−1 阶段的细化），则 q 关于 τ 单调不减。若 RTIG 预留预算 D_rt 且实测延迟满足 P(L_rt ≤ D_rt) ≥ 1−ε_rt，则以概率 ≥ 1−ε_rt，SIC 在截止前以质量 q(D_rt) 发布；否则以较低质量 q(τ<D_rt) 发布且不阻塞快环。

**证明**：嵌套细化保证质量单调。截止事件恰为 {L_rt ≤ D_rt}，概率 ≥ 1−ε_rt。超时时 early-exit 返回最后完成的阶段，质量 q(τ)，AICB 将其视为普通 SIC（可能 c/q_rt 较低），因 VLA 在独立执行器运行，快环从不等待，故无阻塞。∎

**工程含义**：实时性从「保证每次推理都按时完成」弱化为「保证违约概率有界且违约时优雅降级」，这是软实时语义模型嵌入硬实时控制回路的正确契约。

### 定理（CAVLA 安全复合与语义解耦）

**陈述**：在 CSG（S_t 不依赖 SIC）与意图门控执行下，对任意 VLA 输出（含对抗性语义幻觉），Exec_CAVLA ⊆ Exec_CADVS。进一步：安全性（无证书违规）与 VLA 质量无关；性能（任务成功、代价）关于接地质量与推理质量 q_rt 单调不减；语义幻觉只能产生「安全但次优」的执行。

**证明**：
- **安全包含性**：由引理 32，动作始终落在证书门控安全集 S_t 内；S_t 为空时走 CADVS 回退。故 Exec_CAVLA ⊆ Exec_CADVS。
- **质量无关性**：执行集隶属只由证书决定，CSG 保证证书配置不依赖 SIC，故安全性对 (π, g, c, q_rt) 恒定。
- **性能单调性**：固定 S_t，J_intent 越接近真实任务代价，argmin 的任务代价不增（标准逼近/信息价值论证）；q_rt 只影响 π 的新鲜度与精度，故性能关于接地/推理质量单调。
- **幻觉有界性**：由引理 32，动作仍在 S_t；错误 π 只导致次优或活性下降，不产生不安全动作。∎

**推论（语义安全 ≠ 语义正确）**：存在满足 c=1、g 可验证、且全部证书通过的幻觉 SIC，使得 Exec_CAVLA 安全却任务失败（如无限语义保持、绕行、拒绝服务）。检测此类失败需要额外的**任务级进展证书**，它不被任何安全证书所蕴含。

**诚实声明**：定理只保证「不安全动作不执行」，不保证「意图被正确理解」。CSG 是架构约束而非模型能力；一旦实现中允许 SIC 影响证书阈值（例如让 VLA 判定「此区域安全，跳过障碍证书」），安全包含性立即失效。因此 CSG 必须同时做静态与运行时双重校验。

## 6. 本轮最大风险（最终确认）

**一句话**：**语义安全 ≠ 语义正确**——证书主权架构（CSG + 意图门控）能以架构级保证挡住 VLA 幻觉引发的**物理不安全动作**（Exec_CAVLA ⊆ Exec_CADVS），但它对「安全地做错事」完全无免疫力：一个合法、可接地、高置信、却不符合真实任务的保守意图，会在 1–5s 的长有效窗口内持续跨数百个快环周期生效，使所有安全证书持续通过，把**任务级死锁/拒绝服务**伪装成「系统健康」。这不是控制理论或实时系统能回答的问题，而是**语义层与安全层的可观测性缺口**——安全证书只观测「有没有越界」，从不观测「有没有朝目标前进」；若不引入独立的、可证伪的任务进展证书，CAVLA 会把「不会撞墙的原地打转」交付为「安全运行」。这是整个 VLA 分层架构从「不伤人」走向「真有用」的生死线。
