# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；新灵感循环第 1 轮；本轮灵感：「事件相机」×「无刷电机」）

> 第 57 轮把安全的赌注从"证据质量"推进到"元先验质量 + 跨模态一致性 + 个性化信任"，并用 OOD 门 + 共形保底试图让"坏先验"只造成慢而不造成错。但它把两件事当成了不需要论证的前提：**(a) 证据永远在"审议节拍"上采集**——探针、到访、对账都发生在步态/检查点的时间尺度（几十到几百 ms），而打滑、塌陷、冲击这类真正会导致不可逆接触的事件发生在亚步态周期的毫秒尺度；地图是一张快照，世界却是一部电影，承诺给出时它可能已经过期，只是没人有足够快的手段知道。**(b) 身体被视为可信执行器**——传感器被怀疑、被降权、被隔离，作动器却被默认"忠实执行"。本轮两个灵感各补一条此前不存在的轴：**事件相机**给的是**时间**（微秒延迟、120dB+ 高动态、无运动模糊的异步变化流），它天生是"证伪机器"而非"确认机器"——只看得到"变了没有"，看不到"是什么"，因此最诚实的用途是**持续撤销过期地图证据**而不是给地形加分；**无刷电机**给的是**自反性**（相电流/反电动势/编码器残差是高频力矩显微镜），但同一个电机既是证据源又是执行器，绕组发热、磁链衰减、编码器漂移会同时让"地形证据"偏软并削弱"中止能力"，而 FOC 闭环补偿还会把退化伪装成"性能正常"直到饱和。由此核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"时间上可撤销、自反上可自证、且承诺带可中止契约的证据说可信"**。

核心矛盾：
- **H29（被动证据 vs 可校准性）**：主动探针的实验设计由我们选择（在哪、探什么），似然模型与共形校准因此良定义；事件流与电机电流是**世界替我们选择采样时刻**的被动证据——变化触发采样使样本天然偏向"有事件"的时刻，交换性被破坏，普通共形覆盖保证失效。越便宜、越普遍的证据，恰恰是越难保守校准的证据；把它直接汇入校准池会让"覆盖 ≥1−α"变成一句空话。更隐蔽的是"安静≠没事"：没有事件也可能是通道死了，负证据必须先证明通道活着。
- **H30（证据源与执行器的同一性）**：BLDC 同时产生承诺（推、迈、撑）与认证承诺的传感器（电流特征），还决定中止能力。一个退化隐变量 h（温度/R_w/λ_m/编码器偏置）会同时污染证据并缩小可中止集合，制造**正相关的复合失效**——恰好砸碎此前所有并集界依赖的"通道独立"假设。闭环补偿进一步造成"隐蔽观察者偏置"：退化在性能指标上被抹平，却在证据真值上持续累积，暴露时刻与最需要检测的时刻反向。
- **H31（决策时间尺度 vs 失效时间尺度）**：承诺是静态决策，失效是动态事件。若失效可能快于"检测+决策+执行"，则再好的后验也来不及用；承诺必须从"决策"升级为**带 TTL、带中止触发、且中止可行性事先被证明的契约**——不仅要问"地形可信吗"，还要问"若它骗了我，我能否在失效前安全退出"。

## 0. 直觉与动机

**灵感 1（事件相机 → 只证伪的变化见证）**
直觉：一台只在"变化"上发事件的相机，本质上是一个**过期检测器**。它不擅长回答"这块地硬不硬"，却极擅长回答"这块地还是不是地图里那块"。把事件流按"自运动预测（里程计+地图几何）"和"光照伪影（已知静止负对照）"两项减掉，残差显著就意味着地貌已变。设计上把它锁成**单向**：变化见证只能撤销/加宽/升警戒，绝不产生正地形证据。这既符合物理（事件相机看不到静态属性），又符合安全（被动证据只能减信，不能加信），天然满足交互单调性。

**灵感 2（无刷电机 → 自反执行器证书）**
直觉：电机电流是一条免费的高频触觉。打滑的标志不是"力小了"，而是"力矩-速度传递函数在某一刻换了形状"——这比任何到访节拍都快。但要让这条证据可信，必须先让电机**为自己作证**：用摆动相无接触段的"指令力矩 vs 实测加速度"辨识绕组与磁链，用热模型与编码器一致性估计健康 h；只有 h 落在校准包络 H_cal 内，电机派生证据才有资格进入证据门。事后若发现 h 曾越界，则像第 57 轮"坏证据回溯"一样，**作废该时间窗内全部电机证据并重算**。证据与能力共享同一个健康变量 ⇒ 必须同时门控，这也是复合失效的正确处理方式。

**灵感 3（合流 → 时间承诺契约与可中止性证据）**
直觉：既然失效可能在毫秒内发生，承诺就得像一份租约：有 TTL、有中止触发、有"中止本身安全"的证明。把失效时间下界 t_fail 用元历史共形分位数给出保守估计，定义时间安全裕度 τ_safe = t_fail − (检测延迟+决策延迟+执行延迟)；只有 τ_safe>0 且存在一个在反应预算内可达、且保持鲁棒不变式的中止动作时，才允许承诺。这引入全新的证据类 **EV-abort**：承诺前先证明"退得出来"。不可逆接触的 A_set 为空，于是它不能靠 TTL 兜底，必须完全由预测裕度担保。

**灵感 4（选择偏差 → 被动证据选择核算）**
直觉：变化触发采样是一个**倾向得分不为一的观察过程**。要让被动通道的覆盖保证成立，要么用倾向得分加权共形、且只在"被选中子群"上声明覆盖；要么老实承认对"从不触发"的状态**不可识别**，此时它只能当有漏检上界的证伪器。再加一道负对照（对准已知静止目标的事件率）与活性证书（事件率>0 或主动测试图案），把"光照漂移"和"相机死了"从"世界没变"里区分出来。核心原则是**认证问题，而不只是认证答案**。

**灵感 5（双层闭环 → 快层只减信、慢层才加信）**
直觉：把回路劈成两层。**快层**（事件触发，~ms）只允许加宽、降级、冻结、中止，永远不承诺、不升级、不缩窄——安全单调。**慢层**（检查点，PCE+）才允许承诺与升级，且被快层抢占后必须重认证。这把第 57 轮的"交互单调性"升维成"时间单调性"：越快的回路权限越小。滞回 + 最小驻留 + 中止能量预算保证中止有限次、不抖振。于是第 57 轮"元模型时延进控制回路"的风险被结构性消解：快层不依赖慢模型。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（事件见证通道 TEC）** 事件流 ℰ={(x_k,t_k,p_k)}，像素在 |log I(x,t)−log I(x,t−Δ)|>C 时触发。区域 r 的观测事件率分解 λ_obs(r,t)=λ_world(r,t)+λ_ego(v,ω;𝒟)+λ_illum(r,t)+λ_noise。以里程计+IMU+地图几何预测 λ̂_ego，以已知静止负对照区域估计 λ̂_illum，残差 λ_res=λ_obs−λ̂_ego−λ̂_illum。变化见证 W(r,t) 为残差上的 CUSUM 检验，契约：漏检 P(λ_world>δ_ch ∧ ¬W)≤δ_miss（虚警只致保守动作，交滞回抑制）。**单向使用约束**：W 只能撤销/加宽既有证据或升警戒，禁止作为任何正地形认证的输入。

**定义 140（自反执行器证书 RAC）** 健康隐变量 h=(R_w,λ_m,b_enc,T)，由摆动相无接触段的"指令力矩-实测加速度"系统辨识、热模型与编码器一致性联合估计。滑移签名 S(r,t) 由力矩-速度传递函数残差与速度失配定义（亚步态周期延迟）。电机派生证据资格 = 1[h(t)∈H_cal]；自反可靠性 ρ_motor(t)=ρ̄_motor·1[h(t)∈H_cal]·g(dist(h,∂H_cal))。**自反回溯**：若事后发现 h 在 [t0,t1] 越界，则作废该窗口全部电机派生证据并重算相关承诺，审计留痕。关键不变量：证据资格与中止能力由同一 h 门控，二者不得分离评估。

**定义 141（时间承诺契约 TCC）** 契约 κ=(g,r,t_c,τ_ttl,A_set,ϕ_abort,E_abort)：g 步态/落足目标，τ_ttl 有效期，A_set 可中止动作集，ϕ_abort=W(r,·)∨S(r,·) 触发谓词，E_abort 可中止性证据。失效下界 t_fail^conf(r,g) 取元历史共形下界；时间安全裕度 τ_safe=t_fail^conf−(τ_det+τ_dec+τ_act)。承诺 ⇔ 证据门过 ∧ E_abort（∃a∈A_set 在 τ_r 内可达且保持鲁棒不变式）∧ τ_safe>0。TTL 到期自动失效、须重认证。不可逆接触 ⇒ A_set=∅ ⇒ 禁止仅凭 TTL 兜底，须由预测裕度独占担保。

**定义 142（被动证据选择核算 PSA）** 变化触发采样使被动样本非交换：倾向 π(o,θ)=P(被记录|θ)。加权共形以 w_i∝1/π_i（π≥π_min）只在**被选中子群**上给覆盖 ≥1−α_sel；π 不可估或趋零的状态**声明不可识别**，被动证据仅可作证伪器并携带漏检上界 δ_miss。负对照给出伪影底噪 λ̂_illum 及其置信带；**活性证书**（事件率>0 或主动测试图案回波）成立才允许把"无事件"当负证据（EV-quiesce 的前提）。

**定义 143（跨时间对账 CTC）** 对同一区域 r，跨时间佐证 C_t(r)=1 ⇔ 窗口 Δ_t 内 W 与 S 均越阈 ∧ 因果时延 ∈[ℓ_min,ℓ_max] ∧ 两签名形状匹配某一物理地形变化模型。跨时间独立性前提强于跨空间：伪影机制不同（光照 vs 负载），同窗同地同形共现概率低。EV-tcorr = "变化为真"的证据，只用于加宽/撤销/升警戒；EV-quiesce = "双通道静默 ∧ 活性成立"，仅可有限延长 TTL，且仅限 L0/L1。

**定义 144（双层时间承诺协调器 TSC）** 快层 R（事件触发，≤τ_r）：输入 (ℰ,IMU,h)，动作 ⊆{加宽,降级,冻结,中止}；**安全单调**：对承诺风险测度 ρ_risk，R 的任意转移满足 ρ_risk 非增，且永不承诺/永不升级/永不缩窄证据。慢层 D（检查点，继承 PCE+）：可承诺与升级。接口：R 可抢占 D；D 在任意 R 动作后必须重认证。抑抖：滞回 + 最小驻留 τ_dwell + 中止能量预算 B_abort，保证中止有限次且不进入极限环。

def event_change_witness(events, r, map_, proprio, neg_target):
    lam_obs = event_rate(events, r)

def motor_evidence(e, h_est):
    if not in_envelope(h_est, H_cal):                   # 健康门：自反资格
        return None
    S = slip_signature(e.i_q, e.omega, e.tau_cmd)       # 力矩-速度传递残差
    return {'S': S, 'rho': rho_bar*margin(h_est,H_cal), 'eligible': True}

def reflex_step(kappa, W, S, h_est):                    # 快层：安全单调
    if not in_envelope(h_est, H_cal):
        return abort_or_fallback(kappa)                 # 能力门与证据门同源
    if W or S:
        return revoke_or_abort(kappa)                   # 只减信，绝不加信
    return kappa

def commit_contract(cp, M, E, h_est):
    if not evidence_gate(cp, M, E):        return reject('evidence')
    if h_est not in H_cal:                 return fallback_gait(cp)   # 能力不足即降档

    if tau_safe <= 0:                      return reject('temporal_margin')
    return Contract(g=cp.gait, ttl=tau_ttl, A_set=A_set, E_abort=E_abort,

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TEC | O(N_evt)/批；O(|R|)/区域 | O(N_buf) 环形缓冲 | λ_ego/λ_illum 预测诚实、漏检≤δ_miss、单向使用 |
| RAC | O(N log N)/控制拍（FFT）+O(d_h²) | O(窗口) | h 可辨识于 H_cal、回溯完整、证据/能力同门 |
| TCC | O(|A_set|)/承诺 | O(|κ_active|) | t_fail 共形下界、τ_safe>0、中止可行 |
| PSA | O(N_cal log N_cal) | O(N_cal) | π≥π_min、覆盖仅在选中子群、不可识别显式声明 |
| CTC | O(1)/事件批（窗内互相关） | O(Δ_t) | 因果时延窗、形状匹配、独立性前提 |
| TSC | 快层 O(1)/触发；慢层继承 PCE+ | O(|κ_active|) | 安全单调、抢占重认证、有限中止 |

**正确性定理（TCRS，Temporal-Calibrated Reflexive Soundness 概要）**：在 A33–A40 上加 (A41) 事件分解误差有界、变化见证漏检 ≤δ_miss 且活性证书完备；(A42) 电机健康可辨识于 H_cal、电机证据仅在 H_cal 内合格、自反回溯完整；(A43) 对每个被承诺契约，t_fail^conf 为保守共形下界且 τ_det+τ_dec+τ_act<t_fail^conf；(A44) 被动证据覆盖仅在选中子群成立、不可识别状态被显式声明、负对照漂移有界；(A45) 快层安全单调、可抢占慢层、抑抖参数保证有限中止。则：
(i) **时间承诺健全性**：对 h∈H_cal 下发出的契约，P(τ_ttl 内失效) ≤ δ_f+δ_miss·δ_abort_fail+δ_probe+ε_meta(k)+δ_ood·α_conf，且不安全暴露时间 ≤ min(τ_ttl, τ_det+τ_react)，其中 τ_react<τ_safe；
(ii) **反射安全单调性**：快层任意状态转移不增大承诺风险测度，且不存在由快层新建的更高风险动作——越快的回路权限严格更小；
(iii) **被动证据诚实性**：EV-tcorr / EV-quiesce 仅在声明子群与 L0/L1 使用，事件通道永不作正地形认证，负证据必带活性证书；
(iv) **相关失效分层界**（取代独立并集界）：
```
P_safe ≥ 1 − [ P(h∈H_cal)·Σ_cp(δ_f+δ_miss+δ_probe+ε_meta(k)+δ_ood·α_conf)
             + P(h∉H_cal)·(1−p_fallback) ]
```
必须显式声明：第 56/57 轮的独立并集界在证据源=执行器时**失效**，因其假定各失效通道独立，而此处 h 同向腐蚀证据与中止能力；
(v) **终止与抑抖**：每契约中止次数有限，系统在 k_probes+k_cons+k_abort 内终止于 {承诺, 绕行, L2 协商, 安全停}。

关键：**元先验给效率、共形给保底（第 57 轮）+ 反射给时间、健康门给自反诚实（本轮）**——效率/安全、时间/安全、证据/能力三对矛盾分别被解耦。

## 6. 本轮最大风险

**一句话**：本轮把安全押在两个未证假设上——"失效时间尺度慢于反射弧"与"执行器健康可自证"；若新型快速失效叠加隐蔽的电机退化，一个健康隐变量 h 会同时腐蚀证据（打滑检测偏软）与能力（可中止集合收缩），而 FOC 闭环补偿让它在性能指标上看起来一切正常，恰在最需要对账的时刻让快层与证据源同向腐败，因此必须以全时健康门、自反回溯、共形 t_fail 下界与"快层只减信"四重护栏，宁可退回又慢又保守的降档步态，也绝不在无法自证的执行器上发出毫秒级承诺。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TEC | O(N_evt)/批；O(|R|)/区域 | O(N_buf) | 漏检≤δ_miss、单向使用、活性完备（A41） |
| RAC | O(N log N)/拍 + O(d_h²) | O(窗口) | h 可辨识、回溯完整、证据/能力同门（A42） |
| TCC | O(|A_set|)/承诺 | O(|κ_active|) | t_fail 共形下界、τ_safe>0、中止可行（A43） |
| PSA | O(N_cal log N_cal) | O(N_cal) | 覆盖仅选中子群、不可识别声明、负对照有界（A44） |
| CTC | O(1)/事件批 | O(Δ_t) | 因果时延窗、形状匹配、独立性前提 |
| TSC | 快层 O(1)/触发；慢层继承 PCE+ | O(|κ_active|) | 安全单调、抢占重认证、有限中止（A45） |

**正确性定理（TCRS, Temporal-Calibrated Reflexive Soundness）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；并加 **(A41)** 事件分解误差有界、变化见证漏检 ≤δ_miss、活性证书完备；**(A42)** 执行器健康可辨识于 H_cal、电机证据仅在 H_cal 内合格、自反回溯完整；**(A43)** 每个被承诺契约的 t_fail^conf 为保守共形下界且 τ_det+τ_dec+τ_act<t_fail^conf；**(A44)** 被动证据覆盖仅在选中子群成立、不可识别状态显式声明、负对照漂移有界；**(A45)** 快层安全单调、可抢占慢层、抑抖参数保证有限中止。则：

1. **时间承诺健全性**：对 h∈H_cal 下发出的契约，
   `P(τ_ttl 内失效) ≤ δ_f + δ_miss·δ_abort_fail + δ_probe + ε_meta(k) + δ_ood·α_conf`，
   不安全暴露时间 ≤ min(τ_ttl, τ_det+τ_react)，且由 A43 有 τ_react<τ_safe。
2. **反射安全单调性**：快层任意转移不增大承诺风险测度 ρ_risk，且不存在快层新建的更高风险动作——权限随回路变快而严格收窄。
3. **被动证据诚实性**：EV-tcorr/EV-quiesce 只在声明子群与 L0/L1 使用；事件通道永不作正地形认证；负证据必带活性证书。
4. **相关失效分层界**（显式取代第 56/57 轮的独立并集界）：

```
P_safe ≥ 1 − [ P(h∈H_cal)·Σ_cp(δ_f + δ_miss + δ_probe + ε_meta(k) + δ_ood·α_conf)
             + P(h∉H_cal)·(1 − p_fallback) ]
```

   旧独立并集界在"证据源=执行器"时失效：其假定各通道独立，而 h 同向腐蚀证据与中止能力，必须按健康状态分层并给出 fallback 覆盖率。
5. **终止与抑抖**：每契约中止次数有限，系统在 k_probes+k_cons+k_abort 内终止于 {承诺, 绕行, L2 协商, 安全停}。

关键：**元先验给效率、共形给保底（第 57 轮）；反射给时间、健康门给自反诚实（本轮）**——效率/安全、时间/安全、证据/能力三对矛盾各自解耦。
