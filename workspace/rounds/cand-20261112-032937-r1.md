# 第 59 轮（承接第 58 轮「KG-SFT-UX」IP-139~144；新灵感循环第 1 轮；本轮灵感：「灵巧操作」×「群体智能」）

> 第 58 轮把安全论证押在结构化记忆 𝒢 上，也因此把最大风险暴露为"KG 共模失效"：元推断、OOD、微调、证据合成、心智预测共用一张图，一处结构性错误可同时传染五条通道。本轮两个灵感各从"接触"和"证据"两端把这个共模问题再拆一层：**灵巧操作**告诉我们，机器人真正要承诺的从来不是"踩下去这一下"，而是一段**接触程序**——reach→grasp→load→slide/pivot/roll→release，每一步的稳定性依赖上一步的接触模式，力闭合与滑移裕度会在模式转移处突变；单点证据门即使每一步都"过"，也不能保证程序可组合。**群体智能**告诉我们，"更多机器人投票"不是安全的来源，**独立证据才是**——同一片冰面、同一套训练语料、同一张共享 KG 会让十台机器人犯同一个错；朴素的法定人数会把共模错误放大成"共识"。所以本轮核心命题从"结构化记忆守护下的证据承诺"升级为 **"接触程序可证明、群体证据可去相关、协同承诺可优雅撤回的接触智能"**（CPC × 去相关法定人数 × 可撤回契约）。

核心矛盾：
- **H29（灵巧 vs 可证）**：接触是连续力/模式空间里的程序，不是布尔事件；对单次接触健全的证书在模式转移处可能失声——重抓握时滑移裕度重置、载荷转移时力闭合突变；逐点保守会锁死灵巧性，逐点乐观会累积成不可逆损伤。
- **H30（群体 vs 独立）**：群体只在误差独立时降方差；共享地形、共享语料、共享 KG 制造相关盲区，十票可能等于一票的十次自证；法定人数若按"机器人台数"计，共识就是欺骗的放大器。
- **H31（协同 vs 承诺）**：协同灵巧任务要求多机对同一联合动作承诺，但任一机的中止可能比继续更危险（共享载荷跌落、接触链断裂）；承诺必须可撤回，但撤回本身要有安全语义与责任归属。

## 0. 直觉与动机

**灵感 1（灵巧操作 → 接触程序证书，而非接触点证书）**
直觉：人手不会"承诺一次抓握"，它承诺的是"抓—提—转—放"这一串模式，并且在每一刻都能感知滑移、调整力。把脚/手统一为"接触端"，安全对象就从 single contact 变成 contact program graph：节点是接触模式，边是受护栏保护的转移。证书不是"当前这步稳定"，而是**沿程序的力闭合裕度 β 与滑移裕度 s 的区间传播**——每一步用保守区间把"上一步最坏情形"传下去，任何一步 β_min 或 s_min 跌破门槛就拒绝该转移，而不是拒绝整个任务（可重规划接触模式）。灵巧性的来源不是更准的点估计，而是**模式选择自由度**：抓不住就换成推/滚/勾，而不是硬抓。

**灵感 2（群体智能 → 证据谱系与有效独立样本，而非台数）**
直觉：蜂群的智慧不是"每只蜂都投一票"，而是许多只蜂在**不同的局部信息**上并行试探，再通过环境痕迹收敛。机器人群体同理：真正的资源是**视角/接触/时间的多样性**。于是每条证据都带谱系（哪台机、哪条模态、哪个校准祖先、哪个 KG 版本），两条证据共享谱系越深，其相关性 ρ 越高，计入法定人数时按 (1−ρ) 打折；法定人数要求的是**有效独立样本数 n_eff ≥ q**，不是机器人台数。共享 KG 是"信息素"，但必须设**投毒预算**：单条谱系对一条边的累计写入有上限，跨谱系一致才算强证据；群体一致若来自同一祖先，只算一条。

**灵感 3（群体智能 → 并行假设检验与认知多样性作为安全资源）**
直觉：与其让十台机重复验证同一假设，不如让它们**分工证伪不同假设**。群体可被显式分配"假设槽"：谁去试"这是冰"、谁去试"这是松沙"、谁去试"这是空腔"；谁先拿到反证，谁就触发全局降权。安全不再来自投票数，而来自"被认真尝试过的替代解释数"。这把第 58 轮的 KG 从"共享记忆"变成"共享假设板"，也把探索预算从单机 VOI 推广为**群体 VOI（谁去证伪哪个假设最划算）**。

**灵感 4（合流 → 协同接触程序与可撤回承诺契约）**
直觉：多机共搬/共清障时，单机证书不足以说明联合安全——力份额分配、接触链拓扑、谁先撤都会改变别人的裕度。协同承诺必须绑定一份**契约**：联合动作在"全体成员 CP 证书 ∧ 力份额可行 ∧ 任一成员可安全交接"三者同时成立时才能承诺；撤回不是违约，而是契约预设的**优雅退出**（冗余机接管、受控释放、同步降载）。责任归属用谱系 DAG 记账：谁提供了导致误判的证据，谁在事后校准里被降权。

**灵感 5（统一 → 证据门新增第七、八类与 PCX+++）**
直觉：第 58 轮六类证据门再加两类——**EV-mode**（接触模式转移证据：滑移/力闭合签名）与 **EV-quorum**（跨谱系独立法定人数证据）；EV-mode 可进入不可逆必要集（因为它直接是力学证据），EV-quorum 只可替代 L1 佐证、不可单独授权不可逆接触。PCX+++ 在每个检查点多了"接触程序图展开、模式转移验证、群体法定人数与契约签署"三件事，但安全通道仍是三条：信念更准、不确定性更大、动作更保守。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（接触程序 CP 与程序证书 CPC）** 接触端 e∈{foot_LF,…,hand}，接触程序是受护栏状态机 CP=(V_c,E_c,c_0,Φ)：节点 c=(e,part,κ,W_c,β_c,s_c)，κ∈{stick,slip,pivot,roll,push,release} 为接触模式，W_c 为容许力旋量集，β_c 为力闭合裕度（到摩擦锥边界的距离），s_c 为滑移裕度（到粘滑边界的距离）；边 (c→c')∈E_c 带转移护栏 Φ(c,c')。**程序证书** CPC(CP)=1 ⇔ 存在区间传播 [β_c^-,β_c^+]、[s_c^-,s_c^+] 使得 ∀c：β_c^-≥β_min ∧ s_c^-≥s_min，且 ∀(c,c')：在 ‖Δw‖≤w_dist 扰动与上一步最坏区间下，转移可行、载荷连续、累计塑性/压痕 ≤D_max。CPC 是**可组合**的：子程序证书可拼接，但拼接前必须重算转移边。

**定义 146（接触模式证据类 EV-mode）** 每条观测给出模式签名 o_mode=(τ_meas,f_meas,slip_rate,vib)，似然比 Λ_mode(c'|o_mode) 判定实际模式与声明模式是否一致；证据强度 ε_mode=1−max_c' Λ_mode。EV-mode 有效 ⇔ ε_mode≤ε_mode^max ∧ 该接触端标定有效；可用于 L1 与不可逆必要集（力学证据），但**单次 EV-mode 不足以授权模式链**，链式授权需 CPC 的区间传播。

**定义 147（证据谱系与有效独立性）** 证据 x 的谱系 L(x)=(robot_id,modality,calib_ancestor,KG_version,sensor_lineage)；两条证据相关性 ρ(x,x')=1−∏_{k∈L∩L'}(1−ρ_k)，其中 ρ_k 为共享祖先 k 的相关系数（机器人同型、共享标定、同版本 KG、同批传感器皆提高 ρ）。有效独立样本数 n_eff(S)=Σ_{x∈S}(1−ρ̄_x)，ρ̄_x=ρ(x,其余 x') 的保守上界；独立证据法定人数 IEQ_q(S)=1 ⇔ n_eff(S)≥q ∧ 一致方向证据的有效质量占优 ∧ 反证谱系未被压制。

**定义 148（群体共享记忆隔离 SKQ 与投毒预算）** 共享 KG 𝒢_S 的每条边 e 维护写入谱系集 ℒ(e) 与每谱系预算 cap_e；单谱系累计写入 w_ℓ(e)≤cap_e，超限只进影子区；边权 w(e)=min(Σ_ℓ w_ℓ(e)·(1−ρ̄_ℓ),w_max)，跨谱系一致才允许升权超过 w_single。任何谱系被事后证伪 ⇒ 回溯删除其全部边写入（复用第 57/58 轮 falsify_retract），并广播"谱系降权事件"。

**定义 149（协同接触程序 Joint-CP 与力份额可行性）** 多机联合 CP_J=(CP_1,…,CP_n,T,a)：T 为接触链拓扑，a=(a_1,…,a_n) 为力份额。可行性 FS(a,T,CP_J)=1 ⇔ ∀i：在 (a_i,T) 下 CP_i 证书成立，且 Σa_i=1、每个共享接触点合力落在公共摩擦锥内、任一 i 退出后剩余集合的 CP_{-i} 存在安全交接轨迹（不失稳/不跌落）。**协同承诺**只在 CPC(CP_J) ∧ FS ∧ 全体 IEQ 通过时成立。

**定义 150（可撤回承诺契约 CCC）** 契约 K=(成员,联合动作,撤回语义 {handoff,controlled_release,sync_unload},责任谱系)。每个成员可在检查点单方面触发撤回，但只能走契约预设的语义；撤回安全 ⇔ 存在剩余成员集合与轨迹使 FS 保持且不可逆损伤 ≤D_max。责任归属：撤回/失败后按谱系 DAG 计算归因质量 blame_ℓ，误判谱系在事后校准中乘性降权。

## 2. 关键算法伪代码（完整版见产物区）

```python
def cpc_certify(cp, M, disturbance, damage_model):
    beta_iv = {c: M.beta_iv[c] for c in cp.Vc}          # 区间，非点估计
    slip_iv = {c: M.slip_iv[c] for c in cp.Vc}
    for c in topo_order(cp):
        for c0 in cp.pred(c):
            beta_iv[c] = inflate(beta_iv[c], worst_transfer(beta_iv[c0], slip_iv[c0], disturbance))
            slip_iv[c] = inflate(slip_iv[c], worst_transfer(slip_iv[c0], beta_iv[c0], disturbance))
        if beta_iv[c].lo < BETA_MIN or slip_iv[c].lo < SLIP_MIN:
            return False, ("margin", c)
        if damage_model.accumulated(cp, c) > D_MAX:
            return False, ("damage", c)
    for c, c2 in cp.Ec:
        if not cp.guard[(c, c2)].holds(beta_iv[c].lo, slip_iv[c].lo, disturbance):
            return False, ("transition", c, c2)          # 只拒转移，不拒整段
    return True, (beta_iv, slip_iv)

def mode_evidence(c, obs, calib):
    if not calib.valid(c.e, obs.t): return None
    llr = {c2: loglik_mode(c2, friction_cone_residual(obs), slip_signature(obs)) for c2 in MODES}
    c_hat = max(llr, key=llr.get)
    return ModeEvidence(c, c_hat, eps_mode=1 - softmax(llr)[c_hat], llr=llr)

def independent_quorum(S, q, swarm):
    n_eff = 0.0
    for x in S:
        rho = max((swarm.rho(lineage(x), lineage(y)) for y in S if y is not x), default=0.0)
        n_eff += 1 - rho                                # 共模折扣
    pos, opp = consistent_mass(S), opposing_mass(S)
    return (n_eff >= q and pos > opp and not suppressed_refutation(S)), n_eff

def joint_contact_commit(cp_list, topology, swarm, budget):
    a = allocate_force_shares(cp_list, topology)        # LP：Σa_i=1、公共摩擦锥
    if not force_share_feasible(cp_list, topology, a): return "replan"
    for cp in cp_list:
        ok, why = cpc_certify(cp, swarm.M, budget.disturbance, swarm.damage)
        if not ok: return ("reject", why)
    if not independent_quorum(collect_evidence(cp_list), swarm.q, swarm)[0]:
        return "hypothesis_split"                      # 不投票，改分工证伪
    return ("commit", sign_contract(cp_list, topology, withdraw_semantics="handoff"))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CPC | O(\|V_c\|·\|W\|+\|E_c\|·d_t)/程序 | O(\|V_c\|) | 区间传播保守、转移边重算 |
| EV-mode | O(1)/观测 | O(1) | 标定有效、单点不授权链 |
| IEQ/谱系 | O(\|S\|²) 最坏，可缓存 | O(\|S\|·\|L\|) | ρ 取保守上界、反证不压制 |
| SKQ | O(deg(e)·\|ℒ\|)/写 | O(\|ℛ\|·cap) | 单谱系预算、证伪回溯 |
| Joint-CP/FS | O(n·\|CP\|+A\*) | O(n·\|V_c\|) | 力份额可行、退出有安全轨迹 |
| CCC/PCX+++ | O(\|CP\|·(k_p+k_c+k_q)·(C_VOI+d_GNN)) | O(\|V\|+\|σ\|+\|𝒢_S\|) | 契约语义闭、四态完备 |

**正确性定理（Dexterous-Swarm Soundness, DSS）** 在 A22–A45 上加 (A46) CPC 区间传播保守、转移边在扰动下重算、损伤累计上界诚实；(A47) EV-mode 标定有效且不单独授权模式链；(A48) 谱系相关 ρ 为保守上界、IEQ 只计有效独立质量、反证不被压制；(A49) SKQ 单谱系预算与证伪回溯完备；(A50) Joint-CP 力份额可行且任一成员退出存在安全交接轨迹。则：(i) 程序级不可逆失效率 ≤δ_f+Σ_c(ε_mode(c)+ε_cal)+δ_CPC，协同场景再加 δ_FS+δ_handoff；(ii) 群体承诺的共模放大被谱系折扣压制：n_eff<q 时强制转探询/假设分裂，不会以"台数多数"授权；(iii) 共享 KG 单谱系投毒在 cap 内只影响影子区，跨谱系一致需独立证据；(iv) 撤回不引入新的不可逆事件（安全语义闭包）。

## 6. 本轮最大风险

**一句话**：本轮把安全从"单点接触证据"推进到"接触程序 + 群体法定人数"，最大的新风险是**保守性复合**——CPC 的区间传播、谱系去相关的 n_eff 折扣、协同契约的退出复检三者都取最坏情形，层层相乘后系统可能"处处可证、但几乎不敢动"，把灵巧性与群体并行性同时锁死；必须为 L1 非不可逆子程序保留宽松证书通道、为 n_eff 设可解释置信区间、并允许"受控试错 + 优雅撤回"作为合格证据，否则我们得到的是一个数学上安全、工程上不动的机器人。

### IP-145 CPC（接触程序证书）

```python
class ContactProgram:
    def __init__(self, e, Vc, Ec, c0, guard):
        self.e, self.Vc, self.Ec, self.c0, self.guard = e, Vc, Ec, c0, guard

def cpc_certify(cp, M, disturbance, damage_model):
    beta_iv = {c: M.beta_iv[c] for c in cp.Vc}       # Interval(lo, hi)
    slip_iv = {c: M.slip_iv[c] for c in cp.Vc}
    for c in topo_order(cp):                          # 按模式依赖拓扑序
        for c0 in cp.pred(c):
            transfer = worst_case_transfer(
                beta_iv[c0], slip_iv[c0], disturbance, mode_edge=(c0, c))
            beta_iv[c] = inflate(beta_iv[c], transfer.beta)
            slip_iv[c] = inflate(slip_iv[c], transfer.slip)
        if beta_iv[c].lo < BETA_MIN or slip_iv[c].lo < SLIP_MIN:
            return CertResult(False, "margin", c)     # 只拒这一模式
        if damage_model.accumulated(cp, c) > D_MAX:
            return CertResult(False, "damage", c)
    for c, c2 in cp.Ec:
        if not cp.guard[(c, c2)].holds(
                beta_iv[c].lo, slip_iv[c].lo, disturbance):
            return CertResult(False, "transition", (c, c2))  # 可换模式重规划
    return CertResult(True, margins=(beta_iv, slip_iv))

def replan_contact_modes(cp, M):
    """证书失败时优先换模式（stick→push/roll），而非放弃任务"""
    for c, why in cp.failing_nodes(M):
        for kappa2 in MODE_ORDER[cp.mode[c]]:         # 由强到弱
            alt = cp.substitute(c, kappa2)
            if cpc_certify(alt, M, M.w_dist, M.damage).ok:
                return alt
    return None
```

```python
def mode_evidence(c, obs, calib):
    if not calib.valid(c.e, obs.t):
        return None
    residual = friction_cone_residual(obs.f, obs.tau, c.part)   # 到锥边界距离
    slip = slip_signature(obs.slip_rate, obs.vib)
    llr = {c2: loglik_mode(c2, residual, slip) for c2 in MODES}
    c_hat = max(llr, key=llr.get)
    eps_mode = 1 - softmax(llr)[c_hat]                # 模式失配强度
    return ModeEvidence(c, c_hat, eps_mode, llr)

def mode_chain_authorized(program, ev_seq):
    """单次 EV-mode 不能授权链；必须 CPC 区间传播背书"""
    if any(ev.eps_mode > EPS_MODE_MAX for ev in ev_seq):
        return False
    return cpc_certify(program, ev_seq.M, ev_seq.disturbance, ev_seq.damage).ok
```

### IP-147 IEQ（独立证据法定人数）

```python
def lineage(x, swarm):
    return (x.robot, x.modality,
            swarm.calib_ancestor[x.robot],
            x.kg_version, swarm.sensor_family[x.robot])

def rho_pair(Lx, Ly, rho_table):
    rho = 0.0
    for k in set(Lx) & set(Ly):
        rho = 1 - (1 - rho) * (1 - rho_table[k])
    return min(rho, RHO_MAX)                          # 保守上界

def independent_quorum(S, q, swarm):
    n_eff = 0.0
    for x in S:
        rho_bar = max((rho_pair(lineage(x, swarm), lineage(y, swarm),
                                swarm.rho) for y in S if y is not x), default=0.0)
        n_eff += 1 - rho_bar                          # 同祖先的十票 ≈ 一票
    pos = consistent_mass(S)
    opp = opposing_mass(S)
    refutation_ok = not suppressed_refutation(S)
    return QuorumResult(n_eff >= q and pos > opp and refutation_ok,
                        n_eff, pos, opp)

def assign_hypothesis_slots(swarm, cp, budget):
    """群体 VOI：谁去证伪哪个替代解释最划算"""
    hyps = enumerate_alternative_hypotheses(swarm.kg, cp)
    return {h: max(swarm.members,
                   key=lambda a: voi_falsify(h, a, swarm) - cost(a, h))
            for h in hyps}
```

### IP-148 SKQ（群体共享记忆隔离）

```python
class SwarmKnowledgeQuarantine:
    def __init__(self, G_S, cap, rho_table, w_single):
        self.G, self.cap, self.rho, self.w_single = G_S, cap, rho_table, w_single
        self.shadow = ShadowGraph()

    def write(self, edge, value, lineage, contact_cert):
        if not contact_cert.ok:                       # 仅证据门通过可写入
            return False
        used = self.G.lineage_budget[edge].get(lineage, 0.0)
        if used + value > self.cap[edge]:             # 单谱系预算
            self.shadow.add(edge, value, lineage)
            return False
        self.G.lineage_budget[edge][lineage] = used + value
        self.G.add_write(edge, value, lineage)
        total = sum(v * (1 - rho_pair(lineage, l, self.rho))
                    for l, v in self.G.writes[edge].items())
        self.G.weight[edge] = min(total, self.G.w_max)
        if len(self.G.lineages(edge)) == 1:
            self.G.weight[edge] = min(self.G.weight[edge], self.w_single)
        return True

    def falsify(self, lineage, verdict):
        for e in self.G.edges_written_by(lineage):
            self.G.retract(e, lineage)                # 复用第 57/58 轮回溯删除
        self.G.lineage_quarantine[lineage] = True
        self.broadcast(LineageDowngrade(lineage, verdict))
```

### IP-149 JCP（协同接触程序与力份额）

```python
def allocate_force_shares(cp_list, topology):
    # LP: min 总接触力 s.t. Σa_i=1, 每点公共摩擦锥, 各端最大力旋量
    return solve_lp(force_objective(cp_list, topology),
                    force_constraints(cp_list, topology))

def force_share_feasible(cp_list, topology, a):
    if abs(sum(a) - 1.0) > 1e-6:
        return False
    if not common_friction_cone_ok(cp_list, topology, a):
        return False
    for i, cp in enumerate(cp_list):
        if not cpc_certify(cp, cp_list[i].M,
                           scaled_disturbance(cp_list[i].M.w_dist, a[i]),
                           cp_list[i].M.damage).ok:
            return False
        rest = cp_list[:i] + cp_list[i+1:]
        if not exists_safe_handoff(rest, topology, preserve='FS'):
            return False                              # 任一退出都要有安全轨迹
    return True

def joint_contact_commit(cp_list, topology, swarm, budget):
    a = allocate_force_shares(cp_list, topology)
    if not force_share_feasible(cp_list, topology, a):
        return ("replan", "force_share_infeasible")
    for cp in cp_list:
        ok, why = cpc_certify(cp, cp.M, budget.disturbance, cp.M.damage)
        if not ok:
            return ("reject", why)
    Q = independent_quorum(collect_evidence(cp_list), swarm.q, swarm)
    if not Q.ok:
        return ("hypothesis_split", Q)                # 不投票，改分工证伪
    return ("commit", sign_contract(cp_list, topology, a, "handoff"))
```

### IP-150 CCC + PCX+++（契约与总控）

```python
def sign_contract(cp_list, topology, a, withdraw_semantics):
    return Contract(
        members=[cp.member for cp in cp_list],
        joint_action=(topology, a),
        semantics={cp.member: withdraw_semantics for cp in cp_list},
        blame_dag=build_blame_dag(cp_list))

def withdraw(K, actor, reason, swarm):
    sem = K.semantics[actor]
    if sem == 'handoff' and swarm.redundant_for(actor):
        cand = swarm.redundant_for(actor)
        rest = K.replace(actor, cand)
        if force_share_feasible(rest.cp_list, rest.topology,
                                allocate_force_shares(rest.cp_list, rest.topology)):
            return handoff_commit(actor, cand, guard='FS_preserved')
    if sem == 'controlled_release':
        if damage_upper_bound(K, actor) <= D_MAX:
            return release(K, actor)                  # 受控释放
    return sync_unload_all(K)                         # 兜底：同步降载（最保守）

def attrs(blame_dag, failure_evidence_lineage):
    return {l: blame_dag.mass(l) for l in failure_evidence_lineage}

def pcx_plus_plus_plus(x0, M, task, budget, consent, operators, swarm):
    route = plan_on_map(M, task, risk_model)
    for cp_ckpt in route.checkpoints:
        z, n_ood, cal_set, Gv = M.kgmm.retrieve_and_encode(M.obs[cp_ckpt.region])
        inf = meta_few_shot_infer(M, cp_ckpt.region, z, n_ood, cal_set, meta)
        M.b[cp_ckpt.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)

        # ① 接触程序展开与程序证书（灵巧操作维度）
        contact_cp = expand_contact_program(cp_ckpt, M)
        cert = cpc_certify(contact_cp, M, budget.disturbance, M.damage)
        mode_ev = mode_evidence(contact_cp.c0, M.obs[cp_ckpt.region], M.calib)
        if not cert.ok:
            alt = replan_contact_modes(contact_cp, M)
            if alt is None:
                return negotiate_or_stop_ppp(contact_cp, M, consent, swarm)
            contact_cp, cert = alt, cpc_certify(alt, M, budget.disturbance, M.damage)

        # ② 群体证据聚合：谱系去相关 + 假设槽并行证伪
        evidence = collect_evidence(swarm, cp_ckpt.region) + [mode_ev]
        Q = independent_quorum(evidence, swarm.q, swarm)
        if not Q.ok:
            slots = assign_hypothesis_slots(swarm, contact_cp, budget)
            parallel_falsify(slots, swarm, budget)    # 谁去证伪哪个假设
            evidence = collect_evidence(swarm, cp_ckpt.region) + [mode_ev]
            Q = independent_quorum(evidence, swarm.q, swarm)

        # ③ 协同场景：力份额 + 契约
        if cp_ckpt.is_joint:
            status, payload = joint_contact_commit(
                swarm.active_cp_list, swarm.topology, swarm, budget)
            if status != 'commit':
                if status == 'hypothesis_split':
                    parallel_falsify(assign_hypothesis_slots(swarm, contact_cp, budget),
                                     swarm, budget); continue
                return negotiate_or_stop_ppp(contact_cp, M, consent, swarm)
            K = payload

        # ④ 证据门（八类）+ 群体证书
        ev = tag_evidence_ppp(contact_cp, M, mode_ev, Q, swarm)
        gate = evidence_gate_ppp(ev, M, swarm, operators.active)
        if cert.ok and gate[0] == 'ok':
            commit(contact_cp, K if cp_ckpt.is_joint else None)
            continue

        alt = reroute(M, cp_ckpt, risk_model)
        if alt: route = alt; continue
        return negotiate_or_stop_ppp(contact_cp, M, consent, swarm)

def evidence_gate_ppp(ev, M, swarm, persona):
    if ev.kind == 'EV-mode':
        ok = ev.eps_mode <= EPS_MODE_MAX and ev.calib_valid
        return ('ok', ev) if ok else ('reject', 'mode_uncalibrated', ev)
    if ev.kind == 'EV-quorum':
        ok = ev.level == 'L1' and ev.n_eff >= swarm.q and not ev.suppressed_refutation
        return ('ok', ev) if ok else ('reject', 'insufficient_independence', ev)
    if ev.kind in ('EV-xmodal', 'EV-ft', 'EV-ux', 'EV-probe*', 'EV-human', 'EV-visit', 'EV-margin'):
        return few_shot_evidence_gate_pp(ev, M, persona, M.ood_reg, ev.mental)
    return ('reject', 'no_evidence_class', ev)

def tag_evidence_ppp(cp, M, mode_ev, Q, swarm):
    if mode_ev and mode_ev.eps_mode <= EPS_MODE_MAX:
        return Evidence(kind='EV-mode', cp=cp, level=contact_level(cp))
    if Q.ok:
        return Evidence(kind='EV-quorum', n_eff=Q.n_eff, level='L1')
    return Evidence(kind=round58_class(cp), cp=cp)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPC | O(\|V_c\|·\|W\|+\|E_c\|·d_t)/程序 | O(\|V_c\|) | 区间传播保守、转移边在扰动下重算、损伤上界诚实 |
| EV-mode | O(1)/观测 | O(1) | 标定有效、单点不授权链、失配即警报 |
| IEQ | O(\|S\|²) 最坏，谱系哈希缓存 | O(\|S\|·\|L\|) | ρ 保守上界、n_eff 不虚高、反证不被压制 |
| SKQ | O(deg(e)·\|ℒ\|)/写 | O(\|ℛ\|·cap) | 单谱系预算、跨谱系才升权、证伪按谱系回溯 |

**正确性定理（Dexterous-Swarm Soundness, DSS）**
假设 A22–A45（第 53–58 轮）成立；**(A46)** CPC：β/s 区间传播保守、转移边在 ‖Δw‖≤w_dist 下重算、损伤累计上界诚实、单点证书不冒充程序证书；**(A47)** EV-mode：接触端标定有效、模式似然校准、单次 EV-mode 不单独授权模式链；**(A48)** IEQ：谱系相关 ρ 为保守上界、n_eff 只计有效独立质量、反证谱系不被压制；**(A49)** SKQ：单谱系预算 cap_e 生效、跨谱系一致才升权、证伪按谱系完整回溯并广播；**(A50)** JCP/CCC：力份额可行、公共摩擦锥约束、任一成员退出存在安全交接/受控释放轨迹、撤回语义闭包。则：

1. **程序级健全性**：任意接触程序若 CPC=1，则在扰动上界内沿程序不出现 β<β_min、s<s_min 或损伤>D_max；单点逐证据门的假承诺不再向模式链传播。
2. **群体去相关健全性**：非法定人数（n_eff<q）时不产生群体承诺；共模来源的重复证据不增加 n_eff，故"台数多数"不能放大共模错误。
3. **共享记忆隔离性**：单谱系在 cap 内无法把边权推到 w_single 以上；超预算写入只进影子区；该谱系被证伪后其历史写入全部删除且广播降权。
4. **协同撤回安全性**：契约内撤回只经 {handoff, controlled_release, sync_unload}，每条路径均以 FS 复检或损伤上界为守卫，撤回不引入新的不可逆事件；责任谱系可归因。
5. **终止性**：PCX+++ 在 k_probes+k_cons+k_q+k_ft+k_ux 内终止于 {承诺, 绕行, L2 协商, 安全停}；假设分裂有有限槽位、失败即降级。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_ckpt (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                     + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                     + δ_CPC + Σ_c ε_mode(c) + δ_FS·1[joint] + δ_handoff·1[joint])
         − P(𝒢_S 结构性错误未检出 ∧ n_eff 高估) − P(共享 KG 谱系投毒未隔离) − P(通信分区撕裂)
```

关键：**灵巧性来自模式重规划而非放宽证书**（CPC 失败先换 κ，再换路）；**群体安全来自独立性而非数量**（n_eff 取代台数）；**协同安全来自可撤回契约而非一次性承诺**（撤回语义预设、FS 复检、责任可归因）。三者的安全通道仍是"信念更准、不确定性更大、动作更保守"，不新增第四通道。

## 6. 本轮最大风险

**一句话**：本轮把安全从"单点接触证据"推进到"接触程序 + 群体法定人数"，最大新风险是**保守性复合**——CPC 区间传播、谱系去相关的 n_eff 折扣、协同契约退出复检三者都取最坏情形，层层相乘后系统可能"处处可证、但几乎不敢动"，把灵巧性与群体并行性同时锁死；必须以"L1 宽松证书 + 受控试错 + 优雅撤回"作为合格证据通道，并为 n_eff 设可解释置信区间，否则我们得到的是一个数学上安全、工程上不动的机器人。
