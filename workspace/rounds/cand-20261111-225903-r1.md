# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮·新主题首轮；本轮灵感：「情感计算」×「迁移学习」）

> 第 54 轮把技能组合提升为“动作-鲁棒性双证书”，解决了**执行层**的覆盖与云边对齐。本轮补上**人侧状态与跨域复用**：情感计算给出人的情感状态与交互质量度量，迁移学习给出跨用户/跨任务复用这些度量的机制。核心矛盾：H25：情感标签主观、低信噪、非平稳，直接当监督信号会把“源域情感-动作相关”误当因果，迁移后在目标用户上产生共情错位与负迁移；H26：机器人的共情响应会反作用于人的情感，形成闭环混杂，观测到的 affect-conditioned policy 在干预下失效；H27：情感安全若以点估计为前提，会在分布外用户上系统性失守。

## 0. 直觉与动机

**灵感 1（情感是带校准的证据，不是标签）**
直觉：把“用户现在焦虑”当成一个真值标签，是情感计算最危险的简化。同一张脸、同一段语音在不同用户、不同文化、不同任务下可能对应完全不同的内部状态。更稳妥的建模是：情感估计器输出的不是点 `e`，而是一个**校准过的信念集 `E_δ(o)`**——“真实情感至少有 1-α 概率落在这个集合里”。控制层只对 `E_δ` 上一致安全的动作放行；当信念集过大或估计器自评可靠性不足时，宁可退回几何/保守策略，也不拿一个不可靠的情感点估计去驱动机器人。

**灵感 2（情感是域变量，不是任务噪声）**
直觉：跨用户迁移失败，往往不是任务技能没学会，而是**情感分布变了**：源用户对“靠近”感到亲切，目标用户可能感到压迫；源域里“语速快”代表高效，目标域里可能代表焦虑。因此不能把情感当成要消除的噪声，而应把它当成**域偏移的一个显式轴**。做法是双头表示：`φ` 学跨域不变的“任务相关几何/行为”表征，`ψ` 学用户私有的“情感-交互风格”表征；迁移时只迁移 `φ` 与共享先验，`ψ` 在目标域内用极小数据在信赖域内适配。这样核心技能不被负迁移污染，风格则允许个性化。

**灵感 3（迁移的单位是“情感条件下的双风险证书”）**
直觉：普通迁移学习只保证任务误差不升；但对人机交互，**任务成功而用户压力升高**同样是失败。因此迁移的产物不应只是一套参数，而应是一张证书：同时给出目标域的任务风险上界 `ε_task` 与情感风险上界 `ε_aff`，并附带支撑重叠度 `κ`、密度比上界 `w_max` 与因果可识别性标记。若目标情感落在源域支撑之外（`κ<κ_min`），证书直接拒绝迁移——**不对没见过的情感做外推**，这比事后道歉更安全。

**灵感 4（共情是闭环干预，不是被动预测）**
直觉：机器人安慰用户 → 用户情绪变好 → 下一轮观测变好 → 策略更容易重复该安慰动作。若只用观测数据学“什么动作伴随好情绪”，学到的是**自我实现的共情相关**，而不是“这个动作真的让用户变好”。因此必须区分 `E[e'|u]` 与 `E[e'|do(u)]`。可行手段是微随机化：以很小概率随机替换交互动作，估计因果共情增益 `G_emp` 与混杂偏差 `B_conf`；同时给增益设上界，防止策略学会“情感操纵”而非“情感支持”。

**灵感 5（技能也有情感指纹）**
直觉：第 54 轮的动作剖面 `α_S` 只描述“技能能占哪些动作”，没有描述“技能会消耗人的多少情感容量”。本轮给每个技能加一个**情感指纹 `β_S`**：执行该技能会带来的压力、认知负荷、信任变化、参与度变化。技能组合不仅要在动作空间可兼容，还要满足**累计情感预算**：连续高强度交互后必须插入恢复项（解释、停顿、降低速度）。这把“人会不会被机器人累垮”变成组合规划的一等约束。

**灵感 6（金字塔叠加情感-迁移层 𝔽）**
直觉：在第 54 轮的鲁棒性层 `𝕃` 与动作协同层 `𝔸` 之上叠加情感-迁移层 `𝔽`：`𝔽_0` 生理/行为情感信号，`𝔽_1` 校准情感信念集，`𝔽_2` 情感条件交互策略，`𝔽_3` 跨用户/跨任务迁移，`𝔽_4` 共情安全契约。跨层证书由 `J=(ρ,A_cert,γ_ce,δ_a)` 扩展为 `J4=(ρ,A_cert,β_cert,F_cert,γ_ce,δ_a)`；**情感不可证、支撑不足或因果不可识别的迁移，不得进入部署**。

## 1. 形式化定义（增量：定义 127–134）

**定义 127（情感状态与校准信念集）**
情感状态 `e=(v,a,c,t) ∈ 𝔼 = V×A×C×T`，其中 `v∈[-1,1]` 为效价，`a∈[0,1]` 为唤醒度，`c∈[0,1]` 为认知负荷，`t∈[0,1]` 为信任。情感观测 `o∈O_aff`（面部、语音、生理、交互日志）。估计器 `B: O_aff → Δ(𝔼_K)`，`𝔼_K` 为离散情感层。用分裂共形校准：分数 `s(o,e)=1-B(o)[e]`，取 `q_δ` 为校准集 `(1-α)` 分位数，定义信念集
`E_δ(o) = { e_k | B(o)[e_k] ≥ 1 - q_δ }`。
在可交换假设下 `Pr[e* ∈ E_δ(o)] ≥ 1-α`。可靠性 `r(o)=1-H(B(o))/log K`；仅当 `r(o) ≥ r_min` 时允许情感条件控制。

**定义 128（情感条件策略与情感风险谱）**
情感条件策略 `π(a|s,e)`。情感风险向量
`r_aff(e,a,s) = (r_stress, r_discomfort, r_trust↑, r_engage↓)`，
分别表示压力升高、不适、信任侵蚀、参与度下降。情感鲁棒性
`ρ_aff(π) = 1 - sup_{e∈E_δ} CVaR_β[ r_aff(e,π(e),s) ]`。
与第 53 轮鲁棒性谱做积序 `ρ^+ = ρ ⊗ ρ_aff`；部署要求 `ρ^+(d) ≥ ρ_min(d)` 对所有维度成立。

**定义 129（情感域偏移与可迁移度）**
域 `D=(P(o_aff),P(s),P(task),u)`。情感支撑重叠
`κ_aff = ∫ min(p_S(e), p_T(e)) de`，
标签可靠性 `λ_aff = E[1(e*∈E_δ)]`，可迁移度 `κ = κ_aff·λ_aff`。
密度比 `w(e)=p_T(e)/p_S(e) ≤ w_max`。若 `κ < κ_min`，则**禁止迁移**，回退到目标域冷启动或纯几何策略。

**定义 130（双头情感不变量与分层适配）**
表示分解为共享不变量 `φ: S×O_aff → Z_inv` 与私有风格 `ψ: 𝔼×U → Z_style`（`U` 为用户/情境）。策略
`π(a|s,e,u) = π_0(a | φ(s,o_aff), ψ(e,u))`。
`φ` 通过“任务损失 + λ·d_ℋ(φ(D_S),φ(D_T))”学习（可用 MMD/对抗域分类器近似）；`ψ` 为用户适配器 `θ_u ~ N(θ_0,Σ)`，在信赖域 `||θ_u-θ_0|| ≤ τ_pool` 内做部分池化更新。迁移门控通过后 `φ` 冻结，只允许 `θ_u` 适配，防止负迁移进入核心技能。

**定义 131（技能情感指纹与组合预算）**
技能 `S` 的情感指纹 `β_S: 𝔼×A → [0,1]^m`，`m` 为情感风险维数。技能序列 `S_1..S_k` 的累计指纹
`β_comp = clip( Σ_i β_{S_i} - R_rec, 0, 1 )`，
其中 `R_rec` 为恢复项（解释、停顿、降速）带来的情感容量回补。组合可行当且仅当
`||β_comp||_∞ ≤ B_aff` 且第 54 轮动作兼容条件成立。这把情感预算接入 SCOM 的边权。

**定义 132（共情响应核与共情增益上界）**
共情响应核 `K_emp: 𝔼×U → Δ(𝔼)` 描述交互动作 `u` 如何改变人的情感。共情增益
`G_emp = ∂ E[K_emp(e,u)] / ∂u`（Jacobian）。安全约束：`||G_emp||_2 ≤ Θ_g`，且方向约束为“提升效价、降低压力/负荷”。定义情感 CBF `h_aff(e,u) = (stress_max-stress, trust-trust_min, …)`；当 `ρ_aff < ρ_min`、`||G_emp|| > Θ_g` 或信念集过大时，强制进入 **CARE 模式**（降速、增距、给出解释、必要时移交人类），而不是继续优化任务奖励。

**定义 133（闭环可识别性与混杂偏差）**
因果图含未观测混杂 `U_c`：`U_c → e`、`U_c → u`、`e → u`、`u → e'`。观测效应与干预效应之差定义混杂偏差
`B_conf = sup_{u,s} | E[e' | do(u),s] - E[e' | u,s] |`。
以概率 `ε_mr` 对交互动作做微随机化，可在有限样本下估计 `B_conf`。若 `B_conf > Θ_b`，则证书必须标记 `causal=false`：禁止把该策略当作因果共情策略迁移，只允许作为带护栏的相关性热启动。

**定义 134（情感迁移联合证书 J4）**
联合证书
`J4 = (ρ, A_cert, β_cert, F_cert, γ_ce, δ_a)`，
其中 `β_cert=(β_comp, B_aff, evidence)`，`F_cert=(ε_task, ε_aff, κ, w_max, B_conf, α_cov, causal, evidence)`。部署当且仅当
```
dom(T)=in ∧ δ_a<Θ_a ∧ ρ^+≥ρ_min ∧ κ≥κ_min ∧ α_cov≤α
∧ (B_conf≤Θ_b ∨ causal=false→CARE) ∧ ||β_comp||_∞≤B_aff
```
任一条件不满足，则拒绝迁移、拒绝组合或降级为 CARE/几何-only 模式。

## 2. 关键算法 伪代码

### IP-121 ABC（Affective Belief Calibration）

```python
def calibrate_affect(est, calib_loader, alpha=0.1):
    scores = [1.0 - est.belief(o)[e_true] for o, e_true in calib_loader]
    q = quantile(scores, 1 - alpha, method="higher")
    return ConformalAffect(est, q, alpha)

def affect_belief_set(conf, o, r_min=0.6):
    b = conf.est.belief(o)
    E = {e for e, p in b.items() if p >= 1.0 - conf.q}
    r = 1.0 - entropy(b) / math.log(len(b))
    return E, r, (r >= r_min)
```

### IP-122 AIT（Affective Invariant Transfer）

```python
def fit_invariant_encoder(sources, lam=1.0):
    phi = Encoder()
    for batch in sources:
        zs, zt = phi(batch.source), phi(batch.target_view)
        loss = task_loss(phi, batch) + lam * discrepancy(zs, zt)
        update(phi, loss)
    return phi

def adapt_style(phi, target, theta0, tau_pool):
    theta = theta0.clone()
    for batch in target:
        g = grad(affective_risk(phi, theta, batch), theta)
        theta = project_ball(theta - lr * g, theta0, tau_pool)
    return theta
```

### IP-123 ESC（Empathic Safety Contract）

```python
def empathic_filter(pi, E_delta, u_des, Theta_g, rho_min):
    if gain_bound(pi) > Theta_g or max_risk(E_delta) > r_max:
        return care_mode(pi)
    u = argmin_u ||u - u_des||**2
    s.t. h_aff(e, u) >= 0 for all e in E_delta
    return u
```

### IP-124 MRC（Micro-Randomized Causality）

```python
def micro_randomized_gain(policy, env, eps_mr=0.1, horizon=2000):
    data = []
    for t in range(horizon):
        u_des = policy(env.state)
        u = random_intervention(u_des) if bernoulli(eps_mr) else u_des
        e_next = env.step(u)
        data.append((env.state, u, e_next))
    G_emp = causal_gain(data)
    B_conf = confounding_bias(data)
    return G_emp, B_conf
```

### IP-125 AFC（Affective Footprint Composition）

```python
def affective_composition(skill_seq, beta, recovery, B_aff):
    acc = zeros_like(beta[skill_seq[0]])
    for s in skill_seq:
        acc = clip(acc + beta[s] - recovery[s], 0.0, 1.0)
    return acc if norm_inf(acc) <= B_aff else reject("affect_budget")
```

### IP-126 J4（Joint Affective Transfer Certificate）

```python
def joint_affective_certificate(skill_seq, gamma_ce, F, beta_cert, budgets):
    if F.kappa < budgets.kappa_min:
        return reject("no_affective_support")
    if F.B_conf > budgets.Theta_b and F.causal:
        return reject("confounded")
    if not affective_composition(skill_seq, beta_cert.beta, beta_cert.rec, budgets.B_aff):
        return reject("affect_budget")
    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    if delta_a > budgets.delta_a:
        return reject("action_mismatch")
    rho_plus = compose_robustness_chain([s.rho for s in skill_seq], K) * F.rho_aff
    if min(rho_plus.values()) < budgets.rho_min:
        return reject("robustness_fail")
    return ok(J4(rho_plus, A_cert(A_core), beta_cert, F, gamma_ce, delta_a))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| ABC | O(n_cal·K + \|O_aff\|·K) | O(n_cal + K) | 共形覆盖、可靠性门控 |
| AIT | O(E·B·(\|φ\|+\|ψ\|)) | O(\|φ\|+\|ψ\|) | 域不变、信赖域适配 |
| ESC | O(\|E_δ\|·\|U\| + QP) | O(\|E_δ\|·\|U\|) | 鲁棒 CBF、增益上界 |
| MRC | O(T·(\|S\|+\|U\|)) | O(T) | 微随机化、探查重叠 |
| AFC | O(k·m) | O(m) | 指纹可加、恢复项单调 |
| J4 | O(\|S\|·\|A\| + \|S\|²) | O(\|A\|+\|S\|²) | 多条件证书 sound |

**正确性定理（Affective Transfer Soundness under Bounded Shift）**
假设 (A22)–(A28) 承接第 53/54 轮；**(A29)** 目标情感层上加权共形覆盖成立 `Pr[e*∈E_δ] ≥ 1-α`；**(A30)** `κ ≥ κ_min`、`w(e) ≤ w_max`、`λ_aff ≥ λ_min`；**(A31)** `K_emp` 满足 Lipschitz 条件且微随机化估计满足 `B_conf ≤ Θ_b`；**(A32)** `β_comp` 的 CVaR 在 `B_aff` 内且 `||G_emp|| ≤ Θ_g`。

则目标域任务风险与情感风险满足
```
R_T^task(π) ≤ R_S^task(π) + λ_φ + w_max·d_ℋ(φ(D_S),φ(D_T)) + sqrt(log(1/δ)/(2n_eff))
R_T^aff(π)  ≤ R_S^aff(π)  + w_max·d_ℋ^aff(φ(D_S),φ(D_T)) + B_conf + M·α
```
进而部署成功且情感安全的概率
```
P(success ∧ affect-safe) ≥ 1 - R_T^task - R_T^aff
    - P(κ<κ_min) - P(β_comp>B_aff) - P(δ_a>Θ_a)
```
关键：**先验支撑不足则拒绝迁移**、**因果不可识别则只做带护栏热启动**、**情感预算超限则拒绝组合**。三者缺一，证书退化为一纸空文。

## 6. 本轮最大风险

**一句话**：情感-迁移层的 soundness 同时依赖“校准信念集覆盖、目标域支撑重叠、共情闭环因果可识别、情感预算可行”四个条件；一旦情感标签不可靠或机器人自身响应造成闭环混杂，迁移会把“自我实现的共情相关”当成安全证书，在目标用户上系统性抬升压力却仍显示部署成功，故必须以 **支撑重叠门控 + 微随机因果标记 + 共情增益上界 + 情感预算硬约束** 四重护栏，宁可拒绝迁移，也绝不把情感当成可外推的真值。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（ABC×AIT×ESC×MRC×AFC×J4）

> 承接第 54 轮产物 v31。本轮在“动作-鲁棒性”体系之上增加 **人侧情感状态** 与 **跨用户/跨任务迁移** 两个维度：

> - **MRC（Micro-Randomized Causality）**：微随机化识别共情因果效应，显式估计闭环混杂偏差；
> - **AFC（Affective Footprint Composition）**：技能情感指纹 `β_S` 与组合情感预算；
> - **J4（Joint Affective Transfer Certificate）**：动作-鲁棒-情感-迁移联合证书。
>

## 2. 关键算法 伪代码

### IP-121 ABC

```python
def calibrate_affect(est, calib_loader, alpha=0.1):
    scores = [1.0 - est.belief(o)[e_true] for o, e_true in calib_loader]
    q = quantile(scores, 1 - alpha, method="higher")
    return ConformalAffect(est, q, alpha)

def affect_belief_set(conf, o, r_min=0.6):
    b = conf.est.belief(o)
    E = {e for e, p in b.items() if p >= 1.0 - conf.q}
    r = 1.0 - entropy(b) / math.log(len(b))
    return E, r, (r >= r_min)
```

### IP-122 AIT

```python
def fit_invariant_encoder(sources, lam=1.0):
    phi = Encoder()
    for batch in sources:
        loss = task_loss(phi, batch) + lam * discrepancy(
            phi(batch.source), phi(batch.target_view))
        update(phi, loss)
    return phi

def adapt_style(phi, target, theta0, tau_pool):
    theta = theta0.clone()
    for batch in target:
        g = grad(affective_risk(phi, theta, batch), theta)
        theta = project_ball(theta - lr * g, theta0, tau_pool)
    return theta

def transfer_gate(D_S, D_T, kappa_min, w_max):
    kappa = support_overlap(D_S.affect, D_T.affect) * label_reliability(D_T)
    if kappa < kappa_min:
        return "scratch"          # 支撑不足，禁止外推
    if density_ratio_bound(D_S, D_T) > w_max:
        return "scratch"
    return "transfer"
```

### IP-123 ESC

```python
def empathic_filter(pi, E_delta, u_des, Theta_g, r_max):
    if gain_bound(pi) > Theta_g or max_risk(E_delta) > r_max:
        return care_mode(pi)      # 降速/增距/解释/移交
    u = argmin_u ||u - u_des||**2
    s.t. h_aff(e, u) >= 0 for all e in E_delta
    return u
```

### IP-124 MRC

```python
def micro_randomized_gain(policy, env, eps_mr=0.1, horizon=2000):
    data = []
    for t in range(horizon):
        u_des = policy(env.state)
        u = random_intervention(u_des) if bernoulli(eps_mr) else u_des
        e_next = env.step(u)
        data.append((env.state, u, e_next))
    G_emp = causal_gain(data)
    B_conf = confounding_bias(data)
    causal_ok = (B_conf <= Theta_b) and overlap_ok(data)
    return G_emp, B_conf, causal_ok
```

### IP-125 AFC

```python
def affective_composition(skill_seq, beta, recovery, B_aff):
    acc = zeros_like(beta[skill_seq[0]])
    for s in skill_seq:
        acc = clip(acc + beta[s] - recovery[s], 0.0, 1.0)
    return acc if norm_inf(acc) <= B_aff else reject("affect_budget")
```

### IP-126 J4

```python
def joint_affective_certificate(skill_seq, gamma_ce, F, beta_cert, budgets):
    if F.kappa < budgets.kappa_min:
        return reject("no_affective_support")
    if F.B_conf > budgets.Theta_b and F.causal:
        return reject("confounded")
    if not affective_composition(
            skill_seq, beta_cert.beta, beta_cert.rec, budgets.B_aff):
        return reject("affect_budget")
    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    if delta_a > budgets.delta_a:
        return reject("action_mismatch")
    rho_plus = compose_robustness_chain(
        [s.rho for s in skill_seq], K) * F.rho_aff
    if min(rho_plus.values()) < budgets.rho_min:
        return reject("robustness_fail")
    return ok(J4(rho_plus, A_cert(A_core), beta_cert, F, gamma_ce, delta_a))
```

### 迁移决策主流程

```python
def transfer_pipeline(source_domains, target, task):
    phi = fit_invariant_encoder(source_domains)
    gate = transfer_gate(source_domains, target, kappa_min, w_max)
    if gate == "scratch":
        return train_from_scratch(target, task), "no_transfer"
    theta_u = adapt_style(phi, target, theta0, tau_pool)
    E_aff = calibrate_affect(est, target.calib)
    F = evaluate_transfer(phi, theta_u, target, E_aff)
    cert = joint_affective_certificate(
        task.skill_seq, gamma_ce, F, beta_cert, budgets)
    return (phi, theta_u), cert
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ABC | O(n_cal·K + \|O_aff\|·K) | O(n_cal+K) | 共形覆盖 ≥1-α，可靠性门控 |
| AIT | O(E·B·(\|φ\|+\|ψ\|)) | O(\|φ\|+\|ψ\|) | 域不变 + 信赖域，φ 冻结防负迁移 |
| ESC | O(\|E_δ\|·\|U\| + QP) | O(\|E_δ\|·\|U\|) | 鲁棒 CBF、增益上界 |
| MRC | O(T·(\|S\|+\|U\|)) | O(T) | 微随机化、重叠检验 |
| AFC | O(k·m) | O(m) | 指纹可加、恢复项单调、预算闭合 |
| J4 | O(\|S\|·\|A\|+\|S\|²) | O(\|A\|+\|S\|²) | 多条件证书 sound |

**正确性定理（Affective Transfer Soundness under Bounded Shift）**
假设 (A22)–(A28) 承接第 53/54 轮；**(A29)** 目标情感层加权共形覆盖 `Pr[e*∈E_δ]≥1-α`；**(A30)** `κ≥κ_min`、`w≤w_max`、`λ_aff≥λ_min`；**(A31)** `K_emp` Lipschitz 且 `B_conf≤Θ_b`；**(A32)** `β_comp` 的 CVaR 在 `B_aff` 内且 `||G_emp||≤Θ_g`。

则：
```
R_T^task(π) ≤ R_S^task(π) + λ_φ + w_max·d_ℋ(φ(D_S),φ(D_T)) + sqrt(log(1/δ)/(2n_eff))
R_T^aff(π)  ≤ R_S^aff(π)  + w_max·d_ℋ^aff(φ(D_S),φ(D_T)) + B_conf + M·α
P(success ∧ affect-safe) ≥ 1 - R_T^task - R_T^aff
    - P(κ<κ_min) - P(β_comp>B_aff) - P(δ_a>Θ_a)
```
关键：**先验支撑不足则拒绝迁移**，**因果不可识别则只做带护栏热启动**，**情感预算超限则拒绝组合**。

## 7. 本轮最大风险

**一句话**：情感-迁移层的 soundness 同时依赖“校准信念集覆盖、目标域支撑重叠、共情闭环因果可识别、情感预算可行”四个条件；一旦情感标签不可靠或机器人自身响应造成闭环混杂，迁移会把“自我实现的共情相关”当成安全证书，在目标用户上系统性抬升压力却仍显示部署成功，故必须以 **支撑重叠门控 + 微随机因果标记 + 共情增益上界 + 情感预算硬约束** 四重护栏，宁可拒绝迁移，也绝不把情感当成可外推的真值。
