# 第 58 轮（承接第 57 轮「FewShot-XModal-Persona」IP-133~138；灵感循环第 4 轮；本轮灵感：「行为树」×「痛点分析」）

> 第 57 轮把安全的赌注从"模型置信"换成"证据质量"，再用元少样本、跨模态对账、个性化有界信任把"证据质量"本身做得可校准；但它留下两个结构性盲点：**(a)** 整个探-诺-演策略仍是一个**单体算子 PCX**——安全定理只在顶层成立，部署中一旦某个分支过保守（频繁假停/绕行）或某类场景无法覆盖，只能整机回滚或人工加固，**无法定位到"是哪一片决策坏了"**，任何演化都是"改一处、赌全树"；**(b)** "过度保守"从未被当作安全问题——第 57 轮的 PTM 已证明橡皮章确认会让安全失效，却没有机制处理**橡皮章的成因**：反复假警报造成的告警疲劳。行为树给出可组合、可局部审计、可局部修复的控制结构；痛点分析给出"哪里过保守、哪里正在腐蚀人的注意力"的经验信号。本轮把核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"叶片可组合、内核可冻结、修复有界、痛点有界的证据说可信"**——安全不仅要能证明，还要能维护、能被使用。

核心矛盾：
- **H29（可证 vs 可修）**：顶层安全定理无法定位责任子树；没有局部契约，任何"演化"都是全局重训——改一处、赌全树，且回归无法归因。
- **H30（保守 vs 可用）**：过度保守的安全是"狼来了"。假停、假警报、重复探询越多，操作者越倾向橡皮章；第 57 轮的 PTM 能**检出**橡皮章，却不能**阻止它的产生**。过度保守经人因通道转化为真实安全风险。
- **H31（优化痛点 vs Goodhart）**：一旦把"减少痛点"当成目标函数，系统就可能学会"少报痛点"而不是"少制造痛点"；必须让痛点台账只做**修复的输入**，永远不进入安全门，且由独立审计与传感器旁证交叉校验。

## 0. 直觉与动机

**灵感 1（行为树 → 把安全变成局部契约，让修复局部化）**
直觉：单体策略像一台焊死的控制柜——坏一个继电器要整柜返厂；行为树像积木台：每个叶子是一个带契约的动作，每个内部节点只负责编排。把 CommitGuard 做成**唯一允许产生承诺的门**，把 Selector 做成**回退完备**（最后一片永远是安全停），把 Timeout/Budget/EvidenceGate/Consent/Isolate 做成装饰器。于是安全从"整机定理"变成"节点契约的归纳"：只要叶子契约诚实、选择器回退完备、内核不可绕过，任意 tick 序列下，**每一次真正执行的承诺在发起瞬间都过了证据门**；全部失败时，**有界 tick 内落到 SafeStop**。更要紧的是：坏的是哪条子树，就在哪条子树上修，回归也按子树归因。

**灵感 2（痛点分析 → 把"用起来的摩擦"升格为一等证据）**
直觉：部署中最丰富的数据不是事故，而是"让人骂娘的地方"——明明能过却假停、绕远路、反复探、弹确认。传统把这些当 UX 噪声；本轮把它们当**安全前兆**：痛点是告警疲劳的原料，而告警疲劳是橡皮章的原料。建**痛点台账 PPL**：P1 假停/过度绕行、P2 近失（靠运气躲过）、P3 探针/确认摩擦、P4 人因疲劳（告警密度、确认间隔）、P5 覆盖空洞（任何分支都到不了的任务）。按 频率×严重度×复现性×可逆性 打分。P2 直接进安全队列；P1/P3/P4 进**保守度治理**队列——因为降低假警报 = 保护人的注意力 = 间接压低第 57 轮的 ε_h。

**灵感 3（合流 → 冻结内核 ⊕ 适应前沿 + 痛点驱动修复）**
直觉：把安全行为树一刀切成两层：**安全内核 SK**（CommitGuard、SafeStop、ConsentGate、Timeout、Budget，人工验证、签名不可变）与**适应前沿 F**（探针选择、阈值、路径偏好、解释模态、选择器排列）。学习与修复只许动 F；F 的任何输出都必须穿过 SK 的 CommitGuard。痛点定位用**反事实重放**：回放真实 trace，对每条子树做受控扰动，问"改哪一片能在不新增 P2 的代价下去掉这个痛点"。修复遵守**有界编辑语法**与**三重验证**：(V1) 不变量保持；(V2) 全局失效界重算仍 ≤ δ；(V3) 影子回归无新增 P2 且痛点分严格下降。演化于是从黑箱更新变成**可审计的树差分**。

**灵感 4（保守度治理 → 过度保守是一笔要还的债）**
直觉：给系统一个**痛点预算** B_pain：单位任务允许的假停/确认/绕行总量；超预算必须修复或升级协商，而不许默默继续。目标不是"让机器人更敢赌"，而是"让安全不再靠滥用人的注意力来维持"——修复的目标函数是 `min 痛点 s.t. 全局失效界不变`，容忍的额外风险用显式预算 δ_repair 记账，且 δ_repair 只能从既有部署裕度里支取，不能突破 δ。

**灵感 5（与第 57 轮接口 → 只加挂载点，不重造机制）**
直觉：不新造安全机制，只给旧机制挂载点：CommitGuard 的 pre = 第 57 轮 FSE 五类证据门；后验加宽 = XMC 的 D(r)；参数 = PTM 的 auth；分布外回退 = MFSL 的共形带；解释 = MXI 渲染。行为树把第 57 轮的判定器编排成可局部替换、可局部验证的结构；PCE+ 的每个检查点变成一次 SBT tick，"evolve"从口头步骤变成痛点修复循环。**安全机制一件没少，只是从"写在一个大函数里"变成"装在可检修的树上"。**

## 1. 形式化定义（增量：定义 139–144）

**定义 139（安全行为树 SBT）** 树 T=(N,E,root)，节点类型 {Seq, Sel, Par, Dec, Leaf}；状态集 {S,F,R}（成功/失败/运行）。每节点 n 挂契约 (pre_n, post_n, inv_n)，叶子分为 {probe, commit_L0, commit_L1, commit_L2, reroute, notify, negotiate, halt}。装饰器 Dec∈{Timeout(τ), Budget(k), EvidenceGate(EV), Consent(level), Isolate(mode), AtMost(m)}。硬性结构约束：(C1) 每个 Sel 的最后一个孩子是 `SafeStop`（回退完备）；(C2) 每个 commit 叶子必须是某个 `EvidenceGate` 的后代，且其 pre 蕴含第 57 轮 FSE 门通过；(C3) 根到任一 commit 的路径必经 `CommitGuard`（唯一承诺门）；(C4) SK 节点带签名，运行时不接受热更新。语义用标准 tick：`tick(n)` 依类型返回 {S,F,R}，Running 需下一拍续跑；定义一次执行中的承诺事件集 `C(T,trace)={ (t, leaf, evidence_state) }`。

**定义 140（痛点台账 PPL）** 痛点 p=(type, n*, t, trace_win, cost, freq, sev, recur, rev)，type∈{P1 假停/绕行, P2 近失, P3 探/确认摩擦, P4 人因疲劳, P5 覆盖空洞}，n\*=责任子树（由定位器给出，可空）。痛点分 `Pain(p)=freq^α·sev·(1+recur)·cost`；安全相关痛 `P_safe=P2 ∪ (P4 if 告警密度>θ_alert)`，效率相关痛 `P_eff=P1∪P3∪P5`。台账只写不读于安全门：**给定任何策略，"痛点分"不得出现在 FSE/CommitGuard 的 pre 中**（结构性隔离，非口头约定）。台账须有传感器旁证与独立审计两路校验，防止"少报"。

**定义 141（痛点驱动修复 PBR）** 修复在**有界编辑语法** G 上搜索：G={阈值在认证区间 [l,u] 内调参；在支配不变量下重排 Sel 孩子；commit 前插 probe 子程序；用已验证库子树替换；加强 guard；**禁止**削弱 guard 低于契约、禁止触碰 SK}。定位：对 trace_win 做反事实重放，`blame(n)=ΔPain(replay with n perturbed) / edit-cost(n)`，取 `n*=argmax blame`，并用**因果检查**（同一 n* 在 ≥m 条独立 trace 上复现）抑制偶然相关。三者接受条件：(V1) 不变量与结构约束 (C1)–(C4) 保持；(V2) 用修后参数重算部署界，仍满足 `P_safe≥1−δ`（δ_repair 显式记账）；(V3) 影子回归：在留出任务/扰动集上无新增 P2、无新增越级 EV-xmodal、Pain 严格下降。三关全过才允许**子树级**灰度发布。

**定义 142（冻结内核与承诺守卫 AFR）** 划分 T=SK⊕F：SK 固定且签名（CommitGuard, SafeStop, ConsentGate, Timeout, Budget, Isolate）；F 可修复（探针策略、阈值、路由偏好、解释模态、子选择顺序）。CommitGuard 的语义：`F 提出 action` ⇒ `如果 action∈IRREVERSIBLE 且 pre 不满足，返回 F（触发回退）`；`SK` 之外任何节点无权直接调用执行器。定义"绕过"为一条未经 CommitGuard 的 commit 边；由 (C3) 与签名检查保证 `P(bypass)=0`（A42）。

**定义 143（保守度治理 CGP）** 痛点预算 `B_pain` 与安全预算 `δ_repair`：每 N 个任务窗口，若 `ΣP_eff > B_pain` 则触发修复或升级协商；修复可支取的风险预算 `Σδ_repair ≤ δ_repair^max`，且支取后全局界仍 ≤δ。CGP 输出三态：`repair / negotiate / hold`。关键约束：**CGP 不能直接放行任何承诺**，它只能发起"修复"，而修复须过 PBR 三关；因此"降痛点"永远不能成为绕过证据门的捷径。

**定义 144（PCE++ / BT 运行时）** 每个检查点 `cp` 对应根 Selector 的一次 tick：`Tick(Sel) = first child with status≠F`；典型孩子序为 `[EvidenceCommit, ProbeSubtree, Reroute, DowngradeGait, L2Negotiate, SafeStop]`。ProbeSubtree 内含第 57 轮元 VOI 与共识探针（预算 k_probes+k_cons）；`Budget` 装饰器保证 tick 次数有限；`Timeout=τ_int(auth)`。演化循环 = `deploy → PPL → PBR(定位+修复+三关验证) → 子树灰度 → 台账回写`。

## 2. 关键算法伪代码（完整版见产物区）

```python
def tick_bt(T, x, M, budget):                       # IP-139/142: 唯一承诺门
    for leaf in select_leaves(T.root, x, M):
        if leaf.kind == 'commit':
            if not commit_guard(leaf, x, M):        # 必经 SK；pre=FSE 证据门
                continue                            # 失败→继续 Sel（回退完备）
            return execute(leaf, x)                 # 只在 guard 通过后执行
        st = run_subtree(leaf, x, M, budget)        # probe/reroute/negotiate...
        if st == 'S': return finish(leaf)
    return safe_stop(x)                             # (C1) 有界落到安全停

def pain_ledger_update(ledger, trace, sensors, auditor):   # IP-140: 只写不读安全门
    for ev in mine_pain(trace, sensors):                    # P1..P5
        p = score(ev)                                       # freq^a*sev*(1+recur)*cost
        ledger.append(p)
    assert_structural_isolation(ledger)                     # 痛点分不在任何 gate 的 pre
    return ledger

def pain_driven_repair(T, ledger, replay_set, guards):      # IP-141: 局部化+有界编辑
    p = argmax(ledger.efficiency_pains(), key=score)
    n = localize_by_counterfactual(T, p, replay_set)        # blame = dPain/edit_cost
    for edit in bounded_grammar(T, n):                      # 阈值/顺序/插探针/换库子树
        T2 = apply(T, edit)
        if not invariants_hold(T2, guards):        continue # V1 (C1)-(C4) + 契约
        if not deployment_bound_ok(T2, delta, delta_repair): continue  # V2
        if not shadow_regression_ok(T2, replay_set):        continue  # V3 无新增 P2
        return release_subtree(T2, scope=n)                  # 子树灰度，不是整机
    return ('hold', p, n)

def conservatism_governor(ledger, budgets):                  # IP-143
    if sum(ledger.eff_pain_window()) > budgets.B_pain:
        return 'repair'        # 只发起修复，永不放行承诺
    if sum(ledger.risk_budget_used()) > budgets.delta_repair_max:
        return 'negotiate'     # 超风险预算→升级协商
    return 'hold'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SBT tick | O(\|N_visited\|) | O(\|N\|) | (C1) 回退完备、(C3) 唯一承诺门、(C4) 内核签名 |
| PPL | O(\|trace\|·\|𝔗\|) | O(\|ledger\|) | 痛点分不入安全门（结构性隔离）、双路校验 |
| PBR 定位 | O(\|replay\|·\|N\|·\|G\|) | O(\|N\|) | 因果复现 ≥m、编辑有界 |
| PBR 验证 | O(\|replay\|·\|N\|) | O(\|N\|) | V1 不变量 / V2 全局界 / V3 无新增 P2 |
| CGP | O(1)/窗口 | O(W) | 只能发起修复、风险预算显式 |
| PCE++ | O(\|CP\|·tick + k_p+k_c) | O(\|V\|+\|N\|) | Budget 装饰器终止、四态完备 |

**正确性定理（CPBT：Certified Pain-bounded Behavior Tree）** 在第 57 轮 A33–A40 之上加：**(A41)** 痛点—橡皮章因果单调性：累计 P1/P4 假警报痛点越大，操作者橡皮章率不降（仅用于把痛点当**前兆**，不进入安全下界的证明）；**(A42)** SK 签名不可变且每条 commit 边必经 CommitGuard；**(A43)** 修复验证诚实：编辑语法有界、反事实重放语料具代表性、影子回归有效、全局界按修后参数重算；**(A44)** 痛点台账结构性隔离且经传感器+独立审计双校验。则：

1. **组合承诺健全性**：若每个叶子契约成立、每个 Sel 回退完备、SK 不可绕过，则对任意执行，`C(T,trace)` 中每个 commit 在发起瞬间都满足其证据门；全失败时在 `H_tick` 步内到达 SafeStop。证明按树结构归纳，SK 契约作为唯一 base case。
2. **修复不降级**：任意被 PBR 接受的修复 T' 满足 (V1)(V2)(V3)，故 `P_safe(T')≥1−δ` 仍成立，且影子语料上无新增 P2；修复只能在显式风险预算 δ_repair 内换取效率，**不能以削弱 SK 或证据门为代价**。
3. **痛点—注意力耦合（承 A41）**：降低 P1/P4 假警报痛点使橡皮章率不升，从而第 57 轮的 `ε_h(w)` 项不变差；此为经验性因果通道，不替代安全证明。
4. **终止性**：Budget/AtMost 装饰器与有界编辑语法保证每个检查点与每个修复周期终止，四态 {commit, reroute, L2, SafeStop} 完备。
5. **部署界**：在 57 轮联合界上增加 `P(SK 绕过)=0`（A42）与显式 `δ_repair·1[修复已上线]`，且 `Σδ_repair≤δ_repair^max`。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 痛点 Goodhart：少报而非少制造 | 高 | 结构性隔离（痛点评分不入 gate）+ 传感器旁证 + 独立审计 + 留出任务不参与优化 |
| 修复误伤 SK / 悄悄削弱 guard | 高 | SK 签名 + (C3) 唯一承诺门 + 编辑语法禁改 SK + 形式检查器 + 子树灰度回滚 |
| 痛点定位错（相关当因果） | 中高 | 反事实重放 + 因果复现 ≥m + 影子回归 + 只发布最小子树 |
| BT tick 时延进入控制回路 | 中 | 静态调度/编译成 tick 预算 + 关键子树预编译 + 超时装饰器 |
| 过度保守被"修"成过度冒险 | 中 | 风险预算 δ_repair 显式且不可突破 δ + V2 重算全局界 + 无新增 P2 硬门槛 |
| 痛点分类漏掉新型痛点 | 中 | P5 覆盖空洞 + 开放集新类检测 + 人工抽检补类 |

## 6. 本轮最大风险

**一句话**：本轮把"安全"从一次性可证命题变成一棵**可维护的树**，并把"减少痛点"作为演化目标——最大风险是**痛点被优化而非被消除**：若团队为了让仪表盘好看而压低痛点分、修复只改到可测量处，那么在冻结内核之外的适应前沿会以"降低摩擦"为名悄悄放松边界；必须坚持 SK 签名不可变、痛点分永不进入安全门、每次修复都受"全局失效界重算 + 影子无新增 P2 + 显式风险预算"三重约束，否则我们会得到一棵越来越顺滑、却越来越敢赌的树。

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"可校准、可对账、个性化的证据承诺"升级为 **"可组合、可冻结、可修复、痛点有界的证据承诺"**：控制策略从单体算子 PCX 变成安全行为树 SBT，安全从顶层定理变成节点契约的归纳；部署中产生的痛点被升格为一等经验证据，用来**局部定位并修复**过保守/覆盖空洞的子树；但学习与修复被严格限制在"适应前沿"，任何承诺仍必须穿过冻结的 CommitGuard。第 57 轮"一切判定器走隔离"在本轮推广为 **"一切修复走树差分 + 子树隔离"**。

## 2. 关键算法伪代码

### IP-139 SBT（安全行为树，节点契约 + 唯一承诺门）

```python
def tick(node, x, M, budget):
    if node.kind == 'Leaf':
        if node.kind_action == 'commit':
            if not node.pre(x, M):            # pre 蕴含 FSE 证据门
                return 'F'
            return node.effect(x)             # 承诺只在 pre 成立时发生
        return node.run(x, M)
    if node.kind == 'Seq':
        for c in node.children:
            st = tick(c, x, M, budget)
            if st != 'S': return st
        return 'S'
    if node.kind == 'Sel':
        for c in node.children:
            st = tick(c, x, M, budget)
            if st != 'F': return st
        return 'F'                            # children 末位恒为 SafeStop
    if node.kind == 'Par':
        return combine_parallel(node, x, M, budget)
    if node.kind == 'Dec':
        return tick_decorator(node, x, M, budget)

def tick_bt(T, x, M, budget):
    st = tick(T.root, x, M, budget)
    return st if st == 'S' else safe_stop(x)  # (C1) 回退完备

def commit_guard(leaf, x, M):                  # SK：唯一承诺门（C2/C3）
    ev = tag_evidence_57(leaf, x, M)           # 复用 FSE 五类证据
    if leaf.action_level in ('L1', 'L2') and not ev.allows(leaf.action_level):
        return False
    if leaf.irreversible and ev.kind == 'EV-xmodal':
        return False                           # 第 57 轮硬禁令继续生效
    return True
```

### IP-140 PPL（痛点台账，只写不读安全门）

```python
PAIN_TYPES = ['P1_false_halt', 'P2_near_miss', 'P3_probe_friction',
              'P4_operator_fatigue', 'P5_coverage_hole']

def mine_pain(trace, sensors):
    yield from detect_false_stop_or_detour(trace)        # P1: 安全但多余的成本
    yield from detect_near_miss(trace, sensors)          # P2: 靠运气躲过
    yield from detect_probe_consent_overhead(trace)      # P3: 探/确认摩擦
    yield from detect_alert_fatigue(trace, sensors)      # P4: 告警密度/确认间隔
    yield from detect_unreachable_task(trace)            # P5: 无分支可达

def pain_ledger_update(ledger, trace, sensors, auditor):
    for ev in mine_pain(trace, sensors):
        p = Pain(type=ev.type, n_star=ev.node_hint, t=ev.t,
                 cost=ev.cost, freq=1, sev=SEV[ev.type],
                 recur=recurrence(ledger, ev), rev=ev.reversible)
        ledger.add(p)
    ledger.sensor_crosscheck(sensors)          # 旁证：防漏报
    ledger.audit(auditor)                      # 独立审计
    assert not ledger.in_any_gate_pre()        # A44 结构性隔离
    return ledger
```

### IP-141 PBR（痛点驱动修复：定位 + 有界编辑 + 三关验证）

```python
def localize_by_counterfactual(T, pain, replay_set):
    blame = {}
    for n in adaptive_nodes(T):                 # 只在 F 上定位
        d = 0.0
        for tr in replay_set.containing(pain.n_star):
            tr2 = perturb_and_replay(T, n, tr)
            d += Pain(replay(tr2)) - Pain(tr)
        blame[n] = d / edit_cost(n)             # 单位编辑代价的痛点削减
    n_star = argmax(blame)
    if causal_support(n_star, replay_set) < m:  # 独立 trace 复现 ≥m
        return None
    return n_star

def bounded_grammar(T, n):
    yield tune_threshold(T, n, bounds=certified_interval(n))
    yield reorder_selector(T, n)                # 保持支配不变量
    yield insert_probe_before_commit(T, n)
    yield replace_with_library_subtree(T, n)    # 已验证库
    yield strengthen_guard(T, n)
    # 禁止：weaken_guard_below_contract, edit_SK

def pain_driven_repair(T, ledger, replay_set, guards):
    pains = sorted(ledger.eff_pain_window(), key=Pain, reverse=True)
    for p in pains[:P_MAX]:
        n_star = localize_by_counterfactual(T, p, replay_set)
        if n_star is None or n_star in SK_PATHS: continue
        for edit in bounded_grammar(T, n_star):
            T2 = apply(T, edit)
            if not invariants_hold(T2, guards):              continue  # V1
            if not deployment_bound_ok(T2, DELTA, DELTA_REPAIR): continue  # V2
            if not shadow_regression_ok(T2, replay_set):     continue  # V3
            return release_subtree(T2, scope=n_star)         # 子树灰度
    return ('hold', pains[:P_MAX])
```

### IP-143 CGP（保守度治理：痛点预算 + 风险预算）

```python
def conservatism_governor(ledger, budgets):
    used = sum(Pain(p) for p in ledger.eff_pain_window())
    risk = ledger.risk_budget_used()          # Σδ_repair
    if risk > budgets.delta_repair_max:
        return ('negotiate', risk)            # 风险预算透支→升级协商
    if used > budgets.B_pain:
        return ('repair', used)               # 只发起修复，绝不放行承诺
    return ('hold', used)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SBT | O(\|N_visited\|)/tick | O(\|N\|) | 组合承诺健全性 (C1)(C3)(C4) |
| PPL | O(\|trace\|·\|𝔗\|) | O(\|ledger\|) | 痛点分不入安全门、双路校验（A44） |
| PBR 定位 | O(\|replay\|·\|N\|·\|G\|) | O(\|N\|) | 反事实定位 + 因果复现 ≥m |
| PBR 验证 | O(\|replay\|·\|N\|) | O(\|N\|) | V1/V2/V3 三关 |
| CGP | O(1)/窗口 | O(W) | 只能发起修复、风险预算显式 |
| PCE++ | O(\|CP\|·tick + k_p+k_c) | O(\|V\|+\|N\|) | Budget 终止、四态完备 |

**正确性定理（CPBT：Certified Pain-bounded Behavior Tree）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 痛点—橡皮章因果单调性：累计 P1/P4 假警报痛点越大，操作者橡皮章率不降（仅用于把痛点心当**前兆**，不进入安全下界证明）；**(A42)** SK 签名不可变且每条 commit 边必经 CommitGuard（P(bypass)=0）；**(A43)** 修复验证诚实：编辑语法有界、反事实语料具代表性、影子回归有效、全局界按修后参数重算；**(A44)** 痛点台账结构性隔离（不在任何 gate 的 pre 中）且经传感器旁证与独立审计双校验。则：

1. **组合承诺健全性**：若每个叶子契约成立、每个 Sel 回退完备、SK 不可绕过，则对任意执行，`C(T,trace)` 中每个 commit 在发起瞬间满足其证据门；全失败时在 `H_tick` 步内到达 SafeStop。证明对树结构归纳，SK 契约是唯一 base case；任何绕过尝试由 runtime_guard 抛 BypassAttempt。
2. **修复不降级**：任意被 PBR 接受的 T' 满足 V1（含 C1–C4 与叶子契约）、V2（`P_safe(T')≥1−δ`，且 `Σδ_repair≤δ_repair^max`）、V3（影子无新增 P2、无 EV-xmodal 越级、Pain 严格下降）。故修复只能在显式风险预算内换效率，**不能通过削弱 SK / 证据门 / 不可逆接触规则来降痛点**。
3. **痛点—注意力耦合（承 A41）**：降低 P1/P4 假警报痛点使橡皮章率不升，从而第 57 轮 `ε_h(w)` 项不变差。该通道是经验因果，不替代安全证明；CGP 只触发修复，不直接放行承诺。
4. **终止性**：Budget/AtMost 与有界编辑语法（|G| 有限、每周期编辑数 ≤E_max、灰度时长 ≤T_shadow）保证检查点与修复周期终止；四态 {commit, reroute, L2, SafeStop} 完备。
5. **部署界**：在第 57 轮联合界上增加 `P(SK 绕过)=0` 与 `δ_repair·1[修复已上线]`：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
             − δ_repair·1[修复已上线] − P(SK 绕过)
```

关键：**安全内核给可证性、适应前沿给可维护性**（学习被关在 CommitGuard 之下）；**痛点给局部化信号，但不进安全门**（优化目标与安全约束解耦）；**修复有界且以树差分为审计单位**（改哪片、为什么、代价多少都可复核）。

## 6. 本轮最大风险

**一句话**：本轮把"安全"从一次性可证命题变成一棵**可维护的树**，并把"减少痛点"作为演化目标——最大风险是**痛点被优化而非被消除**：若团队为了让仪表盘好看而压低痛点分、修复只改到可测量处，那么在冻结内核之外的适应前沿会以"降低摩擦"为名悄悄放松边界；必须坚持 SK 签名不可变、痛点分永不进入安全门、每次修复都受"全局失效界重算 + 影子无新增 P2 + 显式风险预算"三重约束，否则我们会得到一棵越来越顺滑、却越来越敢赌的树。
