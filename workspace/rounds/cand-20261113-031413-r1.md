# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰三层鲁棒操作闭环」IP-193~202；灵感循环 III 第 1 轮；本轮灵感：「群体智能」×「安全交互」）

> 第 63 轮 LIRO 把单机操作补成了「LiDAR 几何先验 × 通用技能组合 × 四类干扰认证」的闭环，但其全部证书 J_liro、场景银行 SSB、技能库 USL 与安全屏蔽 Shield-Skill 都建立在**单智能体、静态环境、他者不可见**的隐含假设上。本轮自述暴露了三个结构性缺口：
> 1. **群体维度缺失**：SSB 是单机私有记忆，N 个机器人各自「盲人摸象」地重复探索同一场景；φ̂ 的置信球只由本地传感与 RSC 收缩，**没有利用邻居的互补视角与独立观测**——群体本可提供的方差缩减被完全浪费。
> 2. **交互安全缺失**：Shield-Skill 只投影自身技能的前置条件，**不建模他者（机器人/人）的意图、可达集与责任边界**；WCV-Geo 的最坏情形球只含物体物理参数 φ，不含「邻居下一刻会怎么动」，因此在多机/人机共存场景中 ρ_rob 会系统性虚高。
> 3. **集体知识不可信**：把 SSB 直接共享会引入**投毒、陈旧与串谋**问题；若简单地对邻居估计做平均，少数恶意/故障节点即可把错误共识注入所有智能体，使安全证书从「独立失效」退化为「相关失效」。
>
> 因此本轮不是给 LIRO 再加一个感知模块，而是把它的**不确定性与安全语义从「单机局部」提升到「群体交互」**：用群体智能提供**分布式估计与分工**，用安全交互提供**契约化责任与硬安全过滤**，二者互为约束——群体带来信息增益，交互带来安全边界；增益必须可验证，边界必须可组合。

## 0. 直觉与动机

**灵感 1（群体智能 → SIF 痕迹智能场 + CSC 共识安全融合）**
直觉：蚁群不靠中心调度，而靠**信息素痕迹（stigmergy）**间接协调；鸟群不靠全局地图，而靠邻居的局部观测达成一致。LIRO 的 SSB 本质上就是单机版的「场景信息素」——把它变成**群体共享、带扩散与挥发的痕迹场** SIF：智能体在场景指纹 s 上沉积 (成功/失败, ρ_rob, φ 残差, 技能 σ, 时间戳)，场按 `沉积 → 邻居扩散 → 挥发` 演化。阅读 SIF 得到的不是硬事实，而是**带来源与新鲜度的先验**，喂给 CSP 的技能成功率先验与 WCV-Geo 的 φ 初值。与此同时，CSC 在安全关键变量 (φ̂, r, ρ) 上做**拜占庭鲁棒共识**：先用坐标截尾均值剔除极端邻居，再以**方差加权融合**得到群体估计，并用「共识离散度」**保守地膨胀**半径——只有邻居证据一致时才收缩 WCV 球，否则宁可保守。**关键原则：共识只能压缩可验证的不确定性，不能压缩不可验证的分歧。**

**灵感 2（安全交互 → SIC 安全交互契约 + SCF 安全共存滤波 + HAA 人类授权分配）**
直觉：多智能体安全不能靠「每个机器人自己小心」的善意假设，而要靠**契约（contract）**：每个智能体公开承诺自己的不变安全集 G_i、对邻居的假设 A_i、以及违约时的兜底 fallback_i（安全停/后退）。若每个人的 A_i 都被别人的 G_j 兑现，则契约可组合，系统级安全由局部证书拼出。对**人**则不能要求其遵守契约：人被视为**有界理性扰动**，其可达集用反应时间+最大加速度的保守包络建模，机器人必须对「人最坏可达集」保持鲁棒不变。实时层再加一道 **SCF 控制障碍函数（CBF）二次规划滤波**：无论上游策略（含人类遥操作）输出什么，最终执行量都被投影到安全集内，并对人机距离使用更大的安全带。人类授权 HAA 用 λ∈[0,1] 混合人类输入与自主输入，但**安全责任不可转移**——SCF 永远在最后一道，λ 只改变任务偏好，不改变安全不变式。**关键原则：权限可共享，安全不可外包。**

**灵感 3（分工 → SDT 安全感知群体任务分工）**
直觉：群体智能的另一半是**分工**。USL 的技能原语由谁执行不应由中心指定，而应按「响应阈值 + 安全出价」分布式竞标：智能体 i 对技能 σ 出价 `b_i(σ) = cost_i + κ_s/ρ_i(σ) + κ_l·load_i`，只有通过 SIC 兼容性检查且 ρ_i>0 的智能体才能投标，最低价者获得执行权。这样任务分配天然把**安全裕度**计入成本——危险动作自动流向「最有把握且最不拥挤」的智能体，而不是流向「最闲」的智能体。

**灵感 4（三灵感合流 → SILK：Swarm-Intelligence Layered Safety networK 群体智能分层安全网）**
三者咬合：SIF 提供**集体先验**（少走弯路、共享失败），CSC 提供**可验证的信息增益**（方差缩减 + 保守膨胀），SIC/SCF/HAA 提供**交互层的硬安全**，SDT 提供**分工层的安全感知调度**。闭环：本地 LiDAR/触觉 → LIRO 单机闭环 → SIF 沉积/读取 → CSC 融合 → WCV-Geo 球心更准（或更保守）→ CSP 技能规划更稳 → SDT 分配 → SIC 契约协商 → SCF 硬过滤 → 执行 → 证据回沉积。**第 63 轮 LIRO 是「单机的几何-技能-干扰闭环」，SILK 是「群体的估计-契约-分工闭环」，且 SILK 不推翻 LIRO，而是把 LIRO 作为每个节点的内环。**

**灵感 5（LIRO 组件的原位升级）**
- **SSB → SIF**：场景银行升级为带扩散/挥发的共享痕迹场；条目附来源集合、时间戳、可信度。
- **WCV-Geo → WCV-Swarm**：最坏情形从「物体参数球」扩为「物体参数球 × 邻居可达集 × 人类可达包络」；半径含共识离散度膨胀项 δ_cons。
- **CSP → CSP-Contract**：候选技能序列除自身 𝒫_feas 外，还需通过 SIC 契约兼容性检查（不会与他人承诺冲突）。
- **Shield-Skill → Shield-Swarm**：除自身前置条件投影外，增加**交互约束投影**（不进入他人保留区、不违背已承诺的让行/接管协议）。
- **OLP-Geo → OLP-Swarm**：在线投影的损失增加「群体一致性正则」，但仅作用于可验证的共识方向，避免被多数错误拖走。
- **AIC → AIC-Inter**：干扰集增加「邻居异常行为 / 通讯延迟 / 拜占庭消息」维度，认证对象从单机技能序列扩为「技能序列 × 契约图」。

## 1. 形式化定义（增量：定义 201–215）

- **定义 201（SILK 闭环）**：SILK = (LIRO_1..N, SIF, CSC, SIC, SCF, HAA, SDT, SWC, J_silk)。定位：把第 63 轮 LIRO 作为每个节点的内环，新增群体估计层（SIF/CSC）、交互安全层（SIC/SCF/HAA）、分工层（SDT）与群体认证层（SWC）。不变式：**所有跨节点学习/协商/共识只发生在语义流；实时路径只做本地 LIRO 前向 + SCF 一步 QP + 契约兜底**。
- **定义 202（SIF 痕迹智能场）**：场 ℱ_t: 𝒮 → ℝ^{d_f}，𝒮 为场景指纹空间（复用 SSB 的 fp_cloud）。每个条目 e=(φ̂, ρ_rob, skill_stats, src_set, t_stamp, cred)。演化：
  `ℱ_{t+1}(s) = (1−ε_evap)·ℱ_t(s) + ε_diff·Σ_{j∈N_i} W_ij(ℱ_t(s) − ℱ_t^j(s)) + Σ_{deposits at s} d`。
  读取算子 `Read_SIF(s, i) → (φ_prior, σ_prior, cred, age)`；cred 由来源多样性、与本地几何一致性、时间衰减共同决定。SIF 不是事实库，读取结果一律作为**先验/软证据**，不得直接写入 J_silk 的硬约束。
- **定义 203（CSC 共识安全融合）**：对安全关键向量 z_i=(φ̂_i, r_i, ρ_i)，每轮
  `z_i^{k+1} = z_i^k + γ·Σ_{j∈N_i} a_ij·(TM_f({z_l^k}_{l∈N_i}) − z_i^k)`，
  其中 `TM_f` 为坐标截尾均值（剔除每坐标最大/最小各 f 个）。融合估计 `φ̄_i = Σ_j w_j φ̂_j`，`w_j ∝ 1/(σ_j²+ε)`，σ_j 为 j 的局部后验标准差。**共识安全膨胀**：`r_i^cons = r_i^local + δ_cons,i`，`δ_cons,i = max_{j∈N_i} ‖φ̂_i − φ̂_j‖ + β·diam(r)`；仅当 `δ_cons,i ≤ δ_trust` 才允许用融合结果**收缩**球，否则保持本地球或膨胀。
- **定义 204（SIC 安全交互契约）**：智能体 i 的契约 `C_i = (G_i, A_i, K_i, fallback_i)`：
  - `G_i ⊆ 𝒳`：i 保证维持的不变安全集（如 `‖p_i−p_j‖ ≥ d_min`、`|v_i| ≤ v_max`、`|f_i| ≤ F_max`、不进入他人保留区 K_j）；
  - `A_i`：i 对邻居的假设（j 遵守 C_j、j 的可达集不超过宣告包络、通讯消息在 τ_max 内）；
  - `K_i`：i 声明的保留区（他人不得进入）；
  - `fallback_i`：假设被违反或 SCF 不可行时的兜底（减速到停 / 沿安全方向后退 / 释放负载）。
  契约组合 `C_i ⊗ C_j` 可行 ⇔ `G_i ∩ G_j` 非空且双方 fallback 下可达集不相交；组合安全由 rely-guarantee 推理给出（见定理 5）。
- **定义 205（SCF 安全共存滤波）**：实时层求解 CBF-QP：
  `u_i* = argmin_{u} ‖u − u_i^des‖²  s.t.  L_f h_k(x) + L_g h_k(x)·u + α_k(h_k(x)) ≥ 0, ∀k`，
  约束集含：① 智能体间 `h_ij = ‖p_i−p_j‖² − d_min²`；② 人机间 `h_ih = ‖p_i−p_H‖² − d_human²`，`d_human > d_min` 且含反应时间项 `v_rel·τ_react + v_rel²/(2a_brake)`；③ 关节/力/速度硬限。对等责任采用**互惠 CBF**：双方各承担一半避让量，若对方未承担则由本方约束补足（保守）。QP 不可行 → 立即执行 `fallback_i`。
- **定义 206（HAA 人类授权分配）**：`u_i = Π_{SCF}(λ_i·u_H + (1−λ_i)·u_A)`，λ_i∈[0,1] 由信任校准与风险估计给出（高风险/低信任 → λ↓）。**安全不变式与 λ 无关**：∀λ，SCF 保证 `x∈G_i`；λ 只改变任务偏好与效率，不改变硬安全。
- **定义 207（SDT 安全感知分工）**：技能 σ 的投标 `b_i(σ) = cost_i(σ) + κ_s/ρ_i(σ) + κ_l·load_i`，可行投标集 `ℬ_σ = {i: π_σ ∈ 𝒫_feas,i ∧ SIC 兼容 ∧ ρ_i(σ) > 0}`。分配 `a(σ) = argmin_{i∈ℬ_σ} b_i(σ)`；无可行投标则技能降级或请求人类授权。分布式实现：响应阈值 + 共识拍卖，允许重分配但带滞回，避免抖动。
- **定义 208（SWC 群体级证书）**：`J_silk_i = (J_liro_i, F_ver, cons_cert_i, contract_graph_hash, scf_ver, inter_ρ_i)`。`Valid(J_silk_i) ⇔ Valid(J_liro_i) ∧ cons_cert_i 有效 ∧ 契约图可组合 ∧ 实际轨迹逐点满足 SCF ∧ inter_ρ_i ≥ 0`。`cons_cert_i = (φ̄_i, δ_cons,i, n_eff, f_bound, hash)`，其中 `n_eff` 为有效独立来源数。
- **定义 209（WCV-Swarm 交互感知鲁棒编译）**：最坏情形集 `Φ_i = B(φ̂_i, r_i) × ∏_{j∈N_i} Reach_j(τ_h) × Reach_H(τ_h)`，其中 `Reach_j` 为他者可达集（由其契约 G_j 与当前状态估计包络给出），`Reach_H` 为人类可达包络。WCV-Swarm 在 Φ_i 上取最坏 margin：`ρ_inter,i = min_{φ∈B, x_j∈Reach_j, x_H∈Reach_H} margin(K_safe; φ, x_j, x_H)`。**交互裕度直接进入证书，不再被单机 ρ_rob 掩盖。**
- **定义 210（共识信息增益与保守界）**：设局部估计满足 `φ̂_j = φ* + e_j`，e_j 独立、`E[e_j]=0`、`‖e_j‖≤δ_local`，至多 f 个节点拜占庭。CSC 截尾均值误差 `‖φ̄ − φ*‖ ≤ δ_local·√((n)/(n−2f)) + δ_byz`（保守形式），融合半径 `r̄ ≤ δ_local/√(n−2f) + δ_cons + δ_byz`。**只有当 `δ_cons` 小且 `n_eff` 足够时，群体才真正收缩不确定性；否则膨胀项占优，系统退回本地保守。**
- **定义 211（SIF 投毒防御 / 可信痕迹）**：条目的可信度 `cred(e) = min(1, |src_set|/q) · exp(−age/τ_evap) · consistency(e, local_geometry)`；仅当 `cred ≥ c_min` 且被 ≥ q 个**互不串谋的独立来源**佐证时才进入 CSP 先验与 WCV 初值；单源、陈旧、与本地 LiDAR 几何冲突的条目进入隔离区。场条目永不覆盖本地硬观测，只做软初始化。
- **定义 212（安全接管/交接协议）**：任务交接 `handover(i→j, σ)` 可行 ⇔ j 有 `π_σ ∈ 𝒫_feas,j`、双方契约组合可行、且交接窗口内存在 SCF 可行的公共安全走廊；交接期间双方同时维持 `fallback`，完成判据为 j 的 `ρ_inter ≥ ρ_handover` 持续 τ_h。人机接管同理，但人类侧只要求「可达包络可预测」，不要求遵守契约。
- **定义 213（交互干扰集）**：`ℰ_inter = ℰ_sens × ℰ_act × ℰ_adv × ℰ_ood × ℰ_neighbor × ℰ_comm`，新增 `ℰ_neighbor = {他者行为偏离契约的幅度 ≤ ε_nb}`、`ℰ_comm = {延迟 ≤ τ_max, 丢包 ≤ p_loss, 至多 f 个拜占庭消息}`。AIC-Inter 在 ℰ_inter 上认证 `(τ, 契约图)`。
- **定义 214（群体协调遗憾）**：`R_T^swarm = Σ_t [max_σ Σ_i U_i(σ; a_t) − Σ_i U_i(σ_t; a_t)]`，在通讯图混合时间 τ_mix 与拜占庭比例 f/n 下，`R_T^swarm ≤ O(√(T·τ_mix·log N) + (f/n)·T·δ_byz)`——**群体协作的收益被混合延迟与拜占庭比例显式折价**。
- **定义 215（安全不可外包原则）**：对任意上游策略 π（含人类输入），执行量必须经 `Π_{SCF}`；契约 `C_i` 的 fallback 必须独立于 π 可执行。即 `safe(π, C_i) = safe(Π_{SCF}(π), C_i)`，安全证明只依赖 SCF 与 fallback，不依赖上游策略的善意。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（共识收缩与保守膨胀）**：在定义 210 的独立误差与 f 拜占庭假设下，融合半径满足 `r̄ ≤ δ_local/√(n−2f) + δ_cons + δ_byz`。当 `n_eff ≥ 9, f/n ≤ 1/4, δ_cons ≤ δ_local/2` 时，`r̄ < r_local` 严格成立；当共识分歧大或来源不足时，膨胀项使 `r̄ ≥ r_local`，系统自动退回本地保守——**群体先验是「有条件增益」，不是无条件正确**。
- **引理 6（SIF 先验不破坏单机证书）**：若 SIF 仅作为软初始化且 `cred ≥ c_min`，则 WCV-Swarm 的球心偏移被 `δ_cons` 吸收，`J_liro` 的硬约束不被覆盖；投毒条目最多使性能退化，不能直接使 `Valid` 为真（定义 211）。∎
- **定理 4（契约组合安全性）**：若对每个 i `C_i` 成立，且假设图无环、每条 `A_i` 都被某个 `G_j` 或 `Reach_H` 包络兑现，则组合系统在 `∩_i G_i` 上前向不变——**局部契约拼出全局安全**。证明用 rely-guarantee 的不动点论证与定义 204 的组合条件。
- **定理 5（SCF 硬安全与授权无关性）**：若初始 `x(0) ∈ G_i`、CBF 约束在每步 QP 可行、fallback 保持不变集，则 ∀t, `x(t) ∈ G_i`，且该结论对任意 λ_i、任意上游策略 π 成立——**HAA 不削弱安全，SCF 不可被上游绕过**（定义 215）。
- **定理 6（群体认证可靠性）**：若每个 `J_liro_i` 有效、CSC 的拜占庭界 f<n/3 成立、契约图可组合、SCF 全程可行，则 `Valid(J_silk) ⇒ 系统在 ℰ_inter 下不违反 `∩_i G_i`，概率 ≥ `1−α_local−α_cons−α_comm`。**安全概率随节点数下降，但随拜占庭比例与通讯延迟上升而折价。**

## 2. 形式化定义（完整版）

**定义 201（SILK 闭环）** SILK 以 LIRO 为每个节点的内环，外接四层：① 群体估计层（SIF 共享痕迹场、CSC 鲁棒共识）；② 交互安全层（SIC 契约、SCF 硬过滤、HAA 授权分配）；③ 分工层（SDT 安全感知任务分配）；④ 群体认证层（SWC 证书组合）。时序隔离不变式：**跨节点学习、共识、契约协商、分工拍卖只发生在语义流（10–100Hz，允许异步与延迟）；实时路径（1–10kHz）只执行「本地 LIRO 前向 + SCF 一步 QP + 契约 fallback」，零跨节点写操作、零共识等待。**

**定义 202（SIF 痕迹智能场）** 场 ℱ 以场景指纹 s=fp_cloud 为索引。智能体 i 执行技能 σ 后沉积
`d_i(s) = (φ̂_i, ρ_rob,i, [n_succ,n_fail]_σ, src={i}, t, cred=1)`。
场演化（异步、事件驱动）：
`ℱ_{t+1}(s) = (1−ε_evap)·ℱ_t(s) + ε_diff·Σ_{j∈N_i} W_ij·(ℱ_t^j(s) − ℱ_t(s)) + Σ_{deposits} d`，
其中 `W_ij` 为通讯图邻接权重，`ε_evap ∈ (0,1)`，`ε_diff ∈ (0,1/deg_i)` 保证稳定。读取 `Read_SIF(s,i)` 返回先验与可信度；**SIF 读取不得覆盖本地硬观测，只初始化 WCV 球心与 CSP 技能成功率先验**。条目附 `src_set`（去重来源）、`age`、`cred`（定义 211）。

**定义 203（CSC 共识安全融合）** 对每个节点维护安全关键向量 `z_i=(φ̂_i,r_i,ρ_i)`。每轮共识：
`z_i^{k+1} = z_i^k + γ·Σ_{j∈N_i} a_ij·(TM_f({z_l^k}_{l∈N_i∪{i}}) − z_i^k)`，
`a_ij` 为行随机通讯权重，`TM_f` 逐坐标截尾。融合物理参数用逆方差加权：
`φ̄_i = Σ_{j∈N_i∪{i}} w_j φ̂_j / Σ_j w_j`，`w_j = 1/(σ_j²+ε)`。
**共识离散度** `δ_cons,i = max_{j∈N_i} ‖φ̂_i − φ̂_j‖ + β·diam(r_i)`。
**保守规则**：若 `δ_cons,i ≤ δ_trust` 且 `n_eff ≥ 9`，取 `r_i^cons = r̄_i + δ_cons,i`（`r̄_i` 为融合半径，见引理 5）；否则 `r_i^cons = max(r_i^local, r̄_i) + δ_cons,i`。**共识结果永远经过膨胀项才可进入安全球；分歧越大，膨胀越大，直到退回本地保守。**

**定义 204（SIC 安全交互契约）** 契约 `C_i=(G_i,A_i,K_i,fallback_i)`：G_i 为 i 承诺的前向不变安全集；A_i 为对邻居的假设（遵守契约、行为在宣告可达包络内、消息延迟 ≤ τ_max）；K_i 为保留区（他人不得进入）；fallback_i 为安全停/后退/释放负载，必须独立于上游策略可执行。组合条件：
`C_i ⊗ C_j 可行 ⇔ G_i∩G_j ≠ ∅ ∧ Reach(fallback_i) ∩ Reach(fallback_j) = ∅ ∧ K_i∩K_j = ∅`。
契约图 `𝒢_C = (V, E)`，边表示可组合；SWC 要求 `𝒢_C` 存在无环支撑子图（避免循环依赖导致假设无法落地）。

**定义 205（SCF 安全共存滤波）** 实时层 CBF-QP：
`u_i* = argmin_u ‖u−u_i^des‖² + ε_u‖u‖²`
`s.t. L_f h_k + L_g h_k·u + α_k(h_k) ≥ 0, k ∈ {机-机, 人-机, 关节限位, 力限, 速度限}`。
`α_k` 取线性/指数类 K∞ 函数。人-机约束采用**反应时间感知**：`d_safe = d_human + v_rel·τ_react + v_rel²/(2a_brake)`，`v_rel` 为相对速度，`τ_react` 取人类反应时间上界。机-机采用**互惠 CBF**：理想情况下双方各承担 50% 避让；若检测到对方未执行（履约监测残差 > ε_rec），本方将责任权重提升至 100%（保守）。QP 不可行 → 执行 `fallback_i`，并在 `J_silk` 标记 `scf_fallback=True`。

**定义 206（HAA 人类授权分配）** 执行量 `u_i = Π_SCF(λ_i·u_H + (1−λ_i)·u_A)`。λ_i 由信任校准与风险估计给出：
`λ_i = σ(a_trust·T_i − a_risk·ρ_inter,i − a_load·load_i)`。
**核心不变式**：对任意 λ_i ∈ [0,1] 与任意上游 u_H/u_A，只要 SCF 可行或 fallback 可执行，则 `x_i(t) ∈ G_i`。λ 只改变任务偏好，不改变安全证明——**安全责任不可转移给人类**。

**定义 207（SDT 安全感知分工）** 对技能 σ∈USL，可行投标集
`ℬ_σ = {i: π_σ∈𝒫_feas,i(φ̂_i,r_i^cons) ∧ C_i 与任务需求兼容 ∧ ρ_inter,i(σ)>0}`。
投标 `b_i(σ)=cost_i(σ)+κ_s/ρ_i(σ)+κ_l·load_i`。分配 `a(σ)=argmin_{i∈ℬ_σ} b_i(σ)`。
分布式实现：① 响应阈值触发候选；② 共识拍卖（最多 3 轮）；③ 滞回重分配（`b_new < (1−h)·b_old` 才切换，h=0.15）。若无可行投标，技能降级为 `safe_idle` 或请求人类授权（HAA 接管）。

**定义 208（SWC 群体级证书）**
`J_silk_i = (J_liro_i, F_ver, cons_cert_i, contract_graph_hash, scf_ver, inter_ρ_i)`，
`cons_cert_i = (φ̄_i, δ_cons,i, n_eff, f_bound, hash)`。
`Valid(J_silk_i) ⇔ Valid(J_liro_i) ∧ (δ_cons,i ≤ δ_max ∨ r_i 已膨胀) ∧ 𝒢_C 可组合 ∧ 实际轨迹逐点满足 SCF ∧ inter_ρ_i ≥ 0 ∧ dir_fresh。`
审计链：F_ver 追溯 SIF 版本，cons_cert 追溯共识来源与拜占庭界，contract_graph_hash 追溯契约图，scf_ver 追溯滤波器版本。

**定义 209（WCV-Swarm 交互感知鲁棒编译）** 最坏情形集
`Φ_i = B(φ̂_i,r_i^cons) × ∏_{j∈N_i} Reach_j(τ_h) × Reach_H(τ_h)`，
`Reach_j` 由 j 的契约 G_j、当前状态估计与最大加速度包络给出；`Reach_H` 为人类可达包络（反应时间 + 最大速度/加速度）。WCV-Swarm 在 Φ_i 上搜索最坏 margin：
`ρ_inter,i = min_{φ∈B, x_j∈Reach_j, x_H∈Reach_H} min_t margin(π_σ(·;φ), x_j, x_H)`。
若 `ρ_inter,i < 0`，技能不可执行，CSP-Contract 需重新规划或请求让行/接管。**交互裕度是证书的一部分，不能用单机 ρ_rob 替代。**

**定义 210（共识信息增益与保守界）** 设 `φ̂_j=φ*+e_j`，`E[e_j]=0`，`‖e_j‖≤δ_local`，至多 f 个拜占庭节点（误差任意但有界 δ_byz）。CSC 输出满足
`‖φ̄−φ*‖ ≤ δ_local·√(n/(n−2f)) + δ_byz`（保守上界），
`r̄ ≤ δ_local/√(n−2f) + δ_byz`。
**推论**：当 `n_eff ≥ 9`、`f/n ≤ 1/4`、`δ_byz ≤ δ_local/2` 时 `r̄ < r_local`；当来源不足或分歧大时，`δ_cons` 膨胀使 `r_i^cons ≥ r_i^local`，群体不产生虚假信心。

**定义 211（SIF 投毒防御 / 可信痕迹）**
`cred(e) = min(1, |src_set|/q)·exp(−age/τ_evap)·consistency(e, local_geometry)`。
仅当 `cred(e) ≥ c_min=0.6` 且被 ≥ q=3 个互不串谋来源佐证时，条目才进入 CSP 先验与 WCV 初值；单源、陈旧、与本地 LiDAR 几何冲突的条目进入隔离区并记录。**任何 SIF 条目都不能覆盖本地硬观测或直接置 `Valid(J_silk)=True`。**

**定义 212（安全接管/交接协议）** `handover(i→j,σ)` 可行 ⇔ `π_σ∈𝒫_feas,j` ∧ `C_i⊗C_j` 可行 ∧ 存在公共安全走廊 ∧ 交接窗口内双方维持 fallback。交接完成判据：j 的 `ρ_inter ≥ ρ_handover` 持续 τ_h。人机接管只要求人类可达包络可预测，不要求人类遵守契约；机器人始终保留 SCF 否决权。

**定义 213（交互干扰集）**
`ℰ_inter = ℰ_sens × ℰ_act × ℰ_adv × ℰ_ood × ℰ_neighbor × ℰ_comm`，
`ℰ_neighbor = {他者行为偏离契约 ≤ ε_nb}`，`ℰ_comm = {延迟≤τ_max, 丢包≤p_loss, 至多 f 个拜占庭消息}`。AIC-Inter 在此集合上认证 `(τ, 𝒢_C)`，采样 `n_cert=128`（新增两类各 32）。

**定义 214（群体协调遗憾）** `R_T^swarm = Σ_t [max_σ Σ_i U_i(σ;a_t) − Σ_i U_i(σ_t;a_t)]`。在通讯图混合时间 τ_mix、拜占庭比例 f/n 下，
`R_T^swarm ≤ O(√(T·τ_mix·log N) + (f/n)·T·δ_byz + N·H·ε_handover)`。**群体协作收益被混合延迟、拜占庭比例与交接失败率显式折价。**

**定义 215（安全不可外包原则）** 对任意上游策略 π（含人类遥操作），实际执行必须经 `Π_SCF`；`C_i` 的 fallback 必须独立于 π 可执行。形式化：`safe(π,C_i) = safe(Π_SCF(π),C_i)`。**安全证明只依赖 SCF 与 fallback，不依赖上游策略的善意，也不依赖邻居的善意（邻居善意只影响效率与保守度）。**

### IP-204 SIF（痕迹智能场）

```python
class StigmergicIntelligenceField:
    """共享痕迹场：沉积 → 扩散 → 挥发。异步、事件驱动、可隔离投毒。"""
    def __init__(self, eps_evap=0.02, eps_diff=0.1, q=3, c_min=0.6):
        self.field = {}          # scene_fp -> Entry
        self.neighbors = {}      # i -> {j: W_ij}
        self.eps_evap, self.eps_diff = eps_evap, eps_diff
        self.q, self.c_min = q, c_min

    def deposit(self, i, scene_fp, phi_hat, rho_rob, skill, success, t):
        e = self.field.setdefault(scene_fp, Entry())
        e.add(src=i, phi=phi_hat, rho=rho_rob, skill=skill,
              success=success, t=t)
        e.src_set.add(i)

    def diffuse(self, i, t):
        # 仅语义流周期调用；异步邻居版本可容忍延迟
        for s, e in self.field.items():
            neigh = [self.field[s] for j in self.neighbors[i]
                     if s in self.field]
            if neigh:
                agg = sum(W * n.vector(t) for W, n in zip(self.neighbors[i].values(), neigh))
                e.vector = (1-self.eps_evap)*e.vector + self.eps_diff*(agg - e.vector)

    def read(self, i, scene_fp, local_geometry):
        e = self.field.get(scene_fp)
        if e is None: return None
        cred = min(1.0, len(e.src_set)/self.q) \
             * math.exp(-(now()-e.t)/TAU_EVAP) \
             * consistency(e.phi, local_geometry)
        if cred < self.c_min:
            return None                       # 隔离：不进入先验
        return Prior(phi=e.phi, sigma=e.rho, cred=cred, age=now()-e.t)
```

### IP-205 CSC（拜占庭鲁棒共识）

```python
class ConsensusSafetyConsensus:
    def __init__(self, f_bound, gamma=0.2, delta_trust=0.05, beta=0.5):
        self.f, self.gamma = f_bound, gamma
        self.delta_trust, self.beta = delta_trust, beta

    def trimmed_mean(self, values):
        # values: list of per-coordinate arrays
        z = np.stack(values)                       # (n, d)
        z_sorted = np.sort(z, axis=0)
        if self.f > 0:
            z_sorted = z_sorted[self.f:-self.f]
        return z_sorted.mean(axis=0)

    def consensus_step(self, z_i, neighbor_z):
        tm = self.trimmed_mean([z_i] + neighbor_z)
        return z_i + self.gamma * (tm - z_i)

    def fuse(self, local_z, neighbors, local_geom):
        phi_bar = self.inverse_variance_weight(local_z, neighbors)
        delta_cons = max(np.linalg.norm(local_z.phi - nb.phi) for nb in neighbors) \
                     + self.beta * local_z.diam
        n_eff = len({nb.src for nb in neighbors} | {local_z.src})
        if delta_cons <= self.delta_trust and n_eff >= 9:
            r = phi_bar.r + delta_cons            # 融合半径 + 膨胀
        else:
            r = max(local_z.r, phi_bar.r) + delta_cons
        return phi_bar, r, delta_cons, n_eff
```

### IP-206/207 SIC + SCF（契约 + CBF-QP）

```python
class SafetyContract:
    def __init__(self, G, A, K, fallback):
        self.G, self.A, self.K, self.fallback = G, A, K, fallback

    def compose(self, other):
        if intersect(self.G, other.G).is_empty(): return None
        if reach(self.fallback).intersects(reach(other.fallback)): return None
        if intersect(self.K, other.K): return None
        return ComposedContract(self.G & other.G,
                                self.A.discharged_by(other.G),
                                K=self.K | other.K,
                                fallback=ProductFallback(self, other))

def scf_qp(u_des, x, neighbors, humans, cbf_params):
    """CBF-QP：机-机互惠、人-机反应时间感知、全部硬约束。"""
    cons = []
    for j in neighbors:
        h = dist2(x.p, j.p) - D_MIN**2
        cons.append(cbf_constraint(h, x, j, alpha=cbf_params.alpha_agent))
    for H in humans:
        d_safe = D_HUMAN + x.v_rel(H)*TAU_REACT + x.v_rel(H)**2/(2*A_BRAKE)
        h = dist2(x.p, H.p) - d_safe**2
        cons.append(cbf_constraint(h, x, H, alpha=cbf_params.alpha_human))
    cons += [joint_limit_constraint(x), force_limit_constraint(x),
             speed_limit_constraint(x)]
    sol = solve_qp(H=2*np.eye(x.dim), f=-2*u_des, C=cons)
    if not sol.feasible:
        return FallbackResult(contract_fallback=True)
    return sol.u
```

### IP-209 SDT（安全感知分工）

```python
class SwarmDivisionOfTasks:
    def __init__(self, kappa_s=0.5, kappa_l=0.2, h=0.15):
        self.kappa_s, self.kappa_l, self.h = kappa_s, kappa_l, h

    def bid(self, i, sigma, rho_i, cost_i, load_i, contract_ok):
        if not contract_ok or rho_i <= 0: return None
        return cost_i + self.kappa_s/rho_i + self.kappa_l*load_i

    def auction(self, sigma, agents, current_owner=None):
        bids = {i: self.bid(i, sigma, a.rho, a.cost, a.load, a.contract_ok)
                for i, a in agents.items()}
        bids = {i: b for i, b in bids.items() if b is not None}
        if not bids: return None                       # 请求授权/降级
        best = min(bids, key=bids.get)
        if current_owner and bids.get(best, 1e9) >= (1-self.h)*bids.get(current_owner, 1e9):
            return current_owner                       # 滞回，防抖动
        return best
```

## 4. 推导

**引理 5（共识收缩与保守膨胀）** 设 `φ̂_j=φ*+e_j`，e_j 独立、零均值、`‖e_j‖≤δ_local`，至多 f 个拜占庭节点误差有界 δ_byz。截尾均值剔除每坐标 f 个极值后，剩余 `n−2f` 个样本的均值的方差 ≤ `δ_local²/(n−2f)`，加上拜占庭项得 `‖φ̄−φ*‖ ≤ δ_local/√(n−2f)+δ_byz`。再叠加定义 203 的膨胀项 `δ_cons`，得 `r̄ ≤ δ_local/√(n−2f)+δ_byz+δ_cons`。当 `δ_cons≤δ_local/2`、`n_eff≥9`、`f/n≤1/4` 时右端 `< δ_local`，即严格收缩；反之膨胀项占优，退回本地保守。∎

**引理 6（SIF 先验不破坏单机证书）** SIF 只通过 `φ_prior` 初始化 WCV 球心，且 `cred≥c_min` 要求 ≥q 个独立来源与本地几何一致；球半径仍由 `r_i^cons` 控制，硬约束（ERTC、SCF）不读取 SIF。若条目被投毒，最坏使 `φ_prior` 偏移，偏移量被 `δ_cons` 与 `r_i^cons` 吸收，或触发 `consistency` 检查被隔离。因此 SIF 只能影响性能，不能单独使 `Valid(J_silk)` 为真。∎

**定理 4（契约组合安全性）** 对契约图的无环支撑子图做拓扑归纳。基例：叶节点无邻居假设，`C_i` 成立 ⇒ `G_i` 前向不变。归纳：若所有子节点契约成立且其 `G_j` 兑现父节点 `A_i`，则父节点在 `G_i∩(∩_j G_j)` 上的 CBF/fallback 条件成立 ⇒ 不变。组合条件 `G_i∩G_j≠∅` 与 fallback 可达集不交保证不出现「双方同时退让到同一位置」的冲突。故 `∩_i G_i` 前向不变。∎

**定理 5（SCF 硬安全与授权无关性）** CBF 约束 `L_f h+L_g h·u+α(h)≥0` 保证 `h(x(t))≥0`（标准前向不变性），初始 `h(x(0))≥0`。`u=Π_SCF(λu_H+(1−λ)u_A)` 中 λ 只改变 QP 的目标（`u^des`），不改变约束集，故对任意 λ 与任意上游策略，只要 QP 可行则 `x(t)∈G_i`；QP 不可行时 fallback 按定义 204 保持不变集。因此 `safe(π,C_i)=safe(Π_SCF(π),C_i)`。∎

**定理 6（群体认证可靠性）** 由引理 5，CSC 估计误差有界且膨胀后球覆盖真实 φ*（概率 ≥1−α_cons）；由定理 4，契约可组合；由定理 5，SCF 保证硬安全。AIC-Inter 在 ℰ_inter 上采样认证，Hoeffding 给出 `P[ρ_inter^sample > ρ_inter^true + ε] ≤ exp(−2n_certε²/Δ²)`，n_cert=128 时置信度 >99%。合并得 `Valid(J_silk) ⇒ 系统在 ℰ_inter 下不违反 ∩G_i` 的概率 ≥ `1−α_local−α_cons−α_comm−δ_cert`。∎

**命题（WCV-Swarm 保守性）** 因 `Φ_i ⊇ B(φ̂_i,r_i)` 且 `Φ_i` 含邻居/人类可达集，故 `ρ_inter,i ≤ ρ_rob,i`——交互感知裕度必然不大于单机裕度。这不是缺陷而是**正确性**：第 63 轮的 `ρ_rob` 在多机场景中系统性乐观，SILK 把它修正为可执行的下界。∎

**命题（SDT 风险单调性）** 投标 `b_i` 对 `ρ_i` 严格递减（`∂b/∂ρ=−κ_s/ρ²<0`），故安全裕度越高的智能体出价越低、越可能中标；可行投标集过滤 `ρ_i>0` 保证不会把任务分给不安全节点。∎

**命题（群体协调遗憾）** 分布式共识拍卖等价于在时变通讯图上做分布式次梯度下降，混合时间 τ_mix 使每次迭代的有效步长乘以 `1/√τ_mix`；拜占庭节点最多污染 f 个投标，按截尾均值其影响被 `(f/n)δ_byz` 折价；交接失败每次损失 ε_handover。合并得定义 214 的界。∎

## 7. 已知风险

**一句话**：群体智能会把我原本**独立同分布的局部故障变成相关故障**——一旦 SIF 被投毒、共识被 f 个串谋节点（或一个共同的感知盲区）带偏，CSC 会把「错误但一致」的 φ̄ 与 ρ 传播给全体成员，契约图也随之在错误前提上组合，于是每个节点都真诚地相信自己是安全的，而这种**共识性自信恰恰是单点故障的系统级放大**。

**次级风险与缓解**：
1. **共识收敛慢/震荡**：非平稳场景下截尾均值可能来回摆动 → 引入动量项与自适应 γ，设最大共识轮数，超时用本地保守值。
2. **契约图循环依赖**：A 依赖 B、B 依赖 A 导致假设悬空 → 要求无环支撑子图，检测到环时降级为保守让行/安全停。
3. **SCF 频繁不可行**：高密度人群导致 QP 无解 → 提前减速的「安全走廊」规划 + fallback 层级（停 / 后退 / 请求人类接管）。
4. **人类模型过保守**：反应时间包络太大会导致机器人过度保守 → 在线校准 τ_react 的保守分位数，但只允许「收紧」不允许「放松」安全包络。
5. **SIF 声誉系统被长期渗透**：慢速投毒（低幅度、长时间）绕过单次一致性检查 → 滑动窗口一致性 + 来源多样性上限 + 定期与本地几何全量审计。
6. **通讯中断导致证书过期**：`dir_fresh`/`cons_cert` 失效 → 明确降级语义：断连时 `J_silk` 退化为单机 `J_liro`，只执行本地已验证技能，不进入协作区。

**最终一句话**：SILK 的最大风险不是单机失效，而是**共识把错误变成集体确信**——群体越大、越一致，越难在系统内部发现那个被共同继承的偏差。
