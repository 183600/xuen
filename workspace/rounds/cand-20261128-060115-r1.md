### 第 6 轮灵感驱动研究记录（新循环第 1 轮，承接 CADVS-v5）

**灵感词**：UniBot-V1、技能组合

**继承关系**：继承第 5 轮 CADVS-v5（IP-493~496）的「认证的生成式执行（CGE）」：七硬门原样冻结、证书演算与定理 5~8、执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。v5 解决的是「单个轨迹提议器可任意替换、证书边界不变」。本轮补 v5 留下的结构性缺口：**v5 只会认证「一段轨迹」，不会认证「一串技能」**。真实长程任务由技能序列 s₁∘s₂∘…∘sₙ 组成，而 v5 对每段单独铸证、再首尾拼接，是**不健全**的——接缝处的状态不落在下一技能被认证的初始状态域内，价值/记忆/人因门又跨段累积。两个灵感词统一为主题「**认证的技能组合**（Certified Skill Composition, CSC）」，形成 CADVS-v6（IP-497~500）。本轮自律延续 v5：**硬门数量不增**（仍是七门），不把「接缝检查」升格为第八门，而是把组合可行性做成**提议支撑上的前置过滤**（与 v5 的 supp(π) 限制同构），并对七门各做一次「组合提升（compositional lift）」。

**直觉与动机**：

1. **UniBot-V1 → 统一提议器把「轨迹提议」升维为「技能序列提议」，但证书不变性定理照旧成立**。UniBot-V1 是一个跨本体/跨任务的统一 VLA 策略：输入语言/视觉/本体指纹，输出离散**技能 token 序列**加连续参数（每个 token 指向技能库中的一个已铸证技能，参数是该技能的入口条件与目标）。直觉上它像一个「会排菜谱的厨师」：菜（技能）都是验过的，但**菜单（组合）没人验**。关键沿用 v5 定理 6（证书不变性）：提议器换成 UniBot-V1 不改变门；真正新增的对象是**组合算子 ∘** 与**接缝契约**，而不是新门。跨本体带来第二个新问题：不同本体的入口/出口状态语义不同，必须经**归一化边界状态空间 S_norm** 与有界失真适配器 α_e 对接，否则接缝契约在跨本体处静默失配。

2. **技能组合 → 证书从「单点谓词」升级为「带残差的幺半群（graded monoid with residual）」**。直觉：把每个技能的证书想成一张「带接口的通行证」——它不只说「这段安全」，还说「我从什么样的入口进来、能交付出什么样的出口、消耗多少预算、留下什么历史痕迹」。组合 A∘B 能否成立，取决于 A 的出口（在误差腐蚀 δ 后）是否落在 B 的入口∧认证域内。三个结构性事实：
   - **局部门**（覆盖 3DCF、末点 EEK、接缝处物理 BCK）只依赖边界状态与局部轨迹，可逐段闭合——只要接缝状态同时属于两段的认证域。
   - **可加/预算门**（价值 VACK、安全边际 ξ_wrench/ξ_zmp、时间）按资源幺半群组合：成本相加、边际取最小。**组合不创造预算**——长计划不是免费的，由此得到「认证时域 T_cert」。
   - **历史/携带门**（记忆新颖度 n_flow、人因情感 EMA/HICK veto 携带态）按携带态幺半群组合：n_flow 对分解后的计划近似可加（链式分解下 log p 相加），EMA 是仿射可组合的；接缝要求携带摘要落在认证携带集内。
   于是组合健全性可按三类分别证明，而不是笼统地「逐段安全 ⇒ 整体安全」。

3. **组合的工程价值：可结合 + 可增量重认证**。直觉：如果组合算子满足结合律，则层级计划（子任务再分子任务）合法，且改一个后缀只需重算「受影响后缀 + 相邻接缝」，不必全量重铸证。把漂移界写成仿射映射 δ ↦ L·δ + ε，其复合天然结合，于是**误差预算也可增量传播**。这把 v5 的「单轨迹证书缓存」升级为「计划证书 DAG + 接缝证书缓存」。

**关键洞见**：v5 回答「任意单轨迹提议器下证书边界不变」；v6 回答「**证书能否沿组合算子闭合**」。七硬门 kc_evidence_forged_v4 记号与 τ^4 原样冻结；新增的只有：统一技能提议器 π_U（UniBot-V1）、技能契约代数 SCA、组合证书检查器 CCC、计划装配器 EFA-v6。执行集升级为「逐段 ⊆ v5 且整计划通过 Admissible 过滤」：Exec_CADVS-v6 = {P : Admissible(P) ∧ ∀σ∈P, σ∈Exec_v5}，对单技能计划精确退化 v5。**接缝检查不新增门**：它是 Admissible(P) 的前置过滤，等价于进一步收缩提议支撑，故定理 6 与单调收缩保持。

**形式化目标（增量）**：
1. 归一化边界状态 S_norm 与本体适配器 α_e：S_e → S_norm，失真 ‖α_e(s)−α_e(s′)‖ ≤ L_α‖s−s′‖，把 L_α 计入漂移预算。
2. 技能契约 C_σ=(Pre_σ, Post_σ, D_σ, β_σ, h_σ)；组合可行：Post_A∩D_A ⊆ Erode_δ(Pre_B∩D_B)（腐蚀保证鲁棒入口）。
3. 七门三分：局部类 L={3DCF, EEK, BCK_seam}、可加类 A={VACK, ξ 边际, 时间}、携带类 C={LMEM 新颖度, HICK 情感携带}；各自定义组合提升 ⊗_L, ⊗_A, ⊗_C。
4. 漂移仿射复合 Δ_k = D_k∘…∘D_1，D_k(δ)=L_kδ+ε_k；计划可采纳要求 Δ_n ≤ δ_max。
5. 定理 9（组合健全性）、定理 10（结合律与增量重认证）、定理 11（计划 fail-closed 不放大）、定理 12（预算守恒与认证时域）、定理 13（跨本体适配器健全性）。
6. EFA-v6 级联：UniBot-V1 提 K 条计划 → 契约可行剪枝 → 逐段 v5 门（缓存）→ 接缝/漂移/预算检查 → 取 ECS_v6 最大者；全灭则 fail-closed 回退 v5 单技能。
7. ECS_v6 = ECS_v5 · η_comp，η_comp = exp(−漂移预算占用率)·∏ 接缝边际归一。

**本轮最大风险**：**接缝谬误（seam fallacy）**——即使每一段都铸证、每一个接缝都局部匹配，在累积边界误差、未建模的接触模式切换与经验估计的契约/Lipschitz 常数偏乐观的情况下，「逐接缝健全」并不蕴含「整计划健全」，组合证书可能给出一个自洽却全局失真的安全背书。

### IP-498 SCA：技能契约代数与残差证书（离线构建 + 在线 O(1) 组合）

```python
@dataclass(frozen=True)
class SkillContract:
    pre: Any; post: Any; dom: Any          # 边界状态集合（区间/多面体/采样代理）
    beta: tuple                            # (c_val, m_safe, t_exec)
    h: Any                                 # 携带摘要
    lipschitz: float                       # 段对初始边界的 L_σ
    eps: float                             # 段内残差 ε_σ
    L_alpha: float = 1.0                   # 本体适配器失真

@dataclass(frozen=True)
class Affine:
    L: float; eps: float
    def __matmul__(self, o: "Affine") -> "Affine":   # 复合，结合律成立
        return Affine(self.L * o.L, self.L * o.eps + self.eps)

class SkillContractAlgebra:
    def seam_feasible(self, A: SkillContract, B: SkillContract, delta: float) -> bool:
        # 鲁棒入口：A 的出口（含认证域）在 δ 腐蚀后仍落在 B 的入口∧认证域内
        return erode(B.pre & B.dom, delta).issuperset(A.post & A.dom)

    def compose(self, A: SkillContract, B: SkillContract, delta: float) -> SkillContract:
        """三类门组合提升；不新增门，只收紧域与预算"""
        beta = (A.beta[0] + B.beta[0],                 # A 类：成本相加
                min(A.beta[1], B.beta[1]),             # A 类：边际取最小
                A.beta[2] + B.beta[2])
        h = carry_mul(A.h, B.h)                        # C 类：携带幺半群
        drift = Affine(A.lipschitz, A.eps) @ Affine(B.lipschitz, B.eps)
        return SkillContract(
            pre=A.pre, post=B.post,
            dom=A.dom & erode(B.dom, delta),           # L 类：域逐段闭合
            beta=beta, h=h,
            lipschitz=drift.L, eps=drift.eps,
            L_alpha=max(A.L_alpha, B.L_alpha))

    def discharge(self, C: SkillContract, B_val, xi, delta_max, h_cert) -> bool:
        # 预算守恒 + 漂移界 + 携带放电；任一不满足即 fail-closed
        return (C.beta[0] <= B_val and C.beta[1] >= xi
                and C.eps <= delta_max and C.h in h_cert)
```

### IP-499 CCC：组合证书检查器（计划级，秒级；证书 DAG 增量）

```python
@dataclass
class CompositionalCertificateChecker:
    """不新增第八门：Admissible(P) 是提议支撑上的前置过滤，
    等价于对 π_U 的进一步收缩，故定理 6 与单调收缩保持。"""
    sca: SkillContractAlgebra
    v5: Any                         # EvidenceForgingAssemblerV5（逐段门）
    delta_max: float = 0.02

    def check(self, plan: Plan, ctx) -> PlanCert:
        seg_certs = []
        for sigma in plan.tokens:
            # 1) 逐段 v5 七门（缓存 key=(skill_id, boundary_sig, ctx_sig)）
            seg_certs.append(self.v5.certify_segment(sigma, ctx))
        # 2) 接缝契约匹配（含跨本体 α_e 失真）
        for k in range(len(plan.tokens) - 1):
            if not self.sca.seam_feasible(plan.c[k], plan.c[k+1], self.delta_max):
                return PlanCert(False, reason=f'SEAM_MISMATCH@{k}')
        # 3) 仿射漂移传播 + 4) 预算/携带放电
        C = fold(self.sca.compose, plan.c, self.delta_max)
        if not self.sca.discharge(C, ctx.B_val, ctx.xi, self.delta_max, ctx.h_cert):
            return PlanCert(False, reason='BUDGET_OR_DRIFT_OR_CARRY')
        return PlanCert(True, segments=seg_certs, budget=C.beta, drift=C.eps)

    def incremental_recheck(self, plan: Plan, changed_idx: int) -> PlanCert:
        """改一个后缀技能：前缀段证书与 DAG 复用，只重算 changed_idx 之后
        的段、相邻接缝与漂移后缀；成本 O(后缀长度)，而非 O(整计划)"""
        reuse = plan.dag.prefix_certs(changed_idx)     # O(1) 取 DAG 前缀
        return self._recompute_suffix(reuse, plan, changed_idx)
```

### IP-500 EFA-v6：七硬门 + 组合过滤 + 计划级级联

```python
@dataclass
class EvidenceForgingAssemblerV6:
    ustp: UniBotSkillTokenProposer
    sca: SkillContractAlgebra
    ccc: CompositionalCertificateChecker
    v5: Any                              # 单段回退与逐段门

    def select(self, task, obs, embodiment, ctx) -> tuple[bool, Plan | None, str]:
        plans = self.ustp.propose(task, obs, embodiment)         # K 条计划
        plans = [p for p in plans if self.sca.pre_admissible(p)]  # 契约剪枝
        passed = []
        for p in plans:
            cert = self.ccc.check(p, ctx)
            if cert.passed:
                passed.append((p, cert))
        if not passed:
            # fail-closed：回退 v5 单技能（组合不可采纳不代表无解）
            return self.v5.select_singleton(task, obs, ctx)
        best = max(passed, key=lambda pc: self.ecs_v6(pc[0], pc[1], ctx))
        return True, best[0], 'FORGED_CSC'

    def ecs_v6(self, plan, cert, ctx) -> float:
        eta_comp = math.exp(-cert.drift / self.ccc.delta_max)
        eta_comp *= prod(seam_margin(k) for k in cert.seams)
        return self.v5.ecs_v5(...) * eta_comp
```

```
      ──▶ 契约库 + 逐段 v5 证书模板
  适配器校准：跨本体 α_e 的 L_α 上界（对偶采样/一致性回归）──▶ 计入漂移预算

在线准入（异步，秒级）：
  UniBot-V1.propose (契约感知 beam) ──▶ K 条技能 token 计划
      ├─ 契约不可行 ──▶ 剪枝
      └─ 幸存 ──▶ CCC：逐段 v5 门（缓存）→ 接缝匹配 → 漂移/预算/携带放电
             ├─ 全灭 ──▶ fail-closed 回退 v5 单技能
             └─ 通过 ──▶ 取 ECS_v6 最大者 ──▶ 计划证书 DAG

在线执行（1 kHz 环）：
  逐段消费已缓存证书；段间切换前重验接缝边界签名（O(1) 查表）
  执行中边界误差超出 δ_max ──▶ 触发后缀增量重认证 / 安全停机
```

## 4. 正确性论证（增量更新）

### 引理 45（局部类门的接缝闭合）
**陈述**：设局部门谓词只依赖边界状态与局部轨迹段（3DCF 覆盖、EEK 末点、BCK_seam 接缝物理）。若段 A、B 各自在其认证域 D_A、D_B 内通过对应局部门，且接缝状态 s₁ ∈ D_A∩D_B，则拼接段 A·B 通过局部门。
**证明**：局部谓词按段分解为 g(A)∧g(B)∧g_seam(s₁)，三项分别由假设成立。∎

### 引理 46（可加类门的预算幺半群）
**陈述**：价值成本在拼接下相加，安全边际取最小；故 β_{A∘B}=(c_A+c_B, min(m_A,m_B), t_A+t_B) 构成交换幺半群，且**组合不创造预算**：c_{A∘B} ≥ max(c_A,c_B)、m_{A∘B} ≤ min(m_A,m_B)。
**证明**：逐段代价非负可加，边际是逐点下确界。∎

### 引理 47（携带类门与仿射漂移的结合律）
**陈述**：n_flow 在链式分解下按段近似可加（log p(plan) ≈ Σ log p(seg) + 接缝项）；情感 EMA 是仿射可组合的指数加权均值；漂移映射 D(δ)=Lδ+ε 的复合是仿射映射复合，满足结合律：D₃∘(D₂∘D₁)=(D₃∘D₂)∘D₁。
**证明**：EMA 为 (w,x) 上的仿射运算，权重可合并；仿射映射复合即矩阵（1×1）复合，天然结合。∎

### 引理 48（漂移传播界）
**陈述**：若段 k 对初始边界误差的 Lipschitz 常数为 L_k、段内残差为 ε_k，且入口误差为 δ_{k−1}，则出口误差 δ_k ≤ L_k δ_{k−1} + ε_k；故 Δ_n = D_n∘…∘D_1(δ_0)。
**证明**：Lipschitz 定义逐段归纳；跨本体时 L_k 替换为 L_k·L_α。∎

### 定理 9（组合健全性）
**陈述**：若计划 P=σ₁∘…∘σₙ 满足 (C1) 每接缝鲁棒匹配 (Post∩D)⊆Erode_δ(Pre∩D)；(C2) 局部门逐段通过；(C3) Σc_val≤B_val 且 min m_safe≥ξ；(C4) 携带摘要 h∈H_cert；(C5) Δ_n≤δ_max，则拼接轨迹同时通过七门。
**证明**：对 n 归纳。基例为 v5 单段证书。归纳步：由引理 48，第 k+1 段入口误差 ≤δ_k≤δ_max，鲁棒匹配保证其落在认证域内；由引理 45/46/47 三类门分别在拼接下保持；故第 k+1 段及整体通过七门。∎

### 定理 10（结合律与增量重认证）
**陈述**：证书映射 Φ(P)=CertPlan(P) 在组合下是同态：Φ(A∘B)=Φ(A)⊗Φ(B)，且 ⊗ 结合；因此层级计划合法，且修改后缀只需重算「受影响后缀 + 相邻接缝」，成本 O(后缀长度)。
**证明**：关系复合与三类幺半群均结合；仿射漂移复合结合（引理 47）。增量性由 DAG 前缀复用直接得到。∎

### 定理 11（计划 fail-closed 不放大）
**陈述**：Exec_v6 = {P : Admissible(P) ∧ ∀σ∈P, σ∈Exec_v5}；对单技能计划 P=(σ) 精确退化 Exec_v5；组合过滤只收缩提议支撑，不放松任何门，故不存在因组合而被接纳的、原本被 v5 拒绝的段。
**证明**：Admissible 是 ∧ 合取过滤，且每段仍须过 v5 七门；由定理 6（提议无关性），边界仅由门决定。∎

### 定理 12（预算守恒与认证时域）
**陈述**：对任意计划，成本单调不减、边际单调不增（引理 46），故存在有限认证时域 T_cert = max{n : Σ_{k≤n} β_k ≤ B 且 Δ_n ≤ δ_max}；超过 T_cert 的计划不可采纳。
**证明**：非负可加预算单调递增；Δ_n 在 L≥1 时单调，L<1 时仍被 ε 累加下界约束；两者共同给出有限上界。∎

### 定理 13（跨本体适配器健全性）
**陈述**：若适配器 α_e 的 Lipschitz 常数上界为 L_α，且契约匹配在 S_norm 上以鲁棒半径 δ_max 成立，则真实本体空间中的接缝误差 ≤ L_α·δ_max；将 L_α 计入漂移预算后，定理 9 在跨本体组合下仍成立。
**证明**：由 α_e 的 Lipschitz 性与引理 48，把 L_k 替换为 L_k·L_α。∎

**诚实边界**：(i) 契约 (Pre,Post,D,L,ε) 由采样/区间估计，非精确证明，可能偏乐观；(ii) 携带抽象是有损的，未建模的接触图突变、物体形变会逃出 h 的表示，此时**逐接缝健全不蕴含全局健全**；(iii) 组合过滤是保守的，会拒绝一些实际可行的计划（完备性缺口），只能靠技能库补「过渡微技能」缓解。

## 7. 本轮最大风险（最终确认）

**一句话**：**接缝谬误（seam fallacy）**——即使每段都铸证、每个接缝都局部匹配，在累积边界误差、未建模的接触模式切换与经验估计的契约/Lipschitz 常数偏乐观的情况下，「逐接缝健全」并不蕴含「整计划健全」，组合证书可能给出一个自洽却全局失真的安全背书。
