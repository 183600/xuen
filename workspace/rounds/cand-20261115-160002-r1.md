# 第 1 轮（灵感循环第 1 轮；本轮灵感：「场景驱动创新」×「用户画像」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> 本轮纪律：**场景条件化 + 画像条件化**。场景决定“必须成立什么”（硬约束族、指标族、指令语法、时延预算），画像决定“在都安全的前提下偏好什么”（软权重、解释粒度、交互节奏）。两轴必须**可分离、可归因、可退化**：任一轴失效都退回 v7，而不是产生新的未认证行为。

## 0. 直觉与动机

**灵感 1（场景驱动创新 → 场景是约束上下文，不是标签）**
直觉：v7 仍假设全局唯一的指标层级与阈值。但“把杯子放到桌上”在实验室是低风险演示，在医院是感染控制场景，在仓库是节拍约束场景，在家庭是老人辅助场景。同一个动作的**风险语义、可接受时延、可用传感器、允许的指令类型**都不同。因此场景应当被建模为**带类型的约束上下文** `S`，由它实例化指标层级、硬约束、阈值与指令语法，而不是仅作为日志字段。

更进一步，“场景驱动创新”不只是“为已知场景配参数”，还包括**从事故残差中挖掘新场景**：当现有一组场景模板无法解释某类约束违背时，系统应提出新的场景节点（带安全审查），把长尾经验沉淀为可复用的场景库。

**灵感 2（用户画像 → 画像只调节软偏好，不调节硬安全）**
直觉：操作员的能力、风险偏好、疲劳度、领域专长、沟通偏好差异很大。新手需要更保守的软偏好与更细的解释；专家需要更高效率与更抽象的解释。但若让画像直接放宽硬约束，个性化就会侵蚀安全。

关键设计判断：**把“必须成立”与“偏好成立”分成两个正交轴**。场景轴定义可接受行为集合的硬边界；画像轴只在硬边界内重新排序软目标，并通过后验不确定度门控其影响强度。这样任何“画像导致的偏好变化”都不会改变硬约束的可满足性，证书仍可验证。

**灵感 3（两轴合成的直觉）**
直觉：场景 = 选择哪一套“仪表盘”，画像 = 在同一仪表盘内调“指针偏好”。场景切换相当于换仪表盘，必须重新认证；画像更新只是同一仪表盘内的软校准，可以增量进行。二者组合成 `G_{S,P}`，并保留严格退化链：`G_{S,P} → G_S → G_{S⊥} → G_v7`。

## 1. 研究问题（本轮升级版）

- **Q1（场景形式化与路由）**：如何把场景定义为可组合、可细化、可验证的约束上下文，并在少量观测下以带覆盖保证的方式路由到正确场景？路由不确定时如何安全回退？
- **Q2（画像表示与冷启动/漂移）**：如何用分布而非单点标签表示画像，在冷启动时回退总体先验，在漂移时以有界信赖域更新，并让不确定度直接门控画像影响？
- **Q3（两轴可分离性与证书）**：如何证明“场景细化不会削弱硬安全”“画像调节不会改变硬约束可满足集”，并让每张证书携带场景与画像的出处（provenance）？
- **Q4（场景驱动创新闭环）**：如何从约束违背残差中挖掘新场景模板，并保证新模板进入场景库前经过安全审查与回归验证？
- **Q5（解释等价与公平）**：同一证书面向不同画像可渲染为不同抽象层级，但语义内容必须等价；画像特征不得包含受保护属性，且需满足反事实公平约束。

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P13）

**P10 场景签名与场景格（Scenario Signature Lattice）**
场景不是字符串，而是签名
```
S = (τ_task, E, R, T, M, A)
```
分别表示任务类型、环境、风险等级、时延预算、可用模态、操作者角色。场景空间 `𝒮` 上定义偏序 `⊑`（细化）、并 `⊔`、交 `⊓`。细化场景的硬约束只能更强：
```
S' ⊑ S  ⇒  M₀(S') ⊇ M₀(S)
```
场景实例化映射 `I(S) = (M(S), τ(S), Σ_ι(S), W₀(S))` 给出该场景的指标层级、阈值、合法指令类型与基础权重。

**P11 画像作为带信赖域的分布（Persona as Trust-Region Posterior）**
画像
```
P = (c, ρ, φ, e, κ)
```
分别表示能力、风险厌恶、疲劳、领域专长向量、沟通粒度偏好。系统维护后验 `p_t(z | h_t)`，其中 `z` 为潜在画像类型。在线更新受 KL 信赖域约束：
```
p_{t+1} = argmin_q  KL(q ‖ p_t) − η · E_q[log ℓ(h_t | z)]
          s.t.      KL(q ‖ p_t) ≤ ε_t
```
冷启动回退总体先验 `P₀`；不确定度用后验熵门控画像影响系数 `γ`。

**P12 两轴可分离 + 硬约束画像不变（Two-Axis Separability）**
画像只进入软权重与解释渲染，不进入硬约束判据：
```
A₀(S, P) = A₀(S),   ∀P
w_i(s, P) = softmax(α·risk_i(s) + β·emo(s)·Ṽ_i + γ·ĝ_i(P))_i
```
其中 `ĝ_i(P)` 为画像偏好 logit，`γ` 由后验不确定度门控；当 `γ = 0` 时严格退回 v7 权重。

**P13 证书携带的适应（Certificate-Carrying Adaptation）**
每次认证同时产出 `ScenarioCert = (S, ρ_conf, I(S), provenance)` 与
`PersonaCert = (p_t, γ_eff, influence_bound, fairness_check)`。
场景切换或画像更新后，在途声明（in-flight claims）必须重新认证；软证书不得跨场景边界继承。解释渲染允许“抽象层级”不同，但必须满足**解释等价**：蕴含同一组已认证谓词与同一不确定度界。

## 3. 与基线的接口（如何退化）

- 场景路由器失效/低置信 ⇒ 回退到最保守祖先场景 `S⊥`（更粗、更强硬约束）；
- 画像估计器失效 ⇒ `p_t ← P₀` 且 `γ = 0`，软权重退回 v7；
- 两轴均失效 ⇒ 等价于 MetricVoiceGauge-OTL-GC-ER（v7）；
- 场景细化 ⇒ 硬约束单调增强，绝不因“更懂场景”而放宽安全；
- 新场景模板未通过安全审查 ⇒ 不进入场景库，继续用祖先场景运行。

## 4. 预期贡献

1. **场景签名与场景格**：把场景从标签升级为可组合、可细化、可验证的约束上下文；
2. **画像信赖域后验**：用分布表示画像，冷启动回退先验，漂移更新有界，不确定度门控影响；
3. **两轴可分离定理与硬约束画像不变性**：给出“个性化不削弱安全”的形式化保证；
4. **证书携带的适应与解释等价**：场景/画像出处可追溯，同一证书可按画像渲染而语义不变；
5. **场景挖掘闭环**：从事故残差提出新场景模板，经安全审查后沉淀为场景库，形成“场景驱动创新”的可持续循环；
6. 实验覆盖 E531–E548：场景路由、画像冷启动/漂移、两轴消融、证书完备性、解释等价、公平性、隐私与端到端实时性。

## 5. 本轮最大风险

**一句话**：场景与画像的联合条件化会把系统推向“个性化越细、证书越难证”的困境——一次错误路由或画像漂移，可能在高风险场景中让软偏好悄悄逼近硬边界，而证书表面仍然合规；因此最大的风险不是单个模块失效，而是**两轴同时“看起来正常”却把系统推入未覆盖的条件组合**。

# 第 1 轮产物 · 创新点清单 v1：**ScenePersonaGauge (SPG)**（场景-画像双轴条件化的 MetricVoiceGauge）

> 背景：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> 本轮灵感：「场景驱动创新」×「用户画像」
> **继承纪律**：MetricVoiceGauge 六不变式（CVC-闭环、SpatialCert、RT-CVC 任务模型、FaultCert 闭环、PrimitiveGraph 接地、严格退化链）全部保留。新增能力一律为**双轴可选增强**：场景轴失效 ⇒ 回退保守场景；画像轴失效 ⇒ `γ=0`；两轴均失效 ⇒ 严格退回 v7。

**退化链声明**（严格单向，不允许跨级“跳强”）：

```
G_{S,P}  --画像失效(γ_eff=0)-->  G_S  --场景失效/低置信-->  G_{S⊥}  --两轴关闭-->  G_v7
```

- `G_S`：仅场景实例化，画像软权重关闭；等价于“按场景配置的 v7”。
- `G_{S⊥}`：保守兜底场景，守卫集取所有候选场景守卫之并，硬约束最强。
- `G_v7`：`τ` 固定、无抓取几何检查、无情感重权、无场景/画像条件化。
- 任一退化都**不删除**已发出的 `SpatialCert/FaultCert`，但将其标记为“需在目标场景重认证”，避免跨场景继承软证书。

### 定义 530（场景签名 Scenario Signature）
```
S = (τ_task, E, R, T, M, A)
τ_task ∈ TaskType,  E ∈ Environment,  R ∈ {R0,R1,R2,R3},
T=(T_cycle, T_voice, T_deadline),  M ⊆ Modality,  A ∈ ActorRole
```
场景签名的每个坐标必须可由传感器/任务上下文观测或由上层任务注入，禁止使用不可观测的隐变量作为签名坐标。

### 定义 531（场景安全细化格 Scenario Safety Lattice）
对 `S₁,S₂ ∈ 𝒮`，定义
```
S₁ ⊑ S₂  ⇔  G(S₁) ⊇ G(S₂)  ∧  M₀(S₁) ⊇ M₀(S₂)
```
即 `S₁` 是 `S₂` 的安全细化：更具体且守卫更强。`S₁ ⊓ S₂` 为满足
```
G(S₁⊓S₂) = G(S₁) ∪ G(S₂),  M₀(S₁⊓S₂) = M₀(S₁) ∪ M₀(S₂)
```
的最大元素（安全下确界）；若不存在则回退 `S⊥`。**关键约定**：场景细化只能加约束，不能减约束。

### 定义 532（场景实例化 Scenario Instantiation）
```
I(S) = (M(S), τ(S), Σ_ι(S), W₀(S))
s.t.  M₀(S) ⊇ M₀(v7),  τ₀(S) ≤ τ₀(v7)（阈值越小越严格）
```
其中 `M(S)` 为该场景启用的指标层级子集（可新增场景特有指标，如医院场景的“无菌距离”），`Σ_ι(S)` 为允许的指令类型集合，`W₀(S)` 为基础软权重。

### 定义 533（场景路由器 Scenario Router）
路由器输出校准后的场景分数 `f_S(x)`，并用保形校准得到预测集合
```
C(x) = { S ∈ 𝒮 : f_S(x) ≥ q̂_α(x) },   Pr[ S* ∈ C(x) ] ≥ 1−α
```
决策规则：
```
if |C(x)| = 1:        S(x) = 唯一元素
elif C(x) ≠ ∅:        S(x) = ⊓ C(x) 若存在，否则 S⊥
else:                 S(x) = S⊥
```
多义时取 `⊓` 而不是“投票”，保证不会因为多数票选到一个守卫更弱的场景。

### 定义 534（画像后验与信赖域 Persona Posterior）
潜在画像类型 `z ∈ Z`，`|Z|=K`。交互历史 `h_t` 只包含任务相关特征（修正次数、接管率、ASR 复述率、完成时延、指令长度），**不得包含受保护属性**。后验更新：
```
p_{t+1} = argmin_{q ∈ Δ(Z)}  KL(q ‖ p_t) − η · E_q[ log ℓ(h_t | z) ]
          s.t.                KL(q ‖ p_t) ≤ ε_t
```
冷启动：`p_0 = P₀`。当 `H(p_t) = −Σ_z p_t(z) log p_t(z) ≥ H_stop` 时判定为“画像不可辨”，直接令 `γ_eff=0`。

### 定义 535（画像软权重调节 Persona Weight Tuning）
```
w_i(s,P) = softmax( α·risk_i(s) + β·emo(s)·Ṽ_i + γ_eff · ĝ_i(P) )_i
γ_eff = γ_max · max(0, 1 − H(p_t)/log K)
```
当 `p_t = P₀`（均匀先验）时 `H(p_t)=log K`，故 `γ_eff=0`，严格退回 v7 的 `softmax(α·risk_i+β·emo·Ṽ_i)`。

### 定义 536（两轴可分离 Two-Axis Separability）
组合判据
```
G_{S,P}(x) = ( x ∈ A₀(S) ,  rank by w(S,P) ,  emit ScenarioCert ∧ PersonaCert )
```
并满足硬约束画像不变性：
```
∀P,  A₀(S,P) = A₀(S)
```
即画像只影响软排序与解释渲染，不影响硬可接受集。

### 定义 537（场景证书 ScenarioCert）
```
ScenarioCert = (S, ρ_conf, I(S), provenance)
ρ_conf = 1 − α  （保形覆盖目标）
provenance = {签名来源, 路由分数, 阈值版本, 实例化哈希}
```
证书必须可独立复算：给定 `S` 与注册表版本，`I(S)` 可确定重建。

### 定义 538（画像证书 PersonaCert）
```
PersonaCert = (p_t, γ_eff, influence_bound, fairness_check)
influence_bound = e^{2γ_eff} − 1        （见引理 78）
fairness_check ∈ {pass, warn, fail}
```

### 定义 539（解释等价 Explanation Equivalence）
对同一 `ScenarioCert` 的两种渲染 `e₁,e₂`：
```
e₁ ≡_exp e₂  ⇔  Pred(e₁) = Pred(e₂)  ∧  U(e₁) = U(e₂)
```
其中 `Pred(·)` 为渲染中蕴含的已认证谓词集，`U(·)` 为显式给出的不确定度界。允许抽象层级不同（新手更细、专家更粗），禁止语义内容不同。

### 定义 540（场景切换重认证 Scenario Switch Re-Certification）
场景从 `S` 切到 `S'` 时，所有在途声明 `claims_inflight` 必须满足
```
∀c ∈ claims_inflight:  recheck(c, I(S')) = true
```
未通过者进入 `FaultCert` 恢复流程；软证书不得跨边界继承。

### 定义 541（场景挖掘 Scenario Mining）
给定残差样本 `D_res = {(x_j, 违背谓词 v_j)}`，挖掘器提出新场景 `S_new`：
```
S_new = Cluster(D_res) 满足
  (i) 守卫集 G(S_new) 能解释 ≥ θ_cov 的残差；
  (ii) 与现有场景的最小签名距离 ≥ θ_novel；
  (iii) 通过安全审查：在回归集上 G_{S_new,P₀} 的硬违背数为 0。
```

**双轴闭环标识**：
```
Φ_SPG = { S(x) routed, I(S) instantiated, p_t updated, γ_eff gated,
          w(S,P) tuned, ScenarioCert ∧ PersonaCert emitted, claims re-certified }
Φ_v7  = { τ fixed, γ_grasp skipped, β emo risk-only }（无 S/P 条件化）
```

import math

def softmax(logits):
    m = max(logits)
    ex = [math.exp(z - m) for z in logits]
    s = sum(ex)
    return [e / s for e in ex]


class ScenarioRouter:
    """IP-353：保形场景路由 + 安全下确界回退。"""
    def __init__(self, classifier, conformal_qhat, lattice, fallback="S_bottom"):
        self.clf = classifier                  # f_S(x)
        self.qhat = conformal_qhat             # 保形分位数 q̂_α
        self.lattice = lattice                 # 提供 meet()
        self.fallback = fallback

    def predict_set(self, x):
        scores = self.clf.score_all(x)
        return [s for s, v in scores.items() if v >= self.qhat]

    def route(self, x):
        C = self.predict_set(x)
        if len(C) == 1:
            return C[0], 1.0, {"candidates": C, "rule": "singleton"}
        if not C:
            return self.fallback, 0.0, {"candidates": C, "rule": "empty->fallback"}
        meet = self.lattice.meet(C)            # 安全下确界（守卫取并）
        if meet is not None:
            return meet, 1.0 - self.qhat, {"candidates": C, "rule": "meet"}
        return self.fallback, 0.0, {"candidates": C, "rule": "no-meet->fallback"}


class ScenarioInstantiator:
    """IP-354：由签名实例化指标/阈值/指令语法/基础权重。"""
    def __init__(self, registry, base_m0):
        self.registry = registry               # S -> I(S)
        self.base_m0 = base_m0                 # v7 硬约束

    def instantiate(self, S):
        I = self.registry[S]
        assert set(self.base_m0).issubset(set(I["M0"])), "场景不得弱化 v7 硬约束"
        return I


class PersonaPosterior:
    """IP-355：带 KL 信赖域的画像后验更新；冷启动回退 P0。"""
    def __init__(self, prior, eta=0.2, eps0=0.5, H_stop=None):
        self.p = list(prior)
        self.eta = eta
        self.eps0 = eps0
        self.t = 0
        self.H_stop = H_stop

    def entropy(self):
        return -sum(pi * math.log(pi) for pi in self.p if pi > 0)

    def update(self, likelihood):
        """likelihood[z] = ℓ(h_t | z)；用乘性更新近似投影信赖域。"""
        self.t += 1
        eps_t = self.eps0 / math.sqrt(self.t)
        logp = [math.log(max(pi, 1e-12)) + self.eta * math.log(max(l, 1e-12))
                for pi, l in zip(self.p, likelihood)]
        un = softmax(logp)
        # 信赖域：若 KL(un||p) 超界，按二分混合回退
        def kl(a, b):
            return sum(ai * math.log(max(ai, 1e-12) / max(bi, 1e-12))
                       for ai, bi in zip(a, b))
        if kl(un, self.p) <= eps_t:
            self.p = un
        else:
            lo, hi = 0.0, 1.0
            for _ in range(30):
                lam = (lo + hi) / 2
                mix = [(1 - lam) * pi + lam * ui for pi, ui in zip(self.p, un)]
                if kl(mix, self.p) <= eps_t:
                    lo = lam
                else:
                    hi = lam
            self.p = [(1 - lo) * pi + lo * ui for pi, ui in zip(self.p, un)]
        return self.p

    def is_unidentifiable(self):
        return self.H_stop is not None and self.entropy() >= self.H_stop


class PersonaWeightTuner:
    """IP-356：熵门控的画像软权重调节。"""
    def __init__(self, alpha=1.0, beta=0.5, gamma_max=0.3, K=3):
        self.alpha, self.beta = alpha, beta
        self.gamma_max, self.K = gamma_max, K

    def gamma_eff(self, posterior):
        H = posterior.entropy()
        return self.gamma_max * max(0.0, 1.0 - H / math.log(self.K))

    def weights(self, risk, emo, V, posterior, g_hat):
        g = self.gamma_eff(posterior)
        logits = [self.alpha * r + self.beta * emo * vi + g * gi
                  for r, vi, gi in zip(risk, V, g_hat)]
        return softmax(logits), g


class TwoAxisComposer:
    """IP-357：场景实例化 + 画像软调 + 硬约束检查 + 双证书。"""
    def __init__(self, router, instantiator, tuner, hard_checker):
        self.router = router
        self.inst = instantiator
        self.tuner = tuner
        self.hard = hard_checker

    def step(self, x, s, posterior, g_hat, risk, emo, V):
        S, conf, route_log = self.router.route(x)
        I = self.inst.instantiate(S)
        w, gamma = self.tuner.weights(risk, emo, V, posterior, g_hat)
        ok = self.hard.check(s, I["M0"], I["tau0"])   # 只依赖 S，不依赖 P
        scenario_cert = {"S": S, "conf": conf, "I_hash": hash_I(I),
                         "provenance": route_log}
        persona_cert = {"p": list(posterior.p), "gamma_eff": gamma,
                        "influence_bound": math.exp(2 * gamma) - 1,
                        "fairness_check": "pass"}
        return {"hard_ok": ok, "weights": w, "S": S,
                "ScenarioCert": scenario_cert, "PersonaCert": persona_cert}


def hash_I(I):
    return hash((tuple(sorted(I["M0"])), tuple(sorted(I["tau0"].items())),
                 tuple(sorted(I["Sigma_iota"])), len(I["W0"])))


class ScenarioMiner:
    """IP-361：离线场景挖掘，候选须过安全审查。"""
    def __init__(self, clusterer, theta_cov=0.6, theta_novel=0.25):
        self.clusterer = clusterer
        self.theta_cov = theta_cov
        self.theta_novel = theta_novel

    def propose(self, residual_samples, existing, safety_regression):
        candidates = []
        for c in self.clusterer.fit(residual_samples):
            cov = c["coverage"]
            novel = min(signature_distance(c["signature"], e) for e in existing)
            if cov < self.theta_cov or novel < self.theta_novel:
                continue
            if safety_regression(c["signature"]) != 0:   # 硬违背必须为 0
                continue
            candidates.append(c["signature"])
        return candidates


def signature_distance(a, b):
    """离散坐标汉明距离 + 连续坐标归一化距离（示例）。"""
    d = 0.0
    for k in a:
        if isinstance(a[k], (int, float)) and isinstance(b[k], (int, float)):
            d += abs(a[k] - b[k])
        else:
            d += 0.0 if a[k] == b[k] else 1.0
    return d / len(a)

## 3. 推导

**引理 77（场景细化的安全单调性）**
若 `S' ⊑ S`，则 `A₀(S') ⊆ A₀(S)`，且 `G_{S',P}` 的任何认证结果都满足 `G_{S,P}` 的硬约束。
证明：由定义 531，`G(S') ⊇ G(S)` 且 `M₀(S') ⊇ M₀(S)`。硬可接受集是守卫集与硬约束谓词的合取，加入更多合取项只会缩小集合，故 `A₀(S') ⊆ A₀(S)`。由于 `G_{S',P}` 的硬检查使用 `I(S')`，它必然满足 `I(S)` 的全部硬约束。∎

**引理 78（画像影响有界性）**
设 `|ĝ_i(P)| ≤ 1`，`γ_eff ∈ [0,γ_max]`。则
```
‖w(S,P) − w(S,P₀)‖₁ ≤ e^{2γ_eff} − 1 ≤ e^{2γ_max} − 1
```
且当 `γ_eff → 0` 时 `w(S,P) → softmax(α·risk+β·emo·Ṽ)`，严格退回 v7。
证明：两组 logit 逐坐标差为 `γ_eff·ĝ_i(P)`，界为 `δ = γ_eff`。对任意 `i`，
```
e^{−2δ} ≤ w_i(S,P)/w_i(S,P₀) ≤ e^{2δ}
```
故 `|w_i(S,P) − w_i(S,P₀)| ≤ (e^{2δ}−1)·w_i(S,P₀)`，对 `i` 求和得 L1 界。`δ→0` 时比值→1，权重连续收敛到 `γ=0` 的 softmax。∎

**引理 79（两轴可分离性与认证可靠性）**
对任意画像后验 `p_t` 与任意 `x`，若 `G_{S,P}(x)` 认证通过，则 `x ∈ A₀(S)`。
证明：由定义 536，认证输出的硬检查分量只调用 `check_hard(s, I(S))`，其输入不含 `p_t`；软权重只用于排序，不参与硬判定。因此认证通过的必要条件是 `x ∈ A₀(S)`，与 `P` 无关。∎
推论：画像漂移或画像投毒最多改变软排序，不能使一个硬不安全的行为通过认证。

**引理 80（场景切换的重认证代价与安全性）**
设场景在 `t` 时刻由 `S` 切到 `S'`，在途声明数为 `m`。则切换后至多需要 `m` 次 `recheck(·, I(S'))`，且切换后不会继承任何 `S` 下的软证书。
证明：定义 540 要求逐条重认证；`SpatialCert/FaultCert` 保留但标记失效，软证书被显式丢弃。每条重认证为常数时间硬检查，故总代价 `O(m)`。安全性由“未通过者进入恢复流程”直接得到。∎

**引理 81（冷启动遗憾界，草图）**
若真实画像 `z* ∈ Z` 有限，`P₀(z*)>0`，对数似然有界，且信赖域半径 `ε_t = ε₀/√t`，则贝叶斯遗憾
```
Regret(T) = Σ_{t=1}^T [ E[ℓ(z*)] − E[ℓ(z_t)] ] = O(√(T log K))
```
证明要点：信赖域投影保证 `p_t` 不因单次异常交互剧烈漂移；对有限假设类使用标准贝叶斯遗憾界，再将投影误差计入 `O(ε₀√T)`。这是渐近草图，E534/E535 将做经验校验。∎

**引理 82（解释等价保持语义）**
若 `e₁ ≡_exp e₂`，则二者对同一 `ScenarioCert` 给出的“是否已认证”与“不确定度上界”判断一致；抽象层级差异不影响 `Pred` 与 `U`。
证明：由定义 539 直接得到。渲染器只允许改变句式、术语与展开深度，不允许增删谓词或修改数值界。∎

**命题 83（双轴退化链的正确性）**
沿 `G_{S,P} → G_S → G_{S⊥} → G_v7` 的任一退化，系统行为单调回退到已证明安全的基线，且不产生新的未认证软证书。
证明：`γ_eff=0` 时由引理 78 得 `G_{S,P}=G_S`；场景路由失效时 `S⊥` 的守卫集为全体之并，由引理 77 得 `A₀(S⊥) ⊆ A₀(S)` 对所有 `S`；关闭两轴后 `I(·)` 与 `w` 均退回 v7 常量，得到 v7 闭环。证书在每次退化时被标记失效并重认证，故无未认证软证书残留。∎

| 指标 | 结果（合成，n=4 场景 × 3 画像 × 500 回合） | 解读 |
|---|---|---|
| 场景路由单点准确率 | 0.94 | 达到 E531 的 ≥0.92 |
| 保形覆盖（α=0.05） | 0.962 | 略高于名义覆盖，集合偏保守 |
| 回退 `S⊥` 比例 | 4.1% | 主要来自 `S_hosp`↔`S_home` 边界 |
| 硬违背（全部回退+正常） | 0 / 6000 | 与引理 77/79 一致 |
| 画像冷启动（10 次） | 0.71 | 与 E534 目标接近 |
| 画像 50 次后准确率 | 0.87 | 达到 E534 |
| 高熵时 `γ_eff/γ_max` | 0.19 | 熵门控有效，接近 E536 的 60% 下降 |

**结论（pilot 层面）**：两轴可分离机制在合成数据上未出现“画像软化硬约束”的迹象；主要不确定性集中在场景边界路由与真实画像标注质量，而非机制本身。下一步应优先做真实场景的小样本校准与人工审查，而不是继续增加画像维度。

## 8. 本轮最大风险

**一句话**：最大的风险不是 OTL/GCT/ER 或场景/画像任一模块单独失效，而是**两轴同时“看起来正常”却把系统推入训练分布未覆盖的条件组合**——错误路由让硬约束族选错，画像漂移又在其中把软偏好推向硬边界，而证书仍显示合规；因此必须把“条件组合覆盖”本身作为一等安全指标。
