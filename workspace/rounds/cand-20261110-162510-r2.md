# 第 47 轮（承接第 46 轮 v23；本轮灵感：共享控制 × 个性化交互） · Authority-Certificate-Persona：权威分配下的可证书共享控制与个性化交互（架构 v11）

> 承接第 46 轮 v23 的 MVR × VAD × SAB 全局决策 Π。v23 把记忆、语音、安全绑定合为一体，却隐含假设 H5：决策主体只有"自主"一个，人的介入是整句指令式的二值门控；且默认所有用户同质，共用同一 θ_safe 与同一交互方式。UniBot 实机中，同一台机器要在精细装配（专家遥操作示教）、老人/儿童陪护（新手、低反应速度）、多语言访客等场景间切换，用户技能、反应延迟、风险偏好、信任校准差异极大：纯自主牺牲效率与人的意图，纯遥操作丢失证书保证。两个灵感词精确命中 H5：**共享控制**要求把控制权威 α_t 从开关升级为连续可分配量，使人的意图与自主的证书在同一控制回路中混合；**个性化交互**要求用用户模型 u_t 参数化权威曲线、安全阈值与交互模态。二者耦合出核心问题：**人一旦获得权威，姿态证书只约束机器人自身位姿、不约束人的动作；若用户模型误判导致权威过度下放，B(v,P) 与 P_t 会在"人的动作"这一新维度上静默失效，并绕过 v23 的全部安全队列**。

## 0. 直觉与动机

**灵感 1（共享控制 → 连续权威与责任配比）**
直觉：权威不是开关，而是责任配比。定义 α_t∈[0,1] 为人获得的控制权威，混合指令 x_t=α_t·x_t^H+(1-α_t)·x_t^R。v23 的 B(v_t,P_t) 二值门控被升级为连续仲裁：P_t 越宽（位姿越不确定）越应回收权威；P_t 越窄且用户越熟练越可下放。关键约束是权威限速——手交接的瞬间若 α 跳变，证书会在一个控制周期内断裂，因此 |α_{t+1}-α_t|≤Δα_max，并配合滞回避免边界抖动。

**灵感 2（个性化交互 → 用户模型参数化安全曲线）**
直觉：同一个 θ_safe 对专家与新手既不效率也不安全。用 u_t=(技能 s、反应延迟 τ、风险偏好 ρ、信任校准 κ、交互偏好 π) 参数化 θ_safe(u)、α_max(u)、确认频率与模态。个性化不是"为讨喜而降低标准"，而是在用户分群上重新校准覆盖率：用分群（Mondrian）条件共形，使每个用户群的经验覆盖仍 ≥1-α_p，而不是让乐观样本抬高全体均值。

**灵感 3（耦合 → 权威-证书联合对象与人因有界扰动）**
直觉：人一旦获得 α，其动作是自主无法完全预测的扰动。把人的偏差上界 δ_h(u)=ρ(c0+c1τ+c2(1-s)) 作为有界扰动注入证书半径；只有当"剩余自主权威 × 纠偏能力 ≥ α × 人因扰动界"（权威裕度 M_a≥0）时，权威条件证书才 sound。当人的指令越过安全集时，不用简单拒绝（那会破坏共驾手感），而用控制屏障式安全过滤器把指令投影回 A_safe，并同步用交互通道解释"为什么被修正"。

**耦合升级**：在 v10/v23 四层之上新增 **权威-个性化层（APL）**。APS 输出 α_t 与用户模型 u_t；ACC 签发 P_t(α,u)；PXL 决定交互模态与确认等级；PDA 做个性化漂移审计。四层 v11：根信任层增加"权威租约"ℓ_α 与用户模型版本；L1 几何层证书按 (α,u) 条件化；L2 上下文/记忆按用户分区检索；L3 CAR 守卫加入权威裕度 M_a≥0；L4 DCL 采集用户特异退化样本。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（用户模型与个性化状态）**
u_t=(s_t,τ_t,ρ_t,κ_t,π_t)∈U：s∈[0,1] 技能，τ>0 反应延迟(s)，ρ∈[0,1] 风险偏好，κ∈ℝ 信任校准偏差（正=过度信任），π 交互偏好（模态/语言/确认频率）。后验 p(u_t|H_t) 由交互历史 H_t 在线更新，且携带不确定度 Var(u_t)。

**定义 60（共享控制权威分配）**
α_t∈[0,1]，混合指令 x_t=α_t·x_t^H+(1-α_t)·x_t^R。权威动力学
α_{t+1}=clip(A(u_t,P_t,ℓ_e,c_t), α_t-Δα_max, α_t+Δα_max)。
三档语义：自主 α≤α_low；辅助 α_low<α<α_high；遥操作 α≥α_high。仲裁函数 A 以"任务收益 / 证书宽度 / 用户能力"为输入，单调于 P_t 宽度递减、于 s_t 递增。

**定义 61（人因扰动界与权威裕度）**
δ_h(u)=ρ·(c0+c1·τ+c2·(1-s))，c_i≥0 由用户标定集拟合；corr_cap(P_t)>0 为剩余自主权威的纠偏能力。权威裕度
M_a(t)=(1-α_t)·corr_cap(P_t) − α_t·δ_h(u_t)。
**权威可行判据**：M_a(t)≥0 且 α_t≤α_max(u_t)。任一不满足，则权威条件证书失效，必须收权或扩半径。

**定义 62（权威条件姿态证书 ACC）**
P_t(α,u)，联合 soundness：
P(X_t∈P_t(α_t,u_t) | ω_t, m_t, ℓ_e, α_t, u_t) ≥ 1−α_p，仅当 M_a(t)≥0；
且按用户分群 g=user_group(u) 做 Mondrian 条件共形，使每个群经验覆盖 ≥1−α_p。
半径膨胀 rad(P_t(α,u))=rad(P_t^R)+α_t·δ_h(u_t)。若给定 α 下 rad>R_max(φ)，则权威不可行，返回空证书并要求降低 α。

**定义 63（安全权威集、安全过滤器与个性化交互策略）**
A_adm(P_t,u)={α: rad(P_t^R)+α·δ_h(u)≤R_max(φ)}。
给定人指令 x^H，安全过滤器
x_t^safe=argmin_{x∈A_safe(P_t,u)} ‖x−x^H‖，A_safe={x: B(x,P_t)≥θ_safe(u)}；
当 x^H∉A_safe 时记为 override，并抬升确认等级。
个性化交互策略 π_int(a|u_t,c_t,e_t)，确认等级随 |Δα|、Var(u_t)、近期 override 率单调上升；个性化漂移审计量 D(u_t)=KL(p(u_t|H_t)‖p_pop)+Mahalanobis(u_t,U_pop)。

## 3. 算法骨架

APS 每控制周期：
1. 由 H_t 更新 p(u_t|H_t) 与 Var(u_t)（贝叶斯/在线分群）
2. 读 P_t^R、ℓ_e、上下文 c_t、近期 override 率
3. 由 δ_h(u)、R_max 计算 α_max 与当前可行权威集 A_adm
4. 求期望权威 α^des=A(u,P_t,ℓ_e,c_t)，投影到 A_adm 并限速：α_t
5. 校验 M_a(t)≥0；否则按 Δα_step 收权直至可行，仍不可行则 fail-closed
6. 对人指令做安全过滤，输出 x_t^safe 与 override 标志
7. PXL 依据 |Δα|、Var(u)、override 选模态与确认等级并解释
8. PDA 审计漂移；超阈则冻结个性化、回退群体保守参数
9. ACC 签发 P_t(α,u)，总线广播；CAR 用权威裕度与分群覆盖联合守卫

## 4. 本轮最大风险

**一句话**：个性化会以"用户满意/信任"为名义持续放宽权威上限与安全阈值，把安全边界从群体保守值滑向个体乐观值；一旦用户模型或分群共形校准被少数高技能样本、疲劳状态或对抗交互污染，权威条件证书会在真实的新手/低反应用户上覆盖不足，而 v23 的安全队列因 override 被误判为"已辅助"而不再拦截，形成静默失效；因此必须以分群条件共形守住覆盖率、以 PDA 强制冻结漂移，并在 M_a<0 时无条件收权而非协商。

## 2. 关键算法 伪代码

### IP-69 APS（权威仲裁）
```
def human_deviation(u, c=(c0,c1,c2)):
    return u.rho * (c[0] + c[1]*u.tau + c[2]*(1 - u.s))

def authority_max(P_R, u, R_max, alpha_cap):
    dh = human_deviation(u)
    if dh <= 1e-9:
        return alpha_cap
    return clip((R_max - P_R.radius) / dh, 0.0, alpha_cap)

def authority_margin(P_R, alpha, u):
    return (1 - alpha) * corr_cap(P_R) - alpha * human_deviation(u)

def authority_step(P_R, u, lease_e, ctx, alpha_prev,
                   R_max, alpha_cap, dAlpha_max=0.15, dAlpha_step=0.05):
    a_max = authority_max(P_R, u, R_max, alpha_cap)
    a_des = arbitration_policy(u, ctx, P_R)      # 效率/信任/任务收益
    a = min(a_des, a_max)
    # 限速 + 滞回，避免手交接抖动
    a = clip(a, alpha_prev - dAlpha_max, alpha_prev + dAlpha_max)
    # 权威裕度不足则无条件收权（不可协商）
    while a > 0 and authority_margin(P_R, a, u) < 0:
        a = max(0.0, a - dAlpha_step)
    if a > a_max:
        return None                               # 权威不可行
    return a
```

### IP-70 ACC（权威条件证书 + 分群共形）
```
def inflate_radius(P_R, alpha, u):
    return P_R.radius + alpha * human_deviation(u)

def acc_certify(P_R, alpha, u, calib_by_group, alpha_p, R_max):
    if authority_margin(P_R, alpha, u) < 0:
        return None
    r = inflate_radius(P_R, alpha, u)
    if r > R_max:
        return None
    g = user_group(u)                              # 技能/延迟聚类
    q = conformal_quantile(calib_by_group[g], level=1-alpha_p)  # Mondrian
    return PoseCert(center=P_R.center, radius=max(r, q),
                    group=g, level=1-alpha_p, alpha=alpha, u_ver=u.version)
```

def authority_safety_filter(x_H, P_t, u, theta_safe_fn):
    theta = theta_safe_fn(u)
    if safety_bind(x_H, P_t) >= theta:

def confirm_level(u, alpha, alpha_prev, conf_ctx, override_rate):
    d_alpha = abs(alpha - alpha_prev)
    lvl = base_level(u) + k1*d_alpha + k2*(1-conf_ctx) + k3*override_rate
    return clip(round(lvl), 0, 3)

def choose_modality(u, c_t, override_rate):
    if override_rate > tau_ovr or u.rho > rho_hi:
        return 'haptic+visual_confirm'
    return argmax_a u.pi[a] * utility_modality(a, c_t)

def explain_override(u, x_H, x_safe, P_t):
    # 用用户偏好模态解释“为何被修正”，降低困惑与不信任

                  delta=norm(x_H - x_safe), radius=P_t.radius)

### IP-72 PDA（漂移审计）
```
def personalization_audit(u_post, u_prior, coverage_by_group,
                          alpha_p, D_kl_max, D_ood_max, eps_cal):
    kl = kl_div(u_post, u_prior)
    ood = mahalanobis(u_post, U_pop)
    cal_err = max(abs(c - (1-alpha_p)) for c in coverage_by_group.values())
    if kl > D_kl_max or ood > D_ood_max or cal_err > eps_cal:
        return 'freeze', 'revert_population_conservative'
    return 'ok', None
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |

| APS 权威仲裁 | O(1) + 聚类查找 | O(\|U_pop\|) | 限速 + M_a≥0 ⇒ 交接期证书不断裂 |
| ACC 分群共形 | O(1) 查表 | O(\|G\|·n_g) | Mondrian 条件共形 ⇒ 每群覆盖 ≥1−α_p（有限样本） |
| SAB 安全过滤 | O(d) 投影 | O(1) | x∈A_safe ⇒ B(x,P)≥θ_safe(u) |
| PDA 漂移审计 | O(d²) | O(\|U_pop\|) | 超阈冻结 ⇒ 回退群体保守，阻断漂移累积 |
| 全局 Π_v11 | O(\|M\|+\|G\|) | O(\|Q\|) | 权威/证书/审计三重 fail-closed |

**正确性定理（权威条件覆盖）**：设分群共形在每群 g 上取到分位数 q_g，Mondrian 可交换性成立。若 α_t∈A_adm 且 M_a(t)≥0，则对任意 x_t∈A_safe，有 P(X_t∈P_t(α_t,u_t) | g) ≥ 1−α_p；且权威永远不会超过 α_max(u_t)。若 PDA 判定冻结，则 α_t≤α_pop_max、θ_safe 回退群体值，覆盖保证回到群体保守水平。若 α 不可行或 M_a<0 且收权无效，则 CAR fail-closed，不执行任何混合指令。

**命题（过滤器不放松安全性）**：安全过滤器只会将 x_H 替换为 A_safe 中的最近点，故它单调不降 B(x,P)；代价是引入"辅助修正"而非静默执行，修正量 ‖x_H−x_safe‖ 可作为交互解释与用户学习信号。

## 4. 实验设计 E115–E121

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 权威可行性 | A_adm 非空率、M_a 分布、收权次数 | 可行率 ≥ 95%；收权 ≤ 5%/min |
| E116 交接平滑性 | α 变化率、jerk、交接期证书断裂数 | 证书断裂 0 次；jerk 低于阈值 |
| E117 分群覆盖 | 各用户群经验覆盖率、校准误差 | 每群 ≥ 1−α_p−2%；cal_err ≤ 2% |
| E118 安全过滤器 | 执行安全率、效率损失、override 率 | 安全率 ≥ 99.5%；效率损失 ≤ 10% |
| E119 漂移检测 | 投毒/对抗下 AUC、检测时延 | AUC ≥ 0.9；时延 ≤ 3 个会话 |
| E120 用户研究 | NASA-TLX、信任校准、偏好匹配、成功率 | TLX 降 ≥ 15%；信任校准误差降 ≥ 30% |
| E121 100h 多用户闭环 | 安全违例、记忆分区命中、语音成功率 | 安全违例 0；语音成功率 ≥ 95% |

回退策略：E115 可行率 < 85% → 提高 R_max 或收紧 δ_h 拟合；E117 任一群覆盖不足 → 该群回退群体保守 α_max；E118 效率损失 > 15% → 降低 k3 或改用提示而非强制投影；E119 检测失效 → 关闭个性化，固定群体策略并告警。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 用户模型误估导致权威过度下放 | 高 | 保守先验 + 在线分群共形 + 硬性 α_max/M_a 收权 |
| "个性化放松"悄然突破安全边界 | 高 | 每群独立覆盖率保证；禁止跨群借用乐观样本；审计告警 |
| 权威频繁切换破坏共驾手感 | 中 | 限速 + 滞回 + 交接预告（PXL 提前提示） |
| 用户模型隐私泄露 | 中 | 本地化存储、按用户分区记忆、最小化特征、可删除 |
| 记忆-用户耦合形成回声室/投毒 | 中 | PDA 漂移审计 + 对抗样本 + 跨用户去偏校验 |
| 安全过滤器修正导致困惑/不信任 | 中 | 力反馈/视觉解释 + 可学习修正量 + 确认等级自适应 |
| 分群过细导致共形样本不足 | 中 | 层级分群（粗群→细群），小样本回退上级群分位数 |

## 6. 本轮最大风险

**一句话**：个性化会以"用户满意/信任"为名义持续放宽权威上限与安全阈值，把安全边界从群体保守值滑向个体乐观值；一旦用户模型或分群共形校准被少数高技能样本、疲劳状态或对抗交互污染，权威条件证书会在真实的新手/低反应用户上覆盖不足，而 v23 的安全队列因 override 被误判为"已辅助"而不再拦截，形成静默失效；因此必须以分群条件共形守住覆盖率、以 PDA 强制冻结漂移，并在 M_a<0 时无条件收权而不是协商。
