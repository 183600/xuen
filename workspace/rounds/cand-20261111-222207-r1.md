# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「失败恢复」×「分层规划」）

> 第 54 轮已把技能组合提升为「动作空间剖面 α_S + 鲁棒性谱 ρ + 云边映射 γ_ce」的可判定双证书体系。本轮把问题从“如何组合成功”推进到“失败之后如何在正确的抽象层级被吸收”。核心矛盾：**H22** 恢复算子本身也是技能，会继承动作空间不兼容与鲁棒性缺口，形成“恢复盲区”；**H23** 分层规划的抽象恰恰会遮蔽低层故障，检测-升级时延可能结构性超过故障临界时延；**H24** 局部恢复与全局重规划非交换，恢复组合可能诱发名义性能上的“恢复性负迁移”。

## 0. 直觉与动机

**灵感 1（恢复不是兜底，而是分层吸收）**
直觉：真正的失败恢复不是准备一个万能 fallback，而是在多个抽象层级上各准备一小块“可吸收的失败邻域”。最细层（伺服/动作）先做局部修复；修复预算或动作覆盖不足时，向粗层（技能/组合/任务）升级，由粗层撤销承诺并重规划；最上层是安全中止。恢复能力不是某个算子，而是一条**升级梯**：`ℋ = C_0 → C_1 → … → C_L → abort`。这样，“恢复”与“分层规划”不是两个模块，而是同一决策过程的两个方向：规划在抽象层做承诺，恢复在某一层撤回承诺并重新取证。

**灵感 2（恢复算子即技能，复用第 54 轮的动作-鲁棒性证书）**
直觉：一个恢复算子 `R` 也必须回答“它在哪些动作上能起作用、它的鲁棒性谱多宽、它多快能完成”。因此 `R` 直接继承 `α_R : A→[0,1]` 与 `ρ_R`。失败发生时，关键不是“有没有恢复算子”，而是**失败区域 `A_F` 是否落在 `α_R` 的支撑集内**。若失败发生在 `α_R` 的低覆盖区，恢复动作在物理上根本到不了故障现场——这就是**恢复盲区（recovery blind spot）**，也是把恢复从经验条目变成可验证对象的第一性约束。

**灵感 3（规划-恢复对偶）**
直觉：分层规划在每一层都隐含一组“承诺”（当前子目标、当前动作模式、当前时间预算）。失败本质上是某个承诺被证伪。恢复就是**在某一层有代价地撤销承诺**：细层撤销动作假设，中層撤销组合序，粗层撤销任务分解。于是每个规划层都应对偶地拥有一个**恢复契约 `C_ℓ`**：它声明本层能吸收哪些失败签名、用什么算子、时延预算是多少、吸收不了时把哪些残余预算升级给 `ℓ+1`。这把“分层规划”从静态 HTN 变成**带失败吸收边界的 HTN**。

**灵感 4（解释驱动的恢复路由）**
直觉：盲目重试是最坏的恢复。第 53/54 轮的 Explain 已能给出根因 `a_e`。只要把 Explain 输出压缩成**失败签名 `σ_F`**（层级、粗动作区域、残差模式、根因），就可以用签名去索引恢复算子库，而不是用原始高维状态匹配。这把恢复路由从“状态相似度检索”变成“签名→算子”的可审计映射，也让“恢复失败”能反向归因为签名不可辨识或算子覆盖不足。

**灵感 5（恢复的无伤害性与不可追溯性边界）**
直觉：恢复必须“只救不毁”。一个恢复动作可能救回当前子任务，却把机器人带出安全集，或使已经完成的子目标证书失效。因此恢复证书除覆盖与时延外，必须包含 **no-harm**（`post_R ⊆ S_safe`、已完成子目标不变量保持）与 **non-retroactive**（恢复触碰了哪些已发证书、需要重新认证的最小依赖集 `D`）。这直接决定恢复能否安全地与其他恢复串接。

**灵感 6（恢复预算是层级间的零和组合）**
直觉：时间、算力、权限在层间是守恒的。把预算全押在细层快修复上，粗层重规划就会“无钱可用”；反之过度保守升级，会浪费本可局部吸收的故障。因此恢复设计是一个**凹资源分配问题**：每层恢复价值 `V_ℓ(b_ℓ)` 边际递减，最优分配由边际增益均衡决定，并需在线再平衡以防“预算倒挂”。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（失败事件与失败签名）**
失败事件 `F = (ℓ, t, a, e, mode)`：`ℓ∈{0..L}` 为首次观测到异常的层级（0 最细，L 最粗），`t` 为时刻，`a∈A` 为异常动作，`e` 为残差/约束违背证据，`mode` 为残差模式（超时、漂移、碰撞、覆盖缺失、证书失效等）。
失败签名 `σ_F = Sig(F) = (ℓ, ⌊a⌋_c, mode, Explain(e)) ∈ Σ_F`，其中 `⌊·⌋_c` 为到粗动作区域的投影，`Explain(e)` 取第 53 轮根因输出。失败区域 `A_F = supp(𝟙[mode at a]) ⊆ A`。层级失败流形 `𝔉_ℓ = {F : F.ℓ = ℓ}`。

**定义 122（恢复算子）**
恢复算子 `R = (pre_R, post_R, α_R, ρ_R, τ_R, κ_R, auth_R)`：
- `pre_R ⊆ S×A`：可触发条件（含失败签名白名单）；
- `post_R`：相对目标/不变量的恢复后置条件；
- `α_R : A→[0,1]`：恢复动作剖面（继承 IP-115）；
- `ρ_R`：恢复鲁棒性谱（继承第 53/54 轮）；
- `τ_R = (τ_det, τ_dec, τ_act)`：检测/决策/执行时延；
- `κ_R`：恢复代价（能量、时间、风险）；
- `auth_R ∈ {0..L}`：可调用该算子的最高层级权限。

`R` 对 `F` **失败覆盖**当且仅当 `A_F ⊆ supp(α_R)` 且 `α_R(a) ≥ θ_cov, ∀a∈A_F`；**无伤害**当且仅当 `post_R ⊆ S_safe` 且对已完成子目标 `g` 有 `Inv(g)` 保持。`R` **及时**当且仅当 `τ_det+τ_dec+τ_act ≤ τ_crit(F)`。

**定义 123（分层恢复契约与升级梯）**
层级恢复契约 `C_ℓ = (𝔉_ℓ, ℜ_ℓ, τ_ℓ, β_ℓ, esc_ℓ)`：`ℜ_ℓ` 为本层恢复算子组合，`τ_ℓ` 为本层恢复截止期，`β_ℓ=(b^time_ℓ,b^comp_ℓ,b^auth_ℓ)` 为本层剩余预算，`esc_ℓ: 𝔉_ℓ → {ℓ, ℓ+1, abort}` 为升级函数。
**可行性**：`∀F∈𝔉_ℓ`，若 `esc_ℓ(F)=ℓ`，则 `∃R∈ℜ_ℓ` 使 `cover(R,F) ∧ noharm(R) ∧ timely(R,F)`；若 `esc_ℓ(F)=ℓ+1`，则 `β_ℓ` 足以支付升级开销且 `β_{ℓ+1}` 未被透支。
升级梯 `ℋ = (C_0,…,C_L, abort)`，`abort` 为吸收态且 `S_abort ⊆ S_safe`，升级关系无环（始终向 `ℓ+1`）。

**定义 124（恢复感知 HTN，R-HTN）**
R-HTN 计划 `P = (T, M, ≺, m_R)`：`T` 为任务树，`M = M_prim ∪ M_rec`，`M_rec` 为带触发守卫 `guard(m_R)=σ_F∈Σ_R` 的恢复分解方法，`≺` 为子任务偏序。单故障恢复闭包
`Cl(P) = { leaf(τ) : τ 由 P 在任一单点失败 F 处插入至多一个 m_R 后执行得到 }`。
`P` 为**恢复健全**当且仅当 `∀l∈Cl(P): l∈G ∪ S_abort` 且 `l` 不违反硬约束。多故障情形以升级深度 `k` 截断（见 A31）。

**定义 125（恢复证书）**
`RC = (σ_F, R, A_F, cover, slack, ρ_R, noharm, D, next)`：
- `cover = min_{a∈A_F} α_R(a)`，要求 `≥θ_cov`；
- `slack = τ_crit(F) - (τ_det+τ_dec+τ_act)`，要求 `≥0`；
- `ρ_R` 要求 `min_d ρ_R(d) ≥ ρ_min`；
- `noharm` 为定义 122 的无伤害布尔；
- `D` 为被本次恢复触碰、需重新认证的已发证书依赖集；
- `next = esc(F) ∈ {ℓ+1, abort}`。
`dom(RC)=in` 当且仅当上述条件全满足且 `next` 已被认证或为 `abort`。若 `RC` 通过，则必须对 `D` 中证书执行**最小重认证**，否则恢复不得执行（non-retroactive 规则）。

**定义 126（恢复预算与可行性）**
预算 `B = (b_0,…,b_L)`，`b_ℓ` 为三维资源向量，`Σ_ℓ b_ℓ ≤ B_tot`（逐分量）。层级恢复价值 `V_ℓ(b_ℓ)` 为凹、非降函数。分配问题 `max Σ_ℓ V_ℓ(b_ℓ) s.t. Σ b_ℓ ≤ B_tot`；当 `V_ℓ` 可微凹时最优解满足 `∂V_ℓ/∂b_ℓ = λ`（边际均衡）。**预算倒挂**指 `b_ℓ` 过低导致 `C_ℓ` 不可行、却仍从 `ℓ+1` 透支的反常状态，必须由可行性约束显式禁止。

**定义 127（恢复组合与干扰）**
两恢复算子组合 `R_i ⊙ R_j`；**干扰** `int(R_i,R_j) = |supp(α_{R_i}) ∩ supp(α_{R_j})| · 𝟙[post_{R_i} ∧ post_{R_j} 冲突]`。若 `R_i⊙R_j` 与 `R_j⊙R_i` 恢复的已完成子目标集不同，称**恢复非交换**。**恢复性负迁移**定义为名义（无故障）分布上的性能回退
`Δ_nom = P(success | no failure, 部署 R) - P(success | no failure, 无 R)`；要求 `Δ_nom ≥ -ε` 才允许把该恢复组合挂入计划。

**定义 128（分层恢复联合证书）**
`J⁺ = (J, RC-tree, ℋ, β, evidence)`：`J` 为第 54 轮动作-鲁棒性联合证书；`RC-tree` 为计划中每个“失败可达节点”挂接的恢复证书；`ℋ` 为升级梯；`β` 为预算分配；`evidence` 至少含失败注入日志、Explain 根因、恢复覆盖审计与名义回归测试。
**可部署**当且仅当：`dom(J)=in`；`∀v∈reachable(P)`，`v∈RC-tree ⇒ dom(RC-tree[v])=in`；`∀ℓ` 满足 `C_ℓ` 可行性；`Σβ ≤ B_tot`；`Δ_nom ≥ -ε`。

**新增假设**
- **(A29)** 失败签名在层级 `ℓ` 或更低层可在 `τ_det` 内被检测，且 `Sig` 对同模式失败稳定（签名误分类率 ≤ `β_sig`）。
- **(A30)** 每个被选恢复算子均通过定义 125 的覆盖/无伤害/时延/鲁棒性四重证书，且重认证 `D` 在预算内闭合。
- **(A31)** 升级梯无环，`abort` 吸收且安全；多故障截断深度 `k ≤ L+1`，每层至多一次升级。
- **(A32)** 恢复组合干扰有界：`Σ int(R_i,R_j) ≤ ε_int`，且名义回归 `Δ_nom ≥ -ε`。

## 2. 关键算法伪代码

### IP-121 FSL（Failure Signature & Localization）

```python
def failure_signature(trace, level, explain):
    ev = localize(trace, level)                  # (t, a, residual)
    mode = classify_residual(ev.residual)        # timeout/drift/collision/...
    sigma = (level, coarse(ev.a), mode, explain.root_cause)
    A_F = failure_region(trace, ev)              # 失败动作区域
    return FailureEvent(ev.t, ev.a, sigma, A_F)

def signature_index(events):
    return group_by(events, key=lambda F: F.sigma)   # sigma -> [F]
```

### IP-122 ROP（Recovery Operator Portfolio）

```python
def build_recovery_portfolio(failure_manifold, lib, theta_cov, rho_min):
    portfolio = defaultdict(list)
    for F in failure_manifold:
        for R in lib.recovery:
            if cover_ratio(R.alpha, F.A_F) < theta_cov:      continue
            if min(R.rho.values()) < rho_min:                continue
            if not no_harm(R, completed_goals=None):         continue
            if not timely(R, F):                             continue
            portfolio[F.sigma].append(R)
    for s in portfolio:
        portfolio[s].sort(key=lambda R: R.kappa)             # 代价升序
    return portfolio
```

### IP-123 HEL（Hierarchical Escalation Ladder）

```python
def route_recovery(F, portfolio, ladder, budget, L):
    for l in range(F.level, L + 1):                # 细 -> 粗
        C = ladder[l]
        if not contract_viable(C, F): continue
        R = first_covering(portfolio.get(F.sigma, []), F)
        if R is not None and R.auth >= l:
            slack = C.tau - sum(R.tau)
            if slack >= 0:
                return ('recover', l, R, slack)
        if budget[l].time < C.tau:                 # 本层无钱，升级
            continue
        budget[l] = spend(budget[l], C.tau)
    return ('abort', safe_stop())                  # 吸收态
```

### IP-124 RHTN（Recovery-Aware HTN）

```python
def plan_recovery_aware(task, methods, portfolio, ladder):
    P = htn_decompose(task, methods.primary)
    for node in postorder(P):
        for F in predict_failures(node, monitor_model):
            sigma = signature_model(node, F)
            cands = portfolio.get(sigma, [])
            rc = choose_recovery(node, F, cands, ladder)
            if rc is None:
                return ('reject', 'unrecoverable', node, F)
            node.attach(rc)
    return ('ok', P)
```

### IP-125 RCB（Recovery Certificate & Budget）

```python
def recovery_certificate(F, R, ladder, theta_cov, rho_min):
    cover = cover_ratio(R.alpha, F.A_F)
    if cover < theta_cov:          return ('reject', 'blind_spot', F)
    if not no_harm(R):             return ('reject', 'harm', R)
    slack = ladder[F.level].tau - sum(R.tau)
    if slack < 0:                  return ('reject', 'too_late', slack)
    if min(R.rho.values()) < rho_min: return ('reject', 'robustness', R.rho)
    D = touched_certificates(R, certified_set)
    if not recheck_within(D, ladder[F.level].beta):
        return ('reject', 'retroactive', D)
    nxt = ladder[F.level + 1] if F.level < len(ladder)-1 else 'abort'
    return ('ok', RC(F.sigma, R, F.A_F, cover, slack,
                     R.rho, no_harm(R), D, nxt))
```

### IP-126 HRJ（Hierarchical Recovery Joint Certificate）

```python
def hierarchical_joint_certificate(J, P, rc_tree, ladder, budget, eps):
    if domain_check(J) != 'in':                 return ('reject', 'base_cert')
    for v in reachable(P):
        if v in rc_tree and domain_check(rc_tree[v]) != 'in':
            return ('reject', 'recovery_uncertified', v)
    for l, C in enumerate(ladder):
        if not contract_viable(C):              return ('reject', 'ladder_gap', l)
    if not budget_feasible(budget):             return ('reject', 'budget_inverted')
    if nominal_regression(P, rc_tree) < -eps:   return ('reject', 'negative_transfer')
    return ('ok', J_plus(J, rc_tree, ladder, budget))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FSL | O(|trace|·|𝔇_ρ|) | O(|𝔉|) | 签名稳定、Explain 根因可信 |
| ROP | O(|𝔉|·|ℜ|·|A|) | O(|𝔉|·|ℜ|) | 覆盖判定 sound、时延上界保守 |
| HEL | O(L·|ℜ|·|A|) | O(L) | 升级无环、预算不透支 |
| RHTN | O(|T|·|M|·|𝔉| + |E|) | O(|T|+|𝔉|) | 闭包 sound、故障数截断 |
| RCB | O(|A|+|𝔇_ρ|+|D|) | O(|A|+|D|) | 无伤害、slack≥0、重认证闭合 |
| HRJ | O(|V|·|RC|) | O(|V|+|RC|) | 联合证书 sound、名义回归门 |

**正确性定理（Hierarchical Recovery Soundness）**
承第 54 轮 (A22)–(A28) 与 (A29)–(A32) 成立。对计划 `P`，若其单故障恢复闭包 `Cl(P)` 中每个节点均挂接 `dom=in` 的恢复证书，且升级梯每层可行、预算可行、`Δ_nom ≥ -ε`，则执行落入目标或安全中止的概率满足：

```
P(exec ∈ G ∪ S_abort)
  ≥ 1 - Σ_{ℓ=0}^{L} (1 - p_ℓ)      # 各层失败覆盖不足
      - P(σ_F ∉ Σ_R)                 # 签名未登记/误分类
      - P(τ_det + τ_dec > τ_crit)    # 结构性迟到
      - Σ_{i<j} int(R_i,R_j)         # 恢复干扰
      - P(Δ_nom < -ε)                # 名义负迁移
```

其中 `p_ℓ` 为层 `ℓ` 对其失败流形 `𝔉_ℓ` 的覆盖-及时联合概率。关键：**恢复成功不等于部署安全**，只有“覆盖 ∩ 无伤害 ∩ 及时 ∩ 预算可行 ∩ 不追溯破坏”同时成立，才计入 `p_ℓ`。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（FSL×ROP×HEL×RHTN×RCB×HRJ）

> 承接第 54 轮产物 v31。本轮把“动作-鲁棒性双证书”扩展为“**规划-恢复对偶体系**”：失败不再是外部异常，而是**某个抽象层承诺的证伪**；恢复是在正确层级撤销承诺并重新取证的过程。

### IP-122 ROP

```python
def build_recovery_portfolio(failure_manifold, lib, theta_cov, rho_min):
    P = defaultdict(list)
    for F in failure_manifold:
        for R in lib.recovery:
            if cover_ratio(R.alpha, F.A_F) < theta_cov:   continue
            if min(R.rho.values()) < rho_min:             continue
            if not no_harm(R):                            continue
            if not timely(R, F):                          continue
            P[F.sigma].append(R)
    for s in P: P[s].sort(key=lambda R: R.kappa)
    return P
```

### IP-123 HEL

```python
def route_recovery(F, portfolio, ladder, budget, L):
    for l in range(F.level, L + 1):              # 细 -> 粗
        C = ladder[l]
        if not contract_viable(C, F): continue
        R = first_covering(portfolio.get(F.sigma, []), F)
        if R is not None and R.auth >= l:
            slack = C.tau - sum(R.tau)
            if slack >= 0: return ('recover', l, R, slack)
        if budget[l].time < C.tau: continue
        budget[l] = spend(budget[l], C.tau)
    return ('abort', safe_stop())
```

def plan_recovery_aware(task, methods, portfolio, ladder):

### IP-125 RCB

```python
def recovery_certificate(F, R, ladder, theta_cov, rho_min):
    cover = cover_ratio(R.alpha, F.A_F)
    if cover < theta_cov:            return ('reject', 'blind_spot', F)
    if not no_harm(R):               return ('reject', 'harm', R)
    slack = ladder[F.level].tau - sum(R.tau)
    if slack < 0:                    return ('reject', 'too_late', slack)
    if min(R.rho.values()) < rho_min:return ('reject', 'robustness', R.rho)
    D = touched_certificates(R, certified_set)
    if not recheck_within(D, ladder[F.level].beta):
        return ('reject', 'retroactive', D)
    nxt = ladder[F.level+1] if F.level < len(ladder)-1 else 'abort'
    return ('ok', RC(F.sigma, R, F.A_F, cover, slack, R.rho,
                     no_harm(R), D, nxt))
```

def hierarchical_joint_certificate(J, P, rc_tree, ladder, budget, eps):
    if domain_check(J) != 'in':                 return ('reject','base_cert')

def allocate_recovery_budget(value_fns, B_total, eps=1e-3):
    b = {l: zero_vec() for l in value_fns}
    while remaining(B_total, b) > eps:
        l = argmax_l marginal(value_fns[l], b[l])

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FSL | O(|trace|·|𝔇_ρ|) | O(|𝔉|) | 签名稳定率 ≥ 1-β_sig，根因可追溯 |
| ROP | O(|𝔉|·|ℜ|·|A|) | O(|𝔉|·|ℜ|) | 覆盖/无伤害/及时三判 sound |

| HRJ | O(|V|·|RC|) | O(|V|+|RC|) | 联合证书 sound，名义回归门 |
| 预算分配 | O(L·|B|/δ) | O(L) | 凹性下贪心最优性 |

**正确性定理（Hierarchical Recovery Soundness）**
承第 54 轮 (A22)–(A28) 与新增 (A29)–(A32) 成立。对计划 `P`，若 `Cl(P)` 每个节点挂接 `dom=in` 的 `RC`，升级梯逐层可行、预算可行、`Δ_nom ≥ -ε`，则

```
P(exec ∈ G ∪ S_abort)
  ≥ 1 - Σ_{ℓ=0}^{L}(1 - p_ℓ) - P(σ_F ∉ Σ_R)
      - P(τ_det+τ_dec > τ_crit) - Σ_{i<j} int(R_i,R_j) - P(Δ_nom < -ε)
```

其中 `p_ℓ` 为层 `ℓ` 对 `𝔉_ℓ` 的“覆盖 ∩ 无伤害 ∩ 及时”联合概率。
**推论（恢复不放大风险）**：若 `RC` 满足 `noharm` 且 `D` 重认证通过，则恢复执行不降低已有子目标的可达性；故“恢复失败”最多退化为 `abort`，不得退化为越界或证书污染。
