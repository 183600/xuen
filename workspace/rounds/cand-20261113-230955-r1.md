# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互不确定性二分」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「腕部相机」×「指令泛化」）

> R69 把不确定性一分为二：aleatoric 进 λ_floor，epistemic 交给「看/问/触」。但这一整套二分**默认了指令解释是可信的**——策略被条件在 o_t 上，而「o_t 到底要完成什么任务」被当作已知。真实失败常常是：感知没错、动作没错、世界模型没错，**但做的是另一件事**。指令泛化要的正是「把没见过的说法正确地落到当前场景」；一旦分布外、欠指定或指代歧义，解释后验就会散开，系统于是精确、自信、且安全地执行一个错误任务。
>
> 腕部相机则戳破了 R69 的一个隐藏假设：R69 把信息动作 g 当作「不改安全包络」的廉价观测（定义 302）。但腕部相机的位姿是机械臂构型的函数——**看与做共享同一组自由度**。要看清接触细节，手必须靠近、必须挡光、必须触碰；**最值钱的证据恰恰在承诺（contact）的对面**。观测不是免费的，它用状态支付。
>
> 核心命题：**在 R69 的两类不确定性之外增加第三类——语义不确定性 U_sem（我对指令的哪一种解释是对的）；用「腕部相机下的可逆后果实验（consequence-contrast test）」而不是「问人」去消解它；把不可逆性作为硬预算，不可逆的验证一律不许做，退化为 R69 的问询、R68 的保守、或直接拒做。** 命名 **PROBE-RAS**（Physically-grounded, Reversible, Observation-coupled Belief Experiments）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我理解的任务对吗，能否用最小的不可逆代价去证实**」——理解不是一个先验，而是一个需要用身体去检验的假设。

## 0. 直觉与动机

**灵感 1（腕部相机 → 看与做同源）**
直觉：第三人称相机是「旁观」，腕部相机是「参与」。它的视角由手臂构型决定，所以「凑近看」=「把手移过去」，而移动手会挡光、改变接触、扰动被操作物。R69 的增广动作 ξ=(a,g) 假设 a 与 g 可正交组合、安全包络不变；腕部相机让这个假设失效：**g_gaze 必须由手臂构型实现**，因此 g 与 a 共享执行器、共享安全约束、共享状态后果。这带来一个新的成本维度：**信息的价格不是时间，而是状态改变**。

**灵感 2（指令泛化 → 指令本身是一个待检验的假设）**
直觉：VLA/LLM 把自然语言映射到任务，其输出不是「任务」，而是「任务的一个解释」：指代绑定（「那个」是哪个）、空间关系（「左边」是谁的左）、动作谓词（「放」是轻放还是塞入）、未言明约束（没说不能碰倒别的）。分布内这个解释几乎唯一；在**组合泛化**（新组合）、**指代歧义**、**欠指定**、**否定/量词**面前，后验会散开。R69 的 epistemic 讨论的是「怎么做的歧义」；这里是「做什么的歧义」——**U_sem 与 U_epi 正交且更上游**：U_epi 是给定解释 m 的动作多峰，U_sem 是 m 本身的熵。

**灵感 3（三层嵌套 → R69 是 U_sem=0 的边界）**
直觉：把不确定性写成 U = U_ale + U_epi(m) + U_sem。当解释唯一且被证实（U_sem=0），PROBE 逐项退化为 FLUID；再当 VoI≤成本，退化为 CALM（R68）。理论姿态延续 R69：**新层必须是旧层在边界上的严格退化**，否则每加一层就多一个必须独立信任的黑箱。这里还多一条硬约束：U_epi 的分解必须在每个 m 的条件切片内分别进行，因为**不同的任务解释会诱导不同的动作模态**——先聚类再解释，会把两个任务的动作混成一个假模态。

**灵感 4（用「做」代替「问」→ 世界不撒谎，只会不可逆）**
直觉：R69 的最大风险是「问错比不问更危险」——人会撒谎、会共谋、会用提问做社交工程。腕部相机提供一条不依赖人类诚实的验证通道：**做一个小实验，看世界的后果**。不确定「苹果放进哪个碗」，就先把苹果举到两碗的中垂面，从腕部视角看哪个碗在下方、距离更近；不确定抓住的是不是「红的那个」，就用指尖轻触读出纹理/刚度再决定。这就是 consequence-contrast：把「信任人的回答」换成「信任物理后果」。但代价是尖锐的——**世界可以被弄坏，而且它从不说「我错了」**。于是新的核心约束是**可逆性**：能试验的前提是试验能撤回。

**灵感 5（腕部相机的标定悖论 → 证据通道本身要被接触锚定）**
直觉：腕部相机装在手上，它的外参（hand-eye）会漂移；而它的证据又依赖「手在哪」。更糟：R69 用动作似然去抓「标定把故障吸收掉」，但 hand-eye 漂移会同时污染**视觉证据**与**动作条件**，让系统**用错位的眼睛看错位的世界却自洽**。破解只能来自接触：触碰一个已知几何的标记或桌沿，让「看到的接触位置」与「本体感觉的接触位置」对齐——**接触是视觉标定的锚**。这形成 R68→R69→R70 的一条递进：残差通道（R68）→ 行为似然通道（R69）→ **接触锚定通道（R70）**，每一条都在补前一条能被欺骗的地方。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PROBE-RAS 总览与四不变式）** PROBE-RAS = (SEM, GIG, WCO, CCT, RIV, ESC, HEC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **三层嵌套退化**：U_sem=0 ⇒ 逐指令退化为 FLUID；FLUID 的 VoI≤成本 ⇒ 退化为 CALM；安全侧只做包络交叠、绝不扩张；
(iii) **可逆性硬约束**：任何物理验证动作 x 必须存在有界逆 x^{-1} 使 d(s, x^{-1}∘x(s)) ≤ δ_rev，且期望不可逆伤害 ≤ ε_irr；不满足则 x 禁止执行；
(iv) **语义接地证书**：解释 m 只能使用 GIG 中已验证的基元与组合规则，覆盖不足 ⇒ 不得执行，只能升级为问询或拒做。

**定义 311（指令、上下文与解释空间）** 指令 ℓ（自然语言串）；上下文 c（场景、历史、用户）。解释 m ∈ ℳ(ℓ) 是一个结构化接地程序：参考绑定 b（哪个观测指称哪个对象）、空间/时序关系 r、动作谓词 v、目标谓词 goal、未言明约束的默认集 Δ。行为分解为 p(m|ℓ,o,c)（解释后验）× π(a|o,m)（给定解释的行为）。

**定义 312（语义不确定性 U_sem）** U_sem = H(M|ℓ,o,c)，即解释身份的熵。与 U_epi 的区别：U_epi 是给定 m 的动作多峰，U_sem 是 m 本身的不确定；二者在近似条件独立下可加但**必须分通道处置**（定义 314）。注意 U_sem 不是语言模型的 token 熵，而是**落到当前场景后的结构化绑定熵**。

**定义 313（接地指令图 GIG）** GIG = (P, R, V, cov, d)：P 为已验证基元（对象类/关系/谓词/约束），R 为带类型的组合规则，V 为每个基元的验证统计（成功率与置信区间），cov(ℓ) = 叶基元中已验证比例，d(ℓ) = 组合深度。解释 m 合法 ⇔ 所有叶基元 ∈ P 且组合类型合法。语义误差上界 ≤ Σ_{p∈leaves(m)} δ_p ≤ d(ℓ)·δ_max（引理 21）。GIG 支持从腕部第一人称演示扩表，但扩表本身必须过验证门（IP-265）。

**定义 314（语义-认知联合分解 SEP）** U = U_ale + U_epi + U_sem，其中 U_epi = Σ_m p(m|·)·U_epi(m)（每个解释切片内各自做动作聚类），U_sem = H(M|·)。**顺序约束**：不能先对动作聚类再解释——不同 m 的同名模态会被错误合并；分解必须在 m 的条件切片内进行，或做联合聚类并在模态上标注所属 m。**可辨识性**：若两个 m 对任何允许动作诱导的观测分布相同，则二者不可辨识，U_sem 不能靠试���下降，只能外部问询或拒做。

**定义 315（腕部观测算子 WCO）** 腕部观测 o^w = 𝒪(a; q, T_hc) = Render(World, C(q)·T_hc)，其中 C(q) 为手臂正运动学位姿，T_hc 为 hand-eye 外参，q 由 a 积分得到。关键性质 **∂o^w/∂a ≠ 0**：观测随动作变化，动作与观测不可分离。定义观测可达集 𝒪_+(s) 与遮挡函数 occ(a)。

**定义 316（手眼标定状态 HEC）** T_hc = T̂_hc + Δ_hc，Δ_hc 为漂移；标定残差 r_he。**接触锚定**：用已知几何的接触事件（指尖触桌、触标记）构造约束 z_touch = FK(q) 已知，观测到的接触点在腕部图像中投影为 ẑ_cam，则 Δ_hc = argmin Σ‖Proj(C(q)·T_hc·p) − ẑ_cam‖²；只有接触给出 metric 尺度，故只在接触瞬间可观。**WCO 证据有效性以 r_he ≤ τ_he 为前提**（引理 22）。

**定义 317（后果对比试验 CCT）** 一个可逆试验 x=(a_1..a_T) 配逆 x^{-1}；对解释 m_i,m_j，视觉后果似然 p(o^w|x,m_i,s)。可区分度 C(x;m_i,m_j)=D_KL(p_i‖p_j)；对比度 C(x)=min_{i≠j} C(x;m_i,m_j)。选 x* = argmax_x [E[IG(M;o^w|x)] − c_time(x) − c_social(x) − λ_irr·c_irr(x)]，s.t. Rev(x)≤δ_rev、C-RAS-WM 认证、r_he≤τ_he。**接触信息壁垒**（引理 20）：若 m_i,m_j 仅在后接触后果上不同，则任何区分它们的 x 必进入接触集，故 c_irr 有正下界。

**定义 318（可逆性预算与净 VoI，RIV）** 对试验 x，不可逆代价 c_irr(x)=E[d_irr(s, x^{-1}∘x(s))] + Pr[不可逆事件]·伤害。RIV 控制器：仅当 VoI_net = IG − c_time − c_social − λ_irr·c_irr > 0 且 c_irr ≤ ε_irr 时允许试验。λ_irr 是可逆性价格（人旁边高、自由空间低），并随 AuditBuf 自适应。

**定义 319（升级阶梯 ESC）** 四级：①可逆试验（首选，物理后果）；②问询（R69 MINT，信任人但受证据纪律约束）；③保守执行（R68 纯 λ_floor，不做任务级承诺）；④拒做/请求接管（语义不可辨识或不可逆风险超标）。升级规则：任一级失败/超时/被投毒/标定越界 → **单向升一级（更保守）**，绝不跳回更激进的级别。

**定义 320（指令 OOD 与负能力 NC）** 若 cov(ℓ)<1、d(ℓ)>d_max、或 m 的似然落在 GIG 语法外，则判 OOD 指令；系统**不得用最近邻强行接地**（那会产生流畅的幻觉），必须走 ESC ②或④。**负能力**定义为正确拒绝的比例，与任务成功率并列为一级指标。

**定义 321（语义安全前置）** 任务级风险 R_task(m) = 执行 m 造成不可逆伤害的期望。前置门：若存在高后验 m 使 R_task(m) > ρ_task 且无法在不触发该风险的前提下验证，则整个任务拒做（安全压倒任务）。这处理「指令本身有害/越界」的情形（如指示人形机器人推人）。

**定义 322（证书 J_PROBE）** J_PROBE = (J_FLUID, U_sem_before, U_sem_after, coverage, depth, r_he, reversibility_margin, probe_log_hash, irreversibility_spent, probe_ver)。Valid ⇔ Valid(J_FLUID) ∧ cov=1 ∧ r_he≤τ_he ∧ reversibility_margin≥0 ∧ 拒做/降级记录完整。

**定义 323（威胁模型 AIC-PROBE）** ℰ_PROBE = ℰ_FLUID × ℰ_instr × ℰ_vis × ℰ_probe：对抗性指令（诱导越界或误导绑定）、**视觉提示注入**（场景里贴一张写着指令的纸，被腕部相机读到并当成任务）、试探性破坏（用假可逆性骗过 RIV）、语义幻觉（GIG 组合出看似合法实则错误的任务）。并入 AIC。

**定义 324（语义审计 VQAuditor-S）** 审计：解释后验是否被恰当传播、试验是否真的可逆、覆盖/深度是否越界、拒绝是否合理（漏拒 vs 误拒）、视觉证据是否依赖失效的 hand-eye。结论回灌 GIG 验证统计与 RIV 的 λ_irr 先验。

**定义 325（接触锚定标定探针）** 当 r_he>τ_he 且接触预算允许时，执行标定探针：触碰已知几何并比较腕部视觉接触点与 FK 预测，更新 Δ_hc；恢复则证据通道重新可用，否则 WCO 证据降权、ESC 升级。**这是「证据通道自身的可证伪性」——不允许用未标定的眼睛为自己的标定作证。**

**定义 326（解释级实时预算）** 默认只维护 top-1 解释（U_sem 由 GIG 门控直接判 0/高）；仅当 U_sem 高时展开 top-B（B≤3）解释及对应动作模态，做语义 beam search；全程复用 R69 的 z_t，CCT 的 T 与试验次数受 P99 约束。语义展开是预算与拒做率之间的折中。

```python
# IP-264 SEM：解释后验（VLM 给先验，GIG 给合法性，不直接信任 VLM）
def interpret(instruction, obs, ctx, gig):
    m_prior = vlm_ground(instruction, obs, ctx)          # 结构化解释候选
    legal   = [m for m in m_prior if gig.legal(m)]        # 覆盖/深度/类型检查
    if not legal or gig.coverage(instruction) < 1.0:
        return None, 1.0                                  # OOD：不接地 → ESC ②/④
    post = normalize({m: p for m, p in m_prior.items() if m in legal})
    return post, entropy(post)                            # U_sem

# IP-265 GIG：组合泛化与接地证书
class GroundedInstructionGraph:
    def legal(self, m):     return all(p in self.P for p in leaves(m))
    def coverage(self, l):  return verified_ratio(leaves(parse(l)), self.P)
    def error_bound(self, m): return sum(self.V[p].err for p in leaves(m))  # 引理 21
    def expand(self, demo):                                   # 从第一人称演示扩表
        p = induce_primitive(demo)
        if validate(p): self.P.add(p); self.V[p] = stats(p)   # 必须过验证门

# IP-267 CCT：可逆后果试验（腕部相机）
def consequence_test(policy, post, obs, budget, wco, riv):
    best = None
    for x in probe_candidates(post, obs, wco):          # 举到中垂面/轻触/推移可复原点
        if not wco.trusted():                 continue  # r_he > τ_he → 证据不可用
        if not c_ras_wm.certify(x, obs):      continue
        if not riv.reversible(x):             continue  # 逆存在且 d ≤ δ_rev
        ig   = expected_info_gain(post, x, wco)          # 对解释身份 M 的 IG
        cost = c_time(x) + c_social(x) + riv.lambda_irr * c_irr(x)
        if best is None or ig - cost > best.score: best = (x, ig - cost)
    return best if best and best.score > 0 else None    # 无利可图 → 升级

# IP-268/319 升级阶梯
def escalate(post, obs, mission_ctx, gig):
    if mission_ctx.any_high_posterior_unsafe(post): return REFUSE      # 定义 321
    if gig.coverage(mission_ctx.instruction) < 1:   return REFUSE_OR_ASK
    x = consequence_test(...)
    if x is not None:   return PROBE(x)                                # ①
    if mint.voi(post) > 0: return ASK                                  # ②
    return CONSERVATIVE                                                # ③ R68 兜底

# IP-275 主闭环
def PROBE_RAS_round(M, obs, instruction):
    post, U_sem = M.sem.interpret(instruction, obs, M.ctx, M.gig)
    if post is None:                                       # OOD 指令
        return M.esc.run(post=None, reason='OOD')
    z, o = M.mtm.forward(obs); M.cof.step(...)             # R69/R68 继承
    # 联合分解：每个解释切片内各自聚类（不可先聚类后解释）
    U_ale = U_epi = 0.0; per_m_modes = {}
    for m, w in post.items():
        K = 1 if M.fmp.mode_head(z, m) < TAU_MODE else 4
        modes = M.fmp.sample(o, m, K)
        a_, e_ = M.aud.decompose(modes, z, m)
        U_ale += w * a_; U_epi += w * e_; per_m_modes[m] = modes
    if U_sem < TAU_SEM and U_epi <= TAU_EPI:
        m = argmax(post); return M.fluid_execute(m, per_m_modes[m])    # 退化 FLUID
    # 语义优先：语义未定则先做后果试验，而不是先消动作歧义
    action = M.esc.run(post, o, M.mission)
    if action.kind == 'REFUSE': return REFUSE
    if action.kind == 'PROBE':
        o_w = M.wco.observe(action.x)                      # 腕部后果
        post = M.sem.bayes_update(post, o_w, action.x, M.gig)
        U_sem = entropy(post)
        if not M.wco.trusted(): M.hec.recalibrate_probe()  # 标定探针
    elif action.kind == 'ASK':
        post = M.cia.update_belief(post, M.cia.execute(...))
    if U_sem > TAU_SEM:
        return M.esc.run(post, o, M.mission, reason='semantic_unresolved')
    m = argmax(post)
    return M.fluid_execute(m, per_m_modes[m])              # m 定则走 R69
```

## 3. 推导

环境假设：A99（解释空间可数、后验可归一）；A100（腕部相机对每个 m 给出可计算的后果似然）；A101（可逆性谓词 Rev 在 δ_rev 内可靠，由 C-RAS-WM 认证）；A102（hand-eye 残差 r_he 可观测且接触可锚定）；A103（GIG 的基元验证误差相互独立，组合规则类型安全）。

**引理 19（后果对比的可辨识增益）** 若试验 x 对 m_i,m_j 的腕部后果分布 κ-可分（C(x;m_i,m_j)≥κ），则一次试验使 U_sem 至少下降二元熵 H_2(e^{-κ})；经 n 次独立试验后，真实解释的漏检概率 ≤ e^{−nκ}。达到 U_sem≤ε 的期望试验数 O(log(1/ε)/κ)。系：**对比度最大化等价于把歧义指称搬进腕部相机的高分辨率/接触区**——「把东西举到眼前」不是隐喻，是 argmax C(x) 的解。

**引理 20（接触信息壁垒）** 若 m_i,m_j 仅在**后接触**后果上不同（刚度、是否打滑、抓取是否成功），则任何停留在接触集之外的 x 有 p(o^w|x,m_i)=p(o^w|x,m_j)，故 IG=0；要获得正 IG 必须进入接触集，而进入接触意味着状态改变，故 c_irr ≥ c_contact_min > 0。系：**「看清楚了再碰」只能消解前接触解释；真正决定性的语义证据要用接触购买**。这解释了为什么 R69 把探针当免费观测是错的。

**引理 21（指令泛化误差上界）** 若解释 m 的叶基元逐个验证误差 δ_p、组合深度 d、每条组合规则误差 δ_R，则在独立误差与类型安全假设下，任务级语义错误率 ≤ Σ_{p∈leaves(m)} δ_p + d·δ_R ≤ d·(δ_max+δ_R)。因此一张有效接地证书要求 cov=1 且 d·(δ_max+δ_R) ≤ ρ_sem。系：**「指令泛化」从一句愿望变成一个可审计的量化保证**——不是「模型泛化好」，而是「该指令只用到了覆盖内、深度受限、误差可界的基元」。

**引理 22（hand-eye 与证据可信度）** 腕部证据似然对 T_hc 满足 Lipschitz：|log p(o^w|x,m;T_hc) − log p(o^w|x,m;T̂_hc)| ≤ L_he‖Δ_hc‖。若 r_he>τ_he，则 κ-可分性可缩到 κ 以下，试验失去可辨识力。故证据必须由 r_he 门控，接触锚定重标定恢复可分裕度。这是 R68 反吸收引理（引理 13）搬到**观测算子**上的版本：**被标定骗过的不只是传感器残差，还有「看」这件事本身。**

**定理 18（PROBE 对 FLUID 的严格泛化）** 在 A99–A103 下，对任意状态，PROBE 的任务级期望风险 ≤ FLUID 的风险 + λ_irr·ε_irr；且当 U_sem=0 或不存在可采纳的可逆试验时，PROBE 与 FLUID **逐指令相同**（风险相等）。再当 FLUID 的 VoI≤成本时，二者同时退化为 CALM。因此语义轴上是严格泛化，物理扰动轴上是**有证书、有上界、在退化边界上为零**的预算。另：拒做（ESC ④）不会增加任务风险，只会降低任务完成率。**安全侧不做任何让步，代价只在效率侧。**

**定理 19（可逆性与无状态污染 / 升级单调）** 满足 Rev(x)≤δ_rev 且通过 C-RAS-WM 前缀认证的 CCT x，执行后状态偏差 ‖s'−s‖ ≤ δ_rev + ε_cert；试验失败/超时/标定失效时 ESC 单调升向更保守级，λ 单调不降，未消解的 U_sem 绝不被允许触发高风险的不可逆承诺；R68 的提交/换装不变式（定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：PROBE-RAS 把「语义证据」押在「腕部后果可信 + 试验确实可逆」两条前提上，但接触丰富任务里**最决定性的语义证据恰好住在接触之后**（引理 20），于是可逆性门与可辨识性直接对撞——系统要么永远停在「语义未定」而退化成拒做，要么把单向动作**误判为可逆**、用「弄坏一次」来学习；再叠加 hand-eye 漂移，最致命的失败是**自洽的幻觉：一只没标定好的眼睛，用一个它以为可撤销、实际不可撤销的动作，证实了一个错误的解释**。

**次级风险与缓解**：
1. **假可逆性**（学习式 Rev 在边缘样本上过度乐观）→ 解析+学习双判、接触前二次确认、E303 专门测假可逆率、λ_irr 由 AuditBuf 上调；
2. **接触信息壁垒导致「不敢验证」** → 显式代价模型 + 升级到问询/拒做，而不是偷偷冒险；把「拒做」当作合法输出并度量（E306）；
3. **hand-eye 漂移污染证据** → 定义 316/322 的 r_he 门控 + 接触锚定探针，证据通道自身可证伪；
4. **视觉提示注入 / 对抗指令** → ℰ_instr×ℰ_vis、VLM 输出只作先验不作命令、GIG 类型与覆盖门、E308；
5. **指令泛化的过/欠泛化** → 引理 21 的覆盖/深度证书 + 负能力（拒做）一等化，绝不用最近邻硬接地；
6. **语义展开击穿实时** → top-1 默认 + B≤3 门控 + 复用 z_t，E311 守 P99。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写操作继承；三层嵌套退化（U_sem=0⇒FLUID，VoI≤成本⇒CALM）；可逆性硬约束（有界逆 + 期望伤害 ≤ ε_irr）；语义接地证书（只用已验证基元，覆盖不足即不得执行）。

**定义 311–312（解释后验与 U_sem）** `m` 是绑定+关系+谓词+约束的结构化程序；行为 = `p(m|ℓ,o,c) × π(a|o,m)`；`U_sem = H(M|ℓ,o,c)`，与 `U_epi` 正交且更上游。

**定义 313（GIG）** `(P,R,V,cov,d)`；合法 ⇔ 叶基元 ∈ P 且组合类型合法；语义误差 ≤ `d·(δ_max+δ_R)`（引理 21）；支持第一人称演示扩表但须过验证门。

**定义 314（SEP）** `U = U_ale + U_epi + U_sem`，`U_epi = Σ_m p(m)U_epi(m)`；**必须按 m 切片聚类**；不可辨识解释只能靠外部问询或拒做。

**定义 315–316（WCO 与 HEC）** `o^w = Render(C(q)·T_hc)`，观测随动作变化；hand-eye 漂移 `Δ_hc` 由接触锚定估计（只有接触给 metric 尺度）；证据有效性前提 `r_he ≤ τ_he`。

**定义 317–318（CCT 与 RIV）** 试验 `x` 以腕部后果似然区分解释，`x* = argmax[IG − 成本 − λ_irr·c_irr]`；仅当 `VoI_net>0 ∧ c_irr ≤ ε_irr` 允许执行；**接触信息壁垒**：仅后接触可分的解释必须付接触代价。

**定义 319–321（ESC / OOD / 语义安全）** 四级单向升级；`cov<1` 或 `d>d_max` 或无合法解释 ⇒ 拒做/问询，**禁止最近邻硬接地**；高后验解释若越任务风险门 ⇒ 整任务拒做。

**定义 322–326（证书/威胁/审计/标定探针/实时预算）** `J_PROBE` 并入 U_sem、覆盖、深度、r_he、可逆裕度、不可逆花费；ℰ_PROBE 含对抗指令、视觉提示注入、假可逆、语义幻觉；VQAuditor-S 审解释与可逆性诚实度；接触锚定标定探针保证证据通道可证伪；默认 top-1 解释、U_sem 高时 B≤3 语义 beam。

```python
        U_ale += w*a_; U_epi += w*e_; per_m_modes[m] = modes
    if U_sem < TAU_SEM and U_epi <= TAU_EPI:
        m = argmax(post); return M.fluid_execute(m, per_m_modes[m])      # 退化 FLUID
    action = M.esc.run(post, o, M.mission)                   # 语义优先
    if action.kind == 'REFUSE': return REFUSE
    if action.kind == 'PROBE':
        o_w = M.wco.observe(action.x)
        post = M.sem.bayes_update(post, o_w, action.x, M.gig)
        U_sem = entropy(post)
        if not M.wco.trusted(): M.hec.recalibrate_probe()    # 接触锚定标定
    elif action.kind == 'ASK':
        post = M.cia.update_belief(post, M.cia.execute(...))
    if U_sem > TAU_SEM:
        return M.esc.run(post, o, M.mission, reason='semantic_unresolved')
    m = argmax(post); return M.fluid_execute(m, per_m_modes[m])
```

## 4. 推导

环境假设：A99–A103（解释空间可数、后果似然可算、可逆谓词可靠、r_he 可观测可接触锚定、GIG 基元误差独立且组合类型安全）。

**引理 19（后果对比的可辨识增益）** 若试验 `x` 对 `m_i,m_j` 的腕部后果 κ-可分，则一次试验使 U_sem 至少下降 `H_2(e^{−κ})`；`n` 次独立试验后漏检 ≤ `e^{−nκ}`，达 `U_sem≤ε` 期望试验数 `O(log(1/ε)/κ)`。系：最大化对比度 = 把歧义指称搬进腕部相机的高分辨率/接触区。

**引理 20（接触信息壁垒）** 若 `m_i,m_j` 仅在后接触后果上不同，则任何不进入接触集的 `x` 有 `p(o^w|x,m_i)=p(o^w|x,m_j)`、IG=0；进入接触则状态改变，`c_irr ≥ c_contact_min>0`。系：**「看清楚了再碰」只能消解前接触解释；决定性语义证据必须用接触购买**——这正是 R69 把探针当免费观测的错误。

**引理 21（指令泛化误差上界）** 叶基元误差 `δ_p`、组合深度 `d`、组合规则误差 `δ_R`，则任务级语义误差 `≤ Σδ_p + d·δ_R ≤ d·(δ_max+δ_R)`。有效证书要求 `cov=1 ∧ d·(δ_max+δ_R) ≤ ρ_sem`。系：指令泛化从愿望变成**可审计的量化保证**（只用覆盖内、深度受限、误差可界的基元）。

**引理 22（hand-eye 与证据可信度）** `|log p(o^w|x,m;T_hc) − log p(o^w|x,m;T̂_hc)| ≤ L_he‖Δ_hc‖`；若 `r_he>τ_he`，κ-可分性可缩到 κ 以下使试验失效。故证据须由 `r_he` 门控、接触锚定重标定恢复裕度——R68 反吸收引理（引理 13）在**观测算子**上的版本。

**定理 18（PROBE 对 FLUID 的严格泛化）** A99–A103 下，任意状态上 PROBE 任务级期望风险 `≤` FLUID `+ λ_irr·ε_irr`；且当 `U_sem=0` 或无可采纳可逆试验时与 FLUID **逐指令相同**；再当 FLUID 的 VoI≤成本时二者同时退化为 CALM。语义轴严格泛化，物理扰动轴是**有证书、有上界、在退化边界为零**的预算；拒做只降完成率、不增风险。

**定理 19（可逆性与无状态污染 / 升级单调）** 满足 `Rev(x)≤δ_rev` 且过 C-RAS-WM 前缀认证的 CCT，执行后 `‖s'−s‖≤δ_rev+ε_cert`；失败/超时/标定失效时 ESC 单调升向更保守级，λ 单调不降，未消解 U_sem 绝不触发高风险不可逆承诺；R68 提交/换装不变式（定理 15）保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：PROBE-RAS 把语义证据押在「腕部后果可信 + 试验确实可逆」上，但接触丰富任务里**最决定性的语义证据恰好住在接触之后**（引理 20），可逆性门与可辨识性直接对撞——系统要么永远停在「语义未定」而退化为拒做，要么把单向动作**误判为可逆**、用「弄坏一次」来学习；再叠加 hand-eye 漂移，最致命的失败是**自洽的幻觉：一只没标定好的眼睛，用一个它以为可撤销、实际不可撤销的动作，证实了一个错误的解释**。

**次级风险与缓解**：假可逆性（解析+学习双判、接触前二次确认、λ_irr 由 AuditBuf 上调、E303）；接触壁垒导致「不敢验证」（显式代价 + 升级问询/拒做，把拒做当合法输出并度量，E306）；hand-eye 漂移（r_he 门控 + 接触锚定探针，定义 316/325）；视觉提示注入与对抗指令（ℰ_instr×ℰ_vis、VLM 只作先验、GIG 类型/覆盖门、E308）；过/欠泛化（引理 21 覆盖/深度证书 + 负能力一等化、禁止最近邻硬接地）；语义展开击穿实时（top-1 默认 + B≤3 门控 + 复用 z_t，E311）。
