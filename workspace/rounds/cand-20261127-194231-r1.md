## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（决策规划 → 步骤分把问题变成「不可逆的半马尔可夫决策」）**
直觉：现有方案是纯反应式：VLA 每步/每 chunk 直接吐动作，把「先接近、再抓、再搬、再放」的长程结构完全交给数据隐式学习。但计分不是二值成功，而是逐任务里程碑步骤分（F17），且失败仍保留已得步骤分（F22）。这意味着真实目标函数是**不可逆的收益累积**：把已拿到的里程碑做丢，比少拿一个里程碑更糟。反应式策略只在单调推进的成功示教里训练，隐含假设「进度只增不减」，于是有两个系统性失效：(a) 阶段错序/循环（没抓稳就进入搬运）；(b) 偏离后仍自信推进（confidently wrong）。决策规划视角的解法不是再训一个策略，而是给同一个 VLA 加一个**只在决策点工作的轻量监督层**：用「还能不能回到成功示教流形、代价多大」作为状态，用选项表示阶段，只在异常/停滞/选项终止时做离散选择（继续/重采样/检索/恢复/停持）。反直觉点：**决策规划的核心不是「规划出更好的动作」，而是「识别当前动作已不可信，并选择代价最小的回退」。**

**灵感 2（异常检测 → 无失败数据下，异常只能用「可恢复性」自监督定义）**
直觉：评测是零样本 + 人干扰 + 无失败示教（P2/P3/P8），策略必然进入训练没见过的状态。传统异常检测找「离群点」，但离群不等于该干预：有些离群（新物体外观）策略照样能做；有些在流形内（抓空、打滑）却致命。正确的异常定义必须和**后果**绑定：异常 =「从当前状态回到下一个得分点的期望代价显著高于正常，或超过剩余预算」。这个量在成功示教里天然可监督：把示教人为扰动到某状态，原轨迹从该状态到下一里程碑的剩余步数就是「恢复代价」标签——而 I5 的合成偏离正好提供它。反直觉点：**异常检测不需要失败标签，它需要的是「从偏离状态回到成功轨迹要多少步」这个可自监督的代价回归。**

**两者统一（本轮核心）**：用一个共同货币——**可恢复性价值 V(z,k)**（从状态 z、第 k 个里程碑出发，按策略回到下一里程碑的期望剩余步数）——同时定义异常与规划：
- 异常分数 = V 的归一化值 + V 的预测不确定性 + 观测流形距离；
- 规划决策 = 在候选选项 u 上最小化 E[V(z,k|u)] + λ·P(丢失里程碑 k|u)，并受剩余时间预算约束。

这把 I4（人干预）、I5（合成恢复）、I9（检索先验）、I3（接触回退）从「并列 guard 模块」统一成一条**升级阶梯**，也回答了第 2 轮遗留的「guard 栈三模块如何协同」。

## 1. I10 异常触发决策监督层（ATOS, Anomaly-Triggered Option Supervisor）★★★★

- **动机**：反应式 VLA 把长程结构交给数据隐式学习，缺显式阶段状态（P9）；而计分是里程碑步骤分且失败保留已得分（F17/F22），错误推进导致「丢分」的代价大于保守重试（PR6）。需要一个只在决策点工作的轻量层，决定「继续 / 重采样 / 检索 / 恢复 / 停持」。
- **与现有方案差异**：现有方案把 I4/I5/I9/I3 做成并列 guard，各自触发、无统一优先级；ATOS 把它们统一为一条按**期望剩余步骤分**排序的升级阶梯，并用同一个可恢复性价值 V 作为决策货币。它不新增动作策略，只做离散选择。
- **技术可行性**：中-高。选项集 = 官方得分点（若可逆向，F17）或进度分位；Q 值由 V-AD 的 V + I5 估计的「丢失里程碑概率」+ 延迟代价组成；决策策略是一个极浅的决策树/查表，离线拟合，不在线学习。
- **所需资源**：V/丢失概率推理为 MLP + 查表，<2ms；选项执行复用既有模块；1 人周工程 + 1 人周 L0 评估。
- **落地步骤**：①确定决策点定义与迟滞；②实现选项接口（CONTINUE/RESAMPLE/RETRIEVE/RECOVER/HOLD）；③用 I5 合成偏离拟合 Q 与切换策略；④L0 反事实评估（oracle vs 各策略）；⑤3 任务单任务通道 A/B；⑥接入 I8 注册表。
- **风险**：决策点过密 → 抖动与额外延迟（缓解：连续 m 次触发 + 冷却 + 每 episode 升级次数上限）；选项执行本身失败 → 需要选项级超时与回退；单模型边界待确认（见 §8，降级预案 I10'）。

## 2. I11 可恢复性异常检测器（V-AD, Viability-based Anomaly Detector）★★★★

- **动机**：无失败示教、无触觉（P8/F8），传统「离群=异常」既漏检流形内的抓空/打滑，又误报无害的新外观；需要与后果绑定的异常定义（P10）。
- **与现有方案差异**：不训练二分类异常器，而是回归**可恢复性价值 V**（回到下一里程碑的期望剩余步数），异常分数由 V 归一化值 + V 不确定性 + 流形距离 + 动作健康构成；监督来自成功示教与 I5 合成偏离，零失败标签。
- **技术可行性**：中-高。V 是冻结特征上的小回归头（Huber on log(1+V)）+ 一个「超预算不可恢复」分类头；流形距离用 kNN/Mahalanobis；动作健康是确定性规则。
- **所需资源**：V 训练 1 GPU 日/全任务族；kNN 索引 1 GPU 日；1 人周工程。
- **落地步骤**：①从示教抽取 (z_t, k_t, 剩余步数) 标签；②I5 扰动重放生成偏离标签；③训练 V + 不可恢复头；④构建标称嵌入流形与 kNN；⑤按步骤分损失校准阈值；⑥L0 异常基准；⑦真机抽测。
- **风险**：V 在真实异常上外推失真（缓解：OOD 门控，流形距离超阈时不让 V 单独决策，退回保守 HOLD）；里程碑边界不清导致标签噪声（缓解：用进度分位伪里程碑起步，得分点逆向后再替换）；阈值假阳性伤标称（缓解：PR6 损失校准 + 标称零伤害硬门禁）。

## 3. 严格定义

### 3.1 可恢复性价值 V（把异常与规划统一）

设第 k 个里程碑为官方得分点（或进度分位伪里程碑），策略为 π（同一个 VLA），z_t = φ(o_t) 为冻结视觉-语言特征，h_t 为动作历史。定义

  V^π(z, k) = E_π[ min{ n ≥ 0 : k_{t+n} > k } | z_t = z, k_t = k ],

若在剩余预算 T_max 内未到达则记为 V = ∞。V 不是「任务成功率」，而是「从当前偏离状态回到成功轨迹并推进一个里程碑要多少步」——它同时是异常严重度与规划代价。

**离线监督（关键：不需要失败标签）**：
1. 成功示教：对每个 t，令 t' 为首次达成 k+1 的时刻，标签 y_t = t' - t。
2. I5 合成偏离：对成功 eps 在 t 注入受控扰动，再沿原修正段继续，标签 = 从扰动帧到 k+1 的剩余步数；若扰动后无法在原预算内回到 k+1，标为「不可恢复」正类。
3. 训练目标：L = Huber(log(1+V_θ), log(1+y)) + BCE(unrecoverable_θ, label)。

### 3.2 异常分数（三通道 + 一个否决）

  e_t = w_V · q_task(V_θ(z_t,k_t)) + w_U · u_t + w_D · q_task(d_M(z_t)) + w_A · a_t

其中 q_task(·) 为按任务标称分布的分位归一化；u_t 为 V 的预测不确定性（小集成或 MC-dropout 方差）；d_M 为到标称嵌入流形 kNN 距离；a_t 为动作健康度（越界/二阶差分/夹爪抖动/长时间零位移）。融合用加权和而非 max，避免单一通道主导；但动作健康设**否决权**：a_t 触发硬约束时直接 HOLD，不进入规划。

### 3.3 阈值按「步骤分损失」校准（PR6）

在标称留出集与合成异常集上，阈值 τ 的经验损失：

  L(τ) = C_FP · P(e>τ | nominal) · ℓ_esc + C_FN · P(e≤τ | anomaly) · ℓ_miss(τ)

ℓ_esc = 一次不必要升级的期望步骤分损失（含延迟与动作扰动）；ℓ_miss = 漏检导致丢失下一里程碑的期望损失（按剩余预算加权）。因真实异常类型先验未知，用对 5 条泛化轴 + 人干扰 + 接触滑脱的**最坏情况加权**（minimax）选 τ，而不是普通 F1 最优点。

### 3.4 决策规则（不可逆半-MDP）

决策点集合 D = {异常 e_t>τ 连续 m 次} ∪ {进度停滞 g_t>G} ∪ {选项终止} ∪ {人干预结束}。在 u ∈ U = {CONTINUE, RESAMPLE(k), RETRIEVE, RECOVER, HOLD} 上：

  Q(u) = V̂(z_t,k_t | u) + λ · P̂(lose k_t | u) · ℓ_milestone + c(u)

  u* = argmin_{u : latency(u) ≤ budget_remaining} Q(u)

- CONTINUE：V 由当前策略估计；c≈0。
- RESAMPLE(k)：同一 VLA 采样 k 个 chunk，用 V̂ 打分选最小者；c≈(k-1)·L_chunk。
- RETRIEVE：调用 I9 检索先验重设选项；c≈一次检索（<1s，但仅在 reset 或极少数决策点，需预算约束）。
- RECOVER：调用 I5 恢复段 / I3 接触伺服；c≈恢复段推理。
- HOLD：停持等待（人干预时）；V=∞ 但丢分风险≈0，仅当 min Q > ℓ_milestone 或预算将尽时选。

**里程碑状态估计**：隐藏状态 k_t 用单调 HMM 滤波（k 只增，允许小概率回退表示滑脱），发射概率来自进度头；输出 belief b_t(k)，V 用 E_k[V(z,k)]。若官方得分点时序不可得，先用进度分位 k_t = ⌊ρ·p_t⌋ 作伪里程碑，得分点逆向后再替换。

### 4.2 ATOS 的 get_action（事件触发，标称路径零额外开销）

```python
class ATOSPolicy:                         # 仍是唯一 PolicyService
    def reset(self, first_obs=None):
        self.k_belief = self.hmm.init()
        self.last_progress = 0.0
        self.escalations = 0
        self.cooldown = 0
        self.retrieval = self.i9.retrieve(first_obs)   # I9 在 reset 做一次

    def get_action(self, obs):
        z, k = self.feature(obs), self.hmm.argmax(self.k_belief)
        v, u = self.v_net(z, k)                         # V 与不确定性
        e = self.anomaly_score(z, k, v, u, obs)
        self.k_belief = self.hmm.update(self.k_belief, self.progress_head(obs))
        if not self.is_decision_epoch(e, obs):
            return self.vla.propose_chunk(obs)          # 快路径：零额外开销
        if self.cooldown > 0 or self.escalations >= E_MAX:
            return self.vla.propose_chunk(obs)
        u_star = self.choose_option(z, k, e, obs)       # §3.4 的 argmin Q
        self.cooldown = COOLDOWN
        self.escalations += (u_star != CONTINUE)
        return self.execute(u_star, obs)                # 各选项复用 I3/I5/I9/I4

    def execute(self, u, obs):
        if u == CONTINUE:  return self.vla.propose_chunk(obs)
        if u == RESAMPLE:  return self.best_of_n(obs, k=2)      # 仅异常时
        if u == RETRIEVE:  return self.vla.propose_chunk(obs, prior=self.retrieval)
        if u == RECOVER:   return self.i5.recovery_chunk(obs)
        if u == HOLD:      return self.safe_hold(obs)           # I4 停持
```

### 4.3 阈值与升级策略的离线拟合（I8 L0）

```python
def calibrate(scores_nominal, scores_synth, loss_fp, loss_fn_grid):
    best = None
    for tau in candidate_quantiles(scores_nominal, q=range(80, 100)):
        fp = mean(s > tau for s in scores_nominal)
        fn = {ax: mean(s <= tau for s in scores_synth[ax]) for ax in AXES}
        # minimax over anomaly axes（真实先验未知）
        loss = loss_fp * fp + max(loss_fn_grid[ax] * fn[ax] for ax in AXES)
        best = min(best, (loss, tau)) if best else (loss, tau)
    return best
```

## 5. 部署预算分析（F12/F23，PR4 门禁）

单步预算 ≈ 66ms（15Hz）；目标 p99 < 40ms。设单次 chunk 推理实测为 L（待测，按 fp8/compile 估 15–25ms）：

| 路径 | 额外开销 | 触发频率 | 约束 |
|---|---|---|---|
| 标称快路径 | 特征+kNN+V+健康检查 < 5ms | 每步 | 必须始终可用 |
| RESAMPLE(k=2) | +1×L | 仅异常决策点，≤E_MAX 次/集 | 若 L>25ms 则禁用，降为 k=1 重采样 |
| RETRIEVE | 一次检索 <1s | 仅 reset 或极少数点 | 不进每步循环 |
| RECOVER | 1×L + 恢复段 | 仅确认异常 | 选项级超时 |
| HOLD | ≈0 | 人干预/不可恢复 | 安全优先 |

硬规则：`p99_total = max over decision epochs (L + extra + 5ms)`；若超 40ms，按 RESAMPLE→RETRIEVE→RECOVER 顺序裁剪，保留 CONTINUE/HOLD 与 V 检测。所有升级共享每 episode 次数上限 E_MAX（初值 3），防止异常抖动放大延迟。

## 6. 实验设计（分级消融 v2，接入 I8）

| 级别 | 内容 | 成本 | 通过判据 |
|---|---|---|---|
| L0-A | V-AD 异常基准：I1 五轴偏移 + I5 扰动/缝合/抓空，按异常类型报 AUROC、FPR@nominal、检测延迟、损失曲线 | 离线，免费 | 至少「抓空/滑脱/进度停滞」AUROC>0.8；标称 FPR≤5%/集 |
| L0-B | ATOS 反事实：在成功 eps 的已知时刻注入异常，比较 {无监督, 总是重采样, 异常触发, oracle}；指标 = 恢复后步骤分 / 额外步数 / 标称伤害 | 离线，免费 | 标称 Δprog≥0；异常场景恢复率高于无监督 ≥15pp |
| L1 | 2^(k-p) 析因：{V-AD on/off} × {ATOS on/off} × {RESAMPLE k=1/2} × {HOLD 阈值 2 档} | 离线 + 少量真机 | 主效应显著的 ≤3 组合进 L2 |

## 8. 单模型边界与合规（新增确认项）

- V-AD 是冻结特征上的小回归头，ATOS 是离散选择器，动作始终来自同一个 VLA；但「同一 PolicyService 内多组件」是否算单模型，需**书面确认**（与 I3/I9 同一确认项）。
- 若裁定不允许独立监督头：**降级预案 I10'/I11'**——把 V 与不可恢复分类作为训练期辅助损失（多任务头）训进 action expert，推理只用其输出做门控，不加载独立模型；仍保留 HOLD/进度停滞单通道。
- 检索、V、阈值均为离线计算/固定参数，评测期**零权重更新、零在线适应**（诚信红线）；决策点重采样是同一模型的前向多次，不引入新参数。
- 人干预时 HOLD 优先于任何分数优化（PR3），停持动作界内平滑。
