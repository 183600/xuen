### 第 2 轮灵感驱动研究记录

**灵感词**：用户画像、语义建图

**直觉与动机**：
v25 的语义建图证书（SMC）把环境映射为「客观」语义实体，却把人类使用者抽象为一个无差别的「操作员」。然而同一物理场景对不同用户的语义并不相同：一段台阶对轮椅使用者是「不可通行」，对仓库工人是「作业面」，对儿童是「危险区域」。语义建图的本质不是构造世界的唯一真值，而是构造「为某个用户（画像）服务的世界模型」；反之，用户画像的本质是构造「在某个世界（语义地图）中行动的人模型」。二者构成一组对偶：**地图因用户而有意义，用户因地图而可被定位**。核心洞见：**语义建图 = 世界对用户的投影，用户画像 = 用户对世界的投影；可信人机协同要求这两个投影在同一证书框架下双向可验证，并对画像漂移、隐私噪声与群体公平负责**。

**形式化目标**：
1. 定义用户画像 UP：u = (c, p, r, h, q, κ)，即能力向量、偏好分布、风险容忍、交互历史、意图后验、同意状态；并定义画像桶 b(u) 供分组校准。
2. 定义画像条件语义地图 PCSM：M_u = F(O, u)，其语义标签 ℓ_u 与可操作 affordance a_u 均以 u 为条件；给出建图/画像推断的对偶一致性 d_u(Ψ_M(Φ_u(w)), u) ≤ ε_dual。
3. 定义个性化语义证书 PSC：Mondrian 分组 conformal 覆盖 ℙ(ℓ_u(e) ∈ C_{b(u)}(x) | b(u)) ≥ 1-α；分布鲁棒偏好对齐 min_{q'∈KL_δ(q)} E_{q'}[U_u(π)] ≥ U_min；画像统计 (ε_dp, δ_dp)-差分隐私。
4. 定义画像治理证书 PGC：同意 κ∈{granted, revoked, expired}、漂移 D_KL(q_t‖q_ref) ≤ δ_KL、新鲜度 t−t_last ≤ T_stale，任一失效即撤证并回退 v25。
5. 定义个性化公平证书 PFC：分组覆盖差 |cov_g−(1−α)| ≤ δ_fair、分组准入非空 |Adm_g| ≥ n_min、效用极差 ≤ δ_util（保证「保证公平」而非「结果均等」）。
6. 构建十证一体准入门 PC-UC：v25 七证 ∪ PSC ∪ PGC ∪ PFC，Exec_v26 = Exec_v25 ∩ Fil_prof ⊆ Exec_v25，并证明画像缺失/同意撤销/漂移超限/公平违约四条退化路径下的单调退化链保持性。

# ============================================================
# IP-448 Profile-Conditioned Semantic Certificate (PSC)
# ============================================================
@dataclass
class UserProfile:
    """用户画像 u = (c,p,r,h,q,κ)，另附 Mondrian 桶与时间戳"""
    uid: str
    capabilities: Tensor             # c ∈ R^{d_c}
    preferences: 'PreferenceModel'   # p ∈ Δ(𝒯)
    risk_tolerance: float            # r ∈ (0,1)
    history: list['Interaction']     # h
    intent_posterior: 'Posterior'    # q ∈ Δ(𝒰)
    consent: 'ConsentState'          # κ
    bucket: str                      # b(u)
    last_update: float


@dataclass
class ProfileConditionedSemanticCertificate:
    """画像条件语义覆盖 + 分布鲁棒偏好对齐 + 隐私预算 + 对偶一致性"""
    profile: UserProfile
    alpha: float = 0.05
    U_min: float = 0.0
    kl_radius: float = 0.05          # 偏好对齐的后验球半径 δ
    eps_dp: float = 1.0
    delta_dp: float = 1e-5
    eps_dual: float = 0.1            # 建图/画像对偶一致性容差
    mondrian: dict[str, 'MondrianCalibrator'] = field(default_factory=dict)
    label_map: dict[str, str] = field(default_factory=dict)  # 环境标签→画像标签

    def verify_profile_conditioned_coverage(self, observations: Tensor,
                                            entities: list['SemanticEntity']) -> bool:
        """ℙ(ℓ_u(e) ∈ C_{b(u)}(x) | b(u)) ≥ 1-α（Mondrian 分组覆盖）"""
        cal = self.mondrian.get(self.profile.bucket)
        if cal is None:                       # 无该桶校准器 → 拒证
            return False
        pred_sets = cal.predict(observations)  # [N_obs, |L_u|]
        for e in entities:
            ell_u = self.label_map.get(e.semantic_label, e.semantic_label)
            if ell_u not in pred_sets[e.observation_index]:
                return False
        return True

    def verify_preference_alignment(self, plan: 'MultiRobotPlan',
                                    utility_fn: 'ProfileUtility') -> bool:
        """min_{q'∈KL_δ(q)} E_{q'}[U_u(π)] ≥ U_min，用 Pinsker 下界保守化"""
        q = self.profile.intent_posterior
        samples = q.sample(256)              # 后验采样近似
        us = torch.tensor([utility_fn.evaluate(u, plan) for u in samples])
        lo, hi = us.min().item(), us.max().item()
        # KL 球内最坏期望下界：E_q[U] - (hi-lo)·sqrt(δ/2)（TV ≤ sqrt(δ/2)）
        robust_lb = us.mean().item() - (hi - lo) * math.sqrt(self.kl_radius / 2.0)
        return robust_lb >= self.U_min

    def verify_privacy_budget(self) -> bool:
        """画像统计已用隐私预算不超支，且用途在同意范围内"""
        acct = self.profile.consent.accountant
        return (acct.allow_use
                and acct.spent_eps <= self.eps_dp
                and acct.spent_delta <= self.delta_dp)

    def verify_duality(self, world: 'World', map_u: 'SemanticMap',
                       profile_infer: 'ProfileInference') -> bool:
        """d_u(Ψ_M(Φ_u(w)), u) ≤ ε_dual：地图可反推画像（可解释/可定位）"""
        u_hat = profile_infer(map_u, world)
        return profile_distance(u_hat, self.profile) <= self.eps_dual

    def verify_all(self, observations, entities, plan, utility_fn,
                   world=None, map_u=None, profile_infer=None) -> bool:
        ok = (self.verify_privacy_budget()
              and self.verify_profile_conditioned_coverage(observations, entities)
              and self.verify_preference_alignment(plan, utility_fn))
        if world is not None and map_u is not None and profile_infer is not None:
            ok = ok and self.verify_duality(world, map_u, profile_infer)
        return ok


# ============================================================
# IP-449 Profile Governance Certificate (PGC) — 同意/漂移/新鲜度
# ============================================================
@dataclass
class ProfileGovernanceCertificate:
    profile: UserProfile
    q_ref: 'Posterior'
    q_t: 'Posterior'
    delta_kl: float = 0.1
    T_stale: float = 3600.0
    now: float = 0.0
    required_purpose: str = 'assistive_personalization'

    def verify_consent(self) -> bool:
        """同意必须对当前用途有效，且未被撤回/过期"""
        c = self.profile.consent
        return (c.granted and not c.revoked and not c.expired
                and self.required_purpose in c.purposes)

    def verify_drift(self) -> bool:
        """D_KL(q_t‖q_ref) ≤ δ_KL，画像后验不得显著漂移"""
        return kl_divergence(self.q_t, self.q_ref) <= self.delta_kl

    def verify_freshness(self) -> bool:
        return (self.now - self.profile.last_update) <= self.T_stale

    def verify_all(self) -> bool:
        return self.verify_consent() and self.verify_drift() and self.verify_freshness()

    def degraded_profile(self) -> UserProfile:
        """治理失效时退化为总体先验画像 u_0（无个性化，等价 v25）"""
        return POPULATION_PRIOR_PROFILE


# ============================================================
# IP-450 Personalization Fairness Certificate (PFC) — 保证公平
# ============================================================
@dataclass
class PersonalizationFairnessCertificate:
    groups: dict[str, list[UserProfile]]   # g -> 用户列表
    alpha: float = 0.05
    delta_fair: float = 0.02
    delta_util: float = 0.05
    n_min: int = 10

    def verify_coverage_parity(self, coverage_by_group: dict[str, float]) -> bool:
        """各组覆盖都贴近名义 1-α，防止某群体被系统性低覆盖"""
        return all(abs(cov - (1.0 - self.alpha)) <= self.delta_fair
                   for cov in coverage_by_group.values())

    def verify_non_empty_admission(self, admitted_by_group: dict[str, int]) -> bool:
        """任何群体不得被个性化门槛整体排除（防止数字歧视）"""
        return all(n >= self.n_min for n in admitted_by_group.values())

    def verify_utility_parity(self, utility_by_group: dict[str, float]) -> bool:
        """效用极差有界：个性化可不同，但不得造成群体性收益鸿沟"""
        vals = list(utility_by_group.values())
        return (max(vals) - min(vals)) <= self.delta_util

    def verify_all(self, coverage_by_group, admitted_by_group,
                   utility_by_group) -> bool:
        return (self.verify_coverage_parity(coverage_by_group)
                and self.verify_non_empty_admission(admitted_by_group)
                and self.verify_utility_parity(utility_by_group))


# ============================================================
# IP-451 画像条件统一准入门（PC-UC, v26）
# ============================================================
@dataclass
class ProfileConditionedUnifiedCertificate:
    """十证一体：v25 七证 + PSC + PGC + PFC"""
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    psc: ProfileConditionedSemanticCertificate
    pgc: ProfileGovernanceCertificate
    pfc: PersonalizationFairnessCertificate

    def admits(self, multi_plan, sensor_data: dict,
               user_ctx: dict) -> tuple[bool, str]:
        # 0. 治理门：同意/漂移/新鲜度任一失效 → 不授予 v26，显式回退 v25
        if not self.pgc.verify_all():
            return False, 'fallback_v25:profile_governance'
        # 1. v25 七证（USMC + SMC + RMC + MCC）
        if not self.src_usc.admits(
                multi_plan, sensor_data,
                gt_entities=sensor_data.get('gt_entities'),
                queries=sensor_data.get('queries'),
                retrieved=sensor_data.get('retrieved')):
            return False, 'v25_reject'
        # 2. 个性化语义证书（画像条件覆盖 + 偏好对齐 + 隐私 + 对偶）
        if not self.psc.verify_all(
                sensor_data['semantic_observations'],
                user_ctx['entities_u'], multi_plan, user_ctx['utility_fn'],
                world=user_ctx.get('world'),
                map_u=user_ctx.get('map_u'),
                profile_infer=user_ctx.get('profile_infer')):
            return False, 'v26_reject:psc'
        # 3. 个性化公平证书
        if not self.pfc.verify_all(
                user_ctx['coverage_by_group'],
                user_ctx['admitted_by_group'],
                user_ctx['utility_by_group']):
            return False, 'v26_reject:pfc'
        return True, 'v26_admit'

        self.ipam.register_module("pfc", ["IP-450"],
            ["group_coverage_parity", "non_empty_admission",
             "utility_parity"])
        self.ipam.register_module("pc_uc", ["IP-451"],
            ["ten_certificate_gate", "profile_conditioned_monotonic_chain"])

    def step(self, multi_sensor_data: dict,
             user_ctx: dict) -> tuple[bool, dict]:
        # 1. v25 单机/语义/重构/协同更新（复用）
        base_ok, base_info = self._v25_step(multi_sensor_data)
        if not base_ok:
            return False, {'stage': 'v25', 'details': base_info}

        # 2. 画像更新：融合观测 → 后验 → Mondrian 桶 → 隐私记账
        self._update_profile(multi_sensor_data, user_ctx)
        # 3. 画像条件语义地图更新
        map_u = self._build_profile_conditioned_map(multi_sensor_data, user_ctx)
        user_ctx['map_u'] = map_u
        user_ctx['entities_u'] = map_u.entities

        # 4. 十证准入（治理失效则显式回退 v25，不静默个性化）
        multi_plan = self._plan_from_consensus(multi_sensor_data)
        admitted, mode = self.pc_uc.admits(multi_plan, multi_sensor_data, user_ctx)
        return admitted, {
            'mode': mode,
            'multi_plan': multi_plan if admitted else None,
            'profile': {
                'consent_ok': self.pc_uc.pgc.verify_consent(),
                'drift_ok': self.pc_uc.pgc.verify_drift(),
                'freshness_ok': self.pc_uc.pgc.verify_freshness(),
                'coverage_ok': self.pc_uc.psc.verify_profile_conditioned_coverage(
                    multi_sensor_data['semantic_observations'],
                    user_ctx['entities_u']),
                'alignment_ok': self.pc_uc.psc.verify_preference_alignment(
                    multi_plan, user_ctx['utility_fn']),
                'privacy_ok': self.pc_uc.psc.verify_privacy_budget(),
            },
            'fairness': {
                'coverage_parity_ok': self.pc_uc.pfc.verify_coverage_parity(
                    user_ctx['coverage_by_group']),
                'admission_nonempty_ok': self.pc_uc.pfc.verify_non_empty_admission(
                    user_ctx['admitted_by_group']),
                'utility_parity_ok': self.pc_uc.pfc.verify_utility_parity(

    def _update_profile(self, data: dict, user_ctx: dict):

        u.intent_posterior = user_ctx['q_t']
        u.bucket = bucketize(u.capabilities, u.risk_tolerance)
        u.last_update = data['now']

    def _build_profile_conditioned_map(self, data: dict, user_ctx: dict):

        return profile_conditioned_map(data['semantic_observations'],
                                       user_ctx['profile'])

## 3. 正确性论证（增量）

### 定义 1（画像-语义对偶）
设世界状态 w ∈ 𝒲，建图映射 Φ_u: 𝒲 → ℳ 以画像 u 为条件给出 M_u = Φ_u(w)；画像推断映射 Ψ_M: ℳ × 𝒲 → 𝒰 从地图与交互反推 û = Ψ_M(M_u, w)。称 (Φ, Ψ) 在 u 处 ε_dual-对偶一致，若 d_u(Ψ_M(Φ_u(w)), u) ≤ ε_dual 对 w 的支撑集成立。直观：**地图必须「可被反读」为用户模型**，否则个性化就是不可解释、不可追责的暗箱。

### 引理 13（画像条件语义证书的覆盖-对齐-隐私-对偶四重保证）
**陈述**：`PSC.verify_all(...) = True` ⟹ 个性化语义层同时满足：
(1) Mondrian 分组 conformal 覆盖 ℙ(ℓ_u(e) ∈ C_{b(u)}(x) | b(u)) ≥ 1-α，
(2) 分布鲁棒偏好对齐 min_{q'∈𝒫_δ(q)} E_{q'}[U_u(π)] ≥ U_min，
(3) 画像统计 (ε_dp, δ_dp)-差分隐私且用途在同意范围内，
(4) 建图/画像 ε_dual-对偶一致。

**证明**：
1. 对每个画像桶 b，以桶内校准集 D_b 计算非一致性分位数 q_b = Quantile_{⌈(n_b+1)(1-α)⌉/n_b}。由 Mondrian conformal prediction（Vovk et al. 2005; Angelopoulos & Bates 2021），在桶内可交换性下，P(Y ∈ C_b(X) | b) ≥ 1-α。分组校准避免了「边际覆盖达标但少数群体被系统性低覆盖」的陷阱。
2. 设 U_u(π) ∈ [lo, hi]。对任意 q' 满足 D_KL(q'‖q) ≤ δ，由 Pinsker 不等式 TV(q',q) ≤ √(δ/2)，故 |E_{q'}[U] − E_q[U]| ≤ (hi−lo)·TV ≤ (hi−lo)√(δ/2)。于是 min_{q'}E_{q'}[U] ≥ E_q[U] − (hi−lo)√(δ/2) = robust_lb。robust_lb ≥ U_min 即为充分条件。
3. Gaussian 机制以 σ ≥ Δ_2(A)√(2ln(1.25/δ_dp))/ε_dp 释放画像统计，满足 (ε_dp,δ_dp)-DP；DP 的后处理不变性保证下游个性化不会额外泄漏。隐私会计记录累计 spent_eps/spent_delta，超预算即拒证。
4. 对偶一致性由 `verify_duality` 直接检查 d_u(û,u) ≤ ε_dual；它把「地图是否忠实服务于该用户」从主观判断变成可测距离。
∎

### 引理 14（画像治理的撤证-退化单调性）
**陈述**：若 `PGC.verify_all() = False`（同意撤回/漂移超限/过期），则 PC-UC 不授予 v26 准入，且系统退化为以总体先验 u_0 运行的 v25 执行集，即 `Exec_v26(失效) = Exec_v25 ⊇ Exec_v26(正常)`。

**证明**：PC-UC.admits 的第一条即 `if not pgc.verify_all(): return False`，故失效时无 v26 准入。以 u_0 替换 u 后，ℓ_{u_0} 退化为与画像无关的通用语义标签、a_{u_0} 退化为通用 affordance、PSC 退化为 v25 的 SMC，PFC 退化为单组平凡约束，故可用执行集恰为 Exec_v25。由于 Exec_v26 = Exec_v25 ∩ Fil_prof，恒有 Exec_v26 ⊆ Exec_v25。漂移有界时还有定量保证：若 D_KL(q_t‖q_ref) ≤ δ_KL，则真实用户效用相对认证值的偏移 ≤ (hi−lo)√(δ_KL/2)（同引理 13 第 2 步），故 PGC 的 δ_KL 阈值直接给出「认证效用—真实效用」的误差上界。
∎

### 引理 15（个性化公平的保证公平与不排斥性）
**陈述**：若 `PFC.verify_all(...) = True`，则对任意用户组 g∈G：
(a) 覆盖保证差 |cov_g−(1−α)| ≤ δ_fair，即个性化不牺牲任何群体的统计安全保证；
(b) 准入非空 |Adm_g| ≥ n_min，即不存在被个性化门槛整体排斥的群体；
(c) 效用极差 ≤ δ_util，即个性化收益不形成群体性鸿沟。
且当某组违约时，仅对该组关闭个性化并回退到组无关的 v25 保守策略，其他组不受影响，单调链仍成立。

**证明**：(a)–(c) 分别是 `verify_coverage_parity`、`verify_non_empty_admission`、`verify_utility_parity` 的定义展开。关键在于公平约束作用在「保证」而非「结果」：不同能力/偏好的用户允许获得不同动作与不同效用（个性化），但必须获得同样的覆盖风险上界与不被排斥的准入权。违约时的逐组回退是交集的局部化：Exec_v26 = Exec_v25 ∩ (∩_g Fil_g)，去掉某组过滤器只会扩大该组可用集，不会使整体超出 Exec_v25，故单调性保持。
∎

### 引理 16（十位一体单调退化链终极延伸）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加四条退化路径：
- **画像缺失/新用户冷启动** → 无桶校准器或后验为平坦先验 → PSC 拒证 → 退回 `Exec_v25`：使用总体先验 u_0 的通用语义地图，关闭个性化。
- **同意撤销/用途不符/画像过期** → `PGC.verify_consent/freshness=false` → PC-UC 拒证 → 退回 `Exec_v25`：删除/冻结个性化画像，仅保留匿名化通用语义。
- **画像漂移超限** → `PGC.verify_drift=false` → PC-UC 拒证 → 退回 `Exec_v25`：以参考后验 q_ref 的保守画像运行，或触发重新校准窗口。
- **公平违约** → `PFC.verify_*=false` → 对该组关闭个性化并回退组无关策略 → 该组可用集回到 `Exec_v25`，其余组保持 v26。
- **组合失效**：取交集，`Exec_v26` 进一步收缩，单调性由交集保持。
∎

### 定理（PC-UC 十证准入门的安全-合规-可部署-可保护-结构-语义-重构-协同-个性化-治理-公平完备性）
**陈述**：对任意多机计划 Π 与用户画像 u，`PC-UC.admits(Π,u) = True` ⟺ Π 同时满足：
(1)–(10) v25 的十项条件（物理接地、云边一致、少样本 conformal、专利保护、结构/力控/轻量、语义、重构、协同）；
(11) 画像条件语义覆盖、分布鲁棒偏好对齐、画像差分隐私、建图/画像对偶一致四重达标；
(12) 画像治理（同意/漂移/新鲜度）三重达标；
(13) 个性化公平（覆盖/准入/效用）三重达标。

**证明**：`PC-UC.admits` 是 (1)–(13) 的合取。必要性：任一条件缺失即返回 false（治理门先于 v25，其余后于 v25），对应风险表 R16–R21 中某一类未被缓解。充分性：前七证由引理 4、8、12 给出单机到群体的安全闭环；PSC 由引理 13 给出「地图—用户」投影的统计与鲁棒保证；PGC 由引理 14 给出撤证与退化；PFC 由引理 15 给出群体保证公平；四者合取即十证一体，且由引理 16 保持单调退化链。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**用户画像的分布漂移、隐私噪声与效用函数误设，会使「画像条件语义证书」在「模型中的用户」与「真实用户」之间产生系统性错配——证书越精确，越可能在用户能力或意图已改变、或群体公平被悄然侵蚀时仍判定个性化计划安全，从而把 v25 的「事前拦截」退化为「对错误用户的精确合规」。**
