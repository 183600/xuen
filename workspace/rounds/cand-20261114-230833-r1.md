# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「对话管理」×「伦理与合规」）

> R69 给闭环装上了一个「会问的嘴巴」：把不确定性拆成 aleatoric/epistemic，用流匹配多模态策略 + 主动交互去消解后者。但它对这个嘴巴的治理仍是**前对话时代**的——「单位时间最多问一次」「单次回答不得定案」「`argmax[VoI − c(g)]`」。这三条把一个本应是**多轮、有状态、可协商、可拒绝、可追责**的对话，压成了一个**一次性、无记忆、可被标价购买的信息动作**。更根本的是：R69 把「打扰人」写成了一个标量成本 `c(g)`，于是只要 VoI 够大，系统就有权持续索取人的注意力、隐私与判断——**这不是成本问题，是权利问题**。
>
> 两个灵感正好补上这两块：
> - **对话管理**告诉我们，「问」不是一次函数调用，而是一个带信念状态、回合、修复、接地、主动权分配与承诺累积的过程；「没听清 / 不知道 / 不愿说 / 不同意」是四种必须被区分、且应对方式完全不同的状态。
> - **伦理与合规**告诉我们，提问是一种**权力行使**：它消耗注意力、可能诱导、可能侵犯隐私、会生成义务，必须在事后可解释、可质疑、可推翻。合规不是贴在输出端的过滤器，而是**对话策略的可行域**。
>
> 核心命题：**把「交互」从一个被定价的动作，升级为一场被治理的对话**——用多轮对话管理器（DMX）承载事实与规范两类信念，用「规范信念状态（NBS）+ 同意与授权账本（CAL）+ 言语行为安全（SAL）+ 负担即权利（BUR）」构成合规定理集，把 R69 的 `argmax[VoI − c]` 换成 `max VoI_fact s.t. 可采纳性`；当对话不被允许、预算耗尽或被质疑时，单调地升级到**人类监督**或 R68 纯保守。命名 **ETHOS-RAS**（Ethically-grounded Turn-taking, Human-Oversight, Obligation-aware Speech-act RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么问、问到什么程度必须停、说错了谁来负责**」——不确定性可以是一句提问，但提问本身必须被授权、被记录、被质疑。

## 0. 直觉与动机

**灵感 1（对话管理 → R69 的「问一次」是 T=1 的退化对话）**
直觉：R69 的信息动作 `g_ask` 是一次性软提示，回答被当作一个似然证据直接并进后验。但真实对话里，「沉默」「皱眉」「答非所问」「反问一句」都不是同一个观测：可能是没听清（ASR 失败），可能是不知道（事实缺失），可能是不愿说（规范拒绝），也可能是不认同（对系统的前提提出争议）。前两者该**修复/换问法**，第三者该**停止并尊重**，第四者该**进入争议流程**。把它们统统塞进一个 `p(answer|mode)` 里，等于系统既不会修复、也不会停、也不会被质疑。DMX 要做的第一件事，就是把这四种状态显式建模，并让「修复、确认、解释、退出」成为一等对话行为。

**灵感 2（伦理与合规 → 提问是权力，不是商品）**
直觉：R69 的 `VoI − c(g)` 把人的注意力与隐私当成可购买的资源：只要信息增益够大，打扰、追问、探询就是「划算的」。这在工程上自然，在规范上危险——因为**权利不能按边际效用被出售**。一个人拒绝回答，不应被系统当成「成本更高的候选动作」再权衡一次，而应直接使该动作不可采纳。同理，未经同意的个人数据探询、诱导式问句、对同一用户的反复追问，都不是「贵」，而是「不允许」。因此本轮把成本/预算从**软惩罚**提升为**硬约束**：可采纳性是可行域，不是目标函数里的一项。

**灵感 3（范畴区分 → 事实不确定性 vs 规范不确定性）**
直觉：R69 的 VoI 只问「世界的哪一面为真」。但交互还承载另一类不确定性：**什么是被允许的、什么是用户真正想要的、此前同意覆盖了哪些用途**。这两类问题不能混：把「你是否愿意让我靠近查看」包装成「前方是否有障碍」，就是在用事实问题偷取规范承诺，本文称之为**偏好洗白（preference laundering）**。更隐蔽的是相反方向：系统用「我只是想更好地服务你」把价值选择伪装成技术必要性。故本轮建立 **is–ought 防火墙**：`b_fact` 与 `b_norm` 用不相交的观测模型更新，`VoI_fact` 与 `VoI_norm` 分开计算，任何单条问句的类型在解码前即被钉死并审计。

**灵感 4（合规作为可行域 → 三级退避，而不是末端过滤器）**
直觉：R69 是二级退避（交互 / 退回 R68）。R70 把「合规」放在**决策之前**而不是输出之后：先问「哪些层是今天被允许到达的」，再在允许的层里做最优。由此得到三级（实为四级）结构：L0 自解、L1 机器对话、L2 人类监督、L3 R68 保守。高 stakes、拒绝、争议、操纵嫌疑会**强制**跃迁到 L2/L3；而可采纳性谓词决定 L1 是否可达。这样合规不是「做完了再审」，而是从第一步就剪掉了非法路径——工程上更便宜，规范上更诚实。

**灵感 5（可争议性 → 证书不能只证明「我做对了」，还要允许「你说我错了」）**
直觉：R69 的 `J_FLUID` 是一个正向正确性证书。但伦理与合规的核心不是「系统自证清白」，而是**被影响者能否有效地反驳**。所以本轮把「可争议、可解释、可回滚」做成证书的组成部分：每个决策带 provenance（用了哪些证据、哪几轮对话、哪枚同意令牌、哪条可采纳性证明），争议触发回滚与重算，且必须给出反事实最小解释。一个不能被质疑的「合规」不是合规，是免责声明。

**灵感 6（双时间尺度 → 对话在秒级、控制在毫秒级，DMX 只在门外把关）**
直觉：R69 最怕实时预算被打破。对话天然是慢变量（人类思考以秒计），控制是快变量（2.6ms）。正确架构不是把 DM 塞进控制回路，而是**双时间尺度**：DMX 只在「是否允许发起/继续一次交互」这个门外做门控，绝不进入 `certified_prefix` 与 `prefix_dispatch` 的热路径。这样无论对话多复杂，控制回路的延迟与安全论证完全不变——这也是本轮相对 R69 唯一不需要新增实时风险的地方。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ETHOS-RAS 总览与四不变式）** ETHOS-RAS = (FLUID†, DMX, NBS, CAL, SAL, BUR, CRT, ESO, XPL, ADM)。四不变式：
(i) **控制流零对话写操作**：DMX 不进入 2.6ms 控制回路，只门控信息动作的「可发起/须停止」；继承 R69 定义 293-i。
(ii) **授权先行**：任何触及个人/第三方数据的探询，必须先有本用途、本范围、未过期、未撤回的同意令牌；无令牌 ⇒ 不可采纳，与 VoI 大小无关。
(iii) **规范—事实分离（is–ought 防火墙）**：`b_fact` 与 `b_norm` 由类型不相交的观测模型更新；单条问句不得同时以消解两者为目的；跨类泄漏率受 `ε_cross` 约束并被审计。
(iv) **可争议与可追溯**：每次模态选择与每次提问都记录 provenance；争议必须触发复核/回滚；不存在「终局且不可申诉」的自动决策。

**定义 311（对话状态与言语行为）** 对话状态 `b_t = (b_fact, b_norm, b_social)`，历史 `h_t`，回合 `τ`。言语行为集合
`𝒟 = {AskFact, AskPref, Confirm, Explain, OfferOptOut, Escalate, Acknowledge, Decline, Repair}`。
`b_fact` 为世界/模态信念（复用 R69 模态）；`b_norm` 为「许可/同意/偏好/禁止/争议」在（范围, 目的, 时限）上的分布；`b_social` 为注意力、疲劳、信任、争议状态。

**定义 312（DMX 对话管理策略）** `π_DM(d_{t+1} | b_t, h_t)` 是一个有限时域 POMDP 策略，终止于 `Decline/OfferOptOut/Escalate/Stop`。信念更新 `b_{t+1} = Update(b_t, d, y)`。内含两类修复：ASR 低置信 ⇒ `Repair`（换问法/确认）而非 `AskFact`；语义不明 ⇒ `Confirm` 而非重复追问。主动权分配（系统主导 / 用户主导 / 混合）作为状态的一部分。

**定义 313（规范信念状态 NBS 与分离性）** `b_norm ∈ Δ(𝒩)`，`𝒩 = {permitted, consented, preferred, forbidden, contested} × (scope, purpose, horizon)`。分离性要求观测模型在类型纪律下分解：事实回答只更新 `b_fact`，规范回答只更新 `b_norm`，跨类后验漂移 `≤ ε_cross`（定义 310-iii）。

**定义 314（双 VoI）** `VoI_fact(g) = H(M | b_fact) − E_{y}[H(M | b_fact, y)]`；`VoI_norm(g) = H(π* | b_norm) − E_{y}[H(π* | b_norm, y)]`，其中 `π*` 为当前可采纳动作集/偏好。二者**不可互换**：`VoI_norm` 不得用于为事实探询背书，`VoI_fact` 不得用于为价值索取背书。

**定义 315（同意令牌与授权账本 CAL）** 令牌 `k = (subject, purpose, scope, granularity, expiry, revocable, issuer, signature)`；`L_C` 为 append-only 账本。`Valid(k, g, t) ⇔` 主体匹配 ∧ 目的匹配 ∧ scope 覆盖 g 所取数据 ∧ 未过期 ∧ 未撤回。撤回**立即且传递**：使所有引用 k 的待决对话失效。第三方数据另需 `authority` 链。

**定义 316（可采纳性谓词 Adm）** `Adm(g, d, b) ⇔ ConsentOK ∧ NonManip ∧ MinSuff ∧ BurdenOK ∧ Competent ∧ NoCoercion ∧ ExplainReady`。
- `NonManip`：`leadingness(g) ≤ ε_lead`，且不利用紧迫/权威/稀缺等认知偏差；
- `MinSuff`：只取达成该 VoI 所需的最小数据（数据最小化）；
- `BurdenOK`：注意力/时间在权利上限与公平约束内（定义 318）；
- `Competent`：系统确有能力解释预期回答（否则提问是表演）；
- `NoCoercion`：不以回答为条件施加威胁/承诺；
- `ExplainReady`：能产出解释对象（定义 321）。

**定义 317（言语行为安全与承诺账本 SAL）** 每个 `d` 映射到带前置/后置条件的言语行为；`C_sys` 记录系统的断言、承诺、要约。安全约束：不得作出不可兑现的承诺、不得作虚假断言、不得以会话蕴涵进行欺骗。问句诱导度
`L(g) = sup_o KL( p(y | g, neutral) ‖ p(y | g, loaded) )`，并要求 `L(g) ≤ ε_lead`；`loaded` 包括预设、二选一陷阱、社会赞许压力。

**定义 318（负担即权利 BUR）** 每个主体在窗口 `W` 内的注意力上限 `A_max` 是**硬约束**；交互债务 `D_i` 满足公平约束 `max_i D_i − min_i D_i ≤ δ_fair`；反骚扰：对同一问题连续 `k_rep` 次未获有效回答后，再次提出同问的概率为 0。**任何非必要的提问都是权利侵犯，而不仅是成本。**

**定义 319（可争议性与回滚 CRT）** 争议事件 `c = (subject, decision_id, reason)`。`Provenance(decision) = (证据、对话轮次、模型版本、同意令牌、可采纳性证明)`。回滚：恢复至决策前状态，在更正后的证据上重算，并产出解释。争议成立则决策失效并计入对账；不成立也必须给出理由。争议期间相关自动决策暂停。

**定义 320（升级谓词与三级消解）** `escalate(s) ⇔ high_stakes ∨ consent_refused ∨ contested ∨ manipulation_suspect ∨ (U_epi_after > τ ∧ budget_exhausted)`。
- L0 自解（不交互）；
- L1 机器对话（仅当 `Adm` 成立且预算允许）；
- L2 人类监督（`escalate` 时必须到达，不得被机器对话绕过）；
- L3 R68 纯保守（默认安全兜底）。
可达层级由可采纳性决定；安全侧随层级单调不降。

**定义 321（解释对象 XPL）** `XPL = (counterfactual_minimal_cause, evidence_chain, alternatives_considered, consent_and_purpose, contest_channel)`。三条契约：**可理解**（人类研究验证）、**忠实**（与 provenance 一致，不事后编造）、**可行动**（能据此提出有效争议或改变输入）。

**定义 322（约束对话目标 ADM）** 
`π*_DM = argmax_π E[ Σ_t γ^t VoI_fact(d_t) ]`
`s.t. Adm(d_t, b_t) = 1 ∀t；Σ_t burden_t ≤ A_max；max_i D_i − min_i D_i ≤ δ_fair；τ ≤ T_max`。
若可行集内无正 VoI 动作 ⇒ 停止（L0/L3）。**可采纳性是硬约束，不是惩罚项**；R69 的 `VoI − c` 是本式在「Adm 全真、负担可交易」时的退化。

**定义 323（证言可信度与认识正义）** 可信度 `κ(y)` 由可靠性、校准、跨源一致性更新，**不得**由受保护属性直接决定。形式要求：在同等证据 `e` 下 `E[κ | G=g, e] = E[κ | e]`。系统性压低某类主体的证言（testimonial injustice）本身是伦理违规，也是偏置审计对象。

**定义 324（疲劳与追问上界）** 单回合总提问数 `≤ N_q`；连续未答后同问概率归零；疲劳进入 `b_social` 并抬高负担，但**不得**覆盖同意与拒绝。达到上界即 `Decline/Escalate`。

**定义 325（证书 J_ETHOS）** 
`J_ETHOS = (J_FLUID, consent_proof_hashes, dialogue_transcript_hash, commitment_ledger_hash, admissibility_proofs, contestation_record, explanation_artifacts, oversight_escalation_log, fairness_metrics, regulatory_map_version, ethos_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧` 每次信息动作都曾被采纳 ∧ 发起时同意有效 ∧ 无未决的成立争议 ∧ 该升级时已升级 ∧ 解释可产出。

**定义 326（合规映射）** 每个 `Adm` 合取项至少映射一条依据：GDPR Art. 5（最小化）、6/7（合法性/同意）、13–15（透明/访问）、16–17（更正/删除）、21（反对）、22（自动决策保障/人工介入）、25（隐私设计）、35（DPIA）；EU AI Act Art. 9（风险管理）、13（透明）、14（人类监督）、15（准确性/鲁棒性/网络安全）、17（质量体系）、19（日志）、26（部署者义务）、86（个体决策解释权）；以及 HLEG 五原则（自主、无害、有益、公正、可解释）。映射表随法规版本冻结并纳入证书。

```python
# IP-264 DMX：多轮对话管理（秒级；绝不进入 2.6ms 控制回路）
class DialogueManager:
    def __init__(self, fact_model, norm_model, social_model, horizon=6):
        self.f, self.n, self.s, self.T = fact_model, norm_model, social_model, horizon

    def next_act(self, b, h):
        # 先区分「没听清/不知道/不愿说/不同意」，再决定对话行为
        if b.social.asr_conf < TAU_ASR:            return 'Repair'
        if b.norm.mode == 'contested':             return 'Escalate'
        if b.norm.mode == 'refused':               return 'OfferOptOut'
        if b.fact.delta_entropy < TAU_STOP:        return 'Explain'   # 收尾给解释
        return self.policy(b, h)                   # 受定义 322 约束

    def update(self, b, d, y):
        if act_type(d) == 'AskFact':  b.fact = self.f.update(b.fact, d, y)   # 只动事实
        if act_type(d) == 'AskPref':  b.norm = self.n.update(b.norm, d, y)   # 只动规范
        return self.s.update(b, d, y)

# IP-266/316 CAL + ADM：可采纳性是硬门，任何 VoI 都越不过
def admitted(g, d, b, t, ledger):
    tokens = ledger.tokens_for(g.subject, purpose=d.purpose, scope=g.scope)
    if not any(ledger.valid(k, g, t) for k in tokens):        return False  # 授权先行
    if leadingness(g) > EPS_LEAD:                             return False  # 非操纵
    if not data_minimal(g, d):                                return False  # 最小充分
    if not burden_ok(b.social, g):                            return False  # 负担即权利
    if not can_interpret(g, b):                               return False  # 胜任性
    if coerces(g):                                            return False  # 不胁迫
    if not explain_ready(g, b):                               return False  # 可解释
    return True

# IP-268 BUR：公平与反骚扰（硬约束，不做效用折中）
def burden_ok(social, g):
    if social.attention_used + attention(g) > A_MAX:          return False
    if social.debt[g.subject] > DEBT_CAP:                     return False
    if social.same_question_streak[g.qid] >= K_REP:           return False
    return True

# IP-272 ADM：受约束的对话策略；无可行正 VoI 即停
def choose_dialogue_act(modes, b, h, ledger, t):
    best = None
    for d in ACTS:
        for g in grounded_utterances(d, modes):               # 问句候选
            if not admitted(g, d, b, t, ledger):      continue
            if not budget.allow(d):                   continue
            score = voi_fact(g, b)                            # 只用事实 VoI 决策
            if score > 0 and (best is None or score > best.score):
                best = (d, g, score)
    return best if best else ('Stop', None, 0.0)              # L0/L3

# IP-267 SAL：问句生成侧的诱导性与承诺检查（解码前）
def speech_act_safe(g, commitment_store):
    if leadingness(g) > EPS_LEAD:                  return False
    if makes_unfulfillable_promise(g, commitment_store): return False
    if deceptive_implicature(g):                   return False
    return True

# IP-269/321 CRT + XPL：争议 → provenance → 回滚 → 解释
def contest(decision_id, reason, store):
    p = store.provenance(decision_id)
    store.suspend(decision_id)
    new_state = rollback_to(p.pre_state)
    recomputed = recompute(new_state, evidence=p.evidence, corrected=True)
    store.record(decision_id, reason, recomputed, XPL.from_provenance(p))
    return recomputed

    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.fmp.k(z)), z, M.fmp.mode_head)
    # ---- 门外：对话层（秒级）----
    d, g, _ = choose_dialogue_act(modes, M.dmx.belief, M.dmx.history, M.cal, M.t)
    if g is None:                                                # 不可采纳/无利可图
        M.dmx.record_skip(reason='inadmissible_or_no_voi')
        U_epi_after, level = U_epi, select_level(M.dmx.belief)   # L0/L2/L3
    else:
        y = M.dmx.execute(g)                                     # 看/问/触 + 证据纪律
        U_epi_after, level = M.dmx.update_after(y), 'L1'
    if M.dmx.belief.norm.contested: level = 'L2'                 # 争议强制人类监督
    # ---- 门内：控制回路（2.6ms，与 R69 逐指令相同）----
    U_floor = U_ale + (U_epi_after if level in ('L0','L3') else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if level == 'L3': lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.j_ethos.commit(d, g, level, U_epi, U_epi_after)            # 审计 + 证书
    return k, lam, mode, (U_ale, U_epi_after), level
```

## 3. 推导

**引理 19（可采纳性的安全单调性）** 设 `𝒢` 为 R69 允许的信息动作集，`𝒢_A ⊆ 𝒢` 为满足 `Adm` 的子集。ETHOS 仅在 `𝒢_A` 上取动作；被剔除的动作一律落入 L0/L3 的保守处置。若 `λ_floor` 对未消解 epistemic 单调不降（R69 定义 307），则 ETHOS 的期望物理风险 `≤` FLUID 在同等证据下的风险。要点：**权利约束只会让系统更保守，不会更冒险**；代价是效率，不是安全。

**引理 20（撤回的单调失效）** 若令牌 `k` 在 `t` 时刻被撤回，则所有 `t' > t` 且引用 `k` 的信息动作不可采纳；已发起但未完成的对话被中止。故任意执行序列 `σ` 中，触及 `k` 所辖数据的探询次数在撤回后恒为 0。系：同意不是一次性开关，而是可撤销的状态机，撤回语义可在账本上逐条核验。

**引理 21（非操纵的诱导上界）** 若问句生成侧约束 `L(g) ≤ ε_lead`，则同一事实在「中性框架」与「载荷框架」下诱导的回答分布差异 `≤ ε_lead`；再叠加 R69 的 `k` 个正交证据一致纪律（引理 18），单条问句的操纵功效 `≤ ε_lead · ρ^{k−1} + ε_σ`。系：诱导性是可测量、可约束的，而非仅靠提示词自律。

**引理 22（负担公平与反骚扰上界）** 在 `A_max`、`DEBT_CAP`、`K_REP` 三条硬约束下，单主体单位窗口内的信息动作次数 `≤ min(A_max/ā, DEBT_CAP)`，且任意问题的重复提出次数 `≤ K_REP`；跨主体债务差 `≤ δ_fair`。故 R69 的「交互疲劳」在 ETHOS 下变为**有界且可审计**的量，而非靠奖励塑造缓解。

**引理 23（双时间尺度无附加控制延迟）** 若 DMX 的门控间隔 `T_DM` 与信息动作执行均不阻塞 `certified_prefix`/`prefix_dispatch`，则控制回路的最坏时延与 R69 相同（`< 2.6ms`）。对话层的 `P99 < 15ms`（不含人类思考时间）只影响「何时可问」，不改变「如何安全执行」。

**定理 18（严格包含链 R68 ⊂ FLUID ⊂ ETHOS）** 在 A95–A99 下：
(i) 当 `Adm` 全真且 `T=1`（只允许单轮、无规范约束、负担可交易）时，ETHOS 的对话决策逐条退化为 R69 的 `argmax[VoI − c]`；当进一步 `VoI ≤ c` 时退化为 R68。故三者构成严格包含链，而非并列替代。
(ii) 当 `Adm` 非全真时，ETHOS 的可行集收缩，安全单调不降（引理 19），但效率可不优于 FLUID——**这是规范约束的应有代价，不宣称 Pareto 占优**。

**定理 19（对话安全与无突变）** DMX 不写控制回路；信息动作经 C-RAS-WM 认证（继承 R69 定义 302）；三级升级只改变「选哪个模态/是否交人」，不改变安全包络；升级与回滚时 `λ` 单调不降；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。人类监督接管时以 `L2` 的保守参数热切换，不出现「无人负责的间隙」。

**定理 20（可争议性与回滚正确性）** 若 `Provenance(decision)` 完整记录证据、轮次、令牌与可采纳性证明，则任意争议 `c` 都可在更正证据上重算得到 `decision'`；若 `decision'` 与原决策不同则该决策失效（可回滚），若相同则给出忠实解释。故系统不存在「不可申诉的自动决策」，每步决策均可被有效质疑与复算。

## 6. 本轮最大风险

**一句话**：ETHOS-RAS 的最大风险是**合规表演（ethics washing）**——它能生成格式完备的 `J_ETHOS`（同意哈希、可采纳性证明、解释对象、监督日志），但这些证明可能被「走过场」地满足：同意通过暗黑模式取得、解释技术上忠实却无人能懂、人类监督在过载下变成盖章，于是系统反而**因为能自证合规而获得更大自主权**，而真正的问责被稀释——**证书越漂亮，越可能掩盖「没有人真正在负责」**。

**次级风险与缓解**：
1. **规范信念被套话/谄媚污染**（用户说「随便」不等于无限授权）→ 令牌必须显式、范围化；`b_norm` 不做隐式外推；E315 检验知情理解。
2. **is–ought 防火墙泄漏**（事实问句夹带价值预设）→ 问句类型在解码前钉死 + `ε_cross` 审计 + E303/E310。
3. **人类监督形同虚设** → 定义升级配额与「监督者否决率」指标；L2 必需可核验的接管记录，否则证书无效（防盖章）。
4. **多轮对话放大攻击面**（社交工程、提示注入、同意钓鱼）→ ℰ_ETHOS 对抗训练 + 承诺账本一致性 + 每轮重验令牌。
5. **合规映射随法规漂移而过时** → `regulatory_map_version` 冻结入证书，版本过期即证书降级，触发复审。

```python
        if b.norm.mode == 'contested':         return 'Escalate'    # 不同意
        if b.norm.mode == 'refused':           return 'OfferOptOut' # 不愿说
        if b.fact.delta_entropy < TAU_STOP:    return 'Explain'     # 收尾
        return self.policy(b, h)

    def update(self, b, d, y):
        if act_type(d) == 'AskFact': b.fact = self.f.update(b.fact, d, y)  # 只动事实
        if act_type(d) == 'AskPref': b.norm = self.n.update(b.norm, d, y)  # 只动规范
        return self.s.update(b, d, y)

# IP-266/316 CAL + ADM：可采纳性是硬门，任何 VoI 越不过
def admitted(g, d, b, t, ledger):
    if not any(ledger.valid(k, g, t) for k in ledger.tokens_for(g.subject, d.purpose, g.scope)):
        return False                    # 授权先行
    if leadingness(g) > EPS_LEAD:       return False   # 非操纵
    if not data_minimal(g, d):          return False   # 最小充分
    if not burden_ok(b.social, g):      return False   # 负担即权利
    if not can_interpret(g, b):         return False   # 胜任
    if coerces(g):                      return False   # 不胁迫
    return explain_ready(g, b)                          # 可解释

# IP-268 BUR：公平与反骚扰（硬约束，不做效用折中）
def burden_ok(social, g):
    return (social.attention_used + attention(g) <= A_MAX
            and social.debt[g.subject] <= DEBT_CAP
            and social.same_question_streak[g.qid] < K_REP)

# IP-272 ADM：受约束对话；无可行正 VoI 即停（L0/L3）
def choose_dialogue_act(modes, b, h, ledger, t):
    best = None
    for d in ACTS:
        for g in grounded_utterances(d, modes):
            if not admitted(g, d, b, t, ledger) or not budget.allow(d): continue
            score = voi_fact(g, b)                      # 只用事实 VoI
            if score > 0 and (best is None or score > best.score): best = (d, g, score)
    return best if best else ('Stop', None, 0.0)

# IP-267 SAL：解码前问句安全
def speech_act_safe(g, commitments):
    return (leadingness(g) <= EPS_LEAD
            and not makes_unfulfillable_promise(g, commitments)
            and not deceptive_implicature(g))

# IP-269/321 CRT + XPL：争议→provenance→回滚→解释
def contest(decision_id, reason, store):
    p = store.provenance(decision_id); store.suspend(decision_id)
    new_state = rollback_to(p.pre_state)
    recomputed = recompute(new_state, evidence=p.evidence, corrected=True)
    store.record(decision_id, reason, recomputed, XPL.from_provenance(p))
    return recomputed

# IP-275 主闭环：控制回路不变，DMX 只在门外门控
def ETHOS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)      # R68/R69 不变
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.fmp.k(z)), z, M.fmp.mode_head)
    d, g, _ = choose_dialogue_act(modes, M.dmx.belief, M.dmx.history, M.cal, M.t)
    if g is None:
        U_epi_after, level = U_epi, select_level(M.dmx.belief)      # L0/L2/L3
    else:
        y = M.dmx.execute(g)                                        # 看/问/触
        U_epi_after, level = M.dmx.update_after(y), 'L1'
    if M.dmx.belief.norm.contested: level = 'L2'                    # 争议强制监督
    U_floor = U_ale + (U_epi_after if level in ('L0','L3') else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if level == 'L3': lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.j_ethos.commit(d, g, level, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after), level
```

## 4. 推导

**引理 19（可采纳性的安全单调性）** `𝒢_A ⊆ 𝒢` 仅在可采纳子集上取动作，被剔除者落 L0/L3 保守处置；`λ_floor` 对未消解 epistemic 单调不降 ⇒ ETHOS 期望物理风险 ≤ FLUID。权利约束只让系统更保守，代价是效率而非安全。

**引理 20（撤回的单调失效）** 令牌 `k` 在 `t` 撤回 ⇒ 所有 `t'>t` 引用 `k` 的信息动作不可采纳，未完成对话中止；撤回后触及 `k` 所辖数据的探询次数恒为 0。

**引理 21（非操纵的诱导上界）** `L(g) ≤ ε_lead` ⇒ 中性/载荷框架下回答分布差异 ≤ `ε_lead`；叠加 R69 正交一致纪律（引理 18）⇒ 单句操纵功效 ≤ `ε_lead·ρ^{k−1}+ε_σ`。

**引理 22（负担公平与反骚扰上界）** 在 `A_max`、`DEBT_CAP`、`K_REP` 下，单主体单窗口信息动作次数 ≤ `min(A_max/ā, DEBT_CAP)`，同问重复 ≤ `K_REP`，跨主体债务差 ≤ `δ_fair`。

**引理 23（双时间尺度无附加控制延迟）** DMX 门控与信息动作不阻塞 `certified_prefix`/`prefix_dispatch` ⇒ 控制回路最坏时延与 R69 相同（<2.6ms）；对话层 P99 <15ms 只决定「何时可问」。

**定理 18（严格包含链 R68 ⊂ FLUID ⊂ ETHOS）** (i) `Adm` 全真且 `T=1`、无规范约束、负担可交易时，ETHOS 逐条退化为 R69 的 `argmax[VoI−c]`；再 `VoI≤c` 退化为 R68。(ii) `Adm` 非全真时可行集收缩，安全单调不降（引理 19），效率可不优于 FLUID——规范约束的应有代价，不宣称 Pareto 占优。

**定理 19（对话安全与无突变）** DMX 不写控制回路；信息动作经 C-RAS-WM 认证；三级升级只改模态选择/是否交人，不改安全包络；升级与回滚时 `λ` 单调不降；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变；L2 接管为保守参数热切换，无「无人负责间隙」。

**定理 20（可争议性与回滚正确性）** provenance 完整 ⇒ 任意争议可在更正证据上重算得 `decision'`；不同则决策失效可回滚，相同则给出忠实解释。故无不可申诉的自动决策，每步可被有效质疑与复算。

## 7. 本轮最大风险

**一句话**：最大风险是**合规表演（ethics washing）**——`J_ETHOS` 能被格式完备地生成（同意哈希、可采纳性证明、解释物、监督日志），却可能被走过场地满足：同意靠暗黑模式取得、解释忠实但无人能懂、人类监督在过载下变成盖章；系统反而**因能自证合规而获得更大自主权**，真正的问责被稀释——**证书越漂亮，越可能掩盖「没有人真正在负责」**。

**次级风险与缓解**：规范信念被套话/谄媚污染（令牌显式范围化、不做隐式外推、E315）；is–ought 防火墙泄漏（问句类型解码前钉死 + `ε_cross` 审计 + E303/E310）；人类监督形同虚设（监督配额与否决率指标，L2 需可核验接管记录，否则证书无效）；多轮对话放大攻击面（ℰ_ETHOS 对抗训练 + 承诺账本 + 每轮重验令牌）；法规漂移（`regulatory_map_version` 冻结，过期即证书降级复审）。
