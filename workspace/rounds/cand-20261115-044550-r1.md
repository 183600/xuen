# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「能耗优化」×「轮足机器人」）

> R69 把不确定性一分为二，并用「主动交互」去消解 epistemic。但它默默假设了两件事：(a) 保守与求证是**免费**的——只花时间与社交成本，不花能量；(b) 机器人只有一种运动方式，**慢下来总是更安全**。对一台电池供电的轮足机器人，这两条同时失效。
>
> **慢不等于省电**：当酒店负载（计算/传感/待机）不可忽略时，单位距离能耗 `E_d(v) = (p_loco(v) + p_hotel)/v` 在内点 `v*` 处取极小；低于 `v*` 时「再慢一点」反而更费电，甚至把机器人慢到没电。**慢也不等于安全**：能量耗尽本身就是最严重的安全事故——搁浅、无法返航、在坡道上失去动力。
>
> 轮足机器人还多了一个 R69 没有的离散自由度：**轮行（W）/ 足行（L）/ 混合（H）**。轮行在平地上 CoT 最低、速度快，却越不过台阶、在松软地面上会下陷；足行能过坎、适应粗糙地形，代价是更高的 CoT；混合负责过渡。模式切换本身是一次有能量与时间代价、且只能在特定状态完成的机动。于是本轮的核心问题变成：**这份保守、这次求证、这个模式，值多少焦耳？**
>
> 核心命题：把 R69 的「风险预算」升级为「**双预算对偶**」——安全是一笔必须预先计提的**负债**（能量储备），信息是一笔可核算回报的**投资**（能量归一 VoI），能量是二者共同的**记账单位**；并在字典序上保证焦耳永远买不断硬安全。命名 **JOULE-RAS**（Joint Optimization of Uncertainty and Locomotion Energy）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我还付得起吗**」——安全不是免费的，求证也不是；一台会算账的机器人，才可能既保守又跑得远。

## 0. 直觉与动机

**灵感 1（轮足机器人 → 运动模式是被忽略的「离散动作模态」）**
直觉：R69 的流匹配策略在连续动作空间里分出多个模态（绕左/绕右、接住/避让），却把「用轮还是用腿」当成给定前提。轮足机器人恰恰把这个前提变成决策：轮行在平地上极省电，但受台阶高度、沟壑宽度、地面摩擦与下陷限制；足行能过坎、能上楼梯，但 CoT 高、速度慢；混合用于在两种模式间过渡。模式切换是一次**离散、有代价、有可行域**的机动（例如必须先减速、在足够平整且坡度受限的地面上站立/锁定轮组）。这把 R69 的「动作多模态」扩展为 **「运动模式 × 步态 × 任务动作 × 信息动作」的联合离散-连续策略**，也让 R69 的模态权重第一次有了直接的物理价格：选错模式 = 卡住 + 额外切换 + 多花焦耳。

**灵感 2（能耗优化 → 安全与信息用同一种货币支付）**
直觉：R69 的 K=4 多采样、主动注视、探针、问句，全都要耗电（计算、传感器、执行器，甚至人类注意力）；而 R68/R69 的「慢下来」也要耗电——因为机器人有酒店负载，站着不动也在漏电。于是「安全预算」和「能量预算」不是两个独立约束，而是同一张账本上的两栏：**安全储备是负债，信息探询是投资，剩下的是可自由支配的能量**。只有当一笔探询的**期望省电**（避免一次误选模式的切换/卡住、选对更省电的步态/速度、避免返航）超过它的成本时，它才值得做。这把 R69 的熵 VoI 改写成**能量归一 VoI（EVoI）**。

**灵感 3（慢不等于安全 → λ_floor 的单调性在能量约束下反转）**
直觉：R68/R69 的铁律是「不确定就收紧，收紧就慢一点」，隐含假设 `E_d(v)` 随 v 单调下降。但在有限电池 + 酒店负载下，`E_d(v)` 有内点最优：太慢时单位距离能耗反而上升，且可能赶不到充电点/安全点。更尖锐地说，**为了省电而冒险**与**为了安全而慢到没电**都是失败模式。所以 R70 必须用「能量条件化的安全算子」替换标量 λ：在认证安全集内最大化「进度 / 焦耳」，而不是一味减速。安全集随能量收缩，但这个收缩**不是简单的更慢**。

**灵感 4（能量储备 → 把保守主义变成可审计的会计恒等式）**
直觉：安全在 R68 是概率约束，在 R70 应该变成一条**可核算的恒等式**：任何时刻都必须有足够能量执行一条已认证的兜底策略（受控停车 / 锁轮滑行 / 跛行返航 / 原地站立呼救）。这部分能量是**不可侵占的储备**。所有计划、探询、多采样都只能花「储备之外的自由能量」。这样「保守」不再是一个黑箱缩放系数，而是一条能在证书里逐项对账的账本。轮足机器人让这条账本特别有意义：低电量时「最安全的动作」可能不是继续走，而是**认证中止（certified abort）**——停下来并呼救，而不是硬撑到没电。

**灵感 5（能量是双刃剑 → 新的威胁模型：电量幻觉与省电陷阱）**
直觉：一旦系统按能量做决策，能量估计本身就成了攻击面。库仑计漂移、电压模型在负载突变时失真、学习功率模型在 OOD 地形上外推失真，都会造成「**电量幻觉**」——机器人以为自己还有储备。更隐蔽的是：优化器会学会「用省电的名义削安全边际」（energy-induced risk-taking），以及被「看起来很近/很省电」的伪造地形代价图骗进高代价区域。所以本轮必须同时交付：能量可观测性第二意见、储备不变式的在线监控、字典序安全约束（硬风险不可用焦耳买断）、以及新的对抗干扰集。否则 JOULE-RAS 不是进步，而是给 R69 的交互主义装上了一张**会做假账的资产负债表**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（JOULE-RAS 总览）** JOULE-RAS = (EMP, CEM, ERL, EVoI-MINT, HLC, SOCX, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **能量储备非负**：沿任何被认证的前缀 `E_rem − E_plan − E_res ≥ 0`；
(iii) **字典序安全**：硬安全约束（碰撞 / 跌落 / 伤人）≻ 储备不变式 ≻ 能量效率 ≻ 任务收益；焦耳只能买断最后一档。

**定义 311（混合运动模式）** μ ∈ {W, L, H}；切换机动 σ: μ→μ′ 具有代价 `E_switch(σ)`、时长 `T_switch(σ)`，且只在可行切换面 𝒮_σ（坡度、平整度、速度、能量足够）上可执行。模式是离散潜变量，其不确定性进入 R69 的模态身份 M。模式感知的步态参数 `g_gait`（轮速、步频、步高、驱动力分配）与任务动作、信息动作共同构成增广动作 `ξ = (a, g_gait, g)`。

**定义 312（能量代价模型 CEM）** 对动作块 `ξ_{t:t+H}` 与模式 μ，预测能耗 `Ê(ξ, s; μ)`（对功率积分，输入地形特征、速度/步态、负载、温度）。用 conformal 校准得到上界 `E⁺(ξ) = Ê + q_{1−δ}`（q 为校准残差的上分位数）。**账本只用 E⁺，绝不用 Ê**。

**定义 313（能量账本 ERL）** `E_rem` 为当前可用能量（由 SOCX 给出，含不确定区间）；`E_plan = Σ E⁺(ξ_i)`；`E_res(s)` 为认证兜底组合（受控停车 / 锁轮滑行 / 跛行返航 / 站立呼救）中最坏情况的上界；自由能量 `D = E_rem − E_res`。记账 `E_rem ← E_rem − E_actual`，并在每个规划步校验定义 314。

**定义 314（安全储备不变式 SRI）** `E_res(s) = sup_{s′∈Reach_cert(π_fallback)} E⁺(π_fallback(s′))`；不变式：对规划前缀的每个前缀态 `s_k`，`E_rem − Σ_{i<k} E⁺(ξ_i) − E_res(s_k) ≥ 0`。违反 ⇒ 立即收缩到兜底组合中**最低能量可行项**；若连兜底都不可行 ⇒ **认证中止（certified abort）** 并上报，而不是「继续慢慢走」。

**定义 315（能量-风险可行性域）** 候选动作集合给出 `ℱ = {(risk(ξ), E⁺(ξ))}`；在字典序（定义 310-iii）下，先取 `risk ≤ ε_hard`，再取满足 SRI，余下按 `progress/E⁺` 排序。E 充裕时可行边界由风险约束决定（退化为 R69）；E 紧张时由能量约束决定（出现「省电优先」但**不降硬安全**的新行为）。

**定义 316（能量归一 VoI，EVoI）** `EVoI(g) = E[ΔE_saved(g)] − E⁺(g) − κ·ΔRisk(g)`；ΔE_saved 来自「避免一次误选模式的切换/卡住」「选对更省电的步态/速度」「避免返航」等；用 conformal 下界 `ΔE⁻` 代替期望以获得保守保证。选择 `g* = argmax EVoI` s.t. SRI 与预算；若 `max EVoI ≤ 0` ⇒ 不交互，退化为 R69。

**定义 317（能量感知保守算子 E-RAS）** 用 `(ε_hard, E_rem)` 参数化的算子 `Π_E` 替换 R68/R69 的标量 `λ_floor`：`Π_E(𝒜_cert) = argmax_{ξ∈𝒜_cert} progress(ξ)/E⁺(ξ)` s.t. `risk ≤ ε_hard ∧ SRI`。性质：能量下降只收缩 `𝒜_cert`，不放松 `ε_hard`；且**不保证动作更慢**（引理 19）。

**定义 318（模式切换护栏 HLC）** 切换需同时满足：(a) 在 `𝒮_σ` 内；(b) 切换完成后 `E_res` 仍可满足；(c) 摊薄条件 `E_switch(σ) ≤ E[ΔE_saved over dwell]`；(d) 驻留时间 `≥ τ_dwell`（防抖）。任一不满足 ⇒ 不切换，或在当前模式内改选更省电的步态。

**定义 319（电量可观测性 SOCX）** 三个独立估计：库仑计数 `SoC_cc`、开路电压模型 `SoC_ocv`、学习功率模型 `SoC_l`；`ΔSoC = max pairwise |·|`。超阈 ⇒ 按 `γ·ΔSoC·Q_nom` 膨胀 `E_res`，并进入「**低置信能量模式**」：禁止 K>1 多采样与主动交互（对应 R69 MCG 的能量版）；再超阈 ⇒ 仅执行兜底。

**定义 320（能量诱导冒险抑制 EIG）** 硬约束与储备约束**字典序不可交易**；能量优化只在剩余可行域内进行。形式化为带优先级的约束 MDP：`min E` s.t. `P(fail) ≤ ε_hard`，`SRI ≥ 0`；禁止把 `ε_hard` 当作可调旋钮。EIG 同时记录「若放宽 `ε_hard` 本可省多少焦耳」作为审计指标（**只记录，不执行**）。

**定义 321（可逆微滚动探询 RMP）** 轮足特有的信息动作：短时（δ）低速滚动 `ξ_roll`，同时获得地形滑移/下陷/粗糙度信息并推进少量任务。认证条件：存在回退动作使状态回到出发安全集，且 `E_back ≤ B_probe`；不得进入不可恢复集。RMP 把「探询」与「前进」合并，常是 EVoI 成本最低的信息动作。

**定义 322（能量感知自适应采样）** `K* = argmax_K [ E[模态熵降低(K)]·V_info − (E_sample(K) − E_sample(1)) ]` s.t. 延迟与 SRI；默认 K=1，仅当 `mode_head` 报歧义且采样能耗被 EVoI 覆盖时升 K=4。

**定义 323（能量审计 VQAuditor-E）** 审计：储备是否逐项对账、EVoI 预测/实现比、模式切换是否满足摊薄与驻留、是否出现「用省电削安全」、`ΔSoC` 是否被正确膨胀储备。结论回灌 AuditBuf，成为下一轮 CEM/EVoI 的先验。

**定义 324（干扰集 AIC-JOULE）** `ℰ_JOULE = ℰ_FLUID × ℰ_energy`，`ℰ_energy = {伪造/偏置 SoC 与电压负载欺骗, 地形代价图投毒（看似省电实则高耗）, 能量拒绝（诱导无谓交互/切换）, 再生制动诱骗, 储备耗尽的时序攻击}`。

**定义 325（证书 J_JOULE）** `J_JOULE = (J_FLUID, reserve_min, ledger_hash, soc_disagreement_p95, evoi_realized_ratio, mode_switch_count, E_per_meter_p95, joule_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ 窗口内 SRI 恒成立 ∧ SOCX 置信 ∧ 账本闭合（无无法解释的焦耳）∧ 无硬安全违规`。

**定义 326（退化边界，严格包含）** 当 `E_rem → ∞`（或系留供电）：`D → ∞`、EVoI 退化为 R69 的熵 VoI、HLC 无约束、SOCX 不触发 ⇒ JOULE ≡ FLUID 逐指令相同；平地 + 轮行严格占优时模式决策平凡 ⇒ 再退化为 R69。故 R69（从而 R68）是 JOULE 的边界情形。

# IP-264 EMP：模式感知流匹配策略（在 R69 FMP 上增加离散模式与步态）
class EnergyModePolicy:
    def sample(self, o_t, K, N_step=2):
        z = self.trunk(o_t)
        mu_logits = self.mode_head(z)              # W / L / H 的离散分布
        xi = flow_sample(self.v, z, K, N_step)     # ξ=(a, g_gait, g)

# IP-265 CEM：conformal 能量上界（账本只用上界）
def energy_upper(xi, s, mu, calib):
    e_hat = self.net(xi, s.features, mu)           # 功率积分
    return e_hat + calib.quantile(1 - DELTA_ENERGY)

# IP-266 ERL：储备账本 + SRI 校验
def ledger_ok(s, prefix, E_rem, fallback):
    E_plan = sum(energy_upper(x, s_k, mu, CAL) for x, s_k, mu in prefix)
    s_end  = prefix[-1][1] if prefix else s
    E_res  = max(energy_upper(fb, s_end, fb.mu, CAL) for fb in fallback(s_end))
    return (E_rem - E_plan - E_res >= 0), E_res

# IP-267 EVoI-MINT：能量归一交互决策（无正回报即退化 R69）
def choose_interaction(modes, w, s, E_rem, budget):
    best = None
    for g in info_candidates(modes):               # gaze / ask / probe / RMP
        if not budget.allow(g) or not c_ras_wm.certify_info(g, s): continue
        dE   = conformal_lower(energy_saved(g, s)) # 保守下界
        evoi = dE - energy_upper(g, s, TASK_MU, CAL) - KAPPA * risk_delta(g)
        if not ledger_ok(s, [(g, s, TASK_MU)], E_rem, FALLBACK)[0]: continue
        if best is None or evoi > best.evoi: best = (g, evoi)
    return best if best and best.evoi > 0 else None

# IP-268 HLC：模式切换护栏
def can_switch(s, mu, mu_new, E_rem):

    if not amortized(mu, mu_new, E_rem):      return False      # 摊薄

    return ledger_ok_after_switch(s, mu_new, E_rem)

# IP-269 SOCX：电量第二意见（三路独立估计）
def soc_confidence(s):
    d = max(abs(s.soc_cc - s.soc_ocv), abs(s.soc_cc - s.soc_l))
    return d, d < TAU_SOC                    # False ⇒ 低置信能量模式

# IP-270 E-RAS：能量条件化安全算子（替换标量 λ_floor）
def e_ras_select(A_cert, s, E_rem):
    feasible = [x for x in A_cert
                if hard_risk(x) <= EPS_HARD

               default=fallback_min_energy(s))       # 可能不是"最慢"，而是最省

## 3. 推导

**引理 19（酒店负载使「慢」不再省电——λ_floor 单调性的反转）** 设运动功率 `p_loco(v)` 为凸增函数，酒店负载 `p_h > 0` 恒定，则单位距离能耗 `E_d(v) = (p_loco(v) + p_h)/v`。若 `p_loco = c v^p`（p>1），则 `E_d` 在内点 `v* = (p_h / (c(p−1)))^{1/p}` 处取极小；当 `v < v*` 时 `dE_d/dv < 0`。因此对 `v < v*` 的「再慢一点」会**增加**能耗，进而在储备约束下**收缩**可达安全集。系：R68/R69 的单调 λ 只在「酒店负载可忽略、速度高于拐点」的区间成立；E-RAS 必须用能量条件化算子而非标量缩放。

**引理 20（储备不变式的可靠性）** 若 CEM 的 conformal 上界在分布内以 `1−δ` 覆盖真实能耗，兜底组合覆盖所有可达前缀态，且 SOCX 在正常模式下以 `1−δ_s` 未低估可用能量，则 SRI 在 H 步窗口内被违反（即搁浅）的概率 `≤ Hδ + δ_s`。系：**储备不是「感觉安全」，而是一条可对账、可界定的概率保证**；一旦 `ΔSoC` 超阈，正确做法是膨胀 `E_res` 并停用自由支出，而非继续按旧账本走。

**引理 21（EVoI 是投资而非赌博）** 用 conformal 下界 `ΔE⁻` 计算 EVoI；若 `EVoI(g) > 0`，则在覆盖成立时，执行 g 的期望总能耗不高于不执行 g（差至少 `EVoI − 有限样本松弛`）。系：R69 的熵 VoI 是「信息收益」，EVoI 是「信息收益的焦耳折现」；无正回报的探询被系统性拒绝，而不是靠人为预算截断。

**引理 22（模式切换防抖与能量上界）** 在驻留时间 `τ_dwell` 与摊薄条件下，任意长度 T 的窗口内切换次数 `N_sw ≤ T/τ_dwell`，切换附加能耗 `≤ N_sw·E_switch_max`，且每次切换后的驻留收益非负。系：轮足的「轮/足」抖动不会把能量优势吃掉。

**定理 18（JOULE 严格包含 FLUID/R69）** 在定义 326 的退化条件下（`E_rem→∞`、无模式约束、SOCX 不触发），JOULE 的 EVoI 退化为 R69 的熵 VoI、E-RAS 退化为风险约束选择、HLC 无约束 ⇒ **逐指令相同**。因此 JOULE 是 FLUID 在「能量不受限」边界上的严格泛化；能量受限时，它只收缩可行集，不放松任何硬安全约束。

**定理 19（无能量诱导的风险升级）** 在字典序约束（定义 310-iii、320）下，E-RAS 的解始终满足 `risk ≤ ε_hard` 与 SRI；能量压力只能改变「在可行域内选哪个动作」，不能改变 `ε_hard`，也不能把储备挪作自由支出。故相对 R69，JOULE 的硬安全违规率不升；唯一的新增失败源是**能量模型/储备模型本身错误**（引理 20 的 δ 项）——这正是本轮最大风险的所在。

## 4. 推导

**引理 19（酒店负载使「慢」不再省电）** `p_loco(v)` 凸增、`p_h>0` 时 `E_d(v)=(p_loco(v)+p_h)/v`；若 `p_loco=cv^p`，则 `v*=(p_h/(c(p−1)))^{1/p}` 为内点极小，`v<v*` 时 `dE_d/dv<0`。故对低速段的「再慢一点」增加能耗并收缩安全集——单调 λ 只在「酒店负载可忽略、速度高于拐点」时成立。

**引理 20（储备不变式的可靠性）** conformal 以 `1−δ` 覆盖能耗、兜底覆盖所有可达前缀、SOCX 以 `1−δ_s` 未低估余量，则 H 步窗口搁浅概率 `≤ Hδ+δ_s`。系：储备是可对账的概率保证；`ΔSoC` 超阈必须膨胀储备并停用自由支出。

**引理 21（EVoI 是投资而非赌博）** 用下界 `ΔE⁻` 计算 EVoI，若 `EVoI>0`，覆盖成立时期望总能耗不高于不交互（差至少 `EVoI−有限样本松弛`）。系：熵 VoI 是信息收益，EVoI 是其焦耳折现。

**引理 22（模式切换防抖）** 驻留 `τ_dwell` + 摊薄 ⇒ 窗口 T 内 `N_sw≤T/τ_dwell`，切换附加能耗 `≤N_sw·E_switch_max`，驻留收益非负。

**定理 18（JOULE 严格包含 FLUID/R69）** `E_rem→∞`、无模式约束、SOCX 不触发时，EVoI→熵 VoI、E-RAS→风险约束选择、HLC 无约束 ⇒ 逐指令相同；能量受限时只收缩可行集，不放松硬安全。

**定理 19（无能量诱导的风险升级）** 字典序约束下 E-RAS 解始终满足 `risk≤ε_hard` 与 SRI；能量压力只改「可行域内选哪个」，不改 `ε_hard`，不挪用储备 ⇒ 硬安全违规率不升；唯一新增失败源是能量/储备模型本身错误（引理 20 的 δ 项）。

## 7. 本轮最大风险

**一句话**：JOULE-RAS 把安全与求证都折算成焦耳，收益是让保守可负担、让轮足模式决策有统一货币；但**一旦能量账本本身算错**（conformal 上界在地形 OOD 下失效、地形代价图被投毒、或低电量时软风险被能量压力挤压），系统就会以「精算般的自信」走向搁浅或鲁莽——**账本错了，省下来的每一焦耳都是从安全里借来的**。

**次级风险与缓解**：CEM 分布漂移（在线覆盖率监控 + 膨胀 + 认证中止）；电量幻觉（SOCX 三路第二意见 + 低置信模式）；切换不可行（HLC 护栏 + 兜底）；EVoI 高估（conformal 下界 + 实现/预测比审计）；能量诱导削安全（字典序约束 + EIG 只记录不执行）；新增延迟（解析 CEM + O(H) 账本 + P99 预算）。
