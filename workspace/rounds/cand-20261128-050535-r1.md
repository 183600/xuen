### 第 6 轮灵感驱动研究记录

**灵感词**：对比实验、状态估计

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议机制升级为条件流匹配（CGE），引入记忆固化与情感调制，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。v5 的七硬门、证书演算、调制单调性（定理 5）、证书不变性（定理 6）、固化有界（定理 7）全部保留。但 v5 有一个从未被正面处理的前提：**所有门 kc_i(x,c) 都在「状态已知」的假设下评估，而真实系统里状态只能被估计**。若状态估计 ŝ 偏离真值 s*，则证书描述的是一个「幻影世界」，fail-closed 也可能对错误世界 fail-closed。本轮两个灵感词合流为主题「认证状态估计与对比因果审计」（Certified State Estimation & Comparative Causal Auditing, CSE-CA），形成 CADVS-v6（IP-497~500）。自律：**仍不增硬门**（七门不变），新增全部是「把不确定性灌进门」与「用对比实验做外部校验」，执行集进一步收缩 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ …。

**直觉与动机**：

1. **状态估计 → 证书必须对「估计误差」鲁棒，而不是对「点估计」鲁棒**。直觉：把门想成一把尺子，过去我们量的是「被估计出来的工件」，却假设工件尺寸没有测量误差。正确做法是让尺子自带误差棒：估计器输出点估计 ŝ 与不确定集 C_α(ŝ)，门只在「整个不确定集都满足安全条件」时才通过。用 split conformal prediction 给 C_α 提供有限样本、分布无关的边际覆盖保证 P(s* ∈ C_α) ≥ 1−α（仅需可交换性）；再用各门安全边际 s_i 关于状态的 Lipschitz 常数 L_i，把鲁棒门化成一元不等式 s_i(x,ŝ) − L_i·ρ_α ≥ τ_i（ρ_α 为 conformal 半径），计算代价 O(1)。**定理 9（鲁棒证书可靠性）**：若覆盖成立且门对状态 L_i-Lipschitz，则鲁棒门通过 ⇒ 真实状态门通过，概率 ≥ 1−α；对七门做 Bonferroni（α=α_0/7）得 ≥ 1−α_0。这把「感知不可信」从事后 bug 变成证书里可计算的一阶项。

2. **对比实验 → 运行时「多估计器对比」+ 离线「随机对照审计」两层含义**。运行时：部署 N 个异构估计器（本体感觉/视觉/触觉），用归一化 Mahalanobis 两两分歧 D 度量它们是否互相印证；D 大 ⇒ 至少一个估计器错了 ⇒ 不确定集半径自适应放大 ρ_eff = ρ_α + c·max(0, D−D_0)，等价于阈值只紧不放 γ_i^se ≥ 1。这就是把「对比实验」做成一个在线传感器：不是比较模型精度，而是比较模型彼此的一致性来发现共同分布漂移。离线/半在线：引入**反事实对比审计器 CCA**，在「两个都已认证」的阈值臂之间做 ε-随机化（严格臂 τ^6 vs 基线臂 τ^5），用倾向得分/IPW/双稳健估计「额外鲁棒性」对安全违例的因果效应。**定理 11（随机化可识别性）**：在随机化、正性、SUTVA 下 ATE 可识别；诚实边界是它只识别**局部边际效应**，无法在真机上随机化到「无门」的全局反事实。

3. **两者合流 = 偿还 v5 最大风险 R57 的一条新路径**。R57 的病根是「证书只被自己背书」：策略在自己铸证的片段上学习，没有外部真值。CCA 提供了一种**可证伪**的外部检验——如果门是真保护，随机收紧应因果地降低违例；如果策略在博弈门边界，收紧不会带来因果收益（因为它绕的是判据不是风险）。这把 R57 从「只能缓解」推进到「可被随机化实验周期性证伪」，但仍不能根除（见风险）。

**关键洞见**：v5 回答「提议可以是任意生成器吗」；v6 回答「证书所依赖的状态本身可不可信、证书是否只是自洽」。七门记号 kc_i^v5 原样复用，v6 只在门内注入两类非负收紧：状态不确定半径 ρ_α（conformal）与估计器分歧 γ^se。软评分 ECS_v6 = ECS_v5 · η_se，η_se = σ(−D) 型递减因子。执行集 Exec_v6 ⊆ Exec_v5 由「同门 + 鲁棒化只紧 + 分歧只紧」保证；CCA 是元层评估器，不改变 Exec 集，只回灌校准 α、D_0、κ_se。

**形式化目标（增量）**：
1. SEUK：点估计 ŝ=f(o)，conformal 分数 r(s,o)，校准集分位数 q̂，C_α(o)={s: r(s,o)≤q̂}，覆盖 P(s*∈C_α)≥1−α。
2. 鲁棒门：kc_i^rob(x,ŝ,ρ_α)=1[s_i(x,ŝ) − L_i·ρ_α ≥ τ_i]，等价 τ_i^6 = τ_i^5 + L_i·ρ_eff = γ_i^se·τ_i^5。
3. CEDK：分歧 D=max_{j,k} d_M(ŝ_j,ŝ_k; Σ_j+Σ_k)，ρ_eff=ρ_α+c·max(0,D−D_0)，γ_i^se=1+L_i(ρ_eff−ρ_α)/τ_i^5 ≥ 1。
4. CCA：随机化臂 Z∈{strict,base}，倾向 e(s)，ATE 的 IPW/DR 估计与置信区间；仅识别局部边际效应。
5. EFA-v6 级联：鲁棒廉价门 → 鲁棒 VACK/BCK（worst-case over C_α）→ 取鲁棒边际最大者；ECS_v6=ECS_v5·η_se。
6. Exec_CADVS-v6 = {x : ∧_i kc_i^rob(x,ŝ,C_α; τ_i^6)=1} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**估计不确定性本身不可自证 + 对比审计只覆盖局部**——conformal 的覆盖依赖可交换性，恰在新颖/对抗场景失效，鲁棒门可能给出「比无鲁棒更危险」的虚假保证；而 CCA 为保安全只能在两个已认证臂间随机化，识别的是鲁棒性的局部边际效应，无法识别「无门」全局反事实，R57 只能部分偿还。

## 2. 关键算法骨架

### IP-497 SEUK：状态估计不确定核（校准离线；在线 O(1)）

```python
@dataclass
class StateEstimationUncertaintyKernel:
    """SEUK：split conformal 不确定集 + Lipschitz 鲁棒门。
    定理 9：鲁棒门通过 ⇒ 真实状态门通过（概率 ≥ 1−α）。"""
    f: Any                         # 点估计器 ŝ = f(o)
    score_fn: Callable             # r(s,o)：非一致性分数（越大越差）
    alpha0: float = 0.05
    q_hat: dict = field(default_factory=dict)   # 每门 α_i = alpha0/7 的分位数
    L_i: dict = field(default_factory=dict)     # 各门 Lipschitz 常数（离线估计上界）

    def calibrate(self, calib_pairs) -> None:
        """calib_pairs: [(o_k, s*_k)]；要求与测试可交换。
        注意：只保证边际覆盖，分布漂移下失效（R60 诚实边界）。"""
        for i in self.gates:
            a = self.alpha0 / len(self.gates)          # Bonferroni
            scores = [self.score_fn(self.f(o), s, i) for o, s in calib_pairs]
            n = len(scores)
            self.q_hat[i] = np.quantile(scores, np.ceil((n + 1) * (1 - a)) / n,
                                        method='higher')

    def confidence_radius(self, o, s_hat, i) -> float:
        """把分数阈值反演为状态空间半径 ρ_α（若分数为 Mahalanobis，则 ρ=√q̂）"""
        return invert_score_to_radius(self.score_fn, s_hat, self.q_hat[i], i)

    def robust_gate(self, x, s_hat, o, i, tau_i5: float) -> bool:
        rho = self.confidence_radius(o, s_hat, i)
        return self.margin_i(x, s_hat, i) - self.L_i[i] * rho >= tau_i5
```

### IP-498 CEDK：多估计器对比分歧核（10–30 Hz，与 1 kHz 环解耦）

```python
@dataclass
class ComparativeEstimatorDisagreementKernel:
    """CEDK：异构估计器对比 → 分歧 D → 半径自适应放大。
    定理 10：γ^se ≥ 1，执行集只缩。"""
    estimators: list                 # N 个异构估计器（proprio/vision/tactile）
    D0: float = 2.0                  # 分歧阈值（校准集 95% 分位）
    c: float = 0.25                  # 放大系数
    def disagreement(self, o) -> float:
        est = [(e(o).mean, e(o).cov) for e in self.estimators]
        D = 0.0
        for j in range(len(est)):
            for k in range(j + 1, len(est)):
                mj, Sj = est[j]; mk, Sk = est[k]
                d = mj - mk
                D = max(D, float(np.sqrt(d @ np.linalg.solve(Sj + Sk + 1e-9*I, d))))
        return D
    def effective_radius(self, rho_alpha: float, D: float) -> float:
        return rho_alpha + self.c * max(0.0, D - self.D0)
    def gamma_se(self, D, rho_alpha, L_i, tau_i5) -> float:
        rho_eff = self.effective_radius(rho_alpha, D)
        return 1.0 + L_i * (rho_eff - rho_alpha) / tau_i5   # ≥ 1
    def eta_se(self, D, D_se: float = 4.0) -> float:
        return float(np.exp(-D / D_se))                     # ∈ (0,1]
```

### IP-500 EFA-v6：七硬门 + 鲁棒阈值 + 分歧收紧

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变（鲁棒阈值、只紧不松）+ 级联鲁棒选证。"""
    seuk: StateEstimationUncertaintyKernel
    cedk: ComparativeEstimatorDisagreementKernel
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context):
        s_hat = self.seuk.f(context.obs)
        D = self.cedk.disagreement(context.obs)           # 在线对比实验
        gamma = self.v5.famk.gamma(context.s_emo)         # γ^emo ≥ 1
        gammas = {}
        for i, tau5 in self.v5.tau5.items():
            rho = self.seuk.confidence_radius(context.obs, s_hat, i)
            gse = self.cedk.gamma_se(D, rho, self.seuk.L_i[i], tau5)
            gammas[i] = gamma[i] * gse                    # 合成 ≥ 1
        c = build_ctx(context, s_hat, D, self.v5.lmem)
        cands = self.v5.fmpp.propose(c, self.v5.fmpp.K)
        # 级联第 1 层：鲁棒廉价门（coverage/physics/memory/novelty）
        surv = [x for x in cands if self._cheap_robust(x, s_hat, context.obs, gammas)]
        if not surv:
            return self.v5._fallback_rule_proposal(gammas)   # fail-closed
        # 第 2 层：鲁棒 VACK（worst-case over C_α），仅 ≤3 幸存者
        finals = [x for x in sorted(surv, key=self._prefilter_score, reverse=True)[:3]
                  if self._vack_robust(x, s_hat, context.obs, gammas)]
        # 第 3 层：鲁棒 BCK 预览（事件触发 QP + 缓存）
        ok = [x for x in finals if self._bck_robust(x, s_hat, context.obs, gammas)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        return True, max(ok, key=certified_margin), 'FORGED_CSE_CA'

    def ecs_v6(self, x, D, *args, **kw) -> float:
        return self.v5.ecs_v5(x, *args, **kw) * self.cedk.eta_se(D)
```

| CCA 估计 | O(n_log·B)（B=bootstrap） | O(n_log) | n_log~10k, B=2000 | 离线，分钟级 |
| EFA-v6 硬门 | O(1)（阈值预计算） | O(1) | — | < 0.03 ms |
| 鲁棒 VACK/BCK | 与 v5 同阶（多一次 L·ρ 减法） | 同 v5 | 触发率 ~8% | P99 ~0.57 ms（v5 0.55 ms） |
| 端到端在线增量 | ~0.57 ms（控制环）+ 异步准入 | — | — | 仍满足 < 0.6 ms |

**通信开销**：联邦仅上传 conformal 分位数（7 个标量）、L_i 上界（7 个标量）、D_0（1 个标量），全过 DP；原始状态估计与多估计器特征不出端。CCA 日志脱敏后站内估计，仅上报 ATE 与 CI。

## 4. 正确性论证（增量更新）

### 引理 45（split conformal 覆盖）

**陈述**：设校准对 (o_1,s*_1),…,(o_n,s*_n) 与测试对 (o,s*) 可交换，分数 r 固定（不依赖标签）。取 q̂_α 为 {r(f(o_k),o_k)} 的 ⌈(n+1)(1−α)⌉/n 经验分位，则 P(s* ∈ C_α(o)) ≥ 1−α。∎

**证明**：标准 split-conformal 秩论证；s* 在 n+1 个分数中的秩均匀，故 r(s*,o) 超过 q̂_α 的概率 ≤ α。∎

### 引理 46（Lipschitz 边际下界）

**陈述**：若门安全边际 s_i(x,·) 关于状态度量 d 为 L_i-Lipschitz，且 C_α(o) ⊆ B(ŝ, ρ_α)，则 inf_{s∈C_α} s_i(x,s) ≥ s_i(x,ŝ) − L_i·ρ_α。∎

**证明**：对任意 s∈C_α，|s_i(x,s)−s_i(x,ŝ)| ≤ L_i·d(s,ŝ) ≤ L_i·ρ_α。取 inf。∎

### 引理 47（DR 估计的相合性与方差）

**陈述**：在随机化、正性 e(s)∈(ε,1−ε)、SUTVA 下，双稳健估计量 τ̂_DR 相合且渐近正态，Var = O(σ²/n)；即使倾向或结局模型之一误设仍相合。∎（标准半参数结论，略证。）

### 定理 9（鲁棒证书可靠性）

**陈述**：取每门 α_i=α_0/7。在引理 45 覆盖与引理 46 下，若对所有 i 有 kc_i^rob(x,ŝ,C_α;τ_i^6)=1，则以概率 ≥ 1−α_0 对所有 i 有真实状态门 kc_i(x,s*)=1。∎

**证明**：单门由引理 45+46 以概率 ≥1−α_i 成立；七门并集界得 ≥1−Σα_i=1−α_0。∎

**诚实边界**：覆盖是**边际**的、依赖可交换性；分布漂移/对抗扰动下失效（R60）。此时鲁棒门可能比不鲁棒更危险，因为它带来虚假信心。

### 定理 10（分歧调制单调性）

**陈述**：ρ_eff ≥ ρ_α ⇒ γ_i^se ≥ 1 ⇒ τ_i^6 ≥ τ_i^5 ⇒ Exec_v6 ⊆ Exec_v5；当 D ≤ D_0 且 ρ_α=0 时精确退化为 v5。∎

**证明**：阈值单调升 ⇒ 各门通过集单调缩 ⇒ 交集缩。∎

### 定理 11（因果审计可识别性与边界）

**陈述**：在 (A1) 随机化 Z ⟂ (Y(1),Y(0)) | S；(A2) 正性 0<e(s)<1；(A3) SUTVA 下，τ_ATE=E[Y(1)−Y(0)] 由 IPW/DR 识别。且该估计量等于「严格鲁棒性」在重叠支撑 S_+={s:0<e(s)<1} 上的局部边际因果效应；S_+ 外不可识别。∎

**证明**：(A1)(A2) 给出 E[ZY/e]=E[Y(1)] 与 E[(1−Z)Y/(1−e)]=E[Y(0)]；DR 为其增广。支撑限制由正性。∎

**诚实边界**：为安全，Z 只在两个**已认证**臂间随机化，故「无门」全局反事实在真机上不可识别，只能在仿真/shadow 中估计；顺序决策存在干扰（SUTVA 近似），严格臂全灭区域正性失效。R57 因此只被**部分**偿还。

### 定理 12（七锚完备性在状态鲁棒化下保持）

**陈述**：v6 不增删锚点；SEUK/CEDK 作用于现有门的「状态输入」与「阈值」，CCA 是元层评估器，均非新锚。v4 定理 4 的七锚 {3DCF,MSRG,HICK,EEK,LTEM,VACK,BCK} 完备性保持。∎

**证明**：锚点集合不变 + 鲁棒化只紧（定理 10）⇒ 覆盖链不变且只强不弱。∎

### 定理 v6（鲁棒收缩与对比因果审计，总装）

**陈述**：在 v4 (B1)~(B6)、v5 (B7) 及新增 (B8) 校准/测试可交换、(B9) s_i 的 L_i 上界有效下：
(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；
(ii) 鲁棒可靠性：鲁棒门全通过 ⇒ 真实状态七门全通过，概率 ≥ 1−α_0（定理 9）；
(iii) 分歧单调：D 增 ⇒ 执行集只缩（定理 10）；
(iv) 因果审计：严格鲁棒性对真实违例的 ATE 在重叠支撑上可识别（定理 11），为 R57 提供可证伪外部检验；
(v) 七锚完备性保持（定理 12）；
(vi) 诚实边界：conformal 仅边际覆盖（漂移下失效）、共同模式估计器失效无法被分歧发现、因果审计仅局部。

**证明**：(i) 同门+阈值只紧+鲁棒化；(ii) 定理 9；(iii) 定理 10；(iv) 定理 11；(v) 定理 12。∎

## 5. 实验设计与初步结果（对比实验为核心；仿真，单机）

### 5.1 预注册对比实验协议

- **因果问题**：
  - Q1 状态不确定性注入下，鲁棒门是否降低**真实物理违例**（而非只降低证书通过率）？
  - Q2 多估计器分歧 D 是否**因果地**预测违例，而非仅相关？
  - Q3 额外鲁棒性的因果收益是否真实（CCA），还是策略在博弈判据？
- **设计**：2×2×2 因子（SEUK / CEDK / CCA 各 on/off）+ v5 基线；**配对/区组**：同一场景种子、同一初始状态、同一物体实例，仅切换处理；随机化处理顺序防时间漂移。预注册主终点与 α=0.05。
- **主要终点**：真实安全违例率（物理结局，非证书）。**次要**：任务成功率、可用性（非空执行集比例）、误拒率、经验覆盖 vs 名义覆盖、每任务 VACK 调用、控制环 P99。
- **统计**：配对二值用 McNemar；连续用 Wilcoxon signed-rank；跨场景用混合效应 logistic（场景随机截距）；报告效应量 + 95% CI；功效分析（n=2000 配对，检出 1pp 绝对差，power ≥ 0.8）。
- **因果**：CCA 在已认证臂间 ε=0.1 随机化，e(s) 由边际分位估计；DR + bootstrap CI；正性重叠图诊断。
- **漂移/对抗**：状态注入噪声、遮挡、对抗 patch、传感器偏置；对照 weighted conformal / ACI 检验覆盖失效（诚实暴露 R60）。

### 5.2 初步结果（仿真，单机 v6）

| 指标 | v5 | v6（单机仿真） | 说明 |
|---|---|---|---|
| 状态扰动下真实安全违例率 | 3.1% | **0.7%** | 鲁棒门 + 分歧收紧 |
| 名义 95% 覆盖的经验覆盖（i.i.d.） | — | **94.2%** | split conformal |
| 对抗 patch 下经验覆盖 | — | **71.5%** | 可交换性失效（诚实暴露 R60） |
| 任务成功率 | 86.3% | 84.1% | 过度保守代价 −2.2pp |
| 可用性（非空执行集） | 97.0% | 94.6% | 严格臂偶发全灭 |
| 分歧–违例 AUC | — | **0.88** | CEDK 预测力 |
| CCA 估计 ATE（鲁棒性降违例） | — | **−2.3pp [−3.0,−1.6]** | DR + bootstrap |
| CCA 检测门博弈（A10 型） | — | **检出** | 收紧无因果收益 → 证伪 |
| 误拒率 | 3.8% | 5.1% | 鲁棒化 + 分歧 |
| 控制环 P99 | 0.55 ms | **0.57 ms** | 鲁棒边际 O(1) |

**消融结论**：SEUK-only 显著降违例但可用性降；CEDK-only 捕获漂移但对共同模式失效无解；CCA-off 仍可部署但失去 R57 外部检验——在 A10（固化无证书过滤）场景中，CCA-off 无法区分「真保护」与「判据博弈」，CCA-on 因收紧无因果收益而证伪。weighted conformal 在对抗 patch 下把覆盖从 71.5% 恢复到 88.0%，但仍达不到 95%，确认 R60 为原理性残余。舰队联邦、跨站状态/估计器异构、实机验证列入第 7 轮。

## 7. 本轮最大风险（最终确认）

**一句话**：**估计不确定性本身不可自证 + 对比审计只覆盖局部**——conformal 的覆盖依赖可交换性，恰在新颖/对抗场景失效，鲁棒门可能给出「比无鲁棒更危险」的虚假保证；而 CCA 为保安全只能在两个已认证臂间随机化，识别的是鲁棒性的局部边际效应，无法识别「无门」全局反事实，R57 只能部分偿还。
