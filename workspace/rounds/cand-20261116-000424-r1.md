# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「LoRA」×「课程学习」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**适应有界 + 证据晋升 + 白名单运行**。两个灵感分别治理 v10 的两种债：**适应债**（v10 只有「收缩/门控」，没有受控的模型改进通道；INT8 量化损失只能靠加大 β 吸收，长尾区永远 K=1）与**发展债**（τ_sem/β_STF 是一次性全局校准，没有发育顺序、没有晋升/降级、没有「凭什么现在可以放开」的证据账本）。必须保持 v10 铁律：任一新增模块失效 ⇒ 注入声明中立元，行为**回到 v10**（禁用适配器/课程 = 原样 v10），不得出现「适配器坏了但证书更乐观」的漂移。

## 0. 直觉与动机

**灵感 1（LoRA → 把「学习」变成有界、可切换、可审计的扰动）**
直觉：LoRA 常被当作省参数的微调技巧，但对本系统它真正的价值是**三项结构性质**：(i) 冻结基座 ⇒ 有一个不可漂移的证书锚点；(ii) 低秩 ΔW=BA ⇒ 对网络输出的扰动有**可计算的谱范数上界**（‖ΔW‖₂≤‖B‖₂‖A‖₂，沿层传播后仍可界），误差预算可以被证书吸收，而不是「学习了就祈祷」；(iii) 秩 r 是显式容量预算，Eckart–Young 给出「达到给定残差所需的最小秩」——**秩即证据**。于是可以把「在线适应」从不可问责的风险，变成一族按语义区域切换的**带证书适配器**：适配器只允许把有效 β 收紧（β_ℓ ≤ β_STF^v10 才准晋升），绝不放松 d_safe/τ_eff；基座保持冻结，任何适配器失效或选择歧义 ⇒ 回退基座 F̂_q 与 v10 的 β_STF，行为精确回到 v10。副产物：秩-r 修正可专门补偿 INT8 量化在难区上的误差，把 v10 被量化吃掉的证书余量**以有证据的方式**拿回来。

**灵感 2（课程学习 → 从黑名单检测到白名单认证）**
直觉：v10 的安全论证依赖一个经验分割面 τ_sem：显著突变被守卫抓、非显著误差被 β_STF 覆盖。这是**黑名单**逻辑——先假设覆盖一切，再靠检测器把「例外」挑出来；长尾/对抗恰恰在检测器与模型同时失效处穿透（v10 自认最大风险）。课程学习提供了相反的次序：**先从最容易、证据最充分的层级开始，只在该层证据达标后晋升到下一层；未知/未认证区域视为超出能力包络，直接收缩**。这把安全命题从「β 覆盖一切误差」（不可证）换成「只在被认证的层级内运行，且每层有可复算的 β_ℓ 与覆盖率」（可测、可审计）。课程同时给出**发育顺序**：适配器按易→难训练，每级先有回放与校准证据再晋升；一次硬违规立即降级——晋升是渐进的，降级是瞬时的（棘轮）。

**咬合**：LoRA 提供「可认证的局部模型」，课程提供「何时允许使用哪个局部模型」；两者合成 **低秩认证课程适应（LCCA, Low-rank Certified Curriculum Adaptation）**：适配器库给每个课程层级一个可计算误差界 β_adapt,j，课程阶梯决定运营包络 ODD_t，证书余量升级为**层级索引**的 β_ℓ = β_base,j + β_adapt,j + λ·T，并且只有当 β_ℓ ≤ β_STF^v10（在层级校准集上）时才允许晋升。关键反转：v11 不再问「这个新东西是不是显著的」（检测问题），而问「这个区域是否在已认证白名单里」（认证问题）；前者可被长尾绕过，后者默认拒绝。

## 1. 研究问题

- **Q1（有界适应）**：如何用冻结基座 + 低秩适配器给出可计算的输出扰动界 β_adapt，使晋升层的 β_ℓ 在 ≥99% 覆盖下严格不大于 v10 的 β_STF，同时秩预算 Σr_j 与内存/能耗可控？
- **Q2（课程晋升）**：如何定义难度层级、证据记录与晋升/降级谓词，使错误晋升概率可界（PAC 风格）、降级在 ≤1 块内生效，且未认证区域一律收缩到 v10 或更保守？
- **Q3（白名单闭环）**：如何把「预测足迹的多签名 ∈ 认证覆盖域」并入 50Hz 守卫，使 v10 的长尾穿透风险在检测器不响时仍被拦截，且守卫 WCET 不破 0.5ms？

## 2. 设计原则（在 P10–P15 基础上新增 P16–P18）

**P16 适应有界律（Bounded Adaptation, LAB）**
任何模型改变（在线/离线）必须是低秩、基座冻结、携带谱范数/覆盖预算并经证书重验；只许**收紧有效误差界**，不许放松安全裕量（d_safe、τ_eff、停车不变式不变）；无界更新禁止上线。

**P17 能力课程律（Competence Curriculum, CL）**
运营包络只经预注册证据逐级晋升（一次一级、不跳级）；一次碰撞或硬规范违规 ⇒ 瞬时降级；未知/未认证区域按「超出包络」处理（默认拒绝），不得默认放行。

**P18 证据晋升律（Evidence Promotion）**
秩、层级、软规范严格度都是「挣来的」资源；每次容量增加必须附带覆盖率与 β 证据；证据缺口 ⇒ 回退到上一已认证层级（最少为 v10 的 L_0=Π_r）。

## 3. 严谨定义（摘要；完整编号见产物区定义 549–558）

**定义 A（低秩适配器与认证扰动界）** 对第 l 层基座权重 W_{0,l}，适配器 j 给出 W_{j,l}=W_{0,l}+B_{j,l}A_{j,l}，rank(B_{j,l}A_{j,l})≤r_j。若认证激活球 ‖h_l‖≤H_l、下游 Lipschitz 常数为 L_{l+1:L}，则
  β_adapt,j = Σ_{l∈S_j} (Π_{l'>l} L_{l'})·‖B_{j,l}‖₂·‖A_{j,l}‖₂·H_l
是端到端输出扰动上界（引理 92）。H_l 由区间界传播给出，或作为校准假设 A4 以 ≥1−ε_H 成立。

**定义 B（秩—证据对应）** 设目标修正 W*−W_0 的奇异值为 σ_1≥σ_2≥…。达到残差 ε 的最小秩为 r*(ε)=#{i:σ_i>ε}；Eckart–Young 给出 rank-r 最优残差 = σ_{r+1}。因此「申请秩 r」必须同时提交「σ_{r+1}≤ε 的校准证据」，秩预算 Σr_j≤r_max 是硬契约。

**定义 C（课程层级与认证覆盖域）** 层级 L_0≺L_1≺…≺L_m，难度 D(x)∈[0,1] 由语义新颖度、杂波、动态密度、光照等签名合成；x 的层级 ℓ(x)=min{ℓ:D(x)≤d_ℓ}。认证覆盖域 C_ℓ 是第 ℓ 层校准样本在**多签名空间**（语义嵌入 × 几何足迹 × 动态特征）中的 ε-球并集；只有全部签名都落入 C_ℓ 才视为「已认证」。

**定义 D（层级证书与运营包络）** ODD_t = 当前已认证的最高层级；层级证书 Ĉ_t^ℓ=(ĝ_min, ê_max, γ̂_grasp, β_ℓ, n_t, ℓ, κ_adapt)，其中 β_ℓ=β_base,j+β_adapt,j+λ·sup_{x∈Φ(ζ)}T(x)。Ĉ_t^ℓ valid ⇔ v10 定义 543 全条件 ∧ β_ℓ≤β_STF^v10（层级校准集上 ≥1−ε_β）∧ Φ(ζ) 的全部签名 ∈ C_ℓ ∧ ℓ(Φ)≤ODD_t ∧ 适配器门控 margin>δ_gate。

**定义 E（晋升谓词与 PAC 界）** 第 j 层证据记录 E_j=(n_j, cover_j, R̂_j, collision_j, hard_viol_j, β_j)。晋升 ⇔ n_j≥N_min ∧ R̂_j+√(log(1/δ_p)/(2n_j))≤η_j ∧ cover_j≥1−ε_c ∧ collision_j=hard_viol_j=0（PAC 式高概率界，引理 94）。降级 ⇔ 任一碰撞/硬违规，或 R̂_j>β_j+δ_r；降级在下一个块边界生效（≤1 块）。

**定义 F（白名单守卫）** 50Hz 五检：v10 四检之外增第 5 检「包络/适配器一致性」：ℓ(Φ)≤ODD_t ∧ 签名∈C_{ℓ} ∧ adapter.select(x) 的 top-2 margin>δ_gate；任一失败 ⇒ 回退基座 + β_STF 并切最近中止点/安全停驻。总预算 ≤0.5ms。

**定义 G（有效块长，v11）**
```
K_eff(t) = 1                                          若 ¬U_t^sem 或 Ĉ_t^ℓ 不可得 或 ℓ(Φ)>ODD_t
         = 2                                          若 NRB 处于 Π_r 或课程处于 L_0
         = max(1, ⌊K_max·(1 − min(1, max(Δ_dom/τ_dom,
                    sup_走廊 T/τ_sem, D(Φ)/d_{ODD})))⌋)  否则
```
第三门控项 D(Φ)/d_{ODD} 把「距已认证边界多远」显式并入块长：越接近包络边缘块越短。

## 4. 与基线的接口（如何退化）

- 适配器不可用 / 门控歧义（top-2 margin≤δ_gate）/ 谱界校验失败 ⇒ 基座 F̂_q + β_STF：**等价 v10**；
- 课程阶梯失效 / 证据账本缺口 ⇒ ODD_t=L_0=Π_r：行为子集于 v10；
- 回放缓冲失效 ⇒ 禁止晋升、冻结当前层级（不扩权）、适配器回退基座；
- STF/NRB/LS/台账失效 ⇒ 沿 v10 退化链；**任何适配器/课程组件失效不得使 β 变小**（单调退化约束）；
- AC 证书失效 ⇒ K=1（v10 Level-1 原样）；ID 失效 ⇒ 全模块 active、归因冻结（v10 Level-3 原样；适配器训练/课程晋升 φ^elig=false，永不蒸馏）。

## 5. 预期贡献

1. **有界适应证书**：把 LoRA 的谱界变成可进证书的误差预算，秩即证据（定义 549–551，引理 92）；
2. **能力课程包络**：从黑名单检测转为白名单认证，层级晋升/瞬时降级，错误晋升概率可界（定义 552–555，引理 93–94）；
3. **回放与适配器隔离**：冻结基座 + 正交适配器 + 回放，旧层不遗忘、组合干扰可界（定义 556，引理 95）；
4. **证据预算与契约**：秩/内存/能耗配额与部署期静态校验（定义 557，引理 96），E591–E610 覆盖秩扫描、晋升可靠性、长尾拒绝、投毒、遗忘、量化补偿与长跑竞赛。

## 6. 本轮最大风险

**一句话**：课程晋升证据与低秩误差界都在有限、非对抗校准集上估计——分布偏移或被投毒的校准数据可能让系统「错误晋升」到适配器并不成立的层级，而低秩适配与课程证书会给它两层虚假自信（「模型已修好」＋「证据已通过」），此时白名单反而变成了一张被污染的通行证。

**新增定义 549（低秩适配器与认证扰动界）** 对第 l 层基座权重 W_{0,l}，适配器 j 定义 W_{j,l}=W_{0,l}+B_{j,l}A_{j,l}（B∈R^{d×r}, A∈R^{r×k}，r≤r_j）。设第 l 层认证激活球 ‖h_l‖≤H_l（区间界传播给出，或校准假设 A4 以 ≥1−ε_H 成立），下游复合 Lipschitz 常数为 L_{l+1:L}。定义
```
β_adapt,j = Σ_{l∈S_j} (Π_{l'>l} L_{l'}) · ‖B_{j,l}‖₂ · ‖A_{j,l}‖₂ · H_l
```
为端到端输出扰动上界；实际证书使用 β_adapt,j^+ = β_adapt,j + √(log(1/δ_c)/(2n_c))（校准集有限样本修正）。

**新增定义 550（适配器库、门控与组合干扰）** 库 𝒜={A_j} 按课程层级索引。门控 g_j(x) 由语义原型距离与层级匹配合成；运行时选 top-1，若 top1−top2≤δ_gate 则判歧义并回退基座。运行时**每个块至多激活一个适配器**；组合仅允许来自离线预认证对 (j,k)，其交叉干扰界
```
κ_{jk} ≤ min(‖B_j‖₂‖A_k‖₂, ‖B_k‖₂‖A_j‖₂) · sinθ_{jk}
```
且须满足 κ_{jk}≤δ_comp；未预认证的配对一律禁止组合。

**新增定义 551（秩—证据对应与容量预算）** 设目标修正 W*−W_0 的奇异值为 σ_1≥σ_2≥…。Eckart–Young 给出最优 rank-r 残差（谱范数）=σ_{r+1}。定义最小证据秩 r*(ε)=#{i:σ_i>ε}。申请秩 r 的适配器必须提交「σ_{r+1}≤ε 且覆盖 ≥1−ε_β」的校准证据；全局秩预算 Σ_j r_j≤r_max，且部署期静态校验。

**新增定义 552（课程层级与难度函数）** 层级 L_0≺…≺L_m，难度上界 0≤d_0<…<d_m≤1。多签名难度
```
D(x) = 1 − Π_{s∈{sem,geo,dyn,light}} (1 − D_s(x))   （saturating 合成，单调）
```
其中 D_s 为各签名的归一化稀有度/复杂度。x 的层级 ℓ(x)=min{ℓ:D(x)≤d_ℓ}；若 D(x)>d_m 则 ℓ(x)=∞（包络外）。

**新增定义 553（证据记录与晋升/降级谓词）** 第 j 层证据 E_j=(n_j, cover_j, R̂_j, collision_j, hard_viol_j, β_j)，其中 R̂_j 为经验证书失效率。晋升谓词：
```
promote(j) ⇔ n_j≥N_min ∧ R̂_j + √(log(1/δ_p)/(2n_j)) ≤ η_j
            ∧ cover_j ≥ 1−ε_c ∧ collision_j=0 ∧ hard_viol_j=0
```
降级：任一碰撞/硬违规，或 R̂_j>β_j+δ_r，或适配器谱界校验失败 ⇒ **下一个块边界前**降一级（≤1 块生效）。晋升一次只升一级，不跳级；跳级需 2×N_min 且预注册例外审批入 Ψ。

**新增定义 554（认证覆盖域与层级证书）** 认证覆盖域 C_ℓ 为第 ℓ 层校准样本在**多签名空间**中的 ε-球并集：
```
C_ℓ = ⋃_{x_i∈D_ℓ} B_ε(sem(x_i)) × B_ε(geo(x_i)) × B_ε(dyn(x_i))
```
只有全部签名都落入 C_ℓ 才算「已认证」（对抗必须同时骗过语义、几何、动态三类签名）。层级证书
```
Ĉ_t^ℓ = (ĝ_min, ê_max, γ̂_grasp, β_ℓ, n_t, ℓ, κ_adapt)
β_ℓ = β_base,j + β_adapt,j + λ·sup_{x∈Φ(ζ)}T(x)
```
valid ⇔ v10 定义 543 全条件 ∧ β_ℓ≤β_STF^v10（层级校准集上 ≥1−ε_β）∧ 全部签名∈C_ℓ ∧ ℓ(Φ)≤ODD_t ∧ 门控 margin>δ_gate。

**新增定义 555（课程节奏与运营包络）** ODD_t = max{ℓ: promote(ℓ) 成立且其下各层仍有效}。系统从 ODD_0=L_0=Π_r 起步；晋升按定义 553 逐级进行；降级瞬时（下一块边界），随后 ODD_t 单调不增，直到重新累积证据。**棘轮性质**：晋升慢、降级快，任何硬违规都使包络回退而非仅局部修正。

**新增定义 556（回放与适配器隔离）** 回放缓冲 Ω 按层级配额保存 (签名, 动作, 结果, 证书) 样本；训练适配器 j 时以固定比例混入 Ω_{<j}。冻结基座 + 正交惩罚（要求训练后 θ_{jk}≥θ_min）使旧层遗忘界 ≤β_adapt,j+κ_{jk}。Ω 失效 ⇒ 禁止晋升并冻结当前 ODD_t（不降级、不扩权）。

**新增定义 557（证据预算契约与单调退化）** 契约增列秩/内存/能耗配额：Σr_j≤r_max、ΣM_j≤RAM、ΣE_j≤25W；运行期越配额即注 v^⊥（回退基座）。**单调退化约束**：任一新增组件失效时，其替换路径的 β 必须 ≥ 失效前的 β，ODD 必须 ≤ 失效前 ODD——禁止「组件坏了反而更乐观」。

**新增定义 558（有效块长，v11）**
```
K_eff(t) = 1                                          若 ¬U_t^sem 或 Ĉ_t^ℓ 不可得 或 ℓ(Φ)>ODD_t
         = 2                                          若 NRB 处于 Π_r 或课程处于 L_0
         = max(1, ⌊K_max·(1 − min(1, max(Δ_dom/τ_dom,
                    sup_走廊 T/τ_sem, D(Φ)/d_{ODD})))⌋)  否则
```
第三门控项 D(Φ)/d_{ODD} 把「足迹距已认证边界多远」并入块长：越接近包络边缘块越短。

## 2. 形式化定义（要点与升级）

**定义 540–548** 继承 v10；STF 的 τ_sem 不再是安全论证的唯一分割面——它只保留为**块长门控**与领先指标（P14 降级为充分非必要），白名单包络（定义 554–555）成为安全主证据。
**升级定义 543（结构化块证书）** 余量由 β_STF 升级为层级索引 β_ℓ；valid 条件增加多签名覆盖与 ℓ(Φ)≤ODD_t。
**升级定义 547（守卫）** 四检→五检，新增第 5 检「包络/适配器一致性」（定义 554/定义 F）。任一失败 ⇒ 先尝试基座回退（适配器问题）或切最近中止点（包络问题）。
**升级定义 539（有效块长）** 见定义 558；新增 D(Φ)/d_{ODD} 门控项与 ODD 条件。
**δ_trigger 五条件** 中「Ĉ_t⁺ valid」升级为「Ĉ_t^ℓ valid ∧ ℓ(Φ)≤ODD_t」；块证书失效与单步条件仍同样触发 M₀ 硬检查，v9 引理 82+81 的「无块内软通过硬失」空洞论证原样保持。

# IP-361 LoRAAdapterBank：冻结基座 + 低秩认证适配器
class LoRAAdapterBank:
    def __init__(self, base, r_max=16, delta_gate=0.05,
                 orth_min=0.35, delta_c=0.05):
        self.base = freeze_quantized(base)      # F̂_q 冻结；INT8 基座
        self.adapters = {}                      # level -> {layer: (B, A)}
        self.r_max, self.delta_gate = r_max, delta_gate
        self.orth_min, self.delta_c = orth_min, delta_c

    def certify(self, j, calib, act_bounds, lip):
        """定义 549：谱范数沿层传播 + 有限样本修正"""
        beta = 0.0
        for l, (B, A) in self.adapters[j].items():
            beta += lip.downstream(l) * norm2(B) * norm2(A) * act_bounds[l]
        n = len(calib)
        return beta + sqrt(log(1.0 / self.delta_c) / (2.0 * n))

    def rank_needed(self, target_delta, eps):
        """定义 551：Eckart–Young 最小秩"""
        s = singular_values(target_delta)
        return sum(1 for x in s if x > eps)

    def select(self, x, level):
        """门控；歧义或未认证层 ⇒ None（回退基座）"""
        cands = {j: g(x) for j, g in self.adapters[level].gates.items()}
        if not cands:
            return None
        top = sorted(cands.items(), key=lambda kv: kv[1], reverse=True)
        if len(top) > 1 and top[0][1] - top[1][1] <= self.delta_gate:
            return None                         # 选择歧义 ⇒ 基座
        return top[0][0]

    def rollout(self, state, actions, adapter=None):
        if adapter is None:                     # 等价 v10：基座 + β_STF
            return self.base.rollout(state, actions)
        return self.base.rollout_with_lora(state, actions,
                                           self.adapters[adapter])


# IP-362 CurriculumLadder：能力课程阶梯（晋升慢、降级快）
class CurriculumLadder:
    def __init__(self, levels, thresholds, N_min=500,
                 delta_p=0.05, eps_c=0.01, delta_r=0.01):
        self.levels = levels                    # d_0 < ... < d_m
        self.thresholds, self.N_min = thresholds, N_min
        self.delta_p, self.eps_c, self.delta_r = delta_p, eps_c, delta_r
        self.evidence = {j: [] for j in range(len(levels))}
        self.ODD = 0                            # 从 L_0=Π_r 起步

    def level_of(self, signature):
        d = difficulty(signature)               # 定义 552 多签名难度
        for j, dj in enumerate(self.levels):
            if d <= dj:
                return j
        return float('inf')                     # 包络外 ⇒ 默认拒绝

    def update(self, j, record):
        self.evidence[j].append(record)

    def can_promote(self, j):
        """定义 553：PAC 式晋升谓词"""
        E = self.evidence[j]
        n = len(E)
        if n < self.N_min:
            return False
        R_hat = mean(e.fail for e in E)
        cover = mean(e.covered for e in E)
        bound = R_hat + sqrt(log(1.0 / self.delta_p) / (2.0 * n))
        return (bound <= self.thresholds[j] and cover >= 1 - self.eps_c
                and all(e.collision == 0 and e.hard_viol == 0 for e in E))

    def promote_once(self, audit):
        j = self.ODD
        if j + 1 < len(self.levels) and self.can_promote(j):
            self.ODD = j + 1                    # 一次一级，不跳级
            audit.append('promote', j + 1, self.evidence[j])

    def demote(self, reason, audit):
        # 硬违规：瞬时降级（下一块边界前），棘轮不回头
        self.ODD = max(0, self.ODD - 1)
        audit.append('demote', self.ODD, reason)


# IP-363 白名单包络守卫：v10 四检 + 第 5 检
def midchunk_guard_v11(chunk, k_exec, live_obs, stf, nrb, ladder, bank):
    """50Hz 五检 ≤0.5ms；返回 ('continue', k+1) 或 ('abort', p*)"""
    if not chunk.cert_still_valid(live_obs):                 # 检 1（v10）
        return ('abort', chunk.nearest_abort(k_exec))
    stop_inv = (live_obs.nearest_clearance
                - chunk.d_brake(live_obs.speed) - chunk.d_safe)
    if stop_inv < chunk.remaining_len(k_exec):               # 检 2（v10）
        return ('abort', chunk.nearest_abort(k_exec))
    if stf.surprise_near(live_obs.pose) > stf.tau_sem:       # 检 3（v10 领先）
        return ('abort', chunk.nearest_abort(k_exec))
    if nrb.fast_norms(live_obs).violated:                    # 检 4（v10）
        return ('abort', chunk.nearest_abort(k_exec))
    # 检 5（v11）：白名单包络 + 适配器一致性（定义 554/定义 F）
    sig = multi_signature(live_obs)                          # sem×geo×dyn
    if (ladder.level_of(sig) > ladder.ODD
            or not chunk.cert.in_coverage(sig)
            or bank.select(live_obs.pose, ladder.ODD) is None
            and chunk.used_adapter is not None):
        return ('abort', chunk.nearest_abort(k_exec))        # 默认拒绝
    return ('continue', k_exec + 1)

## 4. 推导

**引理 92（低秩认证保界）** 设第 l 层适配器扰动 ΔW_l=B_lA_l，激活满足 ‖h_l‖≤H_l，下游复合 Lipschitz 常数为 L_{l+1:L}。则对任意输入，端到端输出扰动
```
‖Δf‖ ≤ Σ_l (Π_{l'>l} L_{l'})·‖B_l‖₂·‖A_l‖₂·H_l = β_adapt
```
证明：‖ΔW_l h_l‖≤‖B_l‖₂‖A_l‖₂‖h_l‖≤‖B_l‖₂‖A_l‖₂H_l，逐层用三角不等式与 Lipschitz 传播即得。组合两适配器 j,k 的交叉项被 min(‖B_j‖‖A_k‖,‖B_k‖‖A_j‖)·sinθ_{jk} 界住（主角定义），故正交惩罚 θ_{jk}≥θ_min 把组合干扰压到 κ_{jk}；未预认证配对禁止组合。Eckart–Young：rank-r 最优残差为 σ_{r+1}，故达到 β_adapt≤ε 的最小秩为 r*(ε)（定义 551）。有限校准集用 Hoeffding 加 √(log(1/δ_c)/(2n_c)) 修正。∎

**引理 93（白名单支配、安全不变式与 v10 风险拆除）** (i) ODD=L_0 时，v11 的执行集 ⊆ v10 的 Π_r 集（L_0 定义即 Π_r）。(ii) 晋升层 ℓ 的证书要求 β_ℓ≤β_STF^v10 且多签名∈C_ℓ；因此晋升只**收紧**有效误差界，不放松 d_safe/τ_eff，v9 引理 82/86 的不变式前提在更强界下仍成立。(iii) 对 v10 的穿透场景：长尾/对抗样本满足 ν≤τ_sem（检 3 不响）且击穿基座模型；v11 的第 5 检不查「是否异常」，而查「签名是否落在已认证 C_ℓ」，该样本按定义不在任何 C_ℓ 中（未被任何层级校准覆盖）⇒ ℓ(Φ)=∞>ODD_t ⇒ 拒绝并切中止点/基座。故 v10 的「检测不响即放行」被替换为「未认证即拒绝」，风险从「分割面召回」转为「覆盖域是否被投毒污染」（见最大风险）。∎

**引理 94（晋升可靠性、降级及时性与活性）** (i) 对第 j 层，n_j 个 i.i.d. 证据样本，Hoeffding 给出 P(真实失效率 > R̂_j+√(log(1/δ_p)/(2n_j))) ≤ δ_p；晋升谓词要求该上界≤η_j，故单层错误晋升概率≤δ_p；对 m 层取并集界得 ≤mδ_p。(ii) 降级由碰撞/硬违规直接触发，不依赖统计证据，在下一个块边界（≤1 块）生效，故违规持续 ≤1 块。(iii) 活性：若分布平稳且每层成功概率有正下界，逐级晋升（不跳级）在有限期望时间内到达该层；一次硬违规使 ODD 减一，恢复需重新累积证据（棘轮）。∎

**引理 95（隔离与抗遗忘）** 基座冻结 + 回放 + 正交惩罚下，训练适配器 j 后旧层 k<j 的输出变化 ≤β_adapt,j+κ_{jk}（引理 92 组合项）。回放混入使旧层经验失效率 R̂_k 的偏移被限制在配额决定的采样误差内；若 R̂_k 超过 η_k 则晋升被阻断。因此旧层遗忘可界且可审计；组合冲突超 δ_comp 的适配器对不得同时激活。∎

**引理 96（预算守恒、秩证据与量化补偿）** (i) 秩预算 Σr_j≤r_max、内存/能耗 ΣM_j≤RAM、ΣE_j≤25W 在部署期静态校验，运行期越界注 v^⊥ 回退基座。(ii) 由 Eckart–Young，秩 r 不能表示残差低于 σ_{r+1} 的修正，故「秩申请」必须附 σ_{r+1}≤ε 的证据，容量增长无免费午餐。(iii) INT8 补偿：令 δ_q=W_fp16−W_int8，取其 rank-r_q 最优近似 B_qA_q，则残余量化误差的谱范数 ≤σ_{r_q+1}(δ_q)，被 β_adapt 吸收；故 F̂_q+LoRA 可在 β_ℓ≤β_STF^v10 下恢复 v10 被量化吃掉的余量，且成本（秩/内存）显式入账。∎

## 8. 本轮最大风险

**一句话**：课程晋升证据与低秩误差界都在有限、非对抗校准集上估计——分布偏移或被投毒的校准数据可能让系统「错误晋升」到适配器并不成立的层级，而低秩适配与课程证书会给它两层虚假自信（「模型已修好」＋「证据已通过」），此时白名单反而变成了一张被污染的通行证。
