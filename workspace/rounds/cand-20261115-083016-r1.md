# 第 4 轮（灵感循环第 4 轮；本轮灵感：「仿真到现实」×「服务设计」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge（IP-315–320；定义 416–431）与第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。两个新灵感各沿一条轴升级：**仿真到现实升级「证据来源与信任」**，**服务设计升级「承诺与价值」**。任一环节不可用都必须能一键退回 InstructGauge；仿真与服务蓝图是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（仿真到现实 → 把仿真从「真相替代品」降级为「有价提案者」）**
直觉：仿真能廉价覆盖真实世界难以采样的区域，但它最容易制造的错觉是「仿真里已经验证过」。在计量系统里，仿真不应被当作证据，而应被当作**先验与提案**：它提出假设、候选探测与区域风险估计；真实回执才有资格签发最终契约。关键不是「sim2real 迁移率有多高」，而是**每一条仿真证据的信任额度有账可查、有界、可被真实证据补充**。这等于把 sim2real 从「模型精度问题」改写成「证据溯源与信任会计问题」：仿真可以帮你更快地提出正确问题，但不能替你回答「真实世界是否如此」。

**灵感 2（服务设计 → 把标定从「内部过程」提升为「可承诺的服务」）**
直觉：服务设计关心的不是单个组件，而是端到端旅程、前台承诺、后台支撑、关键时刻、失败点与补救。机器人的感知/探测能力最终是**为下游任务或人提供服务**：前台是「在什么时刻、以多大精度、多长延迟交付」，后台是探测与标定，支撑是仿真器、数据集与人工。服务设计补上了现有框架缺的三样东西：**SLO/错误预算**（可承诺，而不仅是统计覆盖）、**蓝图完整性**（每个前台承诺必须有后台证据路径）、**失败点与补救**（承诺失效时如何有界地优雅降级，而不是静默降级）。

**灵感 3（耦合 → 「仿真验证的服务蓝图」会变成服务剧场）**
直觉：最危险的耦合是「蓝图 + 仿真」：一个在仿真里自洽、指标全绿的蓝图，可以在真实世界里完全不对应，因为仿真同时是**证据提供者**又是**评估裁判**。这就是服务剧场（service theater）。解法不是禁用仿真，而是把**提案者与验证者分离**：仿真只能进入**影子契约**与规划；**活契约**必须由真实锚点签发；每个关键时刻必须有真实锚点；区域外不支持就**拒绝承诺**（abstain）。再叠加现实差距证书、仿真信任预算、旅程感知分配与服务恢复自动机，把「自证」压成可检测、可证伪的失败。

## 1. 研究问题（本轮要回答什么）

- **Q1（仿真证据的边界）**：仿真何时可以参与标定？能否用「溯源 + 现实差距证书 + 信任预算」把仿真证据变成有界、可审计、可退回的增强，而不是新的过拟合入口？
- **Q2（服务承诺的可证性）**：能否把感知标定表达为带 SLO / 错误预算 / 失败点的服务蓝图，并保证每个前台承诺都有真实证据路径与补救路径？
- **Q3（耦合的剧场效应）**：当仿真参与服务蓝图的验证，如何防止「自证」？能否用提案/验证分离、影子/活契约、区域外拒绝，把服务剧场压成可检测、可证伪的失败？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P1 证据溯源与提案/验证分离（Provenance & Separation）**
每条证据带 provenance（`R` 真实 / `RS` 仿真经真实配对确认 / `S` 仅仿真 / `H` 人工断言）；标定分**影子契约**（可含 `S`）与**活契约**（必须有真实锚点）。仿真只改先验、候选与风险估计，不直接签发前台承诺。形式化：`promote(κ_shadow → κ_live)` 需要真实锚点、有效 RGC 与晋升审计。

**P2 承诺可证与蓝图完整（Commitment Traceability）**
每个前台 SLO 必须能沿「SLO → 关键时刻 → 后台探测 → 证据 → 回执」追到真实锚点，并有失败点触发词与补救动作。蓝图不完整 ⇒ **拒绝部署/拒绝承诺**，而不是静默降级。这把「服务承诺」变成可类型检查、可审计的对象。

**P3 信任会计与区域外拒绝（Trust Accounting & Refusal）**
仿真证据按区域消耗有限信任预算，有效样本量 `n_eff = n_real + Σ w_gap·w_budget`；现实差距证书只在有支撑的区域有效；区域外或证书失效 ⇒ 拒绝承诺（abstain）或退回真实-only。直观：仿真的「信用额度」是有限的，且只能由真实锚点充值。

## 3. 与基线的接口（如何退化）

- 无仿真 / 差距证书不可用 / 信任预算耗尽 ⇒ 仿真仅作规划先验，活契约只由真实回执签发 ⇒ 等价于 InstructGauge 的 real-only 路径；
- 无服务规格 / 蓝图不完整 ⇒ 目标退回信息增益（InstructGauge / ToolGauge），前台承诺退化为覆盖阈值；
- MoTG 不可用 ⇒ 逐条走 CVC 与共形覆盖（InstructGauge）；
- 恢复自动机不可用 ⇒ 直接安全降级 / 人工接管（ToolGauge 的 stub-and-red）；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「仿真只提案、真实才签发」的证据溯源口径，把 sim2real 从模型精度问题变成可审计的信任会计；
2. 一个带**现实差距证书**与**仿真信任预算**的仿真证据准入机制，使仿真增强有界、可解释、可一键退回；
3. 一个**服务蓝图编译器 + 关键时刻守卫 + 服务恢复自动机**，把标定承诺变成可追责、可补救的端到端服务；
4. 一个**旅程感知的探测分配目标（SVoI）**，把信息增益升级为「下游 SLO 价值」，并给出可证伪的最优性条件；
5. 一条完整可证伪路径：E457–E472 覆盖溯源隔离、差距证书、迁移界、蓝图完整性、MoTG 安全、恢复、真实部署与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：当仿真同时充当「蓝图的设计器」和「承诺的验证器」时，系统会陷入**服务剧场**——蓝图与 SLO 在仿真中自洽且全绿，却在真实分布外完全失效；溯源与差距证书只能约束「有真实锚点覆盖的区域」，无法消除「真实锚点本身不具代表性」与「SLO 被 Goodhart 化」这两种残余风险。

## 2. 形式化定义（要点）

**定义 448（证据溯源格 EPL）** 令 `P = {R, RS, S, H}`，其中 `R` 为真实回执，`RS` 为「仿真预测 + 真实配对确认（差距在 RGC 界内）」，`S` 为仅仿真，`H` 为人工断言；数值主张不接受纯 `H`。序关系 `R ≻ RS ≻ S`。对证据包 `E`，`prov(E) = ⊔_{e∈E} prov(e)`。**真实锚定**定义为
`RealAnchored(E, c, r) ⇔ ∃e∈E: prov(e)∈{R,RS} ∧ region(e)=r ∧ supports(e,c)`。
`RS` 仍是真实锚点，但它携带一个已知差距上界；`S` 永远不是。

**定义 449（影子/活契约与晋升）** 契约对 `K = (κ_shadow, κ_live)`。`κ_shadow` 可用任意来源证据校准；`κ_live` 只可用 `RealAnchored` 证据，且所在区域 `RGC` 有效。晋升
`promote(e): κ_shadow → κ_live` 当且仅当 `RealAnchored(E, c, r) ∧ RGC(r,c).valid ∧ n_eff(r) ≥ n_min ∧ promote_audit(e)`。以下任一条件触发**降级** `demote`：RGC 失效、`U_r > δ_g`、`EB_m ≤ reserve`、`GH_m > δ_GH`。前台承诺只读 `κ_live`；影子契约只能影响规划先验与候选排序。

**定义 450（现实差距证书 RGC）** 对区域 `r` 与主张 `c`，配对探测给出差距样本 `d_i = d(f_real(x_i), f_sim(x_i))`。令 `Q_r(1−β)` 为差距分布的 `(1−β)` 分位。共形上界 `U_r(α,β)` 满足
`P(Q_r(1−β) ≤ U_r(α,β)) ≥ 1−α`
（在 `r` 内配对样本可交换时由共形分位给出）。证书
`RGC(r,c) = (U_r, δ_g, supp_r, n_r, β, cov)`，
`valid ⇔ U_r ≤ δ_g ∧ n_r ≥ n_min ∧ support_ok(r,c)`。
`supp_r` 是经真实配对覆盖的支撑域；`support_ok` 要求目标输入落在 `supp_r` 内。无效 ⇒ 区域 `r` 的仿真证据被**隔离**（可留在影子契约，不可晋升）。

**定义 451（仿真信任预算 STB）** 区域预算
`T_r(t+1) = clip(T_r(t) + a·1[真实锚点] − b·1[仅仿真证据被使用], 0, T₀)`。
有效样本量
`n_eff(r) = n_real(r) + Σ_{i∈S_r} w_i`，
`w_i = w_gap(r)·w_budget(T_r)`，`w_gap = clip(1 − U_r/δ_g, 0, 1)`，`w_budget = T_r/T₀`，并加总上限 `Σ_i w_i ≤ W_max(T_r) = κ·T_r`。
覆盖保证使用 `n_eff`。当 `T_r → 0` 或 `U_r → δ_g` 时 `w_i → 0`，`n_eff → n_real`：**仿真不能无限购买覆盖**。真实锚点既补充 `n_real`，又充值 `T_r`，故「仿真提议、真实充值」形成闭环。

**定义 452（服务蓝图 SB）** `B = (F, K, Sup, FP, L, Rec, Vis)`：
- `F = {(m, τ_m, w_m)}`：前台 SLO（指标、目标成功率、窗口/权重）；
- `K = {(m,k)}`：关键时刻（依赖 SLO `m` 的前台承诺点）；
- `Sup`：后台/支撑义务（探测族、证据 provenance 要求、标定程序、仿真资产）；
- `FP = {(p, trigger, impact, severity)}`：失败点；
- `L`：泳道（前台/后台/支撑）；
- `Rec: FP → RecoveryAction`：补救动作与 `T_rec`；
- `Vis`：可见线，规定哪些信号对下游任务/人可见。
**证据路径** `path(m) = m → k → Sup → evidence → real anchor`。蓝图把「服务承诺」变成可检查的图对象，而不是散落的实现细节。

**定义 453（SLO 与错误预算）** `SLO_m = (m, τ_m, w_m)`，允许违例率 `α_m := 1−τ_m`。错误预算
`EB_m(t) = α_m·w_m − V_m(t)`，
`V_m(t)` 为累计加权违例。`EB_m(t) ≤ reserve` ⇒ 当前窗口禁止前台承诺，必须先补救/退避/abstain。错误预算不是日志字段，而是**运行时准入门槛**。

**定义 454（关键时刻守卫 MoTG）** 在时刻 `t`、区域 `r_t`，对依赖指标 `m` 的前台承诺：
`MoTG(m, κ_live, t) = valid(κ_live, r_t) ∧ prov_ok(κ_live, m) ∧ RGC(r_t,m).valid ∧ EB_m(t) > reserve ∧ ¬∃ open FP(m)`。
任一为假 ⇒ 执行 `Rec(FP)` 或 abstain；**绝不静默改用 `κ_shadow`**。这是「服务承诺前的最后一道真实锚点检查」。

**定义 455（服务价值信息 SVoI 与旅程目标）** 旅程 `J = (e_1…e_J)`，遭遇 `e_j` 的关键时刻为 `MoT(e_j)`，下游代价 `c_j`。对探测动作 `a`：
`SVoI(a) = Σ_j c_j·ΔP(MoT(e_j) 通过 | a) − λ·c(a)`。
把 InstructGauge 的分块目标升级为
`a* = argmax_{a admissible} [ ΔH(a) + w_S·SVoI(a) + w_align·A(ι,a) − λ_cost·c(a) ]`，
`s.t. shield(ι), Barrier(a), B_chunk ≤ B_left, prov_constraints`。
当 `c_j` 均匀且 `MoT` 通过概率与信息增益对齐时，`SVoI` 退化为 `ΔH`（可检验的退化条件）；当关键时刻下游代价高度不均时，`SVoI` 会把探测预算从「平均信息量最大」拉向「最贵失败点」。

**定义 456（配对仿真-现实探测设计）** 对区域 `r`，在匹配上下文（同场景类、同工具、同名义状态）下成对执行 `(a, x)` 于 sim 与 real，得到 `d_i`。按区域/上下文分层取共形分位。若真实侧不可安全执行（如不可逆动作），只能做**安全影子探测**并标 `S` 而非 `RS`；`S` 不能晋升。配对设计是 RGC 的识别前提：没有配对，就没有可证伪的差距证书。

**定义 457（失败点与严重度）** `FP = (p, trigger, impact, severity)`；`trigger` 必须是由回执可评估的可测谓词（沿用定义 443 的纪律，禁止自然语言守卫）。严重度偏序 `≺_sev` 把失败点分为可补救 / 不可补救；不可补救失败点必须在承诺前触发 abstain。

**定义 458（服务恢复自动机 SRA）** 带守卫迁移系统，状态 `{normal, degraded, abstain, handoff}`；迁移守卫来自回执；补救动作时长 ≤ `T_rec`；存在良基秩 `rank: State → ℕ`，每个补救循环严格下降。要求：从任一失败点在 ≤ `T_rec` 内到达 `safe / abstain / handoff`；无 livelock；每次补救写入 `ServiceCert`。这把「出问题怎么办」从临时分支变成可验证自动机。

**定义 459（服务级共形校准 SL-Cal）** 分层标签 `s = (lane, MoT 类型, provenance 类, 区域)`。对每层用有效样本量 `n_eff` 取共形分位 `q_s`，使层内覆盖 `P(h*∈H_s | s) ≥ 1−α`（在加权可交换性与 RGC 有效借用下）。若 `n_eff < n_min` ⇒ 回退到更粗层，再回退全局 **real-only**。这是 InstructGauge `SC-Cal` 的溯源/服务泳道扩展。

**定义 460（蓝图完整性与孤儿 SLO）** `Complete(B) ⇔ ∀m∈F: ∃ path(m) 到达真实锚点 ∧ ∀p∈path_failpoints(m): Rec(p) 已定义`。
`Orphan(B) = {m∈F : ¬∃ path(m) 到真实锚点}`。
部署准入：`Orphan(B)=∅` 且 `Complete(B)`；否则拒绝并输出 `BlueprintCert(B, Orphan(B), missing_recoveries)`。这把「承诺不可证」变成**部署前的硬失败**，而不是上线后的静默漂移。

**定义 461（服务审计证书 ServiceCert）**
`ServiceCert = (B, SLO, RGC, STB snapshot, EB, MoT log, promotion/demotion log, recovery log, provenance map)`。
人类审计可沿「服务承诺 → 关键时刻 → 后台证据 → 真实回执」四级链复现每一次前台承诺，并区分「真实支撑」与「仿真借用」。

**定义 462（Goodhart 风险信号）** 对每个 SLO `m`，跟踪优化代理指标与下游真实结果的一致性：
`GH_m = |corr(proxy_m, outcome_m) − 1|`（或等价的分布散度）。
若 `GH_m > δ_GH` 连续 `q` 个窗口 ⇒ 冻结该 SLO 的优化，要求**结果重锚定**（重新采样真实 outcome，重估蓝图）。原因：服务设计天然鼓励优化「可测承诺」，而可测承诺不等于真实能力；没有 GH 监视，SLO 会被系统性游戏化。

**定义 463（严格退化等价）** 当仿真关闭（`P={R}`）、RGC 空、无服务规格时，ServiceGauge 的**活路径**与 InstructGauge **逐步等价**：EPL 把所有回执标 `R`，RGC 恒真/空，STB 无关，MoTG 退化为 CVC + 覆盖阈值，JPA 退化为 `ΔH`，SRA 退化为 `stub-and-red`。新增的 provenance / blueprint / ServiceCert 日志均为**纯投影**，不改变数值行为。此定义是整条退化链的锚点。

## 3. 关键算法骨架

```python
# IP-328 EPL：证据溯源与影子/活契约分离
class EPL:
    def ingest(self, receipt, source):
        prov = "R" if source.is_real else ("RS" if source.paired_real_ok else "S")
        receipt.prov = prov
        self.store[receipt.id] = receipt
        return receipt

    def can_promote(self, evidence, claim, region):
        return (self.real_anchored(evidence, claim, region)
                and self.rgc.valid(region, claim)
                and self.stb.n_eff(region) >= self.n_min)

    def real_anchored(self, evidence, claim, region):
        return any(r.prov in ("R", "RS") and self.supports(r, claim)
                   and self.region_of(r) == region for r in evidence)

# IP-329 RGC：配对探测 + 区域共形上界
class RGC:
    def certify(self, region, claim):
        d = [dist(f_real(x), f_sim(x)) for x in self.paired[region]]
        if len(d) < self.N_MIN or not self.support_ok(region, claim):
            return Cert(region, claim, valid=False, U=INF, cov=0)
        U = conformal_quantile(d, 1 - self.ALPHA)     # gap 分位的共形上界
        return Cert(region, claim, valid=(U <= self.DELTA_G),
                    U=U, cov=len(d), supp=self.support[region])

# IP-330 STB：信任预算与有效样本量
class STB:
    def update(self, region, used_sim, real_anchor):
        self.T[region] = clip(self.T[region]
                              + self.A * real_anchor
                              - self.B * used_sim, 0, self.T0)

    def n_eff(self, region, n_real, sim_receipts):
        w = [self.w_gap(region) * self.w_budget(region) for _ in sim_receipts]
        if sum(w) > self.W_max(region):
            w = scale_to_cap(w, self.W_max(region))
        return n_real + sum(w)          # T -> 0 ⇒ w -> 0 ⇒ real-only

# IP-331 SBP：服务蓝图编译 + 完整性检查
class SBP:
    def compile(self, service_spec):
        F, K, Sup, FP, Rec, Vis = parse(service_spec)
        B = Blueprint(F, K, Sup, FP, Rec, lanes=..., visibility=Vis)
        orphans = [m for m in F if not self.real_anchor_path(B, m)]
        missing = [p for m in F for p in self.path_failpoints(B, m)
                   if Rec.get(p) is None]
        return B, BlueprintCert(B, orphans, missing)

    def deployable(self, B, cert):
        return not cert.orphans and not cert.missing

# IP-332 MoTG：关键时刻守卫
def moment_of_truth_guard(m, kappa_live, region, t, B, EB):
    return (valid(kappa_live, region)
            and prov_ok(kappa_live, m)             # 必须有 R/RS 锚点
            and B.rgc.valid(region, m)
            and EB[m] > RESERVE
            and not any(open_fp(B, m)))            # 无开放失败点

# IP-333 JPA：旅程感知分配（SVoI / 成本 贪心）
def journey_allocate(journey, tools, budget):
    cands = enumerate_probes(journey, tools)
    scored = sorted(cands,
                    key=lambda a: SVoI(a, journey) / cost(a),
                    reverse=True)
    return knapsack(scored, budget)                # 子模 ⇒ (1-1/e) 近似

# IP-334 SRA：失败点恢复（良基秩 + 有界时间）
def recover(fp, state):
    for step in recovery_plan(fp):                 # rank 严格下降
        state = apply_recovery(step, state)
        if state.safe:
            return state
    return handoff(state)                          # 有界时间内人工接管

# IP-335 ServiceGauge-8C 闭环
def servicegauge_8c(M, s, ell=None):
    # S：服务规格与蓝图（部署前硬失败：孤儿 SLO / 缺补救）
    B, bcert = M.sbp.compile(M.service_spec(s))
    if not M.sbp.deployable(B, bcert):
        return refuse_and_audit(s, bcert)

    # I：可选指令接地（InstructGauge NLI-Box）
    iota = (M.nlib.ground(ell, M.scene, M.ontology)[0]
            if ell is not None else M.default_iota)

    # H：假设；仿真只进先验/影子契约
    H_s = M.lbox.hypothesize(s, M.dbox.R[s], iota, prior=M.epl.shadow_prior(s))

    # C：旅程感知的探测分配（SVoI，而非纯 ΔH）
    a = M.jap.allocate(M.journey(s), M.tools, M.budget_left(s))

    # E：执行并给每条回执打 provenance
    receipts = M.exec.execute(a, provenance=M.epl)

    # 关键闸：没有真实锚点 ⇒ 只留在影子契约，前台承诺必须走补救
    if not M.epl.can_promote(receipts, s, region(s)):
        M.epl.keep_shadow(receipts)
        return M.sra.recover(FP["no_real_anchor"], M.state)

    # C：CVC + RGC 双证书
    cert = M.cvc.commit(a, M.env, iota)
    rgc = M.rgc.certify(region(s), s)

    # V：关键时刻守卫 + 错误预算
    if not moment_of_truth_guard(s, M.dpe.live, region(s),
                                 M.now, B, M.eb):
        return M.sra.recover(open_fp(B, s), M.state)

    # U：真实锚点签发活契约，更新 EB / STB，写审计
    live = M.apcal.update_live(receipts, cert, rgc, B)
    M.stb.update(region(s), used_sim=len(M.epl.shadow(s)),
                 real_anchor=True)
    M.eb.consume(s, cert)
    M.audit.append(ServiceCert(B, live, rgc, M.stb.snapshot(),
                               M.eb.snapshot(), cert))
    return True

# 主闭环：50Hz 路径不变，服务/仿真记账异步
def ServiceGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(servicegauge_8c, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（溯源隔离：仿真不能直接进前台）** 若 EPL 与 MoTG 成立，则任一前台承诺使用的活契约都至少有一个 `R` 或 `RS` 真实锚点；因此纯 `S` 证据只能影响影子契约与探测提案，不能直接改变已认证的前台行为。故 sim2real 差距只有在污染真实锚点或 RGC 时才会造成前台违例，而不能仅凭「仿真里很好」就穿透到前台。
*证明骨架*：晋升规则要求 `RealAnchored`；MoTG 只接受 `κ_live`；若某前台承诺仅由 `S` 支撑，则其活契约无法通过晋升，矛盾。

**引理 60（仿真信任折扣：没有免费的覆盖）** 在区域 `r` 内配对样本可交换、且仿真-真实权重为有界密度比估计时，以权重 `w_i` 做加权共形校准，真实分布上的覆盖满足
`P(h*∈H) ≥ 1−α − ε_w`，
其中 `ε_w` 随权重误差与 `U_r/δ_g` 增大。又由定义 451，`n_eff ≤ n_real + W_max(T_r)`，且 `T_r→0 ∨ U_r→δ_g ⇒ w_i→0`。故仿真带来的覆盖增益被信任预算显式夹住；预算耗尽时精确退化为 real-only。
*证明骨架*：加权共形预测定理 + 权重单调性；`W_max(T_r)=κT_r` 给出总权重上界。

**引理 61（现实差距迁移界）** 设下游指标 `h` 对契约参数 `L`-Lipschitz，`RGC(r,c)` 有效（`U_r` 是差距 `1−β` 分位的 `1−α` 上界），且目标输入落在 `supp_r` 内。则
`P(|h(κ_real) − h(κ_sim)| ≤ L·U_r) ≥ 1−α−β`。
`supp_r` 外无有限界，必须 abstain。
*证明*：Lipschitz 性 + 三角不等式 + 分位定义。该界是 E460 的可证伪对象。

**引理 62（关键时刻安全与错误预算）** 若每次前台承诺都通过 MoTG，且补救失败率 ≤ `R_f`，则实际 SLO 违例率满足
`P(violation) ≤ α + R_f`；
在补救完全成功时 `≤ α`。
*证明骨架*：MoTG 只在 `EB_m > reserve` 时放行；`EB_m` 在无承诺时不变、在承诺/违例时按定义扣减，构成受控超鞅；可选停时给出违例率界；补救失败最多额外贡献 `R_f`。

**引理 63（旅程分配的近似最优性）** 若 `SVoI` 在候选探测集上单调子模、成本可加，则按 `SVoI/cost` 的贪心分配达到 `(1−1/e)` 最优；若 `SVoI` 线性，则贪心精确。
*证明*：子模函数最大化贪心的标准 `(1−1/e)` 界；线性时排序即精确背包（成本可加、单位价值递减为常数）。
推论：当关键时刻下游代价高度不均时，`SVoI` 会把预算从「平均信息增益最大」转向「最贵失败点」；E464 检验该转向是否真的提升 SLO 合规。

**引理 64（蓝图完整性 ⇒ 无孤儿承诺）** `Complete(B)` 蕴含每个前台 SLO 都有真实锚点路径与补救路径；`Orphan(B)≠∅` 时 SBP 拒绝部署。因此系统不存在「没有真实证据路径」的前台承诺，也不存在「失败后无补救」的承诺。
*证明*：由 `Complete` 定义与 `deployable` 准入门槛直接得到；拒绝部署是定义 460 的结构性硬失败。

**引理 65（恢复终止与有界时间）** 若 SRA 的秩函数良基、且所有补救动作时长 ≤ `T_rec`，则从任一失败点在 ≤ `T_rec` 内到达 `safe / abstain / handoff`，无 livelock。
*证明*：每次补救迁移使 `rank` 严格下降；良基性排除无限下降链；动作时长上界给出时间界。

**引理 66（严格退化等价）** 关闭仿真（`P={R}`）、RGC 空、无服务规格时，ServiceGauge 活路径与 InstructGauge 逐步等价；继续退化得 ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。新增日志为纯投影。
*证明*：逐阶段对应：`S` 恒真 ⇒ 跳过蓝图门；`I/H` 同 InstructGauge；`JPA→ΔH`；`EPL` 全 `R` ⇒ `can_promote` 恒真；`MoTG→CVC+覆盖`；`SRA→stub-and-red`。数值路径不变，日志只增不改。

## 8. 本轮最大风险

**一句话**：`SBP` 的服务蓝图与 `RGC/STB` 的仿真信任会计在接口处形成**服务剧场**——蓝图和 SLO 可以在仿真中自洽且全绿，`RGC` 也能给出「区域内有效」的漂亮证书，但真实锚点若只覆盖了容易采样的区域，系统就会在分布外把「仿真里已验证」误当成「真实可承诺」；而服务设计对可测承诺的优化又会诱发 Goodhart 化，使 SLO 达标与真实能力脱钩。缓解只能依赖结构（提案/验证分离、MoTG 真实锚点、支撑外 abstain、错误预算与 GH 监视），并以 E457/E460/E461/E462/E466/E471 主动证伪。
