# 第 3 轮 · 新灵感：情感计算 × 6D 位姿估计

> **基线**：v22 = MetricVoiceGauge-NCD-HUTDH-v22（IP-431–435；HDL/ACSC/DCSC/HPC-E/CFC++），其上承 v21 的语义-规范层 SDC/CAC/DCL/GIC/CFC+，以及 v20 的 PCA/CTS/CFC/HPC/CFCtrl、v19 的 DCM/OGCC/CCV/DRS/OGC、v17 的 CLP/S2C/HCG/PSV/APS/AMC。
> 本轮纪律：**位姿是朝向可辨的几何证据、情感是非对称的交互调制、同意是隐私的门槛**。不推倒 v22：P34–P42 与所有 conformal 校准模块全部保留。本轮只做一件事：在 v22 的"分层能量-规范"证书之上加一层 **"情感-朝向"具身层**，把"会不会碰 / 该不该做 / 能量够不够 / 意图是什么"扩展为 **"以什么朝向、对什么内部状态的人、以何种交互强度去做"**，并给出一个可审计的**累积风险预算 (Cumulative Risk Budget, CRB)**，把"保守 vs 赎回"从口号变成显式的安全-活性权衡。

## 0. 直觉与动机

**灵感 1（6D 位姿估计 → 几何证据从"框"升级为"朝向 + 对称歧义"）**
直觉：v22 的 CertBox 是轴对齐盒 (AABB) + 类别，它丢掉了朝向，于是两种错误同时存在：一根横杆朝向机器人时，AABB 巨大却"空"（活性被杀）；一根细杆斜插时，AABB 又可能低估扫掠体积（安全被高估）。6D 位姿 `(R∈SO(3), t∈ℝ³)` 给回完整刚体变换，但它带来一个**比误差更棘手的东西——对称歧义**：杯子、圆柱、方盒存在离散或连续对称群，估计器可能返回一组等价位姿；若塌缩成一个，"看不见的另一半朝向"就可能撞上。核心创新：**SE(3) 位姿证书 (SE(3) Pose Certificate, SPC)**：用 conformal 校准联合平移-旋转非一致性分数 `s = max(‖t−t̂‖/τ_t, ∠(R,R̂)/τ_R)`，得到覆盖真位姿概率 ≥1−δ 的"SE(3) 管"；对位姿集合做**对称轨道闭包**（离散群逐元素展开、连续群用旋转扫掠体/外接球保守化），**绝不允许塌缩到单一模式**。关键反直觉点：**朝向确定是一种可以"赎回"自由空间的证据，朝向不确定则只能"增补"障碍**——这与 v21 的"障碍只增、自由有偿赎回"完全同构，只是货币从缺席证书换成了位姿证书。

**灵感 2（情感计算 → 交互强度是被调制的规范变量，而非附加功能）**
直觉：v22 能保证"几何不碰、规范允许、能量可行、意图已知"，但一个满足全部条件的机器人仍可能**把人吓到**：逼近太快、贴得太近、启停太猛、悬停盯视 (looming)。情感计算的输出（效价 valence、唤醒 arousal、压力 stress、信任 trust）恰是"交互强度是否可接受"的度量，但有两条铁律：**(i) 误差代价不对称**——把惊恐的人误判为平静（假平静）会导致继续逼近、加重恐慌甚至引发不可预测闪避；把平静误判为惊恐（假惊恐）只损失活性。**(ii) 情感主观、时变、隐私敏感**，标签本身是代理 (proxy)，不等于内感状态。核心创新：**情感舒适调节器 (Affective Comfort Regulator, ACR)**：把 conformal 情感预测集 Δ_a 经一个**单调**失真指数 `D(a) = α·stress + β·arousal − γ·valence` 映射为参数包络（限速 s_max、限距 d_min、jerk 上限 j_max），且**只收缩不扩张**——`Fil_affect(Δ_a) ⊆ Θ_v22`。关键反直觉点：**用"最坏情形上界 D_upper = max_{a∈Δ_a} D(a)"触发收紧，用"最坏情形仍低于严格平静线 D_calm"才允许放开**，配以滞回带 `D_calm < D_low`，于是"收紧易、放开难"被形式化为一个无极限环的滞回状态机。

**灵感 3（两者耦合 → 位姿门控情感可靠性，同意门控隐私）**
直觉：情感读取极度依赖朝向——背过脸、低头、遮挡时**根本读不准**，但一个坏设计会"读不到 ⇒ 默认平静"，这正是致命的假平静。位姿给出了解药：**头部/身体的 6D 位姿不确定度 ε_h 应当单调地膨胀情感集 Δ_a**（`width(Δ_a) ↑ as ε_h ↑`）。位姿越不确定，情感越只能说"不知道"；而在非对称规则下"不知道"自动落入最严默认（按压力处理）。核心创新：**位姿门控情感可靠性 (Pose-Gated Affect Reliability, PGAR)**：`Δ_a(ε_h) = dilate(Δ_a^base, g(ε_h))`，g 单调递增且 `Δ_a^base ⊆ Δ_a(ε_h)`（膨胀保持覆盖有效，只会更保守）。再接 **同意治理器 (Consent Governor, CPG)**：未同意/撤回同意 ⇒ `Fil_affect = 最严包络`（假设惊恐），**绝不等于"忽略此人"**；原始信号不出设备，只外传设备端特征 φ 与证书（延续 E794）。

**三者如何统一**
统一为 **v22 之上的"情感-朝向"具身层**：SPC 回答"物体/人在 SE(3) 的何处、朝向有几种可能"，ACR 回答"以多强的交互强度才不伤害其情感安全"，PGAR/CPG 回答"这份情感证据是否可靠、是否被允许使用"。共享状态扩展为 **ζ_aff = ζ_pgev ∪ (Pose_t, Sym_t, Δ_a, D_upper, h_state, ε_h, consent, δ_ledger)**。统一准入门 **HPC-EA = HPC-E ∧ SPC ∧ ACR ∧ CPG**。**关键理论升级**：把所有 conformal 失败概率（δ_loc、δ_pose、δ_absence、α_affect、δ_gap…）经 **累积风险预算 CRB** 的并集界统一记账 `Σ δ_j ≤ δ_budget`，由此给出**两种显式模式**：
- **保守模式**：`Exec_v23^cons = Exec_v22 ∩ Fil_pose^+ ∩ Fil_affect ∩ Fil_consent ⊆ Exec_v22`（位姿只增障碍、情感只收缩包络、同意只会更严）——硬包含，继承旧链 `⊆ v22 ⊆ v21 ⊆ …`；
- **赎回模式**：`Exec_v23^red` 用位姿证书赎回 AABB 高估的自由空间换取活性，**不声称**集合包含，只声称碰撞概率 `≤ δ_budget` 且由额外独立佐证 + δ 预算显式记账。
这把"活性 vs 安全"从口号变成可审计的预算再分配，也解释了为何 v22 的活性坍缩风险需要"赎回"而非继续叠加保守项。

## 1. 研究问题（轮次升级版）

- **Q12（SE(3) 位姿证书的覆盖与膨胀）**：如何用 split-conformal 联合校准 `(ε_t, ε_R)` 使 SE(3) 管以 ≥1−δ 覆盖真位姿？在旋转误差 `r_R` 下，占据体积的严格包含界应如何由形心外接半径 ρ 与 `2ρ·sin(r_R/2)+r_t` 给出？离散对称群 G_d 的轨道逐元素展开与连续对称群 G_c 的旋转扫掠保守化如何切换？如何检测"模式坍缩"（估计器只报一个模式而真实存在对称模式）并强制退回外接球？

- **Q13（情感调制的非对称性与活性）**：conformal 情感集 Δ_a 到参数包络 `(s_max, d_min, j_max)` 的单调映射如何选取，使 `Fil_affect ⊆ Θ_v22` 且避免保守叠加导致的活性坍缩？"最坏情形触发收紧（D_upper ≥ D_low）、严格平静才放开（D_upper ≤ D_calm < D_low）"的滞回状态机在 D 时变时如何证明无极限环（dwell-time / TTL 注入）？假平静率与假惊恐率如何用同一份校准数据给出显式上界？

- **Q14（位姿-情感耦合、隐私与同意）**：头部/身体位姿不确定度 ε_h 如何单调传播为情感集膨胀 `g(ε_h)`，并保证膨胀后的集合仍 ≥1−α 覆盖？为何"位姿不确定 ⇒ 情感必更宽 ⇒ D_upper 更高 ⇒ 更保守"能避免"读不到即平静"的致命默认？撤回同意如何编译为"最严包络"而非"忽略此人"？设备端特征 φ 与证书如何在不泄露原始信号的前提下被第三方审计？

- **Q15（累积风险预算与跨模态仲裁）**：δ_loc、δ_pose、δ_absence、α_affect、δ_gap 等如何在 `Σδ_j ≤ δ_budget` 下分配，且各证书仅需各自的可交换性（无需跨证书独立）？当位姿说"面向你"、情感说"平静"、手势说"停"时，CFC× 如何用 P36 的优先级（STOP 最高、情感低门槛收紧）与**位姿一致性门控的模态定额**仲裁？赎回模式下如何用 δ 预算显式交换活性而不悄悄侵蚀安全？

## 2. 设计原则（在 P34–P42 基础上新增 P43–P45）

**P43 SE(3) 位姿证据单调律（SE(3) Pose Evidence Monotonicity）**
物体占据集由位姿集合与对称轨道给出：
`Occ_t = ⋃_{(R,t)∈Pose_t} ⋃_{g∈O_G} [ (R g)·S_t + t ] ⊕ Ball(0, 2ρ(S_t)·sin(r_R/2) + r_t)`，
其中 `r_t = q̂_pose·τ_t`、`r_R = q̂_pose·τ_R`，`q̂_pose` 为 conformal 分位。**朝向不确定只能增补障碍**：任一未被消除的对称模式都必须进入并集；若 `r_R` 超过阈值 `r_tighten` 或对称群未知/模式疑似坍缩，则保守化为外接球 `Ball(t, ρ(S_t)+r_t)`。**朝向确定可以赎回**：仅在 `r_R ≤ r_tighten` ∧ 对称群已解析 ∧ 模式消除证书（概率 ≥1−δ_pose）成立时，才允许用定向凸包 `[(Rg)·S_t + t] ⊕ Ball(0, r_t)` 取代 v22 AABB 高估的占据，且赎回区域必须记入 CRB 的 δ_pose 户头。故保守模式下 `Occ_v23 ⊇ Occ_v22` ⇒ `Fil_pose^+ ⊆ Fil_v22`。

**P44 情感调节非对称律（Asymmetric Affective Modulation）**
情感集 `Δ_a ⊆ ℝ^d`（d 维效价/唤醒/压力等）以 ≥1−α_affect 覆盖真情感代理标签。定义单调失真指数 `D(a)=α·stress+β·arousal−γ·valence`，`D_upper = max_{a∈Δ_a} D(a)`。参数包络 `Env(Δ_a) = (s_max, d_min, j_max)` 满足：
- **单调收缩**：`Δ_a ⊆ Δ_a' ⇒ Env(Δ_a) ⊑ Env(Δ_a')`（更宽情感集更严格）；`Env(Δ_a) ⊆ Θ_v22`，永不越过 v22 参数域。
- **非对称滞回**：收紧当 `D_upper ≥ D_low`（低门槛，易触发，fail-safe）；放开当 `D_upper ≤ D_calm` ∧ `D_calm < D_low` ∧ 同意有效 ∧ ≥2 个**位姿一致**的独立模态佐证；中间带 `(D_calm, D_low)` 保持上一状态（TTL 注入保证切换有限）。故 `Fil_affect(Δ_a) ⊆ Θ_v22`。

**P45 同意-位姿门控律（Consent & Pose Gating）**
情感可靠性受位姿门控：`Δ_a(ε_h) = dilate(Δ_a^base, g(ε_h))`，`g` 单调不减，且 `g(ε_h)=0` 仅当头部/身体位姿确定（`ε_h ≤ ε_h^0`）。膨胀是超集，故 conformal 覆盖只增不减，且 `D_upper` 单调不减 ⇒ "位姿越不确定越保守"。撤回同意/未同意 ⇒ `Env := Env_max^cons`（最严包络，假设惊恐），**绝不退化为"无人"或"忽略"**；原始信号不出设备，只外传 φ 与证书，审计仅验证证书与承诺（merkle）。

## 3. 与基线的接口（如何退化）

- SPC 失效（位姿估计器故障）⇒ `Occ` 退回 v22 AABB（更保守），定向赎回一律关闭 ⇒ 等价/严于 v22；
- SPC 对称群未知或模式坍缩检测触发 ⇒ 强制外接球 ⇒ 比 v22 更保守（活性下降但安全方向不变）；
- ACR 失效（情感校准器崩溃）⇒ `Env := Env_max^cons`（最严包络）⇒ `Exec ⊆ Exec_v22` 仍成立；
- PGAR 失效（位姿-情感传播不可用）⇒ 情感集取 `Δ_a^base` 的保守包络；若 `ε_h` 不可得则取 `Env_max`；
- CPG 失效/未同意 ⇒ 最严包络 + 不推断，`Exec ⊆ Exec_v22`；
- CRB 不可核（δ_ledger 无法验证）⇒ 关闭赎回模式，只允许保守模式 ⇒ `Exec_v23^cons ⊆ Exec_v22`；
- 全部失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ …`（引理 162 链）。

## 4. 预期贡献

1. **SE(3) 位姿证书**：首次把 6D 位姿变成带联合平移-旋转误差界与**对称轨道闭包**的占据证据，给出严格包含界 `2ρ·sin(r_R/2)+r_t`，并显式区分"朝向不确定只增障碍"与"朝向确定可赎回自由空间"；
2. **非对称情感调制**：把情感 conformal 集编译为单调、滞回、只收缩的参数包络，形式化"假平静危险 / 假惊恐仅损活性"的不对称代价，并给出假平静率的显式上界；
3. **位姿门控情感可靠性**：给出跨模态误差传播 `ε_h ↦ width(Δ_a)`，从结构上杜绝"读不到即默认平静"，使遮挡/背身/低头自动落入最严默认；
4. **同意即门槛**：把隐私从"附加合规"变成准入门的一个硬门槛（撤回同意 ⇒ 最严而非忽略），原始信号不出设备的可审计承诺；
5. **累积风险预算 CRB**：用无需独立性的并集界统一所有 conformal 失败概率，给出"保守（硬包含）/ 赎回（概率安全）"两种显式模式，把安全-活性权衡变成可审计的 δ 再分配；
6. **HPC-EA 统一准入门与安全链**：`HPC-E ∧ SPC ∧ ACR ∧ CPG` 四证一体，保守模式下 `Exec_v23^cons ⊆ Exec_v22 ⊆ Exec_v21 ⊆ …` 闭环，赎回模式以 `P(collision) ≤ δ_budget` 显式记账。

## 5. 本轮最大风险

**一句话**：情感证书覆盖的是**代理标签**而非真实内感状态，在遮挡/背身/文化差异/情绪掩饰（尤其**冻结反应**被误判为安静）下，形式成立的"平静"证书可与事实相反，机器人将**合规地、可审计地继续逼近一个正在惊恐的人**——即"合规的情感幻觉"，其危险性在于它比 v21 的缺席幻觉更隐蔽：缺席幻觉可由多模态召回冗余部分兜底，而"假平静"恰恰会抑制人发出更多可观测信号。

```python
import math
import numpy as np

# ---------- IP-436 SE(3) Pose Certificate ----------
def geodesic_angle(R, Rhat):
    c = (np.trace(R.T @ Rhat) - 1.0) / 2.0
    return math.acos(max(-1.0, min(1.0, c)))          # ∈ [0, π]

class SE3PoseCertificate:
    """联合平移-旋转 conformal 管 + 对称轨道闭包 + 严格占据膨胀。"""
    def __init__(self, calib, tau_t, tau_R, delta_pose=1e-3, r_tighten=0.05):
        self.calib = calib            # 提供 (1-delta) 分位 q_hat
        self.tau_t, self.tau_R = tau_t, tau_R
        self.delta_pose = delta_pose
        self.r_tighten = r_tighten    # 可用定向凸包的旋转界阈值(rad)

    def score(self, R, t, Rhat, that):
        return max(np.linalg.norm(t - that) / self.tau_t,
                   geodesic_angle(R, Rhat) / self.tau_R)

    def orbit_closure(self, modes, symmetry):
        """返回用于并集的 (R, t) 列表；连续/未知对称 -> None 表示改用外接球。"""
        if symmetry is None or symmetry.is_continuous or symmetry.maybe_mode_collapsed:
            return None                                  # 强制外接球，绝不塌缩
        out = []
        for (R, t) in modes:
            for g in symmetry.generators:                # 离散群逐元素展开
                out.append((R @ g, t))
        return out

    def certify(self, shape, modes, symmetry):
        q = self.calib.quantile(self.delta_pose)         # conformal (1-δ) 分位
        r_t, r_R = q * self.tau_t, q * self.tau_R
        rho = shape.circumradius()
        orbit = self.orbit_closure(modes, symmetry)
        if orbit is None or r_R > self.r_tighten:
            # 保守：旋转不确定 -> 形心外接球（旋转扫掠的严格外包含）
            occ = [Ball(centroid=t, radius=rho + 2 * rho * math.sin(r_R / 2) + r_t)
                   for (_, t) in modes]
            return Occ(occ), q, "CONSERVATIVE_BALL"
        # 紧致：定向凸包 ⊕ 位移球（位移界见 Lemma B2）
        pad = 2 * rho * math.sin(r_R / 2) + r_t
        occ = [transform(shape, R, t).minkowski_ball(pad) for (R, t) in orbit]
        return Occ(occ), q, "ORIENTED_TIGHT"

    def redemption_allowed(self, result, symmetry, mode_elim_cert):
        occ, q, regime = result
        return (regime == "ORIENTED_TIGHT"
                and not symmetry.maybe_mode_collapsed
                and mode_elim_cert.valid(self.delta_pose))
```

```python
# ---------- IP-437 Affective Comfort Regulator ----------
class AffectiveComfortRegulator:
    """conformal 情感集 -> 单调、滞回、只收缩的参数包络。"""
    def __init__(self, alpha=0.1, D_low=0.6, D_calm=0.35, k_s=1.0, k_d=1.0):
        self.alpha = alpha
        self.D_low, self.D_calm = D_low, D_calm     # D_calm < D_low
        self.k_s, self.k_d = k_s, k_d
        self.state = "TIGHT"                         # 上电默认最严

    @staticmethod
    def distress(a):
        return a["alpha"] * a["stress"] + a["beta"] * a["arousal"] - a["gamma"] * a["valence"]

    def envelope(self, delta_set, consent, pose_consistent_modalities, last_switch_t, now):
        D_up = max(self.distress(a) for a in delta_set)   # 最坏情形上界
        # 非对称滞回：收紧低门槛，放开高门槛 + 佐证
        if D_up >= self.D_low:
            self.state = "TIGHT"
        elif (D_up <= self.D_calm and consent
              and len(pose_consistent_modalities) >= 2
              and now - last_switch_t >= self.dwell):
            self.state = "LOOSE"
        # 否则维持原状态（滞回带，避免极限环）
        if not consent:
            self.state = "TIGHT"
        if self.state == "TIGHT":
            s_max = max(0.0, self.s0 - self.k_s * D_up)
            d_min = self.d0 + self.k_d * D_up
        else:                                            # LOOSE == v22 基线，绝不更松
            s_max, d_min = self.s0, self.d0
        return Env(s_max=s_max, d_min=d_min, j_max=self.j0 * (s_max / self.s0))
```

```python
def crb_valid(ledger, budget):

              ledger, budget, mode):

    if not crb_valid(ledger, budget):
        return False, "CRB_EXHAUSTED"                  # δ 户头透支 -> 只许保守

        return False, "POSE_OCCUPIED"
```

## 2. 关键引理与推导（可机械复核）

**引理 B1（SE(3) 管的覆盖）**：若校准样本与测试样本可交换，`s_pose` 定义如上，`q̂` 为 `⌈(n+1)(1−δ)⌉/n` 分位，则
`P(‖t−t̂‖ ≤ r_t ∧ ∠(R,R̂) ≤ r_R) ≥ 1−δ`。
*证明*：标准 split-conformal；事件 `{s_pose ≤ q̂}` 的概率 ≥1−δ，而该事件等价于上述两个界同时成立。∎

**引理 B2（旋转误差下的严格占据包含）**：设真位姿满足 `‖t−t̂‖≤r_t`、`∠(R,R̂)≤r_R`，`ρ=ρ(S)`，则对任意 `p∈S`，
`‖(Rp+t) − (R̂p+t̂)‖ ≤ ‖(R−R̂)p‖ + ‖t−t̂‖ ≤ 2ρ·sin(r_R/2) + r_t`。
故 `Occ_true ⊆ [(R̂S)+t̂] ⊕ Ball(0, 2ρ·sin(r_R/2)+r_t)`。连续对称时先以旋转扫掠体代替 S，结论不变。∎

**引理 B3（位姿单调与保守包含）**：保守模式的 `Occ_v23 = Occ_v22 ∪ Occ_SPC ⊇ Occ_v22`；对称模式只并入集不删；故 `Fil_pose^+ ⊆ Fil_v22`，进而 `Exec_v23^cons = Exec_v22 ∩ … ⊆ Exec_v22`。∎

**引理 B4（情感只收缩）**：`Env` 对 `Δ_a` 单调且 `Env(Δ_a) ⊆ Θ_v22`（LOOSE 取 `(s0,d0,j0)` 即 v22 基线）；`Fil_affect(Δ_a) = {π∈Θ_v22 : speed≤s_max ∧ clearance≥d_min ∧ jerk≤j_max}` ⊆ Θ_v22。故交集不增加可达计划。∎

**引理 B5（滞回无极限环）**：状态机仅在 `D_up≥D_low` 进入 TIGHT、仅在 `D_up≤D_calm` 且 dwell-time 满足进入 LOOSE，带 `D_calm<D_low`，故对分段常值 `D_up` 每次切换后必须跨越宽 `D_low−D_calm` 才能反向切换；对时变 `D_up`，TTL/dwell-time 提供最小驻留，切换次数受信号变差界约束，无 Zeno 行为。∎

**引理 B6（CRB 并集界）**：若对每个证书 `j` 有 `P(证书 j 失效) ≤ δ_j`，则 `P(任一失效) ≤ Σ_j δ_j ≤ δ_budget`，**无需跨证书独立**（仅需各自校准可交换）。赎回模式的 `P(collision) ≤ δ_budget` 由此记账。∎

**推论（两位姿模式的安全语义）**：
- 保守：`Exec_v23^cons ⊆ Exec_v22 ⊆ Exec_v21 ⊆ …`（确定性包含，沿用引理 162）；
- 赎回：不主张包含，主张 `P(collision) ≤ δ_budget`；赎回的每一块自由空间都对应 `δ_pose` 户头的一笔显式支出与一份模式消除证书。

**消融（每条对应一个可证伪假设）**
1. AABB vs SPC：验证对称轨道闭包消除"模式坍缩导致的假自由空间"；
2. 定点阈值 vs ACR 非对称滞回：验证假平静率显著下降、假惊恐损失可接受；

5. 无 CPG（用"读不到=平静"）vs 有 CPG（最严）：验证撤回同意不导致安全回退；
6. CFC× 位姿一致定额 vs v22 CFC++：验证"位姿不一致的平静票"被正确弃权。

**预期结果（待验证假设，非既成结论）**
- T-LESS/YCB-V 对称类：模式坍缩是假自由空间主因，轨道闭包后假自由空间率趋近 0，代价是活性小幅下降；
- 背身/遮挡子集：无 PGAR 的假平静率显著高于有 PGAR；有 PGAR 时该子集几乎全部落入保守包络；
- CRB 赎回：在有模式消除证书的物体上回收可观间隙，同时 `Σδ ≤ δ_budget` 可机械核验；
- 公平：假平静率群组差若超阈，触发在线重校准而非静默接受。

## 4. 产物小结（本轮定理链）

- SPC：`s_pose` 校准 → 引理 B1（覆盖）→ 引理 B2（严格膨胀）→ 引理 B3（保守包含 / 赎回门限）；
- ACR：引理 B4（只收缩）→ 引理 B5（无极限环）；
- PGAC：`ε_h ↦ Δ_a` 单调膨胀（覆盖只增）+ 撤回同意 ⇒ 最严（不忽略）；
- CRB：引理 B6（并集界，无独立性要求）；
- HPC-EA：`admit_v23` 在保守模式返回 `CONS_SUBSET`，硬链 `Exec_v23^cons ⊆ Exec_v22 ⊆ Exec_v21 ⊆ …`；赎回模式返回 `REDEEM_PROB_SAFE`，以 `P(collision) ≤ δ_budget` 显式记账。

**本轮最大风险（复述）**：情感证书覆盖代理标签而非真实内感状态，遮挡/背身/文化差异/情绪掩饰（尤其冻结反应）下"假平静"可与事实相反，机器人会合规地继续逼近一个正在惊恐的人。
