## 1. 两个灵感的第一性原理

### 灵感 1 ·「力觉传感」→ 力不是一个传感器，而是一个带协方差的隐状态

**直觉解释**：视觉告诉你"东西在哪"，力告诉里"你到底碰到了没有、卡住了没有、滑了没有、捏碎了没有"。操作真正难的那一段（接触之后）几乎全靠力：插孔要感受别劲，拧螺丝要感受贴合，抓取要感受是否滑移。但本赛题的手里**没有力传感器**（F6 实测：只有关节位置、EE 位姿、夹爪位置）。于是问题不是"买一个力传感器"，而是"**能不能从可观测信号里把力估出来**"——关节跟踪误差（指令 vs 实际）、逆动力学残差、夹爪位置刚度、物体在腕部视角里的微动，都是力的"影子"。

这与第 3 轮的状态层同构：SLAM 把"位姿"从像素里估出来并带协方差；本轮把"接触力/接触模式"从本体感受 + 视觉里估出来并带协方差。**力觉传感 = 一个可校准的接触状态估计器**，而不是新增硬件。

**严谨定义**：
- **U19（接触状态估计）**：`ĉ_t = (m_t, f̂_t, Σ_t^F)`。`m_t ∈ {free, contact, slip, jam}` 为接触模式；`f̂_t ∈ R^6` 为腕部系接触旋量（可退化为法向 f_n、切向 f_t、夹持力 f_g 三个标量）；`Σ_t^F` 为其协方差。估计器 `g_θ` 的输入仅为可部署观测 `o_t^dep = (q, q̇, q_target, ee_pose, gripper, images, h_t)`。
- **U20（特权标签与蒸馏）**：仿真中可从 IsaacLab 接触传感器读到真值 `f*`。教师 `τ(o^dep, f*)` 在联合任务上训练；学生 `σ(o^dep)` 只吃可部署观测，最小化 `E[ℓ(σ(o^dep), τ(o^dep, f*))] + L_task`。部署只用学生。这是 Vapnik 特权信息/师生蒸馏的操作域实例化。
- **L14（力觉-视觉滑移可检测性的判据，非无条件优势）**：设滑移在 t0 产生切向量变化 Δf。力通道观测 `y_F = Δf + ε_F, ε_F ~ N(0, σ_F²)`；视觉得到投影位移 `y_V = (Δf/k)·s + ε_V`，`s ~ Bernoulli(1−p_occ)`（遮挡时无证据）。在虚警 α 下，力通道可检测指数 `d'_F = Δf/σ_F`，视觉的期望为 `E[d'_V] = (1−p_occ)·Δf/(kσ_v)`。故**力觉严格优于视觉当且仅当 `σ_F < kσ_v/(1−p_occ)`**。这个不等式的价值在于：它把第 3 轮 Q11 的"视觉能不能测滑移"从信仰问题变成**可测门槛**——`σ_F` 就是力观测器（含 sim2real 差距）的噪声，若测不过门槛就不该上力觉闭环。∎

**策略含义**：力觉的收益有两处，恰好对应本赛题的新增数据：①**滑移/接触检测**替换第 3 轮纯视觉的 SlipGuard（Q11 → 可判定的 E634）；②**接触相位的柔顺控制**——新增的装配凳/叠衣/做三明治就是接触密集型任务，纯位置伺服会在别劲处顶死。第 2 轮把"最后一厘米"交给位置伺服；本轮把"接触之后的最后一厘米"交给力位混合（IP-17）。

### 灵感 2 ·「数据规模」→ 真正稀缺的不是 episode，是"轴上的标签"

**直觉解释**：语料确实又开始长了（F4），但那是**所有人都能下载的同一批数据**——消费它不产生护城河。数据规模的正确问题不是"再多训几个 epoch"，而是"**在哪个轴上增加数据，边际收益最高**"。第 3 轮的失败矩阵（六因子 × 五泛化轴）其实已经给出了每个轴的缺口；而"力/接触"这个轴的覆盖度是**零**——公开语料里没有任何力标签（F6）。一个覆盖为零、且与"接触密集新任务"高度相关的轴，其边际收益必然最高。而它恰好可以用官方刚更新的 IsaacLab 资产**近乎无限地生成**（F5）。

于是「数据规模」与「力觉传感」在这里合流：**数据规模不是去堆同分布的 episode，而是去生成一个不存在的新标签轴（力），再用特权蒸馏把它压回可部署观测。** 这也修复了第 3 轮的一个隐含错误：它把"没有数据护城河"当作终局，实际上"没有护城河"只对**现有轴**成立；新标签轴才是护城河。

**严谨定义**：
- **U21（数据轴预算与规模律）**：设总预算 N 分配到轴 `a ∈ {object, task, contact, force-label, interference, viewpoint, …}` 上，得 `n_a`（`Σ n_a ≤ N`）。拟合 `S(n) = S∞ − Σ_a A_a n_a^{−β_a}`。轴 a 的边际收益 `m_a = A_a β_a n_a^{−(β_a+1)}`。
- **L15（边际收益均衡 / water-filling）**：预算约束下最优内点解满足 `A_a β_a n_a^{−(β_a+1)} = λ`，即 `n_a* = (A_a β_a / λ)^{1/(β_a+1)}`。**推论**：起始覆盖为零的轴（如 contact/force-label）在 n_a=0 处边际收益发散，故**应先投入、且是最后才该停的轴**；已饱和的轴（A_a 小或 β_a→0）不应再加同分布数据。这就是「数据规模」的可执行版本：不是均匀放大，而是按缺口做水填。∎
- **P13（数据按轴边际配置）**：任何数据扩充必须先回答"这是哪个轴、当前边际收益多少"，禁止无差别扩量；新轴/零覆盖轴优先。
- **P14（特权标签生成）**：任何**不可观测**的量（力、接触、质量、摩擦）先在大规模仿真里作为特权标签生成，再蒸馏到可观测输入；禁止把不可观测量直接喂给部署模型。

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（力观测器的可辨识性与 sim2real 差距）**：仅凭 `o^dep`（关节/EE/夹爪/图像），接触模式与接触旋量能被估到什么精度？学生相对教师的精度损失、以及相对真机力探针的 sim2real 差距各是多少？是否满足 L14 门槛 `σ_F < kσ_v/(1−p_occ)`？（E634）
- **Q14（力位混合的收益与代价）**：在接触密集相位（装配凳/叠衣/插接）用导纳控制替代纯位置伺服，成功率、峰值接触力、超力事件、步数各改善多少？是否值得其引入的复杂度与失稳风险？（E635）
- **Q15（数据规模律与轴配置）**：在 32 项 + 新增接触任务上，`S(n)` 的各轴 `(A_a, β_a)` 能否被稳定拟合并外推？按 L15 重新分配预算，held-out 轴是否真的按预测提升？（E636）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（数据按轴边际配置）**：数据扩充按 L15 的边际收益分配，零覆盖轴优先；禁止"同分布加量"当默认动作。
- **P14（特权标签生成）**：不可观测物理量先在仿真中作为特权标签规模化生成，再蒸馏；训练损失永远不能替代 sim2real 差距的实测。
- **P15（可见性门控）**：力觉逻辑只在观测器置信度 `> TAU_CONTACT` 时启用；低于阈值退回视觉 SlipGuard 与位置伺服（新增退化层级 Level-1.7），不得让低置信估计进入闭环。

## 5. 本轮最大风险

**真正可能葬送这条线的是仿真接触物理与真机的保真度差距：力标签可以在 IsaacLab 里无限生成，但若接触刚度/摩擦/柔顺模型本身有偏，蒸馏只会把"自信的错误"原封不动地教给学生——而且这是训练曲线完全看不出来、只能在真机力探针上暴露的失败模式。** 次要风险：新任务与挑战 32 项存在域差（新数据只能做 held-out/预训练，不能直接当分发内数据）；导纳控制引入失稳与超力风险（须限幅 + 白名单相位 + P12 记账）。

## 3. 新增 IP 详述

### IP-16 · ContactObserver 接触状态/力观测器（P0，新）

- **动机**：力是操作接触相位的核心反馈；但 F6 实测本赛题观测无关节力矩/电流、无力/触觉。第 3 轮 Q11（视觉滑移可检测性）悬而未决，本质是"用错通道补一个物理量"。本轮把力当作**隐状态**来估计，而非硬件缺口。
- **与现有方案差异**：teaser 模型（待复核假设）均为"观测→动作"单通路、无显式接触状态。本方案显式维护 `(m_t, f̂_t, Σ_F)`，并在因子图中作为接触因子供断言/介入/滑移共用。
- **技术可行性**：中高。输入特征全部已具备（q/q̇/q_target 跟踪误差、EE 位姿、夹爪位置、腕部图像）；估计器用轻量时序网络（GRU/TCN），教师用 IsaacLab 接触传感器真值。分布内可监督，真机靠蒸馏与少量力探针校准。
- **资源**：数据=IP-18（≥1e5 力标注 episode，仿真）；算力=中（单卡训练小网络）；真机校准=实验室 F/T 探针小集（仅离线，不进提交）。
- **落地步骤**：①定义 teacher/student schema 与 U19 输出；②在 IP-18 上训练教师，再蒸馏学生；③按 L14 实测 `σ_F` 与视觉门槛，决定是否进闭环；④将 `p(slip)`、`m_t` 接 IP-14、接 IP-13 因子图、接 IP-17 使能；⑤置信度门控（P15）与 Level-1.7 回退。
- **风险**：sim2real 力差距（L16，最大）；力探针样本少致校准过拟合；`σ_F` 过大则整条力觉线降级为离线诊断。

### IP-17 · ContactAdmittance 接触相位力位混合（P1，新）

- **动机**：新增的装配凳/叠衣/做三明治是接触密集型任务，纯位置伺服在别劲/卡死处会顶死或以超力失败；位置伺服（第 2 轮）解决"怎么动"，导纳解决"碰到之后怎么让"。
- **差异**：不训新策略，只替换白名单相位（insert/jam/release）的动作合成：`a = K_p(x*−x) + K_d(ẋ*−ẋ) + K_f(f*−f̂)`（U22）；非接触相位维持原位置伺服，避免无谓抖动与步数开销。
- **可行性**：中高。导纳/阻抗控制是成熟件；风险在增益失稳与 `f̂` 噪声放大 → 限幅 + 低通 + 白名单。
- **资源**：复用 IP-16 的 `ĉ`；仿真扫参为主，真机仅验证白名单相位。
- **落地步骤**：①U22 增益在仿真接触任务上扫稳定性边界；②设力/速度限幅与超力保护；③白名单转场逻辑（接触模式进入/退出带滞回）；④E635 A/B（位置 vs 导纳）。
- **风险**：导纳失稳抖振；`f̂` 偏置导致稳态力误差；步数开销（P12/L13 记账后仅高价值相位启用）。

### IP-18 · ForceDataEngine 力标签规模化 + 特权蒸馏（P1，新）

- **动机**：力标签在公开语料中覆盖为零（F6），但官方 IsaacLab 资产本轮更新（F5）→ 可在同一任务场景族上近乎无限渲染接触真值。这正是"数据规模"最该投的零覆盖轴（L15）。
- **差异**：不是收集更多真机 episode，而是**制造新标签轴**；产物是 `(o^dep, f*)` 大数据集与蒸馏配方，服务 IP-16/14/17/12。
- **可行性**：高（标签生成）/中（保真）。USD 资产 + 接触传感器是现成件；难点是接触参数域随机化与 sim2real 保真。
- **资源**：数据=官方 USD + 新任务场景（缺 USD 的任务本轮不入）；算力=中（批量渲染 + 轻量监督）。
- **落地步骤**：①USD 场景接入与接触传感器落盘 schema；②域随机化（摩擦/刚度/质量/延迟）；③按任务×物体生成 ≥1e5 episode；④教师训练 → 学生蒸馏；⑤E637 蒸馏/sim2real 差距评估与门控。
- **风险**：接触物理保真不足会污染标签（L16）；渲染/存储成本；场景与真机布局错位。

## 5. 符号与定义（新增 U19–U22；U1–U18 沿用第 1–3 轮）

- **定义 U19（接触状态估计）**：`ĉ_t = (m_t, f̂_t, Σ_t^F)`，`m_t∈{free,contact,slip,jam}`，`f̂_t∈R^6`（腕部系接触旋量；可退化 f_n,f_t,f_g），`Σ_t^F` 协方差。输入 `o^dep=(q,q̇,q_target,ee_pose,gripper,images,h_t)`。
- **定义 U20（特权标签与蒸馏）**：仿真真值 `f*`；教师 `τ(o^dep,f*)`、学生 `σ(o^dep)`；目标 `min_σ E[ℓ(σ(o^dep), τ(o^dep,f*))] + L_task`；部署仅学生。
- **定义 U21（数据轴预算与规模律）**：`S(n)=S∞−Σ_a A_a n_a^{−β_a}`，`n_a≥0, Σ n_a≤N`；边际 `m_a=A_aβ_a n_a^{−(β_a+1)}`。
- **定义 U22（导纳律）**：接触相位 `a=K_p(x*−x)+K_d(ẋ*−ẋ)+K_f(f*−f̂)`，带力/速度限幅；非接触相位退回 `a=K_p(x*−x)`。

## 6. 关键算法骨架（新增片段；主体沿第 1–3 轮 `UniBotSAGEPolicy`）

```python
# ===== IP-16: 接触状态观测器（学生；低频 + 事件触发）=====
class ContactObserver:
    def __init__(self, student):
        self.student = student          # 从 IP-18 蒸馏得到
        self.mode, self.f, self.S = "free", None, None

    def update(self, o_dep, event=False):
        if not (event or self.tick % N_CONTACT == 0):
            return self.mode
        self.mode, self.f, self.S = self.student(o_dep)  # U19
        self.conf = contact_confidence(self.f, self.S)
        return self.mode

    def enabled(self):                  # P15 门控
        return self.conf > TAU_CONTACT
```

```python
# ===== IP-17: 接触相位力位混合（白名单 + 限幅）=====
CONTACT_PHASES = {"insert", "jam", "release"}
def act_with_admittance(a_pos, x, xd, f_hat, phase):
    if phase not in CONTACT_PHASES:
        return a_pos
    a = a_pos + K_D @ (xd - vel_est(x)) + K_F @ (f_star(phase) - f_hat)
    return clip_force_and_vel(a)        # 失稳/超力保护
```

```python
# ===== IP-18: 特权蒸馏（教师吃 f*，学生只吃 o^dep）=====
def distill_step(teacher, student, batch):
    o, f_star = batch["o_dep"], batch["f_star"]
    with torch.no_grad():
        y_t = teacher(o, f_star)
    y_s = student(o)
    return mse(y_s, y_t) + L_task(student, batch["task"])
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（力觉-视觉滑移判据）** 设滑移产生切向变化 Δf；力通道 `y_F=Δf+ε_F, ε_F~N(0,σ_F²)`，视觉 `y_V=(Δf/k)s+ε_V, ε_V~N(0,σ_v²), s~Bern(1−p_occ)`。虚警 α 下检测指数 `d'_F=Δf/σ_F`，`E[d'_V]=(1−p_occ)Δf/(kσ_v)`。故力觉优于视觉 ⇔ `σ_F<kσ_v/(1−p_occ)`。⇒ Q11 不再靠猜：测出 `σ_F`（含 sim2real）即可判定，测不过就不上力觉闭环。∎

**引理 L15（数据轴边际均衡）** 在 `S(n)=S∞−Σ A_a n_a^{−β_a}`、`Σ n_a≤N` 下，内点最优满足 `A_aβ_a n_a^{−(β_a+1)}=λ`，闭式 `n_a*=(A_aβ_a/λ)^{1/(β_a+1)}`。零覆盖轴（n_a=0）边际发散 → 先投；饱和轴（A_a 小或 β_a→0）边际趋零 → 停投。⇒ 数据规模应由 IP-06 的留轴消融估 `(A_a,β_a)` 驱动，而非均匀扩量。∎

**引理 L16（蒸馏误差的可加分解）** 部署风险分解为 `R_deploy ≤ R_teacher^sim + ε_gap + ε_distill + ε_task`：`R_teacher^sim` 为教师在该仿真任务上的误差，`ε_gap` 为接触物理 sim2real 差距（真机力探针对 `f̂` 的误差），`ε_distill` 为师生近似误差，`ε_task` 为任务层误差。⇒ **训练损失只反映 `ε_distill`，完全看不到 `ε_gap`**；故 E634/E637 必须显式测量 `ε_gap` 并设门限，否则"蒸馏很成功"可与"真机很失败"同时成立。∎
