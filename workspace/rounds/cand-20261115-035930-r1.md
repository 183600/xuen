# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「仿真训练」×「单模型多任务」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric / epistemic，epistemic 交给流匹配多模态策略与主动交互去消解，并以「k 个正交证据源一致」作为防投毒纪律。但 R69 埋着两个它自己无法回答的问题：
> 1. **这些「会问」的能力是从哪里学来的？** 主动交互在真实世界里试错代价极高（问错比不问更危险，这正是 R69 自陈的最大风险），几乎必然要先在**仿真**里排练。
> 2. **那些「正交证据源」真的正交吗？** R69 引理 18 假设各源欺骗相关 ρ<1。可当所有任务共用一个**单模型多任务**骨干时，证据源共享同一套表征、同一批训练偏差——独立性假设正被架构本身悄悄摧毁。
>
> 本轮两个灵感正好击中这两处：
> - **仿真训练**提供廉价、可控、可对抗的排练场，但它同时是一个「会说谎的老师」——会 reward hack、会有 sim-to-real gap；
> - **单模型多任务**让一套「问/看/触/标定」的能力被所有任务摊销、正迁移，但也让错误跨任务传播、让证据相关性升高。
>
> 核心命题：**把「能力从哪来、还准不准」变成一等公民。** 给每一项学到的能力打上**溯源标签与 sim-to-real 差距证书**；把仿真器当作「第 k 个被折减的见证」而非真理；显式估计并折减证据相关性（effective k）；只有在能力已认证、证据足够独立时，才允许 R69 的多源交互；否则逐指令退化回 R69 / R68。命名 **STAGE-RAS**（Simulation-trained Task-Agnostic Generalist Epistemic RAS）。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信我学会了求证——那场排练有没有骗我**」。不确定性从此不只关于世界，也关于**我自己能力的来源与保质期**。

## 0. 直觉与动机

**灵感 1（仿真训练 = 廉价排练场，也是一个会说谎的老师）**
直觉：真实交互昂贵且危险，系统必须在仿真里练「何时问、怎么问、问完信几分」。但仿真不是中立的免费午餐：策略会**钻仿真的空子**（reward hacking）——学会利用模拟器的传感器伪影、过简的人类模型、过于配合的「模拟被问者」，在仿真里拿到极高的 VoI，在真实里一问就错。仿真训练的收益与风险是同一枚硬币：**它让你练得多，也让你练歪得更自信**。所以必须给「排练」本身建立证伪机制。

**灵感 2（单模型多任务 = 一个身体、多个自我）**
直觉：让一个骨干同时学操作、导航、社交、标定，共享物理常识，能大幅摊销数据与交互技能（正迁移）。代价是**任务间干涉**与**共享幻觉**：为任务 A 注入或学到一个错误模态，会经共享表征污染任务 B；更隐蔽的是，B 会觉得这个错误「很自然」，因为它的似然也被同一个错误骨干抬高了。共享让能力相加，也让偏差相乘。

**灵感 3（能力不是布尔量，而是带来源与保质期的证据）**
直觉：R68/R69 默认「某个模块已训练好 = 可信」。但能力有**来源**（纯仿真 / 仿真+真实 / 真实）、有**覆盖域**、有**保质期**（部署后世界漂移）。一个在仿真里 ECE=0.02 的模态校准器，搬到真实可能 ECE=0.2。应当像供应链一样给能力建**溯源账本**：每项能力携带 gap 证书、覆盖系数、最后真实校验时间、以及「曾被哪些任务共享更新」的污染指纹。部署时先查账，再用能力。

**灵感 4（仿真器是第 k 个见证，不是真理）**
直觉：R69 已有一套「k 个正交证据源一致才定案」的纪律。仿真器天然就是一个**额外见证**：便宜、可重复、可对抗排练；但它有欺骗率 δ_sim，且与策略高度相关（策略就是在它上面优化的，ρ_sim 可能接近 1）。把它当独立证据是自欺；正确做法是把它作为**被折减的见证**并入证据集，并用真实审计集去校准它的可信度。这与 R69 的投毒模型同构——只不过「投毒者」是模拟器本身。

**灵感 5（独立性的前提正在被共享骨干摧毁）**
直觉：这是本轮最锋利的一刀。R69 引理 18 的防投毒上界依赖各证据源「欺骗相关 ρ<1」。单模型多任务让所有源共享同一套表征与同一批训练偏差，于是**它们的错误高度相关**：模态头、标定头、跨模态一致性可能一起错、且错得一致。此时「k 个源一致」并不提供 k 倍证据，只提供约 k_eff = k/(1+(k−1)ρ) 倍；ρ→1 时 k_eff→1，R69 的保证退化成「一个源自言自语」。**共享架构会把 R69 的安全证明从内部蛀空**，而表面上一切正常。

**灵感 6（退化边界：不可证 → 回 R69；不独立 → 回 R68）**
直觉：本轮不做「更激进的自主」，而做「更严格的可信边界」。若某能力的 sim-to-real gap 无法认证、或证据相关性过高、或排练-部署一致性漂移，就**逐指令**退回 R69（只用真实交互）甚至 R68（纯保守）。新层必须仍是旧层的严格泛化：排练带来的收益是「resolution bonus」，安全侧永不让步。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（STAGE-RAS 总览）** STAGE-RAS = (OMNI, SIMR, GAP, TRACE, DECOR, TCMC, RAS-WM‡)。三不变式：
(i) **实时零学习写操作**（继承 R68 定义 276-i；排练只在离线/影子通道）；
(ii) **溯源纪律**：任何进入安全论证的能力必须携带有效 gap 证书与覆盖域；未认证能力只能「建议」，不得作为单独证据；
(iii) **证据独立纪律**：用于 k-一致定案的证据源，其两两相关须 ≤ ρ_max，且以 k_eff 折减；k_eff 低于阈值则禁止多源定案并退化 R69。

**定义 311（单模型多任务骨干 OMNI 与任务条件认知态）** 共享骨干 z = Φ(o)，任务嵌入 e_τ（FiLM 条件）。策略 π_θ(ξ|o,τ)，但**认知态任务条件化**：模态头、校准头、似然温度均为 τ 专属：h_τ = Ψ_τ(z)。原则：**共享「物理」，隔离「信念」**——世界如何运转可共享，我有多确定必须分任务记账。

**定义 312（仿真保真度与域随机化）** 模拟器族 {Sim_φ}，保真度参数 φ（物理、传感噪声、人类行为模型）。训练分布 p_sim(o,ξ,τ;φ)。域随机化 p_sim^DR = ∫ p_sim(·;φ) dP(φ)。定义覆盖系数 α(φ) = ∫ min(p_sim, p_real) 与随机化半径 r。**保真稀释**：r 增大降 W_1 但稀释任务特异信号，存在最优点 r*。

**定义 313（Sim-to-real 差距证书 GAP）** 对能力 c（某任务模块或交互策略），若损失 ℓ_c 有界 B、对输入 L_c-Lipschitz，则对置信 1−δ、n 对配对 sim-real 回合有
R_real(c) ≤ R_sim(c) + L_c·W_1(p_sim, p_real) + 2B·√(log(2/δ)/(2n))。
记上界为 ĝ(c)。证书 GAP(c) = (ĝ, α, n, 时间戳)。**认证** ⇔ ĝ ≤ ε_task ∧ α ≥ α_min ∧ 未过期。

**定义 314（能力溯源账本 TRACE）** 每项能力 c 记 TRACE(c) = (训练来源 {sim,real}、任务集 𝒯_c、gap 证书、最后真实校验、共享更新指纹、污染标记)。部署只读；账本本身进审计与证书哈希。**保质期**：距最后真实校验超过 T_stale 自动降级。

**定义 315（排练式交互训练 SIMR）** 在仿真中让交互策略面对**见证人群** W = {诚实、噪声、说谎、谄媚、跨模态共谋、以及「模拟器自身」}，以最坏见证分布下的真实 VoI−成本为目标：
min_π max_{w∈W} E_w[ c(g) − VoI_real(g) ]，且 g 过 R69 定义 302 安全认证与证据纪律。排练产出的是**交互先验**，不是真理；其可信度由 GAP 与真实审计集共同背书。

**定义 316（证据相关性与有效独立数 k_eff）** 证据源 r_1..r_k 的误差相关矩阵 P（在留出审计集上估计），等相关近似记 ρ̄。定义 k_eff = k / (1 + (k−1)ρ̄)。定义「独立预算」：仅当 k_eff ≥ k_min 才允许 k-一致定案；否则单源只作似然、不单独定案（回到 R69 纪律的保守版本）。

**定义 317（任务条件模态校准 TCMC）** 对每任务 τ 的模态权重记 ECE_τ；跨任务泄漏 L_{τ|τ'} = E|conf_τ − acc_{τ→τ'}|，其中 acc_{τ→τ'} 是在任务 τ 上、用由 τ' 共享特征解释的置信所对应的真实准确率。若 ECE_τ > τ_ece 或 L_{τ|τ'} > τ_leak，则禁用 τ' 对 τ 的证据借用，并把该模态权重降级为「建议」。

**定义 318（任务干涉与共享幻觉）** 干涉矩阵 I_{τ,τ'} = R_τ(θ_𝒯) − R_τ(θ_τ)（加入 τ' 后 τ 的风险变化）；共享幻觉分 CH_τ = max_{a 错} [log p_θ(a|o,τ) − log p_{θ\τ'}(a|o,τ)]（任务 τ' 的共享更新把 τ 的错误动作抬高的幅度）。I_{τ,τ'} > τ_I 触发**隔离路由**；CH_τ > τ_CH 触发**共享表征回滚/去污染**。

**定义 319（仿真器作为被折减见证）** 模拟器见证 s 的欺骗率 δ_sim、与策略相关 ρ_sim。其证据权重 w_sim = (1−δ_sim)(1−ρ_sim)，且**不得成为唯一定案源**。仿真证据须与至少一个真实/独立源一致，或 VoI 增益超过「排练可信度折扣」后的高置信阈值。直接对应 R69 引理 18 的一个特殊投毒者。

**定义 320（能力门与降级 Capability Gate）** 部署时对每个能力查 TRACE：未认证 / 过期 / 覆盖不足 ⇒ 能力降级为 advisory；其产生的证据只进似然、不进定案。降级可逆（重新真实校验后恢复），但恢复需新证书、不得热写。

**定义 321（排练-部署一致性监视器 RDC）** 在线比较真实交互的实测 VoI/风险与排练预测的 VoÎ/风险̂：drift = |VoI_real − VoÎ| / σ̂。超阈值 ⇒ 该能力立即降级，并把真实回合写入审计集以重估 GAP。防止「排练时过拟合、部署时已漂移」。

**定义 322（证书 J_STAGE）** J_STAGE = (J_FLUID, trace_hash, gap_upper, coverage α, k_eff, interference_top, rehearsal_drift, provenance_version)。Valid ⇔ Valid(J_FLUID) ∧ 所有用到的能力已认证 ∧ k_eff ≥ k_min ∧ drift ≤ τ_drift。

**定义 323（共享/隔离路由 DECOR）** 对任务对 (τ,τ') 依 (I_{τ,τ'}, L_{τ|τ'}, CH_τ) 选择：全共享 / 只共享物理层、信念层隔离 / 完全隔离。目标：在共享摊销收益与相关性惩罚间取最优：max 共享收益 − λ·(相关风险)。给出「共享预算」。

**定义 324（安全退化与严格包含）** 若任一条件不满足（未认证 / k_eff < k_min / drift 越界 / ECE 越界 / 检测到共享幻觉），STAGE 逐指令退化为 R69（禁用排练先验与跨任务证据）；若 R69 的交互也不可得（预算 / VoI），再退化为 R68 纯保守。⇒ STAGE ⊇ R69 ⊇ R68，安全侧单调不让步。

## 2. 关键算法骨架

```python
# IP-264 OMNI：单模型多任务骨干（共享物理，隔离信念）
class OMNI:
    def encode(self, o, tau):
        z = self.trunk(o)                         # 物理表征共享
        e = self.task_emb(tau)
        return z, e
    def epistemic_heads(self, z, tau):            # 任务条件认知态
        return self.mode_head[tau](z), self.calib_head[tau](z), self.temp[tau]

# IP-265 SIMR：排练式交互训练（见证人群 + 模拟器自身作为被折减见证）
def rehearse(policy, sim, witnesses, budget):
    for episode in sim.rollout(...):
        w = witnesses.sample()                    # 诚实/说谎/谄媚/共谋
        g = policy.propose_interaction(episode, w)
        r = episode.reward(g) - budget.cost(g)
        policy.update_worst_case(r, w)            # min_π max_w
    return policy                                 # 产出交互先验，不产出真理

# IP-266 GAP：sim-to-real 差距证书（迁移界 + 配对置信项）
def gap_certificate(c, sim_episodes, real_episodes, L_c, B):
    R_sim = risk(c, sim_episodes)
    W1    = wasserstein1(sim_episodes.dist, real_episodes.dist)
    n     = min(len(sim_episodes), len(real_episodes))
    upper = R_sim + L_c * W1 + 2 * B * sqrt(log(2 / 0.05) / (2 * n))
    alpha = coverage(sim_episodes.dist, real_episodes.dist)
    return GAP(upper, alpha, n, now())

# IP-268 DECOR：证据相关性估计与有效独立数
def effective_k(evidence_matrix):
    P   = corr_matrix(evidence_matrix)            # 留出审计集估计
    rho = offdiag_mean(P)
    k   = evidence_matrix.shape[1]
    return k / (1 + (k - 1) * rho), P

# IP-275 STAGE-RAS 主闭环：先查账、再折减、后复用 R69
def STAGE_RAS_round(M, obs, tau):
    cap = M.trace.lookup(tau)
    if (not cap.certified) or cap.stale:              # 能力门：不可证
        return FLUID_RAS_round(M, obs, use_prior=False)   # 逐指令退化 R69
    k_eff, P = M.decor.effective_k(M.audit.evidence(tau))
    if k_eff < K_MIN:                                 # 独立性被共享骨干蛀空
        return FLUID_RAS_round(M, obs, discipline='single_source_guard')
    w_tau = M.tcmc.calibrated_weights(tau, borrow_mask=(P < RHO_MAX))
    g = M.mint.choose_interaction(
        w_tau, obs, M.budget,
        sim_prior=M.simr.prior(tau),                  # 被折减见证
        sim_weight=(1 - cap.delta_sim) * (1 - cap.rho_sim))
    out = FLUID_RAS_round(M, obs, interaction=g, mode_w=w_tau)
    if M.rdc.drift(out.voi_real, out.voi_rehearsed) > TAU_DRIFT:
        M.capgate.demote(tau); M.audit.enqueue(out.episode)
    M.jstage.submit(out, cap, k_eff, M.interf.top(tau), M.rdc.last)
    return out
```

## 3. 推导

**引理 19（共享骨干摧毁证据独立数）** 设 k 个证据源误差等相关 ρ，则其均值的有效样本量 k_eff = k/(1+(k−1)ρ)。代入 R69 引理 18 的多数一致上界得错误采纳率 ≤ δ_p·ρ^{k_eff−1} + ε_σ。当 ρ→1，k_eff→1，上界退化为单源 δ_p + ε_σ。**系**：单模型多任务的「一个模型」恰是把 ρ 推高的结构性原因；不量化 ρ，「k 源一致」只是集体自洽，不是独立验证。

**引理 20（sim-to-real 迁移界与保真稀释）** 定义 313 给出 |R_real − R_sim| ≤ L_c·W_1 + 置信项。域随机化半径 r 增大使 W_1(r) 下降，但任务特异信噪比 SN(r) 下降（保真稀释），排练风险 R_sim(r) 先降后升，故存在 r* = argmin_r [R_sim(r) + L_c·W_1(r)]。**系**：仿真训练的收益不是「越多越好」，而是「在正确保真档位上的最坏见证排练」。

**引理 21（模拟器作为见证的欺骗上界）** 若模拟器欺骗率 δ_sim、与策略相关 ρ_sim，且不得单独定案，则其引入的错误采纳率不超过 (1−(1−δ_sim)(1−ρ_sim))·δ_p + ε。**系**：把仿真器放进 R69 的投毒框架，而不是放在其外——它只是「最便宜但最不独立的第 k 个见证」。

**定理 18（STAGE 严格包含 R69 与 R68）** 在定义 310 三不变式下：当能力已认证、k_eff ≥ k_min 时，STAGE 的期望真实交互风险 ≤ 纯 R69（排练降低了问错的代价）；当未认证、过期、k_eff 不足或 drift 越界时，STAGE 与 R69 **逐指令相同**；当 R69 亦不可交互时与 R68 相同。故 STAGE ⊇ R69 ⊇ R68，安全侧单调不让步，收益侧只在可证时兑现。

**定理 19（共享幻觉的传播与隔离条件）** 设任务 τ' 的更新使共享表征偏移 Δz，任务 τ 的错误动作对数似然抬升 CH_τ ≤ L_ψ‖Δz‖。若 τ 使用跨任务证据且 CH_τ > τ_CH，则其错误模态采纳率上升至少 δ_p·(1−e^{−CH_τ})；采用定义 323 的隔离路由（信念层隔离 / 物理层共享）可把 CH_τ 压回 ≤ τ_CH，且共享收益损失 ≤ 隔离预算。**系**：**共享物理是资产，共享信念是负债**。

（备注：以上为工作假设 A99 下的界——ℓ_c 有界且 L_c、L_ψ 有限；E301–E315 检验其紧致性。）

## 3. 关键算法伪代码

# IP-264 OMNI：共享物理，隔离信念
class OMNI:
    def encode(self, o, tau):
        return self.trunk(o), self.task_emb(tau)
    def epistemic_heads(self, z, tau):
        return self.mode_head[tau](z), self.calib_head[tau](z), self.temp[tau]

# IP-265 SIMR：最坏见证排练（含模拟器自身）
def rehearse(policy, sim, witnesses, budget):
    for ep in sim.rollout(...):
        w = witnesses.sample()
        g = policy.propose_interaction(ep, w)
        policy.update_worst_case(ep.reward(g) - budget.cost(g), w)

# IP-266 GAP：迁移界证书
def gap_certificate(c, sim_eps, real_eps, L_c, B):
    R_sim = risk(c, sim_eps)
    W1    = wasserstein1(sim_eps.dist, real_eps.dist)
    n     = min(len(sim_eps), len(real_eps))
    upper = R_sim + L_c * W1 + 2 * B * sqrt(log(2 / .05) / (2 * n))
    return GAP(upper, coverage(sim_eps.dist, real_eps.dist), n, now())

# IP-268 DECOR：有效独立数
def effective_k(E):
    P = corr_matrix(E); rho = offdiag_mean(P); k = E.shape[1]
    return k / (1 + (k - 1) * rho), P

# IP-275 主闭环：先查账、再折减、后复用 R69
def STAGE_RAS_round(M, obs, tau):
    cap = M.trace.lookup(tau)
    if (not cap.certified) or cap.stale:
        return FLUID_RAS_round(M, obs, use_prior=False)       # 逐指令退 R69
    k_eff, P = M.decor.effective_k(M.audit.evidence(tau))
    if k_eff < K_MIN:
        return FLUID_RAS_round(M, obs, discipline='single_source_guard')
    w_tau = M.tcmc.calibrated_weights(tau, borrow_mask=(P < RHO_MAX))
    g = M.mint.choose_interaction(
        w_tau, obs, M.budget, sim_prior=M.simr.prior(tau),
        sim_weight=(1 - cap.delta_sim) * (1 - cap.rho_sim))
    out = FLUID_RAS_round(M, obs, interaction=g, mode_w=w_tau)
    if M.rdc.drift(out.voi_real, out.voi_rehearsed) > TAU_DRIFT:
        M.capgate.demote(tau); M.audit.enqueue(out.episode)
    M.jstage.submit(out, cap, k_eff, M.interf.top(tau), M.rdc.last)
    return out

## 4. 推导

**引理 19（共享骨干摧毁证据独立数）** k 个等相关 ρ 的证据源，其均值有效样本量 `k_eff=k/(1+(k−1)ρ)`；代入 R69 引理 18 得错误采纳率 ≤ `δ_p·ρ^{k_eff−1}+ε_σ`。ρ→1 时 k_eff→1，上界退化为单源 `δ_p+ε_σ`。系：单模型多任务恰是推高 ρ 的结构性原因，「k 源一致」可能只是集体自洽。

**引理 20（迁移界与保真稀释）** `|R_real−R_sim| ≤ L_c W_1 + 置信项`；随机化半径 r 增大降 `W_1` 但稀释任务特异信噪比，`R_sim(r)` 先降后升，存在 `r*=argmin_r[R_sim(r)+L_c W_1(r)]`。系：排练不是越多越好，而是「正确保真档位上的最坏见证排练」。

**引理 21（模拟器作为见证的欺骗上界）** 仿真器欺骗率 `δ_sim`、与策略相关 `ρ_sim` 且不得单独定案时，引入的错误采纳率 ≤ `(1−(1−δ_sim)(1−ρ_sim))·δ_p + ε`。系：把仿真器放进 R69 投毒框架，而非置于其外。

**定理 18（STAGE 严格包含 R69 与 R68）** 能力已认证且 `k_eff≥k_min` 时，STAGE 期望真实交互风险 ≤ 纯 R69（排练降低问错代价）；未认证 / 过期 / `k_eff` 不足 / drift 越界时两者**逐指令相同**；R69 亦不可交互时与 R68 相同。故 `STAGE ⊇ R69 ⊇ R68`，安全单调不让步，收益只在可证时兑现。

**定理 19（共享幻觉传播与隔离条件）** 任务 τ' 使共享表征偏移 Δz，则 `CH_τ ≤ L_ψ‖Δz‖`；若 τ 借用跨任务证据且 `CH_τ>τ_CH`，其错误模态采纳率上升至少 `δ_p(1−e^{−CH_τ})`；采用「物理共享、信念隔离」路由可把 `CH_τ` 压回阈值内，共享收益损失 ≤ 隔离预算。系：共享物理是资产，共享信念是负债。

（工作假设 A99：ℓ_c 有界，`L_c, L_ψ` 有限；界之紧致性由 E301–E315 检验。）
