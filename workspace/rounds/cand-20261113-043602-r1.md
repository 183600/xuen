# 第 3 轮迭代（灵感循环 v3：「分布外泛化」×「谐波减速器」）—— 机械相位：开环动作块里最被低估的分布外轴

> **承接 v2（UIP-01′~15）。本轮不换赛道，换"OOD 的定义域"。** v2 把分布外主要理解为"未见物品 / 人为撤回 / 背景位置"，并用 Gazebo 造数据、用验证器重做。两个新灵感词把注意力拉到一个更隐蔽、也更接近物理的轴上：**policy 发出的动作与机器人真正做出的事情之间，存在一个带记忆的机械传动层**。谐波减速器只是这个层最典型的样本——它有运动误差、失动、滞回、柔度与温漂；而 G1 实际用的是 QDD 两级行星减速器（见 §0 纠偏），两者参数不同，但**"命令≠输出、且输出依赖历史"**这件事相同。分布外泛化因此多了一个视觉看不见的维度：**机械相位（mechanical phase）**。
>
> **诚实声明（先于结论）**：本轮做了针对性复核（2026-11-13）：从官方 G1 规格页、公开拆解与规格汇总交叉检查了关节传动类型；从 `unibot_submission` 仓库重新核对了观测/动作/块长硬约束；从 HF 数据集 `meta/info.json` 复核了数据键。**"谐波减速器"不是 G1 的关节硬件**，本轮把它降格为"压力测试模型类"，不当作已核实事实。所有数值量级均为**说明性估算**，不作为测量结论。

### 纠偏 A：G1 不是谐波减速器；不要把方案建在错误硬件上

这是本轮最重要的一条。**"谐波减速器"与 G1 的实际关节不一致**。如果直接写"G1 的谐波减速器导致……"，就是把灵感词误当成事实，评审一眼就能拆穿。正确的用法是：

1. **把谐波减速器当作"传动非理想性"的典型模型类**：高减速比、近零背隙、但强扭转柔度/滞回、2×/rev 的 TE。它代表**最坏情况**的一端。
2. **把 G1 的行星 QDD 当作校准锚点**：低减速比、较高刚度、但有背隙/齿频 TE/摩擦/发热降额。它代表**实际测试分布**。
3. 两者共享同一个可迁移结构：`命令 → 隐藏机械状态 → 输出`，且隐藏状态**依赖历史**。我们研究的是这个结构，而不是某一家减速器。

这样处理有一个额外好处：**行星与谐波压力的是不同的失效模式**（背隙/齿频 vs 柔度/滞回），把它们放进同一个训练族，正好覆盖"传动参数分布外"的两端；但必须用**小权重的压力组**，否则会为了一个不是测试分布的极端而过拟合（见 UIP-18 的抗过拟合条款）。

### 纠偏 B：v2 的"运行期自适应块长"接口上不成立

`action_chunk_size` 握手时固定，`example_env.step()` 对每个动作键硬校验 `shape == (T_a, …)` 且 `dtype == float32`。因此：

- **不能**在运行期返回"≤k 步"的块；v2 UIP-13 ACS 的"每次返回 ≤k 步"作废。
- 所有恢复/门控决策只能发生在**块边界**；块内只能改变**内容**（保持、减速、加 lead），不能改变**长度**。
- 一个直接推论：**最小检测延迟下界 = T_a 步**。人扰撤回若发生在块内，最晚要到块末才被看到。这把 T_a 从"工程参数"提升为**OOD 反应性与得分的安全边界**（UIP-21）。

### 纠偏 C：`human_*` 的语义仍是推断，不是官方定义

v2 把 `human_*` 从"描述文本"升级成了"规则级事实：人为干扰会主动反向消耗步骤分"。这仍然是一个**很强的语义推断**：这些字段也可能是**数据采集时人类示范如何变化**的说明，而不是**评测时的主动干预**。在拿到手册或官方 episode 之前，最多把它当**高价值工作假设**。本轮的对策不是撤回它，而是：

- 把机械轴（UIP-16/17/18/20/21/22）设计成**不依赖人扰语义**也成立：传动非理想性是硬件事实；
- 加一个**廉价证伪实验 E302**：抽查官方示例 episode 视频/`info.json`，确认是否出现测试时的人手干预；若不出现，则 UIP-19 的"guard"分支降权，UIP-17 仍保留（用于自身反向操作）。

## 1. 直觉解释（先讲人话）

### 1.1 关节不是"位置源"，而是一段带记忆的弹簧+齿隙

把机械臂关节想成一根**有间隙、会扭、会热、齿形还有周期误差**的传动链。你命令它转到 `q_c`，它真实到的位置 `q` 不是 `q_c`：

- **运动误差（TE）**：每转一圈，误差像正弦一样重复几次；它不随机，**相位锁定**在关节角上。
- **失动/背隙（lost motion / backlash）**：你反向的那一刻，电机先走一小段"空程"，输出还不动；等间隙吃完，输出才跟上。
- **柔度（compliance）**：碰到东西、受力时，传动链被扭了一下，末端比命令**滞后**一点；力越大，滞后越大。
- **滞回/温漂**：同一位置，加载和卸载的轨迹不重合；热了以后摩擦和扭矩常数还会变。

这些量单独看可能只有零点几度到几度，但换到 0.3 m 的臂展上就是**零点几毫米到几毫米**——正好是插网线、插充电器、拉拉链、叠毛巾这些"高价值末步"的容差量级。

### 1.2 开环动作块把"机械误差"从可纠正的噪声变成了隐藏状态

如果每一帧都能闭环，机械误差可以当场修。但赛制是：你返回一个 `T_a` 步的动作块，评测端**整块执行完**才再调用你。于是：

- 你发出的是**一段意图**，不是一次反馈；
- 块内发生的反向、接触、卡住，你在块末之前看不到；
- 同一个动作块，在"间隙已吃紧"和"间隙还没吃紧"两种机械状态下，会产生**不同结果**；
- 更糟的是：机械状态**不是**观测里的一个键。它是**非马尔可夫的隐变量**。

这解释了一个反直觉现象：**视觉完全相同的两个时刻，可能是两个不同的动力系统。** 如果 OOD 检测只看图像，它永远分不清"同一个场景、不同传动状态"——因为输入分布相同，转移核不同。

### 1.3 但残差是免费的传感器： nuisance → observation

虽然接口不给你 torque，但它给了你 `action(t)` 和下一时刻的 `state(t+1)`。两者之差 `r_t = q_{t+1} - q^c_t` 里混着：

- 可重复的周期项（TE）→ 可以学成傅里叶级数，按关节相位补偿；
- 方向相关的死区（失动）→ 可以用"方向反转"事件检测，并用 lead 补偿；
- 负载相关的滞后（柔度）→ 可以作为**接触/受力的序贯代理**，不追求绝对牛顿值，只追求"是否接触、是否在死区、是否过载"的**序贯类别**；
- 慢变项（温漂/磨损）→ 作为 OOD 分数的一部分。

**关键认识**：人扰的 `human_*` 大多是**反向撤回**（拧回去、拉开、翻开、拿走）。而反向正是失动/滞回最咬人的地方。所以机械模型不是支线任务，它恰好是**最高价值干扰的攻击面**——人扰与机械非理想性在"方向反转"这一点上合流。

> 一个纯信息论的类比（只作直觉，不作理论）：开环动作块本身也像一个"时间上的减速器"——你的意图经过一段不可观测的传动才到达世界，块边界就是"死区"。这也解释了为什么 `T_a` 的选择是 OOD 反应性的核心旋钮。

## 2. 严谨定义

### 2.1 观测、动作与块策略

设第 `t` 个决策时刻的观测
`o_t = (I_t^{L,h}, I_t^{R,h}, I_t^{L,w}, I_t^{R,w}, q_t, s_t^{ee}, g_t, l)`，
其中 `q_t ∈ R^{14}` 为左右臂关节状态，`s_t^{ee} ∈ R^{12}` 为左右 ee pose，`g_t` 为夹爪，`l` 为语言。

策略在每次调用返回一个块
`A_t = (a_t, a_{t+1}, …, a_{t+T_a-1})`，`a ∈ R^{14}`（joint 目标）或 `R^{12}`（ee 目标）；评测端整块执行，然后调用下一次。记 `π: (o_{≤t}, A_{<t}) → A_t`。

### 2.2 传动算子与隐藏机械状态

把它写成带隐状态的算子：

```text
y_t   = G_θ(q^c_t, h_t, τ_t)          # 真实输出（关节/末端）
h_{t+1} = H_θ(h_t, q^c_t, τ_t)        # 隐藏机械状态（间隙啮合、滞回内变量、温度、接触）
r_t   = y_t − q^c_t                   # 可观测残差（接口里 q 与上一条命令之差）
```

分解：

```text
r_t = r_kin(q_t) + r_lost(Δq_t, h_t) + r_comp(τ_t) + r_therm(T_t) + ε_t
```

- `r_kin`：周期运动误差。谐波：主频 2×输入转；行星：齿频/啮合频率的谐波。用
  `r_kin(q) ≈ Σ_k [a_k cos(k q / R) + b_k sin(k q / R)]` 近似。
- `r_lost`：失动/背隙。用 play 算子 `B_b` 或 Bouc–Wen/Maxwell-slip 滞回：
  `ż = A q̇ − β |q̇| |z|^{n−1} z − γ q̇ |z|^n`，输出含 `z` 与死区。
- `r_comp`：柔度。末端近似 `Δx ≈ J K^{-1} J^T F`；关节侧 `Δq ≈ K^{-1} τ`。
- `r_therm`：慢变的热/磨损项，时间常数远大于一个 episode。

> **可辨识性警告（重要）**：接口只有位置，没有 torque/电流。仅凭 `r_t` **不能**辨识绝对负载 `τ` 或绝对刚度 `K`（`τ` 与 `K` 只以比值出现）。因此 UIP-16 的输出必须是**序贯类别/相对状态**（in-deadzone / contact / overload / reversal / thermal-drift）及不确定度，而不是"估计出 3.7 N·m"。任何声称能测绝对力矩的做法都是在骗自己。

### 2.3 分布外偏移族与鲁棒风险

设环境 `e = (任务, 物体/布局, 人手策略, θ_mech)`。训练分布 `P_0`，测试分布 `P_1 = T(P_0)`。考虑三个生成器：

- `T_perc`：物体/背景/光照变化（**改观测似然** `p(o|s)`）；
- `T_human`：人扰策略（**改对手动作**，主动、部分可观测）；
- `T_mech`：传动参数/状态变化（**改转移核** `p(s'|s,a)`，但**常常不改观测似然**）。

定义步骤分回报 `J(π;e) = 1[success] + step_score/100`，鲁棒目标：

```text
分组 DRO:   min_π  max_{g∈G}  E_{e~P_g}[ −J(π;e) ]
CVaR:       min_π  CVaR_α[ −J(π;e) ],   e ~ P_mix
P_mix = (1−β) P_nominal + β P_stress,  β 小（防对极端压力组过拟合）
```

组 `g = (任务族, 机械桶)`，机械桶可取 `{nominal, high-backlash, low-stiffness, hot/worn, harmonic-stress}`。

### 2.4 步骤分期权（Step-Score Option）

设当前已锁定步骤分 `S`，下一步分值 `v`（来自 32 任务计分表），尝试成功概率 `p`，失败时损失当前进度的比例 `ℓ ∈ [0,1]`。则

```text
尝试的期望增量 = p·v − (1−p)·ℓ·S
不尝试（secure）= 0
⇒ 尝试 iff  p > p* = ℓ·S / (v + ℓ·S)
```

- `ℓ=0`（失败不毁前序）⇒ `p*=0`，应当永远尝试；
- `ℓ=1`（失败可能推倒重来）⇒ `p* = S/(S+v)`。例：`S=60, v=40 ⇒ p*=0.6`。
- OOD 上升时 `p↓`、`ℓ↑` ⇒ `p*` 上升 ⇒ 更应 **guard/secure**，而不是盲目搏末步。

这把 v2 的"保前置、搏末步"从口号变成一个**可计算的门限**；"guard"是第三种动作：不前进，但降低 `ℓ`（护住已得进度）并为下一次尝试提高 `p`，代价是时间与暴露在人扰下的风险。

### 2.5 三条可检验命题

- **P1（观测-only 不足）**：存在 `e_1 ≠ e_2`，其观测边缘分布在前缀上相同，但转移核不同；任何只依赖 `o` 的 OOD 分数分布相同。故机械 OOD 必须用**动作条件残差**。证明是构造性的：同一场景、不同关节刚度，首帧图像可完全相同。
- **P2（反向损失一阶）**：一维 play 宽 `b`、反向速度 `v`、控制频率 `f`，反向开始时输出恢复滞后 `b/v` 秒，即 `⌈b f / v⌉` 步；带补偿 `b̂` 后剩 `⌈|b−b̂| f / v⌉` 步。末端量级 `b_x ≈ L b_q`。当 `b_x` 与接触容差同量级时，**一次反向就能吃掉全部容差预算**；开环下策略若不知道反向已发生，还会过冲/顶死。
- **P3（期权单调）**：`p*` 关于 `ℓ` 与 `S` 单调不减、关于 `v` 单调不增；因此"OOD 越强越保守"不是拍脑袋，而是期望步骤分的直接推论（在失败会损失前序的假设下）。

## 3. 对 v2 清单的诊断：升级什么、修剪什么、复活什么

- **升级（把机械层接进旗舰）**：
  - UIP-01′（滚动验证-重做）→ **UIP-16 MBO-PV**：验证器多一路"动作条件机械残差"，`regressed` 不再只靠视觉/语义；并修正块接口。
  - UIP-09′（扰动撤回检测-重做）→ **UIP-17 LMC**：不是"检测到撤回就重做"，而是**反向时加失动 lead + 接触合规**，让重做真的能咬合。
  - UIP-02′（步骤分安全网）→ **UIP-19 OOD-SSO**：从"按计分点推进"升级为"按期望步骤分做 advance/guard/secure 期权"。
  - UIP-11/12（Gazebo 判分 + 扰动工厂）→ **UIP-18 TR-DRO**：从"造人扰数据"扩展为"造**传动参数族**"，并明确"行星锚定、谐波压力"。
  - UIP-15（可信度安全阀）→ **UIP-20 MOSC**：阈值改成保形校准，异常源加入机械残差。
  - UIP-13（ACS 自适应块长）→ **UIP-21 OAT**：运行期变块长作废，改为**离线**选固定 `T_a`。
- **复活（带新理由）**：UIP-10（joint/ee 双空间）→ **UIP-22 MCS**。上轮因"metadata 只能握手定一次"而降级；但机械视角给出**一次性选择的判据**：ee 空间天然吸收可重复的运动学误差，joint 空间则要求策略自己学 `r_kin`。不是"运行期仲裁"，而是"握手时选对不变性"。
- **保留**：UIP-05（语言→可供性）、UIP-08′（多端口延迟工程）、UIP-14（技能图；新增"机械敏感度"标签）。
- **封存**：外部 VLM 验证器（合规风险）、UIP-04 学习式世界模型 MPC（仍不划算）。

**旗舰叙事**：v3 的旗舰不是单个模块，而是 **"机械信念闭环" MBC = UIP-16（观测）+ UIP-17（补偿）+ UIP-19（期权）**，由 UIP-18 造压力分布、UIP-20 设门、UIP-21 定块长。它对准的是：**规则里最高价值的末步，恰好是机械 OOD 最致命的接触/反向步**。

## 4. 瓶颈假设（更新）

- **H1′（最高杠杆）**：对接触密集/反向类步骤，最危险的 OOD 不是"没见过的物体"，而是"没见过的**机械相位**"；它视觉上不可见，靠加同类演示无法覆盖，必须靠**动作条件残差 + 状态估计**。
- **H2′**：人扰与失动共享"方向反转"这一攻击面；因此 UIP-17 有双重收益（既恢复人扰，又纠正自身反向操作）。
- **H3′**：绝对力矩不可辨识，但**序贯机械相位**可辨识；把目标从"测力"降为"分类+不确定度"，是从幻想回到工程的关键。
- **H4′**：`T_a` 存在内点最优：太大 ⇒ 反向/接触的检测延迟大、恢复慢；太小 ⇒ 往返多、延迟方差大、可信度受损。它应在**离线**用最差组步骤分选，而不是运行期变。
- **H5′**：ee 控制空间只提供**部分不变性**：它吸收可重复的运动学误差，但吸收不了负载相关柔度与夹爪/接触非线性；所以要 A/B 实测，不能当成定理。

## 1. 旗舰：UIP-16 · MBO-PV（Mechanical-Belief Observer + Progress Verification）

### 1.1 直觉与形式

我们不试图"测力矩"（接口没有 torque，绝对量不可辨识），而是估计一个**序贯机械相位**：

```text
c_t ∈ { FREE, IN_DEADZONE, CONTACT, OVERLOAD, REVERSAL, THERMAL_DRIFT }
```

它回答四个对策略有用的问题：**现在在空程里吗？刚反向了吗？碰到东西了吗？传动是不是热了/磨损了？**

可观测残差（在块边界对齐时间后）：

```text
r_t = q^obs_{t+1} − a_t          # 关节侧；若用 ee 空间则 r_t^x = s^obs_{t+1} − a_t
r_t ≈ r_kin(q_t) + r_lost(Δq_t,h_t) + r_comp(τ_t) + r_therm(T_t) + ε_t
```

观测器：

```text
z_t = E_ψ(r_{t−H:t}, Δa_{t−H:t}, s^{ee}_{t−H:t}, I^{wrist}_t, l)
(c_t, σ_t, ĉontact_t, b̂_t, T̂e_t) = heads(z_t)
```

- `E_ψ` 共享骨干 + 轻量时序层（TCN/GRU）；腕部图像只做小分辨率分支。
- `b̂_t` 是**归一化失动量**（除以关节行程或齿距），不是绝对弧度。
- `T̂e_t` 是低维傅里叶系数（只取前 2–3 个齿频谐波），用于相位锁定补偿。
- `σ_t` 是预测不确定度，直接进入 UIP-20 的门控。

### 1.2 训练：自监督为主，仿真参数标签为辅

公开数据只有"正常演示"，没有 torque/机械标签，所以：

1. **前向残差预测（自监督）**：`L_fwd = || r_{t+1} − f_φ(r_{≤t}, Δa_{≤t}) ||²`。这迫使 `z_t` 捕捉"下一拍会差多少"，而不是外观。
2. **仿真参数分组对比（有标签）**：在 Gazebo/Isaac 里随机化 `(b, K, 滞回, 齿频 TE, 摩擦, 温度)`，同一任务、同一轨迹、不同参数 = 不同组。用监督对比损失把 `z_t` 拉到"机械参数相同则近、不同则远"；同时用**域对抗头**去掉仿真外观/渲染线索。
3. **弱接触标签**：仿真接触标志、腕部图像里的接触/形变、以及"命令在动而观测不动"的停驻事件，作为 `CONTACT/OVERLOAD` 的弱监督。
4. **真机自监督微调**：用公开 32k episodes 的 `r_t` 做前向预测与一致性正则；**不**假设有机械标签。

> **可辨识性纪律**：训练目标里**禁止**出现绝对 `τ` 回归；只允许序贯类别、相对变化、单调负载等级。否则模型会学到"用图像猜牛顿"的伪相关。

### 1.3 与进度核验的融合

v2 的 `V(o_t,l,g)` 输出 `{done, ongoing, fail, regressed}`。MBO-PV 增加机械证据：

```text
P(regressed | o, l, g, c_t) ∝ P_vis(regressed | o,l,g) · P_mech(c_t | regressed)
```

工程上先做一个可解释的规则层（不引入外部大模型）：

- 视觉说 `done`，但 `c_t = IN_DEADZONE` 且上一块刚反向 ⇒ **暂缓 advance**，再发一个短的"咬合"块；
- 视觉说 `ongoing`，但 `c_t = REVERSAL` 且子目标从 done 回退 ⇒ `regressed`；
- 视觉说 `fail`，但 `c_t = CONTACT/OVERLOAD` ⇒ 先退让/保持，再重试，避免顶死；
- 置信度 `σ_t` 高 ⇒ 不重做，交给 UIP-19 的 guard/secure。

### 1.4 伪代码（严格服从 `(T_a,…)` 与 token 契约）

```python
class MBCPolicy:
    def __init__(self, base, observer, verifier, lmc, option, mosc, T_a, token):
        self.base, self.observer, self.verifier = base, observer, verifier
        self.lmc, self.option, self.mosc = lmc, option, mosc
        self.T_a, self.token = T_a, token
        self.last_chunk = None
        self.h = None

    @property
    def metadata(self):
        return {
            "control_space": self.space,                 # "ee" 优先，见 UIP-22
            "obs_delta_indices": self.obs_offsets,       # 握手后不变
            "image_resize": self.image_resize,
            "action_chunk_size": self.T_a,               # 固定
            "token": self.token,
        }

    def reset(self):
        self.base.reset(); self.observer.reset(); self.verifier.reset()
        self.option.reset(); self.mosc.reset()
        self.last_chunk, self.h = None, None

    def get_action(self, obs):
        # 1) 用“上一块命令 vs 当前观测”更新机械信念（只在块边界）
        if self.last_chunk is not None:
            self.h = self.observer.update(self.last_chunk, obs, self.h)
        self.verifier.update(obs, self.h)

        # 2) OOD 分数 + 保形门控
        d = self.mosc.score(obs, self.h, self.observer.residual)
        ood = self.mosc.flag(d)

        # 3) 步骤分期权：advance / guard / secure
        mode = self.option.decide(self.verifier.progress,
                                  self.verifier.step_idx,
                                  ood, self.h)

        # 4) 生成固定长度块（内容随 mode 变，长度永远 T_a）
        A = self.base.chunk(obs, mode=mode)              # dict[key] -> (T_a, …)

        # 5) 机械补偿与安全裁剪
        A = self.lmc.apply(A, self.h, obs, mode=mode)
        A = self.mosc.clip(A, self.h, ood)

        A["meta.token"] = self.token
        self.last_chunk = A
        return A
```

> **注意**：`A` 必须包含所选控制空间的全部键（joint 或 ee）+ 共享的 gripper/pivot，形状精确 `(T_a,…)`，`dtype=float32`。块内不能"提前结束"；`guard/secure` 只能通过**内容**（保持、减速、退让）实现。

### 1.5 失效模式

- `state` 如果不是负载侧/输出侧，而是经过滤波的电机侧，`r_t` 可能被控制器吃掉，机械信号很弱 → E301 先做可辨识性审计，再决定是否投入。
- 残差里混着控制器跟踪误差与图像/时间对齐误差；时间对齐错一拍就能造出假"反向" → 必须用 timestamp/帧号严格对齐。
- 多关节耦合：`r_t` 的每个关节分量不是独立的；用雅可比投影到末端，按任务方向聚合。

## 2. UIP-17 · LMC（Lost-Motion Compensation）

### 2.1 一维推导（说明性，不是测量）

play/失动模型：反向开始时，输出 `y` 在 `|q_c − y| ≤ b/2` 内不动；命令以速度 `v` 前进，则输出恢复滞后

```text
t_lag = b / v          [秒]
n_lag = b f / v        [步，f 为控制频率]
```

加 lead 补偿 `q'_c = q_c + (b̂/2)·sign(Δq)` 后，残余死区为 `|b − b̂|`，故

```text
n_lag' = |b − b̂| f / v
```

末端量级 `b_x ≈ L·b_q`（`L` 为关节到接触点的有效力臂）。**当 `b_x` 与接触容差同量级时，一次反向就吃掉全部误差预算**；开环下策略还会因为"没看到反向生效"而继续推进，造成过冲/顶死。

### 2.2 算法

```python
def apply(self, A, h, obs, mode):
    dA = diff(A, axis=0)                     # 每步的关节/末端增量
    s  = sign(dA)
    rev = (s[1:] != s[:-1])                  # 反向事件（块内与跨块）
    lead = 0.5 * h.b_hat * s                 # 每个关节/每个笛卡尔轴
    lead *= gate(h.sigma, h.contact_prob)    # 不确定/接触时缩小，避免撞
    lead = clip(lead, -self.delta_max, self.delta_max)
    A = A + lead
    if mode == "guard":
        A = soften(A, factor=self.guard_slow)   # 减速/保持，降低 ℓ
    return A
```

- **只在反向窗口生效**（当前块 + 下一块的 1–2 步），随后指数衰减，避免永久偏置。
- `b̂` 用观测器的相对估计；若 `σ` 高，令 `lead=0`，退回"不补偿但多核验"。
- ee 空间下 `lead_x = J · lead_q`；joint 空间下直接逐关节加。

### 2.3 接触合规（与 LMC 合流）

当 `ĉontact_t` 高且 `r_t` 持续偏大：

1. 停止增加法向位移，保持当前姿态；
2. 用小幅 dither（1–2 mm / 1–2°）搜索啮合；
3. 若 `c_t=OVERLOAD`，先退让再重试（不要和人手/物体硬顶）。

这比"检测到撤回就重做"更细：**先确认反向是否真的咬合，再决定重做多少**。

### 2.4 安全红线

- `delta_max` 按任务容差设上限（例如不超过接触间隙的 1/2）。
- 与人共处时，`guard` 分支优先减速/退让；"抢人手重做"既危险又可能被判违规。
- 补偿是**开环前馈**，不是力控；不能替代碰撞检测。

## 3. UIP-18 · TR-DRO（Transmission-Robust Domain Randomization + Group DRO）

### 3.1 参数族（说明性先验，必须用真机校准）

| 参数 | 行星 QDD（锚） | 谐波（压力） | 说明 |

| 齿频 TE | 齿数×转频 | 2×输入转频 | 用 2–3 个谐波近似 |
| 摩擦 | 0.05–0.3 N·m | 0.05–0.2 N·m | 温度相关 |
| 热漂移 | 扭矩常数 −10~−20%，摩擦 +50% | 类似 | 长 episode 才显著 |

> 这些数字只是**搜索范围**，不是 G1 的实测参数；E310 真机锚点后必须收紧。

### 3.2 目标与抗过拟合

```text
L(θ) = (1−β) · L_nominal(θ) + β · max_{g∈G_stress} L_g(θ)
G_stress = { high-b, low-K, hot/worn, harmonic-stress }
```

- `β` 取小（0.1–0.2），并**报告 nominal 分数**；若 nominal 掉超过预设 δ，说明压力组把策略带偏，应退回。
- 组权重用 online group DRO：`w_g ∝ exp(η · L_g)`，但给 `nominal` 一个下界权重（锚定），防止"为了极端谐波牺牲真实分布"。
- 训练信号：行为克隆/DAgger 的进度/动作损失 + 可微的步骤分代理（子目标完成概率），不要把稀疏成败当唯一信号。

### 3.3 与 Gazebo 的关系

UIP-11′/12′ 不再铺 32 个全场景，而是选 **3–5 个探针任务**（建议 T26 插网线、T19 拉链、T16 叠毛巾、T27 叠碗、T23 球拍），只做两件事：

1. **扫传动参数**，验证 MBO 是否真的能辨识、LMC 是否真的有用；
2. 生成"反向 + 恢复"的对照数据（DRF 的残余价值）。

GSO 判分只当**结构裁判**，不当成败裁判；所有真机结论提测前标注为仿真代理。

## 4. UIP-19 · OOD-SSO（OOD-gated Step-Score Option）

### 4.1 期权公式

```text
S: 当前已锁定步骤分
v: 下一步分值（来自 32 任务计分表）
p: 成功概率（校准头或按任务/步骤/机械相位的经验率）
ℓ: 失败时损失当前进度的比例
尝试 iff  p·v > (1−p)·ℓ·S
⇒ p* = ℓS / (v + ℓS)
```

### 4.2 阈值表（由公式直接算出，不是实验）

| 任务步数 | `S` | `v` | `ℓ=0.25` | `ℓ=0.5` | `ℓ=1.0` |
|---|---|---|---|---|---|
| 2 步 | 50 | 50 | 0.20 | 0.33 | 0.50 |
| 3 步 | 60 | 40 | 0.27 | 0.43 | 0.60 |
| 4 步 | 75 | 25 | 0.43 | 0.60 | 0.75 |
| 5 步 | 80 | 20 | 0.50 | 0.67 | 0.80 |

**读法**：任务越长、末步越"贵"、失败越可能毁前序，`p*` 越高；OOD 下 `p` 下降、`ℓ` 上升，于是**越应该 guard/secure**。如果 `ℓ≈0`（失败不毁前序），则永远应该尝试——这也说明必须先**逐任务估计 `ℓ`**，不能一刀切。

### 4.3 guard / secure 的状态机

```text
if p ≥ 1.2 p*:        ADVANCE   # 正常推进，块内可用 LMC
elif p ≥ 0.5 p*:      GUARD     # 保持/护住进度，减速，优先避免人扰/碰撞
else:                 SECURE    # 放弃高风险末步，锁定已得步骤分
```

- `GUARD` 不是"停"：它可能包含"保持夹持 / 轻微退让 / 重新对准"，目的是降低 `ℓ` 并为下一次尝试提高 `p`。
- `SECURE` 也不是永远停：若人扰 hazard 很高，站着不动也会被撤回；此时"快速完成"可能反而优于"保守等待"。用简单的 hazard 模型评估：

```text
P(no human interference over H seconds) = exp(−λ_h · H)
```

  若 `λ_h` 高且当前 `p` 尚可，ADVANCE 可能优于 GUARD；这必须用 E306 在仿真里扫参数，不能凭直觉。

### 4.4 与 UIP-20 的关系

`ood=True` 且 `severity` 高时，`p` 的校准分布不再可信 → 采用**保守先验**（把 `p` 往下拉、把 `ℓ` 往上抬），并禁止"高风险末步"。这是把 OOD 分数变成**决策**，而不是只报警。

## 5. UIP-20 · MOSC（Mechanical OOD Score + Conformal Gate）

### 5.1 分数

```text
d_t = || z_mech,t − μ ||²_{Σ^{-1}} + λ · s_vis,t
z_mech = [ r_t 的统计量, 观测器隐状态, ĉontact, σ_t, 热漂移代理, 动作-观测不一致 ]
s_vis = 视觉异常分数（正常演示流形上的重构/密度残差）
```

- 机械项是主项：它捕捉"看起来正常、动力学不对"的偏移。
- 视觉项只做补充：未见物体/遮挡/位移。
- 用**正常演示**校准（one-class），不需要干扰标签——这正好匹配公开数据的条件。

### 5.2 保形阈值

在正常校准集上计算 `d_t`，取

```text
q̂ = 第 ⌈(n+1)(1−α)⌉ / n 分位数
flag = (d_t > q̂)
```

若正常窗口可交换，则正常流上的误报率 ≤ α（边际）。**注意**：时间序列相关会破坏可交换性；工程上用**块级/ episode 级校准**或加权保形，并在 E304 里报告实际误报率，而不是只引用理论界。

### 5.3 门控输出

- `flag=False`：正常，允许 ADVANCE，LMC 用正常增益。
- `flag=True, severity低`：降低 LMC lead、缩短"推进"块的有效速度、提高核验频率（在固定 `T_a` 内用保持步填充）。
- `flag=True, severity高`：进入 GUARD/SECURE，禁止高风险末步。

## 6. UIP-21 · OAT（Offline OOD-Aware horizon `T_a`）

`T_a` 只能在握手时选一次。因此把它当成一个**离线最优控制问题**：

```text
T_a* = argmax_{T_a ∈ {1,2,4,8,16}} [
    (1−β)·J_nominal(T_a) + β·J_worst(T_a)
    − λ_lat·Var(latency) − λ_call·(calls per episode)
]
```

- `J` 由仿真 + 真机锚点估计，必须包含**反向恢复**场景（不只是正常演示）。
- 小 `T_a`：反应快、恢复早，但调用多、延迟暴露大、可信度方差高。
- 大 `T_a`：调用少、流畅，但反向/接触的检测延迟下界就是 `T_a` 步。
- 这是 v2 UIP-13 的**合法替代**：不违反 `(T_a,…)` 契约，只在握手时做一次选择。

## 7. UIP-22 · MCS（Control-Space Invariance Selection）

若允许自选控制空间（`metadata.control_space`），做一次 A/B：

| 维度 | `joint` | `ee` |
|---|---|---|
| 可重复运动学误差 `r_kin` | 策略要自己学/补 | 由 IK/控制器吸收一部分 |
| 负载柔度 `r_comp` | 仍在 | 仍在（不会消失） |
| 反向失动 | 明确、可逐关节补 | 经雅可比映射，可能被 IK 放大/缩小 |
| 接口/控制器延迟 | 通常更低 | 可能多一层 IK |
| 观测反馈 | joint state 直接 | ee pose 可能是 FK 重算（非独立） |

**判据**：在 TR-DRO 的最差组上比较步骤分与延迟方差，选 Pareto 更优者；不要先验认定 ee 一定更好。若主办方用 `UNIBOT_CONTROL_SPACE` 固定，则遵循设置；但策略内部仍可**预测 ee 增量**再转 joint，以获得一部分不变性。

## 9. 实验设计 E301–E310

| 实验 | 问题 | 做法 | 成功判据（预注册） |
|---|---|---|---|
| **E301** | 公开数据里到底有没有可用的机械残差结构？ | 在 32 个 HF 数据集上算 `r_t = q_{t+1} − a_t`；按关节相位拟合 2–3 个谐波；检查反向时的平台/死区；用 ee pose 做 FK 一致性检查 | 周期项稳定解释 ≥10% 残差方差；反向处可检测到 ≥1 拍的平台；否则 UIP-16 降级 |
| **E302** | `human_*` 是评测时干预还是采集时变化？ | 抽查官方示例 episode 视频/`info.json`；统计人手出现与撤回事件 | 若只见采集变化，UIP-19 的 guard 分支降权；UIP-17 仍保留 |
| **E303** | LMC 是否真的救反向？ | 1-D/2-D 传动仿真 + 3–5 任务探针；扫 `b, K, v, T_a`；开/关 lead | 反向完成步数下降 ≥30%，最终误差下降 ≥30%，无过冲恶化 |
| **E304** | 机械残差能否检测接触/过载？ | 仿真接触标签 + 腕部图像弱标签；AUROC / 校准曲线 | AUROC ≥0.8（接触）、误报在保形阈值内 |
| **E305** | TR-DRO 是否提升最差组且不伤名义组？ | nominal / full-DR / TR-DRO 三组；按任务族与机械桶分组 | 最差组步骤分 +Δ；nominal 下降 ≤δ（预注册 δ=5%） |
| **E306** | OOD-SSO 是否优于 always-advance/always-secure？ | 扫 `p, ℓ, λ_h, T_a`；比较期望步骤分与成功率 | 在 `ℓ≥0.5` 区显著优于两个基线；在 `ℓ≈0` 区不劣于 always-advance |
| **E307** | joint vs ee 哪个更抗机械偏移？ | 同一策略/数据，切换控制空间；扫传动参数 | 至少一个机械桶上 ee 的步骤分/延迟方差 Pareto 更优 |
| **E308** | 端到端是否值得？ | MBC = 16+17+19+20+21 | 相对 v2 基线：撤回干扰下步骤分 +20~30%，正常任务不降 |
| **E309** | 开头加"标定抖动"是否划算？ | 低幅 dither 1–2 秒，测 `b̂` 可辨识性提升 vs 时间成本 | 仅在 `σ` 高且任务容差紧时启用；否则默认关闭 |
| **E310** | 真机锚点：机械误差到底多大？ | 预约真机 10–20 episodes；做已知的反向/按压/插入动作；测残差、滞回、TE | 若 `b_x, Δx_comp` 远小于任务容差 → 放弃 16/17，只保留 19/20 |

**Go/No-Go**：E301 不过 ⇒ 不投 UIP-16/17；E310 显示机械误差远小于容差 ⇒ 机械信念层是伪需求。这个"可以杀死自己方案"的设计，是本轮区别于"堆模块"的关键。

## 11. 本轮最大风险与押注

**→ 最值得押注：UIP-16 MBO-PV × UIP-17 LMC × UIP-19 OOD-SSO 组成的"机械信念闭环"**——它把"人扰撤回"与"传动非理想性"在**方向反转**这一共同攻击面上合并解决，且完全落在选手 API 权限内；UIP-18/20/21 分别负责造压力分布、设门、定块长。

**一句话最大风险：整套方案的可辨识性依赖"接口给出的 `state` 与上一条命令之差里还保留着传动残差"；如果该状态已被控制器滤波/补偿、或机械误差远小于任务容差，那么 MBO 会退化成噪声源，LMC 会把噪声放大成过冲——此时正确的做法是依据 E301/E310 及时放弃机械层，只保留 UIP-19/20 的通用安全门控。**
