# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「状态机」×「云端协同」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 实现了「认知驱动的场景-执行闭环」，把场景先验、意图锁定、证据链防丢失统一起来。但它的**闭环是「过程」，不是「状态」**，暴露出三个结构性局限：
> 1. **隐藏组合态**：场景置信度跌破阈值、意图锁未释放、EPIR 正在恢复、预算恰好耗尽——这些模式在 SERC 的 if/else 中可同时成立，却没有单一权威状态承认「我现在处于什么模式」。危险交错（如「锁定期内提交新契约」）无法被结构性排除，只能靠日志事后发现。
> 2. **安全属性不可验证**：第 60 轮「认知先行不超过执行安全」是一组自然语言护栏（置信度<0.7 回退、2s 超时），无法回答可达性问题——「是否存在一条从 NORMAL 直接跳到 DANGER 的执行路径？」没有显式迁移表与不变量，护栏本身就是待验证的代码。
> 3. **边云协同是单向的**：EPIR 只做「边→云」的证据同步与云端校验，云端掌握的跨机器人场景先验、意图映射规律**无法安全注入边端**——直接改写边端 K_safe 会与正在执行的契约冲突（云端指令中途抢占）；完全不注入，边端即「孤岛智能」。

## 0. 直觉与动机

**灵感 1（状态机 → 执行契约状态机 ECM）**
直觉：第 60 轮闭环其实有清晰的「生命阶段」——识别场景、锁定意图、提交契约、封存证据、同步云端——但它们是代码里的隐式阶段，不是一等状态。把闭环改写为**带守卫的有限自动机**：状态是安全/认知模式，迁移由事件驱动且被守卫约束，不变量是「禁止迁徙」的集合。关键洞见：**把「回退/降级」从散落的 if 分支升级为显式的吸收态 SAFE_HOLD**——于是「系统现在安不安全」变成一个可查询的状态，而不是一个待推断的故事。

**灵感 2（云端协同 → 边云分层状态机 CBSM）**
直觉：机器人同时活在两个节拍里——**边缘反应态**（毫秒、确定性、必须自治）与**云端深思态**（分钟、跨机器人、可离线）。二者不该共用一个状态机。用层级状态机（HSM）：边缘是叶子机，云端是监督机。关键洞见：**云端拥有的是「迁移规则」的权威，边端拥有「当前状态」的主权**——云端只能下发新的 δ_v/G_v（迁移表与守卫），不能直接写边端的当前状态。这样既注入云端知识，又保住实时安全。

**灵感 3（状态机 × 云端协同 → 版本化迁移规约 VTP + 安全同步点 QSP）**
直觉：如果云端下发的是「规则版本」，边云同步的单元就**不是易逝的「状态」，而是可版本化的「迁移规约」**。边端只在**静默态 Q_q**（无意图锁、无在途执行、证据已封存）提交新版本；执行中途到达的新策略只能 staged，不能 commit。关键洞见：**用「版本向量 + 静默点提交」替代「云端状态覆盖」，把边云冲突转化为可回滚的策略合并**。

**灵感 4（三灵感合流 → 安全熔断 SFNM + 近失学习）**
直觉：状态机的强项是「拒绝」——任何不在已提交迁移表中的事件都被安全熔断拒绝并进入 SAFE_HOLD。关键洞见：**被拒绝的迁移不是垃圾，而是最有价值的「近失事件」**——它精确指出「云端策略在哪个 (状态, 事件) 上存在缺口」，云端据此生成 δ_{v+1}。安全性由「默认拒绝」构造性保证，学习性由「近失聚合」闭环保证。

**灵感 5（迁移预算 TB → 验证本身也要降级）**
直觉：第 60 轮的 B_cog 只度量「识别/意图/消息/执行」，漏掉了**验证与同步的代价**。显式状态机让「验证」变成可度量操作：B_verify（不变量检查、可达性分析）与 B_sync（策略同步、陈旧度容忍）。关键洞见：**验证不是免费的**——当 B_verify 耗尽，系统应降级为「小而静态可验证」的 M_safe_small，而不是继续跑未经验证的大状态机；当 B_sync 耗尽导致策略陈旧度超过 τ_stale，边端进入自治并熔断到 SAFE_HOLD。

**灵感 6（合流 → 可验证边云协同状态机 VECSM）**
直觉：ECM 给边端安全，CBSM 给分层权限，VTP+QSP 给边云协调，SFNM 给构造性安全，TB 给优雅降级，最终得到**可被模型检查的边云闭环**：安全性可归纳证明，活性可公平性证明，收敛性可版本向量证明。上一轮「认知不超过安全」的口号，这一轮变成「所有可达态满足 I」的定理。

  - **(I4) 锁期单调保守**：意图锁定期间禁止任何「提高 F_max」或「降低 K_d」的迁移
  - **(I5) 非抵赖**：EVIDENCE_SEALED 前 S_shadow 必须已持久化该 pre-state 的 EV-exec

**定义 162（边云分层状态机 CBSM）** H = (M_edge, M_cloud, π, Auth)。其中：
- **叶机** M_edge = ECM（毫秒级、确定性、WCET 有界、单机自治）
- **监督机** M_cloud 的状态是**策略版本的抽象**：LEARNING → PROPOSED → COMMITTED → CONFLICTED
- **投影** π: Q_edge → Q_abstract，多对一：{IDLE}→IDLE，{SCENE_ACQ,…,SYNCED}→RUNNING，{SAFE_HOLD}→HOLD，{DEGRADED}→DEGRADED
- **权限分离** Auth：云端只能发布迁移规约 (δ_v, G_v)，**不得写 Q_edge**；边端拥有当前状态主权。形式化：云端的输出字母表 Σ_cloud = {stage(δ_v,G_v), request_rebase}，且 stage 只作用于 P_stage

**定义 163（版本化迁移规约 VTP）** P = (v, δ_v, G_v, VV, t_commit)。其中：
- **版本向量** VV = {(edge_id, c_e), (cloud_id, c_c)}，偏序支配关系 ≻ 用于比较边云进度
- **两阶段**：P_staged 与 P_commit；staged 不参与任何守卫求值
- **提交规则**：仅在安全同步点 Q_q 提交，且该方法 Verify_I(δ_v, G_v, Q_q)=⊤
- **回滚规则**：若 staging 期间边端熔断计数增加，则 P_staged 标记 CONFLICTED，请求云端 rebase
- **单调性**：版本号严格递增；禁止 downgrade（除非显式安全回滚并附 J_safe 证据）

**定义 164（安全同步点与迁移原子性 QSP）**
- **静默点集**：Q_q = {q ∈ Q | locked_intent=∅ ∧ in_flight_exec=∅ ∧ pending_sync=0 ∧ evidence_sealed(q)}
- **迁移原子性**：迁移 t 原子执行 iff ①守卫求值与状态写入在同一临界区；②云提交不得插入临界区；③pre-state 的 EV-exec 已非抵赖持久化
- **推论（互斥性）**：任何云→边策略提交与边端执行迁移在时间上互斥，故「云端中途抢占执行契约」不可能发生

**定义 165（安全熔断与近失事件 SFNM）**
- **熔断判定**：fuse(s,e)=⊤ iff (s,e,g) ∉ δ_commit 或 g(ctx)=⊥ 或 迁移后 I 将破
- **动作**：s → SAFE_HOLD，并发出近失事件 NF = (s, e, g_obs, v_commit, D⁺)
- **构造性安全**：边端只沿 δ_commit 迁移 ⇒ 「未被验证的迁移」在构造上不可能发生（默认拒绝 / fail-closed）
- **近失聚合**：云端以 NF 为负样本，提出 δ_{v+1}；NF 是「策略缺口」的高信息样本，而非噪声

**定义 166（迁移预算 TB 与验证降级）** TB = B_cog ⊕ (B_sync, B_verify)。其中：
- **B_sync** = (bandwidth, policy_staleness_max=τ_stale, reconcile_retries)
- **B_verify** = (invariant_check_ops, model_check_budget, state_cap)
- **驻留成本** c_res(q) = λ_t·τ_res(q) + λ_e·E(q)
- **迁移成本** c_tr(t) = λ_v·Verify(t) + λ_s·Sync(t)
- **降级**：若 B_verify 耗尽 ⇒ 切换 M_safe_small（小状态集、离线静态验证、默认拒绝更严）；若 B_sync 耗尽 ⇒ 边端自治，策略陈旧度 > τ_stale ⇒ SAFE_HOLD；若 B_cog 耗尽 ⇒ 沿用第 60 轮策略

**定义 167（边云状态协调算子 CECR）** reconcile(M_edge, P_cloud) → (M_edge′, commit | rollback)：
```
if VV_edge ≻ VV_cloud:  return push_divergence(safety_overrides)
if conflicts(P_commit, P_cloud):
    P_merged = safety_priority_merge(P_commit, P_cloud)   # 安全约束永远胜出
    P_commit.stage(P_merged); return staged
P_commit.stage(P_cloud); return staged
# 下一次进入 Q_q 时提交；提交失败则 rollback 并记 J_safe
```
- **保证**：安全永不作为一致性的交换代价——冲突时边端安全覆盖总是优先，云端策略降级为「条件策略」

**定义 168（VECSM 可验证性定理）** 设假设 A66–A69 成立：**(A66)** δ_commit 有限且守卫可判定；**(A67)** 每条迁移的临界区无副作用逃逸；**(A68)** 同步时延 ≤ Δ、分歧事件有限 K；**(A69)** 熔断默认拒绝。则：
1. **安全性**：若 ∀t∈δ_commit: I(s) ∧ G(t) ⇒ I(s′)，由迁移归纳，所有可达态满足 I；熔断态 SAFE_HOLD 亦满足 I（构造性）
2. **活性**：所有非终止态在公平调度下非吸收（无死锁/活锁）；SAFE_HOLD 经 reset 可达 IDLE
3. **收敛性**：在 Δ 与 K 有界下，π(M_edge) 与 M_cloud 的抽象态在 O(Δ+K) 轮内收敛（版本向量单调）
4. **降级安全性**：B_verify/B_sync 耗尽触发的 M_safe_small 仍是 I 的子自动机（更保守），故降级不破坏 I

## 2. 关键算法伪代码

### IP-161 ECM（执行契约状态机运行时）

```python
class ExecutionContractMachine:
    def __init__(self, policy, invariants):
        self.state = 'IDLE'
        self.policy = policy                 # committed VTP
        self.inv = invariants
        self.locked_intent = None
        self.in_flight = False
        self.pending_sync = 0
        self.fuse_count = 0

    def step(self, event, ctx):
        with self._critical():               # 守卫+写入同一临界区
            t = self.policy.lookup(self.state, event)
            if t is None:
                return self._fuse(event, ctx, 'no_committed_transition')
            if not t.guard(ctx):
                return self._fuse(event, ctx, 'guard_false')
            if not self.inv.holds_after(self.state, t, ctx):
                return self._fuse(event, ctx, 'invariant_violation')
            self._persist_pre_state(t, ctx)  # I5 非抵赖
            self.state = t.target
            self._apply(t.action, ctx)
            return self.state

    def _fuse(self, event, ctx, reason):
        self.fuse_count += 1
        self.policy.notify_local_fuse()
        self.state = 'SAFE_HOLD'
        return ('SAFE_HOLD', NearMiss(self.state, event, reason,
                                      self.policy.version, ctx.get('D_plus')))
```

```python
class CloudEdgeHierarchicalSM:
```

### IP-163 VTP（版本化迁移规约）

```python
class VersionedTransitionPolicy:
    def __init__(self, version, delta, guards, vv):
        self.version, self.delta, self.guards = version, delta, guards
        self.vv, self.staged, self.conflicted = vv, None, False

    def stage(self, p_new):
        if p_new.version <= self.version:
            return False
        self.staged = p_new
        return True

    def commit_at(self, q):
        if self.staged is None:
            return False
        if not verify_invariants(self.delta, self.staged, q):
            self._rollback()
            return False
        self.version = self.staged.version
        self.delta, self.guards = self.staged.delta, self.staged.guards
        self.staged = None
        return True

    def notify_local_fuse(self):
        if self.staged is not None:
            self.conflicted = True
```

### IP-164 QSP（安全同步点）

```python
def is_quiescent(edge):
    return (edge.locked_intent is None and not edge.in_flight
            and edge.pending_sync == 0 and edge.evidence_sealed)

def atomic_transition(edge, event, ctx):
    with edge.lock:                     # 云提交无法插入
        t = edge.policy.lookup(edge.state, event)
        if t is None or not t.guard(ctx):
            return edge._fuse(event, ctx, 'rejected')
        edge._persist_pre_state(t, ctx)
        edge.state = t.target
        return edge.state
```

### IP-165 SFNM（安全熔断与近失）

```python
class SafetyFuse:
    def __init__(self):
        self.near_misses = []

    def trip(self, state, event, reason, version, d_plus):
        self.near_misses.append(
            NearMiss(state, event, reason, version, d_plus))
        return 'SAFE_HOLD'

    def aggregate(self):
        # 按 (state, event) 分组，输出高频缺口，供云端生成 δ_{v+1}
        gaps = {}
        for nm in self.near_misses:
            gaps.setdefault((nm.state, nm.event), []).append(nm)
        return {k: (len(v), min(x.d_plus for x in v)) for k, v in gaps.items()}
```

### IP-166 TB（迁移预算）

```python
class TransitionBudget:
    def __init__(self, cog_budget, sync_bw=50, verify_ops=1000, stale_max=30.0):
        self.B_cog = cog_budget
        self.B_sync = {'bw': sync_bw, 'stale_max': stale_max, 'retries': 3}
        self.B_verify = {'ops': verify_ops, 'state_cap': 100000}
        self.used = {'sync': 0, 'verify': 0, 'stale': 0.0}

    def mode(self):
        if self.used['verify'] >= self.B_verify['ops']:
            return 'SAFE_SMALL'
        if self.used['stale'] > self.B_sync['stale_max']:
            return 'EDGE_AUTONOMY_HOLD'
        return 'NORMAL'
```

### IP-167 CECR（边云状态协调）

```python
def reconcile(edge, cloud):
    if vv_dominates(edge.policy.vv, cloud.policy.vv):
        return ('push_divergence', edge.safety_overrides)
    if conflicts(edge.policy, cloud.policy):
        merged = safety_priority_merge(edge.policy, cloud.policy)
        edge.policy.stage(merged)
        return ('staged_merged', merged)
    edge.policy.stage(cloud.policy)
    return ('staged', cloud.policy)
```

### IP-168 VECSM（可达性验证器）

```python
def verify_reachable(delta, inv, q0, state_cap=100000):
    seen, frontier = {q0}, [q0]
    while frontier:
        s = frontier.pop()
        for (e, g, a, s2) in delta.out(s):
            if not inv(s, (e, g, a), s2):
                return False, s2
            if s2 not in seen:
                seen.add(s2)
                frontier.append(s2)
                if len(seen) > state_cap:
                    return 'UNVERIFIABLE', None
    return True, seen
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ECM | O(1) 迁移（哈希查表） | O(|Q|+|δ|) | 不变量零违反；熔断 fail-closed |
| CBSM | O(1) 投影 | O(1) | 云端不得直写边端状态 |
| VTP | O(|δ_v|) 提交验证 | O(|δ_v|) | 版本单调；仅静默点提交 |
| QSP | O(1) 静默判定 | O(1) | 提交-执行时间互斥 |
| SFNM | O(1) 触发 / O(NF) 聚合 | O(NF) | 拒绝迁移不破 I |
| TB | O(1) | O(1) | 任一预算耗尽触发保守子自动机 |
| VECSM | O(|Q|·|Σ|) 可达图 | O(|Q|) | 可达性有界模型检查 |

**正确性定理（VECSM）**：设 A66–A69 成立，则：
1. **安全性**：所有可达态满足 I（迁移归纳 + 熔断构造性）；
2. **活性**：非终止态非吸收，SAFE_HOLD 可经 reset 回到 IDLE；
3. **边云收敛**：O(Δ+K) 轮内抽象态收敛；
4. **降级保安全**：M_safe_small ⊆ M_exec 的保守子自动机。

## 4. 实验设计 E192–E196

| 实验 | 指标 | 目标 |
|---|---|---|

### IP-161 ECM 运行时（守卫求值 + 原子写入 + 熔断）

```python
class ExecutionContractMachine:
    def __init__(self, policy, invariants):
        self.state = 'IDLE'
        self.policy = policy
        self.inv = invariants
        self.locked_intent = None
        self.in_flight = False
        self.pending_sync = 0
        self.fuse_count = 0

    def step(self, event, ctx):
        with self._critical():
            t = self.policy.lookup(self.state, event)
            if t is None:
                return self._fuse(event, ctx, 'no_committed_transition')
            if not t.guard(ctx):
                return self._fuse(event, ctx, 'guard_false')
            if not self.inv.holds_after(self.state, t, ctx):
                return self._fuse(event, ctx, 'invariant_violation')
            self._persist_pre_state(t, ctx)
            self.state = t.target
            self._apply(t.action, ctx)
            return self.state

    def _fuse(self, event, ctx, reason):
        self.fuse_count += 1
        self.policy.notify_local_fuse()
        self.state = 'SAFE_HOLD'
        return ('SAFE_HOLD', NearMiss(self.state, event, reason,
                                      self.policy.version, ctx.get('D_plus')))
```

### IP-162/163/164 边云分层 + 版本化 + 静默点

```python
class CloudEdge:
    def __init__(self, edge, cloud):
        self.edge, self.cloud = edge, cloud

    def project(self, q_edge):
        return {'IDLE':'IDLE', 'SAFE_HOLD':'HOLD', 'DEGRADED':'DEGRADED'}.get(
            q_edge, 'RUNNING')

    def on_cloud_policy(self, p_new):
        return self.edge.policy.stage(p_new)      # 只 stage，绝不写 state

    def tick(self):
        if self.edge.policy.has_staged() and is_quiescent(self.edge):
            return self.edge.policy.commit_at(self.edge.state)
        return False

def is_quiescent(edge):
    return (edge.locked_intent is None and not edge.in_flight
            and edge.pending_sync == 0 and edge.evidence_sealed)

class VersionedTransitionPolicy:
    def __init__(self, version, delta, guards, vv):
        self.version, self.delta, self.guards = version, delta, guards
        self.vv, self.staged, self.conflicted = vv, None, False

    def stage(self, p_new):
        if p_new.version <= self.version:
            return False
        self.staged = p_new
        return True

    def commit_at(self, q):
        if self.staged is None:
            return False
        if not verify_invariants(self.delta, self.staged, q):
            self._rollback()
            return False
        self.version = self.staged.version
        self.delta, self.guards = self.staged.delta, self.staged.guards
        self.staged = None
        return True

    def notify_local_fuse(self):
        if self.staged is not None:
            self.conflicted = True
```

```python
class SafetyFuse:
    def __init__(self):
        self.near_misses = []

    def trip(self, state, event, reason, version, d_plus):
        self.near_misses.append(
            NearMiss(state, event, reason, version, d_plus))
        return 'SAFE_HOLD'

    def aggregate(self):
        gaps = {}
        for nm in self.near_misses:
            gaps.setdefault((nm.state, nm.event), []).append(nm)
        return {k: (len(v), min(x.d_plus for x in v)) for k, v in gaps.items()}
```

```python
def reconcile(edge, cloud):
    if vv_dominates(edge.policy.vv, cloud.policy.vv):
        return ('push_divergence', edge.safety_overrides)
    if conflicts(edge.policy, cloud.policy):
        merged = safety_priority_merge(edge.policy, cloud.policy)
        edge.policy.stage(merged)
        return ('staged_merged', merged)
    edge.policy.stage(cloud.policy)
    return ('staged', cloud.policy)

def verify_reachable(delta, inv, q0, state_cap=100000):
    seen, frontier = {q0}, [q0]
    while frontier:
        s = frontier.pop()
        for (e, g, a, s2) in delta.out(s):
            if not inv(s, (e, g, a), s2):
                return False, s2
            if s2 not in seen:
                seen.add(s2); frontier.append(s2)
                if len(seen) > state_cap:
                    return 'UNVERIFIABLE', None
    return True, seen
```
