## 1. 两个灵感的第一性原理

### 灵感 1 ·「创新点提炼」→ 不是删想法，而是把「清单」压成「可证伪的宣称脊柱」

**直觉**：过去三轮像在攒乐高零件——15 个 IP 每个单看都合理，但没有一块被证明是承重的。真正的提炼不是砍数量，而是找出「拆掉它、头条能力就塌」的那几块，并给每块配一个能证伪它的实验。清单的长度是负债，宣称的可证伪性才是资产。

**严谨定义**：把方案抽象为**可验证执行合约 VEC（Verifiable Execution Contract）**——一个包在任意基座策略 `π_B` 外面的包装器 `W = (A, R, Ω)`：`A` 是路标断言集（观测+状态 → {通过, 失败, 不确定}，带可控误差），`R` 是有界恢复家族（重抓 / 重定位 / 换原语 / 换策略），`Ω` 是**在线自审计算子**（维护断言与恢复的校准不变量）。比赛得分只认成功率 `S = P(success)`，于是「创新」的严格定义是：`VEC` 相对基座的边际成功率 `ΔS`，且必须可被消融证伪。

**提炼规则**：对每个 IP `i` 计算边际宣称价值 `v_i = S(Π) − S(Π \ {i})`；只有当 `v_i` 超过评测噪声（`> z·SE`）且与其它项不冗余时，才允许进入 headline。按此规则，15 个 IP 被压成**三条宣称 + 一层基础设施 + 一组期权**：

- **H1 可判定承诺**（IP-09 + IP-13/U17）：每个路标都有可校准的断言，误拒率是可设计参数而非拍脑袋阈值 → 使恢复成为可能；
- **H2 有界违约恢复**（IP-02 + IP-13 重定位 + IP-15 + IP-14 滑移）：断言失败后按步数预算做有界介入并续跑 → 直接改变成功率；
- **H3 自审计校准**（IP-16，新）：在线维护一致性与覆盖率 → 让 H1/H2 在分布漂移下仍然成立。

**为什么现在必须提炼**：公开数据给出两个决定性数字——**模型极差 9.2 分，而任务级 oracle 比最佳单模型高 4.26 分（去偏后约 3–4 分）**。这说明继续卷基座（IP-01 原形态、IP-10 世界模型、IP-12 课程）的边际收益，小于「让同一基座在失败处可恢复、在任务间可路由」的收益。提炼的结论不是「不要基座」，而是「基座是商品，合约是护城河」。

> 关键推论：既然步骤分与成功率共线（F3），第 2–3 轮以「步骤分」为目标的记账体系（L12/L13/P12）必须**从目标降级为约束**——步数只在「超时/超预算导致失败」时影响得分，不再有独立的效率收益。这是本轮最重要的修剪。

### 灵感 2 ·「在线学习」→ 评测期只维护不变量，不学习新技能

**直觉**：在别人的机器上、隐藏任务、单 checkpoint、一个 API——任何「评测期在线学新技能」都是在悬崖边跳舞：会过拟合单个 episode、会触碰规则、会让结果不可复现。但有一类在线学习既安全又必需：让系统的**自检**（协方差、门限、增益）随分布漂移自动校准。它不是「变强」，而是「不变坏」。

**严谨分类**（按风险与合规从低到高）：
1. **估计器自适应**（噪声协方差 / 滤波一致性）——无标签可用，episode 内，合规风险最低；
2. **控制器自适应**（伺服增益、滑移响应阈值）——有界、可逆，需结果信号；
3. **门限覆盖率自适应**（ACI / 序贯 conformal）——需延迟结果标签，但给出分布无关的覆盖率保证；
4. **跨 episode 会话记忆**（IP-11）——触碰「评测期是否允许持久状态」的合规红线（Q9）；
5. **权重级在线学习 / TTT**——高风险、易灾难遗忘、最可能违规，本轮**明确排除**于评测期。

**本轮选择 1–3，明确拒绝 4–5**。核心机制是**同一断言的两条自审计回路**：
- **无标签回路**：用新息序列的归一化新息平方（NIS/ANEES）做协方差匹配，使滤波器保持一致 → 卡方门限的误拒率先验重新成立（L17）；
- **延迟标签回路**：每个路标的成败是一个延迟二元标签，用自适应 conformal inference（ACI）更新接受阈值，长期误覆盖率收敛到设计值 α，即使 Σ 失配、分布漂移（L16）。

**为什么这是正确的在线学习**：它只改「 nuisance 参数」（噪声、阈值、增益），不改策略权重；它 episode 内重置、可回滚，因而绕开 Q9；它保护的是 H1/H2 的**保证**，而不是在评测期偷学新技能。这条原则记为 P14「在线学习只修不增」。

**在线学习也必须记账**：任何更新都要先积累足够证据（L18 的统计功效门槛：`n ≥ ((z_{1−α}+z_{1−β})σ/Δ)²`），否则早期噪声会引发负迁移。这把「在线学习」接回了第 2 轮的步数经济学——但这次是**约束**，不是目标。

## 2. 研究问题（新增 Q13–Q16，接第 1–3 轮 Q1–Q12）

- **Q13（在线适配的合规边界）**：episode 内 nuisance 参数自适应、跨 episode 持久状态、权重更新三者的规则边界在哪里？哪些会被判为「评测期训练」？（合规前置，决定 IP-16 能否上真机）
- **Q14（无标签一致性是否够用）**：仅用 NIS/ANEES 的协方差匹配，能否把卡方断言的误拒率校准到 `[α/2, 2α]`？在多大分布漂移下失效？（E636）
- **Q15（延迟标签下的覆盖率）**：路标级成败作为延迟标签时，ACI 门限能否把长期误覆盖率锁在 α？标签延迟一个路标是否破坏保证？（E637）
- **Q16（任务条件路由的真实头寸）**：公开数据的每任务 oracle 头寸 +4.26 有多少是选择偏差？去偏后，在线任务识别 + 专家路由能否在隐藏任务上兑现 ≥+2 分？（E638）

## 3. 设计原则（新增 P13–P16，接第 1–3 轮 P1–P12）

- **P13（最小可证宣称）**：一个创新点只有在其消融的边际收益超过评测噪声时，才进入 headline；否则降级为工程注记或期权。**没有消融，就没有宣称。**
- **P14（在线学习只修不增）**：评测期只允许维护既有不变量（一致性 / 覆盖率 / 增益），禁止获取新技能或更新策略权重；跨 episode 持久状态须先过合规（Q9/Q13）。
- **P15（有界可逆）**：任何在线更新必须满足 U22 四条约束（步长有界、无权重更新、episode 内重置、可回滚），并配单调性守卫与回滚触发器。
- **P16（记分面前置审计）**：优化一个指标前，先验证它是否携带独立信号；若两个指标共线（如本轮 step 与 success，r=0.998），则只保留一个目标，另一个降为约束。

## 4. 清单处置（提炼 / 降级 / 新增）

- **升为 headline（宣称脊柱）**：H1 = IP-09 + IP-13/U17；H2 = IP-02 + IP-15 + IP-14（滑移作为 H2 的一个特例断言）；H3 = **IP-16 OnlineGate（新）**。

- **降为期权（证据门控）**：IP-10（世界模型）、IP-11（会话记忆）、IP-12（课程）、IP-04（上下文调制）、IP-05（可达性）——保留，但不进入 headline，除非 E635 消融证明其边际收益。
- **重新定位**：IP-01 从「技能 MoE」重定位为「**任务条件路由**」——公开数据显示无单一模型赢过 8/32 任务，且 specialist 榜为空；这是一个可量化的记分面下注（E638），但叙事上仍属「基座工程」而非核心创新。

## 5. 本轮最大风险

**公开 JSON 可能是「生成脚本的占位数据」而非真实评测**：步骤分与成功率呈精确线性（1.3415×），这既可能是评分口径，也可能是 `gen_leaderboard.py` 的退化映射；若后者成立，则 +4.26 路由头寸、逐任务排序、乃至「任务级差异远大于模型级差异」的整条提炼依据都可能是沙上建塔。对冲：①把本轮所有数字预注册为「待运行层复核的工作假设」；②用自有 IP-06 代理评测独立复现排序（E634b）；③任何依赖该数据的决策只做「可逆下注」，不写死架构。次要风险：在线自适应形成反馈环与负迁移；ACI 依赖的延迟标签可能拿不到（退化为仅 NIS）。**一句话：当前方案最大的风险，是把一份可能退化的公开榜单当成真实世界，从而提炼出一个精致的错误。**

## 0. 本轮结论摘要

**一句话路线**：把三轮累积的 15 个 IP 提炼成一份**可验证执行合约 VEC（Verifiable Execution Contract）**——基座策略是商品，护城河是包在外面的「可判定承诺（H1）→ 有界恢复（H2）→ 自审计校准（H3）」三条款；在线学习只承担 H3（维护不变量），不承担「评测期学新技能」。

### 1.2 记分面退化（E634 核心结论）

对全部 256 个 (model, task) 单元：

```
step_score = 0.09 + 1.337 × success_rate      （全局拟合）
step_score / success_rate = 1.3415 ± 0.0225   （逐任务比值分布几乎相同）
corr(success, step) = 0.9977 ; corr(success, duration) = 0.0031
```

## 4. 新增 IP-16 · OnlineGate 自审计在线校准（P0，新）

- **动机**：第 3 轮把断言升级为卡方门限（U17），但 L11 的前提是「Σ 已校准」。真机上协方差几乎必然失配；一旦失配，误拒率失控，只能退回固定阈值——H1 的整个新颖性就没了。在线学习在这里不是锦上添花，而是**保护 H1 保证的唯一手段**。

- **技术可行性**：高。NIS 协方差匹配是经典自适应滤波（Mehra 型）；ACI 是现成的序贯 conformal 更新，一维阈值、O(1) 更新；均无需训练。
- **资源**：算力≈0（标量更新）；数据=路标结果标签（系统内部可记录，不需要额外标注）；接口=无新增字段（全部策略内部）。
- **落地步骤**：①在 IP-13 状态层导出新息 `e_t` 与预测协方差 `S_t`；②实现 ANEES 监控与 `(Q,R)` 协方差匹配；③实现一维 ACI 阈值更新与覆盖率监控；④加证据门槛（L18）与单调性守卫；⑤加回滚与 Level-1.7 退化；⑥E636/E637/E639。

## 5. 符号与定义（新增 U19–U23；U1–U18 沿用第 1–3 轮）

- **定义 U19（可验证执行合约 VEC）**：`VEC = (π_B, A, R, Ω)`。`π_B` 为基座策略；`A` 为路标断言集 `a_i: (obs, x̂, Σ) → {pass, fail, uncertain}`；`R` 为有界恢复家族；`Ω` 为在线自审计算子。合约的得分 `S = P(success)`，创新价值以边际成功率 `ΔS` 度量。
- **定义 U20（创新点台账 / Claim Card）**：每条创新记为 `c_i = (claim, mechanism, novelty_class, falsifier, Δ_i, copy_time_i, deps_i, status_i)`，其中 `novelty_class ∈ {capability, mechanism, combination, engineering}`，`status ∈ {hypothesis, proxy-validated, real-validated}`。
- **定义 U21（边际宣称价值）**：`v_i = S(Π) − S(Π \ {i})`；`c_i` **可宣称** ⇔ `v_i > z_{1−β} · SE(v_i)` 且对所有 `j` 有 `v_i|j > 0`（非冗余）。提炼算子 `Distill(Π) = {c_i : 可宣称}`。
- **定义 U22（维护型在线自适应算子）**：`A_t: θ_t → θ_{t+1}`，`θ` 为 nuisance 参数（噪声、阈值、增益），满足四条约束：(i) `‖θ_{t+1}−θ_t‖∞ ≤ ε`；(ii) 不更新 `π_B` 权重；(iii) episode 边界重置；(iv) 存在回滚 `θ_t → θ_0`。不满足任一条的更新不属于评测期在线学习。
- **定义 U23（任务条件混合）**：`π_mix(o) = π_{r(o)}`，`r` 为任务/技能路由；其成功率上界为逐任务 oracle `E_t[max_k p_{k,t}]`，下界为最佳单模型 `max_k E_t[p_{k,t}]`。

## 6. 推导（新增 L14–L18；L1–L13 沿用第 1–3 轮）

**引理 L14（记分面退化）** 若 `step = c · success`（`c` 为常数），则对任意两个策略 A、B，`step(A) > step(B) ⇔ success(A) > success(B)`，两者排序完全相同；任何只改变 step 不改变 success 的操作，边际得分为 0。本轮公开数据 `c = 1.3415`（256 单元 sd=0.0225，逐任务同分布）。⇒ 公开记分面等价于单目标成功率；步骤分只能作为失败约束（超预算即失败），不能作为优化目标。∎

**引理 L15（路由头寸与选择偏差）** 设任务 `t` 上模型 `k` 的真实成功率为 `p_{k,t}`。路由上界 `S_oracle = (1/T) Σ_t max_k p_{k,t}` 与最佳单模型 `S_best = max_k (1/T) Σ_t p_{k,t}` 满足 `S_oracle ≥ S_best`（逐点 max ≥ 均值 max）。但由有限样本估计 `p̂_{k,t}` 计算 `max_k p̂_{k,t}` 时，`E[max_k p̂] ≥ max_k E[p̂]`（Jensen），偏差随每单元样本量 N 与模型数 K 增大而增大；K=8 时偏差约 `E[max Z]·SE ≈ 1.4·sqrt(p(1−p)/N)`。本轮公开数据原始 gap=4.26；模拟显示 N=200 时表观 gap≈5.27（放大 ~1.0），N=800 时≈4.46，去偏后约 3.3–4.1。⇒ **路由下注必须在隐藏任务/留出样本上去偏后仍 ≥+2 分才成立；否则视为选择偏差。** ∎

**引理 L16（ACI 的长期覆盖率）** 设非一致性分数 `s_t ∈ [0,1]` 有界，误覆盖率目标 α，更新 `α_{t+1} = α_t + γ(α − err_t)`，门限取最近分数窗口的 `⌈(1−α_t)(n+1)⌉` 分位数。则（Gibbs & Candès 型结果）`|(1/T)Σ_t err_t − α| ≤ (max_t|α_t−α| + 1/(γT))·O(1)`，即长期误覆盖率收敛到 α，且**不要求分数分布平稳或模型正确**。⇒ 即使 Σ 失配、分布漂移，只要路标成败能作为延迟二元标签，H1 的误拒率可被在线锁在 α。∎

**引理 L17（无标签一致性）** 线性高斯滤波中，新息 `e_t = z_t − H x̂_{t|t−1}`，真实协方差 `S_t = H P_{t|t−1} Hᵀ + R`；若滤波一致，则 `E[e_tᵀ S_t⁻¹ e_t] = m`（m 为观测维数，ANEES=m）。用滑动窗 ANEES 与 m 的偏差做协方差匹配（调 `Q,R`）可使 `E[ANEES] → m`，从而恢复卡方门限的误拒率先验。⇒ **无需真值标签即可维护一致性**；代价是假设局部线性高斯，强非线性/大漂移下退化为分位数校准。∎

**引理 L18（在线自适应的证据门槛）** 要在噪声标准差 σ、显著性 α、功效 1−β 下检出改善 Δ，所需样本数 `n ≥ ((z_{1−α}+z_{1−β})σ/Δ)²`。⇒ 在线更新必须等 `n ≥ n_min` 才允许生效；否则噪声驱动的更新会造成负迁移。该门槛把「自适应」与「步数预算」显式连接（P12 的新形态：约束而非目标）。∎

## 7. 关键算法骨架（新增片段；主体沿第 1–3 轮）

```python
# ===== IP-16a: 无标签一致性维护（NIS/ANEES 协方差匹配）=====
class ConsistencyMonitor:
    def __init__(self, m, window=50, eps=0.05):
        self.m, self.win, self.eps = m, window, eps
        self.nis = deque(maxlen=window)

    def observe(self, e, S):
        self.nis.append(float(e.T @ inv(S) @ e))

    def anees(self):
        return sum(self.nis) / len(self.nis) if self.nis else self.m

    def adapt(self, Q, R):
        r = self.anees() / self.m            # >1 低估噪声；<1 高估
        if len(self.nis) < self.win:          # L18: 证据不足不更新
            return Q, R
        scale = clip(r, 1 - self.eps, 1 + self.eps)   # U22(i) 步长有界
        return Q * scale, R * scale           # 回滚 = 恢复初始 Q,R
```

```python
# ===== IP-16b: 延迟标签下的 ACI 断言门限 =====
class ACIGate:
    def __init__(self, alpha=0.05, gamma=0.01, n=200):
        self.alpha, self.gamma = alpha, gamma
        self.scores = deque(maxlen=n)         # 历史非一致性分数（Mahalanobis）
        self.a_t = alpha

    def threshold(self):
        if not self.scores:
            return chi2_ppf(1, 1 - self.alpha)
        q = quantile(self.scores, 1 - self.a_t)   # 分位数门限
        return q

    def update(self, score, accepted_and_correct):
        self.scores.append(score)
        err = 0.0 if accepted_and_correct else 1.0
        self.a_t = clip(self.a_t + self.gamma * (self.alpha - err), 0.001, 0.5)
        # 长期误覆盖率 -> alpha（L16）；episode 结束重置 a_t=alpha（U22(iii)）
```

```python
# ===== VEC 主循环：断言 → 恢复 → 自审计 =====
def vec_step(obs, state, gate, mon, phase):
    state.update(obs)                                  # IP-13 低频
    x, S, e = state.estimate_with_innovation(obs)
    mon.observe(e, S)
    Q, R = mon.adapt(state.Q, state.R)                 # H3 无标签回路
    state.set_noise(Q, R)

    verdict = gate.assert_(x, S)                       # H1
    if verdict is PASS:
        action = servo(state, phase)
    else:
        action = recover(verdict, state, phase)        # H2（有界）
    return action
```
