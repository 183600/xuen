### 第 4 轮灵感驱动研究记录

**灵感词**：力矩控制、谐波减速器

**直觉与动机**：
前几轮把证书链从「规划/定位/视觉伺服」一路铺到了速度级指令，但链条在物理边界处是断开的：我们从未证明「下发的力矩真的被关节交付了」。谐波减速器正是这条链的最后一环，也是最先退化的一环——它以高减速比换取力矩密度，同时引入空回（lost motion）、扭转柔度、迟滞、摩擦与磨损。于是出现一个隐蔽的语义缺口：上层证书全部通过，而力矩指令在减速器内部被非线性地改写。

直觉上，谐波减速器不是理想齿轮，而是一份「会疲劳、会打滑、会发热的非线性传动契约」。力矩控制本质上是在信任这份契约：它假设 τ_joint ≈ N·τ_motor·η。一旦润滑老化、齿面磨损、温升改变摩擦，契约悄悄违约，而证书仍在说「有效」——这与前几轮反复出现的「虚假安全感」同构，只是下沉到了执行器的物理层。

据此提出三条互补路线：

1. **传动保真证书（Transmission Fidelity Certificate, TFC）**：用双编码器（电机侧 + 关节侧）与力矩传感，在线辨识「指令力矩 → 交付力矩」的映射误差 ε_τ，并把 ε_τ、谐振裕度、磨损指数打包为可准入的证书。力矩指令只有在 TFC 通过时才允许进入执行集。

2. **谐振感知力矩环（Resonance-Aware Torque Loop）**：谐波减速器的扭转刚度与转子惯量构成一个低频扭转谐振 ω_r，它把力矩环带宽硬性截断。证书需显式携带谐振裕度 M_r；控制侧用自适应陷波 + 扰动观测器（DOB）在谐振之下工作，而不是盲目提高增益。

3. **磨损自适应摩擦/迟滞补偿（Wear-Adaptive Friction-Hysteresis Compensation）**：空回与迟滞环随磨损单调扩大。用 Dahl/LuGre 类模型在线估计 f̂、b̂，并定义磨损指数 w∈[0,1]；当 w 增长时，证书阈值收紧、力矩环自动降级为阻抗/位置控制（对传动非线性更鲁棒）。

**关键洞见**：证书链必须在物理边界处「闭合」——一个力矩指令的可信度，不可能高于为其交付背书的传动证书。把传动层纳入证书体系，等于把「开环的语义缺口」变成「被监控、可门控的契约」。这与前几轮的「证书驱动」一脉相承，但首次把抽象指令锚定到真实的力矩/热/磨损物理量，可称为「证书的物理接地（physical grounding of certificates）」。

**形式化目标（增量）**：
1. 定义谐波传动证书 HTC = (b̂, k̂_θ, f̂, ŵ, ω̂_r, ω̂_a, M_r)，分别表示空回半宽、扭转刚度、摩擦、磨损指数、谐振频率、反谐振频率、谐振裕度。
2. 定义力矩保真证书 TFC = (ε_τ, τ_bw, valid)，其中 ε_τ = ‖τ_cmd − τ_actual‖_∞，τ_bw 为可用力矩带宽。
3. 定义 KC 规则：kc_torque_valid = (ε_τ < ε_max) ∧ (M_r > M_min) ∧ (ŵ < w_max) ∧ (τ_bw > τ_bw_min)；不通过则力矩路径降级为阻抗/位置控制。
4. 给出力矩误差界：在传动参数不确定度 Δ 与 DOB 带宽 ω_dob 下，ε_τ ≤ (Δ_max + δ_f + k_θ b/2)/(1 + ω_dob/ω_c) + N|η−η̂||τ_m|，并证明当 ω_c < ω_a 时闭环稳定。
5. 定义磨损自适应更新：ŵ(k+1) = clip(ŵ(k) + α·Δb + β·Δf, 0, 1)，准入阈值随 ŵ 单调收紧。
6. 扩展框架：KT-MPC ∪ CADVS ∪ HTC ∪ TFC，使 Exec_CADVS+ ⊆ Exec_CADVS（更严格包含），并在 ≥80% 关节上把力矩跟踪误差压到无补偿基线的 50% 以下。

**本轮最大风险**：**证书的自我指涉性（self-referential fidelity）**——TFC 的判据本身依赖传动模型（如用电机电流乘力矩常数估计 τ_actual，或假设标称刚度），而模型误差恰好在减速器退化时增长。于是证书可能「用错误的模型证明自己正确」：所有标量指标仍在阈值内，真实力矩波形却已失真；更糟的是，在线补偿一旦激励未建模的高频模态，会从「不安全但稳定」滑向「不稳定」。这种风险比单纯传感器失效更隐蔽，因为它穿着「量化、可审计」的外衣。

### IP-478 Harmonic Transmission Certificate Kernel (HTCK)

```python
from dataclasses import dataclass
from collections import deque
import numpy as np

@dataclass
class HarmonicTransmissionCertificateKernel:
    """HTCK：双编码器 + 力矩传感在线辨识谐波传动非线性，签发 HTC。

    物理模型（关节侧）：
        e_t = theta_m / N - theta_j = tau_j / k_theta + delta_hys
        |delta_hys| <= b/2,  b 为失动量全宽
        tau_m = J_m * theta_ddot_m + tau_f + tau_j / (N * eta_f)
    """
    N: float = 100.0
    fs: float = 1000.0
    rls_lambda: float = 0.995
    wear_forget: float = 0.999
    b_ref: float = 3.0e-4      # 出厂失动量参考（rad，关节侧）
    f_ref: float = 2.0         # 出厂摩擦参考（N·m）

    def __post_init__(self):
        self.theta_rls = np.array([1.0 / 1.0e4, 0.0, 0.0])  # [1/k, dhys_dc, bias]
        self.P = np.eye(3) * 1e3
        self.b_hat = self.b_ref
        self.f_hat = self.f_ref
        self.k_theta_hat = 1.0e4
        self.omega_a_hat = 2 * np.pi * 80.0
        self.omega_r_hat = 2 * np.pi * 120.0
        self.w_hat = 0.0
        self.buf = deque(maxlen=int(self.fs * 4))

    def on_sample(self, theta_m, theta_j, tau_j, tau_m, t):
        e_t = theta_m / self.N - theta_j
        self.buf.append((t, theta_m, theta_j, e_t, tau_j, tau_m))
        self._update_stiffness_rls(e_t, tau_j)
        if len(self.buf) >= 64:
            self.b_hat = self._estimate_lost_motion()
            self.f_hat = self._estimate_friction()
            self.omega_r_hat, self.omega_a_hat = self._track_resonance()
            self._update_wear()

    def _update_stiffness_rls(self, e_t, tau_j):
        # e_t = (1/k_theta) * tau_j + dhys_dc * sign(tau_j) + bias
        phi = np.array([tau_j, np.sign(tau_j), 1.0])
        K = self.P @ phi / (self.rls_lambda + phi @ self.P @ phi)
        self.theta_rls += K * (e_t - phi @ self.theta_rls)
        self.P = (self.P - np.outer(K, phi) @ self.P) / self.rls_lambda
        self.k_theta_hat = 1.0 / max(self.theta_rls[0], 1e-9)

    def _estimate_lost_motion(self):
        arr = np.asarray(self.buf)
        tau, e = arr[:, 4], arr[:, 3]
        mask = np.abs(tau) < np.percentile(np.abs(tau), 20) + 1e-6
        if mask.sum() < 8:
            return self.b_hat
        # 近零力矩换向区的滞回半宽：2 * 中位绝对偏差（稳健估计）
        return float(2.0 * np.median(np.abs(e[mask] - np.median(e[mask]))))

    def _estimate_friction(self):
        arr = np.asarray(self.buf)
        tau_m, tau_j, theta_j = arr[:, 5], arr[:, 4], arr[:, 2]
        dtheta = np.gradient(theta_j, arr[:, 0])
        mask = np.abs(dtheta) < np.percentile(np.abs(dtheta), 15) + 1e-9
        if mask.sum() < 8:
            return self.f_hat
        resid = tau_m[mask] - tau_j[mask] / (self.N * 0.8)
        return float(np.median(np.abs(resid)))

    def _track_resonance(self):
        arr = np.asarray(self.buf)
        if len(arr) < 256:
            return self.omega_r_hat, self.omega_a_hat
        tau_m = arr[:, 5] - arr[:, 5].mean()
        theta_m = arr[:, 1] - arr[:, 1].mean()
        n = 1 << int(np.ceil(np.log2(len(tau_m))))
        H = np.fft.rfft(theta_m, n) / (np.fft.rfft(tau_m, n) + 1e-9)
        f = np.fft.rfftfreq(n, 1.0 / self.fs)
        band = (f > 20) & (f < self.fs / 2)
        if not band.any():
            return self.omega_r_hat, self.omega_a_hat
        idx = np.argmax(np.abs(H[band]))
        omega_r = 2 * np.pi * f[band][idx]
        return omega_r, omega_r / np.sqrt(2.0)

    def _update_wear(self):
        growth = 0.5 * (self.b_hat / self.b_ref) + 0.5 * (self.f_hat / self.f_ref)
        self.w_hat = float(np.clip(
            self.wear_forget * self.w_hat + (1 - self.wear_forget) * growth,
            0.0, 1.0))

    def certificate(self, omega_c: float) -> HTC:
        M_r = (self.omega_a_hat - omega_c) / max(self.omega_a_hat, 1e-9)
        return HTC(b_hat=self.b_hat, k_theta=self.k_theta_hat,
                   f_hat=self.f_hat, w_hat=self.w_hat,
                   omega_r=self.omega_r_hat, omega_a=self.omega_a_hat,
                   M_r=float(M_r))
```

### IP-479 Torque Fidelity Certificate (TFC)

```python
@dataclass
class TorqueFidelityCertificate:
    """TFC：量化「指令力矩 → 交付力矩」误差，签发 KC 规则 kc_torque_valid。"""
    eps_max: float = 0.15          # N·m 峰值误差阈值
    M_min: float = 0.30            # 谐振裕度下限
    w_max: float = 0.70            # 磨损指数上限
    tau_bw_min: float = 40.0       # 最低力矩带宽 Hz
    hist_len: int = 100

    def __post_init__(self):
        self.cmd_hist = deque(maxlen=self.hist_len)
        self.act_hist = deque(maxlen=self.hist_len)

    def on_torque(self, tau_cmd: float, tau_act: float):
        self.cmd_hist.append(tau_cmd)
        self.act_hist.append(tau_act)

    def evaluate(self, htc: HTC) -> TFC:
        if not self.cmd_hist:
            return TFC(eps=float('inf'), tau_bw=0.0, valid=False)
        eps = float(np.max(np.abs(np.subtract(self.cmd_hist, self.act_hist))))
        # 可用带宽：反谐振以下的可用比例，受谐振裕度约束
        tau_bw = htc.omega_a / (2 * np.pi) * max(1.0 - htc.M_r, 0.0)
        valid = (eps < self.eps_max and htc.M_r > self.M_min
                 and htc.w_hat < self.w_max and tau_bw > self.tau_bw_min)
        return TFC(eps=eps, tau_bw=tau_bw, valid=valid)

    def cert_payload(self, tfc: TFC, htc: HTC) -> dict:
        return {
            'cert_id': 'kc_torque_valid',
            'payload': {'valid': bool(tfc.valid), 'eps_tau': tfc.eps,
                        'tau_bw': tfc.tau_bw, 'M_r': htc.M_r,
                        'wear': htc.w_hat, 'b_hat': htc.b_hat},
            't_stamp': time.time(),
            'validity_window': 0.005,      # 1kHz 力矩环，5ms 有效窗口
            'src_node': 'joint_cert'
        }
```

### IP-480 Resonance-Aware Torque Loop (RATL)

```python
@dataclass
class ResonanceAwareTorqueLoop:
    """RATL：自适应陷波 + 扰动观测器（DOB），穿越频率约束在反谐振之下。"""
    omega_c: float = 2 * np.pi * 60.0
    omega_dob: float = 2 * np.pi * 400.0
    notch_q: float = 8.0
    kp: float = 1.0

    def __post_init__(self):
        self.notch_b = np.array([1.0, 0.0, 0.0])
        self.notch_a = np.array([1.0, 0.0, 0.0])
        self.tau_d_hat = 0.0
        self.tau_ref_prev = 0.0
        self.x1 = self.x2 = 0.0
        self.y1 = self.y2 = 0.0

    def update_notch(self, htc: HTC):
        w0 = max(htc.omega_r, 1e-6)
        bw = w0 / self.notch_q
        self.notch_b = np.array([1.0, 0.0, w0 ** 2])
        self.notch_a = np.array([1.0, bw, w0 ** 2])

    def step(self, tau_ref: float, tau_meas: float, dt: float,
             htc: HTC) -> tuple[float, bool]:
        # 0) 证书门控：穿越频率不得逼近反谐振
        if self.omega_c >= 0.7 * htc.omega_a:
            self.omega_c = 0.7 * htc.omega_a
            safe = False
        else:
            safe = True
        # 1) DOB：用名义模型逆估计总扰动
        tau_d = tau_meas - (self.tau_ref_prev + self.kp * self.tau_d_hat)
        alpha = dt * self.omega_dob / (1.0 + dt * self.omega_dob)
        self.tau_d_hat += alpha * (tau_d - self.tau_d_hat)
        # 2) 陷波后的参考
        tau_ref_f = self._iir(self.notch_b, self.notch_a, tau_ref)
        # 3) PI + 扰动前馈
        u = self.kp * (tau_ref_f - tau_meas) + self.tau_d_hat
        self.tau_ref_prev = tau_ref
        return u, safe

    def _iir(self, b, a, x):
        y = (b[0] * x + b[1] * self.x1 + b[2] * self.x2
             - a[1] * self.y1 - a[2] * self.y2) / a[0]
        self.x2, self.x1 = self.x1, x
        self.y2, self.y1 = self.y1, y
        return y
```

### IP-481 Wear-Adaptive Friction-Hysteresis Compensator (WAFHC)

```python
@dataclass
class WearAdaptiveFrictionHysteresisCompensator:
    """WAFHC：LuGre 摩擦 + 迟滞逆补偿；磨损越大补偿越保守。"""
    sigma0: float = 1e4
    sigma1: float = 50.0
    sigma2: float = 0.5
    alpha_wear: float = 0.5

    def __post_init__(self):
        self.z = 0.0

    def compensate(self, omega_j: float, tau_j: float,
                   htc: HTC, dt: float) -> float:
        # LuGre 内部状态
        g = max(abs(tau_j) / max(htc.k_theta, 1e-9), 1e-6)
        z_dot = omega_j - self.sigma0 * abs(omega_j) / g * self.z
        self.z += dt * z_dot
        tau_f = self.sigma0 * self.z + self.sigma1 * z_dot + self.sigma2 * omega_j
        # 迟滞逆补偿：按运动方向注入 k*b/2
        tau_hys = htc.k_theta * (htc.b_hat / 2.0) * np.sign(omega_j + 1e-9)
        # 磨损越大，补偿越保守，避免过补偿激发谐振
        scale = 1.0 - self.alpha_wear * htc.w_hat
        return scale * (tau_f + tau_hys)
```

```python
@dataclass
class TorqueTemporalValidityMonitor:
    """TTVM：把 TCVM 从消息延迟扩展到力矩波形时效 + 磨损趋势告警。"""
    eps_slo: float = 0.15
    wear_slope_slo: float = 1e-4     # 每秒磨损指数增长上限
    window: int = 2000

    def __post_init__(self):
        self.eps_hist = deque(maxlen=self.window)
        self.wear_hist = deque(maxlen=self.window)

    def on_tfc(self, tfc: TFC, htc: HTC, t: float):
        self.eps_hist.append(tfc.eps)
        self.wear_hist.append((t, htc.w_hat))

    def check(self) -> tuple[bool, list[str]]:
        if len(self.eps_hist) < 100:
            return True, []
        viol = []
        if np.percentile(self.eps_hist, 99) > self.eps_slo:
            viol.append('torque_eps_p99')
        if len(self.wear_hist) > 1:
            (t0, w0), (t1, w1) = self.wear_hist[0], self.wear_hist[-1]
            if (w1 - w0) / max(t1 - t0, 1e-9) > self.wear_slope_slo:
                viol.append('wear_acceleration')
        return len(viol) == 0, viol
```

### CADVS+ 统一执行流（单步，加入力矩层）

```python
def cadvs_plus_step(robot_state: RobotState, sensor_data: SensorData,
                    tau_ref: float) -> ControlOutput:
    """在 IP-473 的 cadvs_step 之后闭合物理边界：力矩层准入与降级。"""
    # 0) 上层证书（规划/定位/视觉伺服）
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)
    if cert_agg is None or not cert_agg.all_passed:
        return fallback_to_teacher(robot_state, sensor_data, reason='cert_agg_fail')

    # 1) 物理层证书
    htc = wait_for_topic('/cert/htc', timeout=0.001)
    tfc = wait_for_topic('/cert/tfc', timeout=0.001)

    # 2) 力矩路径：仅当 TFC 通过
    if htc is not None and tfc is not None and tfc.valid:
        tau_meas = sensor_data.joint_torque
        tau_cmd, safe = torque_ctrl.step(tau_ref, tau_meas, dt=1e-3, htc=htc)
        if safe:
            return ControlOutput(tau_cmd, path='torque',
                                 certs=(cert_agg, htc, tfc))

    # 3) 降级：阻抗/位置控制（对传动非线性更鲁棒）
    q_ref = tau_to_pose_reference(tau_ref, robot_state)
    return ControlOutput(q_ref, path='impedance_fallback', certs=cert_agg)
```

## 4. 正确性论证（增量更新）

### 引理 32（有界传动不确定度下的力矩误差界）

**陈述**：设真实关节力矩 τ_actual = N η τ_m − τ_f − k_θ δ_hys + Δ，其中 |Δ| ≤ Δ_max、摩擦估计误差 |τ_f − f̂| ≤ δ_f、迟滞 |δ_hys| ≤ b/2。若扰动观测器带宽 ω_dob > ω_c（力矩环穿越频率），则稳态峰值力矩跟踪误差满足
ε_τ ≤ (Δ_max + δ_f + k_θ b/2)/(1 + ω_dob/ω_c) + N|η − η̂||τ_m|。

**证明**：DOB 的灵敏度函数 S(jω) = jω/(jω + ω_dob)，在低频 ω ≪ ω_dob 处 |S| ≈ ω/ω_dob，故低频集总扰动被衰减因子 1/(1 + ω_dob/ω_c) 压缩。对三项有界扰动用三角不等式求和即得第一项。效率失配项 N|η−η̂||τ_m| 位于前馈通道，不经 DOB 衰减，故单独保留。∎

**工程含义**：ε_max 不是拍脑袋的常数，而应由 Δ_max、δ_f、b、ω_dob 反推，并随磨损 b↑ 自适应收紧——这正是 HTC 存在的意义。

### 引理 33（谐振裕度与闭环稳定性）

**陈述**：双惯量模型下力矩开环 L(s) = (ω_c/s)·(ω_r²/(s² + 2ζ_r ω_r s + ω_r²))。若在 ω_r 处配置品质因数 Q 的陷波，且 ω_c < ω_a = √(k_θ/J_j)，则闭环稳定；定义 M_r = (ω_a − ω_c)/ω_a，当 ζ_r ≥ 0.1、M_r ≥ 0.3 时相位裕度 ≥ 30°。

**证明**：陷波在 ω_r 处抵消谐振峰（提供 ≥ 20log Q 的衰减），主导相位滞后仅来自积分器（−90°）与反谐振（−90°）。穿越频率低于反谐振时，反谐振相位尚未完全展开，剩余相位 > −180° + 30°。M_r 正是穿越频率到反谐振的相对距离，M_r 越大，剩余相位越多。∎

**工程含义**：RATL 不追求「更高带宽」，而是把 ω_c 锁在 ω_a 之下，并用陷波吃掉 ω_r 的峰值。M_r 进入 TFC，成为可审计的稳定裕度。

### 引理 34（磨损可检测性的信息下界）

**陈述**：磨损使失动量 b 与摩擦 f_c 单调非减。若估计噪声标准差为 σ_b、σ_f，则磨损指数变化 Δw 可检测当且仅当 Δb > 2σ_b 或 Δf > 2σ_f；否则存在一条 Δw > 0 的参数轨迹，其观测分布与「无磨损」不可区分（不可观测）。

**证明**：这是双侧假设检验的功效问题。当真实变化低于两倍噪声标准差时，两种假设下的观测分布重叠区间的误判概率不可忽略，不存在一致最优检验。故低于噪声地板的变化在统计上不可检测。∎

**工程含义**：这条引理是诚实的边界声明——HTC 的磨损指数只在「变化足够大」时有意义。它直接导出本轮最大风险：缓慢、小幅度、与温度耦合的退化，可能长期逃过证书。

### 定理（CADVS+ 执行集收缩与力矩保真保证）

**陈述**：在以下假设下：
(A1) 上层 CADVS 证书有效（IP-473~477 全部通过）；
(A2) HTC 参数估计落在不确定度界内；
(A3) TFC 通过：ε_τ < ε_max ∧ M_r > M_min ∧ ŵ < w_max ∧ τ_bw > τ_bw_min；
(A4) ω_c < 0.7 ω_a。
则 Exec_CADVS+ ⊆ Exec_CADVS；且每个执行步的交付力矩满足 ‖τ_cmd − τ_actual‖_∞ ≤ ε_max，闭环稳定，力矩带宽 τ_bw ≥ τ_bw_min。若 (A3) 不成立，控制器降级为阻抗/位置模式，其执行集同样 ⊆ Exec_CADVS。

**证明**：
- 包含性：cadvs_plus_step 仅在 TFC.valid 时进入力矩路径；否则走阻抗/位置回退，复用 CADVS 的位置/速度证书。两条路径都是 Exec_CADVS 的子集，故 Exec_CADVS+ ⊆ Exec_CADVS。
- 力矩界：由 (A3) 与引理 32，ε_τ ≤ ε_max。
- 稳定性：由 (A4) 与引理 33，M_r > 0，相位裕度为正。
- 带宽：由 TFC 的 τ_bw > τ_bw_min 直接得到。∎

**诚实声明**：该定理是「条件定理」——(A2) 的成立依赖于辨识模型正确，而辨识模型恰是 TFC 的薄弱环节（见 R33）。因此 CADVS+ 提供的是「在模型可信前提下的保证」，而非绝对安全；工程上必须用双编码器、力矩传感、离线标定做交叉校验，并接受「模型退化时保证随之失效」这一事实。

## 5. 实验设计（增量）

**平台**：单关节谐波减速器测试台（N≈100），电机侧/关节侧 19-bit 编码器，关节力矩传感器，电流环伺服，控制频率 1–5 kHz。

**辨识基线**：慢速三角波测失回差；Stribeck 扫频测摩擦；扫频 FRF 测 ω_r、ω_a、ζ_r。

**加速磨损**：额定负载循环加载 10⁵–10⁶ 次，每 2×10⁴ 次记录 (b, f, k_θ, ω_r)。

**对照**：(a) 纯 PID 力矩环；(b) PID + DOB；(c) DOB + 固定陷波；(d) 完整 RATL + WAFHC + HTC（本文）。

**预期**：完整方法 ε_τ ≤ 50% 基线；TFC 误通过率 < 5%；磨损检测延迟 ≤ 2×10⁴ 循环；0–60°C 全程无失稳。

**消融**：去掉陷波 / 去掉磨损收缩 / 用单编码器 + 电流估计替代双编码器——最后一组专门用来暴露 R33 的自我指涉风险。

## 7. 本轮最大风险（最终确认）

**一句话**：**证书的自我指涉性与补偿的稳定性悖论**——TFC 必须用传动模型去证明传动可信，而模型误差恰在磨损/温升时增长，形成「用失真模型证明自己未失真」的闭环；同时，越是积极地补偿空回与摩擦，越可能激励未建模的扭转/结构模态，把「跟踪变差」升级为「闭环失稳」。这是物理层证书与原子上层证书的根本差异：上层证书验证的是逻辑与信息一致性，物理层证书验证的却是「模型对现实的忠实度」，而后者永远无法被模型自身完全证明。
