# 第 41 轮 · 两灵感落地 v8：可认证决策规划 × 本体可行性证书 × 任意时刻可证规划（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「决策规划、机器人」命中 v17 证书体系最后一块空白：**决策层**。v17 证明了「怎么执行」和「在哪执行」，却没有证明「该不该执行这个决策、这个决策对本机器人是否可行、在截止时间前能否给出可证的决策」。本轮把证书从「技能级」提升到「计划级」，把机器人的**本体（形态、接触、力矩）**纳入证书约束，并用任意时刻可证规划解决实时决策的「时间—证据」矛盾。

## 0. 直觉与动机

**灵感 1（决策规划 → 计划级证书的缺口）**：v17 的 CertFlow 认证「单技能怎么生成动作」，C_ms 认证「单技能的前后置条件在几何上成立」，但 L3 的决策仍是符号规划器给出一串技能、再逐段执行；没有任何对象能回答「这整串计划成功的概率下界是多少、最坏安全裕度是多少、在什么初始区域里有效」。证书只覆盖「点」，没有覆盖「路径」。计划级证书必须能**沿计划组合**：成功概率用条件契约的链式乘积下界（无需独立性假设），安全裕度用 1-Lipschitz ESDF 的管道传播下界，有效区域用逐步前像交集。于是「决策」第一次成为可审计对象：选 π 而非 π′，不只是启发式分数高，而是 S_π 更高、H_π 更安全、V_π 更大。

**灵感 2（机器人 → 本体是决策的约束源）**：抽象规划最大的谎言是「机器人是一个点」。同一串「走过去—抓取—搬运」对轮式底盘、四足、人形机械臂的可行性完全不同：支撑多边形、ZMP/CoM、关节限位、力矩饱和、自碰撞、接触摩擦都不在符号计划里。本轮引入**本体可行性证书 EFC**：把技能生成的流轨迹通过已知刚体动力学传播，得到支撑裕度、CoM 裕度、力矩裕度、关节裕度、自碰撞裕度的鲁棒下界（用 ε_tol + B_t + ε_track 膨胀）。决策规划因此变成「在满足本体可行性的技能图中找可证计划」，而不是「先规划再祈祷控制器能跟」。

**灵感 3（决策规划 × 实时 → 任意时刻可证规划）**：机器人决策有硬截止时间，而证书搜索是 NP-hard。传统 anytime 规划只保证「越算越好」，不保证「任意时刻返回的东西可证」。本轮要求任意截断时刻返回三元组 (π_t, L_t, U_t)：π_t 本身带完整 CertPlan，L_t/U_t 是成功概率的认证上下界，间隙 U_t−L_t 显式报告。搜索用证书可采纳启发式保证「返回即有效、单调收紧、耗尽即最优」；再与 IP-48 的 N* 联合分配时间预算：t_plan + N*·c_flow ≤ deadline。

**三线耦合**：决策给出「可证的路径」，本体给出「可证的可行性」，anytime 给出「可证的时间预算」——三者把 v17 的「技能级活证书」升级为「计划级活证书」，并让机器人在截止时间内要么给出可证计划、要么给出带明确风险刻度的降级计划，而不是无证书地硬决策。

## 1. 形式化定义

**定义 27（条件成功契约与计划证书 CertPlan）**：技能 a 的契约 C_a=(pre_a, post_a, p_a, CertBundle_a)，其中 p_a∈(0,1] 是**条件**成功下界：对任意 x∈ValidRegion_a 且 x⊨pre_a，有 P(post_a 在 a 执行后成立 | x) ≥ p_a。计划 π=a₁…a_K 满足类型蕴含 post_i ⊨ pre_{i+1}。定义
CertPlan(π)=(Pre_π, Post_π, S_π, H_π, V_π, Gap_π)：
- S_π = Π_{i=1}^K p_i（链式法则，无需技能间独立）；
- H_π = min_i [ h_min^{(i)} − (B_t^{(i)} + ε_tol^{(i)} + ε_track^{(i)}) ]（ESDF 1-Lipschitz 管道下界）；
- V_π = { x₀ : 认证管道 Φ_i(x₀) ∈ ValidRegion_i, ∀i }（逐步前像交集）；
- Gap_π 仅在 anytime 模式下定义（定义 30）。

**定义 28（证书感知任务-运动规划）**：给定 (s₀,x₀)、目标 G、技能库 A 及契约，求
π* = argmax_{π∈Plans(s₀,G)} S_π
s.t. H_π ≥ 0（安全），x₀∈V_π（有效域），类型检查通过，且 t_plan(π)+N*(π)·c_flow ≤ T_deadline。
这是受约束的 AND/OR 图搜索（一般 NP-hard）。定义**证书可采纳启发式** U(s) 为从状态 s 到 G 的成功概率上界（忽略几何/本体约束的松弛解），L(s) 为当前已认证后缀的成功概率下界；U 用于剪枝（S_incumbent ≥ U(s) 即剪），L 用于 anytime 间隙。

**定义 29（本体可行性证书 EFC）**：对技能 a 在状态 x 下，
EFC(a,x)=(ρ_sup, ρ_com, ρ_τ, ρ_q, ρ_sc)，
分别为支撑多边形符号距离、ZMP/CoM 裕度、力矩裕度 min_j(τ_j^max−|τ_j|)、关节裕度、自碰撞裕度。鲁棒版本 ρ̂_k = ρ_k − L_{ρ_k}·(ε_tol + B_t + ε_track)，其中 L_{ρ_k} 为裕度对状态的 Lipschitz 常数。**定理（本体可行性）**：若对所有 k 有 ρ̂_k ≥ 0，则认证不确定性下的执行轨迹满足动力学/接触/限位可行性。

**定义 30（任意时刻可证规划）**：算法在任意时刻 t 返回 (π_t, L_t, U_t)，满足
(i) 可靠性：π_t 的 CertPlan 有效，且 H_{π_t}≥0、S_{π_t}≥L_t；
(ii) 有界性：L_t ≤ S_{π*} ≤ U_t；
(iii) 单调性：L_{t+1}≥L_t，U_{t+1}≤U_t，S_{π_{t+1}}≥S_{π_t}；
(iv) gap_t = U_t − L_t，搜索耗尽时 gap=0。

**定理 3（计划成功下界，链式积）**：若每个技能满足条件契约且类型蕴含成立，则 P(π 成功) ≥ Π_i p_i。证明：由链式法则 P(π成功)=Π_i P(a_i 成功 | a_{<i} 成功)；a_{<i} 成功 ⟹ post_{i−1} 成立 ⟹ pre_i 成立（类型蕴含），故每个条件概率 ≥ p_i，乘积得证。无需技能间独立。

**定理 4（安全管道）**：若 H_π≥0，则真实轨迹上处处 h(x_true)>0。证明：由定位、流采样与跟踪误差界，‖x_true−x̂‖ ≤ B_t+ε_tol+ε_track；ESDF 1-Lipschitz 给出 h(x_true) ≥ h(x̂) − (B_t+ε_tol+ε_track) ≥ H_π ≥ 0。

**定理 5（anytime 可靠性）**：若启发式 U 可采纳（从不高估），则任意截断时刻返回的 π_t 可证有效，且 L/U 单调；搜索耗尽时 gap=0。证明：对搜索树扩展次数归纳——incumbent 只在「目标节点且证书校验通过」时被替换；松弛上界随约束加入单调不增，已有下界随认证计划发现单调不减。

## 2. 三大产出设计

### 2.1 IP-51 CERTIFIED-DECISION-PLANNER（可认证决策规划器）
1. 契约携带技能图：节点=(符号状态, 几何估计)，边=技能服务（pre/post/p/CertBundle/EFC）。
2. 类型检查 AND/OR 搜索 + 分支定界；证书可采纳启发式 U(s)（松弛计划成功上界）+ L(s)；对 (S,H,V) 做 Pareto 保留。
3. 证书导向修复：无可行计划时找绑定约束（最大归一化赤字），执行主动感知缩 B、换任务分解、触发 IP-50 重颁、或降级为带风险刻度的计划。
4. 计划证书上报 Registry；运行期监测 V_π 与 H_π，出域/裕度衰减触发重规划。

### 2.2 IP-52 EMBODIMENT-FEASIBILITY-CERTIFICATE（本体可行性证书）
1. 本体模型：刚体动力学 + 接触时序 + 支撑多边形 + 关节/力矩/摩擦限。
2. 沿 IP-48 流轨迹传播裕度，用 ε_tol+B_t+ε_track 做鲁棒膨胀，得 EFC。
3. 派发前本体门控：ρ̂<0 拒绝该边；给出修复建议（调站姿/接触、降速、换步态）。
4. 与 IP-43 韵律耦合：韵律 s 作为「裕度—激进程度」调度量，保 ρ̂≥0。

### 2.3 IP-53 ANYTIME-CERTIFIED-PLANNING（任意时刻可证规划）
1. anytime 分支定界/AO*，维护 (π_t,L_t,U_t)，截止即返回可证 incumbent + 间隙。
2. 证书预算分配：在 t_plan 与 N*·c_flow 间分配，使 deadline 下风险最小（拉格朗日/DP）。
3. 中断决策：截止时执行可证 incumbent；若间隙过大，选择高 p 低性能的保守技能。
4. 闭环：执行期监测计划证书，间隙/风险超阈 → 精化重规划。

## 5. 本轮最大风险

**一句话**：计划级证书的两个保守性来源会叠加——长计划的条件概率连乘让 S_π 指数衰减到「无计划可证」，而 B_t+ε_tol+ε_track 的逐段膨胀让 H_π 迅速转负；若不用闭环重规划按段重置乘积、不把证书按段分解，决策层会退化为「要么拒绝行动、要么偷偷用回它声称已认证的符号启发式」，故 E73/E74 是本轮第一守门实验。

## 2. 关键算法（伪代码）

### IP-51 可认证决策规划
```
def certified_plan_search(s0, x0, G, A, deadline):
    incumbent = fallback_plan()            # 停机/保持，p=1，永远可证
    L, U = bounds(root)                    # U 可采纳；L 已证
    PQ = {root}
    while PQ and now() < deadline:
        s = extract_max_upper_bound(PQ)
        if S(incumbent) >= U(s): continue  # 剪枝
        if is_goal(s) and cert_valid(s):   # 计划证书校验
            incumbent = pareto_better(incumbent, s)   # 比较 (S,H,V)
            L = max(L, S(s)); PQ.rebound(L)
            if U - L <= eps_gap: break
        for a in applicable(s, A):
            if not type_check(s, a): continue
            if not applies(s, a): continue             # pre/post 蕴含
            if embodiment_certificate(a, s.x).rho_min < 0: continue  # IP-52 门控
            child = apply(s, a)
            child.U = U(s) * p_a                       # 可采纳松弛
            child.L = L(s) * p_a
            PQ.insert(child)
    return incumbent, L, U, certify_region(incumbent), U - L

def cert_valid(node):
    return node.H >= 0 and node.x0 in node.V and node.pre_ok and node.post_ok

def certify_region(plan):
    V = initial_workspace()
    for a in plan.steps:                    # 逐步前像交集
        V = preimage_under_certified_tube(a, V)
    return V
```

### IP-52 本体可行性证书
```
def embodiment_certificate(a, x):
    margins = []
    traj = flow_rollout(a, x, N_star(a))   # IP-48 认证流轨迹
    for tau, state in traj:
        q, qd, tau_j = rigid_body_dynamics(state, a.contact_schedule)
        rho = (support_margin(q), zmp_margin(q, qd),
               torque_margin(tau_j), joint_margin(q), self_collision(q))
        r = a.eps_tol + a.B_t + tracking_bound(a)
        margins.append([m - L_m * r for m, L_m in zip(rho, lip_margins())])
    return elementwise_min(margins)         # EFC 五元组

def embodiment_gate(a, x):
    efc = embodiment_certificate(a, x)
    if min(efc) < 0:
        return REJECT, suggest_repair(efc)  # 调站姿/降速/换步态
    return ACCEPT, efc
```

### IP-53 任意时刻可证规划
```
def anytime_decide(task, deadline):
    t_plan = allocate_budget(deadline, risk_curve)   # 见下
    plan, L, U, V, gap = certified_plan_search(
        task.s0, task.x0, task.G, task.A, deadline=t_plan)
    if gap > gap_max or not cert_valid(plan):
        plan = conservative_skill()                  # 高 p 低性能兜底
    N = n_star_within(plan, deadline - t_plan)       # IP-48
    return execute(plan, N), (plan, L, U, gap)

def allocate_budget(deadline, risk_curve):
    # 选择规划深度 d 与采样步数 N，最小化风险且满足时间约束
    best = None
    for d in planning_depths():
        for N in sample_steps():                      # e.g. {4,8,16,32}
            if t_plan(d) + N * c_flow <= deadline:
                r = risk_curve(d, N)
                best = argmin_risk(best, (r, d, N))
    return best.d
```

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 计划搜索 | 最坏 O(b^d)（TAMP NP-hard），分支定界+缓存摊销 | **定理 3**：S_π=Πp_i；anytime 返回即可证 |
| 计划安全裕度 | O(K·|traj|)，ESDF 增量查询 | **定理 4**：H_π≥0 ⟹ 真实 h>0 |
| EFC 传播 | O(K·H·(n_q+n_τ))，刚体动力学 | **定理（定义 29）**：ρ̂≥0 ⟹ 本体可行 |
| anytime 界 | 每次扩展 O(log|PQ|)；预算分配小规模 DP | **定理 5**：可靠、单调、耗尽 gap=0 |
| 有效域前像 | O(K·d_geo)，保守凸包近似 | V_π 内起点的认证管道全程在 ValidRegion |
| 组合 κ | κ_comp=min_i κ_i（复用 IP-46） | 串联收缩，误差不累积，支撑管道半径可加 |

## 4. 实验设计（E73-E79，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 计划证书可靠性 | 认证通过但真实违约率（安全/后置） | ≤0.5% |
| E74 链式下界紧致性 | 实测成功率−S_π（应≥0且贴近） | ≥0 且 ≤0.15 |
| E75 本体可行性 | EFC≥0 却跌倒/超限比例；跌倒率 vs 无 EFC | ≤1%；下降≥60% |
| E76 anytime 决策 | 200ms 截止成功率；gap 是否覆盖真实最优 | ≥90%；覆盖率100% |
| E77 端到端延迟 | 规划+执行 p99 vs v17 | 规划≤50ms；总周期≤v17+10ms |
| E78 证书导向修复 | 不可行起点恢复率 vs 随机修复 | 提升≥30% |
| E79 长程组合零样本 | 5-8 步任务成功率 vs v17；证书违约 | ≥+15%；<0.5% |

失败即回退：E73/E74 不达标 → CertPlan 降为启发式评分（不宣称证书），IP-51 作普通规划器；E75 不达标 → 回退点机器人可行性；E76 不达标 → 同步规划 + 固定 N*。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 链式乘积指数衰减 → S_π→0，无计划可证 | 高 | 闭环按段重规划重置乘积；段级证书 + 风险预算；E74 守门 |
| B_t+ε_tol+ε_track 逐段膨胀 → H_π<0 / 可行集空 | 高 | Pareto 保留 + 部分证书 + 保守回退技能；E73/E75 守门 |
| EFC 模型失配（接触、摩擦、柔性、未建模动态） | 高 | 鲁棒裕度 + 实测残差膨胀 + 分区硬件验证；E75 守门 |
| anytime 最坏指数，截止前无证书计划 | 中 | 层级分解 + 计划缓存复用 + 永远可用的 p=1 停机技能 |
| 动态障碍/环境变化使 V_π 过期 | 中 | 运行期有效域监测 + 裕度衰减触发重规划 |
| 启发式不可采纳 → 仅损失最优性 | 低 | 定期在线校准 U；可靠性由证书校验独立保证 |

## 6. 本轮最大风险

**一句话**：计划级证书的两大保守性会叠加——条件概率连乘使 S_π 随步数指数衰减，逐段误差膨胀使 H_π 迅速转负；若不用闭环分段重规划重置乘积、不把计划证书按段分解，决策层将退化为「要么拒绝行动、要么偷偷用回被它声称已认证的符号启发式」，故 E73/E74 是本轮成败判据。
