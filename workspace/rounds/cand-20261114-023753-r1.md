# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「对比实验」×「深度学习」）

> R70 把 FLUID 的「动作模态 epistemic」升级为「世界状态后验 epistemic」b_t，并用贝叶斯 VoI 选择看/问/触来消歧。但 R70 藏着一个根本缺口：它的所有信息动作都停留在**被动信息获取**——注视、提问、探针都只是在既有观测分布里重新加权，**无法区分「观测等价」的世界**。两个假设若在所有被动观测下同分布（例如「铰链卡住」与「电机增益偏低」在静止时对同一指令给出同样响应），看多久、问多少遍都没用；唯一出路是**主动做一个对照实验**：给一个受控、可逆的小干预，看两个假设的响应差分。这正是「对比实验」的字面含义，也是本轮第一个支点。
>
> 但「对比实验」在真实机器人上很危险：干预会改变世界，可能不可逆；会引入顺序效应、遗留效应（carryover）与混杂。于是第二个支点「深度学习」不是装饰，而是三件必需工具：(a) **深度对比响应编码器（ICE）**把匹配对照对 (o_treat, o_ctrl) 的差分映射到状态可分的表示，用 InfoNCE 给「状态身份」一个信息论下界；(b) **深度集成（DEQ）**把预测熵拆成 aleatoric（平均熵）与 epistemic（互信息），替代 R70 单粒子滤波的经验熵；(c) **神经因果世界模型（NCWM）**让系统在 `do(a†)` 下预测响应，从而在真正动手前评估 Do-VoI 与可逆性。
>
> 核心命题：**把 epistemic 再切一刀——分为「观测可约 U_obs」「仅干预可约 U_int」「因果不可约 U_irr」；用匹配对照实验消解 U_int，用深度对比表示与深度集成保证这种消解可学、可校准、可审计；只有干预不安全、不可逆或预算不足时，才退化为 R70 的观测 VoI，再退化为 R68 的纯保守。** 命名 **TRIAL-RAS**（Treatment–Reference Interventional Active Learning）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我相信哪个世界状态」，R71 问「**我能做哪个最小、可逆、有对照的小实验，把两个都说得通的解释分开**」——不确定性可以是一句提问，也可以是一次被精心设计、可收回的轻推。

## 0. 直觉与动机

**灵感 1（对比实验 → 观测等价是 epistemic 的死角）**
直觉：R70 的 VoI 有一个隐含前提——「多看一眼/多问一句，后验就会变」。但若两个世界状态在**所有被动观测与人类回答**下同分布，后验根本不会变，VoI 恒为 0，系统会以为「已无信息可查」，把结构性无知误判成「确定」。这类状态叫**观测等价**。要分开它们，必须进入 Pearl 第二层：不是「看世界」，而是「**动世界一下，看它怎么反应**」。一次轻推（treatment）与一次不推（control）的**差分**，就是对照实验的最小单元。这把「信息动作」从被动采样升级为主动干预。

**灵感 2（对照实验 → 差分把共模混杂一起减掉）**
直觉：直接看「推之后发生了什么」没用，因为温度、姿态、负载都在同时变。对照实验的威力在于**匹配**：在几乎相同的协变量下，一臂施加干预、一臂不施加，两臂之差把共模干扰整体减掉。若噪声自相关为 ρ，配对差分的方差是 `2(1−ρ)σ²`，相对非配对 `2σ²` 缩小 `(1−ρ)` 倍。这解释了为什么「主动做实验」在实时系统里反而**更省**：它用设计换样本。再叠加 AB/BA 交叉与 washout，顺序效应与 carryover 也被控制。

**灵感 3（深度学习 → 让「状态可分」成为可学习、可校准的目标）**
直觉：手工定义「两个状态差多少」很难，但可以学。用同状态的正对、异状态的负对训练 InfoNCE 对比编码器，得到的响应嵌入 r 满足 `I(s;r) ≥ log N − L_NCE`——这不是拍脑袋的相似度，而是状态互信息的下界。深度集成再给出**可分解且可校准**的不确定性：aleatoric = 各成员平均熵，epistemic = 预测熵减平均熵（互信息）。神经因果世界模型则提供一个可微的 `do` 算子，使系统能在动手前先「脑内做实验」。

**灵感 4（三分 → R70 是「不能干预」的退化）**
直觉：R70 把 epistemic 当成一个数 H[b_t]。但信息论上 H[b_t] 可以按等价类链式分解为 `H[C_obs] + H[C_int|C_obs] + H[s|C_int]`。第一项观测可约，第二项只有干预才能约，第三项**任何实验都约不掉**（因果不可分）。把三者混在一起，会导致两种错误：把不可约的当成可查的（浪费预算、过度自信），或把仅干预可约的当成不可约的（过早保守）。正确的姿态是：**U_obs 交给 R70，U_int 交给对照实验，U_irr 永远当风险处理**。R70 恰好是「干预不可用」边界上的退化。

**灵感 5（干预是双刃剑 → 反作用与捷径）**
直觉：为了看清世界而动手，可能把可恢复的歧义变成不可逆的损害（戳破柔软物体、掰断卡死的铰链、扰动本已稳定的接触）。更隐蔽的是**测量反作用**：干预本身改变了被估计的状态，若不做 washout 与交叉设计，系统会把自己的扰动记成世界的属性。深度对比学习还有第二个陷阱——**捷径相关**：训练集里「红色」总与「故障」共现，编码器可能学会用颜色而非因果状态来分正负对，于是系统「自信地区分了一个假区别」。因此本轮必须同时交付：ε-可逆干预认证、随机化交叉、washout、负对照/安慰剂纪律、以及能检测捷径的平衡性假设。

**灵感 6（对比实验也是研究方法论 → 用因果消融矩阵给每个组件定罪）**
直觉：R70 声称「BELIEF ⊇ FLUID ⊇ R68」，但这是**理论包含**，不是**因果贡献**。一个组件到底有没有用，必须用受控对比来估计——这正是「对比实验」在元层面的含义。定义**因果消融矩阵（CAM）**：行是系统与逐组件消融，列是安全/效率/校准/OOD 等指标；用配对 ATE、随机化臂序、正对照（注入已知故障）与负对照（安慰剂/打乱标签）来识别因果效应，用 Holm–Bonferroni 控错误发现、用 TOST 检验「边界处等价」。这样，「哪个部件真的在起作用」从叙事变成可复现的因果估计。

## 1. 形式化定义（增量：定义 331–345）

**定义 331（TRIAL-RAS 总览）** TRIAL-RAS = (BSE†, FMP†, MINT†, CIA†, FMA†, DoVoI, CP, ICE, DEQ, NCWM, AIC†, J_TRIAL)。三不变式：
(i) **实时流零学习写操作**（继承 R70 定义 310-i）；
(ii) **干预硬约束**：每次干预须 (a) `ρ_rev`-可逆、(b) 落在 C-RAS-WM 认证的力/位/时包络内、(c) 带匹配对照臂与随机化臂序、(d) 单位时间 ≤1 组、washout ≥ τ_w、且不得进入任务关键前缀；
(iii) **证据纪律†**：单次对照实验只更新似然、不得单独定案；须同时通过负对照（placebo/打乱标签，效应应 ≈0）与正对照（已知注入差异，效应应显著且功效 ≥ 1−β）。

**定义 332（观测等价、干预等价与可分离性）** 设策略类 Π_obs 为一切被动观测与人类回答，干预类 𝒜_int 为受控物理激励。假设 A102：被动观测等价于空干预 `do(∅)`，故干预等价关系更细，`≡_int ⊆ ≡_obs`。定义可分离性
`κ_int(s,s') = sup_{a†∈𝒜_int} W_2( p(o | do(a†), s), p(o | do(a†), s') )`。
`κ_int = 0` ⇔ 两状态**因果不可分**；`κ_obs = 0 < κ_int` ⇔ 只有干预能分开（R70 的死角）。

**定义 333（Epistemic 三分）** 对后验 b_t，令 `C_obs(s)`、`C_int(s)` 为上述等价类（A102 下 `C_int ⊆ C_obs`）。链式分解：
`H[b_t] = H[C_obs] + H[C_int | C_obs] + H[s | C_int]`，
定义 `U_obs := H[C_obs]`（观测可约）、`U_int := H[C_int | C_obs]`（仅干预可约）、`U_irr := H[s | C_int]`（因果不可约）。语义警告：U_irr **不是噪声**，而是结构性不可识别，必须当作风险保守处理，绝不能派实验去「查」。

**定义 334（干预动作空间与安全包络）** `𝒜_int = {a† = (direction, magnitude, duration, modality)}`，涵盖轻推、差动力探测、视点微移、短时激励。每个 a† 带可逆性 `ρ_rev(a†) ∈ [0,1]`、遗留 `ε_carry(a†)`、成本 `c_int(a†)`。可行集 `𝒜_int^safe = {a† : ρ_rev ≥ 1−ε_rev, ε_carry ≤ τ_carry, C-RAS-WM.certify(a†)=1}`。

**定义 335（Do-VoI 干预信息增益）** `VoI_do(a†) = H[b_t] − E_{o'∼p(·|do(a†),b_t)}[H[b_{t+1}]]`，其可约对象被显式限定为 `U_int`。选择
`a†* = argmax_{a†∈𝒜_int^safe} [VoI_do(a†) − c_int(a†)]`，s.t. 预算未超。
若 `max[VoI_do − c_int] ≤ 0`：不做干预，交回 R70 观测 VoI；若观测 VoI 也为 0：交回 R68 纯保守。

**定义 336（匹配对照对与交叉设计）** 对同一受试状态构造 control 臂 c 与 treatment 臂 t，协变量匹配 `x_m=(pose, velocity, temperature, task_phase)`，臂序随机（AB/BA crossover），臂间 washout ≥ τ_w。响应差分 `Δo = o_t − o_c`。在加性干扰模型 `o = f(s, do) + ν_t`、ν 为 AR(1) 相关 ρ 下，估计量 `ATE_hat = E[Δo]` 无偏估计干预因果效应（A103：SUTVA、positivity、washout 后无遗留）。

**定义 337（深度对比响应编码器 ICE）** `r_θ(o_t,o_c) = g_θ(o_t) − g_θ(o_c)`（孪生网络）。用干预日志构造正对（同一 C_int 成员/重复状态）与负对（不同 C_int），训练
`L_ICE = −E[ log exp(sim(r_i,r_j^+)/τ) / Σ_{k∈{j^+}∪Neg} exp(sim(r_i,r_k)/τ) ]`。
保证 `I(s; r) ≥ log N − L_NCE`（N 为负样本数）。可加干预增强负采样与协变量平衡约束（A104）以抑制捷径学习。

**定义 338（深度集成不确定性 DEQ）** E 个成员 `{f_e}`；`U_ale = E_e H[p(y|o,e)]`，`U_epi = H[mean_e p(y|o,e)] − E_e H[p(y|o,e)]`。温度缩放校准，ECE 作为门控量，替换/校核 R70 的粒子经验熵。

**定义 339（神经因果世界模型 NCWM）** 学习结构化 SCM `f_θ`，含模块化干预头 `do(a†)`；预测干预响应与反事实对照，用于**动手前**预筛 Do-VoI 与可逆性，降低真实干预次数。

**定义 340（可识别性与遗留效应条件）** A103（SUTVA、positivity、washout 后无 carryover、臂序随机化）下，配对差分识别干预的平均处理效应；若存在遗留，则用带 carryover 项的交叉模型并延长 washout。

**定义 341（证据纪律†：负对照门 NCG）** 每次实验后同时跑：(a) **安慰剂/负对照**（把无干预臂标为 treatment 或打乱标签），要求 `|effect_neg| ≤ ε_neg`；(b) **正对照**（注入已知状态差异），要求 `effect_pos ≥ ε_pos` 且功效 `≥1−β`。任一不满足 ⇒ 不得用该实验更新 b_t，只记录为「实验失败」。

**定义 342（三分处置与两级退避†）** 若 U_int 在预算内、安全且通过负对照而被消解：`λ = λ_floor(U_ale + U_irr)`（resolution bonus）；若未消解/不安全/有 carryover/负对照失败：`λ = λ_floor(U_ale + U_int + U_irr)`（退回 R70，再退回 R68）。U_obs 仍走 R70 的观测 VoI。**U_irr 永不进入可查询通道，永远计入保守项。**

**定义 343（双时间尺度调度 TSS）** 快速控制环保持 R70 周期不变；epistemic 实验调度器只在**安全窗口**（低速/截止期有余量/无关键前缀）运行，负责 Do-VoI 规划、NCWM 预筛、配对执行与 washout 排程。干预不进入认证前缀，保证控制连续。

**定义 344（TRIAL 证书 J_TRIAL）** `J_TRIAL = (J_BELIEF, ICE_ECE, ensemble_ECE, do_voi_ratio, pair_ATE, negative_control_stat, positive_control_power, washout_log, cam_report_hash, trial_ver)`。Valid ⇔ Valid(J_BELIEF) ∧ ICE/ensemble ECE ≤ τ_ece ∧ 负对照通过 ∧ 正对照功效达标 ∧ 干预约束未越界。

**定义 345（因果消融矩阵 CAM v2）** 行 = {R68, FLUID, BELIEF, TRIAL} 及逐组件消融 {−BSE, −MINT, −FMA, −ICE, −DoVoI, −CP, −DEQ, −NCWM, −NCG}；列 = {成功率, 消歧所需交互数, P99 延迟, 安全违规, ECE_state, 缓变故障 AUC, 投毒穿透率, OOD 检出, 能耗}。估计配对 `ATE_τ`，配正/负对照、随机化臂序、预注册、Holm–Bonferroni、边界处 TOST、E-value 敏感性。

# IP-275 ICE：深度对比响应编码器（干预日志自监督）
class ContrastiveResponseEncoder:
    def __init__(self, encoder, tau=0.1):
        self.g, self.tau = encoder, tau

    def response(self, o_treat, o_ctrl):
        return self.g(o_treat) - self.g(o_ctrl)          # 配对差分

    def info_nce(self, r, r_pos, r_neg):
        pos = sim(r, r_pos) / self.tau
        neg = sim(r, r_neg) / self.tau                   # [N_neg, B]
        return -(pos - logsumexp(cat([pos[None], neg]), dim=0)).mean()

# IP-276 DEQ：深度集成不确定性（校准后替代粒子经验熵）
def ensemble_uncertainty(members, o):
    p = stack([softmax(m(o)) for m in members])          # [E, C]
    p_bar = p.mean(0)
    U_ale = mean([entropy(pi) for pi in p])
    U_epi = entropy(p_bar) - U_ale
    return U_ale, U_epi                                   # 互信息 = epistemic

# IP-277 DoVoI + CP：干预规划与匹配对照执行
def plan_intervention(b_t, safe_set, ncwm, budget):
    best = None
    for a_dag in safe_set:                                # 已经 C-RAS-WM 认证
        if not budget.allow_intervention(a_dag): continue
        # 先用 NCWM 在脑内做实验，避免真实反作用
        post = mc_posterior(b_t, a_dag, ncwm, n=16)
        voi = entropy(b_t) - mean([entropy(p) for p in post])
        score = voi - cost(a_dag) - risk_penalty(a_dag)
        if best is None or score > best.score:
            best = (a_dag, score)
    return best if best and best.score > 0 else None     # 无利可图→退回 R70

def run_matched_pair(M, a_dag, state):
    order = random_bit()                                 # AB/BA 随机化
    arms = [('control', None), ('treatment', a_dag)]
    if order: arms.reverse()
    obs = {}
    for name, act in arms:
        obs[name] = M.execute_matched(act, state, covariates=state.xm)
        M.wait(washout=TAU_W)
    delta = M.ice.response(obs['treatment'], obs['control'])
    # 负对照 / 正对照门
    if not M.ncg.negative_ok(delta, M.placebo_log): return None
    if not M.ncg.positive_ok(M.known_probe_log):    return None
    ate = delta                                          # 配对因果效应估计
    return ate

# IP-289 主闭环：双时间尺度，仅在安全窗口插入对照实验
def TRIAL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    b_t = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)
    # 快速环：沿用 R70/BELIEF，只把不确定性切成三份
    U_obs, U_int, U_irr = M.epi3.decompose(b_t, M.cia.causal_classes)
    U_ale, U_epi = M.deq.ensemble_uncertainty(M.ensemble, o)   # 校准
    # 慢速环：仅当安全窗口且 U_int 显著，才规划干预
    if M.tss.safe_window(obs) and U_int > TAU_INT:
        a_dag = M.dovoi.plan_intervention(b_t, M.safe_int_actions, M.ncwm, M.budget)
        if a_dag is not None:
            ate = run_matched_pair(M, a_dag, obs)          # 对照实验
            if ate is not None:
                b_t = M.bse.update_interventional(b_t, ate, a_dag)
                U_obs, U_int, U_irr = M.epi3.decompose(b_t, M.cia.causal_classes)
            else:
                M.audit.log_failed_experiment(a_dag)       # 只记录，不更新
    # 三分退避：U_irr 永远保守，U_int 未解则并入
    U_floor = U_ale + U_irr + (U_int if not M.tss.resolved else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode_from_belief(M.modes, b_t, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_iii.submit_async(b_t, a_dag, U_obs, U_int, U_irr, M.last_ate)
    M.cam_logger.log_if_eval(M.cfg.eval_mode)
    M.b_prev = b_t
    return k, lam, mode, (U_obs, U_int, U_irr)

## 3. 推导

**引理 23（配对差分的方差缩减）** 设两臂观测 `o = f(s,do)+ν`，`Var(ν)=σ²`，两臂噪声相关 ρ。则 `Var(o_t − o_c) = 2(1−ρ)σ²`；达到同信噪比所需样本数为非配对设计的 `(1−ρ)` 倍。系：**共模干扰越强（ρ→1），对照实验越省**——配对设计是主动实验能塞进实时预算的数学理由。

**引理 24（干预可识别性的充要判据）** 在 A102–A103 下，`max_{a†} VoI_do(a†) > 0` ⇔ 存在后验正质量状态对 `(s,s')` 使 `κ_int(s,s')>0`。且当所有对 `κ_int=0` 时 `U_int=0`，任何干预都不应发生（那只是 U_irr，白花预算）。系：R70 的观测 VoI 恰在 `κ_obs=0<κ_int` 时**必然失效**，这是它无法自愈的结构盲区。

**引理 25（InfoNCE 下界与捷径风险）** 对比编码器满足 `I(s;r) ≥ log N − L_NCE`；故 ICE 的可分性是状态互信息的**下界代理**，而非任意相似度。若负采样中某伪相关特征在训练集与标签共现（A104 被违背），则该下界同时约束 `I(nuisance;r)`，编码器会学到捷径。系：必须用**干预增强负采样 + 协变量平衡 + 打乱标签负对照**主动破坏伪相关，否则「分得开」不等于「分得对」。

**引理 26（负对照的混杂上界）** 若安慰剂/打乱标签实验仍测得效应 `|effect_neg| ≤ ε_neg`，则匹配协变量之外未观测混杂对估计的偏倚 ≤ ε_neg（在 A103 线性可加近似下）。系：负对照不是形式主义，它给出**残余混杂的可测上界**，把「自以为控制住了」变成可审计的数字。

**定理 20（TRIAL 严格包含 BELIEF 严格包含 FLUID 严格包含 R68）** 在 A102–A104 下，TRIAL 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；且当 `𝒜_int^safe=∅`、`Do-VoI≤c_int`、负对照失败或 `U_int=0` 时，TRIAL 与 BELIEF **逐指令相同**（定义 342）。安全侧不让步，效率侧获得 intervention bonus。U_irr 始终计入保守项，故不会因「查不到」而虚假自信。

**定理 21（干预安全与无突变）** ε-可逆干预 + C-RAS-WM 认证 + 双时间尺度安全窗口 + 交叉/washout ⇒ 交互物理风险 ≤ ε_int；干预只改变「选哪个状态假设」，不改变安全包络；实验失败/超时/负对照不通过时 λ 单调不降地退回 R70/R68；提交/换装不变式保持 ⇒ 控制连续、无突变。

**定理 22（CAM 的因果可识别性）** 在臂序随机化、SUTVA、positivity、匹配协变量下无未观测混杂、washout 后无 carryover 的条件下，配对 `ATE_hat` 是各组件因果效应的无偏估计；负对照给出残余混杂上界，E-value 量化其对未观测混杂的稳健性。故「对比实验」把「哪个组件有用」从相关性叙事升级为**可复现的因果归因**。

## 6. 本轮最大风险

**一句话**：TRIAL-RAS 的最大风险是**干预的不可逆反作用与捷径对比学习**——为了看清世界而动手，可能把一次可恢复的歧义变成不可逆的物理损害，而深度对比编码器可能把训练环境里的伪相关当成因果差异，让系统自信地区分了一个并不存在的区别；一旦干预不安全或表示学错，主动实验就从「消除无知的工具」变成「制造损害的自信」。

## 2. 形式化定义（要点版）

**定义 346（TRIAL-RAS 组件栈）** 快环：MTM/COF/BSE/FMP/ACH/C-RAS-WM（继承 R70，零学习写操作）。慢环：EPI-3 → DoVoI → NCWM 预筛 → RDM 认证 → CP 执行 → NCG 校验 → BSE† 更新 → VQAuditor-III / CAM 记录。两环以安全窗口同步，干预永不进入快环认证前缀。

**定义 347（EPI-3 分解算子）** 给定 b_t 与学习到的因果等价类划分 `{C_obs}`、`{C_int}`（A102：`C_int⊆C_obs`）：
`U_obs=H[C_obs]`，`U_int=H[C_int|C_obs]`，`U_irr=H[s|C_int]`，且 `U_obs+U_int+U_irr=H[b_t]`。该分解**不改变** R70 的安全侧，只改变「哪部分值得花预算」。

**定义 348（干预安全认证 RDM）** 对 a† 计算 `cert(a†)=1[ρ_rev≥1−ε_rev ∧ ε_carry≤τ_carry ∧ a†⊂Envelope ∧ a†∩CriticalPrefix=∅ ∧ c_int≤c_max]`。`cert=0` ⇒ a† 移出候选且不得执行；U_int 记为未消解。

**定义 349（Do-VoI 规划器）** 以 NCWM 生成 `N=16` 个后验预测，估计 `VoI_do(a†)`；选 `argmax[VoI_do−c_int−risk_penalty]`。若 ≤0，交回 R70 观测 VoI；若观测 VoI 亦 ≤0，交回 R68。**U_irr 不进入候选目标**，避免为不可识别量浪费干预。

**定义 350（匹配对照执行器 CP）** 对固定 state 采样匹配协变量 `x_m`，随机臂序（AB/BA），先 control 后 treatment 或反之，臂间 `washout≥τ_w`。输出配对差分 `Δo` 及其协方差，供 BSE† 与 CAM 使用。

**定义 351（交叉估计量）** `ATE_hat = (1/n)Σ_i Δo_i`；配对标准误 `SE=sd(Δo)/√n`；若检测到 carryover，改用 `Δo_i = τ + γ·carryover_prev + ε` 的交叉模型并延长 washout。A103 下 `E[ATE_hat]=ATE`。

**定义 352（ICE 训练与平衡约束）** 正对 = 同一 C_int 成员或重复到达的同一状态；负对 = 不同 C_int。A104（协变量平衡）：在每个负对批次中，要求 nuisance 特征在正负对间分布匹配（用重加权或对抗头抑制）。总损失 `L=L_ICE+λ_bal·L_bal+λ_reg·‖θ‖²`。保证 `I(s;r)≥logN−L_NCE`。

**定义 353（DEQ 校准与门控）** 集成 E=5，温度 T 在验证集上最小化 NLL；`ECE_ens` 越界 ⇒ 禁用 Do-VoI（回 R70），并对 ICE 嵌入做同样的校准门控。

**定义 354（NCWM do 算子）** `f_θ: (s,do(a†))↦p(o'|s,do(a†))`，干预头模块化（与观测头分离）以支持反事实。用于 (a) 预筛 Do-VoI，(b) 估计反作用风险，(c) 生成反事实对照。NCWM 误差超过阈值时禁用其预筛、退化为真实配对实验（更贵但更可信）。

**定义 355（NCG 负对照门）** 每次实验记录 `effect_neg`（安慰剂/打乱标签）与 `effect_pos`（已知注入差异）。判定 `pass = 1[|effect_neg|≤ε_neg ∧ effect_pos≥ε_pos ∧ power≥1−β]`。`pass=0` ⇒ 该实验只入审计日志，不更新 b_t。

**定义 356（TSS 调度器）** 仅在 `safe_window = 1[velocity<v_max ∧ deadline_slack>s_min ∧ not in critical_prefix]` 时启动实验；维护干预预算、washout 队列与实验疲劳计数；实验频率上限 `f_max`。

**定义 357（VQAuditor-III）** 审计对象新增：臂序是否随机、washout 是否达标、负/正对照是否通过、ICE 是否被捷径污染、Do-VoI 是否越权、CAM 记录是否与预注册一致。结论回灌预算先验与 CAM 报告。

**定义 358（AIC-TRIAL）** `ℰ_TRIAL = ℰ_BELIEF × ℰ_intervene`，其中 `ℰ_intervene = {不可逆反作用, carryover 污染, 臂序偏差, 捷径对比学习, 干预诱发 OOD, NCWM 幻觉}`。

**定义 359（J_TRIAL）** 见符号表；Valid ⇔ Valid(J_BELIEF) ∧ ICE/ensemble ECE≤τ_ece ∧ 负对照通过 ∧ 正对照功效达标 ∧ 全部干预 cert=1 ∧ washout 达标。

**定义 360（CAM v2 排布）** 行 `R={R68, FLUID, BELIEF, TRIAL} ∪ {TRIAL−BSE, −MINT, −FMA, −ICE, −DoVoI, −CP, −DEQ, −NCWM, −NCG}`，列 `M={成功率, 消歧交互数, P99, 安全违规, ECE_state, 缓变 AUC, 投毒穿透, OOD 检出, 能耗}`。每格报告 `ATE_hat ± SE`，并附负对照就读与 E-value。

**定义 361（ATE 与随机化）** 对每个组件 τ，`do(τ=1)` 与 `do(τ=0)` 通过匹配消融实现；臂序随机化保证可交换性；`ATE_τ` 为主估计量，`CATE_τ(x_m)` 为按协变量分层的条件效应，用于回答「在哪些场景有效」。

# IP-278 ICE：对比响应编码器（自监督于干预日志）
class ContrastiveResponseEncoder:
    def __init__(self, g, tau=0.1, lam_bal=0.1):
        self.g, self.tau, self.lam_bal = g, tau, lam_bal

    def embed(self, o_treat, o_ctrl):
        return self.g(o_treat) - self.g(o_ctrl)            # 配对差分，消共模

    def loss(self, r, r_pos, r_neg, nuisance):
        pos = sim(r, r_pos) / self.tau
        neg = sim(r, r_neg) / self.tau                     # [N_neg, B]
        nce = -(pos - logsumexp(cat([pos[None], neg]), dim=0)).mean()
        bal = mmd(nuisance[r_pos_idx], nuisance[r_neg_idx]) # A104 平衡
        return nce + self.lam_bal * bal

# IP-279 DEQ：深度集成 + 校准 + 门控
class DeepEnsembleUncertainty:
    def __init__(self, members, temperature=1.0, tau_ece=0.08):
        self.members, self.T, self.tau_ece = members, temperature, tau_ece

    def __call__(self, o):
        p = stack([softmax(m(o) / self.T) for m in self.members])  # [E,C]
        U_ale = mean(entropy(p, axis=1))
        U_epi = entropy(p.mean(0)) - U_ale
        return U_ale, U_epi, ece_pass(self.members, self.tau_ece)

# IP-280/IP-282：NCWM 脑内预筛 + RDM 可逆性认证
def safe_intervention_candidates(M, b_t):
    out = []
    for a_dag in M.proposal.propose(b_t):                  # 轻推/差动力/视点微移
        if not M.rdm.cert(a_dag): continue                 # 力/位/时/可逆/前缀
        if not M.budget.allow_intervention(a_dag): continue
        preds = M.ncwm.sample(b_t, do=a_dag, n=16)         # 脑内实验
        voi = entropy(b_t) - mean([entropy(p) for p in preds])
        score = voi - M.cost(a_dag) - M.rdm.risk(a_dag)
        if score > 0: out.append((a_dag, score))
    return sorted(out, key=lambda z: -z[1])

# IP-277 CP：匹配对照对（随机臂序 + washout）
def matched_pair(M, a_dag, state):
    x_m = M.match.covariates(state)                        # pose/vel/temp/phase
    arms = [('C', None), ('T', a_dag)]
    if M.rng.bit(): arms.reverse()                         # AB/BA
    obs, ate = {}, None
    for name, act in arms:
        obs[name] = M.execute_matched(act, state, x_m)
        M.wait(Tau_w)                                      # washout
    delta = M.ice.embed(obs['T'], obs['C'])
    return delta, obs

# IP-283 NCG：负对照/正对照门
def evidence_gate(M, delta):
    neg = M.placebo.effect(delta)                          # 打乱标签/安慰剂
    pos = M.positive_control.effect()
    ok = (abs(neg) <= M.eps_neg) and (pos >= M.eps_pos) and (M.power() >= 1 - M.beta)
    M.audit.log_controls(neg, pos, ok)
    return ok

# IP-289 TRIAL-RAS 主闭环（快环不动，慢环做实验）
def TRIAL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    b_t = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)
    # EPI-3 三分 + DEQ 校准
    U_obs, U_int, U_irr = M.epi3.split(b_t)
    U_ale, U_epi, ens_ok = M.deq(o)
    if not ens_ok: U_int = 0.0                             # 不可信 → 禁实验，回 R70
    # 慢环只在安全窗口、且 U_int 值钱时动手
    if M.tss.safe_window(obs) and U_int > TAU_INT and ens_ok:
        cands = safe_intervention_candidates(M, b_t)
        if cands:
            a_dag = cands[0][0]
            delta, pair_obs = matched_pair(M, a_dag, obs)
            if evidence_gate(M, delta):                    # 负/正对照都过
                b_t = M.bse.update_interventional(b_t, delta, a_dag)
                U_obs, U_int, U_irr = M.epi3.split(b_t)    # 仅更新真正通过门者
            else:
                M.audit.log_failed_experiment(a_dag)       # 不更新，只记录
    # 三分退避：U_irr 永远保守；U_int 未解并入
    resolved = (U_int <= TAU_INT)
    U_floor = U_ale + U_irr + (0.0 if resolved else U_int)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode_from_belief(M.modes, b_t, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_iii.submit(b_t, U_obs, U_int, U_irr, M.last_ate)
    M.cam.log_if_eval(M.cfg.eval_mode)
    M.b_prev = b_t
    return k, lam, mode, (U_obs, U_int, U_irr)

# IP-288 CAM v2：配对 ATE + 正/负对照 + 统计族
def run_cam(harness):
    pre = harness.load_preregistration()                   # 方向/终点/α/种子
    rows = pre.components
    for tau in rows:
        for x_m in harness.strata():                       # CATE 分层
            y1 = harness.sample(tau=1, x_m=x_m, arms='randomized')
            y0 = harness.sample(tau=0, x_m=x_m, arms='randomized')
            d  = mate_pair(y1, y0).difference()            # 配对差分
            harness.record_ate(tau, x_m, d)
    harness.negative_control()                             # 打乱标签/安慰剂
    harness.positive_control()                             # 已知注入故障
    report = harness.apply(family=['holm', 'bh', 'tost', 'evalue'])
    assert pre.directions_and_endpoints_match(report)
    return report

## 4. 推导（产物侧补强）

**命题 23（配对 ATE 无偏性）** 在 A103（SUTVA、positivity、随机化臂序、washout 后无 carryover）下，`E[ATE_hat]=E[o_t−o_c | x_m]=ATE(x_m)`；协变量匹配只减少方差、不改变期望。系：**配对不是近似，是在 A103 下的精确设计**；一旦 carryover 存在，必须显式建模，否则无偏性失效。

**命题 24（负对照的偏倚界）** 若在「无真实处理」的安慰剂臂上测得 `|effect_neg|≤ε_neg`，则对任何真实处理结论，未观测混杂导致的偏倚不超过 `ε_neg`（线性可加模型下严格；非线性下为一阶上界）。系：负对照把「混杂可能很小」从信念变成**可报告的数字**。

**命题 25（TOST 与边界安全声明）** 对「TRIAL 在 `𝒜_int^safe=∅` 时不劣于 R68」，用等价界 δ_eq 做 TOST：`H0: |μ_T−μ_R|≥δ_eq`。拒绝 H0 才能声明「边界处不劣」。系：**安全声明必须是等价检验，不能是「差异不显著」**——后者只是证据不足。

**命题 26（ICE 与 Do-VoI 的一致性）** 若 ICE 达到互信息下界且 A104 成立，则嵌入空间距离 `‖r(s)−r(s')‖` 是 `κ_int(s,s')` 的单调代理；Do-VoI 在嵌入空间的近似误差随 `L_NCE` 下降而下降。系：**表示学得好不好，直接决定对照实验选得准不准**——深度学习不是外挂，而是 Do-VoI 的前置条件。

**定理 23（TRIAL 的安全-效率双包含）** A102–A104 下，TRIAL 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；当 `𝒜_int^safe=∅`、`Do-VoI≤c_int`、NCG 失败或 `U_int=0` 时逐指令相同；`U_irr` 始终计入保守项 ⇒ 不会因「无法实验」而产生虚假自信。效率侧仅在「安全、可逆、通过负对照」的干预上获得 bonus。

**定理 24（CAM 的可复现因果归因）** 在预注册 + 随机化 + 配对 + 正/负对照 + 统计族 Λ 下，CAM 报告的 `ATE_τ` 是组件 τ 的因果效应无偏估计；Holm 控 FWER、BH 控 FDR、TOST 支持边界等价、E-value 量化未观测混杂稳健性。故「哪个组件有用」成为**可审计的因果结论**，而非消融表格上的相关性叙事。

### 6.2 四类对照（缺一不可）

1. **正对照（positive control）**：注入已知状态差异（如已知刚度变化），要求实验能检出，功效 `≥1−β`。用于证明「实验有分辨力」，防止把「没检出」误当「没差异」。
2. **负对照（negative control / placebo）**：安慰剂干预或打乱 treatment 标签，要求 `|effect|≤ε_neg`。用于给残余混杂与捷径学习设可测上界。
3. **边界等价对照（TOST）**：在 `𝒜_int^safe=∅`、`VoI≤c`、NCG 失败等退化边界，检验 TRIAL 与 BELIEF/R68 **不劣**（等价界 δ_eq），而非「差异不显著」。
4. **消融对照（ablation）**：逐组件关闭，估计 `ATE_τ`；用 CATE 分层回答「在哪些场景有用」，避免平均效应掩盖局部伤害。

### 6.3 统计与可复现纪律

- **随机化**：臂序 AB/BA 随机、种子公开；配对协变量预定义。
- **预注册**：假设、主/次终点、样本量/功效、α、排除标准、失败归因树，先于数据锁定。
- **多重比较**：主效应 Holm–Bonferroni（FWER≤0.05）；网格探索 BH（FDR≤0.05）。
- **敏感性**：E-value ≥2 才允许「稳健」表述；否则标注「脆弱结论」。
- **报告**：CAM 全矩阵 + 负/正对照 + 失败实验清单 + J_TRIAL 验签 + 代码/数据/种子哈希。

## 9. 本轮最大风险

**一句话**：TRIAL-RAS 的最大风险是**「主动实验的反作用 × 对比表示的捷径」双重失配**——物理上，一次 ε-可逆性估计错误的干预可能不可逆地改变被估计的世界；统计上，深度对比编码器若在训练日志里学到伪相关，Do-VoI 就会在错误的「可分性」上选实验、在错误的「状态」上更新后验，而负对照若设计得不够狠（打乱标签仍被捷径骗过），CAM 会给这份自信盖上「因果已验证」的章——**做实验比不做实验更强，但做错实验比不做实验更危险。**
