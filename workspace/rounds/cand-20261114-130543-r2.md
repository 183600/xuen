# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「全身控制」×「嵌入式系统」）

> R69 把不确定性做成了流体：流匹配策略给出**有形状**的多模态动作分布，主动多模态交互把「不知道」变成可生成、可认证、可审计的动作（看/问/触/等）。但它默默假设了两件事：**(a) 动作是抽象的，可以被身体无条件执行；(b) 计算是免费的，可以在需要的那一刻算完。** 真实具身系统两条都不成立。
>
> - **全身控制**说：动作必须落在一副有浮基、有接触、有摩擦锥、有自碰撞、有质心/ZMP 约束的身体上。任务空间里两个都合理的模态，可能一个身体根本做不到——这是**任务空间的幻影**；而「看/问/触/等」本身也是全身动作，会抢 DOF、改变接触力、扰动平衡。
> - **嵌入式系统**说：算力、内存、功耗、时间都是硬预算；多采样、轨迹聚类、Hutchinson 散度、LLM 解码都可能算不完；**在截止期之后才算出的答案，等于没有答案**。更隐蔽的是，定点量化会压小甚至合并模态间距、抹平或伪造似然异常——R69 引以为傲的「标定不可吸收的第二意见」，可能被部署层的量化反向吸收。
>
> 核心命题：**把「能不能消解歧义」从信念层降到执行层——epistemic 动作必须同时属于两个可行流形：全身可行流形 ℱ_body 与实时可调度流形 ℱ_time。只有落在 ℱ_body ∩ ℱ_time 里的不确定性，才配被消解；否则退回 R69/R68 的保守。** 命名 **SOLID-RAS**（Safe whole-body, On-device, Latency-certified, Interaction-Disciplined Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我这副身体、这台芯片，真的做得到这次求证吗**」——不确定性从流体冻成固体：再漂亮的形状，也必须被身体与硅片接住。

## 0. 直觉与动机

**灵感 1（全身控制 → 任务空间模态 ≠ 身体可执行模态）**
直觉：流匹配在动作空间里采样，K 个模态看起来很干净；但把它们交给全身控制器，可能因接触缺失、摩擦锥越界、自碰撞、关节限位、质心越出支撑多边形而不可实现。R69 的模态权重是在「任务空间」里量的，身体却活在「约束流形」上。一个在任务空间里权重 0.4 的模态，如果 90% 的实现都违反平衡，它真正可用的概率远小于 0.4。更糟的是，把所有模态都投影到可行域后，可能发现**可行质量 μ_F 本身很小**——这说明策略在幻觉一种身体做不到的未来；此时该做的不是去「问」，而是报警/请求接管。由此得到**可行性条件化**：先问「这个模态身体做得到吗」，再问「值不值得为它去问」。

**灵感 2（信息动作是全身动作 → 探询也要占身体预算）**
直觉：R69 把 g=(gaze,probe,ask) 当成轻量附加项，用社交/物理成本 c(g) 与位移界 ε_g 约束。但凝视会带动头部与躯干，探针要伸手，等待要保持姿态；这些都会消耗零空间、改变接触力、扰动 ZMP。信息动作与任务动作共享同一副身体，必须进入同一个层级 QP：安全硬约束 ≻ 任务 ≻ 信息 ≻ 姿态。信息动作只能活在**零空间预留**里；预留不够时，g 不是「成本高」，而是**不可执行**。这把 R69 的软成本升级为硬可行性。

**灵感 3（嵌入式系统 → 截止期是硬约束，算不完 = 没算）**
直觉：R69 的预算表把 P99 < 2.6ms 当成「够快」。嵌入式控制不认 P99：1kHz 环就是 1ms 一格，错过一格就是控制断流。WCET 是**最坏**执行时间，不是平均；K=4 多采样、轨迹聚类、Hutchinson 回放、LLM 解码都可能把最坏路径顶穿。于是要引入**实时可调度流形**：只允许在截止期内确定完成的计算配置；算不完的配置在**计划阶段**就被判不可行，而不是运行时祈祷。推论：VoI 必须扣除计算成本并以截止期为零容忍约束——**算得起的问，才叫问**。

**灵感 4（anytime + 保守单调 → 早停也必须安全）**
直觉：若必须按时交付，就得允许提前截止。但提前截止返回的是不完整估计，可能**低估** U_epi，从而让 λ 变小——这会把「算力不足」偷偷转成「过度乐观」。所以 anytime 分解必须**上界单调**：任何时刻的估计都 ≥ 真值，随算力增加从上方逼近。早停只会更保守，不会更冒险。这是把 R68「任何不确定 → 只收紧」从测量层推广到计算层：**任何没算完 → 也只收紧**。

**灵感 5（量化是新的「标定吸收」→ 第二意见自己也会被骗）**
直觉：R69 的精彩之处是用流似然做「标定不可吸收」的第二意见。但嵌入式部署常用定点/低比特，量化步长 Δ_q 会压小模态间距（甚至合并）、把似然差 Δa 压到噪声底。于是两种坏情况同时出现：量化把**真模态合并** → 低估 U_epi → 过度自信；量化把**异常抹平** → Δa 失效 → 缓变故障再度隐形。这不是新问题，而是 R68「标定吸收」在部署层的镜像。必须同时做**量化膨胀**（把 Δ_q 当不确定性保守放大）与**量化感知异常门控**（信噪比不够就关闭该通道）。

**灵感 6（嵌入式威胁模型 → 时间与比特都是攻击面）**
直觉：一旦系统会按输入决定算多久，就有了**时序攻击面**：对抗场景把系统逼进最坏计算路径（强制 K=4、最大 N_step、最大聚类），制造 deadline miss；一旦系统依赖定点似然，就有**比特翻转/故障注入**面：SEU 改一位就能伪造「正常」。还有**身体侧攻击**：外推、负载突变、接触丧失让 ℱ_body 瞬变。R69 的 ℰ_poison 必须扩展为 ℰ_SOLID = ℰ_FLUID × ℰ_timing × ℰ_quant × ℰ_body。**能在最坏时间和最坏比特下仍然安全的认证，才叫认证。**

**灵感 7（严格包含 → 本轮不是又加一层黑箱）**
直觉：R69 已立下规矩：新层必须是旧层的严格泛化。本轮的两个可行流形恰好提供了干净的退化边界：身体→理想质点（F≡1）、算力→∞（ℱ_time 为全集）、Δ_q→0（无量化）时，FPM 退化为恒等、AUD-any 退化为 R69 的 AUD、CVI 退化为 MINT、HQP 退化为直通。于是 SOLID 在边界上逐指令等于 FLUID；一般情形只会**删去**不可行/算不完的动作，而不会新增冒险动作。安全侧不做让步，效率侧获得「可行且算得起」的 resolution bonus。

**定义 310（SOLID-RAS 总览与四不变式）** SOLID-RAS = (HQP-B, FPM, AUD-any, WCET-C, QAU, CVI, EIS, FMC, VQAuditor-E, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **双重可行域**：任何信息动作/消解策略必须同时满足 ξ ∈ ℱ_body(o)（定义 312）与 χ ∈ ℱ_time（定义 316）；
(iii) **部署保守单调**：量化、早停、求解器截断等一切部署近似，只允许使不确定性估计不减、λ 不减（定义 317、319）；
(iv) **严格包含**：身体退化为理想质点（F≡1）、算力无限（ℱ_time=全集）、Δ_q→0 时，逐指令退化为 FLUID-RAS（定义 328、定理 18）。

**定义 311（浮基全身动力学与层级 QP）** q∈ℝ^{n_q}, v∈ℝ^{n_v}；M(q)v̇ + h(q,v) = Sᵀτ + J_cᵀλ_c；接触约束 J_c v̇ + J̇_c v = 0（或摩擦锥 λ_c∈K_μ）。任务层级 p_safety ≻ p_task ≻ p_info ≻ p_posture。HQP-B 逐层解 QP，低层只能在高层最优解的零空间内优化：N_{l+1} = N_l (I − J_l⁺ J_l)。

**定义 312（全身可行流形与可行性指示）** ℱ_body(o) = { ξ ∈ 𝒜_+ : HQP-B(ξ; o) 可行且硬约束残差 ≤ ε_h }；F(ξ) = 1[ξ ∈ ℱ_body(o)]；ρ(ξ) 为到最近可行点的加权距离（不可行度）。

**定义 313（可行性质量与条件化模态后验）** μ_F = E_{ξ~p_θ(·|o)}[F(ξ)] ≈ (1/K)Σ_j F(ξ^{(j)})；p_F(m_k|o) = Σ_{j∈m_k} F(ξ^{(j)}) / Σ_j F(ξ^{(j)})；phantasm_k = 1[ŵ_k ≥ τ_w ∧ (Σ_{j∈m_k}F/K) ≤ τ_F]（概率大而可行质量小 ⇒ 任务空间幻影）。

**定义 314（信息动作零空间预留与授权界）** g 作为低于任务层的任务；可执行性要求存在 α>0 使硬约束 slack(hard) ≥ α，且 g 的参考加速度满足 ‖N_s N_t g‖ ≤ ε_g^α。不满足 ⇒ g 不可执行（而非高成本）。

**定义 315（多速率控制与硬截止期）** WBC 周期 T_c（如 1ms），epistemic 周期 T_e（如 10ms），单次交互时限 D_int。任一阶段 i 的截止期 D_i ≤ T_c（安全环）或 ≤ T_e（认知环）。

**定义 316（WCET 预算与实时可调度流形）** C_i(χ) 为阶段 i 的最坏执行时间上界（静态分析 + 测量夹逼 + 缓存/中断/DVFS/热节流修正）；配置 χ=(K,N,plan)。ℱ_time = {χ : Σ_i C_i(χ) + C_os ≤ D_min}；deadline margin m_D = D_min − Σ_i C_i(χ)。

**定义 317（anytime 不确定性分解 AUD-any）** 每个检查点 t 返回 (Û_ale(t), Û_epi(t))；要求**安全单调**：以高概率 Û_ale(t) ≥ U_ale、Û_epi(t) ≥ U_epi 对 ∀t 成立，且 Û(t+1) ≤ Û(t)（从上方逼近）。截止 t* 时以 Û(t*) 走 R69 的风险缩放。

**定义 318（定点量化误差模型）** 量化算子 Q_Δ(·)，步长 Δ_q；速度场误差界 ‖v̂−v‖ ≤ e_q(z) + L_v Δ_q；散度积分误差界 |â_score − a_score| ≤ E_div(Δ_q,N)；定义量化噪声底 σ_q。

**定义 319（量化膨胀不确定性）** Σ̃_k = Σ_k + Δ_q² I；Δ̃_min = max(0, Δ_min − c_q Δ_q)；Û_ale = Σ ŵ_k tr Σ̃_k，Û_epi = H_mode·g(Δ̃_min)。保证 Û ≥ U（引理 20）。

**定义 320（量化感知异常通道 QAU）** SNR_a = E[Δa_fault] / (σ_q + σ_samp)；仅当 SNR_a ≥ 1 且 ECE_q ≤ τ_ece 时启用 FMA 第二意见；否则把慢变故障判据并入保守退避。

**定义 321（计算价值信息 CVI）** VoI_time(g;χ) = (VoI(g) − C_comp(χ))·1[χ∈ℱ_time]，硬约束 χ∈ℱ_time；若不存在可行 χ 或 VoI_time ≤ 0，则不交互、退化 R69/R68；记录 voi_ratio_time。

**定义 322（嵌入式交互调度 EIS）** 信息动作集为多速率任务；用 RM/EDF 判可调度；等待动作 g_wait 的时长 ≤ D_stab（由闭环稳定裕度给出）；交互不得阻塞安全环；中断安全：任意抢占点均不产生更小的 λ。

**定义 323（可行性条件化模态校准 FMC）** 在 MCG 之外增加：可行子集上的模态校准误差 ECE_F 与幻影率 P_phantasm；任一越界 ⇒ 禁用 VoI，退化 R69/R68；并把「不可行幻影」与「权重不可信」分开报告。

**定义 324（可行性证书）** Cert_body(ξ) = 1[硬约束残差 ≤ ε_h ∧ hierarchy 已解 ∧ slack ≥ α]；Cert_time(χ) = 1[Σ C_i(χ) ≤ D_min]。两者皆 1 才允许执行；否则动作作废且 λ 不减。

**定义 325（SOLID 威胁模型）** ℰ_SOLID = ℰ_FLUID × ℰ_timing × ℰ_quant × ℰ_body；ℰ_timing：对抗性最坏路径诱发 deadline miss 与计时侧信道；ℰ_quant：亚 LSB 扰动、定点合并模态、SEU/故障注入伪造似然；ℰ_body：外推/负载突变/接触丧失/关节退化使 ℱ_body 瞬变。

**定义 326（嵌入式参与式审计 VQAuditor-E）** 审计新增：WCET 是否被低估、可行性证书是否诚实、量化是否吞掉模态或异常、deadline miss 是否被掩盖、计时侧信道是否泄漏。结论回灌 AuditBuf，成为下一轮 WCET 预算与 FMC 阈值先验。

**定义 327（证书 J_SOLID）** J_SOLID = (J_FLUID, WCET_budget, deadline_margin, quant_error_bound, μ_F, P_phantasm, hierarchy_cert, timing_log_hash, body_model_ver, solid_ver)。Valid ⇔ Valid(J_FLUID) ∧ Cert_time ∧ Cert_body 覆盖率 ≥ 1−ε_c ∧ 量化膨胀满足 ∧ 审计无高危。

**定义 328（三级保守退避）** (a) 若 ξ∈ℱ_body∩ℱ_time 且证书有效：用 R69 的 resolution bonus；(b) 若不可行/算不完/证书失败：λ = λ_floor(U_ale + U_epi)（R69 未消解）；(c) 若 FLUID 层本身不可信（ECE / SNR / 幻影越界）：λ = λ_floor(U_ale + U_epi + U_deploy)，其中 U_deploy 为量化+时序膨胀——即 R68 纯保守再加一层部署裕度。三级退避保证 λ 单调不减（定理 19）。

# IP-264 HQP-B：带全身硬约束与信息零空间预留的层级 QP
class WholeBodyHQP:
    def solve(self, xi_ref, o, info=None):
        sol = self.qp_safety(o)                  # 摩擦锥 / 限位 / 自碰撞 / ZMP
        if not sol.feasible: return None
        sol = self.qp_task(sol, xi_ref.a)        # 只在安全零空间内
        if info is not None:
            if sol.slack < info.alpha: return None    # 无授权裕度 => g 不可执行
            sol = self.qp_info(sol, info.g)      # 只活在高层零空间
        return sol
    def certify(self, sol):
        return sol.residual_hard <= EPS_H and sol.slack >= ALPHA_MIN

# IP-265 FPM：把流模态投影到全身可行流形并条件化权重
def feasible_projection(samples, hqp, o):
    F    = [hqp.solve(xi, o) is not None for xi in samples]
    mu_F = sum(F) / len(samples)
    if mu_F < TAU_MU:                            # 可行质量太小 => 任务空间幻影
        return None, mu_F, 'body_phantasm'       # 不交互，报警/请求接管
    modes = cluster([xi for xi, f in zip(samples, F) if f])
    w_F   = feasible_weights(modes)              # 可行子集上重归一
    return modes, w_F, 'ok'

# IP-266 AUD-any：上界单调的 anytime 分解（任意截止都安全）
def decompose_anytime(samples, deadline, checkpoints):
    ub = (INF, INF)
    for t, subset in checkpoints(samples):
        if now() > deadline: break
        ub = min_ub(ub, upper_confidence(subset, delta=DELTA, n_check=t))
    return ub                                    # 任意时刻 ub >= 真值

# IP-267 WCET-C + IP-269 CVI：先判可调度，再算值不值得问
def schedule_and_decide(modes, w, o, body, wcet):
    best = None
    for g in info_candidates(modes):
        chi = plan_compute(g, K=len(modes), N=N_STEP)
        if not wcet.cert_time(chi):        continue   # 算不完 = 不可行
        if body.hqp.solve(body.ref(g), o) is None: continue  # 身体做不到
        s = (voi(w, g, o) - compute_cost(chi))
        if s > 0 and (best is None or s > best.s): best = (g, chi, s)
    return best                              # None => 退化 R69/R68

# IP-268 QAU：量化感知的流似然第二意见
def quant_anomaly(policy_q, xi, o, o_cal, Delta_q):
    a_o   = -policy_q.log_likelihood_q(xi, o,     Delta_q)
    a_cal = -policy_q.log_likelihood_q(xi, o_cal, Delta_q)
    dA    = abs(a_o - a_cal)
    if snr_a(Delta_q) < 1.0: return 0.0          # 量化噪声底淹没信号 => 关闭
    return dA                                    # 否则作为第二意见

# IP-275 SOLID 主闭环（继承 FLUID-RAS）
def SOLID_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)
    K, N = M.wcet.planner.choose(o)              # 计划阶段选可调度配置
    if not M.wcet.cert_time((K, N)):             # 不可调度 => 直接保守
        return M.fluid_fallback(o, extra=M.quant.inflate(U_cal))
    samples = M.fmp.sample(o, K, N)
    modes, mu_F, st = M.fpm.project(samples, M.hqp, o)
    if st == 'body_phantasm':                     # 身体做不到 => 不交互
        return M.fluid_fallback(o, extra=M.quant.inflate(U_cal))
    Ub_ale, Ub_epi = M.aud_any.decompose(modes, deadline=D_e)
    a_hat = M.qau.anomaly(M.fmp_q, M.last_action, o, M.o_cal, M.Delta_q)
    slow  = (a_hat > M.tau_fma) and (M.last_r_res < TAU_RES) and M.qau.snr_ok()
    g, chi = M.cvi.choose(modes, o, M.budget, M.wcet)   # 扣计算成本 + 双重可行
    if g is not None and not slow:
        ans = M.cia.execute_certified(g, M.hqp)         # 带身体证书
        Ub_epi = M.cia.update_belief_ub(modes, ans)
    U_floor = Ub_ale + (Ub_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    sol = M.hqp.solve(M.last_ref, o)
    if not M.hqp.certify(sol):
        lam = max(lam, 0.8); sol = M.last_safe_solution
    if slow:
        lam = max(lam, 0.8)
    tau = M.pi_sigma.prefix_dispatch(sol, lam)
    M.vqa_e.submit_async(g, chi, mu_F, a_hat, sol.cert)
    return tau, lam, sol, (Ub_ale, Ub_epi, mu_F)

## 3. 推导

**引理 19（可行性条件化的 VoI 上界）** 可行性 F(ξ) 是 ξ 的确定性函数；对后验做条件化不会增加信息。设 p_F 为可行子集上重归一的模态后验，则 H(M_F|o) ≤ H(M|o)，且对任意信息动作 g，有 VoI_F(g) ≤ VoI(g)。系 1：**用未条件化权重算 VoI 会系统性高估**，因为可能「消解」到一个身体做不到的模态。系 2：当 μ_F→0 时，朴素 VoI 仍可能很大，而 VoI_F→0；此时主导不确定性是「有没有可行模态」而非「哪个模态」，交互无法回答它——应触发幻影报警而非追问。这直接改写了 R69 的 MINT 候选排序。

**引理 20（量化膨胀的保守性）** 设均匀量化步长 Δ_q，模态间距 Δ_min。若 Δ_min < c_q Δ_q，量化后两模态不可分（合并）；朴素做法会把 Δ_min 估小、把 U_epi 估小、把 λ 估小——**乐观且不安全**。采用定义 319 的膨胀 Σ̃_k = Σ_k + Δ_q²I、Δ̃_min = max(0, Δ_min − c_qΔ_q)，则对任意真实 (Σ_k, Δ_min) 有 Û_ale ≥ U_ale、Û_epi ≥ U_epi；同时由定义 318 的散度误差界，|â_score − a_score| ≤ E_div。系：量化只会让系统更保守，永不更冒险——除非 SNR_a < 1，此时异常通道整体关闭并并入退避，避免「用噪声当第二意见」。

**引理 21（anytime 上界单调 ⇒ 任意截止安全）** 用 K 个样本的 Hoeffding/Bennett 置信上界估计熵、用矩阵 Chernoff 上界估计 tr Σ；在检查点集 {1..T} 上做 union bound，则以概率 ≥ 1−δ，对 ∀t 有 Û(t) ≥ U_true。又因检查点是嵌套子集、上界取 min，故 Û(t) 单调不增、由上方逼近。于是对任意截止 t*，λ(t*) ≥ λ_floor(U_true)——**算力不足只会让系统更保守**，不会把「没算完」伪装成「很确定」。

**定理 18（SOLID 严格包含 FLUID）** 在理想身体（F≡1，HQP 为恒等）、无限算力（ℱ_time 为全集）、无量化（Δ_q=0）下，FPM 退化为恒等投影、AUD-any 退化为 R69 的 AUD、CVI 退化为 MINT、EIS 退化为空调度、QAU 退化为 R69 的 FMA；故 SOLID 与 FLUID 逐指令相同。一般情形下，双重可行域只会**删去** FLUID 允许的（不可行或不可调度的）动作，并把删除转化为定义 328 的保守退避，因此任意状态期望风险 ≤ FLUID；安全侧不让步，效率侧获得可行且算得起的 resolution bonus。

**定理 19（全身交互安全、无突变与三级退避单调）** 精确层级 QP 中，低优先级任务的最优解受限于高优先级零空间，故加入任意信息任务不改变安全硬约束的可行性；若 Cert_body 与 Cert_time 均通过，则物理风险 ≤ ε_int 且交互只改变「选哪个模态」、不改变安全包络。当证书失败、超时、量化 SNR 不足或被投毒时，定义 328 的三级退避使 λ 单调不减地退化为 FLUID/R68；新动作取上一安全解（或 R69 动作），换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：SOLID-RAS 的全部安全性押在「WCET 上界与身体模型是可信的」这一前提上——**若静态 WCET 分析偏乐观（缓存、DVFS、热节流、中断抖动），或全身模型漏了负载/接触/柔性，那么可行性证书会变成一张“虚假的健康证明”：系统会自信地执行一个身体做不到的动作、或在截止期后交付一个迟到的安全决策，并且用 J_SOLID 给自己盖章**；此时「认证」本身成为最大的攻击面——**盖章盖在不可能之上，比不盖章更危险**。

**次级风险与缓解**：
1. **可行性投影过贵/过保守**（每模态解一次 QP）→ 热启动 + 可行域局部线性化 + 仅对高权重模态精算；
2. **anytime 上界过松**（UB 太保守）→ 更紧的经验 Bernstein 界 + 分层检查点，接受适度效率损失；
3. **量化膨胀吃掉全部分辨率**（Δ_q 太大）→ 混合精度：仅似然/聚类用高精度，其余定点；
4. **时序攻击与最坏路径**→ 计划阶段固定配置 + 输入无关的 WCET 上界 + 预算隔离；
5. **身体模型漂移**→ VQAuditor-E 在线校验 + 参数突变检测 + 失败即退 R69/R68；
6. **「可行但无益」的交互**（μ_F 高但 VoI 低）→ CVI 的净收益门 + 定义 328 单调退避。

# IP-264 HQP-B：全身硬约束 + 信息零空间预留
class WholeBodyHQP:
    def solve(self, xi_ref, o, info=None):
        sol = self.qp_safety(o)                 # 摩擦锥/限位/自碰撞/ZMP
        if not sol.feasible: return None
        sol = self.qp_task(sol, xi_ref.a)       # 安全零空间内
        if info is not None:
            if sol.slack < info.alpha: return None   # 无授权 => 不可执行
            sol = self.qp_info(sol, info.g)     # 高层零空间内
        return sol
    def certify(self, sol):
        return sol.residual_hard <= EPS_H and sol.slack >= ALPHA_MIN

# IP-265 FPM：可行性投影与条件化权重
def feasible_projection(samples, hqp, o):
    F    = [hqp.solve(xi, o) is not None for xi in samples]
    mu_F = sum(F) / len(samples)
    if mu_F < TAU_MU: return None, mu_F, 'body_phantasm'  # 幻影 => 报警
    modes = cluster([xi for xi, f in zip(samples, F) if f])
    return modes, feasible_weights(modes), 'ok'

# IP-266 AUD-any：上界单调、任意截止安全
def decompose_anytime(samples, deadline, checkpoints):
    ub = (INF, INF)
    for t, subset in checkpoints(samples):
        if now() > deadline: break
        ub = min_ub(ub, upper_confidence(subset, delta=DELTA, n_check=t))
    return ub                                   # ub >= 真值

# IP-267/269：先判可调度，再算值不值得问
def schedule_and_decide(modes, w, o, body, wcet):
    best = None
    for g in info_candidates(modes):
        chi = plan_compute(g, K=len(modes), N=N_STEP)
        if not wcet.cert_time(chi):        continue      # 算不完 = 不可行
        if body.hqp.solve(body.ref(g), o) is None: continue  # 身体做不到
        s = voi(w, g, o) - compute_cost(chi)
        if s > 0 and (best is None or s > best.s): best = (g, chi, s)
    return best                                 # None => 退化 R69/R68

# IP-268 QAU：量化感知异常
def quant_anomaly(policy_q, xi, o, o_cal, Delta_q):
    dA = abs(-policy_q.log_likelihood_q(xi, o,     Delta_q)
             + policy_q.log_likelihood_q(xi, o_cal, Delta_q))
    return 0.0 if snr_a(Delta_q) < 1.0 else dA  # SNR 不足 => 关闭

# IP-275 主闭环（继承 FLUID-RAS）
def SOLID_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)
    K, N = M.wcet.planner.choose(o)
    if not M.wcet.cert_time((K, N)):
        return M.fluid_fallback(o, extra=M.quant.inflate(U_cal))
    modes, mu_F, st = M.fpm.project(M.fmp.sample(o, K, N), M.hqp, o)
    if st == 'body_phantasm':
        return M.fluid_fallback(o, extra=M.quant.inflate(U_cal))
    Ub_ale, Ub_epi = M.aud_any.decompose(modes, deadline=D_e)
    a_hat = M.qau.anomaly(M.fmp_q, M.last_action, o, M.o_cal, M.Delta_q)
    slow  = (a_hat > M.tau_fma) and (M.last_r_res < TAU_RES) and M.qau.snr_ok()
    g, chi = M.cvi.choose(modes, o, M.budget, M.wcet)

    if slow: lam = max(lam, 0.8)
    tau = M.pi_sigma.prefix_dispatch(sol, lam)

    return tau, lam, sol, (Ub_ale, Ub_epi, mu_F)

## 4. 推导

**引理 19（可行性条件化 VoI 上界）** F(ξ) 是 ξ 的确定性函数，条件化不增信息：`H(M_F|o)≤H(M|o)`，对任意 g 有 `VoI_F(g)≤VoI(g)`。系：未条件化权重会系统性高估 VoI；`μ_F→0` 时朴素 VoI 仍大而 `VoI_F→0`，主导不确定性是「有无可行模态」，交互答不了——应触发幻影报警而非追问。

**引理 20（量化膨胀保守性）** 若 `Δ_min<c_qΔ_q`，量化合并模态；朴素估计会低估 `U_epi` 与 λ（乐观且不安全）。用 `Σ̃=Σ+Δ_q²I`、`Δ̃_min=max(0,Δ_min−c_qΔ_q)` 则 `Û_ale≥U_ale, Û_epi≥U_epi`；配合散度误差界 `|â_score−a_score|≤E_div`，部署近似只增保守性。`SNR_a<1` 时关闭异常通道，避免用噪声当第二意见。

**引理 21（anytime 上界单调 ⇒ 任意截止安全）** 以 Hoeffding/Bennett 估熵、矩阵 Chernoff 估 `trΣ`，在检查点上 union bound，则 w.p. `1−δ` 对 ∀t 有 `Û(t)≥U_true`；嵌套子集 + 取 min ⇒ 单调不增、上逼近。故任意截止 `λ(t*)≥λ_floor(U_true)`，算力不足只更保守。

**定理 18（SOLID 严格包含 FLUID）** 理想身体（F≡1，HQP 恒等）+ 无限算力（ℱ_time 全集）+ 无量化（Δ_q=0）下 FPM/AUD-any/CVI/EIS/QAU 逐项退化为 R69 对应组件，两系统逐指令相同。一般情形双重可行域只删去不可行/不可调度动作，并转为定义 328 的保守退避，故任意状态期望风险 ≤ FLUID。

**定理 19（全身交互安全、无突变与退避单调）** 精确层级 QP 中低优先级任务受限于高层零空间，加入信息任务不改变安全硬约束可行性；Cert_body∧Cert_time 通过则风险 ≤ ε_int 且交互只改模态选择、不改安全包络。证书失败/超时/SNR 不足/投毒时三级退避使 λ 单调不减地退化为 FLUID/R68，并保持上一安全解 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：SOLID-RAS 的全部安全性押在「WCET 上界与身体模型可信」上——**若 WCET 分析偏乐观（缓存/DVFS/热节流/中断抖动），或全身模型漏了负载/接触/柔性，可行性证书就变成一张虚假的健康证明：系统会自信地执行身体做不到的动作、或在截止期后交付迟到的决策，并用 J_SOLID 给自己盖章**；此时「认证」本身成为最大攻击面——**盖章盖在不可能之上，比不盖章更危险**。

**次级风险与缓解**：可行性投影过贵/过保守（热启动 + 局部线性化 + 仅精算高权重模态）；anytime 上界过松（更紧经验界 + 分层检查点）；量化膨胀吃掉分辨率（混合精度，仅似然/聚类高精度）；时序攻击（计划阶段固定配置 + 输入无关 WCET + 预算隔离）；身体模型漂移（VQAuditor-E 在线校验 + 突变检测 + 失败退 R69/R68）；「可行但无益」交互（CVI 净收益门 + 定义 328 单调退避）。
