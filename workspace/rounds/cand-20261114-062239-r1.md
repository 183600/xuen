# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「社会规范理解」×「并发推理」）

> R69 把不确定性拆成 aleatoric / epistemic，用「流匹配多模态策略 + 主动交互消解」把「诚实的不知道」升级成「去问、去看、去触」。但 R69 的成功建立在一个未曾言明的前提上：**世界是一个藏着单一真值的安静对象，交互是向它发出的一次串行查询，查询本身不改变答案。** 这个前提在人类社会里几乎全部失效。
>
> **社会规范理解**说：要查的不是事实，而是**规范**——它是上下文索引的、可废止的（defeasible）、受众相关的、且**多数情况下是复数且都合法**的（隐私 vs 安全、礼貌 vs 效率）。两个人都没说谎，却给出相反的「正确答案」。
> **并发推理**说：交互从来不是串行的。多个利益相关者会同时表态，系统的多个推理线程会同时读同一个规范状态；并发带来**规范竞争（race）**、**社交死锁（mutual yielding）**，以及一个数据库里早就命名过的陷阱：**合流（confluence）只保证「无论调度顺序如何都收敛到同一个结果」，绝不保证这个结果是对的。**
>
> 核心命题：**把 R69 的「单真值 + 串行查询」换成一个可废止规范半格上的并发推理：用快照隔离保证决策不混读，用动作集交集保证冲突下不违约，用合法性质询保证「问」本身不违规，用异议保留保证并发不会把偏见收敛成假共识。** 命名 **CONCORD-RAS**（Concurrent Norm-grounded, Order-independent, Reconciliatory Decision for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这里到底该守哪条规矩，而这条规矩对谁成立**」——规范不是一条要先查到的答案，而是所有并发参与者共同维持、且会被「查」这个动作本身改变的一种平衡。

## 0. 直觉与动机

**灵感 1（社会规范理解 → 「查」的对象不是事实，而是可废止的道义命题）**
直觉：R69 的信息动作把世界当成一个隐藏变量 M，问一句就把 M 的后验压窄。但「这里能不能超车」「能不能打断他们说话」「能不能把老人扶起来」没有唯一 M。它们的正确答案是一个**道义命题**：在上下文 C、受众 A 下，动作 a 是「必须/允许/禁止」，带优先级 σ 和例外 E；而「允许」是可以被新证据撤销的。更麻烦的是**受众相关性**：同一动作，对同伴允许、对陌生人禁止；「问年龄」在医疗场景允许、在社交场合冒犯。R69 的标量社交成本 c(g) 把这一切压成了一个数，等于把「礼貌/越界/失礼」的整个结构丢了。要真正理解规范，必须保留它作为**带受众索引、可废止、带优先级的道义对象**，而不是再算一个更细的标量。

**灵感 2（并发推理 → 规范是多方同时维护的，不是单线程查询出来的）**
直觉：R69 的交互预算是「单位时间 ≤1 次」，隐含单线程世界观。可现实中规范由多个主体并发执行与监督：A 说「快过」、B 同时摇头、C 已经在让行。如果系统只开一条推理线程，它要么**顺序等待**（社交死锁：我等你先走、你等我先走），要么**读到半合并状态**（规范竞争：基于 A 的许可刚提交，B 的否决还没合并）。这正是分布式系统的经典问题，而它有一个成熟的答案：**快照隔离 + 事务式提交**。把「读规范—决策—行动」当成一个事务，只在单一 norm epoch 的快照上决策，提交时再验证前提没有被并发写入破坏；冲突不采用 last-writer-wins，而是走规范半格的 join 并保留异议。

**灵感 3（合流性是一把双刃剑 → 并发推理的最大陷阱是「自信地收敛到错误」）**
直觉：把证据合并设计成 join 半格（交换、结合、幂等），就能得到漂亮的**顺序无关性**：不管交互以何种顺序交错，最终规范信念都一样。这对可复现、可审计是巨大优点。但它只保证**收敛**，不保证**正确**：若所有并发线程共享同一份有偏的规范先验（训练数据里「让行总是对的」「权威总是对的」），合流性会把这份偏见**放大成一个顺序无关、可复现、看似一致的共识**——这正是「假共识」。所以本轮必须同时交付一条反作用力：**异议保留（dissent preservation）**。join 不丢弃少数框架，只在「多数—少数分歧质量」足够低时才允许定案；否则宁可保持未决、走保守。

**灵感 4（问句自带规范足迹 → 质询本身可能违规）**
直觉：R69 的 VoI 只算「问了能多知道多少」，再用一个 c(g) 罚社交成本。但「问」在规范上是一个动作：反复确认是对他人诚信的质疑（不信任信号），追问隐私是不礼貌，向错误的人求助可能让对方为难。换句话说 **Leg(g) 不是成本项，而是可行性约束**：一个违规的提问，信息增益再大也不能发。这让 R69 的 MINT 从「算收益减成本」升级为「先在合法提问集里，再按词典序挑收益最大的」——非法则不问。而「问」又会改变受众后续的规范立场（观察者效应），所以质询的期望收益要算**反事实社会后果**，不能只算互信息。

**灵感 5（严格包含 → R69/R68 是 |𝔑|=1、B=1、无并发、ν=0 的退化）**
直觉：只要规范世界只有一个、并发度为一、没有规范冲突、质询无规范足迹，CONCORD 就应逐指令退化为 FLUID-RAS；再关掉交互就退化为 CALM-RAS。这保证新层不是并列的黑箱，而是旧层的严格泛化——否则每加一层「规范」「并发」，就多一个需要独立信任且无法与旧层对账的模块。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（CONCORD-RAS 总览）** CONCORD-RAS = (NGF, CIR, NCP, DASI, NLV, RAS-WM‡)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **规范快照一致性**：任何一次动作提交只读取单一 norm epoch τ 的规范快照 Snapshot(τ)，禁止跨 epoch 混读（对应数据库的 snapshot isolation）；
(iii) **交集安全**：提交的任务动作必须在**所有可采纳规范世界**下都被许可（SafePerm），不得以「多数允许」为由执行少数禁止的动作；
(iv) **有界活性**：并发协商在 τ_dl 内必须收敛或升级；不得无限等待、不得以并发为借口长期悬置（悬置本身可能违反救助类规范）。

**定义 311（规范框架与规范世界）** 规范框架 n = (C, φ, A, σ, E)：C 为上下文谓词（场景/时段/关系）；φ 为道义公式，取值 O（必须）/P（允许）/F（禁止），可带条件与时限；A 为受众/利益相关者集合；σ ∈ ℝ_{>0} 为优先级/强度；E 为例外集。规范世界 w ⊆ 𝔑 是一个道义一致的规范框架集（不含 O(a) 与 F(a) 同时无优先序失效的矛盾）。Adm(B) 为给定规范信念 B 下可采纳世界的集合。

**定义 312（规范证据半格与 join）** 规范证据 e = (src, n, polarity, weight, τ)，polarity ∈ {+1 支持, −1 撤销}。定义合并算子 ⊔ 为按 (src, n) 的带权证据累积并重新裁决极性，满足**交换律、结合律、幂等律**，构成 join 半格 (𝔼, ⊑, ⊔)。规范信念 B = ⨆_{e ∈ 已提交证据} e。撤销（defeasance）由 polarity=−1 与新证据的优先级比较实现，而不是删除历史：历史保留，结论可撤销。

**定义 313（并发推理运行时 CIR 与 norm epoch）** CIR 并行维护 B 个规范世界推理线程（B ≤ B_max，批处理为一次前向），并维护全局单调递增的 norm epoch τ。每次提交证据 +1 epoch；决策只读 Snapshot(τ)。定义陈旧度 Δτ = τ_now − τ_snapshot，并要求提交时 Δτ ≤ Δ_max，否则必须先刷新快照再验证（乐观并发控制）。一致性等级：**提交点串行化、提交间最终一致**。

**定义 314（可废止许可与动作集交集 DASI）** 在世界 w 下定义 Perm_w(a)（φ 为 P 或 O 且未触发例外）。交集安全许可：
SafePerm(a | B) ⇔ ∀ w ∈ Adm(B): Perm_w(a)。
执行集 A_exec(B) = { a ∈ A_task : SafePerm(a|B) ∧ 任务可行 }。若 A_exec = ∅，不得擅自放宽语义（不得退回多数投票），而必须进入定义 315 的协商/升级；协商失败即退化为 R69/R68 保守。规范被新证据撤销时用 retract 使旧结论失效并重算 A_exec。

**定义 315（规范并发协议 NCP）** 交互事务 = 提议（propose）→ 快照验证（validate）→ 提交（commit）。两类失败：
- **规范竞争（norm race）**：两个并发信息动作基于互相冲突的规范前提提交；检测为提交时 validate 发现所依赖的规范框架在同一 epoch 内被写。
- **社交死锁（social deadlock）**：多方相互让行/相互等待，无人推进。
协议：快照验证 + 锁无关 join + **有界指数退避** + τ_dl 超时升级。竞争不 last-writer-wins，而是合并证据并保留异议；死锁时按最小让步代价打破（让行成本低者先动），超时则升级为 R69 保守。

**定义 316（质询的规范足迹与合法性）** 信息动作 g 的规范足迹为 Leg(g|n) ∈ [0,1]：g 本身在框架 n 下被许可的程度（问隐私、反复确认、打断、向无关者求助均降低 Leg）。规范成本 ν(g) = 1 − min_{w∈Adm(B)} Leg(g|w)。**可行性质询集** G_leg = { g : ν(g) ≤ ν_max }。观察者效应：执行 g 后受众的规范立场按 T_norm(g) 转移，故 g 的收益须用反事实期望计算。

**定义 317（规范敏感 VoI NLV，词典序）** N-VoI(g) = LexMax( info_gain(g), −ν(g), −ρ_relation(g), −Δt(g) )，词典序保证**合法性优先于信息量**：非法提问无论增益多大都不选。g* = argmax_{g∈G_leg, budget.allow(g)} N-VoI(g)；当 |𝔑|=1 且 ν≡0 时，N-VoI 退化为 R69 的 VoI−c。若 max N-VoI ≤ 0：不交互，走 R69 兜底。

**定义 318（制裁监控与规范自适应 NSM）** 对他人反应观测制裁信号 s（皱眉、制止、回避、惩罚）与自身 φ-violation 事件，按贝叶斯/信誉更新规范强度 σ 与例外集 E；从他人的**不遵守**反推其真实规范（显示性偏好）。更新只写 AuditBuf 与规范库的离线副本，满足定义 310-i（实时流零学习写）。

**定义 319（规范—模态联合提交 JMC）** 联合状态 (M, w)：流策略给出动作模态 m_k，规范层给出 SafePerm。提交动作须同时满足：(i) a ∈ 模态 m_k 的支撑集；(ii) SafePerm(a|Snapshot(τ))。若某模态下无安全动作，则该模态作废；若所有模态都作废，则 λ 单调不降、退回 R68 最保守。此层只收缩动作集，不扩张安全包络。

**定义 320（异议保留与假共识护栏 DSP）** 合并保留少数框架集 D_B ⊂ Adm(B)，dissert_mass = Σ_{w∈D_B} β_w。定义共识置信 κ = 多数质量 × 源多样性校正。**定案条件**：κ ≥ κ_min 且 dissent_mass ≤ δ_D；否则认为处于「假共识风险」，保持 U_norm 未决、走协商或保守。合流性只用于保证可复现，绝不被当作正确性证明。

**定义 321（证书 J_CONCORD）** J_CONCORD = (J_FLUID, norm_epoch, B, κ, dissent_mass, safeperm_shrink, race_count, deadlock_count, staleness_p99, concord_ver)。Valid ⇔ Valid(J_FLUID) ∧ 快照一致 ∧ 有界活性满足 ∧ 交集安全未被绕过 ∧ 定案条件（定义 320）满足。

**定义 322（并发—规范干扰集 ℰ_conc）** ℰ_conc = ℰ_FLUID × ℰ_race × ℰ_deadlock × ℰ_normwash × ℰ_consensus。其中 ℰ_normwash 为恶意方宣称宽松规范以诱使越界；ℰ_consensus 为利用合流性把相关偏见包装成「全体一致」。并入 AIC-CONCORD。

**定义 323（退化边界与严格包含）** 当 |𝔑|=1、B=1、无并发写、ν≡0 时，CONCORD ≡ FLUID（R69）；再令永不交互（VoI≤成本），CONCORD ≡ CALM（R68）。即 R70 是 R69 在「单规范、单线程」边界上的退化，R69 是 R70 在「永不交互」边界上的退化。

**定义 324（规范优先级与冲突消解）** 只有当冲突框架之间存在**已声明的层级** σ 时才允许按优先级裁决（如安全 > 隐私 > 礼貌）；无层级声明时**禁止**自行排序，改用交集语义。该约束防止系统用自造的「常理」压过真实的规范多元。

```python
# IP-264 NGF：规范框架生成（冻结 LLM 解析 + 缓存，异步，不阻塞实时环）
def norm_frames(obs, ctx):
    n_list = []
    for text_or_scene in candidates(obs):
        n_list += frozen_llm.parse_deontic(text_or_scene, ctx)   # (C, φ, A, σ, E)
    return dedup_and_typecheck(n_list)                           # 道义一致性检查

# IP-265 CIR：并发推理 + 快照 + join 半格
class ConcurrentInference:
    def __init__(self, B_max=8, delta_max=2):
        self.worlds, self.epoch, self.evidence = [], 0, JoinSemilattice()
        self.B_max, self.delta_max = B_max, delta_max

    def snapshot(self):
        return Snapshot(epoch=self.epoch, belief=J.copy())

    def commit(self, ev):                 # 乐观并发：epoch 单调
        with self.lock:
            self.epoch += 1
            self.evidence = self.evidence ⊔ ev      # 交换/结合/幂等
            self.publish(Snapshot(self.epoch, self.evidence))

    def infer(self, snap):                # B 个规范世界批处理为一次前向
        return self.worlds.batch_forward(snap.belief, B=self.B_max)

# IP-267 DASI：交集安全许可（冲突时收缩，绝不按多数放宽）
def safe_action_set(A_task, belief):
    A_exec = []
    for a in A_task:
        if all(permits(w, a) for w in admissible(belief)):   # ∀ world
            A_exec.append(a)
    return A_exec                        # 空集 ⇒ 协商/升级，不得多数表决

# IP-268 NLV：合法质询优先于信息增益
def choose_query(modes, belief, budget):
    legal = [g for g in info_candidates(modes)
             if legitimacy(g, belief) >= 1 - NU_MAX
             and budget.allow(g) and c_ras_wm.certify_info(g)]
    if not legal: return None
    return lexmax(legal, key=lambda g: (info_gain(g), -nu(g), -rho(g), -dt(g)))

# IP-266 NCP：propose-validate-commit，防竞争/死锁，有界活性
def concurrent_interaction(proposal, cir, deadline=TAU_DL):
    for attempt in range(MAX_TRY):
        snap = cir.snapshot()
        if snap.epoch_stale() > DELTA_MAX:
            cir.refresh(); continue
        tx = build_tx(proposal, snap, deps=norm_deps(proposal))
        if validate(tx, cir):            # 依赖的规范前提未被并发写
            cir.commit(tx.evidence); return tx.result
        backoff(attempt)                 # 冲突 → 合并 + 保留异议，非 LWW
        if time_now() > deadline:
            break
    return escalate_to_r69()             # 死锁/超时 → 保守退化

# IP-269 DSP：异议保留，拒绝把合流性当正确性
def certify_consensus(belief, source_div):
    kappa = majority_mass(belief) * source_div
    ok = (kappa >= KAPPA_MIN) and (dissent_mass(belief) <= DELTA_D)
    return ok, kappa, dissent_mass(belief)

# IP-275 主闭环（继承 R69，在不确定性与动作提交处插入规范/并发层）
def CONCORD_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    frames = M.ngf.norm_frames(obs, M.ctx)                  # IP-264，异步缓存
    M.cir.ingest(frames)                                   # 证据合并（半格）
    snap = M.cir.snapshot()                                # 单一 norm epoch
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    A_task = feasible_actions(modes)
    A_exec = M.dasi.safe_action_set(A_task, snap.belief)   # 交集安全
    # 规范冲突且不可消解 → 直接最保守
    if not A_exec:
        return M.r68_conservative(o, reason="norm_conflict")
    # 合法且有利可图才问；问也要过 C-RAS-WM
    g = M.nlv.choose_query(modes, snap.belief, M.budget) if U_epi > TAU_EPI else None
    if g is not None:
        res = M.ncp.concurrent_interaction(g, M.cir)        # 事务式、有界
        snap = M.cir.snapshot()                            # 提交后重取快照
        A_exec = M.dasi.safe_action_set(A_task, snap.belief)
    # 假共识护栏：不合规则不判定，走协商/保守
    ok, kappa, dmass = M.dsp.certify_consensus(snap.belief, M.cir.source_div)
    if not ok:
        return M.r68_conservative(o, reason="false_consensus")
    a = select(A_exec, modes, lam_from_r69(U_cal))         # 交集中的最优模态动作
    return M.c_ras_wm.certified_prefix(a, ..., wm_preds)
```

## 3. 推导

**引理 19（规范推理的顺序无关性/合流）** 若证据合并 ⊔ 为交换、结合、幂等的 join 半格，且交互事务只做「加入证据」，则对任意并发调度 π，最终规范信念 B_π 相同。证：证据多重集的 join 与归并顺序无关；事务的 validate 只保证在提交时依赖未被破坏，不改变可提交证据集合的 join 值；撤销以 polarity 记录而非删除，故不破坏半格结构。意义：跨轮可复现与可审计；但它**只**说明收敛，不说明正确（见引理 21）。

**引理 20（快照一致 ⇒ 决策可串行化）** 若每次动作提交只读单一 epoch 的 Snapshot(τ) 且提交时 Δτ ≤ Δ_max 或先刷新，则所有提交可线性化到一个等价串行历史。证：标准 snapshot isolation 论证；读集取自同一快照，写集在提交点原子并入。故不存在「读到半合并规范」的规范竞争型越界。

**定理 18（交集安全 / 无规范越界）** 执行 a ∈ A_exec(B) 保证在任意 w ∈ Adm(B) 下 Perm_w(a)；因此在模型正确时不会违反任一可采纳规范。当 |𝔑|=1 时 A_exec 退化为单框架许可集，即 R69 的动作集。代价用**规范收缩率** shrink = 1 − |A_exec|/|A_task| 度量：多规范冲突下 shrink↑ 是安全的代价，而不是失败；A_exec=∅ 时禁止多数表决放宽。

**定理 19（有界活性 / 无死锁）** 在有界退避、τ_dl 超时与最小让步打破下，NCP 必在 τ_dl 内返回「已提交」或「升级为 R69/R68 保守」之一；不存在无限等待或无限竞争。且升级路径上 λ 单调不降，继承 R69 定理 17 的无突变性。故并发不引入新的安全违约，只可能引入效率损失。

**引理 21（假共识界与异议保留的必要性）** 设并发证据源共享偏见比例 ρ_b，则纯 join 后的「共识」错误率下界随 ρ_b 单调上升，即使 κ 很高；引入异议保留与源多样性校正后，可定案集合被限制在 dissent_mass ≤ δ_D，错误率上界 ≈ ρ_b·(1−δ_D) + ε_σ。故合流性越强，越需要 DSP 作为反作用力——效率（顺序无关）与正确性（防偏见放大）在此处是**相反方向**的两个需求。

**引理 22（合法质询的观察者效应界）** 若仅允许 ν(g) ≤ ν_max 的质询，则质询诱发的规范违约期望 ≤ ν_max + E[ΔΦ_obs(g)]，其中 ΔΦ_obs 为受众立场转移。N-VoI 词典序把合法性置于信息量之前，故不存在「为拿信息而违规提问」的解；当 ν≡0 时退化为 R69 VoI，观察者效应在单框架下可忽略。

**定理 20（CONCORD 严格包含 R69/R68）** 在 A99–A102（单规范、单线程、ν=0）下，CONCORD 与 FLUID 逐指令相同；当 N-VoI ≤ 0 时与 CALM 逐指令相同。故安全侧不弱于旧层，新增能力仅在「多规范/并发」被真正触发时提供，且总是以收缩动作集而非扩张包络的方式提供。

## 6. 本轮最大风险

**一句话**：CONCORD 的合流性只保证「无论交互如何交错都会收敛到同一个规范信念」，**却不保证该信念正确**——若各并发线程共享同一份有偏的规范先验，系统会以顺序无关、可复现、可审计的方式**自信地收敛到错误规范**；更糟的是，交集安全在规范冲突时会退化为「什么都不做」，而「见危不救」本身可能违反最高优先级的救助规范——**用瘫痪换来的安全，是一种被合流性掩盖的失败**。

**次级风险与缓解**：
1. **假共识（合流放大偏见）** → DSP 异议保留 + 源多样性校正 + κ/dissent_mass 双门 + E306；
2. **交集为空导致瘫痪** → 定义 314 禁止放宽、但定义 315 有界升级；对「救助类」规范设不悬置约束（存活活性），并显式区分「无动作可做」与「合法动作被收缩」；
3. **规范洗白/恶意宽松规范** → 源信誉 + 层级声明（定义 324）+ ℰ_normwash 对抗训练 + E307；
4. **规范竞争/死锁** → 快照隔离 + 事务提交 + 有界退避 + τ_dl 升级（定理 19）；
5. **跨文化规范错置** → 未声明层级时禁止自造优先级，统一走交集与保守退化 + E314。

```python
def norm_frames(obs, ctx):
    return dedup_and_typecheck(
        [n for x in candidates(obs)
           for n in frozen_llm.parse_deontic(x, ctx)])   # (C,φ,A,σ,E)

class ConcurrentInference:

        return Snapshot(epoch=self.epoch, belief=self.evidence.copy())
    def commit(self, ev):

            self.epoch += 1
            self.evidence = self.evidence ⊔ ev             # 交换/结合/幂等
            self.publish(self.snapshot())
    def infer(self, snap):

        return M.r68_conservative(o, "norm_conflict")
    g = M.nlv.choose_query(modes, snap.belief, M.budget) if U_epi > TAU_EPI else None
    if g is not None:
        M.ncp.concurrent_interaction(g, M.cir)
        snap = M.cir.snapshot()
        A_exec = M.dasi.safe_action_set(feasible_actions(modes), snap.belief)
    ok, kappa, dmass = M.dsp.certify_consensus(snap.belief, M.cir.source_div)
    if not ok:
        return M.r68_conservative(o, "false_consensus")
    a = select(A_exec, modes, lam_from_r69(U_cal))
    return M.c_ras_wm.certified_prefix(a, ..., wm_preds)
```

## 4. 推导

**引理 19（顺序无关性/合流）** 若 ⊔ 为交换、结合、幂等的 join 半格且事务只加入证据，则任意并发调度 π 的最终规范信念 B_π 相同；撤销以 polarity 记录而非删除，不破坏半格。意义：可复现、可审计；但只保证收敛，不保证正确。

**引理 20（快照一致 ⇒ 决策可串行化）** 每次提交只读单一 epoch 且 Δτ≤Δ_max 或先刷新，则所有提交可线性化到等价串行历史，不存在「读到半合并规范」导致的越界。

**定理 18（交集安全 / 无规范越界）** `a∈A_exec(B)` 在任意 `w∈Adm(B)` 下 `Perm_w(a)`，故模型正确时不违反任一可采纳规范；`|𝔑|=1` 时退化为 R69。代价用 shrink 度量；`A_exec=∅` 时禁止多数表决放宽。

**定理 19（有界活性 / 无死锁）** 有界退避 + τ_dl + 最小让步打破 ⇒ 必在 τ_dl 内提交或升级为 R69/R68 保守；升级路径 λ 单调不降，继承 R69 定理 17 无突变。并发不引入新安全违约，只可能引入效率损失。

**引理 21（假共识界）** 共享偏见比例 ρ_b 越高，纯 join 的共识错误率下界越高，即使 κ 很高；加 DSP 后定案集被限制在 dissent_mass≤δ_D，错误率上界 ≈ `ρ_b·(1−δ_D)+ε_σ`。故合流越强越需异议保留——顺序无关（效率）与防偏见放大（正确性）方向相反。

**引理 22（合法质询的观察者效应界）** 仅允许 `ν(g)≤ν_max` 的质询时，诱发违约期望 ≤ `ν_max + E[ΔΦ_obs(g)]`；N-VoI 词典序使「为信息而违规提问」无解；ν≡0 时退化为 R69 VoI。

**定理 20（严格包含 R69/R68）** 单规范、单线程、ν=0 时与 FLUID 逐指令相同；N-VoI≤0 时与 CALM 逐指令相同。新增能力只在多规范/并发被触发时提供，且只收缩动作集、不扩张安全包络。

## 7. 本轮最大风险

**一句话**：CONCORD 的合流性只保证「无论交互如何交错都会收敛到同一个规范信念」，**却不保证该信念正确**——若并发线程共享同一份有偏的规范先验，系统会以顺序无关、可复现、可审计的方式**自信地收敛到错误规范**；而交集安全在规范冲突时会退化为「什么都不做」，但「见危不救」本身可能违反最高优先级规范——**用瘫痪换来的安全，是一种被合流性掩盖的失败**。

**次级风险与缓解**：假共识（DSP 异议保留 + 源多样性 + κ/dissent 双门 + E306）；交集为空致瘫痪（禁止放宽 + 有界升级 + 救助类规范不悬置约束）；规范洗白（源信誉 + 已声明层级 + ℰ_normwash + E307）；竞争/死锁（快照隔离 + 事务 + 有界退避 + τ_dl，定理 19）；跨文化错置（无层级不自造优先级，统一交集与保守退化 + E314）。
