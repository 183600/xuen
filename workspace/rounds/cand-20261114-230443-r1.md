# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「腕部相机」×「数据配比」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配多模态策略显式表示歧义，用注视/探针/问句这些信息动作去消解它。但 R69 暗中假设了两件事：
> (a) **证据是外生的、可自由选择的**——好像「看一眼」不花代价、不改变世界、也不受身体约束；
> (b) **一条证据的可信度只取决于它的物理通道**——好像腕部 RGB、第三人称 RGB、力觉，只要「模态不同」就自动「正交」。
>
> 本轮两个灵感恰好各击穿一个假设：
> - **腕部相机**说明观测是**内生的、动作耦合的**：相机长在手上，你看到什么，取决于你把手指向哪里；看近处会遮挡、会碰撞、会消耗执行器，而且手眼标定一漂，看到的与走到的就一起错。视角不是一个免费的标量，而是一个**有身体、有风险、有标定误差的动作**。
> - **数据配比**说明可信度是**挣来的、有额度的**：模型在腕部视角上是否可信，不取决于腕部相机多好，而取决于训练配比里腕部数据占多少、覆盖了哪些物体/位姿/光照。全局 ECE 达标可以完美掩盖一个「只占 0.1% 部署流量、却 100% 失准」的局部盲区。
>
> 核心命题：**给每条证据发一张「可信度护照」——记录它来自哪个通道（provenance）、由哪个视角动作产生（viewpoint）、落在训练配比的哪个覆盖单元（coverage）；任何证据的使用置信度不得超过护照允许的额度。覆盖不足、护照缺失、或证据之间只是「换了张皮的同源物」，一律不得定案，只能降级或转人工。** 命名 **WRIST-RAS**（Wrist-view, Ratio-aware Information-Source Trust for risk-adaptive closed loop，腕部视角 × 配比感知的信息源信任）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这条证据凭什么可信、它是在我被允许看见的地方产生的吗**」——信任不是通道的属性，而是（通道 × 视角 × 配比覆盖 × 标定）的联合属性，且它是一种**预算**：只能在训练时付过费的地方花。

## 0. 直觉与动机

**灵感 1（腕部相机 → 观测是动作的后果，不是世界的免费投影）**
直觉：第三人称相机像「上帝视角」，它看到的是世界本来的样子；腕部相机像「你自己的眼睛长在手背上」，它看到的是**你决定把手伸到哪里之后**世界剩下的样子。这带来四个 R69 没有的物理事实：
1. **视角改变状态**：为了看清，手臂要动；手臂一动，任务状态、可达性、碰撞风险全变。信息动作不是「旁观的测量」，而是「介入式的测量」。
2. **信息与风险同源**：最 informative 的视角（钻进缝隙、贴近目标、绕过遮挡）往往正是最危险、最容易自遮挡、最容易碰翻东西的视角。于是 VoI 与风险**正相关**，分开优化会系统性低估风险。
3. **手眼标定漂移**：腕部视角的误差 `δ_he` 会同时污染「看到的」与「走到的」；近距离时同样的角误差造成更大的像素位移，故 `δ_he` 的危害随 `1/depth` 放大。这恰恰是 R68 最害怕的**被标定吸收的缓变故障**：残差被 COF 抹平，却在腕部近景上以「覆盖错位」的形式泄漏。
4. **回路的自选择性**：视角由策略选，所以部署分布是内生的。策略越倾向去自己熟悉的高置信视角，低覆盖视角就越没人看，数据就越少，模型就越不自信，于是更不去看——一个自我强化的**覆盖坍缩**不动点。

**灵感 2（数据配比 → 可信度是「付过费的额度」，不是传感器的固有属性）**
直觉：一个模型 90% 用第三人称、10% 用腕部数据训练，它在第三人称上会很自信，在腕部上会很脆——**与腕部相机的硬件好坏毫无关系**。可信度不是「这条证据来自哪个模态」，而是「这个模态 × 这个视角 × 这个物体属性 × 这个位姿，在训练配比里被覆盖了多少、被校准得多好」。更关键的是：
- 全局校准会**撒谎**：一个只占部署 0.1% 的透明物体腕部近景单元，即使局部 ECE=0.4，对全局 ECE 的贡献也只有 0.0004；全局指标漂亮，盲区依旧致命。
- 数据配比是一个**可控变量**：既然可信度是覆盖的函数，那就可以反过来，用部署中暴露的覆盖缺口去**主动调整下一轮配比**——把「数据配比」从训练超参提升为闭环里的一个控制量，甚至提升为安全证书的一部分。
- 但配比也会**反噬**：优化覆盖会过拟合部署、遗忘罕见但致命的安全场景；而「用部署数据补覆盖」本身会制造自选择偏差。数据配比既是解药，也是新的攻击面。

**灵感 3（两条灵感合并 → provenance 独立性 ≠ 模态多样性）**
直觉：R69 的证据纪律是「k 个正交来源一致才定案」。这条纪律有一个致命漏洞：**同源失效（common-mode failure）**。同一只腕部相机的两张 crop、同一次曝光下的 RGB 与深度、同一次标定下的腕部与本体——它们「看起来是不同源」，实际上共享镜头、共享遮挡、共享标定误差、共享数据分片。一旦腕部相机被油污糊住，你问它十次，它会十次一致地骗你。所以「正交」必须在 **provenance（数据分片 × 物理通道 × 标定参数 × 产生它的视角动作）** 上度量，而不是在特征空间或模态名称上度量。**两个 crop 不是一个证据；同一分片的两条数据不是一个证据。**

**灵感 4（理论姿态：WRIST 必须是 FLUID 与 R68 的严格泛化）**
直觉：WRIST-RAS 不推翻 R69，而是给 R69 的每条证据补上「护照」与「额度」。当覆盖处处均匀（`C_α≡1`）、视角动作退化为 R69 的注视（不改变状态）、provenance 独立时，WRIST 逐指令等于 FLUID；当不移动视角、不交互时，进一步逐指令等于 R68。安全侧永不弱于前两轮：**覆盖不足时不是「更激进地用信息」，而是「更早地承认自己没资格用信息」**。

**灵感 5（新威胁模型 → 证书可能变成洗白机制）**
直觉：一旦系统学会给自己的证据发证书，最大的危险不是证书不够多，而是**证书本身被伪造或误发**。一个错误的覆盖估计器会给「它恰好看不见的盲区」盖上「已覆盖」的章；一个被污染的数据分片会让 `provenance_hash` 看起来干净；一个缓慢漂移的手眼标定会让局部 ECE 在重标定窗口内暂时「合格」。于是**盖了章的盲区比没盖章的盲区更危险**——因为它把「未知的未知」洗成了「已审计的许可」。本轮必须正面交付：provenance 图、覆盖估计的置信下界、配比下限、以及「证书自审」的审计器。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（WRIST-RAS 总览）** WRIST-RAS = (VPM, PCM, PIT, ACM, DMC, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i，数据配比更新只发生在离线/换装窗）；
(ii) **证据护照完整**：任何进入决策的证据 e 必须携带 `(σ, v, κ, ν)`（通道、产生它的视角动作、覆盖单元、版本），缺任一项即丢弃；
(iii) **信任受覆盖约束**：e 的可用置信度与似然权重不得超过其覆盖条件证书允许的额度 `T(e)`；覆盖不足 ⇒ 不得高置信使用，只能走定义 321 的三级降级。

**定义 311（腕部视角动作与内生化观测）** 视角动作 `v = (q_v, τ_v, zoom_v) ∈ 𝒱(s) ⊂ SE(3)×ℝ_+×ℝ_+`，`q_v` 为腕部到达位姿，`τ_v` 为驻留，`zoom_v` 为变焦。观测模型
`y = h(s, v; θ_he) + n，n ~ 𝒩(0, Σ_view)`，
其中 `θ_he` 为手眼标定参数、`δ_he(t)` 为其漂移。与 R69 的 `g_gaze` 的本质区别：`v` **改变状态**（`s' = T(s, a, v)`）、**占用执行器**、受可达性/碰撞/自遮挡 `Ω(v)` 约束；观测是**动作条件的**（`do(v)` 下的 `p(y|s, do(v))`），不是外生投影。称此类证据为**内生化证据**。

**定义 312（证据护照 / provenance）** 证据 `e = (y, σ, v, κ, ν)`：`σ ∈ Σ` 为物理/信息通道（腕部 RGB、腕部深度、第三人称、力/触、本体、语言回答）；`v` 为产生它的视角动作；`κ ∈ 𝒦` 为覆盖单元（视角区域 × 物体属性 × 任务相位 × 光照的离散化）；`ν` 为版本（模型/标定/数据配比/分片指纹）。

**定义 313（数据配比与覆盖质量）** 训练配比 `π_train ∈ Δ^{S−1}`，S 个数据源/分片（第三人称、腕部、仿真、真机、遥操作纠正、失败回放、语言标注…）。覆盖质量 `C_α(κ) = P_{π_train}(κ)`（或用有效样本量 `n_eff(κ)` 的置信下界，见定义 314）。部署诱导配比 `π_dep(v)`。定义**覆盖缺口** `G(κ) = D(π_dep(·|κ) ‖ π_train(·|κ))` 与**覆盖风险** `R_cov = Σ_κ P_dep(κ)·[c_min − C_α(κ)]_+`。

**定义 314（覆盖估计的置信下界）** 用 Dirichlet/Clopper–Pearson 或 bootstrap 给每个单元的覆盖一个**下置信界** `C_α(κ) = LCB_{1−α}(n_eff(κ), N)`，而不是点估计。证书只用下界——**宁可低估覆盖，不可高估覆盖**（与 R68「任何不确定 → 只收紧」同构）。

**定义 315（覆盖条件校准 CCC）** 在覆盖单元 κ 上定义局部校准误差
`ECE_κ = Σ_b (|B_b|/n_κ)·|acc(B_b) − conf(B_b)|`。
全局 ECE 是 `ECE_κ` 的部署加权和加上一个配比错配偏移项（引理 20）；**全局达标不蕴含局部达标**。

**定义 316（证据可信额度 Trust Quota）** 
`T(e) = clip( f(1−ECE_κ, C_α(κ), 1−ρ_prov(e, ℰ_past), (1−δ_he/δ_max)_+) , 0, T_max )`。
额度同时限制**置信**与**似然权重**：在 Bayes 更新中，e 的似然取温度 `T(e)` 次幂（`p(y|m)^{T(e)}`），`T=0` 即该证据被忽略。这样「不可信」不是二值丢弃，而是连续降权，避免硬切换造成控制抖动。

**定义 317（provenance 独立性与有效证据数）** 证据集 `ℰ` 的 provenance 相关矩阵 `ρ_prov(i,j) ∈ [0,1]`，由共享的（数据分片, 物理通道, 标定参数, 产生视角动作）加权得到；**provenance 独立**当且仅当 `ρ_prov(i,j) < ρ_0` **且** `κ_i ≠ κ_j`。定义有效独立证据数（Kish 型）
`k_eff = (Σ_i T_i)² / Σ_{i,j} T_i T_j ρ_prov(i,j)`。
两个 crop、同一腕部相机的连拍、同一分片的两条数据，`ρ_prov→1`，对 `k_eff` 几乎无贡献。

**定义 318（视角 VoI 与风险耦合）** 
`VoI_view(v) = I(M; Y_v | o, do(v)) = H(M|o) − E_{y~p(·|o,do(v))} H(M|o,y)`。
但 `v` 有双成本：执行/时间成本 `c_act(v)` 与物理风险 `r(v)`（碰撞、自遮挡导致负信息、越界、标定敏感）。二者**相关**：最 informative 的视角常在杂乱/危险区。故选择问题是**联合约束**而非分离约束：
`max_{v∈𝒱(s)} E[VoI_view(v) − c_act(v)]  s.t.  CVaR_β(r(v)) ≤ ε_int，v 可达且 Ω(v) 有效`，
并输出 Pareto 前沿；若前沿上无可行点 ⇒ 不移动视角，退回 R69 的保守交互。

**定义 319（主动覆盖采样 ACM）** 数据配比是可控变量。给定覆盖缺口与部署流，求下一轮增量
`Δπ* = argmax_{Δπ∈Δ, ‖Δπ‖_1 ≤ B} Σ_κ P_dep(κ)·ΔC_α(κ) − λ_f·ForgetRisk(Δπ) − λ_s·1[critical_drop(Δπ)]`，
`ForgetRisk` 用旧分布上的 KL/Fisher 对齐估计；安全关键单元设硬下限（定义 324）。ACM 只在离线/换装窗执行。

**定义 320（覆盖门控的证据纪律）** 可用证据集 `ℰ_use = {e : T(e) > τ_T}`。当 `k_eff(ℰ_use) < k_min` ⇒ 不得定案：优先补一条**不同 provenance** 的证据（换通道而非换 crop），其次才考虑换视角；若补不到或新证据与旧证据 `ρ_prov > ρ_0`，则走降级。R69 的「k 个正交源」在此严格升级为「`k_eff` 个 provenance 独立且被覆盖」。

**定义 321（覆盖受限三级退避）** 
(a) **丢弃级**：未覆盖证据非关键 ⇒ 丢弃它，用已覆盖证据继续（比 R69 更保守）；
(b) **弃权级**：关键证据未覆盖或 `k_eff` 不足 ⇒ 不交互、不动作，转人工/遥操作或 R68 纯保守；
(c) **补证级**：覆盖处于临界 ⇒ 只允许发起**元动作**（重标定、补采数据、请求人类示范），该元动作不进入实时安全路径。
三级之间 λ 单调不降，绝不因「想看更多」而放松安全包络。

**定义 322（手眼标定–视角耦合）** 腕部视角残差 `r_he = ‖y_wrist − h(s,v;θ_he)‖`；`δ_he` 同时污染观测与视角执行（看到的和走到的错位）。R68 的 COF 可能把 `δ_he` 的慢变分量吸收掉（`r_res≈0`），但腕部近景会**放大**它：同样的角误差在近距离产生更大的像素位移。故门限随 `1/depth` 缩放：`δ_he,max(d) = δ_0·d/d_0`。这给 R68「缓变故障被标定吸收」提供了一个具体的物理载体。

**定义 323（反馈回路的自选择偏差与覆盖坍缩）** 因 `v` 由策略选择，部署分布内生：`π_dep = π_dep(π_θ)`。若策略倾向高置信视角，则低覆盖单元访问概率 `a(κ)` 下降 ⇒ 数据更少 ⇒ 置信更低 ⇒ 更不访问，形成**覆盖坍缩不动点**。要求对安全关键单元设**探索下限** `a(κ) ≥ ε_cov`，并由 ACM 的增配比补偿维持。

**定义 324（配比中的安全关键下限）** 对安全关键单元集 `𝒦_safe`，要求 `C_α(κ) ≥ c_safe, ∀κ∈𝒦_safe`；否则系统在这些单元**不得自主运行**（证书直接失效）。这把「数据配比」从训练超参提升为安全证书的一部分：不是「模型表现好不好」，而是「你根本没有资格在这里自主」。

**定义 325（时序与预算继承）** 护照签发与覆盖查询 O(1) 哈希；`|ℰ| ≤ 6`、`|𝒱| ≤ 8`，故 `k_eff` 与视角枚举均 O(1) 量级；加入 R69 的交互预算。默认 `K=1` 不变；覆盖不足时**禁止升 K**（升 K 只会放大不可信模态分布），而是降级。

# IP-264 VPM：腕部视角动作 + 内生化观测（世界观不再是免费的）
class WristViewPolicy:
    def reachable_views(self, s):
        return [v for v in SE3_candidates(s)
                if self.reach.ok(v) and self.collision.ok(v)]
    def observe(self, s, v):                         # 动作条件的观测 do(v)
        y = self.h(s, v, self.theta_he) + sample_noise(self.Sigma_view)
        return y, self.theta_he, self.delta_he

# IP-265 PCM：覆盖单元 + 局部校准 + 覆盖下界
def coverage_cell(y, sigma, v, ctx):
    return hash((view_bin(v), obj_attr(ctx), task_phase(ctx), light_bin(ctx)))

def issue_passport(e, pcm):
    kappa = coverage_cell(e.y, e.sigma, e.v, e.ctx)
    e.kappa = kappa
    e.coverage = pcm.lcb(kappa, alpha=0.05)          # 置信下界，不是点估计
    e.ece      = pcm.local_ece(kappa)
    return e

# IP-266 PIT：可信额度 + provenance 独立性 + 有效证据数
def trust_quota(e, pcm, past):
    rho = provenance_corr(e, past)                   # 共享分片/通道/标定/视角
    he  = max(0.0, 1.0 - e.delta_he / delta_max(e.depth))
    return clip(calib_map(1 - e.ece) * cov_map(e.coverage)
                * (1 - rho) * he, 0.0, T_MAX)

def k_eff(evidence):
    T = np.array([e.quota for e in evidence])
    P = provenance_corr_matrix(evidence)             # 对角线为 1
    return (T.sum() ** 2) / (T @ P @ T + 1e-9)

# IP-269 ViewVoI：VoI 与风险联合（CVaR），不分开优化
def choose_view(modes, s, budget):
    best = None
    for v in wrist.reachable_views(s):
        if not budget.allow(v) or not self_occlusion_ok(v):
            continue
        voi  = H(modes) - expected_H(modes, v, s)    # do(v) 条件
        cvar = cvar_risk(v, s, beta=0.95)
        score = voi - act_cost(v) - lambda_r * cvar
        if best is None or score > best.score:
            best = (v, score, cvar)
    return best if best and best.score > 0 and best.cvar <= EPS_INT else None

# IP-270 主闭环：R69 的流策略/标定不变，只升级「证据层」
def WRIST_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K))
    # 1) 每条证据先签发护照，额度不足直接丢

    if M.pit.k_eff(ev) < K_MIN:

## 3. 推导

**引理 19（视角信息增益的耦合界）** 在动作条件观测下，可达集 `𝒱(s)` 与自遮挡 `Ω(v)` 共同限制可获得信息：
`I(M; Y_v | o, do(v)) ≤ H(M|o) − E_{y}[H(M | o, y, Ω(v))]`。
且在杂乱场景中，`∂VoI_view(v)/∂r(v) ≤ 0` 的可行域占优——最 informative 的视角集中于高风险区。故 `argmax VoI` 与 `argmin risk` 一般不重合，**分离优化会系统性高估净收益**；必须用 CVaR 联合约束。系：R69 的「看—问—做」若忽略视角的身体成本与风险，会把系统推向「为了看清而冒险伸手」。

**引理 20（全局校准不能保证局部校准）** 设可靠曲线对特征 Lipschitz 常数为 `L`，则
`ECE_glob = Σ_κ P_dep(κ)·ECE_κ + Δ_mix`，且 `|Δ_mix| ≤ L·TV(π_dep, π_train)`。
因此即使 `ECE_glob ≤ τ`，一个低覆盖单元（`P_dep(κ)` 很小）仍可有 `ECE_κ` 任意大而对全局几乎无贡献。**全局 ECE 越低，越容易成为盲区的遮羞布**。系：校准必须按覆盖单元预算，证书必须逐单元签发（定义 315、320）。

**引理 21（同源失效下的证据纪律上界）** 设单通道被误导概率为 `δ_p`，`k` 条证据的 common-mode 相关为 `ρ_prov`（以概率 `ρ_prov` 全体一起被误导）。则多数一致后的错误率
`P(err) ≤ ρ_prov + (1−ρ_prov)·δ_p^{k}`。
当 `ρ_prov → 1` 时任意 `k` 都无效。故 R69 的「k 个正交源」必须替换为 `k_eff`（定义 317）；**增加同一相机的 crop/连拍不是增加证据，只是增加重复**。

**定理 18（WRIST 严格包含 FLUID 与 R68）** 在 A99–A101 下：(i) 当 `C_α(κ)≡1`、视角动作退化为不改变状态的 R69 注视、且证据 provenance 独立时，WRIST 与 FLUID 逐指令相同；(ii) 当不发起任何交互/视角动作时，两者进一步逐指令等于 R68。故 WRIST 是 FLUID 在「覆盖充足 + 视角无身体」边界上的退化，又是 R68 在「不交互」边界上的退化；安全侧不做任何让步。

**定理 19（覆盖门控的安全上界）** 在 A102–A104 下，若所有进入决策的证据满足 `C_α(κ) ≥ c_min`、`ECE_κ ≤ τ_ece`、`δ_he ≤ δ_max(depth)`，则未识别的分布偏移导致的残余 epistemic 风险被覆盖预算 `ε_cov` 控制，闭环期望风险 `≤ R_69 + ε_cov`；若任一条件不满足，系统按定义 321 单调退化为 R68 保守，`λ` 只增不减。**结论：覆盖不是效率指标，而是安全预算；没付够数据费的地方，系统不许自负。**

**定理 20（反馈回路不坍缩）** 在 A104（探索下限 `a(κ) ≥ ε_cov`）+ ACM 的遗忘约束下，安全关键单元的覆盖下界不随时间单调下降，内生部署分布不会收敛到某个真子集上。反之，若 `ε_cov = 0`，存在策略使 `𝒦_safe` 的覆盖趋于 0 而全局指标仍「良好」——这正是覆盖坍缩。系：**数据配比是闭环稳定性的参与者，不是训练结束就冻结的常数。**

## 6. 本轮最大风险

**一句话**：WRIST-RAS 把「可信」定义为「被覆盖」，于是整个方案的安全都押在**覆盖估计器与 provenance 图是诚实的**这一前提上——一旦覆盖被低估（过度保守、系统瘫痪）或被高估（把恰好看不见的盲区盖章为已覆盖），证书就从「审计」退化为「洗白」：**盖了章的盲区比没盖章的盲区更危险，因为它把未知的未知合法化成了可自主行动**。

**次级风险与缓解**：
1. **覆盖估计的抽样偏差与置信下界过松** → 用 LCB 而非点估计 + 关键单元 `c_safe` 硬下限 + E314 证书自审；
2. **provenance 图被污染/伪造**（分片指纹、标定参数被篡改）→ `provenance_hash` 链 + VQAuditor-P 异步审计 + 分片来源签名；
3. **手眼漂移被重标定窗口暂时吸收** → 定义 322 的 `1/depth` 门限 + R68 残差通道 + 引理 19 的联合检出；
4. **覆盖坍缩（自选择偏差）** → 探索下限 `ε_cov` + ACM 遗忘约束 + 定理 20 的监测；
5. **配比过拟合部署 / 遗忘安全场景** → ForgettRisk 惩罚 + 关键单元硬下限 + E309 长时程回放；
6. **视角动作本身越界** → CVaR 联合约束 + 可达/自遮挡过滤 + 三级退避，绝不把「看得更清」当作放松安全包络的理由。

    he  = max(0.0, 1.0 - e.delta_he / delta_max(e.depth))
    return clip(calib_map(1 - e.ece) * cov_map(e.coverage)
                * (1 - rho) * he, 0.0, T_MAX)

def k_eff(ev):
    T = np.array([e.quota for e in ev])
    P = provenance_corr_matrix(ev)                   # 对角线 1
    return (T.sum() ** 2) / (T @ P @ T + 1e-9)

## 4. 推导

**引理 19（视角信息增益的耦合界）** 动作条件观测下，可达集与自遮挡限制可获得信息：
`I(M;Y_v|o,do(v)) ≤ H(M|o) − E_y[H(M|o,y,Ω(v))]`；杂乱场景中 `∂VoI_view/∂r ≤ 0` 的可行域占优，最 informative 视角集中于高风险区。故分离优化会系统性高估净收益，必须 CVaR 联合约束。系：R69 的「看—问—做」若忽略身体成本，会为看清而冒险伸手。

**引理 20（全局校准不能保证局部校准）** `ECE_glob = Σ_κ P_dep(κ)ECE_κ + Δ_mix`，`|Δ_mix| ≤ L·TV(π_dep,π_train)`。故 `ECE_glob ≤ τ` 时，低覆盖单元仍可 `ECE_κ` 任意大而对全局几乎无贡献——全局越漂亮，越可能成为盲区遮羞布。系：校准与证书必须逐覆盖单元签发。

**引理 21（同源失效下的证据纪律上界）** 设单通道误导概率 `δ_p`，common-mode 相关 `ρ_prov`，则 `P(err) ≤ ρ_prov + (1−ρ_prov)δ_p^k`；`ρ_prov→1` 时任意 k 无效。故「k 个正交源」须替换为 `k_eff`；同相机的 crop/连拍只是重复，不是证据。

**定理 18（WRIST 严格包含 FLUID 与 R68）** A99–A101 下：(i) `C_α≡1` + 视角退化为 R69 注视 + provenance 独立 ⇒ 逐指令等于 FLUID；(ii) 不发起交互/视角动作 ⇒ 进一步等于 R68。WRIST 是 FLUID 在「覆盖充足 + 视角无身体」边界、R68 在「不交互」边界上的严格退化，安全侧不让步。

**定理 19（覆盖门控的安全上界）** A102–A104 下，若进入决策的证据满足 `C_α(κ)≥c_min`、`ECE_κ≤τ_ece`、`δ_he≤δ_max(depth)`，则未识别分布偏移的残余 epistemic 风险被覆盖预算 `ε_cov` 控制，闭环风险 `≤ R_69+ε_cov`；任一条件不满足即按定义 321 单调退化为 R68。结：覆盖是安全预算，不是效率指标。

**定理 20（反馈回路不坍缩）** 在探索下限 `a(κ)≥ε_cov` + ACM 遗忘约束下，安全关键单元覆盖下界不随时间单调下降，内生部署分布不收敛到真子集。否则存在策略使 `𝒦_safe` 覆盖趋 0 而全局指标仍「良好」——覆盖坍缩。系：配比是闭环稳定性的参与者，不是冻结常数。

## 7. 本轮最大风险

**一句话**：WRIST-RAS 把「可信」定义为「被覆盖」，于是安全全押在覆盖估计器与 provenance 图诚实这一前提上——覆盖被高估时，证书从审计退化为洗白：**盖了章的盲区比没盖章的盲区更危险，因为它把未知的未知合法化成了可自主行动**。

**次级风险与缓解**：覆盖抽样偏差/下界过松（LCB + `c_safe` 硬下限 + E314 自审）；provenance 被污染/伪造（hash 链 + VQAuditor-P + 分片签名）；手眼漂移被重标定吸收（`1/depth` 门限 + R68 残差 + 引理 19 联合检出）；覆盖坍缩（探索下限 + 遗忘约束 + 定理 20 监测）；配比过拟合/遗忘（ForgetRisk 惩罚 + 关键下限 + E309 回放）；视角动作越界（CVaR + 可达/自遮挡过滤 + 三级退避）。
