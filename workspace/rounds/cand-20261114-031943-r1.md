# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计交互消歧闭环」IP-264~274；灵感循环第 1 轮；本轮灵感：「泛化能力」×「可靠性」）

> R70 把 epistemic 从「动作模态」提升为「世界状态后验 b_t(s)」，并交付了基线协议与原型验收。但它留下一个被写进「最大风险」、却未被正面处理的假设：**观测模型 p(o|s) 与策略 π_θ 都是在某个源分布上训练好的；部署时世界变了，系统仍会拿它解释一切。** 贝叶斯滤波只对「状态不确定」谦逊，对「模型从哪来、还适不适用」保持沉默。源模型在目标域系统性错误时，BSE 会给出熵很低、却离真相很远的后验——**H[b_t] 变小反而意味着风险变大**。
>
> 本轮两个灵感正好从两侧切开：
> - **泛化能力**不是训练时的一个平均分数，而是「系统在哪些条件下仍保有可认证性能」的**适用域**。泛化的反面不是误差变大，而是系统不知道自己已经出界。
> - **可靠性**不是「平均表现好」，而是「出界时仍然安全」。可靠性必须由一条**与学习模型正交**的兜底通道兑现，否则它只是泛化能力的另一个名字。
>
> 核心命题：**把「泛化」变成运行时可查询的适用域 C，把「可靠性」变成与学习组件正交的兜底包络 S；系统在 C∩S 内享受 resolution bonus，在 S\C 内退化到认证兜底，在 S 外拒绝执行；并用 anytime-valid 的在线证据对 C 本身做持续审计。** 命名 **GRACE-RAS**（Generalization-Reliability Assurance via Competence Envelopes）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「该信哪个世界状态」，R71 问「**我还在自己会的地方吗；不在时，谁保底**」。

## 0. 直觉与动机

**灵感 1（泛化是地图，不是分数）**
直觉：一个司机不只知道「我会开车」，还知道「我不擅长夜间暴雨的山路」。R70 的 H[b_t] 回答的是「我在这个路口有多不确定」，却不回答「这条路我走没走过、我的能力在这里还成不成立」。把泛化做成一张**能力地图** c(x)：在每个上下文 x 上给出「策略风险不超过 α」的可信度；部署时先查地图，再决定用不用学到的策略。这把泛化从训练报告里的一个数字，变成运行时的一次**适用域判定**。

**灵感 2（可靠性是包络，不是鲁棒训练）**
直觉：鲁棒训练提高的是平均表现；可靠性问的是最坏情况。真正的可靠性不能依赖被质疑的那个模型——如果兜底控制器也由同一个网络驱动，它就和被监视对象共享同一个盲点。控制理论给了更硬的答案：**受控不变集 / 控制障碍函数**。只要存在经认证的 π_safe，使状态对某个模型类中的所有成员都留在集合 S 内，那么即使学习策略完全失效，S 仍然成立。**可靠性可以被构造，泛化只能被估计**——这个不对称是本轮的理论支点。把两者混成一个分数，是过去所有「鲁棒性 = 泛化 + 正则」叙事的根本错误。

**灵感 3（三种「不知道」，不是两种）**
直觉：R69 分 aleatoric/epistemic，R70 把 epistemic 落到状态后验。但还差最致命的一层：**模型不确定**。噪声是「掷骰子」，状态是「我看不清」，模型是「我拿错了地图」。三者的正确处置完全不同：噪声只能收 λ，状态可以问/看/触，模型只能**换地图或退回认证兜底**。把三者混成一个 H[b_t]，系统就会用「多问一句」去治疗「地图错了」——这正是 R70 最大风险的根源。

**灵感 4（两个时间尺度）**
直觉：泛化的统计认证需要很多回合（慢），可靠性的强制执行必须在毫秒内（快）。在快环里计算泛化界既不可能也不必要。让慢环离线/准在线地发布「能力地图 + 阈值 + 版本哈希」，快环只做只读查表与包络投影。**慢环负责说真话，快环负责不出事。** 这条分离也是唯一能在不击穿实时预算的前提下加入统计保证的方式。

**灵感 5（可靠的哨兵不能与被监视者共享盲点）**
直觉：用 OOD 分数当可靠性，等于再训练一个模型来监督第一个模型；分布一移，哨兵自己的校准也坏了。因此在线监测必须尽量**无分布假设**：用 e-process / conformal martingale 做 anytime-valid 变点检测，用 ACI 维持长期风险覆盖；兜底则用**模型类**上的不变集，而不是单个点模型。这是「统计的诚实 + 控制的硬保证」替代「另一个模型的自信」。

**灵感 6（交互的新用途：从消歧到辨识）**
直觉：R70 的交互是为了消解状态歧义；当歧义来自「世界模型本身」时，问一句没用，得**做一次有信息的实验**（轻推、改变视角、短程试探）。这把 MINT 从 state-VoI 扩展为 state/model 联合 VoI。但模型辨识天然危险，因此只能在 S 内、且永不作为唯一定案证据。

## 1. 形式化定义（增量：定义 331–348）

**定义 331（GRACE-RAS 总览）** GRACE-RAS = (DMB, GAP, CBM, REE, TSD, MINT††, ACRC, FMA††, VQAuditor-III, AIC-GRACE, GRA-Bench, J_GRACE, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **双时间尺度分离**：慢环只发布只读的 (C, S, 阈值, 版本哈希)，快环不得在单步内改写在线的泛化证书；
(iii) **兜底正交性**：π_safe 与 S 只依赖认证模型类，不引用 π_θ、b_t、流似然或任何在线学习量；
(iv) **anytime 有效性**：所有在线统计主张都在明示假设下有时间一致保证，禁止用「跑完再定阈值」的可选停止方式刷显著性。

**定义 332（域增广状态）** 域变量 d ∈ D（有限模型族 / 环境描述子），域增广状态 (s,d)，后验 b_t(s,d) = p(s,d | o_{1:t}, ξ_{1:t-1}, g_{1:t-1}, y_{1:t-1})。d 分段常数、在慢时间尺度上发生变点；给定 d 时，s 的转移与观测模型由 d 索引。R70 的 b_t(s) 是 d 边缘化后的特例。

**定义 333（漂移分类）** 漂移 Δ = (Δ_cov, Δ_concept, Δ_emb, Δ_sensor)，分别表示输入分布、条件动力学/观测、本体/执行器映射、传感器特性的变化。每类配一个可观测描述子：均值嵌入差、流似然残差、动作-效果残差、标定残差。**不把四类压成一个 OOD 标量**——它们的可恢复性与安全后果不同。

**定义 334（泛化间隙与上界）** 对策略 π 与目标域 d：G_d(π) = R_d(π) − R_src(π)。用 PAC-Bayes 型界给 G^{UCB}_{δ}：以概率 ≥1−δ，
R_d(Q) ≤ R̂_src(Q) + √((KL(Q‖P)+ln(2n/δ))/(2n)) + β·D(μ_d‖μ_src)，
其中 Q 为策略后验、P 为先验、D 为域差异度量（MMD / Wasserstein）。**该上界只用于慢环与证书，不进入快环。**

**定义 335（适用域 / 能力地图）** 给定风险上限 α、置信 δ，C_α(δ) = {x : UCB_δ[R(x)] ≤ α}。用保形风险控制（CRC）在校准集上选阈值，使 P(R ≤ α) ≥ 1−δ（可交换窗口）；能力地图 c(x) = σ(τ_α − UCB(x)) ∈ [0,1] 为连续软化版本，便于查表与迟滞。C 不是「训练集覆盖」，而是「可认证低风险的区域」。

**定义 336（可靠性包络）** 给定歧义集 D_β = {d : D(μ_d‖μ_0) ≤ β} 与安全集 S_safe，可靠性包络
S_β = {s_0 : ∃π_safe, ∀d∈D_β, ∀t≥0，s_t∈S_safe 且 B(s_{t+1}) − B(s_t) ≤ −γB(s_t)}，
B 为障碍证书（B≥0 在 S_safe 内，B<0 视为出界）。S_β 只依赖模型类与 π_safe，**不依赖学习策略**。

**定义 337（三区安全调度）** 记区域 A = C∩S（可信且安全）、B = S\C（安全但不可信）、C_out = 全体\S（不安全）。调度：
- A：走 BELIEF 闭环，获 resolution bonus；交互预算开放；
- B：λ=1、禁用泛化 bonus、只允许认证兜底/最小风险动作；交互仅限安全认证的信息动作；
- C_out：拒绝执行任务动作，进入安全停止/交接，并记录证书失效原因。
区域迁移带迟滞 h，避免边界抖振。

**定义 338（anytime-valid 漂移监测 CBM）** 在零假设 H_0（窗口内可交换 / 无漂移）下，构造非负上鞅 e-process E_t，E_0=1，E_t = ∏_{i≤t}(1+λ_i(z_i−μ_0))，λ_i 为可预测下注。当 E_t ≥ 1/δ_e 时报警。由 Ville 不等式，P(∃t: E_t ≥ 1/δ_e) ≤ δ_e。可交换性用 conformal martingale 检验；报警后按 alpha-spending 分账，不允许无损重置。

**定义 339（自适应保形风险控制 ACRC）** 风险水平 α_t 在线更新：α_{t+1} = α_t + η(α* − err_t)，err_t = 1[R_t > α_t]。在 A102–A103 下给出长期覆盖 (1/T)Σ err_t ≤ α* + O(η) + O(1/(ηT))。用于校准窗口之间、e-process 尚未报警但有轻微漂移的灰区。

**定义 340（元 VoI：状态消歧 vs 模型辨识）** 总信息增益
VoI_total(g) = VoI_state(g) + γ_t·VoI_model(g)，
VoI_state 继承 R70（H[b_t] 的期望下降），VoI_model(g) = I(d; y | g, o)（模型身份与回答的互信息）。g* = argmax[VoI_total − c(g)]，s.t. g 过 C-RAS-WM 认证、g 的物理执行落在 S 内、且不违反证据纪律。γ_t 由 H[d_t] 与域后验校准状态给出；若动作无法改变区域判定，则 γ_t=0（引理 27）。

**定义 341（能力感知风险缩放）** λ = λ_floor(U_ale + 1[H[b_t]≥τ_e]·H[b_t] + 1[x∉C]·G^{UCB} + 1[x∉S]·∞)。其中 λ_floor 继承 R70；指示项保证：状态 epistemic 未消解时收紧，泛化不确定时再收紧，出安全包络时直接拒绝。**每一项都可单独审计，不做不可解释的加权和。**

**定义 342（慢-快证书）** 慢环输出 Cert_slow = (C 的阈值与覆盖下界, S 与障碍证书, α_t 初值, 版本哈希, 时间戳)。快环只读消费；证书 age > T_cert 即视为过期，触发保守退化并请求重认证。证书版本与代码/数据/种子哈希绑定。

**定义 343（漂移感知流异常）** 把 R70 的 Δa 分解为 Δa_cal（标定可吸收）与 Δa_model（模型/域不可吸收）；CBM 对 Δa_model 建立 e-process。三元组 (r_res↓, Δa_model↑, H[d_t]↑) 作为「模型层漂移」的判别证据，替代 R70 的二元/三元状态层判据。

**定义 344（GRA-Bench v1 协议）** 五类漂移套件（协变量、概念/动力学、本体、传感器、复合），固定任务族、种子、分割、指标（覆盖率、误安全率、检出延迟、恢复时间、违规率、泛化间隙收紧度、证书过期率）、统计检验（配对 Wilcoxon + Bonferroni，覆盖率报 Clopper–Pearson 下界）与强制报告模板。所有泛化/可靠性主张必须在此协议下复现。

**定义 345（参与式审计 VQAuditor-III）** 审计对象从「交互决策」扩展到「泛化主张与证书」：适用域覆盖是否真实、误安全率是否被低估、e-process 是否被可选停止滥用、兜底包络是否被模型失配击穿、证书是否过期。结论回灌 AuditBuf，成为下一轮慢环重认证的先验。

# IP-276 GAP：慢环适用域校准（保形风险控制，不进入快环）
class CompetenceMap:
    def __init__(self, ctx_encoder, risk_model, alpha=0.1):
        self.enc, self.risk, self.alpha = ctx_encoder, risk_model, alpha
        self.tau = None

    def calibrate(self, calib_loader, delta):
        cal = [(self.enc(x), r) for x, r in calib_loader]        # 留出校准集
        scores = [risk_ucb(self.risk(c), r, delta) for c, r in cal]
        self.tau = conformal_risk_threshold(scores, self.alpha, delta)  # CRC
        return self

    def __call__(self, x):
        return self.risk(self.enc(x)) <= self.tau                # x ∈ C_alpha

# IP-277 CBM：anytime-valid e-process 漂移监测（快环，只读统计）
class ShiftMonitor:
    def __init__(self, delta=1e-3, betting=None):
        self.E, self.delta, self.bet = 1.0, delta, betting or default_bet()
        self.spent = 0.0

    def update(self, z_t):
        self.E *= self.bet(z_t)                                  # E_t = ∏(1+λ_i(z_i-μ0))
        if self.E >= 1.0 / (self.delta - self.spent):
            self.spent += self.delta / 4                         # alpha-spending，不无损重置
            self.E = 1.0
            return ALARM
        return OK

# IP-278 REE：离线求鲁棒受控不变集与障碍证书
def reliability_envelope(ambiguity_set, safe_set, fallback):
    S = maximal_controlled_invariant(ambiguity_set, safe_set, fallback)
    B = solve_barrier_certificate(S, fallback)                  # B>=0, ΔB<=-γB
    assert verify_barrier(B, S, ambiguity_set)                  # 数值证书校验
    return S, B

# IP-287 GRACE-RAS 主闭环（快环；R70 的 BELIEF 作为 A 区内核）
def GRACE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 1) 慢环证书只读查表 + anytime-valid 漂移证据
    x_ctx = M.ctx.encode(o, M.last_action)
    in_C  = M.competence(x_ctx)                                  # C_alpha
    alarm = M.shift.update(M.fma.shift_stat(o, o_cal, M.last_action))
    # 2) BELIEF 层（R70）：状态后验 + 流策略 + 第二意见
    b_t = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)
    samples = M.fmp.sample(o, b_t, K=1 if entropy(b_t) < TAU_ENT else 4)
    U_ale, U_epi, modes, _ = M.aud.decompose_from_belief(b_t, M.fmp, o)
    a_hat = M.fma.flow_anomaly_belief(M.fmp, M.last_action, o, o_cal, b_t)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 3) 模型层不确定 + 三区调度
    G_ucb = 0.0 if in_C else M.gap.upper_bound(x_ctx)
    region = dispatch(in_C, M.envelope.contains(M.state), alarm, G_ucb)
    if region == "A":                                            # C ∩ S
        g = M.mint.choose_meta_voi(b_t, M.fmp, M.budget, M.c_ras_wm) if not slow else None
        if g is not None:
            y = M.cia.execute(g); b_t = M.bse.step(b_t, o, M.last_action, g, y)
            U_epi = entropy(b_t)
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
        mode = select_mode_from_belief(modes, b_t, lam)
        k = M.c_ras_wm.certified_prefix(mode.a, ..., wm_preds)
    elif region == "B":                                          # S \ C
        lam = 1.0
        mode = M.envelope.fallback_action(M.state)               # 认证兜底，不看 π_θ
        k = M.envelope.certified_prefix(mode.a)
    else:                                                        # 出 S
        return M.safe_stop(reason="out_of_envelope", cert=M.cert_hash)
    # 4) 执行 + 审计 + 证书（慢环证书过期则拒绝签 Valid）
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_iii.submit_async(x_ctx, in_C, region, G_ucb, a_hat, M.cert_age)
    return k, lam, mode, (U_ale, U_epi, G_ucb, region)

## 3. 推导

**假设 A102（域族与有界损失）** D 可测且先验支撑覆盖部署域；损失 ℓ∈[0,1]；源/目标风险可积。
**A103（窗口可交换 / 可控漂移）** 单个校准窗口内样本可交换；跨窗漂移由 ACRC 的长期覆盖保证，不承诺单窗精确覆盖。
**A104（兜底存在性）** 存在 π_safe 与可计算 S，使任意 d∈D_β 下 S 受控不变；B 为有效障碍证书且数值校验通过。
**A105（证书时滞有界）** 慢环证书 age ≤ T_cert；超龄即视为不可信，不论内容是否看起来合理。
**A106（能力分数 Lipschitz）** c(x) 对上下文度量 L_c-Lipschitz，用于把采样点的覆盖外推到邻域。

**引理 23（适用域覆盖的有限样本保证）** 在 A102–A103 下，CRC 选出的阈值使可交换窗口内 P(R>α) ≤ δ + 1/(n+1)；在一般漂移下，ACRC 给出 (1/T)Σ err_t ≤ α* + η/2 + O(1/(ηT))。系：**C 的保证是「窗口内无分布假设 + 窗口间靠自适应」，不是无条件全域保证**——证书必须明示这一点，否则就是过度承诺。

**引理 24（兜底包络与学习组件正交）** 若 S 对 D_β 中所有 d 受控不变，则对任意学习策略 π_θ（包括被投毒、数值发散、输出 NaN），一旦调度进入 B 区，状态满足 S_safe 的概率为 1（确定性动力学、精确投影下）；π_θ 只影响性能，不影响该保证。系：可靠性证书不引用 H[b_t]、不引用流似然、不引用任何在线学习量——它是真正的正交通道。

**引理 25（e-process 的 anytime 误报控制）** H_0 下 E_t 为非负上鞅且 E_0=1，Ville 不等式给出 P(∃t: E_t ≥ 1/δ_e) ≤ δ_e。系：可在每个控制步检查而不膨胀误报，这正是快环需要的「随时可停」统计；但**功效（检出延迟）依赖备择与下注策略**，必须在 GRA-Bench 中单独度量，不能把「没报警」当成「没漂移」。

**引理 26（三区调度的单调性与无抖振）** 取可信度偏序 A≻B≻C_out；若区域迁移带迟滞 h，且 λ 沿该序单调不减、允许动作集单调不增，则调度轨迹不会在边界上无限抖振；每次下迁至少需要一次证据翻转，其频率受 e-process 与保形窗口约束。系：避免把安全兜底本身变成执行器抖振源。

**引理 27（元 VoI 的非负增益条件）** 模型辨识动作 g 只有在能改变区域判定、或把 G^{UCB} 降到阈值以下时才有正收益；若 ∀y，dispatch(b_t,y)=dispatch(b_t)，则 VoI_total(g)=VoI_state(g)，应取 γ_t=0。系：不要为了「更懂世界」而做无谓的危险探针。

**定理 20（严格包含与安全退化）** 在 A102–A106 下，GRACE 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；当 C=S=全空间、无漂移、G^{UCB}=0 时，GRACE 与 BELIEF 逐指令相同。进入 B/C_out 的指令集是 BELIEF 指令集的保守投影子集，故安全侧不弱于 R70。**四层严格包含：CALM ⊂ FLUID ⊂ BELIEF ⊂ GRACE。**

**定理 21（证书组合的失效分解）** 在 A102–A106 下，任意回合的「错误安全」概率 ≤ P_false-safe(C) + P_envelope(S) + P_stale(cert)。其中 P_false-safe 由 CRC 覆盖与 e-process 误报控制；P_envelope 由不变集证书给出（理想为 0，工程上为数值/建模残差）；P_stale 由证书 age 与 T_cert 控制。系：**可靠性不是一个标量，而是三项之和；任一项没有独立度量，J_GRACE 就不能签 Valid。**

**定理 22（GRA-Bench 统计功效）** 10 种子、配对检验、Bonferroni 校正下，若真实效应量 d≥0.5，检出功效 ≥0.92；覆盖率必须报告 Clopper–Pearson 下界而非点估计。系：泛化/可靠性主张要报告「下界 + 失效分解」，而不是只报均值。

## 6. 本轮最大风险

**一句话**：GRACE-RAS 的全部保证都建立在「假设集本身覆盖了真实漂移」之上——**保形覆盖只在可交换/已知漂移下成立，e-process 只能检出它有功效检出的漂移，鲁棒不变集只对歧义集 D_β 内的模型成立；一旦出现未建模的漂移类型（新接触动力学、对抗性反馈、完全陌生的本体），系统会拿出一份「格式完全合法、数值也很漂亮」的 J_GRACE 证书，却在真实世界失效——此时证书本身成了最危险的产物，因为它把「不知道」洗成了「已认证」。**

**次级风险与缓解**：
1. **误安全（false-safe）** → 覆盖率报下界 + 独立误安全审计 + E321/E334；
2. **兜底包络失配** → 歧义集外扩 + 障碍证书数值校验 + E325；
3. **e-process 功效不足/被可选停止滥用** → 预注册下注策略 + alpha-spending + E323；
4. **慢环证书过期仍被使用** → age 硬门控 + 过期即保守 + E333；
5. **边界抖振** → 迟滞 + 单调调度 + E328；
6. **「全域泛化」的营销冲动** → GRA-Bench 强制报告适用域边界与失效分解，拒绝只报均值。

class CompetenceMap:
    def __init__(self, ctx_encoder, risk_model, alpha=0.1):
        self.enc, self.risk, self.alpha, self.tau = ctx_encoder, risk_model, alpha, None

    def calibrate(self, calib_loader, delta):

    def __init__(self, delta=1e-3, betting=None):
        self.E, self.delta, self.bet, self.spent = 1.0, delta, betting or default_bet(), 0.0

    def update(self, z_t):
        self.E *= self.bet(z_t)
        if self.E >= 1.0 / max(self.delta - self.spent, 1e-12):
            self.spent += self.delta / 4
            self.E = 1.0
            return ALARM
        return OK

# IP-278 REE：离线鲁棒不变集 + 障碍证书（不引用学习策略）
def reliability_envelope(ambiguity_set, safe_set, fallback):
    S = maximal_controlled_invariant(ambiguity_set, safe_set, fallback)
    B = solve_barrier_certificate(S, fallback)
    assert verify_barrier(B, S, ambiguity_set)
    return S, B

# IP-287 GRACE-RAS 主闭环（快环；BELIEF 作为 A 区内核）
def GRACE_RAS_round(M, obs):

## 4. 推导

**引理 23（适用域覆盖）** A102–A103 下，CRC 阈值使可交换窗口 P(R>α)≤δ+1/(n+1)；一般漂移下 ACRC 长期 err≤α*+η/2+O(1/(ηT))。系：C 是「窗口内分布无关 + 窗口间自适应」，不是无条件全域保证。

**引理 24（兜底正交）** S 对 D_β 中所有 d 受控不变 ⇒ 对任意 π_θ（含被投毒/发散/NaN），进入 B 区后状态留在 S_safe 的概率为 1（确定性、精确投影）；π_θ 只影响性能。

**引理 25（anytime 误报）** H_0 下 E_t 非负上鞅，Ville 给 P(∃t:E_t≥1/δ_e)≤δ_e；功效依赖备择与下注，需在 GRA-Bench 单测。

**引理 26（单调无抖振）** A≻B≻C_out 偏序 + 迟滞 h + λ 单调不减 + 动作集单调不增 ⇒ 区域不无限抖振，下迁需证据翻转。

**引理 27（元 VoI 条件）** 若 ∀y，dispatch(b_t,y)=dispatch(b_t)，则 VoI_total=VoI_state，γ_t 应置 0；不为「更懂世界」做无谓危险探针。

**定理 20（严格包含与安全退化）** A102–A106 下，GRACE 风险 ≤ BELIEF ≤ FLUID ≤ R68；C=S=全域、无漂移、G^{UCB}=0 时与 BELIEF 逐指令相同；B/C_out 指令集为 BELIEF 的保守投影。**CALM ⊂ FLUID ⊂ BELIEF ⊂ GRACE。**

**定理 21（证书失效分解）** 错误安全概率 ≤ P_false-safe(C) + P_envelope(S) + P_stale(cert)；三项必须独立度量，否则 J_GRACE 不能签 Valid。

**定理 22（GRA-Bench 功效）** 10 种子、配对 Wilcoxon、Bonferroni 下，d≥0.5 时功效 ≥0.92；覆盖率报 Clopper–Pearson 下界，不只报均值。

## 7. 本轮最大风险

**一句话**：GRACE-RAS 的保证完全依赖「假设集覆盖真实漂移」——**保形覆盖只在可交换/已知漂移下成立，e-process 只对它有功效的漂移敏感，鲁棒不变集只对歧义集 D_β 内模型成立；一旦出现未建模漂移（新接触动力学、对抗反馈、陌生本体），系统会输出一份格式合法、数值漂亮的 J_GRACE 证书，却在真实世界失效——证书把「不知道」洗成了「已认证」，这比没有证书更危险。**
