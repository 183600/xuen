# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「交互设计」×「模型蒸馏」）

> 第 54 轮把云端技能组合推进到动作剖面 `α_S`、组合图 `SCOM` 与云边协同 `γ_ce`。本轮换一个更“人”的视角：**交互设计**与**模型蒸馏**。二者共享同一个深层结构——**知识不是被单向搬运的，而是在一个被设计出来的界面（representation + mapping + feedback）里，通过一次次可观察的交互被共同建构的**。核心矛盾：**H22**：传统蒸馏把边端学生当作被动接收器、把界面当作中性管道，但“能蒸馏什么”其实由界面决定，教师的能力常以学生无法表达的形式存在，导致 `答案对而可供性缺失`；**H23**：交互设计把“执行鸿沟 / 评估鸿沟”当作可设计的量，而云边蒸馏恰恰没有设计过自己的界面——学生做不到的说不出口，教师看不见学生为什么失败，形成 **沉默的无能（silent incapacity）**，且平均蒸馏损失会把它完全掩盖。

## 0. 直觉与动机

**灵感 1（可供性剖面 → 蒸馏的对象不是策略，而是“情境—动作”关系）**
直觉：交互设计的第一性概念是 **affordance（可供性）**：不是“物体有什么属性”，而是“对某个行动者而言，此刻能做什么”。因此教师真正该交给学生的，不是它在自身动作空间里的策略 `π_T(a_T|o)`，而是**可供性剖面** `φ_T(o,a)`——在情境 `o` 下动作 `a` 的可达程度。策略是教师特有的实现，换个本体、换个夹爪就失效；可供性则是可迁移的“能力形状”。这直接接续第 54 轮的 `α_S`：`α_S` 只描述“动作空间占用”，本轮把它升格为“**情境条件下的可供性**”，并回答“蒸馏到底在传什么”。

**灵感 2（执行的鸿沟与评估的鸿沟 → 蒸馏的两个失效面）**
直觉：Norman 把人与系统的失配拆成 **执行的鸿沟**（想做的事系统做不了）与 **评估的鸿沟**（系统做了什么、为什么失败，人看不见）。云边蒸馏恰有同构的两条缝：`G_exec`——教师的粗动作无法在学生的细动作空间里被表达；`G_eval`——学生的失败无法被教师观测与解释。第 54 轮的 `Explain` 回传只是一个**事后、有损**的评估通道；交互设计要求把这两条鸿沟当作**可度量、可设计**的对象：通过改表示、改映射、改反馈来缩小，而不是靠加大模型容量硬压。

**灵感 3（最近发展区与可教性 → 不是所有教师技能都该被蒸馏）**
直觉：教育心理学的 **最近发展区（ZPD）** 说：只有在“跳一跳够得着”的区间里，脚手架才有效；远超学生当前能力的知识，硬教只会造成机械记忆与负迁移。蒸馏同理：技能 `S_T` 是否可教，是 `(S_T, 学生当前状态 S_S^0, 界面 I)` 的**三元谓词**，而不是 `S_T` 的固有属性。落在 ZPD 内的技能才蒸馏；落在 ZPD 外的高价值技能应改走**重组**（第 54 轮 SCOM）或**云端卸载**（第 54 轮 CEC）。这把蒸馏从“无脑压缩”变成“**可教性驱动的路由**”。

**灵感 4（脚手架课程与淡出 → 蒸馏是交互过程，不是一次拟合）**
直觉：交互设计强调 **scaffolding（脚手架）与 fading（淡出）**：先做给你看（worked example），再带着你做（guided practice），最后让你独立做（independent practice）。一次性 KD 把所有情境、所有温度、所有监督信号一次性压进去，等价于“从不让教师逐步撤手”。本轮把蒸馏写成一条 **课程** `C`：教师支持强度 `β` 单调下降；先用高温柔软标签与示范教高鲁棒维度，再用纠错反馈教脆弱维度，最后学生独立执行、教师只做评估。这把“蒸馏 = 拟合教师输出”改写为“**蒸馏 = 设计一段能让学生长出自我的交互史**”。

**灵感 5（交互账本 → 让蒸馏可复核、可审计）**
直觉：好的交互设计是**可预期、可追溯**的：每一次操作都有可见反馈。给蒸馏配一本 **交互账本 `L`**：记录 `(情境 o_t, 学生动作 a_t, 结果 y_t, 教师纠错 f_t)`。证书不再只声明“学生学会了”，而是声明“**用这本账本能复演出这个学生**”。这把第 54 轮的 `J=(ρ,A_cert,γ_ce,δ_a)` 扩展为 `IDC=(φ_S,G_exec,G_eval,κ_T,C,L)`——一个**可回放**的交互蒸馏证书。

**灵感 6（金字塔加一层：交互—蒸馏层 IXD）**
直觉：在鲁棒性层与动作—协同层之上，再加 **交互—蒸馏层 `𝕏`**：`𝕏_0` 原始感知运动，`𝕏_1` 可供性/示能（signifier），`𝕏_2` 脚手架课程，`𝕏_3` 交互账本与证书。跨层迁移必须同时满足 `ρ`、`A_cert` 与 `IDC`——鲁棒、动作可对齐、且**确实被教过**，三者缺一不可。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（情境可供性剖面 Affordance Profile）**
情境空间 `O`，动作空间 `A`（承接定义 115 的 `A=A_c×A_e`）。技能 `S` 的可供性剖面
```
φ_S : O × A → [0,1],    φ_S(o,a) = α_S(a) · σ_S(o,a)
```
其中 `α_S` 为第 54 轮的动作占用剖面，`σ_S(o,a)` 为情境可行性门控。**示能集** `A_S(o) = { a∈A : φ_S(o,a) ≥ θ_φ }`。可供性距离
```
d_φ(φ,φ') = sup_{o∈O_τ} W_1( φ(o,·)/Z(o), φ'(o,·)/Z'(o) ; d_A )
```
`W_1` 为动作度量 `d_A` 上的 1-Wasserstein 距离，`O_τ` 为任务相关情境，`Z` 为归一化常数。关键：`φ_S` 可通过交互被**观测**，而不依赖教师内部权重，因此它是可迁移、可验证的对象。

**定义 122（蒸馏界面 Distillation Interface）**
界面 `I = (R, γ, β, F)`：
- `R`：传输表示（logits / 可供性 / 关系三元组）；
- `γ : A_T → 2^{A_S}`：教师动作到学生动作的**集值**映射（粗→细，允许一对多）；
- `β ∈ [0,1]`：脚手架强度，`β=1` 为全示范，`β=0` 为完全放手；
- `F : L → Δθ_S`：反馈通道，把交互账本转成学生的更新。
界面投影后的“可表达教师” `φ_T^I(o,a_S) = sup_{a_T : a_S∈γ(a_T)} φ_T(o,a_T)`。**界面是设计变量，而非固定管道**：改变 `(R,γ,F)` 会改变可教集合。

**定义 123（蒸馏双鸿沟 Two Gulfs of Distillation）**
- **执行鸿沟**：教师偏好动作中无法被学生动作空间表达的质量
```
G_exec(φ_T,φ_S,I) = E_{o~P_τ}[ 1 - ∫_{a∈γ(A_S)} φ_T(o,a) da ]
```
- **评估鸿沟**：学生失败中教师无法观测的部分（归一化互信息亏空）
```
G_eval = 1 - I(F_S ; Z_T) / H(F_S)
```
`F_S` 为学生失败指示，`Z_T` 为教师经 `F` 得到的观测。二者均在 `[0,1]`，可分别用可达性分析与账本上的互信息估计。部署要求 `G_exec ≤ Δ_e ∧ G_eval ≤ Δ_v`。

**定义 124（可教性与最近发展区 Teachability / ZPD）**
给定学生初态 `φ_S^0`、界面 `I`、交互预算 `K`。技能 `S_T` 是 `(ε,δ)`-可教的，当且仅当存在脚手架序列 `β_1 ≥ … ≥ β_K` 与账本交互，使 `K` 轮后
```
sup_{o∈O_τ} W_1( φ_S^K(o,·), φ_T^I(o,·) ) ≤ ε  ∧  min_{d} ρ_S^K(d) ≥ ρ_min   (以概率 ≥ 1-δ)
```
成立。**最近发展区** `ZPD(S_S^0,I) = { S_T : S_T 可教 }`。可教性分数 `κ_T(S_T) = P(在 K_max 轮内达到 ε)`。注意 `ZPD` 依赖界面：换一个表示或反馈通道，同一技能可能从“不可教”变为“可教”。

**定义 125（脚手架课程 Scaffolding Curriculum）**
课程 `C = ((o_1,β_1),…,(o_K,β_K))`，`β_1 ≥ … ≥ β_K`，分三相：
- **示范相**（worked，`β≈1`）：教师演示高鲁棒维度的正确可供性；
- **引导相**（guided，`0<β<1`）：学生尝试、教师纠错，`F` 提供方向；
- **独立相**（independent，`β=0`）：学生独做，教师只评估、不再给动作。
课程成本 `Cost(C)=Σ_t c_int(o_t,β_t)`。目标：在预算与鲁棒约束下最大化被覆盖的 `ZPD` 体积（或任务成功率下界）。

**定义 126（交互蒸馏证书 Interaction Distillation Certificate, IDC）**
```
IDC = (φ_S, G_exec, G_eval, κ_T, C, L, h_L)
```
`L = ((o_t,a_t,y_t,f_t))_{t=1..K}` 为交互账本，`h_L` 为其哈希承诺，`replay(L)` 须能在误差 `ε_r` 内复现 `φ_S`。可部署当且仅当
```
G_exec ≤ Δ_e ∧ G_eval ≤ Δ_v ∧ κ_T ≥ τ_t
∧ min_d ρ_S(d) ≥ ρ_min ∧ replay_err(L) ≤ ε_r
```

## 2. 关键算法 伪代码

### IP-121 AAP（Affordance Alignment Profiling）

```python
def affordance_profile(skill, contexts, actions, sampler, theta_phi=0.5):
    phi = {}
    for o in contexts:
        for a in actions:
            reach, conf = sampler.query(skill, o, a)   # 结构化仿真/真机探针
            phi[(o, a)] = conf if reach else 0.0
    return phi

def affordance_distance(phi_t, phi_s, O_tau, d_A):
    # 逐情境归一化后做 1-Wasserstein；只比较任务相关情境
    return max(wasserstein_1(normalize(phi_t[o]), normalize(phi_s[o]), d_A)
               for o in O_tau)

def stratify_active_sample(skill, phi, budget):
    # 主动采样：优先覆盖高 φ 的示能边界与低置信区
    return bandit_loop(skill, priority=lambda o,a: boundary_score(phi,o,a)
                                         + 0.5*uncertainty(phi,o,a), budget=budget)
```

### IP-122 DGG（Distillation Gulf Gauge）

```python
def distillation_gulfs(phi_t, phi_s, gamma, ledger, O_tau):
    g_exec = 0.0
    for o in O_tau:
        reachable = support(gamma.apply(phi_s[o]))
        g_exec += 1.0 - mass(phi_t[o], inside=reachable)
    g_exec /= len(O_tau)
    F = [1 - success(r) for (_, _, r, _) in ledger]
    Z = [observable(f) for (_, _, _, f) in ledger]
    g_eval = 1.0 - mutual_info(F, Z) / max(entropy(F), 1e-9)
    return g_exec, g_eval
```

### IP-123 TDR（Teachability-Driven Routing）

```python
def route_skill(skill, phi_s, interface, budgets):
    kappa = estimate_teachability(skill, phi_s, interface, budgets.K_max)
    if kappa >= budgets.tau_t:
        return ('distill', kappa)
    comp = scom_reachable(skill, phi_s)            # 复用第 54 轮 SCOM
    if comp.feasible and comp.robustness >= budgets.rho_min:
        return ('recompose', comp.path)
    return ('offload', cec_contract(skill))        # 复用第 54 轮 CEC
```

### IP-124 SCF（Scaffolding Curriculum with Fading）

```python
def scaffold_curriculum(skills, phi_s, interface, K_max):
    order = sort_by_robustness_then_failure(skills, phi_s)   # 先教鲁棒维度
    C, beta = [], 1.0
    for t, s in enumerate(order):
        phase = ('worked' if beta > 2/3 else
                 'guided' if beta > 0 else 'independent')
        C.append((s, phase, beta))
        obs = interact(s, beta, interface)
        if obs.success and obs.gulf_delta < interface.eps_g:
            beta = fade(beta)          # 学生达标才撤脚手架
        if obs.failure and phase == 'independent':
            beta = min(1.0, beta + 0.25)  # 独立失败则回退加脚手架
    return C
```

### IP-125 ICL（Interaction Correction Ledger）

```python
def interaction_ledger(student, teacher, interface, K):
    L = []
    for t in range(K):
        o = select_context(teacher.uncertainty, student.failure_set)
        a_s, y_s = student.act(o)
        f_t = teacher.observe_and_correct(o, a_s, y_s)   # 可见反馈
        L.append((o, a_s, y_s, f_t))
        student.update(o, a_s, y_s, f_t, beta=interface.beta(t))
        interface.update_from_feedback(f_t)
    return Ledger(L, h_L=commit(L))
```

### IP-126 IDC（Interaction Distillation Certificate）

```python
def interaction_distillation_certificate(student, teacher, interface, ledger, B):
    phi_s = student.affordance
    g_exec, g_eval = distillation_gulfs(teacher.phi, phi_s, interface.gamma,
                                        ledger, B.O_tau)
    kappa = estimate_teachability(teacher.phi, phi_s, interface, B.K_max)
    if g_exec > B.Delta_e:  return ('reject', 'execution_gulf', g_exec)
    if g_eval > B.Delta_v:  return ('reject', 'evaluation_gulf', g_eval)
    if kappa < B.tau_t:     return ('reject', 'not_teachable', kappa)
    if min(student.rho.values()) < B.rho_min:
        return ('reject', 'robustness_loss', student.rho)
    if replay_error(ledger, student) > B.eps_r:
        return ('reject', 'ledger_not_replayable')
    return ('ok', IDC(phi_s, g_exec, g_eval, kappa, ledger.h_L))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| AAP | `O(|O|·|A|·n_s + |O|·|A|²/ε_ot)` | `O(|O|·|A|)` | 剖面采样覆盖、边界主动采样 |
| DGG | `O(|O|·|A| + n_L log n_L)` | `O(|A| + n_L)` | 可达性 sound、互信息估计一致 |
| TDR | `O(|S|·|O|·|A| + K_max)` | `O(|S|·|A|)` | 可教性排序 sound、路由不误报 |
| SCF | `O(K·|S| log|S|)` | `O(K)` | 脚手架单调、淡出条件可判 |
| ICL | `O(n_L·|A|)` | `O(n_L)` | 账本完整、纠错方向无偏 |
| IDC | `O(Σ组件 + replay)` | `O(|A| + n_L)` | 子证书合取 sound、可回放 |

**命题 2（模式平均的必然性）**
设教师在某情境上以各 `1/2` 的质量放在两个相距 `Δ` 的动作簇上，成功核为 `exp(-d²/2r²)`。任何**情境无关、单槽**的学生在最小化前向 KL 时会把质量放在两簇均值处；其期望成功上界为 `exp(-Δ²/8r²)`。故只要 `Δ≫r`，无论给多少 i.i.d. 数据，单槽 vanilla KD 都无法突破该界——这不是数据量问题，而是**界面/容量没有表达“情境条件性”**。交互设计要么提供多槽（课程拆分），要么让表示携带情境，否则蒸馏目标本身就是错的。

**正确性定理（Interaction-Designed Distillation Soundness）**
假设第 54 轮 (A26)–(A28) 成立；并设 **(A29)** 教师与学生的 `φ` 估计误差 ≤ `ε_φ`；**(A30)** 课程始终位于 `ZPD` 内且 `β` 单调淡出、每课鲁棒性保持；**(A31)** 反馈延迟 ≤ `τ_f`，账本可回放误差 ≤ `ε_r`；**(A32)** 路由的“假可教”概率 ≤ `β_route`。则
```
P_success ≥ 1 - G_exec - G_eval - Σ_d (1 - ρ_min(d)) - β_route - ε_φ - ε_r
```
关键：**只教 ZPD 内的技能**、**界面设计同时压低两条鸿沟**、**账本使主张可回放**。三者共同把“蒸馏成功”从不可证的平均损失下降，变成可证的可供性覆盖 + 鲁棒性保持。

**E162-P（合成 pilot，已跑，`exp/round55_id_distill_sim.py`）**
构造“隐藏模态”任务：情境 `x` 的正确答案在左/右两模态间切换，而感知特征与模态刻意去相关；学生只有 `C` 个共享动作槽。比较 vanilla 一次性 KD、感知聚类、交互设计（纠错反馈拆分 + `x→模态` 分类器）。

| 方法 | C=2 | C=4 | C=8 | C=16 |
|---|---|---|---|---|
| vanilla 一次性 KD（全局边际） | 成功 0.005 | — | — | — |
| 感知聚类（无反馈） | 0.381 | 0.533 | 0.597 | 0.679 |
| 交互设计（反馈拆分） | **0.931** | **0.931** | **0.931** | **0.931** |

反馈预算：`n=10/20/40/80` 时成功率为 `0.722/0.782/0.878/0.928`。更关键的是：感知聚类的“簇内紧致度”在 `C=4/8` 时 100% 判定为“可教”，但实际有 **50%/38%** 的簇混合了两个模态——**假可教**。这直接支持 H23：可教性必须由**交互反馈**测量，不能用感知紧致度替代。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 界面自指：用被设计的界面去估计鸿沟/可教性 | 高 | 界面无关的独立留出集 + 红队反例探针 + 第三方回放审计 |
| ZPD 过保守导致“无可教”而系统瘫痪 | 高 | 动态扩区 + 自动降级到 SCOM 重组 / CEC 云卸载 |
| 评估鸿沟被“可控信号”低估 | 高 | 反事实探针 + 长尾独立站点 + 账本因果检验 |
| 脚手架导致师生共适应/课程过拟合 | 中 | 留出情境、淡出早停、课程正则 |
| 容量收缩使模式平均复发 | 中 | 多槽表示 + 情境条件化 + 路由到重组 |

## 6. 本轮最大风险

## 2. 关键算法 伪代码

### IP-121 AAP

```python
def affordance_profile(skill, contexts, actions, sampler, theta_phi=0.5):
    phi = {}
    for o in contexts:
        for a in actions:
            reach, conf = sampler.query(skill, o, a)
            phi[(o, a)] = conf if reach else 0.0
    return phi

def affordance_distance(phi_t, phi_s, O_tau, d_A):
    return max(wasserstein_1(normalize(phi_t[o]), normalize(phi_s[o]), d_A)
               for o in O_tau)

def stratify_active_sample(skill, phi, budget):
    return bandit_loop(skill,
        priority=lambda o, a: boundary_score(phi, o, a) + 0.5*uncertainty(phi, o, a),
        budget=budget)
```

### IP-122 DGG

```python
def distillation_gulfs(phi_t, phi_s, gamma, ledger, O_tau):
    g_exec = mean(1.0 - mass(phi_t[o], inside=support(gamma.apply(phi_s[o])))
                  for o in O_tau)
    F = [1 - success(r) for (_, _, r, _) in ledger]
    Z = [observable(f) for (_, _, _, f) in ledger]
    g_eval = 1.0 - mutual_info(F, Z) / max(entropy(F), 1e-9)
    return g_exec, g_eval
```

### IP-123 TDR

```python
def route_skill(skill, phi_s, interface, budgets):
    kappa = estimate_teachability(skill, phi_s, interface, budgets.K_max)
    if kappa >= budgets.tau_t:
        return ('distill', kappa)
    comp = scom_reachable(skill, phi_s)                    # 第 54 轮 SCOM
    if comp.feasible and comp.robustness >= budgets.rho_min:
        return ('recompose', comp.path)
    return ('offload', cec_contract(skill))                # 第 54 轮 CEC
```

### IP-124 SCF

```python
def scaffold_curriculum(skills, phi_s, interface, K_max):
    order = sort_by_robustness_then_failure(skills, phi_s)  # 鲁棒维度先教
    C, beta = [], 1.0
    for t, s in enumerate(order):
        phase = ('worked' if beta > 2/3 else
                 'guided' if beta > 0 else 'independent')
        C.append((s, phase, beta))
        obs = interact(s, beta, interface)
        if obs.success and obs.gulf_delta < interface.eps_g:
            beta = fade(beta)
        if obs.failure and phase == 'independent':
            beta = min(1.0, beta + 0.25)   # 独立失败 -> 回退加脚手架
    return C
```

### IP-125 ICL

```python
def interaction_ledger(student, teacher, interface, K):
    L = []
    for t in range(K):
        o = select_context(teacher.uncertainty, student.failure_set)
        a_s, y_s = student.act(o)
        f_t = teacher.observe_and_correct(o, a_s, y_s)
        L.append((o, a_s, y_s, f_t))
        student.update(o, a_s, y_s, f_t, beta=interface.beta(t))
        interface.update_from_feedback(f_t)
    return Ledger(L, h_L=commit(L))
```

### IP-126 IDC

```python
def interaction_distillation_certificate(student, teacher, interface, ledger, B):
    phi_s = student.affordance
    g_exec, g_eval = distillation_gulfs(teacher.phi, phi_s, interface.gamma,
                                        ledger, B.O_tau)
    kappa = estimate_teachability(teacher.phi, phi_s, interface, B.K_max)
    if g_exec > B.Delta_e:  return ('reject', 'execution_gulf', g_exec)
    if g_eval > B.Delta_v:  return ('reject', 'evaluation_gulf', g_eval)
    if kappa < B.tau_t:     return ('reject', 'not_teachable', kappa)
    if min(student.rho.values()) < B.rho_min:
        return ('reject', 'robustness_loss', student.rho)
    if replay_error(ledger, student) > B.eps_r:
        return ('reject', 'ledger_not_replayable')
    return ('ok', IDC(phi_s, g_exec, g_eval, kappa, ledger.h_L))
```

| ICL | `O(n_L·|A|)` | `O(n_L)` | 账本完整、纠错方向无偏 |
| IDC | `O(Σ + replay)` | `O(|A| + n_L)` | 子证书合取保持 sound、可回放 |

**命题 2（模式平均的必然性）**
教师在某情境以各 `1/2` 质量置于相距 `Δ` 的两动作簇，成功核 `exp(-d²/2r²)`。任何情境无关、单槽学生在最小化前向 KL 时把质量置于两簇均值，期望成功上界 `exp(-Δ²/8r²)`。故 `Δ≫r` 时，增加数据无法突破——问题在界面/容量未表达情境条件性，而非数据量。交互设计必须提供多槽（课程拆分）或情境条件化表示。

**正确性定理（Interaction-Designed Distillation Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `φ` 估计误差 ≤ `ε_φ`；**(A30)** 课程在 `ZPD` 内、`β` 单调淡出且每课鲁棒性保持；**(A31)** 反馈延迟 ≤ `τ_f`，账本回放误差 ≤ `ε_r`；**(A32)** 路由“假可教”概率 ≤ `β_route`。则
```
P_success ≥ 1 - G_exec - G_eval - Σ_d(1-ρ_min(d)) - β_route - ε_φ - ε_r
```
关键：**只教 ZPD 内技能**、**界面同时压低双鸿沟**、**账本可回放**。
