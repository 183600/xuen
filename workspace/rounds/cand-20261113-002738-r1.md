# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「运动学」×「动作空间」）

> 第 62 轮的 ROSE 把「语义 → 阻抗 → 执行」做成了带遗憾界与 CVaR 兜底的在线闭环，但它隐含了一个从未被检验的假设：**身体是一台理想、与构型无关的换能器**。具体地：
> 1. **运动学失明**：ROSE 的安全集 𝒦、WCV 的球 B(φ̂,r_φ)、鲁棒裕度 ρ_rob 全部活在**任务空间**；而真实执行是 τ = J(q)ᵀKe + …。J(q) 随构型变化、在奇异点失真：同一个「任务空间安全」的 K，可能在某一构型下产生**越限的关节力矩**。任务空间安全 ≠ 关节空间安全。
> 2. **动作空间单一**：ROSE 只输出阻抗 K。自由空间、约束接触、力敏感阶段分别更适合位置/速度/力矩/混合力位/导纳。用错动作空间，要么任务不可行，要么接触不稳定；且 K 是**瞬时**的，缺少运动/技能层，无法表达「怎么动」。
> 3. **冗余与运动学信用分配未用**：零空间是免费的安全资源（避奇异、避限位、避自碰而不扰动任务）；在线学习的梯度也从未利用 J 的几何——奇异附近误差/梯度被放大，学习与安全同时变脆。

## 0. 直觉与动机

**灵感 1（运动学 → KCF：构型相关的运动学可行阻抗集）**
直觉：既然真正下发的是关节量，那么「安全阻抗」必须在**当前构型 q 下**检查：K 要对称正定，且存在满足 τ=JᵀKe 落在关节力矩/速度/限位内、J 又不接近奇异的实现。把 ROSE 的任务空间安全框 𝒦 升级为**构型相关凸集** 𝒦_kin(q)；WCV 的「物理参数球」因此扩成「物理球 × 构型球」的双球，最终裁决在**关节空间**做。一句话：**先问身体能不能做到，再问语义想不想要。**

**灵感 2（动作空间 → AAL：动作空间格与无源切换）**
直觉：动作空间不是给定的，而是**可选的表示**。把它组织成格：节点 = {关节位置, 笛卡尔位置, 速度, 力矩, 阻抗, 混合力/位, 导纳}，边 = 允许的切换。选择依据 = 接触状态 + 任务阶段 + 运动学条件。硬约束：切换必须**无源（passivity-preserving）**，否则位置↔阻抗↔力矩之间切换会向接触环境注入能量，越切越振。用能量罐给出切换的充分条件——这是「动作空间」从工程 trick 升级为可证明机制的关键。

**灵感 3（动作空间 → SPL：从瞬时阻抗到时间抽象的技能原语）**
直觉：语义层真正想说「把杯子端起来放到左边」，而不是「这一步 K=diag(…)」。把动作提升为**技能原语**：s = (任务空间 DMP 权重 w, 时长 T, 途经点, 阻抗时间表 K(t), 动作空间节点 a)。语义 → 技能参数，技能 → 由运动学编译为关节轨迹。于是 OLP 的在线学习从「学一个瞬时 K」升级为「在技能参数空间里学」，遗憾比较器变成**轨迹级技能**，更贴近人类「学动作」而非「学增益」。

**灵感 4（运动学 → KOG + NSR：运动学预条件学习与零空间安全储备）**
直觉：奇异附近 Jᵀ 把任务误差放大成巨大关节力矩，也让梯度病态。两个动作：① **运动学预条件**——用 (JJᵀ+λI)^{-1/2} 给 OLP 的梯度换度量，使更新在任务空间各向同性，不被奇异方向拖爆；② **零空间安全储备**——把避奇异/避限位/避自撞写成零空间力矩 τ_null ∈ null(J)，由 N=I−Jᵀ(Jᵀ)⁺ 严格保证**不产生任务空间 wrench**，即「安全动作不改变任务」。

**灵感 5（三灵感合流 → KASE：运动学感知的动作空间自适应执行闭环）**
直觉：三者咬合成一个**身体层**：KCF 回答「这个 K 在 q 下做不做得到」，AAL 回答「用哪种动作语言说」，SPL 回答「说一段什么动作」，NSR/KOG 回答「顺着身体最省力/最安全的方向做」。ROSE 是「学习-鲁棒的动态闭环」，KASE 是「学习-鲁棒-身体的三层闭环」：语义流选技能与动作空间，运动流编译并做零空间注入，实时流只做前向与仲裁，**学习永远不写实时路径**。

**灵感 6（证书 → J_kase：把运动学风险写进证书）**
直觉：第 62 轮 J_rose 只证明「物理球内任务空间安全」。新增 ρ_kin = σ_min(J) − σ_kin（奇异裕度）、能量罐余量 E_tank、动作空间节点一致性。证书 Valid ⇔ 任务安全 ∧ 关节安全 ∧ 非奇异 ∧ 无源 ∧ 动作空间合法。**没有运动学签名的安全证书一律作废。**

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（𝒦_kin(q) 凸性）**：PD 锥是凸锥；力矩盒 ‖JᵀKe‖≤τ_max 对 K 线性；速度盒与 σ_min、d_lim 为凸约束。故 𝒦_kin(q) 凸，投影良定义且非扩张。
- **引理 2（双球覆盖与关节安全转移）**：若 P[φ*∈B_φ]≥1−α_φ、P[q*∈B_q]≥1−α_q，则 P[(φ*,q*)∈B_φ×B_q]≥1−α_φ−α_q（并集界，无需独立）。在乘积球上最坏情形编译 ⇒ 任务安全与关节安全同时以 ≥1−α_φ−α_q 成立。
- **引理 3（零空间任务不变）**：N=I−Jᵀ(Jᵀ)⁺ 投影到 null(J)；对任意 τ_safe，(J⁺)ᵀN τ_safe=0 ⇒ 零空间安全力矩不改变任务空间 wrench。
- **引理 4（无源切换）**：若每个动作空间控制器无源且切换时 E_tank ≥ ΔH，则切换后总存储 H+E_tank 不增，闭环保持无源、不注入能量。
- **定理 1（KASE-Safe）**：在 A77–A84 下，任何通过 J_kase 的执行周期同时满足任务空间 CVaR 安全、关节空间力矩/速度/限位安全、非奇异裕度与无源切换；安全概率 ≥1−α_φ−α_q。
- **定理 2（受限比较器遗憾界）**：把 OLP 比较器限制在 𝒲_κ={W:K_W(x_t)∈𝒦_kin(q_t),∀t}（凸、随时间缓变），OGD 的静态遗憾仍 ≤D·G̃·√T；KOG 预条件把奇异方向的放大从梯度挪到度量，任务空间步长恒 ≤ηG，近奇异方向按 σ_min/√λ 优雅退化。
- **实时性**：运动流新增 100–500Hz，但实时流（1–10kHz）仍**零学习写操作**；KCF/NSR 只读 KRA 锚点，保持 ≤1ms 契约。

| `J_kase = (J_rose, ρ_kin, σ_min, E_tank, a_t, s_id, kin_calib_ver, N_null_hash)` | KASE 证书 |
| `α_φ, α_q` | 物理球/构型球覆盖失效率；总安全界 `1−α_φ−α_q` |

## 2. 形式化定义（完整版）

**定义 185（KASE 闭环）** KASE 在 ROSE 的「语义流（10–100Hz）∘ 实时流（1–10kHz）」之间加入**运动流（100–500Hz）**。运动流只做三类事务：① 由本体现测更新 κ_t 与 KRA 锚点；② 将语义层选出的技能/阻抗按 KCF 编译为关节命令；③ 叠加 NSR 零空间安全力矩并做 PST 无源切换仲裁。不变式：**所有学习性写操作仍只在语义流；运动流与实时流对模型参数只读**（升级 A75 为 A83）。

**定义 186（运动学状态 κ_t）** κ_t = (q_t, q̇_t, J(q_t), σ_min(J), μ_t, d_sing, d_lim, d_self)。其中 μ_t = √det(JJᵀ) 为可操作度，d_sing 为当前构型到奇异集距离的下界估计（由最小奇异值与最小奇异向量方向上的可行步长共同给出），d_lim 为到关节限位的最近距离，d_self 为到自碰的最小距离。κ_t 由运动流按本体感知更新，并以 KRA 锚点原子提交。

**定义 187（运动学可行阻抗集 𝒦_kin(q)）** 给定任务误差包络 ℰ = {e:‖e‖≤e_max}，
𝒦_kin(q) = { K ∈ 𝒦 : K=Kᵀ≻0；∀e∈ℰ, τ=J(q)ᵀKe ∈ [τ_min,τ_max]；q̇=J⁺ẋ ∈ [q̇_min,q̇_max]；σ_min(J)≥σ_kin；d_lim≥d_min }。
它是 PD 锥、线性力矩盒、线性速度盒与两个标量下界约束的交，故凸（引理 1）。当 𝒦_kin(q)=∅（构型本身不可用）时触发**姿势回退**：先由 NSR 推到 d_sing/d_lim 可行区，再重编译；期间只执行 K_baseline。

**定义 188（双球鲁棒损失 DRB）** ℓ̃_t^κ(W,q) = sup_{φ∈B(φ̂_t,r_φ), q∈B(q̂_t,r_q)} CVaR_ε[ℓ(K_W(x_t); q, φ)]。物理球半径 r_φ 由第 62 轮 RSC 自校准；构型球半径 r_q 由运动学标定残差与关节编码器噪声估计（标定更新时重置）。两球采用**乘积**而非简单相加：因为任务 wrench 的安全余量由 φ 决定，而关节可实现性由 q 决定，二者对损失的作用不可互相抵扣。

**定义 189（动作空间格 AAL）** L=(𝒜,ℰ)。节点 𝒜 = {a_pos^j（关节位置）, a_pos^x（笛卡尔位置）, a_vel（速度）, a_τ（力矩）, a_imp（阻抗）, a_hyb（混合力/位）, a_adm（导纳）}。边 (a,a′)∈ℰ 当且仅当存在无源切换路径（PST 可仲裁）。选择器 π_act(a | phase, contact, κ_t) 在 ℰ 约束下按"期望任务完成度 − 风险"打分；非法或非无源边被硬屏蔽。**动作空间选择本身是不可跳过硬安全格的**——PST 能量不足时选择器无权切换。

**定义 190（技能原语 SPL）** 技能 s=(w,T,{via},K(·),a)∈𝒮。w 为任务空间 DMP（动态运动原语）权重，T 为时长，{via} 为途经点，K(·) 为阻抗时间表，a∈𝒜 为动作空间节点。语义→技能映射 Π_skill(x_t) 输出技能参数（连续部分用回归头，离散部分 a 与途经点数量用分类头）。技能在运动流按 t↦(x_d(t),K(t)) 展开，再由 KCF 编译到关节空间。技能库 SPL 支持复用、拼接与在线微调。

**定义 191（零空间安全储备 NSR）** 给定任务力矩 τ_task = JᵀF_task，合成 τ_t = τ_task + N τ_safe，其中 N=I−Jᵀ(Jᵀ)⁺ 为到 null(J) 的正交投影，τ_safe = −k_s∇U_safe(κ_t)，U_safe 由三项势函数组成：奇异势（σ_min < σ_kin 时陡增）、限位势（d_lim < d_min 时陡增）、自碰势（d_self < d_min 时陡增）。因 (J⁺)ᵀN=0，故零空间力矩对应的任务等效力矩 (J⁺)ᵀτ_safe 恒为零——**安全动作严格不改变任务**（引理 3）。

**定义 192（运动学鲁棒锚点 KRA）** Anchor^κ_t = (Anchor_t, κ_t, a_t, s_t, E_tank, kin_calib_ver, checksum)。沿用第 62 轮 SACP 的 CAS 原子写与 64 位单调版本号。运动流与实时流只读；语义流在技能/学习更新后提交新版本。锚点过期（age > τ_fresh）时 ρ_kin 与 E_tank 按保守速率衰减，触发动作空间回退到 a_imp 或 a_pos^j。

**定义 193（无源动作空间切换 PST）** 每个动作空间节点 a 配一个控制器存储 H_a。切换 a→a′ 在时刻 t_s 允许当且仅当 E_tank(t_s) ≥ ΔH(a,a′)：=max(0, H_{a′}(t_s) − H_a(t_s))。允许后按 E_{t+1} = E_t + ∫(P_in − P_out)dt 更新能量罐，并要求 E_t ≥ 0 恒成立。能量不足则拒绝切换并保持 a；同时把拒绝事件写入 J_kase 的审计字段。该机制使「切换动作空间」从启发式变为**可证明无源**的离散迁移。

**定义 194（运动学预条件 OLP KOG）** 在 OLP 的梯度上左乘 P_t=(J_tJ_tᵀ+λI)^{-1/2}：g_t^κ=P_t∇_Wℓ̃_t，W_{t+1}=P_𝒲(W_t−η_t g_t^κ)。P_t 把任务空间误差投影到各向同性度量，使近奇异方向（Jᵀ 放大方向）的步长被压缩。λ>0 为数值正则；λ→0 时退化为对 J 行空间的白化。

**定义 195（动作空间/技能老虎机 KCB）** 上下文 bandit：上下文 = (phase, contact∈{free, making, sustained, separating}, κ_t 的离散桶)。臂 = (a∈𝒜, s 的离散参数桶)。奖励 = progress − κ_c·cost − κ_s·ΔE_tank，importance-weighted 无偏化；采用 EXP4 风格的专家混合（专家 = 动作空间先验策略），伪遗憾 O(√(KT log(|𝒜||𝒮|)))。**硬安全格不可选**：AAL 非法边与 PST 能量不足的臂直接从候选集中剔除，构成 bandit 的安全下界。

**定义 196（KASE 证书 J_kase）** J_kase=(J_rose, ρ_kin, σ_min(J), E_tank, a_t, s_id, kin_calib_ver, N_null_hash)。
Valid(J_kase) ⇔ Valid(J_rose) ∧ ρ_kin≥0 ∧ d_lim≥d_min ∧ E_tank≥0 ∧（a_t 与 a_{t−1} 的切换在 ℰ 内且满足定义 193）∧ kin_calib_ver 已签名且未过期。审计链：kin_calib_ver 追溯「谁标定了身体」，N_null_hash 追溯「零空间注入用了哪一版权限」，a_t/s_id 追溯「用了哪种动作语言、哪段技能」。

### IP-193 KCF（运动学可行编译）

```python
def kinematic_feasible_set(K, q, env, limits,
                           sigma_kin=1e-2, d_min=0.02):
    J = jacobian(q)
    s = np.linalg.svd(J, compute_uv=False)
    if s[-1] < sigma_kin or joint_margin(q) < d_min:
        return None, -np.inf                      # 构型不可用 → 姿势回退
    # 误差包络最坏方向：逐轴取 |J^T K| 的行绝对值和
    tau_worst = np.abs(J.T @ K) @ (env.e_max * np.ones(6))
    ok_tau = np.all(tau_worst <= limits.tau_max) and \
             np.all(-tau_worst >= limits.tau_min)
    qd_worst = np.abs(np.linalg.pinv(J)) @ (env.xdot_max * np.ones(6))
    ok_vel = np.all(qd_worst <= limits.qdot_max)
    if ok_tau and ok_vel:
        return K, s[-1] - sigma_kin
    K_proj = project_torque_and_velocity_boxes(K, J, env, limits)  # 凸投影
    return K_proj, s[-1] - sigma_kin

def kcf_project(K_task, q, env, limits):
    K_safe, rho_kin = kinematic_feasible_set(K_task, q, env, limits)
    if K_safe is None:
        return K_BASELINE, -1.0                  # 触发 NSR 姿势回退
    return K_safe, rho_kin
```

```python
def drb_compile(olp, x, eeis, phi_hat, q_hat, r_phi, r_q,
                env, limits, eps=0.05, n_worst=16):
    cands = []
    for i in range(n_worst):
        phi_i = sample_ball(phi_hat, r_phi, i)   # 物理对抗方向
        q_i   = sample_ball_config(q_hat, r_q, i) # 构型对抗方向

        K_c, rho_kin = kcf_project(K, q_i, env, limits)   # 关节空间裁决
        margin = safety_margin(K_c, phi_i)
        loss_i = execution_loss_estimate(K_c, q_i, phi_i)
        cands.append((phi_i, q_i, K_c, margin, loss_i, rho_kin))
    cands.sort(key=lambda z: z[4], reverse=True)
    tail = cands[:max(1, int(eps * n_worst))]
    K_safe = intersect_shrink([c[2] for c in tail])
```

### IP-197 NSR（零空间安全储备）

```python
def null_space_safety(J, tau_safe):
    N = np.eye(J.shape[1]) - np.linalg.pinv(J) @ J   # 投影到 null(J)
    return N @ tau_safe                              # (J^+)^T N = 0，任务不变

def safety_torque(kappa, k_s=2.0):
    g_sing  = grad_potential(kappa.d_sing,  kappa.sigma_kin)   # 奇异势
    g_limit = grad_potential(kappa.d_lim,   kappa.d_min)       # 限位势
    g_self  = grad_potential(kappa.d_self,  kappa.d_min)       # 自碰势
    return -k_s * (g_sing + g_limit + g_self)

def assemble_torque(J, F_task, kappa):
    return J.T @ F_task + null_space_safety(J, safety_torque(kappa))
```

```python
class ActionSpaceLattice:
    ARMS = ('a_pos_j','a_pos_x','a_vel','a_tau','a_imp','a_hyb','a_adm')
    def __init__(self, edges, energy_tank):
        self.E, self.tank = edges, energy_tank

    def select(self, phase, contact, kappa, prev):
        allowed = [a for a in self.ARMS if a == prev or (prev, a) in self.E]
        scored = [(self._score(a, phase, contact, kappa), a) for a in allowed]
        return min(scored)[1]

    def _score(self, a, phase, contact, kappa):
        # 自由空间偏好位置，持续接触偏好阻抗/混合，力敏感偏好力矩
        base = PREFERENCE[contact].get(a, 1.0)
        risk = RISK[phase].get(a, 1.0)
        singular_pen = max(0.0, kappa.sigma_kin - kappa.s_min) * SING_W[a]
        return base + risk + singular_pen

class PassivityTank:
    def __init__(self, E0=1.0):
        self.E = E0

    def admit(self, H_prev, H_next):
        need = max(0.0, H_next - H_prev)
        if self.E < need:            # 能量不足：拒绝切换
            return False
        self.E -= need
        return True

    def update(self, p_in, p_out, dt):
        self.E = max(0.0, self.E + (p_in - p_out) * dt)  # 罐内非负
```

```python
class KinematicContextualBandit:                   # EXP4 风格，硬安全格屏蔽
    def __init__(self, experts, K):
        self.w = np.ones(len(experts)) / len(experts)
        self.experts, self.K = experts, K

    def choose(self, context, legal_arms):
        legal = [arm for arm in legal_arms if arm in self._hard_safe(context)]
        dist = self._expert_mixture(context)       # 专家加权
        dist = normalize({a: dist[a] for a in legal})
        return sample(dist)

    def update(self, context, arm, reward):
        for i, ex in enumerate(self.experts):
            loss = -reward if ex.predict(context) == arm else 0.0
            self.w[i] *= np.exp(-ETA_CTX * loss)
        self.w /= self.w.sum()

    def _hard_safe(self, context):
        # AAL 非法边 + PST 能量不足 的动作空间一律剔除
        return HARD_SAFE_GRID[context.phase]
```

```python
class KinematicPreconditionedOLP(OnlineLearningProjector):
    def online_step_kin(self, x, grad_K, q, lam=1e-3):
        J = jacobian(q)
```

## 4. 推导

**引理 1（𝒦_kin(q) 凸性）** PD 锥 {K=Kᵀ≻0} 是凸锥；对固定 q、e，τ=JᵀKe 对 K 线性，力矩盒与速度盒是线性不等式，故其交凸；σ_min(J)≥σ_kin 与 d_lim≥d_min 只依赖 q 不依赖 K，是「要么全空间、要么空集」的可行性筛选。因此 𝒦_kin(q) 是凸集（或空集）。到闭凸集的欧氏投影 P_{𝒦_kin(q)} 良定义且非扩张：‖P(K_1)−P(K_2)‖ ≤ ‖K_1−K_2‖。∎

**引理 2（双球覆盖与关节安全转移）** 设物理参数与构型误差分别满足 P[φ*∈B(φ̂,r_φ)]≥1−α_φ、P[q*∈B(q̂,r_q)]≥1−α_q。由并集界（无需独立）：
P[(φ*,q*)∈B_φ×B_q] ≥ 1−α_φ−α_q。
DRB 在乘积球 B_φ×B_q 上取最坏情形并编译 K_safe，且 KCF 保证 K_safe∈𝒦_kin(q) 对球内每个 q 成立（尾部交收缩），故对真实 (φ*,q*) 同时有任务空间 CVaR 安全与关节空间力矩/速度/限位安全，概率 ≥1−α_φ−α_q。∎

**引理 3（零空间任务不变）** N=I−Jᵀ(Jᵀ)⁺ 是到 null(J) 的正交投影（等价 I−J⁺J）。对任意 τ_safe，τ_null=Nτ_safe∈null(J)，故 Jτ_null=0 且 (Jᵀ)⁺τ_null=(J⁺)ᵀτ_null=0（因 null((Jᵀ)⁺)=null(J)）。在关节力矩到任务等效力矩的映射 F=(J⁺)ᵀτ 下，F(Nτ_safe)=0，即零空间安全力矩**不产生任何任务空间 wrench**。∎

**引理 4（无源切换）** 设每个动作空间控制器 a 关于供给率 P_ext 无源：存在存储 H_a≥0 使 Ḣ_a ≤ P_ext + P_supply,a。在切换时刻 t_s 从 a 到 a′，定义总存储 H_tot=H_{a′}+E_tank。若 E_tank(t_s)≥ΔH=max(0,H_{a′}(t_s)−H_a(t_s))，则 H_tot(t_s^+) = H_{a′}(t_s)+E_tank(t_s)−ΔH ≤ H_a(t_s)+E_tank(t_s) = H_tot(t_s^−)。结合 E_tank≥0 的更新与各控制器无源性，H_tot 沿轨迹不增，闭环无源（不向环境净注入能量）。∎

**引理 5（受限比较器遗憾）** 令 𝒲_κ={W : K_W(x_t)∈𝒦_kin(q_t), ∀t}。因每个 𝒦_kin(q_t) 凸，有限交仍凸；若构型缓变，𝒲_κ 亦缓变。OLP 在 𝒲_κ（或其在 𝒲 内的投影）上做 OGD，比较器取 W*∈𝒲_κ，标准 OGD 分析给出 R_T=Σℓ̃_t(W_t)−min_{W∈𝒲_κ}Σℓ̃_t(W) ≤ D·G̃·√T，其中 D=diam(𝒲_κ)≤diam(𝒲)、G̃ 同第 62 轮。**关键点**：运动学可行性把比较器限制在「身体做得到」的子集，遗憾不因该限制而变差；代价是可行域可能变小、比较器更弱，这被显式接受而非隐藏。∎

**推论 1（动态构型遗憾）** 若 𝒲_κ 随时间移动（q_t 漂移），标准同时化论证给出 R_T^dyn ≤ D·G̃·√T + 2D·G̃·P_T，P_T 为最优轨迹的路径长度；构型漂移快于 √T 时界变松，由 KCB 的动作空间/技能切换承担快速追踪（已声明的理论缝隙）。

**命题 1（KOG 的条件数无关步长）** 因 P_t=(J_tJ_tᵀ+λI)^{-1/2}，任务空间有效步长为 ‖J_t P_t g_t‖ ≤ ‖J_t(J_tJ_tᵀ+λI)^{-1/2}‖‖g_t‖ = σ_max(J)/√(σ_max²(J)+λ) · ‖g_t‖ ≤ ‖g_t‖。故近奇异方向不再把步长放大到 σ_max/σ_min 倍；代价是收敛沿 σ_min 方向按 σ_min/√λ 优雅变慢。这是「用速度换稳定」的定量表述，而非声称改善最坏情形速率。

**定理 1（KASE-Safe）** 假设 A77–A84 成立，且某执行周期的 J_kase 通过 Valid。则由定义 196 与引理 2–4：
① Valid(J_rose) ⇒ 物理球内任务空间 CVaR 安全；
② KCF 与 DRB ⇒ 对构型球内每个 q，K_safe∈𝒦_kin(q)，关节力矩/速度/限位安全；
③ ρ_kin≥0 与 d_lim≥d_min ⇒ 非奇异且不限位；
④ PST 仲裁通过 ⇒ 本次动作空间切换无源；
⑤ 五项同时成立的概率 ≥1−α_φ−α_q。∎

**定理 2（KASE-Complete）** 假设 A61–A76（第 62 轮）及 A77–A84：
- **(A77)** 对所有可达 q，𝒦_kin(q) 非空或可经 NSR 姿势回退到非空；𝒦_kin(q) 凸（引理 1）。
- **(A78)** 标称运动学 J(q) 与真实机构的偏差落在构型球 B(q̂,r_q) 内，且 q 在运动流速率下可观测（编码器带宽足够）。
- **(A79)** 技能空间 𝒮 紧、Π_skill Lipschitz；DMP 积分稳定（不产生无界轨迹）。
- **(A80)** 每个动作空间控制器单独无源；能量罐可观测且 E_tank≥0。
- **(A81)** U_safe 有下界、梯度 Lipschitz；零空间投影数值精度足够（N 的秩估计正确）。
- **(A82)** KCB 的重要性加权无偏；上下文与奖励可测。
- **(A83)** 学习性写操作只在语义流；运动流/实时流对 KRA 只读，锚点原子（升级 A75）。
- **(A84)** RSC 物理球覆盖 ≥1−α_φ；运动学标定球覆盖 ≥1−α_q。

则：
1. **关节安全**：任何通过 J_kase 的周期，关节力矩/速度/限位违规率 0（在乘积球覆盖事件内）——第 62 轮「任务空间安全」盲区被机制性关闭。
2. **双球偏差免疫**：任务空间与关节空间同时安全概率 ≥1−α_φ−α_q。
3. **动作空间无源可切换**：所有被允许的切换保持闭环无源；被拒绝的切换不破坏当前动作空间。
4. **零空间安全不扰动任务**：NSR 注入的安全力矩产生零任务 wrench（引理 3）。
5. **技能级在线学习**：受限比较器遗憾 ≤D·G̃·√T；KOG 提供条件数无关步长稳定性。
6. **实时性不变**：运动流新增 100–500Hz 只做只读编译与仲裁，实时流（1–10kHz）零学习写、≤1ms 契约与第 62 轮一致。
7. **证书可审计**：J_kase 把「标定版本、动作节点、技能 id、能量罐、零空间基」写入审计链，安全结论可回溯到身体状态。

## 7. 已知风险

**一句话**：若标称运动学 J(q) 与真实机构失配（连杆标定误差、关节柔性、传感器偏置），则 KCF 的可行集、NSR 的零空间投影、KOG 的预条件全部在**错误坐标系**中计算，关节空间安全证书从「机制保证」退化为「纸面保证」——这是本轮全部运动学论证共同依赖的单点假设（A78）。

**次级风险与缓解**：
1. **𝒦_kin(q) 为空**：极端构型下无可行 K → NSR 姿势回退到可行区，期间仅执行 K_baseline，并记录「构型不可用」事件驱动技能库避开该区域。
2. **能量罐可观测性**：E_tank 难以精确测量 → 用保守下界估计（只计已知耗散，不计潜在回收），宁可误拒切换也不误放。
3. **动作空间切换语义断裂**：不同动作空间的状态量不共享 → PST 要求切换时「bumpless」公共状态（位置/速度连续），否则先做短时平滑过渡再切。
4. **技能空间非凸**：轨迹级损失通常非凸，定理 2 的遗憾只对受限凸包比较器成立 → 用 DMP 权重线性化 + 局部凸包，并把全局技能选择交给 KCB（bandit 不依赖凸性）。
5. **KCF/NSR 计算延迟**：运动流 100–500Hz 下 SVD/伪逆可能超预算 → 预计算 J 的 SVD 缓存、零空间基增量更新；实时流只读已编译结果。
6. **标定漂移**：长期使用后 J 漂移 → 定期在线标定（kin_calib_ver 递增），r_q 随之更新；标定未完成时 J_kase 降级为「仅任务安全」并显式标注。
7. **双学习耦合**：技能层与 OLP 同时更新可能互相追逐 → 沿用第 62 轮奇偶交替调度，并把 KCB 的奖励按技能级聚合以降低方差。
