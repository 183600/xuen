# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「竞赛策略」×「预测性维护」）

> R69 把不确定性一分为二：aleatoric 用 λ_floor 收紧，epistemic 用「流匹配多模态策略 + 主动交互」消解，并用一条证据纪律防止「问错」。但 R69 仍是一个**单幕、贪心、资产不折旧**的世界：它每一步独立地算 VoI，默认时间、能量、社交信用和硬件健康都是取之不尽的；它问「现在值不值得问」，却不问「现在问，还是留到最后一个弯道再问」；它检查「此刻证书是否有效」，却不问「这张证书还能撑多久」；它假设对手/环境是（相关但不自适应的）投毒者，却没考虑**竞争者会观察我们提问的动作本身**。
>
> 本轮两个灵感正好切开这两块盲区：
> - **竞赛策略**告诉我们，有限资源下的不确定性处置不是逐步贪心，而是一场**赛程规划**：节奏（pace）、进站时机（pit window）、保留余量（tyre/fuel）、对关键赛段的期权价值，以及「你一问，对手就知道你在犹豫」的信息泄露。
> - **预测性维护**告诉我们，安全不是一个布尔值，而是一条**退化曲线**：标定、世界模型、流似然、模态校准都有 health 与剩余寿命（RUL）；「检测到坏」太晚，必须「预测何时会坏」并排程维护——而维护本身有成本、有风险、也要被认证。
>
> 核心命题：**把 R69 的「即时不确定性」与「赛程级资产健康」分开：瞬时层继续由 R69 的 FLUID 内核保证安全；外圈新增一个只能收紧、不能放宽的「教练层」，把交互预算、节奏 λ、证据采集与维护窗口当作有限赛程资源来规划，用决策论 EVSI 取代熵式贪心 VoI，用 anytime-valid 序贯证据取代固定 k-一致，用带删失的 RUL 预测取代事后故障检测。** 命名 **PACE-RAS**（Prognostics-Aware Competition-strategy Engine for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我还能撑多久、什么时候进站、这一问会被谁听见**」。
>
> 理论姿态与 R69 相同且更硬：**R69 是 PACE-RAS 在「单步视界 H=1、零磨损、无竞争、无泄漏」处的逐指令退化**；外圈教练层只允许收紧 R69 的可行域，因此安全侧永不弱于 R69，新增的只是效率、寿命与对抗鲁棒性。

## 0. 直觉与动机

**灵感 1（竞赛策略 → 贪心 VoI 缺的是「期权」与「赛段」）**
直觉：赛车手不会每个弯都全力推。轮胎、燃油、刹车温度都是**有限且会磨损的预算**；早推一圈可能换来位置，也可能让你在最后三圈没有胎。R69 的 MINT 正是「每个弯都算一次即时收益」的车手：它最大化 `VoI(g) − c(g)`，却忽略三件事——(i) **信息的期权价值**：同样的答案，在关键决策前知道远比在无关紧要时知道值钱，晚一点问可能更值钱，也可能来不及；(ii) **预算的跨期配置**：现在花掉一次交互，就少一次留到关键赛段；(iii) **决策相关性**：熵减 ≠ 收益，只有改变最终动作的熵减才值钱。竞赛策略给出正确的量：**EVSI（期望样本信息价值）** + **等待期权** + **关键时刻的临界性**，并把「节奏」显式化为一条可规划的 λ(t) 曲线。

**灵感 2（预测性维护 → 安全是退化曲线，不是布尔值）**
直觉：预测性维护（PdM）的核心不是「坏了再修」，也不是「定期换」，而是**用退化轨迹预测剩余寿命（RUL），在故障前、且不早得浪费的时点维护**。把它搬到安全闭环：`J_CALM/J_FLUID` 不是「有效/无效」两态，而是有一条 health 轨迹——标定会漂、世界模型会过时、流似然的校准会松、模态 ECE 会升。R69 只在证书失效后才保守，等于「跑到抛锚」。R70 要估计每个安全资产的 RUL 分布，用**控制限（control-limit）策略**提前进站；并且承认维护本身是一个动作：要花时间、要暂停任务、要在安全状态下做、要重新认证——**进站也可能输掉比赛**。

**灵感 3（二者耦合 → 用法改变退化，退化限制用法）**
直觉：这是本轮真正的理论接缝。**你开得越猛（λ 越低、交互越频繁、任务越激进），资产退化越快；而资产越接近寿命终点，你能用的节奏越保守。** 传统 PdM 把「使用剖面」当外生协变量，传统策略把「健康」当静态约束；R70 必须把二者做成一个**耦合不动点**：策略依赖 RUL，RUL 又依赖策略产生的负载。忽略这层内生性，就会得到危险的自我实现预言——「预测还能撑 10 分钟」→ 于是全力推 → 实际 4 分钟就坏。因此 PACE-RAS 必须做**用法感知的 prognostics** 与**退化感知的 pacing** 的双向修正。

**灵感 4（竞赛的另一面 → 提问会泄露，对手会自适应）**
直觉：在赛道上，你进站的动作本身向对手暴露了你的轮胎状态与策略意图；在交互系统里，**你问什么，就暴露了你不知道什么**。R69 只算了交互的物理/社交成本，没算**信息泄露成本**：一个会观察你提问的竞争者（或会社交工程的人）可以从 `g_ask` 反推你的模态后验、你的不确定性、甚至你的安全余量。更严重的是，R69 的投毒界假设各证据源的欺骗**相关但固定**；面对**自适应**对手（他看你怎么问就怎么答、多源共谋、专挑阈值打），固定 `k` 个源一致的错误率没有非平凡上界——你可以被诱导着一直问，直到「问出一致」。因此 R70 必须：把竞争写成**极小极大遗憾**而非 i.i.d. 欺骗率；把「一直问到一致」换成**anytime-valid 的序贯检验**（e-process / 置信序列），否则反复提问本身就是 p-hacking。

**灵感 5（为什么这次是「加层」而不是「加黑箱」）**
直觉：每加一层，就多一个需要独立信任的模型。PACE-RAS 的自保办法有三条：(i) **两时间尺度**——外圈（秒~分钟）只输出约束（λ 下界、交互预算、维护窗口、健康门），内圈（毫秒）仍是 R69 的 FLUID 认证内核，外圈不许绕过内圈；(ii) **只收紧**——教练只能让车慢下来、进站、少问，不能让它超出内圈证书；(iii) **可审计**——每个新组件（EVSI、RUL、维护、竞争）都在 `J_PACE` 里留下字段，且退化时逐指令回落到 R69。这样 R69 不是被替代，而是被**包成一个安全核**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACE-RAS 总览与三不变式）** PACE-RAS = (RSP, EVSI, PAD, CSC, SHT, AVD, PHM, MSP, CDS, HAC, VQAuditor-S, RAS-WM‡)，其内核算子是 R69 的 FLUID-RAS。三不变式：
(i) **安全核不旁路**：外圈只能收缩内圈可行域（λ 下界 ↑、交互预算 ↓、维护窗口、健康门），任何外圈输出都不得放宽 R69 证书；
(ii) **赛程预算守恒**：时间/能量/社交/安全余量是显式预算过程，交互与维护均从中扣费，且**维护本身必须过 C-RAS-WM 安全认证**；
(iii) **任意时刻有效性**：模态判定使用 anytime-valid 证据（e-process），禁止「问到 k 个一致才停」这种可选停止；跨模态/跨时间多重比较须做 α 分配。

**定义 311（赛程状态与预算过程）** 设赛程终点 T（或终止事件）。预算 `B_t = (b_time, b_energy, b_social, m_t)`，其中 `m_t ∈ [0, m_0]` 是**安全余量**（证书松弛量，类比胎纹/燃油）。动作 `u_t = (a_t, g_t, mnt_t, λ_t)` 产生扣费：`B_{t+1} = B_t − Δ_t·(c_time, c_energy, c_social, 0) + (0,0,0, u_mnt) − Δ_t·w(a_t,g_t,λ_t)`；任一 `b < 0` 或 `m_t < 0` ⇒ 赛程失败（触发安全停）。

**定义 312（PACE-MDP）** 约束半马尔可夫决策过程 `M_PACE = (S, U, P, R, C, T, δ)`：状态 `s_t = (x_t, w_t, H_t, B_t, c_t, θ̂_t)`（任务态、模态后验、健康向量、预算、**临界性** c_t、对手信念）；动作 u_t 如上；效用 R = 任务收益 − 风险 − 成本；约束 C = 安全余量、灾难概率 `P(m_{τ< T}<0) ≤ δ`、预算非负。目标：`max_π E[Σ_t γ^t R_t]` s.t. 约束。**临界性 c_t ∈ [0,1]** 度量「从此刻到下一个不可逆决策/终点的距离与不可逆性」，是「关键弯道」的形式化。

**定义 313（节奏–余量–磨损动力学）** 节奏 `λ_t > 0` 越小越激进（任务收益越高、磨损越快）。任务/交互/节奏的磨损率 `w(a,g,λ) = w_0 + w_a(a) + w_g‖g‖ + w_λ(1/λ)`，关于 1/λ 单调增；余量 `m_{t+1} = m_t − Δ_t w(·) + u_mnt − ξ_t`，`ξ_t` 为不可约磨损噪声，`u_mnt` 为维护恢复量。安全条件：对终点 T，`P(inf_{t≤T} m_t ≥ 0) ≥ 1−δ`。这条动力学把 R69 的标量 λ 从「瞬时旋钮」升级为**轨迹级资源分配**。

**定义 314（决策论 VoI / EVSI 与等待期权）** 决策集 D，效用 `U(d,M)`。对信息动作 g 与观测 y：
`EVSI(g) = E_y[max_d E_{M|y}U(d,M)] − max_d E_M U(d,M)`。
相对 R69 的熵式 `VoI(g)=H(M)−E[H(M|y)]`，EVSI 只计「会改变动作」的信息，且 `EVSI ≤ VoI`（对数效用下）。定义**调度价值** `SV_t(g) = EVSI_t(g) − max_{τ>t} E[EVSI_τ(g)]`：若为负，则**等待**比现在问更值钱（把预算留给关键赛段）。净收益 `NEVSI(g) = EVSI(g) − c(g) − κ·L(g)`（L 见定义 315）。

**定义 315（竞争模型与信息泄露）** 对手策略集 `Σ_opp(θ̂_t)`（由观测更新的可行集，可为自适应/非平稳）。稳健目标 `max_π min_{σ∈Σ_opp} E_{π,σ}[Σ R]`；遗憾 `Regret(π) = max_σ [U(σ*,σ) − U(π,σ)]`。信息动作对对手可见，泄露 `L(g) = I(S_priv; O_opp(g) | hist)`，`S_priv = (w_t, m_t, θ̂_t)`；`κ` 为泄露的对手收益折算。**R69 的「问」在此可变成负收益动作**——主动交互不再天然优于沉默。

**定义 316（序贯模态锦标赛 SHT）** 把 R69 的模态 `{m_k}` 当作赛道上的「赛马」。对每个 k 构造相对参考的似然比过程 `e_{k,t}`，聚合为 e-process `E_{k,t} = ∏_{s≤t} e_{k,s}`（或混合/对冲 e-process）。当 `E_{k,t} ≥ 1/α` 时拒绝「k 非真模态」，即宣布 k 胜出；否则继续「跑」。停止时间 `τ` 由数据自适应决定，无需预先固定询问次数。

**定义 317（任意时刻有效证据纪律 AVD）** 证据规则 Valid ⇔ 在任意停时 τ 有 `P_{H_0}(∃t≤τ: E_{k,t} ≥ 1/α) ≤ α`（Ville 不等式）。取代 R69 定义 293-iii 的「k 个正交源一致」固定样本规则：后者对**可选停止**不成立（不断问到多数一致 ⇒ 第一类错误可被推高到 1）；跨模态与跨通道的多重检验按 `α / (#hypotheses)` 或 α-spending 分配。对外部人类回答，用**对冲资本**（hedged capital）版本以在自适应/对抗分布下仍保持 anytime 有效性。

**定义 318（健康态与退化过程）** 健康向量 `H_t = (h_cal, h_wm, h_flow, h_ece, h_track) ∈ [0,1]^5`，分别对应标定、世界模型、流似然校准、模态 ECE、跟踪/交互可信度。退化 `h_{i,t+1} = h_{i,t} − η_i(load_t; θ_i) + ν_{i,t}`，`load_t` 由 `(λ_t, g_t, a_t, 环境)` 决定，`η_i` 单调增于负载；不可逆阈值 `h_i^fail`。健康态由**独立物理/统计指标**观测，不单靠被测模型自报（防「仪表盘永远绿色」）。

**定义 319（危险率、RUL 与删失）** 故障时间 `T_i = inf{t: h_{i,t} ≤ h_i^fail}`。危险率 `ζ_i(t) = lim_{Δ→0} P(t≤T_i<t+Δ | T_i≥t)/Δ`。RUL `R_i(t) = T_i − t` 为随机变量；因我们在维护/赛程结束时**主动停用**（右删失），RUL 必须用生存分析（Cox/Weibull/退化过程）在**删失数据**上估计，不能对「已观测故障时长」做普通回归（会系统性高估寿命）。安全侧使用**下置信界** `RUL_i^LB(t)`（如 5% 分位），而非均值。

**定义 320（维护动作集与维护认证）** `MNT = {recal(COF), refit_flow, reboot_wm, re_ask_human, safe_stop, cool_down}`。每个 `mnt ∈ MNT` 有成本 `c_mnt`、恢复量 `u_mnt`、**停机时间**与**瞬时风险**。维护必须先满足：处于认证安全态（C-RAS-WM 允许）、维护本身过安全包络、维护后重新签发证书；否则不得启动（禁止「高速换胎」）。维护还会造成**瞬态**（参数跳变），需 bumpless transfer。

**定义 321（维护调度 MSP，控制限策略）** 选择维护时点 `τ_1<τ_2<…` 最小化
`E[ c_fail·1{failure before next maint} + Σ_j (c_mnt + c_down·dur_j + risk_j) ]`。
在 A100（健康单调退化、`ζ_i(t)` 单调增、退化马尔可夫、维护恢复可观测）下，最优策略是**控制限**：当 `h_i(t) ≤ h_i*` 或 `ζ_i(t) ≥ ζ*` 时维护。`h_i*` 由成本比与 `δ` 标定。

**定义 322（用法–健康耦合算子 CDS）** 定义双向映射：`F: 策略 π ↦ 负载剖面 load(π) ↦ 退化/RUL 预测 PHM(load)`；`G: 健康/RUL ↦ 可行节奏与预算约束 ↦ 策略 π`。耦合不动点 `π* = G(PHM(load(π*)))`。用阻尼迭代 `π^{(j+1)} = (1−β)π^{(j)} + β G(PHM(load(π^{(j)})))` 求解；收敛性由磨损对节奏的 Lipschitz 常数 `L_w` 与贴现因子决定（见定理 20）。

**定义 323（健康感知证书 HAC）** `J_PACE = (J_FLUID, H_t, RUL^LB, maint_due, λ_plan, budget_left, EVSI_ratio, leakage_est, e_value_max, regret_bound, pace_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ (RUL^LB ≥ horizon_to_next_maint) ∧ (P(m<0)≤δ) ∧ 证据 anytime-valid ∧ 维护已认证`。任一健康门失败 ⇒ 强制进入维护或 R69 纯保守。

**定义 324（两时间尺度架构与 R69 严格包含）** 慢环（PACE，`T_slow` = 0.1–10s）：更新 `H_t, RUL, 对手信念`，解有限视界 `H_plan` 的近似约束 MDP，输出**只收紧**的接口 `(λ_min(t), interaction_budget(t), maint_window(t), health_gate(t))`。快环（R69 FLUID，`T_fast` ≪ `T_slow`，P99 < 2.6ms）：在接口内照常运行，证书签发权仍在快环。**退化条件**：`H=1`（单步）、`w≡0`（零磨损）、`|Σ_opp|=1`（无竞争）、`L≡0`（无泄漏）、维护不可用 ⇒ 慢环输出空约束，PACE 逐指令等于 R69。

**定义 325（威胁模型 ℰ_PACE）** `ℰ_PACE = ℰ_FLUID × ℰ_strategic × ℰ_leak × ℰ_health`：`ℰ_strategic` 为自适应对手（看提问方式调整回答、共谋、阈值探测、诱导过度询问）；`ℰ_leak` 为由交互动作反推私有状态/余量；`ℰ_health` 为健康遥测投毒、选择性上报、传感器退化导致的「假健康」。并入 AIC：任何健康/竞争相关失败都必须可被证书字段检出或安全停兜底。

**定义 326（元维护与递归有界）** 「谁维护维护者」不能无限递归。元维护使用**保守先验 + 独立物理冗余 + 最坏情况界**三层：`RUL^LB` 的估计器本身只允许用不依赖被测模型的物理冗余（如温度/振动/时基漂移）做交叉校验；策略与 PHM 的超参数只在离线/安全停时更新；在线只允许收紧。递归深度硬限制为 2（资产层、元资产层），更深层一律退化为 `safe_stop`。

# IP-264 RSP：有限视界赛程规划（慢环，近似约束 MDP / rollout）
def race_strategy(state, H_plan, model):
    best = None
    for plan in candidate_plans(state):            # 节奏档位 × 交互时点 × 维护窗口
        # EVSI（定义314）与等待期权、泄露成本
        val = expected_utility(plan, state, model) \
              - risk_penalty(plan, state, model) \
              - leak_cost(plan, state, model)
        # 约束：余量不破、灾难概率≤δ、预算非负
        if not feasible(plan, state, model): continue
        if best is None or val > best.val: best = (plan, val)
    return best.plan                              # 只输出 λ_min/预算/窗口，不直接下控制指令

    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, state.o): continue
        if not leak_budget.allow(g): continue
        evsi = decision_voi(w, g, state.D)          # E_y[max_d E[U]] - max_d E[U]
        sv   = evsi - wait_option_value(state, g)   # 现在问 vs 留到关键赛段
        net  = sv - cost(g) - KAPPA * leakage(g, state.S_priv)
        if best is None or net > best.net: best = (g, net)
    return best if best and best.net > 0 else None  # ≤0：沉默 > 提问

# IP-268/269 SHT + AVD：序贯模态锦标赛（anytime-valid）
def sequential_mode_test(modes, evidence_stream, alpha):
    E = {k: 1.0 for k in modes}
    for y in evidence_stream:                       # 每来一条证据就更新，可随时停
        for k in modes:
            E[k] *= likelihood_ratio(y, k, modes)   # 或 hedged e-process（对抗版）
        winners = [k for k, v in E.items() if v >= 1.0/alpha_k]
        if winners: return winners, E               # 也可返回「尚无赢家」继续
    return [], E                                    # 未定案：U_epi 未消解 → R69 兜底

# IP-270 PHM：删失 RUL 与下置信界
def prognose(health_stream, load_profile, sensored):
    theta = fit_survival(health_stream, censored=True, covariates=load_profile)
    rul   = rul_distribution(theta)                 # Weibull / gamma / Cox
    return rul.quantile(0.05), rul                 # 安全侧用 5% 下界，不用均值

# IP-271 MSP：控制限维护调度
def maintain_if_needed(h, hazard, rul_lb, plan):
    if not safe_to_maintain(plan): return None      # 需要认证安全态，禁止高速换胎
    if h <= H_STAR or hazard >= ZETA_STAR or rul_lb <= plan.time_to_next_window:
        return best_maintenance(plan)               # recal/refit/safe_stop/cool_down
    return None

# IP-276 主闭环：外圈只收紧，内圈仍是 R69 FLUID
def PACE_round(M, obs):
    # ---- 慢环（每 T_slow 更新一次）----
    H, rul_lb = M.phm.update(obs, M.load_hist)
    plan      = M.rsp.solve(M.state, H, M.opponent_belief)
    mnt       = M.msp.maintain_if_needed(H, M.phm.hazard, rul_lb, plan)
    if mnt is not None:
        M.execute_maintenance(mnt)                  # 需认证 + bumpless transfer
    if mnt in (MNT.safe_stop,): return SAFE_STOP
    # ---- 快环：R69 FLUID 在收缩后的可行域内运行 ----
    lam_min, ibud, gate = plan.lambda_min, plan.interaction_budget, plan.health_gate
    if not gate:                                    # 健康门失败 → R69 纯保守
        return M.fluid.round_conservative(obs, lam_min=0.8)
    k, lam, mode, U = M.fluid.round(obs, interaction_budget=ibud, lam_min=lam_min)
    # ---- 证据：anytime-valid，替代固定 k-一致 ----
    if U.epi > TAU_EPI and M.avd.may_sample():
        winner, E = M.sht.step(mode, M.evidence)
        U = M.avd.update(U, winner, E, alpha=M.avd.alpha_spend())
    # ---- 证书 ----
    M.hac.emit(J_PACE(J_FLUID=lam.cert, H=H, RUL_LB=rul_lb,
                      maint_due=(mnt is not None), lambda_plan=plan.lambdas,
                      budget_left=M.budget, evsi_ratio=plan.evsi_ratio,
                      leakage_est=M.csc.leakage, e_value_max=max(E.values()),
                      regret_bound=M.csc.regret))
    return k, lam, mode, U

## 3. 推导

**引理 19（EVSI 是 VoI 的决策相关下界；贪心是 H=1 特例）** 在任意先验下 `EVSI(g) ≤ VoI(g)`（把熵换成使决策不变的粗化）。若决策为选择模态且效用是 0-1 正确性、成本对称，则在 A99 下 EVSI 与后验熵减同序。取单步视界 `H=1`、无预算稀缺、无磨损、无对手，则 PACE 的交互选择与 R69 的 MINT 逐指令相同。要点：**「多问」不总是更值钱——只有会改变动作的信息才值钱；R69 的贪心在有限赛程里系统性高估早期信息的价值、低估晚期信息的价值。**

**引理 20（信息预算守恒与阈值/囤积策略）** 设临界性 `c_t` 与歧义 `U_epi,t` 联合超模（TP2），且 EVSI 对 `c_t` 单调、对剩余预算边际递减。则最优提问策略是**双阈值**：当 `c_t·U_epi,t ≥ τ(剩余视界)` 时才问，且阈值 `τ` 随剩余视界缩短而下降。系：**在关键赛段之前，最优策略可能主动保留交互预算并临时收紧 λ 换取余量**（信息囤积）；「每一步都问」不是最优，「到最后才问」也不是——这是一个控制限，与维护策略同构。

**引理 21（控制限维护的最优性）** 在 A100（退化单调、危险率单调增、退化过程马尔可夫、维护效果可观测）下，对定义 321 的成本泛函，存在阈值 `(h*, ζ*)` 使控制限策略最优；且 `δ` 越小，`h*` 越高（越早进站）。系：**RUL 的不确定性不改变「是否阈值」的结构，只推动阈值保守化**——因此即使 prognostics 不完美，控制限结构仍是稳健的。

**引理 22（自适应对手下固定 k-一致的失效与 e-process 的必要性）** 若对手可观察历史并自适应选择回答，则任何「直到 k 个证据源一致」的固定样本规则都可被驱动到任意高的错误采纳率（对手只在临界时刻共谋翻转）；相反，`E_{k,t}` 的 Ville 界在**任意停时与任意（可预测）数据分布**下成立，故错误宣布率 ≤ α。又因 `L(g)` 可正，净 `NEVSI` 可为负：**存在「信息上值得问、策略上不该问」的状态**（提问泄露余量/意图给竞争者）。

**定理 18（PACE 严格包含 R69，安全单调）** 慢环输出只能收缩快环可行域（λ 下界、预算、门控），快环证书签发不变。故对任意状态，PACE 的认证动作集 ⊆ R69 的认证动作集在安全侧，`P(风险 > ε) ≤ P_R69`。在退化条件 `H=1, w≡0, |Σ_opp|=1, L≡0` 下，慢环输出空约束，PACE 与 R69 逐指令相同。**R69 是 PACE 的「单圈、无磨损、无对手」极限**；新层不引入可绕过内核的安全假设。

**定理 19（赛程可行性与安全–进度前沿）** 给定余量动力学（定义 313），一条节奏策略 `{λ_t}` 在 `[0,T]` 上可行（`P(m_t≥0)≥1−δ`）当且仅当 `Σ_t Δ_t w(λ_t) ≤ m_0 + Σ_j u_mnt,j − q_δ√(Σ Δ_t^2 σ_w^2)`（`q_δ` 为 δ 分位）。由此得到**安全–进度 Pareto 前沿**：更激进的节奏换更高任务收益，但必须由更多维护或更高初始余量偿付。系：**维护窗口不是事后补救，而是赛程规划的内生变量**；提前进站（付出 `c_down`）可能在总收益上优于「最后一圈推光余量」。

**定理 20（用法–健康耦合的稳定性）** 在定义 322 的阻尼迭代下，若磨损对节奏的 Lipschitz 常数 `L_w` 与规划视界满足 `β·L_w·H_plan < 1`，迭代收敛到唯一不动点 `π*`；否则出现「预测能撑→推得更猛→退化更快→预测下调→急收」的振荡。系：**必须给耦合加阻尼/滞环**，并让 RUL 更新有最小驻留时间；否则预测性维护会制造它本要避免的不稳定。

## 6. 本轮最大风险

**一句话**：PACE-RAS 把安全押在「健康/RUL 模型与对手模型是对的」这一前提上——**预测性维护最经典的失效恰恰是「仪表盘永远绿色」：健康遥测本身漂移、被投毒、或退化轨迹外推出错，会让系统得到一句致命的「还来得及」，于是在赛程末段把余量全部推光；而所有证书在故障发生前都合法，直到余量归零的那一步同时击穿内圈安全核**——**预测性维护最大的谎言，就是「还来得及」。**

**次级风险与缓解**：
1. **用法–健康强耦合导致振荡** → 阻尼迭代 + 最小驻留时间 + 滞环（定理 20）；
2. **RUL 删失/外推偏差** → 生存分析 + 5% 下界 + 物理冗余交叉校验，绝不用均值；
3. **自适应对手让 k-一致失效** → anytime-valid e-process + minimax/regret + ℰ_strategic 对抗训练（引理 22）；
4. **提问泄露私有状态** → 泄露成本进入 NEVSI；高 κ 时优先被动信息采集；
5. **慢环延迟/陈旧** → 异步两时间尺度 + 事件触发 + 快环保留 R69 内核，慢环永不阻塞快环；
6. **健康遥测投毒/假健康** → 独立物理冗余 + 元维护有界递归（定义 326），越界即 `safe_stop`；
7. **维护瞬态破坏控制连续** → 仅在认证安全态维护 + bumpless transfer + 维护后重签证书。

**定义 312–313（PACE-MDP 与节奏-余量动力学）** 状态 `(x,w,H,B,c,θ̂)`；目标 `max E[Σγ^t R]` s.t. `P(m<0)≤δ`、预算非负。磨损 `w=w_0+w_a+w_g‖g‖+w_λ(1/λ)`，`m_{t+1}=m_t−Δw+u_mnt−ξ`。

**定义 314–315（EVSI/等待期权 与 竞争/泄露）** `EVSI≤VoI`；`SV=EVSI−未来EVSI`；`NEVSI=EVSI−c−κL`。对手自适应 ⇒ `max_π min_σ`，用遗憾度量；提问动作可见 ⇒ 泄露 `L(g)`，净信息价值可为负。

**定义 316–317（SHT 与 AVD）** 模态作为赛马，`E_{k,t}=∏e_{k,s}`，`E≥1/α` 宣布胜出；Ville 界保证任意停时第一类错误 ≤ α。取代固定 k-一致（后者对可选停止失效）；多重检验做 α 分配；对抗数据用 hedged e-process。

**定义 318–319（健康与 RUL）** `H_t∈[0,1]^5` 随负载退化；`RUL` 在**右删失**下用生存分析估计，安全侧取 5% 下界 `RUL^LB`，禁止用均值（均值系统性高估）。

**定义 320–321（维护与调度）** `MNT={recal,refit_flow,reboot_wm,re_ask_human,safe_stop,cool_down}`，维护需认证安全态 + bumpless transfer。A100 下最优为控制限：`h≤h*` 或 `ζ≥ζ*` 即维护；δ 越小 h* 越高。

**定义 322（CDS 耦合）** `π*=G(PHM(load(π*)))`；阻尼迭代，`β·L_w·H_plan<1` 时收敛，否则振荡（需滞环/驻留时间）。

**定义 323–324（HAC 与两时间尺度）** `J_PACE` 并入健康/RUL/维护/EVSI/泄露/e-value/regret；慢环 0.1–10s 只输出 `(λ_min, interaction_budget, maint_window, health_gate)`，快环 R69 保留签发权。退化条件 `H=1,w≡0,|Σ_opp|=1,L≡0` ⇒ 逐指令等于 R69。

**定义 325–326（威胁与元维护）** `ℰ_PACE=ℰ_FLUID×ℰ_strategic×ℰ_leak×ℰ_health`；元维护用「保守先验 + 独立物理冗余 + 最坏界」，在线只收紧、递归深度硬限 2，越界 `safe_stop`。

## 3. 关键算法伪代码

```python
# IP-264 RSP：有限视界赛程规划（慢环，只输出约束）
def race_strategy(state, H_plan, model):
    best = None
    for plan in candidate_plans(state):               # 节奏档 × 交互时点 × 维护窗口
        try:
            val = (expected_utility(plan, state, model)
                   - risk_penalty(plan, state, model)
                   - leak_cost(plan, state, model))
            if feasible(plan, state, model) and (best is None or val > best.val):
                best = (plan, val)
        except ConstraintViolation:
            continue
    return best.plan                                  # 不下控制指令，只给可行域

# IP-265/267：EVSI + 等待期权 + 泄露（替代贪心熵式 VoI）
def choose_ask_evsi(modes, w, state, budget, opponent):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, state.o): continue
        if not leak_budget.allow(g): continue
        evsi = decision_voi(w, g, state.D)            # E_y[max_d E[U]] - max_d E[U]
        net  = evsi - wait_option_value(state, g) - cost(g) - KAPPA * leakage(g, state.S_priv)
        if best is None or net > best.net: best = (g, net)
    return best if best and best.net > 0 else None    # ≤0：沉默优于提问

# IP-268/269：序贯模态锦标赛（anytime-valid）
def sequential_mode_test(modes, evidence_stream, alpha):
    E = {k: 1.0 for k in modes}
    for y in evidence_stream:
        for k in modes:
            E[k] *= likelihood_ratio(y, k, modes)     # 对抗版换成 hedged e-process
        winners = [k for k, v in E.items() if v >= 1.0/alpha]
        if winners: return winners, E
    return [], E                                       # 未定案 → U_epi 未消解，R69 兜底

# IP-270/271：删失 RUL + 控制限维护
def prognose(health_stream, load_profile):
    theta = fit_survival(health_stream, censored=True, covariates=load_profile)
    rul   = rul_distribution(theta)                    # Weibull / gamma / Cox
    return rul.quantile(0.05), rul                     # 安全用 5% 下界

def maintain_if_needed(h, hazard, rul_lb, plan):
    if not safe_to_maintain(plan): return None         # 禁止高速换胎
    if h <= H_STAR or hazard >= ZETA_STAR or rul_lb <= plan.time_to_next_window:
        return best_maintenance(plan)
    return None

# IP-276 主闭环：外圈只收紧，内圈仍是 R69 FLUID
def PACE_round(M, obs):
    # ---- 慢环（异步，每 T_slow 一次）----
    H, rul_lb = M.phm.update(obs, M.load_hist)
    plan      = M.rsp.solve(M.state, H, M.opponent_belief)
    mnt       = M.msp.maintain_if_needed(H, M.phm.hazard, rul_lb, plan)
    if mnt is not None:
        M.execute_maintenance(mnt)                     # 认证安全态 + bumpless
    if mnt in (MNT.safe_stop,): return SAFE_STOP
    # ---- 快环：R69 FLUID 在收缩后的可行域内运行 ----
    if not plan.health_gate:
        return M.fluid.round_conservative(obs, lam_min=0.8)   # 健康门失败 → R69 纯保守
    k, lam, mode, U = M.fluid.round(obs,
                                    interaction_budget=plan.interaction_budget,
                                    lam_min=plan.lambda_min)
    # ---- 证据：anytime-valid，替代固定 k-一致 ----
    E = {mode.k: 1.0}
    if U.epi > TAU_EPI and M.avd.may_sample():
        winner, E = M.sht.step(mode, M.evidence)
        U = M.avd.update(U, winner, E, alpha=M.avd.alpha_spend())
    # ---- 证书 ----
    M.hac.emit(J_PACE(J_FLUID=lam.cert, H=H, RUL_LB=rul_lb,
                      maint_due=(mnt is not None), lambda_plan=plan.lambdas,
                      budget_left=M.budget, evsi_ratio=plan.evsi_ratio,
                      leakage_est=M.csc.leakage, e_value_max=max(E.values()),
                      regret_bound=M.csc.regret))
    return k, lam, mode, U
```

## 4. 推导

**引理 19（EVSI ≤ VoI；贪心 = H=1 特例）** 任意先验下 `EVSI(g) ≤ VoI(g)`；在 A99（单模态决策、0-1 正确性效用、对称成本）下二者同序。取 `H=1`、无预算稀缺、无磨损、无对手、无泄漏，则 PACE 与 R69 MINT 逐指令相同。要点：R69 的贪心在有限赛程里**系统性高估早期信息、低估晚期信息**。

**引理 20（信息预算守恒 / 双阈值）** 若临界性 `c_t` 与歧义 `U_epi` 联合超模、EVSI 对 `c_t` 单调且对预算边际递减，则最优提问为双阈值：`c_t·U_epi ≥ τ(剩余视界)` 才问，`τ` 随剩余视界缩短而下降。系：**关键赛段前最优策略可主动囤积交互预算、临时收紧 λ 换余量**；提问与维护同构为控制限。

**引理 21（控制限维护最优性）** A100 下存在 `(h*,ζ*)` 使控制限策略最优；`δ` 越小 `h*` 越高。系：RUL 不完美只推动阈值保守化，不改变阈值结构——故 prognostics 有误差时控制限仍稳健。

**引理 22（自适应对手下 k-一致失效；e-process 必要）** 对手可预测地选择回答时，任何「问到 k 源一致」的固定样本规则都能被驱动到任意高错误采纳率；而 `E_{k,t}` 的 Ville 界在任意停时、任意可预测数据下成立，错误宣布率 ≤ α。又因 `L(g)` 可正，存在**「信息上值得问、策略上不该问」**的状态。

**定理 18（PACE 严格包含 R69，安全单调）** 慢环只收缩快环可行域，证书签发权不变 ⇒ PACE 认证动作集在安全侧 ⊆ R69，`P(风险>ε) ≤ P_R69`；退化条件下二者逐指令相同。R69 是 PACE 的「单圈、无磨损、无对手」极限。

**定理 19（赛程可行性与安全–进度前沿）** 节奏策略可行 ⇔ `Σ Δw(λ) ≤ m_0 + Σu_mnt − q_δ√(ΣΔ²σ_w²)`；由此得安全–进度 Pareto 前沿。系：维护窗口是赛程规划内生变量，提前进站可能优于「最后一圈推光余量」。

**定理 20（用法–健康耦合稳定性）** 阻尼迭代 `π^{(j+1)}=(1−β)π^{(j)}+βG(PHM(load(π^{(j)})))` 在 `β·L_w·H_plan<1` 时收敛到唯一不动点；否则出现「预测能撑→猛推→退化加速→急收」振荡，需阻尼/滞环/最小驻留时间。

## 7. 本轮最大风险

**一句话**：PACE-RAS 把安全押在「健康/RUL 模型与对手模型是对的」这一前提上——**预测性维护最经典的失效恰恰是「仪表盘永远绿色」：健康遥测本身漂移、被投毒、或退化轨迹外推出错，会让系统得到一句致命的「还来得及」，于是在赛程末段把余量全部推光；所有证书在故障发生前都合法，直到余量归零那一步同时击穿内圈安全核**——**预测性维护最大的谎言，就是「还来得及」。**

**次级风险与缓解**：用法–健康强耦合振荡（阻尼 + 滞环 + 驻留，定理 20）；RUL 删失/外推偏差（生存分析 + 5% 下界 + 物理冗余，绝不用均值）；自适应对手使 k-一致失效（e-process + minimax/regret + ℰ_strategic，引理 22）；提问泄露私有状态（泄露成本入 NEVSI，高 κ 转被动采集）；慢环延迟/陈旧（异步两时间尺度 + 事件触发 + 快环 R69 内核）；健康遥测投毒/假健康（独立物理冗余 + 元维护有界递归，越界 `safe_stop`）；维护瞬态破坏控制连续（仅认证安全态维护 + bumpless + 重签证书）。
