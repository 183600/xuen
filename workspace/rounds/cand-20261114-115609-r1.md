# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「可扩展性」×「多语言支持」）

> R69 教会闭环「提问」：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略显式摆出「几个候选动作」，再主动用看 / 问 / 触去消解。但它有一个几乎没人点破的隐含假设——**提问发生在一个单点、单语、单标定域的实验室里**。
>
> 一旦把 R69 放进真实世界，两个看似工程性的词会变成**认识论算子**：
> - **可扩展性**：N 个站点、N 个智能体不是把单机策略复制 N 份。它们共享标定数据、共享翻译器、共享世界模型、共享同一个人工客服；它们的「互相印证」可能只是**同一个错误戴着 N 张脸**。规模不是线性放大能力，而是**非线性放大相关性**。
> - **多语言支持**：语言不是把同一句话换编码。它同时是（a）潜在的独立探针——同一命题若在祖先不相交的语言路径下都被确认，可信度真的更高；（b）伪装成独立的自相关源——经同一个 pivot、同一个 LLM、同一种文化前见翻译出的「多语一致」是**假共识**；（c）新的攻击面——低资源语言的安全过滤器最弱，翻译能把越狱指令洗白。
>
> 核心命题：**R69 的「问谁、问什么」在规模与语言下必须再加一问——「这些回答的祖先是否真的不相交」。** 名义上的 k 源一致不是证据；**有效独立源数 r_eff** 才是。校准也不能再是全联邦一个 ECE，而必须是**分层、按格、最差格同时保证**。命名 **POLYGLOT-RAS**（Polycentric, Orchestrated, Language-aware, Yield-governed, Local-to-global, Orthogonal-evidence, Trust-calibrated Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**当求证者遍布多站点、说多种语言时，它们的一致还是证据吗**」——规模与语言不是部署参数，而是会改写「证据」定义的两个算子。

## 0. 直觉与动机

**灵感 1（可扩展性 → 不是「更大」，而是「保证可组合」）**
直觉：把单机策略复制 N 份，得到的是「N 个各自局部正确」的系统，不是「一个全局正确」的系统。原因有三：第一，它们**共享失败模式**（同一批标定数据、同一个翻译器、同一个世界模型），所以「本地都对」不代表「联合都对」；第二，它们的**交互会耦合**（N 个智能体追问同一个人、同一条回答在联邦里回响）；第三，它们的**近似会累积**（每个站点为省算力做蒸馏 / 降采样，误差叠加）。所以可扩展性的真正定义是三条：保证在组合下不减弱（non-amplification）、失败可被隔离（graceful degradation）、共享组件被当作**相关证据**而非独立证据。规模本身不是能力，是一个**相关性放大器**。

**灵感 2（多语言支持 → 语言既是探针，也是共谋）**
直觉：R69 里「问」是一个语言动作，默认只有一种语言、一个冻结 LLM。多语言把它一分为三。正面：不同语言路径是**天然的改写探针**——一个命题若在祖先不相交的多条语言路径下都被确认，比同义反复强。负面：若这些语言路径共享一个 pivot、一个模型、一种文化先见，它们的错误高度相关，「多语一致」只是同一错误的多副面孔——这是**假共识（counterfeit consensus）**。第三面：低资源语言的安全对齐最弱，翻译是一个**洗白通道**——把危险意图从高资源语言翻译到低资源语言再翻译回来，过滤器可能两头都漏。所以多语言支持不能「加语言就加置信」，必须**先算证据秩、再算覆盖税**。

**灵感 3（分层标定 → 可扩展性的真瓶颈是长尾格子）**
直觉：R69 的 MCG 只问「全局 ECE 过不过」。规模一大，标定域变成 site × language × task × regime 的笛卡尔积，绝大多数格子是**长尾**：没有足够数据独立估 ECE。独立标定会数据饥饿，全局池化又会**用平均掩盖最差格**（Simpson 式陷阱：整体 ECE 0.04，你此刻所在的小语种格子可能 0.4）。正确对象不是平均 ECE，而是**每个格子的单侧置信上界**与**跨全部格子同时成立**的保证；无法认证的格子必须**就地 fail-closed**，退化为 R68，而不是向邻居「借」信心。这就引出「信任运输」：借可以，但必须付「分布偏移税」。

**灵感 4（共享即相关 → 用祖先图算「证据秩」）**
直觉：联邦里「A 问 B，B 问 C，C 又引用 A」会形成回音室；三个智能体「一致」可能只是一个源头绕了三圈。判断独立性的正确工具不是「是不是不同 agent」，而是 **provenance**：每条证据来自哪个人、哪个模型、哪个翻译器、哪条语言路径、哪个站点。两条证据的独立性 = **祖先集合的重合度**。由此可以把 R69 引理 18 里那个从天而降的「k 个正交源」换成可计算的**有效独立源数 r_eff**（相关矩阵特征值的参与率）。名义 k=3 但 r_eff=1.1 时，系统必须承认：我其实只问了一次。

**灵感 5（压缩即欠账 → 蒸馏与降采样必须带保真证书）**
直觉：要撑住 N 站点与更大 K，必然要蒸馏流策略（少步数、小模型、模式缓存）与批处理。但压缩会**删掉稀有模态**（恰恰是安全关键的那个）或**幻觉出新模态**。R69 已经怕「问错比不问更危险」；如果压缩是静默的，那就是**在安全账本上做假账**。所以任何近似都必须付一张**保真证书**：教师–学生的模态分布 W_2 距离上界 B_fid，直接作为「压缩不确定度」加进两级退避的 floor。压缩只能省算力，不能省安全。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（POLYGLOT-RAS 总览与四不变式）** POLYGLOT-RAS = (FED, HCL, EVI, XLG, FID, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **局部保证不因联邦组合而减弱**：任意站点子集组合的期望风险 ≤ 各站点单机风险的同权重上界 + 显式放大预算 ε_amp（non-amplification）；
(iii) **证据秩诚实**：k 源一致的置信度必须用有效独立源数 r_eff 计，不得用名义 k；祖先未知一律按完全相关处理；
(iv) **校准局部性与 fail-closed**：每个 (site, language, task, regime) 格子的信任不得无偿外借；无法认证的格子就地退化为 R68 纯保守。

**定义 311（联邦站点与契约消息）** N 个站点 s_i，各有本地 FLUID 实例 M_i、本地标定格 C_i、本地语言集 L_i。站点只通过**契约消息**交换：模式原型（脱敏）、标定充分统计量（非原始数据）、证据条目（带 provenance）。契约消息必须可验证（签名 + 差分隐私预算 + 来源标签）；禁止交换原始观测 / 动作（隐私与失败模式隔离）。

**定义 312（证据 Provenance DAG）** 每条证据 e 携带祖先集合 anc(e) = {human, model, translator, pivot, language_path, site, tool, timestamp}。关键祖先按类别加权（translator / model / human 权重高于 site / timestamp）。两条证据的**共享祖先质量** σ(e_i,e_j) ∈ [0,1] 是加权 Jaccard 重合度；σ 是「相关性」的可审计代理，而不是假设。

**定义 313（证据相关矩阵与有效秩）** 对 k 条证据的误差，估计相关矩阵 R（离线用重复测量 / Monte-Carlo 翻译扰动 / bootstrap）。有效独立源数定义为其特征值参与率
r_eff = (Σ_i λ_i)² / Σ_i λ_i²，λ_i 为 R 的本征值。
R=I ⇒ r_eff=k；完全相关 r_eff=1；等相关 ρ 时闭合式 r_eff(ρ)=k² / [(1+(k−1)ρ)² + (k−1)(1−ρ)²]，关于 ρ 单调不增。这是 R69 引理 18 中名义 k 的严格替代，也是「多语一致」是否可信的判决变量。

**定义 314（翻译通道模型）** 问句 / 答句经语言路径 ℓ: L_src→L_tgt。翻译是随机信道 T_ℓ，引入语义失真 d_ℓ = D(p_true, p_{T_ℓ})（用回译一致度 / 蕴含概率估计）。两条路径若共享 pivot / 模型 / 文化先见，则其祖先重合、σ 上调、r_eff 下调。**翻译既是独立探针，也是虚假共识的制造机**——判据只能是路径祖先是否重合，而不是「语言是否不同」。

**定义 315（反虚假共识门 ACG, Anti-Counterfeit Gate）** 采纳前计算 r_eff。若名义 k≥2 但 r_eff < τ_eff（默认 1.5），判定为**虚假共识**：拒绝定案，U_epi 保持未消解并走 R68 兜底。等价地：一致必须来自**祖先不相交**的通道，而不是同一通道的不同语言皮肤。

**定义 316（分层标定 HCL）** 格子 c = (site, language, task, regime)。标定参数 θ_c 服从层级先验 θ_c ~ N(θ_parent(c), Σ_c)（partial pooling），用 empirical Bayes / 多级模型估计。交付物不是点估计 ECE_c，而是**单侧置信上界** UCB_α(ECE_c)。长尾格子借父层先验，但借来的不确定度按定义 318 膨胀。

**定义 317（同时保证与联邦 ECE）** 对全部 C 个格子要求 P(∀c: ECE_c ≤ τ_ece) ≥ 1−α（Bonferroni / e-value / 分层 conformal 的 simultaneous coverage）。任一格子 UCB 越界 ⇒ 该格子局部 fail-closed；若越界格子比例 > β，整个联邦进入全局 R68 保守态。

**定义 318（信任运输 TTP）** 从父格 p 向子格 c 借标定时必须通过**运输测试**：shift(c,p) = W_2(p_feat^c, p_feat^p)/σ_ref ≤ τ_shift；借来的上界按 α_trans·shift 膨胀：ECE_c^borrow = ECE_p + α_trans·shift(c,p) + slack_conformal。不通过则不得借。⇒ 信任不会无证据地跨格传播，只会在付「偏移税」后有限传播。

**定义 319（联邦模式库 FML）** 全局模式原型库 M_global = {ξ̄_k, Σ_k, w_k, provenance}；站点用本地残差适配，匹配用 Fréchet 距离 + provenance 一致性。全局库只提供**候选**，不提供**置信**；置信必须由本地 HCL 认证。⇒ 防止「别处的模式」冒充「这里的模式」（跨站点长尾覆盖与本地幻觉的分离）。

**定义 320（蒸馏保真证书 FID）** 把 FMP 蒸馏为学生策略 π_s（更少步数 / 更小模型 / 模态缓存），双向采样的 W_2 上界 B_fid 作为保真证书。压缩不确定度 U_comp = B_fid 并入两级退避：
λ = λ_floor(U_ale + U_epi_unresolved + U_comp)。
⇒ 压缩不能在安全账本上静默免单；它买到的是算力，支付的是安全余量。

**定义 321（联邦升级格 ESC）** 本地无法消解的 U_epi 按偏序升级：本地交互 → 祖先不相交的同伴 → 更高算力站点 → 人类专家。每级只能提交**证据**，不能直接改写安全状态；升级代价随层级递增，总预算硬约束（继承 R69 定义 293-ii）；升级图必须**无环**（禁止 A→B→C→A 的回音室）。

**定义 322（跨语言安全不变式 XLG）** 存在语言无关的安全谓词集合 Safe_inv（碰撞、力 / 位包络、隐私泄露、时间窗），其真值不依赖语言表达。任何动作执行前必须通过 Safe_inv；语言侧安全过滤器只是纵深防御，绝不作为唯一防线。跨语言注入 / 越狱归入 ℰ_xling。

**定义 323（语言覆盖权重 LCV）** 每个语言 ℓ 的覆盖度 cov(ℓ) = 安全过滤器在该语言的验证样本量 / 该语言意图分布的熵代理。cov 低 ⇒ 该语言的提问 / 回答权重下调、证据秩下调、保守度上调。低资源语言不能自动获得与高资源语言相同的信任——这是**显式、可审计的不对称**，而非隐性偏见。

**定义 324（干扰集 ℰ_POLY）** ℰ_POLY = ℰ_FLUID × ℰ_xling × ℰ_fed。ℰ_xling = {翻译诱导语义漂移、跨语言越狱、pivot 虚假共识、文化语用错配}；ℰ_fed = {联邦回音室、共享祖先冒充独立、传输投毒、校准借用的对抗 shift}。并入 AIC-FED。

**定义 325（证书 J_POLY）** J_POLY = (J_FLUID, r_eff_min, worst_cell_ECE_UCB, transport_hash, fid_bound, prov_DAG_hash, cov_min, poly_ver)。Valid ⇔ Valid(J_FLUID) ∧ ACG 通过 ∧ 全局 simultaneous ECE 满足 ∧ FID 在账本内 ∧ 升级图无环 ∧ Safe_inv 全过。

**定义 326（可组合风险界）** 联邦风险 R_fed ≤ Σ_i π_i R_i + R_amp，π_i 为站点流量权重，R_amp 为交互 / 共享组件引入的**放大项**。R_amp ≤ ε_amp，ε_amp 由跨站点共享祖先总质量与升级图连通度界定；祖先不相交且图无环时 ε_amp → 0。

**定义 327（自适应规模采样）** 站点按负载自适应 K 与 N_step（继承 R69 定义 308），可信上界由本地 HCL 给出；全局调度器用共享模式缓存 + 蒸馏 + 批处理保证 P99 不随 N 线性爆炸。任何降采样必须携带 FID（定义 320）；超预算时优先缩短升级链，而不是放宽证据纪律。

**定义 328（跨语言探针的 VoI）** 在 R69 定义 298 上扩展信息动作 g_ℓ = 用语言 ℓ 提问：
VoI_eff(g_ℓ) = H(M|o) − E_{y_ℓ}[H(M|o,y_ℓ)] − c(g_ℓ) − λ_d·d_ℓ；
多语言批量价值用 r_eff 计权而非名义条数，故「问两种便宜但高度相关的语言」不会被重复计分。只有当跨语言路径祖先不相交、且 cov(ℓ) 足够时，多语提问才产生净 VoI。

## 2. 关键算法骨架

```python
# IP-265 EVI：从 provenance 估有效独立源数（R69 引理 18 的名义 k 的替代）
def effective_rank(evidence, corr_estimator):
    R = corr_estimator(evidence)                  # 由祖先重合 + 重复测量估相关
    lam = eigvalsh(R)
    return (lam.sum() ** 2) / (lam ** 2).sum()   # 参与率 r_eff ∈ [1, k]

# IP-266 ACG：反虚假共识门（多语/多站点一致必须过此门才可定案）
def anti_counterfeit(evidence, tau_eff=1.5):
    if len(evidence) < 2: return False
    r_eff = effective_rank(evidence, est_corr)
    return r_eff >= tau_eff                   # 否则：虚假共识，拒绝定案

# IP-267 HCL：分层标定，交付最差格的单侧置信上界（而非平均 ECE）
def worst_cell_ucb(cells, alpha):
    eb = fit_hierarchical_bayes(cells)         # partial pooling
    ucb = {c: one_sided_ucb(eb[c], alpha=alpha / len(cells)) for c in cells}
    return ucb                                # 同时保证：P(∀c ECE_c<=tau)>=1-alpha

# IP-268 TTP：跨格借信任必须付「偏移税」，过不了就地 fail-closed
def transport_calibration(child, parent, alpha_trans):
    shift = wasserstein2(child.feat, parent.feat) / REF_SCALE
    if shift > TAU_SHIFT: return None         # 不得借 → 本地 R68 保守
    return parent.ece_ucb + alpha_trans * shift + CONFORMAL_SLACK

# IP-270 FID：蒸馏保真证书，压缩不确定度并入安全 floor
def fidelity_bound(teacher, student, n=512):
    a, b = teacher.sample_batch(n), student.sample_batch(n)
    return quantile_ucb(wasserstein2(a, b), q=0.95)   # B_fid

# IP-273 ESC：无环升级格，只提交证据、不直接改安全状态
def escalate(case, graph, budget):
    for level in graph.topo_order(case.site):  # DAG，禁止回音室
        if not budget.allow(level): break
        if level.ancestry_disjoint(case.evidence):
            yield level.request(case)          # 仅返回证据
    return None                                # 升级失败 → R68 兜底

# IP-277 主闭环（继承 R69 FLUID，插入联邦/多语纪律）
def POLYGLOT_RAS_round(M, obs, cell):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)     # 继承 R68
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 1) 本地模式候选可向 FML 查询，但置信只认本地 HCL
    if M.fml is not None: modes = M.fml.augment(modes, cell)       # 候选，不带置信
    # 2) 多语/多站点交互：只选祖先可分离、覆盖足够的探针
    g = M.mint.choose_interaction(modes, o, M.budget, cell,
                                  weight=lambda gg: cov(cell.lang(gg)) * d_penalty(gg))
    ev = []
    if g is not None:
        ev.append(M.cia.execute(g))
        for peer in M.esc.peers(cell, budget=M.budget):            # 无环升级
            ev.append(peer.ask(g))
    # 3) 反虚假共识门：名义条数不算数，r_eff 才算数
    settled = (len(ev) >= 2) and anti_counterfeit(ev, TAU_EFF)
    U_epi_after = M.cia.update_belief(modes, ev) if settled else U_epi
    # 4) 压缩与校准都必须计入账本
    U_comp = M.fid.bound if M.fid is not None else 0.0
    U_floor = U_ale + (U_epi_after if settled else U_epi) + U_comp
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 5) 校准局部性：本格 UCB 越界或运输失败 → 本格 R68 纯保守
    ucb = M.hcl.worst_cell_ucb([cell], M.alpha)[cell]
    if ucb > TAU_ECE or not safe_inv_pass(o, cell):
        lam = max(lam, LAM_SAFE)                                   # fail-closed
    # 6) 语言无关安全不变式先于一切语言侧过滤
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_f.submit_async(ev, r_eff_of(ev), ucb, U_comp, prov_hash(ev))
    return k, lam, mode, (U_ale, U_epi_after, r_eff_of(ev))
```

## 3. 推导

**引理 19（有效秩与虚假共识上界）** 设 k 条证据误差的相关矩阵为 R，其参与率 r_eff = (tr R)²/tr(R²)。等相关 ρ 特例下 r_eff(ρ)=k²/[(1+(k−1)ρ)²+(k−1)(1−ρ)²]，关于 ρ 单调不增，ρ→1 ⇒ r_eff→1，ρ→0 ⇒ r_eff→k。把 R69 引理 18 的多数一致错误率上界中的名义 k 替换为 r_eff，得错误采纳率 ≤ δ_p·ρ^{r_eff−1} + ε_σ。系：多语一致只有在祖先不相交（σ 小、r_eff 大）时才是证据；当所有语言共享一个 pivot / 模型（ρ→1）时系统等价于单源，ACG 必须拒绝定案——否则规模与语言只会把同一个错误包装成更多「独立确认」。

**引理 20（信任运输的偏移税）** 设格子 c 与父格 p 的特征分布 Wasserstein 距离 Δ = W_2(p_c,p_p)。若标定误差映射关于该距离 L-Lipschitz（A101），则 |ECE_c − ECE_p| ≤ L·Δ + slack_conformal。故借来的上界必须膨胀 α_trans·Δ，且运输测试 Δ ≤ τ_shift 是充分条件（当 α_trans ≥ L）。系：跨格借信任必须付「shift 税」；税后仍越界则 fail-closed，绝不向邻居蹭信心。

**引理 21（蒸馏的保守性）** 设教师–学生模态分布满足 W_2(π_t, π_s) ≤ B_fid。定义压缩不确定度 U_comp = B_fid 并入 floor，则学生策略的两级退避 λ_s = λ_floor(U_ale + U_epi_unres + U_comp) 不小于「教师不计压缩」时的安全下界对应值。故蒸馏只会让 λ 不降（更保守）、效率可升，安全不降。⇒ 压缩是「算力换安全余量」的等价交易，任何白拿都会击穿 R69 定理 16。

**定理 18（联邦组合不放大）** 在 A99–A102（provenance 完整、升级图无环、借用必过运输测试、FID 有效）下，若跨站点证据按 r_eff 计权且升级预算硬约束，则联邦期望风险 R_fed ≤ Σ_i π_i R_i + ε_amp，其中 ε_amp 随共享祖先总质量与升级图连通度单调增、祖先不相交且无环时 ε_amp→0。反之，若任一条被违反，存在构造使 ε_amp 任意大：回音室把单点错误放大为全局共识。⇒ ACG、无环、运输税是**可扩展性的必要条件**，不是可选项；规模本身只放大相关性，不自动带来智慧。

**定理 19（POLYGLOT 严格包含 FLUID 与 R68）** 在「单站点、单语言、无升级、无蒸馏」边界（N=1, |L|=1, B_fid=0, r_eff=k）下，定义 310–328 逐条退化为 FLUID 的定义 293–309，再由 R69 定理 16 退化为 R68；安全侧永不弱于 FLUID / R68，效率仅在通过认证时获得 resolution bonus。⇒ 延续「新层必须是旧层严格退化」的理论纪律，避免每加一层就多一个需要独立信任的黑箱。

**定理 20（跨语言安全不变式的不可绕性）** Safe_inv 是与语言无关的执行前谓词；任何动作在执行前必须通过 Safe_inv，语言侧过滤器只是纵深防御。故跨语言越狱 / 注入（ℰ_xling）无法产生一个「通过 Safe_inv 的不安全物理动作」；但**语义层面的误导**（让人相信错误结论、诱导社交工程）不在 Safe_inv 覆盖范围内。⇒ 物理安全可证，语义安全仍留在最大风险里。

## 6. 本轮最大风险

**一句话**：POLYGLOT-RAS 把安全押在「证据祖先可追踪、r_eff 可估」这一前提上——但多语言与多站点恰恰让祖先图**不可观测**（你不知道那条低资源语言的回答背后是不是同一个 pivot、同一个模型、同一次翻译），一旦「祖先缺失」被默认当作「独立」而非「完全相关」，ACG 就会 fail-open，联邦会把「同一个错误换几套语言外衣」算成「多方独立验证」，于是规模越大、语言越多，系统越自信地错。

**次级风险与缓解**：
1. **标定长尾把平均骗成全局可信** → HCL 最差格 UCB + simultaneous coverage + 局部 fail-closed（定义 316–317）；
2. **跨格借信任的对抗 shift** → TTP 偏移税 + 运输测试不过即拒借（定义 318、引理 20）；
3. **压缩删掉安全关键稀有模态** → FID 保真证书并入 floor，蒸馏只能省算力（定义 320、引理 21）；
4. **联邦回音室与共享祖先冒充独立** → provenance DAG + ACG + 无环升级格（定义 312/315/321、定理 18）；
5. **低资源语言过滤器最弱** → 语言无关 Safe_inv 前置 + LCV 覆盖税 + ℰ_xling 对抗训练（定义 322–324、定理 20）。

```python
# IP-265 EVI：从 provenance 估有效独立源数（替代名义 k）
def effective_rank(evidence, corr_estimator):
    R = corr_estimator(evidence)                  # 祖先重合 + 重复测量
    lam = eigvalsh(R)
    return (lam.sum() ** 2) / (lam ** 2).sum()   # r_eff ∈ [1, k]

# IP-266 ACG：反虚假共识门（多语/多站点一致必须过此门）
def anti_counterfeit(evidence, tau_eff=1.5):
    if len(evidence) < 2: return False
    return effective_rank(evidence, est_corr) >= tau_eff

def worst_cell_ucb(cells, alpha):

    return parent.ece_ucb + alpha_trans * shift + CONFORMAL_SLACK

        if level.ancestry_disjoint(case.evidence):
            yield level.request(case)
    return None

    settled     = (len(ev) >= 2) and anti_counterfeit(ev, TAU_EFF)
    U_epi_after = M.cia.update_belief(modes, ev) if settled else U_epi
    U_comp      = M.fid.bound if M.fid is not None else 0.0
    U_floor = U_ale + (U_epi_after if settled else U_epi) + U_comp
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    ucb = M.hcl.worst_cell_ucb([cell], M.alpha)[cell]
    if ucb > TAU_ECE or not safe_inv_pass(o, cell):
        lam = max(lam, LAM_SAFE)                                  # 本格 fail-closed
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_f.submit_async(ev, r_eff_of(ev), ucb, U_comp, prov_hash(ev))
    return k, lam, mode, (U_ale, U_epi_after, r_eff_of(ev))
```

## 4. 推导

**引理 19（有效秩与虚假共识上界）** 证据误差相关矩阵 R 的参与率 `r_eff=(trR)²/tr(R²)`；等相关 ρ 时 `r_eff(ρ)=k²/[(1+(k−1)ρ)²+(k−1)(1−ρ)²]` 单调不增，ρ→1 ⇒ r_eff→1，ρ→0 ⇒ r_eff→k。将 R69 引理 18 错误采纳上界的名义 k 换成 r_eff，得 `≤ δ_p·ρ^{r_eff−1}+ε_σ`。系：多语一致只有祖先不相交时才是证据；共享 pivot / 模型时系统等价单源，ACG 必须拒判。

**引理 20（信任运输的偏移税）** 若标定误差映射关于 `W_2` 距离 L-Lipschitz（A101），则 `|ECE_c−ECE_p| ≤ L·Δ + slack`（`Δ=W_2(p_c,p_p)`）。故借用上界必须膨胀 `α_trans·Δ`（`α_trans≥L`），且 `Δ≤τ_shift` 是充分条件。⇒ 跨格借信任必须付「shift 税」，税后越界即 fail-closed。

**引理 21（蒸馏的保守性）** 若 `W_2(π_t,π_s)≤B_fid` 且 `U_comp=B_fid` 并入 floor，则学生两级退避 `λ_s=λ_floor(U_ale+U_epi_unres+U_comp)` 不小于教师不计压缩时的安全下界对应值。⇒ 蒸馏只让 λ 不降、效率可升，安全不降；白拿压缩会击穿 R69 定理 16。

**定理 18（联邦组合不放大）** 在 A99–A102 下，若跨站点证据按 r_eff 计权、升级图无环、借用必过运输测试，则 `R_fed ≤ Σπ_iR_i + ε_amp`，`ε_amp` 随共享祖先质量与图连通度单调增、祖先不相交且无环时 →0。任一条被违反则存在构造使 `ε_amp` 任意大（回音室把单点错误放大为全局共识）。⇒ ACG、无环、运输税是可扩展性的**必要条件**。

**定理 19（POLYGLOT 严格包含 FLUID 与 R68）** 在 `N=1, |L|=1, B_fid=0, r_eff=k` 边界下，定义 310–328 逐条退化为 R69 定义 293–309，再由 R69 定理 16 退化为 R68；安全侧永不弱，效率仅在通过认证时获 resolution bonus。⇒ 新层严格退化旧层，避免新增不可信黑箱。

**定理 20（跨语言安全不变式的不可绕性）** `Safe_inv` 是语言无关的执行前谓词，语言过滤器仅纵深防御；跨语言越狱 / 注入无法产生「通过 Safe_inv 的不安全物理动作」，但**语义误导 / 社交工程**不在 Safe_inv 覆盖内。⇒ 物理安全可证，语义安全仍留在最大风险。

## 7. 本轮最大风险

**一句话**：POLYGLOT-RAS 把安全押在「证据祖先可追踪、r_eff 可估」这一前提上——但多语言与多站点恰恰让祖先图**不可观测**（你不知道那条低资源语言的回答背后是不是同一个 pivot、同一个模型、同一次翻译），一旦「祖先缺失」被默认当作「独立」而非「完全相关」，ACG 就会 fail-open，联邦会把「同一个错误换几套语言外衣」算成「多方独立验证」，于是规模越大、语言越多，系统越自信地错。

**次级风险与缓解**：标定长尾骗过平均值（HCL 最差格 UCB + simultaneous coverage + 局部 fail-closed）；跨格借信任的对抗 shift（TTP 偏移税 + 运输测试拒借）；压缩删掉安全关键稀有模态（FID 保真证书并入 floor）；联邦回音室与共享祖先冒充独立（provenance DAG + ACG + 无环升级格）；低资源语言过滤器最弱（语言无关 Safe_inv 前置 + LCV 覆盖税 + ℰ_xling 对抗训练）。
