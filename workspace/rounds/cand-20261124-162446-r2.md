## 0. 直觉与动机

**灵感 1（云边协同 → 安全证书必须对"分区"封闭，云只能加约束、不能授许可）**
直觉：v22 的证书隐含一个不成立的假设——感知、模型、规则库都"就在本地且永远新鲜"。云边协同撕开它：全局场景先验、跨站事故负知识、规则库、校准模型在云上；实时融合与控制必须在端上（50Hz、<10ms）；边居中。云能给出 v22 拿不到的**全局负信息**（"这条走廊昨天有人摔倒""该型号检测器在强逆光下的召回率已下调"），但云的延迟/分区/吊销滞后会直接毒化安全证书。核心反直觉点：**把证书状态组织成"越大越保守"的 join-半格，云-边-端同步 = 取 join**，于是合并只会更保守，分区期间本地状态天然是安全下界。更关键的一条纪律：**云永远不得授予许可，只能追加限制或吊销前提**——许可必须由端侧本地证据签发。这把最危险的信号"云侧吊销到达得太晚"转化为可处理的"租约到期即失效"：每个可复用前提（模型校准 / 地图瓦片 / 场景先验 / 规则版本 / 召回下界 κ_c）都是一张**带 TTL 的租约**，断网不续约 ⇒ 自动回落最保守默认。核心创新：**云边安全格 (Cloud-Edge Safety Lattice, CESL) + 租约前提与吊销证书 (Leased Premise & Revocation Certificate, LPRC)**。

**灵感 2（场景理解 → 从"有没有物体"到"是什么场景、哪些规则被激活、哪里被语义误判为自由"）**
直觉：v22 的 SDC 只答"这里有没有障碍"，CAC 只答"这里有没有人"，DCL 的规则是**静态全域**的。但安全真正取决于**场景**：同一块地面在"正常巡检"时可行、在"维护作业/交接模式"时禁行；一个人"背对机器人走动"与"面向机器人伸手"对应完全不同的规范；"瓷砖地面"与"镜面/玻璃隔断"决定自由空间能否被赎回。场景理解把感知证书从物体级提升为**类型化场景图**：节点 = 实体/区域（类别、位姿、范围、置信、conformal 半径），边 = 空间与语义关系（遮挡、支撑、邻近、朝向、注视、所属），并自带误差界。核心反直觉点有二：其一，**语义先验正是"自由空间幻觉"的源头**——"看起来像地面"可能是玻璃、镜面、反光低纹理地板，场景理解越强越容易"合规地把假自由空间赎回"；其二，**场景上下文只能收紧规范，不能放宽规范**——除非端侧同时具备 conformal 意图许可与 AbsCert。核心创新：**场景证书图 (Scene Certificate Graph, SCG) + 开放世界场景守卫 (Open-Set Scene Guard, OSSG) + 上下文激活义务调度 (Context-Activated Deontic Scheduler, CADS)**。

**三者如何统一**
统一为 **v22 证书体系之上的"分层-场景"层**：CESL 回答"断网时证书凭什么还成立"（租约 + 单调合并），SCG/OSSG 回答"这是不是一个能赎回自由空间的场景"（开放世界、语义保守），CADS 回答"此刻哪些规则被场景激活"（上下文→规范，单调收紧）。共享状态 ζ_pgev 扩展为 **ζ_ce = ζ_pgev ∪ (L_t 租约集, E_c 吊销纪元, G_t 场景图, U_t 未知集, m_scene 模式)**。统一准入门升级为 **HPC-EC = (HPC-E, SCG, LPRC) 三证一体**：几何∧规范∧负信息(v21) ∧ 能量∧未证伪(v22) ∧ 场景闭合(SCG) ∧ 前提租约有效(LPRC) 才进入执行。CFC++ 扩展为跨层共识：云票只在**限制方向**加权、边票需模态多样性、端票是执行票；任一层缺票都向保守退化。

## 2. 设计原则（在 P37/P41/P42 基础上新增 P43–P46）

**P43 分区安全单调律（Partition-Safe Monotonicity）**
直觉：只要"合并只会更保守、许可只在本地签发"，断网就不会更危险。
定义：证书状态 `(C, ⊑, ⊔)` 为 join-半格，`x ⊑ y` 表示 y 更保守（`Exec(y) ⊆ Exec(x)`）；同步 `C ← C ⊔ C_msg`；`C_msg` 只能是 `restrict`（加约束）或 `revoke`（删租约）。许可只能由端侧本地证据签发。故对任意消息序列 `M`：`Exec(C ⊔ ⨆M) ⊆ Exec(C)`；分区期间本地证书是安全下界。

**P44 租约前提律（Leased Premise）**
直觉：任何"借来的信任"都会过期；过期就等于被吊销。
定义：跨层前提 `p`（模型校准 / 地图瓦片 / 场景先验 / 规则版本 / 召回下界 κ_c）携带 `lease_p=(issue_p, ttl_p, root_p, epoch_p)`；端侧仅在 `Fresh(p,t) ≡ (t ≤ issue_p+ttl_p) ∧ (epoch_local ≥ epoch_p)` 且 `root_p ∈ TrustedRoots` 时可引用。无法证明新鲜 ⇒ 视为已吊销 ⇒ 回落保守默认。故**许可 σ 的有效期 `exp(σ) ≤ min_{p∈Premises(σ)}(issue_p+ttl_p)`**。

**P45 开放世界保守律（Open-World Conservatism）**
直觉：看不懂的东西一律当障碍；"看起来能走"必须先被证伪。
定义：`Obs_t = Hull ∪ ⋃CertBox_k ∪ CertBox_arm ∪ U_t`，未知实体/低置信区域一律并入障碍。语义可通行只在 SCG 给出 conformal 可通行证书、区域内无未知、且无材料歧义（玻璃/镜面/反光）时才赎回，且赎回区域 `⊆ Cov_t ∩ Passable_cert`。云场景先验只能**收紧**约束；先验与实时几何冲突时取并集（更保守）。

**P46 上下文单调激活律（Context Monotone Activation）**
直觉：场景能决定"哪些规矩此刻生效"，但场景本身不该成为放松安全的理由。
定义：CADS 由 `m_scene` 激活规则子集：`Fil_scene(m) = ⋂_{r ∈ Active(m)} Fil_r`。激活只允许**加入**规则（交更多），不得激活任何能放宽几何/负信息证书的规则；放宽仅经端侧 GIC 高门槛 ∧ AbsCert ∧ SCG 可通行证书。

## 3. 与基线的接口（如何退化）

- 云断网/分区 ⇒ 租约过期 ⇒ 前提回落 v22 本地校准（更保守）⇒ `Exec_v23 ⊆ Exec_v22`；
- LPRC 纪元落后 ⇒ 无法证明未吊销 ⇒ 按已吊销处理 ⇒ 保守；
- SCG 失效 ⇒ 退化为 v22 物体级证据，语义可通行不可用（更保守）；
- OSSG 失效 ⇒ 未知一律当障碍 ⇒ 比 v22 更保守；
- CADS 失效 ⇒ 静态规则默认 ⇒ 等价 v22；
- 三层全失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ … ⊆ Exec_v18`（引理 162 链）。
- **安全继承**：CESL 只 join、LPRC 只让许可随租约到期、SCG/OSSG 只增障碍与收紧可通行、CADS 只增约束；任意失效都向更保守方向退化。租约与纪元以事件方式接入 v17 APS 新鲜度阶梯，控制路径仅 O(1) 查询。

## 5. 本轮最大风险

**一句话**：join-半格 + 租约只能覆盖"边侧已持有前提的吊销滞后"，却覆盖不了"云侧刚发现、尚未下发的新危险"——若分区期间云侧才学到某类新风险（新出现的玻璃隔断、某型号检测器逆光下召回骤降），边侧既无该约束可保守、也无租约可过期，机器人会以"分区安全"之名驶入一个它根本不知道存在的危险；而 SCG 的语义先验又可能把这类新障碍误判为可通行地面，二者叠加即"未知的未知 + 语义自由空间幻觉"。

```python
from dataclasses import dataclass, field
from typing import FrozenSet

# IP-436 云边安全格：合并只会更保守（约束取并），云只能 restrict / revoke
@dataclass(frozen=True)
class CertState:
    geo:    frozenset = frozenset()
    dcl:    frozenset = frozenset()
    scene:  frozenset = frozenset()
    energy: frozenset = frozenset()
    lease:  frozenset = frozenset()   # 已接受且未过期的 lease id

    def __or__(self, other):          # join：约束并集 = 更保守
        return CertState(self.geo | other.geo, self.dcl | other.dcl,
                         self.scene | other.scene,
                         self.energy | other.energy,
                         self.lease | other.lease)

    def revoke(self, pid):
        return CertState(self.geo, self.dcl, self.scene, self.energy,
                         frozenset(x for x in self.lease if x != pid))


class CloudEdgeSafetyLattice:
    def merge(self, local: CertState, msg) -> CertState:
        if msg.kind == "restrict":          # 任意延迟都安全
            return local | msg.constraints
        if msg.kind == "revoke":            # 只删租约，不删约束
            return local.revoke(msg.premise_id)
        if msg.kind == "grant":
            raise PermissionError("云不得授予许可（P43）")
        raise ValueError(msg.kind)


# IP-437 租约前提与吊销：许可寿命封顶于最紧前提租约
class LeasedPremiseCertificate:
    def __init__(self, trusted_roots, epoch_local=0):
        self.trusted_roots = set(trusted_roots)
        self.epoch_local = epoch_local
        self.ledger = {}

    def accept(self, p) -> bool:
        if p.root not in self.trusted_roots:
            return False
        if p.epoch < self.epoch_local:       # 旧纪元前提直接拒收
            return False
        self.ledger[p.id] = p
        return True

    def bump_epoch(self, E_c):               # 单调
        self.epoch_local = max(self.epoch_local, E_c)

    def fresh(self, p, now) -> bool:
        return (now <= p.issue + p.ttl) and (self.epoch_local >= p.epoch)

    def valid(self, permit, now) -> bool:    # 许可 σ 的全部前提都新鲜
        return all(self.fresh(self.ledger[pid], now)
                   for pid in permit.premises)

    def expiry(self, permit):                # 许可寿命上界
        return min(self.ledger[pid].issue + self.ledger[pid].ttl
                   for pid in permit.premises)


# IP-438 场景证书图：conformal 节点/边，安全相关子图抽取
class SceneCertificateGraph:
    RELEVANT = {"inspect": {"person", "floor", "glass", "mirror"},
                "maintenance": {"person", "tool", "barrier", "glass"},
                "handover": {"person", "hand", "object", "floor"}}

    def build(self, dets, depth, calib, alpha=0.01):
        nodes = [SceneNode(d.cls, d.pose,
                           inflate(d.box, calib.q(d.score, alpha)),
                           d.score)
                 for d in dets]
        unknown = self._novelty(depth, dets, alpha)     # 开放世界
        edges = self._relations(nodes, depth)           # occludes/supports/...
        return SceneGraph(nodes, edges, unknown)

    def safe_subgraph(self, G, mode):
        keep = {n for n in G.nodes if n.cls in self.RELEVANT[mode]}
        return G.subgraph(keep)

    def passable(self, G, region):
        # 语义可通行：无未知 ∧ 无材料歧义 ∧ 有几何支撑
        return (not (G.unknown & region)
                and not self._ambiguous_material(region)   # 玻璃/镜面/反光
                and self._supported_by_geometry(region))


# IP-439 开放世界场景守卫：未知并入障碍，语义自由空间须证伪后才赎回
class OpenSetSceneGuard:
    def __init__(self, scg, fdr=0.05, tau_open=0.3):
        self.scg, self.fdr, self.tau_open = scg, fdr, tau_open

    def obstacles(self, G):
        return G.unknown | {n for n in G.nodes if n.conf < self.tau_open}

    def redeem(self, region, G, abs_cert):
        if not self.scg.passable(G, region):        return False
        if not abs_cert.valid(region):              return False
        if self.obstacles(G) & region:              return False
        return True


# IP-440 上下文单调激活：只交更多，不放宽
class ContextActivatedDeonticScheduler:
    def infer_mode(self, G, dcl_state):
        if self._has(G, "hand") and dcl_state.handover_ready: return "handover"
        if self._has(G, "barrier") or self._has(G, "tool"):  return "maintenance"
        if self._has(G, "person"):                            return "inspect"
        return "idle"

    def filter(self, plan, G, dcl):
        m = self.infer_mode(G, dcl)
        active = frozenset().union(*RULES[m])
        return dcl.filter(plan, active)              # 交 = 更严
```

```python
    lprc: LeasedPremiseCertificate

    def admits(self, plan, now, region, G, abs_cert):
        # 1) v22：几何 ∧ 规范 ∧ 负信息 ∧ 能量 ∧ 未证伪
        if not self.hpc_e.admits(plan, ...):
            return False
        # 2) 场景闭合：安全相关子图不可通行或含未知 ⇒ 拒
        if not self.scg.passable(self.scg.safe_subgraph(G, plan.mode), region):
            return False
        # 3) 租约封顶：许可的每个前提都必须 Fresh（P44）
        if not self.lprc.valid(plan.permit, now):
            return False
        return True
```

## 2. 理论保证

**引理 163（分区安全）**：若许可仅由端侧本地证据签发、且同步为 join，则对任意云/边消息序列 `M`，`Exec(C ⊔ ⨆M) ⊆ Exec(C)`；分区期间 `Exec(C_local) ⊇ Exec(C_merged)`，但本地每条许可仍由 P44 的租约封顶。*证明思路*：join 只增约束，`Exec` 对约束单调；`revoke` 仅删租约，不删约束。

**引理 164（租约封顶）**：许可 σ 有效 ⇒ `now ≤ min_{p∈Premises(σ)}(issue_p+ttl_p)` 且 `epoch_local ≥ max_{p} epoch_p`。*证明思路*：由 `valid(σ,now)` 的合取展开直接得到。

**命题 165（语义自由空间必须有证）**：`redeem(r)=True ⇒ r ⊆ Cov_t ∧ Passable_cert(r) ∧ r ∩ (U_t ∪ Obs_t)=∅`。故任何未证伪的语义先验都不可能释放自由空间。

## 3. 实验设计（可证伪）

1. **分区-活性-盲窗三角**：模拟云链路中断 `T ∈ {1s, 10s, 1min, 10min}`，测量轨迹活性（可行距离）与"吊销暴露时长"；对比固定 TTL / 关键度分层 TTL / 无租约（v22）。
2. **语义自由空间幻觉**：注入玻璃隔断、镜面、反光低纹理地板；测量 SCG 独用 vs SCG+OSSG 的假自由空间赎回率；期望 OSSG 将其压到 ≤α。
3. **吊销滞后**：对某类模型下发 `revoke` 后人为延迟 `d`，验证 `d > ttl` 时无任何许可仍引用该前提（引理 164）。
4. **跨层共识**：构造"云/边相关故障"（同一模型被投毒），验证云票单独不构成许可、CFC++ 跨层缺票向保守退化。

## 5. 本轮最大风险

**一句话**：CESL/LPRC 的安全性完全依赖"危险来自已有前提的吊销"这一结构假设；一旦出现**云侧新发现、尚未下发的新危险**（分区期新增的玻璃隔断、某检测器逆光召回骤降），边侧既无约束可保守、也无租约可过期，SCG 还可能把它判成可通行地面——机器人将以"分区安全"的合规姿态撞上一个它不知道自己不知道的危险。
