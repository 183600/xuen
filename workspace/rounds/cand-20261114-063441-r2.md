# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 2 轮；本轮灵感：「状态估计」×「碰撞检测」）

> R72 把 GAUGE 从「认知层」下沉到「具身层」：REG 实时执行图、IRL 意图隐变量、DMEM 灵巧接触计量、EREFLEX 三层反作用、S2R-UQ 桥接，确立了「调度可信、意图可辨、接触可计量」时的逐指令风险界。但 R72 把两个最关键的输入当成了**黑箱**：
> - **状态估计视角**：R72 的所有风险缩放、认证前缀、碰撞判决都消费 `b_t(s,z)` 与 `U_ale/U_epi`，却**从不审计估计器本身**。协方差是滤波器**自报**的；一个过度自信的滤波器可以在 NEES 意义上完全错误，却让 λ 变小、认证前缀变长；遮挡/接触丢失下**不可观测**的方向，数据再多也无法降低不确定度；控制域只读的**过期快照**会把 20ms 前的世界当现在；**延迟/乱序测量**会让后验在时间上错位。**估计器不能自己批改自己的作业。**
> - **碰撞检测视角**：R72 有 `λ_floor` 与 `certified_prefix`，但**没有显式碰撞谓词、碰撞概率与连续碰撞检测**。「认证前缀」在没有碰撞模型时只是「运动学可执行」，不是「碰撞上可证明」。灵巧操作还必须区分**意图接触**（贴合、抓取、按压）与**非意图碰撞**（撞人、撞桌、撞未知障碍）；前者不是事故，后者必须反射；而检测有**延迟**，延迟期间机器人仍在运动——**检测延迟本身必须进安全包络**。
>
> 本轮两个灵感正好补上「风险界的分母」与「风险界的边界」：
> - **状态估计** → **CAES / OBG / TAME / CAPE**：审计式状态估计（NEES/NIS 一致性、外部校准集、尾部资格）、可观测性退化门、时间对齐与估计债、接触辅助估计（把意图接触从噪声源变成可观测性源）。
> - **碰撞检测** → **PCC / CCIL / PCR**：概率-保形碰撞证书（chance constraint + conformal state tube + 连续碰撞检测）、接触/碰撞/近失隔离（基于「预期违背」而非力阈值）、碰撞后反射与恢复门控。
> - **两者交汇** → **SRX / J_AEG**：状态不确定度、估计年龄、不可观测质量、碰撞概率、检测健康度统一进入 λ；证书从 `J_EMB` 扩展为 `J_AEG`，必须同时证明「估计可信」与「碰撞可证」。
>
> 核心命题：**R72 问「在调度/意图/接触下，我的测量链还能兑现风险界吗？」R73 追问「你凭什么相信 `b_t` 的协方差？又凭什么相信 certified prefix 真的不会撞？」** 把 `EMBODIED-GAUGE-RAS` 升级为 **AEGIS-GAUGE-RAS**（Audited Estimation & Guaranteed Interval Safety GAUGE for RAS）——**审计式估计 × 保证性碰撞包络**。一句话：**不确定性不可自证，碰撞必须可证。**

## 0. 直觉与动机

**灵感 1（协方差不是数字，是一张需要担保的承诺）** 卡尔曼滤波输出 `(x̂,P)`，但 `P` 是模型与噪声假设的推论，不是观测事实。若 Q、R、P0 都设小，滤波器会输出漂亮的小 P，同时真实误差很大。NEES 用独立真值检验这个承诺；NIS 只用滤波器自己的新息，**在不可观测方向上没有信号**。所以「NIS 白」不等于「状态对」。**必须用独立校准集/真值窗口做 NEES 审计，并把审计结果转化为协方差的保守膨胀 `P_aud ⪰ P_self`；审计只能膨胀，不能收缩。** 安全侧的审计是**单边**的。

**灵感 2（看不见的方向，数据救不了你）** 可观测性不是「滤波器收敛得快不快」，而是「这个方向是否出现在测量里」。遮挡、接触丢失、单目退化、腿部打滑会让某些方向进入**不可观测子空间**；此时后验协方差可能因为「没有新息」而**虚假收缩**。正确做法：(i) 用局部可观测 Gramian / Fisher 信息识别退化方向；(ii) 把该方向的「不可观测质量」当作**不可被数据消除的认知盲区**计入 λ；(iii) 认证前缀不得依赖该方向；(iv) 用主动感知动作激励可观测方向。**「没看到」不是「没问题」，而是「不知道」。**

**灵感 3（年龄就是不确定度，延迟测量是一笔债）** 控制域 1kHz 只读快照，计量域 50Hz 才写一次。控制域拿到的状态可能已 20ms 旧；对 2m/s 的末端，这是 4cm 位置误差。过程噪声随年龄增长：`P(τ)=F P Fᵀ+Q(τ)`。**快照的新鲜度必须显式进入协方差与 λ。** 乱序/延迟测量到达后，计量域可以回滚平滑，但**已经发出的控制指令不能回滚**；证书必须记录「估计债」（回滚修正量、受影响时间窗、未被修正的控制周期），债务超限即降级。**时间不是免费的，延迟要付利息。**

**灵感 4（碰撞不是点事件，是状态管道上的概率过程）** 传统碰撞检测问「此刻是否相交」。但状态有不确定度、运动有速度、检测有延迟，真正该问的是「未来 k 步内，**以至少 1−δ 的概率**，机器人扫掠体是否与障碍相交」。这要求 (i) 把状态不确定度传播成**状态管道**；(ii) 用连续碰撞检测（CCD）/扫掠体，而不是离散采样；(iii) 在管道上做 **chance constraint**；(iv) 尾部必须可信——高斯 χ² 界在重尾下会低估，必须备一条**分布无关的保形（conformal）管道**，两者取交集。**「认证前缀」的正确含义是：在这个概率碰撞证书内最长的可执行前缀。**

**灵感 5（意图接触不是碰撞，力大不是判据，预期违背才是）** 灵巧手抓杯子，接触力可能很大，但那是**计划中的接触**；手背轻轻擦过桌沿，力很小，却是**非计划碰撞**。用固定力阈值会把「用力抓取」误判为碰撞，又把「软碰撞」漏掉。正确判据是**预期违背**：给定计划接触模式 `c_plan` 与状态估计，实际多模态证据（关节力矩残差、taxel、F/T、音频、电流、IMU）的似然比 `Λ=p(y|计划接触)/p(y|无计划接触)` 低于阈值才判为碰撞。**碰撞检测的对象不是「力」，而是「计划与现实的失配」。**

**灵感 6（检测延迟是安全包络的一部分）** 一个 100% 准确但 50ms 后才报警的碰撞检测器，对高速机械臂仍然危险。安全包络必须扣除**检测-反应穿透预算**：`Δ_pen ≤ v_max τ_det + ½ a_max τ_react²`。反过来给出**速度上限**：`v_max ≤ (Δ_safe − ½ a_max τ_react²)/τ_det`。**检测器越慢，允许速度越低；这不是调参，是几何与时间的不等式。** 因此碰撞检测与运动规划不是两个模块，而是同一条安全约束的两端。

**灵感 7（接触既是不确定度源，也是可观测性源）** R72 的 L3 只说「控制改变接触模式 → 触觉噪声变 → 估计变差」。但接触也有**信息**：抓取约束让物体位姿变得可观测；足端支撑约束腿部里程计漂移；碰撞冲击给出接触法向与位置。**接触是双刃剑**：意图接触提供约束（好的信息），非意图碰撞提供冲击（坏的事件，但也是信息）。同一个物理事件，在估计层与安全层的符号相反。

## 1. 形式化定义（增量：定义 366–382）

**定义 366（AEGIS-GAUGE-RAS 总览与六不变式）** AEGIS-GAUGE-RAS = (CAES, OBG, TAME, CAPE, PCC, CCIL, PCR, SRX, EMBODIED†)。六不变式：
(i) **不确定性不可自证**：进入风险缩放与碰撞证书的协方差必须是审计后的 `P_aud`，且 `P_aud ⪰ P_self`（半正定序）；审计只能膨胀，不能收缩；
(ii) **可观测性前置**：任何认证前缀不得依赖不可观测子空间；不可观测方向的不确定度计入 λ，且不可被「更多数据」消除，只能靠主动感知或保守动作；
(iii) **年龄即不确定度**：控制域只读快照，消费前必须按年龄 τ 传播协方差 `P_aud(τ)`；`τ > τ_max` 或序列号断层超限 ⇒ 否决；
(iv) **碰撞可证明**：认证前缀必须满足 `P(collision) ≤ δ`，证书同时给出模型基界与分布无关的保形界，取二者交集；穿透预算必须扣除检测-反应延迟；
(v) **接触/碰撞可分辨**：所有接触事件先经 CCIL 分为意图接触/非意图碰撞/近失/自由；意图接触可作 CAPE 证据，非意图碰撞触发 PCR；
(vi) **严格逐指令退化**：CAES 失效 ⇒ 保守协方差膨胀 + R72；OBG 失效 ⇒ 禁用依赖不可观测方向的动作 + 主动感知；PCC 失效 ⇒ 速度/力矩受限的 R68 包络；CCIL 失效 ⇒ 力/功率/电流硬阈值包络；全失效 ⇒ R68。**新层只在「估计可审计、方向可观测、碰撞可证明、接触可分辨」时启用。**

**定义 367（CAES 审计状态估计）** 一次状态估计是一个带证据的断言
`E_t = (x̂_t, P_t^self, P_t^aud, ν_t, ω_t, κ_t, τ_t, τchain)`，
其中 `ν_t` 为一致性证据（NEES/NIS/新息白化），`ω_t` 为可观测性证书，`κ_t ≥ 1` 为审计膨胀因子。审计映射
`P_t^aud = κ_t · P_t^self`，
`κ_t = max(1, \bar{NEES}_W / n, \bar{NIS}_W / m)`（截断到 `[1, κ_max]`）。
若一致性检验失败，则 `P_t^aud = P_prior_safe` 并标记 `CAES=INVALID`。**关键：κ 只增不减；审计的目标不是「让 P 更准」，而是「让 P 不被高估为可信」。**

**定义 368（NEES/NIS 一致性与尾部资格）** NEES 用独立真值 `x_t`：
`NEES_t = (x_t − x̂_t)ᵀ P_t^{-1} (x_t − x̂_t)`，一致时 `E[NEES]=n`。窗口 `W` 上做 χ² 检验：
`χ²_{α/2}(nW)/W ≤ \bar{NEES} ≤ χ²_{1−α/2}(nW)/W`。
NIS 用新息 `ν_t = z_t − h(x̂_t^-)`、`S_t = H P_t^- Hᵀ + R`：
`NIS_t = ν_tᵀ S_t^{-1} ν_t`，`E[NIS]=m`，同样做 χ² 检验与新息白化。**NEES 需要独立真值（仿真真值/动作捕捉/标定靶/SEAL 集），NIS 只能在线用；二者不可互相替代。**
**尾部资格**：PCC 若使用高斯 χ² 界，必须额外通过尾部覆盖检验（名义 1−δ 与实际覆盖差 ≤ ε_tail，峰度不超阈）；不通过则强制使用分布无关的保形/Chebyshev 界。**通过 NEES 只说明二阶矩平均一致，不说明尾部可信。**

**定义 369（OBG 可观测性与退化门）** 线性化 `δx_{t+1}=F δx_t+w`、`δz_t=H δx_t+v`。窗口 `W` 的局部可观测 Gramian
`O_W = Σ_{i=0}^{W−1} Φ_iᵀ Hᵀ R^{-1} H Φ_i`，Fisher 信息 `J=O_W`。
特征分解 `O_W = Σ λ_i u_i u_iᵀ`。**可观测裕度** `μ_obs = min{λ_i : λ_i > ε_obs}`；**退化子空间** `U_deg = span{u_i : λ_i ≤ ε_obs}`。状态分解 `x = x_obs ⊕ x_deg`。不可观测质量
`u_deg = sqrt(tr(P_aud|_{U_deg}))`。
**证书规则**：认证前缀的碰撞谓词只能使用 `x_obs`；`u_deg` 进入 λ；若 `u_deg > τ_deg` 或动作依赖退化方向，则 `OBG=INVALID`，只能主动感知或停止。**不可观测不是「方差为零」，而是「数据无法降低的盲区」。**

**定义 370（TAME 时间对齐与估计债）** 快照 `S_t=(x̂_t,P_t^aud,t,seq)`。控制时刻 `t'` 使用 `t≤t'` 的最新快照，年龄 `τ=t'−t`。协方差传播
`P_aud(τ)=F(τ)P_audF(τ)ᵀ+Q(τ)+GΣ_uGᵀ`，`Q(τ)=∫_0^τF(s)Q_cF(s)ᵀds`。
`τ>τ_max` 或 `seq` 断层 > `g_max` ⇒ `TAME=VETO`。计量域保留定长 `L` 的测量缓冲；乱序测量到达时回滚到 `t_d`，重滤波至 `t'−L`，发布新版本快照。**控制域绝不回滚、绝不等待。**
**估计债** `D_est = Σ_{s∈[t_d,t']} ||x̂_s^{new}−x̂_s^{old}||_{P^{-1}} · 1[控制已消费]`。债务超限 ⇒ 降低速度/触发重新认证。**延迟测量只能修正未来，不能修正已经执行的动作；这就是债。**

**定义 371（CAPE 接触辅助估计）** 接触模式 `c∈𝒞`（沿用 R72）。每种模式 `m_i` 对应一个约束因子：sticking 为接触点相对速度零（等式约束）；sliding 为摩擦锥边界（不等式约束）；free 无约束；breaking/impact 为冲量模型 + 协方差膨胀 + 鲁棒更新。多假设滤波 `M_t={(x̂_t^i,P_t^i,w_t^i)}`，全局后验为混合。**接触约束的秩条件**：若接触雅可比 `J_c` 使 `rank([H;J_c])>rank(H)`，则接触**恢复**部分可观测性；否则接触只是噪声源。**意图接触进约束滤波，非意图碰撞进鲁棒重置。**

**定义 372（PCC 概率-保形碰撞证书）** 碰撞谓词 `C(x,u)=[∃t∈[0,T]:d(x_t,O_t)≤0]`，`d` 为到障碍集 `O_t`（含人、自身、未知物）的符号距离。认证前缀长度
`k* = max{k : ∀t≤k, P(C_t|b_t,u) ≤ δ/k}`（Boole 分摊）。
两条界，取更保守者：
- **模型基界**：若 `d` 为 `L_d`-Lipschitz，`d(x_t,O_t) ≥ d(x̂_t,O_t) − L_d||e||`。用 χ² 椭球半径 `r_χ=sqrt(χ²_{1−δ}(n))`，若 `d(x̂_t,O_t) > L_d·sqrt(λ_max(P_aud(t)))·r_χ + m_safe`，则碰撞概率 ≤δ（仅当高斯/尾部资格通过）；
- **保形界**：用独立校准集构造状态管道 `C_α(x̂)={x:s(x,x̂)≤q_{1−α}}`，若整个 `C_α` 在 `[0,T]` 上与 `O_t` 不相交，则 `P(collision)≤α`，**无需高斯假设**；分布漂移时用加权/在线保形（ACI）更新 `q`。
连续碰撞检测用扫掠体/保守推进（conservative advancement）计算 `min_t d`；离散采样只作加速，不作证明。**PCC 的输出不是「安全/不安全」，而是「长度 k* 的认证前缀 + 该前缀的 δ + 界类型 + 追溯链」。**

**定义 373（CCIL 接触/碰撞/近失隔离）** 多模态证据 `y_det=(τ_joint residual,taxel,F/T,audio,current,IMU)`；计划接触 `c_plan` 由规划器/阻抗控制器给出。碰撞判据是**预期违背的似然比**：
`Λ_t = p(y_det|c_plan,x̂_t)/p(y_det|free,x̂_t)`，
`P(collision|y_det)=σ(β_0+β_1logΛ_t+β_2·1[contact∉plan])`。
分类 `ĉ_det∈{intended_contact,collision,near_miss,free}`；隔离输出接触链路/部位/障碍与法向。**硬阈值（力/电流/功率）只作安全兜底，不作主判据。** 检测健康度 `H_det=(TPR,FPR,τ_det,p_fn^{soft},p_fn^{oblique})`。**CCIL 失效 ⇒ 回退到硬阈值包络，速度上限按定义 374 收紧。**

**定义 374（检测延迟-速度-穿透三角与 PCR）** `τ_det=τ_sense+τ_comm+τ_infer+τ_decision`，`τ_react` 为反应延迟。最坏穿透
`Δ_pen ≤ v_max τ_det + ½ a_max τ_react²`。
安全包络要求 `Δ_pen≤Δ_safe`，于是
`v_max ≤ (Δ_safe − ½ a_max τ_react²)/τ_det`。**这是 AEGIS 的硬速度帽，不是软惩罚。**
碰撞后反射 PCR：检出非意图碰撞后，在 `τ_react` 内执行零力矩/阻抗软化/沿估计法向回退，冻结认证前缀，记录碰撞事件；用冲量模型更新状态，重置接触假设，将接触几何加入障碍集（**只增不减**）。恢复门控：连续 `N_rec` 帧估计一致、碰撞证书重新通过、检测器健康度恢复，才允许解除反射。**碰撞事件只能让障碍集变大、速度上限变小，不能相反。**

**定义 375（SRX 状态-风险接口）** 统一风险缩放
`λ_AEG = max(λ_EMB, λ_state, λ_coll)`，
`λ_state = f_state(U_aud,u_deg,τ_age,D_est,divergence_flag)`，
`λ_coll = f_coll(P_coll^max,Δ_pen/Δ_safe,H_det,m_safe)`。
各分量对不确定度、年龄、退化质量、碰撞概率、穿透利用率、检测漏检率**单调不减**。任一审计 `INVALID` ⇒ `λ_AEG=∞`（停止/降级），而非用一个有限大数掩盖。**安全裕度**
`m_safe = d_min − L_d r_conf − Δ_pen`，
只有 `m_safe>0` 的步才进入认证前缀；`m_safe` 同时是碰撞证书与 λ 的共同变量。

**定义 376（AEGIS 指标 E²-MIB）** 在 R72 E-MIB 上新增：**估计族**（NEES/NIS 窗口通过率、κ 分布、滤波发散次数、μ_obs、dim U_deg、u_deg、快照年龄分布、估计债 D_est、尾部覆盖率）；**碰撞族**（认证 δ 与经验碰撞率之差、P_coll 校准、CCD 最小距离误差、TPR/FPR、τ_det、软/斜碰撞漏检、近失率、穿透深度、恢复时间）；**闭环族**（碰撞事件对状态估计的修正量、接触辅助估计的可观测性增益、反射触发后的任务恢复率、障碍集增长速率）。所有指标遵循定义 332 六元组与定义 333 DAG 分层。

**定义 377（AEGIS IVG 门控）** 新增失效条件：**估计**（NEES/NIS 超界、κ 触顶、发散标志、μ_obs 低、u_deg 大、年龄超限、债务超限）；**碰撞**（P_coll 经验校准超差、保形覆盖率不足、CCD 误差超阈、τ_det 超限、软/斜碰撞漏检超阈、m_safe≤0）；**接触**（CCIL 分类校准超差、隔离错误、碰撞后恢复失败）。任一成立 ⇒ 相关模块降级；**估计失效不得用「更小的 P」来修复，碰撞失效不得用「更高的速度」来补偿。**

**定义 378（AEGIS 证书 J_AEG）**
`J_AEG = (J_EMB, caes_hash, nees_nis_proof, obs_cert, age_policy, debt_log, conformal_q, pcc_proof, ccil_health, pcr_log, tail_eligibility, srx_params, aeg_ver)`。
`Valid(J_AEG) ⇔ Valid(J_EMB) ∧ CAES 有效 ∧ OBG 有效 ∧ TAME 未否决 ∧ PCC 证明有效 ∧ CCIL 健康 ∧ SRX 参数哈希匹配 ∧ 尾部资格满足（或已切换到分布无关界）`。
**证书必须记录「用了哪条界」：模型基/保形/两者交集。没有界类型的碰撞声明是裸奔。**

**定义 379（威胁模型 AIC-AEG）** `ℰ_AEG = ℰ_EMB × ℰ_est × ℰ_coll`：
- `ℰ_est`：协方差投毒/自报过小、NEES 校准集污染、可观测性欺骗（遮挡/反射/重复纹理）、延迟测量重放、过程噪声篡改、状态重置攻击；
- `ℰ_coll`：碰撞传感器致盲（遮挡相机/吸音/堵 taxel）、软碰撞规避检测、斜碰撞、碰撞事件伪造（触发不必要急停）、障碍集删除攻击、保形校准集投毒；
- `ℰ_cross`：用「估计很准」的假象换取更短认证前缀，再以高速撞上未建模障碍（**审计-证书串谋**）。

**定义 380（三域放置）** 控制域（1kHz，硬实时）：读取 `P_aud(τ)` 的保守包络、SDF/扫掠体快速检查、`m_safe` 计算、PCR 反射、速度帽；**只做 O(1)/O(log N) 的保守检查，不做完整概率积分**。计量域（20–50Hz，软实时）：完整 BSE、NEES/NIS 审计、保形分位数更新、PCC 完整验证、CAPE 多假设。感知域（异步）：障碍跟踪、CCIL 多模态检测、碰撞音频/触觉特征、隔离。**控制域只读快照，绝不等待计量域的完整证书；证书是异步组装的。**

**定义 381（严格退化包含链）** 全有效 ⇒ AEGIS 完整；CAES 失效 ⇒ 协方差膨胀到先验安全包络 + R72；OBG 失效 ⇒ 仅执行不依赖退化方向的主动感知/保守动作 + R72；PCC 失效 ⇒ 速度/力矩受限的 R68 包络 + R72 认证；CCIL 失效 ⇒ 力/功率/电流硬阈值兜底 + R68；全失效 ⇒ R68。**安全侧只增不减：任何退化都保留 R68 的硬安全包络；碰撞事件只能收紧后续约束。**

**定义 382（AEGIS 认证前缀算子）** `AEGIS-Certify(A,b_t,P_aud,H_det,δ)`：
1. 按 TAME 传播年龄 → `P_aud(τ)`；
2. OBG 检查依赖方向，剔除退化方向；
3. 对候选动作序列 `A` 做扫掠体/CCD，得到 `d_min(t)`；
4. 用模型基界与保形界分别求最大安全前缀 `k_model`、`k_conf`；
5. `k*=min(k_model,k_conf,k_det)`，其中 `k_det` 满足 `Δ_pen(k)≤Δ_safe`；
6. 若 `k*=0` 或 `m_safe≤0` ⇒ 返回停止/降级；
7. 输出 `(k*,δ,bound_type,m_safe,P_aud_used,τ_age,τchain)`。
**性质：k* 对 P_aud、τ_age、δ、τ_det 单调不增；对检测健康度 H_det 单调不减。** 这正是「越不确定越慢、越看不见越停、检测越差越保守」的形式化。

# IP-295 CAES：审计式状态估计（计量域 50Hz，输出 P_aud，绝不收缩）
class CertifiedStateEstimate:
    def __init__(self, filt, calib, n, m, kappa_max=10.0):
        self.f, self.calib = filt, calib
        self.n, self.m, self.kappa_max = n, m, kappa_max
        self.nees, self.nis = deque(maxlen=200), deque(maxlen=200)

    def update(self, z, u, dt, x_gt=None):
        xhat, P_self = self.f.predict_update(z, u, dt)
        nu, S = self.f.innovation()
        self.nis.append(nu.T @ inv(S) @ nu)
        if x_gt is not None:                       # 仅独立真值窗口
            e = x_gt - xhat
            self.nees.append(e.T @ inv(P_self) @ e)
        kappa = 1.0
        if len(self.nees) >= 30:
            nb = mean(self.nees)
            if not chi2_gate(nb * len(self.nees), self.n):
                kappa = clip(nb / self.n, 1.0, self.kappa_max)
        if len(self.nis) >= 30:
            mb = mean(self.nis)
            if not chi2_gate(mb * len(self.nis), self.m):
                kappa = max(kappa, clip(mb / self.m, 1.0, self.kappa_max))
        valid = kappa < self.kappa_max and self.f.divergence() < TAU_DIV
        P_aud = kappa * P_self if valid else self.f.prior_safe_covariance()
        return Estimate(xhat, P_self, P_aud, kappa, valid, self.calib.tchain)

# IP-296 OBG：可观测 Gramian 与退化门
def observability_gate(F, H, R, W, eps=1e-6):
    O, Phi = zeros_like(F), eye(F.shape[0])
    for _ in range(W):
        O += Phi.T @ H.T @ inv(R) @ H @ Phi
        Phi = F @ Phi
    lam, U = eigh(O)
    U_deg = [u for l, u in zip(lam, U.T) if l <= eps]
    mu_obs = min([l for l in lam if l > eps], default=0.0)
    return ObsCert(mu_obs, U_deg, rank=len(lam) - len(U_deg))

def certifiable_projection(xhat, P_aud, obs):
    u_deg = sqrt(trace_project(P_aud, obs.U_deg))
    return project_out(xhat, obs.U_deg), u_deg, (obs.mu_obs > TAU_OBS and u_deg < TAU_DEG)

# IP-297 TAME：年龄传播 + 乱序测量/估计债
def age_inflate(P, F, Qc, G, Sigma_u, tau):
    Ft = expm(F * tau)
    return Ft @ P @ Ft.T + integral_process_noise(F, Qc, tau) + G @ Sigma_u @ G.T

class TimeAlignedSnapshot:
    def read(self, now):
        s = self.latest
        tau = now - s.t
        if tau > TAU_MAX_AGE or self.seq_gap(now) > G_MAX:
            return None
        return Snapshot(s.xhat, age_inflate(s.P_aud, s.F, s.Qc, s.G, s.Sigma_u, tau),
                        tau, s.seq)

    def on_out_of_order(self, z, t_d):
        old = self.buffer.snapshot(t_d)
        new = self.smoother.rewind_and_filter(t_d, z)   # 仅计量域回滚
        self.debt_log.append(mahalanobis(old.xhat, new.xhat, old.P_aud))
        self.publish(new, seq=self.seq + 1)

# IP-298 CAPE：接触辅助多假设估计
def contact_aided_step(filters, hmm, z, u, plan_contact):
    c_post = hmm.step(z, plan_contact)
    hyps = []
    for mode, f in filters.items():
        f.predict(u)
        if mode == 'sticking':
            f.update_equality(z, Jc=contact_jacobian(), vrel=0)
        elif mode == 'sliding':
            f.update_inequality(z, friction_cone=MU)
        else:
            f.update(z)
        hyps.append((f.xhat, f.P, c_post[mode] * hmm.prior(mode)))
    return mixture(hyps)

# IP-299 PCC：概率 + 保形碰撞证书；连续碰撞检测
def certified_prefix(A, est, obstacles, delta, det, policy):
    P = age_inflate(est.P_aud, est.F, est.Qc, est.G, est.Sigma_u, est.age)
    x_obs, u_deg, obs_ok = certifiable_projection(est.xhat, P, est.obs)
    if not obs_ok:
        return 0, None, 'obg_veto'
    k_model = conservative_ccd_prefix(A, x_obs, P, obstacles, delta, 'chi2')
    k_conf  = conformal_ccd_prefix(A, x_obs, est.calib, obstacles, delta)
    k_det   = latency_feasible_prefix(A, det.tau_det, policy.delta_safe, policy.a_max)
    k = min(k_model, k_conf, k_det)
    m_safe = min_safety_margin(A[:k], x_obs, P, obstacles, det)
    if k == 0 or m_safe <= 0:
        return 0, None, 'collision_veto'
    bound = 'intersection' if k_model > k_conf else 'conformal'
    return k, m_safe, bound

# IP-300 CCIL：预期违背似然比，而非固定力阈值
def isolate(y_det, xhat, c_plan):
    log_lr = loglik(y_det, 'planned_contact', xhat, c_plan) - loglik(y_det, 'free', xhat)
    p_coll = sigmoid(B0 + B1 * log_lr + B2 * (c_plan is None))
    cls = argmax({'intended': 1 - p_coll, 'collision': p_coll,
                  'near_miss': near_miss_score(y_det)})
    return cls, p_coll, isolate_link(y_det, xhat)

# IP-301 PCR：碰撞反射与恢复门控
def post_collision_reflex(event, est, obstacles):
    if event.cls != 'collision':
        return est, obstacles
    cmd = soft_impedance(direction=event.normal, k=K_SOFT, d=D_SOFT)
    obstacles.add(event.geometry)                 # 单调只增
    est = robust_reset(est, impulse=event.impulse)
    return est, obstacles

def recovery_gate(est, pcc, det, n_rec):
    return est.consistency_ok and pcc.valid and det.tpr > TAU_TPR and n_rec >= N_REC

# IP-302 SRX：状态-风险接口；任一审计失效即无穷大
def aegis_risk_scale(U_emb, est, p_coll, det, policy):
    lam_emb = embodied_risk_scale(*U_emb, policy)
    lam_state = policy.k_s * (1 + trace(est.P_aud) / policy.p_scale
                              + est.u_deg / policy.deg_scale
                              + est.age / policy.age_scale
                              + est.debt / policy.debt_scale)
    lam_coll = policy.k_c * (1 + p_coll / policy.delta
                             + det.tau_det / policy.tau_det_max
                             + (1 - det.tpr) / policy.tpr_scale)
    if not (est.caes_valid and est.obs_valid):
        return float('inf')
    return max(lam_emb, lam_state, lam_coll)

# IP-304 AEGIS 主闭环：控制域只读、快速复核、不等待完整证书
def AEGIS_round(M, obs, audio, tac):

    snap = M.snapshot.read(now=M.clock.now())          # 含年龄传播
    if snap is None:
        M.ctrl_out.publish(stop_envelope())
        return 0, None, J_AEG(M, 'tame_veto')
    lam = aegis_risk_scale(M.emb_uq(), snap.est, snap.p_coll,
                           M.ccil.health(), M.policy)
    A = M.ach.propose_ctrl(...)
    k, m_safe, bound = AEGIS_Certify_fast(A, snap, M.obstacles,
                                          M.delta, M.ccil.health(), M.policy)
    if k == 0:
        M.ctrl_out.publish(safe_stop())
        return 0, None, J_AEG(M, 'collision_veto')
    M.ctrl_out.publish(A[:k], lam)

    # ---- 计量域 50Hz ----
    if M.clock.due_metric():
        est = M.caes.update(M.obs_buf, M.u, M.dt, x_gt=M.seal.gt_if_available())
        est.obs = observability_gate(M.F, M.H, M.R, W_OBS)

        pcc = M.pcc.verify(M.ach.candidate(), est, M.obstacles, M.delta)
        M.snapshot.write(est, pcc, seq=M.seq + 1)

    # ---- 感知域 100Hz ----
    cls, p_coll, link = M.ccil.detect(tac, M.torque_residual(), audio, M.current)
    if cls == 'collision':
        M.est, M.obstacles = post_collision_reflex((cls, p_coll, link), M.est, M.obstacles)

    if M.mode == 'REFLEX':
        M.n_rec = M.n_rec + 1 if recovery_gate(M.est, M.pcc, M.ccil.health(), M.n_rec) else 0
        if M.n_rec >= N_REC:

    return k, lam, J_AEG(M)

## 3. 推导

**引理 33（审计协方差单边保守）** `P_aud=κP_self, κ≥1 ⇒ P_aud⪰P_self`，故同一马氏半径下 `𝒞_self⊆𝒞_aud`；任何基于 `P_aud` 的碰撞检查都比基于 `P_self` 更保守。若 `\bar{NEES}=κn`，按 `P_aud` 的期望 NEES 回到 `n`。系：**安全审计必须单边；允许审计缩小 P 等于允许滤波器自证。**

**引理 34（年龄单调性）** 若 `Q_c⪰0, GΣ_uGᵀ⪰0`，则 `P_aud(τ)⪰P_aud(0)` 且 `tr P_aud(τ)` 单调不减；`λ_state` 对 `τ` 不减，`k*` 对 `τ` 不增。**旧快照只会让系统更保守。**

**引理 35（不可观测方向 CRLB）** 无偏估计满足 `Cov(x̂)⪰J^{-1}`，`J=O_W`。若 `λ_i≤ε_obs`，则 `u_i` 方向方差 `≥1/ε_obs`，`λ_i→0` 时发散。**任何有限精度证书都不能依赖 U_deg；u_deg 是数据无法降低的盲区。** 系：OBG 必须是认证前缀的前置门。

**引理 36（保形碰撞界）** 在可交换性下，`P(x∈C_α(x̂))≥1−α`（有限样本）。若 `d` 为 `L_d`-Lipschitz 且 `min_{x∈C_α}d(x,O)>0`，则 `P(collision)≤α`。**该界不依赖高斯/椭球假设，是尾部资格失败时的兜底。** 系：模型基界紧、保形界稳，PCC 取交集。

**引理 37（检测延迟-速度-穿透）** `Δ_pen≤v_maxτ_det+½a_maxτ_react²`；`Δ_pen≤Δ_safe` ⇒ `v_max≤(Δ_safe−½a_maxτ_react²)/τ_det`。**检测器延迟直接决定允许速度。** 系：这是硬速度帽，不是软惩罚。

**引理 38（接触可观测性恢复条件）** `O_c=O_0+ΣΦᵀJ_cᵀR_c^{-1}J_cΦ`。若 `rank(O_c)>rank(O_0)`，接触恢复至少一个退化方向；若 `J_c` 在 `U_deg` 上为零，则接触不提供该方向信息。**接触辅助估计不是无条件有效：必须检查接触雅可比在退化子空间上的投影。**

**定理 27（严格包含与风险单调）** 在 CAES 单边审计、OBG 秩条件、TAME 年龄传播、PCC 双界、CCIL 健康度、PCR 单调障碍集下：AEGIS 在退化条件下逐指令等于 EMBODIED/R71/R68；任意有效执行的风险界 ≤ EMBODIED。**安全单调不减，效率只在四门全过时获益。**

**定理 28（J_AEG ⇒ 概率碰撞安全）** 若通过 `J_AEG`，则认证前缀内 `P(collision_t)≤δ_t+ε_tail+ε_obs+ε_det`；使用分布无关保形界时 `ε_tail=0`。**证明：按「界失败/退化方向/检测漏检」三部分做并集界。** 系：碰撞安全是「可审计 δ + 三项显式松弛」；隐藏松弛项就是隐藏风险。

**定理 29（估计器不能自证）** 存在线性系统与噪声实现，使新息白化、NIS 通过，但状态误差在不可观测子空间任意大。构造：取 `Hu=0`，初值误差沿 `u`，过程噪声不激励 `u`；则新息不受影响，NIS/白化全过，而 `u` 方向误差不降、NEES 随 `P_self` 收缩而发散。**NIS 是必要非充分条件；必须有独立真值 NEES 与 OBG。** 系：CAES 与 OBG 必须同时存在。

**定理 30（碰撞-估计闭环收缩）** 在 PCR 障碍集单调、速度帽不增、CAPE 秩条件成立下，不存在「越撞越快」的自激循环；有限次事件后要么恢复认证，要么停在 R68 包络。**证明：每次碰撞增加约束、降低或保持速度上界；新增约束下信息矩阵单调不减；正阻尼/有限事件 ⇒ 有限终止。** 系：安全层是单向棘轮。

**定理 31（三层证书不可替代）** `J_EMB`（调度/意图/接触）、CAES/OBG（估计可信/可观测）、PCC/CCIL（碰撞可证/可分辨）缺一不可。分别构造反例使另外两层全通过而剩余层失效导致事故。**证明：三个独立反例类。** 系：每层覆盖不同的失效模式，不是冗余盖章。

## 6. 本轮最大风险

**一句话**：AEGIS 把风险界的分母从自报协方差换成了审计协方差、把认证前缀从运动学可执行换成了概率碰撞可证，但 **NEES/NIS 只是二阶矩与平均一致性的检验、保形覆盖依赖可交换性**——如果真实误差重尾/多峰且部署分布漂移使保形校准悄悄失效，而可观测性门只覆盖线性化窗口、漏掉遮挡边缘/摩擦锥切换/接触几何突变等非线性退化，再叠加碰撞检测对**软碰撞/斜碰撞的漏检**，系统就会拿着「NEES 通过、保形覆盖、碰撞概率 ≤δ」的盖章证书，以刚好低于速度帽的速度撞上所有审计都未建模的事件；这不是「估计不准」，而是**审计把不可审计的东西误判为可审计**。

次级风险与缓解：
1. **二阶矩审计掩盖尾部** → 强制尾部资格（峰度/尾覆盖/分位数回归）；不通过禁用 χ² 界，改走保形/Chebyshev，取更保守界。
2. **保形可交换性破裂** → 在线 ACI/加权保形 + 漂移检测；漂移超阈退回模型基保守界并降速。
3. **线性化漏非线性退化** → 多窗口/多工作点 OBG + 残差一致性/条件数监测；退化即主动感知或停止。
4. **检测延迟低估** → 端到端时间戳逐段审计；τ_det 进速度帽；定期注入延迟故障。
5. **软/斜碰撞漏检** → 多模态 + 预期违背似然比；软/斜碰撞专用校准集；漏检率纳入 IVG。
6. **审计-证书串谋** → CAES 与 PCC 用独立校准集/独立追溯链；J_AEG 记录界类型；缩短前缀的审计变更需双签。
7. **障碍集被删除/篡改** → 障碍集单调只增、哈希链、写保护；删除事件触发安全审计而非静默通过。

# 第 73 轮产物 · 创新点清单 v4：AEGIS-GAUGE-RAS（Audited Estimation & Guaranteed Interval Safety GAUGE for RAS：审计式状态估计 × 概率-保形碰撞证书 × 接触/碰撞隔离 × 检测延迟感知安全；CAES × OBG × TAME × CAPE × PCC × CCIL × PCR × SRX × J_AEG）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 把 GAUGE 从认知层下沉到具身层：REG 实时调度、IRL 意图隐变量、DMEM 灵巧接触计量、EREFLEX 三层反作用、S2R-UQ 桥接，确立了「调度可信、意图可辨、接触可计量」时的逐指令风险界。但 R72 的两个最关键的输入仍是黑箱：
> - 缺 **状态估计审计（CAES/OBG/TAME/CAPE）**：`b_t` 的协方差是滤波器自报的；NIS 在不可观测方向上没有信号；快照有年龄；乱序测量会制造估计债；接触既可能是噪声源，也可能是可观测性源。**估计器不能自己批改自己的作业。**
> - 缺 **碰撞检测语义（PCC/CCIL/PCR）**：R72 的 `certified_prefix` 没有碰撞谓词、没有概率、没有连续碰撞检测、没有接触/碰撞区分、没有检测延迟预算、没有碰撞后恢复。**「运动学可执行」不等于「碰撞可证明」。**
> - 缺 **统一接口（SRX/J_AEG）**：状态不确定度、年龄、不可观测质量、碰撞概率、检测健康度必须同权进入风险缩放；证书必须同时记录「估计用了哪条界、碰撞用了哪条界、检测延迟是多少」。
>
> 核心命题：**从「在调度/意图/接触下，我的测量链还能兑现风险界吗」，进化为「你凭什么相信 `b_t` 的协方差？又凭什么相信认证前缀不会撞？」** —— **审计式估计 × 保证性碰撞包络**。一句话：**不确定性不可自证，碰撞必须可证。**
>
> IP 编号：IP-295~304（共 10 个）+ EMBODIED 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价，碰撞事件只能让约束单调收紧。**

## 2. 形式化定义（要点版）

**定义 366（总览与六不变式）** AEGIS = (CAES, OBG, TAME, CAPE, PCC, CCIL, PCR, SRX, EMBODIED†)。六不变式：不确定性不可自证（`P_aud⪰P_self`）；可观测性前置；年龄即不确定度；碰撞可证明（模型基 + 保形取交集，扣除检测延迟穿透）；接触/碰撞可分辨；严格逐指令退化（CAES→保守膨胀+R72；OBG→主动感知/停止；PCC→受限 R68；CCIL→硬阈值；全失效→R68）。

**定义 367（CAES 审计状态估计）** `E=(x̂,P_self,P_aud,ν,ω,κ,τ,τchain)`；`P_aud=κP_self`，`κ=max(1,\bar{NEES}/n,\bar{NIS}/m)` 截断到 `[1,κ_max]`；审计失效 ⇒ `P_aud=P_prior_safe` 且 `CAES=INVALID`。**审计是单边的：只准更保守。**

**定义 368（NEES/NIS 一致性与尾部资格）** NEES 用独立真值，`E[NEES]=n`；NIS 用新息，`E[NIS]=m`；窗口 χ² 检验 + 新息白化。**NEES 需要独立真值，NIS 不能替代 NEES。** 高斯 χ² 界另需尾部覆盖/峰度资格；不通过则强制保形/Chebyshev 界。**过 NEES 只说明二阶矩平均一致，不说明尾部可信。**

**定义 369（OBG 可观测性退化门）** `O_W=ΣΦᵀHᵀR^{-1}HΦ`；`μ_obs=min{λ_i>ε_obs}`；`U_deg=span{λ_i≤ε_obs}`；`u_deg=sqrt(tr(P_aud|_{U_deg}))`。认证前缀只用 `x_obs`；`u_deg` 进 λ；退化即主动感知或停止。**不可观测不是方差为零，而是数据无法降低的盲区。**

**定义 370（TAME 时间对齐与估计债）** 快照 `S=(x̂,P_aud,t,seq)`；控制域按 `τ=t'−t` 传播 `P_aud(τ)`；`τ>τ_max` 或 `seq` 断层 ⇒ veto。乱序测量在计量域回滚平滑并递增版本号；控制域不回滚、不等待。估计债 `D_est` 记录已执行控制受回滚修正的影响；超限降级。**延迟只能修正未来，不能修正已执行动作。**

**定义 371（CAPE 接触辅助估计）** sticking：接触点相对速度零（等式约束）；sliding：摩擦锥边界（不等式约束）；free：无约束；breaking/impact：冲量 + 鲁棒更新。多假设混合 `M_t`。**秩条件**：`rank([H;J_c])>rank(H)` 时接触恢复可观测性；否则接触只是噪声源。意图接触进约束滤波，非意图碰撞进重置。

**定义 372（PCC 概率-保形碰撞证书）** `C(x,u)=[∃t∈[0,T]:d(x_t,O_t)≤0]`；`k*=max{k:∀t≤k,P(C_t|b_t,u)≤δ/k}`。模型基界：`d(x̂,O)>L_d·sqrt(λ_max(P_aud))·r_χ+m_safe`（高斯/尾部资格通过）；保形界：整个 `C_α` 与 `O` 不相交 ⇒ `P(collision)≤α`（分布无关）。CCD 用扫掠体/保守推进，离散采样只作加速。**输出是「长度 k* 的认证前缀 + δ + 界类型 + 追溯链」，不是二元安全标签。**

**定义 373（CCIL 接触/碰撞/近失隔离）** `y_det=(τ_joint residual,taxel,F/T,audio,current,IMU)`；`Λ_t=p(y_det|c_plan,x̂)/p(y_det|free,x̂)`；`P(collision|y_det)=σ(β_0+β_1logΛ_t+β_2·1[contact∉plan])`；分类 `{intended_contact,collision,near_miss,free}`；隔离链路/部位/障碍/法向。**硬阈值只作兜底，不作主判据。** 健康度 `H_det=(TPR,FPR,τ_det,p_fn^soft,p_fn^oblique)`。

**定义 374（检测-速度-穿透三角与 PCR）** `Δ_pen≤v_maxτ_det+½a_maxτ_react²`；要求 `Δ_pen≤Δ_safe` ⇒ `v_max≤(Δ_safe−½a_maxτ_react²)/τ_det`。碰撞后 `τ_react` 内零力矩/阻抗软化/沿法向回退；障碍集只增不减；恢复门控需估计一致 + 证书重通过 + 检测健康。**碰撞事件只能让障碍集变大、速度帽变小。**

**定义 375（SRX 状态-风险接口）** `λ_AEG=max(λ_EMB,λ_state,λ_coll)`；`λ_state=f(U_aud,u_deg,τ_age,D_est,divergence)`；`λ_coll=f(P_coll,Δ_pen/Δ_safe,H_det,m_safe)`；各分量单调不减；任一 `INVALID ⇒ λ=∞`。安全裕度 `m_safe=d_min−L_d r_conf−Δ_pen`，只有 `m_safe>0` 才进认证前缀。

**定义 376（E²-MIB）** 估计族：NEES/NIS 通过率、κ、发散次数、μ_obs、`dim U_deg`、u_deg、年龄分布、估计债、尾部覆盖；碰撞族：δ 校准、P_coll 可靠性图、CCD 误差、TPR/FPR、τ_det、软/斜碰撞漏检、近失率、穿透、恢复时间；闭环族：碰撞修正量、接触可观测性增益、恢复率、障碍集增长。

**定义 377（AEGIS IVG）** 估计（NEES/NIS 超界、κ 触顶、发散、μ_obs 低、u_deg 大、年龄超限、债务超限）；碰撞（δ 校准超差、保形覆盖不足、CCD 误差、τ_det 超限、软/斜漏检、m_safe≤0）；接触（分类校准、隔离错误、恢复失败）。任一 ⇒ 降级；**估计失效不得用更小 P 修复，碰撞失效不得用更高速度补偿。**

**定义 378（J_AEG）** `J_AEG=(J_EMB,caes_hash,nees_nis_proof,obs_cert,age_policy,debt_log,conformal_q,pcc_proof,ccil_health,pcr_log,tail_eligibility,srx_params,aeg_ver)`；`Valid ⇔ J_EMB ∧ CAES ∧ OBG ∧ TAME ∧ PCC ∧ CCIL ∧ SRX ∧ 尾部资格（或已切分布无关界）`。**必须记录界类型；没有界类型的碰撞声明是裸奔。**

**定义 379（威胁模型 AIC-AEG）** `ℰ_AEG=ℰ_EMB×ℰ_est×ℰ_coll`。`ℰ_est`：协方差投毒、校准集污染、可观测性欺骗（遮挡/反射/重复纹理）、延迟重放、过程噪声篡改；`ℰ_coll`：传感器致盲、软/斜碰撞规避、碰撞伪造、障碍集删除、保形校准集投毒；`ℰ_cross`：用假精度换长前缀再高速撞未建模障碍（审计-证书串谋）。

**定义 380（三域放置）** 控制域 1kHz：保守包络 + SDF/扫掠体快速复核 + `m_safe` + PCR + 速度帽（O(1)/O(log N)）；计量域 20–50Hz：完整 BSE + NEES/NIS + OBG + 保形分位 + PCC + CAPE；感知域异步：障碍跟踪 + CCIL + 碰撞音频/触觉。**控制域只读快照，绝不等待完整证书。**

**定义 381（严格退化包含链）** 全有效 ⇒ AEGIS；CAES 失效 ⇒ 保守膨胀 + R72；OBG 失效 ⇒ 主动感知/保守动作 + R72；PCC 失效 ⇒ 受限 R68 + R72；CCIL 失效 ⇒ 硬阈值兜底 + R68；全失效 ⇒ R68。**安全侧只增不减。**

**定义 382（AEGIS-Certify 认证前缀算子）** 年龄传播 → OBG 剔除退化方向 → CCD 扫掠 → 模型基/保形分别求 `k_model,k_conf` → `k*=min(k_model,k_conf,k_det)` → `m_safe` 检查 → 输出 `(k*,δ,bound_type,m_safe,P_aud,τ,τchain)`。**k* 对 P/τ/δ/τ_det 单调不增，对检测健康度单调不减。**

# IP-295 CAES：审计式状态估计（计量域，单向膨胀）
class CertifiedStateEstimate:
    def __init__(self, filt, calib, n, m, kappa_max=10.0):
        self.f, self.calib = filt, calib
        self.n, self.m, self.kappa_max = n, m, kappa_max
        self.nees, self.nis = deque(maxlen=200), deque(maxlen=200)

    def update(self, z, u, dt, x_gt=None):
        xhat, P_self = self.f.predict_update(z, u, dt)
        nu, S = self.f.innovation()
        self.nis.append(nu.T @ inv(S) @ nu)
        if x_gt is not None:                       # 仅独立真值窗口
            e = x_gt - xhat
            self.nees.append(e.T @ inv(P_self) @ e)
        kappa = 1.0
        if len(self.nees) >= 30:
            nb = mean(self.nees)
            if not chi2_gate(nb * len(self.nees), self.n):
                kappa = clip(nb / self.n, 1.0, self.kappa_max)
        if len(self.nis) >= 30:
            mb = mean(self.nis)
            if not chi2_gate(mb * len(self.nis), self.m):
                kappa = max(kappa, clip(mb / self.m, 1.0, self.kappa_max))
        valid = kappa < self.kappa_max and self.f.divergence() < TAU_DIV
        P_aud = kappa * P_self if valid else self.f.prior_safe_covariance()
        return Estimate(xhat, P_self, P_aud, kappa, valid, self.calib.tchain)

# IP-296 OBG：可观测 Gramian 与退化门
def observability_gate(F, H, R, W, eps=1e-6):
    O, Phi = zeros_like(F), eye(F.shape[0])
    for _ in range(W):
        O += Phi.T @ H.T @ inv(R) @ H @ Phi
        Phi = F @ Phi
    lam, U = eigh(O)
    U_deg = [u for l, u in zip(lam, U.T) if l <= eps]
    mu_obs = min([l for l in lam if l > eps], default=0.0)
    return ObsCert(mu_obs, U_deg, rank=len(lam) - len(U_deg))

def certifiable_projection(xhat, P_aud, obs):
    u_deg = sqrt(trace_project(P_aud, obs.U_deg))
    return project_out(xhat, obs.U_deg), u_deg, (obs.mu_obs > TAU_OBS and u_deg < TAU_DEG)

# IP-297 TAME：年龄传播 + 乱序测量/估计债
def age_inflate(P, F, Qc, G, Sigma_u, tau):
    Ft = expm(F * tau)
    return Ft @ P @ Ft.T + integral_process_noise(F, Qc, tau) + G @ Sigma_u @ G.T

class TimeAlignedSnapshot:
    def read(self, now):
        s = self.latest
        tau = now - s.t
        if tau > TAU_MAX_AGE or self.seq_gap(now) > G_MAX:
            return None
        return Snapshot(s.xhat, age_inflate(s.P_aud, s.F, s.Qc, s.G, s.Sigma_u, tau),
                        tau, s.seq)

    def on_out_of_order(self, z, t_d):
        old = self.buffer.snapshot(t_d)
        new = self.smoother.rewind_and_filter(t_d, z)   # 仅计量域回滚
        self.debt_log.append(mahalanobis(old.xhat, new.xhat, old.P_aud))
        self.publish(new, seq=self.seq + 1)

# IP-298 CAPE：接触辅助多假设估计
def contact_aided_step(filters, hmm, z, u, plan_contact):
    c_post = hmm.step(z, plan_contact)
    hyps = []
    for mode, f in filters.items():
        f.predict(u)
        if mode == 'sticking':
            f.update_equality(z, Jc=contact_jacobian(), vrel=0)
        elif mode == 'sliding':
            f.update_inequality(z, friction_cone=MU)
        else:
            f.update(z)
        hyps.append((f.xhat, f.P, c_post[mode] * hmm.prior(mode)))
    return mixture(hyps)

# IP-299 PCC：概率 + 保形碰撞证书；连续碰撞检测
def certified_prefix(A, est, obstacles, delta, det, policy):
    P = age_inflate(est.P_aud, est.F, est.Qc, est.G, est.Sigma_u, est.age)
    x_obs, u_deg, obs_ok = certifiable_projection(est.xhat, P, est.obs)
    if not obs_ok:
        return 0, None, 'obg_veto'
    k_model = conservative_ccd_prefix(A, x_obs, P, obstacles, delta, 'chi2')
    k_conf  = conformal_ccd_prefix(A, x_obs, est.calib, obstacles, delta)
    k_det   = latency_feasible_prefix(A, det.tau_det, policy.delta_safe, policy.a_max)
    k = min(k_model, k_conf, k_det)
    m_safe = min_safety_margin(A[:k], x_obs, P, obstacles, det)
    if k == 0 or m_safe <= 0:
        return 0, None, 'collision_veto'
    bound = 'intersection' if k_model > k_conf else 'conformal'
    return k, m_safe, bound

# IP-300 CCIL：预期违背似然比，而非固定力阈值
def isolate(y_det, xhat, c_plan):
    log_lr = loglik(y_det, 'planned_contact', xhat, c_plan) - loglik(y_det, 'free', xhat)
    p_coll = sigmoid(B0 + B1 * log_lr + B2 * (c_plan is None))
    cls = argmax({'intended': 1 - p_coll, 'collision': p_coll,
                  'near_miss': near_miss_score(y_det)})
    return cls, p_coll, isolate_link(y_det, xhat)

# IP-301 PCR：碰撞反射与恢复门控
def post_collision_reflex(event, est, obstacles):
    if event.cls != 'collision':
        return est, obstacles
    cmd = soft_impedance(direction=event.normal, k=K_SOFT, d=D_SOFT)
    obstacles.add(event.geometry)                 # 单调只增
    est = robust_reset(est, impulse=event.impulse)
    return est, obstacles

def recovery_gate(est, pcc, det, n_rec):
    return est.consistency_ok and pcc.valid and det.tpr > TAU_TPR and n_rec >= N_REC

# IP-302 SRX：状态-风险接口；任一审计失效即无穷大
def aegis_risk_scale(U_emb, est, p_coll, det, policy):
    lam_emb = embodied_risk_scale(*U_emb, policy)
    lam_state = policy.k_s * (1 + trace(est.P_aud) / policy.p_scale
                              + est.u_deg / policy.deg_scale
                              + est.age / policy.age_scale
                              + est.debt / policy.debt_scale)
    lam_coll = policy.k_c * (1 + p_coll / policy.delta
                             + det.tau_det / policy.tau_det_max
                             + (1 - det.tpr) / policy.tpr_scale)
    if not (est.caes_valid and est.obs_valid):
        return float('inf')
    return max(lam_emb, lam_state, lam_coll)

# IP-304 AEGIS 主闭环：控制域只读、快速复核、不等待完整证书
def AEGIS_round(M, obs, audio, tac):

    snap = M.snapshot.read(now=M.clock.now())          # 含年龄传播
    if snap is None:
        M.ctrl_out.publish(stop_envelope())
        return 0, None, J_AEG(M, 'tame_veto')
    lam = aegis_risk_scale(M.emb_uq(), snap.est, snap.p_coll,
                           M.ccil.health(), M.policy)
    A = M.ach.propose_ctrl(...)
    k, m_safe, bound = AEGIS_Certify_fast(A, snap, M.obstacles,
                                          M.delta, M.ccil.health(), M.policy)
    if k == 0:
        M.ctrl_out.publish(safe_stop())
        return 0, None, J_AEG(M, 'collision_veto')
    M.ctrl_out.publish(A[:k], lam)

    # ---- 计量域 50Hz ----
    if M.clock.due_metric():
        est = M.caes.update(M.obs_buf, M.u, M.dt, x_gt=M.seal.gt_if_available())
        est.obs = observability_gate(M.F, M.H, M.R, W_OBS)

        pcc = M.pcc.verify(M.ach.candidate(), est, M.obstacles, M.delta)
        M.snapshot.write(est, pcc, seq=M.seq + 1)

    cls, p_coll, link = M.ccil.detect(tac, M.torque_residual(), audio, M.current)
    if cls == 'collision':
        M.est, M.obstacles = post_collision_reflex((cls, p_coll, link), M.est, M.obstacles)
        M.mode = 'REFLEX'
    if M.mode == 'REFLEX':
        M.n_rec = M.n_rec + 1 if recovery_gate(M.est, M.pcc, M.ccil.health(), M.n_rec) else 0
        if M.n_rec >= N_REC:

    return k, lam, J_AEG(M)

## 4. 推导

**引理 33（审计协方差单边保守）** `P_aud=κP_self, κ≥1 ⇒ P_aud⪰P_self`，故同一马氏半径下 `𝒞_self⊆𝒞_aud`；任何基于 `P_aud` 的碰撞检查都比基于 `P_self` 更保守。若 `\bar{NEES}=κn`，按 `P_aud` 的期望 NEES 回到 `n`。系：**安全审计必须单边；允许审计缩小 P 等于允许滤波器自证。**

**引理 34（年龄单调性）** 若 `Q_c⪰0, GΣ_uGᵀ⪰0`，则 `P_aud(τ)⪰P_aud(0)` 且 `tr P_aud(τ)` 单调不减；`λ_state` 对 `τ` 不减，`k*` 对 `τ` 不增。**旧快照只会让系统更保守。**

**引理 35（不可观测方向 CRLB）** 无偏估计满足 `Cov(x̂)⪰J^{-1}`，`J=O_W`。若 `λ_i≤ε_obs`，则 `u_i` 方向方差 `≥1/ε_obs`，`λ_i→0` 时发散。**任何有限精度证书都不能依赖 U_deg；u_deg 是数据无法降低的盲区。** 系：OBG 必须是认证前缀的前置门。

**引理 36（保形碰撞界）** 在可交换性下，`P(x∈C_α(x̂))≥1−α`（有限样本）。若 `d` 为 `L_d`-Lipschitz 且 `min_{x∈C_α}d(x,O)>0`，则 `P(collision)≤α`。**该界不依赖高斯/椭球假设，是尾部资格失败时的兜底。** 系：模型基界紧、保形界稳，PCC 取交集。

**引理 37（检测延迟-速度-穿透）** `Δ_pen≤v_maxτ_det+½a_maxτ_react²`；`Δ_pen≤Δ_safe` ⇒ `v_max≤(Δ_safe−½a_maxτ_react²)/τ_det`。**检测器延迟直接决定允许速度。** 系：这是硬速度帽，不是软惩罚。

**引理 38（接触可观测性恢复条件）** `O_c=O_0+ΣΦᵀJ_cᵀR_c^{-1}J_cΦ`。若 `rank(O_c)>rank(O_0)`，接触恢复至少一个退化方向；若 `J_c` 在 `U_deg` 上为零，则接触不提供该方向信息。**接触辅助估计不是无条件有效：必须检查接触雅可比在退化子空间上的投影。**

**定理 27（严格包含与风险单调）** 在 CAES 单边审计、OBG 秩条件、TAME 年龄传播、PCC 双界、CCIL 健康度、PCR 单调障碍集下：AEGIS 在退化条件下逐指令等于 EMBODIED/R71/R68；任意有效执行的风险界 ≤ EMBODIED。**安全单调不减，效率只在四门全过时获益。**

**定理 28（J_AEG ⇒ 概率碰撞安全）** 若通过 `J_AEG`，则认证前缀内 `P(collision_t)≤δ_t+ε_tail+ε_obs+ε_det`；使用分布无关保形界时 `ε_tail=0`。**证明：按「界失败/退化方向/检测漏检」三部分做并集界。** 系：碰撞安全是「可审计 δ + 三项显式松弛」；隐藏松弛项就是隐藏风险。

**定理 29（估计器不能自证）** 存在线性系统与噪声实现，使新息白化、NIS 通过，但状态误差在不可观测子空间任意大。构造：取 `Hu=0`，初值误差沿 `u`，过程噪声不激励 `u`；则新息不受影响，NIS/白化全过，而 `u` 方向误差不降、NEES 随 `P_self` 收缩而发散。**NIS 是必要非充分条件；必须有独立真值 NEES 与 OBG。** 系：CAES 与 OBG 必须同时存在。

**定理 30（碰撞-估计闭环收缩）** 在 PCR 障碍集单调、速度帽不增、CAPE 秩条件成立下，不存在「越撞越快」的自激循环；有限次事件后要么恢复认证，要么停在 R68 包络。**证明：每次碰撞增加约束、降低或保持速度上界；新增约束下信息矩阵单调不减；正阻尼/有限事件 ⇒ 有限终止。** 系：安全层是单向棘轮。

**定理 31（三层证书不可替代）** `J_EMB`（调度/意图/接触）、CAES/OBG（估计可信/可观测）、PCC/CCIL（碰撞可证/可分辨）缺一不可。分别构造反例使另外两层全通过而剩余层失效导致事故。**证明：三个独立反例类。** 系：每层覆盖不同的失效模式，不是冗余盖章。

## 7. 本轮最大风险

**一句话**：AEGIS 把风险界的分母从自报协方差换成了审计协方差、把认证前缀从运动学可执行换成了概率碰撞可证，但 **NEES/NIS 只是二阶矩与平均一致性的检验、保形覆盖依赖可交换性**——如果真实误差重尾/多峰且部署分布漂移使保形校准悄悄失效，而可观测性门只覆盖线性化窗口、漏掉遮挡边缘/摩擦锥切换/接触几何突变等非线性退化，再叠加碰撞检测对**软碰撞/斜碰撞的漏检**，系统就会拿着「NEES 通过、保形覆盖、碰撞概率 ≤δ」的盖章证书，以刚好低于速度帽的速度撞上所有审计都未建模的事件；这不是「估计不准」，而是**审计把不可审计的东西误判为可审计**。

次级风险与缓解：
1. **二阶矩审计掩盖尾部** → 强制尾部资格（峰度/尾覆盖/分位数回归）；不通过禁用 χ² 界，改走保形/Chebyshev，取更保守界。
2. **保形可交换性破裂** → 在线 ACI/加权保形 + 漂移检测；漂移超阈退回模型基保守界并降速。
3. **线性化漏非线性退化** → 多窗口/多工作点 OBG + 残差一致性/条件数监测；退化即主动感知或停止。
4. **检测延迟低估** → 端到端时间戳逐段审计；τ_det 进速度帽；定期注入延迟故障。
5. **软/斜碰撞漏检** → 多模态 + 预期违背似然比；软/斜碰撞专用校准集；漏检率纳入 IVG。
6. **审计-证书串谋** → CAES 与 PCC 用独立校准集/独立追溯链；J_AEG 记录界类型；缩短前缀的审计变更需双签。
7. **障碍集被删除/篡改** → 障碍集单调只增、哈希链、写保护；删除事件触发安全审计而非静默通过。
