# 第 43 轮 · 事件触发证书飞轮：让「事件相机的时间见证」与「快速原型阶梯」接管 Sim-Cert-RAG 的盲窗（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」，但其底层还有一个未被点破的结构性弱点：**证书在两次同步检查之间是"盲"的**。L0 查表/L1 INT8 监控都按固定控制拍运行，帧间 33ms 的盲窗只能靠最坏情况 Lipschitz 上界 `L_m·Δt` 兜底——这既是保守性（可用性崩塌）的根源，也是高速机动下漏检的根源。本轮灵感词「事件相机」「快速原型」分别从**时间**与**迭代速度**两个维度补刀：
>
> **事件相机（Event Camera）** 是天然的"时间见证者"：微秒级异步事件流把"两次检查之间发生了什么"变成可观测量，用**实测形变界** `ρ_E(Δt)` 替代最坏情况 `L_m·Δt`，既降保守又堵盲窗；120–140dB 高动态范围还直接压缩了 `D_sim` 中最难覆盖的光照域随机化缺口。
> **快速原型（Rapid Prototyping）** 是天然的"证伪加速器"：把证书从"一次性大工程"降级为**可丢弃的原型阶梯**（事件仿真 → 低成本帧差代理 → 真实事件传感器 HIL → 整机），数小时即可得到第一个"带标签的 sound 骨架"，让 CKB 的反例库以天为单位增长。
>
> 二者耦合：事件相机给出高频、低延迟的**反例触发信号**，快速原型给出低成本的**验证载体**；飞轮由此从 `Sim→RAG→Edge→Sim` 升级为 `Event→Prototype→Counterexample→CKB→Sim` 的更快内环。

## 0. 直觉与动机

**灵感 1（事件相机 → 把"盲窗"从假设变成证据）**：v19 的证书安全论证是"离散检查 + 连续时间 Lipschitz 桥接"。桥接项 `L_m·Δt` 是全局最坏上界，在大多数平缓运动里严重过保守；而在真正的高速/高动态场景里，最坏上界又可能被低估。事件相机的直觉是：**不问你飞得多快，问你"看到了多少变化"**。异步事件只在像素对数亮度变化超过对比度阈值 `C` 时触发，事件流本身就是一份"变化证据"。据此可以**按证据开有效期**：变化越猛，证书越早要求重检；几乎无事件时，证书可以合法地"睡"更久。这把 v19 的固定拍调度换成**自触发（self-triggered）调度**，保守性和漏检同时下降。副产物：事件相机的高动态范围让强逆光/明暗急变不再直接把边际打穿。

**灵感 2（快速原型 → 证书的"一次性筷子")**：v19 的证书合成动辄小时级，因为它默认"要么完整 sound，要么不算数"。快速原型的直觉是：**先造一个明确标注"还不 sound"的可丢弃原型，用它去证伪，而不是先花一个月去证明**。具体是三级阶梯：P0 用 `v2e`/`ESIM` 把普通视频/仿真渲染成 DVS 事件流，几小时就能跑通事件触发运行时骨架并产出首批反例；P1 用"帧差 + IMU"做一个**低于百元的事件代理**（把普通卷帘相机当劣质事件相机用），在真实光照/运动下快速暴露问题；P2 才上真实事件传感器（DAVIS346 / Prophesee EVK / DVXplorer）+ MCU 做 HIL；P3 整机。每一级都产出反例，但**只有过提升门的原型才允许升级成熟度**。这样 CKB 的增长速度由"实验迭代速度"而不是"证明速度"决定。

**灵感 3（事件触发运行时 → 空转即省电，事件即算力）**：v19 的 L1 INT8 监控是定时轮询。事件相机的异步性给了一个更自然的运行时：**没有事件包就零计算，只维持 L0 胞元和保守界；事件包到达才按"受影响通道"增量更新边际**。这对低成本边缘（MCU）尤其关键——平均功耗随场景稀疏度下降，而突发高动态时又能把算力瞬时堆到最需要的通道上。与 v19 的"离线预算换在线预算"叠加，形成**离线预计算 + 事件驱动增量**的双重降本。

**灵感 4（快速原型 × 事件指纹 → 原型也能被 RAG 检索）**：v19 的 CKB 只索引"证书/反例/课程"。快速原型让每轮实验都留下一个**原型蓝图**（CertSpec + 编译产物 + 反例集 + 成熟度）。若把事件流的统计指纹 `ψ_E`（事件率谱、极性平衡、光流幅值分布、运动突发度）也嵌入，新任务来时可以检索"事件统计最像"的历史原型，只重编译差的传感器/事件参数，把 `T_proto` 从数天压到数小时。

**耦合升级**：事件相机是"证据源"，快速原型是"证伪机"，两者共同把 v19 的静态证书表变成**带时间戳、带成熟度、带反例来源**的活资产。证书不再只回答"此刻安全吗"，还回答"这份结论还能信多久、由哪一级原型背书"。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（事件证据流与形变界）**：事件相机输出异步流 `E = {(u_k, t_k, p_k)}_{k≥0}`，`u_k` 为像素坐标、`p_k ∈ {+1,−1}` 为极性，触发条件为
`|log I(u_k, t_k) − log I(u_k, t_k^ref)| ≥ C`（对比度阈值 `C ≈ 0.15–0.3` log 单位）。
给定时表面/对比度最大化光流估计器，输出像素速度场 `v_E(u,t)` 及其误差界 `ε_v`。定义区间 `[t, t+Δt]` 上的**事件运动证据**
`M_E(t,Δt) = ∫_t^{t+Δt} ‖v_E(·,τ)‖_∞ dτ`。
对证书状态 `x`，定义**事件形变界**
`ρ_E(Δt) = L_φ·(M_E(t,Δt) + ε_v·Δt) + ε_imu·Δt`，
其中 `L_φ` 是证书边际对状态扰动的敏感度（由 SCV 标定），`ε_imu` 为惯性预积分漂移界。`ρ_E` 取代 v19 的盲窗上界 `L_m·Δt`。

**定义 39（自触发证书有效期与时间完备性）**：给定 `t0` 时刻证书 `(x0, m0, θ, L_m, L_φ)`，令
`τ_self = min{Δt ≥ 0 : m0 − L_m·ρ_E(Δt) ≤ θ}`。
称 `[t0, t0+τ_self)` 为该证书的**自触发有效窗口**。运行时必须在 `t0+τ_self` 或以下**重检事件**之一发生时重算：
E1 区域 `Ω` 内事件计数 `N_Ω ≥ N_thr`；E2 状态离开 L0 证书胞元；E3 心跳 `T_max` 到期；E4 IMU/深度残差超阈；E5 分布偏移告警。
**时间完备性假设 (A-TC)**：任何使证书边际下降超过 `ε_safe` 的状态变化，要么在 `Ω` 内产生至少一个事件，要么被 IMU/深度残差或心跳捕获。
**命题（盲窗零漏检）**：在 A-TC 成立且 `τ_self` 由 `ρ_E` 保守计算时，`[t0, t0+τ_self)` 内不存在未被发现的违约。心跳 `T_max` 是**无条件兜底**，用于覆盖 A-TC 失效（低纹理、纯旋转退化、纯光照变化）。

**定义 40（事件触发 anytime 证书状态机）**：LCS 升级为状态机 `M = (S, Σ_E, δ, s0)`，输入字母表 `Σ_E = 事件包 ∪ {deadline, heartbeat, drift_alarm}`。空事件区间内不主动做重计算，仅维持 L0 胞元与保守界；每个事件包按"脉冲驱动特征"增量更新边际，单包预算 `Γ_e`；预算耗尽即做**单调降级**。定义**陈旧度** `A(t) = t − t_last_check` 与**可用率** `U = 1 − 降级时长/总时长`。目标是最大化 `U`，同时满足 `max_t A(t) ≤ T_max` 与零漏检。

**定义 41（快速原型阶梯与证书成熟度提升）**：原型阶梯 `P0→P3`：
P0 事件仿真（`v2e`/`ESIM` 渲染 DVS 流）；P1 低成本事件代理（普通卷帘相机帧差 + IMU，等效阈值 `C_eq`、等效延迟 `ℓ_eq` 建模）；P2 真实事件传感器 + MCU HIL；P3 整机部署。
证书成熟度 `ℓ(C) ∈ {0,1,2,3}`。**提升关系** `P_i → P_{i+1}` 成立当且仅当在跨分布测试集上
`m_{i+1}(x) ≥ m_i(x) − L_m·ε_transfer(i→i+1)` 且违约集为空。
原型证书允许"带标签地不 sound"（用于快速证伪），但**永不提升**。定义**首次原型时间** `T_proto` = 从 CertSpec 到 P0 可运行并产出首个反例的时间。

**定义 42（证书原型编译器）**：`CertSpec = (A, Inv, G, S_cfg, Γ_budget)`，其中 `A` 为自动机、`Inv` 为不变式、`G` 为守卫集、`S_cfg` 为传感器/算力配置。编译器输出四件套：
`R` = 事件触发运行时骨架；`H` = 事件仿真测试床（含 `Δ_event` 与故障注入）；`B` = HIL 上板清单（引脚/驱动/时序）；`T_set` = 由守卫面反向生成的回归测试集。
**编译正确性**：`L(R) ⊆ L(A)`（运行时行为是规范的保守细化）。P1 低配校验器用帧差近似事件，误差 `(C_eq, ℓ_eq)` 写入证书对象。

**定义 43（事件指纹与原型检索）**：事件指纹
`ψ_E = (R(f) 事件率谱, β 极性平衡, h(‖v‖) 光流幅值直方图, κ 时表面曲率, μ 运动突发度)`。
CKB 记录扩展为 `(φ, ψ, ψ_E, C, Ξ, Ξ^P, Π, ℓ)`，其中 `Ξ^P` 为原型反例、`ℓ` 为成熟度。检索相似度 `sim = sim(φ)·sim(ψ)·sim(ψ_E)`。
**RAG 原型合成**：检索最近原型蓝图 → 只重编译 `ΔS_cfg` 与 `ΔΔ_event` → 产出新 CertSpec 草案。**命题**：若原型蓝图事件指纹距离 `≤ d_ψ`，则新任务在 P1 的首个反例时间 `T_proto` 的期望随 `d_ψ` 单调下降。

## 2. 三大新增产出 + 既有升级（增量 IP-57/58/59 + 升级 IP-54/55/56/51/52/53/49/50/45/47）

### 2.1 IP-57 EVENT-TEMPORAL-WITNESS（事件时间见证层 ETW）
1. **事件形变界估计**：时表面 + 对比度最大化光流，分块并行；`ε_v` 用 IMU 预积分交叉校验在线估计，写入证书。
2. **自触发有效期**：对每条守卫边二分求 `τ_self`，输出 `(τ_self, N_thr, T_max)` 三元组。
3. **A-TC 可证伪检测**：低纹理度（图像梯度熵）、纯旋转退化（光流秩）、纯光照变化（全局一致性）三指标联合判定；命中即强制缩短 `T_max` 或转 SafeStop。
4. **HDR 证据增强**：把事件触发率与局部动态范围写入 SCV 的 `Δ_env`，让高动态从"扰动"变成"可证实的观测"。

### 2.2 IP-58 EVENT-TRIGGERED-CERT-RUNTIME（事件触发证书运行时 ETCR）
1. **空转零计算**：无事件包时只维护 L0 胞元与保守界，CPU 进入低功耗态。
2. **脉冲驱动增量监控**：只更新事件包涉及的极性通道/ROI，INT8 MLP 支持增量推理，单包预算 `Γ_e`。
3. **自适应背压**：事件率 `λ_e` 超过阈值时先降采样/扩 ROI，再降级证书档位，保证 `A(t) ≤ T_max`。
4. **陈旧度与心跳**：双计时器 `τ_self` / `T_max`，超时即重检或显式降级，绝不"静默续命"。

### 2.3 IP-59 CERT-PROTOTYPE-COMPILER（证书原型编译器 CPC）
1. **CertSpec → 四件套**：运行时骨架 + 事件仿真床 + HIL 清单 + 守卫面回归测试集。
2. **原型阶梯运行时**：P0 仿真、P1 帧差代理、P2 真事件传感器 HIL、P3 整机，逐级记录 `Ξ^P`。
3. **提升门（Promotion Gate）**：零违约 + 迁移界 + 跨分布测试 + 人工签署，任何一项不满足则钉死成熟度。
4. **低成本代理校验器**：`C_eq`/`ℓ_eq` 建模的帧差事件代理，明确"只用于 P1 证伪、不用于 sound 认证"。

## 3. 四层架构 v8

```
L1: 事件相机(E) + TRI-FUSE(INT8/定点) + IP-49 LIO → 事件光流 v_E、M_E、ρ_E、漂移界 B_t、L_m(局部/全局双轨)
L2: CTC + VLM + IP-35 仲裁 + 事件语义残差 → R_φ(w) + 几何/事件双证据证书 → CKB 指纹 (φ, ψ, ψ_E)
L3: IP-51 CAR(自触发边 + EventValidated) ← IP-58 ETCR(空转零算 + 脉冲增量 + 背压 + τ_self/T_max 双计时)
    → IP-47 乘积模板检索 → IP-39 规划(margin=ρ_E 桥接) → IP-45 总线(事件流 + 成熟度心跳)
    → IP-48 认证流匹配 + IP-43 韵律调度 → IP-53 CMC(事件通道稀疏化看门狗)
L4: IP-55 CKB(事件指纹 + 原型蓝图检索) ← IP-54 SCV(事件仿真 + 事件对抗注入 + 盲窗压力测试)
    → IP-59 CPC(CertSpec→四件套 + 原型提升门) → IP-44 蒸馏 → IP-50 课程(原型阶梯) 
    → RCA 重颁证书(含 τ_self/T_max/成熟度 ℓ) → 契约热更新
运行期: 无事件→零算空转; 事件到达→脉冲增量(<100μs); τ_self/T_max 到期→自触发重检
        任一级提升门失败→钉死成熟度并回退上一级; A-TC 检测失败→缩短 T_max 或 SafeStop
```

## 5. 本轮最大风险

## 2. 关键算法（伪代码）

### IP-57 ETW：事件形变界、自触发有效期与 A-TC 检测
```
def event_deformation_bound(events, t0, dt, L_phi, eps_v, eps_imu):
    # 时表面 -> 对比度最大化光流；分块并行
    v_field, conf = event_flow_cmax(events, t0, dt)
    # 仅用高置信块，低置信块取保守上界
    M_E = integrate_inf_norm(v_field, conf)
    eps_v_t = max(eps_v, imu_crosscheck_residual(events, t0, dt))
    rho = L_phi * (M_E + eps_v_t * dt) + eps_imu * dt
    return rho, v_field, eps_v_t

def self_triggered_deadline(m0, theta, L_m, events, cfg):
    lo, hi = 0.0, cfg.T_max
    for _ in range(cfg.bisect_iters):          # 单调：rho 随 dt 增
        mid = 0.5 * (lo + hi)
        rho, _, _ = event_deformation_bound(
            events, cfg.t0, mid, cfg.L_phi, cfg.eps_v, cfg.eps_imu)
        if m0 - L_m * rho <= theta:
            hi = mid
        else:
            lo = mid
    return max(cfg.dt_min, min(hi, cfg.T_max))

def atc_check(events, frame_grad_entropy, flow_rank, global_light_ratio, cfg):
    # A-TC 三失效模式：低纹理 / 纯旋转退化 / 纯光照变化
    low_texture = frame_grad_entropy < cfg.entropy_min
    rotation_only = flow_rank < cfg.rank_min          # 光流场近似秩亏
    illumination_only = global_light_ratio > cfg.light_ratio_max \
                        and event_count(events) > cfg.event_burst
    if low_texture or rotation_only or illumination_only:
        return False, {
            'low_texture': low_texture,
            'rotation_only': rotation_only,
            'illumination_only': illumination_only}
    return True, {}

def update_temporal_witness(state, events, cert, cfg):
    ok, why = atc_check(events, state.grad_entropy, state.flow_rank,
                        state.global_light_ratio, cfg)
    if not ok:
        cert.T_max = min(cert.T_max, cfg.T_max_degraded)   # 收紧兜底
        cert.force_safestop_if(why.get('low_texture') and state.v_norm > cfg.v_hi)
    rho, v_field, eps_v_t = event_deformation_bound(
        events, cert.t0, state.dt_since_check, cert.L_phi, cert.eps_v, cert.eps_imu)
    cert.tau_self = self_triggered_deadline(
        cert.m0, cert.theta, cert.L_m, events, cfg)
    cert.m_lo = cert.m0 - cert.L_m * rho
    return cert
```

### IP-58 ETCR：空转零算 + 脉冲增量 + 背压
```
def event_triggered_monitor(ev_packet, cert, budget_us):
    t = ev_packet.t
    # (1) 空转：无事件且未到期 -> 零计算
    if ev_packet.is_empty and t < cert.t0 + cert.tau_self and t < cert.t0 + cert.T_max:
        return cert.conservative_state, 'IDLE'

    # (2) 到期/心跳 -> 自触发重检
    if t >= cert.t0 + cert.tau_self or t >= cert.t0 + cert.T_max:
        return full_recheck(cert), 'RECHECK'

    # (3) 背压：事件率过高先降采样/扩 ROI，不直接算全量
    lam_e = ev_packet.rate
    if lam_e > cert.rate_hi:
        ev_packet = downsample_events(ev_packet, target=cert.rate_hi)
        cert.roi = grow_roi(cert.roi, factor=2)

    # (4) 脉冲驱动增量：只更新被激活的极性通道/ROI
    active = polarity_channels(ev_packet) & roi_channels(cert.roi)
    ts = update_time_surface(cert.ts, ev_packet, active)
    margin_delta = int8_mlp_incremental(cert.model, ts, active, budget_us)
    cert.m_lo = clamp_i16(cert.m_lo + margin_delta)

    if cert.m_lo < cert.theta_i16:
        return cert, 'TRIP'
    return cert, 'OK'

def drift_backpressure(cert, lam_e, t):
    # 事件率-陈旧度 PID：λ_e 上升 -> 提前 τ_self；λ_e 下降 -> 允许睡更久
    cert.rate_ewma = ewma(cert.rate_ewma, lam_e, alpha=0.2)
    cert.tau_self = saturate(cert.tau_self_base * (1 - k * cert.rate_ewma),
                             lo=cert.dt_min, hi=cert.T_max)
    return cert
```

### IP-59 CPC：CertSpec→四件套、原型阶梯与提升门
```
def compile_cert_prototype(spec):
    runtime = emit_event_runtime(spec.automaton, spec.invariants, spec.guards)
    # 小模型轨迹包含检查；大模型退化为运行时断言 + 哈希
    assert trace_inclusion(runtime, spec.automaton), 'runtime refines spec'
    sim     = build_event_sim(spec.env, sensor='dvs', backend='v2e',
                              delta_event=spec.delta_event)
    tests   = guard_surface_tests(spec.guards, n=spec.n_tests)
    bringup = emit_hil_manifest(spec.S_cfg)     # 事件传感器 + MCU 引脚/驱动/时序
    return Prototype(runtime, sim, tests, bringup,
                     maturity=0, counterexamples=[])

def run_prototype_ladder(spec, cfg):
    ladder = [compile_cert_prototype(spec)]
    for stage in range(3):                       # P0->P1->P2->P3
        rung = materialize(ladder[-1], target=stage + 1, cfg=cfg)
        # P1: 帧差 + IMU 代理；P2: 真实事件传感器 HIL；P3: 整机
        violations, ce = execute(rung, cfg.tests, budget=cfg.budget)
        rung.counterexamples = ce
        promoted, why = promotion_gate(ladder[-1], rung, violations, cfg)
        if not promoted:
            rung.maturity = ladder[-1].maturity     # 钉死，不提升
            ladder.append(rung)
            return ladder, why
        rung.maturity = ladder[-1].maturity + 1
        ladder.append(rung)
    return ladder, 'P3'

def promotion_gate(prev, nxt, violations, cfg):
    if violations:                       return False, 'counterexample'
    if not cross_dist_shuffle_ok(nxt, cfg): return False, 'overfit_sim'
    if not margin_transfer_ok(prev, nxt, cfg.eps_transfer):
        return False, 'transfer_bound'
    if not human_signoff(nxt):           return False, 'no_signoff'
    return True, 'promoted'

def lowcost_event_proxy(frame_prev, frame_cur, C_eq, exposure):
    # 低成本 P1：帧差近似事件（带等效阈值与延迟）
    d  = log1p(frame_cur) - log1p(frame_prev)
    ev = where(abs(d) >= C_eq, sign(d), 0)
    return events_with_latency(ev, latency=exposure / 2,
                              C_eq=C_eq, note='P1-only, not sound-certifiable')
```

| 事件传感器 HDR 下的极性/带宽饱和 | 低-中 | 饱和检测 + 局部 ROI 衰减 + 多曝光融合兜底；饱和区间计入 `Δ_sens` |

## 6. 本轮最大风险

**一句话**：事件触发把"漏检"从显式的帧间盲窗，悄悄转移到"无事件即安全"的隐式假设上——一旦 A-TC 在低纹理/纯旋转/纯光照场景失效，而快速原型的提升门又被"能跑就行"的工程惯性绕过，系统会以毫秒级延迟和极高置信度做错事，比第 42 轮的仿真偏差更隐蔽；因此 A-TC 的可证伪检测（E88）与原型提升门（E90/E93）必须作为红线，任何一项失败即回退固定拍并钉死证书成熟度。
