# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「路径规划」×「安全交互」）

> R69 把不确定性一分为二，并让系统学会「问」：aleatoric 收紧，epistemic 去交互消解，信息动作也要过 C-RAS-WM 认证。但它仍是一个**近视、单向、逐点**的理论——每个控制周期独立决策；只降低机器人自己的不确定；安全只检查「这一拍动作是否在包络内」。一旦把场景从「一个决策点」扩展到「一条要穿过人群的路线」，三个隐含假设同时失效：
>
> - **逐点提问不可扩展**：路线上的分叉随长度指数增长，「每个岔口都问一次」既付不起社交成本，也来不及。真实决策是：大多数分叉用**条件计划**对冲，只在少数**拓扑瓶颈**处才值得问。
> - **拓扑承诺不可逆**：动作选错可以下一拍改；路线类选错（走进死胡同、走进无法掉头的窄廊）要绕很远。安全因此不只是「此刻不撞」，而是「**任何看似合理的人反应，都不能把我逼进无路可走**」。
> - **交互是双向的**：人选左还是右，取决于他们**预测我会怎么走**。我的路径是一个公开信号；人对我的不确定性 `U_out` 本身就是物理风险（误判导致人走进我的包络）。R69 只问「我该向谁求证」，却从不主动「说清楚」。
>
> 本轮两个灵感正好补上这三块：
> - **路径规划**把歧义从「一个标量」升级为「**一张带同伦结构的路线图**」：路线类、瓶颈门、条件路线树、承诺成本、期权价值。于是「问」变成「**只在答案能改变路线类的地方问**」，其余用对冲。
> - **安全交互**把安全从「单动作包络」升级为「**可逃逸安全核**」：在路径的每个前缀都保留至少一条未被堵死的出口，并把人的反应显式写进不变式——交互不是安全之后的服务，而是安全约束本身。
>
> 核心命题：**把导航表示成「同伦路线类 × 条件路线树 × 可逃逸核」；把不确定性分成三通道——`U_ale` 走 R68 的 λ_floor，`U_in`（路线类/人的意图）在瓶颈处查询、否则用条件树对冲，`U_out`（人错判我的路线）用真实可读声明降低；残余失配 `U_×` 通过放大响应模型支撑集、收缩可逃逸核保守兜底。安全不变量从「单动作包络」升级为「每个已承诺前缀都在可逃逸核内，且至少有一条任何可信人响应都堵不死的出口」。** 命名 **CLEAR-RAS**（Certified Legible Escape-Aware Routing for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该走哪条路、我还能不能退出来、我有没有说清楚**」——不确定性不只是刹车、提问与注视，也是一条保留出口的路线，和一句会被兑现的承诺。

## 0. 直觉与动机

**灵感 1（路径规划 → 歧义住在图上，不住在点上）**
直觉：R69 的 MINT 在「当前决策点」枚举信息动作，默认歧义是局部的。但导航的歧义是**拓扑性**的：左绕与右绕不是同一个动作的两个噪声版本，而是两个同伦类；它们只在经过窄道、岔口、门时才可能互相转换。拓扑学给了一个极强的先验：**不经过门，路线类不会变**。所以对「走哪边」的观测，只有在门附近才有正的信息增益；在开阔地带问「走哪边」，答案不会改变你已承诺的类。由此得到一个可计算的预算规则：**先建路线类图，找瓶颈，只在瓶颈花交互预算；其余用条件计划覆盖多个可能。** 这把 R69 的逐点 VoI 升级为路线级 VoI，把「问」变成一种稀疏资源。

**灵感 2（安全交互 → 安全是「永远有出口」，不是「此刻不撞」）**
直觉：避障只保证瞬时无碰撞，但一个被人群慢慢围住的机器人，每一拍都「当下安全」，却在某一拍突然发现所有逃逸方向都被堵死——碰撞在更早的时刻就已经不可避免。**真正的安全是可行性（viability），不是瞬时合法性。** 因此 R70 的核心安全对象是**可逃逸安全核**：路径的每个前缀都要留在「存在一条认证逃逸动作」的集合里，并且这条出口必须对**任何可信的人响应**都保持可通行。人的运动会消耗出口，所以「安全交互」= 把人的反应纳入不变式，主动让行、减速、声明意图来保住出口；出口保不住时，必须提前换路线类或安全停车，而不是等到最后一拍。

**灵感 3（路径即承诺 → 可读性是一种安全动作）**
直觉：R69 的信息动作全是内向的（看/问/触），目的是降低机器人的 `U_in`；但人机共处中最致命的往往不是「机器人不确定」，而是「人严重错判机器人要做什么」。人以为我会让行、其实我正准备加速通过，于是人走进我的包络。**`U_out` 是物理风险。** 路径规划天然提供了降低它的手段：轨迹形状、注视方向、指示灯、投影路径、口头「我先过」、预期性减速与让行——这些都是**声明动作**，能让人的推断分布靠近我的真实路线分布。关键约束是**真话**：声明必须可兑现、可撤回、可重新声明；用「可读」制造过度信任不是沟通，是操纵，而且会在未来以更高的预测误差反噬安全。

**灵感 4（路径即承诺 → 期权价值，宁可留一条退路）**
直觉：动作级决策的后悔是局部的；路线级决策的后悔是拓扑的。两条名义代价相同的路线，一条在途中保留了可切换的逃生支路，另一条是死胡同，它们的**期望后悔**在 `H_route` 大、承诺不可逆时相差极大。因此路线选择不是简单的「最短 + 风险」，而是「安全字典序 + 期权价值 − 承诺成本」：**保留出口本身就是收益**。这也解释了人类驾驶员为什么在拥堵时会宁可走一条稍远但随时能掉头的路——不是保守，是最小化最坏后悔。

**灵感 5（交互是双刃剑 → 可读即可预测，可预测即可被利用）**
直觉：一旦系统主动声明意图并依赖人的响应模型，就出现新的攻击面：人可以**假装没看见**、可以**利用机器人的可预测性**在它声明的路径上设伏、可以**集体堵死出口**逼它进入危险区；地图也可能被投毒（走廊其实封了、捷径其实是死路）。更隐蔽的是**虚假声明**：宣布「我会让行」却在最后一刻抢行，短期可能避免一次碰撞，长期却破坏信任校准，让未来所有人对机器人的预测都更差。所以 R70 必须同时交付：真实声明证书、信任校准、人群堵口对抗集、路线类投毒检测，以及「声明失败即退回 R69 提问/减速」的单调退化链。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CLEAR-RAS 总览）** CLEAR-RAS = (TOPO, BIN, HEDGE, ESC, CMR, DECL, ROV, RAS-WM§)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **可逃逸不变式**：已承诺的路线前缀始终位于可逃逸安全核 `V_ε` 内，且至少存在一条对 `CMR` 支撑集内任何可信人响应都未被堵死的逃逸边；
(iii) **真实声明**：任何声明必须可兑现、可撤回、在路线类改变前可重新声明；禁止声明可行集之外的机动；
(iv) **瓶颈预算**：查询只发生在路线瓶颈，单位时间 ≤ 1 次；能对冲时优先对冲而非提问；
(v) **单调回退**：声明不可信/可读性不足 → 退回 R69 的查询；查询不可用/失败 → 退回 R68 的纯收紧；回退过程中安全证书单调不弱。

**定义 311（路线图与同伦类）** 自由空间 `F_t`，路线图 `G_t=(V,E)`（广义 Voronoi 图 / 可见图 / 语义拓扑图）。路线 `τ:[0,1]→F_t`，按固定端点的同伦等价分类，得路线类 `[τ] ∈ Π_t`。路线类后验 `b_t ∈ Δ(Π_t)` 由语义地图、观测与历史承诺更新；路线熵 `H_route = H(b_t)`。每个类取代表元 `τ_k`。**路线类一旦被承诺，就不能用局部动作修正——这是 R70 与 R69 最本质的区别。**

**定义 312（瓶颈与交互前沿）** 顶点 `v` 是路线关键点，若删除它会改变可行路线类集合、或改变起点类与目标类之间的连通性。瓶颈集 `B_t` 是这些关键窄道/岔口的集合；交互前沿 `∂B_t = {(v,g)}`，其中 `g` 是在 `v` 处可执行的信息动作。路线级观测 `y_g` 的支撑只落在门事件上；**不经过门，路线类不发生改变**（拓扑不变性，A101）。因此非瓶颈处的 `VoI_route` 恒为零。

**定义 313（三通道不确定性与失配）**
- `U_ale`：执行噪声/纹波等不可约分量（沿用 R69 定义 297）；
- `U_in = H([τ], h | o_t)`：机器人对路线类与人的意图的认知不确定；
- `U_out = D_KL(p_R(τ) || q_H(τ | d_t))`：人对机器人路线的误判（`q_H` 为人由声明 `d_t` 推断出的路线分布）；
- `U_× = E[ ||P_H(·|q_H) − P̂_H(·|q_H)||_TV ]`：人对机器人响应模型与真实响应模型的耦合失配。
四者不做标量相加：`U_ale` 进 λ_floor；`U_in` 进查询/对冲；`U_out` 进声明；`U_×` 进可逃逸核的保守收缩（定义 321）。

**定义 314（耦合响应模型 CMR）** 人的下一步响应
`h_{t+1} ~ P_H(· | s_t, d_t, q_H(· | d_t))`。
关键：人不是对机器人的状态反应，而是对**自己推断出的机器人意图**反应。假设 Lipschitz：
`||P_H(·|q) − P_H(·|q′)||_TV ≤ L_H · D_KL(q || q′)`（A102）。
因此人对机器人的误判会**因果地**改变机器人面对的风险；预测置信记为 `δ_pred`。

**定义 315（条件路线树与对冲）** 条件路线树 `T` 把每个分支结果（门处观测 / 人的响应）映射到一条子路线。**对冲**：选 `T` 使对可信结果集 `Ω_ε` 内的所有结果，叶节点都留在 `V_ε`，而无需事先知道是哪个结果。只有当**不存在**这样的 `T`（不同结果要求不同的拓扑类，或承诺已迫在眉睫）时才需要提问。
`hedge_cost(T) = Σ_ω P(ω)·cost(T(ω))`；通常 `hedge_cost < ask_cost`，因为提问有社交成本且会延迟承诺。

**定义 316（可逃逸安全核 ESC）** 安全集 `S` = 无碰撞且可在制动距离内停住的状态。可逃逸安全核
`V_ε = { s : ∃ 策略 π, ∀ 扰动 w∈W, ∀ h∈supp(P_H), 在 T 时域内保持于 S }`。
逃逸边 `e(s)` 为一条认证的后备机动；逃逸时间 `t_esc(s)`；最早堵死时间 `t_block(s,h)` 为人的响应最早使 `e` 失效的时刻。逃逸裕度
`m_esc(s) = min_e min_{h∈supp(P_H)} [ t_block(s,h) − t_esc(s) ]`。
要求 `m_esc(s) ≥ δ_esc > 0`。**未被堵死的出口** = 对支撑集内所有 `h` 均有 `m_esc > 0`。**安全交互不变式**：已承诺前缀 ∈ `V_ε` 且至少有一条未被堵死的出口。

**定义 317（可读性与声明动作）** 声明动作 `d ∈ 𝒜_decl = {gaze, projected_path, indicator, speech, anticipatory_yield}`。人由此得到 `q_H(·|d)`。可读性
`ℓ(d) = −D_KL(p_R(τ) || q_H(τ|d))`。
选择 `d* = argmax_d [ℓ(d) − c_decl(d)]`，并满足定义 318 的真实性约束。声明成本 `c_decl` 含社交打扰与注意力占用。

**定义 318（真实声明证书）** 声明 `d` 合资格，当且仅当被宣布的事件集 `A_d` 在认证策略下的实际概率 `≥ 1−δ_decl`，**或**系统保证在任何偏离变得可观测/可行动之前至少 `τ_reannounce` 时间内重新声明。禁止：宣布可行集之外的机动；隐瞒已知的会改变路线类的安全越权。**虚假声明是证书违规，不只是伦理问题**——它直接破坏 `P_H` 的校准，抬高未来的 `U_×`。

**定义 319（路线级 VoI 与查询门）** `VoI_route(g) = H(b_t) − E_{y_g}[H(b_t | y_g)]`，只计路线类熵（或可逃逸裕度的期望增益）。查询选择
`g* = argmax_{g∈∂B_t} [VoI_route(g) − c(g)]`，
s.t. 到达时仍早于承诺点。若 `max[VoI_route − c] ≤ 0`，或答案将晚于承诺到达，则**对冲而不提问**。这是 R69 MINT（逐点 VoI）到路线级的拓扑推广。

**定义 320（路线选择与期权价值）** 路线评分
`J(π) = CVaR_α(risk(π)) + λ_c·commit(π) + λ_i·interact(π) − λ_o·option(π)`，
并按字典序先要求所有前缀 ∈ `V_ε`。`option(π)` = 保留多个路线类可行所带来的期望未来 VoI 与期望逃逸裕度；`commit(π)` = 离开当前路线类的不可逆代价；`interact(π)` = 沿路线的查询/声明成本。当两个类的可行性差异显著时，**至少保留两个可行类**——「留一条退路」被写成目标函数的一项。

**定义 321（三通道处置与失配膨胀）**
- `U_ale` → `λ_floor(U_ale)`（R68）；
- `U_in` → 瓶颈查询或条件树对冲；残余未消解部分按 R69 规则计入 `λ_floor`；
- `U_out` → 声明；若 `ℓ < ℓ_min` 或声明不可认证 → 视作 `U_in`（询问/减速），在人群密集处置信 `λ_floor`；
- `U_×` → 将 `P_H` 的支撑集按 `δ_pred` 膨胀、将 `V_ε` 收缩，保守兜底。
四个通道各有独立执行器，互不抵消；任何一条不可信都不允许被另外三条「投票洗白」。

**定义 322（交互-规划耦合安全证书）** `J_CLEAR = (J_FLUID, route_class, H_route, m_esc^min, legibility, declaration_log_hash, U_out, U_×, trust_ece, clear_ver)`。Valid ⇔ Valid(J_FLUID) ∧ `m_esc^min ≥ δ_esc` ∧ 声明真实 ∧ 已承诺前缀 ∈ `V_ε` ∧ `trust_ece ≤ τ_trust`。

**定义 323（威胁模型 ℰ_CLEAR）** `ℰ_CLEAR = ℰ_FLUID × ℰ_signal × ℰ_crowd × ℰ_map`：
- `ℰ_signal`：虚假声明、可读性投毒、制造过度信任、声明后抢行；
- `ℰ_crowd`：人群协同堵死出口、假装没看见、利用可预测性设伏、突然静止；
- `ℰ_map`：路线类投毒（走廊被封/假捷径/过期门）、语义地图漂移导致的假瓶颈。
并入 AIC，训练与审计同时覆盖。

**定义 324（退化链与单调回退）** `CLEAR → FLUID → CALM`：声明不可认证或 `ℓ < ℓ_min` → 关闭 DECL，退回 R69 的瓶颈查询；查询不可用/失败/超时 → 退回 R68 纯收紧。沿回退链 `λ` 单调不降，证书单调不弱：`Valid(CLEAR) ⇒ Valid(FLUID) ⇒ Valid(CALM)`。

**定义 325（时序与计算分配）** 路线规划 1 Hz；瓶颈/交互前沿 10 Hz；可逃逸过滤 1 kHz；声明在路线改变时或每 `τ_decl` 更新；重声明提前量 `τ_reannounce`。路线图缓存并增量更新，不进入电流/伺服实时路径。

**定义 326（可审计的路线承诺）** 每段已承诺前缀写入承诺记录（路线类、逃逸边集合、声明哈希、失效时刻）。审计可离线重放：是否曾越出 `V_ε`、是否曾做出不可兑现的声明、是否曾把出口耗尽而未提前换类。**「安全交互」因此是可审计的承诺，而不是一句自我声明。**

```python
# IP-264 TOPO：路线类图与同伦后验（1 Hz）
class RouteClassPlanner:
    def build(self, semantic_map):
        G = gvd_or_visibility_graph(semantic_map)
        classes = enumerate_homotopy_classes(G, start, goal)   # h-signature
        return RouteGraph(G, classes)

    def posterior(self, obs, prev_b):
        return bayes_route_classes(obs, prev_b)                # b_t over Π_t

# IP-265 BIN：瓶颈与路线级 VoI（10 Hz）
def interaction_frontier(G, b):
    B = articulation_and_narrow_gates(G)                       # 拓扑瓶颈
    return [(v, g) for v in B for g in info_actions_at(v)
            if route_voi(v, g, b) > cost(v, g)]                # 过不了门就不问

# IP-266 HEDGE：先对冲，后提问
def plan_contingent(G, b, human_model, depth=3):
    for T in contingent_trees(G, b, depth):                    # 分支 = 门观测/人响应
        if all(in_viability_kernel(leaf) for leaf in T.leaves):
            return T
    return None                                                # 对冲不了才去瓶颈提问

# IP-267 ESC：可逃逸安全核与 1 kHz 过滤
def escape_margin(s, human_model, policy):
    return min(escape_edge_margin(s, e, h)
               for e in escape_edges(s)
               for h in human_model.support(s))

def viability_filter(s, u, human_model):
    if escape_margin(s, human_model, None) < DELTA_ESC:
        return fallback(s)          # 让行/减速/换路线类/安全停车
    return u

# IP-269 DECL：真实、可读、可撤回的声明
def choose_declaration(route, policy, human_model):
    for d in declaration_candidates(route):
        if not truthful(d, policy):            continue        # 定义 318
        if legibility(d, route, human_model) < LEG_MIN: continue
        return d
    return None                                                # 不会说真话就退回 R69

# IP-276 CLEAR-RAS 主闭环（继承 FLUID-RAS）
def CLEAR_RAS_round(M, s):
    G, b = M.topo.update(M.map, M.obs)
    # 1) 能对冲就不问；只有对冲不了才在瓶颈花查询预算
    T = M.hedge.plan_contingent(G, b, M.cmr)
    if T is None:
        g = M.bin.best_query(G, b, M.budget)
        if g is not None: b = M.flu.ask(g, b)                  # 复用 R69 MINT/CIA
    # 2) 安全字典序 + 期权价值选路线类
    cls   = M.rov.select(G, b, alpha=0.95)
    route = M.topo.representative(G, cls)
    # 3) 真实声明；声明失败即退回 FLUID（不硬撑）
    d = M.decl.choose_declaration(route, M.policy, M.cmr)
    if d is None:
        return M.fluid_round(M, s)
    # 4) 1 kHz 可逃逸过滤：任何时刻都必须留一条堵不死的出口
    a = M.policy.act(s, route, d)
    a = M.esc.viability_filter(s, a, M.cmr)
    # 5) 承诺记录 + 参与式审计 + 证书
    M.vqa_t.log(cls, T, d, M.esc.margin(s), b)
    return a, M.cert(J_CLEAR)
```

## 3. 推导

**引理 19（瓶颈查询支配性）** 路线级互信息满足 `VoI_route(g) ≤ I([τ]; y_g)`；由 A101（拓扑不变性），若 `g` 的观测支撑与路线关键门不交，则 `I([τ]; y_g)=0`。因此非瓶颈处的查询被「对冲」或「不作为」严格支配（成本为正）。在门处 `VoI_route ≤ H(b_t)`，且由最大类间可分性取得上界。系：**交互预算应稀疏地花在能改变路线类的门上**；这解释了为什么 R69 的逐点 VoI 在长路线上会造成「问得太多、问得太晚」。

**引理 20（可读性降低耦合风险）** 在 A102（Lipschitz 响应）与定义 317 下，碰撞风险满足
`R(d) ≤ R_0 + L_H · sqrt(2 · D_KL(p_R || q_H(·|d)))`（Pinsker）。
可读性 `ℓ` 正是该 KL 的负值，故提升 `ℓ` 会降低风险上界。**结论：声明不是礼貌，而是安全动作；「说清楚」可以直接换成更小的风险上界。**

**引理 21（可逃逸不变式 ⇒ 联合安全）** 若沿闭环轨迹每个已承诺前缀 `s_t ∈ V_ε` 且 `m_esc(s_t) ≥ δ_esc > 0` 对 `supp(P_H)` 内所有响应成立，则对任意 `T` 时域，发生「不可避免碰撞」的概率为 0；计入预测误差后，碰撞概率 `≤ ε_T + δ_pred`。要点：`V_ε` 是受控不变集，逃逸边保证在任何碰撞前存在一段可执行的恢复时间；人的响应只能改变「走哪条逃逸边」，不能取消「存在逃逸边」这一事实。

**引理 22（期权价值与承诺后悔）** 两条名义代价相同的路线，若其一保留一条可切换的逃生支路，则其最坏后悔比死胡同路线低至少 `λ_o·option(π)`，且差距随 `H_route` 与不可逆性单调增大。系：**「留一条退路」不是保守主义，而是最小化最坏后悔**；这也给出了 R70 为什么必须在路线层而非动作层做决策的定量理由。

**定理 18（CLEAR 严格包含 FLUID 与 CALM）** 在 A101–A103 下，CLEAR 的字典序策略在任意状态上的期望风险 `≤` FLUID；当路线图在当前状态塌缩为单节点、无瓶颈门、无拓扑承诺、且关闭 DECL 时，CLEAR 逐周期退化为 FLUID（BIN→MINT，HEDGE 为空，ESC→R69 包络）；再令 `VoI ≤ 成本`，FLUID 退化为 CALM。故 `R68 ⊆ R69 ⊆ R70`，安全侧永不更弱，效率侧通过「对冲 + 瓶颈查询 + 可读性」获得 resolution bonus。

**定理 19（真实声明与交互安全）** 若声明满足定义 318 且重声明及时，则沿路线 `U_out` 单调不增（至校准误差 `trust_ece`）；任何「先虚假声明换取短期风险下降」的策略，会使人的预测误差上升、`U_×` 增大，从而在未来至少以 `L_H·ΔU_out` 的量抬高耦合风险。故在安全目标下，**真实声明弱占优**——这把「诚实」从伦理要求变成了可证明的安全性条件。

## 6. 本轮最大风险

**一句话**：CLEAR-RAS 的安全论证押在「人看得懂我的路径、并按我声明的意图调整」这一**耦合响应模型**上——一旦人根本不看、看了不信、或恶意利用「可读即可预测」，拓扑承诺会把一次误判放大成不可撤回的路线级错误；**可读性既能救人，也能把人训练成更精准的伏击者。**

**次级风险与缓解**：
1. **同伦类枚举在动态人群/复杂三维场景中爆炸** → 语义拓扑图 + 增量缓存 + 只在承诺前展开深度 ≤3 的条件树；
2. **可逃逸核过度保守导致「寸步难行」** → 先用期权价值选路、再以 `δ_esc` 自适应放松；只在人群密度高风险区启用全支撑集保守；
3. **声明与真实策略不一致（非恶意漂移）** → 定义 318 的重声明窗口 + 承诺记录审计 + 声明哈希进入 `J_CLEAR`；
4. **人群协同堵出口** → `ℰ_crowd` 对抗训练 + 出口多样性（≥2 条不同方向逃逸边）+ 提前换类；
5. **地图/路线类投毒** → `ℰ_map` + 在线门可通行性复核 + 假捷径的物理先验惩罚。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** `CLEAR-RAS=(TOPO,BIN,HEDGE,ESC,CMR,DECL,ROV,RAS-WM§)`；零学习写操作继承；**可逃逸不变式**（每个已承诺前缀 ∈ `V_ε`，且至少有对 `supp(P_H)` 全部响应都未被堵死的逃逸边）；**真实声明**（可兑现/可撤回/可重声明，不宣布可行集外机动）；**瓶颈预算**（查询只在瓶颈、单位时间 ≤1、能对冲先对冲）；**单调回退**（CLEAR→FLUID→CALM，λ 单调不降）。

**定义 311–312（路线类与瓶颈）** 路线按固定端点同伦分类得 `[τ]∈Π_t` 与后验 `b_t`；删除后改变可行类集合/连通性的顶点为路线关键点，其集合为 `B_t`。A101 拓扑不变性：不经过门，路线类不变 ⇒ 非瓶颈查询 `VoI_route=0`。

**定义 313–314（三通道不确定性与 CMR）** `U_ale` 进 λ_floor；`U_in=H([τ],h|o)` 进查询/对冲；`U_out=D_KL(p_R||q_H(·|d))` 进声明；`U_×` 进保守膨胀。人的响应
`h_{t+1}~P_H(·|s_t,d_t,q_H(·|d_t))`，且 `||P_H(·|q)−P_H(·|q′)||_TV ≤ L_H·D_KL(q||q′)`（A102）——**人按自己推断的意图行动**，因此误判会因果地改变风险。

**定义 315（条件路线树与对冲）** 条件树把门观测/人响应映射到子路线；若存在 `T` 使 `Ω_ε` 内所有叶节点都在 `V_ε`，则对冲成功、无需提问。只有不存在这种 `T`、或不同结果要求不同拓扑类、或承诺迫在眉睫时才提问。

**定义 316（可逃逸安全核 ESC）** `V_ε={s: ∃π, ∀w, ∀h∈supp(P_H), 在 T 内保持于 S}`；逃逸裕度
`m_esc(s)=min_e min_h [t_block(s,h)−t_esc(s)] ≥ δ_esc>0`。
**安全交互不变式**：已承诺前缀 ∈ `V_ε` 且至少一条出口未被堵死。人的动作只能消耗出口，不能取消「存在出口」。

**定义 317–318（可读性与真实声明）** `ℓ(d)=−D_KL(p_R||q_H(·|d))`，选 `d*=argmax[ℓ−c_decl]`。声明合资格：被宣布事件的实际概率 `≥1−δ_decl`，或在任何偏离可观测/可行动前至少 `τ_reannounce` 内重声明；禁止宣布可行集外机动或隐瞒会改变路线类的安全越权。**虚假声明是证书违规**，会抬高未来的 `U_×`。

**定义 319–320（路线级 VoI 与期权选路）** `VoI_route(g)=H(b_t)−E[H(b_t|y_g)]`，仅在 `∂B_t` 上最大化 `VoI_route−c`；答案晚于承诺则改为对冲。路线评分 `J(π)=CVaR_α(risk)+λ_c·commit+λ_i·interact−λ_o·option`，字典序先要求所有前缀 ∈ `V_ε`；可行性差异显著时至少保留两个可行类。

**定义 321（三通道处置）** `U_ale→λ_floor`；`U_in→` 瓶颈查询/对冲，残余按 R69 计 λ；`U_out→` 声明，声明不可信则视作 `U_in` 或减速；`U_×→` 膨胀 `P_H` 支撑集、收缩 `V_ε`。四通道独立执行器，**不允许任一条被另外三条投票洗白**。

**定义 322（J_CLEAR）** `(J_FLUID, route_class, H_route, m_esc^min, legibility, declaration_log_hash, U_out, U_×, trust_ece, clear_ver)`；Valid ⇔ Valid(J_FLUID) ∧ `m_esc^min≥δ_esc` ∧ 声明真实 ∧ 前缀∈`V_ε` ∧ `trust_ece≤τ_trust`。

**定义 323（ℰ_CLEAR）** `ℰ_FLUID × ℰ_signal × ℰ_crowd × ℰ_map`：假声明/可读性投毒/过度信任；人群堵口/装看不见/利用可预测性；假走廊/假捷径/过期门/地图漂移。

**定义 324–326（退化链、时序、可审计承诺）** CLEAR→FLUID→CALM 单调回退；1 Hz 路线类、10 Hz 瓶颈、1 kHz 可逃逸过滤、按需声明；每段前缀写承诺记录（路线类、逃逸边、声明哈希、失效时刻），支持离线重放审计。

## 3. 关键算法伪代码

```python
# IP-264 TOPO：路线类图与同伦后验
class RouteClassPlanner:
    def build(self, semantic_map):
        G = gvd_or_visibility_graph(semantic_map)
        return RouteGraph(G, enumerate_homotopy_classes(G, start, goal))
    def posterior(self, obs, prev_b):
        return bayes_route_classes(obs, prev_b)

# IP-265 BIN：只在瓶颈计算路线级 VoI
def interaction_frontier(G, b):
    B = articulation_and_narrow_gates(G)
    return [(v, g) for v in B for g in info_actions_at(v)
            if route_voi(v, g, b) > cost(v, g)]

# IP-266 HEDGE：先对冲，后提问
def plan_contingent(G, b, human_model, depth=3):
    for T in contingent_trees(G, b, depth):
        if all(in_viability_kernel(leaf) for leaf in T.leaves):
            return T
    return None                                      # 对冲不了才去瓶颈问

# IP-267 ESC：可逃逸裕度 + 1 kHz 过滤
def escape_margin(s, human_model):
    return min(escape_edge_margin(s, e, h)
               for e in escape_edges(s) for h in human_model.support(s))

def viability_filter(s, u, human_model):
    if escape_margin(s, human_model) < DELTA_ESC:
        return fallback(s)                           # 让行/减速/换类/停车
    return u

# IP-269 DECL：真实、可读、可撤回的声明
def choose_declaration(route, policy, human_model):
    for d in declaration_candidates(route):
        if truthful(d, policy) and legibility(d, route, human_model) >= LEG_MIN:
            return d
    return None                                      # 说不了真话就退回 R69

# IP-276 主闭环（继承 FLUID-RAS）
def CLEAR_RAS_round(M, s):
    G, b = M.topo.update(M.map, M.obs)
    T = M.hedge.plan_contingent(G, b, M.cmr)
    if T is None:
        g = M.bin.best_query(G, b, M.budget)
        if g is not None: b = M.flu.ask(g, b)        # 复用 R69 MINT/CIA
    cls   = M.rov.select(G, b, alpha=0.95)           # CVaR + 承诺 + 期权
    route = M.topo.representative(G, cls)
    d = M.decl.choose_declaration(route, M.policy, M.cmr)
    if d is None: return M.fluid_round(M, s)         # 声明失败即退化
    a = M.esc.viability_filter(s, M.policy.act(s, route, d), M.cmr)
    M.vqa_t.log(cls, T, d, M.esc.margin(s), b)
    return a, M.cert(J_CLEAR)
```

## 4. 推导

**引理 19（瓶颈查询支配性）** `VoI_route(g) ≤ I([τ];y_g)`；A101 下若 `g` 的观测支撑与路线关键门不交，则 `I([τ];y_g)=0`，非瓶颈查询被对冲/不作为严格支配（成本为正）；门处上界为 `H(b_t)`，按类间可分性最大化。系：**交互预算应稀疏地花在能改变路线类的门上**。

**引理 20（可读性降低耦合风险）** A102 下 `R(d) ≤ R_0 + L_H·sqrt(2·D_KL(p_R||q_H(·|d)))`（Pinsker）；可读性正是该 KL 的负值，故提升可读性直接降低风险上界——**声明是安全动作，不是礼貌**。

**引理 21（可逃逸不变式 ⇒ 联合安全）** 若每个已承诺前缀 `s_t∈V_ε` 且 `m_esc≥δ_esc>0` 对所有 `h∈supp(P_H)` 成立，则不可避免碰撞概率为 0；计入预测误差后 `≤ε_T+δ_pred`。`V_ε` 是受控不变集，人的响应只能改变走哪条逃逸边，不能取消逃逸边的存在。

**引理 22（期权价值与承诺后悔）** 名义代价相同的两条路线，保留可切换逃生支路者的最坏后悔低至少 `λ_o·option`，差距随 `H_route` 与不可逆性单调增大。系：**「留退路」是最小化最坏后悔，而非保守**。

**定理 18（CLEAR 严格包含 FLUID 与 CALM）** A101–A103 下 CLEAR 的字典序策略在任意状态期望风险 ≤ FLUID；当路线图在当前状态塌缩为单节点、无瓶颈、无承诺且关闭 DECL 时逐周期退化为 FLUID（BIN→MINT、HEDGE 空、ESC→R69 包络）；再令 `VoI≤成本` 退化为 CALM。故 `R68⊆R69⊆R70`，安全侧不让步，效率侧获得「对冲 + 瓶颈查询 + 可读性」的 resolution bonus。

**定理 19（真实声明与交互安全）** 满足定义 318 且及时重声明时，`U_out` 沿路线单调不增（至 `trust_ece`）；任何「假声明换短期收益」的策略都会抬高人的预测误差与 `U_×`，未来至少以 `L_H·ΔU_out` 的量反噬。故在安全目标下**真实声明弱占优**——诚实成为可证明的安全性条件。

## 7. 本轮最大风险

**一句话**：CLEAR-RAS 的安全论证押在「人看得懂我的路径、并按我声明的意图调整」这一**耦合响应模型**上——一旦人根本不看、看了不信、或恶意利用「可读即可预测」，拓扑承诺会把一次误判放大成不可撤回的路线级错误；**可读性既能救人，也能把人训练成更精准的伏击者。**

**次级风险与缓解**：同伦类爆炸（语义拓扑图 + 增量缓存 + 深度≤3 条件树）；可逃逸核过保守（期权选路 + 自适应 `δ_esc`，仅在人群密集高风险区全支撑集保守）；声明漂移（重声明窗口 + 承诺记录审计 + 声明哈希进证书）；人群堵口（`ℰ_crowd` 对抗训练 + ≥2 条不同方向逃逸边 + 提前换类）；地图/路线类投毒（`ℰ_map` + 在线门复核 + 假捷径物理先验惩罚）。
