# 第 44 轮（新循环第 4 轮） · Map-Cert × Semantic-Fence：把「SLAM 漂移」与「语义地图不确定」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 用契约 + rely-guarantee + 租约把「个性化」与「并发」纳入证书，但它仍压在两个未言明的**认识论假设**上：**(H1) 定位是神谕**——所有证书默认「机器人知道自己在哪里」，L1 的 TRI-FUSE/LIO 只被当作状态输入，漂移与协方差从不进入 soundness 证明；**(H2) 语义地图是静态真值**——CKB/几何证书把房间、门、人当作不变标签，从不给「这张地图可能错了/旧了/张冠李戴了」签发证书。本轮灵感词「同步定位与建图」「语义地图」正好刺中这两点：**SLAM** 把「我在哪」从常量变成带漂移与回环突变的随机过程；**语义地图** 把「那是什么」从标签变成带置信度、时效与感知混叠的信念。核心新问题：**证书不只关于状态，还关于「状态赖以定位的那张图」是否可信**——即 **map-conditioned soundness（地图条件可靠性）**。

## 0. 直觉与动机

**灵感 1（SLAM 漂移 → 证书也会「漂」）**：直觉上，一张在 A 房间证明安全的速度证书，被机器人搬到 B 房间时可能完全无效——因为证书的「空间前提」错了。过去的证书是状态空间里的一个谓词 φ(x)；但真实执行里 x 从未被直接观测，只有带误差的 x̂。若 ‖x−x̂‖≤δ 随时间无界增长（无回环的里程计漂移），任何以 x̂ 为索引的证书都会在**错误的位置**被误用。于是定义 **地图条件证书** c=(φ, D, ρ, δ)：安全谓词 φ 只在空间域 D **内缩 δ** 后有效，且必须绑定地图修订号 ρ。一句话：**定位越不确定，证书有效域越收缩**——把 SLAM 协方差变成 soundness 的一等变量，而不是日志里的装饰。

**灵感 2（语义地图 → 证书的「语义局域性」与迁移）**：很多证书本质不是关于连续坐标，而是关于**语义地标**：「这扇门是开的可以过」「这个区域行人优先」「这类物体不能碰撞」。语义地图把连续状态锚定成可命名、可持久、可回访的地标，于是证书可以挂在锚点上，并借**回环/重访**把上一次的证书迁移到这一次。但语义标签会**自信地错**（感知混叠：两扇一样的门、把海报认成人），这正是 v19 检索幻觉在物理世界的镜像。因此迁移必须持证：**锚点标签后验 ≥ 1−β、几何对齐残差 ≤ ε、且先在影子证书里复验**，否则只许重证、不许继承。

**灵感 3（耦合 → 地图更新是共享证书状态的「写」，必须原子失效）**：回环闭合会让位姿**不连续跳变**，地图编辑/动态物体让语义层变化——这些都是一次对「全局证书状态」的写。若证书/租约不携带地图修订号 ρ，并发运行时会用**旧图**签发的证书去守卫**新图**下的动作，形成「地图撕裂读」。于是把第 43 轮的租约 ℓ=(m,τ,λ,κ) 扩展为 ℓ=(m,τ,λ,κ,ρ)，并引入**修订栅栏（revision fencing）**：地图修订单调递增，更新即原子失效所有与变更区域相交的证书。地图更新由此与并发证书共用同一套 rely-guarantee 与线性一致性审计。

**耦合升级**：MCC（地图条件证书）把 SLAM 误差与地图修订编译进证书有效域；SMC（语义锚点证书）负责地标级标签置信与跨回环迁移；MRCR（地图修订一致性运行时）用修订栅栏把地图更新变成可审计的原子失效事件，并回灌 ICV 的线性一致性检查。四层架构从 v8 的「仿真-检索-边缘-人格-并发」升级为 v9 的「+ 地图认知层（map-epistemic layer）」：**任何证书都必须回答「你在哪张图上、这张图多可信」。**

## 1. 形式化定义（增量：定义 44–48）

**定义 44（地图条件证书 MCC）**：证书 c=(φ, D, ρ, δ)，其中 φ 为安全谓词，D⊆M 为地图区域（或地标邻域），ρ 为签发时的地图修订号，δ=(δ_x, δ_M) 为位姿与地图误差界。c 在 (x̂, M_ρ) 上可用，当且仅当：(i) x̂ ∈ D ⊖ δ_x（内缩域）；(ii) ∀l∈D，‖p̂_l − p_l‖ ≤ δ_M；(iii) ρ = ρ_current。**局部 soundness 定理**：若真实位姿满足 ‖x−x̂‖≤δ_x、地标位置误差 ≤δ_M，且 φ 在真实状态成立，则只要执行保持在 D⊖δ_x 内，c 所守卫的动作 sound。**推论（漂移预算）**：地图带来的保守边际 m_map = m_spatial − L_m·δ_x(t) − L_M·δ_M；δ_x 随无回环时间增长，故**证书有效域随时间单调收缩**，必须靠重定位/回环刷新，否则最终坍缩为空集。

**定义 45（漂移预算并入守卫）**：定义 41 的租约扩展为 ℓ=(m, τ, λ, κ, ρ)，其中 m ← min(m_lookup, m_lease, m_persona, m_map)，m_map = m_spatial − L_m·δ_x(t) − L_M·δ_M。**命题**：若 δ_x、δ_M 为 sound 上界（SLAM 误差界可证），则四源取 min 的守卫绝不因地图误差而误放行；若误差界本身失效（感知混叠），定义 44 的前提崩塌，m_map 不再 sound——这是本架构唯一不可自证的假设。

**定义 46（语义锚点证书与受证迁移）**：语义地图 M={(l_i, y_i, p_i, β_i, ρ, t_i)}，y_i 为标签、β_i 为标签后验、t_i 为观测量时刻。语义锚点证书 c@l_i 只在 β_i ≥ 1−β 时有效。**受证迁移引理**：把上次回访 revision ρ 的证书 c 迁移到 ρ′，当且仅当 (i) 语义匹配后验 ≥ 1−β；(ii) ICP/几何对齐残差 ≤ ε；(iii) 影子证书在 ρ′ 上零违例。三条件缺一即**只许重证、不许继承**。**注意**：该引理只能保证「迁移不引入新违例」，不能修复原证书本身的前提失效。

**定义 47（地图修订栅栏 MRCR）**：地图更新事件 u 产生单调修订 ρ→ρ+1，并把变更区域 R(u) 下的证书集合 C_invalid={c : c.D ∩ R(u) ≠ ∅} 原子失效。**栅栏定理**：若 (i) ρ 单调递增且读修订与读证书是同一原子快照（seqlock/epoch）；(ii) 失效先于新修订对外可见（写屏障）；(iii) 任一守卫在取租约时校验 ρ=ρ_current，则任意并发交错下**不存在用旧图证书守卫新图动作**（无地图撕裂读）。**与定义 40 的衔接**：地图修订作为受 rely-guarantee 保护的共享变量，只有地图线程可写，其余任务只读。

**定义 48（静态/动态语义分层证书）**：语义地图分解为静态层 M_s（墙、门、结构）与动态层 M_d（人、可移动物体）。静态层证书只管修订号；动态层证书额外携带 TTL 与占据后验，TTL 过期或占据后验翻转即失效。**命题**：动态层证书的 soundness 不能靠「地图修订」获得（动态层每秒都在变），必须靠「重感知 + TTL」，因此动态语义证书的过期判据必须比静态层严格一个数量级。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 MAP-CONDITIONED-CERTIFICATE（地图条件证书 MCC）
1. **有效域内缩编译**：把证书的空间域 D 按 δ_x、δ_M 内缩，生成 eroded domain 与守卫谓词；δ 来自 SLAM 误差界而非拍脑袋。
2. **漂移预算 m_map**：把位姿/地图误差经 Lipschitz 常数折算成边际衰减，并入定义 45 的四源取 min。
3. **证书-地图绑定哈希**：证书携带 (D_hash, ρ, δ)，防止证书被搬到错误区域误用（空间层面的「张冠李戴」）。
4. **漂移触发重证**：当 δ_x(t) 使 D⊖δ 为空或 m_map<θ，强制重定位/回环/重证，而非降级放行。

### 2.2 IP-61 SEMANTIC-ANCHOR-CERTIFICATE（语义锚点证书 SMC）
1. **锚点证书挂载**：证书挂到语义地标（门/通道/优先区/禁入物），带标签后验 β 与观测量时刻。
2. **受证迁移闸门**：语义匹配 + 几何对齐 + 影子证书三重，缺一重证；输出迁移成功率与误迁移率。
3. **感知混叠检测**：对「相似地标」做主动验证（多视角/额外观测），防「自信地认错门」。
4. **动静态分层**：静态层走修订栅栏，动态层走 TTL + 占据后验，禁止混用。

### 2.3 IP-62 MAP-REVISION-CONSISTENCY-RUNTIME（地图修订一致性运行时 MRCR）
1. **修订栅栏**：单调 ρ + 写屏障 + 原子快照读，保证失效先于新图可见；租约携带 ρ。
2. **原子失效广播**：地图更新时按区域索引 O(log N) 定位受影响证书并原子失效，避免全量重建。
3. **回环跳变处理**：回环导致的位姿不连续被显式建模为「修订 + 全域 δ 重置」，触发与位姿相关的证书重证队列。
4. **审计与回灌**：所有修订/失效/迁移事件写线性一致性审计日志，反例回灌 IP-59 ICV 与 IP-54 SCV。

回退：E95 δ_x 无界增长 → 缩短无回环运行窗口 + 强制重定位；E96 混叠不可控 → 只允许静态层证书、禁止锚点迁移；E97 回环重证风暴 → 回环分区批量重证 + 旧证只读隔离；E99 栅栏开销超标 → 区域分片锁 + 增量失效；E101 可用性代价过大 → 放宽 δ 估计但明确标注为经验假设并降级。

## 5. 本轮最大风险

**一句话**：整个地图条件证书体系把 soundness 押在「δ_x、δ_M 是可证上界」上，而感知混叠恰恰让机器人「自信地错」——位姿与标签误差在混叠处会突破名义界且毫无告警，导致证书被合法地用在错误的语义地点；因此 E96（感知混叠）与 E99（地图撕裂读）必须是红线实验，兜底只能是「无稳定重定位则只用纯反应式安全层 + 全局静态地图证书」。

| D ⊖ δ_x | 内缩域 | 真实位姿落在 D 内的可证区域 |
| m_map | 漂移预算 | m_spatial − L_m·δ_x(t) − L_M·δ_M |
| M={(l,y,p,β,ρ,t)} | 语义地图 | 地标、标签、位置、后验、修订、观测时刻 |
| β_i ≥ 1−β | 锚点证书前提 | 标签后验门槛 |
| ρ→ρ+1 | 修订栅栏 | 地图更新单调递增修订号 |
| C_invalid={c : c.D∩R(u)≠∅} | 失效集 | 更新区域相交证书原子失效 |
| TTL | 动态层时效 | 动态语义证书过期时间 |
| ℓ=(m,τ,λ,κ,ρ) | 扩展租约 | 增地图修订号，防旧图证书 |

## 2. 关键算法（伪代码）

### IP-60 MCC：有效域内缩、漂移预算与重证
```
def compile_map_conditioned_cert(phi, region_D, sem_map, slam_bound, now):
    dx = slam_bound.pose_upper(now)          # 可证位姿误差上界
    dM = sem_map.landmark_upper(region_D)     # 地标误差上界
    D_ero = erode(region_D, dx + dM)          # 空间域内缩
    if is_empty(D_ero):
        return RequireRelocalize(region_D)    # 域坍缩 => 先重定位，不放行
    return Cert(phi=phi, D=D_ero, rho=sem_map.revision, delta=(dx, dM))

def m_map(cert, t, Lm, LM):
    dx, dM = cert.delta
    return cert.m_spatial - Lm*dx_at(cert, t) - LM*dM   # 漂移预算

def needs_reverify(cert, t, theta, Lm, LM):
    return is_empty(cert.D) or m_map(cert, t, Lm, LM) < theta
```

### IP-61 SMC：锚点证书与受证迁移
```
def anchor_cert_valid(c, sem_map):
    return sem_map.beta[c.anchor] >= 1 - c.beta_req and c.rho == sem_map.revision

def certified_transfer(c_old, l, sem_map, beta_req, eps_req):
    # 三重闸门：语义后验 / 几何对齐 / 影子证书，缺一重证
    if sem_map.beta[l] < 1 - beta_req:
        return None
    if icp_residual(l, c_old.anchor) > eps_req:
        return None
    c_new = rebind(c_old, anchor=l, rho=sem_map.revision)
    if not shadow_zero_violation(c_new, sem_map):
        return None
    return c_new                          # 不满足 => 只许重证、不许继承

def aliasing_guard(l, sem_map, k):
    # 对相似地标做主动验证，防「自信地认错门」
    twins = sem_map.similar(l, k)
    if twins and sem_map.match_margin(l, twins) < M_MARGIN:
        return request_extra_observation(l)
    return OK
```

### IP-62 MRCR：修订栅栏、原子失效与快照读
```
def on_map_update(u, sem_map, cert_index, audit):
    rho_new = sem_map.revision + 1
    affected = cert_index.query(u.region)       # O(log N + k)
    with write_barrier(sem_map):                # 失效先于新修订可见
        for c in affected:
            atomic_invalidate(c)
        sem_map.revision = rho_new              # 最后发布修订
    audit.log(invalidate=affected, rho=rho_new)
    requeue_reverify(affected)
    return rho_new

def on_loop_closure(pose_jump, sem_map, cert_index):
    # 回环不连续：修订+1 并全域重置 δ，触发位姿相关证书重证
    rho = on_map_update(MapEvent(region=ALL, pose_jump=pose_jump), sem_map, cert_index, AUDIT)
    reset_drift_bound(pose_jump)                # δ_x 重新有界
    return rho

def lease_valid(lease, theta, t, cur_rho):
    if lease.rho != cur_rho:                     # 修订栅栏：旧图租约作废
        return False
    return (lease.m - lease.lam*(t - lease.tau)) >= theta
```

### IP-51/52/53 升级：四源守卫与地图修订感知的证书栈
```
def car_transition_guard(e, x_hat, cert, persona, lease, sem_map, t):
    theta = cert.alpha_e[e] * cert.theta_sim[e]
    m_lookup  = cert_lookup_L0(x_hat).m_lo[e]
    m_lease   = lease.m - lease.lam*(t - lease.tau)
    m_persona = persona_cap[e](persona)
    m_geo     = m_map(cert, t, L_M, L_M)         # 地图/漂移预算
    return (min(m_lookup, m_lease, m_persona, m_geo) >= theta
            and lease_valid(lease, theta, t, sem_map.revision))
```

| 风险 | 等级 | 缓解措施 |

## 6. 本轮最大风险

**一句话**：整个地图条件证书体系把 soundness 押在「δ_x、δ_M 是可证上界」上，而感知混叠恰恰让机器人「自信地错」——位姿与标签误差在混叠处会突破名义界且毫无告警，导致证书被合法地用在错误的语义地点；因此 E96（感知混叠）与 E99（地图撕裂读）必须是红线实验，兜底只能是「无稳定重定位则只用纯反应式安全层 + 全局静态地图证书」。
