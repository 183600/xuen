## 0. 直觉与动机

### 灵感 1（多语言支持 → 一份真值，多份受控视图）

直觉：第 2 轮的 `RepairCert` 是单语言自由文本。虽然定义 427 要求「数值逐字引用回执」，但同一次修复用不同语言
或交给不同厂商时，会出现四舍五入、单位换算、区间开闭等**表述漂移**；人工审计无法判断哪一份「更真」。
多语言系统的正确做法不是让每种语言各写一份真值，而是**一份结构化真值 + 多份受控投影**：
先有 CIR（canonical interlingual representation），再有各语言视图；每份视图必须回译到 CIR 并证明等价。

关键设计选择：**受控语言而非自由翻译**。自由自然语言翻译不可判定，不能承载安全论证。
我们定义 **CML（Controlled Metrology Language）**：有限语法、固定谓词表、封闭枚举标签、精确十进制/区间数值。
CIR ↔ CML 的投影是可判定、可逐字校验的；自然语言只作为 CML 的再投影，其正确性由 CML 证书传递，
不单独承担语义正确性。这样「多语言」不会变成「多套可能互相矛盾的语义」。

### 灵感 2（通用操作 → 工具库从枚举变为基上的项）

直觉：ToolGauge 的 T₀ 是手写枚举的六个工具；每来一个新传感器/新厂商工具，就要重写 Pre/Post/TCV，
契约不可移植，而且「工具库是否覆盖所有探测能力」无法回答。通用操作（universal actions）的启示是：
**用一小撮带代数律的原始操作作为基**，所有具体工具都是基上的项；schema/前置/预算/循环检查在基层做一次，
具体工具自动继承。这既让 TCV 有统一语义，也让跨厂商程序可以在基层合并、去重、移植。

我们定义 **UOB（Universal Operation Basis）**：`{SENSE, PERTURB, DIFF, PROJECT, FUSE, CERTIFY}`，带类型与代数律。
每个工具 t 编译为基项 τ_t 并附 `CompCert(t)`；TCV 在基项上验证类型/证书/预算/无环。
「通用」是被严格限定的**相对完备性**：相对于声明的操作签名与工具族，基是完备的；不宣称对「一切物理探测」完备。
未编译工具被隔离为外部工具 T_ext，不进入默认探测路径。

### 灵感 3（两者结合 → 表示商化的摊销先验）

直觉：第 2 轮 AP-Cal 在「预训练分布 → 部署分布」偏移下会跨盲区强相关地错。把环境分布分解为
（物理场景 P，本体/传感 R，语言/契约表示 L）。CIR+UOB 定义商映射 q(P,R,L) = (P, ⌜·⌝)。
若 q 保留物理充分信息，则表示差异被商掉，只剩物理偏移：η ≤ η_phys + 2δ_repr。
这把第 2 轮那个「不可消除、只能实测」的 η 拆成了**可归因的两项**：表示损失可被结构性压低，
物理偏移才是真正的硬核。

但商化本身有危险：错误的 CIR 会把不可通约的物理机制强行归为同一标签，得到「翻译不变、跨本体一致、却系统性错误」
的知识。因此必须同时监控物理正确性（独立真值抽样）与跨语言/跨本体残差（定义 439），不能只看一致性。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（规范中间表示 CIR / M-IR）** CIR 是类型化记录空间 𝒞，字段分三类：
- `num`：精确十进制或闭/开区间（唯一数值真源，禁止浮点重编码、禁止隐式单位换算）；
- `lab`：封闭枚举标签（材质、根因、工具码、操作码），取自预注册本体 O；
- `ref`：证据引用（receipt id / cid / 版本）。
任何契约、假设、主张、证书 x 都有规范编码 ⌜x⌝ ∈ 𝒞。CIR 带语义版本 (v_CIR, v_O)。

**定义 433（受控计量语言 CML 与认证投影）** 对每种表面语言 L（自然语言受控子集或厂商 schema），
定义投影 π_L: 𝒞 → L* 与解析 ρ_L: L* → 𝒞 ∪ {⊥}。CML 语法有限、谓词表固定、数值只允许精确字面量。要求：
(a) **数值逐字**：π_L 中每个数值 token 是 x.num 的精确渲染（单位、精度、区间开闭显式）；
(b) **可判定蕴含**：ρ_L(π_L(x)) 与 x 在片段 𝔽（无量词线性算术 + 枚举等式 + 有限合取）上双向蕴含；
(c) **可识别**：ρ_L(π_L(x)) ≠ ⊥。
满足则称 L 是 CIR 的**认证表面语言**，记 `TransCert(L,x)`；翻译误差 δ_L(x) = d_𝒞(ρ_L(π_L(x)), x)，
要求 δ_L ≤ δ*（默认 δ*=0，即所有数值字段严格相等）。

**定义 434（多语言主张-回执-CIR 三重绑定，扩展定义 423）** 主张 c 在语言 L 的表面形式 c_L 有效 ⇔
∃ x∈𝒞：c_L = π_L(x) ∧ TransCert(L,x) ∧ receipts(x) ⊆ 有效回执集 ∧ x.num 中每个数值都能在 receipts 中找到逐字来源。
否则 c_L 在契约序列化时剥离。剥离仍是纯投影，不改变任何数值行为；多语言集合 {c_L} 只共享同一个 x。

**定义 435（通用操作基 UOB）** ℬ = {SENSE, PERTURB, DIFF, PROJECT, FUSE, CERTIFY}。每个 σ∈ℬ 有：
类型签名 τ(σ)、声明的代数律（结合/交换/单位元/线性，仅声明可证部分）、代价 c_σ、最坏时延 τ_σ、
前置/后置包络 Pre_σ/Post_σ。基项 τ∈Ter(ℬ) 由类型化组合生成；⟦τ⟧: State → Dist(Observation) 为指称语义。

**定义 436（工具编译与编译证书）** 工具 t 可编译 ⇔ 存在 τ_t∈Ter(ℬ) 使：
(a) 行为等价 ⟦τ_t⟧ ≈_env ⟦t⟧（符号检查 + 抽样）；
(b) 包络细化 Pre_t ⇒ Pre(τ_t) 且 Post(τ_t) ⇒ Post_t；
(c) 代价/时延同态 c_t = c(τ_t) + o_t，τ_t^max ≤ τ(τ_t) + o_t（o_t 为适配开销）。
`CompCert(t) = (τ_t, 等价证据, 包络细化证据)`。未编译工具为外部工具，隔离在 T_ext。

**定义 437（基闭包与相对完备性）** T_ℬ = {t : CompCert(t) 存在}。称 ℬ 对工具族 T **相对完备** ⇔ T ⊆ T_ℬ。
这是相对声明签名的可证伪工程命题（E443 检验），**不是**「一切物理探测皆可归约」的形而上学断言。

**定义 438（UOB-TCV）** 对探测程序 Π，先编译为基项 τ_Π；检查：
① 类型正确；② 每个子项有 CompCert 或显式外部标记；③ c(τ_Π) ≤ B_tools；④ 基项 DAG 无环、无重复 (σ,args)；
⑤ Pre 包络可满足。执行语义：任一 Pre 实测失败 ⇒ 该调用 void、程序以完成前缀收尾、零副作用（继承定义 418）。

**定义 439（表示商化与跨语言/跨本体残差）** 环境分布 𝒟 分解为 (P,R,L) 的联合分布；商映射 q(P,R,L) = (P, ⌜·⌝)。
定义表示信息损失 δ_repr(𝒟) = TV(𝒟, (q⁻¹∘q)#𝒟)，物理偏移 η_phys = TV(q#𝒟_dep, q#𝒟_env)。
要求 δ_repr ≤ δ*_repr，否则触发 CIR 重建/退化。运行期监控**跨语言残差**：同一盲区的不同语言证书回译到 CIR 必须逐字一致；
不一致计数连续 ≥ q 次（默认 3）⇒ 判定 CIR 不可信 ⇒ 仅保留单语言 ToolGauge 路径。

**定义 440（多语言修复证书与翻译链）** `RepairCert_poly(s) = (x_cert, {c_L}_{L∈S}, receipts, {TransCert(L,x_cert)}, {CompCert(t)})`。
自然语言解释是 CML 的再投影 π^NL_L ∘ π_CML，其正确性由 CML 证书传递；证书携带 (v_CIR, v_O) 与所有证据 cid。

**定义 441（CIR/本体版本与迁移）** 版本不匹配时：次版本兼容允许带**迁移证书** μ: 𝒞_old → 𝒞_new（须通过往返测试）；
主版本不兼容则把相关先验上下文标记为 stale，禁止 AP-Cal 使用，回退第 2 轮 BP-Cal（与定义 428 的隔离机制联动）。

**定义 442（表示商化的摊销先验 MP-Φ^q）** 第 2 轮 MP-Φ 的输入从 (h, receipts) 改为 (⌜h⌝, ⌜receipts⌝, q-context)；
元训练目标加**表示不变性正则**：
min_θ Σ_m E[−log p(u*_m | q(ctx_m))] + β_KL·KL(q_θ‖p_phys) + λ_inv·E_{L,L'} d(q_θ(π_L(x)), q_θ(π_{L'}(x))).
最后一项惩罚同一 CIR 的不同语言视图给出不同后验；因 CIR 数值逐字一致，其理想值为 0。

**定义 443（基上重写与等价）** 在 ℬ 的代数律下定义重写关系 →_ℬ；τ →*_ℬ τ' 须保持 ⟦·⟧ 且使 (c, τ_max) 非增
（按声明的律）。跨厂商程序可在基层合并/去重，但必须附重写证书；不可判定的重写一律拒绝。

**定义 444（PolyGauge 六段闭环 6C+）** 在 ToolGauge 6C 上增加两个审计点：
H 前把盲区编码为 CIR（定义 432）；U 后做多语言投影与 UOB 编译证书归档（定义 436/440）。
H→C→E→C→V→U 语义不变；V 仍强制独立回执交叉验证后才热替换。

**定义 445（PolyGauge 退化链）** 失效条件：CIR 校验器不可用 / TransCert 全线失败 / δ_repr 超阈 / UOB 编译或类型检查失败 /
主版本不兼容 ⇒ 回退 ToolGauge（单语言、枚举工具）；ToolGauge 再失效 ⇒ LeanGauge ⇒ MODGAUGE。

**定义 446（语言/本体白名单与注入防御，扩展定义 429）** VLA 与翻译器只能读取 CIR 数值张量、封闭枚举与 CML 片段；
禁止原始自由文本、二维码、OCR、未认证翻译记忆进入上下文。多语言不扩大攻击面，反而把「语言」压缩到可判定的 CML 内。

**定义 447（继承与编号）** 未重定义的第 1/2 轮记号沿用定义 398–431；令 |S|=1、ℬ={SENSE}∪外部工具、q=id
⇒ PolyGauge ≡ ToolGauge；再令 VLA=∅、MP-Φ=物理 GP ⇒ ToolGauge ≡ LeanGauge；继续退化 ⇒ MODGAUGE。

## 2. 关键算法骨架

```python
# IP-321 CIR：规范表示 + 受控投影 + 翻译证书
@dataclass(frozen=True)
class Num:                      # 精确十进制或闭/开区间，禁止 float 重编码
    text: str; lo: str | None = None; hi: str | None = None
@dataclass(frozen=True)
class CIR:
    cid: str; kind: str
    num: dict[str, Num]; lab: dict[str, str]; refs: tuple[str, ...]
    v_cir: tuple[int, int]; v_ont: tuple[int, int]

def render(x: CIR, L: Lang) -> str: ...              # π_L，只生成 CML
def parse(text: str, L: Lang) -> CIR | None: ...     # ρ_L，失败返回 None

def certify(x: CIR, L: Lang) -> "TransCert | None":
    y = parse(render(x, L), L)
    if y is None or y.num != x.num:        return None      # 数值逐字，δ=0
    if not entails_both_ways(y, x, F):     return None      # 可判定片段双向蕴含
    return TransCert(x.cid, L, version=(x.v_cir, x.v_ont))

# IP-322 多语言主张绑定（扩展定义 423）
def bind_polyglot_claims(x_cert: CIR, langs, receipts):
    out = []
    for L in langs:
        text = render(x_cert, L)
        tc   = certify(x_cert, L)
        if tc is None:                          continue    # 未认证 ⇒ 剥离
        if not numeric_sources_in(text, receipts): continue # 数字无回执来源 ⇒ 剥离
        out.append(SurfaceClaim(L, text, tc))
    return out                                # 数值行为与 |langs| 无关

# IP-323 UOB：通用操作基与工具编译
BASIS = {"SENSE", "PERTURB", "DIFF", "PROJECT", "FUSE", "CERTIFY"}

def compile_tool(t) -> "CompCert | None":
    term = t.uob_expr
    if not type_check(term, BASIS):                     return None
    if not envelope_refines(term, t.pre, t.post):       return None
    if not behavior_equiv(term, t):                     return None
    return CompCert(term, cost(term) + t.overhead,
                    tau_max(term) + t.overhead)

def gain_lo(term):                            # 保守信息增益下界（链式分解）
    return chain_rule_lower_bound(term, assume_gaussian=True)

# IP-324 UOB-TCV：在 CIR+基项层验证
class UOBTCV:
    def verify(self, prog, budget):
        ccs = [compile_tool(t) for t, _ in prog]
        if any(cc is None for cc in ccs):          return False, "uob_compile"
        if not program_type_ok(ccs, BASIS):        return False, "uob_type"
        if sum(cc.cost for cc in ccs) > budget:    return False, "budget"
        if not dag_unique(ccs):                    return False, "loop"
        return True, "ok"

# IP-325 跨本体移植：φ 把基操作细化为某硬件原语
def port(t, phi):
    cc = compile_tool(t)
    return cc if cc and transports(phi, cc.term) else None   # Pre/Post 包络保持

# IP-326 PolyGauge 主闭环（6C+）
def polygauge_6c(M, s):
    x_s      = M.cir.encode(s, M.dbox.R[s])                  # H 前：CIR 编码
    H        = M.lbox.hypothesize(x_s)                       # ToolGauge 原样
    prog     = M.tbox.select(H, M.tools, M.uob_tcv, M.budget_left(s))
    receipts = M.tcv.execute(prog, M.env)                    # E
    if len(receipts) < n_min(s):
        return degrade(s, "insufficient")                    # 退化链
    ctx = [M.cir.encode_receipt(r) for r in receipts]
    mu, Sig = M.apcal_q.calibrate(ctx, H, x_s)               # C，表示商化
    if not M.apcal_q.cross_validate(mu, Sig, M.cross_receipt(s)):
        mu, Sig = M.apcal_q.calibrate(ctx, ["UNKNOWN"], x_s)
        if not M.apcal_q.cross_validate(mu, Sig, M.cross_receipt(s)):
            return degrade(s, "cross_failed")                # V 失败 ⇒ 退化
    cert = M.repair_cert(s, H, prog, receipts)               # U
    cert.polyglot = bind_polyglot_claims(M.cir.encode_cert(cert), M.langs, receipts)
    cert.uob      = [compile_tool(t) for t, _ in prog]
    if not M.cir.commit(cert):                               # 跨语言残差/版本审计
        return degrade(s, "cir_untrusted")
    M.mreg.hot_replace(M.dpe, cert.ec)                       # 主控不变
    M.pquar.record(M.apcal_q.last_gain, realized_gain(receipts))
    return True
```

## 3. 推导（引理 51–55）

**引理 51（翻译不变性）** 若所有表面主张由定义 433 的认证投影生成且数值字段 δ=0，则对任意语言集合 S，
数值通道的输出（回执、校准后验、热替换后子图）与 S 无关。
证明思路：π_L/ρ_L 只作用于 CIR 的展示层；定义 434 的剥离是投影；数值字段逐字相等 ⇒ 下游纯函数相同。
这是第 2 轮引理 49 的多语言推广：新增语言只增加视图，不增加数值自由度。

**引理 52（UOB 编译保持验证语义）** 若所有 t∈Π 满足 CompCert(t) 且包络细化成立，则
ToolGauge TCV(Π) 接受 ⇒ UOB-TCV(compile(Π)) 接受，且执行语义在 ≈_env 下一致；
UOB-TCV 因类型/证书/预算拒绝的项不产生物理副作用。
证明思路：类型检查、包络细化、代价同态 + 对程序结构归纳；拒绝发生在执行前，故零副作用。

**引理 53（表示商化的偏移分解）** 设 q 为定义 439 的商映射，则
η = TV(𝒟_dep, 𝒟_env) ≤ η_phys + 2δ_repr。
证明思路：TV 的三角不等式 + 数据处理不等式（pushforward 不增 TV）：
TV(𝒟_dep,𝒟_env) ≤ TV(𝒟_dep,q#𝒟_dep) + TV(q#𝒟_dep,q#𝒟_env) + TV(q#𝒟_env,𝒟_env)，前两项均 ≤ δ_repr。
**系 53.1**：引理 47 的超额风险界中的 η 可替换为 η_phys + 2δ_repr；当 CIR/UOB 使 δ_repr→0 时，
先验迁移的不可约项只剩物理偏移。注意这是上界，δ_repr 的估计误差须计入（E447），不能把上界当等号。

**引理 54（多语言证书的安全性与非扩展性）** 多语言投影集合不改变 V 阶段判定与热替换等价性；
|S| 增加不增加数值攻击面；新增风险仅为「错误翻译被认证」，其上界由 CML 可判定片段与数值逐字约束控制；
未认证语言视图被剥离。
证明思路：定义 434/446 + 引理 51；数值源检查把每个数字绑定到 receipts，标签来自封闭本体。

**引理 55（基闭包下的组合代价与增益）** 若 ℬ 满足声明的代数律且 CompCert 对所有 t∈T₀ 成立，则
c(Π)=Σc_t 可加，Ĝ(Π) ≥ ΣĜ_lo(t) − I_cross（交叉项），L_max 与预算不变式保持；
跨厂商重写 →_ℬ 不增代价、不改语义。
证明思路：代价同态 + 高斯信息增益链式法则（交叉项由条件互信息显式扣除，故为下界）+ 重写按项大小良基。
**系 55.1**：第 2 轮引理 46(b) 的增益注在基层用 Ĝ_lo 计算仍安全，且给出多工具组合的联合界。

## 6. 本轮最大风险（一句话）

**一句话**：CIR/UOB 的「普遍性」本质上是人为声明的**本体承诺**——若 CIR 把不可通约的物理机制强行同化为同一标签，
系统会得到「翻译不变、跨本体一致、却系统性错误」的知识；这比第 2 轮的风险更隐蔽，
因为错误会以「已认证、可移植」的外观扩散到所有语言与本体，而翻译不变性检验对此**完全盲视**。

**次级风险与缓解**：
1. **错误本体同化** → 跨语言残差只查表示一致性、不查物理正确性；保留独立物理真值抽样与本体可证伪实验（E444/E447），
   主版本不兼容强制隔离（定义 441）；
2. **把相对完备性误读为绝对完备** → 只在声明签名内宣称；未编译工具隔离 T_ext（E443）；
3. **CML 片段过窄，真实解释无法认证** → 只认证可判定部分，其余标记「未认证解释」，不进入证书数值（定义 433）；
4. **δ_repr 被低估** → 显式上界 + E447 校准 + 超阈退化；
5. **多语言注入仍可经枚举标签** → 标签来自封闭本体 + 白名单（定义 446）；
6. **版本迁移静默改语义** → 往返测试 + stale 标记 + 禁止 AP-Cal 使用旧上下文；
7. **UOB 行为等价只能抽样验证** → 符号检查 + V 阶段独立回执交叉验证双重兜底。

## 2. 形式化定义（要点）

**定义 432（CIR）** 类型化记录空间，字段 `num`（精确十进制/区间）、`lab`（封闭本体标签）、`ref`（证据引用），带版本号；唯一数值真源。
**定义 433（CML 与认证投影）** π_L/ρ_L 双向；数值逐字、片段 𝔽 双向蕴含、可识别；δ_L ≤ δ*（默认 0）。
**定义 434（多语言三重绑定）** 表面主张有效 ⇔ 是某 CIR 的认证投影 ∧ 引用有效回执 ∧ 数值逐字可溯源；否则剥离为纯投影。
**定义 435（UOB）** 六个带类型与代数律的原始操作；基项由类型化组合生成，具指称语义。
**定义 436（CompCert）** 行为等价 ≈_env + 包络细化 + 代价/时延同态；未编译工具隔离 T_ext。
**定义 437（相对完备性）** T ⊆ T_ℬ，仅对声明签名成立，可被 E443 证伪。
**定义 438（UOB-TCV）** 类型/证书/预算/无环/前置五查；前置实测失败 ⇒ void + 零副作用。
**定义 439（表示商化）** q(P,R,L)=(P,⌜·⌝)；δ_repr=TV(𝒟,(q⁻¹∘q)#𝒟)，η_phys=TV(q#𝒟_dep,q#𝒟_env)；跨语言残差连续 3 次不一致 ⇒ CIR 不可信。
**定义 440（多语言 RepairCert）** CIR 真值 + 各语言认证投影 + 回执 + 翻译链 + 编译证书，携带版本。
**定义 441（版本迁移）** 次版本可迁移（往返测试），主版本不兼容 ⇒ stale 先验隔离 + 回退 BP-Cal。
**定义 442（MP-Φ^q）** CIR 上下文 + 物理 KL 锚 + 表示不变性正则 λ_inv。
**定义 443（基上重写）** 代数律下有向重写，语义保持、代价非增；不可判定则拒绝。
**定义 444（6C+）** ToolGauge 6C + H 前 CIR 编码 + U 后多语言/编译证书归档。
**定义 445（退化链）** PolyGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。
**定义 446（语言/本体白名单）** 仅 CIR 数值、封闭枚举、CML 片段可进入 VLA/翻译器；禁自由文本/二维码/OCR/未认证翻译记忆。
**定义 447（继承）** 令 |S|=1、ℬ={SENSE}∪T_ext、q=id ⇒ PolyGauge ≡ ToolGauge。

## 3. 关键算法骨架

```python
# IP-321 CIR 与翻译证书
def certify(x: CIR, L: Lang) -> "TransCert | None":
    y = parse(render(x, L), L)                 # ρ_L ∘ π_L
    if y is None or y.num != x.num:       return None   # 数值逐字，δ=0
    if not entails_both_ways(y, x, F):    return None   # 片段 𝔽 双向蕴含
    return TransCert(x.cid, L, version=(x.v_cir, x.v_ont))

# IP-322 多语言主张绑定（扩展定义 423）
def bind_polyglot_claims(x_cert, langs, receipts):
    out = []
    for L in langs:
        text = render(x_cert, L); tc = certify(x_cert, L)
        if tc and numeric_sources_in(text, receipts):
            out.append(SurfaceClaim(L, text, tc))        # 否则剥离
    return out                                          # 数值行为与 |langs| 无关

# IP-323/324 UOB 编译与基项 TCV
def compile_tool(t):
    term = t.uob_expr
    if not type_check(term, BASIS):                 return None
    if not envelope_refines(term, t.pre, t.post):   return None
    if not behavior_equiv(term, t):                 return None
    return CompCert(term, cost(term)+t.overhead, tau_max(term)+t.overhead)

class UOBTCV:
    def verify(self, prog, budget):
        ccs = [compile_tool(t) for t, _ in prog]
        if any(cc is None for cc in ccs):        return False, "uob_compile"
        if not program_type_ok(ccs, BASIS):      return False, "uob_type"
        if sum(cc.cost for cc in ccs) > budget:  return False, "budget"
        if not dag_unique(ccs):                  return False, "loop"
        return True, "ok"

# IP-326 6C+ 闭环（含表示商化与跨语言审计）
def polygauge_6c(M, s):
    x_s      = M.cir.encode(s, M.dbox.R[s])                # H 前
    H        = M.lbox.hypothesize(x_s)
    prog     = M.tbox.select(H, M.tools, M.uob_tcv, M.budget_left(s))
    receipts = M.tcv.execute(prog, M.env)
    if len(receipts) < n_min(s): return degrade(s, "insufficient")
    ctx = [M.cir.encode_receipt(r) for r in receipts]
    mu, Sig = M.apcal_q.calibrate(ctx, H, x_s)             # 表示商化校准
    if not M.apcal_q.cross_validate(mu, Sig, M.cross_receipt(s)):
        mu, Sig = M.apcal_q.calibrate(ctx, ["UNKNOWN"], x_s)
        if not M.apcal_q.cross_validate(mu, Sig, M.cross_receipt(s)):
            return degrade(s, "cross_failed")
    cert = M.repair_cert(s, H, prog, receipts)
    cert.polyglot = bind_polyglot_claims(M.cir.encode_cert(cert), M.langs, receipts)
    cert.uob      = [compile_tool(t) for t, _ in prog]
    if not M.cir.commit(cert): return degrade(s, "cir_untrusted")   # 定义 439
    M.mreg.hot_replace(M.dpe, cert.ec)
    M.pquar.record(M.apcal_q.last_gain, realized_gain(receipts))
    return True
```

## 4. 推导

**引理 51（翻译不变性）** 认证投影 + 数值 δ=0 ⇒ 数值通道输出（回执/后验/热替换子图）与语言集合 S 无关。
（π_L/ρ_L 只作用于展示层；剥离是投影；数值逐字 ⇒ 下游纯函数相同。推广第 2 轮引理 49。）
**引理 52（编译保持验证语义）** CompCert + 包络细化 ⇒ TCV(Π) 接受 ⇔ UOB-TCV(compile(Π)) 接受；拒绝项零副作用。
（类型/包络/代价同态 + 结构归纳。）
**引理 53（偏移分解）** η ≤ η_phys + 2δ_repr。证明：TV 三角不等式 + pushforward 数据处理不等式。
系 53.1：引理 47 中的 η 可替换为 η_phys+2δ_repr；δ_repr→0 时只剩物理偏移（估计误差须计入 E447）。
**引理 54（多语言非扩展性）** 多语言投影不改变 V 判定与热替换等价性，|S| 不增加数值攻击面；未认证视图被剥离。
**引理 55（基闭包组合界）** c(Π)=Σc_t；Ĝ(Π) ≥ ΣĜ_lo(t) − I_cross；重写 →_ℬ 不增代价、不改语义。
系 55.1：第 2 轮增益注在基层用 Ĝ_lo 仍安全，且得到多工具联合界。

## 8. 本轮最大风险

**一句话**：CIR/UOB 的「普遍性」是人为声明的**本体承诺**——若 CIR 把不可通约的物理机制强行同化为同一标签，
系统会得到「翻译不变、跨本体一致、却系统性错误」的知识；错误以「已认证、可移植」的外观扩散到所有语言与本体，
而翻译不变性检验对此完全盲视。

三重兜底：独立物理真值抽样与本体可证伪实验（E444/E447）、跨语言残差监控 + 主版本 stale 隔离（定义 439/441）、
V 阶段独立回执交叉验证（定义 421.V）。次级风险（相对完备性误读、CML 覆盖不足、δ_repr 低估、枚举标签注入、
迁移静默改语义、行为等价只能抽样）在想法区 §6 逐条给出缓解。
