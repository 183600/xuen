# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「隐私保护」×「基线复现」）

> 第 60 轮把执行证据从「事后日志」升级为「闭环内生」：SSM 场景先验、CIEC 意图约束、EPIR 消息级隔离、SERC 场景适应、PCE++++ 四维认知预算。但证据层仍建立在两个未经审视的假设上：
> 1. **证据即隐私**：EV-exec 含力/位姿/场景/意图/对话，EPIR 却把影子副本原样同步到云端，XMC++ 再跨模态融合。隐私被当成「发布前脱敏」的外挂步骤，而不是**编译期的发布约束**。
> 2. **证据完整 ≠ 结论可复现**：EPIR 只保证消息到达、顺序、哈希一致；它能证明「这条证据没丢」，却不能证明「独立第三方按同一环境、同一随机种子重放后，能得到同一张 E187–E191 的表」。没有胶囊（capsule）的完整性只是**自证**。
> 3. **隐私与复现被误设为对立**：要复现就得放数据，要隐私就得删数据。真实约束是「放什么、放多少、给谁、能否验证」，缺一个把两者放在同一前沿上的形式化。

## 0. 直觉与动机

**灵感 1（隐私保护 → 证据最小披露 EMD）**
直觉：审计员需要「这条轨迹是否满足力上限」，不需要「操作者的家庭住址、健康震颤、语音原声」。隐私不是把名字涂黑，而是**约束攻击者在看到发布视图后对受保护属性的后验**。关键洞见：把证据原子按敏感级 P0–P3 分层，发布视图只保留「验证所必需的最小谓词」；P2/P3 用**承诺 + 零知识谓词**替代原值，P1 用 DP 聚合替代逐条记录。隐私损失定义为属性推断的最大对数比，而不是「是否匿名」。

**灵感 2（基线复现 → 可复现执行胶囊 REC）**
直觉：一个基线结果不是表格里的数字，而是一段**能重新生成该数字的因果配方**：代码摘要、环境镜像、标定、随机种子、决策相关轨迹、指标脚本、容差、复现等级。关键洞见：复现不需要「每一个字节」，只需要**决策相关轨迹**；原始传感器字节只需承诺，不必发布。这把复现从「数据全给」降为「配方 + 承诺」。

**灵感 3（张力 → 隐私-复现前沿 PRF）**
直觉：隐私与复现不是一条直线上的两端，而是二维平面上的**可行域边界**。精确验证「已声称的指标」可以做到近零泄漏（承诺 + 证明）；但独立重算「敏感数据的分布」必须放数据，受 DP 下界约束：要让均值估计误差 ≤ δ，样本量 n 至少 Ω(1/(ε²δ²))。关键洞见：**验证（verification）与重算（recomputation）是两种复现，前者可零知识，后者有不可绕过的隐私下界**。

**灵感 4（合流 → 基线复现契约 BRC）**
直觉：「我们比基线好」这句话只有在**基线和本方法都按同一胶囊、同一环境不变量、配对种子复现**时才成立。若基线本身没复现（基线漂移 D_b 超阈值），或只是「论文参数照抄的重实现」（保真度等级 L2/L3），那么最多只能说「比我们的重实现好」，不能说「比原基线好」。关键洞见：把「基线复现」写成**契约**——基线胶囊、环境不变量、保真度等级、漂移阈值、配对置信区间，五者缺一，结论降级。

**灵感 5（六维预算 → PCE++++++ 与双源账本 DPR）**
直觉：隐私与复现都要花钱：B_priv（每 epoch 的 ε、发布带宽、保险库存储）与 B_repro（重放算力、胶囊存储、锚定频率）。预算耗尽不是「少记一点」，而是改变**可发布性**：B_priv 耗尽 ⇒ 只允许承诺/证明发布（commitment_only）；B_repro 耗尽 ⇒ 新结论隔离（claim_quarantine）；两者都耗尽 ⇒ 本地闭环、暂停对外主张。配套的 DPR 账本只记录胶囊摘要、指标承诺、证明摘要与累计 ε，既防篡改又不泄露原值。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（证据最小披露 EMD）** 证据原子 e=(v_e, σ_e, ρ_e, τ_e)，其中 σ_e∈{P0 公开, P1 内部, P2 敏感, P3 机密}，ρ_e 为来源，τ_e 为时间。角色-目的对 r∈R（审计/研究/云端融合/监管/调试）。发布机制 π_r: E→V_r，V_r 为证据的视图。受保护属性 A（身份、家庭占用、健康震颤、技能水平、位置），辅助知识 aux。定义：
- **先验/后验**：P_adv(A|aux) 与 P_adv(A|V_r,aux)，adv 为攻击者策略族。
- **隐私损失**：L(π)=sup_{r,adv} D_∞( P_adv(A|V_r,aux) ‖ P_adv(A|aux) ) = sup log[P(A=a|V_r,aux)/P(A=a|aux)]。
- **验证效用**：U(π)= 可由 V_r 判定的验证谓词比例（力上限、阻抗包络、场景合规、执行时序）。
- **可容许视图**：Adm(π) ⇔ L(π)≤ε_p ∧ U(π)≥u_min。
- **分层披露算子**：
  - P0 → 原值；
  - P1 → (ε,δ)-DP 聚合或粗粒度摘要；
  - P2 → Com(e;r_e) + 关于 v_e 的零知识谓词（如 v_e≤F_max）；
  - P3 → 仅本地保险库 / TEE 内重放，外部只拿承诺。
- **组合性**：独立证据原子的 DP 发布按基本组合定理累加 ε；跨 epoch 的 ε 由 DPR 单调记账。
关键性质：承诺的 hiding 保证 P2 不泄露 v_e；binding 保证同一承诺不能被开成两个值；DP 保证 P1 的统计发布有可证明的推断上界。

**定义 162（可复现执行胶囊 REC）** 胶囊 C=(d_code, d_env, θ_cal, S_seed, T_trace, m_metric, τ_tol, L_level)。其中：
- d_code：代码/依赖/编译选项摘要；d_env：OS/ROS/驱动/仿真器/硬件版本镜像摘要；
- θ_cal：传感器与执行器标定；S_seed：随机种子集合；
- T_trace：**决策相关轨迹**——观测摘要、场景后验、意图约束、K_safe、派发参数、接触结果、EV-exec 引用；原始高频数据只存承诺 Com(raw) 或留在本地保险库；
- m_metric：指标脚本（与 d_code 绑定）；τ_tol：复现容差；L_level∈{L_exact, L_seed, L_stat}：逐位/同种子/同分布复现等级。
- **重放**：replay(C)→m̂；复现误差 E(C)=‖m̂−m*‖/scale(m*)。
- **可复现**：Reproducible(C,m*) ⇔ E(C)≤τ_tol ∧ 等级满足主张要求（精确主张需 L_exact，统计主张需 L_stat 且给置信区间）。
- **确定性类**：D_exact（同环境逐位一致）、D_seed（同种子一致）、D_stat（多次重放落在置信区间）。
- **最小性**：T_trace 定义为「删除后会使 m_metric 变化的最小事件子序列」，因此胶囊大小与决策复杂度相关，而非与原始采样率相关。

**定义 163（隐私-复现前沿 PRF）** 对发布视图 V 与胶囊 C，令隐私损失 L(V)、复现误差 E(C)。可行域
```
F = {(ℓ,ε) : ∃π,C 使 L(V)≤ℓ ∧ E(C)≤ε ∧ Adm(π)}，
```
Pareto 前沿 PF = F 的极小元集合。两个区域：
- **验证区（verification regime）**：V = 承诺 + VRP 证明，E≈0（对已声称指标），L≈0（在承诺 hiding + ZK 假设下）；但验证者不能探索新指标。
- **重算区（recomputation regime）**：V 含 DP 聚合，E 为估计误差。对取值 [0,1] 的敏感均值，任何 (ε,δ)-DP 机制在 n 个样本上的误差下界 E=Ω(1/(ε√n))（标准 DP 估计下界，Bassily–Smith–Thakurta 型），故达到 E≤δ_r 需 n=Ω(1/(ε²δ_r²))。
- **无免费复现引理**：若 V 足以让独立方**逐位重算**任意敏感原始轨迹，则 V 决定原始轨迹，L(V) 无界；故「精确独立重算」与「有限 ε 隐私」不可兼得。唯一定理级出路是：把「重算」换成「对承诺的验证」。

**定义 164（基线复现契约 BRC）** 给定基线胶囊 C_b、候选胶囊 C_c、环境不变量 I*=(硬件,执行器,传感器标定,ROS/驱动,仿真器,时序模式,种子集)。定义：
- **基线保真度等级** L_b∈{L0 原作者制品重放, L1 从论文独立重实现, L2 参数对齐重实现, L3 环境迁移近似}，以及保真度分数 F_b∈[0,1]（在公开探针套件上与原文行为的一致度）。
- **基线漂移** D_b=(m̂_b−m_b^reported)/scale；若 D_b>τ_drift，原基线主张视为「未复现」，比较必须改用**重复现基线** m̂_b。
- **配对重放**：对每个种子 s∈S_seed，Δ_s=m_c(s)−m_b(s)；报告配对均值、置信区间与效应量。
- **契约有效性**：
```
Valid(C_c,C_b,claim) ⇔ Reproducible(C_c,m*_c) ∧ Reproducible(C_b,m*_b)
  ∧ match(I*_c,I*_b,I*_req) ∧ D_b≤τ_drift ∧ L_b≥L_req
  ∧ CI(Δ) 支持 claim ∧ L(π)≤ε_p。
```
- **降级规则**：若 L_b<L_req，最高结论只能是「相对我们的重实现更优」；若 D_b>τ_drift，结论标注「在重复现环境下」；两者都不得写成「优于原论文基线」。

**定义 165（可验证复现证明 VRP）** 承诺方案 Com（hiding, binding）。公开输入：胶囊摘要 d_C、指标承诺 c_m=Com(m*)、声称值 y_claim、容差 τ、指标脚本摘要 d_m。证明者知道轨迹 T_trace 与开盲 r。关系：
```
R_VRP = { (d_C,c_m,y_claim,τ,d_m) ; (T_trace,r,m*) :
          Com(T_trace,r)=c_m ∧ y_claim=m*(T_trace) ∧ d_m=m.script ∧ ValidTrace(T_trace) }。
```
- **证明** π=ZK(d_C,c_m,y_claim,τ,d_m; T_trace,r,m*)，验证者只得到「声称值与承诺轨迹一致」这一比特。
- **可靠性**：在承诺 binding 与 ZK 可靠性假设下，证明者不能对错误 y_claim 生成有效 π。
- **零知识**：存在模拟器 S，使任何验证者视图可由公开输入模拟；π 不泄露 T_trace 的额外信息。
- **查询隐私（关键限制）**：若验证者可自适应选择 y_claim，则 q 次查询等价于对 m* 的 q 次比较，二分可把 m* 定位到精度 2^{-q}。因此 VRP 必须配 **查询预算 Q** 与 **声称粒度 g**（y_claim 取自公开网格，网格大小 ≤2^Q），或由证明者一次性承诺并公开 y*；否则「零知识」只对单次查询成立。
- **TEE 回退**：对无法电路化的复杂指标，用 TEE 远程证明做 attested replay，信任根从数学假设降为硬件厂商（在 F 中记为不同区域）。

**定义 166（隐私-复现闭环 PRCL）** 算子 PRCL(M, scene, intent, δ_f_req, role):
```
① (E_exec, E_scene) ← collect_and_bind(telemetry, scene, intent, K_safe)
② V ← EMD.release(E_exec ∪ E_scene, role)          # 最小披露
③ if U(V) < u_min and ε_rem > 0:
       V ← EMD.expand(V, Δε)                       # 用预算换验证效用
④ C ← REC.build(E_exec, V, d_code, d_env, θ_cal, S_seed, m_metric, τ_tol)
⑤ C_b ← REC.baseline_capsule()                       # 只在有基线主张时
⑥ if claim_about_baseline:
       valid, level ← BRC.validate(C, C_b, claim, I*)
       if not valid: claim ← claim.downgrade(level)
⑦ π_rep ← VRP.prove(C, claim.value)                  # 对承诺轨迹的复现证明
⑧ ok ← VRP.verify(π_rep, C.digest, claim.value, τ_tol)
⑨ h ← DPR.append(C.digest, Com(claim.value), π_rep.digest, L(V), V.hash)
⑩ B_priv.consume(L(V)); B_repro.consume(replay_cost(C))
⑪ if B_priv.exhausted: role_policy ← 'commitment_only'
    elif B_repro.exhausted: claim_policy ← 'claim_quarantine'
⑫ if EPIR/CPL (第 60 轮) 存在: DPR.cross_link(EPIR.last_seq, CPL.root)
⑬ return (V, C, π_rep, ok, valid, DPR.root(), budget.status())
```
不变量：
(i) ②→⑦ 期间原始 P2/P3 数据不离开本地保险库/TEE；
(ii) ④ 的胶囊摘要绑定 d_code/d_env/m_metric，改一个字节即失效；
(iii) ⑦ 的证明只对 ⑧ 的公开输入成立，不能迁移到另一个 y_claim；
(iv) ⑩ 的 ε 只增不减，DPR 单调审计。

**定义 167（PCE++++++ 六维预算与双债务）** B=(B_scene,B_intent,B_ros,B_exec,B_priv,B_repro)。
- **B_priv=(ε_epoch, Release_bw, Vault_storage)**：隐私预算、发布带宽、保险库容量。
- **B_repro=(Replay_compute, Capsule_storage, Anchor_rate)**：重放算力、胶囊/证明存储、外部锚定频率。
- **隐私债务** D_priv=ε_used/ε_total；**复现债务** D_repro=1−|{claim: REPRO 成功}|/|claims|。
- **耗尽策略**：
  - B_priv 耗尽 ⇒ commitment_only（只发承诺/VRP；禁止原值与 DP 逐条发布）；
  - B_repro 耗尽 ⇒ claim_quarantine（冻结新主张，保留最近已验证主张）；
  - 两者皆耗尽 ⇒ local_only（本地闭环运行，暂停对外发布）；
  - 原 B_scene/B_intent/B_ros/B_exec 策略不变。
- **VOI 扩展**：
```
voi_pr(π)=VOI_meta_pessimistic(π)−cost_cog(π)−cost_exec(π)−cost_priv(π)−cost_repro(π)
cost_priv=λ_ε·ε+λ_bw·Release_bw+λ_v·Vault_storage
cost_repro=λ_r·Replay+λ_c·Capsule+λ_a·Anchor_rate
```

**定义 168（隐私-复现双源账本 DPR）** 扩展 EPIR 的消息级隔离为「主张级」双源记录。条目
```
r_i=(d_C, Com(m*), d_π, ε_i, h(V_i), prev_hash_i, sig_i, ts_i)
h_i=H(h_{i-1} ‖ d_C ‖ Com(m*) ‖ d_π ‖ ε_i ‖ h(V_i) ‖ ts_i)
```
- **防篡改**：任何修改/删除/重排会破坏其后所有 h_i；周期性 Merkle 根外部锚定。
- **隐私预算单调**：验证者检查 Σ_{j≤i} ε_j ≤ ε_total 与 ε_j≥0；回滚 ε 会破坏链。
- **与 EPIR 的分工**：EPIR 保证「EV-exec 消息到达且顺序/哈希一致」；DPR 保证「主张可复现且隐私支出可审计」。前者是传输完整性，后者是**科学完整性 + 隐私完整性**。
- **可验证性**：第三方仅凭 DPR 根 + 公开网格上的 y_claim + VRP 验证，不接触原始数据；需要重算时，按 EMD 策略申请受限视图。
- **胶囊吊销**：若发现 d_env 或 m_metric 被撤回，DPR 记录吊销事件，后续验证返回 revoked，而不是假通过。

## 2. 关键算法伪代码

### IP-161 EMD（证据最小披露）

```python
class EvidenceMinimalDisclosure:
    def __init__(self, epsilon_total, u_min):
        self.eps_total = epsilon_total
        self.eps_used = 0.0
        self.u_min = u_min
        self.vault = EncryptedVault()

    def release(self, atoms, role, purpose):
        view = []
        for e in atoms:
            if e.sensitivity == 'P0':
                view.append(('raw', e.value))
            elif e.sensitivity == 'P1':
                view.append(('dp', self._dp_aggregate(e, role, purpose)))
            elif e.sensitivity == 'P2':
                view.append(('commit+zk', commit(e.value), zk_predicate(e)))
            else:  # P3
                self.vault.put(e.id, e.value)
                view.append(('vault_ref', commit(e.value)))
        return View(view, L=self._privacy_loss(view),
                    U=self._utility(view, role))

    def expand(self, view, delta_eps):
        if self.eps_used + delta_eps > self.eps_total:
            return view            # 不允许透支
        self.eps_used += delta_eps
        return view.add_dp_aggregates(delta_eps)
```

### IP-162 REC（可复现执行胶囊）

```python
class ReproducibleExecutionCapsule:
    def __init__(self, code, env, calib, seeds, metric, tau, level):
        self.d_code = digest(code)
        self.d_env = digest(env)
        self.theta_cal = calib
        self.S_seed = seeds
        self.m_metric = metric
        self.tau = tau
        self.level = level          # L_exact / L_seed / L_stat

    def build(self, trace, view):
        t_dec = minimal_decision_subsequence(trace, self.m_metric)
        raw_commit = merkle_commit(trace.raw_bytes)
        return Capsule(self.d_code, self.d_env, self.theta_cal,
                       self.S_seed, t_dec, raw_commit,
                       self.m_metric, self.tau, self.level)

    def replay(self, capsule):
        env = restore_env(capsule.d_env)
        outs = [run(capsule.d_code, capsule.trace, s, env)
                for s in capsule.S_seed]
        return aggregate(outs, capsule.m_metric)

    def error(self, capsule, claimed):
        return norm(self.replay(capsule) - claimed) / scale(claimed)
```

### IP-163 PRF（隐私-复现前沿）

```python
def pareto_frontier(views, capsules, metric):
    pts = []
    for V in views:
        L = privacy_loss(V)
        for C in capsules:
            E = capsule_error(C, metric)
            pts.append((L, E, V, C))
    pts.sort(key=lambda p: (p[0], p[1]))
    front, best_e = [], float('inf')
    for L, E, V, C in pts:
        if E < best_e:
            front.append((L, E, V, C))
            best_e = E
    return front            # 验证区在左端，重算区沿 DP 下界抬升
```

### IP-164 BRC（基线复现契约）

```python
LEVELS = {'L0': 3, 'L1': 2, 'L2': 1, 'L3': 0}

class BaselineReproductionContract:
    def validate(self, cand, base, claim, invariants, tau_drift, l_req):
        if cand.error(claim.metric) > cand.tau:
            return False, 'candidate_not_reproduced'
        if base.error(base.reported) > base.tau:
            return False, 'baseline_not_reproduced'

        drift = abs(base.reproduced - base.reported) / scale(base.reported)
        if drift > tau_drift:
            base = base.rereproduced()          # 改用重复现基线
        if not match_invariants(cand.env, base.env, invariants):
            return False, 'environment_mismatch'

        level = min(LEVELS[cand.level], LEVELS[base.level])
        if LEVELS[base.level] < LEVELS[l_req]:
            claim = claim.downgrade('vs_reimplementation')

        deltas = paired_delta(cand, base,
                              seeds=common(cand.S_seed, base.S_seed))
```

```python
class DualProvenanceRecord:
    def __init__(self, genesis, epsilon_total):
        self.chain = [sha256(genesis)]
        self.pending = []
        self.eps_cum = 0.0
        self.eps_total = epsilon_total

    def append(self, capsule, metric_commit, proof_digest,
               epsilon, view_hash):
        if epsilon < 0 or self.eps_cum + epsilon > self.eps_total:
            raise PrivacyBudgetViolation
        h = sha256(self.chain[-1] + encode(capsule.digest)
                   + metric_commit + proof_digest
                   + encode(epsilon) + view_hash + encode(now()))
        self.chain.append(h)
        self.pending.append(h)
        self.eps_cum += epsilon
        return h

    def anchor(self, external_store):
        root = merkle_root(self.pending)
        external_store.append(root)     # 只追加
        self.pending = []
        return root

    def verify_budget(self, claimed_eps):
        return abs(self.eps_cum - sum(claimed_eps)) < 1e-9
```

**正确性定理（PRC：Privacy-Reproducibility Certificate）** 假设 A66–A72：
**(A66)** Com hiding/binding，VRP ZK 可靠且零知识；签名不可伪造。**(A67)** DP 机制按证据原子相邻性校准，组合定理适用。**(A68)** 胶囊重放在声明等级内确定；m_metric 摘要一致则实现一致。**(A69)** 环境不变量 I* 覆盖影响指标的混杂因素；基线探针集足以估计保真度。**(A70)** 受保护属性有限，攻击者先验族与 aux 模型包含真实攻击者。**(A71)** 外部锚定只追加且可达。**(A72)** ε 计数器不可伪造，DPR 链覆盖每次发布。

则：
1. **隐私性**：Adm(π) ⇒ L(π)≤ε_p；P1 发布满足 (ε,δ)-DP；P2/P3 只暴露承诺与谓词，除 hiding 破坏外不泄露原值。
2. **复现性**：D_exact/D_seed 胶囊在摘要匹配时 E=0；D_stat 胶囊的重放落在声明的置信区间内。
3. **主张有效性**：Valid(C_c,C_b,claim) ⇒ 基线与候选均复现、环境不变量匹配、漂移受限、保真度等级达标、配对 CI 支持主张；因此「提升」不是环境漂移或弱基线的伪影。
4. **基线降级不可绕过**：L_b<L_req ⇒ 结论只能是「相对重实现」；D_b>τ_drift ⇒ 必须使用重复现基线。故不能把「照抄参数的弱实现」包装成原基线。
5. **无免费复现**：在 A66–A67 下，精确独立重算任意敏感原始轨迹 ⇒ L 无界；有限 ε 下只能验证承诺，不能重算原文。
6. **预算安全**：B_priv 耗尽 ⇒ 仅 commitment_only；B_repro 耗尽 ⇒ claim_quarantine；不存在「既未复现又已发布」且 ε 透支的主张。

| 复现方式 | 发布内容 | 隐私损失 | 复现误差 | 适用场景 |
|---|---|---|---|---|

| 同种子重放 | 决策轨迹 + 承诺 | 低–中 | 0（声明等级内） | 团队内部 |

| 验证 | 承诺 + VRP | ≈0 | 0（对已声称指标） | 公开审计 |

```python
class EvidenceMinimalDisclosure:
    def __init__(self, epsilon_total, u_min):
        self.eps_total, self.eps_used = epsilon_total, 0.0
        self.u_min = u_min
        self.vault = EncryptedVault()

    def release(self, atoms, role, purpose):
        view = []
        for e in atoms:
            if e.sensitivity == 'P0':
                view.append(('raw', e.value))
            elif e.sensitivity == 'P1':
                view.append(('dp', self._dp_aggregate(e, role, purpose)))
            elif e.sensitivity == 'P2':
                view.append(('commit+zk', commit(e.value), zk_predicate(e)))
            else:                          # P3
                self.vault.put(e.id, e.value)
                view.append(('vault_ref', commit(e.value)))
        return View(view, L=self._privacy_loss(view),
                    U=self._utility(view, role))

    def _dp_aggregate(self, atom, role, purpose):
        # 仅对角色需要且 atom 允许的统计量做拉普拉斯/高斯机制
        sens = atom.sensitivity_bound(purpose)
        return laplace(atom.aggregate(purpose), sens / self._eps_share(role))

    def expand(self, view, delta_eps):
        if self.eps_used + delta_eps > self.eps_total:
            return view                    # 预算不可透支
        self.eps_used += delta_eps
        return view.add_dp_aggregates(delta_eps)
```

```python
class VerifiableReproductionProof:
    def __init__(self, max_queries=8, grid_bits=16):
        self.max_queries = max_queries
        self.grid = make_public_grid(bits=grid_bits)
        self.queries_used = 0
```

```python
    if V.U < M.emd.u_min and M.budget.B_priv.remaining() > 0:
        V = M.emd.expand(V, M.budget.B_priv.suggest_delta())

    C = M.rec.build(E.trace, V)
    claim = M.current_claim
    valid, level = True, 'no_baseline'
    if claim.about_baseline:
        valid, level = M.brc.validate(
            C, M.baseline_capsule, claim, M.invariants,
            M.tau_drift, M.l_req)
        if not valid:
            claim = claim.downgrade(level)

    pi = M.vrp.prove(C, claim.value, C.tau)
    ok = M.vrp.verify(pi, C.digest, claim.value, C.tau)

    h = M.dpr.append(C.digest, commit(claim.value), pi.digest,
                     V.L, V.hash)
    M.budget.B_priv.consume(V.L)
    M.budget.B_repro.consume(replay_cost(C))

    if M.budget.B_priv.exhausted() and M.budget.B_repro.exhausted():
        M.policy = 'local_only'
    elif M.budget.B_priv.exhausted():
        M.policy = 'commitment_only'
    elif M.budget.B_repro.exhausted():
        M.policy = 'claim_quarantine'
    return V, C, pi, ok, valid, level, h, M.policy
```

### IP-167 PCE++++++（六维预算与双债务）

```python
class SixBudget:
    def __init__(self, scene, intent, ros, exec_budget, priv, repro):
        self.B_scene, self.B_intent = scene, intent
        self.B_ros, self.B_exec = ros, exec_budget
        self.B_priv, self.B_repro = priv, repro

    def release_policy(self):
        p, r = self.B_priv.exhausted(), self.B_repro.exhausted()
        if p and r:
            return 'local_only'
        if p:
            return 'commitment_only'
        return 'normal'

    def claim_policy(self):
        return 'claim_quarantine' if self.B_repro.exhausted() else 'normal'

    def debts(self):
        return {'privacy': self.B_priv.used / self.B_priv.total,
                'repro': self.B_repro.unverified_claims
                         / max(1, self.B_repro.total_claims)}

def cost_priv(view):
    return (0.5 * view.epsilon + 0.1 * view.bandwidth
            + 0.02 * view.vault_mb)

def cost_repro(capsule):
    return (0.3 * capsule.replay_seconds + 0.05 * capsule.size_mb
            + 0.1 * capsule.anchor_rate)

def voi_pr(pi, M):
    return (M.voi_meta_pessimistic(pi) - M.cost_cog(pi)
            - M.cost_exec(pi) - cost_priv(pi.view)
            - cost_repro(pi.capsule))
```

### IP-168 DPR（隐私-复现双源账本）

```python
class DualProvenanceRecord:
    def __init__(self, genesis, epsilon_total):
        self.chain = [sha256(genesis)]
        self.pending = []
        self.eps_cum = 0.0
        self.eps_total = epsilon_total
        self.revoked = set()

    def append(self, capsule, metric_commit, proof_digest,
               epsilon, view_hash):
        if epsilon < 0 or self.eps_cum + epsilon > self.eps_total:
            raise PrivacyBudgetViolation
        h = sha256(self.chain[-1] + encode(capsule.digest)
                   + metric_commit + proof_digest
                   + encode(epsilon) + view_hash + encode(now()))
        self.chain.append(h)
        self.pending.append(h)
        self.eps_cum += epsilon
        return h

    def anchor(self, external_store):
        root = merkle_root(self.pending)
        external_store.append(root)         # 只追加
        self.pending = []
        return root

    def revoke(self, capsule_digest):
        self.revoked.add(capsule_digest)
        return self.append_revocation(capsule_digest)

    def verify(self, i, proof, anchor_root):
        if self.chain[i] in self.revoked:
            return 'revoked'
        return merkle_verify(self.chain[i], proof, anchor_root)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| EMD | O(\|E\|·\|A\|) / 发布；DP 聚合 O(n) | O(\|E\|+\|vault\|) | L≤ε_p，U≥u_min |
| REC | O(\|T_trace\|) 构建；重放 O(成本) | O(capsule) | D_exact/D_seed 下 E=0 |
| PRF | O(\|V\|·\|C\| log) | O(frontier) | 重算区受 DP 下界 |
| BRC | O(K·replay) | O(2 capsules) | 结论需双复现+环境匹配 |
| VRP | 证明 O(\|C\|)；验证 O(1) | O(proof) | 可靠性+零知识+查询预算 |
| PRCL | O(闭环) | 复用 | 原始 P2/P3 不出本地；ε 单调 |
| PCE++++++ | O(1) | O(1) | 耗尽只收紧可发布性 |
| DPR | O(1) 追加；O(log N) 证明 | O(N) | 防篡改+ε 不可回滚+可吊销 |

**正确性定理（PRC）** 假设 A66–A72 成立（承诺 hiding/binding、ZK 可靠且零知识、DP 校准、胶囊在声明等级内确定、环境不变量覆盖混杂、攻击者模型包含真实攻击者、锚定只追加、ε 计数器不可伪造），则：
1. **隐私性**：Adm(π) ⇒ L(π)≤ε_p；P1 发布 (ε,δ)-DP；P2/P3 除承诺/谓词外不泄露原值。
2. **复现性**：D_exact/D_seed 胶囊摘要匹配时 E=0；D_stat 胶囊重放落在声明置信区间。
3. **主张有效性**：Valid ⇒ 基线与候选均复现、环境匹配、漂移受限、保真度达标、配对 CI 支持；「提升」非环境漂移或弱基线伪影。
4. **基线降级不可绕过**：L_b<L_req ⇒ 只能声称「相对重实现」；D_b>τ_drift ⇒ 必须用重复现基线。
5. **无免费复现**：精确独立重算敏感原始轨迹 ⇒ L 无界；有限 ε 下只能验证承诺，不能重算原文。
6. **预算安全**：B_priv 耗尽 ⇒ commitment_only；B_repro 耗尽 ⇒ claim_quarantine；不存在「未复现却已发布」且 ε 透支的主张。

**四种复现制度**：

| 复现方式 | 发布内容 | 隐私损失 | 复现误差 | 适用场景 |
|---|---|---|---|---|
| 逐位重放 | 原始 trace + raw | 高（通常无界） | 0 | 本地/TEE |
| 同种子重放 | 决策轨迹 + 承诺 | 低–中 | 0（声明等级内） | 团队内部 |
| 统计重放 | DP 聚合 | ≤ε | Ω(1/(ε√n)) | 跨机构 |
| 验证 | 承诺 + VRP | ≈0 | 0（对已声称指标） | 公开审计 |

**基线复现阶梯**：

| 等级 | 含义 | 可支持的结论 |
|---|---|---|
| L0 | 原作者制品/官方胶囊重放 | 可声称「优于原基线」 |
| L1 | 从论文独立重实现并通过探针 | 可声称「优于原基线（独立重实现）」 |
| L2 | 参数对齐但实现自写 | 只能声称「优于我们的重实现」 |
| L3 | 环境迁移近似 | 只能声称「在近似环境下」 |

**差异化对照**（「结构上做不到」而非「做得差一点」）：

| 方案 | 隐私 | 可复现 | 基线可证 | 外部可验证 | 结论 |
|---|---|---|---|---|---|
| B1 原始日志 + 事后脱敏 | 低 | 高 | 弱 | 低 | 脱敏后不可复现 |
| B2 仅 DP 遥测 | 高 | 低（分布级） | 弱 | 中 | 无法精确复现决策 |
| B3 中心化 TEE | 中 | 高 | 中 | 低（信任厂商） | 信任根外移 |
| B4 无胶囊复现 | — | 低 | 弱 | 低 | 自证、不可审计 |
| 本轮 PREC | 高（可调 ε） | 高（决策级） | **强（契约）** | **高（VRP+DPR）** | 隐私/复现/基线三轴同时可证 |

## 5. 本轮最大风险

**一句话**：最大风险是「可复现的伪影」——VRP 只证明声称值与承诺轨迹一致，而承诺又隐藏原始数据；若胶囊的指标脚本、环境清单、基线探针与重实现都由同一方设计，系统就能同时做到「完美隐私」和「完美复现」，却稳定复现一个错误结论，使隐私与复现双双退化为自证，而「优于基线」可能只是优于一个被削弱的 L2 重实现。
