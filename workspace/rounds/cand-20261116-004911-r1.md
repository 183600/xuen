# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「Isaac Sim」×「技能组合」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**双生标定 + 契约化技能代数 + 仿真接地组合**。两个灵感正对 v9 的两种债：**标定债**（β 是拍定的标量，且误差随块长复合放大，恰在 Δ_dom 最大处最不可信）与**结构债**（"技能"仍隐式埋在策略里，未成为可组合、可类型检查、可推理的一等对象）。必须保证新层任一失效即注入中立元、逐位等价退回 v9 ACMD（引理 92）。

## 0. 直觉与动机

**灵感 1（Isaac Sim → 数字孪生证书标定，TC）**
直觉：v9 把安全性压在"信任域内 ‖F̂−F‖∞ ≤ β"这一句假设上，而 β 是**拍定的标量**、靠一次性实验标定。两个隐患：(a) 模型误差沿 K 步复合放大（Lipschitz 动力学下约 (L^K−1)/(L−1)），单个标量对 K=10 极可能低估；(b) 域偏移越大模型误差越大，恰是 v9 自己承认的最大风险。Isaac Sim 的价值不止"仿真"，而是**可并行、可重放、可随机化的数字孪生**——它能在 GPU 上一次跑数千个域随机化环境，把"模型误差 × 域特征 × 块长"的经验曲面**扫出来**。核心创新：**双生标定器（TwinCert, TC）**：用并行数字孪生 + 分裂共形预测给出**状态相关、深度相关**的 β(Δ_dom, K) 及其有限样本覆盖下界；再用**残差影子监视器**在线检验"同分布交换性"是否仍成立。这把 v9 的"假设"升级为**可证伪、可监控的证书包络**——β 不再是一个信念，而是一个带覆盖保证的预测区间。

**灵感 2（技能组合 → 契约化技能代数，SA）**
直觉：v9 的分块证书把"一个块"做成了安全单元，但技能（导航、抓取、放置、交接、询问）仍是策略内部的黑盒，组合靠人编排。技能组合的严谨版本不是行为树工程，而是**类型论**：技能是带前后条件与证书的**态射** s: (X, pre) → (Y, post, cert)，只有当 post_{s1} ⊨ pre_{s2}（后条件蕴含后继前条件）且资源 frame 不冲突时，s2∘s1 才**良型**。核心创新：**契约化技能代数（SkillAlgebra, SA）**：顺序 ∘、并行 ⊗、选择 ⊕、恒等 id、以及与 v9 中立元同源的 abort a^⊥；组合证书由**区间算术 + 误差预算账本**导出，而非重新端到端仿真。于是"组合安全性"从"测出来"变成"类型检查出来"——局部证书 + 良型 ⇒ 复合证书（引理 88）。这把 v9 的契约中间件从"模块接线"提升到"任务结构"。

**灵感 2′（融合 → 仿真接地组合搜索，SGC）**
直觉：有了数字孪生和技能代数，就能把"下一步做什么"从单块选择升级为**组合搜索**：在 Isaac Sim 里批量展开类型合法的候选组合 DAG，用证书余量剪枝，只把"仿真中证书 margin ≥ ξ"的组合提交到现实。v9 的 5Hz 块节拍天然适合这种摊销搜索。核心创新：**仿真接地组合器（SimGroundedComposer, SGC）**。其安全性完全依赖 sim-real gap 有界——这也是本轮最大风险。与 v9 的关键区别是：v9 的风险是"被动滞后"，v10 的风险是"优化器主动挑选仿真漏洞"。

## 1. 研究问题（轮次升级版）

- **Q1（β 的可证伪化）**：如何用数字孪生标定出带有限样本覆盖保证的 β(Δ_dom, K)，并使在线残差监视在交换性破裂时及时失效？共形覆盖的"可交换"前提在 sim→real 迁移中如何被检测而非被假定？
- **Q2（组合的安全可推理性）**：什么样的技能代数、类型规则与误差预算，能使复合证书的保守性成为定理而非经验？frame 条件能否用资源分离（separation）式论证消除并行组合的干扰？
- **Q3（搜索的 sim-real 可信性）**：在 sim-real gap 未界定下，仿真接地搜索在何种条件下保证提交组合在现实中安全？如何检测、限制并形式化"仿真利用（sim exploit）"？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 双生标定律（Twin-Certified Bound, TC）**
β 不是常量而是状态-深度函数 β(Δ_dom, K)，由 Isaac Sim 并行域随机化的**分裂共形分位数**给出：在给定 bin 与深度层内，若残差可交换，则 P(r ≤ β(Δ,K)) ≥ 1−α。误差复合用 Lipschitz 上界 β(K)=β₁·(L^K−1)/(L−1)（L≠1）。在线残差影子监视以 CUSUM + 共形 p 值 + α-spending 检验交换性，破裂即 trust_broken，强制 K_eff←1。

**P14 契约化技能组合律（Contractual Skill Algebra, SA）**
技能 = ⟨π, pre, post, κ, Cert⟩。组合良型当且仅当：(i) 顺序满足 post_{s1} ⊨ pre_{s2}（在可判定的状态谓词片段内）；(ii) 并行满足资源不相交 Res(s1)∩Res(s2)=∅（frame 条件）；(iii) 误差预算 β(comp) ≤ β_budget。良型 ⇒ 复合证书可推导；非良型 ⇒ 拒绝并注入 abort a^⊥（中立元），退回原子技能。

**P15 仿真接地组合律（Sim-Grounded Composition, SGC）**
提交现实执行的组合必须同时满足：良型 ∧ 仿真证书 margin ≥ ξ ∧ sim-real gap 监视未报警 ∧ TC 未报警。任一不满足 ⇒ 退回 v9 原子块决策。搜索在任意时预算下可中断（anytime），返回当前最优**已证**组合或 None，绝不返回未证组合。

## 3. 与 v9 的接口（如何退化）

- SGC 失效/超时/仿真不可用 ⇒ 不搜组合，退化为 v9 原子块（≡ v9 ACMD）；
- SA 组合非良型/预算耗尽 ⇒ 仅执行单原子技能（≡ v9 动作块）；
- TC trust_broken 或标定不可得 ⇒ β←β₀（保守标量）、K_eff←1（≡ v9 最保守模式）；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 五级链降级至 v8/v7/v6；
- 全部失效 ⇒ 完整退回 v9 ACMD → v8 DA-SPR-Cal → v7。

## 4. 预期贡献

1. **可证伪的证书标定**：数字孪生并行域随机化 + 分裂共形预测，把 v9 的 β 假设变成带有限样本覆盖保证的状态-深度函数，并以在线影子监视防止分布漂移下的"虚假安全"；
2. **契约化技能代数**：技能组合的类型规则、误差预算与 frame 条件，使复合安全性局部可推（引理 88），将"组合正确性"从端到端测试变为代数性质；
3. **仿真接地组合搜索**：GPU 并行数字孪生 + 证书余量剪枝的 anytime 组合规划，给出 sim-real gap 有界时的安全性定理与 gap 无界时的显式不可证边界（引理 91）；
4. **v10 契约化七级退化格**：新层全为可选增强，任一失效逐位退化为 v9（引理 92）；E571–E590 覆盖覆盖度、影子监视、sim-real gap、组合等价、预算耗尽、对抗 sim-exploit 与端到端任务。

## 5. 本轮最大风险

**一句话**：仿真接地组合搜索会**主动优化出恰好利用 Isaac Sim 与真实世界差异（sim-to-real gap）的组合**——证书在仿真中成立、在现实中系统性失效；与 v9 的"滑窗滞后"风险不同，这里的失败是被优化器**挑选**出来的，因而更难被随机探索或统计数据发现。

## 1. 符号体系增量（定义 540–549）

**新增定义 540（技能原子 SkillAtom）** 技能 s = ⟨π_s, pre_s, post_s, κ_s, Cert_s, Res_s⟩：π_s 为状态→动作块生成器（内部由 IP-354 AC 生成 K_s 步），pre_s/post_s 为状态谓词（限定在区间/线性算术可判定片段），κ_s 为 v9 中间件契约（定义 535）的技能级 refinement，Cert_s 为块证书模式（定义 533 升级为区间包络），Res_s 为占用的资源/对象集（用于 frame 条件）。

**新增定义 541（组合算子与良型 Composition）**
- 顺序 s₂∘s₁：良型 ⟺ post_{s₁} ⊨ pre_{s₂} ∧ frame_ok(s₁,s₂) ∧ β(s₂∘s₁) ≤ β_budget；
- 并行 s₁⊗s₂：良型 ⟺ Res(s₁)∩Res(s₂)=∅ ∧ pre 可合取 ∧ 两证书包络无冲突；
- 选择 s₁⊕s₂：良型 ⟺ pre_{s₁}∨pre_{s₂} 覆盖当前 pre ∧ post 可上并；
- 恒等 id：pre=post=⊤，π 为空；中止 a^⊥：吸收元 s∘a^⊥ = a^⊥∘s = a^⊥（对应 v9 的安全停驻 a^⊥）。
良型性是**部分**运算（非全定义），安全性 = 良型 ∧ 各原子证书成立。

**新增定义 542（误差预算账本 ErrorBudgetLedger）** 每技能携带 β_s（其块证书的模型误差界）。组合预算：
```
β(s₂∘s₁) = β_{s₁} + β_{s₂} + β_cpl(post_{s₁})     # 耦合项由 post 区间宽度 × L 导出
β(s₁⊗s₂) = max(β_{s₁}, β_{s₂})                      # 资源不相交时无耦合
```
复合深度 n 的 Lipschitz 上界 β(n) = ε·(Lⁿ−1)/(L−1)，其中 ε 为单步误差界。账本拒绝 β(comp) > β_budget(t) 的组合——这是 v9 单标量 β 无法表达的关键约束。

**新增定义 543（双生标定界 TwinCalibratedBound）** 标定集 {(Δ_i, K_i, r_i)} 来自 Isaac Sim 并行 rollout，r_i 为模型残差（相对或绝对）。对每个域 bin b 与深度层 K 取分裂共形分位数：
```
β(b,K) = Quantile_{⌈(N_bK+1)(1−α)⌉}({ r_i : bin(Δ_i)=b, K_i=K })
```
在 bin 内可交换前提下 P(r_new ≤ β(b,K)) ≥ 1−α。跨 bin 用保序插值；样本不足的 bin 回退到全局分位数并标记 low-confidence（触发保守 K_eff 收缩）。深度方向以定义 542 的 Lipschitz 上界包络兜底，防止分层样本稀疏导致低估。

**新增定义 544（残差影子监视 ResidualShadowMonitor）** 执行后可获得真实度量 y_t 与前向预测 ŷ_t 时，残差 r_t=|y_t−ŷ_t|（无真值时用下一帧观测回溯对齐）。定义：
```
S_t = max(0, S_{t−1} + r_t − k)                     # CUSUM，k 为容忍漂移
p_t = (1 + #{i : r_i ≥ r_t}) / (N + 1)             # 共形 p 值
trust_broken ⟺ (S_t > h) ∨ (p_t < α_t)             # α_t 按 α-spending 递减
```
采用 α-spending（如 α_t = α·6/(π²t²)）使任意时刻误报率 ≤ α，避免逐点检验的累积误报。触发原因、S_t、p_t 全量落审计日志（E572 复核）。

**新增定义 545（技能证书与组合证书 SkillCertificate）** Cert_s = (β_s, envelope_s, margin_s)。envelope_s 为指标区间 [g_min, e_max]（升级 v9 点估计）。组合证书：
```
envelope(s₂∘s₁) = propagate(envelope_{s₁}, envelope_{s₂})    # 区间算术/单调传播
margin(comp)    = min_i margin_{s_i} − β_cpl
```
良型 ∧ margin(comp) ≥ 0 ⇒ 复合证书成立。技能契约 κ_s 相对模块契约的 refinement：κ_skill 的 deadline/WCET 是其组成模块契约的聚合上界。

**新增定义 546（组合候选与搜索树 CompositionCandidate）** 以当前状态 s 与目标 g 为根，从技能库按深度 d、分支 b 枚举良型组合，节点携带类型、证书、仿真 rollout 结果。剪枝规则：非良型、margin<ξ、误差预算耗尽、仿真不可用。候选为 DAG 而非树（允许多父共享子技能，命中组合缓存）。

**新增定义 547（仿真接地分数 SimGroundedScore）** 
```
J(C) = Progress_sim(C) − λ_s·SafetyPenalty_sim(C) − λ_c·ComputeCost(C) − λ_g·GapRisk(C)
```
仅保留良型且 margin_sim(C) ≥ ξ 的候选参与排序；GapRisk(C) 由 C 所用技能的历史 sim-real 残差回归给出（高 gap 技能降权）。

**新增定义 548（组合提交证书 CommittedCertificate）** 提交现实当且仅当：
```
well_typed(C) ∧ margin_sim(C) ≥ ξ ∧ ¬trust_broken ∧ ¬gap_alarm ∧ δ_gap(C) ≤ ξ − margin_sim(C)^−
```
其中 gap_alarm 由影子监视对组合关键指标的漂移触发。δ_gap 定义为组合所用技能集上 |J_real−J_sim| 与 |safety_real−safety_sim| 的最大值。任一不满足 ⇒ 返回 None，触发 Level-0 退化。

**新增定义 549（中立元与 v10 退化格 NeutralElements）** TC: v^⊥ = (β₀ 标量, trust-off) ⇒ Level-2；SA: v^⊥ = 原子技能（组合层"缺席"）⇒ Level-1；SGC: v^⊥ = None（不搜索）⇒ Level-0；ID/AC/MW 沿用 v9 定义 536。逐级映射保证任一失效不引入新的可观测行为。

## 2. 形式化定义（要点与升级）

- **升级定义 533（块证书）** β 由标量替换为 β(Δ_dom,K)；证书有效条件增补 `β(Δ,K) ≤ β_budget` 与 `¬trust_broken`。
- **升级定义 534（中止点）** 不变；组合层的中止优先使用 a^⊥（技能级）后再回落到块级 p*。
- **升级定义 535（中间件契约）** 新增技能级契约表，κ_skill 为组成模块契约的 refinement；MW 仍以中立元注入实现超时降级。
- **升级定义 539（有效块长）** K_eff 进一步受误差预算约束：K_eff = max{ K : β(Δ,K) ≤ β_budget(t) }，再与信任域门控取 min。
- **升级定义 496/531（软证书/软硬衔接）** δ_trigger 增补 `¬trust_broken ∧ gap_ok ∧ Cert_composite valid`；组合不成立即触发 M₀ 硬检查或原子块回退。

## 3. 关键算法骨架

```python
# IP-357 TwinCert：数字孪生证书标定器
class TwinCert:
    def __init__(self, isaac, forward_model, alpha=0.05, n_envs=4096,
                 bins=8, L=1.2, eps0=0.02):
        self.sim, self.F = isaac, forward_model
        self.alpha, self.n_envs, self.bins = alpha, n_envs, bins
        self.L, self.eps0 = L, eps0
        self.q = {}                      # (bin, K) -> conformal quantile
        self.cusum, self.alpha_spent, self.t = 0.0, 0.0, 0

    def calibrate(self, domain_grid):
        residuals = defaultdict(list)
        for theta in sample_domains(domain_grid, self.n_envs):   # GPU 批量域随机化
            for s, a in self.sim.rollout(theta):
                r = abs(self.F.predict(s, a) - self.sim.truth(s, a))
                residuals[(self.bin(theta), len(a))].append(r)
        for key, rs in residuals.items():
            self.q[key] = conformal_quantile(rs, self.alpha)     # 定义 543

    def beta(self, delta_dom, K):
        b = self.bin(delta_dom)
        base = self.q.get((b, K))
        if base is None:                                         # 样本不足 → 保守兜底
            base = max(self.q.values())
            return base * (self.L**K - 1) / (self.L - 1)          # 定义 542/543
        return base

    def observe(self, predicted, observed):
        r = abs(predicted - observed)
        self.t += 1
        self.cusum = max(0.0, self.cusum + r - self.k)
        a_t = self.alpha * 6.0 / (math.pi**2 * self.t**2)        # α-spending
        p_t = self.conformal_pvalue(r)                           # 定义 544
        if self.cusum > self.h or p_t < a_t:
            return 'trust_broken'
        return 'ok'


# IP-358 SkillAlgebra：契约化技能代数
@dataclass
class Skill:
    name: str; pre: Pred; post: Pred; policy: Callable
    contract: Contract; cert: CertSchema; resources: frozenset; beta: float

def compose_seq(s1: Skill, s2: Skill, budget: float) -> Skill:
    if not entails(s1.post, s2.pre):                 # 良型条件 (i)
        return None
    if not frame_ok(s1, s2):                         # frame/不变式 (ii)
        return None
    beta = s1.beta + s2.beta + coupling(s1.post, s2.pre)
    if beta > budget:                                # 误差预算 (iii)
        return None
    return Skill(
        name=f"{s2.name}∘{s1.name}", pre=s1.pre, post=s2.post,
        policy=lambda st: s2.policy(s1.policy(st)),
        contract=merge_contracts(s1.contract, s2.contract),
        cert=chain_certs(s1.cert, s2.cert, beta),   # 定义 545 区间传播
        resources=s1.resources | s2.resources, beta=beta,
    )

def compose_par(s1: Skill, s2: Skill) -> Skill:
    if s1.resources & s2.resources:                  # 资源不相交
        return None
    return Skill(..., beta=max(s1.beta, s2.beta))     # 无耦合项

def compose_choice(s1: Skill, s2: Skill) -> Skill:
    return Skill(..., pre=Or(s1.pre, s2.pre), post=join(s1.post, s2.post),
                 beta=max(s1.beta, s2.beta))


# IP-359 SimGroundedComposer：仿真接地组合搜索器
class SimGroundedComposer:
    def __init__(self, isaac, skills, depth=3, branch=4,
                 budget_ms=120, xi=0.0, price_gap=True):
        self.sim, self.skills = isaac, skills
        self.depth, self.branch, self.budget_ms = depth, branch, budget_ms
        self.xi, self.price_gap = xi, price_gap
        self.cache = {}                                # 组合子表达式缓存

    def propose(self, state, goal):
        # 从技能库枚举类型合法的候选组合（定义 546），命中缓存的子树直接复用
        return enumerate_typed_compositions(
            self.skills, state, goal, self.depth, self.branch, self.cache)

    def search(self, state, goal, deadline):
        cands = self.propose(state, goal)
        best = None
        for batch in chunks(cands, self.sim.max_batch):           # GPU 批量 rollout
            if now() > deadline:                                  # anytime 中断
                break
            results = self.sim.batched_rollout(state, batch)      # 并行仿真
            for C, r in zip(batch, results):
                if r.cert_margin < self.xi:                       # 证书余量门槛
                    continue
                gap_pen = self.gap_regressor(C) if self.price_gap else 0.0
                J = (r.progress - self.lam_s * r.safety_penalty
                     - self.lam_c * C.cost - self.lam_g * gap_pen)
                if best is None or J > best.J:
                    best = Scored(C, J, r)
        return best.composite if best else None                   # None → Level-0
```

## 4. 推导

**引理 87（误差沿块长复合界）** 设单步模型误差 ‖F̂−F‖ ≤ ε、真实动力学 F 为 L-Lipschitz。则 K 步状态误差 e_K ≤ ε·(L^K−1)/(L−1)（L≠1），L=1 时 ≤ εK。证明：e_{k+1} = ‖(F̂−F)(x_k) + (F(x̂_k)−F(x_k))‖ ≤ ε + L·e_k，递推 e_K ≤ ε Σ_{i=0}^{K−1}L^i。∎ **推论**：v9 的标量 β 对 K=10 必须至少覆盖该上界，否则块证书非保守；这正是 β(Δ,K) 深度相关化的动机。

**引理 88（组合安全性与证书链）** 若 s₁,s₂ 的证书在各自 pre 域成立，且 s₂∘s₁ 良型（post_{s₁}⊨pre_{s₂}、frame 成立、β_total≤β_budget），则由区间算术 chaining 得到的复合证书成立，执行 s₂∘s₁ 的安全性由局部证书 + 类型规则传递，无需端到端重仿真。证明：良型保证 s₂ 启动时其 pre 成立；区间传播对单调算子保保守性，故 envelope(comp) 覆盖真实轨迹；frame 条件保证 s₂ 不破坏 s₁ 维持的不变式；误差预算给出 β_total 上界，故 margin(comp)≥0 即证。∎

**引理 89（共形标定的有限样本覆盖）** 若标定残差与测试残差在给定 bin 与深度层内可交换，则定义 543 的 β(b,K) 满足 P(r_new ≤ β(b,K)) ≥ 1−α。证明：分裂共形预测（Vovk 等）取 ⌈(N+1)(1−α)⌉ 分位数，其覆盖概率 ≥1−α。∎ **注意**：覆盖是分 bin 的边际覆盖，非逐点条件覆盖；且**交换性是 sim→real 的可证边界**——不成立时覆盖失效，由影子监视兜底（引理 90）。

**引理 90（影子监视的 anytime 有效性）** 采用定义 544 的共形 p 值与 α-spending，则任意时刻误报率 ≤ α；在容许漂移 k 下，CUSUM 对均值阶跃 μ>k 的期望检测时延 ≤ h/(μ−k)。证明：H0 下 p_t 超均匀，α-spending 使并集界 Σα_t ≤ α；CUSUM 为经典累积和结论。∎ 不用 α-spending 时逐点 α 会随测试次数累积误报，v10 显式避免。

**引理 91（仿真接地提交的充分条件）** 设提交组合 C 的关键指标在 sim-real 间偏差 ≤ δ_gap，且 margin_sim(C) ≥ ξ ≥ δ_gap。则 C 在现实中的证书 margin_real(C) ≥ margin_sim(C) − δ_gap ≥ 0，即定义 548 的门槛足以保证现实证书成立。证明：margin_real ≥ margin_sim − |margin_real−margin_sim| ≥ margin_sim − δ_gap。∎ **反面（不可证边界）**：若 δ_gap 无界，SGC 可选出 margin_sim 高而 margin_real 为负的组合——仿真接地搜索**不提供无条件保证**。这界定了 v10 的诚实边界。

**引理 92（v10→v9 逐位退化）** 对每个新模块注入中立元：SGC→None（不搜索）、SA→原子技能、TC→(β₀, trust-off)；三者分别等价 v9 的无组合、动作块、最保守模式，且 v9 内部退化链（AC→MW→ID→DA/SPR/Cal）不变。故可观测日志与决策序列同 v9 对应级逐位一致。∎

**引理 93（anytime 搜索单调性）** SGC 在预算递增下维护 best-so-far；剪枝只删非良型、margin<ξ 或超预算节点，故分数单调不降；中断时返回已证组合或 None，绝不返回未证组合。∎
