# 第 3 轮迭代（灵感循环 v3 · 第 1 轮：「任务规划」×「状态机」）——把"打比赛"重写为**可撤销进度图上的有限期最优控制**

> 承接 v2 的硬事实（计分点、`human_*` 反向撤回、开环动作块、单模型合规），但换一个更底层的视角：**计分点 = 状态机的状态，人类干扰 = 回退边，`action_chunk_size` = 观测采样周期**。本轮不新增"更多模块"，而是把已有想法**收敛成一个可分析、可证明、可离线求解的形式系统**。

## 0. 直觉解释（先讲人话）

- **任务规划**不是"每步都重新想一遍"，而是：把任务拆成**带权重的检查点**；在有限时间与有限"回头确认"次数下，决定"现在推进哪个检查点、什么时候回头核验、被推回了先救哪一段"。
- **状态机**不是流程图装饰，而是**带守卫的推进许可**：只有可观测证据满足条件，才允许把某检查点标记为完成；证据失效就回退。它同时是"计划"的**运行时载体**。
- 把两者合起来看：公开赛的 `scoring_points` 天生就是状态；`human_*` 里的"合上再打开／拉上再拉开／叠好再翻开／叠好再拿走"天生就是**撤销转移**。于是整场比赛 = 一个**状态数极小的有限期博弈**——小到可以**离线精确求解**，在线只查表。这是本轮最关键的"降维"。

## 1. 严谨定义（把直觉变成对象）

**定义 1（子目标与权重）** 任务 $\tau$ 的计分点是有序子目标集 $G=\{1,\dots,n\}$，权重 $w_i>0$，$\sum_i w_i=100$；本轮 32 任务满足 $n\in\{2,3,4,5\}$。

**定义 2（进度状态）** 进度向量 $p\in\{0,1\}^n$，$p_i=1$ 表示子目标 $i$ 当前已达成**且未被撤回**。合法状态集 $P\subseteq 2^G$ 对前驱关系 $\prec$ 闭合（若 $i\prec j$ 且 $p_j=1$，则 $p_i=1$）；计分点通常构成链，少数是浅 DAG。

**定义 3（推进与撤销）** 推进 $A_g(p)=p\cup\{g\}$（$g$ 的前驱已满足）；撤销算子 $R_u(p)=p\setminus\mathrm{clos}(u)$，$\mathrm{clos}(u)$ 为 $u$ 及其所有后继——一次"翻开／拉开／拿走"往往使后续步骤**一并失效**。

**定义 4（进度自动机 / Progress Automaton）** $\mathcal A=(P,G,\{A_g\},\{R_u\},p_0,F,W)$，$p_0=\varnothing$，$F=G$。任务层是层级状态机（HSM）的父状态；每个子目标内部再挂一个技能层 FSM（抓／插／折／拧）。

**定义 5（观测与见证）** 因接口开环，仅在动作块边界观测：$o_{t_k}$，$t_k=t_0+k,t_0+2k,\dots$。守卫是见证谓词 $\phi_g(o)\in\{0,1\}$；每步维护证书 $\kappa_g$（最后一次成立时的证据＋时刻）。**回退事件**：$\kappa_g$ 曾成立，而当前连续 $h$ 帧 $\phi_g=0$。

**定义 6（检测延迟）** 块长 $k$ 下，若撤销在块内均匀发生，检测延迟 $D\sim\mathrm{Unif}\{0,\dots,k-1\}$，$\mathbb E[D]=(k-1)/2$；块内撤销在到达边界前**完全不可见**。

**定义 7（目标）** 官方综合分聚合未公开（手册仍未取到），故保留双目标：$J_{\text{succ}}=\mathbb 1[p=G]$，$J_{\text{step}}=\sum_i w_i p_i$。规划采用**字典序／风险敏感**：先保已得前缀，再搏末步。

**命题 1（状态数）** $|P|\le 2^n\le 32$；若前驱是链，则 $|P|=n+1\le 6$。→ 精确规划在毫秒级。
**命题 2（规划-状态机对偶）** 任意有限期确定性规划 $\pi:P\times\{0..T\}\to G$ 都等价于一个状态数 ≤ $|P|(T+1)$ 的有限控制器；故"离线任务规划"的产物**就是**运行时状态机的转移表。
**命题 3（见证 sound 性）** 若所有守卫无误报，则报告进度恒 $\le$ 真实进度，步骤分永不被高估；代价是可能少报（保守）。→ 这把"验证器"从工程细节升级为**计分正确性的前提**。

- 合规：**单模型多任务**；外部大模型验证器可能被判"非单模型"。

## 3. 用两个新词重读 v2（哪些被吸收、哪些被淘汰）

- **被吸收进形式系统**：UIP-01′/09′（滚动验证／撤回重做）→ UIP-16 的守卫与回退转移；UIP-02′（计分安全网）→ UIP-17 的权重目标；UIP-13（自适应块长）→ UIP-18 的 VOI 调度；UIP-14（技能图）→ UIP-20 的层级技能状态机。
- **被降为"实例生成器"**：UIP-11 GSO / UIP-12 DRF 不再作主线，只负责为博弈生成**撤销样本**与**危害率 $q$ 的估计**（UIP-23 反事实回放）。
- **被淘汰／封存**：任何"再加一个模型"的想法（外部 VLM、独立世界模型）——本轮收益来自**把问题缩小到可精确求解**，而不是扩大模型。

## 4. 瓶颈假设（可检验）

- **H1**：在"计分点有序 + 可撤销"结构下，**离线精确规划**（≤32 状态）就显著优于贪心／脚本；收益主要来自"何时停下来核验"与"撤回后先救哪段"。
- **H2**：块长存在**内点最优**：太小被 RPC 延迟／可信度惩罚，太大则撤销检测延迟上升、丢失步骤分；一阶模型给出 $k^\*=\sqrt{2a/(q\,b\,L)}$（$a$=单次调用代价，$q$=撤销危害率，$L$=暴露权重，$b$=单位权重·步的重做代价）。
- **H3**：撤销不是随机噪声，而是**有结构的对手**；"检查点后加固（guard）"可主动降低对手撤销收益，规划器应把 guard 当作一个动作。
- **H4**：可靠性上限由**守卫误报率**决定；必须用校准（conformal）而非阈值拍脑袋，并正视 sim2real 对可交换性的破坏。

## 5. 本轮方法论：三个"降维"动作

1. **状态降维**：从连续视频／关节空间降到 ≤32 个符号进度状态——规划变成查表。
2. **对手降维**：把 `human_*` 文本编译成有限个撤销宏 $R_u$ 与危害率 $q_u$——对手变成可枚举的博弈者。
3. **时间降维**：只在块边界决策，块长 $k$ 是唯一实时旋钮——把实时性纳入目标函数而非事后优化。

## 6. 候选收敛 → v3 清单（详见产物区）

围绕"任务规划 × 状态机"发散后收敛为 8 个可落地项：**UIP-16 PROSE（旗舰）**、UIP-17 ADP-U、UIP-18 VOI-K、UIP-19 S2F、UIP-20 HSM-S、UIP-21 C2G、UIP-22 CAL-M、UIP-23 CFR。主线闭环：**S2F 编译 → ADP-U 离线求解 → PROSE 在线执行 → CFR 回放校准 → VOI-K／CAL-M 控风险**。

## 7. 本轮最大风险

**一句话**：形式系统的全部保证都建立在"守卫见证在真机上仍然 sound"之上；一旦视觉／接触噪声让守卫误报，规划器会在**自洽的错误状态**里精确地做错事，且 conformal 的覆盖率保证会因 sim2real 不满足可交换性而失效。

## 1. 形式化与命题（证明草图）

记 $G=\{1..n\}$，$w_i$，合法状态 $P\subseteq2^G$，$A_g(p)=p\cup\{g\}$，$R_u(p)=p\setminus\mathrm{clos}(u)$。

- **命题 1**：$|P|\le2^n\le32$；链式前驱时 $|P|=n+1$。*证*：$P$ 是 $2^G$ 的子集；链式下合法状态只能是最长已完成前缀。∎
- **命题 2（规划=状态机）**：确定性策略 $\pi(p,t)$ 只有 $|P|\times(T+1)$ 个输入，故可写成有限转移表；运行时按当前 $(\hat p,t)$ 查表，等价于一个有限控制器。∎
- **命题 3（sound 守卫安全）**：若 $\Pr[\phi_g=1\mid p_g=0]=0$，且只在 $\phi_g=1$ 时置位，则 $\hat p\le p$ 恒成立，$\sum w_i\hat p_i\le\sum w_i p_i$。*证*：置位仅发生在真完成时，撤销只减不增。∎
- **命题 4（检测延迟）**：仅块边界观测时，撤销在块内均匀发生 ⇒ $\mathbb E[D]=(k-1)/2$，且块内撤销此前不可见。∎

> 注意：命题 3 只保证"不高估"。少报会浪费重做预算，所以真正的工程目标是**在误报率 $\le\alpha$ 下最大化召回**（见 §5）。

## 2. 旗舰 UIP-16 · PROSE（Progress-State Machine Execution）

**两层结构**

1. **任务层（父状态机）**：状态=进度向量 $\hat p$；转移只在守卫成立时发生；额外维护 `recovering` 超级状态（任一证书失效即进入）。
2. **技能层（子状态机）**：每个子目标挂一条技能 FSM / 行为树，如 `grasp→transport→align→insert→release`；技能内部可有自己的守卫（接触、力矩、深度）。

**证书与回退**

- 每步完成时记录 $\kappa_g=(\text{证据摘要},\text{帧时间},\text{关系})$。
- 每个块边界重放证书谓词；若曾经成立、当前连续 $h$ 帧不成立 ⇒ 触发 $R_u$，清掉该步及其后继，进入 `recovering`。
- **前缀不变量**：若 $p_i=1$ 则其所有前驱证书仍有效；违反即强制回退到最深有效前缀。

**为什么它是"状态机"而不是"if-else"**：这些状态、守卫、回退边由 UIP-19 从赛题规格**编译**得到，并由 UIP-17 **离线求解**出转移策略，运行时只做查表 + 监控。

## 3. 核心 UIP-17 · ADP-U（Adversarial DP over Undo）

**决策模型（半马尔可夫 / SMDP）**：每次决策选择一个**宏动作**（推进某子目标 $g$）；宏动作有期望时长 $d_g$（由数据估计）与完成概率 $s_g$；随后环境按撤销宏 $u$（危害率 $q_u$，掩码 $m_u$）可能回退。

- 目标（风险敏感、保留双口径）：
  $$J(p)=\sum_i w_i p_i+\lambda\,\mathbb 1[p=G]$$
- 有限期 Bellman（随机对手）：
  $$V_{t}(p)=\max_{g\in\mathrm{En}(p)}\Big[(1-\textstyle\sum_u q_u)\,V_{t-d_g}(A_g(p))+\sum_u q_u\,V_{t-d_g}(R_u(A_g(p)))\Big]$$
- 鲁棒对手（预算 $B$ 次撤销）：把上式对 $u$ 取 $\min$，并在状态里加剩余预算 $b$，即 $V_t(p,b)$。
- 终值：$V_0(p)=J(p)$。

**复杂度**：$|P|\le32$，$T\le$ episode 长度／宏步长，动作 $n\le5$，撤销宏 $|U|\lesssim 10$ ⇒ 精确 DP 在毫秒~秒级；**比训练任何策略都便宜**。

**关键产出**：策略表 $\pi^\*(p,t)\to g$ 或 $\pi^\*(p,b)\to g$。这张表**就是** UIP-16 任务层的转移表（命题 2）。

```python
def solve_undo_game(n, w, prereq, undos, T, lam=1.0, robust=False, budget=None):
    states = valid_states(n, prereq)                 # <= 32
    V = {p: sum(w[i] for i in bits(p)) + lam * (p == full(n)) for p in states}
    policy = {}
    for t in range(1, T + 1):
        Vn = {}
        for p in states:
            best, arg = -1e18, None
            for g in enabled(p, prereq):             # 只推进"前驱已满足"的子目标
                p1 = p | (1 << g)
                if robust:
                    val = min(V[apply_undo(p1, u.mask)] for u in undos if u.q > 0)
                else:
                    val = (1 - sum(u.q for u in undos)) * V[p1]
                    val += sum(u.q * V[apply_undo(p1, u.mask)] for u in undos)
                val -= cost(g)                       # 时长/延迟惩罚
                if val > best:
                    best, arg = val, g
            Vn[p], policy[(p, t)] = best, arg
        V = Vn
    return policy, V
```

> 说明：`enabled` 过滤前驱；`apply_undo` 清掉 $u$ 及其后继；`cost(g)` 可含 UIP-18 的期望延迟。实际实现用字典/位掩码，缓存 `valid_states`。

## 5. 支撑 UIP-18 · VOI-K（块长的内点最优）

**一阶代价模型**（$T$=episode 环境步数）：

- RPC/决策开销：$C_{\text{rpc}}(k)=a\,T/k$（$a$=单次调用代价）。
- 撤销后重做损失：每 episode 撤销事件率约 $q$，每次平均检测延迟 $(k-1)/2$，单位"权重·步"代价 $bL$，于是 $C_{\text{delay}}(k)\approx qT\,bL\,(k-1)/2$。

$$C(k)=a\frac{T}{k}+qT\,bL\,\frac{k-1}{2}+c\;\Rightarrow\;k^\*=\sqrt{\frac{2a}{q\,b\,L}}$$

**读法**：暴露权重 $L$ 越大（末步／难步）、撤销危害 $q$ 越高 ⇒ 块越短（多看几眼）；单次调用越贵 $a$ ⇒ 块越长。$T$ 在最优处抵消，说明 $k^\*$ 是**任务结构量**，可离线标定。落地时用 `metadata` 的全局最大 $K_{\max}$，每次返回 $\le K_{\max}$ 的块。

```python
def choose_k(p, g, sm, a, b):
    q = sm.undo_hazard[g]
    L = sm.weight[g] + sm.downstream_weight(p, g)   # 暴露权重
    return clamp(int((2*a / max(q*b*L, 1e-6)) ** 0.5), 1, sm.K_MAX)
```

## 6. 支撑 UIP-22 · CAL-M（校准式守卫）

对每个守卫 $g$，用 UIP-23 回放得到带标注样本 $(\text{证据}, g\text{ 是否真完成})$。令非一致性分数为 $-s(o,g)$，取负类（未完成）分位数：

$$\tau_{g,\alpha}=\mathrm{Quantile}_{1-\alpha}\{\,s(o,g)\mid \neg\text{done}_g\,\},\qquad \text{advance}\iff s(o,g)\ge\tau_{g,\alpha}$$

在可交换假设下，$\Pr[\text{advance}\mid\neg\text{done}_g]\le\alpha$，直接服务命题 3。**必须按任务/相机分别校准**（组条件覆盖），并对 sim2real 漂移做在线温度缩放/回归校准；漂移严重时回退到更保守的固定阈值。

## 7. 支撑 UIP-20 HSM-S / UIP-21 C2G / UIP-23 CFR

- **UIP-20 HSM-S**：任务层每个子目标挂技能 FSM（`grasp→transport→align→insert→release`），技能层守卫用接触/深度/力矩；失败在技能层重试，不污染任务层。
- **UIP-21 C2G**：把"加固"建模为额外动作 `guard(g)`：代价是时间，收益是把该步撤销危害 $q_g$ 降到 $q_g'$。规划器比较 $\Delta J$ 与代价后决定是否加固（例：T16 折完压边、T17 合盖后压实、T19 拉链拉到端）。
- **UIP-23 CFR**：在公开 32 数据集上离线回放：① 每帧跑守卫，统计每步 precision/recall；② 注入/检索 `human_*` 撤销，估计 $q_u$；③ 用真实 episode 校验 FSM 转移覆盖与死锁。它是 UIP-17/22 的数据来源，也是不做昂贵 Gazebo 的轻量替身。

## 8. 运行时伪代码（UIP-16 + 17 + 18 + 21 + 22）

```python
class PROSE:
    def __init__(self, sm, policy, monitors, skills, voi):
        self.sm, self.policy, self.mon, self.skill, self.voi = sm, policy, monitors, skills, voi

    def reset(self, obs):
        self.p = 0            # 进度位掩码
        self.cert = {}        # g -> 证书
        self.t = 0

    def get_action(self, obs, T):
        self.t += 1
        # 1) 证书刷新：检测"静默撤回"
        for g in achieved(self.p):
            if not self.cert[g].holds(obs):
                self._invalidate(g)                 # p 清掉 g 及后继，进入 recovering
        if self.p == self.sm.full:
            return self.skill["finish"].act(obs, k=1)
        # 2) 任务层规划：查离线策略表
        g = self.policy[(self.p, min(self.t, T))]
        # 3) 是否先加固（C2G）
        if self.sm.should_guard(self.p, g):
            return self.skill["guard"](obs, g)
        # 4) 门控推进（CAL-M）
        if self.mon[g].advance(obs):
            self.p |= 1 << g
            self.cert[g] = Certificate(obs)
        # 5) 用 VOI 选块长执行技能
        k = self.voi.choose(self.p, g, obs)
        return self.skill[g].act(obs, k)

    def _invalidate(self, g):
        self.p &= ~self.sm.closure_mask(g)          # 回退该步及其后继
        self.cert.pop(g, None)
```

> 形状红线：块仍按 `(T_a, …)` 返回、索引 0 先执行、`dtype/token` 严格按 README §3；`k` 不得超过握手声明的 `action_chunk_size`。

## 10. 合规与风险

- **单模型**：守卫用规则/几何谓词或主骨干内部小头；规划器是离线表格；**不引入外部 VLM**。
- **形式保证的边界**：命题 3 依赖守卫 sound；conformal 依赖可交换；两者在 sim2real 下都可能破。必须保留真机锚点与在线校准。
- **对手模型误设**：撤销宏若漏掉真实干扰形态，最坏情况会低估风险；用 CFR 统计 + 随机化时机/速度扩大覆盖。
- **活锁**：回退—重做可能循环；用最大重做次数、前缀优先、时间预算三重护栏（继承 v2 的 CSG 思想）。
- **手册未取到**：评测轮次/时限/控制频率、5 轴中另 3 轴仍需手册确认。
