## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1（运动学 → 模型在 SE(3) 里「想」，身体必须在关节里「做」）

**直觉解释**：官方把动作统一成了 SE(3) 相对位姿（F22），这让人误以为「运动学问题已经被官方解决了」。但部署端有两种控制空间（F20）：选 `ee`，IK 由评测器的黑盒实现决定；选 `joint`，IK 由我方决定。7 自由度机械臂去实现 6 自由度位姿，永远有 1 维剩余自由度（F24）——肘部朝上还是朝下、腕部翻不翻，都是合法的。这个「合法但不唯一」的选择，恰恰决定了三条计分相关的东西：**能不能够到**（可达域）、**动作会不会在奇异点附近抖动**（动作健康度/部署可信度）、**恢复时手臂能否回到示教里那种自然构型**。所以运动学带来的不是一个新的表示，而是一个被所有人忽视的**权威层**：谁掌握「意图→可行关节运动」的映射，谁就掌握了动作可行性与平滑度的下限。

**严谨定义**：设单臂关节 `q ∈ ℝ⁷`，正运动学 `f: ℝ⁷ → SE(3)`，位姿误差用 `e = log(T_target · f(q)^{-1}) ∈ ℝ⁶`，雅可比 `J(q) = ∂e/∂q ∈ ℝ^{6×7}`。一般位形下 `rank(J)=6`，于是零空间维数 `dim ker J = 7−6 = 1`。冗余分解写为

```
Δq = J⁺ e + (I − J⁺J) z ,
```

其中 `J⁺ = Jᵀ(JJᵀ + λ²I)⁻¹` 为阻尼最小二乘逆，`(I−J⁺J)` 把任意向量 `z` 投影到零空间。`z` 不是玄学：取 `z = k(q_ref − q)`，就把「肘部构型」锚定到示教里检索到的姿态 `q_ref`（与 I9 直接咬合）。`λ` 随最小奇异值 `σ_min` 增大而增大：`σ_min` 小（接近奇异）时加大阻尼、缩短动作 chunk，就是天然的动作健康保护。

### 灵感 2（Gazebo → 仿真误差是各向异性的，只在对的轴上用仿真）

**直觉解释**：大家要么把仿真当「免费数据无限公司」，要么因为 sim-to-real 一律不用。两者都错。仿真的误差不是一个标量，而是一个分项：刚体几何、关节极限、自碰撞、可达性这几项，G1 的 URDF + Gazebo 可以做到很准；外观纹理、接触摩擦、可变形物体、传感器噪声这几项，Gazebo 差得很远（F23 还提示官方 URDF 的 armature/惯量需要对齐）。因此正确的用法是**保真度匹配**：只在 Gazebo 可信的轴上用它，在不稳的轴上坚决不用。反直觉点：Gazebo 的最大价值不是「生成更多像素」，而是「给已有的真实示教轨迹发运动学合格证」——它能告诉你一条合成/增广轨迹是不是物理上可行，而不需要它长得像真机。

**严谨定义**：把仿真误差分解为 `E_sim = E_kin + E_geom + E_visual + E_dyn`（运动学、几何/碰撞、外观、接触动力学）。一个仿真产物只应在「该误差项小，且评分对该项不敏感」的轴上使用。本文定义 **Gazebo 可信域** `D_gz = {可达性, 关节极限, 自碰撞, 刚体穿插, 夹爪开合几何}`，**不可信域** `D_gz^⊥ = {外观, 摩擦/接触力, 可变形, 光照}`。所有 Gazebo 产物必须标注自己属于哪个域；跨域使用（例如拿 Gazebo 渲染图直接训练视觉）一律禁止。

### 两者统一

运动学回答「这条 SE(3) 意图在关节空间里是否可行、零空间怎么选」；Gazebo 回答「这个可行域在离线时能否被批量验证与放大」。二者合起来，把第 2 轮的两个数据侧结论再往前推一步：**I1 的位置增广从「像素上可行」升级为「运动学上可行」，I9 的检索先验从「动作参数」升级为「零空间姿态先验」**。本轮结论：**中期胜负手仍是数据/可行性工程，但「可行性」必须由运动学来定义，而不是由像素来定义。**

## 4. 设计原则（新增 PR6/PR7，其余保留）

## 6. 本轮最大风险

**一句话**：一旦选择 `joint` 控制并由我方 IK 接管，任何一处 URDF/关节顺序/零位/EE 坐标系与评测器不一致，都会造成系统性动作偏移，且这种错误会被「任务失败」而不是「动作异常」掩盖——它会安静地吃掉 I1/I2/I5/I9 的全部收益，因此运动学权威层的第一个里程碑必须是 joint 与 ee 在 `example_env` 与单任务通道上的等价性回归，而不是先做花哨的冗余优化。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 v3 考纲校准五轴增广引擎 ★★★★★
- **动机**：计分的真机评测每次都在 5 轴上偏离训练分布（P2/F2），泛化缺口是全局乘性损失。
- **本轮深化（运动学）**：位置轴从「像素上把物体挪一下」升级为「运动学上确认够得到」。用 I11 的可达域图 `R` 给出每个任务在 base 系下的可抓取集合（含接近方向与奇异裕度），I1 的位置偏移采样只在 `R` 内、并留安全边界；超出 `R` 的样本直接丢弃，避免教策略做不可能的动作（P9）。增广分两级：L1「像素可行」（重拼接/inpainting，便宜）→ L2「运动学可行」（IK 可解 + 无自碰撞 + 夹爪开合够宽，由 I11 门验证），只有 L2 样本进入动作监督。
- **与现有方案差异**：直接 SFT 用标称数据；盲目增广用无校准随机化；本点用「官方考纲 + 运动学可行域」双重校准，把零样本泛化转化为分布内且物理可行的泛化（PR1/PR5/PR6）。
- **技术可行性**：高。考纲卡半自动构建（LLM 解析 wiki + 每任务约 10 分钟人工校对）；可达域图离线一次性生成（I11）。
- **所需资源**：分割/inpainting 1×24GB GPU（官方单卡即可，F11）；可达域图 CPU 数小时；磁盘同 v1.1。
- **落地步骤**：①32 张考纲卡；②I11 可达域图；③位置轴按 `R` 裁剪 + 两级可行性；④背景/干扰物两轴按考纲放量；⑤剂量-响应定档；⑥轴间交互（位置×干扰物）2 档析因。
- **风险**：可达域依赖 URDF/标定的准确性（缓解：单任务通道抽测 + 安全边界收缩 20%）；像素级增广与运动学增广的观测一致性（缓解：L2 样本只从真实 eps 的相邻位形插值，不凭空重渲染）。

### 1.1 运动学权威层：冗余 IK + 示教姿态零空间先验（I10）

```python
class KinematicAuthority:                     # 推理期确定性后处理，不新增学习模型
    def __init__(self, urdf, limits, collision_model):
        self.fk  = ForwardKinematics(urdf)     # q(7) -> SE(3)
        self.jac = Jacobian(urdf)              # 6x7
        self.lim = limits                      # 关节位置/速度上限
        self.col = collision_model             # I11 出的自碰撞对（离线标定）

    def solve(self, T_target, q_seed, q_ref, sigma_min=0.03):
        q = q_seed.copy()
        for _ in range(10):                    # 热启动 + 至多 10 次
            e  = se3_log(T_target @ inv_se3(self.fk(q)))     # 6D 位姿误差
            J  = self.jac(q)
            s  = svdvals(J)                    # 6 个奇异值
            lam2 = max(0.0, sigma_min**2 - s[-1]**2)         # 近奇异加阻尼
            Jp = J.T @ inv(J @ J.T + lam2*np.eye(6))         # DLS 伪逆
            N  = np.eye(7) - Jp @ J                          # 1 维零空间投影
            dq = Jp @ e + N @ (K_NULL * (q_ref - q))         # 任务 + 示教姿态
            q  = np.clip(q + STEP*dq, self.lim.lo, self.lim.hi)
            if np.linalg.norm(e) < 1e-4: break
        self.sigma_min = s[-1]                 # 供 I4 自适应 chunk
        return q

    def health(self, q, q_prev):
        return {                               # 动作健康度（PR4）
            "sigma_min": self.sigma_min,
            "jerk":     np.linalg.norm(q - 2*q_prev[0] + q_prev[1]),
            "self_col": self.col.check(q),
            "limit_margin": self.lim.margin(q),
        }
```

| 门禁 | PR4：run_client 全流程 + p99 + 动作健康度 | 本地 stub | 0 拒绝动作、p99 < 40ms |

**首批 L2 排队**：①I10 joint-vs-ee 等价性 + 3 任务 A/B（最高优先，其余收益都压在它上面）→ ②I2 共训基线 → ③I1 位置轴运动学校准 → ④I5 Gazebo 门试点 → ⑤I9 未见轴抽测。
