# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「场景泛化」×「数据增强」）

> R69 让不确定性第一次有了「形状」（多个动作模态 + 权重 + 可分性），也让「看/问/触」成为可以被生成、被认证、被审计的动作。但它把一条最关键的假设藏在了脚注里：**这个模态分布是在与部署场景同分布的数据上学出来的**。R69 自陈的最大风险正是这条假设破裂时的样子——流模型幻觉出不存在的模态、或把真模态坍缩掉，而 MCG 门用 ECE 去拦。问题是：**ECE 是在一个「可交换」的标定集上算的；一旦场景漂移，可交换性就没了，ECE 再小也不能保证模态权重可信。**
>
> 本轮两个灵感正好戳中这个盲点：
> - **场景泛化**把「模态分布可信」从一个**校准**命题改写成**泛化**命题：可信不是一个模型的属性，而是「模型 × 场景」这一对的属性；一个在场景 A 标定良好的流策略，在场景 B 里可能既不准也不 calibrated。
> - **数据增强**是扩大支持集、逼近目标场景的唯一低成本杠杆；但增强不是免费的午餐，它是对观测分布的一次**反事实干预**——水平翻转会把「左绕」变成「右绕」，颜色抖动会抹掉「红灯/热」这类语义线索，背景粘贴会凭空造出训练里不存在的模态。**盲目的增强正是幻影模态的工厂。**
>
> 核心命题：**把「模态分布可信」升级为「当前场景落在已认证支持集内」：训练期只用「等变、保模态」的增强去扩大支持集并给出增强证书；运行期用场景覆盖证书 + 偏移感知模态集 conformal 判断当前场景是否在支持集内；在支持集内才允许 R69 的 VoI 交互；在支持集外先执行「求证书动作」（改变光照/视角/位置进入已认证区域），失败才退回 R69/R68 保守。** 命名 **GEM-RAS**（Generalization-Equivariant Mode-certified Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我所在的这个世界，还是我训练时认识的那个世界吗**」——信任不是模型的属性，是（模型，场景）这一对的属性。

## 0. 直觉与动机

**灵感 1（场景泛化 → 可信度是「模型 × 场景」的二元属性）**
直觉：一支在北京标定过的天气预报模型，到了另一种气候里不是「稍微不准」，而是「标定本身失效」——因为它的误差统计是在另一个分布上估的。R69 的 MCG 门就是这支天气模型：它用 ECE 说「我的模态权重是 calibrated」，但 ECE 是**对场景分布取平均**的量。部署场景一旦换（白天→夜晚、室内→室外、仿真→真实、干净→雨雾），平均不再代表当前点。严格地说：**calibration 是 exchangeability 的下游产物，不是它的替代品**；而泛化研究的语言（domain、support、divergence）才是描述「当前点是否被覆盖」的正确语言。

**灵感 2（数据增强 → 增强是双刃剑：扩大支持集，也伪造支持集）**
直觉：增强同时做两件相反的事。
- 好的一面：它把训练支持集从「见过的场景点」扩成「一个邻域」，让目标场景更可能落进来，直接压低泛化间隙；
- 坏的一面：它改变了观测分布，却**未必**相应地改变动作分布。翻转一张图很容易，把「左绕」精确地翻成「右绕」却要求动作空间、坐标系、机械臂左右不对称性全部同步等变。若不同步，增强数据就把「A 场景的动作」硬贴到「B 场景的观测」上，在策略密度里**长出一个真实世界不存在的模态**——这正是 R69 最怕的幻影模态，而且是被我们自己「喂」出来的。
所以本轮的关键不是「要不要增强」，而是「**哪些增强是可认证的、增强到什么强度是净收益**」。

**灵感 3（等变增强 → 把「增强合法性」变成可计算的缺陷）**
直觉：增强应当被视为一个群作用 g ∈ G，它作用在观测 o 上，并**诱导**一个作用 ρ(g) 在动作 ξ 上。合法的增强满足等变：π(A_g o) ≈ ρ(g) π(o)。我们可以直接测量这个等变缺陷 e_g，以及更根本的**保模态缺陷** δ_g：在 o 处增强后的动作分布，是否等于把 o 处的动作分布经 ρ(g) 搬运过去。e_g、δ_g 都小，增强才被发证书。这把「增强靠经验调」变成了「增强靠缺陷审计」，而且缺陷直接进入 R69 的模态不确定性预算。

**灵感 4（覆盖证书 → 先证明「我在支持集里」，再允许提问）**
直觉：R69 的 VoI 交互有一个隐含前提——「我算出来的模态后验是可信的」。GEM-RAS 把这一步显式化：先用场景描述子 φ_s(o) 把当前场景投影到域空间，用 conformal 支持集给出覆盖 p 值；只有覆盖通过，才相信模态、才允许 MINT 去问。覆盖不通过时不是「照问不误」，而是先执行**求证书动作**：开灯、换个视角、移动到已认证区域、请求场景复位——这些动作改变的**不是模态身份，而是域身份**。这把 R69 的信息动作空间从 𝒜_info 扩成 𝒜_info × 𝒜_dom，VoI 也从「消除模态歧义」扩成「消除模态歧义 + 进入可信域」。

**灵感 5（增强投毒 → 支持集本身成为攻击面）**
直觉：一旦支持集决定了「能不能信任」，攻击者就有了新目标：不再骗策略，而是骗**证书**。对抗增强（人眼不可见的扰动让 e_g 突然变大）、后门风格触发器（某种天气/纹理把任意场景映射到幻影模态）、增强泄漏（近似重复的增强样本把测试场景泄进训练，让覆盖证书虚高）、证书伪造（伪造 e_g/δ_g 与 provenance 哈希）。**最危险的不是「模型没见过」，而是「模型以为自己见过」**。因此本轮必须同时交付：增强证书、覆盖证书的审计、增强投毒干扰集。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GEM-RAS 总览）** GEM-RAS = (AUG-C, SCG, MSC, GSI, MINT-D, TTA-0, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）：运行期只允许非参数化的阈值、重加权、查表，不允许梯度写；
(ii) **无证书不增强、无覆盖不交互**：训练期任何进入数据管线的增强必须携带增强证书 AC；运行期任何进入 VoI 交互的场景必须通过覆盖门；
(iii) **认证单调性**：覆盖失败、证书失效、检测到投毒时，信任指数单调不增，逐级退化为 FLUID-RAS / CALM-RAS，安全侧永不弱于 R68。

**定义 311（场景描述子与域）** 场景描述子 d = φ_s(o) ∈ 𝒟 ⊂ ℝ^{d_d}，编码光照、天气、纹理、布局、动力学参数等**与任务语义解耦**的域因素。场景 =（域 d，实例 o）。部署不是 i.i.d. 采样，而是域混合 P_d = Σ_j π_j P_{d_j}；泛化问题即「当前 d 是否被训练+增强后的支持集覆盖」。

**定义 312（增强群作用与等变缺陷）** 候选增强 g ∈ G 是观测空间上的变换 A_g: 𝒪→𝒪，并诱导动作空间变换 ρ(g): 𝒜→𝒜（或 𝒜_+）。在探针集上定义
e_g = E_{o∼D_probe, ξ∼π_θ(·|o)} [ d_𝒜(A_g ξ, ρ(g) ξ) / (1+‖ξ‖) ]，
即「先动世界再动动作」与「先动动作再动世界」的差。e_g 只测**动作侧**的等变；它不保证语义不变（翻转会交换左右、抖动会抹掉颜色语义）。

**定义 313（增强证书 AUG-C）** AC(g) = (e_g, δ_g, V_g, ρ(g), prov_g)，其中 δ_g 为保模态缺陷（定义 314），V_g ⊂ 𝒟 为该增强的**有效域**（增强只在某些域因素下有物理意义，例如雨雾增强只在户外有效），prov_g 为增强配置与数据血缘哈希。准入条件：e_g ≤ ε_eq ∧ δ_g ≤ ε_mode ∧ V_g 非空 ∧ prov_g 未被篡改。

**定义 314（保模态增强）** 记 P(·|o) 为真实动作条件分布。增强 g 保模态，若在 V_g 上
(ρ(g))_# P(·|o) = P(·|A_g o)（模一个允许的坐标系重参数化），
其缺陷 δ_g = sup_{o∈V_g} W_2( (ρ(g))_# P(·|o), P(·|A_g o) )。δ_g = 0 时，模态身份、模态权重、模态内协方差被**精确搬运**，增强只增加覆盖、不改变模态结构。δ_g > 0 的部分即为「增强注入的幻影模态质量」的来源（引理 19）。

**定义 315（认证支持集 SCG）** 在 φ_s 空间定义非一致性分数 s(o) = kNN 距离（或密度分位）到「训练 + 已认证增强」样本集。给定标定集 {s_i}_{i=1..n} 与显著性 α，认证支持集
S_α = { o : s(o) ≤ q_{1−α} }，q_{1−α} 为标定分数经验分位。
在可交换性下 P(s(o_new) ≤ q_{1−α}) ≥ 1−α；这是「当前场景是否像训练世界」的可否证陈述，而不是一句置信度。

**定义 316（覆盖 p 值）** p_cov(o) = (1 + #{i : s_i ≥ s(o)}) / (n+1)。覆盖门通过 ⇔ p_cov(o) > α。p_cov 是运行期唯一允许的「场景可信」判据；ECE 只能作为辅助诊断，不能替代覆盖（命题 19-系）。

**定义 317（泛化信任指数 GSI）** GSI(o) = h( p_cov(o), 1 − e_max(o), 1 − δ_max(o), Cov_mode(o) ) ∈ [0,1]，h 对各分量单调不减；e_max/d_max 取覆盖该场景所用增强族的最大缺陷，Cov_mode 为模态集 conformal 覆盖（定义 318）。门控：GSI ≥ τ_high 允许完整 VoI；τ_low ≤ GSI < τ_high 只允许高 VoI + k 源一致；GSI < τ_low 或 p_cov ≤ α 直接走保守/求证书路径。

**定义 318（偏移感知模态集 conformal MSC）** 不直接信任模态权重（权重在 shift 下不可辨识），而输出**模态集**：M_α(o) = 最小模态集合，使其重加权累计权重 ≥ 1−α−δ_shift，其中重加权系数 r(o) 由冻结的「偏移银行」ℬ（预先在多种域上估计的密度比）给出，ŵ_k ∝ r(o)·w_k。保证：P(m* ∈ M_α(o)) ≥ 1−α−2ε_r−δ_shift（ε_r 为密度比估计误差，δ_shift 为域间 TV 上界，定理 19）。r(o) 越界（外推）⇒ 证书作废，等价于覆盖失败。

**定义 319（求证书动作与增广信息动作空间）** 𝒜_info^+ = 𝒜_info × 𝒜_dom，g_dom ∈ 𝒜_dom = {调光, 换视角, 移动到已认证区域, 请求场景复位, 延时到光照/天气变化}。与 R69 的信息动作不同，g_dom 改变的是**域身份 d**，不是模态身份 M：它把「我看不清」变成「我换到一个我看得清的地方」。

**定义 320（泛化 VoI）** VoI^+(g) = VoI_mode(g) + VoI_dom(g) − c(g)，其中
VoI_dom(g) = H(1[p_cov(o)≤α]) − E_{o'∼P(·|g,o)}[ H(1[p_cov(o')≤α]) ]
为「执行 g 后进入认证支持集」的期望信息增益（用覆盖指示变量而非连续 p 值，避免对分位估计过拟合）。选 g* = argmax VoI^+，s.t. C-RAS-WM 认证、交互预算、以及 g 不把系统推入**更差**的覆盖状态（单调改进约束）。VoI^+ ≤ 0 ⇒ 不交互，走 R69/R68。

**定义 321（零写偏移适应 TTA-0）** 运行期只做三件非参数操作：查冻结偏移银行得 r(o)、按 α 与 δ_shift 调整 conformal 阈值、按 GSI 调整信任层级。禁止任何梯度更新/参数写入，以满足不变式 310-i。偏移银行更新只在离线维护，带版本与审计。

**定义 322（增强准入与主动增强 AUG-C 控制器）** 训练期候选池 G_cand；先按 AC 准入得 G_adm；再选增强调度以最大化「单位幻影模态风险换来的覆盖增益」：
max_{S⊂G_adm} ΔCov(S) / (ΔPhantom(S)+λ·Cost(S))，
其中 ΔPhantom 由引理 19 的界估计、ΔCov 为目标域混合上的支持集测度增益。输出一条**增强前沿**（coverage–phantom Pareto），而不是一个拍脑袋的增强强度。

**定义 323（增强风险分解）** 对目标域 T 与增强分布 A：
R_T(π_A) ≤ R_A(π) + ½ d_H(P_T, P_A) + L·δ_mode(A) + L'·e_max(A)。
只有当覆盖项 ½ d_H 的下降**大于**模态畸变项 L·δ_mode + L'·e_max 的上升时，增强才是净收益。这条不等式是「增强不是越多越好」的严格版本。

**定义 324（AIC-GEM 干扰集）** ℰ_GEM = ℰ_FLUID × ℰ_aug，ℰ_aug 含：对抗增强（微小变换击穿 e_g）、后门风格触发（特定纹理/天气→幻影模态）、增强泄漏（近重复样本泄入训练使覆盖虚高）、证书伪造（e_g/δ_g/prov 被改）、域欺骗（不同语义场景在 φ_s 中碰撞）。并入统一对抗训练与审计。

**定义 325（证书 J_GEM）** J_GEM = (J_FLUID, p_cov, e_max, δ_max, Cov_mode, δ_shift, domain_mix_ver, aug_prov_hash, gem_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖门通过 ∧ GSI ≥ τ_low ∧ 增强证书链完整 ∧ 偏移银行版本一致。

**定义 326（三级信任与单调退避）**
- **L0（认证域内）**：p_cov > α ∧ GSI ≥ τ_high ⇒ 完整 R69 VoI，U_epi 可被交互消解；
- **L1（边缘域）**：p_cov > α ∧ τ_low ≤ GSI < τ_high ⇒ 仅允许「域动作 + 高 VoI + k 源一致」，未消解 U_epi 一律计入 λ floor；
- **L2（域外/证书失效/投毒）**：p_cov ≤ α ∨ GSI < τ_low ∨ 证书链断 ⇒ 禁止模态交互，先执行 g_dom 进入认证域；失败则 R68 纯保守 λ = λ_floor(U_ale + U_epi)。
三级之间 λ 单调不降，切换只通过已验证的域动作或保守退避完成，保证无控制突变。

```python
# IP-264 AUG-C：增强等变审计与保模态缺陷（训练期离线）
def audit_augmentation(g, policy, probe_loader, rho):
    e_g = mean(normalized_action_dist(policy(A_g(o)), rho(g)(policy(o)))
               for o in probe_loader)
    delta_g = sup_over_probe(W2(pushforward(rho(g), P_true(·|o)),
                                P_true(·|A_g(o))))     # 用真实多模态标注估
    return AugCert(e_g=e_g, delta_g=delta_g, V_g=valid_domain(g),
                   rho=rho(g), prov=hash_config_and_lineage(g))

def admit(cands, eps_eq, eps_mode):
    return [g for g in cands
            if (c := audit_augmentation(g, ...)) is not None
            and c.e_g <= eps_eq and c.delta_g <= eps_mode and c.prov_ok]

# IP-265/322 主动增强调度：单位幻影风险换覆盖
def augmentation_schedule(admitted, target_mix):
    frontier = []
    for S in greedy_subsets(admitted, budget=MAX_AUG):
        d_cov  = coverage_gain(S, target_mix)
        d_risk = phantom_risk_bound(S) + LAM * cost(S)     # 引理 19/20
        frontier.append((S, d_cov / max(d_risk, EPS)))
    return pareto_front(frontier)                          # 交人工/审计选点

# IP-266/316 SCG：场景覆盖证书（运行期，O(log n) kNN）
def coverage_pvalue(o, phi_s, support_index, cal_scores, alpha):
    s = support_index.knn_score(phi_s(o))
    p = (1 + sum(si >= s for si in cal_scores)) / (len(cal_scores) + 1)
    return p, (p > alpha)

# IP-267/318 MSC：偏移感知模态集（零写）
def mode_set(modes, w, o, shift_bank, alpha, delta_shift):
    r = shift_bank.density_ratio(o)          # 冻结查表，禁止写
    if not r.in_support: return None         # 外推 ⇒ 证书作废
    w2 = normalize([r * wi for wi in w])
    need = 1.0 - alpha - delta_shift
    return smallest_mode_set(modes, w2, need)  # 保证真模态在集合内的目标覆盖率

# IP-263→IP-274 GEM 主闭环（在 R69 之上插入信任门）
def GEM_RAS_round(M, obs):
    # ---- R69 原路径 ----
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # ---- R70 信任门 ----
    p_cov, covered = M.scg.pvalue(o)
    e_max, d_max   = M.augc.max_defects(o)          # 覆盖该场景的增强族
    Mset           = M.msc.mode_set(modes, o, ALPHA, M.delta_shift)
    gsi = M.gsi(p_cov, 1 - e_max, 1 - d_max, cov(Mset))
    cert_ok = covered and (Mset is not None) and M.augc.chain_ok(o)
    # ---- L2：域外 / 证书失效：先求证书，再 R68 ----

        if g_dom is not None and M.c_ras_wm.certify_info(g_dom, o):
            M.execute_info(g_dom)                    # 改变域，下一轮重估
        lam = lam_floor(U_ale + U_epi)               # 未认证的 epistemic 视同 aleatoric
        k   = M.c_ras_wm.certified_prefix(...)
        k   = min(k, k_cal_shrink(...))
        return k, lam, safe_mode(modes), (U_ale, U_epi)
    # ---- L0/L1：域内才允许 R69 的交互 ----
    trust = gsi >= TAU_HIGH
    g = (M.mintd.choose_interaction(modes, o, M.budget)   # 含 VoI_mode + VoI_dom
         if (U_epi > TAU_EPI and not slow and trust) else None)
    if g is not None:
        answer, src = M.cia.execute(g)                    # 带认证 + k 源纪律
        U_epi_after = M.cia.update_belief(modes, answer, k_sources=src)
    else:
        U_epi_after = U_epi
    U_floor = U_ale + (U_epi_after if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow: lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(Mset if not trust else modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_g.submit_async(p_cov, gsi, g, U_epi, U_epi_after, e_max, d_max)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 3. 推导

**引理 19（等变增强的保模态性与幻影模态上界）** 若 g 在 V_g 上满足 e_g = 0 且 δ_g = 0，则增强把 o 处的模态集合、权重、协方差经 ρ(g) 精确搬运，模态数不变；若 e_g, δ_g > 0，则在 A_g o 处新增的「真实权重为 0 却预测为正」的模态质量 ≤ c_1 e_g + c_2 δ_g（c_1, c_2 由策略 Lipschitz 常数与动作空间直径给出）。
证明要点：在动作空间用三角不等式，把「增强后策略分布」分别与「经 ρ(g) 搬运的策略分布」和「增强后的真实条件分布」比较，两项分别由 e_g 与 δ_g 控制；再对模态质量做 data-processing。**系：R69 的幻影模态不是流模型的固有缺陷，而是未认证增强的可计算后果；把 e_g、δ_g 压到 0，幻影模态质量随之为 0。**

**引理 20（增强前沿与净收益条件）** 在定义 323 的分解下，增强 g 对目标域 T 的净收益为
ΔR(g) ≈ [½ d_H(P_T, P_A) − ½ d_H(P_T, P_{A∪g})] − [L Δδ_g + L' Δe_g]。
即覆盖增益减去模态畸变成本。**系：存在最优增强强度 g\*；盲目加大增强（δ_g、e_g 同升）会让目标风险先降后升；「增强越多越好」在 GEM 的语言里是一个可被证伪的命题。** 这也解释了 R69 在 OOD 上「越增强越自信地错」的失效模式。

**定理 18（GEM 严格包含 FLUID 与 R68）** 在可交换标定域上，若所有增强取恒等（e_g = δ_g = 0）、p_cov > α 且 GSI ≥ τ_high，则 GEM 逐指令等于 FLUID-RAS；若覆盖/证书/GSI 任一失败，GEM 走 L1/L2，其期望风险 ≤ FLUID-RAS（因为只允许 FLUID 的动作子集或 R68 保守），且 L2 时逐指令等于 CALM-RAS 的保守分支。故 FLUID-RAS 是 GEM 在「域内 + 恒等增强」边界上的退化，R68 是「域外 + 永不交互」边界上的退化。安全侧不做任何让步。

**定理 19（偏移下模态集覆盖与 ECE 的不充分性）** 在密度比精确（ε_r = 0）、域间 TV ≤ δ_shift 时，定义 318 的模态集满足 P(m\* ∈ M_α) ≥ 1−α−δ_shift；密度比估计误差为 ε_r 时下界再减 2ε_r。反例（命题）：存在场景序列使 ECE ≤ 0.02 而模态集覆盖在 α=0.1 时降到 0.55——**因为 ECE 只在标定域平均，覆盖是逐场景的**。故 R69 的 MCG 门只能拒绝「明显不 calibrated」，不能拒绝「在标定域 calibrated、在部署域系统性偏移」；GEM 用覆盖 p 值与偏移模态集把后者接住。

**定理 20（求证书动作的安全与单调退避）** 求证书动作 g_dom 经 C-RAS-WM 认证后物理风险 ≤ ε_int；它只改变域身份 d、不改变安全包络；若 g_dom 失败/超时/越界，信任层级单调不升，λ 单调不降地退化为 R69→R68；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。**系：把「进入可信域」也当作一个受认证的动作，就不会出现「为了看得更清而撞上去」这种把认知收益建立在物理风险上的错误。**

## 6. 本轮最大风险

**一句话**：GEM-RAS 把「是否可信」外包给了一个场景描述子 φ_s 和一套增强证书，而 φ_s 可能对真正的语义漂移是盲的（不同语义场景在域空间里碰撞）、增强又可能把支持集「撑大」成假象——**于是系统会在一个自认为已认证、实则从未见过的场景里，比 R69 更自信地犯错**。

**次级风险与缓解**：
1. **覆盖证书的分布假设**（conformal 需可交换、偏移下需精确密度比）→ 偏移银行 + δ_shift 显式折减 + 越界即证书作废，绝不做无保证外推；
2. **证书伪造/投毒** → provenance 哈希链 + 离线签名 + 审计重放（定义 324）；
3. **增强泄漏导致覆盖虚高** → 近重复检测 + 按场景分组划分训练/标定 + E308；
4. **域动作本身危险**（为看清而移动/转身）→ 定义 319 认证 + 定理 20 无突变；
5. **过度退避使系统僵死** → 三级门限 + 域动作优先于纯保守，并用 E306/E314 监控退避率。

**一句话结论**：R69 把不确定性做成了「有形状」，R70 进一步指出这个形状只在一个被认证的世界里才有意义——**先证明自己在哪，再决定要不要问。**

```python
# IP-264 AUG-C：增强等变审计 + 保模态缺陷（训练期离线）
def audit_augmentation(g, policy, probe_loader, rho):
    e_g = mean(norm_dist(policy(A_g(o)), rho(g)(policy(o))) for o in probe_loader)
    d_g = sup(W2(pushforward(rho(g), P_true(·|o)), P_true(·|A_g(o))) for o in probe_loader)
    return AugCert(e_g, d_g, V_g=valid_domain(g), rho=rho(g), prov=lineage_hash(g))

def admit(cands, eps_eq, eps_mode):
    return [g for g in cands
            if (c := audit_augmentation(g, ...)) and c.e_g <= eps_eq
            and c.d_g <= eps_mode and c.prov_ok]

# IP-271/322 AUG-S：单位幻影风险换覆盖，输出 Pareto 前沿
def augmentation_frontier(admitted, target_mix):
    out = []
    for S in greedy_subsets(admitted, budget=MAX_AUG):
        gain = coverage_gain(S, target_mix)
        risk = phantom_risk_bound(S) + LAM * cost(S)     # 引理 19/20
        out.append((S, gain / max(risk, EPS)))
    return pareto_front(out)

# IP-266/316 SCG：场景覆盖证书（运行期）
def coverage_pvalue(o, phi_s, index, cal_scores, alpha):
    s = index.knn_score(phi_s(o))
    p = (1 + sum(si >= s for si in cal_scores)) / (len(cal_scores) + 1)
    return p, (p > alpha)

# IP-267/318 MSC：偏移感知模态集（零写）
def mode_set(modes, w, o, shift_bank, alpha, delta_shift):
    r = shift_bank.density_ratio(o)            # 冻结查表
    if not r.in_support: return None           # 外推 ⇒ 证书作废
    w2 = normalize([r * wi for wi in w])
    return smallest_mode_set(modes, w2, 1 - alpha - delta_shift)

# IP-274 GEM 主闭环（在 R69 之上插入信任门）
def GEM_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)     # R69
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # ---- R70 信任门 ----
    p_cov, covered = M.scg.pvalue(o)
    e_max, d_max   = M.augc.max_defects(o)
    Mset           = M.msc.mode_set(modes, o, ALPHA, M.delta_shift)
    gsi = M.gsi(p_cov, 1 - e_max, 1 - d_max, coverage_of(Mset))
    cert_ok = covered and (Mset is not None) and M.augc.chain_ok(o)
    # ---- L2：域外/证书失效：先求证书，再 R68 ----
    if (not cert_ok) or gsi < TAU_LOW:
        gd = M.mintd.choose_domain_action(o, p_cov, M.budget)
        if gd and M.c_ras_wm.certify_info(gd, o): M.execute_info(gd)
        lam = lam_floor(U_ale + U_epi)
        k   = min(M.c_ras_wm.certified_prefix(...), k_cal_shrink(...))
        return k, lam, safe_mode(modes), (U_ale, U_epi)
    # ---- L0/L1：域内才允许 R69 交互 ----
    trust = gsi >= TAU_HIGH
    g = (M.mintd.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and not slow and trust) else None)
    if g:
        ans, src = M.cia.execute(g)
        U_epi = M.cia.update_belief(modes, ans, k_sources=src)
    else:
        pass
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow: lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(Mset if not trust else modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_g.submit_async(p_cov, gsi, g, U_epi, a_hat, e_max, d_max)
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（等变增强的保模态性与幻影模态上界）** `e_g=δ_g=0` ⇒ 模态集合/权重/协方差经 `ρ(g)` 精确搬运，模态数不变；否则新增幻影模态质量 ≤ `c₁e_g+c₂δ_g`。系：R69 的幻影模态是未认证增强的可计算后果；把 `e_g,δ_g` 压到 0，幻影质量随之为 0。

**引理 20（增强前沿与净收益条件）** `ΔR(g) = [覆盖增益] − [LΔδ_g + L'Δe_g]`；存在最优增强强度 `g*`，盲目加大增强使目标风险先降后升。系：「增强越多越好」在 GEM 语言里可被证伪；这也解释 R69 在 OOD 上「越增强越自信地错」。

**定理 18（GEM 严格包含 FLUID 与 R68）** 恒等增强 + 域内 + `GSI≥τ_high` ⇒ 逐指令等于 FLUID-RAS；覆盖/证书/GSI 失败 ⇒ 走 FLUID 动作子集或 R68 保守，期望风险 ≤ FLUID-RAS；L2 逐指令等于 CALM-RAS 保守分支。FLUID = 「域内 + 恒等增强」边界，R68 = 「域外 + 永不交互」边界。

**定理 19（偏移下模态集覆盖 / ECE 不充分）** 密度比精确时 `P(m*∈M_α) ≥ 1−α−δ_shift`，估计误差 `ε_r` 再减 `2ε_r`；存在场景序列使 `ECE≤0.02` 而模态集覆盖降至 0.55。故 MCG 门只能拒绝「明显不 calibrated」，接不住「标定域 calibrated、部署域系统偏移」；GEM 用逐场景覆盖 p 值与偏移模态集接住后者。

**定理 20（求证书动作安全与单调退避）** `g_dom` 过 C-RAS-WM 认证后物理风险 ≤ `ε_int`，只改域身份不改安全包络；失败/超时/越界时信任层级单调不升、λ 单调不降地退化为 R69→R68；换装不变式（R68 定理 15）保持 ⇒ 连续、无突变。系：把「进入可信域」也当受认证动作，避免「为了看清而撞上去」。

## 7. 本轮最大风险

**一句话**：GEM-RAS 把「是否可信」外包给了一个场景描述子 `φ_s` 和一套增强证书，而 `φ_s` 可能对真正的语义漂移是盲的（不同语义场景在域空间里碰撞）、增强又可能把支持集「撑大」成假象——**于是系统会在一个自认为已认证、实则从未见过的场景里，比 R69 更自信地犯错**。

**次级风险与缓解**：覆盖证书的分布假设（偏移银行 + `δ_shift` 显式折减 + 越界即作废）；证书伪造/投毒（provenance 哈希链 + 离线签名 + 审计重放）；增强泄漏（近重复检测 + 按场景分组划分 + E308）；域动作危险（定义 319 认证 + 定理 20 无突变）；过度退避僵死（三级门限 + 域动作优先 + E306/E314 监控退避率）。

---

**一句话结论**：R69 把不确定性做成了「有形状」，R70 指出这个形状只在一个被认证的世界里才有意义——**先证明自己在哪，再决定要不要问。**
