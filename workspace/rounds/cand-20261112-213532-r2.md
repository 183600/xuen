# 第 2 轮（灵感循环 v2：「场景驱动创新」×「力控」）—— 把力控搬到「位置接口」上：场景化接触推理与块级导纳整形

> 承接第 1 轮 UIP-01~10。本轮不是再发散十个并列点，而是用两个新灵感词对第 1 轮做**机制级修正**：
> - **「力控」**：第 1 轮把低层阻抗/力控封存了；本轮要证明，**在只允许位置目标的远程 API 上仍然可以做力控**——不是发扭矩，而是**从位置跟踪新息里推断接触**，并**把目标位置整形得像一个弹簧-阻尼系统**。
> - **「场景驱动创新」**：不训练一个万能策略，而是先把 32 个任务按**接触体制**分场景，再用同一套接触模板参数化。
>
> 结论：旗舰点从 UIP-01（稠密 VLM 进度验证器）切换为 **UIP-11 SCFC（Scenario-Conditioned Force-emulation Control）**：用**无传感接触观测器**替代大部分 VLM 验证，延迟更低、方差更小、对插入/拔出/易碎任务更有效，且完全落在选手 API 权限内。

---

## 0. 直觉解释 → 严谨定义

### 0.1 直觉（先给三句话）

1. **力控不等于写扭矩。** 既然只能发「目标位置」，那就把力控藏进**目标位置的形状**：接近时减速、接触时小步试探、卡住时退一点再对准、易碎物前把「虚拟弹簧」调软。
2. **没有力传感器，不等于感觉不到力。** 机械臂被挡住时，「命令它去哪」和「它实际到哪」会出现持续偏差；这个偏差就是接触与力的影子。类比无感 FOC：不装霍尔，用反电动势估计转子位置。
3. **场景驱动不等于给 32 个任务写 32 套规则。** 先把任务按**接触体制**（自由空间 / 插入 / 拔出 / 变形 / 动态 / 流体 / 易碎堆叠）归类，再用**同一套接触策略模板**按场景参数化。

### 0.2 严谨定义

**(a) 接口模型。** 策略是远程函数 `get_action: obs_t → A_t`，`A_t = (a_{t,1..T_a})` 是**位置目标块**（joint 或 ee，二者互斥），评测端执行整块后才再次调用。因此：
- 反馈周期 `Δ = T_a / 30` 秒；块级控制带宽上界（Nyquist）`f_N = 15 / T_a` Hz。
- 这是**块级力控**：足以做「接近 / 接触 / 卡阻 / 释放」的相位决策，**不足以**做高频柔顺或力跟踪。

**(b) 接触可观测量。** 观测里**没有**力矩、电流、关节速度、关节力；只有关节位置、EE 位姿、夹爪开度、4 路 RGB、语言。定义：
- 滞后补偿残差 `ε_q(t) = q_cmd(t−τ) − q(t)`，Cartesian 残差 `ε_x(t) = J(q_t) ε_q(t)`。
- 更严谨地用**自由空间动力学新息**（disturbance observer）：离线辨识 `M_φ: (q_{t−1}, a_{t−1}) → q_t`，在线 `d_t = q_t − M_φ(q_{t−1}, a_{t−1})`。`d_t` 是外部接触扰动的一阶代理；力代理 `f̂_t = J(q_t)^{−T} K_q d_t`，其中 `K_q` 未知，只用 `d_t` 的**方向、相对幅值、持续时间**做决策。
- 接触信念 `c_t = σ(wᵀ φ(d_t, d_{t−1}, v_t, g_t, visual_t))`，用滞回（Schmitt trigger）抑制相位抖动。

**(c) 场景与模板。** `s = g(language, first_frame) ∈ S`，`S = {R1 自由空间, R2 插入, R3 拔出/摩擦, R4 变形, R5 动态, R6 流体, R7 易碎堆叠}`。每个场景一个模板 `π_s(·; θ_s)`：
`θ_s = (接近速度曲线, 探测步长 δ_p, 横向搜索半径 r_s, 力/穿透预算 τ_f, 夹持预算 τ_g, 反馈块长 T_a, 退让策略)`。

**(d) 目标。** 在延迟/方差预算与动作规律性约束下，最大化
`E[1(success) + step_score]`，并满足 `P(latency > L_max) ≤ η`、`action_anomaly ≤ α`。

**离线试测（本轮新做）**：用 HF datasets-server 取 HangCup 前 ~1200 帧（4 个 episode）计算 `‖action[t] − state[t+1]‖`：
- 均值 ≈ **0.05 rad**，p95 ≈ **0.08–0.15 rad**；
- 而 `state` 单帧变化均值 ≈ **0.013 rad**。
- **结论**：原始残差被**控制滞后 / 平滑**主导，不能直接当接触信号；必须先做滞后补偿或学习自由空间动力学，再取新息。这直接决定了 UIP-11 的技术路线（先辨识 `M_φ`，再用新息）。

## 2. 对第 1 轮清单的诊断

- **UIP-01 的机制成本过高**：每步都调 VLM → 延迟与方差上升；而「插进去没有 / 卡住没有」本质是**接触相位**问题，低分辨率 AV1 图的语义 VLM 并不是最优传感器。
- **UIP-02 / UIP-09 有价值但缺骨架**：步骤分安全网、人为干扰恢复都应挂在「场景 + 接触相位」上，而不是独立规则。
- **UIP-10 有硬约束错误**（见 §1 修正 1），需重写为「在 EE 空间内做柔顺，再用 IK 落到关节」。
- **第 1 轮最缺的两块**：① 接触信号；② 按接触体制分场景。这恰好是本轮两个灵感词的落点。

## 3. 两个灵感词的解读

1. **场景驱动创新**：
   - 创新点不是「更大的网络」，而是**场景→控制模板的编译器**；
   - 评测也应场景化：按 R1–R7 分层报告，避免「平均值」掩盖接触任务的塌陷；
   - 场景是**数据效率**的来源：同模板跨任务复用，只需少量任务内标定。
2. **力控**：在位置接口上拆成三件事：
   - **接触推理**：从位置新息 / 视觉 / 夹爪堵转判断「碰到了、卡住了、滑了」；
   - **导纳整形**：把目标轨迹生成为虚拟弹簧-阻尼响应，而不是硬位置；
   - **力 / 穿透预算**：按场景设上限，插入任务需要「顶住」，易碎任务需要「让开」；
   - 夹爪本身也是力受限末端：闭合到堵转 ≈ 抓到；堵转后开度变化 ≈ 滑移。

## 4. 瓶颈假设（工作假设）

- 32 任务里，**自由空间抓放**靠模仿已能拿到大部分步骤分；真正的差距在**接触密集任务**——它们最容易被位置模仿学成「撞上去 / 卡住 / 捏碎」。
- 力信号只能从「位置跟踪新息」里挤出来；块级带宽够做相位决策，不够做高频柔顺。**因此不承诺高频力控，只承诺块级接触决策 + 轨迹整形。**
- 场景路由 + 模板比端到端大模型更省数据、更可解释、更容易离线验证。
- `T_a` 存在**最优点**：变小提高接触带宽，但增加调用次数、延迟与方差；需要在 E008 中扫描。

## 6. 旗舰点深潜：UIP-11 SCFC

**机制（四层）：**
1. **场景编译 SRP**：`language + 首帧` → `s ∈ {R1..R7}` + 参数 `θ_s`。用轻量分类器（文本 embedding + 首帧 CLIP）即可，不需要大模型。
2. **无传感接触观测 SCO**：离线辨识自由空间动力学 `M_φ`；在线计算新息 `d_t`；结合腕部视觉（物体相对位移、插入深度）与夹爪堵转，得到接触相位 `p_t ∈ {approach, contact, jam, release}` 与力代理 `f̂_t`。
3. **块级导纳整形 CAS**：策略网络给名义动作块 `A_nom`；SCFC 生成一个**虚拟导纳参考** `x_ref(τ)`，并按相位混合：
   `a_out[τ] = (1 − w(p_t)) A_nom[τ] + w(p_t) x_ref[τ]`。
   - approach：减速曲线，末段限速；
   - contact：沿插入轴小步 `δ_p` + 正交面螺旋搜索；
   - jam：沿 −轴退 `δ_r`，重对准后再试；
   - release：垂直抬起 + 停顿。
4. **力 / 穿透预算 FBS**：若 `‖f̂_t‖ > τ_f(s)`（由该场景成功演示的接触新息分位数标定），立即退让；易碎场景 `τ_f` 低、`τ_g`（夹持）低。

**与现有方案差异**：常规模仿学习直接回归位置块；SCFC 不改网络、不改执行层，只在**推理时的动作块形状**和**块间相位决策**里注入接触智能。相比 UIP-01 的 VLM 验证，它把每步的昂贵语义查询降为**只在相位切换时**触发。

**可行性**：高。所有输入都在 obs 里；所有输出都是合法位置目标；离线数据可训练 SCO 与场景分类器。
**资源**：1 张推理卡；公开 32 数据集；无需真机即可完成大部分验证。
**落地步骤**：① 辨识 `M_φ`；② 自动标注接触相位；③ 训练 SCO / 场景分类；④ 实现 CAS 与 FBS；⑤ 在 CSV 上扫描 `T_a`、`δ_p`、`τ_f`；⑥ 预约真机。

**风险**：`K_q` 与控制器柔顺度未知且可能随任务变化 → 力代理只能做**相对**判断；若新息被重力 / 滞后污染，会出现误判退让 / 误判卡阻。

---

## 7. 本轮最大风险（一句话）

**当前方案的最大风险是：位置控制器与物体接触动力学未知，导致「位置新息 = 接触力」的代理可能被控制滞后与重力污染；一旦 SCO 误判，导纳整形会主动制造「退让-再插」的振荡，既拉低接触任务成功率，又抬高延迟方差、触发可信度质疑——因此必须先在离线数据上标定 `M_φ` 与新息阈值，并在低置信时退回保守位置策略。**

## 1. 接口约束 → 设计推论

| 接口事实 | 设计推论 |
|---|---|
| 动作只有位置目标（joint 或 ee） | 力控只能通过**目标位置的时间形状**与**块间决策**实现；不能发扭矩 / 阻抗参数 |
| `control_space` 提交级互斥 | 选一种表示贯穿全程；另一种通过 IK/FK 内部转换。**默认选 `joint`**（与公开数据一致，避免评测端 IK 语义差异），Cartesian 导纳层内部生成后再 IK 到关节；`ee` 作为 E014 的对照 |
| `action_chunk_size` 全局固定 | 不能动态缩短反馈周期；只能改变**有效运动步数**（其余返回 hold）。`T_a` 作为全局超参，用 E008 扫描 |
| 反馈只在 chunk 边界 | 块级力控；带宽上界 `15/T_a` Hz。不做高频力跟踪的过度承诺 |
| 观测无 velocity / effort / torque | 用 `obs_delta_indices` 堆叠历史帧估计速度；用位置新息估计接触扰动 |
| 头部为标定立体对 | 可用立体视差恢复米制深度，辅助插入对准与插入深度估计 |
| 延迟与动作规律性计入可信度 | 接触模板必须**平滑、可预测**；避免退让-再插的高频振荡 |

**推荐默认配置**：`control_space="joint"`，`action_chunk_size=4`（接触任务）/`6`（自由空间），`obs_delta_indices` 对关节与 EE 位姿取 `[-2,-1,0]`，图像按需 resize 到 `[240,320]` 以降延迟。

| **R7 易碎堆叠** | StackBowls、StoreCups、PaperCupStacking、ArrangePlates、FruitCollection、FruitSorting | 接触即碎、堆叠对中 | `T_a=4`，先对准后 5 mm/s 下降，`τ_f` 与 `τ_g` 取 0.5×，力代理超调即停 |

> 场景划分不是目的，**参数复用**才是：同一模板跨任务迁移，任务内只需标定少量阈值（`τ_f`、`δ_p`、速度）。

## 3. 技术方案

### 3.1 UIP-13 · 自由空间动力学辨识（得到干净的新息）

不假设能拿到控制器增益，只用公开数据拟合**自由空间二阶 ARX**（逐关节）：

```
q_{t+1} = q_t + α ⊙ (q_t − q_{t−1}) + β ⊙ (a_t − q_t) + γ + ε_t
```

- `α, β, γ` 用 ridge / 鲁棒回归在**自由空间段**拟合；
- 自由空间段用 EM 迭代：先全量拟合 → 残差低者为自由空间 → 重拟合；
- 在线新息：`d_t = q_t − q̂_t`，其中 `q̂_t = M_φ(q_{t−1}, q_{t−2}, a_{t−1})`。
- 该模型同时给出**有效滞后** `τ` 与**跟踪刚度**的近似，供 3.3 的力代理归一化。

> 试测已表明原始残差 `action[t] − state[t+1]` 被滞后主导（见 §6），所以**必须**先做这一步，否则 SCO 会把「控制滞后」误判为「接触」。

### 3.2 UIP-12 · 接触事件离线重标注（弱监督）

在 32 个数据集上自动生成接触相位标签：

1. 计算新息 `‖d_t‖` 与关节速度 `‖q_t − q_{t−1}‖`；
2. **接触候选**：`‖d_t‖` 高、且沿指令运动方向持续 ≥ 2 帧、且 `‖q_t − q_{t−1}‖` 下降；
3. **卡阻候选**：新息高但关节速度 ≈ 0，且夹爪闭合（`g_state` 停止变化）；
4. **释放候选**：新息突降 + 夹爪开度回升 / 物体相对位移跳变；
5. 用腕部视觉光流与立体深度变化做交叉校验，去掉搬运段的惯性伪标签。

产出：每条 episode 的相位序列 `p_t ∈ {approach, contact, jam, release}`，用于训练 SCO（UIP-11 第 2 层）与场景分类器。

### 3.3 UIP-11 · SCO 无传感接触观测器

**特征** `φ_t`：
- 新息 `d_t`（7 维/臂）及其一阶差分；
- 关节速度 `v_t = q_t − q_{t−1}`（由堆叠帧得到）；
- 夹爪指令与实际开度差 `g_cmd − g_state` 及其变化；
- 腕部图像光流幅值 / 物体相对位移（可选：立体深度在夹爪附近的梯度）；
- 语言 embedding（场景先验）。

**输出**：接触相位 `p_t`（4 类）与力代理
`f̂_t = J(q_t)^{−T} K_q d_t`，`K_q` 未知 → 实际只用 `‖J^{−T} d_t‖` 的**相对值**。

**滞回**：进入 `jam` 需连续 2 个 chunk 超 `τ_hi`；退出需连续 2 个 chunk 低于 `τ_lo`，避免相位抖动造成动作振荡。

### 3.4 UIP-11 · CAS 块级导纳整形

给定名义动作块 `A_nom`（来自基座模仿策略）与 Cartesian 目标 `x_goal`，生成虚拟导纳参考：

```
x_ref(τ) = x_t + s(τ) · (x_goal − x_t) + probe(τ),   τ = 1..T_a
s(τ)     = 1 − exp(−τ / λ)                           # 虚拟弹簧-阻尼响应
```

- **approach**：`probe=0`，末段对 `‖x_ref − x_t‖` 限速（近接触减速）；
- **contact**：沿插入轴 `u` 加 `δ_p · clamp(τ/τ_p, 0, 1) · u`，正交平面加螺旋
  `r(τ)[cos(ωτ+φ₀), sin(ωτ+φ₀)]`，`r(τ)=min(r_max, κτ)`；
- **jam**：`x_ref = x_t − δ_r · u`（退让一个 chunk），下一 chunk 重新对准；
- **release**：沿 `u` 的反向抬起 `δ_lift` 后 hold。

按相位混合（`w` 由场景给定，接触相位 `w` 大）：

```
a_out[τ] = (1 − w(p_t)) · A_nom[τ] + w(p_t) · IK(x_ref(τ))
```

> 关键：混合发生在**关节空间**（`IK(x_ref)` 后），因此最终仍返回合法的 `action.left_arm/right_arm`；`control_space="joint"` 不变。

### 3.5 UIP-11 · FBS 力 / 穿透预算（数据驱动，不需真机力标定）

对每个场景 `s`，在成功演示的**接触段**上取新息分位数：

```
τ_f(s) = Q_{0.95}( ‖f̂_t‖ : t ∈ contact(s) )
τ_g(s) = Q_{0.90}( g_state : t ∈ contact(s) )
```

- 易碎场景（R7）与变形场景（R4）：`τ_f ← 0.5·τ_f`，`τ_g ← 0.7·τ_g`；
- 在线若 `‖f̂_t‖ > τ_f(s)` → 立即退让并降速；
- 这样避免了对真实牛顿值的标定，只用**同一场景内的相对分位**，跨机器人仍可迁移。

### 3.6 UIP-16 · GRF 夹爪抓取 / 滑移观测

- **抓取成功**：闭合指令与实际开度差持续存在，且实际开度停止变化（堵转）；
- **滑移**：实际开度在「应夹持」阶段回升，或物体在腕部视觉中相对夹爪移动；
- **响应**：轻微加夹持（不超过 `τ_g`）或退让重抓；易碎场景优先重抓而非加力。

### 3.7 伪代码（可直接改写为提交类）

```python
class SCFCPolicy:
    def __init__(self, base, plant, sco, compiler, grf, ik, cfg):
        self.base, self.M, self.sco = base, plant, sco
        self.compiler, self.grf, self.ik = compiler, grf, ik
        self.cfg = cfg
        self._token = os.environ["UNIBOT_SUBMISSION_TOKEN"]

    @property
    def metadata(self):
        return {
            "control_space": "joint",
            "obs_delta_indices": {
                "observation.language": [0],
                "observation.images.cam_left_high": [0],
                "observation.images.cam_right_high": [0],
                "observation.images.cam_left_wrist": [-1, 0],
                "observation.images.cam_right_wrist": [-1, 0],
                "observation.state.left_arm": [-2, -1, 0],
                "observation.state.right_arm": [-2, -1, 0],
                "observation.state.left_ee_pose_gripper_base": [-2, -1, 0],
                "observation.state.right_ee_pose_gripper_base": [-2, -1, 0],
                "observation.state.left_gripper": [-2, -1, 0],
                "observation.state.right_gripper": [-2, -1, 0],
            },
            "image_resize": {
                "observation.images.cam_left_high": [240, 320],
                "observation.images.cam_right_high": [240, 320],
                "observation.images.cam_left_wrist": [240, 320],
                "observation.images.cam_right_wrist": [240, 320],
            },
            "action_chunk_size": self.cfg.T_a,
            "token": self._token,
        }

    def reset(self):
        self.base.reset()
        self.s = None
        self.phase = "approach"
        self.retry = 0

    def get_action(self, obs):
        if self.s is None:
            self.s = self.compiler(obs)                 # R1..R7
            self.theta = self.cfg[self.s]

        d = self.M.innovation(obs)                      # contact disturbance
        self.phase = self.sco.update(d, obs, self.phase)  # hysteresis
        f = self.sco.force_proxy(d, obs)

        if f > self.theta.tau_f:
            x_ref = self.sco.retreat(obs, self.theta)
            self.phase = "jam"
        elif self.phase == "contact":
            x_ref = self.sco.probe(obs, self.theta)
        else:
            x_ref = self.sco.approach(obs, self.theta)

        a_nom = self.base.get_action(obs)               # (T_a, 7) per arm
        w = self.theta.w[self.phase]
        a_arm = self.sco.blend(a_nom, self.ik(x_ref), w)
        grip = self.grf.command(obs, self.theta)        # stall / slip aware
        return self.pack(a_arm, grip)
```

## 4. 关键推导

### 4.1 块级带宽与 `T_a` 权衡

| `T_a` | 反馈周期 `T_a/30` | 调用频率 | 带宽上界 `15/T_a` | 适用 |
|---|---|---|---|---|
| 2 | 67 ms | 15 Hz | 7.5 Hz | 高速接触，但延迟方差最大 |
| 3 | 100 ms | 10 Hz | 5.0 Hz | 精细插入（候选） |
| **4** | **133 ms** | **7.5 Hz** | **3.75 Hz** | **默认接触配置** |
| 6 | 200 ms | 5 Hz | 2.5 Hz | 自由空间抓放 |
| 8 | 267 ms | 3.75 Hz | 1.875 Hz | 低延迟压力场景 |

目标函数：
`T_a* = argmax_T [ S_contact(T) − λ·L(T) − μ·Var(L(T)) ]`，
其中 `S_contact` 来自 CSV 的接触成功率代理，`L` 为单步延迟。**结论：接触任务用 `T_a=4`，自由空间用 `6`，用 E008 验证。**

### 4.2 位置新息 → 接触力代理

准静态下，位置控制器关节力矩 `τ = K_q(q_cmd − q)`；接触外力满足
`τ_ext = K_q(q_cmd − q) = K_q ε_q`。变换到 Cartesian：

```
f_ext = J(q)^{−T} τ_ext = J(q)^{−T} K_q ε_q
```

`K_q` 未知且可能随任务变化，因此只用归一化代理
`f̂ = J(q)^{−T} ε_q` 的**方向与相对幅值**；阈值取同场景演示的 95 分位（§3.5），不做绝对牛顿标定。

### 4.3 卡阻判据与滞回

```
J_t = ‖d_t‖ / (‖q_t − q_{t−1}‖ + δ)
enter jam:  J_t > τ_hi  连续 2 chunks
exit  jam:  J_t < τ_lo  连续 2 chunks
```

分母抑制「快速运动时的正常跟踪滞后」；分子在「指令不动但实际也不动」时仍高，正是卡阻特征。

### 4.4 为什么不直接用原始残差

试测（§6）：`‖action[t] − state[t+1]‖` 均值 0.05 rad，而单帧运动仅 0.013 rad。原始残差主要反映**控制器滞后与平滑**，不是接触。故必须用 `M_φ` 新息，而不是朴素残差。

### 4.5 步骤分安全网

接触任务的计分点通常是「接近 → 对准 → 插入 / 抓取 → 释放」；失败时若在 `contact` 相位强行重试，可能把已到位的物体推走。SSB 规则：
- 已达成的计分点用相位与视觉双确认后**锁存**；
- 重试只在 `jam` 相位、且 `retry < max_retry(s)` 时允许；
- 重试失败后进入 `release`/hold，保住已得步骤分而非继续撞。

## 6. 本轮试测结果（实做，非真机）

**数据**：`unitreerobotics/G1_Dex1_HangCup`，通过 HF datasets-server 取前 1200 帧（4 个 episode，30 fps）。
**方法**：计算 `‖action[t] − state[t+1]‖`（7 关节 L2）与 `‖state[t+1] − state[t]‖`。

| 量 | 均值 | p95 | 说明 |
|---|---|---|---|
| `‖action[t] − state[t+1]‖` | ≈ 0.050 rad | 0.078–0.151 rad | 含明显控制滞后 / 平滑 |
| `‖state[t+1] − state[t]‖` | ≈ 0.013 rad | 0.041 rad | 真实运动量 |
| 残差 / 运动量 | ≈ 3.8× | — | 原始残差**不能**直接当接触信号 |

**结论**：朴素残差被滞后主导；必须先辨识自由空间动力学再取新息（UIP-13），否则 SCO 会把正常跟踪滞后误判为接触。该试测只证明了「必须做滞后补偿」，尚**未**证明 SCO 的分类性能——这是 E007 的任务。

## 9. 本轮最大风险（一句话）

**最大风险仍是「位置新息 ≠ 真实接触力」：控制器柔顺度未知、重力与滞后会污染新息，一旦 SCO 误判，导纳整形会把一次插入变成反复退让-再插的振荡，同时拉低成功率、抬高延迟方差并触发可信度质疑；因此必须先离线标定 `M_φ` 与分位阈值，并设置「低置信即退回保守位置策略」的硬回退。**
