# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「UniBot-V1」×「意图识别」）

> R69 把不确定性一分为二，给 epistemic 歧义配了一个主动动作：看、问、触，并用 VoI 决定「值不值得问」。它问「我该向谁求证、还能问什么」。但整座 FLUID-RAS 有一个从未被写进定义的前提：**意图是给定的**。U_epi 是「已知任务下，选哪个动作模态」；VoI 是「哪个动作模态更值得确认」；证据纪律是「哪种执行方式被证实」。所有推理都在一个固定的条件 I 里面打转。
>
> 然而现场最贵的错误从来不是「绕左还是绕右」，而是**做错了事**：把「把杯子收起来」做成「把杯子递给你」，把「擦桌子」做成「擦掉桌上的字」，把「先别动」听成「继续」。这类错误在 R69 的框架里根本不可见——因为 R69 假定它已经知道 I。更麻烦的是，**单模型多任务**让这种错误变得更容易而非更难：同一个场景同时 afford 多个任务，统一策略共享参数，任务之间互相干扰（task interference），模型可以「很能干地」执行一个没人要的任务。
>
> 本轮两个灵感正好补上这个缺口：
> - **UniBot-V1** 是一个真实的「单模型多任务」基准：32 项真实桌面操作、约 3.2 万条演示、169 小时、统一 54 维动作 / 60 维状态、30 步 @30Hz 的动作块。它把「一个模型做很多任务」变成了可测的东西；但它**在评测时把任务标签直接喂给模型**，只测「已知意图下的能力」，不测「意图识别本身」。它隐含地假设了一个**单位意图混淆矩阵**——真意图 i 一定被执行成 i。这个假设一旦破了，排行榜上的成功率就系统性高估了部署可靠性。
> - **意图识别** 提醒我们：意图不是一个可以分类一次的标签，而是一个**层级化、可演化、被交互共同构造**的隐变量。正确的问题不是「把指令分到哪一类」，而是「在跨过不可逆点之前，我必须把意图确认到什么程度；以及我怎样发问，才不是在制造答案」。
>
> 核心命题：**R69 处理的是「意图内部的执行不确定性」，R70 处理的是「意图本身的不确定性」。** 引入显式意图后验与承诺边界（commitment boundary）：先把意图收敛到「足以安全承诺」的程度，再谈动作模态消歧；意图不确定与动作不确定不能相加，前者条件化后者。命名 **UNIBOT-RAS**（Unified Behavior-space, Intent-verified, Non-leading, Task-commitment, Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底在替谁做哪件事——而且我确定吗**」。

## 0. 直觉与动机

**灵感 1（UniBot-V1 → 能力 ≠ 意图正确）**
直觉：UniBot-V1 的 32 个任务共享桌面、物体与双手，只是目标不同。单模型在 32 个任务上都很强，恰恰意味着它**有能力执行其中任何一个**——于是「执行了错的那个」变得更可能，而不是更不可能。基准的评测协议是「给定任务标签，测成功率 + 步骤分」；它测的是条件成功率 S(y|I)，不是意图识别率 P(Î=I)，更不是真意图下的部署成功率。一个意图混淆矩阵 C_{ij}=P(执行 j | 真意图 i) 只要不是单位阵，排行榜的成功率就是**乐观偏差**。这不是说 UniBot-V1 不好，而是说它**测不到自己最危险的那一维**。

**灵感 2（意图识别 → 意图是有结构、可约、但不一定可辨识的）**
直觉：意图至少有三层——目标（做什么）、约束（不能怎样做）、偏好（怎样算做得好），外加时间窗与执行者归属（替谁做）。同一句「把它弄干净」在这四层上可以差很远。更重要的是，有些意图在**可观测接口下行为等价**：以现有传感器与动作，两个意图产生几乎相同的观测分布，那它们就**不可辨识**。R69 的错在于把「不可辨识的歧义」当成「值得问的歧义」；R70 要承认：意图空间应被压成**行为等价商空间**（intent quotient），证书只能报等价类，不能报一个虚假的点估计。

**灵感 3（承诺边界 → 意图只需要在不可逆之前确定，而不是一开始就确定）**
直觉：不是所有动作都要求意图已知。看一眼、让开、把手臂收回到安全姿态，这些动作对大多数意图都无害，可以先做；而切割、倾倒、把物体交给某个人、进入某个区域，是**不可逆或高代价**的。于是意图识别的正确形态是**最优停止**：在「不可逆点」之前持续收集证据，一旦跨过边界就要求后验足够尖锐，否则拒绝承诺（defer）。这把 R69 的「不确定就收紧」升级为「不确定就**先不承诺**，并把不承诺本身当成一个可认证的动作」。

**灵感 4（意图是被共同构造的 → 主动提问可能制造答案）**
直觉：R69 已经担心「问错比不问更危险」，但它担心的是投毒与幻觉。R70 要担心一个更隐蔽的东西：**提问会改变人的意图**。当你问「你是要我把杯子放到水槽里吗？」，对方很可能顺着你的话确认；当机器人先做出一个方向的动作，人会把机器人的动作读成自己的意图。于是「主动意图识别」可能变成一个自我实现的预言：系统问出它想听的答案，再把置信度记在自己的账上。**若干次有偏提问可以让 ECE 变好而真实准确率不变甚至变差**。所以非诱导（non-leading）不是礼貌问题，而是校准正确性问题。

**灵感 5（严格包含 R69 → 已知意图是边界情形）**
直觉：如果意图后验退化为一个点 mass（用户明确说了、或任务协议给定），UNIBOT-RAS 应当逐指令退化为 FLUID-RAS：同样的 U_ale/U_epi 分解、同样的 VoI、同样的 λ 退化。这样 R69 不是被替换，而是被**包含**为「意图已定」的切片。安全侧仍不让步：意图未知时只会更保守，不会更激进。这是本轮的理论姿态——新层若不能严格包含旧层，就只是又加了一个需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（UNIBOT-RAS 总览）** UNIBOT-RAS = (UIP, IAG, CBA, CSG, IVA, NPD, ACR, IRG, IQC, RAS-WM‡)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i 与 R69 定义 293-i）；
(ii) **意图先于承诺**：任何不可逆动作 ρ(a) > ρ* 之前，意图后验必须满足承诺安全约束（定义 317），否则必须 defer 或选择可逆替代动作；
(iii) **非诱导证据纪律**：意图探询必须满足非诱导 KL 预算（定义 319），且单次提问/单模态回答不得单独定案（继承 R69 定义 293-iii 并上移到意图层）；
(iv) **严格包含**：当 b_t 为点 mass 时，主闭环与 FLUID-RAS 逐指令一致（定义 325）。

**定义 311（意图本体）** 意图 I = (g, c, p, h, o) ∈ ℐ：目标 g ∈ 𝒢（UniBot-V1 的 32 个任务 token ∪ 开放集）、约束 c ∈ 𝒞（不得碰撞/不得移动他人财物/力上限…）、偏好 p ∈ 𝒫（快/稳/轻/美观）、时域 h、归属 o（为谁执行）。ℐ 带偏序（子目标细化）与互斥关系。意图 token 由 UniBot-V1 统一动作/状态规范对齐，允许跨末端执行器复用。

**定义 312（意图后验与校准）** b_t(I) = p(I | o_{1:t}, y_{1:t}, a_{1:t})，其中 y 为交互回答、a 为已执行动作（动作本身也是证据）。校准：把 b_t 的置信度分桶，ECE_intent = Σ_b (n_b/N)|acc(b) − conf(b)|；只有在 ECE_intent ≤ τ_I 时才允许用 b_t 驱动承诺或探询。

**定义 313（意图条件策略）** 复用 UniBot-V1 / UnifoLM-WLA 式统一策略 π_θ(ξ_{t:t+H} | o_t, I)，H=30 @30Hz；意图经 intent token 注入，不重训主干（零重复训练，沿用 R69 定义 295 的复用原则）。意图层的推理在**动作块边界**（约 1s）更新，而非每个 30Hz 控制 tick。

**定义 314（行为等价与意图商）** 称 I ≡_o I' 当且仅当在观测/动作接口下，二者诱导的最优行为与可达观测分布不可区分：对任意可执行前缀 a_{1:t}≤t*，argmax_ξ π(ξ|o,I) = argmax_ξ π(ξ|o,I') 且最优值相等。意图商 Q_o = ℐ/≡_o。**可辨识边际** μ(I,I') = min_{t≤t*} D_TV(p(y_{1:t}|I), p(y_{1:t}|I'))；若在预算内 μ < μ*，两意图属于同一等价类，证书只能报类。

**定义 315（不确定性的三层分解，非可加）** U_total ≅ (U_ale, U_epi^act, U_epi^int)。U_ale 为执行噪声（→ R68 λ floor）；U_epi^act 为给定 I 下的动作模态歧义（→ R69 AUD/MINT）；U_epi^int 为意图后验熵 H(b_t) 与不可辨识质量。三者**不相加**：U_epi^int 通过「换条件」改变整个 R69 子问题，而不是给 λ 加一个数。意图未定时，R69 的动作 VoI 是**条件 VoI**，其期望必须对 b_t 取平均。

**定义 316（不可逆度与承诺边界）** 动作 a 的不可逆度 ρ(a) = 1 − V_after(a)/V_before ∈ [0,1]（V 为可保留选项价值；切割/倾倒/交付/进入受限区接近 1）。承诺边界 ρ*（任务给定，如 0.7）。不可逆点 t* = min{t : ρ(a_t) > ρ*}；t* 之前允许 defer / 探询 / 可逆替代。

**定义 317（承诺安全约束 CSG）** 设意图错误损失 L(I, Î)（非对称、不可逆后不可恢复），风险预算 L_max、置信 ε。动作 a 可承诺仅当
P_{I~b_t}( ρ(a)·L(I, Î) > L_max ) ≤ ε，且 b_t 的「不可逆错误质量」Σ_{I: L(I,Î)>L_max} b_t(I) ≤ ε。
否则必须 defer、选可逆替代、或提问；**不允许用期望收益抵消不可逆风险**（与 R69 的 λ_floor 同源，但作用于语义承诺而非动作幅值）。

**定义 318（意图级 VoI 与证据分配 IVA）** 意图信息增益 IVoI(g) = H(b_t) − E_{y~p(·|g,b_t)}[H(b_t | y)]。总预算 B = B_I + B_A。分配规则：按边际风险下降 ∂R/∂B_I 与 ∂R/∂B_A 贪心分配；当意图商 |Q_o| > 1 且意图错误损失占优时，优先 B_I。R69 的 MINT 是 B_I = 0 的特例。

**定义 319（非诱导探询 NPD）** 候选探询 q（问句/注视/演示请求/可逆试探动作）。诱导度
Lead(q) = sup_I D_KL( p(answer | do(q), I) ‖ p(answer | do(q_0), I) )，锚定度 Anchor(q) = D_TV( p(I | do(q)) ‖ p(I) )。
约束 Lead(q) ≤ δ_lead、Anchor(q) ≤ δ_anchor，且 q 必须过 C-RAS-WM 认证（问句不得诱发危险动作、注视不得诱导危险转身）。在约束下最大化 IVoI(g) − c(g)。**随机化措辞 + 反向确认 + 独立第二证据源**用于估计并压制 Anchor。

**定义 320（共构造信道 ACR）** 把「人—机器人」建模为带反馈的信道：I_{t+1} ~ T(I_t, a_t, q_t, y_t)。机器人动作与提问会改变人的表达意图甚至真实意图。ACR 维护一个「反事实意图」估计 b_t^{cf}（若未提问/未行动，意图会是什么），并检测 b_t 与 b_t^{cf} 的系统性偏移；偏移超过阈值即判定为**自造意图风险**，冻结基于 b_t 的承诺升级。

**定义 321（意图漂移 IRG）** 允许 I 在任务中途改变（人改主意、发现新信息、多用户交替）。用变点检测（CUSUM / 贝叶斯在线变点）监控似然比；检测到漂移后清空动作模态后验、回到 t* 之前的安全姿态重新确认，绝不把旧意图下的动作模式惯性带入新意图。

**定义 322（意图威胁集 ℰ_intent）** 欠定指令（「把它弄一下」）、多指代（桌上两个「它」）、矛盾约束（快 vs 不洒）、场景提示注入（环境里的文字/标牌）、恶意歧义（故意让两种执行都「说得过去」以便事后索赔）、多用户意图冲突、以及**探询诱导本身**。并入 AIC：ℰ_UNIBOT = ℰ_FLUID × ℰ_intent。

**定义 323（证书 J_UNIBOT）** J_UNIBOT = (J_FLUID, intent_posterior_hash, ECE_intent, intent_quotient_classes, identifiability_margin, commitment_margin_t*, anchor_score, nonleading_kl, intent_confusion_estimate, unibot_bench_ver, unibot_ras_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_intent ≤ τ_I ∧ 承诺安全满足 ∧ 非诱导预算满足 ∧ 商空间已如实报告。

**定义 324（UniBot-V1-I 评测协议与指标）** 在 UniBot-V1 的 32 任务/统一动作状态规范上新增意图层协议：给定欠定/多指代/可漂移指令与场景，测
- 意图识别率 Acc_int(I) 与校准 ECE_intent；
- 意图条件成功率 S_{ij}=P(成功且执行 j | 真意图 i)，构成意图混淆矩阵 C；
- **意图鸿沟** Δ_int = Ŝ_label − E_{I~p_true}[Σ_j C_{ij} S_{ij}]，即「按标签评测」相对「按真意图部署」的乐观偏差；
- 错意图执行率 R_wrong、跨过 t* 后才发现的不可逆错误率、恢复代价；
- 非诱导一致性：同一意图在有/无探询下的回答分布偏移。
**基准的隐含假设是 C = I（单位阵）；本协议显式估计 C。**

**定义 325（严格包含 FLUID-RAS）** 若 b_t = δ_{I0}（意图点 mass、μ 无需估计），则 UNIBOT-RAS 的 CBA→恒可承诺、NPD→不提问、U_epi^int→0，主闭环逐指令退化为 R69 的 FLUID_RAS_round；且安全侧 λ 不低于 R69。R69 = 「意图已定」边界。

**定义 326（统一模型的意图迁移与语义标定）** 跨任务/跨末端执行器共享意图表示可降低意图样本复杂度，重叠度为 κ 时样本量约降为 1/(1−κ)；但仅当意图度量语义标定误差 ε_cal ≤ ε* 时成立，否则发生负迁移（共享表示把无关任务拉近、把相关任务推远），并直接污染 b_t 与 μ 的估计。

```python
# IP-264 UIP：意图后验（复用 UniBot-V1 主干 task-token logits，块边界更新）
class IntentPosterior:
    def __init__(self, trunk, task_tokens, prior, calib):
        self.trunk, self.tokens = trunk, task_tokens     # 32 任务 + 开放集
        self.prior, self.calib = prior, calib

    def update(self, o_hist, y_hist, a_hist):
        logits = self.trunk.intent_logits(o_hist, y_hist, a_hist)
        b = softmax(logits / self.calib.temperature)     # 校准温度/向量缩放
        return self.calib.recalibrate(b)                 # 保形/等渗，报 ECE

# IP-272 IQC：意图商——先判断「能不能辨识」，再谈「识别得准不准」
def intent_quotient(b, policy, probes, mu_star):
    classes = union_find_over(b.support())               # 行为等价合并
    for (I, I2) in pairs(b.support()):
        mu = min_tv_predictive(policy, I, I2, probes)    # 可辨识边际
        if mu < mu_star: classes.merge(I, I2)
    return classes, margin(classes)                     # 只报等价类，不报假点估计

# IP-266/267 CBA+CSG：不可逆度与承诺安全
def commitment_gate(a, b, loss, rho_star, L_max, eps):
    if rho(a) <= rho_star: return True                  # 可逆：可先做后问
    bad_mass = sum(b[I] for I in b if loss(I, argmax(b)) > L_max)
    return bad_mass <= eps                               # 否则 defer / 可逆替代 / 提问

# IP-268 IVA：意图级 vs 动作级证据预算分配
def allocate_evidence(b, action_modes, B):
    gI = info_action_candidates(b)                      # 问/看/演示请求
    gA = info_action_candidates(action_modes)           # R69 的看/触/等
    while B > 0:
        dI = marginal_risk_drop(gI, b)                  # 意图层：改条件
        dA = marginal_risk_drop(gA, action_modes)       # 动作层：同条件内
        if dI >= dA: B -= spend(best(gI)); b = update(b, best(gI))
        else:        B -= spend(best(gA)); update_modes(best(gA))
    return b, action_modes

# IP-269/270 NPD+ACR：非诱导探询 + 反自造意图
def choose_intent_probe(b, q_candidates, delta_lead, delta_anchor):
    best = None
    for q in q_candidates:
        if lead(q) > delta_lead: continue               # 不许诱导
        if anchor(q, b) > delta_anchor: continue        # 不许锚定
        if not c_ras_wm.certify_query(q): continue      # 问句/注视也要安全
        score = ivoi(q, b) - cost(q)
        if best is None or score > best.score: best = (q, score)
    return best if best and best.score > 0 else None

def anti_manufacture_guard(b, b_cf, tau_cf):
    return dist(b, b_cf) > tau_cf                       # 提问把意图带偏了

# IP-271 IRG：意图漂移与重确认
def revision_guard(b, b_prev):
    if cusum_change(b, b_prev) > TAU_DRIFT:
        return 'RESET_TO_PRE_COMMIT'                     # 清空动作模态惯性
    return 'CONTINUE'

# IP-276 主闭环（意图层在块边界；动作层继承 R69）
def UNIBOT_RAS_round(M, o_hist, a_hist, y_hist):
    # 0) 意图层（约 1s 一次，30 步块边界）
    b  = M.uip.update(o_hist, y_hist, a_hist)
    b_cf = M.acr.counterfactual(b)                       # 反事实意图
    if M.acr.drift(b, b_cf) > TAU_CF:
        b = M.uip.widen(b)                               # 自造意图风险 -> 放宽而非升级
    Q, mu = M.iqc.intent_quotient(b, M.policy, M.probe_set, MU_STAR)
    # 1) 证据分配：先意图、后动作
    b, modes = M.iva.allocate_evidence(b, M.last_modes, M.budget)
    if len(Q) > 1 and M.iva.intent_dominates(b):
        q = M.npd.choose_intent_probe(b, M.q_candidates, DELTA_LEAD, DELTA_ANCHOR)
        if q is not None:
            y = M.npd.execute(q)                         # 带认证 + 随机化措辞
            b = M.uip.condition(b, y); M.iq.record(q, y)
    # 2) R69 的动作层（条件于当前意图集合/最大后验）
    I_hat = argmax(b)
    U_ale, U_epi, modes, _ = M.aud.decompose(
        M.fmp.sample(o_hist, K=K_by_mode_head(M, I_hat)), M.mtm.forward(o_hist), I_hat)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_hist, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction(modes, o_hist, M.budget)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 3) 承诺门：不可逆动作必须过意图级 chance constraint
    A = M.ach.propose(..., I_hat, H=M.vista.H)
    if not M.csg.commitment_gate(A, b, M.loss, RHO_STAR, L_MAX, EPS):
        A = M.csg.safe_substitute(A)                     # defer / 可逆替代 / 再问
        lam = max(lam, 0.8)                              # 承诺门未过 -> 更保守
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 4) 审计与证书
    M.vqa_i2.submit_async(b, Q, q if 'q' in dir() else None, a_hat, delta_intent(b))
    return k, lam, mode, (b, Q, U_ale, U_epi)
```

## 3. 推导

**引理 19（意图混淆下的部署成功率）** 设真意图分布 p(I)，意图混淆矩阵 C_{ij}=P(执行 j|i)，条件成功率 S_{ij}=P(成功|执行 j,i)。则部署成功率 R_dep = Σ_i p(i) Σ_j C_{ij} S_{ij}；而按标签评测的 R_bench = Σ_i p(i) S_{ii}。故 Δ_int = R_bench − R_dep = Σ_i p(i) Σ_{j≠i} C_{ij}(S_{ii} − S_{ij})。当且仅当 C = I 时 Δ_int = 0。系：**任何非零的跨任务混淆都会让 UniBot-V1 式的排行榜系统性高估部署可靠性；任务越共享场景/物体，C 越偏离单位阵，偏差越大。**

**引理 20（意图商的可辨识上界）** 在有限交互预算 B_I 与可观测接口下，若两意图的预测观测分布 TV 距离上界为 μ_max(B_I) < μ*，则任何算法都无法以优于 1/2 + μ_max/2 的准确率区分它们；因此任何把二者分开报告的证书都存在虚假精度，且其 ECE 下界 ≥ (1−μ_max)/2·|b 的误置质量|。系：**证书必须报告意图商等价类，并对不可辨识类拒绝给点估计**——否则「意图识别」只是把噪声包装成标签。

**引理 21（非诱导约束是校准的必要条件）** 设每次有偏探询使人的表达意图向机器人假设偏移 Anchor(q) ≥ δ，重复 m 次后 b_t 的置信度单调上升，而真实准确率因共构造至多不变；则 ECE 的增长下界为 Ω(1 − exp(−mδ))。故无 Anchor/Lead 约束的主动意图识别会**制造**它随后度量的置信度；非诱导不是可选项，而是校准正确性的前提。（这也解释了 R69 为何把「问」视为双刃剑：它只防了投毒，没防自我实现。）

**引理 22（统一表示的迁移/负迁移）** 跨任务共享意图表示时，意图样本复杂度约为 N/(1−κ)（κ 为任务间语义重叠）；但若语义标定误差 ε_cal 使相关任务对的嵌入距离被高估、无关任务对被低估，则意图后验的 TV 误差增加 ≥ c·ε_cal，且当 ε_cal > ε* 时净效应为负迁移。系：**UniBot-V1 的「单模型多任务」只有在意图度量被语义标定后才可用来降低意图识别成本；否则它只是把任务先验放大成意图偏见。**

**定理 18（UNIBOT 严格包含 FLUID-RAS）** 在 A95–A99 下，若 b_t 为点 mass，则 UNIBOT-RAS 不触发意图探询、承诺门恒通过、U_epi^int=0，其主闭环与 R69 的 FLUID_RAS_round 逐指令一致；且对任意 b_t，UNIBOT 的承诺集 ⊆ R69 在「误意图执行」情形下的可行集，故安全侧不弱于 R69。**R69 是 UNIBOT 在「意图已定」边界上的退化。**

**定理 19（意图优先的证据分配最优性）** 设意图错误损失 L_int 与动作模态错误损失 L_act，且在当前后验下 ∂R/∂B_I > ∂R/∂B_A。则任意把正预算投到动作模态消歧的策略，其期望风险严格高于把该预算投到意图辨识的策略；特别地，当存在 I≠I' 使 R69 的动作 VoI 为正、但按错意图执行的最优动作期望收益为负时，**R69 的 MINT 可被证明是次优的**。系：意图不确定且损失非对称时，「先问清做什么」优先于「问清怎么做」。

## 6. 本轮最大风险

**一句话**：UNIBOT-RAS 的全部安全承诺押在「意图可辨识且后验可信」这一前提上——但意图既不可直接观测、又会被机器人自己的提问与动作**共同构造**，于是最危险的不是「识别错意图」，而是「系统通过非诱导探询把人锚定到自己猜的意图上，再把这次自我实现记成一次高置信的意图识别」；此时证书越漂亮，越可能只是在给一个被制造出来的意图盖章——**它不是在识别意图，而是在生产意图**。

**次级风险与缓解**：
1. **意图商被误报成点估计**（虚假精度）→ 定义 314/引理 20 强制报告等价类，E309 专测；
2. **统一表示负迁移放大任务先验** → 定义 326 语义标定门，ε_cal 越界即退化为单任务意图先验（E310）；
3. **非诱导约束不可直接测量** → 随机化措辞 + 反事实 b_cf + 独立第二源 + E307 人因实验（引理 21）；
4. **意图漂移被旧惯性拖住** → IRG 变点检测 + 回到 t* 前安全姿态重确认（E308）；
5. **承诺门拖垮任务效率** → 可逆替代动作 + 分级 ρ* + 与 R69 的 λ 联动，效率损失由 E306/E315 量化。

**定义 325–326（严格包含与迁移）** `b_t=δ_{I0}` 时逐指令退化为 FLUID-RAS 且安全不弱化；跨任务共享意图表示降样本至约 `N/(1−κ)`，仅在语义标定误差 `ε_cal≤ε*` 时成立，否则负迁移。

## 3. 关键算法伪代码

```python
# IP-264 UIP：意图后验（复用 UniBot-V1 主干，块边界更新）
class IntentPosterior:
    def update(self, o_hist, y_hist, a_hist):
        logits = self.trunk.intent_logits(o_hist, y_hist, a_hist)
        return self.calib.recalibrate(softmax(logits / self.calib.temperature))

# IP-272 IQC：先问「能不能辨识」，再问「识别得准不准」
def intent_quotient(b, policy, probes, mu_star):
    classes = union_find_over(b.support())
    for I, I2 in pairs(b.support()):
        if min_tv_predictive(policy, I, I2, probes) < mu_star:
            classes.merge(I, I2)
    return classes, margin(classes)          # 只报等价类

# IP-266/267 CBA+CSG：承诺门
def commitment_gate(a, b, loss, rho_star, L_max, eps):
    if rho(a) <= rho_star: return True       # 可逆：先做后问
    bad = sum(b[I] for I in b if loss(I, argmax(b)) > L_max)
    return bad <= eps                        # 否则 defer / 替代 / 提问

# IP-268 IVA：意图层 vs 动作层证据预算
def allocate_evidence(b, modes, B):
    while B > 0:
        dI = marginal_risk_drop(intent_probes(b), b)
        dA = marginal_risk_drop(action_probes(modes), modes)
        if dI >= dA: B -= spend(best(intent_probes(b))); b = update(b, best(intent_probes(b)))
        else:        B -= spend(best(action_probes(modes))); update_modes(best(action_probes(modes)))
    return b, modes

# IP-269/270 NPD+ACR：非诱导探询 + 反自造意图
def choose_intent_probe(b, qs, delta_lead, delta_anchor):
    best = None
    for q in qs:
        if lead(q) > delta_lead or anchor(q, b) > delta_anchor: continue
        if not c_ras_wm.certify_query(q): continue
        s = ivoi(q, b) - cost(q)
        if best is None or s > best.score: best = (q, s)
    return best if best and best.score > 0 else None

def anti_manufacture_guard(b, b_cf, tau_cf):
    return dist(b, b_cf) > tau_cf           # 提问把意图带偏 -> 放宽，不升级

# IP-276 主闭环（意图层在块边界；动作层继承 R69）
def UNIBOT_RAS_round(M, o_hist, a_hist, y_hist):
    b    = M.uip.update(o_hist, y_hist, a_hist)
    b_cf = M.acr.counterfactual(b)
    if M.acr.drift(b, b_cf) > TAU_CF: b = M.uip.widen(b)
    Q, mu = M.iqc.intent_quotient(b, M.policy, M.probe_set, MU_STAR)
    b, modes = M.iva.allocate_evidence(b, M.last_modes, M.budget)
    if len(Q) > 1 and M.iva.intent_dominates(b):
        q = M.npd.choose_intent_probe(b, M.q_candidates, DELTA_LEAD, DELTA_ANCHOR)
        if q is not None: b = M.uip.condition(b, M.npd.execute(q))
    I_hat = argmax(b)
    U_ale, U_epi, modes, _ = M.aud.decompose(
        M.fmp.sample(o_hist, K_by_mode_head(M, I_hat)), M.mtm.forward(o_hist), I_hat)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_hist, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = M.mint.choose_interaction(modes, o_hist, M.budget) if (U_epi > TAU_EPI and not slow) else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(..., I_hat, H=M.vista.H)
    if not M.csg.commitment_gate(A, b, M.loss, RHO_STAR, L_MAX, EPS):
        A = M.csg.safe_substitute(A); lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i2.submit_async(b, Q, a_hat, delta_intent(b))
    return k, lam, mode, (b, Q, U_ale, U_epi)
```

## 4. 推导

**引理 19（意图混淆下的部署成功率）** `R_dep=Σ_i p(i)Σ_j C_{ij}S_{ij}`，基准报告 `R_bench=Σ_i p(i)S_{ii}`，故 `Δ_int=Σ_i p(i)Σ_{j≠i}C_{ij}(S_{ii}−S_{ij})`；`Δ_int=0 ⇔ C=I`。系：任务越共享场景/物体，C 越偏离单位阵，UniBot-V1 式排行榜越系统性高估部署可靠性。

**引理 20（意图商的可辨识上界）** 预算 B_I 内预测观测 TV 上界 `μ_max<μ*` 时，任何算法区分两类意图的准确率 ≤ `1/2+μ_max/2`；把二者分开报告即虚假精度，其 ECE 下界随误置质量线性增长。系：证书必须报意图商等价类，对不可辨识类拒绝点估计。

**引理 21（非诱导是校准的必要条件）** 每次有偏探询使表达意图偏移 `Anchor≥δ`，重复 m 次后置信度单调升而真实准确率至多不变，ECE 增长下界 `Ω(1−e^{−mδ})`。故无 Anchor/Lead 约束的主动意图识别会**制造**它随后度量的置信度；R69 只防了投毒，没防自我实现。

**引理 22（统一表示的迁移与负迁移）** 共享意图表示使样本复杂度约降为 `N/(1−κ)`；但语义标定误差 `ε_cal` 会把相关任务拉远、无关任务拉近，后验 TV 误差增加 ≥ `c·ε_cal`，`ε_cal>ε*` 时净效应为负迁移。系：「单模型多任务」只有在意图度量语义标定后才降低意图识别成本，否则只是把任务先验放大成意图偏见。

**定理 18（UNIBOT 严格包含 FLUID-RAS）** A95–A99 下，`b_t` 为点 mass 时不触发意图探询、承诺门恒通过、`U_epi^int=0`，主闭环与 `FLUID_RAS_round` 逐指令一致；对任意 `b_t`，UNIBOT 的承诺集 ⊆ R69 在误意图情形下的可行集，安全侧不弱于 R69。**R69 = 意图已定边界。**

**定理 19（意图优先证据分配最优性）** 若 `∂R/∂B_I > ∂R/∂B_A`，则把正预算投到动作模态消歧的策略期望风险严格更高；特别地，存在 `I≠I'` 使 R69 的动作 VoI 为正、但按错意图执行的最优动作期望收益为负时，**R69 的 MINT 可被证明次优**。系：意图不确定且损失非对称时，「先问清做什么」优先于「问清怎么做」。

## 7. 本轮最大风险

**一句话**：UNIBOT-RAS 的全部安全承诺押在「意图可辨识且后验可信」这一前提上——但意图既不可直接观测、又会被机器人自己的提问与动作**共同构造**，于是最危险的不是「识别错意图」，而是「系统通过非诱导探询把人锚定到自己猜的意图上，再把这次自我实现记成一次高置信的意图识别」；此时证书越漂亮，越可能只是在给一个被制造出来的意图盖章——**它不是在识别意图，而是在生产意图**。

**次级风险与缓解**：意图商被误报成点估计（定义 314/引理 20 强制报告等价类，E309）；统一表示负迁移放大任务先验（定义 326 语义标定门，E310）；非诱导约束不可直接测量（随机化措辞 + 反事实 b_cf + 独立第二源 + E307）；意图漂移被旧惯性拖住（IRG 变点检测 + 回到 t* 前重确认，E308）；承诺门拖垮效率（可逆替代 + 分级 ρ* + 与 R69 λ 联动，E306/E315）。
