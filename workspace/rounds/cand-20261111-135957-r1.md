# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「评测基准」×「示教学习」）

> 前 54 轮把能力、鲁棒性、动作空间逐层证书化：`ρ`（鲁棒性谱）、`α_S`（动作剖面）、`J`（动作-鲁棒性联合证书）、`γ_ce`（云边映射）。但证书塔有两处未被追问的地基：**(1) 技能与 `α_S` 从何而来**——来自人类示教，而示教天然有偏、稀疏、覆盖不全；**(2) 证书为何可信**——现有评测只报任务成功率，无法区分“证书真对”与“任务碰巧简单”。本轮核心矛盾：**H22**：`α_S` 在未示教区是外推幻觉，证书 soundness 在该区无证据；**H23**：缺少能主动证伪证书的评测基准，证书可能“过拟合”评测而系统性高估安全性。

## 0. 直觉与动机

**灵感 1（示教支撑集 → 动作剖面的“有证据区”）**
直觉：示教不是万能钥匙，而是证书的地基。把动作空间分成两半：`supp(D_S)`（有示教证据的支撑集）与其外部（外推区）。`α̂_S` 只在 `supp` 上有置信，外部应标记为“不可知”而非“可行”。证书 `J` 的 soundness 只在 `supp` 内可主张。**未示教区不是假设，而应是一个可报告的量。**

**灵感 2（证书基准化 → 从“比成功率”到“比证书不撒谎”）**
直觉：现有 benchmark 比拼任务成功率，会把“证书正确”和“任务简单”混为一谈。新基准直接测 **证书校准**：证书预测成功而实际失败（假阳性）与预测失败而实际成功（假阴性）的比例。**证书基准不是比谁成功率高，而是比谁的证书不撒谎。**

**灵感 3（对抗示教 → 主动制造证书反例）**
直觉：好的基准不是被动打分，而是主动搜索“证书高置信成功、实际却失败”的**分布内**反例——且必须留在示教分布内，否则反例不可用于改进，只会退化为随机攻击。这给了基准一个“证伪引擎”。

**灵感 4（主动示教采集 → 用证书不确定性驱动示教）**
直觉：示教样本昂贵。应把示教预算花在证书最不确定、且位于支撑边界 `∂supp` 的状态上。这形成闭环：`示教 → 学技能 → 发证书 → 基准证伪 → 针对性补示教`，把评测从“判卷人”变成“共同设计者”。

**灵感 5（评测基准的层级扩展 → 迁移层基准）**
直觉：同一证书跨示教者、跨本体会发生 **support 漂移** 与 **校准漂移**。基准应分层：`𝔹_0` 任务成功率、`𝔹_1` 证书校准、`𝔹_2` 示教支撑充分性、`𝔹_3` 跨示教者/本体迁移。跨层报告必须显式区分“证据内”与“证据外”。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（示教数据集与支撑集）**
示教数据集 `D_S = {τ_1,...,τ_m}`，轨迹 `τ_i = (s_0,a_0,s_1,...,s_T)`，转移点 `x=(s,a)`。以核密度 `K̂_D(x)` 定义 **示教支撑集** `supp_ε(D_S) = {x : K̂_D(x) ≥ ε}`。**经验动作剖面** `α̂_S(x) = clip(K̂_D(x)/K_max, 0, 1)`，并附 **置信下界** `α̂_S^-(x) = wilson_lower(n(x), N)`。仅当 `x∈supp_ε` 时称 `α̂_S(x)` **有证据**。

**定义 122（示教充分性与证书条件有效性）**
示教充分性 `suff(D_S, A_T) = |A_T ∩ supp_ε(D_S)| / |A_T|`。证书 `J` 在任务 `T` 上 **条件有效**，当且仅当
```
suff(D_S,A_T) ≥ θ_s  ∧  ∀ x∈A_T∩supp_ε: α̂_S^-(x) ≥ θ_cov
```
即“覆盖足够 + 覆盖区置信足够”。支撑外的部分不计入有效域，只计入“不可知质量”。

**定义 123（评测基准三元组）**
评测基准 `B = (D, 𝒯, F)`：
- `D` 为（多示教者）示教分布；
- `𝒯` 为任务分布，含按 `D` 构造的分布内对抗任务；
- `F : Cert × 𝒯 → 2^{X}` 为 **反例生成器**，在 `D` 的分布内搜索证书的假阳性/假阴性反例。
基准输出 `(cal, FPR, FNR, out_support_mass)` 四元组。

**定义 124（证书校准误差）**
证书预测分数 `ŷ_J(x)∈[0,1]`，实测结果 `y(x)∈{0,1}`。分 `n_bins` 个区间，校准误差
```
ECE(J,B) = Σ_b (|B_b|/N) · |mean_{x∈B_b} y(x) - mean_{x∈B_b} ŷ_J(x)|
```
并记 `FPR = P(ŷ_J≥0.5, y=0)`，`FNR = P(ŷ_J<0.5, y=1)`。证书基准的排序键为 `(FPR↓, ECE↓)`，而非单看成功率。

**定义 125（对抗示教反例与证伪率）**
分布内反例 `x* = argmax_{x∈supp_ε(D)} [ ŷ_J(x) - y(x) ]_+`。证伪率 `fals(J,B) = 1` 当且仅当 `F` 在预算内返回至少一个 `ŷ_J≥0.5 ∧ y=0` 的 `x*`。**假阳性反例优先**：证书高置信成功而实际失败，是安全性的直接反例；假阴性只影响效率。

**定义 126（示教-证书闭环）**
闭环 `Loop = (Learn, Certify, Falsify, Teach)`。主动示教查询
```
x_q = argmax_{x∈∂supp_ε(D)} u_cert(x)
```
其中 `u_cert(x)` 为证书在 `x` 处的预测不确定性（集成方差或分类间隔）。收敛判据：`ECE(J_t,B) < ε_cal` 且 `fals(J_t,B)=0`，或示教预算耗尽；否则把反例邻域加入 `D`，重入 `Learn`。

## 2. 关键算法 伪代码

### IP-121 DSR（Demonstration Support Reasoner）

```python
def demo_support(demos, eps, kappa):
    counts, total = defaultdict(float), 0.0
    for tau in demos:
        for x in tau.transitions():
            w = kappa(x)                 # 示教者可信度 / 轨迹权重
            counts[x] += w
            total += w
    supp = {x for x, c in counts.items() if c >= eps}
    alpha_hat, alpha_lo = {}, {}
    for x, c in counts.items():
        p = c / max(total, 1e-9)
        alpha_hat[x] = clip(p / max(p_max(counts), 1e-9), 0, 1)
        alpha_lo[x]  = wilson_lower(c, total)
    return SupportSet(supp, alpha_hat, alpha_lo)

def is_sufficient(sup, A_T, theta_s=0.85):
    return len(A_T & sup.supp) / max(len(A_T), 1) >= theta_s
```

### IP-122 CBF（Certificate Benchmark & Falsification）

```python
def falsify_certificate(cert, benchmark, budget):
    false_pos, false_neg = [], []
    for _ in range(budget):
        x = benchmark.sample_in_distribution()   # 关键：留在示教分布内
        y_hat = cert.predict(x)
        y = benchmark.rollout(x)
        if y_hat >= 0.5 and y == 0:
            false_pos.append(x)                  # 证书说成功，实际失败
        elif y_hat < 0.5 and y == 1:
            false_neg.append(x)
    return FalsifyReport(false_pos, false_neg,
                         fpr=len(false_pos) / budget,
                         fnr=len(false_neg) / budget)
```

### IP-123 CAL（Certificate Calibration Loss）

```python
def calibration_error(cert, benchmark, n_bins=10):
    bins = defaultdict(list)
    for _ in range(benchmark.N):
        x = benchmark.sample_in_distribution()
        b = min(int(cert.predict(x) * n_bins), n_bins - 1)
        bins[b].append(benchmark.rollout(x))
    ece = 0.0
    for b, ys in bins.items():
        if ys:
            ece += len(ys) / benchmark.N * abs(mean(ys) - (b + 0.5) / n_bins)
    return ece
```

### IP-124 ATC（Active Teaching Curriculum）

```python
def active_teaching(cert, support, human, budget_q):
    queried = []
    for _ in range(budget_q):
        x_q = max(support.boundary(), key=lambda x: cert.uncertainty(x))
        tau = human.demonstrate(x_q)      # 人在支撑边界处示教
        support.update(tau)
        queried.append((x_q, tau))
    return queried, support
```

### IP-125 TCL（Teach-Cert Loop）

```python
def teach_cert_loop(task, demos, benchmark, budgets):
    for _ in range(budgets['rounds']):
        skills = lfd_learn(demos)                    # 示教学习得到技能
        cert = certify_v31(skills, task)             # 复用第 54 轮证书 J
        sup = demo_support(demos, budgets['eps'], budgets['kappa'])
        if not is_sufficient(sup, task.action_set):
            x_q = max(sup.boundary(), key=cert.uncertainty)
            demos.append(collect_human_demo(x_q))    # 先补覆盖
            continue
        rep = falsify_certificate(cert, benchmark, budgets['falsify'])
        if not rep.false_pos and not rep.false_neg:
            return ('deploy_with_evidence', cert, sup, rep)
        demos.extend(targeted_demos(rep))            # 针对反例补示教
    return ('reject', 'cert_unfalsifiable_in_budget')
```

### IP-126 XDB（Cross-Demonstrator Benchmark）

```python
def cross_demo_benchmark(cert, demos_by_teacher, retarget_fn):
    scores = {}
    for t_id, demos in demos_by_teacher.items():
        sup = demo_support(demos)
        cert_t = retarget_fn(cert, t_id)             # 跨示教者/本体重定向
        bench_t = make_bench(demos)
        scores[t_id] = {
            'suff': len(cert_t.action_set & sup.supp)
                    / max(len(cert_t.action_set), 1),
            'ece': calibration_error(cert_t, bench_t),
            'supp_drift': jaccard(sup.supp, cert_t.support_ref),
        }
    return scores   # 报告 support 漂移与校准漂移，而非单一成功率
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DSR | O(|D|·L) | O(|supp|) | 核带宽 ε、示教权重 κ |
| CBF | O(N·(cost(rollout)+cost(predict))) | O(N) | 分布内采样、rollout 保真 |
| CAL | O(N·|J|/n_bins) | O(n_bins) | 分箱数、样本量 |
| ATC | O(q·(|∂supp|+cost(demo))) | O(q) | 边界查询、人在环延迟 |
| TCL | O(R·(LfD+CBF+ATC)) | O(|D|+|supp|) | 闭环收敛、反例覆盖 |
| XDB | O(T·(|D|+|supp|+N)) | O(T·|supp|) | 重定向保真、漂移可度量 |

**正确性定理（Certificate Validity under Demonstration Support）**
假设 (A26)–(A28) 承接第 54 轮；**(A29)** 支撑集密度估计一致：`P(supp_ε Δ supp_true) ≤ ε_s`；**(A30)** 反例生成器 `F` 在示教分布内 i.i.d. 采样 `N` 次，rollout 无偏；**(A31)** 主动示教查询在 `∂supp` 上局部 Lipschitz，人类示教延迟 ≤ τ_h。
则对任意证书 `J` 与任务 `T`：
```
P(J 在 T 上 sound) ≥ 1 - ε_s - P(A_T \ supp_ε) - exp(-2Nε²)
```
且基准估计 FPR 与真实 FPR 的偏差满足 Hoeffding 界：
```
P(|FPR_hat - FPR_true| > ε) ≤ 2·exp(-2Nε²)
```
关键：证书 soundness 被显式拆为 **支撑内误差 + 支撑外不可知 + 基准采样误差** 三项——把“未示教区”从隐性假设变成可报告的量，并给出基准置信区间。**证书不再无条件是“真”，而是“在给定示教证据与采样预算下可真”。**

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 支撑集估计 | `IoU(supp_ε, supp_true)` | ≥ 0.85 |
| E163 证书校准 | `ECE / FPR / FNR` | ECE ≤ 0.05，FPR ≤ 3% |
| E164 对抗证伪率 | 分布内假阳性反例发现率 | ≥ 80% within budget |
| E165 主动示教效率 | 达 `ECE<ε` 所需示教数 vs 随机 | 样本减少 ≥ 40% |
| E166 跨示教者迁移 | support/cal 漂移 | `ECE` 漂移 ≤ 0.08 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 高维示教支撑集稀疏，估计不可靠 | 高 | 流形降维 + 分层核密度 + 置信区间报告 |
| 反例生成器分布内采样过弱 | 高 | 对抗采样 + 边界聚焦 + 覆盖审计 |
| 主动示教引发人类疲劳/噪声 | 中 | 单轮小批量 + 置信加权 + 疲劳预算 |
| 证书过拟合基准（Goodhart） | 高 | 留出示教者/任务测试集 + 定期换基准种子 |
| 跨示教者风格漂移 | 中 | 每示教者独立支撑集 + 漂移告警 + 重定向校准 |

## 6. 本轮最大风险

**一句话**：示教-证书基准把评测从“比成功率”升级为“比证书不撒谎”，但其 soundness 与判别力**双重依赖示教支撑集估计的可信度与反例生成器的分布内覆盖**；一旦支撑集是外推幻觉、或证伪器只在易区分区域搜索，证书就会系统性“过拟合基准”，制造一种“已被评测验证”的虚假安全感——故必须以 **支撑集置信区间显式报告 + 分布内对抗覆盖审计 + 留出示教者/任务盲测** 三重护栏，宁可诚实标注“证据外不可知”，绝不把基准的通过当作安全的证明。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim⁺⁺⁺⁺（DSR×CBF×CAL×ATC×TCL×XDB）

> 承接第 54 轮产物 v31。本轮把证书体系缺失的 **地基（示教）** 与 **裁决（评测基准）** 补齐：
> - **DSR（Demonstration Support Reasoner）**：示教支撑集 `supp_ε(D_S)` 与带置信的经验动作剖面 `α̂_S`；
> - **CBF（Certificate Benchmark & Falsification）**：分布内反例生成，主动证伪证书假阳性/假阴性；
> - **CAL（Certificate Calibration Loss）**：证书校准误差 `ECE / FPR / FNR`，取代单一成功率；
> - **ATC（Active Teaching Curriculum）**：证书不确定性驱动的主动示教采集；
> - **TCL（Teach-Cert Loop）**：`示教→证书→证伪→再示教` 闭环；
> - **XDB（Cross-Demonstrator Benchmark）**：跨示教者/本体的 support 漂移与校准漂移基准。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118/120 以纳入示教支撑集与校准维度。

```python
            return ('deploy_with_evidence', cert, sup, rep)
        demos.extend(targeted_demos(rep))
    return ('reject', 'cert_unfalsifiable_in_budget')
```

```python
def cross_demo_benchmark(cert, demos_by_teacher, retarget_fn):
    scores = {}
    for t_id, demos in demos_by_teacher.items():
        sup = demo_support(demos)
        cert_t = retarget_fn(cert, t_id)

                    / max(len(cert_t.action_set), 1),
            'ece': calibration_error(cert_t, bench_t),
            'supp_drift': jaccard(sup.supp, cert_t.support_ref),
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DSR | O(|D|·L) | O(|supp|) | 密度估计一致，置信下界保守 |
| CBF | O(N·(cost(rollout)+cost(predict))) | O(N) | 分布内采样，rollout 无偏 |
| CAL | O(N·|J|/n_bins) | O(n_bins) | 分箱无偏，样本量足够 |
| ATC | O(q·(|∂supp|+cost(demo))) | O(q) | 边界查询 Lipschitz，人在环延迟有界 |
| TCL | O(R·(LfD+CBF+ATC)) | O(|D|+|supp|) | 闭环单调收敛或预算终止 |
| XDB | O(T·(|D|+|supp|+N)) | O(T·|supp|) | 重定向保真，漂移可度量 |

**正确性定理（Certificate Validity under Demonstration Support）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `P(supp_ε Δ supp_true) ≤ ε_s`；**(A30)** `F` 在示教分布内 i.i.d. 采样 `N` 次且 rollout 无偏；**(A31)** 主动示教查询在 `∂supp` 上局部 Lipschitz，人类示教延迟 ≤ τ_h。
则对任意证书 `J` 与任务 `T`：
```
P(J 在 T 上 sound) ≥ 1 - ε_s - P(A_T \ supp_ε) - exp(-2Nε²)
P(|FPR_hat - FPR_true| > ε) ≤ 2·exp(-2Nε²)
```
关键：证书 soundness 被显式拆为 **支撑内误差 + 支撑外不可知 + 基准采样误差**，使“未示教区”成为可报告项，而非隐性假设。

## 5. 本轮最大风险

**一句话**：示教-证书基准把评测从“比成功率”升级为“比证书不撒谎”，但其 soundness 与判别力**双重依赖示教支撑集估计的可信度与反例生成器的分布内覆盖**；一旦支撑集是外推幻觉、或证伪器只在易区分区域搜索，证书就会系统性“过拟合基准”，制造一种“已被评测验证”的虚假安全感——故必须以 **支撑集置信区间显式报告 + 分布内对抗覆盖审计 + 留出示教者/任务盲测** 三重护栏，宁可诚实标注“证据外不可知”，绝不把基准的通过当作安全的证明。
