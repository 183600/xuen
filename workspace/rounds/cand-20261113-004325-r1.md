# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「多机器人协作」×「开放词汇」）

> 第 62 轮把单机闭环做成「在线可学、偏差免疫可证、场景自驱生长」。但它仍默认两个隐含前提：(i) **世界只有一台机器人**——RSC 的球、WCV 的编译、ARA 的锚点全是「我」的，其他智能体要么是环境噪声、要么不存在；(ii) **语义空间是封闭词表**——USR/MEL 只在训练过的类别与固定物理标签上工作，遇到「半透明、像玻璃但按下去发软」这种自由语言描述，系统没有接地点，只能退化到最保守基线。这两个前提在真实部署中同时崩塌：多机团队要用自然语言临时分工、互相借用对陌生物体的经验，而陌生物体恰恰没有标签。
>
> 更尖锐的是：第 62 轮的最大风险是「RSC 覆盖失效 → 纸面保证」。多机协作会把这一风险**放大成系统性风险**：单机的错误是局部的；一旦错误概念通过共享词表扩散，全队会「一致地自信地错」。本轮要回答的不是「再加一个模块」，而是一个结构性问题：**当不确定性既来自开放词汇的语义鸿沟、又来自跨具身/跨智能体的分布差异时，如何让协作只降低「可降的」不确定性，而绝不把「共同模式错误」融合成虚假的确定性？**

## 0. 直觉与动机

**灵感 1（开放词汇 → OVC：带不确定球的语义-物理接地）**
直觉：开放词汇不是「识别更多类别」，而是「承认没见过的词必然带着更大的不确定球」。把语言概念 c 经 VLM 映射为嵌入 e(c)，已知概念上标定好物理后验；新概念 c' 只要在嵌入空间离某个已知概念 c 近（距离 δ），就按接地映射的量化 Lipschitz 常数 L_G **继承**后验，但球半径必须膨胀 r(c') ≥ r(c) + L_G·δ。于是「开放词汇」被翻译成第 62 轮已经能处理的量：**一个更大的 r_t**。未知不再是崩溃，而是 WCV 自动收紧护栏。

**灵感 2（多机器人协作 → CSL：无中心的共享概念织物）**
直觉：让每台机器人把「概念—物理后验—来源—信任」作为可合并的节点发布到共享织物（CRDT，无中心、可分区、最终一致）。A 见过的物体，B 不必从零学；B 的具身不同，则通过迁移算子 T_AB 折算。协作的本质是**证据池化**，但证据池化只有在误差独立时才缩小方差——这直接引出本轮的命门。

**灵感 3（跨具身 → CET：迁移残差必须显式入球）**
直觉：A 的夹爪测得 μ=0.6，不代表 B 的吸盘也适用。把迁移写成 φ_B = T_AB(φ_A) + ε，且 ‖ε‖ ≤ γ_AB；γ_AB 由双机共同标定的配对样本估计。B 的球 = A 的球 + γ_AB。**迁移永远只敢加半径，不敢减半径**——这是「协作不会让安全变差」的最小充分条件。

**灵感 4（鲁棒融合 → TBF：拜占庭鲁棒 + 共同模式地板）**
直觉：N 台机器人报估计与球，用截尾均值/中位数-of-means 抗 f 个恶意或故障节点；但更关键的是加一条**共同模式地板 r_cm**：所有机器人共享同一个 VLM 先验，语义错误是**相关**的，融合只能压掉独立噪声，压不掉共同偏差。因此 r_fused = max(robust_statistic, r_cm)。协作可以更准，但不许把「大家一起错」融合成「大家都很确定」。

**灵感 5（联合安全 → JSS：把队友的不确定可达集当虚拟障碍）**
直觉：第 62 轮的 Shield 只保护「我不撞静态不安全边界」；多机还要保护「我不撞队友，且队友的球也在我考虑内」。把每台机器人未来的可达集按自身 r_j 与通信陈旧度膨胀，作为对方的虚拟障碍塞进 WCV 的约束；只要配对约束线性（CBF/时空预约），联合安全集仍凸，Shield 的投影不动点性质原样保留。

**灵感 6（开放词汇协作 → DCL + CTA：会问、会教、会分派）**
直觉：开放词汇下「不懂就问」是能力不是缺陷。DCL 把 DMS 扩展为 ask（请求澄清/示范）、teach（把概念节点连同来源与信任教给队友）、confirm（执行前确认接地）；CTA 则按「概念不确定球 × 任务风险 + 迁移代价」拍卖分派——把最陌生的物体交给对它最有把握（球最小）的机器人。

**灵感 7（合流 → FABRIC：联邦自适应信念接地协作闭环）**
四层咬合：OVC 回答「这个词是什么」（语义鸿沟 → 膨胀球）；CSL 回答「谁还知道」（证据池化）；CET + TBF 回答「能不能信、信多少」（迁移残差 + 拜占庭鲁棒 + 共同模式地板）；JSS + CTA + DCL 回答「一起怎么安全地干」。第 62 轮 ROSE 是「单机的学习-鲁棒闭环」，FABRIC 是「团队的语言-信念-安全闭环」，且单机退化路径完整保留。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（联邦自适应信念接地协作闭环 FABRIC）**：FABRIC = ({ROSE_i}ᵢ, OVC, CSL, CET, TBF, SCG, JSS, CTA, DCL, J_fabric)。定位：ROSE 的「多智能体 × 开放词表」升级；单机组件接口不变，新增跨智能体/跨词表层。
- **定义 186（开放词汇接地 OVC）**：概念图 g = (实体, 属性槽, 关系, 否定)，规范化为文本后 e = VLM(g)；接地映射 G: ℝ^{d_v} → 𝒫(Φ)。已知概念集带标定后验 {(φ̂_c, r_c)}；新概念 c 取最近邻 c_nn 与嵌入距离 δ，输出 Grounding(c_nn, φ̂, r_sem, δ, g)。
- **定义 187（协作语义织物 CSL）**：节点 n = (concept_id, e, φ̂, r, provenance, trust, evidence OR-set, version)；合并为 LWW-register + OR-set 的 CRDT，满足交换/结合/幂等（ACI），支持分区与最终一致。
- **定义 188（语义覆盖球 SCG）**：r_sem(c) = r(c_nn) + L_G·δ；r(c) = max(r_sem, r_cm)。L_G 为量化 Lipschitz 常数（A77）；r_cm 为共同模式地板，由视觉-触觉跨模态残差估计，任何融合不得低于它。
- **定义 189（跨具身迁移 CET）**：φ_B = T_AB(φ_A) + ε，‖ε‖ ≤ γ_AB；r_B = Lip(T_AB)·r_A + γ_AB。γ_AB 由双机对同一物体的配对标定估计，迁移只增不减。
- **定义 190（信任加权鲁棒融合 TBF）**：reports = {(φ_i, r_i, trust_i)}；保留信任最高的 N−f 份，φ_f = trimmed_mean；r_f = max(robust_stat + β√(log(1/δ)/m), r_cm)。trust 由「与本地执行残差的一致性」在线更新。
- **定义 191（联合空间安全屏蔽 JSS）**：𝒞_joint = 𝒞_safe ∩ ⋂_{j≠i}{dist(R_i(K_i), inflate(R_j(K_j), r_j + staleness·v_max)) ≥ d_safe}；R(·) 为 horizon H 的可达集外近似，线性化后仍为凸约束交集。
- **定义 192（概念感知任务分配 CTA）**：cost(i,t) = λ_r·r_i(t.concept)·risk(t) + λ_d·travel(i,t) + λ_γ·γ_{i,src(t.concept)}；分配解 minimize Σ cost。线性代价下拍卖算法给 ε-最优，且可用二价规则逼近策略诚实。
- **定义 193（协作对话协议 DCL）**：状态 {ask, teach, confirm, act}；r > τ_ask ∨ OOD ⇒ ask；队友概念球更小 ⇒ 请求 teach；risk > τ_confirm ⇒ confirm；一切由教学概念导出的约束必须携带 provenance，trust < τ_trust 时 Shield 保守降级。
- **定义 194（协作联合证书 J_fabric）**：J_fabric = (J_rose, fabric_ver, provenance_hash, trust_vec, r_sem, r_cm, r_transfer, joint_margin)。Valid ⇔ Valid(J_rose) ∧ provenance_verified ∧ joint_margin ≥ 0 ∧ min(trust_vec) ≥ τ_trust ∧ r_fused ≥ r_cm。
- **定义 195（FABRIC 闭环算子）**：语义流执行 [接地 OVC → 拉取 CSL → 迁移 CET → 融合 TBF → 地板 SCG → 与 ROSE 球取并 → 分派 CTA → 联合屏蔽 JSS → ROSE 实时派发 → 执行回传 → 发布/教学 DCL]；实时流仍零学习写，只在派发前增加「队友虚拟障碍」约束。
- **定义 196（共同模式失效与语义传染）**：共同模式偏差 b_cm 为团队共享 VLM 先验导致的、跨机相关的物理后验偏差；语义传染为错误概念沿 provenance DAG 传播。约束：r_fused ≥ ‖b_cm‖ 的在线估计；节点被本地触觉反证超过阈值即标 disputed，trust 沿 DAG 衰减并隔离出融合。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# OVC + SCG：开放词汇 -> 继承后验 + 只增不减的球 + 共同模式地板
e = VLM(c); c_nn, delta = lexicon.nearest(e)
phi0, r0 = lexicon.posterior(c_nn)
r = max(r0 + L_G*delta, r_cm)                 # 语义覆盖球
# CET + TBF：跨具身迁移与拜占庭鲁棒融合
phi_B, r_B = T_AB(phi_A), Lip(T_AB)*r_A + gamma_AB
phi_f = trimmed_mean(top_trust(reports, N-f))
r_f = max(robust_stat(reports) + beta*sqrt(log(1/delta)/m), r_cm)
# JSS + CTA + DCL：联合屏蔽、概念感知分派、会问会教
C_joint = C_safe & {dist(R_i(K_i), inflate(R_j(K_j), r_j+stale*v)) >= d_safe}
i* = argmin_i [ lam_r*r_i(c)*risk + lam_d*travel + lam_gamma*gamma ]
if r(c) > TAU_ASK: ask_clarify(c)             # 不懂就问，不赌
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（语义覆盖）**：若接地满足量化 Lipschitz（A77），则新概念 c 的真实物理参数以概率 ≥1−α 落在 B(φ̂(c_nn), r(c_nn)+L_G·δ) 内——开放词汇的未知被「继承 + 膨胀」而非被忽略。
- **引理 2（迁移膨胀）**：若 φ_B* = T_AB(φ_A*)+ε 且 ‖ε‖≤γ_AB，则 A 的球经 T_AB 映射后加 γ_AB 覆盖 B 的真实参数；迁移只增加保守性。
- **引理 3（鲁棒融合 + 共同模式地板）**：N≥3f+1 时，截尾均值对 f 个拜占庭节点鲁棒，融合误差 ≤ 诚实节点最大球 + 统计项；但共同模式偏差 b_cm 不被融合消除，故必须 r_f ≥ r_cm，否则融合会制造虚假确定性。
- **定理 1（协作覆盖与联合安全）**：在 A77–A82 下，每台机器人的真实参数被自身球覆盖概率 ≥1−α_i；所有机器人派发的 K_safe 投影到 𝒞_joint 后，两两碰撞在球内为不可能事件，舰队安全概率 ≥1−Σα_i。
- **定理 2（协作不劣化 / 优雅退化）**：织物不可用或全体队友失信时，FABRIC 退化为 ROSE（r_i 取本地 RSC 半径、JSS 无队友项、CTA 退化为自分配），第 62 轮全部保证原样成立；且融合半径恒 ≥ r_cm，故协作永远不能宣称比共同模式证据更小的不确定性。
- **分配保证**：CTA 为线性代价指派，拍卖算法给 ε-最优；二价/VCG 变体抑制虚报不确定性的套利（机制设计备注）。

## 5. 本轮最大风险

**一句话**：若语义-物理接地不满足量化 Lipschitz（相似词 ≠ 相似物理），且多机共享同一 VLM 先验使语义错误高度相关，则 TBF 会把共同模式偏差当作可融合噪声压小，球半径跌破真实共同偏差——「共识」变成「共错」，协作把单机局部错误放大为全队系统性失效；SCG 的 L_G 与 r_cm 是全部协作安全论证共同依赖的单点假设。

## 2. 形式化定义（完整版）

**定义 185（联邦自适应信念接地协作闭环 FABRIC）** FABRIC 是 ROSE 的多智能体升级：每台机器人保留完整 ROSE 实例 ROSE_i，并在其语义流上挂载五个跨智能体组件（OVC、CSL、CET、TBF、SCG）与三个协作算子（JSS、CTA、DCL）。不变式：
1. **单机安全优先**：任何跨机信息只能通过「只增不减」的半径进入本地球，绝不允许以协作之名缩小本地不确定球到 r_cm 以下。
2. **实时流零学习写**（继承 A75）：跨机通信与概念合并只发生在语义流/低频线程；实时流仅读取本地锚点、融合后的 (φ̂, r) 与队友虚拟障碍。
3. **可退化**：织物失联时 FABRIC_i ≡ ROSE_i。

**定义 186（开放词汇接地 OVC）** 给定短语 c，组合式解析得概念图 g = (实体, 属性槽, 关系, 否定)，规范化为文本后 e = VLM(g)。设织物中已知概念集 K = {(c_k, φ̂_k, r_k)}。取最近邻 c_nn = argmin_{c_k∈K} ‖e(c) − e(c_k)‖，δ = ‖e(c) − e(c_nn)‖。输出：
`Grounding = (c_nn, φ̂_nn, r_sem = r_nn + L_G·δ, δ, g, ood_flag)`
其中 OOD 判定 `ood_flag = 1[δ > δ_ood]`。属性槽支持组合继承：`r_sem(g) = max_slot (r_nn(slot) + L_G·δ(slot))`，取最保守槽。

**定义 187（协作语义织物 CSL）** 织物是节点的多重集，节点 n = (concept_id, e, φ̂, r, provenance, trust, evidence, version)。合并算子 ⊔ 满足 ACI：
- `φ̂, r, version`：LWW-register，按 (version, origin_id) 全序取胜者；
- `evidence`：OR-set，只增不删（审计需要）；
- `trust`：G-counter 式增量合并，避免删除竞态。
任意两台机器人经有限次 gossip 后收敛到同一状态（CRDT 定理）。节点分三类：`local`（本地接地）、`taught`（他机教学）、`disputed`（被本地触觉反证）。

**定义 188（语义覆盖球 SCG）** `r_sem(c) = r(c_nn) + L_G·δ(c)`，`r(c) = max(r_sem(c), r_cm)`。L_G 为量化 Lipschitz 常数：`Q_{1−α}(G(e)) ≤ Q_{1−α}(G(e')) + L_G‖e−e'‖`（A77）。r_cm 由「视觉-触觉跨模态残差」估计：视觉语言先验与触觉独立，二者对同一物体的物理参数分歧给出共同模式偏差的经验下界，取高分位数。SCG 的输出直接与 RSC 的执行球取并：`r_i ← max(r_i^RSC, r_sem, r_cm)`。

**定义 189（跨具身迁移 CET）** 具身 A、B 对同一物体的物理参数满足 `φ_B = T_AB(φ_A) + ε`，`‖ε‖ ≤ γ_AB`。T_AB 由双机配对校准样本学习（仿射/归一化流），`γ_AB` 取配对残差的高分位数。迁移规则：
`(φ_B, r_B) = (T_AB(φ_A), Lip(T_AB)·r_A + γ_AB)`。
性质：若 T_AB 为恒等（同构型），γ_AB 退化为传感器差；跨构型时 γ_AB 单调增大——**迁移只增加保守性**。

**定义 190（信任加权拜占庭鲁棒融合 TBF）** 机器人 i 收到 reports = {(φ_j, r_j, trust_j)}（含本地）。设至多 f 个拜占庭/故障节点，N ≥ 3f+1。融合：
1. 取 `trust` 最高的 N−f 份；
2. 对每个参数坐标取截尾均值（去掉最高/最低 f 个）得 φ_f；
3. `r_f = max(max_{kept} r_j + β√(log(1/δ)/m), r_cm)`。
trust 更新：`trust_j ← (1−η_t)trust_j + η_t·exp(−‖φ_j − φ_i^resid‖²/σ_t²)`，其中 φ_i^resid 为本地执行残差反演得到的参数证据（RSC）。**关键**：截尾均值只压独立噪声，共同模式偏差 b_cm 在所有诚实节点中相同、无法被截尾消除，故 `r_f ≥ r_cm` 是硬约束；违反它等于把「大家一致地错」当成「大家都很确定」。

**定义 191（联合空间安全屏蔽 JSS）** 对机器人 i 的候选阻抗 K_i：
`𝒞_joint = 𝒞_safe(φ̂_i, r_i) ∩ ⋂_{j≠i} {dist(R_i(K_i,H), inflate(R_j(K_j,H), r_j + stale_j·v_max)) ≥ d_safe}`。
R 用保守外近似（包围盒/椭球），inflate 覆盖队友物理不确定与通信陈旧造成的可达集漂移。若分离约束按 CBF/时空预约线性化，则 𝒞_joint 仍为线性不等式交集（凸）。Shield 仍为 `argmin_{K∈𝒞_joint}‖K−K_prop‖`，投影不动点性质保留：任何经 JSS 的 K 不可能与队友在球内相交。

**定义 192（概念感知任务分配 CTA）** 任务 t 携带概念 c_t 与风险 risk_t。`cost(i,t) = λ_r·r_i(c_t)·risk_t + λ_d·travel(i,t) + λ_γ·γ_{i,src(c_t)}`。指派解 `σ* = argmin_σ Σ_t cost(σ(t), t)`。线性代价下拍卖算法给 ε-最优（Bertsekas）。**机制设计备注**：r_i 是机器人的私有信息，虚报更小的 r 可骗取任务；采用二价/VCG 式支付（支付 = 社会成本增量）使其近似策略诚实，并把「虚报导致的实际超限」计入信任惩罚。

**定义 193（协作对话协议 DCL）** 四态机：
- `ask`：`r(c) > τ_ask ∨ ood_flag` ⇒ 请求澄清或示范（扩展 DMS 的 ask_clarify）；
- `teach`：若队友对 c 的球更小（`r_peer + γ < r_self`），请求教学；接收方强制走 CET+SCG 膨胀；
- `confirm`：`risk_t > τ_confirm` 时执行前复述接地（「你指的是那个看起来像玻璃、但你说发软的杯子？」）；
- `act`：以上皆否。
所有由 `taught` 概念导出的约束，其 `provenance` 必须可验证；`trust < τ_trust` 或 `disputed` 时 Shield 强制降级到保守基线 K_baseline。

**定义 194（协作联合证书 J_fabric）** `J_fabric = (J_rose, fabric_ver, provenance_hash, trust_vec, r_sem, r_cm, r_transfer, joint_margin)`。
验证：`Valid(J_fabric) ⇔ Valid(J_rose) ∧ provenance_verified ∧ joint_margin ≥ 0 ∧ min(trust_vec) ≥ τ_trust ∧ r_fused ≥ r_cm ∧ fabric_ver 与本地视图一致`。
审计链：provenance_hash 记录「这个概念从哪来、经过谁」，使语义传染可追溯、可隔离。

**定义 195（FABRIC 闭环算子）** 见 IP-202 伪代码。语义流：[OVC 接地 → CSL 拉取 → CET 迁移 → TBF 融合 → SCG 地板 → 与 RSC 球取并 → CTA 分派 → DCL 问/教/确认 → JSS 构建联合约束 → 提交 ARA 锚点 → 发布本地证据]。实时流：[原子读锚点 → OLP 前向 → WCV 编译（含队友虚拟障碍）→ JSS 投影 → 派发 → J_fabric 构建]——**零学习写**。

**定义 196（共同模式失效与语义传染）** 
- **共同模式偏差** `b_cm`：团队共享同一 VLM 先验/同一训练分布，导致各机对同一新概念的物理后验偏差**高度相关**；它不是零均值噪声，融合不消除它。
- **语义传染**：错误概念沿 provenance DAG 从教学源扩散到接收者，若接收者不本地验证就发布，则形成级联。
- **约束**：`r_fused ≥ r_cm`（地板）；节点被本地触觉证据反证（`‖φ_obs − φ_node‖ > r_node + 3σ_t`）即标 `disputed`，trust 沿 DAG 衰减，并从融合与分派中隔离，直到重新接地。

```python
class OpenVocabGrounder:
    """组合式解析 + VLM 嵌入 + 最近邻后验继承。输出只增不减的语义球。"""
    def __init__(self, vlm, lexicon, L_G, r_cm, delta_ood=0.35):
        self.vlm, self.lex = vlm, lexicon
        self.L_G, self.r_cm, self.delta_ood = L_G, r_cm, delta_ood

    def ground(self, phrase):
        g = parse_compositional(phrase)            # 实体/属性槽/关系/否定
        e = self.vlm.embed(g.canonical())
        c_nn, delta = self.lex.nearest(e)          # 织物中的已知概念
        phi0, r0 = self.lex.posterior(c_nn)
        # 组合继承：逐槽膨胀后取最保守
        r_sem = max(r0.get(slot, 0.0) + self.L_G * delta
                    for slot in g.slots) or r0
        r = max(r_sem, self.r_cm)                  # 引理 1 + 共同模式地板
        ood = delta > self.delta_ood
        return Grounding(concept=c_nn, phi=phi0, r=r, delta=delta,
                         comp=g, ood=ood)
```

### IP-194 CSL（协作语义织物 / CRDT）

```python
class ConceptFabric:
    """无中心 CRDT：LWW-register(φ,r,version) + OR-set(evidence) + G-counter(trust)。"""
    def __init__(self, origin_id):
        self.origin = origin_id
        self.store = {}                            # concept_id -> Node
        self.clock = LamportClock(origin_id)

    def publish(self, node, parents=()):
        node.version = self.clock.tick()
        node.provenance = Provenance(origin=self.origin, parents=parents,
                                     signature=sign(node), version=node.version)
        self.store[node.concept_id] = merge(self.store.get(node.concept_id), node)
        return node.version

    def pull(self, peers):
        offers = []
        for p in peers:
            offers += p.fabric.diff_since(self.view_vector())
        return offers                              # 交给 CET + TBF

    def teach(self, dst, concept_id):
        n = self.store[concept_id]
        return TransferOffer(concept_id=n.concept_id, phi=n.phi, r=n.r,
                             src=self.origin, gamma=self.estimator.gamma(self.origin, dst))

    def mark_disputed(self, concept_id, tactile_resid):
        n = self.store[concept_id]
        if tactile_resid > n.r + 3 * SIGMA_T:
            n.state = 'disputed'
            for d in self.descendants(concept_id):  # 沿 DAG 衰减信任
                self.store[d].trust *= TRUST_DECAY
```

### IP-195 CET（跨具身迁移）

```python
class CrossEmbodimentTransfer:
    def __init__(self):
        self.T, self.gamma = {}, {}                # (A,B) -> 迁移映射 / 残差上界

    def calibrate(self, A, B, paired_samples):
        self.T[(A, B)] = fit_transfer(paired_samples)
        resid = [phi_B - self.T[(A, B)](phi_A) for phi_A, phi_B in paired_samples]
        self.gamma[(A, B)] = quantile(norm(resid), 0.95)   # 只增不减

    def transfer(self, phi_A, r_A, A, B):

        return T_AB(phi_A), lip(T_AB) * r_A + g_AB          # 引理 2
```

### IP-196 TBF（信任加权拜占庭鲁棒融合 + 共同模式地板）

```python
class TrustedByzantineFusion:
    def __init__(self, N, f, r_cm, beta=1.0):
        self.N, self.f, self.r_cm, self.beta = N, f, r_cm, beta

    def fuse(self, reports):                       # [(phi, r, trust, src)]
        keep = sorted(reports, key=lambda z: z[2], reverse=True)[:self.N - self.f]
        if not keep:
            return None, self.r_cm
        phi_f = trimmed_mean([p for p, _, _, _ in keep], trim=self.f)
        m = len(keep)
        r_stat = max(r for _, r, _, _ in keep) + self.beta * sqrt(log(1/DELTA) / m)
        r_f = max(r_stat, self.r_cm)               # 地板：融合不得制造虚假确定性
        return phi_f, r_f

    def update_trust(self, src, phi_j, phi_resid, sigma_t, eta_t=0.1):
        consistency = exp(-np.linalg.norm(phi_j - phi_resid) ** 2 / sigma_t ** 2)
        self.trust[src] = (1 - eta_t) * self.trust[src] + eta_t * consistency
```

```python
def joint_safe_set(K_self, self_id, peers, d_safe, H):
```

```python
def collaborative_dialogue(grounding, risk, peers):
    if grounding.ood or grounding.r > TAU_ASK:
```

## 4. 推导

**引理 1（语义覆盖）** 设接地满足量化 Lipschitz（A77）：对任意 e, e'，`Q_{1−α}(G(e)) ≤ Q_{1−α}(G(e')) + L_G‖e−e'‖`。取 e = e(c)，e' = e(c_nn)，δ = ‖e(c)−e(c_nn)‖。由已知概念标定 `P[‖φ*(c_nn) − φ̂_nn‖ ≤ r_nn] ≥ 1−α`，且 `Q_{1−α}(G(e)) ≤ Q_{1−α}(G(e_nn)) + L_G δ`，故
`P[‖φ*(c) − φ̂_nn‖ ≤ r_nn + L_G δ] ≥ 1−α`。
组合概念对每个属性槽分别应用并取最大，仍成立。∎

**引理 2（迁移膨胀）** 设 φ_B* = T_AB(φ_A*) + ε，‖ε‖ ≤ γ_AB，且 T_AB 为 Lip(T_AB)-Lipschitz。若 φ_A* ∈ B(φ̂_A, r_A)，则
`‖φ_B* − T_AB(φ̂_A)‖ ≤ Lip(T_AB)‖φ_A* − φ̂_A‖ + ‖ε‖ ≤ Lip(T_AB) r_A + γ_AB`。
故 `r_B = Lip(T_AB) r_A + γ_AB` 覆盖 B 的真实参数。若 A 的覆盖概率为 1−α、γ_AB 的置信为 1−α_γ，则联合覆盖 ≥ 1−α−α_γ（union bound）。∎

**引理 3（拜占庭鲁棒融合与共同模式地板）** 设诚实节点 `φ_j = φ* + b_cm + ξ_j`，ξ_j 独立次高斯(σ)，拜占庭节点任意。N ≥ 3f+1 时，逐坐标截尾均值满足
`‖φ_f − (φ* + b_cm)‖ ≤ max_{honest} r_j + O(σ√(log(1/δ)/m))`
以概率 ≥1−δ。注意 `b_cm` 在所有诚实节点中相同，截尾均值对同一常数平移不变，**无法消除**。因此真实误差下界为 `‖b_cm‖`。若融合后宣称的半径为 r_f，则必须 `r_f ≥ ‖b_cm‖`，否则存在系统性的覆盖缺口。取 `r_cm` 为 `‖b_cm‖` 的高分位估计并强制 `r_f = max(r_stat, r_cm)`，即得覆盖。∎

**定理 1（协作覆盖与联合安全）** 假设：
- **(A77)** 量化 Lipschitz：接地满足 `Q_{1−α}(G(e)) ≤ Q_{1−α}(G(e')) + L_G‖e−e'‖`；
- **(A78)** 迁移：`φ_B = T_AB(φ_A)+ε`，`‖ε‖≤γ_AB`，T_AB Lipschitz 可估；
- **(A79)** 拜占庭：N ≥ 3f+1，诚实节点共同模式偏差 `‖b_cm‖ ≤ r_cm`，噪声独立次高斯；
- **(A80)** 联合约束：分离约束线性化后凸，可达集外近似保守；
- **(A81)** provenance 可验证、trust 初始有界；
- **(A82)** DCL 活跃性：ask/teach 轮次有界，未知概念最终被接地或被保守拒绝。

则对每台机器人 i：
1. `P[φ_i* ∈ B(φ̂_i, r_i)] ≥ 1−α_i`（引理 1–3 的并）；
2. 若所有机器人派发 `K_safe,i = proj_{𝒞_joint,i}(K_prop,i)`，则在球 B(φ̂_i, r_i) 内两两可达集不相交，碰撞为不可能事件；舰队安全概率 ≥ 1 − Σ_i α_i；
3. `r_i ≥ r_cm`，故协作不能宣称低于共同模式证据的确定性。∎

**定理 2（协作不劣化 / 优雅退化）** 若织物不可用（`peers = ∅` 或 `CSL` 超时）或全体队友 `trust < τ_trust`，则 TBF 的 keep 集退化为本地报告、CET 无迁移项、JSS 的队友项为空、CTA 退化为自分配。此时 `r_i = max(r_i^RSC, r_sem, r_cm)`，其中 `r_sem` 在封闭词表下等于 `r_i^RSC`，`r_cm` 为常数地板，故 FABRIC_i 的覆盖与安全保证不弱于 ROSE_i；所有第 62 轮定理原样成立。协作是**在安全下界之上的可选改进**，而非安全的新前提。∎

**命题（分配最优性）** CTA 的代价对指派是线性的，拍卖算法在有限轮内给出 ε-最优指派；若采用 VCG 支付，则在「r_i 为私有信息、机器人最大化自身效用」的模型中，真实报告是弱占优策略，从而抑制「虚报小球抢任务」的套利。∎

**命题（语义传染遏制）** 若每个 `taught` 节点在进入融合前必须通过本地触觉残差检验（阈值 `r_node + 3σ_t`），且被反证节点标 `disputed` 并沿 provenance DAG 衰减信任，则一个错误概念最多传播到其直接接收者的一跳邻居即被隔离，无法形成全队级联。∎（证明：DAG 上每个接收者独立执行本地检验，错误节点在首个不共享该错误的触觉证据处被检出。）

**正确性定理（FABRIC-Complete）** 假设 A61–A76（第 61/62 轮）及 A77–A82，则：
1. **开放词汇覆盖**：任意有最近邻的新概念，其真实物理参数被语义球覆盖 ≥1−α；OOD 概念被强制最小保守半径或拒绝执行。
2. **跨具身安全**：迁移后的球覆盖目标具身的真实参数（只增不减），跨构型违规率为 0（球内）。
3. **协作鲁棒**：N≥3f+1 下融合误差有界；共同模式地板 `r_f ≥ r_cm` 阻止「共识→共错」的虚假确定性。
4. **联合安全**：所有经 JSS 的 K_safe 在球内两两可达集不相交，舰队碰撞为不可能事件，安全 ≥1−Σα_i。
5. **优雅退化**：织物/通信失效时退化为 ROSE，第 62 轮全部保证不变。
6. **可追溯**：J_fabric 的 provenance_hash 与 trust_vec 使概念来源与传播路径可审计，语义传染可定位与隔离。
7. **实时性不变**：实时路径零学习写，≤1ms 契约保持。

## 7. 已知风险

**一句话**：若语义-物理接地不满足量化 Lipschitz（相似词 ≠ 相似物理），且多机共享同一 VLM 先验使语义错误高度相关，则 TBF 会把共同模式偏差当作可融合噪声压小，球半径跌破真实共同偏差——「共识」变成「共错」，协作把单机局部错误放大为全队系统性失效；SCG 的 L_G 与 r_cm 是全部协作安全论证共同依赖的单点假设（A77/A79）。

**次级风险与缓解**：
1. **r_cm 本身被低估**：若触觉模型与视觉模型共享训练数据，跨模态残差也会相关 → 引入至少一个「独立物理探针」（如主动敲击/称重）作为共同模式审计通道，并设 r_cm 的下限常数。
2. **CRDT 语义冲突**：LWW 可能让一次错误教学覆盖正确后验 → 后验用 OR-set 证据加权而非纯 LWW 覆盖，disputed 节点禁止参与融合。
3. **通信陈旧导致联合安全失效**：队友位置/阻抗过期 → 按 staleness·v_max 膨胀可达集，超时则把队友视为最大不确定障碍（完全保守）。
4. **CTA 机制设计的现实性**：VCG 依赖准线性效用与可信支付 → 降级为二价 + 信任惩罚的近似方案，并在 J_fabric 记录虚报导致的实际超限。
5. **概念图爆炸与 VLM 幻觉**：开放词汇无界增长 → 概念节点按信任/使用频率淘汰（provenance 保留审计），低置信接地一律走 ask 而非 act。
6. **DCL 过度询问**：频繁 ask 降低效率 → 用遗憾/效用阈值门控 τ_ask，并学习「哪些词值得问」（把询问成本纳入任务代价）。
