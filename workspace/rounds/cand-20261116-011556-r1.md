# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「抗干扰」×「持续学习」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**管道证书 + 学习联锁 + 可分性诚实**。两个灵感分别治理 v9 的两个债：**脆性债**——块证书把安全押在"点预测误差 ≤ β"上，而 β 恰在域偏移时最不可靠；**冻结债**——F̂ 离线冻结，只能靠 K_eff→1 逃避漂移。核心不是再堆模块，而是把 v9 的"模型正确 ⇒ 安全"替换为"扰动有界 ⇒ 安全"，再把"学习"从自由行为变成带证书回归门的受控行为。

## 0. 直觉与动机

**灵感 1（抗干扰 → 不要预测干扰，把干扰装进集合里）**
直觉：v9 的块证书是一个"点预测 + 标量余量 β"。点预测最怕干扰：域偏移、外推、传感器脉冲、负载突变都会让 F̂ 的误差从 β 内跳到 β 外，而证书对此只有"失效"一种反应。控制理论里的抗干扰给出了更稳的路线——不去预测扰动，而是给扰动一个上界集合 W，设计一个对所有 w∈W 都成立的不变管道（tube）。标称规划可以错，但只要误差被管道包住，安全就与"预测准不准"解耦。关键升级：证书从"点"变成"集合"，从"偶然正确"变成"对一整类干扰都正确"；同时把 v9 的 K_eff 启发式（Δ_dom 代理）替换为**证书反解块长**——管道放不下就不许取大 K，由证书而不是滞后代理来决定块长。

**灵感 2（持续学习 → 学习本身是安全威胁，不是免费午餐）**
直觉：v9 冻结 F̂，正是因为它知道"证书量的是模型"。但冻结的代价是域漂移下模型持续变差，最后只能 K_eff←1 逃避学习。持续学习能追踪漂移，却也把证书所度量的对象本身移动了：一次在线更新可能抹掉稀有安全样本（玻璃、镜面、黑色物体），造成灾难性遗忘；更糟的是若把瞬时干扰当训练信号，模型会把干扰"学进去"（投毒/自确认）。因此学习必须**联锁**：只在块边界、影子模型上、经证书回归门、带分层回放与 EWC 信任域，且永远可原子回滚。安全不依赖学习成功，学习只买性能——这是本轮的中心架构主张。

**灵感 3（抗干扰 × 持续学习 → 干扰与漂移的可分性是承重假设）**
直觉：干扰和域漂移在残差上长得一样。学干扰=投毒，拒漂移=饥饿。唯一有原则的分隔是**结构**而非幅度：干扰通常瞬态/零均值/单模态，漂移通常持久/跨模态/物理自洽。于是做三件事：(a) 用持续性与跨模态一致性做学习门控；(b) 用自适应保形预测给"可解释残差"一个有限样本覆盖的集合；(c) 最关键——**即使分类错了，安全仍由硬管道兜底**，错分类只损失性能，不损失安全。这把"可分性"从卖点降级为可证伪假设（引理 91 给出不可分构造），是本轮最诚实也最重要的设计。

## 1. 研究问题（轮次升级版）

- **Q1（管道证书的紧致性与可靠性）**：如何从残差分解（aleatoric / epistemic / external / reaction）构造一个既对任意有界干扰成立、又不过分保守的管道，使自适应 W_δ 的长期覆盖与硬界 W_hard 的逐块安全性同时成立？
- **Q2（持续学习的安全联锁）**：在线更新前向模型时，如何定义证书回归门与版本原子性，使"任意被接受的更新都不会缩减已认证安全集"，且遗忘在安全关键分层上有界？
- **Q3（干扰与漂移的可分性）**：在只有因果观测的前提下，哪些结构签名能把"该吸收的漂移"与"该拒绝的干扰"分开？当签名不可分时，系统如何保证安全不依赖分类正确？
- **Q4（预算、切换与版本）**：学习训练如何完全移出 50Hz 决策预算？模型版本切换、K_eff 收缩与 chunk↔step 交接如何保持 C⁰ 连续且全程持证？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 管道证书律（Tube-Certificate, TC）**
直觉：安全应该是"对一整类扰动都成立"的集合陈述，而不是"模型恰好准"的点陈述。
形式化：证书 Ĉ_t^tube 以可达集 R_K(W)=⊕_{k=0}^{K−1}A^kW 膨胀标称预测；安全条件只用与模型版本无关的硬界 W_hard 与检测时延可达集 B(L_d·v_max)；自适应 W_δ 只用于收紧与性能。K_eff 由"管道证书仍成立"反解，而非 Δ_dom 代理。

**P14 学习联锁律（Interlocked Continual Learning, ICL）**
直觉：学习能移动证书度量的对象，所以每次移动都必须先证明"证仍然有效"。
形式化：参数更新仅在块边界且无活跃块；更新在隔离线程的影子模型上进行；接受需通过证书回归门 CRG 五条件（覆盖、分位膨胀、遗忘、信任域、影子证书不更乐观）；版本元组原子切换，失败即回滚。

**P15 结构可分律（Structural Separability, SS）**
直觉：分不清干扰与漂移时，别让分类器掌握安全否决权。
形式化：学习门控只能依据结构性签名 σ(e)=(π,χ,ψ,ρ)；签名映射非单射（引理 91），故门控只授予"学习许可"，不授予"安全否决"；任何不确定情形一律升级到硬管道与保守包络。

**P16 版本原子律（Version Atomicity, VA）**
直觉：绝不允许"旧模型生成的证书被新模型守卫"，也不允许块中途换版。
形式化：版本元组 v_t=(θ_v,q_v,β_v,W_v,h_v) 与块证书绑定；活跃块存在时禁止换版；守卫校验版本哈希；每个决策记录版本、签名与门控结果，支持审计与逐位复现。

## 3. 与基线的接口（如何退化）

- TCE 失效 ⇒ 回退 v9 标量 β 证书与 Δ_dom 块长门控（定义 533/539），等价 v9 证书语义；
- CCL 失效 ⇒ 冻结当前模型版本、回放保留，等价 v9 的冻结 F̂；
- ISF 失效 ⇒ 学习门永久关闭（不学），管道仍工作，等价 v9 + 管道；
- IAG 失效 ⇒ 回退 v9 中块守卫，并强制 K_eff←1 与速度/力矩保守包络（保护型模块失效取保守而非 no-op）；
- 全部 v10 新模块失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再沿 v9 链退回 v8/v7。

## 4. 预期贡献

1. **管道证书**：把块证书从点预测升级为扰动不变集，使安全不再依赖"前向模型在信任域内准确"这一最易被域偏移击穿的假设；
2. **证书反解块长**：K_eff 由管道可行性决定，直接修补 v9"DA-ML 滑窗滞后导致块过长"的最大风险，且给出单调性（W 增 ⇒ K_eff 降）；
3. **证书联锁的持续学习**：安全单调的学习算子——任意被接受的更新不缩减已认证安全集，学习只买性能，附版本原子性与可回滚；
4. **结构可分性与其不可能性**：把"干扰 vs 漂移"从口号变成可证伪假设，给出因果不可分构造，并据此把安全否决权从分类器移交给硬管道；
5. **E571–E592** 覆盖管道标定、干扰拒绝、投毒、慢漂移自适应、遗忘、版本审计、击穿检测、可分性前沿、复合扰动与端到端。

## 5. 本轮最大风险

**一句话**：管道证书的安全性最终锚定在"硬扰动界 W_hard 为真"这一不可在线证伪的假设上，而持续学习又会把"已解释的残差"从自适应包络中扣掉——当真干扰在物理上伪装成持久、跨模态、自洽的漂移时，学习门控会把 W_hard 最该接管的情形判成"可学习"，于是系统在最需要保守的时刻最自信。

**定义 540（扰动谱与结构签名 DisturbanceSpectrum）** 直觉：先给残差事件"验明正身"，再决定吸收、拒绝、学习还是报警。对残差事件 e 定义签名：
```
σ(e) = ( π(e), χ(e), ψ(e), ρ(e) )
π = 残差持续越过阈值的时长 / 变点后验驻留长度
χ = 独立模态（视觉/力/本体/音频）残差方向一致性 ∈ [0,1]
ψ = 在传感器-执行器噪声模型下的物理似然
ρ = max‖r‖ / ‖W_hard‖
```
分类规则（阈值由 E571/E581 标定）：
```
D1 暂态噪声: π<τ_π ∧ ρ≤1
D2 外扰脉冲: π<τ_π ∧ ρ>1 ∧ ψ低
D3 域漂移:   π≥T_dwell ∧ χ≥χ0 ∧ ψ≥ψ0
D4 对抗污染: ψ<ψ0 ∨ (χ高但方向违反物理模型)
D5 时序干扰: 由 MW 的截止期/抖动事件直接标记
```

**定义 541（分解扰动集与自适应保形 DecomposedDisturbanceSet）** 直觉：把"模型不准"与"世界在推我"分开装，才能既收紧又不失安全。残差分解为目标扰动（模型误差也并入其中，作为非可学习分量）：
```
r_t = r_ale + r_epi + r_ext + r_adv
W_δ(t) = W_ale(q_{1−α}(t)) ⊕ W_epi(γ_epi·d_ens(t)) ⊕ W_ext(δ_dob(t)) ⊕ W_adv(δ_adv)
W_eff   = W_δ(t) ⊕ B(L_d·v_max)
W_hard  = W_ale^max ⊕ W_epi^max ⊕ W_ext^max ⊕ W_adv^max
```
其中 q 的在线更新（自适应保形，ACI）：
```
q_t = clamp( q_{t−1} + η(α − 1{s_t > q_{t−1}}), 0, q_max )
```
`d_ens` 为 N_ens 个前向模型的分歧（epistemic 代理），`δ_dob` 为广义动量/扰动观测器残差界，`δ_adv` 为鲁棒融合给出的污染上界。W_hard 只由硬件限幅、数据手册与极值标定（EVT）×安全系数决定，**不由任何在线学习更新**。

**定义 542（管道证书 TubeCertificate）** 直觉：标称轨迹可以错，但真实轨迹必须待在"标称 ⊕ 误差管道"里。误差递推 e_{k+1}=A e_k + w_k，e_0=0，w_k∈W：
```
R_K(W) = ⊕_{k=0}^{K−1} A^k W
ĝ_min^tube(K) = min_{k≤K} g^nom_k − h_{R_K(W_eff)}(ℓ_g)
ê_max^tube(K) = max_{k≤K} e^nom_k + h_{R_K(W_eff)}(ℓ_e)
```
证书有效 ⇔ `ĝ_min^tube ≥ d_safe ∧ ê_max^tube ≤ τ_eff ∧ γ̂_grasp valid ∧` 硬证书（用 W_hard）也通过。硬证书是安全判据，软证书（W_eff）是紧致性判据；二者冲突时取硬证书的保守结论。

**定义 543（证书反解块长 Certificate-DerivedChunkLength）** 直觉：块长不该由"域偏移有多像"这种滞后代理决定，而该由"管道还放不放得下"直接反解。
```
K_eff(t) = max{ K ≤ K_max :
    Ĉ_t^tube(K) 有效 ∧ P_t(K) ≠ ∅ ∧ 硬停车不变式成立 }
```
由 R_K 对 K 的单调性，K_eff 可用二分在 O(log K_max) 内求出。v9 的启发式（定义 539）在 A 为标量、W 对 Δ_dom 线性时是本定义的一个特例；当 W 增大，K_eff 单调不增——这正是对 v9「滑窗滞后仍取大 K」风险的结构性修复。

**定义 544（干扰-漂移分离器与学习门 ISF/LearningGate）** 直觉：门控只回答"这次残差配不配被学"，绝不回答"这次残差危不危险"。
```
u_learn(t) = 1  ⇔  变点在 t−τ 被确认且驻留 ≥ T_dwell
                 ∧ χ(e) ≥ χ0 ∧ ψ(e) ≥ ψ0
                 ∧ s_t ≤ q_{1−κ}(t)          # 非重尾离群，拒绝投毒
                 ∧ novelty(S_safe, e) ≥ ν0     # 非冗余，避免过拟合当前域
                 ∧ 无活跃块 ∧ 计算余量 ≥ S_min
```
判定 D4 ⇒ 报警并冻结学习 T_quar；判定 D2/D5 ⇒ 仅吸收/拒绝，不学习；判定不可分（签名落在边界带）⇒ u_learn=0，升级硬管道。

**定义 545（分层安全回放 StratifiedSafetyReplay）** 直觉：持续学习最危险的遗忘不是平均损失上升，而是稀有安全样本被稀释掉。S_safe 按域 d 与分层 z（材质/光照/几何/近碰撞）分层蓄水池采样：
```
m_i = 证书余量（越小越危险）;  p_i ∝ 1/(m_i+ε) · novelty_i
```
近碰撞与稀有材质样本设保留配额 r_min，**永不驱逐**；训练批强制含安全头样本比例 ≥ r_safe。

**定义 546（证书回归门 CertificateRegressionGate, CRG）** 直觉：一次更新只有在"证没变差"时才配被接受。θ→θ′ 接受 ⇔ 五条件同时成立：
```
C1 覆盖： (1/|S_safe|) Σ 1{‖F̂′−y‖ ≤ q′} ≥ 1−α
C2 分位： q′ − q ≤ ε_q
C3 遗忘： max_d [ L_d(F̂′) − L_d(F̂) ] ≤ ε_forget
C4 信任域： ‖θ′−θ‖_G ≤ ρ_trust      # G 为 Fisher/EWC 度量
C5 影子： 当前块在新模型下仍持证，且 cert′(active ctx) 不比 cert 更乐观超过 ε_opt
```
否则回滚到 v_t。C5 是关键：它禁止学习通过"把风险解释掉"来获得接受。

**定义 547（双时间尺度与版本原子性 TwoTimescaleAtomicity）** 直觉：学习必须离开控制回路，版本切换必须像事务一样原子。
```
快环 τ_f = 20ms：只推理/守卫，零参数更新
慢环 τ_s ≥ T_upd = 2s：仅在块边界、无活跃块、计算余量 ≥ S_min 时更新
版本元组 v_t = (θ_v, q_v, β_v, W_v, h_v)，h_v = hash(θ_v,q_v,β_v,W_v)
块证书携带 h_v；IAG 校验 h(chunk) == h(active)，不等即保守降级
```
训练在 CPU 隔离线程/后台进程执行；换版为单次原子指针交换；换版不得发生在活跃块内。

**定义 548（干扰感知守卫 InterferenceAwareGuard, IAG）** 直觉：50Hz 只做最便宜、最可靠的事——查管道成员、查版本、查停车余量。每周期：
```
if h(chunk) != h(active_model):            → 保守降级
if s_t > q_{1−α}(t): breach += 1
if breach ≥ b_max:                          → W_eff←W_hard, K_eff=1, 保守包络
if CUSUM(r) > h_cusum:                      → 请求学习（仍需 ISF 同意）
if 停车不变式(含 h_{R}(ℓ_g) 膨胀) 破坏:      → 最近中止点 p* / 安全停驻
```
保守包络：v ≤ v_cons、|τ| ≤ τ_cons、K_eff=1、学习冻结；`L_d` 为上式的检测时延上界，已并入 W_eff。

**定义 549（鲁棒融合与信任分数 RobustFusion）** 直觉：抗干扰的一半是别让单个被污染的通道说了算，另一半是诚实承认没有冗余时做不到拜占庭容错。每通道信任分数：
```
τ_i = plausibility_i × temporal_consistency_i
融合 = Huber / median-of-means（无冗余）或 coordinate-wise median（有冗余，f < n/2 时有拜占庭保证）
```
无冗余时**明确不声称**对抗性鲁棒，只做离群抑制；此诚实性由 E574/E591 直接检验。

## 2. 形式化定义（继承与升级）

**定义 493（六层指标层级）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变。
**定义 521（DA-OTL）** 继承 v9 不变；τᵢ(t) 在 K_eff>1 时以管道证书替代逐层逐步复核。
**升级定义 496（软证书，v10）**
```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Ĉ_t^tube valid
             ∧ s_t ≤ q_{1−α}(t) ∧ 版本匹配}
```
六条件同尺度；管道证书失效与单步条件同样触发 M₀ 硬检查，无"块内软通过、硬失"空洞。
**升级定义 531（软硬约束衔接）**
M₀ 判据增加两个块级入口：(a) 管道击穿（s_t 超分位且 breach 确认）；(b) 版本失配。任一发生 ⇒ 立即切换 p* 或安全停驻，不等块边界。
**升级定义 533（块证书）** 由点证书升级为定义 542 的管道证书，携带版本哈希 h_v 与硬/软两层有效性。
**升级定义 534（中止点与停车不变式）** 停车不变式按管道膨胀重算：
```
d_brake(v_p) + d_safe + h_{R_{K−p}(W_eff)}(ℓ_g) ≤ dist(s_p,O) − |traj_{p:K}|
```
P_t 随 W 增大而收缩；`P_t=∅` 时拒绝该候选块，退 K−1，直至 K=1 fallback（等价 v9 逐步语义）。
**升级定义 539（有效块长）** 由 Δ_dom 代理升级为定义 543 的证书反解；Δ_dom/risk_SLAM 仅作为 W 的**先验收缩/放大项**，不再直接决定 K_eff。

# ---------- IP-357 TubeCertificateEstimator ----------
@dataclass
class DisturbanceSet:
    radius: float
    hard_radius: float
    def __add__(self, other): ...      # Minkowski sum -> radius 相加（球近似）

class TubeCertificateEstimator:
    def __init__(self, A, W_hard, alpha=0.1, eta=0.05, q_max=0.5,
                 d_safe=0.15, gamma_epi=1.0, L_d=0.10, v_max=1.5):
        self.A, self.W_hard = A, W_hard
        self.alpha, self.eta, self.q_max = alpha, eta, q_max
        self.d_safe = d_safe
        self.gamma_epi, self.L_d, self.v_max = gamma_epi, L_d, v_max
        self.q = 0.0                        # 自适应保形分位

    def conformal_update(self, score):
        self.q = min(self.q + self.eta * (self.alpha - (1.0 if score > self.q else 0.0)),
                     self.q_max)

    def disturbance(self, d_ens, dob_residual, adv_bound):
        r_ale = self.q
        r_epi = self.gamma_epi * d_ens
        r_ext = dob_residual
        r_adv = adv_bound
        r_react = self.L_d * self.v_max         # 检测时延反应余量
        soft = r_ale + r_epi + r_ext + r_adv + r_react
        hard = self.W_hard.hard_radius + r_react
        return DisturbanceSet(soft, hard)

    def tube_radius(self, K, radius):
        # 球近似的可达集半径：sum_{k<K} ||A||^k * radius
        return sum((norm_A ** k) * radius for k in range(K))

    def certify(self, nominal, K, W, use_hard=False):
        rad = self.tube_radius(K, W.hard_radius if use_hard else W.radius)
        g_min = min(nominal.clearance[:K]) - rad
        e_max = max(nominal.effort[:K]) + rad
        ok = (g_min >= self.d_safe and e_max <= nominal.tau_eff
              and nominal.grasp_valid and self._abort_points(nominal, K, rad))
        return Cert(g_min, e_max, ok)


# ---------- IP-358 InterferenceSeparationFilter ----------
class InterferenceSeparationFilter:
    def signature(self, window, modalities, physics):
        pi   = self.persistence(window)
        chi  = self.cross_modal_coherence(modalities)
        psi  = self.plausibility(window, physics)
        rho  = self.boundedness(window)
        return Signature(pi, chi, psi, rho)

    def learn_gate(self, sig, score, q_tail, novelty, active_chunk, slack, ctx):
        if active_chunk or slack < ctx.S_min:
            return False
        if sig.is_corruption():                 # D4
            self.alarm(); self.freeze_learning(ctx.T_quar); return False
        if sig.is_ambiguous():                  # 签名落在边界带
            return False                        # 不学，升级硬管道
        return (sig.pi >= ctx.T_dwell and sig.chi >= ctx.chi0
                and sig.psi >= ctx.psi0 and score <= q_tail
                and novelty >= ctx.nu0)


# ---------- IP-359 CertifiedContinualLearner ----------
class CertifiedContinualLearner:
    def __init__(self, model, replay, gate, tce, ledger):
        self.theta = model.params(); self.version = 0
        self.shadow = model.clone(); self.replay, self.gate = replay, gate
        self.tce, self.ledger = tce, ledger
        self.G = model.fisher()                # EWC 度量

    def maybe_update(self, ctx, at_block_boundary):
        if not at_block_boundary or ctx.active_chunk:     return
        if ctx.slack < ctx.S_min:                          return   # 慢环余量门
        if not self.gate.learn_gate(ctx.sig, ctx.score, ctx.q_tail,
                                    self.replay.novelty(ctx.e), ctx): return

        self.shadow.load(self.theta)
        batch = self.replay.stratified_batch(r_safe=ctx.r_safe)
        self.shadow.train_step(batch, ewc_metric=self.G, robust_loss=True)

        delta = self.shadow.params() - self.theta
        theta_new = self.theta + self.project_trust_region(delta, ctx.rho_trust)
        if self.crg_accept(theta_new, ctx):                # 定义 546
            self.atomic_swap(theta_new)                    # 定义 547
            self.replay.absorb(ctx.e)
        else:
            self.shadow.load(self.theta)                   # 回滚

    def crg_accept(self, theta_new, ctx):
        q_new = self.replay.conformal_quantile(theta_new)
        return (self.replay.coverage(theta_new) >= 1 - ctx.alpha          # C1
                and q_new - self.tce.q <= ctx.eps_q                        # C2
                and self.replay.max_forgetting(theta_new) <= ctx.eps_forget # C3
                and self.distance(theta_new, self.theta, self.G) <= ctx.rho_trust # C4
                and self.shadow_cert_not_more_optimistic(theta_new, ctx))  # C5


# ---------- IP-360 InterferenceAwareGuard ----------
class InterferenceAwareGuard:
    def step(self, chunk, obs, active_version, tce, isf, cusum):
        if chunk.version_hash != active_version.hash:      # 版本失配
            return self.conservative(ctx)
        score = tce.score(obs)
        if score > tce.q:
            self.breach += 1
            if self.breach >= self.b_max:                  # 管道击穿
                return self.conservative(ctx)              # W_hard, K=1, 包络
        if cusum.update(obs.residual) > self.h:
            isf.request_learn()                            # 仅请求，不批准
        if not self.stop_invariant(obs, chunk, W_hard=tce.W_hard):
            return chunk.nearest_abort()                   # 定义 534（膨胀版）
        return ('continue', self.k_exec + 1)

    def conservative(self, ctx):
        ctx.envelope = (self.v_cons, self.tau_cons)
        ctx.force_K = 1
        ctx.learning_frozen = True
        return ('conservative', 1)

## 4. 推导

**引理 87（管道证书可靠性）** 设块内真实扰动 w_k ∈ W（W 为凸紧集，0∈W），误差递推 e_{k+1}=Ae_k+w_k，e_0=0。则（i）e_k ∈ R_k(W)=⊕_{i=0}^{k−1}A^iW；（ii）若管道证书 Ĉ_t^tube 通过（定义 542），则 ∀k≤K 真实间隙 g_k ≥ d_safe、真实力 e_k ≤ τ_eff。证明：对 k 归纳，e_0=0∈R_0；若 e_k∈R_k，则 e_{k+1}=Ae_k+w_k ∈ A R_k ⊕ W = R_{k+1}。对任意线性泛函 ℓ，ℓ·e_k ≤ h_{R_k(W)}(ℓ) ≤ h_{R_K(W)}(ℓ)（R_k⊆R_K）。故 g_k = g^nom_k + ℓ_g·e_k ≥ g^nom_k − h_{R_K}(ℓ_g) ≥ ĝ_min^tube ≥ d_safe，力同理。注意证明**从未使用**"F̂ 点预测准确"；模型误差只是 W 的一个分量。∎

**推论 87.1（K_eff 单调与二分）** R_K 对 K 单调不减、对 W 单调（Minkowski 和），故证书通过集是 {1..K_eff}，K_eff 良定义且对 W 单调不增；二分求 K_eff 正确。∎

**引理 88（保形覆盖的边界：安全不能用统计覆盖单独承担）** ACI 更新在任意（含非平稳）序列上给长期覆盖 ≥1−α−ε，但**不**给逐时刻条件覆盖；存在非平稳序列使某个关键步的残差超出 q_t。故安全判据必须由与学习/统计无关的 W_hard 与反应余量 B(L_d·v_max) 承担；W_δ 仅用于紧致性与性能。∎

**引理 89（学习的安全单调性）** 在 W_hard 为真的前提下，任意被 CRG 接受的更新不缩减已认证安全集：安全集由 W_hard 管道定义，与 θ 无关（引理 87）；C5 禁止新模型对活跃上下文给出更乐观的证书；定义 547 禁止活跃块内换版。故更新至多收紧 W_δ（扩大可认证 K_eff），或保持不变；回滚精确恢复 v_t。∎

**引理 90（遗忘控制）** 设接受更新间隔 ≥T_upd，每次 C3 保证各域损失增量 ≤ε_forget，C1/C3 在 S_safe 上守恒。则覆盖域上的累积遗忘 ≤ H·ε_forget/T_upd；S_safe 上不遗忘。注意：未被回放覆盖的稀有事件仍可能被遗忘（引理边界），故定义 545 的保留配额不可省。∎

**引理 91（可分性不可能性）** 存在两个因果不可分世界 A、B：A 为真实持久域漂移（如负载缓慢增加），B 为同幅、同方向、跨模态且物理自洽的外部慢扰动（如缓变风载/温漂），二者在 T 之前的观测分布完全相同、签名 σ 相同。任何因果学习门在两个世界输出相同的 u_learn：若学，则在 B 中把终将消失的偏置学进模型（T+1 后误差反号）；若不学，则在 A 中错失适应。故不存在同时零误学、零误拒的因果门；只能给出一条由 T_dwell/χ0/ψ0 参数化的 Pareto 前沿。设计后果：学习门不得拥有安全否决权，安全必须由管道兜底。∎

**引理 92（节奏、无 Zeno 与 WCET）** 版本切换仅在块边界且间隔 ≥T_upd ⇒ 切换率 ≤1/T_upd，无 Zeno；IAG 每周期 O(1)（分位比较 + CUSUM + 一次支撑函数求值），TCE 每块 O(log K_max·K_max·d)，训练与 CRG 在隔离慢环、受 S_min 门控，不进入 20ms 预算 ⇒ 50Hz 守恒。∎

## 8. 运行期不变式（可审计）

- **I1 版本**：活跃块内禁止换版；守卫校验 `h(chunk)=h(active)`。
- **I2 硬证书**：每个被执行的动作必须被 W_hard 管道覆盖。
- **I3 学习门**：活跃块/击穿/低余量时学习门关闭。
- **I4 回放**：安全分层保留配额不可驱逐；安全头样本比例达标。
- **I5 保守优先**：任何分类歧义、版本失配、击穿确认 ⇒ 保守包络（K_eff=1 + v/τ 上限）。
- **I6 审计**：每个决策记录（版本哈希、σ、s_t、q_t、u_learn、动作/中止点），支持逐位复现。

## 9. 本轮最大风险

**一句话**：管道证书的安全性最终锚定在"硬扰动界 W_hard 为真"这一不可在线证伪的假设上，而持续学习又会把"已解释的残差"从自适应包络中扣掉——当真干扰在物理上伪装成持久、跨模态、自洽的漂移时，学习门控会把 W_hard 最该接管的情形判成"可学习"，于是系统在最需要保守的时刻最自信。
