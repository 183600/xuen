# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「场景理解」×「单模型多任务」）

> 第 57 轮把安全的赌注从"模型置信"推进到"少样本可校准、跨模态可对账、个性化有界"，并把一切判定器（含元模型）送进隔离区。但它留下一个被自己亲手放大的隐患：EV-xmodal 的全部价值建立在 A38 的"条件独立声明"上，而工程现实恰恰相反——为了算力、时延与数据效率，机器人几乎必然用一个**共享骨干的单模型多任务网络**同时产出语义分割、深度、可通行性、可供性与风险。共享骨干让"跨模态/跨任务一致"既更便宜、又更**不独立**：一次特征级共模扰动可以同时骗过所有头，使它们"一致地错"，而第 57 轮的 XMC 会把这种一致当作最强证据。与此同时，**场景理解**提供了第 57 轮最缺的东西——区域级语义先验（这是路/草/冰/坑、可支撑、可通行），它能把探针预算从"每个新区域从零开始"降为"按语义簇摊销"；但语义同样会自信地错（草地盖住暗沟、水洼与薄冰同色），而且它由同一个共享模型产出。本轮核心命题因此是：**"语义只塑形搜索与否决、共享表征的一致必须先证独立、共模一致永不单独担保。"**

核心矛盾：
- **H29（共享表征 vs 独立性）**：多任务共享骨干带来效率与跨任务平滑，却把各头的误差耦合成一个共模因子；误差相关 ρ(ε_i,ε_j) 越高，第 57 轮赖以成立的"两源同侧=独立佐证"就越接近"同一个错误被复述两遍"。而独立性本身若用共享模型的残差去估计，就是循环论证——越用越自信。
- **H30（语义先验 vs 语义幻觉）**：场景理解能把先验从手工/元学习再往前推一步，变成"按语义类摊销"；但语义标签是**假设**不是**事实**，且它的错误是系统性、成片、跨任务自洽的（把整片暗沟读成"草地"）。先验越强，错时越致命。
- **H31（多任务互证 vs 循环论证）**：多任务一致性（分割边界与深度边缘吻合、可通行性与语义"路"吻合）常被当作自监督/证据信号；但共享特征使一致性成为构造性的，用它做正向证据等于让模型给自己作证。只有**分歧**仍是非循环的——分歧是模型与自己不一致，是安全可用的保守信号。

## 0. 直觉与动机

**灵感 1（场景理解 → 场景图先验：塑形搜索、行使否决，但不担保）**
直觉：人类进入新房间不会对每块地砖做探针——先"看懂"这是厨房、那是湿地，再决定哪里需要轻踩确认。场景理解给机器人的正是这种**按语义簇摊销的先验**：把区域 r 挂到场景图 G_r=(V,E,A) 上（区域/物体/支撑与空间关系/可供性），用"同类表面"的历史响应结构解码后验，探针预算随之下降。但必须先划清认识论边界：**语义只能改变"我往哪看、先探哪"，不能改变"我凭什么敢承诺"**。因此本设计把语义限制在两个单调保守的通道——(P) 塑形提议分布（只排序候选，不扩大可行动作集）；(V) 语义否决（疑似悬崖/深水/薄冰/未知类 ⇒ 直接禁止承诺）。正向证据集里永远没有"EV-scene"。

**灵感 2（单模型多任务 → 共模风险与"独立性审计"）**
直觉：一个骨干多个头，本质是把"多个证人"换成了"一个证人换几套说辞"。这对安全不是中性的：第 57 轮 EV-xmodal 的可靠性 ∝ 证人之间的独立程度，而共享骨干恰恰让独立性成为**需要被测量、且可能不成立**的量。于是把 A38 从"声明独立"降级为"**审计独立**"：在**外部审计集**（物理扰动生成、与训练分布不相交、定期刷新）上测误差相关与表征相似度，得到独立性的置信下界 κ_LB。κ_LB 不达标时，两个源"共模合并"为一本账——一致不产生证据，只保留"不反对"。关键纪律：审计集必须在被审计对象之外，绝不允许共享模型用自己的残差给自己发独立证书。

**灵感 3（场景理解 × 多任务 → 跨任务反证的非对称性）**
直觉：多任务一致性不能正向作证，但**跨任务分歧**可以反向报警，而且是非循环的：当语义说"平坦草地"、深度说"边缘塌陷"、可通行性说"高风险"时，模型正在与自己矛盾——这不需要外部真值就足以降档。因此设计 XTF（跨任务反证）为**纯保守算子**：分歧 ⇒ 加宽 + 定向探针 + 降档；一致 ⇒ 不产生任何正向证据（最多"不反对"）。这把第 57 轮 XMC 的 R1/R2 非对称性推广到任务维，并给出一个清晰口号：**"共享模型的一致只能免罪，不能担保。"**

**灵感 4（开放词汇 → 语义共形集，把"我不认识的类别"变成可界住的 OOD）**
直觉：真实场地的语义是开放词汇的（新材质、新构造、雨后新地貌）。与其强行输出一个高置信标签，不如输出**语义预测集** C_sem(r) 并给覆盖保证：集合大或含 novel/unknown ⇒ 语义 OOD，进注册表；集合含 unsafe 类 ⇒ 触发语义否决。这是第 57 轮"物理参数共形带"在语义层的对偶：物理带管"数值不确定"，语义带管"类别不确定"。

**灵感 5（合流 → FSE+ 证据门与 PCE++ 探-诺-演）**
直觉：第 57 轮五类证据门在本轮只改两处硬规则——EV-xmodal 必须携带 SRIA 独立证书 κ_LB≥κ_0；新增"共模 tripwire"：**任何不可逆接触前，至少需要一条物理独立的直接探针证据**，无论语义与多任务一致多么漂亮。场景先验则进入探询算子：先按 G_r 提议、先查 Veto、再按 D 与 D_K 发共识/定向探针。所有新机制仍只经"信念更准（含强制加宽）"或"动作更保守"两个安全通道起作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（场景图先验 SGP）** 场景理解器输出 G_r=(V_r,E_r,A_r) 与语义后验 p(l_r|I_r)。SGP 仅允许两个作用通道：(P) 提议塑形 π_G(π|G_r) 对探针/路线候选**重排序**，不改变可行动作集，且允许被下层忽略；(V) 语义否决 Veto(G_r)={r : max_{l∈unsafe} p(l|I_r)>θ_veto ∨ unsafe∩C_sem(r)≠∅}，承诺前强制 r∉Veto。硬约束：EV-scene≡⊥（语义永不进入正向证据集）；语义对风险模型只经"否决/加宽"通道。单调性：语义不确定性↑ ⇒ Veto 单调增、候选集只增不减 ⇒ 系统只更保守。

**定义 140（共享表征独立性审计 SRIA）** 多任务模型 f_θ=h_θ∘{g_k}，共享骨干 h、头 g_k（k∈K={seg,depth,trav,afford,risk}）。对任意两证据源 i,j（模态或任务），在外部审计集 𝒟_audit（物理扰动生成、与训练分布不相交、带时间戳且定期刷新）上测归一化误差相关 ρ_norm(i,j) 与表征相似度 CKA_norm(h_i,h_j)，定义 κ̂_ind(i,j)=1−max(ρ_norm,CKA_norm)，取单侧置信下界 κ_LB(i,j)。规则：(A) 任何"两源同侧"的一致性证据仅在 κ_LB(i,j)≥κ_0 且审计集有效（未过期、未被训练污染）时成立；(B) 若 κ_LB<κ_0，两源**共模合并**为一本账（计一次而非两次），一致不产生证据；(C) 共模失效概率上界 δ_cm 必须进入部署界；κ_LB 只降不升，除非审计集刷新且重测通过。禁止用共享模型自身残差估计 κ_LB（循环自证禁令）。

**定义 141（跨任务反证 XTF）** 任务信念 {b_r^k}_{k∈K}，跨任务分歧 D_K(r)=Σ_{k<k'} d(b_r^k,b_r^{k'})（d 为标签 TV + 关键分位差，与 XMC 同构）。非对称三规则：(F1) D_K>θ_K ⇒ 后验加宽 + 触发"最分歧任务对"的定向探针（预算 k_task）+ 步态降档；(F2) D_K≤θ_K **不产生任何正向证据**（共享骨干使其循环），最多"不反对"——故系统中不存在 EV-taskcons；(F3) 反证必须绑定到可被物理探针检验的量，否则只降档、不承诺。

**定义 142（语义共形集 SCS）** 在语义 logits 上用共形预测得预测集 C_sem(r)，满足 P(l_r∈C_sem(r))≥1−α_sem。若 |C_sem(r)|>1 或含 novel/unknown ⇒ 语义 OOD 标记并写入 ood_registry；若 C_sem(r)∩unsafe≠∅ ⇒ 加入 Veto(G_r)。SCS 与第 57 轮物理共形带 C_cf 并列：前者管类别不确定，后者管数值不确定，二者都只经"加宽/否决"进入决策。

**定义 143（共模感知证据门 FSE+ 与证书 J_p+）** 证据类：EV-probe\*（须 ECE_k≤ε_meta(k) 或挂 C_cf）、EV-visit、EV-margin、EV-xmodal（须 SRIA κ_LB≥κ_0 ∧ L1 ∧ D≤θ_D）、EV-human（auth≥A1 且佐证≥corrob\*(auth)）。两条硬禁令：(i) 无 EV-scene；(ii) 无 EV-taskcons。否决层：r∈Veto(G_r) ⇒ 无论证据门如何一律拒承诺。共模 tripwire：不可逆接触前，证据集中至少一条为**物理独立直接探针**（其观测不经过共享骨干 h）。J_p+=(…继承 J_p, κ_ind_audit_log, scene_graph_digest, sem_conformal_set, veto_log, cm_tripwire)。

**定义 144（探-诺-演++ 算子 PCX+）** 每检查点：①场景提议（π_G 塑形候选，先查 Veto）；②元推断（ID→摊销后验 / OOD→共形带）+ 跨模态对账（D）+ 跨任务反证（D_K）；③若 D>θ_D 或 D_K>θ_K ⇒ 发共识/定向探针（预算 k_cons+k_task）；④承诺 ⇔ 证据门过 ∧ r∉Veto ∧ 所用一致性证据均带 κ_LB 证书 ∧ 共模 tripwire 满足；⑤否则选 argmax_π[VOI_元悲观(π)−cost(π)]≥θ_voi，探尽→绕行→降档→L2 协商（τ_int(auth)）或安全停。终止性：预算 k_probes+k_cons+k_task。

## 2. 关键算法伪代码（完整版见产物区）

```python
def scene_prior_and_veto(G, r):                    # IP-139: 语义只塑形/否决
    cand = rank_by_scene(G, r)                     # 只重排序，不扩动作集
    veto = (max_unsafe_prob(G, r) > theta_veto) or (unsafe_label in C_sem(r))
    return cand, veto                              # 永不返回正向证据

def independence_audit(sources, audit_set):        # IP-140: 外部审计，禁止自证
    if not audit_set.valid():                      # 过期/污染 ⇒ 视为不独立
        return {(i, j): 0.0 for i, j in pairs(sources)}
    return {(i, j): lower_bound(1 - max(err_corr(i, j, audit_set),
                                        repr_sim(i, j)))
            for i, j in pairs(sources)}

def xmodal_evidence_plus(b_r, D, rho_m, kappa, level):
    if D > theta_D: return None
    for i, j in agreeing_pairs(b_r, rho_m):
        if kappa[(i, j)] >= kappa_0 and level == 'L1':
            return 'EV-xmodal'                     # 先证独立，再认一致
    return None                                    # 未证独立 ⇒ 一致不担保

def cross_task_falsify(b_r_tasks):                 # IP-141: 纯反证
    DK = sum(dist(b_r_tasks[k], b_r_tasks[k2]) for k, k2 in pairs(tasks))
    if DK > theta_K:
        return ('widen_and_probe', most_disagreeing_pair(b_r_tasks))
    return ('no_positive_evidence', None)          # 一致≠证据（共模循环）

def common_mode_tripwire(contact, evidence):       # 不可逆前的最后一道
    if contact.irreversible:
        return any(e.kind == 'direct_probe' and e.physically_independent
                   for e in evidence)
    return True
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SGP | O(\|V_r\|+\|E_r\|)/区域 | O(\|G\|) | 只塑形/否决，EV-scene≡⊥ |
| SRIA | O(\|K\|²·B_audit) 离线 + O(\|K\|²) 在线 | O(\|𝒟_audit\|) 静态 | 审计外部性、κ_LB 只降不升 |
| XTF | O(\|K\|²·d_b)/区域 | O(\|K\|·d_b) | 一致不产证据、分歧只保守 |
| SCS | O(1) 在线（共形表预计算） | O(\|𝒱\|) 词汇表 | 覆盖≥1−α_sem、unsafe 入否决 |
| FSE+ | O(\|σ\|·\|K\|) | O(\|σ\|) | 双硬禁令、tripwire 必过 |
| PCX+ | O(\|CP\|·(k_p+k_c+k_t)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 悲观元 VOI、预算终止 |

**正确性定理（CSPS 概要，Common-mode-aware Scene-Prior Soundness）**：在 A37–A40 上加 (A41) 语义否决漏检 ≤δ_veto（语义可错，但否决只减少承诺）；(A42) 独立性审计有效性：κ_LB(i,j)≤κ_true(i,j) 以 ≥1−δ_audit 成立，𝒟_audit 与训练分布不相交且刷新；(A43) 共享模型一致仅在 EV-xmodal 且满足 A42 与 L1 时作证，其余一律不作正向证据。则：(i) 承诺失效率 ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1∧κ_LB≥κ_0]+δ_cm+δ_veto；(ii) 交互单调性强化：SGP 只塑形/否决、SRIA 只把源合并（降级证据）、XTF 只加宽、SCS 只加宽/否决，四者均无升险通道；(iii) PCX+ 在 k_probes+k_cons+k_task 内终止于 {承诺, 绕行, L2 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 独立性证书被共享模型"自证"（共模自证） | 高 | 外部物理扰动审计集、与训练不相交、刷新、κ_LB 只降不升、自证禁令 |
| 语义否决漏检导致误入危险区 | 高 | SCS 覆盖保证 + unsafe 入 Veto + 语义只降不升 + 直接探针 tripwire |
| 场景先验把搜索带偏（语义诱导的确认偏误） | 中高 | 语义只重排序、可被下层忽略、按 D/D_K 强制反向探针 |
| 多任务模型更新使 κ_LB 失效 | 中 | 模型版本与证书绑定、更新即重审、影子模式 |
| 语义共形集过大导致过度保守 | 中低 | α_sem 分层、类簇合并、回退文本/几何先验 |

## 6. 本轮最大风险

**一句话**：本轮把第 57 轮"声明独立"改成"审计独立"，但独立性证书本身仍是在共享表征与同一数据生态里估计的——一旦审计集被同分布污染或被模型过拟合，κ_LB 会系统性高估，于是所有头一致、所有模态一致、语义自洽，**一次连贯的共模幻觉可以同时通过每一道门**；"不可逆接触前必须有一条物理独立直接探针"的 tripwire 是最后也是唯一的防线，若它被性能压力绕过，整个纵深将坍缩为一层。

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮直面第 57 轮自己放大的隐患：**EV-xmodal 依赖的"条件独立"在单模型多任务共享骨干下天然不成立**。于是把部署前提从"少样本可校准、跨模态可对账、个性化有界"升级为 **"语义只塑形、独立先审计、共模不担保"**：场景理解提供按语义簇摊销的先验但只能塑形搜索与否决；单模型多任务的一致必须先用外部审计证明独立性；任何不可逆接触前必须有物理独立的直接探针。第 57 轮"一切判定器（含元模型）走隔离"在本轮推广为"**一切一致性证据（含跨任务一致）先证独立**"。

## 2. 关键算法伪代码

### IP-139 SGP（场景图先验：塑形与否决，不担保）

```python
def scene_graph_prior(scene, r):
    G = scene.understand(r)                        # (V,E,A) + p(l|I)
    cand = sorted(candidates(r), key=lambda p: pi_G(p, G))   # 只重排序
    veto = (max_unsafe_prob(G, r) > theta_veto) or \
           bool(unsafe_labels() & semantic_set(r, G))
    return G, cand, veto                           # 注意：从不返回证据标签

def apply_scene_prior(route, G, r):
    if veto(G, r):                                 # 否决只减少承诺
        return forbid_commit(route, r)
    return rerank(route, r, pi_G=G)                # 可被下层忽略的软先验
```

### IP-140 SRIA（共享表征独立性审计：先证独立，再认一致）

```python
def independence_audit(sources, audit_set, model_version):
    if not audit_set.valid(model_version):         # 过期/污染/版本不符
        return {(i, j): 0.0 for i, j in pairs(sources)}
    kappa = {}
    for i, j in pairs(sources):
        rho = normalized_error_corr(i, j, audit_set)      # 外部数据
        cka = repr_similarity(i, j, audit_set)
        kappa[(i, j)] = lower_bound(1.0 - max(rho, cka))
    return kappa                                   # 单侧下界，只降不升

def merge_if_common_mode(sources, kappa, kappa_0):
    groups = union_find(sources)
    for i, j in pairs(sources):
        if kappa[(i, j)] < kappa_0:                # 共模合并：两源算一本账
            groups.union(i, j)
    return groups                                  # 合并后证据计数按组而非按源
```

### IP-141 XTF（跨任务反证：一致不担保，分歧才报警）

```python
def cross_task_falsify(b_tasks):
    DK = sum(dist(b_tasks[k], b_tasks[k2]) for k, k2 in pairs(tasks))
    if DK > theta_K:
        pair = most_disagreeing_pair(b_tasks)
        return Falsify(widen=True, probe=pair, budget='k_task', downshift=True)
    return Falsify(widen=False, probe=None, positive_evidence=None)
    # 显式：D_K <= theta_K 不产生 EV-taskcons；共享一致是循环的
```

### IP-142 SCS（语义共形集与语义 OOD）

```python
def semantic_conformal(logits, calib, alpha_sem):
    C = conformal_set(logits, calib, alpha=alpha_sem)   # 覆盖 >= 1-alpha_sem
    ood = (len(C) > 1) or (C & {'novel', 'unknown'})
    veto = bool(C & unsafe_labels())
    return C, ood, veto
```

### IP-143 FSE+（共模感知证据门 + J_p+）

def fse_plus_gate(c, M, persona, ood_reg, kappa, G):
    if c.region in Veto(G):                        # 语义否决：无条件拒
        return ('reject', 'semantic_veto', c)
    if   c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-xmodal':
        ok = (c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
              and kappa[(c.i, c.j)] >= kappa_0)    # 新增：审计独立
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    elif c.ev in ('EV-scene', 'EV-taskcons'):
        return ('reject', 'shared_model_not_evidence', c)  # 双硬禁令
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and not common_mode_tripwire(c, c.evidence):
        return ('reject', 'no_physically_independent_probe', c)
    return ('ok', c)

def map_certificate_p_plus(sched, log, M, consent_log, auth_log, ood_reg, kappa, G):
    for c in contacts(sched):
        st = fse_plus_gate(c, M, persona_of(c), ood_reg, kappa, G)
        if st[0] != 'ok': return st
    if min(x.K_margin for x in sched) < budgets.theta_K: return ('reject', 'K_margin')
    if rho_sem(sched, M) < budgets.rho_min:           return ('reject', 'rho_sem')
    if semantic_perturbation(M.core) > budgets.Theta_s: return ('reject', 'delta_s')
    if not all(l2.resolved for l2 in consent_log):    return ('reject', 'consent_open')
    return ('ok', Jp_plus(M.core, core_contacts(sched), K_margin, rho_sem,
                          probe_log, consent_log, meta_cal_log, xmodal_log,
                          auth_log, ood_reg, kappa_audit_log, G.digest(),

### IP-144 PCX+（探-诺-演++：场景提议 × 双分歧 × 独立性感知承诺）

```python
def probe_commit_evolve_plus(x0, M, task, budget, consent, personas, scene):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        G, cand, veto = scene_graph_prior(scene, cp.region)   # IP-139
        if veto:                                               # 语义否决优先
            alt = reroute(M, cp, risk_model)
            if alt: route = alt; continue
            return negotiate_or_stop(cp, M, None, None, consent)
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        kappa = independence_audit(evidence_sources(M), meta.audit_set, meta.ver)
        sigma = foothold_schedule(x0, cp, M, cand); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            DK = cross_task_falsify(task_beliefs(M, cp.region))     # IP-141
            if (D > theta_D or DK.widen) and 'consensus' not in cp.done:
                p2 = (most_disagreeing_modality_probe(M, cp.region)
                      if D > theta_D else probe_for(DK.probe))
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(p2, cap=F_abs))
                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        g = select_gait(R)
        lv = contact_level(cp)
        ev = tag_evidence_p(sigma, M, lv, kappa)                # 附 κ_LB
        if g != 'halt' and fse_plus_gate(core_contact(cp), M, personas,
                                         ood_reg, kappa, G)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(ev); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

### IP-134→XMC+（跨模态对账升级：独立证书门控）

```python
def xmodal_evidence_plus(b_r, D, rho_m, kappa, level):
    if D > theta_D:
        return None                                # R1: 分歧即不确定性下限
    for i, j in agreeing_pairs(b_r, rho_m):
        if level == 'L1' and kappa[(i, j)] >= kappa_0:
            return 'EV-xmodal'                     # 先证独立
    return None                                    # 未证独立：合并为一本账
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SGP | O(\|V_r\|+\|E_r\|)/区域 | O(\|G\|) | 只塑形/否决、EV-scene≡⊥（A41） |
| SRIA | O(\|K\|²·B_audit) 离线 + O(\|K\|²) 在线 | O(\|𝒟_audit\|) 静态 | 外部审计、κ_LB 只降不升、自证禁令（A42） |
| XTF | O(\|K\|²·d_b)/区域 | O(\|K\|·d_b) | 一致不产证据、分歧只保守（A43） |
| SCS | O(1) 在线（表预计算） | O(\|𝒱\|) | 覆盖 ≥1−α_sem、unsafe 入否决 |
| FSE+ | O(\|σ\|·\|K\|) | O(\|σ\|) | 双硬禁令、tripwire 必过 |
| PCX+ | O(\|CP\|·(k_p+k_c+k_t)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 悲观元 VOI、预算终止、四态完备 |

**正确性定理（Common-mode-aware Scene-Prior Soundness, CSPS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 语义否决漏检率 ≤δ_veto（语义可错，但否决只减少承诺、不产生承诺）；**(A42)** 独立性审计有效性：κ_LB(i,j)≤κ_true(i,j) 以概率 ≥1−δ_audit 成立，𝒟_audit 与训练分布不相交、带版本与时间戳并定期刷新；**(A43)** 共享模型一致仅在 EV-xmodal 且满足 A42 与 L1 时作正向证据，跨任务一致（D_K≤θ_K）不作任何正向证据；**(A44)** 不可逆接触前存在至少一条物理独立直接探针（tripwire）。则：

1. **共模感知承诺健全性**：承诺失效率 ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1∧κ_LB≥κ_0] + δ_cm + δ_veto。
2. **单调性强化**：SGP 只塑形提议/否决（可被忽略）、SRIA 只把源合并（证据计数下降）、XTF 只加宽/降档、SCS 只加宽/否决——四者均不存在升险路径；"语义否决 + 共模 tripwire"是两条独立于模型的硬闸。
3. **终止性**：每检查点共识探针 ≤k_cons、定向探针 ≤k_task，PCX+ 在 k_probes+k_cons+k_task 内终止于 {承诺, 绕行, L2 协商, 安全停}。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                  + δ_xm·1[L1∧κ_LB≥κ_0] + δ_cm + δ_veto)
             − P(𝓜 陈旧未检出) − P(审计集失效) − P(tripwire 被绕过)
```

关键：**语义给效率、否决给底线**（先验只塑形搜索，永不正向担保）；**独立先审计、共模先合并**（把"多证人"还原成"真实证人数"，拒绝用共享模型给自己发独立证书）；**一致只能免罪、分歧才能报警**（跨任务一致不作证据，避免循环论证）；**不可逆前必有一条物理独立探针**（tripwire 是所有软证据之外的最后硬闸）。

## 6. 本轮最大风险

**一句话**：本轮把第 57 轮"声明独立"改成"审计独立"，但独立性证书本身仍在共享表征与同一数据生态里估计——一旦 𝒟_audit 被同分布污染或被模型过拟合，κ_LB 会系统性高估，于是所有头一致、所有模态一致、语义自洽，**一次连贯的共模幻觉可同时通过每一道门**；"不可逆接触前必须有一条物理独立直接探针"的 tripwire 是最后也是唯一的防线，若它被性能压力绕过，整个纵深将坍缩为一层。
