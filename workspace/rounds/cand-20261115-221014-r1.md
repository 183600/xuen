# 第 10 轮（本轮灵感：「UniBot」×「预训练」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**先验提案、证书裁决、覆盖可证**。两个灵感治理 v9 的两种债：**冷启动债**（每个新环境从零在线学习，无跨任务/跨本体先验）与**误差界债**（块证书的 β 是 ×1.2 手调常数，恰在域偏移时最不可信）。必须保持 v9 纪律：任一预训练组件失效 ⇒ 注入中立元，严格等价退回 v9（引理 89），而非行为漂移。

## 0. 直觉与动机

**灵感 1（UniBot → 统一机器人基座作为「可审计先验」，而非权威）**
直觉：v9 已经会在线适应、会分块、会自省，但它在每个新场景里仍是一个"从零学起的新手"——没有关于物体、可供性、跨本体运动学的常识。UniBot 式统一基座（跨本体、跨任务的大规模预训练策略与世界模型）正好补这个先验。但直接把黑盒策略接进已认证闭环，等于用一个不可验证的模块去覆盖安全论证。正确的接入方式不是"让基座开车"，而是"让基座坐在副驾提案、由证书与硬约束裁决"。核心创新：**UniBot 先验适配器（Unified Prior Adapter, UPA）**——冻结的 (E_ψ, π_θ, F_φ) 只在 5Hz 块边界输出潜目标 z 与动作先验 ā^{1:K}；v9 在其附近做残差采样。基线策略仍持有方向盘，先验只缩小搜索方差。**P13 先验提案、证书裁决律**：先验只能改变候选分布与不确定项，永不能绕过 M₀ 硬检查、SpatialCert 与块证书。

**灵感 2（预训练 → 把 β 从手调常数升级为在线可校准的误差界）**
直觉：v9 最大的债是 β 的来历——"信任域内经验误差上界 ×1.2"。预训练给了两件礼物：更准的世界模型 F_φ，以及一个**可累积的真实残差样本池**。于是 β 不必再猜，而可由保形预测（conformal prediction）从已实现的残差中取分位数。难点在于：域偏移会破坏可交换性，使静态保形覆盖失效。解法是**在线自适应保形推断（ACI）**：用覆盖误差反馈调节显著性水平 α_t，使长期覆盖率维持在 1−α，即使分布在漂移；再用先验集成方差 u_t 做认知不确定膨胀，抵御"标定集已过期"的 OOD 段。核心创新：**保形先验证书（Conformal Prior Certificate, CPC）**：β_t = q_t(1−α_t) + λ_t·u_t，把证书从"一次性假设"变成"逐周期自我纠错的契约"。

**灵感 3（预训练 → 语义域距离作为第二通道早期预警）**
直觉：v9 的 Δ_dom 是对原始观测做 20 帧统计滑窗，天然滞后。统一预训练嵌入把"物体类别、可供性、本体形态"编码成语义特征，未见过的场景可能在**语义空间**先偏离，而在像素统计上尚未积累够 20 帧。于是把 Δ_sem（到预训练特征流形的马氏距离）作为第二条信任通道。关键设计不是"用语义替代统计"，而是**逻辑与（AND）**：U⁺ = U_v9 ∧ (Δ_sem<τ_sem) ∧ 覆盖率门。AND 只用不劣：任一通道报警都会使信任域收缩，绝不放松 v9 的否决。核心创新：**双通道信任监视器（Dual-Channel Trust, DCT）**＋**语料覆盖门 Cov_t**（超出预训练语料半径即 K_eff=1，绝不在"没见过的世界"里信任先验）。

## 1. 研究问题

- **Q1（先验安全接入）**：如何把冻结的统一先验接入已认证闭环，使"先验可用"只可能收缩、绝不扩张 v9 的可达安全集？对抗性/投毒先验下是否仍然 0 越界？
- **Q2（漂移下的误差界）**：当可交换性被域偏移破坏时，ACI＋认知膨胀能否把长期误覆盖率压在 α+o(1)，并让块长 K_cert(β) 随 β 单调收缩？
- **Q3（语义预警的边界）**：预训练语义距离是否比原始统计 Δ_dom 更早报警？对哪些偏移族它是**盲的**（摩擦、负载、深度尺度）——盲区是否被覆盖率门与 AND 组合兜住？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 先验提案、证书裁决律（Prior-Proposes-Certificate-Disposes, UPA）**
预训练基座只以三种身份进入系统：动作块**提案器**（warm-start 采样中心）、**不确定项**（集成分散度 u_t）、**世界模型候选**（F_φ）。所有执行动作必须通过 v9 的安全投影 Proj_{A_safe}、块证书 Ĉ 与 M₀/SpatialCert 否决；先验没有任何特权通道。

**P14 保形先验界律（Conformal-Prior-Bound, CPC）**
β 不再是常数，而是已实现前向误差的在线分位数＋认知膨胀：β_t = q_t(1−α_t) + λ_t u_t。α_t 用 ACI 反馈更新；证书仅在覆盖率下界与双通道信任同时成立时有效；K_cert(β) 对 β 单调不增，故"β 收紧"才允许"块变长"。

**P15 双通道信任、仅与（Dual-Channel Trust, DCT）**
Δ_sem 是独立且**逻辑与**的否决通道：U⁺ = U_v9 ∧ (Δ_sem<τ_sem) ∧ Cov_t。语义通道失效（编码器不可用）⇒ Δ_sem≡0、Cov≡1，退回 U_v9；语义通道超出语料（Cov 失败）⇒ K_eff≡1。拒绝任何"用语义替代统计"的或组合。

## 3. 与基线的接口（如何退化）

- CPC 失效（无真值标签 / 标定池空）⇒ β ← β_v9，ACI 状态关闭，证书等价 v9；
- DCT 失效（E_ψ 不可用）⇒ Δ_sem≡0、Cov≡1，U⁺=U_v9，等价 v9；
- UPA 失效（先验推理超时/不可用）⇒ 关闭 warm-start，采样器退回 v9 的 n=64 原始采样，等价 v9；
- PSD 失效（无离线归因）⇒ c_m⁰ 取"未知即唤醒"=1，等价 v9 在线归因初值；
- 以上全失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再沿 v9 五级链退回 v8/v7/v6。

## 4. 预期贡献

1. **先验的可审计接入范式**：propose/certify/veto 三段式＋严格退化，证明任意（含对抗）先验都不能扩张 v9 安全集（引理 90），把"用不用大模型"从信仰问题变成可论证的工程问题；
2. **在线保形块证书**：用 ACI 将 v9 的手调 β 替换为带长期覆盖率的自适应误差界，首次让块证书在非平稳域偏移下仍可陈述覆盖保证（引理 87）；
3. **语义/统计双通道域监视**：证明 AND 组合使检测时延**无条件不劣于** v9、并在"语义先于物理漂移"时严格更早（引理 88），同时用 E575 主动猎捕其物理盲区；
4. **先验种子蒸馏**：跨任务迁移模块重要性先验，降低 v9 消融回合成本，且"未知即唤醒"保证不预休眠任何模块；
5. **实验 E571–E590**：覆盖先验退化等价、保形覆盖、双通道时延、物理盲区、对抗先验、边缘时延、跨本体迁移与端到端任务。

## 5. 本轮最大风险

**一句话**：预训练的"语义早期预警"对真正致命的物理域偏移可能是盲的——统一嵌入会把没见过的摩擦/负载/深度尺度映射到已见过的语义类别附近，于是 Δ_sem 低、β_t 小、K_eff 大，系统恰好在最危险的新动力学上最自信；AND 组合只能保证"不比 v9 更晚"，却无法保证"一定更早"，若语义通道在物理偏移族上系统性沉默，本轮宣称的早期预警收益可能为零。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-UPAC**（Unified Pretrained Action-Chunk Certification）

> 本轮灵感：「UniBot」（统一跨本体机器人基座）×「预训练」（大规模先验与可校准误差分布）
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 三模块全部保留。新增的预训练组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元，严格等价退回 v9（引理 89），而非行为漂移。**先验只提案，证书与硬约束裁决**（P13）。

- Level-0（增强可用）：Π 可用、CPC 有效、DCT 通过 ⇒ K_eff 由 **min(双通道门, K_cert(β_t^pre))** 决定；

- Level-4（蒸馏先验失效）：无离线归因 ⇒ c_m⁰=1（未知即唤醒），**等价 v9 在线初值**；
- Level-5（全失效）：完整退回 MetricVoiceGauge-ACMD v9，再沿 v9 五级链退回 v8/v7/v6。

**新增定义 540（预训练先验三元组 PriorTriplet）** Π=(E_ψ, π_θ, F_φ)，其中 E_ψ: O→R^{d_e} 为冻结统一嵌入，π_θ:(E_ψ(o),ℓ,state)→(z,ā^{1:K}) 为跨本体基座策略，F_φ:(s,a^{1:K})→指标轨迹为预训练世界模型。全部冻结，唯一可选可训练参数为 rank-r LoRA 适配器 Δθ。Π 携带版本 v_Π 与语料清单 D_pre（含本体、场景、任务分布标签），构成**可审计性契约**。

**新增定义 541（潜目标与动作先验 Latent Goal Prior）** 在 5Hz 块边界：
```
z_t = π_θ^z(E_ψ(o_t), ℓ_t, s_t),  ā_t^{1:K} = π_θ^a(E_ψ(o_t), ℓ_t, z_t),  K=K_eff(t)
```
潜目标 z_t 作为跨本体语义接口，使不同本体的动作先验可在同一空间对齐；ā^{1:K} 仅作采样中心，不直接执行。

**新增定义 542（残差块采样 Residual Chunk Sampling）** 候选块 a^{1:K}=ā^{1:K}+δ^{1:K}，δ^{1:K}~N(0,σ_r² I)，生成 n_warm=16 个候选。先验关闭时改用 v9 的原始采样器与 n=64，因此该定义严格包裹 v9 采样语义（退化等价见引理 89）。

**新增定义 543（语义域距离 Semantic Domain Distance）** 设参考统计 (μ,Σ) 取自 B_pre，d_M(x)=√((x−μ)ᵀΣ⁻¹(x−μ))：
```
Δ_sem(t) = (1/W) Σ_{i=0}^{W-1} d_M(E_ψ(o_{t-i})) / q_{0.99}^{ref}
```
归一化后 Δ_sem≈1 表示位于语料边缘；τ_sem 默认取 1.0。W 与 v9 的 Δ_dom 窗口一致（20 帧），便于时延对比。

**新增定义 544（语料覆盖门 Corpus Coverage Gate）**
```
Cov_t = (1/W) Σ_{i=0}^{W-1} 1[ d_M(E_ψ(o_{t-i})) ≤ q_{0.99}^{ref} ]
```
若 Cov_t < c_min（默认 0.8），判定"预训练语料未覆盖当前域"，强制 K_eff=1 并关闭先验提案——**绝不在没见过的世界里信任先验**。

**新增定义 545（双通道信任域 Dual-Channel Trust）**
```
U_t⁺ = U_t^{v9} ∧ (Δ_sem(t) < τ_sem) ∧ (Cov_t ≥ c_min)
```
逻辑与（AND）是安全设计的关键：U⁺⊆U_v9，故信任域只会收缩、不会扩张；语义通道只能让系统更早进入保守模式，不可能让 v9 已判定的危险被"语义看起来正常"所抵消。

**新增定义 546（保形先验证书 Conformal Prior Certificate）** 维护前向误差样本池。对间隙（安全侧）使用单侧非一致性分数：
```
r_i = max_{k≤K_i} ( F̂_clear(s_i,a_i^{1:k}) − F_clear(s_i,a_i^{1:k}) )    # 低估量
q_t = Quantile_{1−α_t}( {r_i} ),   α_{t+1} = α_t + γ(α − err_t),   err_t = 1[r_t > q_t]
u_t = std_{m=1..M}( F_{φ,m} rollout ),   β_t^pre = q_t + λ_t·u_t
```
其中 ACI 更新仅用"标签已到达"的样本（真值延迟由定义 547 的延迟队列处理）。证书：
```
Ĉ_t^pre = ( ĝ_min − β_t^pre ,  ê_max + β_t^pre )
```
有效 ⇔ ĝ_min−β_t^pre ≥ d_safe ∧ ê_max+β_t^pre ≤ τ_eff ∧ γ̂_grasp=valid ∧ U_t⁺ ∧ (D_t≤γ)。β 缺省回退 β_v9 时，本定义逐位复现 v9 定义 533。

**新增定义 547（延迟标签队列与先验一致性守卫）** 真实指标由执行后传感/仿真回放提供，存在 d_lag 周期延迟；ACI 只在样本出队时更新，避免用未来信息。另定义先验一致性分歧：
```
D_t = max_{k≤K} || F_φ(s,a^{1:k}) − F_v9(s,a^{1:k}) ||
```
D_t>γ 表示两个世界模型对本块预测严重不一致，本块 β 回退 β_v9 且 K_eff≤双通道门，不采用 CPC 的乐观收紧。

**新增定义 548（先验-证书-否决组合 Prior-Certificate-Veto Composition）**
```
a_t^exec = Proj_{A_safe^{v9}}( ā_t^{1:K} + δ_t^{1:K} )
执行条件： Ĉ_t^pre 有效 ∧ M₀ 硬检查通过 ∧ SpatialCert 通过
```
任何一项不满足 ⇒ 执行 v9 单步 fallback，并以 fallback 结果覆盖本块（先验提案作废，不回写证书）。此定义把"先验不得扩张安全集"从口号变成算法结构（引理 90）。

**新增定义 549（预训练种子蒸馏 Pretrain-Seeded Distillation）** 用 D_pre 上的离线全因子消融得到 c_m^pre，作为 v9 贡献向量初值 c_m⁰：
```
c_m⁰ = c_m^pre（若离线证据存在），否则 c_m⁰ = 1（未知即唤醒）
```
首个在线消融回合（T_abl=500）之后，c_m 完全由在线定义 537 覆盖。φ^elig=false 的安全模块其 c_m⁰ 记 ∞，永不参与休眠迁移。

## 2. 形式化定义（继承与升级）

**定义 493（六层指标层级）** 继承 v8/v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变。
**定义 521（DA-OTL）** 继承 v9；τᵢ(t) 在 K_eff>1 时仍由块证书复核，CPC 仅提供 β。
**升级定义 533（块证书，v10）** 误差余量 β 由定义 546 的 β_t^pre 取代常数 β；当 CPC 关闭时 β=β_v9，逐位等价 v9。
**升级定义 534（中止点，v10）** 停车不变式不变；但先验提案块必须先通过 Proj_{A_safe}，投影可能移动轨迹，故中止点集 P_t 在投影后的轨迹上重新计算（防止"先验轨迹安全、投影后不安全"的错配）。
**升级定义 539（有效块长，v10）**
```
K_eff(t) = 1                                          若 ¬U_t⁺
         = min( K_gate(t), K_cert(β_t^pre) )          否则
K_gate(t) = max(1, ⌊K_max·(1 − max(Δ_dom/τ_dom, Δ_sem/τ_sem))⌋)
K_cert(β) = max{ K : ∃ 有效证书块，余量 β 下通过定义 533/534 }
```
K_cert 对 β 单调不增：β 越小，可接受的块越长（引理 87 的单调性），因此"预训练让 β 更紧"是块变长的唯一合法通道。

# IP-357/358 UniBotPriorBank + UnifiedPriorAdapter
class UniBotPriorBank:
    def __init__(self, encoder, policy, world_model, feature_bank,
                 q_ref, version, loRA=None):
        self.E, self.pi, self.F = encoder, policy, world_model   # 全部冻结
        self.B, self.q_ref = feature_bank, q_ref
        self.mu, self.Sigma_inv = feature_bank.mean_cov()
        self.version, self.loRA = version, loRA

    def d_m(self, o):
        x = self.E(o)
        return float(np.sqrt((x - self.mu) @ self.Sigma_inv @ (x - self.mu)))

    def delta_sem(self, obs_window):
        return np.mean([self.d_m(o) for o in obs_window]) / self.q_ref

    def coverage(self, obs_window):
        return np.mean([self.d_m(o) <= self.q_ref for o in obs_window])

    def propose(self, o, ell, s, K):
        z = self.pi.z(self.E(o), ell, s)
        return z, self.pi.a(self.E(o), ell, z, K)


class UnifiedPriorAdapter:
    def __init__(self, bank, n_warm=16, sigma_r=0.1, tau_sem=1.0,
                 c_min=0.8, n_off=64):
        self.bank, self.n_warm, self.sigma_r = bank, n_warm, sigma_r
        self.tau_sem, self.c_min, self.n_off = tau_sem, c_min, n_off

    def trust(self, obs_window, delta_dom, tau_dom):
        d_sem, cov = self.bank.delta_sem(obs_window), self.bank.coverage(obs_window)
        U_v9 = delta_dom < tau_dom
        U_plus = U_v9 and (d_sem < self.tau_sem) and (cov >= self.c_min)
        return U_plus, d_sem, cov

    def candidates(self, o, ell, s, K, prior_ok):
        if not prior_ok:                                  # Level-3：等价 v9
            return sample_policy(s, K, n=self.n_off)      # v9 原始采样器
        z, abar = self.bank.propose(o, ell, s, K)          # 先验提案
        return [abar + self.sigma_r * randn_like(abar)
                for _ in range(self.n_warm)]


# IP-359 ConformalPriorCertificate
class ConformalPriorCertificate:
    def __init__(self, alpha=0.1, gamma=0.01, lam=1.0, lag=25, min_pool=50):
        self.alpha, self.alpha_t = alpha, alpha
        self.gamma, self.lam, self.lag = gamma, lam, lag
        self.pool, self.pending = deque(), deque()        # r_i / 延迟标签队列
        self.min_pool = min_pool

    def push_truth(self, pred_traj, true_traj, K):
        r = max(pred_traj.clearance[k] - true_traj.clearance[k]
                for k in range(K))                        # 单侧低估量
        self.pending.append((now(), r))

    def tick(self):
        while self.pending and now() - self.pending[0][0] >= self.lag:
            _, r = self.pending.popleft(); self.pool.append(r)
        if not self.pool:
            return None                                   # Level-1：回退 β_v9
        q = quantile(self.pool, 1 - self.alpha_t)
        if len(self.pool) >= self.min_pool:               # ACI 反馈
            err = 1.0 if self.pending and self.pending[0][1] > q else 0.0
            self.alpha_t = clip(self.alpha_t + self.gamma * (self.alpha - err),
                                1e-4, 0.5)
        return q

    def beta(self, ens_std):
        q = self.tick()
        if q is None:
            return BETA_V9                                 # 等价 v9
        return q + self.lam * ens_std                     # 定义 546


# IP-360/361 双通道信任 + 先验否决安全滤器
def upac_round_10(M, s, obs, obs_window, ell=None, ...):
    U_plus, d_sem, cov = ua.trust(obs_window, ctx.delta_dom, M.tau_dom)
    if not U_plus:                                         # 含 Cov 失败
        K = 1                                              # 保守：K_eff=1
    else:
        beta = cpc.beta(ens_std=F.ensemble_std(s, K_max))
        K = min(gate_K(ctx.delta_dom, d_sem, M),
                cert_K(beta, M, s))                        # 定义 539

    cands = ua.candidates(obs, ell, s, K, prior_ok=(U_plus and K > 1))
    best = None
    for a in cands:
        a_safe = proj_safe(a, M)                           # P13/定义 548
        pred = F.rollout(s, a_safe)
        if disagreement(pred, F_v9.rollout(s, a_safe)) > GAMMA:
            beta_eff = BETA_V9                             # 定义 547
        else:
            beta_eff = beta
        cert = Cert(pred.min_clearance - beta_eff,
                    pred.max_effort + beta_eff)
        if not cert.valid() or not M.hard_check(s, a_safe) \
           or not M.spatial_cert(s, a_safe):
            continue
        pts = abort_points(s, a_safe, pred)                # 定义 534（投影后重算）

## 4. 推导

**引理 87（在线保形覆盖与 β 的单调控制）** 设前向误差样本在"段内"可交换、段间可任意漂移；ACI 更新 α_{t+1}=α_t+γ(α−err_t) 时，长期误覆盖率满足
```
(1/T) Σ_{t=1}^T err_t ≤ α + (α_0 − α + γT·C)/(γT) = α + O(1/(γT))
```
（Gibbs & Candès 型长期覆盖界；γ 为学习率，C 为有界项）。故 q_t 在漂移下仍给出 1−α 的长期覆盖；认知项 λ_t u_t 在 OOD 段（集成发散）单调增大 β_t^pre，使 K_cert(β_t^pre) 单调不增。又由定义 539，K_cert 对 β 非增，故"更紧的 β"只在覆盖率仍被维持时允许块更长——收紧不是盲乐观。∎

**引理 88（双通道检测无条件不劣，A1 下严格更早）** 因 U⁺ = U_v9 ∧ (Δ_sem<τ_sem) ∧ Cov，集合关系 U⁺⊆U_v9 恒成立，所以对任意观测序列，首次违反信任的时刻 τ_det⁺ ≤ τ_det^{v9}：语义通道与覆盖门只能提前、绝不能推迟进入保守模式。若额外假设 **A1（语义先于物理）**：对某偏移族，存在 W 帧窗口使 Δ_sem 越过 τ_sem 早于 Δ_dom 越过 τ_dom，则 τ_det⁺ < τ_det^{v9}，给出严格早期预警。A1 不是安全前提，而是收益前提——A1 失败时收益退化为 0，但安全不劣（这正是 AND 而非 OR 的理由）。∎

**引理 89（先验关闭严格等价 v9）** 关闭 Π 后：无 z/ā ⇒ 候选由 v9 采样器 n=64 生成；Δ_sem≡0、Cov≡1 ⇒ U⁺=U_v9；无 CPC 样本 ⇒ β=β_v9；无离线证据 ⇒ c_m⁰=1，而 v9 全模块 active；D_t≡0。逐项代入定义 540–549，所有计算路径逐位复现 v9 的 ACMD 闭环（固定随机种子下日志逐位一致）。∎

**引理 90（先验不扩张安全集；对抗先验鲁棒）** 对任意先验输出 ā（含被投毒/对抗的先验），执行动作必经 (i) Proj_{A_safe}，(ii) 证书 Ĉ^pre 有效，(iii) M₀ 与 SpatialCert 否决。故 a_exec ∈ A_safe^{v9}，且每步执行都在 v9 的可行域内；归纳可得 v10 的可达安全状态集 ⊆ v9 的可达安全状态集。因此先验的错误只能导致"提案被拒并 fallback"，不能导致 v9 之外的安全违背。∎

**引理 91（预训练预算摊销）** 5Hz 节拍下：编码 ≤8ms、提案 ≤10ms、先验 rollout ≤12ms，合计 ≤30ms/块，摊销到 50Hz 为 ≤3.0ms/cycle；残差候选 n_warm=16（对比 v9 n=64）使 rollout 成本降为 1/4；50Hz 守卫与 v9 相同（≤0.3ms）。故决策侧典型 ≤9ms、p99 ≤20ms，预算可行且不牺牲 50Hz（静态校验 Σ_m Ŵ_m ≤ B_dec）。∎

**引理 92（预训练种子蒸馏不引入新不安全态）** c_m⁰ 仅改变消融初值；缺省取 1（未知即唤醒），故不存在"无证据即休眠"；在线 c_m 在首个回合后覆盖 c_m⁰；φ^elig=false 的安全模块永不被迁移；且 Δ_dom/Δ_sem/Cov 任一越阈触发全唤醒。于是引理 84 的结论原样保持：任意蒸馏状态 ∈ v9 退化格点，安全性由 v8/v9 引理传递。∎

## 8. 本轮最大风险

**一句话**：预训练的"语义早期预警"对真正致命的物理域偏移可能是盲的——统一嵌入会把没见过的摩擦/负载/深度尺度映射到已见过的语义类别附近，于是 Δ_sem 低、β_t 小、K_eff 大，系统恰好在最危险的新动力学上最自信；AND 组合只能保证"不比 v9 更晚"，却无法保证"一定更早"，若语义通道在物理偏移族上系统性沉默，本轮宣称的早期预警收益可能为零。
