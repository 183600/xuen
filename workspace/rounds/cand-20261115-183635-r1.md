# 第 9 轮（新灵感循环第 1 轮；本轮灵感：「常识推理」×「传感器融合」）
> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–531；引理 77–81；实验 E531–E550）。
> 本轮纪律：**常识作先验，融合作证据，冲突作风险**。两条灵感不是并列加模块，而是合成一个机制——常识推理产生“世界应当如何”的**先验证据**，传感器融合产生“世界实际如何”的**观测证据**，二者的**冲突量**成为新的风险维度与阈值收紧项。任一环节失效都有明确退化，不破坏 v8 的九不变式。

## 0. 直觉与动机

**灵感 1（常识推理 → 世界的“先验分布”）**
直觉：v8 的指标体系只回答“指标是否达标”，却不回答“这件事在语义上是否说得通”。机器人执行“把刀放进婴儿床”“端着热汤快速冲刺”“徒手抓带电插头”时，轨迹平滑、力矩合格、空间证书也可能全部通过，却违背人类常识。常识推理应提供一个**语义先验**：给定「动词 + 物体类别 + 场景」，按需给出“预期结局”的证据质量（杯子易碎、刀危险、热液体怕加速）。关键不是把规则堆得越多越好，而是“按需触发的可供性模板 + 可被反驳的先验强度 λ_cs”。

**灵感 2（传感器融合 → 世界的“观测证据”）**
直觉：v8 已有 sensor_weight 与在线标定隔离，但融合仍是“加权平均”式的点估计，丢掉了各模态的**不确定性**与**相互矛盾**。证据理论（Dempster–Shafer）天然表达两种东西：一是“我不知道”（mass 落在全集 Θ 上），二是“两传感器各说各话”（冲突 K）。把视觉、激光、IMU、音频、触觉各自的质量函数融合，可得到对“任务结局”的信念区间 Bel/Pl，而不只是一个点。

**合成机制（本轮核心直觉）**
把常识先验 `m_prior` 当成“第 0 号虚拟传感器”投入融合。当传感器证据与常识**高度冲突**（K 大）时，有两种可能：感知坏了，或世界真的反常——两者都应提高风险、收紧阈值、更早退到硬约束。于是**常识不再是一票否决的规则表，而是一份可被证据反驳的先验**；融合也不再是点估计，而是一个能自报“矛盾”的监测器。

## 1. 研究问题（新循环第 1 轮）

- **Q1（常识到证据）**：如何把开放式常识稳定、低延迟地编译成可融合的概率质量函数 `m_prior`，并保证“错误的常识先验”不污染安全通道？
- **Q2（冲突即风险）**：如何定义冲突量 K 与无知 U，使其单调、有界、可注入 7 维风险与阈值梯度，而不引发阈值震荡（退化风暴）？
- **Q3（退化与实时）**：CPE / EFC / CAC 任一失效如何平滑退回 v8？证据时序惯性如何在传感器掉线时“滑向无知”而非突变？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P12）

**P10 常识先验化（Commonsense-as-Prior）**
常识不写成 if-then 规则，而写成期待集 `E(c,s)={(p_k,w_k)}`，再聚合为辨识框架 Θ 上的质量函数 `m_prior`：满足的期待支持 `θ_SS`，被违背的期待把质量推向 `θ_RS/θ_F/θ_C`，剩余不确定留在 Θ。强度由 `λ_cs` 控制，`λ_cs=0` 时退化为纯无知。

**P11 冲突鲁棒融合（Conflict-Robust Fusion）**
不采用经典 Dempster 规则（它在高冲突下产生 Zadeh 悖论：两个各自可信的来源互相否定时会得出荒谬的确定性结论），而采用 Dubois–Prade 型规则：冲突组合的乘积**保留在并集上**而非丢进空集，使“矛盾”显式可见、且不被错误地归一化放大。

**P12 语义锁与冲突锁（Semantic/Conflict Lock）**
不合理性 π 与冲突 K 只允许沿**安全方向**调节 τᵢ（`ρᵢ, ϱᵢ ≥ 0` 且 `π,K ≥ 0`），且证据融合以**监测器**身份旁路运行，不进入 M₀/M₁ 的硬判据通道。其后果是：即使常识先验完全错误，也只会让系统更保守，不降低硬安全（详见引理 82/87）。

## 3. 与基线的接口（如何退化）

- **CPE 失效** ⇒ `m_prior(Θ)=1`、`π≡0`，融合退化为纯传感器证据（再退 v8 点估计）；
- **EFC 失效** ⇒ 退回 v8 的 `sensor_weight` 加权融合，`K≡0, U≡0`，风险退回 5 维；
- **CAC 失效** ⇒ M_cs 关闭，`π≡0`；
- **ETD 失效** ⇒ `γ=0`（无时序惯性），其余不变；
- **STL/CDRC 失效** ⇒ τ 不含 `ρπ+ϱK`、风险退回 5 维 ⇒ 完整退回 MetricVoiceGauge-DA-SPR-Cal v8，再退 v7/v6。

## 4. 预期贡献

1. 把常识从“规则表”重构为“**可反驳的先验证据**”，与多模态传感器证据在同一证据框架内融合；
2. **冲突驱动风险**：定义 K 与 U 并注入 7 维风险与阈值梯度，使“感知-语义不一致”可量化、可触发降级；
3. **错误先验的安全性上界**：证明语义/冲突项只能收紧、不能放松硬约束，把“常识可能出错”这一现实风险化为“最多过度保守”；
4. **证据时序惯性**使传感器掉线时质量平滑滑向无知，抑制误退化震荡；
5. 完整 **语音-推理-融合-检测-隔离** 闭环：E551–E570 覆盖常识抽取、冲突检测、可供性阻断、退化等价与实机任务。

## 5. 本轮最大风险

**一句话**：一个自信但错误的常识先验会通过证据融合“劫持”并淹没真实传感器证据，把系统性偏见放大成系统性不安全（或过度拦截），而异步常识缓存一旦返回过期期待，还会把“伪冲突”注入风险通道诱发误退化——必须靠 P12 的非负安全锁与监测器旁路把这种风险压回“只更保守、不变更危险”。

### 定义 532（常识期待集 CommonsenseExpectationSet）
```
E(c,s) = { (p_k, w_k) }_{k=1..K(c,s)},   w_k ∈ [0,1]
```
其中 `c=(verb, obj_class)` 为指令语义，`s` 为场景观测。生成方式：查可供性模板 `T[verb][obj_class]`，再做一跳知识图扩展（ConceptNet/ATOMIC 风格），以 `(verb, obj_class, context_hash)` 为键缓存。`o: P → Θ` 把谓词映射到预期结局类别。

### 定义 533（证据质量函数 BPA）
每个模态 j 由标定过的判别头输出质量函数：
```
m_j(θ) ∝ softmax( h_j(o_j) ),   m_j 经 (1 - δ_calib^j) 折扣后归一化
```
`δ_calib^j` 复用 v8 的在线标定偏移。无观测时 `m_j(Θ)=1`（纯无知）。

### 定义 534（常识先验质量 CommonsensePriorMass）
```
m_prior(θ_x) = λ_cs · ( Σ_{k: o(p_k)=θ_x} w_k ) / ( Σ_k w_k ),   θ_x ∈ Θ
m_prior(Θ)   = 1 - λ_cs
```
若 `E=∅` 或 CPE 不可用，则 `m_prior(Θ)=1`（纯无知，绝不无中生有）。

### 定义 535（冲突鲁棒证据融合 Dubois–Prade Fusion）
两源规则（顺序施加于固定次序，先验置末以保证可复现）：
```
m_⊕(C) = Σ_{A∩B=C}   m₁(A)m₂(B)          # 非冲突 → 交集（合取，信息更确定）
       + Σ_{A∩B=∅, A∪B=C} m₁(A)m₂(B)     # 冲突   → 并集（析取，矛盾保留可见）
```
与经典 Dempster 规则不同，冲突乘积不被丢弃、不进入空集，从而避免 Zadeh 悖论；`m_⊕` 仍满足 `Σ=1`。

### 定义 536（冲突量与无知度 FusionConflict & Ignorance）
```
K(s) = max_{i<j}  Σ_{A∩B=∅} m̄_i(A) · m̄_j(B)      # 最坏模态对，安全优先
U(s) = m_⊕(Θ)                                      # 融合后残留无知
```
`K,U ∈ [0,1]`；`K` 衡量“谁和谁对不上”，`U` 衡量“谁都没把握”。

### 定义 537（可供性不合理性 AffordanceImplausibility）
```
π(s,a) = 1 - Π_{k=1..K} ( 1 - w_k · β_k(s,a) ),   β_k ∈ [0,1]
```
`β_k` 为谓词 p_k 在当前场景/动作下的违背程度。π 对每个 `w_k, β_k` 单调不减；`0` 表示完全合理，`1` 表示必然违背。

### 定义 538（冲突风险与常识风险）
```
risk_CONF(s) = λ_K · K(s)
risk_CS(s)   = λ_π · π(s,a) + λ_U · U(s)
```
默认 `λ_K=1.0, λ_π=1.0, λ_U=0.5`。

### 定义 539（七维风险向量与元权重）
```
risk(s) = [risk_SEN, risk_SEM, risk_EFF, risk_PERF, risk_SLAM, risk_CONF, risk_CS] ∈ ℝ⁷
w_i(s)  = softmax( α · risk(s) )_i,                          i = 0..6
w'_i(s) = softmax( α · risk_i(s) + β · emo(s) · Ṽ_i )_i,    Ṽ ∈ [0,1]⁷
```
情感导向向量 `Ṽ` 由 v8 的 ER 扩展一个维度 `Ṽ_cs`。

### 定义 540（语义阈值梯度 STL）
```
τᵢ(t) = clip( τᵢ⁰ + η·θ(t) + κᵢ·Δ_dom(t) + ρᵢ·π(t) + ϱᵢ·K(t), ε_min,i, ε_max,i )
```
`ρᵢ, ϱᵢ ≥ 0`，索引层 `i=0..6`。默认
`ρ=(1.0,0.9,0.3,0.2,0.4,0.5,0.8)`，`ϱ=(1.0,0.9,0.4,0.3,0.4,0.6,0.7)`；M₀/M₁/M_cs 取大值以保安全。

### 定义 541（常识层 M_cs）
M_cs 监控 `π < τ_cs` 与 `risk_CS < τ_cs'`，均具备到 M₀ 的退化映射 `δ_cs`（直接触发 M₀ 硬约束检查）。默认 `τ_cs=τ_cs'=0.5`。

### 定义 542（证据时序惯性 ETD）
对每个模态的质量函数做凸组合平滑（凸组合仍是合法 BPA）：
```
m̄_j^(t) = (1-γ) · m_j^(t) + γ · m̄_j^(t-1),   γ ∈ [0,1)
```
传感器掉线时令 `m_j^(t)=m_ignorance`（`Θ` 上质量=1），惯性使信念随时间平滑滑向无知，而非突变。

### 定义 543（软证书扩展 SoftCert-v9）
```
δ_trigger = { σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
              ∧ risk_SLAM < τ_SLAM ∧ π < τ_cs ∧ K < τ_K }
```
六个条件置于同一“违背概率上界 / 风险上界”尺度；任一触发 ⇒ 退化到 M₀。

### 定义 544（系统标识）
```
Φ_CSEF = { τᵢ +ρπ+ϱK, risk 7-dim, m_⊕=DP, M_cs, ETD(γ) }
Φ_v8   = { τᵢ +κΔ_dom,  risk 5-dim, fusion=weighted-avg, calib online }
```

### 定义 545（语音-推理-融合闭环 Voice-Reason-Fuse）
七元闭环：感知 → **证据融合（EFC）** → **常识推理（CPE/CAC）** → 指标层级（含 M_cs）→ 动作规划 → 情感重权（ER）→ 标定隔离（OnlineCalib-FI），再回到感知。此即 IP-366 的运行时骨架。

## 2. 关键不变式与退化（陈述）

- **I10 非负收紧**：`ρ,ϱ,π,K ≥ 0` ⇒ τ 的语义/冲突项只收紧不放松（引理 82）。
- **I11 监测器旁路**：EFC 输出的融合信念默认**不替换** v8 进入 M₀/M₁ 的感知估计，仅作监测与风险注入；故硬安全路径不受融合“劫持”（引理 87）。
- **I12 时序有界**：ETD 保证相邻融合质量的全变差 `≤ 2(1-γ)`，抑制退化震荡（引理 84）。
- **I13 退化正交**：各级退化接口互不干扰，全关即 v8（引理 85）。
- **I14 软硬无空洞**：`π<τ_cs ∧ K<τ_K` 与 `τ_safe,τ_dom,τ_SLAM` 同尺度，且 `δ_cs` 直达 M₀（引理 86）。

## 3. 关键算法骨架

```python
from itertools import combinations
from collections import defaultdict
import numpy as np

# Θ = 0:SS 1:RS 2:F 3:C  —— 用 frozenset 表示 2^Θ 的子集
FULL = frozenset({0, 1, 2, 3})
IGNORANCE = {FULL: 1.0}

def normalize(m):
    s = sum(m.values())
    return {k: v / s for k, v in m.items()} if s > 0 else dict(IGNORANCE)

def dp_combine(m1, m2):
    """Dubois–Prade：非冲突→交集，冲突→并集（不丢空集）"""
    out = defaultdict(float)
    for A, a in m1.items():
        for B, b in m2.items():
            inter = A & B
            target = inter if inter else (A | B)
            out[target] += a * b
    return normalize(out)

def pairwise_conflict(m1, m2):
    return sum(a * b for A, a in m1.items() for B, b in m2.items() if not (A & B))


# IP-360 CommonsensePriorEngine
class CommonsensePriorEngine:
    def __init__(self, kb, lambda_cs=0.6, cache_size=4096):
        self.kb = kb
        self.lambda_cs = lambda_cs
        self.cache = {}
        self.cache_size = cache_size

    def expectations(self, verb, obj_class, scene):
        key = (verb, obj_class, scene.context_hash)
        if key in self.cache:
            return self.cache[key]
        E = self.kb.template(verb, obj_class) + self.kb.one_hop(verb, obj_class)
        if len(self.cache) >= self.cache_size:
            self.cache.clear()          # 简单 LRU 退化策略；正式版用 OrderedDict
        self.cache[key] = E
        return E

    def prior_mass(self, E):
        """定义 534：期待集 → 先验 BPA；空 E 或不可用 → 纯无知"""
        if not E or self.lambda_cs <= 0:
            return dict(IGNORANCE)
        acc = defaultdict(float)
        Z = sum(w for _, w in E)
        for p, w in E:
            acc[self.kb.outcome(p)] += w
        m = {frozenset({x}): self.lambda_cs * acc[x] / Z
             for x in acc if acc[x] > 0}
        m[FULL] = 1.0 - self.lambda_cs
        return normalize(m)


# IP-361 EvidentialFusionCore
class EvidentialFusionCore:
    def __init__(self, lk=1.0, lu=0.5):
        self.lk, self.lu = lk, lu

    def fuse(self, masses):
        """masses: list[BPA]，顺序固定（先验置末）；返回 m_⊕, K, U"""
        m = dict(IGNORANCE)
        K = 0.0
        for m2 in masses:
            K = max(K, max((pairwise_conflict(m, m2), ) + (0.0,)))
            m = dp_combine(m, m2)
        return m, K, m.get(FULL, 0.0)

    def belief(self, m, subset):
        return sum(v for A, v in m.items() if A <= subset)


# IP-362 CommonsenseAffordanceChecker
class CommonsenseAffordanceChecker:
    def implausibility(self, E, scene, action, violation_fn):
        """定义 537：π = 1 - Π(1 - w_k β_k)"""
        prod = 1.0
        for p, w in E:
            beta = float(np.clip(violation_fn(p, scene, action), 0.0, 1.0))
            prod *= (1.0 - w * beta)
        return float(np.clip(1.0 - prod, 0.0, 1.0))


# IP-365 EvidenceTemporalDecay
class EvidenceTemporalDecay:
    def __init__(self, gamma=0.7):
        self.gamma = gamma
        self.prev = None

    def smooth(self, m):
        if self.prev is None or self.gamma <= 0.0:
            self.prev = m
            return m
        out = defaultdict(float)
        for k in set(m) | set(self.prev):
            out[k] = (1 - self.gamma) * m.get(k, 0.0) + self.gamma * self.prev.get(k, 0.0)
        self.prev = normalize(out)
        return self.prev


# IP-364 SemanticThresholdLadder（STL，扩展 DA-OTL）
class SemanticThresholdLadder:
    def __init__(self, base_tau, eta=0.05, N=5, kappa=None, rho=None, varrho=None):
        self.base = dict(base_tau); self.tau = dict(base_tau)
        self.eta, self.N = eta, N
        self.kappa = kappa or {i: 0.5 for i in range(7)}
        self.rho = rho or   {0:1.0,1:0.9,2:0.3,3:0.2,4:0.4,5:0.5,6:0.8}
        self.varrho = varrho or {0:1.0,1:0.9,2:0.4,3:0.3,4:0.4,5:0.6,6:0.7}
        self.hist = {i: [] for i in range(7)}
        self.delta_dom = 0.0

    def update(self, layer, satisfied, pi=0.0, K=0.0):
        h = self.hist[layer]; h.append(1 if satisfied else 0)
        if len(h) > self.N: h.pop(0)
        if len(h) < 2: return
        direction = -1.0 if h[-1] - h[-2] < 0 else 1.0
        self.tau[layer] = float(np.clip(
            self.tau[layer] + self.eta * direction
            + self.kappa[layer] * self.delta_dom
            + self.rho[layer] * max(pi, 0.0)
            + self.varrho[layer] * max(K, 0.0), -1e9, 1e9))
```

## 4. 推导

**引理 82（语义/冲突项的保守单调性）** 由定义 537，`β_k,w_k∈[0,1]` ⇒ `π∈[0,1]`；由定义 536，`K∈[0,1]`。又 `ρᵢ,ϱᵢ≥0`，故 `τᵢ` 中新增项 `ρᵢπ+ϱᵢK ≥ 0`，在 clip 之前对 `τᵢ` 单调不减。若约定“τ 越大 = 判据越严 = 软约束越难满足”，则常识/冲突只能让**退化更早发生、不能更晚**。因此错误先验的代价是效率，而非安全。

**引理 83（冲突与不合理性有界）** `0≤K≤1`、`0≤π≤1`、`0≤U≤1`，故 `risk_CONF=λ_K K≤λ_K`，`risk_CS=λ_ππ+λ_U U≤λ_π+λ_U`。`τᵢ` 由 clip 有界，`w_i` 为 softmax 输出故 `0≤w_i≤1`、`Σw_i=1`；7 维扩展不改变数值稳定性。

**引理 84（证据时序惯性的全变差上界）** 设 `m̄^(t)=(1-γ)m^(t)+γm̄^(t-1)`，`γ∈[0,1)`，`m` 为合法 BPA，则
```
||m̄^(t) - m̄^(t-1)||₁ = (1-γ)·||m^(t) - m̄^(t-1)||₁ ≤ 2(1-γ)
```
因为两个 BPA 的 L1 距离 ≤2。故相邻融合估计的全变差被 `2(1-γ)` 界住；`U` 与 `K` 随 `m̄` 连续变化，从而阈值与风险无高频跳变，抑制“退化风暴”。`γ→0` 退化为无惯性（v8 行为）。

**引理 85（退化正交性与塌缩）** 检查各模块输出：CPE 仅改 `m_prior,π`；EFC 仅改 `m_⊕,K,U`；ETD 仅改 `γ`；STL 仅改 `τ` 的附加项；CDRC 仅改风险维数。将任一置为中性元（`m_prior=IGNORANCE`、`π=0`、`K=U=0`、`γ=0`、`ρ=ϱ=0`、删去两维）不改变其余模块状态。逐级施加即得 v8，故任意组合塌缩正确。

**引理 86（七层软硬无空洞）** `δ_trigger` 含 `π<τ_cs` 与 `K<τ_K`，且 `δ_cs` 定义为“直接触发 M₀ 硬检查”。`τ_cs,τ_K,τ_safe,τ_dom,τ_SLAM` 均以“上界”语义给出，量纲一致。任一软条件被违背 ⇒ 必经 M₀，故不存在“软通过、硬失效”的空洞。

**引理 87（错误先验的安全上界）** 设真实先验可任意错误。由引理 82，语义/冲突项只收紧 τ，使 M₀/M₁ 触发时刻不晚于 v8；由 I11，EFC 是监测器，不替换 M₀/M₁ 的感知估计，故硬判据本身不受 `m_prior` 影响；奖励权重只影响“剩余自由度内的偏好塑形”，硬安全由 `δ_trigger→M₀` 独立保证。因此：**错误先验不能降低硬安全，只可能提高误退化率**。误退化率的上界随 `λ_cs·ρᵢ/Δτ` 增大而增大（给出调参依据：λ_cs 应保守，ρ 在 M₂/M₃ 应更小）。

**引理 88（实时预算）** CPE 缓存命中 O(1) ≤1ms（未命中走异步预取，主环降级为纯无知）；EFC：`|Θ|=4 ⇒ 2^4=16` 个子集，源数 `≤6`，DP 两两融合约 `5×16×16≈1.3k` 次乘加 <0.1ms；`K` 取最坏模态对同理；CAC 遍历 `|E|≤~10` 谓词；STL O(1)。感知侧增量 ≤1.5ms；决策侧沿用 v8 且不新增主路径计算，总 WCET 维持 ≤20ms（50Hz）。
