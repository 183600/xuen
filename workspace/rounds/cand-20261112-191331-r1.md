# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「通信延迟」×「可靠性」）

> 第 60 轮实现了「认知驱动的场景-执行闭环」：SSM 把场景转化为阻抗先验、CIEC 把意图时序化为约束锁定、EPIR 用序列号+哈希保障 EV-exec 因果恢复、SERC 把三者统一、PCE++++ 拓展四维认知预算。但**三个被「延迟」暴露的局限**尚未解决：
> 1. **EPIR 只治「丢失」不治「迟到」**：因果恢复的隐含前提是「消息最终会到」。可通信延迟下 EV-exec 会**迟到**——云端拿一份陈旧证据去更新场景/意图信念，产生「证据幻觉」。**丢包可检测，迟到不可检测**；迟到的证据比丢失的证据更危险，因为它伪装成「新鲜事实」进入融合。
> 2. **CIEC 假设意图「即时可达」**：τ_response = max(0, Δt_intent − Δt_execution) 隐含 Δt_intent≈0。真实意图要穿过通信链路，若在 `T_valid` 之后才到达仍被锁定，就等于用**过期意图劫持实时执行（stale-intent hijack）**——「慢点」在机器人已经撞上之后才生效。
> 3. **SERC 本质是含延迟的反馈回路**：`场景→意图→约束→阻抗→执行→EV-exec→场景更新` 是带传感器/通信延迟的闭环。控制论常识：**延迟消耗相位裕度**，第 60 轮那个高增益、提前收敛的 `K_safe` 在延迟下会振荡甚至发散；而第 60 轮完全没有把延迟写进稳定性分析，也没做延迟补偿。

## 0. 直觉与动机

**灵感 1（通信延迟 → 证据时效性衰减 DESM）**
直觉：可靠性的第一性定义不是「到达」，而是「**按时到达**」。一条 EV-exec 有一条出生时间 `t_gen`，它的价值随时间指数衰减：`γ(a)=e^{−λa}`（a 为证据年龄），超过 `D_max` 直接判为「失效」。关键洞见：**把「新鲜度」变成融合权重**——XMC+ 不再等权融合所有证据，而是按 `γ(a)` 加权；陈旧证据只能「弱影响」，不能「改信念」。这把「通信延迟」从工程噪声提升为一等公民的状态变量。

**灵感 2（可靠性 → 有界陈旧一致性协议 RCEP）**
直觉：分布式系统早已给出答案——**至少一次 + 幂等去重 + 有界陈旧（bounded staleness）**。EPIR 的「影子副本」只是本地日志，缺一个「边-云共识状态机」。RCEP 给每条 EV-exec 一个四态生命周期 `{PENDING, CONFIRMED, UNCONFIRMED_STALE, LOST}`：边端在 `D_ack` 内未收到确认就重传，重传耗尽则转 `UNCONFIRMED_STALE` 并进入**本地权威模式**；云端按 `(source, seq_id)` 幂等去重、按序提交。关键洞见：**「未确认」不是「丢失」**——它是一等状态，可被下游显式降权，而不是静默消失。

**灵感 3（延迟 × 意图 → 意图时间有效期 TVI）**
直觉：意图不是「永久命令」，而是**带保质期的约束**。给意图加 `(t_issue, T_valid, priority)`；到达时先算剩余有效期 `ρ = T_valid − (t_now − t_issue) − RTT_est`。若 `ρ < ρ_min`，**绝不锁定**，只能二选一：用预测意图（基于对话上下文外推）或安全中止。关键洞见：**约束锁定的 TTL 必须等于剩余有效期**，过期自动释放——这直接堵住第 60 轮「意图锁定 2s 超时」但没考虑链路时延的漏洞。

**灵感 4（延迟补偿 → Smith 预测器式 DCSERC）**
直觉：控制论里对付纯延迟的标准武器是 **Smith 预测器**——用模型把「延迟的观测」外推回「当前时刻」，再对预测值做控制。把 SERC 的 `R_scene.update(obs)` 改成 `R_scene.predict(obs, D̂)`：用延迟观测 + 场景模型外推 `D̂` 秒后的场景信念，再编译 `K_safe`。同时做**增益调度**：延迟与抖动越大，`K_p` 越保守（`α=1/(1+D̂+J)`）。关键洞见：**延迟补偿不能只补「量」，还要降「增益」**，否则模型误差会被高增益放大。

**灵感 5（PCE+++++ → 通信预算 B_comm）**
直觉：第 60 轮的四维认知预算缺了最贵的一维——**通信**。新增 `B_comm=(D_deadline, J_max, p_loss, N_retry, S_max)`；成本 `cost_comm = λ_D·E[delay] + λ_J·Var(delay) + λ_L·loss·retransmit`。当 `E[delay] > D_deadline` 或 `J > J_max`，预算判负，触发**降级阶梯**而不是硬撑。

**灵感 6（合流 → 可靠延迟感知闭环 RDLC）**
直觉：把上面五条合成一条**带可靠性约束的延迟补偿闭环**：
`场景预测(z@t+D̂) → 意图有效期筛选 → 约束 TTL 锁定 → 增益调度编译 K_safe → 执行 → EV-exec 带 t_gen → RCEP 有界陈旧共识 → DESM 时效加权 → 场景信念更新`。
核心不变量：**任何进入决策的状态都必须携带「年龄 ≤ D_max」的证书**；否则只允许降级动作。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（延迟感知证据时效模型 DESM）** 证据 `e=(payload, t_gen, seq_id, hash, source)`；年龄与可信度：
- `a(e,t) = max(0, t − t_gen)`
- `γ(e,t) = e^{−λ·a(e,t)} · 1[a(e,t) ≤ D_max]`（`λ>0` 为时效衰减率）
- **时效加权融合**：`x_fused = Σ_i γ_i·x_i / Σ_i γ_i`，且要求 `Σ_i γ_i ≥ γ_min`，否则融合结果标记 `FRESHNESS_INSUFFICIENT`。
- **陈旧证据隔离**：`γ=0` 的证据只进入审计日志，**不进入信念更新**。

**定义 162（可靠共识证据协议 RCEP，升级 EPIR）** 边端账本 `L_e`、云端账本 `L_c`，状态机 `σ: seq_id → {PENDING, CONFIRMED, UNCONFIRMED_STALE, LOST}`：
- **提交**：边端 `append(e)` 生成 `seq_id`，状态 `PENDING`，推送云端；
- **确认**：云端按 `(source, seq_id)` **幂等**提交并回 `ACK`；重复 `seq_id` 直接丢弃（去重）；
- **超时重传**：`PENDING` 超过 `D_ack` 未确认则重传，至多 `N_retry` 次；耗尽转 `UNCONFIRMED_STALE`，边端进入 `LOCAL_AUTH`；
- **有界陈旧**：定义 `S_max`，保证网络恢复后 `L_c` 在 `S_max` 内收敛到 `L_e` 的已确认前缀；
- **本地权威**：`LOCAL_AUTH` 下边端可独立推进执行，但所有证据标记 `unconfirmed=true`，云端恢复后**对账重放**。

**定义 163（意图时间有效期 TVI 与延迟感知 CIEC）** 意图 `I=(content, t_issue, T_valid, priority)`：
- **剩余有效期**：`ρ(I,t) = T_valid − (t − t_issue) − RTT_est`；
- **锁定准入**：仅当 `ρ ≥ ρ_min` 才允许 `ERTC.lock(C_intent, ttl=ρ)`；锁定 TTL **等于剩余有效期**，到期自动释放；
- **过期处置**：`ρ < ρ_min` 时执行 `predict_or_abort`：若对话上下文置信度 ≥ `τ_pred` 则用预测意图，否则 `SAFE_ABORT`；
- **劫持定义**：若在 `t > t_issue + T_valid` 仍施加该意图的约束，称**过期意图劫持**，TVI 保证其概率为 0。

**定义 164（延迟补偿场景闭环 DCSERC）** 给定延迟估计 `D̂`、抖动 `J`、场景模型 `f_scene`：
- **预测**：`ẑ_{t+D̂} = f_scene(obs_{t−D̂}, D̂)`；
- **增益调度**：`α(D̂,J) = 1 / (1 + κ_D·D̂ + κ_J·J)`；
- **编译**：`K_safe = EEIS.compile(ẑ_{t+D̂}, gain_scale=α, delta_f_req)`；
- **补偿误差界**：`‖z − ẑ‖ ≤ ε_m·D̂`（`ε_m` 为模型 Lipschitz 常数）。
- **稳定性条件**：若开环相位裕度 `PM_0` 满足 `PM_0 − arctan(ω_c·D̂) − ε_m·D̂·ω_c ≥ PM_min`，则补偿闭环稳定；否则进一步下调 `α`。

**定义 165（PCE+++++ 通信预算）** `B_comm=(D_deadline, J_max, p_loss, N_retry, S_max)`，成本：
```
cost_comm = λ_D·E[delay] + λ_J·Var(delay) + λ_L·p_loss·(N_retry+1)
voi_comm(π) = VOI_cog(π) − cost_comm(π)
```
**降级阶梯**：`NORMAL → DELAYED（降增益） → LOCAL_AUTH（断云） → SAFE_STOP（超 D_max）`，单向不可回跳（除非预算恢复且证据重新新鲜）。

**定义 166（延迟下证据链完整性 ECID）** 
```
I_chain = P(no loss)·P(no reorder)·P(a ≤ D_max)
        ≥ (1 − p^{N_retry+1}) · (1 − q_reorder) · 1[E[delay] ≤ D_max]
```
其中 `p` 为单跳丢失率、`q_reorder` 为乱序率。要求 `I_chain ≥ 1−δ_chain`（如 `δ_chain=1e-3`）。

**定义 167（可靠性感知共识状态机 RAC）** `RAC = (state, evidence_epoch, auth_source)`，状态 `{NORMAL, DELAYED, LOCAL_AUTH, SAFE_STOP}`：
- `NORMAL`：`E[delay]≤D_deadline ∧ J≤J_max ∧ I_chain≥1−δ`；
- `DELAYED`：延迟越界但未丢证据 ⇒ 降增益、加长 TTL；
- `LOCAL_AUTH`：`UNCONFIRMED_STALE` 超阈 ⇒ 本地闭环，证据打标；
- `SAFE_STOP`：证据年龄 `>D_max` 且无预测可用 ⇒ 停止执行并上报。

**定义 168（延迟感知派发引擎 DDE）** 决策规则：
```
if age(EV_exec) ≤ D_max and ρ(intent) ≥ ρ_min:        ACT_FRESH
elif ẑ_{t+D̂} 的 SIC 三元校验通过 and J ≤ J_max:        ACT_PREDICTIVE
elif state == LOCAL_AUTH and 本地证据新鲜:              ACT_LOCAL
else:                                                  SAFE_STOP
```

## 2. 关键算法伪代码

### IP-161 DESM（延迟感知证据时效）

```python
class DelayAwareEvidenceModel:
    def __init__(self, lam=0.5, D_max=1.0, gamma_min=0.2):
        self.lam, self.D_max, self.gamma_min = lam, D_max, gamma_min

    def age(self, e, t_now):
        return max(0.0, t_now - e.t_gen)

    def credibility(self, e, t_now):
        a = self.age(e, t_now)
        return 0.0 if a > self.D_max else math.exp(-self.lam * a)

    def fuse(self, evidences, t_now):
        weighted = [(e, self.credibility(e, t_now)) for e in evidences]
        total = sum(w for _, w in weighted)
        if total < self.gamma_min:
            return None, 'FRESHNESS_INSUFFICIENT'
        x = sum(w * e.payload for e, w in weighted if w > 0) / total
        return x, 'OK'
```

### IP-162 RCEP（可靠共识证据协议）

```python
class ReliableConsensusEvidenceProtocol:
    def __init__(self, D_ack=0.3, S_max=2.0, N_retry=3):
        self.D_ack, self.S_max, self.N_retry = D_ack, S_max, N_retry
        self.edge, self.state = {}, {}
        self.next_seq, self.local_auth = 1, False

    def append(self, ev, t_now):
        seq = self.next_seq; self.next_seq += 1
        msg = EVExecMessage(seq_id=seq, t_gen=t_now, source=self.node,
                            hash=sha256(ev), retries=0)
        self.edge[seq] = msg; self.state[seq] = 'PENDING'
        self._send(msg); return msg

    def on_ack(self, ack):
        if self.state.get(ack.seq_id) == 'PENDING':
            self.state[ack.seq_id] = 'CONFIRMED'

    def tick(self, t_now):
        for seq, st in self.state.items():
            if st != 'PENDING':
                continue
            msg = self.edge[seq]
            if t_now - msg.t_gen > self.D_ack:
                if msg.retries < self.N_retry:
                    msg.retries += 1; self._send(msg)
                else:
                    self.state[seq] = 'UNCONFIRMED_STALE'
                    self.local_auth = True

def cloud_commit(ledger, msg, t_now, desm):
    if msg.seq_id in ledger:
        return 'DUP'                         # 幂等去重
    if msg.seq_id != ledger.last_seq + 1:
        ledger.buffer(msg); return 'OUT_OF_ORDER'
    if desm.credibility(msg, t_now) == 0.0:
        ledger.audit(msg, 'STALE_REJECT'); return 'STALE'
    ledger.commit(msg); ledger.last_seq = msg.seq_id
    return 'COMMIT'
```

### IP-163 TVI-CIEC（意图有效期约束）

```python
class DelayAwareIntentController:
    def __init__(self, ertc, rho_min=0.2, tau_pred=0.7):
        self.ertc, self.rho_min, self.tau_pred = ertc, rho_min, tau_pred

    def receive_intent(self, intent, t_now, rtt_est):
        rho = intent.T_valid - (t_now - intent.t_issue) - rtt_est
        if rho < self.rho_min:
            return self._predict_or_abort(intent, t_now)
        c = self._map(intent.content)
        self.ertc.lock(c, ttl=rho)           # TTL = 剩余有效期
        return c

    def _predict_or_abort(self, intent, t_now):
        p = self._predict_intent(intent)
        if p.confidence >= self.tau_pred:
            self.ertc.lock(self._map(p.content), ttl=self.rho_min)
            return p
        return 'SAFE_ABORT'                  # 绝不锁定过期意图
```

### IP-164 DCSERC（延迟补偿场景闭环）

```python
class DelayCompensatedSERC:
    def __init__(self, scene_model, eeis, kD=0.8, kJ=1.2):
        self.scene_model, self.eeis = scene_model, eeis
        self.kD, self.kJ = kD, kJ

    def step(self, obs, t_now, D_hat, J, delta_f_req):
        z_pred = self.scene_model.predict(obs, horizon=D_hat)
        alpha = 1.0 / (1.0 + self.kD * D_hat + self.kJ * J)
        K_safe = self.eeis.compile(z_pred, gain_scale=alpha,
                                   delta_f_req=delta_f_req)
        stable = self._phase_margin_ok(D_hat, alpha)
        return K_safe, stable

    def _phase_margin_ok(self, D_hat, alpha):
        pm = self.eeis.pm0 - math.atan(self.eeis.wc * D_hat) - self.eeis.em * D_hat * self.eeis.wc
        return pm >= self.eeis.pm_min
```

### IP-165 PCE+++++（通信预算）

```python
class CommBudget:
    def __init__(self, D_deadline=0.3, J_max=0.05, p_loss=0.1, n_retry=3, S_max=2.0):
        self.D_deadline, self.J_max = D_deadline, J_max
        self.p_loss, self.n_retry, self.S_max = p_loss, n_retry, S_max

    def cost(self, delay_mean, delay_var):
        return (0.5 * delay_mean + 2.0 * delay_var
                + 0.1 * self.p_loss * (self.n_retry + 1))

    def ladder(self, delay_mean, jitter, chain_integrity, delta=1e-3):
        if delay_mean > self.D_deadline and chain_integrity >= 1 - delta:
            return 'DELAYED'
        if chain_integrity < 1 - delta:
            return 'LOCAL_AUTH'
        if delay_mean > 2 * self.D_deadline:
            return 'SAFE_STOP'
        return 'NORMAL'
```

def delay_aware_dispatch(EV_exec, intent, z_pred, sic, rac, desm, t_now):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DESM | O(n) 加权融合/周期 | O(n) | 陈旧证据零进入信念；融合权重单调递减 |
| RCEP | O(1) 追加 / O(k) 重传对账 | O(S_max) | 幂等去重；`S_max` 内有界收敛 |
| TVI-CIEC | O(1) | O(1) | 过期意图锁定概率 = 0 |
| DCSERC | O(模型预测) | 复用 | 相位裕度 ≥ `PM_min` 时闭环稳定 |
| PCE+++++ | O(1) 阶梯判定 | O(1) | 任一预算越界必降级，单向不回跳 |

**正确性定理（DRC — Delay-Reliability Closure）**：
假设 A66–A72 成立：**(A66)** 单跳延迟有界 `delay ≤ D_max`、抖动 `≤J_max`、丢包率 `p`；**(A67)** `(source, seq_id)` 幂等去重；**(A68)** 证据可信度按 DESM 指数衰减；**(A69)** 意图携带 `(t_issue,T_valid)` 且 `RTT_est` 为延迟上界；**(A70)** 场景模型 Lipschitz 常数 `ε_m`，`‖z−ẑ‖≤ε_m·D̂`；**(A71)** `B_comm` 单调消耗；**(A72)** 降级阶梯单向且 SAFE_STOP 为吸收态。
则：
1. **有界陈旧收敛**：网络恢复后 `L_c` 在 `S_max` 内收敛到 `L_e` 的已确认前缀；重复消息不改变账本（幂等）。
2. **无过期意图劫持**：`ρ < ρ_min` 的意图永不进入 `ERTC.lock`，故过期约束作用概率为 0。
3. **延迟补偿稳定性**：若 `PM_0 − arctan(ω_c D̂) − ε_m D̂ ω_c ≥ PM_min`，则 DCSERC 闭环渐近稳定；否则增益调度使 `α` 下降至满足条件。
4. **证据链完整性**：`I_chain ≥ (1−p^{N_retry+1})(1−q_reorder) ≥ 1−δ_chain`。
5. **预算安全性**：任一 `B_comm` 分量越界 ⇒ RAC 进入对应降级态，`SAFE_STOP` 不可被普通动作越过。

### IP-161 DESM（延迟感知证据时效）

```python
class DelayAwareEvidenceModel:
    def __init__(self, lam=0.5, D_max=1.0, gamma_min=0.2):
        self.lam, self.D_max, self.gamma_min = lam, D_max, gamma_min

    def age(self, e, t_now):
        return max(0.0, t_now - e.t_gen)

    def credibility(self, e, t_now):
        a = self.age(e, t_now)
        return 0.0 if a > self.D_max else math.exp(-self.lam * a)

    def fuse(self, evidences, t_now):
        weighted = [(e, self.credibility(e, t_now)) for e in evidences]
        total = sum(w for _, w in weighted)
        if total < self.gamma_min:
            return None, 'FRESHNESS_INSUFFICIENT'
        x = sum(w * e.payload for e, w in weighted if w > 0) / total
        return x, 'OK'
```

### IP-162 RCEP（可靠共识证据协议）

```python
class ReliableConsensusEvidenceProtocol:
    def __init__(self, D_ack=0.3, S_max=2.0, N_retry=3):
        self.D_ack, self.S_max, self.N_retry = D_ack, S_max, N_retry
        self.edge, self.state = {}, {}
        self.next_seq, self.local_auth = 1, False

    def append(self, ev, t_now):
        seq = self.next_seq; self.next_seq += 1
        msg = EVExecMessage(seq_id=seq, t_gen=t_now, source=self.node,
                            hash=sha256(ev), retries=0)
        self.edge[seq] = msg; self.state[seq] = 'PENDING'
        self._send(msg); return msg

    def on_ack(self, ack):
        if self.state.get(ack.seq_id) == 'PENDING':
            self.state[ack.seq_id] = 'CONFIRMED'

    def tick(self, t_now):
        for seq, st in self.state.items():
            if st != 'PENDING':
                continue
            msg = self.edge[seq]
            if t_now - msg.t_gen > self.D_ack:
                if msg.retries < self.N_retry:
                    msg.retries += 1; self._send(msg)
                else:
                    self.state[seq] = 'UNCONFIRMED_STALE'
                    self.local_auth = True

def cloud_commit(ledger, msg, t_now, desm):
    if msg.seq_id in ledger:
        return 'DUP'                         # 幂等去重
    if msg.seq_id != ledger.last_seq + 1:
        ledger.buffer(msg); return 'OUT_OF_ORDER'
    if desm.credibility(msg, t_now) == 0.0:
        ledger.audit(msg, 'STALE_REJECT'); return 'STALE'
    ledger.commit(msg); ledger.last_seq = msg.seq_id
    return 'COMMIT'
```

### IP-163 TVI-CIEC（意图有效期约束）

```python
class DelayAwareIntentController:
    def __init__(self, ertc, rho_min=0.2, tau_pred=0.7):
        self.ertc, self.rho_min, self.tau_pred = ertc, rho_min, tau_pred

    def receive_intent(self, intent, t_now, rtt_est):
        rho = intent.T_valid - (t_now - intent.t_issue) - rtt_est
        if rho < self.rho_min:
            return self._predict_or_abort(intent, t_now)
        c = self._map(intent.content)
        self.ertc.lock(c, ttl=rho)           # TTL = 剩余有效期
        return c

    def _predict_or_abort(self, intent, t_now):
        p = self._predict_intent(intent)
        if p.confidence >= self.tau_pred:
            self.ertc.lock(self._map(p.content), ttl=self.rho_min)
            return p
        return 'SAFE_ABORT'                  # 绝不锁定过期意图
```

### IP-164 DCSERC（延迟补偿场景闭环）

```python
class DelayCompensatedSERC:
    def __init__(self, scene_model, eeis, kD=0.8, kJ=1.2):
        self.scene_model, self.eeis = scene_model, eeis
        self.kD, self.kJ = kD, kJ

    def step(self, obs, t_now, D_hat, J, delta_f_req):
        z_pred = self.scene_model.predict(obs, horizon=D_hat)
        alpha = 1.0 / (1.0 + self.kD * D_hat + self.kJ * J)
        K_safe = self.eeis.compile(z_pred, gain_scale=alpha,
                                   delta_f_req=delta_f_req)
        stable = self._phase_margin_ok(D_hat, alpha)
        return K_safe, stable

    def _phase_margin_ok(self, D_hat, alpha):
        pm = self.eeis.pm0 - math.atan(self.eeis.wc * D_hat) - self.eeis.em * D_hat * self.eeis.wc
        return pm >= self.eeis.pm_min
```

### IP-165 PCE+++++（通信预算）

```python
class CommBudget:
    def __init__(self, D_deadline=0.3, J_max=0.05, p_loss=0.1, n_retry=3, S_max=2.0):
        self.D_deadline, self.J_max = D_deadline, J_max
        self.p_loss, self.n_retry, self.S_max = p_loss, n_retry, S_max

    def cost(self, delay_mean, delay_var):
        return (0.5 * delay_mean + 2.0 * delay_var
                + 0.1 * self.p_loss * (self.n_retry + 1))

    def ladder(self, delay_mean, jitter, chain_integrity, delta=1e-3):
        if delay_mean > self.D_deadline and chain_integrity >= 1 - delta:
            return 'DELAYED'
        if chain_integrity < 1 - delta:
            return 'LOCAL_AUTH'
        if delay_mean > 2 * self.D_deadline:
            return 'SAFE_STOP'
        return 'NORMAL'
```
