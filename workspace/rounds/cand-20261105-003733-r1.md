# 第 1 轮（灵感循环第 1 轮）· SOC-NORM WALK：社会规范感知驱动的双足机器人视觉步行

> 检索/复核日期：**2026-11-05（UTC）**。赛事身份：宇树 **UniBot 世界挑战赛**（G1 + Dex1），32 项桌面任务，通才单模型赛道。本轮灵感词：**「社会规范理解」**、**「双足机器人」**、**「视觉定位」**。

## 0. 直觉：从「看见」到「懂约束」的跃迁

社会规范（如「不在人面前走」「沿人行道走」）从硬障碍视角看，是**可变形、动态的、语义化的允许行走场**。它们不是墙，而是「在这些地方可以活跃，哪里只能观望」。

双足机器人需要把这些**模糊的、连续的规范**转化为**离散的、可执行的步态指令**。视觉定位提供唯一的验证信号：步行后若观察到的世界变化无法被动作解释，说明规范场不完整。

**核心押注**：

> 用视觉构建「社会规范场」$s_t$，用「步态-空间折叠」将规范转化为可执行步行，用「视觉一致性残差」实现在线校准：当动作不解释观测变化，说明规范漏洞，退回全局定位。

## 1. 形式化定义

### 1.1 社会规范场 $s_t(x)$

$$\boxed{s_t(x) = \sum_i w_i \cdot C_i(x; p_i^{\text{人}}, b_i, q_i)}$$

约束函数：

| 类型 | 公式 | 权重 |
|---|---|---|
| 避让 $C_{\text{avoid}}$ | $\min_i (\|x - p_i\| - d_{\min}^{(i)})$ | 0.5 |
| 人行道 $C_{\text{path}}$ | $1 - \frac{\text{dist}(x, \text{中心线})}{\text{街宽}}$ | 0.4 |
| 禁入 $C_{\text{blocked}}$ | $\mathbb{1}[x \notin \text{红路}]$ | 0.1 |

其中 $d_{\min} = 0.3\text{m} \cdot \mathbb{1}[\text{站}] + 0.1\text{m} \cdot \mathbb{1}[\text{蹲}]$。

### 1.2 步态-空间折叠 $\mathcal{T}$

$$\boxed{\mathcal{T}(x_t, s_t) \rightarrow \{\tau_1, ..., \tau_K\}}$$

映射规则：

1. $s_t(x) \geq 0.2$ → 可行走，返回 $\tau$；
2. $s_t(x) < 0.2$ → 约束阻挡，缩短步幅 $L \leftarrow L \cdot s_t(x)/0.2$；
3. 前方阻挡 → 侧身转向 $\psi \leftarrow \text{atan2}(-s_t^\perp, s_t^\parallel)$。

### 1.3 视觉一致性残差 $r_{\text{viz}}$

$$\boxed{r_{\text{viz}} = \frac{\|\Delta I_{\text{obs}} - \Delta I_{\text{pred}}(\tau)\|}{\|I_t\|} + \lambda \cdot |\text{Missing}|}$$

若 $r_{\text{viz}} > \theta = 0.25$，触发：

$$\boxed{s_t \leftarrow \text{Refine}(s_t; r_{\text{viz}}), \quad \text{或} \quad \text{Return to global localization}}$$

## 2. 算法步骤

```
Algorithm: SOC_NORM_WALK(I_t, x_t, P_t_prev)

1:  P_t ← DetectAndInfer(I_t)               // 人群姿态+意图
2:  s_t ← BuildNormField(P_t, I_t)          // 规范场构建
3:  waypoints ← Astar(x_t, goal, s_t ≥ 0.2)  // 受约束路径
4:  τ_seq ← WalkPlanner(waypoints, x_t)     // 步态序列
5:  for τ ∈ τ_seq do
6:      I_before ← I_t
7:      Execute(τ)
8:      I_t ← GetFrame()
9:      r_viz ← VisualResidual(I_before, I_t, τ)
10:     if r_viz > 0.25 then
11:         s_t ← RefineField(s_t, r_viz)   // 权重迭代放大
12:         if refinement_fail then
13:             return "FALLBACK_GLOBAL"
14:     end if
15:  end for
16:  return "SUCCESS"
```

| **总计** |  | **<80ms/步** |

## 4. 正确性论证

**命题 1（完备性）**：若 $s_t$ 包含所有硬约束，则 $\mathcal{T}(x_t, s_t)$ 的输出序列 $\tau$ 在 $t \in [t, t+K]$ 上无碰撞。

**命题 2（充分性）**：若 $r_{\text{viz}} < \theta$，则 $\mathbb{P}(\text{未发现约束}) < 0.05$。

**命题 3（回退安全）**：若 $\gamma_t = \frac{\#\{r_{\text{viz}} < \theta\}}{K} < 0.3$，退回到上一「合规状态」不增加碰撞概率。

## 5. 可证伪假设

| 编号 | 假设 | 证伪条件 |
|---|---|---|
| H1 | 规范场 $s_t \geq 0.2$ 的路径碰撞率 < 1% | 实际碰撞率 > 5% |
| H2 | 视觉一致性 $r_{\text{viz}}$ 能区分 ID/OOD，AUROC > 0.85 | AUROC < 0.65 |
| H3 | 在人群密集场景（人密度 > 2人/m²）下成功率 > 60% | 成功率 < 40% |
| H4 | 只用权重调整，不增参数 | 必须引入新的学习模块 |
| H5 | 规范场更新不引入额外模型 | 使用额外的视觉-语言对齐模型 |

## 6. 本轮最大的风险

**社会规范场的误判**：若检测将「正在靠近的行人」误判为「站立者」，$d_{\min}$ 设置为 0.3m 将不足以避免突然接近，导致在人群快速变换的室内环境中，误判的概率显著升高。

# 第 1 轮产物 · SOC-NORM WALK 技术报告

## 1. 结论

SOC-NORM WALK 通过「视觉-社会规范场」$\rightarrow$「步态-空间折叠」$\rightarrow$「视觉一致性回退」的三级映射，实现从感知到行走的合规转化。它不训练全局模型：检测、姿态、意图均为离线训练模块；规范场仅调整线性权重。

## 2. 符号

- $I_t \in \mathbb{R}^{H \times W \times 3}$：RGB 图像
- $P_t = \{(p_i, b_i, q_i)\}_{i=1}^N$：人群状态
- $s_t: \mathbb{R}^2 \rightarrow \mathbb{R}^+$：规范场
- $\mathcal{T}: \mathbb{R}^2 \times \mathcal{S} \rightarrow \{\tau_k\}$：步态映射
- $r_{\text{viz}}$：视觉一致性残差

## 3. 规范场公式

$$s_t(x) = 0.5 \cdot C_{\text{avoid}}(x) + 0.4 \cdot C_{\text{path}}(x) + 0.1 \cdot C_{\text{blocked}}(x)$$

约束阈值：$s_t(x) \geq 0.2$ 可行。

## 4. 伪代码

```python
def SOCMNormWalk(I_t, x_t):
    P_t = DetectAndInfer(I_t)
    s_t = BuildNormField(P_t, I_t)
    path = AstarConstrained(x_t, goal, s_t, thresh=0.2)
    tau_seq = WalkPlanner(path, x_t)
    
    for tau in tau_seq:
        I_before = get_frame()
        Execute(tau)
        I_after = get_frame()
        r_viz = compute_residual(I_before, I_after, tau)
        
        if r_viz > 0.25:
            s_t = RefineField(s_t, r_viz)
            if refinement_fails():
                return "FALLBACK_GLOBAL"
    return "SUCCESS"
```
