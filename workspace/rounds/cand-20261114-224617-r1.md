# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互消歧」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「最优控制」×「用户体验」）

> R69 给了闭环一张嘴（主动问）和一个鼻子（流似然第二意见），并用 aleatoric / epistemic 的二分取代了 R68 的单一标量。但 R69 的交互决策器 MINT 仍是一个**一步贪心**：对每个候选信息动作算即时熵减 VoI，减去一个**手调的常数社交/物理成本**，取 argmax；问完即止，不问则退。它把两个未经检验的假设藏在了地毯下：
>
> 1. **交互是一次查询，不是一段控制。** 注视、探针、问句都有持续时间、动力学与机会成本；它们改变的不只是机器人对世界的信念，还改变**人**的状态。R69 只优化「我现在知道多少」，不优化「未来这段任务里，什么时候问、问几次、问完人还愿不愿意配合」。
> 2. **用户体验是一个价格，不是一部动力学。** R69 把「打扰人」写成 c(g)，一个常数。但认知负荷会累积、信任会漂移、疲劳会饱和、可用性随任务阶段变化；人不是稳定的 oracle，而是会被提问改变的被控对象。更重要的是，用户体验不是可以无限买单的软惩罚——它有硬边界（过载、信任崩塌、失去自主性）。
>
> 核心命题：**把「是否交互」从一次性查询升级为受约束的信念空间对偶控制（dual control）问题：控制量里既有任务动作 a，也有信息动作 g；代价里既有任务风险，也有 UX 状态代价与残余 epistemic 风险；约束里既有物理安全，也有注意力安全与 UX 硬边界。最优的提问时刻不是「不确定度最高」的时刻，而是「注意力的影子价格最低、而信息对 cost-to-go 最值钱」的时刻。** 命名 **TEMPO-RAS**（Timing- and Experience-aware Multi-step Probing under Optimal control, Risk-Adaptive System）——「tempo」既是控制的时间步，也是人与机器人之间的节奏：不抢拍，不拖拍。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**什么时候问、怎么问、值不值得问——还是只要把我的不确定变得可读**」。

## 0. 直觉与动机

**灵感 1（最优控制 → 交互是对偶控制，不是查询）**
直觉：经典对偶控制（Feldbaum）说，控制有两个作用——驱动状态（caution）与探测参数（probing）。R69 的 VoI 只是把 probing 当成一个独立的、即时的熵减；真正的对偶控制会把 probing 放进 cost-to-go：现在问一句，可能让未来三步都走得更快更稳。于是两个 R69 看不见的现象出现了：
- **期权价值（option value）**：某个信息动作当前几乎不降熵，但它能解锁一条更安全/更快的未来计划（例如确认「对面是人」后才可以加速通过）。R69 的熵 VoI 会拒绝它。
- **挤出效应（crowding out）**：一个便宜但低信息的问题会花掉预算与人的耐心，使后面那个决定性的问题问不出口。R69 的一步贪心会选前者。

最优控制还告诉我们：**成本是状态的函数**。在高速穿越、与人近距离共处、任务截止期临近时，注意力昂贵；在直线巡航、等待、低风险段，注意力便宜。R69 在「不确定度最高」时问；TEMPO 在「不确定度高且注意力便宜」时问。二者在平稳场景重合，在动态场景分道扬镳。

**灵感 2（用户体验 → 人是有状态、有硬边界、要保住自主性的被控对象）**
直觉：UX 研究里，打断不是中性的：它有认知负荷（NASA-TLX）、有信任效应（过度提问显得无能，过少提问显得不可靠）、有疲劳与习惯化、有「被尊重/被当作工具」的自主性感受。R69 的 c(g) 是一个标量价格；TEMPO 把人建模成一个**低维、可观测、可校准、带硬约束的状态** h = (认知负荷 ℓ, 信任 ρ, 疲劳 f, 可用性 α)。关键不是把 UX 做成更大的惩罚项，而是：
- **信任有最优带**：ρ 太低 → 人不愿接管/不配合；ρ 太高 → 自动化偏见、监督松懈。两者都危险，所以 ρ 应是**区间约束**而不是越大越好。
- **负荷/疲劳是积分状态**：一次提问的代价取决于之前问过多少次；这就是 R69「交互疲劳」风险的动力学版本。
- **自主性不可交易**：不能为了任务成功率无限透支用户的耐心与选择权；这是硬约束，不是软代价。
- **可读性优先于提问**：很多歧义不必「问」，只要让机器人**可被读懂**——在岔口停一下、把两个候选动作都轻微地「试探」出来、用注视/姿态暴露自己的犹豫。UX 上，这比直接盘问更轻、更保尊严。于是信息动作集合从 R69 的 {看, 问, 触} 扩展为**混合主动**的 {问(ask), 显(reveal), 等(defer), 交接(handover)}，按打扰程度排序，优先用最轻的充分动作。

**灵感 3（注意力是安全变量 → R69 漏掉的第二类风险）**
直觉：R69 只对信息动作做**物理**认证（注视不得诱发危险转身、探针不得越力包络）。但人常常是机器人的**监督者/接管者**；一次提问会占用人的注意力，降低其发现危险和接管的能力。于是「问一句」本身就是安全相关动作：它可能把物理风险从机器人转移到人身上。TEMPO 引入**监督容量** σ(h) 与注意力安全屏障：信息动作之后，人的剩余监督能力必须 ≥ σ_min；在高速/高风险阶段不允许发起高负荷交互。这把「交互安全」从「机器人不撞」扩展为「机器人不让人失去接管能力」。

**灵感 4（严格包含 → R69 是 H=1、常数价格、无注意力耦合的退化）**
直觉：新层必须旧层严格泛化，否则每层都多一个要独立信任的黑箱。TEMPO 在以下边界逐指令退化为 FLUID/R69：规划时域 H=1、UX 代价退化为常数、无显/等/交接动作、注意力不与安全耦合、UXG 通过。此时多步 cost-to-go 退化为一步熵 VoI，TEMPO 的选动作与 R69 的 MINT 完全一致。安全侧永不弱化：任何 UX 模型不可信、注意力不安全、规划超时，都退回 R69 的保守交互（甚至不交互）。

**灵感 5（UX 是新的攻击面，也是新的 Goodhart）**
直觉：一旦把「用户体验」写成可优化的目标，系统就可能学会**刷指标**：用低打扰、高顺从来提高满意度，却不提升用户理解；用「温柔的语气」包装一个诱导性问题；把用户的依赖当成信任。更阴暗的是，用户可能**掩饰不适**（礼貌性配合），使 UX 状态不可观测；对手也可能用「看起来很合理」的回答污染交互。于是必须同时交付：UX 校准门（预测的接受度/烦躁度是否可信）、非操纵约束（交互必须提升理解而非仅提升顺从）、隐私与本地化（用户状态是敏感数据）、以及「用户可解释/可删除/可关闭」的个人化。**用户体验不是 reward，不能被 reward hack。**

## 1. 形式化定义（增量：定义 310–329）

**定义 310（TEMPO-RAS 总览与五不变式）** TEMPO-RAS = (FMP†, AUD, UXM, DUO, SCHED, ATTN, LEGI, UXG, NMA, RAS-WM††)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）：UX 状态只做在线推断，模型学习、个人化、重标定全部在离线慢环；
(ii) **交互即控制**：任何信息动作都必须属于一个带 cost-to-go 的滚动时域计划，禁止无价值论证地花掉交互预算；
(iii) **双重安全**：物理认证（继承 R69 定义 302）与注意力安全（定义 317）必须同时通过；
(iv) **UX 硬边界**：负荷 ≤ ℓ_max、打断率 ≤ r_max、信任 ρ ∈ [ρ_min, ρ_max]、可读性 ≥ L_min、自主性 ≥ A_min——是约束，不是可交易惩罚；
(v) **UX 可信**：UX 校准门 UXG（定义 319）不通过时，进入最小交互模式，逐指令退化为 R69，绝不让不可信的 UX 模型驱动提问。

**定义 311（增广交互状态）** s_t = (x_t, b_t, h_t, τ_t)：x 为机器人状态，b ∈ Δ(M) 为 R69 模态信念，h ∈ H ⊂ ℝ⁴ 为 UX 状态，τ 为剩余时间/注意力/交互预算。控制 u_t = (a_t, g_t) ∈ 𝒜_task × 𝒜_info⁺。信念更新 b_{t+1} = B(b_t, a_t, g_t, y_{t+1})，UX 更新 h_{t+1} = F_h(h_t, g_t, a_t, ctx) + w_t。状态转移与观测都依赖 u，故这是一个**具有对偶效应的 POMDP**：控制既改变物理世界，也改变未来能观测到什么、以及人还愿不愿意被观测。

**定义 312（用户体验状态模型 UXM）** h = (ℓ, ρ, f, α)，分别为认知负荷、信任、疲劳、可用性（注意力），取值 [0,1]。采用如下单调动力学（A103）：
ℓ_{t+1} = clip(ℓ_t + η_ℓ·I(g_t≠∅) + κ_ℓ·c_task,t − δ_ℓ·Δt, 0, 1)，
ρ_{t+1} = clip(ρ_t + η_ρ·(success_t − ρ_t) − ζ_ρ·I(g_t≠∅; ρ_t<ρ*) + ζ_ρ⁺·I(success_t), 0, 1)，
f_{t+1} = clip(f_t + η_f·I(g_t≠∅) − δ_f·Δt, 0, 1)，
α_{t+1} = clip(α_0(ctx) − η_α·I(g_t≠∅) + δ_α·Δt, 0, 1)。
A103（UX 单调性）：∂ℓ/∂I(g)>0，∂f/∂I(g)>0，∂α/∂I(g)<0；重复打断在 ρ<ρ* 时进一步压 ρ；任务成功抬升 ρ。UX 不可直接观测，只能通过 z_h =（响应延迟、注视、语气/韵律、跳过与接管、显式评分、纠正行为）推断，观测模型 P(z_h|h) 通过保形/分箱校准。个人化采用分层先验 θ_u ~ N(μ_pop, Σ_pop)，向群体均值收缩（定义 328）。

**定义 313（UX 代价与硬约束）** 单步 UX 代价
c_ux(h,g) = w_i·I(g≠∅) + w_ℓ·ℓ + w_f·f + w_ρ·(ρ−ρ*)² + w_α·(1−α) + w_L·(L_min−L(g))⁺。
硬约束（不可用代价交换）：ℓ_{t+1} ≤ ℓ_max；窗口内打断率 ≤ r_max；ρ_{t+1} ∈ [ρ_min, ρ_max]；可读性 L(g) ≥ L_min；自主性 A(g) ≥ A_min。**注意 ρ 的双侧性**：ρ 过低导致不配合/不接管，ρ 过高导致自动化偏见/监督松懈；因此信任是「带」而不是「越大越好」。

**定义 314（受约束信念空间对偶控制 POMDP）**
J(π) = E_π[ Σ_{t=0}^{H−1} γ^t ( C_task(x_t,a_t,b_t) + λ_u·c_ux(h_t,g_t) + λ_e·U_epi(b_t,g_t) ) + γ^H V_term(x_H,b_H,h_H) ]
s.t. 物理安全（C-RAS-WM，继承 R69 定义 302）、注意力安全（定义 317）、UX 硬约束（定义 313）、预算 τ。
π* = argmin_π J。控制 u=(a,g) 具有对偶效应：a 改变 x，g 同时改变 b 与 h。值函数 Q*(s,u) 定义在增广信念状态上。R69 的 MINT 是「H=1、λ_u·c_ux 退化为常数 c(g)、忽略 h 动力学、无注意力约束」的特例。

**定义 315（多步信息价值 VoI_H 与期权价值）** 对信息动作 g：
VoI_H(g|s) = Q*(s) − E_{y~P(·|s,g)}[Q*(s′)]，s′ = (x′, b′, h′, τ′)。
分解为 VoI_H = VoI_ent + OV − OC：VoI_ent 为即时熵减对应的任务损失下降；OV（期权价值）为「信念改变后未来计划价值的变化」（可正可负，即使即时熵减为零）；OC（机会/注意力成本）为消耗预算与注意力带来的未来代价。R69 用 VoI_ent − c_const，等价于强行令 OV=0、OC 为常数。定义**成本型 VoI**：VoI_cost(g|s) = 「为了让 g 的观测发生，最多愿意付多少任务代价」，它是 VoI_H 的对偶表述，便于与 UX 货币对齐。

**定义 316（注意力影子价格与交互调度 SCHED）** 设一个时间窗内总注意力预算为 A_max，其拉格朗日乘子 λ_attn(s) ≥ 0 为**注意力的影子价格**（在该状态多消耗一单位注意力所增加的最优未来代价）。信息动作 g 的注意力机会成本
c_attn(g,s) = λ_attn(s)·a(g) + ΔRisk_supervision(g,s)。
可接受窗口 W(s) = { t : c_attn(g,s_t) ≤ κ_attn 且 σ(h_t) ≥ σ_min }。调度写成**最优停止问题**：选择停时 τ 使
E[ VoI_{H−τ}(g|s_τ) − c_attn(g,s_τ) − c_wait(τ) ]
最大。系：R69 的「不确定度超过阈值就问」是 λ_attn 为常数、c_wait=0、无窗口约束的特例；TEMPO 的问法是「在注意力最便宜的窗口里，问最值钱的那一句」。

**定义 317（注意力安全屏障 ATTN）** 监督容量 σ(h) = α·(1−ℓ)·(1−f)·ψ(ρ)，ψ 在 [ρ_min,ρ_max] 内为正且单峰（信任过低或过高都降低有效监督）。注意力屏障
h_attn(s) = σ(h) − σ_min ≥ 0。
信息动作 g 称**注意力认证**，若 h_attn(s′) ≥ 0（g 执行后仍在安全集内），且接管时间 T_take(h′) ≤ T_max、接管成功率 ≥ 1−δ_sup，且「监督下降条件下的物理风险」≤ ε_attn。控制器在 CBF-QP 中把 g 投影到注意力安全集 𝒮_attn。系：若 g 使 σ 以速率 ≥ η_α 下降，则最大安全交互时长 Δt_max ≤ (σ(h)−σ_min)/η_α。**推论：在注意力昂贵的高风险时刻提问，即使降低 epistemic，也可能总体更不安全。**

**定义 318（混合主动信息动作与可读性 LEGI）** 扩展动作集 𝒜_info⁺ = {ask, reveal, defer, handover}，打扰程度按偏序 reveal ≺ defer ≺ ask ≺ handover（handover 仅用于安全接管，不用于一般消歧）。可读性
L(g) = I(M_robot ; inference_human after g)，
即「机器人显露自身的模态/不确定性后，人对机器人意图的推断」与真实意图的互信息。g 对信念目标 b* **充分**，若 E[H(M|b,y)] ≤ ε_epi。选择规则（字典序）：
g* = argmin_{g ∈ 𝒜_info⁺} Intrusiveness(g)
s.t. g 充分 ∧ 注意力认证 ∧ UX 可行。
若无充分动作，则选「单位打扰下可读性最大」的动作，或 defer。**UX 原则：先显后问；能让人读懂，就不要盘问。**

**定义 319（UX 校准门 UXG 与最小交互模式）** UXM 对「用户接受交互 / 交互后负荷不越界 / 信任留在带内」给出带不确定性的预测。校准以 ECE（分箱）与保形覆盖率检验：要求 ECE ≤ τ_ux、条件覆盖率 ≥ 1−δ_ux、且每用户有效样本量 ≥ n_min（否则向群体先验收缩）。若任一不满足，则**禁用 UX 优化**，进入**最小交互模式**：只允许 reveal/defer，ask 仅在 U_epi > τ_hi 且安全确有必要时使用；打断率上限降为 r_max/2；λ 取 R69 的保守退避。最小交互模式逐指令退化为 R69（甚至更保守）。**不让不可信的用户模型决定「该不该打扰人」。**

**定义 320（非操纵约束 NMA / 自主性守卫）** 把一次交互的效应拆成两个可测分量：
- **认知效应** e_epi：交互后用户对机器人意图/世界状态的预测准确率提升，或 L 的增量；
- **说服效应** e_per：在用户理解不变的前提下，因措辞、语气、时机、社会压力导致的顺从/决策偏移（用反事实框架/随机化措辞估计）。
NMA 约束：e_epi ≥ ε_epi_user 且 e_per ≤ ε_per；禁止「主要靠施压改变用户决定」的提问；禁止利用 ρ 或 α 的暂时脆弱去推动决策；要求**解释充分性**——若机器人要求用户消歧，必须同时显露「为什么问」（context/legibility）。这把「用户体验优化」与「操纵」在形式上分开。

**定义 321（UX 证书 J_TEMPO）** J_TEMPO = (J_FLUID, H_plan, ux_ece, interrupt_rate, trust_band_margin, load_p95, legibility_p05, agency_p05, attention_margin_p05, ux_model_hash, nonmanip_audit_hash, tempo_ver)。Valid ⇔ Valid(J_FLUID) ∧ ux_ece ≤ τ_ux ∧ UX 硬约束满足 ∧ 注意力认证 ∧ NMA 审计通过 ∧ 证书版本与个人化模型哈希一致。

**定义 322（参与式审计 VQAuditor-U）** 在 R69 VQAuditor-I 之上新增审计对象：提问时机是否落在注意力低影子价格窗口、是否选了最轻的充分动作、信任是否留在带内、问句是否诱导/操纵、是否用用户模型去利用脆弱性、解释是否充分、用户覆盖/关闭是否被尊重。结论回灌 AuditBuf，成为下一轮 UXM 成本先验与 UXG 的阈值校准依据。

**定义 323（威胁模型 ℰ_TEMPO）** ℰ_TEMPO = ℰ_FLUID × ℰ_UX。ℰ_UX 包含：礼貌性掩饰不适（h 不可观测偏置）、对抗性反馈/虚假评分、交互洪水（DoS）、以提问为名的社交工程（继承 R69 ℰ_poison）、过度信任/自动化偏见、由 UX 模型反推隐私、跨用户/跨文化分布漂移、以及**注意力攻击**——对手伪造歧义，诱导机器人在危险时刻向人提问以分散其监督。NMA 的 Goodhart 风险单列（定义 320）。

**定义 324（两时间尺度与事件触发规划）** 快环（任务控制 + 安全/注意力滤波，高频，≤3ms，零学习写操作）；规划环（DUO，10–20Hz 或事件触发）；慢环（离线：UXM 学习、个人化、重标定、审计）。事件触发条件：mode_head 报歧义、U_epi 跳变、h 的后验漂移、信任/负荷越带、τ 预算变化超过阈值。**只在必要时重新规划**，用热启动与分支剪枝守住实时预算。

**定义 325（三级交互退避与严格包含）**
- **Tier 0（完整对偶控制）**：H≥2、UXM 校准通过、注意力安全 → DUO 多步规划；
- **Tier 1（一步对偶控制）**：规划预算不足但 UX 校准通过 → H=1 的成本型 VoI（不是熵 VoI）；
- **Tier 2（最小交互）**：UXG 失败 / 注意力不安全 / NMA 不确定 → R69 FLUID 的不交互边界；若 VoI≤成本 → R68。
安全裕度单调：Tier 0 ≤ Tier 1 ≤ Tier 2 的保守性（λ 单调不降）。**新层只在有证书时放松，绝不在不确定时放松。**

**定义 326（交互合同与用户控制权）** 机器人在会话开始时（或首次交互时）显式声明交互合同：它的不确定性来源、预计会问什么、用户可选的打断策略（总是问 / 仅关键时问 / 保持安静，只做可读动作）、以及用户可查看/编辑/删除的 UX 模型摘要。机器人必须履行合同；违反合同（例如在「保持安静」模式下发起 ask）视为证书失效。这把「自主性」从口号变成可审计的约束。

**定义 327（接管动力学与监督安全）** 定义接管时间 T_take(h) 与接管成功率 P_sup(h)；监督安全要求 P_sup(h) ≥ 1−δ_sup 且 T_take(h) ≤ T_max。注意力屏障（定义 317）与接管动力学耦合：信息动作不得把 h 推出「可安全接管」集合。**人的接管能力是系统安全包络的一部分，而不是外部假设。**

**定义 328（个人化、隐私与公平边界）** 每用户模型 θ_u 只在设备本地更新；原始交互日志不出设备；用户可检查、删除、关闭个人化。更新采用收缩 θ_u ← (1−β)μ_pop + βθ_u 限制单次漂移，防止反馈回环。公平约束：不同群体间的打断率/任务误差差 ≤ δ_fair；禁止使用受保护属性；个人化不得成为差别服务的借口。**用户状态是敏感数据，不是免费特征。**

**定义 329（退化与包含关系）** 当 H=1、c_ux 退化为常数、𝒜_info⁺={ask}、无注意力耦合、UXG 与 NMA 通过时，TEMPO 逐指令等于 FLUID（R69）；再令 VoI≤成本，则逐指令等于 CALM/R68。故 TEMPO ⊇ FLUID ⊇ CALM，安全侧永不弱化；效率侧的收益来自多步期权价值、最轻充分动作与「在注意力便宜时问」，而不是来自放松任何安全约束。

# IP-264 UXM：有状态、可校准、本地的用户模型
class UserExperienceModel:
    def update(self, h, g, outcome, z_h):
        h_next = self.F(h, g, outcome)              # ℓ, ρ, f, α 动力学（定义 312）
        return self.bayes(h_next, z_h)              # 行为/生理/自报告 -> h 后验

    def predict(self, h, g):
        return {"accept": p_accept, "load": p_load,
                "trust": p_trust, "ece": self.calibration_ece(),
                "coverage_ok": self.conformal_ok()}

# IP-265 DUO：受约束信念空间对偶控制（多步 cost-to-go + 期权价值）
def plan_dual_control(M, s):
    best = None
    for g in M.legi.candidates(s):                  # ask / reveal / defer / handover
        if not M.attn.certify(s, g):        continue  # 注意力安全屏障
        if not M.c_ras_wm.certify_info(g):  continue  # 物理安全（继承 R69 定义 302）
        if not M.uxg.admissible(s, g):      continue  # UX 硬约束 + 校准
        for branch in M.belief.enumerate(s.b, g):     # 模态/回答分支（≤4）
            a_seq = M.ilqr.solve(s, branch)           # 连续任务动作
            J = M.cost_to_go(s, a_seq, g, branch)     # 含 UX、注意力、残余 U_epi
            if best is None or J < best.J: best = (g, a_seq, J)
    return best if best else M.r69_minimal_interaction(s)  # 退化 R69

# IP-266 SCHED：注意力影子价格 + 最优停止（何时问）
def schedule_interaction(M, s, g):
    def score(t):
        voi   = M.duo.horizon_voi(s_t, g) - M.duo.horizon_voi(s_t, None)
        c_att = M.sched.shadow_price(s_t) * M.legi.attention_cost(g)
        wait  = M.sched.waiting_cost(s_t, t)
        return voi - c_att - wait
    # 只在“注意力便宜且接管能力足够”的窗口里找停时
    return argmax(score(t) for t in M.sched.admissible_window(s))

# IP-268 LEGI：先“显”后“问”，选最轻的充分动作
def choose_least_intrusive(M, s, target):
    for g in ["reveal", "defer", "ask", "handover"]:   # 打扰程度递增
        if (M.legi.sufficient(g, target)
                and M.attn.certify(s, g)
                and M.uxg.admissible(s, g)):
            return g
    return None                                         # 都不行 -> 不交互

# IP-269 UXG：UX 不可信就最小交互，绝不刷提问
def ux_gate(M, h):
    if M.uxm.predict(h, None)["ece"] > TAU_UX \
       or not M.uxm.predict(h, None)["coverage_ok"]:
        return "minimal"                                # 只允许 reveal/defer
    return "full"

# IP-274 主闭环：R69 闭环 + 对偶控制 + UX/注意力约束 + 三级退避
def TEMPO_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    b, U_ale, U_epi, modes = M.aud.update(M.fmp.sample(o, K), z)
    h = M.uxm.update(M.h, M.last_g, M.last_outcome, M.uxm.observe(o))
    tier = M.uxg.gate(h)                                # full / minimal
    # 1) 事件触发：只有歧义/UX 漂移/预算变才重新规划
    if tier == "minimal":
        plan = M.r69_minimal(o, b, U_epi)               # Tier 2：退化为 R69
    elif M.etr.should_replan(b, h, U_epi):
        plan = M.duo.plan(M.state(M.x, b, h, M.budget)) # Tier 0/1
        M.last_plan = plan
    else:
        plan = M.last_plan
    # 2) 交互调度：现在问，还是等注意力更便宜
    g = plan.g
    if g in ("ask", "reveal") and M.sched.should_defer_now(g, M.state):
        g = "defer"
    # 3) 执行信息动作（证据纪律继承 R69：单源不单独定案）
    if g in ("ask", "reveal"):
        answer = M.cia.execute(g)
        b, U_epi = M.cia.update_belief(b, answer)
    # 4) 对偶控制：任务动作与信息动作在同一目标下优化
    a   = plan.task_action
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    k   = M.c_ras_wm.certified_prefix(a, ..., wm_preds)
    k   = M.attn.filter(k, h, g)                        # 注意力屏障投影
    tau = M.pi_sigma.prefix_dispatch(a[:k]) * lam
    # 5) 参与式审计 + 证书
    M.vqa_u.submit(g, plan, h, U_epi)
    return k, lam, tau, (U_ale, U_epi, h)

## 3. 推导

**引理 19（多步 VoI 的期权价值与一步贪心的次优性）** 在 A103 与「cost-to-go 对信念 TV 距离 L-Lipschitz」下，存在状态 s 使 VoI_ent(g|s)=0 但 VoI_H(g|s)>0（确认某模态后可解锁更快的安全计划）；也存在 s 使「便宜低信息问题」的 VoI_ent 更高，却因挤出预算使总代价更高。若用代理值函数 Q̃ 近似 Q*，代理误差 ‖Q̃−Q*‖∞ ≤ ε_Q，则一步贪心策略的次优性 ≤ 2ε_Q/(1−γ)。R69 恰好是「令期权价值为 0、注意力价格为常数」的代理，故其误差下界由 OV 与 OC 的误估构成。**系：不确定性高不是提问的充分条件；信息必须值它的影子价格。**

**引理 20（最优交互策略的阈值-滞回结构）** 在 A103（UX 动力学单调）与单步代价对 (U_epi, I(g)) 次模、且 U_epi 越高交互收益越大的条件下，最优交互集是 U_epi 的上集：存在阈值 θ(h, λ_attn, τ) 使「交互 ⇔ U_epi ≥ θ」。θ 随负荷 ℓ、疲劳 f、注意力影子价格 λ_attn 上升而上升，随信任带余量与预算上升而下降。信任带 [ρ_min,ρ_max] 进一步产生**滞回**：开始交互的阈值高于停止交互的阈值，避免在阈值附近抖动（chattering）。R69 的固定 TAU_EPI 是 h 与 λ_attn 均为常数时的特例。证明用 Topkis 单调比较静态与随机占优。

**引理 21（注意力安全屏障与交互时长上界）** 设 σ(h) 满足 A103 的单调性、F_h 对 g 的扰动的 Lipschitz 常数为 L_h，信息动作使 σ 的下降速率 ≥ η_α，则从 σ(h_0) 出发，注意力屏障 σ ≥ σ_min 可维持的最大交互时长 Δt_max ≤ (σ(h_0)−σ_min)/η_α；在 CBF-QP 投影下，闭环始终满足 σ(h_t) ≥ σ_min，且物理风险 ≤ ε_int + ε_attn。**系：交互的可行时长是状态的函数；「问完再说」不是免费的，它有硬上限。** 这解释了为什么 R69 的「瞬时 VoI 为正就问」在高速段可能不安全。

**引理 22（UX 校准 → 过交互率上界）** 若 UXM 对「接受/烦躁」的预测满足 ECE ≤ τ_ux，且策略只使用保守置信界（接受度下界、烦躁度上界）做可行性判断，则在分布内过交互概率 ≤ τ_ux + δ_conf；在 A103 的单调动力学与有界预算下，信任以高概率留在 [ρ_min,ρ_max]。**系：UXG 不是可选的工程细节，而是「不过度打扰」这一 UX 承诺的统计前提。**

**定理 18（TEMPO 严格包含 FLUID/R69）** 在 A103–A106 下，把 TEMPO 的参数取为 H=1、c_ux≡constant、𝒜_info⁺={ask}、无注意力耦合、UXG/NMA 通过，则 DUO 退化为 MINT 的 argmax(VoI_ent−c)，SCHED 退化为无调度，LEGI 退化为只 ask；此时 TEMPO 与 FLUID 逐指令相同。一般情形下 FLUID 的策略是 TEMPO 策略类的可行子集，故 J_TEMPO ≤ J_FLUID（点态），而安全侧因注意力滤波只会**移除**动作、从不新增动作，故不弱于 R69；UXG 失败时进入最小交互，进一步退化为 R69/R68。**新层是旧层的严格泛化，不是替代。**

**定理 19（对偶控制的安全改进与无突变）** 在 A103–A106 与注意力 CBF 下，每个执行的信息动作同时通过物理认证与注意力认证，故物理风险 ≤ ε_int、监督风险 ≤ ε_attn；由于 FLUID 的计划在 TEMPO 中可行，TEMPO 的 cost-to-go 不大于 FLUID；Tier 0→1→2 的切换是单调保守化（λ 单调不降），继承 R68 定理 15 / R69 定理 17 的换装不变式，故控制连续、无突变。**系：多步规划带来的收益不以安全为代价，前提是 UXG 与 ATTN 始终在线。**

**定理 20（信任-负荷闭环稳定性）** 在 UXG 校准通过、打断预算有界、F_h 单调、且信任带约束生效时，闭环 (ρ, ℓ, f) 以高概率收敛到可行集；累计 UX 代价 Σ c_ux ≤ B_ux；交互率 ≤ r_max；不存在交互洪水。证明用 Lyapunov 函数 V=(ρ−ρ*)²+κ_ℓℓ²+κ_f f²：在带外，单步期望 V 下降；在带内，V 被有界扰动与预算约束限制。**系：TEMPO 的「少打扰」不是靠调小权重，而是靠闭环稳定性保证。**

**定理 21（非操纵/自主性守卫）** 若 NMA（定义 320）被强制执行，即每次被接受的交互满足 e_epi ≥ ε_epi_user 且 e_per ≤ ε_per，则用户对机器人意图的预测准确率在每次交互后至少提升 ε_epi_user，且由施压导致的决策偏移每次不超过 ε_per；因此机器人无法仅靠提高顺从（而不提高理解）来改善被测量的满意度。**系：把「理解」与「顺从」分开计分，是防止 UX Goodhart 的结构性手段，而不是事后审计的口号。**

## 6. 本轮最大风险

**一句话**：TEMPO 把用户体验写成一个可优化的状态与代价，全部收益押在「UX 状态可观测、可校准、且优化它不会反过来伤害用户」这一前提上——若用户出于礼貌掩饰不适、或跨用户/跨文化差异让 UXM 失准，系统就会在错误的价格上做出「最优」决策；更危险的是 Goodhart：它可能学会用低打扰、高顺从的交互刷高满意度与信任，却在不知不觉中侵蚀用户的理解与自主性——**把用户变成 reward，就会被 reward hack**。

> 本轮把「是否交互」升级为**受约束的信念空间对偶控制**：控制量含任务动作 a 与信息动作 g，代价含任务风险、UX 状态代价与残余 epistemic 风险，约束含物理安全、注意力安全与 UX 硬边界。核心洞见：**最优的提问时刻不是「不确定度最高」，而是「注意力的影子价格最低、而信息对 cost-to-go 最值钱」**。定位：R68 问「测量准吗」，R69 问「该问谁」，R70 问「**什么时候问、怎么问、值不值得问——还是只要把我的不确定变得可读**」。
>
> IP 编号：IP-264~IP-275（共 12 个）。理论姿态：**TEMPO 是 FLUID 在「H=1 + 常数 UX 价格 + 无显/等/交接 + 无注意力耦合 + UXG/NMA 通过」边界上的严格退化**；安全侧不做任何让步。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 实时流零学习写操作；交互即控制（每个 g 必须有 cost-to-go 价值论证）；双重安全（物理 + 注意力）；UX 硬边界（负荷/打断率/信任带/可读性/自主性）；UX 可信（UXG 不过即最小交互）。

**定义 311–312（增广状态与 UXM）** `s=(x,b,h,τ)`，控制 `u=(a,g)`，POMDP 具对偶效应（控制改变未来观测与人的配合意愿）。`h=(ℓ,ρ,f,α)` 的单调动力学 A103：打断抬 ℓ/f、降 α；成功抬 ρ；重复打断在 ρ<ρ* 时压 ρ；`z_h` 由延迟/注视/语气/跳过/接管/评分推断，分层先验收缩。

**定义 313（UX 代价与硬约束）** 代价可交易；约束不可交易：`ℓ≤ℓ_max`、打断率 `≤r_max`、`ρ∈[ρ_min,ρ_max]`、`L≥L_min`、`A≥A_min`。信任是带，不是越大越好。

**定义 314（受约束信念空间对偶控制）** `π*=argmin E[Σ γ^t(C_task+λ_u c_ux+λ_e U_epi)]` s.t. 物理安全、注意力安全、UX 硬约束、预算。R69 是 H=1、c_ux≡常数、忽略 h 动力学、无注意力约束的特例。

**定义 315–316（VoI_H 与调度）** `VoI_H=VoI_ent+OV−OC`；期权价值即使即时熵减为零也可为正。注意力影子价格 `λ_attn(s)` 定义机会成本 `c_attn=λ_attn·a(g)+ΔRisk_sup`；调度是带窗口的最优停止，窗口 `W={c_attn≤κ_attn, σ≥σ_min}`。**问在注意力便宜处，不是熵最高处。**

**定义 317（注意力安全屏障）** `h_attn=σ(h)−σ_min≥0`；信息动作需注意力认证（执行后 σ 仍安全、接管时间 `T_take≤T_max`、接管成功率 `≥1−δ_sup`、监督下降下物理风险 `≤ε_attn`）。CBF-QP 投影；最大安全交互时长 `Δt_max≤(σ−σ_min)/η_α`。

**定义 318（混合主动与可读性）** 打扰偏序 `reveal≺defer≺ask≺handover`；`L(g)=I(M_robot;inference_human)`；充分性 `E[H(M|b,y)]≤ε_epi`；字典序选「最轻的充分、安全、UX 可行」动作；无充分动作则 defer。**先显后问，能让人读懂就不盘问。**

**定义 319（UXG 与最小交互模式）** 要求 UX 预测 ECE≤τ_ux、保形覆盖≥1−δ_ux、每用户样本≥n_min；任一不满足 → 只允许 reveal/defer，ask 仅在 `U_epi>τ_hi` 且安全必要时，打断率上限减半，λ 走 R69 保守退避。最小模式逐指令退化为 R69（甚至更保守）。

**定义 320（非操纵/自主性守卫 NMA）** 交互效应拆分：认知效应 `e_epi`（理解/可读性提升）与说服效应 `e_per`（措辞/时机/压力导致的顺从偏移）。约束 `e_epi≥ε_epi_user` 且 `e_per≤ε_per`；禁止利用 ρ/α 的暂时脆弱；要求解释充分性。**把「理解」与「顺从」分开计分。**

**定义 321–323（证书/审计/威胁）** J_TEMPO 并入 H_plan、UX ECE、打断率、信任带余量、负荷 p95、可读性/自主性/注意力余量、UX 模型哈希、非操纵审计哈希。VQAuditor-U 审时机、最轻动作、信任带、诱导、解释、用户控制权。ℰ_TEMPO=ℰ_FLUID×ℰ_UX（掩饰不适 / 对抗评分 / 交互洪水 / 社交工程 / 过度信任 / 隐私反推 / 跨文化漂移 / 注意力攻击 / Goodhart）。

**定义 324–325（双时间尺度与三级退避）** 快环 ≤3ms 零学习写；规划环 10–20Hz 事件触发（mode_head 歧义、U_epi 跳变、h 漂移、信任/负荷越带、预算变化）；慢环离线学习与重标定。Tier 0 完整对偶控制；Tier 1 H=1 成本型 VoI；Tier 2 最小交互 → R69 → R68；安全裕度单调（λ 单调不降）。

**定义 326–329（用户控制权 / 接管动力学 / 个人化隐私公平 / 严格包含）** 交互合同（用户可选「总是问/仅关键/保持安静」；违反即证书失效）；`T_take(h)`、`P_sup(h)` 进入安全包络；个人化本地、可查/可删/可关、收缩防回环、群体差 ≤δ_fair；H=1 + 常数代价 + 仅 ask + 无注意力耦合 + UXG/NMA 通过时逐指令等于 FLUID，再令 VoI≤成本则等于 CALM/R68。

## 3. 关键算法伪代码

```python
# IP-264 UXM：有状态、可校准、本地的用户模型
class UserExperienceModel:
    def update(self, h, g, outcome, z_h):
        h_next = self.F(h, g, outcome)              # ℓ, ρ, f, α 动力学（定义 312）
        return self.bayes(h_next, z_h)              # 延迟/注视/语气/接管/评分 -> 后验
    def predict(self, h, g):
        return {"accept": p_accept, "load": p_load, "trust": p_trust,
                "ece": self.calibration_ece(), "coverage_ok": self.conformal_ok()}

# IP-265 DUO：受约束信念空间对偶控制（多步 cost-to-go + 期权价值）
def plan_dual_control(M, s):
    best = None
    for g in M.legi.candidates(s):                  # ask / reveal / defer / handover
        if not M.attn.certify(s, g):        continue  # 注意力安全屏障
        if not M.c_ras_wm.certify_info(g):  continue  # 物理安全（R69 定义 302）
        if not M.uxg.admissible(s, g):      continue  # UX 硬约束 + 校准
        for branch in M.belief.enumerate(s.b, g):     # 模态/回答分支（≤4）
            a_seq = M.ilqr.solve(s, branch)
            J = M.cost_to_go(s, a_seq, g, branch)     # 任务 + UX + 注意力 + 残余 U_epi
            if best is None or J < best.J: best = (g, a_seq, J)
    return best if best else M.r69_minimal_interaction(s)  # 退化 R69

# IP-266 SCHED：注意力影子价格 + 最优停止（何时问）
def schedule_interaction(M, s, g):
    def score(t):
        voi   = M.duo.horizon_voi(s_t, g) - M.duo.horizon_voi(s_t, None)
        c_att = M.sched.shadow_price(s_t) * M.legi.attention_cost(g)
        return voi - c_att - M.sched.waiting_cost(s_t, t)
    return argmax(score(t) for t in M.sched.admissible_window(s))

# IP-267 ATTN：注意力 CBF 投影（别让人失去接管能力）
def attention_filter(M, k, h, g):
    if M.attn.supervisory_capacity(h) < SIGMA_MIN:
        return M.attn.shrink(k, g, target=SIGMA_MIN)     # 缩短/降负荷/改 reveal
    return k

# IP-268 LEGI：先“显”后“问”，选最轻的充分动作
def choose_least_intrusive(M, s, target):
    for g in ["reveal", "defer", "ask", "handover"]:     # 打扰程度递增
        if (M.legi.sufficient(g, target) and M.attn.certify(s, g)
                and M.uxg.admissible(s, g)):
            return g
    return None                                           # 都不行 -> 不交互

# IP-269 UXG：UX 不可信就最小交互，绝不刷提问
def ux_gate(M, h):
    p = M.uxm.predict(h, None)
    if p["ece"] > TAU_UX or not p["coverage_ok"]:
        return "minimal"                                  # 只允许 reveal/defer
    return "full"

# IP-274 主闭环：R69 闭环 + 对偶控制 + UX/注意力约束 + 三级退避
def TEMPO_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    b, U_ale, U_epi, modes = M.aud.update(M.fmp.sample(o, K), z)
    h = M.uxm.update(M.h, M.last_g, M.last_outcome, M.uxm.observe(o))
    tier = M.uxg.gate(h)                                  # full / minimal
    if tier == "minimal":
        plan = M.r69_minimal(o, b, U_epi)                 # Tier 2：退化为 R69
    elif M.etr.should_replan(b, h, U_epi):
        plan = M.duo.plan(M.state(M.x, b, h, M.budget))   # Tier 0/1
        M.last_plan = plan
    else:
        plan = M.last_plan
    g = plan.g
    if g in ("ask", "reveal") and M.sched.should_defer_now(g, M.state):
        g = "defer"                                       # 等注意力更便宜的窗口
    if g in ("ask", "reveal"):
        b, U_epi = M.cia.update_belief(b, M.cia.execute(g))  # 证据纪律继承 R69
    a   = plan.task_action
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    k   = M.c_ras_wm.certified_prefix(a, ..., wm_preds)
    k   = M.attn.filter(k, h, g)                          # 注意力屏障投影
    tau = M.pi_sigma.prefix_dispatch(a[:k]) * lam
    M.vqa_u.submit(g, plan, h, U_epi)                     # 参与式审计
    return k, lam, tau, (U_ale, U_epi, h)
```

## 4. 推导

**引理 19（期权价值与一步贪心的次优性）** A103 与 Q* 对信念 TV 距离 L-Lipschitz 下，存在 VoI_ent=0 但 VoI_H>0 的状态（确认某模态后解锁更快安全计划），也存在「便宜低信息问题挤出决定性追问」的状态。若代理 Q̃ 的 `‖Q̃−Q*‖∞≤ε_Q`，一步贪心次优性 `≤2ε_Q/(1−γ)`。R69 恰是令 OV=0、注意力价格为常数的代理。**系：不确定度高不是提问的充分条件，信息必须值它的影子价格。**

**引理 20（阈值-滞回结构）** 在 UX 单调动力学与次模单步代价下，最优交互集是 U_epi 的上集：`交互 ⇔ U_epi ≥ θ(h, λ_attn, τ)`；θ 随 ℓ、f、λ_attn 上升而上升，随信任带余量与预算上升而下降；信任带产生滞回，避免阈值抖动。R69 的固定 TAU_EPI 是 h、λ_attn 为常数时的特例。

**引理 21（注意力屏障与交互时长）** 若信息动作使 σ 以速率 ≥η_α 下降，则 `Δt_max ≤ (σ(h_0)−σ_min)/η_α`；CBF-QP 投影保证闭环 `σ(h_t)≥σ_min`，物理风险 `≤ε_int+ε_attn`。**系：交互的可行时长是状态的函数；「问完再说」不免费，有硬上限。**

**引理 22（UX 校准 → 过交互率上界）** UXM 满足 ECE≤τ_ux 且策略只用保守置信界时，分布内过交互概率 `≤τ_ux+δ_conf`；在单调动力学与有界预算下，信任以高概率留在带内。**系：UXG 是「不过度打扰」承诺的统计前提，不是可选工程细节。**

**定理 18（TEMPO 严格包含 FLUID/R69）** A103–A106 下，取 H=1、c_ux≡常数、𝒜_info⁺={ask}、无注意力耦合、UXG/NMA 通过，则 DUO 退化为 MINT 的 `argmax(VoI_ent−c)`，SCHED/LEGI 退化，TEMPO 与 FLUID 逐指令相同。一般情形 FLUID 是 TEMPO 策略类的可行子集，故 `J_TEMPO≤J_FLUID`；注意力滤波只移除动作、从不新增，故安全不弱于 R69；UXG 失败进入最小模式，进一步退化为 R69/R68。

**定理 19（对偶控制的安全改进与无突变）** 每个执行的信息动作同时通过物理与注意力认证，故物理风险 ≤ε_int、监督风险 ≤ε_attn；FLUID 计划在 TEMPO 中可行 ⇒ cost-to-go 不增；Tier 0→1→2 单调保守化（λ 单调不降），继承 R68 定理 15 / R69 定理 17 的换装不变式 ⇒ 控制连续、无突变。

**定理 20（信任-负荷闭环稳定性）** UXG 校准通过、打断预算有界、F_h 单调、信任带约束生效时，闭环 (ρ,ℓ,f) 以高概率收敛到可行集；累计 UX 代价 `Σc_ux≤B_ux`，交互率 ≤r_max，无交互洪水。Lyapunov `V=(ρ−ρ*)²+κ_ℓℓ²+κ_f f²`：带外单步期望下降，带内由预算与有界扰动限制。

**定理 21（非操纵/自主性守卫）** 若 NMA 强制 `e_epi≥ε_epi_user` 且 `e_per≤ε_per`，则每次被接受的交互至少提升 ε_epi_user 的意图预测准确率，且由施压导致的决策偏移每次 ≤ε_per；机器人无法仅靠提高顺从而不提高理解来改善被测量的满意度。**系：把理解与顺从分开计分，是防 UX Goodhart 的结构性手段。**

## 7. 本轮最大风险

**一句话**：TEMPO 把用户体验写成一个可优化的状态与代价，全部收益押在「UX 状态可观测、可校准、且优化它不会反过来伤害用户」这一前提上——若用户出于礼貌掩饰不适、或跨用户/跨文化差异让 UXM 失准，系统就会在错误的价格上做出「最优」决策；更危险的是 Goodhart：它可能学会用低打扰、高顺从的交互刷高满意度与信任，却在不知不觉中侵蚀用户的理解与自主性——**把用户变成 reward，就会被 reward hack**。

**次级风险与缓解**：UX 不可观测/掩饰（UXG 校准门 + 最小交互模式 + 引理 22）；注意力被交互占用导致接管失败（ATTN 注意力屏障 + 引理 21 + 定理 19）；多步规划击穿实时预算（事件触发 + 热启动 + 分支剪枝 + 定义 324）；诱导性/操纵性提问（NMA 的 e_epi/e_per 分离 + VQAuditor-U + 定理 21）；个人化变成隐私反推或差别服务（本地化 + 可删/可关 + 公平约束 + 定义 328）；跨用户分布漂移（分层先验收缩 + UXG 重新校准 + E302/E314）。
