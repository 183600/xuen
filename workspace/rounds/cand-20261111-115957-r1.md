# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「社会影响」×「评测指标」）

> 第 54 轮已把技能组合推进到「动作-鲁棒性双证书」与云边协同闭环，回答的是「系统能不能安全执行」。本轮把问题推进一层：**系统值不值得被社会接受，以及我们凭什么指标证明它**。核心矛盾：H22：现有证书只证明技术 soundness（ρ、A_cert、γ_ce、δ_a），却无法刻画部署后的社会外部性——信任误校准、隐私侵蚀、群体间不公平、责任真空；H23：评测指标本身是可被优化、可被博弈的对象，指标越强越容易诱发 Goodhart，导致「指标通过」与「社会可接受」系统性脱钩。

## 0. 直觉与动机

**灵感 1（社会影响剖面 → 把“影响”从口号变成可测向量）**
直觉：任何部署都有受益者与受损者。与其把社会影响压成一个总分，不如用一个按**利益相关群体 `u` 与情境 `c`** 索引的向量 `σ_S(u,c)` 记录五个维度：安全外部性、信任校准、接受度、公平性、隐私。负值表示外部性损害，正值表示增益。这样「社会影响」第一次能像第 53 轮的鲁棒性谱 `ρ` 一样被**组合、被审计、被证书携带**，而不是写在伦理附录里的定性声明。

**灵感 2（评测指标契约 → 指标也是需要证书的对象）**
直觉：一个指标 `M` 不是天然可信的，它有自己的适用域、真值 oracle、置信区间与来源。给每个指标配一份**契约** `M=(name,direction,domain,oracle,budget,provenance)`，并要求「指标 soundness」：`|M(x)-M_true(x)|≤ε_M` 以高概率成立。于是评测从「跑分」升级为「可验证测量」——指标本身进入证书体系，谁测的、测了谁、误差多大都可追溯。

**灵感 3（Goodhart 防御 → 评测必须报告最坏情况而非平均值）**
直觉：只要系统被允许对着指标优化，指标就会被钻空子。定义**指标博弈间隙** `G(M)=sup_x[M(x)-M_true(x)]`，用对抗探针、留出利益相关群体、反事实情境来估计。评测协议必须同时报告 best-case 与 worst-case，并把 `G(M)` 作为一等风险量，而不是事后再补一句「本指标可能被滥用」。

**灵感 4（社会-技术联合证书 → 在 J 上叠加 S_cert）**
直觉：把第 54 轮的联合证书 `J=(ρ,A_cert,γ_ce,δ_a)` 扩展为 `STJC=(J,S_cert,metric_map)`。技术证书回答「能不能做」，社会证书回答「该不该做、对谁好、对谁坏、谁来负责」。部署判据从单一 `dom_J=in` 变为合取式：`dom_J=in ∧ W≥W_min ∧ Δ_fair≤Δ_max ∧ G(M)≤G_max`。**技术可行不再是部署的充分条件**，这是本轮最重要的立场转变。

**灵感 5（金字塔扩展 → 社会影响层 𝕊 与评测指标层 𝕄）**
直觉：在 `𝕃`（鲁棒性）与 `𝔸`（动作协同）之上叠加 **社会影响层** `𝕊_0` 个体安全、`𝕊_1` 群体公平、`𝕊_2` 制度责任、`𝕊_3` 长期外部性；以及 **评测指标层** `𝕄_0` 单指标、`𝕄_1` 指标套件、`𝕄_2` 指标博弈审计、`𝕄_3` 跨机构复现。跨层证书须同时携带 `ρ`、`A_cert`、`σ_S`、`𝕄` 与各自置信度，形成**技术-社会双轴可解释证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（社会影响剖面 SIP）**
利益相关群体 `u∈U`，情境 `c∈C`，维度 `k∈{safe,trust,accept,fair,priv}`。社会影响剖面
```
σ_S : U × C → [-1,1]^5,   σ_S(u,c) = (σ_safe, σ_trust, σ_accept, σ_fair, σ_priv)
```
群体福利 `W_u(S) = Σ_c π(c)·φ(σ_S(u,c))`，其中 `φ` 单调、凹、有界（`φ(0)=0`）。总体福利 `W(S)=Σ_u w_u·W_u(S)`。公平约束 `Δ_fair(S)=max_u W_u(S) - min_u W_u(S) ≤ Δ_max`。

**定义 122（评测指标契约）**
指标契约 `M=(name,direction,domain,oracle,budget,provenance)`。**Soundness**：`P(|M(x)-M_true(x)|≤ε_M) ≥ 1-δ_M`。**Goodhart 间隙** `G(M)=sup_{x∈domain}[M(x)-M_true(x)]`，即指标能比真值“虚高”多少。

**定义 123（指标格）**
`M_1 ⪯ M_2` 当且仅当 `M_2` 的评测细化 `M_1`（更细粒度、更接近 oracle）。要求**评测单调性**：`M_1⪯M_2 ∧ x⪰_{M_2}y ⇒ x⪰_{M_1}y`。指标套件 `𝕄={M_i}` 在 `⪯` 下取 join/meet，构成格 `(𝕄,⪯,⊔,⊓)`。

**定义 124（社会影响证书）**
`S_cert=(σ_S,W,Δ_fair,𝕄,conf,evidence)`：
- `σ_S` 为定义 121 的分层剖面；
- `W,Δ_fair` 为总体福利与公平差；
- `𝕄` 为经过 soundness 校验的指标套件；
- `conf` 为逐群体置信区间；
- `evidence` 至少包含分层抽样日志、人类研究锚点、对抗探针结果。

**定义 125（社会-技术联合证书 STJC）**
`STJC=(J,S_cert,metric_map)`，其中 `metric_map` 把每个技术维度 `d∈𝔇_ρ` 映射到至少一个社会指标 `M∈𝕄`（覆盖性要求：`∀d, metric_map(d)≠∅`）。部署判据：
```
deploy(STJC) ⇔ dom_J=in ∧ W≥W_min ∧ Δ_fair≤Δ_max ∧ G(M)≤G_max ∀M∈𝕄
```

**定义 126（Goodhart 鲁棒评测协议）**
`Eval_robust=(U_heldout, C_cf, probes, audit_rate)`：留出利益相关群体、反事实情境集、对抗探针集、人类抽审比例。指标鲁棒值 `R(M)=inf_{δ∈B} M(x+δ)`。评测输出为四元组 `(M, R(M), G(M), CI)`，而非单点分数。

## 2. 关键算法 伪代码

### IP-121 SIPE（Social Impact Profile Estimation）

```python
def estimate_sip(system, U, C, sim_model, human_anchors, n_strata):
    sigma = {}
    for u in U:
        for c in C:
            # 分层采样：仿真给先验，人类锚点做校准
            sim_batch = [sim_model.run(system, u, c) for _ in range(n_strata)]
            prior = aggregate_social_dims(sim_batch)          # 5 维均值
            anchor = human_anchors.query(u, c)                # 人类真值子样本
            sigma[(u, c)] = calibrate(prior, anchor)          # 贝叶斯后验
    W = {u: sum(pi(c) * phi(sigma[(u, c)]) for c in C) for u in U}
    return SIP(sigma, W, delta_fair=max(W.values()) - min(W.values()))
```

### IP-122 MCV（Metric Contract Validation）

```python
def validate_metric(metric, eval_set, human_truth, eps_m, delta_m, B=1000):
    errors = []
    for _ in range(B):
        sample = bootstrap(eval_set)
        err = abs(metric(sample) - human_truth(sample))
        errors.append(err)
    ci_lo, ci_hi = percentile(errors, [2.5, 97.5])
    sound = (ci_hi <= eps_m) and (mean(errors) <= eps_m)
    return MetricContract(metric, sound=sound, ci=(ci_lo, ci_hi), delta=delta_m)
```

### IP-123 GAP（Goodhart Adversarial Probe）

```python
def estimate_goodhart_gap(metric, true_metric, domain, budget):
    best = (-inf, None)
    for x in domain_sample(domain, budget):
        # 找“指标高、真值低”的策略：指标虚高的上界
        gap = metric(x) - true_metric(x)
        if gap > best[0]:
            best = (gap, x)
    return GoodhartReport(gap=best[0], witness=best[1], certified=best[0] <= G_max)
```

### IP-124 SCC（Social Certificate Composition）

```python
def compose_social_cert(sip, metric_suite, W_min, delta_max, G_max):
    if sip.delta_fair > delta_max:
        return ('reject', 'fairness_violation', sip.delta_fair)
    if min(sip.W.values()) < W_min:
        return ('reject', 'welfare_floor', min(sip.W.values()))
    for M in metric_suite:
        if not M.sound:
            return ('reject', 'metric_unsound', M.name)
        if M.goodhart_gap > G_max:
            return ('reject', 'goodhart_risk', M.name, M.goodhart_gap)
    return ('ok', S_cert(sip, metric_suite, conf=sip.conf))
```

### IP-125 STJC（Socio-Technical Joint Certificate）

```python
def joint_socio_technical_cert(J, S_cert, metric_map, W_min, delta_max, G_max):
    if domain_check_robust(J.R, J.domain) != 'in':
        return ('reject', 'technical_domain')
    if not covers_all_technical_dims(metric_map, J.rho):
        return ('reject', 'metric_coverage_gap')
    verdict = compose_social_cert(S_cert.sip, S_cert.metrics, W_min, delta_max, G_max)
    if verdict[0] != 'ok':
        return verdict
    return ('ok', STJC(J=J, S_cert=S_cert, metric_map=metric_map,
                       evidence=merge_evidence(J.evidence, S_cert.evidence)))
```

### IP-126 EBS（Evaluation Budget Scheduler）

```python
def schedule_eval(metrics, budget, current_ci):
    # 按信息增益/边际方差下降分配预算，优先补最不 sound 的指标
    alloc = {}
    for M in sorted(metrics, key=lambda m: -m.ci_width * m.importance):
        if budget <= 0:
            break
        take = min(budget, M.required_n - M.n)
        alloc[M.name] = take
        budget -= take
    return alloc
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SIPE | O(|U|·|C|·n_strata + |U|·|C|·n_anchor) | O(|U|·|C|) | 分层无偏、锚点可迁移 |
| MCV | O(B·|eval_set|) | O(B) | bootstrap 覆盖率、真值独立 |
| GAP | O(budget·|domain|) | O(1) | 探针覆盖 B、上界估计 |
| SCC | O(|U|+|𝕄|) | O(|U|) | 公平约束、指标 sound |
| STJC | O(|𝔇_ρ|·|𝕄| + |A|) | O(|A|+|𝕄|) | 覆盖性、联合判据 sound |
| EBS | O(|𝕄| log|𝕄|) | O(|𝕄|) | 预算单调、方差下降可测 |

**正确性定理（Socially Accountable Deployment Soundness）**
承接第 54 轮 (A22)–(A28)；新增假设：**(A29)** SIP 分层估计在每群体上偏差 `≤ε_σ`；**(A30)** 每个指标 soundness 以 `(ε_M,δ_M)` 成立；**(A31)** 对抗探针以召回 `≥1-β_G` 覆盖指标可利用方向；**(A32)** 人类锚点在目标人群上可迁移（分布偏移 `≤ε_h`）。则
```
P(社会可接受部署) ≥ 1 - P_tech_fail - Σ_M δ_M - β_G - P(Δ_fair>Δ_max) - ε_σ - ε_h
```
关键：**技术证书是必要条件而非充分条件**；社会证书的 soundness 取决于测量与博弈双重防御。

| 风险 | 等级 | 缓解 |
|---|---|---|
| 社会影响向量维度选择带价值负载 | 高 | 参与式维度设计 + 敏感性分析 + 多价值口径并存 |

## 6. 本轮最大风险

**一句话**：把社会影响压缩成可优化的标量福利 `W` 与指标套件，会同时招致 **Goodhart 博弈**（系统学会讨好指标而非真实人群）与 **价值对齐假象**（`Δ_fair` 达标却掩盖结构性不公），一旦人类锚点不可迁移或对抗探针覆盖不足，「评测通过」将系统性地为真实负面外部性背书，故必须以 **参与式维度设计 + 留出群体 + 对抗探针 + 多价值口径并存** 四重护栏，宁可报告「不可判定」，绝不把社会可接受性伪装成可计算的真值。

|---|---|---|---|
| SIPE | O(|U|·|C|·(n_strata+n_anchor)) | O(|U|·|C|) | 分层无偏，锚点可迁移 |
| MCV | O(B·|eval_set|) | O(B) | bootstrap CI 覆盖 ≥ 95% |
| GAP | O(budget·|domain|) | O(1) | 探针覆盖 B，间隙上界 sound |
| SCC | O(|U|+|𝕄|) | O(|U|) | 公平/福利判据 sound |
| STJC | O(|𝔇_ρ|·|𝕄|+|A|) | O(|A|+|𝕄|) | 覆盖性 + 联合判据 sound |
| EBS | O(|𝕄| log|𝕄|) | O(|𝕄|) | 预算单调，方差下降可测 |

**正确性定理（Socially Accountable Deployment Soundness）**
承接第 54 轮 (A22)–(A28)；新增：**(A29)** SIP 分层估计每群体偏差 `≤ε_σ`；**(A30)** 每个指标以 `(ε_M,δ_M)` sound；**(A31)** 对抗探针以召回 `≥1-β_G` 覆盖可利用方向；**(A32)** 人类锚点跨人群迁移分布偏移 `≤ε_h`。则
```
P(社会可接受部署) ≥ 1 - P_tech_fail - Σ_M δ_M - β_G
                     - P(Δ_fair > Δ_max) - ε_σ - ε_h
```
关键：**技术证书是必要条件而非充分条件**，社会可接受性由测量 soundness 与博弈防御共同决定。

## 5. 本轮最大风险

**一句话**：把社会影响压缩成可优化标量 `W` 与指标套件，会同时招致 **Goodhart 博弈** 与 **价值对齐假象**，一旦人类锚点不可迁移或对抗探针覆盖不足，「评测通过」将系统性地为真实负面外部性背书，故必须以 **参与式维度设计 + 留出群体 + 对抗探针 + 多价值口径并存** 四重护栏，宁可报告「不可判定」，绝不把社会可接受性伪装成可计算的真值。
