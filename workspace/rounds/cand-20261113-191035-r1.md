# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「语义建图」×「数据质量」）

> 第 68 轮把「测量本身的可信度」提升为一等公民：COF 在线估计标定潜变量 c_t，CFA 先标定后归因，CAC 用五关认证把影子学习挡在实时环之外。它补上了 R65 感知链路、R66 观测链路、R67 预测链路共同的计量层。
>
> 但 R68 的自陈风险暴露了一个更深的元问题：**CALM-RAS 的所有一致性检验都是「相对参考」**——跨模态互相比对、WM 与 ERG 互相比对、残差与速率限制器比对。相对参考只能回答「谁和谁不一致」，无法回答「所有人是不是一起错了」。当温漂、结构蠕变、共同时钟偏移以**共模**方式作用于全部模态（B_m d_t 同向），或缓变故障恰好落在 COF 带宽内被当作漂移「标好」，r_cross 会归零，系统反而更自信。
>
> 本轮两个灵感正好补上「绝对参考」与「参考自身的可信度」：
> - **语义建图**提供跨会话、对象级、带语义关系的长期世界记忆，把「当前传感器彼此一致」升级为「与一个外生、可追溯的长期锚点一致」；
> - **数据质量**把「哪些数据有资格成为锚点 / 标定证据 / 认证金标」从隐含假设升级为可审计账本：来源、覆盖、新鲜度、一致性、标签可信、抗投毒风险，逐条打分、逐条留痕。
>
> 核心命题：**用语义地图做绝对锚，用数据质量账本做锚的锚——SQ-MAP-RAS（Semantic-Quality Map-Anchored RAS）**。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我用来判断准不准的那把尺子，本身可信吗**」。

## 0. 直觉与动机

### 灵感 1（语义建图 → 相对一致性有盲区，地图是外生绝对参考）

直觉：R68 的 r_geo、r_emo、r_wm 本质是一次「表决」——三个传感器/模型投票，少数服从多数。可如果漂移是共模的（温度让整个结构一起热膨胀、外参一起偏、所有模态被同一套骨架几何误差污染），投票结果会**一致地错**。错误越一致，相对残差越小，系统越自信：这是「共识的暴政」。

语义地图不同。它是跨会话累积的、对象级的、带语义关系的世界记忆：三个月前见过的工位、门把手、货架层高、杯子与桌面的关系。给定当前位姿，地图能预测「这个传感器此刻应该看到什么」。这个预测的参考系不是当前任何一帧，而是长期记忆，因此对**当前共模漂移敏感**。更关键的是语义层：几何可以随温漂整体缩放/平移而保持自洽，但「杯子在桌上、把手在门的一侧、货架层高固定」这类语义-拓扑关系是离散的、长期稳定的，构成比点云配准更鲁棒的锚。语义建图在这里不是「给地图贴标签」，而是**把长期记忆变成一台外生计量基准**。

### 灵感 2（数据质量 → 标定吸收的本质是「坏数据被当成了金标」）

直觉：R68 说「先标定后归因」，但标定吸收故障的真正机制不是数学，而是**数据治理失败**：COF 把一段带故障特征的数据当成「漂移观测」喂进了 EKF，CAC 的金标集又恰好没覆盖这种模式。数据质量不是「清洗一下」，而是回答三个问题：这条数据从哪来（provenance）、它覆盖了漂移的哪个方向（coverage）、它有没有被当前待检传感器污染（independence）。若一条数据回答不了这三问，它就不该有资格更新标定，更不该有资格进认证金标。

把质量做成账本，等于给「吸收」这件事上了审计轨迹：每一次 ĉ 更新都能回答「你凭什么这么改、用了哪条数据、那条数据谁背书」。数据质量从工程卫生升级为**可计算的认识论**。

### 灵感 3（两者合流 → 信任必须接地：锚点层级与来源 DAG）

直觉：地图锚定标定，那地图谁来锚定？如果地图也是同一批传感器建的，共模漂移会被写进地图，地图反过来「证明」漂移是对的——这是**认识论闭环（epistemic closure）**。所以要显式维护一张来源 DAG：叶节点是原始观测，边是加工/融合关系，根节点是系统外部的东西——出厂计量溯源、人工抽检、独立模态（外部激光跟踪仪/触觉基准）、跨机器人共识、冻结的物理基准（fiducial/canary）。

任何被采信的锚点，必须能沿 DAG 走到一个与待检传感器「来源独立」的根；走不到，系统就必须承认「我现在没有绝对参考」，而不是假装有。数据质量账本记录每条边的质量，使「接地」不是一个哲学口号，而是一个可计算、可审计、可降级的图条件。这给了系统一个比 U(ĉ) 更底层的不可信信号：不是「标定不确定」，而是「连判断标定是否可信的参考都没有」。

### 灵感 4（对 R68 风险的对症下药）

- R68 的「缓变故障被标定吸收」：r_cross 会被标定压平，但 r_map（对语义地图锚点的残差）不会，因为地图锚点跨越了故障演化窗口。CMF 用四象限 (r_cross, r_map) 把「正常 / 单模态瞬态故障 / 共模慢故障 / 参考失配」分开。
- R68 的「标定越强，故障越隐形」：CAT 在 COF 的速率限制边界上做单边 CUSUM——只要 r_map 持续增长而 r_cross 被压平、且标定增量长期贴住速率上限，就判「吸收」而非「漂移」。
- 地图被污染：AAA + ECD 检测来源闭环，数据质量账本把污染尝试留痕，CAC 增加锚点独立性与数据质量关。
- 两轮共同的「过度放宽」通道：新增统一纪律 **λ_floor(q, ρ_A) = max(0.6, 0.8·1[U > τ_cal ∨ q < τ_q ∨ ρ_A < ρ_min])**，并在 ECD=1 时直接 λ=1、k=0——任何参考层的不确定性都只导向收紧。

### 灵感 5（架构总览）

SQ-MAP-RAS 在 R68 的 CALM-RAS 上叠加「锚定层」与「数据治理层」，继承 MTM/COF/CFA/CAC 全部保留：

1. **SMG Semantic Map Graph**：跨会话对象级语义-几何双层地图，提供外生绝对参考；
2. **DQL Data Quality Ledger**：只追加哈希链账本，给每条数据/锚点质量向量与来源证明；
3. **AAA Anchor Admissibility Arbiter**：按质量、独立性、新鲜度、覆盖秩筛选可采信锚点集 A_t；
4. **MAR Map-Anchored Residual**：地图锚定残差 r_map，补足 r_cross 的共模盲区；
5. **CMF + CAT**：四象限共模归因 + 标定吸收陷阱 CUSUM 检测器；
6. **QCOF + AAP + MUP**：质量门控标定、VoI 主动锚定、冻结金标锚约束下的影子地图更新；
7. **ECD + SQ-CAC + RAS-WM†**：认识论闭环检测、七关认证提交、继承核全部保留。

**定义 301（四象限共模归因 CMF）** 依 (‖r_cross‖, ‖r_map‖) 划分：

# IP-255 AAA：锚点可采信仲裁（独立性 + 质量 + 覆盖秩）

def SQ_MAP_round(M, obs):

    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)      # 1) 同源一次前向
    r_cross = residuals_cross(x_prime, o, M.wm_residual_cache) # 2) 相对参考

    A, rho_A = M.aaa.admissible(M.t, sensor='multi')           # 3) 锚点仲裁
    if rho_A < RHO_MIN:                                        #    认识论闭环
        M.ecd.raise_flag()
        return conservative_round(M, x_prime, z, o)            #    λ=1, k=0

    q = M.dql.score(obs)                                       # 4) 数据质量
    r_map, r_par = M.mam.residuals(obs, M.pose, A)             # 5) 绝对参考
    c, U, thr = M.qcof.step(o['cal'], r_par, q, sigma_stat(M)) # 6) 质量门控标定

    absorbed = M.cat.update(r_par) and norm(r_cross) < TAU_CROSS
    if absorbed:                                               # 7) 吸收 → 冻结标定
        c = M.qcof.freeze(); cause = 'absorption'
    else:
        cause = M.cmf.quadrant(r_cross, r_map, rho_A, q)

    joint_post = M.cfa(r_cross, r_map, o['pi'], c, U)          # 8) 双参考归因
    if cause in ('common_mode', 'absorption'):
        joint_post = bump_fault_posterior(joint_post)

    A_act = M.ach.propose(x_prime, H=M.vista.H)
    m_ras = min(M.vista.m, M.m_emo)
    k = M.c_ras_wm.certified_prefix(A_act, joint_post, m_ras, M.alpha_chunk, M.wm_preds)
    if U > TAU_CAL or rho_A < RHO_MIN: k = min(k, k_cal_shrink(A_act, U))

    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'],
              0.8 if (o['qual']['face'] < 0.8 or cause != 'nominal') else 0.6)
    tau = emotion_response_shaping_wm(
        M.pi_sigma.prefix_dispatch(A_act[:k]) * lam, joint_post, M.wm_preds)

    if M.need_anchor(rho_A, U):                                # 9) 主动锚定
        M.schedule(choose_anchor_action(M, rho_A, U))
    M.dql.append(obs, q)                                       # 10) 留痕（影子）
    M.mup.shadow_update(obs, q)
    M.vqa_m.submit_async(r_map, {'cause': cause, 'rho_A': rho_A, 'q': q})
    M.sq_cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint_post, (c, U, rho_A)

## 3. 推导

**引理 16（相对参考的共模盲区）** 在定义 295 下，跨模态残差对 (m,n) 可写为 r_cross^{mn} = (H_m − T_{mn}H_n)x + (B_m − T_{mn}B_n)d + ε。若 B_m = T_{mn}B_n（完全共模），则 ∂r_cross/∂d ≡ 0，Fisher 信息 J_cross(d) = 0：任何仅依赖 r_cross 的检测器都无法区分不同的 d。反之，若存在与 m 来源独立的锚点 a（B_a = 0），则 r_map = B_m d + ε，J_map = B_m^T R^{-1} B_m ≻ 0 当且仅当 rank(B_m) = d_d。**系**：R68 的共模盲区不是实现缺陷，而是相对参考的统计不可辨识性。

**引理 17（吸收窗口与检测延迟）** 设真实故障/漂移以斜率 β 增长。在 COF 速率限制 Δ_max 与红线 c_max 下，只要故障谱落在 ω_cal 内，r_cross 可被标定压到 τ_cross 以下，直到 ĉ 触红线的时刻 T_red ≥ c_max/β。若 T_red 超过任务时域，R68 永不报警。地图锚点未被同步污染时，r_map^∥ 以 σ_min(B_A)·β 增长，CUSUM 检测延迟近似
T_cat ≈ (h_cat + k_cat) / (σ_min(B_A)·β − k_cat)，需 σ_min(B_A)·β > k_cat。
**系**：绝对参考把「不可见」变成「可检测」，代价是引入地图污染这一新攻击面。

**引理 18（锚点污染的可辨识性衰减）** 设锚点集中独立成分占比为 ρ_A，被污染部分与 m 共享同一漂移（endogenous）。则有效锚定残差 r_map ≈ ρ_A·B_m d + ε，Fisher 信息 J = ρ_A²·B_m^T R^{-1} B_m，检测 SNR ∝ ρ_A。若地图更新持续吸收当前漂移（「洗白」），ρ_A 随时间单调下降；ρ_A → 0 时共模漂移重新不可辨识。**系**：地图不是免费的绝对参考；必须用冻结金标锚与来源独立性监控把 ρ_A 钉在 ρ_min 以上。

**定理 16（相对-绝对参考的辨识二分）** 在定义 295–299 与假设 A95–A99 下：
1. 若 A_t 非空、indep(A_t, m) 成立、rank(B_A) = d_d，则共模漂移 d 可由 (r_cross, r_map) 辨识，且估计误差 ‖d̂ − d‖ ≤ ‖B_A^+‖·(‖ε‖ + δ_map)；
2. 若不存在与 m 独立的锚点（ρ_A = 0），则存在两个不同 d ≠ d' 产生完全相同的观测分布，任何算法都无法以优于随机的概率区分；
3. 因而不存在「纯内生」的共模故障检测器；安全系统必须维护至少一个外生根，否则只能保守降级。这是 R68 范式的**不可能性边界**，也是本轮引入语义地图与来源 DAG 的根本理由。

**定理 17（SQ-MAP 端到端风险一致性）** 在 A87–A99 下，输出 τ_cmd 满足：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_map + α_dq + α_closure**；其中 α_map 由引理 16–18 的辨识条件约束，α_dq 由质量门控与账本完整性约束，α_closure 在 ECD=1 时被「λ=1、k=0」完全吸收；
2. **安全单调性**：q 下降、ρ_A 下降、U 上升、ECD 置位，四者任一发生 ⇒ λ_risk 不减、k 不增、τ_risk 不松——任何参考层不确定性都只导向收紧；
3. 若 ρ_A ≥ ρ_min 且 q ≥ τ_q，则共模慢故障的检测概率随观测时域单调上升（引理 17），且不劣于 R68 的快变故障检出（引理 13 的反吸收界仍成立）。

## 6. 本轮最大风险

**一句话**：SQ-MAP-RAS 把「绝对参考」交给了语义地图，但地图本身仍由同一批传感器在长期运行中维护——**若缓变故障被持续写进地图（地图洗白），或数据质量账本的来源/质量分被伪造、外生根长期未复检，那么系统会得到一个「经认证的假真值」：r_map 被地图吸收而趋零，ρ_A 的账面值虚高，ECD 不触发，最终比 R68 更危险——因为它不仅失去了检出能力，还以证书的形式宣称自己「有绝对参考」**；这是把认识论闭环从「未被识别」升级成「被认证」的原罪。

**次级风险与缓解**：
1. **语义地图漂移** → 冻结金标锚 + 语义关系不变量 + E289/E295 长期审计；
2. **账本伪造/合谋** → Merkle 哈希链 + 多根冗余 + 人工抽检 + 来源 DAG 交叉验证；
3. **主动锚定成本与任务冲突** → VoI 门控 + 任务风险约束 + 摊销预算；
4. **语义标签腐化** → r_sem + 标签来源质量 + 冻结锚对照 + 标签更新需 SQ-CAC；
5. **实时开销** → r_sem 降频（200ms）、AAA 分块、地图查询空间索引、账本全在影子流；
6. **无外生根场景** → ECD 显式降级（λ=1、k=0），宁可停机也不假装有真值。

## 2. 形式化定义（要点版）

**定义 293（总览与四不变式）** 在 R68 三不变式上追加：锚点独立性（外生真值必须来源独立）、数据质量防火墙（q<τ_q 不得更新标定/金标/地图）、认知闭环禁止（ρ_A<ρ_min 必须显式降级，不得以相对一致冒充绝对正确）、实时流零学习写操作保持（锚查询只读，更新全在影子流）。

**定义 294（SMG）** 对象级双层地图：几何因子图 Φ + 语义关系图 Ω；节点含位姿/标签/质量/来源；给定位姿与锚点集预测观测 ŷ_ref；语义残差 r_sem 用图编辑距离与谓词不匹配度。

**定义 295（共模观测模型）** y_m = H_m x + B_m d + ε_m；跨模态残差只依赖 (B_m−B_n)d 的差，完全共模时 ∂r_cross/∂d = 0——相对参考的统计盲区。

**定义 296（来源 DAG 与独立性）** indep(a,m)=1 当且仅当 a 的来源 DAG 不存在经传感器 m 到 endogenous 根的污染路径；独立覆盖度 ρ_A 由定义 299 给出。

**定义 297（质量向量与代数）** q∈[0,1]^6；w(q) 为几何平均；q_agg 用 t-范数聚合，任一分量为 0 即否决（短板否决）。

**定义 298（DQL）** 只追加哈希链 e_i=(data_id, source_dag_hash, q_i, t_i, h_{i−1}, h_i)；任何更新必须引用消费数据 id，可重放「更新→数据→来源→质量」全链；支持 Merkle 证明。

**定义 299（AAA）** A_t 满足质量/独立/新鲜/覆盖门限；B_A 堆叠要求 rank=d_d 且 σ_min≥σ_min^0；输出 ρ_A=σ_min/σ_max。

**定义 300（MAR）** r_map = y − ŷ_ref(x; A_t)；r_map^∥=P_A r_map 用于共模/标定，r_map^⊥ 用于几何-语义异常；r_cross 与 r_map 构成双参考。

**定义 301（CMF 四象限）** Q0 双小正常；Q1 r_cross 大/r_map 小为单模态或瞬态；Q2 r_cross 小/r_map 大为共模慢故障或被吸收故障（R68 盲区）；Q3 双大为最坏。后验条件于 q 与 ρ_A。

**定义 302（CAT）** Ψ_t=max(0, Ψ_{t−1}+‖r_map^∥‖−k_cat)；Ψ>h_cat 且 r_cross<τ_cross 且标定增量贴住 Δ_max ⇒ absorption，截断 H_cal、抬升 H_sensor^trans、冻结标定。

**定义 303（QCOF）** R_cal(q)=R_0/max(q_agg,ε)；静态段且 q≥τ_q 才用 R_static；低质量协方差膨胀而非丢弃；保持速率限制；CAT 后冻结 τ_hold。

**定义 304（AAP）** a*=argmax [E[IG(c,H;y(a))]−λ_cost·cost(a)]，约束任务风险；候选为回访路标/看 fiducial/切独立模态/人工抽检/跨机对齐。

**定义 305（MUP）** 影子流鲁棒因子图更新，只吃 q≥τ_map 且独立观测；冻结金标锚只读；残差单调增长而其余自洽 ⇒ 污染告警。

**定义 306（ECD）** 可达独立根覆盖秩 < d_d 或根质量不足 ⇒ ECD=1 ⇒ λ=1、k=0、最保守操作、请求外部计量。

**定义 307（质量加权 SSL）** L_ssl^q=Σ w(q_i)L_ssl,i；伪标签额外乘 1[χ≥τ_χ]·1[α≤τ_α]；低质量只做增广/对比。

**定义 308（SQ-CAC 七关）** 原五关 + 锚点独立性关（ρ_A≥ρ_min）+ 数据质量关（q 的 P10≥τ_q^CAC，Merkle 通过）；新增 frozen-anchor 不可漂移性（残差不得被「修小」超 δ_anchor）。

**定义 309（AIC-SQMAP / J_SQMAP）** ℰ_SQMAP=ℰ_CALM×ℰ_map×ℰ_dq×ℰ_anchor×ℰ_closure；J_SQMAP Valid ⇔ J_CALM Valid ∧ ρ_A≥ρ_min ∧ q_agg≥τ_q^hard ∧ ecd_flag=0 ∧ 红线未越界。

**定义 310（管线）** 离线多会话语义建图 → 来源 DAG 与外部根 → 冻结金标锚 → 账本初始化；在线每帧双参考 + 每 T_anchor 锚点评级 + 60s 影子七关提交 + VQAuditor-M 审计地图洗白。

## 4. 推导

**引理 16（相对参考的共模盲区）** r_cross^{mn}=(H_m−T_{mn}H_n)x+(B_m−T_{mn}B_n)d+ε；若 B_m=T_{mn}B_n，则 ∂r_cross/∂d≡0，J_cross(d)=0——仅依赖 r_cross 无法辨识共模漂移。独立锚点（B_a=0）给出 r_map=B_m d+ε，J_map=B_m^T R^{-1}B_m≻0 ⇔ rank(B_m)=d_d。R68 的盲区是统计不可辨识，不是实现缺陷。

**引理 17（吸收窗口与检测延迟）** 故障斜率 β、速率上限 Δ_max、红线 c_max 下，谱落在 ω_cal 内的故障可被标定压住直到 T_red≥c_max/β；若 T_red 超任务时域则 R68 永不报警。地图锚定残差以 σ_min(B_A)·β 增长，CAT 延迟 T_cat≈(h_cat+k_cat)/(σ_min(B_A)·β−k_cat)，需 σ_min(B_A)·β>k_cat。绝对参考把「不可见」变「可检测」，代价是新增地图污染攻击面。

**引理 18（锚点污染的可辨识性衰减）** 独立成分占比 ρ_A 时，r_map≈ρ_A B_m d+ε，J=ρ_A² B_m^T R^{-1}B_m，SNR∝ρ_A；地图洗白使 ρ_A 单调下降，ρ_A→0 时共模漂移重新不可辨识。地图不是免费真值，必须用冻结金标锚与独立性监控把 ρ_A 钉在 ρ_min 以上。

**定理 16（相对-绝对参考的辨识二分）** (1) A_t 非空、indep 成立、rank(B_A)=d_d ⇒ d 可辨识，误差 ≤ ‖B_A^+‖(‖ε‖+δ_map)；(2) 无独立锚点（ρ_A=0）⇒ 存在 d≠d' 产生同分布观测，任何算法无法优于随机；(3) 因而**不存在纯内生的共模故障检测器**，安全系统必须维护至少一个外生根，否则只能保守降级。这是 R68 范式的不可能性边界。

**定理 17（SQ-MAP 端到端风险一致性）** A87–A99 下：
1. P(|τ_cmd−τ*|>ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_map + α_dq + α_closure**；
2. **安全单调性**：q↓、ρ_A↓、U↑、ECD=1 任一发生 ⇒ λ_risk 不减、k 不增、τ_risk 不松——只收紧不放宽；
3. 若 ρ_A≥ρ_min 且 q≥τ_q，共模慢故障检测概率随观测时域单调上升，且不劣于 R68 的快变故障检出（引理 13 反吸收界仍成立）。

## 7. 本轮最大风险

**一句话**：SQ-MAP-RAS 把「绝对参考」交给了语义地图，但地图仍由同一批传感器长期维护——**若缓变故障被持续写进地图（地图洗白）、来源/质量分被伪造、外生根长期未复检，系统会得到一个「经认证的假真值」：r_map 被地图吸收而趋零、ρ_A 账面虚高、ECD 不触发，最终比 R68 更危险，因为它不仅失去检出能力，还以证书宣称自己「有绝对参考」**——这是把认识论闭环从「未被识别」升级为「被认证」的原罪。

**次级风险与缓解**：地图漂移（冻结金标锚 + 语义不变量 + E289/E295）；账本伪造（Merkle + 多根冗余 + 人工抽检 + 来源交叉验证）；主动锚定成本（VoI 门控 + 任务风险约束 + 摊销预算）；语义标签腐化（r_sem + 标签来源质量 + 冻结锚对照 + 标签更新需 SQ-CAC）；实时开销（r_sem 降频 200ms、AAA 分块、空间索引、账本全影子流）；无外生根场景（ECD 显式降级 λ=1、k=0，宁可停机不假装有真值）。
