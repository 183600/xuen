## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1（基线复现 → 在低成功率赛区，基线是唯一能区分「进步」与「噪声」的仪器）

**直觉**：榜单未发布、官方本地评测只比动作 MAE、社区下载量仅 252——大多数队伍会在没有分母的情况下调参。基线复现的第一性价值不是「跑通官方代码」，而是建立一个**可重复的失败剖面**：同一 checkpoint、同一数据、同一评测协议下，32 个任务各自在哪里失败、失败在哪个泛化轴、失败属于感知/规划/执行/恢复中的哪一类。这个剖面就是创新路线图。**反直觉点：先让基线以可测量的方式失败，比先让模型涨两个点更有价值；一个不能复现的基线，只是一个传闻。**

**严谨定义**：
- **复现（reproduction）**：在**相同工件**（checkpoint、代码 commit、数据版本、配置、环境锁、随机种子）下，重复运行得到**在容差内相同**的动作与成功率。**复制（replication）**：用独立实现得到**相同结论**。本轮要的是前者：先把「同一件事」做对，再谈「换一件事」。
- **R-契约（Reproduction Contract）**：五元组 \(R=(A,E,M,T,D)\)——工件清单 \(A\)、环境 \(E\)、指标集 \(M\)、容差 \(T\)、**在看到结果前写死**的决策规则 \(D\)。没有 \(D\) 的复现只是「跑了一下」。
- **基线阶梯**：\(B_0\) 官方 Base 零样本 → \(B_1\) 官方微调配方在 32 任务上重训 → \(B_2\) \(B_1\) 接赛题 PolicyService 的部署复现 → \(B_3\) 单任务通道上的闭环成功率复现。只有 \(B_3\) 才是「能被打败的基线」；\(B_0\)–\(B_2\) 是诊断台阶。
- **噪声地板与最小可检测效应（MDE）**：由重复实验估计评测方差；任何创新点的增益必须显著超过 MDE，才允许进入真机预算。**离线动作 MAE 与闭环成功率之间的「离线-在线差」本身就是最重要的诊断量**：差大说明瓶颈在复合误差/执行，差小说明瓶颈在表征/感知。

### 灵感 2（共享控制 → 人类干扰不是噪声，而是控制回路里的第二个控制器）

**直觉**：人类干扰是 5 类泛化轴之一，每任务 2/10 次，合计 64/320 次。没有力/触觉，经典阻抗式共享控制不可用；但共享控制的本质不是力，而是**权威**：当人类进入回路时，谁的动作被执行、谁承担后果。最危险的失败不是「不会做」，而是「和人抢」或「被人吓停」。**反直觉点：不要检测人，检测「世界是否按你的命令变化」。背景里走过一个人不应改变权威；人伸手抓住物体或机械臂才应改变权威。存在感是错误抽象，意外才是正确抽象。**

**严谨定义**：
- **共享控制五元组** \(S=(A,H,X,U,\sigma)\)：自主策略 \(A\)、人类 \(H\)、观测 \(X\)、动作 \(U\)、权威分配函数 \(\sigma:(x_{t-k:t},u_{t-k:t})\to\alpha_t\in[0,1]\)。执行动作 \(u_t^{exec}=\alpha_t u_t^{A}+(1-\alpha_t)u_t^{H}\)。评测时没有人类动作指令 \(u_t^{H}\)，只有**物理干扰**；因此本赛的共享控制退化为**隐式物理共享控制**：人类的权威 \(1-\alpha_t\) 只能从「意外」中推断。
- **意外（surprise）**：本体残差 \(r^q_t=\|q_{t+1}-\hat f(q_t,u_t)\|_\Sigma\) 与视觉潜变量残差 \(r^v_t=\|z_{t+1}-\hat g(z_t,u_t)\|\)。\(r^q\) 高 = 有人/物接触机器人；\(r^v\) 高 = 场景被外部改变（人移动物体）。**存在感不进入权威；只有意外进入权威。**
- **权威律**：\(\alpha_t=\mathrm{clip}\big(1-\sigma(\beta(\max(r^q_t,r^v_t)-\tau)),0,1\big)\)，配滞回状态机 PROCEED→SUSPECT→YIELD/REOBSERVE→RESUME。**让权（yield）在位置接口下的正确实现是「跟随当前位姿/零相对位移」，不是力矩柔顺**；这是运动学让权，能减少对抗，但不能声称动力学柔顺。
- **单模型边界**：权威头必须是同一模型内的一个输出头（或确定性规则），不能是第二个任务策略；伺服/几何回退只能当老师（辅助监督），不能当并联队友。若组委会把任何辅助模块都算「第二个模型」，退回到纯确定性意外规则（不引入第二个学习模型）。

### 灵感 3（两者的闭环：baseline-in-the-loop）

**直觉**：基线复现回答「分丢在哪」，共享控制回答「人这一轴怎么拿分」，共享自治数据采集回答「失败示教从哪来」。三者构成一个闭环：**复现基线 → 归因人类失败模式 → 用共享自治采集纠正数据 → 重训 → 再复现**。这个闭环的产出不是某个模块，而是一条可重复的研发流水线。**本轮结论：这场比赛的中后期胜负手是「测量 + 权威」，不是再堆一个架构。**

## 2. 对第 2 轮痛点的增量修订

- **P1（弱任务支配平均分）**：基线复现把「弱任务」从直觉变成逐任务成功率/步骤分的**实测赤字**；I10 的失败剖面直接给出优先修补顺序。
- **P2（泛化缺口）**：五轴中第五轴是**人为干扰**，占 20% 计分权重；第 2 轮 I1 的「五轴」实际只覆盖前四轴（位置/干扰物/背景/未见物品），第五轴必须由 I11 在控制层解决。**这是本轮对 I1 的一处事实修正。**
- **P5（时间压力）**：R-契约会花时间，但它通过「杀死噪声级增益」节省真机预算；关键是给 I10 设**时间盒**（例如 10 个工作日）与止损线。
- **P7（先手窗口）**：平局规则是「早提交者优先」；一个可复现、接口合规、成功率在噪声地板之上的基线，本身就是一个可提前占位的提交候选。
- **P8（示教质量/无失败示教）**：共享自治采集（人类在策略将失败时接管）天然产生「偏离→修正」数据，且人类接管时刻就是免费的「权威标签」，可同时训练 I11 的权威头与 I5 的恢复头。
- **新增 P9（评测方差盲）**：没有基线噪声地板，所有消融增益都可能是随机波动；I8 的注册表必须先有 I10 的噪声估计才能工作。
- **新增 P10（权威混淆）**：人类干扰下策略可能「抢、僵、跟」三种错误；当前清单没有显式权威状态，I4 只做检测与停持，未定义恢复与让权边界。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（复现契约与噪声地板）**：在本赛 320 episode 的协议下，最小充分的 R-契约是什么？如何用 \(B_0\)–\(B_3\) 阶梯把「模型误差」与「评测噪声」分离？动作 MAE 与闭环成功率的离线-在线差由什么因素支配？
- **Q10（意外驱动的共享控制）**：在只有位置指令、无力/触觉的条件下，本体残差 + 视觉潜变量残差能否可靠区分「背景人」「移物人」「接触人」？权威律能否在不伤标称任务的前提下，把人类轴的 64 次从硬伤变成可恢复？
- **Q11（共享自治数据）**：人类-策略共享权威采集的纠正数据，是否比纯遥操作或 I5 的合成扰动更省人时、更贴评测偏离分布？人类接管标签能否蒸馏成推理期权威头？

## 4. 设计原则（新增 PR6/PR7，其余保留）

- **PR6 可复现优先律**：没有 R-契约与噪声地板的增益不进入真机预算；任何创新点的效应量必须先超过 MDE；所有指标与决策规则在看到结果前预注册。
- **PR7 权威显式律**：每个控制决策必须携带显式权威状态（策略/人类/让权/重观测）；禁止隐式混合；人类安全优先于任务完成；让权必须可恢复、可解释、可回放。
- PR1–PR5 保留（第 1/2 轮 §4）。PR5 数据杠杆律补充：共享自治纠正数据的杠杆 = 它覆盖的「评测偏离分布」比例，而不是数据量。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 基线复现与测量契约（R-Harness）★★★★★（新）

- **动机**：榜单未发布、无公开官方成功率、官方本地评测只比动作 MAE（F22/F26）。在「榜首 <30%」的低成功率赛区，若没有可复现基线与噪声地板，团队无法区分「模型进步」与「评测波动」；所有消融和真机预算都可能被噪声吞掉（P9）。I10 不是「跑通官方代码」，而是把基线变成**可重复的失败剖面 + 可判定的量尺**。
- **与现有方案差异**：直接 SFT 队伍把官方代码当起点；本点把官方代码当**测量仪器**：固定工件与环境、预注册指标与决策规则、用 \(B_0\)–\(B_3\) 阶梯分离动作误差/部署误差/闭环误差，并输出逐任务逐泛化轴的失败分类。它不直接涨点，但它决定后面每一分是否可信，且是 I8 注册表的 L-1 前置层。
- **技术可行性**：高。官方 Base 权重、微调脚本、本地动作评测、model_server 均已开源（F21/F22）；单张 24GB 可跑 frozen-VLM 微调；单任务通道可用于闭环抽测。
- **所需资源**：1×24GB GPU 起步（全参 8×A100 上限）；32 任务数据子集约 2TB（先下 6–8 个代表任务）；1–2 人周工程 + 1–3 天微调；单任务通道约 40–80 个 episode。
- **落地步骤**：
  1. **工件清单**：checkpoint sha256、代码 commit、数据版本、config hash、CUDA/驱动/依赖锁、随机种子、硬件型号；写入 `manifest.json`。
  2. **\(B_0\) 动作级复现**：用官方 `eval_local_episode` 在留出 episode 上跑 Base 零样本；记录每维动作 MAE、相对位姿误差（cm/deg）、gripper 误差、chunk 级/轨迹级误差；重复 3 次估计推理确定性。
  3. **\(B_1\) 训练复现**：用官方 frozen-VLM 配方在 32 任务子集上微调 2 个种子；比较 loss 曲线、动作 MAE、种子间方差；确认「同一配方可重训」。
  4. **\(B_2\) 部署复现**：把 \(B_1\) 包成赛题 PolicyService（token、观测键、chunk、N 端口），用 `run_client.py` 做全流程与动作健康度回归；记录 p50/p99 延迟。
  5. **\(B_3\) 闭环复现**：在单任务通道上选 2 个代表任务（一个抓放、一个接触/插入），各跑 10 次；记录成功率、步骤分、失败视频与失败分类。
  6. **负对照**：零动作、首帧重放、界内随机、人类遥操作上限；估计地板与天花板。
  7. **噪声地板与 MDE**：用 Wilson 区间与配对 bootstrap 给出总体/单任务/人类轴的可检测效应；写入 R-契约。
  8. **失败剖面**：按任务 × 泛化轴 × 失败类型（感知/接近/抓取/搬运/放置/插入/恢复/超时）建表；交给 I1/I2/I5/I9/I11 排优先级。
- **风险**：官方「基线」定义模糊（Base 零样本 vs 官方配方重训）——用 \(B_0\)–\(B_3\) 阶梯显式化；动作 MAE 与闭环成功率可能弱相关——把「离线-在线差」本身作为诊断量；单任务通道排期稀缺——先用 2 个任务做最小闭环，不追求全覆盖；R-契约可能变成工程无底洞——设 10 个工作日时间盒与止损线（见 §1.2）。

### I11 共享控制权威仲裁（Authority from Surprise）★★★★（新；吸收 I4）

- **动机**：人为干扰是 5 类泛化轴之一，占 20% 计分权重（F20/D1）；观测无 force/torque，动作无刚度/阻尼（F24），经典阻抗共享控制不可用；当前策略在人类干扰下可能「抢（对抗）、僵（停死）、跟（被带偏）」三种错误（P10）。I11 把人类干扰从「鲁棒性噪声」重构为「权威分配问题」。
- **与现有方案差异**：I4 只做手部检测 + 停持 + 自适应 chunk；本点不检测「人是否存在」，而检测「世界是否按命令变化」：本体残差判断接触，视觉潜变量残差判断移物；权威律决定让权/重观测/恢复。背景人不应触发让权，移物人应触发重规划，接触人应触发运动学让权。**存在感是错误抽象，意外才是正确抽象。**
- **技术可行性**：中-高。本体残差只需状态历史与动作历史；视觉残差可用同一 VLM 的 patch 特征（不引入第二个任务模型）；权威头是同一模型内的额外输出头；让权只需输出当前位姿/零相对位移，接口天然支持。
- **所需资源**：1×24GB GPU；2–3 个高人类轴失败任务；共享自治采集 6–10 人时；1 人周工程 + 1 人周数据/训练。
- **落地步骤**：
  1. **离线原型**：在已有示教/回放上注入受控扰动，验证 \(r^q\)、\(r^v\) 的分离度与阈值；做 ROC 与延迟分析。
  2. **三级干扰课程**：背景人（L1）、移物人（L2）、接触人（L3），见 §1.5；先在实验室/仿真做，不直接上计分通道。
  3. **权威状态机**：PROCEED→SUSPECT→YIELD/REOBSERVE→RESUME，带滞回与最短驻留；记录每次切换的观测、残差、动作。
  4. **共享自治采集**：人类在策略将失败时接管，记录权威标签；用标签训练权威头（蒸馏），并与意外信号融合。
  5. **单任务 A/B**：同一初始场景，配对「无干扰 vs L1/L2/L3」；先验证标称不回归，再看人类轴增益。
  6. **合规确认**：向组委会书面确认「同模型内的权威头 + 确定性让权规则」是否属于单模型；确认前不上计分通道。
- **风险**：人类干扰强度未知（背景/移物/接触比例）——用三级课程覆盖并让意外信号自适应；视觉残差对背景人误报——用物体中心/前景掩码特征，L1 专门测误让权率；单模型解释风险——权威头必须同模型，伺服只当老师（I3'）；无力反馈下「让权」只是运动学跟随，不能声称动力学柔顺；人类安全——限速、限幅、最短停持时间，宁可任务失败不可伤人。

## 1. 形式化定义与伪代码

### 1.1 R-契约（Reproduction Contract）

```text
R = (A, E, M, T, D)

A（工件）  = {checkpoint_sha256, code_commit, dataset_version,
              config_hash, env_lock, seed_set, hardware}
E（环境）  = {CUDA, driver, python, torch, flash-attn, OS}
M（指标）  = {action_mae_cm, action_mae_deg, gripper_mae,
              chunk_mae, trajectory_dtw, success_rate, step_score,
              latency_p50, latency_p99, action_health}
T（容差）  = {action: ε_a, success: Wilson 95% CI,
              latency: p99 ≤ L, determinism: Δ ≤ ε_d}
D（决策）  = {pre_registered hypotheses, MDE, stop rules,
              L-1 gate, L0/L1/L2 promotion rules}
```

**最小要求**：任何「创新点有效」的声明必须报告 \(A,E\) 的完整清单、\(M\) 的原始值、\(T\) 的容差、以及 \(D\) 中预先写死的通过/失败规则。缺一项即视为轶事，不进入 I8 注册表。

### 1.2 基线阶梯、噪声地板与决策规则

| 级别 | 内容 | 输入 | 产出 | 通过判据 |
|---|---|---|---|---|
| \(B_0\) | 官方 Base 零样本动作级 | 官方 checkpoint + 留出 episode | 动作 MAE / 轨迹图 / 确定性 | 3 次重复差异 ≤ ε_d；动作 MAE 可解释 |
| \(B_1\) | 官方配方在 32 任务子集重训 | 32 任务数据 + 官方 config | 2 个种子的 checkpoint + loss/MAE | 种子间方差 ≤ 噪声地板；训练可重跑 |
| \(B_2\) | 接赛题 PolicyService | \(B_1\) + wrapper | 全流程通过 + 延迟账本 | 0 拒绝动作；p99 可接受；状态隔离 |
| \(B_3\) | 单任务通道闭环 | \(B_2\) + 2 个代表任务 | 成功率 / 步骤分 / 失败视频 | 成功率可估；失败可分类 |
| \(B_4\) | 首个最小改进 | \(B_3\) + 一个创新点 | 基线相对增益 | 增益 > MDE 才继续 |

**统计事实（p≈0.3，Wilson 95%）**：

| 样本 | n | 95% CI 宽度 | 近似半宽 | 含义 |
|---|---:|---:|---:|---|
| 总体 32×10 | 320 | 0.100 | ±5.0% | 总体 <5% 的增益不可宣称 |
| 人类轴 32×2 | 64 | 0.219 | ±11.0% | 人类轴需要 >11% 的绝对增益才稳 |
| 单任务 10 次 | 10 | 0.495 | ±24.8% | 单任务小差异几乎不可判定 |
| 半任务 16×10 | 160 | 0.141 | ±7.1% | 分层比较可提升功效 |

**决策规则**：
1. 总体效应 < 5%：不宣称、不排队 L2。
2. 5%–10%：必须有配对设计（同初始场景/同种子）或步骤分支持，否则视为噪声。
3. >10%：进入 L2 排队；L2 真机增益需 ≥ 离线预测的 50%（沿用第 2 轮判据）。
4. 任何多次偷看：用 alpha spending 或固定序贯检验，避免 p-hacking。
5. 单任务结论必须报告 n 与 CI；n=10 时不得用「显著提升」措辞。

### 1.3 共享控制：意外驱动权威（Authority from Surprise）

**定义**：设 \(x_t=(q_t, ee_t, g_t, I_t)\) 为关节/EE/gripper/图像观测，\(u_t\) 为动作。本体前向预测 \(\hat f\)、视觉潜变量预测 \(\hat g\)：

\[
r^q_t=\|q_{t+1}-\hat f(q_t,u_t)\|_\Sigma,\qquad
r^v_t=\|z_{t+1}-\hat g(z_t,u_t)\|
\]

归一化意外 \(s_t=\max(r^q_t/\tau_q,\; r^v_t/\tau_v)\)，权威

\[
\alpha_t=\mathrm{clip}\left(\frac{1}{1+\exp(\beta(s_t-1))},0,1\right)
\]

执行 \(u_t^{exec}=\alpha_t u_t^{policy}+(1-\alpha_t)u_t^{yield}\)。\(u_t^{yield}\) 在 joint 空间 = 当前关节位置（零位移）；在 ee 空间 = 当前 EE 位姿（零相对位移）。**这是运动学让权，不是动力学柔顺**：位置接口无法设定刚度/阻尼，目标只是减少对抗与跟随人类位移。

**状态机**（滞回，避免抖动）：

```python
PROCEED:
    if r_q > TAU_Q for K_Q steps:      -> YIELD
    elif r_v > TAU_V for K_V steps:    -> REOBSERVE
    else: execute alpha * policy + (1-alpha) * hold

SUSPECT:
    if r_q > TAU_Q or r_v > TAU_V:
        shorten_chunk(4);             -> YIELD / REOBSERVE
    else:                              -> PROCEED

YIELD:
    execute hold_current_pose()        # zero relative action
    if r_q < 0.5*TAU_Q for M_Q steps:  -> RESUME
    # no fighting: never command motion against observed displacement

REOBSERVE:
    execute hold_current_pose() for H steps
    then re-plan from current obs       -> RESUME

RESUME:
    execute short chunk (4-6)
    if surprise recurs:                -> YIELD / REOBSERVE
    else:                              -> PROCEED
```

**为什么用意外而不是人检测**：
- 背景人（L1）：\(r^q\approx0, r^v\approx0\)（若视觉特征做前景/物体中心池化）→ 不让权，避免误停。
- 移物人（L2）：\(r^v\) 高 → REOBSERVE，重新规划，不把旧 chunk 硬执行。
- 接触人（L3）：\(r^q\) 高 → YIELD，跟随当前位姿，不与人对抗。
- 纯视觉人检测无法区分 L1/L2/L3，且引入第二个模型；意外信号是单模型内生的。

**权威头（可选，蒸馏）**：共享自治采集时人类接管给出标签 \(a^{human}_t\in\{0,1\}\)；训练 \(\hat\alpha_t=h_\theta(x_t)\) 预测接管概率。推理时 \(\alpha_t=\min(\hat\alpha_t,\alpha^{surprise}_t)\)：既可用视觉提前预判（人伸手时提前让权），又保留意外信号的兜底。权威头必须是同一模型的输出头，或至少共享 VLM 特征；不引入第二个任务策略。

### 1.4 共享自治纠正数据采集（HG-DAgger 风格）

```python
def shared_autonomy_episode(policy, human, env, task):
    obs = env.reset(task)
    log = []
    for t in range(T_max):
        u_policy = policy.propose_chunk(obs)
        u_human, human_active = human.override(obs)   # deadman/leader arm
        alpha = 0.0 if human_active else 1.0
        u = alpha * u_policy + (1 - alpha) * u_human
        log.append({
            "obs": obs, "u_policy": u_policy, "u_human": u_human,
            "alpha": alpha, "surprise_q": r_q(obs), "surprise_v": r_v(obs),
        })
        obs, done = env.step(u)
        if done:
            break
    return log
```

**数据用途**：
- 人类接管区间 → 「偏离→修正」真实分布；用于校准 I5 扰动幅度与恢复段。
- 接管时刻 → 权威标签；用于训练 I11 权威头。
- 交还时刻 + 后续成功 → 恢复成功标签；用于 I5 的里程碑检测器交叉验证。

**对照设计**：同任务、同预算比较三种数据源——纯遥操作、共享自治、I5 合成；指标 = 达到目标成功率所需 episode 数、人时、失败类型覆盖、真机人类轴成功率。

### 1.5 人类干扰三级课程（Human Interference Curriculum）

| 级别 | 干扰 | 主要信号 | 期望权威 | 关键指标 |
|---|---|---|---|---|
| L1 背景人 | 人在背景走动/站立，不接触物体/机器人 | \(r^v\) 低（前景/物体中心特征） | \(\alpha=1\)，不让权 | 标称成功率、误让权率（目标 <5%） |
| L2 移物人 | 人移动/拿走目标物或干扰物 | \(r^v\) 高 | REOBSERVE → 重规划 | 重规划成功率、恢复时间、旧 chunk 废止率 |
| L3 接触人 | 人推机械臂/抓物体/阻挡 | \(r^q\) 高 | YIELD → 跟随 → RESUME | 对抗代理（动作反向率/状态散度）、恢复时间、任务完成率、安全违规数 |
| L4 组合 | L2+L3 连续发生 | 先 \(r^q\) 后 \(r^v\) | YIELD→REOBSERVE→RESUME | 端到端完成率、最小安全距离代理 |

**对抗代理（无力传感器）**：
- 动作反向率：\(\frac{1}{T}\sum_t \mathbb{1}[\langle u_t^{cmd}, \Delta q_t^{human}\rangle < 0]\)；越低越好。
- 状态散度：\(\|q^{actual}-q^{cmd}\|\)；YIELD 时应小（跟随），PROCEED 时可大。
- 速度/加速度峰值：安全门禁。
- 恢复时间：从干扰结束到重新执行任务动作的步数。

## 2. 实验设计（R0–R5 + L-1/L0/L1/L2）

| 编号 | 实验 | 目的 | 通道/成本 | 通过判据 |
|---|---|---|---|---|
| R0 | \(B_0\) 动作级复现 | 验证官方 checkpoint 可跑、确定性、动作误差 | 离线 GPU | 3 次重复 ≤ ε_d；MAE 可解释 |
| R1 | \(B_1\) 训练复现 | 验证官方配方可重训、种子方差 | 1×24GB / 8×A100 | 种子间方差 ≤ 噪声地板 |
| R2 | \(B_2\) 部署复现 | 验证 PolicyService、N 端口、延迟、动作健康 | 本地 stub + 2×A100 | 0 拒绝动作；p99 可接受 |
| R3 | \(B_3\) 闭环基线 | 2 个代表任务 × 10 次；失败分类 | 单任务通道 | 成功率可估；失败可分类 |
| R4 | 共享控制离线原型 | 扰动注入；\(r^q/r^v\) ROC；阈值/延迟 | 离线 | L1 误报低；L2/L3 可分离 |
| R5 | 共享控制闭环 A/B | 同场景配对：无干扰 vs L1/L2/L3 | 单任务通道 | 标称不回归；人类轴增益 > MDE |
| L-1 | 基线复现门禁 | 所有消融的前置 | 离线 + 单任务 | \(B_3\) + 噪声地板存在 |
| L0 | in-silico 消融 | I1 轴剂量、I2 迁移、I5 合成、I9 先验、I11 离线 | 离线（免费） | 效应 > 噪声地板才进 L1 |
| L1 | 分数因子 | I1 四轴 × I11 三组件（意外/让权/权威头） | 离线 + 少量真机 | 主效应显著 ≤3 个组合进 L2 |
| L2 | 真机确认 | top 组合；含人类干扰场景 | 单任务通道 | 真机增益 ≥ 离线预测 50% |

**首批 L2 排队**：①\(B_3\) 基线（2 任务）→ ②I11 L3 接触让权（1 任务）→ ③I11 L2 移物重规划（1 任务）→ ④I5/I2 共享自治数据（1 任务）。**I10 的 \(B_3\) 未完成前，其余创新点不得占用 L2 预算。**

- [ ] **单模型**：I11 权威头必须在同一模型内，或为确定性规则；不按任务混用多个模型（F20）；I3 伺服只当老师/辅助监督；向组委会书面确认权威头/安全 guard 的单模型边界（**新增确认项**）。
