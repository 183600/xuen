# 第 1 轮（本轮灵感循环；承接历史 v9 / 第 9 轮 MetricVoiceGauge-ACMD）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**动力学接地 + 标注主动 + 局部认证 + 单向退化**。两个灵感分别治理 v9 的两笔残余债：**认证债**（块证书的 β 是全局常数工程上界，只在"信任域内"被假设成立；DA-ML 的 20 帧滑窗在真实分布跳变时滞后）与**接地债**（前向模型 F̂ 的训练数据是被动采集的，最需要它的接触/近失/负载突变样本恰恰最少、最晚被标注）。核心转向：不再问"如何把 β 估得更准"，而问"**一个未被局部认证、未被动力学证据支持的块，凭什么被允许执行 K>1 步**"。答案：**无覆盖即退化，残差只许放宽，标注方可收紧**。

## 0. 直觉与动机

**灵感 1（数据标注 → 标注是证书的证据，不是数据量的同义词）**
直觉：v9 的 β 来自 E554 的经验误差上界乘 1.2。这是一个没有覆盖率语义的点估计：换一个域、换一种负载、换一位标注者，它就可能失效，而系统仍会"按证书"执行。数据标注的真正价值不是"多标数据"，而是给证书提供**可审计的证词**：每条标签带来源（物理/人类/自动）、置信度、时间、schema 与标注者；"弃权"是合法标签，也是标签融合的恒等元。主动标注把稀缺的人类注意力花在证书最薄的地方：高动力学残差、高模型分歧、低覆盖的新区域。标注不是安全路径上的同步调用，而是**带截止期与预算的旁路契约**；超时即弃权，弃权只能让证书更保守。
**关键安全语义**：标注是"收紧"证书的唯一合法来源，且必须经过独立验证；没有新标注，β 不许下降。

**灵感 2（动力学 → 物理是免费的、毫秒级的标注者）**
直觉：DA-ML 看的是像素/特征的分布距离，它有 20 帧滑窗，天然滞后；而接触、负载突变、摩擦变化会立刻破坏广义动量守恒关系。用一个广义动量观测器，把"模型预测的动量变化"与"测量/指令力矩积分"比较，得到残差 ρ；模型一旦失配，ρ 在几个观测周期内就抬头。这是**无需人工标注的物理弱标签**：它不知道"发生了什么"，但知道"模型此刻不可信"。虚拟能量罐再提供一条与学习模型无关的无源约束：无论 F̂ 多错，控制器注入的能量有界；非被动的人推/碰撞会让能量罐放电，直接触发安全停驻。**物理不保证避障，但物理保证"不会因为模型错而无限注入能量"**；避障仍由学习证书 + 中止点集负责，二者是合取，不是替代。
动力学还给出第三件事：**可激励性**。并非所有模型误差都能被当前动作激发；在证书裕度大、能量罐充足的块边界做小幅度安全激励，可以主动制造信息量最大的标注样本——但激励必须受证书与能量罐双重门控，且可一键关闭。

**综合直觉（两条灵感如何咬合）**
数据标注是慢通道（分钟级、有人类），动力学残差是快通道（毫秒级、无人类）。快通道负责**放宽**：残差一抬头，立即把该区域的 β 抬高、K_eff 收缩，必要时一个周期内中止。慢通道负责**收紧**：只有经过融合与独立验证的标注批次，才允许把 β 降回去。这个**非对称更新**是 v10 的安全骨架：**残差只许放宽，标注方可收紧；弃权即保守，无覆盖即 K=1**。于是 v9 的"最需要安全时证书最不可靠"被拆成两个可分别验证的问题：快通道保证"失效被尽快发现"，慢通道保证"发现后能被认证地修复"。

## 1. 研究问题（轮次升级版）

- **Q1（动力学失效检测的健全性）**：在力矩估计误差、执行器延迟、关节摩擦与浮动基耦合下，广义动量残差 ρ 能否在一个控制周期内给出**保守**的模型失效信号？阈值如何用共形/极值理论标定，使名义误报可控？哪些非被动交互（人推、碰撞）会让残差与能量罐给出不一致的证据，如何仲裁？
- **Q2（局部认证与主动标注）**：如何用分区域共形 + 自适应共形（ACI）在标签噪声、选择性采样与非交换漂移下维持**每区域**的覆盖率下界？主动采集如何把预算优先分配给"高残差 × 低覆盖 × 高证书裕度缺口"的区域？弃权/缺席如何保证 β 单调不降？
- **Q3（单向退化与等价）**：非对称更新 + 覆盖缺口退化能否构成一个**单向安全格**——任一新增模块失效只会让 β 增大、K_eff 减小，全失效逐位等价退回 v9？在什么条件下"标注失败"不会变成"安全漏洞"而是"更保守"？安全激励的收益是否有可证的上界与可关闭的开关？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 动力学接地律（Dynamics-Grounded Certification, DGC）**
任何学习证书不得单独放行。块证书的有效性定义为**学习证据 ∧ 物理证据**的合取：Ĉ_t(β(ξ)) 有效 ∧ 动量残差 ρ ≤ τ_dyn(ξ) ∧ 能量罐 E_t ≥ E_min ∧ 中止点集 P_t ≠ ∅。物理证据是必要的（防止模型错误导致能量无界注入与接触漏检），但不是充分的（不保证障碍物间隙）；二者缺一即退化。**"没有物理证据的学习证书"在本体系中不是证书，只是猜测。**

**P14 标注单向律（One-Way Annotation, OWA）**
标签代数带来源、置信度与弃权恒等元 ⊥_ann；融合对弃权是恒等的。β 的更新是非对称的：**残差/漂移只能即时放宽 β；只有经过 n_j ≥ n_min 的新标注批次并在独立验证集上通过覆盖率校验，才允许收紧 β**，且每次收紧有上限 δ_down、需连续 h_ok 个窗口确认。缺席、超时、弃权一律视为"不放宽也不收紧"的保守中性。**沉默不是许可，沉默是保守。**

**P15 缺口即退化律（Coverage-Deficit Degradation, CDD）**
把信任域从"一个标量 Δ_dom 的门限"升级为"状态-动作分区上的认证覆盖"。若当前块所在分区未认证（n_j < n_min）、残差超阈、能量罐不足或 β_j ≥ β_stop，则 K_eff = 1，逐步执行（等价 v8 粒度）；否则 K_eff 随局部 β_j 单调递减。任何新增模块失效都只能**增大 β、减小 K_eff**，形成单向安全格；全失效必须逐位等价退回 v9（引理 92）。**覆盖不到的地方，没有块，只有一步。**

## 3. 与基线的接口（如何退化）

- DRM（动量残差）失效/不可信 ⇒ 关闭"一周期失效中止"，K_eff = min(K_β, K_dom)，退回 v9 的 Δ_dom 门控与 50Hz 证书守卫；能量罐仍可独立工作；
- PTG（能量罐）失效 ⇒ 阻断"无源能量界"，K_eff = min(K_β, K_dom)，β = β_global，退回 v9 的证书 + 中止点集；
- RCC（分区域共形）失效 ⇒ β(ξ) ← β_global（v9 的全局常数），K_eff 使用 v9 的 Δ_dom/risk_SLAM 门控；
- AAS（主动标注）失效 ⇒ 弃权恒等、停止局部 β 收紧，β ← β_global；不阻塞主环；
- LFP（标签融合）失效 ⇒ 只接受物理/自动标签并按要求膨胀 η⁺；若仍不可用，按 RCC 失效处理；
- 以上全部失效 ⇒ **逐位等价 v9 MetricVoiceGauge-ACMD**（引理 92）；v9 再失效 ⇒ 按 v9 引理 83 退回 v8/v7；
- 新增层永不改变 v9 的九不变式与 M₀ 硬检查；所有新增模块都是"可选增强"，不是安全前提。

## 4. 预期贡献

1. **动力学接地的块证书**：用广义动量残差 + 虚拟能量罐给学习证书加一层毫秒级、与模型无关的物理证据；把 v9 的"信任域假设"变成"可观测的失效信号 + 能量硬界"；
2. **标注单向的局部认证**：分区域共形 + ACI + 标签来源代数，把 β 从全局工程系数升级为"每区域、带覆盖率语义、可审计"的契约；弃权是恒等元，缺席只会更保守；
3. **单向安全退化格**：非对称更新 + 覆盖缺口退化，证明任一新增模块失效只减小 K_eff；全失效逐位退回 v9，部分失效落在 v9 的保守锥内；
4. **E571–E598** 覆盖残差检测、无源界、分区覆盖、标签噪声、主动采集、单向更新、缺口退化、全失效等价、实时性与端到端接触丰富任务。

## 5. 本轮最大风险

**一句话**：v10 可能只是把 v9 的「滞后信任域」换成了「覆盖盲区信任域」——分区共形与主动标注的健全性依赖局部可交换性/有界漂移，而最危险的恰恰是从未被激励、从未被标注的新动力学模式；在那里 β(ξ) 的"保守"只是没数据时的默认值，残差也只有等失配发生后才看得见。

**新增定义 540（广义动量残差 DynamicsResidual）** 设机器人关节空间动力学为 M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + τ_ext，且 Ṁ − 2C 反对称。定义广义动量 p = M(q)q̇ 与观测器：
```
r(t) = K_o [ p(t) − p(0) − ∫_0^t ( τ + C^T(q,q̇)q̇ − g(q) + r(s) ) ds ]
```
其中 K_o ≻ 0。对时间求导得 `ṙ = K_o(τ_ext + δ_m − r)`，δ_m 为摩擦、负载、未建模执行器与参数误差的等效广义力。故无外部接触且模型精确时 r≡0；失配/接触时 r 以时间常数 1/K_o 收敛到 τ_ext+δ_m。定义归一化残差：
```
ρ(t) = ||r(t)||_{Σ^{-1}} / (||τ(t)|| + ε)
```
Σ 为名义残差协方差（Mahalanobis 归一化），ε 防除零。分区阈值 τ_dyn(ξ) 由名义数据上的共形/极值分位标定，满足名义误报率 ≤ α_dyn。浮动基系统用质心动量/浮动基广义动量替换 p，推导不变。

**新增定义 541（虚拟能量罐 PassivityTank）** 能量罐 E_t ≥ 0 按控制端口功率更新：
```
E_{t+1} = E_t − Δt · (σ_t u_t^T v_t)
```
σ_t ∈ [0,1] 为功率缩放。若 `E_{t+1} < E_min` 且 `u_t^T v_t > 0`（正在向被控对象注入能量），取
```
σ_t = max(0, (E_t − E_min) / (Δt · u_t^T v_t + ε))
```
并对 u_t 缩放；若仍 `E_{t+1} < E_min`，返回 `passivity_stop`。无源性假设下 `V̇ ≤ u^T v`（V 为对象+环境储能），于是 `d(V+E)/dt ≤ 0`：控制器不能向对象注入超过初始总储能的能量。人推/碰撞等外部非被动输入以 `P_env` 进入，`d(V+E)/dt ≤ P_env`，能量罐放电并触发停驻。**注意：能量有界 ≠ 障碍物间隙安全；本项只负责“模型错也不会能量无界注入/漏检接触”，避障仍由学习证书+中止点负责。**

**新增定义 542（标注原子与标签代数 AnnotationAtom & LabelAlgebra）** 标注原子 ℓ=(y,c,p,τ,s,h)，其中 y∈Y∪{⊥_ann}，c∈[0,1]，p∈{physics, human, auto}，s 为片段，h 为 schema hash。弃权 ⊥_ann 是融合恒等元：`ℓ ⊔ ⊥_ann = ℓ`。融合用对数意见池：
```
P(y | ℓ_{1:L}) ∝ exp( Σ_l w(p_l) log P(y | ℓ_l) + log P_0(y) )
```
混淆矩阵 `P(ℓ_l | y)` 由 Dawid-Skene/EM 估计；来源权重 w(p) 有先验但可学习。物理标签不需人类，但相互不独立（共享模型假设），故用有效样本数：
```
n_eff = (Σ_l w_l)^2 / (Σ_l w_l^2 + ε)
```
校准与验证按 n_eff 而非原始条数计。标注噪声只允许通过单侧膨胀 `η⁺` 进入 β：`β ← β + η⁺`，不允许“标签一致 ⇒ 收紧”。

**新增定义 543（标注契约 AnnotationContract）** 人类标注作为 MW 的一等契约：
```
κ^ann = (D_ann=2000ms, Ŵ_ann=0.1ms, B_ann=6/min,
         ⊥_ann=abstain, π_ann=low, φ_ann^crit=false)
```
D_ann 为人类响应截止期，B_ann 为操作员注意力预算；查询只能由 AAS 在非安全路径发起；到截止期未返回即注入 ⊥_ann（弃权），绝不阻塞 50Hz 主环。自动/物理标签走独立的低延迟契约（D=10ms），不占人类预算。

**新增定义 544（主动采集分数 AcquisitionScore）** 对候选片段 ξ：
```
a(ξ) = w_r·ρ̄(ξ) + w_u·H(P(y|ℓ(ξ))) + w_g·(β(ξ) − β_target)^+
     + w_c·covdef(ξ) + w_e·I_exc(ξ) − w_b·cost(ξ)
```
`covdef = (1 − n_j/n_min)^+`；`I_exc` 为安全激励指示。查询条件 `a(ξ) > θ_acq` 且预算未耗尽；每窗口取 Top-B_ann。安全激励仅在块边界、且
```
margin ≥ d_safe + d_exc,  E_t ≥ E_exc,  β(ξ) ≤ β_exc,  ||u_exc|| ≤ u_exc_max
```
时允许，可一键关闭。覆盖项对集合是单调次模；预算为基数约束时贪心给出 (1−1/e) 近似（引理 93）。

**新增定义 545（分区域共形误差界 RegionwiseConformalBound）** 用状态-动作特征把空间划分为分区 C_j（网格/KD-tree/学习聚类）。对每个新标注样本计算非一致性分数 `s_i = |F̂(x_i) − y_i| / scale_i`。Mondrian 共形分位：
```
β_j = s_(⌈(n_j+1)(1−α_j)⌉)    若 n_j ≥ n_min
β_j = β_max                   否则
β(ξ) = β_{j(ξ)},   β_global = max(β_max, sup_j β_j, 离线界)
```
`β_global` 是全局上包络，故任何回退到全局界都只会更保守。漂移用自适应共形（ACI）：
```
α_{j,t+1} = clip( α_{j,t} + γ_aci·(α − err_{j,t}), α_min, α_max )
```
其中 `err_{j,t}=1[|F̂−y|>β_j]`。协变量偏移下用密度比 w(x) 的加权共形分位。保证为**分区边际覆盖**；同时用 Bonferroni α/S 报告最差分区覆盖，但不声称任意条件覆盖。

**新增定义 546（非对称认证更新 AsymmetricCertification）** β 的更新只允许两种方向：
- **即时放宽（残差/漂移）**：`β_j ← min(β_max, β_j + γ_r·(ρ−τ_nom)^+ + λ_drift·Δt + κ_d·D_j)`，并把该分区标为 `provisional`；K_eff 立即按新 β 收缩；
- **认证收紧（仅标注）**：当且有新标注批次满足 `n_j ≥ n_min`、独立验证集覆盖率 `Ĉ_j ≥ 1−α−δ`、连续 `h_ok` 个窗口通过，才计算候选 `β_j^conf`，并按
```
amount = min( max(0, β_j − β_j^conf), δ_down )
β_j ← max(β_j^min, β_j − amount)
```
收紧。弃权/缺席/超时：不改变 β。**这条不对称性是 v10 的安全核心：快通道只能让系统更保守，慢通道才能让它重新激进。**

**新增定义 547（动力学接地块证书 DynamicsGroundedChunkCertificate）**
```
ζ_t = ( a^{1:K}, Ĉ_t, P_t, β(ξ_t), ρ(t), E(t) )
```
有效 ⇔ 四项合取：
1. `Ĉ_t(β(ξ_t))` 在定义 533 下有效（含局部 β 与当前 τᵢ(t)）；
2. `ρ(t) ≤ τ_dyn(ξ_t)`（当前模型有效性）；
3. `E(t) ≥ E_min` 且沿块的保守能量预测 `E_k ≥ E_min, ∀k≤K`；
4. 中止点集 `P_t ≠ ∅`（定义 534）。
中块守卫每周期检查 (2)(3)：若现场 `ρ > τ_dyn` 或 `E < E_min`，立即切换到 ≤ 当前执行步的最大中止点 p*，**不等块边界、不等 DA-ML 滑窗**。块生成时的 (2) 只检查当前残差，不假设未来；未来由 50Hz 现场守卫负责。

**新增定义 548（标注债 AnnotationDebt）**
```
D_j = risk_j · [ (1 − n_j/n_min)^+ + λ_age·age_j + λ_ρ·ρ̄_j ]
D   = Σ_j D_j
```
`risk_j` 为分区风险权重（由 M₀ 裕度、障碍距离、任务关键度合成）。标注债越高，AAS 越优先；无新标注时按定义 546 的 `κ_d·D_j` 持续膨胀 β。**标注债不是“欠的数据”，是“尚未被证词覆盖的风险”。**

**新增定义 549（门控有效块长 GatedEffectiveChunkLength）**
```
K_eff(t) = 1                                           若 n_j < n_min
                                                          ∨ ρ(t) > τ_dyn(ξ)
                                                          ∨ E(t) < E_min
                                                          ∨ β_j ≥ β_stop
         = max(1, ⌊K_max·(1 − β_j/β_stop)⌋)             否则
```
健康模式下 K_eff=K_β；任何回退模式下 `K_eff ← min(K_eff, K_dom(t))`，其中 K_dom 是 v9 定义 539 的 Δ_dom/risk_SLAM 门控。K_max=10（50Hz 下 200ms 时域）。**健康模式允许在局部认证良好的分区取比 v9 更长的块；一旦任何新增证据缺失，立即回落到 v9 的保守包络。**

# IP-357 DynamicsResidualMonitor：广义动量残差
class DynamicsResidualMonitor:
    def __init__(self, M_fn, C_fn, g_fn, Ko=100.0, dt=0.001,
                 tau_dyn=None, Sigma_inv=None, eps=1e-6):
        self.M, self.C, self.g = M_fn, C_fn, g_fn
        self.Ko, self.dt = Ko, dt
        self.tau_dyn = tau_dyn or {}
        self.Sigma_inv = Sigma_inv or (lambda z: z)
        self.eps = eps
        self.p_prev = None
        self.r = 0.0
        self.rho = 0.0

    def step(self, q, qd, tau):
        p = self.M(q) @ qd
        if self.p_prev is None:
            self.p_prev = p
            return 0.0
        p_dot = (p - self.p_prev) / self.dt
        # r_dot = Ko * (p_dot - (tau + C^T qd - g + r))
        e = p_dot - (tau + self.C(q, qd).T @ qd - self.g(q) + self.r)
        self.r += self.Ko * self.dt * e
        self.p_prev = p
        rn = self.Sigma_inv(self.r)
        self.rho = float((rn @ rn) ** 0.5) / (float(tau @ tau) ** 0.5 + self.eps)
        return self.rho

    def violated(self, cell):
        return self.rho > self.tau_dyn.get(cell, self.tau_dyn.get('*', float('inf')))


# IP-358 PassivityTankGuard：无源能量罐
class PassivityTankGuard:
    def __init__(self, E0=50.0, Emin=5.0, dt=0.001):
        self.E, self.Emin, self.dt = E0, Emin, dt

    def step(self, u, v):
        P = float(u @ v)                     # >0: 向对象注入能量
        E_next = self.E - self.dt * P        # 能量罐随注入而下降
        if E_next < self.Emin and P > 0:
            scale = max(0.0, (self.E - self.Emin) / (self.dt * P + 1e-9))
            u = scale * u
            E_next = self.E - self.dt * scale * P
        if E_next < self.Emin:
            return None, 'passivity_stop'
        self.E = E_next
        return u, 'ok'

    def predicted_ok(self, pred):
        E = self.E
        for p_k in pred.power:
            E -= self.dt * p_k
            if E < self.Emin:
                return False
        return True


# IP-359 RegionwiseConformalCertifier：分区共形 + ACI
class RegionwiseConformalCertifier:
    def __init__(self, F, cell_fn, alpha=0.05, alpha_min=0.01, alpha_max=0.5,
                 n_min=30, beta_max=0.10, beta_min=0.0,
                 beta_stop=0.08, delta_down=0.005, kappa_d=0.01,
                 lam_drift=1e-4, gamma_r=0.02, gamma_aci=0.01, h_ok=3):
        self.F, self.cell = F, cell_fn
        self.alpha0 = alpha
        self.alpha = defaultdict(lambda: alpha)
        self.scores = defaultdict(list)
        self.beta = defaultdict(lambda: beta_max)
        self.alpha_min, self.alpha_max = alpha_min, alpha_max
        self.n_min, self.beta_max, self.beta_min = n_min, beta_max, beta_min
        self.beta_stop, self.delta_down, self.kappa_d = beta_stop, delta_down, kappa_d
        self.lam_drift, self.gamma_r, self.gamma_aci = lam_drift, gamma_r, gamma_aci
        self.h_ok = h_ok

    def _q(self, s, a):
        n = len(s)
        if n == 0:
            return float('inf')
        k = min(n, max(1, math.ceil((n + 1) * (1 - a))))
        return sorted(s)[k - 1]

    def certify(self, x):
        j = self.cell(x)
        if len(self.scores[j]) < self.n_min:
            return self.beta_max, False
        return self.beta[j], True

    def observe(self, x, y, scale=1.0):
        j = self.cell(x)
        self.scores[j].append(abs(self.F(x) - y) / scale)

    def inflate(self, x, rho, tau_nom, dt, debt=0.0):
        j = self.cell(x)
        self.beta[j] = min(self.beta_max,
                           self.beta[j] + self.gamma_r * max(0.0, rho - tau_nom)
                           + self.lam_drift * dt + self.kappa_d * debt)

    def try_deflate(self, x, holdout_ok, h_ok_count):
        j = self.cell(x)
        if len(self.scores[j]) < self.n_min or not holdout_ok:
            return False
        if h_ok_count < self.h_ok:
            return False
        cand = min(self.beta_max, self._q(self.scores[j], self.alpha[j]))
        amount = min(max(0.0, self.beta[j] - cand), self.delta_down)
        self.beta[j] = max(self.beta_min, self.beta[j] - amount)
        return True

    def aci_update(self, x, err, alpha_target):
        j = self.cell(x)
        self.alpha[j] = min(self.alpha_max, max(self.alpha_min,
                           self.alpha[j] + self.gamma_aci * (alpha_target - err)))


# IP-360 ActiveAnnotationScheduler：主动采集
class ActiveAnnotationScheduler:
    def __init__(self, rcc, drm, tank, fusion, B_ann=6, theta=0.5,
                 beta_target=0.02, beta_exc=0.02, d_exc=0.10,
                 E_exc=20.0, w=(0.3, 0.2, 0.2, 0.2, 0.1, 0.2)):
        self.rcc, self.drm, self.tank, self.fusion = rcc, drm, tank, fusion
        self.B_ann, self.theta = B_ann, theta
        self.beta_target, self.beta_exc = beta_target, beta_exc
        self.d_exc, self.E_exc = d_exc, E_exc
        self.wr, self.wu, self.wg, self.wc, self.we, self.wb = w
        self.used = deque()

    def score(self, seg):
        beta, covered = self.rcc.certify(seg.x)
        ent = self.fusion.entropy(seg.labels)
        covdef = 0.0 if covered else (1.0 - len(self.rcc.scores[self.rcc.cell(seg.x)]) / self.rcc.n_min)
        exc = 1.0 if self.safe_excitable(seg) else 0.0
        return (self.wr * seg.rho + self.wu * ent
                + self.wg * max(0.0, beta - self.beta_target)
                + self.wc * covdef + self.we * exc - self.wb * seg.cost)

    def safe_excitable(self, seg):
        return (seg.at_block_boundary and seg.margin >= self.d_exc
                and self.tank.E >= self.E_exc and seg.beta <= self.beta_exc)

    def _expire(self, t):
        while self.used and t - self.used[0][0] > 60.0:
            self.used.popleft()

    def step(self, t, candidates):
        self._expire(t)
        if len(self.used) >= self.B_ann:
            return []
        ranked = sorted(candidates, key=self.score, reverse=True)
        picked = [c for c in ranked if self.score(c) > self.theta]
        picked = picked[:self.B_ann - len(self.used)]
        self.used.extend((t, c) for c in picked)
        return picked                       # 交给 κ^ann；超时注入弃权


# IP-361 LabelFusionProvenance：来源加权融合
class LabelFusionProvenance:
    def __init__(self, prior, confusion, weights):
        self.prior, self.confusion, self.weights = prior, confusion, weights

    def fuse(self, labels):
        active = [l for l in labels if l.y is not None]
        if not active:
            return ABSTAIN                  # ⊥_ann：恒等元
        logp = np.log(self.prior + 1e-12)
        for l in active:
            P = self.confusion[l.issuer][l.y]
            logp += self.weights[l.provenance] * np.log(P + 1e-12)
        return softmax(logp)

    def effective_n(self, labels):
        w = np.array([self.weights[l.provenance] for l in labels], dtype=float)
        return float((w.sum() ** 2) / (np.sum(w ** 2) + 1e-12))


# IP-362 DynamicsAnnotatedChunkCertifier：v9 AC 的动力学-标注接地升级
class DynamicsAnnotatedChunkCertifier(ActionChunkCertifier):
    def __init__(self, forward_model, policy, drm, tank, rcc,
                 K_max=10, beta_stop=0.08, tau_nom=1.0, dt=0.02, **kw):
        super().__init__(forward_model, policy, K_max=K_max, **kw)
        self.drm, self.tank, self.rcc = drm, tank, rcc
        self.beta_stop, self.tau_nom, self.dt = beta_stop, tau_nom, dt

    def effective_K(self, x, ctx, fallback=False):
        beta, covered = self.rcc.certify(x)
        j = self.rcc.cell(x)
        if (not covered or self.drm.violated(j)
                or self.tank.E < self.tank.Emin or beta >= self.beta_stop):
            return 1
        K = max(1, int(self.K_max * (1.0 - beta / self.beta_stop)))
        if fallback:                        # 任一新增证据缺失 ⇒ v9 保守包络
            K_v9 = ActionChunkCertifier.effective_K(
                self, ctx.delta_dom, ctx.tau_dom, ctx.trust_ok)
            K = min(K, K_v9)
        return K

    def generate_chunk(self, state, ctx, fallback=False):
        K = self.effective_K(state.x, ctx, fallback=fallback)
        if K == 1:
            return self._single_step_fallback(state)
        beta, _ = self.rcc.certify(state.x)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.F.rollout(state, cand)
            if pred.min_clearance - beta < self.d_safe:      continue
            if pred.max_effort + beta > state.tau_eff:       continue
            if not self.tank.predicted_ok(pred):             continue
            pts = self._abort_points(state, cand, pred)
            if not pts:                                      continue
            score = self.policy.score(cand, pred)
            if best is None or score > best.score:
                best = Chunk(cand, Cert(pred.min_clearance - beta,
                                        pred.max_effort + beta), pts, score)
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs):
        j = self.rcc.cell(live_obs.x)
        if self.drm.violated(j):                              # 一周期失效信号
            self.rcc.inflate(live_obs.x, self.drm.rho, self.tau_nom, self.dt)
            return ('abort', self._nearest_abort(chunk, k_exec), 'dyn_residual')
        if self.tank.E < self.tank.Emin:                      # 无源界破坏
            return ('abort', self._nearest_abort(chunk, k_exec), 'passivity')
        return super().midchunk_guard(chunk, k_exec, live_obs)

## 4. 推导

**引理 87（动量残差的单周期失效检测）** 设 (A1) q,q̇ 可测，τ 为测量或带界估计，模型失配与外部广义力合成 `e(t)=τ_ext(t)+δ_m(t)`；(A2) `0 < K_o Δt < 2`；(A3) 失效事件后 `||e|| ≥ f_min > τ_dyn` 至少持续一个观测周期。则观测器（定义 540）在
```
T_det ≤ (1/K_o)·ln( f_min / (f_min − τ_dyn) ) + Δt
```
内使 ρ(t) > τ_dyn。取 f_min = 2τ_dyn、K_o=100 s⁻¹、Δt=1ms，得 T_det ≤ ln2/100 + 1ms ≈ 8ms。证明：由 `ṙ=K_o(e−r)`，阶跃 e=f 时 `r(t)=f(1−e^{−K_o(t−t0)})`，令 r=τ_dyn 解出上式；归一化不改变符号，阈值按同一分区标定。∎
**与 v9 的对比**：DA-ML 的 20 帧滑窗在 50Hz 下是 400ms；DRM 把“模型失效被看见”的时间压到 ≤10ms 量级。注意：这是**检测**不是**误差上界**；误差上界仍由 RCC 的共形界提供，二者分工不同。

**引理 88（能量罐的无源硬界）** 假设对象+环境对被控端口 (u,v) 无源：`V̇ ≤ u^T v`（V 为储能；人推/碰撞作为外部功率 P_env 另计）。能量罐按定义 541 有 `Ė = −σ u^T v`。取 `W=V+E`，则 `Ẇ ≤ σ u^T v − σ u^T v = 0`；有外部输入时 `Ẇ ≤ P_env`。投影保证 `E_t ≥ E_min > 0`，故
```
V(T) ≤ V(0) + E(0) − E(T) + ∫_0^T P_env dt
     ≤ V(0) + E(0) + ∫_0^T P_env dt
```
控制器注入的能量被初始总储能与外部输入界定，**与 F̂ 的误差无关**。推论：模型错误不能通过“无限注入能量”把系统推向失稳；但该界不保证障碍物间隙，避障仍需定义 547(1)(4)。∎

**引理 89（非对称更新的单调保守性）** 在定义 546 下，两次“认证收紧”之间 β_j 只增不减：放宽项 `γ_r(ρ−τ_nom)^+ + λ_driftΔt + κ_dD_j` 非负；收紧必须满足 `n_j≥n_min`、独立验证通过、连续 h_ok 窗口，且单次降幅 ≤δ_down；弃权/缺席不改变 β。故若上次认证时 `β_j ≥ |F̂−F|` 以概率 ≥1−α 成立，则在下一次认证前该覆盖不被主动削弱；标注失败只能让 β 更大或不变。∎
**推论 89.1（沉默即保守）** 若 AAS 长期无查询返回，β 按漂移/标注债膨胀，K_eff 单调不增；系统不会因为“没有新标注”而变得更激进。

**引理 90（分区域共形的覆盖率与缺口退化）** 在每个分区内样本可交换且 `n_j≥n_min` 时，split-conformal 分位给出 `P(|F̂(x)−y| ≤ β_j) ≥ 1−α`（分区边际）；`n_j<n_min` 时 β_j=β_max 且定义 549 强制 K_eff=1，故未认证分区不会以块模式执行。协变量偏移下，密度比有界 w≤w_max 的加权共形保持目标分布覆盖；ACI 更新给出长程覆盖 `≥1−α−δ`（δ 随 γ_aci 与漂移幅度）。用 Bonferroni α/S 可报告同时覆盖；**但任意条件覆盖不被保证**——这正是 E576 要压测的边界。∎

**引理 91（标注调度的有界性与安全路径隔离）** 在 κ^ann 下，每窗口人类查询数 ≤B_ann，调度成本 Ŵ_ann 与低优先级不破坏 MW 的 EDF 可行性；安全路径在截止期到达时注入 ⊥_ann，故从不等待标注。若事件到达率 λ_e 与单查询成本 c_q 满足 `λ_e c_q ≤ B_ann`，标注队列稳定、D(t) 有界；否则 D 增长，经定义 546 膨胀 β、经定义 549 收缩 K_eff，直至 K=1，系统以保守方式退化而非违规。状态迁移需 h_ok 窗口且 β 每窗口变化有界，故无 Zeno。∎

**引理 92（单向退化格与 v9/v8 等价）** 令健康向量 h=(h_DRM,h_PTG,h_RCC,h_AAS)∈{0,1}^4。对任意 h'≤h（逐分量更多失效），有 `β(h') ≥ β(h)` 且 `K_eff(h') ≤ K_eff(h)`。逐项验证：
- DRM 失效：关闭快中止，`K←min(K,K_dom)`，K 不增；
- PTG 失效：`β←β_global≥β_local`，`K←min(K(β_global),K_dom)≤K`；
- RCC 失效：同 PTG（β_global 为上包络）；
- AAS/LFP 失效：停止收紧、弃权恒等，β 不回降，按 RCC 失效处理。
当 h=0（全部失效）时，β=β_global、K=K_dom、守卫=v9 的证书/停车不变式守卫，逐位复现定义 532–539 的 v9 行为；再失效按 v9 引理 83 退回 v8/v7。∎
**推论 92.1（部分失效的保守锥）** 任一非空失效集合都落在 v9 与健康 v10 之间的保守锥内：不会比健康 v10 更激进，也不会比 v9 更冒险（全失效恰好是 v9 顶点）。

**引理 93（安全激励的收益上界与采集次模性）** 在安全激励门控 `margin≥d_safe+d_exc`、`E≥E_exc`、`β≤β_exc`、仅在块边界且幅值 ≤u_exc_max 下，单次激励的附加风险 ≤ε_exc（由证书裕度与能量储备界定）；在持续激励条件下，每次激励对动力学参数的 Fisher 信息增益 ≥I_min 以概率 ≥1−δ。采集分数中的覆盖缺口项 `covdef(ξ)` 对候选集合单调次模，`ρ̄`、熵、裕度缺口项均为非负模块项，故在基数预算 B_ann 下贪心选择对次模部分达到 (1−1/e) 近似；门控不满足时 I_exc=0，查询被跳过。∎

## 9. 本轮最大风险

**一句话**：v10 可能只是把 v9 的「滞后信任域」换成了「覆盖盲区信任域」——分区共形与主动标注的健全性依赖局部可交换性/有界漂移，而最危险的恰恰是从未被激励、从未被标注的新动力学模式；在那里 β(ξ) 的"保守"只是没数据时的默认值，残差也只有等失配发生后才看得见。
