## 3. 灵感词交点（组合即创新）

- **无刷电机 × 交互设计 = chunk 整形器**：边界混合（上一 chunk 尾与下一 chunk 头的平滑过渡）+ 限速/限加速度——一次工程同时改善执行质量（真机成功率）、§6 动作规律性（可信度）、电机寿命（ negligible 但顺便）。
- **三词交点 = "会喊疼的机器人"**：MOTOR-ECHO 出信号（物理）、INTER-DESIGN 保通道（交付）、ANOM-STACK 做裁决（监督）——裁决结果统一喂 IP-12 重抓 / IP-11 让位 / IP-14 仲裁，全部不依赖 F7/F8、全部近零训练成本，符合 COST-LADDER。

## 5. 风险与本轮最大风险

**最大风险：DERIV-NOISE——从位置堆叠差分出的动力学信号是噪声放大器。** 三个叠加因素：①obs 堆叠偏移非均匀（例 [-10,-5,-2,0]），差分间隔不等距；②评测链路（网络传输→评测器→电机插值）有未知的抖动与平滑；③30Hz 级采样下高频振荡与量化噪声混叠。若残差信号信噪比不足，误报触发重抓/让位会**直接掉分**（步骤分损失+成功率损失），且这类回归在 F8 解除前无法在真机端验证。缓解：①不做裸差分——Savitzky-Golay/学习型滤波 + 残差在 held-out 真演示回放（IP-3）上先行验收，信噪比不过阈不接入触发链；②conformal 校准天然吸收分布内噪声（承 R7f），但校准集必须含 IP-7 注入的接触异常；③残差只喂触发货币、不直接改动作（承第 28 轮"解释不自动改动作"原则）；④E19 验收：误报率 <8% 且提前量 ≥2 步才进触发链。

其余新增风险：⑤平滑整形与 VLA 反应速度的冲突——过度平滑抹掉对人为干扰的快速反应（缓解：只做边界混合+限幅，不做全程滤波；干扰场景消融）；⑥§6 条款可能主要作为诚信审查而非加分项，收益不可直接计入分数预期（按"防扣分+防取消资格"记账）；⑦ee 控制空间下动力学残差语义变化（joint 位置差分在 ee 模式下需经 FK，误差链变长——E19 分控制空间验收）；⑧免训练加速锚点 [R11d] 基于 GPT 类 backbone，向 WLA 架构迁移需验证。

## 0. 结论

第 28 轮清单 v4（15 项）本轮完成「深化 + 净增一项 + 两项扩名」迭代，产出 v5（16 项）：

## 3. 重点展开一：IP-16 MOTOR-ECHO（无刷电机，本轮押注）

### 3.1 设计——三个组件，零训练起步

1. **动力学特征层（特征，无训练）**：obs_delta_indices 本就必须声明堆叠（例 [-10,-5,-2,0]）[R3]——堆叠位置序列经 Savitzky-Golay 平滑后差分，得到每臂关节速度/加速度/jerk 估计 + 夹爪开度变化率。约束：差分间隔非均匀 → 用时间戳加权差分而非裸 diff（A9 验证信噪比）。
2. **接触异常残差（异常检测的硬源）**：三类残差各有独立签名——
   - **滑动** r_slip：指令夹爪闭合到位且指令 ee 上升，但物体（视觉）与 ee 相对位移持续 → "手在走物体没走"；
   - **卡死/堵转** r_stall：指令关节速度大而实测速度≈0 持续 k 步 → "指令在走机器人没走"（无刷电机堵转的典型表现 [R11b]）；
   - **振荡** r_osc：滤波后速度符号翻转率超基线（per-task 演示基线）→ 执行器与指令打架。
3. **chunk 整形器（交付侧副产品）**：对 get_action 返回的 chunk 做末端处理——①边界混合：新 chunk 首步与上一 chunk 尾步做 2-3 步线性/样条过渡（消除 F25 阶跃）；②限幅：按 G1 关节速度/加速度上界裁剪；③well-formed 校验：NaN/超程/维度检查（§6 "well-formed"要求 [R3]）。注意边界混合引入 ≤100ms 滞后，仅对非干扰时段启用（人为干扰场景保留反应速度，见 5 节风险⑤）。

### 3.2 伪代码

```python
class MotorEcho:
    def features(self, obs_hist):                     # obs_hist: 堆叠后 (K, 7) 关节位置
        q = savgol(obs_hist, window=5, dt=ts_weights) # 时间戳加权平滑
        return deriv(q)                                # -> {v, a, jerk} per joint
    def residuals(self, chunk_cmd, feat, vis):
        r_slip  = slip_sign(chunk_cmd.gripper_close, feat.ee_v, vis.rel_disp)
        r_stall = stall_sign(feat.cmd_v, feat.v, k=3)          # 指令-实测速度差
        r_osc   = osc_sign(feat.v, baseline_flip_rate)          # 符号翻转率
        return {"r_slip": r_slip, "r_stall": r_stall, "r_osc": r_osc}
    def shape(self, new_chunk, prev_chunk, mode):
        c = boundary_blend(prev_chunk, new_chunk, steps=2)     # F25 阶跃消除
        c = clip_dyn(c, joint_limits_g1)                       # 限幅
        return validate_wf(c)                                  # NaN/超程/维度
```

### 3.3 成本账与合规

- 算力：**≈0**（滤波/差分/整形为 CPU 级，<1ms；无新网络参数；A9 若证明学习型滤波必要，仍是 <0.5 GPU·天的小头）。
- 数据：0（演示序列即训练基线来源：per-task 的速度符号翻转率/残差分布基线从 32k 演示统计）。
- 边际分预期：自身不加分，经触发链兑现——重抓正确率↑（IP-12）、误让位↓（IP-11）、卡死类任务的步骤分保护（IP-8）；对接触密集任务（PlugCharger/PlugInEthernet/ZipUp/StackBowls 等）预估 +2~5pt。
- 合规：残差只喂触发货币、不直接改动作（承第 28 轮原则）；整形器改的只是指令的时序/幅度合规性，不改任务语义；全量遥测（IP-4）。

## 4. 重点展开二：IP-4 深化 INTER-DESIGN（交互设计）

### 4.1 §6 合规层四件套 [R3]

1. **延迟 SLO**：p50 ≤ 100ms、p99 ≤ 300ms（A10 实测后定标）；手段：模型 warm-up、量化/半精度、CUDA graph、chunk 失配时返回上一 chunk 外推（锚点 [R11d] 免训练加速、[R11e] masked chunk 执行）；N 端口共享后端时并发调度（每端口独立队列）+ 状态隔离（reset/历史 per-port，承 [R3] Approach 2 提示）。
2. **输出整形器**：与 IP-16 第三组件共用一份工程——well-formed 校验+离群裁剪，保证 §6 "returned results free of unnecessary anomalies"。
3. **干扰交互编排**（人为干扰场景的"交互设计"）：被推/挡/抽走物体时的分级响应——轻度遮挡→继续但降速（chunk 步间插值放缓）；物体被抽走→ANOM-STACK 预警触发→暂停+重定位（IP-1 重锚定）；人手进入工作区→IP-11 让位。响应动作本身也要过 SLO（响应延迟是交互质量的一部分）。
4. **交互遥测**：逐步延迟/动作统计量入 IP-4 遥测流，§6 自证材料（第 28 轮已立）扩容为"交互质量体检表"，E20 后随 48h 报告发布。

### 4.2 成本账

- 算力：0（工程项）；风险：共享后端并发的实现复杂度（[R3] 明示 concurrency+state isolation 两个坑）。
- 边际分预期：直接收益是"防扣分/防取消资格"（不可计入成功率先验，按风险账记账）；间接收益是延迟稳定→chunk 执行节奏稳定→步骤分（IP-8 合流）。

## 5. 重点展开三：IP-15 深化 ANOM-STACK（异常检测，上轮押注延续）

### 5.1 四源统一

| 源 | 类型 | 信号 | 成本 | 状态 |
|---|---|---|---|---|
| 动力学残差（IP-16） | **硬物理源**（新） | r_slip/r_stall/r_osc | ≈0 | A9 过阈后进 |
| WM 偏差 | 软源 | 自训结构化 WM 预测 vs 实际观测 | 2-4 GPU·天 | 承第 27/28 轮；新锚点：基础 WM 可检测双臂失败 [R12a] |
| 探针置信度 | 软源 | backbone 中间层→p_fail | <1 GPU·天 | 承第 28 轮 [R7g]，E17 验收后进 |
| 输出规律性自检 | **自检源**（新） | 输出 chunk 统计量（幅度分布/翻转率/边界跳变） | 0 | §6 镜像 [R3] |

四源各自输出非一致性分数 → ANOM-STACK 融合（校准加权的 logit 融合，参数 <10 个）→ conformal 阈值 q_hat（承 R7e/R7f）→ 唯一触发货币，消费方不变：IP-12 重抓 / IP-11 让位 / IP-14 仲裁 / IP-3 归因。

### 5.2 融合伪代码（增量）

```python
class AnomStack(CalibProbe):                       # 承第 28 轮 CalibProbe
    def watch(self, obs_t, obs_pred=None, motor=None, out_stats=None):
        s_geom   = self.wm_deviation(obs_t, obs_pred) if obs_pred else None
        s_probe  = self.probe(self.backbone_feat(obs_t))
        s_motor  = self.fuse_res(motor)            # {r_slip, r_stall, r_osc} -> 标量
        s_out    = self.out_regular(out_stats)     # 输出规律性（§6 镜像）
        s = self.combine(s_geom, s_probe, s_motor, s_out)   # 校准加权融合
        alarm = s > self.q_hat
        return alarm, {"src": argmax_src, "s": s}  # 触发原因可读（§6 自证）
```

### 5.3 边界

- 硬源（动力学残差）权重上限：单源触发不直接生效，双源一致性才触发（防 DERIV-NOISE 误报）；分场景校准（承第 28 轮漂移风险行）继续有效。
- 输出自检发现"模型抽风"时动作：不重置模型（成本高），回退策略=重复上一有效 chunk 或冻结 1 步 + 计数器（连续 3 次才升级为重定位）。
