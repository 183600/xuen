# 第 3 轮（灵感循环第 3 轮；本轮灵感：「Gazebo」×「自主导航」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**在前人基础上改进，而不是推倒重来**——ToolGauge 的四个核心件（L-Box / T-Box+TCV / AP-Cal / 8 段前身 6C）
> 原样保留；本轮只回答它回避的两个问题：**(i) 信息在不在当前位姿的物理可达范围内**（几何/可观测性），
> **(ii) 能不能在碰到真实世界之前先把方案否证掉**（影子世界预演）。
> 同时审计并修复 ToolGauge 的八处遗留缺陷（见 §5）。

## 二元映射（本轮两词，而非三词）

| 灵感词 | ToolGauge 对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| Gazebo | T-Box 的物理探测：只能在真机上试 | **G-Box + SD-Gate + SQM**：影子世界预演、保真账本、在线断路器 | 先在场外把方案逼近可证伪，再决定是否在现实里付出不可逆代价 |
| 自主导航 | D-Box 的静态盲区格子：只问「验没验过」 | **N-Box + PoseCov**：主动视点、计量代价地图、位姿感知的保守覆盖 | 有些盲区不是工具不行，而是**站错了地方**；能走过去的，就不该硬测 |
| （综合） | 6C 闭环：H→C→E→C→V→U | **8 段闭环**：H→C→S→N→E→C→V→U | 在「编译」与「执行」之间插入「影子预演」与「导航到位」，退化链变成可执行行为树 |

**核心命题**：把 ToolGauge 的「语义假设 → 契约工具 → 摊销校准 → 交叉验证热替换」升级为
「**盲区分类 → 影子预演（几何/风险/增益三问）→ 主动视点 → 契约执行 → 位姿感知验证 → 局部热替换**」。
两条硬边界：
- **Gazebo 只回答三个问题**：看得见吗（ω）、值不值（Ĝ）、危不危险（R̂）；**永不回答 `u_s` 是多少**。
- **仿真回执永不是证据**：影子回执只能用于「选择/排序/否决」，不能进入 AP-Cal 样本集，不能被语言主张引用。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；其中三条被**扩展**而非削弱：
  - 契约完整性 ⇒ 导航动作 `nav.goto` 也是工具（定义 436），同样受 TCV 与双层下注约束；
  - 反作用通道完备 ⇒ χ_R 扩展为 χ_R^nav = χ_R^probe ∪ χ_R^locomotion（定义 443）；
  - 主张绑定 ⇒ 证据带 provenance，`prov=sim` 的回执不可绑定（定义 433）；
- **严格退化链延长**：NavGauge 失效（影子世界不可用/保真超界/导航不安全/固有盲区）⇒ 退回 ToolGauge 原地修复 ⇒ 再退回 LeanGauge ⇒ 最后 MODGAUGE。导航与仿真都是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（自主导航 → 盲区首先是一个「可达性/可观测性」问题）**
直觉：ToolGauge 把每个盲区都当成「校准不够」或「工具不够」，于是不断在原位加探测。但镜面后的区域、被遮挡的背面、
超出景深的表面，其信息在当前位姿下**根本不在物理信道里**——再加先验、再加采样，也只是把「不知道」包装成「有分布的不知道」。
自主导航的启示是：**先决定站在哪里**。把盲区分成三类：**视点盲区 V**（换个位姿就能看见）、
**工具盲区 T**（换位姿也看不见，但敲击/热激励/多模态互检能间接暴露）、**固有盲区 I**（所有位姿与工具都低于增益门槛）。
V 类交给导航，T 类交给 ToolGauge，I 类**证书化地承认看不见**并 abstain。这直接终结「预算赌博式探测」。
更进一步，导航不是外挂：`nav.goto` 被包装成带前置、回执、代价与最坏时延的计量工具，因而「移动」也进入契约与风险账本。

**灵感 2（Gazebo → 影子世界：几何沙盘，而非真值神谕）**
直觉：ToolGauge 的验证全部发生在真机上，一个错误的探测程序，其代价是不可逆的（反作用通道 χ_R）。
Gazebo 的价值不在于「仿真出更准的数值」，而在于**在零副作用的前提下回答几何与风险问题**：
从位姿 x 能否看见格子 s（射线/BRDF/遮挡/景深）、这次移动与敲击会不会碰到东西、预计信息增益够不够。
我们把 Gazebo 降格为一个**只会三问的顾问**（ω / Ĝ / R̂），并把它的偏差当作一等公民：
保真账本记录每个传感器×材质×光照的 sim-real 差距 η，所有基于影子的决策都用**下置信界**。
影子回执带 `prov=sim`，类型上永远不能进入数值通道。这样既获得预演收益，又避免「仿真成为新的独断权威」。

**灵感 3（两者相乘 → 8 段闭环与可执行的退化链）**
直觉：导航让盲区变得可修复，仿真让修复变得可预演；但两者一旦组合，系统就多了一个**慢时间尺度**（导航/建图）
和一个**共享的失败源**（同一台 Gazebo 既决定去哪、又决定用什么先验）。因此需要：
(a) 把 6C 扩成 8 段（插入 S 影子预演与 N 导航）；
(b) 用**计量代价地图 MCost** 把「信息增益 / 反作用风险 / 可通行性 / 仿真差距 / 契约影响」放在同一张图上规划；
(c) 用**地图纪元**切断「测量改了地图 → 地图又改测量」的反馈回路；
(d) 用 **BT-Contract** 把退化链写成可执行的行为树，而不是论文里的一句声明（Nav2 的 recovery 子树正好是现成载体）。
**计量不是把仪器对准物体，而是决定站在哪里、用什么工具、以及何时承认看不见。**

## 1. 形式化定义（增量：定义 432–448）

**定义 432（影子世界与保真账本）** 影子世界 `TW = (W_sim, ρ_sens, F, ver)`：
- `W_sim`：SDF 描述的几何、材质（BRDF）、光照、可动物体与接触/摩擦参数；
- `ρ_sens`：各传感器插件（RGB-D / IR / 热像 / 触觉 / 声学）的噪声、量程、时延模型；
- `F`：保真账本，对每个通道 ch、材质 m、光照档 i 维护 sim-real 统计差距的置信区间 `[η⁻, η⁺]`；
- `ver`：世界版本号（与地图纪元绑定，过期即失效）。
**三问原则**：`query(s,x) ↦ (ω̂, Ĝ, R̂, siĝ)`，只给可见性权重、信息增益、反作用风险、预测观测指纹；**不返回 `u_s`**。

**定义 433（影子回执与证据资格）** 影子执行产出 `r̂ = (t,args,obs_sim,sig_sim,ts,seq, prov=sim)`。
回执带来源 `prov ∈ {real, sim}`；`Evidence(r) ⇔ valid(r) ∧ r.prov = real`。
**仿真回执可用于排序、否决与风险评估，但永不进入 AP-Cal 样本集、永不进入 `claims`、永不被 CoverageCert 引用。**
这是第 2 轮「无效回执永不入样本集」的**来源级扩展**，把「假观测」与「真但来自影子世界的观测」区分开。

**定义 434（仿真-现实可观测差距 SRO）** 对每个受影子影响的统计量 φ ∈ {ω, G, R}，定义
`η_φ = sup_{cell,pose} |φ̂_sim − φ_real|`，并由预注册的**独立审计集** `C_SR` 给出高置信上界。
关键纪律：`C_SR` 的抽样策略必须**与 TW 的预测无关**（分层随机真实探测），否则「用仿真挑样本、再用样本校准仿真」
会产生**校准乱伦**（selection-biased fidelity），使 η 被系统性低估。审计集独立性是引理 51 的前提条件。

**定义 435（影子闸门 SD-Gate）** 程序 Π 只有在同时满足以下六条时才允许离开影子世界：
1. `TCV(Π)` 通过（契约层永不绕过）；
2. 对每个目标 s：`Ĝ_sim(s) − L·η_I ≥ γ_B`（**下置信界**增益注）；
3. `R̂_sim(s) + η_R ≤ ρ_max`（**风险上界**）；
4. 视点相关步骤 `ω̂(s,x) ≥ ω_min`，否则该格不得按 V 类处理；
5. **反仿真套利**：预测观测指纹落在预注册指纹库的 η_φ 邻域内，且参数/工具不越出物理包络；
6. 影子世界 `ver` 与当前地图纪元一致且未过期；影子预算 `Σc_sim ≤ B_sim`。
任一条不满足 ⇒ 不执行；若失败原因是「影子不可用/过期/保真超界」⇒ **不阻塞**，直接委派 ToolGauge 原地路径（退化）；若原因是「增益不足/风险超界/套利」⇒ 重规划或 abstain。

**定义 436（可移动计量平台与导航工具）** 平台位姿 `x ∈ 𝒳 ⊆ SE(3)`；`nav.goto(x, path, envelope)` 是预注册工具：
- Schema：目标位姿、速度/加速度包络、路径版本；
- Pre：路径可通行（当前地图纪元）、定位置信度 `tr(Σ_x) ≤ σ²_max`、人机间距合规；
- Post：回执含位姿估计 `x̂`、协方差 `Σ_x`、时间戳、真实来源签名；
- `c_nav`（时间+能耗+磨损）、`τ_nav`（最坏时延）、`Ĝ_nav`（目标位姿处可见格子的增益和）。
**移动因此是契约行为**：受 TCV、风险门 λ、增益注 β、TB-Contract 的共同约束，而不是绕过它们的隐式副作用。

**定义 437（可见性权重、视点增益与盲区三分）** 对格子 s 与位姿 x 定义可见性权重 `ω(s,x) ∈ [0,1]`
（由遮挡/入射角/景深/分辨率决定；`ω=0` 表示该位姿完全不可观测）。有效观测方差 `σ_obs²(s,x) = σ_0²/ω(s,x)`。
在线性高斯近似下，视点信息增益有闭式
`G(s,x) = ½·log(1 + ω(s,x)·σ_prior²(s)/σ_obs²)`（与第 2 轮 Ĝ_t 公式同构）。
盲区三分：
- **V 类（视点盲区）**：`∃x: ω(s,x) ≥ ω_min` ⇒ 交给 N-Box 导航；
- **T 类（工具盲区）**：`sup_x ω(s,x) < ω_min`，但存在工具 t 通过扰动/间接通道使增益 ≥ γ_B ⇒ 交给 ToolGauge；
- **I 类（固有盲区）**：`∀x,t: G < γ_B` ⇒ 颁发 `UNKNOWN_CERTIFIED`，abstain，**永不消耗探测预算**。
估计不确定时标为 **A 类（含糊）**：若 LCB/UCB 跨过门槛，则采取保守动作（原地探测或 abstain），不得导航冒险。

**定义 438（计量代价地图 MCost）** 在 `𝒳 × R` 上的分层地图：
- `U`：契约后验不确定度层（每格 u_s 的熵/方差，来自 AP-Cal 与 R）；
- `Φ`：反作用风险层（χ_R^nav，含探测与移动，定义 443）；
- `T`：可通行层（SLAM/Nav2 地图，带膨胀半径）；
- `η`：保真膨胀层（按 η_ω, η_R 膨胀风险与不确定度）；
- `E`：契约影响层（哪些 EC 边/数值通道依赖该格，来自 claims/依赖图）。
`MCost(x) = (U, Φ, T, η, E)`；导航规划只在 `MCost` 上做，禁止使用未膨胀的裸风险。

**定义 439（视点-风险-代价目标与 LCB-NBV）** 对路径 `π = (x_0,…,x_H)`：
`J(π) = E[ Σ_{t=0..H} ζ^t ( Î_lcb(s_t;x_t) − λ_c·c(x_t,x_{t−1}) − λ_R·Φ(x_t) ) ]`，
硬约束 `Φ(x_t) ≤ ρ_max`、`P(collision) ≤ δ`、`Σc ≤ B_nav`；其中 `Î_lcb = Ĝ_sim − η_I`。
Next-Best-View：`x* = argmax_{x∈BF} [ Î_lcb(x) − λ_c·c − λ_R·Φ(x) ]`，仅当 `x*` 的边际收益（扣代价）≥ γ_B 才移动。
风险约束不可行 ⇒ 不移动，退回 ToolGauge 原地路径或 abstain；绝不「先走过去再说」。

**定义 440（盲区前沿 BF 与主动覆盖）** `BF = { s ∈ R \ V : ∃s' ∈ V 与 s 邻接, reachable(s), impact(s) > 0 }`，
其中 `impact(s)` 由 E 层给出（依赖该格的契约边数 × 后验方差）。前沿按 `impact × uncertainty` 排序。
与 SLAM 的 free-space frontier 不同，BF 是**契约前沿**：不服务「把地图填满」，只服务「把有数值后果的未知变已知」。
无契约影响的格子即使未验证，也不进入 BF。

**定义 441（位姿不确定下的保守覆盖）** 测量在相信位姿 `x̂`、协方差 `Σ_x` 下获得；格子 s 距平台 d，半宽 w，角/距标准差 `σ_θ, σ_r`。
横向不确定度 `σ_lat²(s) ≈ d²σ_θ² + σ_r² + ext(s)²`。定义关联概率 `a(s; x̂, Σ_x)`。
**保守覆盖判据**：只有 `a(s; x̂, Σ_x) ≥ 1−β` 才可把 s 计入已覆盖；对应的等效膨胀半径
`r(s) = z_{1−β/2}·σ_lat(s) + margin`。因此「去过某个坐标」不等于「覆盖了某个格子」：
距离越远、定位越差，有效覆盖集越小。**负证据（没看到）比正证据更危险**，必须用同一膨胀半径做漏检控制。

**定义 442（地图纪元与覆盖证书）** 地图/位姿图每次因回环、重定位或因热替换改变感知模型而更新，纪元 `e → e+1`。
覆盖证书 `CoverageCert(s) = (receipts, {x̂,Σ_x}, map_ver, e, a(s), β)`。
证书只在其纪元内有效；跨纪元用变换 `T_{e→e'}` 传播，若传播后的不确定度越过 β 门槛则该证书 **stale**，必须局部重验。
纪元纪律保证：一次测量不能在「测量时的地图」与「修复后的地图」之间被悄悄重新解释。

**定义 443（运动反作用通道 χ_R^nav）** 移动平台引入新的反作用：气流、振动、地面足迹压力、遮挡/光照变化、声学噪声、
甚至物体位移。定义 `χ_R^nav = χ_R^probe ∪ χ_R^locomotion`。**反作用通道完备不变式**现在要求 Φ 覆盖两类通道；
移动后到探测前设**静定窗口** `τ_settle`（振动/气流衰减），窗口内不得采信测量。这修复了 ToolGauge「只把探测当副作用」的盲点。

**定义 444（导航安全包络与 PROBING-MOVE）** 移动与探测期间进入显式 `PROBING-MOVE` 状态：
速度/加速度/力矩硬限、人机最小间距、急停可达、全日志、禁止边移动边采信（除非运动模糊模型已标定）。
安全包络 `S_env` 是 Pre 的硬谓词；违反即 void，零副作用收尾（继承定义 430 的公开声明精神）。

**定义 445（行为树契约 BT-Contract）** `BT = (N, E, C, ρ)`：节点含 Sequence/Fallback/Condition/Action/Recovery；
每个节点带 `(pre, post, cost, retry_bound, timeout)`。三条硬不变式：
(i) 每个 Action 叶子必须是 TCV 工具（含 `nav.goto` 与计量工具）；
(ii) 每个 Failure 出边必须有且仅有一个已注册 fallback；
(iii) 所有循环有界（retry_bound 由 TB-Contract 给出）。
Recovery 子树与定义 448 的退化链逐级对应——**退化链从文字声明变成可执行、可测试的行为树**。

**定义 446（影子-现实监控 SQM）** 在预注册的安全格上周期性做**配对审计**（同程序，sim 与 real 各跑一次），
残差 `z = (real − sim)/σ`；用 CUSUM 监控均值漂移，阈值 h、参考漂移 ν。**分材质×光照分层**监控，
以捕捉「全局平均正常、某一材质类整体偏移」的结构化偏差。触发 ⇒ 冻结 G-Box、膨胀 η、禁用影子导航、
退回 ToolGauge、排队重校准。审计调度必须与影子预测独立（定义 434 的独立性）。

**定义 447（NavGauge 8 段闭环）** `H → C → S → N → E → C → V → U`：
1. **H**：D-Box 发现盲区 s；L-Box 给共形假设集 `H_s`（继承定义 398/422）；
2. **C（编译+分类）**：VLA 编程器编译候选程序；按定义 437 分类 V/T/I/A；
3. **S（影子）**：G-Box 三问 + SD-Gate 六条；不可用则委派 ToolGauge；
4. **N（导航）**：V 类由 N-Box 选视点并 `nav.goto`；失败/不划算 ⇒ 就地 ToolGauge；
5. **E（执行）**：TCV 逐条校验 + 双层闸门 + 回执来源校验（仅 real 入证据）；
6. **C（校准）**：AP-Cal 摊销后验（仅 real 回执为上下文）；
7. **V（验证）**：独立 cross.modal 回执交叉验证 + **位姿感知覆盖证书** + 契约回归；
8. **U（更新）**：局部热替换 + NavRepairCert + 地图纪元推进 + SQM 记账。
I 类在任何阶段被识别即 `certify_unknown(s)` 并退出；V 失败重试一次再失败 ⇒ stub + RED（继承定义 421）。

**定义 448（退化链与编号约定）** 未被重定义的第 2 轮记号（T₀、TCV、MP-Φ、AP-Cal、P-Quarantine、TB-Contract、EC、M_ver、MReg 等）
沿用定义 416–431。退化链：
`NavGauge --(TW不可用/过期/保真超界/SQM触发/导航不安全/无V类)--> ToolGauge --(VLA不可用/假设全剔/预算耗尽)--> LeanGauge --(数值探测失效)--> MODGAUGE`。

## 3. 推导

**引理 51（影子闸门的保守收益、风险上界与选择偏差）**
设保真账本给出 `|Ĝ_sim − G_real| ≤ η_I`、`|R̂_sim − R_real| ≤ η_R`，各以概率 ≥ 1−δ_s 成立（独立审计集）。
(a) 通过 SD-Gate 的程序满足 `Ĝ_sim − L·η_I ≥ γ_B` 与 `R̂_sim + η_R ≤ ρ_max`，
故以概率 ≥ 1−Lδ_s 有 `G_real ≥ γ_B` 且 `R_real ≤ ρ_max`——**影子只放大把握，不创造把握**。
(b) `prov=sim` 回执被排除后，AP-Cal 的数值后验只依赖真实回执；但**选择偏差不因此消失**：
若「跑哪些真实探测」由影子预测决定，则真实回执分布相对部署分布发生协变量偏移。
设选择倾向 `π_sel(r|x)`，则后验需加重要性权重或注入偏移项 `η_sel = TV(p_real^{selected}, p_real^{audit})`；
`η_sel ≤ η̄_sel` 由独立审计集实测。系：**没有独立审计集的影子闸门，其保证不成立**。
(c) 若影子套利（只优化仿真增益）且第 5 条不启用，则存在世界 `W'` 使 `Ĝ_sim` 任意大而 `G_real = 0`；
反套利指纹把该攻击面压回「指纹库覆盖范围」内，但**不能证明**覆盖完全。

**引理 52（位姿不确定下的覆盖收缩与膨胀半径）**
对每格 s 的横向误差近似高斯，标准差 `σ_lat(s)`。若用 `r(s) = z_{1−β/2}σ_lat(s) + margin` 做膨胀，
并以 `β/|R|` 做逐格门槛，则由 union bound，**所有**被声明覆盖的格子确实落在真实测量footprint内的概率 ≥ 1−β。
推论：有效覆盖集随距离 d 按 `d·σ_θ` 收缩；当 `d` 增大到 `z·d·σ_θ > w` 时，必须靠近或重新观测——
这给出「导航—覆盖」的定量耦合。**负证据**同样适用：漏检概率 ≤ β_neg + P(|pose error| > r)，
因此不能用一次远距离「没看到」来声明格子安全。

**引理 53（LCB-NBV 的近似保证与风险约束间隙）**
(a) 由保真账本的置信上界，`∀x: G_real(x) ≥ Î_lcb(x)` 以概率 ≥ 1−δ 成立。
(b) 条件独立高斯观测下，互信息 `I(u; r_A)` 对集合 A 单调自适应次模；在**基数约束** |A|≤k 下，
贪心 LCB-NBV 达到 `(1−1/e)·OPT − k·η_I` 的近似。
(c) 加入路径代价与**硬风险约束**后，问题一般不再次模；我们解其 Lagrangian 松弛并报告对偶间隙，
硬约束由 BT-Contract 的 fallback 强制满足。因此**我们只声称可行性保证与经验近似，不声称受限情形的最优性**。

**引理 54（地图纪元的局部失效与覆盖证书传播）**
设一次回环/热替换在位姿图上的影响半径为 ρ_e，则只有与受影响边相交的 O(|N_{ρ_e}|) 个格子证书需要重验，
其余证书在同一纪元内保持有效（继承引理 44 的局部性）。跨纪元用 `Σ_x' = Σ_x + J_T Σ_T J_Tᵀ` 传播；
若传播后 `a(s) < 1−β` 则 stale。系：**测量不能悄悄改写自己脚下的地图**——纪元把这种自指切断为显式失效。

**引理 55（SQM 的检测延迟与污染修复比例）**
CUSUM 在 H0（η ≤ η₀）下虚警率 ≤ α_sqm；在 H1（η ≥ η₀+Δ）下期望检测延迟 `D ≲ (h + ν)/(Δ²/σ_z²)`。
若修复事件到达率为 λ_rep，则**在检测到结构化偏差前被污染的修复比例期望 ≤ λ_rep·D**，并按材质×光照分层加 union bound。
系：SQM 能把第 2 轮「跨盲区相关污染」从不可见变为**有延迟上界的可检测事件**；
但若审计集本身由影子挑选，则 H1 可能落在审计分布之外——这是不可由 SQM 自证消除的残余风险（见 §6）。

**引理 56（时序、预算与退化保持）**
S/N 全部位于 50Hz 计量路径之外（事件驱动、异步、每格至多一次在飞）；50Hz 周期只增加
O(1) 的来源/纪元缓存查询（< 0.2ms）。导航规划 ≤ 2Hz，影子回滚按 LOD 并行/缓存；
若 `τ_sim` 或 `τ_nav` 超出 TB-Contract，SD-Gate 返回 Delegate、N-Box 返回 None，直接退化。
故硬实时（引理 45）、预算不变式（定义 424）与组合单调性保持。新增预算 `B_nav, B_sim` 并入 TB-Contract。

## 6. 本轮最大风险（一句话）

**一句话**：Gazebo 与真实世界之间的偏差是**结构化且跨格相关的**，而同一台影子世界既决定「去哪看/看什么」又决定「先验怎么校准」，
一旦该偏差落在独立审计集覆盖不到的材质/光照角落，NavGauge 会把所有被导航过的盲区**一起**推向同一个错误方向，
且影子预演产出的「物理可信」证书比 VLA 幻觉更难被人类质疑。

**次级风险与缓解**：
1. **校准乱伦（selection-biased fidelity）** → 审计集必须分层随机、与影子预测独立；报告 η_sel（引理 51b）；
2. **结构化 sim 偏差** → 分材质×光照的 SQM + 真实独立抽样重验 + 仿真出处账本；
3. **定位漂移导致覆盖虚高** → 定义 441 保守覆盖 + 地图纪元 + 远距离强制靠近；
4. **导航本身扰动场景** → χ_R^nav + 静定窗口 + PROBING-MOVE 安全包络；
5. **安全—收益冲突下的冒险移动** → 硬风险约束 + BT fallback；不可行就原地/abstain；
6. **慢环拖垮硬实时** → 全异步 + LOD + 超时即委派 ToolGauge；
7. **固有盲区被误判为 V/T 类而烧预算** → I 类证书化 + A 类保守处理 + 预算硬顶；
8. **地图纪元频繁失效导致修复抖动** → 纪元合并/滞后推进 + 局部重验，避免全局重算。

## 2. 形式化定义（要点）

**定义 432/433（影子世界 + 证据资格）** `TW.query(s,x) ↦ (ω̂,Ĝ,R̂,siĝ)`；只三问，不返回 `u_s`。
影子回执 `r̂=(…,prov=sim)` 可用于排序/否决/风险评估，但**永不进入 AP-Cal 样本集、claims、CoverageCert**。
**定义 434（SRO）** `η_φ = sup |φ̂_sim−φ_real|`；审计集 `C_SR` 必须与 TW 预测独立（分层随机真实探测），否则 η 被低估（校准乱伦）。
**定义 435（SD-Gate）** 六条：TCV；`Ĝ_sim−L·η_I ≥ γ_B`；`R̂_sim+η_R ≤ ρ_max`；`ω̂ ≥ ω_min`；反套利指纹；世界版本新鲜。
不可用/过期/保真超界 ⇒ **委派** ToolGauge；增益/风险/套利失败 ⇒ 重规划或 abstain。
**定义 436（导航即工具）** `nav.goto` 有前置（可通行/定位置信/人机间距）、后置（`x̂,Σ_x,ts,sig`）、代价与最坏时延；受 TCV + λ/β 双门约束。
**定义 437（三分）** V: `∃x, ω≥ω_min`；T: `sup_x ω<ω_min` 但存在扰动工具使增益 ≥ γ_B；I: `∀x,t, G<γ_B` ⇒ `UNKNOWN_CERTIFIED` 并 abstain；A: LCB/UCB 跨门槛 ⇒ 保守动作。
**定义 438–440（MCost / NBV / 前沿）** 五层代价图；`J(π)=E[Σ ζ^t(Î_lcb−λ_c c−λ_R Φ)]`，硬约束 `Φ≤ρ_max, P(collision)≤δ`；`BF` 只看有契约影响的未验证邻接格。
**定义 441（保守覆盖）** `σ_lat²≈d²σ_θ²+σ_r²+ext²`；`r(s)=z_{1−β/2}σ_lat+margin`；只有 `a≥1−β` 才算覆盖；负证据同标准。
**定义 442（地图纪元）** 回环/重定位/感知模型热替换 ⇒ `e+1`；证书只在纪内有效；跨纪传播不确定度超门槛即 stale，局部重验。
**定义 443（χ_R^nav）** 移动引入气流/振动/足迹/遮挡/声学/位移；反作用完备不变式扩展到移动；移动后有静定窗口 `τ_settle`。
**定义 444（PROBING-MOVE）** 速度/加速度/力矩硬限、人机间距、急停可达、全日志、禁止边动边采信。
**定义 445（BT-Contract）** 每个 Action 叶子是 TCV 工具；每个 Failure 边恰有一个 fallback；所有循环有界。
**定义 446（SQM）** 安全格上配对审计，残差 CUSUM；按材质×光照分层；触发即冻结 G-Box 并退回 ToolGauge。
**定义 447/448（8 段闭环 / 退化）** H→C→S→N→E→C→V→U；I 类证书化退出；V 失败一次重试再失败 stub+RED；`𝒳={x₀},TW=∅` 时退化为 ToolGauge。

class ShadowWorld:
    def query(self, s, x, prog):
        w    = self.raycast_visibility(s, x)              # 遮挡/BRDF/景深
        gain = 0.5*log1p(w*prior_var[s]/obs_var)          # 与定义 437 同构

        sig  = self.predicted_signature(prog, s)          # 反套利
        return ShadowEst(w, gain, risk, sig, self.ver)
    def certified_for(self, e): return self.ledger.in_interval(e)

# IP-322 SD-Gate：六条；拒绝 vs 委派
class SDGate:
    def check(self, prog, H, cells, epoch):
        if not self.tcv.verify(prog, self.budget)[0]: return Reject("tcv")
        if not self.tw.fresh(epoch):                  return Delegate("stale")
        for s in cells:
            e = self.tw.query(s, prog.pose, prog)
            if not self.tw.certified_for(e):          return Delegate("fidelity")
            if e.gain - L*eta_I < self.gamma_B:       return Reject("gain_lcb")
            if e.risk + eta_R > self.rho_max:         return Reject("risk_ub")
            if e.w < self.w_min:                      return Reclassify("not_v")
            if not fingerprint_match(e.sig):          return Reject("sim_exploit")
        return Pass()

# IP-323 N-Box：契约前沿 + MCost + LCB-NBV
class NBox:
    def plan(self, R, V, epoch, pose):
        frontier = contract_frontier(R, V)                 # impact>0 的邻接未验证格
        best = None
        for x in candidate_poses(frontier, self.mcost(epoch)):
            if self.mcost.risk(x) > self.rho_max: continue
            if self.mcost.collision(x) > self.delta: continue
            g = sum(self.info_lcb(s, x) for s in visible(frontier, x))
            score = g - self.lc*self.cost(pose, x) - self.lr*self.mcost.risk(x)
            if score >= self.gamma_B and (best is None or score > best.score):
                best = Candidate(x, score)
        return best      # None => 不移动，退回 ToolGauge / abstain

# IP-324 PoseCov：位姿感知覆盖 + 地图纪元
class PoseCov:
    def association(self, s, x_hat, Sigma_x):
        s_lat2 = x_hat.d**2*Sigma_x.theta + Sigma_x.rng + s.extent2
        r = z(1 - self.beta/2)*sqrt(s_lat2) + s.margin
        return self._prob_offset_within(s, x_hat, r)
    def certificate(self, s, receipts, epoch):
        cc = CoverageCert(receipts, [r.pose for r in receipts], epoch,
                          a=self.association(s, *self.pose_belief(s)))
        return cc if cc.a >= 1 - self.beta else None
    def on_epoch_change(self, e_new):
        for cc in self.store:
            if not self.transport_ok(cc, e_new): self.invalidate(cc)

def navgauge_8(M, s):

    kind, prog = M.classify_and_compile(H, s)                   # C（V/T/I/A）

## 4. 推导

**引理 51（影子闸门：保守收益 + 风险上界 + 选择偏差）**
(a) 若 `|Ĝ_sim−G_real|≤η_I`、`|R̂_sim−R_real|≤η_R`（独立审计集，概率 ≥1−δ_s），则通过 SD-Gate 的程序满足
`G_real ≥ γ_B`、`R_real ≤ ρ_max`，概率 ≥ 1−Lδ_s。影子只放大把握，不创造把握。
(b) 排除 `prov=sim` 只消除「假观测污染」，**不消除选择偏差**：若真实探测由影子挑选，则真实回执分布发生协变量偏移，
需重要性加权或注入 `η_sel = TV(p_selected, p_audit)`；无独立审计集的保证不成立。
(c) 反套利指纹把「仿真里增益无限、现实里零信息」的攻击面压回指纹库覆盖范围，但**不能证明**覆盖完全。

**引理 52（位姿不确定下的覆盖收缩）** `σ_lat²≈d²σ_θ²+σ_r²+ext²`；用 `r(s)=z_{1−β/2}σ_lat+margin` 膨胀并以 `β/|R|` 逐格控制，
则所有被声明覆盖的格子确实落在真实 footprint 内的概率 ≥ 1−β（union bound）。
有效覆盖集随 d 收缩；`z·d·σ_θ > w` 时必须靠近或重测。负证据同标准，不能用一次远距离「没看到」声明安全。

**引理 53（LCB-NBV：近似与间隙）** (a) 保真上界给出 `∀x, G_real(x)≥Î_lcb(x)`（概率 ≥1−δ）。
(b) 条件独立高斯观测下互信息对集合单调自适应次模；**基数约束**下贪心达到 `(1−1/e)OPT−kη_I`。
(c) 路径代价 + 硬风险约束下一般不再次模；解 Lagrangian 松弛并报告对偶间隙，**只声称可行性与经验近似，不声称最优性**。

**引理 54（地图纪元局部失效）** 一次回环/热替换在位姿图上的影响半径为 ρ_e ⇒ 只需重验 O(|N_{ρ_e}|) 个格；
跨纪传播 `Σ_x' = Σ_x + J_TΣ_TJ_Tᵀ`，传播后 `a<1−β` 即 stale。测量不能悄悄改写自己脚下的地图。

**引理 55（SQM 检测延迟与污染比例）** H0 下虚警 ≤ α_sqm；H1（η≥η₀+Δ）下期望检测延迟 `D ≲ (h+ν)/(Δ²/σ_z²)`；
污染修复比例期望 ≤ `λ_rep·D`，分层加 union bound。SQM 把跨盲区相关污染变成「有延迟上界的可检测事件」；
若审计集本身被影子挑选，H1 可能落在审计分布外——这是 SQM 不能自证消除的残余风险。

**引理 56（时序、预算与退化保持）** S/N 全异步于 50Hz 外；周期只增 O(1) 来源/纪元缓存查询（<0.2ms）。
导航 ≤2Hz、影子按 LOD 并行/缓存；超时即 SD-Gate Delegate / N-Box None，直接退化。
硬实时（引理 45）、预算（TB-Contract，新增 B_nav/B_sim）与组合单调性保持。

### 解析 sanity check（非实测，用于量级校准）

- **覆盖收缩**：`d=2 m, σ_θ=0.5°=8.7e-3 rad, σ_r=5 mm, w=2 cm, β=0.05 (z≈1.96)`：
  `σ_lat≈√((2·8.7e-3)²+5e-3²)≈1.84e-2 m`，`r≈3.6 cm > w` ⇒ 该距离下「看到」不足以声明 2 cm 格子被覆盖，必须靠近到约 1.1 m 或把角精度提到约 0.3°。
- **视点增益门槛**：`σ_prior/σ_obs=3, γ_B=0.5 nats`：`ω=0.5 ⇒ G≈0.85 nats`（值得去），`ω=0.05 ⇒ G≈0.19 nats`（不划算，归 I/A 类）。
  ⇒ V/T/I 分类不是定性口号，而是由同一闭式门槛切出来的。

## 8. 本轮最大风险

**一句话**：Gazebo 与真实世界之间的偏差是**结构化且跨格相关的**，而同一台影子世界既决定「去哪看/看什么」又决定「先验怎么校准」，
一旦该偏差落在独立审计集覆盖不到的材质/光照角落，NavGauge 会把所有被导航过的盲区**一起**推向同一个错误方向，
且影子预演产出的「物理可信」证书比 VLA 幻觉更难被人类质疑。

**缓解（按优先级）**：
1. **独立审计集**（分层随机真实探测，禁止影子挑选）→ 报告 `η_sel`（引理 51b）；
2. **分层 SQM**（材质×光照 CUSUM）+ 触发即冻结 G-Box、退回 ToolGauge；
3. **证据来源防火墙**（`prov=sim` 永不入校准/主张/覆盖证书）；
4. **位姿感知保守覆盖 + 地图纪元**，防止「去过=覆盖」与「测量改写地图」；
5. **硬风险约束 + BT fallback**，不可行即原地/abstain，绝不冒险移动；
6. **仿真出处账本**（world ver + 参数哈希）使每次决策可追溯、可复现、可审计。
