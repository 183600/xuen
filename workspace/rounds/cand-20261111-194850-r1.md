# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环新一轮；本轮灵感：「伦理审查」×「评测指标」）

> 第 54 轮把技能组合从“能力匹配”推进到“动作-鲁棒性双证书”（ACS/SCOM/CEC/AEC/JTC）。本轮追问一个此前被回避的问题：**证书只能回答“能不能部署”，却没有回答“该不该部署、对谁可接受、指标本身可不可信”**。核心矛盾：H22：缺乏伦理约束的联合证书在形式上 sound，却可能在伦理上空洞——它证明系统会按规格执行，却不证明规格值得执行；H23：评测指标一旦成为优化目标就会失真（Goodhart），而当前所有实验指标都默认“测量即事实”，没有构念效度与抗博弈的保证。

## 0. 直觉与动机

**灵感 1（伦理不是事后盖章，而是动作空间的前置切除）**
直觉：伦理审查真正可落地的产物，不是一份审查报告，而是一个**禁止动作集 `A_forbid`** 与一个**永远可达的停止动作 `a_halt`**。把伦理投影 `π_eth` 插到第 54 轮 ACS 之前：任何技能的动作剖面先被切除禁区，`α^adm_S(a) = α_S(a)·1[a∉A_forbid]`。这样伦理不再是与技术平行的合规流程，而是**动作空间的第一性边界**——组合图 `G_S` 只在 `A_adm = A \ A_forbid` 上建立，越界组合在搜索阶段就不存在。

**灵感 2（伦理审查是带延迟与不确定性的门，不是布尔值）**
直觉：现实中伦理审查有成本、有延迟、有误判，还有时效。把它形式化为三级漏斗 `ER_0`（自动硬规则）→ `ER_1`（人类复核灰区）→ `ER_2`（伦理委员会高风险）。关键设计是 **fail-closed**：审查超时或证据不足一律 `deny`，而不是默认放行；每张伦理证书带 TTL 与**撤销句柄**，部署后仍可被撤回。这把“审查”从一次性关卡变成**带生命周期契约的在线门**。

**灵感 3（评测指标是带测量证书的构念向量，不是标量）**
直觉：`P_success ≥ 1-ε` 不是事实，而是一个**构念（construct）**：它依赖“成功”如何被操作化、在哪个分布上测量、样本量多大。故本轮要求每个指标 `m_i` 附带**测量证书** `M_cert_i = (C_i, O_i, e_i, u_i)`：`C_i` 构念定义、`O_i` 操作化协议、`e_i` 证据、`u_i` 校准后的不确定度。指标“可采纳”当且仅当操作化可复现、不确定度经过有限样本校准（用 conformal prediction 给出覆盖保证）。**没有测量证书的指标不得进入部署判据。**

**灵感 4（指标抗博弈：把 Goodhart 从口号变成可度量）**
直觉：指标失真不是抽象的，它可以被红队策略直接构造。定义**博弈缺口** `G_m = sup_{ρ: U(ρ) ≤ U(π*)−δ} [m(ρ) − m(π*)]`，即在不损害真实效用超过 `δ` 的前提下，红队能在指标 `m` 上“刷”出多少虚高。若 `G_m > γ_g`，该指标不可单独用于门控。配套提出**最小可证伪指标集**：一组指标，其联合不能在不改变真实目标的情况下被同时最大化——这等价于给评测做“反 Goodhart 设计”。

**灵感 5（可撤销性是拓扑不变量）**
直觉：“人类可随时接管/停止”不能是运行时的补丁，而必须是**组合证书的硬约束**：任何被判可部署的组合 `P_e`，其核心动作集必须包含停止动作，且在 `τ_stop` 内可达：
```
∀ 可部署 P_e:  a_halt ∈ A_core(P_e)  ∧  reach_time(a_halt | P_e) ≤ τ_stop
```
这把可撤销性从“策略层承诺”提升为**动作空间里的不变量**：撤销不是“再规划一次”，而是始终存在一条已在证书中声明、被证明可达的边。

**灵感 6（伦理-指标双证书与金字塔扩展）**
直觉：在第 54 轮 `𝔸`（动作协同层）之上叠加 **伦理层 `𝔼`** 与 **指标层 `𝕄`**：`𝔼_0` 法律/规范禁区，`𝔼_1` 技能伦理可容许剖面，`𝔼_2` 审查漏斗与生命周期，`𝔼_3` 撤销与接管；`𝕄_0` 构念定义，`𝕄_1` 操作化与测量，`𝕄_2` 抗博弈审计，`𝕄_3` 部署判据。跨层传递的联合证书升级为 `J+=(J, E_cert, M_cert, revoke)`，形成**可解释-可审计-可撤销**的三位一体证书。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（伦理可容许动作空间）**
设 `A_forbid = A_hard ∪ A_soft(θ_e)`，其中 `A_hard` 为不可协商禁区（不可逆伤害、越权控制、隐私侵入动作），`A_soft(θ_e)` 为需按风险阈值 `θ_e` 裁量的软禁区。伦理可容许动作空间 `A_adm = A \ A_forbid`。伦理投影 `π_eth : α_S ↦ α^adm_S`，`α^adm_S(a) = α_S(a)·1[a∈A_adm]`。组合可行域从 `A = A_c×A_e` 收缩为 `A_adm`，且 `cover_eth(S,A_T)=1 ⇔ ∀a∈A_T, a∈A_adm ∧ α^adm_S(a)≥θ_cov`。

**定义 122（伦理审查漏斗）**
分级审查 `ER = (g_0,g_1,g_2)`，风险评分 `r(S) ∈ [0,1]`：
```
g_0: r < θ_0            → 自动规则判定（只查 A_hard 与硬性政策）
g_1: θ_0 ≤ r < θ_1      → 人类复核（灰区）
g_2: r ≥ θ_1            → 伦理委员会 + 外部见证
```
审查算子 `Review(S) → d ∈ {approve, deny, escalate, expire}`，带延迟上界 `τ_eth` 与 TTL。**fail-closed 语义**：`Review` 超时/证据缺失/评审冲突 → `deny`。

**定义 123（伦理证书）**
`E_cert = (policy_id, A_forbid, A_soft, a_halt, τ_stop, consent_scope, reviewer, ttl, revoke_handle)`，语义：
- `A_forbid` 已从剖面切除且不可被组合重新引入（闭包性）；
- `a_halt ∈ A_halts` 为停止/接管动作，`reach_time(a_halt) ≤ τ_stop`；
- `consent_scope` 限定可服务的对象/场景范围；
- `ttl` 到期自动失效，`revoke_handle` 支持在线撤销。
若 `ttl` 过期或 `revoke_handle` 被触发，证书立即转为 `revoked`，下游部署判据强制失败。

**定义 124（指标构念包与可采纳性）**
指标集合 `𝕄 = {(m_i, M_cert_i)}`，`M_cert_i=(C_i,O_i,e_i,u_i)`。定义构念效度三元组：
```
convergent:  m_i 与已确立的外部准则正相关（≥ κ_1）
discriminant: m_i 不与其他构念混淆（互信息 ≤ κ_2）
predictive:  用 m_i 预测的部署结论可被独立复现（复现率 ≥ κ_3）
```
指标 **可采纳** 当且仅当：`O_i` 可复现 ∧ `u_i` 经 conformal 校准（覆盖 `≥1−α`）∧ 三元效度达标。否则该指标只能作诊断，**不得作为部署门控**。

**定义 125（指标博弈缺口与最小可证伪集）**
设参照策略 `π*`（经人审基线），真实效用 `U`。指标 `m` 的博弈缺口
```
G_m = sup_{ρ : U(ρ) ≤ U(π*) − δ} [ m(ρ) − m(π*) ]
```
若 `G_m > γ_g`，则 `m` 被标记为 **gameable**。指标集 `𝕄` 为**最小可证伪集**，当且仅当不存在策略 `ρ` 使 `U(ρ) ≤ U(π*) − δ` 且 `∀m∈𝕄: m(ρ) ≥ m(π*)`。直观：没有“全指标都好看但真实更差”的免费午餐。

**定义 126（伦理-指标联合证书 `J+`）**
`J+ = (J, E_cert, M_cert, revoke)`，其中 `J` 为第 54 轮动作-鲁棒性联合证书。部署判据：
```
J.ρ ≥ ρ_min ∧ J.δ_a ≤ Θ_a
∧ E_cert.state = approved ∧ E_cert.ttl > now
∧ a_halt ∈ A_core(J) ∧ reach_time(a_halt) ≤ τ_stop
∧ ∀m∈𝕄_gate: admissible(m) ∧ G_m ≤ γ_g
∧ 𝕄_gate 为最小可证伪集
```
任一子句不满足即 `reject`，且拒绝理由 `reason` 必须可追溯到具体子句（可解释拒绝）。

## 2. 关键算法 伪代码

### IP-121 EASR（Ethics-Aware Space Restriction）

```python
def ethics_projection(alpha, A_forbid, A_soft, theta_e, risk):
    A_blocked = set(A_forbid) | {a for a in A_soft if risk(a) >= theta_e}
    alpha_adm = {a: (v if a not in A_blocked else 0.0) for a, v in alpha.items()}
    return alpha_adm, A_blocked

def cover_eth(alpha_adm, A_T, theta_cov=0.8):
    return all(alpha_adm.get(a, 0.0) >= theta_cov for a in A_T)
```

### IP-122 ERF（Ethics Review Funnel）

```python
def review(skill, policy, timeout=TAU_ETH):
    r = risk_score(skill, policy)
    try:
        if r < THETA0:
            d = g0_rules(skill, policy)          # 仅硬规则
        elif r < THETA1:
            d = human_g1(skill, policy, ttl=...) # 人审灰区
        else:
            d = committee_g2(skill, policy, witness=True)
        if d.needs_evidence and not d.evidence_ok:
            return Decision('deny', reason='insufficient_evidence')
        return d
    except Timeout:
        return Decision('deny', reason='review_timeout_fail_closed')  # 默认拒绝

def refresh(cert, now):
    if now > cert.ttl or cert.revoke_handle.triggered:
        return cert.as_revoked()
    return cert
```

### IP-123 HRM（Halt Reachability Monitor）

```python
def halt_guarantee(P_e, G, a_halt, tau_stop):
    # 最短接管路径：在组合图 G 上求到 a_halt 的最短可达时间
    t = shortest_time_to(G, start=P_e.state, goal=a_halt, cost='trans_time')
    if t is None or t > tau_stop:
        return ('reject', 'halt_unreachable', t)
    A_core = P_e.A_core | {a_halt}          # 停止动作强制进入核心集
    return ('ok', A_core, t)
```

### IP-124 MCV（Metric Construct Validation）

```python
def validate_metric(m, data, alpha=0.05):
    # conformal 校准：给出有限样本覆盖保证
    q = conformal_quantile(residuals(m, data.calib), alpha)
    interval = lambda x: (m(x) - q, m(x) + q)
    val = {
        'convergent': corr(m, data.external) >= KAPPA1,
        'discriminant': mutual_info(m, data.confounders) <= KAPPA2,
        'predictive': reproduction_rate(m, data.holdout) >= KAPPA3,
    }
    admissible = all(val.values()) and m.operationalization.reproducible
    return M_cert(m, interval, q, val, admissible)
```

### IP-125 MGA（Metric Gaming Audit）

```python
def goodhart_gap(m, reference_pi, true_utility, delta, search_budget):
    best = 0.0
    for rho in red_team_policies(search_budget):     # 对抗策略搜索
        if true_utility(rho) <= true_utility(reference_pi) - delta:
            best = max(best, m(rho) - m(reference_pi))
    return best

def minimal_falsifiable_set(metrics, reference_pi, delta, gamma_g):
    M = list(metrics)
    for m in sorted(M, key=lambda x: goodhart_gap(x, reference_pi, U, delta, B)):
        if goodhart_gap(m, reference_pi, U, delta, B) > gamma_g:
            M.remove(m)                               # 单独门控不安全者剔除
    if not is_minimal_falsifiable(M, reference_pi, delta):
        return ('reject', 'metrics_not_falsifiable')
    return ('ok', M)
```

### IP-126 JPC（Joint Ethics-Metric Certificate）

```python
def joint_certificate_plus(J, E_cert, metrics, reference_pi, now, budgets):
    reasons = []
    if not (min(J.rho.values()) >= budgets.rho_min and J.delta_a <= budgets.Theta_a):
        reasons.append('action_robustness_fail')
    if E_cert.state != 'approved' or now > E_cert.ttl:
        reasons.append('ethics_not_valid')
    if not reach_time_ok(J, E_cert.a_halt, budgets.tau_stop):
        reasons.append('halt_unreachable')
    for m in metrics.gate:
        if not m.admissible:
            reasons.append(f'metric_unadmissible:{m.name}')
        if goodhart_gap(m, reference_pi, U, budgets.delta, budgets.B) > budgets.gamma_g:
            reasons.append(f'gameable:{m.name}')
    if not is_minimal_falsifiable(metrics.gate, reference_pi, budgets.delta):
        reasons.append('metrics_not_minimal_falsifiable')
    if reasons:
        return ('reject', reasons)
    return ('ok', JointCertPlus(J, E_cert, metrics.certs, revoke=E_cert.revoke_handle))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EASR | O(|A|) | O(|A|) | 禁区闭包：组合不得重新引入 `A_forbid` |
| ERF | O(1) 摊还 / 人审 O(τ_eth) | O(|skills|) | fail-closed、TTL 与撤销句柄有效 |
| HRM | O(|V| log|V| + |E|) | O(|V|+|E|) | `a_halt ∈ A_core` 且 `reach_time ≤ τ_stop` |
| MCV | O(n_calib · |m|) | O(n_calib) | conformal 可交换性、效度三元组达标 |
| MGA | O(B · |Π|) | O(B) | 红队覆盖、博弈缺口上界可信 |
| JPC | O(|𝕄| · cost(MGA)) | O(|𝕄|) | 判据合取 sound、拒绝理由可追溯 |

**正确性定理 1（Ethical Soundness / 安全性）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `π_eth` 对 `A_forbid` 的切除是闭包的（组合算子不重新生成禁区动作）；**(A30)** 审查漏斗在超时/证据不足时严格 fail-closed，且误放行率 `≤ ε_ER`；**(A31)** 撤销句柄在 `τ_rev` 内生效，失败概率 `≤ ε_rev`。则对任一被部署的 `P_e`：
```
P(发生伦理越界 | 已部署) ≤ ε_ER + ε_proj + ε_rev
```
其中 `ε_proj` 为投影泄漏率（`A_forbid` 中被 `α^adm` 误保留的比例）。

**正确性定理 2（Liveness / 可用性）**
设审查到达率与服务率构成 `M/G/1` 近似，审查拒绝率 `d_ER`、超时率 `d_timeout`（计入拒绝）。则部署覆盖
```
Coverage = P(deploy) ≥ (1 − d_ER)(1 − d_timeout) · P(J.ρ ≥ ρ_min, J.δ_a ≤ Θ_a)
```
**安全性与可用性在此显式分离**：提高 `θ_e`/`τ_eth` 会降低越界率但压低 Coverage，二者构成 Pareto 前沿（E163 测量）。这与第 54 轮只报单一 success 的做法不同：**我们不再用一个标量同时冒充安全与可用**。

**正确性定理 3（Metric Trustworthiness）**
若 `M_cert_i` 的 conformal 校准满足可交换性，则对真实指标值 `m_i^true`：
```
P(m_i^true ∈ [m_i − q_i, m_i + q_i]) ≥ 1 − α
```
且若 `𝕄_gate` 为最小可证伪集，则不存在 `U(ρ) ≤ U(π*)−δ` 却让所有门控指标同时不降的策略（在红队搜索 `B` 内可检测）。注意：这是**相对给定构念与红队预算**的保证，不是对“真实善”的保证。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 伦理审查沦为“橡皮图章”仪式 | 高 | 外部见证 + 审查日志不可篡改 + 随机抽检 + 拒绝理由可追溯 |
| `A_forbid`/`A_soft` 定义本身有争议或过时 | 高 | 政策版本化 + 多方参与定义 + 定期重审 + 允许更严格的地方覆盖 |
| fail-closed 导致可用性塌陷 | 高 | 分级 triage + 预审缓存 + 风险分级白名单 + Pareto 工作点显式选择 |
| 指标构念效度无法真正验证 | 高 | conformal + 外部准则 + 预注册分析 + 独立复现；承认其边界而非宣称绝对 |
| 红队搜索不完备使 `G_m` 低估 | 中 | 多样红队 + 预算内上界 + 对新攻击面持续审计 |
| 撤销动作被组合或策略绕过 | 高 | `a_halt ∈ A_core` 硬约束 + 独立看门狗 + 物理急停冗余 |
| 审查延迟与在线重规划冲突 | 中 | 异步预审 + 证书预取 + 灰区降级到受限动作集 |

## 6. 本轮最大风险

**一句话**：把伦理审查形式化为动作空间切除、把评测指标形式化为带测量证书与抗博弈审计的构念，能显著提升证书体系的诚实度，但其最大风险是**“合规的假安全感”**——`π_eth` 只切除我们写进 `A_forbid` 的东西，`M_cert` 只校准我们选定的构念，`G_m` 只覆盖我们想得到的红队策略；一旦禁区定义滞后于真实伤害、或指标构念本身选错，整套 `J+` 证书会用严密的数学为错误的价值假设背书，故必须把**政策多方参与、禁区版本化重审、独立外部复现**作为与定理同等重要的制度性护栏，宁可承认“证书只覆盖已定义的伦理与已校准的指标”，也不把形式化 sound 误当作道德上的正确。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-EthAudit（EASR×ERF×HRM×MCV×MGA×JPC）

> 承接第 54 轮产物 v31（ACS×SCOM×CEC×AEC×JTC）。本轮在动作-鲁棒性双证书之上，回应「伦理审查」×「评测指标」两大灵感，增加 **伦理可容许动作空间、分级审查漏斗、停止可达性不变量、指标构念校验、抗博弈审计、伦理-指标联合证书** 六个算子：
> - **EASR（Ethics-Aware Space Restriction）**：把伦理禁区投影进动作空间，先切空间再谈能力；
> - **ERF（Ethics Review Funnel）**：三级审查 + fail-closed + TTL/撤销句柄；
> - **HRM（Halt Reachability Monitor）**：把“人类可随时接管”变成组合证书的硬不变量；
> - **MCV（Metric Construct Validation）**：每个评测指标附测量证书与 conformal 校准；
> - **MGA（Metric Gaming Audit）**：量化 Goodhart 博弈缺口，构造最小可证伪指标集；
> - **JPC（Joint Ethics-Metric Certificate `J+`）**：伦理-动作-鲁棒性-指标四位一体部署判据。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118/120 以纳入伦理与指标维度。安全（violation）与可用（coverage）在本轮被显式分离为两个指标族。

## 2. 关键算法 伪代码

### IP-121 EASR

```python
def ethics_projection(alpha, A_forbid, A_soft, theta_e, risk):
    blocked = set(A_forbid) | {a for a in A_soft if risk(a) >= theta_e}
    alpha_adm = {a: (v if a not in blocked else 0.0) for a, v in alpha.items()}
    assert forbidden_closure(alpha_adm, A_forbid)   # 组合不得重新引入禁区
    return alpha_adm, blocked

def cover_eth(alpha_adm, A_T, theta_cov=0.8):
    return all(alpha_adm.get(a, 0.0) >= theta_cov for a in A_T)
```

### IP-122 ERF

```python
def review(skill, policy, timeout=TAU_ETH):
    r = risk_score(skill, policy)
    try:
        if r < THETA0:
            d = g0_rules(skill, policy)
        elif r < THETA1:
            d = human_g1(skill, policy, ttl=TTL_G1)
        else:
            d = committee_g2(skill, policy, witness=True)
        if d.needs_evidence and not d.evidence_ok:
            return Decision('deny', 'insufficient_evidence')
        return d
    except Timeout:
        return Decision('deny', 'review_timeout_fail_closed')

def refresh(cert, now):
    if now > cert.ttl or cert.revoke_handle.triggered:
        return cert.as_revoked()
    return cert
```

### IP-123 HRM

```python
def halt_guarantee(P_e, G, E_cert, tau_stop):
    t = shortest_time_to(G, start=P_e.state, goal=E_cert.a_halt, cost='trans_time')
    if t is None or t > tau_stop:
        return ('reject', 'halt_unreachable', t)
    A_core = P_e.A_core | {E_cert.a_halt}
    return ('ok', A_core, t)
```

### IP-124 MCV

```python
def validate_metric(m, data, alpha=0.05):
    q = conformal_quantile(residuals(m, data.calib), alpha)
    val = {
        'convergent':  corr(m, data.external) >= KAPPA1,
        'discriminant': mutual_info(m, data.confounders) <= KAPPA2,
        'predictive':  reproduction_rate(m, data.holdout) >= KAPPA3,
    }
    admissible = all(val.values()) and m.operationalization.reproducible
    return M_cert(m, interval=(m - q, m + q), q=q, validity=val,
                  admissible=admissible, coverage=1 - alpha)
```

### IP-125 MGA

```python
def goodhart_gap(m, reference_pi, U, delta, budget):
    best = 0.0
    for rho in red_team_policies(budget):
        if U(rho) <= U(reference_pi) - delta:
            best = max(best, m(rho) - m(reference_pi))
    return best

def minimal_falsifiable_gate(metrics, reference_pi, U, delta, gamma_g, budget):
    gate = [m for m in metrics
            if goodhart_gap(m, reference_pi, U, delta, budget) <= gamma_g]
    if not is_minimal_falsifiable(gate, reference_pi, U, delta):
        return ('reject', 'metrics_not_falsifiable')
    return ('ok', gate)
```

### IP-126 JPC

```python
def joint_certificate_plus(J, E_cert, metrics, reference_pi, U, now, budgets):
    reasons = []
    if min(J.rho.values()) < budgets.rho_min or J.delta_a > budgets.Theta_a:
        reasons.append('action_robustness_fail')
    E_cert = refresh(E_cert, now)
    if E_cert.state != 'approved':
        reasons.append(f'ethics_not_valid:{E_cert.state}')
    ok_halt, A_core, t = halt_guarantee(J.P_e, J.G, E_cert, budgets.tau_stop)
    if not ok_halt:
        reasons.append(f'halt_unreachable:{t}')
    for m in metrics.gate:
        if not m.admissible:
            reasons.append(f'metric_unadmissible:{m.name}')
        if goodhart_gap(m, reference_pi, U, budgets.delta, budgets.B) > budgets.gamma_g:
            reasons.append(f'gameable:{m.name}')
    if not is_minimal_falsifiable(metrics.gate, reference_pi, U, budgets.delta):
        reasons.append('metrics_not_minimal_falsifiable')
    if reasons:
        return ('reject', reasons)          # 拒绝理由逐条可追溯
    return ('ok', JointCertPlus(J, E_cert, metrics.certs,
                                revoke=E_cert.revoke_handle, A_core=A_core))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EASR | O(|A|) | O(|A|) | 禁区闭包；`ε_proj=0` |
| ERF | O(1) 摊还 / O(τ_eth) 人审 | O(|skills|) | fail-closed；TTL 与撤销有效 |
| HRM | O(|V|log|V|+|E|) | O(|V|+|E|) | `a_halt∈A_core`，`reach_time≤τ_stop` |
| MCV | O(n_calib·|𝕄|) | O(n_calib) | conformal 覆盖 `≥1−α`，效度三元组 |
| MGA | O(B·|Π|) | O(B) | 红队预算内的博弈缺口上界 |
| JPC | O(|𝕄|·cost(MGA)) | O(|𝕄|) | 合取判据 sound，拒绝可解释 |

**定理 1（Ethical Soundness）**
承接第 54 轮 (A22)–(A28)；**(A29)** `π_eth` 对 `A_forbid` 闭包；**(A30)** 审查漏斗 fail-closed，误放行率 `≤ε_ER`；**(A31)** 撤销在 `τ_rev` 内生效，失败率 `≤ε_rev`。则
```
P(伦理越界 | 已部署) ≤ ε_ER + ε_proj + ε_rev
```

**定理 2（Liveness / Coverage）**
```
Coverage = P(deploy) ≥ (1−d_ER)(1−d_timeout)·P(J.ρ≥ρ_min, J.δ_a≤Θ_a)
```
安全与可用显式分离，沿 `(θ_e, τ_eth)` 形成 Pareto 前沿（E163）。

**定理 3（Metric Trustworthiness）**
若 `M_cert` 的 conformal 校准满足可交换性：
```
P(m_true ∈ [m−q, m+q]) ≥ 1−α
```
若 `𝕄_gate` 为最小可证伪集，则在红队预算 `B` 内不存在“所有门控指标同时不降而 `U` 下降 `>δ`”的策略。

## 6. 本轮最大风险

**一句话**：把伦理审查形式化为动作空间切除、把评测指标形式化为带测量证书与抗博弈审计的构念，能显著提升证书体系的诚实度，但其最大风险是**“合规的假安全感”**——`π_eth` 只切除我们写进 `A_forbid` 的东西，`M_cert` 只校准我们选定的构念，`G_m` 只覆盖我们想得到的红队策略；一旦禁区定义滞后于真实伤害、或指标构念本身选错，整套 `J+` 证书会用严密的数学为错误的价值假设背书，故必须把**政策多方参与、禁区版本化重审、独立外部复现**作为与定理同等重要的制度性护栏，宁可承认“证书只覆盖已定义的伦理与已校准的指标”，也不把形式化 sound 误当作道德上的正确。
