> 升级为「**帧归因的几何盲区修复**」，并审计修复第 2 轮遗留的七处结构性缺陷（见 §5）。

## 三位一体映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 手眼标定 | AP-Cal 输出的 `u_s` 没有帧标签，只在传感器坐标内自洽 | **HG-Box**：SE(3) 变换链误差归因 + 标定规范群 | 同一端到端残差可由相机偏差 / 手眼外参 / 运动学零位以不同方式解释；不归因就会在错误的坐标系里「治好」，在动作里失效或重复计数 |
| 桌面操作（物理锚） | V 阶段只用 cross.modal 残差做交叉验证 | **A-Box**：桌面锚定集 + 任务空间不变式 | 桌面天然提供支撑平面、重力、接触、已知几何与可达/碰撞约束，把「图像对得上」升级为「桌上做得成」 |
| 桌面操作（任务分布） | MP-Φ 预训练先验来自通用数据，β 只看标量信息增益 | **OB-Cal**：可观测性驱动的主动激励 | 桌面任务几乎都是绕重力轴的平面运动，对手眼外参恰是退化激励；必须主动做离面运动，否则标定在最危险的方向上不可识别 |

**核心命题**：把 ToolGauge 的「数值盲区 → 契约化探测 → 摊销校准 → 局部热替换」升级为
「**帧归因的几何盲区 → 规范不变的标定契约 → 桌面锚定与任务空间验证 → 局部/全局分级替换**」：
数值真值仍由计量层独占；标定误差第一次被显式拆成「可识别分量」与「规范自由度」，
不可识别的部分只能进入影子寄存器，永不进入数值通道与语言主张。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- **主张绑定不变式再扩展**：语言主张除了引用有效数值回执，还必须引用帧标签与规范类，否则剥离（定义 446）；
- **严格退化链延长**：TableGauge 失效（无可观测性证书 / 锚定秩不足 / 平面退化未解除 / 任务验证失败 / 同步或遮挡失效）
  ⇒ 退回 ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。几何标定是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（手眼标定 → 从「修数值」到「修坐标系账本」）**
直觉：机器人的最终动作依赖变换链 `T_bo = T_be · T_ec · T_co`（base←ee←cam←obj）。
一个 8mm 的桌面物体深度误差，可能来自相机内参/深度偏置（cam 帧）、手眼外参 `X=T_ec`（ee 帧）、
关节零位（base 帧），或者桌面高度估计（table 帧）。它们在单一视角下可以产生几乎相同的像素残差。
ToolGauge 的 AP-Cal 把修复量记成无帧标签的 `u_s`，等于把不同账户的账混在一起——
在盲区 s 上「修好了」，却可能让整个工作空间的手眼一致性变坏。
手眼标定的经典结构恰好提供了正确的语言：`X` 与 `Y=T_co` 只以乘积 `X·Y` 进入端到端映射，
因此 `(X,Y)` 天然带一个 `SE(3)` **规范群**（gauge group）：对任意 `g`，`(Xg⁻¹, gY)` 给出完全相同的端到端映射。
所以正确的修复对象不是「X 或 Y 的某个数」，而是**规范等价类**；要落地成可执行外参，必须用物理锚把规范固定住。

**灵感 2（桌面操作 → 免费的物理锚，也是任务空间的最终裁判）**
直觉：桌面是机器人每天都会遇到的、几乎免费的标定靶。
- 支撑平面给出重力方向与桌面高度（3 个约束：法向 2 + 偏移 1）；
- 两个已知间距的接触点/物体给出平面内的度量（再 3 个约束）；
- 抓取成功、放置稳定、接触力锥、无碰撞、可达性，给出任务空间的**物理证伪**。
这让验证阶段不再只依赖「另一个传感器也说差不多」——因为 cross.modal 与主通道可能共享同一个手眼误差，
它们的「一致」并不能排除共同的坐标系偏差。桌面接触与任务成功是**独立于视觉通道的物理证据**。

**灵感 3（桌面任务分布 → 可观测性退化与主动激励）**
直觉：桌面任务绝大多数是准静态、绕重力轴的平面操作（推、放、沿桌抓取）。
经典手眼标定 `AX=XB` 的可辨识性要求相对旋转轴**至少两个非平行方向**；若所有运动都绕同一个桌面法向 `n`，
则解沿 `n` 存在螺旋/平移零空间：**绕 `n` 的偏航与沿 `n` 的高度不可辨识**。
更糟的是，这两个分量在平面任务中几乎不产生误差——任务成功率对它不敏感，传感器交叉验证也对它不敏感。
因此 OB-Cal 必须把「标量信息增益」升级为「**观测矩阵可观测性增益**」，并主动规划离面倾斜/抬升/多接触的 PROBING 动作；
若工作空间或安全门不允许，则系统必须承认不可识别并退化，而不是提交一个「任务分布上看起来很好」的欠定外参。

**灵感 4（全局 vs 局部 → 热替换的适用边界）**
直觉：ToolGauge 的「局部热替换 + 误差局部化」论证默认修复是局部的。
但手眼外参是**全局量**：它的误差影响每一个格子，不能用局部子图替换来吸收。
本轮把修复分成两类——可识别的局部残差走子图热替换（继承引理 44），
可识别的全局帧参数必须走「冻结 → 影子契约 → 全任务回归 → 原子切换」；
不可识别的规范分量只进影子寄存器供审计，永不进入控制与语言。

## 1. 形式化定义（增量：定义 432–448）

**定义 432（帧标签契约 UG-Contract）** 每个数值契约字段 `u` 扩展为 `u^f = (value, frame, t, gauge_id)`，
其中 `frame ∈ F = {base, ee, cam, obj, table}`，`t` 为时间戳，`gauge_id` 为规范等价类编号。
合成规则：`frame(A ∘ B) = frame(A)`；跨帧比较必须先经显式变换。
**未标帧、或变换链不闭合的字段视为非法，序列化时拒绝进入 EC。**
这替代 ToolGauge 中无帧标签的 `u_s`（缺陷 1）。

**定义 433（端到端映射与标定规范群）** 记 `X = T_ec`（手眼外参），`Y = T_co`（相机到物体）。
端到端映射 `E = T_be · X · Y`。规范群
`G_cal = { g ∈ SE(3) : (X, Y) ↦ (X g⁻¹, g Y) }`，显然 `E` 在 `G_cal` 作用下不变。
标定契约只能引用商空间 `[X, Y] ∈ (SE(3)×SE(3)) / G_cal` 的元素；
选代表元（规范固定）需要外部物理锚（定义 435/439）。

**定义 434（规范不变契约与影子寄存器）** 设线性化误差 `ξ = (ξ_c, ξ_h, ξ_k, ξ_l)`（cam / hand-eye / kinematic / local）。
投影 `π_G : ξ ↦ ξ / ker(A)`。**提交到数值通道的只能是 `π_G(ξ)`**；
规范分量 `ξ_⊥ = (I − π_G)ξ` 写入**影子寄存器**，仅供审计，禁止进入控制、校准样本与语言主张。
按可识别部分在全局帧参数子空间上的投影范数定义分类：
`‖P_global π_G(ξ)‖ ≥ κ_glob` ⇒ **全局修复**；否则为**局部修复**。

**定义 435（桌面锚定集 A）** `A = (π_table, g_grav, C, M_known, F_fid)`：
支撑平面（法向 `n`、偏移 `d`）、重力方向、接触点集 `C`（力/位姿/时间戳）、已知物体几何 `M_known`、
可选平面标定靶 `F_fid`。锚定残差
`r_A = (|nᵀ p_c + d| for c∈C, ‖g_meas − g_grav‖, fiducial reprojection, …)`。
锚必须带时间戳与可见性标记（定义 443/444）。

**定义 436（任务空间可行域 X_task）**
`X_task = Reach ∩ C_free ∩ Stable ∩ FrictionCone ∩ Visibility`：
机械臂可达、无碰撞、支撑稳定（质心投影落在支撑多边形内）、接触力在摩擦锥内、关键锚可见。
任何探测动作与修复后动作都必须落在 `X_task` 内（定义 455 的安全门）。

**定义 437（帧归因观测模型）** 对 `N` 条有效回执，在小误差下
`y = A ξ + ε`，`A = [A_c A_h A_k A_l]`，`ξ ∈ se(3)^4`；先验取 ToolGauge 的 MP-Φ 输出（定义 420）。
归因解 `ξ̂ = argmin_ξ ‖y − Aξ‖²_Σ + λ‖ξ − ξ_prior‖²_phys`。
可辨识性由 `σ_min(A)` 与 `ker(A)` 给出；规范零空间应恰为 `G_cal` 的 `se(3)` 像（6 维），
**多出来的零空间维数就是不可辨识的物理自由度，必须由锚补齐或拒绝提交。**

**定义 438（可观测性与激励证书 ObsCert）** `ObsCert = (σ_min(A) ≥ σ*, nullity(A) = dim G_cal + r_unknown, r_rot ≥ 2, anchor_rank = 6, static_sync_valid)`，
其中 `r_rot` 为相对旋转轴的非平行方向数。任一不满足 ⇒ 不校准、不替换、stub + RED。
`σ*` 由目标位姿误差 `ε_pose` 与噪声水平 `σ_obs` 反解：`σ* ≥ σ_obs/ε_pose`。

**定义 439（锚定规范固定）** 将锚观测行 `A_anchor` 与归因系统拼接：
`rank([A; A_anchor]) = rank(A) + dim G_cal`（即规范零空间被完全固定）。
充分例：桌面平面给 3（法向 2 + 高度 1），两个已知间距接触点给 3（平面内位置 2 + 朝向 1）⇒ 秩 6。
锚定失败 ⇒ `H_s := {UNKNOWN}` 的几何版本：不提交外参，退回 ToolGauge 的纯数值路径。

**定义 440（可观测性增益与主动标定）** 对候选动作 `a ∈ X_task`（含离面倾斜/抬升/多接触），
`β_obs(a) = log det(I + J_aᵀ Σ⁻¹ J_a) − c_a`（Fisher 信息行列式增益减代价）。
OB-Cal 选择 `argmax_a β_obs(a)`，并受双层闸门约束：风险门 `λ(a,s) ≥ γ` 与可观测性门 `β_obs(a) ≥ γ_obs` 同时通过才执行。
这是对 ToolGauge 定义 419 的精确升级：**从「这条探测值不值」升级为「这条探测让标定变得可辨识吗」**。

**定义 441（TableGauge 七段闭环 7C）** `D → I → G → P → E → V → U`：
1. **D**etect：D-Box（定义 398/399，继承）发现盲区 s；
2. **I**dentify：HG-Box 以回执流 + 锚观测做帧归因，输出 `ξ̂` 与 `ObsCert`；
3. **G**auge：A-Box 检查 `A_anchor` 是否固定规范；投影得到 `π_G(ξ̂)`，规范分量进影子寄存器；
4. **P**lan：OB-Cal 规划含离面激励的探测程序 Π_s，TCV（定义 418，继承）验证 schema/前置/预算/循环；
5. **E**xecute：PROBING 态逐条执行，回执校验 + 静态/同步/遮挡有效性（定义 443/444）；
6. **V**erify：跨模态残差（继承 ToolGauge）+ **任务空间不变式**（定义 442）双重验证；
7. **U**pdate：局部修复走子图热替换；全局修复走影子契约 + 全任务回归 + 原子切换（定义 447）；更新漂移监控。

**定义 442（任务空间验证 V_task）** 对修复后的 `E`，要求
`r_A ≤ ε_A`、预测抓取成功率 `≥ 1−δ_g`、放置稳定裕度 `≥ m_s`、无碰撞、可达、摩擦锥内。
**任一项失败 ⇒ 不提交**。任务空间验证是独立于视觉交叉验证的物理证伪，专门用于识别共享帧误差。

**定义 443（静态-同步有效性）** 手眼标定要求相机与机械臂位姿在同一时刻：
`|ts_cam − ts_robot| ≤ τ_sync` 且 `‖v‖ ≤ v_s, ‖ω‖ ≤ ω_s`（准静态窗口）。
超限回执作废；误差上界 `‖δT‖ ≲ (v_max + ℓ·ω_max)·τ_sync`，直接进入 `ObsCert` 的噪声预算。

**定义 444（遮挡感知回执有效性）** 每条锚观测带可见性掩码：自遮挡/接触导致关键锚不可见时，
该观测**不计为反证**（缺失证据 ≠ 矛盾证据），但会降低 `anchor_rank` 与 `ObsCert`；
`anchor_rank < 6` 时禁止全局提交。

**定义 445（标定漂移监控 CDM）** 对锚残差 `r_A(t)` 做 CUSUM：
`S_t = max(0, S_{t−1} + r_A(t) − μ_0 − k)`；`S_t > h` ⇒ 触发重标定/降级。
监控热漂移、机械负载引起的缓慢外参漂移，避免每盲区重跑完整 7C。

**定义 446（规范修复证书与主张绑定扩展）** `GaugeCert(s) = ([X,Y], A, ObsCert, class∈{local,global}, V_task receipts, 文字解说)`。
语言主张必须同时引用：有效数值回执 + 帧标签 + 规范类；引用影子寄存器数值或未固定规范的主张在序列化时剥离。
这是对定义 423 的几何扩展：**数值主张必须可被坐标系审计**。

**定义 447（局部/全局分级热替换）**
- 局部修复：仅影响子图 `M_ver` 的局部残差 ⇒ 继承引理 44 的子图热替换；
- 全局修复：投影到全局帧参数且 `‖P_global π_G(ξ̂)‖ ≥ κ_glob` ⇒ 冻结相关格子、在影子契约上演算、
  跑全任务回归、通过后**原子切换**；切换期间不得混用新旧帧参数。
这是对 ToolGauge「局部热替换」适用边界的显式修复（缺陷 6）。

**定义 448（继承与编号约定）** 未被本轮重定义的第 2 轮记号（IP-315–320、定义 416–431、引理 46–50）全部沿用。
令 `X` 固定、`A_anchor` 恒满足、`X_task = ℝ⁶`（无桌面约束）、`OB-Cal` 退化为 ToolGauge 的 β 注 ⇒ `TableGauge ≡ ToolGauge`。

## 2. 关键算法骨架

```python
# IP-321 HG-Box：帧归因 + 规范商
@dataclass
class FrameTagged:
    value: float; frame: str; t: float; gauge_id: str

class HGBox:
    def attribute(self, receipts, anchors, prior):
        A, y = self.build_se3_system(receipts, anchors)   # 定义 437
        xi = regularized_map(A, y, prior)                  # ξ̂
        obs = ObsCert(A, anchors, sync=receipts.sync)      # 定义 438
        return xi, obs

    def gauge_quotient(self, xi, obs):
        # 只保留可识别分量；规范零空间投影进影子寄存器
        xi_inv = project_out(xi, obs.gauge_basis)          # π_G
        xi_perp = xi - xi_inv
        shadow.write("gauge", xi_perp)                     # 定义 434
        return xi_inv

# IP-322 A-Box：桌面锚 + 任务空间验证
class ABox:
    def extract(self, anchor_receipts, scene):
        return AnchorSet(
            plane=fit_plane(scene.depth, scene.contact),
            gravity=scene.imu.g,
            contacts=anchor_receipts.contacts,
            known=scene.object_models,
        )

    def fixes_gauge(self, anchors, obs):                   # 定义 439
        A_anc = anchors.jacobian()
        return rank(obs.A, A_anc) == rank(obs.A) + 6

    def task_verify(self, E, anchors, task):               # 定义 442
        return (anchors.residual(E) <= EPS_A
                and task.grasp_success(E) >= 1 - DELTA_G
                and task.stability_margin(E) >= M_S
                and task.collision_free(E)
                and task.reachable(E)
                and task.in_friction_cone(E))

# IP-323 OB-Cal：可观测性驱动的主动标定
class ObsPlanner:
    def plan(self, H, xi_inv, tools, obs, task_domain):
        cands = inflate_out_of_plane(task_domain)          # 倾斜/抬升/多接触
        safe  = [a for a in cands if in_X_task(a)]         # 定义 436
        return argmax(safe, key=lambda a: beta_obs(a, H, obs))

# IP-324 GI-Contract：规范不变契约 + 分级替换
class GIContract:
    def classify(self, xi_inv):                            # 定义 434/447
        return "global" if norm(P_GLOBAL @ xi_inv) >= KAPPA_GLOB else "local"

    def global_atomic_swap(self, M, xi_inv):
        with M.freeze():                                   # 冻结相关格子
            shadow_ec = M.dpe.stage(xi_inv)                # 影子契约
            if not M.task_regression(shadow_ec):           # 全任务回归
                return stub_and_red(reason="global_regression")
            M.dpe.commit_atomic(shadow_ec)                 # 原子切换
        return True

# IP-325 TableGauge 7C 闭环
def tablegauge_7c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                  # D（继承）
    a_receipts = M.tcv.execute(M.abox.anchor_program(H), M.env)  # I：先取锚
    A = M.abox.extract(a_receipts, M.scene)
    xi, obs = M.hgbox.attribute(M.receipts(s), A, M.mp_phi)
    if not (M.abox.fixes_gauge(A, obs) and obs.ok):         # G
        return stub_and_red(s, "unidentifiable")            # 定义 438/439
    xi_inv = M.hgbox.gauge_quotient(xi, obs)                # 规范投影
    prog = M.obs_planner.plan(H, xi_inv, M.tools, obs, M.task_domain)  # P
    if not M.tcv.verify(prog, M.budget_left(s)):
        return stub_and_red(s, "tool_contract")
    receipts = M.tcv.execute(prog, M.env)                   # E（PROBING）
    E = M.dpe.compose(xi_inv)
    if not (M.apcal.cross_validate(xi_inv, receipts)         # V：跨模态
            and M.abox.task_verify(E, A, M.task)):          # V：任务空间
        return stub_and_red(s, "task_verification")
    cls = M.gi.classify(xi_inv)                             # U
    if cls == "global":
        ok = M.gi.global_atomic_swap(M, xi_inv)
    else:
        M.mreg.hot_replace(M.dpe, M.gi.local_contract(xi_inv)); ok = True
    M.cdm.update(A.residual)                                # 定义 445
    M.bind_gauge_cert(s, xi_inv, A, obs, receipts)          # 定义 446
    return ok

# IP-326 主闭环：50Hz 路径不动，几何修复全异步
def TableGauge_round(M, obs, audio, tac, depth, det):

            submit_async(tablegauge_7c, M, s)               # 异步
    if M.cdm.triggered():                                   # 漂移断路器
        M.schedule_recalibration()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)   # 主控不变
```

## 3. 推导

**引理 51（规范不变性与商空间良定义）** 对任意 `g ∈ SE(3)`，`E = T_be X Y` 与 `E' = T_be (Xg⁻¹)(gY)` 逐点相同；
且任何只依赖 `E` 的任务语义（物体位姿、抓取点、碰撞几何）在 `G_cal` 下不变。
故 `[X,Y]` 是良定义的修复对象，`(X,Y)` 的具体分解不可由端到端数据辨识。
*证明*：结合律直接消去 `g`；任务语义是 `E` 的函数。∎

**引理 52（可辨识性与误差界）** 若 `σ_min(A) ≥ σ*`，则 `‖ξ̂ − ξ‖ ≤ ‖ε‖/σ*`；
手眼部分 `AX=XB` 可辨识的必要条件是相对旋转轴至少两个非平行方向（`r_rot ≥ 2`）。
在噪声 `σ_obs`、目标位姿误差 `ε_pose` 下，需 `σ* ≥ σ_obs/ε_pose`，等价样本量 `N = Ω((σ_obs/ε_pose)²·d_ξ/σ*²)`。
*证明思路*：最小奇异值给出线性逆问题的 Lipschitz 界；`AX=XB` 的旋转方程在单轴情形存在共轭旋转对称（见引理 53）。∎

**引理 53（桌面平面退化定理）** 若所有相对运动都是绕桌面法向 `n` 的单轴旋转（准静态平面操作），
则 `ker(A_task)` 至少包含 2 维：绕 `n` 的旋转（偏航）与沿 `n` 的平移（高度）。
因此仅凭桌面任务数据，手眼外参的偏航与高度分量不可辨识；且这两个分量对平面任务的端到端误差贡献近零，
任务成功率与传感器交叉验证均无法证伪。
*证明*：令 `R_A = Rot(n,θ_A)`、`R_B = Rot(n,θ_B)`，则 `R_X' = Rot(n,φ)R_X` 满足旋转方程（`φ` 任意）；
平移方程对 `t_X' = t_X + d n` 在 `R_A n = n` 下不变。∎

**引理 54（锚定固定规范）** 桌面平面（法向/高度）+ 两个已知间距接触点（平面内位置/朝向）使
`rank([A; A_anchor]) = rank(A) + 6`；一般地，锚定集固定规范当且仅当其约束行张成 `se(3)` 的规范零空间。
只有平面而无平面内度量时，仍留 1 维偏航零空间（`SE(2)` 的旋转）。
*证明*：逐项数约束维数并检查独立性；偏航绕 `n` 不改变平面本身，故不能由平面观测确定。∎

**引理 55（任务空间安全门与零副作用）** 若动作同时通过风险门 `λ ≥ γ`、可观测性门 `β_obs ≥ γ_obs`
且落在 `X_task`，则其物理副作用被限制在任务可行域内；任一失败 ⇒ TCV 不执行 ⇒ 零副作用。
故 TableGauge 的探测安全下界继承 ToolGauge 引理 46 的「零副作用」，并额外排除可达/碰撞/稳定类风险。
*证明*：由定义 436/440 与 TCV 执行语义（定义 418）直接得到。∎

**引理 56（规范不变热替换保持任务等价）** 只提交 `π_G(ξ̂)` 时，端到端映射 `E` 的改动等于可识别部分的改动；
局部子图替换保持未涉及子图逐指令等价（继承引理 44/49）；全局修复的冻结-影子-回归-原子切换保证不存在新旧帧混用的中间态。
影子寄存器不进入任何数值路径或语言主张 ⇒ 不影响安全论证。
*证明*：`E` 只依赖 `[X,Y]`（引理 51），提交等价类代表元不改变 `E` 的可识别部分；原子切换消除混合态。∎

**引理 57（漂移检测与盲区）** 锚残差 CUSUM 在漂移幅度 `δ > k` 时期望检测延迟 `~ h/(δ−k)`；
但由引理 53，仅桌面平面锚对**绕 `n` 的偏航漂移**不敏感——CDM 必须配合离面激励或平面内标定靶，
否则漂移监控本身也存在不可观测方向。
*证明*：CUSUM 标准结果；偏航不改变平面残差，故不在 `A_anchor` 的行空间内。∎

## 6. 本轮最大风险（一句话）

**一句话**：桌面任务分布本身的平面退化，恰好把最危险的标定量——绕桌面法向的偏航与沿法向的高度——留在可观测零空间里；
传感器交叉验证与任务成功率都对此不敏感，系统会「自信地」提交一个在平面任务上完美、在抬升/倾斜时灾难失效的手眼外参，
而主动离面激励又可能因工作空间受限或安全门而无法执行（E443/E448/E453 为证伪实验，定义 438/439 为拒绝提交的硬门槛）。

**次级风险与缓解**：
1. **锚本身不可信**（桌面被移动、平面拟合偏、接触点滑移）→ 锚残差 + 多帧一致性 + 锚可见性标记（定义 444/445）；
2. **规范固定错误**（平面只给 3 维，误以为 6 维）→ `rank([A;A_anchor])` 硬校验（定义 439，E444）；
3. **时间同步误差伪装成外参误差** → 静态-同步有效性（定义 443，E450）；
4. **全局切换抖动/混合帧** → 冻结 + 影子契约 + 原子切换（定义 447，E452）；
5. **主动离面激励扰动物品或碰撞** → `X_task` 约束 + PROBING 力矩硬限（定义 430/436，E453）；
6. **遮挡导致锚缺失被误判为矛盾** → 缺失证据 ≠ 矛盾证据（定义 444，E451）；
7. **CDM 对偏航漂移不敏感** → 平面内标定靶 + 定期离面抽检（引理 57，E448）。

**定义 432（UG-Contract）** 每个数值字段带 `frame/t/gauge_id`；跨帧比较必须先变换；未标帧或变换链不闭合 ⇒ 序列化拒绝。
**定义 433（规范群）** `E = T_be X Y`；`(X,Y) ↦ (Xg⁻¹,gY)` 保持 `E` 不变；修复对象是商元素 `[X,Y]`。
**定义 434（规范不变契约 / 影子寄存器）** 只提交 `π_G(ξ)`；`ξ_⊥` 进影子寄存器，禁止进入控制、样本集与语言；按全局投影范数分类 local/global。
**定义 435（桌面锚）** 支撑平面、重力、接触点、已知物体几何、可选标定靶；输出锚残差 `r_A`。
**定义 436（任务可行域）** 可达、无碰撞、支撑稳定、摩擦锥内、关键锚可见。
**定义 437（帧归因）** `y = Aξ + ε`，`ξ∈se(3)^4`；正则化 MAP 解；规范零空间应恰为 6 维，多出的零空间即不可辨识物理自由度。
**定义 438（ObsCert）** `σ_min(A)≥σ*`、`nullity = 6 + r_unknown`、`r_rot≥2`、`anchor_rank=6`、同步/静态有效；任一失败不提交。
**定义 439（锚定固定规范）** `rank([A;A_anchor]) = rank(A)+dim G_cal`；平面 3 + 两接触点 3 = 6；平面单独仍留偏航零空间。
**定义 440（可观测性增益）** `β_obs(a)=log det(I+J_aᵀΣ⁻¹J_a)−c_a`；风险门 + 可观测性门双闸门。
**定义 441（7C 闭环）** D 检测 → I 归因/取锚 → G 规范固定与投影 → P 规划离面激励 → E 执行 → V 跨模态+任务空间 → U 分级替换。
**定义 442（V_task）** 锚残差、抓取成功率、放置稳定裕度、无碰撞、可达、摩擦锥内；任一项失败不提交。
**定义 443（静态-同步）** `|ts_cam−ts_robot|≤τ_sync`、`‖v‖≤v_s`、`‖ω‖≤ω_s`；误差上界 `(v_max+ℓω_max)τ_sync` 进入噪声预算。
**定义 444（遮挡感知）** 锚不可见时不计为反证，但降低 `anchor_rank`；秩不足禁止全局提交。
**定义 445（CDM）** 锚残差 CUSUM，超过阈值触发重标定；偏航漂移需平面内靶/离面抽检配合（引理 57）。
**定义 446（GaugeCert / 主张绑定）** 语言主张必须引用数值回执 + 帧标签 + 规范类；引用影子数值或未固定规范 ⇒ 剥离。
**定义 447（分级热替换）** 局部走子图热替换；全局走冻结-影子契约-全任务回归-原子切换，禁止混合帧中间态。

```python
# IP-321 HG-Box：SE(3) 帧归因 + 规范商
class HGBox:
    def attribute(self, receipts, anchors, prior):
        A, y = build_se3_system(receipts, anchors)   # 定义 437
        xi   = regularized_map(A, y, prior)           # ξ̂ = argmin ‖y−Aξ‖² + λ‖ξ−ξ_prior‖²
        obs  = ObsCert(A, anchors, sync=receipts.sync)
        return xi, obs
    def gauge_quotient(self, xi, obs):
        xi_inv  = project_out(xi, obs.gauge_basis)    # π_G(ξ)
        shadow.write("gauge", xi - xi_inv)            # ξ_⊥：只审计，不进数值
        return xi_inv

class ABox:
    def extract(self, anchor_receipts, scene):
        return AnchorSet(fit_plane(scene.depth, scene.contact),
                         scene.imu.g, anchor_receipts.contacts, scene.object_models)
    def fixes_gauge(self, anchors, obs):
        return rank(obs.A, anchors.jacobian()) == rank(obs.A) + 6
    def task_verify(self, E, anchors, task):
        return (anchors.residual(E) <= EPS_A
                and task.grasp_success(E) >= 1 - DELTA_G
                and task.stability_margin(E) >= M_S
                and task.collision_free(E) and task.reachable(E)
                and task.in_friction_cone(E))

# IP-323 OB-Cal：可观测性驱动的主动标定
class ObsPlanner:
    def plan(self, H, xi_inv, tools, obs, task_domain):
        cands = inflate_out_of_plane(task_domain)      # 倾斜/抬升/多接触
        safe  = [a for a in cands if in_X_task(a)]
        return argmax(safe, key=lambda a: beta_obs(a, H, obs))

# IP-324 GI-Contract：规范不变契约 + 分级替换
class GIContract:
    def classify(self, xi_inv):
        return "global" if norm(P_GLOBAL @ xi_inv) >= KAPPA_GLOB else "local"
    def global_atomic_swap(self, M, xi_inv):
        with M.freeze():
            shadow_ec = M.dpe.stage(xi_inv)
            if not M.task_regression(shadow_ec): return stub_and_red("global_regression")
            M.dpe.commit_atomic(shadow_ec)
        return True

# IP-325 TableGauge 7C 闭环
def tablegauge_7c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                        # D
    a_receipts = M.tcv.execute(M.abox.anchor_program(H), M.env)    # I：先取物理锚
    A = M.abox.extract(a_receipts, M.scene)
    xi, obs = M.hgbox.attribute(M.receipts(s), A, M.mp_phi)
    if not (M.abox.fixes_gauge(A, obs) and obs.ok):               # G
        return stub_and_red(s, "unidentifiable")
    xi_inv = M.hgbox.gauge_quotient(xi, obs)
    prog = M.obs_planner.plan(H, xi_inv, M.tools, obs, M.task_domain)  # P
    if not M.tcv.verify(prog, M.budget_left(s)):
        return stub_and_red(s, "tool_contract")
    receipts = M.tcv.execute(prog, M.env)                          # E（PROBING）
    E = M.dpe.compose(xi_inv)
    if not (M.apcal.cross_validate(xi_inv, receipts)                # V：跨模态
            and M.abox.task_verify(E, A, M.task)):                  # V：任务空间
        return stub_and_red("task_verification")
    if M.gi.classify(xi_inv) == "global":                          # U
        ok = M.gi.global_atomic_swap(M, xi_inv)
    else:
        M.mreg.hot_replace(M.dpe, M.gi.local_contract(xi_inv)); ok = True
    M.cdm.update(A.residual)
    M.bind_gauge_cert(s, xi_inv, A, obs, receipts)                  # 定义 446
    return ok

# IP-326 主闭环
def TableGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(tablegauge_7c, M, s)
    if M.cdm.triggered(): M.schedule_recalibration()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（规范不变性）** `E = T_be X Y` 在 `(X,Y)↦(Xg⁻¹,gY)` 下逐点不变；仅依赖 `E` 的任务语义在 `G_cal` 下不变，故修复对象是商元素 `[X,Y]`。
**引理 52（可辨识性）** `σ_min(A)≥σ* ⇒ ‖ξ̂−ξ‖≤‖ε‖/σ*`；`AX=XB` 需至少两个非平行相对旋转轴；`σ*≥σ_obs/ε_pose`，样本量 `N=Ω((σ_obs/ε_pose)²d/σ*²)`。
**引理 53（桌面平面退化）** 若全部相对运动绕桌面法向 `n`，则 `ker(A_task)` 至少含绕 `n` 的旋转与沿 `n` 的平移 2 维；偏航与高度不可辨识，且平面任务对这两个分量几乎不敏感。
**引理 54（锚定固定规范）** 平面（法向 2 + 高度 1）+ 两个已知间距接触点（平面内位置 2 + 朝向 1）⇒ 规范零空间被完全固定；仅平面仍留 1 维偏航零空间。
**引理 55（任务安全门 / 零副作用）** 风险门 + 可观测性门 + `X_task` 同时通过才执行；任一失败 TCV 不执行 ⇒ 零副作用；继承 ToolGauge 引理 46 并排除可达/碰撞/稳定风险。
**引理 56（规范不变热替换）** 只提交 `π_G(ξ)` 时端到端可识别部分不变；局部子图替换继承引理 44；全局修复的冻结-影子-回归-原子切换消除混合帧中间态；影子寄存器不进入数值路径与语言主张。
**引理 57（漂移检测盲区）** 锚残差 CUSUM 检测延迟 `~h/(δ−k)`；但平面锚对绕 `n` 的偏航漂移不敏感，需平面内标定靶或定期离面抽检。

## 8. 本轮最大风险

**一句话**：桌面任务分布的平面退化把偏航与高度留在可观测零空间里，而这两个分量在平面任务中几乎不产生误差——
传感器交叉验证与任务成功率都无法证伪，系统可能「自信地」提交一个在桌面任务上完美、在抬升/倾斜时灾难失效的外参；
主动离面激励又可能被工作空间与安全门禁止，于是系统面临「要么不可识别地提交、要么永远 stub」的两难。
以 E443/E448/E453 证伪；以定义 438/439 的硬门槛拒绝提交；以 CDM + 定期离面抽检兜底。
