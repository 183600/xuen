# 第 47 轮（承接第 46 轮 v23；本轮灵感：语言指令 × 通用机器人平台） · Language-Embodiment-Portability：语言指令驱动的跨具身证书可移植性（五层架构 v11）

> 承接第 46 轮 v23 MVR × VAD × SAB。v23 把语音指令接入记忆检索与安全绑定，隐含假设 H5：语言指令的语义落地与安全证书只在当前 UniBot 本体内有效，平台固定不变。但“通用机器人平台”意味着同一套语言指令要在不同本体（不同自由度、相机布局、负载、动力学、功耗）上复用；“语言指令”是唯一跨本体不变的抽象层，却也是歧义与错绑的源头。既有灵感已解决单本体内的能量/深度/记忆/语音，本轮把问题提升到跨具身：**同一句语言指令在不同平台上的锚点、可达性、姿态证书与安全绑定都不同，若把源平台的证书直接迁移到目标平台，姿态证书与安全谓词会在本体差异下静默失效**。

## 0. 直觉与动机

**灵感 1（语言指令 → 本体无关的指令抽象与歧义集）**
直觉：语言是跨本体的通用接口，但“把红杯子拿起来”对六轴机械臂、双臂、移动底盘意味着不同的锚点、轨迹与安全半径。语言落地不是单点映射，而是一个随本体变化的锚点集合 G(v|P)。因此必须显式建模落地歧义集与本体条件，而不是假定 g(v) 唯一。

**灵感 2（通用机器人平台 → 能力护照与证书可移植性）**
直觉：通用平台 = 可替换本体。把每个本体抽象为能力护照 P=(DoF, 传感器集, 负载, 运动学参数, 功耗预算, 标定版本)。证书（姿态、能量、绑定）只在签发它的 P 上 sound；跨 P 迁移必须携带最坏退化界，并在超出界时重新标定或 fail-closed。

**灵感 3（语言 × 通用平台 → 重落地触发）**
直觉：平台切换或语言指代漂移时，不重新落地就执行是危险的。定义迁移证书 X_t=(P_src→P_dst, Δ_bound, τ_x)；当平台护照不匹配、落地歧义集跨度过大或标定过期时，触发 re-grounding，否则 fail-closed。

**耦合升级**：在 v10/v23 之上新增 **跨具身可移植层**（LEPL: Language-Embodiment Portability Layer）。LIG 做本体条件化落地并输出歧义集；PPP 维护能力护照与每平台标定注册表；XCT 计算迁移证书与重落地触发。SAB 绑定改为 B(v,P_t,P)；MVR 记忆键加入 P 以防跨平台复制；CAR 守卫加入护照匹配与迁移证书有效性。

## 1. 形式化定义（增量：定义 59–62）

**定义 59（平台能力护照）**
平台护照 P=(d, S, L, K, E_b, v_cal) 分别表示自由度、传感器集、负载上限、运动学/动力学参数、功耗预算、标定版本。护照等价 P_src ≃ P_dst 当且仅当 d、S、K 关键项在容差内一致且 v_cal 匹配。

**定义 60（本体条件化语言落地与歧义集）**
语言指令 v 在平台 P 上的落地为一个锚点-技能分布
G(v|P) = { (a_i, s_i, w_i) }，其中 a_i 为锚点，s_i 为技能/轨迹，w_i 为权重。
落地歧义集 A(v|P) = { a_i : w_i ≥ τ_w }。
**落地置信** conf(v|P)=max_i w_i；**歧义跨度** diam(A)=max_{a,a'∈A} ||a-a'||。

**定义 61（证书可移植性与迁移 soundness）**
设源平台 P_src 签发证书 C_src（姿态 P_t / 能量 ℓ_e / 绑定 B）。迁移证书
X=(P_src→P_dst, Δ_bound, τ_x, ε_trans)。
**迁移 soundness**：若 P_src ≃ P_dst 且 t≤τ_x，则对任意 x∈C_src，
dist(x, C_dst(x)) ≤ Δ_bound，且
P( X_t∈C_dst | 指令 v, P_dst, X 有效 ) ≥ 1-α_p - ε_trans(P_src,P_dst)。
其中 ε_trans 由护照差异与标定残差标定；超出容差即 X 失效。

**定义 62（跨平台决策策略）**
Π_x(v,c_t,B_t,P_src,P_dst,M)= (m_t, a_t, status)
约束：m_t 满足能量租约；a_t∈A(v|P_dst)；若 conf(v|P_dst)<τ_conf 或 diam(A)>τ_diam 或 P_src≄P_dst 且 X 缺失/过期，则 status=fail-closed 或触发 re-grounding。安全绑定 B(v,P_t,P_dst)≥θ_safe(P_dst) 才允许 execute。

## 2. 三大新增产出与既有 IP 升级

**IP-69 LIG（Language-Instruction Grounder）**
- 本体条件化落地：语言+场景+护照→锚点/技能分布 G(v|P)
- 歧义量化：conf、diam(A)、指代消解（“它”/“那个”）
- 重落地触发：平台切换/标定过期/歧义超阈

**IP-70 PPP（Platform Profile Passport）**
- 能力护照建模与版本化
- 每平台标定注册表（共形半径、能量参数、绑定系数 γ）
- 护照差异度量 ε_trans 与等价判定

**IP-71 XCT（Cross-embodiment Certificate Transfer）**
- 迁移证书签发：Δ_bound、τ_x、适用条件
- 迁移校验：护照匹配 + 标定时效 + 边界包含
- 失效级联：X 失效→绑定失效→CAR fail-closed

**既有 IP 升级**
IP-68 SAB：B(v,P_t,P) 本体条件化；绑定阈值随平台标定
IP-67 VAD：槽位解析输出本体无关技能 schema，交给 LIG 落地
IP-66 MVR：记忆键加入护照指纹 P_fp，禁止跨平台直接复用
IP-63 ECPS：模态决策以 P_dst 的传感器集为准，重算效用
IP-61 DCL：按平台采集标定数据，补齐迁移残差
IP-62 CCA：新增跨平台红队（护照伪造、迁移越界）
IP-51 CAR：守卫加入 P 匹配与 X 有效性
IP-45 总线：platform-profile / grounding / transfer-cert / reground 话题

## 3. 算法骨架

每控制周期（目标平台 P_dst）：
1. 读 v, c_t, B_t, P_src, P_dst, M
2. PPP 校验 P_src≃P_dst 与 v_cal 时效
3. LIG 计算 G(v|P_dst)、conf、diam(A)
4. 若平台不匹配或无有效 X → 签发 XCT 或触发 re-grounding
5. XCT 计算 Δ_bound 与 τ_x，校验 C_src→C_dst 包含关系
6. SAB 用 B(v,P_t,P_dst) 绑定；ECPS 按 P_dst 模态集选 m_t
7. 任一环节失败 → fail-closed
PSE 在 P_dst 上重签发 P_t；CAR 联合守卫护照/迁移/绑定。

## 4. 本轮最大风险

**一句话**：语言落地的歧义集在源平台被“碰巧正确”地消解，迁移到目标平台后锚点漂移与本体差异叠加，若仍沿用源平台的姿态证书与安全绑定，迁移 soundness 的 ε_trans 被低估，系统会在“看起来合法”的迁移证书下执行错锚点动作；因此必须以护照等价判定、歧义跨度阈值和每平台独立标定共同把关，任一不满足即拒绝迁移并重落地或 fail-closed。

## 2. 关键算法 伪代码

### IP-70 PPP
```
def passport_fingerprint(P):
    return hash((P.d, frozenset(P.S), P.K_hash, P.v_cal))

def passport_equiv(P_src, P_dst, tol):
    if abs(P_src.d - P_dst.d) > tol.d:            return False
    if not P_src.S.issubset(P_dst.S):             return False  # 目标至少具备源传感器
    if kin_distance(P_src.K, P_dst.K) > tol.K:    return False
    if P_src.v_cal != P_dst.v_cal:                return False
    return True

def epsilon_trans(P_src, P_dst, registry):
    key = (passport_fingerprint(P_src), passport_fingerprint(P_dst))
    return registry.get(key, float('inf'))        # 无标定即不可迁移
```

### IP-69 LIG
```
def ground(v, c_t, P, scene):
    cands = language_parser(v, c_t, scene)        # 候选锚点/技能
    out = []
    for a, s, w0 in cands:
        reach = reachability(a, P)                # 目标平台可达性
        feas  = workspace_feasible(a, P)          # 工作空间/负载可行
        out.append((a, s, w0 * reach * feas))
    return normalize(out)

def ambiguity(G, tau_w):
    A = [(a, s) for a, s, w in G if w >= tau_w]
    conf = max((w for _, _, w in G), default=0)
    diam = max_dist([a for a, _ in A]) if len(A) > 1 else 0
    return A, conf, diam
```

### IP-71 XCT
```
def issue_transfer_cert(C_src, P_src, P_dst, registry, tol):
    if not passport_equiv(P_src, P_dst, tol):
        return None, 'passport-mismatch'
    eps = epsilon_trans(P_src, P_dst, registry)
    if eps == float('inf'):
        return None, 'uncalibrated'
    delta  = transfer_bound(C_src, P_src, P_dst)  # 最坏退化界
    tau_x  = cert_ttl(C_src) - calib_lag(P_dst)
    return TransferCert(P_src, P_dst, delta, tau_x, eps), 'ok'

def transfer_valid(X, P_src, P_dst, t, tol):
    if X is None:                                 return False
    if not passport_equiv(P_src, P_dst, tol):     return False
    if t > X.tau_x:                               return False
    return True
```

### 全局跨平台决策 Π_x
```
def cross_platform_decision(v, c_t, B_t, P_src, P_dst, M, Q_safe):
    X, st = issue_transfer_cert(current_cert, P_src, P_dst, registry, tol)
    G = ground(v, c_t, P_dst, scene)
    A, conf, diam = ambiguity(G, tau_w)
    if conf < tau_conf or diam > tau_diam:
        return 'reground', None                   # 要求澄清/重落地
    a_t = argmax_w(G)
    if not transfer_valid(X, P_src, P_dst, t, tol):
        return 'fail-closed', 'transfer'
    m_t, status = ecps_select(c_t, B_t, P_dst)    # 用目标平台传感器集
    P_t = pose_certify(a_t, m_t)
    if safety_bind(v, P_t, P_dst) < theta_safe(P_dst):
        return 'fail-closed', 'binding'
    return (m_t, a_t), 'execute'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PPP 护照校验 | O(\|S\|+\|K\|) | O(\|registry\|) | 护照等价+标定时效 ⇒ 迁移前提成立 |
| LIG 落地 | O(\|cands\|·\|A\|) | O(\|A\|) | conf≥τ_conf 且 diam≤τ_diam ⇒ 锚点可辨识 |
| XCT 签发/校验 | O(1) | O(1) | P_src≃P_dst 且 t≤τ_x ⇒ dist≤Δ_bound |
| Π_x 全局决策 | O(\|M\|+\|A\|) | O(\|Q\|) | 落地/迁移/绑定三重检查 ⇒ fail-closed |

正确性定理：设护照容差 tol、落地阈值 (τ_conf,τ_diam)、绑定阈值 θ_safe(P)。若 P_src≃P_dst、X 有效且 t≤τ_x，则对任意源证书 x 有 dist(x,C_dst(x))≤Δ_bound，且迁移额外失败概率 ≤ε_trans，故 C_dst 满足 soundness（1-α_p-ε_trans）。若 conf<τ_conf 或 diam>τ_diam，则锚点不可辨识，必须 re-grounding；若护照不匹配或 X 缺失/过期，则拒绝迁移并 fail-closed。三条件全部通过时 Π_x 才 execute。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 语言落地歧义 | conf 分布、diam(A) | conf≥0.9 占前 80%；diam≤5cm |
| E116 护照等价判定 | 误判率、ε_trans 估计误差 | 误判≤1%；ε_trans 误差≤20% |
| E117 迁移证书 soundness | 越界率、dist≤Δ_bound 覆盖率 | 越界率≤0.5%；覆盖率≥99% |
| E118 跨平台复用率 | 免重标定迁移比例 | 同族平台≥70%；异族强制重标定 |
| E119 重落地触发 | 触发准确率、误触发率 | 准确率≥95%；误触发≤5% |
| E120 三平台 100h 闭环 | 任务成功率、安全违例 | 成功率≥92%；违例 0 起 |

回退策略：E115 conf 不达标 → 强制交互澄清；E116 ε_trans 无法标定 → 禁止跨平台迁移，逐平台重标定；E117 越界 >1% → 收紧 Δ_bound 并提高 θ_safe(P)；E120 违例 → 全平台回退单本体 fail-closed。
