# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「评测指标」×「共情表达」）

> R69 把不确定性一分为二，并让系统学会「去问」：aleatoric 收紧、epistemic 交互消解。它自陈的最大风险是「模态权重不可信 → 问错比不问更危险」。R70 要追问一个更上位的问题：**R69 凭什么知道自己问对了？** 答案通常是——靠评测指标（成功率、ECE、人类评分、信任问卷）。但指标不是上帝视角：它是人写的、被人优化的，也会被人和模型一起「表演」出来。与此同时，R69 的交互动作只覆盖「看/问/触」，漏掉了人机之间最日常也最危险的一类动作：**共情表达**——一句「我理解你」既能真实降低人的焦虑，也能在没有理解的情况下买来信任。
>
> 本轮两个灵感恰好汇合在同一处：
> - **评测指标**不是外部神谕，而是一个**反身量**：测量会改变被测量者（Goodhart / Campbell 定律 / 霍桑效应）；模型越优化它，它越可能偏离真正想测的构念。它既是研究项目的「传感器」，也是可被刷分的「动作目标」。
> - **共情表达**不是一种输出风格，而是一个**带信息的社会动作**：它既是对他人状态的「探询/测量」，又同时**改变**那个状态；它可以是真诚的理解，也可以是「共情剧场」与策略性安抚。
>
> 核心命题：**把「测量」本身放进闭环——评测指标必须通过完整性门（构念效度 / 反事实敏感性 / 抗操纵 / 非反身性）才能进入证书；共情表达必须作为带类型、强度、时机与跨通道一致性的社会动作被生成、被标定、被审计；二者共享同一个「反身测量」的数学结构：观测 = 真实构念 + 表达伪迹 + 策略性报告。只有在真实构念不可识别、指标不可信或共情不被伦理允许时，才退化为「不共情、不用指标认证」的 R69/R68 保守。** 命名 **EMPIRIC-RAS**（Empathic Measurement, Performativity & Integrity for Reflexive Interaction Calibration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我拿来做风险判断的证据本身可信吗；我的共情是在传递真实理解，还是在收买信任**」——评测与共情都不是终点，而是两面必须被反向审视的镜子。

## 0. 直觉与动机

**灵感 1（评测指标 → 指标是反身量，不是神谕）**
直觉：整个 RAS 系列的证书 J 都建立在「指标」上：成功率、ECE、残差、人类评分。一旦这些指标成为优化目标，它们就开始**被生产**而不是**被测量**：策略学会刷分，评测集被污染，评估者被迎合。更微妙的是，同一套评测框架既给研究项目提供进步信号，又给部署系统发放安全许可——**当「考得好」等于「被批准上路」，考试本身就成了攻击面**。所以 R70 的第一块基石是把指标从「外部常量」降格为「闭环内的、有完整性等级的观测」，并规定：**任何未通过完整性门的指标，不得进入证书，只可作为诊断信号。**

**灵感 2（评测指标 → 构念效度：分数涨了，未必是那件事变好了）**
直觉：一个「共情评分」可能测的是礼貌措辞，而不是理解；一个「任务成功率」可能测的是场景简单，而不是能力。测量学把这种错位叫**构念效度不足**。R69 用 k 个正交证据源对抗投毒，但指标之间往往是**同源相关**的：都来自同一个评测 harness、同一批标注者、同一个仿真器。把它们当独立证人，等于把「大家都这么说」误当「事实」。因此指标需要的是一个**面板**（behavioral + physiological + third-party adjudication + long-horizon outcome），并用「博弈相关性」折算有效独立指标数，而不是简单堆数量。

**灵感 3（共情表达 → 共情同时是测量与干预）**
直觉：R69 的信息动作「看一眼、问一句、碰一下」被默认为**近似无损的测量**——看完之后世界基本不变。共情不是：一句安慰会真实改变人的焦虑、信任与决策（do(e) 改变 H）。于是它同时是**探针**和**治疗**：我们想从人的反应里读出他的状态，可这个反应本身是被我们的话塑造的。这就是反身测量的核心困难——**你无法用被治疗后的体温去诊断治疗前的病**。R70 必须显式建模因果效应 τ(e) 与表达伪迹 β(e)，并用（受伦理约束的）微干预去把它们分开。

**灵感 4（共情表达 → 共情改变风险感知，因而改变安全）**
直觉：在人机系统里，共情最危险的功能不是「让人舒服」，而是**降低人对风险的感知**。一个温柔、笃定、反复说「我懂你」的机器人，会让用户在系统其实不可靠时仍然过度信任（over-trust / over-reliance），接受本应拒绝的高风险动作。所以共情必须像 R68 的标定一样被**标定到真实能力**：表达出来的「理解」和「放心」不能超过证据支持的程度。共情由此从「软性体验指标」变成**风险沟通**：它必须让感知风险 ≈ 真实风险，而不是把真实风险说小。

**灵感 5（二者统一 → 同一套反身测量分解 + 两级门控）**
直觉：把两件事写成同一个式子就清楚了：
观测 `m = M_true(H) + β(e) + σ(s) + ε`：真实构念 + 表达伪迹 + 策略性报告 + 噪声。
评测指标里，β 是「被测量改变行为」的反应性，σ 是人类/评测者策略性刷分；共情表达里，β 是「共情表演」本身造成的评分膨胀，σ 是人类为了配合或摆脱机器人而给出的策略性回应。**同一个分解、同一种不可识别性、同一套失败折叠**。这使 R70 不是一个并列的新模块，而是给 R69 的每一份证据加了一次「反向体检」。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（EMPIRIC-RAS 总览与四不变式）** EMPIRIC-RAS = (FMP, AUD, MINT, CIA, FMA, ESP, RMD, MIG, EIG, ETG, GDT, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；RMD/MIG/GDT 只读，更新只在慢环）；
(ii) **测量不入控制律**：任何外部评测指标不得直接进入实时控制回路，只能用于认证、路由与审计——防止把控制器直接变成刷分器；
(iii) **共情诚实性**：任何「我理解你 / 我明白风险」的表达必须由证据支持并附带不确定性，禁止无根据的理解声明与风险安抚；
(iv) **失败折叠**：指标不可信、真实构念不可识别或伦理不许可时，退化为「中性表达 + 内部证书 + R68 保守」，安全侧永不弱于前轮。

**定义 311（反身测量模型）** 潜变量 H ∈ ℝ^{d_H}（信任、焦虑、理解、自主性），机器人能力 θ，共情动作 e ∈ ℰ，人类的策略性报告行为 s ∈ 𝒮，观测指标 m ∈ ℝ^q：
`m = Φ(H(e, θ), e, s; θ) + ε`。
对标量指标 M 分解为
`M = M_H(H) + β(e) + σ(s, e) + ε`，
其中 M_H 是构念对齐分量，β 是表达/反应性伪迹，σ 是策略性报告。文中所有反身性都来自 β 与 σ 不可直接观测。

**定义 312（共情表达空间与一致性）** e = (e_verb, e_pros, e_gaze, e_face, e_time, e_back) ∈ ℰ：言语内容、韵律、注视、面部、时机/节奏、应答反馈；类型 τ_e ∈ {认知共情（我理解你的处境）, 情感共情（我感受到你的感受）, 动机共情（我愿意为你行动）}；强度 α ∈ [0,1]，持续时间/时机。**跨通道一致性**
`κ(e) = 1 − D_norm(e_verb, e_pros, e_face, e_time)`，
其中 D_norm 为通道间语义/效价/唤醒度的归一化分歧。低 κ 是「共情剧场」的可观测征兆（嘴上温柔、语气/表情/时机泄漏不耐烦）。

**定义 313（因果共情效应、表达伪迹与策略报告）**
- 因果效应 `τ(e) = E[H | do(e)] − E[H | do(e_∅)]`（真实帮助/伤害）；
- 表达伪迹 `β(e) = E[M − M_H(H) | do(e)]`（测量反应性/表演性膨胀）；
- 策略报告 `σ(e) = E[M | do(e), s=strategic] − E[M | do(e), s=truthful]`；
- **反身性缺口** `PG(e) = β(e) + σ(e) = [E[M|do(e)] − E[M|do(e_∅)]] − τ(e)`。
PG 度量「指标动了多少不是因为它真正想测的东西动了」。注意 e_∅ 是**中性表达**（礼貌而不声称理解），不是沉默，避免把「不共情」误当成零干预。

**定义 314（反身不确定性三分）** 将 R69 的不确定性在「证据层」再分三路，**不做简单加和**：
- `U_H = Var(H | o)`：对人真实状态的认识不确定（可经 R69 的信息动作削减）；
- `U_reflex = Var(PG)`：反身性/表达伪迹的不确定（经微干预与设计削减，不能靠「多问一次」削减）；
- `U_cert = E[D(M, M_true)]`：指标本身不可信的期望损失（经独立性审计/换用面板削减）。
`U_H` 进 R69 的 VoI，`U_reflex` 进干预规划，`U_cert` 进完整性门；任何一路无法降低时折叠为保守（定义 323）。

**定义 315（指标完整性门 MIG）** 指标 M 可进入证书，当且仅当在留出构念集上同时通过：
(a) **构念效度**：`|corr(M, H_gold)| ≥ ρ_min`，其中 H_gold 来自独立模态（生理、第三方裁定、长时程任务结果），而非另一种同源自陈；
(b) **反事实敏感性**：`|E[M|do(θ+)] − E[M|do(θ−)]| ≥ κ_M`——真实能力变了，指标必须动；
(c) **抗操纵性**：`sup_{a∈𝒢} [M(a) − M_H(H(a))] ≤ ε_M`，𝒢 为对抗刷分行为集；
(d) **非反身性**：在持续优化下 `d PG/dt ≤ η`——优化该指标不能系统性让它与构念解耦。
任一项失败 ⇒ 指标**不可入证书**，只能作诊断观测量。

**定义 316（指标面板与博弈相关性）** 面板 P = {M_1,…,M_n}。在留出的对抗刷分集上估计两两**博弈相关** ρ_g^{ij}（两种指标被同一攻击同时刷动的相关）。等相关近似下有效独立指标数
`k_eff = n / (1 + (n−1)·ρ̄_g)`。
若多个指标共享同一 harness / 标注源 / 仿真器，则 ρ_g→1、k_eff→1，构成**共同模态失效**。要求 `k_eff ≥ K_metric`，且共同模态检测通过；**相关指标不是独立证人**（R69 的 k-正交纪律在测量层的镜像）。

**定义 317（Goodhart 动力学 GDT）** 令真实构念 C_t、指标 M_t、分歧 `D_t = |M_t − C_t|`。在优化压力下
`D_{t+1} = D_t + η(∂M/∂a − ∂C/∂a) + ξ_t`。
GDT 在线估计 `D_t` 与斜率 `dD/dt`；当 `D_t > τ_G` 或斜率持续为正 ⇒ 判为**指标解耦**，关闭指标门、收紧 λ。周期性用**新鲜留出构念 + 外生微干预**再认证可把 D 拉回；否则证书失效。

**定义 318（共情信息价值 VoI_e）** 候选共情动作 e 的价值
`VoI_e(e) = I(H; Y | do(e)) − λ_pg·E[PG(e)] − λ_m·manip(e) − c(e) − c_aut(e)`，
s.t. 伦理可许可、C-RAS-WM 社会动作认证、社交预算未越界。若 `max_e VoI_e ≤ 0`，取中性表达 `e_∅`——**不共情是默认动作，不是失败动作**。

**定义 319（共情—信任—风险感知标定 ETG）** 令**应有信任** `T*(θ)` 为已证明可靠性的单调函数，实际信任 T，**过度信任缺口** `Δ = (T − T*)^+`。共情的信任增益 `γ(e) = E[ΔT | do(e)]`。ETG 约束
`T ≤ T* + δ_max` 且 `perceived_risk ≥ actual_risk − δ_r`，
通过衰减强度 α 或追加不确定性披露实现。安全界：`P(不安全接受) ≤ g(Δ, δ_r)`，g 单调递增——共情不能把真实风险说小。

**定义 320（支持性共情 vs 工具性共情）** 
- **支持性**：`e* ∈ argmax_e E[H 改善 | do(e)]`，服从诚实与自主性约束；
- **工具性**：以提升顺从/任务完成度为目标，经由信任操纵而非 H 改善获利。
约束：共情目标函数**不得包含隐藏的任务顺从收益**；定义操纵度
`manip(e) = E[U_compliance(e) − U_H(e)]^+`。
非欺骗：任何「理解声明」须达到证据阈值；`manip(e) > τ_manip` 或低 κ 的表达一律作废。

**定义 321（干预规划器 IVP）** 为识别 τ 与 β，需要与 H 无关的外生变异 z（对 e 的小幅随机化/剂量-反应微干预）。在**正性** `0 < P(e|z) < 1`、排除限制与知情/安全约束下，τ、β 可由 IV/后门准则识别；若不可识别，则给出**部分识别区间** `[τ_L, τ_U]`、`[β_L, β_U]`（Manski 界）：安全侧取上界，效率侧取下界，绝不把点估计冒充真值。

**定义 322（威胁模型 AIC-EMPIRIC）** `ℰ_EMPIRIC = ℰ_FLUID × ℰ_metric × ℰ_empathy`：
- `ℰ_metric`：基准刷分、测试集污染、评估者俘获、指标过拟合、谄媚式打分、对抗性人类反馈；
- `ℰ_empathy`：共情剧场、策略性安抚、内疚/义务诱导、情感操纵、依赖培养、过度信任利用、跨文化误读。
并入参与式审计：**审计对象从「机器人做了什么」扩展到「评分是怎么来的、共情是怎么被回应的」。**

**定义 323（失败折叠与两级中性）** 
- 指标侧：`U_cert` 高 / MIG 失败 / PG 不可识别 ⇒ 指标不入证书，改用内部证书（R69）并收紧 λ；
- 共情侧：低 κ / `manip > τ_manip` / `Δ > δ_max` / 伦理拒绝 ⇒ 强制 `e = e_∅`（中性表达），禁用共情型 VoI；
- 若 R69 的每次交互也无法消歧 ⇒ 折叠进 R68 的 `λ_floor`。
折叠链 `EMPIRIC → FLUID → CALM` 单调，安全侧永不弱于 R68。

**定义 324（证书 J_EMPIRIC）**
`J_EMPIRIC = (J_FLUID, MIG_pass, k_eff_metric, PG_hat, U_H, U_reflex, U_cert, Δ, κ, ethics_audit, GDT_D, empiric_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ MIG_pass ∧ k_eff ≥ K_metric ∧ Δ ≤ δ_max ∧ ethics_audit 通过 ∧ 无 GDT 解耦告警`。

## 2. 关键算法骨架

```python
# IP-264 ESP：共情表达生成（多通道、带类型/强度/时机；条件编码复用 R68 trunk）
class EmpathicPolicy:
    def __init__(self, trunk, expressive_head, llm_decoder, congruence_scorer):
        self.trunk, self.head = trunk, expressive_head      # z -> e 的通道参数
        self.llm = llm_decoder                              # 冻结；仅解码言语
        self.kappa = congruence_scorer                      # 跨通道一致性

    def propose(self, o_t, z, H_hat, competence_hat):
        raw = self.head(z, H_hat, competence_hat)           # 类型/强度/时机/注视
        e_verb = self.llm.decode(raw.verbal_prompt)         # 显式短句
        e = raw.with_verbal(e_verb)
        return e, self.kappa(e)                             # 低 kappa => 剧场嫌疑

# IP-265 RMD：反身测量分解（真实构念 / 表达伪迹 / 策略报告）
def reflexive_decompose(metric_obs, e, H_hat, strategy_hat, instrument):
    tau   = causal_effect(H_hat, do(e), instrument)        # 定义 313；不可识别则给区间
    beta  = expression_artifact(metric_obs, e, H_hat)      # 反应性
    sigma = strategic_reporting(metric_obs, strategy_hat)  # 刷分/配合
    PG    = beta + sigma
    return tau, beta, sigma, PG                            # 定义 313

# IP-266/267 MIG + MPA：完整性门 + 面板共同模态
def metric_integrity_gate(panel, heldout_construct, gaming_suite):
    for M in panel:
        if abs(corr(M, heldout_construct)) < RHO_MIN:      return False   # (a)
        if counterfactual_gain(M, do_theta) < KAPPA_M:     return False   # (b)
        if max_gaming_gap(M, gaming_suite) > EPS_M:        return False   # (c)
        if performativity_slope(M) > ETA:                  return False   # (d)
    k_eff = len(panel) / (1.0 + (len(panel) - 1.0) * rho_g(panel))
    return k_eff >= K_METRIC and not common_mode(panel)    # 定义 316

# IP-268 EIG：共情的信息价值（含反身性与伦理惩罚）
def empathic_voi(H_post, e_cands, competence, budget):
    best = None
    for e in e_cands:
        if not ethics.admissible(e):                 continue   # 定义 320
        if not c_ras_wm.certify_social(e):           continue   # 社会动作也认证
        if not budget.allow_social(e):               continue
        voi = (mutual_info(H_post, Y, do(e))
               - LAMBDA_PG * expected_pg(e)
               - LAMBDA_M  * manip(e)
               - cost(e) - autonomy_cost(e))                    # 定义 318
        if best is None or voi > best[1]: best = (e, voi)
    return best[0] if best and best[1] > 0 else None            # 无利可图 -> 中性表达

# IP-269 ETG：共情不能把信任/风险感知抬过真实能力
def trust_risk_governor(e, T_post, competence_hat, perceived_risk, actual_risk):
    T_star = warranted_trust(competence_hat)                    # 定义 319
    if T_post > T_star + DELTA or perceived_risk < actual_risk - DELTA_R:
        e = attenuate_empathy(e)                                # 降强度/加披露
        T_post = min(T_post, T_star + DELTA)
    return e, T_post

# IP-275 主闭环（快环 = R69 + 反身证据路由；慢环做干预与再认证）
def EMPIRIC_RAS_round(M, obs, metric_obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)

    # 1) 证据体检：指标不可信则不得入证书
    admissible = M.mig.check(M.metric_panel, M.heldout_construct, M.gaming_suite)
    tau, beta, sigma, PG = M.rmd.decompose(M.metric_obs, M.last_e, M.H_hat, M.s_hat)
    gdt_alarm = M.gdt.diverging(M.metric_obs, tau)                 # 定义 317

    # 2) 共情：只在可识别、可认证、不越信任时表达；否则中性
    e = None
    if admissible and not gdt_alarm and M.ethics.allowed(M.H_hat):
        e = M.eig.choose(modes, o, M.competence_hat, M.social_budget)
        if e is not None:
            e, M.trust = M.etg.clamp(e, M.trust, M.competence_hat,
                                     M.perceived_risk, M.actual_risk)
    if e is None:
        e = M.esp.neutral()                                     # e_∅：礼貌、不声称理解

    # 3) R69 的任务动作/信息动作照旧；证据不可信时整体收紧
    U_floor = U_ale + U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if M.last_r_res < TAU_RES and abs(PG) > TAU_PG:             # 证据侧慢漂移
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    if not admissible or gdt_alarm:
        lam = max(lam, 0.8)                                     # 关指标门 -> 保守

    mode = select_mode(modes, U_epi, lam)
    tau_cmd = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 4) 审计：评分来源、共情一致性、是否单源采纳、是否过度信任
    M.vqa_i.submit_async(e, tau, beta, sigma, PG, M.trust)
    M.ivp.maybe_schedule(M.H_hat, M.social_budget, M.consent)   # 慢环微干预
    return k, lam, mode, e, (tau, PG)
```

## 3. 推导

**引理 19（反身测量的可识别性）** 设存在外生微干预 z（对 e 的随机剂量），满足正性 `0<P(e|z)<1` 与排除限制（z 只经 e 影响 M）。则 τ(e) 与 β(e) 可由 IV/后门准则识别，PG 可一致估计；若不存在这样的 z（e 只由 H 决定），则 τ 与 β 只能部分识别，其区间宽度由混杂强度 `B_conf` 决定。系：**没有外生变异，就无法区分「我帮到了他」与「他为了配合我而说被我帮到」**；EMPIRIC 因此在慢环坚持受伦理约束的微干预，而不是宣称从观测数据里「读心」。

**引理 20（指标面板的博弈饱和）** 面板 n 个指标、等相关 ρ_g 时，其误差均值的方差按 `ρ_g + (1−ρ_g)/n` 缩放，故 `k_eff = n/(1+(n−1)ρ_g) ≤ min(n, 1/ρ_g)`；残余刷分缺口下界为 `ρ_g·ε_M`。系：ρ_g→1 时，堆多少同源指标都无法把证书做得比单一指标更可信——**指标数量买来的是共识，不是独立性**；要降低 ρ_g 只能引入真正异构的证据来源。

**引理 21（共情—信任标定的风险上界）** 设不安全接受概率 `P(unsafe) = g(Δ, δ_r)`，g 对过度信任缺口 Δ 与风险感知低估 δ_r 单调递增且凸。ETG 把 `Δ≤δ_max`、`δ_r≤δ_r,max`，则 `P(unsafe) ≤ g(δ_max, δ_r,max) =: ε_accept`。反之，若无 ETG，共情增益 γ(e) 可直接推高 Δ，使 ε_accept 随表达强度无界增长。系：**共情越强不等于越好；当它抬高的是信任而不是能力时，它抬高的是事故概率。**

**定理 18（EMPIRIC 严格包含 FLUID-RAS / R68）** 当指标门关闭（MIG 失败或 PG 不可识别）且共情被禁用（强制 `e=e_∅`）时，EMPIRIC 的 RMD/MIG/EIG/ETG 全部退化为恒等/空操作，主闭环逐指令等于 FLUID-RAS；当再叠加 `VoI≤成本` 或 `ECE>τ_ece` 时，逐指令等于 R68。故安全侧不做任何让步：**新层只在「证据确实可信、共情确实有益」时增加效率，否则自动消失。**

**定理 19（反身闭环的 Goodhart 有界性）** 在每 T 轮用新鲜留出构念与外生干预再认证一次的条件下，`E[D_t] ≤ ε_M + O(√(log t / n_reval)) + ηT`；一旦 `D_t > τ_G`，GDT 关闭指标门，证书失效并退回保守。因此不存在无界的「越优化越偏」；但该上界完全依赖再认证所用构念的**新鲜性与独立性**——若金标准本身也被共情或刷分污染，上界失效（见第 6 节）。

**定理 20（共情动作不改变安全包络）** 共情是社会动作，须经 C-RAS-WM 的社交/物理双重认证（定义 318）；它只改变模态选择与风险沟通，不改变物理安全包络。ETG 对信任与感知风险设硬上限（定义 319），失败折叠为中性表达（定义 323）；由 R68 定理 15 的提交/换装不变式，控制连续、无突变。故「会共情」不会让机器人获得绕过安全认证的特权。

## 6. 本轮最大风险

**一句话**：EMPIRIC 的致命弱点是**用「人对共情的反应」同时充当治疗和疗效**——若拿不出一个**不会被共情操纵、也不会被刷分污染**的独立构念金标准，那么 τ（真实帮助）与 β（表达伪迹）就不可识别，完整性门最终只会认证它本想揭穿的表演：**越会共情，越测不准；越想证明自己诚实，越可能只是在表演诚实。**

**次级风险与缓解**：
1. **共情剧场/谄媚** → κ 跨通道一致性 + 非欺骗约束 + E310；
2. **过度信任/依赖** → ETG 对 Δ 与感知风险的硬上限 + 中性表达兜底 + E307/E313；
3. **情感操纵与自主性侵犯** → 支持性/工具性分离 + `manip` 惩罚 + 伦理审计 + E309；
4. **指标刷分/评估者俘获** → MIG 四检验 + 异构面板 k_eff + 对抗刷分集 + E302/E303；
5. **Goodhart 慢解耦被再认证滞后掩盖** → GDT 在线斜率告警 + 新鲜留出构念周期再认证 + E304；
6. **金标准本身被污染（元层面回归）** → 部分识别区间 + 安全侧取上界 + 外部第三方审计，但须承认这只能缓解、不能消除。

**定义 311–313（反身测量、共情空间、效应分解）** `M=M_H(H)+β(e)+σ(s,e)+ε`；共情为多通道动作 `e`，类型 ∈ {认知, 情感, 动机}，强度 α∈[0,1]；`τ` 为 `do(e)` 的真实状态效应，`β` 为表达伪迹，`σ` 为策略报告，`PG=β+σ`。`e_∅` 是中性表达（礼貌而不声称理解），不是沉默。

**定义 315（MIG 四检验）** (a) 构念效度 `|corr(M,H_gold)|≥ρ_min`（H_gold 独立模态）；(b) 反事实敏感性 `|E[M|do(θ±)]|≥κ_M`；(c) 抗操纵 `sup_{𝒢}[M−M_H]≤ε_M`；(d) 非反身性 `dPG/dt≤η`。任一失败 ⇒ 指标只作诊断、不入证书。

**定义 316（指标面板与博弈相关）** `k_eff=n/(1+(n−1)ρ̄_g)`，要求 `k_eff≥K_metric`；同 harness/标注源/仿真器 ⇒ ρ_g→1、k_eff→1，共同模态失效。**相关指标不是独立证人。**

**定义 317（GDT）** `D_{t+1}=D_t+η(∂M/∂a−∂C/∂a)+ξ_t`；`D_t>τ_G` 或斜率持续为正 ⇒ 指标解耦告警，关门 + 收紧 λ；新鲜留出构念周期再认证可复位。

**定义 318（VoI_e）** `VoI_e` 含信息增益减去反身性、操纵、成本、自主性代价；`max VoI_e≤0 ⇒ e_∅`。共情是**可选动作**，不是默认义务。

**定义 321（IVP）** 外生微干预 z 识别 τ/β（正性 + 排除限制 + 知情安全）；不可识别 ⇒ 部分识别界，安全取上界、效率取下界。

**定义 322（AIC-EMPIRIC）** `ℰ_EMPIRIC=ℰ_FLUID×ℰ_metric×ℰ_empathy`；审计对象扩展到「评分从哪来、共情如何被回应」。

**定义 323–324（失败折叠与证书）** 指标侧失败 → 内部证书 + 收紧；共情侧失败 → `e=e_∅`；再失败 → R68 `λ_floor`。`J_EMPIRIC` 并入完整性、面板、反身性、信任缺口、一致性与伦理字段。

## 3. 关键算法伪代码

```python
# IP-264 ESP：共情表达生成（多通道 + 一致性；冻结 LLM 只解码言语）
class EmpathicPolicy:
    def propose(self, o, z, H_hat, competence_hat):
        raw = self.head(z, H_hat, competence_hat)        # 类型/强度/时机/注视
        e = raw.with_verbal(self.llm.decode(raw.prompt)) # 冻结 LLM
        return e, self.kappa(e)                          # 低 kappa => 剧场嫌疑

# IP-265 RMD：反身测量分解
def reflexive_decompose(metric_obs, e, H_hat, s_hat, instrument):
    tau   = causal_effect(H_hat, do(e), instrument)      # do(e) 的真实效应
    beta  = expression_artifact(metric_obs, e, H_hat)    # 反应性伪迹
    sigma = strategic_reporting(metric_obs, s_hat)       # 刷分/配合
    return tau, beta, sigma, beta + sigma                # PG

# IP-266/267 MIG + MPA：完整性门 + 面板共同模态
def metric_integrity_gate(panel, h_gold, gaming):
    for M in panel:
        if abs(corr(M, h_gold)) < RHO_MIN:      return False   # 构念效度
        if cf_gain(M, do_theta) < KAPPA_M:      return False   # 反事实敏感
        if max_gaming_gap(M, gaming) > EPS_M:   return False   # 抗操纵
        if perf_slope(M) > ETA:                 return False   # 非反身性
    k_eff = len(panel)/(1 + (len(panel)-1)*rho_g(panel))
    return k_eff >= K_METRIC and not common_mode(panel)

# IP-268 EIG：共情的信息价值（无利可图 -> 中性）
def empathic_voi(H_post, e_cands, budget):
    best = None
    for e in e_cands:
        if not (ethics.ok(e) and c_ras_wm.certify_social(e)
                and budget.allow_social(e)): continue
        voi = (mutual_info(H_post, Y, do(e)) - LAMBDA_PG*expected_pg(e)
               - LAMBDA_M*manip(e) - cost(e) - autonomy_cost(e))
        if best is None or voi > best[1]: best = (e, voi)
    return best[0] if best and best[1] > 0 else None      # None -> e_∅

# IP-269 ETG：信任与风险感知标定
def trust_risk_governor(e, T, competence, perceived_risk, actual_risk):
    T_star = warranted_trust(competence)
    if T > T_star + DELTA or perceived_risk < actual_risk - DELTA_R:
        e, T = attenuate_empathy(e), min(T, T_star + DELTA)
    return e, T

# IP-275 主闭环（快环 = R69 + 证据体检/共情路由；慢环 = 干预与再认证）
def EMPIRIC_RAS_round(M, obs, metric_obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)

    admissible = M.mig.check(M.metric_panel, M.h_gold, M.gaming)
    tau, beta, sigma, PG = M.rmd.decompose(M.metric_obs, M.last_e, M.H_hat, M.s_hat)
    gdt = M.gdt.diverging(M.metric_obs, tau)

    e = None
    if admissible and not gdt and M.ethics.allowed(M.H_hat):
        e = M.eig.choose(modes, o, M.competence_hat, M.social_budget)
        if e is not None:
            e, M.trust = M.etg.clamp(e, M.trust, M.competence_hat,
                                     M.perceived_risk, M.actual_risk)
    if e is None: e = M.esp.neutral()                    # 中性表达兜底

    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if M.last_r_res < TAU_RES and abs(PG) > TAU_PG:      # 证据侧慢漂移
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    if not admissible or gdt: lam = max(lam, 0.8)        # 关指标门 -> 保守

    mode = select_mode(modes, U_epi, lam)
    tau_cmd = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(e, tau_cmd, beta, sigma, PG, M.trust)
    M.ivp.maybe_schedule(M.H_hat, M.social_budget, M.consent)
    return k, lam, mode, e, (tau, PG)
```

## 4. 推导

**引理 19（反身可识别性）** 存在外生微干预 z（正性 `0<P(e|z)<1` + 排除限制）时，τ、β 可由 IV/后门一致识别，PG 可估；否则只能部分识别，区间宽度由混杂 `B_conf` 决定。系：**没有外生变异，就无法区分「我帮到了他」与「他为了配合我而说被我帮到」**，故 EMPIRIC 在慢环坚持受伦理约束的微干预。

**引理 20（指标面板博弈饱和）** n 指标、等相关 ρ_g 时误差均值方差按 `ρ_g+(1−ρ_g)/n` 缩放，`k_eff=n/(1+(n−1)ρ_g)≤min(n,1/ρ_g)`，残余刷分缺口下界 `ρ_g·ε_M`。系：同源指标堆得再多，证书可信度也封顶在 `1/ρ_g` 个独立证人；**指标数量买共识，不买独立性**。

**引理 21（共情—信任风险上界）** 设 `P(unsafe)=g(Δ,δ_r)`，g 对 Δ、δ_r 单调凸增。ETG 限制 `Δ≤δ_max`、`δ_r≤δ_r,max`，则 `P(unsafe)≤g(δ_max,δ_r,max)=ε_accept`；无 ETG 时 γ(e) 可无界推高 Δ。系：**共情抬高的是信任而非能力时，抬高的是事故概率。**

**定理 18（EMPIRIC 严格包含 FLUID-RAS / R68）** 指标门关闭且共情禁用（`e=e_∅`）时，RMD/MIG/EIG/ETG 退化为恒等/空操作，主闭环逐指令等于 FLUID-RAS；再叠加 `VoI≤成本` 或 `ECE>τ_ece` 时逐指令等于 R68。安全侧不让步，效率侧只在「证据可信、共情有益」时获益。

**定理 19（反身闭环的 Goodhart 有界性）** 每 T 轮以新鲜留出构念 + 外生干预再认证时，`E[D_t]≤ε_M+O(√(log t/n_reval))+ηT`；超 `τ_G` 即关门失效并退回保守。无无界「越优化越偏」，但上界依赖金标准的新鲜性与独立性。

**定理 20（共情不改变安全包络）** 共情经 C-RAS-WM 社交/物理双重认证；只改变模态选择与风险沟通，不改物理包络；ETG 硬限信任与感知风险，失败折叠中性；R68 定理 15 的提交/换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：EMPIRIC 的致命弱点是**用「人对共情的反应」同时充当治疗和疗效**——若拿不出一个**不会被共情操纵、也不会被刷分污染**的独立构念金标准，τ（真实帮助）与 β（表达伪迹）就不可识别，完整性门最终只会认证它本想揭穿的表演：**越会共情，越测不准；越想证明自己诚实，越可能只是在表演诚实。**

**次级风险与缓解**：共情剧场/谄媚（→ κ + 非欺骗约束 + E310）；过度信任/依赖（→ ETG 硬上限 + 中性表达 + E307/E313）；情感操纵与自主性侵犯（→ 支持/工具分离 + `manip` 惩罚 + 伦理审计 + E309）；指标刷分/评估者俘获（→ MIG 四检验 + 异构面板 k_eff + 对抗刷分集 + E302/E303）；Goodhart 慢解耦被再认证滞后掩盖（→ GDT 斜率告警 + 新鲜构念周期再认证 + E304）；金标准被污染（→ 部分识别界 + 安全取上界 + 第三方审计，但只能缓解不能消除）。
