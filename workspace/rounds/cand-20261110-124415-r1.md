# 第 44 轮（新循环第 4 轮） · ActionSpace-Cert × IMU-Cert：把「证书的作用域」与「新鲜度的物理见证」纳入可验证闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈的最大风险「共形边际覆盖 + 多用户契约空集」仍是统计与协商层面的风险，但它底下还压着两个更基础的假设：**(H3) 动作空间被当作给定且已被证书覆盖的集合**——所有定理都写 ∀a∈A，实际上却只在采样点/网格上验证过，抽象证书动作与连续执行动作之间存在未建模的偏差；**(H4) 新鲜度只按墙钟时间线性衰减**——λ=L_m·v_max 恒取最大速度，忽略机器人大多数时间其实很慢甚至静止，且 v_max 由同一套（可能故障的）感知栈估计。本轮灵感词「动作空间」把证书从「标量结论」提升为「有作用域的映射」；「惯性测量单元」把新鲜度从「时间猜测」提升为「运动实测的物理见证」。二者耦合处是全新的问题：证书在动作空间上是否真的覆盖了被执行的动作，而 IMU 是独立见证这一覆盖是否被现实兑现的唯一通道。

## 0. 直觉与动机

**灵感 1（动作空间 → 证书不是数，而是「作用域上的映射」）**：直觉上，「证书通过」从来不是绝对命题，而是「在你实际会做的动作范围内通过」。今天所有 "∀a∈A" 的定理都有一个未言明前提：A_exec ⊆ A_cert。一旦底层控制器饱和、打滑、或存在未建模的连续残差，执行动作掉出被认证的网格，证书再 sound 也无济于事。因此引入动作空间分层（skill / control）与**动作空间证书图谱**：用网格认证 + margin 的 Lipschitz 外推，把有限采样提升为整片连续域的保证；并诚实标注「未认证边界」，运行时绝不允许越界。这里有个关键 rigor 点——经验差分估计出的 Lipschitz 常数只是**下界**，把它当上界用会静默高估 margin，必须从证书结构导出可证上界。

**灵感 2（IMU → 新鲜度的物理见证，而不只是一个状态传感器）**：v20 的租约用 λ=L_m·v_max 覆盖最坏速度，天然保守：静止时也按最大速度衰减，租约白白过期、可用性崩塌。IMU 给出高频加速度/角速度，可把「时间衰减」换成**运动预算衰减**：W=∫v_max(s)ds，静止时 W≈0、租约不必续期，剧烈运动才快速过期；并且只在可信关键帧锚定速度、只做一次积分，避免双积分漂移。更强的是把 IMU 当**独立见证通道**：它与视觉/LIO 分属不同失效模式，用 min 组合，只要任意一路是有效下界，min 仍 sound——被污染的那一路只会让结果更保守，绝不会更高。但真正的残余风险不是独立噪声，而是**共模误差**（共享时钟、坐标系、标定 id）。

**灵感 3（耦合 → 动作空间一致性证书 ACS）**：给定命令动作 a∈A_cert，动力学模型预言运动集 P(a)；若 IMU 实测增量 Δ̂ 落在 P(a)⊕误差球之外，就说明「你以为你做的动作」与「物理上真正发生的动作」已经分裂（打滑、饱和、控制 bug、重放攻击）。这把 v20 的 sim-to-real 缝隙变成可在线检测的**动作空间一致性违约**：违约即撤销证书、单调降级或安全停机。IMU 由此同时是新鲜度的见证与动作空间覆盖的现实见证。

**耦合升级**：ASCA（动作空间图谱）负责「证书覆盖到哪、边界在哪、控制包络 E 是什么」；IFW（IMU 新鲜度见证）负责「运动预算是否够新鲜、哪路见证可信」；ACA（动作一致性审计器）负责「实际执行有没有掉出被认证的动作空间」。四层架构由此从 v8 的「人格契约 + 并发证书」升级为 v9 的「+ 动作空间作用域层 + IMU 物理见证层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（证书作用域与动作空间覆盖）**：证书是对动作空间的部分映射 C: A ⇀ ({valid,invalid}, ℝ)，定义域 dom(C)=A_cert⊆A。**覆盖前提**：定义 38–43 中任一 sound 性定理都隐含 A_exec⊆A_cert，其中 A_exec 为运行时实际执行的动作集。若 A_exec⊄A_cert，则存在动作 a 使 C 无定义——此时「证书通过」推不出不变式保持（证书空洞）。**命题（作用域引理）**：若 A_exec⊆A_cert 且 ∀a∈A_cert，C(a).valid ∧ margin(a)≥θ(a)，则任意执行序列保持 I。**推论**：动作空间覆盖不是工程细节，而是所有安全定理的显式前置条件；v8 恰恰漏掉了它。

**定义 45（Lipschitz 证书与网格外推）**：设动作空间带度量 d_A，margin 函数 m: A→ℝ 关于 d_A 是 L_A-Lipschitz：|m(a)−m(a')| ≤ L_A·d_A(a,a')。对覆盖半径 ρ 的网格 G，认证 a 的下界取 m̃(a)=m(g(a))−L_A·ρ。**外推定理**：若 L_A 是可证上界（由证书结构或区间雅可比导出），则 m̃ 是 m 在全域的有效下界。**警告（关键 rigor 点）**：从样本差分估计出的 Lipschitz 常数只是**下界**，误当上界会静默高估 margin；必须用结构导出上界，否则用在线一致性监测兜底（定义 47）。网格凸包之外为**未认证区**，禁止外推。

**定义 46（IMU 运动预算与新鲜度衰减）**：租约由 (m,τ,λ,κ) 升级为 (m,τ,W,κ)，W 为自 τ 起的**认证运动预算**：在可信关键帧以速度 v(τ)±e_v 锚定，IMU 区间加速度 a_s∈[a_lo,a_hi]、保证偏置 b∈[b_lo,b_hi]，令 v_max(s)=min(v_phys, ‖v(τ)‖+e_v+∫_τ^s(‖a‖+b_max)dr)，W(t)=∫_τ^t v_max(s)ds。**新鲜度判据**：m−L_x·W(t)≥θ。**命题（严格优于时间衰减）**：因 v_max(s)≤v_max，有 W(t)≤v_max·(t−τ)，故运动预算衰减对时间衰减**逐点不更保守**；静止时 W≈0，租约可长期有效。**sound 条件**：W 必须是真实位移的**上界**——要求 IMU 偏置/漂移被保证界覆盖、锚点速度可信，且只做一次积分（不双积分）以抑制漂移。

**定义 47（动作空间一致性证书 ACS）**：命令 a_t∈A_cert，动力学给出预言运动集 P(a_t)={Δ=f_motion(x,a_t,w): w∈Ω}；IMU 实测增量 Δ̂_t 带误差球 E_imu。**一致性残差** r_t=dist(Δ̂_t⊕E_imu, P(a_t))。**一致性判据**：r_t=0 表示实际执行仍落在被认证动作的预言包络内。**定理（契约传递）**：若 ∀t 一致性成立且 C 在 A_cert 上 sound，则闭环保持 I；反之 r_t>0 表明 a_t 未被物理兑现，证书**立即失效**，必须降级/停机。**注**：P 过宽→漏检（危险），过窄→误报（保守）；P 必须覆盖执行器饱和与打滑的物理模型。

**定义 48（独立见证与 min 组合的 sound 性）**：视觉下界 m_v、IMU 下界 m_i，取 m=min(m_v,m_i)。**命题**：只要至少一路是真实 margin 的有效下界，min 即为有效下界（min ≤ 有效下界 ≤ 真值）。**推论**：被污染或高估的一路只能把结果拉保守，绝不会使其偏高；因此独立见证的失真方向是**安全偏置**。**但**：若两路共享共模误差（同一时钟、坐标系、标定 id、同一状态估计），min 便失去意义——残余风险从「独立传感器噪声」转移到**共模故障**，必须专门监测。

**定义 49（双时间尺度动作空间精化与执行合约）**：技能层 a∈A_skill 的证书导出**控制包络** E(a)⊆A_control，满足：∀u∈E(a)，控制层证书保持技能层不变式。**assume-guarantee 组合**：技能层假设「u 保持于 E(a)」，控制层保证「u∈E(a) ∨ safe_stop」，则联合系统保持 I。**定理（精化可靠性）**：若控制器因饱和/扰动无法保持 u∈E(a)，必须向上发起**重认证请求**或安全停机，绝不允许静默越出 E。此即抽象动作与物理动作之间的桥。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 ACTION-SPACE-CERT-ATLAS（动作空间证书图谱 ASCA）
1. **动作空间分层与度量**：A_skill（技能/语义动作）与 A_control（底层连续控制），定义 d_A、覆盖半径 ρ，维护 A_cert 与未认证前沿；越界动作运行时直接拒绝。
2. **可证 Lipschitz 外推**：由证书结构/区间雅可比导出 L_A 上界；把网格 margin 外推为全域下界；在线一致性监测发现 L_A 被低估即收缩 cell 并重颁。
3. **控制包络导出**：每个 cell/技能导出 E(a)⊆A_control，供低层控制器与定义 49 的精化合约使用。
4. **与人格契约协同**：Π_u 的个性化扩张必须整体落在 A_cert 内部；未认证区不做「个性化试错」。

### 2.2 IP-61 IMU-FRESHNESS-WITNESS（IMU 新鲜度见证 IFW）
1. **运动预算租约 (m,τ,W,κ)**：一次积分 + 关键帧速度锚定；W 是认证位移上界，替代墙钟时间衰减。
2. **偏置/漂移保证界**：偏置观测器 + 区间界；长时程误差预算与重标定触发；靠视觉关键帧重锚定抑制漂移。
3. **独立见证 min 组合 + 共模监测**：min(m_v,m_i)；分歧→保守 + 告警；持续监测共享时钟/坐标系/标定 id。
4. **静态免续期 / 动态加速过期**：静止 W≈0 免续期，剧烈运动快速过期；用便宜续期替代昂贵重查。

### 2.3 IP-62 ACTION-CONFORMANCE-AUDITOR（动作一致性审计器 ACA）
1. **动作-运动预言集 P(a)**：动力学 + 执行器/摩擦不确定性；实时计算残差 r_t。
2. **违约分类**：打滑、饱和、控制/模型失配、IMU 欺骗/重放、时间戳错配。
3. **违约即撤销证书**：触发单调降级/安全停机，反例回灌 CKB/SCV。
4. **对抗鲁棒**：跨源校验（轮/腿里程计、视觉）与物理可行性（|a|≤执行器上限）。

## 5. 本轮最大风险

**一句话**：用 IMU 积分给「新鲜度」当物理见证，一旦偏置/漂移被低估、或与感知共享时钟/坐标系的共模误差未被覆盖，运动预算就会**少报位移**，使物理上已陈旧的租约被判新鲜——直接击穿 v20「绝不误用陈旧边际」的底线；因此 E97（W 的 sound 性）与 E99（共模故障）必须设为红线实验，默认回退到墙钟时间衰减的保守租约。

## 2. 关键算法（伪代码）

### IP-60 ASCA：动作空间图谱与 Lipschitz 外推
```
def certify_action_space(A, grid_rho, cert_struct):
    G = cover(A, grid_rho)                        # 网格，覆盖半径 rho
    L_A = certified_lipschitz_upper(cert_struct)  # 结构/区间雅可比；非经验差分
    atlas = {}
    for g in G:
        m_g = margin_at(g)                        # 网格点认证
        atlas[cell(g)] = CertCell(m_lo=m_g - L_A*grid_rho,
                                  E=export_envelope(g),
                                  valid=(m_g - L_A*grid_rho > 0))
    frontier = A - in_hull(G)                     # 凸包外 = 未认证区
    return Atlas(cells=atlas, L_A=L_A, frontier=frontier)

def select_cell(atlas, a):
    c = atlas.cell_of(a)
    if c is None or a in atlas.frontier:
        return REJECT_OUT_OF_SCOPE                # 越界绝不放行
    return c

def monitor_lipschitz(atlas, samples):
    # 在线证伪：实测 margin 落差超过 L_A 预测 => 上界被低估
    for a, a_, m_a, m_a_ in samples:
        if abs(m_a - m_a_) > atlas.L_A * d_A(a, a_) + tol:
            return shrink_and_recertify(atlas, a, a_)
    return atlas
```

### IP-61 IFW：运动预算、独立见证与续期策略
```
def motion_budget(imu, anchor, t):
    # 只在可信关键帧锚定速度，避免双积分漂移
    v_hi = norm(anchor.v) + anchor.e_v
    W, s = 0.0, anchor.t
    while s < t:
        a_lo, a_hi, b_hi = imu.interval(s)        # 保证界
        v_hi = min(V_PHYS, v_hi + max(abs(a_lo), abs(a_hi))*dt + b_hi*dt)
        W   += v_hi * dt
        s   += dt
    return W                                      # 认证位移上界

def lease_valid_ifw(lease, theta, t, m_vision):
    W   = motion_budget(lease.imu, lease.anchor, t)
    m_i = lease.m - lease.L_x * W                 # IMU 见证下界
    m   = min(m_vision, m_i)                      # 独立见证 min 组合
    if common_mode_alert(lease):
        m = min(m, SAFE_CAP)                      # 共模告警 => 保守化
    return (m >= theta), m

def renew_policy(lease, t):
    if motion_budget(lease.imu, lease.anchor, t) < eps_static:
        return KEEP                               # 静止免续期
    return RENEW if lease_valid_ifw(lease, ...) else DOWNGRADE
```

### IP-62 ACA：动作一致性残差与违约处理
```
def conformance_residual(a, x, imu_delta):
    P    = predicted_motion_set(x, a)             # 含饱和/打滑不确定性
    Eimu = imu_error_ball(imu_delta)
    return dist(imu_delta, P) - Eimu.radius       # >0 => 违约

def action_conformance_guard(a, x, imu_delta, delta_a):
    r = conformance_residual(a, x, imu_delta)
    if r > delta_a:
        cls = classify_breach(a, x, imu_delta)     # slip/saturation/model/spoof/clock
        return VoidCertificate(cls), downgrade_or_safestop(cls)
    return OK, None
```

### 定义 49 双时间尺度精化
```
def skill_to_control_refine(skill_cert, a_skill):
    return skill_cert.envelope(a_skill)           # E(a) ⊆ A_control

def control_step(u, E, a_skill, x, imu_delta):
    if u not in E:                                # 底层包络违约
        return request_recertification(a_skill) or safe_stop()
    ok, _ = action_conformance_guard(a_skill, x, imu_delta, delta_a)
    return commit(u) if ok else safe_stop()
```

def car_transition_guard_v2(e, x, cert_obj, persona, lease, m_vision, t):
    theta   = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| IMU 偏置/漂移被低估 → 运动预算少报位移 → 陈旧租约被判新鲜 | 高 | E97/E101 红线；区间保证界 + 偏置观测器；关键帧重锚；默认回退墙钟衰减 |
| 共模误差（共享时钟/坐标系/标定 id）→ min 组合失效 | 高 | E99 红线；共模监测；跨源 timestamp/frame 校验；共模告警即保守化 |
| 经验 Lipschitz 当上界 → margin 静默高估 | 高 | E96 红线；结构/区间雅可比导出上界；在线证伪即收缩并重颁 |
| P(a) 过宽→打滑/饱和漏检；过窄→误报 | 中-高 | E98 红线；饱和/摩擦物理模型；在误报预算内调 δ |
| 动作空间网格凸包外推越界 | 中 | 凸包外标未认证；运行时越界即拒；E95 |
| 双时间尺度 E-包络与技能证书错配 | 中 | IP-47 组合检查；E100；越出 E 必停机或向上重认证 |
| IMU 欺骗/重放 | 中 | 跨源物理可行性校验；E102；安全任务多源冗余 |

## 6. 本轮最大风险

**一句话**：用 IMU 积分给「新鲜度」当物理见证，一旦偏置/漂移被低估、或与感知共享时钟/坐标系的共模误差未被覆盖，运动预算就会**少报位移**，使物理上已陈旧的租约被判新鲜——直接击穿 v20「绝不误用陈旧边际」的底线；因此 E97（W 的 sound 性）与 E99（共模故障）必须设为红线实验，默认回退到墙钟时间衰减的保守租约。
