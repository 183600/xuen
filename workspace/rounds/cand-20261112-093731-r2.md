# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；灵感循环第 4 轮；本轮灵感：「模型预测控制」×「LoRA」）

> 第 57 轮把安全赌注从"模型置信"移到"证据质量"，又移到"先验质量"——元推断器从历史语料摊销先验，一旦语料有系统性盲区，坏先验就会普遍化；更根本的病灶是：**承诺始终是检查点上的一个一次性 yes/no，而一次承诺要覆盖未来一整段执行**。局部证据界定不了未来，模型误差沿时间累积，而现有框架既没有"这次承诺还能安全多久"这个对象，也没有"承诺后环境偏离怎么办"的闭环比。本轮两个灵感各补一刀：**模型预测控制（MPC）**把承诺从"一次性誓言"变成"滚动契约"——约束按误差界逐时收紧、只承诺一条鲁棒管、只执行第一步、出管即重规划、不可逆接触必须落入终端不变集；**LoRA**把适配从"重写权重"变成"有界低秩镜头"——冻结已认证基座，只学秩 r、范数 ≤ε_A 的增量，按区域路由、经影子校准才准入证据路径、秩与范数成为可审计预算。核心命题由"证据说可信"升级为 **"滚动可递归可行、适配有界、证据有时界的承诺"**：效率交给适配，安全交给管与不变集；准度可以学，稳健必须证。

核心矛盾：
- **H29（一次性承诺 vs 有限预测视界）**：第 56/57 轮把承诺建模为检查点上的一个瞬时判定，但它对应未来 H 步执行；模型误差沿时间累积，局部证据无法界定未来。缺少"承诺有效期"对象，也缺少偏离后的在线闭环，导致"局部正确、累积错误"。
- **H30（在线适配 vs 认证失效）**：不适配则坏先验长存；全量微调则第 57 轮的校准证书、OOD 门、共形带全部作废且无法审计。适配必须挤进"足够表达"与"可证明有界"之间的窄缝。
- **H31（局部适配 vs 全局干扰）**：按区域训练的适配器在路由/复合时会互相改写；适配器本身成为新的攻击面（投毒、后门）与新的"坏先验"载体——比元模型更难查，因为它是权重而非统计量。

## 0. 直觉与动机

**灵感 1（模型预测控制 → 承诺从"一次性誓言"变成"滚动契约"）**
直觉：一次不可逆接触不是"此刻安全就够"，而是要在接下来 H 步里持续安全。MPC 的答案是别承诺理想轨迹，承诺一个"管"：
（a）**约束收紧**：预测模型有误差界 ē_k，就按累积误差把第 k 步约束向内收 ρ_k，只承诺"落在管内"；
（b）**终端不变集**：不可逆接触（L2）的准入条件不是"当前裕度大"，而是"存在控制不变集 𝒳_f 与恢复策略 π_rec，从计划末态出发无论扰动如何都留在 𝒳_f 内"；
（c）**滚动执行与重规划**：只执行计划第一步，每步重算；偏离管、证据过期、适配器越界即触发重规划或安全停。
于是"承诺"= 一个可行管计划的第一个动作，"证书"= 管 + 终端不变集 + 误差界，而不是一个自信的标量。

**灵感 2（LoRA → 适配从"重写权重"变成"有界低秩镜头"）**
直觉：坏先验要能就地纠正，但不能动已认证的基座。LoRA 提供一种"镜头式"适配：W = W0 + BA，rank(BA)≤r，‖BA‖₂≤ε_A；按区域/任务簇训练、按上下文路由、可组合。四个直接好处：
（a）**认证保留**：W0 的校准与不变集仍有效，适配只在一个范数球内扰动；
（b）**局部纠偏**：某类新材质只需一个小秩增量，不必全局重训；
（c）**可审计预算**：秩预算 Σr≤R_max、范数预算 ε_A 成为部署级资源，超预算即拒；
（d）**新证据来源也走隔离**：适配器先在影子模式跑边端探针流，校准不劣化（ECE↑、OOD 检出率↓、假承诺率↑ 任一不通过）不得接管。

**灵感 3（合流 → 效率归适配，安全归管与不变集）**
直觉：适配让预测模型更准，但安全分析仍以"冻结基座 + 范数球内最坏适配"为锚。管半径显式包含适配误差项 L·ε_A：**适配越激进，管越宽、承诺越保守**——这是一个自动的保守性回压，而不是靠人调参。第 57 轮的赌注押在"先验质量"这一学出来的量上；本轮押在"管/不变集/误差界"这一可在线检查的证书上。可证，而非可信。

**灵感 4（MPC 把"时间"带进证据与同意 → 证据视界 + 包络同意）**
直觉：证据像牛奶，有保质期。t_i 时刻要用的证据不能在 t_i 之前过期；于是调度必须满足"证据职责期限"，过期就插入预测性探针（按"新鲜度 VOI"选探针，而非按当前 VOI）。人类同意也升级：不再同意一个动作，而是同意一个**执行包络**（管 + 视界 + 重规划触发器 + 中止包络）；运行时重规划只要仍在已授权包络内即自动放行，越出包络才重新协商或安全停。

**灵感 5（PCE++ → 探-诺-演升级为滚动承诺算子）**
直觉：每检查点改为七步：路由适配 → 建管并查递归可行 → 查证据视界 → 适配证据门 → 只执行第一步 → 监视偏离 → 出管/过期/越界触发重规划，回退链为 重规划→绕行→降档→L2 包络协商→安全停。第 57 轮的"一切判定器走隔离"推广为"**一切在线权重变更也走隔离**"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（管状模型预测承诺 TMC）** 预测模型 f̂=f_{W0+ΔW_r}，扰动 w_k∈𝒲，建模误差 e_k=f−f̂ 带共形上界 ē_k（覆盖 ≥1−α_e）。检查点 cp 上，视界 H 的计划 σ_{0:H−1} 的管为 𝒯_k=z_k⊕𝔻(ρ_k)，ρ_{k+1}=‖A‖ρ_k+L·‖ΔW‖₂+w̄，ρ_0 为初始不确定半径；收紧约束 K_margin(c_k)≥κ(ρ_k)。终端集 𝒳_f 在恢复策略 π_rec 下对 ∀w∈𝒲、∀ΔW∈𝒜(r,ε_A) 控制不变。承诺证书 ComCert=(H,σ,{𝒯_k},𝒳_f,ρ,误差界方法及覆盖,adapter 版本,证据职责期限)。**承诺 ⇔ ∃计划使 z_H∈𝒳_f ∧ 全部收紧约束满足 ∧ 每个待执行接触的证据在执行时刻未过期**；执行时只落地 k=0，随后滚动重算。

**定义 140（有界低秩适配 BLRA）** 基座 W0 冻结且带证书 cert(W0)。适配器 a_c=(ΔW_c=B_cA_c, version, provenance)，属于 𝒜(r,ε)={BA: rank(BA)≤r, ‖BA‖₂≤ε_A}。路由 π_a(z_r) 按区域/任务上下文选择或组合适配器；组合须满足干扰界 sup_{x∈𝒳_cert}‖(ΔW_i+ΔW_j)x−ΔW_i x−ΔW_j x‖≤ε_int 与正交性 ‖ΔW_iᵀΔW_j‖_F≤ε_orth。部署级秩预算 Σ_c r_c≤R_max。生命周期：训练→影子运行→校准回归（ECE 不劣化 ∧ OOD 检出率不降 ∧ 假承诺率不增 ∧ 干扰≤ε_int）→接管→在线监视→回滚。适配器未经影子准入不得进入证据路径。

**定义 141（适配证据门 AEG）** 在第 57 轮五类证据上新增：**EV-tube**（持有效 ComCert；L1 可用，L2 须终端不变集在基座+适配球下已证且证据未过期）；**EV-adapt**（仅 L1，且 ΔW∈𝒜(r,ε_A)、秩预算未超、影子已过、校准未退化）。不可逆接触必要证据集 = {基座 EV-probe\* ∨ 基座 EV-margin ∨ 带终端不变集的 EV-tube} ∪ 佐证；**EV-adapt 与 EV-xmodal 一律不得作为不可逆接触的替代证据**。证书 J_q 在 J_p 上增加 tube_cert、terminal_invariant_cert、adapter_provenance、rank_budget_log、interference_cert、freshness_log、replan_log。

**定义 142（证据-视界预测约束 EHPC）** 证据 e 有有效视界 h_e 与职责期限 d_e=t_obs(e)+h_e（过期概率 ≤α_h）。计划 σ 在时刻 t_i 执行接触 c_i，须满足 d_{e(i)}≥t_i+τ_guard；不满足则计划不可行，须插入预测性探针：选 argmax_π[新鲜度 VOI(π)−cost(π)]，其中新鲜度 VOI 以"计划期内该证据过期的期望风险×下游代价"计量。证据约束与管约束同构：都是随时域推进的收紧约束。

**定义 143（MPC 包络同意与解释 MPC-X）** 解释内容五元组不变，新增执行包络 ℰ=(𝒯,H,重规划触发器,中止包络)。同意阶梯升级：L2 的同意对象是 ℰ 而非单个动作；运行时重规划若仍落在 ℰ 内自动授权；一旦计划越出 ℰ（管半径超限、证据过期、适配器出球、终端不变集失守）即冻结并重新协商或安全停。渲染模态 m_E 仍按第 57 轮个性化选择，但 𝔼 的结构对所有模态一致呈现。

**定义 144（探-诺-演++ 算子 PCE++）** 每检查点：①路由适配并做范数/秩/影子检查；②以 f̂ 建管，检查递归可行与 z_H∈𝒳_f；③检查证据视界；④过 AEG；⑤仅执行首步；⑥监视实际偏离 δx 与适配器范数漂移；⑦若 δx>ρ_0 或证据过期或适配出球 ⇒ 重规划；重规划失败则依次 绕行→降档→L2 包络协商（τ_int(auth)）→安全停。每检查点探针预算仍为 k_probes+k_cons，重规划最多 N_replan 次。

## 2. 关键算法伪代码（完整版见产物区）

```python
def tube_commit(cp, M, task, base, adapter, H):        # IP-139
    f_hat = compose(base.W0, adapter.dW)               # 冻结基座 + 有界镜头
    sigma = nominal_schedule(cp, M, f_hat, H)
    tube, rho = [], rho0
    for k in range(H):
        rho = norm_A * rho + L * adapter.eps + w_bar   # 适配误差计入管半径
        tube.append(inflate(sigma[k], rho))
        if not tightened_feasible(sigma[k], tube[k]): return None
    if not in_terminal_set(sigma[H-1], Xf, base, adapter): return None
    if any(expired_at(c, cp.t + k) for k, c in enumerate(sigma)): return None
    return ComCert(H, sigma, tube, Xf, rho, adapter.version)

def receding_commit(x0, M, task, base, adapter, H):    # IP-144 骨架
    cert = tube_commit(cur_cp, M, task, base, adapter, H)
    if cert is None: return replan_or_fallback(M, cur_cp)
    execute(cert.sigma[0])                             # 只执行第一步
    if deviation(x, cert.tube[0]) > cert.rho0 \
       or adapter.norm > adapter.eps or evidence_stale(cur_cp):
        return replan_or_fallback(M, cur_cp)           # 出管即重规划
    return advance()
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TMC | O(H·(C_solve+d_x²))/检查点 | O(H·d_x) | 误差界覆盖 ≥1−α_e、终端集不变 |
| BLRA | 前向 O(d·r)/层；更新 O(r·d) | O(#adapter·r·d) | 范数/秩硬界、影子准入、干扰界 |
| AEG | O(\|σ\|+\|𝒜\|) | O(\|𝒜\|) | EV-adapt 仅 L1、不可逆用不变集 |
| EHPC | O(\|σ\|·log\|E\|) | O(\|E\|) | 期限诚实、过期概率 ≤α_h |
| MPC-X | O(1) | O(\|ℰ\|) | 包络内自动、出包络即停 |
| PCE++ | O(\|CP\|·H·(C_solve+k_p·C_VOI)) | O(\|V\|+H·d_x) | 递归可行、N_replan 有界 |

**正确性定理（TACS 概要）**：在 A33–A40 上加 (A41) 扰动与适配有界（w∈𝒲、ΔW∈𝒜(r,ε_A)、管半径/误差界声明诚实）；(A42) 适配器影子校准与干扰界诚实、provenance 完整；(A43) 证据视界诚实（过期被漏检概率 ≤α_h）；(A44) 滚动执行与重规划触发器保守。则：
1. **递归可行性**：若 k 时刻 ComCert 存在且实际状态落入 𝒯_{k+1}，则 k+1 时刻必存在 ComCert（终端不变集 + 收紧约束平移），不会"承诺后卡死"；
2. **管安全**：∀w∈𝒲、∀ΔW∈𝒜，x_k∈𝒯_k，且接触安全由 K_margin≥κ(ρ_k) 保证；
3. **适配健全**：适配误差以 L·ε_A 进入管，EV-adapt 仅在 L1 且影子通过时有效，不可逆接触绝不单独采信适配证据；
4. **证据新鲜**：承诺使用过期证据的概率 ≤Σα_h；
5. **终止性**：PCE++ 在 N_replan 内终止于 {承诺, 绕行, 降档, L2 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 管过保守 → 频繁重规划/死锁 | 高 | 自适应视界 H、终端集库、分级降档、超时安全停 |
| 误差界被低估 → 管失效 | 高 | 共形在线校准 + 保守膨胀 + 界不许由适配器学习 + 出管即停 |
| 适配器投毒/后门/干扰 | 高 | 范数秩硬界、影子准入、provenance 审计、正交约束、可回滚 |
| 秩/范数预算过紧 → 适配无收益 | 中 | 按区域协商预算、基座回退、收益-保守性曲线选点 |
| 包络同意理解成本高 | 中 | 多模态包络可视化、默认保守包络、文本回退 |

## 6. 本轮最大风险

**一句话**：本轮把安全垫从"证据门"移到"管/终端不变集"，最大风险是**管半径与不变集所依赖的模型误差界被低估（尤其被在线适配器悄悄改变动力学后）**——一个错误的界会让每一层 MPC 都"递归可行地"走进不可恢复区域，而滚动重规划反而加速把系统推向边界；必须以冻结基座、适配器范数硬界、共形在线校准误差界与"出管即停"四重护栏，宁可将管放大到保守，也绝不让"界"本身成为学习对象。

### IP-139 TMC（管状模型预测承诺）

```python
def tube_commit(cp, M, task, base, adapter, H):
    f_hat = compose(base.W0, adapter.dW)                 # 冻结基座 + 有界低秩镜头
    sigma = nominal_schedule(cp, M, f_hat, H)
    tube, rho = [], rho0
    for k in range(H):
        rho = norm_A * rho + L * adapter.norm + w_bar    # 适配误差归入管半径
        tube.append(inflate(sigma[k], rho))
        if K_margin(sigma[k]) < kappa(rho):              # 约束收紧
            return None
        if not tightened_feasible(sigma[k], tube[k]):
            return None
    if not in_terminal_set(sigma[H - 1], Xf, base, adapter, ball=adapter.eps):
        return None                                      # 不可逆接触必须落不变集
    for k, c in enumerate(sigma):
        if d_e(evidence(c)) < cp.t + k + tau_guard:      # 证据视界（IP-142）
            return None
    return ComCert(H, sigma, tube, Xf, rho, adapter.version,
                   error_bound='conformal', coverage=1 - alpha_e)
```

### IP-140 BLRA（有界低秩适配与影子准入）

```python
def adapter_propose(a, data, base, r, eps):
    dW = lora_fit(base.W0, data, rank=r)                 # 只拟合 BA，W0 不动
    if spectral_norm(dW) > eps:
        dW = dW * (eps / spectral_norm(dW))              # 硬投影回范数球
    if rank(dW) > r:
        dW = truncated_svd(dW, r)                        # 硬截断回秩预算
    cand = a.replace(dW=dW, version=next_ver(a))
    return cand

def adapter_admit(cand, base, budget, shadow_stream):
    report = shadow_eval(cand, base, shadow_stream)      # 边端探针流影子运行
    if report.ece > base.ece + tol:                      return False
    if report.ood_recall < base.ood_recall - tol:        return False
    if report.false_commit > base.false_commit + tol:    return False
    if budget.spent_rank + rank(cand.dW) > budget.R_max: return False
    if interference(cand, budget.active) > budget.eps_int: return False
    if not orthogonal(cand, budget.active, budget.eps_orth): return False
    return True

def adapter_promote(a, cand):
    audit.log(('adapter', a.version, cand.version, cand.provenance, rank(cand.dW),
               spectral_norm(cand.dW)))
    return cand
```

```python
def adapter_evidence_gate(c, cert, base, adapter, budget):

                      tube_certs, adapter_log, budget):
```

### IP-142 EHPC（证据视界与预测性探针）

```python
def evidence_horizon_check(sigma, M, t0):
    for k, c in enumerate(sigma):
        e = evidence_for(c, M)
        if t0 + k + tau_guard > d_e(e):
            return False, e                              # 该证据执行前过期
    return True, None

def freshness_voi(probe, sigma, M):
    p_exp = expected_expiry_prob(probe, sigma, M)        # 探针后证据覆盖到执行期
    return p_exp * downstream_cost(sigma) - cost(probe)

def predictive_probe_insert(sigma, M, budget, t0):
    if evidence_horizon_check(sigma, M, t0)[0]:
        return sigma, 0
    n = 0
    while not evidence_horizon_check(sigma, M, t0)[0] and budget.left > 0:
        p = argmax(admissible_probes(sigma, M), key=lambda q: freshness_voi(q, sigma, M))
        if freshness_voi(p, sigma, M) < theta_voi:
            break                                     # 探针也不再划算 → 绕行/降档
        M = observe(M, execute_probe(p)); budget.spend(p); n += 1
    return sigma, n
```

### IP-144 PCE++（滚动承诺算子）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log, replans = [], [], 0
    for cp in route.checkpoints:
```

## 3. 关键推导与正确性

**推导（适配范数进入管半径的线性情形）**
设真实/预测误差动力学 e_{k+1}=A e_k + E·ΔW·φ(x_k)+w_k，且 ‖E‖‖φ‖≤1、‖ΔW‖₂≤ε_A、‖w_k‖≤w̄。则误差半径递推
ρ_{k+1} ≤ ‖A‖ρ_k + L·ε_A + w̄，其中 L=‖E‖·sup‖φ‖。
展开得
ρ_k ≤ ‖A‖^k ρ_0 + (L ε_A + w̄)·(‖A‖^k−1)/(‖A‖−1)（‖A‖≠1）。
**结论**：ρ_k 对 ε_A 单调不减，故"适配收益↑"与"承诺保守度↑"同源；不存在"既大幅适配又不放宽管"的免费午餐。若 ε_A 过大使放宽后的约束不可行，`tube_commit` 直接返回 None——适配被结构性回压，而不是靠人工阈值。

**正确性定理（Tube-Adapter Certified Soundness, TACS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 扰动与适配有界：w∈𝒲、ΔW∈𝒜(r,ε_A)，误差界 ē_k 声明诚实、共形覆盖 ≥1−α_e，终端集 𝒳_f 对全部允许扰动与适配球控制不变；**(A42)** 适配器影子校准诚实：ECE/OOD/假承诺回归通过、provenance 完整、干扰 ≤ε_int、正交 ≤ε_orth、秩预算不超；**(A43)** 证据视界诚实：过期漏检概率 ≤α_h；**(A44)** 滚动执行与重规划触发器保守：只在偏离 ≤ρ_0 且证据未过期时推进。则：

1. **递归可行性**：若 k 时刻 ComCert 存在且 x_{k+1}∈𝒯_{k+1}（由管控制器保证），则 k+1 时刻存在 ComCert——终端不变集使平移后的计划仍可行，故不会"承诺后卡死"。
2. **管安全**：∀w∈𝒲、∀ΔW∈𝒜，x_k∈𝒯_k；接触安全由 K_margin≥κ(ρ_k) 保证；不可逆接触落于 𝒳_f。
3. **适配健全**：适配误差以 L·ε_A 显式进入管半径；EV-adapt 仅限 L1 且影子准入；不可逆接触必要证据集不含 EV-adapt/EV-xmodal。
4. **证据新鲜**：单次承诺使用过期证据的概率 ≤Σ_h α_h。
5. **终止性**：每检查点探针 ≤k_probes+k_cons，重规划 ≤N_replan，PCE++ 在 |CP|·(k_p+k_c+N_replan) 步内终止于 {承诺, 绕行, 降档, L2 协商, 安全停}。
6. **部署界**（对检查点与视界取联合界）：

```
P_safe ≥ 1 − Σ_cp Σ_{k=0}^{H−1} ( δ_f + α_e + δ_probe + ε_h + α_h
                                  + δ_adapt·1[L1] + P(ΔW∉𝒜 未检出)
                                  + P(干扰>ε_int 未检出) )
             − P(终端不变集失守) − P(重规划预算耗尽 ∧ 安全停失效)
```

关键：**适配给效率、管给鲁棒、不变集给不可逆性**；适配范数是管内生变量，故"学得越猛、承诺越保守"是结构性的而非调参的；证据与同意都获得时间维度（期限、包络），使"承诺"首次拥有可证明的有效期。

## 6. 本轮最大风险

**一句话**：本轮把安全垫从"证据门"移到"管/终端不变集"，最大风险是**管半径与不变集所依赖的模型误差界被低估（尤其被在线适配器悄悄改变动力学后）**——一个错误的界会让每一层 MPC 都"递归可行地"走进不可恢复区域，而滚动重规划反而加速把系统推向边界；必须以冻结基座、适配器范数硬界、共形在线校准误差界与"出管即停"四重护栏，宁可将管放大到保守，也绝不让"界"本身成为学习对象。
