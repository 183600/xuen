# 第 1 轮想法区 · 灵感词：持续学习 × 面部表情识别

## 一、直觉层：三个跳跃

**跳跃 1：表情不是命令通道，而是"否决证据"通道。**
人机协作里，手势/语音可以是正向指令（"过来"），但面部表情天然模糊、文化依赖、可伪装。若让表情直接"授权"动作，系统会被一个假笑攻破；若让表情只能"撤销/阻止"动作，攻破成本就从"做出一个表情"变成"让系统确信你痛苦"，攻击面显著收窄。于是我把表情重构成**非对称证据（asymmetric evidence）**：它只能把计划从执行集中删掉，永远不能把计划加进去。这正好与 v22/v23 里 GIC 的"手势存在性翻转"哲学同构，但更强：表情是 veto-only。

**跳跃 2：持续学习在这里的真正难点不是"记住新用户"，而是"不要忘记罕见的拒绝"。**
个性化需要 plasticity（适应某个人的中性脸、疲劳脸、妆容、光照）；安全需要 stability（对 discomfort/refusal 这类安全关键负证据的召回率不能掉）。普通持续学习用 EWC/回放平衡二者，但安全关键类样本极少、且一旦遗忘就是"把痛苦读成平静"的假阴性。因此我提出**非对称持续学习**：plasticity 只允许发生在非安全类的头部/原型上；安全类用永久锚定缓冲 + 证书门控，任何会削弱其召回下界的更新一律回滚。

**跳跃 3：证书必须在非平稳流上仍然成立，否则"持续学习"会把 conformal 保证悄悄掏空。**
标准 conformal 的 1-α 覆盖依赖可交换性；个性化适应和用户漂移恰好破坏可交换性。解决不是"更频繁重校准"（仍无保证），而是**自适应 conformal 推断（ACI）**：让误覆盖目标 α_t 在线自适应，得到任意漂移下的长期覆盖率保证；再用"锚定召回下界 + Pinsker 漂移修正"把长期保证翻译成对安全关键类的可审计下界。

## 二、严谨层：核心定义

- 表情标签集 E = {comfort, neutral, discomfort, refusal, pain}，安全关键集 S = {discomfort, refusal}。
- 特征 φ_e(x) 由**冻结骨干**给出；原始像素不出端（延续 IP-433 的隐私约束）。
- **非对称 veto**：给定 conformal 标签集 C_{α_t}(x)，定义 Veto(x)=1 ⇔ C_{α_t}(x) ∩ S ≠ ∅。它只删计划、不加计划。
- **误否决界**：若 (x,y) 与校准集可交换，则 P(Veto=0 ∧ y∈S) ≤ α。证明只需注意：Veto=0 且 y∈S ⇒ y∉C_α，而后者概率 ≤ α。这正是"漏掉痛苦"的概率上界。
- **ACI 更新**：α_{t+1} = clip(α_t + γ(α₀ − err_t))，err_t = 1[y_t ∉ C_{α_t}(x_t)]。望远镜求和给出 |(1/T)Σerr_t − α₀| ≤ (α_max−α_min)/(γT)，即任意漂移下的长期误否决率可控。
- **锚定遗忘证书**：设锚定缓冲 A_S ~ P_ref（只存特征，不存像素），R̂_S 为安全类经验召回，CP 下界 R_S^LB。若部署分布与锚定分布的 KL 满足 D_KL(P_t‖P_ref) ≤ Δ_KL，则由 Pinsker 有 TV ≤ √(Δ_KL/2)，从而
  R_{P_t}(S) ≥ R_S^LB − √(Δ_KL/2)。
  仅当该下界 ≥ 1−β 时允许提交本次持续学习更新，否则回滚到 θ_h^ref。
- **隐私预算**：原型增量在本地裁剪后加高斯噪声上传（local DP），用 RDP/矩 accountant 复合；ε_used 超过 ε_budget 即冻结云端同步，退化为 CESC 的 OfflineMode。

## 三、与 v23 证书体系的接口

1. **CESC 版本五元组升级为六元组**：V = (v_model, v_calib, v_proto, v_rule, v_patent, v_expr)。表情头/校准器/锚定缓冲各自带版本，原子切换沿用双轨并行。
2. **FSVC 扩展**：少样本适应对象从"通用原型"扩展到"表情原型 + 分组校准分位数"；覆盖硬约束改为"安全类召回下界 ≥ 1−β"。
3. **CFC+++ → CFC++++**：新增"否决仲裁"，表情 veto 不参与正向模态计数（避免相关系统伪造共识），而是在共识后作为最终删计划算子。
4. **HPC-E+ → HPC-E++**：Exec_v24 = Exec_v23 ∩ Fil_expr ∩ Fil_forget ∩ Fil_dp，保持 Exec_v24 ⊆ Exec_v23 的单调退化链。

## 四、可证伪假设

- H1：在同等误报率下，veto-only 比"表情投票"对伪装表情的越权率高一个数量级地低。
- H2：加入安全锚定 + FBC 门控后，T=100 轮个性化更新后的安全类召回下界仍 ≥ 1−β；去掉锚定则显著崩塌。
- H3：ACI 在突变漂移下比固定 α 的滑动窗口重校准有更小的"持续漏检窗口"。
- H4：DP 噪声会系统性拉低锚定召回测量值，若不把噪声计入证书，会形成"证书越私密越不可信"的循环。

## 五、一句话最大风险

**锚定缓冲是学习者自己选、自己更新的，遗忘证书因此带有自我参照性：它证明的是"对 P_ref 的召回"，而不是"对真实漂移用户的召回"，一旦漂移超出 Δ_KL 预算，证书会给出安全的假象。**

# ============================================================
# IP-440 Veto-Only Expression Certificate (VOEC)
# ============================================================
@dataclass(frozen=True)
class ExpressionVetoCertificate:
    alpha_t: float
    group: str
    label_set: frozenset          # C_{alpha_t}(x) ⊆ E
    q_hat: float
    calib_hash: bytes
    veto: bool

class VetoOnlyExpressionCertificate:
    S = frozenset({"discomfort", "refusal"})

    def __init__(self, backbone, head, calibrator, groups,
                 alpha0=0.01, gamma=0.005):
        self.backbone = backbone          # 冻结
        self.head = head
        self.calibrator = calibrator      # 分组分位数
        self.alpha0 = alpha0
        self.gamma = gamma
        self.alpha_t = {g: alpha0 for g in groups}
        self.window = {g: deque(maxlen=2000) for g in groups}

    def label_set(self, x, g):
        phi = self.backbone.extract(x)            # 像素不出端
        scores = self.head.predict_proba(phi)
        q = self.calibrator.quantile(g, self.alpha_t[g])
        return conformal_set(scores, q)           # Mondrian，按 g 校准

    def veto(self, x, g) -> bool:
        # 非对称：只可能把计划从执行集中删除
        return bool(self.label_set(x, g) & self.S)

    def certify(self, x, g) -> ExpressionVetoCertificate:
        L = self.label_set(x, g)
        return ExpressionVetoCertificate(
            alpha_t=self.alpha_t[g], group=g, label_set=frozenset(L),
            q_hat=self.calibrator.quantile(g, self.alpha_t[g]),
            calib_hash=self.calibrator.hash(g), veto=bool(L & self.S))

    def aci_update(self, x, y, g):
        # 需要延迟/审计标签（人工确认锚定样本），不是每帧都有
        L = self.label_set(x, g)
        err = 0.0 if y in L else 1.0
        a = self.alpha_t[g]
        self.alpha_t[g] = min(0.5, max(1e-4, a + self.gamma * (self.alpha0 - err)))
        self.window[g].append((L, y))
        self.calibrator.refresh(g, self.window[g])


# ============================================================
# IP-441 Continual Expression Learner (CEL)
# ============================================================
class ContinualExpressionLearner:
    def __init__(self, backbone, head, anchor_cap=64, ewc_lambda=10.0):
        self.backbone = backbone          # 冻结，不参与更新
        self.head = head
        self.anchor_cap = anchor_cap
        self.ewc_lambda = ewc_lambda
        self.A_S = []                     # 安全类锚定：仅特征
        self.window = deque(maxlen=2000)  # 非安全类近期样本
        self.fisher = None
        self.theta_ref = deepcopy(head.state_dict())

    def observe(self, x, y):
        phi = self.backbone.extract(x).detach()
        self.window.append((phi, y))
        if y in VetoOnlyExpressionCertificate.S:
            if len(self.A_S) < self.anchor_cap:
                self.A_S.append((phi, y))
            else:
                # 加权蓄水池：保证稀有安全类在缓冲中永不被整体挤出
                reservoir_replace_weighted(self.A_S, (phi, y))
        return phi

    def propose_update(self):
        loss = cross_entropy(self.head, self.window)
        loss += self.ewc_lambda * ewc_penalty(self.fisher, self.theta_ref)
        return grad_step(loss, self.head.parameters())   # 只动 θ_h

    def commit(self):
        self.theta_ref = deepcopy(self.head.state_dict())

    def rollback(self):
        self.head.load_state_dict(self.theta_ref)


# ============================================================
# IP-442 Forgetting-Bounded Certificate (FBC)
# ============================================================
class ForgettingBoundedCertificate:
    def __init__(self, beta=0.05, delta=1e-3, kl_budget=0.05):
        self.beta = beta
        self.delta = delta
        self.kl_budget = kl_budget

    def certify(self, learner, drift_kl):
        n = len(learner.A_S)
        if n < 30:
            return False, 0.0
        correct = sum(1 for phi, y in learner.A_S
                      if learner.head.predict(phi) in VetoOnlyExpressionCertificate.S)
        # Clopper–Pearson 单侧下界：Beta.ppf(delta; correct, n-correct+1)
        lb = beta_ppf(self.delta, correct, n - correct + 1)
        tv = math.sqrt(max(drift_kl, 0.0) / 2.0)          # Pinsker
        lb_drift = lb - tv
        return lb_drift >= 1.0 - self.beta, lb_drift


# ============================================================
# IP-443 DP Continual Expression Prototype (DP-CEP)
# ============================================================
class DPContinualExpressionPrototype:
    def __init__(self, clip=1.0, sigma=1.1, eps_budget=8.0, delta=1e-5):
        self.clip = clip
        self.sigma = sigma
        self.eps_budget = eps_budget
        self.delta = delta
        self.eps_used = 0.0

    def publish(self, delta_proto):
        c = clip_norm(delta_proto, self.clip)
        noisy = c + gaussian(0.0, self.sigma * self.clip, c.shape)
        self.eps_used += gaussian_rdp(self.sigma, self.delta)  # 复合记账
        if self.eps_used > self.eps_budget:
            return None        # 冻结上传 → CESC OfflineMode
        return noisy

# IP-444 HPC-E++ 统一五证准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'
    voec: VetoOnlyExpressionCertificate
    cel: ContinualExpressionLearner
    fbc: ForgettingBoundedCertificate
    dpcep: DPContinualExpressionPrototype

    def admits(self, plan, x, g, drift_kl, modules):
        # 1) v23 全部条件
        if not self.hpc_e_plus.admits(plan, x, modules):
            return False
        # 2) 隐私预算耗尽 → 拒绝依赖云端新版本的执行
        if self.dpcep.eps_used > self.dpcep.eps_budget:
            return False
        # 3) 表情否决（非对称，只能删计划）
        if self.voec.veto(x, g):
            return False
        # 4) 遗忘界不达标 → 保守退化，而非直接放行
        ok, lb = self.fbc.certify(self.cel, drift_kl)
        if not ok:
            degraded = Degrade(plan)     # 降速/增距/要求显式手势确认
            if degraded is None:
                return False
            return self.hpc_e_plus.admits(degraded, x, modules)
        return True

class VetoAwareConsensus(CertificateFederatedConsensusPlusPlusHierarchical):
    def consensus_round(self, timeout=5.0):
        results = super().consensus_round(timeout)
        for key, res in results.items():
            if res == "CI":
                continue
            # 表情 veto 在共识之后作为删计划算子；不进入 modality quorum
            if self.voec.veto(self.sensor[key], self.group[key]):

        return results

## 3. 正确性论证

### 引理 1（非对称否决的漏检上界）
**陈述**：若 (x,y) 与校准集可交换，则 P(Veto(x)=0 ∧ y∈S) ≤ α。
**证明**：Veto=0 ⇒ C_α(x)∩S=∅。若同时 y∈S，则 y∉C_α(x)。由 conformal 覆盖保证 P(y∉C_α(x)) ≤ α，故漏检概率 ≤ α。注意反向不成立：Veto=1 不代表 y∈S（假阳性被允许），这正是非对称性的代价与安全来源。∎

### 引理 2（ACI 在任意漂移下的长期误否决率）
**陈述**：对任意（可对抗的）标签序列，ACI 满足 |(1/T)Σ_{t=1}^T err_t − α₀| ≤ (α_max−α_min)/(γT)。
**证明**：无裁剪时 α_{t+1}−α_t = γ(α₀−err_t)，望远镜求和得 α_{T+1}−α₁ = γ(Tα₀−Σerr_t)，整理即得。裁剪只把 α_t 限制在 [α_min, α_max]，故界为 (α_max−α_min)/(γT)。∎

### 引理 3（遗忘界：从锚定分布到部署分布）
**陈述**：若 D_KL(P_t‖P_ref) ≤ Δ_KL，且锚定安全召回下界为 R_S^LB，则 R_{P_t}(S) ≥ R_S^LB − √(Δ_KL/2)。
**证明**：令 M 为"y∈S 且未否决"事件。Pinsker 给出 TV(P_t,P_ref) ≤ √(Δ_KL/2)。对任意事件 |P_t(M)−P_ref(M)| ≤ TV(P_t,P_ref)。而 P_ref(M) ≤ 1−R_S^LB（CP 下界的补）。故 P_t(M) ≤ 1−R_S^LB + √(Δ_KL/2)，即 R_{P_t}(S) ≥ R_S^LB − √(Δ_KL/2)。∎

### 引理 4（更新门控保持安全召回）
**陈述**：FBC 门控下的 CEL 更新序列保证：任一被提交的 θ_h 满足 R_{P_ref}(S) ≥ 1−β；被拒绝的更新回滚到 θ_h^ref，因此已提交状态的证书链连续。
**证明**：FBC.certify 仅在 CP 下界经漂移修正后 ≥ 1−β 时返回 True；否则调用 rollback 恢复 θ_h^ref（上一次已认证状态）。提交动作是原子的，且 θ_h^ref 只在 commit 后更新，故不存在"半提交"状态。∎

### 引理 5（DP 复合预算）
**陈述**：每轮原型发布满足 (ε_t,δ_dp)-DP，T 轮后累计满足 (Σε_t, Tδ_dp)-DP；当 Σε_t > ε_budget 时停止发布，实际累计隐私损失 ≤ ε_budget。
**证明**：高斯机制对 L2 敏感度 clip 的向量给出 (ε_t,δ_dp)-DP；RDP/矩 accountant 的复合性给出 T 轮累计界。预算检查发生在发布前，故超预算的增量永不外发。∎

### 定理（HPC-E++ 的安全-合规-可部署-可保护-可适应完备性）
**陈述**：对任意计划 π，HPCEPlusPlus.admits(π)=True ⟺ π 同时满足：
(1) v23 的物理接地/云边同步/少样本/IP 四类条件；
(2) 表情否决未触发（或触发后计划被删除）；
(3) 安全类遗忘下界 ≥ 1−β（否则 π 已被保守退化且退化版仍过 v23）；
(4) 隐私预算未耗尽。
**证明**：直接由 admits 的四段连言与引理 1–5 可得。必要性：任一条件失败即拒证或退化。充分性：四条件满足时，引理 1 给出漏否决率 ≤α，引理 3–4 给出安全召回下界，引理 5 给出隐私合规，且 Exec_v24 ⊆ Exec_v23 由"只增条件、只删计划"保证。∎

## 6. 本轮最大风险（最终确认）

**一句话**：安全锚定缓冲由学习者自己选取与更新，遗忘证书因此是自我参照的——它严格证明的是"对 P_ref 的安全召回"，而不是"对真实漂移用户的安全召回"；当局部剧烈漂移未被全局 Δ_KL 捕获时，系统会带着一份形式上正确、实质上失效的证书继续运行。
