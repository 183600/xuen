# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新一轮灵感循环；本轮灵感：「实时控制」×「安全对齐」）

> 第 54 轮把技能组合推进到“动作空间剖面 + 云边联合证书 J”。但 J 本质上是**空间证书**：它回答“动作是否对得上”，不回答“证书在执行那一刻是否仍然有效”。本轮引入时间维度，把安全对齐从**静态布尔判定**升级为**带截止期、带有效期、带回退承诺的实时契约**。核心矛盾：
> - **H22（时滞失效）**：安全对齐证书在慢环（云端/离线）签发，实时控制必须在硬截止期内执行；签发时刻 `t0` 的“安全”不等于执行时刻 `t0+δ` 的安全，静态安全集在时延、抖动与降采样下会失效。
> - **H23（安全-及时-对齐三角）**：为保安全需减速或回退，但回退可能偏离任务意图；为保对齐需保留动作自由度，但自由度消耗安全裕度；为保及时需缩短验证预算，但预算缩短会削弱对齐判定的置信度。三者不能同时零代价成立。

## 0. 直觉与动机

**灵感 1（证书时间戳化 → 从布尔真值到带保质期的区间承诺）**
直觉：安全对齐证书不应是 `safe/unsafe` 的布尔值，而应像食品保质期：`TAC` 在 `[t0, t0+T_v]` 内、且在承诺的执行延迟 `δ ≤ δ_max` 下才有效。超过有效期即 `stale`，而 `stale` 必须被当作 `unsafe` 处理，而不是“再等等看”。这把“安全”从**点判定**变成**区间承诺**。

**灵感 2（实时双环 → 慢环语义对齐 + 快环安全滤波）**
直觉：慢环（云端/规划器）回答“应该做什么”，频率低但语义强；快环（边端控制器）回答“此刻做什么仍不越界”，频率高但视野短。二者之间不是直接传轨迹，而是传**预算化证书**：慢环承诺意图与安全包络，快环承诺在预算内执行或回退。`TAC` 就是这条接口上的“合同”。

**灵感 3（截止期即安全资源 → 时间松弛 σ 与安全债务）**
直觉：WCET、调度抖动、回退切换时间都是会吃掉安全裕度的真实资源。定义 `σ = D - (C_mon + C_shield + C_fb) - J_max`。`σ ≥ 0` 表示“验证 + 回退”都来得及；`σ < 0` 表示系统已欠下**安全债务**，此时继续做精细验证是在透支安全。正确策略是**提前回退**，而不是压缩验证。

**灵感 4（任意时间安全判定 → 超时返回不确定，绝不乐观）**
直觉：对齐验证是任意时间算法：预算越多，判定越细。关键不是“尽快给答案”，而是**单调且可靠**：已判 `safe` 不能被更多预算改判为 `uncertain`（可改判为 `unsafe`，即发现反例）；一旦超时，只能返回 `uncertain` 并触发预认证回退。这样“没算完”永远不会被误读成“安全”。

**灵感 5（时序金字塔 → 三证书联合）**
直觉：在第 53 轮鲁棒性层 `𝕃`、第 54 轮动作协同层 `𝔸` 之上叠加时间层 `𝕋`：`𝕋_0` 物理时序极限，`𝕋_1` 技能 WCET 与执行抖动，`𝕋_2` 证书有效期与漂移界，`𝕋_3` 截止期调度。跨层传递的证书必须同时包含 `ρ`、`A_cert` 与 `TAC`，否则“空间上可行”会被“时间上不可达”一票否决。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（时间参数化安全包络）**
受控系统 `ẋ = f(x) + g(x)u`，`x∈ℝⁿ`，`u∈U`。屏障函数 `h: ℝⁿ×ℝ → ℝ`，安全集 `S(t) = {x | h(x,t) ≥ 0}`。对执行延迟 `δ≥0`，定义延迟鲁棒条件：
```
L_f h + L_g h·u + ∂_t h + α(h) + L_h·δ ≥ 0
```
其中 `L_h` 为 `h` 对执行时刻误差的 Lipschitz 上界，`α` 为扩展类 K 函数。满足该条件的可达集记为 `S_δ(t) ⊆ S(t)`，称**δ-安全包络**。直观：不仅要求“现在在安全集里”，还要求“延迟 δ 后仍在安全集里”。

**定义 122（时序对齐证书 TAC）**
时序对齐证书 `TAC = (π, φ, h, t0, T_v, δ_max, fallback, ε_φ, L_t)`：
- `π` 为名义策略；
- `φ(x,t)` 为意图/规范评价函数，`φ_ref` 为目标值；
- `h` 为安全屏障；
- `t0` 为签发时刻，`T_v` 为有效期；
- `δ_max` 为承诺的最大执行延迟；
- `fallback` 为预认证回退控制器；
- `ε_φ` 为意图偏差上界，`L_t` 为 `φ` 的时间漂移率上界。

若 `t - t0 > T_v`，称 `stale`；若 `L_t·(t-t0) > ε_φ`，称 `drifted`；否则称 `valid`。`valid` 的含义是：在 `δ ≤ δ_max` 下执行 `TAC` 或 `fallback`，对所有 `t∈[t0,t0+T_v]` 均有 `x(t)∈S_δ(t)` 且 `|φ(x(t),t)-φ_ref| ≤ ε_φ`。

**定义 123（时间松弛与安全债务）**
剩余截止期 `D`，监控 WCET `C_mon`，护盾 WCET `C_shield`，回退切换 WCET `C_fb`，最大调度抖动 `J_max`。时间松弛
```
σ = D - (C_mon + C_shield + C_fb) - J_max
```
**安全债务** `d_s = max(0, -σ)`。称调度**安全可行**当且仅当 `σ ≥ 0` 且所有在役证书 `age ≤ T_v`。`σ < 0` 时允许的动作集合退化为“仅剩预认证回退”，不再进行常规对齐验证。

**定义 124（任意时间安全判定）**
判定器 `ATS(x,t,b) → (status, confidence, used)`，`status ∈ {safe, unsafe, uncertain}`，预算 `b`。要求：
1. **无假安全**：若返回 `safe`，则在该预算与假设下不存在反例；
2. **超时保守**：若 `used ≥ b` 且未完成，必须返回 `uncertain`，不得返回 `safe`；
3. **单调细化**：若 `b₂ ≥ b₁`，则 `status(b₁)=safe ⇒ status(b₂) ∈ {safe, unsafe}`；`status(b₁)=unsafe` 不得被更多预算推翻为 `safe`。

**定义 125（实时安全护盾 RTS）**
护盾 `Sh(x,t,TAC,σ,b) → u`，优先级固定为：
```
σ < 0 或 TAC 非 valid  → fallback.control(x,t)
ATS = unsafe           → 最小侵入安全投影 project_to_envelope(x,t)
u_nom ∈ S_δ(t)         → u_nom
否则                   → project_to_envelope(x,t)
```
护盾必须是非阻塞的，且最坏执行时间 `C_shield` 有硬上界。

**定义 126（时序-动作-鲁棒性联合证书）**
联合证书 `J⁺ = (ρ, A_cert, TAC, σ, age, schedule, evidence)`：
- `ρ` 为第 53 轮鲁棒性谱；
- `A_cert` 为第 54 轮动作占用证书；
- `TAC` 为时序对齐证书；
- `σ` 为时间松弛，`age = now - TAC.t0`；
- `schedule` 为监控/护盾/回退的时间分区与优先级；
- `evidence` 至少包含 WCET 实测下界证明、漂移界标定记录、回退不变集验证。

可部署判定：`dom(T)=in ∧ δ_a < Θ_a ∧ σ ≥ 0 ∧ age ≤ T_v ∧ schedule feasible`。

## 2. 关键算法 伪代码

### IP-121 TSA（Temporal Safety Alignment）

```python
def temporal_envelope(skill, x, t, delta_max, L_h):
    h = skill.barrier(x, t)
    Lf_h, Lg_h = lie_derivatives(h, x, t)
    alpha_h = class_k(h)
    # 延迟鲁棒可容许控制集：留出 L_h * delta 的安全余量
    admissible = {
        u for u in sample_inputs(skill.U)
        if Lf_h + Lg_h @ u + d_dt(h, t) + alpha_h + L_h * delta_max >= 0
    }
    return h, admissible
```

### IP-122 DAC（Deadline-Aware Certificate）

```python
def issue_tac(plan, x0, now, deadline, wcet, jitter_max):
    sigma = deadline - (wcet.monitor + wcet.shield + wcet.fallback) - jitter_max
    if sigma < 0:
        return ('reject', 'timing_infeasible', sigma)   # 安全债务
    fallback = select_certified_fallback(x0)            # 预认证不变集
    if fallback is None:
        return ('reject', 'no_certified_fallback')
    delta_max = deadline - wcet.monitor - wcet.shield - wcet.fallback
    T_v = conservative_horizon(plan.h, x0, delta_max, plan.L_h)
    if T_v <= 0:
        return ('reject', 'empty_validity')
    return ('ok', TAC(plan.pi, plan.phi, plan.h, now, T_v,
                      delta_max, fallback, plan.eps_phi, plan.L_t, sigma))
```

### IP-123 RTS（Real-Time Shield）

```python
def realtime_shield(x, t, tac, sigma, budget):
    if sigma < 0:
        return tac.fallback.control(x, t)               # 不等待、不验证
    state = certificate_state(tac, t)                   # valid/stale/drifted
    if state != 'valid':
        return tac.fallback.control(x, t)
    status, conf, used = anytime_alignment_check(x, t, budget)
    if status == 'unsafe':
        return project_to_envelope(x, t, tac.h, tac.delta_max)
    if status == 'uncertain':
        return tac.fallback.control(x, t)
    u_nom = tac.pi(x, t)
    if in_envelope(u_nom, x, t, tac.h, tac.delta_max):
        return u_nom
    return project_to_envelope(x, t, tac.h, tac.delta_max)
```

### IP-124 AJA（Anytime Just-in-time Alignment）

```python
def anytime_alignment_check(x, t, budget):
    t_start = now()
    result = ('uncertain', 0.0, 0.0)                    # 默认保守
    for level in ('coarse', 'medium', 'fine'):
        if now() - t_start >= budget:
            return result                                # 超时绝不升格为 safe
        status, conf = verify_level(level, x, t)
        if status == 'unsafe':
            return ('unsafe', conf, now() - t_start)     # 反例优先
        if status == 'safe' and conf >= theta_conf:
            result = ('safe', conf, now() - t_start)
    return result
```

### IP-125 STC（Stale-Certificate Triage）

```python
def stale_triage(tac, now, rho, A_cert, rho_min):
    age = now - tac.tau_issue
    if age <= tac.T_v and drift_bound(tac, age) <= tac.eps_phi:
        return ('keep', tac)
    core = A_cert.A_core & tac.fallback.invariant_actions
    rho_core = restrict_spectrum(rho, core)
    if core and min(rho_core.values()) >= rho_min:
        return ('degrade', core, tac.fallback)
    return ('abort', 'no_certified_fallback')
```

### IP-126 TJC（Temporal Joint Certificate）

```python
def temporal_joint_certify(skill_seq, x0, now, deadline, wcet, jitter_max):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)
    if J.status != 'ok':
        return J
    tac_res = issue_tac(J.plan, x0, now, deadline, wcet, jitter_max)
    if tac_res.status != 'ok':
        return ('reject', 'timing', tac_res)
    tac = tac_res.cert
    if tac.delta_max > J.A_cert.delta_a:
        return ('reject', 'timing_action_conflict', tac.delta_max, J.A_cert.delta_a)
    if not schedule_feasible(wcet, jitter_max, deadline):
        return ('reject', 'schedule_infeasible')
    return ('ok', JointPlus(J.cert, tac, sigma=tac.sigma, age=0,
                            schedule=build_schedule(wcet, jitter_max)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TSA | O(\|U\|·\|X\|)（采样） | O(\|U\|) | 屏障函数与延迟界经标定 |
| DAC | O(\|X\|) | O(\|X\|) | WCET 上界保守、回退不变集已证 |
| RTS | O(1) + 投影开销 | O(1) | 非阻塞、优先级固定、无动态分配 |
| AJA | O(L·\|X\|)，L 为层级数 | O(\|X\|) | 超时保守、细化单调 |
| STC | O(\|A_core\|) | O(\|A_core\|) | 退化后仍落在预认证集 |
| TJC | O(Σ 各组件) | O(\|J\|+\|TAC\|) | 三证书同时有效、调度可行 |

**正确性定理（Temporal Safety-Alignment Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立，并新增：
- **(A29)** `C_mon, C_shield, C_fb` 由硬件在环测量得到硬上界，抖动 `≤ J_max`；
- **(A30)** `fallback` 在预认证不变集 `I_fb` 上使 `h ≥ 0` 且意图满足 `|φ-φ_ref| ≤ ε_φ^fb`；
- **(A31)** 漂移界 `|h(x(t),t)-h(x(t-τ),t-τ)| ≤ L_t|t-τ| + L_h·δ_max`，`φ` 同理；
- **(A32)** `ATS` 满足定义 124 的无假安全与超时保守性。

则当 `σ(t) ≥ 0` 且 `TAC` 在每个控制步均 `valid` 时，对 `t∈[t0,t0+T_v]` 有
```
x(t) ∈ S_{δ_max}(t)  ∧  |φ(x(t),t) - φ_ref| ≤ ε_φ
```
部署成功概率下界为
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(σ<0) - P(age>T_v)
            - P(drift>ε_φ) - P(fallback fails) - P(ATS unsound)
```

**命题 1（安全-及时-对齐三角）**
对非平凡安全包络（`S(t)` 有界且存在必须偏离名义动作的扰动），若监控成本为正、漂移率 `L_t>0`，则以下三者不能同时以零预算成立：
1. 硬截止期 `D` 内完成验证；
2. 安全包络不扩张（`S_δ` 不放大）；
3. 意图偏差 `ε_φ = 0`。
至少需要放松一项：增加时间松弛 `σ`、扩大回退不变集、或允许有界意图偏差。这解释了为何“实时 + 安全 + 完全对齐”必须显式付出预算。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 时间松弛-违规曲线 | `σ` 预测值 vs 实际越界率 | `σ≥0` 时违规率 ≤ 0.5%，`σ<0` 时回退触发率 ≥ 99% |
| E163 证书过期检测 | stale/drifted 检出率、误报率 | 过期接受 = 0，误报 ≤ 3% |

| E166 WCET 低估敏感性 | WCET 低估 10%/20%/30% 时越界率 | 安全债务警报召回 ≥ 80%，越界率增幅 ≤ 2× |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| WCET 低估导致 `σ` 虚高 | 高 | 硬件在环测量 + 保守上界 + 安全债务警报 + 超预算强制降级 |
| 漂移界 `L_t` 在极限工况失效 | 高 | 在线辨识 + 自适应收缩 `T_v` + 漂移超界即 `stale` |
| 回退安全但偏离意图 | 高 | 多目标回退集 + 最小侵入回退 + 意图下界证书 |
| 任意时间监控超时造成保守死锁 | 中 | 预认证锚点 + 分层缓存 + 超时预算上限 |
| 调度抖动与优先级反转 | 中 | 优先级继承 + 时间分区 + 看门狗 + 抖动实测入证 |

## 6. 本轮最大风险

**一句话**：本方案把安全对齐从静态布尔证书推进为带有效期与截止期的时间证书，但其 soundness **同时依赖 WCET 上界、漂移界与回退不变集三者成立**；一旦 WCET 被低估或漂移界在极限工况失效，“已认证”的证书会在实时执行中悄悄过期，护盾把过期承诺当作有效承诺，导致安全约束恰在最需要时失守。

```python
    Lf_h, Lg_h = lie_derivatives(h, x, t)
    alpha_h = class_k(h)
    admissible = {
        u for u in sample_inputs(skill.U)
        if Lf_h + Lg_h @ u + d_dt(h, t) + alpha_h + L_h * delta_max >= 0
    }
    return h, admissible

def certificate_state(tac, now):
    if now - tac.t0 > tac.T_v:
        return 'stale'
    if tac.L_t * (now - tac.t0) > tac.eps_phi:
        return 'drifted'
    return 'valid'
```

```python
def issue_tac(plan, x0, now, deadline, wcet, jitter_max):
    sigma = deadline - (wcet.monitor + wcet.shield + wcet.fallback) - jitter_max
    if sigma < 0:
        return ('reject', 'timing_infeasible', sigma)   # 安全债务，禁止透支
    fallback = select_certified_fallback(x0)
    if fallback is None:
        return ('reject', 'no_certified_fallback')
    delta_max = deadline - wcet.monitor - wcet.shield - wcet.fallback
    T_v = conservative_horizon(plan.h, x0, delta_max, plan.L_h)
    if T_v <= 0:
        return ('reject', 'empty_validity')
    return ('ok', TAC(plan.pi, plan.phi, plan.h, now, T_v,
                      delta_max, fallback, plan.eps_phi, plan.L_t, sigma))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TSA | O(\|U\|·\|X\|)（采样） | O(\|U\|) | 屏障与延迟界标定，`L_h` 保守 |
| DAC | O(\|X\|) | O(\|X\|) | WCET 硬上界、回退不变集已证 |
| RTS | O(1)+投影 | O(1) | 非阻塞、固定优先级、无动态分配 |
| AJA | O(L·\|X\|) | O(\|X\|) | 超时保守、细化单调 |
| STC | O(\|A_core\|) | O(\|A_core\|) | 降级后仍在预认证集 |
| TJC | O(Σ 组件) | O(\|J\|+\|TAC\|) | 三证书同时有效、调度可行 |

**正确性定理（Temporal Safety-Alignment Soundness）**
假设 (A22)–(A28) 成立；新增 **(A29)** WCET 与抖动有硬上界；**(A30)** `fallback` 在不变集 `I_fb` 上保持 `h≥0` 且 `|φ-φ_ref|≤ε_φ^fb`；**(A31)** 漂移界 `L_t,L_h` 成立；**(A32)** `ATS` 无假安全且超时保守。
则 `σ≥0` 且 `TAC` 每个控制步 `valid` 时：
```
x(t) ∈ S_{δ_max}(t) ∧ |φ(x(t),t)-φ_ref| ≤ ε_φ ,  ∀t∈[t0,t0+T_v]
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(σ<0) - P(age>T_v)
            - P(drift>ε_φ) - P(fallback fails) - P(ATS unsound)
```

**命题（安全-及时-对齐三角）**：监控成本为正且漂移率 `L_t>0` 时，硬截止、零安全扩张、零意图偏差三者不能同时零预算成立；必须显式放宽其一（增加 `σ`、扩大回退集、或允许有界 `ε_φ`）。

## 5. 数值沙盘（最小可行验证）

设控制周期 `T=10ms`，硬截止 `D=10ms`；`C_mon=3ms`、`C_shield=1ms`、`C_fb=2ms`、`J_max=1ms`：
- 正常：`σ = 10-(3+1+2)-1 = 3ms`，允许在 `fine` 层验证；
- WCET 劣化 +2ms：`σ=1ms`，降至 `coarse` 层，`T_v` 收缩；
- WCET 劣化 +4ms：`σ=-1ms`，进入安全债务，护盾直接走 `fallback`，不再签发新 `TAC`。

该沙盘给出可操作的验收线：`σ` 的估计误差必须小于最小安全余量，否则“安全可行”判定本身不可信。

## 7. 本轮最大风险

**一句话**：本方案把安全对齐从静态布尔证书推进为带有效期与截止期的时间证书，但其 soundness **同时依赖 WCET 上界、漂移界与回退不变集三者成立**；一旦 WCET 被低估或漂移界在极限工况失效，“已认证”的证书会在实时执行中悄悄过期，护盾把过期承诺当作有效承诺，导致安全约束恰在最需要时失守。
