# 第 16 轮（研究线累计；本轮灵感循环第 2 轮）· FORCE-COOP：把力觉传感与人机协作做成 ZEST 之上的胜任力-合规层

> 检索/复核日期：**2026-11-03（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮三个词是「力觉传感」「人机协作」「机器人」。**不推倒**第 10–15 轮，研究线累计：FACT-VLA → GEO-RESIDUAL → CHUNK-SERVO → WAVE-SERVO → VOI-MAP → ZEST-VLA。FORCE-COOP 是 ZEST-VLA 之上的**物理交互层**：ZEST 决定「VLA 动作块该不该信」，FORCE-COOP 决定「当不信任时，是否让位给力觉引导的人机协作合规执行」。

## 0. 先给直觉：从「不信任自己」到「学会让位」

第 15 轮 ZEST 用动作-观测残差把零样本失败从「自信地错下去」变成「受控地退一步」。它解决了执行者胜任力不确定性，但留下两个更深的假设：

> A1. 退一步就是几何原语。A2. 物理交互的反馈只来自视觉/运动学。

在接触丰富的桌面任务里，这两个假设会失效。插入、开合、挂取、按压都需要力觉闭环；VLA 对接触力的预测几乎为零，视觉残差对微观滑移、卡滞不敏感。更关键的是，人机协作的本质是**力是意图的直接载体**：当机器人不确定时，物理上的让位比几何原语更安全、更零样本。

本轮的直觉是：**把力觉传感从被动安全变成主动决策信号**。力是环境对动作的即时回执，比下一帧图像更快、比残差更物理。把力残差、力接触模式与人机意图估计做成第三类自监督信号，与 ZEST 的视觉残差融合，形成「信不信 VLA → 能否让位 → 如何协作」的三级门控。

一句话押注：

> **第 15 轮用「动作-观测一致性」决定信不信 VLA；本轮用「力-运动一致性 + 人机意图」决定何时让位给力控合规：把力残差、接触分类与自适应阻抗做成风险受控的协作门，让零样本接触失败从「退回几何原语」升级为「物理上让位并等待/借力」**。

三个可验证创新点：
1. **推理期力觉自监督**：力残差 r_f、接触相位 c_f、力-运动一致性全部来自本机 F/T 与电机电流，无需标签、无需第二模型；用 G13 验证力信号能否区分 OOD-E/OOD-C。
2. **人机协作门控**：基于力模式的意图估计 + 自适应阻抗 + 滞回复检；给出力干扰下假激活控制、合规安全、恢复边界的命题；用 G13/G14 验证。
3. **协作增强的零样本降级**：把 VOI-MAP/ZEST 的动作集扩展为 `SERVO / LOOK / VLA / FALLBACK / COMPLIANT / HOLD`，其中 `COMPLIANT` 是力控让位/借力模式；用 G14 验证未见接触任务上的受控让位。

三个词怎么落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **力觉传感** | 力残差 r_f、接触相位检测、阻抗自适应、力-运动一致性门 | 不做离线力学习；不训练力预测网络；不做力微调 |
| **人机协作** | 力意图估计、共享控制融合、协作门控、复检恢复 | 不做真实人手持交互评测；不引入语音/手势模型 |
| **机器人** | 全系统层级 L5→L4→L3→L2→L1，统一符号、成本、预算 | 不堆模型；不破坏单模型合规；不新增执行通路 |

## 1. 研究日志：为什么是这一层

### 1.1 第 15 轮留下的两个「未付费假设」

```text
A1. 降级就是几何原语。 
A2. 物理交互可被视觉残差覆盖。
```

A1 在插入/挂取/按压上代价高：几何原语需要精确位姿，误差 2-3 mm 就卡死。A2 在接触瞬态上失效：视觉帧率、遮挡、透明会让 r_geo 滞后 1-2 块，而力信号 1kHz 内可检测。

### 1.2 三个新判断

1. **力是比视觉更快的自监督信号**。力残差不依赖特征匹配，对滑移、卡滞、过载的检测延迟更低。把力-运动一致性做成自监督，可在不更新权重的前提下校准一个一维信任阈值。
2. **人机协作本质是合规性**。当 ZEST 触发不信任且几何原语不可行时，合规让位比强行执行更安全。力意图估计把「外部力」解释为「修正意图」，而非「干扰噪声」。
3. **正确的对象是风险受控的让位**。固定阻抗会过度让位；永久合规会过度保守。我们用 conformal 控制力假激活、用 CUSUM 检测持续力异常、用滞回复检恢复。

### 1.3 与第 15 轮的关系

| 层 | 第 15 轮 ZEST | 第 16 轮 FORCE-COOP |
|---|---|---|
| 不确定性 | 执行者胜任力 c_t、视觉残差 | 胜任力 + 力一致性 + 人机意图 |
| 自监督 | 动作-观测残差 | + 力-运动残差 + 接触相位 |
| 调度 | SERVO/LOOK/VLA/FALLBACK/COMMIT | + COMPLIANT/HOLD |
| 零样本 | 几何原语降级 | 力控让位 + 几何原语降级 |
| 安全 | WAVE-SERVO 限幅 | 继承 + 阻抗自适应 + 力限幅 |
| 统计 | 预注册 A/B | 继承 + 力假激活/恢复端点 |

**保留**：FACT-VLA 相位化、GEO-RESIDUAL、CHUNK-SERVO、WAVE-SERVO、VOI-MAP、ZEST 的 conformal/CUSUM 门控。
**升级**：从「视觉信任门」升级到「视-力-人信任-协作门」；从「退回原语」升级到「合规让位 + 原语」。
**剪枝**：不训练力预测模型；不做力微调；不引入第二个策略网络。

## 2. 机制草图

### 2.1 力觉自监督残差

块 b 结束后计算：
```text
r_f   : || f_obs - f_pred(cmd) || / (||f_cmd||+ε)   # 力-运动一致性
r_c   : 接触相位突变指示 1[phase_t ≠ phase_{t-1}] 
r_h   : 人机意图分数 = σ( w1·||f_ext|| + w2·df/dt + w3·持续时间 )
```
f_pred 通过刚体动力学 + 已知阻抗模型预测。

### 2.2 信任-协作门

```text
z_f = r_f/σ_f,  z_h = r_h/σ_h
s'_t = s_t + w_f z_f + w_h z_h
e'_t = 1[s'_t > q'_α]
S'_t = max(0, S'_{t-1}+e'_t - α' - k')
```
触发后：
- TRUST → COMPLIANT 若 r_h 高且 r_f 高 → 让位
- TRUST → FALLBACK 若 r_h 低且几何可行
- COMPLIANT 中每 r 块做一次 SERVO 探针，恢复则回 TRUST

### 2.3 合规控制

COMPLIANT 模式下 WAVE-SERVO 切换为自适应阻抗：
```text
M_des = M0·(1 - λ·c_t),  D_des = D0·(1 + λ·c_t)
```
c_t 为软胜任力，低时更柔。

## 3. 可证伪假设

| 编号 | 假设 | 证伪条件 |
|---|---|---|
| H1 | 力残差能区分 OOD-C，AUROC≥0.8 | AUROC<0.65 或力假激活>10% |
| H2 | FORCE-COOP 在接触 OOD 上成功率≥+5pp，ID 不回归>2pp | 无提升或 ID 回归 |
| H3 | COMPLIANT 比永久 FALLBACK 在瞬态接触上更好 | 复检不优于永久 fallback |
| H4 | 人机意图估计不误触发合规 | 假协作率>5% |

## 4. 放弃条件

力假激活>10%、COMPLIANT 导致超时率上升、力传感器不可用时退回 ZEST-only。

## 5. 一句话押注

**第 15 轮学会不信任自己；本轮学会在不信任时物理让位：力残差 + 人机意图估计 + 自适应阻抗，让零样本接触失败从「退一步」变成「让一步并借力」**。

## 6. 本轮最大风险

**力传感的 OOD 耦合：当 VLA 错误目标与力传感的噪声/基线漂移同时出现时，力残差会像 ID，协作门不会触发，系统会以合规方式执行一个错误的目标。** 这是视-力双通道共享错误先验的盲区，不能靠调参解决。

# 第 16 轮产物 · FORCE-COOP 技术报告

> 检索/复核日期：**2026-11-03（UTC）**。对象：宇树 UniBot 世界挑战赛 G1+Dex1，32 项桌面任务，通才单模型赛道。本报告是研究线累计第 16 轮产物，在第 15 轮 ZEST-VLA 胜任力层之上增加**力觉感知的人机协作层**。不替换 FACT-VLA、GEO-RESIDUAL、CHUNK-SERVO、WAVE-SERVO、VOI-MAP、ZEST。

## 0. 结论与边界

### 0.1 一句话结论
ZEST 用视觉残差决定信不信 VLA；FORCE-COOP 用力残差 + 人机意图决定何时让位。系统在不信任且几何不可行时进入自适应阻抗 COMPLIANT 模式，实现风险受控的物理让位与借力。零样本泛化从「退回几何原语」升级为「退回合规协作」。

### 0.2 证据等级
A 官方规则/API；B 公式与合成实验；C 设计假设待 G13-G16 验证；U 未核验文献排除。

## 1. 承接

第 15 轮 ZEST 解决视觉信任门，留下力觉盲区与降级僵硬。本轮保留 ZEST 所有机制，增加 L5 力觉协作层：
L5 FORCE-COOP → L4 ZEST → L3 VOI-MAP → L2 WAVE-SERVO → L1 VLA。
门控只删动作，不新增执行通路。

## 2. 符号与形式化

设力/torque 观测 f_t ∈ ℝ⁶，电机电流 i_t。
块 b 结束后：
r_f_b = || f_obs_b - f_pred_b || / (||f_cmd_b||+ε)
r_c_b = 1[ phase_b ≠ phase_{b-1} ]
r_h_b = σ( w1||f_ext|| + w2||df/dt|| + w3·T_contact )
归一化 z_f = r_f/σ_f，融合分数 s'_b = s_b + w_f z_f + w_h r_h_b。
conformal 分位数 q'_α 由 ID 校准集求得，CUSUM S'_b = max(0, S'_{b-1}+e'_b-α'-k')。
触发阈值 h'。

合规阻抗： M_des = M0·(1-λc_b), D_des = D0·(1+λc_b)，c_b 为软胜任力。

## 3. 算法

**离线校准**：收集 ID 任务力残差，求 q'_α。
**在线循环**：
1. 更新语义地图、相位。
2. 信任门给出允许集 A_adm。
3. 执行块，记录 f_t。
4. 计算 r_f, r_c, r_h，融合 s'_b。
5. 更新 CUSUM，模式切换 TRUST/COMPLIANT/FALLBACK/HOLD。
6. COMPLIANT 模式下切换自适应阻抗，每 r 块探针恢复。
7. 调度器按 Δ/cost 选择动作。

伪代码核心：
```
if mode==TRUST and S'>h':
   if r_h>θ_h and domain!=geometric: mode=COMPLIANT
   elif domain==geometric: mode=FALLBACK
elif mode==COMPLIANT: impedance_adapt(c_b); probe()
```

复杂度：力残差 O(6)，整体 <1 ms/块，内存 <12 MB。

## 4. 性质与正确性

命题1 无监督：力残差仅依赖观测/动作，不更新权重。
命题2 力假激活控制：split conformal 给出边际保证 Pr(e'>0)≤α'。
命题3 安全降级：COMPLIANT 仍走 WAVE-SERVO 限幅，动作集为子集。
命题4 不可检测边界：若力噪声/基线漂移与 VLA 错误共享先验，力残差不可区分。

## 5. 实验设计

G13 力区分：ID 假激活≤15%，OOD-C AUROC≥0.8。
G14 零样本：接触类任务 +5pp，ID 回归≤2pp。
G15 安全：力限幅不超，p99≤150ms。
G16 协作：假协作率≤5%。

预注册假设 H1-H4 同想法区。

## 6. 风险

力传感漂移导致假激活、COMPLIANT 过柔导致超时、人机意图误判导致安全风险。最大风险已在想法区说明。

## 7. 一句话押注

**第 15 轮学会不信任自己；本轮学会在不信任时物理让位：力残差 + 人机意图 + 自适应阻抗，让零样本接触失败从「退一步」变成「让一步并借力」**。

## 8. 本轮最大风险

**力传感的 OOD 耦合：当 VLA 错误目标与力传感基线漂移/噪声同时出现时，力残差会像 ID，协作门不会触发，系统会以合规方式执行错误目标。**
