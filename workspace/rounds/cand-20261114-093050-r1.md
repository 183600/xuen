# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「推理延迟」×「运动学」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略呈现歧义，再用主动多模态交互（看/问/触）去消解。但 R69 有一个从未被审视的隐含假设——**思考不花时间**。它把推理延迟当成一个静态的 P99 预算（<2.6ms），把 VoI 当成与时间无关的标量，把交互当成瞬时完成的动作。真实系统里，这三点全错：
>
> - 推理本身要时间：多采 K 条轨迹、算 FMA 似然、跑 VoI 枚举，都是毫秒级的真时间；
> - 世界在思考时继续运动：你为 t 时刻算出的动作，到 t+Δ 才落地，Δ 内世界已经移动；
> - 信息动作更慢：眼动约 200ms、探针约 300ms、问一句要等人数秒——**最省力的求证，往往最慢**。
>
> 若延迟只是一段「死时间」，补一个预测器即可。但两个灵感合起来给出更深的判断：**推理延迟的代价，本质上是一个运动学量。** 同样 2ms，在 0.1m/s 时微不足道，在 2m/s 且距人 1m 时就是生死之差；同样「等一秒再问」，在车流中等于没问，在厨房里却绰绰有余。也就是说，**「该想多久、来不来得及想」不是算力问题，而是由速度、加速度、抖动（jerk）与时间-到-接触共同决定的物理问题。**
>
> 核心命题：**把「思考」显式建模为一个消耗时间、并因此改变世界的物理动作；用运动学把「时间」翻译成「风险」，让「要不要交互」「要不要多采样」「要不要再等一拍」统一在同一个以毫秒为货币的经济学框架下求解。** 命名 **KAIROS-RAS**（Kinematic-Aware Inference with Risk-optimal Opportunistic Stopping）——KAIROS，希腊语的「恰当时机」。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我此刻还来得及想吗、值得想多久**」——推理延迟不是工程预算，而是一个会改变世界状态的物理动作。

## 0. 直觉与动机

**灵感 1（推理延迟 → 思考是一种「占用时间的动作」）**
直觉：R69 的闭环读起来像：采样→分解→算 VoI→交互→决策，一气呵成。但在真实控制环里，这串操作要花 Δ_think，而执行器在 Δ_think 内要么保持上一动作、要么在等指令。**等待本身就是一种动作**（保持当前速度前进、原地悬停、继续伸手）。于是「多想一毫秒」不是一个免费的内部事件，而是在世界状态图上走了一步；延迟的代价必须计入决策，而不是事后用一个 P99 预算去「保证不超」。

**灵感 2（运动学 → 把时间换算成风险的、无需动力学模型的汇率）**
直觉：要知道「晚 2ms 有多危险」，严格做法需要精确的动力学/接触模型——而这恰是最不可靠的部分。运动学给了一个便宜且保守的替代：只看位置/速度/加速度/jerk 的几何，就能给出「未来 Δ 内风险最多恶化多少」的上界。关键量是**运动学时间常数** τ_kin：到安全边界的距离除以接近速度（或 TTC 减去制动时间）。它把绝对时延 Δ 变成无量纲的**归一化时延** Δ̃=Δ/τ_kin。Δ̃≪1：想多久都无所谓；Δ̃~1：每一毫秒都在改变风险。这层「汇率」不依赖力模型，因此可认证、可在实时环里算。

**灵感 3（时效贴现 → 迟到的信息等于没有信息，甚至误导）**
直觉：R69 的 VoI 假设「拿到信息就赚」。但信息有**保质期**。若场景会在你犹豫期间自行揭晓（人要么左转要么右转，看一眼就够），那**等待是免费的观测**——被动解析比任何主动交互都便宜。反过来，若你要问的那句话等回答时决策窗口早已关闭（车已到跟前），这条信息的有效价值为零。故 VoI 必须乘一个**时效贴现**，贴现因子由 Δ_g/τ_kin 决定。推论极强：**运动越快，可用的追问模态越少**——τ_kin 很小时，问句（秒级）永远来不及，只剩「看一眼」（百毫秒）甚至「直接保守」。

**灵感 4（延迟阶梯 → 先按运动学筛模态，再按 VoI 排序）**
直觉：不同信息动作的时延差了几个数量级：内部多采样（<1ms）≪ 复看/眼动（~200ms）≪ 物理探针（~300ms）≪ 向人提问（1–5s）。R69 把它们塞进同一个 argmax，隐含假设它们「同时可得」。KAIROS 先做一道**运动学准入过滤**：只有 Δ_g < β·τ_kin 的模态才有资格进入 VoI 竞争。这不是保守，而是正确——你无法用一把要 3 秒才拔得出来的尺子，去量一辆 0.3 秒后撞上来的车。

**灵感 5（最优停止 → 「想多久」是随时可停的决策，而非固定档位）**
直觉：R69 用 mode_head 的硬阈值在 K=1 与 K=4 之间跳。但「多采一条样本」收益递减、成本与运动学紧迫度成正比：场景越急，多等一条越亏；场景越缓，多想越值。于是采样应是一个**最优停止**过程：每多采一条，比较「降低模态不确定带来的期望风险下降」与「多花 Δt 带来的运动学风险上升」，后者超过前者就停。这条规则把 R69 的 K=1（急）与 K=4（缓）**内插成连续谱**，并让算力随时可被抢占——因为每一步都已有一个可执行动作。

**灵感 6（运动学商 → 正面回应 R69 最大风险「幻影模态」）**
直觉：R69 最怕流模型幻觉出不存在的模态，导致系统去追问一个幻影。运动学给了一把筛子：很多「模态」只是同一条路径的不同时间参数化（同样左转，只是快慢不同），在位置空间离得远，在**（位置,速度,加速度,jerk）** 的运动学空间里几乎重合。按**时间重参数化群**做商，幻影模态大量坍缩，有效模态数 K_eff 骤降，VoI 与 U_epi 随之下降——**这是对 R69「问错比不问更危险」的部分解**：先别问，先看这是不是一个真实可分的动作分歧。

**灵感 7（新的威胁：认知冻结）**
直觉：一旦「不确定→多想想」写进策略，就出现一种全新攻击：**在关键时刻把场景伪装得既模糊又紧迫，诱导机器人「停下来想」**——分析瘫痪。攻击者不必撒谎，只需制造歧义，就能让一个安全优先系统的反应时间被自己的「谨慎」吃光。因此 KAIROS 必须有一条由运动学硬性导出的**审议上限**：再想也不能想到「来不及刹车」之后。安全底线是：最多退回 R68 的保守，绝不能被诱导到「因思考而失守」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（KAIROS-RAS 总览）** KAIROS-RAS = (KTE, LAD, LVOI, AIR, KMS, KFC, DTA, RAS-WM‡)，在 FLUID-RAS 之外叠加时间层。四不变式：
(i) **一切计算皆有时延**：任何模块的产出都带显式时间戳与延迟下界，绝不假设零成本；
(ii) **随时安全**：任一迭代结束时都必须存在一个已认证的可执行动作（R68 兜底永远在场），抢占/超时不得使输出未定义；
(iii) **审议有硬上限**：Δ_total ≤ τ_cap(s) = TTC(s) − t_stop(v) − ε_margin，由运动学直接导出，任何「多想/多问」都不得突破；
(iv) **时间-风险汇率一致**：所有时间消耗（采样、注视、探针、问句）都用同一 σ_kin(s) 折算为风险增量，禁止各模块私下定义「免费时间」。

**定义 311（运动学状态、时间常数与 KLS）** 运动学状态 κ_t = (p, v, a, j, κ_curv)（位置、速度、加速度、jerk、曲率），以及相对障碍/人的接近速度 v_rel 与距离 d。**运动学时间常数** τ_kin = min(d_safe / max(‖v_rel‖, v_0), TTC)，其中 d_safe 为安全裕度距离、v_0 防止除零。**归一化时延** Δ̃ = Δ/τ_kin。**运动学风险率（KLS）** σ_kin(s) = dR/dΔ ≥ 0，是当前状态下「每延迟 1ms，风险函数 R 的期望增量」，由 R 沿预测轨迹对时间的导数给出，可用 v、a 与 TTC 给出保守下界（引理 19）。σ_kin 只依赖运动学几何，不需要力/接触模型。

**定义 312（时延阶梯 LAD）** 每个动作（任务或信息）g 携带总时延 Δ_g = Δ_compute + Δ_actuate + Δ_sense + Δ_reason，按数量级分四阶：ℓ0 内部计算（采样/似然/VoI，<1ms）、ℓ1 再感知（复看/眼动，100–300ms）、ℓ2 物理探询（探针/轻触，200–500ms）、ℓ3 语言求证（问句 + 人类作答，1–5s）。同一物理交互的总时延取其所在阶的下界与实测分位。

**定义 313（时效贴现与 L-VoI）** 设决策承诺期限为 τ_c（在该时刻前必须下达不可撤回的动作）。信息动作 g 的有效信息价值
L-VoI(g) = VoI(g) · P(τ_g ≤ τ_c) · ρ(Δ_g/τ_kin) − c(g) − σ_kin·Δ_g，
其中 P(τ_g ≤ τ_c) 为「信息在承诺前到达」的概率，ρ∈(0,1] 为按时到达但已部分过时的时间贴现（默认 ρ(Δ̃)=e^{−Δ̃}），σ_kin·Δ_g 把等待本身的风险计入成本。**自解析情形**：若场景自身将在 τ_res < τ_c 内揭晓真实模态（可由模态间在预测观测上的可分辨性估计），则「等待」获得 VoI_wait = H(M|o) − E[H(M|o, 未来自然观测)]，且成本仅 σ_kin·τ_res；此时主动交互被被动等待支配。

**定义 314（运动学准入）** g 可进入 VoI 竞争 ⇔ Δ_g ≤ β·τ_kin（默认 β=0.5）且 g 通过 FLUID 定义 298/302 的全部安全与预算检查。不满足者直接剔除，不参与 argmax。这保证「模态可不可用」先由运动学裁决，再由信息价值排序。

**定义 315（渐进采样与最优停止 AIR）** 采样序列 K=1,2,…,K_max。在第 k 条样本后，边际收益 MB(k) = E[风险下降 | 第 k 条带来的模态后验改善]，边际成本 MC(k) = σ_kin·Δt_sample + ε_compute。停止规则：若 MB(k) ≤ MC(k) 或 Δ_total + Δt_sample > τ_cap，立即停并执行当前最优动作。K=1 时若已无歧义亦立即停。→ 由此 R69 的 K∈{1,4} 成为该规则在两个极端场景下的取值。

**定义 316（时延-预测权衡 DTA）** 为补偿时延，用预测器把状态前推到 t+Δ：ŝ(t+Δ)=s(t)+vΔ+½aΔ²+…。预测误差由 jerk 界给出 ε_pred(Δ) ≤ ½·J_max·Δ²（或按 jerk 方差）。**审议时域** Δ* 由最小化 [残余模态风险 + ε_pred(Δ) + σ_kin·Δ] 求得。DTA 输出 (Δ*, 补偿轨迹)，并声明当 ‖j‖ 或 jerk 估计不可信时 ε_pred 爆炸、Δ* 自动收缩（定理 20 的安全侧）。

**定义 317（运动学商与有效模态数 KMS）** 动作轨迹 ξ 的**时间重参数化群** G_τ = {ξ∘φ : φ 保序时间变换}；以 (p,v,a,j) 加权的运动学度量 d_kin 定义等价类 [ξ] = argmin_{G_τ} d_kin。**有效模态数** K_eff = 在 d_kin 下、且经 G_τ 商化后仍两两可分（d_kin ≥ 3σ_kin_in）的模态数；幻影模态 = 原始聚类模态 − K_eff。U_epi 与 VoI 一律在 K_eff 上计算，而非在 K̂ 上。

**定义 318（认知冻结 / 时延拒绝 ℰ_lat）** 攻击者不撒谎，只制造「高歧义 + 高紧迫」的表象（对抗贴片、遮挡边界、诱导性场景）以最大化机器人「停下来想/去问」的概率，从而吃掉其反应时间；或直接注入算力负载/传感器洪泛使推理延迟升高。并入干扰集：ℰ_KAIROS = ℰ_FLUID × ℰ_lat × ℰ_kin（运动学欺骗：伪造低相对速度/远 TTC）。

**定义 319（承诺期限与审议硬上限）** τ_cap(s) = TTC(s) − t_stop(v, a_max) − ε_margin，t_stop 由运动学（制动能力）导出。要求 Δ_total(采样+交互+渲染) ≤ τ_cap。τ_cap ≤ 0 ⇒ 禁止任何新增计算与交互，直接取已认证的 R68 兜底动作。该上限优先于一切 VoI 与 MINT 决策。

**定义 320（随时安全契约）** 控制回路维护一个**影子动作** a_fallback（由 R68 保守策略在当前状态下给出并经 C-RAS-WM 认证）。任一时刻若计算被抢占/超时/异常，立即执行 a_fallback。每次 AIR 或交互得到的候选动作，只有在**同样通过认证且风险不高于 a_fallback** 时才可替换它。⇒ 输出对任意中断点都有定义（控制的「随时可交付性」）。

**定义 321（运动学可行性证书 KFC）** 与学习无关的物理检查：候选动作轨迹须满足 ‖v‖≤v_max、‖a‖≤a_max、‖j‖≤j_max、曲率 κ≤κ_max、以及 jerk 连续性；对含信息动作的联合轨迹，探针不得越力/位包络。KFC 只用运动学，**不信任流模型的标定**，因此是 R69「模态分布不可信」风险的一条外部旁证（与 FMA 的似然通道正交）。

**定义 322（时空一致性审计 VQAuditor-τ）** 在 FLUID 的 VQAuditor-I 上新增审计项：每个决策的 (Δ_think, Δ_g, τ_kin, τ_cap, Δ̃) 是否记账、是否越界、时效贴现是否被正确施加、K_eff 与 K̂ 的差是否被如实报告、认知冻结是否发生过。结论回灌 AuditBuf，成为下一轮 σ_kin 与 Δ_g 的实测先验。

**定义 323（证书 J_KAIROS）** J_KAIROS = (J_FLUID, τ_kin_p05, Δ̃_max, Δ_total_p99, τ_cap_violations(=0), K_eff/K̂ 比, L-VoI 记账, fallback_swap_count, kairos_ver)。Valid ⇔ Valid(J_FLUID) ∧ τ_cap 无越界 ∧ 随时安全契约满足 ∧ 时延账本完整。

**定义 324（时隙阴影价格与统一货币）** 令 T 为当前到承诺期限的剩余时间（时间松弛）。所有不确定性消解活动共享 T，其**阴影价格** λ_t(s) = σ_kin(s)（每毫秒的机会成本，即 KLS）。于是「多采一条」「看一眼」「问一句」都在同一价格下竞价：选择单位时间风险下降最大者，直到边际收益 < λ_t。R69 / R68 分别是 T 极大（时间不稀缺、只按 VoI−c 决策）与 T→0（时间无穷贵、只保守）的边界。

**定义 325（两级退避的时延扩展）** 在 FLUID 定义 307 之上再分一维：若 τ_kin 小到连 ℓ1 都不准入，则 **U_epi 直接视同 aleatoric**（来不及查 = 不可查），λ=λ_floor(U_ale+U_epi) 并取 K=1 单样本；若 τ_kin 适中且 L-VoI>0，则在准入模态中交互；若场景自解析，则等待 τ_res 后重估。⇒ 时间越紧，KAIROS 单调地越接近 R68；安全侧永不弱于 R68。

```python
# IP-264 KTE：运动学时间常数与风险率（O(1)，无动力学模型）
def kinematic_sensitivity(kin, R):
    v, a, j, d, v_rel = kin.v, kin.a, kin.j, kin.d, kin.v_rel
    tau   = min(kin.d_safe / max(v_rel, EPS), kin.ttc)        # 时间常数
    sigma = max(dR_dt(R, kin, kin.horizon), 0.0)              # dR/dΔ 下界
    return tau, sigma

# IP-265 LAD + 准入：先按运动学筛模态，再谈 VoI
def admissible_info_actions(cands, tau, beta=0.5):
    return [g for g in cands if g.delta_total <= beta * tau]

# IP-266 L-VoI：时效贴现 + 自解析等待
def latency_voi(g, modes, tau, tau_c, sigma):
    p_on_time = prob_arrive_before(g.delta_total, tau_c)
    rho       = exp(-g.delta_total / tau)
    return entropy(modes) * p_on_time * rho - g.cost - sigma * g.delta_total

def self_resolving(modes, horizon):
    # 模态在未来自然观测上是否将被区分开
    return predict_observation_separation(modes, horizon)

# IP-267 AIR：最优停止采样（随时可停、可被抢占）
def anytime_sample(policy, o, tau, sigma, tau_cap, dt=0.8e-3):
    xs, best, k = [], None, 0
    while k < K_MAX and k * dt < tau_cap:
        xs.append(policy.sample_one(o)); k += 1
        modes = cluster(xs)
        mb = expected_risk_drop(modes, best)
        mc = sigma * dt
        if best is not None and mb <= mc:
            break
        best = modes
    return best

# IP-268 KMS：运动学商，压掉幻影模态
def effective_modes(modes):
    classes = quotient_by_time_reparam(modes, metric=d_kin)   # (p,v,a,j) 加权
    return [c for c in classes if separating(c, 3 * sigma_in(c))]

# IP-269 KFC：不信任流模型的运动学可行性旁证
def kinematic_feasible(xi):
    return all([
        norm(xi.v) <= V_MAX, norm(xi.a) <= A_MAX, norm(xi.j) <= J_MAX,
        curvature(xi) <= KAPPA_MAX, jerk_continuous(xi),
    ])

# IP-274 主闭环（继承 FLUID，插入时间层）
def KAIROS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    tau, sigma = M.kte.kinematic_sensitivity(M.kin, M.risk)
    tau_cap    = max(0.0, M.kin.ttc - M.kin.t_stop - M.eps_margin)
    a_fb       = M.r68_fallback(o)                     # 影子动作，已认证
    if tau_cap <= 0:                                   # 来不及想 → 立即兜底
        return M.c_ras_wm.certified(a_fb)
    # 1) 随时可停的采样；急则早停
    modes = M.air.anytime_sample(M.fmp, o, tau, sigma, tau_cap)
    modes = M.kms.effective_modes(modes)               # 幻影模态坍缩
    U_ale, U_epi, _ = M.aud.decompose(modes, z)
    # 2) 先按运动学准入，再按时效 VoI 选交互；来不及查 = 不可查
    cands = M.lad.admissible_info_actions(M.mint.candidates(modes), tau)
    g = M.lvoi.choose(cands, modes, tau, tau_cap, sigma) if U_epi > TAU_EPI else None
    if g is None and M.lvoi.self_resolving(modes, tau_cap):
        modes = M.wait_and_reobserve(o, tau_res=min(tau, tau_cap))   # 免费观测
    elif g is not None:
        modes = M.cia.update_belief(modes, M.cia.execute(g))
    # 3) 时间预算再核算：交互后可能只剩极少时间
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0)))
    A   = M.ach.propose(M.dta.roll_forward(o, delta=(g.delta_total if g else 0)),
                        M.vista.H)
    if not M.kfc.kinematic_feasible(A):                # 运动学不可行 → 回影子动作
        return M.c_ras_wm.certified(a_fb)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if M.clock.total() > tau_cap:                      # 审议/交互越界 → 兜底
        return M.c_ras_wm.certified(a_fb)
    M.vqa_tau.submit_async(tau, sigma, tau_cap, g, U_epi)
    return M.c_ras_wm.certified(A[:k]) * lam
```

## 3. 推导

**引理 19（时延-风险放大）** 在 jerk 有界（A99）假设下，状态前推误差与风险增量满足 R(s(t+Δ)) − R(s(t)) ≥ σ_kin·Δ − ½L_R·Δ²，其中 σ_kin 由 ‖v‖、TTC 与 d_safe 给出正下界；当 Δ≪τ_kin 时线性项主导。系：**风险对时延的敏感度由运动学时间常数 τ_kin 唯一标定**，因此「多少毫秒算多」是状态相关的，不存在全局常数。

**引理 20（时效准入的支配关系）** 若 τ_kin ≪ Δ_ℓ3（问句时延），则对任意 L-VoI 有限的问句 g_ask，存在低阶动作 g_ℓ1 使 L-VoI(g_ℓ1) > L-VoI(g_ask)；特别地当 P(τ_g ≤ τ_c)=0 时 L-VoI(g_ask) ≤ −c < 0。系：**运动越快，可行求证模态越少**——可用模态集合随 τ_kin 单调收缩；这是物理约束，不是工程调参。

**引理 21（运动学商消除幻影模态）** 若一个「模态」仅由时间重参数化 φ∈G_τ 产生（同一路径、不同速度剖面），则 d_kin([ξ_i],[ξ_j]) = 0，在 KMS 商化后并入同一类；故 K_eff ≤ K̂，且被消除的模态不携带任务决策信息（其任务动作终点与运动学终点一致）。**部分回应 R69 的最大风险**：幻影模态中相当一部分是同路径异时，商化后不再驱动无效追问。但须诚实：**真正带不同终点的幻觉模态不能被 KMS 消除**（见第 6 节）。

**引理 22（认知冻结攻击的界）** 在定义 319 的硬上限与定义 320 的影子动作下，无论攻击者如何制造歧义或负载，系统在每个时刻都至多退化为 a_fallback；故冻结攻击能造成的风险 ≤ R68 在当前状态的风险，且 Δ_total 不可能超过 τ_cap。系：**「想得越久越安全」是错的；「无论想多久，安全底线不变」才对。**

**定理 18（KAIROS 严格包含 FLUID 与 R68）** 在 A95–A100 下：(a) 当 τ_kin → ∞（时间不稀缺）、无 ℰ_lat、且自解析不成立时，KAIROS 的准入与停止规则退化为 FLUID 的 VoI argmax 与 K∈{1,4}，逐指令一致；(b) 当 τ_kin → 0 或 τ_cap ≤ 0 时，KAIROS 退化为 R68 的保守执行 a_fallback；(c) 中间情形下，任意状态期望风险 ≤ min(FLUID, R68 的最差情形)（在 L-VoI 记账正确的前提下）。故 FLUID 是「无限时间」边界、R68 是「零时间」边界，二者都是 KAIROS 的退化。

**定理 19（随时安全与无突变）** 在定义 320 的影子动作契约下，对任意抢占点、任意 ℰ_lat 注入、任意 KFC 失败，输出始终为经 C-RAS-WM 认证的动作，且控制连续（切换仅在认证通过且风险不升时发生）；继承 R68 定理 15 的提交/换装不变式。⇒ 审议时间可被任意裁剪而不破坏安全性（可「随时交付」）。

**定理 20（自适应审议的稳定性）** 当 jerk 估计的置信上界 J_max 增大时，ε_pred(Δ)=½J_maxΔ² 使 DTA 的最优审议时域 Δ* 单调收缩；故运动学越不可预测，KAIROS 自动越早停、越接近 R68 的即时反应——**不确定自己的预测能力时，系统自动选择「少想、快做」**。这是对「运动学惊喜」的第一道结构性防线（但非万全，见第 6 节）。

## 6. 本轮最大风险

**一句话**：KAIROS 的全部「聪明」都建立在「延迟的代价可以用运动学汇率 σ_kin 折算」这一前提上——但运动学描述的是**已发生**的运动，真正决定代价的是**未来**，而未来恰恰可能在下一刻发生不连续（急停、猛冲、遮挡后突然出现的人）。系统越处于平滑可预测的运动中，σ_kin 估计越准、审议越敢推迟，而灾难常正是从平滑中突然出现——**KAIROS 会在运动学惊喜到来前的最后一刻最有信心、也最不设防。**

**次级风险与缓解**：
1. **σ_kin 的模型偏差**（恒定速度/低 jerk 假设在真实场景失效）→ 用保守下界（引理 19）+ jerk 置信上界驱动 Δ* 收缩（定理 20）+ 真实 TTC 传感器冗余；
2. **时效贴现参数 ρ、β 误设** → A/B 标定 + VQAuditor-τ 记账 + 以实测到达分布重估；
3. **认知冻结 / 时延拒绝** → 定义 319 硬上限 + 定义 320 影子动作 + 引理 22 上界（最坏退化为 R68）；
4. **KMS 商化把真模态误并**（两个不同终点恰好运动学相近）→ 仅在终点/风险签名一致时商化，否则保留；KFC 与终点可分性双重校验；
5. **过度早停导致欠思考**（急场景下过早执行欠优动作）→ 保留 FLUID 的 resolution bonus 记账，用 E306/E315 量化「欠思考税」，绝不以安全换时间。

## 3. 关键算法伪代码

```python
# IP-264 KTE：运动学时间常数与风险率
def kinematic_sensitivity(kin, R):
    tau   = min(kin.d_safe / max(kin.v_rel, EPS), kin.ttc)
    sigma = max(dR_dt(R, kin, kin.horizon), 0.0)          # dR/dΔ 保守下界
    return tau, sigma

# IP-265 LAD：先按运动学准入，再谈 VoI
def admissible_info_actions(cands, tau, beta=0.5):
    return [g for g in cands if g.delta_total <= beta * tau]

# IP-266 L-VoI：时效贴现 + 自解析等待
def latency_voi(g, modes, tau, tau_c, sigma):
    p_on_time = prob_arrive_before(g.delta_total, tau_c)
    rho       = exp(-g.delta_total / tau)
    return entropy(modes) * p_on_time * rho - g.cost - sigma * g.delta_total

# IP-267 AIR：最优停止采样（随时可停）
def anytime_sample(policy, o, tau, sigma, tau_cap, dt=0.8e-3):
    xs, best, k = [], None, 0
    while k < K_MAX and k * dt < tau_cap:
        xs.append(policy.sample_one(o)); k += 1
        modes = cluster(xs)
        if best is not None and expected_risk_drop(modes, best) <= sigma * dt:
            break
        best = modes
    return best

# IP-268 KMS：运动学商，压掉幻影模态
def effective_modes(modes):
    classes = quotient_by_time_reparam(modes, metric=d_kin)   # (p,v,a,j) 加权
    return [c for c in classes if separating(c, 3 * sigma_in(c))]

# IP-269 KFC：不信任流模型的可行性旁证
def kinematic_feasible(xi):
    return (norm(xi.v) <= V_MAX and norm(xi.a) <= A_MAX
            and norm(xi.j) <= J_MAX and curvature(xi) <= KAPPA_MAX
            and jerk_continuous(xi))

# IP-274 主闭环（继承 FLUID，插入时间层）
def KAIROS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    tau, sigma = M.kte.kinematic_sensitivity(M.kin, M.risk)
    tau_cap    = max(0.0, M.kin.ttc - M.kin.t_stop - M.eps_margin)
    a_fb       = M.r68_fallback(o)                     # 影子动作，已认证
    if tau_cap <= 0:
        return M.c_ras_wm.certified(a_fb)              # 来不及想 → 立即兜底
    modes = M.kms.effective_modes(
        M.air.anytime_sample(M.fmp, o, tau, sigma, tau_cap))   # 随时可停
    U_ale, U_epi, _ = M.aud.decompose(modes, z)
    cands = M.lad.admissible_info_actions(M.mint.candidates(modes), tau)
    g = M.lvoi.choose(cands, modes, tau, tau_cap, sigma) if U_epi > TAU_EPI else None
    if g is None and M.lvoi.self_resolving(modes, tau_cap):
        modes = M.wait_and_reobserve(o, tau_res=min(tau, tau_cap))
    elif g is not None:
        modes = M.cia.update_belief(modes, M.cia.execute(g))
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0)))
    A   = M.ach.propose(M.dta.roll_forward(o, g.delta_total if g else 0), M.vista.H)
    if not M.kfc.kinematic_feasible(A) or M.clock.total() > tau_cap:
        return M.c_ras_wm.certified(a_fb)              # 越界/不可行 → 回影子动作
    M.vqa_tau.submit_async(tau, sigma, tau_cap, g, U_epi)
    return M.c_ras_wm.certified(A[:M.c_ras_wm.certified_prefix(A, ..., wm_preds)]) * lam
```

## 4. 推导

**引理 19（时延-风险放大）** jerk 有界（A99）下，`R(s(t+Δ))−R(s(t)) ≥ σ_kin·Δ − ½L_RΔ²`，σ_kin 由 ‖v‖、TTC、d_safe 给出正下界；Δ≪τ_kin 时线性主导。系：**风险的时延敏感度由 τ_kin 唯一标定**，「多少毫秒算多」是状态相关的，无全局常数。

**引理 20（时效准入的支配关系）** 若 τ_kin ≪ Δ_ℓ3，则对任意 L-VoI 有限的问句 g_ask，存在低阶 g_ℓ1 使 L-VoI(g_ℓ1) > L-VoI(g_ask)；当 P(τ_g≤τ_c)=0 时 L-VoI(g_ask) ≤ −c < 0。系：**运动越快，可用求证模态越少**，可用模态集随 τ_kin 单调收缩——物理约束，非调参。

**引理 21（运动学商消除幻影模态）** 仅由时间重参数化 φ∈G_τ 产生的「模态」满足 d_kin=0，商化后合并，K_eff ≤ K̂，且被消除者不带任务决策信息。**部分回应 R69 最大风险**（幻影追问），但带不同终点的幻觉模态消不掉（见第 7 节）。

**引理 22（认知冻结攻击的界）** 在 τ_cap 硬上限与影子动作下，无论攻击者制造歧义或负载，系统至多退化为 a_fallback；冻结攻击风险 ≤ R68 当前风险，且 Δ_total ≤ τ_cap。系：**「想得越久越安全」错；「无论想多久，安全底线不变」对。**

**定理 18（严格包含 FLUID 与 R68）** A95–A100 下：(a) τ_kin→∞ 且无 ℰ_lat、自解析不成立时退化为 FLUID 的 VoI argmax 与 K∈{1,4}，逐指令一致；(b) τ_kin→0 或 τ_cap≤0 时退化为 R68 的 a_fallback；(c) 中间情形期望风险 ≤ min(FLUID, R68 最差)，前提是 L-VoI 记账正确。故 FLUID=无限时间边界、R68=零时间边界。

**定理 19（随时安全与无突变）** 影子动作契约下，任意抢占点 / ℰ_lat 注入 / KFC 失败，输出恒为已认证动作，控制连续（切换仅当认证通过且风险不升）；继承 R68 定理 15 的提交/换装不变式 ⇒ 审议可被任意裁剪而不破坏安全。

**定理 20（自适应审议的稳定性）** J_max 增大 ⇒ ε_pred(Δ)=½J_maxΔ² 使 Δ* 单调收缩 ⇒ 运动学越不可预测，系统越早停、越接近 R68 即时反应——**不确定预测能力时自动「少想、快做」**。

## 7. 本轮最大风险

**一句话**：KAIROS 的全部「聪明」都建立在「延迟的代价可以用运动学汇率 σ_kin 折算」这一前提上——但运动学描述的是**已发生**的运动，真正决定代价的是**未来**，而未来恰恰可能在下一刻发生不连续（急停、猛冲、遮挡后突然出现的人）。系统越处于平滑可预测的运动中，σ_kin 估计越准、审议越敢推迟，而灾难常正是从平滑中突然出现——**KAIROS 会在运动学惊喜到来前的最后一刻最有信心、也最不设防。**

**次级风险与缓解**：σ_kin 模型偏差（保守下界 + jerk 上界收缩 Δ* + TTC 冗余）；ρ/β 误设（A/B 标定 + VQAuditor-τ 记账 + 实测到达分布重估）；认知冻结/时延拒绝（τ_cap 硬上限 + 影子动作 + 引理 22 上界，最坏退化 R68）；KMS 误并真模态（仅终点/风险签名一致时商化 + KFC 与终点可分性双校验）；过度早停欠思考（保留 resolution bonus 记账，用 E306/E315 量化「欠思考税」，绝不以安全换时间）。
