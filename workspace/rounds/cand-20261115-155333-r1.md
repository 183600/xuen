# 第 8 轮（新灵感循环第 1 轮；本轮灵感：「云边协同」×「隐私保护」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> 本轮纪律：**云边分层 + 隐私预算**。云只提供“顾问证书”，边保留实时安全主权；隐私不是事后匿名化，而是与在线学习耦合的一等资源。任一云/隐私组件失效，必须**单调退化**到第 7 轮，再退化到第 6 轮。

## 0. 直觉与动机

**灵感 1（云边协同 → 证书顾问，而非循环上云）**
直觉：第 7 轮把 OTL、GCT、ER 全塞进机器人本体，但真正昂贵、频繁更新的是大模型语义解析、全局阈值先验、情感模型——它们天然属于云。然而 50Hz 的安全闭环不能依赖网络。因此正确的切法不是“把闭环搬到云”，而是：**边拥有实时闭环与硬约束主权，云只产出带版本、置信与有效期的“顾问证书”**。云可以提出更好的动作/阈值，但必须与边证书求交，绝不能扩大边已认证的可行集。核心创新：**云边证书对账 CECR** 与**边主权精化关系**。

**灵感 2（隐私保护 → 把 ε 变成一层指标）**
直觉：语音流同时携带身份、情绪与任务/位置信息；第 7 轮的 ER 还显式抽取情感，等于把最敏感的信号放大了。与其“先采集再匿名”，不如让每一次数据出境都**消耗一个不可再生的隐私预算 ε**：只上传特征/统计量而非原始音频，跨机器人聚合用 DP + 安全聚合。但 DP 噪声会扰动 OTL 的阈值，制造虚假退化。故隐私不能外挂，它必须进入指标层级，并与在线学习耦合。核心创新：**隐私预算阶梯 PBL** 与 **DP 平滑 OTL（带冻结门）**。

**灵感 3（两者交叉 → 隐私-效用-适应三元悖论）**
直觉：云越强（效用↑）、ε 越小（隐私↑）、OTL 越激进（适应↑），三者互斥：噪声大的统计让“适应”变成“抖动”。因此需要一个显式的**预算感知退化策略**：当噪声/预算不支持可靠学习时，宁可冻结自适应，也不要用噪声驱动退化。

## 1. 研究问题

- **Q1（边主权）**：如何定义一个精化关系，使得“有云”的系统行为是“无云”系统在硬约束满足意义下的合法精化，而不是安全性的新依赖？
- **Q2（DP-OTL 稳定性）**：在 (ε,δ)-DP 的噪声统计下，OTL 的收敛误差与虚假退化频率如何随 ε、N、η 变化？冻结门能否把退化频率压回无隐私噪声水平？
- **Q3（预算分配）**：在每任务总预算 ε_task 下，如何在 ASR/NLI、情感特征、OTL 聚合之间分配 ε，使任务完成率最大且 M₀/M₁ 不降？

## 2. 设计原则 P10–P12

**P10 云边证书对账（Cloud-Edge Certificate Reconciliation, CECR）**
云顾问证书 `A_c = (v_c, ŷ_c, conf_c, ε_c, ttl_c)`；边证书 `C_e`。对账只在**可行集求交**上做：
```
accept(C_e, A_c) ⇔ (v_c > v_e) ∧ (now < ttl_c) ∧ (ε_remaining ≥ ε_c) ∧ safe_dominance(C_e, A_c)
A_reconciled = A_c ∩ A_e        # 云只能加约束，不能扩大可行集
reconcile(C_e, A_c) = C_e ⊕ A_reconciled  if accept else C_e
```
`safe_dominance(C_e, A_c)` 表示 A_c 的每个建议动作在 M₀/M₁ 上与 C_e 同号或更保守（形式定义见产物区）。

**P11 隐私预算阶梯（Privacy Budget Ladder, PBL）**
每任务预算 `ε_task`，每类出境 `k` 的敏感度 `Δ_k` 与隐私成本 `ε_k` 满足高级组合：
```
ε_remaining = ε_task − Σ_k n_k·ε_k − ε_DP(δ)
若 ε_remaining < ε_k  ⇒  该类出境被拒绝（本地计算或跳过）
```
ε 进入指标层 M₄，作为一个**约束型资源指标**（不是可优化的效能指标）。

**P12 隐私感知的在线阈值冻结（DP-OTL with Freeze Gate）**
OTL 使用带噪充分统计量；当噪声标准差相对信号过大时冻结调节：
```
θ̂(t) = clip( (1/N)Σ(perf(k) − target) + Lap(Δ_perf/ε_otl), −θ_max, θ_max )
若 σ_noise > ρ·|θ̂(t)|  ⇒  τᵢ(t) := τᵢ(t−1)   # 冻结，不消费退化
否则 τᵢ(t) = clip(τᵢ(0) + η·θ̂(t), ε_min, ε_max)
```

## 3. 与基线的接口（单调退化）

- 云不可用 / 对账超时 ⇒ 纯边运行，等价第 7 轮（安全不降，仅性能降级）；
- ε 预算耗尽 ⇒ 冻结 OTL、关闭情感特征出境；ER 退化为本地特征或 β=0；
- DP 噪声过大 ⇒ 冻结门触发，τᵢ 停在上一可靠值，等价“OTL 暂时失效”⇒ 第 7 轮静态阈值分支；
- 三者同时失效 ⇒ 严格退回第 6 轮 MetricVoiceGauge。

## 4. 预期贡献

1. **CECR 与边主权精化定理**：证明云顾问永远不能削弱硬约束；
2. **M₄ 隐私层 + PBL 预算代数**：把隐私变成可审计、不可超支的指标；
3. **DP-OTL 冻结门**：给出噪声-收敛-退化频率的显式折中；
4. 实验 E526–E542 覆盖对账、边主权、DP 收敛、预算、成员推断、故障切换与端到端。

## 5. 本轮最大风险

**一句话**：云顾问与 DP 噪声可能共同诱发“证书抖动”——对账频繁接受/拒绝、OTL 频繁冻结/解冻，系统花掉隐私预算却学到随即被丢弃的阈值，最终把“隐私保护”变成不稳定的退化源。

## 1. 符号体系增量（定义 530–540）

| 符号 | 含义 |

| `ε_task` | 每任务隐私总预算 |
| `K = {voice, emo, otl, cloud}` | 数据出境类别集合 |
| `Δ_k` | 类别 k 的敏感度（相邻数据集查询结果的最大 L1 差） |
| `ε_k` | 类别 k 单次出境的隐私成本 |
| `L = (ε_task, δ, {n_k}, {ε_k})` | 隐私预算账本状态 |
| `A_c = (v_c, ŷ_c, conf_c, ε_c, ttl_c, t_issue)` | 云顾问证书 |
| `C_e = (v_e, A_e, cert_e)` | 边权威证书；`A_e` 为满足 M₀∧M₁ 的可行动作集 |
| `A = A_c ∩ A_e` | 对账后的动作集（云只能加约束） |
| `safe_dominance(C_e, A_c)` | 云建议在 M₀/M₁ 上不劣于边证书的判定 |

| `⪯_ea` | 边主权精化关系（edge-authority refinement） |
| `mode ∈ {full, no-cloud, frozen-otl, local-er, v6}` | 隐私感知退化模式 |

**定义 530（M₄ 隐私约束层）** 指标层级扩展为 `M = (M₀, M₁, M₂, M₃, M₄)`，其中 M₄ 不是被优化的效用，而是**可行性约束**：
```
M₄(s) = ok  ⇔  ε_remaining(s) ≥ 0 ∧ k_anon(s) ≥ k_min ∧ now < ttl(s)
```

**定义 531（隐私预算账本 PBL）** 账本状态与可支付性：
```
L = (ε_task, δ, {n_k}_{k∈K}, {ε_k}_{k∈K})
ε_spent(L) = min_{α>1} [ Σ_k n_k·ρ_k(α) + ln(1/δ)/(α−1) ]      # RDP → (ε,δ)
admissible(k) ⇔ ε_spent(L + e_k) ≤ ε_task
charge(k)     ⇔ if admissible(k) then n_k ← n_k + 1 else reject
ε_remaining(L) = ε_task − ε_spent(L)
```
`admissible` 是**单调**的：已花费不可退还，故 ε_remaining 非增。

**定义 532（云顾问证书 CloudAdvisory）**
```
A_c = (v_c, ŷ_c, conf_c, ε_c, ttl_c, t_issue)
```
其中 `v_c` 为云模型版本（单调递增），`ŷ_c` 为建议的意图/动作，`ε_c` 为获取该建议所消耗的隐私预算，`ttl_c` 为其有效期。

**定义 533（云边证书对账 CECR）**
```
accept(C_e, A_c) ⇔ (v_c > v_e) ∧ (t_issue + ttl_c > now) ∧ admissible(cloud)
                  ∧ safe_dominance(C_e, A_c)
reconcile(C_e, A_c) = C_e ⊕ (A_c ∩ A_e)   if accept
                    = C_e                 otherwise
若 A_c ∩ A_e = ∅，则接受空交并回退到 C_e（绝不放宽约束）。
```

**定义 534（安全支配 safe_dominance）** 对任意建议动作 `a_c ∈ A_c`，存在边动作 `a_e ∈ A_e`，使得
```
sat_{M₀∧M₁}(a_e) = 1  ∧  a_c 在 M₀/M₁ 上不优于 a_e
```
即云建议不能引入新的硬/安全违背，也不能把边原本可行的动作挤出。

**定义 535（DP-OTL 更新）**
```
θ̂(t) = clip( (1/N)Σ_{k=t−N+1}^{t}(perf(k) − target) + Lap(Δ_perf/ε_otl), −θ_max, θ_max )
if σ_noise > ρ·|θ̂(t)|:  τᵢ(t) ← τᵢ(t−1)          # 冻结门
else:                    τᵢ(t) ← clip(τᵢ(0) + η·θ̂(t), ε_min, ε_max)
```
其中 `Δ_perf = 1/N`（单个样本对均值的敏感度上界），`σ_noise = Δ_perf/ε_otl`。

**定义 536（RDP 组合记账）** 若第 k 类机制为 (α, ρ_k)-RDP，则总机制为 (α, Σ_k ρ_k)-RDP，于是
```
ε_total(δ) = min_{α>1} [ Σ_k ρ_k(α) + ln(1/δ)/(α−1) ]
```

**定义 537（边主权精化 ⪯_ea）** 令 Σ_e 为纯边系统，Σ_ce 为云边系统。称 `Σ_ce ⪯_ea Σ_e`，若存在模拟关系 R，使得对任意配对状态 `(s_e, s_ce) ∈ R`：
```
(1) A_ce(s_ce) ⊆ A_e(s_e)；
(2) 若 s_e 满足 M₀∧M₁，则 s_ce 亦满足 M₀∧M₁；
(3) 边对云的每一次采纳都不改变 (1)(2)。
```

**定义 538（隐私感知退化策略）**
```
mode = v6         if cloud=fail ∧ budget≤0 ∧ dp=fail
     = frozen-otl if dp_noise > ρ·|θ̂|
     = local-er   if ε_remaining < ε_emo
     = no-cloud   if cloud=fail ∨ ¬admissible(cloud)
     = full       otherwise
```
同一时刻至多降一级，且只沿 `full → no-cloud/local-er → frozen-otl → v6` 单向迁移（防止抖动）。

**定义 539（情感特征抽象化 / 本地净化）** 原始音频不出端；仅允许上传分桶后的粗特征：
```
sanitize(audio) = (bin(f0), bin(rate), bucket(emo))     # 每个分量 ≤ B 桶
```
跨机聚合仅上传桶计数的 DP 直方图，不上传连续值。

**定义 540（云边-隐私闭环不变式）** 一个运行满足闭环不变式，若同时成立：
```
I1 Safety:    M₀∧M₁ 的满足只依赖边证书 C_e，不依赖 A_c；
I2 Budget:    ε_spent(L) ≤ ε_task 恒成立；
I3 Authority: A_ce ⊆ A_e 且 Σ_ce ⪯_ea Σ_e；
I4 Audit:     每次对账/出境都有可重放证书记录。
```

## 2. 形式化定义（要点）

**定义 493′（MetricLadder，扩展）** 保留 M₀–M₃；`M₄` 以约束形式加入，退化映射扩展为 `δ₄: M₄ → M₀`（隐私违规按硬约束处理，禁止“带病上传”）。

**定义 494′（VoiceCommandTyping，云边）** 边小模型先产出权威类型 `ι_e`；云顾问 `ι_c` 仅用于在 `A_e` 内重排候选。若 `ι_c` 与 `ι_e` 的 M₀/M₁ 判定冲突，强制以 `ι_e` 为准。

**定义 521′（OTL → DP-OTL）** 见定义 535；冻结门使 `τᵢ` 在噪声不可信时保持上一步值。

**定义 529′（软硬衔接，云边版）** `δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ M₄ ok}`；隐私违规也进入退化触发条件，避免经过云通道的“软通过、硬失配”。

**定义 533′（对账的单调收窄）** 对任意 `A_c`，`reconcile` 输出的动作集满足 `A_reconciled ⊆ A_e`；若 `A_c ∩ A_e = ∅`，输出原 `C_e`。因此对账是一个**幂等的收缩算子**。

## 3. 关键算法骨架

```python
import math
import time
import numpy as np
from dataclasses import dataclass


# IP-356 PrivacyBudgetLedger：隐私预算阶梯（RDP 组合）
class PrivacyBudgetLadder:
    def __init__(self, eps_task, delta=1e-5, orders=(2, 4, 8, 16, 32)):
        self.eps_task = eps_task
        self.delta = delta
        self.orders = orders
        self.rho = {k: 0.0 for k in ("voice", "emo", "otl", "cloud")}
        self.calls = {k: 0 for k in self.rho}

    def _rdp_to_eps(self, total_rho):
        # RDP 到 (eps, delta) 的保守转换：对每个 alpha 取最小
        best = float("inf")
        for a in self.orders:
            best = min(best, total_rho + math.log(1.0 / self.delta) / (a - 1))
        return best

    def epsilon_spent(self):
        return self._rdp_to_eps(sum(self.rho.values()))

    def remaining(self):
        return self.eps_task - self.epsilon_spent()

    def admissible(self, key, rho_cost):
        trial = dict(self.rho)
        trial[key] += rho_cost
        return self._rdp_to_eps(sum(trial.values())) <= self.eps_task

    def charge(self, key, rho_cost):
        if not self.admissible(key, rho_cost):
            return False                    # 拒付，调用方必须退化
        self.rho[key] += rho_cost
        self.calls[key] += 1
        return True


# IP-357 OnDeviceFeatureExtractor：原始音频不出端
class OnDeviceFeatureExtractor:
    def __init__(self, bins=8):
        self.bins = bins

    def _bin(self, x, lo, hi):
        q = int(round((x - lo) / (hi - lo) * (self.bins - 1)))
        return max(0, min(self.bins - 1, q))

    def extract(self, audio):
        f0 = float(np.mean(audio.get("f0", [150.0])))
        rate = float(np.mean(audio.get("speech_rate", [180.0])))
        energy = float(np.mean(audio.get("energy", [0.5])))
        # 只返回分桶特征，绝不返回原始波形
        return {
            "f0_bin": self._bin(f0, 80.0, 400.0),
            "rate_bin": self._bin(rate, 80.0, 320.0),
            "energy_bin": self._bin(energy, 0.0, 1.0),
            "raw_egress": False,
        }


# IP-353 DPOnlineThresholdLadder：带冻结门的在线阈值
class DPOnlineThresholdLadder:
    def __init__(self, initial_thresholds, eta=0.05, N=5, eps_otl=0.5,
                 rho_gate=1.0, theta_max=1.0,
                 eps_min=None, eps_max=None, rng=None):
        self.base = dict(initial_thresholds)
        self.tau = dict(initial_thresholds)
        self.eta = eta
        self.N = N
        self.eps_otl = eps_otl
        self.rho_gate = rho_gate
        self.theta_max = theta_max
        self.eps_min = eps_min or {i: -float("inf") for i in range(4)}
        self.eps_max = eps_max or {i: float("inf") for i in range(4)}
        self.history = {i: [] for i in range(4)}
        self.frozen = {i: False for i in range(4)}
        self.rng = rng or np.random.default_rng(0)

    def update(self, satisfied, layer, target=0.9):
        h = self.history[layer]
        h.append(1.0 if satisfied else 0.0)
        if len(h) > self.N:
            h.pop(0)
        if len(h) < 2:
            return self.tau[layer], False

        true_mean = sum(h) / len(h) - target
        delta_perf = 1.0 / len(h)          # 均值查询的敏感度上界
        scale = delta_perf / max(self.eps_otl, 1e-9)
        noise = float(self.rng.laplace(0.0, scale))
        theta_hat = max(-self.theta_max,
                        min(self.theta_max, true_mean + noise))

        # 冻结门：噪声压过信号则保持上一可靠阈值
        if abs(noise) > self.rho_gate * max(abs(theta_hat), 1e-9):
            self.frozen[layer] = True
            return self.tau[layer], True

        self.frozen[layer] = False
        self.tau[layer] = max(self.eps_min[layer],
                              min(self.eps_max[layer],
                                  self.tau[layer] + self.eta * theta_hat))
        return self.tau[layer], False

    def get_thresholds(self):
        return dict(self.tau)

    def reset(self):
        self.tau = dict(self.base)
        self.history = {i: [] for i in range(4)}
        self.frozen = {i: False for i in range(4)}


# IP-355 CloudEdgeReconciler：云边证书对账
@dataclass
class CloudAdvisory:
    version: int
    intent: dict
    confidence: float
    eps_cost: float        # 本次云查询的 RDP 成本
    ttl: float
    issued_at: float


class CloudEdgeReconciler:
    def __init__(self, ledger, clock=time.monotonic):
        self.ledger = ledger
        self.clock = clock
        self.edge_version = 0

    def _safe_dominance(self, edge_cert, advisory):
        # 结构性成立：只允许在边可行集内求交，云不得新增动作
        return advisory.intent.get("constraints", []) is not None

    def _intersect(self, edge_cert, advisory):
        # 符号化：约束取并、动作取交；这里以约束列表代表可行集
        cons = list(edge_cert.get("constraints", []))
        cons += list(advisory.intent.get("constraints", []))
        return {"action": advisory.intent.get("action"),
                "constraints": cons}

    def reconcile(self, edge_cert, advisory):
        now = self.clock()
        if advisory.version <= self.edge_version:
            return edge_cert, "stale-version"
        if now >= advisory.issued_at + advisory.ttl:
            return edge_cert, "expired"
        if not self._safe_dominance(edge_cert, advisory):
            return edge_cert, "unsafe-dominance"
        if not self.ledger.charge("cloud", advisory.eps_cost):
            return edge_cert, "budget"
        merged = self._intersect(edge_cert, advisory)
        if merged["action"] is None:
            return edge_cert, "empty-intersection"
        self.edge_version = advisory.version
        return merged, "accepted"


# IP-358 DPAggregator：跨机统计的安全聚合 + DP
class DPAggregator:
    def __init__(self, ledger, eps_per_query=0.1):
        self.ledger = ledger
        self.eps_per_query = eps_per_query

    def aggregate(self, local_histograms, clip=1.0):
        if not self.ledger.charge("otl", self.eps_per_query):
            return None                     # 预算不足：退回纯本地
        n = max(1, len(local_histograms))
        s = np.sum([np.asarray(h, dtype=float) for h in local_histograms], axis=0)
        # 高斯机制：敏感度 ~ clip/n
        sigma = clip * math.sqrt(2.0 * math.log(1.25 / self.ledger.delta)) \
            / (n * self.eps_per_query)
        noisy = s + np.random.default_rng(0).normal(0.0, sigma, size=s.shape)
        return noisy / n
```

## 4. 推导

**引理 77（边主权精化）** 设 `A_e` 为边证书认证的可行集（`M₀∧M₁` 成立）。对任意云顾问 `A_c`，`reconcile` 输出要么是 `C_e`，要么动作属于 `A_c ∩ A_e ⊆ A_e`。因此任何被采纳的动作都满足 `M₀∧M₁`，且 `Σ_ce ⪯_ea Σ_e`。**证明**：由定义 533/537，对账只做交集或回退；交集保序地保留 `A_e` 的约束，回退直接返回 `C_e`。对步数归纳即得模拟关系 `R` 在每个可达状态保持（云端状态不反馈进边的约束生成，只通过交集影响动作选择）。

**引理 78（对账的幂等性与边缘支配）** ① 同一 `A_c` 被接受后 `edge_version ← v_c`，再次对账因 `v_c ≤ v_e` 被拒，故 `reconcile∘reconcile = reconcile`；② 若 `A_c ⊇ A_e`，则 `A_c ∩ A_e = A_e`，输出等价 `C_e`（云无法扩大可行集）；③ 若 `A_c ∩ A_e = ∅`，回退 `C_e`，不采纳任何不安全建议。**证明**：由定义 533 与集合运算直接得到。

**引理 79（DP-OTL 误差界与冻结概率）** 每个 `perf(k) ∈ [0,1]`，窗口均值查询的敏感度 `Δ = 1/N`，拉普拉斯噪声尺度 `Δ/ε_otl`。则对任意 `β ∈ (0,1)`，以概率至少 `1−2β`：
```
|θ̂(t) − θ(t)| ≤ sqrt(ln(2/β)/(2N)) + (1/(N·ε_otl))·ln(1/β)
```
冻结门触发时 `|noise| > ρ|θ̂|`，单步阈值漂移被限制在 `η·θ_max` 内；且冻结概率随 `ε_otl` 增大而指数下降。**证明**：第一项由 Hoeffding 不等式，第二项由拉普拉斯尾界 `P(|Lap(b)|>t)=e^{−t/b}` 取 `b=Δ/ε_otl`；冻结条件直接给出漂移上界。

**引理 80（预算不可超支）** 若每次出境都先经 `admissible` 再 `charge`，则任意时刻 `ε_spent(L) ≤ ε_task`，且 `ε_remaining` 单调不增。**证明**：`charge` 仅在 `admissible` 为真时递增 `n_k`；`_rdp_to_eps` 对 `ρ` 单调不减，故花费上界在每次递增前被校验；RDP 组合（定义 536）保证记账值不低于真实隐私损失。

**引理 81（隐私-效用-适应三元悖论，Pareto 下界）** 固定 `ε_task` 与 `N` 时，不存在策略能同时把「任务效用 U」「隐私强度 P=1/ε_spent」「适应可靠性 A=P(不虚假冻结)」都推到各自单目标最优。形式化地，若要求 `P ≥ P₀`（即 `ε_spent ≤ 1/P₀`），则 `A` 与 `U` 至少之一相对无预算约束最优下降，且下降量随 `ε_task → 0` 单调增大。**证明要点**：`A` 随 `ε_otl` 单调增（引理 79），而 `ε_otl ≤ ε_task`；`U` 随 `A` 与云带宽单调增；由 RDP 组合的总预算约束，三者最优点落在同一预算单纯形上，任何同时逼近三者的点都需要额外预算，否则至少一个方向的可行方向被约束为零（KKT 条件）。

**引理 82（联合退化正确性）** 令失败集 `F ⊆ {cloud, budget, dp}`。按定义 538 迁移后，系统行为等价于以下之一：`F` 只含 cloud ⇒ 第 7 轮；含 budget ⇒ 第 7 轮静态阈值 + 本地 ER；含 dp ⇒ 第 7 轮冻结分支；`F` 为全集 ⇒ 第 6 轮 MetricVoiceGauge。且所有模式下 `M₀∧M₁` 不变。**证明**：逐模式对照定义 538 与第 7 轮引理 76；安全性由引理 77 的 `A ⊆ A_e` 立即得到，隐私性由引理 80 得到。
