# 第 61 轮（承接第 60 轮 SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「消融实验」×「动力学」）

> 第 60 轮完成了「认知驱动场景闭环」：SSM 场景语义、CIEC 意图约束、EPIR 因果隔离、SERC 闭环、CESC 序贯决策、SIC 三元校验、PCE++++ 认知预算。但**三个方法论层面**的局限尚未被正视：
> 1. **复杂度通胀不可证伪**：连续多轮每轮新增 8 个 IP，却从未隔离过任一模块的边际贡献。SSM/CIEC/EPIR/SERC 也许各自有用，也许只是互相补偿；没有消融实验，「创新点数量」被当成了「有效贡献」——整个 SGEC 在科学上是不可证伪的堆叠。
> 2. **静态消融与闭环动力学失配**：常规消融是「关掉模块→跑一遍基准→比指标」，隐含系统平稳、轨迹可复用的假设。但认知-执行闭环是**状态依赖、非平稳、强耦合**的动力学系统：关掉 SSM 会改变场景信念→改变 CIEC 约束集→改变执行轨迹→改变证据分布，测到的差异混入了「轨迹漂移偏差」与「off-policy 分布偏移」，并非模块本身的因果贡献；且模块间非线性交互使贡献不可加。
> 3. **可辨识性与安全的矛盾**：要看出一个模块有没有用，系统必须被**激励**（否则停在吸引子上，任何模块都显得可有可无）；但主动激励可能突破 K_safe。不能为了做消融把机器人弄坏，于是「安全的系统」天然「不可消融」。

## 0. 直觉与动机

**灵感 1（消融实验 → 运行时可消融归因 ABX）**
直觉：第 60 轮的 EPIR 影子副本本来只用于「消息丢了能补」，其实它是一份**带时间戳的完整执行日志**——只要有日志，就可以做「如果当时没有 SSM 会怎样」的**反事实回放**。消融不必在真机上做，可以在影子上做；而且判据不该是单点指标，而该是**整条轨迹的回报**。关键洞见：**把消融从「离线基准」升级为「基于影子日志的轨迹级 Shapley 归因」**——用同一串外生扰动（common random numbers）做配对回放，消掉轨迹漂移偏差。

**灵感 2（动力学 → 认知-执行动力系统 CED）**
直觉：模块不是「开关」，而是**向量场里的一项**。关掉 SSM 不是删掉一个函数，而是改变闭环的向量场 F→F_{−i}，其效应表现为**瞬态增益、半衰期、整定时间、收缩率变化**。因此「模块重不重要」是一个动力学问题：有的模块只在切换瞬间有用（如 SSM 的场景先验，半衰期短），有的模块只在长期才显形（如 EPIR 的证据链，半衰期长）。关键洞见：**用「消融响应曲线」而非标量来定义贡献**。

**灵感 3（两灵感合流 → 动力学消融算子 DAO）**
直觉：把消融定义为对向量场的扰动算子 Δ_i F = F_θ − F_{θ\i}，在慢-快分解下分别度量：快时间尺度（接触阻抗瞬态，ms）与慢时间尺度（场景/证据信念，s）。**消融半衰期 T½,i** 衡量「关掉后影响多久消失」，**瞬态增益 G_i** 衡量「关掉瞬间有多痛」，**动态重要性 I_i = ∫ r_i(t)w(t)dt** 衡量「整段响应曲线下的面积」。关键洞见：**没有动力学的消融只能测稳态，而 SGEC 的价值恰恰在瞬态**。

**灵感 4（可辨识性 → 安全持续激励 AAE）**
直觉：如果闭环一直停在某个吸引子上，关掉任何模块轨迹都几乎不变，消融结论是「全都无用」。要辨识贡献必须**持续激励**。但激励必须在 K_safe 内。于是定义**安全激励集 U_safe**：在阻抗安全域内注入幅值受限、频率丰富的探测信号，使 Fisher 信息矩阵满足 λ_min(I) ≥ κ_id，同时约束余量 δ>0。关键洞见：**消融预算里必须显式包含「激励预算」，否则归因不可辨识**。

**灵感 5（归因驱动调度 → 自适应模块调度 AMS + PCE+++++）**
直觉：既然能算出每个模块的动态贡献，就能**按贡献/成本比调度模块**：算力紧张时，先关贡献小且半衰期短的模块；而**安全关键模块（N_safe）只允许影子消融、不允许在线关闭**。这把「消融实验」从评价工具变成了**运行时资源分配器**。PCE++++ 扩展为 PCE+++++，加入 B_abl。关键洞见：**能在线关掉的模块，永远不是安全关键模块**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（认知-执行动力系统 CED）** 闭环状态 x_t = (b_t, c_t, K_t, e_t)：
- b_t ∈ Δ^{N−1} 场景信念（SSM 后验）；c_t ∈ C 意图约束向量（CIEC 锁定域）；K_t 阻抗参数（EEIS）；e_t 证据可信度（EPIR/XMC+）
- 模块开关 θ ∈ {0,1}^n，n=|N|；闭环向量场 x_{t+1} = F_θ(x_t, u_t, w_t) + ξ_t，w 为外生接触扰动，u 为计算/意图控制
- **两时间尺度**：ε·ẋ_f = f_f(x_f, x_s, w)（接触力/阻抗瞬态，ε~10⁻³s），ẋ_s = g(x_s, x_f, w)（信念/证据，~10⁰–10¹s）；慢流形 M_ε = {(x_f, x_s) : x_f = h(x_s)}
- **收缩性**：存在度量 M(x)≻0 使 (∂F)ᵀM + M(∂F) ⪯ −2λM，λ>0；λ 即收敛速率，是模块贡献的动力学标尺。

**定义 162（轨迹级消融 Shapley ABX）** 模块集 N = {SSM, CIEC, EPIR, SERC, ...}。对子集 S⊆N，价值函数
```
v(S) = E_w[ Σ_{t=0}^{H} γ^t r(x_t^S, u_t) ]
```
其中 x^S 由**影子反事实回放**在模块子集 S 下生成，外生扰动 w 序列固定（common random numbers）。Shapley 贡献
```
φ_i = Σ_{S⊆N\{i}} [|S|!(n−|S|−1)!/n!] · [v(S∪{i}) − v(S)]
```
**动态版本**：φ_i(t) 在滑动窗口 W 上计算，得到贡献轨迹 Φ_i = {φ_i(t)}。

**定义 163（可重放性与影子保真度）** 影子日志 D = {(timestamp, seq_id, hash, x_t, u_t, θ_t, w_t)}。若 D 包含状态-动作-扰动-模块掩码的**充分统计量**，则回放算子 R(D, S) 可重建任意模块子集 S 下的轨迹。定义：
- **可重放性**：∃ 充分统计量 s_t ∈ D，使 p(x_{t+1}|x_t, u_t, θ) 可由 D 重建；
- **影子保真度** ρ_shadow = 1 − E[‖R(D,S) − F_S‖]/‖F_S‖；当 ρ_shadow < ρ_min 时，ABX 结论标记为「不可信」。

**定义 164（消融响应曲线与消融半衰期）** 在 t₀ 对模块 i 做阶跃消融（θ_i : 1→0），响应 r_i(t) = J_θ(t) − J_{θ\i}(t)，J 为瞬时回报。定义：
- **瞬态增益** G_i = lim_{t↓t₀} r_i(t)；
- **消融半衰期** T½,i = min{t : |r_i(t₀+t)| ≤ ½|G_i|}；
- **整定时间** T_s,i = min{t : |r_i(t₀+t)| ≤ 0.05|G_i| 且此后保持}；
- **动态重要性** I_i = ∫₀^H r_i(t) w(t) dt，w(t) 为任务权重核。
判读：G 大、T½ 短 ⇒ 瞬态关键（如 SSM 场景切换）；G 小、T½ 长 ⇒ 长期关键（如 EPIR 证据链）。

**定义 165（消融可辨识性与安全持续激励 AAE）** 设模块贡献参数 θ_ex。Fisher 信息矩阵 I(θ_ex) = E[∇ℓ ∇ℓᵀ]。可辨识条件 λ_min(I) ≥ κ_id。安全激励集
```
U_safe = { u_ex : margin(K_safe, u_ex) ≥ δ ∧ ‖u_ex‖_∞ ≤ A_max }
```
AAE 选择 u_ex ∈ U_safe 使 λ_min(I(θ_ex)) ≥ κ_id（在激励预算 B_excite 内）。若不存在，则宣告「不可辨识」，拒绝输出归因——**宁可说不知道，也不伪造贡献排序**。

**定义 166（动力学冗余 DRed）** 模块 i、j **动力学冗余**当且仅当
```
ρ(Φ_i, Φ_j) ≥ ρ*  ∧  |Δλ_{−i} − Δλ_{−j}| ≤ ε_λ  ∧  |G_i − G_j| ≤ ε_G
```
其中 Δλ_{−i} 为消融 i 后的收缩率变化。冗余图 G_red 的极大独立集给出**最小可解释模块集** N_min，用于裁剪而非删除（保留代码路径，日常不激活）。

**定义 167（消融预算 B_abl 与 PCE+++++）** B_abl = (Replay_budget, Excitation_budget, Attribution_latency, Shadow_fidelity)。
```
voi_cog(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_abl(π)
cost_abl = λ_rep·Replay_cost + λ_exc·Excite_cost + λ_att·Attribution_cost
```
若 B_abl 耗尽 ⇒ 冻结上次归因结果（attribution cache），不做在线消融；若 ρ_shadow < ρ_min ⇒ 归因标为「不可信」并回退到保守 LOO 上界。

**定义 168（自适应模块调度 AMS）** 安全关键集 N_safe = {i : θ_i=0 ⇒ 违反安全不变式 I_safe}。在线调度
```
π_sched(x) ∈ 2^{N \ N_safe}
max_π  E[Σ r] − λ_c·Compute(π)
s.t.   所有 i ∈ N_safe 恒为 1（仅允许影子消融，不允许在线关闭）
```
即：**可以在真机上关的模块，永远不是安全关键模块**。

### IP-161 CED（认知-执行动力系统）

```python
class CognitiveExecutionDynamics:
    def __init__(self, eps=1e-3, horizon=50, dt=1e-2):
        self.eps, self.H, self.dt = eps, horizon, dt

    def step(self, x, u, w, theta):
        # 慢变量：场景信念 / 证据可信度
        x_s = self._slow_derivative(x, u, w, theta)
        # 快变量：接触力 / 阻抗瞬态，用 eps 缩放
        x_f = x['fast'] + (self.dt / self.eps) * self._fast_derivative(x, u, w, theta)
        x['slow'] = self._project_simplex(x['slow'] + self.dt * x_s)
        x['fast'] = x_f
        return x

    def contraction_rate(self, theta, x0):
        # 数值 Jacobian，解 (DF)^T M + M DF <= -2λM 的最大 λ
        DF = self._numeric_jacobian(theta, x0)
        M = self._solve_lyapunov(DF)
        return self._max_lambda(DF, M)

    def slow_manifold(self, x_s):
        # 快变量在慢流形上的平衡点 h(x_s)
        return self._fixed_point(lambda x_f: self._fast_derivative(
            {'fast': x_f, 'slow': x_s}, 0, 0, theta=1))
```

### IP-162 ABX（轨迹级 Shapley 归因）

```python
def trajectory_shapley(modules, shadow_log, value_fn, n_perm=200, seed=0):
    rng = np.random.default_rng(seed)
    phi = {m: 0.0 for m in modules}
    base_w = shadow_log.exogenous_sequence()   # common random numbers
    v_cache = {}

    def v(S):
        key = frozenset(S)
        if key not in v_cache:
            v_cache[key] = value_fn(shadow_log, key, base_w)
        return v_cache[key]

    for _ in range(n_perm):
        perm = list(rng.permutation(modules))
        S, prev = [], v(set())
        for m in perm:
            S.append(m)
            cur = v(set(S))
            phi[m] += cur - prev
            prev = cur

    return {m: phi[m] / n_perm for m in modules}
```

### IP-163 DAO（消融响应曲线与半衰期）

```python
def ablation_response(module, shadow_log, horizon, weight_kernel):
    base = replay(shadow_log, full_set=ALL_MODULES)     # 配对回放
    abl  = replay(shadow_log, full_set=ALL_MODULES - {module})
    r = np.array([base.J(t) - abl.J(t) for t in range(horizon)])

    G = r[0]
    half = next((t for t in range(horizon) if abs(r[t]) <= 0.5 * abs(G)), horizon)
    settle = next((t for t in range(horizon)
                   if all(abs(r[k]) <= 0.05 * abs(G) for k in range(t, horizon))),
                  horizon)
    I = float(np.sum(weight_kernel[:horizon] * r))
    return {'G': G, 'T_half': half, 'T_settle': settle, 'I': I, 'curve': r}
```

### IP-164 AAE（安全持续激励）

```python
def safe_excitation(K_safe, budget, kappa_id, delta):
    best = None
    for u_ex in candidate_signals(budget):        # 多正弦 / 幅值受限扫频
        if constraint_margin(K_safe, u_ex) < delta:
            continue                              # 安全域外，直接拒绝
        fim = fisher_information(u_ex)            # 对贡献参数的 FIM
        lam_min = np.linalg.eigvalsh(fim).min()
        if lam_min >= kappa_id:
            return u_ex
        if best is None or lam_min > best[0]:
            best = (lam_min, u_ex)
    return None if best is None or best[0] < kappa_id else best[1]
```

### IP-165 AMS（自适应模块调度）

```python
def schedule_modules(state, phi, compute_cost, N_safe):
    active = set(N_safe)                          # 安全关键模块恒开
    for m in sorted(set(ALL_MODULES) - N_safe,
                    key=lambda m: phi[m] / max(compute_cost[m], 1e-6),
                    reverse=True):
        if phi[m] > compute_cost[m]:              # 贡献 > 成本才开
            active.add(m)
    return active
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CED | O(H·dim(x)) / 轨迹 | O(dim(x)) | 收缩率 λ>0 时慢流形吸引 |
| ABX | O(n·m·H)（m 次排列，替代 O(2ⁿ)） | O(2^n) 缓存 | 无偏估计，误差 O(1/√m) |
| DAO | O(H) 回放 × 2 | O(H) | G/T½/I 可数值稳定估计 |
| AAE | O(候选数 × FIM) | O(dim θ²) | 安全约束零违反时方输出 |
| AMS | O(n log n) | O(n) | N_safe 不变式恒成立 |

**正确性定理（ABX-Dyn）**：假设 A66–A70 成立——**(A66)** CED 存在收缩度量，λ>0，慢流形 M_ε 指数吸引；**(A67)** 影子日志 D 满足可重放性，ρ_shadow ≥ ρ_min；**(A68)** ABX 使用 common random numbers，Shapley 估计无偏且方差有界；**(A69)** AAE 输出的激励 u_ex ∈ U_safe，margin ≥ δ；**(A70)** N_safe 由安全不变式 I_safe 定义且不被 AMS 修改。则：
1. **贡献可分解性**：在 A66–A68 下，φ_i 收敛到轨迹级因果贡献，排序误差 ≤ ε_rank；
2. **瞬态可解释性**：T½,i 有限，且 G_i/T½,i 能区分「瞬态关键」与「长期关键」模块；
3. **安全可辨识性**：A69 下归因过程不引入任何安全违反；不可辨识时返回「未知」而非错误排序；
4. **调度安全性**：A70 下 AMS 不影响 N_safe 的恒开性；
5. **裁剪保真性**：裁掉动力学冗余集 N_red 后，轨迹回报下降 ≤ ε_prune。

## 5. 本轮最大风险

**一句话**：反事实回放依赖「影子日志包含充分状态」这一强假设，而闭环模块会改变状态分布——EPIR 回放因自带完整日志而显得「永远有用」，SSM 又可能因先验泄漏被高估，最终得到的不是模块的真实因果贡献，而是「回放器自身的偏置」；必须以「ρ_shadow < ρ_min 即拒绝归因」「安全关键模块只影子消融」「AAE 可辨识性门控」「元消融交叉验证 LOO/Shapley/DAO」四重护栏，确保消融结论不把系统引向「删掉真正救命模块」的方向。

## 2. 关键算法伪代码

### IP-161 CED（认知-执行动力系统）

```python
class CognitiveExecutionDynamics:
    def __init__(self, eps=1e-3, horizon=50, dt=1e-2):
        self.eps, self.H, self.dt = eps, horizon, dt

    def step(self, x, u, w, theta):
        x_s = self._slow_derivative(x, u, w, theta)
        x_f = x['fast'] + (self.dt / self.eps) * self._fast_derivative(x, u, w, theta)
        x['slow'] = self._project_simplex(x['slow'] + self.dt * x_s)
        x['fast'] = x_f
        return x

    def contraction_rate(self, theta, x0):
        DF = self._numeric_jacobian(theta, x0)
        M = self._solve_lyapunov(DF)
        return self._max_lambda(DF, M)
```

### IP-162 ABX（轨迹级 Shapley 归因）

```python
def trajectory_shapley(modules, shadow_log, value_fn, n_perm=200, seed=0):
    rng = np.random.default_rng(seed)
    phi = {m: 0.0 for m in modules}
    base_w = shadow_log.exogenous_sequence()      # common random numbers
    v_cache = {}

    def v(S):
        key = frozenset(S)
        if key not in v_cache:
            v_cache[key] = value_fn(shadow_log, key, base_w)
        return v_cache[key]

    for _ in range(n_perm):
        perm = list(rng.permutation(modules))
        S, prev = [], v(set())
        for m in perm:
            S.append(m)
            cur = v(set(S))
            phi[m] += cur - prev
            prev = cur
    return {m: phi[m] / n_perm for m in modules}
```

### IP-163 DAO（消融响应曲线与半衰期）

```python
def ablation_response(module, shadow_log, horizon, weight_kernel):
    base = replay(shadow_log, full_set=ALL_MODULES)
    abl  = replay(shadow_log, full_set=ALL_MODULES - {module})
    r = np.array([base.J(t) - abl.J(t) for t in range(horizon)])

    G = r[0]
    half = next((t for t in range(horizon) if abs(r[t]) <= 0.5 * abs(G)), horizon)
    settle = next((t for t in range(horizon)
                   if all(abs(r[k]) <= 0.05 * abs(G) for k in range(t, horizon))),
                  horizon)
    I = float(np.sum(weight_kernel[:horizon] * r))
    return {'G': G, 'T_half': half, 'T_settle': settle, 'I': I, 'curve': r}
```

### IP-164 AAE（安全持续激励）

```python
def safe_excitation(K_safe, budget, kappa_id, delta):
    best = None
    for u_ex in candidate_signals(budget):
        if constraint_margin(K_safe, u_ex) < delta:
            continue
        lam_min = np.linalg.eigvalsh(fisher_information(u_ex)).min()
        if lam_min >= kappa_id:
            return u_ex
        if best is None or lam_min > best[0]:
            best = (lam_min, u_ex)
    return None if best is None or best[0] < kappa_id else best[1]
```

### IP-165 AMS（自适应模块调度）

```python
def schedule_modules(state, phi, compute_cost, N_safe):
    active = set(N_safe)
    for m in sorted(set(ALL_MODULES) - N_safe,
                    key=lambda m: phi[m] / max(compute_cost[m], 1e-6),
                    reverse=True):
        if phi[m] > compute_cost[m]:
            active.add(m)
    return active
```

def meta_ablation(shadow_log, methods):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| CED | O(H·dim(x)) / 轨迹 | O(dim(x)) | λ>0 时慢流形吸引 |
| ABX | O(n·m·H)，替代 O(2ⁿ) | O(2^n) 缓存 | 无偏，误差 O(1/√m) |
| DAO | O(H) 回放 × 2 | O(H) | G/T½/I 数值稳定 |
| AAE | O(候选 × FIM) | O(dim θ²) | 安全违反 = 0 才输出 |
| AMS | O(n log n) | O(n) | N_safe 恒开 |

**正确性定理（ABX-Dyn）**：若 A66–A70 成立——A66 收缩慢流形；A67 可重放且 ρ_shadow ≥ ρ_min；A68 CRN 下 Shapley 无偏有界；A69 激励 u_ex ∈ U_safe；A70 N_safe 由 I_safe 定义不可被调度修改——则：
1. φ_i 收敛到轨迹级因果贡献，排序误差 ≤ ε_rank；
2. T½,i 有限，G/T½ 可区分瞬态关键与长期关键；
3. 归因过程零安全违反；不可辨识时返回「未知」；
4. AMS 不破坏 N_safe 恒开性；
5. 裁掉 N_red 后轨迹回报下降 ≤ ε_prune。

## 5. 本轮最大风险

**一句话**：反事实回放依赖「影子日志包含充分状态」这一强假设，而闭环模块会改变状态分布——EPIR 回放因自带完整日志而显得「永远有用」，SSM 又可能因先验泄漏被高估，最终得到的不是模块的真实因果贡献，而是「回放器自身的偏置」；必须以「ρ_shadow < ρ_min 即拒绝归因」「安全关键模块只影子消融」「AAE 可辨识性门控」「元消融交叉验证 LOO/Shapley/DAO」四重护栏，确保消融结论不把系统引向「删掉真正救命模块」的方向。
