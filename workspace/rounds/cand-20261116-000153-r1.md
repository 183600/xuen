# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「位姿估计」×「机器人」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**误差预算完备 + 双通道否决 + 歧义不赌**。两个灵感治理 v10 暴露的三种"隐藏假设"：**几何债**（证书的全部几何量——clearance、effort、足迹、地标位置——都建立在位姿上，但 β_STF 只校准前向模型误差，位姿误差是账面外的黑洞）、**单证债**（τ_sem 单通道可被"语义保真但几何错误"的扰动同时绕过）、**模态债**（γ̂_grasp 是布尔，等于在对称物体的多峰位姿上赌一个模态）。铁律不变：任一新模块失效 ⇒ 注入声明中立元，行为严格**等价**（Σ=0、模态集单点、o=1、age=0 时逐位退回 v10）或**支配**（任何非中立失效只会让余量更大、检测更多、动作集更小）于 v10。

## 0. 直觉与动机

**灵感 1（位姿估计 → 证书缺的是"哪里"，不只是"什么"）**
直觉：v10 把语义创新度做成领先指标，但它衡量的是"看到的东西变没变"；而整张证书里的几何量全是位姿的函数。位姿估计这门学科的核心教训从来不是"算出一个 6DoF 数"，而是：位姿误差是 SE(3) 上**相关、各向异性、可能多峰**的随机量；协方差必须沿**可观测方向**分解；对称、无纹理、玻璃、重复纹理会让位姿出现**离散多模态**与重尾。v10 的 β_STF 是对（量化）前向模型误差的经验标定，天然不覆盖位姿误差；而位姿误差在块内是**相关的**，不会随 rollout 采样平均掉。做个量级检查：家庭场景 σ_t=2cm、σ_θ=1°、杠杆 r_max=0.4m，99% 置信半径（χ²₆,₀.₉₉ 的 √≈4.1）给出 ρ_pose≈8.2–11.0cm——而典型 d_safe 只有 5cm。也就是说，v10 可以在"账面上"认证一个真实间隙为负的块：**不是 β 取小了，而是证书里少了一整项**。核心创新：**位姿锚定认证器（Pose Anchor Certifier, PAC）**——复用现成 SLAM/配准的残差与 Hessian（不新增重组件），给出机器人与地标的相对位姿协方差 Σ_rel、可观测子空间、退化指数 D 与模态集 M；把证书余量升级为**位姿膨胀证书** ĝ = ĉ − β_q − ρ_pose − β_sync。这一步同时把机器人安全标准的**速度-分离监控**（ISO/TS 15066 的 S_p 公式）显式化：v10 只近似了 S_s+S_c+S_f，漏掉了位姿不确定项与时间同步项。

**灵感 2（位姿估计 × 机器人 → 几何是语义的互补证据，不是重复证据）**
直觉：v10 自认的最大风险是单通道 τ_sem 被对抗纹理/长尾语义新颖绕过。位姿估计恰好提供一条**极廉价、与语义近正交**的证据：配准残差与 Hessian 条件数。对抗语义扰动可以保持嵌入距离小，却很难同时保持几何残差小且 Hessian 良态——除非它真的在几何上一致（即真的发生了场景变化）。于是把 50Hz 守卫从"单通道阈值"升级为**双通道一致性守卫（Geometric–Semantic Coherence Guard, GCG）**：ν_sem 与 ν_geo **只许否决、不许因一致而放行**；两通道**分歧**本身就是模型失配信号（不是取平均的理由）。形式上关键一步极干净：v10 的漏检事件 {ν_sem≤τ_sem} 是 v11 漏检事件 {ν_sem≤τ_sem ∧ ν_geo≤τ_geo} 的**超集**。加通道只能缩小漏检（检测支配），代价是**可测**的误报；我们不假设两通道独立，而是把联合漏检率当作预注册实验量测出来。

**灵感 3（机器人 → 歧义下不赌模态：稳健动作 + 有界主动消歧）**
直觉：家庭里大量物体天然对称（杯子、盒子、圆柱、把手），位姿估计输出多峰是常态而非异常；v10 的 γ̂_grasp 是布尔，等于默认"位姿是单点的"。机器人学的正确姿态不是"要更准的位姿"，而是**对位姿不确定性稳健的动作**：要么选在模态商空间上不变的抓取（universal grasp），要么用**有界探测动作**主动消歧，消不掉就拒绝并声明。核心创新：**模态稳健抓取与主动消歧（Mode-Ambiguous Grasp, MAG）**：γ̂_grasp^∀ = min_{m∈M^g} γ̂_grasp(m)（对**所有**可能模态都成立才允许抓），以及 A_probe 上带安全约束的熵减探测；T_probe 步内熵降不到 H_stop ⇒ 拒抓 + 写台账 + 声明式非抓取退化（轻推至已知位 / 请求人工）。这把"接触段赌模态"换成"要么稳健、要么消歧、要么拒绝"，且三种出口都不比 v10 更冒险。

**三者咬合**：PAC 把**误差账**补全（证书物理侧可信），GCG 把**单通道风险**拆成双通道否决（检测更早），MAG 把**接触段赌模态**换成稳健/消歧/拒绝（执行更稳）。三者都只在 v10 的 Ĉ⁺ 上做**单向保守扩张**：PAC 只增不减余量、GCG 只增不减检测、MAG 只缩不放动作集；三者中立元同时注入时逐位等价 v10。这把 v10 的"结构化信任"推进为**可审计的误差预算**：每一个未建模误差都必须以显式加项进入证书，否则视为无穷大（中止）。

## 1. 研究问题（轮次升级版）

- **Q1（位姿膨胀证书）**：如何把证书从"前向模型误差标量"升级为"前向 + SE(3) 位姿 + 同步 + 标定"的**相加误差预算**，使得在相关、各向异性、多峰的位姿不确定性下仍可给出 (1−δ) 可靠的安全下界，同时被拒块比例相对 v10 有界（可用性损失可测），并在中立元下逐位退化为 v10？
- **Q2（双通道否决）**：如何构造与 ν_sem 近正交的几何创新度 ν_geo（配准残差 + Hessian 退化 + 位姿年龄），使检测事件严格支配 v10（漏检事件是子集），并把"通道分歧"定义为**否决/收缩**而非放行，同时把误报与联合漏检率控制在预注册预算内？
- **Q3（歧义下的稳健执行）**：在对称/多假设位姿下，如何用模态商空间上的 universal grasp 与有界主动消歧（≤T_probe 步、每步过同一守卫）保证"要么对所有模态安全成功、要么拒绝"，且探测动作本身的安全性可证、任务可用性不劣于声明的下界？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 误差预算完备律（Pose-Aware Budget Completeness, PAC）**
证书中的每一个几何量都必须携带其**全部**误差源的显式加项：前向/量化 β_q、相对位姿 ρ_pose、时间同步 β_sync、标定残差 β_cal。任一项无法给出（1−δ）界 ⇒ 该项视为 +∞（中止/收缩），**不允许**用其他项的余量"顺手吸收"。沿块内视界，位姿不确定度随预测步数增长，因此**块长必须由位姿视界门控**（K_pose），而非只由域偏移门控。

**P17 双通道否决律（Coherence Veto, GCG）**
多个证据通道只许**否决**，不许因"一致"而授予许可；决策取**单边 OR / max**，不取平均。两通道分歧（一个报警一个不报警）视为模型失配，必须收缩到 K=1 并在下一块强制复验，而不是互相抵消。检测支配性优先于误报率：宁可多停，不可漏停。

**P18 歧义不赌律（Ambiguity Refuses to Gamble, MAG）**
位姿存在多模态时，只允许**模态稳健**（对所有 m∈M^g 成立）的动作；否则在有界预算 T_probe 内主动消歧；再否则**拒绝并声明**。禁止"按最高后验模态执行"。探测动作本身也必须过同一套位姿膨胀证书（用更严的 d_probe），且其信息增益必须可测。

## 3. 与基线的接口（如何退化）

- **PAC 失效**（配准 Hessian/残差不可得、或 o_t 无证书）⇒ 注入离线标定的最坏情形椭球 Σ_0 与粗模态集、o=0；若连 Σ_0 都没有 ⇒ K=1、限速 v_max↓、标记 `pose_unverified`。此路径只会比 v10 更保守（**支配**），不是等价；
- **GCG 失效**（几何通道超时/不可用）⇒ ν_geo:=1（保守上界）⇒ 守卫持续触发 ⇒ K=1，直至恢复；**不**退回 v10 单通道（那会重新引入 v10 风险）；
- **MAG 失效** ⇒ γ̂_grasp^∀:=0（拒抓），导航段仍等价 v10；声明可用性损失；
- **中立元注入**（Σ:=0、M^g 单点、o:=1、a_pose:=0、β_cal:=0、ν_geo 不参与）⇒ 逐位等价 v10 的 Ĉ⁺ 与守卫；
- STF/NRB/LS/台账沿 v10 退化链；AC 失效 ⇒ K=1；ID 失效 ⇒ 全模块 active、归因冻结；MW 失效 ⇒ v10 手写网关；v8 组件失效 ⇒ 中立元 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **位姿膨胀证书与误差预算完备性**：首次把 v10 的隐式"位姿无误差"假设变成显式、可校准、可审计的加项；给出安全支配与中立元等价（引理 92），并用"被漏掉的 8–11cm"解析示例说明 v10 的账面安全可超过 d_safe 本身；
2. **双通道检测支配**：用与语义近正交的几何通道把 v10 的单点漏检事件变成交集事件，证明检测事件单调扩张（引理 93），把"分歧"制度化为否决；
3. **歧义下的稳健抓取**：模态商 + universal grasp + 有界消歧，给出新的唯一假设——模态集覆盖（引理 94），并把它做成可测量的预注册实验，而不是隐含假设；
4. **E591–E606** 覆盖位姿协方差校准、联合漏检、模态覆盖、消歧效率、时延膨胀、对抗位姿欺骗、退化环境、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：位姿证书的可靠性被外包给一个在线无法验证的**模态集覆盖假设**——真实位姿一旦落在声明的模态集之外，或协方差系统性过自信（遮挡、对称、玻璃、传感器欺骗），"认证"反而把 v10 的显式经验风险伪装成形式安全，且主动消歧的探测运动带来新的接触风险与可用性崩塌。

| β_total(k) | β_q + β_pose(k) + β_sync(k) + β_cal（误差预算相加，见定义 553） |
| W, ρ_pose(k) | W=diag(I₃,r_maxI₃)；ρ_pose(k)=L_c·√(λ_max(WΣ_rel(k)Wᵀ))，L_c=1 |
| Ĉ_t⁺⁺ | 位姿膨胀证书 (ĝ_min, ê_max, γ̂_grasp^∀, β_total, o_t, n_t, \|M^g\|, a_pose) |
| A_probe, T_probe | 探测动作集与上限（默认 3）；d_probe 为探测专用更严间隙 |
| K_pose, K_mode | 位姿视界块长上界、模态数块长上界（定义 557） |

**新增定义 549（位姿状态与相对协方差）** 机器人/地标位姿 ξ_r,ξ_ℓ∈SE(3)，右扰动 ξ'=ξ·exp(δ^)，δ~N(0,Σ)。相对位姿 ξ_{rℓ}=ξ_r⁻¹ξ_ℓ 的一阶协方差（Barfoot–Furgale 位姿复合传播）：
```
Σ_rel ≈ Ad(ξ_ℓ⁻¹ξ_r) Σ_r Ad(ξ_ℓ⁻¹ξ_r)ᵀ + Σ_ℓ
```
其中 Ad(·) 为 SE(3) 伴随。**不假设 Σ_r 与 Σ_ℓ 独立**是理想情形；若来自同一因子图，取联合协方差的相对位姿边缘；若只能拿到分块，则用 Cauchy–Schwarz 保守放大（引理 92 注）。位姿年龄 a_pose=t_now−t_pose，过期阈值 T_pose=100ms。

**新增定义 550（可观测性、退化与位姿证书位）** 信息矩阵 H=JᵀΩJ 特征分解。可观测子空间 O_ε=span{uᵢ:λᵢ≥ε_H}；退化指数 D=λ₆/λ₁；退化方向集 Dg={uᵢ:λᵢ<ε_H}。位姿证书位
```
o_t = 1 ⇔ (λ₁ ≥ ε_H) ∧ (‖r_t‖_{Σ_t}⁻¹ ≤ τ_r) ∧ (J ≤ J_max)
```
o_t=0 时 Laplace 协方差不可信，Σ 以 κ_opt 膨胀（κ_opt 由 E594 的离线 SDP 对偶间隙标定）；若 κ_opt 不可得 ⇒ 用 Σ_0。

**新增定义 551（模态集与抓取商）** 物体 o 的位姿模态集
```
M_o = Sym(o) ∪ Hyp(pose-solver) ∪ Ext(退化轴极值)
```
每个 m 带权重 w_m（后验或声明）。商去抓取等价关系 ~：m~m' ⇔ 对所有候选抓取 g 有 γ̂_grasp(g,m)=γ̂_grasp(g,m')。M^g=M_o/~；连续对称（圆柱绕轴）在抓取稳定子下取有限代表元，避免无穷模态。**M^g 只记录对抓取决策有区别的模态**。

**新增定义 552（几何创新度）**
```
ν_geo(t) = clip( ‖r_t‖_{Σ_t}⁻¹/τ_r
               + w_D·max(0, D/D_max − 1)
               + w_a·(a_pose/T_pose), 0, 1)
```
ν_geo 用配准残差、Hessian 条件数与位姿年龄，**与 ν_sem（嵌入距离）近正交**；50Hz 只读求解器缓存的 r_t、λ₁、λ₆，不重跑配准（预算 ≤0.15ms）。

**新增定义 553（误差预算完备的位姿膨胀证书）** 沿足迹/视界的第 k 步：
```
β_pose(k) = L_c · √(λ_max(W Σ_rel(k) Wᵀ)),      W = diag(I₃, r_max·I₃),  L_c = 1
β_sync(k) = L_c · (v_max·a_pose + ω_max·r_max·a_pose)
β_total(k) = β_q + β_pose(k) + β_sync(k) + β_cal
ĝ_min = min_k [ ĉ_k − β_total(k) ]
ê_max = max_k [ ê_k + β_total(k) ]
Ĉ_t⁺⁺ = (ĝ_min, ê_max, γ̂_grasp^∀, β_total(K), o_t, n_t, |M^g|, a_pose)
```
其中 β_q 继承 v10 的 β_STF（量化+前向模型），β_cal 为离线标定残差上界。**valid ⇔**
```
ĝ_min ≥ d_safe ∧ ê_max ≤ τ_eff
∧ (¬grasp ∨ γ̂_grasp^∀ ≥ γ_min)
∧ n_t 全通过（或修复后重验）
∧ (o_t=1 ∨ Σ 已按 κ_opt/Σ_0 膨胀)
∧ a_pose ≤ T_pose ∧ U_t^sem（v10）
∧ 模态覆盖标志 c_M=1（E595 校准；未知则拒抓）
```

**新增定义 554（模态稳健抓取）** 对模态集 M^g：
```
γ̂_grasp^∀ = min_{m∈M^g} γ̂_grasp(m)
g^∀       = min_{m∈M^g} g(m)
```
**universal grasp 条件**：γ̂_grasp^∀≥γ_min ∧ g^∀≥d_safe。即"无论真实模态是哪一个，抓取都成立且不碰"。注意这是**对所有模态取最坏**，因此 M^g 越保守，抓取越难成立——可用性由消歧换回。

**新增定义 555（有界主动消歧）** 探测动作集 A_probe（小视角、腕转、基座微移、轻推），安全集
```
A_probe^safe = { a∈A_probe : g^∀(a) ≥ d_probe > 0 ∧ 快规范通过 }
a* = argmax_{a∈A_probe^safe} [ H(M) − E_{z|a} H(M|z) ] / cost(a)
```
上限 T_probe=3 步；**每步重新过 50Hz 六检**（定义 556）。若 H(M)≤H_stop ⇒ 以 M^g 做 universal grasp；若 T_probe 用尽仍 H(M)>H_stop ⇒ **拒抓**、写 Λ、走声明式非抓取退化（轻推至已知位 / 请求人工）。一步贪心的期望熵单调不增（引理 94-iii）。

**新增定义 556（六检守卫）** 50Hz 六检（全部 O(1)/O(k)，k≤8）：
1. Ĉ_t⁺⁺ 有效（含位姿项与模态项，取代 v10 检 1）；
2. 停车不变式（v10 原检）；
3. 语义创新度 sup ν̄ ≤ τ_sem（v10 原检）；
4. **几何创新度** ν_geo ≤ τ_geo（新）；
5. 快规范（v10 原检）；
6. **一致性**：若 |ν_sem−ν_geo|>τ_coh ⇒ 置 inconsistent，K←1 并在下一块强制复验；
任一硬条件失败 ⇒ 切 p* 或安全停驻。总预算 ≤0.7ms。

**新增定义 557（有效块长，v11）**
```
K_eff^{v10} = v10 定义 539
K_pose = max{ k : β_pose(k)+β_sync(k) ≤ ρ_budget }
K_mode = max{ k : |M^g| 不随视界增长超过 M_max }   # 模态数随视界增长则缩短
K_eff(t) = 1                     若 ¬U_t^sem ∨ Ĉ⁺⁺ 不可得 ∨ (o=0 ∧ 无 Σ_0)
         = 2                     若 NRB 失效(Π_r) ∨ inconsistent
         = min(K_eff^{v10}, K_pose, K_mode)   否则
```
**位姿视界门控**是新增的硬上界：不确定度随 rollout 步数增长，长块的尾部无法用前端的低不确定度背书。

**新增定义 558（位姿预算台账）** 复用 v10 的 append-only 哈希链 Λ（定义 548），每条记录扩展
```
(prev, t, ζ_id, 判定向量 n_t, 修复, utterance,
 o_t, D, |M^g|, β_total, ρ_pose, probe_steps, refuse_flag)
```
链结构与缺口自检不变（κ_h=256、每 C_w=64 块校验点、缺口⇒Π_r）。新增字段只增审计面，**不回灌当期控制**（v10 引理 89-iii 原样保持）。

class PoseAnchorCertifier:
    def __init__(self, tau_r=1.0, eps_H=1e-3, D_max=1e3, kappa_opt=2.0,
                 Sigma0=None, r_max=0.4, T_pose=0.1):

        self.r_max, self.T_pose = r_max, T_pose

# IP-362 GeometricCoherenceGuard：双通道否决（定义 552 / 556）
class GeometricCoherenceGuard:
    def __init__(self, tau_sem, tau_geo=0.5, tau_coh=0.4, w_D=0.3, w_a=0.3):
        self.tau_sem, self.tau_geo, self.tau_coh = tau_sem, tau_geo, tau_coh
        self.w_D, self.w_a = w_D, w_a

    def geometry(self, reg, pose_cert):
        nu_geo = (mahalanobis(reg.residual, reg.cov) / self.tau_r
                  + self.w_D * max(0.0, pose_cert.D / self.D_max - 1.0)
                  + self.w_a * (pose_cert.age / self.T_pose))
        return clip(nu_geo, 0.0, 1.0)

    def check(self, nu_sem, reg, pose_cert):
        nu_geo = self.geometry(reg, pose_cert)
        if nu_sem > self.tau_sem or nu_geo > self.tau_geo:
            return Verdict(abort=True, inconsistent=False)     # 单边 OR
        if abs(nu_sem - nu_geo) > self.tau_coh:
            return Verdict(abort=False, inconsistent=True)      # 分歧⇒K=1+复验
        return Verdict(abort=False, inconsistent=False)


# IP-363 MAG：模态稳健抓取 + 有界主动消歧（定义 554 / 555）
class ModeAmbiguityGrasp:
    def __init__(self, gamma_min=0.85, d_probe=0.08, T_probe=3,
                 H_stop=0.2):
        self.gamma_min, self.d_probe = gamma_min, d_probe
        self.T_probe, self.H_stop = T_probe, H_stop

    def universal_grasp(self, chunk, M, grasp_model):
        if not M:
            return None, 'no_mode'
        margins = [grasp_model.success(chunk, m) for m in M]   # γ̂_grasp(m)
        clear   = [grasp_model.clearance(chunk, m) for m in M] # g(m)
        if min(margins) < self.gamma_min or min(clear) < self.d_safe:
            return None, 'not_universal'
        return chunk, 'universal'                              # γ̂^∀ 成立

    def disambiguate(self, M, probe_policy, certifier, ledger, ctx):
        for step in range(self.T_probe):                       # 有界预算
            if entropy(M) <= self.H_stop:
                return M, 'resolved'
            a = probe_policy.max_info_gain(M, safe=self._safe_probes(M))
            if a is None:                                      # 无安全探测
                break
            if certifier.cert_probe(a, d=self.d_probe) is None:  # 探测自身须认证
                break
            z = execute_and_observe(a)                         # 每步过六检
            M = bayes_update(M, z)
            ledger.append(ctx.chunk_id, 'probe', a.id, entropy(M))
        return M, 'unresolved'                                 # ⇒ 拒抓+声明

## 4. 推导

**引理 92（位姿膨胀证书的可靠性与安全支配）** 设
(A1) 足迹上一致前向误差 sup‖F̂_q−F‖≤β_q（v10 A3 / E579）；
(A2) 位姿校准：真实相对扰动 δ 满足 ‖Wδ‖ ≤ ρ_pose 的概率 ≥1−δ_p（E591 的 NEES/χ² 一致性）；
(A3) clearance 在度量 ‖Wδ‖ 下 1-Lipschitz（平移到表面距离 1-Lipschitz；旋转对半径 r_max 上点的位移 ≤r_max‖δ_θ‖）；
(A4) 同步：a_pose≤T_pose 且年龄内位移 ≤β_sync 的概率 ≥1−δ_s。
则对任一块，以概率 ≥1−(δ_p+δ_s+δ_q)，**若 Ĉ⁺⁺ valid 则真实 clearance ≥d_safe 且 effort ≤τ_eff**。证明：对每个 k，
c_true ≥ ĉ_k − |c_true−ĉ_k| ≥ ĉ_k − (‖δ_t‖+r_max‖δ_θ‖) ≥ ĉ_k − ρ_pose，
再用 A1/A4 与三角不等式把 β_q、β_sync 相加；对 k 取 min、对 k 取 max；并集界收尾。**安全支配**：因 β_pose,β_sync,β_cal≥0、γ̂^∀≤γ̂_grasp，v11 的接受集 ACC(v11)⊆ACC(v10)；且中立元 Σ=0、M^g 单点、o=1、a_pose=0、β_cal=0 时 ρ_pose=β_sync=0、γ̂^∀=γ̂_grasp，Ĉ⁺⁺≡Ĉ⁺ **逐位相等**。注：若 Σ_r、Σ_ℓ 只能分块取得，用 Cauchy–Schwarz 放大 √(λ_max(Σ_r))·√(λ_max(Σ_ℓ)) 相关项，保持上界。∎

**引理 93（双通道检测支配）** 令漏检事件
M10={ν_sem≤τ_sem}，M11={ν_sem≤τ_sem ∧ ν_geo≤τ_geo}。
则 M11⊆M10，故对任意危险事件 e，P(detect₁₁)≥P(detect₁₀)：**加通道只能增检测**。一致性检查把 alarm 集再从 {ν_sem>τ_sem ∨ ν_geo>τ_geo} 扩张为并上 {|ν_sem−ν_geo|>τ_coh}，故 alarm₁₁⊇alarm₁₀。误报增量
ΔFP ≤ P(ν_geo>τ_geo | 无事件) + P(分歧 | 无事件)，二者由 E593 校准并预注册。若两通道在无事件下条件独立，则 P(M11)≤P(M10)·P(ν_geo≤τ_geo | 无事件)；但**我们不依赖独立性**，而是把联合漏检 P(M11) 作为 E592/E600 的实测量。关键：v10 的失败事件是 v11 漏检事件的**超集**，因此 v11 不会比 v10 更容易漏（这是"检测支配"，不是"概率独立"）。∎

**引理 94（模态稳健抓取与有界消歧）** 设
(A5) 模态覆盖：真实抓取相关位姿 m*∈M^g 的概率 ≥1−δ_M（E595）；
(A6) γ̂_grasp 在 M^g 上一致 (1−δ_g)-准确。
则 γ̂_grasp^∀≥γ_min ⇒ 抓取成功概率 ≥1−δ_M−δ_g；g^∀≥d_safe ⇒ 对真实模态无碰撞概率 ≥1−δ_M。若 m*∉M^g，保证失效——这是 v11 **唯一新增的承重假设**，且它被做成可测量（E595），而非隐含。(iii) 一步贪心消歧的期望熵单调不增（信息增益非负），T_probe 有限 ⇒ 要么 H(M)≤H_stop（以 universal grasp 执行），要么拒抓；因此**不存在"按最高后验模态赌一把"的执行路径**。探测动作自身安全性由 Ĉ⁺⁺(d_probe) 同一机制保证（定义 555）。∎

**引理 95（可观测性—量化联合边际预算）** 沿退化方向 uᵢ（λᵢ<ε_H），Laplace/CRB 给出该方向方差 ≥1/λᵢ（在局部线性化下），故 ρ_pose≥L_c√(λ_max(WΣWᵀ)) 随 λᵢ 下降而上升；由定义 557，K_pose 相应缩短——**块长由可观测性上界给出，而不是只靠经验 Δ_dom**。INT8 量化误差进入 β_q，因 β_total 为相加项且证书是下界，量化只能**消耗**而不能**借用**位姿余量：若 β_q+β_pose+β_sync>ĉ−d_safe，块被拒（P16 预算守恒）。这给出 v10 的"量化压缩安全边际"一个可证的处置：不是加大 β 了事，而是把量化误差与位姿误差分账并在预算不足时拒绝。∎

**定理 1（v11 组合安全性）** 在 A1–A6 与 v10 的 STF/NRB 前提（E571/E574 校准）下，(i) 物理安全：任一中块危险事件被六检在 ≤1 帧捕获，否则被 Ĉ⁺⁺ 的位姿预算覆盖，失效概率 ≤ε_s+ε_p+ε_q+ε_sync+ε_M+ε_g；(ii) 规范安全：继承 v10 引理 89 的收缩支配与审计面隔离；(iii) 可用性：被拒块比例 Δrej 由 E593 度量，预注册上限 Δrej≤5%，否则触发 κ_opt/Σ_0 重标定而非放宽预算。证明：引理 92（物理覆盖）+ 引理 93（检测支配）+ 引理 94（模态覆盖）+ v10 引理 87/89，按并集界合并。∎

## 6. 解析示例：被漏掉的 8–11cm

取家庭场景 σ_t=2cm/轴、σ_θ=1°/轴、r_max=0.4m、d_safe=5cm、β_q=2cm。
- WΣWᵀ 的最大特征值主导项为 σ_t²=4×10⁻⁴，√λ_max=0.02m；χ²₆,₀.₉₉ 的 √≈4.10 ⇒ ρ_pose≈**8.2cm**（谱范数口径）；
- 若用度量半径 q(σ_t+r_maxσ_θ)=4.10·(0.02+0.4·0.01745)≈**11.0cm**（保守口径）；
- 若块视界 K=10、过程噪声 q_proc=(1cm)²/步，则尾部方差增至 10 倍，ρ_pose 再乘 √10≈3.2 ⇒ 尾部可达 **26–35cm**，这就是 K_pose 必须随视界收缩的直接原因。
**结论**：v10 的账面余量最多只有 β_q=2cm，而位姿项可达 8–11cm（尾部更大）——**未预算的位姿误差本身已超过 d_safe**。v11 不是"把 β 调大"，而是把这一项显式入账，并在预算不足时拒绝该块（P16）。

## 9. 本轮最大风险
