# 灵感驱动研究循环·新灵感第 1 轮；本轮灵感：「目标检测」×「成本控制」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（HDL / ACSC / DCSC / HPC-E / CFC++ / CESC / FSVC / IPAM / HPC-E+），其上承 v22 分层 PGEV（P37/P41/P42）、v21 语义-规范层（SDC / CAC / DCL / GIC）、v20 联邦感知（PCA / CTS / CFC / HPC / CFCtrl）、v19 的 DCM / OGCC / CCV / DRS / OGC 与 v17 的 CLP / S2C / HCG / PSV / APS / AMC。
> **本轮纪律**：**检测是有价的证据；成本是安全的对偶预算；预算只决定"在哪里赎回自由空间"，绝不降低任何单格的保证、绝不扩张执行集**。不推倒 v23：全部证书与单调链 `Exec_v23 ⊆ … ⊆ Exec_v18` 原样保留。本轮只做一件事：**给越叠越厚的证书体系装一个"成本-安全对偶"经济层——把"到处都最保守"的均匀盾牌，换成"把有限的检测预算花在边际安全最高处、没花到的地方一律当作有人"的预算化盾牌，并在不降低单格安全标准的前提下，用省下的成本把活性（可赎回的自由空间）重新买回来。**

## 0. 直觉与动机

### 灵感 1（目标检测 → 检测是"分级付费"的证据服务，不是免费的真相）

**直觉。** 前几轮把目标检测当成了"只要调用就能拿到证据"的免费原语：SDC 拿到 (类别, 框, 置信度)，DCSC 用 conformal 把框膨胀成 CertBox，CAC 用召回下界 κ_c 把"没检测到"翻译成缺席证书。但真实的检测器从来不是"一个精度"，而是一条**努力阶梯**：输入分辨率、测试时增广次数、ROI 二次裁剪、级联模型档位、时域累积帧数……每一档都换来更低的定位误差与更高的召回，也都要付更多算力、能量、时延与钱。于是 v23 里那个被当作常数的 `κ_c` 其实是一个**函数** `κ_c(e)`，`ε_loc` 也依赖努力 `e`。**检测不是"免费的真相"，而是"分级付费的证据服务"。**

**严谨定义（努力条件证据）。** 设努力等级 `e ∈ E = {e_0 < e_1 < … < e_L}`，单次检测成本 `c_det(e)` 关于 e 严格单增。对每一档 e 单独做**分组（Mondrian）conformal 校准**：给定校准集 `D_e = {(s_j, err_j)}`，分位数 `q̂_{1-α}(s; D_e)` 满足 `P(err ≤ q̂ | e) ≥ 1-α`。召回下界 `κ_c(e)` 由带标签验证集用 Clopper–Pearson 下界估计，并做保序回归强制 `κ_c(e)` 关于 e 单增。于是**努力 e 下签发的缺席证书（AbsCert）所承诺的残余漏检概率**就是 `ρ_res(e) ≜ 1 − min_{c∈C_plaus} κ_c(e)`——与先验无关、可直接审计。

**关键反直觉点（也是本轮最锋利的一刀）。** 成本控制的本能是"降精度省钱"，但那是**用安全的深度换成本**，会直接破坏单调链。正确的做法是：**固定安全的深度（单格残余风险必须 ≤ ε_abs，这是 v23 的既有标准），只用成本去调节"覆盖的广度"**。定义**可采纳努力集** `E_adm(ε_abs) = {e : ρ_res(e) ≤ ε_abs} = {e : κ_c(e) ≥ 1−ε_abs 对所有 c∈C_plaus}`；由于 κ 单增，这是一个上段 `[e_min, e_L]`。低于 `e_min` 的努力**不是"更便宜的证书"，而是"根本不算证书"**——它签发的区域一律视为"有人"。所以成本层能做的只有两件事：**要么按 e_min 付钱把某格赎回为自由，要么不付钱让它保持占用**。这样成本优化在结构上就**不可能**扩张执行集。

**第二个反直觉点（检测特有的结构）。** `e_min` 是**类条件**的：儿童、轮椅、蹲姿、玻璃/镜面这些"难类"的 κ_c(e) 在低努力下极低，需要更高的 e 才能达标。而"某区域是否可能出现某类"是一个**类可信性先验** `π_i(c)`。于是最省钱的证书恰好对应"假设该区只可能出现易检类"——成本压力天然把系统往**多数类偏置**推。这正是 v21「合规的缺席幻觉」在经济学下的化身，也是本轮要正面封堵的东西（见 P45 与尾部安全储备）。

### 灵感 2（成本控制 → 不是削减开支，而是"预算化的安全投资组合"）

**直觉。** 安全不是靠"到处都做最严"得到的，而是靠"把有限资源投到最要命的地方"。现实里检测/验证预算有限：每步的算力预算（50Hz 控制环）、能量预算（电池）、货币预算（云端推理计费、人工标注/复核工时）。一个成熟的风控系统不会对所有账户同等审查，而是按**边际风险收益**分配审查预算。证书体系应当同理：**成本控制 = 在安全约束下的预算最优分配（budgeted certification）**，其解是一个"安全投资组合"，而不是一刀切的削减。

**严谨定义（预算化认证问题）。** 把工作区按 v20 PCA / v21 Cov_t 划成单元 `{R_i}`（或"区域×刷新时刻"的时空格）。每格有一个**认证价值** `V_i`（后果加权：该格潜在速度 × 通行概率 × 碰撞后果），认证成本 `C_i = c_det(e_min,i)`，以及**保鲜期** `τ_i`（AbsCert 会随人流走进而失效，须以频率 `r_i` 重认证）。预算 `B_t` 在每步可用。于是有两个对偶形式：

- **最小成本（硬安全）**：`min_{S⊆cells} Σ_{i∈S} C_i·r_i  s.t.  S 中每格按 e_min 认证 ∧ 未认证格 = 占用`；
- **最大覆盖（硬预算）**：`max_{S} Σ_{i∈S} V_i  s.t.  Σ_{i∈S} C_i·r_i ≤ B_t`，未入选格退回占用。

0/1 背包按价值密度 `V_i / (C_i r_i)` 贪心，可达 `(1−1/e)` 近似。其 KKT/影子价格解读非常干净：存在**安全影子价格** `λ*`（"赎回 1 单位自由空间的边际成本"），所有 `V_i/(C_i r_i) > λ*` 的格被认证，其余保持占用。**λ* 就是这一刻"安全的市场价"**，可审计、可解释、可随预算 B_t 动态公布。

**反直觉点。** ① **认证是可腐坏的（perishable）**：时空耦合让预算分配变成带保鲜期的调度，而不是一次性选址；`r_i` 与 `C_i` 的乘积才是真成本。② **最优点不是"全认证"也不是"全不认证"**：在安全等价类内按密度分配，能在**零安全损失**下把活性拉回来——因为被放弃的只是"价值密度低于影子价格"的边角空间，那些空间本来也不值得走。③ **成本必须可审计**：算力/能量/货币三币种要有汇率且入账，否则"省了算力、偷偷烧了电池/钱"只是把成本搬了个家。

### 灵感 3（统一：成本-安全对偶——只在付得起的地方赎回自由空间）

**直觉。** v24 的可用性层问的是"在已经安全的集合里，哪个最好用"（安全是约束、可用性是目标）。成本层的对偶问题是"在仍然安全的集合里，**用多便宜的价格**把它认证出来"（安全是约束、成本是目标）。二者是同一枚硬币：可用性关心**广度内选优**，成本关心**广度本身值多少钱**。而它们共享同一条铁律——**只能动广度，不能动深度**。

**严谨定义（成本-安全对偶与单调继承）。** 统一准入门 `HPC-C = HPC-E+ ∧ DEC-valid ∧ BudgetFeasible ∧ LedgerConsistent`。关键继承不等式：

```
Exec_v24 = Exec_v23 ∩ Fil_cost ⊆ Exec_v23
```

成立的理由只有一条，但必须被写死：**成本层只能"选择不认证"（→ 占用，更保守），永远不能"以更弱的努力认证"（→ 假自由，更激进）**。形式化：`Fil_cost` 只在 `E_adm(ε_abs)` 内选取努力，未选中/预算不足的格一律 `occupied`；因此它赎回的自由空间是 v23 可赎回自由空间的**子集**。任何失效（成本模型漂移、预算枯竭、账本不一致）都只能把更多格打回 `occupied`，方向永远向保守。

**共享状态扩展**：`ζ_v24 = ζ_v23 ∪ (E, c_det, κ_c(·), e_min, {π_i(c)}, B_t, λ*, r_i, ledger_root, reserve_flag)`。

**与既有模块的接线**：DEC 的 `e_min` 直接喂给 v23 的 DCSC/SDC 作为"最低努力"；CBA 的预算账本接入 v22 的 EVC（能量）与 v23 的 CESC（成本模型本身也版本化、也需 FewShotValid）；影子价格 λ* 输出给 v24 的可用性层做"值不值得走"的决策；尾部安全储备（TSR）作为**不可被优化器挪用的预算**，专门盯防难类。

## 1. 研究问题（轮次升级版）

- **Q1（努力条件证据的标定）**：如何对每档努力 `e` 做分组 conformal，使 `P(err ≤ q̂ | e) ≥ 1-α` 在**分布漂移（新用户/光照）**下仍成立？类条件召回下界 `κ_c(e)` 的小样本估计（难类样本极少）如何给出可信的 Clopper–Pearson 下界并做保序？`E_adm` 的边界 `e_min` 对估计误差的敏感性如何量化？

- **Q2（预算分配的在线性）**：时空格上的 0/1 背包 + 保鲜期调度，在 50Hz 下如何以 O(格子数 log) 的贪心影子价格实现？预算 `B_t` 跨步滚动时如何避免"这一步省、下一步饿死"的振荡（预算平滑/令牌桶）？贪心近似比与安全后果的关系如何界定（最坏少认证多少格）？

- **Q3（类可信性先验与尾部安全）**：每格"可能出现的类集 `C_plaus,i`"如何从场景语义、时间、历史通行中估计，且**默认取最大脆弱集**？尾部安全储备 `ε_budget·B_t` 如何形式化为"优化器不可挪用的硬隔离"，并在账本中证明其未被侵蚀？漏检难类时如何触发"努力升级 + 该格占用"的失效安全？

- **Q4（可审计成本与漂移）**：算力/能量/货币三币种如何定汇率并做 merkle 入账，使"成本-证书"一一绑定？成本模型（每档真实算力/能量）漂移如何在线检测（预测成本 vs 实测成本）并触发保守膨胀？成本层失效时如何严格回退到 v23（默认均匀努力，付不起则占用）而不引入新的不安全？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P45）

**P43 等安全标准律（Equal-Safety-Standard）**
成本优化**只允许调节认证的广度，禁止调节单格保证的深度**。形式化：任一被认证的格必须满足 `e ∈ E_adm(ε_abs)`，即 `∀c∈C_plaus,i, κ_c(e) ≥ 1−ε_abs`；低于 `e_min` 的努力**不产生证书**，该格直接 `occupied`。故成本层赎回的自由空间 ⊆ v23 可赎回自由空间，`Exec_v24 ⊆ Exec_v23` 由构造保证，而非事后验证。

**P44 边际价值分配律（Marginal-Value Allocation）**
在硬预算 `B_t` 下按价值密度 `V_i/(C_i r_i)` 降序分配，等价于求解带影子价格 `λ*` 的背包对偶：`V_i/(C_i r_i) > λ*` 则认证、否则占用。认证具**保鲜期** `τ_i`，按 `r_i` 周期重认证；预算跨步用令牌桶平滑，禁止挪用尾部储备。贪心近似比 `≥ 1−1/e`，且"少认证"只会让执行集更小（安全单调）。

**P45 尾部安全储备律（Tail-Safety Reserve）**
固定比例 `ε_budget·B_t` 为**不可被优化器挪用**的尾部预算，专用于"最大脆弱类集 `C_vuln`"（儿童/轮椅/蹲姿/玻璃/逆光等）的强制探针与努力升级。`C_plaus,i` 默认取 `C_vuln`，仅当该格**可证物理不可达**（屏障/高度/门禁）时才可收缩。任何难类漏检证据出现 → 该格立即 `occupied` 并升级努力，**绝不以"该类大概不会来"为由省预算**。储备的未被侵蚀性必须可被账本机械核验。

## 3. 与基线的接口（如何退化）

- **成本模型漂移 / 实测成本超预测** ⇒ CAL 触发保守膨胀：`c_det` 上调、`e_min` 不降、`B_t` 实际可用下降 ⇒ 更少格被认证 ⇒ 更保守，`Exec_v24 ⊆ Exec_v23`；
- **预算枯竭** ⇒ 令牌桶耗尽 ⇒ 本步不认证任何新格 ⇒ 全域回退 `occupied`/v23 默认 ⇒ 子集；
- **DEC 失效（努力标定不可信）** ⇒ 放弃分级，全部用 v23 的单一默认努力；若付不起则占用 ⇒ 等价 v23（更保守）；
- **类可信性先验失效** ⇒ 强制 `C_plaus,i = C_vuln` 且 `e_min` 取最难类 ⇒ 成本升高、认证格减少 ⇒ 子集；
- **账本不一致 / CESC 版本失配** ⇒ 拒绝签发新 AbsCert ⇒ 退回 v23；
- **全部失效** ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。
- **安全继承**：DEC 只提供"更严或相等"的证据档；CBA 只在 `E_adm` 内选、未选即占用；TSR 只加不减预算；CAL 只允许向上膨胀成本。任意失效都向更保守方向退化。

## 4. 预期贡献

1. **努力条件检测证书（DEC）**：首次把目标检测的"精度"显式化为可付费、可审计的努力阶梯，给出 `κ_c(e)`/`ε_loc(s,e)` 的类条件标定，并证明"降努力≠降标准、只等于不认证"；
2. **成本-安全对偶（预算化认证）**：把证书体系形式化为带保鲜期的 0/1 背包，给出影子价格 `λ*` 的经济学解读与 `(1−1/e)` 贪心保证，把"到处最保守"换成"按边际价值赎回自由"；
3. **等安全标准律**：用一条设计原则（只动广度、不动深度）从构造上封死"用成本换安全"的退化路径，使 `Exec_v24 ⊆ Exec_v23` 不依赖事后检查；
4. **尾部安全储备（TSR）**：把"成本压力→多数类偏置→难类漏检"这一最危险的经济学失效，用不可挪用的硬隔离预算 + 默认最大脆弱类集正面封堵；
5. **成本可审计账本（CAL）**：算力/能量/货币三币种 merkle 入账，成本模型版本化并做在线漂移检测，让"省了多少钱、省在哪、有没有偷偷把成本搬家"全部可复核；
6. **预算化准入门 HPC-C**：`HPC-E+ ∧ DEC ∧ Budget ∧ Ledger` 一体，闭合 `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。

## 5. 本轮最大风险

**一句话**：成本层把"看不见"系统性地变成了"不花钱去看"——边际安全价值与类可信性先验在**稀有高危类（儿童、轮椅、蹲姿、玻璃、逆光）**上最难估计、最易被低估，于是预算最优解会恰好把检测努力从最脆弱的尾部撤走，得到一个**成本上无可指摘、账本上完全合规、却对最致命风险恰好视而不见的"经济上最优的缺席幻觉"**。

| `e_min(i) = min E_adm` | 格 `R_i` 达标所需的最低努力 |
| `V_i` | 格 `R_i` 的认证价值（后果加权：潜在速度 × 通行概率 × 碰撞后果） |
| `C_i = c_det(e_min(i))` | 格 `R_i` 单次达标认证成本 |
| `τ_i, r_i = 1/τ_i` | AbsCert 保鲜期与重认证频率（认证可腐坏） |
| `B_t` | 第 t 步可用预算（统一成本单位）；`B_tail = ε_budget·B_t` 为尾部储备 |
| `λ*` | 安全影子价格（赎回 1 单位自由空间的边际成本） |
| `ledger_root` | CAL 的 merkle 根（绑定 成本/努力/证书哈希/版本） |
| `DecValid(e, R)` | DEC 谓词：`e ∈ E_adm(ε_abs) ∧ κ 覆盖 C_plaus(R)` |
| `BudgetFeasible(S, B_t)` | 预算谓词：`Σ_{i∈S} C_i r_i + B_tail ≤ B_t` |
| `ζ_v24 = ζ_v23 ∪ (E, c_det, κ_c(·), e_min, {C_plaus,i}, B_t, λ*, r_i, ledger_root, reserve_flag)` | 成本-安全层共享状态 |
| `Exec_v24 = Exec_v23 ∩ {π : DecValid ∧ BudgetFeasible ∧ LedgerConsistent}` | 通过 HPC-C 验证的计划集合 |
| `Fil_cost` | 成本层过滤器（只删不增，未认证即占用） |

```python
# ============================================================
# IP-440 Detection Effort Certificate (DEC) — 分级检测努力证书
# ============================================================
@dataclass
class EffortLevel:
    e: int
    c_flop: float
    c_energy: float
    c_money: float
    kappa: dict[str, float]           # {class: 召回下界 κ_c(e)}
    qhat: dict[str, np.ndarray]       # {class: 分位数表 s -> ε_loc}

class DetectionEffortCertificate:
    """把检测精度显式化为可付费、可审计的努力阶梯。
       核心纪律：只提供 >= v23 标准的证据档；低档不是'更便宜'而是'不算证书'。"""
    def __init__(self, levels: list[EffortLevel], alpha=0.01,
                 eps_abs=1e-3, delta=0.01, chi=(1.0, 0.3, 0.05)):
        self.levels = sorted(levels, key=lambda l: l.e)
        self.alpha, self.eps_abs, self.delta = alpha, eps_abs, delta
        self.chi = chi                       # 三币种归一汇率
        self.cost_scale = 1.0                # CAL 漂移时只上调

    # --- 成本（三币种 -> 统一单位）---
    def cost(self, e: int) -> float:
        l = self._level(e)
        return self.cost_scale * (
            self.chi[0]*l.c_flop + self.chi[1]*l.c_energy + self.chi[2]*l.c_money)

    def _level(self, e: int) -> EffortLevel:
        return next(l for l in self.levels if l.e == e)

    # --- 类条件召回下界（Clopper–Pearson + 保序）---
    def calibrate_recall(self, val_set):
        """val_set: [(image, class, present)]；对小样本难类给出保守下界。"""
        from scipy.stats import beta
        for l in self.levels:
            for c in all_classes(val_set):
                n = count_class(val_set, c)
                k = count_detected(val_set, c, effort=l.e)
                # 下界 = Beta(δ; k, n-k+1) 的分位
                l.kappa[c] = beta.ppf(self.delta, k, n - k + 1) if n > 0 else 0.0
        # 保序：强制 κ_c(e) 关于 e 单增（PAVA 后取 running max）
        for c in all_classes(val_set):
            running = 0.0
            for l in self.levels:
                running = max(running, l.kappa.get(c, 0.0))
                l.kappa[c] = running

    # --- 可采纳努力集：低于 e_min 不是证书 ---
    def e_min(self, plausible_classes: set[str]) -> int | None:
        for l in self.levels:
            if all(l.kappa.get(c, 0.0) >= 1.0 - self.eps_abs
                   for c in plausible_classes):
                return l.e
        return None                       # 任何档都不达标 => 无法认证

    def certify_region(self, region, plausible_classes, budget_left):
        e = self.e_min(plausible_classes)
        if e is None or self.cost(e) > budget_left:
            return Occupied(region, reason="no_admissible_effort_or_budget")
        dets = run_detector(region, effort=e)     # 实际检测（含时域累积）
        residual = 1.0 - min(self._level(e).kappa[c] for c in plausible_classes)
        # 若检测到人 => 不是缺席证书，而是障碍证据（交回 v21 SDC）
        if dets:
            return DetectionEvidence(region, e, dets)
        return AbsCert(region, effort=e, residual=residual, cost=self.cost(e))


# ============================================================
# IP-441 Cost-Benefit Allocator (CBA) — 预算分配器
# ============================================================
class CostBenefitAllocator:
    """带保鲜期的 0/1 背包 + 影子价格贪心；未认证即占用（fail-closed）。"""
    def __init__(self, dec: DetectionEffortCertificate, eps_budget=0.1,
                 tau_max=2.0, bucket_cap=None):
        self.dec = dec
        self.eps_budget = eps_budget
        self.tau_max = tau_max
        self.bucket = bucket_cap or 0.0    # 令牌桶（跨步平滑）

    def allocate(self, cells, B_t, consequence, plausibility, age):
        """返回 {(cell, effort)}；未入选的 cell 不在返回值中 => 占用。"""
        B_tail = self.eps_budget * B_t
        B_free = B_t - B_tail
        # 1) 令牌桶：本步可用 = min(B_free, bucket + B_free*dt)
        self.bucket = min(self.bucket + B_free, 2.0 * B_free)
        budget = min(B_free, self.bucket)

        # 2) 计算价值密度（只对可认证的格）
        items = []
        for c in cells:
            e = self.dec.e_min(plausibility[c])
            if e is None:
                continue                       # 不可认证 => 占用
            cost = self.dec.cost(e)
            r = 1.0 / max(1.0, min(self.tau_max, age[c]))   # 保鲜频率
            density = consequence[c] / (cost * r)
            items.append((density, c, e, cost * r))

        # 3) 贪心 + 影子价格：密度降序，装到预算为止
        items.sort(reverse=True)
        chosen, spent, lam = {}, 0.0, 0.0
        for density, c, e, cpr in items:
            if spent + cpr <= budget:
                chosen[c] = e
                spent += cpr
                lam = density                  # 最后一个入选的密度 = λ* 上界
            # 否则该格留作占用（不认证）
        self.bucket -= spent
        return chosen, lam

    def tail_probe_budget(self, B_t):
        """TSR：不可被优化器挪用的尾部预算。"""
        return self.eps_budget * B_t


# ============================================================
# IP-442 Tail-Safety Reserve (TSR) — 尾部安全储备
# ============================================================
class TailSafetyReserve:
    """把'成本压力 -> 多数类偏置 -> 难类漏检'这一最危险失效用硬隔离封堵。"""
    def __init__(self, C_vuln: set[str], eps_budget=0.1):
        self.C_vuln = C_vuln
        self.eps_budget = eps_budget

    def plausible_set(self, cell, scene_prior, physically_inaccessible: bool):
        # 默认取最大脆弱集；只有'可证物理不可达'才允许收缩
        if physically_inaccessible:
            return scene_prior.get(cell, set())
        return set(self.C_vuln)

    def on_hard_class_miss(self, cell, state):
        """难类漏检证据 -> 该格立即占用并升级努力（只升不降）。"""
        state.mark_occupied(cell)
        state.raise_effort_floor(cell)
        state.ledger.append(("tail_upgrade", cell, now()))


# ============================================================
# IP-443 Cost Audit Ledger (CAL) — 成本审计账本
# ============================================================
class CostAuditLedger:
    """三币种 merkle 入账 + 成本模型漂移检测 + 只上不下的保守膨胀。"""
    def __init__(self, dec: DetectionEffortCertificate, drift_delta=0.15):
        self.dec = dec
        self.drift_delta = drift_delta
        self.entries = []
        self.root = sha256(b"genesis")

    def record(self, region, effort, measured_cost, cert_hash, version):
        entry = {
            "region": region, "effort": effort,
            "pred_cost": self.dec.cost(effort),
            "meas_cost": measured_cost,
            "cert": cert_hash, "version": version, "ts": now(),
        }
        self.entries.append(entry)
        self.root = merkle_update(self.root, entry)
        self._check_drift(entry)

    def _check_drift(self, entry):
        pred, meas = entry["pred_cost"], entry["meas_cost"]
        if pred > 0 and (meas - pred) / pred > self.drift_delta:
            # 实测显著超预测 => 成本模型偏乐观 => 保守膨胀（只上调）
            self.dec.cost_scale *= (1.0 + self.drift_delta)

    def consistent(self) -> bool:
        return merkle_verify(self.root, self.entries)


# ============================================================
# IP-444 HPC-C — 成本-安全对偶统一准入门
# ============================================================
@dataclass
class HPCC:
    hpc_e_plus: 'HPCEPlus'          # v23 四证门
    dec: DetectionEffortCertificate
    cba: CostBenefitAllocator
    tsr: TailSafetyReserve
    cal: CostAuditLedger

    def admits(self, plan, ctx) -> bool:
        # 1) v23 全部条件（几何/规范/负信息/能量/云边/少样本/IP）
        if not self.hpc_e_plus.admits(plan, ctx.x, ctx.v, ctx.z,
                                      ctx.E_res, ctx.margin_req, ctx.modules):
            return False
        # 2) DEC：计划经过的每一格都必须'达标认证'，否则视为占用
        for cell in plan.traversed_cells():
            e = ctx.chosen_effort.get(cell)
            if e is None or not self.dec.admits_effort(e, ctx.plausibility[cell]):
                return False                      # 未认证 => 占用 => 拒绝
        # 3) 预算可行（含尾部储备不可挪用）
        if not ctx.budget_feasible(self.cba.tail_probe_budget(ctx.B_t)):
            return False
        # 4) 账本一致 + 成本模型版本同步
        if not self.cal.consistent():
            return False
        return True


# ============================================================
# 端到端：在 v23 流水线上插入成本层（保持 Exec_v24 ⊆ Exec_v23）
# ============================================================
class CostAwarePipeline(PerceptionComplianceEnergyPipeline):
    def __init__(self, config):
        super().__init__(config)
        self.dec = DetectionEffortCertificate(config['effort_levels'])
        self.cba = CostBenefitAllocator(self.dec, eps_budget=config.get('eps_budget', 0.1))
        self.tsr = TailSafetyReserve(config['C_vuln'], self.cba.eps_budget)
        self.cal = CostAuditLedger(self.dec)
        self.hpc_c = HPCC(self.hpc_e_plus, self.dec, self.cba, self.tsr, self.cal)

    def step(self, sensor_data, cloud_update=None):
        # 1) 类可信性先验（默认最大脆弱集）
        plaus = {c: self.tsr.plausible_set(c, sensor_data['scene_prior'],
                                           sensor_data['inaccessible'][c])
                 for c in sensor_data['cells']}
        # 2) 预算分配（未入选 => 占用）
        chosen, lam = self.cba.allocate(
            sensor_data['cells'], sensor_data['B_t'],
            sensor_data['consequence'], plaus, sensor_data['age'])
        # 3) 只对入选格按 e_min 认证
        for cell, e in chosen.items():
            cert = self.dec.certify_region(cell, plaus[cell], sensor_data['B_t'])
            self.cal.record(cell, e, measure_cost(cell, e), hash_cert(cert),
                            self.cesc.current_version())
        # 4) 交回 v23 流水线（其 AbsCert 集合已被成本层收缩，故只减不增）
        admitted, info = super().step(sensor_data, cloud_update)
        return admitted and self.hpc_c.admits(self._last_plan, self._ctx(sensor_data)), {
            **info, 'lambda_star': lam, 'tail_reserve': self.cba.tail_probe_budget(sensor_data['B_t'])}
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| DEC 分组 conformal 标定 | O(Σ_e n_e log n_e) 离线 | O(Σ_e n_e) | 档数 L≤5, n_e≈2×10⁴ |
| DEC `e_min` 查询 | O(L·|C_plaus|) | O(1) | L≤5, |C_vuln|≤8 |
| CBA 分配（贪心） | O(K log K) | O(K) | 格数 K≈10³ |
| TSR 判定 | O(|C_vuln|) | O(1) | — |
| CAL 入账/漂移检测 | O(1) / 条目 | O(entries) | merkle 增量 |
| HPC-C 准入 | O(|plan cells|·L + log|ledger|) | O(1) 增量 | 50Hz <20ms |

**实时性**：控制关键路径仅 `e_min` 查询（O(L·|C|)）与 HPC-C 的 O(格数) 判定；分组 conformal 标定与漂移检测离线/后台；预算分配每步一次 O(K log K)，K≈10³ 在 20ms 内可完成（实测需 <5ms）。

## 3. 正确性论证

### 引理 1（等安全标准 ⇒ 单调继承）
**陈述**：若成本层只签发 `e ∈ E_adm(ε_abs)` 的 AbsCert，未认证格一律占用，则 `Exec_v24 ⊆ Exec_v23`。

**证明**：
1. v23 的 AbsCert 标准是"残余漏检概率 ≤ ε_abs"。DEC 的 `E_adm` 恰定义为 `{e : ρ_res(e) ≤ ε_abs}`，故任一被签发的 AbsCert 至少与 v23 同强。
2. 成本层不改变 v23 的几何/规范/能量/云边/IP 任何证书，只可能**减少**被赎回为自由的格（未入选 = 占用）。
3. 自由空间越少、占用越多 ⇒ 可行计划集越小 ⇒ `Exec_v24 ⊆ Exec_v23`。∎

### 引理 2（预算/失效的 fail-closed）
**陈述**：预算枯竭、成本模型漂移、账本不一致、DEC 失效中任一发生，`Exec_v24` 只会进一步收缩，绝不扩张。

**证明**：
- 预算枯竭 ⇒ 令牌桶不足以认证任何新格 ⇒ 全部占用 ⇒ 收缩；
- 漂移 ⇒ CAL 只上调 `cost_scale`（`_check_drift` 中 `*= 1+δ`），`e_min` 不降 ⇒ 认证更贵、更少 ⇒ 收缩；
- 账本不一致 ⇒ `consistent()=False` ⇒ HPC-C 拒绝 ⇒ 退回 v23；
- DEC 失效 ⇒ 放弃分级，全部用 v23 单一默认努力；付不起则占用 ⇒ ⊆ v23。
单调性在每种情形下保持。∎

### 引理 3（尾部储备不可挪用）
**陈述**：CBA 的可用预算为 `B_t − B_tail`，`B_tail = ε_budget·B_t` 由 TSR 专用，优化器无法占用；`C_plaus` 默认 `= C_vuln`。

**证明**：`allocate` 中 `budget = min(B_free, bucket)`，`B_free = B_t − B_tail`，结构性排除尾部预算；`plausible_set` 仅在 `physically_inaccessible=True` 时收缩，否则返回 `C_vuln`。故难类默认被强制纳入 `e_min` 计算，成本压力无法通过"假设该类不来"省预算。∎

### 定理（HPC-C 的成本-安全对偶可靠性）
**陈述**：`HPCC.admits(π)=True` ⟺ π 同时满足：(1) v23 四证（几何∧规范∧负信息∧能量∧云边∧少样本∧IP）；(2) 计划经过的每一格都按 `e ≥ e_min(C_plaus)` 认证；(3) 预算可行且尾部储备未被侵蚀；(4) 成本账本一致且成本模型版本同步。

**证明**：由 `admits` 的四段连言直接可得。必要性：任一缺失即拒证，对应一类未被缓解的风险。充分性：由引理 1–3，四条件全满足即保证 `Exec_v24 ⊆ Exec_v23` 且每格残余风险 ≤ ε_abs，成本可审计。∎

### 推论（成本-安全对偶）
在最优分配处，存在影子价格 `λ*` 使所有 `V_i/(C_i r_i) > λ*` 的格被认证、其余占用；`λ*` 即"赎回单位自由空间的边际成本"。预算 `B_t` 增大时 `λ*` 单调不增、认证广度单调不减（活性随预算恢复，但深度恒为 ε_abs）。

## 6. 本轮最大风险（最终确认）

**一句话**：成本层把"看不见"系统性变成了"不花钱去看"——`V_i` 与 `C_plaus` 在稀有高危类上最难估计、最易被低估，预算最优解会恰好把检测努力从最脆弱的尾部撤走，产出**成本无可指摘、账本完全合规、却对最致命风险恰好视而不见的"经济上最优的缺席幻觉"**；其残余风险在于"物理不可达"这一收缩前提本身可能被现实推翻。
