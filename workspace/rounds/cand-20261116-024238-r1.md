# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「自适应控制」×「鲁棒性」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**残差驱动自适应 + 管状鲁棒证书 + 鲁棒蒸馏**。两个灵感治理 v9 的三种债：**滞后债**（Δ_dom 的 20 帧滑窗在分布跳变时最不可靠）、**名义债**（"点预测 + 标量 β"隐含误差界全局成立）、**估计债**（EMA 点估计决定休眠，噪声即可误睡关键模块）。统一原则：**鲁棒包络内自适应，包络外严格退化**——自适应只提升包络内性能，绝不替代安全不变式。

## 0. 直觉与动机

**灵感 1（自适应控制 → 预测残差是零延迟的老师）**
直觉：v9 拿"域偏移检测器"当"模型是否可信"的代理信号，可检测器天生滞后；但系统每周期都能立刻算出"上一帧我预测的状态 vs 真实状态"。自适应控制的核心正是**用跟踪/预测误差在线修正模型与不确定性**，而不是等外部故障诊断。核心创新：**残差自适应调节器（ResidualAdaptiveGovernor, RAG）**：一步预测残差 e_t 经**死区**（抗噪）、**投影**（有界）、**σ 泄漏**（抗漂移）、**激励门**（PE surrogate，防在退化数据上误适应）更新误差界 ε_t，1 个控制周期内驱动块长收缩与证书张开。附带收益：Δ_dom 从"决策依据"降级为"慢备份先验"——这正好补上 v9 最大风险的缺口。

**灵感 2（鲁棒性 → 不要信点预测，信包络）**
直觉：v9 证书是"名义轨迹 + 标量 β"，隐含"误差界全局成立"；真实世界只有**有界扰动**，没有准确点预测。鲁棒控制的正解是 **tube**：给名义轨迹套一个可达误差管，要求**整根管**满足约束，并与停车不变式联立。核心创新：**管状块证书（TubeChunkCertifier, TCC）**：证书从点时标量升级为**集合值**；只要扰动在已知界 W 内，管不变式保证约束满足；**越管（tube breach）**是最快、最硬的中止触发器——不依赖任何检测器的窗口统计。

**灵感 3（自适应 × 鲁棒的交叉 → 鲁棒蒸馏）**
直觉：v9 的休眠/唤醒基于 EMA 点估计 c_m，估计噪声本身就能把关键模块"睡"掉；且 v9 只对点估计做双阈，未对**估计不确定性**做鲁棒化。鲁棒统计的做法：用贡献的**置信下/上界**做决策，并让休眠在模糊集上取最坏情形。核心创新：**鲁棒贡献蒸馏器（RobustDistiller, RD）**：只有**贡献上界** c_m^UCB < τ_off（有把握它确实低）才休眠，只有**贡献下界** c_m^LCB ≥ τ_on（有把握它确实高）才唤醒；任一鲁棒告警（管破裂、残差跳变、域偏移）强制全唤醒。这使"睡觉"成为一个带统计/最坏情形保证的动作，而非点估计赌博。

## 1. 研究问题（轮次升级版）

- **Q1（残差可观测性与覆盖）**：在什么一步残差可观测性、信噪比与激励条件下，自适应误差界 ε_t 能以有限暂态覆盖真实模型误差？死区 ν 引入的稳态下界与安全裕度如何换算？
- **Q2（管-停车联合不变式）**：在有界扰动 W 与误差管 T_t 下，如何构造中止点集 P_t，使"从任一中止点停驻"的鲁棒不变式严格成立，且越管能在一个控制周期内被检出？
- **Q3（鲁棒蒸馏的可证权衡）**：置信下/上界的选择如何同时约束"误睡概率"、算力收益与唤醒延迟，并给出可预注册的三方 Pareto？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 残差驱动自适应律（Residual-Adaptive, RAG）**
安全相关的模型不确定度必须由**在线可观测的一步残差**驱动，而非仅由慢速外环检测器驱动。误差界按带死区/投影/泄漏的更新律演化（定义 542），且仅在激励门通过时适应；残差是"模型可信度"的**主信号**，Δ_dom 仅作先验与慢备份。

**P14 管不变式律（Tube-Invariance, TCC）**
块证书必须是**集合值**的：对误差管 T_t 内任意状态，块内软层约束与停车不变式都成立；状态一旦越出 T_t 或残差超界即触发**硬中止**，不等块边界、不等 Δ_dom 窗口。

**P15 鲁棒包络律（Robust-Envelope / Robust-Distill, RD）**
任何"减少安全冗余"的决策（休眠、延长块、放大信任域）都必须以**鲁棒判据**（置信界/最坏情形）为前提；包络外（扰动越界、激励不足、估计不可靠）一律退化为保守行为（K_eff=1、全模块 active、静态 β）。**自适应只花钱买性能，不许赊账买安全。**

## 3. 与基线的接口（如何退化）

- RAG 失效（残差不可观测 / 激励长期不足）⇒ ε_t ← β 常数，退回 v9 静态余量；
- TCC 失效（管传播不可信 / 集合运算超时）⇒ 退回 v9 点证书（点预测 + 标量 β）；
- RD 失效 ⇒ 退回 v9 点估计 EMA 双阈蒸馏；
- v9 的 AC/MW/ID 任一失效 ⇒ 分别按 v9 定义 532–539 退化至 v8 决策粒度/集成方式/全模块常开；
- v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

退化链是**严格向下包含**的：RAG/TCC/RD 三者关闭后，系统逐位等价于 v9 ACMD（引理 92），再沿 v9 自身退化链回到 v6。

## 4. 预期贡献

1. **管状块证书**：把"点预测 + 标量余量"升级为"名义轨迹 + 可达误差管"，在**有界扰动**下给出块内鲁棒约束满足，且越管即硬中止——安全论证从"相信 β"变为"相信集合包含"；
2. **残差自适应误差界**：用一步预测残差把模型退化的检出延迟从 Δ_dom 的 ≥20 帧压到 **1 周期**，并以死区/投影/泄漏/激励门四条自适应控制标准件保证有界性与抗噪性；
3. **鲁棒蒸馏**：用贡献置信界替代点估计，使模块休眠从"经验阈值"变为"带误睡概率/最坏情形保证"的决策，并保留陌生域与鲁棒告警的强制唤醒；
4. **"包络内自适应、包络外退化"范式**：给出自适应与鲁棒性的清晰分工与形式化退化定理，E571–E590 覆盖管标定、滞后对决、越管中止、死区/激励消融、鲁棒蒸馏、WCET 不确定调度与端到端任务。

## 5. 本轮最大风险

**一句话**：管不变式与自适应界都建立在"残差可观测且扰动有界"之上——若出现**残差不可观测的隐蔽偏移**（缓慢一致的传感器偏置、被欺骗/被篡改的观测、或落在死区内的漂移），ε_t 会被死区锁在偏小值，误差管保持"名义安全"却已整体偏离真实状态，此时自适应恰恰用自己被压小的误差界证明了鲁棒性。

## 1. 符号体系增量（定义 540–550）

| 符号 | 含义 |
|---|---|
| e_t = Ψ(x_t) − Ψ(F̂(x_{t−1},a_{t−1})) | 一步预测残差向量；Ψ 投影到安全相关坐标（间隙/速度/位姿） |
| r_t = ‖e_t‖_∞ / 各坐标量程 | 归一化标量残差（定义 540） |
| ε_t | 在线自适应误差界（定义 541），替代 v9 的静态 β |
| ν, λ, σ, ρ_pe | 死区、适应增益、泄漏系数、激励门限（定义 541–542） |
| φ_t = [x_{t−1}; a_{t−1}] | 适应回归量；W_pe 为激励窗 |
| T_k = {x : ‖x − x̂_k‖ ≤ ε_k} | 第 k 步误差管截面（定义 543） |
| L_F, w_max | 前向模型 Lipschitz 常数、可容许扰动界 |
| Ĉ_t^tube | 管状块证书（集合值最坏界，定义 544） |
| κ_b, κ_e | 越管阈值（几何/残差），定义 545 |
| c_m^UCB, c_m^LCB | 贡献置信上/下界（定义 547） |
| ρ_m | 贡献估计的置信半径（经验 Bernstein） |
| γ | WCET 不确定度上界（定义 549） |

**新增定义 540（预测残差 PredictionResidual）** 记安全相关观测投影为 Ψ，则
```
e_t = Ψ(x_t) − Ψ(F̂(x_{t−1}, a_{t−1})),   r_t = max_i |e_{t,i}| / s_i
```
其中 s_i 为第 i 坐标量程。r_t 是自适应控制中的"跟踪误差"类比物：它直接度量上一周期模型错得多离谱，延迟恰为 1 个控制周期。

**新增定义 541（残差自适应误差界 AdaptiveErrorBound）** ε_t 按带死区、泄漏与投影的离散自适应律演化：
```
ε_t = Proj_{[ε_min, ε_max]}( ε_{t−1}
        + λ·[ (r_t − ν)^+ − σ·(ε_{t−1} − β) ] ),   (z)^+ = max(z,0)
```
- **死区 ν**：残差在 ν 内视为传感器噪声，不推高 ε（抗噪，避免"噪声→过度保守→虚假退化"）；
- **泄漏 σ**：把 ε 缓慢拉回先验 β，防止无界漂移与"适应爆炸"（σ-modification）；
- **投影**：ε 恒在 [ε_min,ε_max]，保证有界；ε_max 是"鲁棒包络"的显式边界；
- 初值 ε_0 = β（与 v9 逐位兼容）。
仅当激励门（定义 542）通过时执行更新，否则 ε_t = ε_{t−1}。

**新增定义 542（激励门 PersistencyGate）** 维护回归量窗 W_pe（最近 N_pe 帧）：
```
adapt_allowed ⇔ λ_min( Σ_{τ∈W_pe} φ_τ φ_τ^T ) ≥ ρ_pe
```
不满足则冻结 ε。含义取自自适应控制的可辨识性/持续激励：在机器人静止、动作恒定或状态退化时，观测不含新信息，此时"适应"只会拟合噪声，故宁可不适应。

**新增定义 543（误差管 ErrorTube）** 从 x_t 出发的名义 rollout x̂_0=x_t, x̂_{k+1}=F̂(x̂_k,a_k)，管半径递推
```
ε_0 = ε_t,   ε_{k+1} = L_F·ε_k + w_max
```
并定义截面 T_k = {x : ‖x − x̂_k‖ ≤ ε_k}。若 L_F<1，管收缩；否则线性增长，块长 K_max 需满足 ε_{K_max} ≤ ε_tube_max（定义 543 与 K_max 联立约束，入部署期静态校验）。管内状态集合的上下界由标量余量函数的 Lipschitz 常数给出。

**新增定义 544（管状块证书 TubeCertificate）** 对候选块计算集合值最坏界：
```
ĝ_min = min_{k≤K} ( g(x̂_k) − L_g·ε_k )
ê_max = max_{k≤K} ( u(x̂_k) + L_u·ε_k )
```
证书有效 ⇔（i）ĝ_min ≥ d_safe；（ii）ê_max ≤ τ_eff；（iii）γ̂_grasp=valid；（iv）用当前 τᵢ(t) 复核各层；（v）鲁棒中止点集 P_t 非空（定义 546）。与 v9 定义 533 的差别：余量不再是全局标量 β，而是**逐步、随管半径增长**的 ε_k，越到块后段越保守。

**新增定义 545（越管与硬中止 TubeBreach）** 设当前执行步 k_exec，若
```
‖x_t − x̂_{k_exec}‖ > κ_b·ε_{k_exec}   或   r_t > κ_e·ε_t     (κ_b,κ_e ≥ 1)
```
则判定越管。越管立即触发：K_eff←1、切换到不超过当前步的最大鲁棒中止点、必要时安全停驻。越管是**不用窗口统计、不用块边界、单周期可判**的硬信号——这是对 v9"Δ_dom 滞后"缺口的直接封堵。

**新增定义 546（鲁棒停车不变式 RobustStopInvariant）** 中止点 p 合法当且仅当对管内所有状态成立：
```
d_brake(v_p) + d_safe + (L_v + L_d)·ε_p ≤ dist(s_p, O) − |traj_{p:K}|
```
即在 v9 定义 534 上把刹车距离与间隙余量按管半径 ε_p 双向膨胀。骨架仅接受 P_t 非空的候选块；无点可退仅发生于 K=1 fallback（等价 v8 逐步语义）。

**新增定义 547（鲁棒贡献界 RobustContributionBound）** 对每个 φ^elig 模块，在滑动窗内取贡献得分样本 {J_m^(i)}，用经验 Bernstein 界构造
```
ρ_m = sqrt( 2·Var_n·ln(2/δ) / n ) + 7·ln(2/δ) / (3(n−1))
c_m^LCB = max(0, c_m − ρ_m),   c_m^UCB = min(1, c_m + ρ_m)
```
其中 c_m 为 v9 定义 537 的 EMA，n 为样本数，置信度 1−δ。ρ_m 随样本数收缩：证据越少越保守。

**新增定义 548（鲁棒蒸馏状态机 RobustDistillFSM）**
- active → dormant：c_m^UCB < τ_off 且连续 H_off 回合成立，且无鲁棒告警；
- dormant → active：c_m^LCB ≥ τ_on，或任一鲁棒告警（越管/残差跳变 r_t>κ_e ε_t/Δ_dom≥τ_dom）；
- dormant → frozen：dormant 持续 20 回合且无告警；frozen 仅由离线证据解冻。
关键方向性：**用上界决定休眠**（有把握贡献低才睡），**用下界决定唤醒**（有把握贡献高才醒）；这与"点估计双阈"相比，把误睡风险从估计噪声中剥离。

**新增定义 549（鲁棒预算 EDF RobustBudgetEDF）** 每个契约预留 W_m^max=(1+γ)·Ŵ_m，部署期校验 Σ_m W_m^max ≤ B_dec；运行期 deadline_guard 仍按 Ŵ_m 触发中立元。若 Σ W_m^max 超预算，按优先级从低到高把 φ^elig 模块置 dormant（注入 v^⊥，引理 83），从而在 WCET 不确定下保持 50Hz。

**新增定义 550（自适应有效块长 AdaptiveEffectiveChunk）** 统一 v9 定义 539，把误差界也纳入门控：
```
u_t = max( Δ_dom(t)/τ_dom,  ε_t/ε_max,  risk_SLAM(t)/τ_SLAM )
K_eff(t) = 1                              若越管 或 u_t ≥ 1
         = max(1, ⌊K_max·(1 − u_t)⌋)       否则
```
域越陌生、残差越大、误差界越接近包络边界，块越短；极端统一退化为逐步。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v8 不变。

# IP-358 ResidualAdaptiveGovernor：残差自适应调节器
class ResidualAdaptiveGovernor:
    def __init__(self, beta, nu=0.005, lam=0.2, sigma=0.02,
                 eps_min=0.005, eps_max=0.15, rho_pe=1e-3, n_pe=10):
        self.beta, self.nu, self.lam, self.sigma = beta, nu, lam, sigma
        self.eps_min, self.eps_max = eps_min, eps_max
        self.rho_pe, self.n_pe = rho_pe, n_pe
        self.eps = beta
        self.pe_window = deque(maxlen=n_pe)

    def residual(self, x_true, x_prev, a_prev, Fhat, Psi):
        return Psi(x_true) - Psi(Fhat(x_prev, a_prev))

    def persistency_ok(self):
        if len(self.pe_window) < self.n_pe:
            return False
        Phi = np.array(self.pe_window)            # (n_pe, d)
        return np.linalg.eigvalsh(Phi.T @ Phi).min() >= self.rho_pe

    def update(self, x_true, x_prev, a_prev, Fhat, Psi):
        e = self.residual(x_true, x_prev, a_prev, Fhat, Psi)
        r = np.max(np.abs(e) / Psi.scale)
        self.pe_window.append(np.concatenate([Psi(x_prev), a_prev]))
        if not self.persistency_ok():
            return self.eps                     # 冻结：无新信息不适应
        drive = max(0.0, r - self.nu)           # 死区
        leak = self.sigma * (self.eps - self.beta)  # σ 泄漏
        eps = self.eps + self.lam * (drive - leak)
        self.eps = min(self.eps_max, max(self.eps_min, eps))  # 投影
        return self.eps


# IP-357 TubeChunkCertifier：管状块证书执行器
class TubeChunkCertifier:
    def __init__(self, forward_model, policy, gov, K_max=10,
                 L_F=1.05, w_max=0.01, L_g=1.0, L_u=1.0,
                 d_safe=0.15, kappa_b=1.5, kappa_e=1.5, dt=0.02):
        self.F, self.policy, self.gov = forward_model, policy, gov
        self.K_max, self.L_F, self.w_max = K_max, L_F, w_max
        self.L_g, self.L_u = L_g, L_u
        self.d_safe, self.kappa_b, self.kappa_e = d_safe, kappa_b, kappa_e

    def tube_radii(self, K):
        radii = [self.gov.eps]
        for _ in range(K):
            radii.append(self.L_F * radii[-1] + self.w_max)
        return radii                                  # ε_0..ε_K

    def robust_cert(self, pred, radii):
        g_min = min(pred.clearance[k] - self.L_g * radii[k]
                    for k in range(len(pred.clearance)))
        e_max = max(pred.effort[k] + self.L_u * radii[k]
                    for k in range(len(pred.effort)))
        return g_min, e_max

    def generate_chunk(self, state, delta_dom, tau_dom, risk_slam, tau_slam):
        u = max(delta_dom / tau_dom, self.gov.eps / self.gov.eps_max,
                risk_slam / tau_slam)
        if u >= 1.0:
            return self._single_step_fallback(state)          # 包络外
        K = max(1, int(self.K_max * (1.0 - u)))
        radii = self.tube_radii(K)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.F.rollout(state, cand)
            g_min, e_max = self.robust_cert(pred, radii)
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._robust_abort_points(state, cand, pred, radii)
            if not pts:
                continue
            score = self.policy.score(cand, pred)
            if best is None or score > best.score:
                best = Chunk(cand, TubeCert(g_min, e_max, radii), pts, score)
        return best or self._single_step_fallback(state)

    def _robust_abort_points(self, state, actions, pred, radii):
        pts = []
        for p in range(1, len(actions)):
            infl = (self.L_v + self.L_d) * radii[p]        # 管膨胀
            margin = (pred.clearance[p] - d_brake(pred.speed[p])
                      - self.d_safe - infl)
            if margin >= pred.path_len[p:]:
                pts.append(p)
        return pts

    def midchunk_guard(self, chunk, k_exec, live):
        """50Hz 廉价守卫：先判越管（硬），再判鲁棒证书。"""
        if np.linalg.norm(live.x - chunk.nominal[k_exec]) > \
                self.kappa_b * chunk.tube[k_exec]:
            return ('breach', self._nearest_abort(chunk, k_exec))   # 定义 545
        if live.r > self.kappa_e * self.gov.eps:
            return ('breach', self._nearest_abort(chunk, k_exec))
        stop_inv = (live.nearest_clearance - d_brake(live.speed)
                    - self.d_safe
                    - (self.L_v + self.L_d) * chunk.tube[k_exec])
        if stop_inv < chunk.remaining_len(k_exec):
            return ('breach', self._nearest_abort(chunk, k_exec))
        return ('continue', k_exec + 1)


# IP-359 RobustDistiller：鲁棒贡献蒸馏器
class RobustDistiller:
    def __init__(self, mw, tau_on=0.03, tau_off=0.01, delta=0.05,
                 T_abl=500, n_min=8, H_off=3):
        self.mw, self.tau_on, self.tau_off = mw, tau_on, tau_off
        self.delta, self.T_abl, self.n_min, self.H_off = delta, T_abl, n_min, H_off
        self.samples = defaultdict(list)
        self.state, self.count = {}, defaultdict(int)

    def observe(self, module, J_with, J_base):
        self.samples[module].append(normalize(J_with - J_base))

    def bounds(self, m):
        xs = np.array(self.samples[m][-self.T_abl:])
        if len(xs) < self.n_min:
            return 0.0, 1.0                     # 证据不足：上下界取满 → 不睡
        c = 0.9 * self.ema.get(m, xs.mean()) + 0.1 * xs.mean()
        n, var = len(xs), xs.var(ddof=1)
        rho = np.sqrt(2 * var * np.log(2 / self.delta) / n) \
              + 7 * np.log(2 / self.delta) / (3 * (n - 1))
        return max(0.0, c - rho), min(1.0, c + rho)

    def step(self, ctx):
        if ctx.tube_breach or ctx.delta_dom >= ctx.tau_dom:
            self.wake_all(); return                         # 鲁棒告警强制唤醒
        for m in self.samples:
            lcb, ucb = self.bounds(m)
            if self.state.get(m, 'active') == 'active' and ucb < self.tau_off:
                self.count[m] += 1
                if self.count[m] >= self.H_off:             # 上界决定休眠
                    self.state[m] = 'dormant'; self.mw.set_dormant(m)
            elif self.state.get(m, 'dormant') == 'dormant' and lcb >= self.tau_on:
                self.state[m] = 'active'; self.mw.set_active(m)  # 下界决定唤醒
                self.count[m] = 0

## 4. 推导

**引理 87（管不变式与鲁棒约束满足）** 设真实系统满足 x_{k+1}=F(x_k,a_k)+w_k，‖w_k‖≤w_max，且模型误差 ‖F−F̂‖≤ε_t（由引理 88 在概率/有界意义下覆盖）。若按定义 543 递推管半径，则对任意 k≤K 有 x_k∈T_k。于是对任意候选块的管证书有效（定义 544），块内所有软层约束在**任意可容许扰动**下成立。证明：对 k 归纳。k=0 由 ε_0=ε_t 覆盖模型误差；若 x_k=x̂_k+δ_k, ‖δ_k‖≤ε_k，则
```
‖x_{k+1} − x̂_{k+1}‖ ≤ ‖F(x_k,a_k) − F̂(x̂_k,a_k)‖ + ‖w_k‖
                     ≤ L_F‖x_k − x̂_k‖ + ε_t + w_max
                     ≤ L_F ε_k + ε_t + w_max,
```
取 ε_{k+1}=L_F ε_k + ε_t + w_max（保守版）即得 x_{k+1}∈T_{k+1}。再由 g,u 的 Lipschitz 性，管上最坏间隙 ≥ g(x̂_k)−L_g ε_k ≥ d_safe，最坏 effort ≤ u(x̂_k)+L_u ε_k ≤ τ_eff。停车情形由定义 546 的膨胀不变式直接给出刹车终点距障碍 ≥ d_safe。∎

**引理 88（自适应误差界的有界性、覆盖与稳态下界）** 设真实一步残差满足 r_t ≤ ē + w_max 且激励门通过。则定义 541 的 ε_t 在投影下一致有界：ε_t∈[ε_min,ε_max]；在残差统计平稳时，
```
|ε_t − ε*| ≤ (1−λ)^t |ε_0 − ε*| + σ·(λ/λ)·sup|ε − β| 的几何衰减,
ε* = β + [ (ē + w_max − ν)^+ ] / σ          （若 σ>0）
```
即 ε_t 指数收敛到由"真实误差−死区"与泄漏共同决定的邻域；死区给出稳态下界，泄漏给出无模型漂移时的有界偏移。证明：把更新写成 ε_t = (1−λ)ε_{t−1} + λ[(r_t−ν)^+ + σβ] + λσ(−ε_{t−1}+...) 的仿射形式，取关于 ε 的压缩映射；投影是 1-Lipschitz 非扩张算子，复合后仍收缩；扰动有界 ⇒ 输入-状态有界。∎

**引理 89（零延迟检出优势）** 设 t₀ 发生模型突变使 r_{t₀+1} > κ_e ε_{t₀}。则 RAG 在 t₀+1 周期即报越管/残差告警并把 u_t 推至 ≥1，K_eff 在 t₀+1 收缩到 1。而 v9 的 Δ_dom 为 20 帧滑窗统计，最早在 t₀+20 才可能越阈，且滑窗本身进一步平滑延迟。故在突变场景下 RAG 的检出延迟 ≤1 周期，严格优于 v9 的 ≥20 周期；结合定义 550，K_eff 的收缩在 1 周期内完成。∎

**引理 90（鲁棒蒸馏安全：无误睡）** 由经验 Bernstein 界，以概率 ≥1−δ 有 c_m∈[c_m^LCB, c_m^UCB]。若真实贡献 c_m ≥ τ_off，则 c_m^UCB ≥ c_m ≥ τ_off，定义 548 的休眠条件 c_m^UCB<τ_off 不可能成立，故不会误睡；若 c_m^LCB ≥ τ_on，则真实 c_m ≥ τ_on，唤醒是正当的。证据不足（n<n_min）时上下界取 [0,1]，休眠条件恒不成立，退化为全激活（保守正确）。∎

**引理 91（鲁棒双阈无抖振）** 定义 548 要求休眠需 c_m^UCB<τ_off 连续 H_off 回合、唤醒需 c_m^LCB≥τ_on，且 c_m^UCB ≥ c_m ≥ c_m^LCB。由于 τ_off<τ_on 且 ρ_m 非负，休眠/唤醒区间存在间隔，迁移需跨过间隔；再叠加 v9 引理 85 的回合节流，相邻迁移间隔 ≥ T_abl·H_off 个控制周期，有限时间迁移次数有限，无 Zeno。∎

**引理 92（严格退化等价）** 逐项关闭新模块：
- RAG 关闭 ⇒ 定义 541 的更新被替换为 ε_t≡β ⇒ 定义 543/544 退化为 v9 定义 533 的点证书；
- TCC 关闭 ⇒ 定义 544 取 ε_k≡β 且不做管传播 ⇒ 即 v9 点证书；
- RD 关闭 ⇒ 定义 548 用 c_m 点估计与 v9 双阈 ⇒ 即 v9 定义 538；
三者同时关闭 ⇒ 系统逐位等价于 v9 MetricVoiceGauge-ACMD；再沿 v9 定义 532–539 的退化链逐位回到 v8/v7/v6。因为退化只替换"不确定度来源"（在线 ε_t/管/置信界 → 静态 β/点证书/点估计），不改变任何模块的取值集合与聚合算子，故可观测日志逐位一致。∎

**引理 93（ISS 型性能界与无悬崖退化）** 设名义闭环在扰动 w 下的状态偏差为 d_t。管膨胀保证安全约束对 ‖w‖≤w_max 成立；性能（任务成功率）关于 (ε_t, w_max, 越管率) 单调不增。当 ε_t→ε_max 或越管率→1 时，定义 550 使 K_eff→1、定义 545 触发逐步安全停驻，系统连续过渡到 v8 逐步模式而非跳变失效。形式化地，存在 ISS 型界
```
succ_rate ≥ succ_v8 − C1·(ε_max − β) − C2·w_max
```
其中 C1,C2>0 为 Lipschitz 常数；退化是渐进的、可预算的，而非"某一刻突然失去证书"。∎

## 8. 本轮最大风险

**一句话**：管不变式与自适应界都以「残差可观测且扰动有界」为前提——若出现**残差不可观测的隐蔽偏移**（缓慢一致的传感器偏置、被欺骗/被篡改的观测、或恰好落在死区内的漂移），ε_t 会被死区锁在偏小值，误差管保持"名义安全"却整体偏离真实状态，自适应便用自己被压小的误差界为鲁棒性作了伪证。
