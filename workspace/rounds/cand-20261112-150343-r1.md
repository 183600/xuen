# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC；新灵感循环第 1 轮；本轮灵感：「机器人」×「产学研合作」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「执行层→证据层」升级为「认知驱动的场景-执行闭环」。但整套栈有一个隐含前提：**证据由同一主体、同一协议、同一激励产生**。当机器人真正的落地形态是**产学研协同**（高校出算法、企业出场景与数据、研究院出标准与安全评估）时，这个前提崩溃：
> 1. **证据不可通约（incommensurability）**：A 校的“抓取成功率 95%”与 B 企的“95%”在不同物体集、标定、光照、安全包络、试验次数下测得，直接平均会犯 Simpson 悖论式错误；第 60 轮的 EV-exec 只在机内自洽，跨机构后失去可比性。
> 2. **原始数据不可共享**：知识产权与商业机密使得“把日志交出来重算”不可行，证据必须以**可验证封装**而非原始数据的形式流转。
> 3. **激励不相容**：学求新颖可发表、产求可靠低成本、研求标准合规，三方都有**选择性报告**（只报成功、HARKing、刷榜）与**串通虚报**的动机；缺乏机制时，联邦证据池会被“刷”成不可信。
> 4. **抽象泄漏的机构版本**：单机栈里“证据层高度确定、执行层灾难失效”的风险，在跨机构情境下演化为“**证书高度确定、真实能力系统性虚高**”——这是比第 60 轮更隐蔽、更系统性的失效。

## 0. 直觉与动机

**灵感 1（机器人 → 能力证据的「可携带性」）**
直觉：一个机器人能力主张（“此策略在桌面抓取成功率 95%”）之所以不可携带，是因为**评测协议是隐性的**——物体集、传感器标定、光照范围、安全包络、试验次数、失败判据都散落在实验者的脑子里。类比临床研究：一个疗效结论必须附带**方案（protocol）+ 预注册（preregistration）+ 原始记录哈希**才可复现。关键洞见：把能力证据从「一个数字」升级为**协议清单 PM + 溯源封装 CPE**，让“在什么条件下、由谁、怎么做出的”成为证据的一部分，从而**可验证、可审计、可折算**。

**灵感 2（产学研合作 → 协议折算图与网络 Meta 分析）**
直觉：不同机构用不同协议评测，但总会有**共同锚定任务**（如标准物体集 GraspNet-Anchor、标准力控轨迹）。把这些锚定任务当作**汇率锚**，机构间的配对评测就是**汇率观测**，于是可以构造一张**协议折算图 G_τ**：节点是协议，边是头对头锚定评测。借用循证医学的**网络 Meta 分析**：用混合效应模型估计各协议到参考协议的折算因子 τ_{i→ref}，用**一致性（transitivity/consistency）检验**判断这张图是否自洽——若环路折算不闭合，就**拒绝全局聚合**（fail-closed），而不是硬凑一个“平均成功率”。

**灵感 3（产学研合作 → 激励相容预注册与盲测抵押）**
直觉：刷榜的根源是「先看结果再决定报什么」。用**预注册承诺**（先锁定假设、指标、失败判据的哈希）+ **盲测抵押**（主张越强、抵押越多）+ **严格适当评分规则**（Brier/对数损失，如实报告期望分最高）让诚实成为占优策略；对不可立即验证的远期主张，用**同行预测（peer prediction）**以机构间信号的互信息结算。再叠加**权重上限 + 法定人数 + 串通界**，使单方或少数合谋无法翻盘。**关键洞见：可信不只是“验证得对”，更是“在自利动机下没有动力去骗”。**

**灵感 4（三灵感合流 → 产学研可信能力演化闭环 R-CAPE）**
直觉：把「协议清单 → 溯源封装 → 折算 → 聚合 → 证书 → 缺口 → 下一轮联合实验」串成闭环：各机构按 PM 跑评测，产出带 EV-exec Merkle 根的 CPE；PXE 用锚定任务标定折算图；FEP 做异质性感知聚合，签发带外推边界的 **CTC（能力折算证书）**；证书暴露的覆盖缺口驱动**跨机构主动实验设计**（下一批锚定任务/边界任务）。这就是「联邦式的能力共同演化」，把第 60 轮的“场景先验收敛”换成“**跨机构证据先验收敛**”。

**灵感 5（预算/风险 → 协同预算 CBC 与串通风险）**
直觉：把第 60 轮的 PCE++++ 再扩一维**协同预算 B_collab** =（锚定任务预算、折算图维护预算、审计/质押预算、通信预算）。若锚定预算耗尽 ⇒ 证书降级为“仅本协议有效”；若一致性检验失败 ⇒ fail-closed；若检测到疑似串通 ⇒ 触发“加水印任务”复核并冻结相关权重。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（协议清单 PM）** 协议清单是一个可签名的机读结构：
`PM = (T_task, O_objset, Σ_sensor, L_light, E_safe, N_trials, F_fail, V_env, c_prereg)`，其中 T_task 为任务族、O_objset 为物体集（以内容哈希标识）、Σ_sensor 为标定指纹、L_light 为光照范围、E_safe 为安全包络、N_trials 为试验次数、F_fail 为失败判据、V_env 为环境版本、c_prereg 为预注册承诺哈希。`PM` 由机构私钥签名，任何字段改动都会破坏签名。

**定义 162（能力溯源封装 CPE）** `CPE = (institution_id, claim, PM, hw_fingerprint, root_EV, refs, t, σ)`。其中 `root_EV` 是本地 EV-exec 链（第 60 轮 EPIR 的 S_shadow）的 Merkle 根，`refs` 指向 J_exec/Cert_eeis，`σ` 为机构签名。验证算子 `Verify(CPE)`：校验签名、重算 Merkle 根、比对 PM 与预注册承诺。**CPE 让证据以“可验证封装”流转，而无需共享原始数据。**

**定义 163（协议折算图 G_τ 与一致性）** `G_τ = (V, E)`，V 为协议集合，E 为机构间在**共同锚定任务**上的配对评测，边 e=(i,j) 携带配对差 d_e 与方差 v_e。折算因子 `τ_{i→ref}` 由混合效应（网络 Meta）模型估计。**一致性（transitivity）**：对任一环路，折算差之和应近似为 0；用 node-splitting / design-by-treatment 检验其不一致性 `I²_net`。若 `I²_net > I²_max`，则判定「协议不可通约」，触发 **fail-closed**（拒绝全局聚合，仅给出分协议证书）。

**定义 164（联邦证据池 FEP）** 给定参考协议 `ref` 与一组通过验证的 CPE 集 `C`，聚合算子：
```
FEP(C, ref) = (μ̂, CI_{1-α}, τ², I², W)
① 折算: {x_k = PXE.exchange(c_k, ref) : c_k ∈ C ∧ Verify(c_k)}
② 随机效应: μ̂ = Σ w_k x_k / Σ w_k, w_k = 1/(v_k + τ²)
③ 异质性: τ² 由 DerSimonian–Laird 或 REML 估计; I² = τ²/(τ²+ v̄)
④ 权重封顶: w_k ← min(w_k, w_cap·Σw), 然后重新归一（防止单机构主导）
⑤ 若 I² > I²_max 或 τ² > τ²_max: return FAIL_CLOSED
```
输出 μ̂ 的置信区间须在异质性允许时保持名义覆盖率。

**定义 165（激励相容预注册 ICP）** `ICP = (Prereg, Escrow, Score, PeerPred, Slash)`：
- **预注册** `Prereg(c)`：在实验前提交 PM 与主张的哈希，事后不可改；
- **盲测抵押** `Escrow(claim) ∝ strength(claim)`：主张越强抵押越多；
- **适当评分** `Score(r, y)`：采用 Brier/对数损失，使 E[Score|如实] ≥ E[Score|谎报]；
- **同行预测** `PeerPred`：对暂不可验证的远期主张，用机构间评审信号的互信息结算；
- **惩罚** `Slash`：预注册不符或检出选择性报告时没收抵押。
在 `coalition < quorum` 时，如实报告为弱占优策略。

**定义 166（产学研可信能力演化闭环 R-CAPE）** 算子 `R-CAPE(institutions, ref, budget)`：
```
① 各机构按 PM 运行 → EV-exec / J_exec
② 打包 CPE（签名 + Merkle root + prereg 承诺）
③ PXE: 用锚定任务标定 G_τ，估计 τ_{i→ref}
④ FEP: 异质性感知聚合，过高 → FAIL_CLOSED
⑤ 签发 CTC（含覆盖协议集、外推边界、一致性状态、见证集合、有效期）
⑥ 缺口识别: 找 CI 最宽 / 锚定稀疏的 (协议, 任务) 区域
⑦ 跨机构主动实验设计: 选下一批锚定/边界任务（最大化 VOI）
⑧ 结算 ICP（评分、抵押、Shapley 归因）；更新协同信念
⑨ 循环
```

**定义 167（协同预算与串通界 CBC）** `B_collab = (B_anchor, B_graph, B_audit, B_comm)`。串通界：设法定人数为 q、单机构权重上限 w_cap，则翻转聚合结论至少需要 `k* = ⌈(1/2)·(Σw)/w_cap⌉` 个受封顶权重的合谋机构；未检出虚高的概率 ≤ δ，通过“水印任务 + 随机复核”控制。

**定义 168（能力折算证书 CTC 与贡献归因）**
`CTC = (μ̂, CI, applicable_protocols, extrapolation_boundary, consistency_status, witnesses, expiry)`。
**贡献归因**：对联合能力，机构 i 的 Shapley 值 `φ_i = Σ_{S⊆N\{i}} |S|!(n-|S|-1)!/n! · [v(S∪{i}) − v(S)]`，其中 v(S) 为联盟 S 的证据对 μ̂ 精度（1/方差）的边际贡献，用于产学分账与激励结算。

```python
class ProtocolManifest:

class CapabilityProvenanceEnvelope:
    def __init__(self, institution, claim, pm, hw_fp, ev_chain, refs, priv_key):
        self.institution, self.claim, self.pm = institution, claim, pm
        self.hw_fp, self.ev_chain, self.refs = hw_fp, ev_chain, refs
        self.t = now()

            return False

            return False
```

### IP-163 PXE（协议折算引擎）

```python
class ProtocolExchangeEngine:
    def fit(self, anchor_evals, ref):
        # anchor_evals: [(protocol_i, protocol_j, paired_diff d_e, var v_e)]
        G = build_graph(anchor_evals)
        tau = {}
        for node in G.nodes():
            tau[(node, ref)] = mixed_effects_estimate(G, node, ref)
        self.I2_net = inconsistency_test(G)      # node-splitting / design-by-treatment
        self.tau = tau
        return tau

    def exchange(self, cpe, ref):
        if not cpe.verify():
            return None
        t = self.tau.get((cpe.pm.task, ref), None)
        if t is None:
            return None                          # 无折算路径 → 不参与聚合
        return apply_calibration(cpe.claim, t, cpe.pm)

    def consistent(self, I2_max=0.5, tau2_max=0.04):
        return self.I2_net <= I2_max and self.tau2 <= tau2_max
```

### IP-164 FEP（联邦证据池聚合）

```python
def federated_pool(cpes, ref, pxe, w_cap=0.25, I2_max=0.5):
    xs, vs = [], []
    for c in cpes:
        x = pxe.exchange(c, ref)
        if x is None:
            continue
        xs.append(x.estimate); vs.append(x.variance)
    if len(xs) < pxe.quorum:
        return FAIL_CLOSED(reason="quorum")

    tau2 = dl_estimator(xs, vs)
    w = [1/(v + tau2) for v in vs]
    w = cap_and_normalize(w, w_cap)              # 单机构权重封顶
    mu = sum(wi*xi for wi, xi in zip(w, xs))
    I2 = tau2 / (tau2 + mean(vs))
    if I2 > I2_max or not pxe.consistent():
        return FAIL_CLOSED(reason="heterogeneity", I2=I2)
    ci = normal_ci(mu, 1/sum(w))
    return PooledCapability(mu, ci, tau2, I2, weights=w)
```

### IP-166 R-CAPE（闭环）

```python
def rcape(institutions, ref, budget):
    pxE = ProtocolExchangeEngine()
    while not budget.exhausted():
        cpes = [inst.run_protocol_and_wrap() for inst in institutions]
        pxE.fit(collect_anchor_evals(institutions), ref)
        pooled = federated_pool(cpes, ref, pxE)
        if isinstance(pooled, FAIL_CLOSED):
            ctc = degrade_to_per_protocol(cpes)
        else:
            ctc = issue_ctc(pooled, pxE, witnesses=sample_witnesses(institutions))
        gap = identify_coverage_gap(cpes, ctc)       # 宽 CI / 稀疏锚点
        next_tasks = active_experiment_design(gap, budget)  # 最大化 VOI
        settle_incentives(ctc, shapley_attribution(cpes))
        budget.charge(next_tasks)
        institutions.assign(next_tasks)
    return ctc
```

```python
class CollaborationBudget:
    def __init__(self, anchor=20, graph=10, audit=5, comm=100):
        self.B = dict(anchor=anchor, graph=graph, audit=audit, comm=comm)
        self.used = defaultdict(int)
    def consume(self, kind, n=1):
        self.used[kind] += n
        return self.used[kind] <= self.B[kind]

def collusion_bound(total_weight, w_cap):
    return math.ceil(0.5 * total_weight / w_cap)

def detect_collusion(reports, watermark_tasks, alpha=0.01):
    # 水印任务：只有合谋方会一致虚报的隐藏探针
    suspicious = []
    for group in candidate_groups(reports):
        if agreement(group, watermark_tasks) > expected + z(alpha):
            suspicious.append(group)
    return suspicious
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PM/CPE 验证 | O(log N)（Merkle 路径） | O(1) | 签名与 Merkle 根一致 ⇒ 证据完整未篡改 |
| PXE 折算 | O(A·K)（锚定边×机构）拟合；单包 O(1) | O(V+E) | 图内一致时折算无偏；不一致即拒绝 |
| FEP 聚合 | O(M)（M 为有效 CPE 数） | O(M) | I²≤阈值时 CI 名义覆盖率 ≥ 1−α |
| ICP 结算 | O(M) | O(M) | 合谋 < quorum 时如实为弱占优 |
| R-CAPE | O(轮 × 闭环) | 复用 | 缺口驱动下 μ̂ 方差单调不增 |

**正确性定理（FCP，Federated Capability Provenance）**：假设 A66–A70 成立——
**(A66)** CPE 通过 Verify ⇒ 证据与协议承诺完整、未篡改；
**(A67)** 折算图在锚定集上满足传递性（I²_net ≤ I²_max、τ² ≤ τ²_max）；
**(A68)** ICP 的预注册+抵押+严格适当评分成立，且合谋规模 < quorum；
**(A69)** 权重封顶 w_cap 与法定人数 q 生效；
**(A70)** 协同预算 B_collab 单调消耗，任一维耗尽即触发降级。
则：
1. **覆盖率**：若协议同质（I²≤阈值），FEP 输出的 CI 对参考协议真值覆盖率 ≥ 1−α；异质时 fail-closed 而非给出错误窄区间。
2. **可携带性**：证书 CTC 的能力主张仅在 `applicable_protocols` 与外推边界内有效，边界外主张无证书支持（拒绝“无限外推”）。
3. **诚实性**：在合谋 < quorum 时，如实预注册与报告是 ε-占优策略；选择性报告的期望收益被 Slash 抵消。
4. **抗串通**：翻转聚合结论至少需 k* = ⌈(Σw)/(2·w_cap)⌉ 个受封顶机构合谋；未检出概率 ≤ δ。
5. **归因公平**：Shapley 归因满足效率性、对称性、零贡献者零分配，可用于产学分账。

## 5. 本轮最大风险

**一句话**：若折算图只在极少数锚定任务上拟合、且合谋规模恰好低于 quorum，那么“**协议外推**”与“**合法串通**”会叠加成系统性虚高——证书看起来无懈可击，真实能力却被高估，这是第 60 轮抽象泄漏的机构放大器；必须以「**无锚点不出证书、I² 超阈即 fail-closed、权重封顶 + 水印任务随机复核、Shapley 归因留痕**」四重护栏，确保可信来自“可折算 + 难作弊”，而非“看起来一致”。

```python
class ProtocolManifest:
    def __init__(self, task, objset, sensor, light, safe, n_trials, fail, env, prereg):
        self.task, self.objset, self.sensor = task, objset, sensor
        self.light, self.safe, self.n_trials = light, safe, n_trials
        self.fail, self.env, self.prereg = fail, env, prereg
        self.digest = sha256(canonical_json(self.__dict__)).hexdigest()
    def verify_prereg(self, committed_hash):
        return self.digest == committed_hash

class CapabilityProvenanceEnvelope:
    def __init__(self, institution, claim, pm, hw_fp, ev_chain, refs, priv_key):
        self.institution, self.claim, self.pm = institution, claim, pm
        self.hw_fp, self.ev_chain, self.refs = hw_fp, ev_chain, refs
        self.t = now()
        self.root_EV = merkle_root([e.hash for e in ev_chain])
        self.sigma = sign(priv_key, self._payload())
    def verify(self):
        if not verify_signature(self.institution, self._payload(), self.sigma):
            return False
        if merkle_root([e.hash for e in self.ev_chain]) != self.root_EV:
            return False
        return self.pm.verify_prereg(self.pm.prereg)
```

### IP-163 PXE（协议折算图 = 网络 Meta 分析）

```python
class ProtocolExchangeEngine:
    def fit(self, anchor_evals, ref):
        G = build_graph(anchor_evals)                 # 边: (i,j,d_e,v_e)
        self.tau = {n: mixed_effects_estimate(G, n, ref) for n in G.nodes()}
        self.I2_net = inconsistency_test(G)           # node-splitting
        return self.tau
    def exchange(self, cpe, ref):
        if not cpe.verify():
            return None
        t = self.tau.get((cpe.pm.task, ref))
        return apply_calibration(cpe.claim, t, cpe.pm) if t else None
    def consistent(self, I2_max=0.5, tau2_max=0.04):
        return self.I2_net <= I2_max and self.tau2 <= tau2_max
```

### IP-164 FEP（异质性感知聚合）

```python
def federated_pool(cpes, ref, pxe, w_cap=0.25, I2_max=0.5):
    xs, vs = [], []
    for c in cpes:
        x = pxe.exchange(c, ref)
        if x is None: continue
        xs.append(x.estimate); vs.append(x.variance)
    if len(xs) < pxe.quorum:
        return FAIL_CLOSED(reason="quorum")
    tau2 = dl_estimator(xs, vs)
    w = cap_and_normalize([1/(v+tau2) for v in vs], w_cap)
    mu = sum(wi*xi for wi, xi in zip(w, xs))
    I2 = tau2 / (tau2 + mean(vs))
    if I2 > I2_max or not pxe.consistent():
        return FAIL_CLOSED(reason="heterogeneity", I2=I2)
    return PooledCapability(mu, normal_ci(mu, 1/sum(w)), tau2, I2, weights=w)
```

```python
def rcape(institutions, ref, budget):
    pxe = ProtocolExchangeEngine()
    while not budget.exhausted():
        cpes = [inst.run_protocol_and_wrap() for inst in institutions]
```

```python
class CollaborationBudget:
    def __init__(self, anchor=20, graph=10, audit=5, comm=100):
        self.B = dict(anchor=anchor, graph=graph, audit=audit, comm=comm)
        self.used = defaultdict(int)
    def consume(self, kind, n=1):
        self.used[kind] += n
        return self.used[kind] <= self.B[kind]

def collusion_bound(total_weight, w_cap):
```

### IP-168 CTC 与 Shapley 归因

```python
def issue_ctc(pooled, pxe, witnesses):
    return CTC(mu=pooled.mu, ci=pooled.ci,
               applicable_protocols=pxe.reachable_protocols(),
               extrapolation_boundary=pxe.boundary(),
               consistency_status='consistent' if pxe.consistent() else 'split',
               witnesses=witnesses, expiry=now()+TTL)

def shapley_attribution(cpes, value_fn):
    n = len(cpes); phi = {i: 0.0 for i in range(n)}
    for i in range(n):
        for S in subsets_excluding(n, i):
            phi[i] += factorial(len(S))*factorial(n-len(S)-1)/factorial(n) \
                      * (value_fn(set(S)|{i}) - value_fn(set(S)))
    return phi
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| PM/CPE | O(log N) 验证 | O(1) | 签名+Merkle 根 ⇒ 未篡改 |
| PXE | O(A·K) 拟合 / O(1) 单包 | O(V+E) | 一致性成立 ⇒ 折算无偏 |
| FEP | O(M) | O(M) | I²≤阈 ⇒ CI 覆盖率 ≥ 1−α |
| ICP | O(M) 结算 | O(M) | 合谋<quorum ⇒ 如实弱占优 |
| R-CAPE | O(轮×闭环) | 复用 | 缺口驱动 ⇒ μ̂ 方差单调不增 |

**正确性定理（FCP）**：若 A66–A70（同想法区）成立，则：
1. 同质协议下 FEP 的 CI 覆盖率 ≥ 1−α；异质时 fail-closed。
2. CTC 仅在 `applicable_protocols` 与外推边界内有效，拒绝无限外推。
3. 合谋 < quorum 时如实报告为 ε-占优；Slash 抵消选择性报告收益。
4. 翻转结论需 ≥ k* 个受封顶机构合谋，未检出概率 ≤ δ。
5. Shapley 归因满足效率性、对称性、零贡献者零分配。

## 5. 本轮最大风险

**一句话**：若折算图只在少量锚定任务上拟合、且合谋规模恰好低于 quorum，“协议外推”与“合法串通”会叠加成系统性虚高，证书看似无懈可击而真实能力被高估——这是第 60 轮抽象泄漏的机构放大器；必须以「无锚点不出证书、I² 超阈即 fail-closed、权重封顶 + 水印随机复核、Shapley 归因留痕」四重护栏，确保可信来自“可折算 + 难作弊”，而非“看起来一致”。
