# 第 3 轮（灵感循环第 3 轮；本轮灵感：「意图识别」×「语义建图」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其下为 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45）与 **MODGAUGE**。
> 本轮纪律：**在前人基础上改进，而不是推倒重来**——不新增「替代」模块，而是给 ToolGauge 加两个
> **上层条件变量**（意图、语义地图），并在其证据/退化体系内闭合。
> MODGAUGE 五不变式、ToolGauge 的 TCV / 双层下注 / AP-Cal / P-Quarantine 全部保留；
> 同时**正面回应第 2 轮最大风险**（AP-Cal 跨盲区相关污染）。

## 双轴映射（条件化而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 意图识别 | ToolGauge 对所有盲区「一视同仁」地修复，无相关性维度 | **I-Box**：意图假设集 I_t + 保守相关集 Rel(I_t) + 意图-动作绑定 IAB | 有限预算应投给「与当前任务意图相关」的盲区；但意图会错，所以只允许把相关集**保守放大**，绝不缩小 |
| 语义建图 | R 是匿名格子；AP-Cal 用**单一全局先验**跨盲区共享 | **S-Map + S-Transfer**：实体级、带证据的语义地图 + 语义门控的**带证书先验迁移** | 只有「语义上可交换」的盲区才共享先验；把第 2 轮的全局相关污染变成**局部、有半径、可证伪**的迁移误差 |

**核心命题**：把 ToolGauge 的「语义假设 → 契约化工具调用 → 摊销校准 → 交叉验证 → 局部热替换」升级为
「**意图条件化定向 → 实体级语义建图 → 语义门控迁移 → 契约化探测 → 交叉验证 → 局部热替换**」。
意图与语义**只做条件化与门控**，绝不进入数值真值通道；所有数值结论仍由计量层（回执 + 独立交叉验证）独占。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 主张绑定不变式**再扩展**：意图主张、地图节点标签、地图边关系都必须引用有效回执，否则序列化时剥离（定义 444）；
- **严格退化链延长**：MapGauge 失效（意图 SLA 跌破 / 地图 disputed / 无证书可迁移 / IAB 全拒）⇒ 退回 ToolGauge（全局 AP-Cal + 全盲区）⇒ 退回 LeanGauge ⇒ 退回 MODGAUGE。
  意图与语义是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（意图识别 → 给有限预算一个「相关性」维度）**
直觉：ToolGauge 的 6C 对每个被 D-Box 发现的盲区平等地启动修复，但感知/探测预算有限，
一个「倒水入透明杯」任务里，墙面镜面反射的盲区无关紧要，而杯口透明边缘的盲区决定成败。
意图识别提供 task-conditioned relevance，但它本身以「自信地误判」著称。
于是我们把它设计成**只会放大、不会缩小**的保守算子：
(a) 意图识别器只吃白名单数值与实体级统计（继承定义 429），输出共形意图集 I_t（定义 432）；
(b) 相关集 Rel(I_t) 取「I_t 中任一意图下都可能相关」的并集，再**硬并入**安全关键集合 C1（定义 433）；
(c) 意图越不确定，I_t 越大、Rel 越大；SLA 跌破直接取全集（定义 443）。
结论：意图错误的最坏后果是**浪费预算**，而不是**漏修关键盲区**。
第二个、更隐蔽的用法：对**探测程序本身**做意图识别——每条工具调用必须声明 target(c) 与预期增益，
无有效 target 的调用在 TCV 前剥离（定义 434）。这把定义 423 的「主张-回执绑定」对偶到了**动作侧**，
堵住 VLA 生成「无的放矢」的探测程序。

**灵感 2（语义建图 → 把匿名格子变成带证据的实体知识图）**
直觉：第 2 轮最大风险源于 AP-Cal 让**所有**盲区共享一个全局先验——一旦先验在部署分布下偏移，
错误会沿着「所有盲区」这条隐式全连接图同时传播。语义建图提供一把手术刀：
物理世界的规律是语义的——同材质、同光照 regime、同物体的区域才真正可交换。
于是把 R 的格子按实体聚合为节点，建 `same_object / same_material / adjacent / occludes / lighting_regime` 边，
每条边与标签都**绑定回执证据**（定义 435、444）。先验迁移只在**证书成立**的实体对间发生（定义 437、438），
且迁移方差按 L·d_sem 保守膨胀。这样：
(a) 污染从「全局」缩为「半径 ρ 的局部」，并有 Lipschitz 风险界（引理 52）；
(b) 地图本身可被数值残差**证伪**（MNC，定义 440），证伪沿边局部回滚（引理 55），
由 M-Quarantine（定义 441）在线断路；
(c) 地图是「带证据的知识图」，无证据标签/边在序列化时剥离为纯投影（定义 444，推广引理 49）。
**语义不等于真值**：地图只影响**先验**，最终仍被独立回执与 MNC 复核后才允许热替换。

**灵感 3（二者协同：意图选「修哪里」，语义定「怎么迁移」）**
直觉：意图解决**调度**（哪些盲区先修、值不值得修），语义解决**迁移**（同一先验能安全借给谁）。
二者正交又互补：I-Scheduler 在实体级排序（定义 439），S-Transfer 在实体级供先验（定义 438）；
当意图不确定时相关集放大 + 迁移退回全局先验 = 精确退回 ToolGauge。
这保证 MapGauge 的每一条新机制都有一个「关闭开关」对应到已知安全的旧系统。

## 1. 形式化定义（增量：定义 432–446）

**定义 432（意图变量与意图假设集 I_t）** 任务意图是潜变量 z_t ∈ 𝒵，𝒵 为预注册枚举
（`handover / place / avoid / inspect / pour / idle` 等，禁止自由生成）。
意图识别器 f_I 仅接收白名单数值与实体级统计（继承定义 429），输出 score_I(z|ctx)。
部署前用共形校准得阈值 τ_I，运行时 I_t = {z : score_I(z|ctx) ≤ τ_I}；
可交换性下 P(z* ∈ I_t) ≥ 1−α_I。|I_t| > 1 表示意图歧义。

**定义 433（意图-盲区相关度与保守相关集）** rel(s|z) ∈ [0,1] 为「解决盲区 s 对意图 z 的价值」，
由预注册任务模型给出（可用仿真回归拟合，但枚举绑定，不接受自由文本）。
保守相关集 Rel(I_t) = (⋃_{z∈I_t}{s : rel(s|z) ≥ ρ_rel}) ∪ C1，
其中 C1 为安全关键盲区集合（**硬包含，与意图无关**）。
单调性：I_t ⊆ I_t' ⇒ Rel(I_t) ⊆ Rel(I_t')。

**定义 434（意图-动作绑定 IAB）** 探测调用 c=(t,args) 必须携带 target(c) ∈ H_s 与预测增益 Ĝ(c)；
IAB(c) ⇔ target(c) 有效 ∧ Ĝ(c) ≥ γ_B。无 target 的调用在 TCV 之前剥离；
整个程序无有效 target ⇒ 拒绝并回退 ToolGauge 的 numeric_fallback。
这是定义 423「主张-回执绑定」在**动作侧**的对偶。

**定义 435（语义地图 S-Map）** G_t = (V_t, E_t, φ_t, ψ_t, ν_t)：
- V_t：实体节点（物体实例，或未映射区域节点 ē）；
- 每节点携带材质分布 m_v、可供性 a_v、几何包络 b_v、光照 regime l_v、置信 ν_t(v)；
- E_t：关系边 `same_object / same_material / adjacent / occludes / lighting_regime`；
- φ_t : V → 2^{R cells}：实体到数值格子的接地映射；
- ψ_t : E ∪ V → receipts：**证据绑定**（地图标签/边必须引用有效回执，继承定义 417）。

**定义 436（盲区提升到实体级）** 盲区 s 提升为 ent(s)：若 φ_t(v) ∋ s 则取覆盖它的实体；
否则新建 unmapped 节点（未知物体）。调度与迁移在实体级进行，但数值修复**仍逐格写契约**，
不改变 U 阶段的数值语义与热替换等价性。

**定义 437（语义度量与可迁移性证书）**
d_sem(e,e′) = w_m·W₂(m_e,m_e′) + w_g·‖b_e−b_e′‖ + w_l·1[l_e ≠ l_e′]
（材质分布的 Wasserstein-2 + 几何 + 光照 regime 差异）。
可迁移性证书 TC(e→e′) ⇔ d_sem(e,e′) ≤ ρ_transfer ∧ support(ψ 证据) ≥ κ_ev ∧ ¬disputed(e,e′)。
只有 TC 成立的实体对才允许共享先验。

**定义 438（语义门控迁移 S-Transfer）** 对实体 e，从已校准且 TC 成立的源中取 d_sem 最近者 e*；
迁移后验 q_e = 𝒯_ρ(q_{e*})，方差按 L·d_sem 膨胀（保守）。
无证书源 ⇒ 回退定义 420 的全局 MP-Φ / 物理先验（即 ToolGauge 行为）。
**迁移只改先验，不改观测似然**；最终仍由回执与 V 阶段独立交叉验证裁决。

**定义 439（意图-语义调度器 I-Scheduler）**
Priority(s) = rel(ent(s)|I_t) · VoI(ent(s)) / c(s)，VoI 为预期任务关键不确定度下降。
预算 B_tools 下按优先级做 0/1 背包式排序；**硬约束**：C1 安全关键盲区优先于任何 C0，
且 C1 不得因预算被裁掉。调度只改**修复顺序与取舍**，不改任何数值算子。

**定义 440（语义-数值一致性 MNC）** 每条语义边/节点标签必须与数值校准残差一致：
若声称 `same_material`，则两实体契约参数在 d_sem 尺度下的残差必须落在预注册带内；
否则该边被证伪、移除，并失效经过它的所有迁移（局部回滚）。

**定义 441（地图证伪断路器 M-Quarantine）** 每个边/节点维护矛盾计数；
连续 ≥ q 次矛盾 ⇒ 标记 disputed，阻断其上迁移，排队重扫；
被 disputed 节点覆盖的盲区退回 ToolGauge 全局先验路径。

**定义 442（MapGauge 七段闭环 7C）** I(ntent) → H(ypothesize) → C(ompile) → E(xecute) → C(alibrate) → V(erify) → U(pdate)：
1. **I**：意图假设集 I_t + 保守相关集 Rel(I_t)；
2. **H**：仅对 Rel(I_t) 内盲区做 L-Box 假设（其余保留观测、暂不消耗修复预算）；
3. **C**：IAB 校验 + TCV（继承定义 418）；
4. **E**：工具执行（继承，PROBING 显式态）；
5. **C**：S-Transfer 门控先验 + AP-Cal 摊销；
6. **V**：独立回执交叉验证 + **MNC 地图一致性** + 契约回归；
7. **U**：热替换 + 地图节点/边更新（带证据）+ 语言修复证书。
任一阶段失败 ⇒ 逐级退化为 ToolGauge 全局先验路径。

**定义 443（意图歧义与 SLA 保守退化）** 若 |I_t| > λ_amb 或意图共形 SLA < 1−α_I−2η_I，
则 Rel(I_t) := 全部盲区（含 C1），即退回 ToolGauge 的「所有盲区都修」。
这是**只会增加**相关集的安全退化，绝不减少。

**定义 444（地图证据绑定与投影）** 节点标签与边关系都必须携带 receipts；
无证据的标签/边在契约序列化时剥离（纯投影，不改变数值行为）。
这是定义 423/427 在语义侧的推广——地图因此是「带证据的知识图」，而非自由生成的世界模型。

**定义 445（地图持久化与会话复用）** 地图跨任务片段保留，边置信按时间/环境变化衰减
ν ← ν·exp(−Δt/τ_map)；环境变化检测（几何/光照统计显著变化）触发重扫与再验证，避免复用过期语义。

**定义 446（继承与编号约定）** 未重定义记号沿用定义 398–431；
MapGauge 以 ToolGauge 为退化特例：令 I_t = 𝒵（全意图）、G = ∅（无实体，全部 unmapped）、
ρ_transfer = 0（禁止迁移）⇒ MapGauge ≡ ToolGauge。

## 2. 关键算法骨架

```python
# IP-321 I-Box：意图假设 + 保守相关集（只会放大，不会缩小）
class IBox:
    def infer(self, ctx):                       # ctx 仅白名单数值/实体统计（定义 429）
        scores = {z: self.fI(z, ctx) for z in Z_ENUM}
        I = {z for z, sc in scores.items() if sc <= self.tau_I}
        if len(I) > LAMBDA_AMB or self.sla() < 0.8:
            return set(Z_ENUM)                  # 保守放大（定义 443）
        return I
    def relevant(self, I, smap):                # 定义 433
        rel = {s for z in I for s in REL_BY_INTENT[z]
               if REL_BY_INTENT[z][s] >= RHO_REL}
        return rel | CRITICAL_SET               # C1 硬包含

# IP-325 IAB：意图-动作绑定
class IAB:
    def check(self, call, H_s):                 # 定义 434
        return (call.target in H_s) and (call.pred_gain >= GAMMA_B)

# IP-322 S-Map：带证据的实体级语义地图
class SMap:
    def lift(self, s):                          # 定义 436
        v = self.owner_of(s)
        return v if v is not None else self.new_unmapped(s)
    def update(self, e, label, receipts):       # 定义 444：标签必须带证据
        self.nodes[e].labels.append(Label(label, receipts)); self.revalidate(e)
    def d_sem(self, e, e1):                     # 定义 437
        return (W_M * wasserstein(self.mat[e], self.mat[e1])
                + W_G * geom_dist(self.box[e], self.box[e1])
                + W_L * (self.light[e] != self.light[e1]))
    def transferable(self, e, e1):
        return (self.d_sem(e, e1) <= RHO_TRANSFER
                and self.support(self.edge(e, e1)) >= KAPPA_EV
                and not self.disputed(e, e1))

# IP-323 S-Transfer：语义门控迁移（无证书即退化）
class STransfer:
    def prior_for(self, e):
        srcs = [x for x in self.smap.calibrated() if self.smap.transferable(e, x)]
        if not srcs:
            return self.global_prior(e)          # 退化：定义 420 全局先验
        e1 = min(srcs, key=lambda x: self.smap.d_sem(e, x))
        q  = transport(self.smap.posterior[e1], self.smap.d_sem(e, e1))
        return inflate(q, L_LIP * self.smap.d_sem(e, e1))   # 保守方差膨胀

# IP-324 I-Scheduler：意图 × 信息价值 × 代价（C1 不可裁）
class IScheduler:
    def order(self, rel, budget):
        crit = sorted(rel & CRITICAL_SET, key=lambda s: -self.priority(s))
        rest = sorted(rel - CRITICAL_SET, key=lambda s: -self.priority(s))
        out, spend = [], 0.0
        for s in crit + rest:                    # 定义 439
            c = self.est_cost(s)
            if s in CRITICAL_SET or spend + c <= budget:
                out.append(s); spend += c
        return out

# IP-326 MapGauge-7C（逐级退化到 ToolGauge）
def mapgauge_7c(M, s):
    e = M.smap.lift(s)                                    # 实体级提升（定义 436）
    I = M.ibox.infer(M.ctx)                               # I
    if s not in M.ibox.relevant(I, M.smap):
        return "deferred"                                 # 相关集外：不消耗预算
    H    = M.lbox.hypothesize(e, M.dbox.R[s])             # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))
    prog = [c for c in prog if M.iab.check(c, H)]         # 意图-动作绑定（定义 434）
    if not prog:
        return M.toolgauge_6c(M, s)                       # 退化 ToolGauge
    receipts = M.tcv.execute(prog, M.env)                 # E
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    prior   = M.stransfer.prior_for(e)                    # C：语义门控先验
    mu, Sig = M.apcal.calibrate(receipts, H, s, prior=prior)   # C
    if not (M.apcal.cross_validate(mu, Sig, M.cross_receipt(s))
            and M.mnc.consistent(e, mu, Sig)):            # V：独立回执 + MNC（定义 440）
        return M.toolgauge_6c(M, s)                       # 退化 ToolGauge
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)   # U
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    M.smap.update(e, label_from(H), receipts)             # 地图证据绑定（定义 444）
    M.mq.record(M.mnc.last_residual(e))                   # M-Quarantine（定义 441）
    bind_claims(new_ec, H, prog, receipts)
    return True

# IP-327 主闭环：先意图调度，再 7C，全异步于 50Hz 路径外
def MapGauge_round(M, obs, audio, tac, depth, det):
    I   = M.ibox.infer(M.ctx)
    rel = M.ibox.relevant(I, M.smap)
    for s in M.isched.order(rel, M.budget_left(None)):
        if s not in M.inflight:
            M.inflight.add(s); submit_async(mapgauge_7c, M, s)
    if M.mq.triggered():
        M.stransfer.disable(); M.smap.revalidate_disputed()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 3. 推导

**引理 51（意图覆盖与相关集单调性）** 可交换性下 P(z* ∈ I_t) ≥ 1−α_I；
Rel 单调（I ⊆ I′ ⇒ Rel(I) ⊆ Rel(I′)），故 P(Rel(z*) ⊆ Rel(I_t)) ≥ 1−α_I。
C1 硬包含 ⇒ 安全关键盲区的修复优先级与意图无关。
**系 51.1**：意图越不确定，相关集越大，最终退化为全集（定义 443），
故在覆盖事件内，**意图错误只会浪费预算，不会漏修相关盲区**。

**引理 52（语义迁移的风险界）** 设实体标定 e ↦ u_e 关于 d_sem 是 L-Lipschitz，
且迁移仅在 d_sem ≤ ρ_transfer 且证书成立时发生；则从源 e* 迁移到 e 的后验超额风险
R(q_e) − R(q*) ≤ [R(q_{e*}) − R(q*)] + L·d_sem(e,e*)。
沿由 m 条证书边构成的路径，累计污染 ≤ m·L·ρ_transfer。
无证书源时回退物理先验，风险不超过 LeanGauge。
**系 52.1**：第 2 轮「一个错误先验污染所有盲区」被替换为**半径 ρ 的局部污染**；
ρ_transfer→0 或地图全 disputed 时精确退化为 ToolGauge，并被 P-Quarantine 继续监控。

**引理 53（调度不降安全性）** I-Scheduler 只重排 C0（非安全关键）修复；
C1 按定义 439 硬优先且不被预算裁掉 ⇒ 对任意意图输出，C1 修复完成时刻
不晚于 ToolGauge 在同一预算下的完成时刻（优先队列只把 C1 前移）。
系：意图识别的最坏情况是「C0 修复变慢/被跳过」，**不是安全关键盲区被跳过**。

**引理 54（意图-动作绑定不削弱探测）** IAB 只剥离 target 无效或增益低于 γ_B 的调用；
γ_B 与定义 419 的增益注阈值一致，故被保留的调用都满足原 ToolGauge 的收益门；
全程序被拒 ⇒ 退 ToolGauge numeric_fallback。
因此 MapGauge 的探测有效性不低于 ToolGauge，且额外获得「无的放矢程序」的可执行检查。
**系 54.1**：IAB 把「程序是否真的服务于假设」从语义承诺变成契约检查。

**引理 55（地图证伪的局部性）** MNC 证伪一条边只失效经过该边的 S-Transfer；
不经过该边的实体，其先验与契约数值不变（局部回滚）。
结合 U 阶段热替换局部性（引理 44/49），未受影响子图逐指令等价。
**系 55.1**：语义地图错误的影响域 = 证伪边所在的连通迁移分量，可被 M-Quarantine 隔离。

**引理 56（7C 时序与预算保持）** I 阶段（意图前向）、地图更新与证书计算全在 50Hz 路径之外异步执行；
50Hz 内联新增仅为调度查表与既有回执验证 O(1) < 0.2ms；
单盲区修复时延 ≤ ToolGauge 上界 + τ_I + τ_map ≤ τ_repair（TB-Contract 扩充）。
逐级退化到 ToolGauge/LeanGauge/MODGAUGE ⇒ 引理 45/50 保持。

**引理 57（地图证据绑定的投影不变性）** 剥离无证据的节点标签/边是纯投影，不进入任何数值算子；
地图只通过 S-Transfer 的**先验**影响数值，而先验在 V 阶段被独立回执与 MNC 复核。
故地图证据绑定不破坏热替换等价性（推广引理 49）。

## 6. 本轮最大风险（一句话）

**一句话**：语义地图本身可能「自信地错」——**语义别名（semantic aliasing）**会把两种不同材质/光照的实体
合并到同一节点或 `same_material` 边，S-Transfer 的证书机制于是沿着这个错误等价类
**系统性地、且带着证据外观地**复制同一错误先验；这恰好把第 2 轮想消灭的「跨盲区相关污染」重新引入，
而且因为地图看起来「局部且有证据」，比全局 AP-Cal 污染更难被审计者怀疑——
**用一张错的地图去局部化误差，可能把一个全局错误伪装成许多个互相印证的局部正确**。

**次级风险与缓解**：
1. **语义别名 / 地图漂移** → MNC 残差检验 + M-Quarantine + 定期盲区抽样主动重验（E444/E448/E449）；
2. **意图误判** → 相关集只放大不缩小 + C1 硬包含 + 歧义退化 + 对抗意图实验（引理 51/53，E442/E452）；
3. **意图识别输入被注入** → 白名单数值输入 + 枚举输出 + schema 校验（定义 429/432，E449）；
4. **地图证据伪造** → 边/标签绑定签名回执 + 单调 seq + 纯投影剥离（定义 417/444，E455）；
5. **迁移误差沿路径累积** → 路径长度上限 + 只取最近证书源 + 方差保守膨胀（定义 438，引理 52）；
6. **意图/地图时延抖动** → 全异步 + 缓存 + 逐级退化到 ToolGauge（引理 56）；
7. **新机制过度自信** → 定义 446 的精确退化 + E450 逐指令 diff = 0 作为回归护栏。

# 第 3 轮产物 · 创新点清单 v3：**MapGauge**（Intent-Conditioned Semantic Metrology Mapping）

> 背景：第 2 轮 ToolGauge（IP-315–320）把探测动作接口化（TCV）、把先验预训练摊销化（AP-Cal）、

## 2. 形式化定义（要点）

**定义 432（意图假设集）** 意图 z_t ∈ 𝒵（预注册枚举），识别器仅吃白名单数值与实体统计；
共形阈值 τ_I 给出 I_t = {z : score_I(z|ctx) ≤ τ_I}，可交换下 P(z*∈I_t) ≥ 1−α_I。
**定义 433（保守相关集）** Rel(I_t) = (⋃_{z∈I_t}{s : rel(s|z) ≥ ρ_rel}) ∪ C1，单调、只增不减。
**定义 434（IAB）** 调用 c 必须带 target(c)∈H_s 且 Ĝ(c) ≥ γ_B；否则执行前剥离；全程序无目标则回退 ToolGauge。
**定义 435（S-Map）** 实体节点携带材质/可供性/几何/光照/置信，关系边含 `same_material` 等；标签与边绑定回执 ψ。
**定义 436（实体提升）** ent(s) 把格子盲区提升为实体级查询，但数值修复仍逐格写契约。
**定义 437（语义度量与证书）** d_sem = w_m·W₂(材质) + w_g·几何 + w_l·光照；
TC ⇔ d_sem ≤ ρ_transfer ∧ support(ψ) ≥ κ_ev ∧ ¬disputed。
**定义 438（S-Transfer）** 从最近证书源迁移先验，方差按 L·d_sem 膨胀；无源则回退定义 420 全局先验。
**定义 439（I-Scheduler）** Priority = rel·VoI/c；C1 硬优先且不被预算裁掉；只改顺序不改算子。
**定义 440（MNC）** 语义边/标签必须与数值残差一致，否则证伪并失效经过它的迁移（局部回滚）。
**定义 441（M-Quarantine）** 矛盾计数连续 ≥ q ⇒ disputed，阻断迁移，退回 ToolGauge 路径。
**定义 442（7C）** I→H→C→E→C→V→U；V 加 MNC；失败逐级退化。
**定义 443（歧义退化）** |I_t|>λ_amb 或 SLA 跌破 ⇒ Rel := 全盲区（只增不减的安全退化）。
**定义 444（地图证据绑定）** 无证据标签/边序列化时剥离，纯投影不改数值（推广定义 423/427）。
**定义 445（持久化）** 地图跨片段保留，置信按 τ_map 衰减，环境变化触发重扫。
**定义 446（退化约定）** I_t=𝒵、G=∅、ρ_transfer=0 ⇒ MapGauge ≡ ToolGauge。

```python
# IP-321 I-Box：意图假设 + 保守相关集（只放大）
class IBox:
    def infer(self, ctx):
        scores = {z: self.fI(z, ctx) for z in Z_ENUM}
        I = {z for z, sc in scores.items() if sc <= self.tau_I}
        return set(Z_ENUM) if (len(I) > LAMBDA_AMB or self.sla() < 0.8) else I
    def relevant(self, I, smap):
        rel = {s for z in I for s in REL_BY_INTENT[z]
               if REL_BY_INTENT[z][s] >= RHO_REL}
        return rel | CRITICAL_SET

# IP-325 IAB
class IAB:
    def check(self, call, H_s):
        return (call.target in H_s) and (call.pred_gain >= GAMMA_B)

# IP-322 S-Map
class SMap:
    def lift(self, s):
        v = self.owner_of(s)
        return v if v is not None else self.new_unmapped(s)
    def update(self, e, label, receipts):
        self.nodes[e].labels.append(Label(label, receipts)); self.revalidate(e)
    def d_sem(self, e, e1):
        return (W_M * wasserstein(self.mat[e], self.mat[e1])
                + W_G * geom_dist(self.box[e], self.box[e1])
                + W_L * (self.light[e] != self.light[e1]))
    def transferable(self, e, e1):
        return (self.d_sem(e, e1) <= RHO_TRANSFER
                and self.support(self.edge(e, e1)) >= KAPPA_EV
                and not self.disputed(e, e1))

# IP-323 S-Transfer
class STransfer:
    def prior_for(self, e):
        srcs = [x for x in self.smap.calibrated() if self.smap.transferable(e, x)]
        if not srcs:
            return self.global_prior(e)          # 退化：全局先验
        e1 = min(srcs, key=lambda x: self.smap.d_sem(e, x))
        q  = transport(self.smap.posterior[e1], self.smap.d_sem(e, e1))
        return inflate(q, L_LIP * self.smap.d_sem(e, e1))

# IP-324 I-Scheduler
class IScheduler:
    def order(self, rel, budget):
        crit = sorted(rel & CRITICAL_SET, key=lambda s: -self.priority(s))
        rest = sorted(rel - CRITICAL_SET, key=lambda s: -self.priority(s))
        out, spend = [], 0.0
        for s in crit + rest:
            c = self.est_cost(s)
            if s in CRITICAL_SET or spend + c <= budget:
                out.append(s); spend += c
        return out

# IP-326 MapGauge-7C
def mapgauge_7c(M, s):
    e = M.smap.lift(s)                                    # 实体提升
    I = M.ibox.infer(M.ctx)                               # I
    if s not in M.ibox.relevant(I, M.smap):
        return "deferred"
    H    = M.lbox.hypothesize(e, M.dbox.R[s])             # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))
    prog = [c for c in prog if M.iab.check(c, H)]         # IAB
    if not prog:
        return M.toolgauge_6c(M, s)
    receipts = M.tcv.execute(prog, M.env)                 # E
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    prior   = M.stransfer.prior_for(e)                    # C：语义门控先验
    mu, Sig = M.apcal.calibrate(receipts, H, s, prior=prior)
    if not (M.apcal.cross_validate(mu, Sig, M.cross_receipt(s))
            and M.mnc.consistent(e, mu, Sig)):            # V：交叉验证 + MNC
        return M.toolgauge_6c(M, s)
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)   # U
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    M.smap.update(e, label_from(H), receipts)             # 地图证据绑定
    M.mq.record(M.mnc.last_residual(e))                   # M-Quarantine
    bind_claims(new_ec, H, prog, receipts)
    return True

# IP-327 主闭环
def MapGauge_round(M, obs, audio, tac, depth, det):
    I   = M.ibox.infer(M.ctx)
    rel = M.ibox.relevant(I, M.smap)
    for s in M.isched.order(rel, M.budget_left(None)):
        if s not in M.inflight:
            M.inflight.add(s); submit_async(mapgauge_7c, M, s)
    if M.mq.triggered():
        M.stransfer.disable(); M.smap.revalidate_disputed()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（意图覆盖与相关集单调性）** P(z*∈I_t) ≥ 1−α_I；Rel 单调 ⇒ P(Rel(z*)⊆Rel(I_t)) ≥ 1−α_I；
C1 硬包含 ⇒ 关键盲区修复与意图无关。系：意图错误只会浪费预算，不会漏修相关盲区。
**引理 52（语义迁移风险界）** L-Lipschitz 下 R(q_e)−R(q*) ≤ [R(q_{e*})−R(q*)] + L·d_sem(e,e*)；
m 条证书路径累计污染 ≤ m·L·ρ_transfer；无证书源回退物理先验，不劣于 LeanGauge。
系：第 2 轮全局污染 → 半径 ρ 的局部污染，ρ→0 精确退 ToolGauge。
**引理 53（调度不降安全性）** I-Scheduler 只重排 C0，C1 硬优先不可裁 ⇒ C1 完成时刻不晚于 ToolGauge 同预算。
**引理 54（IAB 不削弱探测）** 保留调用都满足原增益门 γ_B；全拒则退 numeric_fallback ⇒ 有效性不降。
**引理 55（证伪局部性）** MNC 证伪一条边只失效经过它的迁移，不经过的实体数值不变（局部回滚）。
**引理 56（7C 时序预算保持）** 意图/地图/证书全异步；50Hz 内联新增 < 0.2ms；
修复时延 ≤ ToolGauge 上界 + τ_I + τ_map ≤ τ_repair；逐级退化保持引理 45/50。
**引理 57（地图证据投影不变性）** 剥离无证据标签/边为纯投影；地图只经先验影响数值，且先验被 V 阶段复核 ⇒ 推广引理 49。
