# 第 1 轮（新循环；承接第 69 轮 FLUID-RAS IP-253~263；本轮灵感：「MuJoCo」×「语义建图」）

> R66–R69 把「风险」做成了一条闭环：谁控制、未来怎样、测量还准吗、该向谁求证。但它们共享一个从未被审视的前提——**世界模型里的物理是给定的**。语义地图告诉你「哪里有什么」，却几乎不告诉你「那东西有多重、有多滑、推一下会怎样、能不能承重」；MuJoCo 提供高保真接触物理，却是一个「模型饥饿」的预言机：质量、摩擦、接触刚度、关节类型稍有偏差，仿真就是在精确地演一个错的世界。
>
> 本轮把两者接起来：**语义是物理的先验，接触是物理的测量，MuJoCo/MJX 是前向模型兼批量推断引擎**。于是地图不再是「标签 + 几何」，而是逐实体的**物理信念**——一张「世界会怎样响应我的动作」的地图。
>
> 命名 **PHYSEM**（Physics-grounded SEMantic mapping）。一句话定位：R69 问「我该向谁求证、还能问什么」，本轮问「**这个东西到底是什么做的，我一碰会发生什么**」。

## 0. 直觉与动机

**灵感 1（MuJoCo 是一个「模型饥饿」的预言机）**
直觉：MuJoCo 的强大在于软接触模型（solref/solimp）、丰富的关节/约束和 MJX 的批量并行仿真；但它的输出完全由 MJCF 决定。给它一个「杯子」，它不知道杯子是空是满、杯壁多厚、桌面多滑；给它一扇门，它不知道门轴阻尼和门闩是否存在。**仿真精度不会自动转化为世界知识**；它只会把你喂给它的假设演得更逼真。更准确的说法：MuJoCo 是一个条件预言机 p(未来 | 当前状态, 模型 θ)，误差的主项不是数值积分，而是 θ 与模型类。

**灵感 2（语义地图是「无物理的标签地图」）**
直觉：经典语义地图把空间分成带标签的区域/实例，最多附上几何与关系。它回答「这里是不是可通行」「这是不是椅子」。但「椅子」并不能直接变成 MuJoCo 参数：椅面能承重多少、轮子是否锁死、扶手是否可抓，全是空的。**语义学到的恰恰是物理的先验结构**：材质（木/金属/织物/玻璃）强烈约束摩擦与恢复系数，类别（杯/瓶/箱/门）约束质量量级、质心范围与关节类型，可供性（可抓/可推/可坐/可装液体）约束动作可行域。于是语义的真正用途不是「贴标签」，而是**在接触发生之前把 θ 的高维先验收窄**。

**灵感 3（接触是唯一能测量物理的传感器）**
直觉：视觉测几何、测外观，几乎测不到质量、摩擦、内部质心、关节阻尼。要测物理，必须**碰**：推一下看加速度，抓一下看滑移，掂一下看力矩，压一下看接触刚度与恢复。接触观测是物理参数的似然来源。并且接触可以**主动选择**：推哪个方向、用多大力、抓哪一侧，决定了你能把 θ 的哪一维从「不可观」变成「可观」。这把「语义地图」与「主动系统辨识」合并成同一件事：**建图 = 在接触预算下对物理后验做实验设计**。

**灵感 4（二分：可约的物理歧义 vs 不可约的接触噪声）**
直觉：延续 R69 的 aleatoric/epistemic 二分，但在物理空间里重做一遍。这里的 epistemic 是**参数/模型歧义**（它是重还是被粘住？门有闩吗？），可由更多、更多样的接触消解；aleatoric 是**接触本身的随机性**（微滑移、表面颗粒、传感噪声），再碰也消不掉。分清二者决定了「该多碰一下」还是「该保守绕开」：把不可约噪声当歧义去探询是浪费，把可约歧义当噪声去保守是永久无知。

**灵感 5（双向泛化与双向风险）**
直觉：若语义先验平坦（I(L;Θ)=0），S2P 退化为均匀先验，PHYSEM 就是标准在线系统辨识；若无接触观测（探询预算为 0），后验停留于先验，PHYSEM 就是普通语义地图。两个边界都被包含，中间由「语义先验 × 接触似然」共同决定——这正是本轮要求的新层严格泛化旧层。但同一个结构也带来对称的黑暗面：**语义先验可能自信地错**（「看起来像杯子，其实被粘在桌上」），而某些自由度（密封物内部质心、表层下的材质）接触永远观不到，先验错了就**永远纠不回来**。于是系统可能得到一张内部自洽、风险认证完备、却对现实自信错误的地图——这是本轮必须正面交付防线的地方。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PHYSEM 总览）** PHYSEM = (S2P, SPM, BCF, APP, RAP, SRM, MCG†)。四不变式：
(i) **地图持有信念而非点估计**：每个实体保存物理参数后验（加权粒子集），不存单一 MJCF；
(ii) **语义只是先验、且必须重尾**：标签可被接触证据推翻，任何标签不得写成硬约束或无穷精度先验；
(iii) **接触即测量、测量即动作**：每次接触观测都进入 BCF 并可审计；主动探询与任务动作走同一安全包络；
(iv) **只在任务相关子空间更新**（惰性更新），并对模型类失配设独立门控（MCG†），不允许「类内最优」冒充「世界正确」。

**定义 311（实体的语义-物理状态）** 实体 e_i = (g_i, l_i, r_i, b_i)：几何 g_i（网格/位姿/尺度）、标签分布 l_i（含开放词汇与置信）、关系上下文 r_i（on/in/attached/contains/opening）、物理信念 b_i = {(θ_i^{(j)}, w_i^{(j)})}_{j=1..K}。地图 SPM(t) = {(e_i, b_i(t))}。

**定义 312（MuJoCo 物理参数向量）** θ_e ∈ Θ_MJ ⊂ ℝ^{d_θ}，至少含：质量 m、惯性 I、滑动/扭转/滚动摩擦 (μ_s, μ_t, μ_r)、恢复系数 e、接触软度 (solref, solimp)、关节类型与限位、阻尼/刚度、可变形参数，以及**模型类标签** κ ∈ {刚体, 铰接, 软体, 黏附, 约束耦合}。MJCF = Φ(g_e, θ_e)；注意接触模型本身（Coulomb + 软约束）也是模型类 ℳ_MJ 的一部分，而非「真实物理」。

**定义 313（语义→物理编译器 S2P）** p(θ_e | l_e, g_e, r_e) = ∫ p(θ_e | z_e, l_e) p(z_e | l_e, g_e, r_e) dz_e。结构化分解：材质→(μ, e, solref/solimp)，类别→质量/惯性范围，可供性→关节类型与运动自由度，尺寸→质量随体积的尺度律。用重尾分布（Student-t / 尺度混合）而非窄高斯，保证「例外实体」不会被先验一票否决。在资产语料上训练，并强制**覆盖校准**（经验覆盖 ≈ 名义覆盖），否则先验精度只是虚高。

**定义 314（物理粒子地图 SPM）** 每个实体存 K 个 MJCF 粒子及权重；地图查询提供 physics(e)、coverage(e)、task_relevant(e)。地图更新是粒子权重的贝叶斯更新，而非覆盖写；几何/标签更新与物理更新解耦，但通过 SRM 互相校验。

**定义 315（接触观测模型）** 对已执行动作 a_{t-1}，真实观测 y_t = h_MJ(s_t, a_{t-1}, θ_e) + δ(s_t, a_{t-1}) + n_t。其中 h_MJ 为（MJX 批量）前向仿真，δ 为**仿真-现实差异**（模型类之外的系统偏差），n_t 为传感/接触噪声。似然 p(y_t | θ_e, a_{t-1}) 由粒子回放的残差与噪声模型给出；δ 单独建模（GP/残差网络），绝不与 θ 混为一谈。

**定义 316（贝叶斯接触滤波 BCF）** 仅在接触事件触发更新：w_j ← w_j · p(y_t | θ^{(j)}, a_{t-1})，归一化后计算 ESS；ESS < K/2 时重采样，并用 S2P 先验做 rejuvenation（MCMC/核扰动）避免粒子退化。更新是**惰性**的：非接触时段只做预测，不做参数更新。

**定义 317（任务相关投影 TRP）** 对任务风险 R(s, θ) 定义敏感子空间 T_e = span{∂R/∂θ_e}（按阈值截断）。只在 T_e 上做精化与探询；T_e 之外参数保持先验，避免为一堆与任务无关的参数浪费接触预算。示例：抓握任务只关心接触点附近的质量、摩擦与质心，不关心杯子底部的转动惯量。

**定义 318（物理不确定性二分）** 对实体 e：U_phys^epi = H(θ_{e,T} | y_{1:t})（粒子在任务子空间上的熵/离散度，可约）；U_phys^ale = E_{θ}[tr Σ_noise(θ)]（给定 θ 的接触随机性，不可约）。**只有 epistemic 进入主动探询；aleatoric 进入保守规划**。这是 R69 二分在物理参数空间的对应物。

**定义 319（主动物理探询 APP）** 候选探询动作 a ∈ 𝒜_probe（推/轻敲/抓-提/压/旋转/等待稳定），g* = argmax_a [ I(θ_{e,T}; y | a, b_e) − λ_c c(a) ]，s.t. risk(a) ≤ ε_int 且预算未超。若无候选的净信息增益 > 0，则不探询、直接用当前后验做任务动作（退化为被动建图）。信息增益用粒子回放的预测熵近似，不引入额外可训练黑箱。

**定义 320（风险感知规划 RAP）** 设后验 ε-可信集 B_ε = {θ : 后验质量 ≥ 1−ε}。规划最小化 CVaR_ε（或最坏情况）任务代价：π* = argmin_π max_{θ∈B_ε} J(π; θ)。若后验多峰且不存在对**所有**峰都安全的动作，则先探询、后行动；若探询不可行，退回对最坏峰安全的保守动作（与 R69 的 λ_floor 边界一致）。

**定义 321（语义修正监控 SRM）** 用后验预测检验（PPC）做语义-物理一致性检查：semantic_surprise = D_KL(p(θ_e | y_{1:t}) ‖ p(θ_e | l_e))，或等价的预测似然比。超过阈值 τ_srm 时，标签 l_e 进入「待复核」，并按关系图传播（容器错→内容物质量先验也错；支撑面错→其上物体承重先验也错）。SRM 是**双向**的：语义修正物理先验，物理也修正语义标签。

**定义 322（模型类失配门 MCG†）** 计算模型类边缘似然 m(y|a) = ∫ p(y|θ,a) p(θ) dθ。若 m(y|a) < τ_miss（所有 θ 都解释不了这次接触），**禁止**把后验塌缩到「类内最优 θ」；应升级模型类（加入铰接/软体/黏附假设）、扩大 δ 的支撑，或退回安全。形式化：可检测的失配只存在于参数切线空间的正交补；若 δ 落在切线空间内（可被 θ 冒充），则**不可辨识、不可检测**——这是本轮公开承认的盲区。

**定义 323（MJX 粒子推断引擎）** 用 MJX 将 K 个 MJCF 粒子在 GPU 上批量前向：一次调用完成 K×H 步回放，得到全部粒子对候选动作的预测分布。推断、探询的信息增益、规划的风险评估共用这一批量后端，避免「推断一个仿真器、规划另一个」。K 随 U_phys^epi 自适应：常规 K=32，歧义/失配可疑时 K=128。

**定义 324（证书 J_PHYSEM）** J_PHYSEM = (J_RAS, posterior_coverage, ESS_min, sim2real_residual, semantic_surprise, model_class_margin, probe_budget_used, physem_ver)。Valid ⇔ 后验覆盖达标 ∧ ESS 未退化 ∧ δ 在包络内 ∧ 无未复核的 SRM 告警 ∧ 探询预算未越界。

**定义 325（双向退化边界）** (a) 语义先验平坦（I(L;Θ)=0）⇒ S2P 为无信息先验，PHYSEM 退化为标准在线系统辨识 + 风险规划；(b) 无接触观测/探询预算为 0 ⇒ BCF 无更新，b_e = 先验，PHYSEM 退化为普通语义地图 + 先验规划；(c) 无主动探询 ⇒ 退化为被动贝叶斯建图；(d) 无风险感知 ⇒ 退化为均值规划。四个边界都必须是逐指令一致的退化，而非近似。

**定义 326（关系物理先验）** 场景图 G=(V,E) 上的关系对 θ 施加结构化约束：`on` ⇒ 支撑法向力上界与承重；`contains` ⇒ 内容物质量/质心耦合；`attached` ⇒ 在阈值力以下视为不可动、超过则可能脱落；`opening` ⇒ 必有关节/自由度；`stacked` ⇒ 下层承重与稳定性。关系先验把逐实体 S2P 提升为**关系一致的物理场**，也提供 SRM 的传播路径。

```python
# IP-264 S2P：语义→物理先验（结构化、重尾、覆盖校准）
class SemanticToPhysics:
    def __init__(self, asset_corpus, material_prior, category_prior, aff_prior):
        self.material, self.category, self.aff = material_prior, category_prior, aff_prior

    def prior(self, label, geom, rel, K):
        z = self.encode(label, geom, rel)
        mu, scale, df = self.head(z)                 # 重尾参数化
        theta = sample_student_t(mu, scale, df, K)   # 例外实体不被一票否决
        theta = apply_relational_constraints(theta, rel)  # 定义 326
        return [mjcf_from(geom, t) for t in theta]

# IP-265/266 SPM + BCF：物理粒子地图与接触滤波（MJX 批量回放）
class PhysicsParticleMap:
    def predict(self, state, action, H):
        return mjx_rollout_batch(self.particles, state, action, H)  # K×H 并行

    def update(self, y, action):
        preds = self.predict(self.last_state, action, H=1)
        loglik = self.obs_model.loglik(y, preds)                   # 定义 315
        self.w = softmax(self.logw + loglik)
        if ess(self.w) < len(self.w) / 2:
            self.resample_and_rejuvenate(self.s2p.prior)          # 防退化

# IP-267/268 TRP + APP：只问任务相关的事，且只在值钱时问
def choose_probe(entity, belief, task, budget):
    T = task_relevant_subspace(task, entity)                       # 定义 317
    best = None
    for a in probe_candidates(entity):
        if not budget.allow(a) or not safety.certify_probe(a): continue
        ig = expected_info_gain(belief, a, T, backend=mjx)         # 粒子回放
        score = ig - probe_cost(a)
        if best is None or score > best.score: best = (a, score)
    return best if best and best.score > 0 else None               # 不划算→被动

# IP-269 RAP：在物理可信集上做风险感知规划
def plan(belief, task, eps):
    B = credible_set(belief, eps)                                  # 定义 320
    if multimodal_ambiguity(belief) and not shared_safe_action(B, task):
        return ("probe_first", choose_probe_until_safe(B, task))
    return robust_mpc(task, B, risk=cvar(eps))

# IP-270/272 SRM + MCG†：语义-物理互查 + 模型类失配门
def audit_and_gate(belief, y, label_prior, action):
    surprise = kl(belief.posterior, label_prior)
    margin   = model_class_marginal_likelihood(belief, y, action)  # 定义 322
    flag_semantic = surprise > TAU_SRM
    flag_class    = margin < TAU_MISS
    if flag_class:
        return ("escalate_class_or_safe", None)                    # 不许类内塌缩
    return ("ok", flag_semantic)

# IP-274 主闭环：建图即实验设计，接触即测量
def PHYSEM_round(M, obs):
    M.spm.track(obs)                                   # 几何/标签/关系
    for e in M.spm.contacted_entities(obs):
        M.spm[e].update(obs.contact, M.last_action)    # BCF
        status, flag = M.audit_and_gate(M.spm[e], obs.contact, e.label_prior,
                                        M.last_action)
        if status.startswith("escalate"):
            return M.safe_fallback()                   # MCG† 触发
        if flag: M.srm.revise_label(e)                 # 语义被物理反证
    # 为下一步任务选择：先探询还是直接执行
    e_star = M.spm.most_task_relevant_uncertain()
    if M.budget.allow_probe() and M.spm[e_star].U_epi > TAU_EPI:
        a_probe = choose_probe(e_star, M.spm[e_star], M.task, M.budget)
        if a_probe is not None:
            return ("probe", a_probe)                  # 接触换信息
    return ("act", plan(M.spm.belief_over_task_entities(), M.task, M.eps))
```

## 3. 推导

**引理 19（语义先验降低接触辨识的样本复杂度）** 在局部高斯近似下，先验 p(θ|l) = N(μ_l, Λ_l^{-1})，一次探询动作 a 的 Fisher 信息为 F(a)。k 次探询后后验精度 Λ_k = Λ_l + Σ_{i=1}^k F(a_i)。达到目标后验迹 tr(Λ_k^{-1}) ≤ ε 所需探询数满足 k_sem = min{k : tr((Λ_l + Σ F)^-1) ≤ ε} ≤ k_flat（平坦先验需正则 Λ_0 = ε₀I 才能定义）。要点：语义把有效假设空间从「全 ℝ^{d_θ}」压到「类别/材质可行域」，等价于给了一组**有限先验精度**；接触只需补足先验没覆盖的方向，而不是从零辨识全部参数。系：I(L;Θ) 越大，探询越省；语义无用（I=0）时退化为标准 sysID 的样本复杂度。

**引理 20（单次接触的秩亏与语义补全）** 令 J = ∂h/∂θ，F(a) = JᵀR^{-1}J。任何单次接触的输出维数远小于 d_θ，故 rank F(a) < d_θ，存在非平凡零空间 N(a)。后验协方差在 N(a) 上等于先验协方差在该子空间上的限制：Σ_post|_{N(a)} = Σ_prior|_{N(a)}。故：(i) 语义先验给 N(a) 一个有限方差，避免「不可观方向方差爆炸」；(ii) 平坦先验下这些方向**永远不可辨识**；(iii) 更关键的是，若先验均值在 N(a) 上错误，**接触在该方向不提供任何纠正信息**，误差会保留。系：必须用**零空间不断变化的多样探询**（推、抓、压、转）来缩小 ∩_i N(a_i)，但仍有物理上不可观的维度（密封内部质心、表层下材质）只能靠先验，这是本轮风险的数学根源。

**引理 21（双向泛化的互信息刻画）** 语义通道的价值 ≈ I(L;Θ)，接触通道的价值 ≈ I(Θ;Y|A)，两者联合的额外收益 ≈ 交互信息 I(L;Y|Θ) 的不可替代部分。若 I(L;Θ)=0，则 S2P 无信息，PHYSEM ≡ 在线 sysID；若探询预算为 0，则后验 ≡ 先验，PHYSEM ≡ 语义地图。因此 PHYSEM 不是「语义地图 + sysID 的拼接」，而是以语义为先验、接触为似然的同一后验的两个边界。系：两通道正交互信息时，联合后验的熵严格小于任一单通道（在相同数据预算下）。

**引理 22（模型类失配的可检测性与盲区）** 设真实动力学 p* 可能不在 ℳ_MJ 内，最优投影 θ* = argmin_θ KL(p* ‖ p_θ)。若 δ = p* − p_{θ*} 在参数切线空间 T_θ = span{∂h/∂θ} 上的投影非零，则随接触数据增多，模型类边缘似然比检验能以趋于 1 的功效检出失配；若 δ 落在 T_θ 内（可被某个 θ 冒充），则失配**不可辨识**，后验会收敛到一个自洽但错误的 θ*。系：MCG† 只能挡住「切向之外」的错误；对「切向内」的冒充，唯一防线是**跨模型类比较**（显式加入铰接/软体/黏附假设并比较证据）与真实世界的持续残差监控。

**定理 18（PHYSEM 双向严格泛化）** 在 A99（S2P 先验校准，经验覆盖 ≥ 名义覆盖）、A100（真实动力学落在 ℳ_MJ 内或 δ 可被 MCG† 检出）、A101（规划在 ε-可信集上取 CVaR）下：PHYSEM 的期望任务风险 ≤ 语义地图单独使用（无接触更新）与在线 sysID（平坦先验）两者的较小者；且当 I(L;Θ)=0 或探询预算为 0 时，分别**逐指令**退化为后两者。安全侧不弱于 R69：探询动作经认证，无安全动作时退回最坏峰保守策略。

**定理 19（语义-物理一致性修正的相合性）** 若标签真实分布与物理参数存在非零互信息 I(L;Θ)>0，且接触噪声有界，则随着该实体接触观测数 t→∞，SRM 的语义惊讶度在标签错误时以概率 1 超过 τ_srm、在标签正确时收敛到 0。阈值 τ_srm 控制误报率（后验预测 p 值）。系：**地图不仅会学物理，还会用物理学来纠正语义**——这是把「语义建图」从静态标注升级为可证伪信念的关键。

**定理 20（探询安全与信息不伤害的边界）** (i) 若所有探询动作通过力/位/工作空间/时间窗认证，则探询引起的约束违反 ≤ ε_int，且不改变任务安全包络；(ii) 在**后验校准且模型类正确**的前提下，先探询后行动对期望任务风险单调不增（信息不伤害）；(iii) 一旦模型类失配或先验错误，信息可能有害——因此 MCG† 与 SRM 必须先于「信息不伤害」使用，否则会得到「越问越自信地错」。

**一句话**：PHYSEM 把「地图是否正确」押在两个本身只是假设的东西上——**语义先验可能自信地错，而 MuJoCo 的接触模型类可能根本装不下真实物理**；一旦错误方向恰好落在接触不可观测、或可被参数冒充的切向空间里，粒子后验会收敛到一个内部完全自洽、风险认证完备、却对现实自信错误的世界。**最危险的不是地图说「我不知道」，而是它用一套错误的物理把「不知道」伪装成「知道」，然后据此认证了一个不安全动作。**

**定义 320（RAP）** 在 `B_ε` 上最小化 CVaR_ε；后验多峰且无共安全动作 → 先探询；探询不可行 → 最坏峰保守动作（接 R69 λ_floor 边界）。

```python
class SemanticToPhysics:
    def prior(self, label, geom, rel, K):
        z = self.encode(label, geom, rel)
        mu, scale, df = self.head(z)                    # 重尾参数化
        theta = sample_student_t(mu, scale, df, K)      # 例外实体不被一票否决

    def update(self, y, action):

        loglik = self.obs_model.loglik(y, preds)                    # y=h+δ+n

        if best is None or score > best.score: best = (a, score)

        M.spm[e].update(obs.contact, M.last_action)                 # BCF
        status, flag = M.audit_and_gate(M.spm[e], obs.contact,
                                        e.label_prior, M.last_action)
        if status.startswith("escalate"):
            return M.safe_fallback()                                # MCG† 触发
        if flag: M.srm.revise_label(e)                              # 语义被物理反证
    e_star = M.spm.most_task_relevant_uncertain()                   # 只问任务相关的
    if M.budget.allow_probe() and M.spm[e_star].U_epi > TAU_EPI:
        a_probe = choose_probe(e_star, M.spm[e_star], M.task, M.budget)
        if a_probe is not None:
            return ("probe", a_probe)                               # 接触换信息
    return ("act", plan(M.spm.belief_over_task_entities(), M.task, M.eps))
```

## 4. 推导

**引理 19（语义先验降低样本复杂度）** 高斯局部近似下先验精度 `Λ_l`，k 次探询后 `Λ_k=Λ_l+ΣF(a_i)`；达 `tr(Λ_k^{-1})≤ε` 所需探询数 `k_sem ≤ k_flat`（平坦先验需正则 `Λ_0=ε₀I`）。语义把有效假设空间压到类别/材质可行域，接触只补先验未覆盖的方向。系：`I(L;Θ)=0` 时退化为标准 sysID 的样本复杂度。

**引理 20（秩亏与零空间盲区）** `F(a)=JᵀR^{-1}J`，单次接触 `rank F(a)<d_θ`；`Σ_post|_{N(a)}=Σ_prior|_{N(a)}`。故先验给出不可观方向的有限方差，但**若先验均值在这些方向错误，接触不提供任何纠正信息**。系：需用零空间不断变化的多样探询缩小 `∩N(a_i)`；密封内部质心、表层下材质仍不可观，是风险根源。

**引理 21（双向泛化的互信息刻画）** 语义价值 ≈ `I(L;Θ)`，接触价值 ≈ `I(Θ;Y|A)`；`I(L;Θ)=0` ⇒ PHYSEM ≡ 在线 sysID；探询预算 0 ⇒ PHYSEM ≡ 语义地图。二者是同一后验的两个边界，而非拼接。

**引理 22（失配可检测性与切向盲区）** 若差异 `δ=p*−p_{θ*}` 在参数切线空间 `T_θ=span{∂h/∂θ}` 的投影非零，则模型类边缘似然检验功效 →1；若 `δ∈T_θ`（可被某 θ 冒充），失配不可辨识，后验收敛到自洽但错误的 θ*。系：MCG† 只挡切向之外；切向内只能靠跨模型类比较与真实残差监控。

**定理 18（双向严格泛化）** A99（S2P 覆盖校准）、A100（真动力学在 ℳ_MJ 内或 δ 可检出）、A101（B_ε 上 CVaR）下，PHYSEM 期望任务风险 ≤ min(纯语义地图, 在线 sysID)；`I(L;Θ)=0` 或无接触时分别逐指令退化。安全侧不弱于 R69。

**定理 19（语义-物理修正相合性）** 若 `I(L;Θ)>0` 且噪声有界，则 `t→∞` 时 SRM 语义惊讶度在错标时以概率 1 超阈、正确时收敛 0；阈值控制误报。系：地图会用物理学**纠正语义**，把静态标注升级为可证伪信念。

**定理 20（探询安全与「信息不伤害」边界）** (i) 认证探询的约束违反 ≤ `ε_int` 且不改安全包络；(ii) **后验校准且模型类正确**时先探询后行动期望风险单调不增；(iii) 模型类失配或先验错误时信息可能有害——故 MCG†/SRM 必须先于「信息不伤害」使用。

## 7. 本轮最大风险

**一句话**：PHYSEM 把地图正确性押在两个本身只是假设的东西上——**语义先验可能自信地错，MuJoCo 的接触模型类也可能装不下真实物理**；一旦错误方向落在接触不可观测、或可被参数冒充的切向空间里，粒子后验会收敛到一个内部自洽、风险认证完备、却对现实自信错误的世界——**最危险的不是地图说「我不知道」，而是它用错误的物理把「不知道」伪装成「知道」，并据此认证了一个不安全动作。**

**次级风险与缓解**：
1. **仿真-现实差异被参数吸收** → DISC 显式建模 δ + 参数-差异可辨识性检查 + 真实残差持续监控；
2. **模型类切向盲区**（δ 在 span{∂h/∂θ} 内）→ 跨模型类证据比较（刚体/铰接/软体/黏附并列）+ E307 单报「自信错误」率，不掩盖；
3. **语义先验自信错误** → 重尾 S2P + 覆盖校准 + SRM 反证 + E315 语义投毒；
4. **接触探询损坏物体/越界** → 认证探询 + 力/位/时间窗约束 + 信息不伤害仅在 MCG† 通过后启用；
5. **粒子退化与实时预算** → ESS 门控 + S2P rejuvenation + 自适应 K + 惰性更新（仅任务相关子空间）。
