# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 1 轮；本轮灵感：「运动控制」×「四足机器人」）

> R72 把 GAUGE 从「认知层算法」下沉到「具身计量审计」：ROS 2 实时执行图（REG）、意图隐变量（IRL）、灵巧手接触计量（DMEM）、三层反作用预算（EREFLEX）、sim2real 桥接（S2R-UQ），并确立了「调度可信、意图可辨、接触可计量」才启用的严格退化链。但 R72 仍默认了一个**固定基座、可以停下来想清楚再动的操作者**：
> - **固定基座假设**：R72 的机械臂可以「先停后想」。碰撞风险来自末端，基座是安全锚点。四足机器人**没有固定基座**：它必须持续维持浮动基座的平衡与可捕获性，**停下来本身也可能是危险的**（单腿支撑、斜坡、外力扰动）。
> - **被动观测假设**：R72 的测量链假设「观测是被动到达的」。但四足的物理状态估计——浮动基座位姿/速度、地形高度/摩擦/刚度、接触状态——**只有在运动中才可观测**：站立不动时腿式里程计无激励、基座速度/航向不可观；地形摩擦只有踩上去才知道。**测量不是被动接收，而是主动激发。**
> - **平稳噪声假设**：R72 的接触模式 c 是连续 HMM（free/sticking/sliding/rolling/breaking）。四足的接触是**混合/事件系统**：touchdown/liftoff 是离散跳变，冲击（impact）带来力尖峰、传感器饱和、接触模型瞬时失效。接触**既是信息事件**（揭露地形刚度/摩擦/高度），**又是风险事件**（峰值力、滑移、跌倒、部件损伤）。
> - **静态世界假设**：R72 的 s 是单点状态。四足面对的是**空间相关的地形场**（冰/沙/草/斜坡/碎石），每一步都是一个测量样本，样本间有强空间相关性；地形不确定度应是**足迹索引 + 空间高斯过程**，而非独立同分布噪声。
>
> 本轮两个灵感正好补两块：
> - **运动控制**：把控制从「追踪参考轨迹」升级为「**激发-安全联合设计**」。MPC/WBC 的决策变量不只是速度/步长/阻抗/落脚点，还包括**激发动作**（刻意的小幅偏航摆动、试探步、重心转移、局部踏步）；控制目标从 `min risk` 变成 `min risk s.t. observability ≥ O_min`——**在能估计世界的前提下尽可能安全**。
> - **四足机器人**：把接触调度（swing/stance/touchdown/liftoff）显式建模为**测量调度（Measurement Schedule）**；把浮动基座可达性/可捕获性（viability kernel）作为硬安全约束；把腿式里程计漂移、足端滑移、地形场估计纳入计量链。
>
> 核心命题：**R72 问「我的测量链可信吗」；R73 问「我的测量链只有通过我选择的运动才变得可信——而那个运动本身就是最大风险，我如何在『必须动才能知道』与『动可能致命』之间给出可证明的证书？」** 即 **LOCO-GAUGE-RAS**（Legged, Observability-excited, Contact-scheduled, Viability-kernel-constrained GAUGE for RAS）——**运动激发计量闭环**。

## 0. 直觉与动机

**灵感 1（运动控制 → 观测不是免费的，观测要靠运动去买）**
直觉：在固定基座机械臂上，「测量」和「运动」可以解耦：先看清再动手。四足不是。基座速度主要靠腿式里程计 + IMU 融合，而**腿式里程计在你不动时没有信息**；航向角在匀速直行时弱可观；地形摩擦与刚度**只有足端真正加载后才可辨识**。所以「先看清楚再走」在腿式机器人上是一个**伪命题**：你必须先走，才知道地在哪、能不能走。这是控制理论里「对偶控制（dual control）」与「持续激励（persistent excitation）」的具身版本：**控制信号既是执行也是探测**。**运动控制的第一性难题不是「怎么到达」，而是「怎么在到达的过程中顺便把世界测出来，且不把自己测死」。**

**灵感 2（四足机器人 → 接触调度就是测量调度）**
直觉：四足的步态（trot/pace/bound/crawl）本质上规定了「哪个足在什么时候是可靠的力/地形传感器」。支撑相的足端可测地形反力与高度；摆动相的足端只能测空气。**「哪只脚可靠」不是传感器的属性，是步态相位的函数**。更深一层：接触是**混合系统**——touchdown 瞬间有冲击、liftoff 时接触模型突变、stance 中可能从 sticking 滑到 sliding。R72 把接触模式当作慢变隐变量；四足必须把**离散事件（touchdown/liftoff/impact）**作为一等公民：事件既触发状态估计重置，又触发风险预算重算。

**灵感 3（浮动基座 → 可捕获性是硬安全包络，不是软惩罚）**
直觉：机械臂避障失败=撞一下；四足失稳失败=整机跌倒、可能压伤人。四足有**可捕获性（capturability）**与**生存核（viability kernel）**：在当前支撑多边形、当前质心速度、当前足端可达集下，存在一组控制使系统未来不摔倒的状态集合。**这是非补偿性约束**：任何「测量收益」都不能买通「越出生存核」。这与 R71 建立的非补偿性安全否决一脉相承：**收益不能补偿安全，只能换安全。**

**灵感 4（运动激发计量 → 必须动才能知道，但动就是风险：双侧约束）**
直觉：安全侧希望你「慢、稳、宽支撑」；计量侧要求你「动、激励、试探」。这两者方向相反。R72 只有单侧 `λ_floor`（不确定度越高越软化）。四足引入**第二侧 `λ_excite`**：可观测性越低越必须激发。可行的步态集合必须同时满足
`observability(gait) ≥ O_min` 与 `viability_margin(gait) ≥ V_min`。
**两者交集为空时，正确的行为不是「更保守」也不是「更激进」，而是「改变问题」**——换步态（从 trot 降为 statically-stable crawl）、主动求援、或退回已知安全区。这是 R72 单侧风险缩放表达不了的新结构。

**灵感 5（地形场 → 不确定性是空间相关且足迹索引的）**
直觉：踩到一块冰，只说明「这块冰」滑，不说明「前方三米」滑，也不说明「这里永远是冰」。地形不确定度是**空间 GP**：观测点是足迹落点，核函数编码地形连续性；不确定性沿「未走过区域」增长，沿「已走过区域」收缩。**更阴险的是：地形可能被观测动作本身破坏**（踩塌雪壳、踩碎薄冰、扰动沙面），即「观测改变被观测对象」——R72 的 L3 接触反作用在四足上扩展成**地形反作用**：你的落脚点改变了地面，也改变了下一步的可观测性与可通行性。

**灵感 6（主动地图 → 落脚点选择 = 主动测量的实验设计）**
直觉：四足每一步的落脚点不仅是「保持平衡」的执行决策，还是「在哪采样地形」的实验设计决策。于是 foothold selection 变成 **measurement-aware experimental design**：在「安全落脚」与「信息最大落脚」之间做 VoI 权衡。这与 R72 的 ERVOI 同构，但动作空间从「问人」扩展到「迈脚」。

## 1. 形式化定义（增量：定义 366–390）

**定义 366（LOCO-GAUGE-RAS 总览）** LOCO-GAUGE-RAS = (CSMS, EOC, HEMM, TGP, MEVOI, VKC, LOCO-GAUGE†)。六不变式：
(i) **测量调度优先**：接触调度 σ_t 决定此刻哪些观测通道有效；失效通道不得进入状态估计或风险分母；
(ii) **激发-可观测完整性**：每个需要估计的状态必须携带经验可观测性证书 (O, σ 窗口, 激励动作 u_exc, 有效域 D_obs)，`O < O_min` 即判该状态「当前不可估」，禁止假装修正；
(iii) **可捕获性硬约束**：任何动作（含激发动作）必须留在生存核 𝒦_viab 内；越界即安全否决，收益不可补偿；
(iv) **事件计量完整性**：每次 touchdown/liftoff/impact 必须产出 (事件类型, 时间戳, 冲击能量, 接触模式后验, 地形样本, 不确定度)，缺一不可用于地形更新；
(v) **地形场空间一致**：地形估计必须携带 (GP 均值, 方差, 足迹索引, 核超参不确定度, 追溯链)；单足迹样本不得外推为全局地形；
(vi) **严格退化链**：激发证书失效 ⇒ 降为保守步态（爬行/静止稳定）；地形场失效 ⇒ 降为「仅本体安全反射」；可捕获性失效 ⇒ 立即进入 R68 式硬安全（急停/屈膝/撑地）。**新层只在「测量可激发、地形可场化、生存核可验证」时启用。**

**定义 367（接触调度即测量调度 CSMS）** 设相位 σ_t ∈ {swing_i, stance_i, touchdown_i, liftoff_i}_{i=1..4}。测量有效性映射
`valid: (channel, σ) → {0,1} × D_channel`。
例：足端力/力矩仅在 stance_i 有效；地形高度样本仅在 touchdown_i 产生；腿式里程计约束仅在 stance_i 且检测为 no-slip 时有效；IMU 全程有效但姿态可观性依赖是否有足够角激励。**给定步态 g 的测量调度是 σ_{t:t+H} 的确定序列**，它决定观测矩阵随时间的切换。**步态不仅是运动模式，更是一张「传感器开窗时间表」。**

**定义 368（浮动基座估计链与条件可观测性）** 待估状态 x = (p_base, v_base, R_base, b_gyro, b_acc, θ_terrain, f_contact, c)。测量链
`y_t = h_σt(x_t) + n_σt`，其中 h 依赖相位。局部经验可观测性矩阵（empirical observability Gramian）
`O_H(σ, u_exc) = Σ_{k=0}^{H-1} Φ_k^T H_{σ_k}^T W^{-1} H_{σ_k} Φ_k`，
Φ_k 为状态转移。**关键：O_H 显式依赖激励输入 u_exc 与相位序列 σ**——同一状态在不同步态/不同激励下可观测性天差地别。**可观测性不是系统属性，是「系统 × 我选择的运动」的属性。**

**定义 369（激发-可观测性证书 EOC）** EOC(x_state) = (O, O_min, λ_min(O), u_exc*, D_obs, τ_obs, h_obs)：
- `O`：定义 368 的 Gramian 最小特征值或条件数倒数；
- `λ_min(O) ≥ λ_min^req`：关心的方向可辨识；
- `u_exc*`：达到 O_min 的最小激发动作（能量/风险最小化）；
- `D_obs`：该结论成立的相位/地形/速度有效域；
- `h_obs`：可观测性计算所用模型哈希。
**判定规则**：`O < O_min ⇒ 状态「不可观测」，必须以先验 + 保守包络替代，禁止把「没测到」当成「测到了且为零」。**

**定义 370（地形场 GP：TGP）** 地形属性场 `θ(x) ~ GP(m(x), k(x,x'))`，θ 可为 (高度, 摩擦系数, 刚度, 可通行性)。观测来自足迹：`y_i = θ(p_i) + n_i(c_i)`，噪声 n_i 依赖接触模式 c_i（贴合低噪、滑移重尾、冲击饱和）。后验
`p(θ | 足迹集) = GP(μ_post, Σ_post)`。
**足迹索引**：每个观测关联落点 p_i、时间、相位、接触质量 q_i（由 DMEM 四分量改写）。**空间相关性意味着「踩到冰」只局部更新；但「冰的连通性先验」可被核函数编码（如沿等高线的长程相关）。** 核超参本身带不确定度，需分层贝叶斯。

**定义 371（混合事件计量 HEMM）** 接触事件 e ∈ {touchdown, impact, slip_onset, liftoff} 是离散状态转移。事件模型
`p(e_t | σ_t, x_t, u_t^ctrl)`，事件观测 `y_e = (t_impact, F_peak, Δv_foot, 声/振动特征)`。
**双重性**：事件的后验既是信息增益源（冲击能量 → 地形刚度/摩擦估计），又是风险源（F_peak 超限 → 结构/物体损伤；slip_onset → 失稳前兆）。定义**事件信息-风险比**
`EIR(e) = IG_terrain(e) / Risk_event(e)`，
控制只在 `EIR(e) ≥ EIR_min` 或**被迫接触**（无法避免）时才主动制造事件。

**定义 372（运动激发 VoI：ME-VoI）** 对激发动作 u_exc（小幅偏航摆动、试探步、重心转移、局部踏步），
`VoI^M(u_exc) = Σ_j w_j · [H_j(before) − E[H_j(after)]] − β·Risk(u_exc) − γ·Energy(u_exc) − δ·D_KL(b_t(gait) ‖ b_{t+1}(gait))`，
其中 j 遍历待估分量（基座速度、航向、地形摩擦、接触状态），w_j 由下游任务敏感度决定。**当 `VoI^M ≤ 0` 时不得为「好奇」而激发；但若下游存在 `O < O_min` 的硬需求，则 VoI 计算改为约束满足：找到最小 Risk 的 u_exc 使 O ≥ O_min。** 这区分了「可选探索」与「必要激发」。

**定义 373（生存核与可捕获性）** 生存核 𝒦_viab ⊆ 𝒮_base 为满足「存在控制序列使未来 H 步内不摔倒、关节/力矩/接触力在物理限内」的浮动基座状态集（位置、速度、姿态、支撑相位）。**可捕获性余量**
`V(x) = dist(x, ∂𝒦_viab)`。
**硬约束**：所有动作（含测量激发、地形试探步）必须满足 `V(x_{t+1}) ≥ V_min`。**这是非补偿性约束：`VoI^M` 再大也不能买通 `V < V_min`。** 支撑多边形缩小（抬腿）会即时收缩 𝒦_viab，因此「抬脚探测」天然比「原地重心转移」更危险。

**定义 374（双侧风险-激发约束与可行步态集）** 控制律在 WBC/MPC 上追加两层调制：
- 单侧安全缩放（继承 R72）：`λ_safe = max(risk_scale(U_ale,U_epi,H_z,u_tac), λ_floor(...))`；
- 单侧激发缩放：`λ_exc = max(0, 1 − O/O_min)`，O 越低 λ_exc 越大，强制提高激励幅度/降低对弱观测的依赖。
**可行动作集**
`𝒜_feas = { u : V(x_{t+1}) ≥ V_min, O_{t:t+H}(u) ≥ O_min^{req}(task), τ ≤ τ_max, F_c ≤ F_max }`。
**若 𝒜_feas = ∅：触发「换问题」协议**（降速/换步态到 statically-stable crawl/退到已知安全区/请求人类），而非在空集上强行优化。

**定义 375（步态级反作用预算 GREFLEX）** 在 R72 三层（ψ, z, c）之上新增**L4 步态反作用**：步态切换 g→g' 改变测量调度与生存核，成本
`c_reflex^g = |O(g') − O(g)| 的信息损失 + D_KL(b_t(contact) ‖ b_{t+1}(contact)) + λ_g·𝟙[V(g') < V_min]`。
**四层合算预算** `Σ_t (c^ψ + c^z + c^c + c^g) ≤ B_reflex_total`。**频繁换步态本身就是一种反作用成本**（每次切换都有冲击、打滑、能耗与测量中断）。

**定义 376（腿式里程计滑移与漂移计量）** 足端速度残差 `r_slip = ‖v_foot^kin − v_foot^support‖`；滑移判定用 SPRT/HMM，输出 `P(slip)`、检出延迟 `τ_slip`。**有效里程计测量仅在 `P(slip) < p_slip_max` 且 `τ_slip` 内未触发时可用**；否则该支撑相被标记为「里程计失效」，基座位移不确定度按运动学 + 惯性外推膨胀。**漂移不是慢变误差，而是「支撑相可靠性」的函数。**

**定义 377（运动激发指标族 L-MIB）** 在 R72 E-MIB 上新增加族：
- **可观测族**：`λ_min(O)`（最弱可观测方向）、条件数、O 的时间积分、`D_obs` 覆盖率；
- **接触事件族**：冲击峰值分布、touchdown 时序抖动、`P(slip)` 校准误差、事件检出延迟；
- **地形场族**：GP 后验方差（分区域）、核超参不确定度、单足迹外推比例、被观测动作破坏的地形比例；
- **生存族**：`V(x)` 最小时序、支撑多边形裕度、可捕获性预测误差、恢复成功率；
- **步态族**：换步态频次、换步态信息损失、换步态能耗、测量中断时长。
所有指标同遵循定义 332 六元组 (φ,m,u,D,τ,I⊥) 与 333 DAG 分层。

**定义 378（运动激发 IVG：L-IVG）** 在 R72 E-IVG 上新增失效条件：
- 可观测：`λ_min(O) < O_min`、`D_obs` 外推（当前状态落在证书有效域外）、O 计算模型哈希不匹配；
- 事件：冲击峰值 > F_max、touchdown 抖动 > τ_td、`P(slip)` 校准误差 > τ_slip_cal；
- 地形：GP 方差 > τ_TGP、单足迹外推 > τ_extrap、地形破坏率 > τ_destruct；
- 生存：`V < V_min`、可捕获性预测误差 > τ_viab_err。
**任一成立 ⇒ 相关模块降级：可观测失效 ⇒ 保守步态/静止稳定；地形失效 ⇒ 仅本体反射；生存失效 ⇒ R68 硬安全。**

**定义 379（LOCO 风险缩放 L-RISK）** 在 WBC 的任务空间力/速度上调制：
`λ = max( risk_scale(U_ale, U_epi, H_z, u_tac) , λ_floor(U_ale+U_epi+H_z+u_tac) , λ_viab(1/V(x)) , λ_exc(1 − O/O_min) )`。
其中 `λ_viab` 在接近生存核边界时指数增大，`λ_exc` 在可观测性不足时增大。**注意二者方向相反**：`λ_viab` 让你慢下来，`λ_exc` 要求你动起来；最终由定义 374 的可行集仲裁。**这是四足区别于机械臂的核心：安全与认知第一次在控制层面显式对抗。**

**定义 380（LOCO 证书 J_LOCO）** `J_LOCO = (J_EMB, csms_hash, eoc_vec, tgp_posterior_hash, event_log_hash, viability_proof, gait_budget_hash, loco_ver)`。
`Valid ⇔ Valid(J_EMB) ∧ CSMS 哈希匹配 ∧ 所有被估计状态的 EOC 有效 ∧ TGP 后验在有效域 ∧ 事件日志完整 ∧ 生存核证明有效 ∧ GREFLEX 预算未超`。

**定义 381（威胁模型 AIC-LOCO）** `ℰ_LOCO = ℰ_EMB × ℰ_terrain × ℰ_event × ℰ_state_est`：
- ℰ_terrain：欺骗性地形（雪覆盖薄冰、可塌陷表面、伪装斜坡）、摩擦场对抗梯度；
- ℰ_event：伪造 touchdown（振动/声学注入）、冲击掩盖、接触事件重放；
- ℰ_state_est：IMU 欺骗/漂移、腿式里程计滑移诱导（推/拉足端）、可观测性证书的模型投毒（给错动力学模型使其高估 O）；
- ℰ_gait：步态调度攻击（诱导频繁切换消耗预算/中断测量）、支撑相缩短攻击。

**定义 382（严格退化链）** LOCO 在退化条件下逐层等价：
- 全失效 ⇒ R68（急停/屈膝/撑地，本体安全反射）；
- 可观测失效 + 其余有效 ⇒ 保守步态（crawl/静止稳定）+ R72；
- 地形场失效 + 其余有效 ⇒ 仅本体反射 + 局部接触计量 + R72；
- 事件计量失效 ⇒ 关闭冲击学习，退化为保守接触力上限 + R72；
- 全有效 ⇒ LOCO-GAUGE-RAS 完整形态。
**安全侧只增不减：任何退化都保留 R68 硬安全包络与 𝒦_viab 约束。**

**定义 383（激发感知 MPC）** 在标准质心/全身 MPC 上增加**可观测性约束项**：
`min_{u_{0:H-1}} Σ (ℓ_task + ρ·Risk + β·Energy) s.t. dynamics, V ≥ V_min, O_{0:H}(σ,u) ≥ O_min, F_c ≤ F_max`。
可观测性约束以 Gramian 的线性化近似 `−log det(O_H) ≤ c` 或最小特征值约束实现；用对偶变量把可观测性「价格化」到控制代价中。**当可行集为空时，MPC 触发步态/任务切换（定义 374）。**

**定义 384（测量感知落脚点选择）** 候选落脚点 p 的评分
`S(p) = w_info·E[IG_TGP(p) | p] − w_risk·Risk_foot(p) − w_energy·Cost(p) − w_viab·(V_min − V(p))^+`，
`IG_TGP(p)` 由 GP 后验方差的预期下降估计；**在 `V(p) ≥ V_min` 硬约束下最大化 `S(p)`。** 落脚点即实验设计点：**四足用脚在做主动学习。**

**定义 385（运行时可观测性监控器 ROM）** 最高优先级、静态内存节点，每控制周期重算当前相位下的简化 Gramian 与 `V(x)`；超阈即冻结对应状态通道、记录证据、降级。**ROM 与 R72 的 RTM 并列，是「认知安全」的最后防线；其自身模型哈希被证书锁定。**

**定义 386（地形反作用）** 观测动作改变地形：`θ_{t+1} = G(θ_t, p_t, F_t)`（踩塌/碎裂/扰动）。**地形反作用预算** `c^θ = D_KL(p(θ|x_{t+1}) ‖ p(θ|x_t))` 计入 GREFLEX；**若地形破坏不可逆，则「观测即永久损失」——必须把不可逆性作为额外风险项。**

**定义 387（空间测量地图 SMM）** `M_meas: 空间位置 → (GP 后验, 足迹历史, 破坏标记, 最后有效时间)`。规划器用它区分「未探索」「已探索可信」「已探索不可信」「已知被破坏」四类区域；**未探索区域的先验必须是保守包络，不得用 GP 均值冒充真实地形。**

**定义 388（腿部冲击能量约束）** touchdown 冲击能量 `E_imp = ½ m_eff Δv²`；约束 `E_imp ≤ E_max` 且 `F_peak ≤ F_max`。**冲击是测量的代价：更大的落差/更快的落脚给更多地形信息，也带来更大损伤与失稳风险。** ME-VoI 中的 `Risk_event` 由此展开。

**定义 389（跨相位不确定性传播）** 状态估计不确定度随相位切换传播：`Σ_{t+1} = A_σ Σ_t A_σ^T + Q_σ + (滑移/冲击注入)`。**摆动相不确定性增长，支撑相（no-slip）收缩；一次滑移会同时抬高基座与地形的不确定度，并可能压低可观测性。** 证书必须验证最坏相位序列下的不确定度上界。

**定义 390（LOCO 主闭环契约）** 每个控制周期必须产出 `(u_ctrl, u_exc, σ, λ, V(x), O, J_LOCO 片段)`；测量域异步产出 `(TGP 后验, 事件日志, EOC, slip 后验)`；**控制域只读测量域快照，绝不等待（继承 R72 三域分离）**。

# IP-295 CSMS：接触调度即测量调度（部署期由步态库生成）
class ContactSchedule:
    def __init__(self, gait, T):
        self.gait, self.T = gait, T          # trot/pace/bound/crawl + 周期
    def phase(self, t): ...                   # -> sigma_t (swing/stance/touchdown/liftoff)
    def valid_channels(self, sigma):
        # 足端F/T仅在stance；地形样本仅在touchdown；里程计仅stance且no-slip
        return {ch: (sigma in dom_ch) for ch, dom_ch in CHANNEL_PHASE_DOMAIN.items()}

# IP-296 EOC：激发-可观测性证书（计量域，软实时）
class ObservabilityCertifier:
    def __init__(self, model, o_min, lam_min_req):
        self.model, self.o_min, self.lam_req = model, o_min, lam_min_req
    def cert(self, sigma_seq, u_exc, x_prior):
        H = self.model.linearized_obs(sigma_seq, x_prior)
        Phi = self.model.transition(sigma_seq, u_exc)
        O = sum(Phi[k].T @ H[k].T @ W_inv @ H[k] @ Phi[k]
                for k in range(len(sigma_seq)))
        lam_min = min_eig(O)
        return EOC(O=O, lam_min=lam_min,
                   ok=(lam_min >= self.lam_req),
                   u_exc_star=argmin_excitation(sigma_seq, self.o_min),
                   h_obs=hash_model(self.model))

# IP-297 HEMM：混合接触事件计量（感知域异步 -> 计量域消费）
class HybridEventMetrology:
    def __init__(self, event_hmm, terramodel):
        self.hmm, self.tgp = event_hmm, terramodel
    def on_event(self, e_raw, sigma, x, u_ctrl):
        e = self.hmm.classify(e_raw)              # touchdown/impact/slip/liftoff
        F_peak, dv, t_imp = e_raw.peak, e_raw.dv, e_raw.t
        E_imp = 0.5 * e_raw.m_eff * dv**2
        # 双重性：信息 + 风险
        ig    = self.tgp.expected_info_gain(e.footprint, E_imp, e.c_mode)
        risk  = risk_event(F_peak, E_imp, self.tgp.fragility(e.footprint))
        eir   = ig / (risk + EPS)
        # 地形样本（带接触质量与破坏标记）
        sample = TerrainSample(p=e.footprint, y=e.terrain_obs,
                               q=contact_quality(e.c_mode),
                               destroyed=self.tgp.destruction(e))
        return EventEvidence(e=e, F_peak=F_peak, E_imp=E_imp, ig=ig,
                             risk=risk, eir=eir, sample=sample)

# IP-298 TGP：空间地形场（足迹索引 GP）
class TerrainGP:
    def __init__(self, kernel, hyper_prior):
        self.k, self.hp = kernel, hyper_prior
        self.post = None
    def observe(self, sample):
        if sample.q < Q_MIN: return self.post       # 低质量足迹不更新均值
        self.post = gp_update(self.post, sample.p, sample.y,
                              noise=noise_from_quality(sample.q))
        return self.post
    def info_gain(self, p):
        return 0.5 * (logdet(self.post.cov) - logdet(posterior_cov_at(self.post, p)))
    def destroy(self, p, F):
        # 地形反作用：不可逆破坏标记
        self.destroyed.add(p)

# IP-299 ME-VOI：运动激发 VoI（计量域/规划交界）
def motion_excitation_voi(x, state_dists, terrain, budget, viab):
    cands = [YawWiggle(amp), WeightShift(dx), TestStep(foot, len),
             GaitSwitch(g) for g in GAITS]
    best = None
    for u in cands:
        if not viab.safe(u): continue               # 可捕获性硬约束
        H_before = sum(w_j * entropy(d) for j, d in enumerate(state_dists))
        H_after  = expected_post_entropy(state_dists, u, terrain)
        ig = H_before - H_after
        cost = BETA * risk(u) + GAMMA * energy(u) + DELTA * gait_kl(u)
        score = ig - cost
        if best is None or score > best.score: best = (u, score)
    return best if best and best.score > 0 else None

# IP-300 VKC：生存核 + 双侧约束仲裁
class ViabilityKernel:
    def __init__(self, v_min, horizon):
        self.v_min, self.H = v_min, horizon
    def V(self, x, sigma): ...                       # dist to boundary
    def feasible(self, u, x, sigma, o_req):
        x2 = rollout_one(x, u, sigma)
        if self.V(x2, sigma_next(sigma)) < self.v_min: return False
        if observability(x2, sigma, u) < o_req:       return False
        return True
    def arbitrate(self, u_safe, u_exc, x, sigma, o_req):
        if not self.feasible(u_safe, x, sigma, o_req):
            # 空集：换问题，而不是硬优化
            return SwitchGait(most_stable_meeting(o_req)) or RequestHelp()
        return blend(u_safe, u_exc)                  # 兼顾安全与激发

# IP-301 L-RISK：LOCO 风险缩放（控制域硬实时）
def loco_risk_scale(U_ale, U_epi, H_z, u_tac, V, O, p):
    lam_safe = max(risk_scale(U_ale, U_epi, H_z, u_tac),
                   p.lam_floor * (1 + U_ale + U_epi + H_z + u_tac))
    lam_viab = p.k_v * exp(-p.c_v * (V - p.v_min))   # 近边界指数放大
    lam_exc  = p.k_e * max(0.0, 1.0 - O / p.o_min)   # 可观测不足 -> 要动
    return max(lam_safe, lam_viab, lam_exc)

# IP-302 LOCO 主闭环（三域分离继承 R72）
def LOCO_GAUGE_RAS_round(M, obs, imu, foot_sensors, cmd):
    # ===== 控制域 (1kHz, 硬实时) =====
    snap = M.snapshot.read_latest()
    sigma = M.csms.phase(M.t)
    x_hat, Sigma = M.estimator.predict_ctrl(snap, imu, foot_sensors, sigma)
    V = M.vkc.V(x_hat, sigma)
    O = snap.eoc.lam_min if snap.eoc else M.o_min  # 无证书按最保守
    lam = loco_risk_scale(*decompose(x_hat), U_tac(snap), V, O, M.p)
    u_task = M.mpc.solve_task(cmd, x_hat, lam)
    u_exc  = snap.u_exc if snap.u_exc else 0.0
    u = M.vkc.arbitrate(u_task, u_exc, x_hat, sigma, M.o_req[cmd.task])
    M.wbc.publish(u, sigma, lam)
    M.cert_ctrl.write(sigma=sigma, V=V, O=O, lam=lam, wcet=M.rtm.wcet_us())

    # ===== 计量域 (50Hz, 软实时) =====
    if M.clock.due_metric():
        x_full, Sigma_full = M.estimator.update_full(snap, obs, imu, foot_sensors)
        eoc = M.eoc.cert(M.csms.next_sigma(M.H), snap.u_exc, x_full)
        slip = M.slip.update(foot_sensors)
        ev   = [M.hemm.on_event(e, sigma, x_full, snap.u_ctrl)
                for e in M.events.drain()]
        for e in ev:
            if e.sample.q >= M.q_min: M.tgp.observe(e.sample)
        gate = M.l_ivg.check(x_full, Sigma_full, eoc, ev, M.tgp, V, slip)
        if not gate.valid:
            M.mode = gate.fallback                 # crawl / R72 / R68
            M.gaitmgr.freeze(gate.reason)
        M.snapshot.write(x_full, Sigma_full, eoc, slip, ev,
                         M.tgp.post, M.viab.plan_next(V))

    # ===== 感知域 (Best-effort) =====
    if M.clock.due_excite():
        u_exc = M.mevoi.choose(x_full, M.state_dists(), M.tgp,
                               M.budget, M.vkc)
    if M.mode == 'FULL' and M.tgp.uncertain_at(M.next_footholds()) > TAU_TGP:
        p = M.foothold.select(M.tgp, x_full, M.vkc, M.o_req[cmd.task])
        M.mpc.set_foothold(p)                      # 测量感知落脚点
    return J_LOCO(M)

## 3. 推导

**引理 33（接触调度条件可观测性）** 在定义 367–368 下，腿式里程计对基座速度的可观测性仅在支撑相且 no-slip 时为正；摆动相该方向可观测性退化为 IMU 单独支撑。故 `O_H` 是相位序列 σ 的函数，且任意含长摆动相的窗口 `O_H` 严格低于全支撑窗口。系：**「站着不动更安全」与「不动就测不准」在四足上同时为真。**

**引理 34（激发-安全双侧约束的非空判据）** 记 `𝒜_safe = {u: V(x') ≥ V_min}`，`𝒜_obs = {u: O(u) ≥ O_min}`。`𝒜_feas = 𝒜_safe ∩ 𝒜_obs`。若任务要求的 `O_min` 只能由「抬腿/大步/快速转向」实现，而这些动作使 `V < V_min`，则 `𝒜_feas = ∅`。此时**任何单侧缩放（无论 λ_safe 还是 λ_exc 更大）都无法产生可行解**；必须改变离散决策（步态/任务）。证明：连续优化在空可行集上无解；离散切换改变约束本身。系：**存在一类情境，正确的安全行为是「放弃当前任务/换步态」，而不是「更小心地继续」。**

**引理 35（地形 GP 后验收缩的足迹下界）** 在 TGP 下，一次足迹观测对位置 p 的后验方差收缩正比于 `q·k(p,p_i)`（接触质量 × 空间核）。若 `q < Q_MIN`（滑移/冲击饱和）则不更新均值、仅微增方差。故**「踩了但没踩实」不是有效测量**；足迹密度与接触质量共同决定地形场收敛速度。系：**地形学习速度被接触计量质量直接限制，R72 的 DMEM 四分量在此成为地形估计的瓶颈。**

**引理 36（冲击事件的信息-风险不可分割）** 由定义 388，`E_imp = ½ m_eff Δv²` 同时决定地形信息（越大越能辨识刚度/摩擦）与损伤风险。故不存在「零风险的高信息冲击」；信息-风险比 `EIR = IG/Risk` 在 `Δv→0` 时 `IG→0`，`Δv→∞` 时 `Risk→∞`，`EIR` 存在内点最优。系：**试探步的「力度」不是超参，是可由 EIR 诱出的最优控制量。**

**引理 37（生存核在风险缩放下的前向不变性）** 若每个控制周期都强制 `V(x_{t+1}) ≥ V_min` 且 𝒦_viab 在真实动力学下前向不变，则对任意激发动作序列，`x_t ∈ 𝒦_viab` 恒成立（归纳）。证明：基例由初始化检查；归纳步由硬约束保证。系：**激发探索不能把系统推出生存核——这是「安全优先于好奇」的可证形式。**

**引理 38（可观测性证书的模型依赖脆弱性）** EOC 由模型哈希 `h_obs` 锁定；若实际动力学 `f_real ≠ f_model`，则 `O_H^{real}` 可任意偏离 `O_H^{model}`。特别地，存在对抗性 `f_real` 使 `O^{model} ≥ O_min` 而 `O^{real} ≈ 0`（如真实足端持续微滑）。故**可观测性证书的可信度上界 = 动力学模型的可信度上界**。系：**R72 的 S2R-UQ 必须扩展到「动力学模型不确定度」而非仅参数不确定度。**

**定理 27（LOCO 严格包含与安全单调）** 在 A111–A116（CSMS 有效、EOC 模型可信、TGP 核合理、生存核前向不变、事件计量完备、GREFLEX 预算有界）下：LOCO 在退化条件（定义 382）下逐指令等于 EMBODIED/GAUGE/R71/R68；且对任意有效执行，其物理风险界 ≤ R72 风险界（定理 24），跌倒概率 ≤ 基线。**安全单调不减；效率只在「测量可激发、地形可场化、生存核可验证」时获益。**

**定理 28（LOCO 证书有效性 ⇒ 物理安全）** 若一次执行通过 `J_LOCO`，则：(i) `J_EMB` 有效 ⇒ 认知与操作层安全界成立；(ii) EOC 全有效 ⇒ 所有用于决策的状态在当前运动中可观测（不靠幻觉）；(iii) `V ≥ V_min` 且生存核前向不变 ⇒ 不跌倒；(iv) TGP 后验在有效域 ⇒ 地形决策不基于单足迹外推；(v) 事件日志完整 ⇒ 冲击信息与损伤均被计量。综上，**物理执行风险 ≤ ε_loco（相对模型）且跌倒概率 ≤ δ_viab**。**证明重量落在「生存核模型在实机上真实不变」与「动力学模型未被投毒」上。**

**定理 29（必要激发的有限停止）** 设必要激发集合 `𝒰_req = {u: O(u) ≥ O_min}`，每次激发后 `O` 单调不减（合理步态下 Gramian 累积），且 `O_min` 有上界 `O_max < ∞`。则达到 `O_min` 所需的激发次数有限（`≤ ceil((O_min − O_0)/ΔO_min)`）。**「动到能看清」是可证明有限的，不会无限试探。** 但注意：地形/扰动会重置 O，停止性仅对**静态世界**成立；对动态世界需重新定义（见风险）。

**定理 30（激发感知 MPC 的递归可行性）** 若初始 `𝒜_feas ≠ ∅` 且 MPC 终端集在 𝒦_viab 内、可观测性约束沿预测时域单调可满足，则标准 MPC 递归可行性论证成立（每步存在可行解继承）。**若某步 `𝒜_feas = ∅`，递归可行性被打破——这正是定义 374 必须向上触发步态/任务切换的原因；切换后的新 MPC 以新约束重新初始化。**

**定理 31（欺骗性下界的不可判定性）** 在无先验限制的地形场类与无界观测动作集下，不存在仅凭在线证书保证「永不在未观测区域跌倒」的算法：存在地形配置使所有未踩区域看起来与已知安全区 GP 一致，而实际为薄冰/塌陷。**推论：安全性必须由「保守地形先验 + 速度/冲击上界 + 可捕获性余量」联合保证，而非由「探索充分」保证。** 这是本轮最重要的负面结果：**你可以证明「我看清了踩过的地方」，不能证明「我没踩过的地方安全」。**

## 6. 本轮最大风险

**一句话**：LOCO-GAUGE-RAS 把安全从「相信测量链在运动下仍可信」进一步押注到「**相信生存核模型在实机上真实前向不变、相信动力学模型未被投毒因此可观测性证书不说谎、相信未踩过的地形能被保守先验兜住**」——**而运动激发计量有一个残酷的内禀悖论：为了知道世界是否安全，你必须先做一个可能不安全、且其安全性只能靠『你还没获得的知识』来保证的动作**。如果生存核模型在真实接触/冲击下高估了可捕获性（例如忽略足端微滑、关节柔顺、执行器饱和），或可观测性证书建立在错误动力学模型上而在真实微滑下 `O^{real}≈0`，或地形呈现「未踩区域与已知安全区 GP 一致、实为薄冰/塌陷」的欺骗性配置——系统会拿着「所有 EOC 有效、V 在核内、TGP 在有效域」的盖章证书，在一次为了『看清前方』而迈出的试探步里踩穿地面或侧滑跌倒，事后审计发现「它当时确实按证书行事，证书当时确实全部有效」。这是 R72「自信地错自己的可执行性」的**运动版**：**自信地错自己「为了测量而必须承担的风险」的可承受性**。

次级风险与缓解：
1. **生存核模型漏项（微滑/柔顺/饱和）** → **在线生存核验证 + ROM**：实测 `V` 与预测 `V` 残差超阈即收缩核；保守偏置 `V_min` 随残差自适应放大；关键场景用可达性分析（HJ）离线包络。
2. **动力学模型投毒导致 O 高估** → **模型哈希 + 残差监控 + 多模型集**：证书要求模型属于经 S2R-UQ 认证的模型集；ROM 每周期比对预测/实测残差，超阈即作废 EOC。
3. **欺骗性地形（未踩区域不可判定）** → **定理 31 的工程化**：强制「保守地形先验 + 速度/冲击上界 + 可捕获性余量」三重下界；对高代价场景（人类附近、高处）禁止纯探索性试探步。
4. **地形反作用不可逆** → **不可逆代价计入 GREFLEX**；对「已知脆弱地形」设硬禁足区；把破坏率纳入证书。
5. **步态切换频繁导致测量中断/预算耗尽** → **切换滞回 + 最小驻留时间 + 联合预算上界**；GREFLEX 按四层联合保守上界分配。
6. **激发动作被误当任务动作** → **动作空间显式分离**：`u_task` 与 `u_exc` 分开生成、分开审计、只在 VKC 仲裁处混合；激发动作必须带「可中止」保证。
7. **证书实时性** → 控制域只写最小片段（σ, V, O, lam, WCET），完整 J_LOCO 异步组装（继承 R72）。
8. **复杂度爆炸** → **模块化上限**：|GAITS|≤6、|footprints|≤4/周期、EOC 状态分量 ≤8、TGP 稀疏预算固定；每个 veto 一条可复算证明。

# 第 73 轮产物 · 创新点清单 v4：LOCO-GAUGE-RAS（Legged, Observability-excited, Contact-scheduled, Viability-kernel-constrained GAUGE for RAS：运动激发 × 接触调度 × 地形场 × 生存核 × 计量审计的腿足安全闭环；CSMS×EOC×HEMM×TGP×MEVOI×VKC×LOCO-GAUGE†）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 完成了「具身计量审计」：REG 实时调度、IRL 意图、DMEM 接触计量、EREFLEX 三层反作用、S2R-UQ 桥接，确立了「调度可信、意图可辨、接触可计量」的严格退化链。但 R72 默认了**固定基座、可停下再想、观测被动到达**的操作者假设：
> - 缺 **接触调度即测量调度（CSMS）**：四足的状态估计依赖步态相位，哪个足在何时是可靠传感器由步态决定；「站着不动更安全」与「不动就测不准」同时为真；
> - 缺 **激发-可观测性证书（EOC）**：可观测性不是系统属性，是「系统 × 我选择的运动」的属性；R72 只问「测得准吗」，没问「在当前运动下这状态是否根本不可观」；
> - 缺 **混合事件计量（HEMM）**：四足接触是离散事件系统，touchdown/impact 既是信息事件又是风险事件，不能用连续 HMM 近似；
> - 缺 **地形场 GP（TGP）**：地形不确定度是空间相关、足迹索引、且会被观测动作本身破坏的；单足迹不可外推为全局；
> - 缺 **运动激发 VoI（MEVOI）与生存核（VKC）**：安全要与认知显式对抗（`λ_safe` vs `λ_exc`），且可捕获性是**非补偿性硬约束**；可行集为空时必须「换问题」而非「更小心地继续」。
>
> 本轮四位一体补齐：
> - **CSMS**：把步态升级为「传感器开窗时间表」，观测矩阵随相位切换；
> - **EOC**：经验可观测性 Gramian + 模型哈希，`O < O_min` 即判「不可观」，禁止把「没测到」当「测到了且为零」；
> - **HEMM/TGP**：接触事件双重计量 + 足迹索引空间 GP（信息与风险不可分割）；
> - **MEVOI/VKC**：运动激发 VoI 与生存核硬约束；双侧风险缩放 `λ_safe` vs `λ_exc`，空可行集触发「换问题」协议。
>
> 核心命题：**从「我的测量链可信吗」进化为「我的测量链只有通过我选择的运动才变得可信，而那个运动本身就是最大风险——我如何在『必须动才能知道』与『动可能致命』之间给出可证明的证书？」** ——**运动激发计量闭环**。
>
> IP 编号：IP-295~302（共 8 个）+ EMBODIED-GAUGE-RAS 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价。**

## 2. 形式化定义（要点版）

**定义 366（LOCO-GAUGE-RAS 总览与六不变式）** 见想法区。核心：测量调度优先、激发-可观测完整性、可捕获性硬约束、事件计量完整性、地形场空间一致、严格退化链。

**定义 367（接触调度即测量调度 CSMS）** 相位 σ 决定通道有效性：足端力仅 stance、地形样本仅 touchdown、腿式里程计仅 stance+no-slip、IMU 全程但姿态可观性依赖角激励。**步态 = 传感器开窗时间表。**

**定义 368（浮动基座估计与条件可观测性）** x=(p,v,R,b_gyro,b_acc,θ_terrain,f_contact,c)；测量 h 依赖相位；`O_H(σ,u_exc)` 显式依赖激励与相位。**可观测性不是系统属性，是「系统×运动」的属性。**

**定义 369（激发-可观测性证书 EOC）** `O < O_min ⇒ 状态不可观测`，必须以先验 + 保守包络替代；禁止把「没测到」当「测到了且为零」；模型哈希 `h_obs` 锁定。

**定义 370（地形场 GP TGP）** `θ(x)~GP(m,k)`；足迹观测噪声依赖接触质量 q；分层贝叶斯核超参；**单足迹不可外推为全局地形。**

**定义 371（混合事件计量 HEMM）** 事件 e 既有信息增益又有风险；`EIR=IG/Risk`；只在 `EIR≥EIR_min` 或被迫接触时主动制造事件。**信息与风险不可分割（引理 36）。**

**定义 372（运动激发 VoI MEVOI）** `VoI^M=Σw_j·ΔH_j − β·Risk − γ·Energy − δ·D_KL(gait)`；区分「可选探索」与「必要激发」（后者转为约束满足：最小 Risk 使 O≥O_min）。

**定义 373（生存核与可捕获性 VKC）** `V(x)=dist(x,∂𝒦_viab)`；所有动作（含激发/试探步）须 `V(x_{t+1})≥V_min`；**非补偿性**：VoI 再大不能买通 V 越界。

**定义 374（双侧约束与可行步态集）** `𝒜_feas=𝒜_safe∩𝒜_obs`；`𝒜_feas=∅` 时触发「换问题」协议（降速/换 crawl 步态/退安全区/求援），**而非在空集上强行优化（引理 34）。**

**定义 375（步态级反作用预算 GREFLEX）** 新增 L4 步态反作用，成本 `c_reflex^g`；四层合算 `Σ(c^ψ+c^z+c^c+c^g)≤B_reflex_total`。**频繁换步态本身是反作用成本。**

**定义 376（腿式里程计滑移与漂移计量）** 残差 `r_slip=‖v_foot^kin−v_foot^support‖`；SPRT/HMM 判滑移；仅 `P(slip)<p_max` 且未超延迟的支撑相里程计有效；失效则按惯性/运动学外推膨胀。**漂移是「支撑相可靠性」的函数。**

**定义 377（L-MIB 运动激发指标族）** 可观测族（λ_min(O)、条件数、O 积分、D_obs 覆盖率）、事件族（冲击峰值、touchdown 抖动、P(slip) 校准、事件延迟）、地形族（GP 方差、核超参不确定度、单足迹外推比例、破坏率）、生存族（V 最小时序、支撑多边形裕度、可捕获性预测误差、恢复成功率）、步态族（切换频次/信息损失/能耗/中断时长）。同遵循定义 332/333。

**定义 378（L-IVG 运动激发 IVG）** 新增失效：可观测（λ_min<O_min、D_obs 外推、哈希不匹配）、事件（冲击超限、抖动超限、校准误差超限）、地形（GP 方差、外推、破坏率超限）、生存（V<V_min、预测误差超限）。**任一失效 ⇒ 相关模块降级。**

**定义 379（L-RISK 运动激发风险缩放）** `λ=max(λ_safe, λ_viab, λ_exc)`；`λ_viab` 近边界指数增大（让你慢），`λ_exc` 可观测不足增大（让你动）。**安全与认知在控制层显式对抗，由 VKC 仲裁。**

**定义 380（LOCO 证书 J_LOCO）** `Valid ⇔ J_EMB 有效 ∧ CSMS 哈希匹配 ∧ EOC 全有效 ∧ TGP 在有效域 ∧ 事件日志完整 ∧ 生存核证明有效 ∧ GREFLEX 预算未超`。

**定义 381（威胁模型 AIC-LOCO）** `ℰ_LOCO=ℰ_EMB×ℰ_terrain×ℰ_event×ℰ_state_est×ℰ_gait`。新增：欺骗性地形、接触事件伪造/重放、IMU 欺骗、滑移诱导、可观测性模型投毒、步态调度攻击。

**定义 382（严格退化链）** 全失效→R68；可观测失效→保守步态+R72；地形失效→本体反射+接触计量+R72；事件失效→关闭冲击学习+保守力限+R72；全有效→LOCO。**安全侧只增不减。**

**定义 383（激发感知 MPC）** `min Σ(ℓ_task+ρRisk+βEnergy) s.t. dynamics, V≥V_min, O_{0:H}≥O_min, F_c≤F_max`；可观测性以 `−logdet O` 或最小特征值约束表达，对偶变量价格化；空集触发步态/任务切换。

**定义 384（测量感知落脚点）** `S(p)=w_info·IG_TGP(p) − w_risk·Risk_foot(p) − w_e·Cost(p) − w_v·(V_min−V(p))^+`，在 `V(p)≥V_min` 下最大化。**落脚点即实验设计点。**

**定义 385（运行时可观测性监控器 ROM）** 最高优先级、静态内存；每周期重算简化 Gramian 与 V(x)；超阈冻结通道、记录、降级；模型哈希被证书锁定。与 R72 RTM 并列。

**定义 386（地形反作用）** `θ_{t+1}=G(θ_t,p_t,F_t)`（踩塌/碎裂/扰动）；`c^θ` 计入 GREFLEX；**观测即永久损失时须计不可逆风险。**

**定义 387（空间测量地图 SMM）** `M_meas: 位置 → (GP 后验, 足迹历史, 破坏标记, 最后有效时间)`；区分「未探索/可信/不可信/已破坏」；未探索区用保守先验，不用 GP 均值冒充。

**定义 388（冲击能量约束）** `E_imp=½m_effΔv²`；`E_imp≤E_max ∧ F_peak≤F_max`；**冲击是测量的代价**，MEVOI 的 Risk_event 由此展开。

**定义 389（跨相位不确定度传播）** `Σ_{t+1}=A_σΣ_tA_σ^T+Q_σ+(滑移/冲击注入)`；摆动相增长、支撑相收缩；**证书验证最坏相位序列下的不确定度上界。**

**定义 390（LOCO 主闭环契约）** 每控制周期产出 `(u_ctrl,u_exc,σ,λ,V,O,J_LOCO 片段)`；测量域异步产出 `(TGP,EOC,事件,slip)`；控制域只读快照、绝不等待（继承 R72）。

class ContactSchedule:
    def __init__(self, gait, T): self.gait, self.T = gait, T
    def phase(self, t): ...                       # -> sigma_t

# IP-296 EOC：激发-可观测性证书（计量域）
class ObservabilityCertifier:
    def __init__(self, model, o_min, lam_min_req):
        self.model, self.o_min, self.lam_req = model, o_min, lam_min_req
    def cert(self, sigma_seq, u_exc, x_prior):
        H = self.model.linearized_obs(sigma_seq, x_prior)
        Phi = self.model.transition(sigma_seq, u_exc)
        O = sum(Phi[k].T @ H[k].T @ W_inv @ H[k] @ Phi[k]
                for k in range(len(sigma_seq)))
        lam_min = min_eig(O)
        return EOC(O=O, lam_min=lam_min,
                   ok=(lam_min >= self.lam_req),
                   u_exc_star=argmin_excitation(sigma_seq, self.o_min),
                   h_obs=hash_model(self.model))

# IP-297 HEMM：混合接触事件计量
class HybridEventMetrology:
    def on_event(self, e_raw, sigma, x, u_ctrl):
        e = self.hmm.classify(e_raw)
        E_imp = 0.5 * e_raw.m_eff * e_raw.dv**2
        ig   = self.tgp.expected_info_gain(e.footprint, E_imp, e.c_mode)
        risk = risk_event(e_raw.F_peak, E_imp, self.tgp.fragility(e.footprint))
        sample = TerrainSample(p=e.footprint, y=e.terrain_obs,
                               q=contact_quality(e.c_mode),
                               destroyed=self.tgp.destruction(e))
        return EventEvidence(e=e, E_imp=E_imp, eir=ig/(risk+EPS),
                             ig=ig, risk=risk, sample=sample)

# IP-298 TGP：空间地形场（足迹索引 GP）
class TerrainGP:
    def observe(self, sample):
        if sample.q < Q_MIN: return self.post       # 低质量足迹不更新均值
        self.post = gp_update(self.post, sample.p, sample.y,
                              noise=noise_from_quality(sample.q))
        return self.post
    def info_gain(self, p):
        return 0.5*(logdet(self.post.cov) - logdet(posterior_cov_at(self.post, p)))
    def destroy(self, p, F): self.destroyed.add(p)  # 地形反作用

# IP-299 MEVOI：运动激发 VoI
def motion_excitation_voi(x, state_dists, terrain, budget, viab):
    cands = [YawWiggle(amp), WeightShift(dx), TestStep(foot, len),
             GaitSwitch(g) for g in GAITS]
    best = None
    for u in cands:
        if not viab.safe(u): continue               # 可捕获性硬约束
        ig   = sum(w*entropy(d) for w, d in zip(WEIGHTS, state_dists)) \
             - expected_post_entropy(state_dists, u, terrain)
        cost = BETA*risk(u) + GAMMA*energy(u) + DELTA*gait_kl(u)
        score = ig - cost
        if best is None or score > best.score: best = (u, score)
    return best if best and best.score > 0 else None

# IP-300 VKC：生存核 + 双侧约束仲裁
class ViabilityKernel:
    def V(self, x, sigma): ...
    def feasible(self, u, x, sigma, o_req):
        x2 = rollout_one(x, u, sigma)
        return (self.V(x2, sigma_next(sigma)) >= self.v_min
                and observability(x2, sigma, u) >= o_req)
    def arbitrate(self, u_task, u_exc, x, sigma, o_req):
        if not self.feasible(u_task, x, sigma, o_req):
            return SwitchGait(most_stable_meeting(o_req)) or RequestHelp()
        return blend(u_task, u_exc)                 # 兼顾安全与激发

# IP-301 L-RISK：LOCO 风险缩放（控制域硬实时）
def loco_risk_scale(U_ale, U_epi, H_z, u_tac, V, O, p):
    lam_safe = max(risk_scale(U_ale, U_epi, H_z, u_tac),
                   p.lam_floor*(1 + U_ale+U_epi+H_z+u_tac))
    lam_viab = p.k_v * math.exp(-p.c_v*(V - p.v_min))   # 近边界指数放大
    lam_exc  = p.k_e * max(0.0, 1.0 - O/p.o_min)        # 可观测不足 -> 要动
    return max(lam_safe, lam_viab, lam_exc)

# IP-302 LOCO 主闭环（继承 R72 三域分离）
def LOCO_GAUGE_RAS_round(M, obs, imu, foot_sensors, cmd):
    # ===== 控制域 (1kHz, 硬实时) =====
    snap  = M.snapshot.read_latest()
    sigma = M.csms.phase(M.t)
    x_hat, Sigma = M.estimator.predict_ctrl(snap, imu, foot_sensors, sigma)
    V = M.vkc.V(x_hat, sigma)
    O = snap.eoc.lam_min if snap.eoc else M.o_min
    lam = loco_risk_scale(*decompose(x_hat), U_tac(snap), V, O, M.p)
    u_task = M.mpc.solve_task(cmd, x_hat, lam)
    u_exc  = snap.u_exc if snap.u_exc else 0.0
    u = M.vkc.arbitrate(u_task, u_exc, x_hat, sigma, M.o_req[cmd.task])
    M.wbc.publish(u, sigma, lam)
    M.cert_ctrl.write(sigma=sigma, V=V, O=O, lam=lam, wcet=M.rtm.wcet_us())

    # ===== 计量域 (50Hz, 软实时) =====
    if M.clock.due_metric():
        x_full, Sigma_full = M.estimator.update_full(snap, obs, imu, foot_sensors)
        eoc  = M.eoc.cert(M.csms.next_sigma(M.H), snap.u_exc, x_full)
        slip = M.slip.update(foot_sensors)
        ev   = [M.hemm.on_event(e, sigma, x_full, snap.u_ctrl)
                for e in M.events.drain()]
        for e in ev:
            if e.sample.q >= M.q_min: M.tgp.observe(e.sample)
        gate = M.l_ivg.check(x_full, Sigma_full, eoc, ev, M.tgp, V, slip)
        if not gate.valid:
            M.mode = gate.fallback                 # crawl / R72 / R68
            M.gaitmgr.freeze(gate.reason)
        M.snapshot.write(x_full, Sigma_full, eoc, slip, ev,
                         M.tgp.post, M.vkc.plan_next(V))

    # ===== 感知域 (Best-effort) =====
    if M.clock.due_excite():
        u_exc = M.mevoi.choose(x_full, M.state_dists(), M.tgp,
                               M.budget, M.vkc)
    if M.mode == 'FULL' and M.tgp.uncertain_at(M.next_footholds()) > TAU_TGP:
        p = M.foothold.select(M.tgp, x_full, M.vkc, M.o_req[cmd.task])
        M.mpc.set_foothold(p)                      # 测量感知落脚点
    return J_LOCO(M)

## 4. 推导

**引理 33（接触调度条件可观测性）** 腿式里程计对基座速度的可观测性仅在支撑相且 no-slip 时为正；摆动相该方向退化为 IMU 单独支撑。故 `O_H` 是相位序列 σ 的函数，任意含长摆动相的窗口 `O_H` 严格低于全支撑窗口。系：**「站着不动更安全」与「不动就测不准」同时为真。**

**引理 34（激发-安全双侧约束的非空判据）** `𝒜_feas=𝒜_safe∩𝒜_obs`。若任务所需 `O_min` 只能由抬腿/大步/快速转向实现而它们使 `V<V_min`，则 `𝒜_feas=∅`；任何单侧缩放都无法产生可行解，必须改变离散决策。系：**存在一类情境，正确的安全行为是「放弃当前任务/换步态」，而非「更小心地继续」。**

**引理 35（地形 GP 后验收缩的足迹下界）** 一次足迹观测对 p 的后验方差收缩正比于 `q·k(p,p_i)`；`q<Q_MIN`（滑移/饱和）则不更新均值仅微增方差。故「踩了但没踩实」不是有效测量；地形学习速度被接触计量质量直接限制。系：**R72 的 DMEM 四分量在地形估计中成为瓶颈。**

**引理 36（冲击事件的信息-风险不可分割）** `E_imp=½m_effΔv²` 同时决定地形信息与损伤风险；`Δv→0 ⇒ IG→0`，`Δv→∞ ⇒ Risk→∞`，`EIR` 存在内点最优。系：**试探步的「力度」不是超参，是由 EIR 诱出的最优控制量。**

**引理 37（生存核在风险缩放下的前向不变性）** 若每周期强制 `V(x_{t+1})≥V_min` 且 𝒦_viab 在真实动力学下前向不变，则任意激发序列下 `x_t∈𝒦_viab` 恒成立（归纳）。系：**激发探索不能把系统推出生存核——「安全优先于好奇」的可证形式。**

**引理 38（可观测性证书的模型依赖脆弱性）** EOC 由模型哈希锁定；若 `f_real≠f_model`，则 `O_H^{real}` 可任意偏离 `O_H^{model}`，存在对抗性 `f_real` 使 `O^{model}≥O_min` 而 `O^{real}≈0`（如真实足端持续微滑）。故**可观测性证书可信度上界 = 动力学模型可信度上界**。系：**S2R-UQ 必须扩展到「动力学模型不确定度」，而非仅参数不确定度。**

**定理 27（LOCO 严格包含与安全单调）** 在 A111–A116 下：LOCO 在退化条件（定义 382）下逐指令等于 EMBODIED/GAUGE/R71/R68；且任意有效执行物理风险界 ≤ R72 风险界，跌倒概率 ≤ 基线。**安全单调不减；效率只在「测量可激发、地形可场化、生存核可验证」时获益。**

**定理 28（LOCO 证书有效性 ⇒ 物理安全）** 通过 `J_LOCO` ⇒ (i) J_EMB 有效 ⇒ 认知/操作安全界成立；(ii) EOC 全有效 ⇒ 决策状态在当前运动中可观测（不靠幻觉）；(iii) `V≥V_min` 且核前向不变 ⇒ 不跌倒；(iv) TGP 在有效域 ⇒ 不基于单足迹外推；(v) 事件日志完整 ⇒ 冲击信息与损伤均被计量。综上物理风险 ≤ ε_loco 且跌倒概率 ≤ δ_viab。**证明重量落在「生存核模型真实不变」与「动力学模型未被投毒」上。**

**定理 29（必要激发的有限停止）** 若每次激发后 O 单调不减且 `O_min ≤ O_max < ∞`，则达到 O_min 的激发次数有限（`≤ceil((O_min−O_0)/ΔO_min)`）。**「动到能看清」可证明有限；但地形/扰动会重置 O，停止性仅对静态世界成立。**

**定理 30（激发感知 MPC 的递归可行性）** 若初态 `𝒜_feas≠∅`、终端集在 𝒦_viab 内、可观测性约束沿时域单调可满足，则递归可行性成立。**若某步 `𝒜_feas=∅`，递归可行性被打破——必须向上触发步态/任务切换（定义 374），以新约束重新初始化。**

**定理 31（欺骗性下界的不可判定性，负面结果）** 在无先验限制的地形场类与无界观测动作集下，不存在仅凭在线证书保证「永不在未观测区域跌倒」的算法：存在地形配置使所有未踩区域与已知安全区 GP 一致，而实际为薄冰/塌陷。**推论：安全性必须由「保守地形先验 + 速度/冲击上界 + 可捕获性余量」联合保证，而非由「探索充分」保证。** 你能证明「我看清了踩过的地方」，不能证明「我没踩过的地方安全」。

## 7. 本轮最大风险

**一句话**：LOCO-GAUGE-RAS 把安全从「相信测量链在运动下仍可信」进一步押注到「**相信生存核模型在实机上真实前向不变、相信动力学模型未被投毒因此可观测性证书不说谎、相信未踩过的地形能被保守先验兜住**」——**而运动激发计量有一个残酷的内禀悖论：为了知道世界是否安全，你必须先做一个可能不安全、且其安全性只能靠「你还没获得的知识」来保证的动作**。如果生存核模型在真实接触/冲击下高估可捕获性（忽略足端微滑、关节柔顺、执行器饱和），或可观测性证书建立在错误动力学模型上而在真实微滑下 `O^{real}≈0`，或地形呈现「未踩区域与已知安全区 GP 一致、实为薄冰/塌陷」的欺骗性配置——系统会拿着「所有 EOC 有效、V 在核内、TGP 在有效域」的盖章证书，在一次为了『看清前方』而迈出的试探步里踩穿地面或侧滑跌倒，事后审计发现「它当时确实按证书行事，证书当时确实全部有效」。这是 R72「自信地错自己的可执行性」的**运动版**：**自信地错自己「为了测量而必须承担的风险」的可承受性**。

次级风险与缓解：
1. **生存核模型漏项（微滑/柔顺/饱和）** → 在线生存核验证 + ROM：实测/预测 V 残差超阈即收缩核；`V_min` 随残差自适应放大；关键场景用 HJ 可达性离线包络。
2. **动力学模型投毒导致 O 高估** → 模型哈希 + 残差监控 + 多模型集；证书要求模型属于经 S2R-UQ 认证的集合；ROM 每周期比对预测/实测残差，超阈作废 EOC。
3. **欺骗性地形（未踩区域不可判定）** → 定理 31 工程化：强制「保守地形先验 + 速度/冲击上界 + 可捕获性余量」三重下界；人类附近/高处禁止纯探索性试探步。
4. **地形反作用不可逆** → 不可逆代价计入 GREFLEX；已知脆弱地形设硬禁足区；破坏率纳入证书。
5. **步态切换频繁导致测量中断/预算耗尽** → 切换滞回 + 最小驻留时间 + 联合预算上界；GREFLEX 按四层联合保守上界分配。
6. **激发动作被误当任务动作** → `u_task` 与 `u_exc` 分离生成、分离审计、只在 VKC 仲裁处混合；激发动作必须「可中止」。
7. **证书实时性** → 控制域只写最小片段（σ,V,O,lam,WCET），完整 J_LOCO 异步组装（继承 R72）。
8. **复杂度爆炸** → 模块化上限：|GAITS|≤6、|footprints|≤4/周期、EOC 状态分量 ≤8、TGP 稀疏预算固定；每个 veto 一条可复算证明。
