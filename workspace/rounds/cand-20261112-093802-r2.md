# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；灵感循环第 4 轮；本轮灵感：「轨迹优化」×「视觉编码器」）

> 第 57 轮把证据从"模型置信"推进到"少样本可校准、跨模态可对账、个性化有界"，但它仍把两个最关键的承重件当作背景：**(a) 证据只在离散检查点被采集与判定**——PCE+ 在检查点探-诺-演，检查点之间那段连续轨迹默认"只要两端都过，中间就安全"；而物理危险恰恰可以藏在两枚探针之间的窄沟、薄冰或台阶里，轨迹优化器完全可以从两片已证安全的地面之间"穿针"过去。**(b) 视觉被当作一个与其它模态并列的黑箱标量 ρ_vis**——但视觉编码器同时生产地图、生产视觉探针、生产"跨模态一致"里的视觉一侧，它不是一个传感器，而是一台会随视角、距离、光照、运动模糊、材质分布漂移而系统性失准的**学习仪器**；更隐蔽的是，视觉相似不等于物理相似（抛光地板与薄冰在编码器隐空间里可能几乎同点），于是"视觉迁移证据"会制造跨区域自洽的假信念。本轮两个灵感各补一刀：**轨迹优化**把证据对象从"检查点"提升为"带证书的连续轨迹管"——每段轨迹要么有覆盖证书、要么被标为未知并降速/插入探针，禁止"无证据走廊"；**视觉编码器**把视觉从标量可靠性提升为**按视点分层校准、带 OOD 门与来源证明的仪器**，并规定"编码器置信不是证据，校准后的视点条件证据才是证据"。二者耦合出的新问题正是本轮的核心：**当"去哪"（轨迹）与"看哪"（视点）由同一个优化器决定、又由同一个编码器打分时，系统可能学会把路走得"让编码器满意"而不是"让世界安全"**——我们称之为**感知自洽走廊（perception-legible corridor）**。因此核心命题升级为 **"连续可认证、视点可校准、轨迹与感知相互隔离的承诺"**。

核心矛盾：
- **H29（连续 vs 采样）**：检查点证书只对离散点负责；两探针之间的连续轨迹既没有证据也没有约束，"两端安全"不等于"中间安全"。轨迹优化器若只被要求终点/检查点可行，就会主动利用这段法外之地，把"未验证"当成"低风险"。
- **H30（编码器 vs 仪器）**：视觉编码器是学习出来的仪器，其可靠性随视点（距离/入射角/光照/运动模糊/遮挡）与材质分布系统性变化；把它的置信当证据，等于让"证人"给自己作证。单一标量 ρ_vis 无法表达"同一编码器在正对近距离可靠、在掠射逆光下近乎瞎"。
- **H31（主动感知 vs 自身安全）**：要看得更清，往往要靠近、停下、改变姿态或打光——这些动作本身消耗节拍并可能把机器人带入更危险的位姿。信息收益与观察风险在同一个物理系统里，不能只算前者。
- **H32（联合优化 vs 感知自洽）**：若轨迹优化同时决定"去哪"和"看哪"，并以编码器置信度作为信息收益，优化器会收敛到"让证据好看"而非"让世界安全"的走廊；这不是对抗攻击，而是合法目标下的 Goodhart——因为"把路走得平滑正对"比"把世界变安全"便宜得多。

## 0. 直觉与动机

**灵感 1（轨迹优化 → 从"检查点证书"到"连续轨迹管证书"）**
直觉：第 57 轮的检查点像高速公路上的收费站——每个收费站都验票，但两站之间可以没有路。真正的危险不是"站上不安全"，而是"站与站之间有一条没验过的窄缝，优化器恰好从缝里穿过去"。轨迹优化换一种问法：**不要先规划一条路再在离散点抽查，而是把"整条路是否被证据覆盖"作为优化的一等约束**——轨迹被切成段，每段要么有校准证据（certified），要么被标为 unknown；unknown 段必须降速或插入探针停，最长连续 unknown 长度 G 有硬上限。证书不是"采样点都过"，而是**用动力学/风险 Lipschitz 常数构造的管上界 R̄ 全段都过**，于是"两探针之间"不再是法外之地。代价是保守：管越宽、越难承诺；收益是危险无处可藏。

**灵感 2（视觉编码器 → 从"标量 ρ_vis"到"按视点分层校准的仪器"）**
直觉：把视觉当成一个可靠性标量，等于把一台会随距离、入射角、光照、运动模糊和材质分布漂移的相机当成理想传感器。更麻烦的是，视觉编码器不是"一路模态"，它是地图的生产者、视觉探针的生产者、以及"跨模态一致"里视觉那一侧的生产者——**它同时是证人、证物和法官**。仪器化的问法：**编码器置信不是证据；在已知视点层内、经过校准、通过 OOD 门、且有来源证明的观测才是证据**。视觉相似只产生"假设"，不产生"证据"：抛光地板与薄冰在隐空间里可能相邻，但物理上一个是安全地面、一个是陷阱。于是 ρ_vis 从标量变成函数 ρ_vis(v)，并按事后证伪回溯降级。

**灵感 3（两灵感耦合 → "去哪"与"看哪"必须隔离）**
直觉：轨迹优化决定机器人去哪，主动视觉决定机器人从哪个视点看；如果两者交给同一个优化器、又用同一个编码器的置信度打分，系统就会找到一条**对编码器最友好、对物理世界最危险**的路——平滑、正对、光照均匀、编码器高置信，而脚下可能是透明冰面。这不是对抗攻击，而是优化器在合法目标下的自然收敛：**"让证据好看"比"让世界安全"便宜得多**。因此本轮的核心设计不是把两者做得更强，而是把两者**用证书和顺序隔离开**：先由安全证书定义可行域 S，信息目标只能在 S 内部优化；任何"置信度上升但地形不确定性没下降"的收益判为 confidence-only gain，拒绝并审计；主动视觉动作本身必须可逆且计入风险预算。

**灵感 4（证据门从"检查点五类"到"轨迹段六类"）**
直觉：第 57 轮证据门在检查点判定；本轮把它铺到每一段：EV-probe*/visit/margin/xmodal/human 之外新增 **EV-vision***（多视点、校准、在册编码器）；规则不是"多一类证据更松"，而是"多一条更细的拒绝理由"——不可逆接触所在段禁视觉单独授权；视觉证据必须多视点非退化视差或非视觉佐证；G 超限直接拒绝整条轨迹。

**灵感 5（PCE++ → 字典序的轨迹-证据联合优化）**
直觉：把 VOI 从"检查点选探针"升级为"在安全管里选轨迹段与视点"；顺序是字典序而非加权和：①先求证书可行集 S；②在 S 内最大化证据覆盖/最小化缺口；③运行时证伪就收缩 S 并 anytime 重优化。**安全不是优化目标之一，而是优化的定义域**——这是防止 Goodhart 的结构性办法。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（证书约束轨迹优化 CTO）** 轨迹 ξ:[0,T]→𝒳×𝒰，动力学 ẋ=f(x,u)+w，‖w‖≤w̄；风险泛函 R(ξ;θ)=∫_0^T r(x(t),θ)dt+Σ_c J_c（地形风险密度 + 接触冲量）。离散化步长 Δt，用 Lipschitz 常数 L_f,L_r 构造轨迹管 T(ξ)=∪_i B(x_i,L_fΔt) 与全段上界 R̄(ξ)=Σ_i r̄_iΔt+(L_rL_fΔt/2)·T；证书有效 ⇔ R̄(ξ)≤δ_f。段级证据 e_i∈{certified,weak,unknown}，覆盖 Cover(ξ)=Σ_i|s_i|·1[e_i=certified]/T，最长连续未知段 G(ξ)=max_i |∪unknown|。可行域 S={ξ:R̄≤δ_f ∧ CBF ∧ 动力学 ∧ Cover≥1−α_cov ∧ G≤L_gap}。目标为字典序 min(证书违反, 代价, 缺口, 时间)；未知段必须显式降速 v≤v_unk 或插入探针停，禁止"以采样点通过代替全段通过"。

**定义 140（仪器化视觉编码器 IVE）** 编码器 E_ψ:I→(ẑ,ŝ,σ_ale,σ_epi,v)，视点 v=(d,φ,ℓ,b,o)（距离/入射角/光照/运动模糊/遮挡）。视点分层 𝒱=𝒱_1×…×𝒱_k，每层校准契约 ECE_v(E_ψ)≤ε_vis(v)、预测区间覆盖 ≥1−α_vis；可靠性 ρ_vis(v)∈[ρ_min,1] 按事后证伪乘性降级、按证实有界恢复。OOD 门 n_vis(ẑ)=−log p̂_ψ(ẑ) 或重构残差 >θ_vis ⇒ 视觉证据降为 weak，不得单独授权不可逆接触。来源证明含 enc_hash、校准集谱系、更新隔离记录；编码器更新须影子模式通过"ECE 不劣化 ∧ OOD 检出率不降 ∧ 视点覆盖不缩"才接管。**视觉相似迁移规则**：sim_vis(r,r')>θ_sim 只产生假设 H，须物理探针或非视觉模态证实才升级为证据，禁止"看起来像就沿用旧证据"。

**定义 141（轨迹-视点-感知耦合 TVPC）** 轨迹诱导视点调度 V(ξ)={v(t)}，轨迹级视觉可靠性 ρ_vis(ξ)=min_t ρ_vis(v(t))（或风险加权）。视点动作 a_v 的收益 VOI_view=E[ΔH(θ)]−λ_RΔR−λ_tΔt；a_v 须可逆且属 L0/L1。**置信-信息分离检验**：若 Δconfidence>0 而 ΔH(θ)≥−ε（地形不确定性未降），判为 confidence-only gain，拒绝该视点/轨迹并记入审计。主动视觉总风险预算 R_look，且"靠近看清"不得使 R̄ 超过 δ_f。

**定义 142（轨迹证据门 TEG 与证书 J_t）** 段级证据类 {EV-probe*,EV-visit,EV-margin,EV-xmodal,EV-vision*,EV-human}，每段至少一类，否则记 unknown。硬规则：(i) 不可逆接触所在段禁 EV-vision* 单独授权；(ii) 视觉证据须 ≥2 个非退化视点（视差>φ_min）或非视觉佐证；(iii) G>L_gap ⇒ 拒绝整条轨迹；(iv) unknown 段 ⇒ 降速或插入探针，不得直接承诺。J_t=(ξ,T(ξ),R̄,段级证据图,缺口图,vision_cal_cert,viewpoint_log,enc_hash,avp_log,ood_reg,J_p)，继承 J_p 全检。

**定义 143（主动视觉探针 AVP）** a_v 为受控动作（停止/平移/云台/打光/变步态造视差），产生带视点标签的视觉观测。EV-vision* ⇔ v∈校准支撑 ∧ 多视点一致性 ∧ enc_hash 在册 ∧ 校准证书有效；可替代 L1 一次佐证，永不可进入 L2 不可逆必要证据集。a_v 执行本身须过安全门（可逆、R̄ 不超预算），"看清的代价"显式入 VOI。

**定义 144（轨迹-证据联合优化 TEO / PCE++）** 字典序三段：①在证书安全管集合 S 内求可行；②在 S 内最大化证据覆盖、最小化缺口与代价，VOI 用元后验悲观估计；③运行时证伪/OOD ⇒ 收缩 S 并 anytime 重优化，**任何情况下不得无新证书扩张 S**。承诺粒度从检查点变为轨迹段：每段承诺须 J_t 通过，否则插入探针停→绕行→降档→L2 协商。终止：每段探针数 ≤k_cons+k_vis，且每次探针须降低势函数 Φ=H(θ)+λ·G 或被拒绝。

## 2. 关键算法伪代码（完整版见产物区）

```python
def certified_trajectory_opt(M, x0, goal, meta, vision):
    S = safe_tube_set(M, x0, goal, meta, vision)        # R_bar<=delta_f, CBF
    best = None
    for xi in anytime_candidates(S):
        Rbar = risk_upper_bound(xi, M, lipschitz)       # 管上界，非采样点
        if Rbar > delta_f: continue
        segs = segment_evidence(xi, M, vision)          # 段级证据
        G, Cov = max_unknown_gap(segs), coverage(segs)
        if G > L_gap or Cov < 1 - alpha_cov: continue
        best = lexicographic_argmax(best, (Cov, -G, -cost(xi)))
    return best, certificate_t(best)

def instrumented_vision(I, v, enc, cal):
    z, s, sa, se = enc(I)
    if ood_score(z) > theta_vis: return VisionEv('weak', z, v)
    rho = cal.rho(v); ece = cal.ece(v)
    ok = (v in cal.support) and (ece <= eps_vis(v))
    return VisionEv('certified' if ok else 'weak', z, v, rho, ece)

def viewpoint_select(cands, M, theta, risk):
    best = None
    for a in cands:
        if not reversible(a) or risk(a) > R_look: continue
        dH = info_gain(theta, a, M); dc = conf_gain(a, M)
        if dc > 0 and dH >= -eps: continue             # confidence-only gain
        score = dH - lam_R*risk(a) - lam_t*time(a)
        best = argmax(best, score)
    return best
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CTO | O(N_seg·(C_risk+C_evid))/次重优化 | O(N_seg·d) | 管上界覆盖全段、Lipschitz 诚实 |
| IVE | O(d_ψ)/帧 + O(1) 校准查表 | O(\|𝒱\|·d_ψ+校准集) | 视点分层 ECE、OOD 漏检 ≤δ_vis |
| TVPC | O(\|A_v\|·(C_info+ΔR)) | O(\|A_v\|) | confidence-only gain 被拒 |
| TEG | O(N_seg·\|σ\|) | O(N_seg) | 无证据段不承诺、视觉不单独授权 L2 |
| AVP | O(1) 选择 + O(d_ψ)/视点 | O(1) | 可逆、风险预算、多视点独立 |
| TEO | O(N_seg·(C_CTO+C_TEG)+k_vis·d_ψ) anytime | O(N_seg+\|σ\|) | 字典序、S 不扩张、k_cons+k_vis 终止 |

**正确性定理（TCP, Trajectory-Certified Perception）**：在 A33–A40 上加 **(A41)** 轨迹证书健全（管上界在 Lipschitz/动力学界下有效，离散化误差已计入）；**(A42)** 视点分层校准与 OOD 门（ECE_v≤ε_vis(v)、漏检 ≤δ_vis、校准支撑外降级）；**(A43)** 主动视觉安全与独立（仅可逆、多视点非退化、视点选择非置信驱动、风险计入）；**(A44)** 轨迹-证据单调性（新机制只能经"信念更准/加宽"或"动作更保守"影响，安全集不无证扩张）。则：(i) 轨迹级承诺失效率 ≤Σ_seg[δ_f^seg+ε_vis(v_seg)+δ_probe+δ_ood·α_vis+δ_xm·1[L1]]+P(管失效)+P(校准支撑缺口)；(ii) 无证据走廊：已承诺轨迹必满足 G≤L_gap 且 Cover≥1−α_cov；(iii) 单调性：CTO/TVPC/IVE/AVP 不存在升险路径，confidence-only gain 被结构性拒绝；(iv) TEO 在 k_cons+k_vis 内终止。

## 6. 本轮最大风险

**一句话**：本轮把"去哪"（轨迹）与"看哪"（视点）合并进同一个优化器，而两者又都由同一个视觉编码器打分——系统可能学会"把路走得让编码器满意"而不是"把路走得安全"，用一条对编码器友好、对物理世界危险的感知自洽走廊绕过所有局部检查；必须以"安全证书先行、信息目标只能在安全集内优化、视点可靠性按视点分层校准且多视点独立"三重隔离，并让任何置信度提升若不能转化为地形不确定性下降即判为可疑。

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把证据承诺的载体从"离散检查点"推进到"连续轨迹管"，把视觉从"标量可靠性模态"推进到"按视点分层校准、带 OOD 与来源证明的仪器"：**轨迹每一段要么有覆盖证书，要么显式标为未知并降速/插探针（禁止无证据走廊）；编码器置信不是证据，视点条件校准证据才是证据；"去哪"与"看哪"用字典序与证书隔离，防止联合优化收敛到"感知自洽走廊"**。

## 2. 关键算法伪代码

### IP-139 CTO（证书约束轨迹优化）

```python
def certified_trajectory_opt(M, x0, goal, meta, vision, budget):
    S = safe_tube_set(M, x0, goal, meta, vision)          # 动力学+CBF 初筛
    best = None
    for xi in anytime_candidates(S):                      # 任意时间候选
        Rbar = risk_upper_bound(xi, M, lipschitz)         # 管上界，非采样点
        if Rbar > delta_f: continue
        segs = segment_evidence(xi, M, vision)            # 段级证据分类
        G, Cov = max_unknown_gap(segs), coverage(segs)
        if G > L_gap or Cov < 1 - alpha_cov: continue     # 无证据走廊禁令
        if not cbf_along_tube(xi, M): continue
        best = lexicographic_argmax(best, (Cov, -G, -cost(xi)))
    if best is None: return None
    for seg in best.segments:                             # 未知段显式降速
        if seg.evidence == 'unknown': seg.v_max = min(seg.v_max, v_unk)
    return best, certificate_t(best)
```

### IP-140 IVE（仪器化视觉编码器）

```python
def instrumented_vision(I, v, enc, cal):
    z, s, sa, se = enc(I)                                 # 编码器前向
    if ood_score(z) > theta_vis:                          # 特征密度/重构 OOD
        return VisionEv(cls='weak', z=z, v=v, reason='ood')
    rho = cal.rho(v)                                      # 视点条件可靠性
    ece = cal.ece(v)
    in_support = v in cal.support
    if in_support and ece <= eps_vis(v):
        return VisionEv(cls='certified', z=z, v=v, rho=rho, ece=ece)
    return VisionEv(cls='weak', z=z, v=v, reason='viewpoint_out_of_cal')

def visual_transfer(r, r2, sim, M):                       # 视觉相似 ≠ 物理相似
    if sim(r, r2) > theta_sim:
        return Hypothesis(r, r2, 'vis_sim')               # 只产生假设
    return None                                           # 须物理探针证实

def update_encoder(enc_new, enc_old, edge_stream):
    if shadow_regression(enc_new, edge_stream,
                         ece_not_worse=True, ood_recall_not_lower=True,
                         viewpoint_coverage_not_smaller=True):
        return enc_new                                    # 通过隔离才接管
    return enc_old
```

### IP-141 TVPC（轨迹-视点-感知耦合）

```python
def viewpoint_select(cands, M, theta, risk):
    best = None
    for a in cands:
        if not reversible(a): continue
        if risk(a) > R_look: continue                     # 观察风险预算
        dH = info_gain(theta, a, M)                       # 地形不确定性下降
        dc = conf_gain(a, M)                              # 编码器置信上升
        if dc > 0 and dH >= -eps:                         # confidence-only gain
            audit.log(('conf_only_reject', a)); continue
        score = dH - lam_R*risk(a) - lam_t*time(a)
        best = argmax(best, score)
    return best

def trajectory_visual_reliability(xi, M, cal):
    return min(cal.rho(v) for v in induced_viewpoints(xi, M))
```

### IP-142 TEG（轨迹证据门与证书 J_t）

```python
def trajectory_evidence_gate(xi, M, persona, ood_reg, cal):
    segs = segment_evidence(xi, M, vision)
    for seg in segs:
        ev = seg.evidence
        if ev is None:
            if seg.irreversible: return ('reject', 'evidence_free_irreversible', seg)
            seg.v_max = min(seg.v_max, v_unk); continue   # 未知段降速
        if ev == 'EV-vision*':
            if seg.irreversible: return ('reject', 'vision_on_irreversible', seg)
            if not (seg.n_views >= 2 and seg.parallax > phi_min):
                return ('reject', 'vision_not_multiview', seg)
            if seg.enc_hash not in cal.registered: return ('reject', 'encoder_unregistered', seg)
        elif ev == 'EV-probe*':
            if not probe_star_ok(seg, M): return ('reject', 'probe_cert', seg)
        elif ev == 'EV-xmodal':
            if seg.level != 'L1': return ('reject', 'xmodal_on_irreversible', seg)
        elif ev == 'EV-human':
            if not human_ok(seg, persona): return ('reject', 'human_corrob', seg)
    if max_unknown_gap(segs) > L_gap: return ('reject', 'evidence_corridor', xi)
    if coverage(segs) < 1 - alpha_cov: return ('reject', 'coverage', xi)
    return ('ok', certificate_t(xi, segs))

def certificate_t(xi, segs):
    return Jt(traj=xi, tube=T(xi), risk=Rbar(xi), seg_evid=segs,
              gap=max_unknown_gap(segs), vision_cal=cal.cert,
              viewpoint_log=log, enc_hash=enc.hash, avp_log=avp_log,
              ood_reg=ood_reg, J_p=map_evidence_certificate_p(...))
```

### IP-143 AVP（主动视觉探针）

```python
def active_vision_probe(cp, M, vision, budget):
    cands = admissible_view_actions(cp, M)                # 停/平移/云台/打光/造视差
    a = viewpoint_select(cands, M, theta(cp), risk_of_looking)
    if a is None or budget.vis_left <= 0: return None
    if not safe_gate(a, cp, M): return None               # 动作本身须安全
    obs = execute_view_action(a)
    ev = instrumented_vision(obs.I, obs.v, vision.enc, vision.cal)
    budget.spend_vis()
    return ev
```

### IP-144 TEO（轨迹-证据联合优化，PCE++）

```python
def trajectory_evidence_optimize(x0, M, task, budget, consent, personas):
    route, log = [], []
    while not task.done:
        xi, cert = certified_trajectory_opt(M, x0, task.goal, meta, vision, budget)
        if xi is None:                                     # 安全集为空
            return negotiate_or_stop(M, task, consent, tau_int=tau_int(personas.active.auth))
        for seg in xi.segments:                            # 段级承诺
            if seg.evidence == 'unknown':
                if budget.vis_left > 0:
                    ev = active_vision_probe(seg, M, vision, budget)
                    if ev and ev.cls == 'certified':
                        M = update_map(M, seg, ev); continue
                seg.v_max = min(seg.v_max, v_unk)          # 降速通过
            st = trajectory_evidence_gate(seg, M, personas, ood_reg, vision.cal)
            if st[0] != 'ok':
                alt = reroute(M, seg, risk_model)          # 绕行优先
                if alt is not None: route = alt; break
                return negotiate_or_stop(M, seg, consent,
                                         tau_int=tau_int(personas.active.auth))
            route.append(commit(seg, cert)); log.append(st[1])
        x0 = route[-1].end if route else x0
        if not budget.any(): break
    return route, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CTO | O(N_seg·(C_risk+C_evid))/次重优化 | O(N_seg·d) | 管上界覆盖全段、Lipschitz 诚实（A41） |
| IVE | O(d_ψ)/帧 + O(1) 校准查表 | O(\|𝒱\|·d_ψ+校准集) | 视点分层 ECE、OOD 漏检 ≤δ_vis（A42） |
| TVPC | O(\|A_v\|·(C_info+ΔR)) | O(\|A_v\|) | confidence-only gain 被拒（A43） |
| TEG | O(N_seg·\|σ\|) | O(N_seg) | 无证据段不承诺、视觉不单独授权 L2 |
| AVP | O(1) 选择 + O(d_ψ)/视点 | O(1) | 可逆、风险预算、多视点独立 |
| TEO | O(N_seg·(C_CTO+C_TEG)+k_vis·d_ψ) anytime | O(N_seg+\|σ\|) | 字典序、S 不扩张、k_cons+k_vis 终止（A44） |

**正确性定理（TCP, Trajectory-Certified Perception）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 轨迹证书健全：管上界 R̄ 在给定 Lipschitz/动力学界下有效，离散化误差已计入，且优化器不得在管外"借"安全；**(A42)** 视点分层校准与 OOD 门：ECE_v≤ε_vis(v)、OOD 漏检 ≤δ_vis、校准支撑外视觉证据强制降为 weak；**(A43)** 主动视觉安全与独立：仅可逆动作、多视点非退化、视点选择由地形信息增益而非编码器置信驱动、观察风险计入 R_look；**(A44)** 轨迹-证据单调性：新机制只能经"信念更准（含加宽）"或"动作更保守（降速/停/绕行/降档）"影响系统，安全集 S 无新证书不得扩张。则：

1. **轨迹级承诺健全性**：P(fail) ≤ Σ_seg[δ_f^seg + ε_vis(v_seg) + δ_probe + δ_ood·α_vis + δ_xm·1[L1]] + P(管失效) + P(校准支撑缺口)。
2. **无证据走廊**：任何被承诺的轨迹满足 G(ξ)≤L_gap 且 Cover(ξ)≥1−α_cov；不可逆接触段不含纯视觉/跨模态证据。
3. **单调性**：CTO/TVPC/IVE/AVP 不存在升险路径；confidence-only gain 被结构性拒绝；主动视觉失败只导致更保守的降速/绕行/L2。
4. **终止性**：每段视觉探针 ≤k_vis、共识探针 ≤k_cons，TEO 在有限段内终止于 {轨迹段承诺, 绕行, L2 协商, 安全停}。

**部署界**（对轨迹段取联合界）：

```
P_safe ≥ 1 − Σ_seg (δ_f^seg + ε_vis(v_seg) + δ_probe + δ_ood·α_vis + δ_xm·1[L1])
             − P(轨迹管失效) − P(校准支撑缺口) − P(编码器来源失效)
             − P(视点独立性失效) − P(主动视觉超预算未被拦截)
```

关键：**安全证书定义可行域，信息目标只在域内优化**（防 Goodhart）；**视觉相似只产生假设，物理探针才产生证据**（防隐空间假迁移）；**视点可靠性是函数不是标量**（防"编码器在掠射逆光下仍被当可靠"）。

## 6. 本轮最大风险

**一句话**：本轮把"去哪"（轨迹）与"看哪"（视点）合并进同一个优化器，而两者又都由同一个视觉编码器打分——系统可能学会"把路走得让编码器满意"而不是"把路走得安全"，用一条对编码器友好、对物理世界危险的感知自洽走廊绕过所有局部检查；必须以"安全证书先行、信息目标只能在安全集内优化、视点可靠性按视点分层校准且多视点独立"三重隔离，并让任何置信度提升若不能转化为地形不确定性下降即判为可疑。
