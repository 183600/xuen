# 第 43 轮（新循环第 3 轮） · 竞赛-关节双层证书：让「赛制」当红队、让「关节驱动」当物理锚点（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR，Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」导致证书在自信中静默失效。本轮灵感词「机器人竞赛」「关节驱动」恰好补上这个风险的两个盲区：**机器人竞赛**把「域随机化分布」升级为「自适应对手 + 裁判规则」——域随机化只会采样参数，而对手会主动寻找证书的边界并反复利用；赛制还天然提供排行榜、重复试跑和规则文档，是免费的「红队 + 课程信号源」。**关节驱动**则把证书的物理锚点从任务/几何层下探到力矩-转速-热包络——sim-to-real 差距最大、最容易被对手利用、也最容易在长时程中热累积失守的，正是关节执行器。两者耦合成本轮的双层飞轮：**外环赛制当红队，内环关节当锚点**。

## 0. 直觉与动机

**灵感 1（机器人竞赛 → 赛制即红队、排行榜即课程）**：第 42 轮的 SCV 用域随机化采样「环境有多坏」，但坏是**被动的**；竞赛里的对手是**主动的**——它会针对你的策略、你的证书边界、你的关节极限反复施压。直觉上应把赛制编译成三样东西：(a) **裁判自动机**，把规则变成与 CAR 并联的硬约束（出界、超时、违规接触、抢跑）；(b) **对手策略池**，用自博弈/PSRO 训练多种风格（激进、防守、干扰、拖延），把「最坏对手」而不是「最坏参数」作为证书的压力源；(c) **排行榜形课程**，官方评分天然可分解为子技能，用位次遗憾值决定练什么、按什么顺序练，课程相位直接由 KB 检索迁移。竞赛还提供少量「练习赛」真机数据，是校准 W_1 与关节参数的最便宜来源。

**灵感 2（关节驱动 → 把证书钉在力矩-转速-热包络上）**：第 42 轮的边际 m 主要来自任务/几何残差，隐含假设「关节能执行规划给出的力矩」。真实失效往往不在几何，而在执行器：**力矩饱和**（高速时反电动势导致 τ_max 随转速下降）、**摩擦/齿隙迟滞**（低速爬行、换向死区）、**热降额**（铜损 i²R 累积，绕组温度升高后持续电流能力下降）、**编码器/驱动故障**。直觉上要把每个关节抽象成一个**可执行包络** E_j(q, q̇, τ, T)，并让总边际变成 m = min(m_task, min_j m_joint,j)。更关键的是：E_j 本身不能靠标称参数，要用**区间辨识证书**（摩擦、齿隙、Kt、热阻/热容都落在置信盒内）取最坏角点，才能保持 sound；热裕度 h_t 必须作为自动机的额外状态跨时间递推，否则「前半场猛、后半场软」的静默降额无法被发现。

**灵感 3（耦合 → 双层飞轮）**：对手最有效的攻击，往往是把机器人逼到关节包络边界（高速变向造成力矩饱和、连续对抗造成热累积）；反过来，关节包络的收紧会改变赛制策略（该保守还是该抢分）。于是外环（赛制环）更新对手池/规则版本/排行榜，内环（关节环）更新参数盒/包络/热模型，两条环共享同一 KB，但触发频率与预算不同。**证书从「对分布鲁棒」升级为「对自适应对手鲁棒，且物理上真的可执行」。**

## 1. 形式化定义（增量：定义 38–44）

**定义 38（赛制契约与裁判自动机）**：赛制规则编译为自动机 R = (Q_R, Σ_R, δ_R, q_R0, F_R) 与合法性约束 K_R ⊆ X × U × X（位置、动作、接触、时间窗）。系统自动机取乘积 H ⊗ R；违规谓词 Viol(x,u) = 1 ⇔ (x,u) ∉ K_R。竞赛分布定义为 D_contest = (1−β)·D_official + β·D_adv，其中 D_adv 由对手策略池 Π_r 生成。**赛制可靠性**要求 P_{ξ∼D_contest}(Viol=0 ∧ m ≥ θ) ≥ 1−δ_c。

**定义 39（对抗边际与 ε-极小极大证书）**：对对手策略 π_r ∈ Π_r，轨迹边际 m(ξ; π_r) = min_t m(x_t, u_t)。**对抗边际** m_adv = inf_{π_r∈Π_r} Q_{α}[m(ξ;π_r)]（α 分位，取尾部）。证书 **ε-sound** 当且仅当 m_adv ≥ θ + ε_dual，其中 ε_dual 是双预言机/PSRO 的原始-对偶间隙上界；对手池按 best-response 迭代扩充，收敛判据为 gap ≤ ε_dual。

**定义 40（关节可执行包络）**：第 j 关节 E_j = {(q, q̇, τ, T_j) : τ ∈ [τ_min(q̇,T_j), τ_max(q̇,T_j)], T_j ≤ T_j^max, i_j²R_j ≤ P_max, |τ − τ_fric(q̇)| ≤ τ_ripple}。其中 τ_max(q̇,T) = Kt·i_max(T)·η(q̇)，i_max(T) 为热降额后的最大电流，η 含齿隙/效率。**力矩裕度** m_τ,j = dist(τ_j, ∂E_j)/τ_norm；**热裕度** m_T,j = (T_j^max − T_j)/ΔT_norm。关节边际 m_joint = min_j min(m_τ,j, m_T,j)。

**定义 41（关节参数区间辨识证书）**：参数 θ_joint = (F_c, F_v, b, Kt, R_th, C_th) 的真值落在盒 B = ∏_k [θ_k^lo, θ_k^hi]，由集合成员辨识 + 区间最小二乘给出，覆盖率 ≥ 1−δ_id。**最坏包络** E_j^wc = ⋂_{θ∈B} E_j(θ)（对不确定参数取保守交）。激励轨迹 τ_exc 在 CBF 安全约束下最大化 Fisher 信息 det(I(θ))（D-最优），同时满足 m ≥ θ 硬约束。

**定义 42（分层证书组合与热预算）**：C_global = C_task ∧ ⋀_j C_joint,j ∧ C_couple，m_global = min(m_task, min_j m_joint,j, m_couple)。串行链的关节证书可按关节独立验证（O(n)、可并行）。热是**跨时间**约束：剩余热裕度 h_t ∈ R，h_{t+1} = h_t − i_t²R Δt / C_th − (T_t − T_amb)Δt/(R_th C_th)，约束 h_t ≥ 0。**组合定理**：若各因子 sound，则合取 sound（min 的单调性）；关节饱和使有效 L_m 增大，必须并入 IP-49 的 L_m 上界。

**定义 43（竞赛双层飞轮）**：外环（赛制环）更新 Π_r、D_contest、规则版本 ρ、排行榜位次 ℓ_t；内环（关节环）更新参数盒 B、包络 E_j^wc、热模型。触发：ℓ_t 下降 > Δℓ 或规则版本变更 → 外环；关节参数漂移 S_joint > τ_j 或热漂移 → 内环。KB v2 键为 (φ, ψ, ρ, j)，ρ=对手风格/规则版本，j=关节配置指纹。**更新定理**：若外环 gap ≤ ε_dual 且内环盒覆盖真值概率 ≥ 1−δ_id，则证书长期 sound 概率 ≥ 1−δ_c−δ_id。

**定义 44（竞赛成本-效用模型）**：U = w_s·Score + w_a·Availability − w_c·COT − w_r·N_rehearsal，其中 COT 增项 = N_rehearsal·C_rehearsal（练习赛/真机试跑）+ C_joint_id（激励辨识）+ C_redteam（对手池训练）。**代理差距** g_proxy = |Score_proxy − Robust_true| 必须实时监控：排行榜分数是真实鲁棒性的代理，代理失效会把优化引向过拟合。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-51/52/53/49/50/45/47/54/55/56）

### 2.1 IP-57 CONTEST-ADVERSARY-ENGINE（CAE，赛制红队引擎）
1. **规则编译**：赛制文档 → LTL/自动机约束 K_R；可形式化部分自动生成断言测试，不可形式化部分用 LLM 抽取 + 人工确认（复用 CKB 的版本化溯源）。
2. **对手策略池**：PSRO/双预言机，按风格聚类（激进/防守/干扰/拖延）；best-response 用 RL + CBF shield，对手策略本身也要过裁判自动机，避免「靠犯规获胜」的伪反例。
3. **攻关节包络的场景生成**：把对手行为当环境扰动，重点生成把机器人逼到力矩饱和/热累积边界的交互序列（高速变向、连续对抗、贴身推挤）。
4. **排行榜形课程**：官方评分分解为子技能，按位次遗憾值安排训练顺序；课程相位 Π 与对手风格一起入 KB。
5. **输出**：对手池、违规反例、规则断言、课程草案 → 喂给 SCV（IP-54）与 CKB（IP-55）。

### 2.2 IP-58 JOINT-ENVELOPE-CERTIFIER（JEC，关节包络认证器）
1. **安全激励辨识**：多层 chirp + 随机阶跃，D-最优设计，全程受 CBF 安全约束；集合成员/区间 LS 得参数盒 B。
2. **最坏包络构造**：τ_max(q̇,T) = Kt·i_max(T)·η，取 B 的最坏角点（区间算术）；齿隙死区作为不确定性项并入。
3. **双时间尺度热模型**：绕组（快）+ 外壳（慢）RC 网络，区间参数；剩余热裕度 h_t 递推并作为 CAR 额外状态，接近上限时主动降额而非等到报警。
4. **退化模式库**：单关节卡滞/失力/编码器失效 → 预计算降级策略（锁关节、用剩余 DoF、改步态），每个策略都带证书片段与组合契约。
5. **HIL 校准**：真机短测更新 B，并与 SCV 的关节域随机化参数对齐，降低 W_1 低估。

### 2.3 IP-59 DUAL-LOOP-CONTEST-FLYWHEEL（DLCF，双层飞轮调度器）
1. **双环调度**：外环低频（每场/每周，跑对手池与规则重编译），内环高频（每次上电/热漂移，更新参数盒与包络）；统一预算仲裁。
2. **KB schema v2**：在 (φ,ψ,C,Ξ,Π) 上增加 ρ（对手/规则）、j（关节配置）、h_0（初始热裕度）、退化模式索引。
3. **触发与冷却**：排行榜下降、规则变更、参数漂移、热漂移、对手池 gap 超阈；每类触发有冷却期与最小间隔，防止抖动耗尽预算。
4. **版本化与回滚**：规则版本、对手池版本、参数盒版本、证书 hash 一致性校验；任一项不一致即熔断回退。

```
    → IP-48 认证流匹配(N*=LUT) + IP-43 韵律调度 → IP-53 CMC(看门狗=INT8 + 热看门狗)

运行期：T-2 关节查表(2μs) + T-1(5μs) + T0(100μs) + 热裕度递推 → 双环触发 → Sim/对手池重跑 → KB 更新 → 热更新下发
```

## 5. 本轮最大风险

**一句话**：本轮最大风险是「对抗红队与排行榜代理的共演化过拟合」——对手池越训越强却只覆盖自博弈流形，排行榜分数上升的同时真实赛制鲁棒性可能下降，而关节包络的保守取交又会把可用性压回 Degraded、掩盖这一退化；因此 E87（留出对手/随机对手审计）与 E92（代理差距 g_proxy 红线）必须作为熔断实验，E88/E89 的区间覆盖一旦跌破置信界也要立即回退到额定包络。

### IP-57 CAE：规则编译、对手池与排行榜课程
```
def compile_rulebook(doc, KB):
    ltl = llm_extract_ltl(doc)                 # 规则文本 -> LTL 草案
    assertions = ltl_to_assertions(ltl)        # 可执行断言
    R = ltl_to_automaton(ltl)                  # 裁判自动机
    human_confirmed = KB.audit(assertions)     # 人工确认 + 版本化
    return R, human_confirmed

def psro_rival_pool(H, R, iters=50, eps=0.02):
    Pi = init_pool(['aggressive','defensive','disturb','stall'])
    for it in range(iters):
        meta = solve_meta_nash(Pi)             # 元策略（混合）
        for pi in Pi:
            br = best_response(H, R, opponent=meta, shield=cbf_shield)
            br = project_to_legal(br, R)       # 对手也须守规则，避免犯规伪反例
            Pi.append(br)
        gap = duality_gap(Pi, H, R)
        if gap <= eps:
            break
    return Pi, gap

def contest_curriculum(Pi, leaderboard, KB):
    skills = decompose_score(leaderboard.rules)
    regret = {s: leaderboard.gap(s) for s in skills}
    order = sort_by_desc(regret)               # 位次遗憾值定训练顺序
    phases = []
    for s in order:
        style = argmin_style(Pi, s)            # 找该子技能最克制的对手风格
        phases.append(retrieve_phase(KB, s, style) or draft_phase(s, style))
    return phases, Pi

def attack_joint_envelope(H, E_wc, N=500):
    # 生成把机器人逼到力矩饱和/热累积边界的交互初始状态
    X0 = []
    for _ in range(N):
        x = backward_reach_boundary(H, boundary=E_wc, horizon=0.5)
        x.opponent = sample_aggressive(Pi)
        X0.append(x)
    return X0
```

### IP-58 JEC：安全激励辨识、最坏包络与热证书
```
def identify_joint_safe(robot, theta_prior, safety_cbf):
    tau_exc = d_optimal_design(theta_prior, max_det_fisher,
                                subject_to=[safety_cbf, torque_rated_limit])
    traj = execute(robot, tau_exc)             # 全程 CBF 保护
    B = set_membership_interval_ls(traj, model=joint_model, cover_prob=0.99)
    return B, traj

def worst_case_envelope(B):
    corners = box_corners(B)                   # 2^6 角点（可剪枝）
    E_wc = intersect([envelope(c) for c in corners])
    # 齿隙死区作为不确定性膨胀：
    E_wc = inflate(E_wc, backlash_margin(B.b))
    return E_wc

def thermal_update(h_t, i_t, T_t, T_amb, B, dt):
    # 双时间尺度：绕组快、外壳慢；区间参数取保守端
    loss = i_t**2 * B.R_lo
    h_t = h_t - loss*dt/B.C_hi - (T_t - T_amb)*dt/(B.Rth_hi*B.C_hi)
    T_next = estimate_winding_temp(T_t, loss, B)
    return max(h_t, 0), T_next

def joint_margin(tau_cmd, q, qdot, T, E_wc):
    m_tau = distance_to_boundary(tau_cmd, E_wc(q, qdot, T)) / TAU_NORM
    m_T   = (T_MAX - T) / DT_NORM
    return min(m_tau, m_T), (m_tau, m_T)

def degradation_policy(fault, H, cert):
    if fault.type == 'joint_lock':
        return cert.degraded_modes['lock'][fault.joint]   # 锁关节 + 剩余 DoF
    if fault.type == 'loss_torque':
        return cert.degraded_modes['weak'][fault.joint]
    if fault.type == 'encoder':
        return cert.degraded_modes['dead_reckon'][fault.joint]
    return SafeStop()
```

### IP-59 DLCF：双层飞轮调度与版本熔断

```
def dual_loop_tick(state, D_sim, KB, budget):
    # ---- 内环（高频）：关节 ----
    if state.S_joint > TAU_JOINT or state.thermal_drift:
        B, traj = identify_joint_safe(state.robot, state.B, state.cbf)
        E_wc = worst_case_envelope(B)
        KB.upsert(j=joint_fingerprint(state), B=B, E_wc=E_wc, ver=next_ver())
        state.ecr.reload(T2_table=build_joint_lut(E_wc))
    # ---- 外环（低频）：赛制 ----
    if state.leaderboard_drop > DL or state.rule_version != KB.rule_ver:
        R, _ = compile_rulebook(state.rulebook, KB)
        Pi, gap = psro_rival_pool(state.H, R)
        if gap > EPS_DUAL: raise FlywheelNotConverged()
        phases, Pi = contest_curriculum(Pi, state.leaderboard, KB)
        X_adv = attack_joint_envelope(state.H, E_wc)

                  C=sim_stats.cert, Xi=sim_stats.counterexamples, Pi=phases)

    # ---- 熔断与回滚 ----
```

```
def car_step(x, u, cert, R_state):
    m_task = cert_lookup_L0(x).m_lo
    m_joint, parts = joint_margin(u.tau, x.q, x.qdot, x.T, cert.E_wc)

def certify_v3(x, guards, budget_us=200):
```

## 6. 本轮最大风险

**一句话**：本轮最大风险是「对抗红队与排行榜代理的共演化过拟合」——对手池越训越强却只覆盖自博弈流形，排行榜分数上升的同时真实赛制鲁棒性可能下降，而关节包络的保守取交又会把可用性压回 Degraded、掩盖这一退化；因此 E87（留出对手/随机对手审计）与 E92（g_proxy 红线）必须作为熔断实验，E88/E89 的区间覆盖一旦跌破置信界也要立即回退到额定包络。
