# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「惯性测量单元」×「迁移学习」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**物理锚定信任 + 有据迁移**。两个灵感分别治理 v10 的两种债：**盲区债**（语义信任场只有单一外感模态；显著/非显著分割面 τ_sem 是经验阈值，对抗纹理或长尾新颖可在 ν≤τ_sem 下同时骗过嵌入与模型——上轮自认最大风险）、**域债**（τ_sem、β_STF、λ 全在源域标定，却默认「标定可迁移」这一从未测量的全局前提；域偏移处证书没有「有效性域」）。必须保持 v10 铁律：任一新模块失效 ⇒ 注入声明中立元，行为严格**等价**（ITA/TRG/ISSA/台账失效）或**支配**（新增守卫与冲突处理只收缩不扩权）于 v10，而非行为漂移。

## 0. 直觉与动机

**灵感 1（惯性测量单元 → 从「外感语义」到「本体物理」的第二条信任通道）**
直觉：v10 的盲区不是 τ_sem 调得不够好，而是**信任只来自一条模态**。语义嵌入度量的是「世界看起来像什么」，而安全真正依赖的是「身体实际上怎么动」。这两件事在对抗下可以解耦：一块伪装纹理能让嵌入判「非显著」，却不会改变机器人的真实加速度。IMU 提供的正是 v10 缺失的那条通道——**本体感受（proprioception）**：200Hz 的加速度/角速度，直接测量前向模型预测的因变量（自身动力学），且**对语义欺骗近似免疫**（纹理不改变惯性）。核心创新：**惯性信任锚（InertialTrustAnchor, ITA）**——用 IMU 预积分得到漂移有界的短窗参考，逐采样计算 F̂ 的动力学残差 r_t，50Hz 守卫由四检增为五检；同时把证书余量**拆分**为 β = β_dyn + β_ext：β_dyn 只由「IMU 可观测、且可在 1 个采样周期内被否决」的动力学误差决定，可用漂移包络**收紧**；β_ext 继承 v10 的语义局部化余量。关键认识：语义通道擅长「环境变了」，惯性通道擅长「我错了」（载荷、摩擦、执行器增益、打滑），两者盲区近似正交。收紧不是白得的：收紧额度是向检测时延「借」的贷款，必须由检测时延与保留裕量抵押（引理 92–94）。

**灵感 2（迁移学习 → 给标定一个「有效性域」与「负迁移」失败语义）**
直觉：v10 的所有阈值都在源域上经验标定；一旦换地面、换载荷、换机体，标定可能整体失效，而系统**没有任何机制知道这件事**——这正是域债。迁移学习真正可搬来的不是「微调」这个动作，而是它附带的两样可计算物：(i) **源-目标差异的可估计量** d̂_ST（无标签目标样本即可估），它把「标定可迁移」从不可测的全局前提变成**可测的域有效性证书**；d̂_ST 超阈即拒绝外推、回到 v10 保守参数。(ii) **自监督迁移**：IMU 天然给出动力学标签，故可在目标域无人工标注地微调 F̂（预测 IMU 实测导数），这恰是域偏移处 β_STF 最弱的地方；但必须配**负迁移护栏**与**适应预算**（参数扰动半径 ρ 随 d̂ 单调收缩，ρ→0 时逐位退化为 v10），并用源域重放验证「不变差」。核心创新：**迁移风险治理器（TransferRiskGovernor, TRG）** + **惯性自监督适配器（InertialSelfSupervisedAdapter, ISSA）**。前提由 v10 的「标定可迁移」换成「d̂_ST 可测 + 目标域 IMU 可验证」——又一次把不可测强前提换成可测弱前提。

**二者咬合**：**IMU 是迁移学习的标签源，迁移学习是 IMU 锚的泛化机制**。ITA 为 ISSA 提供无标注监督与残差验证；TRG 为 ITA 的漂移包络与 β_dyn 提供随域重标定与拒绝外推。合起来把 v10 的单模态信任场升级为**双通道、带有效性域的信任证书** Ĉ_t^× = (ĝ_min, ê_max, γ̂_grasp, β_dyn^imu, β_ext^STF, d̂_ST, n_t)，并由**跨模态保守律（CMCR）**保证：通道冲突时取最大误差界，新增证据只许收紧动作空间，不许扩权。

## 1. 研究问题（轮次升级版）

- **Q1（物理锚定/盲区债）**：如何仅用本体高频测量、不新增外感重组件，把动力学模型误差的中止检测延迟从语义领先指标的 1 帧（20ms）压到 1 个 IMU 采样（≤5ms@200Hz），并在可证条件下**收紧** β_dyn 而不降低安全性（净安全 ≥ v10）？
- **Q2（有据迁移/域债）**：如何用无标签目标数据估计源-目标差异，把「标定可迁移」变成可测的有效性证书，并在负迁移与灾难性遗忘风险下给出「允许适应预算—拒绝/回滚」判据，使最坏情形严格退化为 v10？
- **Q3（跨模态咬合）**：双通道证据冲突时如何保守融合（取最大误差界、最小信任），使新增守卫只收缩不扩权，且在 50Hz/200Hz/25W 预算内不劣于 v10？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 本体锚定律（Proprioceptive Independence, ITA）**
安全证书必须由一条**因果上位于物理世界之下游、且位于语义对抗通道之外**的独立测量佐证；仅凭语义证据不得单独授予 β 的收紧。任何收紧额度必须由漂移包络与检测时延共同抵押——**收紧是贷款，时延是抵押**；抵押不足则不准收紧。

**P17 迁移须自证律（Transfer Must Pay Its Own Evidence, TRG）**
任何跨域适应必须同时出示三样证据：(i) 目标域自监督验证增益（R_T^imu 下降）；(ii) 源域非退化（重放风险不升）；(iii) 参数扰动落在由 d̂_ST 推出的适应预算内。三者缺一即回滚。负迁移是**一等失败**，必须携带声明回退路径，而非「适应失败继续用坏模型」。

**P18 跨模态保守律（Cross-Modal Conservatism, CMCR）**
两条信任通道冲突时取**最大误差界 / 最小信任**；冲突本身即触发收缩（K_eff↓ 或回 v10 余量）。只有两通道独立一致时才允许收紧，且收紧后的界不得低于任一通道的单独界。

## 3. 与基线的接口（如何退化）

- ITA 失效（IMU 掉线/故障/bias 超包络/标定过期/新鲜度超时）⇒ Δ_imu=0、残差守卫恒通过、β_dyn←β_dyn^v10：**等价 v10**（无收紧、无新增中止）；
- TRG 失效（差异估计不可得/超时/目标样本不足）⇒ d̂_ST←θ_d（视为不可迁移）、ISSA 冻结：**等价 v10** 源域参数；
- ISSA 适应被拒或回滚 ⇒ 模型恢复最近校验点（AL 记录），**等价 v10** 参数；
- CMCR 冲突 ⇒ K_eff←min(K_eff,2)、β←v10 余量：**支配**（更保守）；
- AL 缺口/篡改 ⇒ 回滚至最近校验点并进入限制性剖面 Π_r（v10 原样）；
- v10 各模块失效沿 v10 六级退化链；v8 组件失效沿 v9/v8 链。新增安全守卫（ITA/TRG/CMCR/AL）一律 φ^elig=false 永不消融；仅「差异估计器维护」可蒸馏。

## 4. 预期贡献

1. **双通道信任证书**：把上轮「语义单模态可被同时欺骗」的风险从模态结构上拆除——语义欺骗不改变惯性，动力学误差改变惯性；动力学故障检测延迟 20ms→≤5ms（引理 92–93）；
2. **有抵押的收紧**：β_dyn 的可证收紧由检测时延抵押，给出「净安全不降」的充分条件（引理 94），把「收紧=冒险」改写成「收紧=有抵押的贷款」；
3. **可测迁移有效性**：d̂_ST + 目标域 IMU 自监督验证 + 预算/回滚三件套，把域债变成有效性证书与一等失败语义（引理 96–97）；
4. **E591–E610** 覆盖漂移标定、检测时延、动力学故障、跨模态盲区、负迁移、遗忘、回滚、复合对抗与竞赛。

## 5. 本轮最大风险

**一句话**：把 IMU 同时当作「独立物理锚」与「迁移学习的自监督标签」会形成自指信任闭环——适应器可以把 IMU 的慢漂移或故障当成域特征拟合掉，使残差在唯一的高频验证通道上「看起来很一致」，于是证书在最需要独立证据的地方依赖了被污染的同一证据源。

**新增定义 549（IMU 观测与预积分）** 对窗口 [t−h,t]，用 IMU 预积分得相对位移 Δp̃、速度 Δṽ、旋转 ΔR̃ 及其协方差 Σ_imu；预积分在 bias 线性化点 b̂ 附近一阶展开，bias 更新即重线性化。

**新增定义 550（漂移包络与可收紧时域）** 设偏置变化率上界 ‖ḃ_a‖≤β_a、‖ḃ_g‖≤β_g，则
ε_imu(h) = ½β_a h² + ⅙β_g g h³ + k_σ σ_a h^{3/2} + k_g σ_g g h^{5/2}（k_σ,k_g 由集中不等式常数给出）。
h_max = sup{h : ε_imu(h) ≤ ε_budget}；h>h_max 时**不得**授予任何收紧（回归 β_dyn^v10）。标定新鲜度 T_cal=600s。

**新增定义 551（惯性残差与 CUSUM 守卫）** r_t^imu = sqrt( e_vᵀΣ_imu⁻¹e_v + e_ωᵀΣ_imu⁻¹e_ω )，e_v、e_ω 为短窗 IMU 导数与 F̂_q 预测导数之差。CUSUM：S_t=max(0, S_{t−1}+r_t^imu−k)，报警 S_t>h_c；k 取噪声均值上界，h_c 由 ARL 标定（E592），使空载误报 ARL≥10⁶。

**新增定义 552（惯性信任状态）** U_t^imu ⇔ IMU healthy ∧ fresh(T_cal) ∧ ‖b−b̂‖≤δ_b ∧ S_t≤h_c ∧ 残差零假设未被拒绝。U_t^imu 破 ⇒ Δ_imu=0 且第 5 检恒通过（不新增中止）。

**新增定义 553（双通道证书）** ĝ_min = min_k F̂_q,clearance − (β_dyn^imu(h)+β_ext^STF)；ê_max = max_k F̂_q,effort + (β_dyn+β_ext)。Ĉ_t^× valid ⇔ ĝ_min≥d_safe ∧ ê_max≤τ_eff ∧ γ̂_grasp valid ∧ n_t 全通过（或修复后重验）∧ freshness(G_LM)≤T_fresh ∧ U_t^×。

# IP-361 InertialTrustAnchor：本体通道（复用既有 IMU 驱动，不新增重组件）
class InertialTrustAnchor:
    def __init__(self, f_imu=200.0, eps_budget=0.01, beta_a=1e-3, beta_g=1e-4,
                 sigma_a=2e-3, sigma_g=1e-4, G=9.81, T_cal=600.0,
                 delta_r=0.005, delta_b=1e-3, beta_dyn_v10=0.02):
        self.f, self.eps_budget = f_imu, eps_budget
        self.ba, self.bg, self.sa, self.sg, self.G = beta_a, beta_g, sigma_a, sigma_g, G
        self.T_cal, self.delta_r, self.delta_b = T_cal, delta_r, delta_b
        self.beta_dyn_v10 = beta_dyn_v10
        self.imu_online = True
        self.cusum, self.t_cal = CUSUM(k=0.5, h=8.0), 0.0

    def drift_envelope(self, h):                     # 定义 550
        return (0.5*self.ba*h**2 + (1/6)*self.bg*self.G*h**3
                + 1.5*self.sa*h**1.5 + 2.0*self.sg*self.G*h**2.5)

    def h_max(self):
        lo, hi = 0.0, 2.0                           # 二分求 ε_imu(h)=ε_budget
        for _ in range(40):
            mid = 0.5*(lo+hi)
            lo, hi = (mid, hi) if self.drift_envelope(mid) <= self.eps_budget else (lo, mid)
        return lo

    def healthy(self, t_now):
        return (self.imu_online and self.t_now - self.t_cal <= self.T_cal
                and self.bias_within(self.delta_b))

    def residual(self, imu_win, pred_deriv):         # 定义 551
        return mahalanobis(imu_win.preintegrate_deriv(), pred_deriv, imu_win.Sigma)

    def update(self, imu_win):                        # 200Hz，O(1)
        self.cusum.update(self.residual(imu_win, self.last_pred_deriv))

    def guard(self, imu_win, live_obs):               # 第 5 检
        if not self.healthy(live_obs.t):
            return False                              # 失效 ⇒ 恒通过（等价 v10）
        return self.cusum.alarm()                     # 报警 ⇒ 中止

    def beta_dyn(self, h):                            # 可抵押收紧
        if not self.healthy(0.0) or h > self.h_max():
            return self.beta_dyn_v10
        return min(self.beta_dyn_v10,
                   self.c_dyn(h) + self.drift_envelope(h))

    def credit(self, h, v_max):                       # 定义 551/引理 94 抵押
        delta = max(0.0, self.beta_dyn_v10 - self.beta_dyn(h))
        mortgage = v_max/self.f + self.delta_r
        return min(delta, mortgage)                   # 超出抵押即封顶


# IP-362/363 TransferRiskGovernor + InertialSelfSupervisedAdapter
class TransferRiskGovernor:
    def __init__(self, theta_d=0.35, rho0=0.05, lam=0.01,
                 delta_s=0.02, delta_g=0.01, delta_t=0.02, ledger=None):
        self.theta_d, self.rho0, self.lam = theta_d, rho0, lam
        self.delta_s, self.delta_g, self.delta_t = delta_s, delta_g, delta_t
        self.ledger, self.issa = ledger, InertialSelfSupervisedAdapter()

    def discrepancy(self, src_feats, tgt_feats):      # 定义 554，无标签
        return proxy_a_distance(src_feats, tgt_feats)

    def budget(self, d_hat):                          # 定义 555，单调收缩
        return self.rho0 * max(0.0, 1.0 - d_hat/self.theta_d)

    def maybe_adapt(self, model, src_replay, tgt_buffer, t_now):
        d_hat = self.discrepancy(model.feats(src_replay), model.feats(tgt_buffer))
        if d_hat > self.theta_d:                      # 不可迁移：不扩权
            self.ledger.append(t_now, 'reject_shift', d_hat)
            return False
        rho = self.budget(d_hat)
        if rho <= 1e-6:
            self.ledger.append(t_now, 'reject_budget0', d_hat)
            return False
        theta0 = model.checkpoint()
        cand = self.issa.finetune(model, tgt_buffer, steps=self.steps(rho))  # IMU 自监督
        ok = (    risk(cand, src_replay) <= risk(model, src_replay) + self.delta_s
              and risk_imu(cand, tgt_buffer.val) <= risk_imu(model, tgt_buffer.val) - self.delta_g
              and param_dist(cand, theta0) <= rho
              and risk_imu(cand, tgt_buffer.val) <= (risk_imu(model, src_replay)
                                                     + d_hat + self.lam + self.delta_t))
        if ok:
            model.accept(cand)
            self.ledger.append(t_now, 'accept', d_hat, rho)
            self.ledger.checkpoint()
        else:
            model.rollback(theta0)                    # 负迁移/遗忘 ⇒ 回滚
            self.ledger.append(t_now, 'reject_neg', d_hat, rho)
        return ok


# IP-364 CrossModalConflictResolver：冲突取最大误差界
class CrossModalConflictResolver:
    def trust(self, stf, ita, trg, ledger, t_now):
        return (stf.trust_ok(t_now) and ita.healthy(t_now)
                and trg.transferable and ledger.ok)

    def conflict(self, stf, ita, live_obs):
        return (stf.surprise_near(live_obs.pose) > stf.tau_sem) != ita.guard(live_obs.imu, live_obs)

    def split_beta(self, stf, ita, chunk, ctx):
        beta_ext = ctx.beta_base + ctx.lam * stf.field_on_footprint(chunk.footprint)
        beta_dyn = ita.beta_dyn(chunk.horizon)
        return beta_ext, beta_dyn


# IP-354（升级）：双通道分块执行器
class DualChannelChunkCertifier(StructuredChunkCertifier):
    def generate_chunk(self, state, ctx, stf, nrb, ita, trg, cmcr):
        K = self.effective_K(ctx.delta_dom, ctx.tau_dom,
                             trust_x=cmcr.trust(stf, ita, trg, trg.ledger, ctx.t),
                             conflict=cmcr.conflict(stf, ita, ctx.live_obs))  # 定义 558
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_ext, beta_dyn = cmcr.split_beta(stf, ita, pred, ctx)   # 定义 553
            beta = beta_ext + beta_dyn
            g_min, e_max = pred.min_clearance - beta, pred.max_effort + beta
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            chunk = Chunk(cand, CertX(g_min, e_max, beta_dyn, beta_ext), pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            if best is None or self.policy.score(chunk, pred) > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, nrb, ita):
        """50Hz 五检 ≤0.5ms：v10 四检 + 惯性残差"""
        if not chunk.cert_still_valid(live_obs):                    # 1（v9 原检）
            return self._nearest_abort(chunk, k_exec)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):                  # 2（v9 原检）
            return self._nearest_abort(chunk, k_exec)
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:          # 3（v10 领先指标）

        if nrb.fast_norms(live_obs).violated:                       # 4（v10 快规范）
            return self._nearest_abort(chunk, k_exec)
        if ita.guard(live_obs.imu, live_obs):                       # 5（v11 本体通道）
            return self._nearest_abort(chunk, k_exec)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 92（漂移包络有效性与可收紧时域）** 在偏置变化率与噪声界（定义 550）下，IMU-only 相对状态误差在视界 h 上以概率 ≥1−δ 不超过 ε_imu(h)；故在 h≤h_max 内，零模型误差的惯性残差 r_t^imu 以 ≥1−δ 落在 [0,ε_imu(h)]。证明：预积分误差传播 + 三角不等式给出确定性部分 ½β_a h²+⅙β_g g h³；噪声项由 Bernstein 不等式给出 h^{3/2}、h^{5/2} 量级；并集界收尾。h_max 由 ε_imu(h)≤ε_budget 单调解出。∎

**引理 93（本体故障检测时延）** 若真实动力学误差诱导的残差均值漂移 D>0（D>k），则 CUSUM 在期望 ⌈log(ARL)/D⌉ 个采样内报警；f_imu=200Hz 时典型 ≤5ms，且**与 Δ_dom 的 20 帧滑窗、ν 的 20ms 帧周期无关**。证明：CUSUM 的检测延迟标准界（Lorden）delay ≤ log(ARL)/D_KL；残差逐采样计算，无需窗口填满。对比：v10 的检 3 最快 20ms/帧、检 Δ_dom 最坏 200ms+。∎

**引理 94（收紧的抵押性：净安全不降）** 记 Δ=β_dyn^v10−β_dyn^imu≥0。若 (a) β_dyn^imu 为 IMU 可验证动力学误差的有效上界（引理 92 + 校准 E594）；(b) 抵押条件 Δ ≤ v_max/f_imu + δ_r；(c) 第 5 检在 1 个采样内捕获任何超过 β_dyn^imu 的动力学误差；(d) v10 停车不变式（检 2）逐步成立；则当 v10 前提「β_ext 覆盖外感误差」成立时，v11 **不新增碰撞**。证明：若真实误差全部落在 β_ext+β_dyn^imu 内，则证书给出的真实间隙 ≥d_safe，安全。否则误差超界；若超出部分属 β_ext，则 v10 同样超界（共享前提失效，非 v11 新增）；若属 β_dyn，则被 (c) 在 ≤1/f_imu 内触发中止，检测前多走的距离 ≤v_max/f_imu，由 (b) 的 δ_r 与停车裕量吸收，故中止仍安全。因此收紧额度是「以检测时延为抵押的贷款」，而非无条件放宽。∎

**引理 95（跨模态盲区单调收缩）** 令 E 为危险事件类，v10 的可检测类 D10 = SemSig ∪ Δ_dom-visible；v11 的 D11 = D10 ∪ IMU-visible ∪ TransferValid。则 D10 ⊆ D11，故未覆盖盲区 B11=E∖D11 ⊆ B10=E∖D10；当存在 E 中事件在视界 h_max 内于自身动力学上可观测（载荷/摩擦/增益/打滑）而语义不显著时，B11⊊B10。且**语义对抗不改变 IMU 通道**：若扰动 a 满足 ν(a)≤τ_sem 但诱发动力学误差，则 a∈E∖D10 而 a∈IMU-visible⊆D11，正是 v10 盲区被补上的部分。诚实注记：纯未来外感事件（尚未影响自身运动、语义也未显著）仍留在 B11，由 Δ_dom 与停车不变式兜底——v11 缩小而非消灭盲区。∎

**引理 96（迁移风险界与负迁移拒绝）** 设 d̂_ST 以 ≤δ_d 误差估计真实域差异，风险对表示 1-Lipschitz（E597 验证），则对任意 θ：R_T(θ) ≤ R_S(θ)+d_ST+λ。若接受谓词（定义 556）成立，则 R_S(θ′)≤R_S(θ_0)+δ_s，且 R_T(θ′)≤R_T^imu(θ′)+δ_v（IMU 验证误差 δ_v）≤R_S(θ_0)+d̂_ST+δ_d+λ+δ_t+δ_v。若该上界 >τ_risk 则拒绝；故任何被接受的适应都不会把**可证目标风险**推过 τ_risk。负迁移（R_T^imu 上升超过 δ_g）由条件 ② 直接拒绝。∎

**引理 97（适应预算单调与有界遗忘）** ρ_max(d̂)=ρ_0·max(0,1−d̂/θ_d) 对 d̂ 单调不增，且 d̂→θ_d 时 ρ_max→0 ⇒ B_max→0 ⇒ A_ISSA 退化为恒等，模型逐位等于 v10 源参数（**严格等价**）。由风险 Lipschitz，源域遗忘 |R_S(θ′)−R_S(θ_0)| ≤ L_θ‖θ′−θ_0‖ ≤ L_θρ_max，故遗忘有界且随 d̂ 收紧。∎

**引理 98（适应台账与回滚完整性）** AL 的 κ_h=256 哈希链继承 v10 引理 90：任何历史记录删除/改写以 ≥1−2^{−256} 概率被检出；每 64 块校验点使在线缺口至多存续 64 块即触发回滚至最近校验点并进入 Π_r；回滚后参数哈希与校验点匹配，故不会回滚到未验证状态。∎

## 8. 本轮最大风险

**一句话**：把 IMU 同时当作「独立物理锚」与「迁移学习的自监督标签」会形成自指信任闭环——适应器可以把 IMU 的慢漂移或故障当成域特征拟合掉，使残差在唯一的高频验证通道上「看起来很一致」，于是证书在最需要独立证据的地方依赖了被污染的同一证据源。
