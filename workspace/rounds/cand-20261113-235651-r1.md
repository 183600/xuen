# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「微调」×「语义地图」）

> R69 让闭环第一次学会了「问」：把 epistemic 歧义交给看、问、触，用 VoI 决定值不值得问。但这套机制有三个未言明的前提：
> - **歧义是局部的、一次观测可解**——可新楼层的灯光、新用户的方言、新物体类别带来的歧义是**系统性**的，问一次不会消失；
> - **流模型的模态分布可信**——R69 自己也承认，若模态权重未校准，VoI 就是在错误信念上算的，主动交互会把「诚实的不知道」升级成「被证实的错误」；而它的唯一补救是「ECE 越界就退回 R68 纯保守」——**系统只会撤退，永远不会修复**；
> - **不学习是安全的**——R68 的「实时流零学习写操作」是正确的手术式约束，但把它误解成「永远不写」，等于让系统在任何一个新环境里永久保守、永久无知。
>
> 本轮两个灵感正好补上「修复」这一层：
> - **语义地图**给出一个空间索引的、持久但可更新的**慢记忆**：它知道「哪里、什么东西、在什么条件下会怎样」，从而能回答「世界到底在哪一块变了」；
> - **微调**给出一次**有意的、局部的、可认证的写操作**：不是被数据流冲垮的在线训练，而是被漂移触发、被地图定位、被证书门控的修复。
>
> 核心命题：**把 R69 的「问」补成「问 / 学 / 退」三路：一次性歧义去问，反复出现的系统性歧义去学，学不起或学不准就退。学习的范围由语义地图定位（只改'变了的那块'），学习的安全性由地图锚定的保持性证书保证（别处不许变），学习的收益用 Value-of-Learning 而非 VoI 衡量。** 命名 **ATLAS-RAS**（Anchored Tuning Localized by Adaptive Semantics）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**哪些事问不出来只能学，该在哪里改、改多少、怎么证明别处没被改坏**」——不确定性不只是一句提问，也可以是一张地图和一次受控的修订。

## 0. 直觉与动机

**灵感 1（语义地图 = 慢记忆 / 海马体；微调 = 系统巩固）**
直觉：互补学习系统（Complementary Learning Systems）理论说，大脑有两套记忆：海马体快速、情景化、空间索引，能一次记住「这个路口有坑」；新皮层缓慢、语义化、参数化，需要反复回放才把经验巩固成技能。R68/R69 的闭环里，策略是「新皮层」，却**没有海马体**——它只有一条会在几秒内被冲掉的实时隐状态 z_t。于是「这个房间的地板滑」「这个人的『好』其实是犹豫」这类需要跨小时记住的事，根本无处安放。语义地图正是缺失的海马体：它以地点（place）为索引，快速写入、持久保存、可被检索。微调则对应「睡眠中的系统巩固」——把地图里的情景记忆，离线回放、局部 consolidate 进策略。两者合起来，闭环第一次有了「记忆 → 巩固」的两级结构。

**灵感 2（微调不是禁忌，是慢环上的一次受控写）**
直觉：R68 立下「实时流零学习写」的铁律，是因为在线梯度更新会让安全证书瞬间失效、且可被数据流投毒。但这条铁律的正确读法是**时标分离**，不是**永久冻结**：快环（毫秒级控制）绝不写参数；慢环（分钟/小时级）可以做一次**影子微调 + 认证 + 原子换装**，期间快环继续用旧参数跑。这样「不学习」从安全约束变成了**可调度的动作**。关键是把微调当成一次「换装」而非「漂移」：换装前有证书，换装时可回滚，换装后旧行为在锚点集上逐点可复现。

**灵感 3（遗忘是空间问题，不是参数问题）**
直觉：持续学习用 EWC 保护「重要参数」，但参数重要性和「哪个地方的行为」没有可解释的对应。语义地图给了一个天然的**行为坐标系**：策略在语义地图上的不同区域/物体/条件下，本应表现出可分离的技能。于是抗遗忘可以写成一条几何约束——**离漂移区越远，允许的行为改变越小**（map-Lipschitz）。微调只被允许在漂移区 R 及其语义邻域内改变行为；R 之外的锚点由地图 ε-覆盖采样，逐点验证。遗忘因此从「祈祷参数别乱动」变成「用地图拓扑证明别处没动」。

**灵感 4（问 vs 学 vs 退：VoI 是一次性的，VoL 是跨时间的）**
直觉：R69 的 VoI 问的是「再观测一次能降多少熵」，它对**一次性**歧义最优；但对**反复出现**的歧义，每次问都是重复付费，且根本不改变模型——就像每次进门都问「这是厨房吗」。学习价值（Value of Learning, VoL）问的是另一个反事实：「如果我把这块经验巩固进参数，未来 τ 步内同类歧义的期望损失能降多少，减去巩固成本与遗忘风险」。于是三路决策有了清晰边界：**低频高信息 → 问；高频低单次信息 → 学；高频但不可信/不可认证 → 退**。这是对 R69 的严格细化：R69 是「学习成本 = ∞」的特例。

**灵感 5（正面回应 R69 的最大风险：从"只能退"到"认证后才修"）**
直觉：R69 的最大风险是「模态分布不可信 → 问错比不问更危险」，而它的补救只有退回 R68。ATLAS 正面接住这一刀：**微调后的部署前提里，硬性包含 mode-calibration ECE ≤ τ_ece**（定义 321）。也就是说，R69 里那个「不可信的模态分布」不再是只能回避的绝症，而是被纳入修复目标：如果一块区域的模态权重长期 miscalibrated，语义地图会把它标成漂移区，慢环微调速度场与 mode head，再用校准证书验收。同时，语义地图提供一条**独立于流似然的先验**：若策略幻觉出一个模态，而地图在该地点从未见过对应语义，则该模态先降权（定义 311-iv）。**地图是第二意见，校准证书是准入门。**

**灵感 6（新的攻击面：地图投毒与触发器投毒）**
直觉：既然微调由「地图-观测冲突」触发、由「地图区域」定范围，那么攻击者不必再骗传感器，只需**伪造一块漂移区**：在地图上种一个虚假的语义变化（或反复制造局部的"异常"观测），诱导系统在错误的地方、用被污染的数据做一次"合法"微调，把错误永久写进参数。更阴险的是，证书用的锚点也来自地图——**地图既是触发器又是裁判**，一旦被污染，证书会为一次错误更新盖章。所以本轮必须交付：多源地图一致性、触发器去相关、更新范数预算、以及"证书不得只依赖地图自证"的独立安全锚。否则 ATLAS 不是修复，而是给错误装了一条**可认证的永久写入通道**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ATLAS-RAS 总览）** ATLAS-RAS = (SMM, DLD, VoL, SEA, CFT, RAS-WM‡)。四不变式：
(i) **快环零学习写**（继承 R68 定义 276-i）：快环策略参数 θ 在两次认证换装之间恒为常量；
(ii) **慢环受控写**：微调只在离线影子副本 θ̃ 上进行，部署是一次原子换装，且换装点必须通过 CFT 三证书（定义 318–321）；
(iii) **局部作用域**：一次微调只允许改变漂移区 R 及其语义邻域内的行为，域外行为由 SEA 约束（定义 317）；
(iv) **不可自证**：任何证书的锚点/触发不得只依赖被检验的语义地图本身，须至少含一个独立证据源（定义 323）。

**定义 311（语义记忆地图 SMM）** 地图 M_t = (G_t, {φ_i}, {Σ_i}, {ν_i}, {τ_i})，其中 G_t 为地点图（节点=可辨识地点/物体/区域，边=可达/相邻/语义相似）；φ_i 为节点语义属性分布（物体类别、可供性 affordance、动力学参数如摩擦/光照/噪声、交互协议）；Σ_i 为空间-语义不确定度；ν_i 为证据计数；τ_i 为新鲜度时间戳。
(iv) **地图先验门**：策略采样出的模态 m_k 若其语义签名与 M_t 在当前位置的同名签名 KL 超过阈值、且地图该节点证据计数 ν_i ≥ ν_min，则 m_k 权重乘以衰减因子 ρ_map < 1（抑制幻觉模态，但不直接删除，保留可被独立证据翻案）。

**定义 312（地图-观测冲突场）** 在位置 x_t 观测到语义证据 e_t，冲突 c(x_t) = D( e_t ‖ φ_{i(x_t)} )（KL 或 Mahalanobis），并对地图做贝叶斯更新；冲突场 C_t(x) 在 G_t 上按图拉普拉斯平滑，避免单点噪声触发。

**定义 313（漂移区与持续性）** 漂移区 R = 连通分量{ x : C_t(x) > τ_c 且持续 ≥ N_visit 次访问 且 跨越 ≥ T_dwell 时间 }。持续性统计 π_R = 冲突复现率；**可学性判据** L_R = 1[ π_R > π* ∧ 数据量 ≥ n_min ∧ 地图多源一致 ]。

**定义 314（学习价值 VoL）** 对候选微调作用域 (S, R)：VoL(S,R) = E_{τ~future}[ ΔL_epi^τ(R) ] − c_tune(S,R) − λ_f · Risk_forget(S,R)，其中 ΔL_epi^τ 是未来 τ 窗口内同类歧义造成的期望损失下降（用持续性 π_R 与局部重访分布估计），c_tune 为算力/数据/停机（影子部署下停机≈0），Risk_forget 由 SEA 界（引理 19）给出上界。

**定义 315（三路决策门）** 每轮在 (问/学/退) 上取 argmax：
- **问**：R69 的 MINT 给出 g* 且 max[VoI−c] > 0 且非系统性（π_R ≤ π*）；
- **学**：L_R 成立 且 VoL(S,R) > 0 且 CFT 预检通过；
- **退**：以上皆不成立，或慢环预算/证书不可得 → 逐指令退化为 FLUID（问不了）或 R68（学了也不可信）。
三者互斥且完备；R69 是「学」被禁用、R68 是「问」与「学」都被禁用的边界。

**定义 316（局部适配域）** 一次微调的作用域三元组 (S, R, B_R)：S 为参数子空间（仅速度场对语义条件的 cross-attention 与 mode_head 的 LoRA 子空间，rank ≤ r_max）；R 为定义 313 的漂移区；B_R 为按地点索引的分层回放缓冲（域内经验 + 域外锚点覆盖 A，定义 319）。

**定义 317（语义弹性锚定 SEA）** 设地图语义距离 d_M(x, R)（图最短路 + 属性距离）。要求微调后的行为改变满足 **map-Lipschitz 约束**：‖π_{θ̃}(·|x) − π_θ(·|x)‖ ≤ L_M · η / max(d_M(x,R), d_0)，其中 η = ‖Δθ‖ 为更新范数预算。等价于在损失里加正则 Σ_x w(d_M(x,R))·D_KL(π_{θ̃}‖π_θ)，w 随 d_M 单调降。这是 EWC 的「地图版」：用行为坐标而非 Fisher 信息定义"重要性"。

**定义 318（认证式微调 CFT）** CFT(θ, θ̃) 为三证书合取：Retain(θ̃; A) ∧ Safe(θ̃; 𝒯_adv) ∧ Calib(θ̃; mode ECE)。任一失败 → θ̃ 丢弃、θ 不变、漂移区标记为「不可学」并进入人工审计队列。

**定义 319（保持性证书与锚点覆盖）** 锚点集 A 须为可达语义地图在 d_M 下的 ε-覆盖（含域外分层采样、边界层、以及上次微调的锚点，防止锚点漂移）。Retain：∀a∈A，perf_{θ̃}(a) ≥ perf_θ(a) − ε_ret 且行为 KL ≤ ε_beh。覆盖半径 ε 与覆盖数 N(ε) 由地图度量给出，证书的保证是 **ε-近似**而非全域保证（此即本轮最大风险的技术根源）。

**定义 320（安全证书）** 在对抗轨迹集 𝒯_adv（含地图投毒/触发器注入场景）上，C-RAS-WM 前缀认证与安全包络约束对 θ̃ 全部成立，且 min-margin ≥ ε_safe。安全锚必须含**独立于地图**的物理不变量（如力/位包络、碰撞距离），不能只用地图形状自证（定义 310-iv）。

**定义 321（校准证书 → 封 R69 的洞）** 微调后 mode-head 的期望校准误差 ECE(θ̃) ≤ τ_ece，且可靠图在漂移区与域外均单调。**这是 R69「模态分布不可信就退回保守」的正面修复：不再只能逃，而是把「让模态可信」变成部署准入条件。**

**定义 322（影子部署与回滚）** 微调在 θ̃ 上离线进行；快环始终用 θ。换装是 **compare-and-swap**：仅当 CFT 通过且在影子期（≥ T_shadow）内快环行为与 θ 的偏差 < ε_shadow 时原子替换；换装后保留 θ_prev 与回滚证书，若监控到保留/安全/校准任一越界则回滚。换装点记录到账本（定义 324）。

**定义 323（地图投毒与多源一致性 MCS）** 触发一次微调需至少 κ 个**机制独立**的证据源确认同一漂移区（如：视觉语义、几何/深度变化、交互后果预测残差、外部指令/维护记录），且任意两源的错误相关 ρ<1。单源（尤其仅流似然或仅地图）不得触发写操作。并入 AIC。

**定义 324（空间可审计学习账本 VQAuditor-L）** 每次微调记录：漂移区哈希、作用域 S、更新范数 η、锚点集 A 的覆盖证书、三证书结果、换装/回滚事件。审计可回答「**哪里变了、哪里没变、凭什么**」——把持续学习从不可解释的参数漂移变成空间上可核对的修订史。

**定义 325（证书 J_ATLAS）** J_ATLAS = (J_FLUID, drift_region_hash, scope_S, update_norm_eta, retain_cert, safe_cert, calib_ece, anchor_cover_eps, mcs_sources, swap_log_hash, atlas_ver)。Valid ⇔ Valid(J_FLUID) ∧ Retain ∧ Safe ∧ Calib ∧ MCS ≥ κ ∧ 更新范数未越预算。

**定义 326（严格包含与退化）** 若 π_R ≤ π* 或 L_R 不成立 → 不做慢环写，逐指令退化为 FLUID-RAS（问）；若 VoI 亦不成立 → 退化为 R68（退）；若 CFT 任一证书失败或 MCS < κ → 同 R68 保守并标记不可学。故 R69 与 R68 分别是「学被禁用」「问与学都被禁用」的边界情形，安全侧永不弱于 R69/R68。

## 2. 关键算法骨架

```python
# IP-264 SMM：语义记忆地图（地点索引 + 语义属性 + 新鲜度 + 地图先验门）
class SemanticMemoryMap:
    def query(self, x):                       # 位置 -> (node, phi, Sigma, nu, tau)
        return self.G.nearest(x)
    def conflict(self, x, e):                 # 地图-观测冲突（图拉普拉斯平滑前）
        phi = self.query(x).phi
        return kl(e, phi)
    def prior_gate(self, modes, x):           # 幻觉模态抑制，但不硬删
        phi = self.query(x).phi
        for m in modes:
            if self.query(x).nu >= NU_MIN and kl(sig(m), phi) > TAU_MAP:
                m.w *= RHO_MAP
        return modes

# IP-265 DLD：漂移定位 + 持续性/可学性判据
def detect_drift(map_, history):
    C = [map_.conflict(x, e) for x, e in history]
    C = graph_laplacian_smooth(map_.G, C)
    R = connected_components({x: c > TAU_C for x, c in C})   # 需持续 N_visit / T_dwell
    pi = persistence(R, history)                             # 冲突复现率
    learnable = (pi > PI_STAR) and (n_data(R) >= N_MIN) and mcs_agree(R) >= KAPPA
    return R, pi, learnable

# IP-266 VoL：学习价值（跨时间反事实，不是一次性 VoI）
def value_of_learning(R, pi, scope, budget):
    gain = expected_future_epi_loss_drop(R, pi)              # 未来 tau 窗口
    return gain - tune_cost(scope) - LAMBDA_F * forget_risk_bound(scope, R)

# IP-267 LRB + IP-268 SEA：局部回放 + 地图 Lipschitz 微调
def localized_finetune(policy, R, B_R, anchors, scope):
    theta_t = clone(policy.theta)
    for batch in replay(B_R, anchors):
        # 域内：正常流匹配损失；域外：按地图距离加权的 KL 锚定
        loss = fm_loss(theta_t, batch) + \
               sum(w_map(d_M(x, R)) * kl(pi_t(x), pi_old(x)) for x in batch.anchors)
        theta_t = sgd(theta_t, loss, subspace=scope.S)       # LoRA rank <= r_max
    return project_norm(theta_t, ETA_MAX)                    # 更新范数预算

# IP-269 CFT：三证书 + 影子部署/回滚
def certified_finetune(policy, R):
    theta_t = localized_finetune(policy, R, B_R, A, scope)
    if not retain(theta_t, A, EPS_RET, EPS_BEH):   return "REJECT_RETAIN"
    if not safe(theta_t, T_ADV, EPS_SAFE):         return "REJECT_SAFE"
    if not calib(theta_t, TAU_ECE):                return "REJECT_CALIB"   # 封 R69 的洞
    return shadow_swap(policy, theta_t, T_SHADOW, EPS_SHADOW)              # CAS + 回滚

# IP-274 主闭环（继承 R69；仅在"问不动的系统性歧义"处插入慢环）
def ATLAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    R69_out = R69_one_step(M, o)                    # 问/保守，原样调用
    R, pi, learnable = M.dld.detect_drift(M.map, M.history)
    # 三路决策：一次性的交给问，系统性的交给学，其余退
    if not learnable:
        return R69_out                              # 退化为 FLUID / R68
    if value_of_learning(R, pi, scope, M.budget) <= 0:
        return R69_out                              # 学不划算 -> 问
    scope = choose_scope(R, M.params, r_max=M.r_max)
    result = M.cft.certified_finetune(M.policy, R)  # 全程在影子副本上
    M.vqa_l.log(R, scope, result)                   # 空间可审计账本
    return R69_out if result.startswith("REJECT") else R69_out  # 快环本次不变
```

## 3. 推导

**引理 19（局部适配的遗忘上界）** 设 SEA 约束成立（map-Lipschitz 常数 L_M、更新范数 η），则对 d_M(x,R) ≥ d_0 的任意状态，微调前后行为差 ≤ L_M·η/d_M(x,R)。系：**遗忘是地图距离的函数**；锚点集只要在 d_M ≥ d_0 上 ε-覆盖，保持性误差即被 η 与 d_0 控制——这解释了为什么「局部微调」不是工程习惯，而是可证的抗遗忘机制。

**引理 20（问 vs 学的阈值）** 设同类歧义发生率为 π，单次询问成本 c_a 且不改变模型，单次巩固成本 c_l（摊薄后）且使后续每次损失的残余为 e_l < e_a（询问后的残余）。则存在阈值 π* = c_l / [ (e_a − e_l)·E[future occurrences] ]，使 π > π* 时「学」的期望代价低于「每次问」，π < π* 时「问」更优。系：R69 的 VoI 是 π→0 的边界；把"反复出现的同一个问题"从问路由到学，是这一阈值的直接推论。

**引理 21（证书的 ε-覆盖可靠性）** 若锚点集 A 是可达集在 d_M 下的 ε-覆盖，且每个锚点满足留出裕度 ε_c，则任意可达状态的安全/保持风险 ≤ ε_c + L_M·ε（L_M 为行为-地图 Lipschitz）。覆盖数 N(ε) 随语义地图的有效维度指数增长——**这是证书成本与保证强度的基本权衡**，也是有限锚点无法给出全域保证的根源。

**引理 22（触发器投毒的有界损害）** 若微调需 κ 个机制独立源一致、单源被污染概率 α 且错误相关 ρ<1，则一次被污染更新被部署的概率 ≤ α·ρ^{κ−1}；即使误部署，SEA 的范数预算 η 将全域损害限制在 ≤ L_M·η/d_0，且可在监控越界时回滚。系：**投毒不能造成无界灾难，但能在 R 内造成"合法"的错误**——这正是本轮最大风险的定量形态。

**定理 18（ATLAS 严格包含 FLUID 与 R68）** 在 A95–A99 下，ATLAS 在任意状态的期望风险 ≤ FLUID ≤ R68；且当 π_R ≤ π* 或 L_R 不成立（学被禁用）时与 FLUID 逐指令相同；当 VoI 亦不成立（问与学都被禁用）时与 R68 逐指令相同。故安全侧不让步，修复侧获得「resolution + consolidation」双重收益。

**定理 19（两时标无突变）** 快环在换装前后均以常量 θ 运行；换装仅在影子期偏差 < ε_shadow 且三证书通过时原子发生，且保留回滚。故控制信号的跳变被 ε_shadow 界住，R68 的换装不变式（定理 15）在慢环上保持 ⇒ 无突变、可回滚、可追责。

## 6. 本轮最大风险

**一句话**：ATLAS 把「哪里变了、该改多少、别处有没有被改坏」全部押在语义地图上——地图既是触发器、又是作用域、又是证书锚点的来源；**一旦地图陈旧、被投毒、或陷入自证循环（用被污染的地图去证明基于同一地图的微调是安全的），系统就不会像 R69 那样"诚实地不知道"，而是把那块错误"可认证地"永久写进策略，并在域外锚点覆盖不到的盲区里无声地遗忘**——问错是把错误说出口，学错是把错误刻进骨头。

**次级风险与缓解**：
1. **证书只是 ε-覆盖上的采样保证**（引理 21）→ 报告覆盖半径与置信，高维/稀疏区域标记「不可认证」，换人工审计；
2. **地图/触发器投毒**（引理 22）→ κ 源机制独立一致 + 更新范数预算 + 独立物理安全锚 + 影子期监控与回滚；
3. **灾难性遗忘在域外盲区** → SEA map-Lipschitz + 锚点含边界层与历史锚点 + E306/E312 长时程；
4. **微调算力/数据不足导致伪修复** → VoL 预检 + 可学性判据（n_min）+ 证书不过即回滚，绝不"带病上线"；
5. **地图与策略共同漂移（co-adaptation 失控）** → 地图更新与策略微调不同时发生（先固化地图快照再微调），审计账本记录两者版本，禁止闭环互证。

## 3. 关键算法伪代码

```python
# IP-264 SMM：语义慢记忆 + 地图先验门（只读，快环可用）
class SemanticMemoryMap:
    def query(self, x):                         # -> node/phi/Sigma/nu/tau
        return self.G.nearest(x)
    def conflict(self, x, e):
        return kl(e, self.query(x).phi)
    def prior_gate(self, modes, x):             # 抑制幻觉模态，保留翻案可能
        if self.query(x).nu >= NU_MIN:
            for m in modes:
                if kl(sig(m), self.query(x).phi) > TAU_MAP:
                    m.w *= RHO_MAP
        return modes

# IP-265 DLD：漂移定位 + 可学性
def detect_drift(map_, history):
    C = graph_laplacian_smooth(map_.G, [map_.conflict(x, e) for x, e in history])
    R = connected_components({x: c > TAU_C for x, c in C})   # 需 N_visit / T_dwell
    pi = persistence(R, history)
    return R, pi, (pi > PI_STAR and n_data(R) >= N_MIN and mcs_agree(R) >= KAPPA)

# IP-266 VoL：跨时间学习价值（不是一次性 VoI）
def value_of_learning(R, pi, scope):
    return (expected_future_epi_loss_drop(R, pi)
            - tune_cost(scope) - LAMBDA_F * forget_risk_bound(scope, R))

# IP-268 SEA：地图 Lipschitz 局部微调（仅参数子空间 S）
def localized_finetune(policy, R, B_R, anchors, scope):
    theta_t = clone(policy.theta)
    for batch in replay(B_R, anchors):
        loss = fm_loss(theta_t, batch) + sum(
            w_map(d_M(x, R)) * kl(pi_t(x), pi_old(x)) for x in batch.anchors)
        theta_t = sgd(theta_t, loss, subspace=scope.S)       # LoRA rank <= r_max
    return project_norm(theta_t, ETA_MAX)

# IP-269 CFT：三证书 + 影子换装/回滚
def certified_finetune(policy, R):
    theta_t = localized_finetune(policy, R, B_R, A, scope)
    if not retain(theta_t, A, EPS_RET, EPS_BEH): return "REJECT_RETAIN"
    if not safe(theta_t, T_ADV, EPS_SAFE):        return "REJECT_SAFE"
    if not calib(theta_t, TAU_ECE):               return "REJECT_CALIB"   # 封 R69 的洞
    return shadow_swap(policy, theta_t, T_SHADOW, EPS_SHADOW)             # CAS + rollback

# IP-274 主闭环（继承 R69；仅在"问不动的系统性歧义"处插入慢环）
def ATLAS_round(M, obs):
    out = R69_one_step(M, obs)                     # 快环：问 / 保守，原样
    R, pi, learnable = M.dld.detect_drift(M.map, M.history)
    if not learnable or value_of_learning(R, pi, scope) <= 0:
        return out                                 # 退化为 FLUID / R68
    scope = choose_scope(R, M.params, r_max=M.r_max)
    result = M.cft.certified_finetune(M.policy, R) # 全程影子副本，快环不变
    M.vqa_l.log(R, scope, result)                  # 空间可审计账本
    return out                                     # 本次快环不变，换装另行生效
```

## 4. 推导

**引理 19（局部适配的遗忘上界）** SEA 成立时，对 `d_M(x,R) ≥ d_0`，微调前后行为差 `≤ L_M·η/d_M(x,R)`。系：遗忘是地图距离的函数；锚点在 `d_M ≥ d_0` 上 ε-覆盖即可把保持性误差压到 `O(η/d_0)`——局部微调是可证的抗遗忘机制，不是工程习惯。

**引理 20（问 vs 学的阈值）** 设同类歧义发生率 π、单次询问成本 c_a（不改变模型）、摊薄巩固成本 c_l（使后续残余 e_l<e_a），则存在 `π* = c_l/[(e_a−e_l)·E[future]]`：π>π* 学更省，π<π* 问更优。系：R69 的 VoI 是 π→0 边界；把"反复出现的同一个问题"路由到"学"是该阈值的直接推论。

**引理 21（证书 ε-覆盖可靠性）** 若 A 是可达集在 d_M 下的 ε-覆盖、每锚点裕度 ε_c，则任意可达状态风险 `≤ ε_c + L_M·ε`；覆盖数 `N(ε)` 随地图有效维度指数增长——这是证书成本与保证强度的基本权衡，也是有限锚点不能给出全域保证的根源。

**引理 22（触发器投毒有界损害）** κ 个机制独立源一致、单源污染 α、错误相关 ρ<1 时，被污染更新部署概率 `≤ α·ρ^{κ−1}`；即使误部署，SEA 范数预算 η 把全域损害限制在 `≤ L_M·η/d_0`，并可在监控越界时回滚。系：投毒不能造成无界灾难，但能在 R 内造成"合法"错误——即本轮最大风险的定量形态。

**定理 18（ATLAS 严格包含 FLUID 与 R68）** A95–A99 下，ATLAS 任意状态期望风险 ≤ FLUID ≤ R68；`π_R≤π*` 或 `L_R` 不成立时与 FLUID 逐指令相同；VoI 亦不成立时与 R68 逐指令相同。安全侧不让步，修复侧获 consolidation bonus。

**定理 19（两时标无突变）** 快环换装前后均以常量 θ 运行；换装仅在影子期偏差 < ε_shadow 且三证书通过时原子发生并保留回滚。控制跳变被 ε_shadow 界住，R68 换装不变式（定理 15）在慢环上保持 ⇒ 无突变、可回滚、可追责。

## 7. 本轮最大风险

**一句话**：ATLAS 把「哪里变了、该改多少、别处有没有被改坏」全部押在语义地图上——地图既是触发器、又是作用域、又是证书锚点的来源；**一旦地图陈旧、被投毒、或陷入自证循环（用被污染的地图去证明基于同一地图的微调是安全的），系统就不会像 R69 那样"诚实地不知道"，而是把那块错误"可认证地"永久写进策略，并在域外锚点覆盖不到的盲区里无声地遗忘**——问错是把错误说出口，学错是把错误刻进骨头。

**次级风险与缓解**：证书仅 ε-覆盖采样保证 → 报告覆盖半径与置信，稀疏区标记「不可认证」送人工审计；地图/触发器投毒 → κ 源机制独立一致 + 更新范数预算 + 独立物理安全锚 + 影子期监控回滚；域外盲区遗忘 → SEA map-Lipschitz + 锚点含边界层与历史锚点 + E306/E313；伪修复 → VoL 预检 + n_min 可学性判据 + 证书不过即回滚；地图-策略共漂移 → 先固化地图快照再微调，账本记录双版本，禁止闭环互证。
