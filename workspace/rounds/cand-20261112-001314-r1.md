# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「成本控制」×「手势识别」）

> 第 54 轮把技能组合升级为动作剖面 α_S + 动作-鲁棒性联合证书 J，并闭合了云边协同。本轮把两个看似“应用层”的词还原为第一性约束：**手势是低带宽、欠定义的意图编码**，**成本控制是“把算力花在能改变决策的地方”**。核心矛盾——H22：手势识别精度的提升未必转化为组合成功率（过度识别 over-recognition），边缘算力被消耗在与动作等价的冗余区分上；H23：成本、鲁棒性、动作对齐三者耦合，均匀成本分配会在罕见关键手势上欠投入、在常见手势上过投入。

## 0. 直觉与动机

**灵感 1（手势是意图压缩，不是分类目标）**
直觉：系统并不需要知道“他做的是哪一个手势”，只需知道“该手势诱导的动作等价类”。两个手势只要诱导出动作兼容且动作核心相同，就不值得被区分。于是识别目标从手势空间 G 商到动作等价类 A/∼，记商映射为 Q。**超过商的精度是浪费**——这是成本控制的第一杠杆：只奖励有决策价值的准确率。形式化上，手势-动作商是对“组合决策”的**最小充分统计量**，是 information bottleneck `min I(G;Q) − β·I(Q;A_decision)` 的一个特例。

**灵感 2（识别是 anytime 过程 → 成本-精度剖面）**
直觉：识别可随时中断并给出当前置信度与已花成本。每条识别链（传感器采样率 × 模型深度 × 是否上云）有单调递增、边际递减的成本-精度剖面 a_g(c)（rate-distortion 形状）。“花多少算力去识别”因此是一个 metareasoning 决策：仅当继续识别的**信息价值 VoI** ≥ 成本-风险兑换率 μ·Δc 时才继续。

**灵感 3（成本进入组合图，成为与 ρ、δ_a 并列的硬约束）**
直觉：把成本作为组合图的第三维权重：路径成本 `C(P)=Σ c_trans + Σ c_recog + Σ c_coord`；在预算 B 下最小化期望组合风险 `R(P)`。这不是“先组合再算账”，而是**预算约束下的资源受限最短路（RCSP）**：用标号法维护风险-成本 Pareto 前沿，或用拉格朗日松弛在凸包上取点；其对偶变量恰好是预算的**影子价格**（每多一单位成本能换回多少风险），可直接当作 μ 的标定值。成本从此写进联合证书，可被第三方核验。

**灵感 4（歧义用最便宜的提问消解）**
直觉：手势天然歧义。当歧义映射到互不兼容的动作剖面时，与其猜，不如发起**最小成本消歧查询**（再做一次手势/一次确认）。选择查询 `q* = argmax 信息增益/成本`，直到等价类唯一；若查询预算耗尽仍不唯一，则落到安全默认并记为拒部署证据。这把第 54 轮的 Explain 反向通道升级为“主动问”，也让第 53 轮的负迁移绊线从被动拦截变为主动规避。

**灵感 5（成本-意图-鲁棒性四层金字塔）**
直觉：在 𝕃（鲁棒性）与 𝔸（动作）之上再叠加 **ℂ（成本台账）** 与 **𝔾（手势意图商）**。跨层证书必须同时携带 ρ、A_cert、成本台账 Λ、手势商类 χ，否则“低成本”与“可部署”无法被同时证明；缺任一维，证书即不可组合。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（手势-动作商 Q）**
手势空间 G，动作剖面映射 `π: G → 2^A`。称 `g_1 ≡_θ g_2` 当且仅当 `compat(π(g_1),π(g_2)) ≥ θ_a` 且 `A_core(π(g_1)) = A_core(π(g_2))`。商集 `Q = G / ≡_θ`，每类 `χ=[g]` 是识别目标。**过度识别量** `ORR = (a_full − a_Q)/a_full`，其中 `a_full` 为全标签精度、`a_Q` 为商类精度；`ORR>0` 表示存在无决策价值的精度。

**定义 122（anytime 识别剖面）**
对识别预算 `c∈[0,C_max]`，识别器输出商类上的信念 `b_c ∈ Δ(Q)`；精度 `a_g(c)=P(argmax b_c = [g])` 单调非降、上凸（边际递减）。识别成本分解 `c_recog = c_sensor + c_comp + c_comm`。剖面由温度标定，满足 `|conf_c − P(·|o,c)| ≤ ε_c`。

**定义 123（信息价值门控 VoI）**
决策集 `D={execute(χ), clarify, safe_default}`。信念 b 下的期望风险 `R(b)=min_{d∈D} E_{χ~b}[risk(d,χ)]`，其中 `risk(execute(χ))` 由第 54 轮 ρ、δ_a 与 compat 计算。继续识别的信息价值
```
VoI(Δc | b) = R(b_c) − E_{b_{c+Δc}}[ R(b_{c+Δc}) ]
```
门控规则：`refine ⇔ VoI(Δc|b) ≥ μ·Δc`，μ 为**成本-风险兑换率**（risk per cost），可由 CASP 的对偶变量标定。

**定义 124（成本感知组合）**
路径 `P=(S_1,…,S_k)` 覆盖任务动作序列 A_T；`C(P)=Σ c_trans(S_i,S_{i+1}) + Σ c_recog(g_i) + Σ c_coord`；期望风险 `R(P)` 由第 54 轮 ρ 组合链与 δ_a 给出。成本感知组合问题：
```
P* = argmin_P R(P)  s.t.  C(P) ≤ B ∧ δ_a(P) ≤ Θ_a ∧ ρ(P) ≥ ρ_min
```
这是带额外约束的资源受限最短路；Pareto 前沿上的点集记为 `PF(B)`。

**定义 125（成本台账证书）**
`Λ = (B, c_used, c_sensor, c_comp, c_comm, c_trans, c_margin, μ, evidence)`。部署判据：
```
c_used + c_margin ≤ B ∧ δ_a ≤ Θ_a ∧ min_d ρ(d) ≥ ρ_min
```
`evidence` 至少含识别置信度剖面、成本采样日志与消歧查询记录。

**定义 126（成本感知消歧查询）**
查询集 Qry（再来一次手势、一次按键确认、一次方位指认），查询 `q` 成本 `c(q)`、期望后验 `b'`。选取
```
q* = argmax_{q∈Qry} ( R(b) − E[R(b')] ) / c(q)
```
当商类唯一或 `Σc(q) > B_clar` 时停止；停止于非唯一则执行 `safe_default` 并记为拒绝部署证据。

## 2. 关键算法 伪代码

### IP-121 GQC（Gesture-Action Quotient Classification）

```python
def build_quotient(gestures, pi, theta_a):
    reps, Q = [], []
    for g in gestures:
        for k, rep in enumerate(reps):
            if compat(pi(g), pi(rep)) >= theta_a and A_core(pi(g)) == A_core(pi(rep)):
                Q[k].members.append(g); break
        else:
            reps.append(g); Q.append(QuotientClass(rep, [g], pi(g)))
    return Q   # 识别目标从 |G| 降到 |Q|，类内区分不计入损失

def quotient_loss(pred, target_class):   # 只惩罚跨类混淆
    return 0.0 if pred == target_class else 1.0
```

### IP-122 ACR（Anytime Cost-aware Recognition）

```python
def anytime_recognize(obs, ladder, conf_target, budget):
    b, c_used = uniform(Q), 0.0
    for stage in ladder:                 # 采样率↑ / 模型深度↑ / 上云
        if c_used + stage.cost > budget: break
        b = stage.update(obs, b); c_used += stage.cost
        if calibrated_conf(b) >= conf_target: break
    return b, c_used
```

### IP-123 VCG（Value-of-information Compute Gating）

```python
def voi_gate(b, obs, c_used, budget, mu, ladder):
    r0, best = expected_risk(b), None
    for stage in ladder:
        if c_used + stage.cost > budget: continue
        b2 = stage.preview(obs, b)
        voi = r0 - expected_risk(b2)
        ratio = voi / stage.cost
        if voi >= mu * stage.cost and (best is None or ratio > best[0]):
            best = (ratio, stage, b2)
    return ('refine', best) if best else ('decide', b)
```

### IP-124 CASP（Cost-Aware Skill Path）

```python
def cost_aware_path(G, src, goal, B, Theta_a):
    frontier = {src: [(0.0, 0.0, None)]}      # (cost, risk, backptr)
    pq = [(0.0, 0.0, src, None)]
    while pq:
        cost, risk, node, back = heappop(pq)
        if not pareto_admissible(frontier[node], cost, risk): continue
        if node == goal: return reconstruct(back)
        for e in G[node]:
            c2 = cost + e.c_trans + e.c_recog
            if c2 > B: continue
            r2 = compose_risk(risk, e)        # 复用第54轮 compose_robustness_chain
            if r2.delta_a > Theta_a: continue
            if dominated(frontier[e.dst], c2, r2.risk): continue
            insert_pareto(frontier[e.dst], (c2, r2.risk, back))
            heappush(pq, (c2, r2.risk, e.dst, e))
    return None   # 预算内无可行路径：拒部署
```

### IP-125 CLQ（Cost-aware cLarification Query）

```python
def clarification_loop(b, Qry, B_clar, mu_q):
    spent = 0.0
    while not unique_class(b) and spent < B_clar:
        q = max(Qry, key=lambda q: (expected_risk(b) - expected_risk(posterior(b, q))) / q.cost)
        gain = (expected_risk(b) - expected_risk(posterior(b, q))) / q.cost
        if gain < mu_q: break
        b = observe(q); spent += q.cost
    return b if unique_class(b) else safe_default(b)
```

### IP-126 CLC（Cost Ledger Certificate）

```python
def cost_ledger(plan, B, margin, rho_min, Theta_a):
    c = sum(e.c_trans for e in plan.edges) \
        + sum(h.c_used for h in plan.recog) + plan.c_coord
    L = Ledger(B=B, c_used=c, c_margin=margin, breakdown=plan.measurements)
    ok = (c + margin <= B) and min(plan.rho.values()) >= rho_min and plan.delta_a <= Theta_a
    return ('ok', L) if ok else ('reject', 'budget_or_risk', L)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| GQC | O(|G|·|Q|·|A|) | O(|G|+|Q|·|A|) | 商映射 sound，类内不可分 |
| ACR | O(|ladder|·|Q|) | O(|Q|) | 剖面单调、温度标定 |
| VCG | O(|ladder|·|D|·|Q|) | O(|Q|) | VoI 估计无偏、μ 标定 |
| CASP | O(|E|·|PF|·log(|V|·|PF|)) | O(|V|·|PF|) | Pareto 剪枝完备、风险单调 |
| CLQ | O(|Qry|·|Q|²) | O(|Q|) | 后验更新正确、查询成本测量 |
| CLC | O(|P|) | O(|P|) | 成本上界保守、台账可复核 |

**正确性定理（Cost-Bounded Gesture-Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 商映射 sound：`χ=[g]` 蕴含 `compat(π(g),π(rep))≥θ_a` 且 `A_core` 一致，跨类误判率 ≤ ε_Q；**(A30)** anytime 剖面标定误差 ≤ ε_c，商类数 |Q|；**(A31)** 成本模型保守，预测误差 ≤ c_margin，超预算概率 ≤ ε_B。则
```
P(success ∧ C(P) ≤ B) ≥ 1 − [ Σ_d(1−ρ_min(d)) + β_E + P(δ_a>Θ_a) + ε_Q + ε_c·|Q| + ε_B ]
```
且 CASP 返回的路径在 Pareto 前沿上风险 ε-最优（前沿完全枚举时精确；ε-支配剪枝时给 (1+ε) 近似界）。**关键洞察**：`μ* = dR*/dB`（预算影子价格）给出“每单位成本应换回的最小风险降幅”，它把“成本控制”与“鲁棒性”统一到同一个拉格朗日乘子上。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 商映射误设（把危险手势并入安全类） | 高 | 安全类只做“保守合并”+ 红队手势 + 拒绝可选 |
| 成本模型漂移/隐藏成本 | 高 | 在线成本采样 + 保守 c_margin + 台账审计 |
| VoI 门控饿死罕见关键手势 | 高 | 关键类下界采样 + 稀有度加权 μ |
| 消歧查询造成交互疲劳 | 中 | 查询预算 B_clar + 成本感知停止 + 安全默认 |
| anytime 剖面失准 | 中 | 温度标定 + 分布漂移检测 + 回滚 |

## 6. 本轮最大风险

**一句话**：本轮把“手势识别”化为意图-动作商、把“成本控制”化为预算约束下的信息价值门控，理论上让成本与鲁棒性统一到同一拉格朗日乘子，但整套 soundness 依赖**商映射不把危险手势错误并入安全类、anytime 剖面与成本模型在线可标定、以及 μ 的影子价格在分布漂移下仍有效**——一旦商化为了省成本而吞掉安全关键区分，系统会以极低成本“高置信地做错”，因此必须把**安全类保守合并 + 关键手势召回下界 + 成本台账审计**设为不可交易的硬护栏，宁可多花预算，也绝不把“便宜的自信”当作可部署。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-CAGE（GQC×ACR×VCG×CASP×CLQ×CLC）

> 承接第 54 轮产物 v31。本轮把「手势识别」还原为**意图-动作商**、把「成本控制」还原为**资源受限决策 + 信息价值门控**，形成 **v17 GroundEdge-CAGE（Cost-Aware Gesture-composed Edge）**。
> - **GQC（Gesture-Action Quotient Classification）**：识别目标从手势空间商到动作等价类 `Q=G/≡_θ`；
> - **ACR（Anytime Cost-aware Recognition）**：识别是可中断的 anytime 过程，附成本-精度剖面；
> - **VCG（Value-of-information Compute Gating）**：仅当 `VoI ≥ μ·Δc` 才继续买算力；
> - **CASP（Cost-Aware Skill Path）**：预算 B 下的风险-成本 Pareto 最短路；
> - **CLQ（Cost-aware cLarification Query）**：最小成本消歧查询，替代盲目猜测；
> - **CLC（Cost Ledger Certificate）**：成本台账写入联合证书，部署前可核验。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118 以纳入手势条件与成本维度。核心叙事：**成本从“事后统计”变为“组合前硬约束 + 可核验台账”；手势从“分类目标”变为“动作等价类 + 消歧查询”。**

```python
    while pq:
        cost, risk, node, back = heappop(pq)
        if not pareto_admissible(frontier[node], cost, risk): continue
        if node == goal: return reconstruct(back)
        for e in G[node]:
            c2 = cost + e.c_trans + e.c_recog
            if c2 > B: continue
            r2 = compose_risk(risk, e)
            if r2.delta_a > Theta_a: continue
            if dominated(frontier[e.dst], c2, r2.risk): continue
            insert_pareto(frontier[e.dst], (c2, r2.risk, back))
            heappush(pq, (c2, r2.risk, e.dst, e))
    return None

def lagrangian_bound(G, src, goal, B):
    # 凸包近似：对 λ 二分，取 R(P)+λ(C(P)-B) 最小路径
    for lam in dual_search(lambda lo, hi: ...):
        P = shortest_path(G, src, goal, w=lambda e: e.risk + lam * e.cost)
        if P.cost <= B: yield P, lam    # lam ≈ μ* = dR*/dB
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GQC | O(|G|·|Q|·|A|) | O(|G|+|Q|·|A|) | 商映射 sound，类内不可分 |
| ACR | O(|ladder|·|Q|) | O(|Q|) | 剖面单调、温度标定 |
| VCG | O(|ladder|·|D|·|Q|) | O(|Q|) | VoI 无偏、μ 标定 |
| CASP | O(|E|·|PF|·log(|V|·|PF|)) | O(|V|·|PF|) | Pareto 剪枝完备、风险单调 |
| CLQ | O(|Qry|·|Q|²) | O(|Q|) | 后验更新正确、成本实测 |
| CLC | O(|P|) | O(|P|) | 成本上界保守、台账可复核 |

**正确性定理（Cost-Bounded Gesture-Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 商映射 sound：`χ=[g]` 蕴含 `compat(π(g),π(rep))≥θ_a` 且 `A_core` 一致，跨类误判率 ≤ ε_Q；**(A30)** anytime 剖面标定误差 ≤ ε_c，商类数 |Q|；**(A31)** 成本模型保守，预测误差 ≤ c_margin，超预算概率 ≤ ε_B。则
```
P(success ∧ C(P) ≤ B)
  ≥ 1 − [ Σ_d(1−ρ_min(d)) + β_E + P(δ_a>Θ_a) + ε_Q + ε_c·|Q| + ε_B ]
```
且 CASP 返回路径在 `PF(B)` 上风险 ε-最优（前沿完全枚举时精确；ε-支配剪枝给 (1+ε) 近似界）。统一点：**μ* = dR*/dB 是预算的影子价格**，VCG 的门控阈值与 CASP 的对偶变量因此共享同一标定量，成本控制与鲁棒性在同一拉格朗日框架下闭合。

## 5. 本轮最大风险

**一句话**：GQC 把识别商到动作等价类、VCG/CASP 把成本与鲁棒性统一到预算影子价格，理论上用同一乘子同时管住“花多少算”与“能不能部署”，但整套 soundness 依赖**商映射不把危险手势错误并入安全类、anytime 剖面与成本模型在线可标定、μ 在分布漂移下仍近似影子价格**——一旦为了压成本而商化掉安全关键区分，系统会“以极低代价高置信地做错”，故必须把**安全类保守合并 + 关键手势召回下界 + 成本台账审计**设为不可交易的硬护栏，宁可超预算，也绝不把“便宜的自信”当作可部署。
