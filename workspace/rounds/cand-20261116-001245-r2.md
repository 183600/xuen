# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「技能组合」×「力矩传感」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**组合安全 + 物理接触闭环**。两个灵感治理 v9 的两处结构性缺口：(1) v9 的 PrimitiveGraph 是扁平图，技能拼接靠人工编排，局部证书不自动组合——「组合债」；(2) v9 的块证书依赖学习前向模型与 20 帧 DA 滑窗，最慢通道 20ms，对"接触"这一物理事件只能间接推断——「接触债」。本轮坚持**安全单调性**：新通道只允许更早中止、绝不放大可行动作集，任一新模块失效注入中立元、严格退回 v9。

## 0. 直觉与动机

**灵感 1（技能组合 → 可组合技能证书）**
直觉：v9 把技能当成 PrimitiveGraph 上的扁平节点，任务 = 人工连边。但"局部安全"推不出"组合安全"：A 的后置条件可能违反 B 的前置条件，A/B 的工作空间与算力可能冲突，接缝处不变量会断。真正缺的是一套**组合代数**。核心创新：**可组合技能证书（Composable Skill Certificate, CSC）**：技能 σ=(Pre,Post,Inv,C,R,W_exp,φ)，组合算子 ∘(顺序)/∥(并行)/▷(回退)/⊳(中断) 各带证书合成规则，接缝由**接缝守卫** G_{σ1→σ2} 覆盖；组合计划 π=σ1∘σ2∘… 的证书由各子证书 + 接缝守卫归纳传递（引理 87/88）。这把 v9 的扁平 PrimitiveGraph 升级为**带证书的技能组合图**，并把契约中间件从模块级扩展为"技能级→模块级"两级契约。

**灵感 2（力矩传感 → 力矩残差接触证书）**
直觉：v9 最慢的安全通道是块证书（50Hz/20ms，依赖学习模型 + 20 帧 DA 滑窗），对碰撞/接触这类物理事件只能"看"不能"触"。关节力矩传感给出 1kHz、与视觉/前向模型**失效模式独立**的物理真值：外部接触在 τ_res 中 1–2ms 显现。核心创新：**力矩残差接触证书（Torque-Residual Contact Certificate, TRCC）**：用广义动量观测器从 τ_res 估计外部力旋量 ŵ_ext 及其置信椭球；每个技能声明**期望接触签名** W_exp（自由运动≈零接触，抓取≈法向力区间），**意图门控**判定期望/异常接触，异常即触发 M₀ 硬检查或就近安全停驻。关键：力矩通道与技能组合天然耦合——组合定义了"应该接触什么"，力矩验证"实际接触了什么"。

**灵感 3（两者合成 → 快慢双层接触闭环）**
直觉：单靠任一都不够。组合给"语义期望"，力矩给"物理真值"，二者构成三个时间尺度的嵌套安全闭环：技能组合 5Hz（块边界/接缝）→ 块证书/视觉 50Hz（20ms）→ 力矩残差 1kHz（<5ms）。核心设计律：**安全单调性（只增不减律）**——力矩通道只新增中止触发，绝不授权 v9 本来禁止的动作；任一通道报"危险"即停（OR-中止），从不同时要求两票才停（引理 90）。这让新通道的故障只会退化为"更慢但仍旧安全"，而不是"更快但更脆"。

## 1. 研究问题（轮次升级版）

- **Q1（组合证书传递）**：在什么接缝守卫与不变量条件下，局部技能证书可归纳组合为整计划证书？并行组合的资源/接触签名不相交性能否成为可判定的充分条件？
- **Q2（接触可辨识与意图门控）**：在模型误差 ε_model 与传感噪声 ν 下，力矩残差能在多大幅度上区分"期望接触"与"异常碰撞"？意图门控的接受域 A_σ 如何随组合算子变化？
- **Q3（安全单调与快慢一致性）**：如何形式化"新通道只收缩可行动作集"？当力矩通道与视觉/块证书判定冲突时，OR-中止是否仍保持 v9 安全性且不引入不可恢复的误停？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 组合证书律（Composable Skill Certificate, CSC）**
技能 σ 携带契约 (Pre,Post,Inv,C,R,W_exp,φ)；组合 π 合法 ⇔ 每个子技能证书有效 ∧ 每条接缝守卫 G_{σi→σj} 在 Post_{σi}∧Inv 下成立 ∧ 资源包络两两不相交（并行时）。组合证书 C_π 由归纳合成，不重新验证子技能内部。

**P14 力矩残差接触律（Torque-Residual Contact, TRC）**
以广义动量观测器输出 r(t)≈外部力矩，τ_res=τ_meas−(M q̈+C q̇+g)；接触证书 K=(ŵ_ext,Σ_c,κ)。接触被判"异常" ⇔ ŵ_ext ∉ A_σ(active skill)；异常 ⇒ 立即 M₀ 硬检查/就近停驻。A_σ 由技能声明，组合时按算子合成（顺序=分段切换，并行=力旋量叠加）。

**P15 安全单调律（Safety Monotonicity, No-Weakening）**
新通道只能向"更保守"方向改变判据：v10 的可行动作集 A_v10 ⊆ A_v9。力矩中止是"或"关系（任一通道危险即停），从不是"与"关系；TRC 失效注入中立元（A_σ≡全域，永不因力矩中止）严格等价 v9。

## 3. 与基线的接口（如何退化）

- TRC 失效（观测器发散/传感器故障）⇒ 注入中立元 A_σ≡全域，力矩不中止，等价 v9；
- SC 失效（组合验证失败/接缝不可覆盖）⇒ 退回 v9 扁平 PrimitiveGraph 人工连边，等价 v9；
- 组合算子失败 ⇒ 仅保留顺序算子 ∘（最保守），等价 v9 原语链；
- 接触签名未知（新技能无 W_exp）⇒ A_σ 取全域（只保留视觉/块证书），等价 v9；
- AC/MW/ID/DA/SPR/Cal 失效 ⇒ 沿用 v9 五级退化；
- 全部失效 ⇒ v9 → v8 → v7 → v6。

## 4. 预期贡献

1. **可组合技能证书代数**：接缝守卫 + 证书归纳合成，把"组合安全"从人工枚举变为可判定性质；
2. **力矩残差接触证书与意图门控**：1kHz 独立物理安全通道，与视觉/前向模型失效模式正交；
3. **快慢双层接触闭环 + 安全单调性**：新通道只增早停、不放大可行集，严格继承 v9 安全性；
4. **组合×接触×分块×蒸馏的四向耦合**：E571–E590 覆盖组合传递、接缝覆盖、碰撞时延、意图门控 ROC、偏差盲区、快慢冲突、传感器故障与端到端。

## 5. 本轮最大风险

**一句话**：接触签名与力矩残差共享同一动力学模型，在持续接触丰富操作中"偏差漂移"与"真实接触"不可辨识——A_σ 的期望接触包络会恰好把缓慢增长的真实碰撞藏在里面，即「最快通道在它最该保护的接触丰富区留下最大盲区」。

**新增定义 540（技能与技能契约 SkillContract）** 技能 σ 是带证书的可组合单元：
```
σ = (Pre_σ, Post_σ, Inv_σ, C_σ, R_σ, W_exp_σ, φ_σ^comp)
```
Pre/Post 为边界状态谓词，Inv 为技能执行全程须保持的安全谓词，C 为证书（软层指标界，沿用 v9 定义 533 的 Ĉ 语义），R=(算力 ms, 工作空间, 力上限) 为资源包络，W_exp 为期望接触签名（定义 546），φ^comp 为是否允许参与组合（安全关键技能如 M₀ 硬检查、SpatialCert 为 false）。

**新增定义 541（组合算子 Composition Operators）**
- 顺序 `π = σ1 ∘ σ2`：存在接缝守卫 G_{σ1→σ2}，接触签名按分段切换 W_exp(σ1) → W_exp(σ2)；
- 并行 `π = σ1 ∥ σ2`：要求 R_{σ1} ∩ R_{σ2} = ∅（算力/工作空间不相交），Inv_{σ1} ∧ Inv_{σ2} 可满足，接触签名按力旋量叠加 W_exp = W1 ⊕ W2；
- 回退 `π = σ1 ▷ σ2`：σ1 未达成 Post 时转 σ2，证书为 C_σ1 ∨ C_σ2（互斥分支）；
- 中断 `π = σ1 ⊳ σ2`：G_int 触发时 σ2 抢占 σ1，证书须覆盖抢占接缝（σ1 可随时安全停驻）。

**新增定义 542（接缝守卫与组合证书 SeamGuard & Composed Certificate）** 组合证书按区间传播的单调转移函数合成：
```
C_{σ1∘σ2} valid ⇔ C_σ1 valid ∧ C_σ2 valid
                 ∧ (Post_σ1 ⇒ G_{σ1→σ2}) ∧ (G_{σ1→σ2} ⇒ Pre_σ2)
                 ∧ Inv_{σ1} ∧ Inv_{σ2} 在接缝处保持
```
其中 ⊗ 对每个软层指标做区间传播（min 下界、max 上界单调合并），不重新验证子技能内部。

**新增定义 543（组合计划 CompositionPlan）** π 为算子树，证书 C_π 自底向上计算；规划期仅搜索通过 C_π 的树，运行期按当前技能查 A_σ 与块边界对齐（接缝 = 块边界，避免中块换技能）。

**新增定义 544（力矩残差与广义动量观测器 TorqueResidual）**
```
τ_res = τ_meas − (M(q)q̈ + C(q,q̇)q̇ + g(q))
p = M(q)q̇
r(t) = K_O [ p(t) − ∫_0^t (τ_meas + C^T(q,q̇)q̇ − g(q) + r) ds ]
```
r 收敛到外部关节力矩（一阶低通，截止由 K_O 定）；末端力旋量 ŵ_ext = (J^T)^† r（接触点雅可比伪逆）。

**新增定义 545（接触证书 ContactCertificate）** K = (ŵ_ext, Σ_c, κ, t_det)。Σ_c 由传感噪声协方差 Σ_ν 与模型误差 ε_model 经雅可比传播；κ 由定义 546 判定；t_det 为从真实接触到 κ=anomalous 的时延（目标 <5ms）。

**新增定义 546（期望接触签名与意图门控 Expected Contact & Intent Gating）** 技能 σ 声明接受域 A_σ：
- 自由运动：A_σ = { ‖ŵ_ext‖ ≤ 2(ε_model + √tr Σ_c) }（近零接触）；
- 抓取：A_σ = { f_n ∈ [f_min,f_max], ‖f_t‖ ≤ μ f_n, ‖τ_z‖ ≤ τ_z,max }；
- 推/擦：A_σ = { 接触方向锥 C_σ, 力区间 [f_min,f_max] }。
门控：ŵ_ext ∈ A_σ ⇒ κ=expected；ŵ_ext ∉ A_σ 且超出迟滞带 margin ⇒ κ=anomalous；迟滞带内 ⇒ κ=uncertain（不中止，仅记录）。

**新增定义 547（安全单调可行集 Safety Monotone Admissible Set）**
```
A_v10(t) = A_v9(t) ∩ { a : 力矩通道未判 anomalous }
```
故 A_v10 ⊆ A_v9。TRC 中立元：A_σ ≡ ℝ⁶（永不判 anomalous），于是 A_v10 = A_v9（严格等价 v9）。

**新增定义 548（快慢接触闭环 Contact-Aware Composition Loop）** 三时间尺度嵌套：组合规划 5Hz（块边界/接缝）→ 块证书 50Hz（20ms）→ 力矩残差 1kHz（<5ms）。仲裁：OR-中止（任一通道危险即停），按最小时延优先；停驻锁存，直到两通道均清除且重规划成功才恢复。

## 3. 关键算法骨架

```python
# IP-357 SkillComposer：可组合技能证书编排器
@dataclass
class SkillContract:
    name: str
    pre: Predicate; post: Predicate; inv: Predicate
    cert: CertBound                     # 软层指标界（v9 定义 533 语义）
    res: ResourceEnvelope               # (ms, workspace, force)
    w_exp: ContactSignature             # 定义 546
    comp_eligible: bool                 # φ^comp

class SkillComposer:
    def __init__(self, skills, seam_guards):
        self.skills, self.seams = skills, seam_guards

    def compose_sequence(self, s1, s2):
        G = self.seams[(s1.name, s2.name)]
        if not implies(s1.post, G) or not implies(G, s2.pre):
            return None                                 # 接缝不可覆盖 → 拒绝
        if not invariant_preserved(s1.inv, s2.inv, G):
            return None
        cert = transfer(s1.cert, s2.cert, G)            # 定义 542 区间传播
        return ComposedSkill(s1, s2, 'seq', G, cert,
                             w_sched=[s1.w_exp, s2.w_exp],
                             res=merge_res(s1.res, s2.res))

    def compose_parallel(self, s1, s2):
        if not disjoint(s1.res, s2.res):                 # 定义 541 资源不相交
            return None
        if not satisfiable(And(s1.inv, s2.inv)):
            return None
        if not superposition_consistent(s1.w_exp, s2.w_exp):
            return None                                 # 力旋量抵消会掩盖接触 → 拒绝
        return ComposedSkill(s1, s2, 'par', None,
                             combine(s1.cert, s2.cert),
                             w_exp=superpose(s1.w_exp, s2.w_exp))

    def compose_fallback(self, s1, s2):
        return ComposedSkill(s1, s2, 'fallback', None,
                             Or(s1.cert, s2.cert), w_sched=[s1.w_exp, s2.w_exp])

    def compose_interrupt(self, s1, s2, guard):
        if not can_abort_anytime(s1):                   # 中断须能随时安全停驻
            return None
        return ComposedSkill(s1, s2, 'interrupt', guard,
                             transfer(s1.cert, s2.cert, guard),
                             w_sched=[s1.w_exp, s2.w_exp])

    def build_plan(self, task_spec):
        # 规划期搜索算子树，仅保留 C_π valid 者；返回最优计划
        candidates = self._enumerate_operator_trees(task_spec)
        valid = [p for p in candidates if p.cert.valid]
        return max(valid, key=lambda p: p.utility, default=None)


# IP-358 TorqueResidualCertifier：力矩残差接触证书
class TorqueResidualCertifier:
    def __init__(self, model, K_O, Sigma_nu, eps_model, hz=1000):
        self.M, self.K_O = model, K_O
        self.Sigma_nu, self.eps = Sigma_nu, eps_model
        self.r = zeros(model.n); self.p_prev = None
        self.dt = 1.0 / hz

    def momentum_observer(self, q, qd, tau_meas):
        p = self.M.p(q, qd)                             # p = M(q) qd
        if self.p_prev is None:
            self.p_prev = p
        rhs = tau_meas + self.M.CT(q, qd) @ qd - self.M.g(q) + self.r
        self.r = self.K_O * (p - (self.p_prev + rhs * self.dt))
        self.p_prev = p
        return self.M.jacobian_T_pinv(q) @ self.r       # ŵ_ext

    def contact_certificate(self, w_ext, q):
        Sigma_c = self.M.propagate_cov(self.Sigma_nu)   # 定义 545
        margin = 2 * (self.eps + sqrt(trace(Sigma_c)))
        return ContactCert(w_ext, Sigma_c, norm(w_ext), margin)

    def intent_gate(self, cc, active_skill, state):
        A = active_skill.w_exp.accept_region(state)     # 定义 546
        if cc.w_ext in A:
            return 'expected'
        if cc.mag > A.margin + cc.margin:
            return 'anomalous'
        return 'uncertain'                              # 迟滞带：不中止

    def tick(self, q, qd, tau_meas, active_skill):
        w = self.momentum_observer(q, qd, tau_meas)
        cc = self.contact_certificate(w, q)
        kappa = self.intent_gate(cc, active_skill, q)
        if kappa == 'anomalous':
            return Abort(reason='contact', cert=cc)     # 定义 547：只收缩可行集
        return Continue(kappa, cc)
```

## 4. 推导

**引理 87（组合证书传递）** 设 σ1、σ2 均有效（C_σi valid、Inv_σi 全程保持），且接缝守卫 G 满足 Post_σ1 ⇒ G ⇒ Pre_σ2 且 Inv_{σ1}∧Inv_{σ2} 在接缝保持。则组合证书 C_{σ1∘σ2} 有效，且 Inv 在接缝处不断裂。证明：对边界状态归纳；每个子技能内部由归纳假设保证；唯一可能的不连续点在接缝，G 恰覆盖该点且区间传播的转移函数单调，故界不丢失。∎

**引理 88（并行组合可靠性）** σ1∥σ2 有效 ⇔ R_{σ1}∩R_{σ2}=∅ ∧ Inv_{σ1}∧Inv_{σ2} 可满足 ∧ 接触签名叠加不产生抵消性掩盖。则证书界由区间加法合成且安全保持。证明：资源不相交 ⇒ 无时序干扰（由 v9 引理 86 的 EDF 可行性逐行保证）；力旋量叠加线性 ⇒ 接触证书可加；叠加一致性排除"两力相消致净力为零而实际存在夹挤"的掩盖。∎

**引理 89（力矩接触可辨识界）** 设模型误差 ‖F̂−F‖≤ε、传感噪声协方差 Σ_ν，则 ‖ŵ_ext − w_true‖ ≤ ε + √tr Σ_c。接触被判 anomalous 可检出的充要下界：‖w_true‖ > 2(ε + √tr Σ_c) + margin_A。证明：三角不等式与协方差椭球传播；门控阈值分离即得。∎

**引理 90（安全单调性 / 不弱化）** A_v10(t)=A_v9(t)∩{力矩未判 anomalous}，故 A_v10⊆A_v9；v10 下任意可行轨迹在 v9 的守卫下亦可行，v9 引理 80–86 的安全性传递成立。TRC 中立元 A_σ≡ℝ⁶ ⇒ A_v10=A_v9。证明：集合包含关系；OR-中止只删除动作、从不新增动作。∎

**引理 91（组合退化等价）** SC 失效 ⇒ 扁平 PrimitiveGraph = v9；TRC 失效 ⇒ 中立元 = v9；算子失效 ⇒ 仅顺序 ∘ = v9 原语链；各行映射与 v9 可观测日志逐位一致。证明：构造逐行映射，中立元恒等性保证输出不变。∎

**引理 92（快慢通道无冲突 / OR-中止良构）** 力矩与视觉/块证书判定冲突时，OR-中止安全且不引入死锁：停驻被锁存，假阳性只降低可用性、不降低安全性；恢复需两通道均清除且重规划成功。证明：停驻集单调；锁存防抖；可用性损失由迟滞带与去抖上界界定。∎

**引理 93（接触盲区下界）** 持续接触且偏差 b(t) 仅在无接触相可辨识时，最小不可检出碰撞满足 ‖w_coll‖ ≤ |b| + 2(ε+√tr Σ_c)；若无接触时间占比 → 0，则盲区随 |b| 无界增长（偏差不可辨识）。证明：残差 = w_true + b + model_err + noise；b 不可观测时阈值必须超过 |b|；可辨识性要求激励或接触自由参考相。∎
