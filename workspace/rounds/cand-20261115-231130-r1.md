# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「避障控制」×「奖励设计」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**屏障安全 + 约束奖励 + 势垒耦合**。两个灵感分别治理 v9 的两种债：安全债（中止点集只做纯运动学刹车，忽略转向可逃逸性、动态障碍与离散采样，且硬安全仍间接受前向模型证书影响）、对齐债（奖励=手调加权和，ID 消融得分可被"删安全相邻模块"黑客，多目标不可解释）。必须通过**中立元退化链**保证任一新模块失效时严格退回 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（避障控制 → 鲁棒屏障安全滤波器）**
直觉：v9 的中止点集只回答"我能不能在直线上刹住"——这是纯运动学刹车模型，忽略了转向可逃逸性、动态障碍，以及离散时间采样本身的安全裕度。真正的避障控制不仅问"停得下吗"，还问"是否存在一个控制使系统永远留在安全集内"。核心创新：**鲁棒离散时间控制屏障函数安全滤波器（RobustBarrierFilter, RBF）**：把 M₀ 硬安全层从"几何刹车距离"升级为"屏障不变集"；每个块动作先经 RBF **最小修正投影**再执行；中止点集由**不变恢复集**定义。关键设计：RBF 只用**实时状态 + 有界扰动界 W**，完全不依赖前向模型——这恰好把 v9 的最大风险（证书在最需要时最不可靠）隔离在软性能层，硬安全对前向模型误差"免疫"。

**灵感 2（奖励设计 → 势函数奖励治理器）**
直觉：v9 的奖励与 ID 归因指标 J = 任务进展 − 安全罚，是一个手调加权和——这既是奖励黑客的温床（ID 可能"学到"让某个安全相邻模块休眠反而提高 J），又让多目标不可解释。奖励设计理论给出两条可直接落地的硬结果：势函数塑形（F=γΦ(s')−Φ(s)）保持最优策略集不变（Ng 等 1999）；CMDP 用拉格朗日对偶把安全变成**约束**而非罚项。核心创新：**势函数奖励治理器（PotentialRewardGovernor, PRG）**：控制奖励 = 任务项 + 势函数塑形（策略不变、无黑客），安全 = CMDP 约束（对偶变量 λ 自适应逼近"违背率 ≤ ε"）；而 ID 的**元奖励** = 受屏蔽的约束目标（meta-CMDP + action shield），从机制上禁止"以安全换分数"的休眠。

**灵感 3（综合：安全屏障即奖励势函数）**
直觉：若奖励势函数 Φ 就取作安全屏障 h 的饱和单调变换，则"趋向安全的动作自动获得正塑形、逼近边界的动作自动获得负塑形"，而势函数塑形的望远镜恒等式保证总回报只平移常数、最优策略不变。核心创新：**屏障-奖励耦合器（BarrierRewardCoupler, BRC）**：Φ(s)=log(h(s)+h₀)，使 AC 块评分、PRG 塑形、ID 消融归因共用**同一个安全证书**。关键洞察：塑形的**总量**经望远镜求和后退化为任务回报 + 常数（策略不变，故不黑任务）；但塑形的**逐步项**携带 ∇Φ=∇h/(h+h₀) 的屏障梯度，在边界附近自动放大——这正是 ID 做逐步信用分配所需的、与安全同向的信号。故"控制奖励用望远镜化 PBS、诊断归因用非望远镜化屏障均值"成为一条刻意的分工原则。

## 1. 研究问题（轮次升级版）

- **Q1（硬安全独立性）**：如何用鲁棒 DT-CBF 把 M₀ 硬安全与前向模型证书解耦，使"证书失效"在结构上不可能传染为"硬安全失效"？
- **Q2（可逃脱中止集）**：如何定义并高效计算"不变恢复集"作为中止点集，使其在动态障碍与转向约束下严格强于纯刹车集（P_t^CBF ⊇ P_t^brake），且在线可算？
- **Q3（奖励对齐）**：势函数塑形与 CMDP 对偶在 50Hz 在线场景下如何同时保证"策略不变 + 违背率 ≤ ε"，并使 ID 元奖励不可能通过休眠安全相邻模块获利？
- **Q4（势垒耦合）**：Φ=log(h+h₀) 的逐步梯度能否在不改变任务最优的前提下提升归因精度与安全裕度？逐步信用与望远镜总回报的分工边界在哪？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 屏障安全律（Robust Barrier Safety, RBF）**
安全集 C={h≥0}。执行前对标称动作做最小修正投影：a_safe=argmin‖a−a_nom‖² s.t. h(f(s,a))−(1−α)h(s)−L_h·W ≥ 0。仅用实时状态 s 与扰动界 W，**不用前向模型**。无可行动作时退最大制动（等价 v9 刹车语义）并置 degraded。RBF 是安全关键模块，φ^elig=false，永不蒸馏。

**P14 约束奖励律（Constrained Potential Reward, PRG）**
控制奖励 r'=r_task+γΦ(s')−Φ(s)，Φ 有界（策略不变）；安全以 CMDP 约束 E[viol]≤ε 承载，λ←[λ+η(viol−ε)]₊。ID 元奖励为**屏蔽后**的约束目标：任何使最坏屏障裕度下降超 δ_h 的休眠提案被 veto。PRG 的 λ 更新与 veto 属安全关键，φ^elig=false。

**P15 势垒耦合律（Barrier-Reward Coupling, BRC）**
Φ(s)=log(h(s)+h₀)。逐步塑形项提供 ∇h/(h+h₀) 的安全同向信用；望远镜恒等式保证总回报=任务回报+常数，故不改任务最优。AC 评分、PRG 塑形、ID 归因共享同一 h。**分工**：控制奖励走望远镜化 PBS（策略不变）；诊断归因走非望远镜化屏障均值（可辨安全轨迹差异）。

## 3. 与基线的接口（如何退化）

- RBF 失效/无解 ⇒ 退回 v9 刹车中止点集 P_t^brake 与中块守卫（仍满足 v9 引理 82）；
- PRG 失效 ⇒ Φ≡0、λ=0，奖励退回 v9 手调 J；
- BRC 失效 ⇒ Φ≡0，RBF 保持（用自身 h）、PRG 退化为无塑形，整体等价 v9；
- v9 ACMD 失效 ⇒ K_eff←1 与 MW 网关，退 v8；
- v8 的 DA/SPR/Cal 失效 ⇒ 中立元注入，退 v7；全失效退 v6。

## 4. 预期贡献

1. **硬安全与前向模型证书解耦**的鲁棒屏障滤波（v9 最大风险的结构性修复，引理 89）；
2. **不变恢复集**：把中止点从"刹得住"升级为"可逃逸/可维持"，覆盖动态障碍与转向约束（P_t^CBF ⊇ P_t^brake）；
3. **无黑客的奖励治理**：势函数塑形策略不变 + CMDP 约束 + 元屏蔽三层防线；
4. **屏障-奖励耦合**：同一 h 既做安全证书又做奖励势函数，逐步信用安全同向；并厘清"望远镜总回报 vs 非望远镜归因"的分工；
5. **状态相关域门控**：τ_dom(s)=τ_dom⁰·h/(h+h₀) 加屏障速率触发 ḣ<−θ_h，把 v9 的"20 帧滑窗滞后"在边界附近压到近零；
6. E571–E590 覆盖最小干预、动态避障、鲁棒性、可逃脱性、黑客压力、对偶收敛、耦合归因与端到端。

## 5. 本轮最大风险

**一句话**：鲁棒 CBF 的安全性依赖 Lipschitz 常数 L_h、扰动界 W 与离散步长的可靠上界——若真实扰动或模型失配超过 W（例如重载滑移、传感器突跳），屏障条件会在"看似安全"的状态上被违反；而 RBF 的保守性又可能过度制动导致任务停滞。即「把安全押在扰动界这一个标量上」。

## 1. 符号体系增量（定义 540–549）

**新增定义 540（鲁棒离散时间屏障函数 RDT-CBF）** 安全集 C={s:h(s)≥0}，h 连续、L_h-Lipschitz。离散系统 s_{k+1}=f(s_k,a_k)+w_k，‖w_k‖≤W。称 h 为 (α,W)-鲁棒屏障，若 ∀s∈C 存在 a 使
```
CBF(s,a) := h(f(s,a)) − (1−α)h(s) − L_h·W ≥ 0,   α∈(0,1]
```
成立。由 Lipschitz 性，h(s_{k+1}) = h(f(s_k,a_k)+w_k) ≥ h(f(s_k,a_k)) − L_h W ≥ (1−α)h(s_k) ≥ 0，故 C 前向不变。

**新增定义 541（屏障安全滤波器 RBF）** 对块策略给出的标称动作 a_nom，执行前求最小修正投影：
```
a_safe = argmin_{a∈A_local} ‖a − a_nom‖²   s.t.   CBF(s,a) ≥ 0
```
可行集空时 a_safe = a_brake(s)（最大制动，等价 v9 刹车语义）并置 safety_degraded=True 记事件。实现用 a_nom 邻域采样 + 局部一维线搜索（A_local 为可微/离散动作邻域）；性质见引理 88（安全内部零干预）。

**新增定义 542（不变恢复集 P_t^CBF）** 前缀索引 p ∈ P_t^CBF，若存在从 s_p 出发的候选控制序列 a^{p:K} 使 ∀k∈[p,K]，CBF(s_k,a_k) ≥ 0（用实时可达状态与扰动界估计）。计算为深度 K−p 的采样可行性检查，末端以最坏情形制动兜底：
```
P_t^CBF = { p : ∃ a^{p:K}, ∀k∈[p,K] CBF(s_k,a_k) ≥ 0 } ⊇ P_t^brake
```
刹停是不变控制的特例，故 P_t^CBF 严格包含 v9 的 P_t^brake；RBF 退化时只用 P_t^brake。

**新增定义 543（势函数奖励塑形 PBS）**
```
r'(s,a,s') = r_task(s,a) + γΦ(s') − Φ(s),   Φ 有界
```
策略不变性见引理 90。r_task 继承 v9 的 GCT/ER 复合奖励（含情感项）；ER 只作用于 r_task，不触碰约束项。

**新增定义 544（约束 MDP 与对偶更新 CMDP）**
```
max_π  E[Σ γ^k r'_k]    s.t.  E[Σ γ^k c_k] ≤ ε,  c_k = 1{ h(s_k) < 0 }
L(π,λ) = E[Σ r'] − λ( E[Σ c] − ε ),   λ ← [λ + η(viol − ε)]₊
```
λ 进入执行奖励：r_exec = r' − λ·c。约束收敛性见引理 92。

**新增定义 545（屏障-奖励耦合 BRC）**
```
Φ(s) = log( h(s) + h₀ ),   h₀ > 0
逐步塑形项 b_k = γ[ log(h(s_{k+1})+h₀) − log(h(s_k)+h₀) ]
∇Φ(s) = ∇h(s) / (h(s)+h₀)   →  h→0 时 |∇Φ| 发散（边界附近强信用）
```
望远镜消去见引理 91：总塑形回报 = 任务回报 + 常数。

**新增定义 546（元屏蔽 Veto Shield）** ID 提出的休眠集合 S_dorm 被 veto 当且仅当存在 s∈C 使
```
h_full(s) − h_{S_dorm}(s) > δ_h
```
其中 h_{S_dorm} 为休眠 S_dorm 后（各自注入中立元）的最坏屏障裕度。ID 只能在 A_safe = {S_dorm : veto 条件不成立} 内选择；φ^elig=false 的模块（RBF/PRG/λ/veto 自身/M₀ 硬检查/SpatialCert/FaultCert/MW/AC 证书检查）永不在候选内。

**新增定义 547（状态相关域阈值 τ_dom(s)）**
```
τ_dom(s) = τ_dom⁰ · h(s) / (h(s) + h₀)
```
h→0（贴边界）时 τ_dom(s)→0（检测最敏感，任何偏移即触发）；h 大（安全内部）时 τ_dom(s)→τ_dom⁰（宽松，避免虚假退化）。

**新增定义 548（安全敏感域偏移与屏障速率联合门控）**
```
放大偏移：  Δ_dom^h(t) = Δ_dom(t) · (1 + h₀ / h(s_t))
屏障速率：  ḣ(t) = (h(s_t) − h(s_{t−1})) / Δt
门控：      U_t = { Δ_dom^h < τ_dom⁰  ∧  risk_SLAM < τ_SLAM  ∧  ḣ ≥ −θ_h }
```
若 ḣ < −θ_h，则**绕过 20 帧滑窗**立即 K_eff←1 并强制全模块唤醒（零窗延迟）。这把 v9 的"20 帧滞后"在边界突变处替换为屏障速率触发（引理 95）。

**新增定义 549（屏障信用归因得分）** 对模块 m 的消融归因（仅 φ^elig 模块）：
```
J_abl(m) = Δtask_progress(m) + κ · Δ mean_k[ log(h_m(s_k)+h₀) ],   κ > 0
```
注意：此处**刻意不望远镜化**——总塑形回报经望远镜后与策略无关（引理 91），无法区分策略；因此归因必须用逐步屏障均值以捕捉安全轨迹差异。控制奖励（影响动作）与诊断归因（影响休眠）使用不同口径，是本轮明确的分工原则。

## 3. 关键算法骨架

```python
# IP-357 RobustBarrierFilter：鲁棒屏障安全滤波器
class RobustBarrierFilter:
    def __init__(self, h, f, alpha=0.2, L_h=1.0, W=0.02, h0=0.1, theta_h=0.05):
        self.h, self.f = h, f            # h: 屏障函数；f: 名义一步动力学
        self.alpha, self.L_h, self.W = alpha, L_h, W
        self.h0, self.theta_h = h0, theta_h

    def cbf(self, s, a):
        return self.h(self.f(s, a)) - (1 - self.alpha) * self.h(s) - self.L_h * self.W

    def filter(self, s, a_nom, a_brake):
        """最小修正投影；返回 (a_safe, degraded)"""
        best = None
        for a in self._local_neighborhood(a_nom):          # 邻域采样/线搜索
            if self.cbf(s, a) >= 0:
                d = norm(a - a_nom)
                if best is None or d < best[0]:
                    best = (d, a)
        if best is None:
            return a_brake(s), True                        # 等价 v9 刹车语义
        return best[1], False                              # 安全内部零干预（引理 88）

    def recovery_set(self, s, actions, pred, n_sample=32):
        """不变恢复集 P_t^CBF（定义 542），末端制动兜底"""
        P = []
        for p in range(1, len(actions)):
            if self._viable(s, actions[p:], pred, n_sample):
                P.append(p)
        return P or [len(actions) - 1]                     # 至少保留末端

    def rate_trigger(self, h_prev, h_now, dt):
        return (h_now - h_prev) / dt < -self.theta_h       # 零窗延迟触发（定义 548）

# IP-358 PotentialRewardGovernor：势函数奖励治理器
class PotentialRewardGovernor:
    def __init__(self, Phi, gamma=0.99, eps=0.01, eta=0.01, lam=0.0):
        self.Phi, self.gamma = Phi, gamma
        self.eps, self.eta, self.lam = eps, eta, lam

    def shape(self, s, a, s_next, r_task):
        return r_task + self.gamma * self.Phi(s_next) - self.Phi(s)   # PBS（定义 543）

    def update_dual(self, viol_est):
        self.lam = max(0.0, self.lam + self.eta * (viol_est - self.eps))

    def exec_reward(self, s, a, s_next, r_task):
        return self.shape(s, a, s_next, r_task) - self.lam * self._viol(s_next)

# IP-359 BarrierRewardCoupler：屏障-奖励耦合器 + 元屏蔽
class BarrierRewardCoupler:
    def __init__(self, h, h0=0.1, delta_h=0.02, kappa=1.0):
        self.h, self.h0, self.delta_h, self.kappa = h, h0, delta_h, kappa

    def Phi(self, s):
        return math.log(self.h(s) + self.h0)               # 定义 545

    def credit(self, h_prev, h_next):
        return self.kappa * (math.log(h_next + self.h0)
                             - math.log(h_prev + self.h0))

    def tau_dom(self, s, tau_dom0):
        return tau_dom0 * self.h(s) / (self.h(s) + self.h0)   # 定义 547

    def veto(self, proposal_modules, margin_fn):
        """元屏蔽（定义 546）：休眠若降最坏屏障裕度超 δ_h 则否决"""
        h_full = margin_fn(active=ALL_MODULES)
        h_prop = margin_fn(active=ALL_MODULES - set(proposal_modules))
        return (h_full - h_prop) > self.delta_h

    def attribution(self, d_task, h_traj):
        return d_task + self.kappa * mean(
            math.log(x + self.h0) for x in h_traj)          # 定义 549（非望远镜）

# 主闭环集成：MetricVoiceGauge-BARD
def metricvoicegauge_round_10(M, s, obs, audio_stream=None, ell=None, ...):
    ctx = mw_default_ctx()
    # ---- MW 驱动感知侧（v9 不变）----
    results = middleware.run_cycle(runners={
        'DA_ML': lambda c: domain_adapter.update_and_measure(obs),
        'SPR':   lambda c: slam_risk.compute(M.slam_backend.get_latest_state()),
        'CAL_FI':lambda c: calib_fi.get_weights_kappa(),
        'OTL':   lambda c: online_learner.update_and_thresholds(c),
    }, ctx=ctx)

    # ---- 状态相关门控（定义 547/548）：屏障敏感 + 速率触发 ----
    h_now = barrier.h(s)
    tau_dom_s = coupler.tau_dom(s, M.tau_dom)
    delta_dom_h = results['DA_ML'] * (1 + coupler.h0 / max(h_now, 1e-6))
    rate_bad = rbf.rate_trigger(ctx.h_prev, h_now, M.dt)
    trust_ok = (delta_dom_h < M.tau_dom
                and results['SPR'] < M.tau_slam and not rate_bad)

    # ---- 5Hz 块生成（受 ID 状态影响候选池）----
    if current_chunk is None or current_chunk.exhausted:
        current_chunk = chunker.generate_chunk(
            s, delta_dom_h, M.tau_dom, trust_ok=trust_ok,
            score_fn=lambda cand, pred: policy_score(cand, pred)
                                        + coupler.Phi(pred.s_end))   # BRC 评分

    # ---- 执行前 RBF 投影（硬安全，不依赖前向模型；引理 89）----
    a_nom = current_chunk.actions[k_exec]
    a_safe, degraded = rbf.filter(s, a_nom, a_brake)
    if degraded:
        log_degraded('RBF', s); current_chunk = None

    # ---- 50Hz 中块守卫：不变恢复集（定义 542）----
    verdict, k_next = chunker.midchunk_guard(
        current_chunk, k_exec, live_obs, recovery_set=rbf.recovery_set(s, ...))
    execute(a_safe if verdict == 'continue'
            else current_chunk.execute_safe_stop_at(k_next))

    # ---- v9 继承路径 + PRG 奖励（定义 543/544）----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v9_path(ctx)
    r_task = rewards
    r_exec = prg.exec_reward(s, a_safe, s_next, r_task)
    prg.update_dual(viol_est=ema_violation(metrics))

    # ---- ID 归因与状态迁移（BRC 屏障信用 + 元屏蔽 veto）----
    proposal = distiller.propose(cycle_idx, ctx)
    if not coupler.veto(proposal, margin_fn=worst_case_margin):
        distiller.commit(proposal)                # 否则保持 v9 全模块常开
    distiller.attribute_with(coupler.attribution) # 定义 549
    return C, spatial_cert, claims, metrics, r_exec
```

## 4. 推导

**引理 87（RBF 归纳安全性）** 设 s_0∈C 且每步 a_k=a_safe 满足 CBF(s_k,a_k)≥0、扰动 ‖w_k‖≤W。则 ∀k，h(s_k)≥0。证明：由 L_h-Lipschitz，h(s_{k+1})=h(f(s_k,a_k)+w_k)≥h(f(s_k,a_k))−L_h W；由 CBF(s_k,a_k)≥0 得 h(f(s_k,a_k))≥(1−α)h(s_k)+L_h W，故 h(s_{k+1})≥(1−α)h(s_k)≥0（归纳）。∎

**引理 88（最小干预/安全内部透明）** 若 a_nom 满足 CBF(s,a_nom)≥0，则 a_safe=a_nom（零修正）；一般地 a_safe 是可行集在欧氏范数下距 a_nom 最近的点。证明：可行集非空时投影定义为最近点，a_nom 可行则到自身距离 0 为最小。∎ 故 RBF 在安全内部不改变 v9 任务行为，只在将违约时介入。

**引理 89（硬安全对前向模型证书的独立性）** RBF 的不变保证只依赖 (s_k,a_k,h,L_h,W)，不含块证书 Ĉ_t 或前向模型 F̂。故即使 Ĉ_t 失效且 K_eff 取大，只要 RBF 每步生效，硬安全不变式仍成立。证明：引理 87 的前提中无 F̂ 项；CBF 仅调用 h∘f 与实时 s。∎ 这直接修复 v9 最大风险：软性能证书失效不再传染硬安全。

**引理 90（势函数塑形策略不变性）** 对任意 MDP，若 Φ 有界，则 r'=r+γΦ(s')−Φ(s) 不改变最优策略集。证明（望远镜）：沿轨迹 Σ_{k=0}^{T} γ^k(γΦ(s_{k+1})−Φ(s_k)) = γ^{T+1}Φ(s_{T+1}) − Φ(s_0)；γ<1 且 Φ 有界时末项 → 与策略无关的常数 −Φ(s_0)，故 argmax_π 不变。∎

**引理 91（屏障势耦合的零总偏置与强逐步信用）** 取 Φ=log(h+h₀)（h 有界 ⇒ Φ 有界），塑形总回报 = 任务回报 − Φ(s_0) + o(1)，最优策略不变；而逐步项 b_k=γ[log(h_{k+1}+h₀)−log(h_k+h₀)]，因 ∇Φ=1/(h+h₀)，在 h→0 时 |b_k| 增大，提供边界附近的强安全信用。∎

**引理 92（CMDP 对偶约束满足）** 在标准假设（有界奖励/代价、衰减步长 Ση=∞,Ση²<∞、Slater 条件、违背估计一致）下，对偶更新 λ←[λ+η(viol−ε)]₊ 收敛到 λ*，且 E[Σc]→≤ε+δ（δ 为估计误差）。证明：标准约束 MDP 的对偶鞍点收敛（Borkar 随机逼近 + 鞍点定理）；λ 的有界性由投影步保证。∎

**引理 93（元屏蔽防奖励黑客）** ID 的动作被限制在 A_safe={S_dorm : h_full−h_{S_dorm} ≤ δ_h}，且 φ^elig=false 的安全模块永不在候选内。故任何被执行的休眠提案使最坏屏障裕度下降 ≤δ_h；ID 无法通过休眠"以安全换分数"，其可达目标空间被裁剪为与安全正交的子空间。∎

**引理 94（退化与 v9 逐位等价）** RBF 无解时 a_safe=a_brake、P_t=P_t^brake、τ_dom(s)=τ_dom⁰ ⇒ 与 v9 中止与门控语义逐位一致；PRG 失效置 Φ≡0,λ=0 ⇒ r_exec=r_task=v9 奖励；BRC 失效置 Φ≡0 ⇒ 无塑形、ID 用 v9 得分、屏障门控退常数。各端口读数与 v9 对应退化级一致。∎

**引理 95（屏障敏感门控的提前触发）** 由定义 547/548，有效偏移信号 Δ_dom^h=Δ_dom·(1+h₀/h)。若真实分布跳变使模型误差在 h→0 处增大，则 Δ_dom^h 至少以 1/h 放大，故存在 h_临 使 h<h_临 时提前越阈（K_eff=1、全唤醒）；此外 ḣ<−θ_h 触发**完全绕过** 20 帧滑窗。故边界突变的检测延迟由 min(滑窗滞后, 屏障速率响应) 决定，最坏情形降至单步。∎（注：远离边界时仍受 20 帧窗限制，这是诚实边界。）

## 8. 本轮最大风险

**一句话**：鲁棒 CBF 的安全性依赖 Lipschitz 常数 L_h、扰动界 W 与离散步长的可靠上界——若真实扰动或模型失配超过 W（例如重载滑移、传感器突跳），屏障条件会在"看似安全"的状态上被违反；而 RBF 的保守性又可能过度制动导致任务停滞。即「把安全押在扰动界这一个标量上」。
