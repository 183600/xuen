### 第 4 轮灵感驱动研究记录

**灵感词**：地形适应、力矩传感

**继承关系**：第 3 轮 CADVS-v3（IP-485~488）在 v2 三锚点（空间 3DCF / 物理 MSRG / 人因 HICK）之上追加了末点锚 EEK（EEC，kc_ee）与记忆锚 LTEM（kc_mem），并以 FFA 联邦校准做慢时域先验，形成五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem，执行集 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v3，而是补上两个此前被当作常量的维度：**支撑地形**与**全身力矩预算**，形成 CADVS-v4（IP-489~492），执行集嵌套升级为 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **地形适应：把「规则成立的默认地面」变成「被证书化的地形域 + 迁移界」**。v3 的 kc_coverage 回答「目标附近是否被观测」，kc_physics 回答「规则在 MuJoCo 默认地形上是否成立」，kc_ee 回答「此刻末端接触是否真实」。但一条规则从平地迁移到斜坡/碎石/泡沫/冰面/可变形地面时，重力项、接触法向、摩擦锥与基座反作用都改变，同一条「已认证」规则会在地形切换处静默失效。关键在于：地形适应不能只是分类器给地形贴标签，而要给出**动力学迁移残差上界**——若查询地形与最近已认证地形的参数偏移经闭环收缩后仍小于容差，则 S2RC 可迁移；否则必须重铸（在地形上重跑 MSRG）或降级到保守步态。引入地形证书 TC 与硬门 kc_terrain。

2. **力矩传感：把「末端一点的证据」升级为「整条运动链的本体证据」**。v3 的 EEC 只用腕部力/力矩与触觉。关节力矩是全身本体感觉：经广义动量观测器可估计外部接触 wrench、定位接触、检测冲击，并在地形探测期反演摩擦系数 μ 与柔顺 κ。力矩因而同时是**新证据通道**（kc_torque）与**地形辨识仪器**（PTI）。但力矩反演依赖精确动力学模型，这是一个新的认识论依赖，必须与 EEC 做交叉一致性校验，避免同一物理量被两套模型重复计信。

3. **耦合与循环风险：地形辨识与力矩包络互为输入**。PTI 用力矩反演地形参数 ξ，TAK 用 ξ 判定迁移；同时地形（坡度/摩擦）又决定力矩预算与重力补偿。这个「力矩→地形→力矩」的闭环若共用同一套动力学模型，就会把模型误差重复放大。故 v4 显式要求：PTI 与 TAK 的模型参数来源分离（一个来自离线多地形辨识，一个来自在线观测），不可辨识时一律 fail-closed，而非用模型先验填补。

**关键洞见**：v3 回答「末端此刻是否真实」；v4 追加地形锚回答「脚下这块地是否就是被认证的那块地、偏移是否仍被迁移界覆盖」（TC / kc_terrain），追加力矩锚回答「整条链的外部力矩、力矩储备与冲击是否仍在包络内」（τ_ext / kc_torque），并让力矩成为地形辨识的本体通道。七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_terrain ∧ kc_torque，fail-closed；软评分 ECS_v4 仅用于回退分级与仪表盘，不参与安全决策。

**形式化目标（增量）**：
1. 定义地形状态 ξ = (α 坡度, ρ 粗糙度 RMS, κ 柔顺, μ 摩擦, h 障碍高度)，地形证书 TC = (ξ, Σ_ξ 不确定度, fp, t)，及硬门 kc_terrain = (TC.fp ∈ Ξ_cert) ∨ (r_T(ξ, ξ_c) ≤ δ_T ∧ ‖ξ − ξ_c‖ ≤ R_cov)，其中 r_T 为闭环迁移残差上界。
2. 定义闭环迁移残差 r_T = c_L·L_ξ·‖ξ − ξ_c‖/λ + ε_model：L_ξ 为动力学对 ξ 的 Lipschitz 常数，λ 为闭环收缩率，c_L 为状态转移范数界；即地形偏移经收缩后仍是可界定的状态偏差。
3. 定义力矩证书 τ_ext（广义动量观测器残差）与硬门 kc_torque = (‖τ_ext − τ_des‖ ≤ τ_tol) ∧ (|τ_m| ≤ (1−β_res)τ_max) ∧ (¬impact) ∧ (‖Jᵀτ_ext − f_contact‖ ≤ δ_cons)；最后一项强制力矩证据与 v3 的 EEC 交叉一致。
4. 定义本体地形辨识器 PTI：由接触 wrench 反演 μ̂ = ‖f_t‖/f_n、κ̂ = Δf_n/Δδ，并以回归矩阵最小奇异值判可辨识性；不可辨识输出 UNIDENTIFIED，TAK 不得用模型先验替代。
5. 定义 EFA-v4 七硬门与软评分 ECS_v4(x,t,r) = ECS_v3(x,t,r) · η_terrain · η_torque，η_terrain, η_torque ∈ [0,1] 仅用于分级。
6. 定义 Exec_CADVS-v4 ⊆ Exec_CADVS-v3：在 v3 每条路径上再追加 kc_terrain（准入/地形切换时）与 kc_torque（控制环内每周期），故只缩不涨。

**本轮最大风险**：**地形迁移界与力矩观测器共用同一套可能在真实地形上失配的动力学模型，形成自证循环**——TAK 用仿真标定的 Lipschitz 常数证明「迁移安全」，PTI 又用同一模型从力矩反演 μ/κ，一旦真实地形存在未建模的松软、回弹或未知负载，两者会同时给出偏乐观的证书，把「没见过的地形」误判为「已认证地形」。

## 2. 关键算法骨架

### IP-489 TAK：地形证书与闭环迁移界（准入/地形切换时，O(|Ξ_cert|) 或 KD-tree O(log n)）

```python
@dataclass
class TerrainAdaptationKernel:
    """TAK：地形域证书 + 闭环迁移残差；kc_terrain 硬门。只界动力学偏移，不做地形分类。"""
    L_xi: float = 1.5            # 动力学对 ξ 的 Lipschitz 常数（离线多地形辨识）
    lam: float = 2.0             # 闭环收缩率 λ > 0
    c_L: float = 1.0             # 状态转移范数界
    delta_T: float = 0.02        # 迁移残差容忍（归一化）
    eps_model: float = 0.01      # 模型残差底噪
    R_cov: float = 0.25          # 地形覆盖半径（归一化参数空间）

    def observe(self, slope, roughness, compliance, mu, obstacle_h,
                sigma_xi, t_now) -> TC:
        """ξ 由视觉/激光 + 足端/末端触地估计；σ_xi 为参数不确定度"""
        xi = np.array([slope, roughness, compliance, mu, obstacle_h])
        fp = self._fingerprint(xi, sigma_xi)
        return TC(xi=xi, Sigma=sigma_xi, fp=fp, t=t_now)

    def transfer_residual(self, xi_q: np.ndarray, xi_c: np.ndarray) -> float:
        """引理 41：地形偏移经闭环收缩后的状态偏差上界"""
        d = np.linalg.norm(self._normalize(xi_q) - self._normalize(xi_c))
        return self.c_L * self.L_xi * d / self.lam + self.eps_model

    def kc_terrain(self, tc: TC, xi_cert: dict) -> tuple[bool, float]:
        """已认证地形直接过；否则要求最近邻在覆盖半径内且迁移残差达标"""
        if tc.fp in xi_cert:
            return True, 0.0
        xi_c = self._nearest(tc.xi, xi_cert)          # KD-tree，O(log n)
        if xi_c is None:
            return False, np.inf                       # 空认证集：fail-closed
        d = np.linalg.norm(self._normalize(tc.xi) - self._normalize(xi_c))
        if d > self.R_cov:
            return False, np.inf                       # 域外：不可迁移
        r = self.transfer_residual(tc.xi, xi_c)
        return (r <= self.delta_T), r

    def _fingerprint(self, xi, sigma_xi) -> str:
        """地形指纹对不确定度做量化，防止把高不确定度当已知地形"""
        return hashlib.sha1(np.round(xi / np.maximum(sigma_xi, 1e-6)).tobytes()).hexdigest()
```

**设计要点**：kc_terrain 的「通过」不是「地形标签相似」，而是「最近邻已认证地形 + 偏移经闭环收缩后状态偏差 ≤ δ_T」。地形不确定度进入指纹量化：σ_ξ 越大，指纹越不可能与已有条目相同，从而自动趋向重铸而非误迁移。

### IP-490 TSCK：广义动量观测器与力矩包络（控制环内，O(n²) 质量阵乘，n=关节数）

```python
@dataclass
class TorqueSensingContactKernel:
    """TSCK：全身外部力矩估计 + 力矩预算 + 冲击检测 + 与 EEC 交叉一致"""
    K_O: float = 50.0            # 动量观测器增益
    tau_tol: float = 3.0         # N·m，外部力矩残差容忍
    beta_res: float = 0.15       # 力矩储备比例
    delta_cons: float = 8.0      # N，力矩-力交叉一致性容忍
    impact_thresh: float = 30.0  # N·m/ms，冲击导数阈值

    def __post_init__(self):
        self.p_hat = None        # 动量观测器内部状态，跨周期持久化

    def momentum_observer(self, q, dq, tau_m, M, C, g, dt) -> np.ndarray:
        """标准广义动量观测器：p = M(q)q̇；p̂̇ = τ_m + Cᵀq̇ − g + r；r = K_O(p − p̂)
        稳态 r → τ_ext；误差动力学 ṙ = K_O(τ_ext − r) + K_O·e_model（引理 42）"""
        p = M(q) @ dq
        if self.p_hat is None:
            self.p_hat = p.copy()
        r = self.K_O * (p - self.p_hat)
        p_dot = tau_m + C.T @ dq - g + r
        self.p_hat = self.p_hat + dt * p_dot
        return r                  # ≈ τ_ext

    def kc_torque(self, tau_ext, tau_des, tau_m, tau_max,
                  f_contact, J, tau_ext_prev, dt) -> tuple[bool, str]:
        """引理 42：外部力矩在容忍内 + 力矩预算 + 无冲击 + 与 EEC 一致"""
        if np.linalg.norm(tau_ext - tau_des) > self.tau_tol:
            return False, 'TORQUE_DEVIATION'
        if np.any(np.abs(tau_m) > (1.0 - self.beta_res) * tau_max):
            return False, 'TORQUE_BUDGET'
        impact = np.any(np.abs(tau_ext - tau_ext_prev) / max(dt, 1e-6) > self.impact_thresh)
        if impact:
            return False, 'IMPACT'
        if np.linalg.norm(J.T @ tau_ext - f_contact) > self.delta_cons:
            return False, 'CONSISTENCY'      # 力矩与腕部 F/T/触觉不一致：拒绝双重计信
        return True, 'OK'
```

**设计要点**：交叉一致性项 ‖Jᵀτ_ext − f_contact‖ ≤ δ_cons 是本模块与 v3 EEK 的「防重复计信」接口。若两套独立通道对同一接触给出矛盾结论，说明至少一套模型失配，直接 fail-closed，而不是取平均。

### IP-491 PTI：本体地形辨识与可辨识性（慢于控制环，触地/探测期触发）

```python
@dataclass
class ProprioceptiveTerrainIdentifier:
    """PTI：由接触 wrench 反演 μ、κ；不可辨识时返回 UNIDENTIFIED，禁止模型先验替代"""
    f_n_min: float = 5.0         # 法向力下限，低于此不辨识
    sigma_min: float = 0.10      # 回归矩阵最小奇异值阈值（激励充分性）

    def identify(self, tau_ext_seq, J_seq, base_motion, t) -> TerrainEstimate:
        """μ̂ = ‖f_t‖/f_n；κ̂ 由法向力-法向位移回归；可辨识性由回归矩阵奇异值判定"""
        F = np.array([J.T @ tau for tau, J in zip(tau_ext_seq, J_seq)])   # 足端/末端 wrench
        f_n = F[:, 2]
        f_t = np.linalg.norm(F[:, :2], axis=1)
        mask = f_n > self.f_n_min
        if mask.sum() < 3:
            return TerrainEstimate(UNIDENTIFIED, reason='INSUFFICIENT_CONTACT')
        mu_hat = float(np.median(f_t[mask] / f_n[mask]))
        # κ̂：法向力对法向位移的斜率（位移由 base_motion 与足端雅可比积分给出）
        Phi = self._compliance_regressor(f_n[mask], base_motion)
        sigma_min = np.linalg.svd(Phi, compute_uv=False).min()
        if sigma_min < self.sigma_min:
            return TerrainEstimate(UNIDENTIFIED, reason='POOR_EXCITATION')
        kappa_hat = float(np.linalg.lstsq(Phi, f_n[mask], rcond=None)[0][0])
        return TerrainEstimate(mu_hat, kappa_hat, IDENTIFIED, sigma_min)

    def to_terrain_state(self, est: TerrainEstimate, tc: TC) -> TC:
        """辨识成功则用 μ̂/κ̂ 覆盖 TC 中对应分量并收紧不确定度；失败则保持原不确定度"""
        if est.status is UNIDENTIFIED:
            return tc.replace(Sigma=tc.Sigma * 1.5)   # 不确定度增大 → 更易触发重铸
        return tc.replace(xi=tc.xi_with(mu=est.mu, kappa=est.kappa),
                          Sigma=tc.Sigma * 0.5)
```

**设计要点**：PTI 的失败不是「用默认 μ=0.5 兜底」，而是**放大 TC 的不确定度**。这会让 TAK 的指纹更难命中、迁移残差更难达标，自然收敛到「重铸或保守模式」，从机制上避免用先验掩盖未知。

### IP-492 EFA-v4：七硬门 + 软评分 + 证据铸造流水线 v4

```python
@dataclass
class EvidenceForgingAssemblerV4:
    """EFA-v4：七硬门 fail-closed；软评分仅分级，不参与安全决策"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict                       # rule_id -> S2RC（含 terrain_fp）

    xi_cert: dict                          # terrain_fp -> ξ
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec: EEC, tc: TC,
                  tau_ext, tau_des, tau_m, tau_max, f_contact, J,
                  tau_ext_prev, dt, object_class, geo_sig, theta_domain_fp
                  ) -> tuple[bool, str]:
        if self.hic.veto_active(hic):                 return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):        return False, 'COVERAGE_BLIND'

        # 地形先于物理：物理成立性依赖地形域
        ok_t, r_T = self.tak.kc_terrain(tc, self.xi_cert)
        if not ok_t:                                  return False, 'TERRAIN_UNTRANSFERABLE'

        s2rc = self.msrg_cache.get(rule_id)
        if (s2rc is None or s2rc.verdict != 'accept'
                or s2rc.mu_pass < self.mu_S
                or not self._terrain_compatible(s2rc, tc)):   # S2RC 地形域须覆盖 tc
            return False, 'PHYSICS_UNPROVEN'

        if not self.eek.kc_ee(eec):                   return False, 'EE_UNPROVEN'
        pass_mem, eta_mem, novelty = self.ltem.query(
            object_class, geo_sig, theta_domain_fp + '|' + tc.fp, rule_id)
        if not pass_mem:                              return False, 'MEMORY_REJECT'

        ok_tau, why = self.tsck.kc_torque(
            tau_ext, tau_des, tau_m, tau_max, f_contact, J, tau_ext_prev, dt)
        if not ok_tau:                                return False, 'TORQUE_' + why
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def _terrain_compatible(self, s2rc, tc: TC) -> bool:
        """S2RC 的 terrain_fp 必须等于 tc.fp，或 tc 在 s2rc 的地形迁移域内"""
        return s2rc.terrain_fp == tc.fp or s2rc.transfer_residual <= self.tak.delta_T

    def ecs_v4(self, x, t_now, rule_id, A_att=0.0,
               eta_mem=0.5, eta_terrain=0.5, eta_torque=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        return base * eta_mem * eta_terrain * eta_torque
```

## 4. 正确性论证（增量更新）

### 引理 41（地形迁移残差的闭环界）

**陈述**：设闭环误差动力学 δq̇ = A δq + B Δξ，A 为 Hurwitz 且 ‖e^{At}‖ ≤ c_L e^{−λt}（λ>0）；地形相关项满足 ‖B Δξ‖ ≤ L_ξ‖Δξ‖。则对任意任务时域 t ≥ 0，状态偏差满足 ‖δq(t)‖ ≤ c_L·L_ξ·‖Δξ‖/λ。若该上界 ≤ δ_T 且 ‖Δξ‖ ≤ R_cov，则已认证地形 ξ_c 上的 S2RC 迁移到 ξ 后，状态偏差仍在容忍带内。

**证明**：由变常数公式 δq(t) = ∫₀ᵗ e^{A(t−s)}B Δξ ds，取范数并代入指数界得 ‖δq(t)‖ ≤ c_L L_ξ‖Δξ‖ ∫₀ᵗ e^{−λ(t−s)}ds ≤ c_L L_ξ‖Δξ‖/λ。∎

**工程含义**：kc_terrain 界的是「迁移后的状态偏差」，而不是「地形标签相似度」。这使地形适应从分类问题变成可控的鲁棒性判据；代价是 L_ξ、λ、c_L 必须离线多地形辨识（见风险 R46/R48）。

### 引理 42（动量观测器的收敛与检测延迟）

**陈述**：设模型误差有界 ‖e_model‖ ≤ ē，观测器增益 K_O>0。则外部力矩估计误差 e_τ = τ_ext − r 满足 ė_τ = −K_O e_τ + K_O e_model，故 ‖e_τ(t)‖ ≤ e^{−K_O t}‖e_τ(0)‖ + ē。给定冲击检测阈值 τ_imp 与力矩变化率 ρ，检测延迟 ≤ (1/K_O)ln(‖e_τ(0)‖/(τ_imp−ē))；若 ē ≥ τ_imp 则无法可靠检测（不可辨识）。

**证明**：标准一阶误差动力学，直接积分；检测延迟由误差包络首次超过阈值的时间给出。∎

**工程含义**：力矩门把「接触是否真实」从腕部单点扩展到整链，但其可靠性以模型误差 ē 为上界；这为 R47 与「交叉一致性」提供理论依据：当 Jᵀτ_ext 与 EEC 的 f_contact 冲突时，说明 ē 已不可忽略。

### 引理 43（地形参数的本体可辨识性）

**陈述**：由接触 wrench 反演 μ = ‖f_t‖/f_n 与 κ（法向力-位移斜率）时：(a) μ 可辨识当且仅当 f_n > f_n,min（存在法向接触）；(b) κ 可辨识当且仅当柔顺回归矩阵 Φ 满秩（σ_min(Φ) ≥ σ_min），即法向激励充分；(c) 若 (a) 或 (b) 不成立，则任何有限样本估计的置信区间无界，必须输出 UNIDENTIFIED，且不得以模型先验替代。

**证明**：(a) μ 是比值，f_n→0 时分母趋零、方差爆炸；(b) 最小二乘可辨识性等价于回归矩阵满秩，σ_min 给出条件数界；(c) 秩亏时解不唯一，置信椭球沿零空间无界。∎

**工程含义**：PTI 的 UNIDENTIFIED 通过放大 TC 不确定度触发重铸/保守，从机制上阻断「用先验假装已知地形」的自证。

### 定理 v4（执行集收缩与七锚点补全）

**陈述**：在以下假设下：(B1) 末点传感器与关节力矩传感器噪声模型成立；(B2) LTEM 表忠实反映历史执行结果；(B3) FFA 联邦先验与实机舰队分布无系统性偏离；(B4) 继承 v3 的 (A1′)~(A3′)；(B5) TAK 的 L_ξ、λ、c_L 在查询地形所属参数域内为有效上界。则：
(i) Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29（严格收缩）；
(ii) 地形迁移后的状态偏差由引理 41 界定，kc_terrain 通过 ⟹ 偏差 ≤ δ_T；
(iii) 外部力矩估计误差与冲击检测延迟由引理 42 界定；
(iv) 地形参数仅在引理 43 的可辨识条件下进入证书，否则 fail-closed；
(v) 七硬门 fail-closed，任一不通过即拒，仅 HIC veto 旁路至 S_stop。

**证明**：(i) v4 在 v3 每条路径上追加 kc_terrain（准入/切换）与 kc_torque（每周期），故只缩不涨；严格性由 v3 未检查的地形迁移失效与力矩预算/冲击失效处关闭路径保证。(ii)~(iv) 分由引理 41、42、43。(v) 由 EFA-v4 hard_gate 的合取结构。∎

**诚实声明**：(B5) 是 v4 最脆弱假设——L_ξ 与 λ 在仿真/有限地形上标定，真实地形的未建模松软、回弹、颗粒流会使其低估偏移；更严重的是 TAK、PTI、TSCK 共用同一套动力学模型，模型误差可能被三者同时低估（见 R48）。缓解：多地形离线辨识 + 在线保守外扩、PTI 不可辨识即放大不确定度、力矩-EEC 交叉一致性、定期实机回灌、高风险规则保留人审。

## 7. 本轮最大风险（最终确认）

**一句话**：**地形迁移界与力矩观测器共用同一套可能在真实地形上失配的动力学模型，形成自证循环**——TAK 用仿真标定的 Lipschitz 常数证明「迁移安全」，PTI 又用同一模型从力矩反演 μ/κ，一旦真实地形存在未建模的松软、回弹或未知负载，两者会同时给出偏乐观的证书，把「没见过的地形」误判为「已认证地形」。
