# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环新循环第 3 轮；本轮灵感：「演示数据」×「成本控制」）

> R70 把 FLUID 的「动作模态 epistemic」升级为「世界状态后验 epistemic」，用 BSE 显式维护 b_t(s)，用流似然 / 交互回答 / 标定残差三分解做观测模型，再以 RAS-Baselines 与 Proto-Val 兜底。但 R70 有三个未言明的前提，全部压在**演示数据**上：
> (a) 观测模型的三个因子 p_flow、p_interact、p_calib 都是从演示数据学出来或校准出来的；
> (b) 演示数据被视为「固定、诚实、代表部署分布」的既成事实；
> (c) 「降低不确定性」只在交互成本 c(g) 上计价，BSE/FMP 的训练、标定样本、算力似乎免费。
>
> 现实恰好相反：演示数据是**有偏、昂贵、非平稳、可能被污染或自我生成**的；每降低一个 nat 的 epistemic 熵，都要付出数据、标注、算力或交互的**真实价格**。R70 能回答「我信哪个世界状态」，却无法回答「**我对世界的这点把握值多少钱，该从哪条最便宜的渠道买，买不起时是不是干脆别做**」。
>
> 本轮两个灵感正好补上两块缺失：
> - **演示数据**把「数据」从一个被动前提变成一等资产：它带着来源、质量、成本、覆盖标签，也带着偏差与自食风险；
> - **成本控制**把「不确定性」从一个待压低的标量变成一个要按预算购买的资源：act / ask / demo / calib / retrain / abstain 都是可计价的证据渠道。
>
> 核心命题：**把 BELIEF-RAS 升级为「证据经济」——演示数据成为不可篡改、质量加权的账本；epistemic 增补后验熵看不见的覆盖缺口；所有降不确定性的渠道进入同一个成本受控调度器，按「单位成本的边际风险下降」购买证据；买不起（或买到的证据不值得）时退化为保守或弃权，安全侧永不弱于 R70。** 命名 **LEDGER-RAS**（Learning from Demonstrations with Evidence-calibrated Guarantees and Economic Regulation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我相信哪个世界状态」，R71 问「**这份确定性值多少钱，该向谁买、买多少，买不起时是否该不做**」——不确定性不只是刹车和提问，还是一张要结算的账。

## 0. 直觉与动机

**灵感 1（演示数据 → 观测模型的三个因子都踩在「演示脚印」上）**
直觉：R70 的 p(o|s)=p_flow·p_interact·p_calib 看起来很干净，但拆开看，每一项都来自演示：流策略用演示轨迹训练，交互回答模型用人类示范/偏好校准，标定残差模型也是在一批标定演示上拟合的。也就是说，**b_t 的可信度不是「贝叶斯给的」，而是「演示数据给的」**。如果演示只覆盖了桌面正前方 30cm，那么后验在侧后方的「自信」只是外推幻觉。把数据当既成事实，等于把模型的外推误差记成了世界的低熵。

**灵感 2（演示数据 → 覆盖缺口是后验熵看不见的 epistemic）**
直觉：R70 的 H[b_t] 是「模型内部」的熵：模型被训练得越自信，H[b_t] 越小。但在演示没有覆盖的区域，真实世界可能完全出乎模型预料，而 H[b_t] 仍会很小——这就是 R70 最大风险「自信地错」的数据版根源。人类会知道自己「没见识过」：没开过的路况、没抓过的材质，会主动减速或求示范。因此需要第二个、**与模型无关**的 epistemic 量：部署分布到演示支撑集的距离（覆盖缺口 δ_cov），以及基于留出演示的**分布无关风险证书**（加权共形）。H[b_t] 管「模型不确定」，δ_cov 管「世界没教过我」。

**灵感 3（成本控制 → 确定性是一种可购买的商品）**
直觉：既然 b_t 的可信度来自演示，而演示要花数据采集、标注、专家时间、算力，那么「降低不确定性」就是一个**购买决策**，不是一条自动执行的铁律。同一条信息可以用不同渠道买到：在线问一句（社交成本）、采一条演示（专家成本）、补标定样本（标注成本）、离线重训（算力与时间成本）、或者干脆弃权（机会成本）。哪条最便宜、买多少刚好够用，应该由「单位成本带来的风险下降」决定，而不是由固定规则决定。

**灵感 4（成本控制 → 影子价格统一 VoI、数据价值与算力）**
直觉：R69/R70 的 VoI 只比较「信息增益 − 交互成本」。但如果把每个渠道都看成预算约束，就能定义一个统一的**证据影子价格 μ**：多花一个单位预算能换来多少风险下降。最优时，所有被使用的渠道的边际收益 / 成本都相等；某渠道低于 μ 就不买。这把「值不值得问」「值不值得采数据」「值不值得重训」变成同一个拉格朗日问题，也让「CoC（把不确定性降到阈值所需的最小成本）」成为一个可计算、可审计的量。**买不起的确定性，比买错的确定性更该被拒绝。**

**灵感 5（演示数据×成本控制 → 便宜数据陷阱与 Goodhart）**
直觉：一旦成本成为优化目标，系统就会找到「最便宜的达标方式」——用廉价、低质、自生成、来源单一的演示把账本刷平。这不是假想：自训练/模型自食会造成分布坍缩，廉价标注会引入系统性偏差。更阴险的是，成本优化会**优先砍掉那些「用来发现自己在犯错」的留出集与交叉验证**，因为它们在短期报表上只花钱不产出。于是账本越来越漂亮，后验越来越自信，而真实覆盖越来越窄。所以必须把「质量调整成本」「来源多样性」「公开-隐藏留出差」写成硬约束与可检测指标，否则成本控制会把 R70 的「自信地错」升级为「精打细算地自信地错」。

## 1. 形式化定义（增量：定义 331–350）

**定义 331（LEDGER-RAS 总览）** LEDGER-RAS = (BELIEF-RAS†, DDL, CGEM, WCP, UEB, EAS, CoC, ADS, OTG, CPT, PLG, TTC, J_LEDGER)。四不变式：
(i) **实时流零学习写操作**（继承 R70 定义 310-i）：在线环只读账本与模型，任何数据/参数写入都在离线证据经济环完成；
(ii) **证据不免费**：任何不确定性消解动作必须记入账本并消耗对应预算维度，禁止隐式免费校准；
(iii) **质量调整与来源纪律**：演示以质量调整成本 c̃=c/q 计价，单来源演示不得单独定案/定标；
(iv) **安全不可交易**：成本压力只能提高保守度或触发弃权，不得降低认证包络与物理安全裕度。

**定义 332（演示账本 DDL）** 一条演示 ℓ_i = (τ_i, o_{t:t+H}, ξ_{t:t+H}, c_i, q_i, prov_i, cover_i, ts_i)，其中 τ_i 任务/场景标签，o/ξ 观测与动作块，c_i 采集与标注成本，q_i∈(0,1] 质量分，prov_i 来源（专家 / 遥操作 / 仿真 / 模型自生成），cover_i 覆盖区域标签。账本 L = {ℓ_i} 为仅追加、哈希链式结构，任何删除/改写留下可审计空洞。

**定义 333（质量调整成本与预算向量）** 质量调整成本 c̃_i = c_i / q_i；总数据支出 S_data=Σ_i c̃_i。预算向量 B=(B_int, B_data, B_comp, B_time) 分维度硬约束（钱买不到社交容忍，算力买不到时间），不先验标量化为单一货币。

**定义 334（覆盖缺口 CGEM）** 设演示分布 p_demo、部署分布 p_dep，密度比 r(s)=p_dep(s)/p_demo(s)（截断于 r_max）。局部覆盖 c(s)=P_demo(B(s,ρ))。覆盖缺口
δ_cov(s) = [1/c(s) − 1]_+ + λ_r·[r(s) − 1]_+。
δ_cov=0 表示处于演示稠密支撑内；δ_cov 大表示「模型没见过、却要在此决策」。

**定义 335（校正 epistemic U_epi†）** U_epi†(s) = H[b_t] + β·δ_cov(s)。H[b_t] 是模型相对的认知不确定，δ_cov 是模型无关的支撑缺口；二者语义不同但都对「我还不知道」负责。β 由留出演示上的风险回归校准，保证 U_epi† 是真实 epistemic 的保守上界（引理 23）。

**定义 336（加权共形风险证书 WCP）** 在留出演示 {s_i, loss_i} 上，以权重 w_i=min(r(s_i), r_max) 计算加权分位数，得分布无关上界：P(R(π) ≤ R̂_w + q_{1−α}) ≥ 1−α，在协变量漂移且密度比有界（A102）下成立。若实际 r>r_max，则证书失效并强制进入保守分支。

**定义 337（证据动作空间 EAS）** 𝒜_ev = {a_act, a_int, a_demo(k,R), a_calib(R), a_retrain, a_abstain, a_handover}。前三个在线可执行（a_int 继承 R70 MINT），a_calib/a_retrain 离线异步，a_abstain/a_handover 为终止型。每个动作有预算向量消耗 c(α)∈ℝ⁴ 与条件期望风险下降 ΔR(α)。

**定义 338（统一证据成本泛函）** 对策略 π 与证据序列 seq：
C(π,seq) = c_exec·E[risk] + c_int·N_int + c_data·Σ c̃_i + c_comp·T_retrain + c_safe·P(violation) + c_delay·E[delay]。
目标不是最小化 C，而是在硬预算 C_j ≤ B_j 下最小化期望风险；成本只是约束，安全是另一条不可交换约束。

**定义 339（证据影子价格）** 对预算维度 j，μ_j = ∂R*/∂B_j。在可分离凸近似（A103）下，最优证据组合满足：所有被启用渠道的「边际风险下降 / 预算消耗_j」= μ_j；低于 μ_j 的渠道不购买。μ 即「一个单位预算的确定性价格」。

**定义 340（成本-确定性 CoC）** CoC(τ; s) = min_{seq} C(seq)，s.t. E[U_epi†(s′)|seq] ≤ τ 且所有预算维度不越界。可行性判据：仅当 CoC(τ;s) ≤ V_task(s) − V_abstain(s) 才购买证据并继续；否则弃权/移交。V_task 为成功完成的价值，V_abstain 为安全退出的残值。

**定义 341（成本感知证据调度器）** 在线每一步：
1. 若 U_epi† ≤ τ_entropy（已够确定）→ a_act；
2. 否则枚举可用证据动作（在线仅 a_int/a_abstain；离线动作入队），按 ΔR/C_j 排序；
3. 选「最便宜且足够」的动作；若 CoC>价值或预算耗尽 → a_abstain/a_handover；
4. 所有决策与花费写入账本，影子价格 μ 随预算余额更新。

**定义 342（主动演示选择 ADS）** 给定待补区域 R 与预算，选择下一条演示位置/任务最大化「覆盖增益 / c̃」；在 A103（覆盖增益单调子模、成本可加）下，贪心达到 (1−1/e) 近似最优。

**定义 343（离线重训门 OTG）** 仅当 (i) 新增演示覆盖证书通过 WCP；(ii) 来源多样性 ≥ k；(iii) 自生成比例 ≤ ρ_max；(iv) 账本哈希与留出集完整可审计，才允许离线重训。在线环永不热更新参数。

**定义 344（成本感知风险退避 λ†）** 
λ† = max(λ_efs, λ_floor(U_ale + α·H[b_t] + γ·δ_cov_unresolved))。
当 H[b_t]<τ_entropy **且** δ_cov<δ_max **且** WCP 证书有效时 α=0、γ=0（获 resolution bonus）；任一不满足则 α=γ=1，未消解的覆盖缺口视同 aleatoric 收紧。这是对 R70「H[b_t] 小就自信」的正面修正。

**定义 345（演示投毒与来源一致性 PLG）** 演示来源分为 k 个近似正交渠道（专家遥操作 / 人类标注 / 仿真 / 外部数据集 / 模型自生成）。单来源演示只提供似然、不定案；k 渠道多数一致才更新标定/覆盖证书。与 R69 证据纪律同构。

**定义 346（廉价数据陷阱与 Goodhart 指数 CPT）** 记公开留出上的成本归一化表现 U_pub、隐藏留出上 U_hid，定义
G_data = (U_pub / S_pub) / (U_hid / S_hid)。
G_data 显著 >1 表示「靠便宜数据在公开面上刷出的优势」，冻结成本归一化决策并回退 BELIEF。辅以自生成比例 ρ_self 与覆盖收缩率作为塌缩预警。

**定义 347（账本证书 J_LEDGER）** J_LEDGER = (J_BELIEF, ledger_root_hash, coverage_cert, G_data, μ_t, budget_remaining, c̃_total, ρ_self, WCP_valid, ledger_ver)。Valid ⇔ Valid(J_BELIEF) ∧ WCP_valid ∧ G_data≤τ_G ∧ ρ_self≤ρ_max ∧ 账本无空洞。

**定义 348（双时间尺度架构 TTC）** 实时环（≤ R70 延迟）只读 b_t、模型、账本，执行 act/interact/abstain；证据经济环（分钟–小时级）执行 demo/calib/retrain/审计。两环通过只读快照与不可篡改账本解耦，保证实时安全与离线学习互不阻塞。

**定义 349（成本归一化评估协议 LEDGER-Bench）** 每个方法报告三元组 (success, safety, C)；显著性检验针对成本归一化效用 U = V·success − C（而非裸成功率）；所有对比必须在隐藏留出上重复，并给出 TCO = 采集+标注+算力+交互+事故。任何「更优」必须 Pareto 占优或 U 显著占优；仅靠多花钱换成功率不算更优。

**定义 350（IP 升级映射）** 见产物区表格：R70 的 11 个 IP 全升级（†），新增 DDL/CGEM/WCP/UEB/EAS/CoC/ADS/OTG/CPT/PLG/TTC/LEDGER-Bench。

```python
# IP-275/276 DDL：仅追加、质量调整成本的演示账本
class DemoLedger:
    def append(self, o, xi, cost, quality, provenance, cover):
        e = Entry(obs=o, act=xi, c=cost, q=quality, prov=provenance,
                  cover=cover, prev=self.root, ts=now())
        self.root = sha256(e)                       # 哈希链，不可篡改
        self.store.append(e)
        self.budget.spend_data(cost / quality)      # c̃ = c/q
        return self.root

    def coverage(self, s, rho=0.1, r_max=20.0):
        c = local_mass(self.store, s, rho)          # P_demo(B(s,rho))
        r = clip(density_ratio(self.store, s), 0, r_max)
        return max(0, 1/max(c,eps) - 1) + LAM_R * max(0, r - 1)

# IP-278 WCP：漂移下的分布无关风险证书
def weighted_conformal(calib, loss_fn, alpha, r_max=20.0):
    w = [min(density_ratio(calib, s), r_max) for s in calib.states]
    scores = sorted(loss_fn(calib) / normalize(w))
    return weighted_quantile(scores, 1 - alpha, w)  # 返回风险上界 q

    M.ledger.append_decision(b_t, a_ev, g, cost_of(a_ev, g), H, d_cov)

    return k, lam, mode, (U_ale, U_epi, d_cov)
```

## 3. 推导

**引理 23（覆盖缺口下界）** 在 A102（真实部署分布对演示分布绝对连续、密度比有界、观测似然 L-Lipschitz）下，任何仅由演示数据支撑构建的后验 b，在覆盖缺口 δ_cov(s) 处的真实 KL 满足
KL(p_dep(·|o) ‖ b(·|o)) ≥ c·δ_cov(s) − ε_demo。
要点：H[b_t] 是「模型内」熵，模型对没见过的区域可以既自信又错；δ_cov 是「模型外」的支撑缺口下界。系：R70 的「H[b_t] 小 ⇒ 自信」在低覆盖区不成立，必须以 U_epi†=H+βδ_cov 替代，且未消解时不得给 resolution bonus。

**引理 24（证据调度贪心近似最优）** 在 A103（各证据渠道在给定状态后条件独立、覆盖增益单调子模、成本可加）下，f(seq)=E[风险下降] 单调子模；在分维度预算的背包约束下，贪心按 ΔR/C 排序达到 (1−1/e) 近似（基数约束精确，背包为常数因子）。系：R70 引理 20 只覆盖交互一个渠道，本引理把它推广到 demo/calib/retrain 全部证据渠道。

**引理 25（确定性价格对偶）** 拉格朗日 L = R + Σ_j μ_j(C_j − B_j)。在可分离凸近似下，KKT 给出：所有被启用渠道的 ΔR_j/ΔC_j 相等且等于 μ_j；未启用者 ≤ μ_j。CoC(τ) 关于 τ 单调不增，且存在阈值 τ*：当任务价值 V_task−V_abstain 低于 μ·∂CoC/∂τ 时，继续购买确定性会净损失。系：「把不确定性降到 τ」不是无条件正确，只有价格低于任务价值时才正确。

**引理 26（便宜数据陷阱上界）** 若以质量调整成本 c̃=c/q 计价并要求来源多样性 ≥k、自生成比例 ≤ρ_max，则自训练/自食造成的分布漂移满足
D_collapse ≤ C_1·ρ_self^{k} + C_2·(1−q̄)，
其中 q̄ 为平均质量。若改用裸成本 c 计价，则对任意预算 B 都可构造 q→0 的演示使公开面成本达标而真实风险无界——即廉价数据陷阱在裸成本下不可防。系：质量调整与来源纪律不是工程细节，而是成本控制可用的前提。

**定理 20（LEDGER 严格包含 BELIEF 严格包含 FLUID 严格包含 R68）** 在 A102–A104 下，LEDGER 的期望风险（在成本归一化约束下）≤ BELIEF ≤ FLUID ≤ R68。当 B_data=B_comp=∞（证据免费）、δ_cov=0、且无自食/投毒时，LEDGER 逐指令退化为 BELIEF；当 B=0 或 CoC>任务价值时，退化为 R68 的保守或安全弃权。故四者是同一条「证据预算 → 保守度」谱系上的不同截断，安全侧逐层不让步。

**定理 21（安全对成本优化免疫）** 由于 (i) 在线环零学习写操作、(ii) 认证技能包络离线固定、(iii) λ† 对未消解不确定性单调不降，预算收缩只能使允许任务集变小、保守度变大或触发弃权/移交，不能使物理违规概率超过 ε。形式化：B↓ ⇒ λ†↑、k↓、P(violation)≤ε。系：成本控制可以决定「做不做」，不能决定「多不安全地做」。

**定理 22（成本归一化评估的诚实性）** 在隐藏留出、成本归一化效用 U=V·success−C、且 G_data≤τ_G 的条件下，任何宣称的优势都必须表现为 Pareto 占优或 U 显著占优；仅靠更高支出换来的成功率提升会被 G_data 与 TCO 拆穿。系：这把「更便宜」与「更好」分开，使 R70 的基线纪律从「统计显著」升级为「成本归一化后仍显著」。

## 6. 本轮最大风险

**一句话**：LEDGER-RAS 把「确定性」变成可购买的商品，但**成本是会自我强化的目标——最便宜的省钱方式，恰恰是买廉价、低质、自生成、来源单一的演示，并砍掉那些只花钱、却能揭穿自己在犯错的留出与交叉验证**；于是账本越记越漂亮，后验越训越自信，覆盖却越来越窄，最终系统「精打细算地自信地错」——它省掉的正是那部分能证明自己省错了的证据。

**次级风险与缓解**：
1. **覆盖估计本身不可靠**（高维密度比难估、kNN 在稀疏区方差大）→ 用保守截断 r_max、集成估计 + 证书失效即回退 R70 保守，绝不把不可信的 δ_cov 当成安全信号；
2. **加权共形的交换性/有界密度比假设在部署中被破坏** → 显式检测 r>r_max、分布外报警，证书失败即禁用成本归一化决策；
3. **质量分 q 被策略性操纵**（刷高质量分以压低 c̃）→ q 由多来源交叉验证与隐藏留出估计，q 的更新本身过 PLG/CPT 审计；
4. **成本优化挤压安全验证预算** → 定理 21 的安全不可交易约束 + 认证包络离线固定 + 成本压力对抗测试 E339；
5. **自食坍缩的滞后性**（塌缩在数轮后才显现）→ 硬上限 ρ_max + 覆盖收缩率在线预警 + 定期人类锚定演示，宁可多花钱也不让演示分布闭环。

## 4. 推导

**引理 23（覆盖缺口下界）** A102（部署分布对演示绝对连续、密度比有界、观测似然 L-Lipschitz）下，仅由演示支撑构建的后验 b 满足 KL(p_dep(·|o)‖b(·|o)) ≥ c·δ_cov(s) − ε_demo。系：H[b_t] 是模型内熵，低覆盖区可以「自信而错」；必须用 U_epi†=H+βδ_cov，且未消解不给 resolution bonus。

**引理 24（证据调度贪心）** A103（证据渠道条件独立、覆盖增益单调子模、成本可加）下，f(seq)=E[风险下降] 单调子模；分维预算背包中按 ΔR/C 贪心得 (1−1/e)（基数）/常数因子（背包）。系：把 R70 引理 20 从交互单渠道推广到全部证据渠道。

**引理 25（确定性价格对偶）** 拉格朗日 L=R+Σμ_j(C_j−B_j)；KKT 令所有启用渠道 ΔR/ΔC_j=μ_j，未启用者 ≤μ_j。CoC(τ) 单调不增，存在阈值 τ*：任务价值低于 μ·∂CoC/∂τ 时继续购买确定性净损失。系：「多降不确定性」只在价格低于任务价值时正确。

**引理 26（廉价数据陷阱上界）** 以 c̃=c/q 计价并令来源多样性≥k、ρ_self≤ρ_max 时，自食漂移 D_collapse ≤ C_1·ρ_self^k + C_2·(1−q̄)。若用裸成本 c，则对任意预算可构造 q→0 演示使公开面达标而真实风险无界。系：质量调整与来源纪律是成本控制可用的前提。

**定理 20（严格包含链）** A102–A104 下 LEDGER 的成本归一化期望风险 ≤ BELIEF ≤ FLUID ≤ R68。B_data=B_comp=∞、δ_cov=0、无自食/投毒时逐指令退化为 BELIEF；B=0 或 CoC>V_task−V_abstain 时退化为 R68 保守/弃权。四者为同一「证据预算→保守度」谱系的截断，安全侧逐层不让步。

**定理 21（安全对成本优化免疫）** 在线零学习写 + 离线固定认证包络 + λ† 对未消解不确定性单调不降 ⇒ B↓ 只使 λ†↑、k↓、允许任务集↓ 或触发弃权/移交，物理违规概率 ≤ε。系：成本控制可决定「做不做」，不可决定「多不安全地做」。

**定理 22（成本归一化评估诚实性）** 隐藏留出 + U=V·success−C 检验 + G_data≤τ_G ⇒ 优势必须 Pareto/U 占优；靠多花钱换成功率会被 G_data 与 TCO 拆穿。系：把「更便宜」与「更好」分开，使基线纪律从统计显著升级为成本归一化后仍显著。

## 7. 本轮最大风险

**一句话**：LEDGER-RAS 把确定性明码标价，但**成本是会被 Goodhart 化的目标——最便宜的「省钱」方式，是买廉价、低质、自生成、来源单一的演示，并优先砍掉那些只花钱却能把错误揭穿的留出集与交叉验证**；结果账本越漂亮、后验越自信、覆盖越窄，系统「精打细算地自信地错」，省掉的恰恰是证明自己省错了的那部分证据。

**次级风险与缓解**：
1. **δ_cov / 密度比在稀疏高维区估计不可靠** → r_max 截断 + 集成估计 + 证书失效即回退 R70 保守，不把不可信覆盖当安全信号；
2. **加权共形的交换性/有界密度比被部署破坏** → 在线检测 r>r_max 与 OOD，证书失败即禁用成本归一化决策（E323/E333）；
3. **质量分 q 被策略性刷高** → q 由多来源交叉验证 + 隐藏留出估计，q 更新本身过 PLG/CPT 审计（E328/E335）；
4. **成本优化挤压安全验证预算** → 定理 21 安全不可交易 + 认证包络离线固定 + 对抗预算测试 E339；
5. **自食坍缩滞后** → ρ_max 硬上限 + 覆盖收缩率在线预警 + 定期人类锚定演示，宁可多花钱也不让演示分布闭环（E329）。
