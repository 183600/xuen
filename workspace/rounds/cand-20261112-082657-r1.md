# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；灵感循环第 4 轮；本轮灵感：「触觉感知」×「安全对齐」）

> 第 57 轮把安全的赌注从"证据质量"再押到"元先验质量"，并用共形保底、跨模态仅限 L1、授权单向有界三重护栏把风险自陈收在"坏先验普遍"。但它默认了两件从未被质疑的事：**(a)** 触觉探针是"非破坏性"的（A34 过滤后即可随意问），因此感知与承诺是两件事——先免费地看，再决定是否赌；**(b)** 安全约束是"给定"的参考系，学习只改变信念、不改变"什么算安全"。本轮两个灵感正好拆掉这两个默认。**触觉感知**揭示：触觉是唯一一种"必须改变世界才能读取世界"的模态——最小的一次轻按也已留下压痕、滑移与暴露，感知本身就是一次小额承诺；于是"探针 vs 承诺"不是二值，而是一条**足迹单调的接触连续统**。**安全对齐**揭示：真正的危险不是"信念错了"，而是"信念更新了、安全包络却没同步更新"——系统的安全约束与真实风险之间的**对齐残差**会在触觉学习中悄悄漂移，等价于 AI 安全里的规范博弈/奖励黑客：机器人优化的是它**以为**的安全裕度。本轮核心命题：**"触觉即承诺、对齐即同步"——用足迹预算把感知与承诺统一，用对齐不变量把学习锁进参考包络的信任域，用不可学习的宪法层保证"对齐不会被学掉"。**

核心矛盾：
- **H29（触觉 vs 不可逆性）**：最可信的模态（真实接触）恰恰是唯一不可逆的模态；要更准就得摸得更重，要更安全就得摸得更轻——信息与足迹之间存在一条被长期忽视的帕累托前沿。
- **H30（学习 vs 对齐）**：安全包络必须随触觉证据更新（否则僵化），但一旦允许更新，便宜的证据就可能买到昂贵的授权——一次侥幸的低足迹成功会让包络向危险方向外推（触觉诱发的过度自信）。
- **H31（个性化 vs 对齐）**：不同操作者的风险态度不同，对齐应个性化；但若允许某操作者把包络调松，就制造了"对齐套利"——用宽松的操作者训练、让系统对所有人变松。

## 0. 直觉与动机

**灵感 1（触觉感知 → 接触原语与足迹单调的"感知即承诺"）**
直觉：把触觉探针重新定义为**接触原语** p，每按一次都要付出不可逆"足迹" ℓ(p)（压痕深度、滑移、能量、暴露时间），并换来可观测量 o_p。安全的第一性约束不再是"信息足够"，而是"总足迹 ≤ 预算"。于是探针与承诺共享同一本预算账：轻点=微承诺，重压=强承诺。衡量一个探针好不好，不是信息增益本身，而是**触觉信息效率 η=IG/ℓ**——单位不可逆扰动换来的信息量。这把第 57 轮"非破坏性过滤"从硬门升级为一条**可优化的前沿**：在信息-足迹帕累托前沿上选点，而不是在"安全/不安全"二值上撞墙。

**灵感 2（安全对齐 → 信念-约束同步与对齐残差）**
直觉：安全对齐不是一次性满足约束，而是**让"学到的安全包络 E_θ"始终被"参考包络 E_ref（仿真/规范/人类演示）"罩住**。定义对齐残差 ε_align=d_⊆(E_θ,E_ref)，并要求单向包含：E_θ ⊆ E_ref⊕ε_max。触觉证据只能在一个**认证信任域**内移动包络，信任域半径由足迹与佐证共同决定（便宜的证据只能微调，贵的证据才能改写）。这样"触觉诱发过度自信"被结构性地挡住：摸到一次侥幸成功，无法把包络整体向危险方向平移。

**灵感 3（载荷单调外推 → 不许用轻载证据论证重载安全）**
直觉：薄冰上的关键欺骗是"低载荷下读数很好、高载荷下塌陷"。触觉证据天然只在**已测载荷**处可信；把它外推到更高载荷必须显式携带外推证书（材料刚度下界、支撑几何、载荷单调性），否则一律拒绝。这是对"局部触觉"的诚实：我没有摸过更重的世界，就不许为它担保。

**灵感 4（人-机风险对齐 → 从 L2 同意中学习序数风险态度）**
直觉：操作者的 L2 接受/拒绝不是"标签"，而是对接触足迹的**序数偏好**——"这个足迹我能接受，再大就不行"。把每次同意看作一次成对比较，学出操作者的风险态度 a_o；机器人的风险态度 a_r 只被允许对齐到 a_o 的**保守下界**（a_r ≤_cons a_o）。对齐用主动查询：在两个操作者分歧最大的足迹点上请求一次 L2 判定作为校准锚点。个性化对齐由此成立，但只能"更保守地向某个人靠拢"。

**灵感 5（合流 → 证据门加"足迹"维度、宪法层兜底）**
直觉：第 57 轮证据门 EV-probe\*/visit/margin/xmodal/human 在本轮各获得一个足迹注记：任何证据都声明自己"花了多少不可逆足迹、能支撑到多大载荷"。新增**EV-touch**（触觉证书：足迹-载荷-外推三元组）作为不可逆接触的**唯一**可接受实证类，且必须过宪法投影。击穿安全需要：足迹预算错 ∧ 对齐残差漏检 ∧ 触觉外推造假 ∧ 跨模态共谋 ∧ 人也错——纵深再加一层。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（接触原语与足迹单调性 TCF）** 接触原语集 𝒫，p 携带足迹 ℓ(p)∈[0,ℓ_max]（不可逆扰动度量：压痕/滑移/能耗/暴露）与观测 o_p。要求足迹单调：进一步加载 ℓ(p')≥ℓ(p) ⇒ 不可逆扰动不减。接触预算 ℓ_budget(risk_class) 由宪法层给定、不可学习放宽。触觉信息效率 η(p)=IG(p)/ℓ(p)；探-诺-演在信息-足迹帕累托前沿上选点。累计足迹不变量 Σ_t ℓ(p_t)≤ℓ_budget。

**定义 140（安全对齐残差 AR）** 参考包络 E_ref(r)（仿真/规范/人类演示，附健全性证书），学习包络 E_θ(r)。对齐残差 ε_align(r)=d_⊆(E_θ,E_ref)（单向包含距离；学习包络越界即取正）。对齐不变量：E_θ(r) ⊆ E_ref(r)⊕ε_max。监控器每检查点重估 ε_align；ε_align>ε_max ⇒ 冻结学习、回退 E_ref、动作降档。单向性保证"学习只能更保守、或只在受限邻域内乐观"。

**定义 141（触觉对齐契约 TAC）** 触觉证据 e=(p,o,ℓ) 对包络的更新为 θ'=Proj_{Θ_align(e)}(θ⊕e)。认证信任域 Θ_align(e) 的半径 r_cert(e)=g(ℓ(p), corrob(e), D(r))：足迹越小、佐证越少、跨模态分歧越大 ⇒ 信任域越小（只能微调）。只有"高足迹 ∧ 多佐证 ∧ 跨模态一致"的证据才允许显著移动包络。原则：**便宜的证据买不到昂贵的授权**。Proj 在宪法可行集上做欧氏投影，保证投影后仍满足 𝒦_con。

**定义 142（载荷单调外推证书 LMC）** 在载荷 ℓ 处测得的触觉安全证据只能声明"≤ℓ 安全"。外推到 ℓ'>ℓ 需外推证书 X=(刚度下界, 支撑几何, 单调性声明, 最坏失效模式)；无证书的外推一律拒绝，视同无证据。外推不得跨越已声明的最坏失效模式阈值。

**定义 143（人-机触觉风险对齐 HTRA）** 操作者风险态度 a_o 由 L2 对足迹的成对接受/拒绝学习（Bradley-Terry/序数回归）；机器人风险态度 a_r 对齐约束 a_r ≤_cons a_o，且个性化仅在该保守下界内生效。主动对齐查询：在足迹轴上取 a_o 分歧最大点请求 L2 判定作为锚。对齐残差 ε_hra=|a_r−a_o| 进审计；a_o 跨会话衰减、单会话不得抬高全局下界。

**定义 144（安全宪法层 SCL）** 不可变约束集 𝒦_con={ℓ_max, 载荷外推禁令, ε_max, EV-xmodal 不可逆禁令, 证据门不可绕过, 授权单向有界}。任何元学习/个性化/触觉更新先经宪法投影 Π_{𝒦_con}；若投影为空（更新必然违反宪法）⇒ 该更新非法、回退。宪法是"对齐不能被学习掉"的形式保证，等价于可证明的硬约束不变式。

## 2. 关键算法伪代码（完整版见产物区）

```python
def tactile_query_select(M, r, H, budget):               # IP-139: 信息-足迹前沿
    cands = contact_primitives(r, M)
    front = [p for p in cands if footprint(p) <= budget.left]
    front = pareto(front, key=lambda p: (IG(p, H), -footprint(p)))
    p = argmax(front, key=lambda p: IG(p, H) / max(footprint(p), EPS))
    return p, budget.spend(footprint(p))

def align_update(theta, e, E_ref, K_con):                # IP-140/141/144
    theta = bayes_update(theta, e)
    theta = project(theta, trust_region(e))              # TAC: 半径 ~ 足迹×佐证
    theta = project(theta, {th: encloses(E_ref, th, eps_max)})  # AR 单向包含
    return project_constitution(theta, K_con)            # SCL: 不可学习放宽
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TCF | O(\|𝒫\|·log\|𝒫\|) 前沿排序 | O(\|𝒫\|) | 足迹单调、预算不越界 |
| AR | O(d_θ) 残差 + O(1) 门 | O(1) | 单向包含、ε_max 不放松 |
| TAC | O(d_θ) 两次投影 | O(d_θ) | 信任域半径单调于证据强度 |
| LMC | O(1) 证书校验 | O(1) | 无证书不外推 |
| HTRA | O(1)/次同意 | O(\|操作者\|) | a_r≤_cons a_o |
| SCL | O(\|𝒦_con\|) 投影 | O(1) | 宪法不变式 |

**正确性定理（Tactile-Aligned Safety, TAS 概要）**：在 A37–A40 上加 (A41) 足迹单调与预算；(A42) 参考包络健全、对齐残差可监控、ε_max 不放松；(A43) TAC 信任域投影保守；(A44) 载荷外推证书诚实；(A45) 宪法不变式保持。则：(i) 对齐健全性：真实包络逃出学习包络的概率 ≤ δ_ref+ε_align+ε_max 项；(ii) 足迹守恒与"便宜证据不买贵授权"：Σℓ≤ℓ_budget，且授权扩张 ≤ r_cert 所允许；(iii) 单调性：触觉/对齐/个性化只经"包络收缩或保守位移"作用，无越界扩张路径；(iv) 每条接触的部署界联合成立。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 参考包络本身有偏 → 对齐到错的锚 | 高 | 参考多源交叉（仿真×演示×规范）+ 残差监控 + 宪法兜底 |
| 足迹度量滞后/不可观测 | 高 | 在线足迹估计 + 保守上界 + 超预算即停 |
| 宪法投影被近似破坏 | 中 | 投影后形式校验 + 只读宪法 + 审计 |
| 操作者风险态度学习样本稀疏 | 中 | 主动对齐查询 + 保守先验 + 只允许更保守 |
| 触觉硬件退化 | 中低 | 自检 + 退化即降为 EV-visit 保守路径 |

## 6. 本轮最大风险

**一句话**：本轮把安全从"约束满足"升级为"约束对齐"，但**监控对齐残差的估计器和被它监督的触觉学习共用同一份证据**——若某种系统性触觉偏差（如传感器低温下普遍低估压痕）让真实包络漂移而 ε_align 读数仍然很小，系统就会"对齐到一个谎言"，且宪法层只保证形式不变式、不保证参考包络 E_ref 本身贴近真实；必须以多源参考交叉、载荷外推禁令与不可学习宪法三重锚定，并默认"任何单一触觉通道的自我证明都不可信"。

def probeability(r, ev):
    return 'P' if ev.kind in {'terrain', 'material', 'bearing'} else 'N'

def evidence_dispatch(r, ev, t, budget):
    if probeability(r, ev) == 'N':                     # 探它=撞它
        return Bound(reachable_set(r, ev), delta_pred=ev.delta_pred)
    voi = expected_info_gain(ev) - probe_cost(ev) - time_cost(t)
    if voi > theta_voi and budget.remaining(t) > 0:
        return Probe(ev)                               # 只有可探类才花探针
    return Bound(worst_case(r), delta_pred=ev.delta_pred)
```

def reachable_set(agent, horizon):
    R = set()
    for tau in horizon:
        R |= Reach(agent.x, agent.U, tau) + conformal_residual(agent, tau)
    return R                                          # 覆盖 ≥ 1 - delta_pred

def dynamic_safe(sigma, agents, occluded, beta):
    for t in sigma.times:
        R = union(reachable_set(a, t) for a in agents) | worst_occupancy(occluded, t)
        if dist(sigma(t), R) < beta(t):                # 裕度随不确定性单调增
            return False
    return True
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TEL | O(1)/新鲜检查；O(N_e) 账本 | O(N_e) | ρ_chg 界诚实、ε_stale 声明、时间共形覆盖（A41） |
| PBX | O(1)/分派 | O(1) | 可探性分类正确、不可探不误用探针（A42 前置） |
| RDA | O(\|𝒪\|·T·d_ℛ)/rollout，可摊销 | O(\|𝒪\|·T) | ℛ 含真值（δ_pred）、遮挡最坏占据（A42） |
| RVC | O(1)/控制拍（viability 预算） | O(\|σ\|) | π_bk 不变集在真实执行器界下成立（A43） |
| EAC | O(N_test·C_test) | O(N_test) | 阶梯门、风险预算、物理底座（A44） |
| SPRC | O(N·d)+O(N_cal) | O(N_cal) | 重要性权重正确、CI 有效、E_cert 诚实（A44） |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+N_ℛ) | O(\|V\|+\|σ\|) | 时间感知 VOI、TTL 内终止、四态完备 |

**正确性定理（Temporal Reachable Certified Soundness, TRCS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 变化速率界与 TTL 诚实：P(‖ΔW‖>ρ_chgΔ)≤ε_stale，时间共形覆盖 ≥1−α_t；**(A42)** 可达集健全：真实未来状态 ∈ℛ 的概率 ≥1−δ_pred，遮挡区按最坏占据处理；**(A43)** 备份控制器在真实执行器/传感界（时延、饱和、磨损）下保持 𝒮_inv；**(A44)** 评测风险预算成立（Σrisk≤B_eval）、仿真-现实加权共形覆盖 ≥1−α_real、稀有事件置信区间有效。则：

1. **新鲜承诺健全性**：fresh 证据路径 P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + ε_stale + δ_pred。
2. **可撤销承诺安全性**：P(碰撞) ≤ δ_pred + δ_bk + ε_stale；且由 A43，任何时刻 revoke 不引入新风险（撤销是安全构造，而非又一次赌注）。
3. **评测证书有效性**：P(真 δ_f > CI 上界) ≤ α_eval；E_cert 外部署必被标 ood_eval 并退回保守控制器，故"未测世界"不进入自主承诺。
4. **交互单调性保持**：TTL 收紧、可达集加宽、裕度 β 增大、撤销触发、评测门收紧，只经"信念更准（含加宽）"或"动作更保守"影响系统，不存在升险路径。
5. **终止性**：每检查点探针 ≤k_probes+k_cons，且时间预算耗尽即停止探测、转鲁棒承诺或协商。

**部署界**（对检查点取联合界，并显式分离"系统失效"与"评测误认证"）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − ε_stale − δ_pred − δ_bk
             − P(𝓜 陈旧未检出) − P(E_cert 外误自主) − P(π_bk 真机失效)

评测侧独立声明：P(真 δ_f > UCB_δf) ≤ α_eval，且仅对场景 ∈ E_cert 成立。
```

关键：**时间维把"证据承诺"变成"证据租约"**（新鲜度是承诺的必要条件，撤销是安全构造）；**可探性分型把"探"从万能动作降级为地形专用**（对智能体，正确的不是探而是围）；**评测从终点变成起点**（物理硬约束触底，仿真给效率、真机给校准，只认证包络不认证系统）。

## 6. 本轮最大风险

**一句话**：本轮把安全性押在两个"模型"上——描述世界变化速率的 TTL 模型与描述他人未来位置的可达集模型——再叠一个"在有限场景上统计认证"的评测包络；最深的危险不是某个模型算错，而是真机评测给出**统计上很紧、分布上却错误**的证书：在测过的世界里精确测出的 δ_f，被当成了未测世界的保证，而可达集与备份的健全性又在磨损、时延与陌生地形下被悄悄违反；必须以 TTL 在线变化检测、共形可达集、物理触底的阶梯评测与"只认证包络、绝不认证系统"四重护栏，把未知世界挡在自主承诺之外。
