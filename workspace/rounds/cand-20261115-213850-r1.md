# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「闭环控制」×「避障控制」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**反馈证书 + 主动避障 + 权限一致性**。两个灵感分别治理 v9 的两个隐含债：**开环债**（块证书用前向模型开环外推 K 步，安全性整段押在「信任域内模型误差 ≤ β」上）与**被动债**（守卫只做阈值检测与停车中止，避障是事后判据而不是控制律）。必须保证：CLC/AAF/AA 任一失效都注入中立元（ρ_k≡β / u≡u_nom / 直通），严格等价退回 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（闭环控制 → 证书应是反馈不变式，而不是开环预测）**
直觉：v9 的块证书把未来 K 步的间隙押在冻结前向模型的一次开环 rollout 上，守卫只在越界时中止——这是"开环预测 + 事后报警"。控制理论的核心教训是：**只要闭环误差动力学是收缩的，长期偏差由一步扰动增益决定，而不需要长期模型准确**。若执行策略使偏差满足 e_{k+1} ≤ γe_k + w_k（γ<1），则 e_k 有与块长 K 无关的一致界，证书只需在线估计「一步误差 w」与「收缩率 γ」即可外推整块；而且估计本身可以用保形反馈闭环校准——覆盖不足就自动放宽管半径。核心创新：**闭环证书器（ClosedLoopCertifier, CLC）**：用随时间增长的偏差管 ρ_k 替换常数 β，把块证书从"标称 rollout 的乐观断言"变成"标称 rollout ± 管的包含性命题"。这正好拆掉 v9 的最大风险：证书不再要求"信任域内长期误差 ≤ β"，只要求"一步误差可测、闭环收缩可验、覆盖率可反馈"。

**灵感 2（避障控制 → 守卫应是主动安全滤波器，而不是被动停车判据）**
直觉：v9 的中止点集是"发现要撞了就刹车"，停车是唯一手段。但避障控制的现代语言是**前向不变性**：存在一个安全集，控制律保证状态永不离开它；控制障碍函数（CBF）把这件事变成每周期可解的小 QP——在保持名义动作最小的前提下，只修正到刚好满足不变性。停车退化为最后手段，而不是默认手段。对动态障碍，不能信任点预测，必须对障碍的**可达集**取最坏距离。核心创新：**主动避障滤波器（ActiveAvoidanceFilter, AAF）**：每个 50Hz 周期解一个离散时间 DCBF-QP，把"安全"从周期末的阈值检查变成周期初的硬约束；QP 不可行时才进入认证中止/恢复。

**灵感 3（耦合 → 权限预算是闭环与避障的公共货币）**
直觉：安全滤波器会改动作，而块证书是按标称动作算的——滤波越权，证书就失真。二者必须共享一个显式的**权限预算** a_res：证书把 a_res 计入扰动管（w_max = w_model + L_u·a_res），滤波器只能在 a_res 内修正；一旦实测修正超过 a_res，仲裁器先作废证书并要求重规划，而不是继续"带着失效证书避障"。这把"滤波器 vs 证书"的潜在冲突变成一个可证明的一致性条件。核心创新：**权限仲裁器（AuthorityArbiter, AA）**与四态耦合模式机（CC/AV/RP/AB），优先级 AB > RP > AV > CC，并用驻留时间与计数器防抖。

## 1. 研究问题（轮次升级版）

- **Q1（闭环证书可靠性）**：在什么收缩率、状态估计误差、执行延迟与饱和条件下，偏差管 ρ_k 是可靠的？在线辨识 (γ, w_max) 如何避免"在域偏移最剧烈时恰好乐观"？保形反馈能否在非平稳下维持长期覆盖率 ≥ 1−δ？
- **Q2（主动避障相容性）**：DCBF-QP 与动作分块如何相容——滤波器改变动作后，块证书凭什么仍然有效？动态障碍可达集如何定价，才既不漏检又不让 QP 频繁不可行？认证中止所必需的最小权限储备 a_res 是多少？
- **Q3（耦合、失效与退化）**：滤波-证书冲突的充要条件是什么？四态模式机能否保证无静默违背、无抖振、有限时间收敛？CLC/AAF/AA 任一失效能否通过中立元严格退回 v9，并与 v9 五级退化链正交复合？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 闭环证书律（Closed-Loop Certificate, CLC）**
证书的有效性以**反馈管**为单位：x^k ∈ T_k = {x : ‖x − x̂_k‖ ≤ ρ_k}，其中 ρ_k = γ^k ρ_0 + w_max(1−γ^k)/(1−γ)。证书只减去 ρ_k 而不是常数 β：ĝ_min^{CL} = min_k[F̂_clearance(x̂_k) − L_g ρ_k] − β_obs。在线用滑窗残差辨识 (γ̂, ŵ) 的形状，再用自适应保形推断（ACI）校正分位，覆盖不足即放宽 ρ。禁止在收缩性或覆盖率不达标时宣称证书有效。

**P14 主动避障律（Active Avoidance Barrier, AAF）**
每个 50Hz 周期解 DCBF-QP：在 u∈U、执行器速率/幅值约束下最小化 ‖u−u_nom‖²，约束为鲁棒离散障碍条件 h(f̂(x_k,u), k+1) ≥ (1−η)h(x_k) + L_h ŵ。静态障碍用 h = dist(x,O) − r_rob − r_safe；动态障碍用可达集 O_reach(t+k) 的最坏距离。QP 可行则执行 u*；不可行则进入认证中止/恢复，而非静默继续。

**P15 权限一致性律（Authority Consistency, AA）**
存在显式权限预算 a_res：块证书的扰动界包含 L_u·a_res，滤波器被约束 ‖u−u_nom‖ ≤ a_res。实测 a_used 超预算（或连续 K_auth 周期逼近临界）⇒ 立即作废当前证书并进入 RP；任何"继续执行"状态都必须同时满足「证书有效」与「a_used ≤ a_res」。安全滤波器优先级最高，证书次之，名义动作最低；冲突时先降级再重规划。

## 3. 与基线的接口（如何退化）

- CLC 失效（收缩对不可辨识 / 保形覆盖持续不足 / 延迟超界）⇒ 令 γ=0、w_max=β、ρ_0=0，则 ρ_k≡β，证书逐项退化为 v9 定义 533（引理 82）；
- AAF 失效（QP 超时 / 不可解 / 求解器异常）⇒ u≡u_nom 恒等滤波，守卫退回 v9 定义 534 的被动间隙检查与停车中止；
- AA 失效（仲裁超时 / 模式机异常）⇒ 直通（恒 CC）+ v9 守卫，不引入新约束；
- 三个新模块与 v9 的 AC/MW/ID 正交：任一层失效后继续沿 v9 五级链下退（Level-1 AC → … → Level-5 v6）。所有新契约行都带中立元与 φ^elig=false（不可蒸馏）。

## 4. 预期贡献

1. **反馈证书**：把"长期模型精度"替换为"一步误差 + 收缩性 + 保形覆盖"，理论上切断 v9 的「域偏移 × 证书失效」耦合；证书在域偏移下自动收紧而非保持乐观。
2. **主动避障**：DCBF-QP + 动态可达集，把避障从停车判据升级为每周期硬约束，并给出滤波可行性与认证中止的统一定义。
3. **权限一致性**：用 a_res 把滤波修正纳入证书扰动预算，证明「无静默违背」与「无抖振」，并给出最小权限储备的可计算下界。
4. **实验体系**：E571–E590 覆盖收缩辨识、域偏移斜坡、动态障碍、权限冲突注入、模式抖振、执行延迟/饱和、形式化验证与端到端竞赛。

## 5. 本轮最大风险

**一句话**：闭环证书与主动避障共享同一个执行器权限预算，而收缩性/保形覆盖的在线估计在接触、打滑与突发动态障碍同时发生时最不可信——若权限仲裁为了避障临时借用了证书预留的扰动预算，管半径会低估真实偏差，系统可能在"证书仍有效"的状态下发生静默的避障越界。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-CLAA**（Metric Voice Gauge with Closed-Loop Certificates & Active Avoidance）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「闭环控制」×「避障控制」

## 1. 符号体系增量（定义 540–548）

| 符号 | 含义 |
|---|---|
| x̂_k, x_k | 块内第 k 步的标称 rollout 状态与实测状态（含状态估计） |
| e_k = x_k − x̂_k | 闭环跟踪偏差（向量范数按任务相关加权） |
| (γ, w_max) | 收缩对：闭环误差增益 γ∈[0,1)，一步扰动上界 w_max |
| ρ_k | 偏差管半径：e_k 的时变上界（定义 540） |
| q_k, α_k | 保形分位与 ACI 误覆盖率反馈量（定义 541） |
| Ĉ_t^{CL} | 闭环块证书，含管半径修正后的间隙/力度最坏界（定义 542） |
| h(x,t) | 障碍函数：安全集 {h ≥ 0}，静态/动态统一形式（定义 543） |
| O_reach(t+k) | 动态障碍在未来第 k 步的可达集（定义 544） |
| a_res, a_used | 权限预算（预留给避障的最大修正量）与实测修正量（定义 545） |
| ℳ = {CC,AV,RP,AB} | 耦合模式机：认证块 / 避障介入 / 重规划 / 中止恢复（定义 548） |
| K_auth, T_dwell | 超预算确认周期数与最小驻留时间（防抖） |

**新增定义 540（闭环偏差管 ClosedLoopTube）** 对块 ζ 的标称 rollout x̂^{1:K}，若闭环执行策略满足
```
e_{k+1} = A_cl,k e_k + B_w w_k,   ‖A_cl,k‖ ≤ γ,   ‖w_k‖ ≤ w_max,   ‖e_0‖ ≤ ρ_0
```
则管半径与包含性为
```
ρ_k = γ^k ρ_0 + w_max·(1 − γ^k)/(1 − γ),
T_k = { x : ‖x − x̂_k‖ ≤ ρ_k },   x^k ∈ T_k  (k = 0..K)
```
ρ_0 由状态估计协方差给出；γ=0 时退化为常数管 ρ_k ≡ w_max。

**新增定义 541（保形-收缩管标定 ConformalContractionTube）** 从滑窗 𝒲 的残差对 {(e_k,e_{k+1})} 用分位回归估计 (γ̂,ŵ)，得到形状函数 ρ_k(γ̂,ŵ)；再以自适应保形推断（ACI）维持长期覆盖：
```
q_k = Quantile_{1−α_k}({ ‖e_j‖ − ρ_j(γ̂,ŵ) : j ∈ 𝒲 }),
α_{k+1} = clip( α_k + η(δ − 1{‖e_k‖ > ρ_k}), α_min, α_max ),
ρ_k ← ρ_k(γ̂,ŵ) + max(0, q_k).
```
覆盖不足（误覆盖指示=1）时 α 下降、分位水平上升、管自动放宽；覆盖富余时管缓慢收紧。**这是"对证书本身闭环"的关键**：不预标定一个 β，而是用实测误差反馈维持长期覆盖率 ≥ 1−δ（非平稳下由 ACI 的 regret 界保证）。

**新增定义 542（闭环块证书 ClosedLoopChunkCertificate）**
```
ĝ_min^{CL} = min_{k≤K} [ F̂_clearance(x̂_k) − L_g·ρ_k ] − β_obs,
ê_max^{CL} = max_{k≤K} [ F̂_effort(x̂_k)  + L_e·ρ_k ] + β_obs,
```
其中 L_g、L_e 为间隙/力度对状态的 Lipschitz 常数，β_obs 只承担观测与数据关联膨胀（模型误差已进入 w_max/ρ）。证书有效 ⇔
```
ĝ_min^{CL} ≥ d_safe ∧ ê_max^{CL} ≤ τ_eff ∧ γ̂_grasp = valid
∧ h_dyn(x,t) ≥ 0 ∧（用当前 τᵢ(t) 复核各层）
```

**新增定义 543（主动避障安全滤波器 DCBFSafetyFilter）** 障碍函数
```
h(x,t) = dist(x, O_reach(t)) − r_rob − r_safe.
```
鲁棒离散障碍条件与 QP：
```
u* = argmin_{u∈U} ‖u − u_nom‖²_W
     s.t. h(f̂(x_k,u), k+1) ≥ (1−η)·h(x_k) + L_h·ŵ
          u_min ≤ u ≤ u_max,  |u − u_{k−1}| ≤ Δu_max
```
η∈(0,1] 为收缩系数。可行 ⇒ 执行 u* 并记录 a_used=‖u*−u_nom‖；不可行 ⇒ 进入认证中止/恢复（定义 547），绝不以"近似解"冒充安全。

**新增定义 544（动态障碍可达集 DynamicReachableSet）** 对障碍 o 的速度/加速度界 (v_o,a_o) 与协方差 Σ_o：
```
O_reach(t+k) = O(t) ⊕ Ball( ‖v_o‖kΔt + ½‖a_o‖(kΔt)² ,  λ·√(tr Σ_o(k)) ),
```
⊕ 为 Minkowski 和，λ 为 3σ 覆盖系数。被遮挡/减速中的障碍取更保守的 a_o 上界；可达集以 10–20Hz 更新、50Hz 线性插值，h 对可达集取最坏距离。

**新增定义 545（权限预算 AuthorityBudget）** 令 L_u 为闭环动力学对控制修正 δu=u−u_nom 的 Lipschitz 常数，证书的扰动界取
```
w_max = w_model + L_u·a_res,
```
滤波器受约束 ‖δu‖ ≤ a_res。实测 a_used 满足：
- a_used ≤ a_res：修正落在证书预留扰动内，证书仍有效；
- a_used > a_res 连续 K_auth 周期，或在 h < h_crit 时任一周期的 a_used > a_res：AA 立即作废证书并进入 RP。

最小权限储备 a_res^min 由临界状态集上的最小可行修正给出；若 a_res < a_res^min，则临界状态下只能认证中止，而不是继续。

**新增定义 546（滤波-证书一致性 FilterCertificateConsistency）** 全局不变式：
```
(安全)        h(x_k) ≥ 0,
(一致)        (CC ∨ AV) ⇒ (Ĉ_t^{CL} valid ∧ a_used ≤ a_res),
(升级)        (¬Ĉ_t^{CL} valid ∨ a_used > a_res ∨ QP infeasible) ⇒ (RP ∨ AB).
```
优先级 AB > RP > AV > CC；任何"继续执行"状态同时要求证书有效与权限未超预算。

**新增定义 547（认证中止与恢复 CertifiedAbortRecovery）** 滤波器感知的刹车不变式：
```
A_t = { p ≤ k_exec : d_brake(v_p, d_act) + d_safe
        ≤ dist(s_p, O_reach(p)) − |traj_{p:K}| − L_h·ρ_p }.
```
A_t 非空 ⇒ 取最大 p* 执行认证减速；A_t 为空（停车本身不安全）⇒ 在恢复动作集 R 中求一步 DCBF 可行的最大裕度动作 r∈R（刹车 + 转向避让）；R 也为空 ⇒ 进入 fail-safe："K=1 + 硬停 + 全模块唤醒"，仅当 h 仍 ≥0 时允许，否则明确的不可恢复报警（不静默继续）。

**新增定义 548（耦合模式机 CoupledModeFSM）** ℳ = {CC, AV, RP, AB}：
- CC→AV：a_used > ε_a；AV→CC：a_used ≤ ε_a 持续 T_dwell；
- ∗→RP：¬cert valid ∨ a_used > a_res 连续 K_auth ∨ 新障碍进入可达时域；
- ∗→AB：QP 不可行 ∧ A_t=∅ ∧ R=∅，或 h < ε_crit；
- RP→CC：新块通过 CLC 复核；AB→RP：停驻/恢复完成后环境确认。
所有边带驻留时间 T_dwell 与 Schmitt 式阈值，消除抖振（引理 91）。

**升级定义 496（软证书，v10）**
```
δ_trigger = { σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
              ∧ risk_SLAM < τ_SLAM ∧ Ĉ_t^{CL} valid
              ∧ h_dyn ≥ 0 ∧ a_used ≤ a_res }.
```
任一条件失效均触发 M₀ 硬检查；块内失效不再等块边界，立即进入 RP/AB。

**升级定义 531（软硬约束衔接，v10）** 中块守卫违规 ⇒ 先尝试滤波器内修正（权限预算内），超预算 ⇒ 认证中止（定义 547），全程不等块边界；"继续"仅在定义 546 的一致状态下允许。

# IP-357 / IP-360：闭环证书器 + 保形收缩管
class ClosedLoopCertifier:
    def __init__(self, F, Lg=1.0, Le=1.0, beta_obs=0.02,
                 delta=0.05, eta_aci=0.02, window=400):
        self.F, self.Lg, self.Le, self.beta_obs = F, Lg, Le, beta_obs
        self.delta, self.eta, self.W = delta, eta_aci, window
        self.gamma_hat, self.w_hat, self.alpha = 0.9, 0.05, delta
        self.errs, self.q = [], 0.0

    def tube_radius(self, k, rho0):
        g, w = self.gamma_hat, self.w_hat
        if g >= 1.0:                       # 非收缩：退回常数管（v9）
            return self.w_hat + self.q
        return (g ** k) * rho0 + w * (1 - g ** k) / (1 - g) + self.q

    def observe(self, e_k, e_prev):
        self.errs.append(e_k)
        if len(self.errs) > self.W:
            self.errs.pop(0)
            self._fit_contraction()
            self.q = max(0.0, quantile([e - self.tube_radius(i, 0.0)
                                        for i, e in enumerate(self.errs)],
                                       1 - self.alpha))
        mis = int(e_k > self.tube_radius(1, 0.0))
        self.alpha = clip(self.alpha + self.eta * (self.delta - mis),
                          0.005, 0.5)      # ACI 反馈：覆盖不足即放宽

    def _fit_contraction(self):
        # 分位回归 e_{k+1} <= gamma e_k + w，取 (1-delta) 分位
        self.gamma_hat, self.w_hat = robust_quantile_fit(self.errs, self.delta)

    def certify(self, chunk, rho0, tau_eff, tau_layers, h_dyn):
        gmin, emax = float('inf'), -float('inf')
        for k, st in enumerate(chunk.nominal_states, 1):
            rho = self.tube_radius(k, rho0)
            gmin = min(gmin, self.F.clearance(st) - self.Lg * rho)
            emax = max(emax, self.F.effort(st) + self.Le * rho)
        gmin -= self.beta_obs; emax += self.beta_obs
        valid = (gmin >= chunk.d_safe and emax <= tau_eff
                 and h_dyn >= 0 and recheck_layers(chunk, tau_layers))
        return ClosedCert(gmin, emax, valid, [self.tube_radius(k, rho0)
                                              for k in range(1, len(chunk.nominal_states) + 1)])


# IP-358：主动避障安全滤波器（DCBF-QP）
class ActiveAvoidanceFilter:
    def __init__(self, dyn, reach, r_safe=0.15, r_rob=0.05,
                 eta=0.3, Lh=1.0, w_hat=0.05, W=None,
                 u_lo=None, u_hi=None, du_max=None):
        self.dyn, self.reach = dyn, reach
        self.r_safe, self.r_rob, self.eta = r_safe, r_rob, eta
        self.Lh, self.w_hat, self.W = Lh, w_hat, W
        self.u_lo, self.u_hi, self.du_max = u_lo, u_hi, du_max

    def barrier(self, x, t):
        obs = self.reach.over_approx(t)          # O_reach(t)（定义 544）
        return dist(x, obs) - self.r_rob - self.r_safe

    def filter(self, x, u_nom, u_prev, t):
        h = self.barrier(x, t)
        h_next = lambda u: self.barrier(self.dyn.step(x, u), t + self.dyn.dt)
        cons = [NonlinearConstraint(lambda u: h_next(u) - (1 - self.eta) * h
                                    - self.Lh * self.w_hat, 0, np.inf)]
        if self.du_max is not None:
            cons.append(NonlinearConstraint(
                lambda u: self.du_max - np.abs(u - u_prev), 0, np.inf))
        res = solve_qp(objective=lambda u: (u - u_nom) @ self.W @ (u - u_nom),
                       bounds=list(zip(self.u_lo, self.u_hi)),
                       constraints=cons, x0=u_nom,
                       time_limit_ms=0.6)
        if not res.success or res.x is None:
            return None, False, 0.0              # 不可行 → 认证中止/恢复
        a_used = norm(res.x - u_nom)
        return res.x, True, a_used


# IP-359：权限仲裁器 + 耦合模式机
class AuthorityArbiter:
    def __init__(self, a_res, K_auth=3, T_dwell=5, eps_a=1e-3, eps_crit=0.05):
        self.a_res, self.K_auth, self.T_dwell = a_res, K_auth, T_dwell
        self.eps_a, self.eps_crit = eps_a, eps_crit
        self.mode, self.over, self.dwell = 'CC', 0, 0

    def step(self, cert_valid, h, a_used, qp_feasible, abort_exists, recovery_exists):
        if (not qp_feasible and not abort_exists and not recovery_exists) \
           or h < self.eps_crit:
            self._to('AB'); return 'AB'
        if (not cert_valid) or a_used > self.a_res:
            self.over = self.over + 1 if a_used > self.a_res else 0
            if self.over >= self.K_auth or a_used > self.a_res and h < self.eps_crit:
                self._to('RP'); return 'RP'
        if a_used > self.eps_a:
            self._to('AV'); return 'AV'
        if self.dwell >= self.T_dwell:
            self._to('CC'); return 'CC'
        return self.mode

    def _to(self, m):
        if m != self.mode:
            self.mode, self.dwell, self.over = m, 0, 0
        else:
            self.dwell += 1

## 3. 推导

**引理 87（偏差管的保守性）** 若定义 540 的收缩对 (γ,w_max) 与初始界 ρ_0 成立，则 ∀k≤K：‖e_k‖ ≤ ρ_k；进而真实间隙 g(x_k) ≥ ĝ_min^{CL} + β_obs，真实力度 ≤ ê_max^{CL} − β_obs。证明：归纳。k=0 由假设。设 ‖e_k‖≤ρ_k，则 ‖e_{k+1}‖ ≤ γρ_k + w_max = γ[γ^kρ_0 + w_max(1−γ^k)/(1−γ)] + w_max = γ^{k+1}ρ_0 + w_max(1−γ^{k+1})/(1−γ) = ρ_{k+1}。再由 L_g-Lipschitz：g(x_k) ≥ F̂_clearance(x̂_k) − L_g‖e_k‖ ≥ F̂_clearance(x̂_k) − L_gρ_k ≥ min_k[·] = ĝ_min^{CL} + β_obs。力度同理。∎

**引理 88（闭环证书不弱于 v9 的开环证书）** 在 (γ,w_max) 下，ρ_k ≤ ρ_K = γ^Kρ_0 + w_max(1−γ^K)/(1−γ)。v9 若要保证整块 sound，必须取常数 β ≥ ρ_K；故对任意 k≤K，CLC 扣除的 ρ_k ≤ ρ_K，其可执行集不小于"sound 的 v9"。反之，v9 的固定 β 只覆盖"训练域内"的长期误差，一旦域偏移使一步 w 上升，β 不会自动收紧，而 CLC 通过 ACI 反馈把 q_k 抬高。特别地，当 w_k 有界但长期累积超过 β 时，v9 证书失效而 CLC 仍 sound——这切断了「Δ_dom 滞后 ⇒ 证书仍被信任」的因果链。∎

**引理 89（鲁棒 DCBF 的前向不变性）** 设真实一步演化与模型预测的偏差满足 |h(x_{k+1}) − h(f̂(x_k,u))| ≤ L_hŵ，且滤波器满足 h(f̂(x_k,u),k+1) ≥ (1−η)h(x_k) + L_hŵ。则真实 h(x_{k+1}) ≥ h(f̂) − L_hŵ ≥ (1−η)h(x_k) ≥ 0（当 h(x_0)≥0）。归纳得 ∀k：h(x_k) ≥ (1−η)^k h(x_0) ≥ 0，安全集前向不变。∎

**引理 90（权限一致性与无静默违背）** 设滤波修正 ‖δu‖≤a_res，且证书扰动界取 w_max = w_model + L_u·a_res。则滤波后的真实轨迹与标称 rollout 的偏差仍被 ρ_k 包含（引理 87 的 w_max 已计入 L_u·a_res），故"证书在管上有效"⇒"滤波轨迹安全"。AA 在 a_used > a_res 时于 K_auth 周期内（临界裕度下立即）作废证书并进入 RP/AB，因此不存在同时满足「继续执行」与「证书已失效」的周期。结合引理 89，若 RP 成功则新证书重新成立；若 AB 则进入认证中止/恢复。故系统不会静默违背定义 546。最小权限储备 a_res^min 由临界状态 h=h_crit 处满足 DCBF 的最小 ‖δu‖ 取上确界给出；当 a_res < a_res^min 时该状态只能 AB，这是可用性损失而非安全性损失。∎

**引理 91（无抖振 / 有限切换）** 模式机所有边均带阈值与计数器：AV/CC 切换需 T_dwell 驻留，RP 需 K_auth 次超预算确认，AB 由不可行/临界裕度触发且只能经 RP 离开。定义秩 r(AB)>r(RP)>r(AV)>r(CC)，任何一次切换要么消耗至少 T_dwell 个周期，要么严格增加秩且随后需显式恢复。故在长度 T 的窗口内切换次数 ≤ T/T_dwell + |ℳ|，有限时间无 Zeno；在噪声下翻转率被 T_dwell 与 K_auth 双重下界约束。∎

**引理 92（中立元严格退化到 v9）** 逐项验证：
(i) CLC 关：取 γ=0、w_max=β、ρ_0=0，则 ρ_k≡β，定义 542 逐项等于 v9 定义 533，引理 87 退化为引理 82；
(ii) AAF 关：取 U_filter={u_nom}，QP 返回 u_nom 且 a_used=0，h 检查退化为 v9 的被动间隙检查，定义 547 在 d_act=0 时与定义 534 一致；
(iii) AA 关：取 a_res=0 且忽略 a_used，模式恒为 CC，守卫完全由 v9 逻辑决定；
(iv) 组合：CLC/AAF/AA 的契约行注入各自中立元后，下游端口读数与 v9 对应路径逐位一致；再由 v9 引理 83（MW 中立元）与五级退化链，整体严格等价退回 v9，而非行为漂移。∎

## 7. 本轮最大风险

**一句话**：闭环证书与主动避障共享同一个执行器权限预算，而收缩性/保形覆盖的在线估计在接触、打滑与突发动态障碍同时发生时最不可信——若权限仲裁为了避障临时借用了证书预留的扰动预算，管半径会低估真实偏差，系统可能在"证书仍有效"的状态下发生静默的避障越界。
