# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「最优控制」×「多机器人协作」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**值证书 + 联合契约**。两个灵感分别治理 v9 的两种债：**最优性债**（AC 用 64 采样 + 手写评分，安全但不最优；重规划节拍固定 5Hz，"何时重算"没有原理）、**单机智子债**（MW/AC 只有单机视角，多机"各自安全"≠"联合安全"）。仍要求退化链，但要诚实承认：**协作端口不存在安全中立元**，v7–v9 的"严格逐位等价"纪律首次在多机边界失效，只能退化为"保守包络 → 全体安全停驻"的有界安全缺口链。

## 0. 直觉与动机

**灵感 1（最优控制 → 值证书与最优性触发重规划）**
直觉：v9 的 AC 从 64 条采样轨迹里挑"得分最高"的块，但 score 是手写启发式；Ĉ 只证明"不碰撞、不超限"，回答不了"这个块离最优有多远、什么时候值得重算"。最优控制给出了稀缺的另一半：**值函数 V(s)（cost-to-go）是决策的充分统计量**。核心创新：**值证书（ValueCertificate, VC）**——每个块附带终端值估计 V̂(s_{t+K}) 与残差 ρ；块的真实代价 J = Σ 阶段代价 + V̂(终端)。证书有效要求：(i) 最优性 J − V̂(s_t) ≤ ε_opt；(ii) 安全性——离散时间控制障碍函数（CBF）/HJ 可达值沿块非负。这样"重规划"从 v9 的固定节拍升级为**事件驱动**：只有当实测状态把已认证的 cost-to-go 恶化超过 ε_replan，才重算。这既治理 v9"固定节拍浪费算力、突变响应慢"的债，也把经验评分替换为可证明的近最优性界（引理 87）。

**直觉补充**：MPC 与无穷时域 LQR 的桥正是"终端代价 = 值函数"；给短块配一个看得更远的 V̂，就不必把 K 拉长也能近似全局最优。HJ 可达性则回答"是否存在控制使安全性对**任意扰动**成立"——它给出最大安全不变集，是安全性的最强形式。性能用值函数、安全用可达集/障碍函数，正好补上 v9 只有经验评分的空缺。

**灵感 2（多机器人协作 → 联合证书、分布式最优与通信退化）**
直觉：v9 的 MW/AC 是单机视角。多机世界里，两台各自"安全"的机器人可能联合不安全——轨迹管在块内相交、抢同一通道、或互相等待成死锁。核心创新：**多机契约层（MultiRobotContract, MRC）**：每台机器人广播块声明 β_i = (ζ_i, Ĉ_i, P_i, VC_i, 𝒯_i, V̂_i, π_i, 时间戳)。联合安全不变式要求块时域内所有轨迹管两两保持 d(𝒯_i, 𝒯_j) ≥ d_ij^safe。冲突用确定性优先级 + 让行拍卖消解；联合代价 J_joint = Σ_i J_i + Σ_{i<j} ℓ_ij 用对偶价格 λ_ij 分解为各机本地最优控制（对偶分解/ADMM）。通信失效时注入**最坏占位包络 W_{i←j}**（基于最后已知状态与速度/加速度上界的 Minkowski 膨胀），在补掉包络后的自由空间里保守规划。

**关键的理论诚实**：协作端口的中立元**不是**联合安全算子的恒等元——"忽略他机"并不能满足联合安全约束。因此 v9 的"注入中立元 ⇒ 逐位等价退回上一版"纪律在这里第一次失效。我们必须把退化链改成"**保守包络（有界安全缺口）→ 包络不可行 → 全体安全停驻（吸收元）**"，并在引理 92 里量化这道缺口。这不是缺陷，而是本文最硬的发现：**多机安全不能靠可组合中立元获得，只能靠显式的保守协议与失败即停（fail-passive）兜底。**

## 1. 研究问题（轮次升级版）

- **Q1（值证书的正确性）**：在值函数误差 ‖V̂−V*‖∞ ≤ ε_V、前向模型误差 ≤ β 的前提下，块级"近最优 + 安全"证书能否给出对**真实策略**的次优性上界？终端值残差 ρ 如何与 ε_V、ε_opt、模型误差合成？
- **Q2（联合安全与通信退化）**：如何用轨迹管包络把"每机局部安全"提升为"联合安全"？通信中断时占位包络在什么假设下可靠，何时必须升级为全体停驻？由此产生的安全缺口能否被界定？
- **Q3（分布式最优性）**：对偶价格分解在有限通信轮次下残差多大？价格 λ_ij 能否解释为"让路的边际安全成本"，并据此得到可解释、可审计的让行策略？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 值证书律（Value-Certificate, VC）**
块 ζ 除 v9 的 Ĉ 外，附带 VC = (Ĵ, V̂_term, ρ, h_min)。Ĵ = Σ_{k=1}^K ℓ(s_k,a_k) + V̂(s_{t+K})。VC 有效 ⇔ (i) Ĵ − V̂(s_t) ≤ ε_opt；(ii) min_k h(s_k) ≥ 0，其中 h 为已吸收模型误差余量的离散时间 CBF，沿块满足 h(s_{k+1}) ≥ (1−γ) h(s_k)。重规划事件：实测 V̂(s^{actual}) 使已实现代价超过认证剩余代价 ε_replan，或 CBF 余量跌破预警带 h_warn。

**P14 联合证书律（Joint-Certificate, MRC）**
每机广播块声明 β_i；联合证书有效 ⇔ 所有单机 VC 有效 ∧ 块时域内两两轨迹管间距 ≥ d_ij^safe。冲突以确定性优先级 π（固定 ID 全序 + 让行代价拍卖）消解，保证有界轮次终止、无死锁。

**P15 退化不保等价律（Conservative-Degradation，新诚实条款）**
协作端口无安全恒等元。通信中断 ⇒ 用可靠过近似包络 W 在自由空间保守规划（有界缺口 L1）；包络占满可行空间或超出可行性时域 ⇒ 全体沿最近中止点安全停驻（fail-passive，吸收元 L2）。其余端口（VC、单机 AC、MW、ID）仍遵守 v9 的中立元等价纪律。**明确放弃"多机行为严格等价于 v9"这一不成立的承诺**，只在单机/关闭 MRC 时保留严格等价（L3）。

## 3. 与基线的接口（如何退化）

- VC 值模型超差（误差 > ε_V 或连续残差越界）⇒ 丢弃 V̂，恢复 v9 手写评分 AC（等价 v9）；
- CBF/HJ 不可用 ⇒ 恢复 v9 停车不变式 d_stop（已内嵌于 AC，等价 v9）；
- 最优性触发失效 ⇒ 恢复固定 5Hz 块边界重规划（等价 v9）；
- 单机场景 / MRC 关闭 ⇒ 行为 ≡ v9 ACMD（此条仍严格成立）；
- 多机 + MRC 失效 ⇒ 保守包络模式（不等价 v9，有界安全缺口，引理 90）；
- 包络不可行 / 超可行性时域 ⇒ fail-passive 全体停驻（吸收元）；
- 感知侧 MW 超时 ⇒ v9 中立元注入（等价 v8/v7）；
- 全失效 ⇒ 逐级退回 v9 → v8 → MetricVoiceGauge-OTL-GC-ER v7 → v6。

## 4. 预期贡献

1. **值证书执行**：把块级执行从"安全但不最优"升级为带可证明次优性界的最优控制实例（终端值 + 鲁棒 CBF），并给出事件驱动重规划，进一步降低算力；
2. **联合证书与保守退化链**：多机安全的可组合性分析，第一次诚实刻画"协作中立元不可用"的边界与 fail-passive 兜底；
3. **分布式最优与可解释让行**：以对偶价格 λ_ij 解释"让路的边际安全成本"，给出有限轮次残差界；
4. **实验 E571–E590**：值误差-次优性、CBF 鲁棒性、联合碰撞率、通信中断、死锁、拍卖效率、异构违约、端到端多机竞赛。

## 5. 本轮最大风险

**一句话**：多机安全建立在"所有同伴遵守同一速度上界与协作协议"这一共同假设上，占位包络对违约的恶意/异构快机不再 sound，而 fail-passive 全体停驻又会制造停驻诱发的连环拥堵或被追尾——最保守的保命动作在多机流里反而成为新的攻击面。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-VOC-MRC**（Value-Optimal Certificates & Multi-Robot Collaboration）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「最优控制」×「多机器人协作」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v9 的 AC/MW/ID 与 v8 的 DA-ML/SPR/Cal 原样继承。新增 VC/MRC 为**可选增强**：单机或关闭 MRC 时行为 ≡ v9（引理 92 的 L3）；但多机协作端口**不存在安全中立元**，其退化改为"保守包络 → fail-passive"的有界安全缺口链，这是本版对 v7–v9 退化哲学的有意修正。

**退化链声明（v10 六层，注意 L1–L2 不再逐位等价）：**
- L0 联合认证：全部单机 VC + 联合安全证书有效；
- L1 保守包络：通信部分/全部丢失且 Δt<T_trust，各机在补掉占位包络的自由空间内独立保守规划（有界安全缺口，非 v9 等价）；
- L2 全体停驻：Δt≥T_trust 或包络可行空间为空 ⇒ 各机沿最近中止点 p* fail-passive 安全停驻（吸收元）；
- L3 单机 / 关闭 MRC：行为 ≡ v9 ACMD（严格逐位等价，唯一保留的严格等价层）；
- L4 v9 内部退化：VC/V̂ 失效 ⇒ v9 评分 AC；CBF 失效 ⇒ v9 d_stop；5Hz 固定节拍；
- L5 v9 以下：DA/SPR/Cal 中立元 ⇒ 等价 v8/v7；全失效 ⇒ v7 → v6。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |

| J(ζ) = Σ_{k≤K} ℓ(s_k,a_k) + V̂(s_{t+K}) | 块的真实代价估计（阶段代价 + 终端值） |

**新增定义 540（值证书 ValueCertificate）** 块 ζ_t=(a^{1:K}, Ĉ_t, P_t) 扩展为 ζ_t=(a^{1:K}, Ĉ_t, P_t, VC_t)，VC_t=(Ĵ_t, V̂_t^term, ρ_t, h_t^min)。其中 Ĵ_t=Σ_{k=1}^K ℓ(s_k,a_k)+V̂_θ(s_{t+K})，ρ_t=ε_V 为终端值误差余量，h 为安全函数。VC 有效 ⇔
```
Ĵ_t − V̂_θ(s_t) ≤ ε_opt + ε_V      （近最优性）
min_{k≤K} h(s_k) ≥ 0              （安全性）
```
V̂_θ 为冻结的 cost-to-go 网络（iLQR/DDP 离线生成专家轨迹 + 拟合，在线仅前向推理 ≤0.5ms），误差界 ‖V̂−V*‖∞ ≤ ε_V（E571 标定）。

**新增定义 541（离散时间 CBF / HJ 安全值）** 理想安全值 V_HJ(s) 由 Hamilton-Jacobi-Isaacs 可达性给出：安全集 𝒮={s : V_HJ(s)≥0}。可计算实例用离散时间 CBF h，h 已吸收前向模型误差余量（即在 β-收缩后的轨迹管上定义），沿块满足
```
h(s_{k+1}) ≥ (1−γ) h(s_k),  γ ∈ (0,1]
```
则 h(s_0) ≥ 0 ⇒ h(s_k) ≥ 0 ∀k（引理 88）。HJ 是理论上界，CBF 是其可微、可实时求值的下近似。

**新增定义 542（最优性触发重规划 Value-Gap Trigger）** 块内执行第 k 步后观测到 s_{t+k}：
```
J_real(k) = Σ_{j<k} ℓ(s_j,a_j) + V̂(s_{t+k})
J_cert(k) = Ĵ_t − Σ_{j<k} ℓ(s_j,a_j)
重规划 ⇔ J_real(k) − J_cert(k) > ε_replan  ∨  h(s_{t+k}) < h_warn
```
否则继续执行至块边界。块边界重规划作为 v9 兜底保留。

**新增定义 543（块声明 BlockClaim）** 机器人 i 广播 β_i(t)=(ζ_i, Ĉ_i, P_i, VC_i, 𝒯_i, π_i, t_i^stamp)，其中 𝒯_i={𝒯_i(k)}_{k≤K_eff^{(i)}}，𝒯_i(k) 为第 k 步可达集（v9 的 β 余量膨胀后）。

**新增定义 544（联合安全证书 JointSafetyCertificate）** 对共同时域 K=min_i K_eff^{(i)}，联合证书有效 ⇔
```
∀i: VC_i 有效  ∧  ∀i<j, ∀k≤K: d(𝒯_i(k), 𝒯_j(k)) ≥ d_ij^safe
```
d 为集合距离。任一条件失效即触发定义 546 的让行或定义 545 的包络退化。

**新增定义 545（占位包络与通信中立元 OccupancyEnvelope）** 机器人 i 对 j 的占位包络
```
W_{i←j}(t) = W_j(t_j^stamp) ⊕ B( v_max,j·Δt ) ⊕ B( ½·a_max,j·Δt² ),  Δt = t − t_j^stamp
```
即最后已知扫掠体的 Minkowski 膨胀。在同伴遵守 (v_max,a_max) 上界时，它是 j 实际位置集合的**可靠过近似**（引理 89）。通信端口的中立元取"退避到 W_{i←j} 之外"，而非"忽略 j"——这是它区别于 v9 恒等元的关键。

**新增定义 546（确定性让行拍卖 DeterministicYieldingAuction）** 冲突集 C 内机器人按绕行代价增量出价
```
bid_i = J_i(绕行) − J_i(直行) + Σ_j λ_ij
```
低价者优先通行，其余让行；固定 ID 全序作 tie-break；每轮至少最高优先级者不改变意图 ⇒ 轮次上界 |C|，无活锁/死锁（E580）。

**新增定义 547（耦合代价与对偶分解 CooperativeOptimalControl）** 联合代价
```
J_joint = Σ_i J_i(ζ_i) + Σ_{i<j} ℓ_ij(ζ_i, ζ_j)
```
ℓ_ij 惩罚管间距不足。取对偶价格 λ_ij≥0，各机本地最小化 J_i + Σ_j λ_ij·g_ij（g_ij 为间距约束违反量），主问题对偶上升 λ_ij ← [λ_ij + η·g_ij]^+。T_dual 轮后的残差 Δ_dual 计入 ε_opt，保持证书 sound 但更松（引理 91）。

**新增定义 548（通信信任与可行性时域 TrustHorizon）** 在同伴遵守 (v_max,a_max) 上界的前提下 W_{i←j} 对一切 Δt sound；T_trust,i 定义为包络首次吞没 i 全部可行自由通道的时间（或超过 T_comm）。Δt<T_trust ⇒ L1 保守规划可行；Δt≥T_trust ⇒ 升级 L2 fail-passive。

**新增定义 549（MRC 退化状态机）**
```
L0 联合认证  : 全部 VC + 联合证书有效
L1 保守包络  : 通信缺失 ∧ Δt<T_trust  → 自由空间 \ ⋃W 内独立保守规划（有界缺口）
L2 全体停驻  : Δt≥T_trust ∨ 包络吞没可行空间 → 沿最近中止点 fail-passive（吸收元）
L3 单机/关闭 : 无同伴 ∨ MRC 关闭 → 行为 ≡ v9 ACMD（严格等价）
L4 v9 内退化 : V̂ 失效→v9 评分；CBF 失效→v9 d_stop；触发失效→5Hz 固定节拍
L5 v9 以下   : DA/SPR/Cal 中立元 → v8/v7；全失效 → v6
```

## 2. 形式化定义（要点与升级）

# IP-357 ValueCertifier：值证书器
class ValueCertifier:
    def __init__(self, V_hat, cbf_h, eps_opt, eps_V, eps_replan,
                 gamma, h_warn, F_hat):
        self.V, self.h = V_hat, cbf_h
        self.eps_opt, self.eps_V = eps_opt, eps_V
        self.eps_replan, self.gamma, self.h_warn = eps_replan, gamma, h_warn
        self.F = F_hat

    def certify(self, s0, chunk):
        states, costs = self.rollout(s0, chunk.actions)      # F_hat 前向
        J_hat = sum(costs) + self.V(states[-1])              # 定义 540
        opt_ok = (J_hat - self.V(s0)) <= self.eps_opt + self.eps_V
        h_vals = [self.h(s) for s in states]
        cbf_ok = min(h_vals) >= 0 and all(
            self.h(states[k + 1]) >= (1 - self.gamma) * self.h(states[k])
            for k in range(len(states) - 1))                 # 定义 541
        return VC(J_hat, self.V(states[-1]), rho=self.eps_V,
                  h_min=min(h_vals), valid=opt_ok and cbf_ok)

    def replan_trigger(self, chunk, k, s_actual):
        realized = chunk.cum_cost(k) + self.V(s_actual)
        certified = chunk.VC.J_hat - chunk.cum_cost(k)
        return ((realized - certified) > self.eps_replan
                or self.h(s_actual) < self.h_warn)           # 定义 542


# IP-358 MultiRobotContract：多机契约层
class MultiRobotContract:
    def __init__(self, robot_id, comms, d_safe_fn, v_max, a_max, T_comm):
        self.id, self.comms = robot_id, comms
        self.d_safe, self.v_max, self.a_max = d_safe_fn, v_max, a_max
        self.T_comm = T_comm
        self.last_swept, self.last_stamp = {}, {}

    def envelope(self, j, now):                              # 定义 545
        dt = now - self.last_stamp[j]
        r = self.v_max[j] * dt + 0.5 * self.a_max[j] * dt * dt
        return self.last_swept[j].minkowski_ball(r)

    def coordinate(self, my_claim, peer_claims, now):
        env = {j: self.envelope(j, now) for j in peer_claims}
        if self.joint_cert_valid(my_claim, peer_claims):     # 定义 544
            return 'L0', my_claim
        lost = any(now - self.last_stamp[j] > self.T_comm for j in peer_claims)
        if not lost and self.can_plan_conservative(env):     # 定义 548
            order = self.yielding_auction([my_claim] + list(peer_claims.values()))
            return 'L1', self.plan_around(env, order)         # 定义 546
        return 'L2', self.fail_passive(my_claim)              # 定义 549

    def joint_cert_valid(self, mine, peers):
        K = min([mine.K_eff] + [p.K_eff for p in peers.values()])
        for k in range(K):
            for j, p in peers.items():
                if d(mine.tube[k], p.tube[k]) < self.d_safe(self.id, j):
                    return False
        return all(p.VC.valid for p in peers.values()) and mine.VC.valid


# IP-359 CooperativeValueDecomposer：对偶价格分解
class CooperativeValueDecomposer:
    def __init__(self, eta=0.05, T_dual=8):
        self.eta, self.T_dual = eta, T_dual

    def solve(self, claims, local_solvers):
        lam = {ij: 0.0 for ij in self.pairs(claims)}
        for _ in range(self.T_dual):                          # 定义 547
            plan = {i: local_solvers[i](claims[i], lam) for i in claims}
            for (i, j) in lam:
                g = self.separation_violation(plan[i], plan[j])
                lam[(i, j)] = max(0.0, lam[(i, j)] + self.eta * g)
        residual = sum(self.separation_violation(plan[i], plan[j])
                       for (i, j) in lam)
        return plan, lam, residual                            # Δ_dual → ε_opt

## 4. 推导

**引理 87（值证书次优性界）** 设 ‖V̂−V*‖∞ ≤ ε_V，且块内前向模型阶段代价误差 ≤ β_ℓ。若 VC 有效（Ĵ−V̂(s_0) ≤ ε_opt+ε_V），则块策略的真实代价满足 J_true(ζ) ≤ V*(s_0) + 2ε_V + ε_opt + K·β_ℓ。证明：由 Bellman 最优性 V*(s_0) ≤ Σℓ_true + V*(s_K) ≤ Σℓ_true + V̂(s_K) + ε_V = J_true + ε_V；又 J_true = Σℓ_true+V̂(s_K) ≤ Σℓ̂+Kβ_ℓ+V̂(s_K)=Ĵ+Kβ_ℓ（Ĵ 定义 540）≤ V̂(s_0)+ε_opt+ε_V+Kβ_ℓ ≤ V*(s_0)+ε_opt+2ε_V+Kβ_ℓ。终端 V̂ 吸收尾部，故无随 K 指数的因子。∎

**引理 88（鲁棒 CBF 前向安全）** 若 h(s_{k+1}) ≥ (1−γ)h(s_k)、γ∈(0,1]，且 h(s_0)≥0，则 h(s_k) ≥ (1−γ)^k h(s_0) ≥ 0 ∀k，轨迹始终位于安全集 𝒮 内。证明：对 k 归纳，h≥0 时 (1−γ)h≥0。∎ HJ 值 V_HJ 是其理论上界（任意扰动下最大不变集），CBF 为其实时可微实例；F̂ 预测误差已通过 β-收缩进 h 的定义。

**引理 89（占位包络的可靠性）** 若 |v_j|≤v_max,j、|a_j|≤a_max,j，则真实位置 p_j(t) ∈ W_{i←j}(t) 对一切 t≥t_j^stamp 成立。证明：由运动学可达集上界，位置偏差 ≤ v_max dt + ½ a_max dt²，Minkowski 膨胀恰为其外接球过近似。∎

**引理 90（保守规划的联合安全）** 若每机 i 的规划轨迹与 ⋃_{j≠i}W_{i←j} 保持 d_ij^safe 间距，且各 W 满足引理 89，则任意两机间距 ≥ d_ij^safe，块时域内联合无碰撞。证明：p_j(t)∈W_{i←j}(t)，traj_i 与 W 的间距 ≥d_safe ⇒ d(traj_i,p_j)≥d_safe。∎ 该引理保证 L1 模式在协议假设下的安全性，缺口来自包络膨胀导致的保守性（可行空间收缩），而非碰撞。

**引理 91（对偶分解收敛与有限轮残差）** 对凸 J_i、ℓ_ij 与有界次梯度，对偶上升步长 η 收敛；T_dual 轮后残差 Δ_dual=O(1/T_dual)。将 Δ_dual 计入 ε_opt 后引理 87 仍成立（证书 sound 但更松）。∎

**引理 92（严格等价不可得 / 有界安全缺口）** 不存在联合安全算子的中立元 v^⊥ 使"注入 v^⊥"既满足联合安全又等价于 v9（v9 无联合约束）。形式上，"忽略他机"投影在同伴占据本机规划通道时违反联合安全谓词；故退化必须经 L1 保守包络、最终 L2 fail-passive。L1 相对 L0 的安全缺口由包络膨胀 d_ij^safe 界定（保守性，非碰撞）；L2 保持安全但机动性归零。因此 v7–v9 的严格逐位等价仅在 L3（单机/关闭 MRC）保留，这是该退化哲学首次被显式放宽并被量化界定的地方。∎
