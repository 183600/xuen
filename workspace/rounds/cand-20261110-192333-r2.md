# 第 47 轮（本循环第 2 轮；承接第 46 轮 v23 / 四层 v10；本轮灵感：自监督学习 × 可用性评估） · SSL-Usability：自监督覆盖扩展 × 可用性预算约束的证书治理（五层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v10/v23 把能量、姿态、记忆、语音、安全队列都纳入了证书与 fail-closed 体系，但隐含假设 H5：**证书与上下文预测器总能靠独立标注审计集校准，且“保守 fail-closed”在可用性上是免费的**。现实是：透明/镜面/弱纹理/深度空洞等 Ω_deg 尾部样本标注昂贵且稀少，审计集只能给出边际覆盖，尾部仍可能静默失守；而一个技术上 sound 的系统若频繁停机、反复要求确认、语音重问，就会被用户判定为不可用，进而被绕过或被不信任。两个灵感词精确命中 H5：**自监督学习**把时序一致性、跨模态一致性、可预测性当作免费监督，用无标注流扩展 Ω_deg 覆盖并挖掘困难样本；**可用性评估**把用户的重问/纠正/中止/任务耗时当作分布内的免费弱标签流，并把“可用性预算”提升为一等约束。二者耦合出新问题：**如何用自监督免费监督扩展覆盖、用人类交互免费监督校准信任，同时保证可用性压力永远不会把安全证书悄悄放松成“舒服但不安全”？**

## 0. 直觉与动机

**灵感 1（自监督学习 → 免费覆盖扩展，但不免费给保证）**
直觉：世界自己会“出题”。同一场景相邻帧应一致、RGB 与深度应几何一致、不同增强视图应语义一致；不一致处往往正是退化层或分布漂移。于是无需人工标注即可得到一致性分数 s_ssl 与新颖度 n_ssl，用来：①把 Ω 切成自监督分层；②挖掘困难/新颖样本回灌采集（DCL）；③给上下文预测器提供伪标签。关键警惕：**自监督只负责“提议”，不负责“担保”**。它可以把样本分层、给出非一致性分数，但最终覆盖率仍必须由共形校准在标注审计集（或经门控的人类弱标签）上兑现；SSL 表征坍缩时，正确做法是证书变宽（可检测），而不是假装更确定。

**灵感 2（可用性评估 → 人类是分布内的免费校准集）**
直觉：用户每次“再说一遍”“不对，是那个杯子”“停”都是一条免费的、分布内的弱标签，且恰好标注了我们最在乎的失败。把可用性形式化为向量 u=(任务耗时、干预率、中止率、重问率、信任校准误差、解释充分度)，并设可用性预算 B_u。可用性评估不只是事后问卷，而是持续的在线信号：既用于校准（人类弱标签），也用于治理（约束交互策略）。

**灵感 3（双免费监督闭环 → 安全更便宜、交互更可信）**
直觉：SSL 让“安全”更便宜（更少标注覆盖更广尾部），可用性评估让“安全”不被浪费（减少不必要的停机与误解释）。但二者也互相诱导：可用性压力想把证书调松，SSL 的过度自信会把罕见失败藏进低新颖度簇。因此必须规定一条硬边界：**可用性只能优化交互层（确认阈值、解释粒度、任务推迟），绝不能下调安全证书的失败预算下限 α_safe**。

**耦合升级**：在 v10 四层之上新增第五层 **SUGL（Self-supervised Usability Governance Layer，自监督-可用性治理层）**。SCE 用 SSL 扩展分层覆盖与困难样本；UEV 在线估计可用性与信任校准；UBCG 在“总风险预算 α_safe + 可用性预算 B_u”双约束下，只在可行安全包络内分配**分层风险预算**并调整交互策略。四层不推倒：ECPS 用新颖度预触发深度，PSE 用分层 α_ω 签发证书，DCL 接收 SSL 困难样本，CCA 红队 SSL 假阴性与可用性博弈，CAR 增加可解释 fail-closed。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（自监督一致性分数与新颖度）**
对观测 x 构造 K 个视图 T_1..T_K（时序邻帧、RGB-深度跨模态、增强不变性）。编码器 f_θ 以 InfoNCE 训练：
L_ssl = -Σ_{i<j} log [ exp(sim(f(T_i x), f(T_j x))/τ) / Σ_{neg} exp(sim(f(T_i x), f(neg))/τ) ]。
一致性分数 s_ssl(x) = (2/(K(K-1))) Σ_{i<j} d(f(T_i x), f(T_j x))。
新颖度 n_ssl(x) = 在参考池上对 s_ssl 的秩归一化。**高 s_ssl/高 n_ssl = 视图互相矛盾或远离参考分布**。

**定义 60（SSL 分层与分层覆盖证书）**
用 n_ssl 与上下文 c_t 把 Ω 划分为自监督分层 g(x)∈{1..G}。对每层用共形非一致性分数 A_ssl(x)=n_ssl(x) 在标注审计集（及门控后的人类弱标签）上校准：
p_ω(x) = (1 + #{i∈I_ω: A_ssl(x_i) ≥ A_ssl(x)}) / (|I_ω|+1)，
证书集合 C_ω(x) = { y : p_ω(x,y) > α_ω }。
若层内可交换，则 P(Y∈C_ω | g=ω) ≥ 1-α_ω。**SSL 决定分数与分层，共形校准负责覆盖兑现**；SSL 错误只会改变效率（宽度），不会凭空提高覆盖率。

**定义 61（可用性向量与可用性预算）**
u_t = (T_task, r_int, r_abort, r_reask, ECE_trust, L_expl)。
可用性代价 C_u(u) = c_T·T_task/T_max + c_I·r_int + c_A·r_abort + c_R·r_reask + c_E·ECE_trust + c_L·(1-L_expl)。
**可用性预算**：C_u(u) ≤ B_u。B_u 由用户研究/任务规范给定。

**定义 62（信任校准误差）**
对上下文簇 k，用户信任 t_k（显式评分或行为推断）与系统经验成功率 ŝ_k：ECE_trust = Σ_k w_k·|t_k - ŝ_k|。过度信任（t_k>ŝ_k）是安全风险，信任不足（t_k<ŝ_k）是可用性风险；系统必须主动解释证书宽度与 fail-closed 原因以缩小 ECE。

**定义 63（分层风险预算与证书治理）**
全局安全预算 α_safe。为每层分配失败预算 α_ω，满足
Σ_ω π_ω·α_ω ≤ α_safe，0 ≤ α_ω ≤ α_safe（并集界）。
证书半径 rad_ω(α_ω) 随 α_ω 增大而收缩。治理问题：
max_{α_ω, θ, ℓ} E[U_task(rad_ω, θ, ℓ)]
s.t. Σ_ω π_ω α_ω ≤ α_safe；C_u(u) ≤ B_u。
其中 θ 为确认阈值、ℓ 为解释粒度。**硬约束**：α_ω ≤ α_safe 恒成立，可用性只可调整 α 的“层间分配”和交互层，绝不可抬高全局下限。

**定义 64（双免费监督闭环与一致性门控）**
SSL 伪标签 y_ssl 与人类弱标签 y_h 的一致性 a = 1[y_ssl = y_h]（或连续一致度）。仅当 a ≥ τ_agree 时，SSL 伪标签可进入**候选挖掘/分层提议**；进入**校准集**必须经人类弱标签确认或保持为未标注池。定义双监督覆盖率增长
ΔCov = Cov(SSL∪human) - Cov(audit)，并以假阴性率 FNR_ssl = P(n_ssl 低 | 真实 ω∈Ω_deg) 作为核心审计量。

## 2. 新增产出与既有 IP 升级

**IP-69 SCE（SSL Coverage Expander）**
- 多视图编码器：时序对比、RGB-深度几何一致、增强不变性
- s_ssl / n_ssl 在线计算与秩归一化
- SSL 分层 g(x) 与分层共形非一致性分数
- 困难/新颖样本挖掘 → 回灌 IP-61 DCL
- 伪标签一致性门控 τ_agree

**IP-70 UEV（Usability Evaluator）**
- 交互遥测：任务耗时、干预、中止、重问、解释查看
- 信任校准 ECE 在线估计
- 解释充分度探针（用户是否理解了 fail-closed 原因）
- 可用性预算 B_u 与违规监测

**IP-71 UBCG（Usability-Budgeted Certificate Governor）**
- 在 [0, α_safe] 内做分层风险预算分配（并集界）
- 拉格朗日/二分求解交互策略 θ、ℓ
- 可用性压力只作用于交互层，安全下限锁死
- 可解释 fail-closed：输出“哪一层、哪条预算、为何不可行”

**既有 IP 升级**
IP-63 ECPS：用 n_ssl 提前触发深度预热（新颖度前哨）
IP-65 CONTEXT PREDICTOR：SSL 伪标签仅作候选，校准仍靠人类弱标签
IP-61 DCL：采集任务加入 SSL 困难样本与新颖样本
IP-62 CCA：新增 SSL 假阴性红队、可用性博弈红队（诱导放松证书）
IP-51 CAR：fail-closed 附带分层解释与替代动作建议
IP-45 总线：新增 ssl-novelty / usability-metric / trust-calibration / risk-budget 话题

## 3. 算法骨架

SUGL 每评估周期：
1. 读无标注多模态流，计算 s_ssl、n_ssl、SSL 分层 g(x)
2. 困难/新颖样本入 DCL 候选；伪标签经 a≥τ_agree 门控
3. 在审计集 + 已确认人类弱标签上做分层共形校准，得 p_ω、rad_ω
4. UEV 由交互日志估计 u_t、ECE_trust，判断 C_u(u) ≤ B_u
5. UBCG 在 Σπ_ω α_ω ≤ α_safe、C_u≤B_u 下求解 α_ω^*、θ^*、ℓ^*
6. PSE 按 rad_ω(α_ω^*) 签发 P_t；CAR 用 P_t 守卫并生成解释
7. 若 SSL 分层出现表征坍缩（层内 A_ssl 方差→0）或可用性不可行 → 证书加宽 + 保守交互，并上报审计

## 4. 本轮最大风险

**一句话**：可用性预算的压力与自监督新颖度的过度自信会合谋出一个“舒服但不安全”的系统——SSL 可能把罕见的透明/镜面样本因表征坍缩或虚假不变性压进低新颖度簇，治理器又把有限风险预算挪向任务相关层以换取流畅交互，而减少标注使审计集过小、难以发现该尾部失守；因此必须锁死 α_safe 硬下限、为每层设最小审计样本量、持续红队 SSL 假阴性，并禁止可用性优化触碰证书安全下限。

## 2. 关键算法 伪代码

### IP-69 SCE
```
def ssl_scores(x, f_theta, views):
    zs = [f_theta(T(x)) for T in views]
    s = mean([1 - cos(zs[i], zs[j])
              for i in range(len(zs)) for j in range(i+1, len(zs))])
    return s

def ssl_stratify(x, ref_pool, f_theta, views, G):
    s = ssl_scores(x, f_theta, views)
    n = rank_normalize(s, ref_pool)          # 新颖度
    g = cluster_assign(f_theta(x), k=G)      # 表征聚类 + 上下文
    return s, n, g

def ssl_ssl_gate(y_ssl, y_human, tau_agree=0.8):
    a = agreement(y_ssl, y_human)
    return a >= tau_agree          # 只允许进入候选/分层提议

def ssl_hard_mining(n_ssl, pool, top_ratio=0.1):
    return topk(pool, key=n_ssl, ratio=top_ratio)  # 回灌 IP-61 DCL
```

### IP-70 UEV
```
def usability_vector(logs):
    T_task = mean_task_time(logs)
    r_int  = rate(logs, 'intervention')
    r_ab   = rate(logs, 'abort')
    r_re   = rate(logs, 'reask')
    L_expl = mean_explanation_view(logs)
    ECE    = trust_calibration_error(logs)
    return dict(T_task=T_task, r_int=r_int, r_abort=r_ab,
                r_reask=r_re, L_expl=L_expl, ECE_trust=ECE)

def usability_cost(u, w, T_max):
    return (w.T*u.T_task/T_max + w.I*u.r_int + w.A*u.r_abort
            + w.R*u.r_reask + w.E*u.ECE_trust + w.L*(1-u.L_expl))

def usability_ok(u, w, B_u, T_max):
    return usability_cost(u, w, T_max) <= B_u
```

### IP-71 UBCG
```
def conformal_radius(n_ssl, calib_by_layer, alpha_by_layer):
    rad = {}
    for w, cal in calib_by_layer.items():
        p = conformal_pvalue(n_ssl, cal)
        rad[w] = radius_from_pvalue(p, alpha_by_layer[w])
    return rad

def allocate_risk(pi_w, alpha_safe, task_utility):
    # 并集界：sum_w pi_w*alpha_w <= alpha_safe
    # 只做层间再分配，任何 alpha_w 不得超过 alpha_safe
    alpha = {w: alpha_safe for w in pi_w}     # 初始化
    while sum(pi_w[w]*alpha[w] for w in alpha) > alpha_safe:
        # 把预算从“边际效用最低”的层收回
        w = argmin_marginal(task_utility, alpha)
        alpha[w] = max(0.0, alpha[w] - d_alpha)
    return alpha

def ubcg_govern(pi_w, alpha_safe, u, B_u, w, T_max, task_utility):
    alpha = allocate_risk(pi_w, alpha_safe, task_utility)
    theta, ell = 0.85, 'normal'
    # 可用性只调交互层，绝不抬高 alpha 下限
    if not usability_ok(u, w, B_u, T_max):
        theta = min(0.95, theta + d_theta)     # 更谨慎确认
        ell   = 'verbose'                      # 增强解释
        if not usability_ok(project(u, theta, ell), w, B_u, T_max):
            return alpha, theta, ell, 'infeasible-conservative'
    return alpha, theta, ell, 'ok'
```

### 全局闭环
```
def sugl_cycle(x, logs, calib, pi_w, alpha_safe, B_u, f_theta, views):
    s, n, g = ssl_stratify(x, calib.ref_pool, f_theta, views, G)
    # 困难样本入 DCL；伪标签仅在门控后作候选
    dcl_enqueue(ssl_hard_mining(n, calib.pool))
    alpha, theta, ell, status = ubcg_govern(
        pi_w, alpha_safe, usability_vector(logs), B_u, W, T_max, task_utility)
    rad = conformal_radius(n, calib.by_layer, alpha)
    P_t = PSE.certify(x, rad[g], alpha[g])
    if status == 'infeasible-conservative':
        return P_t, 'fail-closed', explain(g, alpha, 'usability-infeasible')
    return P_t, 'execute', explain(g, alpha, status)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCE 多视图打分 | O(K·d) 每样本 | O(K·d) | SSL 只提议分层与分数，不直接给覆盖保证 |
| 分层共形校准 | O(|I_ω|) 每层 | O(Σ|I_ω|) | 层内可交换 ⇒ P(Y∈C_ω)≥1-α_ω |
| UEV 遥测估计 | O(1) 每交互 | O(1) | 可用性为软约束，不改变安全谓词 |
| UBCG 风险分配 | O(G·(α_safe/Δα)) | O(G) | Σπ_ω α_ω≤α_safe ⇒ 全局失败概率≤α_safe（并集界） |
| 全局闭环 | O(K·d + G·|I|) | O(Σ|I_ω|) | 安全下限锁死；不可行即保守 fail-closed |

**正确性定理**：设每层共形校准满足层内可交换，且治理器输出满足 Σ_ω π_ω α_ω ≤ α_safe、0≤α_ω≤α_safe。则姿态证书的全局失败概率
P(X_t ∉ P_t) ≤ Σ_ω π_ω α_ω ≤ α_safe。
自监督分数 A_ssl 只作为非一致性分数与分层依据，其错误不破坏该不等式，只会改变证书宽度；伪标签未经人类弱标签确认不得进入校准集。若可用性约束在安全包络内不可行，系统返回保守交互与 fail-closed 解释，而非放松 α_safe。

| E115 SSL 尾部新颖度 | Ω_deg 上 AUROC；固定 FPR 下 FNR | AUROC ≥ 0.85；FNR ≤ 10% |
| E116 分层共形覆盖 | 各层经验覆盖 vs 名义覆盖 | 偏差 ≤ ±2%；层间最小样本 ≥ n_min |
| E117 伪标签门控 | 一致性率、伪标签伤害率 | τ_agree=0.8 时伤害率 ≤ 2% |
| E118 可用性评估 | 任务耗时、干预率、SUS | SUS ≥ 75；干预 ≤ 1 次/10 任务 |
| E119 信任校准 | ECE_trust、过/欠信任率 | ECE ≤ 0.10；过信任 ≤ 5% |
| E120 100h 闭环 | 安全违例、可用性预算违规、覆盖增长 | 违例 0；预算违规 ≤ 5%；覆盖 +30% 且标注 +≤10% |

**回退策略**：E115 FNR > 15% → 关闭 SSL 新颖度门控，回退纯标注审计；E116 覆盖缺口 > 5% → 加宽 α_ω 或关闭分层、退回全局共形；E117 伤害率 > 5% → 提高 τ_agree 至 0.9；E118 可用性不可行 → 增强解释/调整任务推迟，**绝不放松 α_safe**；E119 信任失准 → 增加证书宽度可视化与 fail-closed 原因说明。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| SSL 表征坍缩把罕见退化样本压成低新颖度 | 高 | 层内 A_ssl 方差监控；坍缩即证书加宽；独立红队假阴性 |
| 可用性压力诱导放松证书 | 高 | α_safe 硬下限；可用性只调交互层；审计日志留痕 |
| 伪标签污染校准集 | 高 | 一致性门控 τ_agree；伪标签只进候选池，不进校准集 |
| 减少标注导致审计集过小 | 中 | 每层最小审计配额 n_min；主动学习补样 |
| 解释过度增加认知负荷、反伤可用性 | 中 | 解释粒度 ℓ 分级；用 ECE 与 SUS 联合调 |
| 人类弱标签有噪声/偏置 | 中 | 弱标签降权；多用户聚合；与审计集交叉验证 |

## 6. 本轮最大风险

**一句话**：自监督的过度自信与可用性预算的压力会形成“舒服但不安全”的合谋——SSL 把罕见的透明/镜面/深度空洞样本误判为低新颖度，治理器为流畅交互把风险预算挪向任务相关层，而缩减的标注审计集又不足以暴露尾部失守，最终名义覆盖成立而真实安全静默破坏；因此必须锁死 α_safe、设每层最小审计量、持续红队 SSL 假阴性，并禁止可用性优化触碰安全证书下限。
