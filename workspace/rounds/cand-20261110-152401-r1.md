# 第 46 轮（承接第 45 轮 v10；本轮灵感：泛化能力 × 轨迹优化） · GenTraj-Cert：泛化租约 × 轨迹证书 × 证书感知轨迹优化（四层架构 v11）

> 承接第 45 轮 v10 Energy-Context-Depth。v10 把姿态升级为分层条件覆盖证书、能量升级为租约、上下文升级为预测性深度门控，但保留两个从未被打开的根假设：**H6 校准分布 = 部署分布**——所有共形保证只是校准分布 Q 下的**边际**覆盖，换场景、换任务、换实施例、甚至闭环自诱导的状态分布变化都会让可交换性失效，而 v10 把 Q 默认成永远代表 P；**H7 点态证书可组合为轨迹安全**——v10 的守卫逐时刻签发证书，安全却被默认成「每一步都过就等于整段安全」，忽略了误差沿时间累积、相邻步误差相关、以及采样间空隙。两个灵感词精确命中这两层：**泛化能力**迫使我们把证书从「同分布声明」升级为带**分布偏移半径**与**支持集**的泛化租约；**轨迹优化**迫使我们把证书从「点态」升级为**整条轨迹的管状覆盖**，并让优化器在证书约束下规划。二者耦合出全新且对抗性的问题：**轨迹优化会主动把系统推到性能边界，而那里正是证书最薄、支持最稀、分布偏移最大的地方——优化器因此成为泛化证书的对手，并通过改变状态访问分布制造自诱导协变量偏移；如何在泛化租约、轨迹管证书与优化器之间建立可证一致的安全闭环**。

## 0. 直觉与动机

**灵感 1（泛化能力 → 泛化租约与分布偏移半径）**
直觉：覆盖保证从来不是无条件的。共形预测给的是「在 Q 上抽取校准集、在 Q 上抽取测试点」的边际保证；一旦部署分布 P 偏离 Q，覆盖可以静默崩塌，尤其是 Ω_deg 这类在校准集里本就稀少的层。因此证书必须自带一个**适用范围**：把参考校准分布 Q_ref、可容许偏移半径 ρ_gen、支持集分位 q_β、实施例签名 σ_emb 打包成**泛化租约 ℓ_g**，与姿态租约、能量租约并列为根信任。ℓ_g 有效意味着「当前部署分布仍落在证书可迁移的球内」，失效则证书不可信、直接 fail-closed 或触发主动重校准。迁移界用 TV：若 Q 下覆盖 ≥1−α 且 TV(P,Q)≤ρ_gen，则 P 下覆盖 ≥1−α−ρ_gen——这把「泛化」变成可计算、可审计、可扣减的量，而不是一句口号。

**灵感 2（轨迹优化 → 轨迹级证书与不确定管）**
直觉：安全不是逐帧截图，而是一整段电影。把每步半径 r_t 沿动力学用 Lipschitz 常数传播成不确定管 R_t：R_{t+1}≥L_x R_t+L_u‖Δu‖+w_max。于是「轨迹安全」= 名义轨迹的整条管都不碰障碍且在安全集内。再定义**轨迹非一致性分数** S(ξ)=max_t 归一化裕度亏空，用整条轨迹的校准集取共形分位 q̂_{1−α_T}，得到轨迹级证书 T_t={ξ:S(ξ)≤q̂}，其覆盖为 1−α_T，比逐点并集界 1−Σα_t 更紧且能利用误差相关。α 预算也不该平均分：按各步风险权重 w_t∝L_φR_t 分配，把有限的覆盖预算花在管最粗、下游最敏感的时刻。

**灵感 3（耦合 → 优化器是证书的对手：自诱导分布偏移与证书套利）**
直觉：优化器不是被动执行者。它会把轨迹贴着证书边界推，因为那里任务代价最低；而证书边界正是校准支持最薄、外推最不可信的地方。更隐蔽的是，优化后的策略改变了状态访问分布 P_π，于是即使在同一环境内，部署分布也不再等于校准分布——**优化行为本身制造了分布偏移**。因此必须做**证书感知轨迹优化**：把鲁棒管安全、泛化支持、轨迹覆盖预算做成硬约束，把「信息增益」作为受限探索项去扩张支持，并显式惩罚**证书套利**（在证书便宜但支持稀薄的区域刷性能）。同时要求 (π*, ℓ_g) 满足不动点一致性：π* 在 ℓ_g 允许的分布球内求解，且 π* 诱导的偏移不超过 ρ_gen；不存在不动点即 fail-closed。

**耦合升级**：在 v10 四层上新增**泛化-轨迹证书层**。根信任层增加泛化租约 ℓ_g；L1 几何层由点态半径升级为**泛化修正半径 + 轨迹管**；L2 上下文层加入 OOD/新颖度检测，上下文预测越界即触发 ℓ_g 复核；L3 CAR 升级为**泛化-轨迹联合门**；L4 DCL 从「补覆盖」升级为**主动扩张校准支持**（采集 OOD 轨迹、新场景、新实施例）；并新增证书感知轨迹优化器，只在认证域内规划。

## 1. 形式化定义（增量：定义 54–57）

**定义 54（泛化租约与覆盖迁移）**
设参考校准分布 Q（覆盖状态/观测/任务/实施例联合空间），部署分布 P，按分层 ω 记为 Q_ω、P_ω。分布偏移半径
ρ_gen(β)=max_ω ρ_gen,ω，其中 P(TV(P_ω,Q_ω)≤ρ_gen,ω)≥1−β。
**泛化租约** ℓ_g=(Q_ref,ρ_gen,q_β,h_g,σ_emb)，支持判据用新颖度 s(x) 在 Q 上的 (1−β) 分位 q_β。
**覆盖迁移定理**：若在 Q 下 P_Q(Y∈C(X))≥1−α，且 TV(P,Q)≤ρ_gen，则
P_P(Y∈C(X)) ≥ 1−α−ρ_gen。
证明：对任意可测证书集 A，|P_P(A)−P_Q(A)|≤TV(P,Q)≤ρ_gen，故 P_P(A)≥P_Q(A)−ρ_gen。∎
ℓ_g 有效 ⇔ sup_ω D̂_ω≤ρ_gen ∧ s(x_t)≤q_β ∧ σ_emb 匹配 ∧ t−τ_g≤h_g。
**推论（泛化不是布尔值）**：证书可用性随偏移连续退化，ρ_gen 应作为扣减项进入守卫，而不是等偏移爆表才失效。

**定义 55（轨迹证书与不确定管）**
轨迹 ξ_{0:T}=(x_0,u_0,…,x_T)，逐点半径 r_t(x_t,m_t)。**不确定管**递推
R_0=r_0，R_{t+1}=L_x R_t+L_u‖Δu_t‖+w_max。
**轨迹非一致性分数** S(ξ)=max_t [(θ_φ−m_t)/R_t]_+，其中 m_t 为名义裕度。
在 M 条校准轨迹上取共形分位 q̂_{1−α_T}，**轨迹证书** T_t={ξ:S(ξ)≤q̂}，满足
P(S(ξ_true)≤q̂) ≥ 1−α_T。
**α 预算分配**：取 α_t 使 Σ_t α_t≤α_T，风险加权
α_t=α_T·w_t/Σ_s w_s，w_t∝L_φ·R_t。
**点态不可组合命题**：逐点覆盖 1−α 在 T 步上只能给并集界 1−Tα；当 Tα≥1 时界为空，且相关性未被利用。故不存在由逐点证书直接推出轨迹安全的 sound 规则，必须显式做轨迹级校准或保守预算分配。

**定义 56（证书感知轨迹优化与自诱导偏移）**
优化变量 u_{0:T−1}：
min J_task(ξ)+λ_r·Risk(ξ)−λ_i·InfoGain(ξ)
s.t. x_{t+1}=f(x_t,u_t), u_t∈U,
R_{t+1}≥L_x R_t+L_u‖Δu_t‖+w_max,
dist(X̂_t,𝒪)>R_t ∀t（管安全），S(ξ)≤q̂，
s(x_t)≤q_β ∀t（支持约束），Σ_t α_t≤α_T。
**自诱导偏移** D_π=TV(P_π,Q_ref)，P_π 为策略 π 的状态访问分布。
**不动点一致性**：策略-租约对 (π*,ℓ_g) 合法 ⇔ D_{π*}≤ρ_gen ∧ π* 为上式在 ℓ_g 下的解；不存在则拒绝规划并回退保守控制器。
**证书套利**：定义缺口 Γ_cert=sup_{ξ∈T}(empirical margin−certified margin)，优化目标对高 Γ_cert/高新颖度区域加罚，禁止用未认证支持换性能。

**定义 57（泛化-轨迹联合证书与联合门）**
联合证书 G_t=(P_t,T_t,ℓ_p,ℓ_e,ℓ_g,m_t)。
**联合 soundness**：若 ℓ_p、ℓ_e、ℓ_g 均有效、T_t 满足轨迹级覆盖、管安全，则
P(Φ(ξ_{0:T}) | ω,m,ℓ 有效) ≥ 1−(α_T+α_e)−ρ_gen−ε_δ。
**联合门**：CAR 仅在「三租约有效 ∧ 轨迹管安全 ∧ T_t sound ∧ 支持未越界」时放行；任一失效进入 TrajectoryFailClosed 或 GeneralizationFailClosed，优化器不得在租约失效时继续规划。

## 2. 三大新增产出与既有 IP 升级

**IP-66 GEN-CERT（泛化证书引擎）**
- 实施例/场景/任务签名 σ_emb 与参考分布 Q_ref 注册
- 分层 TV/MMD 漂移估计：分类器双样本检验为主、MMD 为回退，给单侧上置信界
- 加权共形（密度比 w=dP/dQ）与新颖度支持检验双保险
- 泛化租约签发/续期/失效级联；失效触发主动重校准而非静默降级

**IP-67 TRAJ-CERT（轨迹证书引擎）**
- Lipschitz 不确定管传播（状态/控制/过程噪声三源）
- 轨迹级非一致性分数与共形分位校准
- α 预算分配（风险加权，必要时用相关误差模型替代并集界）
- 滚动时域证书刷新：规划期签发、执行前复核、过期即废

**IP-68 CERT-TRAJ-OPT（证书感知轨迹优化器）**
- 鲁棒管硬约束的 direct collocation / iLQR（增广拉格朗日保证硬约束）
- 支持约束与信息增益受限探索项（扩张校准支持但不出认证球）
- 证书套利惩罚与保守回退控制器
- 规划-证书-租约不动点求解与拒绝机制

**既有 IP 升级**
IP-60 PSE：点态半径升级为泛化修正 r_ω(m)·(1+c_g·ρ_gen)，并输出轨迹管
IP-63 ECPS：深度门控受泛化支持约束；上下文预测 OOD 即触发 ℓ_g 复核
IP-61 DCL：从补覆盖升级为主动扩张支持，采集 OOD 轨迹/新场景/新实施例，护照新增 distribution_signature / novelty
IP-62 CCA：新增分布偏移红队、优化器证书套利红队、轨迹覆盖与泛化间隙审计
IP-51 CAR：升级为 v7 泛化-轨迹联合门（含管安全与支持检查）
IP-45 总线：新增 generalization-lease / trajectory-cert / novelty-score / drift-estimate 话题

## 3. 算法骨架

每个控制周期：
1. 读 ℓ_p、ℓ_e、ℓ_g、T_t、当前新颖度与漂移估计。
2. 若 ℓ_g 失效或新颖度越界 → GeneralizationFailClosed 或请求重校准。
3. 轨迹优化器在认证域内求解，检查管安全、轨迹分数与支持约束。
4. 执行首段控制，滚动刷新 T_t 与 α 预算。
5. CAR 用泛化修正半径扣减裕度，三租约联合门放行。
6. 采集器优先采样高新颖度/高 Γ_cert 轨迹，回灌扩张支持。
PSE 签发 P_t(m_t)，TRAJ-CERT 签发 T_t，二者共同进入守卫。

## 4. 本轮最大风险

**一句话**：泛化租约依赖对真实分布偏移与支持集的估计，而优化器会主动把系统推向支持稀薄、证书最薄的边界以换取性能，一旦漂移/新颖度被系统性低估，ℓ_g 会假有效、轨迹管看似安全而覆盖率已崩塌，产生静默安全违例；因此必须用单侧上置信界估计偏移、对优化器做证书套利红队，并在支持耗尽时直接 fail-closed。

## 2. 关键算法 伪代码

### IP-66 GEN-CERT（泛化租约 + 漂移/支持检验）
```
def tv_upper(Pn, Qn, strata, beta):
    # 分类器双样本检验：TV ≈ 1 - 2*err_bayes；用 Clopper-Pearson 上界保守化
    ub = {}
    for w in strata:
        err = two_sample_clf_error(Pn[w], Qn[w])
        tv_hat = 1.0 - 2.0*err
        ub[w] = clopper_pearson_upper(tv_hat, len(Pn[w]), beta/len(strata))
    return ub

def novelty_score(x, Q_ref):
    return Q_ref.embed_dist(x)          # 嵌入空间距离 / energy score

def gen_lease(Pn, Q_ref, s_t, beta, rho_gen, h_g, t):
    if s_t > Q_ref.q_beta:      return INVALID('support')
    ub = tv_upper(Pn, Q_ref.data, Q_ref.strata, beta)
    if max(ub.values()) > rho_gen: return INVALID('drift')
    return Lease(Q_ref, rho_gen, Q_ref.q_beta, h_g, Q_ref.sig_emb, tau=t)

def weighted_conformal_quantile(scores, w, alpha):
    # 加权共形（Tibshirani et al.）：w=dP/dQ，权重和归一
    order = argsort(scores); cw = cumsum(w[order])/sum(w)
    return scores[order][first_index(cw >= 1-alpha)]

def generalized_coverage_floor(alpha, rho_gen):
    return 1.0 - alpha - rho_gen      # 覆盖迁移定理的直接下界
```

### IP-67 TRAJ-CERT（不确定管 + 轨迹共形）
```
def tube_propagate(x0, R0, us, Lx, Lu, du_max, w_max):
    xs, Rs = [x0], [R0]
    for u in us:
        xs.append(f(xs[-1], u))
        Rs.append(Lx*Rs[-1] + Lu*du_max + w_max)
    return xs, Rs

def tube_safe(xs, Rs, obstacles):
    return all(dist(x, obstacles) > R for x, R in zip(xs, Rs))

def traj_score(xs, Rs, phi, theta):
    return max(max(0.0, (theta - margin(x, phi))/R) for x, R in zip(xs, Rs))

def traj_cert(xs, Rs, qhat, phi, theta):
    return tube_safe(xs, Rs, obstacles) and traj_score(xs, Rs, phi, theta) <= qhat

def alpha_budget(Rs, alpha_T):
    w = [R/sum(Rs) for R in Rs]        # 风险权重 ∝ 管粗 × 敏感度
    return [alpha_T*wi for wi in w]
```

### IP-68 CERT-TRAJ-OPT（证书感知轨迹优化）

```
def cert_traj_opt(x0, T, task, calib, lg, qhat, lam_r, lam_i):
    if not lg.valid:                       return FailClosed('generalization')
    def rollout(z):
        xs, us = decode(z); return xs, tube_propagate(x0, calib.r0, us, ...)
    def cons(z):
        xs, Rs = rollout(z)
        return [capsule_dynamics(xs, us),
                tube_safe(xs, Rs, calib.obstacles),
                traj_score(xs, Rs, calib.phi, calib.theta) <= qhat,
                all(novelty_score(x, lg.Q_ref) <= lg.q_beta for x in xs),
                sum(alpha_budget(Rs, calib.alpha_T)) <= calib.alpha_T]
    z = sqp(obj=task(z) - lam_i*info_gain(z) + lam_r*cert_arbitrage_gap(z),
            cons=cons(z), x0=x0)
    if not feasible(z):                    return conservative_fallback(x0)
    pi = policy_from(z)
    if tv_upper_rollout(pi, lg.Q_ref) > lg.rho_gen:   # 不动点一致性
        return FailClosed('self_induced_shift')
    return z

def info_gain(z):
    # 仅用于扩张支持：对 q_β 边界附近、信息量高但仍在球内的状态给正项
    return mean(novelty_score(x, Q_ref) * local_entropy(x) for x in z.xs)
```

### IP-51 CAR v7（泛化-轨迹联合门）
```
def car_guard_v7(e, x, cert, persona, lp, le, lg, T_t, t):
    # 1) 三租约全部有效（不可补偿）
    if not (pose_lease_valid(lp,t) and energy_lease_valid(le,t,E_min(e))
            and gen_lease_valid(lg,t)):
        cascade_invalidate('pose_energy_generalization')
        return FailClosed()
    # 2) 轨迹级：管安全 + 轨迹证书 sound
    if not tube_safe(T_t.xs, T_t.Rs, cert.obstacles):
        return TrajectoryFailClosed('tube')
    if not traj_cert(T_t.xs, T_t.Rs, cert.qhat, cert.phi, cert.theta):
        return TrajectoryFailClosed('score')
    # 3) 泛化修正半径扣减（覆盖退化折算成几何保守量）
    r = radius_lookup(x.stratum, x.m_t, cert.calib) * (1 + c_g*lg.rho_gen)
    m_pose   = L_phi[e]*r
    m_energy = L_e*(B_min - E(t))_+
    m_gen    = L_g*lg.rho_gen + L_s*max(0, T_t.score - cert.qhat)
    m = min(cert.lookup, lp.m, persona_cap) - m_pose - m_energy - m_gen
    return m >= theta(e)
```

```
def dcl_expand(loops, support, budget):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GEN-CERT 漂移估计 | O(n_d) 分类器 / O(n_d²) MMD，按审计周期 | O(n_d) | 单侧上置信界 ⇒ P(TV≤ρ_gen)≥1−β |
| 新颖度支持检验 | O(d_emb) 每样本 | O(n_cal) | Q 上支持覆盖 ≥1−β |
| TRAJ-CERT 管传播 | O(T) | O(T) | Lipschitz 递推 ⇒ 真实轨迹在管内 |
| 轨迹共形校准 | O(M·T) 离线 + O(log M) 分位 | O(M·T) | 轨迹级覆盖 ≥1−α_T |
| α 预算分配 | O(T log T) | O(T) | Σα_t≤α_T ⇒ 并集界可用 |
| CERT-TRAJ-OPT | O(N_iter·T·(n_x+n_u)³) | O(T·(n_x+n_u)) | 硬约束 SQP ⇒ 可行解满足全部证书约束 |
| CAR v7 | O(1) 守卫（管预计算） | O(T) | 三租约 ∧ 管安全 ∧ T_t ⇒ fail-closed 级联 |

**联合正确性定理**：若 ℓ_p、ℓ_e、ℓ_g 均有效，T_t 满足轨迹级覆盖 1−α_T，管安全，且能量证书满足 α_e-sound，则泛化-轨迹联合证书 G_t 对谓词 Φ(ξ_{0:T}) 的 soundness 下界为 1−(α_T+α_e)−ρ_gen−ε_δ。证明要点：轨迹级覆盖给出 P(S(ξ_true)≤q̂)≥1−α_T；TV 迁移把该结论搬到 P 并扣 ρ_gen；管包含性把归一化裕度亏空转成谓词违例界 ε_δ；能量项并集界。任一前提失效即进入对应 FailClosed。∎

**命题（点态不可组合）**：T 步逐点覆盖 1−α 仅给并集界 1−Tα；Tα≥1 时界为空，且未利用误差相关性，故不能由点态证书直接推出轨迹安全。
**命题（优化诱导偏移破坏可交换性）**：若优化策略改变状态访问分布使 D_π>0，则校准集与部署样本不再可交换，未修正的共形覆盖在 P_π 下无保证；因此必须满足 (π*,ℓ_g) 不动点一致性，或使用加权共形 + ρ_gen 扣减。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 漂移/新颖度低估导致 ℓ_g 假有效 | 高 | 单侧上置信界 + 独立偏移审计 + 支持耗尽即 fail-closed |
| 优化器证书套利（贴边界刷性能） | 高 | 硬支持约束 + Γ_cert 惩罚 + 套利红队 + 受限信息增益 |
| 不确定管过度保守致任务不可用 | 中 | 分层 Lipschitz、相关性误差模型、按 regime 收紧/放松 |

| 主动扩张支持时发生未认证探索 | 高 | 探索仅在保守控制器覆盖下、受认证探索预算约束 |
| 多证书并集界随证书数变松 | 中 | 相关性建模替代朴素并集界；关键证书 α 收紧 |

## 6. 本轮最大风险

**一句话**：泛化租约与轨迹管都建立在「偏移/新颖度/管半径被正确估计」之上，而证书感知优化器会主动把系统推向支持稀薄、证书最薄的边界以换取性能，一旦估计偏低，ℓ_g 会假有效、轨迹管看似安全而真实覆盖率已崩塌，产生静默安全违例；因此必须以单侧上置信界估计偏移、对优化器做证书套利红队，并在支持耗尽或不动点不一致时直接 fail-closed。
