# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「轨迹优化」×「状态隔离」）

> R69 让系统第一次学会「问」，但它的问是**短视的**：`VoI(g)` 只对单个信息动作、单个动作块计算，问完再重新决策，等价于每步都做 Myopic MPC，忽略了「先走到能看清的位置再问」这类信息动作的**时序与路径依赖**。更关键的是，R69 把「多模态假设」和「被认证的物理控制状态」揉在同一个状态里：一旦模态权重未校准、或某个回答被投毒，一个幻影模态就可能被直接写进被认证的控制回路。R69 自陈的最大风险正是这个——「问错，比不问更危险」。
>
> 本轮两个灵感正好各补一刀：
> - **轨迹优化**把 R69 的单步 VoI 升级为**有限时域联合「做—看—问」轨迹优化**：信息不是一次孤立动作，而是可以排进一条前瞻轨迹的节点；系统优化的是「先走到哪里、看什么、问什么、得到不同回答后各自怎么收」的**应急计划树**，而不是贪心地问一句再说。
> - **状态隔离**把「假设」与「控制」从结构上分开：每个模态跑在**隔离的分支状态**里，信念/证据/隔离区都有**单向晋升屏障**；未经 k 源一致 + 几何裕度验证，任何单条观测都写不进被认证的控制态。安全因此在**所有未消解假设下同时成立**，而不依赖「消歧是否恰好正确」。
>
> 核心命题：**安全不再由「我猜对了哪个模态」保证，而由「所有假设都活着时，我的轨迹仍落在它们安全集的交里」保证；当这个交为空，才由几何（而非可能未校准的模态权重）强制系统去问或停车；问哪个，才交给 R69 的 VoI。** 命名 **ISOLATE-RAS**（Isolated-State Optimal Look-Ahead Trajectory Engine for Risk-Adaptive Shielding）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在还没问清之前，我能不能先走一条对所有答案都安全的轨迹**」——把「问」从安全的前置条件，降级为效率的可选优化。

## 0. 直觉与动机

**灵感 1（轨迹优化 → 信息动作是轨迹上的节点，不是孤立的一步）**
直觉：R69 的 VoI 是贪心的，它不知道「先靠近看清楚」会让后续某个提问变得不必要，也不知道「先问再走」与「先走再问」哪个更省。信息动作的价值本质上是**路径依赖**的：走到不同位置，可问的问题、能看到的证据、以及得到回答后的安全裕度都不同。把 `(a, g)` 放进同一条有限时域轨迹里联合优化，得到的就是「先探路—再提问—按回答分支恢复」的应急计划树。理论上，短视计划可以作为长视计划的前缀，故 horizon-VoI 弱支配 myopic VoI。

**灵感 2（状态隔离 → 假设必须活在各自的笼子里）**
直觉：每个模态其实蕴含一个**不同的物理未来**。R69 用信念加权把它们揉成一个期望状态，正是「以 0.5 的速度同时走两条路」这种荒谬动作的来源。隔离的做法：给每个模态维护独立的 `x^(k)` 与独立 rollout，分支之间**只共享动作和观测流，绝不共享状态**；信念、证据、疑似故障各在独立命名空间里。这是操作系统「进程隔离 / 故障containment」在控制回路里的类比——一个分支崩了，不能把别的分支和已认证控制态一起带走。

**灵感 3（共同安全管 → 安全可以与消歧解耦，本轮最重要的理论姿态）**
直觉：如果一条轨迹同时落在**所有**未消解模态的安全集交集里，那么无论哪个模态为真，它都安全。于是「问」不再是安全的前置条件，而只是效率选项；而「是否必须问」变成一个**几何可行性问题**：当共同安全管为空（各模态安全集互不相容，如绕左 vs 绕右、接住 vs 避让），才强制交互或安全停车。这使得交互触发**只依赖被认证的安全集与动力学，不依赖可能未校准的模态权重**——正面回应 R69 的阿喀琉斯之踵：R69 用「信念熵 × 可分性」这种软量决定要不要问，而软量恰恰是最可能未校准的部分。R70 把「必须问」交给硬几何，把「问哪个」才交还给软 VoI。

**灵感 4（隔离的代价 → 瘫痪与模型自欺）**
直觉：隔离不是免费的。a) 若分支永不合并，系统会**瘫痪**在共同管里（或安全停车到天荒地老），所以必须有带 deadline 的提交/合并协议；b) 共同管保证的好坏完全取决于 `Safe_k` 与分支动力学——模型错了，隔离只会给出「错误模型里的自信安全」，而且因为没有强制提问，这种错误比 R69 的幻影模态**更难被发现**；c) 计算隔离 ≠ 语义隔离，若所有分支共享同一条被投毒的观测流，它们仍然强相关，所以证据本身也要分源隔离。

**灵感 5（对 R69 的姿态 → 严格泛化，而不是替代）**
直觉：取 H=1（无前瞻）、K=1（单分支、信念合并、无隔离），ISOLATE 逐指令退化为 R69 的 VoI 决策：MSTO 变成单步期望成本最小化，LAP 变成 MINT，CST 空等价于「唯一支撑模态下所有动作都不安全」。因此 R69 是本轮在「单分支短视」边界上的退化；安全侧永不更弱，效率侧多出「不必问也能安全走」的一档。延续 R69 的原则：新层必须严格包含旧层，否则每加一层就多一个需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ISOLATE-RAS 总览）** ISOLATE-RAS = (MSTO, BIM, CST, LAP, QZ, CMP, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **隔离不变式**：信念/模态/隔离区位于独立命名空间，写被认证控制态只有唯一通道 `Promote`，且须满足 k 源一致（R69 定义 293-iii）与几何裕度；
(iii) **共同安全不变式**：提交（commit）之前，执行轨迹必须位于所有活跃分支安全集的交 `∩_{k∈supp(b)} Safe_k` 内；交集为空时只允许「信息动作 or 安全停车」。

**定义 311（隔离增广状态）** `s = (x, {x^(k)}, b, e, q)`。`x` 为已提交物理态；`x^(k)` 为模态 k 的隔离分支态；`b` 为模态信念；`e` 为分源证据；`q` 为隔离/疑似故障标志。隔离性：`x^(k)_{t+1} = f_k(x^(k)_t, a_t, o_t)`，从不读取 `x^(j) (j≠k)`；分支仅共享动作 `a_t` 与观测流，不共享状态。

**定义 312（模式感知安全管轨迹优化 MSTO）** 决策 `U = (a_{0:H-1}, {g at nodes})`，目标
`min_U E_{k~b}[Σ_t c_k(x^(k)_t, a_t)] + λ_r·CVaR_α(risk) + λ_i·Σ cost(g)`
s.t. `x^(k)_t ∈ Safe_k (∀k∈supp(b), ∀t<commit)`、控制限幅、R69 交互预算、证据纪律。因分支隔离，动力学雅可比块对角：每个分支独立求解 DDP/iLQR，共享动作由加权 Q 一致性（ADMM / 块坐标）耦合，共同管约束作为投影。

**定义 313（共同安全管 CST 与空证书）** `T_∩(x,b) = {U : ∀k∈supp(b), rollout_k(U) ⊆ Safe_k}`；裕度 `m_∩(U) = min_{k,t} dist(x^(k)_t, ∂Safe_k)`。若 `T_∩ = ∅`（或 `m_∩ < δ_cst`），输出**强制交互/停车证书**。注意：该判据只用安全集与动力学，不用模态权重，故对模态校准误差不敏感。

**定义 314（前瞻应急计划 LAP 与 horizon-VoI）** 应急计划是一棵深度 H 的树：节点为信息动作 g，边为可能回答 y，叶为恢复轨迹。`VoI_H(plan) = H(M|o) − E_y[H(M|o, y along plan)]`。安全强制时，用 `VoI_H − cost` 在候选 g 中选「问哪个」；非强制时，仅当效率收益 > 成本才问（R69 的「可选消歧」语义被保留）。

**定义 315（并行分支 DDP 与共享动作一致性）** 各分支求解局部 `Q_k`；共享动作由 `argmin_a Σ_k b_k Q_k(a) + ρ‖a−ā‖²` 迭代；收敛后校验 `U∈T_∩`。复杂度 `O(K·H·n³)` 可并行；K=1 时退化为单分支 DDP。

**定义 316（信念隔离管理器 BIM / 单向晋升）** 证据只写 `e`；`Promote(m)` 需 (i) ≥k 个正交源一致、(ii) `m_∩ ≥ m_commit`、(iii) 无 active quarantine，方可将 `x^(m)` 写入 `x` 并选择 m。任何单条观测、单个模态回答、单个流采样都没有直接写控制态的路径——这是对 R69 幻影模态风险的**结构性**隔离。

**定义 317（故障隔离区 QZ）** 当 R69 FMA 报 `slow_fault_suspect`，fork 影子态 `x_shadow` 到隔离区，独立运行标定/估计/似然检验；调查期间 live 控制回路完全不受污染；仅当影子假设被独立验证并通过 CMP 才晋升，否则丢弃。这把 R69 的「对偶告警」升级为「可调查的隔离副本」。

**定义 318（提交/合并协议 CMP）** Commit 条件：后验质量 ≥ `1−δ_commit`、`m_∩ ≥ m_commit`、k 源一致、且距上次 commit 的时间在界内。Commit 走 bumpless transfer：状态拷贝 + 不变量检查 + 控制连续性约束（继承 R68 定理 15）。若 deadline 前无法 commit：安全停车或退回 R68，绝不无限隔离（防瘫痪）。

**定义 319（隔离非污染，引理化）** 见引理 21：单条未验证证据/mode 改变执行动作的概率 ≤ R69 引理 18 的上界，且被 CST 几何门进一步压低；与 R69 中模态权重可直接驱动 VoI 与选模不同，这里该路径被单向屏障切断。

**定义 320（严格包含 R69）** 取 H=1、K=1（单分支、信念合并、无隔离）：MSTO = 单步期望成本最小化，LAP = MINT，`T_∩=∅ ⇔` 唯一支撑模态下所有动作都不安全 `⇔` R69 也退回保守。故 R69 = ISOLATE 的「单分支短视」边界。

**定义 321（证书 J_ISO）** `J_ISO = (J_FLUID, cst_margin_min, horizon_H, branch_count_K, isolation_violations, commit_latency, shadow_fault_auc, ddp_residual, iso_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 隔离违规=0 ∧ 共同管不变量全时成立 ∧ 审计通过`。

**定义 322（威胁模型 AIC-ISO）** `ℰ_ISO = ℰ_FLUID × {branch_desync（分支喂陈旧/恶意观测）, state_injection（越隔离边界写）, tube_forgery（用错 Safe_k 伪造共同管）, model_exploitation（优化器利用模型误差）, fragmentation_DoS（逼系统永久隔离）}`。

**定义 323（审计 VQAuditor-T）** 审计轨迹级决策：共同管是否用正确支撑集计算、commit 是否有据、隔离边界是否被穿越、优化是否在「吃」模型误差（残差/敏感度）、QZ 是否被恰当释放；结论回灌 AuditBuf，成为 H/K 与 commit 阈值的先验。

**定义 324（自适应 H/K 与实时预算）** 默认 `H=1、K=1`（等价 R69，<2.6ms）；仅当 `mode_head` 报歧义或 `m_∩` 接近 `δ_cst` 时升 `H≤5、K≤4`，并 warm-start DDP；报告 P99 与超支次数。

**定义 325（两级安全退避的扩张）** 若 `T_∩` 非空：执行共同管轨迹（resolution-free safety）；若 `T_∩` 空且交互成功：转向已提交分支；若交互失败/超时/被投毒/ECE 越界/疑似故障：安全停车或 R68 纯保守。安全侧永不弱于 R69；效率侧多出「不必问也能安全走」的一档。

**定义 326（与 R69 的接口）** R69 的 g 候选 = LAP 树上的节点；R69 的 VoI = 在强制节点上「选哪个 g」的准则；R69 的模态分布 = 分支支撑与先验；R69 的 FMA = QZ 触发。ISOLATE 不替换 FLUID，而是把它的每个决策放进「隔离状态 + 前瞻轨迹」的容器里。

# IP-264 MSTO：模式感知安全管轨迹优化（分支隔离 + 并行 DDP + 共享动作一致性）
class ModeAwareTubeOptimizer:
    def optimize(self, x, branches, b, H):
        # 分支隔离 => 动力学块对角；各分支独立 DDP，仅共享动作与共同管约束耦合
        Qs = [ddp_solve(br.f, br.x0, cost_k, H) for k, br in branches.items()]
        a_bar = weighted_mean([Q.q for Q in Qs], w=b)          # 共享动作初值
        for it in range(N_ADMM):
            a_bar = consensus([Q.argmin_q(a_bar, rho) for Q in Qs], w=b)
        U = rollout_shared(branches, a_bar, H)
        m = cst_margin(U, branches, b)
        if m is None or m < DELTA_CST:
            return None, empty_certificate(branches, b)         # CST 空 => 强制交互/停车
        return U, m

# IP-265 BIM：信念隔离管理器（唯一写控制态的 Promote 通道）
class BeliefIsolationManager:
    def observe(self, obs, src):
        self.evidence[src].append(obs)                         # 只写分源证据区
    def promote(self, m):
        if not self.evidence.k_orthogonal_agree(k=2): return False
        if self.cst.margin(m) < M_COMMIT:            return False
        if self.quarantine.active:                   return False
        self.committed = m; self.x = self.branch[m].x  # 唯一受控写入
        return True

# IP-266 CST：共同安全管与空证书
def cst_margin(U, branches, b):
    margins = []
    for k in support(b):
        if not rollout_in_safe(branches[k], U): return None
        margins.append(min_clearance(branches[k], U))
    return min(margins)

# IP-267 LAP：前瞻应急计划树（安全强制时只选「问哪个」）
def plan_lookahead(x, b, H, g_candidates):
    U, m = MSTO.optimize(x, M.branches, b, H)
    if U is not None:
        return {'mode': 'execute', 'U': U, 'margin': m}
    g = max(g_candidates, key=lambda g: M.mint.voi_H(g, b) - cost(g))  # R69 VoI 仅此用
    return {'mode': 'interact_forced', 'g': g}

# IP-268 QZ：故障隔离区（影子态进隔离容器，不进控制回路）
def quarantine_if_suspect(fma, x):
    if fma.slow_fault_suspect:
        return fork_isolated(x)                                # 只读拷贝 + 独立估计器
    return None

# IP-269 CMP：提交/合并（带 deadline，防瘫痪）
def commit_or_fallback(bim, now, deadline):
    if bim.can_promote():
        return bumpless_transfer(bim.branch[bim.committed].x)  # 不变量 + 连续性检查
    if now > deadline:
        return safe_stop_or_R68()                              # 绝不无限隔离
    return None                                                # 继续共同管/隔离调查

# IP-274 主闭环（继承 R69，在决策处插入隔离与前瞻）
def ISOLATE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 1) R69 先验：模态分解 + 行为似然第二意见
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 2) 隔离：为每个模态 fork 独立分支态；疑似故障进 QZ 影子态
    M.branches = {k: fork_branch(modes[k], M.x) for k in modes}
    shadow = quarantine_if_suspect(slow, M.x)
    # 3) 前瞻轨迹优化：非空共同管就执行（安全与消歧解耦）
    plan = M.lap.plan_lookahead(M.x, M.belief, H=M.H, g_candidates=M.info_actions)
    if plan['mode'] == 'execute':
        U = plan['U']                                          # 对所有支撑模态同时安全
    else:
        ans = M.cia.execute(plan['g'])                         # 安全强制交互
        M.bim.observe(ans, src='interaction')
        if M.bim.promote(answer_to_mode(ans)):
            U = M.lap.plan_lookahead(M.x, M.belief, H=M.H, g_candidates=[])
        else:
            U = safe_stop_or_R68()                             # 证据不足 => 保守
    # 4) 认证 + 执行 + 审计
    A = M.ach.propose(M.branches, U, H=M.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(U.a[:k]) * max(lam_floor(U_ale), 0.0)
    M.vqa_t.submit_async(plan, a_hat, cst_margin=plan.get('margin'), shadow=shadow)
    return k, U, (U_ale, U_epi), plan

## 3. 推导

**引理 19（共同安全管的鲁棒保证）** 设真实模态 `k* ∈ supp(b)`。若 `U ∈ T_∩(x,b)`，则对任意 `k∈supp(b)`，`rollout_k(U) ⊆ Safe_k`，特别地 `rollout_{k*}(U) ⊆ Safe_{k*}`。故**执行 U 的安全性不依赖消歧是否正确**，只依赖支撑集覆盖真实模态。证明：由 `T_∩` 定义逐时刻归纳；每一步 `x^(k)∈Safe_k` 且 `Safe_k` 前向不变。注意：该引理**不需要**模态权重校准，只需要支撑集不遗漏真值。

**引理 20（前瞻弱支配短视）** 在相同信息动作预算与成本下，H 步最优计划的期望决策风险不高于贪心短视策略。证明：短视策略是 H 步计划空间中以「后续不再收集信息」为约束的前缀，DP 最优值 ≤ 任一可行策略值。系：**前瞻只会让「问」更少、更准，不会更多**——因为它能提前把未来回答纳入规划。

**引理 21（隔离非污染与幻影模态上界）** 由于控制态写入只经 `Promote`，而 `Promote` 需 k 源一致且几何裕度，故单条未验证证据/单个幻影模态改变执行动作的概率 ≤ `δ_p·ρ^{k−1}+ε_σ`（复用 R69 引理 18），且被 `m_∩ ≥ m_commit` 的几何门进一步压低。相较 R69：模态权重可直接驱动 VoI 与选模；R70 切断了这条「软量 → 控制」的直连路径。

**引理 22（共同管空 ⇒ 交互必要性）** 若 `T_∩(x,b) = ∅`，则对任意动作 a，存在 `k∈supp(b)` 使 `rollout_k(a)` 越出 `Safe_k`。因此在支撑集覆盖真值的前提下，要以概率 ≥ 1−δ 保持安全，必须**缩小支撑集**（观测/交互）或**停车**。反之，若 `T_∩` 有裕度，即使模态熵很高，安全也不强制交互——消歧可延后或省略。这正是把「是否必须问」从软 VoI 阈值变成硬几何判据的依据。

**定理 18（ISOLATE 严格包含 R69）** 取 H=1、K=1 时，MSTO 退化为单步期望成本最小化、LAP 退化为 MINT、CST 空等价于 R69 的保守退避，故二者逐指令相同。在 H>1 或 K>1 时，由引理 19–20，期望风险 ≤ R69 且安全不依赖消歧正确性。因此 R69 是 ISOLATE 在「单分支短视」边界上的退化，安全侧不做让步，效率侧获得 resolution-free 安全与更长视收益。

**定理 19（隔离-优化闭环的安全与无突变）** 引理 19 保证提交前对全支撑安全；CMP 的 bumpless transfer 保证提交瞬间状态连续、不变量保持（继承 R68 定理 15）；QZ 保证疑似故障调查期间 live 回路零污染；退避链（共同管空 → 交互 → 失败则 R68/停车）使 λ 单调不降。故控制连续、无突变，且安全与「是否猜对」解耦。

**定理 20（交互触发的必要-充分性）** 由引理 22，CST 空是安全强制交互的**必要**条件；由引理 19，CST 非空时执行共同管即可安全，交互对安全**非必要**。于是组合策略在安全维度上不冗余、不遗漏；VoI 只在已被安全强制或已被效率收益触发的节点上做「选哪个」的次级优化。代价是：该性质依赖 `Safe_k` 与分支动力学的正确性（见第 6 节风险）。

## 6. 本轮最大风险

**一句话**：状态隔离能保证「分支之间不互相污染」，却保证不了「每个分支的 `Safe_k` 与动力学模型本身是对的」——一旦安全集或模型被误设，共同安全管就是一张盖了数学印章的空头支票，系统会以极大的自信，在一个错误的模型里保持「认证过的安全」；而且因为不再被迫提问，这种错误比 R69 的幻影模态**更难被观测到**。

**次级风险与缓解**：
1. **隔离瘫痪**（分支永不合并、长期停在共同管）→ CMP 带 deadline + 最大隔离时长 + 超时退 R68/停车；
2. **空证书导致过度保守/频繁停车** → 只在 `m_∩ < δ_cst` 时升 H/K，并用 R69 交互争回裕度；
3. **DDP 利用模型误差**（规划出一条模型里安全、现实里不安全的轨迹）→ 鲁棒管/机会约束 + 残差敏感度审计（E310、VQAuditor-T）；
4. **语义隔离缺失**（共享投毒观测流使分支相关）→ BIM 分源证据隔离 + E311 分支失同步攻击测试；
5. **CST 伪造/越界写** → 独立证书校验（C-RAS-WM 二次认证）+ 单向屏障 + E312/E313。

class ModeAwareTubeOptimizer:

    def promote(self, m):

        if not rollout_in_safe(branches[k], U): return None
        ms.append(min_clearance(branches[k], U))
    return min(ms)

## 4. 推导

**引理 19（共同安全管的鲁棒保证）** 若真实模态 `k*∈supp(b)` 且 `U∈T_∩`，则 `rollout_{k*}(U)⊆Safe_{k*}`；执行 U 的安全性不依赖消歧是否正确，只依赖支撑集覆盖真值、不需要模态权重校准。

**引理 20（前瞻弱支配短视）** 相同信息预算下，H 步最优计划的期望决策风险 ≤ 贪心短视策略（短视是长视以「后续不收集信息」为约束的前缀，DP 最优值 ≤ 任一可行值）。系：前瞻只会让「问」更少更准。

**引理 21（隔离非污染与幻影模态上界）** 控制态只经 `Promote` 写入且需 k 源一致 + 几何裕度，单条未验证证据/幻影模态改变执行动作的概率 ≤ `δ_p·ρ^{k−1}+ε_σ`，并被 `m_∩≥m_commit` 进一步压低；切断了 R69 中「模态权重 → VoI → 控制」的直连路径。

**引理 22（共同管空 ⇒ 交互必要性）** 若 `T_∩=∅`，任意动作在某个支撑模态下不安全；在支撑覆盖真值下，要安全必须缩小支撑集（观测/交互）或停车。反之 `T_∩` 有裕度时高熵也不强制交互——「是否必须问」由几何而非软权重决定。

**定理 18（ISOLATE 严格包含 R69）** H=1,K=1 时 MSTO=单步期望成本最小、LAP=MINT、CST 空 ⇔ R69 保守退避，逐指令相同；一般情形由引理 19–20，期望风险 ≤ R69 且安全不依赖消歧正确性。R69 = 单分支短视边界。

**定理 19（隔离-优化闭环安全与无突变）** 引理 19 保证提交前全支撑安全；CMP 的 bumpless transfer 保持状态连续与不变量（R68 定理 15）；QZ 使故障调查零污染；退避链使 λ 单调不降 ⇒ 控制连续、无突变，安全与「是否猜对」解耦。

**定理 20（交互触发的必要-充分性）** 由引理 22，CST 空是安全强制交互的必要条件；由引理 19，CST 非空时执行共同管即安全，交互对安全非必要。组合策略在安全维度不冗余不遗漏；VoI 只在已触发节点上做次级「选哪个」。该性质依赖 `Safe_k` 与分支动力学的正确性（见第 7 节风险）。

## 7. 本轮最大风险

**一句话**：状态隔离能保证「分支之间不互相污染」，却保证不了「每个分支的 `Safe_k` 与动力学模型本身是对的」——一旦安全集或模型被误设，共同安全管就是一张盖了数学印章的空头支票，系统会以极大的自信，在一个错误的模型里保持「认证过的安全」；而且因为不再被迫提问，这种错误比 R69 的幻影模态**更难被观测到**。

**次级风险与缓解**：隔离瘫痪（CMP deadline + 最大隔离时长 + 超时退 R68/停车）；空证书导致过度保守/频繁停车（仅 `m_∩<δ_cst` 时升 H/K，用 R69 交互争回裕度）；DDP 利用模型误差（鲁棒管/机会约束 + 残差敏感度审计，E310、VQAuditor-T）；语义隔离缺失（BIM 分源证据隔离 + E311 分支失同步攻击）；CST 伪造/越界写（C-RAS-WM 二次认证 + 单向屏障 + E312/E313）。
