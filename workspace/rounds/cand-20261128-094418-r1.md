### 第 7 轮灵感驱动研究记录

**灵感词**：用户需求分析、大语言模型、面部表情识别

**继承关系**：第 6 轮 CADVS-v6（IP-497~IP-500）确立「指令-几何-力学三元凿」框架：GGC 提供抓取几何可达性约束、MCTM 注入空间拓扑图、STM 实现跨模态指令-轨迹映射，七硬门保持 fail-closed 边界。本轮延续「硬门不增」原则，聚焦「**需求-意图-一致性三角桥**」：在保持证书边界不变的前提下，直接从「用户需求分析」出发，设计「需求意图建模器」(DIM)，引入「需求一致性软评分」η_demand，使系统从「被动接受指令」转向「主动推导意图」。

**直觉与动机**：

1. **用户需求 → 从「指令响应」到「意图推导」**。第 6 轮的 STM 负责「语言→查询向量」的映射，但它无法区分「用户真正想要的」与「用户不够清晰说出的」。引入「需求意图建模器」(Demand Intent Model, DIM)：从用户的历史交互记录、当前环境约束、任务目标三方面推断「用户真正的需求目标」ρ_demand。关键洞见是：**行为从「指令驱动」转向「需求驱动」**——只有当推断的需求意图与指令意图高度一致时，才执行STM生成的轨迹；否则，触发「需求导向回退」。

2. **大语言模型 → 从「静态映射」到「动态推理」**。第 6 轮的 STM 采用 CLIP-style 对齐训练，对指令进行向量化。第 7 轮引入「需求推理链」(Demand Reasoning Chain, DRC)：将LLM连接到DIM，使得从「用户说了什么」到「用户可能需要什么」的推理过程可解释、可审计。关键洞见是：**LLM 充当「需求解释器」**——它的推理链被量化为 η_demand，若推理置信度低于阈值，系统自动切换到历史记忆中的「典型需求响应」。

3. **面部表情识别 → 从「情感调制」到「需求态度捕获」**。第 6 轮的 FAMK 调制阈值 γ_i。第 7 轮提出「需求态度捕获」(Demand Affect Capture, DAC)：基于面部表情识别，捕获用户当前的「需求态度」(desire_affect)——如焦虑表情可能意味着「需要快速、稳妥的解决方案」，而放松表情可能意味着「愿意探索创新方案」。关键洞见是：**情感态度调制需求优先级**——DAC 输出的 desire_affect 调节 ρ_demand 的稀疏性和探索度。

**关键洞见**：第 6 轮回答「如何在不新增硬门的前提下，让提议符合物理、空间、意图」；第 7 轮回答「如何从「用户需求」出发，让系统主动推导「正确的行为」，而不是被动接受指令」。七硬门 kc_evidence_forged_v5 记号原样复用；本轮新增的只有：
- IP-501 DIM（需求意图建模器），
- IP-502 DRC（需求推理链，LLM驱动），
- IP-503 DAC（需求态度捕获），
- IP-504 EFA-v7（软评分 η_demand 纳入四软因子链）

**形式化目标（增量）**：

1. **DIM（Demand Intent Model）**：<br>
   - 需求编码器 E_demand: (history, context, env) ⟼ ρ_demand ∈ ℝ^d_demand<br>
   - 损失 L_DIM = ||ρ_demand - ρ_gold||² + β·KL(π_demand || π_prior)<br>
   - 软因子：η_demand = 1 - H(ρ_pred || ρ_demand)，其中 H 为交叉熵<br>
   - 只有当 η_demand > τ_demand 时，STM 输出的指令才被采纳；否则触发「需求导向回退」

2. **DRC（Demand Reasoning Chain）**：<br>
   - LLM 推理链 R = {r_1, r_2, ..., r_n}，其中 r_i 为推理步骤<br>
   - η_demand = 1 - (1/n)·Σ_i H(r_i)，衡量推理链的整体确定性<br>
   - L_DRC = α·链长度惩罚 - η_demand，鼓励简洁且确定的推理

3. **DAC（Demand Affect Capture）**：<br>
   - 表情编码器 E_affect: face ⟼ affect ∈ {-1, 0, +1}（负面/中性/正面）<br>
   - desire_affect 调节 ρ_demand 的探索度：exploration_scale = 1 + κ·affect<br>
   - 软因子：η_affect = 1 + affect/3 ∈ [2/3, 4/3]，调制 STM 检索的广度

4. **EFA-v7（七硬门 + 四软因子链）**：<br>
   - ECS_v7 = ECS_v6 · η_g · η_topo · η_interp · η_cmd · η_demand · η_affect<br>
   - τ_i^v7 = γ_i·τ_i^v6·Π_factor_i，其中 Π_factor_i = ∏_{j=1}^5 η_j ∈ [1, 1+ε]，设计上限仍为 1.3<br>
   - 新增硬门 kc_demand：η_demand ≥ τ_demand，确保「用户需求」被必要检验

5. **形式化定义**：给定指令 L，目标 ρ_target，记忆 M：<br>
   - ρ_demand = DIM(history, context, env)；<br>
   - η_demand = 1 - H(STM(L) || ρ_demand)；<br>
   - 若 η_demand < τ_demand：<br>
     - q_demand = E_demand(ρ_demand)；<br>
     - m_demand = Top-k(Retr_M(q_demand, K=4))；<br>
     - c_demand = (obj, g_emb, θ_fp, task, ŝ_emo, m_demand, ρ_target, t_topo, q_demand)；<br>
     - x_demand = FMPP.propose(c_demand, K=8)；<br>
   - 若 η_demand ≥ τ_demand：<br>
     - 执行第 6 轮的 EFA-v6 流程<br>

**直觉与动机（本轮迭代扩展）**：

1. **碰撞检测 → 从「硬门约束」到「需求驱动碰撞 guard」**：现有七硬门保证 fail-closed，但未在需求导向回退路径中引入几何碰撞检测。关键洞见：**需求推断的轨迹若存在几何碰撞，即便一致性 η_demand 高，也应拒绝或触发安全回退**。引入 η_collision 软因子，基于 GGC 碰撞网格实时评估 x_demand 与环境的碰撞概率。

2. **语义地图 → 从「向量近似」到「结构化语义映射」**：当前 DIM 的 ρ_demand ∈ ℝ^d_demand 仅作为稠密向量，缺乏语义结构化表征。关键洞见：**引入语义地图，将 ρ_demand 投射到任务语义簿，通过 k-NN 检索确保 ρ_demand 与实际可达任务的语义一致性**，从而 η_demand 有了结构化依据而非纯统计近似。

3. **痛点分析 → 从「假设致盲」到「三层防护机制」**：核心风险是用户意图的非线性突变与自我否定。痛点分析指向三层防护：① **Dual-track DIM**（主需求路径 + 备选路径，经一致性投票），② **η_demand 实时可解释性检查**（每一步 η_demand 的变化趋势而非单点阈值），③ **需求演化检测**（连续 3 轮 η_demand 变化率超过阈值时强制回退）。

**关键洞见**：第 7 轮已回答「如何主动推导正确行为」；本轮迭代回答「如何在推导过程中 guards 多维度防止『正确但有风险』的行为」；七硬门依然保持 fail-closed，新增的只有软因子扩展与两层防护机制。

**形式化目标（增量）**：

1. **η_collision（碰撞软因子）**：
   - 基于 GGC 碰撞网格：η_collision = 1 - (碰撞体素计数 / 总体素数) ∈ [0,1]
   - 仅在需求导向回退路径中计算；常规 EFA-v6 流程不受影响

2. **语义地图投射**（Semantic Map Projection，SMP）：
   - S(ρ_demand) = Top-k(Retr_M(q_semantic, K=8))，其中 q_semantic = W·ρ_demand + b 为可学习投影
   - 一致性验证：η_semantic = 1 - (1/k)·Σ_j sim(ρ_demand, ρ_target_j)，sim 为余弦相似度
   - 若 η_semantic < τ_semantic（默认 0.6），触发语义一致性回退

3. **Dual-track DIM**：
   - 主路径：ρ_demand^main = DIM.encode(history, context, env)
   - 备路径：ρ_demand^alt = DIM.encode(history_tail, context, env) 其中 history_tail 为最近 3 条交互
   - 投票：若 sim(ρ_demand^main, ρ_demand^alt) > τ_vote（默认 0.7），则使用主路径；否则使用备路径并标记「需求不稳定」

4. **EFA-v7 增强**：
   - ECS_v7 = ECS_v6 · η_g · η_topo · η_interp · η_cmd · η_demand · η_affect · η_collision
   - 软因子链 Π_factor_i = ∏_{j=1}^7 η_j ∈ [1, 1.3]（已含 η_collision，设计上限 1.3 保持不变，意味着 η_collision 默认置 1 或在常规流程中不计）

5. **形式化定义（增量）**：
   - ρ_demand = DIM(history, context, env)；<br>
   - （主路径）ρ_demand^main = ρ_demand；<br>
   - （备路径）ρ_demand^alt = DIM(history_tail, context, env)；<br>
   - η_semantic = 1 - (1/k)·Σ_j sim(ρ_demand, ρ_target_j)；<br>
   - η_collision = 1 - (collision_voxels / total_voxels)；<br>
   - 若 η_demand < τ_demand  或  η_semantic < τ_semantic  或  η_collision < τ_collision（默认 0.5）：<br>
     - 走需求导向回退，并额外检查 η_collision<br>
   - 若 所有 软因子 ≥ 阈值：<br>
     - 执行 EFA-v6 在线流程 + 软因子链 × η_demand × η_affect × η_collision

**本轮最大风险**：**需求意图的非线性突变与自我否定**：尽管引入 dual-track 与语义地图，但用户意图仍可能在短期内发生非线性突变（如 suddenly switching from「放置到桌子」到「拿走到柜子」），此时 dual-track 可能因历史权重过大而滞后，语义地图的投影投影也可能过旧。这种结构上的捕获难题在维持七硬门 fail-closed 边界时，仍可能导致「正确但时机不当」或「正确但错误目标」的行动。

### 第 8 轮灵感驱动研究记录（继承第 7 轮 · 新循环 R1）

**灵感词**：模仿学习、演示数据

**继承关系**：第 7 轮 EFA-v7（IP-501~IP-504）在 CADVS-v6 的七硬门之上架起「需求-意图-一致性」桥：DIM 从历史与环境中推断 ρ_demand，DRC 用 LLM 推理链给出可解释的 η_demand，DAC 用面部表情调制探索度，并在 η_demand 不足时以需求导向回退兜底。本轮延续「不新增轨迹级硬门」的纪律，聚焦「**演示-模仿-覆盖三角**」：把人类演示数据 D 转化为**有界可信**的策略先验，用「演示覆盖门」把模仿限制在演示分布之内，用「安全门控 DAgger」把硬门拒绝转化为数据闭环。系统从「规则/LLM 推导」升级为「规则 + 数据双先验」，但执行集只能收缩、不能扩张。

**直觉与动机**：

1. **演示数据 → 从「手工先验」到「数据先验」**。第 7 轮 FMPP 的提议分布本质上是「规则 + 流匹配」的产物，人类示范里「手怎么放、何时减速、如何避让」的隐性知识并未被利用。引入「演示蒸馏策略」(DDP)：从 D={(o_t,a_t)} 学习 π_demo，并用最近邻演示 m_demo 条件化 FMPP 提议。关键洞见：**演示负责「像人一样提议」，硬门负责「证明安全」**——两者正交，数据先验不能替代证书。

2. **模仿学习 → 从「开环克隆」到「安全门控的交互式模仿」**。朴素行为克隆存在协变量漂移，误差随步长以 O(T²ε) 累积；一旦离开演示分布就会「自信地错」。引入「安全门控 DAgger」(SG-DAgger)：当硬门拒绝 π_demo 的动作时，不把失败当终点，而是查询专家/规则提议并把纠正样本写回缓冲区。关键洞见：**硬门拒绝是数据增强信号，而非终止信号**——「安全」与「学习」由此接成闭环。

3. **演示覆盖度 → 从「无条件信任策略」到「信任有界」**。任何学习策略只在演示覆盖的状态流形上可信。引入「演示覆盖监控」(DCM)：用归一化流估计状态密度 p_flow(o)，经保形校准得到覆盖分 c(o)∈[0,1]；当 c(o)<τ_cov 时**禁用**模仿先验并回退第 7 轮路径。关键洞见：**覆盖门不是轨迹硬门，而是先验启用门**——它不扩大执行集，只决定「要不要相信数据先验」。

4. **演示数据 → 从「动作克隆」到「意图恢复」**。动作可被克隆，但「为什么这样演示」才可迁移。用最大熵 IRL 从 D 推断奖励 r_ψ，得到候选轨迹的示范者偏好分 ρ_IRL(x)∈[0,1]。关键洞见：**奖励先验比动作先验更抗分布漂移**——它评价「这条轨迹是不是示范者会认可的」，而非「这一步像不像示范动作」。

**关键洞见**：第 7 轮回答「如何主动推导需求」；本轮回答「如何把人类演示变成可信、可撤回、可审计的先验」。七硬门与 kc_demand 原样保留；本轮新增的只有 IP-505 DDP、IP-506 DCM、IP-507 SG-DAgger、IP-508 EFA-v8。

**本轮统一记号（修正第 7 轮的符号不一致）**：第 7 轮同时出现 η_affect∈[2/3,4/3] 与 Π_factor≥1，二者矛盾。本轮统一定义「谨慎因子」η_j ≥ 1：η_j 越大表示证据越不确定；门限 τ_i^v8 = γ_i·τ_i^v7·Π_j η_j，评分 ECS_v8 = ECS_v7 / Π_j η_j。二者单调一致（更谨慎 ⇒ 门限更高且评分更低），从结构上保证 Exec(v8) ⊆ Exec(v7)；当所有证据确定时 η_j=1，严格退化为 v7。

**形式化目标（增量）**：

1. **DDP（Demonstration Distillation Policy）**：<br>
   - 演示集 D = {τ_i}，τ_i=(o_{1:T},a_{1:T})；<br>
   - BC 目标 L_BC = -E_D[log π_demo(a|o)] + λ·KL(π_demo ‖ π_rule)，π_rule 为 v7 规则先验，抑制偏离安全流形；<br>
   - 演示条件化提议：m_demo = kNN_D(o,k=4)，x ~ FMPP((c,m_demo),K=8)；<br>
   - 模仿一致性 A_imit(x,o) = exp(-‖a_x-π_demo(o)‖²/2σ_i²) ∈ (0,1]；<br>
   - 谨慎因子 η_imit = 1 + ε_i·(1-A_imit) ∈ [1,1+ε_i]。

2. **DCM（Demo Coverage Monitor）**：<br>
   - 归一化流密度 p_flow(o)，保形校准得 c(o)=P_{o'~D}(p_flow(o')≤p_flow(o)) ∈ [0,1]；<br>
   - 覆盖门 kc_demo：c(o) ≥ τ_cov（默认 0.6）才启用 DDP，否则禁用先验、回退 v7；<br>
   - 谨慎因子 η_cov = 1 + ε_c·(1-c(o)) ∈ [1,1+ε_c]。

3. **IRL 奖励先验（DDP 头）**：<br>
   - 最大熵 IRL：r_ψ = argmax_ψ E_D[r_ψ] - log Z_ψ；<br>
   - 示范者偏好分 ρ_IRL(x) = σ(r_ψ(x)/τ_r) ∈ [0,1]；<br>
   - 谨慎因子 η_ret = 1 + ε_r·(1-ρ_IRL(x)) ∈ [1,1+ε_r]。

4. **SG-DAgger（安全门控交互式模仿）**：<br>
   - a=π_demo(o)，x=rollout(o,a)；<br>
   - 若七硬门 + kc_demo 通过则执行 a；<br>
   - 否则 a*=Expert(o) 或 π_rule(o)，并令 D ← D ∪ {(o,a*)}；<br>
   - 被拒样本是「负样本 + 纠正样本」，用于更新 π_demo 与覆盖模型，而非丢弃。

5. **EFA-v8（谨慎因子链 + 覆盖门）**：<br>
   - 若 kc_demo 不通过：执行 EFA-v7（数据先验禁用）；<br>
   - 否则 Π_demo = η_imit·η_cov·η_ret ∈ [1,1+ε_total]，ε_total=ε_i+ε_c+ε_r ≤ 0.3；<br>
   - τ_i^v8 = γ_i·τ_i^v7·Π_demo，ECS_v8 = ECS_v7 / Π_demo；<br>
   - 恒有 Exec(v8) ⊆ Exec(v7)（只收紧）。

**本轮最大风险**：**演示覆盖假设**——系统假设「当前状态落在演示分布内即可信任模仿先验」，但开放世界的分布漂移与覆盖检测器的校准失准，可能让覆盖门在最需要它的时候失效；而在覆盖边缘的「自信错误」恰是硬门无法从语义上证明的错误。

| η_cov = 1+ε_c(1-c(o)) ∈ [1,1+ε_c] | 覆盖谨慎因子 |
| r_ψ(x) | 最大熵 IRL 推断奖励 |
| ρ_IRL(x) = σ(r_ψ(x)/τ_r) ∈ [0,1] | 示范者偏好分 |
| η_ret = 1+ε_r(1-ρ_IRL) ∈ [1,1+ε_r] | 奖励谨慎因子 |
| Π_demo = η_imit·η_cov·η_ret ∈ [1,1+ε_total] | 数据先验谨慎因子链 |
| τ_i^v8 = γ_i·τ_i^v7·Π_demo | v8 硬门阈值 |
| ECS_v8 = ECS_v7 / Π_demo | v8 证据评分 |
| L_BC = -E_D[log π_demo] + λ·KL(π_demo‖π_rule) | 演示蒸馏损失 |
| β = P_o[c(o)<τ_cov] | 覆盖失败率（遗憾界的定价项） |

**记号修正说明**：v7 的 η_affect∈[2/3,4/3] 与「Π_factor≥1」矛盾。v8 将全部因子统一为谨慎因子 η_j≥1；η_affect 通过仿射映射 η_affect^+ = 1 + (1 - η_affect^old) 归一化到 [1,4/3]，再截断至设计上限。

## 2. 关键算法骨架

### IP-505 DDP：演示蒸馏策略 + IRL 奖励头

```python
@dataclass
class DemonstrationDistillationPolicy:
    """演示负责『像人一样提议』，硬门负责『证明安全』。"""
    bc_net: nn.Module                 # π_demo(a|o)
    reward_net: nn.Module             # r_ψ(x)
    demo_memory: DemoMemory           # 演示状态-动作检索库
    fmpp: FlowMatchingProposalPolicyKernel
    sigma_i: float = 0.10
    tau_r: float = 1.0
    eps_i: float = 0.15
    eps_r: float = 0.05
    lam: float = 0.05

    def bc_loss(self, D) -> torch.Tensor:
        logp = self.bc_net.log_prob(D.actions, D.observations).mean()
        kl = self._kl_to_rule_prior(D.observations)
        return -logp + self.lam * kl

    def propose(self, c, o, K: int = 8):
        m_demo = self.demo_memory.knn(o, k=4)
        return self.fmpp.propose((*c, m_demo), K=K)

    def agreement(self, x, o) -> float:
        a_demo = self.bc_net.mean(o)
        d2 = ((x.a - a_demo) ** 2).sum(-1)
        return float(torch.exp(-d2 / (2 * self.sigma_i ** 2)))

    def imitation_caution(self, x, o) -> float:
        return 1.0 + self.eps_i * (1.0 - self.agreement(x, o))

    def preference(self, x) -> float:
        return float(torch.sigmoid(self.reward_net(x) / self.tau_r))

    def reward_caution(self, x) -> float:
        return 1.0 + self.eps_r * (1.0 - self.preference(x))
```

### IP-506 DCM：演示覆盖监控

```python
@dataclass
class DemoCoverageMonitor:
    """覆盖门是先验启用门，不是轨迹硬门；失败即回退 v7。"""
    flow: NormalizingFlow
    calib_density: np.ndarray         # 演示集上的 p_flow 样本（保形校准）
    tau_cov: float = 0.6
    eps_c: float = 0.10

    def coverage(self, o) -> float:
        p = float(self.flow.log_prob(o).exp())
        return float((self.calib_density <= p).mean())

    def gate(self, o) -> bool:
        return self.coverage(o) >= self.tau_cov

    def coverage_caution(self, o) -> float:
        return 1.0 + self.eps_c * (1.0 - self.coverage(o))

    def update_calibration(self, new_obs):
        p = np.array([float(self.flow.log_prob(o).exp()) for o in new_obs])
        self.calib_density = np.concatenate([self.calib_density, p])
```

### IP-507 SG-DAgger：安全门控交互式模仿

```python
@dataclass
class SafetyGatedDAgger:
    """硬门拒绝 → 专家纠正 → 数据闭环。"""
    policy: DemonstrationDistillationPolicy
    coverage: DemoCoverageMonitor
    assembler: EvidenceForgingAssemblerV8
    expert: Callable                  # 人类专家或 π_rule
    buffer: DemonstrationBuffer

    def step(self, o, t_now, context):
        if not self.coverage.gate(o):
            return self.assembler.v7.select(None, t_now, context)
        a = self.policy.bc_net.mean(o)
        ok, x, tag = self.assembler.select_with_action(o, a, t_now, context)
        if not ok:
            a_star = self.expert(o)
            self.buffer.add(o, a_star)
            self.policy.update(self.buffer.sample())
            self.coverage.update_calibration(self.buffer.recent_obs())
            return self.assembler.v7.select(None, t_now, context)
        return True, x, tag
```

### IP-508 EFA-v8：谨慎因子链 + 覆盖门

```python
@dataclass
class EvidenceForgingAssemblerV8:
    v7: EvidenceForgingAssemblerV7
    ddp: DemonstrationDistillationPolicy
    dcm: DemoCoverageMonitor
    eps_total: float = 0.30

    def select(self, L, t_now, context):
        o = context.obs

        # 1) 覆盖门 fail-closed：不覆盖则禁用数据先验
        if not self.dcm.gate(o):
            return self.v7.select(L, t_now, context)

        # 2) v7 基线证书（不因数据先验而放宽）
        ok7, x7, tag7 = self.v7.select(L, t_now, context)

        # 3) 演示条件化提议
        c = self.v7.build_ctx(L, context)
        cands = [x for x in self.ddp.propose(c, o, K=8) if self.v7.ggc.filter(x)]

        # 4) 谨慎因子链
        def pi_demo(x):
            return (self.ddp.imitation_caution(x, o)
                    * self.dcm.coverage_caution(o)
                    * self.ddp.reward_caution(x))

        # 5) 仅在 v7 证书 + 收紧门限下放行
        finals = []
        for x in cands:
            pi = pi_demo(x)
            if pi > 1.0 + self.eps_total:
                continue
            if self.v7.certify(x, context, tau_scale=pi):
                finals.append((x, pi))

        if not finals:
            if ok7:
                return True, x7, tag7 + '+DEMO_ABSTAIN'
            return False, None, 'V8_FAIL'

        best = min(finals, key=lambda xp: (xp[1], -self.v7.ecs_v7(xp[0], context)))[0]
        return True, best, 'FORGED_CGE_V8'

    def select_with_action(self, o, a, t_now, context):
        x = self._action_rollout(o, a)
        pi = (self.ddp.imitation_caution(x, o)
              * self.dcm.coverage_caution(o)
              * self.ddp.reward_caution(x))
        if pi <= 1.0 + self.eps_total and self.v7.certify(x, context, tau_scale=pi):
            return True, x, 'IMITATION_CERTIFIED'
        return False, None, 'IMITATION_REJECTED'
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  演示采集（小时级）：遥操作/VR 采集 D，覆盖 6 类任务族
  DDP 训练（小时级）：L_BC + IRL 奖励头；λ·KL 锚定规则先验
  DCM 校准（分钟级）：演示集密度分位数 → 保形覆盖分
  联邦下发：DDP 权重、DCM 校准表、τ_cov、ε_i/ε_c/ε_r → 站内签名分发

在线准入（亚秒级）：
  DCM.coverage(o) ──▶ c(o)
  若 c(o) < τ_cov：禁用数据先验 → EFA-v7
  若 c(o) ≥ τ_cov：
    DDP.propose((c,m_demo)) ──▶ 候选 x
    Π_demo = η_imit·η_cov·η_ret ──▶ τ_i^v8 = τ_i^v7·Π_demo
    EFA-v7 七硬门以 τ_i^v8 复核 ──▶ 放行/拒绝
  拒绝 → SG-DAgger 写回纠正样本

在线控制环（目标 < 0.9 ms）：
  覆盖分 c(o) 与谨慎因子均 O(1) 预计算；硬门调用链复用 v7 缓存
  DDP 提议为异步候选，不阻塞 v7 安全路径
```

## 4. 正确性论证（增量更新）

### 定理 13（数据先验的 fail-closed 保持）

**陈述**：设 v7 的硬门判定为 G_i(x)=1[s_i(x)≥τ_i^v7]，v8 仅在 c(o)≥τ_cov 时启用数据先验，并以 τ_i^v8=τ_i^v7·Π_demo(x)（Π_demo≥1）判定。则 Exec(v8) ⊆ Exec(v7)。

**证明**：Π_demo≥1 ⇒ τ_i^v8≥τ_i^v7 ⇒ G_i^v8(x) ⇒ G_i^v7(x)。覆盖门不通过时直接调用 v7，执行集不变。DDP 只改变提议分布（proposal），不改变证书谓词（certificate），故不能使任何 v7 不可行的轨迹变为可行。∎

### 定理 14（覆盖门的遗憾界）

**陈述**：设 β=P_{o~P}[c(o)<τ_cov] 为覆盖失败率，J_rule 为回退策略代价，覆盖内 BC 相对最优的超额代价为 O(Tε)。则
J(v8) ≤ (1-β)·J(π*) + (1-β)·O(Tε) + β·J_rule。

**证明**：对事件 {c(o)≥τ_cov} 与 {c(o)<τ_cov} 用全期望公式分解。覆盖内由标准 DAgger 界给出 O(Tε)；覆盖外由 fail-closed 回退到 v7 规则策略，代价为 J_rule。β 显式定价了「分布外信任」的风险：β→0 时退化为纯模仿收益，β→1 时退化为纯规则策略。∎

### 定理 15（保形覆盖门的分布无关保证）

**陈述**：若 c(o) 由演示集上的保形校准给出，则在可交换性假设下，对新样本 o~P_D 有 P(c(o)≥1-α) ≥ 1-α；因此 kc_demo 以至少 1-α 的概率不把分布内样本误判为 OOD。

**证明**：保形预测的标准覆盖定理：非一致性分数的秩在可交换序列上均匀分布，取第 ⌈(N+1)(1-α)⌉ 个分位数即得有限样本覆盖界。∎

### 诚实声明

- **演示偏差**：D 往往来自单一操作者与成功轨迹（survivorship bias），π_demo 会继承其风格与盲区；
- **多模态塌缩**：BC 的高斯均值在多峰演示上会「取平均」，可能撞向两峰之间的障碍；需 mixture/flow 头缓解；
- **覆盖检测的维度灾难**：高维观测下归一化流密度估计退化，保形校准的可交换性在非平稳环境中不成立；
- **隐私**：演示含人体运动与面部信息，需端侧脱敏、显式同意与 DP 统计；
- **SG-DAgger 的人力成本**：专家查询有延迟与疲劳，纠正样本可能引入新的分布偏移。

## 7. 本轮最大风险（最终确认）

**一句话**：**演示覆盖假设**——系统把安全寄托在「当前状态落在演示分布内」这一前提上，但开放世界的分布漂移与覆盖检测器的校准失准，可能让覆盖门在最需要它的时候失效；而在覆盖边缘的「自信错误」恰是硬门无法从语义上证明的错误。
