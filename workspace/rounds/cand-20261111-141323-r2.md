# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「自主导航」×「记忆检索」）

> 第 54 轮已把技能组合落到动作空间剖面 α 与云边联合证书 J 上。本轮把视角从「技能如何组合」推进到「智能体凭什么在长时程中记得住、找得回、信得过」：**导航是记忆条件的序贯决策，检索是受约束的可判定查询，记忆本身是需要认证、会过期、会被污染的资产**。核心矛盾：H22：导航要求长时程空间-时间一致性，而检索是关联式近似召回，二者在感知混叠与分布漂移下天然冲突；H23：检索增强的策略在旧记忆上看似有先验，实则可能用过期地图覆盖新观测，形成「记忆幻觉」。

## 0. 直觉与动机

**灵感 1（导航即记忆条件决策：把检索放进控制回路）**
直觉：自主导航不是「当前观测 → 动作」的反射，而是「信念 `b_t` → 查询 `q_t` → 检索记忆 `M_t` → 条件规划 → 动作」的闭环。记忆不是离线预处理的资料库，而是 POMDP 中与信念并列的外部状态。任何把检索当作一次性前置步骤的做法，都会在长走廊、回环、动态障碍等需要「回访」的场景中失效。因此我们主张：**检索算子 `R` 必须是策略 `π` 的内层算子**，其输出直接影响子目标、代价先验与探索方向。

**灵感 2（检索即受约束查询：从 top-k 相似到可判定选择）**
直觉：向量检索只回答「像不像」，导航却要回答「现在能不能用」。一条语义极相似但空间上不可达、时间上已过期、或动作上与边端能力不兼容的记忆，是有害先验。于是把检索写成带硬约束、软排序的优化：在**有效、可达、动作兼容、风险可接受**的可行域内最大化相关性与信息量；可行域为空时**显式弃权（abstain）**并退回探索。这把检索从「召回率问题」升级为「可判定性与弃权问题」。

**灵感 3（记忆条目 = 带证书的资产）**
直觉：一条记忆不应只是向量 `k → c`，而应是 `m = (k, c, τ, Ω, prov, ρ_m, α_m, u)`：有有效期 `τ`、空间作用域 `Ω`、来源溯源 `prov`、鲁棒性谱 `ρ_m`、动作剖面 `α_m` 与可信度 `u`。每次检索返回一张**检索证书**，记录用了哪些记忆、为何可用、残余风险多大。这样记忆可审计、可隔离、可遗忘，并直接复用第 53/54 轮的 `ρ` 与 `α`。

**灵感 4（主动检索：用导航动作消歧，让「去看一眼」成为动作）**
直觉：当多条记忆高相似却互相冲突（感知混叠，alias set），被动检索无法消歧，但导航本身能产生信息：转向、靠近、回访地标都是**信息获取动作**。选动作时同时评估预期信息增益 `IG(a)` 与运动代价，就得到「主动记忆检索」。这第一次把「自主导航」与「记忆检索」在动作层真正耦合：**检索动作 = 导航动作**，代价核算则要求「主动检索代价 < 错误记忆导致的重规划代价」。

**灵感 5（记忆代谢闭环：检索→执行→验证→写回/遗忘）**
直觉：一次导航产生轨迹与 Explain 根因，写回时携带来源与反事实标签；被反复证实的记忆提升可信度，被反例反驳的记忆降权、隔离甚至遗忘。形成**检索—执行—验证—写回—遗忘**的代谢闭环。没有遗忘的检索系统会越用越自信、越自信越陈旧，最终把回声当成事实。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（认证记忆条目）**
记忆条目 `m = (k, c, τ, Ω, prov, ρ_m, α_m, u)`：
- `k` 为多模态键（视觉/语义嵌入 + 拓扑单元 + 任务签名）；
- `c` 为内容（子目标、局部地图块、轨迹片段、失败谓词）；
- `τ = [t_0, t_1]` 为时间有效期，`Ω ⊆ ℝ³` 为空间作用域；
- `prov` 为来源溯源（episode id、传感器、第 54 轮证书编号）；
- `ρ_m : 𝔇_ρ → [0,1]` 为记忆的鲁棒性谱，`α_m : A → [0,1]` 为动作剖面；
- `u ∈ [0,1]` 为可信度。记忆库 `𝔐 = {m_i}`。

**定义 122（导航查询与可采纳检索）**
查询 `q_t = (b_t, g, ctx, A_e, B_t)`，其中 `b_t` 为信念、`g` 为目标、`ctx` 为任务上下文、`A_e` 为边端可用动作、`B_t` 为检索预算。
检索评分 `s(m|q) = sim(k_m, q) − λ_1·age(m,t) − λ_2·dist(Ω_m, Reach_t(g)) − λ_3·(1−u_m)`。
**可采纳集**：
```
M_t = { m ∈ 𝔐 : u_m ≥ u_0 ∧ t ∈ τ_m ∧ Ω_m ∩ Reach_t(g) ≠ ∅
                 ∧ α_m ∩ A_e ≠ ∅ ∧ ρ_m(d) ≥ ρ_min ∀d }
```
若 `M_t = ∅`，检索输出 **abstain**，导航转入探索或主动检索。检索结果按 `s` 取前 `k` 条，且附弃权标记。

**定义 123（记忆条件导航策略与检索增益）**
记忆条件策略 `π(a | b_t, M_t) ∝ exp(Q(b_t, a; M_t)/η)`。
检索增益 `Δ_ret = J(π_{M_t}) − J(π_∅)`，其中 `J` 为期望任务回报。若 `Δ_ret < τ_gain`，即使 `M_t` 非空也应弃用，避免「有检索但无收益」的虚假先验。定义弃权策略 `π_abs` 在 `M_t=∅` 或 `Δ_ret<τ_gain` 时触发。

**定义 124（检索证书）**
`R_cert = (q_t, M_t, {s_m}, valid_proof, α_compat, ρ_bound, abstain, evidence)`。
**检索可靠性**：若 `abstain=0`，则对任意 `m ∈ M_t`，`m` 在 `τ_m × Ω_m` 上以概率 `≥ 1−ε_r` 与真实环境一致，且 `α_m ∩ A_e ≠ ∅`、`ρ_m ≥ ρ_min`。`evidence` 至少包含键匹配证据与有效性检查日志。

**定义 125（导航-记忆图与主动检索）**
导航-记忆图 `G_NM = (V_S ∪ V_M, E_topo ∪ E_ret)`：`V_S` 为拓扑/空间节点，`V_M` 为记忆节点，`E_topo` 为可行运动边，`E_ret` 为「键邻近/时空关联」边。导航路径在 `E_topo` 上求解，检索等价于在 `E_ret` 上做**受约束邻域扩张**。
对键相同的状态集 `Alias(k) = {s : key(s)=k, outcome(s) ≠ outcome(s')}`，定义**混叠度** `Amb(k) = 1 − max_o P(o|k)`。
**主动检索算子** `Act(q_t) = argmax_{a∈A_e} [ IG(a|q_t) − λ_c·(c_move(a)+c_query) ]`，其中 `IG(a|q_t) = H(o|b_t) − 𝔼_{o}[H(o|b_t,a)]`；仅当净收益 `> 0` 且 `c_move ≤ B_t` 时执行。

**定义 126（记忆生命周期算子与负迁移隔离）**
写回算子 `W(ep, Explain, R_cert)`：
```
u_m ← clip(u_m + η_+·1[verify] − η_−·1[contradict], 0, 1)
```
并在 `contradict` 时写入反事实条目 `m^⊥ = (k_m, ¬c_m, prov=Explain)`。
遗忘算子 `F`：若 `u_m < u_min` 或 `contradict(m) ≥ κ`，则移出可检索集；若使用 `m` 后 `Δρ(d) < 0` 超过预算，则触发**负迁移隔离** `Q(m)`，并附 `δ_a`（第 54 轮动作对齐误差）作为联动证据。

## 2. 关键算法 伪代码

### IP-121 CMM（Certified Memory Materialization）

```python
def materialize(item, rho, alpha, now):
    m = MemoryItem(
        key=item.key, content=item.content,
        tau=item.valid_interval, omega=item.spatial_region,
        prov=item.provenance, rho=rho, alpha=alpha,
        trust=item.initial_trust)
    if not valid_interval(m.tau, now):
        m.trust = 0.0                      # 过期记忆降为零可信度
    return m
```

### IP-122 CAR（Constrained Admissible Retrieval）

```python
def admissible_retrieval(q, memory, u0, rho_min, k=8):
    cand = []
    for m in memory:
        if m.trust < u0: continue
        if not m.tau.contains(q.t): continue
        if not intersects(m.omega, reachable(q.belief, q.goal)): continue
        if not action_compatible(m.alpha, q.A_e): continue
        if min(m.rho.values()) < rho_min: continue
        s = (similarity(m.key, q.key)
             - l1 * age(m, q.t)
             - l2 * distance(m.omega, q.belief)
             - l3 * (1.0 - m.trust))
        cand.append((s, m))
    cand.sort(key=lambda z: -z[0])
    if not cand:
        return RetrievalCertificate(q, [], abstain=True)
    return RetrievalCertificate(q, [m for _, m in cand[:k]],
                                scores=[s for s, _ in cand[:k]],
                                abstain=False)
```

### IP-123 AMN（Active Memory Navigation）

```python
def active_retrieval(q, model, budget):
    best = None
    for a in q.A_e:
        ig = expected_info_gain(model, q.belief, a)
        cost = motion_cost(q.belief, a) + query_cost(q)
        if cost > budget: continue
        net = ig - lam_c * cost
        if net <= 0: continue
        if best is None or net > best[0]:
            best = (net, a)
    return best  # None 表示被动检索已足够或主动检索不划算


def memory_conditioned_plan(b, g, memory, model, budget):
    q = make_query(b, g)
    cert = admissible_retrieval(q, memory, U0, RHO_MIN)
    if cert.abstain:
        act = active_retrieval(q, model, budget)
        return explore(b, g, act)
    plan = plan_with_prior(b, g, cert)
    if retrieval_gain(plan, cert) < TAU_GAIN:
        act = active_retrieval(q, model, budget)
        return explore(b, g, act)
    return plan, cert
```

### IP-124 RMC（Retrieval-Motion Consistency）

```python
def retrieval_motion_check(plan, cert, sim, rho_min, epsilon_r):
    for m in cert.items:
        traj = sim.rollout(plan)
        if contradicts(m, traj):
            exp = explain_failure(traj, sim)
            return ('reject', 'memory_contradicted', m, exp)
        rho = robustness_spectrum(traj)
        if min(rho.values()) < rho_min:
            return ('reject', 'robustness_fail', m, explain_failure(traj, sim))
    if cert.residual_risk > epsilon_r:
        return ('reject', 'retrieval_risk', None, None)
    return ('ok', plan, cert)
```

### IP-125 MLC（Memory Lifecycle & Counterfactual Writeback）

```python
def writeback(ep, cert, explain, memory, eta_pos, eta_neg, u_min, kappa):
    for m in cert.used:
        if verified(ep, m):
            m.trust = min(1.0, m.trust + eta_pos)
        elif contradicted(ep, m):
            m.trust = max(0.0, m.trust - eta_neg)
            memory.add(counterfactual(m, explain))
            if m.trust < u_min or count_contradict(m) >= kappa:
                memory.quarantine(m)
    memory.add(extract_memory(ep, cert, explain))
    memory.forget(lambda x: x.trust < u_min or x.expired())
```

### IP-126 NMCC（Navigation-Memory Certificate）

```python
def nav_memory_certificate(plan, cert, rho, gamma_ce, delta_a, budgets):
    if cert.abstain:
        return ('reject', 'no_admissible_memory')
    if not action_compatible(cert.alpha, plan.actions):
        return ('reject', 'action_incompatible', cert.alpha)
    if min(rho.values()) < budgets.rho_min:
        return ('reject', 'robustness_fail', rho)
    if delta_a > budgets.delta_a:
        return ('reject', 'action_misalignment', delta_a)
    if cert.residual_risk > budgets.eps_r:
        return ('reject', 'retrieval_risk', cert.residual_risk)
    return ('ok', NavMemCert(cert, rho, gamma_ce, delta_a,
                             domain=compute_nav_domain(cert, plan)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CMM | O(|𝔐|·|A|) | O(|𝔐|) | 有效期与来源完整 |
| CAR | O(|𝔐|·(|k|+log|𝔐|)) | O(|𝔐|+|E_ret|) | 约束 sound、弃权完整 |
| AMN | O(|A_e|·(T_IG+T_cost)) | O(|A_e|) | IG 估计无偏、预算闭合 |
| RMC | O(|M_t|·T_roll) | O(|M_t|·T_roll) | 反例可判定、ρ 单调 |
| MLC | O(|M_t|·|𝔐|) | O(|𝔐|) | trust 有界、隔离不可逆 |
| NMCC | O(|M_t|·|𝔇_ρ|) | O(|M_t|+|𝔇_ρ|) | 联合证书 sound |

**正确性定理（Certified Memory-Conditioned Navigation Soundness）**
承接第 54 轮 (A22)–(A28)；新增假设：**(A29)** 检索评分在结构化仿真上校准，`sim` 与真实键分布偏差 `≤ ε_k`；**(A30)** 有效性区域 `τ_m × Ω_m` 的检查是 sound 的，且 `Reach_t` 保守可达；**(A31)** 主动检索的 `IG` 估计偏差 `≤ ε_ig`，且预算内完成；**(A32)** 写回验证延迟 `≤ τ_wb`，写回前 `m` 不参与检索。

则记忆条件导航的部署成功概率满足：
```
P_success ≥ 1 − (1−p_r) − P(alias_undetected) − Σ_d(1−ρ_min(d))
              − P(δ_a > Θ_a) − ε_k − ε_ig − P(verify_timeout)
```
其中 `p_r` 为可采纳检索的精度。该式的含义是：**导航失败的主要来源不是规划器，而是「检索进了不该进的记忆」与「该弃权时没有弃权」**；因此 `CAR` 的约束与 `abstain` 是 soundness 的第一道闸门，`RMC` 是第二道，`MLC` 负责阻止错误记忆在下一轮回流。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 记忆索引随环境漂移失效 | 高 | 在线重建 + 键分布漂移检测 + 保守弃权 |
| 感知混叠导致错误键匹配 | 高 | 主动检索消歧 + 多帧键 + 地标锚定 |
| trust 自增强形成回声室 | 高 | 独立留出探针 + 反事实强制写回 + 可信度上限 |
| 写回延迟污染当前回合 | 中 | 版本化记忆快照 + 写回前不可检索 |
| 过度弃权导致探索爆炸 | 中 | 弃权预算 + 分层回退（先主动检索再探索） |

## 6. 本轮最大风险

**一句话**：认证记忆与检索闭环的最大风险是 **trust 自增强的「记忆回声室」**——检索增强的导航会反复使用同一条陈旧记忆并因「任务完成」而给它加分，使证书在分布漂移下系统性失真；必须以独立留出探针、强制反事实写回与混叠感知的主动检索三重护栏，宁可在不确定时弃权探索，也不把「检索到的熟悉感」误当作「仍然正确」。

    if not m.tau.contains(now):
        m.trust = 0.0
    return m

### IP-122 CAR

```python
def admissible_retrieval(q, memory, u0, rho_min, k=8):
    cand = []
    for m in memory:
        if m.trust < u0: continue
        if not m.tau.contains(q.t): continue
        if not intersects(m.omega, reachable(q.belief, q.goal)): continue
        if not action_compatible(m.alpha, q.A_e): continue
        if min(m.rho.values()) < rho_min: continue
        s = (similarity(m.key, q.key) - l1*age(m, q.t)
             - l2*distance(m.omega, q.belief) - l3*(1-m.trust))
        cand.append((s, m))
    cand.sort(key=lambda z: -z[0])
    if not cand:
        return RetrievalCertificate(q, [], abstain=True)
    return RetrievalCertificate(q, [m for _,m in cand[:k]],
                                [s for s,_ in cand[:k]], abstain=False)
```

### IP-123 AMN

def active_retrieval(q, model, budget):
    best = None
    for a in q.A_e:
        ig = expected_info_gain(model, q.belief, a)
        cost = motion_cost(q.belief, a) + query_cost(q)
        net = ig - lam_c*cost
        if cost <= budget and net > 0 and (best is None or net > best[0]):
            best = (net, a)
    return best

def memory_conditioned_plan(b, g, memory, model, budget):
    q = make_query(b, g)
    cert = admissible_retrieval(q, memory, U0, RHO_MIN)
    if cert.abstain or retrieval_gain(plan_with_prior(b,g,cert), cert) < TAU_GAIN:
        act = active_retrieval(q, model, budget)
        return explore(b, g, act)
    return plan_with_prior(b, g, cert), cert

### IP-124 RMC

```python
def retrieval_motion_check(plan, cert, sim, rho_min, eps_r):
    for m in cert.items:
        traj = sim.rollout(plan)
        if contradicts(m, traj):
            return ('reject', 'memory_contradicted', m,
                    explain_failure(traj, sim))
        if min(robustness_spectrum(traj).values()) < rho_min:
            return ('reject', 'robustness_fail', m,
                    explain_failure(traj, sim))
    if cert.residual_risk > eps_r:
        return ('reject', 'retrieval_risk')
    return ('ok', plan, cert)
```

### IP-125 MLC

```python
def writeback(ep, cert, explain, memory, eta_pos, eta_neg, u_min, kappa):
    for m in cert.used:
        if verified(ep, m):
            m.trust = min(1.0, m.trust + eta_pos)
        elif contradicted(ep, m):
            m.trust = max(0.0, m.trust - eta_neg)
            memory.add(counterfactual(m, explain))
            if m.trust < u_min or count_contradict(m) >= kappa:
                memory.quarantine(m)
    memory.add(extract_memory(ep, cert, explain))
    memory.forget(lambda x: x.trust < u_min or x.expired())
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CMM | O(\|𝔐\|·\|A\|) | O(\|𝔐\|) | 有效期/来源完备 |
| CAR | O(\|𝔐\|·(\|k\|+log\|𝔐\|)) | O(\|𝔐\|+\|E_ret\|) | 约束 sound、弃权完整 |
| AMN | O(\|A_e\|·(T_IG+T_cost)) | O(\|A_e\|) | IG 无偏、预算闭合 |
| RMC | O(\|M_t\|·T_roll) | O(\|M_t\|·T_roll) | 反例可判定 |
| MLC | O(\|M_t\|·\|𝔐\|) | O(\|𝔐\|) | trust 有界、隔离不可逆 |
| NMCC | O(\|M_t\|·\|𝔇_ρ\|) | O(\|M_t\|+\|𝔇_ρ\|) | 联合证书 sound |

**正确性定理（Certified Memory-Conditioned Navigation Soundness）**
承接 (A22)–(A28)；新增 **(A29)** 检索评分在结构化仿真上校准，键分布偏差 `≤ ε_k`；**(A30)** 有效性区域检查 sound，`Reach_t` 保守；**(A31)** 主动检索 `IG` 估计偏差 `≤ ε_ig` 且预算内完成；**(A32)** 写回验证延迟 `≤ τ_wb`，写回前不参与检索。则：
```
P_success ≥ 1 − (1−p_r) − P(alias_undetected) − Σ_d(1−ρ_min(d))
              − P(δ_a > Θ_a) − ε_k − ε_ig − P(verify_timeout)
```
关键：**先约束后排序、可行域空则弃权、检索后必验一致性、错误记忆不回流入检索**。

## 6. 本轮最大风险

**一句话**：认证记忆与检索闭环的最大风险是 **trust 自增强的「记忆回声室」**——检索增强的导航会反复使用同一条陈旧记忆并因「任务完成」而给它加分，使证书在分布漂移下系统性失真；必须以独立留出探针、强制反事实写回与混叠感知的主动检索三重护栏，宁可在不确定时弃权探索，也不把「检索到的熟悉感」误当作「仍然正确」。
