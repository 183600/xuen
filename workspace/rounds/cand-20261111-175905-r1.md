# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「末端执行器控制」×「避障控制」）

> 第 54 轮把技能组合建立在动作空间剖面 `α_S` 与云边映射 `γ_ce` 上，形成动作-鲁棒性双证书。本轮引入 **末端执行器控制（EEC）** 与 **避障控制（OAC）** 这对天然对偶的控制目标，提出新的核心矛盾：H22：安全滤波不是透明投影——它在保安全的同时改写末端执行器指令与技能交接状态，使第 54 轮的动作兼容证书在物理执行时静默失效；H23：末端执行器跟踪（高频任务环）与避障约束（低频安全环）存在双速率错位，规划期的安全裕度在真实闭环中不被保持。

## 0. 直觉与动机

**灵感 1（末端执行器是任务空间的“笔尖”，避障是构型空间的“围墙”）**
直觉：末端执行器控制关心 SE(3) 任务空间里的位姿/力/阻抗跟踪；避障控制关心构型空间（或全身）里与障碍物的距离 `h(x) ≥ 0`。二者天然活在两个空间。第 54 轮的动作空间 `A = A_c × A_e` 只区分了云/边粒度，没有区分 **任务空间 vs 安全空间**。本轮先把动作空间升维为 **双空间 `A = A_T × A_S`**：技能的动作占用必须同时在任务空间“够得着”、在安全空间“站得住”。

**灵感 2（安全滤波是投影，投影会付“任务税”）**
直觉：避障最常用的实现是安全滤波（CBF-QP / 速度障碍 / APF）：把期望末端指令 `u_des` 投影到安全集，得到 `u_sf = Π_h(u_des)`。投影保住了安全，却产生任务偏差 `ε = u_sf - u_des`。于是“技能能执行动作 a”不再等价于“技能执行 a 后仍能完成任务”。定义 **安全滤波后的动作剖面** `α^sf_S(a)`：只有偏差 `ε` 不超过任务容差时才记 a 为可用。这把“可执行”细化为 **可执行且可保任务**。

**灵感 3（安全滤波会污染技能交接）**
直觉：组合的脆弱点不在技能内部，而在 **交接瞬间**。`S_i` 的末端状态经安全滤波偏移 `ε_i` 后交给 `S_j`，交接点可能落在 `S_j` 的动作缓冲带之外——第 54 轮的 `A_buffer` 正是为此准备，但当时没有“安全滤波漂移”这一项。于是提出 **交接漂移 `δ_H(S_i→S_j)`**，并要求 `δ_H ≤ b_j`（`b_j` 为缓冲带半径），否则组合虽“动作兼容”却“交接不安全”。这是对第 54 轮 `compat` 的第一次真实证伪。

**灵感 4（双速率：末端环快、安全环慢 → 采样间安全漏洞）**
直觉：末端执行器跟踪常跑在 1 kHz，全身避障 CBF 常跑在 100–200 Hz。安全约束只在离散时刻被强制，两个安全采样之间末端可能以 `v_max` 冲进障碍，距离缩水约 `L_h·v_max·Δt_S`。故安全裕度必须预留 **采样间余量**：`h_min > h_req + L_h·v_max·Δt_S`。这把“安全”从连续时间理想变成 **离散时间可证**，也解释了为什么仿真里安全的组合上真机会撞。

**灵感 5（用交接适配器把“被安全滤波破坏的组合”救回来）**
直觉：既然破坏点在交接，就不必重规划整条技能链，只需在交接邻域内调整 `S_i` 的终止动作，使滤波后的落点重新进入 `S_j` 的安全缓冲带：`a_i^H = argmin ||a_i - a_i^des||` s.t. `δ_H(a_i) ≤ b_j`。这是最小的 **交接安全适配（HSA）**，代价是少量任务偏差，换来组合可行。

**灵感 6（把安全包络纳入证书金字塔）**
直觉：第 54 轮的 `J = (ρ, A_cert, γ_ce, δ_a)` 只证明“动作对得上”，本轮叠加 **安全包络证书 `C_safe = (h_min, e_task, δ_lag)`**，形成 `J_safe = (ρ, A_cert, C_safe, δ_H, γ_ce, evidence)`。部署条件从“动作对齐”升级为“动作对齐 ∧ 交接无漂移 ∧ 采样间安全 ∧ 任务偏差可接受”。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（双空间动作空间）**
`A = A_T × A_S`，其中 `A_T ⊆ se(3)` 为末端执行器任务空间（速度旋量/力旋量），`A_S ⊆ C × ℝ_{≥0}` 为安全空间（构型与障碍距离）。“空间桥” `π_TS : A_T → A_S` 由逆运动学/全身控制给出，在作业域上 `L_TS`-Lipschitz。技能 S 的双空间剖面 `α_S(a_T,a_S) ∈ [0,1]`，满足 `∫_A α_S = vol(S)`。

**定义 122（安全滤波算子）**
给定障碍距离函数 `h : A_S → ℝ_{≥0}` 与安全集 `S_safe = {x | h(x) ≥ h_req}`，安全滤波
```
Π_h(u | x) = argmin_{v∈A_T} ||v - u||²_M
             s.t. h(f(x, π_TS(v))) ≥ (1-γ)h(x)  ∧  v ∈ 关节/速度限幅
```
任务税 `ε(a) = ||Π_h(a) - a||_M`。

**定义 123（安全滤波后动作剖面）**
```
α^sf_S(a) = α_S(a) · 1[ ε(a) ≤ ε_task ] · 1[ h_min(a) ≥ h_req + L_h·v_max·Δt_S ]
```
其中 `h_min(a)` 为沿动作 a 执行期间的最小障碍距离，`L_h` 为 h 的 Lipschitz 常数。安全可执行集 `A^sf_S = {a | α^sf_S(a) = 1}`。

**定义 124（交接漂移与缓冲约束）**
技能 `S_i` 在安全滤波下的终止映射记为 `Φ^sf_i`；交接漂移
```
δ_H(S_i→S_j) = dist( Φ^sf_i(x_0, a_i), A_buffer(S_j) )
```
安全交接条件 `δ_H(S_i→S_j) ≤ b_j`，`b_j` 为 `A_buffer(S_j)` 的半径（承接定义 120）。

**定义 125（双空间安全兼容）**
```
compat_safe(S_i,S_j) = |A^sf_i ∩ A^sf_j| / |A^sf_i ∪ A^sf_j|
safe_edge(i,j) ⇔ compat_safe ≥ θ_a ∧ δ_H(i→j) ≤ b_j ∧ ρ_comp ≥ ρ_min
```
注意：`safe_edge ⇒ compat`（第 54 轮），反之不成立——这正是 H22 的形式化。

**定义 126（双速率安全一致性）**
任务环步长 `Δt_T`，安全环步长 `Δt_S = n·Δt_T`。若 `h(x_k) ≥ h_min` 且 `||ẋ|| ≤ v_max`，则采样间安全保持的充分条件为
```
h_min ≥ h_req + δ_lag,   δ_lag = L_h · v_max · Δt_S
```
`δ_lag` 称为 **安全滞后证书**；当 `Δt_S → 0` 时退化为标准 CBF 不变性。

**定义 127（安全包络联合证书）**
```
J_safe = (ρ, A_cert, C_safe = (h_min, e_task, δ_lag), δ_H, γ_ce, evidence)
```
可部署当且仅当
```
dom_J(T) = in ∧ δ_H ≤ b ∧ δ_lag ≤ δ_lag^budget ∧ e_task ≤ e_max
```

## 2. 关键算法 伪代码

### IP-121 SEEC（Safety-filtered End-Effector Control profile）

```python
def safety_filtered_profile(skill, A_T, h, cfg):
    alpha_sf, envelope = {}, []
    for a in sample(A_T, cfg.samples):
        x0 = skill.state_after(a)
        u_sf = cbf_qp(skill, a, x0, h, gamma=cfg.gamma)
        eps = metric(u_sf, a)                    # 任务税
        h_min = min_distance_rollout(skill, a, h)  # 或 CBF 下界
        safe = (eps <= cfg.eps_task and
                h_min >= cfg.h_req + cfg.L_h * cfg.v_max * cfg.dt_s)
        alpha_sf[a] = 1.0 if safe else 0.0
        envelope.append((h_min, eps))
    return alpha_sf, pareto_front(envelope)      # 安全-性能 Pareto 前沿
```

### IP-122 DSA（Dual-Space Admissibility）

```python
def dual_space_admissible(skill, obstacles, cfg):
    A_sf = {a for a in skill.A_T
            if safety_filtered_profile(skill, [a], obstacles.h, cfg)[0][a] > 0}
    A_safe = {pi_TS(a) for a in A_sf if obstacles.h(pi_TS(a)) >= cfg.h_req}
    h_min = min((obstacles.h(x) for x in A_safe), default=0.0)
    return A_sf, A_safe, h_min
```

### IP-123 SFSC（Safety-Filtered Skill Composition）

```python
def build_safe_composition_graph(skills, cfg):
    G = nx.DiGraph()
    for i, s1 in skills:
        for j, s2 in skills:
            if i == j:
                continue
            c_safe = jaccard(s1.A_sf, s2.A_sf)
            dH = handoff_drift(s1, s2, filter_=cbf_qp)
            if c_safe >= cfg.theta_a and dH <= s2.buffer_radius:
                rho = compose_robustness(s1.rho, s2.rho, cfg.K)
                if rho >= cfg.rho_min:
                    G.add_edge(i, j, compat_safe=c_safe, delta_H=dH, rho=rho)
    return G
```

### IP-124 HSA（Handoff Safety Adapter）

```python
def handoff_adapter(s1, s2, a_des, cfg):
    best = None
    for a in neighborhood(a_des, cfg.radius):
        if not feasibility(s1, a):
            continue
        dH = handoff_drift(s1, s2, forced_action=a, filter_=cbf_qp)
        if dH <= s2.buffer_radius:
            cost = metric(a, a_des) + cfg.w_rho * (1 - compose_rho(s1, s2))
            if best is None or cost < best.cost:
                best = Adapter(a, dH, cost)
    return best if best else ('reject', 'no_adapter')
```

### IP-125 SEC（Safety Envelope Certificate）

```python
def safety_envelope_certificate(seq, gamma_ce, cfg):
    J54 = joint_certificate(seq, gamma_ce, cfg.delta_a_budget, cfg.rho_min)
    if J54[0] != 'ok':
        return J54
    C_safe = []
    for s_i, s_j in zip(seq, seq[1:]):
        dH = handoff_drift(s_i, s_j, filter_=cbf_qp)
        if dH > s_j.buffer_radius:
            return ('reject', 'handoff_unsafe', dH)
        C_safe.append((s_i.id, s_j.id, dH))
    h_min = min(s.h_min for s in seq)
    delta_lag = cfg.L_h * cfg.v_max * cfg.dt_s
    if h_min < cfg.h_req + delta_lag:
        return ('reject', 'intersample_unsafe', h_min, delta_lag)
    return ('ok', JointSafeCert(J54.cert, C_safe, h_min, delta_lag,
                                e_task=max(s.e_task for s in seq)))
```

### IP-126 SCL（Safety Control Lag monitor）

```python
def dual_rate_monitor(task_rate, safety_rate, v_max, h_obs, L_h):
    dt_s = 1.0 / safety_rate
    delta_lag = L_h * v_max * dt_s
    margin = h_obs - delta_lag
    if margin <= 0:
        need = L_h * v_max / max(h_obs, 1e-9)
        return ('violate', 'need_safety_rate', need)
    return ('ok', margin, delta_lag)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SEEC | O(|A_T|·(T_rollout + T_qp)) | O(|A_T|) | 滤波 sound、Pareto 非支配 |
| DSA | O(|A_T|·|C|) | O(|A|) | π_TS Lipschitz、h 连续 |
| SFSC | O(|S|²·|A|·T_qp) | O(|S|²) | safe_edge 蕴含 compat |
| HSA | O(k·|A|·T_qp) | O(k) | 邻域完备、缓冲半径一致 |
| SEC | O(|S|·|A| + |P|·T_qp) | O(|A|) | δ_H 预算闭合、δ_lag 可证 |

**引理 1（采样间安全）**
若 `h` 为 `L_h`-Lipschitz、`||ẋ|| ≤ v_max`，则任意 `t∈[t_k, t_k+Δt_S)` 有 `h(x(t)) ≥ h(x(t_k)) - L_h v_max Δt_S`。故 `h_min ≥ h_req + L_h v_max Δt_S` 时采样间不发生越界。

**引理 2（交接漂移传播）**
若终止映射对动作的敏感度 `||∂Φ/∂u|| ≤ L_H` 且任务税 `ε ≤ ε_task`，则 `δ_H ≤ L_H·ε_task`。故缓冲半径满足 `b_j ≥ L_H ε_task` 时，安全滤波不会破坏交接兼容。

**正确性定理（Safety-Filtered Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `Π_h` 对 `S_safe` 前向不变且每 `Δt_S` 施加一次；**(A30)** `||∂Φ/∂u|| ≤ L_H`；**(A31)** `π_TS` 与 `h` 分别在作业域上 `L_TS`、`L_h`-Lipschitz。
若路径上每条边满足 `safe_edge`、每个交接 `δ_H ≤ b_j`、且 `h_min ≥ h_req + L_h v_max Δt_S`，则组合执行 **确定性地无碰撞**（前向不变），任务误差上界 `e_task + L_H ε_task`，部署成功概率满足
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)
             - P(δ_H > b) - P(ε > ε_task)
```
**推论（第 54 轮证书不充分）**：存在 `compat ≥ θ_a` 但 `safe_edge = false` 的组合，故仅用 `J=(ρ,A_cert,γ_ce,δ_a)` 会给出虚假可部署判定；新增 `δ_H` 与 `δ_lag` 是必要的。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 安全滤波模型不匹配（未建模动力学） | 高 | robust/aCBF + 测量误差界 + `h_req` 保守化 |
| 缓冲半径过小导致 HSA 不可行 | 高 | 依 `L_H ε_task` 自适应定缓冲 + 分层回退 |
| 双速率导致采样间越界 | 高 | 事件触发安全 + 预测 CBF + 限速 |
| 末端执行器/工具自碰撞盲区 | 中 | 将工具与腕部纳入障碍体 + 自碰撞距离场 |
| 安全-性能 Pareto 过保守致误拒 | 中 | Pareto 前沿校准 + 任务容差自适应 |
| Explain 与安全滤波冲突 | 中 | 把安全干预 `ε` 作为 Explain 的一等证据 |

## 6. 本轮最大风险

**一句话**：安全滤波并非透明投影——它以“任务税”改写末端执行器指令、以“交接漂移”污染技能边界、以“双速率滞后”掏空规划期的安全裕度；一旦 `δ_H` 超出下一技能的缓冲带或安全环慢于末端环，第 54 轮动作兼容的组合会在物理上“名义安全、实际越界”，故必须把交接漂移 `δ_H`、采样间滞后 `δ_lag` 与任务税 `ε` 提升为联合证书的一等字段，任何缺其一的安全包络都不得判定可部署。

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮引入「末端执行器控制」×「避障控制」对偶，在动作-协同层之上新增 **安全包络层**：

```python
    for a in sample(A_T, cfg.samples):
        x0 = skill.state_after(a)
        u_sf = cbf_qp(skill, a, x0, h, gamma=cfg.gamma)
        eps = metric(u_sf, a)
        h_min = min_distance_rollout(skill, a, h)
        safe = (eps <= cfg.eps_task and
                h_min >= cfg.h_req + cfg.L_h * cfg.v_max * cfg.dt_s)
        alpha_sf[a] = 1.0 if safe else 0.0
        envelope.append((h_min, eps))
    return alpha_sf, pareto_front(envelope)
```

```python
def dual_space_admissible(skill, obstacles, cfg):
```

### IP-123 SFSC

```python
def build_safe_composition_graph(skills, cfg):
    G = nx.DiGraph()
    for i, s1 in skills:
        for j, s2 in skills:
            if i == j:
                continue
            c_safe = jaccard(s1.A_sf, s2.A_sf)
            dH = handoff_drift(s1, s2, filter_=cbf_qp)
            if c_safe >= cfg.theta_a and dH <= s2.buffer_radius:
                rho = compose_robustness(s1.rho, s2.rho, cfg.K)
                if rho >= cfg.rho_min:
                    G.add_edge(i, j, compat_safe=c_safe, delta_H=dH, rho=rho)
    return G
```

### IP-124 HSA

```python
def handoff_adapter(s1, s2, a_des, cfg):
    best = None
    for a in neighborhood(a_des, cfg.radius):
        if not feasibility(s1, a):
            continue
        dH = handoff_drift(s1, s2, forced_action=a, filter_=cbf_qp)
        if dH <= s2.buffer_radius:
            cost = metric(a, a_des) + cfg.w_rho * (1 - compose_rho(s1, s2))
            if best is None or cost < best.cost:
                best = Adapter(a, dH, cost)
    return best if best else ('reject', 'no_adapter')
```

### IP-125 SEC

```python
def safety_envelope_certificate(seq, gamma_ce, cfg):
    J54 = joint_certificate(seq, gamma_ce, cfg.delta_a_budget, cfg.rho_min)
    if J54[0] != 'ok':
        return J54
    C_safe = []
    for s_i, s_j in zip(seq, seq[1:]):
        dH = handoff_drift(s_i, s_j, filter_=cbf_qp)
        if dH > s_j.buffer_radius:
            return ('reject', 'handoff_unsafe', dH)
        C_safe.append((s_i.id, s_j.id, dH))
    h_min = min(s.h_min for s in seq)
    delta_lag = cfg.L_h * cfg.v_max * cfg.dt_s
    if h_min < cfg.h_req + delta_lag:
        return ('reject', 'intersample_unsafe', h_min, delta_lag)
    return ('ok', JointSafeCert(J54.cert, C_safe, h_min, delta_lag,
                                e_task=max(s.e_task for s in seq)))
```

### IP-126 SCL

```python
def dual_rate_monitor(task_rate, safety_rate, v_max, h_obs, L_h):
    dt_s = 1.0 / safety_rate
    delta_lag = L_h * v_max * dt_s
    margin = h_obs - delta_lag
    if margin <= 0:
        need = L_h * v_max / max(h_obs, 1e-9)
        return ('violate', 'need_safety_rate', need)
    return ('ok', margin, delta_lag)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SEEC | O(\|A_T\|·(T_rollout+T_qp)) | O(\|A_T\|) | 滤波 sound，Pareto 非支配 |
| DSA | O(\|A_T\|·\|C\|) | O(\|A\|) | π_TS Lipschitz，h 连续 |
| SFSC | O(\|S\|²·\|A\|·T_qp) | O(\|S\|²+\|E\|) | safe_edge ⇒ compat，路径最优 |
| HSA | O(k·\|A\|·T_qp) | O(k) | 邻域完备，缓冲半径一致 |
| SEC | O(\|S\|·\|A\|+\|P\|·T_qp) | O(\|A\|+\|P\|) | δ_H 预算闭合，δ_lag 可证 |
| SCL | O(1) | O(1) | 采样间不等式闭合 |

**引理 1（采样间安全）**：若 `h` 为 `L_h`-Lipschitz 且 `‖ẋ‖ ≤ v_max`，则 `h(x(t)) ≥ h(x(t_k)) - L_h v_max Δt_S`，`t∈[t_k,t_k+Δt_S]`。故 `h_min ≥ h_req+δ_lag` 时采样间不越界。

**引理 2（交接漂移传播）**：若 `‖∂Φ/∂u‖ ≤ L_H`、`ε ≤ ε_task`，则 `δ_H ≤ L_H ε_task`；取 `b_j ≥ L_H ε_task` 可保交接兼容。

**正确性定理（Safety-Filtered Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `Π_h` 对 `S_safe` 前向不变且每 `Δt_S` 施加一次；**(A30)** `‖∂Φ/∂u‖ ≤ L_H`；**(A31)** `π_TS`、`h` 分别 `L_TS`、`L_h`-Lipschitz。
若路径每条边 `safe_edge`、每个交接 `δ_H ≤ b_j`、且 `h_min ≥ h_req+L_h v_max Δt_S`，则组合执行确定性无碰撞，任务误差 `≤ e_task+L_H ε_task`，且
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - P(δ_H>b) - P(ε>ε_task)
```
**推论**：存在 `compat ≥ θ_a` 而 `safe_edge=false` 的组合，故第 54 轮 `J` 会给出虚假可部署判定；`δ_H` 与 `δ_lag` 为必要新增。

## 6. 本轮最大风险

**一句话**：安全滤波并非透明投影——它以“任务税”改写末端执行器指令、以“交接漂移”污染技能边界、以“双速率滞后”掏空规划期的安全裕度；一旦 `δ_H` 超出下一技能的缓冲带或安全环慢于末端环，第 54 轮动作兼容的组合会在物理上“名义安全、实际越界”，故必须把交接漂移 `δ_H`、采样间滞后 `δ_lag` 与任务税 `ε` 提升为联合证书的一等字段，任何缺其一的安全包络都不得判定可部署。
