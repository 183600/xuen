# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「双足机器人」×「步骤分」）

> R69 把不确定性一分为二：aleatoric 收进 λ_floor，epistemic 交给「流匹配多模态策略 + 主动多模态交互」，用 VoI 决定要不要看/问/触。但它埋着三个未言明的假设：**时间是免费的、动作是可回滚的、交互可以在任意时刻发起**。对机械臂大致成立，对双足机器人则根本不成立——(i) 双足不能「暂停」，站着不动本身就是主动平衡，平衡裕度（capture point / DCM）会随拖延流失；(ii) 抬脚落步是**不可逆承诺**，抬脚之后才到的信息一文不值；(iii) 摔倒是**吸收态**，不是「收紧 λ」就能化解的连续风险。于是 R69 的无时相 VoI 会在它最需要好使的时刻——临近承诺边界时——系统性地高估交互动价值。
>
> 本轮两个灵感正好补上两块缺失：
> - **双足机器人**给出**时相结构**：接触相/摆动相构成天然的决策节拍，每一步都是一次有截止期的承诺；平衡裕度是可消耗的「生命预算」，等待不是免费的。
> - **步骤分**给出**过程信用**：不必等最终成败，也能给中间步打分——既能提前止损，也能把失败归因到具体某一步，还能在承诺前用逐步到达的证据做序贯消歧。
>
> 核心命题：**把 R69 的「瞬时、无时相」消歧升级为「步级、有截止期」的序贯承诺问题**。在每一步的决策点做四选一 {执行 act, 询问 ask, 承诺 commit, 中止 abort}；交互价值按「信息能否在承诺前到达」折现（晚到即零）；用**物理可验证的步骤分**锚定**学习型步骤分**，防止过程信用被伪造。命名 **STRIDE-RAS**（Step-wise Temporal credit & IRreversibility-aware Disambiguation Engine）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我什么时候必须停止求证、把脚迈出去**」——不确定性不只决定问不问，还决定**在问得来不及之前就必须落子**。

## 0. 直觉与动机

**灵感 1（双足 → 每个决策都有截止期）**
直觉：R69 的 VoI 是一个「静态」量：算 ask 值不值。但双足机器人的信息获取有硬截止期——脚一旦离地进入摆动相，落点已由当前状态基本锁定，此时再「看一眼前方」对本次落脚毫无帮助，只能影响下一步。人类的经验正是如此：过独木桥时，你在抬脚**之前**看，抬脚之后再犹豫只会摔。于是「值不值得问」之外多了一个维度：「**还来不来得及问**」。R69 的 VoI 在 τ_g > τ_c（交互延迟超过承诺期）时应恒为 0，而它并没有这个项。

**灵感 2（双足 → 平衡裕度是生命预算，等待要花钱）**
直觉：R69 的交互预算是一个固定配额（单位时间 ≤1 次、位移 ≤ ε_g），暗含「不交互就不消耗」。但双足走路时，**站着不动也在消耗平衡裕度**：扰动持续作用，DCM 逼近支撑多边形边界；拖得越久，可用的安全落脚点越少。因此「等信息」不是一个零成本的中性动作，而是**拿安全裕度换信息**。这给出了一个比 R69 固定预算更本质的约束：交互必须在「花掉裕度后仍存在可行落点」的前提内进行，即保持在 viability kernel 里。R69 的固定预算被包含为「裕度充足」的退化情形。

**灵感 3（步骤分 → 过程信用能提前止损与归因）**
直觉：批改数学题给「步骤分」，意义在于**不必等最终答案错了才知道过程错了**，而且能定位错在哪一步。R69 只有终局证书：任务失败后，你不知道是「问错了模态」还是「执行差了」。步级过程信用 s_k 提供两件事：(a) **提前止损**——若「已得分 + 未来乐观上界」都低于门槛，就应在摔之前中止/回退，而不是赌到最后一刻；(b) **步级归因**——审计可以指出是哪一步的信用被错误授予。这把 R69 的「交互审计」扩展到「决策链审计」。

**灵感 4（步骤分 → 证据是逐步到达的，够用就停）**
直觉：R69 的消歧是「一次交互、看结果、更新后验」。但每一步本身就会自然产生一点证据（落点是否打滑、接触是否稳定、视觉是否自洽），这些证据**免费且连续**。于是消歧可以变成序贯检验（SPRT 式）：每走一步更新一次模态后验，一旦后验越过阈值就停止求证、直接承诺——用比 R69 更少的显式交互达到同样的确定度。反过来，如果到截止期前累计的证据量根本不足以把后验推过阈值，那**在承诺前消歧就是不可能的**，必须直接进入 R69 的保守兜底。这是一个可以事先判定的可行性条件，而不是走一步看一步。

**灵感 5（步骤分 → 过程信用本身是可被伪造的信号）**
直觉：步骤分是「学出来的裁判」，而学出来的裁判会被奖励黑客（reward hacking）骗：把一步拆成两步刷分、给物理上不可行的动作高分、或干脆幻觉出一个「这步做对了」。一旦高步骤分在不可逆承诺前盖章，系统会**自信地落一个注定要摔的脚**。R69 的最大风险是「问错比不问更危险」；R70 把它升级为「**信错步比不问更危险**」——因为承诺不可逆，错不再是可以回滚的答案，而是已经摔下去的身体。因此本轮必须把步骤分拆成「物理可验证」与「学习可伪造」两部分，用前者锚定后者。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（STRIDE-RAS 总览）** STRIDE-RAS = (PSM, RCE, BLB, MINT-τ, SCS, EAS, ARF, RAS-WM†)。四不变式：
(i) 继承 R69 定义 293 的实时流零学习写操作与交互预算；
(ii) **承诺安全**：任何 commit 必须在 viability kernel 𝒱 内发起，且发起时存在至少一条可行后续落点；承诺期 τ_c 由 RCE 在线给出；
(iii) **生命预算**：ask 的准入条件不是固定配额，而是「执行 g 后以概率 ≥ 1−δ 仍满足平衡裕度 M ≥ M_min」；
(iv) **证据纪律（时相版）**：步级证据必须与至少一个物理可验证源交叉，学习型步骤分不得单独触发 commit；ECE_p 越界则禁用学习型步骤分。

**定义 311（时相半马尔可夫抽象 PSM）** 把时域按接触事件切分为相 k=0,1,…, 状态 s_k = (x_k, φ_k, k)，φ_k ∈ {DS, SS_L, SS_R, flight} 为接触模式，T_k 为相时长。决策点 d_k 是每个相边界；**推理节拍 = 相边界**，而非 R69 的每个控制 tick（2.6ms）。相内沿用低层控制器；相边界才允许重估 VoI、升 K 采样与交互。转移由 guard 事件（触地、离地、越界）驱动。

**定义 312（决策空间）** 每个决策点 d_k 选 d ∈ 𝒟 = {act, ask, commit, abort}：act=继续执行当前任务动作块；ask=执行一个信息动作 g（继承 R69 定义 294）；commit=把当前模态/落点固化为不可逆承诺并进入执行；abort=放弃当前计划并转 ARF 回退。四者共享同一 C-RAS-WM 前缀认证。

**定义 313（可逆度与承诺期 RCE）** 对动作轨迹 ξ，定义可逆度 ρ(ξ) ∈ [0,1] 为「存在一个反动作能在安全包络内把状态恢复到等价类」的概率；承诺期 τ_c(ξ) = inf{ t : ρ(ξ_{t:}) < ρ_min }。按 ρ 分为 **R（可逆，ρ≥ρ_hi）**、**Q（准可逆，ρ_lo≤ρ<ρ_hi，需代价）**、**A（吸收/不可逆，ρ<ρ_lo）**。双足支撑相切换通常为 A：落脚一旦接触，改落点即需迈出更多步。

**定义 314（可行核与平衡裕度）** 用 DCM ξ_dcm = x + ẋ/ω（ω=√(g/h)）描述平衡；viability kernel 𝒱 为「存在安全落点序列」的状态集；平衡裕度 M(t) = dist(ξ_dcm(t), ∂𝒱)。liveness 约束 M(t) ≥ M_min。等待/交互的代价体现为 M 在等待期间的期望耗散率 μ（由扰动与支撑面积估计）。

**定义 315（生命预算 BLB）** 选择一个信息动作 g 的准入条件：E[M(t+τ_g) | g] ≥ M_min 且 P(M(t+τ_g) ≥ M_min) ≥ 1−δ。可用时域预算 B_bal(t) = (M(t) − M_min)/μ。R69 定义 293-ii 的固定配额是本定义在 M(t) ≫ M_min 时的上界特例。

**定义 316（时相折现 VoI，MINT-τ）** 设交互 g 的完成延迟为 τ_g（含执行+解读），则
VoI_τ(g) = P(τ_g ≤ τ_c | o, g) · [ H(M_mode|o) − E_{y∼p(·|g,o)} H(M_mode|o,y) ] − c_phys(g) − c_bal(g)，
其中 c_bal(g) 为 BLB 的裕度成本；若 τ_g > τ_c 则 VoI_τ(g) ≡ 0。最优交互 g* = argmax_g VoI_τ(g)，且仅在 VoI_τ(g*) > 0 且预算允许时执行。

**定义 317（序贯证据与步级后验）** 每个相结束产生一步部分观测 y_k（打滑/触地一致性/视觉自洽等）。后验 b_k = P(M_mode | y_{1:k}) ∝ b_{k−1}·p(y_k | M_mode)。定义步级对数似然比 Λ_k = log [p(y_{1:k}|m_1)/p(y_{1:k}|m_0)]，并采用 SPRT 停止规则：Λ_k ≥ A ⇒ 承诺 m_1；Λ_k ≤ B ⇒ 承诺 m_0；否则继续收集。这就是「步骤分」在统计侧的形态。

**定义 318（步级过程信用 SCS）** 相 k 的步骤分 s_k = α·s^phys_k + (1−α)·s^learn_k，其中
s^phys_k ∈ {0,1}（或 [0,1] 的硬判据）：落点在 𝒱 内、接触一致、DCM 在支撑多边形内等**物理可验证**量；
s^learn_k：PRM 给出的任务进度分（可学习、可被伪造成）。
累积信用 S_k = Σ_{j≤k} γ^{k−j} s_j，γ∈(0,1]。s^phys 是「不可伪造锚」，s^learn 是「可伪造的丰富信号」。

**定义 319（物理锚定校准 PAC）** 以 s^phys 为标签校准 s^learn，定义步骤分校准误差 ECE_p。若 ECE_p > τ_p，则把 α 提升到 α_min（甚至 α=1，仅用物理分），并禁用 s^learn 触发 commit。这是 R69 的 MCG（模态校准门）在**信用域**的镜像。

**定义 320（提前止损 EAS）** 给定可采纳的乐观剩余上界 V̄_remaining(k)（满足 V̄ ≥ 真实可达剩余进度），继续条件为 S_k + V̄_remaining(k) ≥ S_min；否则 abort→ARF。可采纳性保证不误杀，这与分支定界/可采纳启发式同构。

**定义 321（非对称风险与回退集 ARF）** 摔倒代价 c_fall = ∞（吸收态）。回退集 ℱ = {step-in-place, squat, sit, brace}，每个动作有有界残余风险 ε_fb 与「到达安全姿态」的有限时域 T_safe；abort 必须选择一个 f∈ℱ 使 T_safe ≤ B_bal(t) 且 ε_fb ≤ ε_abort。

**定义 322（步级 epistemic 交叉检验 SEC）** 若模态置信高（H_mode 低）但 s^phys 低，或反之，则判为「未建模危险」并上调 U_epi；即用物理步骤分与模态分布的一致性做第二意见，而非只看模态熵。

**定义 323（证书 J_STRIDE）** J_STRIDE = (J_FLUID, {s_k}, {ρ_class_k}, τ_c_margin, ECE_p, abort_log, fallback_used, stride_ver)。Valid ⇔ Valid(J_FLUID) ∧ 承诺时刻在 𝒱 内 ∧ ECE_p ≤ τ_p（或已退化为纯物理分）∧ 证据纪律满足。

**定义 324（信用投毒干扰集 ℰ_credit）** 步骤分注水（把一步拆两步）、幻觉部分信用（无证据给分）、边界漂移（移动相切分以刷分）、漏步（省略关键步）。ℰ_STRIDE = ℰ_FLUID × ℰ_credit。与 R69 的 ℰ_poison 不同，这里攻击的是**裁判**而非回答者。

**定义 325（退化边界）** 若任务只有单一相（N=1）、τ_c=∞、M(t)=∞（无平衡约束）、s_k≡1，则 STRIDE 逐指令退化为 R69 的 FLUID-RAS：四选一坍缩为 act/ask，VoI_τ 坍缩为 VoI，EAS/ARF 不触发。故 FLUID 是 STRIDE 的「无时相、可逆、无截止」边界。

## 2. 关键算法骨架

```python
# IP-264 PSM：时相半马尔可夫调度——把决策从每个 tick 降到每个相边界
class PhaseScheduler:
    def step(self, x, phi, k):
        # 低层控制沿用 R68/R69，不在相内做重推理
        return low_level_control(x, phi)
    def on_guard_event(self, event, x):
        if event in ("touchdown", "liftoff", "boundary"):
            return DecisionPoint(x, phase=self.next_phase(event))  # 触发步级决策
        return None

# IP-265 RCE：可逆度与承诺期（DCM 闭式 + 轻量分类器）
def commitment_horizon(x, xi_dcm, g=None):
    tau_c = time_until(xi_dcm, viability_boundary(x))      # 物理可算
    rho   = reversibility(x, g)                            # 轻量分类器
    cls   = "R" if rho >= RHO_HI else ("Q" if rho >= RHO_LO else "A")
    return tau_c, cls, rho

# IP-266/316 BLB + MINT-τ：时相折现的交互决策
def choose_interaction_tau(modes, b, o, tau_c, M_now, budget):
    best = None
    for g in info_action_candidates(modes):
        tau_g = latency(g)                                  # 执行 + 解读
        if tau_g > tau_c:                       continue    # 晚到即零：不再花冤枉钱
        if not budget.allow_balance(g, M_now):  continue    # E[M(t+tau_g)] >= M_min
        if not c_ras_wm.certify_info(g, o):     continue    # 继承 R69 定义 302
        voi = p_arrive(tau_g, tau_c) * (entropy(b) - expected_entropy(b, g, o))
        score = voi - cost_phys(g) - cost_balance(g, M_now)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None       # 无利可图 -> FLUID/R68

# IP-268/317 SCS：步级过程信用 + 序贯证据
def step_credit(y_k, b_prev, phys_ok, prm):
    b  = bayes_update(b_prev, y_k)                          # 步级后验
    s_phys  = 1.0 if phys_ok else 0.0                       # 物理可验证锚
    s_learn = prm.score(y_k, b)                             # 可被伪造，需校准
    s = alpha * s_phys + (1 - alpha) * s_learn
    return b, s, (s_phys, s_learn)

# IP-269 EAS：可采纳上界的分支定界式提前止损
def early_abort(S_k, Vbar_remaining, S_min):
    return (S_k + Vbar_remaining < S_min)                   # 只在必然达不到时才中止

# IP-270 ARF：非对称风险下的安全回退
def fallback(M_now, budget):
    feas = [f for f in FALLBACKS
            if f.T_safe <= budget.time_left(M_now) and f.epsilon <= EPS_ABORT]
    return min(feas, key=lambda f: f.epsilon) if feas else SQUAT_EMERGENCY

# IP-275 主闭环（继承 R69，把每 tick 决策改为步级四选一）
def STRIDE_RAS_round(M, x, phi, k, b):
    tau_c, cls, rho = commitment_horizon(M.x, M.xi_dcm)
    dp = M.psm.on_guard_event(M.event, M.x) if M.event else None
    # --- 相内：只做廉价证据累积，不做重推理 ---
    b, s_k, (s_phys, s_learn) = step_credit(M.y_k, b, M.phys_ok, M.prm)
    M.eas.update(s_k)
    if M.eas.should_abort(M.S_k, M.Vbar_remaining):
        f = fallback(M.M_now, M.budget); return ("abort", f)     # 摔之前先撤
    if dp is None:                                                   # 非决策点
        return ("act", M.low_level_control(x, phi))
    # --- 决策点：四选一 ---
    g = (choose_interaction_tau(M.modes, b, M.o, tau_c, M.M_now, M.budget)
         if (entropy(b) > TAU_EPI and M.pac.trusted(M.ECE_p)) else None)
    if g is not None:
        y = M.cia.execute(g)
        b = bayes_update(b, y)                                       # 交互只提供似然
    # 证据是否足以在截止期内过阈值？不行就退 R69 兜底
    if not M.sprt.decided(b) and M.sprt.in_time_feasible(b, tau_c):
        return ("ask" if g else "act", b)                            # 继续收集
    if not M.sprt.decided(b):                                        # 来不及消歧
        return ("commit_with_fallback", M.efs.risk_scale(U_from(b)), fallback(M.M_now, M.budget))
    mode = M.sprt.decide(b)
    if not in_viability(M.x, mode.a, M.x_dcm):                       # 承诺安全不变式
        return ("abort", fallback(M.M_now, M.budget))
    return ("commit", mode)                                          # 不可逆落步
```

## 3. 推导

**引理 19（晚到信息零价值）** 若交互延迟满足 τ_g ≥ τ_c 几乎必然，则 VoI_τ(g) = 0，且继续执行 g 只增加成本。系 1：R69 的 VoI 是 VoI_τ 在 τ_c=∞ 时的上界，故在任何有限承诺期处，R69 的决策**系统性高估**交互价值，高估量恰为 P(τ_g > τ_c)·VoI。系 2：「还来不来得及」不是效率问题而是正确性问题——它决定问出的答案能否进入本次决策。

**引理 20（步级证据的可消歧性条件）** 设步级证据对真实模态与竞争模态的期望 KL 散度为 D_k>0，SPRT 阈值 (A,B)。则到承诺期 τ_c 前可用的总信息量为 D(τ_c) = Σ_{k: t_k < τ_c} D_k。若 D(τ_c) < log(A) − log((1−β)/α)，则**在承诺前把后验推过阈值的概率 ≤ β**，即「时间不够消歧」。故 STRIDE 可以**事先**判定本次是否值得交互：不足则直接走 R69 兜底，不做无效追问。系：序贯消歧所需显式交互次数 ≤ R69 单次交互方案的 (log A)/D̄ 期望步数下界，通常显著更少。

**引理 21（提前止损的可采纳性）** 若 V̄_remaining(k) ≥ 真实可达剩余信用，且 s_k ≤ 真实归一化进度，则 EAS 的 abort 永不误杀可达目标：被中止的轨迹其真实可得分 < S_min。故提前止损只损失本来就不可能成功的轨迹，换来回退的时间裕度。EAS 与分支定界的可采纳剪枝等价。

**引理 22（物理锚定的信用抗伪造界）** 设 s^phys 对物理造假不可伪造、s^learn 的误差率 ε_s 且与 s^phys 的相关为 ρ_c。在 PAC 门控 ECE_p ≤ τ_p 下，信用注水攻击被接受的期望超额信用 ≤ (1−α)·(ε_s + τ_p)/(1−ρ_c)。系：α 是「可解释但可伪造」与「可信但稀疏」之间的旋钮；α→1 时攻击面消失、但过程信用的分辨力退化为物理判据。

**定理 18（STRIDE 严格包含 FLUID）** 在 A99（viability kernel 非空、回退风险 ε_fb ≤ 继续风险、EAS 上界可采纳）下，对任意状态：(a) 当单相、τ_c=∞、无平衡约束时，STRIDE 与 FLUID 逐指令相同（定义 325）；(b) 否则 STRIDE 的期望风险 ≤ FLUID，因为 STRIDE 只做两件 FLUID 不做的事——**删去晚到而无效的交互**（引理 19）与**增加一个可选的提前回退**（引理 21），二者都是单侧改进。安全侧不让步。

**定理 19（承诺安全与不可逆错误的上界）** 在可行性不变式（定义 310-ii、314）与 BLB 准入（定义 315）下，任一 commit 落在 𝒱 外的概率 ≤ δ；交互只改变「选哪个模态」，不改变安全包络；当证据来不及（引理 20）或信用不可信（引理 22）时，STRIDE 单调不降地退化为 R69 的保守兜底 ⇒ 控制连续，无突变。系：**「问得晚」与「问得错」都被转化为「不承诺、回退」，而不是「硬着头皮摔」。**

**定理 20（步级节拍的等价性）** 若相内后验的变化率有界（Lipschitz L_b），且存在紧急中断通道，则把推理从每 tick 降到相边界，其决策风险相对逐 tick 增加 ≤ L_b·T_k；而计算量下降与 T_k 成正比。故在双足这类 T_k ≫ 控制周期的系统上，步级节拍是「几乎免费」的降本，同时获得更稳的决策（避免每 tick 的 VoI 抖动）。这是 R69 的 K 自适应之外的另一种实时预算解法。

## 2. 形式化定义（要点版）

**定义 311（PSM）** 按接触事件切相，决策点=相边界；推理节拍从每 tick 降到每相（双足约 2Hz）；相内低层控制，相边界才允许重估 VoI / 升 K / 交互。

**定义 313（RCE）** `ρ(ξ)` 可逆度、`τ_c` 承诺期；三分类 R/Q/A；`τ_c = inf{t: ρ(ξ_{t:}) < ρ_min}`。

**定义 322（SEC）** 模态置信高但 `s^phys` 低（或反之）⇒ 上调 U_epi（未建模危险），物理步骤分与模态分布互为第二意见。

```python
# IP-264 PSM：时相半马尔可夫调度（相内不重推理）
def on_guard_event(event, x):
    return DecisionPoint(x, phase=next_phase(event)) if event in \
        ("touchdown", "liftoff", "boundary") else None

# IP-265 RCE：可逆度与承诺期
def commitment_horizon(x, xi_dcm):
    tau_c = time_until(xi_dcm, viability_boundary(x))     # 物理可算
    rho   = reversibility(x)
    cls   = "R" if rho >= RHO_HI else ("Q" if rho >= RHO_LO else "A")
    return tau_c, cls, rho

# IP-267 MINT-τ：晚到即零的交互决策
def choose_interaction_tau(modes, b, o, tau_c, M_now, budget):
    best = None
    for g in info_action_candidates(modes):
        tau_g = latency(g)
        if tau_g > tau_c:                      continue    # 晚到信息无价值
        if not budget.allow_balance(g, M_now): continue    # E[M(t+tau_g)] >= M_min
        if not c_ras_wm.certify_info(g, o):    continue
        voi = p_arrive(tau_g, tau_c) * (entropy(b) - expected_entropy(b, g, o))
        score = voi - cost_phys(g) - cost_balance(g, M_now)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268/317 SCS：步级过程信用 + 序贯后验
def step_credit(y_k, b_prev, phys_ok, prm):
    b  = bayes_update(b_prev, y_k)
    s  = alpha * (1.0 if phys_ok else 0.0) + (1 - alpha) * prm.score(y_k, b)
    return b, s

# IP-269 EAS：可采纳上界的分支定界式提前止损
def early_abort(S_k, Vbar_remaining, S_min):
    return S_k + Vbar_remaining < S_min                    # 仅必然达不到时中止

# IP-270 ARF：非对称风险回退
def fallback(M_now, budget):
    feas = [f for f in FALLBACKS
            if f.T_safe <= budget.time_left(M_now) and f.epsilon <= EPS_ABORT]
    return min(feas, key=lambda f: f.epsilon) if feas else SQUAT_EMERGENCY

# IP-275 主闭环（继承 R69，逐 tick 决策改为步级四选一）
def STRIDE_RAS_round(M, x, phi, k, b):
    tau_c, cls, rho = commitment_horizon(M.x, M.xi_dcm)
    dp = on_guard_event(M.event, M.x) if M.event else None
    b, s_k = step_credit(M.y_k, b, M.phys_ok, M.prm)       # 相内廉价累积
    if early_abort(M.S_k, M.Vbar_remaining, S_MIN):
        return ("abort", fallback(M.M_now, M.budget))
    if dp is None:
        return ("act", low_level_control(x, phi))
    g = (choose_interaction_tau(M.modes, b, M.o, tau_c, M.M_now, M.budget)
         if entropy(b) > TAU_EPI and M.pac.trusted(M.ECE_p) else None)
    if g is not None:
        b = bayes_update(b, M.cia.execute(g))              # 交互只提供似然
    if not sprt.decided(b) and sprt.in_time_feasible(b, tau_c):
        return ("ask" if g else "act", b)                  # 证据仍在累积
    if not sprt.decided(b):                                # 来不及消歧
        return ("commit_with_fallback", risk_scale(b), fallback(M.M_now, M.budget))
    mode = sprt.decide(b)
    if not in_viability(M.x, mode.a, M.x_dcm):             # 承诺安全不变式
        return ("abort", fallback(M.M_now, M.budget))
    return ("commit", mode)                                # 不可逆落步
```

## 4. 推导

**引理 19（晚到信息零价值）** `τ_g ≥ τ_c` a.s. ⇒ `VoI_τ(g)=0`，继续执行只增成本。系 1：R69 的 VoI 是 `τ_c=∞` 的上界，故有限承诺期处系统性高估，高估量 = `P(τ_g>τ_c)·VoI`。系 2：「来不来得及」是正确性问题而非效率问题。

**引理 20（可消歧性条件）** 步级证据期望 KL 为 `D_k`，到截止期总信息 `D(τ_c)=Σ_{t_k<τ_c}D_k`。若 `D(τ_c) < log A − log((1−β)/α)`，则承诺前过阈值概率 ≤ β ⇒ 应直接走 R69 兜底，不做无效追问。序贯方案所需显式交互 ≤ R69 单次方案的 `(log A)/D̄` 下界。

**引理 21（提前止损可采纳性）** `V̄_remaining ≥ 真实可达剩余`、`s_k ≤ 真实进度` ⇒ 被 EAS 中止的轨迹真实可得分 `< S_min`，永不误杀；等价于分支定界可采纳剪枝。

**引理 22（物理锚定抗伪造界）** `s^phys` 不可伪造、`s^learn` 误差 `ε_s`、相关 `ρ_c`，PAC 门控 `ECE_p≤τ_p` 下，信用注水被接受期望超额 ≤ `(1−α)(ε_s+τ_p)/(1−ρ_c)`。α 是可解释-可伪造与可信-稀疏之间的旋钮。

**定理 18（STRIDE 严格包含 FLUID）** A99（𝒱 非空、`ε_fb ≤ 继续风险`、`V̄` 可采纳）下：单相/无截止时逐指令相同；否则 STRIDE 风险 ≤ FLUID，因为它只做两件单侧改进——删去晚到无效交互（引理 19）、增加可选提前回退（引理 21）。

**定理 19（承诺安全上界）** 可行性不变式 + BLB 准入下，commit 落在 𝒱 外概率 ≤ δ；交互只改模态选择、不改安全包络；来不及或信用不可信时单调退化为 R69 保守 ⇒ 无突变。系：「问得晚」「问得错」都转化为「不承诺、回退」。

**定理 20（步级节拍等价性）** 相内后验变化率有界且有紧急中断时，相边界推理相对逐 tick 的风险增量 ≤ `L_b·T_k`，算力下降正比 `T_k`。故双足（`T_k ≫` 控制周期）上步级节拍几乎免费，且避免每 tick VoI 抖动。

## 7. 本轮最大风险

**一句话**：STRIDE 把「何时必须承诺」交给可逆度/承诺期、把「该不该继续」交给步骤分，但这两者都可能被自己算错——τ_c 估短则过早放弃求证、估长则在不可逆前夜才发现来不及，而步骤分裁判一旦被注水或幻觉，系统就会用错误的局部信用为不可逆的落步盖章；由于摔倒是吸收态，这不再是 R69 那种「被证实的错误答案」，而是不可回滚的物理失败——**信错一步，比不问更危险**。
