# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「关节驱动」×「多机协同」）

> R69 把不确定性一分为二，把 epistemic 交给「看 / 问 / 触」去主动消解。这个闭环很漂亮，却默认了两件在真实机器上都不成立的事：
> - **身体是透明的**：R69 假设动作被精确且「沉默」地执行，不确定性只存在于世界（传感器）与策略（模态）里，从不存在于「我这个关节此刻还能出多大力、它正在承受什么、我到底做不做得出这个动作」。可关节本身是一个因果锚定的、高带宽的传感接口——力矩、电流、位置残差里写着接触、负载、摩擦与回差。
> - **同伴是合作的**：R69 的「问」对着一个会老实回答的 oracle 或一个静态场景。多机场景里，另一个机器人是有自己信念与目标的规划者；更关键的是，我们**被同一个物体物理耦合**——它的错误会通过力，直接写进我的安全包络。
>
> 本轮两个灵感正好补上这两块缺失：
> - **关节驱动**把「身体」变成信息源与约束源：一方面提供 R68 残差、R69 流似然之外的**第三条独立证据通道**（本体证据）；另一方面引入第三类不确定性——**权限不确定性 U_eff**（饱和、热降额、限位、回差）——它不是「问」出来的，是「**做**」出来的，且必须先被硬约束住。
> - **多机协同**把「交互」从语言/注视升级为**物理耦合上的协商**：共享负载既是控制通道，也是信息通道；协同不是发消息对表，而是在耦合通道上达成**可认证的共享模态**；而同伴可能是拜占庭的。
>
> 核心命题：**把 R69 的「信息动作」从看/问/触扩展到「本体探询（exert/probe）」与「协同承诺（offer/commit/yield）」；把不确定性从二分扩为四分 (U_ale, U_epi, U_eff, U_coord)；U_eff 由权限调节器硬约束，U_coord 由拜占庭鲁棒意图协商消解；任何一步失败或被投毒，就逐层退化，R69 恰是「单机、不探询、不耦合」的边界。** 命名 **ARTICULATE-RAS**（Articulated-joint, Trust-aware, Interactive Load-sharing And Target-consistent Evidence）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「**我的身体还能做多少，我和同伴的力与意图是否对得上**」——不确定性不只在脑与世界之间，也在关节里、在机器与机器之间。

## 0. 直觉与动机

**灵感 1（关节是身体的麦克风，不是执行器的尾巴）**
直觉：R69 的「触」只在末端执行器上发生一次；但一台真正有本体感的机器，**每一次驱动都在读世界**。命令 τ 与实测力矩的残差 e_τ 里，叠加着摩擦、回差与外力：末端碰到墙、负载变重、地面变滑，最先变化的不是相机，而是关节电流。于是「探询」不必总是伸出一个探针——**把关节阻抗调一下、轻轻点一下、慢慢压一下**，就是一次信息动作。R69 的「看/问/触」漏掉了成本最低、延迟最小、因果最直接的那一类：**动一动身体去感受**。

**灵感 2（权限是第三类不确定性：不是不知道，而是做不到）**
直觉：aleatoric 是「世界的噪声」，epistemic 是「信念的歧义」，而真实机器人还有第三种：**我的执行权限不够了**。电机接近饱和、关节接近限位、驱动器热降额、回差让精确定位失效——此时策略再确定，动作也做不准。更危险的是：R69 的 VoI 可能选了一个「信息上很值钱、但身体做不出」的探询，然后系统把「动作没做出来」误读成「世界没给信息」。**权限不是风险，是可行性；它必须被治理，而不是被概率化。**

**灵感 3（力的耦合就是信息总线：耦合是双刃的）**
直觉：两个机器人抬同一张桌子，不是一个发消息、一个听话；它们通过桌子的反作用力**实时交换**负载分布、估计各自抓取是否打滑、对方是否在偷懒或突然发力。耦合越刚，力传得越清楚——但也把对方的错误**以增益 1 传进来**：一个撒谎的同伴只要施加一个虚假的内力，就能让我「感觉」到负载变轻。所以**柔顺度是一个可调的信息-污染折中**：太软，读不到对方；太硬，被对方带偏。

**灵感 4（协同 = 共享模态协商，不是消息对表）**
直觉：R69 里每个机器人都可能对世界有多种模态（走左/走右、抓上/抓下）。多机协同的关键不是「告诉对方我的动作」，而是**在联立的模态空间里找到一组彼此物理可行、且能被双方安全执行的组合**。这不是一个通信问题，是一个**分布式约束优化 + 故障容错**问题：同伴可能延迟、丢包、撒谎、或临时变卦。单条消息永远不能定案，必须达到 quorum。

**灵感 5（朴素扩展的三个陷阱）**
直觉：直接给 R69 加「关节探询 + 多机通信」会踩三个坑。
(i) **刚性耦合放大谎言**：为了信息把耦合调硬，等于把同伴的拜占庭误差直接注入自己的力控，安全界瞬间失效；
(ii) **探询耗尽权限**：为了消歧而反复激励关节，把热裕度和力矩裕度花光，真正需要出力时反而做不到——**用安全换信息，再用信息换不安全**；
(iii) **协商被投毒**：一个恶意机器人只要在关键时刻报一个错误的共享模态，就可能诱使整个队进入物理上不可行、但「大家看起来都同意」的构型。
所以本轮必须同时交付：耦合认证、权限调节、拜占庭 quorum、以及「单机/单次证据不得定案」的纪律。

**灵感 6（严格包含：新层必须是旧层的边界退化）**
直觉：只有一台机器人、不做关节探询、不参与耦合时，ARTICULATE 必须逐指令等于 R69；再把交互也关掉，等于 R68。安全侧逐层嵌套：L0 全协同 → L1 单机（R69）→ L2 禁交互（R68）→ L3 安全停。否则每加一层就多一个必须独立信任的黑箱，前 69 轮建立的可认证性就断了。

## 1. 形式化定义（增量：定义 310–330）

**定义 310（ARTICULATE-RAS 总览）** ARTICULATE-RAS = (JPE, AUE, LSC, CMG, BIC, CQC, JPP, CFC, AG, TDM, VQAuditor-M, RAS-WM‡)。五不变式：
(i) **只读本体证据**：JPE 只读关节量与力矩残差，不改写策略参数（继承 R68/R69 的实时零学习写）；
(ii) **权限非负**：任何发出指令先过权限调节器 AG，要求 α_min ≥ 0；接近饱和/热限时必须降权或拒绝，不得「硬撑」；
(iii) **耦合前认证**：未通过耦合力认证 CFC 的机队不得进入物理耦合，只能单机执行；
(iv) **证据纪律**：单个同伴、单条消息或单次关节探询都不得单独定案，协商需拜占庭 quorum，本体证据需与至少一个正交通道一致；
(v) **分层安全单调**：L0 ARTICULATE → L1 单机 R69 → L2 禁交互 R68 → L3 安全停，动作可达集逐层收缩，风险逐层不增。

**定义 311（本体动力学与驱动约束）** 机器人 i 有 n_i 个关节，q_i ∈ ℝ^{n_i}。关节力矩
τ_i = M_i(q)q̈ + C_i(q,q̇)q̇ + g_i(q) + J_iᵀ(q) f_i^ext + τ_fric(q̇) + τ_back(q) + η_τ，
其中 f_i^ext 为末端/接触外力，η_τ 为力矩测量噪声，τ_fric、τ_back 为摩擦与回差项。驱动约束 |τ_{i,j}| ≤ τ_max,j(q̇_i, T_i)，τ_max 随关节速度与驱动器温度 T_i 单调下降（热降额）；关节位置 q_{i,j} ∈ [q_min,j, q_max,j]。

**定义 312（本体-协同增广动作空间）** 机器人 i 的动作
ξ_i = (a_i, g_i, p_i, c_i) ∈ 𝒜_task × 𝒜_info × 𝒫_i × 𝒞_i，
其中 a_i 为任务动作（继承 R69）；g_i = (g_gaze, g_probe, g_ask) 为 R69 的信息动作；p_i 为**关节探询**（阻抗增益、激励频率、幅值、时长、力矩上限），满足能量 ∫‖τ‖²dt ≤ E_p、幅值 ≤ ε_p、力/位包络不越界；c_i ∈ {offer, request, yield, claim, commit, release} 为**协同承诺动作**。联合动作为 ξ = (ξ_1,…,ξ_n) 的可行配置。

**定义 313（关节驱动指纹 JPE）** 令模型预测力矩 τ̂_i = 名义刚体项（不含 f_ext）。本体残差
e_τ,i = τ_meas,i − τ̂_i = J_iᵀ f_i^ext + τ_fric + τ_back + η_τ。
特征 z_τ,i = Φ_J(e_τ,i)（滑窗内的均值/方差/频带能量/跨关节相关）。JPE 输出**接触/负载签名**（外部项）与**本体签名**（摩擦/回差项）的分离估计。JPE 是只读通道：它产生证据，不产生写操作。

**定义 314（权限不确定性与权限调节器 AG）** 关节权限裕度
α_{i,j}(t) = (τ_max,j(q̇_i,T_i) − |τ_{i,j}|) / τ_max,j(q̇_i,T_i)，α_i = min_j α_{i,j}。
权限不确定性
U_eff,i = E[ (‖τ_i^req‖ − α_i·τ_max,i)_+ / τ_max,i ] + κ_T·1[T_i > T_derate]。
AG 把期望力矩投影到权限包络：τ^cmd = clip(τ^des, ±(1−ε_a) α_i τ_max,i)，并在 T_i 越界时按降额曲线降低速度/力上限。**U_eff 不进入交互预算，而进入可行性门控**：α_i < ε_a 时该关节探询/耦合一律作废。

**定义 315（不确定性四分）** U = (U_ale, U_epi, U_eff, U_coord)，其中 U_ale = Σ_k ŵ_k tr(Σ_k)、U_epi = H_mode·g(Δ_min) 继承 R69；U_eff 见定义 314；协同不确定性
U_coord = H(μ | o)·g(Δ_coord)，
μ 为共享模态指派（定义 317），Δ_coord 为不同指派下力分配的 W_2 距离。四者语义不同、通道不同，禁止简单相加：U_ale 进 λ floor；U_epi 走 R69 交互；U_eff 走 AG 硬门控；U_coord 走 CQC/BIC 协商。

**定义 316（负载共享耦合模型 LSC）** 被操作物体位姿 x_o，物体方程
M_o(x_o)ẍ_o + C_o(x_o,ẋ_o)ẋ_o + g_o(x_o) = Σ_i G_i(x_o) f_i + f_ext^env。
机器人 i 通过抓取矩阵 G_i 施加末端力 f_i，内力 f_int 位于 {G_i} 的零空间且须落在摩擦锥 𝒦_μ 内。耦合图 𝒢_c = (𝒱, ℰ) 连接共享同一物体的机器人；耦合刚度 K_c 由末端阻抗与物体刚度合成。LSC 同时给出**力的分配可行域** 𝔽 与**信息可观测性**（见引理 19、21）。

**定义 317（共享模态与承诺 SMC）** 机器人 i 的 R69 模态集 {m_k^i, ŵ_k^i}。共享模态指派 μ ∈ Π_i ℳ_i，μ_i 为机器人 i 选定的模态。承诺动作 c_i 携带 (μ_i, 截止时刻 d_i, 置信度)；承诺在 d_i 前有效，逾期视为未承诺。一致性谓词
Cons(μ) ⇔ 力分配可行 ∧ 无碰撞 ∧ 双方权限裕度 ≥ ε_a ∧ 抓取不打滑。
共享模态熵 H(μ|o) = −Σ_{μ∈Cons} p(μ|o) log p(μ|o)，p(μ|o) ∝ Π_i ŵ_{μ_i}^i · 1[Cons(μ)]。

**定义 318（协同模态图 CMG）** 以可行共享指派 μ 为节点，若两个指派仅一个机器人改变模态且切换代价 ≤ c_sw 则连边。节点权 w(μ) = Π_i ŵ_{μ_i}^i · compat(μ)，其中 compat 度量力分配与外力的匹配度。CMG 上求**最大权一致指派**
μ* = argmax_{μ∈Cons} w(μ)，
并要求 μ* 的边际（换掉任一机器人）不降低安全裕度；否则不协同，退单机。

**定义 319（拜占庭鲁棒意图协商 BIC）** 机队 n 台，最多 f 台拜占庭，n ≥ 3f+1。每台广播 (μ_i, 证据摘要, 承诺)。定义信任权重 ρ_i ∈ (0,1]（由 TDM 维护）。**认证谓词**
Certified(μ) ⇔ Σ_{i∈𝒬} ρ_i ≥ Q，Q = 2f+1（或加权版本 Σρ_i ≥ 2/3 Σρ），且 |𝒬| ≥ 2f+1。
安全决策只允许基于 Certified(μ)；任意两个认证 quorum 至少交叠 f+1 台，其中至少一台诚实，故两个冲突指派不能同时被认证。无 quorum（延迟/分裂/宕机）⇒ 不耦合，退 L1 单机。

**定义 320（协同查询控制器 CQC）** 对协同查询动作 c（向同伴请求意图/负载份额/可靠性）：
VoI_coord(c) = H(μ|o) − E_{y_c}[H(μ|o, y_c)]，
选择 c* = argmax_c [ β_l·VoI_local + β_c·VoI_coord(c) − c_cost(c) − c_comm(c) − c_byz(c) ]，s.t. 通信预算与延迟上限。其中 c_byz 由同伴信任 ρ 与历史不一致率给出。R69 的 MINT 是 c=∅、β_c=0 的边界。

**定义 321（关节探询规划 JPP）** 把接触/负载参数记为 θ_ext（摩擦力、刚度、质量、抓取偏移）。探询 p 的 Fisher 信息
I(θ_ext; p) = (1/σ_η²) Σ_{t∈p} (∂ e_τ(t)/∂θ_ext)ᵀ(∂ e_τ(t)/∂θ_ext)。
选 D-最优探询
p* = argmax_p log det I(θ_ext; p)，s.t. ∫‖τ‖² ≤ E_p、α_i ≥ ε_a、轨迹在安全包络内。
探询库：轻点（tap）、按压（press）、微摆（wriggle，激励摩擦/回差）、阻抗扫频（compliance sweep，辨识接触刚度）。

**定义 322（耦合力认证 CFC）** 给定已认证的负载/接触估计与其不确定集 Θ̂，耦合可行当且仅当
∃ f_i ∈ 𝒦_μ: Σ_i G_i f_i = f_total, ‖τ_i(f_i)‖ ≤ α_i τ_max,i ∀i，且对 Θ̂ 内所有参数成立。
即耦合力分配既要满足物体力平衡、又要同时落在**双方**的权限包络与摩擦锥内。若不可行 ⇒ 不耦合，单机执行或请求重新抓取。

**定义 323（本体感知风险缩放与权限调节 ARS）** 在 R69 的两级退避上增加权限项：
- 若 U_epi、U_coord 均在预算内消解：λ = λ_floor(U_ale)，得 resolution bonus；
- 若未消解/超时/被投毒/无 quorum：λ = λ_floor(U_ale + U_epi + U_coord)；
- 无论哪种，最终指令再乘权限因子 λ_eff = 1/(1 + κ_α·U_eff) 并经 AG 投影，且 τ^cmd ≤ (1−ε_a)α τ_max。
故权限不足时系统**主动降速降力**，而不是把执行失败误读为「世界无信息」；R69 为 U_eff=0、U_coord=0 的边界。

**定义 324（信任动力学 TDM）** 同伴信任
ρ_i ← clip( (1−γ_t)ρ_i + γ_t·1[μ_i 与认证结果一致], ρ_min, 1 )，
γ_t 随不一致历史与投毒疑度增长；ρ_i < ρ_min 时该同伴的消息不计入 quorum，但保留其物理存在（仍按最坏情况避让）。信任只能由**多源一致的历史**恢复，不由单次声明恢复。

**定义 325（威胁模型 ℰ_ART）** 人类/环境欺骗（继承 ℰ_FLUID）× 本体攻击 × 协同攻击：
- **力矩欺骗**：篡改力矩/电流测量，伪造接触或掩盖过载；
- **机械教学（mechanical teaching）**：同伴通过施加/卸载内力，把虚假的负载参数「教」进我的 JPE；
- **承诺反悔（covert reneging）**：先报 commit、诱导我进入耦合，再在关键时刻撤离/反向发力；
- **通信重放/延迟**：重放过期承诺、制造无 quorum 或假 quorum；
- **热/权限耗尽攻击**：诱导我反复探询，把热裕度与力矩裕度耗尽。
ℰ_ART = ℰ_FLUID × ℰ_mech × ℰ_byz × ℰ_comm。

**定义 326（证书 J_ART）** J_ART = (J_FLUID, α_min_p5, U_eff_p95, coupling_force_margin, quorum_margin, trust_min, U_coord_before/after, probe_info_gain, coordination_log_hash, articulate_ver)。Valid ⇔ Valid(J_FLUID) ∧ α_min ≥ 0 ∧ CFC 通过（耦合时）∧ quorum 满足（协同决策）∧ 证据纪律满足。

**定义 327（参与式审计 VQAuditor-M）** 审计对象新增：是否在权限不足时仍发出指令、是否用单个同伴定案、探询是否耗尽热/力裕度、耦合力是否越锥、承诺反悔是否被及时识别。结论回灌 AuditBuf，成为下一轮 TDM 与 CQC 的先验。

**定义 328（降级阶梯）** L0 全协同（探询 + 耦合 + 协商）；L1 单机（关闭耦合与协同，等价 R69）；L2 禁交互（等价 R68）；L3 安全停（最大安全集）。触发谓词带滞回与最小驻留时间；安全侧动作可达集单调收缩，风险反向。

**定义 329（严格包含）** 记 ARTICULATE(coord, probe, interact) 为开关配置。则
ARTICULATE(0,0,1) ≡ R69，ARTICULATE(0,0,0) ≡ R68。
「≡」指相同输入与随机种子下逐指令相同（含 λ、k、模态选择、τ 输出）。故 R68 ⊂ R69 ⊂ R70，且 J_ART ⇒ J_FLUID ⇒ J_CALM。

**定义 330（力-信息对偶）** 耦合通道同时承载力与信息：对耦合刚度 K_c，信息项 I(θ; τ_i|τ_j) 随 K_c 先升后饱和，污染项（同伴误差注入）随 K_c 单调放大。故存在一个由安全与信息共同决定的最优柔顺度
K_c* = argmax_{K_c} [ β_I·I(K_c) − β_p·Γ_byz(K_c) ]，s.t. CFC 可行，
它把「多硬才算协同」从工程旋钮变成一个可优化的对偶量。R69 的「不耦合」是 K_c=0 的边界。

        e = tau_meas - tau_hat
        z_ext, z_int = self.separate(e)                    # 外力 / 摩擦回差

def authority_margin(tau, tmax, temp, temp_derate):
    alpha = min((tmax[j] - abs(tau[j])) / tmax[j] for j in range(len(tau)))
    u_eff = max(0.0, norm(tau) - alpha*norm(tmax)) / norm(tmax)
    u_eff += K_T * (1.0 if temp > temp_derate else 0.0)
    return alpha, u_eff

def authority_governor(tau_des, alpha, tmax, eps_a=0.05):
    cap = max(0.0, (1.0 - eps_a) * alpha) * tmax
    return clip(tau_des, -cap, cap)                       # 永不超过权限包络

def certify_coupling(object_model, robots, theta_sets):

def byzantine_consensus(messages, trust, n, f):

    for mu_i, ev, commit in messages:
        if trust[mu_i.robot] >= RHO_MIN and commit.valid():

    return certified.pop()

def coordinated_query(modes, o, trust, budget):

    for c in query_candidates(modes):                      # 请求意图/份额/可靠性
        if not budget.allow(c): continue

                 - cost(c) - comm_cost(c) - byz_cost(c, trust))

    z_ext, z_int = M.jpe.residual(q, dq, M.ddq, tau_meas, M.last_tau_cmd)

        M.fmp.sample(o, M.k_for(M.fmp.mode_head(z))), z, M.fmp.mode_head)

    p = M.jpp.plan_probe(M.theta_ext, M.sigma_eta, M.probe_budget, alpha)

        M.cqc.update_ext_estimate(z_ext, z_int)

    mu_star = None

        msgs = M.comm.exchange(c, M.local_commitment(modes))

    u_coord = M.coord_entropy(modes) if mu_star is None else M.coord_entropy_after(mu_star)
    U_floor = U_ale + ((U_epi + u_coord) if mu_star is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))

    tau = M.ag.govern(tau_des, alpha, M.tmax)               # 最后一道硬投影
    # 6) 证据纪律 + 审计 + 证书
    M.vqa_m.submit_async(p, mu_star, alpha, U_eff, U_floor)
    return tau, lam, mu_star, (U_eff, u_coord)

## 3. 推导

**引理 19（关节外力的可辨识性）** 令 e_τ = Jᵀ f_ext + b(q,q̇) + η，η 为零均值、方差 σ_η² 的力矩噪声。若在滑窗 𝒲 内堆叠的雅可比 J_𝒲 对外力方向满列秩，且摩擦/回差基 b 与 Jᵀ 不共线，则 f_ext 可辨识，Fisher 信息 I(f_ext) = σ_η⁻² Σ_{t∈𝒲} J_tᵀ J_t，估计协方差下界为 σ_η²(Σ J_tᵀJ_t)⁻¹。反之，若机器人**静止保持刚性位姿**（q̇≈0、位姿不变），则 J_𝒲 在外力方向秩亏，且摩擦/回差与外力在 e_τ 中不可分——**静止是最不具信息量的姿态**。系：**想知道身体承受什么，必须让它动一动**；这正是关节探询（定义 321）为何必要，也是 R69 纯视觉/末端触觉的结构性盲区。

**引理 20（权限约束下的探询信息-能耗前沿）** 在权限裕度 α、力矩上限 τ_max 与能耗预算 E_p 下，任一关节探询的 Fisher 信息满足 tr I(θ_ext; p) ≤ c·α²τ_max² E_p / σ_η²（c 为与探询频谱相关的常数）。系：**U_eff 越大（α 越小），可获得的接触/负载信息越少**；当 α < ε_a 时信息上界趋零，此时再探询只是徒劳地耗尽热/力裕度。故 JPP 必须与 AG 联合规划：先保权限，再谈信息。

**引理 21（耦合信道容量与柔顺性对偶）** 两机器人经刚度 K_c 的物体耦合，同伴参数 θ（意图/负载份额）经力传递进入我方力矩。设信号功率 ∝ K_c²S，未建模动态与传感噪声功率为 N_0 + βK_c²，则
I(θ; τ_i | τ_j) ≤ ½ log(1 + K_c²S / (N_0 + βK_c²))，
关于 K_c 单调递增后饱和；而拜占庭污染增益 ∂τ_i/∂θ_byz ∝ K_c 无界随 K_c 增长。故存在有限 K_c* 使 β_I·I − β_p·Γ_byz 最大（定义 330）。系：**越刚的耦合越能读清同伴，也越容易被同伴带偏**——多机协同必须把柔顺度当作安全变量，而不是性能旋钮。

**引理 22（拜占庭协商的安全与活性）** 设 n ≥ 3f+1、quorum 规模 Q = 2f+1，任一两条认证消息的 quorum 至少交叠 f+1 台，其中至少一台诚实，故诚实节点不会认证两个冲突的共享模态（**安全**：冲突认证不可能）。在同步或已知有界延迟、诚实节点最终广播的条件下，若存在可行指派且诚实多数持续激励，协商在有限步内产生唯一认证指派（**活性**）。系：**单条消息、单个同伴、单次承诺永远不能定案**；这直接把 R69「问一次」升级为「问到一个可认证的一致」。

**定理 18（协同安全不变集）** 在 A102–A104 下，若 (i) 任何耦合前都通过 CFC 的最坏情况力认证；(ii) AG 硬投影保证 α ≥ 0 且 τ ≤ (1−ε_a)ατ_max；(iii) 协同决策只基于 Certified(μ)；(iv) 无 quorum/不可行时退单机，则对任意 τ，机队不发生关节过载、抓取打滑、摩擦锥越界与相互挤压，安全集 𝒮 以至少 1−α_risk 概率前向不变。即**物理耦合不会把协同的乐观变成身体的损伤**。

**定理 19（严格包含 R69/R68）** 关闭耦合与协同（coord=0）、关闭关节探询（probe=0）后，JPE 只读不写、AUE 在 α 充足时不改变 λ（U_eff=0），AG 不裁剪，CMG/BIC/CFC 不介入，控制回路逐指令等于 R69；再关闭交互（interact=0），等于 R68。且 J_ART ⇒ J_FLUID ⇒ J_CALM。故 R70 是 R69 在「允许认证地动用身体 + 允许认证地物理耦合」方向上的严格泛化，安全侧不做任何让步。

**定理 20（降级无 Zeno、控制连续）** 降级阶梯 L0–L3 的触发谓词带滞回与最小驻留时间，动作集逐层嵌套、安全侧单调；进入 L1/L2 后直接复用 R69/R68 的连续换装不变式。故有限时间内切换次数有限，力矩指令无突变；权限治理器的 clip 与 AG 投影是 Lipschitz 的，不会与 R69 的风险缩放产生振荡。**降级与释放耦合同样是一等公民，不是异常。**

**定理 21（协同信念收缩）** 在诚实多数、有界延迟与持续性关节激励下，JPE 对外部参数的 Fisher 信息随时间线性累积（引理 19），BIC 的共享模态后验在每次认证更新后以收缩系数 <1 收紧，故 U_coord 与 U_eff 的估计误差均以 O(1/√t) 收缩；若激励停止，则误差停在由引理 20 给出的上界，**不会虚假地收敛**。

## 6. 本轮最大风险

## 3. 关键算法伪代码

```python
# IP-264/265/272：本体证据 + 权限治理（快层，只读 + 硬投影）
def proprio_layer(M):
    z_ext, z_int = M.jpe.residual(M.q, M.dq, M.ddq, M.tau_meas, M.last_tau_cmd)
    alpha = min((M.tmax[j]-abs(M.tau_meas[j]))/M.tmax[j] for j in range(len(M.tau_meas)))
    u_eff = max(0.0, norm(M.tau_req)-alpha*norm(M.tmax))/norm(M.tmax) \
            + K_T*(M.temp > M.temp_derate)
    return z_ext, z_int, alpha, u_eff

def govern(tau_des, alpha, tmax, eps_a=0.05):
    cap = max(0.0, (1.0-eps_a)*alpha) * tmax
    return clip(tau_des, -cap, cap)                        # 永不越权限包络

# IP-270：D-最优关节探询
def plan_probe(theta_hat, sigma_eta, energy, alpha):
    best = None
    for p in probe_library():                              # tap/press/wriggle/sweep
        if energy_of(p) > energy or alpha < EPS_A or not safe_envelope(p):
            continue
        score = logdet_regularized(fisher_information(p, theta_hat, sigma_eta))
        if best is None or score > best[1]: best = (p, score)
    return best[0] if best and best[1] > 0 else None       # 无收益不激励

# IP-266/271：耦合建模与最坏情况力认证
def certify_coupling(object_model, robots, theta_sets):
    for theta in sample(theta_sets):
        F = feasible_wrench_set(object_model, theta)        # 摩擦锥 + 力平衡
        sol = solve_force_allocation(F, robots)             # Σ G_i f_i = f_total
        if sol is None: return False
        for i, f in sol.items():
            if norm(inv_jac(robots[i]) @ f) > robots[i].alpha*robots[i].tmax:
                return False
    return True

# IP-268：拜占庭鲁棒协商（无 quorum 不耦合）
def byzantine_consensus(msgs, trust, n, f):
    Q, tally = 2*f+1, {}
    for mu, ev, commit in msgs:
        if trust[mu.robot] >= RHO_MIN and commit.valid():
            tally[mu] = tally.get(mu, 0.0) + trust[mu.robot]
    certified = [mu for mu, s in tally.items() if s >= Q and count(mu) >= Q]
    return certified[0] if len(certified) == 1 else None    # 无唯一共识 → 单机

# IP-269：本地 + 协同联合 VoI
def coordinated_query(modes, o, trust, budget):
    best = None
    for c in query_candidates(modes):
        if not budget.allow(c): continue
        score = (B_L*(H(modes)-expected_entropy(modes,c,o))
                 + B_C*voi_coord(modes,c,o) - cost(c) - comm_cost(c) - byz_cost(c,trust))
        if best is None or score > best[1]: best = (c, score)
    return best[0] if best and best[1] > 0 else None        # 无利可图 → R69

# IP-276：主闭环（快层永远在线，协同/探询异步，R69/R68 为边界）
def ARTICULATE_round(M, obs):
    z_ext, z_int, alpha, U_eff = proprio_layer(M)
    if alpha < EPS_A:
        if M.in_coupling: M.cfc.release()                  # 不带着低权限继续耦合
        return M.ladder.enter("L1")                         # 退单机 R69
    z, o = M.mtm.forward(obs)
    U_ale, U_epi, modes, _ = M.aud.decompose(
        M.fmp.sample(o, M.k_for(M.fmp.mode_head(z))), z, M.fmp.mode_head)
    p = M.jpp.plan_probe(M.theta_ext, M.sigma_eta, M.probe_budget, alpha)
    if p is not None: M.jpe.execute_probe(p, M)
    mu = None
    if M.has_teammates and M.coord_budget.allow():
        c = M.cqc.coordinated_query(modes, o, M.trust, M.comm_budget)
        mu = M.bic.consensus(M.comm.exchange(c, M.commitment(modes)), M.trust, M.n, M.f)
        if mu is not None and M.cfc.certify(mu, M.theta_ext_set):
            M.cfc.engage(mu)
        else:
            mu = None                                  # 无 quorum/不可行 → 单机
    u_coord = M.coord_entropy(modes) if mu is None else M.coord_entropy_after(mu)
    U_floor = U_ale + ((U_epi + u_coord) if mu is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor)) / (1.0 + K_ALPHA*U_eff)
    tau = M.ag.govern(M.pi_sigma.prefix_dispatch(M.select_mode(modes, mu).a)*lam,
                      alpha, M.tmax)
    M.vqa_m.submit_async(p, mu, alpha, U_eff, U_floor)
    return tau, lam, mu, (U_eff, u_coord)
```

## 4. 推导

**引理 19（关节外力可辨识性）** e_τ=Jᵀf_ext+b+η；滑窗内 J_𝒲 在 f_ext 方向满列秩且 b 不与 Jᵀ 共线时，f_ext 可辨识，I(f_ext)=σ_η⁻²ΣJ_tᵀJ_t；静止刚性保持时秩亏，摩擦/回差与外力不可分。系：**想知道身体承受什么，必须让它动一动**（关节探询的必要性）。

**引理 20（权限约束下的探询前沿）** tr I(θ_ext;p) ≤ c·α²τ_max²E_p/σ_η²。系：**U_eff 越大，可获得的接触/负载信息越少**；α<ε_a 时信息上界趋零，再探询只是耗尽热/力裕度。

**引理 21（耦合信道容量与柔顺性对偶）** I(θ;τ_i|τ_j) ≤ ½log(1+K_c²S/(N_0+βK_c²))，关于 K_c 先升后饱和；拜占庭污染增益 ∝ K_c 无界增长。故存在有限 K_c*（定义 330）：**越刚越能读清同伴，也越容易被同伴带偏**。

**引理 22（拜占庭协商安全与活性）** n≥3f+1、Q=2f+1 下，两认证 quorum 至少交叠 f+1（含至少一台诚实），故不会认证冲突模态（安全）；诚实多数 + 有界延迟下有限步收敛（活性）。系：单条消息/单个同伴/单次承诺永不能定案。

**定理 18（协同安全不变集）** CFC 最坏情况认证 + AG 硬投影 α≥0 + 只基于 Certified(μ) + 无 quorum/不可行退单机 ⇒ 无关节过载、无打滑、无摩擦锥越界、无相互挤压，安全集以 ≥1−α_risk 前向不变。

**定理 19（严格包含）** coord=0、probe=0 时 JPE 只读、AUE 的 U_eff=0、AG 不裁剪、CMG/BIC/CFC 不介入 ⇒ 逐指令等于 R69；再 interact=0 ⇒ R68。故 R68 ⊂ R69 ⊂ R70，J_ART ⇒ J_FLUID ⇒ J_CALM。

**定理 20（降级无 Zeno）** 滞回 + 最小驻留 + 嵌套动作集 + Lipschitz 的 clip/AG ⇒ 切换次数有限、力矩无突变；释放耦合与降级是一等公民。

**定理 21（协同信念收缩）** 诚实多数 + 有界延迟 + 持续激励下，JPE 的 Fisher 信息线性累积、BIC 后验每次认证后以 <1 的收缩系数收紧，U_coord/U_eff 误差 O(1/√t) 收缩；激励停止则停在引理 20 上界，**不会虚假收敛**。

## 7. 本轮最大风险

**一句话**：ARTICULATE-RAS 的全部收益押在「本体模型可信 + 同伴诚实多数」这两个前提上——**若关节摩擦/回差模型缓慢漂移，或一个拜占庭同伴通过机械教学把虚假的负载与意图写进我的关节证据，系统会以「我的身体亲自感受到了」的确定性，自信地共享负载、压缩安全裕度，并把错误通过力传播给整队；被物理耦合的谎言，比单机的不确定更危险，因为它同时污染了身体与信任。**

**次级风险与缓解**：刚性耦合放大谎言（力-信息对偶 + CFC 最坏情况认证 + 受限 K_c）；探询耗尽权限/热裕度（AG 硬门控 + 引理 20 + 探询预算）；本体模型漂移被误当真实接触（e_τ 分解 + 与 R68/R69 交叉验证 + 只读）；协商被投毒/无 quorum（n≥3f+1 + 2f+1 quorum + TDM + 单机回退）；慢层压垮实时（1kHz 快环不含协同结论 + 异步 + E316）；降级抖动（滞回 + 最小驻留 + 定理 20 无 Zeno）。
