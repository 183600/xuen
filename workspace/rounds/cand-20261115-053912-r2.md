# 第 4 轮（灵感循环第 4 轮；本轮灵感：「阻抗控制」×「商业模式」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 1/2 轮 MODGAUGE / LeanGauge / ToolGauge 骨架继续原样继承。
> 本轮纪律：**阻抗只调节「证据的权限」，商业模式只给「权限定价」；二者都不得改写能力闭包与安全盾。** 任一环节不可用必须一键退回：审计/账本不可用 ⇒ 退回 RepairCert′；经济层不可用 ⇒ α 回退固定值 ⇒ 阻抗回退刚体（`K_bar→∞`）⇒ InstructGauge 的 CVC ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。caution: 这不是「给计量系统贴一个商业模块」，而是让合同参数与控制器参数互为约束。

## 0. 直觉与动机

**灵感 1（阻抗控制 → 不是「更软的 PD」，而是把硬约束换成可证明无源的本构关系）**
直觉：第 3 轮的修复循环是「按计划走，一旦残差/漂移超阈就截断或急停」（CVC）——这等价于一道**无限硬的墙**：轨迹不许偏离。阻抗控制反过来，不直接命令位置或力，而命令二者之间的**关系** `Mδ̈ + Bδ̇ + Kδ = w`：环境（这里是证据）施加多大的广义力 `w`，系统就产生多大的合规位移 `δ`，而 `(M,B,K)` 显式刻画「多愿意让步」。我认为有三点值得偷过来：
(i) **让步要花能量**，把它记进**能量罐**，就得到「证据只能花预算内的权限」这一可证明界；
(ii) **过阻尼 + 无源** ⇒ 不自激振荡，坏证据最多把轨迹推歪，不能把系统推爆；
(iii) 在边界上把刚度推到无穷（`K_bar→∞`）时，阻抗律**严格退化为 CVC 的硬截断**——所以这不是替换第 3 轮，而是把它的离散开关连续化，并补上它缺的稳定性证明。

**灵感 2（商业模式 → 覆盖率不是超参数，而是被定价的风险）**
直觉：系统真正卖的不是「探测动作」，而是「一次带覆盖率承诺 `1−α` 的修复」。那么 `α` 不该由工程师拍脑袋固定，而应由**风险价格**决定：覆盖率每提高一点，探测/验证成本按 `log(1/α)` 上升，残余责任 `αL` 线性下降。最小化 `C_exec(α) + αL` 立刻给出 `α* ≈ c_probe/L`——**责任越大、探测越便宜，就该承诺越高覆盖率**。这把第 3 轮的共形阈值从「统计超参」变成「经济变量」，也解释了为什么不同客户/场景必须用不同 α。若成本律是 `n(α)∝1/α`，则 `α*∝√(c_probe/L)`——两种成本律给出可区分、可证伪的指数，正好让实验去裁决。

**灵感 3（两者相乘 → 合同就是阻抗，阻抗就是合同）**
直觉：阻抗控制是机器人与环境之间的**本构契约**（用「偏离时如何响应」替代设定值，对未建模环境鲁棒）；商业模式是价值与风险之间的**本构契约**（用「失败时如何赔付」替代精确交付承诺，对未建模故障鲁棒）。二者结构同构：都用一组参数刻画响应曲线，都把硬承诺换成可审计的关系。于是本轮的接合点不是比喻，而是：**合同参数 `(α,L,P)` 直接决定阻抗参数 `(K,B,E_tank)`，而阻抗的无源裕度反过来成为合同可兑现性的物理证据。** 英文里 compliance 同时是「柔顺」与「合规」，这个词的双关恰好就是本轮的技术内容。

**灵感 4（相乘后的新危险 → 可购买的合规 ≠ 可证明的安全）**
直觉：一旦覆盖率能被定价，就有套利：少做验证、重复使用同一套校准集、把相关性风险打包进组合、在不可逆动作上偷偷拉长块长以摊薄成本。必须补两块：**结构可验证性**（校准集承诺-揭示 + 客户 nonce，防挑选）与**统计审计**（抽样复核实测覆盖 + 抵押/罚金）。否则经济优化会系统性地把风险外部化给用户，而账本看上去仍然干净。

## 1. 研究问题（本轮要回答什么）

- **Q1（阻抗与安全）**：把 CVC 的硬截断换成有限刚度阻抗，能否在保持安全不变量的同时降低抖动与急停？「证据权限」能否被能量罐严格预算，并在预算耗尽时无损退回 CVC？
- **Q2（经济与校准）**：覆盖率 `α` 作为经济变量时，最优解是否存在、唯一、且给出正确比较静态（`α*` 随 `L` 降、随 `c_probe` 升）？成本律的指数能否被实验区分？
- **Q3（激励与组合）**：在托管承诺 + 随机审计 + 抵押下，「如实报告覆盖率」是否是占优策略？多合同共享校准数据时的相关性风险，如何在账本上正确计价而不被并集界掩盖？
- **Q4（退化）**：经济层 / 审计层 / 阻抗层任一缺失时，能否严格、逐指令地退回 InstructGauge / ToolGauge？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–463）

**P1 证据权限有预算（Bounded Evidence Authority）**
证据只能通过能量罐授权的合规位移改变计划；越权证据被裁剪而不是被信任。安全不变量由盾与边界屏障保证，合规只决定「多软、多快」地服从证据。关键安全陈述：**攻击证据通道最多耗尽合规预算；预算耗尽后系统退回刚性计划 + CVC，而不是继续被推着走。**

**P2 合同参数化阻抗（Contract-Parameterized Impedance）**
`K_c`（内部柔顺）与 `K_bar`（边界屏障）随责任 `L`、覆盖率 `1−α`、不可逆度单调递增；歧义指令使系统更硬（更保守）。经济选择不得突破 `K_min`（安全下界）与 `δ_max`（物理包线）。直观：**高责任场景里，柔顺是奢侈品；它必须由低责任或高预算来买单。**

**P3 覆盖率是价格，不是常数（Coverage as Price）**
`α* = argmin C_exec(α) + αL`，并把账本逐笔记录「声称覆盖 vs 实测覆盖」。组合覆盖不许直接用单合同 α 相加，必须走并集界或相关性校正，并标注校准血缘，防止同一份校准数据被重复当作独立证据。

**P4 可验证优于可声称（Verifiable over Claimable）**
校准集用「承诺-揭示 + 客户 nonce」固定，防提供方挑选有利样本；审计抽样 + 抵押使虚报的期望收益 ≤ 0；无法绑定回执的覆盖率主张一律剥离（沿用第 3 轮定义 441）。

## 3. 与基线的接口（如何退化）

- 审计 / 账本不可用 ⇒ 只保留 RepairCert′（第 3 轮定义 447），经济结论降级为内部估计；
- 经济层不可用 ⇒ `α = α_ref`（固定）⇒ 阻抗退化为 CVC 的刚体极限；
- 能量罐失效 / 可采纳集非凸 / 饱和 ⇒ 禁用合规位移，`K_bar→∞` ⇒ CVC 硬截断；
- 跨不可逆屏障 ⇒ 强制 `K_bar = K_hard` 且 `K = 1`（与第 3 轮定义 445 一致）；
- 指令不可接地 / 分层校准样本不足 ⇒ 沿用第 3 轮退化路径；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「证据权限」的无源阻抗口径：把 CVC 的开关式急停连续化，并证明无自激、坏证据的权限有界、预算耗尽即退回 CVC；
2. 一个把共形覆盖率内生于经济目标的校准方案：`α*` 由 `(c_probe, L)` 决定，且两种成本律给出可区分的指数预测；
3. 一个「托管承诺 + 随机审计 + 抵押」的激励相容证书机制，量化虚报检测概率、罚金下界与组合覆盖的并集/相关性界；
4. 一条严格退化路径与 E457–E474 的可证伪实验矩阵，其中 E458（硬极限逐动作 diff = 0）与 E465（罚金过低应出现可测套利）是主动的「自杀式」检验。

## 5. 本轮最大风险

**一句话**：当「合规」可以被购买，最强的失败模式不是控制器不稳定，而是审计不足时经济优化把未覆盖的风险悄悄转嫁给用户——系统稳定、账本干净，而承诺是空的。

## 2. 形式化定义（要点）

**定义 448（修复契约 Ω）** `Ω = (α, L, P, B_exec, T, ρ_rev, D_bond) ∈ 𝒪`。`α ∈ (0,1)` 为**声称**误覆盖率（承诺覆盖 `1−α`）；`L ≥ 0` 为责任上限（单次失败最大赔付）；`P ≥ 0` 为保费/计算预算；`B_exec` 为执行预算；`T` 为承诺时域；`ρ_rev: T₀ → [0,1]` 为工具可逆度（1=完全可逆，0=不可逆）；`D_bond` 为抵押。可行集 `𝒪_feas` 还须满足后文的安全与无源约束。

**定义 449（证据偏差与证据力）** 在块 `C` 的第 `t` 步，计划参考量 `y_t^ref`，观测 `ŷ_t`。证据偏差 `e_t = ŷ_t − y_t^ref`；证据力
`w_t = −∇_y log p(ŷ_t | y) |_{y=y_t^ref}`，
并在契约尺度下裁剪 `w_t ← clip(w_t, [−w_max(Ω), +w_max(Ω)])`。`w_t` 是「证据想把计划推多远」的广义力，其幅度可由对抗输入放大——这正是能量罐要限制的量。

**定义 450（契约阻抗 Z 与二元合规）** `Z(Ω) = (M_c, B_c, K_c, K_bar)`，取 `B_c = 2ζ√(M_c K_c)`，要求 `ζ ≥ 1`（过阻尼，杜绝振荡）。内部柔顺律
`M_c δ̈_t + B_c δ̇_t + K_c δ_t = w_t`，
执行动作 `a_t = a_t^plan ⊕ δ_t`。可采纳位移集 `Δ_adm = {δ : ‖δ‖ ≤ δ_c}`（`δ_c` 即第 3 轮 CVC 的漂移容差）。边界屏障：若 `δ` 企图越出 `Δ_adm`，施加恢复力 `K_bar·(δ − Proj_{Δ_adm} δ)`；当 `K_bar ≥ K_hard` 时视为刚性屏障，产生 **barrier event**，按 CVC 语义截断到 `t−1` 并出证。**硬极限**：`K_c→∞, K_bar→∞` ⇒ `δ_t ≡ 0` 且越界即截断，逐动作等价于第 3 轮 CVC。

**定义 451（能量罐与证据权限）** 存储函数 `S_t = ½ δ̇_t^T M_c δ̇_t + ½ δ_t^T K_c δ_t`。单步权限支出 `a_t = max(0, Δ·δ̇_t^T w_t)`（沿证据力输入方向的功）；能量罐
`E_{t+1} = min(E_max, E_t − a_t + r·Δ)`，
准入条件 `E_t ≥ a_t`。屏障恢复力**不计入**能量罐（它属于安全层，不属于探索权限）。当 `E_t < a_t` ⇒ 冻结柔顺（`δ̇←0`）并回退刚体计划 + CVC。**作用域声明**：本定义只约束「证据→修正」子系统；物理接触稳定性仍由第 1 轮 MODGAUGE 不变量负责，二者不混用。

**定义 452（契约阻抗单调性公理）** 调度 `Z(·)` 满足：(i) `K_c` 对 `L`、`(1−α)`、`(1−ρ_rev)`、歧义度 `Û(ι|ℓ)` 单调不减；(ii) `K_bar` 对 `L`、`(1−α)`、`(1−ρ_rev)` 单调不减，且 `ρ_rev=0 ⇒ K_bar ≥ K_hard`；(iii) `E_tank` 对 `P` 单调不减、对 `L` 单调不增；(iv) `ζ ≥ 1`；(v) `K_c ≥ K_min > 0`、`K_bar ≥ K_safe > 0`。直观：责任越大、越不可逆、指令越含糊，系统越硬、权限越小。

**定义 453（阻抗调度函数）** 令 `L_ref, α_ref` 为参考契约，
`K_c = clip(K_min + ΔK[β_L·L/L_ref + β_α·(1−α)/(1−α_ref) + β_r·(1−ρ_rev) + β_u·Û(ι|ℓ)], K_min, K_max)`，
`K_bar = max(K_safe, K_safe + ΔK_bar[β'_L·L/L_ref + β'_α·(1−α)/(1−α_ref) + β'_r·(1−ρ_rev)])`，
`E_tank = clip(e₀ + η_P·P − η_L·L, E_min, E_max)`。所有系数为正，故定义 452 自动成立。

**定义 454（契约感知块长）** 块 `C=(a_{1:K})` 的预测位移上界 `ē = max_i ‖e_i^pred‖`。能量需求 `E_need(C) ≈ ½ K_c Σ_{i=1}^K ‖e_i^pred‖² ≤ ½ K_c K ē²`。准入
`K ≤ K_contract(Ω,ι) = min( K_MAX(ι), ⌊2E_tank/(K_c ē²)⌋, K_budget(B_exec) )`。
`K_MAX(ι)` 是第 3 轮的语义-时间上界，`E_tank` 界是新的**经济-能量上界**。当 `E_tank→∞`、`B_exec` 充足时退化为第 3 轮。

**定义 455（经济共形校准 EconCal）** `C_exec(α) = c_probe·n(α) + c_verify + c_audit`。两种**已声明**的成本律：
(L1) `n(α) = n₀ log(1/α)`；(L2) `n(α) = n₀/α`。
经济最优误覆盖
`α* = argmin_{α∈[α_min,α_max]} C_exec(α) + α·L`。
(L1) 给出 `α* = clip(c_probe·n₀/L, α_min, α_max)`；(L2) 给出 `α* = clip(√(c_probe·n₀/L), α_min, α_max)`。两种指数可被 E462 区分。分层共形（第 3 轮定义 438）在此只是「α 固定」的特例。

**定义 456（保证账本 GLedger）** `Λ = {λ_j}` 为 append-only 记录，`λ_j = (contract_id, Ω_j, α_claim, VCert_j, ChunkCert_j, realized_coverage_j, audit_status_j, lineage_j)`。`lineage_j` 记录该合同用到的校准数据集合的哈希；若两合同共享校准数据，则 `n_eff = n/(1+overlap)` 折减。账本不可原地改写；任何赔付/结算必须引用一条已验证前缀与一条 `VCert`。

**定义 457（可验证证书 VCert）** `VCert = (Com(calib_pool), Com(protocol), nonce, α_claim, sig)`，其中 `nonce ∼ customer`，`calib_set = Sample(calib_pool, nonce)`、`α_claim = Quantile(calib_set, 1−α)`。审计时揭示 `calib_set` 与 `protocol`，任何第三方可复核：(a) 承诺匹配；(b) `α_claim` 是承诺协议在该 nonce 下的确定性输出。**这消灭了「挑选有利校准集」这一整类虚报**（结构性检测概率 = 1），剩下的只是部署期分布漂移。

**定义 458（审计-抵押机制 Audit）** `A = (p_a, n_a, D_bond, π_pen)`。部署期随机抽取 `n_a` 次结果，检验 `H₀: α_true ≤ α_claim`；若违规数超过 `BinomQuantile(1−β_test; n_a, α_claim)` 则判虚报，没收 `D_bond` 并处罚 `π_pen`。当真实 `α_true ≥ α_claim + Δ` 时检测功效 `1−β'(n_a,Δ) → 1`（`n_a→∞`）。

**定义 459（激励相容 IC 与个体理性 IR）** 报告策略 `σ` 为 IC，若对所有 `α' ≠ α_true`，
`E[Π(σ=α_true)] ≥ E[Π(σ=α')]`；
且 IR：`E[Π] ≥ 0`。在托管承诺下，`α_claim` 被协议锁死；IC 的剩余约束是「不隐瞒部署期漂移」，其充分条件为 `p_a·(D_bond + π_pen) ≥ ΔP_gain`（`ΔP_gain` 为虚高覆盖带来的额外保费）。

**定义 460（经济效用与可行契约）** 提供方 `Π(Ω) = P − C_exec(α_true) − α_true·L − c_audit`；客户 `S_net(Ω) = V₀ − α_true·L − P`；社会福利 `U_soc = Π + S_net = V₀ − C_exec − α_true L − c_audit`。可行契约 `Ω ∈ 𝒪_feas` 要求 `Π ≥ 0`、`S_net ≥ 0`、无源与安全约束成立。注意 `U_soc` 与 `P` 无关——**保费只是风险在双方之间的转移，不创造价值**；这防止把「涨价」误当成「改进」。

**定义 461（经济化信息价值 VoI）** `VoI_econ(C) = (α_before − α_after(C))·L − cost(C)`。停止准则：`max_C VoI_econ(C) ≤ 0`。当 `L` 均匀、`cost` 线性时，该停止准则与第 3 轮引理 53 的 `K*` 一致（引理 65）。

**定义 462（契约漂移检测）** 窗口 `w` 内实测覆盖 `ĉ = 1 − α̂`；漂移 `Δ_c = |α̂ − α_claim|`。若 `Δ_c > η_s` 连续 `q` 个窗口 ⇒ 冻结对应账本条目、触发重新校准或赔付；与第 3 轮定义 446 的 P-Quarantine 共用断路器。

**定义 463（端到端合规证书）** `ComplianceCert = (Ω, Z(Ω), C, ChunkCert, VCert, ledger_entry, μ_pass, audit_status)`，`μ_pass` 为无源裕度。人类审计可沿「合同→阻抗→块→回执→覆盖→结算」六级证据链复现。

```python
# IP-328 CIC：契约阻抗控制器（离散导纳 + 能量罐 + 硬极限回退）
class ContractImpedanceController:
    def __init__(self, omega):
        self.Z    = impedance_schedule(omega)        # 定义 452/453
        self.tank = EnergyTank(omega.P, self.Z)      # 定义 451
        self.d, self.v = zeros(m), zeros(m)

    def step(self, w, delta_adm):
        w = clip(w, -W_MAX, +W_MAX)                  # 证据力裁剪
        acc = (w - self.Z.B * self.v - self.Z.K_c * self.d) / self.Z.M
        d2  = self.d + DT * self.v + 0.5 * DT * DT * acc
        v2  = self.v + DT * acc
        if norm(d2) > self.Z.delta_c + SAFETY_MARGIN:
            return self.barrier_event()              # 边界屏障 → 截断
        spend = max(0.0, DT * dot(v2, w))            # 权限支出（定义 451）
        if not self.tank.spend(spend):               # 预算耗尽
            self.freeze(); return self.rigid_plan()  # ⇒ 第 3 轮 CVC
        self.d, self.v = d2, v2
        return self.d

    def barrier_event(self):
        self.chunk.abort_at(self.t)                  # verified_prefix = t-1
        return RIGID                               # K_bar→∞ ⇒ CVC 逐动作等价

# IP-329/451：能量罐（passivity-preserving 离散化）
class EnergyTank:
    def __init__(self, P, Z):
        self.E = clip(E0 + ETA_P * P - ETA_L * Z.L, E_MIN, E_MAX)
    def spend(self, a):
        if self.E < a: return False
        self.E = min(E_MAX, self.E - a + R_RECHARGE * DT)
        return True

# IP-331 EconCal：覆盖率由价格内生（两种成本律）
def choose_alpha(omega, calib_pool):
    if COST_LAW == "log":     # n(α)=n0 log(1/α)
        a = C_PROBE * N0 / max(omega.L, EPS)
    else:                     # n(α)=n0/α
        a = sqrt(C_PROBE * N0 / max(omega.L, EPS))
    return clip(conformal_quantile(calib_pool, a, omega.nonce),
                ALPHA_MIN, ALPHA_MAX)

# IP-333/334：托管承诺 + 审计
def audit(entry, omega, outcomes, rng):
    if not verify_commit(entry.vcert.com_calib, entry.vcert.calib_set):
        return FAIL("cherry_pick", bond=omega.D_bond)      # 结构性虚报
    viol = sum(1 for o in outcomes if not o)
    if viol > binom_quantile(1 - BETA_TEST, len(outcomes), omega.alpha_claim):
        return FAIL("drift", bond=omega.D_bond, pen=PI_PEN) # 统计型虚报
    return PASS

# IP-335 ComplianceGauge 8C 闭环
def compliancegauge_8c(M, s, ell, omega):
    alpha = choose_alpha(omega, M.calib_pool) if M.econ else ALPHA_REF   # P
    out   = M.nlib.ground(ell, M.scene, M.ontology)                     # I
    iota  = out[0] if out else M.default_iota                           #   退化
    H     = M.lbox.hypothesize(s, M.dbox.R[s], iota)                    # H
    Z     = M.zsched.schedule(omega.with_alpha(alpha), iota, H)         # 阻抗
    C     = M.iac.plan_chunk(iota, H, M.tools,
                             budget=M.budget_left(s),
                             drift_bound=M.drift_bound(s),
                             k_contract=M.econ.k_contract(Z, omega))    # C
    if not M.tcv.verify(C.as_program(), M.budget_left(s))[0]:
        C = M.numeric_fallback(H)                                       #   退化
    cert, receipts = M.cic.commit(C, M.env, iota, Z, omega)             # E
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    vcert = M.vcert.issue(alpha, M.calib_pool, omega.nonce)             # C/V
    realized = empirical_coverage(receipts, alpha)
    entry = M.ledger.append(omega, vcert, cert, realized)              # U
    M.mreg.hot_replace_at_quiescence(
        M.dpe, M.apcal.update_contract(M.dpe, mu, Sig, s), cert.boundary)
    bind_claims(cert, iota, receipts)                                   # 纯投影
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True

# IP-336 主闭环（50Hz 路径不变）
def ComplianceGauge_round(M, obs, audio, tac, depth, det, ell=None, omega=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(compliancegauge_8c, M, s, ell,
                         omega or M.default_contract)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（证据-修正子系统的无源性）** 令 `S_t = ½δ̇^T M_c δ̇ + ½δ^T K_c δ`，`B_c ≻ 0`。沿内部阻抗律
`Ṡ = δ̇^T(M_c δ̈ + K_c δ) = δ̇^T w − δ̇^T B_c δ̇ ≤ δ̇^T w`。
故对任意时域 `S_T ≤ S_0 + Σ_t Δ·δ̇_t^T w_t`；当 `w≡0` 时 `Ṡ ≤ −δ̇^T B_c δ̇ < 0`（`δ̇≠0`），`δ→0` 渐近稳定，且 `ζ≥1` 时特征根非正实 ⇒ **无自激振荡**。能量罐准入保证 `Σ a_t ≤ E_0 + rT`，因此任何（含对抗）证据能注入修正子系统的总功被 `E_0+rT` 夹住。*作用域*：仅对证据-修正子系统；物理接触稳定性由第 1 轮不变量单独负责。离散实现须用保无源离散化（Tustin/能量法）并加数值阻尼，E457 检验离散无源性。

**引理 60（阻抗-盾一致性与 CVC 硬极限）** 设盾在每步保持不变量 `Inv`，且实际位移满足 `‖δ_t‖ ≤ δ_c + margin`。屏障穿透界 `p ≤ w_max/K_bar`。取 `K_bar ≥ K_safe = w_max/margin`，则 `p ≤ margin`，故 `Inv` 逐步保持。令 `K_bar→∞`，则 `p→0`，屏障事件恰为「所需位移越出 `Δ_adm`」，按定义 450 截断到 `t−1` 并出证，与第 3 轮 CVC **逐动作一致**；再令 `K_c→∞`，内部位移 `δ≡0`，得到完全开环计划 + 边界截断，即第 3 轮 CVC 原样。*推论*：CVC 是 ComplianceGauge 的刚体极限，柔顺是严格增量而非替代。

**引理 61（契约感知块长上界）** 由 `E_need(C) ≤ ½K_c K ē²` 与准入 `E_need ≤ E_tank` 得 `K ≤ ⌊2E_tank/(K_c ē²)⌋`；与语义上界 `K_MAX(ι)`、预算上界 `K_budget(B_exec)` 取 min 即定义 454。当 `E_tank→∞` 且 `B_exec` 不受限时上界退化为 `K_MAX(ι)`（第 3 轮）。*证明*：逐步能量核算；屏障不计入罐，故最坏情况由内部柔顺位移主导。

**引理 62（最优覆盖率的存在唯一与比较静态）** 设 `C_exec` 凸、`L>0`。目标 `J(α)=C_exec(α)+αL` 严格凸 ⇒ 唯一 `α*`。(L1) 下 `α*=clip(c_probe n₀/L)`，故 `∂α*/∂L = −c_probe n₀/L² < 0`、`∂α*/∂c_probe = n₀/L > 0`；(L2) 下 `α*=clip(√(c_probe n₀/L))`，同样 `∂α*/∂L<0`、`∂α*/∂c_probe>0`，但弹性为 `−1/2` 而非 `−1`。两者对 `L` 的双对数斜率分别为 `−1` 与 `−0.5`，构成可证伪的模型选择判据（E462）。*证明*：一阶条件 `C_exec'(α)+L=0`；凸性给唯一性；隐函数定理给符号。

**引理 63（审计下的激励相容）** (i) 结构性：在定义 457 的承诺-揭示 + 客户 nonce 下，`α_claim` 是 `(protocol, calib_pool, nonce)` 的确定性函数，任何偏离被第三方以概率 1 检出，故挑选样本型虚报的期望收益 ≤ 0。(ii) 统计性：若提供方隐瞒部署期漂移致 `α_true ≥ α_claim+Δ`，审计功效 `1−β'(n_a,Δ)` 随 `n_a` 与 `Δ` 单调增；当 `p_a(D_bond+π_pen) ≥ ΔP_gain` 时，如实报告最大化 `E[Π]`，即 IC；当 `Π≥0 且 S_net≥0` 时 IR 成立。*证明*：比较如实与虚报的期望利润；虚报期望增益 = `(1−p_a·功效)·ΔP_gain − p_a·功效·(D_bond+π_pen)`，令其 ≤0 即得条件。

**引理 64（组合覆盖与校准血缘）** 对 `m` 个合同，`P(∨_j fail_j) ≤ Σ_j α_j`（并集界）。若承诺组合覆盖 `1−α_port`，则须 `Σ_j α_j^{eff} ≤ α_port`（Bonferroni）；若合同共享校准数据，`lineage` 重叠使独立证据量降为 `n_eff = n/(1+overlap)`，对应 `α_j^{eff} ≈ α_j·(1+overlap)`。*推论*：对同一份校准集复用 `m` 次并分别宣称独立覆盖，会在账本上制造 `~m` 倍的覆盖率高估——必须按血缘去重，否则「卖得越多、看起来越安全」。*证明*：容斥/并集界 + 有效样本量单调性。

**引理 65（VoI 最优停止与第 3 轮 K\* 的一致性）** 若 `VoI_econ` 关于探测步数单调不增且每步成本 `>0`，则首次 `VoI_econ ≤ 0` 即停是最优停止（贪心）。当 `L` 为常数、`cost` 线性、`α_after` 随信息增益按同一指数衰减时，该停止点与第 3 轮引理 53 的 `K*` 一致。*证明*：单调性 ⇒ 前缀最优；代入引理 53 的增益函数即得。

**引理 66（契约漂移检测的延迟与误报）** 窗口 `w`、连续 `q` 个窗口超阈 `η_s` 才触发，则检测延迟 `≤ w+q` 个窗口；单窗口误报率 `≤ exp(−2wη_s²)`（Hoeffding），连续 `q` 次误报 `≤ exp(−2wqη_s²)`。故可在给定误报预算下选择 `(w,q,η_s)`。*证明*：Hoeffding 不等式 + 并集界。

**引理 67（严格退化链）** 取 `L=0`、`P` 充分大使 `α=α_ref`、`E_tank=∞`、`B_exec` 不受限、审计/托管关闭，则 ComplianceGauge 的定价、阻抗、块长、证书分别退化为 `α_ref`、CVC 刚体极限、`K_MAX(ι)`、`RepairCert′`，即第 3 轮 InstructGauge；再令 InstructGauge 的 NLI/IAC 失效即第 2 轮 ToolGauge，依此类推至 MODGAUGE。逐指令等价性由引理 60、61 与第 3 轮引理 57 复合得到；`claims` 与 `ledger` 条目均为纯投影，不改变数值路径。

## 8. 失败模式与诚实边界

1. **可购买合规的错觉**：经济层能优化「声称的覆盖」，不能创造「真实的保证」；若审计样本与部署分布不同（同一台设备的磨损漂移、同一批物料的系统性偏差），统计审计会失效。诚实边界：审计只能验证「与审计分布同源」的覆盖。
2. **相关性打包**：组合覆盖的并集界在强相关下极松；若把同一校准血缘卖给多个客户，账本会系统性高估安全。故血缘去重是硬约束，不是优化项。
3. **阻抗参数不可辨识**：真实环境刚度 `K_env` 未知时，同样的 `K_c` 在不同工件上表现不同；`Z-Sched` 只能保证单调方向，不能保证标定准确。靠 E473 的迁移退化界兜底。
4. **经济目标压过安全**：若允许 `K_c < K_min` 或 `K_bar < K_safe` 以换取利润，则所有安全证明失效。故 `K_min, K_safe` 是**合同不可谈判项**，写进 `𝒪_feas`。

## 9. 本轮最大风险

**一句话**：真正的风险不是阻抗律不稳定（无源性与硬极限都有证明），而是**审计与血缘去重不到位时，经济优化会把「可购买的合规」伪装成「可证明的安全」**——账本干净、控制器稳定，但被卖出的覆盖率在部署分布上并不成立。
