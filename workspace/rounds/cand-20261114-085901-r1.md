> R69 给闭环装上了「眼」和「嘴」：看不清就凑近看、拿不准就问、摸不透就用**力探针**触一下；并把不确定性拆成 aleatoric 与 epistemic，用 VoI 决定值不值得求证。但 R69 有一个从未写进定义的默认前提——**被控制的那具身体是给定的、不变的、参数已知的**。所有关于「模态、交互、认证、风险缩放」的推理，都建立在一个抽象的 `M` 上；而 `M` 的本体（执行器、减速器、力传感器、夹爪、固件、标定）在真实世界里恰恰是最容易换、最容易修、最容易分叉、也最容易被廉价替代的部分。
>
> 当机器人由**开源硬件**拼成，身体就不是一台机器，而是一个**可替换、可维修、可 fork、逐台不同的模块联邦**：同型号不同批次、非原厂维修件、社区魔改固件、磨损到超出铭牌的减速器。清单（BOM/固件哈希/标定）能证明「设计是什么」，却证明不了「此刻这台机器是什么」——存在一条**来源—物理鸿沟**。

## 0. 直觉与动机

**灵感 1（开源硬件 → 身体是联邦，不是给定物）**
直觉：R69 把 `M` 当成常量，于是「换件」「维修」「升级」在系统里是隐形的——它们不改变任何定义，却改变了被控对象本身。开源硬件把这种隐形变成常态：模块可插拔、可 3D 打印、可用第三方替代、可刷社区固件。于是控制器面对的不是「一个已知系统 + 噪声」，而是「一族可能系统 + 一个只证明了设计而非实例的清单」。关键不是「硬件不可信」这种泛泛之谈，而是一个精确的结构：**清单是符号证据，身体是物理证据，二者之间存在鸿沟，且鸿沟必须逐台、运行时、用物理手段跨越。** 这也给了一个正面的工程姿态：模块化意味着身体可以被表示成一张**因子图**——换一个夹爪只需失效与夹爪相邻的局部因子，其余参数（大臂惯量、基座标定）不必从头再学。

**灵感 2（力控 → 力既是危险，也是唯一的逐台探针）**
直觉：视觉可以看错，语言可以撒谎，但接触力是身体与世界的直接交换——你推多硬，世界就回你多硬。R69 已经把 `g_probe` 当作信息动作，但它只把力探针用来问**世界**（这物体软不软）；本轮把它反过来问**自己**（我的手软不软、我的力矩常数漂没漂、我换上的这根手指量程够不够）。更妙也更危险的是：**要识别身体，必须激励身体；而激励本身就是这一集里最大的一次力事件。** 所以力控必须同时承担两个互相拉扯的角色：它是辨识的信使，也是安全的人质。

**灵感 3（第三类不确定性 → R68/R69 的二分不完整）**
直觉：R68 的 aleatoric 是「噪声不可约」，R69 的 epistemic 是「世界有歧义可问」。但还有一类既不是噪声、也不是世界歧义的东西：**我连模型类别/身体身份都不确定**。把「软手指」误判成「软物体」，不是把某个参数估偏，而是把「是谁在软」这个结构搞错了；这种错误不会被更多同类数据平均掉，反而会被自适应控制器「学到」并放大。因此 U_emb 必须单独成通道：连续参数（质量/摩擦/刚度）、离散结构（换的是哪个型号、接口拓扑）、身份来源（清单是否真实）三者语义不同，更新方式与安全后果也不同。

**灵感 4（可辨识性 → 同一个力，是软世界还是软手指？）**
直觉：接触力是身体参数与世界参数的**乘积式耦合**。最简单的一维接触里，手指刚度 k_b 与物体刚度 k_w 只以串联 `k_eff = (1/k_b + 1/k_w)^{-1}` 出现——单次接触根本分不开「软手指推硬物」与「硬手指推软物」。这就是本轮最锋利的技术命题：**辨识身体的前提，是先把身体从世界里解耦出来**。可用的锚点只有三类：自由空间激励（不接触，世界参数不参与，直接识别惯量/摩擦/力矩常数）、已知标定件（世界参数已知，反解身体）、以及多接触/多姿态多样性（打破对称）。若三者都不可用且 Fisher 信息矩阵病态，正确做法不是「估一个」，而是**拒绝更新**——不知道就不要假装知道。

**灵感 5（物理作为信任根 → 清单可伪造，物理不会替你撒谎）**
直觉：开源生态的攻击面也被开源了：翻新件冒充新品、清单漏报失效模式、恶意固件谎报力传感器、fork 改变符号约定。签名只能证明「这是某个设计」，不能证明「这是那台机器」。但物理有惯性：一个标称 20 N·m 的关节若实际只有 8 N·m，你在安全激励下测出的响应会露馅；一个量程被改小的力传感器，在大载荷区会出现与模型系统性偏离。**校准层可以吸收传感器偏置（仿射、低维），却吸收不了结构性的动力学改变（高维、非线性）。** 这正是 R69 「标定不可吸收的第二意见」在具身侧的镜像：R69 用动作似然对抗传感器残差被吸收，本轮用接触力响应与能量/运动学一致性对抗清单被伪造。

**灵感 6（安全与性能必须分离 → 安全不能依赖自模型）**
直觉：如果力限依赖 `θ̂_body`，那么辨识错一次就可能直接越界——这是不可接受的。正确架构是**安全与性能分层**：L0 物理硬限（机械离合器、电流/力矩限、保险丝）不可被软件欺骗；L1 基于**实测力**的无源/阻抗环，不依赖模型；L2 基于辨识模型的鲁棒控制屏障函数，只用来自模型增益的**权限**；L3 来源与审计。无论 `θ̂` 多离谱、清单多假，L0/L1 保证接触力/能量不越硬界；辨识只决定「敢用多高的性能增益」。这把 U_emb 从「安全威胁」降级为「性能税」。

def robust_envelope(Theta):

## 3. 推导

**引理 19（身体—世界的可辨识性条件）** 设接触模型 F = Φ(θ_b, θ_w, ξ)，在 N 个激励条件下有 Fisher 信息 J。边际化 θ_w 后身体信息阵为 Schur 补 S_b = J_b^T (I − P_w) J_b。则 θ_b 局部可辨识 ⇔ S_b 满秩且 κ(S_b) ≤ κ_max；若 Φ 仅通过某个标量耦合变量（如串联刚度 k_eff）依赖 θ_b、θ_w，则 rank(S_b) < dim θ_b，**单靠未知世界接触不可辨识**。系：自由空间锚点或已知标定件是充分条件；多接触多样性可恢复秩，但成本与磨损随接触数增长。

**引理 20（物理来源的不可吸收性）** 设真实结构相对清单的偏离为 Δθ，其在校准低维仿射子空间上的投影为 P_cal Δθ。若 ‖(I − P_cal)Δθ‖ ≥ δ_⊥ 且激励对 Δθ 的灵敏度下界为 L_⊥，则期望力残差增量 ≥ L_⊥ δ_⊥ − √(trΣ_F)。而传感器标定只能吸收 P_cal 分量，故**结构换件/伪造清单会在 ΔF 或能量/运动学一致性上留下不可被标定吸收的痕迹**。反之，若 ‖(I−P_cal)Δθ‖ 小于噪声除以灵敏度，则该改变在行为上不可区分——可安全地视为「无变化」（行为等价论证）。

**引理 21（安全激励—信息—磨损的三方权衡）** 任何 a_ex ⊆ 𝒮 的激励对 ∀θ ∈ Θ_plausible 满足瞬时物理风险 ≤ ε_int（L0/L1 + 鲁棒 CBF/能量罐保证）。同时，参数估计误差协方差受 Cramér–Rao 下界约束：Cov(θ̂) ⪰ (E_ex · J_unit(θ))^{-1}，其中 E_ex 为激励能量/频率丰富度。故 VoI_body(a) ≤ κ·E_ex，**辨识精度与安全/磨损预算构成 Pareto 前沿**：不可能在有限预算内任意准确地认识身体。

**引理 22（不可辨识防护的「不自信地错」保证）** 若防护铁律（κ > κ_max 或证据 < 2 源 ⇒ 冻结）成立，则身体后验始终被先验 Θ 的半径 ρ_Θ 约束，且控制器权限停留在 conservative 区；结合引理 21 与 FSA 的 Θ 一致性，**即使辨识彻底失败，接触力/力矩/能量仍不越硬界**。故系统可以「一直不够好」，但不会「自信地错到危险」。

**定理 18（FORGE 严格包含 FLUID/R69）** 当身体被认证（τ(h) 高、PPM 残差低、U_emb ≤ ε、三源一致）且既有 R69 认证包络已满足时，激励的净收益 ≤ 0，调度不触发辨识，FSA 包络退化为 R69 的已知身体包络，**FORGE 的输入-输出与证书逐条等同 FLUID-RAS**。故 R69 是 FORGE 在「已知身体」边界上的严格退化；安全侧瞬时风险上界为 max(ε_FLUID, ε_int)，效率侧获得identified-body bonus。

**定理 19（具身不确定性下的力安全）** 若 SafetyCert 对 ∀θ ∈ Θ_plausible 成立且 L0/L1 常开，则对任意估计误差、清单伪造、非兼容 fork，接触力、力矩、功率、能量均不超过硬限；辨识只改变 AuthorityCert 与性能增益，**不改变安全不变式**。证明由最坏情形鲁棒 CBF、能量罐无源性与 L0 物理硬限的串联给出；前提是 Θ_plausible 覆盖真实参数，超出 Θ 的极端未知件由 L0 兜底。

**定理 20（身体漂移不静默）** 在可辨识激励与 PPM 监视下，任何超阈值的结构性/身份改变以概率 ≥ 1 − β 被检测；若未被检测，则其可观测投影必然小于噪声-灵敏度比，即与真实身体在容差内行为等价。因此不存在「长期被当成正常、实则已换了一具身体」的静默漂移——要么被抓住，要么无关紧要。这是 R68 反吸收引理在具身侧的对应物。

## 6. 本轮最大风险

**一句话**：FORGE 的收益押在「力响应能把身体从世界里解耦出来」这一前提上——**若探针在未知物体上把「软世界」误辨识成「软身体」，自适应力控会为了达到同一接触力而自信地加大力矩，恰好越过真实接触力的硬限；而这次探针本身就是整集里最大的一次力事件**——**用最危险的动作去学习如何不危险，是这一层最致命的自我指涉**。

1. **开源清单可伪造/翻新件伪装**（签名只证设计不证实例）→ 三源证据 + PPM 物理反证 + L0 硬限兜底（引理 20、定理 19）；

**定义 317–319（ASM / PPM / FAS）** 信任域 + 双源约束的鲁棒更新；`ΔF=|r_F(o)−r_F(o_cal)|`，`ΔF↑` 且传感器残差低 ⇒ 结构换件可疑；SafetyCert 不依赖 θ̂/h，AuthorityCert 才依赖双源，故辨识失败只降性能。

**定义 320–322（退化阶梯 / HRI 力界 / FCL）** certified→identified→conservative→safe-stop，只升不跳；人机交互让步优先且对 Θ 限力；兼容由机械/电气/时序/语义四层运行时契约测试判定，容量区间必须嵌套。

**定义 323–326（威胁 / 证书 / 预算 / 调度）** `ℰ_FORGE=ℰ_FLUID×ℰ_hw×ℰ_ident`；`J_FORGE` 并入身体模式哈希、来源信任、U_emb 前后、κ、力包络裕度、PPM 残差、磨损；激励消耗寿命 `W≤W_max`；触发式辨识 + 不可辨识防护铁律（κ 越界/证据不足/残差不可解释 ⇒ 冻结）。

## 3. 关键算法伪代码

```python
# IP-264 HIM：逐台清单（符号证据，只入先验）
def verify(ids):
    hs = [manifest[m] for m in ids]
    return HMC(hs, trust=min(tau(h) for h in hs))          # τ 连续

# IP-265/312 EMU + 身体因子图：换件只失效局部因子
def body_posterior(obs, hmc, bfg):
    if hmc.changed: bfg.invalidate_local(hmc.changed)      # 不全量重训
    return emu.infer(obs, hmc, bfg)                        # θ_par, s_struct, id

# IP-266/315 FIC：安全辨识激励（VoI 覆盖磨损与风险成本）
def plan_excitation(theta, anchors, fsa, budget, wear):
    if wear.exhausted(): return None
    best = None
    for a in excitation_candidates(anchors):
        if not fsa.inside_static_envelope(a): continue     # 对 ∀θ∈Θ 安全
        if not bwd.identifiable(a, theta):    continue     # 先确认能分开
        score = voi_body(theta, a) - excitation_cost(a) - wear_penalty(a)
        if best is None or score > best.score: best = (a, score)
    return best if best and best.score > 0 else None       # 无利可图 → 不激励

# IP-267/316 BWD：身体-世界 Schur 补可辨识性
def identifiable(a, theta):
    Jb, Jw = contact_jacobians(a)
    S = Jb.T @ (np.eye(len(Jb)) - proj(Jw)) @ Jb          # 边际化世界
    return matrix_rank(S) == dim_body and cond(S) <= KAPPA_MAX

# IP-268/317 ASM：信任域 + 双源证据约束
def update_self_model(theta0, y_F, hmc, consistency):
    if count_agreeing([hmc, y_F, consistency]) < 2:
        return theta0, frozen=True
    theta = argmin(data_nll(y_F, theta) + prior(theta),
                   s.t. |theta - theta0| <= RHO, ppm_residual(theta) <= TAU_F)
    return theta, frozen=False

# IP-269/314 FSA：安全包络只看 Θ，不看 θ̂
def robust_envelope(Theta):
    return Lambda(F_max(Theta), tau_max(Theta), v_max, E_max)  # 最坏情形

# IP-270/318 PPM：物理反证——校准吸收不了结构改变
def ppm_residual(obs, theta_hat, o_cal):
    rF = force_meas(obs) - force_model(theta_hat, obs)
    dF = abs(residual(o_cal) - rF)                         # R69 Δa 的具身镜像
    c  = energy_consistency(obs) + kinematic_closure(obs)
    return rF, dF, c

# IP-275 主闭环（继承 R69；仅在「身体权限」处插入 FORGE 层）
def FORGE_RAS_round(M, obs):
    hmc = M.him.verify(obs.module_ids)
    theta, Uemb = body_posterior(obs, hmc, M.bfg)
    rF, dF, c = ppm_residual(obs, theta, M.o_cal)
    a_ex = None
    if M.sched.should_identify(hmc, rF, Uemb, M.wear):
        a_ex = plan_excitation(theta, M.bwd.anchors(rF), M.fsa, M.budget, M.wear)
    if a_ex is not None:
        y = M.fic.execute_safe(a_ex)                       # ⊆𝒮，L0/L1 兜底
        theta2, frozen = update_self_model(theta, y, hmc, c)
    else:
        theta2, frozen = theta, True
    env = M.fsa.robust_envelope(M.fsa.Theta)               # 不依赖 θ̂/h
    K = (M.asm.impedance(theta2)
         if M.emu.authority_certified(hmc, rF, c, theta2) and not frozen
         else M.asm.conservative_impedance())              # 辨识只买权限
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(obs, M.k), M.z, M.fmp.mode_head)
    g = M.mint.choose_interaction(modes, obs, M.budget, Uemb)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., env=env)
    mode = select_mode(modes, U_epi, lam)
    tau = M.fsa.project(K, mode.a[:k], env, lam)           # L0/L1 硬投影
    M.vqa_e.submit_async(hmc, a_ex, Uemb, rF, dF, K)
    return k, lam, mode, tau, (U_ale, U_epi, Uemb)
```

## 4. 推导

**引理 19（身体—世界可辨识性）** 接触模型 `F=Φ(θ_b,θ_w,ξ)`，边际化世界后的身体 Fisher 信息为 `S_b=J_b^T(I−P_w)J_b`。`θ_b` 可辨识 ⇔ `S_b` 满秩且 `κ≤κ_max`；若 Φ 仅通过串联刚度 `k_eff` 等标量耦合依赖两者，则 `rank(S_b)<dim θ_b`，无锚点时不可辨识。自由空间、已知标定件、多接触多样性是恢复秩的三类充分条件。

**引理 20（物理来源不可吸收）** 结构偏离 `Δθ` 在标定仿射子空间上的投影为 `P_calΔθ`；若正交分量 `‖(I−P_cal)Δθ‖≥δ_⊥`，则力残差/能量一致性增量 ≥ `L_⊥δ_⊥−√(trΣ_F)`。标定只吸 `P_cal` 分量，故换件/伪造清单留下不可吸收痕迹。反之若正交分量低于噪声-灵敏度比，则该改变行为等价——可安全视为无变化。

**引理 21（安全—信息—磨损权衡）** `a_ex⊆𝒮` 对 ∀θ∈Θ 风险 ≤`ε_int`；估计协方差受 Cramér–Rao 约束 `Cov(θ̂)⪰(E_ex·J_unit)^{-1}`。故 `VoI_body≤κ·E_ex`，辨识精度与安全/磨损预算构成 Pareto 前沿，不存在「免费的认识身体」。

**引理 22（不自信地错）** 不可辨识防护（`κ>κ_max` 或证据<2 ⇒ 冻结）使身体后验被先验半径约束、权限停留保守区；结合 FSA，即使辨识彻底失败，力/力矩/能量仍不越硬界。

**定理 18（FORGE 严格包含 FLUID/R69）** 身体被认证（`τ(h)` 高、`r_F` 低、`U_emb≤ε`、三源一致）时，激励净收益 ≤0、调度不触发，FSA 退化为 R69 已知身体包络，**输入-输出与证书逐条等同 FLUID-RAS**。安全侧瞬时风险上界 `max(ε_FLUID, ε_int)`，效率侧获 identified-body bonus。

**定理 19（具身不确定性下力安全）** SafetyCert 对 ∀θ∈Θ 成立且 L0/L1 常开时，任意估计误差、清单伪造、不兼容 fork 都不使力/力矩/功率/能量越界；辨识只改变 AuthorityCert 与性能，不改变安全不变式。前提是 Θ 覆盖真实参数，超出者由 L0 物理硬限兜底。

**定理 20（身体漂移不静默）** 可辨识激励 + PPM 下，超阈值结构/身份改变以概率 ≥1−β 被检出；未检出者其可观测投影小于噪声-灵敏度比，即行为等价。故不存在长期静默的「换了一具身体」。这是 R68 反吸收引理在具身侧的对应物。

## 7. 本轮最大风险

**一句话**：FORGE 的收益押在「力响应能把身体从世界里解耦」这一前提上——**若探针在未知物体上把「软世界」误辨识成「软身体」，自适应力控会为达到同一接触力而自信加大力矩，恰好越过真实接触力硬限；而这次探针本身就是整集最大的一次力事件**——**用最危险的动作学习如何不危险，是这一层最致命的自我指涉**。

**次级风险与缓解**：清单伪造/翻新件（三源证据 + PPM 物理反证 + L0 硬限）；不可辨识时强行更新（κ/证据冻结 + 拒绝更新）；激励磨损透支寿命（磨损账本 + VoI 覆盖成本）；鲁棒包络过保守（安全/性能分离，仅用 AuthorityCert 花性能预算）；fork/维修语义不兼容（FCL 运行时契约测试，拒绝仅凭版本号继承认证）。
