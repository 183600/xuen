# 第 12 轮（新灵感循环第 1 轮；本轮灵感：「故障诊断」×「姿态估计」）

> **基线**：第 11 轮 MetricVoiceGauge-NCD-H（定义 554–570；引理 96–103；实验 E589–E606；IP-363–366）。
> 本轮纪律：**健康先于安全、姿态是集合不是点、可诊断性即可行性**。不推倒 v11：HAS/HCC/HATD/HDT、MetricVoiceGauge 九不变式、NGE/DSL/CC/CWM/CAE/NCP、AC/MW/ID、DA/SPR/Cal 全部保留；四个新组件以**互不相交端口**接入，任一失效注入中立元，严格退回 v11（引理 93/102 升级版），再沿 v11 十六级链退回 v10/v9/v8/v7/v6。本轮只做三件事：把"故障假设"变成证书条件、把"姿态歧义"变成证书定义域、把"消歧"变成带盾的决策动作。

## 0. 直觉与动机

### 0.1 v11 真正遗漏的两个隐含假设

v11 已经把规范、接触、因果、谐波四类约束接进同一个块级决策闭环，但它的四重证书默认两件事：

1. **传感器与执行器是健康的**。HCC 的 β 余量只吸收零均值噪声与准静态参数漂移，不吸收编码器偏置、电流零漂、力传感器漂移、柔轮磨损/点蚀、关节卡滞。一个缓慢增长的编码器偏置会被 HCC 解释成"刚度变小"，证书仍然有效，而真实接触力可能已经越界。
2. **物体位姿是一个已知的点**。Ĉ_contact 的力闭合、抓取质量、无滑移判据全部建立在单一 ξ 上；而对称物体、遮挡、透明/反光材质会让 6-DoF 姿态估计出现**多峰、对称商、系统性偏置**。把 MAP 点估计喂给证书，等于在一个可能错误的几何上做正确的力学校验。

更危险的是，这两个盲点会**互相伪装**：物体滑移产生的位姿跳变与关节编码器偏置，在末端相对观测上几乎同形；柔轮磨损产生的扭矩残差与抓取点估计偏差产生的力矩残差，在力/电流通道上同向。于是系统会遇到最坏情形——**诊断错误，但证书自洽**。

### 0.2 灵感 1（故障诊断 → 残差是证书的条件变量，不是报警器）

直觉：传统故障诊断是"残差超阈 → 报警/停机"。在 v11 里这不够：证书是**执行前**签发的，故障是**执行中**演化的。把诊断当外挂报警器，会留下"证书已签、执行中途故障、报警后才停"的时序漏洞。核心创新：**故障残差监视器（Fault Residual Monitor, FRM）+ 可诊断合规证书（Diagnosable Compliance Certifier, DCC）**。

关键转身：不把残差 r_t 变成布尔告警，而把它变成**相容故障集 F_t 的约束**。证书不再问"这个技能安全吗"，而问"**对所有与观测相容的故障假设 f∈F_t，这个技能是否都安全；若不能，故障是否已被隔离到足以选对裕度 β(f)**"。固定 β 被废除，改为故障条件裕度 β(f)。由此得到一条新纪律：**不可诊断 ⇒ 不可认证**。若某个能破坏证书的故障与正常模式在当前激励下不可区分，DCC 必须拒绝签发证书，而不是"保守一点继续"——因为保守裕度无法区分"该修传感器"还是"该降接触力"。

### 0.3 灵感 2（姿态估计 → 姿态是带对称商的多峰信念）

直觉：6-DoF 姿态估计的输出不是一个 ξ，而是一个**在 SE(3) 上、对物体对称群 G_sym 取商后的多峰信念** b(ξ)。杯子绕轴转 180° 可能不可区分；被手遮挡的一侧让平移沿视线方向方差爆炸；反光面让网络在几个离散模式间跳变。v11 只用 ξ̂_MAP 计算接触点、法向、抓取矩阵，等价于把多峰信念塌缩成一个可能错误的点。

核心创新：**歧义感知姿态证书（Ambiguity-aware Pose Certifier, APC）**。APC 维护 b(ξ) 的混合表示（每个模式是 SE(3) 上的集中高斯），构造可信集 Ξ_α，并把证书判据改为**对 Ξ_α 内所有姿态取最坏情形**：Ĉ_contact 只有在整个可信集上闭合才有效；若按模式分裂，则只允许在"当前模式可识别"时执行对应模式的条件证书，否则转入消歧。**姿态歧义不是噪声，而是证书的定义域。**

### 0.4 灵感 3（故障诊断 × 姿态估计 → 故障-姿态混淆与主动消歧）

直觉：把前两者直接拼起来，会得到一个更自信也更危险的东西：一个**联合信念 b(f,ξ)**，其中故障与姿态沿某些方向不可辨识（gauge 简并）。例如物体在夹爪中缓慢滑移 δξ 与关节侧编码器慢偏置 δθ 可产生相同的相对位姿序列；柔轮磨损与抓取点偏移可产生相同的力矩偏差。若规划器只做被动估计，它会在简并方向上"平均"，得到一个既不真实也不安全的 (f,ξ)。

核心创新：**联合诊断-姿态规划器（Joint Diagnosis–Pose Planner, JDPP）**。它把"执行 / 探测 / 求助 / 回退"统一到 v11 的盾式规划里：在 v11 证书允许的动作集中选一个**探针** u（小幅转动、换视角、轻触、受控重抓、谐波安全频带内的力脉冲），最大化对 (f,ξ) 的互信息增益，扣除时间/接触/热成本；若信息增益不足以把证书相关故障或姿态模式分离，就 a_ask 或退回 v11 保守路径。**消歧不是感知后处理，而是带证书的决策动作。**

### 0.5 三者如何统一

把决策写成**健康-姿态-合规闭环（Fault–Pose–Compliance Loop, FPCL）**：

```
多源观测 (双编码器/电流/力/触觉/视觉)
   │
   ├─ FRM：parity/observer 残差 → 相容故障集 F_t 与签名分离度
   └─ APC：SE(3)/G_sym 多峰姿态信念 → 可信集 Ξ_α
                │
                ▼
        JDPP：联合信念 b(f,ξ)，识别 gauge 简并
                │  (执行 / 探针 / 求助 / 回退)
                ▼
        DCC：∀f∈F_t, ∀ξ∈Ξ_α 的故障条件 + 姿态最坏情形证书
                │
                ▼
        v11 四重证书 + 盾 + 块守卫（只删、只截断、只回退）
                │
                ▼
        执行后证据 → 贝叶斯更新 b(f,ξ)（残差/触觉/视觉）
```

**故障诊断回答"我现在还能相信哪些模型和传感器"，姿态估计回答"几何到底可能是什么"，规划回答"为了安全，我该先弄清哪一件事"。** 三者共享 v11 的 ζ_h、CWM、HCC 与 HDT，因此不是三个补丁，而是一个**健康—几何—认证**闭环。

### 0.6 为什么不是这些"显然的解法"

- 不是"加一个故障分类器"：分类器只给标签，不给"证书在未知故障下是否仍成立"的量化条件；DCC 要的是**相容集上的最坏情形裕度**。
- 不是"姿态用不确定性加权"：加权平均会把两个对称模式平均到物体内部，得到物理上不存在、证书上却"看起来居中"的姿态；APC 要的是**最坏模式**与**模式条件证书**。
- 不是"多跑几次估计取一致"：被动重复观测无法打破 gauge 简并，必须**主动选择能打破简并的动作**，且动作本身要过 v11 证书。
- 不是"提高检测阈值/加大 β"：这会把漏检换成误诊，且在故障-姿态混淆方向上 β 再大也无法区分"该修传感器"还是"该换抓取点"。

## 1. 研究问题（轮次升级版）

- **Q1（故障可诊断性）**：在接触丰富、强非线性、只有双编码器/电流/力/触觉的灵巧操作中，哪些故障对四重证书是"证书相关"的？其签名在何种激励下可分离？最小可检测故障幅度与激励、噪声的定量关系是什么？
- **Q2（姿态歧义证书）**：如何表示 SE(3) 上多峰、带对称商的姿态信念，并高效计算"可信集上的最坏情形接触/力闭合证书"？模式条件证书与全局证书何时等价、何时必须消歧？
- **Q3（故障-姿态联合可辨识性）**：故障与姿态的 gauge 简并结构是什么？哪些探针动作能以最小证书风险/成本打破简并？主动消歧的近似最优性界是什么？
- **Q4（与 v11 的兼容与退化）**：故障条件裕度 β(f)、姿态最坏情形证书与 v11 的 Ĉ_h/Ĉ_contact 如何合取而不清空可行集？四个新端口失效时是否严格等价 v11？预算是否仍守 p99≤22ms？

## 2. 设计原则（在 P16–P18 基础上新增 P19–P21）

**P19 故障假设显式律（Fault Hypothesis First-Class）**
任何证书不得假设传感器/执行器健康。证书必须以相容故障集 F_t 为条件，使用故障条件裕度 β(f)；固定 β 仅作为 F_t={f_nom} 的中立元特例。证书相关故障与正常模式不可分离时，禁止签发证书。

**P20 姿态歧义保守律（Pose Ambiguity Conservatism）**
证书的定义域是姿态可信集 Ξ_α，而非点估计。全局证书必须对 Ξ_α 取最坏情形；模式条件证书只在模式可识别时有效。禁止把多峰信念加权平均成单点后认证。

**P21 可诊断性即可行性律（Diagnosability as Feasibility）**
技能/段/块可执行的必要条件新增：其证书相关故障与姿态模式在执行激励下**可分离，或已由探针/求助解决**。诊断不是事后告警，而是可行性判定的一部分；无法诊断的"安全"视为不安全。

## 3. 与基线的接口（如何退化）

- JDPP 失效 ⇒ 退回被动联合估计 + v11 规划；仍保留 DCC/APC，**等价 v11 规划路径 + 更强证书**（无主动消歧）；
- APC 失效 ⇒ 姿态退回 ξ̂_MAP 单点，证书退回 v11 Ĉ_contact，**等价 v11 几何路径**；
- DCC 失效 ⇒ 证书退回 v11 固定 β；FRM 降级为只读告警、不参与认证，**等价 v11 证书路径**；
- FRM 失效 ⇒ F_t≡{f_nom}、β(f)≡β_v11，四个新端口同时失活，**严格等价 v11 Level-0**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-H v11，再沿 v11 十六级链退回 v10/v9/v8/v7/v6；
- **安全继承**：健康/几何/物理/接触/谐波/规范证书取合取。FRM 只能扩相容集、DCC 只能删候选、APC 只能缩/分裂可信集、JDPP 只能在已认证集合内选探针；新模块不能绕过任何 v11 适用证书（引理 101/111）。

## 4. 预期贡献

1. **故障条件证书与可诊断性判据**：把故障假设集、签名分离度、故障条件裕度接进证书，覆盖 v11 完全未建模的"健康状态不确定性"；
2. **SE(3) 歧义感知姿态证书**：在对称商上的多峰信念 + 可信集最坏情形认证，给出"证书何时因几何歧义必须弃权/消歧"的可判定条件；
3. **故障-姿态联合消歧规划**：识别 gauge 简并，把探针选择写成带 v11 盾的 VOI 决策，给出近似最优性界；
4. **健康-几何-合规统一闭环**：E607–E624 覆盖故障可诊断性、姿态歧义证书、联合消歧、退化等价、预算与长跑。

## 5. 本轮最大风险

**一句话**：慢变故障（编码器偏置、柔轮磨损、力传感器漂移）与姿态多峰模式在 gauge 简并方向上互相伪装，被动数据无法分离，系统会以一个自洽但错误的 (f,ξ) 签发"最坏情形安全"证书——即**把故障误诊为几何歧义，在最坏情形上算对了错误问题**。

| u_probe | 探针动作（小转动/换视角/轻触/重抓/力脉冲） |
| IG(u), κ(u), VOI(u) | 期望信息增益、探针成本、VOI = IG − κ |

**定义 571（故障假设与相容集 Fault Hypothesis Set）** 故障假设
```
f = (type, mag, onset) ∈ F_lib,   f_nom = 无故障标称假设
```
残差生成器给出 r_t。对每个 f∈F_lib，集员包络 R_t(f) 由故障签名与噪声有界集 V_t 的 Minkowski 和给出：
```
R_t(f) = S_f φ(f) ⊕ V_t,   V_t = {v : ‖W v‖₂ ≤ γ_t}
```
相容故障集
```
F_t = { f ∈ F_lib : r_t ∈ R_t(f) }
```
**可靠性假设 (A-F)**：真实故障 f*∈F_t（包络对外部噪声与建模残差是可靠的）。F_t 是证书唯一允许使用的健康信息；任何"假设全健康"的证书等价于断言 F_t={f_nom}。

**定义 572（故障条件裕度 Fault-Conditioned Margin）** 对证书分量（力、偏置、速率、耗散能量、k_h/d_h 等）定义
```
β(f) = β_nom + L_β·‖φ(f)‖
```
其中 L_β 是该证书分量对故障结构化参数的 Lipschitz 常数（由离线标定/区间分析给出）。故障条件证书写为 Ĉ(π; β(f))。当 f=f_nom 时 Ĉ 逐位退回 v11 的 Ĉ_h/Ĉ_contact。

**定义 573（签名分离度与可诊断性 Signature Separation & Diagnosability）** 在激励 u^{1:H} 下
```
d_sep(f_i, f_j) = ‖W_sep (S_{f_i} − S_{f_j})(φ(f_i) − φ(f_j))‖ / (γ_i + γ_j)
```
称故障对 (f_i,f_j) 在阈值 δ_diag 下可诊断，若 d_sep(f_i,f_j) > δ_diag。称技能序列 π 对其证书相关故障集 F_rel(π) **可诊断**，若
```
∀ f_i ≠ f_j ∈ F_rel(π) ∪ {f_nom}:  d_sep(f_i, f_j) > δ_diag
```
否则称 π 在 F_rel(π) 上存在**不可诊断对**。

**定义 574（可诊断合规证书 Diagnosable Compliance Certificate, DCC）** 给定 π、状态、F_t、姿态可信集 Ξ_α、谐波估计，DCC 证书
```
Ĉ_DCC(π) 有效 ⇔
  (i)   可诊断：F_rel(π)∩F_t 与 {f_nom} 两两可诊断（定义 573）；
  (ii)  ∀f ∈ F_t:  Ĉ_h(π; β(f)) ∧ Ĉ_contact(π; β(f)) ∧ Ĉ_safety(π; β(f)) 有效；
  (iii) ∀ξ ∈ Ξ_α:  Ĉ_contact(π; ξ) 有效（与 APC 合取）；
  (iv)  故障安全中止点 P^f(π) ≠ ∅。
```
其中 P^f 是满足下述不变式 I_f 的配置点集：从该点起存在**在 F_t 中任一故障假设下**都不破坏 I_c、I_h 且能进入安全保持/停机的轨迹。若 F_rel(π)∩F_t 含不可诊断对，DCC **拒绝**签发（返回 ⊥），而不是放宽 β。

**定义 575（姿态混合信念与可信集 Pose Mixture Belief）** 姿态信念是 SE(3) 上对对称群取商的混合
```
b(ξ) = Σ_{m=1}^{M} w_m · (δ_{G_sym} ∗ N_{SE(3)}(μ_m, Σ_m)),   Σ_m w_m = 1
```
其中 N_{SE(3)} 为集中高斯（切空间高斯经指数映射回 SE(3)），δ_{G_sym} 表示对 G_sym（如 C_k 旋转、镜像）的等变推送。可信集
```
Ξ_α = argmin_{U = ∪_m U_m, U_m 为模式 m 的水平集} |U|  s.t.  Σ_m w_m·1[Ξ 覆盖模式 m 的 (1−α_m) 水平集] ≥ 1−α
```
模式 m 可识别 ⇔ w_m ≥ 1−δ_mode。**禁止**用 Σ_m w_m μ_m 作为认证用的位姿。

**定义 576（歧义感知姿态证书 Ambiguity-aware Pose Certificate, APC）** 对技能序列 π：
```
Ĉ_pose(π) 有效（全局） ⇔ ∀ξ ∈ Ξ_α:  Ĉ_contact(π; ξ) ∧ Ĉ_safety(π; ξ) 有效
Ĉ_pose^m(π) 有效（模式条件） ⇔ w_m ≥ 1−δ_mode ∧ ∀ξ ∈ Ξ_α ∩ mode_m:  Ĉ_contact(π; ξ) ∧ Ĉ_safety(π; ξ) 有效
```
若全局无效且无任一可识别模式的条件证书有效，APC 返回 ⊥（弃权），并把"几何歧义"作为一等弃权原因上报 JDPP。模式条件证书执行时，监视器必须在执行期间持续确认模式未切换；一旦切换即中止并重认证。

**定义 577（故障-姿态联合信念与 gauge 简并 Joint Belief & Gauge Degeneracy）** 联合信念由因子图给出：
```
b(f, ξ) ∝ P_prior(f, ξ) · ∏_t P(y_t | f, ξ, u_t) · ∏_t P_contact(τ_t | f, ξ) · P_slip(ξ_{t+1} | ξ_t, τ_t, f)
```
在被动动作集 U_passive 下，gauge 简并子空间定义为
```
G_gauge(b) = { (δf, δξ) ≠ 0 : (∂h/∂f)δf + (∂h/∂ξ)δξ = 0,  ∀u ∈ U_passive }
```
若 dim G_gauge(b) > 0，则 b 在等价类 (f,ξ)+G_gauge 上不可压缩，任何仅依赖 b 的点估计都不是可辨识的；证书必须对等价类取最坏情形，或由主动探针打破。

**定义 578（主动消歧规划 Active Disambiguation, JDPP）** 动作集
```
A = A_exec(已认证技能/段) ∪ A_probe(探针) ∪ {a_ask, a_fallback}
```
探针 u 可行 ⇔ v11 六重证书（物理/接触/谐波/规范/健康/几何）在执行 u 前均闭合。期望信息增益
```
IG(u) = H[b(f,ξ)] − E_{y∼P(·|b,u)} H[b(f,ξ) | y, u]
VOI(u) = IG(u) − κ(u),   κ(u) = λ_t·T(u) + λ_c·contact_cost(u) + λ_h·harmonic_cost(u)
```
决策规则：
1. 若存在 π∈A_exec 使 Ĉ_DCC(π)∧Ĉ_pose(π) 有效，且其证书**不受残余 gauge 简并影响**，执行最大化任务价值的 π；
2. 否则选 u* = argmax_{u∈A_probe} VOI(u)；若 VOI(u*)>0 且 u* 通过六重证书，执行探针；
3. 否则若 a_ask 可行，a_ask；否则 a_fallback（退回 v11 保守路径）。
**探针不是免费的感知，而是有证书、有成本、有中止点的动作。**

**定义 579（v12 中立元表）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| FRM | F_t≡{f_nom}，β(f)≡β_v11，d_sep≡∞ | Level-4（v11） |
| DCC | Ĉ_DCC≡v11 四重证书，P^f≡P^c∩P^h | Level-3（v11） |
| APC | Ξ_α≡{ξ̂_MAP}，Ĉ_pose≡v11 Ĉ_contact | Level-2（v11） |
| JDPP | A_probe≡∅，仅被动估计 + v11 规划 | Level-1（v11） |

## 2. 形式化定义（要点与升级）

**升级定义 555′（谐波合规性证书，v12）** HCC 的固定余量 β 升级为故障条件 β(f)（定义 572）；证书检查从"标称模型 + 固定 β"变为"∀f∈F_t 的 Ĉ_h(π;β(f))"。当 F_t={f_nom} 时逐位退回定义 555。

**升级定义 547′（接触证书，v12）** Ĉ_contact 的定义域从点 ξ̂ 升为可信集 Ξ_α；合取证书为
```
Ĉ_joint(π) = Ĉ_DCC(π) ∧ Ĉ_pose(π) = [∀f∈F_t Ĉ(f)] ∧ [∀ξ∈Ξ_α Ĉ(ξ)]
```
两者都只能删候选，不能相互"补偿"（不允许"故障大就放宽姿态"或反之）。

**升级定义 548′（接触安全中止，v12）** 接触中止点要求同时∈P^h 且∈P^f；若 P^c∩P^h∩P^f=∅，则任何故障假设下都不可执行，DCC 拒绝，JDPP 必须消歧或回退。

**升级定义 531′（软硬约束衔接，v12）** M₀ 硬检查新增三类入口：(a) 证书相关故障不可诊断；(b) 姿态可信集上存在违反 I_c 的模式且该模式未被排除；(c) 探针未通过六重证书。三者直接进入 M₀ 硬违规；v11 判据不因新模块存在而放宽。

**升级定义 534″（多语义中止点，v12）** 
```
P_t = P_t^nav ∪ P_t^c ∩ P^h ∩ P^f ∪ P_t^probe
```
块可执行必要条件：当前模式对应的中止点集非空，且**证书相关故障与姿态模式已可诊断或被探针覆盖**。

**升级定义 557′（谐波感知分解，v12）** HATD 的每段可执行条件新增可诊断性约束：
```
(可诊断) F_rel(seg) ∩ F_t 两两 d_sep > δ_diag，或 ∃ 段内可行探针 u 使条件成立
(几何闭合) Ĉ_pose(seg) 有效，或段内存在已认证的消歧探针
```
HATD 只能重切分，不能通过放宽 δ_diag 或 α 来"制造"可行性。

**新增定义 580（健康状态转移与故障出现）** 故障不是静态标签，允许在执行中按
```
P(f_{t+1} | f_t) = (1−ε_on)·1[f_{t+1}=f_t] + ε_on·P_new(f_{t+1})
```
出现/演化（ε_on 为故障到达率上界）。块守卫在每个控制拍重算 F_t；证书只在**当前 F_t 下**有效，跨拍的证书沿用必须显式检查 F_t 未扩张到证书相关集。

# IP-367 FaultResidualMonitor
class FaultResidualMonitor:
    def __init__(self, harmonic_model, parity_basis, fault_lib,
                 noise_enclosure, sigma_pe, delta_diag):
        self.model = harmonic_model
        self.W = parity_basis              # parity space，满足 W·C = 0
        self.fault_lib = fault_lib
        self.noise = noise_enclosure       # γ_t
        self.sigma_pe = sigma_pe
        self.delta_diag = delta_diag

    def residuals(self, obs, state):
        r_enc = (obs.motor_enc - obs.joint_enc) - self.model.predict_flex(state, obs)
        r_cur = self.model.k_t * obs.current - self.model.predict_tau_h(state, obs)
        r_force = obs.force - self.model.predict_contact_force(state, obs)
        r_kin = log_SE3(self.model.predict_pose(state, obs).inv() @ obs.pose_meas)
        return concat(self.W @ stack([r_enc, r_cur, r_force, r_kin]))

    def update(self, obs, state):
        r = self.residuals(obs, state)
        F_t = set()
        for f in self.fault_lib:
            if self.enclosure(f, state).contains(r):     # 定义 571
                F_t.add(f)
        sep = {(fi, fj): self._d_sep(fi, fj, state)
               for fi in F_t for fj in F_t | {F_NOM} if fi != fj}
        return FaultEstimate(F_t=F_t, r=r, sep=sep,
                             diagnosable=self._pairwise_diagnosable(F_t, sep))

    def certificate_relevant(self, skill_seq):
        rel = set()
        for f in self.fault_lib - {F_NOM}:
            if self._can_invalidate(skill_seq, f):        # ∃ 状态使 Ĉ(f) 失效而 Ĉ(f_nom) 有效
                rel.add(f)
        return rel

    def _d_sep(self, fi, fj, state):
        num = norm(self.W @ (self.signature(fi) - self.signature(fj)) @
                   (self.phi(fi) - self.phi(fj)))
        return num / (self.noise(fi, state) + self.noise(fj, state))


# IP-368 DiagnosableComplianceCertifier
class DiagnosableComplianceCertifier:
    def __init__(self, hcc, cc, margin_lipschitz, delta_diag):
        self.hcc, self.cc = hcc, cc
        self.L_beta = margin_lipschitz          # 证书分量 -> L_β
        self.delta_diag = delta_diag

    def beta(self, f, component):
        return self.hcc.beta_nom[component] + self.L_beta[component] * norm(phi(f))

    def certify(self, skill_seq, state, fault_est, pose_est, harmonic_est):
        rel = fault_est.certificate_relevant(skill_seq)
        compat_rel = fault_est.F_t & rel
        # (i) 不可诊断即拒绝，绝不放宽 β
        if not self._pairwise_diagnosable(compat_rel | {F_NOM}, fault_est.sep):
            return None
        # (ii) 对所有相容故障假设取最坏情形
        for f in fault_est.F_t:
            betas = {c: self.beta(f, c) for c in CERT_COMPONENTS}
            if not (self.hcc.certify(skill_seq, state, harmonic_est, betas)
                    and self.cc.certify(skill_seq, state, betas)):
                return None
        # (iii) 几何最坏情形（与 APC 合取）
        if not pose_est.globally_certified(skill_seq, state):
            return None
        # (iv) 故障安全中止点非空
        if not self.fault_safe_abort_points(skill_seq, fault_est, state):
            return None
        return ConditionalCert(faults=tuple(fault_est.F_t),
                               pose_modes=pose_est.modes,
                               betas={f: {c: self.beta(f, c) for c in CERT_COMPONENTS}
                                      for f in fault_est.F_t})

    def fault_safe_abort_points(self, seq, fault_est, state):
        return [p for p in range(1, len(seq))
                if all(safe_hold_feasible(p, seq, f, state) for f in fault_est.F_t)
                and contact_and_harmonic_invariants_hold(p, seq, state)]

class AmbiguityAwarePoseCertifier:
    def __init__(self, pose_net, symmetry, alpha, delta_mode, contact_cert):
        self.pose_net = pose_net
        self.G_sym = symmetry
        self.alpha = alpha
        self.delta_mode = delta_mode

        self.belief = PoseMixture(modes)
        self.Xi_alpha = self.belief.credible_set(self.alpha)
        return self.belief

    def globally_certified(self, skill_seq, state):

        return all(self.contact_cert.valid(skill_seq, state, xi)
                   for xi in self.Xi_alpha)

    def per_mode_certificate(self, skill_seq, state):
        if not self.belief.mode_identified(self.delta_mode):
            return None
        m = self.belief.dominant_mode()
        if all(self.contact_cert.valid(skill_seq, state, xi)
               for xi in self.belief.mode_credible_set(m, self.alpha)):
            return PoseCert(mode=m, set=self.belief.mode_credible_set(m, self.alpha))
        return None


# IP-370 JointDiagnosisPosePlanner
class JointDiagnosisPosePlanner:
    def __init__(self, frm, apc, dcc, dsl, hdt, v11_shield, probe_cost):
        self.frm, self.apc, self.dcc = frm, apc, dcc
        self.dsl, self.hdt = dsl, hdt
        self.shield = v11_shield                 # 六重证书 + v11 规范盾
        self.kappa = probe_cost

    def step(self, task, b_joint, exec_candidates):
        # 1) 若能直接认证且证书不受残余 gauge 简并影响，执行价值最高者
        certified = [pi for pi in exec_candidates
                     if self.dcc.certify(pi, b_joint.state, b_joint.fault_est,
                                         b_joint.pose_est, b_joint.harmonic_est)
                     and not self._gauge_affects_cert(pi, b_joint)]
        if certified:
            return ("execute", max(certified, key=task.value))

        # 2) 主动消歧：在已认证探针集中最大化 VOI
        probes = [u for u in self.dsl.probe_primitives()
                  if self.shield.admits(u)]
        best = max(probes, key=lambda u: self.voi(b_joint, u), default=None)
        if best is not None and self.voi(b_joint, best) > 0:
            return ("probe", best)

        # 3) 求助 / 回退
        if self.shield.admits_ask():
            return ("ask", None)
        return ("fallback", None)

    def voi(self, b_joint, u):
        ig = self.mutual_information(b_joint, u)      # (f,ξ) 互信息（定义 578）
        return ig - self.kappa(u)

    def mutual_information(self, b_joint, u):
        # 蒙特卡洛：从 b(f,ξ) 采样，经 HDT 的 M_h 与视觉/力观测模型展开
        samples = [b_joint.sample() for _ in range(N_MC)]
        h_before = entropy([s for s in samples])
        h_after = 0.0
        for s in samples:
            pred = self.hdt.observe_model(s.f, s.xi, u)
            post = b_joint.bayes_update(pred.sample_observation())
            h_after += entropy(post) / len(samples)
        return h_before - h_after

    def _gauge_affects_cert(self, pi, b_joint):
        # 若证书在最坏情形等价类上不闭合，则简并仍影响该证书
        return any(not self.dcc.certify_under(pi, delta) for delta in
                   b_joint.gauge_basis_affecting(pi))

## 4. 推导

**引理 104（故障条件证书安全性）** 设 (A-F) 真实故障 f*∈F_t；(A-M) 对每个证书分量 c，β_c(f) ≥ β_c^nom + L_{β,c}‖φ(f*)‖ 且 L_{β,c} 是该分量对 φ 的 Lipschitz 常数；(A-C) DCC 对 ∀f∈F_t 检查 Ĉ_c(π;β_c(f)) 通过。则真实执行中该分量不超过 v11 证书界。
证明：由 Lipschitz 性，f* 下的真实误差 ≤ β_c^nom + L_{β,c}‖φ(f*)‖ ≤ β_c(f)（取 f=f* 即得）。DCC 对 f* 的检查通过，故真实量 ≤ 证书上界；其余分量同理。证毕。∎

**引理 105（可诊断性与最小可检测故障）** 设残差噪声 v∼N(0,σ²I)、签名矩阵最小奇异值 σ_min(S)≥σ_pe（持久激励），故障库有限。若
```
‖φ(f)‖ ≥ 2σ√(2 ln(|F_lib|/δ)) / σ_min(S)
```
则单一故障 f 被隔离的概率 ≥1−δ；两故障可分离的充分条件为 d_sep(f_i,f_j) > 2。证明：线性化残差均值 μ(f)=S_f φ(f)，对非真故障的检验统计量做 union bound + 高斯尾界；分离度归一化后恰为两均值之差的信噪比，d_sep>2 保证两类错误概率可同时 ≤δ/|F_lib|。∎

**引理 106（姿态可信集证书的弃权概率界）** 设 APC 的姿态信念已校准，即 P(ξ*∈Ξ_α) ≥ 1−α，且全局证书 Ĉ_pose 有效（对所有 ξ∈Ξ_α 通过）。则"执行时真实位姿违反证书"的概率 ≤ α。若使用模式条件证书 m̂，则违反概率 ≤ α + P(m̂≠m*)，其中 P(m̂≠m*) ≤ Σ_{m≠m*} w_m。
证明：全局有效意味着在事件 {ξ*∈Ξ_α} 上真实位姿被覆盖，故违反蕴含 ξ*∉Ξ_α，其概率 ≤α；模式情形再由全概率公式与模式误判事件合并。证毕。∎

**引理 107（故障-姿态 gauge 简并的存在性）** 在一阶意义下，存在非零 (δf_enc, δξ) 使物体在夹爪中的切向微滑与关节编码器偏置在相对位姿、相对接触力、电流残差上产生**完全相同**的观测；即 G_gauge(b) 至少为 1 维。仅靠被动动作集 U_passive 无法降低该方向的不确定性。证明：线性化观测只依赖关节测量与物体位姿之差 z = θ_joint^meas − ξ（相对量），故取 δθ_joint^meas = δ、δξ = δ 使 δz=0，所有仅依赖 z 的通道（相对位姿、接触力、谐波回差）一阶不变；外部力/视觉依赖世界系或绝对量，才能打破该方向。因此 dim G_gauge ≥1，且该方向对 U_passive 不可观。∎

**引理 108（主动消歧的近似最优性）** 设给定 (f,ξ) 后各次观测条件独立，且互信息 IG(u | 已观测) 对探针集是自适应子模的。则按 VOI 贪心选择探针，在基数预算 B 下取得的期望信息增益 ≥ (1−1/e)·OPT；在带成本预算下，按 IG/κ 密度贪心取得 ≥ (1−1/e)/2·OPT。
证明：条件独立保证互信息是子模函数；自适应子模性由 Golovin & Krause (2011) 给出贪心 (1−1/e) 近似；带成本版本用 Nemhauser 等的预算化子模最大化界。∎

**引理 109（中立元退化等价 v11）** 将定义 579 的四个中立元分别注入 FRM/DCC/APC/JDPP 端口，则 F_t≡{f_nom}、β(f)≡β_v11、Ξ_α≡{ξ̂_MAP}、A_probe≡∅，DCC 证书逐项退化为 v11 四重证书，JDPP 退化为 v11 NCP 规划，主闭环调用序列与 v11 逐位一致；再由 v11 引理 102 继续退回 v10/v9/v8/v7/v6。
证明：逐端口代入中立元；四端口互不相交，代入后可交换至调度顺序，得到 v11 程序；其余由 v11 引理 102 链式成立。∎

**引理 110（预算守恒 v12）** 新增在线成本上界：FRM 残差+相容集 ≤0.4ms（|F_lib|≤12、6 通道）；DCC 证书 ≤0.3ms（每拍缓存 F_t、增量 β）；APC 5Hz 摊销 ≤1.5ms（3 模式、Σ_m 为 6×6）；JDPP 2Hz 摊销 ≤2ms（VOI 采样 16、探针≤8）；探针执行摊销 ≤0.5ms。新增合计摊销 ≤4.7ms；v11 典型 11ms、p99 22ms 的 2ms 余量不足以覆盖最坏叠加，故将 APC/JDPP 移出 50Hz 关键路径（异步+缓存），静态 EDF 校验后仍在 p99≤22ms 内，50Hz 保持。
证明：逐项代入复杂度表并做静态 EDF 校验 ΣŴ_m ≤ B_dec；关键路径只保留 FRM/DCC 与缓存查表，故最坏叠加不超过预算。∎

**引理 111（六重证书合取安全继承）** v12 执行管线为
```
健康证书 ∧ 几何证书 ∧ 物理证书 ∧ 接触证书 ∧ 谐波证书 ∧ 规范证书 → 规范盾 → 因果评分
```
FRM 只能扩相容集、DCC 只能删候选、APC 只能缩/分裂可信集、JDPP 只能在已认证集合内选探针。对 v11 技能子集，四个新模块退化为恒真/点估计/空探针，执行集等于 v11 安全集；对新增谓词，引理 104（健康）、106（几何）、108（消歧）独立覆盖。故不存在绕过任何 v11 适用证书的执行路径，v11 引理 101 的安全继承在 v11 子集上继续成立。
证明：合取管线中每个新模块只作用于自己的端口且只做删除/限制；中立元下逐项等于 v11；新增谓词由各自引理保证。∎

## 8. 已知风险与失效模式

1. **故障库不完备**：真实故障可能是未列入 F_lib 的复合/新故障，导致 F_t 为空或错配。缓解：残差包络留出"未知故障"桶、非参数残差检测器、把 F_t=∅ 视为硬违规而非"健康"。
2. **集员包络过保守**：为覆盖建模误差把 γ_t 放大，导致 F_t 长期含多故障、DCC 频繁拒绝。缓解：分通道/分状态标定包络、用数据驱动残差界、把保守度作为可调风险预算显式记录。
3. **可信集校准失配**：姿态网络在分布外/反光/透明物体上过度自信，Ξ_α 未覆盖真值。缓解：温度标定、一致性训练、OOD 检测、α 自适应、在证书外显式记录校准假设。
4. **gauge 简并无法完全打破**：某些场景世界系观测也不可靠（视觉遮挡 + 无力传感），简并维残留。缓解：证书对等价类取最坏情形、把"不可消歧"作为合法弃权、退回 v11 保守路径而非硬猜。
5. **探针本身的代价与损伤**：探针需要运动/接触，可能引入磨损或扰动任务对象。缓解：探针幅值/频带受 v11 谐波与接触证书约束、成本项显式计入 VOI、设置每任务探针预算。
6. **故障-姿态-因果同源误差放大**：FRM 包络误差 → DCC 裕度误差 → CWM 预测误差 → 规范信念误差。缓解：独立证据通道（双编码器/电流/力/触觉/视觉）、显式不确定性传播、a_ask 打破环。
7. **六重证书过度保守清空可行集**：健康+几何+物理+接触+谐波+规范合取可能无解。缓解：证书裕度分层（hard/soft）、HATD 自动细化、JDPP 主动探针、把"无可行段"显式转为 a_ask，而非静默放宽。
8. **退化实现不严格**：中立元若在任一端口残留状态（缓存 F_t、模式权重、探针预算），Level-4 可能不逐位等价 v11。缓解：端口冻结接口、每轮运行 E620 diff 测试、CI 中做退化等价门禁。

## 9. 本轮最大风险

**一句话**：慢变故障（编码器偏置、柔轮磨损、力传感器漂移）与姿态多峰模式在 gauge 简并方向上互相伪装，被动数据无法分离，系统会以一个自洽但错误的 (f,ξ) 签发"最坏情形安全"证书——即**把故障误诊为几何歧义，在最坏情形上算对了错误问题**。
