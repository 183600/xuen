# 灵感驱动研究循环 · 新三元组第 1 轮

本轮灵感词：**「语义地图」×「迭代验证」**

> **基线**：v22 = MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（HDL / ACSC / DCSC / HPC-E / CFC++），其上承 v21 语义-规范层（SDC/CAC/DCL/GIC、HPC+）、v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）与 v19/v17 各模块。
> **本轮纪律**：不推倒 v22。**语义地图不是"又一层感知"，而是把过去所有证书的证据持久化为可审计的空间账本；迭代验证不是"多跑几次实验"，而是把每张证书变成在任意停时都有效的可证伪过程。** 本轮只做一件事：给 v22 加一层"持久化-时序化"的维护层——让安全结论**有记忆、有半衰期、有反证义务**。

## 0. 直觉与动机

**灵感 1（语义地图 → 空间证据的持久账本，而非空间真理）**
直觉：v20–v22 的所有证书都是"快照"：ζ_fed / ζ_sem / ζ_pgev 只描述"此刻"。但机器人在同一环境里跑几百小时，每天都在重新发现"这张桌子在哪、这扇门多宽、这个角落通常没人"。语义地图的价值不在于给出更漂亮的世界模型，而在于它把**重复观测的证据累加起来**：(a) 摊销检测与重新探索成本；(b) 给缺席证书（v21 CAC）提供"历史负证据"，缓解上一轮最大的"合规缺席幻觉"；(c) 把 CTS 的类先验、ACSC 的臂配空间占用、DCL 的规范区域（禁区/共享区）统一锚定到同一套空间坐标上。
但这里必须反直觉地克制：**地图不能直接授予自由空间**。地图是"证据账本"（ledger），不是"事实数据库"（database）。若地图能直接说"这里空"，它就变成一个永不失效、无法被现场观测推翻的 oracle——这恰恰是最危险的失效模式。故核心创新之一：**语义地图证据账本 (Semantic Map Evidence Ledger, SMEL)**。每个格子/锚点存 `(类别, 几何, 正证据, 负信用, 来源, 时间戳, 模态集合, 状态)`；其中**障碍证据只增不减、自由信用有界且随时间衰减、并且必须被现场 CAC 复核才能赎回**。地图书写与 v21 P34 完全同构：障碍单调、自由有偿。

**灵感 2（迭代验证 → 证书是波普尔式可证伪过程，不是一次性签发的证明）**
直觉：v22 的证书"签发即生效，直到失效"，最大隐患是假设漂移：标定的召回率 κ_c 会变、人会新进入、物体会被挪走。迭代验证给的不是"再验一遍"，而是**证书的生命周期**：签发 → 监控 → 确认/过期/被证伪/撤销。更关键的是统计上的严格化——控制环每个周期（50Hz）都在"偷看"数据，传统固定样本 conformal 在可选停时（optional stopping）下覆盖会失效；而 **e-process / test martingale** 配合 Ville 不等式给出**任意停时有效（anytime-valid）**的证伪界：在"证书仍成立"的原假设下，`P(∃t: E_t ≥ 1/α) ≤ α`。这与 v22 的证伪主义立场完全一致：**验证只能提高"未被证伪"的信心，永远不能把"未证伪"变成"已证明"**（对应 v22 的 `W_sim=∅ ≠ proved`）。故核心创新之二：**证书生命周期管理器 (Certificate Lifecycle Manager, CLM) + 任意时刻有效证伪引擎 (Anytime-Valid Falsification Engine, AVFE)**，并配一个**主动证伪预算**：把有限的观测动作花在"最可能翻案"的地方，而不是平均地重复看已经稳定的区域。

**二者如何统一**
统一为 v22 之上的**"持久-时序维护层"**：SMEL 回答"过去观测在空间上留下了什么证据、可信到几时"；CLM/AVFE 回答"这张证据/证书此刻还能不能被依赖、下一次该去证伪哪里"。共享状态扩展为 **ζ_map = ζ_pgev ∪ (M_sem, CertSet, B_t)**；统一准入门 **HPC-M = (HPC-E, AbsMap, Valid(Cert))**——几何∧规范∧负信息（v21/v22）∧ 地图证据未过期 ∧ 全部依赖证书在任意停时下未被证伪。任一缺失即退回 v22 的保守收缩。安全继承方向：地图只增障碍、证书只做交/过期/撤销，故 `Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

## 1. 研究问题（轮次升级版）

- **Q12（地图即证据的融合与单调性）**：多机器人、多会话、多模态的地图记录如何带 provenance 融合，使得"障碍只增、自由只减（除非现场复核）"？同一格子的冲突观测（A 说有、B 说无）如何消解而不被陈旧数据污染？可移动物体的"证据重置"如何触发（移动检测/环境变更点）？地图匹配误差（回环漂移）如何像 CertBox 一样膨胀，避免"地图对得准"这一未证假设偷渡进安全结论？
- **Q13（地图接地的缺席与陈旧上界）**：历史负证据在什么条件下可以降低现场观测频率而不突破召回下界 κ_c？定义一个"陈旧缺席"误差界 `ε_stale(age, λ_change, κ_c)`，使 `P(人真在该格 ∧ 地图判空) ≤ ε_stale`；当环境非平稳（λ_change 上升）时该界如何单调收紧到"必须现场复核"？
- **Q14（任意停时的迭代验证）**：如何为每张证书构造 e-process，使其在 50Hz 连续查询、可选停时下仍满足 `P(误撤销 | 证书有效) ≤ α_cert`？固定样本 conformal 与 e-process 如何在同一个证书里共存（前者给几何误差界、后者给持续证伪）？非平稳下如何加 change-point 检测与"证据重置"，且不因重置过频繁导致活性坍缩？
- **Q15（生命周期与级联安全）**：`Issued→Monitoring→{Confirmed,Stale,Refuted,Revoked}` 的每次迁移如何保证只收缩执行集？一张地图证书被撤销后，依赖它的 DCL/HPC-E/ACSC 证书如何级联重算而不振荡？主动证伪预算 `B_t` 在战略/战术/操作三层如何分配，且"预算未花完"必须按未验证处理（保守）而非默认安全？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P45）

**P43 地图即证据律（Map-as-Evidence, Not Map-as-Truth）**
`M_sem(t)` 中每个单元 `m` 维护双通道：障碍证据 `L^occ_t(m) = L^occ_{t−1}(m) + Σ_k logLR_k`（**只增不减**，障碍只能被增补）；自由信用 `F_t(m) = γ^{Δt} F_{t−1}(m) + credit`（`F∈[0,F_max]`、`γ<1`、有界衰减）。自由空间赎回谓词
`Redeem_t(x) = [F_t(m(x)) ≥ τ_free] ∧ [age ≤ TTL_map] ∧ [Diver(provenance) ≥ 2] ∧ [live CAC valid] ∧ [no gesture presence]`（最后一项继承 v21 GIC 的"在场翻转"）。
地图**只提交**候选缺席 `AbsMap_t(x) := Redeem_t(x)`，**从不直接授予**自由空间；现场观测与地图冲突时 **live dominates map**（地图信用立即清零并记审计）。类先验收紧、ArmConfigSpace 占用、DCL 区域一律只写 `L^occ` 通道，禁止借地图"打开"空间。

**P44 证书生命周期律（Certificate Lifecycle & Anytime Validity）**
每张证书 `C = (id, φ, {E_t}, α_cert, τ_c, deps, state, t0, TTL)`，其中 `E_t` 为在原假设 `H_C`（证书成立）下满足 `sup_t E[E_t|H_C] ≤ 1` 的 e-process。由 Ville 不等式：`P_H(∃t: E_t ≥ 1/α_cert) ≤ α_cert`，故**任意停时**下的误撤销率有显式上界。判定：
`Valid(C,t) := state ∈ {Issued, Confirmed} ∧ (t − last_confirmed) ≤ TTL ∧ E_t < 1/α_cert`。
**非证伪 ≠ 已证明**：`Valid` 只表示"当前未被打倒、且未过期"，绝不表示 `φ` 已成立（与 `W_sim=∅ ≠ proved` 同构）。任意迁移到 `{Stale, Refuted, Revoked}` 只能**交**上额外过滤器，故 `Exec(state') ⊆ Exec(state)`。总门：
`Exec_v23 = Exec_v22 ∩ {π : AbsMap_t(region(π)) ∧ ∀C∈deps(π) Valid(C,t)} ⊆ Exec_v22`。

**P45 主动证伪预算律（Active Falsification Budget）**
验证预算 `B_t`（观测动作数/代价）只用于**尝试证伪**，绝不用于"确认安全"。分配 `a* = argmax_a IG(a; C)/cost(a)`（对占用后验的信息增益，或对证书有效期区间的期望缩减）。未花完的预算 / 覆盖不足的区域一律按**未验证**处理（保守），不得默认安全。预算按 v22 分层 PGEV 自顶而下分配：战略层决定总预算与高风险区配额，战术层在配额内选点，操作层执行 O(1) 查询与即时观测；低层不得把"没看"报成"看过且安全"。

## 3. 与基线的接口（如何退化）

- **SMEL 失效**（地图损坏/定位漂移超界）⇒ 无历史负证据 ⇒ `AbsMap ≡ false` ⇒ 退回 v21 每周期现场 CAC（更保守，活性下降，安全不降）；
- **CLM 失效**（生命周期状态机崩溃）⇒ 所有证书视为过期 ⇒ 退回 v22 的签发时门（若其 TTL 未到），安全子集关系保持；
- **AVFE 失效**（e-process 不可计算）⇒ 证书只保留固定 TTL，且将 TTL 视为待复核 ⇒ 退回纯 v22 快照，绝不"算不出就不证伪"；
- **主动预算不可用** ⇒ 退化为对高风险区/边缘区均匀加密观测的最保守分配，宁可活性损失；
- **地图与现场冲突** ⇒ live 优先、地图信用清零、触发一次强制复核（refute 记录入审计链），不静默覆盖；
- **与 v22 三模块的再整合**：DCSC 的深度特征 φ(x) 作为地图锚点描述子（不传原图，满足 E794）；ACSC 的臂配空间占用写入 `L^occ`；HDL 的战略层持有 `B_t`、战术层消费。三者失效均向 v22 收敛；
- **全失效** ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 163）。

## 4. 预期贡献

1. **地图即证据账本**：给出带 provenance、双通道、有界衰减的语义地图融合，首次明确"地图只提名、现场才授予"的自由空间纪律，并证明其与 P34 单调律同构；
2. **地图接地的缺席证书与陈旧界**：把历史负证据纳入 AbsCert，给出 `ε_stale(age, λ_change, κ_c)` 的单调上界，使"长期没人"从经验直觉变成可审计的、会过期的信用；
3. **任意停时有效的证书生命周期**：e-process + Ville 使 50Hz 连续查询下的误撤销率有显式 α 界，并在形式上区分"未证伪"与"已证明"，封堵"验证即安全"的滑坡；
4. **主动证伪预算**：以信息增益分配观测，把迭代验证从"被动重放"变成"主动找反例"，并规定预算未花完按未验证处理；
5. **级联安全继承**：证明任意生命周期迁移只会收缩执行集，且撤销/过期沿依赖图级联重算不振荡；
6. **与 v22 的统一**：CTS/ACSC/DCL/DCSC 全部锚定到同一语义地图；`Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 闭环（引理 163）。

## 5. 本轮最大风险

**一句话**：语义地图的"缺席信用"与主动证伪预算会形成**确认偏误闭环**——长期被验证为空的区域因信息增益低而被持续少看，一旦环境非平稳（新进入者、系统性漏检类别如儿童/轮椅/蹲姿），迭代验证只会不断确认旧结论而极少真正去证伪它，使 v23 带着更完备的审计链**"越验越安全、实则越盲"**，把上一轮的"合规缺席幻觉"升级为"可审计的缺席幻觉"。

## 1. 形式定义与命题

**定义 926（语义证据账本 SMEL）**
`M_sem(t)` 是一组记录 `r_t(m)`。融合算子 `⊕` 按 provenance 去重后写入：
- 障碍通道（只增）：`L^occ_t(m) = L^occ_{t−1}(m) + Σ_{k∈obs_occ(m)} log LR_k`；
- 自由通道（有界衰减）：`F_t(m) = clip(γ_map^{Δt} F_{t−1}(m) + Σ_{k∈obs_free(m)} c_k, 0, F_max)`；
- 来源：`P_t(m) = P_{t−1}(m) ∪ {(robot_id, modality, session, ts)}`；
- 冲突：若 `obs_occ` 与 `obs_free` 同格冲突，以 `obs_occ` 为准（保守），并触发一次 `→_ref` 复核事件。
地图**不**产生任何直接可执行谓词。

**定义 927（地图匹配误差膨胀）**
锚点几何按 `inflate(g, ε_map)` 膨胀，`ε_map` 由回环漂移/重定位的 conformal 分位给出；`ε_map` 不得由"地图与点云看起来对齐"这一未证观察替代。

**定义 928（地图接地缺席 `AbsMap`）**
`Redeem_t(x) := F_t(m(x)) ≥ τ_free ∧ (t − ts(m(x))) ≤ TTL_map ∧ Diver(P_t(m(x))) ≥ 2 ∧ live_CAC_t(x) ∧ ¬gesture_presence_t`。
`AbsMap_t(x) := Redeem_t(x)`。任一合取项失败 ⇒ `AbsMap=false` ⇒ 口径退回"可能有人"（保守）。

**定义 933（证书有效性与任意停时证伪）**
`Valid(C,t) := state(C) ∈ {Issued, Confirmed} ∧ (t − last_confirmed(C)) ≤ TTL(C) ∧ E_t(C) < 1/α_cert(C)`。
e-process 构造（Bernstein/betting 形式）：给定有界增量 `X_i ∈ [−b, b]`，取 `E_t = Π_{i≤t} (1 + λ_i X_i)`，`λ_i` 由预测下界在线选取使 `E[1+λ_i X_i | F_{i−1}] ≤ 1`。

**引理 929（地图单调律）**
在无显式"物体移走"复核时，`Obs_t = Hull ∪ ⋃ CertBox_k ∪ {m : L^occ_t(m) ≥ τ_occ}` 关于 t 单调不减；`Redeem` 的可达面积关于 `age` 与 `λ_change` 单调不增。故地图层不会创造 v22 之外的自由空间。

**引理 930（任意停时误撤销界）**
若 `H_C`（证书成立）下 `E_t` 为非负上鞅且 `E[E_t|H_C] ≤ 1`，则对任意停时 τ 与任意 `α_cert∈(0,1)`：`P_H(∃t: E_t ≥ 1/α_cert) ≤ α_cert`。即 50Hz 逐周期查询不放大误撤销率；反之，`E_t < 1/α_cert` **不**推出 `φ` 成立（不可由未证伪推出已证明）。

**命题 931（陈旧缺席误差界）**
设格内占用为非齐次泊松/风险过程，风险率上界 `λ_change`，检测召回下界 `κ_c`，则
`ε_stale(age, λ_change, κ_c) ≤ 1 − κ_c + (1 − κ_c)·(1 − e^{−λ_change·age})` 的量级；
且 `ε_stale` 关于 `age`、`λ_change` 单调不减，关于 `κ_c` 单调不增。当 `ε_stale > ε_budget` 时强制 `AbsMap=false` 并要求现场复核（P43/P44 联动）。

**定理 932（生命周期安全继承）**
对任意迁移 `σ → σ'`，若 `σ' ∈ {Stale, Refuted, Revoked}`，则 `Exec(σ') = Exec(σ) ∩ Fil_extra ⊆ Exec(σ)`；又 `Valid(C,t)` 只做合取（P44），故
`Exec_v23 = Exec_v22 ∩ {AbsMap ∧ ∀deps Valid} ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
撤销沿依赖图 `deps` 级联重算，每次重算只增加合取项，故级联亦单调收缩、无振荡（滞回由 `TTL` 与 `λ_change` 的迟滞带给出）。

## 2. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
import math
from dataclasses import dataclass, field
from enum import Enum

# ---------- IP-436 SMEL：地图即证据 ----------
@dataclass
class CellRecord:
    label: str
    geom: object                 # 已含 inflate(g, eps_map)（定义 927）
    L_occ: float = 0.0           # 障碍对数似然（单调不减）
    F: float = 0.0               # 自由信用（有界衰减）
    prov: set = field(default_factory=set)
    ts: float = 0.0
    modalities: set = field(default_factory=set)
    status: str = "active"

class SemanticMapEvidenceLedger:
    def __init__(self, gamma=0.999, ttl_map=60.0, tau_free=2.0, f_max=5.0, eps_budget=1e-3):
        self.gamma, self.ttl_map = gamma, ttl_map
        self.tau_free, self.f_max = tau_free, f_max
        self.eps_budget = eps_budget
        self.cells = {}

    def update(self, m, obs_occ, obs_free, prov, t, modalities):
        r = self.cells.setdefault(m, CellRecord(label="unknown", geom=None))
        dt = max(0.0, t - r.ts)
        # 障碍只增
        r.L_occ += sum(obs_occ)                      # obs_occ 为 log LR 列表
        # 自由信用有界衰减 + 有界累加
        r.F = min(self.f_max, self.gamma ** dt * r.F + sum(obs_free))
        r.prov |= {prov}
        r.modalities |= set(modalities)
        r.ts = t
        return r

    def redeem(self, m, t, live_cac_ok, gesture_present, diver_min=2):
        r = self.cells.get(m)
        if r is None:
            return False
        # 现场优先：冲突/超龄 ⇒ 拒绝赎回
        fresh = (t - r.ts) <= self.ttl_map
        diverse = len(r.prov) >= diver_min
        return (r.F >= self.tau_free) and fresh and diverse \
               and live_cac_ok and (not gesture_present)

# ---------- IP-437/439：缺席证书 + 任意停时证伪 ----------
class CertState(Enum):
    PROPOSED = "Proposed"; ISSUED = "Issued"; MONITORING = "Monitoring"
    CONFIRMED = "Confirmed"; STALE = "Stale"; REFUTED = "Refuted"; REVOKED = "Revoked"

@dataclass
class EProcess:
    alpha: float
    log_e: float = 0.0
    def update(self, x, lam):
        # x: 有界增量；lam 由预测下界在线选择，保证条件期望 <= 0
        self.log_e += math.log1p(lam * x)
        return math.exp(self.log_e)
    def refuted(self):
        return self.log_e >= math.log(1.0 / self.alpha)

@dataclass
class Certificate:
    cid: str
    claim: object
    alpha_cert: float
    ttl: float
    deps: list = field(default_factory=list)
    state: CertState = CertState.PROPOSED
    t0: float = 0.0
    last_confirmed: float = 0.0
    ep: EProcess = None

    def valid(self, t):
        # 关键：未证伪 != 已证明
        return (self.state in (CertState.ISSUED, CertState.MONITORING, CertState.CONFIRMED)
                and (t - self.last_confirmed) <= self.ttl
                and not self.ep.refuted())

class CertificateLifecycleManager:
    def __init__(self):
        self.certs = {}

    def issue(self, c, abs_map_ok, hpce_ok, t):
        if not (abs_map_ok and hpce_ok):
            c.state = CertState.PROPOSED
            return c
        c.state, c.t0, c.last_confirmed = CertState.ISSUED, t, t
        return c

    def monitor(self, c, x, lam, t):
        c.ep.update(x, lam)
        if c.ep.refuted():
            return self._cascade(c, CertState.REFUTED, t)
        if (t - c.last_confirmed) > c.ttl:
            return self._cascade(c, CertState.STALE, t)
        c.state = CertState.MONITORING
        return c

    def _cascade(self, c, new_state, t):
        # 撤销/过期沿依赖图级联；只增加合取项 ⇒ 单调收缩、无振荡
        c.state = new_state
        for dep in c.deps:
            d = self.certs[dep]
            d.state = CertState.REVOKED
            self._cascade(d, CertState.REVOKED, t)
        return c

# ---------- IP-439/45：主动证伪预算 ----------
class ActiveFalsifier:
    def __init__(self, budget):
        self.budget = budget
    def allocate(self, candidates, ig_fn, cost_fn):
        # a* = argmax IG/cost；只用于"尝试证伪"
        best, best_score = None, -1.0
        for a in candidates:
            score = ig_fn(a) / max(cost_fn(a), 1e-9)
            if score > best_score:
                best, best_score = a, score
        return best, best_score
    def exhaust(self):
        # 预算未花完 ⇒ 显式标记 under-validated，调用方按未验证处理
        return self.budget <= 0.0

# ---------- IP-440 HPC-M 统一准入门 ----------
@dataclass
class HPCM:
    hpce: object          # v22 的 HPC-E（原样保留）
    smel: SemanticMapEvidenceLedger
    clm: CertificateLifecycleManager

    def admits(self, plan, x, v, z, E_res, margin_req, t,
               live_cac_ok, gesture_present, m_region):
        if not self.hpce.admits(plan, x, v, z, E_res, margin_req):
            return False
        abs_map = self.smel.redeem(m_region, t, live_cac_ok, gesture_present)
        certs_ok = all(self.clm.certs[d].valid(t) for d in plan.deps)
        return bool(abs_map and certs_ok)
```

## 3. 实验设计（预注册、成对比较、报告最坏情形）

**3.1 假设**
- H1（安全）：在"系统性漏检类别 + 环境变更"压力下，v23 的缺席假阴性率（AFNR）不高于 v22（目标：≤ v22，且 `ε_stale` 经验覆盖率落在理论界内）；
- H2（活性）：在平稳环境下，v23 因历史负证据而提升任务成功率/平均速度，相对 v21 的"全静态保守"有显著提升，且不牺牲 H1；
- H3（统计有效性）：50Hz 逐周期查询下，e-process 对有效证书的经验误撤销率 ≤ α_cert（含可选停时）；固定样本 conformal 作为对照会超界；
- H4（验证效率）：主动证伪预算在相同预算下比均匀分配发现更多真实反例（refutations/budget）。

**3.2 基线与消融**
- 基线：v22（无地图、无生命周期）；v21 现场 CAC；naive SLAM+occupancy（**把地图当真理**，作为反例对照）。
- 消融：去 `γ_map` 衰减（冻结地图）→ 观察陈旧幻觉；去 AVFE 用固定-n conformal → 观察偷看膨胀；去主动分配用均匀 → 观察效率；去 provenance 多样性（`Diver=1`）→ 观察地图投毒。

**3.3 指标**
- 安全：AFNR、`ε_stale` 经验覆盖率、危险接近事件数（分"地图判空但有人"与"现场已判有人"两类）；
- 稳定：误撤销率、证书 churn（撤销/小时）、级联深度、振荡（相邻周期执行集对称差）；
- 活性：任务成功率、平均通行速度、空转/等待时间；
- 地图：`L^occ`/`F` 校准（ECE）、provenance 覆盖、地图匹配误差膨胀是否被违反；
- 验证：refutations/budget、复核延迟（change-point 到撤销的时延）。

**3.4 压力场景（每项均注入真值）**
1. 系统性漏检类别（儿童/轮椅/蹲姿/强逆光）随机出现于"历史空置"格；
2. 机器人离开期间环境变更（家具挪动、门开合）——检验 `λ_change` 与陈旧界；
3. 地图投毒/陈旧地图跨机器人共享（错误 provenance）；
4. 检测召回 κ_c 缓慢漂移（标定失效）；
5. 多机器人地图冲突观测（A 有 B 无）；
6. 监控期传感器黑屏/延迟（e-process 无更新时按 stale 处理）；
7. 高频策略查询（每周期查询 → 可选停时）。

**3.5 协议与判定**
- 仿真 + 真机 log-replay + HIL 三阶段；每场景 ≥ 30 seeds，成对（同 seed 比基线），报告均值与 5% 最差分位；预注册 H1–H4 与停止规则；所有"未证伪"结果明确标注为**未验证**而非安全；任何一次"地图判空 ∧ 真值有人 ∧ 现场也未检出"记为最严重失败（safety violation），单独统计。

## 4. 与 v22 的接口（退化清单，与想法区 §3 一致）

- SMEL 失效 ⇒ `AbsMap≡false` ⇒ v21 现场 CAC（更保守）；
- CLM 失效 ⇒ 证书视为过期 ⇒ v22 签发时门；
- AVFE 失效 ⇒ TTL 待复核 ⇒ 纯 v22 快照，绝不静默豁免；
- 主动预算不可用 ⇒ 高风险区均匀加密（保守）；
- 地图/现场冲突 ⇒ live 优先、信用清零、强制复核；
- 全失效 ⇒ v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`（定理 932 / 引理 163）。
