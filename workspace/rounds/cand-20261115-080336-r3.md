# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环第 3 轮；本轮灵感：「检索增强生成」×「力矩传感」）

> R69 把「不确定」拆成 aleatoric / epistemic，并让系统学会「问」。但它对答案的判断仍建立在两个**没有出处**的东西上：一是流模型自己生成的模态先验，二是人/环境给的一句话或一次注视。R69 的证据纪律要求「k 个正交证据源一致」，却没有回答更基本的问题：**这些证据是关于这个物体、这个任务、这一次标定的吗？它们从哪里来、谁写的、什么时候过期、能不能被反证？**
>
> 更隐蔽的是，R69 的所有证据通道——流策略、FMA、CIA、甚至人类回答的解释——最终都经过同一个表征 z_t。它们的「一致」可能只是同一套先验的多个副本。R69 自陈的最大风险（模态权重未校准 → 自信地追问幻影）只是这个共模问题的一个表现。
>
> 本轮两个灵感各提供一根**不经过这个表征的锚**：
> - **检索增强生成**：从可审计的经验库 / 维护日志 / 操作手册中检索「过去在相似情境下，什么被验证过、什么被证伪过」。它给的是**有出处、可引用、可过期、可反证**的先验；但库可能陈旧、错配、被投毒，甚至由系统自己写入——所以检索只能移动先验，不能单独定案。
> - **力矩传感**：关节力矩 / 外力估计是**当下的、物理的、与视觉语义相对独立**的通道。它能直接检验「抓到了没有、负载对不对、接触在哪、动作有没有产生预期效果」；但力矩残差依赖动力学模型，也会温漂、饱和、被摩擦模型吸收——所以力矩可以**否决**，确认则要求模型误差有界、通道健康。
>
> 核心命题：**epistemic claim 必须被「双锚」系住——档案锚（检索到的、带 provenance 的先例 / 文档）与物理锚（力矩 / 力的一致性检验）——才允许从「未消解」变为「已消解」；任一锚缺失 / 不可信，就退回 R69 的交互或 R68 的保守。** 命名 **TETHER-RAS**（Torque-grounded Epistemic resolution with Traceable Historical Evidence Retrieval）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证」，R70 问「**我凭什么是相信这个答案的，它属于这个世界吗**」——从「问到答案」升级到「答案有出处、可被物理世界反证」。

## 0. 直觉与动机

**灵感 1（RAG 不是「查资料」，是给信念装上 provenance）**
直觉：R69 的信念更新只关心「答案让后验熵降了多少」，不关心答案从哪来。真实世界里，一个「相似案例」可能来自三年前的旧固件、另一种材质、另一个负载；一段操作手册可能已被修订。检索增强生成的价值不只是「多一个证据」，而是把证据变成**可追溯对象**：来源、时间、适用条件、版本、是否被后续证伪。这样系统才能区分「有据可依」与「只是听过」。

**灵感 2（检索也是双刃剑：错配、投毒、自证）**
直觉：检索系统最容易骗自己的方式，是**用自己的话去查自己的记忆**。如果经验库由策略自己写入、查询又偏向确认当前假设，那么检索只会把旧错放大成「有先例」。因此检索必须（i）查反例而不只查正例；（ii）区分独立作者与自作者；（iii）在无适用先例时明确返回「无先例」，而不是硬凑一个最近邻。**无先例是一个合法且必须被表达的结论。**

**灵感 3（力矩是当下的物理投票，但不是真值）**
直觉：视觉可以被遮挡 / 对抗贴纸骗，语言可以被撒谎，世界模型可以被标定吸收；但「这个关节到底受了多大力矩」是当下物理世界直接给出的。力矩能独立验证接触、负载、抓取成功、碰撞、滑动。代价是：力矩传感器会温漂、零偏、饱和，力矩残差又要减去重力 / 摩擦 / 惯性模型——这些模型和策略共享参数时，又会出现共模。所以力矩是**强证据、弱真值**。

**灵感 4（RAG 与力矩的耦合：检索给「该看到什么」，力矩答「是否看到」）**
直觉：单用力矩，系统知道「有异常力」，却不知道「这异常意味着什么」；单用检索，系统知道「历史上这种情况通常是 X」，却不知道「这一次是不是 X」。把两者接起来：检索返回的不只是文本 / 标签，还有**物理签名模板**（预期力矩波形、负载区间、接触时序）；力矩检验的是「当前物理签名是否匹配这个先例」。这让检索从「语言先验」落到「可测预测」，也让力矩从「孤立阈值」变成「有语义的检验」。

**灵感 5（检索前置：先查再问，省下的是人的耐心）**
直觉：R69 的交互预算很贵，尤其是问人。很多问题其实手册 / 日志里已有答案。检索应当发生在交互之前：能从可信档案中消解的，不打扰人；只能部分消解的，用检索结果缩小问题空间，再问「残差」。这把 R69 的「问什么」升级为「**先查、再问剩下的**」，直接缓解交互疲劳与社交成本。

**灵感 6（严格包含：新锚只能加证据或否决，不能放松安全）**
直觉：档案锚和物理锚都是**额外的否决 / 证据源**，不是新的安全许可证。没有适用档案、力矩通道不健康、动力学模型误差过大时，它们应当**弃权**，让系统退回 R69（继续交互）或 R68（纯保守）。安全侧只会因为多了一个否决者而单调不变差；效率侧则因为「查得到、测得出」而减少不必要的交互与保守。

**灵感 7（新的最大风险：把自己拴在自己的过去上）**
直觉：检索的记忆如果由系统自己写入，力矩模型如果与策略共享参数，那么「档案 + 物理」看似两根锚，实际可能是同一根绳子的两股。系统会以「有据可查、物理验证」的姿态，更自信地重复旧错。这是本轮必须正面设计的东西：**作者独立性、反例检索、模型独立不变量、记忆隔离与延迟合并**，一个都不能少。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（TETHER-RAS 总览与五不变式）** TETHER-RAS = (FLUID-RAS, ARC, RAGate, TGV, OTT, TSH, ATP, CLG, DAF, AWL, J_TETHER)。五不变式：
(i) **实时流零学习写**（继承 R68 定义 276-i）；
(ii) **证据可追溯**：任何参与决策的档案证据必须带 provenance、时间戳、适用范围与内容哈希，可被审计复算；
(iii) **锚的权限非对称**：档案锚只能移动先验 / 提供否决，不能单独确认；力矩锚可确认 / 否决**物理谓词**，但在 TSH 失效或模型误差超界时只能弃权；
(iv) **无先例即弃权**：检索未达适用性阈值时必须返回 ⊥，不得用最近邻硬凑；
(v) **自作者隔离**：系统自己写入的经验不得作为安全确认证据，只能作为非安全先验，且需延迟合并与独立复核。

**定义 311（epistemic claim 与声明图 CLG）** claim c = (π, P, τ, A, h, deps)，其中 π 为待判命题（如「当前是模态 m_k」「负载为 2kg」「抓取已成功」），P 为 provenance 集合，τ 为有效时间窗，A 为适用范围谓词，h 为内容哈希，deps 为依赖的其他 claim。声明图是有向无环图；任何被依赖 claim 过期 / 被证伪，则下游 claim 自动降级为未消解。这样「一个错误的前提」不会静默地支撑一串结论。

**定义 312（档案记忆与检索算子 ARC）** 档案 D = {(φ_i, c_i, y_i, P_i, t_i, h_i, a_i)}，φ_i 为情境描述子（任务、物体类别、材质、标定版本、环境、负载区间），y_i 为已验证结局，a_i 为作者 / 来源标识。检索 R(q, D; k, filters) 先按结构化过滤（同一标定版本、同一物体类别等），再按语义相似度取 top-k；返回每个案例的引用与其物理签名模板。**检索返回的是候选证据，不是答案。**

**定义 313（检索适用性门 RAGate）** 对候选案例 e 定义适用性 A(e) = trust(a_e) · fresh(t_e; τ) · app(φ_e, φ_t) · rel(q, e)，其中 app 用协变量偏移 / 覆盖度检验（描述子落在档案支持集内），fresh 为指数衰减。仅当 A(e) ≥ τ_admit 且 top-k 覆盖度 ≥ τ_cov 时 e 可入证；否则返回 **negative retrieval** ⊥。**无先例是一个合法且必须被表达的结论**，不是失败。

**定义 314（自作者隔离与反例检索）** 作者独立性 ind(a) ∈ {independent, self, unknown}；self 案例权重上限 w_self < w_ind。检索必须同时执行**支持查询**与**反例查询**（同一情境下结局相反的案例），并返回二者的似然比 LR_arc = P(E_sup|π) / P(E_ref|π) 而非单一相似度。若支持与反例作者高度相关（同一来源、同一批次），按 (1−ρ_author) 折扣。

**定义 315（力矩残差与物理谓词）** 关节力矩测量 τ_m ∈ ℝ^n；名义动力学模型 τ̂_nom = M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_fric(q̇; θ_f) + J^T ŵ_known（含已知负载 / 接触参数 θ），未知外力通过 J^T ŵ_env 进入。残差 r_τ = τ_m − τ̂_nom，任务空间估计 ŵ = (J^T)^† r_τ。物理谓词 π_phys（如「有接触」「负载 ∈ [1.8,2.2]kg」「抓取成功」）通过 ŵ 与假设预测 ŵ_π 的一致性检验：‖ŵ − ŵ_π‖ ≤ b_model + b_sensor。残差本身不是真值，**是模型 + 传感器的联合判据**。

**定义 316（三值力矩验证器 TGV）** 输出 {confirm, refute, abstain}：
- **refute**：‖ŵ − ŵ_π‖ > b_refute（含安全裕度），且 TSH 健康；
- **confirm**：一致性成立且 b_model 足够小、力矩通道健康，并有独立档案 / 交互证据同向；
- **abstain**：TSH 不健康、模型误差界过大、谓词不可观（如纯语义意图）或接触不可达。
**confirm 永远不能单独来自力矩**；refute 可以单独否决物理谓词。

**定义 317（序数力矩检验 OTT）** 当绝对标定不可信但符号 / 单调性可信时，使用**序数**判据：例如「抬升时力矩应单调上升」「夹紧时法向力应随指令增加」「接触瞬间力矩应出现阶跃」。序数检验对仿射零偏 b_0 与增益误差不敏感（差分消去），因此可作为低标定条件下的模型轻量物理锚。TGV 在 metric 不可用时退化为 OTT。

**定义 318（主动力矩探询 ATP）** 信息动作新增 g_torque ∈ 𝒜_info：在安全包络内施加小幅、有界、可撤销的激励（轻推、试抬、轻夹），使某物理谓词的可观测性提升。约束：力 / 位包络、接触预算、时间窗、可撤销性，且必须通过 C-RAS-WM 前缀认证；ATP 与 R69 的看 / 问 / 触共享全局交互预算。ATP 的收益用 VoI_phys = H(π_phys|o) − E[H(π_phys|o, y_τ)]。

**定义 319（力矩通道健康 TSH）** 监测零偏、温漂、饱和、迟滞、摩擦变化、双通道（关节力矩 vs 电机电流 / 估计力矩）一致性；输出健康度 h_τ ∈ [0,1] 与误差界 b_sensor。h_τ < τ_health 或 b_model > b_max ⇒ TGV 强制 abstain。力矩不是「永远可信的物理真值」，而是**有条件可信的仪器**。

**定义 320（依赖感知证据融合 DAF）** 对 claim c，证据 E = {E_arc, E_τ, E_int}。融合前先估有效独立性 ρ_uv（共享 trunk、共享动力学模型、共享作者），则有效权重 w_u = 1 − max_{v≠u} ρ_uv。后验 odds = prior × ∏_u LR_u^{w_u}。**确认门**：至少一个非自作者档案锚与一个物理锚（或两个独立交互源）同向；否则 claim 保持未消解，走 R69 / R68。相关的一致按 (1−ρ) 折扣——这是 R69「k 个正交源」在模型 / 档案侧的镜像。

**定义 321（解析控制器与决策次序）** 每个 tick：① **检索前置**——用当前 claim 查档案，能消解的直接消解（不耗交互）；② 若残留物理谓词且力矩可观测，做 TGV / OTT，必要时 ATP；③ 若仍是语义 / 社交歧义，走 R69 MINT 交互；④ 任一锚弃权或冲突 ⇒ 未消解 ⇒ R69 兜底；⑤ 若连交互也不可行 ⇒ R68 纯保守。检索与力矩都在**安全提交门之前**，且只影响「选哪个模态 / 是否解除保守」，不影响安全包络。

**定义 322（档案写入纪律 AWL）** 只有经过**独立证据确认**且过了冷静期（cool-down）的 claim 才可写入档案；写入时记录完整 provenance、反例、适用条件、模型版本、力矩签名；自作者条目进入隔离区，需 N 个独立任务 / 版本复核后才能提升为可用先例。**绝不把一次交互的回答直接写成事实。**

**定义 323（证书 J_TETHER）** J_TETHER = (J_FLUID, retrieval_log_hash, admit_rate, negative_retrieval_rate, provenance_diversity, torque_health_p95, model_error_bound, ott_ratio, atp_count, daf_conflict_count, archive_write_quarantine)。Valid ⇔ J_FLUID valid ∧ 所有入证档案可追溯 ∧ 无自作者单独确认 ∧ 力矩弃权被尊重 ∧ 写入纪律满足。

**定义 324（严格包含与两级退化）** 若 RAGate 全返回 ⊥、TSH 不健康（TGV 全 abstain）且不使用 ATP，则 TETHER 在每个状态与 FLUID-RAS 逐指令相同；再关闭交互则退化为 R68。新增模块只**删除候选 / 增加证据**，不新增安全许可。

# IP-264 ARC：检索前置（适用性门 + 反例查询 + provenance）
class ArchiveRetriever:
    def __init__(self, index, tau_admit, tau_cov):
        self.index, self.tau_admit, self.tau_cov = index, tau_admit, tau_cov

    def retrieve(self, claim, o_t):
        q = describe(o_t, claim)
        sup = self.index.search(q, filters=same_calib_and_object(o_t), k=4)
        ref = self.index.search(q, filters=same_context_opposite_outcome(o_t), k=4)
        adm = [e for e in sup + ref if applicability(e, o_t) >= self.tau_admit]
        if coverage(adm, q) < self.tau_cov:
            return NegativeRetrieval()                 # 合法结论：无先例
        return Evidence(lr=self.likelihood_ratio(adm),
                        templates=[e.torque_template for e in adm],
                        provenance=hash_set(adm),
                        diversity=author_diversity(adm))

# IP-267 TGV：三值力矩验证（metric + ordinal 退化）
def torque_verify(claim, tau_m, q, qd, qdd, dynamics, tsh):
    if not tsh.healthy(): return Abstain("unhealthy")
    r = tau_m - dynamics.nominal(q, qd, qdd)
    w_hat = task_wrench(r)
    b = dynamics.error_bound() + tsh.sensor_bound()
    if claim.is_physical():
        d = norm(w_hat - claim.predicted_wrench)
        if d > b_refute + b: return Refute(d)
        if b <= b_confirm and tsh.confidence >= tau_h:
            return Confirm(d)                          # 仍需独立证据同向
    if claim.is_ordinal():                             # 零偏 / 增益不敏感
        if not monotone_sign_test(claim.expected_order, tau_m):
            return Refute("ordinal_violation")
        return Confirm("ordinal_ok")
    return Abstain("unobservable")

# IP-270 ATP：有界主动力矩探询（信息动作，也过安全认证）
def active_torque_probe(claim, modes, budget, c_ras_wm):
    if budget.exhausted(): return None
    for g in bounded_probe_candidates(claim):          # nudge / lift-test / squeeze
        if not c_ras_wm.certify_info(g): continue
        voi = entropy(claim.posterior) - expected_entropy(claim.posterior, g)
        if voi - cost(g) > 0: return g
    return None

# IP-271 DAF：依赖感知融合 + 确认门
def fuse(claim, E_arc, E_tau, E_int, rho):
    odds = claim.prior_odds
    for e in [E_arc, E_tau, E_int]:
        if e is None or e.abstain: continue
        odds *= e.lr ** (1 - max(rho[e.name].values()))
    if not has_independent_confirm(E_arc, E_tau, E_int):
        return claim.undetermined(odds)                # 有证据也不定案
    return claim.resolve(odds)

# IP-276 主闭环（继承 FLUID-RAS，仅在不确定性处置处插入 TETHER 层）
def TETHER_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)                          # R68 一次前向
    c, U_cal, thr = M.cof.step(o)                      # R68 标定
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z)
    claim = make_claim(modes, o, U_epi)                # 「哪个模态 / 负载 / 接触」
    # 1) 检索前置：能查到的，不打扰人
    E_arc = M.arc.retrieve(claim, o)
    if not isinstance(E_arc, NegativeRetrieval):
        claim = claim.apply(E_arc, weight=M.w_arc)
    # 2) 物理锚：力矩先验 + 必要时主动探询
    E_tau = M.tgv.verify(claim, M.tau_m, *M.dyn_state()) if claim.is_physical() else None
    g_t = M.atp.propose(claim, modes, M.budget) if claim.still_ambiguous() else None
    if g_t is not None:
        y_tau = M.execute_certified(g_t)               # 带 C-RAS-WM 认证
        E_tau = M.tgv.verify(claim.update(y_tau), M.tau_m, *M.dyn_state())
    # 3) 语义残差才问人（R69）
    g_ask = (M.mint.choose_interaction(modes, o, M.budget)
             if claim.still_ambiguous() and claim.is_semantic() else None)
    E_int = M.cia.execute(g_ask) if g_ask else None
    # 4) 依赖感知融合；没有独立双锚则不定案
    claim = M.daf.fuse(claim, E_arc, E_tau, E_int, M.rho)
    # 5) 风险缩放：消解成功仅用 U_ale；否则 ale + epi（R68 边界）
    U_floor = U_ale + (0.0 if claim.resolved else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode(modes, claim, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 审计 + 仅把「已独立确认且过冷静期」的 claim 写档案
    M.vqa_t.submit_async(claim, E_arc, E_tau, g_ask)
    M.awl.maybe_write(claim)
    return k, lam, mode, claim
```

## 3. 推导

**引理 19（适用性过滤后的检索先验收缩）** 设档案中与当前情境同分布的有效样本量 n_eff = Σ_e A(e)，则检索后验的熵收缩满足 H(π|E_arc) ≤ H(π) − ½ log(1 + n_eff·I_0)（高斯近似，I_0 为单案例信息量）。要点：**不是「检索到越多越好」，而是「适用性加权后的有效样本量」决定收益**；错配案例的 A(e) 低，几乎不收缩后验，只会增加虚假自信。

**引理 20（序数力矩检验对仿射误差的不变性）** 若 τ_m = a·τ_true + b + ε（a>0，b 为未知零偏），则同一情境下两次测量的差 Δτ_m = a·Δτ_true + Δε，零偏 b 被消去；因此符号 / 单调性判据在 a>0 时不变。系：**绝对力矩不可信时，仍可用序数物理检验确认方向性谓词**；但无法用它确认绝对负载值。

**引理 21（自作者记忆的放大上界）** 设未验证 claim 的写入错误率为 δ_m，自作者案例在支持检索中被优先选中的偏置为 β≥1，则单靠档案确认的错误率可放大至 ≈ βδ_m/(1+βδ_m) > δ_m。若执行自作者隔离（w_self<1）、反例检索与作者去相关折扣，则错误率 ≤ δ_m·ρ_author^{k−1} + ε_σ。系：**RAG 的安全性不取决于库有多大，而取决于作者独立性与反例是否被检索**。

**定理 18（TETHER 严格包含 FLUID-RAS / R68）** 在 A99–A101 下，TETHER 的可行动作集是 FLUID-RAS 可行集的子集（新增模块只能否决 / 弃权 / 增加认证信息动作），故任意状态期望风险 ≤ FLUID-RAS；当 RAGate=⊥、TSH 不健康、ATP 禁用时，两者逐指令相同；再关闭交互则与 R68 逐指令相同。安全侧单调不弱，效率侧获得「少问、少保守」的收益。

**定理 19（双锚确认的可靠性上界）** 若 (i) 力矩通道健康且模型误差 ≤ b_model，(ii) 至少一个非自作者档案锚与物理锚同向，(iii) 二者误差相关 ρ<1，则错误确认率 ≤ δ_arc·ρ_τ + δ_τ·ρ_arc + ε_model + ε_sensor；当只有单一锚或 ρ→1 时，退化为单源错误率，**不得确认**。这就是「相关的一致不是票」在档案-物理侧的版本。

**定理 20（检索前置的交互预算收益与安全不变）** 检索前置只会在交互前消解 claim，不改变任何安全约束；若检索消解的是 R69 会去交互的 claim，则交互次数单调不增，且由于 RAGate 的适用性门与自作者隔离，新增的错误消解率被引理 21 界定。故预算节省不以安全为代价；最坏情况是「查不到」，退回 R69，成本仅为一次索引查询。

## 6. 本轮最大风险

**一句话**：TETHER-RAS 把「可信」寄托在「档案有出处、力矩是物理的」上，但**档案可能是系统自己写的旧错，力矩残差又由与策略共享参数的动力学模型计算**——两根锚可能在同一个偏差方向上重合；此时系统会以「有据可查、物理已验证」的姿态把错误**固化进记忆**，形成自我确认的回音室——**被拴住的不是真相，而是自己的过去**。

**次级风险与缓解**：
1. **检索错配 / 陈旧** → RAGate 适用性门 + negative retrieval + 时间衰减；
2. **档案投毒 / 自作者放大** → 作者独立性 + 反例检索 + 自作者隔离 + 引理 21；
3. **力矩模型共模** → OTT 序数不变量 + 双通道 TSH + 定理 19 的 ρ 折扣；
4. **主动探询越界** → 有界 / 可撤销 / 过 C-RAS-WM + 接触预算；
5. **检索延迟击穿实时性** → ANN 索引 + 异步预取 + 检索未命中就走 R69，绝不等检索。

def retrieve(claim, o_t, index):
    q = describe(o_t, claim)
    sup = index.search(q, filters=same_calib_and_object(o_t), k=4)
    ref = index.search(q, filters=same_context_opposite_outcome(o_t), k=4)
    adm = [e for e in sup + ref if applicability(e, o_t) >= TAU_ADMIT]
    if coverage(adm, q) < TAU_COV:
        return NegativeRetrieval()                    # 无先例是合法结论
    return Evidence(lr=likelihood_ratio(adm),
                    templates=[e.torque_template for e in adm],
                    provenance=hash_set(adm),
                    diversity=author_diversity(adm))

# IP-267 TGV：三值力矩验证（metric + ordinal 退化）
def torque_verify(claim, tau_m, q, qd, qdd, dynamics, tsh):
    if not tsh.healthy(): return Abstain("unhealthy")
    w_hat = task_wrench(tau_m - dynamics.nominal(q, qd, qdd))
    b = dynamics.error_bound() + tsh.sensor_bound()
    if claim.is_physical():
        d = norm(w_hat - claim.predicted_wrench)
        if d > B_REFUTE + b: return Refute(d)
        if b <= B_CONFIRM and tsh.confidence >= TAU_H:
            return Confirm(d)                         # 仍需独立证据同向
    if claim.is_ordinal():
        if not monotone_sign_test(claim.expected_order, tau_m):
            return Refute("ordinal_violation")
        return Confirm("ordinal_ok")
    return Abstain("unobservable")

def active_torque_probe(claim, budget, c_ras_wm):
    if budget.exhausted(): return None
    for g in bounded_probe_candidates(claim):
        if not c_ras_wm.certify_info(g): continue
        voi = entropy(claim.posterior) - expected_entropy(claim.posterior, g)
        if voi - cost(g) > 0: return g
    return None

def fuse(claim, E_arc, E_tau, E_int, rho):
    odds = claim.prior_odds
    for e in [E_arc, E_tau, E_int]:
        if e is None or e.abstain: continue
        odds *= e.lr ** (1 - max(rho[e.name].values()))
    if not has_independent_confirm(E_arc, E_tau, E_int):
        return claim.undetermined(odds)
    return claim.resolve(odds)

    E_tau = M.tgv.verify(claim, M.tau_m, *M.dyn_state()) if claim.is_physical() else None
    g_t = M.atp.propose(claim, modes, M.budget) if claim.still_ambiguous() else None
    if g_t is not None:                                # ② 物理探询（认证）
        E_tau = M.tgv.verify(claim.update(M.execute_certified(g_t)), M.tau_m, *M.dyn_state())
    g_ask = (M.mint.choose_interaction(modes, o, M.budget)
             if claim.still_ambiguous() and claim.is_semantic() else None)
    E_int = M.cia.execute(g_ask) if g_ask else None     # ③ 只问语义残差
    claim = M.daf.fuse(claim, E_arc, E_tau, E_int, M.rho)  # ④ 无双锚不定案
    U_floor = U_ale + (0.0 if claim.resolved else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, claim, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(claim, E_arc, E_tau, g_ask)
    M.awl.maybe_write(claim)                           # ⑤ 只有独立确认才入档
    return k, lam, mode, claim
```

## 4. 推导

**引理 19（适用性过滤后的检索先验收缩）** 有效样本量 `n_eff=Σ_e A(e)` 时，`H(π|E_arc) ≤ H(π) − ½log(1+n_eff·I_0)`（高斯近似）。系：收益由**适用性加权后的有效样本量**决定，不是检索条数；错配案例只会增加虚假自信。

**引理 20（序数力矩检验的仿射不变性）** 若 `τ_m=aτ_true+b+ε`（a>0），则 `Δτ_m=aΔτ_true+Δε`，零偏消去；符号 / 单调性判据不变。系：绝对力矩不可信时仍可确认方向性谓词，但无法确认绝对负载值。

**引理 21（自作者记忆的放大上界）** 未验证写入错误率 δ_m、自作者优先偏置 β≥1 时，单靠档案确认的错误率可放大至 `βδ_m/(1+βδ_m)`；执行自作者隔离、反例检索与作者去相关后 `≤ δ_m·ρ_author^{k−1}+ε_σ`。系：RAG 安全取决于作者独立性与反例检索，不取决于库的大小。

**定理 18（TETHER 严格包含 FLUID-RAS / R68）** 在 A99–A101 下，可行动作集是 FLUID-RAS 可行集的子集（新模块只能否决 / 弃权 / 增加认证信息动作），故任意状态期望风险 ≤ FLUID-RAS；RAGate=⊥、TSH 不健康、ATP 禁用时逐指令相同；再关闭交互则与 R68 逐指令相同。

**定理 19（双锚确认的可靠性上界）** 力矩健康且模型误差有界、至少一个非自作者档案锚同向、二者误差相关 ρ<1 时，错误确认率 `≤ δ_arc·ρ_τ + δ_τ·ρ_arc + ε_model + ε_sensor`；只有单一锚或 ρ→1 时退化为单源错误率，**不得确认**。这是「相关的一致不是票」在档案-物理侧的版本。

**定理 20（检索前置的预算收益与安全不变）** 检索前置只在交互前消解 claim，不改变安全约束；若消解的是 R69 会去交互的 claim，交互次数单调不增，新增错误消解率由引理 21 界定。最坏情况是「查不到」退回 R69，成本仅一次索引查询。

## 7. 本轮最大风险

**一句话**：TETHER-RAS 把「可信」寄托在「档案有出处、力矩是物理的」上，但**档案可能是系统自己写的旧错，力矩残差又由与策略共享参数的动力学模型计算**——两根锚可能在同一个偏差方向上重合；此时系统会以「有据可查、物理已验证」的姿态把错误**固化进记忆**，形成自我确认的回音室——**被拴住的不是真相，而是自己的过去**。

**次级风险与缓解**：检索错配 / 陈旧 → RAGate + negative retrieval + 时间衰减；档案投毒 / 自作者放大 → 作者独立性 + 反例检索 + 隔离 + 引理 21；力矩模型共模 → OTT + 双通道 TSH + 定理 19 的 ρ 折扣；主动探询越界 → 有界 / 可撤销 / C-RAS-WM + 接触预算；检索延迟击穿实时性 → ANN + 异步预取，未命中直接走 R69。
