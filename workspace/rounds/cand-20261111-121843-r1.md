# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「通用操作」×「嵌入式系统」）

> 第 54 轮已把技能组合落到动作空间剖面 α_S、组合图 G_S、云边映射 γ_ce 与联合证书 J。本轮追问一个更根本的问题：**「通用」与「可嵌入」是否天然对立？** 核心矛盾 H22：通用操作（跨任务/跨物体/开放指令）通常依赖云端大模型与高带宽，嵌入式端受算力/内存/功耗/实时性硬约束，二者之间存在「能力-资源鸿沟」；H23：把通用策略蒸馏到边端后，动作精度可能保留而**操作语义覆盖**丢失——模型会做动作，但不会做「事」。

## 0. 直觉与动机

**灵感 1（通用操作 = 可编译的中间表示，而非大模型本身）**
直觉：今天「通用操作」几乎等于「更大的 VLA、更多数据」。但这把通用性错误地绑定在参数规模上。更本质的问题是：**是否存在一个与任务、本体、模型都无关的操作指令集，使任何通用任务都能被「编译」进去？** 若存在，通用性就变成「编译器的定义域 + 指令集封闭性」，而不是「模型有多大」。于是提出 **通用操作中间表示 UIR**：`u = (verb, target, constraint, resource_class)`。云端 VLA 只负责把自然语言/视觉任务编译为 UIR 序列，边端只负责执行 UIR——**通用性被从模型里「移植」到了接口里**。

**灵感 2（嵌入式系统 = 操作微内核，而非缩小版大模型）**
直觉：把 VLA 量化/蒸馏后塞进嵌入式，是「把通用性硬塞进资源」；正确的方向是让边端运行一个 **固定、可验证、WCET 可分析的操作微内核 EMM**：它不「理解」任务，只执行一小套**已认证原语控制器**（阻抗、导纳、视觉伺服、力保护）。通用性下沉为「指令集的封闭性 + 微内核绑定的合法性」，从而把不可解释的神经网络风险，替换为可审计的控制原语风险。这是一种**责任边界的迁移**：通用性归云端编译器，安全性归边端微内核。

**灵感 3（语义-资源契约 → 通用性是「资源索引」的，不是绝对的）**
直觉：不存在「无条件通用」的边端系统。通用性应被定义为 **在资源预算 R 下的任务覆盖率** `Gen(π|R)`。每条 UIR 指令携带 **语义-资源契约 SRC**：最坏执行时间、内存、功耗、精度容差，以及对 UIR 前置/后置语义的义务。这样「能不能通用」变成「在 R 下 Gen 曲线的哪个点」，把 H22 的能力-资源鸿沟从口号变成可测量的一维 Pareto 曲线。

**灵感 4（操作降级格 → 资源不足时不是失败，而是有格序的降级）**
直觉：边端资源不足时最危险的不是「做不到」，而是「以为做到了」。引入 **操作降级格 ODL**：`insert_dexterous ≽ insert_compliant ≽ push_align ≽ request_help`。降级必须**目标保持 goal-preserving**——不能把「插入」悄悄降成「推到旁边」。用偏序与单调性保证：资源越少动作越保守，但目标语义不丢失，必要时显式求助，而不是静默失败。

**灵感 5（通用性感知蒸馏 + 资源感知组合 → 与第 54 轮闭环）**
直觉：云端教师蒸馏到 EMM 时，损失不能只约束动作轨迹，还要约束 **opcode 决策边界**（学生是否在同样的语义条件下选同一类原语）与 **契约满足**。这就是 **GAD**。再把它接到第 54 轮的 SCOM 上：技能组合不仅要满足动作兼容 `compat ≥ θ_a`，还要满足 **资源可加性** `Σ c(u) ≤ R_edge`，且每个 opcode 存在合法降级——这就是 **RAC**。至此，动作空间、鲁棒性、资源三维统一。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（通用操作中间表示 UIR）**
`𝕌 = (𝒱, 𝒯, 𝒞, ℛ)`：
- `𝒱` 原语动词集（reach, grasp, place, insert, push, pour, wipe, handover, …）；
- `𝒯` 类型化目标/可供性描述（物体、位姿、区域、力模式）；
- `𝒞` 约束（位姿容差、力/速度上限、避障约束）；
- `ℛ` 实时/资源类（硬实时、软实时、尽力）。
任务编译 `compile: 𝒟_T → 𝕌*`，`u_{1:k} = compile(τ)`。

**定义 122（指令集封闭性与语义覆盖）**
任务分布 `𝒟_T` 上，`Cov(𝕌,𝒟_T) = Pr_{τ∼𝒟_T}[compile(τ) 有定义]`。若 `Cov ≥ 1-ε`，则称 `𝕌` 为 ε-封闭。**关键区分**：覆盖度量的是「能否表达」，不是「能否执行」；表达与执行的差额正是 H22。

**定义 123（嵌入式操作微内核 EMM）**
`M = (𝒪, Ctrl, sched, W, Mem, P)`：`𝒪` 为认证原语，`Ctrl` 为控制器族，`W(u)`/`Mem(u)`/`P(u)` 为最坏时间/内存/功耗上界。若对任意合法 UIR 序列 `u_{1:k}` 有 `Σ W(u_i) ≤ deadline`、`Σ Mem(u_i) ≤ M_budget`、`Σ P(u_i) ≤ P_budget` 且调度确定性成立，则称 `M` 为 **k-安全**。

**定义 124（语义-资源契约 SRC）**
`c(u) = (w_u, m_u, p_u, τ_u, tol_u, sem_u)`：资源上界 + 语义义务 `sem_u`（UIR 前置/后置条件）。绑定 `b: 𝕌 → Ctrl` 满足契约，当且仅当 `W_b(u) ≤ w_u`、`Mem_b(u) ≤ m_u`、`P_b(u) ≤ p_u`，且 `ctrl_b(u)` 在 `tol_u` 内保持 `sem_u`。

**定义 125（资源索引通用性）**
`Gen(π|R) = ∫_{𝒟_T} 1[compile(τ) ∈ dom(π) ∧ feasible(π,R,τ)] dP(τ)`，`R = (compute, mem, power, latency)`。性质：`Gen` 对 `R` 单调不减；对固定 `R`，`Gen` 是该资源下的「通用性切片」。

**定义 126（操作降级格 ODL）**
偏序集 `(𝕆, ≼)`，`u' ≼ u` 表示 `u'` 是 `u` 的**目标保持**弱化（`goal(u') ⊒ goal(u)`，`sem(u')` 蕴含任务目标而非完整规格）。降级算子 `D_R(u) = max{u' ≼ u : feasible(u',R)}`。要求：单调 `R1 ⊆ R2 ⇒ D_{R1}(u) ≼ D_{R2}(u)`；幂等 `D_R(D_R(u)) = D_R(u)`；若 `{u' ≼ u} = ∅`，则显式 `request_help`。

**定义 127（通用性感知蒸馏证书 GDC）**
`GDC = (Δ_act, Δ_sem, Δ_res, evid)`：
- `Δ_act` 动作保真（轨迹/位姿误差）；
- `Δ_sem` 语义边界分歧（教师在「何时选哪类 opcode」上的决策与学生的一致度下降）；
- `Δ_res` 契约违约裕度；
- `evid` 至少含 OOD 任务集与在环 WCET 标定记录。
部署条件：`Δ_act ≤ ε_a ∧ Δ_sem ≤ ε_s ∧ Δ_res ≤ ε_r`。

**定义 128（资源-通用性证书 RGC）**
`RGC = (𝕌, Cov, Gen(·|R), {c(u)}, ODL, GDC)`。若 `Cov ≥ 1-ε`、`Gen(π|R_edge) ≥ g_min`、每个 `u` 有契约合法绑定或合法降级、且 `GDC` 通过，则称方案在资源 `R_edge` 下**可部署通用**。注意：这是**资源索引的**通用性声明，不是无条件通用。

## 2. 关键算法伪代码

### IP-121 UIR 编译与封闭性审计

```python
def compile_task(task, UIR):
    seq = []
    for step in task.semantic_plan:
        verb = UIR.verb_of(step)
        if verb is None:
            return ('uncompilable', step, 'verb_not_in_UIR')
        u = UIR.instantiate(verb, target=step.target,
                            constraints=step.constraints,
                            rclass=step.realtime_class)
        if not UIR.typecheck(u):
            return ('uncompilable', step, 'constraint_type_error')
        seq.append(u)
    return ('ok', seq)

def coverage_audit(tasks, UIR):
    ok = sum(compile_task(t, UIR)[0] == 'ok' for t in tasks)
    return ok / len(tasks)
```

### IP-122 EMM 绑定与 WCET

```python
def bind_and_verify(seq, EMM, R):
    used_t = used_m = used_p = 0
    binds = []
    for u in seq:
        cands = [b for b in EMM.bindings(u) if EMM.satisfies(b, u)]
        if not cands:
            return ('need_degrade', u)
        b = min(cands, key=lambda b: (b.W, b.mem))   # 保守优先
        used_t += b.W; used_m += b.mem; used_p += b.power
        if used_t > R.deadline or used_m > R.mem or used_p > R.power:
            return ('resource_exceeded', u, (used_t, used_m, used_p))
        binds.append(b)
    return ('ok', binds)
```

### IP-123 SRC 校验器

```python
def verify_src(u, b, hw_model):
    if b.W > u.c.w_u or b.mem > u.c.m_u or b.power > u.c.p_u:
        return ('reject', 'resource')
    if not hw_model.wcet_sound(b):            # 在环标定覆盖率
        return ('reject', 'wcet_unsound')
    if not implies(b.ctl_post, u.c.sem_u, tol=u.c.tol_u):
        return ('reject', 'semantic')
    return ('ok',)
```

### IP-124 ODL 降级

```python
def degrade(u, R, EMM, ODL):
    for u2 in ODL.descendants(u):             # 按 ≼ 由上到下
        if not ODL.goal_preserving(u2, u):
            continue
        if bind_and_verify([u2], EMM, R)[0] == 'ok':
            return ('degraded', u2)
    return ('escalate', 'request_help')
```

### IP-125 GAD 通用性感知蒸馏

```python
def gad_distill(teacher, student, D_in, D_ood, UIR, R):
    for batch in D_in:
        u_t = teacher.opcode_logits(batch)
        u_s = student.opcode_logits(batch)
        l_act = action_loss(teacher.act(batch), student.act(batch))
        l_sem = semantic_boundary_loss(u_t, u_s)      # 决策边界对齐
        l_res = contract_penalty(student, UIR, R)
        (l_act + lam_s * l_sem + lam_r * l_res).backward()
    gdc = GDC(
        delta_act=eval_action(student, D_ood),
        delta_sem=opcode_f1_drop(teacher, student, D_ood),
        delta_res=wcet_margin(student, R),
        evid=(D_ood, hardware_in_loop_log))
    return ('ok' if gdc.within() else 'reject', gdc)
```

### IP-126 RAC 资源感知组合

```python
def resource_aware_path(G, task_seq, R_edge):
    # G 为第 54 轮动作兼容图，节点/边附加 SRC 成本
    path = a_star(G, start='root', goal=task_seq,
                  heuristic=lambda n: cost_align(n),
                  constraint=lambda p: sum_src(p) <= R_edge)
    for u in expand(path):
        if not has_legal_binding_or_degrade(u, R_edge):
            return ('infeasible', u)
    return ('ok', path, RGC(UIR, Cov, Gen(path, R_edge), srcs(path), ODL, gdc))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| UIR 编译 | O(|τ|·|𝒱|) | O(|τ|) | 类型系统 sound、封闭性可审计 |
| EMM 绑定 | O(|seq|·|B|) | O(|seq|) | WCET 保守、调度确定 |
| SRC 校验 | O(|seq|) | O(1) | 语义蕴含可判定 |
| ODL 降级 | O(|𝕆|·|seq|) | O(|𝕆|) | 偏序无环、goal-preserving |
| GAD | O(E·|D|) | O(|θ_student|) | OOD 覆盖、边界校准 |
| RAC | O(|V| log|V| + |E|) | O(|V|+|E|) | 资源可加性保守上界 |

**正确性定理（Resource-Indexed Generality Preservation, RIGP）**
假设承接第 54 轮 (A26)–(A28)，并新增：**(A29)** `compile` 在 `𝒟_T` 上以概率 `1-ε` 全定义；**(A30)** EMM 的 `W/Mem/P` 上界是硬件保守上界且调度确定；**(A31)** GAD 在 OOD 上以概率 `1-δ_s` 保持 opcode 语义边界，且 `D_R` 目标保持；**(A32)** 资源可加性忽略并发峰值（或已含安全系数）。
则对任意任务 `τ` 与预算 `R`：

```
P(success(τ)|R) ≥ Cov(𝕌,𝒟_T) · (1-δ_s) · ∏_{u∈compile(τ)} (1 - p_fail(u,R))
```

其中 `p_fail(u,R)` 是 `u` 及其合法降级 `D_R(u)` 均未满足 `goal(u)` 的概率，且被 `sem_u` 违约概率上界约束。**该定理不声称边端复刻云端通用性**；它给出的是资源索引下的下界，差额 `1 - Gen(π|R)` 被显式量化——这正是本方案相比「强行蒸馏」的诚实之处。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| UIR 过粗导致语义不可表达 | 高 | 分层动词表 + 开放词表回退 + coverage 审计 |
| WCET/资源上界在真实并发下失效 | 高 | 硬件在环标定 + 安全系数 + 看门狗 |
| goal-preserving 降级判定主观 | 中 | 形式化 goal 规格 + 人审 + 红队场景 |
| 蒸馏语义边界在长尾 OOD 崩塌 | 高 | OOD 主动采样 + 边界一致性正则 + 拒绝执行 |
| 资源可加性忽略峰值并发 | 中 | 峰值包络 + 资源预留 |

## 6. 本轮最大风险

**一句话**：UIR+EMM 的最大风险是把「通用性」误当成「指令集封闭 + 蒸馏保真」——一旦 UIR 在长尾操作上不可编译、或 WCET/资源契约在真实中断、温度与并发下被打破，系统会在「看似可嵌入」的证书下执行语义降级的错误操作；因此必须以 **分布外 coverage 审计 + 硬件在环 WCET 标定 + 降级动作的 goal-preserving 形式验证** 三重护栏，宁可承认「资源索引下的通用性有明确边界」，也绝不宣称边端复刻了云端的通用性。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-UniOp（UIR×EMM×SRC×ODL×GAD×RAC×RGC）

> 承接第 54 轮产物 v31。本轮把「通用操作」重构为**可编译的中间表示**，把「嵌入式系统」重构为**可验证的操作微内核**，并给出资源索引的通用性证书。核心新增七个 IP：
> - **UIR（Universal Operation IR）**：任务 → 原语序列的通用中间表示与封闭性审计；
> - **EMM（Embedded Manipulation Microkernel）**：认证原语 + WCET/内存/功耗 k-安全的边端微内核；
> - **SRC（Semantic-Resource Contract）**：每条原语的资源上界 + 语义义务契约；
> - **ODL（Operation Degradation Lattice）**：资源不足时的目标保持降级格；
> - **GAD（Generality-Aware Distillation）**：动作 + opcode 边界 + 契约三合一蒸馏；
> - **RAC（Resource-Aware Composition）**：在 SCOM 上叠加资源可加性的组合规划；
> - **RGC（Resource-Generality Certificate）**：可部署通用性的联合证书。
>
> IP 编号：IP-121~IP-127（共 7 个新增），升级 IP-115/116/117/118 以纳入资源维度。

```python
def coverage_audit(tasks, UIR):
    ok = sum(compile_task(t, UIR)[0] == 'ok' for t in tasks)
    return ok / len(tasks)
```

### IP-122 EMM：绑定与 k-安全校验

```python
def bind_and_verify(seq, EMM, R):
    used_t = used_m = used_p = 0
    binds = []
    for u in seq:
        cands = [b for b in EMM.bindings(u) if EMM.satisfies(b, u)]
        if not cands:
            return ('need_degrade', u)
        b = min(cands, key=lambda b: (b.W, b.mem))     # 保守优先
        used_t += b.W; used_m += b.mem; used_p += b.power
        if used_t > R.deadline or used_m > R.mem or used_p > R.power:
            return ('resource_exceeded', u, (used_t, used_m, used_p))
        binds.append(b)
    return ('ok', binds)
```

### IP-123 SRC：契约校验

```python
def verify_src(u, b, hw_model):
    if b.W > u.c.w_u or b.mem > u.c.m_u or b.power > u.c.p_u:
        return ('reject', 'resource')
    if not hw_model.wcet_sound(b):
        return ('reject', 'wcet_unsound')
    if not implies(b.ctl_post, u.c.sem_u, tol=u.c.tol_u):

    return ('ok',)
```

### IP-124 ODL：目标保持降级

```python
def degrade(u, R, EMM, ODL):
    for u2 in ODL.descendants(u):             # 按 ≼ 由上到下
        if not ODL.goal_preserving(u2, u):
            continue
        if bind_and_verify([u2], EMM, R)[0] == 'ok':
            return ('degraded', u2)
    return ('escalate', 'request_help')
```

### IP-125 GAD：通用性感知蒸馏

```python
def gad_distill(teacher, student, D_in, D_ood, UIR, R):
    for batch in D_in:
        u_t = teacher.opcode_logits(batch)
        u_s = student.opcode_logits(batch)
        l_act = action_loss(teacher.act(batch), student.act(batch))
        l_sem = semantic_boundary_loss(u_t, u_s)
        l_res = contract_penalty(student, UIR, R)
        (l_act + lam_s * l_sem + lam_r * l_res).backward()
    gdc = GDC(
        delta_act=eval_action(student, D_ood),
        delta_sem=opcode_f1_drop(teacher, student, D_ood),
        delta_res=wcet_margin(student, R),
        evid=(D_ood, hardware_in_loop_log))
    return ('ok' if gdc.within() else 'reject', gdc)
```

### IP-126 RAC：资源感知组合

```python
def resource_aware_path(G, task_seq, R_edge):
    path = a_star(G, start='root', goal=task_seq,
                  heuristic=lambda n: cost_align(n),
                  constraint=lambda p: sum_src(p) <= R_edge)
    for u in expand(path):
        if not has_legal_binding_or_degrade(u, R_edge):
            return ('infeasible', u)
    return ('ok', path)
```

### IP-127 RGC：资源-通用性证书

```python
def issue_rgc(UIR, tasks, G, ODL, gdc, R_edge, g_min):
    cov = coverage_audit(tasks, UIR)
    if cov < 1 - eps:
        return ('reject', 'coverage_gap', cov)
    path = resource_aware_path(G, tasks.goal, R_edge)
    if path[0] != 'ok':
        return ('reject', 'composition', path)
    gen = Gen(path, R_edge)
    if gen < g_min:
        return ('reject', 'generality_below_budget', gen)
    if gdc.status != 'ok':
        return ('reject', 'distillation', gdc)
    return ('ok', RGC(UIR, cov, gen, srcs(path), ODL, gdc))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| UIR | O(|τ|·|𝒱|) | O(|τ|) | 类型系统 sound、封闭性可审计 |
| EMM | O(|seq|·|B|) | O(|seq|) | WCET 保守、调度确定 |
| SRC | O(|seq|) | O(1) | 资源不超界、语义蕴含可判定 |
| ODL | O(|𝕆|·|seq|) | O(|𝕆|) | 偏序无环、降级目标保持 |
| GAD | O(E·|D|) | O(|θ_student|) | OOD 覆盖、opcode 边界校准 |
| RAC | O(|V| log|V| + |E|) | O(|V|+|E|) | 资源可加性保守上界 |
| RGC | O(E162 + |V| log|V|) | O(|V|+|E|) | 证书各分量独立可验 |

**正确性定理（Resource-Indexed Generality Preservation, RIGP）**
假设承接第 54 轮 (A26)–(A28)，新增：**(A29)** `compile` 在 `𝒟_T` 上以概率 `1-ε` 全定义；**(A30)** EMM 的 `W/Mem/P` 为硬件保守上界且调度确定；**(A31)** GAD 在 OOD 上以概率 `1-δ_s` 保持 opcode 语义边界，且 `D_R` 目标保持；**(A32)** 资源可加性忽略并发峰值（或已含安全系数）。
则对任意任务 `τ` 与预算 `R`：

```
P(success(τ)|R) ≥ Cov(𝕌,𝒟_T) · (1-δ_s) · ∏_{u∈compile(τ)} (1 - p_fail(u,R))
```

其中 `p_fail(u,R)` 为 `u` 与其合法降级 `D_R(u)` 均未满足 `goal(u)` 的概率，被 `sem_u` 违约概率上界约束。**该定理只承诺资源索引下界，不承诺边端复刻云端通用性**；差额 `1-Gen(π|R)` 被显式量化。

## 7. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| UIR 过粗导致语义不可表达 | 高 | 分层动词表 + 开放词表回退 + coverage 审计 |
| WCET/资源上界在真实并发下失效 | 高 | 硬件在环标定 + 安全系数 + 看门狗 |
| goal-preserving 降级判定主观 | 中 | 形式化 goal 规格 + 人审 + 红队场景 |
| 蒸馏语义边界在长尾 OOD 崩塌 | 高 | OOD 主动采样 + 边界一致性正则 + 拒绝执行 |
| 资源可加性忽略峰值并发 | 中 | 峰值包络 + 资源预留 |
| 云端重编译与边端灰度的版本漂移 | 中 | UIR 版本号 + 证书签名 + 回滚锚点 |

## 8. 本轮最大风险

**一句话**：UIR+EMM 的最大风险是把「通用性」误当成「指令集封闭 + 蒸馏保真」——一旦 UIR 在长尾操作上不可编译、或 WCET/资源契约在真实中断、温度与并发下被打破，系统会在「看似可嵌入」的证书下执行语义降级的错误操作；因此必须以 **分布外 coverage 审计 + 硬件在环 WCET 标定 + 降级动作的 goal-preserving 形式验证** 三重护栏，宁可承认「资源索引下的通用性有明确边界」，也绝不宣称边端复刻了云端的通用性。
