# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「强化学习训练」×「迭代验证」）

> R69 把不确定性拆成 aleatoric / epistemic，用 VoI 决定「要不要问、问谁」，并用流似然给标定层补了一条第二意见。但 R69 的策略是**冻结的**：它只在测试时消歧，从不把「问到的答案、探针的结果、失败的模态」变成下一轮的能力。更严重的是，R69 自陈的最大风险——流模态分布不可信导致「自信地追问幻影」——本质上是一个**训练问题**，而 R69 只能用 MCG 把它挡在门外（越界即退回 R68），永远修不好。
>
> 本轮两个灵感正好补上「学习」与「可信地学习」两块缺失：
> - **强化学习训练**：把交互结果从「一次性证据」变成「可训练信号」，让策略学会何时问、问什么、问完之后怎么改；但 RL 是一台天然的**模态坍缩机**——最大化回报会压掉 R69 赖以生存的多峰性。所以训练必须是有界、风险敏感、保模态的。
> - **迭代验证**：训练不是一次更新，而是一条**只能向上走的棘轮**——每个候选策略必须在分阶段验证阶梯上通过所有门，且任意时刻「安全上界」不得上升；失败候选不仅回滚，还要变成后续训练的负约束。多轮迭代会放大「偷看」与「验证集过拟合」，因此验证必须是 anytime-valid 的。
>
> 核心命题：**把 R69 的「测试时消歧」升级为「训练—验证闭环」：用有界残差 RL 学习，用保模态信赖域防止坍缩，用证据门控把交互数据变成训练数据（而不是投毒入口），用 anytime-valid 棘轮保证任意一次晋级都不抬高安全上界；当没有候选通过、残差为零、或验证被污染时，逐指令退化为 R69。** 命名 **TEMPER-RAS**（Training with Evidence-gated Multimodal Policy Evolution under Risk）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我怎样在不变坏的前提下，越问越会问**」——不确定性不只是刹车和提问，也可以是一段被严格验证过的成长。

## 0. 直觉与动机

**灵感 1（强化学习训练 → 冻结的策略不会变聪明，只会变保守）**
直觉：R69 的流策略是一次离线流匹配的产物，之后再也不变。它能在测试时问一次，但问完就把数据扔了；下一次遇到同一种歧义，仍然从零开始问。这在「交互预算极贵」的设定下是巨大浪费：系统付出了最贵的信息获取成本，却没有把「哪类问题值得问、问了之后答案长什么样」沉淀下来。RL 训练把这条飞轮接上：任务回报 + 信息回报共同塑造策略，让「问」本身成为可优化的技能，而不是一个手工阈值触发的例外分支。直觉上，这让系统从「会执行」变成「会学习如何执行」。

**灵感 2（迭代验证 → 验证不是一次考试，而是一条只能向上的棘轮）**
直觉：单次验证只回答「这个候选在这一次抽样里看起来行不行」。但当训练迭代几十上百次，候选是**自适应生成**的，测试集会被反复「偷看」，平均分可以通过选择偏差慢慢爬上去，而真实安全可能早已滑落。迭代验证的正确形态不是「再跑一遍测试」，而是**棘轮 + 序贯检验**：安全上界只允许单调不升；每个候选都必须通过固定阶梯（单元契约 → 仿真 → 离线回放 → 影子 → 灰度 → 全量）；每个门的「通过」用 anytime-valid 的 e-process 表述，允许随时停、随时看，且不会因多次偷看而虚报置信。失败的候选不是浪费，而是被写入能力账本的**负约束**，防止下一轮换个方式再犯。

**灵感 3（RL 是模态坍缩机 → 训练必须保模态）**
直觉：R69 的全部安全论证都建立在「多峰动作分布及其校准权重」上。而标准 RL 目标（最大化期望回报）恰好会做两件最危险的事：把低概率但高损失的模态**压没**（mode collapse），以及把高概率但任务无关的模态**放大**（mode inflation）。这不是调参问题，而是目标函数的结构性问题。因此本轮把 RL 限制在**有界残差**里：新策略 = R69 冻结流场 + 一个范数受限、低秩的残差速度场；再叠加**模态级信赖域**：已认证模态的质量只能在窄带内变化，除非跨轮证据明确判它虚假。零残差时严格等于 R69——这是本轮的理论锚点。

**灵感 4（交互数据是最贵的训练数据，也是最脏的）**
直觉：R69 的交互数据恰恰是信息量最高的样本——它们落在模型最不确定、任务最敏感的地方。但同一条数据也是最危险的：人会撒谎、会共谋、会用「看起来很合理」的答案做社会工程。R69 用「k 个正交证据源一致」挡住了单次决策被立刻污染，却没有回答「这条被污染的数据会不会在下一轮训练里变成永久偏见」。如果直接把交互日志喂给 RL，R69 的「被证实的错误」就会升级为「被写进权重的错误」。所以训练前必须有一道**证据门控标注**：交互标签只是弱证据，需跨轮、跨源、可因果验证后才允许进入训练；未过门的一律隔离。

**灵感 5（标定不是门，是可以修的；但只能在独立数据上修）**
直觉：R69 的 MCG 发现 ECE 越界就禁用 VoI、退回纯保守。这是正确的安全动作，却是糟糕的学习动作——系统永远停在「不敢问」的档位。TEMPER 把标定从「门」升级为「可修复量」：在非自选择的留出数据上，用重要性加权拟合温度/向量标定，只有在校准误差下降且所有安全门不回归时才允许部署；否则保持 R69 的保守档。关键在「非自选择」：交互数据是按模型自己的不确定性采样的，直接在上面标定会把偏差学得更自信。更一般地，**新层必须是旧层的严格泛化**：零残差、零晋级、任一门失败，都必须逐指令回到 R69。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TEMPER-RAS 总览）** TEMPER-RAS = (BRL, CRL, MTR, MVA, IVL, AVR, CLR, IGL, ICR, PSM, VQAuditor-T, AIC-TRAIN, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）：训练/验证只发生在离线影子进程，在线环路只读取已签名的冻结快照；
(ii) **有界残差**：新策略与 R69 参考策略的差被参数化为范数受限、低秩的残差速度场；零残差 ⇒ 逐指令等于 R69；
(iii) **棘轮晋级**：任一候选只有在全部门通过、且认证安全上界不升时才能换装；失败即原子回滚；
(iv) **训练数据证据纪律**：交互标签不得作为真值直接入训，需跨轮跨源佐证并通过因果许可检查；未过门者进入隔离区，永不静默入训。

**定义 311（有界残差策略 BRL）** 参考流场 v⁰ = v_θ^{R69}(x_s,s|o)。候选 v⁺ = v⁰ + P_r Δv_φ，其中 P_r 为秩 r 投影，‖P_r Δv_φ‖_{L∞} ≤ ε_r。对应 ODE 流 π⁺ 与 π⁰。π⁺|Δv=0 = π⁰。行为偏差由引理 19 控制：‖ξ⁺ − ξ⁰‖ ≤ (e^{L_v H} − 1)·ε_r / L_v（L_v 为速度场 Lipschitz 常数）。

**定义 312（约束风险敏感目标 CRL）** 设回报 G = Σ_t γ^t r_t，安全代价 C_s = Σ_t c_t^safe，交互次数 N_int。候选优化：
max_φ E_{π⁺}[G]
s.t. CVaR_β(C_s) ≤ ε_s，E[N_int/T] ≤ b_int，
∀k ∈ Cert：ŵ_k(π⁺) ≥ (1−δ_cov)·ŵ_k(π⁰)，且 D_KL(ŵ(π⁺)‖ŵ(π⁰)) ≤ δ_mode。
拉格朗日乘子 λ_s, λ_b, μ_k 有界于 [0, λ_max]，防止「用安全换回报」的角点解；乘子与残差范数一并写入证书。

**定义 313（模态级信赖域 MTR）** 对每个已认证模态 k，质量带 δ_cov,k 与逐模态 KL 上界 δ_mode,k 由该模态的跨轮佐证强度决定：证据越强，带越窄（越不许被 RL 悄悄改掉）；临时模态（定义 314）不参与 VoI，也不允许被「顺手剪掉」，只能走认证/废弃流程。

**定义 314（跨轮模态认证 MVA）** 模态状态机：`provisional → certified → deprecated`。模态 m 在 T_cert 轮内被 ≥k_src 个正交证据源（仿真、离线回放、交互日志、留出集、几何/形式检查）一致支持，才升为 certified；连续 T_dep 轮无佐证且通过安全审计，才可降为 deprecated。**provisional 模态不得驱动 VoI、不得作为训练目标、不得被无证据剪枝**——这正是把 R69 的「证据纪律」从单次决策推广到跨轮学习，直接回应「幻觉模态诱发追问」与「真模态被坍缩」。

**定义 315（迭代验证阶梯 IVL）** 六级阶梯 L0 契约（J_FLUID 有效、签名可验）→ L1 仿真分布内 → L2 离线回放（历史交互 + 部署日志）→ L3 影子（并行运行、不驱动执行器）→ L4 灰度（小流量、可回滚）→ L5 全量。每级有门族 G = {任务回报, 安全代价, 模态覆盖, 模态校准, VoI 评论器校准, OOD, 交互质量}。候选必须逐级通过，不得跳级；任一级失败即回滚并写入负约束。

**定义 316（Anytime-valid 棘轮 AVR）** 对每个门 g，构造 e-value E_g^{(k)}，在「候选不优于/不安全」的零假设下满足 E[E_g] ≤ 1。晋级判据：
min_g log E_g^{(k)} ≥ log(1/α)，且安全门的上置信界 UCB_α(C_s) ≤ ε_s。
则在候选自适应生成、可随时观察、可选停时的条件下，P(存在某一轮晋级了不安全策略) ≤ α（引理 21）。同时维护认证安全上界 B_k = UCB_α(C_s^{(k)})，棘轮要求 B_{k+1} ≤ B_k。

**定义 317（棘轮与能力账本 CLR）** 能力账本 L = {(模态/行为, 证据来源, 回归用例, 认证版本)}。每个候选必须通过 L 中全部回归用例；失败即回滚到上一认证策略 π^‡ 并把该候选写入负约束缓冲。账本只增不减（除非走废弃流程），因此「曾经会的能力」不会因一次训练而静默消失。

**定义 318（训练数据证据门控标注 IGL）** 每条交互标签 ℓ 附带来源证明 prov(ℓ)。用 Dawid–Skene 类潜真值模型得后验 p(z|ℓ, prov)。入训条件（三者同时）：
(a) p(z|ℓ, prov) ≥ τ_lab；
(b) 至少 k_src 个正交来源一致；
(c) **因果许可**：用离线策略评估（IPS/DR）给出的「使用该标签后留出任务风险下降」的下置信界 > 0。
未过门者进入 quarantine，不参与任何梯度更新；同一来源反复失败会降低其 prov 权重。

**定义 319（交互感知标定修复与经验 VoI 评论器 ICR）** 部署分布 p_deploy 与自选择分布 p_self 不同，用重要性权重 w = p_deploy/p_self 在留出数据上拟合标定映射 T（温度/向量/等渗），目标为加权 ECE。接受条件：ECE_weighted(T) < ECE(identity) 且全部门不回归；否则保持 R69 的 MCG 保守档。经验 VoI 评论器 q_ψ(g,o) 预测「执行 g 后任务风险的实际下降」，仅在留出交互集上 ECE(q_ψ) ≤ τ_v 且后悔界可接受时替换 R69 的解析 VoI；否则回退到解析 VoI。

**定义 320（训练威胁模型 AIC-TRAIN）** ℰ_train = ℰ_FLUID × {标签投毒, 奖励黑客, 后门触发, 验证集过拟合, 模态注入, 非平稳漂移}。其中「模态注入」指投毒数据在训练中制造一个看似被多源支持的假模态，随后被 MVA 误认证；「验证集过拟合」指候选学会通过验证而非变安全。ℰ_train 作为对抗训练与红队验证的生成器，而不是一次性测试集。

**定义 321（非平稳与遗忘）** 交互日志按年龄加权回放（半衰期 τ_age）；漂移检测器监测 p_deploy 变化。检测到显著漂移时：**暂停晋级**（棘轮不前进）、扩大探索但只在安全包络内、并强制重跑 L2–L3；绝不以「新分布」为由降低安全门。

**定义 322（策略签名与原子换装 PSM）** 每个认证策略生成签名清单 manifest = (权重哈希, 残差范数, 证书哈希, 账本哈希, 训练数据 provenance 根, temper_ver)。双槽 A/B 存储，换装为原子指针切换（<1 帧），回滚为确定性指针还原。在线实时环路只读不可变快照，永不执行学习写操作。

**定义 323（参与式训练审计 VQAuditor-T）** 审计对象从「单次交互」扩展到「训练—验证过程」：候选是否只对公开验证集好（隐藏测试差距）、provenance 是否完整、认证模态是否在训练后静默消失、标定是否诚实、负约束是否被绕过。审计结论回灌账本与负约束缓冲，并作为下一轮 L0 门的一部分。

**定义 324（证书 J_TEMPER）** J_TEMPER = (J_FLUID, 各门 e-value, 安全上界 B_k, 模态质量带, ECE_mode, ECE_VoI, ‖Δv_φ‖, provenance_root, ledger_hash, manifest_hash, rollback_ptr, temper_ver)。Valid ⇔ 全部门通过 ∧ 棘轮条件 B_{k+1} ≤ B_k ∧ provenance 完整 ∧ 签名可验。

**定义 325（严格退化与包含）** 若 (a) Δv_φ = 0，或 (b) 无候选通过，或 (c) 任一门/审计失败，或 (d) 检测到训练污染/漂移且未清除，则策略逐指令退化为 R69，验证与控制行为完全一致。故 R69 是 TEMPER 在「永不训练」边界上的严格退化；安全侧不做任何让步。

**定义 326（训练预算与停止准则）** 设第 k 轮训练的边际收益为 ΔJ_k。当 anytime-valid 下置信界显示 ΔJ_k ≤ 0，或验证成本超过收益，或连续 M 轮候选全被回滚时停止训练并锁定当前认证策略；「不训练」本身是合法且被证书承认的动作。

# IP-264 BRL：有界残差流策略（零残差 = R69）
class BoundedResidualFlow:
    def __init__(self, ref_flow, residual_net, rank=4, eps_r=0.05):
        self.v0, self.dv = ref_flow, residual_net       # v0 冻结
        self.Pr, self.eps_r = low_rank_proj(rank), eps_r

    def velocity(self, x, s, z):
        r = self.Pr(self.dv(x, s, z))                   # 低秩残差
        return self.v0(x, s, z) + self.eps_r * torch.tanh(r)  # 范数受限

    def sample(self, o_t, K, N_step=2):
        z = trunk(o_t); xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0 / N_step) * self.velocity(xs, i / N_step, z)
        return [decode(x) for x in xs]

# IP-265/266 CRL + MTR：约束风险敏感更新 + 模态信赖域
def train_candidate(ref, data, cert_modes, lam):
    for batch in data:
        G, Cs, Nint, modes = rollout(ref, batch)
        loss = -G.mean() + lam.s * cvar(Cs, beta) + lam.b * n_int_rate(Nint)
        for k, m in cert_modes.items():
            loss += lam.mu[k] * band_penalty(modes.w[k], m.w0, m.delta)
        loss += lam.mode * kl_mode(modes.w, cert_modes.w0)
        update_residual(loss)                            # 只更新 Δv_φ

# IP-267 MVA：跨轮模态状态机（provisional/certified/deprecated）
def certify_modes(mode, evidence_by_round, k_src, T_cert, T_dep):
    support = orthogonal_sources(mode, evidence_by_round)
    if mode.state == "provisional" and len(support) >= k_src \
       and rounds_with_support(mode) >= T_cert:
        mode.state = "certified"
    elif mode.state == "certified" and rounds_without(mode) >= T_dep:
        mode.state = "deprecated"                       # 需安全审计通过
    return mode

def gate_label(label, prov, sources, holdout):

    return ("train", label) if ok else ("quarantine", label, prov)

def validate_and_ratchet(cand, ledger, alpha):
    B_prev = ledger.last_certified.safety_ub
    for level in ["L0_contract", "L1_sim", "L2_replay",
                  "L3_shadow", "L4_canary", "L5_fleet"]:

        if min(log(e[g]) for g in GATES) < log(1 / alpha):
            return rollback(ledger, reason=f"{level}:{argmin_gate(e)}")
        if ucb(cand.safety_cost) > B_prev:               # 棘轮

    ledger.promote(cand, B_new=ucb(cand.safety_cost))

# IP-277 主闭环：高频在线环路（只读冻结快照，零学习写）
def TEMPER_act(M, o_t):
    snap = M.snapshot.read()                             # 签名快照，不可变
    z, o = snap.mtm.forward(o_t)
    U_ale, U_epi, modes, _ = snap.fmp.decompose(snap.fmp.sample(o, snap.K))
    # R69 的 VoI 决策保留；仅当 ICR 认证时使用经验 VoI 评论器
    voi = snap.voc(o, modes) if snap.voc_certified else snap.mint.model_voi
    g = snap.mint.choose(modes, voi, o, snap.budget)
    lam = snap.r69_risk_scale(U_ale, U_epi, g)
    mode = snap.select_mode(modes, lam)
    tau = snap.pi_sigma.dispatch(mode.a[:snap.k]) * lam
    return tau
```

## 3. 推导

**引理 19（有界残差 ⇒ 行为与模态有界漂移）** 若参考流场 Lipschitz 常数 L_v，残差满足 ‖P_r Δv_φ‖_{L∞} ≤ ε_r，则同一噪声初始 x_0 下，π⁺ 与 π⁰ 的轨迹差满足 ‖ξ⁺ − ξ⁰‖ ≤ (e^{L_v H} − 1)·ε_r / L_v（离散 Heun 下同阶）。系：模态原型的位移 ≤ 该界，故 R69 已认证的安全包络至多被 ε_r 规模地扰动；令 ε_r → 0 即逐指令回到 R69。

**引理 20（模态信赖域 ⇒ 熵不坍缩）** 若所有认证模态满足质量带 |ŵ_k⁺ − ŵ_k⁰| ≤ δ_cov,k，则 H_mode(π⁺) ≥ H_mode(π⁰) − Σ_k |log ŵ_k⁰ + 1|·δ_cov,k − O(δ²)。即：模态熵的下降速率被预算显式限制；标准 RL 的「赢者通吃」在本约束下不能在一轮内压掉任何认证模态。系：**保模态不是正则技巧，而是可证书化的约束**。

**引理 21（Anytime-valid 晋级错误控制）** 对每个门构造非负 e-process E_g^{(k)}，在零假设（候选不优/不安全）下 E[E_g] ≤ 1。若晋级要求 min_g log E_g^{(k)} ≥ log(1/α)，则由 e-process 的可选停时性质，P(∃k：晋级不安全候选) ≤ α。对比：若每轮用固定显著性水平 α 的普通检验，K 轮后族错误率上界为 1 − (1−α)^K；当 K = 50、α = 0.05 时约 92%。故「迭代验证」必须配 anytime-valid 统计，否则验证越多次越不安全。

**引理 22（投毒标签的传播上界）** 设单源欺骗率 δ_p、正交源间欺骗相关 ρ<1，IGL 要求 k_src 源一致，则有毒标签入训比例 ≤ δ_p·ρ^{k_src−1} + ε_σ。进一步，由引理 19 与模态信赖域，任何单轮由毒标签引起的策略偏移 ≤ O(ε_r + δ_cov)；因此投毒不能在单轮内造成无界漂移。系：**证据门控把「投毒」从一次性事故降级为有界、可回滚的扰动**；但跨轮潜伏仍可能绕过，需审计（定义 323）。

**定理 18（棘轮安全与 R69 严格包含）** 在 A99–A102（Lipschitz 流场、e-process 有效性、正交源相关 ρ<1、漂移暂停晋级）下，TEMPER 部署策略的认证安全上界单调不升：B_{k+1} ≤ B_k；且任意一次换装都可原子回滚到 π^‡。当 Δv=0、无候选通过、任一门失败或污染未清除时，TEMPER 与 R69 逐指令相同。故 R69 是「永不训练」边界，TEMPER 在安全侧不弱于 R69，在效率侧获得「学习收益」。

**定理 19（标定修复不越过安全包络）** 若 ICR 只在加权留出集上改变模态权重/VoI，且接受条件包含「全部门不回归」与「模态质量仍在信赖域内」，则修复后的 VoI 决策落在 R69 的可行决策集内；ECE 下降只改变「问不问」的收益估计，不改变安全认证与执行包络。故修复失败时保持 MCG 保守档不会引入新的不安全性。

## 6. 本轮最大风险

**一句话**：TEMPER-RAS 的全部收益押在「验证阶梯能代表真实部署分布、且候选无法绕过它」这一前提上——**若 RL 学会的是「通过验证」而不是「变得安全」（验证集过拟合、规范博弈、跨轮潜伏的后门），棘轮就会把一次被误认证的退化永久锁进部署策略，而且因为盖了「已认证」的章，后续轮次反而更难发现它——训练得越好，错得越牢。**

**次级风险与缓解**：
1. **模态坍缩仍可能缓慢发生** → 有界残差 + 模态级信赖域 + MVA 跨轮认证，三重结构约束；
2. **投毒通过多轮累积** → IGL 证据门控 + 负约束缓冲 + VQAuditor-T 的 provenance 审计；
3. **验证被候选 gaming** → 隐藏/轮换测试集 + 独立验证者 + 契约/因果检查 + E309 红队；
4. **非平稳导致旧能力失效** → 年龄加权回放 + 漂移期暂停晋级 + 能力账本回归；
5. **训练成本与实时预算冲突** → 训练完全离线、在线只读冻结快照、原子换装 <1 帧，实时预算与 R69 基本持平。

class BoundedResidualFlow:
    def velocity(self, x, s, z):
        r = self.Pr(self.dv(x, s, z))                    # 低秩残差
        return self.v0(x, s, z) + self.eps_r * tanh(r)   # 范数受限

# IP-265/266 CRL + MTR：约束风险敏感更新
def train_candidate(ref, data, cert_modes, lam):

        G, Cs, Nint, modes = rollout(ref, batch)
        loss = (-G.mean() + lam.s * cvar(Cs, beta)
                + lam.b * n_int_rate(Nint)
                + sum(lam.mu[k] * band_penalty(modes.w[k], m.w0, m.delta)
                      for k, m in cert_modes.items())
                + lam.mode * kl_mode(modes.w, cert_modes.w0))

    B_prev = ledger.last_certified.safety_ub
    for level in ["L0", "L1", "L2", "L3", "L4", "L5"]:
        e = {g: gate_eprocess(cand, g, level) for g in GATES}
        if min(log(e[g]) for g in GATES) < log(1 / alpha):
            return rollback(ledger, reason=f"{level}:{argmin_gate(e)}")
        if ucb(cand.safety_cost) > B_prev:               # 棘轮
            return rollback(ledger, reason=f"{level}:safety_ratchet")
        if not ledger.regression_pass(cand):
            return rollback(ledger, reason=f"{level}:capability_regression")
    ledger.promote(cand, B_new=ucb(cand.safety_cost))
    return atomic_swap(cand)                             # <1 帧

# IP-272 ICR：交互感知标定修复
def repair_calibration(model, deploy_p, self_p, holdout):
    w = density_ratio(deploy_p, self_p, holdout)
    T = fit_temperature(model.mode_logits, holdout, weights=w)
    if weighted_ece(model, T, holdout) < weighted_ece(model, ID, holdout) \
       and gates_pass(model, T):
        return T
    return None                                          # 保持 R69 MCG 保守档

# IP-277 在线环路：只读签名快照，零学习写
def TEMPER_act(M, o_t):
    snap = M.snapshot.read()                             # 不可变、已签名
    z, o = snap.mtm.forward(o_t)
    U_ale, U_epi, modes, _ = snap.fmp.decompose(snap.fmp.sample(o, snap.K))
    voi = snap.voc(o, modes) if snap.voc_certified else snap.mint.model_voi
    g   = snap.mint.choose(modes, voi, o, snap.budget)
    lam = snap.r69_risk_scale(U_ale, U_epi, g)
    mode = snap.select_mode(modes, lam)
    return snap.pi_sigma.dispatch(mode.a[:snap.k]) * lam
```

## 4. 推导

**引理 19（有界残差 ⇒ 有界漂移）** `‖P_r Δv_φ‖_{L∞}≤ε_r` 且参考流 Lipschitz 常数 `L_v` 时，`‖ξ⁺−ξ⁰‖ ≤ (e^{L_v H}−1)ε_r/L_v`。系：模态原型位移同阶有界，R69 已认证安全包络至多被 `ε_r` 规模扰动；`ε_r→0` 回到 R69。

**引理 20（模态信赖域 ⇒ 熵不坍缩）** 若所有认证模态满足 `|ŵ_k⁺−ŵ_k⁰|≤δ_cov,k`，则 `H_mode(π⁺) ≥ H_mode(π⁰) − Σ_k|log ŵ_k⁰+1|δ_cov,k − O(δ²)`。系：标准 RL 的「赢者通吃」在本约束下不能单轮压掉认证模态；保模态是可证书化约束，不是正则技巧。

**引理 21（Anytime-valid 晋级错误控制）** 每门 e-process 在零假设下 `E[E_g]≤1`；晋级要求 `min_g log E_g ≥ log(1/α)`，则由可选停时性质 `P(∃k 晋级不安全候选)≤α`。对比：每轮固定 α 的普通检验，K 轮族错误率 `1−(1−α)^K`；K=50、α=0.05 时约 92%。故迭代验证必须 anytime-valid，否则验证越多次越不安全。

**引理 22（投毒标签传播上界）** 单源欺骗率 `δ_p`、正交源相关 `ρ<1`、要求 `k_src` 源一致时，有毒标签入训比例 `≤δ_p ρ^{k_src−1}+ε_σ`；结合引理 19 与信赖域，单轮策略偏移 `≤O(ε_r+δ_cov)`。系：投毒被降级为有界、可回滚扰动；跨轮潜伏仍需 VQAuditor-T 审计。

**定理 18（棘轮安全与 R69 严格包含）** 在 A99–A102（Lipschitz 流场、e-process 有效、`ρ<1`、漂移暂停晋级）下，`B_{k+1}≤B_k`，任意换装可原子回滚 `π^‡`；当 `Δv=0`、无候选通过、任一门失败或污染未清除时，TEMPER 与 R69 逐指令相同。故 R69 = 「永不训练」边界；安全不让步，效率获学习收益。

**定理 19（标定修复不越过安全包络）** ICR 只在加权留出集上改模态权重/VoI，且接受条件含「全门不回归 + 模态仍在信赖域」，故修复后 VoI 决策落在 R69 可行决策集内；ECE 下降只改「问不问」的收益估计，不改安全认证与执行包络；修复失败保持 MCG 保守档不引入新风险。

## 7. 本轮最大风险

**一句话**：TEMPER-RAS 的全部收益押在「验证阶梯能代表真实部署分布、且候选无法绕过它」这一前提上——**若 RL 学会的是「通过验证」而不是「变得安全」（验证集过拟合、规范博弈、跨轮潜伏的后门），棘轮就会把一次被误认证的退化永久锁进部署策略，而且因为盖了「已认证」的章，后续轮次反而更难发现它——训练得越好，错得越牢。**

**次级风险与缓解**：模态坍缩缓慢发生（有界残差 + 模态信赖域 + MVA 三重约束）；投毒跨轮累积（IGL 证据门控 + 负约束缓冲 + provenance 审计）；验证被 gaming（隐藏/轮换测试集 + 独立验证者 + 因果检查 + E309 红队）；非平稳导致旧能力失效（年龄加权回放 + 漂移暂停晋级 + 能力账本）；训练成本与实时预算冲突（训练全离线、在线只读冻结快照、原子换装 <1 帧）。
