# 第 66 轮（承接第 65 轮「VISTA 故障可归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「闭环控制」×「情感语音」）

> 第 65 轮的自述风险非常尖锐：VISTA 的归因依赖「故障属于有限假设集、且视觉与几何失效相互独立」；真实故障是未知复合类型，透明/镜面/对抗 patch 让视觉与几何共享同一 OOD 源，FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，而且系统因「已经归因」而更自信地继续执行。第 65 轮在「未来工作」里留了一句：引入第三个物理独立通道。本轮就做这件事，但换来的不是免费午餐——**人本身就是闭环的一部分**。因此本轮的核心命题不是「再加一个模态」，而是：
>
> **把人类情感语音当作闭环里的第三条接地证据，同时用闭环控制的可辨识性理论先回答一个更根本的问题：这条证据说的是「机器人做错了」，还是「机器人因为我刚才的反应而改变了行为」？只有通过内生性门的情感证据才允许进入故障归因；情感只允许单向收紧安全裕度，绝不允许单独放松。**

## 0. 直觉与动机

**灵感 1（情感语音 → 物理传感器之外的第三条通道）**
直觉：相机和力传感器都是"机器感知机器"，它们可能共享同一个分布外失效源（透明物体既骗深度也骗接触几何）。人的语音是**声学**通道，硬件与物理机理都不同：当机器人即将压到人手、或把玻璃杯捏出细裂纹时，人可能先发出吸气、音高骤升、语速加快、一声"哎"——这些**副语言（paralinguistic）**信号在视觉/力觉尚未越界前就已出现。但要诚实：情感识别跨文化、跨说话人、易被语义内容和语境混淆，且人可以说反话、可以伪装。所以它不是真值，是**第四条可错证据**；它最大的价值不在"更准"，而在**错误结构不同**，因而可能打破视觉与几何的共因失效。

**灵感 2（闭环控制 → 人环是内生系统，不是被动传感器）**
直觉：如果机器人一检测到"人不安"就减速，人会因为机器人减速而安心，语音随之平复——这时语音的变化是**控制器自己造成的**，不是新的物理故障证据。这就是闭环控制里的**内生性/反馈偏置**：控制律 u_t 依赖 y_{1:t−1}，而 y_t 又依赖 u_t（人是对机器人行为的响应）。把 y 直接当外生证据喂给 FIR，会把"控制器诱导的安抚"误读成"故障解除"，把"必要但令人不适的操作"误读成"机器人故障"。更糟的是，若以"让人平静"为目标，会形成 Goodhart：系统学会回避一切令人不适但必要的动作——表面舒适，实则放弃任务与安全。

**灵感 3（闭环控制 → 用激励与工具变量做可辨识性）**
直觉：系统辨识告诉我们，闭环下要分离"输入→输出"的因果，需要**外部激励**或**工具变量**。这里工具变量可以是机器人**任务规划给出的、尚未被人反应污染的指令分量**；激励可以是**安全的微动、空动作或澄清提问**（social probe），目的从"估几何参数"改为"打破情感反馈的混杂、最大化条件互信息 I(故障; y | u)"。这把第 65 轮的 AFA（故障判别探针）升级为「**社会激励探针 SEP**」：探针首先是为了**让因果变得可辨识**，而不是为了多测一个力。

**灵感 4（三灵感合流 → ECHO：Emotional Closed-loop Human-loop Observability，情感语音 × 闭环控制的人环可观测安全仲裁）**
闭环：副语言似然 PSL → 人环隐状态观测 HSL → 闭环内生性/可辨识性 ACI → 社会接地仲裁 SGA（门控后并入 FIR-E）→ 安全激励探针 SEP/AFA-E → 情感参考调节器 ARG（单向收紧）→ 块级认证前缀 CSC-E → 证书 J_echo。第 65 轮把"接触"拆成前/中/后；ECHO 把"人"从**环境干扰**提升为**闭环内一个可观测但内生的一层**——它不是上帝视角的裁判，而是一个会因控制器动作而改变读数的传感器。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → FIR-E**：故障假设集增 `H_social`（人类不安/误读/无关因素）；情感证据仅在 ACI 门通过后进入似然。
- **AFA → AFA-E/SEP**：探针目标增"降低闭环混杂、提高 κ_soc"；新增 `ask`（澄清提问）、`explain`（先解释再动）、`dither`（安全微动激励）。
- **RSC-V → RSC-E**：增 `r_human`，且**单向**——只允许变大，绝不因"人看起来很放松"而缩小。
- **WCV-V → WCV-E**：搜索域增人类舒适约束集 `C_h`（软约束、只收紧）。
- **CSC → CSC-E**：认证前缀 `k*` 同时受 ARG 的速率上限与舒适裕度约束。
- **AIC-V → AIC-E**：干扰集增讽刺/假意安抚/背景人声/文化偏移/多旁观者，以及"人也被同一视觉错觉骗"的共因。
- **CSP-V → CSP-E**：技能图增 `explain / ask / retreat / handover` 社会元技能。
- **J_vista → J_echo**：证书增 `affect_posterior, aci_margin, governor_state, consent_flag, content_free_hash`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（ECHO 闭环）**：ECHO = (VISTA, PSL, HSL, ACI, SGA, SEP/AFA-E, ARG, RSC-E/WCV-E, CSC-E, CSP-E, AIC-E, J_echo)。定位：VISTA 的"人环内生通道"升级。不变式：**副语言特征端侧计算、不转写内容、不落盘原始音频；情感只能单向收紧安全裕度；情感证据进入故障归因前必须通过 ACI 门；实时流只做声学特征、门控查表与 ARG 限幅，零学习写操作。**
- **定义 234（副语言观测与 PSL）**：语音帧 → 副语言特征 `y^s_t ∈ ℝ^{d_s}`：F0 轮廓及其一/二阶差分、短时能量、语速/发声率、jitter/shimmer、谐噪比 HNR、谱倾斜、停顿率。映射到隐情感 `z_t=(arousal, valence, urgency)` 的似然 `p(z|y^s)`，并给 split-conformal 上界 `q_s(α)`。**禁止使用 ASR 转写内容**：内容既高延迟又涉及隐私，且"说什么"与"有多急"在因果上可分离。
- **定义 235（人环隐状态与舒适动力学 HSL）**：`x^h_t=(comfort, trust, arousal) ∈ ℝ³`，动力学
  `x^h_{t+1} = f_h(x^h_t, u_t, ξ_t) + w_t`，
  观测
  `y^s_t = g_s(x^h_t, u_t) + v_t`。
  关键：`g_s` 显式含两条 `u_t` 通路——**声学耦合**（机器人噪声直接污染麦克风）与**行为耦合**（人因机器人动作改变情绪）。前者是直接混杂，后者是反馈内生。
- **定义 236（闭环内生性与情感故障证据）**：控制律 `u_t = π(u_task, y^s_{1:t−1}, post_{1:t−1})`。定义朴素关联 `I(F; y^s)` 与条件关联 `I(F; y^s | u_{1:t})`，其中 `F` 为物理故障指示。情感故障证据取残差化形式
  `e_soc = y^s − E[y^s | u_{1:t}]`，
  或等价地用条件互信息。**只有 `e_soc` 允许进入 FIR-E 的似然；原始 `y^s` 只允许进入 ARG。**
- **定义 237（情感通道可辨识性 ACI）**：定义
  `κ_soc = I(F; y^s | u_{1:t}) / (I(F; y^s) + ε) ∈ [0,1]`，
  内生性缺口 `Γ = 1 − κ_soc`。门规则：
  `gate_soc = 1 ⇔ κ_soc ≥ κ_min 且 bootstrap 下界 I_lb(F; y^s | u) > δ_soc`。
  当 `gate_soc=0` 时输出 `affect_unidentifiable`，情感证据**不得用于归因**（只能用于单向收紧）。直觉：`κ_soc` 低意味着语音里的"信息"大部分由机器人自己的动作解释掉了，再当证据就是在读自己的回音。
- **定义 238（安全激励探针 SEP）**：探针集 `A_s = {dither, ask, explain, null_social, press, ...}`，选择
  `a* = argmax_{a∈A_s} I(F; y^s(a) | u_{1:t})`，
  s.t. 预测力/形变 ≤ 安全限、预测舒适下降 ≤ ε_c、且已获同意。与第 65 轮 AFA 的差别：SEP 的首要目标是**提高条件互信息（打破闭环混杂）**，其次是判别故障；`ask/explain` 是零接触探针，用于在物理探针不安全时仍能激励出可辨识反应。
- **定义 239（ARG 情感参考调节器）**：维护安全裕度 `m_t`（越大越保守）。更新
  `m_{t+1} = clip(m_t + η·max(0, d_t − θ_dead), m_base, m_max)`，
  其中 `d_t` 为舒适/紧迫的复合失调量。**单向性**：`m_t ≥ m_base`，情感只能使 `m` 增大；放松（`m` 减小）必须同时满足：(i) 物理通道独立给出健康证据，(ii) 人类显式同意，(iii) 速率限幅。线性化下环路增益 `β = |∂d/∂m · η| < 1`、含死区与限幅时闭环收缩，不会因反馈自激振荡。
- **定义 240（SGA 社会接地仲裁）**：把门控后的 `e_soc` 作为 `H_social` 与其他故障假设的附加证据；冲突时按"**物理硬安全优先、情感只收紧**"的字典序处理。SGA 明确：人**不是 oracle**——人可以错、可以反讽、可以因文化而表达不同；故 `H_social` 的后验不得单独触发对物理故障的放行。
- **定义 241（FIR-E 扩展归因）**：`ℋ_E = ℋ ∪ {H_social}`；似然在 `gate_soc=1` 时用 `p(e_soc|H)` 增广，`gate_soc=0` 时该项退化为均匀（无信息）。归因确定阈值、熵门、定向处置沿用第 65 轮，但**任何处置都不得因 `H_social` 而放松物理裕度**。
- **定义 242（RSC-E 定向球）**：在第 65 轮 `r_geo/r_force/r_model` 之外增 `r_human`，表示"人类行为/意图不确定度"。`r_human` **单调不减**；仅当连续多次独立物理证据健康且人类同意时以极慢速率衰减。融合 `r = √(r_geo²+r_force²+r_model²+r_human²)` 只进 WCV-E 的保守方向。
- **定义 243（WCV-E 人环约束压缩）**：搜索域
  `B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ C_h(m_t)`，
  其中 `C_h` 为舒适/速率约束（软约束，只收紧：`m` 增大则速度上限、力上限、块长上限同步收紧）。交集为空则回退 `B(φ̂,r)` 并置 `human_conflict=True`。
- **定义 244（CSC-E 情感感知认证前缀）**：`k* = min(k*_VISTA, k_ARQ(m_t), m)`，其中 `k_ARG` 由 ARG 的速率上限反解。执行 `k*` 步后强制重规划与再归因；若 `d_t` 在块内越死区，立即早停并进入 SGA。
- **定义 245（AFA-E / SEP 选择）**：在 `gate_soc=0` 且故障归因模糊时，优先选能提升 `κ_soc` 的探针（`dither/ask/explain`）；若易损/未同意，则退回纯物理探针或被动观测。探针的收益函数为"判别增益 + 可辨识增益"，显式惩罚舒适代价。
- **定义 246（AIC-E 情感对抗认证）**：干扰集
  `ℰ_E = ℰ_V × ℰ_affect × ℰ_social`，
  `ℰ_affect` 含讽刺、假意安抚、刻意夸张、情绪抑制；`ℰ_social` 含背景人声、多旁观者、文化/语言偏移、麦克风遮挡。并显式建模**共因**：同一视觉错觉同时骗过机器人视觉与人类判断（此时"人看起来没事"不能作为放行证据）。证书增 `aic_e_ver`。
- **定义 247（CSP-E 社会技能规划）**：技能图增 `explain`（先说明再执行）、`ask`（澄清意图/同意）、`retreat`（拉开距离）、`handover`（移交人类）；每条边需 `Valid(J_echo)`；社会技能的成本含 `λ_h·H(P(H|e_soc))` 与舒适代价。
- **定义 248（ECHO 证书 J_echo）**：`J_echo = (J_vista, affect_posterior, aci_margin κ_soc, gate_soc, governor_state m_t, consent_flag, content_free_hash, aic_e_ver)`。验证：
  `Valid(J_echo) ⇔ Valid(J_vista) ∧ (gate_soc=1 ∨ 未将情感用于归因) ∧ m_t ≥ m_base ∧ 同意与内容无关性成立 ∧ aic_e_ver 为当前版本`。

## 2. 关键算法骨架

```python
# PSL + HSL：端侧副语言 → 情感后验；内容绝不离开设备
feat = prosody.extract(audio_frame)          # F0/energy/rate/jitter/HNR/tilt
z_post = psl.infer(feat)                     # p(z | y^s)，conformal 校准

# ACI：闭环内生性门 —— 只有"机器人动作解释不掉"的部分才是证据
u_hist = control_history(window)
e_soc = residualize(feat, u_hist)            # y^s - E[y^s | u]
kappa = cond_mi(fault_hist, feat, u_hist) / (mi(fault_hist, feat) + EPS)
gate = (kappa >= KAPPA_MIN) and (bootstrap_lb(fault_hist, feat, u_hist) > DELTA_SOC)

# SGA：门控后并入 FIR-E；H_social 不得放松物理裕度
post = fir_e.attribute(phases, e_soc if gate else None)
h_star, ambiguous = argmax(post), post[argmax(post)] < 1 - DELTA_FI

# ARG：单向收紧（情感只能更保守）
d = comfort_distress(z_post, post)
m = clip(m + ETA * max(0.0, d - THETA_DEAD), M_BASE, M_MAX)
speed_cap, force_cap, H_cap = arg.bounds(m)  # 只收紧，不放松

# SEP：模糊且可辨识性不足时，先做"让因果可辨识"的探针
if gate == 0 and ambiguous:
    a = sep.choose(post, kappa, phi_hat, f_safe, consent, fragile)
    if a in ('ask', 'explain', 'dither'):
        execute_social_probe(a)              # 零接触或安全微动
        feat = prosody.extract(next_audio()); e_soc, gate = aci.refresh(feat)

# CSC-E：认证前缀同时受不可逆视界与情感速率上限约束
k_star = min(csc.certified_prefix(A, post, m_irreversible, alpha_chunk),
             csc_e.rate_prefix(m), m_irreversible)
for a in A[:k_star]:
    dispatch(a)
    if arg.monitor(z_post).distress_beyond_deadzone:
        break                                 # 实时早停 → 重归因 / SGA
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（内生通道的价值条件）**：设故障 `F`、语音 `Y`、机器人动作历史 `U`。朴素证据的信息量 `I(F;Y) = I(F;Y|U) + [I(F;U) − I(F;U|Y)]`，方括号项即**内生性偏差** `B`。若 `B>0`（控制器对故障有反应），用朴素似然会系统性高估证据、造成过度自信与误归因；只有条件信息 `I(F;Y|U)` 才是可直接归因的因果分量。故加入情感通道的净收益为正 ⇔ `κ_soc` 超过由 `B` 与噪声决定的阈值；否则该通道**比没有更糟**。这解释了为什么"多一个模态"不是免费的。
- **引理 10（ARG 闭环稳定性）**：将舒适环线性化为 `d_t = g·m_t + h·d_{t−1} + ν_t`，`g<0`（越保守越不 distress）。在死区 `θ_dead`、速率限幅 `|Δm|≤Δ_max` 与增益 `η` 下，若 `β=|g·η|<1` 且 `|h|<1`，则闭环是收缩映射，`m_t` 收敛到唯一不动点，不产生自激振荡；延迟 `τ` 使稳定域进一步收缩为 `β < 1/(1+τ)`。
- **定理 9（ECHO 端到端安全-可辨识）**：在 A88–A94 下：(1) 情感证据仅在 `κ_soc` 过门后进入归因，未知复合故障仍由第 65 轮机制判 `ambiguous`；(2) 物理硬安全优先，`H_social` 永不放松 `m` 与 `r_*`；(3) `m_t` 有界、`k*` 受 `m` 与不可逆视界双重约束，块承诺不放大风险；(4) 视觉/力/情感任一失效时按字典序降级，证书链显式标注 `gate_soc / consent / affect_unidentifiable`。
- **定理 10（单向性防 Goodhart）**：由于 `m_t ≥ m_base` 且情感只增不减，任何以情感为输入的策略都不可能把物理安全裕度降到基线以下；故情感通道无法被"优化到好看"来换取物理风险。代价是**活力风险**：过度收紧会导致任务停滞——这被显式建模为 liveness 约束（超时 + 解释 + 独立证据恢复），而非隐藏副作用。
- **实时性**：副语言特征端侧 <0.3ms（每 20ms 一帧）、ACI 门查表 <0.05ms、ARG 限幅 <0.01ms、CSC-E 早停 <0.02ms；语义流承担 PSL 推断、ACI 重估、SEP 规划，目标实时路径 ≤2.7ms（A95 修订契约）。

## 2. 形式化定义（完整版）

**定义 233（ECHO 闭环）** ECHO 是 VISTA 的"人环内生通道"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 PSL（副语言似然）、HSL（人环状态观测）、ACI（可辨识性门）、SGA/FIR-E（社会接地仲裁）、SEP/AFA-E（社会激励探针）、ARG（单向参考调节器），并原位升级 RSC-V→RSC-E、WCV-V→WCV-E、CSC→CSC-E、CSP-V→CSP-E、AIC-V→AIC-E、J_vista→J_echo。不变式：**副语言特征端侧计算、不转写内容、不落盘原始音频；情感只能单向收紧安全裕度；情感证据进入故障归因前必须通过 ACI 门；实时流只做声学特征、门控查表与 ARG 限幅，零学习写操作。**

**定义 234（副语言观测与 PSL）** 语音帧 → 副语言特征 `y^s_t ∈ ℝ^{d_s}`：F0 轮廓及一/二阶差分、短时能量、发声率、jitter/shimmer、谐噪比 HNR、谱倾斜、停顿率。映射到隐情感 `z_t=(arousal, valence, urgency)` 的似然 `p(z|y^s)`。由于跨说话人/文化/噪声存在分布漂移，用 split-conformal 在标定集上取非一致性分数分位数 `q_s(α)`，给分布无关覆盖。**禁止使用 ASR 转写内容**：内容延迟高、涉隐私，且"说什么"与"有多急"在因果上可分离；证书只记 `content_free_hash`（特征哈希，不可逆）。

**定义 235（人环隐状态与舒适动力学 HSL）** `x^h_t=(comfort, trust, arousal) ∈ ℝ³`，
`x^h_{t+1}=f_h(x^h_t,u_t,ξ_t)+w_t`，`y^s_t=g_s(x^h_t,u_t)+v_t`。
`ξ_t` 为外生因素（任务难度、旁观者、个人事务）。`g_s` 显式含两条 `u_t` 通路：
- **声学耦合** `g_ac`：机器人电机/风噪直接污染麦克风——这是直接混杂，可用设备自身动作谱做前馈抵消；
- **行为耦合** `g_beh`：人因机器人动作改变情绪——这是反馈内生，是 ACI 要处理的核心。
把二者分开建模，是"情感语音"能成为证据而非回音的前提。

**定义 236（闭环内生性与情感故障证据）** 控制律
`u_t = π(u_task, y^s_{1:t−1}, post_{1:t−1})`。
定义朴素关联 `I(F;y^s)` 与条件关联 `I(F;y^s|u_{1:t})`。情感故障证据取残差化形式
`e_soc = y^s − E[y^s|u_{1:t}]`，
或等价用条件互信息。**只有 `e_soc` 允许进入 FIR-E 的似然；原始 `y^s` 只允许进入 ARG。** 这是"读证据"与"读回音"的分界。

**定义 237（情感通道可辨识性 ACI）**
`κ_soc = I(F;y^s|u_{1:t}) / (I(F;y^s)+ε) ∈ [0,1]`，`Γ=1−κ_soc`。
门规则
`gate_soc = 1 ⇔ κ_soc ≥ κ_min ∧ I_lb(F;y^s|u) > δ_soc`，
其中 `I_lb` 为 bootstrap/置换检验下界，`δ_soc` 为最小可判别信息。`gate_soc=0` 时输出 `affect_unidentifiable`，情感证据**不得用于归因**，只能用于单向收紧。直觉：`κ_soc` 低说明语音里的"信息"大部分被机器人自己的动作历史解释掉了；此时再当证据，就是在读控制器的回音。

**定义 238（安全激励探针 SEP）** `A_s={dither, ask, explain, null_social, press, rub, tap, lift}`，
`a* = argmax_{a∈A_s} [ I(F;e_soc(a)|u_{1:t}) − λ_c·cost_h(a) ]`，
s.t. 预测力/形变 ≤ 安全限、预测舒适下降 ≤ ε_c、且已获同意。与第 65 轮 AFA 的差别：SEP 的首要目标是**提高条件互信息（打破闭环混杂）**，其次才是判别故障。`ask`（澄清意图/同意）、`explain`（先说明再动）、`dither`（安全微动）是零接触或极低接触探针，用于易损/未同意/高不确定场景。

**定义 239（ARG 情感参考调节器）** 维护安全裕度 `m_t`（越大越保守）：
`m_{t+1}=clip(m_t+η·max(0, d_t−θ_dead), m_base, m_max)`，
`d_t` 为舒适/紧迫复合失调量。**单向性**：`m_t≥m_base`，情感只能使 `m` 增大；放松（`m` 减小）必须同时满足 (i) 物理通道独立健康证据、(ii) 人类显式同意、(iii) 速率限幅。线性化 `d_t=g·m_t+h·d_{t−1}+ν_t`（`g<0`），若 `β=|g·η|<1`、`|h|<1`，闭环为收缩映射；延迟 `τ` 使稳定域收缩为 `β<1/(1+τ)`。死区 `θ_dead` 抑制抖动，限幅 `|Δm|≤Δ_max` 抑制过冲。

**定义 240（SGA 社会接地仲裁）** 把门控后的 `e_soc` 作为 `H_social` 与其他故障假设的附加证据；冲突时按"**物理硬安全优先、情感只收紧**"的字典序处理。SGA 明确：人**不是 oracle**——人可以错、可以反讽、可以因文化而表达不同；故 `H_social` 的后验不得单独触发对物理故障的放行。归因确定阈值、熵门、定向处置沿用第 65 轮，但任何处置都不得因 `H_social` 而放松物理裕度。

**定义 241（FIR-E 扩展归因）** `ℋ_E = ℋ ∪ {H_social}`，`ℋ={H0,H_geo,H_force,H_model,H_vis,H_policy}`。似然在 `gate_soc=1` 时用 `p(e_soc|H)` 增广；`gate_soc=0` 时该项退化为均匀（无信息）。新增定向处置：
- **H_social**：不放松任何物理球；增大 `r_human`、降低任务速率、触发 `explain` 或 `ask`；若同时物理通道异常，则 `H_social` 与物理假设**并列**而非替代。
- 共因（人也被骗）：若 `H_vis` 与 `H_social` 同向而 `H_force` 健康，仍须判 `ambiguous` 并保守降级，禁止用"人没事"抵消视觉异常。

**定义 242（RSC-E 定向球）** 在 `r_geo/r_force/r_model` 之外增 `r_human`。`r_human` **单调不减**；仅当连续 `N_rec` 次独立物理证据健康且人类同意时，以极慢速率 `γ_rec≪1` 衰减。融合
`r=√(r_geo²+r_force²+r_model²+r_human²)`
只进 WCV-E 的保守方向；H_social 只增 `r_human`，不动其他球。

**定义 243（WCV-E 人环约束压缩）** 搜索域
`B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ C_h(m_t)`，
`C_h` 为舒适/速率约束（软约束，只收紧：`m` 增大则速度上限、力上限、块长上限同步收紧）。交集为空则回退 `B(φ̂,r)` 并置 `human_conflict=True` 写入 J_echo。CVaR 尾部 `n_worst=8`，并按 `P(H|e_soc)` 做归因边缘化。

**定义 244（CSC-E 情感感知认证前缀）**
`k* = min(k*_VISTA, k_ARG(m_t), m)`，
其中 `k_ARG` 由 ARG 的速率上限反解（保证块内 `Δd` 不超过死区），`m` 为不可逆视界。执行 `k*` 步后强制重规划与再归因；若 `d_t` 在块内越死区，立即早停并进入 SGA。

**定义 245（AFA-E / SEP 选择）** 在 `gate_soc=0` 且故障归因模糊时，优先选能提升 `κ_soc` 的探针（`dither/ask/explain`）；若易损/未同意，则退回纯物理探针或被动观测。收益函数为"判别增益 + 可辨识增益 − 舒适代价"，并显式惩罚未经同意的接触。

**定义 246（AIC-E 情感对抗认证）** `ℰ_E=ℰ_V×ℰ_affect×ℰ_social`。`ℰ_affect` 含讽刺、假意安抚、刻意夸张、情绪抑制、情绪突变；`ℰ_social` 含背景人声、多旁观者、文化/语言偏移、麦克风遮挡。并显式建模共因 `ℰ_common`：同一视觉错觉同时骗过机器人视觉与人类判断。`ρ_dir` 在 `ℰ_E` 上重算（`n_cert 128→160`，其中 32 给情感/社会/共因）。**共因下不要求归因正确，只要求判 `ambiguous` 并安全降级。**

**定义 247（CSP-E 社会技能规划）** 在 CSP-V 的块级 A* 上增社会元技能：`explain`（先说明再执行）、`ask`（澄清意图/同意）、`retreat`（拉开距离）、`handover`（移交人类）。每条块边需 `Valid(J_echo)`；软约束代价增 `λ_h·H(P(H|e_soc))`（情感归因熵）与舒适代价 `λ_c·d_t`。

**定义 248（ECHO 证书 J_echo）**
`J_echo=(J_vista, affect_posterior, κ_soc, gate_soc, m_t, consent_flag, content_free_hash, aic_e_ver)`。
验证：
`Valid(J_echo) ⇔ Valid(J_vista) ∧ (gate_soc=1 ∨ 未将情感用于归因) ∧ m_t≥m_base ∧ consent_flag=1 ∧ content_free_hash 不可逆 ∧ aic_e_ver 为当前版本`。
审计链新增：情感是否被用于归因（`gate_soc`）、为何收紧（`m_t`）、是否获同意（`consent_flag`）、是否只用了副语言（`content_free_hash`）。

```python
class ProsodicSocialLikelihood:
    """端侧副语言 → 隐情感后验。绝不调用 ASR，不落盘原始音频。"""
    def extract(self, frame):
        f0 = pitch_track(frame)                       # 轮廓
        return np.array([
            f0.mean(), f0.std(), np.diff(f0).mean(),  # 音高与变化
            rms(frame), speaking_rate(frame),
            jitter(frame), shimmer(frame), hnr(frame),
            spectral_tilt(frame), pause_rate(frame),
        ])

    def infer(self, feat, q_s):
        z = self.model(feat)                          # p(z|y^s) 均值/方差
        valid = self.conformal_ok(feat, q_s)          # 分布内?
        return z, valid                               # 不可观测时 valid=False

class HumanStateLatent:
    """x^h=(comfort,trust,arousal)；显式分离声学耦合与行为耦合。"""
    def update(self, x, u, z, robot_noise_psd):
        y_clean = z - self.g_ac(u, robot_noise_psd)   # 先扣声学混杂
        return self.f_h(x, u) + self.K @ (y_clean - self.g_beh(x, u))
```

### IP-226 ACI（核心：闭环内生性门）

```python
class AffectiveChannelIdentifiability:
    """只有机器人动作历史解释不掉的情感分量才允许归因。"""
    def __init__(self, kappa_min=0.35, delta_soc=0.02, n_boot=200):
        self.kappa_min, self.delta_soc, self.n_boot = kappa_min, delta_soc, n_boot

    def residualize(self, y, u_hist):
        # E[y|u] 用非参数回归/线性高斯近似；残差 = 因果候选分量
        return y - self.predict_under_action(y, u_hist)

    def margin(self, fault_hist, y, u_hist):
        mi_joint = mutual_info(fault_hist, y)
        mi_cond  = conditional_mutual_info(fault_hist, y, u_hist)
        return mi_cond / (mi_joint + EPS), mi_cond

    def gate(self, fault_hist, y, u_hist):
        kappa, mi_cond = self.margin(fault_hist, y, u_hist)
        lb = bootstrap_lower(mi_cond, self.n_boot)     # 置换检验下界
        ok = (kappa >= self.kappa_min) and (lb > self.delta_soc)
        return ok, kappa, ('ok' if ok else 'affect_unidentifiable')
```

```python
        rho = fir.signature(phases)
        logp = {h: np.log(fir.lik[h](rho) + 1e-12) + np.log(prior[h])
                for h in HYP_E}                          # 含 H_social
        if gate:
            for h in HYP_E:
                logp[h] += np.log(self.lik_soc[h](e_soc) + 1e-12)
        # gate=0：lik_soc 退化为均匀 → 情感不提供信息
        post = softmax(logp)
        h_star = max(post, key=post.get)
        ambiguous = post[h_star] < 1 - DELTA_FI
        return post, h_star, ambiguous

    def directed_demote(self, h_star, balls, m, H):
        if h_star == 'H_social':
            balls['r_human'] = min(R_MAX, KAPPA_H * balls['r_human'])
            m = min(M_MAX, m + ETA * M_STEP)            # 只收紧
        elif h_star in ('H_geo', 'H_force', 'H_model'):
            fir.directed_demote(h_star, balls, w_vis, H) # 沿用第 65 轮
        return balls, m
```

### IP-229 ARG（单向参考调节器）

```python
class AffectiveReferenceGovernor:
    """情感只收紧：m 单调不减（除显式同意 + 独立物理证据）。"""
    def __init__(self, eta=0.3, theta_dead=0.15, m_base=0.0, m_max=1.0,
                 delta_max=0.05):
        self.eta, self.theta_dead = eta, theta_dead
        self.m_base, self.m_max, self.delta_max = m_base, m_max, delta_max
        self.m = m_base

    def step(self, d_t):
        dm = self.eta * max(0.0, d_t - self.theta_dead)
        dm = min(dm, self.delta_max)
        self.m = min(self.m_max, max(self.m_base, self.m + dm))
        return self.m

    def release(self, phys_healthy, consent, k=1):
        # 放松需要：独立物理证据健康 + 人类同意；且速率极慢
        if phys_healthy and consent:
            self.m = max(self.m_base, self.m - self.delta_max / (10 * k))
        return self.m

    def bounds(self, m):
        return dict(speed_cap=1 - 0.6 * m, force_cap=1 - 0.7 * m,
                    H_cap=int(H_MAX * (1 - 0.5 * m)))
```

```python
def ECHO_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow, audio = obs
    # ———— 语义流 ————

    # 1) VISTA 原有：块生成 + 视觉证据 + 阶段签名
    A = M.ach.propose(x_prime, H=M.H)

    phases = M.stage.split(M.residual_log, visual)

    feat, psl_valid = M.psl.infer(M.psl.extract(audio), M.q_s)

    gate, kappa, tag = M.aci.gate(M.fault_hist, feat, M.u_hist)

    post, h_star, ambiguous = M.sga.attribute(phases, e_soc, gate, M.prior)

    if not ambiguous:
        M.balls, M.m = M.sga.directed_demote(h_star, M.balls, M.m, M.H)

    # 4) ARG：无论归因是否确定，情感都单向收紧
    d_t = comfort_distress(feat, x_h)
    M.m = M.arg.step(d_t)
    caps = M.arg.bounds(M.m)

    # 5) 规划 + 认证前缀（受 m 与速率上限双重约束）
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))

                                        M.alpha_chunk),
                 M.csc_e.rate_prefix(M.m), M.m_irreversible)

    # 6) 实时执行 + 情感早停
    K_safe, EV_exec, cert_exec = realtime_step_echo(M, delta_f_req, tau,

                      execution_loss_grad(K_safe, EV_exec, M.balls))

    rho_dir = M.aic_e.certify(tau, x_prime, M.phi_hat, M.balls, post, M.m)
    return M, K_safe, EV_exec, build_j_echo(
        cert_exec, J_vista=M.j_vista, affect_posterior=post,
        kappa_soc=kappa, gate_soc=gate, m_t=M.m, consent_flag=M.consent,
        content_free_hash=hash_features(feat), aic_e_ver=AIC_E_VERSION)
```

## 4. 推导

**引理 9（内生通道的价值条件）** 设 `F` 物理故障、`Y` 语音、`U` 机器人动作历史。由互信息链式分解，
`I(F;Y) = I(F;Y|U) + I(F;U) − I(F;U|Y)`。
方括号 `B = I(F;U) − I(F;U|Y)` 即**内生性偏差**：当控制器对故障有反应（`I(F;U)>0`），朴素 `I(F;Y)` 把"控制器反应"也算作证据，系统性高估。只有 `I(F;Y|U)` 是可归因的因果分量。设归因用朴素似然时的有效信息为 `I_naive = I(F;Y)`，用 ACI 门控后为 `I_gate = I(F;Y|U)`；在 Laplace 近似下归因错误率 `err ∝ exp(−n·I)`。故加入情感通道的净收益
`Δerr ∝ exp(−n·I(F;Y|U)) − exp(−n·I(F;Y))`，
其符号由 `κ_soc = I(F;Y|U)/I(F;Y)` 与噪声共同决定：存在阈值 `κ*`，`κ_soc>κ*` 时通道有益，否则**比不加更糟**（用朴素似然会被回音带偏）。这给出 ACI 门的理论依据，也解释了"多一个模态不是免费的"。∎

**引理 10（ARG 闭环稳定性）** 线性化舒适环 `d_t = g·m_t + h·d_{t−1} + ν_t`，`g<0`（裕度越大越不 distress），调节 `m_{t+1}=m_t+η·max(0,d_t−θ_dead)`。忽略死区与限幅时闭环特征方程 `z² − (1+h)z + h + gη = 0`，根在单位圆内当且仅当 `|h|<1` 且 `β=|gη|<1`。含延迟 `τ` 时，小增益条件收紧为 `β < 1/(1+τ)`。死区 `θ_dead` 使小扰动不触发调节（防抖），限幅 `|Δm|≤Δ_max` 防过冲。故在 `β<1` 且死区/限幅下，`m_t` 收敛到唯一不动点，不产生自激振荡。∎

**定理 9（ECHO 端到端安全-可辨识）** 在 A88–A94 下：
1. **情感只作门控证据**：`gate_soc=1` 时 `e_soc` 才进入 FIR-E；否则情感不参与归因（定义 236/237/241）。未知复合故障仍由第 65 轮机制判 `ambiguous` 并保守降级。
2. **物理硬安全优先**：`H_social` 与 ARG 都只增 `m`、只增 `r_human`，不放松任何物理裕度（定义 239/242/240）；故共因"人也被骗"时不会因"人看起来没事"而放行。
3. **块承诺不放大风险**：`k*≤min(m, k_ARG(m))`，块内越死区即早停；由第 65 轮引理 8，单块越界概率仍 ≤ `α_chunk+δ_fi+α_vis`。
4. **优雅降级**：语音不可用→`gate_soc=0`、退回 VISTA；情感与物理冲突→字典序保守；未同意/易损→仅 `ask/explain` 或纯物理探针。证书链显式记录 `gate_soc/consent/m_t/affect_unidentifiable`。∎

**定理 10（单向性防 Goodhart）** 由于 `m_t≥m_base` 且情感只增不减，任何以情感为输入的策略都无法把物理安全裕度降到基线以下；因此"让情感指标好看"不能换取物理风险。代价是**活力风险**：过度收紧导致任务停滞。ECHO 将其显式建模为 liveness 约束——`release()` 仅在独立物理证据健康且人类同意时以 `γ_rec=1/(10k)` 极慢恢复，并设超时后 `explain/ask`；停滞因此是可观测、可恢复的显式状态，而非隐藏副作用。∎

**命题（ACI 门 vs 朴素情感）** 若 `κ_soc<κ*`，朴素使用情感证据的归因风险严格高于不使用；ACI 门控后退化为"仅 ARG 收紧"，风险回到 VISTA 基线且不引入回音偏差。故门控是**安全的一侧**：最坏情况下只是少用一个通道，而不是被它带偏。∎

## 7. 已知风险

**一句话**：情感语音是低带宽、跨文化有偏、可被伪装、且在闭环中**内生**的一层证据；ECHO 用条件互信息去混杂，但去混杂既可能**过度条件化**（把真实因果一起减掉）也可能残留混杂，而单向收紧虽挡住了 Goodhart，却把风险转移到**任务活力**——系统可能为了"让人平静"长期停滞，或把文化/个体差异误判成"社会故障"，最终在真正的物理故障发生时因为"人看起来还好"而放行。这是全部 ACI 门与 ARG 稳定性论证共同依赖的隐藏假设（A94：情感通道的因果效应可被机器人动作历史充分条件化，且人类反馈单调）。

**次级风险与缓解**：
1. **过度条件化**：`u_{1:t}` 若包含控制器对故障的全部反应，条件化会把真实因果一起减掉，`κ_soc` 假性偏低、通道被弃用；缓解：用任务指令分量（外生）作工具变量，限制条件化维度，并做敏感性分析。
2. **残留混杂**：`E[y|u]` 估计不准时残差仍含回音；缓解：非参数回归 + 置换检验下界，`κ_soc` 低即弃用（安全一侧）。
3. **活力风险 / 停滞**：单向收紧可能冻结任务；缓解：显式 liveness 约束、超时 `explain/ask`、独立物理证据 + 同意的极慢恢复。
4. **文化/个体偏差**：同一 arousal 在不同文化/个体含义不同；缓解：说话人自校准基线、分层 conformal、把偏差计入 `r_human` 而非物理球。
5. **伪装与反讽**：`H_social` 可吸收假意，但若同时物理异常仍须保守；缓解：AIC-E 对抗训练 + 永不因情感放松。
6. **隐私与同意**：语音含身份与内容；缓解：端侧仅算副语言、零转写、`content_free_hash`、显式 opt-in 与可撤回。
7. **共因"人也被骗"**：透明/错觉让人也判断错；缓解：AIC-E 共因模型，人声只作并列证据，不作放行依据。
8. **实时预算**：副语言 + 门控逼近 2.7ms；缓解：特征降采样、事件触发、PSL 推断留语义流。
