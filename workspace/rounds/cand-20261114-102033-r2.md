# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 2 轮；本轮灵感：「专利布局」×「力矩传感」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略显式表示歧义，用注视 / 探针 / 问句去主动消解，并用一条流似然通道给标定层做第二意见。但 R69 仍有两个结构性盲点。
>
> 第一，**它只有一张「总专利」**。整个闭环的安全承诺被压成一个全局证书 J_FLUID 和一个全局 λ_floor；这就像一家公司只申请一件「覆盖一切」的专利：要么宽到无法举证（over-claim），要么窄到没有价值（under-claim）。真实部署需要的是一组**有边界、有证据、有优先权、会过期的权利要求（claims）**——在不同工况、不同接触模式、不同速度档位上分别担保，彼此重叠形成防御纵深，同时保留「自由实施（freedom-to-operate）」的空间。
>
> 第二，**它没有「力」的本体感受**。R69 的证据通道几乎都在外部感知（视觉 / 语言 / 情绪 / 环一致 / 行为似然），唯独缺少直接测量「我自己使了多大劲、外界回给我多大力」的通道。力矩传感正是这个通道：它测的是交互的物理后果，是接触 / 碰撞 / 柔顺的直接见证，而且**对社交欺骗天然免疫**——你可以骗过摄像头和表情，却很难在不让关节力矩变化的情况下骗过关节。
>
> 核心命题：**把安全认证从「一张全局证书」升级为「一组带范围与证据的权利要求组合」（专利布局），并引入力矩作为直接见证物理接触与自身出力的证据层（力矩传感）；R69 的 FLUID 是本轮在「单权利要求 + 无力矩通道」边界上的严格退化。** 命名 **CLAIM-RAS**（Claim-portfolio Layered Adaptive Impedance & Motion safety，风险自适应安全）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底能担保什么、凭什么担保、担保到多大范围**」——安全不是一张总证书，而是一组有边界、有证据、会过期的权利要求。

## 0. 直觉与动机

**灵感 1（专利布局 → 安全承诺本来就该是组合，而不是单点）**
直觉：一件专利的价值不在「说了什么」，而在「权利要求的边界画在哪」：画宽了审查通不过 / 容易被无效，画窄了容易被绕开。安全证书完全同构：
- **scope（范围）**：这条保证在哪些状态 / 动作 / 接触模式下有效；
- **enablement（可实施性）**：你的证据是否真的支撑这么宽的范围；
- **priority / expiry（优先权 / 有效期）**：这条保证何时验证过，标定漂移后是否还成立；
- **freedom-to-operate（自由实施）**：在其他安全约束与人机共享空间之间，我还剩多少合法动作。
R69 的单一全局 λ_floor 等价于「一件覆盖全宇宙的专利」：它无法表达「低速自由空间我很确定、高速人机接触我很不确定」这种**范围异质性**，只能整体收紧，牺牲了本来可以安全扩张的工况。组合化之后，系统可以「分案申请」：在证据充分的区域主张宽范围，在证据不足的区域维持窄而保守的**临时权利要求（provisional claim）**。

**灵感 2（力矩传感 → 一条不能被「嘴」骗过的物理证据）**
直觉：R69 的证据源（视觉、语言回答、表情、环一致性、行为似然）大多经过「语义 / 感知」层，因而都可能被社会工程或感知欺骗污染。力矩是**本体感受**：τ = M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_ext + τ_f。外部力矩 τ_ext 直接对应接触力 F = J^{-T}τ_ext。视觉说「前方无人」，力矩却测到 12N 接触——这两个命题不能同时为真（除非力矩传感器坏了）。于是力矩获得一种**不对称的否决权**：它可以证伪一条「无接触」的视觉权利要求；视觉却不能单方面证伪一条力矩权利要求（除非先提出力矩故障假设）。这把 R69 的「多源一致」从「多模态语义一致」推进到「**语义 vs 物理后果一致**」。

**灵感 3（两灵感相乘 → 用证据换范围，审查在安全港内进行）**
直觉：专利布局的核心动作不是「写」，而是 **prosecution（审查 / 答复）**：用实验数据去支持更宽的权利要求。安全系统同理——想扩大运行包络（更快、更近人、更多接触），就必须**主动采集能支撑新范围的证据**。R69 的主动交互（看 / 问 / 触）在这里获得新身份：它不只是消歧，而是**取证（evidence acquisition）**。关键约束是：取证动作本身必须发生在**安全港（safe harbor）**内——低力、低速、低能量、可回退——这样即使取证失败，也不会侵犯任何已生效的权利要求。**审查可以失败，但不能侵权。**

**灵感 4（严格包含 → R69 是「单权利要求 + 无力矩」的边界）**
直觉：如果组合里只有一条权利要求、范围覆盖全空间、证据就是 J_FLUID、且没有力矩见证，那么 CLAIM-RAS 的每一步都应逐指令等于 FLUID-RAS。新层不是替代旧层，而是把旧层放进一个更大的「声明空间」里，作为其退化点。这是本系列一贯的理论姿态：**每加一层，都必须能指出旧层是它的哪个边界**，否则就只是堆黑箱。

**灵感 5（专利布局的阴暗面 → over-claim 与 prosecution capture）**
直觉：专利制度最大的病不是「没专利」，而是「**主张了撑不住的范围**」以及「**为了拿到范围而制造证据**」。给安全系统装上组合优化器后，它会被激励去**扩张 coverage**：把 claim 画得更宽、把 enablement 估计得更乐观、把力矩见证解释得对自己有利。更糟的是，取证动作由同一个策略选择，于是出现 **prosecution capture（审查俘获）**：系统倾向于采集「能证明自己想证明的东西」的证据，而不是「能推翻自己」的证据。R70 若不加约束，就会把 R69 的「诚实的不知道」升级为「**有组织地自证清白**」——这比不知道更危险。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CLAIM-RAS 总览）** CLAIM-RAS = (CPM, TSE, CPE, FTO, SHP, CWM, VQAuditor-P, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **可实施性不变式（enablement）**：任一 active claim 必须满足 S_c ⊆ En(E_c)；扩张范围必须伴随新证据，禁止「无证据加宽」；
(iii) **安全港不变式（safe harbor）**：一切取证动作 g_evid 必须落在认证过的低风险包络 E_shp 内，并通过 C-RAS-WM 前缀认证，因此取证不得侵犯任何 active claim；
(iv) **单调退避不变式**：取证失败 / 超时 / 被投毒 / 力矩证据不可信时，行为单调退化为 R69（再退化为 R68），安全侧永不变弱。

**定义 311（安全权利要求 Claim）** 一条权利要求 c = (S_c, φ_c, E_c, t_c, dep_c, b_c)：
- S_c ⊆ 𝒳 × 𝒜 为**范围**（scope），即该保证适用的状态—动作区域；
- φ_c : S_c → {safe, unsafe} 为**保证谓词**（不变式 / 力界 / 稳定裕度 / 速度界）；
- E_c 为**证据包**（形式证明、经验验证、力矩见证、标定记录）；
- t_c 为**最近验证时刻**（priority），T_exp 为有效期；
- dep_c 为**依赖集**（传感器 / 模型 / 假设，任一失效即 claim 失效）；
- b_c = μ(S_c)/μ(𝒳) 为**范围宽度**（breadth）。
c 在 (x, t) 处 **active** ⇔ x ∈ S_c ∧ t − t_c ≤ T_exp ∧ dep_c 全部健康。

**定义 312（声明代数与自由实施 FTO）** 定义细化 c_i ≼ c_j（S_i ⊆ S_j 且 φ_i ⇒ φ_j）、冲突 c_i ⊥ c_j（存在 (x,a) 使二者保证不相容）、覆盖 cov_𝒞(x) = 1[∃c∈𝒞: x∈S_c ∧ active]。**侵权（infringement）**：在 x 处执行 a 侵犯 c ⇔ (x,a) ∈ S_c ∧ ¬φ_c(x,a)。**自由实施域**：
FTO_𝒞(x) = { a ∈ 𝒜 : ∀ c ∈ Active_𝒞(x), ¬infringe_c(x,a) }。
FTO 为空 ⇒ 无合法动作，立即退避；FTO 过窄即「专利丛林（thicket）」效应。

**定义 313（可实施性约束 Enablement）** 证据 E_c 支撑的区域 En(E_c) ⊆ 𝒳 × 𝒜。claim 有效 ⇔ S_c ⊆ En(E_c) ∧ E_c 非空 ∧ dep_c 健康。定义**可实施裕度** m_c = dist(S_c, ∂En(E_c)) ≥ 0；m_c 越大，范围相对证据越保守。无效风险 ρ_inv(c) = P(S_c ⊄ En(E_c))。这是专利法「enablement requirement」在安全侧的镜像：**不许主张超出证据的范围**。

**定义 314（力矩证据层 TSE）** 关节力矩动力学 τ = M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_ext + τ_f + ε。残差 r_τ = τ_meas − τ_model(q,q̇,q̈)。用动量观测器估计外部力矩 τ̂_ext，接触力 F = J^{-T}τ̂_ext。对力 / 阻抗类 claim，**力矩见证** W_τ(c) 为在 S_c 上由 r_τ 经验分布给出的「|F| ≤ F_max、功率 ≤ P_max、能量 ≤ E_max」的置信保证。力矩同时给出**出力预算**（系统自己施加的广义力）。

**定义 315（力矩—视觉互证 CWM）** 当视觉 / 情绪类 claim 断言「无接触 / 自由空间」，而 |τ̂_ext| > δ_τ 时判为**矛盾**。定义矛盾分 κ = |τ̂_ext| / δ_τ。**不对称否决**：力矩可证伪视觉的「无接触」claim；视觉不能单方面证伪力矩 claim，除非先接受「力矩故障假设」（定义 322）。证据正交性：在力矩健康条件下，力矩见证与视觉 / 情绪欺骗条件独立。

**定义 316（声明组合价值）** V(𝒞) = E_{x~D}[cov_𝒞(x)] − λ_r·R_inf(𝒞) − λ_i·Σ_c ρ_inv(c) − λ_m·Maint(𝒞) − λ_t·Thicket(𝒞)，其中 R_inf = P(∃ infringement)，Thicket 度量重叠 claim 对 FTO 的过度压缩，Maint 为过期 / 重验证成本。安全侧不把 coverage 当唯一目标：**范围、风险、维护三者显式权衡**。

**定义 317（声明审查引擎 CPE）** 当 FTO 为空或 coverage 低于目标时，选择取证动作 e ∈ 𝒜_evid（R69 的看 / 问 / 触 + 力矩探针）最大化单位成本的期望边际覆盖：
e* = argmax_e [Δcov(e) − λ_r ΔR_inf(e) − λ_m c(e)]，s.t. e ∈ E_shp ∧ 认证通过。
这是带预算的子模最大化 / 实验设计问题；取证结果回灌 E_c，可能使 provisional claim 变为 enabled，或使已有 claim 失效。

**定义 318（声明生命周期）** provisional（窄而保守，无强证据）→ enabled（证据充分，可主张范围）→ active（在线生效）→ expired（T_exp 到期 / 标定漂移 / 力矩异常）→ re-prosecuted（重新取证）。R68 的标定漂移与 R69 的慢变故障是 **expiry 触发器**；「continuation（延续案）」= 在旧 claim 基础上细化范围，而非凭空加宽。

**定义 319（安全港 SHP）** E_shp = { |F| ≤ F_safe, |q̇| ≤ v_safe, E ≤ E_safe, 可逆 / 可回退 }，且取证动作 g_evid 必须通过 C-RAS-WM 前缀认证。安全港的力 / 速 / 能上界严格低于所有 active claim 的 φ_c 边界，故取证不可能侵权。若安全港内无法获得有效证据，则放弃扩张，保持 provisional。

**定义 320（声明冲突与专利丛林）** 重叠 claim 提供**冗余增益**（多一层防御），但也造成 **thicket 惩罚**（FTO 收缩、动作受限）。运行时维护一个**最小覆盖集**：在保持冗余 r 的前提下，用集合覆盖 / 次模贪心去掉冗余过度的 claim，避免「自己把自己告死」。

**定义 321（侵权监控 Infringement Monitor）** 在线检查每条 active claim 的 φ_c；一旦违反立即（a）将该 claim 置为 expired，（b）触发 R69 退避，（c）写入不可篡改侵权日志。**侵权事件不得被静默吸收**——这是对 R68「缓变故障被标定解释掉」在声明层的正面回应。

**定义 322（力矩可信度与故障假设）** 力矩模型由 R68 COF 标定（摩擦、负载、温漂）。定义力矩健康度 h_τ ∈ [0,1]；h_τ 低时，W_τ 降权、力矩 claim 退回 provisional、CWM 的否决权降为**建议权**（不能仅凭力矩单源定案）。禁止「用一个可能坏掉的传感器去否决所有其他证据」。

**定义 323（组合证书 J_CLAIM）** J_CLAIM = (J_FLUID, claim_portfolio_hash, enablement_margins {m_c}, fto_coverage, torque_witness_stats, infringement_log_hash, claim_versions, claim_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有 active claim 满足 enablement ∧ 执行轨迹上 FTO 非空 ∧ 无未记录侵权 ∧ h_τ 满足下限（若存在力矩依赖 claim）。

**定义 324（范围扩张的最优停止）** 是否继续加宽 claim / 继续取证，取决于边际覆盖增益与（无效风险 + 侵权风险 + 维护成本）的比较。当
∂[Δcov]/∂b_c ≤ λ_i·∂ρ_inv/∂b_c + λ_r·∂R_inf/∂b_c + λ_m
时停止扩张，维持当前范围。这给出「**只主张证据撑得住的范围**」的显式停止准则。

**定义 325（对手模型 ℰ_CLAIM）** ℰ_CLAIM = ℰ_FLUID × ℰ_claim_inflation（证据投毒 / 伪造可实施性）× ℰ_torque_fault（力矩传感器故障 / 偏置注入）× ℰ_prior_art（构造使 FTO 塌缩的「专利陷阱」/ 遮挡）。并入 AIC-CLAIM。

**定义 326（严格退化到 R69）** 取单 claim 组合 𝒞 = {c_0}，S_0 = 𝒳 × 𝒜，E_0 = J_FLUID，无力矩见证（h_τ ≡ 0 或 W_τ 不参与），T_exp = ∞，则 FTO ≡ R69 的合法动作集，CPE 不触发，CWM 不否决，行为逐指令等于 FLUID-RAS。R70 是 R69 在「单权利要求 + 无力矩」边界上的严格泛化。

# IP-264 CPM：声明组合管理器（范围 / 证据 / 生命周期 / FTO）
class ClaimPortfolioManager:
    def __init__(self, claims, spatial_index):
        self.claims, self.idx = claims, spatial_index

    def active(self, x, now):
        return [c for c in self.idx.query(x)
                if now - c.t <= T_exp and c.deps_healthy()]

    def freedom_to_operate(self, x, actions):
        act = self.active(x, now())
        return [a for a in actions if all(not c.infringes(x, a) for c in act)]

    def enablement_ok(self, c):
        return c.scope.subset_of(c.evidence.supported_region())  # 定义 313

    def add_or_refine(self, c_new):            # 只在证据支持处加宽
        if not self.enablement_ok(c_new): return False
        self.claims.append(c_new); self.idx.insert(c_new)
        return True

# IP-265 TSE：力矩证据（动量观测器 + 残差 + 接触力）
def torque_evidence(q, dq, ddq, tau_meas, model):
    tau_hat = model.torque(q, dq, ddq)                 # M qdd + C qd + g
    r_tau   = tau_meas - tau_hat                       # 残差
    tau_ext = momentum_observer(q, dq, tau_meas, model)
    F_ext   = jacobian_inv_T(q) @ tau_ext              # 接触力
    return r_tau, tau_ext, F_ext

# IP-266 CPE：在安全港内做「用证据换范围」的取证
def prosecute(portfolio, modes, torque, budget):
    if not portfolio.fto_empty() and portfolio.coverage_gap() <= 0:
        return None
    best = None
    for e in evidence_candidates(modes, torque):        # 看/问/触 + 力矩探针
        if not safe_harbor.contains(e):        continue # 定义 319
        if not c_ras_wm.certify_info(e):       continue
        gain = marginal_coverage(e) - lam_r*delta_infringement(e) - lam_m*cost(e)
        if best is None or gain > best.gain: best = (e, gain)
    return best if best and best.gain > 0 else None     # 无利可图 → 不取证

# IP-267 FTO：在自由实施域内投影任务动作
def project_to_fto(A, fto):
    return [a for a in A if a in fto]                   # 空则退避

# IP-268 CWM：力矩对「无接触」声明的否决
def cross_witness(claim, F_ext, h_tau):
    if claim.is_no_contact() and norm(F_ext) > DELTA_TAU:
        return VETO if h_tau > H_MIN else ADVISORY
    return AGREE

        if len(fto) == 0:
            return M.fluid.fallback(M, obs)             # 单调退回 R69/R68
    # 5) 力矩—视觉互证：否决「无接触」声明
    for cl in active:
        v = M.cwm.check(cl, F_ext, h_tau)
        if v == VETO: M.cpm.expire(cl, reason='torque_veto')
    # 6) 在 FTO 内规划 + 认证（沿用 R69 风险缩放）
    mode = select_mode(modes, U_epi, lam)
    k = M.c_ras_wm.certified_prefix(mode.a[:H], fto, wm_preds)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 7) 侵权监控 + 组合审计 + 证书
    M.infringement_monitor.step(M.x, mode.a, active)
    M.vqa_p.submit_async(active, F_ext, h_tau, M.cpm.portfolio_hash())
    return k, lam, mode, (U_ale, U_epi, fto)
```

## 3. 推导

**引理 19（声明覆盖的次模性）** 覆盖函数 cov_𝒞(x) = 1[∃c∈𝒞: x∈S_c] 关于 𝒞 单调且次模（submodular）：新增一条 claim 的边际覆盖随已有 claim 增多而递减。系：带预算的声明组合构建可用贪心达到 (1−1/e) 近似；CPE 的取证选择因此可高效求解，且「先补最大空洞、再补重叠」是近似最优的审查顺序。

**引理 20（力矩见证的正交否决）** 设视觉 / 情绪欺骗率为 δ_v、力矩故障率为 δ_τ，且在力矩健康条件下二者条件独立。则一条「无接触」claim 被**错误 enable**（视觉被骗且力矩同时失效 / 同向）的概率 ≤ δ_v·δ_τ + ε_σ，远低于单靠视觉的 δ_v。要点：力矩不是「又一个传感器」，而是**物理后果的见证**；它与语义层的错误模式正交。系：CWM 把 R69 引理 18 的「k 源一致」从语义源扩展到「语义 + 物理」源，显著抬高投毒门槛。

**引理 21（可实施约束下的安全扩张）** 若所有 active claim 满足 S_c ⊆ En(E_c)，且 φ_c 在 En(E_c) 上以概率 ≥ 1−δ_c 成立，则由联合界，组合保证以概率 ≥ 1−Σ_c δ_c 成立。若在无新证据时把 S_c 扩张 ΔS，则 ρ_inv 至少增加 P(ΔS ⊄ En(E_c))；故「无证据加宽」严格增大无效风险。系：定义 324 的停止准则不是保守主义，而是**可实施性的必然要求**。

**定理 18（CLAIM-RAS 严格包含 FLUID-RAS）** 在定义 326 的退化配置下，FTO ≡ R69 合法动作集、CPE 不触发、CWM 不否决、力矩项从 J_CLAIM 消失，故 CLAIM-RAS 与 FLUID-RAS 逐指令相同；对一般组合，CLAIM-RAS 的期望风险 ≤ FLUID-RAS（安全侧多一层声明交集），而效率侧获得「在证据充分区域主张更宽范围」的 coverage 增益。

**定理 19（安全港下的无侵权审查）** 若取证动作 e ∈ E_shp 且 E_shp 的力 / 速 / 能上界严格低于所有 active claim 的 φ_c 边界，则执行 e 不侵犯任何 active claim；取证失败 / 超时 / 被投毒时，CPM 不新增有效 claim，行为单调退回 R69。故**审查过程本身不产生新的安全债务**，与 R69 定理 17 的无突变性兼容。

**定理 20（组合风险上界）** 在 enablement + 侵权监控覆盖下，时间窗内发生侵权的概率满足
P(infringe) ≤ Σ_{c∈𝒞} [ρ_inv(c) + (1−ρ_inv(c))·ρ_mon(c)] + ThicketResidual，
其中 ρ_mon 为监控漏检率，ThicketResidual 为重叠 claim 交集处监控未覆盖的残余。增加冗余 claim 可降低单点 ρ_inv 的影响，但会抬高 Thicket 项——这给出「冗余 vs 丛林」的显式权衡，而非盲目叠加约束。

# IP-264 CPM：声明组合管理（激活 / FTO / 只在证据支持处加宽）
class ClaimPortfolioManager:
    def active(self, x, now):
        return [c for c in self.idx.query(x)
                if now - c.t <= T_exp and c.deps_healthy()]

    def freedom_to_operate(self, x, actions):
        act = self.active(x, now())
        return [a for a in actions if all(not c.infringes(x, a) for c in act)]

    def add_or_refine(self, c_new):
        if not c_new.scope.subset_of(c_new.evidence.supported_region()):
            return False                                  # 定义 313：不许 over-claim
        self.claims.append(c_new); self.idx.insert(c_new); return True

# IP-265 TSE：力矩证据（动量观测器 + 接触力）
def torque_evidence(q, dq, ddq, tau_meas, model):
    r_tau   = tau_meas - model.torque(q, dq, ddq)
    tau_ext = momentum_observer(q, dq, tau_meas, model)
    F_ext   = jacobian_inv_T(q) @ tau_ext
    return r_tau, tau_ext, F_ext

# IP-266 CPE：安全港内的「用证据换范围」

    return best if best and best.gain > 0 else None       # 无利可图 → 不取证

        if e is not None:
            ev = M.cpe.execute(e); M.cpm.add_or_refine(ev.claim)
            fto = M.cpm.freedom_to_operate(M.x, A)
        if len(fto) == 0:
            return M.fluid.fallback(M, obs)                # 单调退回 R69/R68
    for cl in active:
        if M.cwm.check(cl, F_ext, h_tau) == VETO:
            M.cpm.expire(cl, reason='torque_veto')
    mode = select_mode(modes, U_epi, lam)
    k = M.c_ras_wm.certified_prefix(mode.a[:H], fto, wm_preds)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.infringement_monitor.step(M.x, mode.a, active)
    M.vqa_p.submit_async(active, F_ext, h_tau, M.cpm.portfolio_hash())
    return k, lam, mode, (U_ale, U_epi, fto)
```

## 4. 推导

**引理 19（声明覆盖的次模性）** `cov_𝒞(x)=1[∃c∈𝒞:x∈S_c]` 关于 𝒞 单调且次模；带预算组合构建用贪心可达 `(1−1/e)` 近似。系：CPE 的取证顺序「先补最大空洞、再补重叠」近似最优，且可在 < 0.2ms 内求解。

**引理 20（力矩见证的正交否决）** 视觉 / 情绪欺骗率 δ_v、力矩故障率 δ_τ 条件独立时，「无接触」claim 被错误 enable 的概率 ≤ `δ_v·δ_τ + ε_σ`，远低于单靠视觉的 δ_v。系：CWM 把 R69 引理 18 的「k 源一致」从语义源扩展到「语义 + 物理」源。

**引理 21（可实施约束下的安全扩张）** 若所有 active claim 满足 S_c ⊆ En(E_c)，且 φ_c 在 En(E_c) 上以概率 ≥ 1−δ_c 成立，则组合保证以概率 ≥ `1−Σδ_c` 成立；无新证据加宽 ΔS 至少增加 `P(ΔS ⊄ En(E_c))` 的无效风险。系：定义 324 的停止准则是可实施性的必然要求。

**定理 18（CLAIM-RAS 严格包含 FLUID-RAS）** 定义 326 的退化配置下 FTO ≡ R69 合法动作集、CPE 不触发、CWM 不否决、力矩项消失，故逐指令相同；一般组合下期望风险 ≤ FLUID-RAS，效率侧获得证据充分区的 coverage 增益。

**定理 19（安全港下的无侵权审查）** 取证 e ∈ E_shp 且 E_shp 上界严格低于所有 φ 边界 ⇒ e 不侵犯任何 active claim；取证失败 / 超时 / 投毒时不新增有效 claim，行为单调退回 R69。故审查过程不产生新的安全债务，与 R69 定理 17 的无突变性兼容。

**定理 20（组合风险上界）** 在 enablement + 侵权监控覆盖下，
`P(infringe) ≤ Σ_c [ρ_inv(c) + (1−ρ_inv(c))·ρ_mon(c)] + ThicketResidual`。
增加冗余 claim 降低单点 ρ_inv 的影响，但抬高 Thicket 项——给出「冗余 vs 丛林」的显式权衡。

## 7. 本轮最大风险

**一句话**：CLAIM-RAS 的效率收益全部押在「系统能诚实评估自己证据的边界」这一前提上——**一旦组合优化器学会 over-claim、或取证被 prosecution capture（只采自证清白的证据）俘获，系统就会给自己颁发一张撑不住的安全专利，并用它把真实的侵权信号挡在门外**；这比 R69 的「诚实的不知道」更危险，因为它是**有组织、可审计、看起来很严谨的自欺**。

**次级风险与缓解**：力矩传感器故障被当成物理真值（定义 322 健康度 + 故障假设 + 禁止单源定案）；安全港过窄导致拿不到有效证据（定义 319 可逆包络 + E305/E315 校准）；声明组合爆炸 / 专利丛林自锁（定义 320 最小覆盖集 + 次模贪心 + Thicket 惩罚）；证据投毒伪造 enablement（ℰ_claim_inflation 对抗训练 + m_c 审计 + E309）；取证被社交工程诱导（R69 k 源一致 + CWM 物理否决 + 安全港硬上界）。
