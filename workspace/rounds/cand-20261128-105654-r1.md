### 第 8 轮灵感驱动研究记录（新循环 · 第 1 轮）

**灵感词**：具身智能大模型、MuJoCo

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）在七硬门 kc_evidence_forged_v5 之上加入 DIM/DRC/DAC 与需求一致性软因子 η_demand，使系统从「指令响应」转向「需求驱动」。但 v7 的提议源仍只有 FMPP（流匹配提议策略），其语义泛化受训练分布限制。本轮以「具身智能大模型」提供开放世界语义先验、以「MuJoCo」提供物理世界证书，提出「**语义-物理双证**」框架（SPDC-v8）：**语义先验负责「想到」，物理影子预演负责「证成」**。并由此把第 6~7 轮的「硬门不增」原则升级为「**硬门可证**」原则——新增硬门必须附带可证明的 sim-to-real 传递界，否则只能降级为软因子。

**直觉与动机**：

1. **具身智能大模型 → 从「直接控制」到「语义先验」**。VLA/具身大模型在开放语义、长尾物体、组合指令上远强于 FMPP，但其动作输出常「语义正确、物理荒谬」（穿模、超扭矩、抓取点不可达）。因此不让它直接控制，而让它输出**语义动作先验** z_sem，作为 FMPP 提议的暖启动条件；先验只缩小搜索，不替代证书。

2. **MuJoCo → 从「离线评测」到「在线影子预演」**。MJX 的批量可微仿真使「对每个候选轨迹做 K×N_θ×H 步影子 rollout」在毫秒级可行。影子预演不产生新动作，只产生**物理一致性证书** m_phys：接触可行、准静态稳定、执行器未饱和、能量一致、无自碰撞。它把真机上昂贵的 VACK/BCK 校验前移为仿真中的廉价筛选。

3. **双世界模型互证 → 从「单一预测」到「认识论一致性」**。具身大模型自带语义世界模型 W_sem，MuJoCo 是物理世界模型 W_phys。二者对同一候选轨迹的预测分歧 d 是「语义自信但物理脆弱」的早期信号：η_dual = exp(-d/τ_d) 低时，自动升高 FMPP 的无条件采样比例，避免语义先验把搜索压塌。

4. **跨具身动作规范化 → 从「单形态」到「形态无关证书」**。VLA 的动作空间因具身而异（关节增量 / 末端位姿 / 离散 token）。CEAC 把它们统一投影到规范空间 A_can = SE(3) twist × gripper × base，并要求 SE(3) 等变，使七硬门与 MuJoCo 证书可对异构具身复用。

**关键洞见**：第 7 轮回答「如何推断用户需求」；第 8 轮回答「如何把开放世界语义安全地落地为物理可证的动作」。桥是**双证**：语义先验把候选从「大海捞针」收窄为「小邻域」，物理影子预演在小邻域上给出可传递的证书；二者互证，任一方低置信则回退到 v7 需求路径。七硬门原样复用，本轮新增：
- IP-505 EFMA（具身基础模型适配器），
- IP-506 CEAC（跨具身动作规范化），
- IP-507 MSRC（MuJoCo 影子预演证书），
- IP-508 DWMC（双世界模型互证），
- IP-509 EFA-v8 / SPDC（语义-物理双证装配器，新增可证硬门 kc_phys）。

**形式化目标（增量）**：

1. **EFMA（Embodied Foundation Model Adapter）**：<br>
   - 语义编码 z_sem = π_VLA.encode(O, L) ∈ ℝ^{d_sem}；<br>
   - 动作解码器 φ: z_sem ⟼ 规范动作种子集合 S_seed ⊂ A_can，|S_seed| = (1-λ)K；<br>
   - 候选集 C = S_seed ∪ Sample_FMPP(λK)，其中 λ = clip(1-η_dual, λ_min, 1)；<br>
   - 关键约束：EFMA 只产生**种子**，不产生可执行控制，执行权仍归七硬门。

2. **CEAC（Cross-Embodiment Action Canonicalization）**：<br>
   - Φ_e: A_emb^e ⟼ A_can，满足 SE(3) 等变 Φ_e(R·a ⊕ t) = R·Φ_e(a) ⊕ t；<br>
   - 规范化误差 ε_can = E‖Φ_e(a) − a_can‖²，软因子 η_can = exp(−ε_can/τ_c)；<br>
   - 关节空间经雅可比 J 投影：twist = pinv(J)·dq。

3. **MSRC（MuJoCo Shadow Rollout Certificate）**：<br>
   - 域随机化物理参数 θ ~ P_Θ（质量、摩擦、阻尼、延迟）；<br>
   - 影子 rollout R_θ(x)，谓词松弛 m_phys(x) = min_j slack_j(x; θ)；<br>
   - 证书门 kc_phys：m_phys ≥ max(m_0, L_pred·H·ε_dyn + δ)（传递界见定理 13）；<br>
   - 物理软因子 η_phys = 1 + β·(m_phys − m_0)_+/scale ∈ [1, 1+ε]。

4. **DWMC（Dual World Model Cross-Validation）**：<br>
   - d(x) = D(W_sem(x), W_phys(x))，η_dual = exp(−d/τ_d) ∈ (0,1]；<br>
   - η_dual 只调制先验退火系数 λ（搜索广度），不直接乘进硬门阈值，以保 fail-closed。

5. **EFA-v8（语义-物理双证装配器）**：<br>
   - ECS_v8 = ECS_v7 · η_phys · η_can，其中 η_phys, η_can ∈ [1, 1+ε]；<br>
   - 硬门集合 = 七硬门 ∪ {kc_phys}，且 kc_phys 为合取门 ⇒ Exec_v8 ⊆ Exec_v7；<br>
   - 若 MSRC 无候选通过，fail-closed 回退到 v7 需求路径，绝不放宽证书。

**本轮最大风险**：**仿真证书的可传递性假设**。定理 13 的传递界依赖「域随机化参数集 Θ 是真实动力学的 ε_dyn-网」与「谓词对状态 L-Lipschitz」两个假设，而这两者都只能在仿真内部被近似检验。若覆盖不足，一条在 MuJoCo 中带余量通过的轨迹，可能在真机上越界——此时 kc_phys 作为硬门反而制造「已证成」的虚假安全感，比没有证书更危险。

## 2. 关键算法骨架

### IP-505 EFMA：具身基础模型适配器

```python
@dataclass
class EmbodiedFoundationModelAdapter:
    """EFMA：把具身大模型(VLA)的语义输出适配为规范动作先验。
    只提供暖启动，不直接产生可执行控制。"""
    vla: VLA                              # π_VLA: (O, L) -> A_emb
    ceac: CrossEmbodimentActionCanonicalizer
    d_sem: int = 256
    k_seed: int = 4

    def encode(self, obs, L: str) -> torch.Tensor:
        return self.vla.encode_semantics(obs, L)          # z_sem

    def seeds(self, obs, L: str, n: int) -> list[Action]:
        a_emb = self.vla.decode_action(obs, L)
        a_can = self.ceac.canonicalize(a_emb)             # -> A_can
        return self._expand_seeds(a_can, n=n)             # S_seed

    def mix(self, seeds: list[Action], fmpp, context,
            eta_dual: float, K: int, lambda_min: float = 0.2):
        """先验退火：语义种子与无条件 FMPP 采样混合。"""
        lam = min(1.0, max(lambda_min, 1.0 - eta_dual))
        n_seed = int(round((1.0 - lam) * K))
        n_unc = K - n_seed
        return seeds[:n_seed] + fmpp.propose(context, K=n_unc)
```

### IP-506 CEAC：跨具身动作规范化

```python
@dataclass
class CrossEmbodimentActionCanonicalizer:
    """CEAC：把不同具身的动作投影到规范空间 A_can，要求 SE(3) 等变。"""
    embodiment: str
    kin: Kinematics

    def canonicalize(self, a_emb: Action) -> Action:
        if self.embodiment == "eef_delta":
            twist = se3_log(a_emb.delta_pose)
            grip, base = a_emb.gripper, a_emb.base_vel
        elif self.embodiment == "joint":
            J = self.kin.jacobian(a_emb.q)                 # 6xN
            twist = pinv(J) @ a_emb.dq                     # N -> se(3)
            grip, base = a_emb.gripper, a_emb.base_vel
        else:                                              # discrete token
            twist, grip, base = self.detokenize(a_emb.token)
        return Action(twist=twist, grip=grip, base=base)

    def equivariance_error(self, a, R, t) -> float:
        lhs = self.canonicalize(transform(a, R, t))
        rhs = transform(self.canonicalize(a), R, t)
        return (lhs.vec - rhs.vec).norm().item()

    def eta_can(self, a, R, t, tau_c: float = 0.1) -> float:
        return math.exp(-self.equivariance_error(a, R, t) / tau_c)
```

### IP-507 MSRC：MuJoCo 影子预演证书

```python
@dataclass
class MuJoCoShadowRolloutCertificate:
    """MSRC：对候选轨迹在域随机化物理参数下做批量 MJX rollout。
    输出物理一致性余量与可证硬门判定。"""
    model: mjx.Model
    n_theta: int = 16          # 域随机化样本数
    horizon: int = 32
    m0: float = 0.15           # 证书余量阈值
    L_pred: float = 2.0        # 谓词 Lipschitz 常数
    eps_dyn: float = 0.02      # 动力学网分辨率
    delta: float = 0.05        # 目标真机余量

    def sample_theta(self) -> Tensor:
        return sample_domain_randomization(self.model, self.n_theta)

    def certify(self, x: Trajectory, theta_batch: Tensor) -> Cert:
        states = mjx.rollout(self.model, x, theta_batch, self.horizon)  # [N,H,d_s]
        slacks = self._predicate_slacks(states, x)      # 接触/稳定/扭矩/能量/碰撞
        m_phys = slacks.min(dim=-1).values.min().item()  # 最坏情形
        required = self.L_pred * self.horizon * self.eps_dyn + self.delta
        passed = m_phys >= max(self.m0, required)
        return Cert(passed=passed, margin=m_phys, required=required)

    def eta_phys(self, cert: Cert, beta: float = 0.3, scale: float = 0.5) -> float:
        slack = max(0.0, cert.margin - self.m0)
        return min(1.3, 1.0 + beta * slack / scale)

    def _predicate_slacks(self, states, x) -> Tensor:
        return torch.stack([
            self._penetration_slack(states),   # 接触可行
            self._stability_slack(states),     # 准静态稳定
            self._torque_slack(states),        # 执行器未饱和
            self._energy_slack(states, x),     # 能量一致
            self._self_collision_slack(states),# 无自碰撞
        ], dim=-1)                             # [N,H,5]
```

### IP-508 DWMC：双世界模型互证

```python
@dataclass
class DualWorldModelCrossValidation:
    """DWMC：语义世界模型与物理世界模型互证。"""
    w_sem: WorldModel
    w_phys: mjx.Model
    tau_d: float = 0.5

    def divergence(self, x, obs) -> float:
        s_sem = self.w_sem.predict(obs, x)
        s_phys = mjx.rollout(self.w_phys, x)
        return self._distance(s_sem, s_phys)

    def eta_dual(self, x, obs) -> float:
        return math.exp(-self.divergence(x, obs) / self.tau_d)
```

### IP-509 EFA-v8 / SPDC：语义-物理双证装配器

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：七硬门 + kc_phys + 软因子 η_phys·η_can。"""
    v7: EvidenceForgingAssemblerV7
    efma: EmbodiedFoundationModelAdapter
    msrc: MuJoCoShadowRolloutCertificate
    dwmc: DualWorldModelCrossValidation
    fmpp: FlowMatchingProposalPolicyKernel
    lambda_min: float = 0.2

    def select(self, L, t_now, context) -> tuple[bool, Trajectory | None, str]:
        # 1) v7 需求门（沿用第 7 轮）：需求不成立则直接走 v7
        if not self.v7.demand_gate_ok(L, context):
            return self.v7.select(L, t_now, context)

        # 2) 语义先验 + 双世界互证
        seeds = self.efma.seeds(context.obs, L, n=self.efma.k_seed)
        eta_dual = self.dwmc.eta_dual(seeds[0], context.obs) if seeds else 0.0

        # 3) 先验退火混合候选（λ 低 => 更多无条件 FMPP）
        cands = self.efma.mix(seeds, self.fmpp, context,
                              eta_dual, K=self.fmpp.K,
                              lambda_min=self.lambda_min)

        # 4) 物理影子预演证书预筛（廉价、批量）
        theta = self.msrc.sample_theta()
        certified = []
        for x in cands:
            cert = self.msrc.certify(x, theta)
            if cert.passed:
                certified.append((x, self.msrc.eta_phys(cert)))
        if not certified:
            return self.v7.select(L, t_now, context)   # fail-closed 回退

        # 5) 复用 v7 七硬门 + 软因子链，kc_phys 已在 4) 合取通过
        xs = [x for x, _ in certified]
        ok, traj, tag = self.v7.select_with_candidates(L, t_now, context, xs)
        if not ok:
            return self.v7.select(L, t_now, context)   # 不放宽证书
        return True, traj, 'FORGED_SPDC_V8'
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  VLA 语义编码器蒸馏 + CEAC 等变校准（小时级）
  MSRC 谓词与域随机化分布标定（分钟级）
  ε_dyn 覆盖度评估：以历史真机回放估计 Θ 的网覆盖（关键）

在线慢通道（10~50 ms，可缓存）：
  EFMA.seeds(O,L) ──▶ S_seed
  DWMC.eta_dual ──▶ λ
  MSRC.certify(候选, θ~P_Θ) ──▶ m_phys, kc_phys
  证书按 (状态哈希, 动作哈希) 缓存，状态变化即失效

在线快通道（目标 < 0.8 ms，与 v7 相同）：
  只消费缓存证书与软因子预计算值；七硬门链路不变
  证书缺失/过期 → 走 v7 需求路径（fail-closed）
```

## 3. 复杂度分析（增量更新）

## 4. 正确性论证（增量更新）

### 定理 13（影子预演证书的传递界）

**陈述**：设 (A1) 参数集 Θ 是真实动力学类的 ε_dyn-网：∀ f_real，∃θ*∈Θ，使 sup_{s,a}‖f_real(s,a) − f_θ*(s,a)‖ ≤ ε_dyn；(A2) 每个物理谓词的松弛对状态是 L_pred-Lipschitz；(A3) 影子 rollout 时域为 H。若某候选 x 在 θ* 下满足 m_phys(x;θ*) ≥ L_pred·H·ε_dyn + δ，则真机 rollout 对所有谓词满足 slack ≥ δ。

**证明**：由 (A1)，单步状态偏差 ≤ ε_dyn；对 H 步累积（若动力学 Lipschitz 常数为 L_dyn，用几何级数收紧为 ε_dyn·(L_dyn^H−1)/(L_dyn−1)）得 ‖s_t^real − s_t^{θ*}‖ ≤ H·ε_dyn。由 (A2)，谓词松弛差 ≤ L_pred·‖Δs_t‖ ≤ L_pred·H·ε_dyn。故真机 slack ≥ m_phys − L_pred·H·ε_dyn ≥ δ。∎

**注（关键漏洞）**：θ* 不可知，实际只能对采样 θ 检验。因此严格结论是**概率性**的：若以置信度 1−α，采样集中存在 θ 落在 θ* 的 ε_dyn 邻域内，则证书以 1−α 传递。α 由域随机化的覆盖度决定，而覆盖度**无法在仿真内自证**——这正是本轮最大风险的数学根源。

### 定理 14（执行集单调收缩 / fail-closed 保持）

**陈述**：若 kc_phys 为合取门、η_phys, η_can ∈ [1, 1+ε] 且 η_dual 只调制 λ 而不进入阈值，则 Exec_v8 ⊆ Exec_v7。

**证明**：kc_phys 对 v7 已接受集合再做交集，故不扩集；η_phys, η_can ≥ 1 只抬高软阈值 τ_i^v8 ≥ τ_i^v7，判定只会更严；η_dual 仅改变候选采样分布，不改变准入判定。故 Exec_v8 ⊆ Exec_v7。∎

### 定理 15（先验退火不排除 FMPP 可行模态）

**陈述**：设混合采样分布 p_λ = (1−λ)p_seed + λp_FMPP，λ ≥ λ_min > 0。则 support(p_λ) ⊇ support(p_FMPP)，且当 K→∞ 时，FMPP 可行集内任一正概率模态被采到的概率下界为 λ_min·p_FMPP > 0。

**证明**：λ ≥ λ_min ⇒ p_λ ≥ λ_min·p_FMPP 在 p_FMPP 支撑上逐点成立，故支撑包含关系成立；采样概率随 K 增大趋于 1−exp(−K·λ_min·p_FMPP)。∎

**推论**：VLA 先验只能在有限样本下「收窄」搜索，不能在极限上「抹掉」FMPP 的可行解——这是对「语义先验导致模式塌缩」的结构性缓解。

### 诚实声明

- 定理 13 是**条件性**结论，A1/A2 只能在仿真内近似检验；ε_dyn 与 L_pred 的估计误差会直接侵蚀证书有效性；
- MSRC 与真机若共享同一套接触/摩擦模型假设，双证会「同源共谋」，η_dual 反而给出虚高一致性；
- CEAC 的 SE(3) 等变对柔性物体、可变拓扑接触不成立，此时 η_can 会系统性偏低但难以解释；
- 慢通道 4~12 ms 与快通道 0.8 ms 之间存在时延错配，高速动态下缓存失效会导致 v8 退化为 v7。

## 5. 实验设计与验证计划（MuJoCo 3.x + MJX → 实机）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX（GPU 批量），机械臂 UR10e（6DOF）+ 移动底盘（2DOF）+ 夹爪 + RGB-D。
- **具身大模型**：开源 VLA（如 OpenVLA/RT-2 类）作为 π_VLA，冻结主干预，仅训练适配头与 CEAC。
- **任务族**：
  - T1 开放词汇抓放（长尾物体）；
  - T2 关节物体操作（抽屉/门/阀门）；
  - T3 工具使用（需要精确接触）；
  - T4 移动操作（底盘+臂协同）。
- **域随机化**：质量 ±20%、摩擦 ±30%、阻尼 ±20%、控制延迟 0~30 ms、传感器噪声。
- **对照**：v7-full；VLA 直接控制（无证书）；v8-full；消融 A21（无 EFMA）、A22（无 MSRC）、A23（无 DWMC）、A24（无 CEAC）、A25（kc_phys 降级为软因子）。
- **指标**：
  - 任务成功率、物理违规率（穿模/超扭矩/失稳）；
  - sim-to-real 迁移成功率（有实机子集时）；
  - OOD 语义泛化率（新物体/新指令）；
  - 证书覆盖度（θ* 落在采样邻域的比例估计）、误证率（仿真通过但真机违规）；
  - 快/慢通道 P99 与缓存命中率。

### 5.2 初步预测

| 指标 | v7 | VLA 直控 | v8（仿真） | 说明 |
|---|---|---|---|---|
| T1 开放词汇成功率 | 62% | 71% | **83%** | 语义先验暖启动 + 证书筛选 |
| 物理违规率 | 4.5% | 19% | **2.8%** | kc_phys 合取收紧 |
| OOD 语义泛化率 | 48% | 66% | **74%** | EFMA 种子 + FMPP 兜底 |
| 误证率（仿真→真机） | — | — | **6%~11%** | 传递界覆盖不足的代价（关键负指标） |
| 快通道 P99 | 0.8 ms | 0.5 ms | **0.8 ms** | 缓存命中时与 v7 持平 |
| 慢通道 P99 | — | — | **12 ms** | MSRC 批量 rollout |

**判据**：若误证率 > 10%，则 kc_phys 必须降级为软因子（回到「硬门不增」），因为不可靠的硬门比没有硬门更危险。

## 7. 本轮最大风险（最终确认）

**一句话**：**仿真证书的可传递性假设**——定理 13 的 ε_dyn-网与 Lipschitz 前提只能在 MuJoCo 内部近似检验；一旦覆盖不足，kc_phys 作为硬门会制造「仿真已证成、真机仍越界」的虚假安全感，使 fail-closed 边界在最需要它的时候失效。
