# 第 44 轮（新循环第 1 轮） · Cost-Cert：把「成本」升为一等证书维度，并从 20+ IP 压缩出 3 个可辩护的论文创新点（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约空集」。但把它放进真实研究与工程语境，还有两个更根本的隐忧：**(H1) 证书不免费**——查表、INT8 监控、几何证书、共形校准、人工确认、仿真检索，每一项都在消耗算力、能耗、时延、标注与人力；v20 只把 τ_u、租约衰减、RTA 预算当作局部补丁，没有统一货币，导致「越安全越贵、越贵越难落地」。**(H2) 创新点通胀**——20+ IP、8 个红线实验已超出任何单篇论文可辩护的边界，继续加 IP 的边际创新收益趋零、评审可验证成本趋高。本轮灵感词「成本控制」「论文创新点」正命中这两点：把**成本**提升为与 soundness 并列的一等证书维度（证书经济学），并把**论文创新点**形式化为一次「贡献压缩 / 最小可发表核」优化。核心命题：**soundness 是硬约束，成本是硬预算；而研究的创新点本身也要受成本控制。**

## 0. 直觉与动机

**灵感 1（成本控制 → 证书经济学：安全不是免费的，必须记账）**：直觉上，v20 的每条结论都像一张「安全发票」：L0 查表便宜、INT8 监控中等、几何证书昂贵、共形校准要数据、人工确认要注意力、仿真检索要 GPU 小时。过去我们只问「这张证书 sound 吗」，从不问「这张证书值多少钱、还能不能更便宜地达到同样的 sound」。成本控制要求建立**统一成本向量与台账**，把「预算化 soundness」变成一等公民：决策不仅要在逻辑上 sound，还要在**成本预算内**可行。一旦成本可记账，优化目标就从「尽可能多验证」变成「在固定预算下最大化可认证能力」，即沿**成本-能力 Pareto 前沿**选工作点。

**灵感 2（论文创新点 → 贡献压缩：从 IP 清单到可辩护的三条主张）**：直觉上，20+ IP 是工程愿望清单，不是论文。评审只认三条左右、彼此独立、可被消融验证的主张。因此引入**贡献账本（novelty ledger）**：每条主张记录「最近先验工作 / 增量 / 证据 / 消融」，并定义**可辩护性分数**。据此求**最小可发表核（MPC）**：在满足新颖性与证据门槛的前提下，最小化「构建 + 验证」成本。这不是偷懒，而是把「成本控制」用到研究自身——**用最少的机制讲清一个真命题**。

**灵感 3（耦合 → 成本让既有机制各归其位）**：v20 里散落的 τ_u、租约衰减 λ、HI/LO 预算、投机并行度 b，本质都是「用成本换能力/新鲜度」的局部启发式。统一到成本台账后：租约过期 = 陈旧成本超过重取成本；HI 模式 = 安全关键任务的成本权重置为无穷；投机并行 = 用 b 倍算力买证书新鲜度；CKB 缓存 = 用存储/检索成本摊销重复验证。它们从「各自为政的补丁」变成**同一优化问题的不同约束/权重**。

**本轮真正押注的三条论文创新点**：
- **C1（理论）预算化 soundness 与成本代数**：证书携带成本向量，证明「逻辑 soundness 与资源可行性可分离」，并给出成本可组合（组合证书成本的下界/上界）的代数。
- **C2（算法）验证边际价值（MoV）调度**：把异质验证动作按「单位成本换来的保守性下降」排序，在预算下做（近似）最优分配；证明能力函数次模时贪心达 (1−1/e)，并给出非次模时的修正。
- **C3（实证）成本条件下的基准与边缘部署**：在等安全下把证书成本降 ≥30%（或等成本下能力 +X pp），并在 Jetson 类边缘硬件给出 $/h、W 的端到端账本。

其余 IP 一律降级为「支撑系统 / 未来工作」，不再作为创新点主张。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（证书成本向量与成本台账）**：每个验证/证书动作 π 附带成本向量 c(π) = (c_comp, c_energy, c_lat, c_data, c_human, c_risk) ∈ R_+^6，分别对应算力（μs·核）、能耗（mJ）、时延（ms）、校准/标注样本数、人工确认次数、集成风险当量。台账 L_t = Σ_{s≤t} c(π_s)。预算 B ∈ R_+^6。成本偏序 c ≼ c' 当且仅当逐分量 ≤。

**定义 45（预算化 soundness / Budgeted Certificate）**：决策 d 的证书 cert(d) = (snd, c)，其中 snd ∈ {0,1} 为逻辑 soundness，c 为成本。d 在台账 L 与预算 B 下**可采纳**当且仅当 snd=1 ∧ L + c ≼ B。**分离命题**：成本不改变逻辑 soundness 的真值，只改变可采纳性；因此「为省成本而跳过验证」只可能降低 snd（不安全），而「在预算内选择验证子集」必须在 snd=1 的可行域内优化。**推论**：任何成本优化都必须以「被跳过动作的 soundness 已被更便宜动作覆盖」为前提，否则不 sound。

**定义 46（验证边际价值 MoV 与次模性）**：设 V(S) 为验证动作集合 S 所认证的「可采纳能力」（如可认证可行域体积 / Nominal 占比 / 任务成功率上界）。MoV_i(S) = [V(S∪{i}) − V(S)] / cost_i。**次模性假设**：V 单调次模（边际收益递减）⟹ 预算约束下的贪心分配满足 V(S_greedy) ≥ (1−1/e)·V(S*)。**注意**：几何证书依赖 VLM 语义、共形校准依赖分布，动作间可能互补（非次模）；因此需定义**条件次模**（在给定上下文分层内成立）并用 E98 实测违背程度。

**定义 47（成本-能力 Pareto 前沿与工作点）**：P = {(V(S), Σ_{i∈S} c_i) : snd(S)=1}。运行期按预算 B 选工作点 op(B) = argmax_{S: cost(S)≼B} V(S)。**命题**：若 V 次模，MoV 贪心生成的 (V, cost) 序列是 P 的 (1−1/e) 近似前沿。**可用性判据**：若 op(B) 下目标不可达，触发协商/降级，而非静默超预算。

**定义 48（贡献账本与可辩护性）**：每条论文主张 k 记 (prior_k, delta_k, evid_k, abl_k)：最近先验、增量、证据强度、消融覆盖。可辩护性 D_k = min(δ(delta_k), η(evid_k), α(abl_k))（短板效应）。**门槛**：主张可写入正文当且仅当 D_k ≥ D_min，且与最近先验的 delta 可被一句话说清。**反通胀规则**：任何不能给出「最近先验 + 一句 delta + 一个消融」的 IP，不得进入创新点清单。

**定义 49（最小可发表核 MPC 与研究成本前沿）**：给定候选主张集 K、构建+验证成本 w_k、证据/新颖性覆盖需求 R，MPC = argmin_{S⊆K} Σ_{k∈S} w_k，s.t. cover(S) ≥ R ∧ ∀k∈S: D_k ≥ D_min。**命题**：MPC 是带覆盖约束的背包/集合覆盖，NP-hard，但 |K| 小时可精确枚举；MPC 的补集显式标注为「支撑系统 / 未来工作」，避免评审把工程体量误读为创新体量。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERT-COST-LEDGER（证书成本台账 CCL）
1. **统一成本货币**：为每个验证动作测/标定六维成本，硬件单调时钟 + 能耗计数器 + 人工确认计数。
2. **预算化采纳**：决策前检查 snd ∧ L+c ≼ B；超预算走降级/协商，绝不静默超支。
3. **成本审计**：按任务/关键级/人格出成本报表，支撑 $/h、W、p99 时延与「安全每美元」指标。
4. **成本校准**：离线标定 + 在线漂移检测，成本预测误差超阈值即触发重标定。

### 2.2 IP-61 MOV-SCHEDULER（验证边际价值调度器 MoVS）
1. **MoV 估计**：在线估计每个候选验证动作的边际能力增益与成本，维护分层（关键级/人格/场景）的 V 估计。
2. **预算化贪心分配**：在硬约束（safety 关键级权重 ∞）下对软验证动作做预算贪心；非次模时用局部搜索修正。
3. **机制归位**：租约续期 = 用重取成本对冲陈旧成本；投机并行度 b = 用算力买新鲜度；HI 模式 = 安全成本权重置 ∞。
4. **工作点选择**：按当前预算输出 op(B)，不可行则协商/安全停机。

### 2.3 IP-62 CONTRIBUTION-COMPRESSOR（贡献压缩器 CoCo）
1. **贡献账本**：抽取候选主张，逐条填 prior/delta/evidence/ablation，计算可辩护性 D_k。
2. **MPC 求解**：在 |K| 小的情况下精确枚举，输出「正文三主张 + 支撑系统 + 未来工作」三分法。
3. **消融/基线计划生成**：为每条正文主张强制配 ≥1 消融 + ≥2 基线，缺一不得进正文。
4. **研究成本模型**：估算每条主张的构建/验证工时与算力，作为选核的成本输入（把成本控制用到研究自身）。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 成本台账准确性 | 预测 vs 实测六维成本误差 | <15% |
| E96 预算化 soundness | 预算内序列违例；静默超预算 | 0 起；0 起 |
| E97 MoV 调度收益 | 等安全下成本降幅；等成本下能力提升 | ≥30%；≥5pp |
| E98 次模性检验 | 边际收益递减违背率；贪心 vs 最优差距 | <20%；<10% |
| E99 Pareto 前沿 | 相对 oracle 的 hypervolume 覆盖 | ≥85% |
| E100 缓存摊销 | CKB 命中率；重复验证成本降幅 | ≥60%；≥25% |
| E101 贡献可辩护性 | 每条正文主张消融数/基线数/先验 delta | ≥1 / ≥2 / 可一句话说清 |
| E102 端到端边缘成本 | 等安全下 $/h、W；相对 v20 全栈降幅 | ≥2x |

回退：E95 成本失真 → 退回保守上界记账；E96 违例 → 关闭预算优化，回到固定验证阶梯；E97/E99 无 Pareto 收益 → 承认「成本只是工程记账」，把论文收缩到 C1+C3（理论 + 基准）或只保留 C3；E98 严重非次模 → 改精确/局部搜索，放弃 (1−1/e) 主张；E100 缓存无效 → 移除 CKB 复用主张；E101 不达标 → 该主张降级为支撑系统；E102 不达标 → 论文不宣称边缘部署，仅仿真。

## 5. 本轮最大风险

**一句话**：若「成本」与「能力」之间并不存在真实的、可测量的 trade-off（Pareto 前沿很平），则 Cost-Cert 会退化为给既有 mixed-criticality/anytime 工作套一层记账外壳，三条创新点中的 C1/C2 失去经验支撑；因此 E97/E99（可测的 Pareto 改善）与 E101（对最近先验的可辩护 delta）必须设为红线，失败即把论文收缩为「证书缓存/复用」这一更窄但可证的贡献。

## 1. 论文创新点（三条正文主张，经贡献压缩）

| 主张 | 最近先验 | 一句话 delta | 证据 | 消融/基线 | D_k |
|---|---|---|---|---|---|
| **C1 预算化 soundness 与成本代数** | 运行时验证、混合关键级（只调度不记账）；anytime（只谈时延，无统一货币） | 首次把成本向量作为证书一等维度，证明逻辑 soundness 与资源可行性可分离且成本可组合 | 定义 44–45 + 分离命题 + 成本组合界 | 去掉成本维度的对照；与 MC-only 比 | 高 |
| **C2 验证边际价值 MoV 调度** | 次模覆盖/传感器选择（静态、单一资源）；MC 调度（固定关键级） | 用「单位成本换保守性下降」把租约/投机/HI 模式统一为同一预算贪心 | 定义 46–47 + 算法 + E97/E98/E99 | 均匀分配 vs MoV；关次模修正 | 高 |
| **C3 成本条件基准与边缘部署** | 现有 safety benchmark 不报 $/W/校准数据 | 首个「等安全」下的证书成本基准与边缘端到端账本 | E95–E102 | 关缓存；关 MoV；关 HI 模式 | 中-高 |

**支撑系统（不作为创新点主张）**：PCE 人格契约、CCR 并发运行时、ICV 交互验证器、几何证书、Sim-Cert-RAG 飞轮、共形意图集。
**未来工作**：多用户契约协商、长时程人格漂移、跨硬件成本迁移。

> 反通胀规则（定义 48）：凡不能给出「最近先验 + 一句 delta + 一个消融」的 IP，一律留在支撑系统或未来工作，不进正文。

## 3. 关键算法（伪代码）

### IP-60 CCL：成本台账与预算化采纳
```
def charge(ledger, action, t):
    c = measure_or_predict_cost(action)          # 六维：算力/能耗/时延/数据/人工/风险
    ledger.append((t, action, c))
    return ledger

def budget_admit(ledger, B, cert):
    if not cert.snd:                              # 逻辑不 sound，直接拒
        return False, "unsound"
    projected = ledger.total() + cert.c
    if not leq_all(projected, B):                 # 逐分量预算检查
        return False, "over_budget"               # 绝不静默超支
    return True, "admit"

def audit_cost(ledger, group_by):
    # 输出 $/h、W、p99 时延、安全每美元等报表
    return aggregate(ledger, group_by)
```

### IP-61 MoVS：MoV 估计与预算贪心
```
def mov_estimate(S, i, V_hat, cost):
    gain = V_hat(S | {i}) - V_hat(S)
    return gain / max(cost[i], eps)

def mov_allocate(actions, B, V_hat, hard_constraints):
    S = set(hard_constraints)                     # safety 关键动作：权重无穷，先入
    budget_left = B - cost_sum(S)
    while True:
        cand = [(mov_estimate(S, i, V_hat, cost), i)
                for i in actions - S if cost[i] <= budget_left]
        if not cand:
            break
        mov, i = max(cand)
        if mov <= 0:                              # 边际价值非正，停止
            break
        S.add(i); budget_left -= cost[i]
    return S

def choose_operating_point(B, actions, V_hat):
    S = mov_allocate(actions, B, V_hat, hard_constraints=SAFETY)
    if not feasible(V_hat, S):
        return negotiate_or_degrade()             # 预算下不可行，协商/降级
    return S
```

### IP-62 CoCo：贡献压缩与 MPC
```
def defensibility(claim):
    return min(delta_score(claim.delta),
               evidence_score(claim.evid),
               ablation_score(claim.abl))         # 短板效应

def solve_MPC(claims, R, D_min):
    eligible = [k for k in claims if defensibility(k) >= D_min]
    best = None
    for S in powerset(eligible):                  # |K| 小，精确枚举
        if cover(S) < R:
            continue
        w = sum(build_verify_cost(k) for k in S)
        if best is None or w < best.w:
            best = (S, w)
    return best                                   # 补集 = 支撑系统/未来工作

def contribution_gate(claims):
    for k in claims:
        assert len(k.ablations) >= 1 and len(k.baselines) >= 2
        assert one_sentence_delta(k.prior, k.delta)
    return [k for k in claims if defensibility(k) >= D_min]
```

### 机制归位：租约/投机/HI 模式作为成本权衡
```
def lease_decision(lease, t, theta, reacquire_cost):
    stale_cost = lease.lam * (t - lease.tau)      # 陈旧带来的保守性损失当量
    if lease.m - stale_cost >= theta:
        return "use"                              # 仍新鲜
    # 否则比较：重取成本 vs 继续用陈旧边际的代价
    return "reacquire" if reacquire_cost <= stale_cost else "degrade"

def speculative_depth(B, base_cost, freshness_value):
    # 用算力买新鲜度：选 b 使边际新鲜度收益/成本最大
    return argmax_b(freshness_value(b) / (b * base_cost))

def hi_mode(tasks):
    # HI 模式 = 安全任务成本权重置无穷，只删不增
    return [t for t in tasks if t.kappa >= K_GEOMETRY]
```

## 5. 实验设计（E95–E102，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 成本台账准确性 | 预测 vs 实测六维成本误差 | <15% |
| E96 预算化 soundness | 预算内序列违例；静默超预算 | 0 起；0 起 |
| E97 MoV 调度收益 | 等安全下成本降幅；等成本下能力提升 | ≥30%；≥5pp |
| E98 次模性检验 | 边际收益递减违背率；贪心 vs 最优差距 | <20%；<10% |
| E99 Pareto 前沿 | 相对 oracle 的 hypervolume 覆盖 | ≥85% |
| E100 缓存摊销 | CKB 命中率；重复验证成本降幅 | ≥60%；≥25% |
| E101 贡献可辩护性 | 每条正文主张消融数/基线数/先验 delta | ≥1 / ≥2 / 可一句话说清 |
| E102 端到端边缘成本 | 等安全下 $/h、W；相对 v20 全栈降幅 | ≥2x |

**基线设置**：B1 = v20 固定验证阶梯（无 MoV）；B2 = 均匀/轮转分配；B3 = 仅安全关键 + 关缓存；B4 = 全量验证（成本上界、安全参照）。

**消融**：A1 关 MoV（固定阶梯）；A2 关 CKB 复用；A3 关预算化采纳（允许超支）；A4 关 HI 模式成本隔离。

回退：E95 成本失真 → 退回保守上界记账；E96 违例 → 关闭预算优化，回到固定验证阶梯；E97/E99 无 Pareto 收益 → 承认「成本只是工程记账」，把论文收缩到 C1+C3 或只保留 C3；E98 严重非次模 → 改精确/局部搜索，放弃 (1−1/e) 主张；E100 缓存无效 → 移除 CKB 复用主张；E101 不达标 → 该主张降级为支撑系统；E102 不达标 → 论文不宣称边缘部署，仅仿真；任何红线实验失败 → 全链路熔断回退 v20。

## 7. 本轮最大风险

**一句话**：若「成本」与「能力」之间并不存在真实的、可测量的 trade-off（Pareto 前沿很平），则 Cost-Cert 会退化为给既有 mixed-criticality/anytime 工作套一层记账外壳，三条创新点中的 C1/C2 失去经验支撑；因此 E97/E99（可测的 Pareto 改善）与 E101（对最近先验的可辩护 delta）必须设为红线，失败即把论文收缩为「证书缓存/复用」这一更窄但可证的贡献。
