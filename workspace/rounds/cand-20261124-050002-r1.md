## 1. 三个灵感的第一性原理

### 灵感 1 ·「多模态交互」→ 不是加传感器，而是让模态互相「举证」

**直觉**：官方 API 只有 observation→action，没有触觉、没有力。硬造新模态是死路；但现有观测其实已经是一个**异步、部分冗余、彼此可校验的传感器阵列**：头部 RGB、腕部 RGB、关节/末端位姿、夹爪标量、语言指令、动作历史、时间戳。真正的「交互」不是人对机器人说话，而是**模态之间的交叉盘问**：视觉说目标在左，本体感受说手没动，夹爪说已经闭合——三者一致才叫「知道」，不一致就是信息，而不是噪声。

**严谨定义**：给每条证据一个类型化记录 `e_m = (m, t, z_m, Σ_m, h_m, src)`（U19：模态 m、时间戳 t、测量 z、协方差 Σ、健康度 h、来源）；所有下游断言/伺服/介入只消费**融合估计** `(x̂, Σ̂)`，不再各自直读某一模态（P13）。融合用**协方差交叉（Covariance Intersection, CI）**而非朴素卡尔曼：CI 在**不知道模态间互相关**时仍给出保守一致估计（U20）。原因是头/腕两路视觉共享光照、遮挡与运动模糊，朴素 KF 假设独立会重复计信、把协方差压得过小——这会让卡方断言误报，也会让「地图毒化」显得比实际更确定。CI 的代价是保守（检测功效略降），收益是**不会自信地错**。

### 灵感 2 ·「技术融合」→ 把自动驾驶的传感器融合手艺搬进 VLA 执行栈

**直觉**：自动驾驶早就解决了「多速率异步传感器 + 相关失效 + 延迟预算 + 多假设」这一整套问题；VLA 则擅长「语义先验 + 闭环动作」。两边的长处正好互补：把前者的**时间对齐、协方差交叉、卡方门限、事件触发**接到后者的状态层/断言/介入上，就是一次真正的技术融合，而不是把两个热词拼在一起。更关键的是**同一残差三种用途**：同一个跨模态一致性统计量，在线做异常触发器，离线做失败因子标注器，赛前做预注册指标——评测栈与运行栈共享一个数学对象，减少「离线好看、线上失灵」的落差。

**严谨定义**：对任意两个模态估计 `(x_a, P_a)`、`(x_b, P_b)`，定义归一化互证残差 `d² = rᵀ S⁻¹ r`，`r = x_a − x_b`，`S` 取 CI 一致的保守协方差（U21）；`d²` 超过 `χ²_{d,α}` 报警，超过 `χ²_{d,α'}`（α′≪α）触发高置信异常。同一 `d²` 在离线侧按（任务×阶段×模态对）聚合，直接产出 IP-06 的失败矩阵单元格；在在线侧按（路标×阶段）聚合，直接驱动 IP-13/14/15 的响应。再加一条 sim-real 桥：**模态 dropout 作为训练增强**，让策略在任一模态短时缺失时平滑退化到 Level-1.6，而不是整段失效。

### 灵感 3 ·「交互设计」→ 把「提问权」预算化

**直觉**：当两个模态打架时，最聪明的动作往往不是猜，而是**问一个有针对性的问题**：把腕部相机移近一点、保持一拍等遮挡过去、轻推一下确认。但每一次「提问」都要花步数，而评分器直接按步骤计分。因此交互设计的核心不是「能不能问」，而是「这一问值不值」。

**严谨定义**：把可执行的取证动作集 `A_q = {re-view（移动末端获取新视角）, hold（等待遮挡解除）, probe（轻推/预升力）}` 纳入 P12 的期望步数账；对每个候选动作估计信息增益 `IG(a)` 与消耗步数 `cost(a)`，仅在 `IG(a)/cost(a)` 超过阈值且该路标在白名单内时执行。语言在这里只能**提供先验、缩小假设集**，不能当作测量证据（P15 / L16）：如果视觉与接触似然在各假设上相同，后验就退化为先验——错误的指令先验会制造「自信的绑错」。所以「问」的对象必须是世界（视觉/接触），不是指令文本。

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（证据平权与互证优先）**：没有任何模态默认可信；所有断言/伺服/介入只消费融合估计；决策依据是「多模态是否互相印证」，而不是任何单模态的高置信。
- **P14（信任可证伪且有界）**：每个模态的信任权重必须可在线被残差证伪（持续不一致则单调降权，持续一致则缓慢恢复），且任一单模态的权重设上限 `ω_max`——保证单点错误最多造成有界的状态偏移，不能绑架整张地图。
- **P15（语言只作先验，不作证据）**：指令解析只允许产生先验因子/候选排序/搜索约束；目标绑定与到点必须由视觉或接触似然认证；语言与感知冲突时，默认怀疑语言先验。

## 5. 本轮最大风险

**共同模态失效（相关误差盲区）**：当头/腕/语言共享同一个错误来源——同侧光照过曝、遮挡同时挡住两路、或指令先验本身就错——互证残差会趋近于零，CI 也只能给出一致的自信；此时信任层可能把唯一正确的本体感受/夹爪信号也压低，系统进入「全体一致地错」。这是所有基于一致性的融合方法的根本盲区。对冲：①保留硬锚（EE 位姿/夹爪标量）不受视觉信任下调影响；②在路标级做绝对成功检查（接触确认/任务谓词），不只看相对一致性；③对「全模态高置信但任务谓词失败」单独记一类事件，强制重定位而非继续。次要风险：CI 过度保守吃掉检测功效（E636 门槛）；信任权重振荡导致冻结（权重地板 + 滞回）；Dex1 新任务与挑战 32 项存在灵巧手/夹爪域差（只做辅助，不做直接迁移）。

## 3. 新增 IP 详述

### IP-16 · XMB 跨模态证据总线 + CI 信任融合（P0，新）

- **动机**：官方观测是异步多速率信号：两路视觉低频、本体高频、夹爪事件稀疏、语言静态。v3 的 SceneState 默认「检测器输出可直接融合」，隐含了两个错误假设：模态独立（实际共享光照/遮挡）与模态同信任（实际健康度随时间剧变）。相关误差会让朴素 KF 过度自信，恰好是地图毒化的放大器。
- **与现有方案差异**：teaser 榜（待复核假设）的 8 个模型是「观测→动作」单通路；本方案显式维护**证据的时间戳、协方差、健康度、来源**，用 CI 在未知互相关下融合，并给每个模态信任权重设上下限。组件全部现成：时间对齐缓冲、CI 信息式融合、卡方门限；无新模型、无新传感器。
- **技术可行性**：高。CI 的 N 路推广是线性代数（`P⁻¹ = Σ ω_m P_m⁻¹`），权重搜索一维即可；健康度用轻量规则（遮挡面积、模糊度、检测置信、时间新鲜度）先验给出，再由残差在线校正。
- **资源**：数据=无新增（用现有回放标定权重）；算力=小（与检测同步的低频矩阵运算）；接口=无新增字段，全部策略内部。
- **落地步骤**：①枚举 observation 实际字段、时间戳与刷新率（E634）；②实现证据记录与时间对齐缓冲；③CI 融合替换 v3 的加权平均；④信任更新律（残差驱动的乘性降权 + 地板/天花板 + 滞回）；⑤`ω_max` 由 E637 压力测试标定；⑥模态 dropout 训练增强（IP-12）验证退化平滑。
- **风险**：CI 过度保守 → 检测变钝（E636）；信任振荡 → 权重地板 + 滞回；共同模态失效 → 硬锚（EE/夹爪）保底 + 路标级绝对谓词检查。

### IP-17 · CMC 跨模态一致性监视器（P1，新）

- **动机**：v3 的绑定校验、SlipGuard、干扰检测是三套阈值、三套标注、三套误报率——维护成本高且口径不一致。它们本质都是「两个模态对同一件事说了不同的话」：视觉绑定 vs 接触/本体（毒化）、腕部视觉位移 vs 夹爪/EE 位移（滑移）、当前场景 vs 地图预测（干扰）。
- **差异**：把三类故障统一为一个归一化残差 `d² = rᵀ S⁻¹ r`（U21），用 CI 一致的保守 `S` 保证误报 ≤α；低阈值做「观察」，高阈值做「触发」，中间区滞回。**离线同一残差**按任务/阶段/模态对聚合，直接生成 IP-06 失败矩阵的单元格证据。
- **可行性**：高。全部是统计检验 + 现成估计器，不需要新训练；难点在残差表设计（哪对模态查哪类故障）与延迟。
- **资源**：近零；复用 IP-16 证据与 IP-13 状态。
- **步骤**：①建立残差表（故障类型 × 模态对 × 期望协方差）；②两类阈值（α/α′）与滞回；③在线事件推送 IP-02/14/15；④离线聚合器接 IP-06；⑤E635/E636/E637 标定。
- **风险**：共同模态失效时残差盲（最大风险，见 §10）；某些故障在单模态上不可观（如不可见滑移）→ 只能降级日志器；监控本身吃延迟 → 与检测同频旁路，不阻塞动作。

### IP-18 · IATG 指令锚定任务图（P2·条件，新）

- **动机**：指令文本是唯一免费的语义模态，但它最容易被误用。v3 的绑定完全依赖视觉，遇到相似干扰物时缺一个「角色/关系」先验；而直接让 VLM「按指令找目标」又会把语言幻觉变成绑定证据。
- **差异**：离线把指令解析成类型化任务图 `G=(V,E,Φ)`（目标/容器/工具/角色、空间关系、前置条件、成功谓词），在线只用它做**候选排序与搜索约束**，并用 L16 明确其证据上限：似然平坦时后验=先验，语言不能认证。
- **可行性**：中。离线解析可用现成 VLM/LLM，不进入实时闭环；风险在指令歧义与任务图 schema 覆盖。
- **资源**：离线一次解析 32 项任务 + 少量同义改写；在线仅查表/匹配，近零算力。
- **步骤**：①任务图 schema；②32 项指令离线解析与人工校对；③绑定候选排序接口接 IP-13；④E638 消融（有/无先验、故意给错先验测幻觉）。
- **风险**：先验错误放大绑错（P15 对冲：与感知冲突时怀疑先验）；解析覆盖不足（只作 tie-breaker）；E638 无收益则归档。

## 5. 符号与定义（新增 U19–U22；U1–U18 沿用第 1–3 轮）

- **定义 U19（证据记录）**：`e_m = (m, t, z_m, Σ_m, h_m, src)`；m∈{head_rgb, wrist_rgb, proprio, gripper, instruction, action_hist}；t 为采集时间戳；z/Σ 为测量与协方差；h∈[0,1] 为健康度（遮挡/模糊/新鲜度/检测置信的规则合成）；src 记录产生该证据的模块，供离线归因。
- **定义 U20（CI 信任融合）**：每模态先产生同一状态的估计 `(x_m, P_m)`；取权重 `ω_m ∈ [ω_floor, ω_max]`、`Σω_m=1`，融合为
  `P⁻¹ = Σ_m ω_m P_m⁻¹`，`x̂ = P Σ_m ω_m P_m⁻¹ x_m`。
  CI 保证：对任意未知互相关，`P` 不低估真实误差协方差；`ω_max` 使任一单模态对 `x̂` 的影响有界（L14）。权重由健康度先验与残差后验共同决定，带滞回。
- **定义 U21（互证残差）**：对模态对 (a,b)，`r = x_a − x_b`（或经 `H` 投到公共空间），`S = S_ci(P_a, P_b)` 为 CI 一致的保守差协方差；`d² = rᵀ S⁻¹ r`。`d²>χ²_{d,α}` 记事件，`d²>χ²_{d,α'}`（α′≪α）记高置信事件；中间区滞回。
- **定义 U22（指令任务图）**：`G=(V,E,Φ)`；V=实体与角色（target/container/tool/obstacle），E=空间与功能关系（on/in/left-of/inside），Φ=前置条件与成功谓词；由指令离线解析得到，只允许作为先验因子进入 IP-13，不得直接写入目标档案的认证字段。

## 6. 关键算法骨架（新增片段；主体沿第 1–3 轮 `UniBotSAGEPolicy`）

```python
# ===== IP-16: 跨模态证据总线（异步对齐 + CI 融合 + 有界信任）=====
class Evidence:
    def __init__(self, m, t, z, cov, health, src):
        self.m, self.t, self.z, self.cov = m, t, z, cov
        self.health, self.src = health, src

class XMB:
    def __init__(self, floor=0.05, cap=0.45, eta=0.5):
        self.floor, self.cap, self.eta = floor, cap, eta
        self.w = {}                                   # 每模态基础信任

    def fuse(self, evs, t_now):
        est = [e.to_state_estimate(t_now) for e in evs]   # (x_m, P_m)，预测到 t_now
        om = self.weights(est)
        P_inv = sum(om[i] * inv(est[i][1]) for i in range(len(est)))
        P = inv(P_inv)
        x = P @ sum(om[i] * inv(est[i][1]) @ est[i][0] for i in range(len(est)))
        return x, P

    def weights(self, est):
        raw = {m: self.w.get(m, 0.5) for m in range(len(est))}
        s = sum(raw.values())
        om = {m: min(max(v / s, self.floor), self.cap) for m, v in raw.items()}
        z = sum(om.values())                          # 重新归一化，保持 Σω=1
        return {m: v / z for m, v in om.items()}

    def update_trust(self, d2, dof, alpha):
        # 持续不一致 → 乘性降权；持续一致 → 缓慢恢复；滞回见 E635
        over = max(0.0, d2 - chi2_ppf(dof, alpha))
        for m in self.w:
            self.w[m] *= exp(-self.eta * over)
            self.w[m] = min(max(self.w[m], self.floor), self.cap)
```

# ===== U20/CI: 两模态无关假设下的保守融合 =====
def ci_fuse(xa, Pa, xb, Pb, omega):
    Pa_i, Pb_i = inv(Pa), inv(Pb)
    P = inv(omega * Pa_i + (1 - omega) * Pb_i)       # 对任意互相关均保守
    x = P @ (omega * Pa_i @ xa + (1 - omega) * Pb_i @ xb)
    return x, P

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（CI 的相关误差鲁棒性与有界影响）** 设两估计 `(x_a,P_a)`、`(x_b,P_b)` 的真实互相关未知但联合协方差存在。对任意 `ω∈[0,1]`，CI 融合的 `P` 满足 `P ⪰ P_true`（不低估真实误差），故协方差一致；当 `P_m` 同构且 `ω_m≤ω_max`、`Σω=1` 时，`x̂=Σω_m x_m`，任一单模态测量偏移 `Δ` 对 `x̂` 的影响至多 `ω_max‖Δ‖`。⇒ **地图毒化从「灾难」降为「有界扰动」**：把 `ω_max` 设为 `β·tol/‖Δ‖_max` 即可保证单点错误位移不超过容差的 β 倍；这是 v3 的加权平均（无上限）不具备的保证。∎

**引理 L15（互证残差的校准与功效）** 若 `S` 为真实差协方差的保守上界，则零假设下 `d²` 随机占优于 `χ²_d`，故误报率 ≤α；备择假设下真实偏差 `δ` 使 `d²` 服从非中心 `χ²_d(λ)`，`λ=δᵀS⁻¹δ`，检测功效随 `λ` 单调上升。⇒ 同一残差可同时校准误报（α 设计参数）与比较不同故障的可检测性（λ 大小）；绑定错/滑移/干扰的差异被还原为「该故障在所选模态对上的非中心参数大小」。∎

**引理 L16（语言先验的证据上限）** 若在给定假设 `H_i` 下观测似然 `P(z|H_i)` 对各候选相同（视觉/接触对该区分不提供信息），则后验 `P(H_i|z) ∝ P(z|H_i)P(H_i) ∝ P(H_i)`，即后验退化为先验。⇒ **语言只能重排假设，不能认证假设**；错误先验在此情形下会制造「自信的绑错」。因此 P15 规定：绑定认证必须有非平坦的视觉/接触似然，语言与感知冲突时默认怀疑语言。∎
