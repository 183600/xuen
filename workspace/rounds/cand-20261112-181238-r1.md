# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「动力学」×「失败恢复」）

> 第 60 轮实现了「认知驱动的场景-执行闭环」：SSM 场景语义建模、CIEC 认知意图约束、EPIR 执行感知隔离区、SERC 场景闭环、SIC 三元校验、CESC 联合决策、EPIR-Protocol。但把系统推到**接触作业的真实动力学**下，暴露三个更本质的局限：
> 1. **阻抗被当作静态参数，而非动力学算子**：`K_safe^scene` 是按场景先验与参数幅值裁剪出的静态集合。但真正决定接触是否稳定的是闭环方程 `M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + JᵀF_ext` 与 `τ = Jᵀ(K_p e + K_d ė) + τ_comp`。同一组 `(K_p,K_d)` 在刚性环境无源稳定，在软环境 + 采样延迟 + 高刚度下会相位滞后、接触抖振、力矩饱和。**静态安全不等于动力学安全**，第 60 轮缺少动力学一致性证书。
> 2. **失败被当作事后事件，没有前驱与可恢复性**：SERC 靠「执行下滑」被动感知场景改变，EPIR 靠序列号重放事后恢复证据。但失败在动力学上有可观测前兆（接触刚度骤降、能量注入、相位漂移、饱和比例上升）；等 EV-exec 显示出异常时，系统可能已经越过**不可恢复边界**。缺「失效前驱 → 恢复前置」这一环。
> 3. **预算只有消耗、没有恢复裕度**：PCE++++ 的 `B_scene/B_intent/B_ros/B_exec` 只计量算力、时延、消息与执行资源。为多探测一次场景而耗尽最后一点力矩/能量/热裕度，会把「可恢复的小扰动」变成「不可逆的失效」——**可恢复性必须作为预算与不变式，而不是优化目标**。
> 更深一层：三者指向同一个缺口——此前工作优化的是「顺利时执行什么」，缺少「出问题时还剩下多少回来的余地」。**动力学是失败的发生机制，失败恢复是动力学的逆问题**；必须把二者放在同一个闭环里。

## 0. 直觉与动机

**灵感 1（动力学 → 动力学可行阻抗编译 DACC）**
直觉：把 `K_safe` 从「安全盒子里的一个点」重新理解为「动力学方程里的一个算子」。给定当前位形与速度、机器人惯量 `M(q)`、科氏/重力 `C,g`、雅可比 `J`、执行器上限 `τ_max`、采样周期 `Δt`、环境阻抗 `Z_env` 和通信延迟 `T_d`，问的不是「参数大不大」，而是「闭环是否稳定、无源、不饱和、能抗延迟、远离奇异」。高 `K_p` 提升跟踪精度却压缩相位裕度；高 `K_d` 抑制振荡却抬高力矩需求——安全是这些**归一化裕度同时非负**。
关键洞见：安全应定义为**闭环动力学的可容许性**，并输出一张可复核的**动力学一致性证书 `J_dyn`** 与**能量槽 `E_tank`**；场景先验只作为搜索的起点，动力学可行性才是硬约束。

**灵感 2（失败恢复 → 可恢复性场度量 RFM）**
直觉：站在悬崖边 1 米和 10 米，都「当前安全」，但可恢复性完全不同。把安全集 `S_safe` 收缩成**鲁棒可控不变集 `R_N`（可恢复集）**：从 `x` 出发，在扰动集 `W` 与有界控制权限下，是否存在恢复策略使系统在 N 步内仍停在安全集内。定义可恢复裕度 `ρ(x)`、恢复时间 `TR(x)` 与失效时间 `TTF(x)`，并强制 **`TR(x) ≤ TTF(x)`**。
关键洞见：安全不是「没越界」，而是「还有足够余量回来」。用**控制障碍函数 + 可达性分析**给 `ρ` 一个在线可算且**保守**的估计，宁可误报不可漏报（禁止 false-safe）。

**灵感 3（前驱 → 失效前驱观测器 FPO）**
直觉：接触刚度估计下降、无源性残差转为能量注入、指令-测量相位漂移增大、力矩饱和占空比上升、动力学残差变大、机械能导数转正——这些都是失效前的「动力学指纹」。用 CUSUM 序贯检验 + 保形预测下置信界，在真正的失效之前 `δ_warn` 处报警，且要求预警提前量 `T_ew ≥ T_rec + T_comm + T_margin`。
关键洞见：把「失败检测」从阈值后验改造成**序贯假设检验 + 校准的保守下界**，让报警既有统计保证又有可执行的提前量。

**灵感 4（动力学 × 失败恢复合流 → 恢复契约分级 RCT + 动力学可恢复闭环 DREC）**
直觉：恢复不是单一动作，而是分级动作库：`a0` 拒绝扰动、`a1` 重调阻抗、`a2` 重接触/重规划、`a3` 撤出、`a4` 安全停、`a5` 硬件急停。每个动作有前置条件、后置保证、耗时、权限需求与代价。选择规则不是「最省事」，而是**满足 `post(a) ⊆ R_N` 且 `T_a ≤ TTF(x)` 的可行动作里代价最小者**。
关键洞见：DREC 把「编译（DACC）→ 评估（RFM）→ 预警（FPO）→ 恢复（RCT）→ 取证（DIF）」串成一个以**可恢复性不变式**为守门人的闭环，恢复从「事后回退」升级为「前驱触发的可行性恢复」。

**灵感 5（预算与仲裁 → PCE+++++ 与恢复仲裁 RAP）**
直觉：新增 `B_dyn`（模型不确定性预算：在线辨识算力、模型误差 `ε_dyn` 配额）与 `B_rec`（可恢复性预算：能量、力矩头寸、热裕度、可恢复裕度下限 `ρ_min`、恢复时限），由 `B_rec` 吸收原 `B_exec`。施加**可恢复性不变式**：任何时刻 `ρ(x_t) ≥ ρ_min` 且 `B_rec ≥ b_min`，否则该动作不可行，与 VOI 多大无关。
关键洞见：恢复是时间关键且可能发生在 ROS 失联时，因此需要**有界本地自主 + 证明携带令牌**的仲裁 `RAP`：风险低于 `L_local` 就地恢复、事后对账，绝不因等待云端授权而错过 `TTF`。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（动力学可行阻抗 DACC）** 设阻抗元组 `K = (M_d, K_p, K_d)`。动力学实现映射 `Ψ: K × (M,C,g,J,τ_max,Δt,T_d,Z_env,ε_dyn) → 闭环系统 G_K`。定义归一化裕度向量
```
γ_dyn(K) = ( γ_ζ, γ_τ, γ_φ, γ_p, γ_s, γ_bw )
γ_ζ  = min_i (ζ_i − ζ_min)/ζ_min ,      ζ_i = K_d,i / (2√(K_p,i·M_d,i))
γ_τ  = 1 − max_t ‖τ(K, x_t)‖∞ / τ_max
γ_φ  = (φ_m − φ_min)/φ_min             （含延迟 T_d 的相位裕度）
γ_p  = E_tank / E_tank_max             （能量槽无源性裕度，E_tank ≥ 0）
γ_s  = (σ_min(JJᵀ) − σ_J)/σ_J          （远离奇异位形）
γ_bw = 1 − (ω_n,max·Δt)/0.2 ,          ω_n = √(K_p/M_d)
```
动力学可行域 `D_adm(x) = { K : γ_dyn(K;x) ≥ 0 }`，动力学一致安全集
```
K_safe^dyn = K_safe^scene ∩ D_adm(x)
```
若该交集为空，允许**保恢复松弛**：仅沿 `αK_p (α≤1)` 降刚度、`βK_d (β≥1)` 升阻尼方向搜索，且始终满足 `γ_dyn ≥ 0` 与可恢复性不变式；仍为空则缩小任务（降速/缩短接触行程）或安全停。编译输出**动力学一致性证书**
```
J_dyn = (γ_dyn, K*, model_id, T_d, Δt, W_env, timestamp, SHA256)
```
能量槽离散更新 `E_{k+1} = clip(E_k + Δt·(τᵀq̇ − P_diss), 0, E_max)`；若 `E_k < 0` 则拒绝该 `K`（禁止向环境注入净能量）。

**定义 162（可恢复性场度量 RFM）** 状态 `x=(q,q̇)∈X`，控制 `u∈U`，扰动 `w∈W`，安全集 `S_safe`（关节限位、力上限、无碰撞、接触模式保持）。鲁棒 N 步可恢复集
```
R_0 = S_safe
R_{k+1} = { x ∈ R_k : ∃u∈U, ∀w∈W, f(x,u,w) ∈ R_k }
R_N = R_N ，   R_∞ = 最大鲁棒受控不变子集 ⊆ S_safe
```
可恢复裕度 `ρ(x) = dist_M(x, ∂R_∞)`（动能度量 `G=blkdiag(M(q),M(q))`）。在线估计必须**保守**：
```
ρ̂(x) = ρ_approx(x) − L_ρ·ε_dyn ≤ ρ(x)      （禁止 false-safe）
```
失效时间 `TTF(x) = min{ t : x(t) ∉ S_safe | u = 冻结/失效, w 最坏 }`；恢复时间 `TR(x) = min_{a∈A_rec} T_a(x)` 满足后置可达。可恢复性不变式
```
INV_rec:  ∀t:  ρ(x_t) ≥ ρ_min  ∧  TR(x_t) ≤ TTF(x_t)  ∧  B_rec ≥ b_min
```
`R_∞ = {h_rec ≥ 0}` 时用离散控制障碍函数证书 `h_rec(x_{k+1}) ≥ (1−α_cbf)·h_rec(x_k)`。

**定义 163（失效前驱观测器 FPO）** 前驱特征向量
```
φ_k = ( −ΔK̂_env,  r_pass,  Δφ_cmd-meas,  σ_τ,  ‖e_dyn‖,  V̇⁺ )
r_pass   = ∫ (τᵀq̇ − dE/dt) dt        （无源性残差，>0 表示能量注入）
e_dyn    = ‖M̂q̈ + Ĉq̇ + ĝ − τ − JᵀF̂_ext‖   （动力学残差）
V̇⁺      = max(0, d/dt(½q̇ᵀMq̇ + V_pot))
```
失效流形 `M_fail = ∂S_safe`，失效距离 `d_fail(x,φ)`。用保形预测给保守下界 `d_lcb`，并用 CUSUM 序贯检验
```
g_k = max(0, g_{k−1} + log(p_1(φ_k)/p_0(φ_k)) − ν) ,   alarm if g_k > h
```
报警条件 `alarm = (g_k > h) ∨ (d_lcb < δ_warn)`。要求提前量
```
T_ew = t_fail − t_alarm ≥ T_rec + T_comm + T_margin
```
若 `d_lcb / |ḋ_fail| < T_rec`，说明常规恢复已太晚，直接进入反射层 `a4/a5`。校准目标：`P(虚警) ≤ α_fa`，`P(检测延迟 ≤ δ_det) ≥ 1−β_det`。

**定义 164（恢复契约与分级 RCT）** 恢复动作库 `A_rec = {a0…a5}`，每个动作是带契约的四元组
```
a = ( pre_a ⊆ X,  post_a: X→2^X,  T_a,  b_a,  cost_a )
cost_a = λ_t·T_a + λ_e·E_a + λ_l·L_task + λ_r·Risk_a
```
可行性（Hoare 风格）：
```
feasible(a,x) ⇔ x ∈ pre_a ∧ post_a(x) ⊆ R_∞ ∧ T_a ≤ TTF(x) ∧ b_a ≤ B_rec
a* = argmin_{a: feasible(a,x)} cost_a
```
分级顺序与降级单调性：`a0 ⊑ a1 ⊑ a2/a3 ⊑ a4 ⊑ a5`；`a5`（硬件急停）无前置、`T_a5` 最小，故恒可行，保证活性。契约组合 `{P}a{Q}, {Q}b{R} ⇒ {P}a;b{R}`，并要求 `T_a+T_b ≤ TTF`、`ρ` 单调不降。

**定义 165（动力学可恢复执行闭环 DREC）** 算子 `DREC(M, task, δ_f^req)`：


**定义 166（五维预算 PCE+++++ 与可恢复性不变式）** `B = (B_dyn, B_rec, B_scene, B_intent, B_ros)`，其中 `B_rec` 吸收并严格强于原 `B_exec`：
```
B_dyn  = (ε_dyn_budget, ident_ops, sim_budget)
B_rec  = (E_energy, τ_headroom, T_thermal, ρ_min, TR_deadline, b_min)
B_rec ⊃ B_exec = (WCET_slack, Bus_bw_slack, Thermal_slack, Prio_headroom)
```

VOI 改为**带约束的优化**：
```
maximize  voi_dyn(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_dyn(π) − cost_exec(π)
s.t.      ρ(x_{k+1}) ≥ ρ_min  ∧  B_rec ≥ b_min  ∧  TR(x) ≤ TTF(x)
```
降级表：`B_dyn` 耗尽 ⇒ 使用最坏情形鲁棒动力学（升阻尼、降刚度）、关闭在线学习；`B_rec < θ_rec` ⇒ 放弃任务、禁止探测、进入恢复；`B_scene` 耗尽 ⇒ 通用场景先验；`B_intent` 耗尽 ⇒ 默认约束；`B_ros` 异常 ⇒ 本地闭环 + RAP 本地自主。**任何降级都不得先花掉恢复裕度**。

**定义 167（动力学完整性指纹 DIF）** 在执行证据之外新增可复核的动力学/恢复证据：
```
DIF = ( EV-exec, J_dyn, J_rec, {precursor_t}, {ρ_t}, energy_account, token_trace )
J_rec = ( x_0, a*, {x_t}, {h_rec(x_t)}, {ρ_t}, tok, model_id, SHA256 )
```

验证器在模型误差 `≤ ε_dyn` 下重放轨迹，检查：`h_rec` 不违反 CBF 下降条件、`post_a` 成立、`INV_rec` 全程成立、预算单调且未越界。**声音性**：若验证通过且 `ε_dyn ≤ e_max`，则「执行过程中始终可恢复/已按契约恢复」为真。DIF 回答 EV-exec 回答不了的问题——「为什么没有失败 / 为什么这次恢复是合法的」。

**定义 168（恢复仲裁协议 RAP）** 恢复令牌 `tok = (rid, level, pre_hash, expiry, sig)`，幂等键 `rid` 保证至多一次。本地自主等级
```
L_local(x) = 3  if TR(x) ≤ TTF(x) − T_wait   else  2
authorize(a,x,ρ̂,comm_ok):
    if ρ̂ ≤ 0:                         return issue_local(a, 'reflex')        # 已到边界，不等待
    if a.level ≤ L_local(x) ∨ ¬comm_ok: return issue_local(a, 'bounded_autonomy')
    tok = request_remote(a, timeout=T_wait)
    return tok if tok else issue_local(a, 'timeout')
```
冲突消解按全序 `(level, term, timestamp)`；通信恢复后以 EPIR 日志对账，恢复记录可合并（幂等 + 末写胜出带 term）。**安全性**：任何动作执行前必有合法令牌或本地自主谓词成立；**活性**：若 `TR(x) ≤ TTF(x)` 且通信不可用，本地自主在 `T_wait < TTF − T_a` 内触发。

### IP-161 DACC（动力学可行阻抗编译）

```python
class DynamicsAdmissibleCompiler:
    def __init__(self, robot, tau_max, dt, zeta_min=0.3, pm_min=45.0,
                 sigma_J_min=0.05, torque_margin=0.15):
        self.robot = robot            # M, C, g, J
        self.tau_max = tau_max
        self.dt = dt
        self.zeta_min = zeta_min
        self.pm_min = math.radians(pm_min)
        self.sigma_J_min = sigma_J_min
        self.torque_margin = torque_margin

    def _margins(self, K, state, x_d, xdot_d, Z_env, delay_T):
        M, C, g, J = self.robot.dynamics(state.q, state.qdot)
        zeta = K.Kd / (2 * np.sqrt(K.Kp * K.Md + 1e-9))
        wn = np.sqrt(K.Kp / (K.Md + 1e-9))
        gamma_zeta = np.min(zeta - self.zeta_min) / self.zeta_min
        gamma_bw = 1.0 - np.max(wn) * self.dt / 0.2

        tau = J.T @ (K.Kp * (x_d - state.x) + K.Kd * (xdot_d - state.xdot)) \
              + g + C @ state.qdot + self._contact_feedback(state, Z_env)
        gamma_tau = 1.0 - np.max(np.abs(tau)) / self.tau_max

        E_tank, ok_pass = self._passivity_tank(K, state, Z_env, delay_T)
        gamma_p = E_tank / self.E_tank_max if ok_pass else -1.0
        phi_m = self._phase_margin(K, Z_env, delay_T)
        gamma_phi = (phi_m - self.pm_min) / self.pm_min

        sigma_min = np.linalg.svd(J @ J.T, compute_uv=False).min()
        gamma_s = (sigma_min - self.sigma_J_min) / self.sigma_J_min

        g = np.array([gamma_zeta, gamma_bw, gamma_tau, gamma_p, gamma_phi, gamma_s])
        return g, tau, E_tank

    def compile(self, K_scene, state, x_d, xdot_d, Z_env, delay_T, B_dyn):
        best = None
        for K in self._candidates(K_scene):
            gamma, tau, E_tank = self._margins(K, state, x_d, xdot_d, Z_env, delay_T)
            if np.all(gamma >= 0.0):
                score = self._task_score(K) - self._conservatism(K)
                if best is None or score > best.score:
                    best = Candidate(K, gamma, E_tank, score)
        if best is None:
            K = self._recovery_relax(K_scene)        # 只降 Kp / 升 Kd
            gamma, tau, E_tank = self._margins(K, state, x_d, xdot_d, Z_env, delay_T)
            if not np.all(gamma >= 0.0):
                if B_dyn.strict:                     # 模型预算已不足以担保
                    return None
                return SafeStop(K='fallback', reason='NO_DYNAMICS_CONSISTENT_K')
            best = Candidate(K, gamma, E_tank, self._task_score(K))
        best.cert = J_dyn(best.gamma, best.K, self.robot.model_id,
                          delay_T, self.dt, Z_env.params)
        return best
```

### IP-162 RFM（可恢复性场度量）

```python
class RecoverabilityField:
    def __init__(self, dynamics, safe_set, horizon_N=50, lip_rho=1.0):
        self.dyn = dynamics
        self.R = safe_set
        self.N = horizon_N
        self.lip_rho = lip_rho

    def build(self, W):
        R = self.safe_set
        for _ in range(self.N):
            R_next = self._pre(R, W)                 # {x: ∃u ∀w f(x,u,w) ∈ R}
            if R_next.is_empty():
                break
            R = R_next
        self.R_inf = R
        self.critic = self._fit_critic(R)            # 学习/网格近似 rho_approx
        return R

    def margin_lcb(self, x, eps_dyn):
        # 保守下界：近似值减去 Lipschitz×模型误差，禁止 false-safe
        return self.critic(x) - self.lip_rho * eps_dyn

    def ttf(self, x, W):
        return self._time_to_leave(self.safe_set, x, control='freeze', W=W)

    def recovery_time(self, x, a):
        return a.T(x)

    def invariant_ok(self, x, a, rho_min):
        return (self.margin_lcb(x, self.dyn.eps_dyn) >= rho_min and
                self.recovery_time(x, a) <= self.ttf(x, self.dyn.W))
```

```python
class FailurePrecursorObserver:
    def __init__(self, d_model, conformal_q, nu=0.5, h=5.0, delta_warn=0.2):
        self.d_model = d_model
        self.q = conformal_q          # 保形分位数（离线校准）
        self.nu, self.h, self.delta_warn = nu, h, delta_warn
        self.g = 0.0

    def observe(self, telem, cmd):
        e = self._dynamics_residual(telem, cmd)
        feats = np.array([
            -self._dK_env(telem),
            self._passivity_residual(telem, cmd),
            self._phase_drift(telem, cmd),
            self._saturation_fraction(cmd),
            np.linalg.norm(e),
            self._positive_energy_rate(telem),
        ])
        llr = self._loglik_prefailure(feats) - self.nu
        self.g = max(0.0, self.g + llr)
        d_hat = self.d_model(feats)
        d_lcb = d_hat - self.q                   # 保形下界
        dd = self._d_fail_rate(feats)
        alarm = (self.g > self.h) or (d_lcb < self.delta_warn)
        reflex = (abs(dd) > 1e-6) and (d_lcb / abs(dd) < self.T_rec)
        return Precursor(d_lcb, dd, self.g, alarm, reflex)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|

| FPO | O(dof²)/周期，CUSUM O(1) | O(1)+滑动窗 | `P(虚警) ≤ α_fa`，`P(检测延迟 ≤ δ_det) ≥ 1−β_det` |

| DREC | O(闭环) + O(dof³) | 复用 + DIF 日志 | `INV_rec` 全程成立或安全停 |

**正确性定理（DREC）**：假设 A66–A72 成立：
- **(A66)** 动力学模型误差有界 `‖ΔM,ΔC,Δg,ΔJ‖ ≤ ε_dyn`，且 `B_dyn` 覆盖该误差。
- **(A67)** `R_N` 由可达性近似，误差满足 Lipschitz 界 `|ρ̂−ρ| ≤ L_ρ·ε_dyn`，在线使用下界。
- **(A68)** FPO 经保形校准：虚警率 `≤ α_fa`，检测延迟以概率 `1−β_det` 不超过 `δ_det`。
- **(A69)** 每个恢复契约 `(pre,post,T_a)` 在其动力学域内成立。
- **(A70)** RAP 保证令牌至多一次，且本地自主先于 `TTF` 触发。
- **(A71)** 五预算单调消耗，`INV_rec` 为所有动作的准入条件。
- **(A72)** 场景先验 `K_safe^scene` 仍是 `K_safe^dyn` 的超集约束（第 60 轮 SIC 保持有效）。

则：
1. **动力学一致性**：若 `K ∈ K_safe^dyn`，则闭环在模型误差 `ε_dyn`、延迟 `T_d` 与 `Z_env` 下无源、接触稳定、力矩不饱和，且最坏归一化裕度 `≥ 0`。
2. **可恢复性声音性**：若 `ρ̂(x) ≥ ρ_min`，则真实 `ρ(x) ≥ ρ_min`（无 false-safe）；`TR(x) ≤ TTF(x)` 时存在可行恢复动作。
3. **恢复安全与活性**：任何按 RCT 契约执行、经 RAP 授权的恢复序列，要么在 `S_safe` 内终止，要么安全停；在通信不可用且 `TR ≤ TTF` 时，本地自主在 `T_wait` 内触发，概率 `≥ 1−α_fa−β_det`。
4. **证据声音性**：若 DIF 通过验证且 `ε_dyn ≤ e_max`，则「执行全程满足 `INV_rec` 或已按契约恢复」为可复核事实。
5. **预算安全**：任一 `B` 耗尽，触发对应降级且不降低 `ρ` 下界；`B_rec` 耗尽 ⇒ 立即放弃任务进入恢复/安全停。

```python
class DynamicsAdmissibleCompiler:
    def _margins(self, K, state, x_d, xdot_d, Z_env, delay_T):
        M, C, g, J = self.robot.dynamics(state.q, state.qdot)
        zeta = K.Kd / (2 * np.sqrt(K.Kp * K.Md + 1e-9))
        wn = np.sqrt(K.Kp / (K.Md + 1e-9))
        gamma_zeta = np.min(zeta - self.zeta_min) / self.zeta_min
        gamma_bw = 1.0 - np.max(wn) * self.dt / 0.2
        tau = J.T @ (K.Kp * (x_d - state.x) + K.Kd * (xdot_d - state.xdot)) \
              + g + C @ state.qdot + self._contact_feedback(state, Z_env)
        gamma_tau = 1.0 - np.max(np.abs(tau)) / self.tau_max
        E_tank, ok_pass = self._passivity_tank(K, state, Z_env, delay_T)
        gamma_p = E_tank / self.E_tank_max if ok_pass else -1.0
        gamma_phi = (self._phase_margin(K, Z_env, delay_T) - self.pm_min) / self.pm_min
        sigma_min = np.linalg.svd(J @ J.T, compute_uv=False).min()
        gamma_s = (sigma_min - self.sigma_J_min) / self.sigma_J_min
        return np.array([gamma_zeta, gamma_bw, gamma_tau,
                         gamma_p, gamma_phi, gamma_s]), tau, E_tank

    def compile(self, K_scene, state, x_d, xdot_d, Z_env, delay_T, B_dyn):
        best = None
        for K in self._candidates(K_scene):
            gamma, _, E_tank = self._margins(K, state, x_d, xdot_d, Z_env, delay_T)
            if np.all(gamma >= 0.0):
                score = self._task_score(K) - self._conservatism(K)
                if best is None or score > best.score:
                    best = Candidate(K, gamma, E_tank, score)
        if best is None:
            K = self._recovery_relax(K_scene)          # 仅降 Kp / 升 Kd
            gamma, _, E_tank = self._margins(K, state, x_d, xdot_d, Z_env, delay_T)
            if not np.all(gamma >= 0.0):
                return None if B_dyn.strict else SafeStop('NO_DYNAMICS_CONSISTENT_K')
            best = Candidate(K, gamma, E_tank, self._task_score(K))
        best.cert = J_dyn(best.gamma, best.K, self.robot.model_id, delay_T, self.dt)
        return best
```

```python
        feats = np.array([
            -self._dK_env(telem),               # 接触刚度下降
            self._passivity_residual(telem, cmd),  # 能量注入
            self._phase_drift(telem, cmd),      # 相位漂移
            self._saturation_fraction(cmd),     # 力矩饱和占空比
            self._dyn_residual_norm(telem, cmd),# 动力学残差
            self._positive_energy_rate(telem),  # 机械能上升
        ])
        self.g = max(0.0, self.g + self._loglik_prefailure(feats) - self.nu)
        d_lcb = self.d_model(feats) - self.conformal_q
        dd = self._d_fail_rate(feats)
        alarm = (self.g > self.h) or (d_lcb < self.delta_warn)
        reflex = (abs(dd) > 1e-6) and (d_lcb / abs(dd) < self.T_rec)
        return Precursor(d_lcb, dd, self.g, alarm, reflex)
```

### IP-166 PCE+++++（五维预算 + 可恢复性不变式）

```python
class RecoverabilityBudget:
    def __init__(self, E=1.0, tau=0.3, thermal=0.5,
                 rho_min=0.25, TR_deadline=0.2, b_min=0.2):
        self.E, self.tau, self.thermal = E, tau, thermal
        self.rho_min, self.TR_deadline, self.b_min = rho_min, TR_deadline, b_min

    @property
    def available(self):
        return min(self.E, self.tau, self.thermal)

    def consume(self, energy, torque, thermal):
        self.E -= max(0.0, energy)
        self.tau -= max(0.0, torque)
        self.thermal -= max(0.0, thermal)

    def exhausted(self):
        return (self.E < self.b_min or self.tau < self.b_min
                or self.thermal < self.b_min)


def constrained_voi(pi, B_dyn, B_rec, rho_next, TR, TTF):
    if rho_next < B_rec.rho_min or TR > TTF or B_rec.exhausted():
        return float('-inf')                    # 恢复裕度不足 ⇒ 动作不可行
    if B_dyn.exhausted():
        pi = pi.with_conservative_dynamics()    # 最坏情形模型，关闭学习
    return (voi_meta_pessimistic(pi)
            - cost_cog(pi) - cost_dyn(pi, B_dyn) - cost_exec(pi, B_rec))
```

```python
class RecoveryArbitrator:
    def authorize(self, name, a, x, rho, comm_ok):
        if rho <= 0.0:
            return self._issue_local(name, x, 'reflex')          # 已到边界：反射
        if a['level'] <= self.L_local or not comm_ok:
            return self._issue_local(name, x, 'bounded_autonomy')
        tok = self._request_remote(name, x, timeout=self.T_wait)
        return tok if tok else self._issue_local(name, x, 'timeout')

    def _issue_local(self, name, x, reason):
        rid = hash((name, x.key(), reason))
        if rid in self.executed:
            return Existing(rid)                                 # 至多一次
        self.executed.add(rid)
        return RecoveryToken(rid, RECOVERY[name]['level'], reason)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| DACC | O(N_c·dof³)/编译；回退 O(dof³) | O(dof²) | 五重裕度 `γ_dyn ≥ 0`，含延迟/无源/饱和/奇异 |
| RFM | 离线 O(N·|X|·|U|·|W|)；在线 O(1)+O(dof²) | O(|X|) | `ρ̂ ≤ ρ`，false-safe = 0 |
| FPO | O(dof²)/周期，CUSUM O(1) | O(1)+滑窗 | 虚警 `≤ α_fa`，检测延迟 `≤ δ_det`（概率 `1−β_det`） |
| RCT | O(6) | O(1) | 契约组合保持 `INV_rec`；`a5` 恒可行 |
| RAP | O(1) | O(rid 日志) | 至多一次；安全 + 活性 |
| DREC | O(闭环)+O(dof³) | 复用+DIF | `INV_rec` 全程或安全停 |

**正确性定理（DREC）**：若 A66–A72 成立，则：
1. `K ∈ K_safe^dyn ⇒` 闭环无源、接触稳定、力矩不饱和，最坏归一化裕度 `≥0`；
2. `ρ̂(x) ≥ ρ_min ⇒ ρ(x) ≥ ρ_min`（无 false-safe）；`TR ≤ TTF` 时存在可行恢复；
3. RCT+RAP 的恢复序列在 `S_safe` 内终止或安全停；通信不可用时本地自主先于 `TTF` 触发；
4. DIF 通过验证且 `ε_dyn ≤ e_max ⇒`「全程满足 `INV_rec` 或已按契约恢复」为可复核事实；
5. 任一 `B` 耗尽触发降级且不降低 `ρ` 下界；`B_rec` 耗尽 ⇒ 放弃任务、进入恢复/安全停。

## 5. 本轮最大风险

**一句话**：`R_N/ρ` 建立在近似动力学模型上，若模型在恢复关键方向系统性偏乐观（低估饱和、接触丢失、延迟），系统会陷入「自以为可恢复」的 **false-safe**，把可提前回退的扰动拖成不可逆失效——比明确不安全更危险；必须坚持「`ρ` 只认可达性/保形下界」「与学习无关的能量反射层 `a4/a5` 永不退役」「`B_dyn` 耗尽即切最坏情形模型」「DIF 事后可复核」四重护栏，确保可恢复性估计永不超前于真实动力学。
