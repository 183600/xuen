# 第 63 轮（承接第 62 轮「ROSE」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「共享控制」×「可解释性」）

> 第 62 轮用 ROSE 补上了在线学习（OLP 遗憾界）、鲁棒编译（WCV+RSC）、场景进化（SBR+SHC）、对话屏蔽（Shield）与预算对抗（OCB）。但 ROSE 仍然是一个**「全自主系统 + 人只在离散对话层出现」**的方案，它留下了三个新短板：
> 1. **人只有「说约束」的入口，没有「共同驾驶」的入口**：DMS/Shield 处理的是离散约束提案，而真实共享控制里人给的是连续的速度/力矩/遥操作输入。Shield 的凸投影无法约束连续动作；人一旦猛打摇杆，ROSE 没有任何前向不变性保证。且第 62 轮从未定义「谁在什么时刻该拥有多少权限」——α 根本不存在。
> 2. **J_rose 是「机器可读、人不可读」的证书**：ρ_rob、r_t、R̂_c 对操作员是黑箱。系统可能「安全但不可解释」：机器人拒绝执行时，人不知道为什么、也不知道该不该接管。第 62 轮把安全做成了可证明，却把**信任与协作**留在了系统之外。
> 3. **第 62 轮的单点风险对人是隐形的**：若 RSC 低估 r_t，J_rose 会静默降级，而人从未被告知「我在这里可能算错了」。共享控制本可以用人的判断兜住模型错误，但 ROSE 没有把不确定性变成**可沟通的信号**。
>
> 本轮把「共享控制」与「可解释性」合成一个闭环 XSC：**安全与权限解耦**（CBF 过滤使任何权限分配都安全），**解释与证据绑定**（反事实可执行、归因可校验、半径可证明），**信任与可靠性对齐**（用解释校准人，而不是用解释说服人）。

## 0. 直觉与动机

**灵感 1（共享控制 → SCA + RCBF：权限无关的安全，安全之上的权限）**
直觉：把人也看成一条策略 π_H，机器人是 π_R；混合动作 u_nom = α·u_H + (1−α)·u_R。关键洞见是**先保证安全，再谈权限**：让混合动作统一过一个鲁棒控制屏障函数 QP（RCBF-QP）。这样无论 α 取 0 还是 1、无论人怎么打摇杆，只要 QP 可行，状态就永远停在安全集内。于是 α 可以自由地按「谁更强、谁更该被信任、解释是否有效」来分配，而**安全性不依赖 α**。这是第 62 轮 Shield 的严格升级：从「投影离散约束」升级为「对连续动作的前向不变性保证」。鲁棒化直接复用 RSC 的球：把 CBF 约束按 L_hφ·r_t 收紧，物理不确定性越大，安全护栏自动内缩。

**灵感 2（可解释性 → XCE + MSA：解释必须是可执行的干预，不是热力图）**
直觉：操作员问「为什么减速」，有用的回答不是「因为摩擦特征激活高」，而是「**如果摩擦系数再低 15%，0.2 秒后接触力会超过 40N；所以我现在把权限交给你**」。因此本轮把解释定义成**反事实干预**：存在一个最小扰动 δ*，执行它会让决策翻转；δ* 可执行、可证伪。结构归因则用**模块级 Shapley**：把 USR/MEL/OLP/WCV/SCA 当作 5 个玩家，精确枚举 32 个联盟，回答「这次决策主要该记在谁头上」。更重要的是，每个解释都带一个**可信半径 ρ_xai**：当物理不确定球 r_t 超过 ρ_xai 时，任何「自信的解释」都不可信，系统只允许输出「我不确定，请人工确认」——解释系统自己必须会说「不知道」。

**灵感 3（两灵感合流 → 解释门控的共享控制）**
直觉：解释不是界面装饰，而是**权限协商的信道**。二者咬合成三条规则：
- **可信性规则**：r_t > ρ_xai ⇒ 解释不可断言 ⇒ 权限向人倾斜并显式报告不确定性（而不是编一个自洽的故事）；
- **过度信任规则**：τ_H > ρ_R（人过度信任机器）⇒ 解释必须强调反事实风险与不确定球，必要时主动降权；
- **信任不足规则**：τ_H < ρ_R（人不信任机器）⇒ 解释展示可核验的能力证据与场景覆盖，避免无谓接管。
于是 α 与解释策略 π_exp 联合设计：**只在解释能改变人的决策时才解释**（VOI>0），把认知带宽当作和算力一样的预算。

**灵感 4（信任校准 TCM：过度信任比不信任更危险）**
直觉：共享控制的事故往往不是「人不理机器」，而是「人太信机器」。用行为信号（接管率、响应时延、建议采纳率、注意力、权限使用）在线估计信任 τ_H，与真实可靠性 ρ_R 比较得到校准误差；把解释当作信任的控制输入，用 Robbins-Monro 型更新把 τ_H 拉向 ρ_R。目标不是让人更信任，而是让信任**匹配**能力。

**灵感 5（主动解释 AXQ：解释是认知预算）**
直觉：每次都全量解释会把人淹没。把解释模式 {none, uncertainty, counterfactual, attribution, full} 当作臂，收益是决策质量提升（VOI）减去认知成本与风险；用 EXP3/UCB 在线选择，伪遗憾 O(√(KT log K))。但当 r_t > ρ_xai 时，「uncertainty」是硬性必选，不受老虎机支配——安全规则永远压过学习规则。

**灵感 6（闭环 XSC：把解释放到慢流，把安全留在快流）**
直觉：沿用第 62 轮「语义流承载学习、实时流零学习写」的时序隔离：反事实生成、Shapley、信任更新、权限头学习全部在语义流（10–100Hz）；实时流只做锚点读、RCBF-QP、派发与日志（1–10kHz），解释绝不进关键路径。XSC = ROSE + SCA/RCBF + XCE/MSA/ECV + TCM + AXQ + ECL，不推翻第 62 轮任何接口。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（可解释共享控制闭环 XSC）**：XSC = (ROSE, SCA, RCBF, XCE, MSA, ECV, TCM, AXQ, ECL, J_xsc)。定位：ROSE 的「连续人机共享 × 可验证解释」升级；实时流仍是零学习写操作。
- **定义 186（共享控制动作 SCA）**：u_nom = α·u_H + (1−α)·u_R，α∈[0,1] 为人的权限份额；α 由权限头 α_t = σ(wᵀψ_t) 给出，ψ_t = [1, q̂_H, q̂_R, r_t, U_ep, novelty, τ_H, VOI]。
- **定义 187（权限学习）**：w_{t+1} = P_𝒲(w_t − η_t ∇ℓ_t^sc)，ℓ_t^sc = 任务代价 + λ_h·切换代价；遗憾 ≤ D_w·G_w·√T（静态比较器）。
- **定义 188（鲁棒 CBF 过滤 RCBF）**：h̄(x) = h(x;φ̂) − L_hφ·r_t；u* = argmin_{u∈𝒰}‖u−u_nom‖² s.t. ∇h̄ᵀ(f+gu) + γ h̄ ≥ 0。任何 α、任何 u_H 下，若 QP 可行则 h̄(x(t))≥0。
- **定义 189（解释对象 XCE）**：E_t = (mode, target, δ*, Δπ, evidence_hash, ρ_xai, fidelity, ts)；mode ∈ {none, uncertainty, counterfactual, attribution, full}。
- **定义 190（反事实与决策裕度）**：δ* = argmin_{δ∈Δ_exp}‖δ‖₂ s.t. π(x⊕δ) ≠ π(x)；决策裕度 m(x) = min_{δ: π(x⊕δ)≠π(x)}‖δ‖（在可编辑子空间上）。
- **定义 191（模块 Shapley 归因 MSA）**：玩家 M={USR,MEL,OLP,WCV,SCA}，v(S)=−ℓ(π(x_S))；φ_i 为精确 Shapley（2⁵=32 次评估）；交互误差 ε_int = max_S |v(S) − (v(∅)+Σ_{i∈S}φ_i)|。
- **定义 192（解释可信半径 ECV）**：ρ_xai = min(ρ_attr, m(x)/L_π, ρ_max)，ρ_attr = (s_(k)−s_(k+1))/(2L_s)；规则：r_t ≤ ρ_xai 方可断言解释，否则仅允许 uncertainty 模式。
- **定义 193（信任校准 TCM）**：τ_H,t = σ(θᵀ b_t)，b_t 为行为特征；ρ_R,t 为可靠性 EWMA；校准误差 C_t = |τ_H,t − ρ_R,t|；τ_{t+1} = τ_t + η_t(χ_t − τ_t)。
- **定义 194（主动解释 AXQ）**：VOI(m) = E_Y[max_a E(U|E_m,Y) − max_a E(U|∅)] − λ_c·cost(m) − λ_s·risk(m)；m* = argmax VOI，r_t > ρ_xai 时强制 m=uncertainty。
- **定义 195（解释-证书绑定 ECL / J_xsc）**：J_xsc = (J_rose, α_t, u_H, u_R, u*, h̄, ρ_xai, explanation_hash, τ_H, C_t, mode, human_ack, fallback_flag)；Valid ⇔ Valid(J_rose) ∧ (h̄≥0 ∨ fallback) ∧ explanation_valid ∧ authority_trace_consistent。
- **定义 196（XSC 闭环算子）**：语义流 [意图/能力估计 → XCE/MSA → ECV 判定 → AXQ → TCM → 权限 OGD → ROSE 记账]；实时流 [锚点读 → u_nom → RCBF-QP → 派发/日志 → J_xsc]。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# 实时流：安全与权限解耦（零学习写，<1ms）
u_nom = alpha * u_H + (1 - alpha) * u_R
u_star = RCBF_QP(u_nom, phi_hat, r)          # 按 L_hphi*r 收紧；不可行则安全回退
# 语义流：解释、信任、权限学习（绝不进实时路径）
E = XCE.generate(x, decision, r)             # 反事实 + Shapley + 可信半径
if r > E.rho_xai: E = uncertainty_only(r)    # 解释自己会说「不知道」
mode = AXQ.select(VOI)                       # 解释认知预算
tau = TCM.update(behavior, E, outcome)       # 信任→可靠性
w = OGD(w, grad_authority_loss)              # 权限头在线更新
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（权限无关安全性）**：RCBF-QP 的可行性蕴含前向不变性；安全性不依赖 α 与 u_H。这是共享控制能自由分配权限的前提。
- **引理 2（物理偏差免疫）**：若 φ*∈B(φ̂,r) 以概率 ≥1−α_cal（承接第 62 轮 RSC 覆盖引理），则 h̄≤h(·;φ*)，真实安全概率 ≥1−α_cal。
- **引理 3（权限最优性间隙）**：权限头在 OCO 假设下静态遗憾 ≤ D_w G_w √T；能力估计误差 ε_q 经平滑映射放大为 O(L_α ε_q) 的权限次优。
- **引理 4（解释可信性）**：r_t ≤ ρ_xai ⇒ top-k 归因排序不变、反事实方向有效；r_t > ρ_xai ⇒ 任何确定性断言都可能被真实参数翻转，必须降级为 uncertainty 模式。
- **命题 1（信任校准收敛）**：在解释证据偏差 ≤ b、步长 Robbins-Monro 条件下，τ_t → ρ_R（偏置 ≤ b）。
- **命题 2（解释预算遗憾）**：AXQ 的 EXP3 伪遗憾 O(√(KT log K))，且硬性 uncertainty 规则构成安全下界。
- **定理（XSC-Complete）**：安全 ∨ 权限 ∨ 解释可信 ∨ 信任校准 ∨ 实时性五条同时成立（完整陈述见产物区）。

## 5. 本轮最大风险

**一句话**：若「模型内忠实」被误当作「世界真值」——即 MEL 的 φ̂ 已系统性偏差（第 62 轮 A72 失效），XCE 仍会为错误决策生成自洽、反事实可执行、Shapley 可解释的「完美故事」，而 TCM 又会用这些故事把人校准到**过度信任**；CBF 与解释共用同一个 φ̂，解释层无法独立发现「模型本身错了」，这是本轮「可解释性提升安全」论证的单点假设。

| `J_xsc = (J_rose, α_t, u_H, u_R, u*, h̄, ρ_xai, exp_hash, τ_H, C_t, mode, human_ack, fallback)` | XSC 证书 |

## 2. 形式化定义（完整版）

**定义 185（可解释共享控制闭环 XSC）** XSC 是 ROSE 的连续人机共驾升级。它在第 62 轮「语义流 ∘ 实时流」骨架上挂载：权限仲裁 SCA、鲁棒安全过滤 RCBF、反事实解释 XCE、模块归因 MSA、可信半径 ECV、信任校准 TCM、主动解释 AXQ 与证书绑定 ECL。不变式：
1. **安全与权限解耦**：实时路径上的安全由 RCBF-QP 保证，与 α、u_H 无关；
2. **解释与证据绑定**：任何确定性解释都携带 ρ_xai 与 evidence_hash，r_t>ρ_xai 时只允许 uncertainty 模式；
3. **学习与安全时序隔离**：全部学习/解释/信任更新发生在语义流（10–100Hz），实时流（1–10kHz）零学习写操作（继承第 62 轮 A75）。

**定义 186（共享控制动作 SCA）** 人类策略 π_H 输出 u_H，自主策略 π_R 输出 u_R，权限份额 α∈[0,1]：
u_nom(t) = α_t·u_H(t) + (1−α_t)·u_R(t)。
语义解释：α 是「人拥有多少权威」，不是「人动作占多少比例」的物理混合；在冲突意图下由 RCBF 决定可行投影，α 只改变名义点。权限头：
α_t = clip(σ(w_tᵀψ_t) + ξ_t, 0, 1), ξ_t ~ 𝒩(0, σ_ξ²)（仅语义流侧探索，实时流不加噪）。

**定义 187（权限学习）** 权限头的在线损失：
ℓ_t^sc = ℓ_task(u*) + λ_h·𝟙[α_t ≠ α_{t−1}]·|α_t−α_{t−1}| + λ_e·‖u_H − u_R‖·α_t(1−α_t)，
其中末项惩罚「意图冲突时的无效混合」。更新 w_{t+1} = P_𝒲(w_t − η_t ∇ℓ_t^sc)，η_t = D_w/(G_w√t)。在 ℓ^sc 对 w 凸且 G_w-Lipschitz 的 OCO 假设下，静态遗憾 ≤ D_w G_w √T。ξ_t 以 t^{−1/4} 衰减保证探索充分且渐近消失。

**定义 188（鲁棒 CBF 过滤 RCBF）** 安全集 𝒮(φ) = {x : h(x;φ) ≥ 0}，物理不确定球 B(φ̂_t, r_t)。若 h 对 φ 是 L_hφ-Lipschitz，则
h̄(x) = h(x;φ̂_t) − L_hφ·r_t ≤ min_{φ∈B} h(x;φ)。
RCBF-QP：
u* = argmin_{u∈𝒰} ‖u − u_nom‖²
s.t. ∇_x h̄(x)ᵀ(f(x) + g(x)u) + γ·h̄(x) ≥ 0。
其中 γ>0 为 class-𝒦 线性增益。𝒰 为控制盒约束。单标量约束 + 盒约束的 QP 有闭式投影解（见 IP-195），复杂度 O(m)。

**定义 189（解释对象 XCE）** E_t = (mode, target, δ*, Δπ, evidence_hash, ρ_xai, fidelity, ts)：
- mode ∈ {none, uncertainty, counterfactual, attribution, full}；
- target = (α_t, a_t) 被解释的决策；
- δ* 为定义 190 的最小反事实扰动（uncertainty 模式为 ∅）；
- Δπ = π(x⊕δ*) − π(x) 为预测的决策翻转量；
- evidence_hash = H(x, φ̂_t, r_t, K_safe, α_t) 绑定解释与当时证据；
- ρ_xai 为定义 192 的可信半径；
- fidelity = (sufficiency, counterfactual_validity, stability) 三元组。

**定义 190（反事实与决策裕度）** 在用户可编辑子空间 Δ_exp（物理参数、目标点、场景标签；**不含**安全约束本身）上：
δ* = argmin_{δ∈Δ_exp} ‖δ‖₂  s.t.  π(x⊕δ) ≠ π(x)。
决策裕度 m(x) = min_{δ:π(x⊕δ)≠π(x)} ‖δ‖₂；若在 Δ_exp∩B(0,ρ_max) 内不存在翻转，则记 m(x)=ρ_max 并输出「局部鲁棒」。反事实生成用「梯度方向 + 二分最小步长」：
g = ∇_δ 𝟙[π(x⊕δ)≠π(x)] 的连续松弛（用决策分数差替代指示），δ_dir = g/‖g‖，δ* = −ε*·δ_dir，ε* = min{ε : π(x−εδ_dir) ≠ π(x)}，二分 O(log(1/ε_tol)) 次。

**定义 191（模块 Shapley 归因 MSA）** 玩家集合 M={USR, MEL, OLP, WCV, SCA}，|M|=5。对联盟 S⊆M，把 S 之外的模块替换为基线实现（如 USR→冻结编码器、MEL→φ 先验、OLP→Π_0、WCV→点估计编译、SCA→α=0），得 x_S 与 v(S)=−ℓ(π(x_S))。精确 Shapley：
φ_i = Σ_{S⊆M\{i}} |S|!(|M|−|S|−1)!/|M|! · [v(S∪{i}) − v(S)]。
|M|=5 时只需 2⁵=32 次前向，语义流按需（险情/用户提问）计算。加性解释的忠实度用交互误差 ε_int = max_S |v(S) − (v(∅)+Σ_{i∈S}φ_i)| 度量；ε_int=0 当且仅当 v 可加。

**定义 192（解释可信半径 ECV）** 设归因分数 s(x)∈ℝ^d 为 L_s-Lipschitz，top-k 分界间隙 Δ_s = s_(k)(x) − s_(k+1)(x)，则排序在半径 ρ_attr = Δ_s/(2L_s) 内不变。设决策映射 π 为 L_π-Lipschitz，则决策在 m(x)/L_π 内不变。定义
ρ_xai = min(ρ_attr, m(x)/L_π, ρ_max)。
**断言规则**：r_t ≤ ρ_xai 时允许 counterfactual/attribution/full；r_t > ρ_xai 时仅允许 uncertainty，并在 E_t 中写明「物理不确定球超出解释可信半径，解释不可断言」。

**定义 193（信任校准 TCM）** 行为特征 b_t 由交互日志估计；信任 τ_H,t = σ(θᵀb_t)，θ 用带标签的接管事件在线更新。机器人可靠性 ρ_R,t = EWMA(𝟙[任务成功 ∧ 无需纠正])。校准误差 C_t=|τ_H,t − ρ_R,t|。解释作为信任的控制输入，信任动力学：
τ_{t+1} = τ_t + η_t·(χ_t − τ_t)，
χ_t 为解释/结果揭示的可靠性证据，η_t = η_0·t^{−κ}, κ∈(0.5,1]。目标是把 τ_H 拉向 ρ_R，而非单向增大信任。

**定义 194（主动解释 AXQ）** 解释模式臂 A={none, uncertainty, counterfactual, attribution, full}，K=5。信息价值：
VOI(m) = E_{Y|do(m)}[max_a E(U(a)|E_m,Y) − max_a E(U(a)|∅)] − λ_c·cost(m) − λ_s·risk(m)。
选择 m* = argmax_m VOI(m)。VOI 未知时用 EXP3 采样并按重要性加权更新；伪遗憾 ≤ √(2KT log K)。**硬规则**：r_t > ρ_xai 时 m 强制为 uncertainty（安全下界，不受老虎机支配）；用户显式请求解释时跳过 VOI 门控。

**定义 195（解释-证书绑定 ECL / J_xsc）**
J_xsc = (J_rose, α_t, u_H, u_R, u*, h̄(x_t), ρ_xai, explanation_hash, τ_H,t, C_t, mode, human_ack, fallback_flag)。
验证规则：
Valid(J_xsc) ⇔ Valid(J_rose)
∧ (h̄(x_t) ≥ 0 ∨ fallback_flag)
∧ explanation_valid(explanation_hash, ρ_xai, r_t)
∧ authority_trace_consistent(α_t, u_H, u_R, u*)
∧ human_ack_if_required(mode, C_t)。
其中 explanation_valid ⇔ (r_t ≤ ρ_xai) ∨ (mode = uncertainty)；authority_trace_consistent ⇔ u* 是 RCBF-QP 在 (u_nom, φ̂_t, r_t) 下的解（可重放验证）。审计时可重建「机器人当时告诉了人什么、人看到了什么、权限如何变化、是否回退」。

**定义 196（XSC 闭环算子 XLO）** 见 IP-202 伪代码。语义流执行 [意图/能力估计 → XCE 反事实 → MSA 归因 → ECV 判定 → AXQ 选模式 → TCM 更新 → 权限头 OGD → ROSE 记账]；实时流执行 [ARA 原子读 → u_nom → RCBF-QP → 派发/日志 → J_xsc]。实时流无任何学习写操作，解释不进入控制回路。

### IP-194 SCA（共享权限仲裁）

```python
class SharedControlArbiter:
    """权限头：α 在线学习；只改名义动作，不参与安全保证。"""
    def __init__(self, d_psi=8, D_w=2.0, eta0=0.1, sigma_xi=0.02):
        self.w = np.zeros(d_psi)
        self.D_w, self.eta0, self.sigma_xi = D_w, eta0, sigma_xi
        self.t = 0

    def features(self, qH, qR, r, U_ep, novelty, tau, voi):
        return np.array([1.0, qH, qR, r, U_ep, novelty, tau, voi])

    def authority(self, psi, explore=True):
        base = sigmoid(self.w @ psi)
        if explore and self.t > 0:                     # 语义流侧探索，实时流不调用
            base += np.random.normal(0, self.sigma_xi / self.t**0.25)
        return float(np.clip(base, 0.0, 1.0))

    def update(self, psi, loss, grad_loss):
        eta = self.D_w / (self.eta0 * np.sqrt(self.t + 1))
        self.w -= eta * grad_loss
        n = np.linalg.norm(self.w)
        if n > self.D_w: self.w *= self.D_w / n        # 投影回凸紧集
        self.t += 1
```

### IP-195 RCBF（鲁棒 CBF 过滤，实时流）

```python
def rcbpf_qp(u_nom, x, phi_hat, r, f, g, h, grad_h, L_hphi, gamma=1.0,
             u_min=-U_MAX, u_max=U_MAX):
    """单标量 CBF 约束 + 盒约束：闭式投影，O(m)，无学习写。"""
    h_bar = h(x, phi_hat) - L_hphi * r                # 鲁棒收紧（r 驱动）
    dh = grad_h(x, phi_hat)                           # ∂h/∂x
    drift = float(dh @ f(x))
    ctrl = dh @ g(x)                                  # 1×m
    # 约束：ctrl·u ≥ -(drift + gamma*h_bar) =: b
    b = -(drift + gamma * h_bar)
    u = np.clip(u_nom, u_min, u_max)
    lhs = float(ctrl @ u)
    if lhs >= b:
        return u, True, h_bar                         # 名义点已安全
    denom = float(ctrl @ ctrl)
    if denom < 1e-9:
        return np.clip(u_nom, u_min, u_max), False, h_bar   # 无法影响 h，回退
    u_proj = u + ((b - lhs) / denom) * ctrl           # 投影到半空间
    u_proj = np.clip(u_proj, u_min, u_max)
    feasible = float(ctrl @ u_proj) >= b - 1e-9
    return u_proj, feasible, h_bar
```

### IP-196 XCE（反事实解释）

```python
def generate_counterfactual(x, decision_fn, editable_idx, rho_max=0.5,
                            eps_tol=1e-3):
    """最小反事实：沿连续松弛梯度方向二分最小步长。"""
    x0 = x.copy()
    d0 = decision_fn(x0)
    def score(z):                                     # 连续决策分数（可微/可差分）
        return decision_fn.score(z)
    grad = numerical_grad(score, x0, idx=editable_idx)  # 仅可编辑维度
    if np.linalg.norm(grad) < 1e-9:
        return None, rho_max, "no_local_counterfactual"
    direction = grad / np.linalg.norm(grad)
    def flips(eps):
        z = x0.copy(); z[editable_idx] -= eps * direction[editable_idx]
        return decision_fn(z) != d0
    lo, hi = 0.0, rho_max
    if not flips(hi):
        return None, rho_max, "decision_robust_within_rho"
    for _ in range(int(np.log2(hi / eps_tol))):
        mid = 0.5 * (lo + hi)
        if flips(mid): hi = mid
        else: lo = mid
    delta = -hi * direction
    delta[~editable_idx] = 0.0
    return delta, hi, "counterfactual_found"          # m(x)=hi
```

### IP-197 MSA（模块级精确 Shapley）

```python
MODULES = ('USR', 'MEL', 'OLP', 'WCV', 'SCA')

def module_shapley(x, loss_fn, baseline_ctx, modules=MODULES):
    """|M|=5 → 32 次联盟评估；返回 Shapley 值与交互误差。"""
    from itertools import combinations
    from math import factorial
    n = len(modules)
    value = {}
    for mask in range(1 << n):
        active = {modules[i] for i in range(n) if mask >> i & 1}
        xS = run_pipeline(x, active=active, baseline=baseline_ctx)
        value[mask] = -loss_fn(xS)
    phi = {m: 0.0 for m in modules}
    for i, m in enumerate(modules):
        others = [k for k in range(n) if k != i]
        for s in range(len(others) + 1):
            for combo in combinations(others, s):
                mask = sum(1 << k for k in combo)
                w = factorial(s) * factorial(n - s - 1) / factorial(n)
                phi[m] += w * (value[mask | (1 << i)] - value[mask])
    # 交互误差：加性解释对每个联盟的偏差上界
    eps_int = 0.0
    for mask in range(1 << n):
        add = value[0] + sum(phi[modules[i]] for i in range(n) if mask >> i & 1)
        eps_int = max(eps_int, abs(value[mask] - add))
    return phi, eps_int
```

### IP-198 ECV（可信半径与断言规则）

```python
def explanation_validity(x, decision_fn, s, k, L_pi, L_s, r, rho_max=0.5):
    m = decision_margin(decision_fn, x, rho_max)        # 定义 190
    topk = np.argsort(s)[-k:]
    s_sorted = np.sort(s)[::-1]
    delta_s = s_sorted[k - 1] - s_sorted[k] if len(s) > k else np.inf
    rho_attr = delta_s / (2 * L_s) if L_s > 0 else np.inf
    rho_xai = min(rho_attr, m / L_pi, rho_max)
    mode_allowed = (r <= rho_xai)
    return rho_xai, mode_allowed, topk

def assert_explanation(E, r):

                           delta=None, rho_xai=E.rho_xai,
                           message='物理不确定球超出解释可信半径，请人工确认')
```

### IP-199 TCM（信任校准）

```python
class TrustCalibrationMonitor:
    def __init__(self, d_b=6, eta0=1.0, kappa=0.7):
        self.theta = np.zeros(d_b); self.tau = 0.5
        self.rho_R = 0.5; self.eta0, self.kappa = eta0, kappa
        self.t = 0

    def estimate(self, b):
        return float(sigmoid(self.theta @ b))

    def update(self, b, outcome_success, explanation_evidence):
        self.t += 1
        self.tau = self.estimate(b)
        self.rho_R = 0.9 * self.rho_R + 0.1 * float(outcome_success)
        eta = self.eta0 / self.t ** self.kappa         # Robbins-Monro
        chi = float(explanation_evidence)              # 解释揭示的可靠性证据
        self.tau += eta * (chi - self.tau)             # 信任动力学
        self.theta += 0.01 * (self.tau - self.estimate(b)) * b  # 行为头慢更新
        return self.tau, self.rho_R, abs(self.tau - self.rho_R)
```

### IP-200 AXQ（主动解释，VOI + EXP3）

```python
class ActiveExplanationQuery:
    MODES = ('none', 'uncertainty', 'counterfactual', 'attribution', 'full')
    def __init__(self, eta=0.3):
        self.w = np.ones(len(self.MODES)) / len(self.MODES)
        self.eta = eta

    def select(self, r, rho_xai, user_requested=False):
        if r > rho_xai:                                # 硬规则优先于老虎机
            return 'uncertainty', None
        if user_requested:
            return 'full', None
        i = np.random.choice(len(self.MODES), p=self.w)
        return self.MODES[i], i

    def update(self, arm_idx, vois):
        if arm_idx is None: return
        r_hat = vois[arm_idx] / max(self.w[arm_idx], 1e-6) / len(self.MODES)
        self.w[arm_idx] *= np.exp(self.eta * r_hat / len(self.MODES))
        self.w /= self.w.sum()
```

```python
def XSC_round(M, obs, u_H):

        M.ocb.choose().mode, V, T, P, L, M.anchor.x if M.anchor else None)

def realtime_step_xsc(M, u_H, alpha):
    anchor, fresh = M.ara.read_latest()
    phi_hat = anchor.phi_hat if anchor else PHI_SAFE
    r = M.rsc.r
    u_R = M.policy(anchor.x if anchor else M.last_x)
    u_nom = alpha * u_H + (1 - alpha) * u_R
    u_star, feasible, h_bar = rcbpf_qp(
        u_nom, anchor.x if anchor else M.last_x, phi_hat, r,
        f=M.f, g=M.g, h=M.h, grad_h=M.grad_h, L_hphi=L_HPHI)
    M.h_bar, M.fallback = h_bar, (not feasible)
    if not feasible:                                   # 安全回退：最大制动/停
        u_star = M.safe_stop(anchor.x if anchor else M.last_x, phi_hat, r)
    cert_exec = M.ertc.dispatch(u_star)                # 零学习写
    EV_exec = wait_contact_and_build_evidence()
    M.usr.push_evidence(EV_exec)
    return u_star, EV_exec, cert_exec
```

## 4. 推导

**引理 1（权限无关安全性）** 设 h̄ 连续可微、𝒰 非空紧凸，RCBF-QP 在 x_0 处可行且 h̄(x_0)≥0。则对任意 α∈[0,1] 与任意 u_H（只要 u_nom∈𝒰 或投影后可行），闭环满足 h̄(x(t))≥0 ∀t≥0。
证明：QP 的约束即 ḣ̄(x,u)+γh̄(x)≥0。由 Nagumo/前向不变性定理，满足该约束的 Lipschitz 控制场使超水平集 {x:h̄(x)≥0} 前向不变；γ>0 保证严格裕度。α、u_H 只通过目标函数 u_nom 影响解，不影响约束的可行性与不变性。∎
**含义**：权限分配从「安全约束」中解放出来，可以按能力/信任/解释价值自由优化；这是与第 62 轮 Shield（只过滤离散约束）最本质的区别。

**引理 2（物理偏差免疫）** 若 RSC 使 P[φ*∈B(φ̂_t,r_t)]≥1−α_cal，且 h 对 φ 为 L_hφ-Lipschitz，则 h̄(x)=h(x;φ̂_t)−L_hφr_t ≤ h(x;φ*) 对球内所有 φ 成立。于是 RCBF-QP 的可行性 ⇒ h(x(t);φ*)≥0，真实安全概率 ≥1−α_cal。
证明：对任意 φ∈B，h(x;φ) ≥ h(x;φ̂) − L_hφ‖φ−φ̂‖ ≥ h(x;φ̂) − L_hφ r_t = h̄(x)。故 h̄≥0 ⇒ h(·;φ*)≥0。覆盖事件概率由第 62 轮引理 2 给出，联合界得结论。∎

**引理 3（权限最优性间隙）** 设 ℓ_t^sc 对 w 凸、G_w-Lipschitz、w∈𝒲 直径 D_w。OGD 取 η_t=D_w/(G_w√t) 得静态遗憾 Σℓ_t^sc(w_t) − min_w Σℓ_t^sc(w) ≤ D_wG_w√T。若能力估计误差 |q̂−q|≤ε_q，且 α=σ(wᵀψ) 对 q 的 Lipschitz 常数为 L_α，则单步权限次优 |J(α_t)−J(α_t^*)| ≤ L_α ε_q。
证明：前半为标准 OCO 分析（与第 62 轮定理 1 同构）。后半由 σ 的 1-Lipschitz 与线性组合得 |α_t−α_t^*| ≤ L_α ε_q，再由 J 对 α 的 Lipschitz 性得单步间隙。∎
**注意**：这是「静态比较器」保证；人类策略非平稳时退化为动态遗憾，由 ξ_t 探索 + 重估计补偿（已声明缝隙）。

**引理 4（解释可信性）** 设 s 为 L_s-Lipschitz、π 为 L_π-Lipschitz，定义 ρ_xai=min(ρ_attr,m/L_π,ρ_max)。
(i) 若 ‖x'−x‖≤ρ_attr，则 s 的 top-k 集合不变；
(ii) 若 ‖x'−x‖≤m/L_π，则 π(x')=π(x)；
(iii) 若 r_t≤ρ_xai，则对球 B(φ̂,r_t) 内任意 φ，归因排序与反事实方向均不被物理不确定性翻转；
(iv) 若 r_t>ρ_xai，存在 φ∈B 使 π 或 top-k 改变，确定性解释可能错误，必须降级为 uncertainty。
证明：(i)(ii) 由 Lipschitz 定义直接得；(iii) 由 r_t≤ρ_xai≤ρ_attr 且 ≤m/L_π，联合 (i)(ii) 与球覆盖得；(iv) 是 (iii) 的逆否：半径超出保证界时无法排除翻转。∎

**命题 1（信任校准收敛）** 设 χ_t 为解释/结果揭示的可靠性证据，E[χ_t|ℱ_t]=ρ_R,t+b_t，|b_t|≤b，步长满足 Ση_t=∞、Ση_t²<∞（如 η_t=η_0 t^{−κ}, κ∈(0.5,1]）。则 τ_t→ρ_R（在 b=0 时几乎必然；b>0 时极限落在 ρ_R±b 带内）。
证明：τ_{t+1}=τ_t+η_t(χ_t−τ_t) 是 Robbins-Monro 随机逼近；噪声可积、步长条件满足，标准定理给出收敛；偏置 b_t 进入极限的 O(b) 邻域。∎
**含义**：解释的作用是提供「可靠性证据」，而非「说服」；只要证据真实且持续，信任会收敛到真实可靠性。

**命题 2（解释预算遗憾）** AXQ 在 K=5 个解释模式上用 EXP3 更新，伪遗憾 ≤ √(2KT log K)；硬性 uncertainty 规则与用户显式请求是「不参与学习的安全/可用性下界」，不破坏该界。
证明：EXP3 标准界；硬规则只裁剪臂集合（等价于在子集上运行 EXP3），不影响遗憾阶。∎

**定理（XSC-Complete）** 假设第 62 轮 A61–A76 及：
- **(A77)** 安全集 𝒮(φ) 非空，h 对 x、φ 分别连续可微且 L_hφ-Lipschitz；RCBF-QP 在安全集内可行（或存在安全回退）。
- **(A78)** 人类输入 u_H 有界且经 RCBF 过滤；α∈[0,1] 由语义流写入，实时流原子读。
- **(A79)** 决策映射 π 与归因分数 s 分别 L_π、L_s-Lipschitz；可编辑子空间 Δ_exp 不含安全约束本身。
- **(A80)** 信任证据 χ_t 有界、偏差 ≤b；解释生成延迟不进入实时路径。
则：
1. **权限无关安全**：∀α、∀u_H，若 RCBF-QP 可行，则真实状态满足 h(x;φ*)≥0（概率 ≥1−α_cal，承接 RSC 覆盖）。共享控制不会因人的操作而破坏安全。
2. **权限在线最优**：权限头静态遗憾 ≤ D_wG_w√T；能力估计误差只造成 O(L_αε_q) 的次优。
3. **解释可信**：r_t≤ρ_xai 时归因排序与反事实方向在物理不确定球内稳定；r_t>ρ_xai 时系统禁止确定性断言，只输出 uncertainty——**解释系统自身可证伪、会说「不知道」**。
4. **信任校准**：在真实、持续的解释证据下 τ_H→ρ_R（偏置 ≤b），过度信任与信任不足均被压缩。
5. **认知预算**：AXQ 伪遗憾 O(√(KT log K))，且安全硬规则不被学习突破。
6. **实时性不变**：实时路径零学习写操作，RCBF-QP 为 O(m) 闭式投影，≤1ms 契约与第 62 轮一致；解释生成全部在语义流。

## 7. 已知风险

**一句话**：若「模型内忠实」被误当作「世界真值」——MEL 的 φ̂ 已系统性偏差（第 62 轮 A72 失效）时，XCE 仍会为错误决策生成自洽、反事实可执行、Shapley 可解释的「完美故事」，TCM 又用这些故事把人校准到**过度信任**；RCBF 与解释共用同一个 φ̂，解释层无法独立发现「模型本身错了」——这是本轮「可解释性提升共享控制安全」论证的单点假设。

**次级风险与缓解**：
1. **CBF 不可行/模型失配**：激进人类输入或强扰动使 QP 不可行 → 安全回退（最大制动/停）+ fallback_flag 写入 J_xsc；监控回退率，超阈值时扩大 r_t 或降级自主权限。
2. **解释诱发认知过载**：full 模式信息量过大 → AXQ 的 VOI 门控 + 用户显式请求优先；解释分块与渐进披露。
3. **Shapley 组合爆炸**：|M|=5 可精确；未来模块增多 → 分层 Shapley（组间/组内）或采样近似，并报告置信区间。
4. **信任估计被行为噪声污染**：接管率/时延受任务难度混杂 → 用情景归一化与工具变量；信任只作为软信号，不直接决定安全。
5. **人类策略非平稳**：静态遗憾界失效 → ξ_t 探索 + 能力模型滑动窗口 + 动态遗憾监控，必要时退回固定保守权限。
6. **解释与审计的「事后合理化」**：explanation_hash 绑定证据，反事实可重放；但若证据本身错，审计只能证明「当时解释与证据一致」，不能证明「证据与世界一致」——需外部校准源（标定件、触觉探针）定期注入，作为 A72 的独立校验。
7. **责任与伦理**：共享控制的权限分配必须可追溯、可解释、可人工覆盖；J_xsc 记录 human_ack 与 fallback，但最终责任边界需在系统外定义。
