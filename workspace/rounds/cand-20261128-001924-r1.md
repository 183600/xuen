## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（比赛策略 → 这不是「把每个任务做好」，而是「在 12.8% 的荒年怎么分粮」）**

直觉：榜单按「平均成功率 + 平均步骤分」综合排序（F20），而真机最强也只有约 12.8% 成功率（F21）。这两件事合起来改变了一切：**成功率是稀疏伯努利，步骤分才是连续、可优化的主战场**；而且「平均」意味着方差受罚，任何一次崩盘都会稀释均分。于是比赛不是「逐个任务刷分」，而是一个带预算约束的**投资组合问题**：每个创新点（I1–I11）在 32 个任务上产生不同的边际期望增益，算力/真机预算是有限的，应该把钱投给「每单位算力边际榜分最高」的格子，并主动降方差。更妙的是，官方提供「不计分单任务调试」通道（F22），等于给你一台**免费探针**：先用它测弱项，再决定计分提交的资源配置。

严谨定义：设任务 $t\in[1,32]$、评测次 $n\in[1,N_t]$，成功 $s_{tn}\in\{0,1\}$、步骤分 $p_{tn}\in[0,100]$。榜分
$$U(x)=w_S\cdot\frac1{32}\sum_t \bar s_t(x)+w_P\cdot\frac1{32}\sum_t \bar p_t(x),\quad w_S+w_P=1,$$
其中 $\bar s_t,\bar p_t$ 为任务内均值，$x\in\{0,1\}^M$ 为创新点启用组合，成本 $c(x)\le B$。比赛策略即求解
$$\max_x\ \min_{w\in\Delta}\ \mathbb E[U(x)]-\lambda\,\mathrm{Var}(U(x))\quad \text{s.t. } c(x)\le B,$$
即在权重不确定（榜单未公布合成公式，P11）下做**鲁棒 max-min + 方差惩罚**的组合优化。边际排序律：$m_j=\partial\mathbb E[U]/\partial x_j \,/\, c_j$，按 $m_j$ 贪心分配，直到预算耗尽。

**灵感 2（MuJoCo → 你缺的不是更聪明的模型，而是一台能在 GPU 上同时开一万局的廉价物理考官）**

直觉：真机通道稀缺，离线图像增广又不懂摩擦与接触。MuJoCo Menagerie 恰好有 G1 全系模型，且 MJX 能在单卡并行上万环境（F23/F24）——这给了我们一个**物理接地、可无限重放、可成批扰动**的考官。但它的正确用法不是「训一个策略再 sim2real 迁移」（接触密集的 Dex1-1 操作 gap 很大），而是两件更稳的事：(a) 给干预**排序**——绝对保真度不重要，序关系才重要；(b) 生成**物理合法的「偏离→修正」恢复数据**，修掉 I5 扰动重放可能物理不可行的硬伤。最大陷阱已核实：Menagerie 的带手模型是 Dex3-1 三指手，而赛题用 Dex1-1 二指夹爪（F25），孪生必须自建夹爪并做系统辨识。

严谨定义：数字孪生 $\mathcal T=(M,S,\theta)$，$M$ 为 G1+Dex1-1 MJCF，$S$ 为 32 任务场景，$\theta$ 为接触/PD/时延参数。对一组干预 $\{i\}$，真机增益 $g_i$（单任务调试通道测得）与孪生增益 $\hat g_i$。$\mathcal T$ 可作**排序 oracle** 当且仅当留出干预上的 Spearman $\rho(\hat g,g)\ge 0.6$；未达阈值则降级为**纯数据引擎**（只产恢复数据，不参与预算决策），绝不拿不可信孪生去分配真机预算。

**碰撞与统一**：比赛策略是**决策层**（把有限预算分配给边际步骤分最高的任务×干预格子），MuJoCo 是**评估层**（提供廉价、物理接地的排序 oracle 与数据源）。合起来，本轮把比赛从「造模块」升维成「用信息优势打资源战」：**在 12.8% 的荒年，赢家不是模型最强的人，而是最快知道自己哪块地能打粮、并把种子全撒到那里的人。** 三个反直觉点：(1) 成功率是彩票，步骤分是工资——荒年先领工资；(2) 孪生用来排序，不用来迁移；(3) 榜单一开就提交，一次真实反馈的信息价值高于十次离线调参（先手窗口 F19）。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 v3 考纲校准五轴增广引擎 ★★★★★
- **动机**：计分的 320 次真机评测每次都在 5 轴上偏离训练分布（P2/F2），泛化缺口是全局乘性损失。
- **v3 增量**：增广分布继续按官方考纲卡校准（v2）；「位置重拼接」的物理可行性不再靠启发式，改由 I11 孪生在物理引擎中试跑，统计不可行动作占比，>5% 即降级为仅平移不变增广。
- **与现有方案差异**：盲目随机化 → 按考纲出模拟题；物理不可行增广 → 孪生体检后再入训（PR5/PR6）。
- **技术可行性/资源**：高；分割/inpainting 1×24GB GPU（F11），磁盘同 v1.1。
- **落地**：①32 张考纲卡；②背景/干扰物按考纲放量；③外观/位置 L0 先行；④I11 物理体检；⑤剂量-响应定档。
- **风险**：考纲卡偏差（单任务通道抽测）；孪生体检本身有 gap（与 I11 共用保真门禁）。

### I2 v2 数据引擎 2.0：110 语料孪生迁移 + 加权共训 ★★★★★（维持）
- **动机**：单模型平均分被最弱任务支配（P1）；示教语料与质量双重浪费（P8）。
- **核心**：孪生语料入训（110 语料按技能孪生表）；patch 官方 ConcatDataset 采样器实现族级权重（32 全量 / 孪生半权 / 远任务 ≤5%）；per-episode 质量加权并剪最差 10%。
- **差异/可行性**：均匀混训 → 诊断先行、孪生定向、权重受控；LoRA/frozen-VLM 单卡起步（F11）。
- **资源**：孪生子集 ≈1–2TB + 32 任务 ≈2TB；1×24GB 起步、8×A100 上限。
- **落地**：孪生表 → 下载子集 → loader patch + 频率单测 → 首轮共训 → 族级 L0 验证后放量。
- **风险**：负迁移（ZipUp↔Unzip 受力相反）；缓解：低权起步、退步即裁该孪生对。

### I3 接触任务族关键点视觉伺服回退 ★★★★（维持）
- **动机/差异**：通用 chunk 管接近段、几何伺服管接触段，同一 PolicyService 内混合推理（PR2 边界待确认）；降级预案 I3'：伺服关键点仅作训练辅助监督，推理纯端到端。
- **可行性/资源**：中；开放词汇检测零训练起步；关键点模块 1 人周。
- **落地/风险**：触发滞回 + 低置信回退；最大前提是组委会对「单模型内混合推理」的书面认可。

### I4 人手干预感知门控 + 自适应 chunk ★★★★（维持）
- **动机/差异**：人为干扰轴（P3）要求策略识别人手在场并停持让位；手部检测 + `obs_delta_indices` 历史栈判别（<50ms）。
- **可行性/资源**：高、低成本；状态机 INTERFERED→停持→重估→续做。
- **落地/风险**：干预态 chunk 4–6、稳定态 8–16（参照 15Hz，F12），待真机标定。

### I5 v3 非标称示教合成 + 得分点对齐恢复 ★★★★
- **动机**：步骤分为官方得分点制（F17）；数据集全成功、无失败示教（P8）。
- **v3 增量**：在 v2（扰动重放 / 跨段缝合 / WMA 生成 / 得分点过滤）之上，新增 **MuJoCo 物理恢复合成**——在 I11 孪生里对成功轨迹中段注入扰动，让物理引擎生成真实接触/摩擦下的「偏离→修正」延续段；只有达成下一得分点的段才保留。相较纯重放，轨迹物理可行、接触一致。
- **与现有方案差异**：手工恢复原语会引入新动作分布；本点恢复行为来自（物理合法的）数据分布内。
- **可行性/资源**：中-高；1×24GB GPU + MJX 并行 rollout；数据工程 2 人周。
- **落地**：得分点逆向 → 3 个弱任务试点（PlugCharger/ZipUp/PourOutMedicine）→ 进度头改得分点监督 → LoRA 增量训练 → 单任务调试 A/B。
- **风险**：孪生恢复与真实偏离分布失配；缓解：扰动幅度取自考纲卡，且 I11 未过排序门禁时仅用重放/缝合分支。

### I8 v3 评测运营闭环 + 分级消融注册表 ★★★★★
- **动机**：真机通道稀缺 + 待验证组合爆炸（P7）；现在还要为 I10 提供可信的离线增益估计。
- **v3 分级**：
  - **L0 图像空间消融**（免费）：考纲轴偏移，代理指标 Δprog/Δact/Δkp；
  - **L0.5 MuJoCo 物理消融**（廉价）：在 I11 孪生中重放同一批干预，输出物理增益 $\hat g$，并用留出干预检验与真机的 Spearman；
  - **L1 分数因子设计**（低真机）：$2^{k-p}$ 部分析因，主效应优先；
  - **L2 真机确认**（稀缺）：只测 top 2–3 候选，优先用「不计分单任务调试」通道（F22）做 A/B。
- **注册表**：记录每次「离线预测增益 vs 真机实测增益」，并按指标分层滚动 Spearman；新增 `sim_rank_corr` 字段，$\rho\ge0.6$ 的孪生才可进入 I10 决策。
- **可行性/资源**：高；代理指标 1 人周 + 注册表表格/脚本。
- **风险**：相关建立慢；先用 3–4 个已知真机点回填，且 I10 在相关未建立前只做保守贪心。

### I9 reset 期检索类比迁移 ★★★★（维持）
- **动机/差异**：未见物品轴（同类不同外观）全面出现；`reset()` 每 episode 恰一次（F18）做一次检索，把首帧物体嵌入映射到「物体-技能库」，结果作 episode 全程软先验；零权重更新。
- **可行性/资源**：中-高；嵌入 1×GPU 日 + FAISS；1 人周。
- **落地/风险**：物体库 → 索引 → 先验参数化 → 软注入 → 未见轴 L0 + 真机抽测；误检索用距离阈值门控，超阈退回无先验；合规性需书面确认。

### I10 比赛策略组合优化器 ★★★★★（新）

- **动机**：榜分 = 平均成功率 + 平均步骤分（F20），而最强真机成功率仅 ~12.8%（F21）。**均值制惩罚方差，稀疏成功率使步骤分成为唯一有统计意义的连续战场**。有限算力/真机预算下，「均匀提升」和「死磕成功率」都不是最优；必须按每单位算力的边际榜分做组合分配，并主动降方差。
- **与现有方案差异**：其他队伍按「平均能力/成功率」直觉分配资源；本点显式建模榜分效用、预算约束与不确定性，用鲁棒 max-min 防榜分权重未知（P11），用信息价值决定下一次真机调试测哪个格子。
- **形式化**：$U(x)=w_S\frac1{32}\sum_t\bar s_t(x)+w_P\frac1{32}\sum_t\bar p_t(x)$，$w_S+w_P=1$；求解
  $$\max_x\ \min_{w\in\Delta}\mathbb E[U(x)]-\lambda\mathrm{Var}(U(x))\quad\text{s.t. }c(x)\le B.$$
  边际排序 $m_j=\frac{\partial\mathbb E[U]}{\partial x_j}/c_j$；先验 $w_P>w_S$（荒年步骤分主导），随榜分公布用真实数据更新。序贯调度用知识梯度：下一次调试选「能最大降低最高 $m_j$ 格子不确定性」的任务。
- **技术可行性**：高。纯分析与决策层，无新模型；输入来自 I8 注册表 + I11 孪生 + 单任务调试结果。
- **所需资源**：1 名分析/工程 1 人周；无额外 GPU。
- **落地步骤**：①建「任务×干预」分数账本（当前均值/方差/样本数）；②实现鲁棒组合优化（贪心 + 局部搜索）；③实现知识梯度调度器；④用 3–4 个已知真机点校准 $w_P/w_S,\lambda$；⑤每次计分提交后重规划（仅用自身结果，合规）。
- **风险**：榜分权重未知导致优化错目标；缓解：鲁棒 max-min + 以步骤分为主（其对权重不敏感）；榜单「即将发布」期间用 F21 外部基准作先验，不做激进押注。

### I11 MuJoCo 数字孪生评估场 + 物理恢复数据 ★★★★（新）

- **动机**：真机预算稀缺；I8 的 L0 只是图像空间，不懂摩擦/接触；I5 的重放扰动可能物理不可行。MuJoCo Menagerie 有 G1 全系模型，MJX 可在单卡并行上万环境（F23/F24），可做廉价、物理接地的考官。
- **与现有方案差异**：官方仿真是 Isaac Lab（F14，重、与 32 任务不对齐）；本点用轻量 MuJoCo 做**相对排序 oracle + 物理数据引擎**，明确不承担策略 sim2real 迁移。关键工程点：Menagerie 的带手模型是 Dex3-1 三指手，赛题用 Dex1-1 二指夹爪（F25），必须自建夹爪（1 个 prismatic 自由度、90mm 行程、力限 120N）。
- **形式化可信门禁**：对留出干预集，真机增益 $g_i$（单任务调试）与孪生增益 $\hat g_i$ 的 Spearman $\rho(\hat g,g)\ge0.6$ 才可作排序 oracle；否则该任务族降级为纯数据引擎，不参与 I10 预算决策。
- **技术可行性**：中。基座 `g1_mjx.xml` 现成；自建 Dex1-1 夹爪与 32 任务场景需工程；系统辨识（接触参数/PD/时延）用真机日志拟合。
- **所需资源**：1×A100（MJX 并行）+ 1 名仿真工程 3–4 周；场景物体网格取自 HF 数据集/公开资产（注意许可）。
- **落地步骤**：①G1+Dex1-1 MJCF 最小可用；②3 个接触任务场景（插网线/插充电器/拉拉链）先跑通；③系统辨识；④在 5–8 个已知干预上测 $\rho$；⑤过门禁的族接入 L0.5 与 I5；⑥扩到 32 任务。
- **风险**：Dex1-1 自建夹爪与真机接触参数失配；MuJoCo 在网格接触/插入任务上 gap 大（F24 的 sharp bits）；缓解：先做「排序」而非「绝对值」，分族设门禁，不达标即降级为数据引擎。

### 1.1 比赛策略组合优化 + 信息价值调度（I10）

```python
# 分数账本：ledger[(task, intervention)] = (mean_U, var, n, cost)
def robust_utility(ledger, x, weight_simplex, lam):
    # 对权重单纯形采样，取最坏情形；减去方差惩罚
    return min(wS * avg_success(x) + (1 - wS) * avg_step(x)
               for wS in weight_simplex) - lam * total_var(x)

def allocate(ledger, budget, weight_simplex, lam):
    x = set()
    while True:
        # 边际步骤分每算力（PR6）
        cand = max(
            ((j, dU(ledger, x | {j}) / ledger.cost[j])
             for j in feasible_additions(ledger, x, budget)),
            key=lambda kv: kv[1], default=None)
        if cand is None or cand[1] <= 0:
            break
        x.add(cand[0]); budget -= ledger.cost[cand[0]]
    return x

def next_probe(ledger, x):
    # 知识梯度：选能最大降低“最高边际格子”不确定性的任务
    target = max(ledger.cells(x), key=lambda c: ledger.marginal(c))
    return argmax_task(lambda t: info_gain(ledger, target, t))

# 每次计分提交后调用；只用自身结果，绝不看评测分布
```

### 1.2 MuJoCo 批量物理消融与排序门禁（I11 + I8 L0.5）

```python
import jax, mujoco, mujoco.mjx as mjx

def build_twin():
    # 基座 g1_mjx.xml + 自建 Dex1-1 二指夹爪（prismatic, range 0..0.09m, force<=120N）
    return load_mjcf("g1_dex1_scene.xml")

def batched_rollout(m, params, inits, policy):
    # 单卡并行上千个扰动初态，MJX vmap 一次算完
    step = jax.vmap(lambda d: mjx.step(m, d))(inits)
    return jax.jit(step)

def l05_ablation(twin, interventions, heldout):
    sim_gain = {}
    for i in interventions:                      # 与 L0 同一批干预
        sim_gain[i] = evaluate(twin, i, heldout) # 物理增益（步骤分/成功率）
    return sim_gain

def ranking_gate(sim_gain, real_gain, heldout_interventions):
    rho = spearman([sim_gain[i] for i in heldout_interventions],
                   [real_gain[i] for i in heldout_interventions])
    return rho >= 0.6          # 否则该族仅作数据引擎，不进 I10 决策
```
