> R70 给交互装上了「世界信念」，问出了「我该信什么」：epistemic = 状态后验熵 H[b_t]，VoI = 贝叶斯实验设计，并交付了基线协议与原型验收。但 R70 的交互藏着一个从德尔斐神谕时代就没被质疑过的假设：**被问的人是静止的神谕**——观测模型三分解中 p_interact 时不变，问十次同一个问题得到同一个分布，人的信任、耐心、疲劳、注意力统统不在信念里。社会影响理论的第一句话就是：**每一次交互都在改变被交互的人**——提问不是读取，是写入，写在人的信任上。同时，R69–70 的信息动作（看/问/触）全是在「读」，缺了带宽最高、风险最低、且天然消除接地鸿沟的动作：**把方案演给人看**（演示方案）。而所有这些动作——探针、凑近、慢放重演、手把手引导——最终都要靠身体执行，轨迹前缀认证是运动学层面的，撑不住力、平衡与接触层面的安全。
>
> 本轮三个灵感正好是同一个问题的三面：
> - **社会影响** → 人必须成为信念的一部分：b_t(s,h)；交互预算不再是静态 c_max，而是「信任账户」——每次交互是取款，成功消歧是存款；
> - **演示方案** → 信念的最高带宽输出信道：与其问「是这个意思吗」，不如把 top-2 模态演出来让人批准/纠正；人的纠正是一段演示轨迹——它是似然，进信念，**永不进权重**；
> - **全身控制** → 信息动作终于有了身体：认证升级为两层（运动学前缀 + 全身动力学证书），演示重放靠时间同缩获得「构造性安全」。
>
> 核心命题：**把「交互=查询」升级为「交互=双人舞」**——人进信念（SOC）、演示进信道（DEM）、身体进认证（WBC-C）；CALM ⊂ FLUID ⊂ BELIEF ⊂ TANGO 四层严格包含，边界逐指令恒等。命名 **TANGO-RAS**（Trust-Aware Negotiation via Grounded whole-body Operations）。
>
> 一句话定位：R69 问「我该向谁求证」，R70 问「信念如何表示」，R71 问「**我每次开口，都改变了什么**」——不确定性消解的最高形式不是问对问题，是把方案演出来让人纠正。

## 0. 直觉与动机

**灵感 1（社会影响 → 被问的人不是静止的神谕，是一支会漂移的传感器）**
R70 的贝叶斯 VoI 假设观测模型 p(y|s,g) 时不变。但人是动态系统：反复提问 → 信任下降、烦躁上升 → 回答质量退化 → 观测模型失配 → 后验「自信地错」——这正是 R70 最大风险（观测模型失配 ⇒ H[b_t] 变小反而更危险）的**社会放大版**：失配不是外生的噪声，是系统自己的提问行为诱发的内生漂移。更隐蔽的是反向通道：机器人一次吓人的探针、一个错误的演示，会永久改变此后所有回答的分布。所以交互预算不该是静态 c_max，而应形式化为**社交资源动态治理**：信任是账户，每次交互是取款，成功消歧是存款；预算治理继承 R68 铁律——**对人的状态越不确定，预算只收紧**。

**灵感 2（演示方案 → 最高带宽的信息动作是把信念演出来）**
R69–70 的三问都在「读」，缺一个「写回校验」的动作。语言问句的根本缺陷是接地鸿沟：E294 只敢承诺 95% 理解率，剩下的 5% 就是「自信地问错」。演示方案 g_show 把后验的 top-2 模态渲染成慢速排练/轨迹投影，人面对的是**将要发生的事**，纠正的是具体方案而非抽象语言：approve 把后验质量指数级压到该模态（引理 24）；correct 直接是一段人手引导的演示轨迹——**它是似然，进信念，永不进权重**。这是证据纪律的自然延伸：信念更新可逆、有界、可审计（引理 25 给出 β_max/(1−λ_d) 的显式上界），权重更新不可逆且无界。一条式子守住 R68 以来的零学习写不变式，同时打开 R70 缺失的「从数据学」路径（少样本、非参数、检索式、可删除）。

**灵感 3（全身控制 → 信息动作终于有了身体）**
凑近看要动基座，探针要力控，演示重放要全身协调，手把手引导要零力柔顺——R69 用任务动作的轨迹前缀机制认证信息动作，运动学层面勉强够，动力学层面不够：力矩饱和、ZMP/CoM 平衡裕度、接触 wrench cone、自碰、ISO/TS 15066 人体接触限值。升级两层认证 WBC-C：L1 认证前缀（继承），L2 全身证书（torque-QP 可行性 + 裕度 + 运行时监测 + 认证缓沖 fallback）。关键引理 26：演示重放用**时间同缩**——准静态主导下所需力矩 τ(α)=α²τ_dyn+τ_static 随 α 单调下降，静态可行 ⇒ 必存在 α 使慢放全程可行。g_show 由此是「构造性安全」的：这直接回答「演错了怎么办」——演得足够慢，且随时可中止。

**灵感 4（三灵感合一 → 交互问题本质是社交 POMDP）**
三者不是并列而是同一 POMDP 的三面：人是**状态**（社会影响），演示是**最高带宽信道**（演示方案），身体是**受动力学约束的执行器**（全身控制）。信念升为 b_t(s,h)，VoI 升为影响感知（边缘化人的转移核），执行升为 WBC-C。R68/R69/R70 全部成为边界退化：h 冻结 → R70；去演示信道 → R70；WBC 退化为前缀 → R69；VoI≤成本或门控失败 → R68。延续 R69 定理 16、R70 定理 18 的理论姿态：**新层必须是旧层的严格泛化**——否则每加一层就多一个需要独立信任的黑箱。

**灵感 5（会「演」就有新攻击面 → 展示欺骗与信任操纵）**
(a) 展示欺骗：渲染层被操纵，人批准了一个与实际执行不符的方案——人被机器人骗，攻击方向与 R69 的「人骗机器人」相反；(b) 恶意演示：重复投喂可通过纠错库漂移行为（虽只进信念，但蓄意构造的演示序列可精确操纵检索上下文）→ β_max + 衰减 + 溯源哈希 + 检索质量门；(c) 信任操纵：用「你只剩一次提问机会」制造社交压力诱导批准 → 配给决策强制可解释、可审计（VQAuditor-III 反事实重放）；(d) 演示重放本身是动作：必须自由空间/接触认证 + 一触即停。

```python
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES) and (D_h > TAU_D)
    g = (M.mint.choose_tango(b, M.budget, M.wbc)
         if (U_epi > TAU_EPI and not slow and M.gates.all_pass(b)) else None)
    if g is not None:
        y = M.cia.execute(g, executor=M.wbc)        # 看/问/演/引导，WBC-C 认证执行
        b  = M.soc.step(b, o, M.last_action, g, y)  # 回答 + 人的转移同时更新
        if y.type == 'correct': M.clib.add(z, y.xi_demo, provenance='human')
        U_epi = entropy(b)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode_from_belief(b, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_iii.submit_async(g, y, b, a_hat, D_h, rationale=M.soc.last_rationale)
    M.b_prev = b
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 23（冻结退化与短视 VoI 的误差界）** h 冻结时 p(h'|h,g)=δ_h ⇒ VoI_inf ≡ VoI（R70 定义 317），子模性恢复，贪心 (1−1/e)（引理 20 直接引用）。h 动态时 VoI 不再子模——2-step lookahead 在候选集内精确最优；且在 A108（VoI 对 h 为 L_h-Lipschitz）下 |VoI_inf(g; b(s,h)) − VoI(g; b(s,ĥ))| ≤ L_h·TV(p(h'|h,g), δ_ĥ)：短视 VoI 的误差由转移核的集中度控制——**胖尾的社交动态才是真正的风险**。

**引理 24（批准的信念集中速率）** A106 下，approve_k 使后验质量向真实模态 m_{k*} 集中：H[b_after] ≤ H[b] − log(p_min/ε_appr) + log K̂；correct 以 O(1/σ_d²) 收缩连续参数后验方差。系：演示信道的「每单位社交成本的信息量」高于问句——一次可见的批准 ≈ 多次问答，因为批准同时提供了「所见即所执行」的第二证据源。

**引理 25（纠错库有界影响与可逆性）** 检索混合权重 w ≤ β_max、衰减 λ_d<1、单条目影响范数 ≤ C，则任意时刻库诱导的速度场散度 ≤ β_max·C/(1−λ_d)，与历史长度无关；删除全部条目后散度精确为 0（可逆）。对照：任何权重更新既无界又不可逆。此引理是「演示改信念、永不改权重」的形式化，也是零学习写不变式在 TANGO 下的完整表述。

**引理 26（时间同缩构造性可行性）** 准静态主导（A107：show 模式 ‖q̈‖ ≤ α²·q̈_max）下，所需力矩 τ(α) = α²τ_dyn + τ_static 随 α 单调下降，ZMP 裕度单调趋近静态裕度；故静态可行 ⇒ ∃α* ∈ [α_min,1] 使慢放全程可行；运行时监测违例即认证缓沖。g_show 由此「构造性安全」，直接回答「演错了怎么办」。

**定理 20（四层严格包含）** A102–A108 下，TANGO 两阶段-两信道策略期望风险 ≤ BELIEF ≤ FLUID ≤ R68；且当（h 冻结 ∧ g_show/g_follow 移除 ∧ WBC 退化为前缀）时逐指令恒等于 R70，当 VoI≤c 或任一门失败时恒等于 R68。安全侧层层不让步，效率侧获得 resolution bonus（消解）+ social bonus（信任存款 → 未来交互容量）。

**定理 21（社交可持续性）** η_annoy 每交互增量有界 Δη_max（A102）、SOC-G 只收紧、信任账户不可透支（定义 331-ii）下，长期交互频率收敛且 τ_trust ≥ τ_floor 以概率 ≥ 1−δ（亚鞅漂移论证）。系：社交可持续性是一个**可证明的性质**，不是 24h 实验的侥幸——E329 验证的正是定理前提（Δη_max 有界）在真实人群是否成立。

## 6. 本轮最大风险

**一句话**：TANGO-RAS 把全部增量收益押在「θ_soc——人的信任/烦躁动态——在真实人群上可校准」这一前提上，而这里有一个自证困境：**改变 h 的正是用 h 做决策的系统本身**——若信任模型系统性失配（个体/文化差异、慢变量不可辨识），影响感知 VoI 会「花掉不存在的信任」，过度提问 → 信任崩塌 → 观测信道劣化 → R70 的「自信地错」被社会反馈闭环放大；且演示重放把信念驱动的方案放进了物理世界——**错的「演」也是一次真实的运动**，「构造性安全」只保证慢放不摔，不保证演的内容不误导人。

**次级风险与缓解**：
1. 展示欺骗（渲染-执行不一致）→ 定义 347 三段哈希锚 + E328 拦截 100%；

## 4. 推导

**引理 23（冻结退化与短视 VoI 的误差界）** h 冻结时 p(h'|h,g)=δ_h ⇒ VoI_inf ≡ VoI（R70 定义 317），子模性恢复，贪心 (1−1/e)（引理 20 直接引用）。h 动态时 VoI 不再子模——2-step lookahead 在候选集内精确最优；且在 A108（VoI 对 h 为 L_h-Lipschitz）下 |VoI_inf(g; b(s,h)) − VoI(g; b(s,ĥ))| ≤ L_h·TV(p(h'|h,g), δ_ĥ)：短视 VoI 的误差由转移核的集中度控制——**胖尾的社交动态才是真正的风险**。系：影响感知 VoI 不是锦上添花，而是把「信任崩塌」这类重尾事件从无界误差变成有界误差项。

**引理 24（批准的信念集中速率）** A106 下，approve_k 使后验质量向真实模态 m_{k*} 集中：H[b_after] ≤ H[b] − log(p_min/ε_appr) + log K̂；correct 以 O(1/σ_d²) 收缩连续参数后验方差。系：演示信道的「每单位社交成本的信息量」高于问句——一次可见的批准 ≈ 多次问答，因为批准同时提供了「所见即所执行」的第二证据源。

**引理 25（纠错库有界影响与可逆性）** 检索混合权重 w ≤ β_max、衰减 λ_d<1、单条目影响范数 ≤ C（A105），则任意时刻库诱导的速度场散度 ≤ β_max·C/(1−λ_d)，与历史长度无关；删除全部条目后散度精确为 0（可逆）。对照：任何权重更新既无界又不可逆。此引理是「演示改信念、永不改权重」的形式化，也是零学习写不变式在 TANGO 下的完整表述。

**引理 26（时间同缩构造性可行性）** 准静态主导（A107：show 模式 ‖q̈‖ ≤ α²·q̈_max）下，所需力矩 τ(α) = α²τ_dyn + τ_static 随 α 单调下降，ZMP 裕度单调趋近静态裕度；故静态可行 ⇒ ∃α* ∈ [α_min,1] 使慢放全程可行；运行时监测违例即认证缓沖。g_show 由此「构造性安全」，直接回答「演错了怎么办」。

**定理 20（四层严格包含）** A102–A108 下，TANGO 两阶段-两信道策略期望风险 ≤ BELIEF ≤ FLUID ≤ R68；且当（h 冻结 ∧ g_show/g_follow 移除 ∧ WBC 退化为前缀）时逐指令恒等于 R70，当 VoI≤c 或任一门失败时恒等于 R68。安全侧层层不让步，效率侧获得 resolution bonus（消解）+ social bonus（信任存款 → 未来交互容量）。

**定理 21（社交可持续性）** η_annoy 每交互增量有界 Δη_max（A102）、SOC-G 只收紧、信任账户不可透支（定义 331-ii）下，长期交互频率收敛且 τ_trust ≥ τ_floor 以概率 ≥ 1−δ（亚鞅漂移论证）。系：社交可持续性是一个**可证明的性质**，不是 24h 实验的侥幸——E329 验证的正是定理前提（Δη_max 有界）在真实人群是否成立。

## 7. 本轮最大风险

**一句话**：TANGO-RAS 把全部增量收益押在「θ_soc——人的信任/烦躁动态——在真实人群上可校准」这一前提上，而这里有一个自证困境：**改变 h 的正是用 h 做决策的系统本身**——若信任模型系统性失配（个体/文化差异、慢变量不可辨识），影响感知 VoI 会「花掉不存在的信任」，过度提问 → 信任崩塌 → 观测信道劣化 → R70 的「自信地错」被社会反馈闭环放大；且演示重放把信念驱动的方案放进了物理世界——**错的「演」也是一次真实的运动**，「构造性安全」只保证慢放不摔，不保证演的内容不误导人。

**次级风险与缓解**：
1. 展示欺骗（渲染-执行不一致）→ 定义 347 三段哈希锚 + E328 拦截 100%；
2. 恶意演示库投毒 → β_max/λ_d/检索质量门 + 引理 25 有界性 + E326/E337；
3. 实时预算被社交/动力学层侵蚀（4.5→5.6ms）→ 证书检查与 QP 执行分线程（500Hz 独立）+ E334；
4. g_follow 人力越界/突然释放 → 导纳包络 + 一触即停（定义 346）+ E335；
5. 慢放演示冗长诱发烦躁 → 定义 348 时长预算 + α 联合优化。
