# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环第 3 轮；本轮灵感：「个性化交互」×「数据集」）

> R69 让系统学会了「问」：向人看一眼、探一下、说一句，用信息动作消解 epistemic 歧义。但它把「向谁问、这个回答值多少」当成**普适常数**——同一个「是」，从赶时间的老手、新手、恶作剧者、会调传感器的对手嘴里说出来，被赋予了相同的可靠度 δ_p、相同的成本 c(g)、相同的语义。R69 的 VoI 公式里没有「人」这个下标。可交互的价值从一开始就是**人的函数**：有人一句话点醒，有人越问越乱，有人你越问、他越知道该怎么骗你。
>
> 本轮两个灵感正好把这个缺口撕开：
> - **个性化交互**：把 R69 的 δ_p、I(M;y|g)、c(g)、甚至模态先验 w 全部变成用户 u 的函数 π_u，并承认它是**带不确定性的随机量**，不是可拟合的常量。
> - **数据集**：个性化需要数据，但能拿到的数据只有「系统自己过去问过的那些问题」——这是一份**被策略选择出来的、有混杂、有选择偏差、会随时间漂移**的数据集，而不是自然样本。数据集因此不是配料，而是本轮的核心困难与一等公民。
>
> 核心命题：**个性化的 VoI 只能建立在「数据支持得住」的地方；而这份数据是被旧策略选出来的，所以必须同时交付『可审计的个性化交互数据集（PID）』与『个性化门控（PG）』——没有数据支持、来源不可信、隐私预算不足时，逐级退回人群模型乃至 R69 的全局常数。** 命名 **PIVOT-RAS**（Personalized Interaction Value-Of-information with Trustworthy data：个性化交互价值 × 可信数据集）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这个人值得我问到什么程度，我又凭什么相信这份关于他的数据**」——个性化不是把模型调得更贴身，而是把「信任」变成一件需要证据、需要隐私预算、需要被人审计的事。

## 0. 直觉与动机

**灵感 1（个性化交互 → VoI 的每一个量都是人的函数）**
直觉：R69 的 MINT 在一个「平均用户」上算信息增益，于是对所有人都用同一套问法、同一个欺骗率、同一个打扰成本。现实中，专家的一个「别动」抵得上一百次试探，新手的一句「应该没事」几乎不含信息；有人被问会烦，有人不被问才不安；更麻烦的是，人的可靠度**随情境（stakes）变化**：平时诚实的人，可能只在关键节点撒谎一次。所以个性化不是「换一个说话风格」，而是把交互决策的**每个量都条件化到用户**：模态先验 w_u、通道可靠度 R_u、成本 C_u、以及策略性/漂移状态 d_u。R69 的全局模型成为 u→∞ 的退化边界。

**灵感 2（数据集 → 这份数据不是自然长出来的，是被策略选出来的）**
直觉：直觉上「个性化」=「多收集这个用户的数据，训一个用户模型」。但真正的问题是：系统只会去问它**当时认为值得问**的问题（R69 的 VoI 门控），于是日志里从来没有「系统没问的问题」的答案。用这种日志去训练用户模型、再用该模型去决定问什么，会形成**自我确认的闭环**：模型相信自己该问 A，数据里就全是 A 的答案，模型于是更相信自己该问 A。这不是数据量不足，而是**数据分布由被评估的策略自己决定（off-policy / bandit feedback）**。因此本轮必须把「数据集」当作有 provenance、有 propensity、有 support 的统计对象来处理，而不是一个静态 CSV。

**灵感 3（门控 → 个性化必须是有证据才允许的推断，不是默认开）**
直觉：个性化天然过拟合：三个样本就能编出一个「他喜欢简短回答」的画像，然后系统此后一直简短地问，永远收不到反驳。安全做法不是禁止个性化，而是给个性化装一个**数据支持门**：后验区间够窄、有效样本量够、候选动作落在历史 support 内、来源可信、隐私预算足够——五者同时满足才启用用户级 VoI；否则退到人群级；再否则退到 R69 全局常数。**新增层只能是旧层的严格泛化，退化时逐指令一致**，这条 R69 的方法论纪律必须继承。

**灵感 4（养号与画像投毒 → 个性化制造了 R69 没有的攻击面）**
直觉：一旦系统「相信这个用户」，就有了「先养信誉、再在关键处背叛」的策略：低风险阶段高度配合以抬高 δ̂_p(u)，等系统把高风险决策托付给他时反水一次。这与 R69 的「单次交互不得定案」正面冲突——因为个性化恰恰想给高可靠用户更大的话语权。结论：**个性化不得豁免证据纪律**，只能用可靠度**上置信界**加权，且 `stakes` 必须分层估计；单次高风险回答永远只是似然，不是判决。此外，PID 本身可被投毒（伪造日志、合成数据灌入、共谋标注），所以数据集需要来源标签与投毒检测。

**灵感 5（数据集是一等公民 → 可版本化、可审计、可投资）**
直觉：R69 的证书只证明「这一次决策怎么来的」。R70 还要证明「这个用户模型是从哪份数据、在什么授权范围内、以多大的隐私代价学出来的」。更进一步，系统可以在安全包络内**主动探索**去补数据集的盲区（在支持度外多问一句），于是「数据采集」本身成为决策的一部分：一次交互同时产生任务价值与数据价值（双 VoI）。这把数据集从被动日志升级为可以主动投资、也必须被审计的资产。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（PIVOT-RAS 总览）** PIVOT-RAS = (HUM, PID, OPEV, PG, PIG, DPA, PIVOT-WM†)，构建在 FLUID-RAS 之上。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i；用户模型更新一律异步/端侧）；
(ii) **个性化门控**：任何用户级参数只有在 PG（定义 315）同时满足数据支持、来源可信、隐私预算时才生效；
(iii) **三级嵌套退化**：USER → POPULATION → GLOBAL（R69），逐级回退，安全侧永不减弱。

**定义 311（用户交互画像）** 对用户 u，π_u = (w_u, R_u, C_u, d_u)：
- w_u ∈ Δ^{K−1}：该用户的模态先验（他更可能表达哪种意图）；
- R_u: 𝒜_info × ℰ → [0,1]：通道可靠度，含分情境欺骗先验 δ_p(u, ch, s)；
- C_u: 𝒜_info → ℝ_+：该用户的社交/物理打扰成本（有人厌问、有人需问）；
- d_u ∈ ℝ^{d_d}：漂移与策略性状态（含 stakes 分层、声誉半衰期）。
π_u 是随机量，只有后验 P(π_u | D_u)，没有「真值」。

**定义 312（个性化交互数据集 PID）** 一条记录 e = (u, t, o_t, g, y, a, z, p)：
- o_t 观测、g 信息动作、y 返回证据、a 任务动作与结果、z 模态身份标签（若可得）；
- 来源 p = (consent_scope, source ∈ {real, synthetic, self-play}, behavior_propensity e_μ(g|o,u), adversarial_tag, poison_flag, ts, dp_ε)。
清洗与划分必须 **user-disjoint**：D_train / D_val / D_test 的用户集合两两不相交，杜绝同一用户的记录跨集泄漏。

**定义 313（分层用户模型 HUM）** 部分池化（partial pooling）：
ψ ~ p(ψ)（人群超先验）；π_u ~ p(π_u | ψ)；给定 D_u 得后验 P(π_u | D_u, ψ)。可靠度用分层 Beta-Binomial，成本用分层 LogNormal，模态先验用分层 Dirichlet。HUM 的输出不是点估计，而是 **(均值, 可信区间, ESS, support)** 四元组。

**定义 314（离策略 VoI，OPEV）** 行为策略 μ 在每条记录里留下 propensity e_μ(g|o,u)。目标 VoI：VoI_u^π(g) = H(M|o,u) − E_{y~P(·|g,o,u)}[H(M|o,y,u)]。用自归一化重要性采样 / 双重稳健估计：
V̂oI_u^π(g) = Σ_i w_i·f_i，w_i = clip(e_π(g_i|o_i,u)/e_μ(g_i|o_i,u), w_min, w_max)，ESS = (Σw_i)²/Σw_i²。
只有落在 support S_μ = {g : e_μ(g|·,u) > τ_e} 内的估计才可信；support 外一律标记为**外推**（Extrapolated），不得驱动高风险交互。

**定义 315（个性化门控 PG）** 允许对用户 u 启用用户级 VoI 当且仅当五条同时成立：
(a) 后验可信区间宽度 W(π_u) ≤ τ_π；
(b) ESS_u ≥ N_min 且所有候选 g ∈ S_μ；
(c) provenance 可信：consent_scope 覆盖该用途、poison_flag 清零、synthetic 比例 ≤ ρ_max、user-disjoint 校验通过；
(d) 隐私预算 ε_u ≤ ε_max；
(e) 跨用户公平性检查通过（个性化不得使少数用户的可达安全集收缩）。
任一不满足 → 回退人群模型 ψ；人群模型仍不可用 → 回退 R69 全局常数。

**定义 316（隐私保护个性化 DPA）** 画像在端侧更新；只有满足 (ε,δ)-DP 的裁剪聚合统计/梯度上行；对每个用户做隐私预算会计（composition）。个性化收益必须在**扣除 DP 噪声后的后验**上重算——不允许拿未加噪的画像做决策、再用 DP 只洗上行通信。

**定义 317（画像完整性守卫 PIG / 养号检测）** 定义 stakes 分层可靠度 δ_p(u, s)，s ∈ {low, high}。养号统计量
κ_u = |δ̂_p(u, low) − δ̂_p(u, high)| / √(Var[δ̂_p(u, low)] + Var[δ̂_p(u, high)])。
再加声誉半衰期 r_u(t) 与跨源一致性检验。关键纪律：**检测不能替代证据纪律**——即使 κ_u 正常，单次高风险回答也永不单独定案（见定义 319）。

**定义 318（数据覆盖与安全探索）** 为避免「只记录系统已经会问的」，以概率 η 在 C-RAS-WM 认证的安全包络内采样次优信息动作 g′，扩展 PID 的 support。覆盖度 cov(D) = 候选 g 落在 support 内的比例。探索代价计入交互预算，物理/社交风险沿用 R69 定义 298/302 的认证。

**定义 319（个性化证据纪律）** 定案仍需 k 个正交证据源，各源按用户可靠度的**上置信界**加权：
错误采纳率 ≤ Σ_s β_{u,s}·δ_p^+(u,s)·ρ_s^{k−1} + ε_σ，
其中 δ_p^+ 取上置信界（不是均值），β_{u,s} 为源权重。理由：对手会在最关键时背叛，均值会系统性低估尾部。

**定义 320（双 VoI / 数据价值）** 一次交互同时有任务价值 VoI_task 与模型改进价值 VoI_data = E[熵下降(π_u 后验)]。安全时选
g* = argmax_g [VoI_task(g) + κ·VoI_data(g) − C_u(g)]，
κ 随数据稀缺度自适应。这把数据集从被动日志变成可主动投资的资产。

**定义 321（PIVOT 证书）** J_PIVOT = (J_FLUID, dataset_hash, consent_scope, user_disjoint_split, ESS, coverage, privacy_budget ε_u, PG_state, provenance_flags, trust_farming_stat κ_u, pivot_ver)。
Valid ⇔ Valid(J_FLUID) ∧ PG_state ∈ {USER, POPULATION} ∧ 证据纪律满足 ∧ 隐私预算未越界 ∧ provenance 校验通过。

**定义 322（三级嵌套包含）** 记策略族 Π_USER ⊂ Π_POP ⊂ Π_GLOBAL（R69）。在 A99–A101 正则性下：
(a) PG 关闭或无数据支持 ⇒ PIVOT 与 R69 逐指令相同；
(b) 用户后验退化到人群先验 ⇒ 与人群级模型逐指令相同；
(c) 任意状态下期望风险 ≤ R69。

## 2. 关键算法骨架

# IP-265 HUM：分层用户画像（端侧，部分池化，输出带区间）
class HierarchicalUserModel:
    def update(self, u, records, privacy):
        rec = clip_records(records, limit=privacy.clip)      # 防单条记录支配
        post = self.posterior(self.psi, rec)                 # Beta/Dirichlet/LogNormal
        return Profile(post.mean(), post.ci, post.ess,
                       post.support, post.eps_used)

    def population_prior(self, D):
        return self.psi_posterior(D)                         # 人群级回退

# IP-266 OPEV：只在 support 内相信 VoI
def ope_voi(profile, g, o, D_u, tau_e):
    if profile.support(g) < tau_e:            return Extrapolated(g)
    w  = propensity_ratio(g, D_u)             # clip 到 [w_min, w_max]
    ess = (w.sum()**2) / (w**2).sum()
    if ess < N_MIN:                           return Extrapolated(g)
    return DR_estimate(profile, g, o, D_u, w), ess

# IP-267 PG：个性化门控 + 三级回退
def select_level(u, o):
    prof = HUM.get(u)
    if not (prof.ci_width <= TAU_PI and prof.ess >= N_MIN):  return POPULATION, None
    if not (provenance_trusted(PID[u]) and prof.eps_used <= EPS_MAX): return POPULATION, None
    if not fair_check(u):                                     return POPULATION, None
    return USER, prof

# IP-268 PIG：养号 / 条件背叛检测（上置信界，不用均值）
def trust_farming(prof):
    lo, hi = prof.reliability('low'), prof.reliability('high')
    kappa = abs(lo.mu - hi.mu) / sqrt(lo.var + hi.var)
    return kappa > TAU_KAPPA or prof.defection_flag

# IP-269 DPA：端侧更新 + 上行 DP 聚合（异步，不进实时环路）
def dp_sync(prof, agg, eps_user):
    if prof.eps_used + eps_user > EPS_MAX: return NO_UPLOAD
    return laplace_clip(agg, eps_user), prof.eps_used + eps_user

# IP-273 主闭环（继承 R69，仅把 VoI 层换成个性化门控）
def PIVOT_RAS_round(M, u, obs, stakes):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    lvl, prof = M.pg.select_level(u, o)                 # USER / POPULATION
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes = M.aud.decompose(samples, z)
    # 个性化 VoI：只在 support 内；否则回退人群/R69
    g = None
    if U_epi > TAU_EPI:
        if lvl is USER:
            g = M.mint.choose_personalized(modes, o, prof, M.pid[u], stakes)
        else:
            g = M.mint.choose_population(modes, o)      # R69 的 VoI
    if g is not None and M.pig.trust_farming(prof):
        g = None                                        # 养号疑 → 不采纳个性化
    if g is not None:
        y = M.cia.execute(g)                            # 认证 + 交互预算
        U_epi = M.cia.update_belief_personalized(
                    modes, y, prof, discipline='k_ucb_agree')
        M.pid.append(u, o, g, y, prop=prof.propensity, source='real')
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(...)
    # 安全探索：低风险时留一点预算给数据集覆盖
    if safe_and(stakes == 'low') and rand() < ETA_EXPLORE:
        M.pid.append_gap_probe(u, M.c_ras_wm.safe_probe(o))
    M.vqa_i.submit_async(u, g, U_epi, prof, M.pig.kappa)
    return k, lam, modes, (U_ale, U_epi)

## 3. 推导

**引理 19（个性化 VoI 的支持条件）** 设行为 propensity 有界 e_μ ∈ [e_min, e_max]，目标/行为策略偏移受控；则双重稳健 VoI 估计的均方误差 ≤ C₁/ESS + B_extrap·1[g ∉ S_μ]，其中外推偏差 B_extrap 随 g 到 support 的距离单调增。系：**个性化只在系统「问过类似问题」的地方可信**；对从未问过的 g，个性化 VoI 是外推幻觉——这正是「数据集」必须带 support 信息的原因。

**引理 20（部分池化的收缩界）** 设用户 n_u 个有效样本、用户-人群异质性 ‖π_u − ψ‖ ≤ B、池化强度 λ，则后验均值误差 ≤ B/(1 + n_u/λ) + √(σ²/n_u)。系：PG 的 τ_π 等价于「在给定 n_u、B 下要求后验收缩到可接受精度」——**个性化是有代价的统计推断，不是开关**；数据少时它必须自动变得像人群模型。

**引理 21（一次性背叛的不可检测性）** 若用户在低风险阶段几乎全可靠（δ_low ≈ 1），仅在唯一一次高风险节点背叛，则任何基于历史的分层检验在事前都无法以显著检出力 > α 识别它（高风险样本数 n_high ∈ {0,1}）。故**检测不能替代证据纪律**：必须用 δ_p^+ 上置信界与 k 源一致，把单次背叛的损失压在上界内，而不能指望「提前识破」。

**定理 18（三级嵌套包含）** 在 A99–A101（正则性、support 覆盖、DP 校准、公平检查）下，PIVOT 任意状态期望风险 ≤ FLUID ≤ CALM；当 PG 回退 GLOBAL 时与 R69 逐指令相同；回退 POPULATION 时与「不做个性化的 FLUID」逐指令相同。个性化是**加法**，不是替代。

**定理 19（隐私-个性化权衡）** 在 (ε,δ)-DP 下，用户后验的 KL 误差下界随 1/ε² 增长（组合定理），导致 VoI 估计偏差 ≥ c·Lip·(1/ε²)。PG 的 ε_max 与 ESS 门槛把可行个性化限制在「数据足够且隐私预算足够」的区域。系：**隐私不是附加合规项，它直接决定个性化能否被相信。**

**定理 20（安全探索的覆盖-安全二象性）** 在 C-RAS-WM 认证包络内以概率 η 探索，单步物理风险 ≤ ε_int（与 R69 定理 17 同），且 cov(D) 以速率 η 单调增；有限时域累积风险 ≤ T·η·ε_int，可由预算 η 控制。**探索是数据集的燃料，但必须付安全税。**

## 6. 本轮最大风险

**一句话**：PIVOT-RAS 把信任条件化到个人，却只能用「系统自己问出来的数据」去支撑这份信任——**个性化越深，数据越是被旧策略筛选过的自我确认样本，系统越可能精准地信任错的那个人**：三个样本编出的画像让系统只问它想听的、养号者用前期配合换来关键处的一次背叛、隐私噪声又恰好抹掉了能证伪这份画像的信号；于是「个性化交互」把 R69 的「诚实的不知道」升级成「有证据支撑的偏见」，而这份证据恰恰来自偏见本身。

**次级风险与缓解**：
1. **support 外外推**（从未问过的问题却被算出高 VoI）→ OPEV 的 Extrapolated 标记 + 定义 315-b 硬门控；
2. **养号/条件背叛** → 上置信界 δ_p^+ + stakes 分层 κ_u + 单次高风险不单独定案（引理 21）；
3. **数据集投毒/合成数据污染** → provenance 标签 + poison_flag + synthetic 比例上限 + user-disjoint 校验；
4. **隐私噪声毁掉个性化** → DPA 端侧更新 + 定理 19 的 ε_max 与 ESS 联立门控；
5. **自我确认反馈环** → 定义 318 安全探索（双 VoI）+ E311 长时程监测，模态熵坍缩即强制提高 η。

def ope_voi(profile, g, o, D_u, tau_e):

    w   = propensity_ratio(g, D_u)            # clip 到 [w_min, w_max]
    ess = (w.sum()**2) / (w**2).sum()

    if not fair_check(u):                                            return POPULATION, None

def trust_farming(prof):

    kappa  = abs(lo.mu - hi.mu) / sqrt(lo.var + hi.var)
    return kappa > TAU_KAPPA or prof.defection_flag

## 4. 推导

**引理 19（个性化 VoI 的支持条件）** propensity 有界、策略偏移受控时，双重稳健 VoI 估计的 MSE ≤ C₁/ESS + B_extrap·1[g∉S_μ]，外推偏差随到 support 的距离单调增。系：个性化只在「问过类似问题」处可信；对从未问过的 g，高 VoI 是外推幻觉。

**引理 20（部分池化收缩界）** `err ≤ B/(1+n_u/λ) + √(σ²/n_u)`。系：PG 的 τ_π = 在给定 n_u、B 下要求后验收缩到可接受精度——个性化是有代价的统计推断，数据少时必须自动像人群模型。

**引理 21（一次性背叛不可检测）** 低风险阶段近全可靠、仅在唯一高风险节点背叛时，任何历史分层检验事前检出力 ≤ α。故检测不能替代证据纪律，必须用上置信界 + k 源一致压住单次背叛损失。

**定理 18（三级嵌套包含）** A99–A101 下 PIVOT 期望风险 ≤ FLUID ≤ CALM；PG 回退 GLOBAL 时与 R69 逐指令相同；回退 POPULATION 时与「不做个性化的 FLUID」逐指令相同。个性化是加法，不是替代。

**定理 19（隐私-个性化权衡）** (ε,δ)-DP 下用户后验 KL 误差 ~ 1/ε²，VoI 偏差 ≥ c·Lip/ε²；PG 的 ε_max 与 ESS 门槛把可行个性化限制在数据与隐私都足够的区域。隐私直接决定个性化能否被相信。

**定理 20（覆盖-安全二象性）** C-RAS-WM 认证包络内以 η 探索，单步风险 ≤ ε_int，`cov(D)` 以速率 η 单调增；有限时域累积风险 ≤ T·η·ε_int。探索是数据集的燃料，但必须付安全税。

**次级风险与缓解**：support 外外推（OPEV Extrapolated + 定义 315-b 硬门控）；养号/条件背叛（δ_p^+ 上置信界 + stakes 分层 κ_u + 单次高风险不单独定案，引理 21）；数据集投毒/合成污染（provenance + poison_flag + synthetic 上限 + user-disjoint 校验）；隐私噪声毁掉个性化（DPA 端侧 + 定理 19 的 ε_max/ESS 联立门控）；自我确认反馈环（定义 318 安全探索/双 VoI + E311 监测，熵坍缩即强制提高 η）。
