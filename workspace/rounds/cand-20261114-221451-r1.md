# 第 3 轮（灵感循环第 3 轮；本轮灵感：「群体智能」×「多机评测」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45）。本轮纪律：**改进而非推倒重来**。
> ToolGauge 的三个模块（L-Box / T-Box / AP-Cal）各沿「群体」轴升级；MODGAUGE 五不变式、4CV/6C 骨架、
> 严格退化链全部保留；并正面处理第 2 轮亲笔写下的最大风险：**AP-Cal 的跨盲区相关偏差**。

## 0. 核心直觉：单机看不见自己的共模误差

第 2 轮把最大风险押在一句话上：摊销先验一旦在 sim→real 偏移下产生**跨盲区强相关**的偏差，
所有被热替换的子图会同时向同一错误方向收缩。可第 2 轮的防线——独立回执交叉验证与 P-Quarantine——
**仍发生在同一台机器、同一套传感器、同一个先验族内部**。这暴露一个此前未被点破的结构性事实：

> **同一台机器上的任何交叉验证，都对「共模误差」天然失明。**
> 若偏差 b 同时加到该机的所有预测上（同一先验、同一标定链），则任意两条回执之差的期望里 b 被抵消；
> 残差看起来「彼此一致」，一致性被误读成正确性。

这不是工程疏漏，而是**可辨识性（identifiability）**问题：在没有第二个「不同规范（gauge）」的观测者时，
「真值整体平移」与「共同偏差」在数学上不可区分。于是：
**群体智能与多机评测不是效率灵感，而是第 2 轮那个失败模式的「测量仪器」**——
只有引入被不同规范标定、不同传感器族、不同先验的机器，让共模方向与真值方向不再共线，偏差才第一次变得可观测。

一句话概括本轮升级：
**把「单机的局部修复」升级为「机群的差分测量 + 留一机审计」**——
不是用更多机器投票来「更自信」，而是用机器之间的**差异**去暴露单机永远看不见的共同错误。

一个来自电子学的类比贯穿全文：差分放大器靠「共模抑制比（CMRR）」拒斥同时进入两端的噪声；
机群就是一组**差分对**，而留一机审计就是测量 CMRR 的那台仪器。差分放大器有一个致命前提——
两端噪声不能完全相关；对应地，机群有一个致命前提——**不能共享同一个共模源**（同一先验 / 同一信息素祖先）。

## 1. 三位一体映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 群体智能 | IP-315 L-Box：单个 VLA 提假设 | **S-Box 群体假设器**：异构提议者群体 + 信息素证据板 + 仲裁 | 单个先验/模型是相关失效的单点；但「多模型」≠「误差独立」 |
| 群体智能 | IP-317 T-Box：单机串行探测 | **P-Box 并行契约探测器**：机群分工、k 冗余、信息素去重 | 探测可并行、证据可共享，但共享即相关信道 |
| 多机评测 | IP-318 AP-Cal：一个共享摊销先验 | **F-Cal 联邦/留一校准 + Q-Watch**：差分校准与共模断路器 | 用机器间差异估计并剔除共模分量 |
| 多机评测 | 定义 421.V：单条独立回执交叉验证 | **SG-Audit 留一机（LOEO）审计** | 单机交叉验证在共模子空间上恒为零信息 |

**核心命题**：SwarmGauge = ToolGauge + **规范协变（gauge-covariant）的机群层**。
真值 u_s 规范不变，机器 m_i 报出 g_i(u_s)+b_i+e_i；跨机可比较的前提是**规范固定（gauge fixing）**，
固定后的残差分解为**共模 b** 与**私模 e_i**。群体层的全部算法（共识、仲裁、联邦校准、审计）
都必须显式区分这两项——否则「群体」只会把共模误差放大成「集体幻觉」。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 主张绑定不变式扩展：机群级修复证书必须引用**至少一台留出机**的回执（定义 442）；
- **严格退化链延长**：SwarmGauge 在 n=1（或机群不可达 / 共模不可辨识）时**逐位退化为 ToolGauge**，
  再退 LeanGauge，再退 MODGAUGE。群体是增强项，不是依赖项（引理 56）。

## 2. 形式化定义（增量：定义 432–446）

**定义 432（机群、具身规范与规范变换）** 机群 ℳ={m_1,…,m_n}，每机具身 e_i 给出已知规范变换
g_i: U→V_i（出厂标定/几何对齐，g_i^{-1} 存在）。盲区 s 的真值 u_s∈U 规范不变；
机器报出 x_i = g_i(u_s) + b_i + e_i。**规范固定**后 w_i := g_i^{-1}(x_i) = u_s + g_i^{-1}b_i + g_i^{-1}e_i。
机群的价值不在「数量」，而在规范变换 g_i 与噪声族**不完全共线**。

**定义 433（盲区签名的跨机索引）** 盲区签名 σ(s) = (区域描述子, 失效模态, 不变群) 是机器无关的索引键；
u_{s,i} 可随具身不同，但必须能通过已知 g_i 对齐。签名只用于**检索与去重**，绝不作为真值传递。

**定义 434（共识证据场 / 信息素板 𝒫）** 分布式键值场：𝒫[σ] = { (r, prov, t, ttl) }，
r 为 ToolGauge 定义 417 的有效回执，prov 为来源（机器、传感器族、先验版本、证据祖先），
按 (σ, prov 独立哈希) 去重；信息素以速率 μ 蒸发（过期证据退出仲裁）。
**𝒫 同时是共享证据与相关信道**（见定义 435）。

**定义 435（来源独立性与有效样本量 n_eff）** 两回执「独立」当且仅当 prov 的祖先图不共享：
(i) 同一传感器族；(ii) 同一预训练检查点；(iii) 时间窗内同一信息素祖先。设机群误差的组内相关 ρ，
则有效样本量 n_eff = n / (1 + (n−1)ρ)。**所有机群级统计与共形保证必须使用 n_eff，而非 n**。

**定义 436（S-Box 群体假设器与机群共形覆盖）** 异构提议者群体 Π={π_1,…,π_k}（不同 VLA/提示/具身先验）
各自产出 H_s^{(j)}，经 SNC 过滤（继承定义 425）后按**加权共形**合并：
H_s = { h : Σ_j ω_j·1[h∈H_s^{(j)}] ≥ θ_q }，权重 ω_j 与来源独立性成正比。
覆盖保证：P(h*∈H_s) ≥ 1−α，但**仅在 n_eff 满足引理 55 的条件下**成立，否则 H_s:={UNKNOWN}。

**定义 437（P-Box 并行契约探测与分工）** 探测程序 Π_s 被划分为机群任务分配
A: {(t,a)} → {m_i}，满足每机预算 Σ_{a∈A^{-1}(i)} c_a ≤ B_tools 与冗余 k（关键探测至少 k 台独立执行）；
分工由响应阈值模型（响应阈值随剩余预算/能力变化）给出，信息素板去重避免重复探测。

**定义 438（仲裁 / 法定人数 quorum）** 修复在盲区 s 上被接受，当且仅当存在 ≥q 个**来源独立**（定义 435）
的机器在容差 ε_q 内复现同一契约参数：|w_i − w_j| ≤ ε_q。q 与 n_eff 绑定，而非与 n 绑定。

**定义 439（F-Cal 联邦/留一校准）** 每机后验 q_i(u_s)=𝒩(μ_i,Σ_i)（由本机回执 + 摊销先验给出），
共享超先验 q_0。联邦更新采用规范固定的乘积专家（PoE）：q ∝ q_0 · Π_i (q_i)^{λ_i}，
λ_i 由来源独立性加权；**留一版本** q^{(-j)} 用除 j 外全部机器拟合，专门用于审计第 j 台（定义 442）。
物理锚（第 2 轮 p_phys）继续作为 KL 锚与方差下界。

**定义 440（共模-私模分解与可辨识条件）** 规范固定后写机群观测 x = u·1_n + Φc + e，
Φ∈R^{n×r} 为已知**偏差基**（传感器族/标定链/先验族的共同响应），c 为各机载荷，e 为私模噪声。
**共模可辨识** 当且仅当 **1_n ∉ span(Φ)**（等价的均匀平移方向不能被偏差模式伪造）。
若 1_n∈span(Φ)（例如全机群共享同一先验、同一传感器族），则真值整体电平与共模偏差**不可区分**：
系统必须**显式弃权**（absolute level unobservable ⇒ 只发相对修复证书，或 stub+RED），
并有 ≥1 个**外部锚**（可溯源标定机 / 独立模态 / 周期人类真值）来固定绝对电平。

**定义 441（Q-Watch 群体分歧断路器）** 维护规范固定后的跨机分歧统计
D = (1/2)·mean_{i≠j} |w_i−w_j| / sqrt(σ_i²+σ_j²)。
若 D 低于私模噪声预测（「过于一致」）而留一残差（定义 442）显著非零 ⇒ 判为**共模相关偏差**，
暂停共享先验、提高来源独立性权重、必要时回退 ToolGauge 单机路径。
Q-Watch 是第 2 轮 P-Quarantine 的机群化升级：**P-Quarantine 看时间上的同向偏差，Q-Watch 看机器间的过度一致**。

**定义 442（SG-Audit 留一机/留一具身审计与证书）** 对每个被修复盲区 s，用 q^{(-j)} 预测留出机 j 的回执，
标准化残差 |z_j| ≤ ε_audit；审计单元是**具身族**而非单机（避免近同构机「互相背书」）。
机群级修复证书 RepairCert_ℳ(s) 必须含 ≥1 个**留出机**回执；未通过 ⇒ 该修复只在拟合机局部有效，
不得写入机群共享证据场，不得声称机群级覆盖。

**定义 443（机群级共形保证）** 以 n_eff 为有效样本量，机群级覆盖 ≥ 1−α−2η−δ_corr，
其中 δ_corr 为信息素共享诱导的相关修正项；当 n_eff < n_min 时覆盖声明失效，降级为单机保证。

**定义 444（反污染聚合）** 对回执聚合使用中位数/截尾均值（median-of-means），
破坏点（breakdown point）≤ 1/2；而非简单平均。单台被攻陷机器（定义 417 的签名伪造 + 语义伪造）
不得移动聚合中心超过截尾比例。

**定义 445（机群安全态与扩展退化链）** 多机并行探测期间，每机独立进入 PROBING 态（继承定义 430），
机群协调只经**建议信道**（advisory），绝不进入各机 50Hz 控制环；网络延迟/丢包只降低证据率，不破坏单机安全。
退化链：**SwarmGauge ⇒（n=1 或共模不可辨识）ToolGauge ⇒ LeanGauge ⇒ MODGAUGE**。

**定义 446（继承与编号约定）** 未重定义的记号沿用定义 398–431；本轮所有增量以 ToolGauge 为退化特例：
n=1、Φ 使 1_n 平凡可辨识（单机无跨机差异）、𝒫 退化为本地缓存 ⇒ SwarmGauge ≡ ToolGauge。

## 3. 推导要点（引理 51–56）

**引理 51（单机共模盲性）** 对单机上任意回执集合，两两差分算子 D 满足 D·1 = 0；
故任何与所有预测共线的偏差 b·1 落在 D 的零空间，单机交叉验证对 b 的统计功效恒为 0（与样本量无关）。
*证明*：差分是线性算子，常向量在其核中。*系*：第 2 轮的「独立回执交叉验证」只能检验**私模**偏差，
恰好无法检验它自己写下的最大风险。

**引理 52（共模可辨识与锚的必要性）** 模型 x = u·1_n + Φc + e。u 与 c 可同时辨识 ⇔ 1_n ∉ span(Φ)。
若 1_n∈span(Φ)，存在 (u,c)≠(u',c') 给出同一分布，任何仅依赖 x 的估计量都无法区分二者；
外部锚把 1_n 方向的信息补入，恢复秩条件。*证明*：秩-零空间定理 + 不可区分情形构造。

**引理 53（机群方差分解）** E[(x̄−u)²] = b̄² + σ²/n（b̄ 为共模均值）。n→∞ 只消灭私模项，共模项留下。
*系*：多机平均提高**精度**，但不提高**正确性**；因此评测必须报 worst-case / CVaR，而非均值。

**引理 54（信息素的相关税）** 若共享信息素使各机误差组内相关为 ρ，则 n 条证据的有效样本量
n_eff = n/(1+(n−1)ρ)；样本效率增益从 n 降为 n_eff。当 ρ→1（同一先验/同一信息素祖先），n_eff→1：
「群体」退化为单点，且因表面票数而更自信。*系*：去重与来源独立性不是工程优化，而是统计声明成立的必要条件。

**引理 55（仲裁共形覆盖与 Byzantine 破坏点）** 在来源独立（ρ=0）且可交换下，以 n_eff 计的仲裁覆盖 ≥ 1−α；
当比例 f 的回执被污染，简单平均可被任意平移，而中位数/截尾均值在 f<1/2 时保持有界偏差。
*系*：q 必须按 n_eff 与 f 设，而不是按 n。

**引理 56（并行安全与退化等价）** 机群协调位于 50Hz 环之外且为建议信道 ⇒ 单机硬实时与安全不变式
（引理 45/50）保持；n=1 且 𝒫 退化时，S/P/F/Q 各模块逐位退化为 ToolGauge 的 L/T/AP/P-Quarantine，
故 ToolGauge 的全部保证被继承。

## 4. 对第 2 轮遗留缺陷的审计

| # | 第 2 轮缺陷 | 本轮处置 |
|---|---|---|
| 1 | P-Quarantine 只测「时间上同向」，对**静态共模偏差**无基线可测 | Q-Watch 用跨机差异作基线（定义 441） |
| 2 | 「独立回执交叉验证」用同机 cross.modal，共享机身与标定链，**独立性名不副实** | SG-Audit 留一具身族审计（定义 442） |
| 3 | 共形覆盖直接代入 n，未校正回执相关性 | 引入 n_eff 与相关税（定义 435、引理 54/55） |
| 4 | MP-Φ 的「M 越大越好」只在 i.i.d. episode 上论证，忽略具身相关 | 多机评测：留一具身 + worst-case，暴露相关（E447/E452） |
| 5 | 单个 VLA 是相关失效单点，假设集并不真「异构」 | S-Box 以来源祖先图而非模型数量计独立性（定义 435/436） |

## 5. 本轮最大风险（一句话）

群体可能对共模误差形成**高置信度的集体共识**——当所有机器共享同一先验/传感器族或信息素板被污染时，
仲裁与联邦只会放大而非纠正偏差；更危险的是，留一机审计**无法发现落在共模子空间内的偏差**
（引理 51/52 的必然推论），于是「多机评测通过」反而成为错误最可信的证书。

# 第 3 轮产物 · 创新点清单 v3：**SwarmGauge**（群体规范协变计量：差分测量、信息素共识与留一机审计）

> 背景：第 2 轮 ToolGauge（IP-315–320）用「契约化工具调用 + 预训练摊销先验 + VLA 降格审计」修好了
> LeanGauge 的三大弱点，却留下一个**自认无法在线检测**的最大风险：AP-Cal 的摊销后验在 sim→real 偏移下
> 产生**跨盲区强相关**的系统性偏差，一次错误先验同时污染所有热替换子图。
> 本轮的判据很简单：**这个风险在同一台机器内部原理上不可观测**（引理 51），
> 因此本轮不从「更好的先验」入手，而引入**第二个规范（gauge）**——机群。
>
> **集成链：MODGAUGE ⊃ LeanGauge ⊃ ToolGauge ⊃ SwarmGauge**（右侧为增强项，失效时向左退化）。
> 群体智能提供机制（异构假设、信息素共享、quorum、分工），多机评测提供**判据**（留一具身审计、worst-case、共模注入）。
> 一句话：**用机器之间的差异做差分测量，用留一机审计测共模抑制比；能测就修，测不了就弃权，绝不用票数冒充正确性。**
> IP 编号：IP-321–326（共 6 个）。定义增量 432–446；引理增量 51–56；实验增量 E441–E455。

| IP-324 | Q-Watch 群体分歧断路器 | 安全模块 | 用跨机分歧作共模基线；「过度一致 + 留一残差大」⇒ 共模报警（P-Quarantine 的机群化） |

## 2. 形式化定义（要点）

**定义 432–434（规范、签名、信息素）** 真值 u_s 规范不变，机器报 g_i(u_s)+b_i+e_i，规范固定得 w_i。
盲区签名只做跨机索引；信息素板按 (σ, prov 独立哈希) 去重并以 μ 蒸发。
**定义 435（独立性/n_eff）** 共享传感器族、共享预训练检查点、或共享信息素祖先即视为不独立；
有效样本量 n_eff=n/(1+(n−1)ρ)。
**定义 436（S-Box）** 异构提议者假设集经 SNC 过滤后，以独立性权重做加权共形仲裁，n_eff 不足则退 UNKNOWN。
**定义 437–438（P-Box/仲裁）** 探测按能力-成本分工，关键探测 k 冗余，信息素去重；quorum q 只按 n_eff 设。
**定义 439（F-Cal）** 规范固定的乘积专家 q ∝ q_0·Π_i q_i^{λ_i}；留一后验 q^{(-j)} 专供审计；物理锚作 KL 锚与方差下界。
**定义 440（共模可辨识）** x=u·1_n+Φc+e；可辨识 ⇔ 1_n∉span(Φ)；否则绝对电平不可观测，必须弃权或依赖外部锚。
**定义 441（Q-Watch）** D 低于私模预测而留一残差大 ⇒ 共模相关偏差，暂停共享先验。
**定义 442–443（SG-Audit/机群共形）** 留一具身族审计 + 机群证书；覆盖保证用 n_eff 并扣 δ_corr。
**定义 444（反污染）** median-of-means/截尾均值，破坏点 ≤1/2。
**定义 445–446（安全/退化）** 协调仅建议信道、各机独立 PROBING；n=1 逐位退化 ToolGauge。

## 3. 关键算法骨架

```python
# IP-321 S-Box：异构群体 + 来源独立性加权 + 机群共形仲裁
class SBox:
    def hypothesize(self, s, fleet):
        raw = [pi.propose(featurize_num(s, fleet.obs[s])) for pi in self.proposers]
        raw = [SNC_filter(hs, fleet.obs[s], fp_lib) for hs in raw]      # 定义 425
        groups = provenance_groups(self.proposers)   # 同传感器族/同检查点/同信息素祖先 ⇒ 折叠
        w = {g: 1.0 / len(groups) for g in groups}   # 独立性权重，而非 1/k
        score = weighted_vote(raw, w)
        H = [h for h in union(raw) if score[h] >= self.theta_q]
        if effective_n(groups, rho=self.rho) < self.n_min:
            return ["UNKNOWN"]                        # n_eff 不足 ⇒ 退化链
        return H or ["UNKNOWN"]

# IP-322 P-Box：机群分工 + 去重 + 并行 PROBING + 规范固定
class PBox:
    def assign(self, prog, fleet, budget):
        tasks = [x for x in prog if not self.pheromone.covered(x, fleet, self.eps_dedup)]
        return allocate(tasks, fleet, budget, k=self.k_red)   # 响应阈值分工 + 关键探测 k 冗余
    def execute(self, plan, fleet):
        out = {}
        for m, tasks in plan.items():
            if not m.probing_safe(): continue
            out[m.id] = m.tcv.execute(tasks, m.env)           # 每机独立 PROBING（定义 430/445）
        receipts = gauge_fix_and_merge(out, fleet.gauge)      # 定义 432/433
        for r in receipts:
            self.pheromone.write(r.sig, r, prov=r.prov, ttl=self.ttl)  # 定义 434
        return receipts

# IP-323 F-Cal：规范固定的乘积专家 + 留一后验
class FCal:
    def fit(self, receipts, s):
        per = {i: self.posterior(rs, s) for i, rs in receipts.items()}
        lam = independence_weights(per)                   # 定义 435
        q = poe(self.q0, per, lam, anchors=self.phys_anchor)   # 定义 439
        self.q = clamp_variance(q, KAPPA_PHYS)            # 继承定义 420 保守性夹紧
        return self.q
    def leave_one_out(self, receipts, s, j):
        rest = {i: rs for i, rs in receipts.items() if i != j}
        return poe(self.q0, {i: self.posterior(rs, s) for i, rs in rest.items()},
                   independence_weights(rest), anchors=self.phys_anchor)

# IP-324 Q-Watch：用跨机分歧作共模基线
class QWatch:
    def update(self, receipts, loo_resid):
        D = pairwise_disagreement(receipts)               # 规范固定后 |w_i-w_j|
        if D < self.tau_consistent and loo_resid > self.eps_audit:
            self.trigger("common_mode")                   # 过度一致 + 留一残差大
        if effective_n(receipts) < self.n_min:
            self.trigger("correlated_evidence")           # 相关税过高
        self.record(D, loo_resid, effective_n(receipts))

# IP-325 SG-Audit：留一具身族审计 + 共模注入 + worst-case
def sgaudit(s, receipts, fleet, fcal):
    resids = []
    for j in holdout_embodiment_families(fleet):          # 留出具身族，而非单机
        q_loo = fcal.leave_one_out(receipts, s, j)
        z = standardized_resid(q_loo, receipts[j])
        resids.append(z)
        if abs(z) > EPS_AUDIT:
            return Fail(reason=f"carried_by_{fleet.family(j)}", worst=max(resids))
    if not observable(fleet.bias_basis):                  # 1_n ∈ span(Φ)？
        return Partial(reason="absolute_level_unobservable")   # 只发相对证书 / 弃权
    if not common_mode_injection_passes(fleet):           # 协议自检：能测出合成共模吗？
        return Partial(reason="audit_blind_to_common_mode")
    return Pass(worst=max(map(abs, resids)))

# IP-326 SwarmGauge-7C 主闭环
def swarmgauge_round(M, fleet):
    for s in M.dbox.detect_blind_spot():                  # 继承定义 398/399
        if s not in M.inflight:
            M.inflight.add(s); submit_async(swarmgauge_7c, M, fleet, s)
    if M.qwatch.triggered():
        M.fcal.pause_shared(); M.use_toolgauge_single = True   # 定义 441 断路器
    return [MODGAUGE_round(mi, ...) for mi in fleet] if fleet.parallel else MODGAUGE_round(M, ...)

def swarmgauge_7c(M, fleet, s):
    H    = M.sbox.hypothesize(s, fleet)                         # S（机群假设）
    plan = M.pbox.assign(M.tbox.plan(H), fleet, M.budget(s))    # A（分工+去重）
    R    = M.pbox.execute(plan, fleet)                          # E（并行 PROBING）
    if effective_n(R) < M.n_min(s):                             # 定义 426/435
        return stub_and_red(s, "insufficient_effective_evidence")
    q    = M.fcal.fit(R, s)                                     # C（联邦校准）
    v    = M.sgaudit(s, R, fleet, M.fcal)                       # V（留一具身审计）
    if not v.ok:
        return stub_and_red(s, v.reason)                        # 未过审计 ⇒ 不写共享证据场
    ec   = M.fcal.update_contract(M.dpe, q, s)                  # U
    if not contract_regression(ec):
        return stub_and_red(s, "regression")
    for mi in fleet.local_to(s):                                # 逐机热替换
        M.mreg.hot_replace(mi.dpe, ec)
    M.qwatch.update(R, v.worst)
    bind_claims(ec, H, plan, R, v)                              # 机群证书（定义 442）
    return True
```

## 4. 推导（引理 51–56）

**引理 51（单机共模盲性）** 单机任意回执集合的两两差分算子 D 满足 D·1=0，故与所有预测共线的偏差 b·1
落在 D 的零空间，单机交叉验证对 b 的统计功效为 0（与样本量无关）。
*证明*：差分线性、常向量入核。*系*：第 2 轮的独立回执交叉验证只能测私模偏差，恰好测不到它自己的最大风险。

**引理 52（共模可辨识与锚的必要性）** x=u·1_n+Φc+e 中 u 与 c 可同时辨识 ⇔ 1_n∉span(Φ)。
若 1_n∈span(Φ)，存在 (u,c)≠(u',c') 给出同一分布；仅依赖 x 的估计量无法区分。外部锚补入 1_n 方向信息后恢复秩条件。
*证明*：秩-零空间定理；令 u'=u+α、c'=c−αΦ⁺1_n 即构造不可区分对。

**引理 53（机群方差分解）** E[(x̄−u)²]=b̄²+σ²/n。n→∞ 只消灭私模项，共模项留下。
*系*：多机平均提高精度不提高正确性；评测必须报 worst-case / CVaR（E447）。

**引理 54（信息素的相关税）** 若共享信息素使各机误差组内相关为 ρ，则 n 条证据的有效样本量
n_eff=n/(1+(n−1)ρ)；当 ρ→1（同一先验/同一信息素祖先）n_eff→1，群体退化为单点且因表面票数更自信。
*证明*：等相关系数下均值的方差为 (σ²/n)(1+(n−1)ρ)，等效独立样本数即 n_eff。
*系*：去重与来源独立性是统计声明成立的必要条件，不是工程优化。

**引理 55（仲裁共形覆盖与 Byzantine 破坏点）** 来源独立（ρ=0）且可交换下，以 n_eff 计的仲裁覆盖 ≥1−α；
污染比例 f 时，简单平均可被任意平移，而中位数/截尾均值在 f<1/2 时保持有界偏差（破坏点 ≤1/2）。
*证明*：共形分位数在可交换下覆盖；中位数的影响函数有界。

**引理 56（并行安全与退化等价）** 机群协调在 50Hz 环外且为建议信道 ⇒ 单机硬实时与安全不变式（引理 45/50）保持；
n=1 且 𝒫 退化时，S/P/F/Q 逐位退化为 L/T/AP/P-Quarantine ⇒ ToolGauge 全部保证被继承。
*证明*：协调信号不在控制回路；逐模块代入 n=1 与退化 𝒫 即得恒等。

## 5. 复杂度分析

| 组件 | 域 | 时间 | 空间 | 正确性锚 |
|---|---|---|---|---|
| S-Box 群体假设 | 异步事件 | k×VLA 前向（可并行缓存） | O(Σ\|H^{(j)}\|) | 定义 436、引理 54/55 |
| 来源独立性图 | 异步 | O(n·d_prov) | O(n) | 定义 435 |

| F-Cal 联邦 PoE | 异步 | O(r·d_u³)（r=独立组数，低秩加速） | O(r·d_u²) | 定义 439、引理 52 |
| LOEO 审计 | 异步 | O(n) 次留一拟合（可并行） | O(n·d_u²) | 定义 442、引理 51/53 |
| Q-Watch | 异步 | O(n²) 两两分歧（n 小）或 O(n) 稳健统计 | O(n) | 定义 441、引理 53 |

**相对第 2 轮**：新增开销全在异步机群层；50Hz 单机路径零增量。机群层的主要成本是**通信与留一拟合**，
但它们把第 2 轮「不可检测的共模风险」变成可测量量（D 与留一残差），这是本轮唯一真正新增的**信息**。

## 6. 多机评测协议（SG-Audit，定义 442/443）

1. **留一具身族**（LOEO-family）：按具身/传感器族聚类留出，避免近同构机互相背书；
   同时报告 LOMO（留一机）作补充。
2. **三段指标**：均值（精度）、worst-case（正确性下界）、CVaR₀.₁（尾部风险），**以 worst-case 为发布门槛**。
3. **共模注入自检**：向机群注入已知合成偏差 b†=α·1_n，审计协议必须在检测到 b† 之前**拒绝通过**；
   若协议对合成共模不敏感，则协议本身失效（`audit_blind_to_common_mode`）。
4. **锚审计**：报告 `1_n∉span(Φ)` 是否成立；不成立时只允许相对修复证书，绝对电平标 `unobservable`。
5. **相关税披露**：每组实验同时报告 ρ、n、n_eff，任何覆盖声明必须用 n_eff 重算。

## 9. 本轮最大风险

**一句话**：群体可能对共模误差形成**高置信度的集体共识**——当所有机器共享同一先验/传感器族或信息素板被污染时，
仲裁与联邦只会放大而非纠正偏差；更致命的是，留一机审计**无法发现落在共模子空间内的偏差**（引理 51/52 的必然推论），
于是「多机评测通过」反而成为错误最可信的证书。

**次级风险与缓解**：
1. **共模不可辨识** → 定义 440 显式弃权 + 外部锚 + E454 负面结果公开（绝不假装已修复）；
2. **伪多样性**（同基座不同提示）→ 来源祖先图计独立性 + n_eff 披露（定义 435、E445）；
