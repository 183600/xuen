# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「对比实验」×「隐私保护」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，又用元少样本、跨模态对账、个性化信任三条腿把证据做得更准；但它留下的三个问题恰好在本轮两个灵感里照了镜子：**(a)** 元先验摊销的是**相关性**不是**因果**——语料只能告诉元模型"这种观测常伴随这种表面"，不能回答"是材质还是坡度造成的"；EV-xmodal 的跨模态一致也可能是同一场地、同一时刻的共同混杂（两模态被同一因素同时推动），我们却把它当成独立佐证。**(b)** 云端元学习默认探针日志、标注、操作者确认时延可以上传，而这些数据里有位置、地形与人的行为指纹；第 57 轮只谈"证据隔离"，没谈"数据边界"——隐私不是事后加噪，而是重画谁能看见什么。**(c)** E172–E176 的"↓≥60%""+8%"是**无对照的观察性指标**：版本、场地、探针预算、操作者都不同，机制效应和混淆效应混在一起；我们甚至没有做过对比实验来证明"对比/隐私机制本身有效"。
> 本轮两条灵感各补一条腿：**对比实验**把"同一问题问五遍"换成"问一个配对的反事实问题"——倾向匹配找对照、差分中的差分剥离单一因素，产出证据类 EV-contrast；并把全部评估升级为预注册、匹配分配、序贯 e-value 的可证伪协议。**隐私保护**把云端学习改成联邦 + 安全聚合 + 差分隐私，把个性化信任状态留在边端，只上传带密码学承诺的粗粒度摘要；并把**隐私预算当作安全预算**——噪声必须写进校准证书，预算耗尽则证据降级。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"可因果识别、可隐私审计、噪声不冒充精度的证据说可信"**。

核心矛盾：
- **H29（对比 vs 混杂）**：机器人不能随机化物理世界；匹配只能平衡**可观测**混杂，未观测混杂（地下水位、日照史、制造批次、前人踩踏）会让 DiD 把相关当因果；更糟的是"能匹配到的对照"本身是从已探/可达区域里选出来的，正性（positivity）可能系统性失败——越安全的区域越容易被当成对照，越危险的区域越没有对照。
- **H30（隐私 vs 校准）**：DP 噪声与安全聚合的掉线鲁棒性会改变后验宽度与 ECE；ε 越小，证书越不可信，而证书恰是承诺的前提。隐私保护和证据健全性在**同一个预算**里争夺；组成（composition）随探针数×区域数×轮数增长，长期部署下 ε 会爆。噪声若不计入证书，系统会把"隐私造成的模糊"误读成"模型很确定"。
- **H31（隐私个性化 vs 可问责）**：把信任状态留在本地保护了操作者，却让跨站验证、追责、反女巫变难；可验证审计要暴露历史，隐私要求不暴露。承诺 + 选择性披露能同时满足二者，但密码学证明自身有实现漏洞、延迟与"承诺了假事实"的风险。

## 0. 直觉与动机

**灵感 1（对比实验 → 配对差分证据 EV-contrast）**
直觉：单模态重复探针像"把同一道题抄五遍"；对比实验像"做一道控制变量题"——找两块除目标因素外尽量相同的表面，各探一次，用差值把目标因素的贡献分离出来。机器人不能随机化世界，但可以在"持久地图 + 可达区域"里做**倾向得分匹配**，把可观测混杂（坡度/湿度/季节/材质簇/纹理）配平，用差分中的差分（DiD）估计目标因素效应；只有当平衡诊断（SMD≤θ_bal）、重叠（positivity≥η）、无干扰（SUTVA）与同协议同模态同时成立，差值才升格为证据类 **EV-contrast**。它还有第二重身份：**元先验的证伪器**——若元先验预测的对比方向与配对实验相反，就触发第 57 轮 R3 的回溯降权，把"沉默的坏先验"从相关性里揪出来。对比实验不只用于运行时，也用于评估：预注册、匹配分配、负对照、序贯推断，让"机制有效"成为可被数据推翻的因果命题。

**灵感 2（隐私保护 → 联邦 DP 元校准 + 本地信任 + 隐私预算入证）**
直觉：第 57 轮的云端元学习默认"日志可上传"，但日志里有位置、地形、确认时延（可推断疲劳与身份），标注里有人的判断质量（敏感行为）。隐私保护不是给系统加一个开关，而是重画数据边界：**原始日志永不出边端**，云端只收安全聚合后的模型增量与 DP 摘要；个性化状态 s_o 留在本地，跨站只承认 DP 聚合先验、禁止直接导入他站信任（防声誉洗白/女巫）。更关键的是把 DP 噪声写进证据：噪声使后验变宽，证书必须用**膨胀后的 ECE/区间**声明；若膨胀超过 w* 容忍，EV-probe* 自动降级——宁可证据变弱，不可让隐私噪声冒充精度。隐私预算因此与探针预算并列，成为第二种"会被花光的安全资源"。

**灵感 3（对比实验 × 隐私保护 → 隐私机制本身要被对比检验）**
直觉：隐私机制（DP、聚合、本地化）同时改变安全与效用，不能只说"我们加了 DP"；必须用同一套对比协议估计它的**因果代价**：在匹配地形/任务上随机分配 ε 档位与隐私开关，报告"隐私—校准—承诺失败"的剂量-响应曲线，并设负对照（把 DP 加在不应影响安全的通道上，验证无虚假效应）。反过来，对比实验也能隐私化：只上传聚合后的对比统计量与 e-value，不上传个体轨迹。两条灵感不是拼接，而是互为约束——对比实验给出"隐私值多少钱"的可识别估计，隐私保护给出"对比实验能看多少"的数据边界。

**灵感 4（三灵感合流 → 证据门从五类到六类、从"质量"到"可识别性 × 隐私成本"）**
直觉：第 57 轮证据门 EV-probe*/visit/margin/xmodal/human 本轮各获得新维度：EV-contrast 新增且仅限 L0/L1 非不可逆接触；EV-probe* 须同时声明"元校准 + DP 膨胀 + ε_spent≤ε_max"；EV-xmodal 的"独立"要过对比审计（同一混杂下的伪独立降级）；EV-human 的信任本地化后审计走承诺 + 选择性披露。击穿安全需要：匹配失败 ∧ 未观测混杂 ∧ DP 账本乐观 ∧ 跨模态伪独立 ∧ 无裕度 ∧ 人错——纵深从五层到六层。

**灵感 5（PCE++ → 对比是更便宜的探询，隐私是更贵的证据）**
直觉：VOI 新增两类动作——"配对对照探针"（若匹配成功，一次对照可能比 k 次重复探针提供更多信息）与"隐私降级动作"（预算耗尽时转本地共形带/绕行/降档，而不是硬上传）。对账检查点若发现分歧，优先问"最大分歧模态在对照区域是否也分歧"——把分歧本身变成对比问题。承诺前的解释也改成对比式：把目标区域与匹配对照并排展示，让操作者校准的是"差在哪里"，而不是孤立地看一个分数。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（匹配对照差分证据 MCD / EV-contrast）** 区域因素向量 z_r=(材质簇,坡度,湿度,季节,纹理)∈Z，目标因素 t_r⊂z_r。响应 θ=f(z)+η。对目标区域 r，在可达非破坏探针区域集 𝒜_r 中取对照 r'=argmin_{r'∈𝒜_r, t_{r'}≠t_r} d(z_r^{¬t},z_{r'}^{¬t})。平衡 SMD(z_r,z_{r'})≤θ_bal、倾向得分 e(z)∈[η,1−η]（正性）、同模态同协议、探针不改变对照（SUTVA/无干扰）合称条件 A41。差分估计 τ̂=Δ(o_r−o_{r,pre})−Δ(o_{r'}−o_{r',pre})；敏感度上界给出 |τ̂−真效应|≤δ_contrast。EV-contrast 仅在 A41 全过且 τ̂ 的符号/量级与元先验预测冲突或互补时入账；**仅限 L0/L1**，可替代一次 L1 佐证，永久不得进入不可逆接触必要证据集；与预测冲突时触发定义 134 的 R3 回溯降权。

**定义 140（联邦差分隐私元校准 FDPC）** 边端数据 D_j 不出本地。本地更新 Δ_j=Clip(∇ℓ(q_φ;D_j),C)；安全聚合 SecAgg 只向云端暴露 Σ_{j∈S_t}Δ_j 与掉线集（|S_t| 的掉线鲁棒界进入证书）；再加高斯噪声 Δ̃=ΣΔ_j+𝒩(0,σ²I)，σ=C√(2ln(1.25/δ))/ε_t，满足 (ε_t,δ)-DP。用 RDP/zCDP 会计跨 T 轮、跨区域、跨模态组成总预算 ε_tot≤ε_budget。**噪声感知校准**：后验协方差取 Σ_post+σ²I，覆盖区间按 DP 膨胀；声明的校准契约为 ECE_k^{DP}≤ε_meta(k)+κσ，区间宽 w_k^{DP}≤w*。若 w_k^{DP}>w* 或 ε_spent>ε_max(L)，EV-probe* 自动降级为 DP 共形带（DP 分位数）或拒绝。元模型更新仍走影子模式回归测试（ECE^{DP} 不劣化 ∧ 覆盖不降 ∧ 分歧触发率不降）。

**定义 141（本地隐私信任与承诺审计 LPT）** 状态 s_o=(cal,vig,auth) 仅存边端并加密。上传摘要 com_o=Commit(auth_bucket, DP(cal̃), DP(vig̃))，auth_bucket 为粗粒度且 ε_p 受控。跨站信任禁止直接导入，只允许经 SecAgg 的全局 DP 先验间接影响；每个边端/操作者单凭证 + 速率限制做反女巫。审计为 append-only Merkle 哈希链；监管者/安全方可通过**选择性披露**获得零知识证明 Π："操作者 o 在时刻 t 对接触 c 持有 auth≥A1 且 corrob≥2"，不泄露 cal 历史与身份明文。承诺不可否认；仅在多方授权的 break-glass 下可开启原始记录（隐私与可问责的显式边界）。

**定义 142（隐私感知证据门 PAG 与证书 J_q）** 证据 c 附 privacy 字段 (ε_spent(c),σ_DP(c),commit_root)。门规则：EV-probe* ⇔ ID ∧ ECE_k^{DP}≤ε_meta(k) ∧ w_k^{DP}≤w* ∧ ε_spent≤ε_max(L)；EV-contrast ⇔ A41 全过 ∧ 平衡/正性诊断过 ∧ L≤L1 ∧ 隐私预算够；EV-xmodal ⇔ 独立声明 ∧ **对比审计过**（若匹配对照显示两模态被同一因素同向推动，则判伪独立降级）∧ D(r)≤θ_D；EV-visit/margin 继承第 57 轮；EV-human ⇔ auth≥A1 ∧ corrob≥corrob*(auth) ∧ com_o 可验证 ∧（若要求）Π 通过。证书 J_q=J_p∪{DP 账本, 每区域 σ/ε, SecAgg 掉线日志, 对比设计日志(匹配对/平衡/正性), 承诺根, ZK 证明, 隐私预算分配表}。

**定义 143（可证伪对比实验协议 CXP）** CXP=(预注册假设 H, 匹配分配 A, 因子设计 F, 因果估计量 τ, 序贯推断 e-value, 负对照 N, 隐私遥测规则 P)。匹配分配：同一地形/任务按块随机化版本（v57/v58、ε 档位、隐私开关），倾向匹配+分层保证协变量平衡；估计量报 ATE/CATE（承诺失败率、探针数、首访时延）；推断用 anytime-valid e-value/置信序列，预注册停止规则；负对照包括 placebo 探针与"DP 加在非安全通道"；遥测只上传聚合 DP 统计与 e-value，逐实验登记 ε_exp。任何"机制有效"的声明必须过预注册 + 匹配分配 + 外部复现，否则只算假设。

**定义 144（探-诺-演++ 算子 PCE++）** 每检查点候选动作扩展为 {常规探针, 配对对照探针, 共识探针, 隐私降级动作}：①元推断（ID→DP 膨胀后验/OOD→DP 共形带）；②对账；③若 k 次重复探针的 VOI < 一次配对对照的 VOI 且存在合格对照，则走 MCD；④承诺 ⇔ ∃g:R≤δ_f(g) ∧ PAG 通过；⑤否则 argmax_π[VOI_元悲观(π)−cost(π)−λ_p·ε(π)]≥θ_voi；⑥探尽/预算尽→绕行→降档→本地共形→L2 协商（τ_int(auth)）或安全停。协商解释采用对比式渲染（目标 vs 匹配对照），且不泄露对照区域的可识别信息。

## 2. 关键算法伪代码（完整版见产物区）

```python
def match_and_contrast(M, r, factor, budget):        # IP-139 / 定义139
    ctrl = argmin_control(M, r, factor, reachable=True, non_destructive=True)
    if not (smd(M, r, ctrl) <= theta_bal and overlap(M, r, ctrl) >= eta):
        return None, 'balance_or_positivity_fail'
    pair = [probe(M, r), probe(M, ctrl)]              # 同模态同协议
    tau = did(pair, M.history)
    return Contrast(tau=tau, ctrl=ctrl, delta=delta_contrast), 'EV-contrast'

def federated_meta_update(q_phi, clients, eps_round):  # IP-140 / 定义140
    grads = [clip(local_grad(q_phi, c), C) for c in clients if c.alive]
    agg = secagg_sum(grads, dropout_bound=rho_drop)    # 只看得到和
    noisy = agg + gaussian(0, sigma_of(eps_round, C))
    eps_tot = accountant.compose(eps_round); assert eps_tot <= eps_budget
    q_new = q_phi - lr * noisy
    return q_new, noise_inflate(q_new, sigma_of(eps_round, C)), eps_tot

def privacy_aware_gate(c, M, persona, dp):            # IP-142 / 定义142
    if c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_dp <= eps_meta(c.k)
              and c.inf.w_dp <= w_target and dp.spent(c.region) <= eps_max(c.level))
    elif c.ev == 'EV-contrast':
        ok = c.level in ('L0','L1') and c.a41_ok and c.balance_ok
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and not c.contrast_confounded
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and c.corrob >= corrob_star(persona[c.op].auth) \
             and verify_commitment(c.com) and (not c.zk_required or verify_zk(c.pi))
    else:
        return ('reject', 'no_evidence_class', c)
    return ('ok', c) if ok else ('reject', 'privacy_or_evidence_insufficient', c)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MCD | O(\|𝒜_r\|·d_z) 匹配 + O(2) 探针 | O(\|V\|·d_z) | A41：平衡/正性/SUTVA/无干扰；δ_contrast 敏感度界 |
| FDPC | O(d_φ)/客户端 + O(\|S_t\|d_φ) 聚合 | O(\|𝒟_meta\|) 静态 | (ε,δ)-DP、组成账本诚实、噪声入证 |
| LPT | O(1)+O(log N) 承诺/证明 | O(\|操作者\|) 本地 | 承诺绑定性、ZK 可靠性、跨站导入禁止 |
| PAG | O(\|σ\|+H_zk) | O(\|σ\|) | 无证据类即拒、噪声超限即降级 |
| CXP | 离线 O(N·d_z) 匹配 + 序贯 | O(N) | 预注册、平衡、e-value 有效性 |
| PCE++ | 同第 57 轮 + O(1) 对比/隐私决策 | O(\|V\|+\|σ\|) | VOI 含隐私成本、k_p+k_c+k_ct 终止 |

**正确性定理（CCPPS 概要）**：在 A33–A40 上加 (A41) 对比识别：平衡≤θ_bal、正性≥η、SUTVA/无干扰、同协议，违者 EV-contrast 无效，且 |τ̂−τ|≤δ_contrast；(A42) DP 会计诚实：每轮 (ε_t,δ)-DP、σ 与掉线界正确入账、ε_tot≤ε_budget、噪声膨胀覆盖真实后验；(A43) 本地信任完整性：承诺绑定性、ZK 可靠性、跨站信任不可直接导入。则：(i) ID 路径承诺失效率 ≤δ_f+ε_meta(k)+κσ+δ_probe+ε_h(w_max)，对比路径附加 δ_contrast，OOD/DP 降级路径贡献 ≤δ_ood·α_conf+δ_dp；(ii) **隐私单调性**：在同一证据流上增大隐私保护（ε↓/噪声↑/本地化↑）只能加宽区间、降级证据或转保守动作，**不存在升险路径**，代价是活性（探针数/时延↑）；(iii) 评估有效性：任何机制效应声明在 CXP 下可识别为 ATE/CATE，未过预注册与匹配的指标只作探索；(iv) PCE++ 在 k_probes+k_cons+k_contrast 内终止于四态。

## 4. 实验设计 E177–E181

```python
def match_and_contrast(M, r, factor, budget):
    cands = [c for c in M.regions
             if reachable(c) and nontrivial_probe_ok(c) and c != r]
    ctrl = min(cands, key=lambda c: confound_dist(M.z[r], M.z[c], exclude=factor))
    if smd(M.z[r], M.z[ctrl], exclude=factor) > theta_bal:
        return None, 'balance_fail'
    if not (eta <= propensity(M.z[r]) <= 1 - eta and
            eta <= propensity(M.z[ctrl]) <= 1 - eta):
        return None, 'positivity_fail'
    o_r  = execute_probe(r,   modality='tap', cap=F_abs)
    o_c  = execute_probe(ctrl, modality='tap', cap=F_abs)   # 同模态同协议
    tau  = (o_r.post - r.pre) - (o_c.post - ctrl.pre)       # DiD
    ev   = Contrast(tau=tau, ctrl=ctrl, a41_ok=True,
                    balance_ok=True, level=contact_level(r),
                    delta=delta_contrast)
    if sign(tau) != sign(meta.predict_contrast(r, ctrl, factor)):
        M = retro_demote_meta(M, r, reason='contrast_violation')   # 触发 R3
    return ev, 'EV-contrast'
```

    alive = [c for c in clients if c.alive]

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MCD | O(\|𝒜_r\|·d_z)+O(2·d_probe) | O(\|V\|·d_z) | A41；δ_contrast 敏感度界；仅 L0/L1 |
| FDPC | O(d_φ)/客户端 + O(\|S_t\|·d_φ) | O(\|𝒟_meta\|) 静态 | (ε_t,δ)-DP、组成会计、噪声入证（A42） |
| LPT | O(1)+O(log N) | O(\|操作者\|) 本地 | 承诺绑定性、ZK 可靠性、禁止跨站导入（A43） |
| PAG | O(\|σ\|+H_zk) | O(\|σ\|) | 六类门、噪声超限降级、伪独立降级 |
| CXP | 离线 O(N·d_z) 匹配 + 序贯 | O(N) | 预注册、平衡、e-value 有效性 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_ct)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | VOI 含隐私成本、三类探针终止 |

**正确性定理（Causal-Privacy Calibrated Personalized Soundness, CCPPS）**
假设 A22–A32、A33–A36、A37–A40 成立；新增 **(A41) 对比识别**：匹配后 SMD≤θ_bal、倾向得分∈[η,1−η]、SUTVA/无干扰、同模态同协议，违者 EV-contrast 无效，且 |τ̂−τ|≤δ_contrast；**(A42) DP 会计诚实**：每轮 (ε_t,δ)-DP、σ 与掉线界正确入账、ε_tot≤ε_budget、噪声膨胀区间覆盖真实后验；**(A43) 本地信任完整性**：承诺绑定性、ZK 可靠性、跨站信任不可直接导入。则：

1. **因果-隐私承诺健全性**：ID 路径 P(fail) ≤ δ_f+ε_meta(k)+κσ+δ_probe+ε_h(w_max)；对比路径附加 ≤δ_contrast；OOD/DP 降级路径贡献 ≤δ_ood·α_conf+δ_dp；EV-xmodal 仅 L1 贡献 ≤δ_xm 且需过对比审计。
2. **隐私单调性（对偶于交互单调性）**：同一证据流上，提高隐私保护（ε↓、σ↑、聚合↑、本地化↑）只能 (a) 加宽信念/区间、(b) 降级证据类、或 (c) 选择更保守动作，不存在升险路径；代价是活性（探针/时延/绕行）单调不降。
3. **评估有效性**：任何"机制有效"声明在 CXP 下可识别为 ATE/CATE；未过预注册、匹配平衡或负对照的指标只能作探索性假设，不得进入安全论证。
4. **终止性**：每检查点常规/共识/对比探针分别 ≤k_probes/k_cons/k_contrast，PCE++ 终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + κσ + δ_probe + ε_h + δ_ood·α_conf
                   + δ_xm·1[L1] + δ_contrast·1[EV-contrast] + δ_dp)
             − P(匹配诊断失效未检出) − P(DP 会计乐观) − P(承诺/ZK 失效)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**对比把"相关"升级为"可识别"**，代价是必须承认"无对照即无证据"；**DP 把隐私噪声写入证书**，用隐私单调性保证"更隐私只会更保守"；**本地信任 + 承诺审计**把个性化从"集中监控"变成"可问责但不泄露"；评估本身也接受同一套可证伪标准。

## 6. 本轮最大风险

**一句话**：本轮把证据的因果合法性押在一套物理世界无法随机化的匹配设计上，又把审计可靠性押在密码学承诺上——若匹配漏掉一个混杂因素、且 DP 会计偏乐观，EV-contrast 会把伪因果包装成"对照实验证明"，隐私噪声会把模糊包装成"校准良好"，系统将在同时宣称严谨与隐私的情况下自信地犯错；必须以平衡/正性硬门、噪声入证、预注册与负对照、以及本地单向有界信任 + 选择性披露审计四重护栏，宁可承认"这对照不成立、这预算不够"，绝不让不可识别的相关性与不可验证的账本进入承诺。
