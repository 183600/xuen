# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「数据采集」×「激光雷达」）

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（PCA / CTS / CFC / HPC / CFCtrl）。
> 本轮纪律：**采集是主动实验、样本是证书预算、回波是物理证据**。不推倒 v20：v20 的 PCA/CTS/CFC/HPC/CFCtrl 与 v19 的 DCM/OGCC/CCV/DRS/OGC、v17 的 CLP/S2C/HCG/PSV/APS/AMC 全部保留。本轮只做一件事：**把"有限、主动、多回波的激光雷达数据采集"变成碰撞证书的一等公民**，并正面修补 v20 的"众口铄金"薄壁盲区。

## 0. 直觉与动机

**灵感 1（激光雷达 → 采集是主动实验，不是被动等帧）**
直觉：深度相机是被动的——它按固定视场接收一帧稠密深度，你只能决定"看不看"，不能决定"朝哪看多密"。激光雷达是主动的——它发射脉冲，你可以选择方位、俯仰、驻留时间与重访间隔。于是"数据采集"从**接收问题**变成**控制问题**。反直觉点在于：证书不该由感知来驱动，而该反过来**驱动感知**——下一步该扫的方向，不是"场景最有趣"的方向，而是"证书最不确定、且最可能推翻当前结论"的方向。这把 v20 的 `perceive → certify` 单向流水线，改造成 `certify → acquire → certify` 的闭环，核心创新记为 **主动采集规划器 (Active Acquisition Planner, AAP)**。

**灵感 2（数据采集 → 样本是证书预算，存在采样-保守性定律）**
直觉：每个激光雷达样本都要花时间、能量和带宽，而它只带来有限的证书不确定性下降。要把保守碰撞域的边界收窄 δ，至少需要 N(δ, ε) 个有效独立样本；这是信息论下界，不是工程调参。所以采集理应有**最优停止**，而不是固定 10–30Hz 一路狂扫。核心创新记为 **采样-证书预算 (Sample-Certificate Budget, SCB)**：把"采多少"写成关于目标精度 δ 与失败概率 ε 的预算不等式，当边际证书收益低于单位采集成本时停止。反直觉点：**采集不是越多越好，而是"刚好够证书用"最好**；盲目高频扫描既费电，又不改善证书。

**灵感 3（激光雷达多回波 + 强度 → 回波是物理证据，专治 v20 的薄壁盲区）**
直觉：v20 的最大风险是"众口铄金"——所有深度相机都系统性漏掉薄壁、玻璃、细线，联邦共识反而把这个盲区放大。激光雷达的多回波与强度恰好提供**透射率**证据：玻璃/薄壁会产生"近端弱回波 + 远端强回波"的双回波，而深度相机只给一个含糊的单深度。核心创新记为 **多回波透射证书 (Multi-Echo Transmittance Certificate, METC)**：把每条射线的多回波序列转成"透射率下界 τ_min + 中间占据壳层"，从而**双向**修正 v20：既能**证伪**（发现薄壁 → 更保守，修补盲区），也能**证真**（确认无遮挡 → 回收被 v20 误排除的安全 θ，提升活性）。反直觉点：**更好的感知不是让安全域单调变大，而是让"保守域"与"真实安全域"同时从两侧逼近**——证伪与证真是同一个物理量的两个方向。

**三者如何统一**
v21 = v20 感知层之上的**采集层**。v20 问"给定分布式感知，节点 n 在参数 θ 下是否安全"；v21 问"给定有限、主动选择、多回波的 LiDAR 采集预算，θ 能否被证书化，以及下一步该扫哪里"。AAP 是控制侧（扫哪里），SCB 是预算侧（何时停），METC 是证据侧（回波意味着什么）。共享状态 `ζ_acq = (scan_plan, ray_returns, tau_profile, budget_ledger, reclaim_set, mode_acq)`。统一接口：**保守模式下，采集只能收缩安全域（`Exec_v21^cons ⊆ Exec_v20`）；回收模式下，仅当 METC+SCB+AAP 三重证书同时通过时，才允许回收 v20 误排除的 θ，且必须满足 `P(reclaim ⊆ TrueSafe) ≥ 1-ε`**。任一模块失效即退回 v20。

## 1. 研究问题（轮次升级版）

- **Q1（主动采集的证书增益）**：AAP 如何度量"某方向采集对证书的期望增益"？在只允许保守收缩的前提下，如何保证主动扫描不会因为"没扫到"而漏掉障碍（未扫描区域必须默认占据）？探索-利用如何与 50Hz 控制环共存而不拖慢主循环？

- **Q2（采样-证书预算）**：N(δ, ε) 的紧致下界是什么？多回波、射线非独立、噪声相关时，集中不等式如何修正？最优停止准则如何与 v20 的 margin_col / τ_consensus 耦合？预算耗尽时如何优雅降级而不产生控制跳变？

- **Q3（多回波透射的物理可信度）**：强度未标定、材质反射率变化、雨雾/镜面/高反条件下，τ_min 如何给出**可信下界**而非点估计？双回波如何区分"薄壁"与"玻璃/开放"？METC 的证真（回收）如何避免把真实障碍误判为开放？

- **Q4（回收证书的可靠性）**：回收集如何与 v20 的 HPC 合成？回收的 false-free 概率如何用 SCB 的 ε 严格控制？回收后若后续回波推翻结论，如何回滚且不产生控制跳变？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 主动采集保守律（Active Acquisition Conservatism）**
未扫描方向**默认占据**；采集只能通过 METC 的**显式证据**改变占据状态。保守模式下，任意时刻的认证安全域单调不增：`Safe_{t+1} ⊆ Safe_t ⊆ Safe_0 = HPC_v20`。因此 `Exec_v21^cons ⊆ Exec_v20`。扫描不是"发现自由"，而是"在默认占据的底图上，用证据逐点擦除占据"。

**P35 采样-证书预算律（Sample-Certificate Budget）**
对任意目标精度 δ 与失败概率 ε，把某区域的占据边界认证到 ±δ 至少需
`N_stat(δ, ε) = ⌈ log(2/ε) / (2δ²) ⌉` 个有效独立样本（Hoeffding / DKW 一致收敛），并叠加角度覆盖下界 `N_ang = ⌈ Ω_total / ω_min ⌉`，取 `N_need = max(N_stat, N_ang)`。采集在 `ΔU/Δcost < λ` 时停止（U 为证书不确定性，λ 为单位成本门槛）。回收区的每个单元都必须满足 `n_cell ≥ N_stat(δ, ε)`。

**P36 多回波双向证据律（Multi-Echo Bidirectional Evidence）**
METC 对每条射线输出四值判决 `{OCCUPIED_SHELL, OPAQUE_NEAR, OPEN_PAST, UNKNOWN}`。只有 `OPEN_PAST` 且 `τ_min > τ_thresh` 才允许进入回收候选；`OCCUPIED_SHELL` / `OPAQUE_NEAR` 触发保守收缩；`UNKNOWN` 保持 v20。回收必须同时获得 **SCB 预算签** 与 **AAP 覆盖签**（该方向确实被主动扫过且角度覆盖达标），缺一不可。

## 3. 与基线的接口（如何退化）

- AAP 失效（无法主动控制扫描）⇒ 退化为固定栅格扫描 = v20 的被动感知 ⇒ 等价 v20；
- SCB 失效（无法估计样本下界）⇒ 关闭回收，只保留保守模式 ⇒ 等价 v20（更保守）；
- METC 失效（强度未标定 / 单回波）⇒ 回波退化为单深度 ⇒ 等价 v20；
- 回收证书失败（预算不足 / 覆盖不足 / 回波矛盾）⇒ `Exec_v21 = Exec_v21^cons ⊆ Exec_v20`；
- **安全继承**：保守模式 ⊆ v20；回收模式 ⊆ TrueSafe（概率 ≥ 1-ε）；任意失效都回到更保守一侧。

## 4. 预期贡献

1. **主动采集证书**：首次把"数据采集"从被动接收改写为**证书驱动的主动实验**，用证书不确定性而非场景显著性来分配扫描预算，填补"感知—证书"闭环的控制侧空白；
2. **采样-证书预算**：给出采样数与证书保守性之间的定量定律、集中不等式下界与最优停止准则，使"采多少"第一次有可证明的判据；
3. **多回波透射证书**：用 LiDAR 的物理证据（多回波 + 强度）**双向**修正 v20——证伪补盲区、证真提活性，正面回应"众口铄金"风险；
4. **回收证书与回滚**：给出可审计的回收—回滚机制，使"扩大安全域"成为一件有证书、可撤销、可追责的事，而非拍脑袋；
5. **层次化采集证书**：AAP+SCB+METC 构成采集层，落在 v20 感知层之上，形成"主动采集 → 物理证据 → 证书收敛"的闭环。

## 5. 本轮最大风险

**一句话**：METC 的回收（证真）依赖"回波能量可解释"，一旦高反/镜面/雨雾/远距离把真实薄壁的弱回波压到噪声下并判成 `OPEN_PAST`，回收就会把 v20 本来正确排除的障碍重新授权为安全——即"主动扫描的证真误判"，而且这种误判会被 SCB 的统计置信"洗白"。

```python
# IP-425 Multi-Echo Transmittance Certificate
@dataclass
class RayVerdict:
    kind: str          # OCCUPIED_SHELL / OPAQUE_NEAR / OPEN_PAST / UNKNOWN
    near: float        # 最近占据距离
    far: float         # 壳层远端（无壳层时等于 near）
    tau_min: float     # 透射率下界
    evidence: dict

class MultiEchoTransmittanceCertificate:
    def __init__(self, tau_thresh=0.35, gap_min=0.05, I_min=1e-3,
                 sigma=0.02, kappa=3.0, max_range=20.0):
        self.tau_thresh = tau_thresh
        self.gap_min = gap_min
        self.I_min = I_min
        self.sigma = sigma
        self.kappa = kappa
        self.max_range = max_range

    def analyze_ray(self, returns, E0):
        """returns: [(depth, intensity), ...] 按 depth 升序；E0: 发射能量"""
        if not returns or E0 <= 0:
            return RayVerdict("UNKNOWN", 0.0, self.max_range, 0.0, {})

        E_ret = sum(I for _, I in returns)
        # 能量守恒 + 噪声安全系数 -> 透射率下界（非点估计）
        tau_min = max(0.0, (E0 - E_ret - self.kappa * self.sigma) / E0)

        # 中间壳层：相邻回波间距足够大且近端回波可辨（薄壁/玻璃）
        shells = []
        for (d1, I1), (d2, I2) in zip(returns, returns[1:]):
            if d2 - d1 >= self.gap_min and I1 >= self.I_min:
                shells.append((d1, d2))
        if shells:
            d1, d2 = min(shells, key=lambda s: s[0])
            return RayVerdict("OCCUPIED_SHELL", d1, d2, tau_min,
                              {"shells": shells, "E_ret": E_ret})

        # 无壳层且大部分能量未被解释 -> 开放（证真候选）
        if tau_min > self.tau_thresh:
            return RayVerdict("OPEN_PAST", returns[-1][0], self.max_range,
                              tau_min, {"E_ret": E_ret})

        # 否则视为近端不透明占据（证伪）
        d1 = returns[0][0]
        return RayVerdict("OPAQUE_NEAR", d1, d1, tau_min, {"E_ret": E_ret})

    def ray_to_occupancy(self, verdict):
        """保守模式下：只有显式 OPEN_PAST 才是自由；其余一律占据。"""
        if verdict.kind == "OPEN_PAST":
            return ("FREE", verdict.near, self.max_range)
        if verdict.kind == "UNKNOWN":
            return ("V20_FALLBACK", 0.0, self.max_range)
        return ("OCCUPIED", 0.0, verdict.far)


# IP-426 Sample-Certificate Budget
class SampleCertificateBudget:
    def __init__(self, delta=0.02, epsilon=1e-3,
                 omega_total=4 * math.pi, omega_min=1e-4, lam=1e-4):
        self.delta = delta
        self.epsilon = epsilon
        self.omega_total = omega_total
        self.omega_min = omega_min
        self.lam = lam

    def statistical_lower_bound(self, delta=None, epsilon=None):
        d = delta if delta is not None else self.delta
        e = epsilon if epsilon is not None else self.epsilon
        return math.ceil(math.log(2.0 / e) / (2.0 * d * d))

    def angular_coverage_bound(self):
        return math.ceil(self.omega_total / self.omega_min)

    def required_samples(self, delta=None, epsilon=None):
        return max(self.statistical_lower_bound(delta, epsilon),
                   self.angular_coverage_bound())

    def marginal_gain(self, u_before, u_after, cost):
        return (u_before - u_after) / max(cost, 1e-9)

    def should_stop(self, u_before, u_after, cost, n_used):
        if n_used >= self.required_samples():
            return True
        return self.marginal_gain(u_before, u_after, cost) < self.lam

    def reclaim_budget_ok(self, n_used, region_cells):
        need = region_cells * self.statistical_lower_bound()
        return n_used >= need


# IP-427 Active Acquisition Planner
class ActiveAcquisitionPlanner:
    def __init__(self, metc, scb, lidar, swept_index):
        self.metc = metc
        self.scb = scb
        self.lidar = lidar
        self.swept_index = swept_index

    def certificate_uncertainty(self, hpc):
        return hpc.hull_ci.volume() + hpc.unscanned_solid_angle

    def expected_gain(self, cell, hpc, obj, node):
        theta_touch = self.swept_index.count_theta(cell, node, obj)
        entropy = hpc.occupancy_entropy(cell)
        cost = self.lidar.cost(cell)        # 时间 + 能量 + 带宽
        return theta_touch * entropy / max(cost, 1e-9)

    def plan_next(self, hpc, obj, node):
        cells = self.candidate_cells(hpc)   # 未扫描 + 高不确定单元
        if not cells:
            return None
        best = max(cells, key=lambda c: self.expected_gain(c, hpc, obj, node))
        return AcquisitionAction(target_cell=best,
                                 dwell=self.lidar.dwell_for(best),
                                 revisit=self.lidar.revisit_for(best))

    def acquire(self, action):
        raw = self.lidar.scan(action)
        return [self.metc.analyze_ray(r, self.lidar.E0) for r in raw]

    def candidate_cells(self, hpc):
        # 未扫描单元默认占据，但仍是"证据增益"最高的候选
        return [c for c in hpc.cells if hpc.coverage(c) < 1.0
                or hpc.occupancy_entropy(c) > 0.1]


# IP-428 Hierarchical Acquisition Certificate
@dataclass
class HierarchicalAcquisitionCert:
    node: Node
    hull_certified: ConvexHull     # 认证安全域（保守模式）
    reclaim_set: ConvexHull        # 回收域（仅三签通过）
    tau_profile: dict              # ray_id -> tau_min
    budget_ledger: dict            # n_used / required / delta / epsilon
    acquisition_log: list          # 每条射线: action + returns + verdict
    merkle_root: str
    timestamp: float

    def safe_set(self):
        return self.hull_certified.union(self.reclaim_set)

    def reclaim_sound(self):
        return (self.budget_ledger["n_used"]
                >= self.budget_ledger["required"]
                and self.reclaim_set.volume() > 0)

    def audit(self, verifier):
        return verifier.recompute(self.acquisition_log,
                                  self.tau_profile,
                                  self.merkle_root)


# IP-429 Acquisition Freshness Controller
class AcquisitionFreshnessController:
    def __init__(self, aps, ttl_acq=1.0, rollback_hysteresis=0.02):
        self.aps = aps
        self.ttl_acq = ttl_acq
        self.rollback_hysteresis = rollback_hysteresis

    def freshness(self, hac, now):
        if now - hac.timestamp > self.ttl_acq:
            return "V20_FALLBACK"
        return "OK"

    def reconcile(self, hac, new_verdicts, plan):
        # 后续回波若推翻回收（出现占据），立即回滚回收域
        contradicted = [v for v in new_verdicts
                        if v.kind in ("OCCUPIED_SHELL", "OPAQUE_NEAR")]
        if contradicted and hac.reclaim_set.volume() > 0:
            hac.reclaim_set = ConvexHull.empty()
            return self.aps.apply_hysteresis(plan, self.rollback_hysteresis)
        return plan

    def integrate(self, plan, hac, now):
        if self.freshness(hac, now) == "V20_FALLBACK":
            return self.aps.activate_freshness_ladder(plan, force_mode="V20")
        return self.aps.update_plan_risk(plan, safe_set=hac.safe_set())
```

## 2. 推导

**引理 157（主动采集保守性）** 保守模式下，每条射线的占据是 `{OCCUPIED_SHELL, OPAQUE_NEAR, UNKNOWN→v20}` 的并集；新增样本只会加入新射线，占据集合关于样本数单调不减，故认证安全域单调不增：`Safe_{t+1} ⊆ Safe_t ⊆ Safe_0 = HPC_v20`。因此 `Exec_v21^cons ⊆ Exec_v20`。∎

**引理 158（回收可靠性）** 被回收的 θ 满足：其扫掠体 `V(θ)` 内每条射线均为 `OPEN_PAST`，且每个单元 `n_cell ≥ N_stat(δ,ε)`。由 Hoeffding/DKW，以概率 ≥ 1-ε，每个单元的经验自由比例与真实自由比例相差 ≤ δ。若 `V(θ)` 内存在间隙 ≥ δ 的真实障碍，则必落在某单元内并使其自由比例偏离 > δ，矛盾。故 `P(reclaim ⊆ TrueSafe) ≥ 1-ε`。∎

**引理 159（采样-证书下界）** 区分"自由"与"间隙 δ 的占据"在统计上至少需要 `Ω(log(1/ε)/δ²)` 个独立样本（Le Cam 下界）；AAP 的贪心熵下降在角度覆盖修正下达到 `O(log(1/ε)/δ² · log R)`，与下界同阶（差 log 因子）。由此得到停止律 `ΔU/Δcost < λ` 的理论依据。∎

**引理 160（多回波薄壁检测优势）** 对厚度 w、透射率 τ 的薄壁，单回波深度相机的深度歧义 ≥ 薄壁到背景的间距；LiDAR 在脉冲空间长度 `< 2w` 且角足迹小于障碍尺度时，只要 `τ ∈ (τ_thresh, 1-τ_thresh)` 即产生 `m ≥ 2` 个可分辨回波。故 METC 的薄壁召回率 ≥ `1 - P(脉冲重叠)`，在给定采样条件下严格优于单回波。∎

**引理 161（HAC 可审计性）** HAC 保存逐射线的采集动作、原始回波、判决与 τ_min，并以 Merkle 根封存；任何验证器可确定性地重算 τ_min 与占据、复核回收三签。故 HAC 可机械验证且可复现。∎

**引理 162（v21 安全继承）** `Exec_v21 = Exec_v21^cons ∪ Exec_v21^reclaim`。由引理 157，`Exec_v21^cons ⊆ Exec_v20`；由引理 158，`P(Exec_v21^reclaim ⊆ TrueSafe) ≥ 1-ε`。任何模块失效由 AFCtrl 强制 `mode_acq = V20_FALLBACK`，故不存在"既不在 v20 又无有效回收证书"的 θ。v21 在无有效回收证书时恒等于 v20，最坏情形不劣于 v20。∎

## 6. 已知风险与失效模式

1. **强度未标定导致 τ_min 失真**：不同材质反射率差异极大，若用统一 E0/σ，τ_min 可能系统性偏高。缓解：在线反射率标定、按材质分桶、保守取分位数。
2. **镜面/高反/雨雾的伪 OPEN_PAST**：镜面把能量反射出接收孔径，回波能量偏低 → 被误判为开放。缓解：多视角冗余、反射率异常检测、雨雾衰减模型。
3. **多回波合并**：脉冲宽度大于薄壁厚度时，双回波合并为单回波，薄壁被漏检。缓解：窄脉冲硬件、波形分解、与 v20 保守层叠加兜底。
4. **回收证书的分布假设失效**：射线空间相关（同一面墙）使独立同分布假设失效，N_stat 低估。缓解：有效样本数估计、块相关修正、按覆盖块计数。
5. **主动扫描的"越扫越盲"**：为降低证书不确定性而把扫描预算投向远离行进方向，造成行进方向盲区。缓解：安全方向硬约束、行进方向保底扫描。
6. **回滚振荡**：矛盾回波频繁出现导致回收-回滚抖动。缓解：滞回、证据累积、最小驻留时间。
7. **HAC 日志膨胀**：逐射线日志与 Merkle 树体积随采集时长增长。缓解：分段 Merkle、日志压缩、摘要上链。

## 7. 本轮最大风险

**一句话**：METC 的回收（证真）依赖"回波能量可解释"，一旦高反/镜面/雨雾/远距离把真实薄壁的弱回波压到噪声下并判成 `OPEN_PAST`，回收就会把 v20 本来正确排除的障碍重新授权为安全——即"主动扫描的证真误判"，而且这种误判会被 SCB 的统计置信"洗白"。
