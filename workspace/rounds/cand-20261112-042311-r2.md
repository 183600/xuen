# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「传感器融合」×「手势识别」）

> 第 57 轮把证据门做成五类，并把"人"从静态权重升级为单向有界的信任状态机；但它对"人"的建模仍有两个未写进假设的简化：**(a) 人的证据是无指称的标量确认**——一个"是/否"被当作与具体区域、具体待决动作无关的全局佐证，而真实的人机交互里，人最自然的输入是手势：指向"那边"、演示"这样走"、竖起拇指"可以"；手势是**带参考系、带时窗的时空测量**，不是命令。**(b) 人的证据是永久有效的**——第 57 轮的 𝓜 让证据长寿，却也让"三秒前的同意"与"三分钟前的同意"同权；而多传感器融合的真相是：不同模态有不同延迟、不同时钟、不同更新率，"同时观测"本身就是一个需要证书的近似。本轮两个灵感各补一条腿：**手势识别**把 EV-human 拆成"指称/演示/授权"三种不可互换的证据，并让连续识别具备拒绝与有意激活；**传感器融合**把人的参考系、指向射线、异步时延与运动传播都变成可估计、可审计的量。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"指称可落地、时窗可对齐、手势不越权的证据承诺"**——**你只能承诺一个新鲜的、已落地到具体指称、且类型权限允许的人的证据所支持的动作；人是传感器，不是神谕。**

核心矛盾：
- **H32（指称 vs 权威 / 手势通胀）**：指向给的是"哪里"，不是"可以"；演示给的是"怎么做"的先验，不是"可行"的证明；批准给的是"是否"，不是"何处"。把三者混同就是手势通胀——一个挥手既可能是打招呼、可能是"停"、也可能是跟踪器的一次误检。类型必须最小权限、不可提升。
- **H33（时窗 vs 证据长寿 / 异步对齐）**：证据在 𝓜 里长寿，人的意图却会过期；异步多率融合中"同时"是近似，指向移动区域的手势在决策时刻已指向别处。过期同意 + 运动 = 未经授权的承诺；未对齐的融合 = 把不同世界状态的观测拼在一起。
- **H34（人的参考系 vs 机器人地图 / 系统性偏差）**：指向是相对人的视角与心理地图的；左右手、视差、遮挡、视角差异会造成**高置信的系统性偏差**。必须边缘化人的参考系、用射线束而非单射线、用共形指称集而非 argmax，并让"手势-地图分歧"触发修复而不是承诺。
- **H35（连续识别 vs 有意激活 / Midas 触摸）**：连续手势流在无关动作中会产生假阳性（Midas touch）；识别器越灵敏，误激活越多。需要参与线索、运动学有意性、多模态一致与拒绝类，而不是"看到手在动就执行"。

## 0. 直觉与动机

**灵感 1（手势识别 → 手势是带时窗的指称测量）**
直觉：人不会用"是/否"和机器人说话，人会指、会示范、会摆手。一个手势不是符号，而是一段轨迹 + 一个分段 + 一个指称 + 一个意图。连续流里先要回答"这里到底有没有一个有意的手势"（spotting），再回答"它是什么意思"（classification），再回答"它指向哪里/演示了什么"（grounding），最后才是"它有没有权限"。把这四件事压成一个置信度，就是把"看见手在动"误当成"人下了命令"。

**灵感 2（传感器融合 → 人的参考系是待估状态，指称是射线束与地图的融合）**
直觉：人指向"那边"时，机器人听到的不是一个坐标，而是一条从人的手/眼出发、带有指向锥和骨架噪声的射线；这条射线要经过人的参考系 T_h^r 才能落到机器人地图上。T_h^r 不是已知的，它由共注册、骨架、注视估计，带协方差 Σ_h。把 Σ_h 与指向锥积分掉，得到的是**射线束**与一个**指称集合**，不是单个 argmax。若射线穿过地图上"不可达/不可通行"的区域，说明人的视角与机器人的地图分歧——这时该问，不该猜。移动场景还要把指称从手势时刻传播到决策时刻：运动不确定度会让指称集变大，大到超过阈值就重指。

**灵感 3（时窗 → 证据有半衰期，同意有保鲜期）**
直觉：第 57 轮让证据在 𝓜 里长寿，这对地形属性是对的（μ、k 不会一秒就变），但对人的同意是灾难（三秒前的"可以"不等于现在的"可以"）。给每类证据一个半衰期 h_x：同意/拒绝秒级、演示中、地形观测到访级且需再验证。承诺前做**时窗审计**：过期同意作废，过期地形证据触发再验证探针；因果上不能追溯批准已执行的动作。异步融合再加一张**对齐证书**：时间戳、延迟、时钟偏移、运动补偿误差，超过 Δ_max 的观测不得参与融合。

**灵感 4（合流 → 证据门从五类到七类，手势类型最小权限）**
直觉：EV-human 不再是一个类，而是三个不可互换的子类：**EV-deixis**（只回答 where，来自 POINT）、**EV-demo**（只给 trajectory prior，来自 DEMO）、**EV-human†**（只回答 whether，来自 APPROVE/DENY，且必须新鲜、绑定 decision_id、满足 auth 与佐证）。**STOP 是硬否决**，最高优先级、无需确认、永不被优化掉。不变式：**手势的证据类由类型决定，不由操作者置信度或系统需要决定；类型不可提升**。EV-deixis/EV-demo 永远不能进入不可逆接触的必要证据集——指称可以缩小搜索，演示可以给种子，但"可行"仍须探针/裕度证明，"授权"仍须新鲜且绑定的确认。

**灵感 5（GPCE → 指称先行、时窗审计、修复优先）**
直觉：第 57 轮 PCE+ 的检查点先做元推断与对账；本轮在它们之前插入两步：**指称解析**（有新鲜指称就把探针候选限制到 R_g；歧义/分歧超阈值就修复，修复失败就绕行/降档/安全停，绝不盲选）与**时窗审计**（过期同意丢弃、对齐证书检查、过期地形证据再验证）。手势的三个类型分别走三条不同的窄通道：POINT 只改"where"，DEMO 只改"how 的初值"，APPROVE 只改"whether"，STOP 直接否决。所有机制仍只经"信念更准（指称更窄/证据更新鲜）"或"动作更保守（修复/再验证/否决/安全停）"两个安全通道起作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（手势证据通道 GEC）** 操作者 o 的连续手势流 G={g_t}（骨架/深度/事件相机/IMU 手套等多模态）。手势事件 e_g=(I=[t_s,t_e], c, R_g, u_g, π_g, φ_g)：I 为分段区间（边界不确定 δ_seg）；c∈C={POINT,DEMO,APPROVE,DENY,STOP,OTHER}，后验 p(c|G)；R_g⊆2^V 为指称假设集（POINT/DEMO），共形覆盖 ≥1−α_g；u_g 为有意性分数（参与线索、保持时间、运动学、多模态一致）；π_g 为来源（模态/标定/模型版本/操作者）；φ_g 为新鲜度（定义 141）。接受条件：p(c)≥θ_c ∧ u_g≥θ_u ∧ 分段在扰动下稳定 ∧ 有意激活通过；否则记为 OTHER，不产生证据。个性化：每操作者手势词表与运动风格做共形校准，冷启动用群体先验并加宽 R_g；个性化只允许加宽 R_g 或提高 θ_u，永不放宽授权（定义 142）。

**定义 140（指称落地融合 DGF）** 人的参考系 T_h^r=(x_h,θ_h) 及协方差 Σ_h（由共注册/骨架/注视估计）。指向射线 r_h(t)、注视 g_h、场景语义 s 与机器人地图 𝓜。指称信念 b_v ∝ ∫ p(v|𝓜,T_h^r,r_h,g_h,s) N(T_h^r;T̂_h,Σ_h) dT_h^r；人的指向锥半角 κ_pt 与手眼/骨架误差使积分结果为**射线束**而非单射线。R_g(α_g)=使后验覆盖 ≥1−α_g 的最小区域集。**参考系歧义** A(r)=H(b_v)（或 |R_g|）；**手势-地图分歧** G(r)=min_{v∈R_g} d(v,𝓜_consistent(r))（射线穿过地图判为不可达/不可通行区域时分歧大）。A(r)>θ_A ∨ G(r)>θ_G ⇒ 指称修复（"您指的是 A 还是 B？"/请再指一次），不得 argmax 直接承诺。移动场景把 b_v 用人与机器人运动估计从 t_g 传播到决策时刻 t\*，运动不确定度进入协方差；传播后 R_g 超阈值 ⇒ 重指或降级。

**定义 141（时序证据融合 TEF）** 证据 x 带有效窗口 [t_x,t_x+h_x]，半衰期 h_x 按类型（同意/拒绝秒级、演示中、地形观测到访级且需再验证）。新鲜度 φ(x,t)=exp(−(t−t_x)/h_x)（或硬窗）；承诺要求所有支撑证据 φ≥φ_min。异步多率融合：观测 z_i 的时间戳 t_i、延迟 ℓ_i、协方差 Σ_i，有效时刻 t_i^eff=t_i+ℓ_i；对齐证书 Δ=max_i|t_i^eff−t\*|，运动补偿误差 ε_mot=J_vΣ_vJ_vᵀΔ² 加入 Σ_i^eff；要求 Δ≤Δ_max ∧ 时钟偏移有界，否则不得参与融合（只能以加宽协方差单独使用）。**因果一致**：证据必须在决策前观测到，不能追溯批准已执行动作；过期同意自动作废；过期地形证据触发再验证探针而非直接丢弃。

**定义 142（手势权限格 GAL / 最小权限）** 类型能力域 scope(c)：POINT→locative（只提出候选区域/探针位置）；DEMO→trajectory prior（只给轨迹/落脚先验，不作可行性证明或授权）；APPROVE/DENY→authorization（只对绑定 decision_id 的待决动作、在有效窗口内生效）；STOP→veto（最高优先级硬否决，无需确认，永不被优化掉）。不变式：手势证据类由类型决定，不由操作者置信度或系统需要决定；类型不可提升（no inflation）；任何手势不得越过 PTM 的 auth 上界（承 57 单向有界）；个性化只加宽指称集/提高有意性阈值，不放宽 scope。EV-deixis/EV-demo 永不进入不可逆接触必要证据集；只有新鲜、绑定 decision_id 的 EV-human† 可作佐证。

**定义 143（手势证据门 GEG，证据门七类）** 证据类：EV-probe\*（承 57：元校准+共形）、EV-visit、EV-margin、EV-xmodal（限 L1）、EV-human†（新鲜 φ≥φ_min ∧ 绑定 decision_id ∧ auth≥A1 ∧ 佐证≥corrob\*(auth)）、EV-deixis（仅 locative，来自 POINT，R_g 覆盖 ≥1−α_g，A≤θ_A，G≤θ_G）、EV-demo（仅 trajectory prior，来自 DEMO，物理可行性仍须 EV-probe\*/margin 证明）。不可逆接触必要证据集={EV-probe\*∨EV-margin}∪新鲜 EV-human†；EV-deixis/EV-demo 可缩小搜索/种子但不计为必要证据。证书 J_g=(M_core,C_core,K_margin,ρ_sem,δ_s,probe_log,consent_log,evidence,meta_cal_log,xmodal_log,auth_log,ood_registry,gesture_log,referent_sets,frame_cov,alignment_cert,freshness_log,repair_log,scope_log)，继承 J_p 全检。

**定义 144（指称-时窗探诺演 GPCE / PCE+++）** 每检查点：①元推断（承 57：ID→摊销后验/OOD→共形带）；②**指称解析**：若有新鲜 EV-deixis，探针候选限制到 R_g；A(r)>θ_A ∨ G(r)>θ_G ⇒ 指称修复（L0/L1，最多 k_repair 轮），修复失败 ⇒ 绕行/降档/安全停，不得盲选；③**时窗审计**：丢弃过期同意、检查对齐证书与因果一致，过期地形证据触发再验证探针（预算 k_reval）；④**类型域证据门**：POINT 只选 where、DEMO 只种子 how、APPROVE 只授权 whether（绑定 decision_id 且新鲜）、STOP 立即否决；⑤承诺 ⇔ ∃g:R≤δ_f(g) ∧ 七类证据门过 ∧ 所有支撑证据新鲜 ∧ 指称歧义/分歧在阈值内；否则 argmax_π[VOI_元悲观(π)−cost(π)]≥θ_voi；⑥探尽→绕行→降档→L2（τ_int(auth)）或安全停；STOP 任何时候直接安全停。

## 2. 关键算法伪代码（完整版见产物区）

```python
def gesture_evidence(stream, op, ctx):              # IP-139: spotting + 共形指称
    evs = []
    for seg in spot(stream, reject=True):
        if not stable_under_perturb(seg): continue
        c, p = classify(seg, op.vocab)
        u = deliberate(seg, ctx.engagement, ctx.gaze, ctx.imu)
        if p[c] < theta_c or u < theta_u: continue  # Midas 防御
        R = conformal_referent(seg, ctx, alpha_g)
        evs.append(GestureEvent(seg.I, c, R, u, prov(seg), seg.t_end))
    return evs

def deictic_ground(M, ev, frame, gaze, scene, t_star):   # IP-140: 射线束 + 传播
    b = posterior_regions(M, frame.T, frame.Sigma, ev.ray_bundle(kappa_pt), gaze, scene)
    b = motion_propagate(b, ev.t_end, t_star, M, frame)
    R = smallest_cover(b, alpha_g)
    A, G = entropy(b), min_dist_to_inconsistent(R, M)
    return Repair(R, A, G) if A > theta_A or G > theta_G else Grounded(R, b, A, G)

def freshness_audit(evidence, t_now, clocks):      # IP-141: 时窗 + 对齐
    fresh, expired, reval = [], [], []
    for x in evidence:
        if x.t_obs > t_now: return Violation('causal')
        if not alignment_ok(x, t_now, clocks): x = widen_for_skew(x)
        (expired if freshness(x, t_now) < phi_min else fresh).append(x)
        if x in expired and x.kind == 'terrain': reval.append(x.region)
    return fresh, expired, reval

def gesture_authority_gate(ev, decision, persona):  # IP-142: 最小权限
    s = scope(ev.c)
    if s == 'veto':       return ('veto', ev)
    if s == 'locative':   return ('locative_only', ev.R)
    if s == 'trajectory': return ('trajectory_prior_only', ev.traj)
    if s == 'authorization':
        ok = ev.decision_id == decision.id and fresh(ev) \
             and persona.auth >= 'A1' and ev.corrob >= corrob_star(persona.auth)
        return ('authorize', ev) if ok else ('reject', 'stale_or_unbound')
    return ('reject', 'unknown_type')
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| GEC | O(T·d_g)/流窗口；O(\|C\|) 分类；共形 O(N_cal) | O(\|E\|·d_g) | 分段稳定、有意激活误报 ≤δ_midas、R_g 覆盖 ≥1−α_g |
| DGF | O(N_mc·\|V\|)（参考系边缘化）；空间索引可降 | O(\|V\|) | Σ_h 诚实、射线束保守、分歧触发修复 |
| TEF | O(\|E\| log\|E\|)/审计 | O(\|E\|) | 新鲜度/对齐/因果诚实（A47） |
| GAL | O(1)/事件 | O(1) | 类型域固定、不可提升、STOP 硬否决 |
| GEG | O(\|σ\|) | O(\|σ\|) | 七类证据、无越权替换、必要集不含手势指称 |
| GPCE | O(\|CP\|·(k_p+k_c+k_repair+k_reval)·(C_VOI+d_g)) | O(\|V\|+\|σ\|) | 指称先行、时窗审计、五态终止 |

**正确性定理（Grounded-Temporal Gesture Soundness, GTGS 概要）**：在 A33–A40 上加 **(A45)** 手势 spotting/分类校准、分段稳定、R_g 共形覆盖 ≥1−α_g、有意激活误报 ≤δ_midas；**(A46)** 人参考系 T̂_h 误差有界且 Σ_h 诚实、射线束边缘化保守、手势-地图分歧触发修复、运动传播诚实；**(A47)** 新鲜度/时延/时钟偏移诚实，对齐证书有效，过期证据不计入承诺，因果一致；**(A48)** 手势类型最小权限、不可提升、STOP 硬否决、个性化不放宽 scope。则：(i) P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_g+δ_frame+δ_fresh+δ_midas+δ_xm·1[L1]；(ii) 交互单调性：手势机制只能经"指称更窄/证据更新鲜"或"动作更保守（修复/再验证/否决/安全停）"影响系统，不存在升险路径；(iii) GPCE 在 k_probes+k_cons+k_repair+k_reval 内终止于 {承诺,绕行,L2 协商,安全停,否决}。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是系统会倾向于相信一个流畅、及时、看似明确的手势，而手势的指称偏差（参考系/运动传播）与连续识别误激活（Midas）恰恰是"高置信地错"——若修复回路在节拍压力下被跳过，或指称被悄悄当成授权，安全就会从"证据不足"退化为"证据很自然地指向了错误的地方"；必须以最小权限手势类型、共形指称集、新鲜度硬窗与修复优先四重护栏，宁可不动作，也不接受一个未被落地、已经过期或越权的手势。

### IP-140 DGF（指称落地：参考系边缘化 + 射线束 + 运动传播 + 修复）

```python
def deictic_ground(M, ev, frame, gaze, scene, t_star):
    if ev.c != 'POINT': return None
    b = zeros(len(M.regions))
    for T in sample(frame.T_hat, frame.Sigma, n=N_mc):  # 边缘化人的参考系
        ray = ev.ray(T, kappa=kappa_pt)                # 指向锥 -> 射线束
        b += likelihood(M.regions, ray, gaze, scene) / N_mc
    b = motion_propagate(b, ev.t_end, t_star, M, frame)  # 从手势时刻到决策时刻
    R = smallest_cover(b, alpha_g)                     # 共形指称集
    A = entropy(b)                                     # 参考系/指称歧义
    G = min_dist_to_inconsistent(R, M)                 # 与地图不可达区冲突
    if A > theta_A or G > theta_G:
        return Repair(referents=top_k(b, 2), A=A, G=G)  # 问，不猜
    return Grounded(R=R, b=b, A=A, G=G)

def motion_propagate(b, t_g, t_star, M, frame):
    dt = t_star - t_g
    v, Sv = relative_motion(M, frame, t_g, t_star)
    return propagate(b, v * dt, Jv @ Sv @ Jv.T * dt * dt)  # 不确定度入协方差
```

### IP-141 TEF（时序证据融合：半衰期 + 对齐证书 + 因果一致 + 再验证）

```python
def freshness_audit(evidence, t_now, clocks):
    fresh, expired, reval = [], [], []
    for x in evidence:
        if x.t_obs > t_now:                            # 因果一致
            return Violation('causal', x)
        if not alignment_ok(x, t_now, clocks):         # 时钟/延迟/运动补偿
            x = widen_for_skew(x, delta=align_delta(x, t_now),
                               eps_mot=motion_err(x, t_now))
        if freshness(x, t_now) < phi_min(x.kind):
            expired.append(x)
            if x.kind == 'terrain': reval.append(x.region)
        else:
            fresh.append(x)
    return fresh, expired, reval

def freshness(x, t):
    return exp(-(t - x.t_obs) / h[x.kind])            # 同意秒级/地形到访级

def alignment_ok(x, t_now, clocks):
    d = abs(x.t_obs + x.latency - t_now)
    return d <= Delta_max and abs(clocks.skew(x.sensor)) <= skew_max
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |

**正确性定理（Grounded-Temporal Gesture Soundness, GTGS）**
假设 A22–A32（第 53–55 轮）、A33–A44（第 56–57 轮）成立；**(A45)** 手势 spotting/分类校准、分段在扰动下稳定、R_g 共形覆盖 ≥1−α_g、有意激活误报率 ≤δ_midas；**(A46)** 人参考系 T̂_h 误差有界且 Σ_h 诚实、射线束边缘化保守、手势-地图分歧触发修复、运动传播不确定度诚实；**(A47)** 新鲜度/时延/时钟偏移诚实、对齐证书有效、过期证据不计入承诺、因果一致；**(A48)** 手势类型最小权限、类型不可提升、STOP 硬否决、个性化不放宽 scope。则：

1. **指称-时窗承诺健全性**：P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h(w_max) + δ_g + δ_frame + δ_fresh + δ_midas + δ_xm·1[L1]。
2. **交互单调性强化**：手势/时窗机制只能经 (a) 指称更窄、证据更新鲜的信念更新，或 (b) 更保守的动作参数（修复、再验证、重指、否决、安全停、指称集加宽）影响系统，不存在升险路径；个性化只加宽 R_g/提高 θ_u，不放宽授权。
3. **终止性**：每检查点修复 ≤k_repair、再验证 ≤k_reval，GPCE 在 k_probes+k_cons+k_repair+k_reval 内终止于 {承诺, 绕行, L2 协商, 安全停, 否决}。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_g + δ_frame
                   + δ_fresh + δ_midas + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(参考系估计失效 ∧ 修复超时) − P(时钟偏移漏检 ∧ 对齐误判)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**指称给方向、共形给保守**（不把 argmax 当指称）；**时窗给新鲜、对齐给诚实**（不把三秒前的同意当现在）；**权限格给边界、STOP 给底线**（不把指称/演示偷换成授权）；三个新机制仍全部经"信念更准或动作更保守"两个安全通道起作用。

其中新增：`gesture_log` 手势事件与拒绝；`R_g` 共形指称集；`Σ_h` 人参考系协方差；`φ` 新鲜度；`Δ_t` 对齐证书；`scope(g)` 手势类型权限；`repair_log` 指称修复记录；`J_g` 手势-时窗-权限证书。

云边协议 CEB++ → **CEB+++**：云端可下发手势模型与词表增量，但**手势模型更新同样走隔离区**——先以影子模式在边端手势流上运行，回归测试（误激活率不升 ∧ 指称覆盖不降 ∧ 越权替换为 0 ∧ STOP 召回 100%）通过后才接管；边端回传指称修复样本、参考系残差与过期/再验证事件，作为云端手势补盲与个人化校准集；原始视频不出端，只回传匿名骨架与统计量。第 57 轮"一切判定器走隔离"在本轮推广为"**一切人类输入走指称-时窗-权限三重门**"。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是系统会倾向于相信一个流畅、及时、看似明确的手势，而手势的指称偏差（参考系/运动传播）与连续识别误激活（Midas）恰恰是"高置信地错"——若修复回路在节拍压力下被跳过，或指称被悄悄当成授权，安全就会从"证据不足"退化为"证据很自然地指向了错误的地方"；必须以最小权限手势类型、共形指称集、新鲜度硬窗与修复优先四重护栏，宁可不动作，也不接受一个未被落地、已经过期或越权的手势。
