## 1. 两个灵感的第一性原理

### 灵感 1 ·「三维感知」→ 从「带协方差的点」升级到「带各向异性协方差的刚体 + 占据空间」

- **2.5D 的隐藏缺陷**：第 3 轮 U16/U17 的协方差实际接近标量（各向同性），但视觉深度不确定度天然是**锥形**——沿光线方向 σ_d 远大于切向 σ_t。固定欧氏阈值在各向异性下必然次优：切向误拒偏高、深度误拒偏低（L16）。三维感知让 U17 第一次真正吃到「完整 Σ」。
- **点是假象、刚体才是对象**：操作需要 6-DoF 位姿而非 3-DoF 点。对称物体（盒/杯/圆柱）使位姿**多模态**——单一高斯失效，位姿应建模为混合分布 {w_k, x_k, Σ_k}；卡方断言要在「最近合法模态」上计算，这是对第 3 轮 U17 的严格修正。
- **占据与物理一致性**：点云 → TSDF 占据 + 表面法向 + 支撑关系；路标第一次能做碰撞/净空检查（IP-05），抓取候选第一次能在**真实表面**做对跖采样（IP-14），而不是在外观框里猜。
- **一句话**：三维感知把状态层从「目标在哪」升级为「目标是什么形状、占多少空间、能不能放得下」。

### 灵感 2 ·「触觉感知」→ 没有触觉传感器的触觉：残差即触觉

- **接口硬约束**：官方观测只有头/腕 RGB + EE 位姿 + 夹爪标量，没有力/触觉阵列。触觉无法「接入」，只能从已有信号**重构**；因此本轮不新增任何硬件假设。
- **第一性原理**：触觉是唯一直接测接触的通道，而视觉恰在接触点最差（遮挡、透视）。没有传感器时，接触信息藏在**动作-观测残差**里：命令夹爪闭合而宽度停在 w*（plateau）、命令 EE 前进而观测速度塌陷、命令手腕下压而物体区域相对手静止——这些残差就是触觉（U20）。
- **两个用途**：①接触检测/确认（补 IP-02 抓握确认、IP-15 的 contact 类）；②**接触因子**沿法向回灌三维位姿。关键互补性：**视觉最不确定的方向（沿光线/法向）恰好是接触约束最强的方向**（L14）——融合不是锦上添花，而是把病态信息矩阵变成良态。
- **主动触觉**：第 3 轮 P12/L13 的「探测换信息」有了触觉解释——一次轻触的法向信息量远高于视觉；insert/release 相位接触探测的盈亏平衡概率最低（与 L13 合账）。
- **柔顺**：可信接触后切换到阻抗/让步小步控制（probe-and-yield），把「最后一厘米」从位置伺服升级为**接触伺服**。
- **一句话**：触觉不是新传感器，而是「预测误差」这一被浪费掉的信号。

### 灵感 3（隐含第三灵感）·「接触密集语料」→ Dex1 110 项是触觉线的免费标注源

- Dex1 的 110 个任务里 Insert / Install / Thread / Assemble / Fold 占大头 → 全部接触密集；用「残差 + 夹爪标量」做 contact-event 半自动标注，零额外采集成本。

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（三维标定）**：仅 RGB（或无标定深度）时，head+wrist 多视图 + EE 位姿锚定能否给出可校准的 6-DoF 各向异性协方差，使 U17 卡方覆盖 ∈[α/2,2α]、对称物体模态正确率 ≥90%？（E634）
- **Q14（伪触觉可检测性）**：夹爪 plateau + 动作-观测残差对刚性/柔性接触的检测 ROC 与力代理误差？软物体与 latency 下的虚警率？（E635）
- **Q15（互补与柔顺收益）**：接触因子沿法向的不确定度缩减是否 ≥20%（L14）？由此带来的插入/运输挽回是否在 P12 步数预算内为正？（E636/E637）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（接触即真值）**：一旦接触被可信检测（过 L15 信噪门槛），接触几何约束优先于视觉；必须把接触因子回灌位姿。无力传感器时以残差代理，但残差必须过门槛，否则退化为「仅视觉」。
- **P14（三维优先、2.5D 兜底）**：感知栈优先三维；深度/多视图标定未过 E634 时，退化为第 3 轮 2.5D U17（含各向同性退化），不得静默使用未校准三维；触觉不可信时退化为日志器（Level-1.7）。
- **P15（零新增硬件假设 / 合规）**：不假设触觉传感器、不假设深度通道；一切能力只用官方观测接口可达信号（头/腕 RGB、EE 位姿、夹爪标量）。这条同时是合规边界与工程护城河。

## 4. 清单处置（深化 / 修剪 / 新增）

## 5. 本轮最大风险

**残差混淆 × 深度错标（伪触觉与三维协方差的联合失效）**：伪触觉把「模型误差 / 控制延迟 / 摩擦」与「真实接触」混为一谈——虚警会在未接触时提前柔顺（漏抓），漏检会在已接触时继续硬推（压坏/卡死）；同时，单目/多视图的尺度偏差会让三维 Σ 名义上「各向异性且漂亮」但实际错标，L14 的互补性主张随之静默失效。二者叠加会制造最坏的失败模式：系统在最需要确定的接触时刻「自信地错」。对冲：①接触判定必须过 L15 信噪门槛 + 三态滞回，样本不足时只记日志；②三维 Σ 用 held-out 覆盖检验（E634），未过则按 P14 退回 2.5D；③接触因子只在「多帧一致 + 夹爪 plateau + 低速」三条件同时满足时回灌。次要风险：Dex1 与 32 项挑战任务的域差 → 只做接触事件迁移而非策略迁移。**一句话：本轮最大风险是「把控制残差误当触觉、把未校准的三维协方差当真值」，二者联合会让接触时刻的决策以最高置信度出错。**

## 6. 下一轮迭代计划（深化与修剪，不推倒重来）

- **深化**：IP-16 的对称多假设与混合分布下的卡方修正（L14 在混合先验上的失效点）；IP-17 的软物体检测与力代理标定；Dex1 contact-event 标注管线先过「标注一致性」前置门槛，再谈 E635/E637。
- **修剪预案**：E634 覆盖检验失败 → 三维仅用于重定位，断言退回 2.5D；E635 接触 AUROC <0.75 或虚警 >5% → IP-17 仅日志；E636 沿法向缩减 <20% → 放弃融合主张、三维与触觉各自独立；E637 无增益 → 柔顺仅用于刚性接触子集。
- **待外部事件**：榜单开放日 48 h 内 F2 复核（并复核任务级口径 F6）；规则手册可读版关闭 Q3/Q4/Q9/Q12，并新增确认 Q13 是否允许外部深度/力传感（预期不允许 → P15 生效）。

## 3. 新增 IP 详述

### IP-16 · MetricScene3D 三维场景状态（P1，新；IP-13 的 3D 模式）

- **动机**：v3 的协方差近似各向同性，而视觉深度是锥形不确定度（σ_d ≫ σ_t），固定欧氏阈值在各向异性下必然次优（L16）；对称物体的位姿是多模态而非单高斯；操作更需要形状、占据与净空，而不只是一个点。
- **与现有方案差异**：teaser 榜（待复核假设）与主流端到端 VLA 都是「观测→动作」单通路，无显式三维状态、无 6-DoF 不确定性、无碰撞净空；本方案把这些全放在策略内部（合规安全），组件全部现成件（多视图三角/单目深度 + 位姿混合 + TSDF + 信息滤波），无新模型。
- **技术可行性**：中高。难点在无深度时的尺度锚定与对称多假设；用 EE 位姿提供米制尺度、head+wrist 多视图三角、对称检测生成多假设。训练量近零。
- **资源**：数据=IP-06 的 32 集阶段标注（位姿/净空验证）+ Dex1 接触片段；算力=小（低频 + 事件触发）。
- **落地步骤**：①深度前端（深度直用 / 单目+多视图，EE 位姿锚定尺度）；②位姿混合拟合（多假设 + 各向异性 Σ，对称物体枚举模态）；③TSDF 占据与表面法向；④U17 改为「完整 Σ + 最近合法模态」卡方（E634）；⑤净空/碰撞检查接入 IP-09 路标与 IP-05；⑥表面几何对跖抓取候选交给 IP-14。
- **风险**：单目尺度偏差 → Σ 错标（E634 覆盖检验前置）；对称模态误选 → 绑定错误复现（多帧一致 + 接触确认兜底）；延迟（低频 + 事件触发，E633 沿用）。

### IP-17 · PseudoTactile ContactGuard 伪触觉接触层（P1，新）

- **动机**：观测无力/触觉传感，而「最后一厘米」的失败（插入、旋拧、卡扣、塞入）本质是接触问题。触觉的唯一可得代理是**动作-观测残差**：夹爪宽度 plateau、EE 速度塌陷、手腕视角物体相对手静止。
- **与现有方案差异**：不训接触分类大模型——接触检测器是残差阈值 + 三态滞回（规则级），接触因子是法向单边约束（信息滤波），柔顺是夹爪阻抗/让步小步；与 IP-16 共享位姿与 TSDF。别人没有力传感器就放弃接触推理，本方案把「预测误差」变成免费的触觉。
- **技术可行性**：中高。刚性接触（plateau 明显）可靠；软体/可压缩物体 plateau 弱，需保守化（L15）。Dex1 提供半自动 contact-event 标注。
- **资源**：Dex1 110 项（接触片段裁剪 + 残差标注）；算力=小（每步轻量）。
- **落地步骤**：①残差定义（宽度/速度/腕部光流）与自由空间 99 分位阈值；②三态 {free, contact, slip} + jam 的滞回状态机；③可信接触 → 接触因子回灌 IP-16 位姿（P13）；④柔顺原语（probe-and-yield）接入 IP-02 介入家族；⑤多模态滑移（视觉光流 + 夹爪微分）升级 IP-14 的 SlipGuard；⑥接触探测按 L13×L15 记账后仅在 insert/release 相位启用。
- **风险**：残差混淆（延迟/摩擦/模型误差 → 虚警，控制残差被误当接触）；软体漏检（保守化：只在刚性/多帧一致时入闭环）；Dex1 与挑战任务域差（只迁移接触事件，不迁移策略）。

### §3.3 IP-16 ↔ IP-17 接口：接触因子（本轮的理论核心）

接触不只是「一个事件」，而是**一条几何约束**：接触点 k 处沿法向 n_k 的单边约束 `n_kᵀ(x − s_k) = 0`（s_k 为表面点），配摩擦锥。它给位姿估计增加秩 1 信息 `J_c = Σ_k σ_c^{-2} n_k n_kᵀ`。把它并入 IP-16 的信息滤波后，沿视觉最弱方向（光线/法向）的后验方差被打下去（L14）——这就是「三维感知」与「触觉感知」两个灵感词的真正交点：**不是两件独立的事，而是一次互补的信息融合**。

- **定义 U20（接触残差 / 伪触觉信号）**：`r_t = m_t − m̂_t^free`，`m = (夹爪宽度, 夹爪电流代理, EE 速度, 腕部物体区域运动)`，`m̂^free` 为自由空间模型预测。接触指示 `c_t = 1[ d'(r_t) > τ ]` 要求过 L15 信噪门槛 + 多帧一致；滑移指示由「宽度微分 > 0 且物体区域光流 > 0」融合得到。

```python
class MetricScene3D:
    def __init__(self):
        self.pts, self.tsdf = None, None
        self.poses = []                       # [{w, x(6), Sigma(6x6 anisotropic)}]

    def depth_frontend(self, obs):
        if obs.depth is not None:             # 有深度：直用
            return obs.depth
        return multiview_triangulate(obs.head, obs.wrist, obs.ee_pose)  # 无深度：多视图 + EE 尺度

    def update(self, obs, state2d, force=False):
        if not (force or self.due()): return self.poses
        d = self.depth_frontend(obs)
        self.pts = fuse(self.pts, d, obs.ee_pose)       # EE 位姿锚定米制尺度
        self.tsdf = integrate(self.tsdf, self.pts)
        self.poses = pose_mixture(self.pts, state2d.target)  # 对称 → 多假设
        return self.poses

    def clearance(self, wp):
        return self.tsdf.check(wp.pose, wp.radius)      # 净空/碰撞
```

```python
# ===== U21: 接触因子回灌（信息滤波；单边约束用 active-set）=====
def fuse_contact(pose_mix, contacts):
    for p in pose_mix:                                  # 每个模态各自吸收同一接触
        J = np.linalg.inv(p.Sigma)
        for c in contacts:                              # c: (n, s, sigma_c)
            J = J + np.outer(c.n, c.n) / c.sigma_c**2
        p.Sigma = np.linalg.inv(J)
        p.x = project_along_normals(p.x, contacts)      # 平滑近似单边约束
    return renormalize(pose_mix)
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（视觉—接触信息互补性）** 设位置估计 `x∈R³`（6-DoF 平滑推广），视觉信息矩阵 `J_v = R_vᵀ diag(σ_t⁻², σ_t⁻², σ_d⁻²) R_v`，`R_v` 把光线方向 `u` 旋到第三轴，且 `σ_d ≫ σ_t`，故 `Σ_v` 最大方差方向为 `u`。一次接触在法向 `n` 施加单边约束 `nᵀ(x−s)=0`，信息贡献 `J_c = σ_c⁻² n nᵀ`（秩 1；摩擦锥只给切向有界约束，不给切向位置信息）。融合信息 `J = J_v + Σ_k J_c`、`Σ = J⁻¹`。在 `n·u ≠ 0` 时，沿 `u` 的后验方差 `σ_{d|n}² = (σ_d⁻² + (n·u)²σ_c⁻²)⁻¹ < σ_d²`——接触沿视觉最弱方向降低不确定度；反之单次接触秩 1，切向仍依赖视觉，故**两者不可互相替代**。多次非共面接触使 `Σ_k n_k n_kᵀ` 张成切向，`J` 全秩。∎（注：`n⊥u` 的侧向接触无此互补；顶抓 `n≈−u` 最强；对称物体需对每个模态分别融合。）

**引理 L15（伪触觉接触检测的信噪比）** 设自由空间模型预测夹爪宽度 `m̂_t^free`，实测 `m_t`，残差 `r_t = m_t − m̂_t^free`。无接触时 `r_t ~ N(0, σ_m²)`（含模型/延迟误差）；刚性接触时夹爪停在 `w*`，命令仍以速率 `v_c` 闭合，则接触后 `|r_t| ≈ v_c·Δt`（Δt 为接触后时长）。取阈值 `τ = σ_m Φ⁻¹(1−α_fa)`，检测功效 `d' = (v_c Δt)/σ_m`，当 `Δt > σ_m Φ⁻¹(1−α_fa)/v_c` 时可检。柔性/可压缩物体夹爪持续压缩，plateau 幅度小、有效 `v_c` 小 → `d'` 低。⇒ **伪触觉对刚性接触可靠、对软体弱**；latency 抬高 `σ_m`，必须用保守阈值（E635 直接验此门槛）。∎

**引理 L16（各向异性下固定阈值断言的次优性）** 设 `Σ = diag(σ_t², σ_t², σ_d²)`、`σ_d > σ_t`。固定欧氏阈值 `‖x̂−g‖ ≤ ε` 的接受域为球；为令总误拒 = α 选定 ε 后，切向单方向误拒 `P(|x̂_t−g_t|>ε)` 与深度方向 `P(|x̂_d−g_d|>ε)` 之比随 `(σ_d/σ_t)` 指数失衡（球在扁平 Σ 下切向过宽、深度过窄），**无法同时把每个方向校准到 α**。Mahalanobis `d² = (x̂−g)ᵀΣ⁻¹(x̂−g)` 对各方向标准化，per-direction 误拒均为 α。⇒ 各向异性下固定阈值必然次优，U17 必须吃完整 Σ；若 Σ 本身错标（单目尺度偏差），则虚拒与虚受同时放大。∎
