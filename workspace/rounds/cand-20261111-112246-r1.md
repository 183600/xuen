# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感驱动循环第 1 轮；本轮灵感：「触觉感知」×「真机评测」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书（ACS/SCOM/CEC/AEC/JTC），但仍有两个未言明的假设：**接触被折叠成"动作是否成功"**、**证书证据默认来自仿真**。本轮用 **触觉感知** 与 **真机评测** 拆开这两个假设。核心矛盾：H24：动作剖面 `α_S(a)` 只说明动作可达/被占用，不说明**接触能否建立并维持**；接触丰富任务的失败集中在 stick→slip、impact、edge 等**接触模式迁移**上，而这些在动作空间中几乎不可见。H25：证书的 `evidence` 主要来自仿真，而触觉恰是仿真最不可靠的模态；真机评测又昂贵、且"看结果决定是否继续"的**可选停止偏差**会让点估计系统性乐观，使仿真证书在真实接触处失效。

## 0. 直觉与动机

**灵感 1（触觉感知 → 从动作占用到接触占用剖面）**
直觉：能到达一个动作，不等于能在这个动作上"握住"接触。把动作剖面 `α_S` 扩展为 **接触占用剖面 `β_S(a,m)`**，其中 `m` 是触觉接触模式（stick / slip / impact / edge / free）。`β_S(a,slip)=0.9` 的技能在"需要稳定夹持"的任务上必须被否决，即便 `α_S(a)=1`。这样，**接触模式成为技能组合的第一性可观测量**，与第 54 轮的动作空间约束并列。

**灵感 2（接触条件化鲁棒性与接触可辨识缺口 C-gap）**
直觉：接触一旦迁移，鲁棒性谱会突变。证书必须在接触模式的 `δ_m` 邻域内取最坏情况：`ρ(d|m,b)=inf_{m'∈B_{δ_m}(m)} ρ(d|m',b)`。更关键的是，某些模式在有限触觉分辨率下**不可区分**（如初滑 incipient slip 与静摩擦），此时不是"低置信"，而是**不可声明**：定义 **接触可辨识缺口 `C-gap`**，与第 54 轮的可观测性缺口 `O-gap` 同构，但观测对象是接触而非位姿。任务若必须经过 `C-gap` 模式，证书直接为 `⊥`。

**灵感 3（真机评测 → 随时有效证书，而非排行榜）**
直觉：真机评测的本质是**证据采集**，不是刷分。如果每采一个样本就判断是否达标并随时停止，经典置信区间失效（可选停止偏差）。用 **e-process / confidence sequence** 给出随时间一致的置信下界 `p^L_t`，使得对任意停止时刻 `t` 都有 `P(p ≥ p^L_t) ≥ 1-α`。于是部署保证由真机样本签署，允许"达到就停"，且不会因为多看几眼而虚高。

**灵感 4（触觉鸿沟 → 证据折扣与支持集检验）**
直觉：触觉仿真与真机的差异 `Δ_tac` 是可测的。若真实接触落在仿真支持集之外（`μ_supp>0`），则仿真证据**没有外推资格**：它只能用于主动选点，不能进入最终保证。给每条证据打 **provenance 标签**（sim / real / mixed），并用有界密度比 `w≤w_max` 限定重要性加权，避免"仿真里全对"冒充"真机可部署"。

**灵感 5（主动证伪评测 → 用最少真机预算找接触反例）**
直觉：真机预算有限，评测应是**主动证伪**：优先选择能最大化证书信息量、或最可能产生 **contact witness**（未被仿真覆盖的真实接触）的试验。找到反例就触发第 54 轮的反向解释信道，回传云端重剖分接触-动作剖面。真机评测从此是"找反例的闭环"，而不是"跑完取平均"。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（触觉观测与接触占用剖面）**
触觉观测 `z_t∈Z`（触觉图像 / 六维力扭），接触模式 `m_t=φ(z_t)∈M`，`M={free,stick,slip,impact,edge}`。技能 `S` 的 **接触占用剖面** `β_S:A×M→[0,1]`，`Σ_m β_S(a,m)=1`；支撑集 `supp_β(S,a)={m | β_S(a,m)≥θ_m}`。任务在动作 `a` 要求模式集 `M_T(a)`，**接触覆盖** `cover_c(S,A_T)=1` 当且仅当 `∀a∈A_T, M_T(a)⊆supp_β(S,a)`。

**定义 128（接触条件化鲁棒性与接触可辨识缺口）**
接触条件化鲁棒性
`ρ(d|m,b)=inf_{x∈B_ε(x̂)} inf_{m'∈M: dist_M(m',m)≤δ_m} ρ(d|x,m')`。
**C-gap**：`C-gap(S,M_T)={m∈M_T | ¬distinguishable(φ,m;δ_res)}`，即在触觉分辨率 `δ_res` 下不可分的必需模式。证书成立当且仅当
```
cover_c(S,A_T)=1 ∧ C-gap(S,M_T)=∅ ∧ min_{d,m∈M_T} ρ(d|m,b) ≥ ρ_min(d)
```

**定义 129（仿真-真机触觉鸿沟与证据支持）**
对匹配的 `(s,a)`，`Δ_tac(a)=W_1(P_real(z|s,a), P_sim(z|s,a))`，支持集失配率 `μ_supp(a)=P_real(z∉supp(P_sim))`。密度比 `w(z)=p_real(z)/p_sim(z)≤w_max`（重叠区）。仿真证据**可采信**当且仅当 `Δ_tac≤Θ_tac ∧ μ_supp≤μ_max`；否则 `provenance=prior_only`，只能用于主动选点。

**定义 130（随时有效真机证书）**
真机试验 `X_i∈{0,1}` 表征任务成功，`p=P(X=1)`。**e-process** `E_t` 满足 `H_0:p≤p_req` 时 `E[E_t]≤1`；由 e-value 反演得到**随时有效置信下界** `p^L_t`，满足
`P(∀t≥1: p ≥ p^L_t) ≥ 1-α`。
真机证书成立当且仅当在某停止时刻 `t*`：`p^L_{t*} ≥ p_req`。允许任意停止，不膨胀 `α`。

**定义 131（主动证伪评测策略）**
在预算 `B_real` 内选试验 `(a,m)`：
`(a,m)* = argmax [ I(cert; a,m) + λ_w·1[m∉supp_β] - λ_c·cost(a,m) ]`，
其中 `I` 为证书不确定性（如置信带宽度）的期望缩减，第二项奖励**接触见证**。策略输出真实试验序列，直至证书 `certified` / `rejected` / 预算耗尽。

**定义 132（触觉锚定的真机联合证书）**
`J_tac=(β_S, ρ(d|m,b), A_cert, Δ_tac, μ_supp, w_max, p^L_t, α, provenance, contact_witness, evidence)`。
**可部署条件**：
```
M_T(a)⊆supp_β(S,a) ∀a∈A_T
∧ min_{d,m∈M_T} ρ(d|m,b) ≥ ρ_min(d)
∧ Δ_tac ≤ Θ_tac ∧ μ_supp ≤ μ_max
∧ p^L_t ≥ p_req
```
注意：`ρ` 承接第 53 轮鲁棒性层，`A_cert` 承接第 54 轮动作层，`p^L_t` 是**唯一由真机签署**的量。

## 2. 关键算法 伪代码

### IP-127 TCP（Tactile Contact Profile）

```python
def contact_profile(skill, A, M, tactile_sampler, theta_m=0.1):
    beta = {}
    for a in A:
        counts = {m: 0.0 for m in M}
        for _ in range(N_SAMPLE):
            z = tactile_sampler.rollout(skill, a)     # 仿真触觉
            counts[classify_contact(z)] += 1.0
        beta[a] = {m: c/N_SAMPLE for m, c in counts.items()}
    return beta

def contact_cover_check(beta, A_T, M_T, theta_m=0.1):
    for a in A_T:
        support = {m for m, p in beta[a].items() if p >= theta_m}
        if not set(M_T[a]).issubset(support):
            return False, a, set(M_T[a]) - support
    return True, None, None
```

### IP-128 CCR（Contact-Conditioned Robustness）

```python
def contact_certificate(skill, belief, M_req, delta_m, delta_res, rho_min):
    rho_c = {}
    for m in M_req:
        modes = [m2 for m2 in M if mode_dist(m2, m) <= delta_m]
        rho_c[m] = min(
            robustness(skill, x, d, m2)
            for m2 in modes
            for x in trust_region_samples(belief, eps)
            for d in DIMS
        )
    c_gap = [m for m in M_req if not distinguishable(skill.tactile, m, delta_res)]
    if c_gap:
        return ('reject', 'contact_mode_unobservable', c_gap)
    if min(rho_c.values()) < rho_min:
        return ('reject', 'contact_robustness', rho_c)
    return ('ok', ContactCert(rho_c, c_gap, M_req))
```

### IP-129 SRG（Sim-Real tactile Gap）

```python
def sim_real_gap(real_tac, sim_tac, A_grid, theta_tac, mu_max, w_max):
    gaps, ood = {}, {}
    for a in A_grid:
        zr, zs = real_tac[a], sim_tac[a]
        gaps[a] = wasserstein1(zr, zs)
        ood[a]  = knn_ood_rate(zr, zs)          # 真实样本落在仿真 kNN 支撑外比例
    delta_tac = max(gaps.values())
    mu_supp   = max(ood.values())
    w = density_ratio(real_tac, sim_tac, clip=(1e-3, w_max))
    admissible = (delta_tac <= theta_tac) and (mu_supp <= mu_max)
    return GapCert(delta_tac, mu_supp, w, admissible,
                   provenance='mixed' if admissible else 'prior_only')
```

### IP-130 AVCE（Anytime-Valid Certificate Evaluation）

```python
def anytime_valid_eval(real_stream, p_req, alpha):
    n, mean = 0, 0.0
    pL = pU = 0.0
    for x in real_stream:                       # 可随时停止
        n += 1
        mean += (x - mean) / n
        log_term = math.log(math.log2(2*n) / alpha + 1.0)
        rad = math.sqrt(2*log_term/n) + 3*log_term/n   # 经验 Bernstein 置信序列
        pL, pU = max(0.0, mean-rad), min(1.0, mean+rad)
        if pL >= p_req:
            return ('certified', pL, n)
        if pU < p_req:
            return ('rejected', pU, n)
    return ('pending', pL, n)
```

### IP-131 AWP（Active Witness Probe）

```python
def active_witness_probe(cert, unsupported_modes, budget, cost_fn,
                         lambda_w=1.0, lambda_c=0.5):
    best, best_val = None, -float('inf')
    for (a, m) in candidate_trials(cert):
        info    = expected_info_gain(cert, a, m)
        witness = 1.0 if m in unsupported_modes else 0.0
        val     = info + lambda_w*witness - lambda_c*cost_fn(a, m)
        if val > best_val:
            best, best_val = (a, m), val
    return best
```

### IP-132 RGC（Real-Grounded Certificate）

```python
def real_grounded_certificate(skill_seq, belief, real_stream, sim_gap,
                              A_T, M_T, p_req, alpha):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)  # 第54轮
    if J.status != 'ok':
        return ('reject', 'action_layer', J)
    beta = contact_profile(skill_seq, A_T, M)
    ok, a_bad, missing = contact_cover_check(beta, A_T, M_T)
    if not ok:
        return ('reject', 'contact_coverage', a_bad, missing)
    cc = contact_certificate(skill_seq, belief, M_T, delta_m, delta_res, rho_min)
    if cc.status != 'ok':
        return ('reject', 'contact_layer', cc)
    provenance = 'mixed' if sim_gap.admissible else 'prior_only'
    status, pL, n = anytime_valid_eval(real_stream, p_req, alpha)
    if status != 'certified':
        return ('reject', 'real_evidence', status, pL, n)
    return ('ok', J_tac(J, beta, cc, sim_gap, pL, provenance))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TCP | O(|A|·N_SAMPLE·|Z|) | O(|A|·|M|) | 接触分类校准、采样覆盖 ≥95% |
| CCR | O(|M_T|·|B_{δ_m}|·|𝔇|·|B_ε|) | O(|M_T|·|𝔇|) | `δ_m` 邻域完备、C-gap 判定 sound |
| SRG | O(|A|·(n_real+n_sim)log n) | O(n_real+n_sim) | 两样本检验功效、支撑估计一致 |
| AVCE | O(1) 每样本 | O(1) | e-process 有效、任意停止不膨胀 α |
| AWP | O(|candidate|·|cert|) | O(|candidate|) | 采集函数单调、见证优先 |
| RGC | O(TCP+CCR+SRG+AVCE) | O(|A|·|M|+|𝔇|) | 证据 provenance 不越权 |

**正确性定理（Tactile-Grounded Real-Evaluation Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 接触模式分类器校准，`P(m_t=φ(z_t))≥1-δ_m`；**(A30)** 在部署接触模式上 `Δ_tac≤Θ_tac` 且 `μ_supp≤μ_max`，密度比 `w≤w_max`；**(A31)** 真机试验在任务内可交换/平稳；**(A32)** AVCE 的 e-process 有效，`P(∀t:p≥p^L_t)≥1-α`；**(A33)** 主动评测在预算 `B_real` 内覆盖所有必需模式。则
```
P_success ≥ p^L_{t*} - δ_m - μ_supp - P(Δ_tac > Θ_tac)
```
以概率 `≥1-α` 成立。关键：**最终下界由真机样本签署**；仿真只影响 `ρ` 的先验与选点效率，不进入 `p^L`；接触层的 `C-gap` 与动作层 `A_cert` 均为硬否决项。任一项破缺，证书都会从"有真机锚点"退化为"仿真自证"。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 触觉仿真鸿沟不可测/高维 | 高 | 配对真机数据 + 域适应 + provenance 硬隔离 |
| 初滑等模式不可辨识 | 高 | 高频触觉 + 多模态融合 + C-gap 硬否决 |
| e-process 过于保守导致样本爆炸 | 中 | 混合 e-process + 先验借力（仅选点）+ 预算自适应 |
| 真机非平稳破坏可交换性 | 高 | 分段平稳检验 + 重启 e-process + 漂移告警 |
| 主动评测损坏硬件 | 中 | 力/位移安全包络 + 低能量优先 + 人工急停 |
| 接触模式分类器过自信 | 高 | 温度校准 + OOD 检测 + 红队接触注入 |

## 6. 本轮最大风险

**一句话**：触觉接触剖面与真机 anytime-valid 证书把"可部署"从仿真自证推进为真机锚定，但其 soundness **三重依赖接触模式可辨识、真机样本平稳可交换、以及真实接触不逃出仿真支持集**；一旦初滑等关键模式不可辨识、或真机接触分布漂移到仿真支撑之外，`C-gap` 会漏检、`μ_supp` 会被低估，随时有效下界将在一个被系统性污染的样本流上"合法地"收敛到虚高成功率，故必须以 **C-gap 硬否决 + 支持集 OOD 检验 + 分段平稳重启 + 硬件安全包络** 四重护栏，宁可多花真机预算，绝不把"仿真里握住了"当作"真实世界握得住"。

# 第 55 轮产物 · 创新点清单 v32：TacGround-RealCert（TCP×CCR×SRG×AVCE×AWP×RGC）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮在「动作-鲁棒性双证书」之上，用 **触觉感知** 与 **真机评测** 增加 **接触模式层、仿真-真机证据层、真机统计保证层**：
> - **TCP（Tactile Contact Profile）**：接触占用剖面 `β_S(a,m)`，把"动作可达"升级为"接触可建立/可维持"；
> - **CCR（Contact-Conditioned Robustness）**：`ρ(d|m,b)` 与接触可辨识缺口 `C-gap`，不可辨识即硬否决；
> - **SRG（Sim-Real tactile Gap）**：触觉鸿沟 `Δ_tac`、支持集失配 `μ_supp`、有界密度比，给证据打 provenance；
> - **AVCE（Anytime-Valid Certificate Evaluation）**：真机样本的随时有效置信下界 `p^L_t`，允许任意停止；
> - **AWP（Active Witness Probe）**：预算约束下主动寻找 contact witness 的证伪策略；
> - **RGC（Real-Grounded Certificate）**：触觉锚定的真机联合证书 `J_tac`，最终保证只由真机签署。
>

### IP-127 TCP

```python
def contact_profile(skill, A, M, tactile_sampler, theta_m=0.1):
    beta = {}
    for a in A:
        counts = {m: 0.0 for m in M}
        for _ in range(N_SAMPLE):
            z = tactile_sampler.rollout(skill, a)
            counts[classify_contact(z)] += 1.0
        beta[a] = {m: c/N_SAMPLE for m, c in counts.items()}
    return beta

def contact_cover_check(beta, A_T, M_T, theta_m=0.1):
    for a in A_T:
        support = {m for m, p in beta[a].items() if p >= theta_m}
        if not set(M_T[a]).issubset(support):
            return False, a, set(M_T[a]) - support
    return True, None, None
```

### IP-128 CCR

```python
def contact_certificate(skill, belief, M_req, delta_m, delta_res, rho_min):
    rho_c = {}
    for m in M_req:
        modes = [m2 for m2 in M if mode_dist(m2, m) <= delta_m]
        rho_c[m] = min(
            robustness(skill, x, d, m2)
            for m2 in modes
            for x in trust_region_samples(belief, eps)
            for d in DIMS
        )
    c_gap = [m for m in M_req if not distinguishable(skill.tactile, m, delta_res)]
    if c_gap:
        return ('reject', 'contact_mode_unobservable', c_gap)
    if min(rho_c.values()) < rho_min:
        return ('reject', 'contact_robustness', rho_c)
    return ('ok', ContactCert(rho_c, c_gap, M_req))
```

### IP-129 SRG

```python
def sim_real_gap(real_tac, sim_tac, A_grid, theta_tac, mu_max, w_max):
    gaps, ood = {}, {}
    for a in A_grid:
        zr, zs = real_tac[a], sim_tac[a]

        ood[a]  = knn_ood_rate(zr, zs)
    delta_tac = max(gaps.values())
    mu_supp   = max(ood.values())

    admissible = (delta_tac <= theta_tac) and (mu_supp <= mu_max)
    return GapCert(delta_tac, mu_supp, w, admissible,
                   provenance='mixed' if admissible else 'prior_only')
```

### IP-130 AVCE

```python
def anytime_valid_eval(real_stream, p_req, alpha):
    n, mean = 0, 0.0
    pL = pU = 0.0
    for x in real_stream:                       # 可随时停止
        n += 1
        mean += (x - mean) / n
        log_term = math.log(math.log2(2*n) / alpha + 1.0)
        rad = math.sqrt(2*log_term/n) + 3*log_term/n   # 经验 Bernstein 置信序列
        pL, pU = max(0.0, mean-rad), min(1.0, mean+rad)
        if pL >= p_req:
            return ('certified', pL, n)
        if pU < p_req:
            return ('rejected', pU, n)
    return ('pending', pL, n)
```

### IP-131 AWP

```python
def active_witness_probe(cert, unsupported_modes, budget, cost_fn,
                         lambda_w=1.0, lambda_c=0.5):
    best, best_val = None, -float('inf')
    for (a, m) in candidate_trials(cert):
        info    = expected_info_gain(cert, a, m)
        witness = 1.0 if m in unsupported_modes else 0.0
        val     = info + lambda_w*witness - lambda_c*cost_fn(a, m)
        if val > best_val:
            best, best_val = (a, m), val
    return best
```

### IP-132 RGC

```python
def real_grounded_certificate(skill_seq, belief, real_stream, sim_gap,
                              A_T, M_T, p_req, alpha):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)  # 第54轮
    if J.status != 'ok':
        return ('reject', 'action_layer', J)
    beta = contact_profile(skill_seq, A_T, M)
    ok, a_bad, missing = contact_cover_check(beta, A_T, M_T)
    if not ok:
        return ('reject', 'contact_coverage', a_bad, missing)
    cc = contact_certificate(skill_seq, belief, M_T, delta_m, delta_res, rho_min)
    if cc.status != 'ok':
        return ('reject', 'contact_layer', cc)
    provenance = 'mixed' if sim_gap.admissible else 'prior_only'
    status, pL, n = anytime_valid_eval(real_stream, p_req, alpha)
    if status != 'certified':
        return ('reject', 'real_evidence', status, pL, n)
    return ('ok', J_tac(J, beta, cc, sim_gap, pL, provenance))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TCP | O(|A|·N_SAMPLE·|Z|) | O(|A|·|M|) | 接触分类校准、采样覆盖 ≥95% |
| CCR | O(|M_T|·|B_{δ_m}|·|𝔇|·|B_ε|) | O(|M_T|·|𝔇|) | `δ_m` 邻域完备、C-gap sound |
| SRG | O(|A|·(n_r+n_s)log n) | O(n_r+n_s) | 两样本检验功效、支撑估计一致 |
| AVCE | O(1) 每样本 | O(1) | e-process 有效、可选停止安全 |
| AWP | O(|candidate|·|cert|) | O(|candidate|) | 采集函数单调 |
| RGC | O(TCP+CCR+SRG+AVCE) | O(|A|·|M|+|𝔇|) | provenance 不越权、硬否决闭合 |

**正确性定理（Tactile-Grounded Real-Evaluation Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 接触模式分类器校准，`P(m_t=φ(z_t))≥1-δ_m`；**(A30)** 部署接触模式上 `Δ_tac≤Θ_tac ∧ μ_supp≤μ_max ∧ w≤w_max`；**(A31)** 真机试验在任务内可交换/平稳；**(A32)** `P(∀t:p≥p^L_t)≥1-α`；**(A33)** 主动评测在预算内覆盖所有必需模式。则部署成功概率
```
P_success ≥ p^L_{t*} - δ_m - μ_supp - P(Δ_tac > Θ_tac)
```
以概率 `≥1-α` 成立。关键：**最终下界只由真机样本签署**，仿真证据只能提出候选/做先验；`C-gap` 与 `A_cert` 是硬否决；`provenance=prior_only` 时仿真不得进入最终证书。

## 6. 本轮最大风险

**一句话**：触觉接触剖面与真机 anytime-valid 证书把"可部署"从仿真自证推进为真机锚定，但其 soundness **三重依赖接触模式可辨识、真机样本平稳可交换、以及真实接触不逃出仿真支持集**；一旦初滑等关键模式不可辨识、或真机接触分布漂移到仿真支撑之外，`C-gap` 会漏检、`μ_supp` 会被低估，随时有效下界将在一个被系统性污染的样本流上"合法地"收敛到虚高成功率，故必须以 **C-gap 硬否决 + 支持集 OOD 检验 + 分段平稳重启 + 硬件安全包络** 四重护栏，宁可多花真机预算，绝不把"仿真里握住了"当作"真实世界握得住"。
