# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「检索增强生成」×「Isaac Sim」）

> 第 54 轮已把技能组合建立在动作空间剖面 `α_S`、组合图 `G_S`、云边映射 `γ_ce` 与联合证书 `J` 之上。但 `α_S` 与 `ρ` 仍是“离线采样得到的静态断言”，证书内的证据是隐式的、不可追溯的。本轮引入 **Isaac Sim 作为高保真证据工厂**、**RAG 作为证据索引与检索式论证器**：把“我声称可行”改写为“我能引用哪些证据、这些证据覆盖查询邻域多少、证据迁移到真实边端后还剩多少置信度”。核心矛盾：H22：静态剖面在分布外场景覆盖不足，`compat` 边成为“无出处的断言”；H23：高保真仿真证据昂贵且存在 sim-to-real 漂移，检索到的“相关证据”可能“相关但不可迁移”。

## 0. 直觉与动机

**灵感 1（Isaac Sim = 可编程证据工厂，而非一次性验证器）**
直觉：第 54 轮把 Isaac Sim 当成“跑一遍看行不行”的验证器，浪费了它可编程、可随机化、可反事实重放的特性。更合理的定位是：Isaac Sim 是一个 **按查询需求生产结构化证据** 的工厂——给定“场景 × 域随机化参数 × 技能 × 动作上下文”，产出带出处、带成功/失败标签、带鲁棒性谱、带反事实分支的 **证据单元**。这样第 54 轮的 `α_S` 与 `ρ` 不再是采样后即丢弃的统计量，而是可存储、可检索、可审计的证据资产。

**灵感 2（RAG = 让证书“可引用”，而不是让模型“多说几句”）**
直觉：RAG 的真正价值不是给 LLM 补知识，而是把决策从 **参数化断言** 变成 **带引用的论证**。每个组合边、每个鲁棒性下界都应附一个“引用集”`E_q`、一个覆盖度 `Cov_δ(q)`、一个邻域标签纯度 `Pur_δ(q)`。若检索不到足够支撑，系统应输出 **“证据不足”** 而非“可行”——这把第 54 轮无法界定的 `β_E`（证据误差）拆成可审计的检索风险、迁移风险与时效风险。

**灵感 3（检索增强的技能组合：静态图 → 证据加权图）**
直觉：第 54 轮的 `compat(S_i,S_j)` 是动作剖面的 Jaccard 系数，它只说明“动作集合像”，不说明“在查询场景里组合过、且成功过或失败过”。RAG 把 `G_S` 的每条边从常量权重升级为 **随查询变化的证据权重**：`compat_R(q) = Cov_δ(q)·compat_ev(E_q) + (1−Cov_δ(q))·compat_prior`，其中 `compat_prior` 被刻意设在阈值之下。于是“没有证据”自动退化为“保守拒绝”，而不是“默认兼容”。

**灵感 4（检索增强的解释：从根因分析到“最近反例取证”）**
直觉：第 54 轮的 `Explain` 是模型内省式根因定位，容易给出看似合理但无据的结论。RAG 让它先检索 **最近的历史失败证据**，若邻域标签纯度足够，则用这些反例的共性动作维度作为根因假设，并附出处；若纯度不足，则触发 Isaac Sim **定向反事实生成**（固定其余变量，只扫失败动作维度），把“解释”变成一次可复现的实验，而不是一次语言猜测。

**灵感 5（符合预测：把“检索到”升级为“可保证”）**
直觉：检索到 k 条相似证据仍不足以说“新查询也安全”，因为相似不等于同分布。用 **符合预测（conformal prediction）** 在检索邻域/锚点集上校准非一致性分数，可给出鲁棒性谱的分布无关下界 `ρ_lcb`：只要局部可交换性成立，真实 `ρ` 落入预测区间的概率至少 `1−α`。这把 RAG 从“经验检索”抬升为“有覆盖保证的检索式认证”。

**灵感 6（证据生命周期：RAG 的敌人不是检索不到，而是检索到过期的）**
直觉：证据库会老化：Isaac Sim 资产版本更新、真实场景漂移、域随机化参数失配。必须给每条证据加 **新鲜度权重与有效期**，并用有效样本量 `n_eff` 与实时描述子到证据邻域的 KL 漂移来判定“陈旧”。陈旧时证书状态转为 `stale`，而非继续复用旧结论。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（证据单元）**
证据单元 `e = (x, s, a, y, ρ, f, π, t, θ)`：
- `x ∈ X` 为场景/任务描述子（多模态嵌入）；
- `s` 为技能标识，`a ∈ A` 为动作上下文；
- `y ∈ {0,1}` 为结果，`ρ ∈ [0,1]^D` 为第 53 轮鲁棒性谱；
- `f` 为失败模式标签（无失败时 `f=⊥`）；
- `π` 为出处链（Isaac Sim 资产版本、seed、配置哈希）；
- `t` 为生成时间，`θ ∈ Θ_DR` 为域随机化参数。

**定义 122（证据索引与检索）**
索引 `I = (E, d_X, d_A)`，查询 `q = (x_q, s_q, a_q)` 的距离
```
d_λ(e,q) = λ_X·d_X(x_e,x_q) + λ_A·d_A(a_e,a_q)
```
`R_k(q)` 为距离最小的 `k` 条证据，权重 `w_e ∝ exp(−d_λ(e,q)/τ)`；支持集 `N_δ(q) = {e ∈ E : d_λ(e,q) ≤ δ}`。

**定义 123（检索覆盖、标签纯度与证据间隙）**
```
Cov_δ(q) = μ_A(proj_A(N_δ(q))) / μ_A(A_q)
Pur_δ(q) = max_f  Σ_{e∈N_δ(q), f_e=f} w_e / Σ_{e∈N_δ(q)} w_e
Gap(q)   = 1 − Cov_δ(q)
```
其中 `A_q` 为查询相关的动作子空间，`μ_A` 为其上的度量。`Cov_δ` 衡量“邻域证据在动作空间上的覆盖”，`Pur_δ` 衡量“邻域结论的一致性”。

**定义 124（Isaac Sim 证据生成协议）**
生成器 `Gen_Sim(B) = {e_i}`：按 `x ~ D_scene`、`θ ~ Θ_DR` 采样，对每个 `(x,θ,s)` 执行 `isaac_rollout`，并用锚点集 `A_anchor` 估计 sim-to-real 校准映射 `κ : R^D → R^D`：
```
L_κ = sup_{u≠v} ||κ(u)−κ(v)||_∞ / ||u−v||_∞
ε_κ = sup_{a∈A_anchor} ||κ(ρ_sim(a)) − ρ_real(a)||_∞
```
证据生成需 **面向覆盖**：对 `Gap(q)` 高的区域优先分配预算（主动采样），而非均匀撒点。

**定义 125（检索增强证书 RAC）**
```
RAC(q) = (J, E_q, w, Prov(E_q), Cov_δ(q), Pur_δ(q), n_eff(q), ρ_lcb)
```
`RAC` 判定为 `certified` 当且仅当：
1. `|N_δ(q)| ≥ k_min` 且 `Cov_δ(q) ≥ θ_cov`；
2. `Pur_δ(q) ≥ θ_pur`；
3. 有效样本量 `n_eff(q) ≥ n_min`；
4. `ρ_lcb(d) ≥ ρ_min(d), ∀d`（见定义 126）；
5. 所有引用证据出处完整且 `t` 在有效期 `TTL` 内。
若仅因 1–3 不满足，则输出 `insufficient`（证据不足，触发定向生成），而非 `reject`（方案不可行）；两者的区别是可恢复性。

**定义 126（检索增强符合证书）**
在检索邻域（或锚点集）上定义非一致性分数 `u_e = ||κ(ρ_sim(e)) − ρ_real(e)||_∞`，取分位数
```
q̂ = Quantile_{⌈(n+1)(1−α)⌉/n}({u_e})
ρ_lcb(d) = κ(ρ̂(d)) − q̂,  ρ̂ = weighted_mean_{e∈R_k(q)}(ρ_sim(e))
```
在 **局部可交换性** 假设下，`P(ρ_real(d) ≥ ρ_lcb(d)) ≥ 1−α`。注意：这里 `ρ_lcb` 是 **检索条件化** 的下界，其保证随 `Cov_δ` 与 `n_eff` 退化，不能跨邻域外推。

**定义 127（证据生命周期与陈旧判定）**
新鲜度 `f_e = exp(−λ(t−t_e))`，有效样本量
```
n_eff(q) = (Σ_e w_e f_e)² / Σ_e (w_e f_e)²
```
实时漂移 `D_drift = KL(P_live(a) || P_store(a | N_δ(q)))`。当 `n_eff < n_min` 或 `D_drift > θ_drift` 或存在 `t_e + TTL < now` 的关键证据时，标记 `stale` 并触发 `Gen_Sim` 的增量补证。

## 2. 关键算法 伪代码

### IP-121 EIG（Evidence Index Generation）

```python
def build_evidence_index(skills, scenes, DR, budget, anchor):
    E = []
    for x in scenes:
        for theta in coverage_oriented_dr(DR, budget, E, scenes):
            cfg = IsaacConfig(scene=x, dr=theta)
            for s in skills:
                traj = isaac_rollout(s, cfg)          # 可反事实重放
                e = EvidenceUnit(
                    x=embed_scene(x), s=s.id, a=traj.action_ctx,
                    y=traj.success, rho=spectrum(traj),
                    f=classify_failure(traj), pi=provenance(cfg),
                    t=now(), theta=theta)
                E.append(e)
    kappa = calibrate_sim2real(E, anchor)             # 定义 124
    return EvidenceIndex(E, d_X, d_A), kappa
```

### IP-122 RA-SCOM（Retrieval-Augmented Skill Composition）

```python
def ra_composition(skills, q_task, I, theta_a, delta, theta_cov):
    G = empty_graph()
    for si, sj in pairs(skills):
        q = (q_task.x, si.id, sj.id)
        E_q = retrieve(I, q, k=k_min)
        cov = coverage(E_q, delta, q_task.action_subspace)
        if cov < theta_cov:
            request_evidence(si, sj, q_task)          # Isaac Sim 定向补证
            E_q = retrieve(I, q, k=k_min); cov = coverage(E_q, delta, ...)
        compat_ev = evidence_weighted_compat(E_q, si, sj)
        compat_emp = jaccard(si.alpha, sj.alpha)
        compat = cov * compat_ev + (1 - cov) * compat_prior   # prior < theta_a
        if compat >= theta_a and purity(E_q) >= theta_pur:
            G.add_edge(si, sj, compat=compat, evidence=E_q,
                       cert=RAC(q, si, sj, I, kappa))
    return G
```

### IP-123 REX-RAG（Retrieval-Augmented Explanation）

```python
def explain_with_retrieval(failure, I, sim_model, theta_pur):
    q = encode_failure(failure)
    E_q = retrieve(I, q, k=K)
    proto = [e for e in E_q if e.f == failure.mode]
    if label_purity(proto) < theta_pur:
        # 解释不足 -> 用 Isaac Sim 做受控反事实，而不是语言猜测
        return ('unknown', request_isaac_counterfactual(failure, axes=failure.candidates))
    causes = rank_action_dims(proto)                  # 反例共性动作维度
    return Explanation(causes, citations=[e.pi for e in proto],
                       conf=label_purity(proto), coverage=coverage(E_q))
```

### IP-124 SRC（Sim-to-Real Retrieval Conformal）

```python
def retrieval_conformal_certificate(q, I, kappa, alpha, rho_min, theta_cov):
    E_q = retrieve(I, q, k=K)
    if coverage(E_q) < theta_cov or effective_n(E_q) < n_min:
        return ('insufficient', trigger=Gen_Sim(q, budget=adaptive))
    scores = [nonconformity(kappa, e) for e in E_q]
    qhat = conformal_quantile(scores, alpha)
    rho_hat = kappa(weighted_mean([e.rho for e in E_q]))
    rho_lcb = {d: rho_hat[d] - qhat for d in rho_hat}
    if min(rho_lcb.values()) < rho_min:
        return ('reject', rho_lcb, qhat)
    return ('certified', RAC(rho_lcb, E_q, qhat, coverage(E_q)))
```

### IP-125 EAM（Evidence Aging Monitor）

```python
def evidence_health(q, I, live_desc, TTL, lam, theta_drift):
    E_q = retrieve(I, q, k=K)
    fresh = [exp(-lam * (now - e.t)) for e in E_q]
    n_eff = ess(fresh * weights(E_q))
    drift = KL(live_desc, descriptor_distribution(E_q))
    expired = any(e.t + TTL < now for e in critical(E_q))
    if n_eff < n_min or drift > theta_drift or expired:
        return ('stale', n_eff, drift, request_evidence(q))
    return ('fresh', n_eff, drift)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EIG | O(B·|S|·T_rollout) | O(B·|S|·d) | 覆盖导向采样、出处完整 |
| RA-SCOM | O(|S|²·(log|E|+k)) | O(|S|²+k) | 证据加权兼容、低覆盖退化保守 |
| REX-RAG | O(log|E| + K·d) | O(K) | 邻域纯度、反事实可复现 |
| SRC | O(k log k + |R_k|·D) | O(k+D) | 局部可交换、κ 有界 |
| EAM | O(k + d) | O(k) | 时效与漂移阈值闭合 |

**正确性定理（Retrieval-Augmented Composition Soundness）**
承接第 54 轮 (A22)–(A28)；新增：
**(A29)** 检索邻域/锚点集对查询满足局部可交换性；
**(A30)** `κ` 为 `L_κ`-Lipschitz 且锚点残差 `≤ ε_κ`；
**(A31)** 查询分布被证据索引覆盖的概率 `≥ 1−β_cov`；
**(A32)** 检索与符合校准延迟 `≤ τ_loop`，且证据未越过 `TTL`。
则对通过 `RAC` 的查询 `q`：
```
P(ρ_real(d) ≥ ρ_min(d), ∀d) ≥ (1 − β_cov)(1 − α) − ε_κ − β_drift
P(success(P_e)) ≥ (1 − β_cov)(1 − α) − ε_κ − β_drift
                  − Σ_d(1 − ρ_min(d)) − P(δ_a > Θ_a)
```
与第 54 轮相比，原先不可界定的实证误差 `β_E` 被替换为 **可审计的三项**：覆盖失败 `β_cov`、符合风险 `α`、迁移/漂移残差 `ε_κ + β_drift`。代价是：证书只在“证据充分”时成立，`insufficient` 必须显式暴露给规划器，而不能被静默当作可行。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| “相关但不可迁移”证据被当作支撑 | 高 | 锚点校准 + `ε_κ` 显式入界 + 域标签约束 |
| 证据库分布偏移/老化 | 高 | `TTL` + `n_eff` + KL 漂移监测 + 增量补证 |
| 局部可交换性在非平稳部署中破裂 | 高 | 分域校准 + 保守 `α` + 覆盖度门槛 |
| 检索延迟拖垮云边实时回路 | 中 | 分层索引 + 边缘缓存 + `insufficient` 快速回退 |
| 证书“引用幻觉”（引用不支持结论） | 高 | 出处审计 + 引用-结论一致性检查 + 反事实复核 |
| Isaac Sim 资产/物理参数版本漂移 | 中 | 版本化证据、重放回归、资产锁 |

## 6. 本轮最大风险

**一句话**：RAG 把“无证据的断言”升级为“有引用的断言”，但引用的存在不等于引用的有效——本方案 soundness 同时依赖检索邻域的局部可交换性、Isaac Sim 证据的可迁移性、以及证据库的时效性；一旦检索到“相关却不可迁移”或被污染的证据，证书会以合规外观输出系统性错误的组合，故必须以 **符合预测下界 + 时效漂移监测 + 出处审计** 三重护栏，宁可显式判定“证据不足”，也绝不把“有引用”当作“已证明”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（EIG×RA-SCOM×REX-RAG×SRC×EAM）

> 承接第 54 轮产物 v31。本轮把“静态证书体系”升级为“可引用、可校准、可老化”的 **证据驱动证书体系**，新增五大算子：
> - **EIG（Evidence Index Generation）**：用 Isaac Sim 按需生产带出处、带标签、带鲁棒性谱的结构化证据单元，并建立可检索索引；

> - **SRC（Sim-to-Real Retrieval Conformal）**：在检索邻域上做符合校准，输出有覆盖保证的鲁棒性下界；
> - **EAM（Evidence Aging Monitor）**：新鲜度、有效样本量与分布漂移驱动的证据生命周期管理。
>

### IP-122 RA-SCOM

```python
def ra_composition(skills, q_task, I, kappa, theta_a, delta, theta_cov):
    G = empty_graph()
    for si, sj in pairs(skills):
        q = (q_task.x, si.id, sj.id)
        E_q = retrieve(I, q, k=k_min)
        cov = coverage(E_q, delta, q_task.action_subspace)
        if cov < theta_cov:
            request_evidence(si, sj, q_task)
            E_q = retrieve(I, q, k=k_min)
            cov = coverage(E_q, delta, q_task.action_subspace)
        compat = cov * evidence_weighted_compat(E_q, si, sj) \
                 + (1 - cov) * compat_prior          # compat_prior < theta_a
        if compat >= theta_a and label_purity(E_q) >= theta_pur:
            cert = RAC(q, si, sj, I, kappa)
            if cert.status == 'certified':
                G.add_edge(si, sj, compat=compat, evidence=E_q, cert=cert)
            else:
                G.add_node('insufficient:'+str(q), reason=cert.status)
    return G
```

### IP-124 SRC

```python
def retrieval_conformal_certificate(q, I, kappa, alpha, rho_min, theta_cov):
    E_q = retrieve(I, q, k=K)
    if coverage(E_q) < theta_cov or effective_n(E_q) < n_min:
        return ('insufficient', Gen_Sim(q, budget=adaptive))
    scores = [nonconformity(kappa, e) for e in E_q]
    qhat = conformal_quantile(scores, alpha)
    rho_hat = kappa(weighted_mean([e.rho for e in E_q]))
    rho_lcb = {d: rho_hat[d] - qhat for d in rho_hat}
    if min(rho_lcb.values()) < rho_min:
        return ('reject', rho_lcb, qhat)
    return ('certified', RAC(rho_lcb, E_q, qhat, coverage(E_q)))
```

### IP-125 EAM

```python
def evidence_health(q, I, live_desc, TTL, lam, theta_drift):
    E_q = retrieve(I, q, k=K)
    fresh = [exp(-lam * (now - e.t)) for e in E_q]
    n_eff = ess(fresh * weights(E_q))
    drift = KL(live_desc, descriptor_distribution(E_q))
    expired = any(e.t + TTL < now for e in critical(E_q))
    if n_eff < n_min or drift > theta_drift or expired:
        return ('stale', n_eff, drift, request_evidence(q))
    return ('fresh', n_eff, drift)
```

### IP-127 ECP

```python
def evidence_conditioned_plan(T_desc, G, I, kappa, budget):
    frontier = PriorityQueue([(0, 'root', [])])
    while frontier:
        cost, node, path = frontier.pop()
        if satisfies(node, T_desc):
            return ('ok', path)
        for nxt in G.successors(node):
            cert = G[nxt].cert
            if cert.status == 'insufficient' and budget > 0:
                Gen_Sim(query=cert.query, budget=adaptive); budget -= 1
                cert = re_certify(cert)
            if cert.status != 'certified':
                continue                      # 未认证边不进入可行路径
            frontier.push((cost + cost_align(nxt), nxt, path + [nxt]))
    return ('no_certified_path', collect_insufficient_reasons())
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EIG | O(B·|S|·T_rollout) | O(B·|S|·d) | 覆盖导向采样、出处完整 |
| RA-SCOM | O(|S|²·(log|E|+k)) | O(|S|²+k) | 低覆盖退化保守、边必带证书 |
| REX-RAG | O(log|E| + K·d) | O(K) | 邻域纯度门槛、反事实可复现 |
| SRC | O(k log k + |R_k|·D) | O(k+D) | 局部可交换、κ 有界 |
| EAM | O(k + d) | O(k) | 时效/漂移阈值闭合 |
| ECP | O((|V| log|V|+|E|)·B_gen) | O(|V|+|E|) | 仅认证边连通，`insufficient` 显式传播 |

**正确性定理（Retrieval-Augmented Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 检索邻域/锚点集局部可交换；**(A30)** `κ` 为 `L_κ`-Lipschitz、锚点残差 `≤ ε_κ`；**(A31)** 查询分布被索引覆盖的概率 `≥ 1−β_cov`；**(A32)** 检索与符合校准延迟 `≤ τ_loop` 且证据未过期。
则对 `RAC(q)=certified` 的查询：
```
P(ρ_real(d) ≥ ρ_min(d), ∀d) ≥ (1 − β_cov)(1 − α) − ε_κ − β_drift
P_success ≥ (1 − β_cov)(1 − α) − ε_κ − β_drift
            − Σ_d(1 − ρ_min(d)) − P(δ_a > Θ_a)
```
关键：第 54 轮的固定实证误差 `β_E` 被分解为 **覆盖失败 `β_cov` + 符合风险 `α` + 迁移/漂移残差 `ε_κ+β_drift`**；证书只在证据充分时成立，`insufficient` 不被静默当作可行。

## 5. 本轮最大风险

**一句话**：RAG 把“无证据的断言”升级为“有引用的断言”，但引用的存在不等于引用的有效——本方案 soundness 同时依赖检索邻域的局部可交换性、Isaac Sim 证据的可迁移性、以及证据库的时效性；一旦检索到“相关却不可迁移”或被污染的证据，证书会以合规外观输出系统性错误的组合，故必须以 **符合预测下界 + 时效漂移监测 + 出处审计** 三重护栏，宁可显式判定“证据不足”，也绝不把“有引用”当作“已证明”。
