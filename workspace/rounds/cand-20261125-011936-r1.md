## 1. 两个灵感的第一性原理

### 灵感 1 ·「时空推理」→ 第 3 轮的地图是一张照片，但操作是一部电影

**直觉解释**：IP-13 回答「此刻东西在哪、协方差多大」，像一张照片。可真实操作里，目标会被推走、会被临时遮挡、机器人执行有延迟、装配/折叠有先后和进度。拿「观测时刻」的照片去判「执行时刻」的到点，相当于用过期地图导航——**过期本身不可怕，可怕的是它带着很小的协方差、显得很自信**。时空推理不是多存几个坐标，而是把状态变成时间的函数：`state(t)`，并让它**活到动作真正执行的那一刻**。

**严谨定义**：

- **运动增广状态（U19）**：每个物体 `s_k(t)=[p_k, v_k]`，线性高斯动态 `s_{t+1}=F s_t + w, w~N(0,Q)`；预测 `ŝ_k(t+Δ|t)=F(Δ)ŝ_k(t|t)`、`Σ_k(t+Δ|t)=FΣFᵀ+Q(Δ)`。场景图在 U16 上加时间戳与运动场。
- **执行时刻断言（U20）**：U17 卡方断言的 `x̂/Σ` 一律换成执行时域的 `ŝ(t+Δ)/Σ(t+Δ)`；另加时序谓词「窗口内到点」「进度率 ≥ ρ」「窗口内无进展」。这不是换阈值，是换**评估时刻**。
- **延迟偏差律（L14）**：用观测时刻估计去控制执行时刻，若真实位移 `d=vΔ`，断言统计量服从非中心 χ²，非中心参数 `dᵀΣ⁻¹d`——**误拒率被系统性抬高，且调 α 无法修复**（只能拿误拒换误受）。预测把确定性均值项归零，只留过程噪声；运动模型正确时预测严格不劣于过期快照，模型错误时可能更糟 → 必须有模型切换门（见 §5）。
- **遮挡滑行（COAST）**：有运动模型时，短暂遮挡不必「保持」，可外推续跑（L16 给出盈亏条件）——把第 3 轮 IP-15 的「遮挡 → 保持」升级为「遮挡 → 有限滑行，超时 → 重定位」。遮挡从「停」变成「按预测继续」，是时空推理对干扰协议最直接的改写。
- **按预测关联**：数据关联用预测位置的马氏门限，而非最近快照——这同时缓解第 3 轮最大风险「地图毒化」在移动目标上的版本（按轨迹绑定，而非按瞬时距离绑定）。
- **诚实的收益边界**：静态抓放里，预测的收益主要来自「协方差诚实化 + 遮挡滑行 + 更好绑定」，不是成功率大增；**增益集中在相对运动存在、且与感知延迟同量级的场景**（人为推移、遮挡、长程装配/折叠）。不夸大。

**策略含义**：第 3 轮把「在哪 / 是谁 / 卡没卡」交给了空间状态层；本轮补上「**什么时候**在哪」——因为动作是在未来执行的，状态必须活到未来。

### 灵感 2 ·「动作空间」→ 离散决策不该是散落的 if-else，而应是一个有语义的动作空间

**直觉解释**：第 3 轮已经有一堆离散决策——continue / hold / relocalize / regrasp / switch / probe / yield——但它们以触发器的形式散落在主循环里，没有统一的前置条件、后果、时长和代价。这不是动作空间，是一把条件反射。**动作空间 = 带类型的可选项集合 + 明确前置/效果 + 时长 + 代价**。一旦成型，「何时介入」就从拍脑袋变成良定义的决策问题；否则你会得到两种病：抖动（HOLD/RELOCALIZE 快速来回切）和不可比（没法说清重定位到底值不值）。

**严谨定义**：

- **元动作（U21）**：`a=(type, params)`，`type ∈ {CONTINUE(ℓ), HOLD(τ), COAST(τ), RELOCALIZE, REGRASP, REALIGN, SWITCH_GEN, PROBE, YIELD}`；每个声明 `pre(a)`（对时空状态的前置）、`eff(a)`、时长 `d(a)`、期望代价 `c(a)`（步数，复用 L12/L13 口径）。
- **半马尔可夫 / 选项（semi-MDP）**：元动作是时间扩展的 option，带终止条件；连续动作空间是它的 primitive（CONTINUE 内部仍由 VLA chunk 产生动作）。于是第 1–3 轮的连续动作层与离散决策层被显式分层：**底层「怎么动」、高层「做什么、做多久」**。
- **统一代价**：HOLD / COAST / RELOCALIZE / RESTART 的比较，不再是各自启发式，而是同一个 `Q(a)=c(a)+E[V(s')]` 下的比较（L15）；P12 的探测记账变成 `PROBE` 动作的可采纳性检验。
- **安全屏蔽 + 承诺（P14/P15）**：只有 `pre(a)` 成立的元动作可采纳（YIELD 有接触硬门控）；已启动的 option 跑到达成或最短承诺时长，提前切换需硬安全前置——**用承诺期消除抖动**（L15 证明无承诺的近视切换可能零进展地无限循环）。
- **规则优先、可学习后接**：先用规则 / 一步前瞻实现 meta-policy，保持接口不变；日后可用日志中的步数代价拟合 bandit 策略替换，**不训练新的大模型**。

### 灵感 1 × 灵感 2 · 两个正交的轴：状态空间 × 动作空间

时空推理定义**状态空间** `S_t=(ŝ(t),Σ(t),progress,deadline)`，动作空间定义**决策变量** `A_meta`；两者合起来才是一个良定义的决策问题 `π_meta: S_t → A_meta`。第 1–2 轮解决「怎么动」（连续动作 + 伺服 + 评测），第 3 轮解决「世界是什么」（空间状态），本轮把「世界随时间怎么变」与「我能做什么」同时显式化——**这是四轮里第一次把系统写成一个完整的（半）MDP，而不是一串模块**。

## 2. 研究问题（新增 Q13–Q16，接 Q1–Q12）

- **Q13（时空预测与校准）**：运动增广预测能否在延迟 Δ 与目标速度下把断言误拒率拉回 `[α/2,2α]`？预测误差如何随 Δ 增长？（E634）
- **Q14（预测拦截与遮挡滑行）**：预测式拦截 + 有限滑行，在移动目标 / 人为干扰切片上的收益是否足以覆盖新增状态成本？（E635）
- **Q15（元动作空间）**：把离散决策统一为带类型的半 MDP 动作空间，能否在不损成功率的前提下降低步骤与动作抖动？（E636 / E637）
- **Q16（长程 / 形变的前瞻 · 悬置）**：若任务分布向装配 / 折叠漂移（F4 的预训练信号），ST-Scene 是否需要显式「进度变量」、元动作是否需要有序子目标结构？——**本轮不承诺，只登记观测口径**。

## 3. 设计原则（新增 P13–P15，接 P1–P12）

- **P13（按执行时刻估计）**：断言与设定点一律消费预测到执行时刻的状态；预测不可信（NIS 门限不过）时**膨胀协方差并标记不确定**，绝不用过期点估计配过期协方差。（P10 的时间维强化）
- **P14（离散决策即动作空间）**：主循环里不允许无类型触发器；每个离散决策都是声明了 `pre/eff/d/c` 的元动作，未知情形默认 `CONTINUE`。
- **P15（承诺与滞回）**：元动作启动后跑到达成条件或最短承诺时长；提前切换需接触类硬安全前置。用承诺换防抖，用滞回换稳定。

## 4. 清单处置（深化 / 修剪 / 新增）

- **新增**：**IP-16 ST-Scene**（P0，时间维）、**IP-17 MetaActionSpace**（P0/P1，决策层）。
- **深化**：IP-13 的空间图作为 IP-16 的空间内核（SceneGraph）并入，不重复；IP-15 的响应状态机成为 IP-17 的「干扰元策略实例」；IP-02 的介入选择并入 IP-17，抓握确认与低层介入原语保留；IP-14 的探测、IP-10 的前瞻统一为 `PROBE/COAST` 的可采纳性问题；IP-09 断言升级为执行时刻断言（U20）；IP-04 的 FiLM 输入加入速度 / 预测不确定度 / 遮挡时长；IP-06 失败分解新增「时序因子」（延迟超阈 / 抖动 / 滑行失败 / 预测失配）。
- **修剪**：不再为每个干预单独写触发逻辑（全部收敛进 IP-17）；第 3 轮 IP-15 的「遮挡 → 保持」被 COAST 替换为默认分支，「保持」降为兜底。
- **MVP 不变**：IP-06 + IP-02 + IP-09 + IP-03 + 通用基线；**IP-17 可独立于 IP-16 先落地（纯规则重构）**，IP-16 为动态/干扰轴的定向增强。
- **退化链更新**：新增 **Level-1.7：预测不可信 → 冻结为「过期快照 + 膨胀协方差 + HOLD」**；**Level-1.8：元动作空间异常 → 仅保留 {CONTINUE, YIELD} 的最小安全集**。

## 5. 本轮最大风险

**运动模型失配导致「自信地预测错」**：恒定速度模型遇到人的脉冲式推挤、形变物体的非刚体动力学时，预测可能比过期快照更糟——恰好在本轮最想赢的动态场景里放大误差。对冲：①IMM 静态 / 机动双模 + NIS 新息门限（门限不过即拒绝预测，退 Level-1.7）；②预测时域 Δ 有上界（只预测短窗）；③协方差膨胀保证断言「宁拒不误到」；④COAST 有硬超时，超时转 RELOCALIZE。次要风险：动作空间过度设计 / 策略过拟合 → 规则优先、动作集最小化、默认 CONTINUE、只用回放做回归测试。

**一句话最大风险：本轮把「时间」引入状态层，代价是——一个预测错误但协方差很自信的运动模型，会比一张过期照片更危险。**

## 3. 新增 IP 详述

### IP-16 · ST-Scene 时空状态层（P0，新）

- **动机**：IP-13 是「现在在哪」的照片，但动作在 `t+Δ` 执行；L14 证明用过期估计做断言会系统性抬高误拒率，调 α 救不回来。F4 的新数据（装配 / 折叠）进一步说明长程、带时序的任务在增长。
- **与现有方案差异**：在 U16 场景图上加运动状态与预测；断言评估时刻从观测时域改到执行时域；数据关联用预测位置做马氏门控；遮挡响应从 HOLD 升级为有限 COAST。**无新大模型**：EKF/IMM + NIS 门限 + 沿用 IP-13 的检测器。
- **技术可行性**：高。EKF / 交互多模型 / NIS 一致性检验都是成熟件；预测时域只需覆盖控制延迟（短窗），计算量小。
- **资源**：数据 = 官方回放做运动/失配标定；算力 = 小（低频检测 + 轻量滤波）；接口 = 无新增字段（全部策略内部，合规安全）。
- **落地步骤**：①U16 加 `[p,v]` 与过程噪声 `Q` 标定；②IMM（静态 / 匀速）双模 + NIS 新息门限；③U20 执行时刻断言接 IP-09；④预测关联接 IP-13 的数据关联；⑤COAST 接 IP-15 的遮挡分支；⑥E634 / E635。
- **风险**：运动模型失配（NIS + Level-1.7）；Δ 过大时预测无用（时域上界）；动态任务覆盖不足导致收益集中。

### IP-17 · MetaActionSpace 元动作空间 + 半 MDP meta-policy（P0/P1，新）

- **动机**：v3 的离散决策散落为主循环触发器，导致两种病——抖动（HOLD/RELOCALIZE 快速来回切）与不可比（重定位 / 重启 / 探测各自拍脑袋）。动作空间把「做什么、做多久、值不值」显式化。
- **与现有方案差异**：类型化 option 集 + 统一步数代价 `c(a)` + 承诺 / 滞回 + 默认 CONTINUE；不改连续动作层（VLA chunk 仍是 CONTINUE 内部的 primitive）。
- **可行性**：高，纯规则重构；可完全独立于 IP-16 先落地，风险隔离。
- **资源**：近零训练；复用 IP-02/14/15 的既有逻辑，只是改造成带类型的动作。
- **落地步骤**：①定义 U21 动作表（pre/eff/d/c）；②实现 option 执行器（承诺时长 + 终止条件）；③替换主循环触发器；④`c(a)` 从日志拟合，接一步前瞻 meta-policy（E636/E637）；⑤保留规则 / 学习的统一策略接口。

## 5. 符号与定义（新增 U19–U21；U1–U18 沿用第 1–3 轮）

- **定义 U19（运动增广场景状态 / ST-Scene）**：每物体 `s_k(t)=[p_k(t), v_k(t)]`，动态 `s_{t+1}=F s_t + w, w~N(0,Q)`；预测 `ŝ_k(t+Δ|t)=F(Δ)ŝ_k(t|t)`、`Σ_k(t+Δ|t)=FΣFᵀ+Q(Δ)`。场景图 `M(t)=(T(t),D(t),F)` 在 U16 上增加每股轨迹的时间戳、运动模式与协方差。
- **定义 U20（执行时刻断言）**：路标通过 ⇔ `d²=(ŝ(t+Δ)−g_i)ᵀΣ(t+Δ)⁻¹(ŝ(t+Δ)−g_i) ≤ χ²_{d,α}`；另含时序谓词 `within(deadline)`、`progress_rate ≥ ρ`、`no_progress(window)`。Δ 为观测到执行的时延；Δ 不可知或超界时按 Level-1.7 处理。
- **定义 U21（元动作 / option）**：`a=(type, params)`，`type ∈ {CONTINUE(ℓ), HOLD(τ), COAST(τ), RELOCALIZE, REGRASP, REALIGN, SWITCH_GEN, PROBE, YIELD}`，每项含 `pre(a)`、`eff(a)`、时长 `d(a)`、期望步数代价 `c(a)`；元策略 `π_meta(S_t)→a`，承诺期 `τ_min`。由 U21 诱导的决策过程为半 MDP，其值满足 option Bellman 式。

## 6. 关键算法骨架（新增片段；主体沿第 1–3 轮 `UniBotSAGEPolicy`）

```python
# ===== IP-16: 时空场景状态（运动增广 EKF/IMM + 执行时刻查询）=====
class STScene:
    def __init__(self, task_token):
        self.tracks = {}            # id -> {mu:[p,v], Sigma, mode, t_last}
        self.frame = None

    def predict(self, dt):
        for tr in self.tracks.values():
            F, Q = motion_model(tr.mode, dt)          # IMM: static / constant-velocity
            tr.mu = F @ tr.mu
            tr.Sigma = F @ tr.Sigma @ F.T + Q(dt)

    def update(self, obs):
        dets = self.detector(obs.head)
        tr = self.associate(dets, gate="predicted")   # 按预测位置做马氏关联
        nu = tr.z - H @ tr.mu                          # 新息
        nis = nu.T @ inv(H @ tr.Sigma @ H.T + R) @ nu
        if nis > NIS_GATE:                             # 模型失配 → 拒绝预测
            tr.mode = "maneuver"; inflate(tr.Sigma, K_INFLATE)
        tr.mu, tr.Sigma = ekf_update(tr.mu, tr.Sigma, dets)

    def state_at(self, t_exec):
        dt = max(t_exec - self.t_now, 0.0)
        return predict_to(self, min(dt, DT_MAX))       # U20: 只在短时域外推
```

```python
# ===== U20: 执行时刻卡方断言（替换 U17 的观测时刻断言）=====
def assert_waypoint_exec(wp, scene, latency):
    t_exec = now() + latency
    x, S = scene.state_at(t_exec), scene.cov_at(t_exec)
    d2 = x.T @ inv(S) @ x
    if d2 <= chi2_ppf(wp.dim, ALPHA):       return True     # 执行时刻误拒率 = ALPHA
    if d2 > chi2_ppf(wp.dim, ALPHA_FAIL):   return False    # 高置信未到 → 交 IP-17
    return None                                             # 不确定 → COAST/HOLD
```

```python
# ===== IP-17: 元动作空间 + 半 MDP meta-policy（承诺/滞回）=====
META = ("CONTINUE", "HOLD", "COAST", "RELOCALIZE",
        "REGRASP", "REALIGN", "SWITCH_GEN", "PROBE", "YIELD")

def admissible(a, S):
    if a.type == "YIELD":  return S.contact                        # 硬安全门控
    if a.type == "COAST":  return S.occluded and within_tol(S, a.tau)  # L16
    if a.type == "PROBE":  return P12_break_even(S) and S.phase in PROBE_WHITELIST
    return pre(a, S)

def meta_policy(S, engaged):
    if engaged and not terminated(engaged, S):                     # P15 承诺：先跑完
        return engaged
    cand = [a for a in expand(META, S) if admissible(a, S)]
    return min(cand, key=lambda a: Q(a, S), default=CONTINUE(S))   # L15: 统一 Q 比较
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（过期断言的偏差律）** 设执行时刻真实位置 `p(t+Δ)=p(t)+vΔ+ε`，过期断言使用 `x̂(t)~N(p(t),Σ)`。在「执行时刻已到点」的零假设下，统计量服从非中心 χ²，非中心参数 `λ=(vΔ)ᵀΣ⁻¹(vΔ)`（`ε` 的贡献并入过程噪声），故误拒率 `P(χ²_d(λ)>χ²_{d,α})>α` 且随 `λ` 单调上升；对任意固定 α，总存在速度 `v` 使校准失效。预测 `ŝ(t+Δ)` 在运动模型正确时消去 `vΔ` 的确定性均值项，残余非中心性来自过程噪声 `tr(Q(Δ)Σ⁻¹)`，故期望校准误差不劣于过期快照；模型错误时 `λ_pred` 可反超过期方案 ⇒ 必须用 NIS 门限切换（Level-1.7）。∎

**引理 L15（option 价值与承诺的良定义性）** 设每个元动作时长 `d(a)>0`、代价 `c(a)≥0`。若允许每步任意切换，近视策略可在 `a→b→a…` 间循环而状态无进展，代价每轮累加、价值不变，界可任意大——即离散层无良定义。施加承诺 `τ_min ≥ min_a d(a)`、且仅在 option 自身终止集内终止后，每个完成的 option 要么推进进度变量、要么终结 episode，诱导链为半 MDP，值满足 `V(s)=min_a{c(s,a)+E[V(s')]}`。⇒ 承诺不是启发式，而是使离散决策问题良定义的必要条件。∎

**引理 L16（遮挡滑行的盈亏）** 遮挡期望时长 `h`：HOLD 花费 `h` 步（且可能被新干扰打断）；COAST 花 0 个额外步，成功条件为预测误差在 `τ≤h` 内不超容差 `τol`，可近似为 `tr(Σ(t+τ|t)) ≤ τol²`。故 COAST 可采纳 ⇔ 预测协方差在容差内；否则应 HOLD / RELOCALIZE。推论：当 `h>0` 且预测成立时 COAST 严格优于 HOLD；当预测协方差超容差时退化为 HOLD。∎

**一句话最大风险：本轮把「时间」引入状态层，代价是——一个预测错误但协方差很自信的运动模型，会比一张过期照片更危险。**
