## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1（本体感知 → 被浪费的稠密物理通道）

**直觉解释**：过去两轮把本体感知当成 VLA 的一个普通输入特征，真正的用法被漏掉了。评测在真机上、有接触、有人手干扰、没有力/触觉（F8），而本体感知恰好是唯一直接感知「接触、打滑、卡住、被人推、跟丢」的通道。关键不是「多喂 43 维状态」，而是把本体感知看成**指令与现实的残差**：策略发出动作，机器人执行后回报真实状态；两者之差就是物理世界对策略的「惊讶」。这个残差不需要新传感器、不需要新模型、不需要真机训练，却是接触与干预的天然探测器。更进一步，把当前本体状态投影到示教流形上，可以得到**任务相位与进度**——在遮挡和接触段，它比视觉进度头更稳。

**严谨定义**：令本体状态 \(s_t=[q_t,e_t,g_t,b_t]\in\mathbb{R}^{43}\)（14 臂关节 + 12 末端位姿 + 2 夹爪 + 15 下体），时间栈 \(S_t=[s_{t-h},\dots,s_t]\)。定义一步残差

\[
r_t=s_{t+1}-f_\psi(S_t,a_t),
\]

其中 \(f_\psi\) 是离线示教上训练的轻量前向模型；冷启动可退化为运动学参考残差（joint 模式 \(r_t=q_{t+1}-q^{cmd}_t\)，ee 模式 \(r_t=e_{t+1}-e^{cmd}_t\)）。用每 episode 前若干自由空间步做逐维标定，得到归一化事件分数

\[
z_t=\|(r_t-\mu_0)\oslash\sigma_0\|_2 .
\]

用 CUSUM + 滞回判定事件 \(E_t=\mathbb{1}[z_t>\tau]\)，并按残差方向/频率/相位联合分类为接触起始、打滑、卡住、外部干预、标定漂移。定义相位 \(\phi_t\) 为当前状态在示教流形上的最近邻归一化进度，偏离告警为「到示教流形距离超阈」或「相位回退」。这套「本体感知残差-相位监视器」（PRPM）是零样本、低延迟、单模型内的运行时组件。

### 灵感 2（评测基准 → 排行榜是小样本统计估计，不是单次成功率）

**直觉解释**：排行榜不是「跑一次看成功率」，而是一个**小样本设计实验**：32 任务 × 10 次，且 10 次 = 5 类泛化 × 2。每个泛化轴只有 2 个样本，单任务只有 10 个样本。大多数队伍把「平均成功率」当点估计来优化，忽略了方差、相关性和排名。正确的问题是：在固定真机预算下，怎样最大化**排名提升的概率**，而不是最大化某个不可靠的均值。更反直觉的是：由于主指标是成功率、步骤分只在平局时起作用，**把 0% 变成 10% 的成功率提升，通常比把 70% 步骤分打磨到 85% 更值钱**——除非成功率已经饱和、平局概率很高。评测基准的结构本身就在告诉你钱该花在哪。

**严谨定义**：令 \(X_{t,a,r}\in\{0,1\}\) 为任务 \(t\)、泛化轴 \(a\)、第 \(r\in\{1,2\}\) 次是否成功，\(p_t=\frac{1}{10}\sum_{a,r}X_{t,a,r}\)，总分 \(S=\frac{1}{32}\sum_t p_t\)。在独立近似下

\[
\mathrm{Var}(S)=\frac{1}{32^2}\sum_t \frac{p_t(1-p_t)}{10}.
\]

当 \(p_t=0.3\) 时 \(\mathrm{SD}(S)\approx 2.56\) 个百分点；而单任务 \(n=10\) 的 95% 置信区间半宽约 \(\pm28\) 个百分点，单轴 \(n=2\) 约 \(\pm63\) 个百分点。也就是说：**单任务/单轴的 A/B 几乎没有统计功效，只有聚合指标才可读**。因此定义分层贝叶斯模型

\[
\mathrm{logit}(p_{t,a})=\mu+u_t+v_a+w_{t,a},\quad
u_t\sim N(0,\sigma_u^2),\ v_a\sim N(0,\sigma_v^2),\ w_{t,a}\sim N(0,\sigma_w^2),
\]

用部分池化借跨任务/跨轴信息估计每个格子的后验；再定义排名概率 \(P(\mathrm{rank}\le k)\) 与「期望排名提升」

\[
\mathrm{ERI}(T,\delta)=\mathbb{E}[\mathrm{rank}(S)]-\mathbb{E}[\mathrm{rank}(S+\delta\mathbf{1}_T)],
\]

把真机预算分配给 ERI/成本最高的任务集合。A/B 采用配对公共随机数 + 分层抽样（5 轴 × 2），报告后验 \(P(\Delta>0)\) 与配对置信区间，而不是裸增益。

### 统一：稠密信号 ↔ 统计功效

本体感知把「稀疏的二值成功」变成「稠密的物理过程」（接触时刻、相位误差、残差异常率、恢复延迟）；评测基准统计告诉你这些稠密信号该投到哪些任务/轴上、以及多小的差异才值得信。两者合起来是一个**测量学命题**：这场比赛的中期胜负手，不只是数据引擎，而是**谁能用更少真机样本测出更可信的物理改进**。本体感知提供低成本高密度观测，评测统计提供决策规则——这是本轮的主线。

## 2. 对第 2 轮痛点的增量修订

- P2（泛化缺口）细化：5 轴 × 2 的抽样结构（F21）意味着单轴估计极不稳定；增广与调参应优化聚合成功率，不应过拟合单轴。
- P4（无触觉）降级：本体残差不是力传感器，但能给出接触起始/打滑/卡住的**事件签名**，可作为「虚拟接触通道」；I3 不再必须依赖独立几何伺服。
- P5（时间压力）补充：接触起始可被残差提前检测，恢复触发从「视觉发现失败」提前到「物理事件发生」，为长任务抢回步骤分。
- P7（先手窗口）补充：平局规则最后比提交时间（F21），早提交有真实期权价值；先手窗口不仅是模型先手，也是**评测数据先手**。
- P8（示教质量）补充：质量分加入「接触一致性」（残差能否解释接触段）与「相位单调性」。
- 新增 **P9（评测统计功效不足）**：单任务/单轴 A/B 欠功效，裸增益不可读；这是比真机排期更隐蔽的浪费。
- 新增 **P10（跨机器人标定漂移）**：残差阈值随机器人/底层控制器漂移，若漂移大于接触信号，PRPM 会系统性误报。

## 3. 研究问题（本轮立项 Q9–Q12，Q1–Q8 保留）

- **Q9（残差可信度）**：最小充分的前向模型/运动学参考是什么？每 episode 无标签标定能否把跨机器人漂移压到接触信号以下？误报率/漏报率在 32 任务上的分布如何？
- **Q10（本体相位）**：本体流形投影估计的进度与官方步骤分/视觉进度头的一致性有多高？在遮挡与接触段是否更稳？相位回退能否作为恢复的充分触发？
- **Q11（排名统计）**：在 n=10/任务、n=2/轴、N 台机器人的结构下，分层贝叶斯 + ERI 能否比「平均成功率点估计」更可靠地选出真机 top 候选？离线稠密代理与官方聚合分的相关性何时达到可替代 L2 的阈值？
- **Q12（孪生指纹）**：本体技能指纹（相位归一化轨迹 + 接触时序 + 夹爪剖面）能否比语言语义相似度更好地预测正/负迁移，从而修正第 2 轮的孪生表？

## 4. 设计原则（新增 PR6/PR7，其余保留）

- **PR6 本体感知优先律**：在新增任何视觉/几何/世界模型模块前，先问「现有本体感知的残差或相位是否已经回答了它」。本体感知是物理事件的第一性传感器，视觉是语义确认。
- **PR7 排名目标律**：每个实验必须报告它对「排名提升概率」的影响，而不只是平均增益；主目标成功率、次目标步骤分；单任务/单轴结果默认只作定性信号，不作放量依据。
- PR1–PR5 保留（第 1/2 轮）。

## 6. 本轮最大风险

**一句话**：I10 的残差阈值依赖每台机器人的底层控制器与装配标定，若跨机器人漂移大于接触/干预信号，PRPM 会把标定误差误判为物理事件；而官方每轴只有 2 次样本（F21），这种系统性误报在评测中既难被统计发现、又会直接破坏恢复与干预逻辑——这是本轮必须先做跨机器人零样本标定验证、再上计分通道的点。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 v3 考纲校准五轴增广引擎 ★★★★★
- **动机**：泛化缺口是全局乘性损失；第 2 轮已把增广从「盲目随机」升级为「按考纲校准」，本轮再补两件事。
- **本轮深化**：①**5×2 分层增广**——官方每任务 10 次 = 5 类泛化 × 每类 2 次（F21），增广也按同样分层生成，使离线集与官方评测同构，而不是 i.i.d. 随机；②**本体物理可行性过滤**——增广后的场景若隐含不可达位姿、物体悬浮/穿插、夹爪开合不可能，用运动学/几何检查直接剔除（与 I10 的残差先验共用）。
- **与现有方案差异**：直接 SFT 用标称数据；盲目增广用无校准随机化；本点按官方分层出模拟题，并过物理可行性闸。
- **技术可行性**：高。32 张考纲卡（LLM 解析 wiki + 人工校对）沿用第 2 轮；分层采样器与物理过滤器各约 2 人日。
- **所需资源**：分割/inpainting 1×24GB GPU；磁盘同 v1.1。
- **落地步骤**：①32 张考纲卡；②分层采样器（轴内剂量 × 轴间组合）；③物理可行性过滤；④L0 剂量-响应；⑤轴间 2 档析因；⑥单任务通道抽测。
- **风险**：考纲卡与真实评测仍有偏差；物理过滤过严会删掉「难但可行」的样本——保留 5% 灰区做对照。

### I2 v3 数据引擎 2.0：孪生迁移 + 加权共训 + 本体指纹 ★★★★★
- **动机**：第 2 轮最大风险是「语义孪生负迁移」（如 ZipUp 与 Unzip 拉链受力方向相反）；语言相似不等于物理可迁移。
- **本轮深化（新增 Q12）**：给每个任务算一个**本体技能指纹**：相位归一化后的关节/末端轨迹 + 接触区间时序 + 夹爪开合剖面；用 DTW 距离 + 接触时序差 + 速度符号一致性定义迁移分数。语义孪生若物理指纹距离大或速度符号相反，降权/剔除；物理指纹相近但语义不同的任务可补入。质量分同时加入「接触一致性」与「相位单调性」。
- **与现有方案差异**：语义孪生表只看任务名/语言；本点用物理执行签名做二次校验，直接针对负迁移。
- **技术可行性**：高（指纹在示教上离线计算；采样器沿用第 2 轮 patch）。
- **所需资源**：指纹计算 1×GPU 日；数据同 v1.1。
- **落地步骤**：①32+110 任务指纹；②语义孪生表 × 指纹矩阵；③冲突项人工抽检；④加权采样器（32 全量 + 指纹孪生半权重 + 远任务 ≤5%）；⑤族级 L0 正/负迁移；⑥放量。
- **风险**：指纹只覆盖运动学、不覆盖语义可供性；用「语义 × 指纹」双门控，任一不过则降权而非直接删。

### I3 v2 接触任务族：PRPM 触发的同模型接触模式 ★★★★
- **动机**：无触觉（F8）时接触段最易失败；第 2 轮用独立几何伺服回退，但存在「单模型边界」合规风险（PR2）。
- **本轮深化**：主路径改为**同一个 VLA 的相位/模式条件化**——PRPM 检测到接触起始后，把 `mode="contact"` 与相位 `φ` 作为条件嵌入动作专家，让同一模型切换到接触段行为；独立几何伺服降为 I3' 训练时辅助监督/离线回退，不再作为推理期第二模型。这样既保留接触段先验，又把 PR2 风险降到最低。
- **技术可行性**：中-高。条件嵌入是小改；接触段数据由 PRPM 自动标注。
- **所需资源**：1×24GB GPU；条件嵌入与训练 3–5 人日。
- **落地步骤**：①PRPM 接触标签；②相位/模式嵌入；③接触段上采样；④L0 接触段误差；⑤单任务通道 A/B（I3' 作对照）。
- **风险**：PRPM 误报导致错误切换——用滞回 + 视觉确认 + 低置信回退；接触段数据不足时先只做辅助监督。

### I4 v2 人手干预感知门控 + 自适应 chunk ★★★★
- **动机**：人手干扰是明确评测条件；纯视觉手检在遮挡/快速动作下漏检。
- **本轮深化**：干预判别 = 视觉手检 **OR** 本体残差突变（外部推力不在动作解释范围内）。残差给出 <50ms 的快速触发，视觉给出语义确认；状态机 INTERFERED→停持→重估→续做不变。干预态 chunk 4–6 步、稳定态 8–16 步（F12 参照）。
- **技术可行性**：高；复用 I10。
- **所需资源**：低。
- **落地步骤**：①残差干预特征；②视觉+残差融合规则；③误报/漏报离线评估；④真机 A/B。
- **风险**：残差误报导致频繁停持；用「双通道确认」与保守阈值，标称场景零误报优先。

### I5 v3 非标称示教合成 + 得分点对齐恢复 ★★★★
- **动机**：数据集全成功、无失败示教；恢复能力只能靠合成「偏离→修正」。

- **技术可行性**：中-高；数据工程为主。
- **所需资源**：1×24GB GPU；2 人周。

### I6 v2 确定性低延迟部署服务 ★★★★

### I10 v1 本体感知残差-相位监视器（PRPM）（新）★★★★★
- **动机**：无触觉/力通道（F8），但真机接触、打滑、卡住、人手干预都需要一个物理事件探针；本体感知是免费、稠密、低延迟的唯一候选。
- **核心定义**：
  - 状态 \(s_t\in\mathbb{R}^{43}\)（14 臂关节 + 12 EE 位姿 + 2 夹爪 + 15 下体），时间栈 \(S_t\)；
  - 残差 \(r_t=s_{t+1}-f_\psi(S_t,a_t)\)，冷启动用运动学参考残差；
  - 逐 episode 自由空间标定 \(\mu_0,\sigma_0\)，事件分数 \(z_t=\|(r_t-\mu_0)\oslash\sigma_0\|_2\)；
  - CUSUM + 滞回判事件；残差方向/频率/相位分类为接触起始、打滑、卡住、外部干预、标定漂移；
  - 相位 \(\phi_t\) 为示教流形最近邻归一化进度；相位回退/流形距离超阈 = 偏离告警。
- **与现有方案差异**：别人把本体感知当输入特征；本点把它当「指令-现实残差」的物理事件信号，且同时服务 I3/I4/I5/I6/I8，不新增独立大模型。
- **技术可行性**：高。冷启动零训练（运动学参考 + 标定）；前向模型只是小型 MLP/GRU。
- **所需资源**：前向模型 1 GPU 小时；相位库离线；1 人周工程。
- **落地步骤**：①运动学参考残差 + 每 episode 标定；②CUSUM/滞回；③相位最近邻；④事件分类器；⑤与 I3/I4/I5/I6 联调；⑥跨机器人误报率评估。
- **风险**：跨机器人标定漂移 > 接触信号（本轮最大风险）；接触段起始即接触的任务无法用自由空间标定——用任务级示教先验；低层控制器滞后造成假残差——用一步延迟对齐 + 低通。

### I11 v1 面向排名的评测基准统计层（ROE）（新）★★★★★
- **动机**：官方 32×10、5 轴 ×2（F21）是小样本设计；裸平均成功率不可读，单任务 A/B 欠功效；排行榜平局还看步骤分与提交时间。
- **核心定义**：
  - 分层贝叶斯 \(\mathrm{logit}(p_{t,a})=\mu+u_t+v_a+w_{t,a}\)，部分池化估计每任务/轴后验；
  - 排名概率 \(P(\mathrm{rank}\le k)\)（自身后验 × 竞争者分数分布）；
  - 期望排名提升 \(\mathrm{ERI}(T,\delta)\) 作为预算分配目标；
  - 词典序目标：先最大化成功率，步骤分只在平局概率高/成功率饱和时优化；
  - 配对公共随机数 + 5 轴分层，报告 \(P(\Delta>0)\) 与配对 CI；
  - 污染守卫：留出任务/轴，公开示例只用于校准、不用于模型选择。
- **与现有方案差异**：别人优化均值点估计；本点优化排名概率，并把「统计功效」作为实验设计的一等公民。
- **技术可行性**：高（NumPyro/PyMC + 蒙特卡洛排名模拟）。
- **所需资源**：1 人周；CPU/单 GPU。
- **落地步骤**：①分层模型；②排名模拟器；③ERI 分配器；④注册表 schema；⑤历史 L2 回填校准；⑥榜单发布后更新竞争者先验。
- **风险**：竞争者分布未知（先用「榜首 <30%」的保守先验 + 敏感性分析）；官方只给聚合分时，分层模型的观测粒度不足——用任务/轴先验与单任务通道补数据。

### I7 裁撤说明（原「世界模型测试时前瞻」）
- **裁撤理由**：①部署预算——15Hz/66ms（F12）下 O(1–2) 次视频 rollout 无法稳定满足 p99<40ms；②统计上——ROE 显示成功率转换的边际收益远高于「高险节点择优」；③资产复用——WMA-0 的仿真模式转入 I5 合成示教数据引擎，不作为推理路径。**裁撤不等于废弃。**

### 1.1 PRPM：残差 + 相位 + 事件分类

```python
class ProprioceptiveMonitor:
    def __init__(self, fwd_model, demo_bank, cfg):
        self.fwd = fwd_model          # 离线示教训练；冷启动用运动学参考
        self.bank = demo_bank         # 每任务相位归一化本体轨迹
        self.cfg = cfg

    def reset(self, task, robot_id):
        self.task = task
        self.calib = load_calibration(task, robot_id)   # 逐维 mu/sigma
        self.cusum = 0.0
        self.phase_max = 0.0
        self.mode = "approach"

    def update(self, obs_hist, act_hist):
        s = pack_state(obs_hist[-1])                    # 43 维
        s_hat = self.fwd(obs_hist, act_hist)            # 或运动学参考
        r = s - s_hat
        z = mahalanobis(r, self.calib)                  # 逐维标准化
        self.cusum = max(0.0, self.cusum + z - self.cfg.mu0 - self.cfg.k)
        phi, conf = project_phase(s, self.bank[self.task])   # DTW / NN
        regress = phi < self.phase_max - self.cfg.eps
        self.phase_max = max(self.phase_max, phi)
        event = classify_event(z, self.cusum, r, phi, conf, regress)
        return Event(z=z, phi=phi, conf=conf, **event)
```

## 6. 本轮最值得押注（一句话）

**押「本体感知 × 评测统计」这对测量学组合：I10 把本体残差变成接触/干预/相位的稠密标签，I11 把这些标签变成小样本下可信的排名决策；在官方 32×10、5×2 的结构下，先解决「测得准」，再谈「训得强」。**

## 7. 本轮最大风险（一句话）

**PRPM 的残差阈值若被跨机器人标定漂移主导，系统性误报会同时污染恢复、干预与离线代理，而 n=2/轴的官方评测又几乎无法用统计发现它——所以先做跨机器人零样本标定验证，再让它碰计分通道。**
