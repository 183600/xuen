# 第 43 轮（新循环第 3 轮） · 证伪优先的力矩见证与数据质量门控（FF-TWDQ）：让新传感器与新数据只当「守门人」，不当「背书人」（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」，二者同源：**评价者与被评价者共享同一套模型与数据**，于是证书在最需要被质疑的地方最自信。本轮灵感词「力矩传感」「数据质量」给出的不是又一层更强的生成模型，而是一条**认识论上的转向**：新传感器与新数据不应被用来「证明安全」，而应被用来「证伪安全」。力矩残差是物理世界的测谎仪，数据质量是证据的会计学；二者都只获得**否决权**（一票否决），不获得**背书权**（不能单独证明安全）。这把 v19 的「自评飞轮」改造成「他证飞轮」：先把不安全的、不可信的、模型不成立的样本与状态剔除，再在剩下的证据上发证。核心原则一句话：**负信息可以是 sound 的，正信息永远只是经验**。

## 0. 直觉与动机

### 灵感 1（力矩传感 → 证书的物理测谎仪，但只能证伪）

直觉：一张安全证书本质上是一个条件句——「若模型正确、无意外接触、执行器健康、状态估计误差在界内，则系统不会越界」。v19 把大量精力花在**后件**（边际、阈值、保持时间），却几乎不检查**前件**。力矩传感恰好是检查前件最便宜、最直接的物理通道：关节力矩是广义力，在自由空间且模型正确时，广义动量观测器的残差应≈0；一旦残差持续偏离，就说明发生了意外接触、负载突变、摩擦/间隙变化、执行器退化或模型失配。它不看光照、不依赖纹理，与视觉/激光的失效模式**正交**。

但关键的反转是：**力矩模型本身也不可信**。若把力矩残差当作「真值」去证明安全，只是把 v19 的模型自证换了一个传感器继续自证。因此力矩见证只做一件事：当残差超界、力矩裕度耗尽、热/功率越限、饱和异常时，**立即吊销证书**；当它一切正常时，**不给出任何安全结论**。这是形式化方法里的 witness 语义——见证的是「违例」，不是「正确」。安全性只要求这个见证**不漏报**（高召回）；它的误报只影响可用性（可调）。这个不对称性，是整轮设计的支点。

### 灵感 2（数据质量 → 证书的「证据会计」，而不是预处理）

直觉：v19 的 KB 把所有轨迹一视同仁地喂给 W_1 估计与 RAG；但一条时间戳错位 20ms 的轨迹、一次关节零位标定漂移、一段只覆盖平地却声称覆盖楼梯的数据，会以「高相似度」被检索、被合并、被发证。数据质量不是清洗脚本，而是**证书的证据属性**：证书的置信度必须显式扣除「证据有多脏、多少、是否独立、是否过期」。

我们把数据质量拆成六维：覆盖（coverage）、准确/标定（accuracy）、同步（sync）、独立/多样性（diversity）、来源/可追溯（provenance）、对抗有效性（adversarial validity）。更重要的两条原则：

1. **质量是下界，不是点估计**：Q 取置信下界，只允许它让证书更保守，不允许它让证书更激进；
2. **质量只否决，不背书**：Q < Q_min 的数据不能进 KB、不能参与合并；Q ≥ Q_min 只表示「可以考虑」，不表示「可以相信」。

为了让「否决」既可证又不饿死系统，我们用保形风险控制（conformal risk control）校准 Q_min 与力矩阈值，使「漏放坏数据/漏检真故障」的概率被显式限住，再在此约束下最小化误否决率（最大化可用性）。这把「质量—可用性」从拍脑袋 trade-off 变成一个带风险预算的约束优化。

### 灵感 3（耦合 → 力矩是数据质量的物理锚点，数据质量是力矩见证的可信度）

力矩残差可以审计数据：时间戳错位会在加速段制造与 q̈ 相关的伪残差；关节零位/质量参数错误会在静态重力姿态暴露；接触标签错误会让自由空间段出现残差尖峰；仿真与实机的摩擦/惯量差异会表现为「力矩 gap」。反过来，数据质量决定我们能在多大程度上相信力矩见证：标定过期、传感器饱和、采样丢帧时，残差界必须自动放宽，见证自动降级为「不可用」而不是「正常」。

于是闭环变成 **Falsify → Quantify → Gate → Certify → Re-falsify**：力矩残差找缺陷 → 数据质量量化缺陷 → 质量门控只放行干净证据 → 在干净证据上发带证据下界的证书 → 运行时力矩见证继续否决 → 在残差热点主动采集新数据。注意这里没有「用数据证明模型、再用模型证明数据」的闭环自证：我们强制引入**独立三角验证**（关节力矩传感器、电流估计力矩、IMU/触觉/外部标定），三者不一致时只能降级，不能互相背书。

### 为什么不是「再加一层更强的模型」

v19 已经不缺模型，缺的是**诚实的失败面**。本轮新增的两个通道都刻意做成廉价、单向、可证伪：力矩见证 O(n_j) 每拍、T-2 档 <20μs；数据质量大多离线计算，在线只维护滑窗统计。它们不提升「能做什么」，只提升「什么时候必须承认自己不知道」。

## 1. 形式化定义（增量：定义 38–45）

**定义 38（广义动量观测器与力矩残差）**：对 n 关节系统，令 p = M(q)q̇，构造

  \dot{\hat p} = τ_m + Cᵀ(q,q̇)q̇ − g(q) + r_τ,  \dot r_τ = K_o(p − \hat p),  \hat p(0)=p(0).

残差 r_τ 经带宽 K_o 低通后逼近外部广义力与模型误差之和。健康自由空间下要求

  ‖r_τ(t)‖ ≤ ε_τ(t) ≜ ε_model(x) + ε_sensor + ε_disc + ε_obs(K_o).

其中 ε_model 由质量/惯量/摩擦参数不确定度经区间传播给出，ε_sensor 由力矩传感器噪声/漂移/饱和给出，ε_disc 为离散化误差，ε_obs 为观测器暂态。ε_τ(t) 用健康数据的分位数经保形校准得到，而不是手调常数。

**定义 39（力矩见证与单边契约）**：令执行器安全集

  A_τ = { (τ, P, T) : |τ_j| ≤ τ_j^cont, |\dot τ_j| ≤ \dot τ_j^max, P_j ≤ P_j^max, T_j ≤ T_j^max, 接触力 ∈ 摩擦锥 }.

定义力矩见证

  W_τ(x,u) = [ r_τ 满足定义 38 的界 ] ∧ [ m_τ(x,u) ≥ 0 ] ∧ [ 无饱和/丢帧/标定过期 ],

其中 m_τ = min_j 归一化力矩/功率/热裕度。**单边契约**：

  ¬W_τ ⇒ 证书立即失效（进入 Degraded/SafeStop）；W_τ ⇏ 证书有效。

即 W_τ 是必要条件而非充分条件。**命题 1（证伪器合取仍 sound）**：若 F_1,…,F_k 均满足「违例 ⇒ F_i=false」，则 F=∧F_i 仍是证伪器；若每个 F_i 的漏报率 ≤ α_i，则 F 的漏报率 ≤ Σα_i。误报只增加降级时间，不破坏 soundness。

**定义 40（数据质量证书 DQC 与区域条件质量）**：对数据项/轨迹 ξ 与目标有效域 B，质量向量

  q(ξ|B) = (q_cov, q_acc, q_sync, q_div, q_prov, q_adv) ∈ [0,1]^6,

分别刻画：B 内状态覆盖、标定与力矩一致性、时间同步、有效独立样本数、来源链完整度、对抗/污染检验。取保守下界

  Q_δ(ξ|B) = min_i LCB_{1−δ}(q_i),

并定义质量—偏差契约：若数据集 D 的质量为 Q，则对任意有界证书边际 m，

  |E_D[m] − E_true[m]| ≤ (1−Q)·R_max,

其中 R_max 为边际值域。Q=1 表示在标定范围内无偏；Q<1 显式地把潜在偏差记入证书。**质量只能降低置信、不能提高置信**。

**定义 41（物理一致性审计与「坏数据」）**：用三类独立力矩估计——关节力矩传感器 τ_s、电流估计 τ_i、模型预测 τ_m——构造三角残差

  Δ_si = τ_s − τ_i, Δ_sm = τ_s − τ_m, Δ_im = τ_i − τ_m.

静态重力测试、自由空间动量测试、已知负载/推力测试与时间同步互相关共同给出 q_acc, q_sync。定义坏数据事件

  B_ε = { ξ : |\hat m(ξ) − m_true(ξ)| > ε  ∨  接触/标签/时间戳因果错误 }.

质量门控的目标不是「识别所有坏数据」，而是把**漏放坏数据**的概率压到 α_fn 以下。

**定义 42（证据携带证书 ECC）**：证书升级为

  C = (θ, Inv, T_hold, Q_C, W_τ^contract, E, n_eff, δ),

其中 E 为证据集，Q_C 为证据质量下界，n_eff = (Σ_i w_i)² / Σ_i w_i²（w_i 为去相关与质量过滤后的有效权重）。由定义 40 的偏差契约与加权经验 Bernstein 不等式，以概率 ≥ 1−δ：

  m_true ≥ \hat m − (1−Q_C)·R_max − √(2σ̂² ln(3/δ)/n_eff) − 3R_max ln(3/δ)/n_eff.

只有该下界 ≥ θ 的区域才进入 ValidRegion；否则标为 **Unknown**（保守降级），而不是默认为安全。

**定义 43（质量分层检索与最弱环合并）**：KB 记录带 (Q_i, 支持域 B_i, 独立证据组 id)。检索分数

  s(φ,ψ) = sim_φ^a · sim_ψ^b · Q_δ^γ · 1[Q_δ ≥ Q_min] · 1[coverage(x; B_i) ≥ cov_min],

并强制同时返回 Top-k 成功模板与 Top-k 失败/反例。合并时

  Q_C(merge) = min_i Q_{C_i},  ValidRegion(merge) = ∩_i ValidRegion_i ∩ {Q ≥ Q_C},

即取最弱证据环；不允许把低质量模板与高质量模板「平均」成高质量。

**定义 44（保形否决校准与质量—可用性约束）**：给定风险预算 (α_fn, β_fv)，选择力矩阈值 ε_τ 与质量门限 Q_min，使得在标定分布上

  P(¬veto | B_ε) ≤ α_fn  （坏数据漏放率）,
  P(veto | ¬B_ε) ≤ β_fv  （好数据误否决率）,

在满足第一式的前提下最小化第二式（最大化可用性）。用保形风险控制选阈值可给出有限样本保证；分布漂移时用在线保形/加权保形重校准。**这把「质量门控是否安全」本身变成了可验证对象**。

**定义 45（质量门控飞轮与主动采集）**：KB 更新规则：仅当 Q_new ≥ Q_old、通过物理一致性审计、且覆盖 Δ 时才替换；否则进入隔离区。证书重颁时携带 Q_C；运行时若局部质量 Q_t < Q_C 或 W_τ=false，则证书失效（先降级、再重采集）。主动采集的采样分布

  π_acq(x) ∝ (1−Q(x))·R_max(x) + U(x) + λ_n·novelty(x),

其中 U 为证书不确定性（n_eff 小、方差大处），novelty 为与 KB 的语义距离；优先在力矩残差热点、标定漂移区、覆盖空洞处采集。**质量飞轮不允许用「更多低质数据」换「更高置信」**。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-54/55/56/51/52/53/49/50/45/47）

### 2.1 IP-57 TORQUE-WITNESS-AUDITOR（TWA）

1. **广义动量观测器**：浮点离线版用于标定，Q15.16 定点在线版用于见证；残差带通、死区、速度/加速度自适应阈值，避免低速摩擦与高速离散化造成的假阳性。
2. **三角力矩验证与故障归因**：传感器故障、电流环故障、模型失配、意外接触、摩擦/间隙退化五类签名；三路不一致时只允许降级。
3. **见证合约**：只输出 VETO / PASS / UNKNOWN；PASS 不携带任何安全承诺，UNKNOWN 等价于 VETO（缺省保守）。
4. **传感器自身质量**：标定年龄、温漂、饱和、丢帧、带宽；任一不满足 → 见证降级为 UNKNOWN。

### 2.2 IP-58 DATA-QUALITY-CERTIFICATE（DQC）

1. **六维质量向量 + 区域条件质量 + 质量下界**：质量是相对于目标有效域 B 的，不存在「全局高质量数据」。
2. **物理一致性审计流水线**：静态重力、自由空间动量、已知负载/推力、时间同步互相关、三角残差；用外部标定/触觉作为独立锚点。
3. **证据会计**：有效样本数 n_eff、自相关/聚类去相关、偏差契约、质量分层、证据独立性分组。
4. **保形否决校准**：Q_min、ε_τ、覆盖门限；输出质量—可用性 Pareto 曲线；在线/加权保形重校准。

### 2.3 IP-59 QUALITY-GATED-FLYWHEEL（QGF）

1. **KB 准入/隔离/淘汰**：质量门控 + 物理审计 + 版本溯源；低质数据只能进隔离区，不能进证据集。
2. **质量分层检索与最弱环合并**：Unknown 区域不参与 CEGAR 的「已证明」集合；失败反例与成功模板成对检索。
3. **主动采集**：力矩残差热点、覆盖空洞、标定漂移、失败反例优先；激励轨迹（傅里叶/chirp）保证质量/惯量/摩擦参数可辨识。
4. **质量漂移监控**：Q_t 滑窗 + 校准年龄 + 传感器健康 → 证书失效与重颁；质量漂移与分布漂移分开告警。

### 2.1 IP-57 TWA：力矩见证与三角验证

```
# 广义动量观测器（在线定点版见 2.6）
def momentum_observer(q, dq, tau_meas, model, Ko, dt, state):
    p = model.M(q) @ dq
    p_hat = state.p_hat + dt * (tau_meas + model.C(q, dq).T @ dq
                                 - model.g(q) + state.r)
    r = state.r + dt * Ko * (p - p_hat)
    return r, p_hat

def torque_witness(x, u, tau_s, tau_i, model, dqc):
    # 0) 传感器健康是见证的前件；不健康 -> UNKNOWN（等价于 VETO）
    if not dqc.sensor_healthy('torque') or dqc.calibration_age > AGE_MAX:
        return UNKNOWN, 'sensor_unhealthy'

    # 1) 动量残差
    r, _ = momentum_observer(x.q, x.dq, tau_s, model, KO, DT, x.obs_state)
    eps = dqc.epsilon_tau(x, u)          # 保形分位数 + 模型不确定度
    # 2) 三角验证：三路估计不一致不得互相背书
    tau_m = model.inverse_dynamics(x.q, x.dq, x.ddq, u)
    d_si, d_sm, d_im = tau_s - tau_i, tau_s - tau_m, tau_i - tau_m
    tri = triangulate(d_si, d_sm, d_im, dqc.tri_bounds)
    # 3) 执行器裕度
    m = actuator_margin(tau_s, model.tau_cont, model.P_max, model.T_max,
                        model.contact_cone)
    if norm(r) > eps or m < 0 or tri.inconsistent or tri.model_mismatch:
        return VETO, attribute_fault(r, tri, m, x)
    return PASS, 'no_safety_claim'      # 只表示未发现反例
```

```
def attribute_fault(r, tri, m, x):
    # 五类签名：传感器 / 电流环 / 模型失配 / 意外接触 / 摩擦-间隙
    if tri.sensor_fault:        return 'torque_sensor'
    if tri.current_fault:       return 'current_loop'
    if m.thermal_exceeded:      return 'thermal'
    if is_contact_signature(r, x):  return 'unexpected_contact'
    if tri.model_mismatch:      return 'model_mismatch'
    return 'friction_backlash_drift'
```

```
# 保形否决校准：先保证漏放坏数据 <= alpha_fn，再最小化误否决
def calibrate_veto(calib_bad, calib_good, alpha_fn, beta_fv):
    # veto 规则：Q < Q_min 或 r_tau > eps_tau
    # 坏数据漏放条件：Q_bad >= Q_min -> P <= alpha_fn
    Q_min = upper_quantile([d.Q for d in calib_bad], alpha_fn)
    eps_tau = lower_quantile([d.r_tau for d in calib_bad], alpha_fn)
    fv = mean([(d.Q < Q_min) or (d.r_tau > eps_tau) for d in calib_good])
    # 若误否决超预算，优先增加质量分辨率/采样，而不是放宽漏放率
    if fv > beta_fv:
        return {'Q_min': Q_min, 'eps_tau': eps_tau,
                'status': 'COLLECT_MORE_OR_SPLIT_STRATA', 'fv': fv}
    return {'Q_min': Q_min, 'eps_tau': eps_tau, 'status': 'OK', 'fv': fv}
```

```
# 证据下界（加权经验 Bernstein + 质量偏差契约）
def evidence_lower_bound(margins, weights, Q_C, R_max, delta):
    w = normalize(weights)
    n_eff = 1.0 / sum(w_i**2 for w_i in w)       # = (Σw)²/Σw²
    m_hat = sum(w_i*m_i for w_i,m_i in zip(w,margins))
    sigma = weighted_std(margins, w)
    conc = sqrt(2*sigma**2*log(3/delta)/n_eff) \
           + 3*R_max*log(3/delta)/n_eff
    bias = (1 - Q_C) * R_max                     # 质量偏差上界
    return m_hat - bias - conc
```

## 3. 证据下界推导（简述）

设证据权重 w_i 已做去相关与质量过滤，有效样本数 n_eff=(Σw)²/Σw²。对加权经验均值 \hat m 应用经验 Bernstein 不等式，以概率 ≥1−δ：

  |E_w[m] − \hat m| ≤ √(2σ̂² ln(3/δ)/n_eff) + 3R_max ln(3/δ)/n_eff.

再叠加定义 40 的质量—偏差契约 |E_D[m]−E_true[m]| ≤ (1−Q_C)R_max，得

  m_true ≥ \hat m − (1−Q_C)R_max − √(2σ̂² ln(3/δ)/n_eff) − 3R_max ln(3/δ)/n_eff.

三项分别对应「数据有多脏」「样本有多少」「随机性有多大」。只有该下界 ≥θ 的区域进入 ValidRegion；其余标 Unknown。**质量门控的作用不是把 Unknown 变成 Safe，而是阻止 Unknown 被误当成 Safe。**

**预注册判据（不是实测结果）**：E89 若出现任何一起「证据下界 ≥θ 但实测边际 <θ」的静默失效，直接判定本轮方案不达标并回退 v19，不做阈值微调；E88 若 Q 与误差相关性 <0.5，则质量向量退化，仅保留来源/覆盖/同步三项并重新校准。

## 6. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 循环自证：力矩审计与质量评分共用同一动力学模型，共模偏差被高置信放行 | 高 | 三角独立验证 + 外部物理标定（静态重力/已知负载/触觉）+ 独立证据组；禁止质量/见证提升证书置信，只允许否决 |
| 力矩传感器自身故障/漂移/饱和被当成「物理真值」 | 高 | 传感器健康证书；电流/IMU/触觉交叉验证；标定年龄；任一异常 → UNKNOWN（等价 VETO） |
| 质量门控过严导致数据饥饿、可用性崩塌 | 高 | 保形校准 Q_min；质量分层；Unknown→Degraded 而非 SafeStop；主动采集补证据；风险预算可审计地调整 |
| 保形保证依赖交换性，长时运行/分布漂移下失效 | 高 | 在线/加权保形；漂移监控与重校准；质量漂移与分布漂移分开告警 |
| 最弱环合并过度保守，组合证书大面积 Unknown | 中 | 质量分层与独立证据池化；按任务域分别发证；组合前先补齐最弱环证据 |
| 力矩残差对模型精度敏感，模型差 → 误否决 | 中 | 参数辨识 + 自适应阈值 + 鲁棒观测器；模型失配单独归因并触发 SCV 重校准 |
| 主动采集被低质/对抗数据污染 | 中 | 采集前先过 DQC；来源哈希与金丝雀；隔离区；人工抽检 |
| 在线质量统计开销 | 低 | 只维护滑窗均值/方差/分位数；重计算离线；定点实现 |
| 力矩见证无法发现纯感知失效（如视觉误检但动力学未受扰） | 中 | 保留几何/语义证书作为互补证伪器；见证只覆盖「动力学前件」 |

## 7. 本轮最大风险

**一句话**：力矩审计与数据质量评分仍共用同一套动力学模型，形成「模型验证数据、数据验证模型」的循环自证——一旦模型存在共模偏差，低质量数据会被高置信放行，质量门控反而成为静默失效的加速器，因此必须用三角独立验证与外部物理标定把这条回路打断。
