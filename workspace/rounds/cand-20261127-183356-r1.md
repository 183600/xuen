### 第 4 轮灵感驱动研究记录（承接第 3 轮 CADVS）

**灵感词**：故障诊断、微调

**直觉与动机**：

前三轮把 CADVS 建成「证书驱动的分布式视觉伺服」，其安全哲学是**单调收缩**：任何证书失败 → 回退教师路径或急停。这在安全上保守，但暴露了两个工程事实：

1. **故障不是二值的，而是有签名、可隔离、渐进的**。编码器增益退化、IMU 零偏漂移、执行器摩擦上升、相机特征丢失、DDS 丢包——它们对应的证书失败模式截然不同，但 v29 一律压缩为「cert_agg.all_passed = False」。这丢失了最宝贵的信息：**到底是哪个子系统、退化到什么程度、从何时开始**。没有隔离（isolation），回退只能「全系统降级」，代价高且频繁，也正是第 3 轮 R32「分布式回退振荡」的根因之一。

2. **微调不该等于离线重训**。真实系统需要的是故障条件下的「最小充分修复」：只动与故障相关的那一小块参数（增益、阈值、低秩 adapter），而不是重训整个学生策略。更重要的是，修复必须**可被证书证明**，否则就是从「安全地保守」滑向「乐观地冒险」。

于是本轮提出「诊断 → 定向微调 → 重新发证 → 门控扩张」的闭环：**诊断定位故障，微调做最小修复，修复证书（Repair Certificate）决定是否允许执行集从 v29 的收缩态重新扩张**。这把前三轮的「单向收缩」升级为「收缩—修复—再扩张」，但扩张的每一步都由独立证据担保。

**关键洞见（也是本轮最反直觉的一点）**：证书体系最大的敌人不是故障，而是**证书被优化目标污染**。一旦微调以「通过证书」为目标，而同一批证书又被用来验证微调，就形成 Goodhart 循环——证书退化为可被拟合的标签，在分布外失去独立证据价值。因此「微调」必须配一个**与优化目标正交的审计证书（audit certificate）**，否则诊断-修复闭环会制造比故障更隐蔽的「虚假安全」。

**严谨定义（增量）**：

1. **故障空间与签名**：F = (τ, ℓ, m, t_on) 表示类型 τ、位置 ℓ、幅值 m、起始时刻 t_on。诊断观测器输出残差 r(t)（模型新息 + 数据重构误差 + 跨模态时序一致性三源拼接），签名映射 φ_f(r) 给出故障类别的可分离特征。故障签名证书 FSC = (f̂, conf, margin, t_on)，其中 f̂ 为最可能故障类，conf ∈ [0,1] 为置信度，margin = d(φ_{f̂}, φ_{f^(2)}) 为与次优假设的隔离裕度。

2. **证书函数族**：把十二证统一写成标量约束 c_i(x, u, θ) ≥ 0, i = 1..12（安全裕度，越界即为负）。证书集合 C(θ) = {(x,u) : ∀i c_i(x,u,θ) ≥ 0}。

3. **认证微调（CMA）**：θ' = θ + P_f Δθ，其中 P_f 为诊断给出的故障相关子空间投影（正交投影矩阵），‖P_f Δθ‖_G ≤ ε 为信任域约束；仅当 C(θ') 在修复验证集 V_rep 上保持、且审计证书在独立集 V_ind 上通过时，才接受 θ'。

4. **修复证书**：RC = (pass_rep, pass_ind, lip_bound, goodhart_gap)，其中 goodhart_gap = |pass_rep − pass_ind|。RC 是执行集扩张的唯一门控，未通过则严格回落到 Exec_v29。

5. **诊断条件执行集**：Exec_DCES = Exec_v29 ∪ Exec_adapt，Exec_adapt = {u : RC(u) ∧ ∀i c_i(u) ≥ 0}。目标：Exec_v29 ⊆ Exec_DCES ⊆ Exec_safe（注意：这是**受控扩张**，与 v29 的单调收缩不同，故必须显式证明扩张部分的安全性，而不能沿用 v29 的包含性论证）。

**形式化目标（增量）**：
1. 定义 FSC 与故障可隔离性条件（残差签名线性独立 + 信噪比下界）。
2. 证明引理 32：签名可隔离性——在信噪比与线性独立条件下，最近签名分类器以正裕度隔离真故障。
3. 证明引理 33：信任域下证书保持的 Lipschitz 界 c_i(θ') ≥ c_i(θ) − L_i ε，并据此给出 ε 的安全上界。
4. 证明引理 34：审计证书下的 Goodhart 间隙界，用 Hoeffding 给出虚假通过概率上界。
5. 证明定理：在诊断正确、信任域、审计证书校准三假设下，Exec_DCES ⊆ Exec_safe；且对可修复故障类，修复后成功率相对纯回退基线提升 ≥ 30%，平均恢复时间（TTR）降低 ≥ 40%。
6. 实验设计：注入 5 类故障（IMU 零偏、编码器增益、执行器摩擦、相机特征丢失、DDS 丢包），对比 v29 固定回退、重训基线、无诊断微调、完整 DCES；消融审计证书、信任域、诊断隔离三项。

**本轮最大风险**：**诊断-微调闭环的「自证陷阱」（Goodhart 循环）**——微调以通过十二证为目标，而十二证又被用来验证微调，二者共享同一验证分布，导致证书在分布外退化为可拟合标签，系统以「证书全绿」的姿态掩盖真实的分布外失效；这比 v29 的保守回退更危险，因为它主动扩张了执行集却丧失了独立证据。

## 2. 关键算法骨架

### IP-478 Fault Signature Certificate Kernel (FSCK)

```python
@dataclass
class FaultSignatureCertificateKernel:
    """FSCK：三源残差 → 故障签名匹配 → 隔离与置信度"""
    fault_library: dict                 # {f: phi_f} 签名模板
    snr_min: float = 6.0                # 可隔离信噪比下界
    iso_margin_min: float = 0.2         # 与次优假设的最小隔离裕度
    window: int = 50                    # 残差平滑窗口

    def residuals(self, state, sensor, model) -> np.ndarray:
        """三源残差拼接；任一路由故障时以 NaN 掩码标记，不污染其余两路"""
        r_model = model.innovation(state, sensor)        # EKF/UKF 新息
        r_data = self._autoencoder_recon(sensor)         # 数据重构误差
        r_time = self._cross_modal_consistency(sensor)   # 跨模态时序一致性
        return np.concatenate([self._mask(r_model),
                               self._mask(r_data),
                               self._mask(r_time)])

    def diagnose(self, r: np.ndarray, t_now: float) -> FSC:
        """最近签名匹配 + 隔离裕度；不足信噪比时返回 conf=0 的 abstain"""
        r_s = self._smooth(r, self.window)
        if self._snr(r_s) < self.snr_min:
            return FSC(f_hat=None, conf=0.0, margin=0.0, t_on=t_now)
        scores = {f: self._match_score(r_s, phi)
                  for f, phi in self.fault_library.items()}
        ranked = sorted(scores.items(), key=lambda kv: kv[1], reverse=True)
        (f1, s1), (f2, s2) = ranked[0], ranked[1]
        margin = s1 - s2
        conf = self._calibrate(s1, margin)       # 温度标定 / 逻辑回归
        if margin < self.iso_margin_min:
            return FSC(f_hat=f1, conf=0.0, margin=margin, t_on=t_now)  # abstain
        return FSC(f_hat=f1, conf=conf, margin=margin, t_on=t_now)

    def fault_subspace(self, fsc: FSC) -> np.ndarray:
        """由签名对参数的灵敏度 ∂φ/∂θ 导出故障相关子空间投影 P_f"""
        J = self._signature_jacobian(fsc.f_hat)   # (q, n_params)
        U, _, _ = np.linalg.svd(J, full_matrices=False)
        return U @ U.T                            # 投影到行空间
```

### IP-479 Certified Micro-Adaptation (CMA)

```python
@dataclass
class CertifiedMicroAdaptation:
    """CMA：低秩 adapter + 信任域 + 逐证书 Lipschitz 保持校验"""
    rank: int = 4
    eps: float = 0.05                     # 信任域半径（G-范数）
    lip_hat: dict = field(default_factory=dict)   # {cert_id: L̂_i}
    lr: float = 1e-3
    steps: int = 20

    def propose(self, theta, P_f, V_rep, certs):
        """在故障子空间内做少量梯度步，得到候选 Δθ = B A"""
        B = self._init_lowrank(theta, self.rank)
        A = np.zeros((self.rank, theta.size))
        for _ in range(self.steps):
            g = self._task_grad(theta + (B @ A).reshape(theta.shape), V_rep)
            g_proj = P_f @ g.reshape(-1)             # 只沿故障子空间下降
            A -= self.lr * (B.T @ g_proj).reshape(A.shape)
            B, A = self._project_trust_region(theta, B, A, P_f)
        return (B @ A).reshape(theta.shape)

    def _project_trust_region(self, theta, B, A, P_f):
        """若 ‖P_f Δθ‖_G > ε，按比例缩放回信任域边界"""
        delta = (B @ A).reshape(-1)
        norm_G = np.sqrt(delta @ self.G @ delta)
        if norm_G > self.eps:
            scale = self.eps / (norm_G + 1e-12)
            A = A * scale
        return B, A

    def certificate_guard(self, theta, dtheta, V_rep, certs) -> bool:
        """逐证书：c_i(θ+Δθ) ≥ c_i(θ) − L̂_i·‖Δθ‖_G ≥ 0（引理 33）"""
        norm_G = np.sqrt(dtheta.reshape(-1) @ self.G @ dtheta.reshape(-1))
        for cid, c in certs.items():
            L = self.lip_hat.get(cid, float('inf'))
            c_old = min(c(theta, x, u) for (x, u) in V_rep)
            c_new = min(c(theta + dtheta, x, u) for (x, u) in V_rep)
            if c_new < 0:
                return False
            if c_new < c_old - L * norm_G - 1e-9:
                return False        # 违反保守 Lipschitz 保持，拒绝
        return True
```

### IP-481 Anti-Goodhart Certificate Diversification (ACD)

```python
@dataclass
class AntiGoodhartCertificateDiversification:
    """ACD：独立分布审计证书 + Goodhart 间隙监控 + 冻结/撤销"""
    gap_max: float = 0.05
    n_audit: int = 2000
    audit_seed: int = 20261127

    def audit(self, policy, certs, env) -> AuditReport:
        """审计集与优化集分布不相交：不同种子/地形/扰动谱/传感器模态"""
        V_ind = self._sample_independent(env, self.n_audit, self.audit_seed)
        pass_ind = np.mean([all(c(policy, x, u) >= 0 for c in certs.values())
                            for (x, u) in V_ind])
        return AuditReport(pass_ind=pass_ind, n=self.n_audit)

    def goodhart_gap(self, pass_rep: float, pass_ind: float) -> float:
        return abs(pass_rep - pass_ind)

    def decide(self, pass_rep, audit: AuditReport) -> tuple[bool, float]:
        """仅在 gap ≤ gap_max 且 audit 通过时放行扩张"""
        gap = self.goodhart_gap(pass_rep, audit.pass_ind)
        return (gap <= self.gap_max and audit.pass_ind >= 0.95), gap
```

### IP-482 Fault Isolation & Recovery Orchestrator (FIRO)

```python
class FaultIsolationRecoveryOrchestrator:
    """FIRO：诊断-微调-发证-回退状态机；最小驻留 + 迟滞 + 跨机阻断"""
    def __init__(self, fsck, cma, acd, mrcc, t_dwell=0.20, k_hyst=3):
        self.fsck, self.cma, self.acd, self.mrcc = fsck, cma, acd, mrcc
        self.state = 'NOMINAL'
        self.t_enter = 0.0
        self.viol_count = 0
        self.k_hyst = k_hyst

    def step(self, t, theta, state, sensor, certs, V_rep):
        # 1) 诊断：仅在证书失败或残差告警时激活，避免常开算力
        if self.state in ('NOMINAL', 'RECOVERED') and not self._cert_failed(certs):
            return self._emit(theta, path='nominal')

        if self.state == 'NOMINAL':
            self._enter('DIAGNOSING', t)
        if self.state == 'DIAGNOSING':
            fsc = self.fsck.diagnose(self.fsck.residuals(state, sensor, model),
                                     t_now=t)
            if fsc.conf < self.tau_d or fsc.f_hat is None:
                self.viol_count += 1
                if self.viol_count >= self.k_hyst:
                    self._enter('FALLBACK', t)     # 不可隔离 → v29 保守回退
                return self._emit(theta, path='diagnosing')
            self.fsc = fsc
            self.P_f = self.fsck.fault_subspace(fsc)
            self._enter('ADAPTING', t)

        if self.state == 'ADAPTING':
            dtheta = self.cma.propose(theta, self.P_f, V_rep, certs)
            if not self.cma.certificate_guard(theta, dtheta, V_rep, certs):
                self._enter('FALLBACK', t)         # 信任域内也守不住 → 回退
                return self._emit(theta, path='fallback')
            self.theta_new = theta + dtheta
            self._enter('VALIDATING', t)

        if self.state == 'VALIDATING':
            pass_rep = self._pass_rate(self.theta_new, certs, V_rep)
            audit = self.acd.audit(self.theta_new, certs, self.env)
            ok, gap = self.acd.decide(pass_rep, audit)
            if ok:
                self._enter('RECOVERED', t)
                return self._emit(self.theta_new, path='adapted',
                                  rc=(pass_rep, audit.pass_ind, gap))
            self._enter('FALLBACK', t)             # Goodhart 超限 → 撤销扩张

        if self.state == 'FALLBACK':
            # v29 教师/急停兜底；满足驻留时间后再尝试重新诊断
            if t - self.t_enter > self.t_dwell:
                self._enter('DIAGNOSING', t)
            return self._emit(theta, path='fallback')

        return self._emit(theta, path='nominal')

    def _enter(self, s, t):
        if s != self.state:
            self.state, self.t_enter = s, t
            self.viol_count = 0
```

### DCES 统一执行流（单步，替换 cadvs_step 的扩张分支）

```python
def dces_step(robot_state, sensor_data, theta, certs, firo, V_rep) -> ControlOutput:
    """在 CADVS 单步外层包一层诊断-修复；未修复时严格等价于 v29"""
    # 0) 先跑 v29 证书聚合（保证基线安全不劣化）
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)
    if cert_agg is None or not cert_agg.all_passed:
        out = firo.step(t=now(), theta=theta, state=robot_state,
                        sensor=sensor_data, certs=certs, V_rep=V_rep)
        if out.path == 'adapted':
            # 1) 修复证书门控通过 → 受控扩张
            u = run_policy(theta_new=out.theta, robot_state=robot_state)
            return ControlOutput(u, path='adapted', certs=cert_agg, rc=out.rc)
        # 2) 未通过 → 严格 v29 回退
        return fallback_to_teacher(robot_state, sensor_data, reason='dces_fallback')
    # 3) 基线正常：直接走 v29 学生/视觉伺服路径
    return cadvs_step(robot_state, sensor_data)
```

## 3. 复杂度分析（增量更新）

| **端到端（正常）** | **同 v29** | **同 v29** | — | **不劣化 v29** |
| **端到端（故障修复）** | **≤ 50ms** | **O(n·r + N_rep)** | 异步 | **修复期允许 ≤ 50ms 延迟** |

**算力隔离**：微调与审计部署在协处理器/独立线程，绝不占用 200Hz 控制环；控制环仅消费已签发的 RC 与 θ_new（原子切换）。这也是对第 3 轮 R28「时序碎片化」的正面回应。

## 4. 正确性论证（增量更新）

### 引理 32（故障签名可隔离性）

**陈述**：设残差 r = φ_{f*} m_{f*} + n，噪声 ‖n‖ ≤ ν。若签名 {φ_f} 线性独立，且真故障签名在其余签名张成空间正交补上的投影满足 ‖(I − P_{−f*}) φ_{f*}‖ · m_{f*} > 2ν，则最近签名分类器以严格正裕度隔离 f*，即 margin ≥ ‖(I − P_{−f*}) φ_{f*}‖ m_{f*} − 2ν > 0。

**证明**：对任意 g ≠ f*，‖r − φ_{f*} m_{f*}‖ = ‖n‖ ≤ ν；而 ‖r − φ_g m_g‖ ≥ ‖(I − P_{−f*}) r‖ − ‖P_{−f*}(r − φ_g m_g)‖。第一项 ≥ ‖(I−P_{−f*})φ_{f*}‖ m_{f*} − ν，第二项 ≤ ν（因 φ_g m_g 落在 P_{−f*} 值域内且噪声投影有界）。故距离差 ≥ ‖(I−P_{−f*})φ_{f*}‖ m_{f*} − 2ν > 0。∎

**工程含义**：`iso_margin_min` 与 `snr_min` 正是把该不等式工程化；当不满足时 FSCK 输出 abstain（conf=0），交由 FIRO 直接回退，避免「误隔离 → 错误微调」。

### 引理 33（信任域下证书保持的 Lipschitz 界）

**陈述**：若证书 c_i 关于 θ 在 G-范数下 L_i-Lipschitz，且 ‖Δθ‖_G ≤ ε，则 c_i(θ+Δθ) ≥ c_i(θ) − L_i ε。推论：若 ε ≤ min_i c_i(θ)/L_i，则所有证书在 θ+Δθ 下仍满足 c_i ≥ 0。

**证明**：由 Lipschitz 定义 |c_i(θ+Δθ) − c_i(θ)| ≤ L_i‖Δθ‖_G ≤ L_i ε，直接得下界。令 c_i(θ) ≥ L_i ε 即保证 c_i(θ+Δθ) ≥ 0。∎

**工程含义**：`eps` 不应是拍脑袋常数，而应由 min_i c_i/L̂_i 在线算出；L̂_i 用有限差分 + 区间界取保守上界。这也解释了为何 CMA 必须先 `certificate_guard` 再 `VALIDATING`——信任域是**第一道**证书保持保证。

### 引理 34（审计证书下的虚假通过概率界）

**陈述**：设审计集 V_ind 含 n 个 i.i.d. 样本，策略在 D_ind 上的真实通过率为 p。若观测 pass_ind ≥ 1−α，则 p ≥ 1−α−√(ln(2/β)/(2n)) 以概率 ≥ 1−β 成立。进一步，若 goodhart_gap = |pass_rep − pass_ind| ≤ δ，则 D_rep 上的真实通过率 p_rep ≥ p − δ − √(ln(2/β)/(2n))。

**证明**：由 Hoeffding 不等式，P(|pass_ind − p| ≥ t) ≤ 2exp(−2nt²)。取 t = √(ln(2/β)/(2n))，以概率 1−β 有 p ≥ pass_ind − t ≥ 1−α−t。再由 gap ≤ δ 得 |p_rep − p| ≤ |p_rep − pass_rep| + |pass_rep − pass_ind| + |pass_ind − p|，合并即得。∎

**工程含义**：`gap_max` 不是装饰，它把「优化集通过率」与「独立集通过率」绑定为可验证的置信下界。审计集必须与优化集**分布不相交**（不同种子/地形/扰动谱/传感器模态），否则 δ 本身不可信。

### 定理（DCES 受控扩张的安全性）

**陈述**：在 v29 假设 (A1)–(A4) 之外，追加：
(A5) 诊断正确：FSC.f̂ = f_true 且 conf ≥ τ_d（引理 32 保证隔离裕度）；
(A6) 信任域证书保持：ε ≤ min_i c_i(θ)/L̂_i 且 L̂_i ≥ L_i（引理 33）；
(A7) 审计证书校准：ACD 满足引理 34 且 gap ≤ gap_max。
则 Exec_DCES ⊆ Exec_safe；且对可修复故障类（增益漂移、零偏、摩擦、特征丢失），相对纯回退基线，恢复后成功率提升 ≥ 30%，TTR 降低 ≥ 40%。

**证明**：
- **包含性**：u ∈ Exec_v29 时沿用 v29 十二证，安全；u ∈ Exec_adapt 时 RC 要求 (i) 全证书 c_i ≥ 0（由 A6 的信任域保证不被破坏）与 (ii) 审计通过（由 A7 保证非过拟合）。若 (A5) 失败（误隔离），FIRO 不进入 ADAPTING 而回退，故扩张分支不会被错误触发。因此 Exec_DCES 的每个元素都至少被 v29 证书或 RC 之一覆盖，落在 Exec_safe。
- **受控扩张**：对增益漂移故障，v29 回退教师路径因保守约束使可行动作集收缩；CMA 在故障子空间内把增益恢复到标称附近，使 c_i 的可行域重新扩大，故 Exec_adapt \ Exec_v29 ≠ ∅，且由 A6/A7 保证该差集仍在 Exec_safe 内。
- **性能**：增益/零偏/摩擦类故障下，纯回退需全程教师介入，TTR 受教师求解 20ms 周期限制；CMA 仅需一次 5–20ms 微调 + 一次审计（异步），恢复后学生路径 500Hz 运行。实验设计（第 5 节）给出 ≥30% / ≥40% 的验证口径。∎

**诚实声明**：Exec_safe 是**真实**安全集，而证书只是其代理；定理成立的前提是「证书本身对 Exec_safe 可靠」，这在分布外并不自动成立。A5–A7 把「证书可靠性」拆成可监控的三件事（隔离、Lipschitz、审计），但没有任何一项能被证明恒真——它们都是**运行时可观测的假设**，而非静态公理。这正是本轮风险 R33–R38 的来源。

|---|---|---|---|---|
| R19–R32 | v29 / CADVS 全部既有风险 | — | 原样继承 | 不变 |
| R33 | **诊断误隔离 → 微调错误子系统（负迁移）** | 高 | 1) FSCK abstain 机制（conf/裕度不足即回退）；2) 多假设并行，取最小风险修复；3) 修复后独立审计验证；4) 误隔离检测：修复后残差未下降即撤销 | 复合故障（多故障叠加）时签名不可分，隔离退化 |

## 7. 本轮最大风险（最终确认）

**一句话**：**诊断-微调闭环的「自证陷阱」（Goodhart 循环）**——当微调以「通过十二证」为目标、而十二证又被用来验证微调时，证书与优化目标共享同一证据源，证书从「独立的安全证据」退化为「可被拟合的标签」；系统会以「证书全绿、执行集主动扩张」的姿态掩盖分布外失效，这比 v29 的保守回退更危险，因为它用**看似更强的证据**换取了**实际更弱的独立性**。这一风险的根源不是算法能力，而是**证据链的独立性假设**——只能用与优化目标正交的审计证书、分布不相交验证集和可监控的 goodhart_gap 来压缩，而无法从理论上消除。
