> 承接 research.md 的 UIP-01~10（迭代验证 / 排行榜 / 常识推理）。上一轮把杠杆放在**推理时的外部编排**：进度验证器、重试、路由、端口工程。本轮两个灵感词把镜头拉回**模型本体**：具身智能大模型（VLA 基座）与视觉感知（4 路相机如何变成空间理解）。核心判断：**当执行栈已被厂商解决、动作头已由预训练 VLA 提供时，剩余泛化损失的主要项在感知，而不是重试策略。**

## 1. 两个灵感词：先直觉，再定义

### 1.1 具身智能大模型（Embodied Large Model）

**直觉**：它不是「更大的聊天模型」，而是把「看图 → 理解指令 → 输出一段动作」压进同一个网络。对赛事而言，它意味着**不必从零训练**：以 UnifoLM-VLA-0 这类基座做继续微调/适配，才是现实起点；「单模型」约束也意味着不能按任务切换多个独立大模型。

**严谨定义**：一个参数化策略
`π_θ(a_{t:t+H} | o_{≤t}, p_{≤t}, l)`，
其中 `o_t={I_t^v}_{v=1..V}` 为多路图像，`p_t` 为本体状态（关节角、EE 位姿、夹爪），`l` 为语言指令，`H` 为动作块长度；θ 共享一个 VLM 主干与一个动作头。赛事「单模型」等价于：推理时只有一个可执行体，任务条件化必须发生在**同一组权重内部**。

### 1.2 视觉感知（Visual Perception）

**直觉**：感知不是「把图片编码成 token」，而是回答三个问题：**目标在哪（3D 位置）、它能不能这样抓（可供性）、我刚才动过的东西现在在哪（记忆）**。

**严谨定义**：感知算子
`Ψ: (o_t, K_v, T_v, l) → (z_t^geo, A_t, u_t, m_t)`
其中 `z_t^geo` 为跨视角一致的三维场景 token，`A_t` 为任务条件可供性图，`u_t` 为感知不确定性，`m_t` 为物体中心记忆；`K_v, T_v` 为相机内外参。基线 VLA 近似只用 `z_t=[φ(I^1);…;φ(I^V)]`，缺少几何约束与持久状态——这正是「视图无关 token 拼接」的通病。

## 2. 诊断：为什么这轮要换杠杆

- 上一轮 UIP-01/02/03/08 都是**外部编排**：验证、重试、路由、延迟工程。它们能榨取边际收益，但**无法修复「看错 / 抓错」**。对一个基于错误 3D 理解的动作反复重试，只会更慢地失败。
- 预训练 VLA 已把「控制」做得较好（动作块 + 流匹配 + 动力学约束）；赛事剩下的 5 条泛化轴——位置、干扰物、背景、未见物品、人为干扰——**本质全是感知轴**。
- 数据侧：4 路 480×640、AV1 压缩；小目标（电池、试管、网线头）在压缩后细节脆弱。**显式几何 + ROI 放大**比「再训一个更大的端到端模型」更省算力。
- 规则侧：若只允许单 checkpoint，则**外部大模型即插即用是陷阱**（可能违规 + 抬高延迟方差）。正确路径是**训练期用大模型/工具当教师，推理期内化为轻量模块**。

---

## 3. 瓶颈假设（工作假设）

- **H1（感知主导）**：在 32 任务上，失败主导项是感知/空间 grounding，而非控制精度；因此感知增强的边际收益 > 推理时重试。
- **H2（视图无关拼接有损）**：多视图 token 的视图无关拼接丢失跨视角几何一致性；显式 3D 提升 + 一致性约束能显著提升位置/背景/未见物品三轴。
- **H3（记忆缺失）**：长时域任务（整理书架、装包、折毛巾）的失败常来自物体离开视野后的记忆缺失；物体中心记忆比扩大上下文窗口更省算力。
- **H4（成本护栏）**：任何感知增强若使单步延迟均值或方差超预算，会先触发可信度扣分；因此必须**可蒸馏、可降频、可缓存**。

## 4. 候选创新点（草稿 → 收敛）

发散 14 个草案，合并为 10 个（见产物区 UIP-11~20）。收敛原则：
1. 只保留**能内化进单模型**的方案（排除推理时调用外部 SAM/VLM 的方案）；
2. 优先**不改变动作头接口**的适配器注入，降低工程风险；
3. 每个点必须能映射到至少一条泛化轴与一个排名口径（成功率 / 步骤分 / 可信度）。

**旗舰点：UIP-11 PIP-VLA —— 多视图几何一致 + 任务条件可供性的感知注入。** 它同时命中「具身大模型」（复用 UnifoLM-VLA 基座、只训适配器）与「视觉感知」（3D 一致性 + 可供性），且不破坏单模型约束。关键的工程支点是：**head 双目给度量深度，腕部相机位姿可由关节角 + URDF 正运动学得到**，因此几何融合不需要额外标定。

---

## 5. 本轮最大风险

**一句话**：感知模块若不能被蒸馏、降频或缓存，就会把 3D 提升与跨视角注意力的计算开销变成**延迟均值与方差的异常**，在可信度判定上先失分，再抵消感知带来的成功率收益。

## 1. 旗舰点深潜：UIP-11 · PIP-VLA

### 1.1 机制

模型输出动作块 `A=(a_1..a_H)` 前，先构造一个**几何一致的感知上下文**：

1. **头双目 → 度量深度**：`head_stereo_left/right` 做立体匹配得到全局点云，尺度由已知基线决定，无需学习深度。
2. **腕部相机 → 位姿**：由 `observation` 的双臂关节角 + G1 URDF 正运动学得到腕部相机外参 `T_v`，与头相机统一到机器人基座/世界坐标系。
3. **统一 3D 特征**：将各视图特征 `F_t^v` 按 `T_v` 反投影为带语义的点/体素；用几何位置编码 + 跨视角注意力聚合，得到 `z_t^geo`。
4. **任务条件可供性**：以语言查询 token `Q_l` 对 3D 特征做 cross-attention，输出可供性图 `A_t`（在哪里抓/插/放）与不确定度 `u_t`。
5. **注入**：取可供性 top-k 区域与全局场景 token，作为 `extra_tokens` 与 VLM 隐状态拼接/交叉注意，动作头不变。

### 1.2 与现有方案的差异

- 常规 VLA（含 UnifoLM-VLA-0 的默认多相机配置）把多视图特征**视图无关地拼接**，几何一致性靠注意力隐式学习；PIP 显式用**双目度量深度 + FK 外参**建立共享 3D 空间。
- 3DVLA / PEAfowl / MV-Actor 证明了「3D 提升 + 跨视角一致 + 可供性」的有效性，但它们多在仿真/机械臂设定；PIP 针对**人形 G1 + 4 路固定相机 + 32 桌面任务**，并把腕部 FK 作为免费几何先验。
- 与 UIP-01（推理时重试）互补而非替代：PIP 提升每次观测的质量，UIP-01 的重试应由 `u_t` 触发，而不是盲目重试。

### 1.3 为什么命中 5 条泛化轴

| 泛化轴 | PIP 的作用 |
|---|---|
| 位置 | 度量 3D 坐标使动作不依赖图像像素位置 |
| 干扰物 | 任务条件可供性抑制无关物体；3D 分离遮挡 |
| 背景 | 点云/几何表征对纹理背景不敏感 |
| 未见物品 | 可供性按几何+语义泛化，而非记忆坐标 |
| 人为干扰 | 3D 占据突变 + 不确定度可触发安全暂停 |

### 1.4 训练信号（无需额外人工标注）

- **动作损失**：沿用 VLA 的 flow-matching / 动作块回归。
- **可供性弱监督**：成功演示中，夹爪闭合前后的 EE 轨迹投影到各视图，生成高斯热图作为 `A_t` 的弱标签。
- **跨视角一致性**：把聚合后的 3D 特征重投影回各视图，最小化特征/光度一致性；腕部单目深度用双目深度做尺度对齐监督。
- **深度（可选）**：双目自监督 + 稀疏几何约束。

### 1.5 落地步骤

1. 用 G1 URDF + 关节角实现 FK，标定并固化 4 路相机外参（离线一次）。
2. 在公开 32 数据集上跑双目深度与点云管线，做回放可视化，确认坐标系一致。
3. 训练轻量几何适配器（点/体素编码 + 可供性头），VLM 主干冻结或低秩微调。
4. 将 `z_t^geo` 以 `extra_tokens` 注入 VLM/动作头，端到端微调动作损失。
5. 在 RRV（UIP-07）回放代理上逐轴评测，再预约真机提测。

### 1.6 风险

深度在 AV1 压缩、反光/透明物体（试管、药瓶、网线头）上会退化；若几何噪声大于收益，可供性会被错误引导。缓解：双目置信度门控、腕部近距离几何优先、低置信时退回纯 RGB token。

## 2. 其余点（结构化）

**UIP-12 OCM-Ledger**｜动机：整理书架/装包/折毛巾等任务需要记住已离开视野的物体。差异：维护世界坐标系下的物体轨迹、容器包含关系与事件历史，作为**记忆 token** 注入策略；规划器按需查询，而非扩大上下文窗口。可行性：中高（可用演示轨迹 + 检测/跟踪弱标注训练）。风险：跟踪漂移污染记忆；需带置信度的读写与遗忘机制。

**UIP-13 APC**｜动机：遮挡与精细操作（插网线、抽药、取电池）需要更好的视角。差异：以 `u_t`（深度方差/可供性熵/遮挡率）触发腕手微动再观测或 3D ROI 放大，再决策。可行性：高。风险：探索动作消耗 episode 预算与步骤分；需设触发阈值与最大次数。

**UIP-14 XVR-PT**｜动机：多视图对应与空间关系是 VLA 的薄弱项。差异：用 4 路同步帧构造「对应/校验/定位」自监督任务预训练视觉主干（参考 XVR）。可行性：高（数据自带多视图）。风险：预训练任务与动作目标错位；需与动作损失联合微调。

**UIP-15 GAX-P**｜动机：评测含背景/干扰物/未见物品轴。差异：背景替换、干扰物合成、视图 dropout、AV1 压缩退化增广，并按泛化轴重加权。可行性：高。风险：过度增广损害真实分布；需逐轴消融。

**UIP-16 PERR**｜动机：盲目重试会放大错误。差异：显式检测感知失效模式（遮挡、滑移、抓错物体），触发**重定位/重新 grounding**，而不是重复同一动作。可行性：中高（可用成功/失败回放训练分类器）。风险：误报导致效率下降；与 UIP-01 的三重护栏共用门限。

**UIP-17 WLA-T**｜动机：WLA-1.0 有更强的空间感知与 64 任务先验。差异：以 WLA-1.0 为教师，蒸馏中间层 3D/空间表征到可部署的 VLA 学生；推理时不需要教师。可行性：中（需对齐层与算力）。风险：教师-学生容量差导致蒸馏收益有限。

**UIP-18 CAV**｜动机：不同相机/位姿下同一物体外观差异大。差异：把相机内参、相对外参、view-id 编码为 token（类似相机位姿编码），让模型显式知道「这是哪只眼睛」。可行性：极高（几乎零成本）。风险：过拟合到固定相机配置；需随机扰动增广。

**UIP-19 V-FUSE**｜动机：单相机遮挡/失效会拖垮整体。差异：学习视图门控权重，按任务阶段与遮挡动态融合；缺失视图用其余视图补全。可行性：高。风险：门控塌缩到单一视图；需熵正则与视图 dropout。

**UIP-20 PCB**｜动机：感知增强不能牺牲可信度。差异：按任务/阶段调度感知计算（接近阶段用高分辨率/3D，移动阶段用低分辨率/缓存），把延迟方差压进 SLA。可行性：高。风险：调度抖动本身增加方差；需确定性预算表而非学习调度。

## 3. 关键算法（旗舰 UIP-11 伪代码）

```python
class PIPVLA:
    def __init__(self, vlm, action_head, geo_adapter,
                 cam_extrinsics, urdf, topk=32, H=25):
        self.vlm, self.action_head = vlm, action_head
        self.geo = geo_adapter
        self.cams = cam_extrinsics      # head stereo + wrist, calibrated once
        self.urdf = urdf
        self.topk, self.H = topk, H

    def get_action(self, obs):
        # 1) per-view visual features (frozen or LoRA VLM encoder)
        feats = [self.vlm.encode(I) for I in obs.images]        # V views

        # 2) metric geometry: head stereo depth + wrist FK extrinsics
        depth_head = self.stereo_depth(obs.images[0], obs.images[1])
        T = self.cams.copy()
        T["wrist_l"], T["wrist_r"] = self.fk(obs.joint_q, self.urdf)

        # 3) lift to shared 3D frame, then cross-view consolidate
        pts, pfeat = self.geo.lift(feats, depth_head, T)
        pts, pfeat = self.geo.cross_view_consolidate(pts, pfeat)

        # 4) task-conditioned affordance + uncertainty
        A, u = self.geo.affordance(pfeat, obs.language)
        z_geo = self.geo.pool(pts, pfeat, A, topk=self.topk)

        # 5) inject as extra tokens; action head interface unchanged
        hidden = self.vlm.forward(feats, obs.language, extra_tokens=z_geo)
        chunk = self.action_head(hidden, obs.proprio)
        return chunk[:self.H]                                    # (H, action_dim)
```

**训练目标**：

```text
L = L_action
  + λ1 * L_afford      # 成功轨迹 EE 接触点投影生成的弱监督热图
  + λ2 * L_xview       # 3D 特征重投影到各视图的一致性
  + λ3 * L_depth       # 双目自监督 / 腕部深度尺度对齐（可选）
```

**成本护栏**：`z_geo` 只在动作块边界重算（默认 `H=25`），腕部几何可缓存；`u_t` 高时启用 UIP-13，`u_t` 低时跳过 3D 分支，保证延迟方差可控。

## 4. 实验设计 E101–E108

| 实验 | 对照 | 指标 | 目标 |
|---|---|---|---|
| E101 | 基线 UnifoLM-VLA-0 vs +PIP-VLA | 32 任务平均成功率 / 步骤分 | 成功率 +Δ，步骤分 +15% |
| E102 | PIP 去掉 3D 提升 / 去掉跨视角一致 / 去掉可供性 | 逐轴成功率 | 三组件各自有正贡献 |
| E103 | 有无 UIP-18 CAV | 位置/背景轴成功率 | CAV 提供低成本的位姿感知 |
| E104 | 有无 UIP-12 OCM | 长时域子集（书架/装包/折毛巾） | 记忆轴成功率 +Δ |
| E105 | 有无 UIP-13 APC | 遮挡/精细子集（插网线/抽药/电池） | 精细任务成功率 +Δ，且不超时 |
| E106 | 无教师 vs UIP-17 WLA-T | 未见物品/背景轴 | 蒸馏带来 +Δ |
| E107 | 视图 dropout / 背景替换 | 鲁棒性曲线 | 性能下降更平缓 |
| E108 | 朴素实现 vs UIP-20 PCB | 每步延迟 p50/p95/方差 | 方差 −50%，成功率不降 |

> 真机结论前一律用 RRV（UIP-07）回放代理；代理与真机的相关性需在首次提测后校准。

## 6. 本轮最大风险（承接想法区 §5）

**一句话**：PIP-VLA 的 3D 提升与跨视角注意力若不能在动作块边界降频/缓存，或不能在透明/反光小目标上稳定，就会先以延迟方差与感知噪声的形式失分，抵消成功率收益；因此**先做几何置信度门控与成本护栏，再上完整感知栈**。
