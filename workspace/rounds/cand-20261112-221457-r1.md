# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；灵感循环第 1 轮；本轮灵感：「基线复现」×「机械臂」）

> 第 61 轮用 USR×MEL×DMS×SRT-Dual×PCE+++++ 搭起了「语义先行、实时兜底」的 ESEC 闭环，理论上自洽、指标上漂亮（零样本 +40%、适应时间 -50%）。但**它有一个比任何算法缺陷都更致命的方法论空洞：不可信**。四个具体问题：
> 1. **收益是目标值不是测量值**：E192–E200 全是"目标"，没有种子数、没有基线、没有置信区间、没有显著性检验——无法区分"真实语义增益"与"调参过拟合 + 幸运种子"。
> 2. **仿真-硬件断裂**：所有定义停留在抽象层，从未落到真实机械臂的**关节力矩上限、奇异位形、负载惯量、1kHz 控制周期、通讯抖动**上；USR 投影出的 K_prior 可能在数学上优雅、在物理上不可执行。
> 3. **基线缺位**：没有统一的基线动物园（阻抗控制 / OSC / VICES / Diffusion Policy / 纯 MPC），因此任何"提升"都无法归因——到底是 USR 有用，还是仅仅多了算力与人工调参？
> 4. **复现鸿沟不可分解**：不同实验室复现同一方法，误差可能来自实现（代码）、硬件（型号/摩擦）、协议（评估口径）、种子（随机性），但第 61 轮把它们混成一个数，无法定位。

> 本轮把研究范式从「再加一个模块」切换到「**让已有结论可被第三方复现、可被因果归因、可在真实机械臂上执行**」。

## 0. 直觉与动机

**灵感 1（基线复现 → 复现契约 BRC：基线不是一个数，而是一个分布）**
直觉：论文里的 "baseline = 72.3%" 是一个**点估计的幻觉**。真实基线是一个随机变量：同一份代码换一台机械臂、换一组种子、换一次评估脚本，结果就会漂移。因此"复现"不是"跑出同一个数"，而是"重建该基线的条件分布"。关键洞见：把基线形式化为**复现契约（Baseline Reproduction Contract, BRC）**——(代码摘要、数据/任务配置、种子集、硬件指纹、超参、评估协议) 六元组；复现质量用**复现保真度 RFS** 度量，并用**复现鸿沟分解 RGD** 把总偏差拆成实现/硬件/协议/种子四个可归因分量。这样"复现失败"第一次变成可诊断的工程信号，而不是玄学。

**灵感 2（机械臂 → 形态感知语义锚定 MASA：让语义先验长在身体上）**
直觉：第 61 轮的 scene_emb/intent_emb 是"无身体"的语义——它们不知道这台机械臂有几个关节、力矩多少、是否接近奇异、末端负载多重。直接把 Π(anchor) 送进 EEIS，等于让一个没有本体的"大脑"指挥一具它不了解的身体。关键洞见：在 USR 与 EEIS 之间插入**形态适配器 A_arm**，把语义锚点投影到**机械臂阻抗可行流形 MIFM**：τ = JᵀF ≤ τ_max、关节限位留裕度、可操作度 σ_min(J) ≥ σ_sing、末端力 ≤ 负载约束。语义先验不再"直接下发"，而是"在身体允许的空间里最接近地实现"。

**灵感 3（基线复现 × 机械臂 → 硬件在环可复现基准 RRAB）**
直觉：要证明 ESEC 真有用，必须有一个**所有方法共用、真实机械臂执行、种子可控、扰动可注入**的试验台。关键洞见：构建 **RRAB（Reproducible Robotic-Arm Benchmark）**：任务套件（插孔、擦拭、线缆穿引、开门、曲面跟踪）＋基线动物园（阻抗/OSC/VICES/DP/MPC）＋确定性回放 Harness＋分层指标（成功率、接触力、柔顺性、恢复时间、能耗）。每个 episode 都带可复现的扰动种子，评估协议预注册。

**灵感 4（基线复现 → 反事实复现回放 CRR：把"消融"变成因果推断）**
直觉：传统消融是"去掉模块再训一遍"，既贵又不可比（重新训练改变了所有变量）。关键洞见：用**事件溯源日志**记录 (时间戳、观测、动作、接触事件、随机数)，实现**确定性回放**；在此之上做 `do(module := baseline)` 的**反事实替换**——保持数据、种子、硬件、评估协议不变，只替换一个模块，得到该模块的因果效应 Δ。这让"USR 贡献 +8%"第一次有因果含义，而不是相关性叙事。

**灵感 5（五灵感合流 → 可复现证据闭环 REC 与复现统计证书 RSC）**
直觉：复现、硬件、基准、因果四件事必须收敛成一张**可审计的证书**。关键洞见：定义 **RSC（复现统计证书）**：种子数、bootstrap 置信区间、TOST 等价检验、检验功效、种子敏感性、预注册哈希；把它并入第 61 轮 J_sem_exec，得到 **J_repro**；最终形成 **REC（Reproducible Embodied Closure）**：设计→BRC 初始化→ESEC 执行→CRR 记录→RSC 检验→失败图谱→回灌设计。评估不再是终点，而是闭环的传感器。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（基线复现契约 BRC）**
一个基线 B 不是点估计，而是契约六元组 B = (C_code, D_task, S_seed, H_hw, Θ_hyper, E_eval)：
- **代码摘要** C_code = (git_commit, container_digest, dep_lock_hash)
- **任务配置** D_task = (scene_set, object_set, initial_pose_dist, perturbation_dist)
- **种子集** S_seed = {s_1,…,s_n}（训练种子 × 评估种子 × 扰动种子）
- **硬件指纹** H_hw = (arm_model, firmware, driver, control_rate, sensor_set, clock_source)
- **超参数** Θ_hyper（含搜索空间与最终选点，必须声明是否用测试集调参）
- **评估协议** E_eval = (success_criterion, horizon, metric_defs, aggregation_rule)
**复现 = 在报告分布下重建 P(metric | B)**，而不是复现单个标量。契约哈希 H(B) = SHA256(以上字段规范序列化)，任何字段漂移都使 H(B) 改变并触发"非同契约比较"告警。

**定义 174（复现保真度 RFS 与复现鸿沟分解 RGD）**
设报告基线指标分布为 μ_rep、第三方复现分布为 μ_new（均含 n 个种子）：
- **复现保真度**：RFS(B) = exp(−D(μ_rep, μ_new)/τ_rep)，D 可取标准化均值差或 1-Wasserstein 距离，τ_rep 为任务容差。
- **复现鸿沟**：g = μ_new − μ_rep，分解为
  g = g_impl + g_hw + g_protocol + g_seed + g_inter + ε，
  其中各项通过**多因素方差分析 / Shapley 方差分解**估计：
  σ²_total = σ²_impl + σ²_hw + σ²_protocol + σ²_seed + σ²_inter，
  RGD(B) = (σ²_impl, σ²_hw, σ²_protocol, σ²_seed, σ²_inter)/σ²_total。
  诊断规则：某分量占比 > 60% ⇒ 该维度为复现主因（实现/硬件/协议/随机），定向修复。

**定义 175（形态感知语义锚定 MASA）**
设机械臂本体描述 M_arm = (kinematic_chain, q_min, q_max, τ_max, payload_max, dynamics_params)。形态适配器：
A_arm: ℝ^{d_us} × M_arm → ℝ^{d_us}，Anchor_morph = A_arm(anchor; M_arm)
适配器由"本体条件化"的小型网络实现（以 M_arm 的物理量作为 FiLM/条件向量），使**同一语义在不同机械臂上投影出不同但物理可行的先验**。语义-身体一致性损失：
ℒ_morph = ‖Π(A_arm(anchor; M_arm)) − Π(anchor)‖² · w_con + λ_feas · dist(K, F_arm)。
第一项防止语义漂移，第二项惩罚不可行谱。

**定义 176（机械臂阻抗可行流形 MIFM）**
任务空间阻抗 K = (K_p, K_d) 经雅可比映射为关节力矩 τ = Jᵀ(K_p e + K_d ė) + τ_g(q)。可行集：
F_arm = { K | ‖τ‖∞ ≤ τ_max·(1−m_τ), q ∈ [q_min+m_q, q_max−m_q],
          σ_min(J(q)) ≥ σ_sing, ‖F_ee‖ ≤ F_payload, ‖ė‖ ≤ ė_max }
其中 m_τ、m_q 为安全裕度。**可行性投影**：
P_feas(K_prior) = argmin_{K∈F_arm} ‖K − K_prior‖²_Σ，
用其对 K_prior 做最小改动投影；若 P_feas 距离 > ε_infeas，则判定"语义先验不可实现"，回退到保守 K_safe 并写入 J_repro 的告警字段。可操作度 w(q)=√(det(JJᵀ)) 用于预测奇异接近度。

**定义 177（硬件在环可复现基准 RRAB）**
RRAB = (T, Z_B, Harness, Metrics, Π_protocol)：
- **任务套件** T = {peg_insert, wipe, cable_route, door_open, surface_follow}，每个任务带参数化难度与接触密集度标注；
- **基线动物园** Z_B = {pure_impedance, OSC, VICES, diffusion_policy, MPC}，各自绑定 BRC；
- **Harness**：统一 episode 生命周期、种子注入、扰动注入（摩擦/负载/位姿/延迟）、时钟同步、日志落盘；
- **指标** Metrics = {success_rate, contact_force_p95, completion_time, recovery_time, energy, jerk}；
- **协议** Π_protocol：预注册、固定评估种子集、禁止测试集调参、报告 CI 与失败图谱。

**定义 178（反事实复现回放 CRR）**
事件日志 L = {(t_i, type_i, payload_i)}，type ∈ {obs, action, contact, rand, clock}。回放算子 Replay(L, do(m := m′))：
- **确定性回放**：当且仅当日志记录全部影响转移的隐变量（含随机数、接触摩擦状态、外部扰动）时，Replay(L, do(∅)) 与原始运行在 ε_replay 内一致；
- **反事实替换**：固定 L 与种子，仅把模块 m 换为 m′，得到 Y(do(m′))，因果效应 Δ_m = E[Y | do(m)] − E[Y | do(m′)]；
- **可识别条件**：待替换模块的输入在 L 中可观测（backdoor 可阻断），否则只能给"部分可识别区间"而非点估计。

**定义 179（接触事件同步与时间戳对齐 CESTA）**
设接触事件定义为首帧 ‖F_ext‖ > τ_contact 的时刻。定义：
- **同步误差** e_sync = |t_contact^hw − t_contact^log|；
- **相位锚定** φ = (t_anchor − t_contact)/T_cycle，用于对齐"语义锚点相对接触的时序位置"；
- **抖动** J_sync = P95(|t_i^log − t_i^ros|)。
用 PTP/单调时钟消除墙钟跳变，所有跨设备事件重采样到统一时间轴；e_sync > ε_sync 的 episode 标记为"时序不可复现"并不计入 RSC。

**定义 180（复现统计证书 RSC）**
RSC = (n_seeds, CI_bootstrap, TOST, δ_eq, power, seed_sensitivity, prereg_hash, exclusion_log)：
- **bootstrap CI**：对指标做 B=10000 次分层重采样，报告 95% CI；
- **TOST 等价检验**：若 CI ⊂ [−δ_eq, +δ_eq]，则判定"与基线等价"；若 CI 下界 > δ_eq，则判定"显著优于基线"；
- **检验功效** power ≥ 1−β（β=0.2）；
- **种子敏感性**：留一法/去尾法检查结论是否由单一种子驱动；
- **预注册哈希** prereg_hash 在运行前锁定假设与指标，禁止事后挑选。
Valid(RSC) ⇔ CI 有效 ∧ power 达标 ∧ 种子敏感度 < θ_seed ∧ 无未声明排除。

**定义 181（失败图谱 FA）**
失败因果分类 F = {perception, contact_dynamics, kinematic, semantic, timing, hardware, protocol}。失败图谱：
FA(task, baseline, arm, cause) → (rate, CI, representative_log_hash)，
并构造**复现保真地图** M_map = FA × RFS：横轴任务、纵轴基线、颜色 RFS、标记主导失败类别。用途：若某方法 RFS 高但成功率低，说明"复现得很好但方法本身差"；若 RFS 低，则任何性能比较都无效。

**定义 182（复现感知预算 PCE++++++ / RAB）**
在 B_cog5 上增加复现预算：
B_cog6 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_repro)，
B_repro = (n_seeds_min, n_episodes_max, wall_clock_max, operator_time_max, δ_eq, ε_sync)。
价值函数扩展：voi_repro(action) = VOI_meta(action) − cost_cog5(action) − cost_repro(action)，
其中 cost_repro = λ_seed·(n_seeds/n_seeds_min) + λ_wall·(wall/wall_max) + λ_op·(operator/operator_max)。
降级策略：B_repro 耗尽 ⇒ 先减种子（保持每任务 ≥ 3），再切到仿真回放 CRR，最后输出"低功效告警"而非假装显著。

**定义 183（可复现证据联合证书 J_repro）**
J_repro = (J_sem_exec, RSC, RFS, replay_hash, env_digest, arm_id, failure_ref, cross_arm_gap)：
Valid(J_repro) ⇔ Valid(J_sem_exec) ∧ Valid(RSC) ∧ RFS ≥ τ_rfs ∧ ReplayConsistent(replay_hash, L) ∧ env_digest 匹配。

**定义 184（可复现具身闭环 REC）**
REC 算子（对每个任务、每个种子）：
```
REC(B, task, seed):
  contract ← BRC.build(B)                      # 契约与哈希
  env ← RRAB.reset(task, seed)                 # 确定性初始化
  for step in episode:
      K_safe, EV_exec, cert ← ESEC(M, obs)     # 第 61 轮闭环
      K_safe ← P_feas(K_morph)                 # MIFM 可行性投影
      L.append(event(step))                    # 事件溯源日志
  RSC ← certify(L, contract)                   # 统计证书
  FA.update(task, cause_of_failure(L))
  J_repro ← assemble(cert, RSC, RFS, replay_hash)
  return J_repro
```
聚合层把 RGD 的主因回灌到对应模块（硬件主因→换臂复验；实现主因→代码审计；协议主因→重预注册），使评估成为设计闭环的传感器。

```python
class ReproductionContract:
    def __init__(self, code, task, seeds, hardware, hyper, eval_protocol):
        self.code = code
        self.task = task
        self.seeds = seeds
        self.hardware = hardware
        self.hyper = hyper
        self.eval_protocol = eval_protocol

    def digest(self):
        payload = canonical_json({
            'code': self.code, 'task': self.task, 'seeds': self.seeds,
            'hardware': self.hardware, 'hyper': self.hyper,
            'eval': self.eval_protocol,
        })
        return sha256(payload)

class BaselineReproducer:
    def __init__(self, zoo, harness):
        self.zoo = zoo            # {name: baseline_factory}
        self.harness = harness

    def reproduce(self, name, contract, n_runs=30):
        results = []
        for seed in contract.seeds[:n_runs]:
            baseline = self.zoo[name](seed=seed, hyper=contract.hyper[name])
            with self.harness.episode(contract.task, seed, contract.hardware) as ep:
                for step in ep:
                    a = baseline.act(step.obs)
                    ep.step(a)
                results.append(ep.metrics())
        return Distribution(results)   # 不是标量，是分布

    def rfs(self, report_dist, new_dist, tau_rep):
        return math.exp(-standardized_distance(report_dist, new_dist) / tau_rep)
```

### IP-184 RGD（复现鸿沟方差分解）

```python
def reproduction_gap_decomposition(records):
    # records: list of dicts -> {impl, hw, protocol, seed, metric}
    # 多因素方差分析 + Shapley 方差归因
    factors = ['impl', 'hw', 'protocol', 'seed']
    grand_mean = mean(r['metric'] for r in records)
    ss_total = sum((r['metric'] - grand_mean) ** 2 for r in records)

    # 主效应
    ss_main = {}
    for f in factors:
        groups = group_by(records, f)
        ss_main[f] = sum(
            len(g) * (mean(x['metric'] for x in g) - grand_mean) ** 2
            for g in groups.values()
        )
    # 交互效应：残差按 Shapley 分摊（这里用二因子交互近似）
    ss_inter = ss_total - sum(ss_main.values())
    # Shapley 分摊交互到各主因子
    shapley = shapley_variance_attribution(records, factors)
    total = max(ss_total, eps)
    return {
        'impl': shapley['impl'] / total,
        'hw': shapley['hw'] / total,
        'protocol': shapley['protocol'] / total,
        'seed': shapley['seed'] / total,
        'interaction': max(0.0, ss_inter / total),
        'dominant': max(shapley, key=shapley.get),
    }
```

### IP-185/186 MASA + MIFM（形态适配与可行性投影）

```python
class MorphologyAwareAnchor:
    def __init__(self, d_us=256, arm_spec=None):
        self.adapter = FiLMAdapter(d_us, cond_dim=len(arm_spec.to_vector()))
        self.arm = arm_spec

    def adapt(self, anchor):
        cond = self.arm.to_vector()          # 关节数/力矩/负载/连杆
        emb = self.adapter(anchor.fused_emb(), cond)
        return anchor.with_embedding(emb)

class ImpedanceFeasibleManifold:
    def __init__(self, arm, margin_tau=0.1, margin_q=0.05, sigma_sing=0.02):
        self.arm = arm
        self.m_tau, self.m_q, self.sigma_sing = margin_tau, margin_q, sigma_sing

    def is_feasible(self, K, q, e, de):
        J = self.arm.jacobian(q)
        tau = J.T @ (K.Kp @ e + K.Kd @ de) + self.arm.gravity(q)
        ok = np.max(np.abs(tau)) <= self.arm.tau_max * (1 - self.m_tau)
        ok &= np.all(q >= self.arm.q_min + self.m_q)
        ok &= np.all(q <= self.arm.q_max - self.m_q)
        ok &= np.linalg.svd(J, compute_uv=False).min() >= self.sigma_sing
        ok &= np.linalg.norm(K.Kp @ e) <= self.arm.F_payload
        return ok

    def project(self, K_prior, q, e, de, lr=0.05, iters=30):
        K = K_prior.clone()
        for _ in range(iters):
            if self.is_feasible(K, q, e, de):
                return K, 0.0
            grad = self._constraint_gradient(K, q, e, de)
            K = K - lr * grad              # 投影到约束切空间
        return K, self._distance_to_feasible(K, q, e, de)  # >ε 则告警
```

### IP-187 RRAB Harness（硬件在环确定性基准）

```python
class RRABHarness:
    def __init__(self, arm, task_suite, baselines, clock):
        self.arm = arm
        self.tasks = task_suite
        self.baselines = baselines
        self.clock = clock
        self.log = EventLog()

    @contextmanager
    def episode(self, task, seed, hardware_cfg):
        self.clock.sync_ptp()
        rng = np.random.default_rng(seed)
        scene = task.sample_initial(rng)
        self.arm.reset(scene.q0)
        self._inject_perturbations(task, rng)
        ep = Episode(task, scene, rng, self.arm, self.log)
        try:
            yield ep
        finally:
            ep.finalize()
            self.log.flush(ep.id)

    def _inject_perturbations(self, task, rng):
        # 摩擦/负载/位姿/延迟四类扰动，全部由 seed 决定 -> 可复现
        self.arm.set_friction(task.friction.sample(rng))
        self.arm.set_payload(task.payload.sample(rng))
        self.arm.set_comm_latency(task.latency.sample(rng))
```

### IP-188 CRR（反事实复现回放）

```python
class CounterfactualReplay:
    def __init__(self, log):
        self.log = log

    def replay(self, episode_id, interventions=None):
        interventions = interventions or {}
        for ev in self.log.iter(episode_id):
            if ev.type == 'rand':
                np.random.set_state(ev.payload['rng_state'])   # 还原随机性
            elif ev.type == 'obs':
                obs = ev.payload
            elif ev.type == 'action':
                module = ev.payload['module']
                if module in interventions:
                    a = interventions[module].act(obs)          # do(module := m')
                else:
                    a = ev.payload['action']
                self.arm.apply(a)
            elif ev.type == 'clock':
                self.clock.set(ev.payload['t'])
        return self.log.metrics(episode_id)

    def causal_effect(self, episode_ids, module, baseline):
        y_do = np.mean([self.replay(e, {module: baseline})['success'] for e in episode_ids])
        y_orig = np.mean([self.log.metrics(e)['success'] for e in episode_ids])
        return y_orig - y_do       # Δ_module
```

```python
def reproduction_statistical_certificate(metrics, baseline_metrics,
                                         delta_eq=0.05, n_boot=10000, alpha=0.05):

            for _ in range(n_boot)]

    if lo > delta_eq:

    elif hi < -delta_eq:
        verdict = 'inferior'
    elif lo > -delta_eq and hi < delta_eq:
        verdict = 'equivalent'
    else:
        verdict = 'inconclusive'

    seed_sensitivity = leave_one_seed_out_spread(metrics)
    return {
        'ci': (lo, hi), 'verdict': verdict, 'power': power,
        'seed_sensitivity': seed_sensitivity,
        'valid': power >= 0.8 and seed_sensitivity < 0.3,
    }
```

```python
def reproduction_gap_decomposition(records):
    factors = ['impl', 'hw', 'protocol', 'seed']
    grand = mean(r['metric'] for r in records)
    ss_total = sum((r['metric'] - grand) ** 2 for r in records)
    shapley = shapley_variance_attribution(records, factors)  # 交互按 Shapley 分摊
    total = max(ss_total, 1e-12)
    out = {f: shapley[f] / total for f in factors}
    out['interaction'] = max(0.0, 1.0 - sum(out.values()))
    out['dominant'] = max(out, key=out.get)
    return out
```

```python
class ImpedanceFeasibleManifold:
    def __init__(self, arm, margin_tau=0.1, margin_q=0.05, sigma_sing=0.02):
        self.arm = arm
        self.m_tau, self.m_q, self.sigma_sing = margin_tau, margin_q, sigma_sing

    def is_feasible(self, K, q, e, de):
        J = self.arm.jacobian(q)
        tau = J.T @ (K.Kp @ e + K.Kd @ de) + self.arm.gravity(q)
        return (np.max(np.abs(tau)) <= self.arm.tau_max * (1 - self.m_tau)
                and np.all(q >= self.arm.q_min + self.m_q)
                and np.all(q <= self.arm.q_max - self.m_q)
                and np.linalg.svd(J, compute_uv=False).min() >= self.sigma_sing
                and np.linalg.norm(K.Kp @ e) <= self.arm.F_payload)

    def project(self, K_prior, q, e, de, lr=0.05, iters=30):
        K = K_prior.clone()
        for _ in range(iters):
            if self.is_feasible(K, q, e, de):
                return K, 0.0
            K = K - lr * self._constraint_gradient(K, q, e, de)
        return K, self._distance_to_feasible(K, q, e, de)  # >ε 触发告警
```

**正确性定理（REC-Reproducible）**：
假设 A61–A70 及新增 **(A71)** 契约完备且哈希无碰撞；**(A72)** P_feas 在凸近似可行域收敛且对可行点恒等；**(A73)** 日志记录全部隐变量，ε_replay→0；**(A74)** 种子 i.i.d.，bootstrap/TOST 前提成立；**(A75)** PTP 同步误差远小于接触时间尺度。则：
1. **可复现性**：H(B) 相同 ⇒ RFS(B) ≥ 1−ε_rep，RGD 可定位主因。
2. **物理可行性**：K_safe 满足力矩/关节/奇异/负载约束或显式告警，绝不静默越界。
3. **因果归因**：A73 下 Δ_m 为干预效应；不可识别时只给区间。
4. **统计严谨**：RSC 控制第一类错误 ≤ α；低功效显式 inconclusive。
5. **端到端**：Valid(J_repro) ⇔ 语义、执行、复现三重证书同时通过。

## 5. 本轮最大风险

**一句话**：若 RRAB 任务套件过窄、BRC 遗漏摩擦/接触/人因等隐变量、或 RGD 错误摊派交互效应，就会产出"自家机械臂上 RFS 很高、RSC 很漂亮、却完全无法外推"的**复现剧场（reproduction theater）**——统计证书认证的是噪声而非能力；必须以"预注册 + 多臂交叉复验 + 失败图谱强制公开 + 反事实可识别性检查"把"可复现"锚定在真实世界而非自家日志上。
