# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；本轮灵感：「视觉感知」×「自监督学习」）

> R69 把不确定性一分为二（aleatoric / epistemic），并让系统学会「问」。但它默认了一件更靠前的事：**产生模态的那个视觉表示本身是可信的**。R69 自陈的最大风险正是这一点——模态权重若未校准（rectified flow 幻觉出幻影模态、或坍缩掉真模态），VoI 就是在错误信念上计算，系统会自信地追问一个不存在的东西，并把人给的误导性回答盖上「已验证」的章。
>
> R70 因此不再往前加「更聪明的提问」，而是往回退一步问：**我的眼睛还可靠吗？可靠到足以提出一个有意义的问题吗？**
> - **视觉感知**给的不是又一路输入，而是「仪器 / 测量」的视角：注视、fovea、换视角、改曝光，首先是为了检验仪器是否还准，其次才是看清答案；多视角几何（重投影 / 光度一致性）提供物理锚定、不依赖标签的校验信号。
> - **自监督学习**给的是一组无标签、部署时可只读运行的一致性检验：掩码重建、视角一致、等变一致、时序可预测。它让「表示是否有效」第一次成为一个**可计算、可校准、可审计**的统计量。
>
> 核心命题：**在 FLUID 之外加一层「表示完整性门 IRIS」——先用自监督一致性检验组 + 无标签共形/序贯标定 + 坍缩解毒 + 语义捷径守卫 + 独立审计编码器，判定视觉表示是否可信；只有可信时，才允许 R69 的语义交互。不可信时禁止「问」，只允许认证的「再看一次」或退回 R68 纯保守。** 命名 **IRIS-RAS**（Invariant-Representation Integrity Seal；iris 兼指虹膜 / 光圈，视觉感知的双关）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我的观看本身可信吗**」——在问别人之前，先检验自己的眼睛。理论姿态：IRIS 对 FLUID 严格包含——PIV 通过时逐指令等于 FLUID；失败时安全侧不弱于 R68，效率损失以假警报率 α 为上界。

## 0. 直觉与动机

**灵感 1（视觉感知 → 注视是校准，不只是消歧）**
直觉：R69 的 `g_gaze` 是一个「信息动作」，目的是消解语义歧义——看清对方是笑还是紧张。但人还有另一种看：**凑近、换角度、眯眼、等眼睛适应**，这些不是为了得到答案，而是为了确认「我的眼睛此刻还能不能信」。前者是测量任务变量，后者是测量仪器本身。多视角几何给了后者一个物理锚：同一静止场景在两个已知位姿下的成像必须满足极线 / 重投影约束；这个残差不需要任何标签，也不依赖任务，因而是检验视觉表示的一条独立通道。

**灵感 2（自监督学习 → 无标签的仪器自校准）**
直觉：自监督 pretext 任务本质上是「用数据的一部分预测另一部分」：用周边预测中央（masked reconstruction）、用视角 A 的表示预测视角 B（view agreement）、用已知相机运动约束表示变换（equivariance）、用过去预测未来（temporal prediction）。这些都是**可检验的关系**，而不是需要人工标注的答案。部署时权重冻结，只把这些关系当作检验统计量；无标签意味着可以在真实分布上持续监控，而不是依赖一个可能过期的离线验证集。

**灵感 3（自洽 ≠ 正确 → 本轮最诚实的一刀）**
直觉：一台稳定的坏仪器可以每次读数都一致。坍缩编码器会把所有输入映到同一点，使一切一致性残差为 0；过强的不变性会把「把 A 看成 B」变成「不变」；对抗扰动可以专门保持 SSL 残差而翻转语义。所以**自监督最多证明「自洽 / 精度」，不能证明「正确 / 准确」**。R70 必须同时交付：坍缩解毒门（看表示是否退化）、语义捷径守卫（用行为 / 物理通道交叉验证）、双编码器独立性（避免审计与策略共享盲点）。否则 IRIS 会把 R69 的「幻影」升级成「已校准的幻影」。

**灵感 4（先校准仪器，再决定问谁 → 两种动作、两笔预算）**
直觉：R69 的交互预算不能修复坏表示——问人「这是猫吗」无法修复一个把一切都看成噪声的编码器；反过来，多看一眼通常也不能消解「绕左还是绕右」这种语义歧义，除非歧义本来来自看不清。于是 R70 区分**语义信息动作 g** 与**感知测量动作 h**，并主张两笔预算不可互相挪用。这不是工程细节，而是一条可形式化的正交分离（定义 324、定理 19）。

**灵感 5（部署时不能在线学习 → 双时间尺度）**
直觉：R68 的铁律是快速环零学习写操作。自监督很容易被误用成「部署时在线适应」——那会悄悄破坏这条铁律，并制造不可审计的漂移。R70 把 SSL 更新严格关进**维护期（MIP）**：版本化、留出集再认证、可回滚；快速环只读取冻结的 Φ_a、共形阈值与 e-process 统计量。自监督由此不是偷偷训练，而是被纳入证书。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（IRIS-RAS 总览与四不变式）** IRIS-RAS = (PIV, AVP, CDC, CAG, SSG, MIP, RAS-WM‡)。四不变式：
(i) **快速环零学习写操作**（继承 R68 定义 276-i）：Φ_a、共形阈值、e-process 超参在快速环内只读；
(ii) **感知动作是测量不是学习**：h 只产生新观测，不改参数，且必须过 R69 定义 302 的安全认证；
(iii) **表示门优先于语义交互**：PIV 未通过 ⇒ 禁止基于该表示的语义问句，只允许认证的测量动作或 R68 退避；
(iv) **双时间尺度**：任何 SSL/阈值更新只在维护期（MIP）发生，必须版本号 + 再认证 + 可回滚。

**定义 311（双编码器与审计独立性）** 任务编码 Φ_p（复用 R68 MTM trunk）给 z_t；审计编码 Φ_a（不同架构 / 目标 / 数据种子）给 z^a_t。定义表示失败相关度 ρ_rep = 在留出损坏集上估计的 P(Φ_p 失效 ∧ Φ_a 失效 | c) 与边缘失效率的归一化相关，或用 CKA 作上界。要求 ρ_rep ≤ ρ_max；否则审计与策略共享盲点（如同被某种纹理骗过），证书无效。

**定义 312（自监督一致性检验组 PIV）** 对观测 I_t 与已知相机变换 T_{t−1→t}，定义四类残差：
- e_mask：掩码 / 周边预测中央（fovea）的重建误差；
- e_aug：视角或光度增强下审计表示的负余弦不一致；
- e_equiv：等变残差 ‖Φ_a(T·I) − ρ(T)Φ_a(I)‖（T 已知时）；
- e_temp：时序 / 世界模型下一帧预测残差。

用经验 CDF 变换 q_j 规范化，s_t = Σ_j w_j q_j(e_j)。PIV 通过 ⇔ s_t ≤ τ_α 且 e-process 未报警且 CAG 通过。

**定义 313（无标签共形 / 序贯标定 CDC）** 维护期冻结标定集 D_cal（ID 无标签观测）。split conformal 阈值 τ_α 取 s_(⌈(n+1)(1−α)⌉)；在可交换性下 P(s_new ≤ τ_α) ≥ 1−α（引理 19）。流式监控构造 e-process E_t = Π_{i≤t}(1 + λ_i(s_i − τ_α))，在「表示有效」零假设下为超鞅，故 P(∃t: E_t ≥ 1/α) ≤ α（anytime-valid）。真实漂移破坏可交换性时，保证退化为条件近似——此时只收紧、不放松（A100）。

**定义 314（坍缩解毒门 CAG）** 设审计嵌入协方差特征值为 λ_i，有效秩 r_eff = exp(−Σ_i (λ_i/Σλ) log(λ_i/Σλ))，并检查嵌入方差与残差方差。若 r_eff < r_min 或方差 < v_min 或残差全部退化（方差≈0），则 PIV 一律判无效。理由：坍缩编码器可让所有一致性残差趋零（引理 20）。

**定义 315（语义捷径守卫 SSG）** SSL 一致性对「保持自洽的语义翻转」不敏感。SSG 要求 PIV 与至少一条独立通道一致：R69 FMA 的动作似然 a_score、多视角几何重投影残差、或维护期小样本线性探针。判据：PIV 通过而 FMA 报警 ⇒ shortcut_suspect（不放行）；PIV 失败而 FMA 正常 ⇒ representation_suspect（只许测量）；两者皆警 ⇒ 维护标记 + R68 纯保守。

**定义 316（主动视觉测量 AVP）** 测量动作 h = (viewpoint, fovea, exposure, dwell) ∈ ℋ，与 R69 语义信息动作 g 分离。选择

h* = argmax_h E_{e|h}[ D_KL(p(e|h, valid) ‖ p(e|h, invalid)) ] − c(h)，

s.t. 安全认证、测量预算（每窗口 ≤ 1 次、位移 ≤ ε_h、打扰 ≤ c_h^max）。直觉：选对「表示是否有效」这个假设最有**检验功效**的视角，而不是对任务最有信息量的视角；多视角至少两视，视角间一致性差异即检验统计量。

**定义 317（第三通道：表示不确定性 U_rep）** 总不确定性 = (U_ale, U_epi, U_rep)。U_rep 为表示无效 / 漂移的后验风险（由 PIV 分数、CAG、SSG 融合）。它与前两者语义不同：**不能由语义交互降低**（问人修不好编码器），只能由测量动作或维护期更新降低。仅当 U_rep ≤ τ_rep 时，R69 的 VoI 才有定义。

**定义 318（IRIS 门控与三级退避）**
- **valid**（PIV ∧ CAG ∧ SSG）：原样交给 FLUID，resolution bonus 可用；
- **rep_suspect**：禁止语义问句；λ = λ_floor(U_ale + U_epi + U_rep)（未消解表示风险叠加）；允许一次 AVP，恢复则回 valid；
- **shortcut_suspect / 双警**：直接 R68 纯保守 + 维护标记，本轮不信任任何模态分布。

安全侧 λ 单调不降；效率侧假警报概率受 α 控制（引理 19）。

**定义 319（维护期自监督更新 MIP）** 维护期可用无标签数据更新 Φ_a、标定集与 e-process 参数。更新前在留出集验证：假警报 ≤ α、r_eff ≥ r_min、ρ_rep ≤ ρ_max、任务探针不退化。通过则 mip_version += 1 并写 audit log，失败回滚；快速环永不写。任何更新都触发 J_IRIS 重新签发。

**定义 320（视觉-自监督威胁模型 ℰ_IRIS）** ℰ_IRIS = ℰ_FLUID × ℰ_ssl_shortcut（SSL-一致语义翻转 / 对抗）× ℰ_collapse（坍缩诱导）× ℰ_view_spoof（对所有视角都一致的纹理 / 显示欺骗）× ℰ_cal_poison（标定集投毒）。每条威胁至少对应一个检验或证书字段。

**定义 321（证书 J_IRIS）** J_IRIS = (J_FLUID, piv_pass, s_t, τ_α, eproc_alarm, r_eff, rho_rep, ssg_agreement, avp_log_hash, mip_version, iris_ver)。Valid ⇔ Valid(J_FLUID) ∧ PIV pass ∧ CAG pass ∧ SSG agree ∧ e-process 未报警 ∧ ρ_rep ≤ ρ_max。

**定义 322（占空比与实时预算）** 轻量检查（e_aug, e_temp）每帧；重量检查（e_mask, e_equiv, CAG 谱）每 N 帧或在 mode_head/COF 报警时；AVP 仅在 rep_suspect 且预算允许时。N 自适应，保证 P99。

**定义 323（审计独立性度量 ρ_rep）** 见定义 311；补充：可用留出损坏集上的条件失效相关估计，或用 CKA(Φ_p, Φ_a) 作为共享表征上界。ρ_rep > ρ_max ⇒ 证书无效（审计不可信）。

**定义 324（测量-消歧正交分离）** 设语义模态 M 与表示有效性 V。若在给定观测下 h ⊥ M | (V, o) 且 g ⊥ V | (M, o)（A102），则 H(M | h, o) = H(M | o)、H(V | g, o) = H(V | o)。即测量动作不消解语义歧义，语义问句不修复表示；两笔预算不可互相挪用。

## 2. 关键算法骨架

```python
# IP-264 PIV：自监督一致性检验组（部署时只读）
class PerceptualIntegrityVerifier:
    def __init__(self, phi_policy, phi_audit, cdc, cag, ssg):
        self.phi_p, self.phi_a = phi_policy, phi_audit      # 双编码器
        self.cdc, self.cag, self.ssg = cdc, cag, ssg

    def residuals(self, I, T=None):
        za = self.phi_a(I)
        e = {
            "mask":  masked_recon_residual(self.phi_a, I),          # 周边→中央
            "aug":   1.0 - cosine(za, self.phi_a(augment(I))),      # 视角一致
            "equiv": equivariance_residual(self.phi_a, I, T) if T else 0.0,
            "temp":  temporal_pred_residual(za, self.prev_za),      # 下一帧
        }
        self.prev_za = za
        return e, za

    def check(self, I, T=None, fma_ok=None):
        e, za = self.residuals(I, T)
        s = self.cdc.normalize(e)                   # 经验 CDF 加权和
        piv = self.cdc.within(s) and self.cdc.eproc_update(s) is False
        cag = self.cag.effective_rank(za) >= self.cag.r_min
        ssg = self.ssg.agree(piv, fma_ok)            # 与行为/几何通道交叉
        return {"piv": piv, "cag": cag, "ssg": ssg,
                "s": s, "e": e, "za": za}

# IP-265 AVP：选最有检验功效的测量动作；不是消歧，是校准
def choose_measurement(obs, e, budget):
    best = None
    for h in measurement_candidates(obs):            # 换视角/注视/fovea/曝光
        if not budget.allow_measure(h):          continue
        if not c_ras_wm.certify_info(h, obs):    continue
        power = expected_kl(e, h)                # valid vs invalid 的可分性
        score = power - cost(h)
        if best is None or score > best.score: best = (h, score)
    return best if best and best.score > 0 else None

# IP-270 IRIS 主闭环：门控优先于 R69 的语义交互
def IRIS_RAS_round(M, obs):
    fma_ok = M.fma.not_alarming()                    # R69 行为通道
    c = M.piv.check(obs.I, obs.T, fma_ok=fma_ok)
    state = classify(c)                              # valid / rep_suspect / shortcut
    if state == "valid":
        return M.fluid.round(obs), "valid"           # 逐指令回到 R69
    if state == "rep_suspect":
        h = M.avp.choose_measurement(obs, c["e"], M.budget)
        if h is not None:
            obs2 = M.avp.execute(h)                  # 只产生新观测，不学习
            c2 = M.piv.check(obs2.I, h.T, fma_ok=fma_ok)
            if classify(c2) == "valid":
                return M.fluid.round(obs2), "recovered"
        return M.r68.conservative_round(obs), "quarantine"
    # shortcut_suspect / 双警：不信任任何模态分布
    M.maintenance.flag(obs, c)
    return M.r68.conservative_round(obs), "quarantine"
```

## 3. 推导

**引理 19（共形与 e-process 的假警报控制）** 若标定集与部署观测可交换，split conformal 满足 P(s_t ≤ τ_α) ≥ 1−α；若零假设下 E_t 为超鞅，则序贯规则「首次 E_t ≥ 1/α 即报警」满足 P(∃t 报警) ≤ α。二者均不需要标签，也不需要假设编码器正确。系：**IRIS 把「误把好表示判坏」的概率控制在 α**，这是效率损失的显式上界。

**引理 20（一致性不蕴含有效性）** 存在坍缩编码器 Φ_c（对所有 I 输出常数 c），使 e_mask、e_aug、e_equiv、e_temp 全为 0，从而 s_t = 0 恒过 PIV；也存在对抗扰动 δ，使 ‖δ‖ ≤ ε 且 PIV 残差不变而任务语义翻转。故 PIV 单独既非充分（坍缩）也非鲁棒（对抗）；CAG（排除退化谱）与 SSG（行为 / 物理交叉）是必要条件，而非锦上添花。

**引理 21（审计独立性的共谋上界）** 设有单一损坏 c 同时骗过 Φ_p 与 Φ_a 的概率上界为 p_shared，独立失效概率为 p_ind；则联合漏检率 ≤ p_shared + (1−p_shared)·p_ind·ρ_rep。ρ_rep → 0 时退化为单通道失效；ρ_rep → 1 时双编码器无增益。故定义 311 的 ρ_max 直接决定 IRIS 相对单编码器的安全增益。

**引理 22（AVP 的检验功效）** 在 A101（不同视角下 valid 与 invalid 的残差分布满足一定可分性）下，选择使 KL 最大的 h 使检验功效（1−β）单调最大；两视角差异统计量在 H_invalid 下的期望 ≥ 单视角的 2 倍（成对抵消共同噪声）。系：**校准仪器的最优动作是「换一个能放大偏差的视角」，而不是「再仔细看同一处」**。

**定理 18（IRIS 严格包含 FLUID 与 R68）** 在 A100–A102 下：
(a) 若 PIV、CAG、SSG 全通过，IRIS 逐指令等于 R69 的 FLUID（gate 不改变任何决策）；
(b) 若表示无效，IRIS 禁止语义交互并把 U_rep 并入 λ_floor，其安全风险 ≤ R68（因为只增加了保守项、去掉了可能基于坏表示的交互）；
(c) 假警报概率 ≤ α（引理 19），故效率损失以 α 为上界，且 α 可调。

因此 R69 是 IRIS 在「表示恒有效」边界上的退化，R68 是「表示恒无效」边界上的退化。

**定理 19（测量-消歧不可替代）** 在 A102 的正交条件下，感知测量 h 对语义模态 M 的信息增益为 0，语义信息动作 g 对表示有效性 V 的信息增益为 0。故 R69 的交互预算不能替代 R70 的测量预算；把两者混入同一 VoI 会系统性高估交互价值（尤其在表示已坏时）。这是把「先校准仪器，再决定问谁」写成数学，而不是口号。

**定理 20（双时间尺度与无突变）** MIP 更新只发生在维护边界，更新后 J_IRIS 版本单调递增并重新认证；快速环中 Φ_a、τ_α、e-process 参数只读。故快速环的输入-输出映射在两次维护之间连续，R68 的提交 / 换装不变式（定理 15）与 R69 的交互无突变（定理 17）均保持。

## 6. 本轮最大风险

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** IRIS-RAS = (PIV, AVP, CDC, CAG, SSG, MIP, RAS-WM‡)；快速环零学习写；感知动作是测量不是学习；表示门优先于语义交互；SSL 更新仅在维护期且版本化 / 再认证 / 可回滚。

**定义 311（双编码器与审计独立性）** Φ_p（任务）与 Φ_a（不同架构 / 目标 / 种子）双编码；`ρ_rep ≤ ρ_max` 才可审计，防共享盲点。

**定义 312（PIV）** 四类残差 `e_mask`（周边→中央重建）、`e_aug`（视角一致）、`e_equiv`（已知相机变换下的等变残差）、`e_temp`（时序预测）；经验 CDF 加权得 `s_t`；通过 ⇔ `s_t ≤ τ_α ∧ eproc 未警 ∧ CAG 通过`。

**定义 313（CDC）** 冻结无标签标定集；split conformal 给 `τ_α`，`P(s ≤ τ_α) ≥ 1−α`；e-process 给序贯 anytime-valid 假警报控制；非可交换时只收紧不放松。

**定义 314（CAG）** 有效秩 `r_eff`、嵌入方差、残差方差；任一退化 ⇒ PIV 无效（防坍缩）。

**定义 315（SSG）** PIV 需与 FMA 行为似然 / 几何重投影 / 维护期探针一致；`PIV 过 ∧ FMA 警` ⇒ shortcut_suspect；`PIV 败 ∧ FMA 正常` ⇒ representation_suspect。

**定义 316（AVP）** `h* = argmax_h E[D_KL(p(e|h,valid)‖p(e|h,invalid))] − c(h)`，s.t. 安全认证与测量预算；选「放大偏差」的视角，而非「看清任务」的视角。

**定义 317（U_rep）** 第三通道；不能由语义交互降低，只能由测量或维护降低；`U_rep ≤ τ_rep` 时 R69 的 VoI 才有定义。

**定义 318（三级退避）** valid → FLUID；rep_suspect → 禁语义问句、λ 叠加 U_rep、允许一次 AVP；shortcut / 双警 → R68 纯保守 + 维护标记。

**定义 319（MIP）** 维护期更新 Φ_a / 标定集 / e-process；留出再认证（假警报 ≤ α、r_eff、ρ_rep、任务探针）；版本 +1、audit log、失败回滚、快速环永不写。

**定义 320（ℰ_IRIS）** ℰ_FLUID × ℰ_ssl_shortcut × ℰ_collapse × ℰ_view_spoof × ℰ_cal_poison。

**定义 321（J_IRIS）** Valid ⇔ Valid(J_FLUID) ∧ PIV ∧ CAG ∧ SSG ∧ e-process 静默 ∧ `ρ_rep ≤ ρ_max`。

**定义 322（占空比）** 轻量检查每帧；重量检查每 N 帧或报警时；AVP 仅 rep_suspect；N 自适应守 P99。

**定义 323（ρ_rep 度量）** 留出损坏集条件失效相关，或 CKA(Φ_p, Φ_a) 上界；超限则证书无效。

**定义 324（测量-消歧正交分离）** 在 `h ⊥ M | (V,o)`、`g ⊥ V | (M,o)` 下，`H(M|h,o)=H(M|o)`、`H(V|g,o)=H(V|o)`；两笔预算不可互挪。

## 3. 关键算法伪代码

```python
# IP-264 PIV：自监督一致性检验组（部署只读）
class PerceptualIntegrityVerifier:
    def residuals(self, I, T=None):
        za = self.phi_a(I)
        return {
            "mask":  masked_recon_residual(self.phi_a, I),
            "aug":   1.0 - cosine(za, self.phi_a(augment(I))),
            "equiv": equivariance_residual(self.phi_a, I, T) if T else 0.0,
            "temp":  temporal_pred_residual(za, self.prev_za),
        }, za

    def check(self, I, T=None, fma_ok=None):
        e, za = self.residuals(I, T)
        s   = self.cdc.normalize(e)
        piv = self.cdc.within(s) and not self.cdc.eproc_update(s)
        cag = self.cag.effective_rank(za) >= self.cag.r_min
        ssg = self.ssg.agree(piv, fma_ok)
        return {"piv": piv, "cag": cag, "ssg": ssg, "s": s, "e": e}

# IP-265 AVP：按检验功效选测量动作（不是消歧）
def choose_measurement(obs, e, budget):
    best = None
    for h in measurement_candidates(obs):
        if not budget.allow_measure(h):       continue
        if not c_ras_wm.certify_info(h, obs): continue
        score = expected_kl(e, h) - cost(h)
        if best is None or score > best.score: best = (h, score)
    return best if best and best.score > 0 else None

# IP-274 IRIS 主闭环：门控优先于 R69 的语义交互
def IRIS_RAS_round(M, obs):
    fma_ok = M.fma.not_alarming()
    c = M.piv.check(obs.I, obs.T, fma_ok=fma_ok)
    state = classify(c)                       # valid / rep_suspect / shortcut
    if state == "valid":
        return M.fluid.round(obs), "valid"    # 逐指令回到 R69
    if state == "rep_suspect":
        h = M.avp.choose_measurement(obs, c["e"], M.budget)
        if h is not None:
            obs2 = M.avp.execute(h)           # 只产生新观测，不学习
            if classify(M.piv.check(obs2.I, h.T, fma_ok)) == "valid":
                return M.fluid.round(obs2), "recovered"
        return M.r68.conservative_round(obs), "quarantine"
    M.maintenance.flag(obs, c)
    return M.r68.conservative_round(obs), "quarantine"
```

## 4. 推导

**引理 19（共形 / e-process 假警报控制）** 可交换性下 `P(s ≤ τ_α) ≥ 1−α`；零假设超鞅下 `P(∃t: E_t ≥ 1/α) ≤ α`。无需标签、无需编码器正确 ⇒ 「误判好表示」概率 ≤ α，是效率损失的显式上界。

**引理 20（一致性不蕴含有效性）** 常数 / 坍缩编码器使所有残差为 0 而恒过 PIV；对抗扰动可保持残差而翻转语义。故 PIV 非充分、非鲁棒；CAG 与 SSG 是必要条件。

**引理 21（审计独立性的共谋上界）** 联合漏检 ≤ `p_shared + (1−p_shared)·p_ind·ρ_rep`；`ρ_rep→0` 时双编码器显著增益，`ρ_rep→1` 时无增益。

**引理 22（AVP 检验功效）** 选 KL 最大的视角使 `1−β` 单调最大；两视角差异统计量在 invalid 下的期望 ≥ 单视角 2 倍（共同噪声成对抵消）。

**定理 18（IRIS 严格包含 FLUID 与 R68）** PIV/CAG/SSG 通过时逐指令等于 R69；表示无效时禁语义交互并把 U_rep 并入 λ_floor，安全风险 ≤ R68；假警报 ≤ α ⇒ 效率损失有界。R69 = 「表示恒有效」边界，R68 = 「表示恒无效」边界。

**定理 19（测量-消歧不可替代）** 正交条件下 h 对 M、g 对 V 的信息增益均为 0；交互预算不能替代测量预算，混合会高估交互价值。

**定理 20（双时间尺度与无突变）** MIP 更新只在维护边界；J_IRIS 版本单调、再认证；快速环只读 ⇒ R68 提交/换装不变式与 R69 交互无突变均保持。

## 7. 本轮最大风险

**一句话**：自监督只能证明「自洽」，不能证明「正确」——一个稳定坍缩、系统性偏置或专门保持 SSL 残差的编码器可以让 PIV 全部一致通过，于是 IRIS 会给 R69 的幻影模态盖上「仪器已校准」的章；**自洽的盲目比诚实的模糊更危险**。

**次级风险与缓解**：共形交换性失效（序贯 e-process + 只收紧不放松 + E311）；坍缩 / 捷径漏检（CAG 有效秩门 + SSG 交叉 + E303/E304）；审计与策略共谋（双编码器 + ρ_rep 上限 + E305）；测量预算滥用（定义 316 硬预算 + 认证 + E307）；维护期标定污染（定义 319 留出再认证 + 可回滚 + ℰ_cal_poison）。
