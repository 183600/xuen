# 第 46 轮（承接第 45 轮 v10；本轮灵感：步骤分 × 模仿学习） · StepCert-IL：步骤分驱动的模仿学习步级证书与过程安全（四层架构 v11）

> 承接第 45 轮 v10 Energy-Context-Depth。v10 用能量租约与上下文预测守住了“感知是否可用”，但隐含假设 H5：任务安全仍是终态二值谓词，只要最终 φ(X_T) 成立、姿态证书不失效即可；数据采集也只服务几何/姿态覆盖。UniBot 的抓取-搬运-放置是长程多步任务，真正的安全违例常发生在中间步（抓空、滑落、拿错物体、放置碰撞），终态成功会掩盖过程违例。两个灵感词精确命中 H5：**步骤分**把“成功/失败”细化为每个中间步的部分得分，使安全谓词从终态下沉到过程；**模仿学习**从人类示教中同时获得步骤切分、子目标标签与稠密进度监督，是可规模化获取步骤分的现实途径，但它继承示教分布与部署分布之间的协变量偏移。二者耦合出新问题：**如何让模仿学习给出的步骤分成为可验证的保守下界，并在分布偏移下防止“虚高步骤分”让过程守卫放行不安全中间态**。

## 0. 直觉与动机

**灵感 1（步骤分 → 过程证书与保守下界）**
直觉：老师给解题过程打步骤分，是因为只看最终答案无法区分“蒙对”和“真会”。机器人同理：只看终态成功无法区分“安全完成”和“侥幸完成”。把任务 φ 分解为步骤 s_1…s_K，每步有谓词 φ_k；步骤分 z_{t,k} 不应是乐观估计，而应是**真实完成度的保守下界**（z_{t,k} ≤ 1[φ_k 成立]）。只有当 z_{t,k} 达到阈值 θ_k 且该步姿态证书仍覆盖时，才允许进入下一步。安全因此从“终态检查”变成“逐步放行的过程证书”。

**灵感 2（模仿学习 → 可扩展的步骤切分与进度监督）**
直觉：人工标注每一步既贵又主观，而人类示教天然包含步骤边界、子目标与进度节奏。用示教数据同时训练 π_IL(a|o) 与步骤分评论家 g_ψ(o)→ẑ，可低成本获得稠密步骤分。但模仿学习的致命弱点是分布偏移：部署时一旦偏离示教流形，g_ψ 的输出既不准也不可校准，乐观偏差会直接变成安全漏洞。

**灵感 3（耦合 → 步骤分不确定性作为 OOD 触发器与采集信号）**
直觉：步骤分本身的不确定性是宝贵的元信号。当 g_ψ 的步骤分置信低或 OOD 分数高时，不应相信它，而应 (a) 触发 fail-closed 的保守步骤盒，(b) 把该状态作为高价值样本回灌采集（DAgger 式人工纠正），(c) 把模仿策略的执行权限限制在已认证包络内。于是步骤分既是监督信号，也是数据采集的主动学习准则。

**耦合升级**：在 v10 四层架构上插入 **步级证书层（Step-Cert Layer）**，四层 v11：根信任层（姿态租约 + 能量租约 + 步骤租约 ℓ_s），L1 几何层（步骤条件化的 ω_t 与 r_ω），L2 上下文层（上下文预测同时预测下一步），L2.5 步级层（步骤切分、步骤分证书、OOD 门控），L3 CAR（过程守卫逐步放行），L4 DCL（步骤分不确定性驱动示教采集）。模仿策略只在步级证书有效时获得执行权。

## 1. 形式化定义（增量：定义 54–57）

**定义 54（步骤分解与步骤分证书）**
任务 φ 分解为有序步骤 S={s_1,…,s_K}，每步谓词 φ_k:X→{0,1}。步骤分向量 z_t∈[0,1]^K，任务进度
C(z_t)=Σ_k w_k z_{t,k} / Σ_k w_k。
**保守性（soundness）**：认证步骤分满足 z_{t,k} ≤ 1[φ_k(X_t)]，即它必须是真实完成度的下界而非乐观估计。**步骤完成判据**：z_{t,k} ≥ 1-ε_k 且 φ_k 由独立证据（几何/力/视觉）确认。步骤租约 ℓ_s=(k, θ_k, τ_s) 规定当前允许停留的步骤与超时。

**定义 55（模仿学习步骤分估计器与偏移界）**
示教集 D={(o_i,a_i,κ_i,ζ_i)}，κ_i 为步骤标签，ζ_i 为人工步骤分。训练模仿策略 π_IL(a|o) 与评论家 g_ψ(o)=(ẑ, u)，u 为不确定性/OOD 分数。用分裂共形校准偏移 q_s，使在可交换假设下
P( ẑ_{t,k} - q_s ≤ z_{t,k} ) ≥ 1-α_s。
设示教分布 D_demo 与部署分布 D_dep 的 TV 距离 δ_TV，则偏移下界损失满足 |E_dep[ẑ]-E_demo[ẑ]| ≤ L_g·δ_TV。若 u_t>τ_ood 或 δ̂_TV>δ_max，则步骤分证书**不可用**。

**定义 56（步级联合证书与过程守卫）**
步级证书 S_{t,k}=(P_{t,k}, z_{t,k}, ℓ_p, ℓ_e, ℓ_s, m_t)。**步级 soundness**：
P( X_t∈P_{t,k} ∧ z_{t,k} ≤ z^true_{t,k} | ω_t,m_t,ℓ_e,ℓ_s 有效 ) ≥ 1-α_p-α_s。
**过程守卫**：允许从步 k 迁移到 k+1 当且仅当
z_{t,k} ≥ θ_k ∧ P_{t,k}⊆Safe_k ∧ E(t)≥E_min ∧ ℓ_s 未超时；
否则冻结在步 k 并进入保守步骤盒（降速/回退/请求人工）。

**定义 57（步骤分驱动的模仿学习采集与执行约束）**
示教采集效用
A(o)= U_step(g_ψ(o)) · Deficit_ω(o) · 1[o∈∂M] / (c_demo+c_e),
其中 ∂M 为策略流形边界，Deficit_ω 为几何覆盖缺口。执行策略
π_exec = π_IL 若 u_t<τ_ood ∧ S_{t,k} 有效；否则 π_exec=π_safe（脚本化/后退时域）。
**DAgger 式纠正**：把 π_exec 偏离示教流形且步级证书失败的样本优先回灌 D。

## 2. 三大新增产出与既有 IP 升级

**IP-66 STEP-CERT DECOMPOSER（步骤分证书分解器）**
- 从示教与任务规划联合推断步骤边界与 φ_k
- 步骤分保守化：把 g_ψ 的点估计经共形校准转成下界 z
- 步骤租约 ℓ_s 与超时/重试语义
- 独立证据融合：几何到位、夹爪力、视觉子目标确认

**IP-67 IL STEP-CRITIC（模仿学习步级评分器）**
- 多任务头：π_IL 动作头 + g_ψ 步骤分头 + u OOD 头
- 分裂共形校准 q_s，保证步骤分下界覆盖率
- 协变量偏移监测：特征密度比/能量分数，δ̂_TV 在线估计
- 偏移超阈 → 证书降级 + 采集任务

**IP-68 PROCESS GUARD（过程守卫）**
- 逐步放行状态机：只有步级证书通过才推进 ℓ_s
- 保守步骤盒：降速、回退到上一已认证步、请求人工接管
- 与 CAR 的级联：步骤租约失效 → 姿态/能量证书一并 fail-closed

**既有 IP 升级**
IP-60 PSE：ω_t 与 r_ω 增加步骤条件，按当前步 k 选择退化层先验
IP-61 DCL：采集效用加入步骤分不确定性与示教纠正项（定义 57）
IP-62 CCA：新增模仿学习协变量偏移红队、步骤分乐观偏差注入测试
IP-63 ECPS：能量预算按步骤分配，关键步（抓取/放置）保底能量
IP-51 CAR：守卫加入步级证书与步骤租约一致性
IP-45 总线：新增 step-credit / step-lease / ood-score / demo-request 话题

## 3. 算法骨架

StepCert-IL 每个控制周期：
1. 读 o_t、当前步 k、ℓ_s、ℓ_p、ℓ_e
2. g_ψ(o_t) → (ẑ_t, u_t)，共形校准得下界 z_t
3. 若 u_t>τ_ood 或 δ̂_TV>δ_max：证书不可用 → 保守步骤盒，并生成 demo-request
4. 融合独立证据确认 φ_k；计算步级证书 S_{t,k}
5. 若 z_{t,k}≥θ_k ∧ P_{t,k}⊆Safe_k ∧ 能量可行：推进 ℓ_s 到 k+1
6. 否则冻结步骤，π_exec 回退 π_safe；CAR 用 S_{t,k} 守卫
7. 采集器按 A(o) 排序回灌示教，周期性重训/校准 g_ψ

## 4. 本轮最大风险

**一句话**：模仿学习步骤分在部署分布偏移下会系统性乐观，若过程守卫把虚高的步骤分当作真实完成度放行，安全违例将从终态前移到中间步且更难被终态检查发现；因此必须以共形下界替代点估计、以 OOD 分数硬门控执行权，并在任何偏移超阈时 fail-closed 到保守步骤盒。

## 2. 关键算法 伪代码

### IP-66 Step-Cert Decomposer
```
def step_credit_lower_bound(ghat, o, calib):
    z_hat, u = ghat(o)                 # 步骤分点估计 + OOD 分数
    z = z_hat - calib.q_s              # 分裂共形下界
    return clip(z, 0, 1), u

def confirm_step(k, evidence):
    # 独立证据：几何到位 / 夹爪力 / 视觉子目标
    return evidence.geom_reached and evidence.force_ok and evidence.subgoal_seen

def step_cert(k, o, calib, evidence, lease_p, lease_e):
    z, u = step_credit_lower_bound(critic, o, calib)
    ok = confirm_step(k, evidence)
    return StepCert(P=pose_cert(o,k), z=z, valid=(ok and z[k]>=theta[k]),
                    lease_p=lease_p, lease_e=lease_e, lease_s=lease_s)
```

### IP-67 IL Step-Critic
```
def il_step_critic(o):
    z_hat = net_step(o)                # |S| 维步骤分
    u = ood_score(o, demo_stats)       # 密度比/能量分数
    delta_tv = estimate_tv(o, demo_stats)
    return z_hat, u, delta_tv

def step_cert_valid(z, u, delta_tv, tau_ood, delta_max):
    return u < tau_ood and delta_tv < delta_max and z_is_calibrated(z)
```

### IP-68 Process Guard
```
def process_guard(o, k, lease_s, lease_p, lease_e, calib, t):
    if not (pose_lease_valid(lease_p,t) and energy_lease_valid(lease_e,t,E_min)):
        cascade_invalidate('pose_energy'); return FailClosed()
    if not step_lease_valid(lease_s,k,t):
        return ConservativeStepBox('step_timeout')
    z, u, d = il_step_critic(o)
    if not step_cert_valid(z,u,d,tau_ood,delta_max):
        request_demo(o); return ConservativeStepBox('ood')
    if z[k] < theta[k] or not (pose_cert(o,k).P <= Safe_k):
        return FreezeStep(k)
    return Advance(k+1)
```

### IP-61 DCL 升级：步骤分驱动采集
```
def demo_utility(o):
    z, u, d = il_step_critic(o)
    boundary = indicator(o in policy_boundary)
    return (u * coverage_deficit(o) * boundary) / (c_demo + c_e)
```

### IP-51 CAR 升级守卫
```
def car_guard_v7(e,x,cert,persona,lease_p,lease_e,lease_s,m_t,t):
    if not pose_lease_valid(lease_p,t) or not energy_lease_valid(lease_e,t,E_min(e)):
        cascade_invalidate('pose_energy'); return FailClosed()
    if not step_lease_valid(lease_s, x.step, t):
        cascade_invalidate('step'); return FailClosed()
    r = radius_lookup(x.stratum, m_t, cert.calib)
    m = min(cert.lookup, lease_p.m, persona_cap) \
        - L_phi[e]*r - L_e*(B_min - E(t))_+ - L_s*(1 - cert.z[x.step])
    return m >= theta(e)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| Step-Cert Decomposer | O(|S|) 每步 | O(|S|·d_o) | 共形下界 ⇒ P(z≤z_true)≥1-α_s |
| IL Step-Critic | O(d_o) 前向 | O(params) | OOD 分数 + 偏移界 ⇒ 证书可用性判定 |
| Process Guard | O(|S|) 状态机 | O(|S|) | 步级证书 ∧ 租约 ⇒ 逐步 sound；否则 fail-closed |
| DCL 步骤分采集 | O(N·d_o) 批排序 | O(N) | 采集效用优先覆盖流形边界 |
| 步级联合证书 | O(1) | O(V+E) | ℓ_s∧ℓ_p∧ℓ_e∧z 下界 ⇒ φ_k^□ ⇒ 过程安全 |

正确性定理：若步骤租约 ℓ_s 有效、姿态/能量租约有效、步骤分下界满足 z_{t,k}≤z^true_{t,k}（共形覆盖率 ≥1-α_s）、且 δ̂_TV<δ_max、u<τ_ood，则过程守卫在第 k 步保持 sound；任一条件失效则冻结步骤并进入保守步骤盒或 fail-closed，不推进到 k+1。
