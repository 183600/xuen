# 第 43 轮（新循环第 3 轮） · 语义即安全：把语义分割的不确定性升级为「任务条件语义证书」，把 UniBot 世界挑战赛变成「证书竞技场」（SemCert × SGSF × CAC，四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」，本质是**验证链路与知识检索的可信度**。但前 42 轮所有证书都默认了一个从未被认证的前提：**「什么算障碍」这个语义判断本身是对的**。真实机器人上，「能否穿越/踩踏/抓取」是任务相关的语义问题：玻璃桌几何上近乎透明却是禁区，镜面反射几何上是实体却是虚像，无纹理地板几何退化却完全可走，水渍、帘布、电线、玩具与地面的几何边界极其模糊；同一个「平面」，在「送餐」任务里是桌面，在「收纳」任务里是可踩区域。本轮灵感词「语义分割」「UniBot 世界挑战赛」给出两个抓手：**语义分割**把「像素标签」升级为「带覆盖保证的标签集合」，让证书能对语义世界的不确定性取最坏情况；**UniBot 世界挑战赛**提供标准化任务分布、评分规则与隐藏测试集，可作为证书真正的「竞技场」，用任务失败与对抗扰动反推语义证书的漏洞。核心主张：**把语义从「感知前置条件」升格为「安全证书的签发对象」，并让竞赛评分与对抗评测成为证书进化的选择压力**。

## 0. 直觉与动机

**灵感 1（语义分割 → 不是一张标签图，而是一个「语义世界集合」）**：分割网络输出 argmax 标签，等于只给出「一个世界」；但安全需要的是「所有与观测相容的世界」。直觉上，对每个像素给出一个 conformal 标签集合 L(u)（如 {floor, rug} 或 {glass, wall, unknown}），所有满足 ℓ(u)∈L(u) 的标注构成语义世界集 W。最坏情况有一个极简的几何形式：**只要某像素的标签集合里存在「对当前任务危险」的标签，就把该像素并入「可能危险区」**——因为 hazard 是二值的，最坏世界恰好把所有模糊像素都判危。这与第 42 轮把不确定性传播成保守几何是同一套「集合值感知」哲学：不确定时不是赌一个标签，而是把不确定性传播成保守障碍，再由任务决定保守到什么程度。

**灵感 2（语义-几何双向修正 → 语义既能「加障碍」也能「释放自由空间」）**：第 42 轮 IP-49 的几何膨胀（漂移界 B_t / L_m）是纯几何的：定位漂移变大时它把**所有**障碍一起膨胀，必然吞掉自由空间，这正是 v19 长期可用性不足的结构性来源。语义提供两条反向修正：(a) **膨胀**——玻璃、水面、镜面、帘布在几何地图里可能是「薄壳/空洞/平面/无回波」，但语义 hazard 必须把它们补成障碍；(b) **释放**——在语义标签集合**全部为良性**、且时序一致、且几何可佐证的区域，可以对 B_t 的过度膨胀做**有风险预算的收缩**，把被几何保守性吞掉的自由空间还回来（例如无纹理但语义明确的走廊地板、空旷水泥地）。这两条修正让「不撞」与「能走」第一次由同一个证书统一权衡，而不是各管一头。

**灵感 3（UniBot 挑战赛 → 证书的对抗课程与评分对齐）**：竞赛的价值不只是排名，而是它给出研究中稀缺的三样东西：**任务分布**（会被考什么）、**评分规则**（成功/时间/人工干预/违规如何加权）、**隐藏测试集**（真正的分布外泛化）。把证书目标写成与评分对齐的效用 U(C)=E[S]−λ·CVaR(−S)，就能显式回答「为了多高成功率，允许多少安全违例」这个此前从未建模的问题。更进一步：把竞赛失败案例与**对抗语义扰动**（换纹理/光照/透明材质/词表外物体）当红队，生成「在 conformal 预算内最坏」的语义世界，再用**证书增益驱动的主动课程**挑选下一个该练的任务——让竞赛从「考试」变成「证书的定向压力测试」。这也正面回应第 42 轮遗留的「检索幻觉」：竞赛隐藏集是最难被 RAG 幻觉糊弄的外部裁判。

**耦合升级**：SemCert 签发「标签集合 + 语义信任」→ SGSF 把语义与第 42 轮几何漂移膨胀合成联合安全集（膨胀/释放双向算子）→ CAR 用任务条件守卫 → 语义消歧反馈给主动感知与课程 → SCV/CAC 用竞赛任务与对抗世界挖语义反例 → CKB 存「任务 × 语义反例 × 扰动 × 后果」→ ECR 在边缘跑语义信任闸门。证书由此从「几何给定下的控制证书」升级为「**语义也被认证、且以任务和竞赛评分为判据**」的全栈证书。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（任务条件语义安全规范）**：任务 τ 带自然语言指令 ℓ_τ，标签词表 Y（开放词表，用嵌入而非固定类别）。**hazard 谓词** H_τ: Y × R³ → {0,1} 由 grounded VLM 把 ℓ_τ 编译而成（例：τ=「把地上玩具收进篮子」→ 易碎/液体/电线为 hazard；τ=「送餐」→ 人/玻璃/台阶为 hazard）。任务族 T 服从竞赛诱导分布 D_T。规范以「任务 × 标签」矩阵缓存，且**必须经人工审核**（规范错误是本轮最致命风险，见第 5 节）。

**定义 39（集合值语义分割与语义世界集）**：对像素 u，分割器输出 conformal 标签集合 L(u)⊆Y，满足 P(y_true(u)∈L(u)) ≥ 1−α_pix。经投影与遮挡推理得世界点的标签集合 L(q)。**语义世界集** W_α = { ℓ: X→Y : ℓ(q)∈L(q), ∀q }。逐像素 union bound 过松，故用**空间聚类 conformal**（超像素/实例级）控制地图级覆盖 1−α；语义模糊度 A(q)=|L(q)|，含 unknown 时单列。标签集包含 unknown 表示「不敢判」，其 hazard 状态由风险预算决定（默认按危险处理）。

**定义 40（语义条件最坏碰撞边际）**：对任务 τ，定义**可能危险区** Q_haz⁺(τ) = { q : L(q) ∩ H_τ⁻¹(1) ≠ ∅ }，以及**语义碰撞边际** m_sem(x;τ) = min_{p∈R(x)} d_{Q_haz⁺}(Tp) − δ_model，d 为可能危险区的 SDF。**命题 4（保守坍缩）**：hazard 对标签是二值的，最坏世界恰好把所有模糊点判危，故对任意 ℓ∈W_α 有 dist(T·R(x), Haz_τ(ℓ)) ≥ m_sem(x;τ)；m_sem>0 ⟹ 在全部 conformal 相容语义世界下无碰。**推论**：W 上指数级的最坏情况搜索坍缩为单一「可能危险区」上的几何距离，O(|R(x)|) 可算——这是语义证书能上边缘的前提。

**定义 41（风险预算语义释放与语义-几何联合安全集）**：m_sem 过保守，引入**释放集** R_rel ⊆ { q : L(q) 全良性 }，要求 P(∃q∈R_rel : ℓ_true(q) 为 hazard) ≤ δ_s（用 conformal risk control / e-value 校准）。设第 42 轮 IP-49 的几何不确定集为 Θ_geo、其膨胀障碍为 Q_geo^infl，**联合安全集**
Safe(τ,Θ_geo,W) = { x : ∀g∈Θ_geo, ∀ℓ∈W_α, dist(g(T·R(x)), Haz_τ(ℓ) ∪ Q_geo) > 0 }，
实现上用 (Q_geo^infl ∪ Q_haz⁺) \ R_rel 的联合 SDF。**命题 5**：若几何证书覆盖 1−α_g、语义释放风险 ≤ δ_s，则联合安全以概率 ≥ 1−α_g−δ_s 成立。语义释放是**唯一**能回收 v19 退化场景自由空间的算子，也是唯一能直接致撞的算子（见风险节）。

**定义 42（竞赛评分诱导的证书效用、Pareto 前沿与语义鲁棒半径）**：UniBot 单任务得分 S_τ = w_s·success + w_q·quality + w_t·time⁻¹ − w_v·violation − w_h·human_intervention。证书 C 的效用 U(C) = E_{τ∼D_T}[S_τ(C)] − λ·CVaR_β(−S)，约束 P(violation) ≤ ε。在 (成功率, 安全违例率, 延迟/成本, 语义鲁棒半径 r_sem) 四维上给出 **Pareto 证书前沿**；对外提交的不是单点，而是「安全调整后的排行榜」。**语义鲁棒半径** r_sem(C) = 使证书失效所需的最小标签扰动预算。

**定义 43（对抗语义世界与挑战驱动课程）**：红队求最坏语义世界 ℓ* = argmin_{ℓ∈W_α} m_sem，等价于选择模糊像素判危（对 m_sem 单调，已被 Q_haz⁺ 吸收）；但**释放算子**的对抗是反过来的：找「被释放却真实为危」的点，故需在扰动预算内同时搜物理扰动（光照/纹理/透明材质/词表外物体）与释放集，求 release_attack = argmax_{pert∈Budget} risk_released(pert,C,τ)。反例按 (τ, 标签区域, 扰动类型, 后果) 归因入 CKB。**挑战驱动课程**：下一采样任务/扰动取 argmax 期望**证书增益**（模糊度下降 + 覆盖缺口缩小 + 与评分损失的互信息），即用证书不确定性做主动学习。

**定义 44（运行时语义信任证书与一致性闸门）**：逐帧语义信任 q_sem = g(标签集熵, 相邻帧不一致率, OOD 分数, unknown 占比, |L|)，用 split conformal 定阈值 q_min（覆盖 1−α）。时序一致性证书要求语义地图更新引起的标签集变化在预算内（抑制闪烁）。运行时若 q_sem<q_min，或认证走廊与「unknown 且 hazard 风险 > δ_s」区域相交，CAR 进入 SemanticUnknown→Degraded，并优先触发「语义消歧」感知动作或请求人工，而非直接 SafeStop。

## 2. 四大产出设计（新增 IP-57/58/59 + 升级 IP-49/39/51/52/53/54/55/56/50/45/47）

### 2.1 IP-57 SEM-CERT（语义证书引擎 SC）
1. **集合值分割**：开放词表分割器 + conformal（APS/RAPS）逐像素/超像素标签集；unknown 显式建模，默认按危险处理但可由 δ_s 释放。
2. **任务 hazard 编译**：VLM 把 ℓ_τ 编译成 hazard 谓词，输出「任务 × 标签」矩阵；多 VLM 投票 + 人工审核 + 版本化，规范变更即重签发证书。
3. **语义地图与模糊度**：投影/遮挡推理得 L(q)、A(q)；空间聚类 conformal 控地图级覆盖；超像素级平滑抑制逐点抖动。
4. **语义信任与一致性**：逐帧 q_sem + 时序一致证书；conformal 定阈值；与第 42 轮漂移监控共用告警通道。
5. **消歧服务**：输出「可能危险区 / 释放候选区 / 模糊高发区」给 SGSF、主动感知与红队，把「哪里该多看」从超参变成证书内生量。

### 2.2 IP-58 SGSF（语义-几何安全融合）
1. **联合 SDF**：Q_joint = (Q_geo^infl(Θ_geo) ∪ Q_haz⁺(τ)) \ R_rel；八叉树/ESDF 增量维护，复用地形分壳。
2. **双向算子**：语义膨胀（玻璃/液体/镜面/帘布/电线）与**风险预算释放**（全良性 + 时序一致 + 几何佐证三重证据才可释放）。
3. **鲁棒 CBF/走廊**：h(x)=m_joint−m_safe；走廊边检查用联合 SDF；动态障碍把语义 hazard 与预测管叠加。
4. **任务切换**：τ 改变即重算 Q_haz⁺、R_rel 与守卫阈值；任务切换点强制重签发证书，禁止沿用旧 hazard 矩阵。

### 2.3 IP-59 CAC（挑战竞技场与对抗课程）
1. **竞赛任务接入**：解析 UniBot 任务/评分/隐藏测试协议，转成 D_T 与 S_τ；区分公开集（可调）与隐藏集（仅评测）。
2. **评分对齐目标**：优化 U(C)（含 CVaR），显式给出安全-成功率-成本 Pareto，拒绝单一刷分。
3. **语义红队**：在扰动预算内搜物理+标签扰动，生成最坏世界与释放攻击，估计 r_sem。
4. **证书增益课程**：按「预期证书增益 / 评分损失」选下一个任务与扰动，驱动 SCV 场景库与 CKB 检索键更新。
5. **反例归因入库**：失败轨迹 → 语义切片 → (任务, 标签区域, 扰动, 后果) → CKB，供下一轮语义证书合成热启动。

## 5. 本轮最大风险

**一句话**：语义证书最致命的风险不是「分割不准」，而是**规范本身错**——若 VLM 把任务的危险谓词编译错（或任务理解偏了），又或用语义释放去回收几何保守性而标签在透明/镜面/OOD 处静默出错，证书会「完美地证明一个错误的安全命题」；因此 E87（覆盖）与 E88（联合 soundness）必须作为红线，且语义释放默认关闭、只在「全良性 + 时序一致 + 几何佐证」三重证据下按 δ_s 预算开启，任一红线失守即熔断回退。

### IP-57 SemCert：集合值分割、任务 hazard 与语义信任
```
def compile_hazard_table(task_tau, vlm_ensemble, audit):
    # 1. 多 VLM 把自然语言指令编译成 hazard 谓词（离线）
    votes = [vlm.hazard_predicate(task_tau.instruction, label_vocab)
             for vlm in vlm_ensemble]
    H = majority_vote_merge(votes)          # Y -> {0,1}
    # 2. 规范必须人工审核；不一致/低置信标签进 unknown
    H = audit.review(H, task_tau)           # 返回审核后的 hazard 矩阵
    return HazardTable(task=task_tau.id, H=H, version=hash(H))

def semcert_frame(rgb, depth, K, T_hat, task_tau, alpha_pix=0.01):
    # 1. 开放词表分割 -> 逐像素 conformal 标签集
    logits = open_vocab_segmenter(rgb)                      # [H,W,|Y|]
    L_pix = aps_conformal_set(logits, alpha=alpha_pix)      # 每像素候选集
    # 2. 投影 + 遮挡推理 -> 世界点标签集（超像素聚类控地图级覆盖）
    L_world = project_to_world_clustered(L_pix, depth, K, T_hat)
    # 3. 任务 hazard 查表 -> 可能危险区（最坏世界坍缩）
    H_tau = hazard_table[task_tau.id].H
    Q_haz = { q for q, Lq in L_world.items()
              if any(H_tau.get(y, 1) for y in Lq) }         # unknown 默认 hazardous
    # 4. 逐帧语义信任 + 时序一致性证书
    q_sem = semantic_trust(logits, L_pix, temporal_state,
                           ood_score(rgb), unknown_ratio(L_pix))
    consistency_ok = temporal_consistency_check(L_world, budget=0.05)
    return SemanticCert(L_world=L_world, Q_haz=Q_haz, q_sem=q_sem,
                        ambiguity=map_ambiguity(L_world),
                        consistency=consistency_ok)

def semantic_trust(logits, L_pix, temporal_state, ood, unknown_ratio):
    ent = mean_entropy(logits)
    flicker = label_disagreement(L_pix, temporal_state.prev)
    set_size = mean_set_size(L_pix)
    return g_theta([ent, flicker, ood, unknown_ratio, set_size])   # -> [0,1]
```

### IP-58 SGSF：联合 SDF、双向算子与鲁棒 CBF
```
def joint_safe_map(cert_geo, sem_cert, task_tau, delta_s):
    # 释放候选：全良性 + 时序一致 + 几何佐证（三重证据）
    H_tau = hazard_table[task_tau.id].H
    R_cand = { q for q, Lq in sem_cert.L_world.items()
               if all(not H_tau.get(y, 1) for y in Lq)          # 全良性
               and temporal_consistent(q, sem_cert)
               and geo_corroborated(q, cert_geo) }              # 几何佐证
    # conformal risk control：只释放使 P(释放区含真危)<=delta_s 的最大子集
    R_rel = risk_controlled_release(R_cand, sem_cert.risk_scores, delta_s)
    Q_joint = (cert_geo.inflated_obstacles | sem_cert.Q_haz) - R_rel
    return OctreeESDF(Q_joint), R_rel

def joint_margin(x, cert_geo, esdf_joint, delta_model=0.0):
    best = +inf
    for p in robot_occupied_points(x):
        tp = apply(cert_geo.T_hat, p)
        best = min(best, esdf_joint.signed_distance(tp))
    return best - delta_model

def semantic_robust_cbf_qp(x, u_ref, cert_geo, esdf_joint, alpha, m_safe):
    h = joint_margin(x, cert_geo, esdf_joint) - m_safe
    dh = esdf_joint.gradient(x)
    # min ||u-u_ref||^2  s.t.  dh·(f(x)+g(x)u) + alpha(h) >= 0
    return solve_qp(u_ref, dh, h, alpha)

def certified_corridor_joint(x0, x_goal, cert_geo, esdf_joint):
    K = convex_decompose(x0, x_goal, esdf_joint)
    assert all(conservative_advancement(e, esdf_joint) for e in K.edges)
    return K
```

### IP-59 CAC：竞赛评分、语义红队与证书增益课程

```
def unibot_evaluate(policy, cert, tasks, split='hidden'):
    scores, violations = [], []
    for tau in tasks:                          # 严格按竞赛评分协议
        ep = rollout(policy, tau)
        scores.append(challenge_score(ep, tau))            # success/time/quality
        violations.append(cert_violation(ep, cert, tau))   # 0/1
    U = mean(scores) - lambda_cvar * cvar(-array(scores), beta=0.1)
    return {'U': U, 'violation_rate': mean(violations),
            'pareto': pareto_front(scores, violations, latency=mean_latency(cert)),
            'split': split}

def semantic_red_team(cert, task_tau, budget):
    # (a) 最坏语义世界：模糊像素判危 -> 已坍缩进 Q_haz⁺，检查最小边际
    worst_margin = min(joint_margin(x, cert.geo, build_joint(cert, task_tau))
                       for x in critical_states(cert))
    # (b) 释放攻击：在物理扰动预算内找「被释放却真实为危」的点
    attack = argmax(budget,
                    key=lambda pert: risk_released(pert, cert, task_tau))
    r_sem = min_perturbation_budget_causing_violation(cert, task_tau)
    return {'worst_margin': worst_margin, 'release_attack': attack,
            'r_sem': r_sem}

def certificate_gain_curriculum(KB, remaining_budget):
    # 证书增益 = 模糊度下降 × 覆盖缺口 × 评分敏感度
    return argmax(remaining_budget,
                  key=lambda t: expected_cert_gain(t, KB) / cost(t))

def attribute_semantic_counterexample(ep, cert, task_tau):
```

| 透明/镜面物体 RGB 不可见 | 中 | 多模态融合（深度/偏振/触觉/主动打光）；仅语义不足时禁止释放；E89 专项 |
| 竞赛过拟合/刷榜牺牲安全 | 中 | 公开/隐藏集严格隔离；安全调整榜；CVaR 约束；E91 同时看违例率 |
| 任务切换时 hazard 表/证书未热更新 | 低-中 | 任务切换点强制重签发 + 总线版本校验；旧 hazard 表禁止复用 |
| 组合技能 hazard 谓词叠加遗漏 | 低-中 | 子任务 hazard 取并 + 接口契约含语义变量；组合前契约兼容性检查 |

## 6. 本轮最大风险

**一句话**：语义证书最致命的风险不是「分割不准」，而是**规范本身错**——若 VLM 把任务的危险谓词编译错（或任务理解偏了），又或用语义释放去回收几何保守性而标签在透明/镜面/OOD 处静默出错，证书会「完美地证明一个错误的安全命题」；因此 E87（覆盖）与 E88（联合 soundness）必须作为红线，且语义释放默认关闭、只在「全良性 + 时序一致 + 几何佐证」三重证据下按 δ_s 预算开启，任一红线失守即熔断回退。
