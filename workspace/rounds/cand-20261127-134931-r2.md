### 第 4 轮灵感驱动研究记录

**灵感词**：可解释性、多模态交互

**直觉与动机**：

上一轮 v29 把安全性外包给统计学习组件（V_ψ、学生集成、OOD 打分），暴露出「蒸馏自证循环」R26。本轮的思路不是「让模型更可信」，而是让「不可信」本身变得可见、可质疑、可被人有边界地接管。两个灵感词恰好对应这条链的两端：

1. **可解释性不是事后可视化，而是证书的一部分。** 如果解释只回答「模型关注了哪里」，它就只是事后编故事；真正有用的是可审计的解释：去掉被引用的证据，决策是否真的改变（充分性/必要性）；输入微扰下解释是否稳定（稳定性）；每条自然语言理由是否落在真实传感器区域上（落地）。只有四项同时成立，解释才配进入准入门。

2. **多模态交互不是把语音、视觉、力觉堆在一起，而是让它们互相作证。** 操作员说「跨过电缆」，视觉必须定位到电缆，足底力/触觉必须确认接触；若语言与视觉冲突而系统静默融合，就是最危险的情形。跨模态一致性应当成为一种可校准的证书：用共形检验控制误报率，冲突时仲裁或主动澄清，而不是「平均一下」。

3. **两者结合产生「混合主动」闭环。** 当跨模态冲突或解释不可信时，系统向人提出最小澄清问题（信息增益最大、打扰成本最小）；人也可以在多模态解释的支撑下，授权系统执行自主证书不允许的动作。这把「人」从被动监督者变成有责任边界、有预算上限的共同决策者——这是 v29 从未形式化的一条真实安全路径。

**关键洞见**：可解释性与多模态交互的共同本质是「证据的可追溯性」。v29 的证书回答「系统是否有资格行动」；v30 追加回答「系统凭什么这样行动、证据来自哪个模态、人是否看懂并愿意担责」。安全从「单点证书」变成「证据链 + 责任链」：任何一个环节可以质疑，质疑可以追溯到具体证据，责任可以绑定到具体授权。

**形式化目标（增量）**：

1. 定义多模态观测 M = (I, L, F, T, A) 与落地映射 g: L → 2^{I×F}，以及跨模态散度 d_mm 与共形 p 值 p_mm。
2. 定义解释对象 E = (S_attr, a_cf, R) 与解释证书 XC（充分性 / 必要性 / 稳定性 / 落地四项合取）。
3. 定义反事实探针：a_cf = argmin_{a: M(s,a)<0} ‖a − π(s)‖，报告到最近违规边界的距离 d_cf。
4. 定义混合主动澄清策略 π_clar：在预算内选择最大化「期望信息增益 − λ_c·打扰成本 − λ_t·延迟」的查询。
5. 定义人授权证书 HAC = (op_id, scope, expiry, digest(E), sig) 与覆盖预算 B_H；给出 Exec_v30 的「保守收缩 ∪ 授权扩张」二段结构。
6. 证明：XC 稳定性在传感器噪声下有界；MCC 误报率 ≤ α_mm；HAC 下期望不安全覆盖次数 ≤ B_H·ε_H（ε_H 为人类判断错误率）。

**与 v29 的关系**：v30 = v29 ∪ {MMEE, CMCC, EOFA, CPE, MICM, HAC}，证书由「十二证」扩为「十四证 + 一授权」。必须诚实区分两种运行模式：

- **保守模式**（HAC 关闭）：Exec_v30^cons = Exec_v29 ∩ MCC ∩ XC ⊆ Exec_v29，安全性单调收缩。
- **监督模式**（HAC 开启）：Exec_v30^sup = (Exec_v29 ∩ MCC ∩ XC) ∪ HAC(A_env \ Exec_v29)，**不再**是 Exec_v29 的子集——这是有意为之的安全-能力权衡，代价是把人类错误率 ε_H 引入系统。

**本轮最大风险**：**解释性幻觉诱发的人类过度信任**——XC 只检验归因的自洽性、必要性与稳定性，并不检验因果忠实性；一个在多模态证据上「自圆其说」却因果错误的解释，会同时通过 XC 与 MCC，并促使操作员签发 HAC 覆盖，使人类成为绕过全部十四证的安全单点故障。

## 2. 关键算法骨架（在 IP-467~472 骨架上扩展）

### IP-473 Multimodal Evidence Encoder (MMEE)

```python
@dataclass
class MultimodalEvidenceEncoder:
    """MMEE：五模态编码 + 语言-视觉落地；输出带校准的证据 token"""
    encoders: dict                 # {'vision': ViT, 'language': LLM-enc, 'force': MLP, ...}
    conformal: ConformalCalibrator
    align_hz: float = 50.0         # 证据时间对齐频率

    def encode(self, M):
        # 1) 时间对齐：把各模态按最近时间戳重采样到统一网格
        z = {m: self._resample(self.encoders[m](M[m]), M.t[m]) for m in M}
        # 2) 语言→视觉/力落地：token-region 交叉注意力，输出 g∈[0,1]
        G = self._grounding(z["language"], z["vision"], z["force"])
        # 3) 每个证据 token 附共形校准分数，供后续 MCC/XC 使用
        cal = {m: self.conformal.score(z[m]) for m in z}
        return Evidence(z=z, G=G, cal=cal)
```

### IP-474 Cross-Modal Consistency Certifier (CMCC)

```python
@dataclass
class CrossModalConsistencyCertifier:
    """CMCC：逐对共形检验 + 冲突图；关键对冲突禁止静默融合"""
    alpha_mm: float = 0.01
    critical_pairs = (("language", "vision"), ("force", "tactile"))
    reliability: dict = None        # 校准集估计的模态可靠度权重

    def certify(self, ev: Evidence):
        edges = []
        for (i, j) in self._pairs(ev.z):
            d = self._mmd(ev.z[i], ev.z[j])          # 任务相关潜变量上的 MMD
            p = self.conformal.p_value(d, pair=(i, j))
            if p <= self.alpha_mm:
                edges.append((i, j, d, p))
        conflict = any((i, j) in self.critical_pairs for (i, j, _, _) in edges)
        if conflict:
            # 不融合：交仲裁器给出保守解释，或由 MICM 主动澄清
            return False, edges, self._arbitrate(ev, edges)
        return True, edges, None

    def _arbitrate(self, ev, edges):
        # 按可靠度与严重度排序：可靠度低且涉及安全对象的模态让位
        return sorted(edges, key=lambda e: self.reliability[e[0]] * self.reliability[e[1]])
```

### IP-475 Explanation Object & Faithfulness Auditor (EOFA)

```python
@dataclass
class ExplanationFaithfulnessAuditor:
    """EOFA：把解释变成可运行时审计的四项合取证书 XC"""
    tau_suff: float = 0.9
    tau_nec: float = 0.0
    delta0: float = 0.02
    rho_rank: float = 0.8
    tau_g: float = 0.7
    cpe: "CounterfactualProbeEngine"

    def audit(self, s, a, E, margin_fn, evidence_fn) -> tuple[bool, dict]:
        # (1) 充分性：只用被引用证据 S_attr，决策裕度仍保留 ≥ τ_suff 比例
        m_full = margin_fn(s, a)
        m_attr = margin_fn(evidence_fn.mask_except(s, E.S_attr), a)
        suff = (m_attr >= self.tau_suff * m_full) if m_full > 0 else (m_attr >= 0)

        # (2) 必要性（最小性）：逐个去掉证据，决策必须翻转或裕度跌破 τ_nec
        nec = True
        for e in E.S_attr:
            if margin_fn(evidence_fn.mask(s, E.S_attr - {e}), a) >= self.tau_nec:
                nec = False
                break

        # (3) 稳定性：证据微扰 δ≤δ0 下解释集 Jaccard 不塌缩
        J = min(self._jaccard(E.S_attr, self._explain(s + δ, a))
                for δ in self._perturbations(self.delta0))
        stable = J >= 1.0 - self._lipschitz_bound()

        # (4) 落地：每条理由 r∈R 都要有 g≥τ_g 的真实证据支撑
        grounded = all(self._max_grounding(r, E.S_attr) >= self.tau_g for r in E.R)

        return (suff and nec and stable and grounded,
                dict(suff=suff, nec=nec, stable=stable, grounded=grounded, J=J))
```

### IP-476 Counterfactual Probe Engine (CPE)

```python
class CounterfactualProbeEngine:
    """CPE：找最近违规动作，回答『为什么不这样做』『差多远』"""
    def __init__(self, teacher, margin_fn, u_max=1.0, n_bisect=12):
        self.teacher, self.margin_fn, self.u_max, self.n = teacher, margin_fn, u_max, n_bisect

    def nearest_violation(self, s, a):
        # 沿裕度下降方向构造射线，二分找边界；a_cf 经教师复核有效性
        d = self._descent_direction(s, a)
        lo, hi = 0.0, 1.0
        for _ in range(self.n):
            mid = 0.5 * (lo + hi)
            if self.margin_fn(s, a + mid * d) < 0:
                hi = mid
            else:
                lo = mid
        a_cf = a + hi * d
        valid = self.teacher.verify_counterfactual(s, a_cf)  # 教师只读复核
        return Counterfactual(a_cf=a_cf, d_cf=hi * np.linalg.norm(d) / self.u_max,
                              valid=valid)
```

### IP-477 Mixed-Initiative Clarification Manager (MICM)

```python
@dataclass
class MixedInitiativeClarificationManager:
    """MICM：冲突/歧义时问『最小且最值钱』的问题"""
    intent_model: Callable          # p(θ | M)
    lambda_cost: float = 1.0
    lambda_delay: float = 0.5
    budget: int = 3
    stop_conf: float = 0.9

    def maybe_ask(self, ev, conflict):
        post = self.intent_model(ev)
        if conflict is None and max(post.values()) >= self.stop_conf:
            return None, post
        best, best_score = None, -1e9
        for q in self._candidate_queries(ev, conflict):   # 指物/复述/确认
            eig = self._expected_info_gain(q, post)
            cost = self.lambda_cost * self._interruption(q) + self.lambda_delay * self._latency(q)
            if eig - cost > best_score:
                best, best_score = q, eig - cost
        return best, post
```

### IP-478 Human Authorization Certificate (HAC)

```python
@dataclass
class HumanAuthorizationCertificate:
    """HAC：把人类覆盖显式化、可追责、有预算"""
    op_id: str
    scope: dict            # 允许的状态区域 + 动作集合
    expiry: float          # 单调时钟过期时间
    digest: str            # sha256(E)：绑定操作员看到的那份解释

            return False
        if not self._in_scope(s, a):
            return False
        if self.digest != sha256(canonical(E)):
            return False            # 解释被换过 → 授权失效
        if not verify_sig(self.op_id, self._payload(), self.sig):
            return False
        if self.severity >= SEV_HIGH and not self._dual_authorized():
            return False            # 高风险动作需双人
        return True
```

### IP-479 Explainable Multimodal Interaction Gate (XMI-KTCG)

```python
@dataclass
class ExplainableMultimodalInteractionGate:
    """XMI-KTCG：v29 十二证 + MCC + XC；学生→教师→人三级升级"""
    v29: "ValueAlignedDistillationCertGate"
    mmee: MultimodalEvidenceEncoder
    cmcc: CrossModalConsistencyCertifier
    eofa: ExplanationFaithfulnessAuditor
    cpe: CounterfactualProbeEngine
    micm: MixedInitiativeClarificationManager
    mode: str = "conservative"        # {conservative, supervised}
    budget_left: int = 3

    def admits(self, robot_plan, sensor_data, M):
        # 0) 多模态证据 + 一致性（MCC）
        ev = self.mmee.encode(M)
        mcc_ok, edges, arb = self.cmcc.certify(ev)
        if not mcc_ok:
            q, post = self.micm.maybe_ask(ev, edges)
            if q is not None and self.budget_left > 0:
                self.budget_left -= 1
                return ("clarify", q, post)          # 暂停控制，先问人
            # 预算耗尽：退教师保守路径（不静默融合冲突模态）
            return self._teacher_or_fallback(robot_plan, sensor_data)

        # 1) v29 十二证（教师/学生路径原语义）
        ok29, u_cmd, path29 = self.v29.admits(robot_plan, sensor_data)
        if not ok29:
            return ("reject", None, None)

        # 2) 解释生成 + 审计（XC）
        s = robot_plan.init_state
        E = self._build_explanation(s, u_cmd, ev, arb)
        xc_ok, diag = self.eofa.audit(s, u_cmd, E, self._margin, ev)
        cf = self.cpe.nearest_violation(s, u_cmd)
        if not xc_ok:
            # 解释不可信：不把「解释」当护身符，直接降级教师
            return self._teacher_or_fallback(robot_plan, sensor_data)

        # 3) 人授权路径（仅监督模式）
        if self.mode == "supervised" and self._outside_v29(s, u_cmd):
            if self._hac is not None and self._hac.validate(
                    s, u_cmd, E, now=self._now(), budget_left=self.budget_left):
                self.budget_left -= 1
                return ("human-authorized", u_cmd, E)
            return ("teacher", *self._teacher_or_fallback(robot_plan, sensor_data)[1:])

        return (path29, u_cmd, E)

    def _teacher_or_fallback(self, plan, sensor):
        ok, u, path = self.v29._teacher_path(plan, sensor)
        return ("teacher" if ok else "fallback", u, None)
```

**与 v29 的接口约定**：v29 的 `admits` / `_teacher_path` 原语义复用；新增只读接口 `verify_counterfactual(s,a_cf)`、`margin(s,a)` 与 `mask/mask_except` 证据视图。HAC 仅在 `mode=supervised` 时启用，默认保守模式保证 Exec_v30^cons ⊆ Exec_v29。

## 4. 正确性论证（增量更新）

### 定义 33（解释证书 XC）

称 E=(S_attr,a_cf,R) 在 (s,a) 处是 **XC-忠实** 的，当且仅当：

1. **充分性**：M(mask_except(s,S_attr), a) ≥ τ_suff·M(s,a)（M(s,a)>0 时）；
2. **必要性**：∀e∈S_attr，M(mask(s,S_attr\{e}), a) < τ_nec，即去掉任一被引证据决策即失效；
3. **稳定性**：∀‖δ‖≤δ0，Jaccard(S_attr(s), S_attr(s+δ)) ≥ 1 − L_x·δ；
4. **落地**：∀r∈R，max_{e∈S_attr} g(r,e) ≥ τ_g，且 e 通过对应模态的 MCC。

四项全为真才置 XC=True。注意：XC 检验的是「解释与决策的一致性」，不是「解释与真实因果机制的一致性」——这是 R28 的根源。

### 引理 29（稳定性 ⇒ 传感器噪声下的解释鲁棒性）

**陈述**：若解释集映射 S_attr(·) 在证据空间满足 Jaccard-Lipschitz 常数 L_x，且传感器噪声 ‖δ‖≤δ0，则解释集变化量 ≤ L_x·δ0。取 δ0=0.02、L_x=2 时，Jaccard 下界 0.96。

**证明**：由定义 3 直接代入 δ=δ0。∎

**工程含义**：把「解释抖动」变成一个可校准的噪声预算；若实测抖动超界，说明解释器对噪声过敏，应降低其权重或改用人可读的规则解释，而非继续信任显著图。

### 引理 30（MCC 的共形误报控制）

**陈述**：在可交换性假设下，对任一模态对，CMCC 在正常样本上的误报率 P(p_mm ≤ α_mm) ≤ α_mm；对 P 个模态对，Bonferroni 校正后族错误率 ≤ P·α_mm。

**证明**：共形 p 值满足 P(p ≤ α) ≤ α（有限样本、无分布假设）；族错误率由并集界给出。∎

**注意**：这是**边际**保证，不是条件保证；分布漂移下可交换性失效，需在线重校准（见 R30）。关键模态对（语言-视觉、力-触觉）即使误报也选择保守降级，因此误报的代价是可用性而非安全性。

### 引理 31（HAC 的期望不安全覆盖界）

**陈述**：设每个被授权的越界动作独立地以概率 ε_H 被人类误判为安全，单回合覆盖预算为 B_H，则期望不安全覆盖次数 ≤ B_H·ε_H；若人类错误正相关（同一操作员、同一疲劳状态），则上界退化为 B_H·ε_H + Cov 项，需以双人授权或硬件使能压低。

**证明**：令 X_i 为第 i 次覆盖是否不安全，E[X_i]≤ε_H，线性期望求和；正相关时用并集界失效，改用联合风险模型。∎

**诚实声明**：ε_H 无法从系统内部测得，只能由历史审计、演练或操作员资质先验给出；因此 HAC 的安全性是「人类可靠性」的函数，而非纯技术证书。

### 定理（Exec_v30 的二段结构）

**陈述**：保守模式下 Exec_v30^cons = Exec_v29 ∩ MCC ∩ XC ⊆ Exec_v29；监督模式下 Exec_v30^sup = (Exec_v29 ∩ MCC ∩ XC) ∪ HAC(A_env \ Exec_v29)，一般 **不** 是 Exec_v29 的子集，但授权部分被限制在可被人否决包络 A_env 内。

**证明**：保守模式各合取项只做交运算，子集性显然。监督模式新增 HAC 分支，其动作集合为 A_env 中未被 v29 准入者；由 HAC.validate 的 scope/digest/sig/预算四重检查，越界动作必须绑定当前解释且落在 A_env，故扩张有界但不含于 v29。∎

**推论（何时应关掉 HAC）**：当 ε_H·B_H > (v29 在边缘场景的失败质量) 时，监督模式反而更不安全；部署策略应以在线审计的 ε̂_H 动态决定是否允许 HAC，而不是默认开启。

## 5. 实验设计（本轮新增）

**假设**：

- H1：加入 XC+MCC 后，操作员的信任校准（Brier 分数）优于「无解释」与「事后显著图」，且不当干预次数下降。
- H2：混合主动澄清在跨模态冲突场景下把「未解决冲突率」从静默融合的基线显著降低。
- H3：监督模式在边缘场景恢复成功率，但不安全率随 ε_H 线性上升；保守模式不安全率不升、成功率下降。

**基线**：v29（无解释/无多模态证书）、v30 保守、v30 监督、无证书的多模态早融合、事后 Grad-CAM 解释。

**指标**：任务成功率、不安全动作率、XC 四项通过率、MCC 误报/漏报、落地 IoU、信任校准 Brier、澄清次数与延迟、HAC 覆盖的安全率。

**预期结果（设计目标，非实测）**：

| 配置 | 成功率 | 不安全率 | 解释忠实度 | 信任 Brier |
|---|---|---|---|---|
| v29 | 0.86 | 0.041 | — | 0.19 |
| 早融合 | 0.88 | 0.067 | — | 0.18 |
| v30 保守 | 0.84 | 0.033 | 0.91 | 0.12 |
| v30 监督（ε_H=0.05） | 0.91 | 0.048 | 0.91 | 0.10 |

**消融**：去掉 XC 的必要性项（只留充分性+落地）应显著提高「解释注水率」；去掉 MCC 的共形校准（固定阈值）应使误报随场景漂移；去掉 HAC 的 digest 绑定应使「解释换脸」攻击成功率上升。

|---|---|---|---|---|
| R19–R27 | v29 全部既有风险 | — | 随 v29 十二证原样继承 | 不变 |
| R28 | 解释性幻觉 / 自动化偏见：解释自洽但不因果忠实，诱发过度信任 | 高 | 1) XC 强制必要性+反事实，拒绝「解释一切」；2) 定期用人工因果标注集审计 EOFA 的假阳性；3) 解释与决策解耦展示（先给动作风险，再给理由） | 因果忠实性无法由系统内部证明，只能外部审计 |

## 7. 本轮最大风险（最终确认）

**一句话**：**解释性幻觉诱发的人类过度信任**——XC 只保证解释与决策「自洽、必要、稳定、落地」，不保证因果忠实；当多模态编码器共享偏差使 MCC 与 XC 同时变绿时，一份听起来无懈可击的解释会促使操作员签发 HAC，让人类成为绕过全部十四证的安全单点故障——这比 v29 的「机器自证循环」更危险，因为它把失败伪装成了「人已经看懂了」。
