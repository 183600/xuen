# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「真实世界泛化」×「示教学习」）

> R69 把不确定性分成 aleatoric 与 epistemic，然后让 epistemic 去「问」。但它从未追问一个更根本的问题：**这些模态是从哪来的？** 流策略不是从天上采样，它是从示教数据里学出来的。所谓「两个都合理的动作」，十有八九不是环境的歧义，而是**两位示教者的风格差异**；所谓「模态权重可不可信」，在示教覆盖不到的地方根本没有意义——那里的速度场是外推出来的幻觉。
>
> 本轮两个灵感正好戳中这一点：
> - **示教学习**告诉我们：策略的能力边界由示教数据决定，而策略的「多峰」先天地混合了示范者熵、环境歧义与支持外推三样东西；
> - **真实世界泛化**告诉我们：泛化不是「相信模型」，而是「知道自己被教过什么、没被教过什么，并在没被教过的地方体面地退场」。
>
> 核心命题：**把 R69 的 (U_ale, U_epi) 按「来源」细分为 (U_demo, U_support, U_amb)**——示范者风格（不可约，不许问）、示教支持外（数据级可约，只能靠慢环补示教）、环境歧义（回合级可约，交给 R69 的快环交互）；并用**保形支持证书**给「在支持域内」一个有限样本保证，用**两级时间尺度**把快环（毫秒，零学习写）与慢环（离线，版本化换装）严格隔离。命名 **ROOT-RAS**（Reference-grounded, Out-Of-support-aware, Teaching-enabled RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底被教过什么，哪里其实没教过**」——泛化的第一步不是外推，而是承认边界。

## 0. 直觉与动机

**灵感 1（示教学习 → 多峰的第一来源是示范者，不是世界）**
直觉：同一个人教两遍同一个任务，轨迹也不会完全一样；不同的人教，风格差异更大——有人保守绕远，有人贴着障碍走。R69 的流策略在这些数据上做最大似然，学到的往往不是「世界有两个模态」，而是「人类有两种习惯」。这时 `H_mode` 高、`Δ_min` 大，VoI 会算出「去问一问很值」，于是系统向环境提了一个环境根本无法回答的问题：**环境不负责解释你的老师**。更糟的是，把示范者风格当环境歧义去交互，会把 R69 的「问错比不问更危险」从偶发风险变成系统性偏差——只要示教者不止一个，系统就会持续地追问幻影。

**灵感 2（真实世界泛化 → 支持域是泛化的硬边界）**
直觉：深度策略在训练分布内插值，在分布外外推；外推出来的速度场没有任何保证，流匹配甚至会「自信地」生成一条平滑但错误的轨迹。R68 的标定管传感器、R69 的似然管行为自洽，但两者都默认「这个状态我见过」。真实世界泛化要求一个更靠前的门：**这个观测/任务/本体是否落在示教支持域内？** 域内可以用保形预测给出有限样本覆盖保证；域外，一切覆盖保证都静默失效——唯一诚实的动作是退到已示教的恢复/安全集，或者举手求教。

**灵感 3（三分 → 互信息链式法则给出的精确分解）**
直觉：R69 的二分是「拍脑袋」的两类；本轮可以用一条恒等式把它变成三分：
`H(M|o) = I(M;D|o) + I(M;E|o,D) + H(M|o,D,E)`，
其中 `D` 是示范者身份、`E` 是环境/支持指示。三项分别对应**风格熵、支持外贡献、真环境歧义**。这不是比喻，是互信息的链式法则——它逼着我们把「问」的三种处置对上三种来源：风格 → 平均/不变化（**不许问**）；支持外 → 慢环补示教（**问了也没用**）；真歧义 → R69 快环交互（**问得值**）。能分解，才能正确地不问。

**灵感 4（两级时间尺度 → 泛化是慢变量，安全是快变量）**
直觉：补示教是天级的、交互是毫秒级的、控制是微秒级的——把它们塞进同一个环，必然破坏 R68 的「实时流零学习写」。所以本轮的核心工程姿态是**时间尺度分离**：快环完全继承 FLUID-RAS，一行不改、延迟不变；慢环只在离线、版本化、影子评估、审计通过后换装。泛化能力靠「下一条示教」提升，而不是靠运行时的隐式微调。

**灵感 5（可辨识性 → 三分法的命门在「交叉示教」）**
直觉：如果每个环境只由一个人教（环境和示范者完全混杂），那么从被动数据里**根本无法区分**「这个模态是风格还是支持缺口」。把风格误判为支持缺口：系统拒绝一切泛化（永远说没教过），把 R69 的效率收益全部吐回去；把支持缺口误判为风格：系统把外推当习惯差异，自信地在没教过的地方行动。所以本轮必须交付：交叉示教设计/正性假设、风格相关性的因果门、以及「不可辨识时默认更保守」的纪律。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（ROOT-RAS 总览与四不变式）** ROOT-RAS = (PDD, TRI, SSC, SGL, CTR, DRB, TSC, RAS-WM†)。四不变式：
(i) **快环零学习写**（继承 R68 定义 276-i，ROOT 不放松）；
(ii) **慢环契约**：任何示教/恢复数据只能在离线、空闲、审计通过后经版本化换装进入，快环在单回合内读到的策略版本冻结；
(iii) **支持先于保证**：任何覆盖/泛化声明必须由 SSC 先判定「在支持域内」，域外声明无效；
(iv) **来源路由**：`U_demo` 不许触发交互，`U_support` 不许触发快环交互，只有 `U_amb` 才触发 MINT。

**定义 311（示教语料与来源元数据）** `𝒟 = {τ_i = (o_{1:T}, a_{1:T}, μ_i)}`，`μ_i = (d, e, g, b)` 分别为示范者、环境、任务、本体标识。来源图 `G_μ` 支持留一示范者（LODO）、留一环境（LEO）、留一任务（LTO）、留一本体（LBO）划分。示教语料是可审计资产，带 `demo_version_hash`。

**定义 312（三分不确定性分解）** 模态身份 M（R69 定义 296）。按互信息链式法则：
`H(M|o) = U_demo + U_support + U_amb`，
`U_demo = I(M; D | o)`（示范者风格熵，部署时不可约），
`U_support = I(M; E | o, D)`（支持外贡献，数据级可约，需慢环），
`U_amb = H(M | o, D, E)`（真环境歧义，回合级可约，快环可消解）。
三者语义不同，分通道处置（定义 318/325），**不做标量加和**。

**定义 313（任务相关表征与风格相关门 TRI）** 表征分裂 `Φ = (Φ_tr, Φ_st)`。风格不变目标：最小化 `I(Φ_tr; D)`（对抗/正交约束），同时最大化 `I(Φ_tr; Y)`（任务充分性）。**相关门**：方向 `v` 可移除当且仅当在交叉示教下 `v` 对任务结果无因果效应（干预检验/工具变量近似）；否则保留——防止把与环境混杂的「风格」当噪声删掉（把信号当噪声）。输出支持距离 `s(o) = d(Φ_tr(o), Supp(Φ_tr))`。

**定义 314（保形支持证书 SSC）** 在留出示教校准集上算新颖度 `s_i = d(Φ_tr(o_i), 𝒟_train)`（kNN/能量距离）。部署观测 O 的支持 p 值
`p(O) = (1 + #{i : s_i ≥ s(O)}) / (n + 1)`，`O ∈ 𝒮_α ⇔ p(O) > α`。
在可交换分层内 `P(s(O) ≤ q_{1−α}) ≥ 1−α`（有限样本）。**注意**：这是「支持成员」的覆盖，不是「动作正确」的覆盖；后者需对动作集另做保形（可选）。

**定义 315（泛化缺口界，引理 19）** 支持域内任务风险
`R ≤ U_demo + L·E[d_support] + O(√(log(1/δ)/n))`，`L` 为策略对表征的 Lipschitz 常数。**域外无界**：只能用最坏情形 `≤ R_max` 或恢复集风险界。系：泛化提升只有两条合法途径——降 `U_demo`（不变化/多示范者平均）或降 `d_support`（补示教），而不是「更自信地外推」。

**定义 316（支持缺口限幅器 SGL）** 当 `p(O) ≤ α`：动作被限制在**已示教安全包络** `𝒜_demo`（历史示教动作的可行凸包/恢复集 `ℛ_demo`）内；`λ = λ_floor(U_demo + U_support + U_amb)`（全保守，退化为 R68 口径）；允许**弃权/交接** `a_⊥`（停机、退回、呼叫人类）。恢复集动作同样过 C-RAS-WM 认证。支持域恢复时单调解除，不跳跃。

**定义 317（慢环示教请求 CTR 与示教价值 VoT）** 当支持缺口**结构化且持续**（区域 R 上 p 值长期 ≤ α、且 `U_amb` 低——不是问一句能解决的），发出示教请求规格 `q_R = (R, 期望示范的技能, 交叉设计约束)`，进入离线队列。示教价值
`VoT(R) = P(R)·Δ_support(R)·Δ_risk(R) / c_demo(R)`，
按 `VoT` 排序；`c_demo` 含人类时间与安全成本。CTR 只在安全/空闲态或 HITL 通道执行，绝不进快环。

**定义 318（来源路由 TSC）** 路由表：
- `U_amb` 主导且 `p(O) > α` → **MINT 快环交互**（R69，ms）；
- `U_support` 主导 → **SGL 兜底 + CTR 慢环**（禁止快环交互，因为环境答不了「你没教过我」）；
- `U_demo` 主导 → **不变化/多风格边缘化 + λ_floor**（禁止交互，环境不负责解释老师）；
- 不可辨识（定义 320 条件不满足）→ **默认支持外保守**（宁可拒绝泛化，不可自信外推）。
每次路由写 `routing_log_hash`，可审计。

**定义 319（示教条件流策略）** 训练时把 `μ` 作为条件/风格潜变量，部署时**对 D 边缘化**（消 `U_demo`）或对最坏 `D` 做鲁棒（minimax）；流场 `v_θ(x_s, s | o, z, D̄)`，`D̄` 为风格平均。风格条件只用于离线诊断（判断某模态是否由风格引起），不用于运行时「挑一个老师」。

**定义 320（可辨识性与交叉示教假设 A99）** 若示教设计满足**正性/交叉**：每个环境 `e` 至少被 ≥2 个示范者覆盖、每个示范者至少覆盖 ≥2 个环境，则 `I(M;D|o)` 与 `I(M;E|o,D)` 可由数据估计；若 `D ⊥ E` 被违背（完全混杂），二者不可辨识，任何分账都是假设。ROOT 要求数据集交付 `crossed_coverage` 审计；不满足时按定义 318 走默认保守。

**定义 321（恢复缓冲与复合误差 DRB）** 慢环用安全过滤后的 DAgger 式聚合：在 `𝒮_α` 边界与 `ℛ_demo` 上采样、由人类/安全控制器标注恢复动作并加入 `𝒟`；目标是把行为克隆的 `O(T²ε)` 复合误差压到 `O(Tε)`（Ross–Bagnell 界）。只在离线版本化，新版本须在影子集上非劣于旧版本才换装。

**定义 322（威胁模型 ℰ_ROOT）** `ℰ_ROOT = ℰ_FLUID × ℰ_demo × ℰ_shift × ℰ_leak × ℰ_contam`：投毒示教 / 边界对抗状态 / 风格捷径泄漏 / 评估污染（训练-测试示范者重叠、同一轨迹泄漏）。并入 AIC-ROOT。

**定义 323（参与式审计 VQAuditor-D）** 审计数据来源与分账：来源标签是否真实、风格-支持归因是否可辨识、示教质量与覆盖、评估划分是否泄漏示范者/环境、CTR 请求是否被恰当排序与关闭。结论回灌 `AuditBuf` 与 `crossed_coverage` 报告。

**定义 324（证书 J_ROOT）** `J_ROOT = (J_FLUID, support_coverage, conformal_coverage, alpha, crossed_coverage, style_leakage_auc, demo_version_hash, routing_log_hash, teaching_request_log, ood_split_manifest, root_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ support_coverage ≥ 1−α−ε ∧ crossed_coverage 通过 ∧ style_leakage ≤ τ_leak ∧ 划分无污染`。

**定义 325（两级退避与严格包含链）** 支持内且歧义可解：`λ = λ_floor(U_demo)`（继承 R69 的 resolution bonus）；支持内歧义不可解：`λ = λ_floor(U_demo + U_amb)`；支持外：`λ = λ_floor(U_demo + U_support + U_amb)` 且动作限幅到 `𝒜_demo`。⇒ `R68 ⊂ FLUID ⊂ ROOT`，退化时逐指令相同（定理 18）。

**定义 326（部署门与真实世界泛化证书）** 部署前须在**留出真实世界探针集**上满足：支持覆盖 ≥ 阈值、保形覆盖成立、风格泄漏低、恢复集已示教、`J_ROOT` 有效；sim2real 迁移须附 `ood_split_manifest`（本体/环境/任务变化）。不满足则只允许「示教内任务」上线。

**定义 327（快慢环非干涉）** 快环输入只有冻结的策略版本与只读统计；慢环写操作只在离线、经影子评估与审计；支持门的保守性单调（证据变少 → 更保守，绝不反向）；换装沿用 R68 定理 15 的不变式 ⇒ 控制连续、无突变。

## 3. 推导

**引理 19（来源三分恒等式）** 由互信息链式法则 `H(M|o) = I(M;D|o) + H(M|o,D)` 与 `H(M|o,D) = I(M;E|o,D) + H(M|o,D,E)`，三项之和恒等于 `H(M|o)`。系：R69 用 `H_mode` 直接当 `U_epi`，系统性高估了可交互消解的歧义，高估量恰为 `U_demo + U_support`；这就是「幻影追问」的数学来源。

**引理 20（保形支持覆盖及其域外失效）** 在可交换分层内，`p(O)` 是支持新颖度的有效 p 值，`P(s(O) ≤ q_{1−α}) ≥ 1−α`。但部署风险满足
`P(err) ≤ (1−α)·R_in + α·R_out`，`R_out` 无分布无关上界（可构造任意坏的外推）。系：**保形保证不能替代支持门**；「先判定域内、再谈覆盖」不是保守，而是唯一合法顺序。

**引理 21（风格-支持的可辨识性）** 若示教满足交叉正性（定义 320），`I(M;D|o)` 与 `I(M;E|o,D)` 可由数据一致性估计。若 `D` 与 `E` 完全混杂，则存在两组不同的生成机制（纯风格 vs 纯支持缺口）产生**完全相同的示教似然**，从被动数据不可辨识。系：交叉示教不是数据采集的锦上添花，而是三分法成立的前提。

**引理 22（恢复缓冲的复合误差）** 行为克隆的期望后悔上界为 `O(T²ε)`；在支持边界与 `ℛ_demo` 上加入 DAgger 式恢复标注后，标准分析给出 `O(Tε)`（`ε` 为单步监督误差）。系：慢环补示教的收益是可量化的误差阶下降，而非玄学「见得多就会」。

**定理 18（ROOT 严格包含 FLUID 与 R68）** 在 A95–A99 下：当 `U_support=0` 且 `U_demo` 已边缘化时，ROOT 逐指令等价于 FLUID-RAS；当再令 `VoI ≤ c`（不交互）时等价于 R68。一般情形 ROOT 的安全侧风险不高于 FLUID：支持外强制限幅与全保守，域内保留 R69 的 resolution bonus。故 `R68 ⊂ FLUID ⊂ ROOT`，安全层层收紧、效率侧只在有证据时放开。

**定理 19（两级时间尺度非干涉）** 快环只读冻结版本与预计算阈值，故延迟、安全包络与 FLUID 相同（复杂度见 §4）；慢环写操作被离线/影子评估/审计/版本化换装四重约束，且支持门单调保守 ⇒ 不存在「学习把系统改坏」的运行时通道；换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

## 4. 推导

**引理 19（来源三分恒等式）** 由链式法则 `H(M|o)=I(M;D|o)+H(M|o,D)`、`H(M|o,D)=I(M;E|o,D)+H(M|o,D,E)`，三项之和恒等于 `H(M|o)`。系：R69 用 `H_mode` 当 `U_epi`，系统性高估可交互歧义，高估量恰为 `U_demo+U_support`——这是「幻影追问」的数学来源。

**引理 20（保形支持覆盖及域外失效）** 可交换分层内 `P(s(O)≤q_{1−α})≥1−α`；但部署风险 `P(err) ≤ (1−α)R_in + αR_out`，而 `R_out` 无分布无关上界。系：保形不能替代支持门，「先判定域内、再谈覆盖」是唯一合法顺序。

**引理 21（风格-支持可辨识性）** 交叉正性（定义 320）下两分量可由数据一致性估计；若 `D` 与 `E` 完全混杂，则「纯风格」与「纯支持缺口」两种生成机制产生相同示教似然，被动数据不可辨识。系：交叉示教是三分法的前提，不是数据采集的装饰。

**引理 22（恢复缓冲的复合误差）** 行为克隆期望后悔 `O(T²ε)`；在 `𝒮_α` 边界与 `ℛ_demo` 上加入 DAgger 式恢复标注后标准分析给出 `O(Tε)`。系：补示教的收益是可量化的误差阶下降。

**定理 18（ROOT 严格包含 FLUID 与 R68）** A95–A99 下：`U_support=0` 且 `U_demo` 已边缘化时 ROOT 逐指令等价 FLUID；再令 `VoI≤c` 则等价 R68。一般情形安全侧风险不高于 FLUID（支持外强制限幅+全保守），域内保留 R69 的 resolution bonus。故 `R68 ⊂ FLUID ⊂ ROOT`。

**定理 19（两级时间尺度非干涉）** 快环只读冻结版本与预计算阈值，延迟与安全包络同 FLUID；慢环写操作受离线/影子评估/审计/版本化四重约束且支持门单调保守 ⇒ 无「学习改坏系统」的运行时通道；换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：三分法的全部合法性押在「风格与支持缺口可由交叉示教辨识」这一前提上——**被动示教数据里二者常常完全混杂，一旦归因反了，系统要么永远宣称「没教过」而拒绝泛化，要么把外推误当示范者习惯，在没教过的地方自信行动；而保形覆盖在支持域外会静默失效，支持门本身又无任何分布无关的保证——ROOT 最大的危险不是外推出错，而是它以为自己知道「哪里算支持域内」**。

**次级风险与缓解**：风格-支持不可辨识（A99 交叉示教 + 默认保守路由 + E301/E302）；风格不变删掉真信号（因果相关门 + E304）；支持门误报导致过度保守（保形阈值校准 + E303/E306）；示教投毒与评估污染（ℰ_demo/ℰ_contam + VQAuditor-D + E311/E312）；慢环偷偷进快环（定义 327 非干涉 + 只读冻结版本 + E313/E314）；恢复集本身不安全（C-RAS-WM 认证 + E305）。
