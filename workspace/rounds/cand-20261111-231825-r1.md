# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；本轮灵感：「力控」×「语音合成」）

> 第 56 轮把安全的依据从"模型置信"升级为"证据承诺"，用持久地图 𝓜、主动探询 PCE、协商护盾 ISE 把语义不确定性挡在不可逆接触之前；但它自陈的最大风险恰是自己架构的影子：安全最终仍信任语义信念（A33 的 ε_cal），而护盾面对不确定性仍只有"保守或制动"两个动作。更根本的是，第 56 轮的全部保证都是**离散、检查点、信念空间**的——它管住了"要不要碰"，却几乎没管"碰上去之后的连续几十毫秒"。本轮两个灵感补两个正交维度：**力控**把承诺从离散门变成连续带，用柔顺 + 力饱和铸一个**不依赖语义信念的物理安全底**；**语音合成**把解释从"发出去的文本"变成"被听懂的、韵律校准的、不可伪造的话语"，并把人类的**注意力**显式当作会被耗尽的预算来核算。核心命题再进一步：**物理说不会致伤，声证说不撒谎，二者不得互相代替**。

核心矛盾：
- **H26**：第 56 轮的 soundness 仍压在同一张语义地图上；再校准的地图也无法保证"这一次"的接触对象与刚度，而"制动"既非总可行（动态步态、平衡、逃生通道）也非总更安全（急停致跌）。需要一个**信念无关**的安全层：不赌信念对不对，而把力、能量、速度钉死在物理可承受域内。
- **H27**：第 56 轮把拒绝变成了解释，但人真正稀缺的不是解释而是**注意力**：运动噪声里听不清、看不懂、听腻了就无脑确认；且语音一旦成为授权通道，立刻变成新的攻击面（合成、克隆、重放）。交互的难点不是"生成解释"，而是"用有限注意力说真话"。
- **H28**：力与声都是**连续信号**，而证书只在检查点采样；若证书不覆盖高频力迹与话语，信念–力、说–做之间的漂移会恰好藏在两个检查点之间。

## 0. 直觉与动机

**灵感 1（力控 → 柔顺是第三种动作，力饱和是不信语义的安全底）**
直觉：第 56 轮的第三个动作是"把不确定性变少"（探询）；物理层还有第三个动作：**让**。与其在"保守绕开"与"急停"之间二选一，不如降低阻抗、把手变软，让接触本身成为有界且可回退的能量交换。力控给出漂亮性质：若硬件/控制律保证 `‖F(t)‖ ≤ F_sat ≤ F_tol`（对象与人的可承受力下界），则无论语义信念多离谱，接触造成的机械伤害都有上界——**这个上界不乘 ε_cal**。于是 safety case 从"信念正确"里解耦出"物理有限"。
更妙的是阻抗也是变速箱（与第 56 轮步态变速箱同构）：语义/接触风险高 → 调软（低 `K_p`、低 `F_sat`、限接近速度）；能力需求高（推/提/拧）→ 调硬。但"软"不等于"稳"：接触刚度失配会自激，故必须加**无源性/能量罐**条件，把"软=安全"从口号变成控制不变量。

**灵感 2（力控 → 触觉是 1kHz 探针，柔顺让"非破坏"从假设变定理）**
直觉：第 56 轮的探针是低频离散的（view/tap/shift），且"非破坏"只是统计假设 A34——"薄冰上轻点即塌"正是它自陈的首位风险。力/力矩是天然高带宽探针：滑移前兆、接触刚度、摩擦系数、接触质心都在 1kHz 流里。更关键：若探针在阻抗限下执行、力被饱和在 `F_abs` 以下，则"探针非破坏"不再需要假设，而是**控制律的构造性推论**，A34 从"幸存者偏差式假设"升级为"可验证的物理不变量"。触觉的软肋是覆盖：只在碰到的地方有，故必须与视觉/语义探针做**带宽–覆盖权衡**的联合 VOI，而非替代。

**灵感 3（语音合成 → 韵律是校准不确定度的信道，不是修辞）**
直觉：第 56 轮的解释 `Exp` 是文本，但人不在屏幕前，人在运动噪声里。可控韵律/风格 TTS 给三样东西：①**可听性**（噪声里也能被抓住）；②**韵律作为不确定度信道**（语速、停顿、音高、能量可编码"我很确定"与"我在猜"，且要求**校准**：听众从语气里听出的把握 ≈ 系统真实成功概率）；③**流式低延迟**（`τ_head ≤ 300ms` 内先给"当心—"的注意力锚点与要点，再流式补细节）。但合成语音必须被"锁死"在证书上：每个事实断言都要落在 `J_m` 的蕴含集内，否则就是"说"越过了"证"。此即 **say-do consistency**：说的与做的来自同一份证书。

**灵感 4（语音 → 语音是注意力预算的花费，也是新攻击面）**
直觉：告警不免费。重复同级告警会习惯化，响应概率按 `γ^k` 衰减，最终人把系统静音——等于拔掉安全回路。所以要像管能量一样管**注意力预算** `A(t)`：每次发声扣费，超支就升级/换渠道，且**禁止静默丢弃 L2**。同时语音一旦能授权，就必须假设它会被克隆、合成、重放：活体 + 说话人认证 + 内容绑定 nonce/水印，且**语音不得单独授权不可逆动作**。

**灵感 5（交叉 → 三重预算 + 双底 + 说做一致）**
直觉：把三样东西放进同一本账：**证据预算 ε**（语义，继承第 56 轮）、**物理预算 (F_sat, E_max, v_impact)**（力控）、**注意力预算 A**（语音交互）。三者不可互相替代：物理底保证"不会致伤"但不保证"碰对东西"；证据底保证"碰对东西"但不保证"碰的方式不伤"；注意力底保证"人还能介入"但既不能代替前两者、也不能被无限提取。证书 `J_c` 同时核算三本账，并强制 say-do 一致：**声只许说证书蕴含的，力只在物理包络内执行**。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（柔顺接触包络 CCE）** 接触不再是离散承诺，而是柔顺流形上的受控轨迹。阻抗律 `τ = Jᵀ[K_p(x_d−x) + K_d(ẋ_d−ẋ) + F_ff] + g(q)` 经力饱和 `sat_{F_sat}` 后执行。接触状态机 `Q={approach, impact, establish, sustain, release, abort}`，转移受守卫 `(v_impact ≤ v*, |ΔF| ≤ J_imp, E_tank ≥ 0)`。物理安全包络 `E_phys = {(F,E,v): ‖F(t)‖ ≤ F_sat ≤ F_tol⁻, ∫F·v dt ≤ E_max, v_impact ≤ v*, passivity: dE_tank/dt = P_in − P_out ≥ 0}`。**信念无关安全性**：`∀b,∀σ: contact under E_phys ⇒ P(mechanical harm) ≤ δ_phys`，且 `δ_phys` 不依赖 `ε_cal`。

**定义 134（触觉证据流 HBE）** 高频信号 `s_t=(F,τ,ẋ,slip)`；检测器 `D={slip, stiffness, friction, centroid}` 输出事件包 `e_hap=(r, k̂, μ̂, s_slip, t)`；带宽 `f_hap ≥ 1kHz`，空间覆盖仅接触点。似然 `p(e_hap|θ_true)`，校准误差 `|μ̂−μ| ≤ ε_μ`。**构造性非破坏**：探针在阻抗限下执行且 `F_probe(t) ≤ F_sat ≤ F_abs` 由控制律**保证**（非假设），故 `P(探针致失效) ≤ P(执行器/传感器故障) = δ_act`，取代第 56 轮 A34 的统计假设。

**定义 135（声证接地 SAG）** 话语 `u=(text,p)`，`p=(urgency, confidence, valence)`。生成策略 `π_utt(J_m, x_t, C_t)` 且 `content(u) ∈ Conseq(J_m)`（证书蕴含集）——无证据类不得成句。**说–做一致**：`‖claim(u) ⊖ state(x_t)‖ ≤ ε_sd`；说"稳" ⇔ `force_margin ≥ θ_m ∧ q=sustain`；说"不确定" ⇔ `H(b_r) ≥ θ_H`。**韵律校准** `PCE_p = E|conf_perceived(u) − P(success|J_m)| ≤ ε_pros`。生成受证书约束的模板/受限解码限制，不允许自由发挥。

**定义 136（语音指令完整性 VCI）** 语音输入 `c` 经门 `(auth, act, authz)`：说话人认证与活体/防重放 `auth(c) ≥ θ_auth`；语音行为分类 `act(c) ∈ {command, consent, annotation, question}`；权威映射 `authz: act → authority`。**语音不得为不可逆动作的唯一授权**（需非语音因子）。机器人自身语音带水印 + 内容绑定 nonce，可与人类语音及重放区分。

**定义 137（韵律同意阶梯 PCL）** 在 L0/L1/L2 上加"可听契约"：`τ_head ≤ 300ms` 内必须含注意力标记 + 紧急性韵律 + 要点，其后流式细节。**注意力预算** `A(t)`：告警率与习惯化使 `dA/dt ≤ 0`，重复同级告警响应概率 `r_k = r_0 γ^k`；升级规则：`τ_ack` 内未确认 → 升级或保守停；**不得静默丢弃任何 L2**。

**定义 138（接触–语音证书 CSC）** `J_c = (J_m, F_trace, q_log, audio_log, saydo_log, auth_log, budgets)`；检查：每承诺接触全程 `F_trace ⊂ E_phys`；`q_log` 状态机守卫合法；每句 `u` 被 `J_m` 蕴含；`saydo ≥ θ_sd`；每个 L2 有 `auth ≥ θ_auth` 的决议；三预算未超支。继承 `J_m` 全部检查。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 CIC（Compliant Interaction Control）

```python
def compliant_contact(x, sigma, M, task):
    K = impedance_from_risk(schedule_risk(sigma, M), task)   # 柔顺度变速箱
    F_sat = min(F_abs, F_tol_lower(M), task.force_cap)       # 取最保守物理帽
    q, tank = 'approach', EnergyTank(E_max)
    while q not in ('release', 'abort'):
        F_cmd = saturate(impedance_law(x, K, sigma), F_sat)
        if not passive_guard(tank, F_cmd, x):                # 无源性/能量罐
            F_cmd = damp(F_cmd)
        F = actuate(F_cmd)
        q = transition(q, guards(F, x, v_impact, impulse))
        log_force_trace(F, q)
    return q, trace   # 全程受 E_phys 约束，与 b_r 无关
```

### IP-134 HBE（Haptic Belief Evidence）

```python
def haptic_evidence(stream):
    for pkt in sliding_window(stream, f_hap):
        ev = []
        if slip_detector.onset(pkt): ev.append(E_hap('slip', s=pkt.slip))
        khat, muhat = contact_estimator(pkt)
        ev += [E_hap('stiffness', k=khat), E_hap('friction', mu=muhat)]
        if any(ev): yield to_map_events(ev, region=touched(pkt))   # 事件触发入图
```

### IP-135 SAG（Speech-Act Grounding）

```python
def generate_utterance(J, x, listener):
    claims = allowed_claims(J, x)                 # 证书蕴含集
    gist = most_salient(claims, listener)         # 前 300ms 的要点
    p = calibrated_prosody(J, x)                  # urgency/conf/valence ← 后验
    assert entail(gist, J) and saydo_ok(gist, x)  # 说-做一致
    audio = stream_tts(gist, p, first_chunk_deadline=tau_head)
    verify_watermark(audio)                       # 出处/防重放
    return audio, claim_record(gist, J)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CIC | O(f_ctrl·T) | O(Q+E_tank) | 力/能量饱和由构造保证、无源性 |
| HBE | O(f_hap) 流式 | O(1) 均摊 | 检测器校准、事件触发不丢关键跃迁 |
| SAG | O(|J|+L_utt) | O(L_utt) | 只生成证书蕴含句、韵律校准 |
| VCI | O(1)+O(H_op) | O(1) | 活体/防重放、语音不独授不可逆 |
| PCL | O(1)+流式 | O(Exp) | 前 300ms 要点、L2 不静默丢弃 |
| CSC | O(|F_trace|+|audio_log|) | O(|σ|+迹) | 全迹力包络、说-做一致、授权审计 |

**正确性定理（Compliant-Grounded Interaction Soundness, CGIS）**：在 A29–A36 基础上加 **(A37)** 物理包络可执行且可故障检测（`F_sat ≤ F_tol⁻`、能量罐无源性）；**(A38)** 触觉检测器校准（`|μ̂−μ| ≤ ε_μ`）且事件时延 `≤ τ_hap`；**(A39)** 话语由证书约束生成且韵律校准（`PCE_p ≤ ε_pros`）；**(A40)** 说话人认证健全（`P(spoof accepted) ≤ δ_spoof`）；**(A41)** 习惯化监控与升级保证（L2 不得静默丢弃）。则：(i) **信念无关物理界**：任意语义信念下 `P(mechanical harm) ≤ δ_phys(A37)+δ_hap`；(ii) 承诺健全性继承第 56 轮，但 `δ_probe → δ_act`（构造性非破坏）；(iii) **说–做一致界**：`P(utterance ⊥ state) ≤ ε_sd+ε_pros+P(audio fault)`；(iv) 交互单调性继承，且语音只可改有界信念或触发更保守动作。

# 第 57 轮产物 · 创新点清单 v33：TriBudget-Voice（柔顺力控×声证接地×三重预算，CIC×HBE×SAG×VCI×PCL×CSC）

## 2. 关键算法伪代码

### IP-133 CIC（Compliant Interaction Control）

```python
def impedance_from_risk(R, task):
    if task.needs_force:            K = stiff(task)        # 能力需求 → 调硬
    if R.high or task.near_human:   K = soft(K, R)         # 风险高 → 调软
    return clamp(K, K_min, K_max)

def compliant_contact(x, sigma, M, task):
    K = impedance_from_risk(schedule_risk(sigma, M), task)
    F_sat = min(F_abs, F_tol_lower(M), task.force_cap)     # 最保守物理帽
    q, tank, trace = 'approach', EnergyTank(E_max), []
    while q not in ('release', 'abort'):
        F_cmd = saturate(impedance_law(x, K, sigma), F_sat)
        if not passive_guard(tank, F_cmd, x):              # A37: 无源性/能量罐
            F_cmd = damp(F_cmd)
        F = actuate(F_cmd)                                 # 执行器限幅硬件兜底
        q = transition(q, guards(F, x, v_impact, impulse))
        trace.append((t_now, F, q, tank.level))
    return q, trace        # 全程受 E_phys 约束，其界与 b_r / ε_cal 无关
```

### IP-134 HBE（Haptic Belief Evidence）

```python
def haptic_evidence(stream, M):
    for pkt in sliding_window(stream, f_hap):
        ev = []
        s = slip_detector.onset(pkt)                       # 滑移前兆（提前量指标）

            ev.append(E_hap('stiffness', k=khat))
        if ev: yield to_map_events(ev, region=touched(pkt))  # 走 SMM 融合
# 探针力由 IP-133 饱和在 F_abs 以下 ⇒ 非破坏为构造性，而非 A34 的幸存假设
```

### IP-135 SAG（Speech-Act Grounding）

```python
def allowed_claims(J, x):
    claims = set()
    for c in core_contacts(J):                             # 证书里已承诺/已否决的接触
        claims.add(Claim(c.region, c.ev, c.margin, c.state))
    claims.add(Claim('uncertainty', H(J.M_core)))          # 只能声明真实后验熵
    return claims

def generate_utterance(J, x, listener, tau_head=0.3):
    claims = allowed_claims(J, x)
    gist = most_salient(claims, listener)                  # 前 τ_head 的要点
    p = calibrated_prosody(J, x)                           # 韵律 ← 校准后验
    if not entail(gist, J) or not saydo_ok(gist, x):       # A39: 说-做一致
        gist = fallback_grounded(claims)                   # 退回保守模板，绝不自由生成
    audio = stream_tts(gist, p, first_chunk_deadline=tau_head)
    audio = embed_watermark(audio, nonce=J.id, region=gist.region)
    return audio, claim_record(gist, J)
```

def voice_gate(c, op_hist, action):

def speak_consent(exp, level, A, listener):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CIC | O(f_ctrl·T) | O(Q+E_tank) | 力/能量饱和由构造保证、无源性（A37） |
| HBE | O(f_hap) 流式 | O(1) 均摊 | 检测器校准（A38）、事件触发不丢关键跃迁 |
| SAG | O(\|J\|+L_utt) | O(L_utt) | 只生成证书蕴含句、韵律校准（A39） |
| VCI | O(1)+O(H_op) | O(1) | 活体/防重放、语音不独授不可逆（A40） |
| PCL | O(1)+流式 | O(\|Exp\|) | 300ms 要点、L2 不静默丢弃（A41） |
| CSC | O(\|F_trace\|+\|audio_log\|) | O(\|σ\|+迹) | 全迹力包络、说–做一致、授权审计 |

**正确性定理（Compliant-Grounded Interaction Soundness, CGIS）**
假设 A29–A36（第 55/56 轮）成立；**(A37)** 物理包络可执行且可故障检测（`F_sat ≤ F_tol⁻`、能量罐无源性、执行器限幅硬件兜底）；**(A38)** 触觉检测器校准（`|μ̂−μ| ≤ ε_μ`）且事件时延 `≤ τ_hap`；**(A39)** 话语由证书约束生成且韵律校准（`PCE_p ≤ ε_pros`），不得自由生成；**(A40)** 说话人认证健全（`P(spoof accepted) ≤ δ_spoof`）且活体/防重放；**(A41)** 习惯化监控与升级保证（L2 不得静默丢弃）。则：

1. **信念无关物理界**：对任意语义信念 `b`（甚至对抗性），接触满足 `P(mechanical harm) ≤ δ_phys(A37) + δ_hap(A38)`，**不含 `ε_cal`**；
2. **承诺健全性**：继承第 56 轮 `P(fail) ≤ δ_f + ε_cal + ε_h(w_max) + δ_act`，其中 `δ_probe` 因构造性力饱和被 `δ_act`（执行/传感故障）替代；
3. **说–做一致界**：`P(utterance ⊥ state) ≤ ε_sd + ε_pros + P(audio pipeline fault) + δ_spoof`；
4. **交互单调性**：任何语音/探针路径只经（a）有界信念更新或（b）触发更保守动作影响系统，语音永不修改决策规则；
5. **部署界**（双底 + 注意力）：

```
P_safe ≥ 1 − [ Σ_cp (δ_f + ε_cal + ε_h)         # 语义底（第56轮）
             + δ_phys + δ_hap                    # 物理底（力控）
             + P(habituation ∧ escalation failure) # 注意力底（语音）
             + δ_spoof + P(护盾回退失败) ]
```

关键：**物理底与语义底正交**——物理底不信任语义，语义底不信任物理，二者同时失守才导致"碰对且不伤"的联合失败；**声证把两者绑在同一份证书上**，使"说"不能越过"证"，"力"不能越过"包络"。
