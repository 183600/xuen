# 第 42 轮（新循环第 2 轮） · 电池管理 × 视觉定位：把证书从「安全谓词」升级为「带资源与证据前置条件的恢复可行性契约」（四层架构 v7）

> 承接第 41 轮 v18（CAR × LCS × CMC）。第 41 轮把证书变成运行期转移守卫，并用 E74/E78 守住「可用性崩塌」；但它默认了两个从未写进不变式的前提：**(A) 执行器、算力与散热是无限的**——SafeStop 与所有守卫都隐含「想停就能停、想算就能算」；**(B) 位姿证据是真的**——几何边际与 ValidRegion 都建在「位姿已知」上。电池管理与视觉定位正好各拆掉一个前提：前者说明安全是一份会被消耗、会老化、会被功率/热约束削减的预算；后者说明位姿是一个可能「自信地错、且错得相关」的信念集合。本轮核心主张：**证书不应只回答「是否安全」，而应回答「在现有能量、功率、算力与证据下，是否还存在一条被认证的恢复路径」；运行时自动机维护的不是单一安全集，而是资源—证据联合的恢复可行域。** 可用性因此不再是阈值调参的结果，而是必须用资源买回来的性质。

## 0. 直觉与动机

**灵感 1（电池管理 → 安全有预算，而且预算会老化）**：第 41 轮的守卫大多写成 \(g_e(x)=m_e(x)-\theta_e\ge0\)，其中控制量 \(u\) 被默认可取整个容许集 \(U\)。但真实机器人上，\(U\) 由电池管理系统的 **SoP（可用功率）** 实时裁剪：低温、低 SoC、电芯不一致、热保护都会让同样一条 CBF/收缩证书失效。更隐蔽的是 **SafeStop 本身要耗能**：机械臂保持位姿要力矩，移动底盘返回充电桩要行驶，通信与计算也要电。于是存在一种 v18 无法表达的不安全：*证书说「随时可以安全停」，但机器人已经没有能量执行这个「安全停」。* 电池管理给出的第二个提醒是 **老化**：容量衰减與内阻上升是慢时间尺度、近似单调的状态，它不会让某一拍突然不安全，却会让「三年前颁发的证书」在生命周期后段系统性失效。因此本轮把证书的时间有效性从秒级 \(T_{hold}\) 扩展到 **循环/健康度级的 \(T_{life}\)**，并把「能量到恢复」写成显式守卫，而不是假设。

**灵感 2（视觉定位 → 位姿证据是第二种会耗尽的资源）**：激光雷达/几何定位的失效常表现为「退化」，视觉定位的失效则常表现为 **感知别名（perceptual aliasing）**：走廊、货架、重复纹理、相似房间会让位置识别给出一个「高分但错误」的位姿。更危险的是它往往**自信地错**：协方差很小，多帧也一致，因为整个场景本来就长得一样。若沿用 v18 的「点估计 + 误差球」，证书会在这个错误位姿上算出「安全」，而真实位姿已经越过边界。正确的对象不是单个位姿，而是带覆盖保证的 **信念集合 \(B_t\)**（conformal / 多假设 / 粒子集）。关键洞察是：**我们并不需要位姿精确，只需要位姿「足以做决定」**——若信念集合里的每个假设都让当前所有守卫取相同符号，那么再高的定位精度对本次转移也没有信息量；这正是第 41 轮「决策等价证书」（定义 28）从「界的紧致度」到「信念的歧义度」的平移。若不够充分，就应当**主动换取证据**（移动到可区分视角、回看已知地标）或保守降级，而不是把 top-1 当成真值。

**耦合（两种资源共用一个储备，恢复动作本身也要花钱）**：视觉重定位要耗电、耗时、占算力；能量储备又依赖位姿（不知道自己在哪，就不知道回充电桩要多少电）；任务推进同时消耗能量与证据新鲜度。于是「先重定位、再返回、还是继续任务」不是三个独立模块的 if-else，而是一个 **联合可行性问题**：任何恢复动作都必须连同其失败分支一起，被当前的能量下界、功率包络、算力预算与证据覆盖共同担保。这把第 41 轮的最大风险「可用性崩塌」重构为一个更可操作的问题：**可用性不是免费的，它必须由储备支付；真正该问的不是「能不能留在 Nominal」，而是「在任何时刻是否还买得起一条被认证的恢复路径」。**

## 1. 形式化定义

**定义 32（资源条件化执行包络 RCE）**：设资源状态 \(r=(s,p,T_b,h)\) 为 SoC、可用功率、温度与健康度。技能 \(\pi\) 的容许控制集升级为 \(U_\pi(r)=\{u:\|u\|\le u_{\max}(p,T_b,h)\}\)，且 \(r_1\preceq r_2\Rightarrow U_\pi(r_1)\subseteq U_\pi(r_2)\)。证书不再是对固定 \(U\) 的断言，而是对包络的断言：\((r,\delta)\)-有效证书要求 barrier/收缩条件对所有 \(u\in U_\pi(r)\) 成立。记对应的最大安全不变集为 \(S_\pi(r)\)；资源单调性给出 \(S_\pi(r_1)\subseteq S_\pi(r_2)\)。**这使「功率降额」直接表现为不变集收缩，而不是被忽略的运行时扰动。**

**定义 33（能量—恢复储备证书 ESR）**：对模式 \(q\) 与状态 \(x\)，令 \(\Pi^{rec}_q(x)\) 为已认证的恢复计划集（就地安全停、返回充电、先重定位再停、释放/支撑等）。每个计划 \(\rho\) 的**最坏分支能量**为
\[
E^{hi}_\rho(x,q;\delta)=\max_{\text{成功/失败分支}}\ \sup_{P\in\mathcal P_\delta}\ \mathbb E_P\!\left[\int_0^{T_\rho}\!\|u(t)\|\,\|v(t)\|\,dt\right]+\eta,
\]
其中 \(\mathcal P_\delta\) 是能耗分布的 \(\delta\)-模糊集（取 CVaR 或分布鲁棒上界，而非仅点估计）。记能量下界 \(E^{lo}_{avail}=C(h,T_b)\cdot s_{lo}\)。**能量守卫**为
\[
g_E(x,q)=\max_{\rho\in\Pi^{rec}_q(x)}\big(E^{lo}_{avail}-E^{hi}_\rho(x,q;\delta)\big)\ge0,
\]
即「至少存在一条买得起的恢复路径」。取 \(\max\) 而非 \(\min\) 是因为只需存在性；但每个候选 \(\rho\) 都必须先通过证据与算力守卫。**尾部风险修正**：若只取区间上界而不覆盖重尾，罕见故障仍会搁浅——这正是本轮合成实验观察到的残余 0.25% 失败，故 \(E^{hi}\) 必须用 CVaR/极值界而非均值加固定百分比。

**定义 34（视觉定位信念集与决策充分定位 DSL）**：视觉定位输出信念 \(B_t=\{(\hat T_k,w_k)\}_{k=1}^{K}\)，满足 \(\Pr[T^\star\in B_t]\ge1-\delta\)（可交换性下 conformal，或对多假设做保守并集）。给定守卫集 \(G=\{g_e\}\) 与位姿参数化 \(g_e(x,T)\)，定义决策映射 \(d_G(x,T)=(\mathbf 1[g_e(x,T)\ge0])_e\)。称 \(B_t\) 在 \(x\) 处对 \(G\) **决策充分**，当且仅当
\[
d_G(x,T)\ \text{对所有}\ T\in B_t\ \text{相同（或对所有非零权模态相同）}.
\]
未定守卫集 \(U_B(x)=\{e:\exists T,T'\in B_t,\ \operatorname{sign}g_e(x,T)\ne\operatorname{sign}g_e(x,T')\}\)。若 \(U_B=\emptyset\)，称 \(B_t\) 已「足够做决定」，可停止精化；否则必须选择恢复性证据动作 \(a\in A_{evid}\)（换视角、回看地标、减速），或降级。**别名证书**要求：次优模态后验质量低于阈值，或其次优模态与主模态**决策等价**；否则不得宣称定位可用。另记证据龄期 \(\tau_{ev}\) 与环境支持度：外观漂移、光照突变、动态遮挡会膨胀 \(B_t\) 并提高 \(\delta\)，而不是悄悄沿用旧协方差。

**定义 35（联合资源—证据恢复不变式 REJI）**：状态 \(z=(x,q,r,B_t)\)。定义**恢复可行域** \(K\) 为满足下式的最大受控不变集：\(z\in K\) 当且仅当存在恢复计划 \(\rho\) 与策略，使得沿 \(\rho\) 的每个后继 \(z'\)：
1. 证据充分：\(U_{B_t'}(x')=\emptyset\)（或按保守解释把未定守卫映射到更保守模式）；
2. 资源可行：\(g_E(x',q')\ge0\)，且算力 \(C_\rho\le\Gamma(r)\)、最坏执行时间 \(W_\rho\le W_{\max}(T_b,p)\)；
3. 受控封闭：\(z'\in K\)；
4. 活性：存在秩函数 \(\phi\) 在有限步内下降到再生集 \(R\)（充电桩、家、已确认地标邻域）或终止安全集，从而排除「永远困在 SafeStop」。
运行时证书升级为 **REJI 不变式** \(I_{REJI}\subseteq K\)。SafeStop 不再是一个无条件保底动作，而是 \(\Pi^{rec}\) 中「就地停」这一条计划；它同样要通过能量与证据守卫。

**定义 36（寿命证书与再认证时钟）**：健康度 \(h(t)\) 慢变且近似单调，证书参数 \(u_{\max},C,W_{\max},L_m\) 均为 \((h,T_b)\) 的函数。定义寿命有效期 \(T_{life}(h)\)（或循环数 \(N_{life}\)）使
\[
\sup_{t\in[t_0,t_0+T_{life}]}\ \big|h(t)-h_{cal}\big|\le\varepsilon_h
\ \Rightarrow\ \text{证书参数漂移仍在 }\delta\text{ 预算内}.
\]
再认证由事件触发：\(\min\{t_0+T_{life},\ |h-h_{cal}|>\varepsilon_h,\ \text{热剂量超限},\ \text{循环数跨越}\}\)。这把 v18 的「每拍/每保持时间」重认证扩展为**第四时间尺度（生命周期）**，并使「电池老化导致证书失效」成为可观测的维护事件，而不是运行期的不安全。

**定义 37（资源—证据增广自动机 REA）**：在 CAHA 上增加制度 \(Q'=Q\cup\{\textsc{ReLocalize},\textsc{Return},\textsc{Brownout}\}\)，并把守卫扩展为 \(g_e^{re}(z)=g_e(x)\wedge g_E(z)\wedge g_{DSL}(z)\)，其中 \(g_{DSL}\) 编码决策充分性。**单调保守性随之扩展**：能量/证据/热状态不确定时，转移只能指向更保守模式；但新增两个「用储备换可用性」的正向动作：`ReLocalize`（花能量与时间消除可约歧义）与 `Return`（主动返回再生集）。于是可用性崩塌被替换为**可支付、可恢复的储备调度**，且任何一次「继续 Nominal」都必须先证明恢复计划仍买得起。

## 2. 三大产出设计

### 2.1 IP-54 RESOURCE-EVIDENCE AUTOMATON（REA，资源—证据自动机）
1. 制度扩展：Nominal / Watch / ReLocalize / Brownout / Degraded / Return / Escalate / SafeStop；`ReLocalize` 与 `Return` 为可恢复态，带最小驻留与滞回。
2. 每条边绑定三元守卫 \((m_e,g_E,g_{DSL})\)；守卫计算复用 IP-55/56 与 IP-52 分层证书。
3. 恢复计划集 \(\Pi^{rec}_q(x)\) 的合成与检查：对每个计划验证证据充分、能量下界、算力/WCET、受控封闭与活性秩函数；失败则增加保守计划或提前转移。
4. 组合：与 IP-47 乘积自动机兼容；`ReLocalize`/`Return` 作为可共享的子自动机，乘积时守卫合取、资源预算相加。
5. 抖动/Zeno：\(\tau_{\min}\) + 滞回 + 「每次 ReLocalize 只允许一个证据动作」上限，保证单位时间转移有界。

### 2.2 IP-55 ENERGY-TAIL-RISK CERTIFICATE（PERC，功率—能量储备证书）
1. 电池状态估计：SoC/SoP/SoH 的区间/分布鲁棒界，含温度与电芯不一致；热模型给算力降额包络。
2. 能耗模型：按技能/模式标定 \(E_\rho\)，用 CVaR/极值理论覆盖重尾；输出带有效区间的能耗证书。
3. 恢复能量守卫：\(g_E=E^{lo}_{avail}-E^{hi}_\rho-\eta\)，对成功/失败两分支取最坏；支持「就地停」「返回」「先重定位再停」三种计划。
4. 寿命管理：健康度触发再认证与降额，输出 \(T_{life}\) 与维护建议；与 IP-53 编译成 BMS 看门狗。
5. 与规划耦合：把 \(g_E\) 作为路径/技能选择的资源约束，避免规划出「安全但回不来」的轨迹。

### 2.3 IP-56 DECISION-SUFFICIENT LOCALIZATION CERTIFICATE（DSLC，决策充分定位证书）
1. 视觉定位输出多假设信念集与覆盖保证；按场景重复性/外观漂移自适应膨胀，禁止用 top-1 冒充真值。
2. 决策充分性检查：对当前守卫集计算 \(U_B\)；为空则停止精化，非空则触发证据动作或降级。
3. 主动重定位：以信息增益/能量成本比选择视角或地标；失败分支必须仍满足 REJI。
4. 别名证书：次优模态后验质量阈值 + 决策等价判定；与地图新鲜度/证据龄期联合报告。
5. 与 IP-49 融合：视觉全局位姿约束漂移上界，LoL 回环用于收紧 \(B_t\)，但回环误匹配必须被别名证书拦截。

## 4. 实验设计（E79–E84 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E79 能量储备有效性 | 搁浅率、储备违反率、任务完成率、充电频次（含老化前后） | 标称模型 0 搁浅；重尾下≤0.3%；储备违反=0；完成率降≤5 个百分点 |
| E80 决策充分定位 | 别名误安全率、任务成功率、重定位次数、可用性损失 | 误安全=0；成功率≥95%；≤1 次/回合；步数增幅≤5% |
| E81 联合储备 | 因重定位耗能导致的搁浅率、完成率、能量开销 | 搁浅=0；完成率降≤3 个百分点；开销可解释 |
| E82 寿命再认证 | 证书违反数、再认证次数、提前告警率、\(T_{life}\) 覆盖 | 0 违反；≤16 次/年；提前≥1 个维护周期；覆盖≥99% |
| E83 REA 正确性/活性 | REJI 验证通过率、恢复成功率、Zeno、再生集到达时间 | 100% 通过；恢复≥99%；有界驻留；中位<2s |
| E84 长时端到端 | 不安全事件、Nominal 占比、成功率、充电间隔、恢复时间 | 0 起；Nominal≥70%；成功率≥85%；≥1h；恢复<2s |

回退：E79 不通过（储备不可保证）→ 退回 v18 + 固定 20% 能量保留 + 仅就地停；E80 不通过（别名不可拦）→ 停用视觉全局定位，退回 LiDAR/局部几何并扩大误差球；E81 不通过（联合预算过度保守）→ 拆分为独立储备但把重定位限制为单步；E84 可用性不达标 → 增加 `Return` 中间档与慢速 Brownout，而非放弃资源证书。

## 5. 本轮最大风险

**一句话**：最大的风险是**能量与位姿的置信界系统性偏乐观**——BMS 漏掉长尾消耗、视觉定位在重复结构下过度自信，于是「联合恢复储备」变成一张空头支票，系统反而因为「账面还有储备」而更敢进入 Nominal，实际却在透支并不存在的安全边际；因此 E79 的搁浅/储备违反率与 E80 的别名误安全率必须是硬门槛，任何分布漂移或证据龄期告警都必须回退到 v18 的保守包络。

# 第 42 轮产物 · 创新点清单 v19：资源—证据联合认证运行时（REA × PERC × DSLC）（四层架构 v7）

> 承接第 41 轮产物 v18（IP-51/52/53）。本轮**增量插入** IP-54/55/56，并升级 IP-39/45/46/47/48/49/50/51/52/53；不推倒既有层级。核心是把 v18 的「证书=安全谓词」升级为「证书=在能量、功率、算力、证据预算下仍存在被认证恢复路径的可行性契约」。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |
|---|---|---|---|
| IP-54 | RESOURCE-EVIDENCE AUTOMATON (REA) | 新增 | 在 CAHA 上增加 ReLocalize / Return / Brownout；守卫扩展为 \((m_e,g_E,g_{DSL})\)；维护资源—证据联合恢复不变式 REJI；SafeStop 降级为一种需付费的恢复计划 |

## 2. 关键算法（伪代码）

### IP-55 PERC：能量—恢复储备检查

```
def avail_lower(r):
    return capacity(r.h, r.T) * (r.s - k_delta * sigma_s(r))   # 保守下界

def plan_energy_upper(rho, z, delta):
    # 成功/失败分支都算；尾部用 CVaR 而不是 mean*(1+eps)
    return max(cvar(rho.energy_success, delta),
               cvar(rho.energy_failure, delta)) + rho.margin

def energy_guard(z, rho):
    return avail_lower(z.r) - plan_energy_upper(rho, z, z.delta) - eta

def lifetime_valid(cert, r, cycles):
    return (abs(r.h - cert.h_cal) <= eps_h
            and r.T <= cert.T_max
            and cycles <= cert.N_exp)

def recertify(cert, r, cycles):
    if not lifetime_valid(cert, r, cycles):
        return RCA.issue(health_aware=True)   # 新证书带新的 T_life
    return cert
```

### IP-56 DSLC：决策充分定位与别名拦截

```
def decision_sufficient(B, guards, x):
    signs = set()
    for (T, w) in B.modes_with_mass_above(w_min):
        signs.add(tuple(sign(g(x, T)) for g in guards))
    return len(signs) == 1, signs

def localize_and_guard(z, guards):
    B = visual.update(z.obs)
    ok, _ = decision_sufficient(B, guards, z.x)
    if ok:
        return B, True                       # 足够做决定，停止精化
    # 别名证书：次优模态要么决策等价，要么必须消歧
    if B.second_best_is_guard_equivalent(guards):
        return B, True
    if z.can_afford("relocalize") and B.expected_info_gain() > cost_threshold(z):
        return visual.active_relocalize(B, z), False
    return B, False                          # 不可消歧 → 保守解释
```

### IP-54 REA：恢复可行性合成与制度转移

```
def feasible_recovery(z, guards):
    best = None
    for rho in Pi_rec(z.x, z.q):
        # 1) 证据充分性（含重定位后的分支）
        B_ok, _ = decision_sufficient(rho.belief, rho.guards(), z.x)
        if not B_ok and rho.can_relocalize:
            rho = rho.prepend_relocalize()
            B_ok, _ = decision_sufficient(rho.belief, rho.guards(), z.x)
        if not B_ok:
            continue
        # 2) 能量、算力、WCET 预算
        if energy_guard(z, rho) < 0:
            continue
        if rho.compute > compute_budget(z.r) or rho.wcet > wcet_max(z.r):
            continue
        # 3) 受控封闭 + 活性
        if not in_recovery_set(z, rho) or not rho.ranks_down():
            continue
        if best is None or rho.cost < best.cost:
            best = rho
    return best

def rea_step(z, obs):
    z = update(z, obs)                       # BMS + visual + state
    guards = current_guards(z)
    rho = feasible_recovery(z, guards)
    if rho is None:
        return force_last_resort(z)          # 只允许最保守的就地动作
    if not decision_sufficient(z.B, guards, z.x)[0]:
        return enter("ReLocalize")
    if energy_guard(z, rho) < safety_margin(z):
        return enter("Return")               # 主动补充储备
    if derated(z.r):
        return enter("Brownout")             # 功率降额，缩小控制包络
    if rho is not nominal_plan(z):
        return enter("Degraded")
    return enter("Nominal")
```

### 联合调度（任务 / 重定位 / 返回）

```
def joint_schedule(z):
    options = [("task", task_action(z)),
               ("relocalize", evidence_action(z)),
               ("return", return_action(z))]
    best, best_score = None, -inf
    for name, a in options:
        z2 = predict(z, a)
        rho2 = feasible_recovery(z2, current_guards(z2))
        if rho2 is None:
            continue                          # 任何选项都不得消耗掉恢复能力
        score = expected_progress(z2) - lambda_E * reserve_use(a) \
                - lambda_B * ambiguity(z2.B) - lambda_T * time(a)
        if score > best_score:
            best, best_score = (name, a), score
    return best or ("return", return_action(z))
```

### 寿命再认证时钟

```
def life_clock(cert, r, cycles):
    if abs(r.h - cert.h_cal) > eps_h:
        return "recertify"                 # 健康度漂移
    if r.T > cert.T_max or thermal_dose(r) > cert.dose_max:
        return "derate+recertify"          # 热预算
    if cycles > cert.N_exp:
        return "recertify"                 # 循环数
    return "valid"
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| IP-55 储备检查 | \(O(|\Pi^{rec}|\cdot(S+|\text{guards}|))\)，\(S\) 为尾部场景数 | 若 \(E^{lo}_{avail}\) 覆盖真实可用能量且 \(E^{hi}_\rho\) 覆盖真实消耗，则 \(g_E\ge0\Rightarrow\) 恢复计划能量可行 |
| IP-55 尾部界 | 每次重认证 \(O(S\log S)\) | CVaR 覆盖 \(\mathcal P_\delta\) 时，仅对分布内成立；分布外失效必须由漂移检测拦截 |
| IP-56 决策充分性 | \(O(K\cdot\|G\|)\)，\(K\) 为有效模态数 | 若 \(T^\star\in B_t\) 且 \(d_G\) 在 \(B_t\) 上恒定，则用任一假设算出的守卫决策等于真位姿决策 |
| IP-56 主动重定位 | \(O(K\cdot\|A_{evid}\|)\) | 失败分支仍须通过 REJI；否则拒绝该证据动作 |
| IP-54 REA 合成 | 离线 \(O(|Q'|\cdot|E|\cdot|\Pi^{rec}|\cdot\text{cost})\) | \(I_{REJI}\) 归纳封闭 + 活性秩函数 ⟹ 安全且不永久困于 SafeStop（依赖再生集可达） |
| IP-54 在线转移 | 每拍 \(O(|\Pi^{rec}|\cdot K\cdot\|G\|)\) | 仅当存在可行恢复计划时才允许进入 Nominal；否则单调降级 |
| IP-53 看门狗 | WCET 受功率/热包络约束；内存 \(O(\|G\|+\|K\|)\) | 单边可靠：ok \(\Rightarrow\) 守卫在 \((1-\delta)\) 下成立；BMS/视觉任一 trip 强制最保守恢复 |
| IP-50 课程 | 与原课程同阶 | 低电量/高别名分带不改变证书本身，只改变训练分布 |

**四条正确性命题（摘要）**：
1. **储备可靠性**：在 \(E^{hi}\) 的分布鲁棒覆盖成立时，\(\textsc{Return}\) 与 \(\textsc{SafeStop}\) 均可在耗尽前执行；若真实能耗落在 \(\mathcal P_\delta\) 之外，命题失效——这正是尾部风险必须显式建模的原因。
2. **证据可靠性**：DSL 的 soundness 来自信念集覆盖而非 top-1 精度；只要真位姿在 \(B_t\) 内且守卫决策恒定，就不会因定位错误而误判安全。
3. **寿命可靠性**：若 \(h\) 漂移在 \(\varepsilon_h\) 内、证书参数对 \(h\) 的局部 Lipschitz 界成立，则 \(T_{life}\) 内证书仍 \((1-\delta)\) 有效；超出即触发再认证。
4. **活性**：REJI 的秩函数在有限步内到达再生集 \(R\) 或终止安全集，因此不会出现 v18 所担心的「永久 Degraded/SafeStop」——除非 \(R\) 本身不可达，此时应把「不可达」显式报告为环境/任务不可行，而非静默滞留。

## 6. 本轮最大风险

**一句话**：最大的风险是**资源与证据的置信界系统性偏乐观**——BMS 漏掉长尾消耗、视觉定位在重复结构下过度自信，于是「联合恢复储备」变成空头支票，系统反而因为「账面还有储备」而更敢进入 Nominal，实际却在透支并不存在的安全边际；因此 E79 的搁浅/储备违反率与 E80 的别名误安全率必须与 E84 的可用性同时守门，任何分布漂移或证据龄期告警都回退到 v18 的保守包络。
