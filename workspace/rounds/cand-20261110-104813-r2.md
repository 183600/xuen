# 第 43 轮（新循环第 3 轮） · Demo-Cert × CertBench：以「模仿学习的演示流形」收窄证书作用域，以「证伪式基准」做外部判决（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 的 Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」——证书可能在自信满满中静默失效。本轮灵感词「模仿学习」「基准测试」精准命中该风险的两个根因。**模仿学习**给出一条来自真实世界的锚：人类演示既是策略先验，也是「证书究竟要为哪片状态负责」的作用域约束；把证书从「全域 sound、因而全域过保守」收紧为「演示可达管（tube）内 sound + tube 外显式降级/SafeStop」，用真实数据同时压低保守性与仿真偏差。**基准测试**回答「谁来判断证书真的有效」——v19 的 E79–E86 是自设自评，存在「出题人=答题人」的评估污染；本轮建立**证伪式、留出式、抗泄漏**的 CertBench，把 soundness、可用性、可迁移性变成可复现的外部判决。

## 0. 直觉与动机

**灵感 1（模仿学习 → 证书的「作用域锚」）**：v19 的证书要覆盖整个状态空间 |X|，因此必须对最坏情形取保守上界，必然牺牲可用性（第 41 轮「可用性崩塌」的根因）。但机器人实际只沿「人类演示所示的少数行为模式」运行。直觉是：证书不必对 |X| 负责，只需对**演示流形 D_demo 经策略跟踪后的可达管 T_demo** 负责；一旦检测到偏离管就显式 SafeStop/降级。这一步把「全域 sound」换成「管域 sound + 管外显式不安全」，不是放松安全性，而是把**不可验证的默认安全**换成**可验证的显式降级**，同时让保守余量大幅收窄。

**灵感 2（模仿学习 → 证书的「结构先验」与「真实锚」）**：模仿学习不只是给一条策略。若采用**稳定动力系统（stable DS / SEDS / 收缩理论）**拟合演示，策略天然携带 Lyapunov 函数 V(x) 与收缩度量 M(x)，子水平集 {V ≤ c} 就是**由构造保证的不变集**——这是真正的 certificate-by-construction，而非事后打补丁。更进一步，用演示拟合真实动力学的**残差** r(x,u)=f_real−f_model，再用**共形预测（conformal prediction）**给出有限样本、分布无关的残差覆盖界（可交换性下覆盖 ≥1−α），替代 v19 里手工设定的 W_1 与经验 L_m。这直接、可证地填「仿真偏差」的坑，比 Wasserstein 假设更可信。

**灵感 3（基准测试 → 证伪优先的外部判决）**：一张证书最危险的不是「被证伪」，而是「没被认真证伪」。v19 的压力测试由 SCV 自导自演，容易被自己的域随机化假设框住。CertBench 的直觉是做一个**证书界的对抗基准**：分层任务族（标称、守卫面逼近、故障注入、分布偏移、组合、长时程）+ **证伪器主动搜索反例**（利用证书结构做定向攻击）+ **冻结隐藏测试集** + **黑盒证书接口**。只允许通过证书 API 查询，防止「改评测代码」。核心指标不是平均奖励，而是**不安全率（带置信区间）、标称可用率、保守比 ρ、认证耗时、人工确认耗时、演示-认证效率、迁移间隙**。

**灵感 4（闭环升级：Demo ↔ Cert ↔ Bench）**：三者形成比 v19 更靠外的飞轮。CertBench 的失败用例反哺 IP-50 课程与 CKB；若失败集中在「演示未覆盖但可达」的区域，则由 ADQ 主动向人类请求该区域的**恢复演示**（active imitation）；新演示重训稳定 DS 策略 → 重算 Lyapunov/收缩证书 → 重跑 CRC 残差界 → 交给 CertBench。证书的进化单位从「仿真参数」升级为「**演示 + 评测证据**」。

**与 v19 的关系（不推倒，只外接）**：SCV 仍是仿真数据引擎，CKB 仍是模板仓库，ECR 仍是边缘执行体；本轮把 DAC/CRC 插在「证书合成与 soundness 证明」处，把 CertBench 插在「评估与验收」处，形成 **Cert → Bench → Demo → Cert** 的外部闭环。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（演示分布与行为流形）**：演示集 Ξ_demo = {ξ^(i)}_{i=1}^N，ξ^(i) = {(x_t, u_t)}_{t=0}^{T_i}，采样自人类策略 π_H。演示分布 D_demo 为状态-动作对的联合经验分布；**行为流形** M_demo = supp(D_demo) 的 δ-膨胀（在证书相关度量下）。定义**演示覆盖度** cov(M) = P_{x∼D_deploy}[dist(x, M_demo) ≤ δ]，作为证书作用域的置信度指标。

**定义 39（演示锚定可达管与证书作用域）**：给定模仿策略 π_θ 与跟踪误差界 e_track（由 CRC 或实机标定给出），演示锚定可达管
T_demo = {x : ∃ξ∈Ξ_demo, ∃t, ‖x − x_t^ξ‖ ≤ r_tube(t) + e_track}。
证书作用域从 |X| 收紧为 T_demo：**管域 soundness** = ∀x∈T_demo, m(x) ≥ θ；管外一律进入 SafeStop/降级态。即「**sound within, explicit-unsafe outside**」。

**定义 40（稳定 DS 模仿的构造性证书）**：策略 π_θ 由稳定动力系统表示 ẋ = f_θ(x) + g_θ(x)u，存在 Lyapunov 函数 V_θ(x)（正定、径向无界）与收缩度量 M_θ(x)≻0，满足沿闭环 Ḣ(x) ≤ −λV_θ(x)。取不变集 Ω_c = {x : V_θ(x) ≤ c}。**命题（certificate by construction）**：若 T_demo ⊆ Ω_c 且 Ω_c 内所有守卫/障碍约束由 V_θ 的梯度条件满足，则 Ω_c 是前向不变安全集，证书模板（守卫、不变式、T_hold）可直接从 (V_θ, M_θ) 读出，无需事后 CEGAR 全域搜索。

**定义 41（共形残差证书）**：令残差 r(x,u)=f_real(x,u)−f_model(x,u)。用演示/标定数据拟合 r̂，并以共形预测构造**非一致性分数** s(x,u)=‖r(x,u)−r̂(x,u)‖/σ(x)，取校准集分位数 q_{1−α}，得**有限样本、分布无关**的残差界 ‖r−r̂‖ ≤ q_{1−α}·σ(x)，覆盖概率 ≥1−α（可交换性下）。把该界经证书 Lipschitz 常数 L_m 传播：**m_real ≥ m_model − L_m·q_{1−α}·max σ**。**命题**：当真实数据与部署数据可交换时，该界比 v19 的 W_1 假设更紧且带显式置信；若检测到可交换性破坏（定义 43），降级回 v19 的 Wasserstein 保守界。

**定义 42（CertBench 基准协议与指标）**：CertBench = (T_fam, S_dev, S_hidden, F, M)。T_fam 为分层任务族：B1 标称可用、B2 守卫面逼近、B3 故障注入、B4 分布偏移、B5 组合任务、B6 长时程。S_dev 公开开发集，S_hidden 冻结隐藏集。F 为**证伪器**：以证书结构（守卫面、边际梯度、管边界）为先验的定向反例搜索。指标：
- 不安全率 UR（Wilson 95% CI 上界），
- 标称可用率 NA，
- 保守比 ρ = m_cert / m_true（sound 需 ≥1，越接近 1 越好），
- 认证耗时 t_cert、人工确认 t_human，
- 演示-认证效率 E_dc = 认证成功任务数 / 演示小时数，
- 迁移间隙 G_tr = |UR_sim − UR_B4|。
**验收准则**：S_hidden 上的 UR 上界 ≤ ε_safe，且 ρ ≤ 1+ε_cons，且 NA ≥ NA_min。

**定义 43（泄漏、污染与可交换性破坏）**：**检索泄漏**：若评估任务 τ∈S_hidden 与 CKB/Ξ_demo 的指纹相似度 > τ_leak 且其证书模板被直接复用，则该任务结果作废（防止 RAG 把答案「背」进基准）。**基准污染**：任何对 S_hidden 的梯度/调参接触都视为污染，用哈希承诺与审计日志保证只读。**可交换性检验**：用滑窗与置换检验判定 D_t 与校准集是否可交换；拒绝则 CRC 界失效，回退定义 41 的 Wasserstein 分支。

**定义 44（主动示范请求与评测驱动课程）**：CertBench 失败集 Φ_fail ⊆ S_hidden 触发 ADQ：按「失败密度 × 证书敏感度 × 可达性」排序，生成**恢复演示查询** q = (x_fail, 期望恢复行为)，交人类标注。新演示并入 Ξ_demo，触发 π_θ、V_θ、q_{1−α} 的增量更新，并在 Φ_fail 上回归（不通过则不发布新证书）。课程难度由「CertBench 通过率曲线 + 决策等价边际」联合调度。

## 2. 五大产出设计（增 IP-57/58/59/60 + 升级 IP-49/50/51/52/53/54/55/45/47）

### 2.1 IP-57 DEMO-ANCHOR-CERT（DAC，演示锚定证书）
1. **稳定 DS 策略拟合**：SEDS/收缩约束最小二乘拟合演示，输出 f_θ、V_θ、M_θ；用留出演示做稳定性回归。
2. **管构造**：由跟踪残差与 CRC 界计算 r_tube(t)、e_track；管边界只在演示邻域扩张，避免全域爆炸。
3. **证书抽取**：从 (V_θ, M_θ, Ω_c) 读出守卫、不变式、T_hold；对管外定义显式 SafeStop 与「管重入」判定。
4. **演示安全过滤**：用安全 critic 剔除不安全演示；无法剔除的标注为「负演示」约束（far-from-demo 惩罚），而非当作正样本。

### 2.2 IP-58 CONFORMAL-RESIDUAL-CERT（CRC，共形残差证书）
1. **残差学习**：r̂ 以状态-动作特征拟合（含 IMU/接触模式），校准集与训练集严格分离。
2. **共形校准**：按条件分层（速度/接触/载荷）做 Mondrian 共形，给出条件覆盖 c(x)。
3. **界传播**：将 q_{1−α}·σ(x) 经 L_m 传播成证书保守修正，写入证书对象；可交换性检验失败则回退 W_1 界。
4. **在线监控**：残差分布漂移统计量 S_t^{res} 与定义 36 的 S_t 并列上报。

### 2.3 IP-59 CERTBENCH（CB，证伪式基准）
1. **任务族与冻结隐藏集**：六大任务族 B1–B6；S_hidden 以哈希承诺冻结，仅排行榜评测时解开。
2. **证书感知证伪器**：以守卫面法向、边际梯度、管边界为目标做对抗采样（CEM/MCMC + 梯度近似），持续产出反例。
3. **黑盒证书接口**：仅暴露 certify(x)→(decision, m, θ, scope)，禁止读取内部代码/模板，防评测作弊。
4. **抗泄漏与可复现**：检索相似度防火墙 + 证据日志 + 随机种子/版本钉死；输出 dev→hidden 迁移报告。

### 2.4 IP-60 ACTIVE-DEMO-QUERY（ADQ，主动示范请求）
1. **失败聚类**：对 Φ_fail 按语义/几何聚类，定位「管外可达」缺口。
2. **查询生成**：生成恢复演示的最小查询集（状态种子 + 期望动作提示），人机交互式采集。
3. **增量再认证**：新演示 → 稳定 DS 增量拟合 → 证书增量更新 → Φ_fail 回归；未过回归不发布。

```
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + CRC 残差界 → 演示跟踪误差 e_track
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 管域 soundness | CertBench B1–B6 上管域不安全事件；UR 95%CI 上界 | 0 起；UR 上界 ≤ 1e−3 |
| E88 保守性收窄 | 保守比 ρ vs v19；标称可用率提升 | ρ 中位数 ≤ 1.3；NA +≥10pp |
| E89 共形覆盖 | 经验覆盖率 vs 1−α；条件分层覆盖偏差 | ≥1−α−2%@α=0.05；分层偏差 < 3pp |
| E90 基准抗泄漏/可复现 | 泄漏判定任务数；dev→hidden 复现差 | 0 泄漏；UR 差 < 1pp |
| E91 演示-认证效率 | 达到认证所需演示小时数 E_dc | 比 v19 冷启动降 ≥40% |
| E92 主动示范闭环 | Φ_fail 在 ≤2 轮 ADQ 后消除比例 | ≥80% |
| E93 证伪强度 | 证伪器发现的独立反例数/严重度 | 严重反例 ≥5 类，修复后回归通过 |
| E94 长时程 + 组合 | 100h 连续；组合任务乘积管 sound | 0 不安全；组合认证通过 ≥95% |

回退：E87 失败 → 扩大 T_demo/加恢复演示；E89 可交换性拒绝 → 回退 W_1 界；E90 泄漏 → 冻结更大隐藏集并隔离 CKB；E91/E92 无收益 → 回到 v19 模板手写路径；E93 证伪过强导致不可认证 → 缩小任务族至 B1/B2 并显式声明范围。

## 5. 本轮最大风险

**一句话**：最大的新失效不是「证书错了」，而是「证书对了但作用域错了」——若演示流形过窄或偏置（只演示了容易的标称行为），T_demo 会把安全关键区域排除在证书之外，而管外 SafeStop 在高速/拥挤场景下本身就是危险动作；再叠加共形预测的可交换性在部署偏移下被破坏，证书会「在演示流形上完美、在流形外盲区」地失效。

# 第 43 轮产物 · 创新点清单 v20：Demo-Anchored Certificate × Conformal Residual × CertBench（四层架构 v8）

> 承接 v19（Sim-Cert-RAG 飞轮）。本轮**增量插入** IP-57/58/59/60，并升级 IP-49/50/51/52/53/54/55/45/47；不推倒任何既有层级。核心是把 v19 的「仿真验证→知识沉淀→边缘低成本→持续进化」外接两层：用**模仿学习**把证书作用域从全域收紧到演示管，并给出构造性 Lyapunov 证书与共形残差界；用**证伪式基准**把评估从自设自评升级为冻结隐藏集的外部判决。

## 2. 关键算法（伪代码）

### IP-57 DAC：稳定 DS 模仿与演示锚定证书
```
def fit_stable_ds(demos, lambda_contract=0.5):
    # SEDS / 收缩约束：拟合 f_theta 使存在 V_theta, M_theta > 0
    f_theta, V_theta, M_theta = solve_seds(
        demos,
        constraints=['V(0)=0', 'V(x)>0', 'dV/dt <= -lambda_contract*V'])
    assert stability_regression(f_theta, V_theta, holdout_demos) > 0.99
    return f_theta, V_theta, M_theta

def build_demo_tube(demos, e_track, delta):
    # 可达管：每条演示轨迹逐点膨胀 r_tube(t)=delta+e_track(t)
    balls = []
    for xi in demos:
        for t, x_t in enumerate(xi.x):
            balls.append(Ball(center=x_t, radius=delta + e_track(t)))
    return TubeUnion(balls)   # 并集近似 + 空间哈希加速 contains()

def extract_certificate(V_theta, M_theta, tube, c):
    Omega_c = sublevel_set(V_theta, c)
    assert tube.subset(Omega_c), '演示管必须落在不变集内'
    guards = level_set_guards(V_theta, c)       # 由 V 的等值面直接生成
    invariant = Omega_c
    T_hold = hold_time_from(lambda_min(M_theta))
    return Certificate(guards=guards, invariant=invariant,
                       T_hold=T_hold, scope=tube, lyap=V_theta)

def filter_demos(demos, safety_critic):
    pos, neg = [], []
    for xi in demos:
        (pos if safety_critic(xi).min_margin >= 0 else neg).append(xi)
    return pos, neg   # neg 作为 far-from-demo 约束，不当正样本
```

### IP-58 CRC：共形残差界与保守阈值传播
```
def conformal_calibrate(residual_model, calib_trajs, alpha=0.05):
    scores = []
    for (x, u, r_true) in calib_trajs:
        s = norm(r_true - residual_model.predict(x, u)) / residual_model.sigma(x)
        scores.append(s)
    # 有限样本修正，保证边缘覆盖 >= 1-alpha
    q = empirical_quantile(scores, ceil((len(scores)+1)*(1-alpha))/len(scores))
    return q

def propagate_residual_bound(q, L_m, sigma_max, theta_model):
    # m_real >= m_model - L_m*q*sigma_max  ->  阈值上抬保证 sound
    bound = L_m * q * sigma_max
    return theta_model + bound, bound

def check_exchangeability(window, calib):
    # 置换检验；拒绝则 CRC 界失效，回退 W_1
    p = permutation_test(window, calib, stat='KS')
    return (p >= 0.05), p
```

### IP-59 CertBench：抗泄漏的证伪式评测
```
def certbench_run(cert_api, S_hidden, falsifier, eps_safe=1e-3,
                  eps_cons=0.3, NA_min=0.8):
    # 1) 泄漏防火墙：与 CKB/演示高度重合的隐藏任务作废
    S_eval = [t for t in S_hidden if leak_score(t, CKB, demos) <= TAU_LEAK]
    assert len(S_eval) / len(S_hidden) > 0.99, '隐藏集泄漏过多'

    # 2) 证书感知证伪：只经黑盒 API 定向搜索反例
    adv = falsifier.search(cert_api, budget=10_000,
                           prior=cert_api.structure_hint())  # 面法向/边际梯度/管边界

    # 3) 冻结评测（黑盒，不可读内部模板）
    recs = []
    for task in S_eval:
        for t in task.rollout(interactive=False):
            d = cert_api.certify(t.x)
            recs.append(Rec(unsafe=t.unsafe, decision=d.decision,
                            m_cert=d.margin, m_true=task.true_margin(t.x)))
    UR = unsafe_rate(recs); UR_ub = wilson_upper(UR, len(recs), z=1.96)
    NA = nominal_availability(recs)
    rho = median([r.m_cert / max(r.m_true, 1e-9) for r in recs])
    ok = (UR_ub <= eps_safe) and (rho <= 1 + eps_cons) and (NA >= NA_min)
    return Result(UR_ub, NA, rho, adv, ok, commit=hash(S_hidden))

def leak_score(task, CKB, demos):
    # 检索相似度 + 模板复用检测（防 RAG 背答案）
    return max(task.fp.sim(phi) * task.fp.sim(psi) for phi, psi in CKB.keys())
```

### IP-60 ADQ：主动示范请求与增量再认证
```
def active_demo_query(Phi_fail, cert, K=5):
    clusters = cluster_by(Phi_fail, key=lambda f: (f.semantic, f.region))
    ranked = sorted(clusters,
                    key=lambda c: c.density * cert.sensitivity(c) * c.reachability)
    return [RecoveryQuery(seed=c.rep_state, expected='stabilize/return_to_tube')
            for c in ranked[:K]]

def incremental_recertify(new_demos, cert, Phi_fail):
    demos = cert.demos + new_demos
    f, V, M = fit_stable_ds(demos)
    tube = build_demo_tube(demos, cert.e_track, cert.delta)
    C = extract_certificate(V, M, tube, cert.c)
    q = conformal_calibrate(cert.residual, cert.calib + new_demos)
    theta_real, bound = propagate_residual_bound(q, C.L_m, cert.sigma_max, C.theta)
    C = C.with_theta(theta_real, conformal=q, demos=demos)
    assert regression_pass(C, Phi_fail), '未通过失败回归，不发布'
    return C
```

### IP-51/52 升级：管域守卫与作用域感知的轻量认证
```
def car_transition_guard_v2(e, x, cert):
    if not cert.scope.contains(x):          # 管外：显式不安全
        return GuardResult('SAFE_STOP', reason='out_of_demo_tube',
                           reentry=cert.reentry_condition)
    margin = cert.margin(x)                 # 来自 V_theta 或 L0 查表
    return GuardResult('GO' if margin >= cert.theta_real[e] else 'SAFE_STOP',
                       margin=margin)

def certify_light_v3(x, cert, budget_us=200):
    if not cert.scope.contains(x):
        return downgrade_to_safe_stop(cert), -1   # 域外不跑高成本档
    b = cert_lookup_L0(x)                          # T-1: 5μs
    U = undecided_guards(b, cert.guards)
    if not U:
        return b, -1
    status, margin = monitor_step_INT8(quantize_obs(x))  # T0: 100μs
    b.m_lo = margin
    return (b, 0) if not undecided_guards(b, cert.guards) else (downgrade_monotone(b), 0)
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 演示流形过窄/偏置：证书在「未演示但可达」区域成盲区 | 高 | 演示覆盖度 cov(M) 作为发布门禁；ADQ 主动补演示；管外强制 SafeStop + 重入条件 |
| 管外 SafeStop 本身危险（高速/拥挤） | 高 | 管设计纳入制动距离约束；SafeStop 需在 Ω_c 内可执行；E88 同时评估降级安全性 |

| 稳定 DS 拟合失败：演示含多模态/不连续行为 | 中 | 分段/混合稳定 DS（GMM-SEDS）；必要时退回 DMP + 单独收缩证书 |
| 共形界过宽导致重新保守 | 中 | Mondrian 条件分层 + σ(x) 归一分数；保守比 ρ 纳入验收，超阈值触发重设计 |

## 6. 本轮最大风险

**一句话**：最大的新失效不是「证书错了」，而是「证书对了但作用域错了」——若演示流形过窄或偏置（只演示了容易的标称行为），T_demo 会把安全关键区域排除在证书之外，而管外 SafeStop 在高速/拥挤场景下本身就是危险动作；再叠加共形预测的可交换性在部署偏移下被破坏，证书会「在演示流形上完美、在流形外盲区」地失效。
