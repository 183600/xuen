# 第 56 轮（承接第 55 轮 v31.5 语义-接触接地；新一轮灵感循环第 1 轮；本轮灵感：「意图识别」×「多机协同」）

> 第 55 轮把证书从“动作-鲁棒性”推进到“接触语义是否可信、全身耦合下是否可行”，但仍站在**单机**视角。本轮把视角抬到**团队**：机器人要协调的不是“我下一步做什么”，而是“**别人到底想做什么、愿意为此承诺什么、我该信到什么程度**”。核心矛盾：
> **H27**：意图识别的输出是隐藏目标/资源/时序的后验，而非确定事实；把高置信意图当事实，会让多机协同在“我以为你要让”与“你以为我要让”之间同时礼让或同时抢行。
> **H28**：多机协同的可行性不是单机可行性的笛卡尔积；共享通道、互斥资源、碰撞与死锁把团队约束耦合在一起，逐机安全的意图组合仍可联合失败。
> **H29**：意图推断是内生的——我的观测取决于你的动作，你的动作又取决于你对我的意图判断；被动分类会被自己的行为自证，必须允许**安全的主动探测**。
> **H30**：意图会漂移、会过期、会被通信延迟与云边不一致污染；证书必须把“意图歧义预算”和“协同不变量”写成可部署条件，而不是假定共识天然存在。

## 0. 直觉与动机

**灵感 1（意图识别 → 可执行意图假设，而非语义标签）**
直觉：在机器人团队里，“意图”至少是四元组：目标 `g`、资源声明 `r`（我要用哪段通道/哪个工位）、时间窗 `τ`、协同模式 `c`（独立/让行/跟随/共同搬运）。若一个意图无法由本机技能与语义-接触条件执行，它就不该进入假设空间。于是意图识别不是开放词表分类，而是**在可执行性约束下做假设检验**：`Γ_i(ι)=1` 才进入 `ℐ_i^adm`。这把第 55 轮的语义-接触层变成意图的“接地器”，显著压低“看起来像但做不到”的虚假意图。

**灵感 2（多机协同 → 意图条件联合生存核，而非独立护盾）**
直觉：每台机器人都安全，不等于团队安全。两机在窄通道相向而行，各自“前方无障碍”，联合状态却已进入死锁/碰撞的吸引域。因此需要**团队级生存核** `K(B)`：在意图歧义球 `B` 内，存在一个联合策略，使所有可能的真实意图实现都不越出安全集与协同不变量。协同从“各自避障”变成“在同一个联合可行域里选动作”。

**灵感 3（意图歧义 → 承诺与仲裁，而非同时礼让）**
直觉：不确定性下最危险的不是不知道，而是双方都用同一条“礼貌规则”。若两机都检测到对方意图不明并同时让行，会活锁；若同时抢行，会碰撞。因此需要一个**承诺-仲裁协议**：把意图的一部分变成可观测的承诺令牌（谁先声明资源、谁已提交、谁在让行），用单调承诺与固定优先级兜底把“猜意图”转成“读承诺”。意图识别负责缩小可能性，承诺协议负责在剩余歧义上选出唯一行动者。

**灵感 4（主动意图探测 → 用安全的信息动作换确定性）**
直觉：被动等对方暴露意图可能太晚。机器人可以在**不离开联合生存核**的前提下，做一个小的“问路”动作或发一条结构化意图查询，使对方的响应最大化地区分候选意图。关键是探测本身必须带风险预算：`IG/risk` 最大化，而不是“先试探再说”。

**灵感 5（意图-协同证书 → 把歧义与团队不变量写进部署）**
直觉：第 54/55 轮的证书只对单机动作与接触负责。团队部署需要新证书 `J_I`：记录核心意图元组、校准后的意图集、联合生存核裕度、意图扰动实测量 `δ_I`、承诺日志、协同不变量见证与消息新鲜度 `τ_stale`。只有“意图集覆盖真实意图 + 联合核不塌 + 协议不变量成立 + 消息不过期”同时满足，团队才可部署。

**灵感 6（云边意图共识 → 全局意图图 + 本地证据回传）**
直觉：云端适合维护跨机的全局意图图、资源占用与任务优先级；边端适合用局部观测、力反馈和承诺日志做细粒度校验。两者不该交换“一个意图标签”，而应交换**意图集 + 证据 + 版本号**：边端回传意图集与云端不一致的热点，云端触发重规划或提高该区域的歧义预算。这把第 54 轮的云边动作接口升级为**意图-动作联合接口**。

## 1. 形式化定义（增量：定义 127–134）

**定义 127（意图元组与可执行意图）**
机器人 `i` 的意图 `ι=(g,r,τ,c)`，其中 `g∈G` 目标，`r⊆R` 共享资源声明，`τ∈T` 时间窗，`c∈C` 协同模式。意图空间 `ℐ_i`。接地判定
`Γ_i(ι)=1 ⇔ ∃σ∈S_i^*: achieves(σ,g) ∧ cover(α_σ,A_g) ∧ C_contact(σ)⊆C^+(Σ) ∧ r 与自身资源约束相容`。
可执行意图集 `ℐ_i^adm={ι∈ℐ_i | Γ_i(ι)=1}`，信念 `b_i∈Δ(ℐ_i^adm)`。
（`α_σ` 来自第 54 轮 ACS，`C^+(Σ)` 来自第 55 轮定义 123。）

**定义 128（校准意图集与联合歧义球）**
给定校准集，构造保形意图集 `I_i^α(x_i)`：
`P(ι_i^true∈I_i^α(x_i)) ≥ 1-α`（可交换性下）。
联合信念 `b=Corr(⊗_i b_i)`，`Corr` 修正共同任务先验造成的相关性。联合歧义球
`B_ε(b)={b' | d_W(b,b')≤ε}`，其中 `d_W` 为联合意图单纯形上的 Wasserstein-1。
鲁棒意图集 `𝕀^α_ε = supp(∪_{b'∈B_ε(b)} b')`，意图鲁棒谱
`ρ_int(ε)=inf_{b'∈B_ε(b)} P_team_success(b')`。

**定义 129（意图条件联合生存核）**
联合状态 `x=(x_1,…,x_n)`，联合动作 `u=(u_1,…,u_n)`，接触力 `λ`。协同约束集 `𝒞` 包含：动力学可行、`||p_i-p_j||≥d_min`、资源互斥 `r_i(t)∩r_j(t)=∅`、以及协同不变量 `χ`（不进入他人已承诺走廊、至少保留一条撤离路径、无活锁等待环）。定义
`K(B)=νZ.{x∈𝒳_safe∩χ | ∃π: ∀b'∈B, x^{π,b'}_{t+1}∈Z}`。
即“在意图歧义球内，存在一个联合策略，使所有可能意图实现都留在安全集与协同不变量内”的最大固定点。`K_in⊆K(B)⊆K_out` 为可计算的内/外近似。

**定义 130（意图-协同盾）**
机器人 `i` 收到邻居已承诺意图 `m_-i` 后，
`u_i^*=argmin_{u_i∈U_i} ||u_i-u_i^nom||²_W`
`s.t. (u_i,û_-i)∈K_in(B), supp(λ_i)⊆C_i^+(Σ), u_i 与 m_i 的承诺状态一致, r_i 不与已提交资源冲突`。
若可行集为空，按 CAP 的优先级回退到 `yield_i` 或 `stop_i`，而不是无条件急停；急停本身可能制造新的死锁。

**定义 131（承诺-仲裁协议 CAP）**
每机协议状态 `m_i∈{Free,Propose,Commit,Yield}`，资源令牌 `tok_i⊆R`。转移关系 `→_CAP` 满足：
(S1) 互斥：`Commit_i(r)∧Commit_j(r) ⇒ i=j`；
(S2) 单调：同一资源上的 `Commit` 不可静默撤销，只能显式 `Abort` 并进入退避；
(S3) 无死锁：存在固定优先级 `≺`，当等待图出现环时，优先级最低者强制 `Yield`；
(S4) 有界收敛：任意资源争用在 `τ_cap` 内要么一方 `Commit`，要么全部安全 `Yield`。
CAP 的输出是可观测承诺令牌序列，作为证书中的协同不变量见证。

**定义 132（主动意图探测）**
在状态 `x` 下，候选探测 `(u_i,m_i)`（动作或结构化消息）。信息增益
`IG(b;u_i,m_i)=H(b)-E_{o'~P(·|b,u_i,m_i)}[H(b'|o')]`。
选择
`probe^*=argmax_{(u_i,m_i)} IG(b;u_i,m_i)`
`s.t. risk(u_i,m_i)≤δ_probe ∧ (u_i,û_-i)∈K_in(B)`。
即“只在联合生存核内做最有助于消除意图歧义的动作”，探测不是冒险，而是受控的信息获取。

**定义 133（意图-协同证书）**
`J_I=(ℐ_core,𝕀^α_ε,K_margin,ρ_int,δ_I,χ_cert,τ_stale,evidence)`：
- `ℐ_core` 规划实际使用的核心意图元组；
- `𝕀^α_ε` 部署时的鲁棒意图集；
- `K_margin=min_{x∈轨迹} dist(x,∂K(B))` 联合生存核裕度；
- `δ_I=d_W(b_deploy,b_calib)` 意图分布漂移实测量；
- `χ_cert` 承诺令牌序列与资源互斥日志；
- `τ_stale` 最旧未过期意图消息年龄；
- `evidence` 含歧义热点、协议违例反例与探测日志。
若 `I_i^α` 覆盖校准通过、`K_margin≥θ_K`、`ρ_int≥ρ_min`、`δ_I≤Θ_I`、`τ_stale≤τ_max` 且 CAP 不变量全部验证通过，则团队意图-协同可部署。

**定义 134（云边意图共识协议）**
云端意图图 `G_I=(V_I,E_I)`：节点为意图元组与共享资源，边为兼容/冲突关系。云端信念 `b_c`，边端信念 `b_e`。意图不一致度 `Δ_I=d_W(b_c,b_e)`。若 `Δ_I>δ_c` 或边端报告歧义热点，边端回传证据 `E_I`，云端触发重规划或扩大歧义预算；否则合并意图集：
`𝕀^α_ε ← merge(𝕀_c,𝕀_e)`
并要求 `supp(𝕀^α_ε)` 同时覆盖两侧校准集。协议以版本号 `ver` 与 TTL `τ_stale` 防止陈旧意图被当作共识。

## 2. 关键算法 伪代码

### IP-127 EIG（Executable Intent Grounding）

```python
def executable_intent_set(robot, Sigma, skill_lib, kappa, theta_m):
    I_adm = set()
    for intent in enumerate_intents(robot.goal_space, robot.resources):
        g, r, tau, c = intent
        for sigma in skill_lib.sequences_for(g):
            if not cover_check(sigma.alpha, action_goal(g)):
                continue
            if not contact_subset(contacts_used(sigma),
                                  conservative_contacts(Sigma, kappa, theta_m)):
                continue
            if resource_conflict(r, robot.own_resources):
                continue
            I_adm.add(intent)
            break
    return I_adm
```

### IP-128 IIB（Intent Inference with Belief）

```python
def calibrated_intent_belief(obs, robot, I_adm, calib, alpha):
    logits = intent_model(obs, robot)
    b = softmax(logits, mask=I_adm)          # 只在可执行意图上归一化
    I_alpha = conformal_set(b, calib, alpha) # 覆盖率 >= 1-alpha
    eps = ambiguity_radius(b, calib)         # 由残差/漂移估计
    return b, I_alpha, eps
```

### IP-129 JVK（Joint Viability Kernel）

```python
def joint_viability_kernel(B, x0, horizon, robots):
    Z = safe_states(x0, horizon) & coordination_invariant_space(robots)
    while True:
        Z_next = set()
        for x in Z:
            if exists_joint_policy(x, B, robots, Z):  # 含碰撞/资源互斥/chi
                Z_next.add(x)
        if Z_next == Z:
            break
        Z = Z_next
    return KernelApprox(K_in=inner_approx(Z), K_out=outer_approx(Z, B))
```

### IP-130 ICS（Intent Coordination Shield）

```python
def intent_coordination_shield(u_nom, x, i, B, commitments, K_in, C_plus):
    u = qp_solve(
        H=W_i, g=-W_i @ u_nom,
        constraints=[
            joint_viability_constraint(x, u, K_in, B),
            commitment_consistency(u, commitments[i]),
            resource_exclusion(u, commitments, i),
            contact_constraint(u, C_plus),
            joint_limit_constraint(u),
        ],
    )
    if u is None:
        return yield_or_stop(i, commitments, priority=CAP_priority), 'fallback'
    return u, 'ok'
```

### IP-131 CAP（Commitment Arbitration Protocol）

```python
def cap_step(i, intent_claim, commitments, priority, now, tau_cap):
    st = commitments[i].state
    if st == 'Free':
        if intent_claim.resource in committed_resources(commitments):
            return propose(i, intent_claim)
        return commit(i, intent_claim)
    if st == 'Propose':
        if no_conflict(intent_claim, commitments) and has_token(i, priority):
            return commit(i, intent_claim)
        if wait_age(i, now) > tau_cap:
            return yield_(i)
    if st == 'Commit':
        if intent_done(i):
            return release(i)
        return keep(i)
    if st == 'Yield':
        if channel_clear(i, commitments):
            return propose(i, intent_claim)
        return keep(i)
```

### IP-132 AIP（Active Intent Probing）

```python
def active_intent_probe(x, b, B, candidate_probes, K_in, delta_probe):
    best, best_score = None, -inf
    for probe in candidate_probes:
        if risk(probe, x) > delta_probe:
            continue
        if not in_joint_kernel(probe, x, K_in, B):
            continue
        ig = mutual_information(b, probe, observation_model)
        score = ig / max(risk(probe, x), eps_risk)
        if score > best_score:
            best, best_score = probe, score
    return best
```

### IP-133 ICC（Intent-Coordination Certificate）

```python
def intent_coordination_certificate(traj, I_alpha, B, rho_int, budgets, cap_log):
    I_core = core_intents(traj)
    if not coverage_ok(I_alpha, I_core, budgets.alpha):
        return ('reject', 'intent_coverage_fail')
    K_margin = min(distance_to_boundary_K(x, B) for x in traj)
    delta_I = wasserstein(b_deploy, b_calib)
    if K_margin < budgets.theta_K or delta_I > budgets.Theta_I:
        return ('reject', 'intent_budget_exceeded', K_margin, delta_I)
    if rho_int(delta_I) < budgets.rho_min:
        return ('reject', 'intent_robustness_fail')
    if not verify_cap_invariants(cap_log):       # S1-S4
        return ('reject', 'commitment_invariant_violation')
    if max_age(cap_log) > budgets.tau_stale:
        return ('reject', 'stale_intent')
    return ('ok', IntentCert(I_core, I_alpha, K_margin, rho_int, delta_I, cap_log))
```

### IP-134 CEI（Cloud-Edge Intent Consensus）

```python
def cloud_edge_intent_consensus(b_c, G_I, edge, delta_c):
    b_e, I_e, evidence = edge.local_intent_belief()
    delta = wasserstein(b_c, b_e)
    if delta > delta_c or edge.has_hotspots():
        return ('reprofile', edge.intent_hotspots(I_e), evidence)
    I_shared = merge_intent_sets(b_c, b_e)
    if not covers(I_shared, I_e):
        return ('widen_budget', 'intent_set_mismatch')
    return ('ok', I_shared, merge_uncertainty(b_c, b_e))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EIG | O(\|ℐ_i\|·\|S_i\|·\|A\|) | O(\|ℐ_i\|) | 可执行性判定 sound、动作剖面覆盖 |
| IIB | O(\|ℐ_i\|·\|D_cal\|) 校准；O(\|ℐ_i\|) 推理 | O(\|ℐ_i\|·\|D_cal\|) | 保形覆盖率、漂移检测 |
| JVK | O(\|X\|·T·QP^n) 最坏；分解后 O(\|X\|·Π\|U_i\|) | O(\|X\|) | 内近似 sound、固定点收敛 |
| ICS | O(QP_i) 每机每步 | O(\|U_i\|) | QP 可行或协议安全回退 |
| CAP | O(\|N\| log\|N\|) 每争用 | O(\|N\|) | 互斥/单调/无死锁/有界收敛 |
| AIP | O(\|Π_probe\|·(\|ℐ\|+H)) 每次探测 | O(\|ℐ\|) | 探测在联合核内、风险预算闭合 |
| ICC | O(\|轨迹\|·\|ℐ\|+\|cap_log\|) | O(\|ℐ\|+\|cap_log\|) | 覆盖、裕度、漂移、新鲜度联合校验 |
| CEI | O(\|V_I\|+\|E_I\|+\|ℐ\|) | O(\|V_I\|+\|E_I\|) | 不一致阈值、版本/TTL 防陈旧 |

**正确性定理（Team Intent-Coordination Soundness）**
假设第 55 轮 (A29)–(A32) 成立；新增：
**(A33)** 意图保形集在校准域内满足 `P(ι^true∈𝕀^α_ε) ≥ 1-α_int`，且漂移检测能在 `δ_I>Θ_I` 前触发；
**(A34)** `K_in⊆K(B)⊆K_out`，且 ICS 在不可行时按 CAP 回退到 `yield/stop∈𝒳_safe`；
**(A35)** 真实联合意图 profile 落在 `𝕀^α_ε` 内；
**(A36)** CAP 满足 (S1)–(S4)，通信延迟 ≤ `τ_c`，等待图优先级无环；
**(A37)** 云边意图不一致 `Δ_I≤δ_c`，且 `τ_stale` 外的消息被丢弃；
**(A38)** 第 55 轮语义-接触层与其校准假设继续成立。
则单次团队任务的安全概率满足：
```
P_safe ≥ 1 - P(ι^true ∉ 𝕀^α_ε) - P(K_out \ K_in ≠ ∅)
          - P(CAP 不变量违反) - P(δ_I > Θ_I)
          - P(τ_stale > τ_max) - P(语义-接触失败)
```
关键：**意图不确定性进集合、联合可行性进核、剩余歧义进承诺、通信陈旧性进证书**。任何一层都不允许把“看起来确定”的意图当作“已经承诺”的事实。

```python
def executable_intent_set(robot, Sigma, skill_lib, kappa, theta_m):
    I_adm = set()
    for intent in enumerate_intents(robot.goal_space, robot.resources):
        g, r, tau, c = intent
        for sigma in skill_lib.sequences_for(g):
            if not cover_check(sigma.alpha, action_goal(g)):
                continue
            if not contact_subset(contacts_used(sigma),
                                  conservative_contacts(Sigma, kappa, theta_m)):
                continue
            if resource_conflict(r, robot.own_resources):
                continue
            I_adm.add(intent)
            break
    return I_adm
```

### IP-128 IIB

```python
def calibrated_intent_belief(obs, robot, I_adm, calib, alpha):
    logits = intent_model(obs, robot)
    b = softmax(logits, mask=I_adm)          # 只在可执行意图上归一化
    I_alpha = conformal_set(b, calib, alpha) # 覆盖率 >= 1-alpha
```

### IP-129 JVK

```python
def joint_viability_kernel(B, x0, horizon, robots):
    Z = safe_states(x0, horizon) & coordination_invariant_space(robots)
    while True:
        Z_next = set()
        for x in Z:
            if exists_joint_policy(x, B, robots, Z):  # 含碰撞/资源互斥/chi
                Z_next.add(x)
        if Z_next == Z:
            break
        Z = Z_next
    return KernelApprox(K_in=inner_approx(Z), K_out=outer_approx(Z, B))
```

### IP-131 CAP

```python
def cap_step(i, intent_claim, commitments, priority, now, tau_cap):
    st = commitments[i].state
    if st == 'Free':
        if intent_claim.resource in committed_resources(commitments):
            return propose(i, intent_claim)
        return commit(i, intent_claim)
    if st == 'Propose':
        if no_conflict(intent_claim, commitments) and has_token(i, priority):
            return commit(i, intent_claim)
        if wait_age(i, now) > tau_cap:
            return yield_(i)
    if st == 'Commit':
        if intent_done(i):
            return release(i)
        return keep(i)
    if st == 'Yield':
        if channel_clear(i, commitments):
            return propose(i, intent_claim)
        return keep(i)
```

### IP-132 AIP

```python
def active_intent_probe(x, b, B, candidate_probes, K_in, delta_probe):
    best, best_score = None, -inf
    for probe in candidate_probes:
        if risk(probe, x) > delta_probe:
            continue
        if not in_joint_kernel(probe, x, K_in, B):
            continue
        ig = mutual_information(b, probe, observation_model)
        score = ig / max(risk(probe, x), eps_risk)
        if score > best_score:
            best, best_score = probe, score
    return best
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |

**正确性定理（Team Intent-Coordination Soundness）**
假设第 55 轮 (A29)–(A32) 成立；新增：
**(A33)** `P(ι^true∈𝕀^α_ε) ≥ 1-α_int`，漂移检测在 `δ_I>Θ_I` 前触发；
**(A34)** `K_in⊆K(B)⊆K_out`，ICS 不可行时按 CAP 回退到 `yield/stop∈𝒳_safe`；
**(A35)** 真实联合意图 profile 落在 `𝕀^α_ε` 内；
**(A36)** CAP 满足 (S1)–(S4)，通信延迟 ≤ `τ_c`，等待图优先级无环；
**(A37)** 云边 `Δ_I≤δ_c`，`τ_stale` 外消息被丢弃；
**(A38)** 第 55 轮语义-接触层及其校准假设成立。
则单次团队任务安全概率：
```
P_safe ≥ 1 - P(ι^true ∉ 𝕀^α_ε) - P(K_out \ K_in ≠ ∅)
          - P(CAP 不变量违反) - P(δ_I > Θ_I)
          - P(τ_stale > τ_max) - P(语义-接触失败)
```
关键：**意图不确定性进集合、联合可行性进核、剩余歧义进承诺、通信陈旧性进证书**；任何一层都不允许把“看起来确定”的意图当作“已经承诺”的事实。
