# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环新周期第 1 轮；本轮灵感：「惯性测量单元」×「迭代验证」）

> 第 54 轮的致命弱点是「动作空间可对齐假象」：云端与边端都只比对“声明执行的动作”，而无法证明物理上真的执行了该动作；证书 `J` 是一次性签发的静态对象，签发后环境漂移、执行偏差、传感器退化都不会让它失效。本轮引入 **惯性测量单元（IMU）作为高频物理见证者**，并把 **验证从一次性签发改为证书上的迭代算子**。核心矛盾：H22：IMU 能高频见证真实运动，但它自身漂移且只观测本体；H23：一次性证书在非平稳环境中必然过期，迭代验证必须跑赢漂移。

## 0. 直觉与动机

**灵感 1（IMU = 物理见证者，而非又一个传感器）**
直觉：第 54 轮的 `cover(S,A_T)` 只检查“边端声称能执行 a_e”，本质是**声明式**的。IMU 给出与命令无关的 `ω(t), f(t)`：如果技能 S 被真正执行，其角速度/比力的频谱形状、jerk 分布、重力对齐方式应当与 S 的“运动指纹”匹配；若只是动作错位或空转，指纹必然不匹配。因此 IMU 不是增加一个输入，而是给证书加一个**不可由云端伪造的见证项** `W_imu`。这把“动作对齐”从语义承诺降级为物理事实。

**灵感 2（动作剖面 → 惯性指纹剖面）**
直觉：`α_S(a)` 是“技能能覆盖哪些动作”，但同一动作在不同本体上可以有完全不同的实现路径。于是把动作剖面细化为 **惯性签名** `ς_S`：技能 S 的典型 IMU 特征轨迹（主频、谱熵、jerk RMS、Allan 偏差）。执行窗口的实测特征 `φ_imu` 与 `ς_S` 的 Mahalanobis 距离，就是这回执行的“物理相似度”。覆盖检查升级为 `α_S(a) ≥ θ_cov ∧ W_imu(a) ≥ θ_w`。

**灵感 3（证书会过期 → 把验证变成迭代算子）**
直觉：静态证书在新环境里不是“对/错”而是“过没过期”。IMU 提供 100–1000 Hz 的连续观测，天然适合做**迭代验证的时钟**：每 `Δτ` 用新窗口更新证书，得到 `J_{k+1}=V(J_k, D_k)`。验证不是一次测试，而是一个以 IMU 频率驱动的收缩迭代，直到证书固定点 `J*=V(J*)` 或预算耗尽。

**灵感 4（迭代验证必须跑赢漂移 → 漂移竞速条件）**
直觉：IMU 的角随机游走（ARW）与零偏不稳定性（BI）使积分姿态误差随时间增长：随机游走约 `∝√t`，零偏约 `∝t`。迭代验证每次只能把不确定度压低一个因子。若验证频率太低，漂移累积会快于验证收缩——证书刚刷新就过期。于是从递推 `u_{k+1}=λu_k+gΔτ` 得到稳态误差 `u_∞=gΔτ/(1-λ)`，可部署条件 `u_∞≤ε*` 反解出**可行性不等式** `f_val ≥ g/(ε*(1-λ))`。这是整个方案能否成立的第一性条件，而不是工程调参。

**灵感 5（跨模态见证三角 → 定位“传感器坏了”还是“动作错了”）**
直觉：IMU 只观测本体，单独用它分不清“动作执行错”与“IMU 自身漂移/故障”。引入腿/编码器运动学 `x_K` 与视觉/接触 `x_V`，构成三个独立见证。三者两两残差一旦超阈值，证书立即失效；而**谁与另外两个不一致**就定位故障通道。这给第 54 轮的 `Explain` 增加了一个新的根因类别：`sensor_fault` vs `action_mismatch`。

**灵感 6（金字塔再叠加一层：惯性证据层）**
直觉：在 `𝕃`（鲁棒性）与 `𝔸`（动作空间）之上，加入 `𝕀` 惯性证据层：`𝕀_0` 物理运动极限、`𝕀_1` 技能惯性签名、`𝕀_2` 跨模态一致性、`𝕀_3` 证书新鲜度。跨层证书必须携带 `(ρ, A_cert, ς_S, W_imu, conf, t_J)`，形成“鲁棒性-动作-惯性证据”三证书体系。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（惯性运动签名）**
技能 S 的惯性签名 `ς_S = (μ_S, Σ_S)`，其中 `μ_S = E[φ_imu(W_S)]`，`φ_imu(W) = [f_dom, H_spectral, J_rms, σ_A(τ_1..τ_k), g_align]` 为 IMU 窗口特征；`Σ_S` 为多次执行的特征协方差。`ς_S` 是技能在物理运动空间中的指纹。

**定义 122（惯性见证度）**
执行 exec 对技能 S 的惯性见证度
`W_imu(exec,S) = exp(-½ (φ_imu(exec)-μ_S)^T Σ_S^+ (φ_imu(exec)-μ_S)) ∈ (0,1]`。
当 `W_imu ≥ θ_w` 时称执行“物理匹配”。证书证据项必须含 `W_imu`。

**定义 123（漂移时域与证书新鲜度）**
设 IMU 噪声参数为 `(ARW, BI, RRW)`，则姿态/速度积分误差 `ε(t) ≤ c_1·ARW·√t + c_2·BI·t + c_3·RRW·t^{3/2}`。定义漂移时域 `τ_drift(ε*) = inf{t: ε(t) ≥ ε*}`。证书 `J` 于 `t_J` 签发，其有效时域
`h(J) = min(τ_valid, τ_drift(ε*))`，
新鲜度 `conf(J,t) = conf_0·exp(-(t-t_J)/h(J))`。当 `conf < conf_min` 时证书“过期”，禁止继续部署。

**定义 124（迭代验证算子）**
`V: (J_k, D_k) → J_{k+1}`，其中 `D_k` 为 IMU 窗口及跨模态观测。要求：
(a) **收缩性**：在证书度量 `d` 下 `d(V(J),V(J')) ≤ λ·d(J,J')`，`0<λ<1`；
(b) **见证单调性**：`W_imu(J_{k+1}) ≥ W_imu(J_k) - η_k`，`η_k` 可积且趋 0；
(c) **预算性**：迭代次数 ≤ N 或耗时 ≤ τ_budget。
固定点 `J* = V(J*)` 为可部署证书；带漂移时跟踪误差满足 `d(J_k,J*) ≤ λ^k d(J_0,J*) + gΔτ/(1-λ)`。

**定义 125（跨模态见证三角）**
三路运动估计 `x_I`（IMU 预积分）、`x_K`（腿/编码器运动学）、`x_V`（视觉/接触）。一致性残差 `r_IK=||x_I-x_K||`，`r_IV, r_KV` 同理。若 `max(r) > θ_r`，证书失效。故障定位：若恰有两对残差超阈值、第三对正常，则“异类”通道为故障源（`sensor_fault`）；否则判为 `action_mismatch`。这使 `Explain` 能区分“传感器坏”与“动作错”。

**定义 126（惯性鲁棒性维度）**
在第 53 轮维度集 `𝔇_ρ` 上增加 `d_imu=(ARW,BI,RRW)`，鲁棒性谱扩展为 `ρ ∪ {ρ_imu}`。`ρ_imu(d_imu)` 表示使用该噪声参数注入后技能仍满足稳定性阈值的概率。预失效余量 `m_imu = inf{t: ||x_I(t)-x_ref(t)||>ε} - t_now`。

**定义 127（新鲜度契约）**
云边契约 `C_ce` 增加 `(τ_valid, h_conf, f_val, checkpoint)`：边端必须以 `f_val ≥ max(1/τ_valid, g/(ε*(1-λ)))` 重验证；若任务时长 `T_task > h(J)`，云端必须把计划切分为若干段并在 `checkpoint` 安排重验证或重剖分，否则计划不可部署。

**定义 128（验证证书代数）**
验证序列 `V_{1:n}=V_n∘…∘V_1`。证书偏序 `J_{k+1} ⊑ J_k` 表示“前者不弱于后者”（约束更紧）。若每次 `V_k` sound 且收缩，则 `J_n` 在 `[t_J, t_J+h(J)]` 内 sound。组合 `J_{S1} ⊕ J_{S2}` 的新鲜度取 `min(h_1,h_2)`，见证度取 `min(W_1,W_2)`，签名取条件化签名的加权拼接。

## 2. 关键算法 伪代码

### IP-121 IMS（Inertial Motion Signature）

```python
def extract_signature(skill, imu_windows, eps=1e-6):
    feats = [imu_features(w) for w in imu_windows]
    mu = mean(feats)
    Sigma = cov(feats) + eps * I
    return Signature(mu=mu, Sigma_pinv=pinv(Sigma))

def imu_features(w):
    w = detrend(w)
    P = |rfft(w * hann(len(w)))| ** 2
    f_dom = argmax(P)
    H = entropy(P / sum(P))
    J = rms(diff(w, axis=0) / dt)
    allan = allan_deviation(w, taus)
    g = angle_between(mean(w.accel), [0, 0, 9.81])
    return concat([f_dom, H, J, allan, g])
```

### IP-122 IWV（Inertial Witness Validation）

```python
def inertial_witness(exec_window, sig, theta_w):
    phi = imu_features(exec_window)
    diff = phi - sig.mu
    m2 = diff @ sig.Sigma_pinv @ diff
    W = exp(-0.5 * m2)
    return (W >= theta_w, W)
```

### IP-123 CVL（Continuous Validation Loop）

```python
def validate_loop(J0, imu_stream, V, lam, drift_rate, budgets):
    J = J0
    for k in range(budgets.N):
        now = imu_stream.time()
        if predicted_conf(J, now) < budgets.conf_min:
            return ('expired', J)                 # 漂移已吃掉新鲜度
        D = imu_stream.window(k)
        J_next = V(J, D)                          # 收缩更新 + 见证刷新
        if d(J_next, J) < budgets.tol and witness_gain(J_next, J) < budgets.eta:
            return ('fixed_point', J_next)        # 到达 J*
        J = J_next
        if (k + 1) * dt > budgets.tau:
            break
    return ('budget_exhausted', J)

def feasible(lam, f_val, g, eps_star):
    # 漂移-验证递推 u_{k+1}=lam*u_k+g*dt 的稳态 u_inf=g*dt/(1-lam)
    # 要求 u_inf <= eps_star  =>  f_val >= g / (eps_star*(1-lam))
    return f_val >= g / (eps_star * (1.0 - lam))
```

### IP-124 CMT（Cross-Modal Triangle）

```python
def cross_modal_check(xI, xK, xV, theta_r):
    r = {'IK': norm(xI - xK), 'IV': norm(xI - xV), 'KV': norm(xK - xV)}
    if max(r.values()) <= theta_r:
        return ('ok', r, None)
    big = {k for k, v in r.items() if v > theta_r}
    # 恰有两对超阈值 -> 公共通道是异类，定位为 sensor_fault
    if big == {'IK', 'IV'}:
        return ('sensor_fault', r, 'I')
    if big == {'IK', 'KV'}:
        return ('sensor_fault', r, 'K')
    if big == {'IV', 'KV'}:
        return ('sensor_fault', r, 'V')
    return ('action_mismatch', r, None)           # 三路全乱或模式不闭合
```

### IP-125 IRD（Inertial Robustness Dimension）

```python
def inertial_robustness(skill, allan_params, n_trials):
    ok = 0
    for _ in range(n_trials):
        noise = synthesize_imu_noise(allan_params)   # ARW / BI / RRW
        traj = rollout(skill, noise)
        ok += stable_within_horizon(traj, eps_star)
    return ok / n_trials

def pre_failure_margin(traj, ref, eps):
    for t, (x, xr) in enumerate(zip(traj, ref)):
        if norm(x - xr) > eps:
            return t * dt
    return inf
```

### IP-126 RVC（Revalidation Scheduling / Freshness Contract）

```python
def schedule_revalidation(J, T_task, g, lam, eps_star):
    interval = min(J.h, eps_star * (1.0 - lam) / g)   # 由漂移竞速条件反解
    checkpoints = arange(interval, T_task, interval).tolist()
    if J.h < T_task and not checkpoints:
        return ('reject', 'certificate_too_stale')
    return ('ok', checkpoints)
```

### IP-123 预积分加速（关键实现细节）

```python
# on-manifold IMU preintegration (Forster et al.)：验证算子复用增量因子，
# 参数（零偏/证书）更新时用一阶雅可比修正，而非重积分，O(1) per update
def preintegrate(imu_segment, bias):
    dR, dv, dp = I, 0, 0
    J_R, J_v, J_p = zeros_like(bias), zeros_like(bias), zeros_like(bias)
    for a, w in imu_segment:
        dR, dv, dp = propagate(dR, dv, dp, a, w, bias)
        J_R, J_v, J_p = propagate_jacobians(J_R, J_v, J_p, a, w, bias)
    return Preint(dR, dv, dp, J_R, J_v, J_p)

def correct(preint, d_bias):
    return first_order_correct(preint, d_bias)        # O(1) 更新证书参数
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IMS | O(|W|·log|W|) per window | O(|Σ|) | 签名可分性、条件化分桶 |
| IWV | O(|φ|² + |φ|) per exec | O(|φ|²) | 协方差非奇异/伪逆稳定 |
| CVL | O(N·(|V| + |W|)) | O(|J|·N) | λ-收缩、见证单调 |
| CMT | O(1) per window | O(1) | 至少两路独立可信 |
| IRD | O(n_trials·T) | O(T) | Allan 参数上界已知 |
| RVC | O(T_task/interval) | O(checkpoints) | 漂移竞速条件成立 |

**正确性定理（Inertial-Witnessed Iterative Validation Soundness）**
承接第 53–54 轮 (A22)–(A28)，新增：**(A29)** `φ_imu` 对技能可分：不同技能签名间 KL ≥ κ > 0；**(A30)** 验证算子 `V` 在证书度量下 λ-压缩且见证单调；**(A31)** 跨模态至少两路独立可信，且 IMU 噪声参数上界 `(ARW,BI,RRW)` 已知。则对固定点 `J*=V(J*)`，在其有效时域 `[t_J, t_J+h(J)]` 内：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(W_imu<θ_w) - P(conf<conf_min) - P(CMT≠ok)
```
且迭代误差 `d(J_k,J*) ≤ λ^k d(J_0,J*) + gΔτ/(1-λ)`，故 `N = ⌈log(tol/d_0)/log(1/λ)⌉` 步可达容差；可部署性要求 `f_val ≥ g/(ε*(1-λ))`。关键：**物理见证闭合了“声明-执行”缝隙**，**漂移竞速保证了刷新先于过期**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 签名受负载/地形干扰 | 高 | 条件化签名（按地形/负载分桶）+ 域适应 |
| 漂移时域估计偏乐观 | 高 | 在线 Allan 方差估计 + 保守置信下界 |
| 迭代验证震荡不收敛 | 中 | λ-收缩保证 + 阻尼 + 最大迭代 |
| 跨模态共模故障 | 高 | 至少三路异构 + 独立供电/时钟 |

## 6. 本轮最大风险

**一句话**：IMU 见证 + 迭代验证把“动作对齐”从声明式承诺升级为物理事实，并让证书具备漂移感知的时效性，但整套 soundness 压在一个乐观假设上——**能够稳定地从 IMU 窗口提取可分的技能签名并准确预估漂移时域**；一旦负载/地形改变签名或漂移被低估，验证会收敛到一个“物理见证通过却早已过期”的假固定点，故必须以 **条件化签名分桶 + 在线 Allan 估计的保守下界 + 跨模态见证三角** 三重护栏，宁可频繁重验证，绝不把“签名偶然匹配”当作物理对齐的充分证据。

| `τ_drift(ε*)` | 积分误差达到 `ε*` 的漂移时域 |
| `h(J)=min(τ_valid,τ_drift)` | 证书有效时域 |
| `conf(J,t)` | 证书新鲜度（指数衰减） |
| `V(J_k,D_k)` | 迭代验证算子，λ-压缩 |
| `J*=V(J*)` | 可部署证书固定点 |
| `x_I,x_K,x_V` | IMU 预积分 / 运动学 / 视觉三路运动估计 |
| `r_IK,r_IV,r_KV` | 跨模态一致性残差 |
| `ρ_imu(d_imu)` | 惯性鲁棒性维度概率 |
| `m_imu` | 预失效余量 |
| `f_val` | 重验证频率；`g` 漂移增长率；`λ` 压缩率 |

## 2. 关键算法 伪代码

### IP-121 IMS

```python
def extract_signature(skill, imu_windows, eps=1e-6):
    feats = [imu_features(w) for w in imu_windows]
    mu = mean(feats)
    Sigma = cov(feats) + eps * I
    return Signature(mu=mu, Sigma_pinv=pinv(Sigma))

def imu_features(w):
    w = detrend(w)
    P = |rfft(w * hann(len(w)))| ** 2
    return concat([argmax(P), entropy(P / sum(P)),
                   rms(diff(w, axis=0) / dt),
                   allan_deviation(w, taus),
                   angle_between(mean(w.accel), [0, 0, 9.81])])
```

### IP-122 IWV

```python
def inertial_witness(exec_window, sig, theta_w):
    phi = imu_features(exec_window)
    diff = phi - sig.mu
    W = exp(-0.5 * diff @ sig.Sigma_pinv @ diff)
    return (W >= theta_w, W)
```

### IP-123 CVL

```python
def validate_loop(J0, imu_stream, V, lam, budgets):
    J = J0
    for k in range(budgets.N):
        if predicted_conf(J, imu_stream.time()) < budgets.conf_min:
            return ('expired', J)
        J_next = V(J, imu_stream.window(k))
        if d(J_next, J) < budgets.tol and witness_gain(J_next, J) < budgets.eta:
            return ('fixed_point', J_next)
        J = J_next
        if (k + 1) * dt > budgets.tau:
            break
    return ('budget_exhausted', J)

def feasible(lam, f_val, g, eps_star):
    return f_val >= g / (eps_star * (1.0 - lam))
```

### IP-124 CMT

```python
def cross_modal_check(xI, xK, xV, theta_r):
    r = {'IK': norm(xI - xK), 'IV': norm(xI - xV), 'KV': norm(xK - xV)}
    if max(r.values()) <= theta_r:
        return ('ok', r, None)
    big = {k for k, v in r.items() if v > theta_r}
    if big == {'IK', 'IV'}:
        return ('sensor_fault', r, 'I')
    if big == {'IK', 'KV'}:
        return ('sensor_fault', r, 'K')
    if big == {'IV', 'KV'}:
        return ('sensor_fault', r, 'V')
    return ('action_mismatch', r, None)
```

### IP-125 IRD

```python
def inertial_robustness(skill, allan_params, n_trials):
    ok = sum(stable_within_horizon(rollout(skill, synthesize_imu_noise(allan_params)),
                                   eps_star)
             for _ in range(n_trials))
    return ok / n_trials

def pre_failure_margin(traj, ref, eps):
    return next((t * dt for t, (x, xr) in enumerate(zip(traj, ref))
                 if norm(x - xr) > eps), inf)
```

### IP-126 RVC

```python
def schedule_revalidation(J, T_task, g, lam, eps_star):
    interval = min(J.h, eps_star * (1.0 - lam) / g)
    checkpoints = arange(interval, T_task, interval).tolist()
    if J.h < T_task and not checkpoints:
        return ('reject', 'certificate_too_stale')
    return ('ok', checkpoints)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IMS | O(|W|·log|W|·|S|) | O(|S|·|Σ|) | 签名可分 AUC ≥ 0.95 |
| IWV | O(|φ|²) per exec | O(|φ|²) | 伪逆稳定、见证单调 |
| CVL | O(N·(|V|+|W|)) | O(|J|·N) | λ-收缩、固定点存在唯一 |
| CMT | O(1) per window | O(1) | 两路独立可信则定位 sound |
| IRD | O(n_trials·T) | O(T) | Allan 参数上界已知 |
| RVC | O(T_task/interval) | O(#checkpoints) | 漂移竞速条件成立 |

**正确性定理（Inertial-Witnessed Iterative Validation Soundness）**
承接第 53–54 轮 (A22)–(A28)，新增 **(A29)** `φ_imu` 技能可分（KL ≥ κ>0）；**(A30)** `V` λ-压缩且见证单调；**(A31)** 三路见证至少两路独立可信、IMU 噪声上界已知。则固定点 `J*` 在 `[t_J, t_J+h(J)]` 内：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(W_imu<θ_w) - P(conf<conf_min) - P(CMT≠ok)
```
迭代误差 `d(J_k,J*) ≤ λ^k d(J_0,J*) + gΔτ/(1-λ)`；`N=⌈log(tol/d_0)/log(1/λ)⌉` 步达容差；可部署要求 `f_val ≥ g/(ε*(1-λ))`。
关键：**物理见证闭合“声明-执行”缝隙**，**漂移竞速保证刷新先于过期**，**跨模态三角把见证失效归因到具体通道**。

## 6. 本轮最大风险

**一句话**：IMU 见证 + 迭代验证把“动作对齐”从声明式承诺升级为物理事实，并让证书具备漂移感知的时效性，但整套 soundness 压在一个乐观假设上——**能够稳定地从 IMU 窗口提取可分的技能签名并准确预估漂移时域**；一旦负载/地形改变签名或漂移被低估，验证会收敛到一个“物理见证通过却早已过期”的假固定点，故必须以 **条件化签名分桶 + 在线 Allan 估计的保守下界 + 跨模态见证三角** 三重护栏，宁可频繁重验证，绝不把“签名偶然匹配”当作物理对齐的充分证据。
