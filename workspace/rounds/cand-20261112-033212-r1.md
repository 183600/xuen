# 第 59 轮（承接第 58 轮「KG-SFT-UX」IP-139~144；灵感循环第 1 轮；本轮灵感：「腕部相机」×「运动学」）

> 第 58 轮把安全论证压在"结构化记忆"上：知识图谱同时驱动检索、OOD、微调、证据合成与心智预测，代价是共模故障。可它仍默认了一个更深的"实验室假设"——**观测者在系统之外，且各证据源的误差彼此独立**。真实平台是四足+机械臂的移动操作体：腕部相机装在末端，和关节编码器、手眼标定、工具几何共享同一条运动链；它看到的每一样东西，都先被这条链"搬运"过。于是第 57 轮 EV-xmodal 的"条件独立"不再天然成立：手眼标定的一处偏差，可以让"相机看到的接触点"和"编码器推算的接触点"**一起错到同一个地方**——两票看似一致，实则同源。更麻烦的是，零空间自运动虽能制造多基线视差，但固定手眼偏差会随相机坐标系一起转，多个视图仍可能一致地错。本轮两个灵感正是冲着这个盲区：**腕部相机**是因果上离接触最近、但视野最窄、来得最晚、运动最模糊的终端证据；**运动学**是机器人唯一"自己知道"的物理，它既能为观测者发可观测性证书，也能用零空间运动制造**不改变世界的多基线视差**，让机器人用自己的身体生成"第二意见"——但只能用来看穿世界、审计自身，不能用来给自己发通行证。核心命题由"结构化记忆守护的安全自适应"升级为 **"观测者可证、零空间可自证、终端只否决的实时证据承诺"**。

核心矛盾：
- **H41（共享运动链 vs 跨模态独立）**：腕眼与本体感觉共享基座、臂链、手眼与工具几何。一个固定手眼偏差会让两者一致地错在同一点；绕零空间移动相机时偏差随相机转动，多视图仍可自洽。此时"跨模态一致"只是"同一条链自洽"，不是"世界被独立验证"——第 57 轮 EV-xmodal 的独立性假设被结构性违反。
- **H42（终端近场 vs 及时授权）**：腕眼视野窄、景深浅、只在接触前几厘米看清，且伴随运动模糊与工具自遮挡。它天然是"太晚的证据"：能可靠地说"停"，不能可靠地说"走"。把终端证据当授权证据，等于用最后一瞥为整段不可逆接触背书。
- **H43（零空间自运动 vs 世界不变）**：多基线视差的前提是"自运动不扰动世界"。真实系统的柔性、线缆、惯性、摩擦会让零空间运动施加侧向力或微滑；一旦对象被改变，多视图就不是同一世界的多次采样，而是"边看边改"。
- **H44（观测者不确定 vs 世界不确定）**：运动学给"相机在哪"的高精度先验，但奇异位形、大杠杆、热漂移、标定老化会让它在特定区域失效。把观测者误差记成世界不确定性，会无谓加宽后验、浪费探针；把世界欺骗记成观测者误差，会去调标定而不去探针——两者都会让系统学到错误的教训。

## 0. 直觉与动机

**灵感 1（腕部相机 → 终端否决证据）**
直觉：腕部相机是装在工具上的显微镜。它因果上离接触最近（同一条链去碰），所以能看清将要接触的那一小块；但它只看一小块，而且只在接触前才看清。它的认识论角色因此不是"全局授权者"，而是**终端否决者**：可以收缩动作集合（减速、停、撤回、绕行），不能扩张动作集合。把它当"最后一瞥的授权"，就是把"局部看清"误当成"整段可控"。

**灵感 2（运动学 → 观测者证书，而非世界证书）**
直觉：观测是位姿的函数。正运动学告诉我们"相机在哪"以及这个"在哪"有多不确定。于是可以给每条观测附一张**观测者证书**：从关节编码器、基座里程计、手眼标定、工具几何传播来的协方差，加上该位姿对深度/法向的可观测性。奇异位形附近，小的编码器误差会被放大成大的笛卡尔误差；单视图没有公制深度；运动模糊毁掉视差。证书声明这条观测"能用于什么、不能用于什么"。这把"观测者不确定"从"世界不确定"里分离出来——前几轮把它们笼统压进一个 ρ_vis，导致该加宽世界时去加宽、该怀疑标定时去怀疑世界。

**灵感 3（零空间 → 不改变世界的多基线视差）**
直觉：冗余机械臂有自运动流形 ℳ_sm：保持工具/接触点不动的那些关节配置。沿它移动，腕眼就能在不移动世界的情况下，从多个**已知公制基线**看同一块表面。真实表面在已知视差下保持一致；镜面、透明层、贴纸/涂装造成的假表面不一致。因为基线来自正运动学，这个检验是**公制的**，不是"两张图看起来像"。这就是"用机器人自己的身体生成独立性"。但必须诚实：若零空间为 0 维、基线共线或深度 Fisher 信息不足，必须返回"不可观测"，绝不能返回"安全"；而且 NMP 只检测视角相关欺骗，检测不了随相机一起转的固定手眼偏差——那一类必须靠接触锚点。

**灵感 4（共享误差 → 独立性按溯源判定，而非按传感器名）**
直觉：两票只有在误差来自不同地方时才是两票。腕眼与编码器共享臂链与手眼变换；"不同传感器"不等于"独立证据"。于是把第 57 轮的 EV-xmodal 从"不同模态名"升级为"**误差溯源路径不相交**"：相机与编码器的误差路径若在共享节点汇合，它们的"一致"不构成新证据；但它们的"不一致"仍然有用——说明世界或模型至少有一个错了。共享误差一致不计票，共享误差分歧照样报警，这个不对称很关键。

**灵感 5（合流 → 证据门的不对称：疑免费，信昂贵）**
直觉：新增 EV-wrist（终端、仅否决）与 EV-kin（接触残差佐证）。硬规则是**负证据永远可作否决且不可被多数票覆盖；正证据永远不能靠腕眼授权不可逆接触**。这样腕部相机是**安全单调**的：无论它错得多离谱，最多让机器人更保守、更常停（可用性代价），不会让不可逆承诺的失效率上升——前提是否决被实现为动作集合的硬交集，且安全核（停/返航/最小退避）始终保留。把"更多证据"升级为"**证据的观测者证书 + 否决的单向性**"。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（运动学可观测性证书 KOC）** 配置 q∈R^n、基座位姿 x_b、手眼参数 θ_he、工具几何 θ_tool 定义链 T_wc = T_wb(x_b)·T_ba(q)·T_ae(q)·T_ec(θ_he)。令 η=(q,x_b,θ_he,θ_tool)，Σ_η=blkdiag(Σ_q,Σ_b,Σ_he,Σ_tool)。一阶传播 Σ_wc=J Σ_η J^T，J=∂T_wc/∂η。对局部表面参数 φ=(p,n,ρ)（位置、法向、逆深度），几何 Fisher 信息 I_geo(o;q)=J_geo^T Σ_wc^{-1} J_geo + I_img(o) + I_base(B)。深度可观测性由多视图基线 B=[b_1,…,b_m]（相机中心在垂直于视线平面上的投影）决定：I_ρ=Σ_k b_k^T Σ_k^{-1} b_k。可观测子空间 O(o)={u : u^T I_geo u ≥ β_obs}；证据质量
`ρ_kin(o)=λ_min(I_geo)/(λ_min(I_geo)+τ_obs) · g_blur · g_vis · 1/(1+κ(J))`，
其中 κ(J) 为运动学雅可比条件数（奇异位形惩罚），g_blur 由曝光×角速度给出，g_vis 为工具自遮挡/视场检查。证书 C_o=(O,ρ_kin,Σ_wc,q,scope)，scope⊆{depth,normal,in_plane,appearance,contact_pose} 声明该证据可被用于哪些判定。**O 之外或 scope 之外的几何量一律不得进入证据门**；单视图深度默认不可观测，除非显式声明尺度/结构光/双目。ID 证据以 ρ_kin 入账，OOD 证据只以证书给出的最坏方向入 P_fail。

**定义 146（零空间多基线视差 NMP）** 自运动流形 ℳ_sm(q_0)={q∈Q_free : FK_tool(q)=FK_tool(q_0) ∧ ||ΔF_contact(q)||≤ε_F}。视差计划 V={q_0,…,q_m}⊂ℳ_sm，每点驻留 T_dwell 抑制模糊，要求基线矩阵满足 λ_min(B^T Σ_cam^{-1} B)≥β_B 且基线非共线。对各视图三角化表面点 x̂_i 与法向 n̂_i、协方差 Σ_i，一致性检验 δ_ij=||x̂_i−x̂_j||²_{Σ_i+Σ_j}、ψ_ij=1−|n̂_i·n̂_j|。判定
`NMP(q_0)∈{verified, deceptive, chain_fault, unobservable, guard_abort}`：
- verified ⇔ ∀i<j: δ_ij≤χ²_{1−α} ∧ ψ_ij≤θ_n ∧ 基线可观测；
- 不一致时用留出视图判别：若残差能被位形相关偏差模型 r_ij≈Φ(q_i,q_j)δθ 解释（拟合显著且留出误差低）⇒ chain_fault；若残差随视角/材质变化、不能由位形偏差解释 ⇒ deceptive；
- nullity(q_0)=0 或基线退化 ⇒ unobservable（不是 safe）；
- 接触力护栏失败 ⇒ guard_abort，本次视差全部作废。
**世界不变引理**：若护栏成立，则 V 中所有视图是同一世界状态的采样，差异只来自观测者位姿；故一致性检验的是"世界+观测链"的联合一致性。**注意**：固定手眼偏差随相机坐标系旋转，可能对所有视图保持一致——NMP 检测不了它，必须由 KKR 的接触锚点检测。

**定义 147（运动链信任账本 HTL）** 误差溯源 DAG G_err=(V_err,E_err)，V_err={encoder,base_odom,hand_eye,tool_geom,image,surface,contact}，每条观测 o 携带从源到 o 的路径集 P(o)。定义运动学独立
`Indep(o_i,o_j) ⇔ P(o_i)∩P(o_j)=∅`，或共享节点已被独立证书压到 Σ≤Σ_cert（共享项可视为已知）。对每条变换 ℓ∈{base,arm,hand_eye,tool} 维护信任状态 τ_ℓ=(Σ_ℓ,age_ℓ,n_anchor_ℓ,drift_ℓ,ver_ℓ)：
- **膨胀（即时、单向）**：冲击/温漂标志、KKR 残差超界、NMP 位形相关不一致 ⇒ Σ_ℓ←Σ_ℓ⊕Δ；
- **收缩（缓慢、有界、需锚）**：n_anchor≥N_anchor ∧ 驻留 T_dwell ∧ 残差一致 ⇒ Σ_ℓ←shrink(Σ_ℓ,η)，η≤η_max/会话；无锚不收缩；
- **证据折价**：ρ_eff(o)=ρ_kin(o)·g(τ_{ℓ(o)})，g 随 Σ 单减；
- **独立性计票**：EV-xmodal 候选对 (i,j) 仅当 Indep(o_i,o_j) 才计两票；否则为共享误差一致，只按共享节点的已验证信息计权。
**单向引理**：Σ_ℓ 随时可膨胀，只能在有外生锚点且有界速率下收缩；信任只会"赢得慢、失去快"。

**定义 148（力觉-运动学对账 KKR）** 接触事件 c=(t_c,q(t_c),τ(t_c),x̂_cam,x̂_kin)，x̂_kin=FK_tool(q(t_c);θ̂_tool)，τ 为力/力矩。残差 r_c=x̂_cam−x̂_kin，协方差 Σ_c。累计接触建立线性化 r≈Hδθ+ε，δθ=(δθ_he,δθ_tool,…)，H 为激励矩阵。仅当 λ_min(H^T Σ^{-1} H)≥β_exc（持续激励）才更新：
`δθ̂=argmin ||Hδθ−r||²_{Σ^{-1}} s.t. ||δθ||≤Δ_θ`；
否则只检测不更新。若 ||r_c||²_{Σ_c} 超界 ⇒ 撤销受影响区域 EV-wrist、膨胀对应链节点、记入审计。**外生性**：接触由世界反作用力产生，不由相机自身产生，因此能检测 NMP 检测不到的固定手眼偏差。口诀：**相机提议、接触裁决、运动学记账**。

**定义 149（终端否决证据门 TVG）** 证据类：EV-wrist（终端、scope=当前 cell/grasp/step，须 NMP=verified 且链可信，只能否决）；EV-kin（接触残差在界内且工具几何已认证，只能 L1 佐证）；既有 EV-probe*/visit/margin/xmodal(L1)/human/ft/ux 保留。硬规则：
- (V1) EV-wrist 永不进入不可逆接触的必要证据集，只能 A_exec←A_exec∩Veto(e)；
- (V2) 负证据（NMP 不一致、链信任下降、KKR 超界）永远可作否决，且不可被其他正证据多数票覆盖；
- (V3) EV-xmodal 两票须过 Indep 溯源检验；共享误差一致不计新证据；
- (V4) 单次接触不得更新标定；须持续激励 + 有界信任域；
- (V5) 腕部证据不得提升 auth、不得减少佐证数 corrob*、不得缩短 τ_int。
**安全核**：A_core={安全停/返航/最小退避}⊆A_exec 恒成立；否决不得移除 A_core，否则直接触发安全停。

**定义 150（运动学验证的探-诺-演 KVX）** 每检查点：①KOC 对每条腕眼观测计算 (O,ρ_kin,scope)，丢弃 scope 外或 ρ_kin<ρ_min 的观测；②若判定涉及不可逆接触且当前只有 EV-wrist/EV-kin：尝试 NMP（nullity≥1 且护栏允许），否则安排物理探针；③终端检查：NMP∈{deceptive,chain_fault,unobservable} 或 ρ_kin<ρ_min ⇒ 否决→减速/撤回/绕行；④接触后 KKR：残差在界内且激励充分 ⇒ 有界更新 HTL，否则撤销 EV-wrist 并安排重标定；⑤承诺 ⇔ ∃g:R≤δ_f(g) ∧ 证据门过（不可逆：EV-probe*∨EV-margin 或 EV-kin+物理佐证）；否则在探针/视差/标定预算内按 VOI 悲观选下一步；⑥终止于 k_p+k_par+k_cal；预算耗尽→绕行→降档→L2 或安全停。

def koc_certificate(obs, q, chain, calib):          # IP-145: 观测者证书
    T, J = chain.fk_and_jac(q, calib)
    Sigma = J @ chain.cov(calib) @ J.T
    I_geo = fisher_geo(obs, T, Sigma)               # 含多视图基线项
    O = observable_subspace(I_geo, beta_obs)
    rho = lmin(I_geo) / (lmin(I_geo) + tau_obs)
    rho *= blur_gate(obs.exp, obs.omega) * vis_gate(obs, T) / (1 + cond(J))
    return Cert(scope=O, rho=rho, Sigma=Sigma, q=q)

def nullspace_parallax(q0, chain, guard, m):        # IP-146: 不改变世界的多视图
    if chain.nullity(q0) == 0: return Unobservable('no_self_motion')
    views = plan_nullspace_views(q0, chain, m)      # 非共线基线 + 驻留
    for q in views:
        if not guard.ok(q): return GuardAbort(q)    # 接触力/自碰撞/关节限位
    patches = [triangulate(capture(q), koc_certificate(capture(q), q, chain, calib))
               for q in views]
    if not observable_baselines(patches, beta_B):
        return Unobservable('degenerate_baseline')  # 绝不返回 safe
    if consistent(patches, alpha, theta_n):
        return Verified(patches)
    return classify_inconsistency(patches)          # deceptive vs chain_fault

def kinematic_gate(ev, A_exec, ledger, M):          # IP-149: 疑免费，信昂贵
    if ev.cls == 'EV-wrist':
        if not (ev.nmp == 'verified' and ledger.trusted(ev.chain)):
            return reject('wrist_unverified')
        return A_exec & ev.veto                     # 只能收缩，永不授权
    if ev.cls == 'EV-kin':
        if ev.residual > ev.bound or not M.tool.certified:
            return reject('kin_uncertified')
        return corroborate_only(ev, level='L1')
    if ev.cls == 'EV-xmodal':
        if not provenance_independent(ev.pair, ledger):
            return reject('shared_error_agreement')
    return legacy_gate(ev, A_exec)
```

## 3. 复杂度与正确性（要点）

**正确性定理（Kinematic-Verified Probe Soundness, KVPS 概要）**：在 A22–A45 上加
**(A46)** KOC：协方差传播与可观测性声明诚实，scope 外证据一律拒收；
**(A47)** NMP：远护栏成立时世界不变、基线公制且非退化，判定四态完备，"不可观测"绝不等于"安全"；
**(A48)** HTL：溯源 DAG 诚实、信任单向有界、Indep 只在误差路径不相交（或共享项已认证）时成立；
**(A49)** KKR：接触事件外生、仅在持续激励与信任域内更新、超界即撤销；

class KinematicObservabilityCertificate:
    def __init__(self, chain, calib, alpha=0.1):
        self.chain, self.calib, self.alpha = chain, calib, alpha

    def certify(self, obs, q):
        T, J = self.chain.fk_and_jac(q, self.calib)
        Sigma = J @ self.chain.cov(self.calib) @ J.T          # Σ_wc
        J_geo = self.chain.surface_jac(obs, T)                # 表面参数雅可比
        I_img = self.chain.image_fisher(obs)                  # 像素噪声
        I_base = self.chain.baseline_fisher(obs, self.calib)  # 多视图基线项
        I_geo = J_geo.T @ inv(Sigma) @ J_geo + I_img + I_base
        O = self.observable_subspace(I_geo, beta_obs)         # 特征值≥β_obs
        rho = lmin(I_geo) / (lmin(I_geo) + tau_obs)
        rho *= self.blur_gate(obs.exp, obs.omega)
        rho *= self.visibility_gate(obs, T)
        rho /= (1.0 + cond(J))                                # 奇异位形惩罚
        return Cert(O=O, rho=rho, Sigma=Sigma, q=q,
                    scope=self.scope_from(O), valid=(rho >= rho_min))

    def observable_subspace(self, I, beta):
        w, V = eigh(I)
        keep = w >= beta
        return V[:, keep]                                      # 方向性子空间

    def scope_from(self, O):
        return {k for k, u in GEOM_BASIS.items() if proj_energy(O, u) >= 0.9}
```

class KinematicTrustLedger:
    def __init__(self, chain):
        self.chain = chain
        self.tau = {l: Trust(Sigma0[l], age=0, n_anchor=0) for l in CHAIN_NODES}
        self.P = ProvenanceDAG()

    def inflate(self, nodes, delta, why):
        for l in nodes:
            self.tau[l].Sigma += delta                        # 即时、单向
            self.tau[l].drift = max(self.tau[l].drift, delta)
            self.audit.log('inflate', l, why)

    def deflate(self, nodes, eta, anchor_cert):
        for l in nodes:
            t = self.tau[l]
            if t.n_anchor < N_anchor or eta > eta_max:
                continue                                      # 无锚/超速不收缩
            t.Sigma = shrink(t.Sigma, eta)
            t.n_anchor += 1
            self.audit.log('deflate', l, eta, anchor_cert)

    def independent(self, oi, oj):
        return self.P.paths(oi).isdisjoint(self.P.paths(oj)) \
               or all(self.certified(l) for l in self.P.shared(oi, oj))

    def g(self, l):
        return 1.0 / (1.0 + trace(self.tau[l].Sigma) / trace_ref)

**正确性定理（Kinematic-Verified Probe Soundness, KVPS）**
假设 A22–A45（第 53–58 轮）成立；**(A46)** KOC：协方差传播与可观测性声明诚实，scope 外证据一律拒收，单视图深度不可观测；(**A47**) NMP：护栏成立时世界不变、基线公制且非退化，判定四态完备，"不可观测"绝不等于"安全"；(**A48**) HTL：溯源 DAG 诚实、信任单向有界、Indep 只在误差路径不相交（或共享项已认证）时成立；(**A49**) KKR：接触事件外生、仅在持续激励与信任域内更新、超界即撤销；(**A50**) TVG：否决为硬交集、负证据不可被多数票覆盖、安全核 A_core 恒在。则：

1. **否决单调性（核心）**：若 EV-wrist 仅以 `A_exec←A_exec∩Veto` 实现且 `A_core⊆A_exec` 恒成立，则对任何单调安全失效事件 `P_fail(A_exec∩Veto) ≤ P_fail(A_exec)`。腕部相机无论多错，都不能提高不可逆承诺的失效率，最多降低可用性。证明：交集只缩小被执行动作集合，失效事件关于执行集合单调上闭；安全核保证不会因否决而无安全动作可执行。
2. **可观测健全性**：深度 Fisher 信息不足时任何证书的 scope 都不含 depth；单视图不能被静默当作公制接触证据；零空间为 0/退化时返回 unobservable 并转物理探针。
3. **共享误差界**：EV-xmodal 若 Indep 不成立，关于世界的互信息增益不超过共享节点已认证的信息；第 57 轮界中的 δ_xm 项被"零新证据"替代，共享误差一致不能收紧承诺界。
4. **标定单向性**：HTL 的 Σ 在锚点之间非减，收缩有界且需外生锚；不存在"信任螺旋"。
5. **终止性**：KVX 在 k_p+k_par+k_cal 内终止于 {承诺, 绕行, L2 协商, 安全停}；视差计划与标定更新均有预算上界。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                   + δ_kin·1[EV-kin] + δ_kkr + δ_par)
         − P(链结构性故障未检出) − P(安全核不可用)
```

**注意式中没有 δ_wrist 的授权项**：腕眼不能授权，故不向安全界贡献新的失败项；它的错误只进入"中止率/可用性"而非"承诺失效率"。这正是本轮相对第 57/58 轮最重要的结构性改进——把"再加一个传感器"从"再加一个可能出错的正证据"变成"只加一个否决器"。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"用机器人自己的运动制造独立票"的幻觉——腕部相机与本体感觉共享同一条运动链，一个固定手眼偏差会随相机一起移动，使零空间多视图仍然一致地错；因此运动学只能产生**否决与标定审计**、永远不能为不可逆接触**授权**，一旦任何实现让 EV-wrist/EV-kin 进入必要证据集，共享误差就会变成一张伪造的安全证书。
