# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感驱动循环第 1 轮；本轮灵感：「参数高效微调」×「轨迹优化」）

> R73 用证据契约 EC、组合代数 CCA、热替换定理与 CPB 把「具身计量」做成了可组合、可审计的模块系统；R73 追加的 IP-302 又把证据因果图 ECG 与形态无关契约 MIC 接上。但 R73 仍把两件事当成**外生给定**：
> - **适配是静态且全有或全无的**。EC 与证书在部署前由 SEAL/conformal/RTA 一次定死；环境一旦漂移（新材质、新光照、换末端执行器、换场景统计），系统只有两个选择：**全模块重认证**（昂贵，认证成本 O(系统)）或**宣告 stub**（丢失模态）。R73 的在线自标定（定义 378）只更新一个标量 `u_calib`，并没有「受控、低维、可证的安全适配」这一层。**适配的自由度本身没有被计量，也没有被预算。**
> - **证书是快照，不是轨迹**。R73 的覆盖保证是逐步（per-step）conformal：对每步 t，`P(y_t ∈ C_t) ≥ 1−α`。但机器人执行的是长度 H 的轨迹；由联合界，整条轨迹全部覆盖的概率最坏只有 `1−Hα`，长任务下迅速空洞。更根本的是：动作会改变观测分布（R73 的 χ_R），使校准集与部署集**不可交换**。PVOP（定义 372）只做一步视角修正，ECG（IP-302）只管因果链完整性，二者都没有回答「**整条轨迹的证据质量与覆盖如何被证明**」。
>
> 本轮两个灵感正好补这两块：
> - **参数高效微调** → **LREA（Low-Rank Evidence Adapter）**：冻结已认证的计量主干 θ0，只在声明的低维子空间 S 内学习低秩证据增量 `Δθ = Π_S(BA)`，不变坐标 I（否决集/有效域/阈值）严格不可动。把**秩 r、谱范数 ρ、支持维数**变成一等认证预算；证书分解为 `J_PACT = J_core ⊗ J_adapt ⊗ J_traj ⊗ J_comp`，认证成本从 O(系统) 降为 O(r)。再配**非收缩地板**（适配器不得单方面把不确定度压到主干从未验证的水平）与**合并且审计、否则路由**的 ACA。
> - **轨迹优化** → **PEX-TO + TCM**：轨迹不只是「怎么走过去」，而是同时决定任务进展、累积证据质量与**适配器可辨识性**的外层决策变量。把**持续激励（persistent excitation）** `λ_min(G_H) ≥ ε_exc` 写成适配器可认证的**结构前提**，而不是正则项；用**覆盖检验鞅 / e-process** 给出轨迹级时间一致（anytime-valid）覆盖监控，并通过**动作条件可交换性 ACE** 把 χ_R 从「覆盖的敌人」变成「可局部恢复可交换性的条件」。
> - 二者相乘 → **PACT-RAS**（Parameter-efficient Adaptation with Certified Trajectories）：**参数高效的适配之所以安全，不是因为它改得少，而是因为它的改动落在被声明的子空间里、被独立校准、被激励到可辨识、并被轨迹级覆盖监控。**
>
> 核心命题转换：R73 问「证据计量能否成为可组合的契约」；本轮问——**当环境持续漂移、而系统必须在有限预算内自我修正时，「适配」本身能否成为一个带证书的、可被轨迹优化主动供给可辨识性的算子，使人只认证低维增量而不是重证整个世界？**

## 0. 直觉与动机

**灵感 1（参数高效微调 → 冻结主干 + 低秩证据增量 = 证书增量）**
直觉：LoRA 类方法真正有价值的不是「参数少」，而是**更新被约束在一个低维、可控的子空间**：冻结 `W0`，只学 `ΔW = BA`，秩 `r ≪ d`。把它照搬到证据计量系统，不是去微调机器人策略，而是微调**证据/校准映射**：已认证主干 θ0 保持冻结，适配器只修改声明过的可适配坐标 S（噪声尺度、校准温度、偏置、材质 logit），而否决指示、有效域、风险阈值等**不变坐标 I 严格不可动**。于是安全证明不必从零重做，只需认证「增量」：`J_core` 管主干，`J_adapt` 管 Δθ。但 PEFT 的已知病理也原样迁移过来，而且每一条都对应一个安全病理：(a) 低秩更新在子空间外仍有大影响 → **支持越界/过度自信**；(b) 多适配器合并互相干扰 → **证书相互污染**；(c) 用自己生成的数据继续训练 → **自确认坍缩**。所以 PEFT 提供的既是机制，也是**威胁模型**。

**灵感 2（轨迹优化 → 证据质量与可辨识性都是轨迹的泛函）**
直觉：轨迹优化（直接配点/MPC/iLQR）与单步规划的本质差别，是它在一个时间窗内联合决定状态、控制与约束余量。R73 已经有 χ_R：动作会调制噪声；但它只把 χ_R 用在一步 PVOP 上。把窗口拉长，轨迹同时决定三件事：(i) 累积证据质量（走到哪、看多久、以什么入射角）；(ii) 反作用预算的消耗路径；(iii) **任何适配器的可辨识性**。第三点是关键且常被忽略：低秩适配器要在子空间 S 上被辨识，轨迹产生的回归量 `φ_t` 必须张满 S；若轨迹从未激励某个方向，该方向的参数误差无界。**未激励的适配器不是「差一点的适配器」，而是「不可认证的适配器」。** 于是存在一条干净的二分：激励足够 ⇒ 适配器可认证；否则 ⇒ 只跑冻结主干（core-only）。轨迹优化器必须诚实地选择站在哪一边，并能为「探针动作」定价。

**灵感 3（时间一致覆盖 → 逐步 conformal 不组合，必须用过程证书）**
直觉：逐步 conformal 的 `1−α` 是**边际**保证；把它沿 H 步相乘/取并，最坏退化为 `1−Hα`。而且策略的动作依赖历史证据，测试分布随自身行为漂移，破坏可交换性。两条互补的修补：(i) **ACE（动作条件可交换性）**——把可交换性条件在上下文单元 `c=(v,m,g,模态状态)` 上；R73 的 χ_R 恰好提供了这个条件变量。只要单元内可交换，逐步条件覆盖仍成立，单元间漂移只需付**覆盖税**。(ii) **覆盖 e-process**——构造非负检验鞅 `M_t` 累积「覆盖是否低于 1−α」的证据，Ville 不等式给出 `P(∃t: M_t ≥ 1/δ) ≤ δ`，**无需可交换性**；一旦告警，轨迹证书失效、降级并重校准。这把覆盖从「部署前一次性断言」变成「沿轨迹被监控的过程」，也给出了一个原则性的停止/回退规则。

**灵感 4（适配器组合 → 正交合并或诚实路由）**
直觉：多个任务/环境适配器可以按 `Δθ = Σ_i Δθ_i` 合并，省推理成本；但交叉项 `B_i^T B_j` 造成干扰，旧任务性能退化（灾难性遗忘）。R73 的 CCA 已经给出了正确的模式：**PAR 只有在一致性审计通过时才允许缩窄，否则取保守上界**。适配器合并完全同构：**MERGE 只在干扰审计、秩预算、遗忘预算、跨任务 conformal 残差全部通过时合法；否则退化为 ROUTE（按上下文路由，各自持有自己的 J_adapt）**。秩不是免费资源，合并省下的推理成本必须用干扰/遗忘预算来支付。这样「多任务适配」就不会变成「多任务证书互相担保」的循环论证。

**灵感 5（蒸馏纪律 → 新增两条可证伪主张 C4/C5）**
直觉：R73 的 C1–C3 覆盖「物理感知计量 / 反作用预算 / 契约模块化」。本轮只新增两条，且每条必须有最小基准与隔离消融：
- **C4（参数高效的可证适配）**：在支持受限的低秩适配器 + 差分证书分解 + 非收缩地板 + 轨迹覆盖 e-process 下，适配能达到接近全量重校准的任务增益，而**认证成本按 O(r) 而非 O(系统) 增长**，且**安全地板永不低于冻结主干**。反例检验：无约束适配、无地板适配、朴素记忆复用。
- **C5（激励感知的轨迹优化）**：联合优化任务/证据质量/持续激励能得到**可认证**的适配器且任务代价有界；而任务-only 轨迹优化会产生秩亏适配器，只能回退 core-only。反例检验：固定探针、任务-only、无激励约束。
每条绑定最小基准、预注册指标；不服务主张的组件降级为工程附件。**我们不主张低秩适配普适有效；我们主张一套能诚实检测「它何时不适用」的协议。**

## 1. 形式化定义（增量：定义 383–398）

**定义 383（PACT-RAS 总览与七不变式）** PACT-RAS = (LREA, EC-A, J_PACT, TCM, ACE, PEX-TO, ACA, PACT-pipeline, MODGAUGE-RAS†)。七个不变式：
(i) **主干冻结**：适配期间 θ0 与其证书不被修改，适配只产生增量；
(ii) **支持受限**：`Δθ = Π_S(Δθ)`，且 `Π_I Δθ = 0`（否决/有效域/阈值等不变坐标严格不可动）；
(iii) **差分证书**：`J_PACT = J_core ⊗ J_adapt ⊗ J_traj ⊗ J_comp`，四者缺一不可；
(iv) **非自我收缩**：无独立跨模态审计时 `u_adapter ≥ u_floor = LCB(u_core)`；
(v) **激励可证**：`J_adapt` 仅在 `λ_min(G_H) ≥ ε_exc` 时有效，否则 core-only；
(vi) **时间一致覆盖**：轨迹证书由覆盖 e-process 监控，告警即降级、重校准；
(vii) **退化链扩展**：PACT(full) → core-only → module stub（R73 定义 381）→ R68，安全侧单调不减。

**定义 384（低秩证据适配器 LREA）** 给定已认证证据模块 `(EC, θ0, J0)`，适配器
`a = (S, I, B, A, r, ρ, D_a, cert_a)`：
- `S ⊆ Θ`：可适配子空间（声明为噪声尺度/温度/偏置/材质 logit 等可微坐标）；
- `I ⊆ Θ`：不变坐标，要求 `Π_I Δθ = 0`；
- `B ∈ R^{d×r}, A ∈ R^{r×k}`，`r ≤ r_max`；
- `Δθ = Π_S(BA)`，且 `||Δθ||_* ≤ ρ`（核范数/谱范数预算）；
- `D_a ⊆ D0`：有效域只能收缩不能扩张；
- `cert_a`：独立 SEAL-Adapter 校准报告、覆盖税记录、版本哈希。
适配后证据模型为 `p_{θ0+Δθ}(y|x)`。**适配器不是新模态，而是对既有模态的受控修正。**

**定义 385（适配器证据契约 EC-A）** `EC-A = EC ∪ (S, I, r, ρ, ε_exc, fallback_ref, merge_meta, seal_adapt)`。其中 `ε_exc` 为持续激励门槛，`fallback_ref` 指向冻结主干 θ0，`merge_meta` 声明可合并的适配器族与干扰上界。要求 `χ_R` 在 S 上与主干相容：`Π_S χ_R(g) ⊆ S`，否则动作调制会把证据推出支持域。

**定义 386（差分证书 J_PACT）** `J_PACT = J_core ⊗ J_adapt ⊗ J_traj ⊗ J_comp`。`J_adapt` 有效当且仅当：
- (A1) 支持性：`Δθ ∈ Π_S`，`Π_I Δθ = 0`，`D_a ⊆ D0`；
- (A2) 幅度：`||Δθ||_* ≤ ρ`；
- (A3) 激励：`λ_min(G_H) ≥ ε_exc`（定义 390/391）；
- (A4) 独立校准：SEAL-Adapter 覆盖率 `≥ 1−α_a`，且 `α_eff = α_a + δ_drift`（定义 389）；
- (A5) 非收缩：`u_adapter ≥ u_floor`（定义 387），除非独立跨模态 PAR 审计通过；
- (A6) 漂移：训练/部署上下文 `TV ≤ δ_drift`，超界触发重认证。
`J_traj` 有效当且仅当覆盖 e-process 未告警（定义 388）。**注意 (A1)+(A5) 是安全侧的关键：适配器可以变「更准」，但不可以变「更敢」。**

**定义 387（不确定度地板与非自我收缩）** 令 `u_floor(c) = LCB_{1−β}(u_core(c))` 为冻结主干在上下文 c 下的单侧下置信界。若适配器输出 `u_a < u_floor`，则必须提交独立跨模态一致性审计（CCA PAR，校准于 SEAL）；否则裁剪 `u_a ← u_floor` 并记录 `OVERCONF` 事件。理由：低秩适配最危险的失效不是「变得不准」，而是「**变得过度自信**」——它把不确定度压到主干从未验证过的水平，让下游 λ 与轨迹优化误以为世界变简单了，从而主动走进适配器最不可靠的区域。

**定义 388（轨迹覆盖证书 TCM）** 轨迹 `τ = (g_0,…,g_{H−1})`，每步覆盖指示 `I_t = 1[y_t ∈ C_t]`。在零假设 `H0: E[I_t | F_{t−1}] ≥ 1−α` 下，定义覆盖检验鞅
`M_t = Π_{s=1}^t (1 − λ_s (I_s − (1−α)))`，`λ_s ∈ [0, 1/α]` 且 `F_{s−1}`-可预测。
则 `M_t ≥ 0` 且 `E[M_t] ≤ 1`；由 Ville 不等式，`P(∃t: M_t ≥ 1/δ) ≤ δ`。告警 ⇒ 该轨迹证书失效，立即降级 core-only 并触发重校准。**覆盖从静态属性变成沿轨迹演化、可被监控与拒绝的过程。**

**定义 389（动作条件可交换性 ACE 与覆盖税）** 上下文单元 `c = (v, m, g, 模态状态)`。ACE：在每个单元 c 内，部署评分与 SEAL 校准评分的条件分布可交换。若 ACE 成立，则 `E[I_t | c_t] ≥ 1−α`（逐步条件覆盖）；若单元间存在 TV 漂移 `δ(c)`，则覆盖下界退化为 `1−α−δ(c)`（conformal 的 TV 鲁棒性）。轨迹证书取 `α_eff = α + sup_c δ(c)`。**χ_R 不是覆盖的敌人：只要把条件放在动作上，可交换性可以在单元内局部恢复；真正的敌人是未声明的上下文漂移。**

**定义 390（持续激励轨迹优化 PEX-TO）** 令 `φ_t = φ(x_t, g_t) ∈ R^r` 为适配器特征（对 Δθ 的回归量），`G_H = Σ_{t=0}^{H−1} φ_t φ_t^T`。求解
`τ* = argmin_τ [ −Σ_t Progress + λ_r Σ_t risk(E_t) + λ_u Σ_t E[u^{next}] + λ_c Σ_t c_reflex + λ_e · PriceExc(τ) ]`
s.t. REG 时序契约、`Ω_safe`、ΣREFLEX 预算、`λ_min(G_H) ≥ ε_exc`、`rank(Δθ) ≤ r_max`。
当任务最优轨迹不满足激励约束时，优化器进入 **probe 模式**：注入最小能量探针动作使 `λ_min` 达标；若仍不达标，则**诚实地放弃适配**（core-only）。`PriceExc(τ)` = 为激励而牺牲的任务进展 + 额外反作用成本。

**定义 391（激励证书与可辨识性门槛）** 在线性化证据模型 `y_t ≈ φ_t^T Δθ + ξ_t`（`ξ_t` 次高斯，方差 σ²）下，最小二乘误差协方差 `≈ σ² G_H^{-1}`。若 `λ_min(G_H) ≥ σ² r / ρ²`，则最坏方向适配误差 `≤ ρ`，`J_adapt` 可签；若 `λ_min(G_H) = 0`，存在零信息方向，误差无界，`J_adapt` 无效。故**适配器可认证的结构条件是「轨迹在适配器子空间上持续激励」**——激励不是正则项，而是证书前提。

**定义 392（适配器组合代数 ACA）** 三个算子：
- **STACK（并存）**：`Δθ = Σ_i Δθ_i` 但不共享参数，按上下文选择；各适配器独立证书，推理成本相加。
- **MERGE（合并）**：`J_merge` 有效当且仅当秩预算 `Σ_i r_i ≤ R_max`、干扰审计 `max_{i≠j} ||B_i^T B_j|| / (||B_i|| ||B_j||) ≤ ρ_int`、遗忘预算 `Forget ≤ B_forget`、SEAL 跨任务残差在 conformal 集内；否则拒绝合并，退化为 STACK/ROUTE。
- **ROUTE（路由）**：`c ↦ i(c)`；切换需满足 ζ-switching 稳定性（切换瞬态不破坏 `Ω_safe`），每个分支携带自己的 `J_adapt`。
与 CCA 的 PAR 同构：**只有审计通过才允许合并（缩窄），否则保守分离。**

**定义 393（适配器降级链）** `PACT(full) → core-only（丢弃 Δθ，θ0 证书仍有效）→ module stub（定义 381）→ R68`。任一层失效只降一级，安全侧单调不减；适配器失效**不可能**把系统带到比冻结主干更差的证据状态。

**定义 394（漂移与秩饱和监控）** 监控三个量：(i) 子空间外残差 `r_out = ||(I−Π_S)(∇_θ log p)||`；(ii) 覆盖 e-process `M_t`；(iii) 滑窗激励 `λ_min(G_{H,window})`。`r_out` 超阈值 ⇒ 真实变化超出低秩支持域（**秩饱和**），必须扩秩/重认证或回退；`M_t` 告警 ⇒ 覆盖失效；`λ_min` 衰减 ⇒ 当前轨迹不再能辨识适配器。

**定义 395（适配器威胁面 AIC-ADAPT）** 五类：秩膨胀攻击（强制高秩耗尽预算）、激励欺骗（伪造回归量使 `λ_min` 虚高）、自确认毒化（用适配器自己的预测训练自己）、合并毒化（跨任务干扰使旧证书失效）、支持越界（把不变坐标偷渡进 S）。防线：支持投影硬校验、独立探针集、非收缩地板、干扰审计、秩/幅度硬上限、单源不定案（继承 E356/E357 原则）。

**定义 396（CPB 扩展：C4/C5）**
- **C4** ← (LREA, J_PACT, TCM, 非收缩地板, ACA) ← MB4 ← AB4（rank-r 适配 vs 全量重校准 vs 无适配 vs 无约束适配）← (适配后任务增益，认证成本比，覆盖率，安全违例率，过度自信率，遗忘量)；
- **C5** ← (PEX-TO, 激励证书, probe 定价) ← MB5 ← AB5（激励感知 TO vs 任务-only TO vs 固定探针）← (`λ_min`，适配误差，回退率，任务代价，探针开销)。
非绑定组件 = 工程附件，不入 MReg、不进正文。

**定义 397（PACT 结构上限）** 每适配器 `r ≤ 8`，总秩 `Σ r_i ≤ R_max ≤ 24`，`||Δθ||_* ≤ ρ_max`，支持维数 `≤ 256`，轨迹窗 `H ≤ 32`，e-process 状态 `O(1)`，适配器数 `≤ 8`，组合深度 `≤ 4`——全部为运行时可审计的预算/图性质（延续定义 377 的结构上限思想）。

**定义 398（MBench 扩展 MB4/MB5）** MB4（适配：换材质/换光照/换末端执行器的小样本适配，≤1h 单卡可复现）；MB5（激励轨迹：同一任务在不同激励约束下的适配可辨识性与安全，≤2h 单卡可复现）。预注册脚本 + 固定种子 + 密封保持集 SEAL-ADAPT / SEAL-EXC。

## 2. 关键算法骨架

```python
# IP-303 LREA：低秩证据适配器
@dataclass(frozen=True)
class LREA:
    core: EvidenceModule                 # θ0 + J_core（冻结）
    support: SupportProjector             # Π_S
    invariants: InvariantMask             # Π_I：否决/域/阈值不可动
    r: int; rho: float; eps_exc: float

def fit_lrea(core, support, invariants, batch, r, rho):
    B, A = fit_low_rank(core.features(batch), r)     # 只拟合增量
    delta = support.project(B @ A)
    assert invariants.masked_norm(delta) == 0         # (A1) 硬校验
    assert nuclear_norm(delta) <= rho                 # (A2)
    return delta, B, A

# IP-304 差分证书：只认证增量，不重证主干
def certify_pact(core, adapter, traj, seal):
    d = adapter.delta
    if not (adapter.support.contains(d) and adapter.invariants.masked_norm(d) == 0): return None
    if nuclear_norm(d) > adapter.rho: return None
    if lambda_min(traj.G_H) < adapter.eps_exc: return None          # (A3) 激励
    if seal.adapter_coverage(d) < 1 - alpha_eff(seal, traj): return None  # (A4)
    if expected_u(core, d) < u_floor(core) and not seal.cross_modal_audit(d):
        d = clip_uncertainty(d, floor=u_floor(core))                 # (A5) OVERCONF
    return J_PACT(core.cert, adapter_cert(d), traj.cert, MReg.comp_cert)

# IP-305 TCM：覆盖 e-process（O(1)/步）
class CoverageEProcess:
    def __init__(self, alpha, delta_alarm, lam):
        self.p0 = 1 - alpha
        self.lam = min(max(lam, 0.0), 1.0 / alpha)   # 保证因子非负
        self.logM = 0.0
        self.bound = math.log(1.0 / delta_alarm)
    def update(self, covered: bool):
        x = float(covered) - self.p0
        self.logM += math.log(max(1.0 - self.lam * x, 1e-12))
        return self.logM < self.bound                  # False ⇒ 告警、降级

# IP-306 PEX-TO：任务 × 证据质量 × 激励 × 反作用联合优化
def pex_to(state, mods, adapter, budget, H):
    def objective(tau):
        prog = sum(task_progress(state, g) for g in tau)
        risk = sum(comp_risk(state, g, mods) for g in tau)
        une  = sum(expected_u_next(state, g, mods) for g in tau)   # χ_R 解析
        refl = sum(sigmareflex_cost(state, g, mods) for g in tau)
        return -prog + lam_r*risk + lam_u*une + lam_c*refl + lam_e*price_exc(tau)
    cons = [reg_timing, omega_safe, sigma_budget,
            excitation_constraint(adapter, eps=adapter.eps_exc)]
    tau = solve_nlp(objective, cons, H)                # iLQR/SQP，热启动
    if lambda_min(gramian(tau, adapter)) < adapter.eps_exc:
        tau = probe_augment(tau, adapter)              # 最小探针
        if lambda_min(gramian(tau, adapter)) < adapter.eps_exc:
            return tau, MODE_CORE_ONLY                 # 诚实放弃适配
    return tau, MODE_ADAPT

# IP-307 ACA：合并必须过审计，否则路由
def compose_adapters(adapters, mode, seal):
    if mode == 'STACK': return StackedAdapter(adapters, certs=[a.cert for a in adapters])
    if mode == 'MERGE':
        if sum(a.r for a in adapters) > R_MAX:          return route(adapters)
        if max_interference(adapters) > RHO_INT:        return route(adapters)
        if seal.forgetting(adapters) > B_FORGET:        return route(adapters)
        merged = merge_low_rank(adapters)
        if not seal.cross_task_conformal(merged):       return route(adapters)
        return merged
    if mode == 'ROUTE':
        return Router(adapters, switching_stable=True)

# IP-308 PACT 主闭环（复用 R73 三域）
def PACT_round(M, obs, audio, tac_frame, depth_img):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    tau, mode = pex_to(M.bse.snapshot(), M.mods, M.adapter, M.budget, H=16)  # IP-306
    J = certify_pact(M.dpe.core, M.adapter, tau, M.seal_adapt)               # IP-304
    if mode == MODE_ADAPT and J is not None:
        M.policy.set_adapter(M.adapter.delta)
    else:
        M.policy.drop_adapter()                          # core-only（定义 393）
    for g in tau:
        k, lam = M.control(g, M.snapshot.read_latest())
        covered = M.tcm.update(M.verify(k))              # IP-305 逐步覆盖
        if not covered:
            M.policy.drop_adapter(); M.recalibrate(); break
    M.monitor.update(d_ev, M.adapter, M.tcm)             # 漂移/秩饱和（定义 394）
    return k, lam, J
```

## 3. 推导

**引理 38（低秩适配的敏感度上界）** 设证据泛函 `f: Θ → E` 在 `θ0 + {δ∈S: ||δ||_* ≤ ρ}` 上 `L_S`-Lipschitz。则对 `Δθ = Π_S(BA)` 且 `||Δθ||_* ≤ ρ`，有 `||f(θ0+Δθ) − f(θ0)|| ≤ L_S ρ`。故 `J_core` 的保证最多损失可加余量 `L_S ρ`，`J_adapt` 只需认证增量而非整个模型。系：**「差分证书」不是近似，而是 Lipschitz 结构的直接推论。**

**引理 39（激励–可辨识性）** 对线性化模型 `y_t = φ_t^T Δθ + ξ_t`，误差协方差 `≈ σ² G_H^{-1}`。最坏方向误差 `≤ σ sqrt(r / λ_min(G_H))`。因此 `||Δθ̂ − Δθ*|| ≤ ρ` 的一个充分条件是 `λ_min(G_H) ≥ σ² r / ρ²`；若 `λ_min(G_H) = 0`，存在零信息方向，误差无界，`J_adapt` 不可签。系：**适配器的可认证性由轨迹的回归量张成性质决定，是轨迹优化可直接约束的量。**

**引理 40（轨迹覆盖 e-process）** 在 `H0: E[I_t|F_{t−1}] ≥ 1−α` 下，`X_t = I_t − (1−α)` 满足 `E[X_t|F_{t−1}] ≥ 0`；取 `λ_t ∈ [0,1/α]` 使 `1−λ_t X_t ≥ 0`，则 `M_t` 为非负超鞅且 `E[M_t] ≤ 1`。由 Ville 不等式，`P(∃t: M_t ≥ 1/δ) ≤ δ`。故轨迹级证书给出**时间一致**的误报控制，且不要求跨时间可交换。系：**逐步 conformal 的联合界空洞被 e-process 替换；告警即降级，形成可执行的停止规则。**

**引理 41（非收缩地板阻断自确认）** 若 `u_a < u_floor` 且无独立跨模态审计，则要么裁剪到 `u_floor`（放弃适配器声称的收益但保安全），要么 `J_adapt` 无效。因此适配器不能用自己的似然去降低不确定度；必须有另一模态/已知几何/独立探针确认。系：**这是对 PEFT「用自己生成数据继续训练」病理的安全版回答——自我预测不能成为降低自身不确定度的证据。**

**引理 42（合并干扰与遗忘上界）** 合并 `Δθ = Σ_i Δθ_i` 时，任务 j 的输出扰动满足 `||δ_j|| ≤ L·(Σ_{i≠j} ||B_i^T B_j||·||A_j|| + …)`；旧任务遗忘 `Forget_j ≤ L²·Σ_{i≠j} ||G_ij||² + o(ρ_int)`。因此若干扰归一化上界 `≤ ρ_int` 且秩预算满足，则 `J_merge` 可签；否则分离/路由。系：**合并省推理成本，但必须以干扰/遗忘预算支付；这是 CCA PAR 在适配器层的同构。**

**引理 43（激励代价的可摊销性）** 设探针段额外付出 `ΔProbe = ΔProg_probe + λ_c Δc_reflex`，适配后在剩余 `T−H` 步上每步期望不确定度下降 `Δu`。则净收益 `≥ (T−H)Δu − ΔProbe`。因此长时程任务值得激励，短时程任务应诚实选择 core-only。系：**给出一条可操作的、可被实验证伪的「何时探针」判据。**

**定理 30（PACT 严格包含 R73）** 取 `r = 0`（无适配）、`H = 1`（单步轨迹）、`δ = 1`（e-process 不告警）、`χ_R` 恒等组合，则 PACT 的七不变式退化为 R73 的五不变式与 ECG/MIC 扩展，退化链逐指令一致。故 R73 全部定理是 PACT 的特例；安全侧单调不减。

**定理 31（差分证书 ⇒ 轨迹安全）** 在 A1–A6、TCM 未告警、PEX 激励达标下，轨迹级物理风险满足 `risk ≤ ε_core + L_S ρ + ε_ident + ε_cov`，概率至少 `1−δ_alarm`。其中 `ε_ident` 由引理 39 的激励误差给出，`ε_cov` 由 ACE 覆盖税给出。证明由引理 38–41 与 R73 定理 28 组合。**证明重量落在「低秩支持假设」与「ACE 在上下文单元内成立」上——这正是下一节的风险。**

**定理 32（回退零级联）** 适配器失效/漂移/告警 ⇒ 丢弃 Δθ ⇒ core-only；因 θ0 冻结且已认证，安全 ≥ core；不影响其他模块；回退在一个控制周期内完成。把 R73 定理 29 的「模块级 stub 零级联」再向下扩展一级。

**定理 33（激励–或–回退二分）** 对任意轨迹 τ，要么 `λ_min(G_H) ≥ ε_exc` 且 `J_adapt` 可有效，要么 `J_adapt` 无效、管线只跑 core-only。不存在「未激励适配器进入控制域」的路径。证明：定义 386 的 (A3) 是控制域快照写入的硬前置条件（定义 390/391 的校验在计量域完成，控制域只读快照，沿用 R72 三域隔离）。

## 6. 本轮最大风险

**一句话**：PACT 的最大风险是**适配器与轨迹优化形成自我确认闭环**——轨迹优化会主动选择最能激励适配器、最能让低秩模型显得可辨识的运动，适配器又用这些被自己挑选的数据降低不确定度；当真实环境变化落在声明的低秩支持子空间之外时，`J_core`、`J_adapt`、`J_traj`、`J_comp` **全部有效**，覆盖 e-process 也不会告警（因为它在监控自己选择的上下文单元内的覆盖），系统会沿着一条每一步都合规的轨迹，**越来越自信地走进低秩模型最不可靠的区域**。

次级风险与缓解：
1. **低秩支持假设失效（真实漂移在 S 外）** → `r_out` 子空间外残差监控（定义 394）+ 秩饱和告警 + 扩秩/重认证/回退；C4 只主张「可证适配」，不主张「低秩普适」。
2. **ACE 在单元内也不成立（隐藏上下文变量）** → 覆盖税按最坏 TV 上界收取；e-process 告警即降级；隐藏变量审计（温度/振动/光照）作为独立 VETO 输入（延续 R73 次级风险 5）。
3. **激励欺骗/探针污染** → 独立探针集与 SEAL-EXC 密封保持；回归量来源追溯；秩/幅度硬上限。
4. **自确认毒化** → 非收缩地板（定义 387）+ 独立跨模态审计 + 适配器训练数据与评估数据严格分离。
5. **合并毒化/灾难性遗忘** → MERGE 干扰审计 + 遗忘预算 + 审计失败即 ROUTE（定义 392、引理 42）。
6. **PEX-TO 实时性** → H≤32 + 热启动 SQP + 20Hz 计量域；超时降级为单步 PVOP（R73 IP-299）。
7. **认证预算被适配器耗尽** → R_max、ρ_max、支持维数、适配器数全部硬上限（定义 397）+ 运行时审计。
8. **MBench 过拟合** → SEAL-ADAPT/SEAL-EXC + 预注册 + 三方复现（E411）；只认预注册指标。

# 第 74 轮产物 · 创新点清单 v5：PACT-RAS（Parameter-efficient Adaptation with Certified Trajectories for RAS：低秩证据适配 × 轨迹级覆盖证书 × 持续激励 × 适配器组合代数 × 差分认证；LREA×EC-A×J_PACT×TCM×ACE×PEX-TO×ACA×PACT-Pipeline）

> - **J_PACT**：差分证书 `J_core ⊗ J_adapt ⊗ J_traj ⊗ J_comp`；只认证增量，认证成本 O(r) 而非 O(系统)；
> - **TCM + ACE**：覆盖检验鞅给出轨迹级时间一致覆盖监控；动作条件可交换性把 χ_R 从「覆盖的敌人」变成「可局部恢复可交换性的条件」，并显式收取漂移覆盖税；
> - **PEX-TO**：把持续激励 `λ_min(G_H) ≥ ε_exc` 写成适配器可认证的结构前提，轨迹优化在任务、证据质量、反作用预算与激励之间联合求解；不满足即诚实回退 core-only；
> - **ACA**：多适配器 STACK/MERGE/ROUTE；合并必须通过干扰、遗忘与跨任务 conformal 审计，否则路由；
> - **非收缩地板**：适配器不得用自身似然把不确定度压到主干 LCB 以下，阻断「自确认坍缩」；
> - **CPB 扩展 C4/C5**：参数高效的可证适配 / 激励感知的轨迹优化，各绑定最小基准与隔离消融。
>
> 核心命题：**当环境持续漂移时，安全的自我修正不是「重证整个世界」，而是「认证一个被轨迹主动激励到可辨识、被独立校准、被时间一致覆盖监控的低维增量」；适配器可以变准，但不允许变敢。**
>
> IP 编号：IP-303~310（共 8 个）+ R73 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化（r=0,H=1,δ=1 ⇒ R73），安全侧只增不减，退化链逐指令等价。**

## 2. 形式化定义（要点版）

**定义 383（PACT-RAS 总览与七不变式）** 主干冻结 / 支持受限 / 差分证书 / 非自我收缩 / 激励可证 / 时间一致覆盖 / 退化链扩展（PACT→core-only→stub→R68）。

**定义 384（LREA）** `a=(S,I,B,A,r,ρ,D_a,cert_a)`；`Δθ=Π_S(BA)`；`Π_I Δθ=0`；`||Δθ||_*≤ρ`；`D_a⊆D0`。适配器不是新模态，是对既有模态的受控修正。

**定义 385（EC-A）** `EC-A = EC ∪ (S,I,r,ρ,ε_exc,fallback_ref,merge_meta,seal_adapt)`；要求 `Π_S χ_R(g) ⊆ S`，否则动作调制会推出支持域。

**定义 386（J_PACT）** 四元组合；`J_adapt` 有效 ⇔ A1 支持性 ∧ A2 幅度 ∧ A3 激励 ∧ A4 独立校准（含覆盖税）∧ A5 非收缩 ∧ A6 漂移；`J_traj` 有效 ⇔ e-process 未告警。

**定义 387（非收缩地板）** `u_a < u_floor(c)` 时，无独立跨模态审计则裁剪到地板并记录 OVERCONF；适配器不可用自身似然降低自身不确定度。

**定义 388（TCM）** 覆盖检验鞅 `M_t`；`H0` 下非负超鞅；Ville ⇒ 时间一致误报 ≤ δ；告警即轨迹证书失效、core-only、重校准。

**定义 389（ACE 与覆盖税）** 单元内条件可交换 ⇒ 逐步条件覆盖；单元间 TV 漂移 δ(c) ⇒ 覆盖下界 `1−α−δ(c)`；轨迹证书用 `α_eff=α+sup_c δ(c)`。

**定义 390（PEX-TO）** `argmin −Progress + λ_r risk + λ_u E[u^next] + λ_c c_reflex + λ_e PriceExc`；s.t. REG、Ω_safe、ΣREFLEX 预算、`λ_min(G_H)≥ε_exc`、秩上限。不满足激励则 probe，仍不满足则 core-only。

**定义 391（激励证书）** 线性化下误差 `≤ σ sqrt(r/λ_min(G_H))`；`λ_min ≥ σ²r/ρ²` ⇒ 误差 ≤ ρ 可签；`λ_min=0` ⇒ 不可签。激励是证书前提。

**定义 392（ACA）** STACK（并存，独立证书）/ MERGE（秩预算 ∧ 干扰审计 ∧ 遗忘预算 ∧ 跨任务 conformal，否则退 ROUTE）/ ROUTE（ζ-switching 稳定，分支各自持证）。

**定义 393（降级链）** `PACT → core-only → module stub → R68`；一次只降一级，安全单调不减。

**定义 394（漂移/秩饱和监控）** `r_out` 超阈值 ⇒ 扩秩/重认证/回退；`M_t` 告警 ⇒ 覆盖失效；滑窗 `λ_min` 衰减 ⇒ 当前轨迹不再可辨识。

**定义 395（AIC-ADAPT）** 秩膨胀 / 激励欺骗 / 自确认毒化 / 合并毒化 / 支持越界；防线：支持投影硬校验、独立探针、非收缩地板、干扰审计、硬上限、单源不定案。

**定义 396（CPB C4/C5）** C4 ← (LREA,J_PACT,TCM,NSG,ACA) ← MB4 ← AB4 ← (增益,认证成本比,覆盖率,安全违例,过度自信率,遗忘)；C5 ← (PEX-TO,激励证书,probe定价) ← MB5 ← AB5 ← (λ_min,适配误差,回退率,任务代价,探针开销)。

**定义 397（结构上限）** `r≤8`、`Σr_i≤24`、`ρ≤ρ_max`、支持维数≤256、`H≤32`、e-process 状态 O(1)、适配器数≤8、组合深度≤4。

**定义 398（MBench MB4/MB5）** MB4 适配（换材质/光照/末端执行器，≤1h）；MB5 激励轨迹（λ_min 扫描与安全，≤2h）；SEAL-ADAPT / SEAL-EXC 密封保持集 + 预注册 + 固定种子。

## 3. 关键算法伪代码

```python
# IP-303 LREA
@dataclass(frozen=True)
class LREA:
    core: EvidenceModule; support: SupportProjector
    invariants: InvariantMask; r: int; rho: float; eps_exc: float

def fit_lrea(core, support, invariants, batch, r, rho):
    B, A = fit_low_rank(core.features(batch), r)
    delta = support.project(B @ A)
    assert invariants.masked_norm(delta) == 0
    assert nuclear_norm(delta) <= rho
    return delta, B, A

# IP-304 差分证书
def certify_pact(core, adapter, traj, seal):
    d = adapter.delta
    if not (adapter.support.contains(d) and adapter.invariants.masked_norm(d) == 0): return None
    if nuclear_norm(d) > adapter.rho: return None
    if lambda_min(traj.G_H) < adapter.eps_exc: return None
    if seal.adapter_coverage(d) < 1 - alpha_eff(seal, traj): return None
    if expected_u(core, d) < u_floor(core) and not seal.cross_modal_audit(d):
        d = clip_uncertainty(d, floor=u_floor(core))              # OVERCONF
    return J_PACT(core.cert, adapter_cert(d), traj.cert, MReg.comp_cert)

# IP-305 TCM 覆盖 e-process
class CoverageEProcess:
    def __init__(self, alpha, delta_alarm, lam):
        self.p0 = 1 - alpha; self.lam = min(max(lam, 0.0), 1.0/alpha)
        self.logM = 0.0; self.bound = math.log(1.0/delta_alarm)
    def update(self, covered):
        x = float(covered) - self.p0
        self.logM += math.log(max(1.0 - self.lam*x, 1e-12))
        return self.logM < self.bound

# IP-307 PEX-TO
def pex_to(state, mods, adapter, budget, H):
    def objective(tau):
        return (-sum(task_progress(state, g) for g in tau)
                + lam_r*sum(comp_risk(state, g, mods) for g in tau)
                + lam_u*sum(expected_u_next(state, g, mods) for g in tau)
                + lam_c*sum(sigmareflex_cost(state, g, mods) for g in tau)
                + lam_e*price_exc(tau))
    tau = solve_nlp(objective,
                    [reg_timing, omega_safe, sigma_budget,
                     excitation_constraint(adapter, adapter.eps_exc)], H)
    if lambda_min(gramian(tau, adapter)) < adapter.eps_exc:
        tau = probe_augment(tau, adapter)
        if lambda_min(gramian(tau, adapter)) < adapter.eps_exc:
            return tau, MODE_CORE_ONLY
    return tau, MODE_ADAPT

# IP-308 ACA
def compose_adapters(adapters, mode, seal):
    if mode == 'STACK': return StackedAdapter(adapters)
    if mode == 'MERGE':
        if sum(a.r for a in adapters) > R_MAX:       return route(adapters)
        if max_interference(adapters) > RHO_INT:     return route(adapters)
        if seal.forgetting(adapters) > B_FORGET:     return route(adapters)
        merged = merge_low_rank(adapters)
        if not seal.cross_task_conformal(merged):    return route(adapters)
        return merged
    return Router(adapters, switching_stable=True)

# IP-309/310 PACT 主闭环
def PACT_round(M, obs, audio, tac_frame, depth_img):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    tau, mode = pex_to(M.bse.snapshot(), M.mods, M.adapter, M.budget, H=16)
    J = certify_pact(M.dpe.core, M.adapter, tau, M.seal_adapt)
    if mode == MODE_ADAPT and J is not None: M.policy.set_adapter(M.adapter.delta)
    else:                                    M.policy.drop_adapter()      # core-only
    for g in tau:
        k, lam = M.control(g, M.snapshot.read_latest())
        if not M.tcm.update(M.verify(k)):                 # 告警
            M.policy.drop_adapter(); M.recalibrate(); break
    M.monitor.update(d_ev, M.adapter, M.tcm)              # r_out / 秩饱和
    return k, lam, J
```

## 4. 推导

**引理 38（低秩敏感度上界）** 若证据泛函在 `θ0+{δ∈S:||δ||_*≤ρ}` 上 `L_S`-Lipschitz，则 `||f(θ0+Δθ)−f(θ0)|| ≤ L_S ρ`。⇒ 主干保证最多损失可加余量，差分证书只需认证增量。

**引理 39（激励–可辨识性）** 线性化模型误差协方差 `≈σ²G_H^{-1}`；最坏方向误差 `≤σ sqrt(r/λ_min(G_H))`；`λ_min ≥ σ²r/ρ²` ⇒ 误差 ≤ρ 可签；`λ_min=0` ⇒ 误差无界不可签。⇒ 适配器可认证性是轨迹性质。

**引理 40（轨迹覆盖 e-process）** `H0` 下 `E[I_t|F_{t−1}]≥1−α`，取 `λ_t∈[0,1/α]` 使因子非负，则 `M_t` 非负超鞅且 `E[M_t]≤1`；Ville ⇒ `P(∃t:M_t≥1/δ)≤δ`。⇒ 时间一致误报控制，不要求跨时可交换。

**引理 41（非收缩阻断自确认）** `u_a<u_floor` 且无独立审计 ⇒ 裁剪或证书无效。⇒ 适配器不能用自己的似然降低自身不确定度；PEFT 自训练病理的安全版回答。

**引理 42（合并干扰/遗忘上界）** 任务 j 扰动 `≤ L·Σ_{i≠j}||B_i^T B_j||·||A_j|| + …`；遗忘 `≤ L²Σ_{i≠j}||G_ij||² + o(ρ_int)`。⇒ 干扰/遗忘预算达标才可 MERGE。

**引理 43（激励代价可摊销）** 探针成本 `ΔProbe`，适配后每步不确定度下降 `Δu`，剩余 `T−H` 步 ⇒ 净收益 `≥(T−H)Δu−ΔProbe`。⇒ 长时程值得激励，短时程应 core-only。

**定理 30（PACT 严格包含 R73）** `r=0, H=1, δ=1, χ_R 恒等` ⇒ 七不变式退化为 R73 五不变式与 ECG/MIC 扩展，退化链逐指令一致；R73 全部定理为特例。

**定理 31（差分证书 ⇒ 轨迹安全）** 在 A1–A6、TCM 未告警、PEX 激励达标下，`risk ≤ ε_core + L_S ρ + ε_ident + ε_cov`，概率 `≥1−δ_alarm`。证明由引理 38–41 与 R73 定理 28 组合；重量落在「低秩支持假设」与「ACE 单元内成立」。

**定理 32（回退零级联）** 适配器失效/漂移/告警 ⇒ 丢弃 Δθ ⇒ core-only；θ0 冻结已认证 ⇒ 安全 ≥ core；一个控制周期内完成；扩展 R73 定理 29 一级。

**定理 33（激励–或–回退二分）** 任意轨迹要么 `λ_min(G_H)≥ε_exc` 且 `J_adapt` 可有效，要么 `J_adapt` 无效、只跑 core-only；不存在未激励适配器进入控制域的路径（定义 386(A3) 为控制域快照写入硬前置）。

| E412 C4 隔离消融 | 差分证书 vs 全量 vs 无地板 | 安全违例显著降（p<0.01,d≥0.5），成本降 >10× |
| E413 C5 隔离消融 | 激励感知 TO vs 任务-only vs 固定探针 | 可认证率与任务代价同时显著优 |
| E414 严格包含回归 | r=0,H=1,δ=1 退化 R73 | 与 R73/R72/R71/R68 逐指令差 = 0 |
| E415 主张包完整性 | C4/C5 各有最小可证伪实验 | 各有 MB+AB+预注册指标，无孤悬组件 |

## 7. 本轮最大风险

**一句话**：PACT 的最大风险是**适配器与轨迹优化形成自我确认闭环**——轨迹优化主动选择最能激励适配器、最能让低秩模型显得可辨识的运动，适配器又用这些被自己挑选的数据降低不确定度；当真实环境变化落在声明的低秩支持子空间之外时，`J_core`、`J_adapt`、`J_traj`、`J_comp` 全部有效，覆盖 e-process 也不会告警（它只在自选上下文单元内监控覆盖），系统会沿一条每一步都合规的轨迹，**越来越自信地走进低秩模型最不可靠的区域**。

次级风险与缓解：
1. **低秩支持假设失效** → `r_out` 监控 + 秩饱和告警 + 扩秩/重认证/回退；C4 只主张可证适配，不主张低秩普适。
2. **ACE 单元内不成立（隐藏变量）** → 最坏 TV 覆盖税 + e-process 告警即降级 + 环境级独立 VETO 输入。
3. **激励欺骗/探针污染** → 独立探针集 + SEAL-EXC 密封 + 回归量来源追溯 + 硬上限。
4. **自确认毒化** → 非收缩地板 + 独立跨模态审计 + 训练/评估数据严格分离。
5. **合并毒化/灾难性遗忘** → MERGE 干扰审计 + 遗忘预算 + 失败即 ROUTE。
6. **PEX-TO 实时性** → H≤32 + 热启动 SQP + 20Hz；超时降级为单步 PVOP。
7. **认证预算被适配器耗尽** → R_max/ρ_max/支持维数/适配器数硬上限 + 运行时审计。
8. **MBench 过拟合** → SEAL-ADAPT/SEAL-EXC + 预注册 + 三方复现；只认预注册指标。
