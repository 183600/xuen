# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；新一轮灵感循环第 1 轮；本轮灵感：「力矩控制」×「多端口部署」）

> 第 66 轮 RAS 把「被动故障闭环」升级为「主动意图闭环」，用面部表情捕获风险态度。但它所有的证书、认证前缀与风险缩放，**都停在指令层 τ_cmd**：`λ_risk·τ_cmd` 被假定能被执行器忠实地、无损地执行出来。而这个假定正是整条链条最薄弱的一环——真正作用在人身上的不是 τ_cmd，而是经过饱和、死区、摩擦、齿隙、速率限制、热降额与网络延迟之后的 τ_real。
>
> 本轮灵感的核心命题是：
>
> **把「指令层的风险证书」下沉为「力矩层的、可跨端口迁移的证书」：T-PORT（Torque-parametric Passivity-certified Orchestration for Robust Transfer，力矩参数化、无源认证的多端口迁移编排）。**
>
> T-PORT 追问的不再是「该发多大的指令」，而是「**这个端口能不能把这条指令真实地、无源地、可迁移地执行出来；换一个端口还成不成立**」。它把 RAS 的「情绪-风险」闭环，接到「力矩-端口」这最后一公里上。

## 0. 直觉与动机

**灵感 1（力矩控制 → 证书必须下沉到执行器）**
直觉：此前 VISTA/RAS 的安全保证本质上是「纸面上的」：它保证某个抽象安全域里的指令可行。但用户真正接触到的是 `τ_real = Φ_p(τ_cmd)`。执行器有饱和上限、Coulomb 死区、速率限制、齿隙、热降额、采样与网络延迟。把证书停在 τ_cmd 层，等于隐式假设 `Φ_p` 是恒等映射。力矩控制的核心教训是：**安全裕度必须定义在 τ_real 与能量流上，而不是指令上**。更尖锐地说，「把指令乘小一点就更安全」在死区附近是**假命题**——缩到静摩擦以下只会带来粘滑与失控的微动，而不是更安全。

**灵感 2（多端口部署 → 一份证书、N 个异构端口）**
直觉：真实落地从来不是「一台机器人、一次认证」，而是「一次认证、批量上线」。同一份 `k*` 证书会被复制到不同减速比、不同电机常数、不同摩擦、不同控制频率、不同网络端口的机器/边缘节点上。如果证书不能写成端口参数的函数，「复制」就是无声的越界。多端口部署因此要求证书**参数化**（`J(ξ)`）且**可迁移**（只在超出迁移半径时才重新认证 re-badge），而不是每台重跑一遍昂贵的语义推理。

**灵感 3（无源性 → 多端口天然可迁移的不变量）**
直觉：绝对力矩阈值不可迁移（每台 `τ_max` 不同）；但**无源性/能量裕度**是尺度无关且可组合的。只要每个端口维持能量罐 `μ_p ≥ 0`，多端口并联系统就稳定。这正好给「多端口部署」提供了一个可加的不变量：passivity margin 在并联下可加和。于是 T-PORT 选择「无源裕度」作为证书的 port-invariant core，而把绝对力矩阈值降级为端口实例化时的约束。

**灵感 4（合流 → T-PORT 六件套）**
1. **PDB Port Deployment Badge**：上线时用短时力矩啁啾（chirp）测端口指纹 `ξ̂` 与协方差 `Σ_ξ`；
2. **TCA Torque Contract Algebra**：把语义层的 `τ_cmd` 翻译成端口可行的「力矩合同」；
3. **PPO Port Passivity Observer**：每端口能量罐，维持 `μ_p ≥ 0`；
4. **CTC Certificate Transport Calculus**：把源端口证书迁移到目标端口，给出裕度退化界；
5. **PQO Port Quorum Orchestrator**：多端口取「第 q 小前缀」调度，端口掉线时单调收缩；
6. **HTA H_torque Attribution**：把饱和/死区/热降额/端口失配/抖动纳入故障假设。

**灵感 5（对 RAS/VISTA 的增量）**
- **λ_risk 不能乘完就完事**：新增死区守卫，`λ_eff = max(λ_risk, λ_min)`，低于 `λ_min` 时改为受控停止而非「更小的力矩」；
- **C-RAS → C-TPORT**：`k*_TP = min(k_VISTA, k_emotion, k_torque, k_port)`；
- **EFS → EFS-T**：故障假设集加入 T0..T5（饱和/死区/热降额/端口失配/延迟抖动/齿隙）；
- **J_RAS → J_TP**：证书增 `ξ_badge, Σ_ξ, μ_p, r_transport, quorum, aic_tp_ver`；
- **AIC-RAS → AIC-TP**：干扰集加 `ℰ_torque`（饱和、齿隙、热漂移、时钟抖动）与 `ℰ_port_mismatch`（错误标定/混装端口）。

## 1. 形式化定义（增量：定义 245–262）

- **定义 245（端口描述子）**：端口 p 由 `ξ_p = (τ_max, τ_min, k_t, g, b, τ_c, f_s, d, η_th, E_budget) ∈ Ξ` 描述：力矩上下限、电机常数、减速比、粘性摩擦、Coulomb 死区、采样率、延迟、热降额系数、能量预算。
- **定义 246（执行映射）**：`τ_real(t) = Φ_p(τ_cmd(·), ξ_p) = sat_{[τ_min,τ_max]}(k_t·g·τ_cmd(t-d)) - b·q̇ - τ_c·sgn(q̇)`，并叠加速率限制与齿隙；要求 `Φ_p` 在死区外非降。
- **定义 247（力矩安全裕度）**：`m_p(τ) = (τ_max^eff - |τ|)/τ_max^eff`，其中 `τ_max^eff = τ_max·η_th(T_joint)` 随结温热降额。
- **定义 248（端口无源裕度）**：能量罐 `μ_p(t) = E_p(0) + ∫_0^t (τ_real·q̇ - σ_p) dτ ≥ 0`，`σ_p` 为端口耗散；`μ_p < 0` 即端口失去无源性。
- **定义 249（力矩可行集）**：`T_feas(ξ) = {τ_cmd : m_p(Φ_p(τ_cmd,ξ)) ≥ ρ_min ∧ rate_ok ∧ μ_p ≥ 0}`。
- **定义 250（T-PORT 证书）**：`J_TP(ξ) = (J_sem, ξ_badge, Σ_ξ, μ_p, r_transport, T_feas_sig, quorum, aic_tp_ver)`；Valid ⇔ `Valid(J_sem) ∧ m_p ≥ ρ_min ∧ μ_p ≥ 0 ∧ ||ξ - ξ_badge||_{Σ_ξ^{-1}} ≤ r_transport ∧ quorum_ok`。
- **定义 251（T-PORT 认证前缀）**：`k*_TP(ξ) = max{k ≤ m : ∀s≤k, Φ_p(λ_eff(s)·τ_s, ξ) ∈ T_feas(ξ)}`。
- **定义 252（多端口/法定人数前缀）**：对端口集合 P、法定人数 q，`k*_P(q) = 第 q 小的 {k*_TP(ξ_p)}_{p∈P}`（`q=|P|` 时即 min）。
- **定义 253（证书迁移半径）**：`r_transport = sup{r : ||ξ-ξ̂|| ≤ r ⇒ 裕度退化 ≤ δ_budget}`，由执行映射与裕度的 Lipschitz 常数给出闭式上界。
- **定义 254（死区守卫）**：`λ_min(τ,ξ) = τ_c/|τ|`；若 `λ_risk < λ_min`，不得以「更小力矩」执行，而应转为受控停止（CONTROLLED_STOP）。
- **定义 255（端口徽章 probe）**：以小幅、可回零的啁啾激励估计 `(ξ̂, Σ_ξ)`，要求激励能量 `≤ E_badge` 且不越过 `ρ_min`。
- **定义 256（力矩-端口故障假设）**：`T = {T0 nominal, T1 saturation, T2 dead-zone, T3 thermal-derate, T4 port-mismatch, T5 delay-jitter}`；`ℋ_TP = ℋ_RAS × T`。
- **定义 257（无源并联组合）**：解耦端口 `μ_parallel = Σ_p μ_p`；带耦合矩阵 W 时 `μ_parallel = Σ_p μ_p - γ_c||W||`。
- **定义 258（部署可采纳性）**：`Admissible(P, q, J_TP) ⇔ |{p ∈ P : J_TP(ξ_p) valid}| ≥ q`。
- **定义 259（优雅降级单调性）**：任一端口失效后 `k*_P(t+1) ≤ k*_P(t)`；恢复执行前必须重新认证（re-badge）。
- **定义 260（热降额动力学）**：`η_th(T) = 1 - β_th·max(0, T - T_nom)`，T 由一阶热 RC 模型 `C_th·Ṫ = τ_real·q̇ - (T - T_amb)/R_th` 演化。
- **定义 261（端口失配检测）**：部署时若 `||ξ_observed - ξ_badge||_{Σ_ξ^{-1}} > r_transport`，判 `T4` 并拒绝该证书。
- **定义 262（端到端风险预算）**：`α_total = α_chunk + δ_fi + α_emotion + α_torque + α_port`。

## 2. 关键算法骨架

```python
class PortDeploymentBadge:
    """IP-234：上线时力矩啁啾，估计端口指纹 xi_hat 与协方差。"""
    def probe(self, port, T_chirp=0.3, f0=1.0, f1=40.0):
        u = chirp(T_chirp, f0, f1) * port.tau_badge_amp
        log = []
        for t in range(int(T_chirp * port.fs)):
            tau_r = port.command_and_read(u[t])
            log.append((u[t], tau_r, port.q, port.qdot))
        xi_hat = robust_ls(log, model='saturation_deadzone_delay')
        return xi_hat, covariance(log, xi_hat)


class TorqueContractAlgebra:
    """IP-235/241：力矩合同 + 死区守卫。"""
    def guarded_scale(self, tau_cmd, lam_risk, xi):
        if tau_cmd == 0.0:
            return 0.0, 'ZERO'
        lam_min = xi.tau_coulomb / abs(tau_cmd)
        if lam_risk >= lam_min:
            return lam_risk * tau_cmd, 'SCALED'
        return 0.0, 'CONTROLLED_STOP'        # 死区内不做「假缩放」

    def feasible(self, tau_cmd, xi, mu_p):
        tau_real = xi.phi(tau_cmd)
        return (xi.margin(tau_real) >= xi.rho_min
                and xi.rate_ok(tau_real)
                and mu_p >= 0.0)


class PortPassivityObserver:
    """IP-236：单端口能量罐。"""
    def update(self, p, tau_real, qdot, dt):
        p.E += (tau_real * qdot - p.sigma) * dt
        p.mu = p.E - p.mu0
        return p.mu >= 0.0


class CertificateTransport:
    """IP-237：证书迁移与迁移半径。"""
    def __init__(self, L_phi, L_m):
        self.L_phi, self.L_m = L_phi, L_m

    def radius(self, delta_budget):
        return delta_budget / (self.L_m * (self.L_phi + 1.0))

    def transport(self, J_src, xi_src, xi_dst):
        d = port_distance(xi_src, xi_dst)
        if d <= J_src.r_transport:
            return instantiate(J_src, xi_dst, margin_delta=self.L_m * d)
        return 'NEED_REBADGE'


class PortQuorumOrchestrator:
    """IP-238：多端口法定人数调度 + 单调降级。"""
    def dispatch(self, A, ports, q):
        prefix = []
        for p in ports:
            if not self.c_tport.cert_valid(p):
                continue
            prefix.append(self.c_tport.certified_prefix(A, p.xi, p.mu))
        if len(prefix) < q:
            return 0, 'QUORUM_LOST'
        prefix.sort()
        return prefix[q - 1], 'OK'           # 第 q 小

    def on_port_drop(self, prev_k):
        return min(prev_k)                   # 只减不增


def T_PORT_round(M, obs, ports, q):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    face_gate = M.er.recognize(img)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs.synthesize(rho, face_gate)
    lam_risk = M.efs.risk_scale(joint_post)

    for p in ports:
        if not p.badged:
            p.xi, p.Sigma = M.pdb.probe(p)
            p.badged = True

    tau_des = M.vista.pi_sigma.prefix_dispatch(A[:M.vista.m]) * lam_risk
    tau_guarded, mode = M.tca.guarded_scale(tau_des, lam_risk, ports[0].xi)
    if mode == 'CONTROLLED_STOP':
        return 0, 'CONTROLLED_STOP'

    k_q, status = M.pqo.dispatch(A, ports, q)
    if status != 'OK':
        return 0, 'QUORUM_LOST'

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_q])
    tau_real = ports[0].xi.phi(tau_cmd)
    mu_ok = M.ppo.update(ports[0], tau_real, ports[0].qdot, M.dt)
    return k_q, ('OK' if mu_ok else 'PASSIVITY_LOST')
```

## 3. 推导

**引理 11（守卫缩放的单调安全性）** 在死区外 `|τ| ≥ τ_c`、且 `Φ_p` 与 `m_p` 满足单调性时，对任意 `λ ∈ [λ_min, 1]` 有 `m_p(Φ_p(λτ)) ≥ m_p(Φ_p(τ))`；当 `λ < λ_min` 时，守卫返回受控停止，按定义落于 `T_feas`。因此守卫缩放不会降低安全裕度。**反例**：死区内无守卫的 `λτ` 会落入静摩擦，产生粘滑/不可预测微动，此时「更小的力矩更安全」不成立。

**引理 12（迁移的 Lipschitz 界）** 若 `||Φ_p(τ,ξ) - Φ_p(τ,ξ')|| ≤ L_Φ||ξ-ξ'||` 且 `|m_p(τ,ξ) - m_p(τ,ξ')| ≤ L_m||ξ-ξ'||`，则 `||ξ-ξ̂|| ≤ r` 时裕度退化 `≤ L_m(L_Φ+1)·r`。取 `r_transport = δ_budget / (L_m(L_Φ+1))` 即可保证迁移后仍满足裕度预算。

**定理 11（T-PORT 端到端可靠性）** 在 A92–A97（守卫缩放、无源能量罐、迁移半径、法定人数、故障归因扩展、实时分离）下，若执行法定人数的每个端口均 `J_TP` 有效且指令落于 `T_feas`，则
1. `P(|τ_real - τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_torque + α_port`；
2. `μ_p ≥ 0 ∧ ||ξ-ξ_badge|| ≤ r_transport ⇒ 执行轨迹保持无源`；
3. 端口掉线时 `k*_P` 单调不增，任何恢复必须先 re-badge。

**定理 12（多端口无源组合与法定人数）** 解耦端口并联系统无源当且仅当 `Σ_p μ_p ≥ 0`；对 q-法定人数调度，执行前缀 `k*_P(q)` 至少对 q 个端口安全；若端口独立，系统整体失效概率由 `{k*_TP(ξ_p)}` 的第 q 阶顺序统计量界定。带耦合 W 时需 `Σ_p μ_p ≥ γ_c||W||`。

**定理 13（迁移摊销）** 部署到 N 个端口、迁移半径 r、端口分布 D 时，期望 re-badge 次数为 `N·(1 - F_D(r))`；若用 k-medoids 选 `N_b` 个徽章中心，则期望 re-badge `≤ N·(1 - coverage)`。这给出了「安全裕度 `δ_budget` ↔ 复用率」的显式权衡：r 越大复用越高但裕度预算越紧。

## 6. 本轮最大风险

**一句话**：T-PORT 的全部可迁移性都压在「端口描述子 `ξ̂` 准确、且执行映射 `Φ_p` 在运行区域内对力矩单调」这两个假设上；一旦 Coulomb 死区、齿隙或热降额使 `Φ_p` 非单调，或徽章探测把摩擦/延迟估小，多端口迁移就会把「在 A 端口认证过的安全证书」错误地搬到 B 端口，而守卫缩放又可能把真实故障滑入受控停止或粘滑——于是证书看似处处有效，实则在最需要力矩的那台端口上失效。

## 2. 形式化定义（完整版）

**定义 245（端口描述子）** 端口 `p` 由 `ξ_p ∈ Ξ` 描述：力矩上下限、电机常数、减速比、粘性摩擦、Coulomb 死区、采样率、延迟、热降额系数、能量预算。

**定义 246（执行映射）** `τ_real(t) = sat_{[τ_min,τ_max]}(k_t·g·τ_cmd(t-d)) - b·q̇ - τ_c·sgn(q̇)`，叠加速率限制与齿隙；要求 `Φ_p` 在死区外非降。

**定义 247（力矩安全裕度）** `m_p(τ) = (τ_max^eff - |τ|)/τ_max^eff`，`τ_max^eff = τ_max·η_th(T_joint)`。

**定义 248（端口无源裕度）** `μ_p(t) = E_p(0) + ∫_0^t (τ_real·q̇ - σ_p) dτ ≥ 0`。

**定义 249（力矩可行集）** `T_feas(ξ) = {τ_cmd : m_p(Φ_p(τ_cmd,ξ)) ≥ ρ_min ∧ rate_ok ∧ μ_p ≥ 0}`。

**定义 250（T-PORT 证书）** `J_TP(ξ) = (J_sem, ξ_badge, Σ_ξ, μ_p, r_transport, T_feas_sig, quorum, aic_tp_ver)`；Valid ⇔ `Valid(J_sem) ∧ m_p ≥ ρ_min ∧ μ_p ≥ 0 ∧ ||ξ-ξ_badge||_{Σ_ξ^{-1}} ≤ r_transport ∧ quorum_ok`。

**定义 251（T-PORT 认证前缀）** `k*_TP(ξ) = max{k ≤ m : ∀s≤k, Φ_p(λ_eff(s)·τ_s, ξ) ∈ T_feas(ξ)}`。

**定义 252（多端口/法定人数前缀）** `k*_P(q) = 第 q 小的 {k*_TP(ξ_p)}_{p∈P}`。

**定义 253（证书迁移半径）** `r_transport = sup{r : ||ξ-ξ̂|| ≤ r ⇒ 裕度退化 ≤ δ_budget}`。

**定义 254（死区守卫）** `λ_min(τ,ξ) = τ_c/|τ|`；若 `λ_risk < λ_min`，转为 `CONTROLLED_STOP`，不以更小力矩执行。

**定义 255（端口徽章 probe）** 小幅、可回零的啁啾激励估计 `(ξ̂, Σ_ξ)`，激励能量 `≤ E_badge` 且不越 `ρ_min`。

**定义 256（力矩-端口故障假设）** `ℋ_TP = ℋ_RAS × T`，`T = {T0 nominal, T1 saturation, T2 dead-zone, T3 thermal-derate, T4 port-mismatch, T5 delay-jitter}`。

**定义 257（无源并联组合）** 解耦端口 `μ_parallel = Σ_p μ_p`；带耦合 `μ_parallel = Σ_p μ_p - γ_c||W||`。

**定义 258（部署可采纳性）** `Admissible(P,q,J_TP) ⇔ |{p : J_TP(ξ_p) valid}| ≥ q`。

**定义 259（优雅降级单调性）** 失效后 `k*_P(t+1) ≤ k*_P(t)`；恢复前必须 re-badge。

**定义 260（热降额动力学）** `η_th(T) = 1 - β_th·max(0, T - T_nom)`，`C_th·Ṫ = τ_real·q̇ - (T - T_amb)/R_th`。

**定义 261（端口失配检测）** `||ξ_observed - ξ_badge||_{Σ_ξ^{-1}} > r_transport ⇒ 判 T4 并拒绝证书`。

**定义 262（端到端风险预算）** `α_total = α_chunk + δ_fi + α_emotion + α_torque + α_port`。

```python
# IP-234 PDB
class PortDeploymentBadge:
    def probe(self, port, T_chirp=0.3, f0=1.0, f1=40.0):
        u = chirp(T_chirp, f0, f1) * port.tau_badge_amp
        log = [(u[t], port.command_and_read(u[t]), port.q, port.qdot)
               for t in range(int(T_chirp * port.fs))]
        xi_hat = robust_ls(log, model='saturation_deadzone_delay')
        return xi_hat, covariance(log, xi_hat)


# IP-235/241 TCA + 死区守卫
class TorqueContractAlgebra:
    def guarded_scale(self, tau_cmd, lam_risk, xi):
        if tau_cmd == 0.0:
            return 0.0, 'ZERO'
        lam_min = xi.tau_coulomb / abs(tau_cmd)
        if lam_risk >= lam_min:
            return lam_risk * tau_cmd, 'SCALED'
        return 0.0, 'CONTROLLED_STOP'

    def feasible(self, tau_cmd, xi, mu_p):
        tau_real = xi.phi(tau_cmd)
        return (xi.margin(tau_real) >= xi.rho_min
                and xi.rate_ok(tau_real) and mu_p >= 0.0)


# IP-236 PPO
class PortPassivityObserver:
    def update(self, p, tau_real, qdot, dt):
        p.E += (tau_real * qdot - p.sigma) * dt
        p.mu = p.E - p.mu0
        return p.mu >= 0.0


# IP-237 CTC
class CertificateTransport:
    def __init__(self, L_phi, L_m):
        self.L_phi, self.L_m = L_phi, L_m

    def radius(self, delta_budget):
        return delta_budget / (self.L_m * (self.L_phi + 1.0))

    def transport(self, J_src, xi_src, xi_dst):
        d = port_distance(xi_src, xi_dst)
        if d <= J_src.r_transport:
            return instantiate(J_src, xi_dst, margin_delta=self.L_m * d)
        return 'NEED_REBADGE'


# IP-238 PQO
class PortQuorumOrchestrator:
    def dispatch(self, A, ports, q):
        prefix = [self.c_tport.certified_prefix(A, p.xi, p.mu)
                  for p in ports if self.c_tport.cert_valid(p)]
        if len(prefix) < q:
            return 0, 'QUORUM_LOST'
        prefix.sort()
        return prefix[q - 1], 'OK'

    def on_port_drop(self, prev_k):
        return min(prev_k)


# IP-240 T-PORT 闭环
def T_PORT_round(M, obs, ports, q):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    face_gate = M.er.recognize(img)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs.synthesize(rho, face_gate)
    lam_risk = M.efs.risk_scale(joint_post)

    for p in ports:
        if not p.badged:
            p.xi, p.Sigma = M.pdb.probe(p)
            p.badged = True

    tau_des = M.vista.pi_sigma.prefix_dispatch(A[:M.vista.m]) * lam_risk
    tau_guarded, mode = M.tca.guarded_scale(tau_des, lam_risk, ports[0].xi)
    if mode == 'CONTROLLED_STOP':
        return 0, 'CONTROLLED_STOP'

    k_q, status = M.pqo.dispatch(A, ports, q)
    if status != 'OK':
        return 0, 'QUORUM_LOST'

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_q])
    tau_real = ports[0].xi.phi(tau_cmd)
    mu_ok = M.ppo.update(ports[0], tau_real, ports[0].qdot, M.dt)
    return k_q, ('OK' if mu_ok else 'PASSIVITY_LOST')
```

## 4. 推导

**引理 11（守卫缩放的单调安全性）** 死区外 `|τ| ≥ τ_c` 且 `Φ_p`、`m_p` 单调时，`λ ∈ [λ_min,1] ⇒ m_p(Φ_p(λτ)) ≥ m_p(Φ_p(τ))`；`λ < λ_min` 时守卫返回受控停止，落于 `T_feas`。故守卫缩放不降低安全裕度。反例：死区内无守卫缩放会进入静摩擦，产生粘滑/不可预测微动。

**引理 12（迁移的 Lipschitz 界）** 若 `||Φ_p(τ,ξ)-Φ_p(τ,ξ')|| ≤ L_Φ||ξ-ξ'||`、`|m_p(τ,ξ)-m_p(τ,ξ')| ≤ L_m||ξ-ξ'||`，则 `||ξ-ξ̂|| ≤ r` 时裕度退化 `≤ L_m(L_Φ+1)r`；取 `r_transport = δ_budget/(L_m(L_Φ+1))` 保证迁移后满足预算。

**定理 11（T-PORT 端到端可靠性）** 在 A92–A97 下，若执行法定人数端口均 `J_TP` 有效且指令落于 `T_feas`，则
1. `P(|τ_real-τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_torque+α_port`；
2. `μ_p ≥ 0 ∧ ||ξ-ξ_badge|| ≤ r_transport ⇒ 轨迹无源`；
3. 端口掉线时 `k*_P` 单调不增，恢复须 re-badge。

**定理 12（多端口无源组合与法定人数）** 解耦端口并联无源 ⇔ `Σ_p μ_p ≥ 0`；q-法定人数前缀对至少 q 个端口安全，独立端口下失效概率由第 q 阶顺序统计量界定；带耦合 W 需 `Σ_p μ_p ≥ γ_c||W||`。

**定理 13（迁移摊销）** 部署 N 端口、半径 r、分布 D 时，期望 re-badge `= N(1-F_D(r))`；用 k-medoids 选 `N_b` 徽章中心时期望 `≤ N(1-coverage)`。给出「裕度预算 δ_budget ↔ 复用率」的显式权衡。

## 6. 本轮最大风险

**一句话**：T-PORT 的全部可迁移性都压在「端口描述子 `ξ̂` 准确、且执行映射 `Φ_p` 在运行区域内对力矩单调」这两个假设上；一旦 Coulomb 死区、齿隙或热降额使 `Φ_p` 非单调，或徽章探测把摩擦/延迟估小，多端口迁移就会把「在 A 端口认证过的安全证书」错误地搬到 B 端口，而守卫缩放又可能把真实故障滑入受控停止或粘滑——于是证书看似处处有效，实则在最需要力矩的那台端口上失效。
