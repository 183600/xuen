## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（数字孪生 → 官方给的不是「仿真器」，而是「一台待校准的测量仪」）**
直觉：数字孪生的通常想象是「高保真虚拟副本，用来替代真机」。但本赛事实恰好相反：官方 sim 与真机同 DDS（F20），能读任务离散奖励（F20），这是稀缺的**离线可测性**；可它只覆盖 5 个原始场景（F26），还带三类校准 bug（F21），而视频世界模型连「动作→画面」的可控性都被质疑（F22）。所以真正的机会不是「造一个更逼真的仿真」，而是**把孪生当成测量仪去校准**：它的价值在「能反复跑完整 episode 并读步骤奖励」，不在「画面像不像」。校准后的孪生能把 I8 里最弱的逐帧代理（动作一致性）升级为**全 episode 成功/步骤分**，并给 I5 的合成示教一个物理可行性闸门。反直觉点：**最像真机的孪生（WMA-0）反而最不可信；最可信的孪生是最朴素的物理 sim + 一个数据驱动的残差动力学。**

严谨定义（本轮口径）：一个可用于**排序**的数字孪生是五元组 `T = (S, A, f_θ, R, C)`：`f_θ: S×A→S` 为动力学（物理 sim + 在 32k 遥操作上学到的残差修正），`R: S×A→ℝ` 为与官方得分点对齐的进度/奖励（F20 的 `get_step_reward_value` + F17 的得分点），`C` 为校准算子（修 F21 三类缺陷并最小化与真机轨迹的偏差）。称 `T` 在任务族 `F` 上「可用于排序」，当且仅当真机锚点上孪生 episode 收益与真机收益的 Spearman 相关 `ρ ≥ ρ*`（如 0.6）。**绝对分数不可信，只信排序。**

**灵感 2（持续学习 → 比赛本身是一个多轮持续学习流，敌人是遗忘而非漂移）**
直觉：单次计分 episode 内做在线学习是诚信红线（F24 且手册明确禁止），所以「持续学习」若理解成 test-time adaptation 就是违规。但 F23 给了另一条合法通道：**计分多任务 + 不计分单任务调试可反复发起**，加上 110 语料可分批入训——这构成一条**跨提交轮次的离线持续学习流**。真正的难点不是「学新东西」，而是「每并入一轮新数据/真机反馈，都不能把 32 任务基线学忘」。这恰好就是第 2 轮 I2 最大风险（孪生负迁移）在时间轴上的推广。反直觉点：**持续学习在本赛的核心指标是「遗忘量」而不是「新任务增益」；一个不遗忘的保守更新，比一个涨新任务但掉老任务的激进更新更值钱。**

严谨定义（本轮口径）：给定基础任务集 `B`（32 考题）、更新序列 `U_1,…,U_k`（每轮新数据 + 单任务调试反馈），持续学习器求 `θ_k` 在 `B` 上平均风险不升、同时吸收 `U`；约束：**所有梯度更新只发生在两次提交之间，计分 episode 内零更新**。遗忘度量 `F = (1/|B|) Σ_i max_{j<k}(R_i(θ_j) − R_i(θ_k))`（backward transfer 的负部），要求 `F ≤ ε`。

**两者统一（本轮结论）**：数字孪生是**经验生成器 + 离线裁判**，持续学习是**不遗忘的积分器**。孪生回答「新经验从哪来、怎么在真机预算外先筛」，持续学习回答「新经验怎么并入而不毁掉旧能力」。二者合起来，把第 2 轮的「数据引擎」从一次性离线管道升级为**带遗忘保护的闭环飞轮**——这正是官方 sim 自称支持的 RSI（F20）。本轮的胜负手从「造多少数据」转向「**能否在不忘掉 32 任务的前提下持续吸收新数据**」。

## 2. 对第 2 轮痛点的增量修订

- P2（泛化缺口）：孪生提供可控离线测试台 → 从「无法测量」升级为「可离线测量并排序」，但只信排序（F21/F22）。
- P5（时间压力）：`get_step_reward_value`（F20）+ 官方得分点（F17）给离线稠密进度标签 → I5 标注成本下降。
- P7（先手窗口）：官方 sim 数据集月下载仅约 1.9k、issue #132 仍未修（F21/F25）→ 谁先把孪生校准对，谁就握有**私有离线评测预言机**，先手复利更大。
- 新增 **P9（孪生保真债）**：官方 sim 有三类校准缺陷（F21）、视频世界模型动作可控性存疑（F22）→ 数字孪生不是免费资产，**校准才是主要工作量**；不校准的孪生会给出乐观假象。
- 新增 **P10（迭代遗忘）**：多轮提交 + 110 语料分批 + 单任务调试反馈 → 灾难性遗忘升为一等风险，需回放/适配器隔离/遗忘哨兵。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（孪生最小充分性）**：在物理 sim + 残差、纯行为动力学、视频世界模型三者中，哪一层能以最低校准成本达到与真机增益的排序相关 `ρ ≥ ρ*`？F21 三类缺陷里哪一类对排序失真贡献最大？
- **Q10（孪生验证的合成示教）**：用孪生 rollout 过滤 I5 合成示教，能否把真机恢复增益从「未过滤」显著抬高？孪生能否检出 I1「位置重拼接」产生的物理不可行动作？
- **Q11（不遗忘的迭代）**：在 32 任务基线上，回放缓冲 / 家族 LoRA 隔离 / EWC / TIES 合并四种抗遗忘手段，哪种在吸收每轮新数据 + 单任务调试反馈时把遗忘量 `F` 压在 `ε` 内且新任务仍增益？真机反馈可以稀疏到什么程度？

## 4. 设计原则（新增 PR6，其余保留）

- **PR6 孪生-回放对偶律**：①任何基于孪生的结论必须至少锚定一个**真机单任务调试点**（F23），否则只是假设；②任何离线更新必须在固定的 **32 任务哨兵电池**上复测遗忘量，`F > ε` 即回滚/重加权。孪生管「生成与排序」，回放管「不忘」，两者互为对偶。
- PR1–PR5 保留（第 1–2 轮 §4）。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 v3 考纲校准五轴增广引擎 ★★★★★
- **动机**：（v1.0/v2 保留）计分的 320 次真机评测每次都在 5 轴上偏离训练分布（P2/F2），泛化缺口是全局乘性损失。
- **本轮深化（接孪生门控）**：考纲增广器产出的「位置重拼接」样本，先过 I10 孪生的物理可行性检查（残差动力学 + 关节限位/穿透检测），把 v2 遗留的「物理不可行动作占比」判据从人工抽样升级为自动门控；不可行样本直接丢弃，不进入训练。
- **与现有方案差异**：直接 SFT 用标称数据；盲目增广用无校准随机化；本点用官方考纲校准 + 孪生物理闸门。
- **技术可行性**：高（考纲卡半自动：LLM 解析 wiki + 人工校对 32×10 分钟；可行性检查复用 I10）。
- **所需资源**：分割/inpainting 1×24GB GPU；无新增下载。
- **落地步骤**：①32 张考纲卡；②背景/干扰物两轴放量；③外观/位置两轴 L0 先行；④剂量-响应定档；⑤位置轴接孪生可行性门控。
- **风险**：考纲卡与真实评测仍有偏差（单任务调试抽测校准）；孪生门控本身有误差（只用它做「否决」不做「准入」，避免把孪生偏好带入训练）。

### I2 v3 数据引擎 2.0：110 语料孪生迁移 + 加权共训 + 抗遗忘课程 ★★★★★
- **动机**：单模型平均分被最弱任务支配（P1）；示教语料与质量双重浪费（P8）；多轮迭代下遗忘风险（P10）。
- **本轮深化（持续学习视角）**：在 v2 三件事（孪生语料入训 / loader 加权 patch / 示教质量加权）之上，加两条：
  1. **分阶段课程**：110 语料不再一次性全混入，而是「32 全量 → 高相似孪生族 → 中相似族 → 远任务 ≤5%」分阶段放量，每阶段结束跑遗忘哨兵（I11），退步的族回退。
  2. **回放缓冲常驻**：32 任务的固定小回放集（约 200 eps 量级）在每次增量更新中恒在 batch 内，作为「不遗忘锚」。回放集与 I11 共用同一份，避免两套数据口径。
- **与现有方案差异**：均匀混训把容量浪费在已会任务/低质示教，且无遗忘保护；本点诊断先行、孪生定向、权重受控、课程防遗忘。
- **技术可行性**：高（LoRA/frozen-VLM 单卡起步，F11；全参 action expert 4–8 卡）。
- **所需资源**：孪生子集 ≈1–2TB + 32 任务 ≈2TB；训练 1×24GB 起步、8×A100 上限；回放集可忽略。
- **落地步骤**：①孪生表（LLM 初筛+人工校对）；②下载孪生子集；③loader patch + batch 频率单测；④分阶段课程 + 每阶段遗忘哨兵；⑤正迁移确认后放量。
- **风险**：负迁移（孪生动态相反）——家族级 L0 + 低权重起步 + 退步即裁剪；110 语料相机配置不一致（先抽样核对 4 相机命名/分辨率）。

### I3 接触任务族关键点视觉伺服回退 ★★★★（维持）

### I10 数字孪生校准 + 闭环评测（新） ★★★★★
- **动机**：I8 的离线代理太弱、I5 的合成数据无物理闸门、I1 的位置重拼接无可行性判据——三者缺的是同一个东西：**能离线跑完整 episode 并读奖励的测量仪**。官方 sim 与真机同 DDS 且暴露 `get_step_reward_value`（F20），但只覆盖 5 个原始场景且有三类校准缺陷（F21/F26），不能开箱即用。
- **核心思路（分层孪生，按成本递增）**：
  - **Tier A 物理孪生**：Isaac Lab 原始场景族（PickPlace/Stack/Into-Drawer 等），修 F21 三缺陷（语言重标、夹爪 friction=0、腕相机外参对齐），再学一个**残差动力学** `r_φ(s,a) ≈ s'_real − f_sim(s,a)`（在 32k 遥操作上拟合），奖励用 `get_step_reward_value` 并对齐官方得分点（F17）。用于验证整条校准管线，服务与原始场景同族的考题。
  - **Tier B 行为孪生（可扩展）**：不渲染画面，只学低维对象中心状态-动作-状态动力学（来自 32k 遥操作），配一个学到的进度/终止分类器当奖励。覆盖全部 32 任务，避免昂贵的场景重建；牺牲视觉保真，保留**排序能力**。
  - **Tier C 场景重建**：仅对少数高价值弱任务（如 ZipUp/SyringeWaterTransfer）按需组场景，预算允许再做。
- **与现有方案差异**：别人要么不用 sim，要么把 sim 当真机替代；本点明确「孪生是测量仪不是替代品」——先校准、只信排序、只做否决与筛选，不做绝对成绩。
- **技术可行性**：中。Tier A 有现成 sim + 资产（F25），主要成本是修 F21 三缺陷与残差拟合；Tier B 是标准 dynamics model 工程。
- **所需资源**：Tier A 约 2 GPU-周 + 1 人 3 周；Tier B 约 1 GPU-周；sim 资产 ≈3.51GB（F25）；真机锚点用单任务调试通道（F23）。
- **落地步骤**：①修 F21 三缺陷并复现官方 sim 数据分布；②拟合残差动力学；③在 2–3 个原始场景上跑「孪生排序 vs 真机调试」相关；④`ρ ≥ ρ*` 后开放给 I5/I8 用；⑤Tier B 覆盖 32 任务并复测相关。
- **风险**：sim-to-real 残差不可学（缓解：残差只学低维状态，视觉不迁移；只用孪生做排序/否决）；官方 sim 场景覆盖不足（Tier B 兜底）；**最大风险是孪生乐观偏差被误当真值**（PR6：每个孪生结论必须锚定真机单任务调试点）。

### I11 持续学习式迭代 + 抗遗忘（新） ★★★★
- **动机**：比赛可反复发起「计分多任务 + 不计分单任务调试」（F23），加上 110 语料分批入训，形成跨提交轮次的离线持续学习流（P10）；每次更新都可能把 32 任务基线学忘，而排行榜按平均成功率+步骤分排序，掉老任务直接掉名次。
- **核心思路（抗遗忘四件套，按性价比）**：
  1. **回放缓冲**：32 任务固定小回放集常驻每个 batch（与 I2 共用），是最便宜的防遗忘基线；
  2. **家族 LoRA 隔离**：按任务族训练独立 LoRA，更新某族时不改共享 action expert；合并用 TIES/task-arithmetic 抑制符号冲突；
  3. **EWC/梯度投影**：对共享主干加 Fisher 约束，保护旧任务重要参数；
  4. **遗忘哨兵**：固定 32 任务电池（孪生为主 + 周期性真机单任务调试锚定），每次更新后计算 `F`；`F > ε` 即回滚或提高回放比例。
- **合规红线**：所有更新只发生在**两次提交之间**，计分 episode 内零梯度更新；更新日志记录数据来源与版本，可审计。
- **与现有方案差异**：多数队伍是「训一版、交一版」；本点把每轮真机调试反馈变成可持续吸收的信号，且以「不遗忘」为第一目标。
- **技术可行性**：高（回放/LoRA/EWC/TIES 都是成熟手段；单卡 LoRA 起步，F11）。
- **所需资源**：回放集可忽略；LoRA 训练 1×24GB；遗忘哨兵复用 I10 孪生 + 少量真机调试排期。
- **落地步骤**：①固定回放集与哨兵电池；②四种抗遗忘手段的最小对比（L1）；③选最优组合接 I2 课程；④每轮提交前跑哨兵；⑤记录 `F` 与排行榜名次的关系。
- **风险**：真机反馈稀疏（单任务调试只测 1 任务）→ 哨兵主要靠孪生，而孪生本身是 I10 的假设（循环依赖；用周期性真机锚点打破）；抗遗忘手段可能压制新任务学习（在 `F ≤ ε` 前提下最大化新任务增益）；合规误读（严格限定在提交间隙离线更新）。

class DigitalTwin:
    def __init__(self, sim_task_cfg, teleop):
        self.sim = IsaacLabRunner(sim_task_cfg)     # 与真机同 DDS（F20）
        self.fix_known_bugs()                        # 修 F21 三类缺陷
        self.residual = fit_residual_dynamics(teleop) # (s,a)->Δs' 残差
        self.progress = fit_progress_classifier(teleop, scoring_points)  # 对齐 F17

    def fix_known_bugs(self):
        relabel_language()          # F21①：按真实场景重标
        set_gripper_friction(0.0)   # F21②：解锁 Dex1 夹爪
        align_wrist_extrinsics()    # F21③：腕相机 pos/pitch 对齐训练分布

    def step(self, s, a):
        s_next, r = self.sim.step(a)                 # get_step_reward_value（F20）
        return self.residual.correct(s, a, s_next), r

    def rollout(self, policy, init_state, horizon):
        s, traj, R = init_state, [], 0.0
        for _ in range(horizon):
            a = policy.act(s)
            s, r = self.step(s, a)
            traj.append(s); R += r
        return traj, R, self.progress(traj)          # 成功/步骤分代理

def calibrate(twin, policy, real_debug_eps):
    pairs = [(twin.rollout(policy, e.s0)[1:], e.return_) for e in real_debug_eps]
    return {"sim_real_mae": mae(pairs),
            "rank_corr": spearman([p[0] for p in pairs], [p[1] for p in pairs])}
    # 只信 rank_corr；绝对 mae 仅作诊断（PR6）

        self.ckpt = base_ckpt
        self.replay = replay                    # 32 任务固定回放集（与 I2 共用）
