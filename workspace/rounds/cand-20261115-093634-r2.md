# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「流匹配策略」×「数据增强」）

> R69 把不确定性一分为二（aleatoric 收紧、epistemic 去问），并把「看、问、触」做成了可认证的信息动作。但它的全部效率收益押在一个从未写进证书的前提上：**流模型给出的模态分布是可信的**。R69 自己在第 6 节承认了这个洞——rectified flow 可能在有限数据上幻觉出不存在的模态、或把真模态坍缩掉；一旦如此，VoI 就是在错误信念上计算，系统会自信地追问一个幻影、或把人类一个误导性回答盖上「已验证」的章。**问错，比不问更危险。**
>
> 本轮两个灵感正好从这个洞的两侧下手：
> - **流匹配策略**已经给了我们「有坐标的模态」（原型、权重、协方差、模态间距离）。有了坐标，才谈得上「同一个模态在变换下还是不是它」——可辨识性问题才有定义。
> - **数据增强**的通常叙事是「更多数据」。但严格说这是错的：确定性增强不增加关于真实模态的互信息（数据处理不等式），它增加的是**一个已知的对称性先验**。正确用法不是「造出更多模态」，而是「检验一个模态是否在本应保持语义的变换下继续存在」，以及**把「换个角度重读同一份证据」变成一个零社交成本、零物理风险的内部信息动作**。
>
> 核心命题：**数据增强不是数据，是先验，也是动作。** 作为先验，它给出模态可辨识性检验（MIAS）与无标签自标定（ACC）；作为动作，它给 R69 的信息阶梯补上最便宜的第一级——内部增强（g_aug），在「问别人」之前先「问自己」。只有当内部增强无法消解、且外部证据过关时，才升级到注视/探针/问句。命名 **AUGUR-RAS**（Augmentation-Grounded Uncertainty Resolution：以增强为根据的不确定性消解）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在开口之前，我能否先换个角度重读同一份证据？**」——最便宜的那次求证，是问自己。

## 0. 直觉与动机

**灵感 1（数据增强的第一性原理 → 它不是数据，是已知对称性的注入）**
直觉：把一张猫的照片旋转 30°，你得到的不是「第二只猫的照片」，而是「同一只猫在已知变换下的像」。它没有告诉你任何新东西。信息论上这就是 data processing inequality：对确定性变换 A，马尔可夫链 M → O → A(O) 满足 I(M; A(O)) ≤ I(M; O)。所以「增强 = 更多数据」是错的；增强真正注入的是**一个先验**——群结构。这个纠正不是抠字眼：它决定了增强**能**用来做什么（检验不变性、降方差、降样本复杂度）和**不能**用来做什么（凭空创造 epistemic 信息）。
严谨：因此增强唯一合法的 epistemic 用途，是把「这个模态是真的吗」转化为「这个模态在一个本应保持语义的变换族下是否一致存在」。这把增强从训练技巧升格为**可辨识性检验**；也立刻暴露一个反例：任何在动作空间做 mixup 的增强会**制造**一个插值处的假模态，正好是 R69 最怕的幻影。

**灵感 2（流匹配策略 → 模态是「有坐标」的对象，才谈得上等变）**
直觉：要问「旋转后同一个模态还在不在」，必须能在两组模态之间建立对应。R69 的流匹配采样已经给了显式结构：原型 ξ̄_k、权重 ŵ_k、模态内协方差 Σ_k、模态间距 Δ_min。没有它，模态只是一团模糊的密度，「稳定性」无从定义；没有增强，这个结构又从没被验证过。二者互补：流匹配出题（模态长什么样），增强判卷（模态是不是真的）。

**灵感 3（幻影 vs 真实 → 跨环境不变性，内部版的证据纪律）**
直觉：真实的多峰性来自任务本身（绕左/绕右都合理），它应当**跨增强族不变**：换光照、换视角、轻微时间伸缩，两个模态都在，权重按已知方式变换。幻影模态来自对 nuisance 的过拟合（某个特定视角下的伪相关），换一个环境就消失。所以「这个模态是真的吗」≡「它在多个独立、语义保持的增强族下是否一致存在」——这正是 R69「k 个正交证据源一致」的**内部版**：现在证据由系统自己生成，不必打扰世界。
危险：族太弱 → 幻影活下来（假阳性）；族太强或悄悄破坏语义 → 真模态被杀掉（假阴性）。后者尤其阴险：系统会误以为「单峰、无歧义」，从而跳过求证、拿到 resolution bonus、降低 λ，**自信地错**。所以本轮的核心张力是**族的丰富性 vs 忠实性**，且必须用不对称的处理把它压到安全侧。

**灵感 4（增强是推理期的动作 → 信息阶梯的最低一级）**
直觉：解决歧义的动作有一条天然成本/风险梯级：先在脑子里「换个角度看」（只花算力，零物理风险、零社交成本）→ 再看一眼/凑近看（gaze）→ 再探一下（probe）→ 最后才开口问（ask）。R69 只有后三级。数据增强补上了最便宜的第一级：**内部增强（mental re-encoding）**。它不改变世界，只改变「我如何读同一份观测」，所以可以随意多试。这把增强从训练期搬到推理期，成为 MINT 的一个新动作 g_aug；交互预算也从「外部动作」扩展到「内部算力动作」。
严谨：AIL 阶梯要求「低一级还有正 VoI−成本时，不得先动用高一级」；在自适应子模性下，贪心阶梯近似最优（引理 22）。注意这不是「增强能问出更多信息」（不可能，灵感 1），而是「同样的信息，换一种读法可能更可分」——它榨的是**已有观测里被表征湮没的那部分可分性**。

**灵感 5（增强是双刃剑 → 投毒、捷径、自我确认）**
直觉：一旦系统用自己生成的增强来自我标定，就有了新的攻击面与新的认知病：①增强捷径——模型学到增强伪影而非任务（比如把「加了椒盐噪声」当成「有障碍」）；②错误等变标签——教出一个错误的不变性，越训越自信；③投毒流水线——后门藏在某个变换触发器里；④**自我确认**——用策略自己的模态头生成「答案」再喂回去，越算越信自己的幻觉。R69 已经为「外部回答会撒谎」立过纪律（k 源一致）；本轮必须为「自生成的证据也会撒谎」立同名纪律：生成器独立性、变换代数自洽、独立族留出。

**灵感 6（增强不消除假设 → 只是把假设挪到可检验的地方）**
直觉：R69 的假设「模态权重可信」在线**不可检验**；R70 的假设「增强族保持语义」至少可以离线检验、红队、证伪，并且可以用「族间独立 + 留出族」来做压力测试。本轮最诚实的姿态是：我们不是「解决」了模态可信问题，而是把它**换成一个能被证伪的假设**，再用不对称代价把它压到安全侧。买到的不是确定性，而是**可审计性**。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（AUGUR-RAS 总览）** AUGUR-RAS = (MFG, MIAS, ACC, AIL, CIA-A, SAN, AAG, FLUID†)。四不变式：
(i) **实时流零学习写操作**（继承 FLUID 定义 276-i / R68）；
(ii) **增强预算硬约束**：在线内部增强 ≤ B_aug 个族、离线增强流水线全程可溯源；
(iii) **增强忠实性**：任何进入正向训练/标定的增强必须通过模态忠实性（定义 312）与动力学可行性认证（复用 C-RAS-WM 对增强轨迹做离线前缀认证）；
(iv) **双层证据纪律**：模态真实性需 ≥k 个**独立增强族**一致（内部证据），真实交互仍需 R69 的 k 个**外部源**一致（外部证据）；两层不可互相替代，也不可互相「贷信」。

**定义 311（增强代数）** 观测变换 A_o: 𝒪→𝒪 与动作块推前 A_ξ: 𝒜→𝒜。语义保持群 𝒢_s = { A : p(ξ|o) = (A_ξ)_# p(ξ|A_o o) }（近似等变，误差 ε_A）；语义扩张算子 𝒢_e 改变任务标签，必须携带**已知传输** π_A。增强族 {𝒢_1,…,𝒢_m} 两两「生成机制独立」（不同物理量 / 不同传感器通道 / 不同噪声模型），独立性检验见定义 313。

**定义 312（模态忠实增强 MFG）** 称 A 为 δ-模态忠实，若它把 o 的模态集 {m_k} 双射到 A_o 的模态集 {m_{π(k)}}，模态数保持，且传输误差 W_2(A_ξ ξ̄_k, ξ̄_{π(k)}) ≤ δ、权重满足 |log(w_{π(k)}/w_k)| ≤ δ_w。**反例（必须显式禁止作正样本）**：动作空间 mixup 在 ξ̄_i 与 ξ̄_j 中点上制造第三峰，模态数破坏；跨模态拼接制造动力学不可行轨迹。此类增强只允许作为 RED-AUG（定义 321）的负样本或对抗课程。

**定义 313（跨族环境与独立性）** 把每个增强族视为一个「环境」e ∈ {1,…,m}，对模态 m_k 得到环境记录 (b_{k,e}, w_{k,e}, ξ̄_{k,e})，其中 b_{k,e} 为存在性。族间独立用「留出族预测」检验：用 m−1 族训练得 A，若能以高于随机的精度预测被留出族的模态结构，则判定两族共享生成机制，**不许计入 k**（防止「同源多族」假装成多方证据）。

**定义 314（MIAS 模态可辨识性）** 模态 m_k 的跨族稳定性 S_k = (1/m) Σ_e 𝟙[ ∃ 对应模态：W_2(A_{ξ,e} ξ̄_k, ξ̄_{k,e}) ≤ δ_stab ∧ 权重比 ∈ [1/ρ, ρ] ]；存在一致性 C_k = 1 − (分歧族数 / m)。模态**可辨识**当且仅当 S_k ≥ τ_S ∧ C_k ≥ τ_C。稳定性谱 𝒮 = {S_k}_{k=1..K̂} 作为离线证书与在线门控的接口。

**定义 315（三分类与不对称处置）** 对每个 clean 模态：
- **真实**（S≥τ_S, C≥τ_C）：允许进入 VoI 与交互；
- **幻影**（只在单一族显著、跨族即消失，且可由已知 nuisance 传输解释）：拒绝其参与 VoI；
- **脆弱/存在性未知**（clean 有、增强后系统性消失，却**无**已知传输解释）：**不得**当作「单峰」处理；U_epi 保持 R69 原值（定义 324）。
代价不对称：接受幻影的成本 ≫ 拒绝真模态造成的效率损失；但「误杀真模态 → 降 λ」被定义 324 显式禁止，确保假阴性不会降低安全。

**定义 316（DPI 与认知增益 EAG）** 对确定性语义保持增强 A，有 I(M; A(O)) ≤ I(M; O)（数据处理不等式）。故增强**不制造** epistemic 信息。定义认知增益 EAG(A) = S_k^{(A)} − S_k^{(∅)}（固定数据量 N 下可辨识性的提升）以及样本复杂度降低 ΔN(A)；正向采用仅当 EAG(A) > 0、ΔN(A) > 0 且通过定义 312。此定义是防止「增强通胀」（拿增强样本数冒充证据量）的会计口径。

**定义 317（ACC 增强一致标定）** L_ACC = E_{A∈𝒢_s} OT( ŵ(o), π_A^{-1} ŵ(A_o) )，其中 OT 为模态权重间的（带熵正则）最优传输，π_A 由定义 312 的传输给出。全程无标签、自监督。副产物：给出每个模态的 ECE 上界（引理 21），可直接替代/补强 R69 的 MCG（定义 306）。

**定义 318（AIL 增强信息阶梯）** 信息动作集合扩展为 𝒜_info = 𝒜_int ∪ 𝒜_ext，其中 𝒜_int = {g_aug}，𝒜_ext = {g_gaze, g_probe, g_ask}。成本 c(g_aug) = 算力/时延，物理风险 risk(g_aug) = 0（不触世界，g_aug 只改变对 o 的读法，不产生外部动作）。选择规则：先在 𝒜_int 内 argmax[VoI − c]；仅当其 ≤ 0，或在 B_aug 预算内仍无法把 U_epi 压到阈值，才升级到 𝒜_ext 并按 R69 定义 298 选择。定义升级为一个**单调的信息预算阶梯**。

**定义 319（CIA-A 反事实交互增强）** 对已知传输 (A, π_A)，用**冻结的、与模态头参数/训练数据均不重叠**的答案生成器 𝒲（物理引擎 + 已标定传感器模型，**不是**策略）合成 y = 𝒲(A_o, g)，得到带模态标签的反事实样本 (o, g, y, π_A(k))，用于监督 MINT 的 VoI 头与 CIA 的证据加权。**独立性条件**是硬约束：𝒲 与 mode_head 不共享参数、不共享训练数据；否则投毒/自我确认偏差无界（引理 23）。

**定义 320（SAN 语义增强零假设）** 在 𝒢_s 下构造 Δa（R69 定义 301 的流似然差）的零分布：Δa_null = |a_score(A_o) − a_score(A_o^{cal})|，A 语义保持。用其分位数标定 TAU_FMA（取代 R69 的手工阈值），并做零假设检验：真正的第二意见通道应当**只在语义变化时**显著升高，而不是在语义保持变换下也升高。若在零分布下已越界，说明 Δa 测的是增强伪影，禁用该通道。

**定义 321（RED-AUG 红队增强搜索）** 在增强空间上最大化 J_red = λ_1·模态不稳定 + λ_2·安全违规（C-RAS-WM 认证失败）+ λ_3·Δa 误标定。产出的样本只作为**负样本/对抗课程/威胁模型扩充**，绝不在未审计时进入正样本。搜索离线摊销。

**定义 322（AAG 增强溯源门与 ℰ_aug）** 每次增强携带 provenance =（源样本哈希, 变换族与参数, 变换代数自洽证明 A∘B = C, 生成器版本, 审计戳）。ℰ_aug = { 错标变换, 模态注入/擦除, 捷径伪影, 后门触发器, 溯源伪造 }。并入 AIC：ℰ_AUGUR = ℰ_FLUID × ℰ_aug。任何 provenance 断裂或代数不自洽的增强批次，整批隔离，不得用于 ACC/MIAS。

**定义 323（预算与摊销）** 训练期增强离线摊销（不进实时环）。在线仅：(a) 稳定性头 s_φ(m_k, z_t) 预测 S_k（<0.05ms）；(b) 高价值时在线跑 ≤ B_aug=1 个族的重读（trunk 复用 + 一次 flow 前向，≈1.2ms）作为 g_aug。总在线延迟：常规 <2.7ms（与 R69 持平）；歧义路径 <3.5ms；歧义 + 内部增强 <4.9ms（一次性预算，与 R69 K=4 同量级）。

**定义 324（两级信任门与风险缩放整合，扩展定义 307）** Level-1 存在性门（MIAS 三分类）；Level-2 权重门（ACC-ECE，继承 MCG）。整合：
- 真实且权重可信 → U_epi 交交互消解；消解成功 λ = λ_floor(U_ale)（resolution bonus）；
- 存在性未知/脆弱 → U_epi 保持 R69 原值，λ = λ_floor(U_ale + U_epi)（**不得因「疑似单峰」降 λ**）；
- 判定幻影 → 仅当**剩余结构被 ≥k 族认证**且移除可由已知 nuisance 传输解释时，才更新 U_epi；否则保持 R69 原值。
⇒ 严格包含 R69：当 B_aug = 0 或 𝒢 平凡时 MIAS/ACC 空转，AUGUR **逐指令等价于 FLUID**（因而也包含 R68）。

**定义 325（J_AUG 证书）** J_AUG = (J_FLUID, augmentation_provenance_hash, mode_stability_spectrum, acc_ece, san_tau, red_aug_pass, aug_ver)。Valid ⇔ Valid(J_FLUID) ∧ 溯源链完整 ∧ 稳定性谱通过 ∧ ACC-ECE ≤ τ_ece ∧ 红队套件通过。

## 2. 关键算法骨架

```python
# IP-264 MFG：模态忠实增强 + 动力学可行性认证（离线）
def mode_faithful_augment(o, xi, families, c_ras_wm, delta=0.05):
    out = []
    for A in families.sample_semantic_preserving():          # 禁止 mixup 作正样本
        o2, xi2 = A.apply_o(o), A.apply_xi(xi)
        if not A.algebra_consistent() or not A.provenance_ok():  # 定义 322
            continue
        if c_ras_wm.certified_prefix_len(xi2, o2) < K_MIN:    # 动力学可行性
            continue
        out.append((A, o2, xi2))
    return out

# IP-265 MIAS：跨族模态可辨识性（离线谱 + 在线稳定性头）
def mias(modes, families, transport):
    records = []
    for A in families:
        modes_e = cluster_trajectories(flow_sample(families.obs_o(A)))  # 同 R69 AUD
        pi = transport.match(modes, modes_e)                          # W2 / DTW
        records.append((A.id, modes_e, pi))
    S, C = {}, {}
    for k in modes:
        hit = [is_match(records[e], k, delta_stab, rho) for e in range(len(records))]
        S[k] = sum(hit) / len(records)
        C[k] = 1 - families.disagreement(records, k) / len(records)
    return stability_spectrum(S, C)                                   # 三分类在定义 315

# IP-266 ACC：无标签增强一致标定（离线，产出 ECE 上界）
def acc_calibrate(mode_head, families, o_batch):
    for o in o_batch:
        w0, o_ref = mode_head.weights(o), o
        for A in families.semantic_preserving:
            wA = mode_head.weights(A.apply_o(o))
            loss += ot_distance(w0, A.push_weights(wA))              # 定义 317
    return install_calibrated_head(loss)                              # ECE 见引理 21

# IP-267 AIL：内部增强 → 外部交互的单调阶梯
def choose_information(modes, w, o, budget, u_epi):
    # 1) 先问自己：内部增强（零风险，只花算力）
    for g in info_candidates_internal(modes, budget):
        if not budget.allow(g): continue
        score = voi_internal(w, g, o) - compute_cost(g)              # VoI − 算力
        if score > 0:
            u_epi, w, modes = apply_internal(g)                      # 重读同一份 o
            if u_epi <= TAU_EPI: return None, (u_epi, w, modes)      # 已解决，不问外部
    # 2) 再问世界：R69 的外部信息动作
    g = choose_interaction(modes, w, o, budget)                      # 复用 IP-255
    return g, (u_epi, w, modes)

# IP-268 CIA-A：反事实交互增强（冻结、独立的答案生成器）
def counterfactual_answers(A, o, g, W_frozen):
    assert W_frozen.independent_of(mode_head) and W_frozen.data_disjoint   # 定义 319
    return W_frozen.answer(A.apply_o(o), g), A.mode_transport()            # (y, pi_A)

# IP-269 SAN：用语义保持零分布标定 TAU_FMA
def calibrate_fma(policy, families, o_cal):

                + policy.log_likelihood(xi, o_cal)) for A, o, xi in families.null_pairs()]
    if quantile(null, 0.99) > TAU_FMA_SAFE: return None              # 通道被伪影污染 → 禁用

# IP-274 AUGUR 主闭环（继承 FLUID，只在信任门与信息阶梯处插入）
```

## 3. 推导

**引理 19（增强是先验，不是信息）** 设 A 为确定性语义保持变换，则 M → O → A(O) 构成马尔可夫链，I(M; A(O)) ≤ I(M; O)。故任何声称「增强带来了关于真实模态的新信息」的机制，要么偷偷用了**已知传输标签**（那信息来自标签，不来自样本），要么在制造伪相关。系：增强的正向价值只能体现为**样本复杂度降低与方差收缩**（EAG/ΔN），而不是互信息增加；一切「增强后模态数变多 ⇒ 学到了新模态」的叙事都应被自动怀疑为幻影或人为注入。

**引理 20（MIAS 分离幻影与真实）** 在 A100 下：(a) 真实模态由任务结构生成，对 𝒢_s 近似等变，E[S_real] ≥ 1 − η_eq，E[C_real] ≥ 1 − η_eq；(b) 幻影模态由 nuisance 伪相关驱动，其存在依赖被变换破坏的特定环境，E[S_phantom] ≤ δ_spur / δ_stab。故当 τ_S ∈ (δ_spur/δ_stab, 1−η_eq) 且 τ_C 同构时，阈值可分离二者。系：**族越丰富（不同 nuisance 维度越多），δ_spur 越小、分离越干净**；但族一旦破坏语义，η_eq 上升，真实模态开始被误杀——这正是丰富性/忠实性的定量版本。

**引理 21（ACC 的标定误差上界）** 设速度场在 𝒢_s 上的等变误差为 ε_v，模态最小间距 Δ_min，则跨族权重差满足 |ŵ_k(o) − ŵ_{π(k)}(A o)| ≤ c·ε_v / Δ_min。因此 ACC 把权重误差压到 O(ε_v/Δ_min)，对应 ECE 上界 ≤ c·ε_v/Δ_min + √(log(2/δ)/2N_eff)，其中 N_eff 因 |𝒢_s| 个等价样本而放大约 |𝒢_s| 倍（引理 19 的正确用法：降样本复杂度，不是增信息）。系：ACC 能在**无标签**下把 R69 的 MCG 从「被动测 ECE」升级为「主动压 ECE」。

**引理 22（信息阶梯近优）** 若每个信息动作的期望信息增益关于已获证据是自适应子模的，且成本满足 c(g_aug) ≤ c(g_gaze) ≤ c(g_probe) ≤ c(g_ask) 与 risk(g_aug)=0，则按 AIL 由低到高的贪心升级所得 U_epi 残余满足 (1−1/e) 近似最优，且**先内部后外部**在同等残余下外部动作数最少。系：内部增强把「必须问人」的场景切成两半——一半在自己脑内就解决了。

**引理 23（CIA-A 自我确认上界）** 若答案生成器 𝒲 与模态头独立（参数与训练数据均不重叠），则用反事实样本训练 VoI 头带来的自我确认偏差 ≤ ε_gen（𝒲 与真实环境之差）；若二者共享参数或数据，则偏差无上界（可自我强化到任意置信）。系：**独立性不是工程细节，是定理前提**；违反它，交互增强会把 R69 的「诚实的不知道」训练成「自信的幻觉」。

**定理 18（AUGUR 严格包含 FLUID 与 R68）** 在 A100–A102 下，AUGUR 的期望风险 ≤ FLUID ≤ R68；且当 B_aug = 0 或 𝒢 平凡时 MIAS/ACC 空转，AUGUR 与 FLUID **逐指令相同**；定义 324 保证「误杀真模态/存在性未知」永不降低 λ，故安全侧不做任何让步。效率侧因内部增强先消解一部分 U_epi 而严格不劣。

**定理 19（增强投毒上界）** 若对手控制比例 δ_a 的增强更新，且采用 k 个独立族（相关 ρ<1）一致纪律与留出族检验，则错误模态准入率 ≤ δ_a·ρ^{k−1} + ε_σ；若 provenance 链完整且代数自洽检查通过率被强制为 1，则后门触发需同时伪造 ≥k 族一致，检测概率 ≥ 1 − (1−p_det)^k。系：内部证据与外部证据用同一套「k 源一致」纪律，威胁模型可以复用 R69 的引理 18 结构。

**定理 20（内部增强不能静默降低安全）** g_aug 只改变对既有观测的读法、不产生外部动作、不进入 C-RAS-WM 的物理执行链，故 risk(g_aug)=0；且任何内部增强导致的 U_epi 下降都必须通过定义 324 的存在性门，而「脆弱/未知」被强制保持 R69 原值。因此内部增强只能减少外部交互次数或提升可分性，不能单独把系统推离安全包络；一旦 SAN 判定第二意见通道被伪影污染，Δa 通道禁用并回退 R69。

## 6. 本轮最大风险

**一句话**：AUGUR 把「模态权重是否可信」换成了「增强族是否真的保持语义」——但若所选增强族悄悄破坏了语义（例如某个「光照不变」变换同时改变了材质/接触线索，某个「视角不变」变换越过了遮挡边界），MIAS 会把真模态误判成幻影、把幻影误判成真实，ACC 更会**朝着错误的不变性自我标定**，产出一组恰好通过 ECE 门、却系统性地错在同一个方向上的模态权重；而由于内部增强是最便宜的一级，系统会**在开口问任何人之前，先用一个错误的先验把自己说服**——这不是「问错」，而是「不用问就已经错」，且带着一张自洽的证书。

**次级风险与缓解**：
1. **族的丰富性–忠实性张力**（太弱留幻影、太强杀真模态）→ 留出族检验（定义 313）+ 族扫描 E311 + 不对称处置（定义 315/324）；
2. **增强投毒 / 捷径 / 后门**（ℰ_aug）→ provenance 哈希链 + 代数自洽 + k 族一致 + RED-AUG + 定理 19；
3. **自我确认**（用策略自己的模态头造答案）→ CIA-A 生成器独立性硬约束 + 引理 23；
4. **在线预算被 g_aug 击穿** → B_aug=1 + 稳定性头门控 + 离线摊销（定义 323）；
5. **把「增强是数据」的错觉写进指标**（拿增强样本数冒充证据量）→ DPI/EAG 会计口径（定义 316），所有增益必须报告 ΔN 而非样本数。

**定义 318（AIL）** `𝒜_info=𝒜_int∪𝒜_ext`，`𝒜_int={g_aug}`；先在内部 argmax[VoI−c]，≤0 或预算内压不下 U_epi 才升级外部；`risk(g_aug)=0`。

**定义 321–322（红队与溯源）** RED-AUG 最大化 `J_red`，产物只作负样本/课程；AAG 要求 provenance 含源哈希、族参数、代数自洽 A∘B=C、版本、审计戳；断裂即整批隔离。`ℰ_AUGUR=ℰ_FLUID×ℰ_aug`。

**定义 323–325（预算/信任门/证书）** 增强离线摊销、在线仅稳定性头 + ≤1 次 g_aug；两级信任门（存在性 × 权重）整合到定义 307：真实且可信→resolution bonus，未知/脆弱→保 R69 原值不降 λ，幻影→需 ≥k 族认证方可更新。`J_AUG` 增补 provenance、稳定性谱、ACC-ECE、SAN-τ、红队通过位。

```python
# IP-264 MFG：模态忠实增强 + 动力学可行性（离线）
def mode_faithful_augment(o, xi, families, c_ras_wm):
    out = []
    for A in families.sample_semantic_preserving():           # 禁 mixup 作正样本
        o2, xi2 = A.apply_o(o), A.apply_xi(xi)

        if c_ras_wm.certified_prefix_len(xi2, o2) < K_MIN:     continue
        out.append((A, o2, xi2))

# IP-265 MIAS：跨族稳定性谱（离线）+ 在线稳定性头
def mias(modes, families, transport):
    rec = []
    for A in families:
        me = cluster_trajectories(flow_sample(families.obs_o(A)))
        rec.append((A.id, me, transport.match(modes, me)))
    S = {k: mean(is_match(rec[e], k, delta_stab, rho) for e in range(len(rec))) for k in modes}
    C = {k: 1 - families.disagreement(rec, k)/len(rec) for k in modes}
    return stability_spectrum(S, C)                            # 三分类见定义 315

# IP-266 ACC：无标签一致标定（离线）
def acc_calibrate(mode_head, families, o_batch):
    for o in o_batch:
        w0 = mode_head.weights(o)
        for A in families.semantic_preserving:
            loss += ot_distance(w0, A.push_weights(mode_head.weights(A.apply_o(o))))
    return install_calibrated_head(loss)                       # ECE 界见引理 21

# IP-267 AIL：内部增强 → 外部交互的单调阶梯
def choose_information(modes, w, o, budget, u_epi):
    for g in info_candidates_internal(modes, budget):          # 先问自己
        if budget.allow(g) and voi_internal(w, g, o) - compute_cost(g) > 0:
            u_epi, w, modes = apply_internal(g)                # 重读同一份 o
            if u_epi <= TAU_EPI: return None, (u_epi, w, modes)
    return choose_interaction(modes, w, o, budget), (u_epi, w, modes)  # 再问世界（IP-255）

# IP-268 CIA-A：反事实交互增强（冻结、独立生成器）
def counterfactual_answers(A, o, g, W_frozen):
    assert W_frozen.independent_of(mode_head) and W_frozen.data_disjoint   # 定义 319
    return W_frozen.answer(A.apply_o(o), g), A.mode_transport()

# IP-269 SAN：零分布标定第二意见阈值
def calibrate_fma(policy, families, o_cal):
    null = [abs(-policy.log_likelihood(xi, A.apply_o(o))
                + policy.log_likelihood(xi, o_cal)) for A, o, xi in families.null_pairs()]
    return None if quantile(null, .99) > TAU_FMA_SAFE else quantile(null, .99)

# IP-274 AUGUR 主闭环（继承 FLUID）
def AUGUR_RAS_round(M, obs):
    spec   = M.mias.stability_spectrum(obs)
    trust  = three_way_gate(spec, M.acc.ece)                   # 定义 315/324
    U_ale, U_epi, modes = M.fluid.decompose_as_r69(obs)
    U_epi  = apply_trust(U_epi, modes, trust)
    g, (U_epi, modes) = M.ail.choose_information(modes, U_epi, obs, M.budget)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    a_hat  = M.san.flow_anomaly(M.fmp, M.last_action, obs, M.o_cal)
    lam    = risk_scale_with_trust(U_ale, U_epi, trust)
    k      = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    if trust.fragile: lam = max(lam, lam_floor(U_ale + U_epi)) # 不得降 λ
    if a_hat > M.san.tau: lam = max(lam, 0.8)
    mode = select_mode(modes, U_epi, lam)
    M.vqa_i.submit_async(g, spec, trust, a_hat)
    return k, lam, mode, (U_ale, U_epi), spec
```

## 4. 推导

**引理 19（增强是先验，不是信息）** 确定性语义保持 A 使 M→O→A(O) 成马尔可夫链，`I(M;A(O)) ≤ I(M;O)`。增强不制造关于真实模态的信息；正向价值只在样本复杂度降低与方差收缩。系：任何「增强后模态变多 ⇒ 学到新模态」应被自动怀疑为幻影或人为注入。

**引理 20（MIAS 分离幻影与真实）** A100 下：真实模态 `E[S_real] ≥ 1−η_eq`、`E[C_real] ≥ 1−η_eq`；幻影 `E[S_phantom] ≤ δ_spur/δ_stab`。取 `τ_S∈(δ_spur/δ_stab, 1−η_eq)` 可分离。系：族越丰富 δ_spur 越小，但破坏语义会抬高 η_eq 并误杀真模态——丰富性/忠实性的定量张力。

**引理 21（ACC 标定误差上界）** 等变误差 ε_v、模态间距 Δ_min 下，跨族权重差 `≤ c·ε_v/Δ_min`，故 `ECE ≤ c·ε_v/Δ_min + √(log(2/δ)/2N_eff)`，`N_eff` 因 |𝒢_s| 个等价样本放大约 |𝒢_s| 倍。系：无标签也能主动压 ECE，优于 R69 的被动 MCG。

**引理 22（信息阶梯近优）** 期望信息增益自适应子模、成本单调且 `risk(g_aug)=0` 时，按 AIL 由低到高贪心升级满足 `(1−1/e)` 近似最优，且同等残余下外部动作数最少。

**引理 23（CIA-A 自我确认上界）** 𝒲 与模态头参数/数据皆独立时自我确认偏差 `≤ ε_gen`；共享则无上界。系：独立性是定理前提，不是工程细节。

**定理 18（AUGUR 严格包含 FLUID 与 R68）** A100–A102 下风险 ≤ FLUID ≤ R68；`B_aug=0` 或 𝒢 平凡时与 FLUID 逐指令相同；「误杀真模态/存在性未知」永不降 λ（定义 324），安全侧不让步，效率侧因内部增强先消解部分 U_epi 而严格不劣。

**定理 19（增强投毒上界）** 对手控制比例 δ_a、采用 k 独立族（ρ<1）一致 + 留出族检验，错误模态准入 `≤ δ_a·ρ^{k−1}+ε_σ`；provenance 完整 + 代数自洽强制时，后门需伪造 ≥k 族一致，检测概率 `≥ 1−(1−p_det)^k`。

**定理 20（内部增强不能静默降低安全）** g_aug 不产生外部动作、不进物理执行链，`risk=0`；U_epi 的下降必须过存在性门，「脆弱/未知」强制保 R69 原值；SAN 判定通道被伪影污染时禁用 Δa 并回退 R69。故内部增强只减少外部交互或提升可分性，不能单独把系统推离安全包络。

## 7. 本轮最大风险

**一句话**：AUGUR 把「模态权重是否可信」换成了「增强族是否真的保持语义」——若增强族悄悄破坏语义（「光照不变」同时改了材质/接触线索、「视角不变」越过遮挡边界），MIAS 会把真模态误判为幻影、幻影误判为真实，ACC 更会**朝错误的不变性自我标定**，产出一组恰好通过 ECE 门却系统性错在同一方向的权重；而内部增强最便宜，系统会**在开口问任何人之前先用错误先验说服自己**——不是「问错」，而是「不用问就已经错」，且带着一张自洽的证书。

**次级风险与缓解**：丰富性–忠实性张力（留出族检验 + E311 扫描 + 不对称处置）；增强投毒/捷径/后门（provenance 链 + 代数自洽 + k 族一致 + RED-AUG + 定理 19）；自我确认（CIA-A 生成器独立性硬约束 + 引理 23）；在线预算被 g_aug 击穿（B_aug=1 + 稳定性头门控 + 离线摊销）；「增强是数据」的指标错觉（DPI/EAG 会计口径，增益只报 ΔN）。
