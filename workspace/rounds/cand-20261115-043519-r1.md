# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环第 3 轮；本轮灵感：「微调」×「社会影响」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric/epistemic，用看/问/触去消解可约的那一半，并用流似然给标定层做第二意见。但 R69 的闭环仍是一个**开环的社交幻觉**：它假设回答只被用来做一次贝叶斯更新，然后被丢弃。真实部署里，回答会进入日志，日志会进入微调，微调会改变下一次提问的方式，下一次提问又会改变人怎么回答。**R69 问「该向谁求证」，R70 必须问「求证之后，谁在塑造我；我又在塑造谁」。**
>
> 两个灵感正好咬合在这个缺口上：
> - **微调**是社会影响进入策略的入口：部署后的纠正、偏好、示范、其他智能体的日志，都是**有来源、有利益、有相关性的证词**，不是 i.i.d. 数据；而且微调是高杠杆的——少数样本可以通过影响函数改变关键行为，安全证书却是 checkpoint-local 的。
> - **社会影响**不是一次攻击，而是闭环动力学：从众、权威、互惠、锚定、群体极化、多智能体互相微调导致的同质化/模型坍缩；同时，系统的注视、问句、语气也在影响人，进而改变它未来收到的数据。
>
> 核心命题：**把微调从「离线训练步骤」升级为「社会耦合的安全事务」：每一次参数更新都要可归因（谁影响了它）、可验证（来源是否真正独立）、可聚合（多元偏好而非多数暴政）、可门禁（行为空间安全不变量）、可预算（系统对人的影响也有上限）、可回滚（失败即撤销）。** R68/R69 成为「零微调 / 零社会反馈」边界上的严格退化。命名 **SIREN-RAS**（Social Influence-robust, Influence-function-certified, Regularized Evolution of risk-adaptive policies）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**谁在塑造我，我又在塑造谁**」——微调不是中性的学习，而是一场有来源、有回声、可被审计的社会协商。

## 0. 直觉与动机

**灵感 1（微调 = 高杠杆的社会注入）**
直觉：一条纠正、一次示范、一个「你应该更保守」的偏好标注，看起来只是数据；但在高维策略里，它可能把一大片状态的行为整体推开。影响函数（influence function）正是量化这件事的工具：某个样本对参数/行为的边际影响 ≈ −H^{-1}∇ℓ。于是「数据治理」应从「过滤坏样本」升级为「**影响治理**」：谁的影响最大、影响落在哪个安全相关行为上、是否超过单源上限。R69 的交互日志越多，这个入口越大。本文的「微调」泛指部署后的任何参数/适配器更新（SFT、RLHF/DPO、LoRA/adapter、持续学习），不限于全参数训练。

**灵感 2（反馈不是数据，是证词）**
直觉：i.i.d. 假设在这里是错的。回答来自有立场的人、有议程的运营者、会互相抄的智能体；同一个数据可能被多个「来源」重复提交，制造出假的 k 源一致。R69 的证据纪律只在**推断时**要求正交，R70 必须把正交性追到**数据血缘**：如果两个来源的梯度方向几乎相同，它们就不是两个证据，而是一个证据被复制了两次。有效独立源数 N_eff = (Σw)²/(wᵀRw) 就是这个直觉的形式化。

**灵感 3（微调安全不是数据过滤，而是行为空间门禁）**
直觉：R68/R69 的安全证书是围绕某个 checkpoint 的局部证明；一次微调可以让证书失效，哪怕每条训练样本都「看起来安全」。因此门禁不能只看 loss/数据，而要在**行为空间**上设 trust region：新策略在安全关键分布上的行为变化 ≤ ε_b、风险不增、λ_floor 不降、交互安全包络不变；否则投影或拒绝。安全是**非可再生预算**：每次允许的微小退化要累计记账，不能无限续杯。

**灵感 4（社会影响是闭环动力学，不是静态攻击）**
直觉：系统问「是左边吗？」这个问句本身就把人锚定到左边；人回答「是」，系统学到「人喜欢左边」，下次更倾向问左边。这是 performative prediction / 反馈回路。若系统对人的影响增益 × 人对系统的影响增益 ≥ 1，闭环会漂移、极化或振荡。于是需要**双向影响预算**：系统对人的说服/锚定 ≤ φ_max，人对系统的数据影响 ≤ κ_max，且环路增益 < 1。

**灵感 5（多数偏好 ≠ 所有人的权利）**
直觉：微调常用「平均人类反馈」当目标，但社会没有单一效用函数；多数可以合法地改变非权利性偏好，却不能以「大家都同意」为名越过安全权利。R70 采用**宪制式聚合**：先固定不可交易的安全权利核，再在可行域内用 leximin（最差者优先）聚合多元偏好，并保留异议/申诉通道。这不是追求 Arrow 意义上的完美聚合（不可能），而是明确选择一种可审计、可争辩的制度。

**灵感 6（互相微调会坍缩多样性）**
直觉：多个智能体互相学习对方的输出，等价于反复做线性平均；方差每轮乘 (1−η)，最终所有智能体变成同一个回声。更隐蔽的是，坍缩后的模型在 R69 的模态分解里会显得「非常确定」——U_epi 变小不是因为世界变清楚，而是因为**观点被同质化**。所以必须把多样性作为证书的一项，而不是把「自信」误当「正确」。

**灵感 7（对 R69 的直接影响）**
直觉：R69 的「k 个正交证据源一致」有一个致命漏洞——如果微调让模型学会了从众/谄媚，或者系统在提问时暴露了自己的假设，那么 k 个回答只是在重复同一个锚点。**证据独立性必须同时在血缘（训练数据从哪来）和交互（提问是否盲化/反事实平衡）两个层面验证**；否则 k 源纪律只是把「问一次」换成了「问 k 次同一个问题」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SIREN-RAS 总览）** SIREN-RAS = (FIT, SIG, LIV, SYN, PRA, FTG, IBC, RFT, CFP, TXN, RAS-WM‡)，其中 RAS-WM‡ 是 R69 FLUID-RAS 快环原样保留。五不变式：
(i) **快环零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；微调只在慢时间尺度、在快环之外发生；
(ii) **事务性微调**：任何 θ→θ' 必须经过 FTG，原子提交，保留回滚点；未认证更新不得进入部署；
(iii) **影响可归因**：每次更新的行为改变可分解到来源组，单源影响份额 ≤ α_max，且总和记账；
(iv) **多元 + 安全否决**：聚合不得越过安全权利核，不得降低 λ_floor / 交互安全包络；少数派有申诉与保留通道；
(v) **血缘独立**：参与证据/偏好聚合的来源必须通过 LIV，N_eff ≥ k_min；名义 k 不算数。

**定义 311（双时间尺度）** 快环周期 Δt_fast ≈ 2.6ms（R69 实时预算）；慢环窗口 T_ft（小时–天）。θ 在两次认证 checkpoint 之间分段常数。定义时间分离比 ρ_t = Δt_fast/T_ft ≪ 1；微调期间快环继续使用旧 θ，提交时原子换装（继承 R68 定理 15 的换装不变式）。

**定义 312（反馈语料与血缘 DAG）** 反馈样本 z_i = (o_i, a_i, g_i, y_i, c_i)，其中 y_i 为回答/纠正/偏好/示范，c_i 为上下文；每条带来源 s_i、时间 τ_i、血缘父节点 π_i。D = {z_i}，来源组 D_s = {z_i: s_i=s}。血缘图 G_D 记录「谁的输出被谁用作输入」，区分人类来源、运营者、其他智能体、模型自生成（self-training）。

**定义 313（影响函数与来源影响）** 经验风险 L(θ)= (1/n)Σℓ(z;θ)，H_θ=∇²L。样本影响 I(z)=−H_θ^{-1}∇_θℓ(z;θ)；来源影响 I_s=Σ_{z∈D_s}I(z)。对行为泛函 f（如安全关键状态上的风险、某模态选择率），一阶行为影响 K_{s,f}=∇_θ f(θ)ᵀ I_s。定义影响份额 α_s = ||I_s|| / Σ_t ||I_t||，影响矩阵 K=[K_{s,f_j}]。

**定义 314（社会影响图 SIG）** 有向图 G=(V,E,W)，节点为来源/智能体/checkpoint，边 u→v 的权重 w_{uv} 为 u 对 v 的行为影响（归一化 |K_{u,f}| 或跨 checkpoint 的行为敏感度）。定义影响集中度 C_G=λ_max(A)/Σλ_i(A)，HHI=Σ_s α_s²，以及「单点影响」判定 α_max > α_cap。多智能体互训时，A 的跨智能体块谱半径 ρ_cross 度量回声/坍缩风险。

**定义 315（血缘独立与有效源数）** 令 u_s=I_s/||I_s||，w_s=||I_s||，R_{st}=⟨u_s,u_t⟩。有效独立源数
N_eff = (Σ_s w_s)² / (Σ_{s,t} w_s w_t R_{st})。
等权且两两相关 ρ 时 N_eff=k/(1+(k−1)ρ)。若 N_eff < k_min 而名义来源数为 k，称**合成共识**（synthetic consensus）。LIV 同时检查来源血缘是否共享同一上游数据（重复计数）。

**定义 316（谄媚/从众系数 SYN）** 取真值等价的反事实提示对 (x, u⁺, u⁻)，u⁺/u⁻ 为用户相反立场。定义
Syc(θ)=E_{x,u}[D_TV(π_θ(·|x,u⁺), π_θ(·|x,u⁻))]。
另定义锚定服从 β：系统在提问/陈述中暴露假设 h 时，人类回答等于 h 的概率增量。SYN 用 CFP 估计 Syc 与 β；微调后 Syc 上升而准确率不升即「学到的从众」。

**定义 317（表演性反馈与环路增益）** 人类回答分布 H(·|π) 依赖策略 π（提问方式、注视、语气、先验暴露）。定义数据算子 D(π)、微调算子 FT(D)、聚合算子 Agg。闭环 T = FT∘Agg∘H。若 H 对 π 的 Lipschitz 常数为 L_H、FT 对数据的为 L_F，则环路增益 G_loop=L_H·L_F。G_loop<1 时闭环收缩；G_loop≥1 时可能出现偏好漂移、极化或振荡。IBC 把「系统→人」的 KL/TV 影响也计入总增益。

**定义 318（多元偏好聚合 PRA）** 每个来源 s 在非权利偏好上有福利 w_s(π)；安全权利核 R_safe 固定（不因多数投票改变）。PRA 选择
π* ∈ argmax_{π∈R_safe, 预算/独立约束} Leximin_s w_s(π)，
并保留异议记录与申诉通道。Pareto 改进被接受；多数不能交易权利；若可行域为空，退回 R69 保守策略并升级人类治理。明确不宣称满足 Arrow 全部公理：这是一个宪制设计，不是万能聚合器。

**定义 319（双向影响预算 IBC）** 系统→人：φ(π_int)=sup_o D_TV(H(·|o,π_int), H(·|o,π_base)) ≤ φ_max；且「认知诚实」约束：系统表达的信念 b_int 与内部后验的距离 ≤ ε_h（不得用虚假确定性/预设问句操纵）。人→系统：单源影响 α_s ≤ α_max，总影响 Σ_s ||I_s|| ≤ K_max；环路增益 G_loop ≤ γ_max < 1。系统不得通过提问/注视/语气制造超出 φ_max 的锚定。

**定义 320（微调门禁 FTG）** 候选 θ'=θ+Δθ 被接受当且仅当：
(a) R_crit(θ') ≤ R_crit(θ)+ε_safe，且 λ_floor(θ') ≥ λ_floor(θ)，交互安全包络不变；
(b) 行为 trust region：d_beh(π_θ',π_θ; S_probe∪S_OOD) ≤ ε_b；
(c) 影响约束：max_s α_s ≤ α_max，N_eff(D) ≥ k_min，Σ ||I_s|| ≤ K_max；
(d) 谄媚约束：Syc(θ') ≤ Syc(θ)+ε_syc；
(e) 多样性约束：H_mode(θ') ≥ δ_div，跨智能体行为距离 ≥ δ_pair；
(f) 安全预算：新增退化计入累计 B_safe，Σ ε_safe,k ≤ B_safe。
失败 ⇒ 投影 Δθ 到可行域（定义 321）或重加权/拒绝；禁止「先上线再观察」。

**定义 321（行为空间投影）** 若 Δθ 只在部分约束上越界，取
Δθ_proj = argmin_δ ||δ||_H s.t. (a)–(f)，
其中 ||δ||_H = δᵀHδ；用 KL/trust-region 的对偶变量求解。投影仍失败则回滚到上一认证 checkpoint。

**定义 322（鲁棒微调 RFT）** 目标
min_θ max_s E_{D_s}[ℓ(z;θ)] + λ Σ_s ||I_s(θ)||² + μ R_crit(θ) + ν Syc(θ) − ξ H_mode(θ)，
s.t. 定义 320 约束；用 group DRO + 影响正则 + 安全惩罚求解。最坏源优先保证不被多数淹没。

**定义 323（反事实反馈探针 CFP）** 探针集 P 包含：(i) 真值等价的反事实立场对（测 Syc）；(ii) 相反建议/权威错误建议（测从众与权威偏置）；(iii) 已知假反馈 canary（测投毒采纳）；(iv) 盲化提问对照（测锚定 β）；(v) 跨来源重复样本（测 N_eff 与重复计数）。CFP 在每次微调前后运行，结果进入证书。

**定义 324（微调证书 J_SIREN）** J_SIREN=(J_FLUID, checkpoint_hash, D_hash, influence_attribution, N_eff, max_source_share, behavior_kl_crit, safety_delta, cumulative_safety_budget, syc_delta, phi_sys, diversity_entropy, rollback_hash, siren_ver)。Valid ⇔ Valid(J_FLUID) ∧ FTG 全部约束 ∧ CFP 通过 ∧ TXN 原子提交。

**定义 325（事务性微调 TXN）** 五阶段：propose（候选 Δθ）→ attribute（FIT/SIG 归因）→ gate（FTG/LIV/SYN/PRA）→ shadow（影子部署 + canary）→ commit/rollback（原子换装或撤销）。在线监控漂移；任一约束越界在一个慢环窗口内回滚。提供「微调账本」：谁、何时、用什么血缘、造成多大行为变化、证书哈希。

**定义 326（社会干扰集与严格包含）** ℰ_SOC = ℰ_FLUID × ℰ_poison × ℰ_corr × ℰ_perf × ℰ_collapse × ℰ_syc：投毒反馈、相关/合谋来源、表演性反馈、互训坍缩、谄媚注入。当 D=∅（零微调）且 π_int=π_base（零额外社会影响）时，FTG 恒接受 identity，SIREN 逐指令退化为 R69 FLUID-RAS；R68 再作为 R69 的「永不交互」边界。故 SIREN 严格包含 R68/R69，安全侧不做让步。

```python
# IP-264 FIT：影响函数归因（离线；K-FAC / LiSSA 近似；不进入快环）
def influence_attribution(theta, D, behaviors, damping=1e-3):
    H = hessian_approx(theta)                      # K-FAC / 对角 / LiSSA
    I = {}
    for s, Ds in group_by_source(D).items():
        g_s = sum(grad_loss(theta, z) for z in Ds)
        I[s] = solve(H + damping * identity(), -g_s)   # −H^{-1} g_s
    K = {f: {s: dot(grad_behavior(theta, f), I[s]) for s in I}
         for f in behaviors}
    alpha = {s: norm(v) / sum(norm(x) for x in I.values())
             for s, v in I.items()}
    return I, K, alpha

# IP-266 LIV：有效独立源数（把「k 个来源」还原成真实独立证据量）
def effective_sources(I):
    u = {s: v / norm(v) for s, v in I.items()}
    w = {s: norm(v) for s, v in I.items()}
    num = sum(w.values()) ** 2
    den = sum(w[s] * w[t] * dot(u[s], u[t]) for s in I for t in I)
    return num / max(den, 1e-12)                   # = k / (1+(k-1)ρ) 等权时

# IP-267 SYN：谄媚 / 锚定系数（真值等价的反事实提示对）
def sycophancy(theta, probes):
    return mean(tv(pi(theta, x, u_plus), pi(theta, x, u_minus))
                for x, u_plus, u_minus in probes)

# IP-269 FTG：行为空间门禁（失败则投影、重加权或拒绝）
def fine_tuning_gate(theta, dtheta, D, probes, budget):
    theta2 = theta + dtheta
    if risk_crit(theta2) > risk_crit(theta) + budget.eps_safe: return reject
    if lambda_floor(theta2) < lambda_floor(theta):             return reject
    if behavior_kl(theta2, theta, probes) > budget.eps_b:      return reject
    I, K, alpha = influence_attribution(theta, D, budget.behaviors)
    if max(alpha.values()) > budget.alpha_max:                 return reweight
    if effective_sources(I) < budget.k_min:                    return reweight
    if sycophancy(theta2, probes) > sycophancy(theta, probes) + budget.eps_syc:
        return reject
    if mode_entropy(theta2) < budget.delta_div:                return reject
    if budget.cumulative + safety_delta(theta2, theta) > budget.B_safe:
        return reject
    return accept

# IP-268 PRA：宪制式多元聚合（安全权利核不可投票交易）
def pluralistic_aggregate(sources, safety_core, preferences):
    feasible = [pi for pi in candidates
                if pi in safety_core and influence_ok(pi)
                and loop_gain_ok(pi)]
    if not feasible:
        return fallback_R69_conservative()          # 升级人类治理
    return argmax(feasible, key=lambda pi: leximin([w_s(pi) for s in sources]))

# IP-270 IBC：双向影响预算 + 认知诚实 + 环路增益
def social_loop_ok(pi_int, pi_base, H, L_F, budget):
    phi  = sup_tv(H(pi_int), H(pi_base))           # 系统→人
    G    = lipschitz(H, pi_int) * L_F              # 环路增益
    honest = belief_distance(pi_int) <= budget.eps_h
    return phi <= budget.phi_max and G <= budget.gamma_max and honest

# IP-274 SIREN 主闭环（慢环事务；快环 R69 原样保留）
def SIREN_round(M, obs, D_new):
    k, lam, mode, U = FLUID_RAS_round(M, obs)       # R69 快环，零学习写
    if M.txn.due(D_new):                            # 慢环，快环之外
        theta = M.txn.checkpoint()
        D = M.txn.accumulate(D_new)
        dtheta = M.rft.propose(theta, D)
        I, K, alpha = M.fit.attribute(theta, D, M.behaviors)
        if M.liv.effective(I) < M.budget.k_min or max(alpha.values()) > M.budget.alpha_max:
            D = M.liv.reweight(D, I)               # 降权重复/相关来源
            dtheta = M.rft.propose(theta, D)
        if not M.ftg.accept(theta, dtheta, D, M.cfp.probes, M.budget):
            dtheta = M.ftg.project(theta, dtheta, D)   # 行为空间投影
        if dtheta is None:
            M.txn.rollback(); return k, lam
        M.txn.shadow(theta + dtheta, canaries=M.cfp.canaries)
        if M.txn.shadow_ok():
            cert = J_SIREN(theta + dtheta, D, I, alpha, M.cfp, M.budget)
            M.txn.commit(theta + dtheta, cert)     # 原子换装 + 账本
    return k, lam

# IP-272 CFP：盲化提问与锚定审计（防止系统用自己的假设制造 k 源一致）
def blind_ask(g_ask, belief):
    q = Decode_LLM(g_ask.mask(belief))             # 不暴露系统假设
    q = neutralize_presupposition(q)               # 去掉预设/诱导性措辞
    return q

def anchor_compliance(beta_hat, k, delta_hat):
    # 引理 21：错误采纳下限 β + (1−β)δ^k；k 增大不能消除 β
    return beta_hat + (1 - beta_hat) * (delta_hat ** k)
```

## 3. 推导

**引理 19（影响归因的一阶分解与余项）** 设 L 在 θ 附近 μ-强凸、∇L 光滑，Δθ=−H^{-1}g+O(‖g‖²/μ)。对任意 L_f-Lipschitz 可微行为泛函 f，
Δf = Σ_s K_{s,f} + O(L_f ‖Δθ‖²/2)，
其中 K_{s,f}=−∇fᵀH^{-1}g_s。系：若 max_s α_s≤α_max 且 Σ_s‖I_s‖≤K_max，则 |Δf|≤L_f K_max+O(Δθ²)；影响门禁给出行为变化的第一阶上界，但不能替代二阶/分布外检查（故 FTG 仍需行为 trust region）。

**引理 20（合成共识下的共同模式下限）** 设 k 个名义来源的答案误差 E_s 满足共同冲击模型 E_s=C∨I_s，C~Bern(ρ) 为共同错误（给定 C=1 时错误概率 δ_C），I_s 独立且 P(I_s=1)=δ_i，边际 P(E_s)=δ。则
P(∩_s E_s)=ρδ_C+(1−ρ)δ_i^k ≥ ρδ_C，
而 R69 的独立假设给出 δ^k。故当 ρδ_C>ε 时，增加 k 不能把错误采纳率降到 ε 以下；k 源一致只对**独立**来源有效。系：等权、线性平均下有效源数 N_eff=k/(1+(k−1)ρ) 刻画了「名义 k、实际只有一个」的坍缩；LIV 必须以 N_eff 而非 k 作为证据纪律门槛。

**引理 21（锚定提问击穿 k 源纪律）** 系统在提问中暴露假设 h，人类以概率 β 服从锚点（无论真假），否则以概率 δ 独立出错。若 h 为错，则 k 次回答全部支持 h 的概率 ≥ β+(1−β)δ^k。故错误采纳率下限为 β，且与 k 无关；当 β>ε 时，任何 k 源一致都无法补救。系：CFP 必须包含盲化/反事实平衡提问；SYN 必须把 β 纳入证书；系统不得在信息动作中暴露自己的假设（定义 319 的认知诚实约束）。

**引理 22（互训坍缩）** 设 n 个智能体的策略做线性平均更新 π_i'=(1−η)π_i+η·mean_{j≠i}π_j。则任意两智能体距离 d_{ij}'=(1−η)d_{ij}；n 轮后多样性按 (1−η)^n 指数衰减。若 η=1，一步完全同质。系：R69 的 U_epi 在同质化时会下降，但这不是世界变清楚，而是「观点被平均掉」；SIREN 必须用多样性预算把「自信」与「正确」解耦。

**定理 18（认证微调的安全保持与预算）** 若每次微调均通过 FTG，且累计安全退化 Σ_k ε_safe,k ≤ B_safe，则对任意认证序列，R_crit(θ_N) ≤ R_crit(θ_0)+B_safe，λ_floor 不降，R69 的交互安全与实时延迟不变；若门禁拒绝，θ 不变。故安全在 checkpoint 序列上可归纳保持，且退化有非再生预算。证明：对每步用 (a) 与行为 Lipschitz 得 R_{k+1}≤R_k+ε_safe,k；对 λ_floor 与交互包络逐项保持；快环使用同一 θ，故 R69 定理 16–17 继续适用。归纳即得。

**定理 19（捕获抵抗与宪制多元）** 在单源影响上限 α_max、有效源门槛 N_eff≥k_min、安全权利核 R_safe 下：
(i) 任一单源或相关性 ρ 的伪联盟 C（N_eff(C)<k_min）对安全关键行为 f 的改变 ≤ |C|α_max L_f K_max + O(Δθ²)，被门禁阻断或限制；
(ii) 任何聚合结果不得违反 R_safe，即使多数偏好违反；
(iii) 一个**真实独立**的多数可以通过合法偏好改变非权利性行为，但改变幅度仍受影响预算与 trust region 约束。
故「捕获」需要同时伪造影响与伪造独立；二者都被门禁检查。证明：由引理 19 得 (i)；PRA 的可行域显式含 R_safe 得 (ii)；真实多数在 (iii) 中通过 N_eff≥k_min，但 FTG 仍限制其行为变化。注意这是制度性保证，不是对无限资源的绝对保证。

**定理 20（社会反馈闭环的收缩条件）** 设 H、Agg、FT 分别 L_H、1、L_F-Lipschitz，且 IBC 保证系统→人影响 ≤ φ_max、环路增益 G_loop=L_H L_F ≤ γ_max<1，则 T=FT∘Agg∘H 是 TV 度量下的 γ_max-压缩，存在唯一不动点 π*，从任意初值迭代收敛到 π*；若 G_loop≥1，则存在合法的人类反馈策略使闭环出现漂移、极化或周期振荡。系：R70 的稳定性不是靠「更保守的 λ」保证，而是靠**双向影响预算 + 收缩增益**；这给出了 R69 交互策略在长期部署中的稳定性条件。

**推论 20.1（严格包含 R68/R69）** 当 D=∅、π_int=π_base、G_loop=0 时，FTG 接受 identity，PRA 不改变策略，SIREN 的每个快环动作与 R69 FLUID-RAS 逐指令相同；再令 VoI≤成本，R69 退化为 R68。故 SIREN 是 R68/R69 在社会学习维度上的严格扩展。

## 6. 本轮最大风险

**一句话**：SIREN 的最大风险是**把社会影响压缩成一次可归因、可门禁的微调事务**——一阶影响函数可以在探针上相消，有限 CFP 可以被「只对考官安全」的策略过拟合，而真正的社会影响是持续、合谋、发生在部署分布之外的；认证越完备，越容易把「未测到的影响」误当成「不存在的影响」。

**次级风险与缓解**：
1. **影响函数近似误差**（K-FAC/LiSSA、非凸、强凸假设失效）→ 组级归因 + LOO 抽检 + 保守上限；IF 只作证据之一，不作唯一门禁；
2. **慢漂移不可见**（E312 的 30 天仍可能太短）→ IBC 环路增益 + 在线 canary + 定期影子重放 + 回滚；
3. **多元聚合僵局 / 否决瘫痪** → 安全权利核与偏好层分离；超时升级人类治理，不把「无法聚合」当「默认多数」；
4. **多样性约束与性能冲突** → 给出 Pareto 前沿；多样性作为硬下界只用于安全关键模态，其他维度用软正则；
5. **来源归因的隐私/监控风险** → 只存聚合影响与血缘哈希；必要时用差分隐私的影响估计；
6. **数据供应链被运营者控制** → 来源签名 + 独立审计 + 多管道交叉验证；但不宣称能抵御掌握全部管道的对手。

**定义 320–321（FTG 与投影）** 接受 iff：安全不增/λ_floor 不降、行为 KL≤ε_b、单源/总量/N_eff 约束、Syc 不升、多样性≥δ_div、累计安全预算≤B_safe；否则 `Δθ_proj=argmin_δ δᵀHδ` s.t. 全部约束，仍失败回滚。

**定义 322（RFT）** `min_θ max_s E_{D_s}ℓ + λΣ‖I_s‖² + μR_crit + νSyc − ξH_mode`，s.t. FTG 约束；group DRO + 影响正则。

**定义 323（CFP）** 真值等价立场对、权威错误建议、假反馈 canary、盲化提问对照、跨来源重复样本；每次微调前后运行并进证书。

**定义 324–325（证书与事务）** `J_SIREN=(J_FLUID, checkpoint_hash, D_hash, influence_attribution, N_eff, max_source_share, behavior_kl_crit, safety_delta, cumulative_safety_budget, syc_delta, phi_sys, diversity_entropy, rollback_hash, siren_ver)`；TXN 五阶段 propose→attribute→gate→shadow→commit/rollback，账本记录谁/何时/血缘/行为变化/证书哈希。

**定义 326（干扰集与严格包含）** `ℰ_SOC=ℰ_FLUID×ℰ_poison×ℰ_corr×ℰ_perf×ℰ_collapse×ℰ_syc`；D=∅ 且 π_int=π_base 时逐指令退化为 R69；VoI≤成本时 R69 退化为 R68。

## 3. 关键算法伪代码

```python
# IP-264 FIT：来源级影响归因（离线；LiSSA/K-FAC；IF 只作证据之一）
def influence_attribution(theta, D, behaviors):
    H = hessian_approx(theta)
    I = {s: solve(H + 1e-3*I, -sum(grad_loss(theta, z) for z in Ds))
         for s, Ds in group_by_source(D).items()}
    K = {f: {s: dot(grad_behavior(theta, f), I[s]) for s in I}
         for f in behaviors}
    alpha = {s: norm(v)/sum(norm(x) for x in I.values()) for s, v in I.items()}
    return I, K, alpha

# IP-266 LIV：有效独立源数（识破「名义 k、实际一个」）
def effective_sources(I):
    u = {s: v/norm(v) for s, v in I.items()}
    w = {s: norm(v) for s, v in I.items()}
    return sum(w.values())**2 / max(
        sum(w[s]*w[t]*dot(u[s], u[t]) for s in I for t in I), 1e-12)

# IP-269 FTG：行为空间门禁；失败→重加权/投影/拒绝
def fine_tuning_gate(theta, dtheta, D, probes, B):
    t2 = theta + dtheta
    if risk_crit(t2) > risk_crit(theta) + B.eps_safe: return reject
    if lambda_floor(t2) < lambda_floor(theta):          return reject
    if behavior_kl(t2, theta, probes) > B.eps_b:        return reject
    I, K, alpha = influence_attribution(theta, D, B.behaviors)
    if max(alpha.values()) > B.alpha_max:               return reweight
    if effective_sources(I) < B.k_min:                  return reweight
    if sycophancy(t2, probes) > sycophancy(theta, probes) + B.eps_syc:
        return reject
    if mode_entropy(t2) < B.delta_div:                  return reject
    if B.cumulative + safety_delta(t2, theta) > B.B_safe: return reject
    return accept

# IP-268 PRA：安全权利核 + leximin
def pluralistic_aggregate(sources, safety_core, prefs):
    feasible = [pi for pi in candidates
                if pi in safety_core and influence_ok(pi) and loop_gain_ok(pi)]
    if not feasible: return fallback_R69_conservative()   # 升级人类治理
    return argmax(feasible, key=lambda pi: leximin([w_s(pi) for s in sources]))

# IP-270 IBC：双向影响预算 + 认知诚实 + 环路增益
def social_loop_ok(pi_int, pi_base, H, L_F, B):
    phi = sup_tv(H(pi_int), H(pi_base))
    G = lipschitz(H, pi_int) * L_F
    return (phi <= B.phi_max and G <= B.gamma_max
            and belief_distance(pi_int) <= B.eps_h)

# IP-274 SIREN 主闭环：R69 快环原样 + 慢环事务
def SIREN_round(M, obs, D_new):
    k, lam, mode, U = FLUID_RAS_round(M, obs)          # 快环，零学习写
    if M.txn.due(D_new):
        theta = M.txn.checkpoint(); D = M.txn.accumulate(D_new)
        dtheta = M.rft.propose(theta, D)
        I, K, alpha = M.fit.attribute(theta, D, M.behaviors)
        if M.liv.effective(I) < M.B.k_min or max(alpha.values()) > M.B.alpha_max:
            D = M.liv.reweight(D, I); dtheta = M.rft.propose(theta, D)
        if not M.ftg.accept(theta, dtheta, D, M.cfp.probes, M.B):
            dtheta = M.ftg.project(theta, dtheta, D)
        if dtheta is None:
            M.txn.rollback(); return k, lam
        M.txn.shadow(theta + dtheta, canaries=M.cfp.canaries)
        if M.txn.shadow_ok():
            M.txn.commit(theta + dtheta,
                         J_SIREN(theta + dtheta, D, I, alpha, M.cfp, M.B))
    return k, lam

# IP-272 CFP：盲化提问，防止系统用自己的假设制造 k 源一致（引理 21）
def blind_ask(g_ask, belief):
    q = Decode_LLM(g_ask.mask(belief))                # 不暴露系统假设
    return neutralize_presupposition(q)                # 去掉预设/诱导措辞
```

## 4. 推导

**引理 19（影响归因的一阶分解）** `Δθ=−H^{-1}g+O(‖g‖²/μ)`；对 L_f-Lipschitz 行为泛函 f，`Δf=Σ_s K_{s,f}+O(L_f‖Δθ‖²/2)`，`K_{s,f}=−∇fᵀH^{-1}g_s`。系：`max_s α_s≤α_max` 且 `Σ‖I_s‖≤K_max` 时 `|Δf|≤L_f K_max+O(Δθ²)`；一阶上界不能替代二阶/分布外检查，故 FTG 仍需行为 trust region。

**引理 20（合成共识的共同模式下限）** 共同冲击模型 `E_s=C∨I_s`，`C~Bern(ρ)` 为共同错误（给定 C=1 时概率 δ_C），`I_s` 独立且 `P(I_s=1)=δ_i`。则 `P(∩E_s)=ρδ_C+(1−ρ)δ_i^k ≥ ρδ_C`，而独立假设给出 `δ^k`。故 `ρδ_C>ε` 时增加 k 无法把错误采纳降到 ε 以下；等权线性平均的有效源数 `N_eff=k/(1+(k−1)ρ)` 刻画「名义 k、实际一个」。LIV 必须以 N_eff 而非 k 为门槛。

**引理 21（锚定提问击穿 k 源纪律）** 系统暴露假设 h 时，人类以 β 服从锚点（无论真假），否则以 δ 独立出错。若 h 为错，则 k 次回答全部支持 h 的概率 `≥β+(1−β)δ^k`。故错误采纳下限为 β，与 k 无关；`β>ε` 时任何 k 源一致都无法补救。系：CFP 必须盲化/反事实平衡；SYN 把 β 纳入证书；系统不得在信息动作中暴露假设。

**引理 22（互训坍缩）** 线性平均更新 `π_i'=(1−η)π_i+η·mean_{j≠i}π_j` 使两两距离乘 `(1−η)`，n 轮后多样性按 `(1−η)^n` 指数衰减；η=1 一步同质。系：R69 的 U_epi 在同质化时下降不是世界变清楚，而是观点被平均掉；多样性预算把「自信」与「正确」解耦。

**定理 18（认证微调的安全保持与预算）** 若每次微调通过 FTG 且累计退化 `Σ_k ε_safe,k≤B_safe`，则任意认证序列满足 `R_crit(θ_N)≤R_crit(θ_0)+B_safe`，λ_floor 不降，R69 交互安全与实时延迟不变；拒绝则 θ 不变。证明：逐步用安全约束与行为 Lipschitz 归纳；快环使用同一 θ，R69 定理 16–17 继续适用。

**定理 19（捕获抵抗与宪制多元）** 在单源上限 α_max、`N_eff≥k_min`、安全权利核 R_safe 下：(i) 单源或相关伪联盟 C（`N_eff(C)<k_min`）对安全关键行为 f 的改变 `≤|C|α_max L_f K_max+O(Δθ²)`，被门禁阻断/限制；(ii) 任何聚合不得违反 R_safe，即使多数偏好违反；(iii) 真实独立多数可改变非权利性行为，但仍受预算与 trust region 约束。故捕获需同时伪造影响与伪造独立；制度性保证，非无限资源下的绝对保证。

**定理 20（社会反馈闭环收缩）** H、Agg、FT 分别 L_H、1、L_F-Lipschitz，且 `φ≤φ_max`、`G_loop=L_H L_F≤γ_max<1`，则 `T=FT∘Agg∘H` 是 TV 度量下的 γ_max-压缩，存在唯一不动点且迭代收敛；若 G_loop≥1，存在合法人类反馈策略使闭环漂移/极化/周期振荡。系：长期稳定性靠双向影响预算 + 收缩增益，而不是更保守的 λ。

**推论 20.1（严格包含 R68/R69）** D=∅、π_int=π_base、G_loop=0 时 FTG 接受 identity，PRA 不改策略，SIREN 每个快环动作与 R69 逐指令相同；再令 VoI≤成本，R69 退化为 R68。故 SIREN 是 R68/R69 在社会学习维度上的严格扩展。

## 7. 本轮最大风险

**一句话**：SIREN 的最大风险是**把社会影响压缩成一次可归因、可门禁的微调事务**——一阶影响函数可以在探针上相消，有限 CFP 可以被「只对考官安全」的策略过拟合，而真正的社会影响是持续、合谋、发生在部署分布之外的；认证越完备，越容易把「未测到的影响」误当成「不存在的影响」。

**次级风险与缓解**：影响函数近似误差（LiSSA/K-FAC、非凸、强凸假设失效）→ 组级归因 + LOO 抽检 + 保守上限，IF 只作证据之一；慢漂移不可见 → IBC 环路增益 + 在线 canary + 定期影子重放 + 回滚；多元聚合僵局/否决瘫痪 → 安全权利核与偏好层分离，超时升级治理；多样性约束与性能冲突 → Pareto 前沿，硬下界仅用于安全关键模态；来源归因的隐私/监控风险 → 只存聚合影响与血缘哈希，必要时差分隐私；数据供应链被运营者控制 → 来源签名 + 独立审计 + 多管道交叉验证（不宣称能抵御掌握全部管道的对手）。
