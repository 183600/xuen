# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 2 轮；本轮灵感：「通用机器人平台」×「多模态交互」）

> 第 67 轮 SimRAS 把 RAS 升级为「离线仿真 + 世界模型 + 视觉问答审计」，解决了「未来风险如何演化、如何可解释地审计」。但它悄悄绑定在**单一具身、单一传感/交互配置**上：`Enc/dyn_head/fault_head` 假设观测维度与动力学固定，`VQAuditor` 假设只有视觉可审计。通用机器人平台恰恰要跨形态（机械臂/移动底盘/人形/外骨骼）、跨传感器套件（有无力觉/触觉/深度）、跨用户与交互通道（语音/手势/注视/触觉/AR）。
>
> 更根本的是：**多模态交互不是被动增加的传感器，而是机器人可主动选择的控制动作**。询问、注视、手势、预览既降低意图不确定性，又改变人的情绪、认知负荷与信任——**探测本身会制造风险**。
>
> 本轮命题：**把 SimRAS 的「单具身/单模态前瞻闭环」升级为「跨具身、跨模态的对偶控制闭环」**——用具身-模态合同（EMC）使证书可迁移，用交互模态路由器（IMR）把"问不问、怎么问"变成带信息增益与扰动风险的对偶控制，用跨模态一致性证书（CCC）保证模态缺失/冲突下的安全兜底。代号 **MOSAIC**（Multimodal Open-platform Safety via Adaptive Interaction Closure）。

## 0. 直觉与动机

**灵感 1（通用机器人平台 → 安全证书要"可迁移"，而不只是"可复现"）**
直觉：SimRAS 的证书像一份只在某台机器上有效的体检报告，换一台机器就作废。通用平台真正需要的是一份**可移植的保险契约**：每个平台提供一个适配器 `A_p`，把它的观测/动作翻译到规范空间；只要证明 `A_p` **保持风险序**（risk-preserving），证书就能从规范空间"拉回"到平台 `p`。数学上这是一个 **Galois 连接**：平台状态格与规范风险格之间的单调伴随函子。安全不是某个场景的属性，而是一个**函子**——它把平台的态射（动作）映成风险空间的态射。

**灵感 2（多模态交互 → 观测算子本身是动作）**
直觉：经典估计里"看得更多"总是更好；但交互不是免费的。对一个紧张的用户开口询问可能让他更紧张（扰动风险），对一个熟练用户则是低成本高信息。也就是说，**机器人选择模态 `m` 和内容 `c` 时，同时在控制人的状态、也在学习人的状态**——这是 Feldbaum 的**对偶控制**：动作既控制又探测。好的交互策略不是"尽量多问"，而是选**单位扰动下信息增益最大**的模态。

**灵感 3（模态格 → 让"更多模态"单调地更安全）**
直觉：语音带宽高但侵入性强；注视带宽低但侵入弱；触觉最确定但最冒犯。它们不应被简单加权平均，而应组织成一个**偏序（模态格）**。安全证书取所有激活模态的**交（meet）**：每个模态都必须"点头"。于是增加模态只会让证书更严，绝不会更松——这正好补上第 67 轮"世界模型过度自信 → 放宽"的漏洞。若两个模态互相矛盾（语音说"停"、手势说"继续"），格落到 ⊥，触发保守回退。

**灵感 4（三灵感合流 → MOSAIC 的八段流水线）**
1. **EMC**：平台适配 → 规范风险等价状态；
2. **HeteroWM**：带具身 token / 模态 token 的异构世界模型，模态 dropout 训练；
3. **HRM**：人类交互响应模型，把情绪/信任/负荷当作内生状态；
4. **IMR**：对偶控制路由器，选 `u* = argmax [IG - κΔR - c]`；
5. **C-MOSAIC**：在合同 + 模态格 + 扰动界下求认证前缀；
6. **MRS**：控制律加入交互动作与扰动补偿；
7. **PolyAuditor**：跨视频/语言/手势/注视的多模态因果审计；
8. **CCC**：在模态格 meet 上合成最终证书。

**灵感 5（SimRAS 组件升级映射）**
- WorldModel → **HeteroWM**：`(具身 token, 模态 mask)` 条件化，规范化潜空间 `z`；
- VQAuditor → **PolyAuditor**：多流 grounding，输出 `grounding_score`，低于阈值即弃用；
- C-RAS-WM → **C-MOSAIC**：`k* = min(k_VISTA, k_emo, k_wm, k_contract, k_modal, m)`；
- ERS-WM → **MRS**：交互动作 `u*` 与 `τ_cmd` 联合优化；
- AIC → **AIC-MOSAIC**：新增 ℰ_embodiment、ℰ_modality、ℰ_dual、ℰ_culture；
- J_SimRAS → **J_MOSAIC**：新增 contract_hash、modality_set、router_trace、dual_gain_lb、ccc_flag、hrm_ver。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（MOSAIC 总览）** `MOSAIC = (EMC, HeteroWM, HRM, IMR, C-MOSAIC, MRS, PolyAuditor, CCC)`。定位：把 SimRAS 的「单具身前瞻闭环」升级为「跨具身、跨模态的对偶控制闭环」。不变式：合同编译与 PolyAuditor 在离线/异步流；实时流只做适配、路由、认证前缀与控制，零学习写操作。
- **定义 267（模态集与模态格）** 交互模态集 `M = {m_sp 语音, m_ge 手势, m_gz 注视, m_tc 触觉, m_vp 视觉预览, m_hp 触觉提示}`。每个模态带三元组 `(r_m 可靠度, ι_m 侵入度, c_m 成本)`。对子集 `S ⊆ M`，融合观测 `y_S = ⊕_{m∈S} y_m`，冲突度 `conf(S) = max_{m,m'∈S} KL(p(z|y_m) ‖ p(z|y_{m'}))`。证书格：`Cert(S) = ⋀_{m∈S} Cert_m`，`Cert(∅) = ⊤`，满足单调性 `S ⊆ T ⇒ Cert(T) ⪯ Cert(S)`。
- **定义 268（交互动作）** `u = (m, c) ∈ U_int`，`m ∈ M` 为通道，`c ∈ C_m` 为内容（问句、指向、预览帧）。`u = ∅` 表示静默。交互动作与物理动作 `a_t` 构成联合动作 `(a_t, u_t)`。
- **定义 269（具身-模态合同 EMC）** 对平台 `p = (具身, 传感器套件, 执行器)`，合同为二元组 `A_p = (α_p, φ_p)`：`α_p: O_p × A_p → O_c × A_c` 把平台观测/动作映到规范空间；`φ_p: ℝ → ℝ` 单调，把规范安全裕度映回平台裕度。`A_p` **风险保持** ⇔ `∀a: ρ_safe^p(a) ≥ φ_p(ρ_safe^c(α_p(a)))`。
- **定义 270（合同距离与迁移误差）** `d_EMC(p,q) = ‖α_p - α_q‖_Lip + ‖φ_p - φ_q‖_∞`。风险迁移误差 `ε_trans(p→q) = L_EMC·d_EMC(p,q) + ε_align`，`L_EMC` 为规范风险函数的 Lipschitz 常数。
- **定义 271（人类交互响应模型 HRM）** `h_{t+1} ~ Q_ψ(h_{t+1} | h_t, u_t, a_t, s_t)`，`h_t = (π_t 情绪, trust_t 信任, load_t 认知负荷, intent_t 意图)`；`π_t = g(h_t)`。HRM 使人类状态**内生**：机器人的交互动作是其输入。
- **定义 272（对偶控制风险）** 对探测 `u`：
```
ΔR(u) = E_{h_{t+1}~Q_ψ}[R_emotion(g(h_{t+1})) | do(u)] - E[R_emotion(g(h_{t+1})) | do(∅)]
```
即"问一次"相对"不问"造成的瞬时风险变化；硬约束 `ΔR(u) ≤ ΔR_max`。
- **定义 273（交互信息增益）** `IG(u) = I(h_t; y_t^u | history)`，`y_t^u` 为选择模态 `m` 后的观测。高斯近似下 `IG(u) = ½ log det(Σ_post^{-1} Σ_prior)`。
- **定义 274（交互模态路由器 IMR）**
```
u* = argmax_{u ∈ U_int, ΔR(u) ≤ ΔR_max, c(u) ≤ c_max} [ IG(u) - κ·ΔR(u) - c(u) ]
```
若可行集为空或最优值 `< 0`，取 `u* = ∅`（宁可少问，不制造风险）。
- **定义 275（异构世界模型 HeteroWM）** `HeteroWM_θ = (Enc_θ, dyn_θ, emo_θ, fault_θ, emb_θ, mod_θ)`，输入 `(o_t, a_t, e_p 具身 token, mask_S 模态 mask)`，编码到规范潜状态 `z_t`；训练时对 `mask_S` 做 dropout、对 `e_p` 做随机化。损失 `L = L_recon + λ_e L_emo + λ_f L_fault + λ_a L_align + λ_m L_modalid`，`L_align` 强制不同 `e_p` 的同一语义轨迹在 `z` 上对齐。
- **定义 276（跨具身潜空间对齐）** 对平台 `p,q` 与同一语义事件 `ξ`，`d_align(p,q) = E_ξ ‖z^p(ξ) - z^q(ξ)‖`。证书可用性要求 `d_align(p,q) ≤ τ_align`。
- **定义 277（多模态审计员 PolyAuditor）** `PolyAuditor = (VideoRenderer, ASR, GestureEncoder, GazeEncoder, VQA_Model, Grounder, StructParser)`。输入 WM 滚动的多流：渲染视频、语言转写、骨架序列、注视热图；输出 `AuditReport = {risk_factors[], counterfactuals[], λ_adjust, grounding_score}`。
- **定义 278（跨模态 grounding 分）** `grounding_score = 1 - min_{s≠s'} d_sem(claim_s, evidence_{s'})`。`grounding_score < τ_g` 时审计结论不可信，弃用。
- **定义 279（跨模态一致性证书 CCC）** `CCC(S) = (⋀_{m∈S} Cert_m) ∧ (conf(S) < τ_conflict) ∧ (grounding_score ≥ τ_g)`。任一合取项为假则 `CCC = ⊥`，触发保守回退 `λ_risk ≥ 0.9 ∧ k* = 0`。
- **定义 280（C-MOSAIC 认证前缀）**
```
k_mosaic = max{k' ≤ m : ∀i≤k', ∀m∈S: λ_risk_{t+i}·ρ_safe^m(α_p(a_{t+i})) ≥ 0 ∧ conf(S) < τ_conflict}
k* = min(k_VISTA, k_emo, k_wm, k_contract, k_mosaic, m)
```
其中 `k_contract` 由合同风险保持条件给出。
- **定义 281（MRS 交互塑造控制律）** 联合优化：
```
(τ_cmd, u*) = argmin_{τ,u} [ R_emotion(π_{t+1}) + c_fault·P(H_{t+1}≠H0) + κ·ΔR(u) + c(u) ]
s.t. ΔR(u) ≤ ΔR_max, λ_risk·ρ_safe ≥ 0
```
- **定义 282（AIC-MOSAIC 干扰集）** `ℰ_MOSAIC = ℰ_SimRAS × ℰ_embodiment × ℰ_modality × ℰ_dual × ℰ_culture`，其中 `ℰ_embodiment={动力学偏移, 传感器缺失, 执行器饱和}`，`ℰ_modality={模态缺失, 模态冲突, 通道欺骗}`，`ℰ_dual={探测诱发扰动, 探测延迟, 探测过载}`，`ℰ_culture={敬语/直白差异, 手势歧义, 注视禁忌}`。
- **定义 283（J_MOSAIC 证书）**
```
J_MOSAIC = (J_SimRAS, contract_hash_p, modality_set S, router_trace, dual_gain_lb, ccc_flag, hrm_ver)
```
Valid ⇔ `Valid(J_SimRAS) ∧ EMC(p) 已认证 ∧ ccc_flag = True ∧ ΔR_realized ≤ ΔR_max`。
- **定义 284（在线/离线不变式）** 离线流：EMC 编译、HeteroWM 预训练、HRM 标定、PolyAuditor 审计缓冲；实时流：`α_p` 适配、IMR 路由、C-MOSAIC 认证、MRS 控制、CCC 校验。PolyAuditor 异步，周期 ≤ 100ms，不阻塞 `k*` 决策。
- **定义 285（合同失效回退）** 若 `d_align(p, p0) > τ_align` 或 EMC 未认证，平台 `p` 禁用跨具身证书，退化为平台本地 RAS（`k* = k_ras`，`λ_risk ≥ 0.8`）。

## 2. 关键算法骨架

```python
class EmbodimentModalityContract:
    def __init__(self, alpha_p, phi_p, lip=1.0):
        self.alpha, self.phi, self.lip = alpha_p, phi_p, lip

    def to_canonical(self, o_p, a_p):
        return self.alpha(o_p, a_p)

    def risk_preserved(self, a_p, rho_c):
        return self.safety_margin_p(a_p) >= self.phi(rho_c)

    def distance(self, other):
        return lip_dist(self.alpha, other.alpha) + inf_norm(self.phi, other.phi)


class InteractionModalityRouter:
    def __init__(self, hrm, kappa=0.5, dR_max=0.1, c_max=1.0):
        self.hrm, self.kappa = hrm, kappa
        self.dR_max, self.c_max = dR_max, c_max

    def select(self, h_t, scene, history):
        best_u, best_val = None, 0.0
        for m in MODALITIES:
            for c in CONTENT[m](scene):
                u = (m, c)
                dR = self.hrm.perturbation_risk(h_t, u, scene)
                if dR > self.dR_max or cost(u) > self.c_max:
                    continue
                ig = self.info_gain(h_t, u, history)
                val = ig - self.kappa * dR - cost(u)
                if val > best_val:
                    best_u, best_val = u, val
        return best_u if best_u is not None else NULL_ACTION  # 宁可静默


class HeteroWorldModel:
    def __init__(self, enc, dyn, emo, fault, emb_token, mod_enc):
        self.enc, self.dyn, self.emo, self.fault = enc, dyn, emo, fault
        self.emb, self.mod = emb_token, mod_enc

    def rollout(self, o_t, a_seq, e_p, mask_S, k=5):
        z = self.enc(o_t, self.emb(e_p), self.mod(mask_S))
        out = []
        for a in a_seq[:k]:
            z = self.dyn(z, a, self.emb(e_p))
            out.append({'pi': self.emo(z), 'pH': self.fault(z)})
        return out


class CrossModalCertificate:
    def __init__(self, tau_conflict=0.4, tau_g=0.7):
        self.tau_conflict, self.tau_g = tau_conflict, tau_g

    def evaluate(self, S, per_modality_certs, conf_S, grounding_score):
        certs = [per_modality_certs[m] for m in S]
        ok = all(c >= 0 for c in certs)
        ok = ok and conf_S < self.tau_conflict
        ok = ok and grounding_score >= self.tau_g
        return {'ok': ok, 'flag': 'CCC_OK' if ok else 'CCC_BOTTOM',
                'min_cert': min(certs) if certs else 1.0}


def MOSAIC_round(M, obs, e_p):
    # 0) 具身-模态合同：适配到规范空间
    o_c, a_c = M.emc[e_p].to_canonical(obs['o'], obs['a'])
    S = M.active_modalities            # 当前可用交互模态集合

    # 1) 异构世界模型滚动（带具身/模态 token）
    act_seq = M.vista.ach.propose_actions(o_c, H=M.vista.H, steps=5)
    wm_preds = M.hetero_wm.rollout(o_c, act_seq, e_p, mask_of(S), k=5)

    # 2) 人类响应模型 + 交互模态路由（对偶控制）
    h_t = M.hrm.infer(obs['multimodal'], history=M.history)
    u_star = M.imr.select(h_t, o_c, M.history)

    # 3) 若选择探测，先预测其扰动风险，再执行
    dR = 0.0
    if u_star is not None:
        dR = M.hrm.perturbation_risk(h_t, u_star, o_c)
        if dR <= M.imr.dR_max:
            M.execute_interaction(u_star)
            h_t = M.hrm.update(h_t, u_star, o_c)   # 探测后重估

    # 4) 多模态审计（异步）与跨模态一致性证书
    grounding = M.poly_auditor.grounding_score(wm_preds, obs['multimodal'])
    per_cert = {m: M.cert_margin(o_c, m) for m in S}
    ccc = M.ccc.evaluate(S, per_cert, conf(S), grounding)

    if not ccc['ok']:
        return 0, 0.9, ccc, wm_preds, u_star   # 保守回退

    # 5) C-MOSAIC 认证前缀
    k_wm = M.certified_wm_prefix(act_seq, wm_preds)
    k_contract = M.certified_contract_prefix(act_seq, e_p)
    k_mosaic = M.certified_mosaic_prefix(act_seq, S, wm_preds)
    k_star = min(M.vista.m, k_wm, k_contract, k_mosaic)
    λ_risk = M.efs_wm.risk_scale(M.joint_post) * (1 - 0.2 * dR)

    # 6) MRS：物理动作 + 交互动作联合塑造
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(act_seq[:k_star])
    tau_cmd = M.mrs.shaping(tau_cmd, u_star, h_t, λ_risk)

    return k_star, λ_risk, ccc, wm_preds, u_star
```

## 3. 推导

**引理 13（对偶探测的瞬时风险界）** 若 `ΔR(u) ≤ ΔR_max` 且探测前 `R_emotion ≤ R_max`，则探测后 `R_emotion ≤ R_max + ΔR_max`；若 C-MOSAIC 在**预测的探测后状态**上仍满足 `λ_risk·ρ_safe ≥ 0`，则探测不引入新的安全违规。

**引理 14（合同迁移的风险差界）** 对已认证合同 `A_p, A_q`，`|R^p(a) - R^q(α_q^{-1}∘α_p(a))| ≤ L_EMC·d_EMC(p,q) + ε_align`。即迁移误差随合同距离线性增长，`p=q` 时退化为 0。

**引理 15（模态格的误接受下界）** 若每个模态的误接受概率 `P_fa(m) ≤ ε_m`，且冲突漏检 `P_miss(conf) ≤ ε_c`，则 `P_fa(S) ≤ min_{m∈S} ε_m + ε_c`。因此增加模态只会降低误接受概率，绝不会提高——这是"更安全单调性"。

**定理 14（MOSAIC 端到端证书在异构平台下的保持）** 在 A87–A91、SimRAS 定理 11、及引理 13–15 下：
1. `P(|τ_cmd - τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_contract + α_modal + α_router`；
2. `k*_MOSAIC ≥ min(k_VISTA, k_emo, k_wm, k_contract, k_mosaic)·(1 - δ_lip)`；
3. 合同未认证或 `CCC=⊥` ⇒ `k*=0 ∧ λ_risk ≥ 0.9`（自动退化到本地 RAS）；
4. `d_align(p,p0) > τ_align ⇒ 跨具身证书禁用`。

**定理 15（对偶控制的探测收益判据）** 在 HRM 误差 `‖Q_ψ - Q*‖ ≤ ε_H` 下，探测的实际风险可能超出预测 `L_H·ε_H`。因此 IMR 只应在
```
IG(u) ≥ (κ + L_H·ε_H/ΔR_max)·ΔR(u) + c(u)
```
时执行探测；否则静默。该判据保证"探测的期望收益严格大于其最坏扰动"，从而避免把"提问"变成"制造风险"。

**定理 16（多模态审计的幻觉抑制）** 若 PolyAuditor 单模态幻觉率为 `h_m`，跨模态 grounding 后幻觉率满足 `h_S ≤ ∏_{m∈S} h_m^{1/|S|}·exp(-γ_g·grounding_score)`。当 `grounding_score < τ_g` 时弃用审计并回退 CCC，避免 SimRAS 中"VQA 幻觉 → 过度放宽"的路径。

## 6. 本轮最大风险

**一句话**：MOSAIC 把「交互」当作可优化其信息增益与扰动风险的对偶控制动作，但驱动该优化的**人类响应模型 HRM 本身跨用户、跨文化、跨平台不可靠**——一旦 HRM 系统性失配，路由器可能对某些亚群反复选择"看似高信息、实则高扰动"的探测（如对焦虑用户频繁追问），使证书在错误的响应模型下自我认证、把交互通道变成**隐蔽的风险执行器**，并逐步侵蚀信任。这是本轮所有理论依赖的核心假设：**人类对交互动作的响应可学习、可迁移，且其扰动风险上界可在离线标定并被硬约束可靠执行**。

**次级风险与缓解**：
1. **HRM 失配**：用分层贝叶斯 + 人群先验收缩；对少数群体设保守先验，`ε_H` 大时自动降低探测频率（定理 15）；
2. **合同距离被低估**：EMC 需在留出具身上做对抗验证；`d_align > τ_align` 必须硬回退；
3. **模态冲突导致证书频繁落 ⊥**：用冲突消解协议（时间戳优先/用户显式确认），而非直接停机；
4. **交互延迟**：语音/手势有 300–800ms 延迟，需把 `u_t` 时间戳纳入 CCC，避免使用过期证据；
5. **多模态审计成本**：PolyAuditor 需 4 路编码，嵌入式平台改用蒸馏小模型 + 事件触发。

## 2. 形式化定义（完整版）

**定义 266（MOSAIC 总览）** MOSAIC 把 SimRAS 的「单具身前瞻闭环」升级为「跨具身、跨模态的对偶控制闭环」：
```
MOSAIC = (EMC, HeteroWM, HRM, IMR, C-MOSAIC, MRS, PolyAuditor, CCC)
```
不变式：合同编译、HeteroWM 预训练、HRM 标定、PolyAuditor 审计在离线/异步流；实时流只做适配、路由、认证前缀与控制，零学习写操作。

**定义 267（模态集与模态格）** `M = {m_sp 语音, m_ge 手势, m_gz 注视, m_tc 触觉, m_vp 视觉预览, m_hp 触觉提示}`；每模态带 `(r_m, ι_m, c_m)`。对 `S ⊆ M`：
```
y_S = ⊕_{m∈S} y_m
conf(S) = max_{m,m'∈S} KL(p(z|y_m) ‖ p(z|y_{m'}))
Cert(S) = ⋀_{m∈S} Cert_m,  Cert(∅) = ⊤
S ⊆ T ⇒ Cert(T) ⪯ Cert(S)     # 单调性：加模态只会更安全
```

**定义 268（交互动作）** `u = (m, c) ∈ U_int`，与物理动作 `a_t` 构成联合动作 `(a_t, u_t)`；`u = ∅` 为静默。

**定义 269（具身-模态合同 EMC）** `A_p = (α_p, φ_p)`，`α_p: O_p×A_p → O_c×A_c`，`φ_p` 单调。风险保持：
```
∀a: ρ_safe^p(a) ≥ φ_p(ρ_safe^c(α_p(a)))
```

**定义 270（合同距离与迁移误差）**
```
d_EMC(p,q) = ‖α_p-α_q‖_Lip + ‖φ_p-φ_q‖_∞
ε_trans(p→q) = L_EMC·d_EMC(p,q) + ε_align
```

**定义 271（人类交互响应模型 HRM）** `h_{t+1} ~ Q_ψ(h_{t+1}|h_t,u_t,a_t,s_t)`，`π_t = g(h_t)`；人类状态内生，交互动作是其输入。

**定义 272（对偶控制风险）**
```
ΔR(u) = E_{h_{t+1}~Q_ψ}[R_emotion(g(h_{t+1})) | do(u)]
      - E[R_emotion(g(h_{t+1})) | do(∅)]
```
硬约束 `ΔR(u) ≤ ΔR_max`。

**定义 273（交互信息增益）** `IG(u) = I(h_t; y_t^u | history)`；高斯近似 `IG(u)=½ log det(Σ_post^{-1}Σ_prior)`。

**定义 274（交互模态路由器 IMR）**
```
u* = argmax_{u: ΔR(u)≤ΔR_max, c(u)≤c_max} [IG(u) - κ·ΔR(u) - c(u)]
```
可行集为空或最优值 `<0` 时取 `u*=∅`。

**定义 275（异构世界模型 HeteroWM）** `HeteroWM_θ = (Enc,dyn,emo,fault,emb,mod)`，输入 `(o_t,a_t,e_p,mask_S)`，编码到规范潜状态 `z_t`；训练做模态 dropout + 具身随机化：
```
L = L_recon + λ_e L_emo + λ_f L_fault + λ_a L_align + λ_m L_modalid
```

**定义 276（跨具身潜空间对齐）** `d_align(p,q) = E_ξ‖z^p(ξ)-z^q(ξ)‖`；证书可用要求 `d_align ≤ τ_align`。

**定义 277（多模态审计员 PolyAuditor）** `PolyAuditor = (VideoRenderer, ASR, GestureEncoder, GazeEncoder, VQA_Model, Grounder, StructParser)`；输入多流，输出 `AuditReport = {risk_factors[], counterfactuals[], λ_adjust, grounding_score}`。

**定义 278（跨模态 grounding 分）** `grounding_score = 1 - min_{s≠s'} d_sem(claim_s, evidence_{s'})`；`< τ_g` 时审计不可信。

**定义 279（跨模态一致性证书 CCC）**
```
CCC(S) = (⋀_{m∈S} Cert_m) ∧ (conf(S)<τ_conflict) ∧ (grounding_score≥τ_g)
CCC=⊥ ⇒ λ_risk≥0.9 ∧ k*=0
```

**定义 280（C-MOSAIC 认证前缀）**
```
k_mosaic = max{k'≤m : ∀i≤k', ∀m∈S: λ_risk_{t+i}·ρ_safe^m(α_p(a_{t+i}))≥0 ∧ conf(S)<τ_conflict}
k* = min(k_VISTA, k_emo, k_wm, k_contract, k_mosaic, m)
```

**定义 281（MRS 交互塑造控制律）**
```
(τ_cmd,u*) = argmin_{τ,u} [R_emotion(π_{t+1}) + c_fault·P(H_{t+1}≠H0) + κ·ΔR(u) + c(u)]
s.t. ΔR(u)≤ΔR_max, λ_risk·ρ_safe≥0
```

**定义 282（AIC-MOSAIC 干扰集）** `ℰ_MOSAIC = ℰ_SimRAS×ℰ_embodiment×ℰ_modality×ℰ_dual×ℰ_culture`，其中：

```python
# IP-243 EMC：具身-模态合同
class EmbodimentModalityContract:
    def __init__(self, alpha_p, phi_p, lip=1.0):
        self.alpha, self.phi, self.lip = alpha_p, phi_p, lip

    def to_canonical(self, o_p, a_p):
        return self.alpha(o_p, a_p)

    def risk_preserved(self, a_p, rho_c):
        return self.safety_margin_p(a_p) >= self.phi(rho_c)

    def distance(self, other):
        return lip_dist(self.alpha, other.alpha) + inf_norm(self.phi, other.phi)


# IP-244 IMR：对偶控制路由器
class InteractionModalityRouter:
    def __init__(self, hrm, kappa=0.5, dR_max=0.1, c_max=1.0):
        self.hrm, self.kappa = hrm, kappa
        self.dR_max, self.c_max = dR_max, c_max

    def select(self, h_t, scene, history):
        best_u, best_val = None, 0.0
        for m in MODALITIES:
            for c in CONTENT[m](scene):
                u = (m, c)
                dR = self.hrm.perturbation_risk(h_t, u, scene)
                if dR > self.dR_max or cost(u) > self.c_max:
                    continue
                ig = self.info_gain(h_t, u, history)
                val = ig - self.kappa * dR - cost(u)
                if val > best_val:
                    best_u, best_val = u, val
        return best_u if best_u is not None else NULL_ACTION


# IP-245 HeteroWM：异构世界模型
class HeteroWorldModel:
    def __init__(self, enc, dyn, emo, fault, emb_token, mod_enc):
        self.enc, self.dyn, self.emo, self.fault = enc, dyn, emo, fault
        self.emb, self.mod = emb_token, mod_enc

    def rollout(self, o_t, a_seq, e_p, mask_S, k=5):
        z = self.enc(o_t, self.emb(e_p), self.mod(mask_S))
        out = []
        for a in a_seq[:k]:
            z = self.dyn(z, a, self.emb(e_p))
            out.append({'pi': self.emo(z), 'pH': self.fault(z)})
        return out


# IP-250 CCC：跨模态一致性证书
class CrossModalCertificate:
    def __init__(self, tau_conflict=0.4, tau_g=0.7):
        self.tau_conflict, self.tau_g = tau_conflict, tau_g

    def evaluate(self, S, per_modality_certs, conf_S, grounding_score):
        certs = [per_modality_certs[m] for m in S]
        ok = all(c >= 0 for c in certs)
        ok = ok and conf_S < self.tau_conflict
        ok = ok and grounding_score >= self.tau_g
        return {'ok': ok, 'flag': 'CCC_OK' if ok else 'CCC_BOTTOM',
                'min_cert': min(certs) if certs else 1.0}


# IP-252 MOSAIC 闭环（在线实时环路）
def MOSAIC_round(M, obs, e_p):
    # 0) 具身-模态合同：适配到规范空间
    o_c, a_c = M.emc[e_p].to_canonical(obs['o'], obs['a'])
    S = M.active_modalities

    # 1) 异构世界模型滚动（具身/模态 token）
    act_seq = M.vista.ach.propose_actions(o_c, H=M.vista.H, steps=5)
    wm_preds = M.hetero_wm.rollout(o_c, act_seq, e_p, mask_of(S), k=5)

    # 2) HRM + IMR：对偶控制路由
    h_t = M.hrm.infer(obs['multimodal'], history=M.history)
    u_star = M.imr.select(h_t, o_c, M.history)
    dR = 0.0
    if u_star is not None:
        dR = M.hrm.perturbation_risk(h_t, u_star, o_c)
        if dR <= M.imr.dR_max:
            M.execute_interaction(u_star)
            h_t = M.hrm.update(h_t, u_star, o_c)

    # 3) 多模态审计 + CCC
    grounding = M.poly_auditor.grounding_score(wm_preds, obs['multimodal'])
    per_cert = {m: M.cert_margin(o_c, m) for m in S}
    ccc = M.ccc.evaluate(S, per_cert, conf(S), grounding)
    if not ccc['ok']:
        return 0, 0.9, ccc, wm_preds, u_star   # 保守回退

    # 4) C-MOSAIC 认证前缀
    k_wm = M.certified_wm_prefix(act_seq, wm_preds)
    k_contract = M.certified_contract_prefix(act_seq, e_p)
    k_mosaic = M.certified_mosaic_prefix(act_seq, S, wm_preds)
    k_star = min(M.vista.m, k_wm, k_contract, k_mosaic)
    λ_risk = M.efs_wm.risk_scale(M.joint_post) * (1 - 0.2 * dR)

    # 5) MRS：物理动作 + 交互动作联合塑造
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(act_seq[:k_star])
    tau_cmd = M.mrs.shaping(tau_cmd, u_star, h_t, λ_risk)
    return k_star, λ_risk, ccc, wm_preds, u_star
```

## 4. 推导

**引理 13（对偶探测的瞬时风险界）** 若 `ΔR(u)≤ΔR_max` 且探测前 `R_emotion≤R_max`，则探测后 `R_emotion≤R_max+ΔR_max`；若 C-MOSAIC 在**预测的探测后状态**上仍满足 `λ_risk·ρ_safe≥0`，则探测不引入新的安全违规。

**引理 14（合同迁移的风险差界）** 对已认证合同 `A_p,A_q`：
```
|R^p(a) - R^q(α_q^{-1}∘α_p(a))| ≤ L_EMC·d_EMC(p,q) + ε_align
```
`p=q` 时退化为 0。

**引理 15（模态格的误接受下界）** 若 `P_fa(m)≤ε_m`、冲突漏检 `P_miss(conf)≤ε_c`，则
```
P_fa(S) ≤ min_{m∈S} ε_m + ε_c
```
增加模态只会降低误接受概率，这是「更安全单调性」。

**定理 14（MOSAIC 端到端证书在异构平台下的保持）** 在 A87–A91、SimRAS 定理 11 与引理 13–15 下：
1. `P(|τ_cmd-τ*|>ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_contract + α_modal + α_router`；
2. `k*_MOSAIC ≥ min(k_VISTA,k_emo,k_wm,k_contract,k_mosaic)·(1-δ_lip)`；
3. 合同未认证或 `CCC=⊥` ⇒ `k*=0 ∧ λ_risk≥0.9`；
4. `d_align(p,p0)>τ_align ⇒ 跨具身证书禁用`。

**定理 15（对偶控制的探测收益判据）** 在 HRM 误差 `‖Q_ψ-Q*‖≤ε_H` 下，实际风险可超出预测 `L_H·ε_H`。故 IMR 仅在
```
IG(u) ≥ (κ + L_H·ε_H/ΔR_max)·ΔR(u) + c(u)
```
时执行探测，否则静默；该判据保证探测的期望收益严格大于其最坏扰动。

**定理 16（多模态审计的幻觉抑制）** 单模态幻觉率 `h_m` 经跨模态 grounding 后：
```
h_S ≤ ∏_{m∈S} h_m^{1/|S|} · exp(-γ_g·grounding_score)
```
`grounding_score<τ_g` 时弃用审计并回退 CCC，堵住「VQA 幻觉 → 过度放宽」路径。

## 7. 本轮最大风险

**一句话**：MOSAIC 把「交互」当作可优化其信息增益与扰动风险的对偶控制动作，但驱动该优化的**人类响应模型 HRM 本身跨用户、跨文化、跨平台不可靠**——一旦 HRM 系统性失配，路由器可能对某些亚群反复选择"看似高信息、实则高扰动"的探测，使证书在错误模型下自我认证、把交互通道变成**隐蔽的风险执行器**，并逐步侵蚀信任。这是本轮所有理论依赖的核心假设：**人类对交互动作的响应可学习、可迁移，且其扰动风险上界可在离线标定并被硬约束可靠执行**。
