# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「创新点提炼」×「地形适应」）

> R69 教会系统「去问」：看不清就看，拿不准就问，答完再用 k 个证据源定案。但它在开口之前漏了两个更根本的问题：**(1) 这个问题我到底能不能知道？(2) 我用来回答它的这个机制，到底是不是真的在起作用？**
>
> 当机器人踏上碎石、薄冰、可塌陷沙地，隐藏变量是动力学参数 θ（摩擦 μ、刚度 k、坡度 α、可变形性、黏聚力），而不是 R69 假设的「动作模态」。R69 的 U_epi 隐含一个乐观前提：歧义总能靠一次注视/一句问话消解。可有些 θ 方向对任何**安全**激励都不可辨识——再问也问不出来，只能按最坏情况扛。另一方面，前 69 轮累积了 263 个 IP，绝大多数是对同一招「加一层」的换皮；「不确定就再加一层」本身就是一种认知捷径——它把「我还没想清楚」伪装成「我已经覆盖了」。
>
> 本轮两个灵感各补一刀：
> - **地形适应**把不确定性从「选哪个动作」推进到「隐藏动力学到底能被观测到什么」：可辨识子空间由**激励**决定，而安全约束给可辨识性设了一个硬天花板。
> - **创新点提炼**把「哪些层值得留」从一个叙事问题变成一个可计算问题：只有在「可辨识 × 风险相关」这张 2×2 表上同时成立的机制，才有资格被称为创新点；其余的是叙事、冗余，或**保险**。
>
> 核心命题：**把 epistemic 再分一刀——可激励辨识的（去探）与安全激励下不可辨识的（去扛）；把「创新」定义为「可归因的可辨识差异」，只保留通过相干风险归因的最小机制核，并禁止按平均贡献剪掉尾部保险。** 命名 **DIG-RAS**（Distillation of Identifiable Grounding：可辨识接地蒸馏）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么知道、我又凭什么说我加了新东西？**」——地形是最诚实的审稿人：它只让你知道你能踩出来的那部分。

## 0. 直觉与动机

**灵感 1（地形适应 → 真正隐藏的是动力学，不是动作模态）**
直觉：在平地上，「绕左还是绕右」是动作歧义；在斜坡与冻土上，真正决定生死的是「这块地会不会滑、会不会塌」。前者可以靠多采样看出峰，后者不会因为你多想几个动作就显形——它藏在**转移模型**里。于是 R69 的 `U_epi = H_mode·g(Δ_min)` 只覆盖了「策略输出多峰」这一种可约性；地形引入的是**参数级可约性**：θ 的某些方向能通过本体感觉/探针/短时滑移被估计，另一些方向在任何安全动作下都留不下可观测痕迹。把这两类混成一个标量 U_epi，等于把「再问一句就知道」和「永远问不出来」写进同一个账本。

**灵感 2（可辨识性 → 你只能知道你能激励的东西）**
直觉：摩擦系数不是「看」出来的，是「踩」出来的。更准确地说，参数 θ 只有在动作序列 u 让观测对 θ 敏感时才会在 Fisher 信息矩阵里留下大特征值；否则对应方向落在零空间。控制论里这叫持续激励（persistency of excitation），统计里叫可辨识性。它给出一个残酷但有用的结论：**可辨识性是动作的属性，不是数据的属性**。想估 μ 就得让轮子有相对滑动；但真正危险的地形恰恰不允许你「安全地滑一下」去测。于是出现一条**信息-安全前沿**：安全激励集越小，可辨识的风险方向越少，证书越窄。

**灵感 3（创新点提炼 → 机制也有同一张 2×2 表）**
直觉：把「地形参数」换成「机制贡献」，数学是同构的。一个机制（一层、一个 loss、一个门控）是否值得留，取决于两件事：它的贡献**能不能被实验分辨**（可辨识），以及它**是否影响我们真正在乎的风险**（风险相关）。四格：
- 可辨识 × 风险相关 → **保留**（真创新/承重墙）；
- 可辨识 × 与风险无关 → **剪掉**（可观但无用，最常见的「为创新而创新」）；
- 不可辨识 × 与风险无关 → **降级为叙事**（不可证伪，也不该占用实时预算）；
- 不可辨识 × 风险相关 → **保险**（平均贡献可能为零，只在尾部生效，绝不能按平均值剪）。
这张表把「创新点提炼」从一个写作技巧变成一个有可测判据的蒸馏过程：**创新 = 可归因的可辨识差异**，不是「我又加了一个模块」。

**灵感 4（同构 → 两个灵感共用同一个货币：「可区分性」）**
直觉：地形参数能不能知道，取决于激励能否在观测里把它们区分开；机制贡献能不能声称，取决于实验能否在风险里把它区分开。两者都是「信号 vs 零空间」的问题，都能用同一套 FIM/功效分析的语言写。DIG-RAS 因此不是「又一层」，而是给已有各层配一把**审计尺**：先把不可辨识的部分从「可优化」划到「只能稳健化」，再把不可归因的模块从「创新」划到「叙事或保险」。

**灵感 5（对 R69 的严格包含 → 以及一个新的失败模式）**
直觉：当 θ 完全可辨识（I ≻ 0、泄漏为零）、且机制核被完整保留时，DIG 逐指令退化为 FLUID；当风险相关的不可辨识方向导致泄漏超过阈值时，DIG 在那些方向上退化为 R68 的纯保守（robust margin）。这是「新层必须是旧层严格泛化」的延续。但蒸馏带来一个 R69 没有的失败模式：**按平均贡献提炼，会精确地剪掉只在尾部生效的保险**。R69 的风险是「问错比不问更危险」；R70 的风险是「提炼掉的，恰好是救命的」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（DIG-RAS 总览）** DIG-RAS = (TID, TAP, RID, URG, TCF, DIL, INS, RSK, TRC, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；地形信念与蒸馏均不写实时策略）；
(ii) **最坏情况探针安全**：任何激励只有在当前信念支撑内的**所有**可信 θ 下都通过 C-RAS-WM 认证时才被允许（定义 315）——期望安全不能为探针背书；
(iii) **证书纪律**：风险相关但不可辨识的方向不得用点估计发证书，只能用 robust margin；机制只有在「可辨识 × 风险相关」或「保险豁免」下才可进入创新账本（定义 319–320）。

**定义 311（地形隐变量与风险雅可比）** 地形参数 θ ∈ Θ ⊂ ℝ^d（d ≤ 8：摩擦、刚度、坡度、可变形性等）。转移 x_{t+1}=f_θ(x_t,a_t)+w，观测 y_t=h_θ(x_t,a_t)+v。风险泛函 R(θ,π)（均值或 CVaR_α）。地形信念 b_t(θ)（粒子/因子化）。定义风险雅可比 J_R(θ)=∇_θ R(θ,π)（或次梯度），它把「θ 的哪个方向值得关心」与「θ 的哪个方向可观测」解耦。

**定义 312（激励依赖的可辨识子空间）** 对动作/激励序列 u，Fisher 信息矩阵 I_u(θ)=E[∇_θ log p(y|θ,u) ∇_θ^T log p(y|θ,u)]。特征分解 I_u=Σ_i λ_i v_i v_i^T。给定目标精度 τ，**可辨识子空间** E_u(τ)=span{v_i: λ_i ≥ 1/τ²}，**不可辨识子空间** N_u=E_u^⊥。关键点：E_u 显式依赖 u——这正是「主动激励」的杠杆，也是「持续激励」的形式化。

**定义 313（风险相关可辨识性与泄漏）** 风险相关子空间为 row(J_R)。定义**可辨识**当且仅当 row(J_R) ⊆ E_u(τ)（至多差一个可标定的标量增益）。**风险泄漏** L_u = ‖P_{N_u} J_R‖：风险敏感、却落在不可辨识方向上的那部分。L_u=0 表示「该知道的都能知道」；L_u 大表示「关心的东西恰好看不见」。注意 gauge 自由：θ 常只能辨识到某个函数（如 μ/m 的比值），可辨识的不变量才是合法状态，原始 θ 不是。

**定义 314（地形主动激励 TAP）** 候选探针 𝒰_probe = {足端轻点、短时滑移测试、侧向推、慢速通过、前视注视、变步长}。选择
u* = argmax_{u∈𝒰_probe} [ Δ_risk(u) − c(u) ]，s.t. TC-Safe(u)（定义 315）且预算未超，
其中 Δ_risk(u) = E_y[ tr(Cov(R|b_t)) − tr(Cov(R|b_t,y,u)) ] 是在**风险标量**上的 A/D-最优信息增益，而不是对全 θ 的朴素熵减。收益 ≤ 0 则不探，退回 R69 的 MINT（问/看）或 R68 保守。

**定义 315（最坏情况探针安全 TC-Safe）** u 可采纳当且仅当 ∀θ ∈ support(b_t) 且 b_t(θ) ≥ ε_b，增广动作 (a,u) 都通过 C-RAS-WM 前缀认证，且最坏情形代价 ≤ ε_int。**探针的信息价值不能覆盖安全违规**；这堵死了「为探索而冒险」的漏洞，也直接引出可辨识性天花板（引理 20）。

**定义 316（地形条件化流策略 TCF）** 在 R69 FMP 的速度场上增加条件：v_θ(x_s,s | o_t, φ(θ_∥))，其中 φ 只取**可辨识且 gauge 不变**的地形函数（如 ‖P_{E}θ‖ 的若干主成分），绝不把 N_u 方向喂进网络（否则是在拟合噪声）。适应 = 条件化 + 信念更新；实时仍零梯度写。

**定义 317（不可辨识风险守门 URG 与不确定性三分）** 若 L_u > L_max，定义 robust 风险 R_rob = sup_{θ∈B_t} R(θ,π)。三级缩放：
U_total=(U_ale) + (U_epi^id) + (U_unid)，U_unid = L_u · diam(B_t)。
- U_ale → R68 的 λ_floor（不可约噪声）；
- U_epi^id → R69 的 MINT 交互（可激励消解）；
- U_unid → **robust margin**（不可激励消解，只能按最坏情况扛）+ 触发「买异构激励」的离线请求。
⇒ U_unid 既不是 aleatoric 也不是 R69 意义下的 epistemic，它是**结构不可知（agnostic）**：靠更多数据/更聪明提问都消不掉，只能靠硬件/异构/保守。

**定义 318（机制账本与相干风险归因）** 机制集 M={m_1,…,m_n}（历史 IP/层/门控）。定义子集 S 的**相干风险** ρ(S)=CVaR_α(R_cert(S))，在一个分层场景族上评估。贡献 φ_i 用 Shapley 在 ρ 上求（CVaR 非线性，改用 Aumann–Shapley / 广义 Shapley，并显式报告效率缺口 e_eff=|Σφ_i − (ρ(M)−ρ(∅))|）。用 cross-fitting + bootstrap 给 φ_i 置信区间。**注意：不能用均值 Shapley 代替 CVaR-Shapley**（引理 21）。

**定义 319（创新可辨识性与新颖性账本 NVL）** 机制 m 被**蒸馏保留**当且仅当：(i) φ_i 的置信下界 > δ（贡献可辨识）；(ii) 在投影掉已保留机制后仍有残余贡献 > δ（不是重参数化）；(iii) 不属于定义 320 的保险类，或已获保险豁免。未保留者进入**新颖性账本**，标注为「叙事/候选/不可辨识」，不得在证书与论文中声称。创新 = 可归因的可辨识差异。

**定义 320（保险机制与不可蒸馏约束 INS）** 若机制满足 E[ΔR|m]≈0 但 CVaR_α(ΔR|m) > δ_tail（只在尾部生效，如滑移回退、力限、急停），则称**保险机制**。保险机制不受平均贡献蒸馏约束，只能由**安全包络**判定：任何蒸馏后核 K 必须满足 R_tail(K) ≤ R_tail(M) + δ_attr（归因误差），否则拒绝该次蒸馏。保险集随地形 regime 版本化，不可被单次评测删除。

**定义 321（地形 regime 与再蒸馏 RSK）** 地形非平稳；按地形嵌入把场景聚为 regime，蒸馏只在 regime 内做条件化归因。regime 漂移触发再蒸馏；旧核与旧证书保留可回滚。防止「在平地上蒸馏出的核」被带到冰面上还自称有效。

**定义 322（证书 J_DIG）** J_DIG = (J_FLUID, fim_min_eig, risk_leakage L_u, robust_margin, probe_log_hash, kernel_version, attribution_ci, insurance_set, tail_risk_ci, dig_ver)。Valid ⇔ Valid(J_FLUID) ∧ (L_u ≤ L_max ∨ robust_margin 生效) ∧ 保险约束满足 ∧ 探针全部 TC-Safe ∧ 蒸馏功效达标。

**定义 323（地形风险证书 TRC）** 对当前 regime 给出三元组：(可辨识风险函数估计 + 置信区间, N_u 上的 robust 上界, 覆盖/共因下限)。若 L_u > L_max 且 robust 上界 > ε，则**不发证书**——这是「不知道就别盖章」的形式化。

**定义 324（可辨识性实验设计）** 用 D-最优设计选激励序列以最大化 tr(I_u) 在风险方向上的投影；用分数阶因子设计 + Shapley 抽样把机制归因的组合爆炸压到 O(n·2^{k})（k 为主要机制数）。评测集与蒸馏集交叉拟合。

**定义 325（与 FLUID/R68 的边界）** 若 L_u=0（全可辨识）且 K=M（不蒸馏），则 DIG ≡ FLUID；若 L_u>L_max 且 robust margin 绑定，则 DIG 在风险相关方向 ≡ R68 纯保守。二者是 DIG 的两条边界，安全侧不做让步。

## 2. 关键算法骨架

```python
# IP-264 TID：地形可辨识性分解（粒子信念下的 FIM + 风险投影）
class TerrainIdentifiability:
    def __init__(self, d, tau, L_max):
        self.d, self.tau, self.L_max = d, tau, L_max

    def fim(self, belief, u_seq, dynamics):
        I = zeros(self.d, self.d)
        for th, w in belief.particles():                 # 信念加权
            g = dynamics.loglik_grad(th, u_seq)          # ∂ log p(y|θ,u)
            I += w * outer(g, g)
        return I

    def decompose(self, I, J_R):
        lam, V = eigh(I)
        E = V[:, lam >= 1.0/self.tau**2]                 # 可辨识子空间
        N = V[:, lam <  1.0/self.tau**2]                 # 不可辨识零空间
        leakage = norm(N.T @ J_R)                         # 风险泄漏 L_u
        return E, N, leakage, lam

# IP-265 TAP：安全激励下的风险相关最优探针
def choose_probe(belief, J_R, probes, budget, wm, tid, dynamics):
    best = None
    for u in probes:
        if not budget.allow(u):                         continue
        if not worst_case_safe(wm, belief.support(), u): continue   # 定义315
        I    = tid.fim(belief, u, dynamics)
        gain = expected_risk_var_reduction(I, J_R)      # 风险标量上的 D/A-最优
        score = gain - cost(u)
        if best is None or score > best.score: best = (u, score)
    return best if best and best.score > 0 else None    # 无利可图 → 不探

# IP-269 DIL：相干风险 + 可辨识性 + 保险豁免的机制蒸馏（离线）
def distill(mechanisms, suite, alpha=0.95, delta=0.02):
    rho = lambda S: cvar(risk_samples(S, suite), alpha) # 相干风险，不是均值
    phi = generalized_shapley(rho, mechanisms, sampler='permutation')
    ci  = bootstrap_ci(phi, suite)
    keep = set()
    for i, m in enumerate(mechanisms):
        identifiable  = ci[i].low > delta
        risk_relevant = relevance(m, suite) > delta
        insurance     = (mean_contrib(m, suite) <= delta
                         and cvar_contrib(m, suite) > delta)
        if insurance or (identifiable and risk_relevant):
            keep.add(m)                                  # 保险不可被平均贡献剪
    return keep, phi, ci

# IP-277 主闭环（继承 R69，仅在“可知道什么/留哪些层”处插入 DIG）
def DIG_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    b    = M.terrain.update(o)                          # 低频异步地形信念
    I    = M.tid.fim(b, M.last_u, M.dynamics)
    E, N, leak, lam = M.tid.decompose(I, M.J_R)
    U_unid = leak * b.diameter()                        # 结构不可知
    # 1) 只在可安全激励时提高可辨识性；否则绝不冒险
    u = M.tap.choose_probe(b, M.J_R, M.probes, M.budget, M.c_ras_wm)
    if u is not None: b = M.terrain.execute(u, o)
    # 2) 只对可辨识、gauge 不变的地形函数条件化策略
    phi = project_identifiable(E, b.mean())
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K, terrain=phi)           # R69 FMP + TCF
    # 3) 不确定性三分
    U_ale, U_epi, modes = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if U_epi > TAU_EPI else None)                  # R69：可约的去问
    U_floor = U_ale + U_epi + U_unid                    # unid 视同不可约
    lam_s   = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if leak > M.tid.L_max:
        lam_s = max(lam_s, M.urg.robust_margin(b, M.J_R))  # 不可辨识 → 扛
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    # 4) 离线蒸馏只在换挡/换 regime 时发生；实时核冻结
    cert = M.j_dig.issue(leak=leak, margin=M.urg.margin,
                         kernel=M.kernel_version, probes=M.tap.log)
    M.vqa_d.submit_async(u, leak, cert)
    return k, lam_s, phi, cert

## 3. 推导

**引理 19（不可辨识方向的 minimax 下界）** 设 I_u 在单位向量 v 上特征值 λ_v < 1/τ²。则对任何估计器与任何合法观测，沿 v 的 minimax 均方误差 ≥ τ²（Cramér–Rao 伪逆 + Le Cam 两点法）。若 v 同时风险相关（|v^T J_R| > 0），则风险估计沿 v 的不可约方差 ≥ (v^T J_R)² τ²。**系：再多的探针预算也不能消掉 N_u 方向的风险不确定性；唯一出路是改变可激励集（硬件/异构/接触方式）或稳健化。** 这把 R69 的「交互可消解一切 epistemic」修正为「交互只能消解 E_u 内的 epistemic」。

**引理 20（安全激励的可辨识性天花板）** 令 𝒰_safe(b)={u: TC-Safe(u)}。可达最大信息为 I* = max_{u∈𝒰_safe(b)} I_u。若风险相关方向所需的激励要求真实越界（例如必须在极限摩擦下打滑才能估 μ），则 I* 在该方向的特征值 < 1/τ²，可辨识性被**安全集**封顶。**系：地形适应的瓶颈不只是数据量，而是「安全地制造信息」的能力；正确投资是扩大 𝒰_safe（更低的质心、更软的足、外部传感、异构机器人），而不是更用力地探。**

**引理 21（平均蒸馏必然剪掉保险）** 存在机制 m，使 |E[ΔR|m]| < δ 但 CVaR_α(ΔR|m)=B（只在滑移/塌陷尾部生效的回退控制器）。按均值 Shapley 蒸馏会以任意接近 1 的概率剪掉 m，而 CVaR 风险增加 B 可任意大。**系：机制蒸馏必须使用相干风险泛函 + 保险豁免（定义 320）；平均贡献不是安全贡献。** 同时 CVaR 非线性导致 Shapley 效率公理不成立，需显式报告效率缺口 e_eff，否则归因本身不可审计。

**定理 18（DIG 的双边界安全包含）** 在 A99–A101（动力学光滑、FIM 正则可微、CVaR 相干且归因误差有界）下：
(i) 在可辨识风险方向，DIG 的认证风险 ≤ FLUID（FLUID 把全部 U_epi 当可约；DIG 只在 TC-Safe 且 Δ_risk>c 时探，并额外加 robust margin）；
(ii) 在不可辨识风险方向，DIG 的证书要么带 robust 上界、要么拒绝签发；FLUID 可能在这里发出一个「看似更紧、实则不可信」的证书；
(iii) L_u=0 且 K=M 时逐指令 ≡ FLUID；L_u>L_max 时在相关方向 ≡ R68；
(iv) 带保险约束的蒸馏满足 R_tail(K) ≤ R_tail(M)+δ_attr。⇒ 安全侧对 R69 严格不弱，效率收益被限制在「可安全激励且可归因」的格子里。

**定理 19（地形适应的信息–安全前沿）** 设任务成功率 S 随风险相关可辨识信息 tr(P_E J_R^T Σ^{-1} J_R) 单调增，则在 𝒰_safe 封顶处饱和；超过饱和点后，增加数据/探针不能提升认证成功率，只有扩大 𝒰_safe（异构激励）或提高鲁棒裕度才能移动前沿。**系：把「地形适应」重述为「购买激励能力」，而不是「收集更多日志」。**

## 6. 本轮最大风险

**一句话**：DIG-RAS 把「可辨识」当成「真实」的代理——但安全探针只能激励安全的地形、平均归因只能看见平均的贡献；于是蒸馏会精确地剪掉只在尾部生效的保险机制，而主动激励会系统性地只学会「自己能安全触碰的地形」，系统最终成为一个「对安全地形非常专家、对能杀死自己的地形完全盲」的自信者。

**次级风险与缓解**：
1. **安全探针制造可辨识性天花板**（定义 315、引理 20）→ 承认信息–安全前沿，改用异构激励/外部传感扩展 𝒰_safe，而非冒险探测；
2. **平均蒸馏剪保险**（引理 21）→ CVaR-Shapley + 保险豁免 + 尾部非退化约束（定义 320）；
3. **FIM 局部性/非线性失效**（A99）→ profile likelihood / 可观测秩条件做全局校验，E301 覆盖；
4. **归因过拟合与效率缺口**（定义 318）→ cross-fitting + bootstrap CI + 显式报告 e_eff，E306；
5. **地形 regime 漂移使旧核过期**（定义 321）→ 版本化再蒸馏 + 回滚 + E309；
6. **观测攻击伪造地形**（E315）→ TRC 的共因/锚校验 + 探针日志哈希并入 J_DIG。

## 3. 关键算法伪代码

# IP-264 TID：可辨识性分解
class TerrainIdentifiability:
    def fim(self, belief, u_seq, dynamics):
        I = zeros(self.d, self.d)
        for th, w in belief.particles():
            g = dynamics.loglik_grad(th, u_seq)
            I += w * outer(g, g)
        return I

    def decompose(self, I, J_R):
        lam, V = eigh(I)
        N = V[:, lam <  1.0/self.tau**2]
        E = V[:, lam >= 1.0/self.tau**2]
        return E, N, norm(N.T @ J_R), lam        # 泄漏 L_u

# IP-265 TAP：安全激励下的风险相关最优探针
def choose_probe(belief, J_R, probes, budget, wm):
    best = None
    for u in probes:
        if not budget.allow(u) or not worst_case_safe(wm, belief.support(), u):
            continue
        gain = expected_risk_var_reduction(tid.fim(belief, u, dyn), J_R)
        score = gain - cost(u)
        if best is None or score > best.score: best = (u, score)
    return best if best and best.score > 0 else None

# IP-269 DIL：CVaR-Shapley + 保险豁免
def distill(mechanisms, suite, alpha=0.95, delta=0.02):
    rho = lambda S: cvar(risk_samples(S, suite), alpha)
    phi = generalized_shapley(rho, mechanisms)
    ci  = bootstrap_ci(phi, suite)
    keep = set()
    for i, m in enumerate(mechanisms):
        insurance = mean_contrib(m, suite) <= delta and cvar_contrib(m, suite) > delta
        if insurance or (ci[i].low > delta and relevance(m, suite) > delta):
            keep.add(m)
    return keep, phi, ci

# IP-277 主闭环
def DIG_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    b = M.terrain.update(o)
    E, N, leak, _ = M.tid.decompose(M.tid.fim(b, M.last_u, M.dyn), M.J_R)
    u = M.tap.choose_probe(b, M.J_R, M.probes, M.budget, M.c_ras_wm)
    if u is not None: b = M.terrain.execute(u, o)
    phi = project_identifiable(E, b.mean())
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K, terrain=phi), z, M.fmp.mode_head)
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    U_floor = U_ale + U_epi + leak * b.diameter()       # unid 视同不可约
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if leak > M.tid.L_max: lam = max(lam, M.urg.robust_margin(b, M.J_R))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    cert = M.j_dig.issue(leak, M.urg.margin, M.kernel_version, M.tap.log)
    M.vqa_d.submit_async(u, leak, cert)
    return k, lam, phi, cert
```

## 4. 推导

**引理 19（不可辨识方向的 minimax 下界）** 若 `I_u` 在 v 上 `λ_v<1/τ²`，任何估计器沿 v 的 minimax MSE ≥ τ²；若 v 风险相关，则风险估计不可约方差 ≥ `(v^T J_R)²τ²`。**系：交互只能消解 E_u 内的 epistemic；N_u 方向只能稳健化或靠异构激励扩展。**

**引理 20（安全激励的可辨识性天花板）** `I*=max_{u∈𝒰_safe} I_u`；若风险方向需要越界激励（如极限摩擦下真实打滑），则 `I*` 在该方向仍低于阈值。**系：地形适应的瓶颈是「安全地制造信息」的能力，应投资扩大 𝒰_safe（低质心/软足/外部传感/异构），而非更用力探测。**

**引理 21（平均蒸馏剪保险）** 存在机制 m：`|E[ΔR]|<δ` 但 `CVaR_α(ΔR)=B`（仅滑移/塌陷尾部生效）。均值 Shapley 会剪掉它，CVaR 风险增加 B 可任意大。**系：蒸馏必须用相干风险 + 保险豁免；CVaR 非线性使 Shapley 效率公理失效，须报告 e_eff。**

**定理 18（双边界安全包含）** A99–A101 下：(i) 可辨识方向 DIG 认证风险 ≤ FLUID；(ii) 不可辨识方向 DIG 要么带 robust 上界要么拒发证书，而 FLUID 可能发出不可信的「更紧」证书；(iii) `L_u=0 ∧ K=M` 时逐指令 ≡ FLUID，`L_u>L_max` 时相关方向 ≡ R68；(iv) 带保险约束的蒸馏满足 `R_tail(K)≤R_tail(M)+δ_attr`。

**定理 19（信息–安全前沿）** 认证成功率随风险相关可辨识信息单调增并在 𝒰_safe 封顶处饱和；此后只有扩大 𝒰_safe 或增大鲁棒裕度能移动前沿。**系：地形适应 = 购买激励能力，不只是收集更多日志。**

## 7. 本轮最大风险

**一句话**：DIG-RAS 把「可辨识」当成「真实」的代理——安全探针只能激励安全的地形、平均归因只能看见平均的贡献；于是蒸馏会精确地剪掉只在尾部生效的保险机制，主动激励则系统性地只学会「自己能安全触碰的地形」，最终系统成为「对安全地形非常专家、对能杀死自己的地形完全盲」的自信者。

**次级风险与缓解**：安全激励天花板（定义 315 + 引理 20，改用异构激励扩展 𝒰_safe）；平均蒸馏剪保险（CVaR-Shapley + 保险豁免 + 尾部非退化，定义 320）；FIM 局部性/非线性失效（profile likelihood + 可观测秩校验，E301）；归因过拟合与效率缺口（cross-fitting + bootstrap CI + 显式 e_eff，E306）；regime 漂移使旧核过期（版本化再蒸馏 + 回滚，E309）；观测攻击伪造地形（TRC 共因/锚校验 + 探针日志哈希并入 J_DIG，E315）。
