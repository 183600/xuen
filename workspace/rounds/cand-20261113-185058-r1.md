# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「可扩展性」×「力矩传感」）

> R68 把「标定」升级为在线潜变量 c_t，却在风险自陈里留下一个**结构性缺口**：单台机器的自标定是一个**闭环自证系统**——它用被标定的传感器去判断自己是否需要标定。慢变故障只要落在标定带宽 ω_cal 之内，就能被滤波器「解释掉」；系统越标定越自信，越自信越看不见自己正在缓慢失效。问题的本质不是 EKF 不够好、canary 不够多，而是**缺乏外部参照（external reference）**：要否定「我的测量还准」，必须存在一个不由这条测量链控制的第二意见。
>
> 本轮的两个灵感恰好给出两种不同性质的外部参照：
> - **力矩传感 → 物理外部参照**：同一外部力旋量在运动链上有两条独立测量路径（末端 F/T 传感器 vs 关节力矩/动量观测器）。常值偏置在构型变化下具有不同的**关节空间签名**，慢载荷与慢偏置因此可在「构型维度」上分离；
> - **可扩展性 → 统计外部参照**：把单机自标定扩展为**机群差分标定**。环境/温度/任务/同批次固件是共模漂移，会同时打到所有单位；传感器渐进失效是特异漂移，只打到一台。机群是**分布式对照实验**，慢故障因此可在「群体维度」上分离。
>
> 核心命题：**把「标定」从单机自证，升级为「可辨识 + 有外部参照」的双重计量——SCALE-RAS（Scalable Calibration with Analytical redundancy & population LEarning）。** 标定不再是「谁都能被吸收」，而是「只有可辨识、且被独立参照背书的那个方向，才允许被吸收」。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「**凭什么相信它说准？谁能否证它？**」

## 0. 直觉与动机

**灵感 1（力矩传感 → 不是多一个传感器，而是多一个「几何签名」）**
直觉：R68 的标定向量里有末端力零偏 b_F，但只有 F/T 一个测量通道；一个缓慢增大的 b_F 与真实外载荷的缓慢变化，在单通道上不可分。力矩传感改变的不是精度，而是**信息的几何结构**：末端六维力旋量经雅可比转置 J(q)ᵀ 映射到 n 个关节力矩，而关节力矩传感器（或 SEA、广义动量观测器）对同一物理量给出第二组读数。关键事实是：
- 末端常值偏置 b_F 映射到关节空间是 J(q)ᵀb_F，**随构型 q 变化**（尤其随末端姿态变化）；
- 关节力矩传感器的常值零偏 b_τ 在关节空间是**常向量**；
- 世界系常值真实载荷 F_w 映射为 J(q)ᵀ·Ad(g(q))·F_w，其构型依赖与 b_F **不同**（因为传感器系相对世界系在旋转）。

于是让机器人经过若干姿态不同的构型，堆叠残差 r(q_k)=J(q_k)ᵀF_m − τ̂_ext，就得到一个线性模型 r = A(q_{1:K})·(b_F, b_τ) + ν。只要构型差异让雅可比差异张成六维，b_F 与 b_τ 就可分离；而世界系真实载荷因为构型签名不同，会留下**不可被常值 b_F 跨构型吸收**的残差（引理 16）。这给 R68 最缺的东西：一个**方向判据**——哪些残差是「可以标定掉的偏置」，哪些是「不能被标定吸收的真实变化」。力矩传感因此不是「又一路输入」，而是把标定从「无方向的速率限制」升级为「有方向的可辨识门控」。

**灵感 2（可扩展性 → 机群是分布式对照实验，不是更多机器）**
直觉：单机上「环境变冷了」和「力传感器在缓慢失效」都会让读数缓慢漂移，且都在标定带宽内，所以单机永远分不清。但放到机群上，二者的统计结构不同：
- 环境/温度/任务/同批次固件 = **共模**（common-mode），同时作用于所有单位；
- 传感器渐进老化/慢泄漏/缓慢松动 = **特异**（idiosyncratic），只作用于一台。

每台机器都为其他机器提供了一次**反事实基线**：把单位 i 的慢残差 z_i 减去其参考队列的鲁棒共识 ĉ_i，共模项被抵消，剩下的离群慢变量 d_i=z_i−ĉ_i 就是故障证据（引理 17）。可扩展性的真正回报不是吞吐量，而是**可辨识性**：N 台机器把慢故障的检出阈值从 O(环境漂移幅度 σ_c) 降到 O(单机噪声 σ_ε·√(1+1/N_eff))。这正好对 R68 最大风险「标定越强、缓变故障越隐形」做正面对冲——**机群越大，慢故障越无处藏身**。

**灵感 3（两种参照互补，但共享同一软肋 → 相关失效）**
直觉：物理参照（力矩）管「单机内部两条通道是否自洽」，统计参照（机群）管「单机相对群体是否异常」。二者不是简单冗余，而是**正交的失效方向**：
- 力矩 parity 对「整批传感器同批坏」无效（两个通道可能源自同一批坏器件）；
- 机群差分对「全体共享的共因故障」无效（大家一起坏，差分归零）。

但它们共享同一个致命软肋：**参照与被参照不独立**。若关节力矩通道与末端 F/T 互为标定源（**循环标定**），或整个机群使用同批次传感器、同版本固件、共享同一套被投毒的激励/canary 资产，则两条参照会**一致地错**。此时系统不是「没有参照」，而是「拿到两份互相印证的错误参照」——这比 R68 的单机自证**更危险**，因为它把虚假置信从 0.7 抬到了 0.95。因此本轮必须把「参照独立性」本身作为一等公民来检验、认证与降级（定义 303、定理 16）。

**灵感 4（可扩展性的代价 → 共享资产是相关失效的通道）**
直觉：机群参照要成立，必须共享：激励库（哪套安全动作最能激发可辨识性）、canary 故障组合、标定先验、证书聚合拓扑。共享带来规模效应，也**把本来独立的故障模式耦合起来**：一个被投毒的激励库、一个被泄漏的 canary 组合、一个被攻陷的聚合节点，会同时污染所有下游单位。可扩展性因此不是免费午餐：它用「统计功效 √N」换来了「相关失效面」。架构必须在享受收益的同时，用鲁棒聚合（RFA）、随机轮换（DCP）、层级证书（HCC）与独立性检验把相关失效面压回可控。

**灵感 5（合流 → SCALE-RAS 十组件 + 继承核）**
1. **JTR Joint-Torque Reference**：动量观测器/关节力矩传感给出 τ̂_ext，与 JᵀF 构成 parity 残差；标定向量扩展为 (b_F, b_τ)，但**只在可辨识方向更新**；
2. **IGC Identifiability-Gated Calibration**：用配置多样性 Gram 矩阵 G=AᵀA 把 c 的更新投影到可辨识子空间 Π_obs；正交补 r_⊥ 不吸收、直接送故障归因——补上 R68「速率限制只限速度、不限方向」的漏洞；
3. **TIE Torque-Informed Excitation**：安全不变集内的 D-optimal 激励调度，保持 G 良态；机群共享激励库但**随机化**以抗投毒；
4. **FCD Fleet Consensus Differential**：残差分解为共模+特异+噪声，用协变量匹配的参考队列做差分；
5. **RFA Robust Fleet Aggregation**：trimmed/Krum 鲁棒聚合 + 信任权重 + 独立新鲜参照锚点；
6. **DCP Distributed Canary Portfolio**：把 R68 的单机 canary 扩展为机群轮换覆盖，并保留「canary 不可修复性」；
7. **HCC Hierarchical Certificate Chain**：单机证书 → 单元/产线 → 机群的可组合证书链，带租约与干扰界；
8. **TRS Trust-Responsive Scaling**：阈值/前缀/标定步长由参照信任度 τ_ref 响应，**信任低只收紧、绝不放宽**；
9. **AIC-SCALE**：在 ℰ_CALM 上乘入 ℰ_jtr×ℰ_fleet×ℰ_hcc（循环标定、共因漂移、拜占庭投毒、队列失配、证书组合错误等）；
10. **RAS-WM† 继承核**：CALM-RAS 全部保留，只是 COF 被 IGC 门控、阈值被 TRS 信任缩放；无参照时**优雅退化**回 R68 保守模式。

## 1. 形式化定义（增量：定义 293–306）

**定义 293（SCALE-RAS 总览与三不变式）** SCALE-RAS = (JTR, IGC, TIE, FCD, RFA, DCP, HCC, TRS, RAS-WM†)。三不变式：
(i) **可辨识门控标定**：COF 只允许在可辨识子空间 Π_obs 内更新 c；不可辨识方向一律不吸收，计入 U 并进入 H_sensor^trans；
(ii) **外部参照纪律**：任何标定状态的「可信」必须由至少一个**与被标定链不共享标定来源**的参照背书；无可信参照 ⇒ 退化到 R68 单机保守模式；
(iii) **收缩免费、扩张持证**：参照只允许降低 λ 上限（更保守）；任何「因参照说没事而放宽」必须先过 HCC 认证，且放宽量与 τ_ref 成反比。

**定义 294（JTR 关节力矩解析冗余）** 设 q∈ℝⁿ、末端 F/T 读数 F_m∈ℝ⁶、关节力矩传感/电机电流给出 τ_m。广义动量观测器：
p = M(q)q̇，τ̂_ext = K_o·(p − ∫₀ᵗ(τ_m − C(q,q̇)ᵀq̇ + g(q) + τ̂_ext)dτ)。
parity 残差 r_τ(q) = J(q)ᵀ F_m − τ̂_ext = J(q)ᵀ b_F − b_τ + ν（自由空间/已知载荷下）。残差在 range(Jᵀ) 内的分量对应「自洽的力旋量」，其正交分量对应通道不一致（标定错误或故障）。

**定义 295（配置多样性可辨识性）** 在 K 个构型上堆叠 r_τ(q_k)，得 r = A(q_{1:K})·φ + ν，φ=(b_F,b_τ)∈ℝ^{6+n}，
A = [J(q_1)ᵀ, −I; J(q_2)ᵀ, −I; …; J(q_K)ᵀ, −I] ∈ ℝ^{6K×(6+n)}。
辨识 Gram 矩阵 G = AᵀA；特征分解 G=UΛUᵀ。**可辨识子空间** 𝒪 = span{u_j : λ_j ≥ λ_min}，投影 Π_obs = U_𝒪U_𝒪ᵀ；**不可辨识子空间** 𝒩 = span{u_j : λ_j < λ_min}（含 rank 缺失方向）。κ(G)=λ_max/λ_min 作为条件数。标定只在 𝒪 内进行。

**定义 296（IGC 可辨识门控标定）** COF 更新改为
Δc = Π_obs·K·(z_meas − h(ĉ))，c ← RateLimit(c + diag(τ_ref)·Δc)；
正交残差 r_⊥ = (I − A·A⁺)·r_τ −−−→ H_sensor^trans 证据。
协方差在 𝒩 方向注入大先验方差，使 U(ĉ)=tr(Σ_c) 同时编码「噪声不确定」与「结构不可辨识」——**不可辨识本身被显式计为不确定性**，而不是被悄悄忽略。

**定义 297（TIE 安全激励）** 选择构型序列 q_{1:K}（及接触状态）以最大化 log det G（D-optimal），约束：
q_k ∈ S_safe（预先认证的安全不变集）、|τ_j|≤τ_max、激励时长 ≤ T_exc、对任务扰动 ≤ δ_task。
激励是**受限的安全实验**：它只在已认证的不变集内运动，不扩大可达集；机群维护共享激励库 E，但按随机化策略 p(e) 抽样，并保留 hold-out 激励集防投毒。

**定义 298（FCD 群体差分分解）** 单位 i 经 JTR+IGC 后的慢模态残差
z_i(t) = c(x_t) + f_i(t) + ε_i(t)，
其中 c 为共模（环境/温度/任务/批次），f_i 为特异故障，ε_i 为噪声，x_t 为协变量（负载、任务、温度代理）。
参考队列 R_i = {j : dist(x_j,x_i) ≤ ρ}；共模估计 ĉ_i = Agg_{j∈R_i} z_j；差分 d_i = z_i − ĉ_i。
H0（健康）下 Var(d_i) ≈ σ_ε²(1+1/N_eff)；H1（故障）下 d_i ≈ f_i。

**定义 299（RFA 鲁棒聚合）** Agg ∈ {坐标wise trimmed mean(trim=β), Krum, 中位数}，故障/恶意单位比例 ≤ β 时共识误差有界。信任权重 w_i 由历史 leave-one-out 一致性更新；**独立新鲜参照锚点**（新出厂、异批次、独立标定链的单位）作为「信任根」，用于检测全体共模漂移与合谋。异质性用协变量匹配处理，禁止裸池化。

**定义 300（DCP 分布式 canary 组合）** 故障模式组合 C={c_1,…,c_M}，每轮把 c_m 随机分配给单位子集 π_t(m)。覆盖概率 P(cover m) ≈ 1−(1−p_m)^{N_eff(m)}，并保留 R68 的 canary 不可修复性判据。共享 canary 库必须随机化+轮换+留出验证，防「canary 泄漏→针对性规避」与「被投毒 canary 让全体一起误判」。

**定义 301（HCC 层级证书链）** 单机证书 C_i=(φ_i, τ_i, lease_i, τ_ref,i)；组合律
C_cell = ⊗_{i∈cell} C_i，要求租约重叠 ∧ 干扰界 I_cell；
C_fleet = ⊗_{cell} C_cell。
可靠性：∧φ_i 在干扰界 I 下蕴含 Φ_fleet。新鲜度租约：结论仅在 m − λ(t−τ) ≥ θ 时可用于守卫。树深 O(log N)，每单位每轮通信 O(1)。

**定义 302（TRS 信任响应缩放）** 参照信任
τ_torque = f(κ(G), parity 残差健康度, 循环标定检测)；
τ_fleet = f(N_eff, 异质性, 单位间分歧, 拜占庭告警)；
τ_ref = min(τ_torque, τ_fleet)（或含锚点一致性）。
阈值与风险缩放：
λ_floor(U, τ_ref) = max(0.6, 0.8·1[U>τ_cal], 0.8·1[τ_ref<τ_trust])；
τ_risk = τ⁰_risk·(1 − κ_r·U)·(1 + κ_s·(1−τ_ref))；
k ← min(k, k_scale(τ_ref))。
语义保持 R68 纪律：**任何不确定性来源（标定、力矩、机群）都只导向收紧。**

**定义 303（外部参照独立性公理 A95–A97 与检验）**
- **A95（力矩–F/T 独立）**：关节力矩通道不得由末端 F/T 通道标定得到（标定溯源图无环）。检验：维护 calibration provenance DAG；检测到环 ⇒ τ_torque:=0，禁止力矩参照参与标定。
- **A96（群体独立）**：故障率稀疏、拜占庭比例 ≤ β、故障模式非完全相关、独立新鲜锚点到达率 ≥ ρ_anchor。
- **A97（协变量充分）**：给定 x，H0 下各单位可交换；协变量失配 ⇒ 队列失配告警，τ_fleet 下调。
- **共因检测器**：监控机群离散度；若全体同向漂移且超出环境模型，则「真实环境变化」与「共因故障」**不可分**——此时全局抬升 U、请求新鲜锚点，绝不把它当作「大家都正常」。

**定义 304（AIC-SCALE 干扰集）** ℰ_SCALE = ℰ_CALM × ℰ_jtr × ℰ_fleet × ℰ_hcc，其中
ℰ_jtr = {parity 误归因, 激励诱发风险, 力矩通道自身慢漂}；
ℰ_fleet = {循环标定, 队列失配, 拜占庭投毒, 共因漂移, 共识陈旧/分区, canary 泄漏}；
ℰ_hcc = {证书组合错误, 租约过期, 聚合节点被攻陷}。

**定义 305（J_SCALE 证书）** J_SCALE = (J_CALM, identifiability_gram_hash, κ(G), torque_ref_hash, fleet_ref_hash, τ_ref, anchor_ids, hcc_root_hash, scale_ver)。
Valid ⇔ Valid(J_CALM) ∧ κ(G)<κ_max ∧（τ_ref>τ_trust ∨（退化模式 ∧ λ_floor 已抬升））∧ 独立性检验通过。

**定义 306（SCALE-RAS 管线与优雅降级）** 离线：单机力矩–F/T 辨识 → 机群激励库与锚点配置 → 标定溯源图建档。在线：JTR parity → IGC 门控 COF → FCD 与参考队列差分 → RFA 共识 → TRS 缩放 → HCC 证书更新 → DCP canary 轮换 → CAC（继承 R68）。降级：通信中断或 τ_ref<τ_trust ⇒ 切回 R68 单机模式，λ_floor 抬升、𝒩 方向禁止任何标定增益；**降级绝不放宽到 R68 之上**。

## 2. 关键算法骨架

```python
# IP-253 JTR：关节力矩解析冗余（动量观测器 + parity 残差）
class JointTorqueReference:
    def __init__(self, M_fn, C_fn, g_fn, Ko):
        self.M, self.C, self.g, self.Ko = M_fn, C_fn, g_fn, Ko
        self.p = None; self.tau_hat = 0.0

    def step(self, q, dq, tau_m, F_m, dt):
        p = self.M(q) @ dq
        if self.p is None: self.p = p
        tau_ext = self.Ko * (p - self.p)          # 广义动量观测
        self.p = p
        r_parity = self.jac(q).T @ F_m - tau_ext   # 定义 294
        return r_parity, tau_ext


# IP-254 IGC：可辨识门控标定（只在 Π_obs 内吸收）
class IdentifiabilityGatedCalibration:
    def __init__(self, lam_min=1e-3):
        self.lam_min = lam_min; self.buffer = []

    def observe(self, J, r_parity):
        A = np.hstack([J.T, -np.eye(J.shape[1])])  # [Jᵀ, -I]
        self.buffer.append((A, r_parity))

    def gate(self):
        A = np.vstack([a for a, _ in self.buffer[-K_MAX:]])
        G = A.T @ A
        lam, U = np.linalg.eigh(G)
        obs = U[:, lam >= self.lam_min]            # 可辨识子空间 𝒪
        Pi_obs = obs @ obs.T
        return Pi_obs, lam, G

    def update(self, cof, z_meas, h):
        Pi_obs, lam, G = self.gate()
        delta = Pi_obs @ cof.K @ (z_meas - h)      # 只在 𝒪 内
        cof.c = cof.rate_limit(cof.c + np.diag(self.tau_ref) @ delta)
        return cof.c


# IP-255 TIE：安全激励（D-optimal，受限不变集）
def torque_informed_excitation(robot, S_safe, N):
    best = None
    for cfg_seq in randomized_candidates(N):       # 机群共享库 + 随机化
        if not all(cfg in S_safe for cfg in cfg_seq): continue
        G = gram_over(cfg_seq, robot.jac)
        score = np.log(np.linalg.det(G + 1e-9*np.eye(G.shape[0])))
        if best is None or score > best[0]:
            best = (score, cfg_seq)
    return best[1]                                 # 只返回不变集内序列


# IP-256/257 FCD + RFA：群体差分 + 鲁棒聚合
class FleetConsensusDifferential:
    def __init__(self, beta=0.2):
        self.beta = beta
        self.trust = {}                            # 信任权重

    def differential(self, unit_id, z, cohort):
        zs = np.stack([z[j] for j in cohort])
        w  = np.array([self.trust.get(j, 1.0) for j in cohort])
        c_hat = trimmed_weighted_mean(zs, w, trim=self.beta)  # RFA
        d = z[unit_id] - c_hat
        tau_fleet = self._trust_score(z, cohort, c_hat)
        return d, c_hat, tau_fleet

    def _trust_score(self, z, cohort, c_hat):
        disp   = np.median(np.abs(z[list(cohort)] - c_hat))
        byz    = byzantine_flags(z, cohort)       # Krum / 留一验证
        hetero = covariate_mismatch(z, cohort)    # A97
        return sigmoid(-(disp + byz + hetero))    # 越低越不可信

# IP-262 主闭环：SCALE-RAS round
def SCALE_RAS_round(M, obs, unit_id, cohort):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))

    # 1) 物理参照：力矩 parity + 可辨识门控
    r_parity, tau_ext = M.jtr.step(M.q, M.dq, M.tau_m, M.F_m, M.dt)
    M.igc.observe(M.jac(M.q), r_parity)
    Pi_obs, lam, G = M.igc.gate()
    kappa = lam.max() / max(lam.min(), 1e-12)
    tau_torque = 0.0 if M.provenance.has_cycle() else f_trust(kappa, r_parity)

    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    z_cal = np.concatenate([o['cal'], r_parity])
    c, U, thr = M.cof.step(z_cal, residuals(x_prime, o),
                           sigma_stat(M), Pi_obs=Pi_obs)  # 2) IGC 门控
    r_perp = orthogonal_residual(G, r_parity)              # 不可辨识残差 → 故障

    # 3) 统计参照：群体差分 + 鲁棒共识
    d, c_hat, tau_fleet = M.fcd.differential(unit_id, z_cal, cohort)
    tau_ref = min(tau_torque, tau_fleet)

    # 4) WM 前瞻 + 归因（继承 R68，加入 r_perp 与信任缩放）
    wm_preds = M.mtm.rollout(z, M.ach.propose_actions(x_prime, 5))
    joint_post = M.cfa(r_perp, o['pi'], c, U, tau_ref)

    # 5) 缩放：信任低只收紧
    lam_floor = max(0.6, 0.8 if (U > TAU_CAL or tau_ref < TAU_TRUST) else 0.6)
    lam = max(M.efs.risk_scale(joint_post), lam_floor,
              0.8 if (o['qual']['face'] < 0.8 or wm_drift) else 0.6)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, H=M.vista.H),
                                    joint_post, M.m_ras, M.alpha_chunk, wm_preds)
    if tau_ref < TAU_TRUST or U > TAU_CAL:
        k = min(k, k_scale(tau_ref, U))

    # 6) 层级证书 + 异步审计/提交（继承 CAC）
    M.hcc.update(unit_id, Certificate(thr, lam, k, tau_ref))
    M.vqa_c.submit_async(wm_preds, {'parity': r_perp, 'd': d, 'tau_ref': tau_ref})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)

    tau = M.pi_sigma.prefix_dispatch(M.ach.propose(x_prime)[:k]) * lam
    return k, lam, joint_post, (c, U, tau_ref)
```

## 3. 推导

**引理 16（力矩–F/T 偏置可分离性与构型签名）** 在 K 个构型上，自由空间/已知载荷残差 r_k = J(q_k)ᵀb_F − b_τ。若构型差异使 { (J(q_1)−J(q_k))ᵀ }_{k=2..K} 张成 ℝ⁶，则 A 列满秩，(b_F,b_τ) 可辨识，且 Var(φ̂)=σ²(AᵀA)^{-1}，条件数 κ(G) 决定标定可信度。进一步，世界系常值真实载荷 F_w 的关节空间像为 J(q)ᵀ·Ad(g(q))·F_w；若末端姿态随构型变化，则它**不等于任何常值 b_F 的像**，最小二乘会留下不可被标定吸收的残差 r_⊥。系：**构型多样性同时给出「偏置间可分离」与「真实载荷 vs 常值偏置可分离」两重判据**；这也是 TIE 必须激发姿态变化、而非只做平移的原因。

**引理 17（群体差分的共模抵消与检出阈值下移）** 设 z_i = c + f_i + ε_i，f_i 稀疏（≤βN），ε_i~𝒩(0,σ_ε²)。鲁棒聚合 ĉ_i 在 H0 下满足 E[ĉ_i]≈c，故 d_i=z_i−ĉ_i ≈ f_i + ε_i − noise_agg。H0 下 Var(d_i)≈σ_ε²(1+1/N_eff)。取阈值 τ_f = z_{1−α}σ_ε√(1+1/N_eff)，则最小可检故障
MDF(N) ≈ (z_{1−α}+z_{1−β_power})·σ_ε·√(1+1/N_eff)。
对比单机自标定：共模 c 与特异 f_i 混在同一慢模态中，可辨识门限被 σ_c 主导，MDF_single ≥ O(σ_c)。因此当 σ_c ≫ σ_ε 时，机群把慢故障可检出幅度压低约 σ_c/(σ_ε√(1+1/N_eff)) 倍，且随 N 增大趋近 σ_c/σ_ε 的饱和上限。系：**可扩展性是可辨识性资源**；收益在 N_eff 超过队列同质性上限后饱和，此时继续加机器只会引入异质性偏差（定义 298、A97）。

**引理 18（层级证书组合与通信复杂度）** 若每个单元证书在干扰界 I_cell 下 sound，且租约区间两两重叠，则 AND 组合在 max 干扰与 min 租约下 sound。树深 O(log N) ⇒ 单机到根路径 O(log N) 跳，每轮每单位 O(1) 消息，聚合节点 O(deg) 工作量。系：证书的**规模扩展代价是对数通信**，不是线性带宽；但聚合节点成为相关失效点，需多副本 + 拜占庭聚合（定义 299）。

**引理 19（分布式 canary 覆盖）** 故障模式 m 被独立分配的概率 p_m，N_eff 个独立单位覆盖概率 1−(1−p_m)^{N_eff}。若 canary 库共享且分配可预测，则有效独立单位数坍缩为常数，覆盖退化为 p_m——**共享 canary 是覆盖率与相关失效的权衡**，随机轮换 + 留出验证是必要条件。

**定理 16（SCALE-RAS 端到端一致性与优雅降级）** 在 R68 的 A87–A94 及本轮 A95–A97 下：
1. P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+**α_jtr**+**α_fleet**，其中 α_jtr 受引理 16 的条件数约束，α_fleet 受引理 17 的 N_eff 与鲁棒界约束；
2. τ_ref<τ_trust ∨ U>τ_cal ⇒ λ_risk≥0.8 ∧ k 收缩 ∧ 不可辨识方向零标定增益——**任何参照不可信都只收紧**；
3. 参照不可用或独立性检验失败 ⇒ 退化到 R68 单机模式且 λ_floor 抬升，故 Safe(SCALE) ≥ Safe(R68)（在相同工况下）；
4. 在 A95–A97 成立且构型多样性满足引理 16 时，对落在 R68 标定带宽内的**特异慢故障**，SCALE-RAS 的检出概率严格高于 R68（引理 17 阈值下移）。

**定理 17（鲁棒参照的拜占庭界与误报控制）** 设恶意/故障单位比例 ≤ β，trimmed 聚合 breakdown ≥ β，则共识误差 ≤ 有界函数 O(β·diam)；用保形校准（conformal）在健康机群上标定 τ_f，可使 H0 误报 ≤ α。若检测到拜占庭比例 > β、共因漂移或队列失配，则 τ_fleet→0 并触发退化；**机群共识无法检测共模故障**，必须依赖独立锚点与力矩参照——这正是定义 303 的共因检测器存在的原因。

**定理 18（可扩展性的安全收益—相关失效界的权衡）** 在 A95–A97 且锚点率 ρ_anchor>0 下，机群慢故障 MDF 随 N_eff 单调下降至饱和值（引理 17）；但相关失效概率随共享资产（激励库/canary/聚合拓扑）规模上升。存在最优规模 N*，使「检出收益 − 相关失效损失」最大化；超过 N* 后继续扩容不再安全。系：**可扩展性必须被认证地扩展，而非无脑复制**。

## 6. 本轮最大风险

| `τ_ref = min(τ_torque, τ_fleet)` | 参照信任度（TRS 输入） |
| `λ_floor(U,τ_ref)` | 信任响应风险下限（不确定性 → 收紧） |
| `C_i / C_cell / C_fleet` | 单机 / 单元 / 机群证书（HCC 组合） |
| `A95–A97` | 力矩独立 / 群体独立 / 协变量充分公理 |
| `J_SCALE = (J_CALM, G_hash, κ(G), τ_ref, anchor_ids, hcc_root_hash, scale_ver)` | 规模扩展证书 |

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 可辨识门控标定（只吸收 Π_obs 内方向）；外部参照纪律（可信标定须有非共享来源的参照背书）；收缩免费、扩张持证（参照只允许收紧；放宽须过 HCC 且与 τ_ref 成反比）。

**定义 294（JTR）** 广义动量观测器给出 τ̂_ext；parity 残差 `r_τ(q)=J(q)ᵀF_m−τ̂_ext=J(q)ᵀb_F−b_τ+ν`；正交分量指示通道不一致/故障。

**定义 295（可辨识性）** 堆叠 K 构型：`r=Aφ+ν`，`φ=(b_F,b_τ)`；`G=AᵀA` 特征分解；𝒪=span{λ≥λ_min}，Π_obs 投影；𝒩 为不可辨识子空间。

**定义 296（IGC）** `Δc=Π_obs·K·(z−h(ĉ))`，`c←RateLimit(c+diag(τ_ref)Δc)`；`r_⊥=(I−AA⁺)r_τ→H_sensor^trans`；Σ_c 在 𝒩 方向注入大先验，使 `U=tr(Σ_c)` 显式编码不可辨识性。

**定义 297（TIE）** 最大化 `log det G` s.t. `q_k∈S_safe`、力矩/时长/任务扰动预算；激励是受限安全实验，不扩大可达集；机群共享库随机抽样 + hold-out。

**定义 298（FCD）** `z_i=c(x)+f_i+ε_i`；参考队列 `R_i={j:dist(x_j,x_i)≤ρ}`；`ĉ_i=Agg_{j∈R_i}z_j`；`d_i=z_i−ĉ_i`；H0 下 `Var(d_i)≈σ_ε²(1+1/N_eff)`。

**定义 299（RFA）** trimmed mean/Krum，故障比例 ≤β 时共识误差有界；信任权重 leave-one-out 更新；独立新鲜锚点为信任根；协变量匹配处理异质性。

**定义 300（DCP）** canary 组合随机分配，覆盖 `1−(1−p_m)^{N_eff}`；保留不可修复性；随机轮换 + 留出验证防泄漏/投毒。

**定义 301（HCC）** `C_cell=⊗C_i`（租约重叠 ∧ 干扰界 `I_cell`），`C_fleet=⊗C_cell`；可靠性：∧φ_i 在 I 下蕴含 Φ_fleet；树深 O(log N)。

**定义 302（TRS）** `λ_floor=max(0.6, 0.8·1[U>τ_cal], 0.8·1[τ_ref<τ_trust])`；`τ_risk=τ⁰(1−κ_r U)(1+κ_s(1−τ_ref))`；`k←min(k,k_scale(τ_ref))`——只收紧。

**定义 303（独立性公理与检验）** A95 力矩–F/T 溯源无环；A96 稀疏故障/拜占庭 ≤β/非完全相关/锚点率 ≥ρ_anchor；A97 协变量充分可交换。共因检测器：全体同向漂移且超环境模型 ⇒ 环境变化与共因故障不可分 ⇒ 全局抬 U + 请求锚点。

**定义 304（AIC-SCALE）** `ℰ_SCALE=ℰ_CALM×ℰ_jtr×ℰ_fleet×ℰ_hcc`；ℰ_jtr={parity 误归因, 激励诱发风险, 力矩通道慢漂}；ℰ_fleet={循环标定, 队列失配, 拜占庭投毒, 共因漂移, 共识陈旧/分区, canary 泄漏}；ℰ_hcc={组合错误, 租约过期, 聚合节点被攻陷}。

**定义 305（J_SCALE）** `J_SCALE=(J_CALM, G_hash, κ(G), τ_ref, anchor_ids, hcc_root_hash, scale_ver)`；Valid ⇔ Valid(J_CALM) ∧ κ(G)<κ_max ∧（τ_ref>τ_trust ∨ 退化模式且 λ_floor 抬升）∧ 独立性检验通过。

**定义 306（管线与优雅降级）** 离线力矩–F/T 辨识 + 机群激励库/锚点配置 + 溯源建档；在线 parity→IGC→FCD→RFA→TRS→HCC→DCP→CAC；断网/参照不可信 ⇒ R68 单机模式 + λ_floor 抬升 + 𝒩 方向零标定增益。

```python
# IP-253 JTR：动量观测 + parity 残差
class JointTorqueReference:
    def step(self, q, dq, tau_m, F_m, dt):
        p = self.M(q) @ dq
        if self.p is None: self.p = p
        tau_ext = self.Ko * (p - self.p)
        self.p = p
        return self.jac(q).T @ F_m - tau_ext, tau_ext

# IP-254 IGC：只在可辨识子空间吸收
class IdentifiabilityGatedCalibration:
    def observe(self, J, r_parity):
        self.buffer.append((np.hstack([J.T, -np.eye(J.shape[1])]), r_parity))

    def gate(self):
        A = np.vstack([a for a, _ in self.buffer[-K_MAX:]])
        lam, U = np.linalg.eigh(A.T @ A)
        obs = U[:, lam >= self.lam_min]
        return obs @ obs.T, lam, A.T @ A

    def update(self, cof, z_meas, h, tau_ref):
        Pi_obs, lam, G = self.gate()
        delta = Pi_obs @ cof.K @ (z_meas - h)
        cof.c = cof.rate_limit(cof.c + np.diag(tau_ref) @ delta)

# IP-255 TIE：安全不变集内 D-optimal 激励
def torque_informed_excitation(robot, S_safe, N):
    best = None
    for seq in randomized_candidates(N):          # 共享库 + 随机化
        if not all(c in S_safe for c in seq): continue
        G = gram_over(seq, robot.jac)
        score = np.log(np.linalg.det(G + 1e-9*np.eye(G.shape[0])))
        if best is None or score > best[0]: best = (score, seq)
    return best[1]

# IP-256/257 FCD + RFA：群体差分 + 鲁棒共识
class FleetConsensusDifferential:
    def differential(self, unit_id, z, cohort):
        zs = np.stack([z[j] for j in cohort])
        w  = np.array([self.trust.get(j, 1.0) for j in cohort])
        c_hat = trimmed_weighted_mean(zs, w, trim=self.beta)
        d = z[unit_id] - c_hat
        return d, c_hat, self._trust_score(z, cohort, c_hat)

    def _trust_score(self, z, cohort, c_hat):
        disp   = np.median(np.abs(z[list(cohort)] - c_hat))
        byz    = byzantine_flags(z, cohort)        # Krum / 留一验证
        hetero = covariate_mismatch(z, cohort)     # A97
        return sigmoid(-(disp + byz + hetero))

# IP-259 HCC：层级证书组合
class HierarchicalCertificateChain:
    def compose(self, children):
        assert all(lease_overlap(children))
        assert interference_bound(children) <= I_MAX
        return Certificate(AND([c.claim for c in children]),
                           max(c.tau for c in children),
                           min(c.lease for c in children),
                           min(c.tau_ref for c in children))

# IP-262 主闭环
def SCALE_RAS_round(M, obs, unit_id, cohort):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    r_parity, tau_ext = M.jtr.step(M.q, M.dq, M.tau_m, M.F_m, M.dt)
    M.igc.observe(M.jac(M.q), r_parity)
    Pi_obs, lam, G = M.igc.gate()
    tau_torque = 0.0 if M.provenance.has_cycle() else f_trust(lam, r_parity)

    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    c, U, thr = M.cof.step(np.concatenate([o['cal'], r_parity]),
                           residuals(x_prime, o), sigma_stat(M), Pi_obs=Pi_obs)
    r_perp = orthogonal_residual(G, r_parity)

    d, c_hat, tau_fleet = M.fcd.differential(unit_id, np.concatenate([o['cal'], r_parity]), cohort)
    tau_ref = min(tau_torque, tau_fleet)

    wm_preds = M.mtm.rollout(z, M.ach.propose_actions(x_prime, 5))
    joint_post = M.cfa(r_perp, o['pi'], c, U, tau_ref)

    lam_floor = max(0.6, 0.8 if (U > TAU_CAL or tau_ref < TAU_TRUST) else 0.6)
    lam = max(M.efs.risk_scale(joint_post), lam_floor,
              0.8 if (o['qual']['face'] < 0.8 or wm_drift) else 0.6)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, H=M.vista.H),
                                    joint_post, M.m_ras, M.alpha_chunk, wm_preds)
    if tau_ref < TAU_TRUST or U > TAU_CAL:
        k = min(k, k_scale(tau_ref, U))

    M.hcc.update(unit_id, Certificate(thr, lam, k, tau_ref))
    M.vqa_c.submit_async(wm_preds, {'parity': r_perp, 'd': d, 'tau_ref': tau_ref})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint_post, (c, U, tau_ref)
```

## 4. 推导

**引理 16（力矩–F/T 偏置可分离与构型签名）** 自由空间残差 `r_k=J(q_k)ᵀb_F−b_τ`；若 `{(J(q_1)−J(q_k))ᵀ}` 张成 ℝ⁶，则 A 列满秩，`(b_F,b_τ)` 可辨识，`Var(φ̂)=σ²(AᵀA)^{-1}`。世界系常值载荷 `J(q)ᵀAd(g(q))F_w` 随姿态变化，**不等于任何常值 b_F 的像**，其正交残差不可被标定吸收。系：构型多样性同时提供「偏置间分离」与「真实载荷 vs 偏置分离」；TIE 必须激发姿态变化。

**引理 17（群体差分阈值下移）** `z_i=c+f_i+ε_i`，稀疏故障 ≤βN。H0 下 `d_i=z_i−ĉ_i` 的 `Var≈σ_ε²(1+1/N_eff)`，最小可检故障 `MDF(N)≈(z_{1−α}+z_{1−β_power})σ_ε√(1+1/N_eff)`；单机因共模混叠 `MDF_single≥O(σ_c)`。σ_c≫σ_ε 时检出幅度被压低约 `σ_c/(σ_ε√(1+1/N_eff))` 倍，N 增大后饱和。系：可扩展性是可辨识性资源，超过队列同质性上限后收益饱和并转为异质性偏差。

**引理 18（HCC 组合与通信）** 单元证书在干扰界 `I_cell` 下 sound 且租约两两重叠 ⇒ AND 组合在 max 干扰/min 租约下 sound。树深 O(log N) ⇒ 每单位每轮 O(1) 消息，聚合节点 O(deg)。系：规模扩展代价是对数通信；聚合节点是相关失效点，需多副本 + 拜占庭聚合。

**引理 19（DCP 覆盖）** 独立分配下覆盖 `1−(1−p_m)^{N_eff}`；共享且可预测时有效独立单位坍缩，退化为 `p_m`。系：共享 canary 是覆盖率与相关失效的权衡，随机轮换 + 留出验证必要。

**定理 16（端到端一致性与优雅降级）** A87–A97 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_jtr+α_fleet`（α_jtr 受 κ(G) 约束，α_fleet 受 N_eff 与鲁棒界约束）；
2. `τ_ref<τ_trust ∨ U>τ_cal ⇒ λ_risk≥0.8 ∧ k 收缩 ∧ 𝒩 方向零标定增益`；
3. 参照不可用/独立性失败 ⇒ 退化 R68 单机且 `λ_floor` 抬升 ⇒ `Safe(SCALE)≥Safe(R68)`；
4. A95–A97 且构型多样性满足时，对 R68 标定带宽内的**特异慢故障**，检出概率严格高于 R68。

**定理 17（鲁棒参照界）** 恶意比例 ≤β、trimmed breakdown ≥β ⇒ 共识误差 O(β·diam)；保形校准使 H0 误报 ≤α；检测到超限拜占庭/共因漂移/队列失配 ⇒ `τ_fleet→0` 并退化。**机群共识无法检测共模故障**，必须依赖独立锚点与力矩参照。

**定理 18（可扩展性权衡）** A95–A97 且 `ρ_anchor>0` 下，MDF 随 N_eff 单调下降至饱和；相关失效概率随共享资产规模上升；存在最优 N* 使「检出收益−相关失效损失」最大。系：可扩展性必须被认证地扩展，而非无脑复制。

## 7. 本轮最大风险

**一句话**：SCALE-RAS 把安全性押在「外部参照与被参照链相互独立」上——**若力矩与 F/T 互为标定源（循环标定），或整批机器人共享同批次传感器/同版本固件/同一套被投毒的激励与 canary 资产，则物理参照与群体参照会一致地错，系统将在两份互相印证的错误参照下获得比 R68 单机自证更高的虚假置信，把「慢故障隐形」升级为「慢故障被双重背书」**。

**次级风险与缓解**：激励诱发风险（TIE 限定认证不变集 + 能耗/节拍预算 + E291）；队列异质性偏差（协变量匹配 + 失配告警 + τ_fleet 下调）；拜占庭共识（trimmed/Krum + 独立锚点 + 多副本）；共因漂移不可分（全局抬 U + 请求锚点，绝不默认「大家都正常」）；分布式 canary 泄漏（随机轮换 + 留出验证）；力矩通道元故障（E296 监控 + τ_torque 自降级）。
