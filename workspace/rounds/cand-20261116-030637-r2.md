# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「对话管理」×「多语言支持」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**对话承诺 + 语义中间语言 + 接地证书**。两个灵感各自治理 v9 的一个盲区：交互债（v9 把语音当作"单句→指标"的一次性管道，没有多轮指代、澄清与撤销）与语言债（v9 的声学指标与阈值默认单一语言/文化，跨语言时情感与置信标定系统性偏移）。必须通过**中立元退化**保证任一交互层失效即退回 v9 单轮单语行为，而非行为漂移。

## 0. 直觉与动机

**灵感 1（对话管理 → 承诺账本与"澄清即主动感知"）**
直觉：家用机器人真正危险的不是"听不懂"，而是"听懂了但指错了东西还很自信地执行"。一句"把那个红的给我"若是三义指代，v9 会把它压成一个软指标照常进块执行；严谨的交互系统应把"我承诺了什么、指哪个、确认没有、是否还新鲜"变成可审计对象。核心创新：**对话承诺管理器（DialogueCommitmentManager, DCM）**——承诺账本 ℒ 记录每条 (意图, 指代集, 约束, 确认令牌, 对话纪元)，仅当指代唯一、确认未过期、接地证书有效且无待澄清问题时 Executable；歧义超预算即强制澄清，而澄清不是"多问一句"，是**带信息增益的主动感知**（选最具判别力的属性/视角，必要时请求转头补看）。核心不变量：**对话可以推翻承诺，但不能推翻安全**——任何撤销/改口先令当前动作在中止点安全停驻，再重开承诺。对应 P13 承诺账本律。

**灵感 2（多语言支持 → 语义中间语言与"语言不变的安全判定"）**
直觉：把"多语言"做成多套解析器各自接安全逻辑，等于把安全论证复制 N 份，必然漂移。正确做法是让所有语言先塌缩到一个**类型化语义中间语言（Semantic Interlingua）**，下游安全判定只看中间帧与置信，不看表层语言。核心创新：**多语中间层（PolyglotInterlingua, PIL）**：语言后验 L（含 token 级 code-switching 标签）→ 统一帧 F=(意图, 槽位, 指代约束, 空间指示, 紧迫度, 置信)；同时做**分语种标定**：情感韵律与语音置信在不同语言/文化有系统偏移，用带收缩的分语种偏置 κ_l 校正 MetaWeight/ER，避免"某语言听起来更平静 ⇒ 被误判低紧迫"。核心不变量：**语言不变律**——在解析误差界内，同一语义帧无论用哪种语言表达，安全判定（接受/拒绝/弃权）一致；置信不足则弃权转澄清，绝不"低置信强接受"。对应 P14 语言不变律。

**灵感 3（跨学科桥接 → 接地证书把"指代"接入分块证书）**
直觉：v9 的块证书只约束"动作会不会撞"，却默认"抓的对象就是用户说的对象"——这是安全论证里一个从没写出来的隐藏前提。桥接创新：**接地证书器（GroundingCertifier, GC）** 为每个指代绑定签发 g=(歧义边际 m, 新鲜度 a, 语言/解析置信 p, 空间一致性 s)，只有 g 有效时 AC 才允许生成作用于该物体的块；用户中途改口（对话矛盾）作为**外部中止事件** β_dlg 并入 v9 中块守卫，切换到最近安全中止点。于是"对话层"与"控制层"通过证书与一个布尔信号耦合，而不是靠字符串约定。对应 P15 接地证书律。

## 1. 研究问题（轮次升级版）

- **Q1（承诺安全边界）**：在什么账本不变量与对话纪元机制下，撤销/改口/过期确认永不导致"已确认但指错"的不可逆执行？澄清预算与熵减门槛如何同时保证安全与活性（不死循环）？
- **Q2（语言不变性的可证界限）**：跨语言与代码切换下，安全判定能对表层语言不变到什么误差界？解析置信、语言后验与接地歧义边际如何共同决定"弃权"而非"误接受"？
- **Q3（交互-控制耦合）**：对话轮（5Hz）与分块控制（50Hz）如何共享预算而不破坏 v9 引理 86 的可行性？对话中止事件并入中块守卫的延迟上界是多少？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 承诺账本律（Dialogue Commitment, DCM）**
每条不可逆动作绑定承诺 c=(ι,R,K,τ_c,φ,e)。仅当 |R|=1 ∧ 确认令牌属于当前对话纪元 e ∧ 未过期 ∧ 接地证书有效 ∧ 无待澄清问题时才可执行。任何改变意图/指代的话语使纪元自增并吊销相关未执行承诺；撤销/改口先令当前块在最近中止点安全停驻，再重开承诺。

**P14 语言不变律（Language-Invariance, PIL）**
所有语言经 π_l 映射到同一类型化中间帧 F；下游安全判定只依赖 (F, 接地证书)，不依赖表层语言 l。语言/解析置信低于阈值即 abstain 转澄清。分语种标定 κ_l 只作用于情感/置信的加性偏置，且带收缩，低资源语言自动退回全局标定并下调置信。

**P15 接地证书律（Grounding Certificate, GC）**
每个指代 r 的绑定携带 g_r=(m_r,a_r,p_r,s_r)；g 有效是 AC 生成作用于 r 的动作块的必要条件，也是 v9 五条件软证书的新增输入。对话层只能通过"令 g 失效 + 置 β_dlg"影响控制层，不能直接下发动作。

## 3. 与基线的接口（如何退化）

- DCM 失效 ⇒ 每条话语独立成承诺、无跨轮记忆（账本更新取恒等元 no-op），等价 v9 单轮管道；
- PIL 失效 ⇒ 锁定部署默认语言（如 zh-CN）严格词表，非默认语言一律弃权转人工/物理模式，等价 v9 单语接口；
- GC 失效 ⇒ 注入 v9 帧内接地证书（单帧感知，无跨轮/跨语证书），等价 v9 接地方式；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 五级链退回（AC→MW→ID→DA/SPR/Cal→v7→v6）；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再按 v9 链退回 v8。

## 4. 预期贡献

1. **对话承诺账本**：把多轮交互从"文本历史"升级为带纪元、确认令牌与吊销语义的安全对象，证明撤销/改口不会导致过期确认被复用；
2. **语言不变的语义中间层**：以类型化帧 + 语言后验 + 分语种收缩标定，把跨语言安全判定从"多套逻辑"变成"一个帧上的判定 + 弃权规则"；
3. **接地证书**：补上 v9 块证书缺失的"对象身份"前提，使"指错对象"第一次进入可证安全边界；
4. **交互-控制解耦**：5Hz 对话核只向 50Hz 控制环送一个布尔中止信号，保持 v9 的实时可行性，同时给出 ≤1 控制周期的中止延迟上界；E571–E591 覆盖跨语言解析、代码切换、承诺安全、接地、预算隔离与端到端任务。

## 5. 本轮最大风险

**一句话**：语言后验与对话状态由同一条噪声语音通道推断，而同一通道又同时供给声学安全指标——当用户 code-switch、口音或低资源语言导致语言/意图误判时，系统可能把"指错对象的确认"当成有效承诺执行，即"最危险的不是没听懂，而是用错误的语言自信地听懂并确认"。

**新增定义 540（对话信念状态 DialogueBelief）** 𝒟_t = (b_t, ℒ_t, e_t, Q_t)，其中 b_t ∈ Δ(ℐ×2^𝒪) 为意图-指代后验，ℒ_t 为承诺账本，e_t∈ℕ 为对话纪元，Q_t 为待澄清问题集。每处理一句 u_t 执行 𝒟_{t+1}=Update(𝒟_t,u_t)；Update 在意图或指代发生变化时强制 e_{t+1}=e_t+1。

**新增定义 541（承诺与账本 Commitment/Ledger）** c=(ι,R,K,τ_c,φ,e,st)，ι∈ℐ，R⊆𝒪，K 为约束集，τ_c=(hash_SIL(R), spatial_anchor(R), e_conf, t_conf)，φ 为来源证据，st∈{proposed, clarifying, confirmed, executing, done, aborted, revoked}。账本 ℒ_t 为承诺多重集。
```
Executable(c, 𝒟_t) ⇔ |R|=1 ∧ st=confirmed ∧ e_conf=e_t
                    ∧ (t − t_conf) ≤ T_fresh ∧ g_R.valid ∧ Q_t=∅
```

**新增定义 542（歧义与澄清预算 Ambiguity/Budget）** 令 𝒪_cand 为候选指代集，
```
Amb(R|𝒟) = H(r|𝒟) / log|𝒪_cand| ∈ [0,1]
```
若 Amb>τ_amb 或 g_R 无效则进入澄清。澄清问题 q 由属性选择给出：a* = argmax_a I(R; a | 𝒟)（最大信息增益）。预算 B_amb：每承诺澄清至多 B_amb 次，且每次须满足 ΔH ≥ δ_clar，否则 EscalateHuman。澄清期间 Q_t≠∅。

**新增定义 543（语义中间帧 SemanticInterlingua）** F=(ι, S, R_c, D, urgency, conf)，S 为槽位映射（缺失槽取中立元 ⊥），R_c 为指代约束（类别/属性/空间关系），D 为空间指示（"这个/左边/那个"），urgency∈[0,1]，conf∈[0,1]。语言解析器 π_l: U_l→F。
```
代码切换：u = u^{(1)}…u^{(m)}，标签 ℓ_j ⇒ F = ⊔_j π_{ℓ_j}(u^{(j)})
帧合并 ⊔ 遇槽位冲突取 ⊥ 且 conf ← conf·ρ  (0<ρ<1)
```

**新增定义 544（语言后验与代码切换 LanguagePosterior）** L_t∈Δ(Λ∪{mix})，token 标签 ℓ(x_i)；p_l=L_t(l)。混合帧置信
```
conf_mix = min_j conf(F_j) · agree({F_j})
```
其中 agree 为各子帧在意图/指代约束上的一致率。若 max_l p_l < τ_lang 或 conf_mix < τ_mix ⇒ **abstain（弃权转澄清）**。

**新增定义 545（接地证书 GroundingCertificate）** 对指代 r，
```
g_r = (m_r, a_r, p_r, s_r)
m_r = P(r|evidence) − max_{r'≠r} P(r'|evidence)        # SIL+视觉联合后验边际
a_r = 当前控制周期 − r 的最后观测周期                    # 新鲜度
p_r = conf(F) · L_t(argmax_l)                          # 解析×语言置信
s_r = |bearing_depth预测(SLAM) − 观测(r)|              # 空间一致性残差
valid ⇔ m_r ≥ τ_m ∧ a_r ≤ τ_a ∧ p_r ≥ τ_p ∧ s_r ≤ τ_s
```

**新增定义 546（分语种标定 CrossLingualCalibration）**
```
κ_l = (n_l·κ̂_l + λ·κ_0) / (n_l + λ),    s̃ = s − κ_l
若 n_l < n_min ⇒ κ_l ← κ_0 且 p_r ← p_r·γ  (γ<1)
```
κ̂_l 为该语言的情感韵律/置信偏置估计，κ_0 为全局偏置，λ∈[20,50] 为收缩强度。用于 MetaWeight、ER 评分与 urgency 阈值，消除语言相关的加性系统偏差。

**新增定义 547（对话诱导中止 DialogueAbort）** 若新对话行为 a_t∈{Revoke, Correct, NewReferent} 且其目标优先级不低于当前块所指代，则令 β_dlg=1。中块守卫在下一控制周期（≤20ms）读取 β_dlg，切换到最近安全中止点 p*（v9 定义 534）。β_dlg 是交互层向控制层唯一传递的中止信号。

**新增定义 548（纪元不变与抗重放 EpochInvariance）** 确认令牌绑定 (hash_SIL(R), spatial_anchor(R), e_conf)。Executable 要求 e_conf=e_t 且 hash 与当前 R 一致；任何改变指代的对话行为使 e_t 自增，故旧令牌失效。空间锚点进入哈希，使"同一名称但被移动过的物体"也不能复用旧确认。

**新增定义 549（交互-控制预算隔离 BudgetSeparation）** 交互核运行于 5Hz：D_turn=200ms，Ŵ_PIL≤8ms，Ŵ_DCM≤10ms，Ŵ_GC≤2ms，合计 ≤20ms；仅 β_dlg（O(1) 布尔，≤0.1ms）与已承诺命令跨入 50Hz 控制环。控制预算仍为感知 2ms + 决策 20ms。

**新增定义 550（语言不变判定 LanguageInvariance）** 记 Decision(F,g)∈{accept, reject, abstain}。若两种语言表述映射帧满足 ‖F−F'‖_SIL ≤ ε_π、g,g' 均 valid 且 m ≥ τ_m + 2ε_π，则 Decision(F,g)=Decision(F',g')；任一条件不满足则 abstain。此谓词是 P14 的形式化，也是引理 88 的证明目标。

## 2. 形式化定义（要点与升级）

```
δ_trigger = { σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
```

- **升级定义 531（软硬约束衔接）** M₀ 判据增加两个交互入口：β_dlg=1 ⇒ 立即切换 p* 或安全停驻；g_R 失效 ⇒ 拒绝生成作用于 r 的块。

## 3. 关键算法骨架

```python
# IP-358 PolyglotInterlingua：多语中间层
class PolyglotInterlingua:
    def __init__(self, parsers, lang_tagger, kappa0, lam=30, n_min=100):
        self.parsers, self.tagger = parsers, lang_tagger   # parsers: lang -> π_l
        self.kappa, self.kappa0, self.lam, self.n_min = {}, kappa0, lam, n_min

    def parse(self, utterance):
        spans = self.tagger.segment(utterance)             # [(u_j, l_j)]
        partials = [self.parsers[l].parse(u) for u, l in spans]
        F = reduce(merge_frames, partials)                 # 定义 543 的 ⊔
        L = self.lang_posterior(spans)                     # 定义 544
        F.conf = min(F.conf, self.mixed_conf(L, partials))
        if max(L.values()) < TAU_LANG or F.conf < TAU_MIX:
            F.abstain = True                               # 低置信弃权
        return F, L

    def calibrate(self, score, lang):                      # 定义 546
        n_l = self.counts.get(lang, 0)
        k = self.kappa.get(lang, self.kappa0) if n_l >= self.n_min else self.kappa0
        return score - k

class GroundingCertifier:
    def __init__(self, tau_m, tau_a, tau_p, tau_s):
        self.tm, self.ta, self.tp, self.ts = tau_m, tau_a, tau_p, tau_s

    def certify(self, r, F, perception, epoch):
        cands = perception.detect(F.R_c)
        m = posterior_margin(cands, r)                     # 定义 545
        g = GroundingCert(
            margin=m,
            age=epoch - perception.last_seen(r),
            parse_conf=F.conf,
            spatial_resid=spatial_residual(r, perception))
        g.valid = (g.margin >= self.tm and g.age <= self.ta and
                   g.parse_conf >= self.tp and g.spatial_resid <= self.ts)
        return g


# IP-357 DialogueCommitmentManager：对话承诺管理器
class DialogueCommitmentManager:
    def __init__(self, ledger, dst, gc, clarifier,
                 tau_amb=0.35, b_amb=3, delta_clar=0.15, t_fresh=50):
        self.ledger, self.dst, self.gc = ledger, dst, gc
        self.clarifier = clarifier
        self.tau_amb, self.b_amb = tau_amb, b_amb
        self.delta_clar, self.t_fresh = delta_clar, t_fresh

    def step(self, F, L, D, perception):
        if getattr(F, "abstain", False):
            return Clarify(self.clarifier.ask_language(F)), 0.0

        D.b = self.dst.update(D.b, F, L)                   # 定义 540
        if F.intent in IRREVERSIBLE:
            c = self.ledger.propose(F, D.e)
            if self.ambiguity(c.R, D) > self.tau_amb:
                q = self.clarifier.select(c.R, D)          # 最大信息增益
                if c.n_clar < self.b_amb and q.gain >= self.delta_clar:
                    c.n_clar += 1; c.st = "clarifying"
                    D.Q.add(q); return Clarify(q), 0.0
                return EscalateHuman(), 0.0                # 预算耗尽
            g = self.gc.certify(c.R[0], F, perception, D.e)
            if not g.valid:
                return Clarify(self.clarifier.refine(c.R, D)), 0.0
            if not self.ledger.confirmed(c, D.e):
                return AskConfirm(c), 0.0                  # 不含执行
            c.st = "confirmed"; c.st = "executing"
            return Commit(c), 0.0

        beta = self.abort_signal(F, D)                     # 可逆行为
        return Ack(), beta

    def abort_signal(self, F, D):                          # 定义 547
        if F.intent in ("Revoke", "Correct", "NewReferent"):
            D.e += 1                                       # 定义 548 自增纪元
            self.ledger.revoke_open(D.e)
            return 1.0
        return 0.0

    def ambiguity(self, R, D):                             # 定义 542
        return normalized_entropy(R, D.b) if len(R) > 1 else 0.0
```

## 4. 推导

**引理 87（承诺执行安全性）** 若 Executable(c,𝒟_t) 成立，则 c 的执行作用于唯一、当前新鲜、接地有效的指代，且确认令牌绑定当前纪元、无待澄清问题；反之任何条件失败只能转入 Clarify/Escalate 或在安全中止点停驻。证明：定义 541 六项合取逐项对应"指代唯一（|R|=1）、确认属当前纪元（e_conf=e_t）、未过期（T_fresh）、接地有效（g_R.valid）、无开放澄清（Q_t=∅）"。AC 生成作用于 r 的块前强制 g_R.valid（P15），故无证书无动作；令牌哈希含 SIL 指代身份与空间锚点（定义 548），改口使纪元自增、旧令牌失配；与 v9 中块守卫的 β_dlg 分支联合，撤销时先切 p* 再重开，刹车终点距障碍 ≥ d_safe（v9 引理 82(ii)）。故不存在"已确认但指错"的不可逆执行。∎

**引理 88（语言不变的安全判定）** 假设指代边际对 SIL 距离满足 1-Lipschitz。设两语言表述 u,u' 满足 π_l(u)=F、π_{l'}(u')=F'，‖F−F'‖_SIL ≤ ε_π，且 conf≥τ_p。则 (i) 若 m ≥ τ_m + 2ε_π，两侧后验边际均 ≥τ_m，判定同为 accept；(ii) 若任一侧落入灰区 [τ_m, τ_m+2ε_π)，定义 550 强制 abstain，不发生单侧误接受；(iii) 分语种标定仅引入可估加性偏置，收缩误差 |κ_l−κ_l^⋆| ≤ Cλ/(n_l+λ)，在阈值余量内不改变判定符号。故在 ε_π 意义下语言不变，且退化方向恒为弃权（安全侧）。∎

**引理 89（澄清活性 / 无死循环）** 初始 H_0 ≤ log|𝒪_cand|，每次澄清满足 ΔH ≥ δ_clar > 0，故至多 ⌈H_0/δ_clar⌉ 次即可使 Amb < τ_amb；预算 B_amb 进一步截断，超预算转 EscalateHuman。澄清期间 Q_t≠∅，由定义 541 Executable 为假，不执行任何不可逆动作。有限时间内必然终止于"已澄清"或"升级人工"，无死锁。∎

**引理 90（交互层退化与 v9 等价）** 对三个新模块分别注入中立元：DCM 失效 ⇒ Update 退化为单轮、跨轮账本更新取恒等元（no-op），即 v9 单句管道；PIL 失效 ⇒ π_l 固定默认语言、非默认输入 abstain（保守），下游读到的 F 与 v9 单语接口一致；GC 失效 ⇒ g 注入 v9 帧内接地证书 g^{v9}，接受/拒绝判定与 v9 相同。三者都只对下游端口做恒等或保守替换，不改变取值集合，故可观测行为与 v9 对应路径等价，安全性由 v9 引理 82–86 传递成立。∎

**引理 91（交互-控制预算隔离与中止延迟）** 交互核独立运行于 5Hz，预算封顶 Ŵ_PIL+Ŵ_DCM+Ŵ_GC ≤ 20ms；跨入 50Hz 的仅 β_dlg（布尔读，≤0.1ms）与已承诺命令（本就在 v9 决策预算内）。控制侧 ΣŴ_m 不变，故 v9 引理 86 的 50Hz 可行性保持；β_dlg 在下一控制周期被中块守卫读取，故对话诱导中止延迟 ≤1 个控制周期 = 20ms。∎

**引理 92（纪元抗重放）** 反设旧令牌 τ_c=(hash(R),anchor(R),e_conf) 能通过新指代 R' 的 Executable 检查，则需 e_conf=e_t 且 hash(R')=hash(R)、anchor(R')=anchor(R)。但产生 R'（或移动 R）的对话行为属于改变指代，定义 540/548 强制 e_t←e_conf+1，故 e_conf≠e_t，矛盾；若 R'=R 但空间锚点改变，anchor 进入哈希亦不匹配。因此"改口后复用旧确认"在密码学哈希与纪元双重约束下不可行。∎

## 8. 本轮最大风险

**一句话**：语言后验与对话状态由同一条噪声语音通道推断，而同一通道又同时供给声学安全指标——当用户 code-switch、口音或低资源语言导致语言/意图误判时，系统可能把"指错对象的确认"当成有效承诺执行，即"最危险的不是没听懂，而是用错误的语言自信地听懂并确认"。
