# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「流匹配策略」×「物体泛化」）

> 第 54 轮把技能组合从能力匹配推进到动作-鲁棒性双证书，动作空间 `A = A_c × A_e` 成为第一性约束。本轮引入 **流匹配策略（Flow Matching Policy）** 与 **物体泛化（Object Generalization）**：技能不再是静态动作占用 `α_S`，而是条件于物体的连续速度场 `v_θ(a,t|z(o))`；泛化不再是「在物体集合上不掉点」，而是「从训练物体到新物体的概率路径可传输且有界」。核心矛盾：H22：流匹配策略的速度场在自由空间光滑、在接触模式边界本质不连续，基于 Lipschitz 的平滑泛化证书在最需要它的接触处最不可信；H23：物体中心潜变量 `z(o)` 若遗漏质量/摩擦/可变形等物理属性，`z` 距离小但真实泛化差距大，形成「潜在充分性幻觉」。

## 0. 直觉与动机

**灵感 1（流匹配策略 → 技能从静态占用升级为可传输轨迹场）**
直觉：第 54 轮的 `α_S : A → [0,1]` 回答「这个动作能不能做」，但没回答「从哪个动作出发、沿什么路径到达」。流匹配策略把技能写成条件速度场 `v_θ^S(a,t|z(o))`，技能执行 = 解 ODE `da/dt = v_θ^S(a,t|z(o))`，`a(0)~N(0,I)`。技能由此成为一个 **流管（flow tube）** 而非一个点集：动作剖面从静态覆盖率变成「轨道穿过区域」的测度。组合也从集合交集变成 **流拼接**，兼容性由「上游终态分布 ≈ 下游初态分布」的 handoff 距离决定。

**灵感 2（物体泛化 → 从「分布内不掉点」变为「概率路径可传输」）**
直觉：物体泛化不是策略在物体集合 `O` 上碰巧成功，而是训练物体 `o` 诱导的动作分布能沿概率路径 **传输** 到新物体 `o'` 的动作分布。用最优传输距离 `W2(π(·|o), π(·|o'))` 度量「要改多少」，用物体潜变量距离 `d_Z(z(o),z(o'))` 度量「看起来多像」。泛化证书给出 **泛化半径 `r_gen`**：`z` 落在半径内的新物体可被证书覆盖。关键洞察：`W2` 小不等于 `o'` 成功——若 `z` 没编码质量/摩擦/可变形，则「看起来像」是假象。

**灵感 3（接触模式 → 速度场是分段光滑流形拼接）**
直觉：接触丰富操作的速度场不是全局 Lipschitz 的。自由空间、接触保持、滑移、冲击各对应一个模式区域 `Ω_m`，速度场在每个 `Ω_m` 内光滑，在边界 `Γ` 处发生跳跃 `J_Γ`。因此泛化证书必须 **逐模式成立 + 跨边界有跳跃预算**。基于全局 Lipschitz 常数的传输界会在接触边界处给出空洞保证——而这恰是泛化最脆弱的地方（新物体的摩擦/质量差异首先在接触处显形）。

**灵感 4（等变 → 物体泛化的免费维度与可证伪残差）**
直觉：若策略对 `SE(3)×尺度` 等变，则物体泛化的一部分维度（位姿、尺度）被对称性免费吸收，只剩形状/外观/物理属性需要泛化。等变误差 `E_g` 是一个可直接测量的「伪泛化损失」：它把群变换下速度场的失配量化为泛化半径的扣减项。等变训练不是「更优雅」，而是 **用可测误差换掉不可测泛化**。

**灵感 5（云边残差流 → 粗流规划 + 细流修正）**
直觉：第 54 轮的 `γ_ce : A_c → A_e` 升级为流场映射 `γ_ce : v_c → v_e`。云端输出低频粗流 `v_c`（大时间步、全局可达），边端学习残差流 `r_θ` 使 `v_e = γ_ce(v_c) + r_θ`，并强制 `||r_θ|| ≤ δ_v`。这既保留第 54 轮的「云规划-边校验」闭环，又让「动作对齐」变成 **流场对齐**，`δ_a` 泛化为 `δ_v`。

**灵感 6（金字塔扩展 → 物体泛化层 𝕆）**
直觉：在第 54 轮动作-协同层 `𝔸` 之上叠加 **物体泛化层 `𝕆`**：`𝕆_0` 物体物理属性（质量/摩擦/可变形），`𝕆_1` 物体潜变量 `z(o)` 与充分性残差，`𝕆_2` 条件流场 `v_θ(·|z)`，`𝕆_3` 传输泛化证书 `J_obj`。跨层传递需同时携带 `α_S`、`ρ`、`J_obj`，形成 **动作-鲁棒性-泛化三证书体系**。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（流匹配技能策略）**
技能 `S` 条件于物体 `o`（`z=φ(o)∈Z`）的速度场 `v_θ^S : A × [0,1] × Z → T A`。策略 `π_θ^S(·|o)` 是基分布 `a_0~N(0,I)` 在 ODE
```
da/dt = v_θ^S(a,t|z(o)),  a(0)=a_0
```
下的推前分布。训练用条件流匹配（OT 路径）：
```
L_CFM = E_{t,(a_0,a_1),o} || v_θ^S((1-t)a_0 + t a_1, t | z(o)) - (a_1 - a_0) ||²
```

**定义 122（流管与连续动作剖面）**
技能流管 `Tube(S,o) = {a(t) : t∈[0,1], a 解定义 121 的 ODE}`。连续动作剖面 `α_S^flow(a|o) = P_{a_0}( ∃t, ||a(t)-a|| ≤ ε )`。**流覆盖** `cover_flow(S,A_T,o)=1` 当且仅当 `∀ a∈A_T, α_S^flow(a|o) ≥ θ_cov`。静态剖面 `α_S` 是 `ε→0` 时流管的支撑测度。

**定义 123（传输泛化差距）**
训练物体 `o` 与新物体 `o'` 的泛化差距
```
G(o,o') = W2( π_θ^S(·|o), π_θ^S(·|o') ) + λ_s · ε_s(o,o')
```
其中 `W2` 为 2-Wasserstein 距离，`ε_s(o,o') = inf_z ( |Prop(o) - Prop(o')| + dist(z, Z) )` 为潜变量无法解释的 **物理属性残差**（质量、摩擦、可变形等），`λ_s` 为残差权重。

**定义 124（物体泛化半径）**
```
r_gen(θ,S,o) = sup{ r : ∀o' [ d_Z(z(o),z(o')) ≤ r ∧ ε_s(o,o') ≤ ε_s^max ⇒ P_success(o') ≥ 1-ε ] }
```
证书只对落入 `r_gen` 且物理残差可接受的新物体签发。

**定义 125（接触模式分解与跳跃）**
轨迹的模式序列 `M(o) = (m_0,…,m_k)`，速度场在每个区域 `Ω_m` 内 `L_v^m`-Lipschitz。边界 `Γ_{ij} = ∂Ω_i ∩ ∂Ω_j`，跳跃 `J_Γ = sup_{a∈Γ} ||v^+(a) - v^-(a)||`。模式转移证书 `C_mode = (M, {L_v^m}, {J_Γ}, P_trans)`，`P_trans` 为模式转移成功率。

**定义 126（等变误差）**
对群 `G = SE(3) × 尺度`，表示 `ρ`，速度场等变误差
```
E_g(θ) = E_{a,o,g~G} || v_θ(ρ(g)a, t | z(g·o)) - dρ(g) v_θ(a,t|z(o)) ||
```
`E_g` 越小，位姿/尺度维度被对称性吸收得越充分。

**定义 127（物体泛化流证书 OGFC）**
```
J_obj = ( z(o), r_gen, G, L_v, E_g, C_mode, δ_v, evidence )
```
满足 `d_Z(z(o),z(o')) ≤ r_gen`、`G ≤ Θ_G`、`J_Γ ≤ Θ_Γ`、`E_g ≤ Θ_e` 时，证书对新物体 `o'` **可部署**。`evidence` 至少含跨模式仿真反例、物理属性探针记录、等变审计样本。

**定义 128（云边残差流契约）**
`v_e = γ_ce(v_c) + r_θ`，`γ_ce` 为粗流到细流的映射，`||r_θ||_∞ ≤ δ_v`，且 `γ_ce` 在流管上 `L_γ`-Lipschitz。契约 `C_flow = (v_c, v_e, δ_v, L_γ, Explain_loop)`；若 `δ_v` 或 `L_γ` 超预算，边端否决并回传残差解释。

## 2. 关键算法 伪代码

### IP-121 FMP（Flow Matching Policy Profiling）

```python
def train_flow_skill(demos, z_fn, steps):
    v = VelocityNet()
    for _ in range(steps):
        a0 = randn_like(actions)
        (a1, o) = sample_demo(demos)
        z = z_fn(o)
        t = rand(steps)
        a_t = (1 - t) * a0 + t * a1
        loss = mse(v(a_t, t, z), a1 - a0)
        v.step(loss)
    return v

def flow_tube(skill, o, n=64, eps=0.05):
    z = skill.z(o)
    trajs = [integrate(skill.v, randn(A_dim), tgrid, z) for _ in range(n)]
    return trajs

def cover_flow(skill, A_T, o, theta_cov=0.8):
    trajs = skill.tube(o)
    return all(occupancy(trajs, a, eps) >= theta_cov for a in A_T)
```

### IP-122 OCZ（Object-Centric Conditioner + Sufficiency Audit）

```python
PHYS_PROPS = ['mass', 'friction', 'deformability']

def object_latent(o, encoder, probe_set):
    z = encoder(o)
    residual = {}
    for p in PHYS_PROPS:
        pred = prop_head(z, p)
        residual[p] = abs(pred - probe_physics(o, p))
    return z, residual   # residual 入证；不归零则泛化半径收缩
```

### IP-123 TGC（Transport Generalization Certificate）

```python
def transport_cert(skill, o_ref, o_new, eps_succ, eps_s_max):
    z0, r0 = skill.latent(o_ref)
    z1, r1 = skill.latent(o_new)
    dz = norm(z0 - z1)
    A0 = sample_actions(skill, o_ref)
    A1 = sample_actions(skill, o_new)
    W = wasserstein2(A0, A1)
    Lv = estimate_lipschitz(skill.v, z0, region=success_basin(skill, o_ref))
    Eg = equivariance_error(skill, SE3_SCALE, o_ref)
    es = max(r1.values())
    budget = eps_succ - W - es - Eg
    r_gen = max(0.0, budget / max(Lv, 1e-6))
    ok = (dz <= r_gen) and (W + es + Eg <= eps_succ) and (es <= eps_s_max)
    return ok, OGFC(z1, r_gen, W + es, Lv, Eg, skill.mode_cert, skill.delta_v)
```

### IP-124 CMC（Contact Mode Certificate）

```python
def contact_mode_cert(trajs, contact_detector, theta_jump):
    modes = segment_modes(trajs, contact_detector)
    for (mi, mj, Gamma) in mode_boundaries(modes):
        jump = max_jump(skill.v, Gamma)
        if jump > theta_jump:
            return ('reject', 'contact_jump', mi, mj, jump)
    cert = ModeCert(modes, {m: lipschitz(skill.v, m) for m in modes},
                    jumps, success_rate(modes))
    return ('ok', cert)
```

### IP-125 EQC（Equivariance Check）

```python
def equivariance_error(skill, group, o, n=256):
    errs = []
    for g in group.sample(n):
        a = sample_base()
        errs.append(norm(
            skill.v(group.act(a, g), t, skill.z(group.act_obj(o, g)))
            - group.dact(skill.v(a, t, skill.z(o)), g)))
    return mean(errs)
```

### IP-126 RCF（Residual Cloud-Edge Flow）

```python
def cloud_edge_flow(v_c, r_theta, gamma_ce, delta_v):
    def v_e(a, t, z):
        return gamma_ce(v_c)(a, t, z) + r_theta(a, t, z)
    if max_norm(r_theta) > delta_v:
        return ('reject', 'residual_budget', max_norm(r_theta))
    if lipschitz(gamma_ce) > L_gamma_budget:
        return ('reject', 'mapping_unstable')
    return ('ok', v_e, FlowContract(v_c, v_e, delta_v))
```

### IP-127 OFC（Object-generalization Flow Composition）

```python
def compose_flows(skill_seq, o, theta_handoff):
    for s_i, s_j in pairs(skill_seq):
        end_i = end_distribution(s_i, o)
        start_j = start_distribution(s_j, o)
        handoff = wasserstein2(end_i, start_j)
        if handoff > theta_handoff:
            return ('reject', 'handoff_mismatch', s_i, s_j, handoff)
    v_comp = time_reparameterized_concat([s.v for s in skill_seq])
    return ('ok', FlowSkill(v_comp, o, handoff_cert=True))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FMP | O(N·T·|A|) 训练 / O(n·T·|A|) 采样 | O(|A|·|Z|) | OT 路径无偏、模式内光滑 |
| OCZ | O(|o|·|Z| + |Prop|·|Z|) | O(|Z|+|Prop|) | 物理探针可观测、残差入证 |
| TGC | O(n²·|A| + |Z|·|A|) | O(n·|A|) | W2 估计收敛、Lipschitz 局部有效 |
| CMC | O(n·T + |Γ|·|A|) | O(|M|·|A|) | 模式完备、跳跃预算闭合 |
| EQC | O(n·|G|·|A|) | O(|A|) | 群作用可实现、表示匹配 |
| RCF | O(|A|·|Z|) | O(|A|·|Z|) | 残差有界、γ_ce Lipschitz |
| OFC | O(k·n²·|A|) | O(k·|A|) | handoff 分布匹配、重参数无奇点 |

**正确性定理（Object-Generalization Flow Soundness, OGFS）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 速度场在每个接触模式内 `L_v`-Lipschitz，且模式分解 `M` 完备覆盖轨迹；**(A30)** `z(o)` 对物理属性 `ε_s`-充分（探针残差 ≤ `ε_s`）；**(A31)** `d_Z(z(o),z(o')) ≤ r ≤ r_gen`；**(A32)** 成功盆地 κ-收缩（`div v ≤ -κ`），残差流 `||r_θ|| ≤ δ_v`。则对新物体 `o'`：
```
P_success(o') ≥ 1 - Σ_d (1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
                 - (L_v·r + ε_s + E_g)/δ_succ
                 - P(J_Γ>Θ_Γ) - P(W2>Θ_w)
```
每项对应一条失败信道：物理残差、潜变量距离、等变失配、接触跳跃、传输成本。

| 风险 | 等级 | 缓解 |
|---|---|---|
| 接触模式边界速度跳跃超预算 | 高 | 模式分解证书 + 跳跃预算 + 接触感知采样 |

| 云边残差流累积漂移 | 中 | `δ_v` 硬预算 + 周期回滚 + 锚点重校准 |
| 流拼接 handoff 不匹配 | 高 | handoff `W2` 证书 + 时间重参数化 + 接缝重采样 |

## 6. 本轮最大风险

**一句话**：流匹配策略与物体泛化把技能从静态动作占用升级为「可传输连续轨迹场 + 泛化半径证书」，但其 soundness **双重依赖接触模式的分段光滑与 `z(o)` 的物理充分性**；一旦接触边界跳跃超出预算、或潜变量遗漏质量/摩擦/可变形导致 `z` 近而物理远，泛化半径会被系统性高估，证书在最危险的新物体上给出最自信的错误许可，故必须以 **模式分解证书 + 物理属性探针残差 + 等变误差审计** 三重护栏，宁可低估泛化半径，绝不把「流场平滑」误认为「物体泛化安全」。

### IP-123 TGC

```python
def transport_cert(skill, o_ref, o_new, eps_succ, eps_s_max):
    z0, r0 = skill.latent(o_ref)
    z1, r1 = skill.latent(o_new)
    dz = norm(z0 - z1)
    W  = wasserstein2(sample_actions(skill, o_ref),
                      sample_actions(skill, o_new))
    Lv = estimate_lipschitz(skill.v, z0, region=success_basin(skill, o_ref))
    Eg = equivariance_error(skill, SE3_SCALE, o_ref)
    es = max(r1.values())
    r_gen = max(0.0, (eps_succ - W - es - Eg) / max(Lv, 1e-6))
    ok = (dz <= r_gen) and (W + es + Eg <= eps_succ) and (es <= eps_s_max)
    return ok, OGFC(z1, r_gen, W + es, Lv, Eg, skill.mode_cert, skill.delta_v)
```

### IP-125 EQC

```python
def equivariance_error(skill, group, o, n=256):
    errs = []
    for g in group.sample(n):
        a = sample_base()
        errs.append(norm(
            skill.v(group.act(a, g), t, skill.z(group.act_obj(o, g)))
            - group.dact(skill.v(a, t, skill.z(o)), g)))
    return mean(errs)
```

def cloud_edge_flow(v_c, r_theta, gamma_ce, delta_v):
    def v_e(a, t, z):
        return gamma_ce(v_c)(a, t, z) + r_theta(a, t, z)

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FMP | O(N·T·|A|) 训练 / O(n·T·|A|) 采样 | O(|A|·|Z|) | OT 路径无偏、模式内光滑 |
| OCZ | O(|o|·|Z| + |Prop|·|Z|) | O(|Z|+|Prop|) | 物理探针可观测、残差入证 |
| TGC | O(n²·|A| + |Z|·|A|) | O(n·|A|) | W2 估计收敛、局部 Lipschitz 有效 |
| CMC | O(n·T + |Γ|·|A|) | O(|M|·|A|) | 模式完备、跳跃预算闭合 |
| EQC | O(n·|G|·|A|) | O(|A|) | 群作用可实现、表示匹配 |
| RCF | O(|A|·|Z|) | O(|A|·|Z|) | 残差有界、γ_ce Lipschitz |
| OFC | O(k·n²·|A|) | O(k·|A|) | handoff 匹配、重参数无奇点 |

**正确性定理（Object-Generalization Flow Soundness, OGFS）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 速度场在每个接触模式内 `L_v`-Lipschitz，模式分解完备；**(A30)** `z(o)` 对物理属性 `ε_s`-充分；**(A31)** `d_Z(z(o),z(o')) ≤ r ≤ r_gen`；**(A32)** 成功盆地 κ-收缩，`||r_θ|| ≤ δ_v`。则
```
P_success(o') ≥ 1 - Σ_d (1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
                 - (L_v·r + ε_s + E_g)/δ_succ
                 - P(J_Γ>Θ_Γ) - P(W2>Θ_w)
```
关键：**泛化前提先验物理充分**，**接触边界有跳跃预算**，**传输成本可估且保守**。

## 5. 本轮最大风险

**一句话**：流匹配策略与物体泛化将技能从静态动作占用升级为「可传输连续轨迹场 + 泛化半径证书」，但其 soundness **双重依赖接触模式的分段光滑与 `z(o)` 的物理充分性**；一旦接触边界跳跃超出预算、或潜变量遗漏质量/摩擦/可变形导致 `z` 近而物理远，泛化半径会被系统性高估，证书在最危险的新物体上给出最自信的错误许可，故必须以 **模式分解证书 + 物理属性探针残差 + 等变误差审计** 三重护栏，宁可低估泛化半径，绝不把「流场平滑」误认为「物体泛化安全」。
