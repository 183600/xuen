# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「机器人」×「可解释性」）

> 第 54 轮已把技能组合建立在动作空间剖面 α_S 与云边联合证书 J 上，并把 Explain 作为反向信道。但那里的“解释”仍是**回传给规划器的故障根因**。本轮把解释推进到**具身层面**：机器人面对的是人，解释必须是**可执行的反事实动作**而非事后叙述，且必须同时**因果忠实**与**人类可读**。核心矛盾：H22：对人类可读的解释往往是事后合理化（confabulation），而真正高维的因果反事实又不可读；H23：仿真中忠实的最小干预，跨过 sim-to-real 后可能不再翻转结果，使“看起来忠实”的演示在物理世界退化为“有说服力的谎言”。

## 0. 直觉与动机

**灵感 1（解释即反事实动作，而非文本）**
直觉：当机器人说“我失败是因为抓取点偏了”时，这句话无法被验证；但若机器人把抓取动作替换为另一个动作原语并成功，这个**反事实动作轨迹**就是可验证的解释。定义解释为最小干预 `δ`：在名义轨迹 `π` 上把动作段 `δ` 替换为 `a'`，使失败结果 `y` 翻转为 `y'`。解释的价值不在措辞，而在**可执行、可复现、最小**。这把「可解释性」从 NLP 问题拉回到动作空间与因果推断。

**灵感 2（具身忠实性：在真实机器人上过因果闸门）**
直觉：一个解释只有同时满足两件事才算忠实：(i) 在真实机器人上**复现**反事实结果；(ii) 干预相对基线有**真实因果效应**，而不是碰巧成功。仅靠仿真或语言模型生成的“合理解释”一律不可信。于是引入**双条件闸门** `φ = repro·σ(ACE)/(1+λ|δ|)`，其中 `repro` 为真实 rollout 复现率，`ACE` 为平均因果效应，`|δ|` 为干预规模。**不达标的解释不进入人机界面**——宁可不解释，也不制造 confabulation。

**灵感 3（可读原语化：把解释对齐到人可理解的动作粒度）**
直觉：人读不懂 200 维关节轨迹，但读得懂“伸手—对准—闭合—抬起”这样的**可解释动作原语（XAP）**。因此把轨迹按带前后条件的原语切分，解释只在原语粒度上生成；可读性定义为人类解释模型 `H` 下目标/根因与解释之间的互信息占比 `leg(E)=I_H(G;E)/H_H(G)`，工程上用“正确识别根因 + 正确预测修补动作”的经验准确率估计。原语化同时给出解释的**最小语义单元**，避免过度细化。

**灵感 4（双忠实 Pareto：忠实性与可读性不可同时最大化）**
直觉：最忠实的最小干预可能是一个反直觉的高维动作切换（不可读）；最可读的解释可能是“它没抓稳”这种正确但空洞的叙述（不忠实）。因此存在**双忠实 Pareto 前沿**。方案不再追求单点最优，而是按风险选取工作点：高风险场景偏向 `φ`（忠实优先），低风险教学场景偏向 `leg`（可读优先），并把两者都写进证书。这把“解释好不好”变成**可度量、可仲裁的多目标问题**。

**灵感 5（解释—动作闭环 + 信任校准）**
直觉：解释不是终点。机器人给出忠实解释后，必须能据此**修补动作或重剖分 α_S**（EAL），并让人类信任与真实成功率对齐（TCC）。过度信任（`t > p`）比不信任更危险：人会在机器人已不可靠时仍把安全关键动作交给它。于是解释粒度 `d` 与风险 `r` 共同决定信任契约；若校准误差超限，则触发“降低自动化等级 + 增加解释证据”，而不是继续解释。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（具身解释 Embodied Explanation）**
对失败事件 `e=(π,c,y,G)`（名义动作轨迹、上下文、失败结果、目标/查询），具身解释
```
E = ⟨π, δ, a', y', c, G⟩
```
其中 `δ ⊆ π` 为被替换的最小动作原语段，`a'` 为替换动作，`y'` 为反事实结果。要求：**可执行**（机器人 R 能 rollout）、**对比性**（回答“为什么是 y 而不是 y'”）、**最小性**（不存在更小的 `δ'` 仍能翻转结果）。解释是行为，不是字符串。

**定义 122（具身忠实度 Embodied Faithfulness）**
```
repro_R(E) = 1[ y_real(π ⊕ δ→a') ≈ y' ]            # 真实机器人复现
ACE_R(E)   = E[y | do(a'), c] - E[y | do(a), c]      # 平均因果效应
φ(E)       = repro_R(E) · σ(ACE_R(E)) / (1 + λ|δ|)
```
`E` 具身忠实当且仅当 `repro_R(E) ≥ 1-ε_r ∧ ACE_R(E) ≥ κ`。`φ` 单调于复现与因果效应、反比于干预规模：**大而巧的解释不算好解释**。

**定义 123（可读性 Legibility）**
给定人类解释模型 `H`（其关于机器人目标与因果的信念），
```
leg(E) = I_H(G; E) / H_H(G) ∈ [0,1]
```
经验估计为 `leg(E) = ½[ P_H(根因正确 | E) + P_H(修补动作正确 | E) ]`。可读性衡量解释**改变人类心智模型**的效率，而非解释长度。

**定义 124（解释—动作闭环 EAL）**
EAL 是失败集 `F` 上的算子 `T: F_k → F_{k+1}`：
```
E_k = CEG(max_{f∈F_k} vol(f));  patch_k = repair(E_k)
F_{k+1} = re_evaluate(F_k, patch_k)
```
若 `vol(F_{k+1}) ≤ γ·vol(F_k)`（`γ<1`，`vol` 沿用定义 115 的动作覆盖体积）则称**收缩**并签发解释证书；否则升级到人类，禁止无限自解释。EAL 保证“解释必须导致动作改变”，而非只改叙述。

**定义 125（信任校准契约 TCC）**
`TCC = (E, d, t, r, evidence)`：`d` 为解释粒度，`t∈[0,1]` 为人类信任，`r` 为场景风险，`p` 为经验成功率。校准误差 `CE=|t-p|`。契约有效当且仅当
```
CE ≤ ε_t ∧ t ∈ [p-ε_r, p+ε_r] ∧ evidence 覆盖真实 rollout 与人类试验
```
`t > p+ε_r` 为**过度信任**（安全风险），`t < p-ε_r` 为**信任不足**（效率损失），二者触发不同的再校准动作。

**定义 126（具身解释证书 XJC）**
```
X = (J, E, φ, leg, g_s2r, evidence)
```
`J` 为第 54 轮联合证书；`g_s2r` 为解释相关动作段的仿真—现实残差。可接受条件：
```
J.deployable ∧ φ ≥ φ_min ∧ leg ≥ leg_min ∧ g_s2r ≤ ε_s2r
```
`X` 是**双忠实证书**：既证明解释在物理世界为真，又证明它对人可读。缺一不可部署到人机协作场景。

## 2. 关键算法 伪代码

### IP-121 CEG（Contrastive Embodied explanation Generation）

```python
def generate_embodied_explanation(R, trace, failure, goal, primitives):
    # 按干预规模从小到大搜索最小对比反事实
    best = None
    for k in range(1, MAX_INTERVENTION + 1):
        for delta in minimal_interventions(trace, k):
            for a2 in primitives.compatible(delta):
                y2 = R.simulate(replace(trace, delta, a2))
                if flips(y2, failure.outcome, goal):
                    cost = len(delta) + transition_cost(delta, a2)
                    if best is None or cost < best.cost:
                        best = EmbodiedExplanation(trace, delta, a2,
                                                   failure.context, y2, goal)
        if best is not None:      # 找到最小 k 即停止，保证最小性
            break
    return best                   # 可能为 None：无忠实解释
```

### IP-122 EFV（Embodied Faithfulness Verification）

```python
def verify_embodied_faithfulness(E, R_sim, R_real, eps_r, kappa):
    y_sim = R_sim.rollout(E.pi_intervened())
    if not flips(y_sim, E.base_outcome, E.goal):
        return ('reject', 'not_counterfactual_in_sim')
    y_real = R_real.rollout(E.pi_intervened())
    repro  = agreement(y_real, E.y_cf)
    ace    = R_real.estimate_causal_effect(E)
    phi    = repro * sigmoid(ace) / (1.0 + LAMBDA * len(E.delta))
    gap    = sim2real_gap(R_sim, R_real, E.delta)
    if repro < 1 - eps_r or ace < kappa:
        return ('reject', 'unfaithful', phi, gap)
    return ('ok', phi, gap)
```

### IP-123 XAP（eXplainable Action Primitive）与可读性估计

```python
def segment_explainable_primitives(trace, ontology):
    seq = []
    for seg in split_by_ontology(trace, ontology):
        seq.append(ActionPrimitive(pre(seg), post(seg),
                                   effect(seg), vol(seg)))
    return seq

def legibility(E, human_model):
    p_cause = human_model.predict_cause(E)      # 正确识别根因
    p_next  = human_model.predict_next_action(E) # 正确预测修补动作
    return 0.5 * (p_cause + p_next)
```

### IP-124 TCC（Trust Calibration Contract）

```python
def trust_calibration_contract(E, human_trials, risk, eps_t):
    t = mean([h.trust for h in human_trials])
    p = empirical_success(E, risk, human_trials)
    ce = abs(t - p)
    if ce > eps_t or over_trust(t, p, risk):
        kind = 'over_trust' if t > p else 'under_trust'
        return ('recalibrate', kind, ce,
                action_for(kind, risk))   # 过度信任→降自动化等级
    return ('ok', ce)
```

### IP-125 EAL（Explanation–Action Loop）

```python
def explanation_action_loop(F0, R_sim, R_real, budget, gamma):
    F, patches, certs = F0, [], []
    for k in range(budget):
        f = max(F, key=failure_volume)
        E = generate_embodied_explanation(R_sim, f.trace, f, f.goal, PRIMITIVES)
        if E is None:
            escalate_human(f, reason='no_counterfactual'); break
        st, phi, gap = verify_embodied_faithfulness(E, R_sim, R_real, EPS_R, KAPPA)
        if st != 'ok':
            escalate_human(f, reason='unfaithful'); continue   # 宁可不解释
        patch = repair_patch(E)              # 改动作原语或重剖分 alpha_S
        F_new = re_evaluate(F, patch, R_sim, R_real)
        if failure_volume(F_new) > gamma * failure_volume(F):
            escalate_human(f, reason='non_contracting'); break
        F = F_new; patches.append(patch)
        certs.append((E, phi, gap, patch))
    return F, patches, certs
```

### IP-126 XJC（eXplainable Joint Certificate）

```python
def embodied_explanation_certificate(J, E, phi, leg, gap, budgets):
    if not J.deployable:
        return ('reject', 'joint_cert_fail')
    if phi < PHI_MIN or leg < LEG_MIN or gap > EPS_S2R:
        return ('reject', 'dual_faithfulness_fail', phi, leg, gap)
    return ('ok', XJC(J, E, phi, leg, gap,
                      evidence=[E.rollout_log, E.human_study,
                                E.sim2real_residual]))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CEG | 最坏 O(2^{|π|}·|P|)，分支定界后 O(|δ*|·|P|) | O(|π|) | 最小性、原语完备 |
| EFV | O(|π|·(T_real+T_sim)) | O(|π|) | 真实 rollout、do-干预可识别 |
| XAP | O(|π|·|Q|) | O(|π|) | 本体切分 sound、前后条件闭合 |
| TCC | O(n·|E|) | O(n) | 人类试验无偏、风险分层 |
| EAL | O(budget·(CEG+EFV)) | O(|F|) | 收缩性 γ<1、升级不回环 |

**正确性定理（Dual-Faithfulness Explanation Soundness）**
承接第 54 轮 (A22)–(A28)；新增 **(A29)** 解释 `E` 可执行且为最小对比反事实；**(A30)** 解释动作段的仿真—现实残差 `g_s2r ≤ ε_s2r`，故反事实可迁移；**(A31)** 人类解释模型 `H` 的可读性缺口有界 `δ_leg`；**(A32)** EAL 为 γ-收缩（`γ<1`）。
若 `X` 被接受，则修补后部署成功率与信任校准满足：
```
P(success after repair) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a) - (1-φ) - g_s2r
E[ |t - P_success| ]    ≤ ε_t + δ_leg
```
关键分离：**部署安全由 φ 与 g_s2r 主导，可读性缺口只进入信任项**。因此忠实性是硬门控，可读性是软目标；不能为了“讲得懂”而放宽忠实性。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 具身反事实忠实率 | 真实机器人复现率 `repro`、`φ` | repro ≥ 90%，φ ≥ 0.8 |
| E163 解释可读性 | 根因识别率 / 修补动作预测率 | 分别 ≥ 85% / 80% |
| E164 信任校准 | ECE、过度信任事件数 | ECE ≤ 0.10，过度信任 ↓ ≥ 40% |
| E165 EAL 修补效果 | 失败体积下降、收缩系数 γ | 成功率 Δ ≥ 18%，γ < 0.8 |
| E166 sim-to-real 解释漂移 | `Δφ`、误接受率 | Δφ ≤ 0.10，误接受 ≤ 3% |

**判别性对照**：与“纯语言解释（LLM 生成）”“纯仿真忠实解释（不做真实 rollout）”“无解释直接修补”三组对比；核心消融是**去掉 EFV 闸门**，预期 confabulation 接受率显著上升并导致过度信任。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 生成看似合理但因果不忠实的解释（confabulation） | 高 | EFV 真实 rollout 硬门控 + 反事实不可解释则沉默 |
| sim-to-real 使反事实失效 | 高 | `g_s2r` 预算、域随机化、真实微校准、作用域收窄 |
| 忠实性与可读性 Pareto 冲突 | 高 | 按风险选工作点 + 证书双指标 + 人类试验回归 |
| 人类过度信任解释 | 高 | TCC 校准契约 + 降低自动化等级 + 反例展示 |
| 反事实搜索组合爆炸 | 中 | 原语因果图剪枝 + 分支定界 + 缓存 |
| 解释延迟影响安全回路 | 中 | 解释与人机交互解耦、离线预计算、异步回传 |

## 6. 本轮最大风险

**一句话**：具身解释把“可解释性”从叙述变成**可执行反事实**，但其 soundness 集中在**反事实能否跨 sim-to-real 仍然成立**——一旦域偏移使最小干预在真实机器人上不再翻转结果，机器人就会用流畅的演示讲出一个“有说服力的谎言”，并恰好在此刻把人类信任校准到最危险的高位；因此必须坚持 **EFV 忠实性硬门控 + g_s2r 预算 + 不可解释即沉默**，绝不允许先讲故事再补证据。

### IP-125 EAL

```python
def explanation_action_loop(F0, R_sim, R_real, budget, gamma):
    F, patches, certs = F0, [], []
    for k in range(budget):
        f = max(F, key=failure_volume)
        E = generate_embodied_explanation(R_sim, f.trace, f, f.goal, PRIMITIVES)
        if E is None:
            escalate_human(f, reason='no_counterfactual'); break
        st, phi, gap = verify_embodied_faithfulness(E, R_sim, R_real, EPS_R, KAPPA)
        if st != 'ok':
            escalate_human(f, reason='unfaithful'); continue
        patch = repair_patch(E)
        F_new = re_evaluate(F, patch, R_sim, R_real)
        if failure_volume(F_new) > gamma * failure_volume(F):
            escalate_human(f, reason='non_contracting'); break
        F = F_new; patches.append(patch)
        certs.append((E, phi, gap, patch))
    return F, patches, certs
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CEG | 最坏 O(2^{\|π\|}·\|P\|)，定界后 O(\|δ*\|·\|P\|) | O(\|π\|) | 最小干预、原语完备 |
| EFV | O(\|π\|·(T_real+T_sim)) | O(\|π\|) | 真实 rollout、do-干预可识别 |
| XAP | O(\|π\|·\|Q\|) | O(\|π\|) | 本体切分 sound、前后条件闭合 |
| TCC | O(n·\|E\|) | O(n) | 人类试验无偏、风险分层 |
| EAL | O(budget·(CEG+EFV)) | O(\|F\|) | γ-收缩、升级不回环 |

**正确性定理（Dual-Faithfulness Explanation Soundness）**
承接 (A22)–(A28)；新增 **(A29)** `E` 可执行且为最小对比反事实；**(A30)** `g_s2r ≤ ε_s2r`，反事实可迁移；**(A31)** 人类模型可读性缺口 `δ_leg` 有界；**(A32)** EAL γ-收缩（`γ<1`）。
若 `X` 被接受，则：
```
P(success after repair) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a) - (1-φ) - g_s2r
E[ |t - P_success| ]    ≤ ε_t + δ_leg
```
**推导要点**：由 A30，真实世界反事实与仿真一致，故 `(1-φ)` 为解释误导项；由 A32，EAL 每次迭代至少消去 `1-γ` 比例失败体积，修补成功项可加；可读性缺口只通过 TCC 进入信任项，因而不改变物理部署安全界——这给出**忠实性硬门控、可读性软约束**的明确分层。
