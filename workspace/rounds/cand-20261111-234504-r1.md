# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；灵感循环第 1 轮；本轮灵感：「UniBot-V1」×「中间件」）

> 第 56 轮把命题从"模型说可信"推进到"证据说可信"，并让证据住进持久地图 𝓜。但它仍是一个**单读者、单时钟、同步循环**的模型：地图没有"这份证据对哪个端口、在哪个时刻仍然有效"的概念。UniBot-V1 的真实运行时恰好相反——N 个端口并发、远程 API 有 RTT、动作以 30Hz chunk 提交、180s 硬截止、单 checkpoint、无深度/力/触觉。于是第 56 轮最危险的漏洞不再是"坏证据活得久"，而是 **好证据在错误的时间/端口被当成好证据**：一个端口在旧快照上提交、另一个端口把本端 episode 的信念洗成全局先验、一个已撤销的探针仍在为后续承诺背书。本轮用「中间件」补的正是这一层：把证据从"值"升级为"带因果时戳、带作用域、带可撤销血缘的事务对象"，并让中间件承担 **组合安全性证明**，而不只是解耦与转发。

核心矛盾：
- **H26（时间）**：第 56 轮的证据门在"决策时刻"检查，却被默认在"执行时刻"仍成立；chunk 执行跨数百毫秒，期间新帧、人工标注、云端召回都可能改变证据，**用旧证据执行新动作**是比模型误校准更隐蔽的失守。
- **H27（组合）**：SMM/PCE/BVK/ISE/TAF/MEC 各自的 soundness 不会自动相加；当它们被装进多端口中间件，**契约不闭合、写作用域重叠、故障不隔离**会让每个模块"局部正确"而系统整体错误。
- **H28（作用域）**：多端口共享一张地图会带来正迁移，也会带来**证据洗白**（把某个 episode 的偶然观察当全局真理）；需要显式的提升协议与污染屏障。

## 0. 直觉与动机

**灵感 1（UniBot-V1 → 约束不是背景，是中间件的接口规格）**
直觉：UniBot-V1 的每个事实都在逼中间件做选择。单 checkpoint → 不能在中间件里偷偷加第二个学习模型，创新只能落在 **运行时契约、证据调度与安全外壳**；4 路 RGB、无深度/力/触觉 → 证据类型必须降级为视觉/本体/行为证据，"探针"只能是**信息性动作**（换视角、轻接近、重访、主动遮挡），不能假装有接触力；N 端口 → 状态必须**按端口隔离**，共享的只能是经过校准的先验；180s + 远程 RTT → 必须有**执行期租约**，不能用"计划期证据"一路执行到底。

**灵感 2（中间件 → 从"胶水"升级为"安全性的组合证明器"）**
直觉：最朴素的中间件是消息总线；真正决定安全的是三件事：**读写作用域**（谁能改哪块证据）、**时序契约**（每个服务的延迟/新鲜度保证）、**故障封闭**（一个服务坏了，系统只会更保守，不会更冒险）。于是中间件的第一职责不是"把模块连起来"，而是**证明连起来之后端到端界仍然成立**；连不起来（契约不闭合）就拒绝发证书，而不是"尽力运行"。这与第 16 轮 CAM"把胜任力抽离成中间件"不同：CAM 解决**解耦与复用**，本轮解决**并发证据的一致性与组合健全性**。

**灵感 3（事务与 MVCC → 证据需要 epoch，而不是时间戳堆叠）**
直觉：数据库早就解决了"并发读者看到半更新状态"的问题——多版本并发控制 + 一致快照 + 可串行化提交。把每个区域的信念更新做成**证据事务**：带依赖集、提交 epoch、读写集；每个端口在一致快照上决策，提交时做冲突检测。这样第 56 轮的"融合"从一次函数调用变成**可回滚、可重放、可审计的提交**。

**灵感 4（血缘与撤销 → 坏证据不是"衰减"，而是"可召回"）**
直觉：第 56 轮用隔离区 + 陈旧衰减对抗坏证据，但衰减是"让它慢慢失效"，召回是"立刻让它和它的后代全部失效"。给证据建 DAG 血缘（探针 → 融合 → 承诺），一旦某条证据被判定为破坏性/错误/云端回滚，沿依赖闭包做 **taint 传播**，把所有受影响的承诺在下一 epoch 前撤销并重算。承诺还要求**不可约支撑**（≥k 条独立证据），这样单条坏证据不会一票击穿。

**灵感 5（执行期租约 → 把"计划时证据"与"执行时证据"分开）**
直觉：UniBot-V1 以 chunk 提交动作，30Hz。给每个 chunk 挂一张**证据租约**：`(epoch, 依赖哈希, TTL, taint 集)`。执行每一步都要问：租约没过期？关键依赖没变？没被撤销？任一不满足，**已执行前缀保留、剩余后缀作废并重规划**。这把"证据门"从一次静态检查变成沿时间轴的**持续有效性检查**。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（证据事件与证据代数）** `e=(eid,r,type,payload,t_obs,t_ing,src,w,par,ver)`：区域/任务键 `r`，观测时戳 `t_obs` 与入图时戳 `t_ing` 分离，来源 `src∈{probe,visit,seg,cloud,human}`，父证据集 `par`，内容版本 `ver`。证据代数 `(E,⊔,≼)` 的 `⊔` 满足交换/结合且**保校准**，从而保证重放确定性；每份证据带作用域 `scope(e)`（本端口 / 已提升 / 全局）。

**定义 134（因果证据一致性与证据新鲜度）** 提交 `d` 与快照 `S` 因果一致 ⇔ `d` 的所有依赖在 `S` 中可见，且端口已提交的更新不会被更旧版本覆盖（端口内单调读 + 读己之写）；对动态区域再加新鲜度门 `age(e)=t_now−t_obs(e) ≤ τ_stale(r)`。**证据洗白禁止**：端口 `q` 的 episode 证据不得直接进入 `p` 的承诺支撑，除非经定义 137 的提升协议。

**定义 135（证据租约与可撤销 chunk）** chunk `a_{t:t+H}` 的租约 `L=(κ,dep_hash,τ_lease,taint_set)`。第 `s` 步可执行 ⇔ `age≤τ_lease` ∧ 关键依赖哈希未变 ∧ `taint_set∩Revoked=∅` ∧ 未超 180s 预算；否则撤销后缀、保留已执行前缀并重规划。**单 chunk 至多一次重规划**保证实时性与终止。

**定义 136（证据血缘图与污染闭包）** DAG `P=(E,D)`，`D` 为派生边。撤销事件 `R(e0)`（探针致损、标注判错、云端版本回滚）触发污染闭包 `T(e0)={e | e0 ⤳ e}`；所有 `e∈T` 失效，引用其的承诺作废。承诺支撑要求**不可约性**：至少 `k` 条独立来源，去掉任一条仍满足证据门；`ρ_ev(r)` 度量支撑独立度。

**定义 137（端口作用域与提升协议）** 端口状态 `X_p`；共享证据仅限 `G_cal`（校准/任务先验/冻结权重）与显式提升的 `G_prom`。提升 `promote(e)` 需 ≥k 个端口独立复现、去除端口标识、不得携带 episode 物体身份；否则只能留在本端口。**污染屏障**把未提升证据对 `q` 的残余影响计入 `ε_leak`。

**定义 138（组合安全契约与中间件证书 MEC+）** 服务 `s` 的契约 `Γ_s=(Pre,Post,Invar,T,Fail,Scope,Cap)`；组合闭合 ⇔ 相邻 `Post⇒Pre`、时延预算之和 ≤ `τ_budget`、写作用域不相交或可串行化、任一违约进入 `Fail`（fail-closed）。中间件证书 `J_mw=(J_m,epoch_log,lease_log,taint_closure,contract_log,scope_proof)`，任一检查失败即拒绝，不允许"带病运行"。

### IP-133 ECM（Evidence-Consistent Middleware）

```python
def read_snapshot(port):
    return mvcc.snapshot(port.epoch, deps=port.read_set)

def commit(port, update):
    if not mvcc.causally_ready(port, update): return CONFLICT
    if not evidence_algebra.calibration_preserved(update): return REJECT
    ep = mvcc.commit(update, deps=update.parents, scope=port.write_scope)
    mvcc.notify_dependents(update.parents)       # 使相关租约失效
    return ep
```

### IP-134 ELC（Evidence-Leased Chunking）

```python
def execute_chunk(chunk, lease, step_budget):
    for s in range(chunk.H):
        if lease.expired() or lease.dep_changed() or lease.tainted():
            return revoke_suffix_and_replan(chunk, s)   # 前缀已执行，后缀作废
        if step_budget.exhausted(): return fallback(...)
        act(chunk.a[s]); lease.tick()
    return commit_chunk(chunk)
```

### IP-135 EPG（Evidence Provenance Graph）

```python
def revoke(e0):
    T = taint_closure(e0)                         # 后代闭包，sound over-approx
    for e in T: e.state = 'invalid'
    for c in commitments_using(T): c.revoke('tainted_evidence')
    return recompute_regions(regions(T)), T
```

### IP-136 CSC（Compositional Safety Contracts）

```python
def compose_and_check(services, deadline):
    for a, b in adjacent(services):
        if not implies(a.Post, b.Pre): return REJECT('contract_open')
        if a.Scope & b.Scope: return REJECT('write_conflict')
    if sum(s.T for s in services) > deadline: return REJECT('timing')
    return run_with_monitor(services, fail_closed=True)
```

### IP-137 XPB（Cross-Port Barrier）

```python
def promote(e, ports):
    if len(independently_reproduced(e, ports)) < k: return HOLD
    if has_episode_identity(e): return REJECT
    return G_prom.add(strip_identity(aggregate(e)))
```

### IP-138 MEC+（Middleware-Evidence Certificate）

```python
def cert_mw(Jm, epoch_log, lease_log, taint, contracts, scope):
    if not causal_consistent(epoch_log): return ('reject','epoch')
    if any(l.revoked_before_exec for l in lease_log): return ('reject','lease')
    if taint.live: return ('reject','taint')
    if not contracts.closed: return ('reject','contract')
    if not scope.within_barrier: return ('reject','port_scope')
    return ('ok', MECPlus(Jm, epoch_log, lease_log, taint, contracts, scope))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ECM | O(|dep|·log V) 每次提交 | O(V·版本数) | 因果一致、融合保校准 |
| ELC | O(H) 每 chunk | O(H) | 租约到期/依赖变/污染即撤后缀 |
| EPG | O(|E|+|D|) 每次撤销 | O(|E|+|D|) | 污染闭包含全部后代、支撑不可约 |
| CSC | O(|服务|²) 启动检查 + O(1) 每提交 | O(|服务|) | 契约闭合、违约 fail-closed |
| XPB | O(k·|ports|) 每次提升 | O(|G_prom|) | 独立复现、去身份、作用域隔离 |
| MEC+ | O(|日志|+|血缘|) | O(|证书|) | 无 epoch/租约/污染/契约缺口 |

**正确性定理（Consistent Composed Commitment, CCC）**：在 A29–A36 基础上加 **(A37)** 端口读因果一致且单调、提交前依赖可见；**(A38)** 租约内证据误差增长 ≤ `ε_lease`，撤销先于越界动作；**(A39)** 血缘完整且污染闭包是污染集的 sound over-approx；**(A40)** 每个服务局部 sound 且契约闭合，违约 fail-closed；**(A41)** 端口仅经提升协议相互影响；**(A42)** 中间件 p99 开销 ≤ `τ_mw` 且不侵蚀 180s 预算。则：(i) **时相健全**：不存在用因果不一致或已污染证据执行的已提交动作；(ii) **组合健全**：端到端失效率 ≤ 各阶段局部界之和 + `ε_lease` + `ε_leak` + 契约违约界，且任一契约违约只触发更保守动作；(iii) **污染遏制**：坏证据的影响半径被限制在其后代闭包与本端口内，撤销后下一 epoch 前不再有承诺为其背书；(iv) **实时终止**：每 chunk 至多一次重规划，在 180s 内进入 {提交, 回退, 安全停} 之一。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 中间件自身成为单点故障/可信基过肥 | 高 | 安全关键子集做成 in-process micro-kernel，热路径零网络；中间件崩溃即 fail-closed |
| epoch/租约抖动引发级联撤销与重规划饥饿 | 高 | 提交限流 + 租约合并 + 每 chunk 一次重规划上界 |
| 契约本身写错，组合定理空洞成立 | 高 | 契约假设显式注册 + 运行时监视器 + 契约反例测试 |
| 血缘图无限膨胀 | 中 | 区域级聚合、深度裁剪、旧 epoch 压缩 |
| 端口隔离牺牲正迁移 | 中 | 提升协议 + 冻结先验；只共享经多端复现的统计量 |
| 无深度/力/触觉导致证据先天弱 | 高 | 只用视觉/本体/行为证据，证据门不降阈值；弱证据只能触发绕行/重试，不能支撑不可逆承诺 |

## 6. 本轮最大风险

**一句话**：本轮把安全从"证据质量"再推进到"证据在正确时间/端口/契约下的有效性"，但代价是中间件成为新的可信基——一个 epoch 或租约 bug、一次契约误写、或高频更新引发的撤销风暴，都可能让系统要么长时间保守到无法完成任务，要么"按闭合契约"组合出一份错误的安全证明，因此必须把安全关键中间件压到极小、留在进程内、默认 fail-closed，并用反例测试持续证伪它的契约，否则"组合健全"只是把单点故障从模型搬到了中间件。

# 第 57 轮产物 · 创新点清单 v33：ECM-Transaction（一致性证据中间件×可撤销租约×组合安全契约）

> 承接第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）与第 55 轮 IP-121~126（SCG/WBV/SSF/SCC/SRS/CEB）。本轮**不推翻** v56 的"证据承诺"，而是补上它默认掉的一层：**证据只有在一个一致的 epoch、一个正确的作用域、一组闭合的契约下才可信**。新增 IP-133~138（共 6 个），升级 IP-127/128/130/132 以纳入事务、租约、血缘与组合监视。
> 事实锚点（沿用第 56 轮之前复核）：UniBot-V1 为定基座桌面双臂操作；官方观测为 4 路 RGB + 双臂本体 + 夹爪 + episode 语言，不提供 LiDAR/深度/力/触觉；平均成功率主排序、步骤分为平局裁决；单 checkpoint 覆盖 32 任务；N 端口并发、远程 API、180s 硬截止。故本轮"探针"一律指**视觉/本体/行为信息性动作**，中间件不得假设接触力通道。

## 2. 关键算法伪代码

### IP-133 ECM（Evidence-Consistent Middleware）

```python
def evidence_merge(a, b):
    # 证据代数：交换、结合、保校准；同源重复观测按有效样本数去重
    return calibration_preserving_join(a, b)

def read_snapshot(port, now):
    snap = mvcc.snapshot(port.epoch, deps=port.read_set)
    snap = filter_by_scope(snap, port.scope)          # 端口作用域
    return apply_staleness(snap, now, tau_stale)      # 动态区域新鲜度门

def commit(port, update):
    if not mvcc.causally_ready(port, update):         # A37: 依赖全可见
        return CONFLICT
    if not evidence_algebra.calibration_preserved(update):  # A33 继承
        return REJECT
    if conflict(update.write_set, mvcc.pending()):    # 可串行化提交
        return RETRY
    ep = mvcc.commit(update, deps=update.parents, scope=port.write_scope)
    lease_index.invalidate(update.parents)            # 依赖变更→相关租约失效
    return ep

def replay(epoch_log):
    # 确定性重放：同一 epoch 顺序得到同一信念，用于审计与证书复核
    M = checkpoint(epoch_log.base)
    for u in epoch_log.updates: M = commit_without_notify(M, u)
    return M
```

### IP-134 ELC（Evidence-Leased Chunking）

```python
def make_lease(chunk, snapshot, support, now):
    return Lease(epoch=snapshot.epoch,
                 dep_hash=hash_critical_deps(snapshot, chunk),
                 expiry=now + min(tau_lease, chunk.H / freq),
                 taint_set={e.eid for e in support if e.tainted})

def execute_chunk(chunk, lease, budget, step_budget):
    executed = 0
    for s in range(chunk.H):
        if budget.exhausted() or step_budget.exhausted():
            return fallback_safe(chunk, executed, 'deadline')
        if lease.expired(now()):
            return revoke_suffix_and_replan(chunk, s, 'lease_expired')
        if hash_critical_deps(current_snapshot(), chunk) != lease.dep_hash:
            return revoke_suffix_and_replan(chunk, s, 'evidence_changed')
        if lease.taint_set & revocation_set():
            return revoke_suffix_and_replan(chunk, s, 'tainted')
        act(chunk.a[s]); executed += 1; lease.tick()
    return commit_chunk(chunk, executed)
# 关键：已执行前缀是已提交事实；后缀撤销必须重新取证/重规划，绝不"补发旧动作"。
```

### IP-135 EPG（Evidence Provenance Graph）

```python
def add_evidence(e, parents):
    e.par = parents
    graph.add_node(e)
    for p in parents: graph.add_edge(p, e)
    graph.check_invariants()                  # 无环、父版本≤子版本

def taint_closure(e0):
    return descendants(graph, e0)             # sound over-approx：全后代

def revoke(e0, reason):
    T = taint_closure(e0)
    for e in T: e.state = 'invalid'
    affected = commitments_using(T)
    for c in affected: c.revoke(reason)       # 承诺作废，不得"带病执行"
    for r in regions(T): schedule_recompute(r)
    return RevocationReport(e0, T, affected)

def support_ok(commitment):
    sup = commitment.support
    independent = max_independent_set(sup)     # 去掉任一条仍满足证据门
    return len(independent) >= k and not any(e.state == 'invalid' for e in sup)
```

### IP-136 CSC（Compositional Safety Contracts）

```python
def compose(services):
    for a, b in adjacent(services):
        if not implies(a.Post, b.Pre):
            return Reject('contract_open', (a, b))       # 不闭合即拒绝发证
        if a.Scope & b.Scope and not serializable(a, b):
            return Reject('write_conflict', (a, b))
        if a.Cap & b.NeedsCap != b.NeedsCap:
            return Reject('capability', (a, b))          # 最小权限
    if sum(s.T for s in services) > tau_budget:
        return Reject('timing', services)
    return Monitored(services, fail_closed=True)

def run_with_monitor(services, fail_closed):
    for s in services:
        try:
            out = s.step()
            if not s.check_invariant(out): raise ContractViolation(s)
        except ContractViolation:
            if fail_closed: return safe_degrade(s)       # 只允许更保守
            raise
```

```python
def scope_filter(e, port):

def promote(e, ports):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ECM | O(\|dep\|·log V) 每提交；重放 O(\|log\|·d) | O(V·版本数) | 因果一致、可串行化、融合保校准（A37/A33） |
| ELC | O(H) 每 chunk | O(H) | 租约到期/依赖变/污染即撤后缀（A38） |
| EPG | O(\|E\|+\|D\|) 每次撤销 | O(\|E\|+\|D\|) | 污染闭包 sound、支撑不可约（A39） |
| CSC | O(\|S\|²) 启动 + O(1) 每提交 | O(\|S\|) | 契约闭合、违约 fail-closed（A40） |
| XPB | O(k·\|ports\|) 每次提升 | O(\|G_prom\|) | 独立复现、去身份、作用域隔离（A41） |
| MEC+ | O(\|日志\|+\|血缘\|) | O(\|证书\|) | 无 epoch/租约/污染/契约/作用域缺口 |
| 热路径附加 | O(1) 快照指针 + O(1) 租约检查 | O(1) | 不做网络/分配，p99 ≤ `τ_mw`（A42） |

**正确性定理（Consistent Composed Commitment, CCC）**
假设 A22–A28（第 53/54 轮）、A29–A36（第 55/56 轮）成立；**(A37)** 端口读因果一致且单调，提交前全部依赖可见；**(A38)** 租约内证据误差增长 ≤ `ε_lease`，撤销事件先于任何越界动作被处理；**(A39)** 血缘完整，污染闭包是真实污染集的 sound over-approximation；**(A40)** 每个服务局部 sound、契约闭合，任何违约只进入 fail-closed；**(A41)** 端口仅经 `G_cal/G_prom` 相互影响，未提升证据不跨端口；**(A42)** 中间件 p99 开销 ≤ `τ_mw` 且不侵蚀 180s 预算。则：

1. **时相健全**：不存在"证据已撤销/已过期/依赖已变"却仍被执行的已提交动作；已执行前缀只包含租约有效期内、依赖未变的步。
2. **组合健全**：端到端失效率
```
P_fail ≤ Σ_s ε_s + ε_lease + ε_leak + P(contract_violation) + ε_cal + ε_h + δ_probe
```
任一契约违约只触发更保守动作，不产生升险路径（继承第 56 轮交互单调性）。
3. **污染遏制**：坏证据的影响半径 ⊆ 其血缘后代闭包 ∪ 本端口；撤销后下一 epoch 前，所有引用它的承诺被作废并重算。
4. **实时终止**：每 chunk 至多一次重规划、每检查点探针预算 `k_probes` 有限，故在 180s 内终止于 {提交, 回退, 安全停} 之一；契约 DAG 无环、调度非抢占，故无死锁。
5. **部署界**（对检查点与端口取联合界）：
```
P_safe ≥ 1 − Σ_cp [δ_f + ε_cal + δ_probe + ε_h]
             − P(epoch 违约) − P(租约过期仍执行) − P(污染漏检)
             − P(契约缺口) − P(跨端口泄漏) − P(中间件崩溃 ∧ fail-closed 失效)
```

关键：第 56 轮保证"有证据才承诺"；本轮保证"**承诺所依据的证据在执行时仍然有效、且组合链上没有缺口**"。单点过度自信已不足以击穿；现在还需要时间、血缘、作用域、契约四层同时失守。

## 6. 本轮最大风险

**一句话**：本轮把安全从"证据质量"再推进到"证据在正确时间/端口/契约下的有效性"，但代价是中间件成为新的可信基——一个 epoch 或租约 bug、一次契约误写、或高频更新引发的撤销风暴，都可能让系统要么长时间保守到无法完成任务，要么"按闭合契约"组合出一份错误的安全证明，因此必须把安全关键中间件压到极小、留在进程内、默认 fail-closed，并用反例测试持续证伪它的契约，否则"组合健全"只是把单点故障从模型搬到了中间件。
