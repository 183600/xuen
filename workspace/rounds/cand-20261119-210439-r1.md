# 第 1 轮（UniBot 线 · 本轮灵感：「专利布局」×「协同控制」）

> **承接声明**：接续既有 UniBot-SAGE 基线（上一版以「抓取 × 技能学习 × 地形适应」组织，U1–U12 / L1–L7 / IP-01–IP-08 / E601–E618 已封存）。本轮**不推倒主线**，而是把研究当作**专利组合**来经营：先用 patent landscape 找空白带与 FTO 约束，再用**权利要求树（claim tree）**把"协同控制"做成只在双臂耦合相位激活的**从属权利要求**，从而在不通吃 SAGE 主线的条件下捕获协同红利。
> **数据纪律**：榜单数字来自 `unibot.unitree.com/leaderboard_data.json`（**teaser / 占位表**，检索 2026-11-17），仅作结构参考；32 任务元数据为本地离线统计（2026-11-19）；专利情报为关键词初检（2026-11-19，**非法律意见**）；本轮无真机实测，实验均为可执行规格 + 离线探测。

## 0. 情报核实（2026-11-19）

### 0.1 任务面：官方 32 任务元数据告诉我们"协同在哪里"

对 `exp/round_mv/task_meta_summary.json`（32 任务，33,276 episodes，169.3 h）做离线统计：

> **命名口径提醒**：teaser 榜任务名与 HF 数据集任务名存在映射差异（如 teaser "Open Pill Bottle" ↔ 数据集 "PourOutMedicine"、"Stack Cups" ↔ "StackBowls"、"Store Racket" ↔ "StorePaddle"）。本轮只用能一一对应的 PlugInEthernet / Unlock / OrganizeStationery / SpellRobot / PickOutBatteries，其余映射下一轮核对。

**由此得到本轮第一个可证伪命题（H1）**：在 teaser 最难任务中，双臂并发比例并不高；协同控制只在 bimanual-static 子集上有效。若 H1 成立，协同就必须被**门控**，不能作为全局主线。

### 0.2 专利面：拥挤区在哪里，空白带在哪里（关键词初检）

初检返回的高相关专利族（全部为 2024–2026 公开/授权，详见产物区 §11）：

| 拥挤区 | 代表专利 | 已被主张的核心特征 | 对我们的约束 |
|---|---|---|---|
| **相对阻抗 / 势场 / 闭链约束** | US12779694B2、US20250269535A1、WO2025179629A1（东南大学）；CN113524183B；CN121290452A（Paxini） | 记录并持续更新双臂相对位姿、相对阻抗模型、闭链约束、虚拟弹簧、主从动态切换 | **不能把"相对阻抗"当作独立卖点**；必须设计绕开（design-around） |
| **内外力分解 + 6D F/T + 自适应导纳** | CN119283031A（南京泰瑞）、CN118617411B | 六维力传感器、重力补偿、内外力分解、导纳/力位混合 | **依赖力传感器**；UniBot 接口无 F/T ⇒ 正面撞车不可行，反而给出空白 |
| **多臂分布式 / 纳什博弈 / 耦合动力学** | CN118204976A/B、WO2026011484A1 | 多臂耦合动力学、位置/力分解、分布式自适应协同、纳什博弈 | 偏工业多臂/遥操作，与"单机双臂 + 学习型 VLA"不同源 |
| **双臂模仿学习 + 动作分块 + 力感知** | CN120395850A | 动作分块、力感知、双臂示教 | 邻近但不覆盖"无 F/T + 1-DoF + 抓握不确定" |

**空白带假设（H2）**：现有权利要求普遍以"**有力传感 / 已知闭链 / 遥操作或工业多臂**"为前提；**没有**把"**无 F/T、无触觉、1 自由度夹爪、抓握不确定、学习型通才 VLA、标准化远程 API**"这六个约束同时纳入。⇒ 空白不在"相对阻抗"本身，而在以下三者的组合：

1. **无传感器内力代理**（夹爪闭合动力学 + 腕部爪-物间隙/形变 + 滑移残差 + 伺服误差 → 力带，而非绝对牛顿）；
2. **滑移触发的约束流形重估**（把双臂相对变换当**隐变量**，而非已知常量）；
3. **权利要求树式门控退化**（把专利的独立/从属/fallback 结构变成运行时的分层门控）。

> **诚实边界**：关键词初检**不能**证明新颖性；"非显而易见性"是法律判断；上述三要素只是**候选分离要素（separating elements）**，须用 incoPat / PatSnap / Espacenet 做同族、引证、权利要求逐项比对，并由专业 FTO 复核。本轮把它写成**可执行的 claim chart 与审计规格**，不写成法律结论。

## 1. 直觉（先给第一性原理，再给定义）

### 灵感 1 ·「协同控制」→ 稀缺的不是"每个臂更准"，而是"相对关系不崩"

**A. 共模误差可被相对坐标消掉。**
双臂、躯干、手眼标定的漂移是**共模**的。绝对坐标控制要分别用两个臂的有限带宽去抑制同一个扰动；而相对坐标直接测 `e_rel = e_R − e_L`，共模项在测量里相消。⇒ 双臂协同的收益 ≈ 两臂闭环灵敏度的**失配度**：灵敏度越一致、共模扰动越大，收益越大。这给出一条可测的判据，而不是"双臂听起来更稳"。

**B. 无 F/T 时内力不可测，但可"带符号地"观测。**
没有力传感器，内力只能从**夹爪闭合动力学 + 腕部视觉的爪-物间隙/形变 + 滑移残差 + 伺服跟踪误差**推断成一个**力带**（低 / 合适 / 过高），而不是绝对牛顿。对"别夹碎 / 别松脱"这类二值安全目标，力带足够；而且天然绕开"力传感/内外力分解"类权利要求。

**C. 抓握不确定 ⇒ 约束不是常量，而是隐变量。**
双臂闭链的"相对位姿恒定"只在**没滑移**时成立。滑移会让约束漂移。⇒ 必须把相对变换当**带滑移事件的隐变量**在线重估，而不是假设已知闭链。这正好是 SAGE IP-02 抓握隐变量在双臂上的自然延伸。

**D. 协同只在耦合相位有用。**
若任务两臂独立，协同只增加开销与失败模式；协同必须被**门控**到 bimanual / leader-follower 相位。否则就是"给基线加复杂度"。

### 灵感 2 ·「专利布局」→ 研究不是选一个最强方案，而是经营一个可存活、可退化、可自证的组合

**E. 独立权利要求 + 从属权利要求 = 主干 + 退化。**
专利的鲁棒性来自"宽独立权利要求 + 多层窄从属权利要求"：窄权利要求不能替代宽权利要求，但能在宽权利要求被无效时保住阵地。对应到策略：**通才主干（SAGE）+ 只在特定 scope 激活的窄协同控制器 + 逐级 fallback**。协同控制器**不能替换** SAGE 主线，只能作为**从属权利要求**挂在主线之下。

**F. FTO 是设计约束，不是事后检查。**
设计从一开始就要避开拥挤权利要求的**必要技术特征**；每条候选权利要求都要有至少一个**分离要素**，使其不被单篇现有技术完全覆盖。⇒ 我们不去正面撞"相对阻抗"，而是用"无 F/T 内力代理 / 滑移重估 / 门控树"作为分离要素。

**G. 防御性公开 + 组合价值。**
把诊断基准与负结果公开，形成 prior art，防止被他人专利堵死；核心权重/实现作为商业秘密。研究组合的价值 = 覆盖 × 成功率 × 可辩护性 ÷ 成本，而不是单点 SOTA。

### 合成

协同控制给出**技术候选**（对象中介、无传感器内力、滑移重估、双臂/全身）；专利布局给出**选择与风控纪律**（landscape → 空白带 → 分离要素 → 权利要求树 → 门控退化 → 防御性公开）。⇒ **CLAIM-PORT：以权利要求树经营的协同操作组合**。它不是"又一个双臂控制器"，而是"**一个决定何时才允许双臂控制器接管的研究组合**"。

## 2. 严谨定义（预览；完整符号、公式与引理见产物区 §3/§5）

- **协调域** `R_t = g_R(o_t, ℓ) ∈ {IND, LF, RDG, WBS, WBD}`：独立 / 主从 / 刚性双臂抓握 / 静态全身 / 动态全身。
- **对象中介约束** `T_rel = T_L^{-1} T_R ∈ SE(3)`；约束流形 `M`；估计 `M̂_t` 与不确定度 `Σ_t`。`M` 不是常量，而是随滑移变化的隐变量。
- **滑移残差** `s_t = Log(T_rel^{obs}(T_rel^{pred})^{-1}) ∈ se(3)`；`‖s_t‖_{Σ_t} > τ_s` 触发约束重估。
- **无传感器内力代理** `p_t = φ(g_t, Δg_t, I^{wrist}_t, s_t, e^{servo}_t)`；力带 `b_t = h(p_t) ∈ {LOW, OK, HIGH}`。
- **相对坐标协同** 把期望运动分解为对象运动 `ξ_o` 与内部（相对）运动 `ξ_rel`：`ξ_L = ξ_o − ½ξ_rel`、`ξ_R = ξ_o + ½ξ_rel`，经协同雅可比 `J_c` 投影到关节（产物区 CC5）。
- **权利要求** `c = (S_c, γ_c, π_c, k_c, ν_c)`：scope / 门控 / 控制器 / 成本 / 新颖性状态。
- **权利要求树** `T=(C,E)`：`c_j` 是 `c_i` 的从属权利要求当 `S_j ⊆ S_i`；根 `c_0 = SAGE`。运行时选"根到叶路径上最深的、所有祖先门控都通过的节点"。
- **组合价值** `V(C) = E[R(π_{c*})] − λE[k_{c*}]`；**空白带分数** `W(f)=relevance(f)·(1−density(f))`；**分离要素**：对每篇现有技术 `p`，存在一个我们的要素 `f` 不在 `p` 中。

## 3. 瓶颈与机会的交叉（本轮量化结论）

| 维度 | 结论 | 设计含义 |
|---|---|---|
| **技术面** | bimanual-static 候选区 19/32；动态全身仅 3/32 | 火力放在**双臂静态协同**，不投入动态全身 |
| **关键路径** | 最难 6 项中 3 项双夹爪大行程、2 项明显单臂 | 协同**只能覆盖一部分**最难任务；必须门控 + 先用 E801 验证 |
| **法律面** | 相对阻抗/力分解/主从切换为拥挤区；"无 F/T + 滑移重估 + 门控树"为候选空白 | 分离要素必须是**传感器缺失**与**抓握不确定性**，而非"更准的相对阻抗" |
| **交集** | 技术机会 ∩ 法律空白 = "双臂 bimanual-static 任务中的抓握不确定 / 滑移恢复" | 这是唯一值得押注的交叉点；其余一律降级为从属权利要求或防御性公开 |
| **反直觉** | 动态全身协同只有 3/32，但 SAGE IP-05 曾把它当 P1 | 本轮把 pivot 降级为**静态姿态先验**，把省下的算力给滑移重估 |

**一句话**：协同控制的价值不在"多一个控制器"，而在"**在正确相位、以不撞专利的方式、只在能赢时才接管**"。

## 4. 研究问题（可证伪）

- **Q1（协同是否打在关键路径）**：teaser 最难任务中，双手是否在时间上**并发**使用？若并发率低，协同只能覆盖中等任务，组合增益被摊薄。
- **Q2（相对坐标的净收益）**：在 bimanual-static 任务上，相对坐标控制相对独立绝对控制，能把相对位姿误差降多少、成功率提多少？共模漂移（躯干/标定/负载）的贡献有多大？
- **Q3（无传感器内力带）**：夹爪闭合 + 视觉间隙 + 滑移残差能否可靠区分"松脱 / 合适 / 过夹"？在透明、软、遮挡物体上何时失效？
- **Q4（滑移重估）**：滑移残差能否作为约束重估的触发器？重估后的恢复率、误触发代价、最大重试次数是多少？
- **Q5（门控的 regret）**：权利要求树相对"单体强基线"与"oracle 路由"的 regret 上界是多少？门控误判在什么条件下会伤害主线？
- **Q6（空白带 ∩ 瓶颈）**：若 H1 成立（协同不覆盖最难任务），是否应把组合缩减为"只保留抓握/滑移从属权利要求"，把主线还给 SAGE 的插入闭环？

## 5. 设计原则（在 SAGE P1–P6 上增补）

- **P7 从属权利要求不替代主线**：协同控制器必须挂在 SAGE 主干下，默认关闭，门控通过才激活；任何"全局替换主干"的方案一律不进主线。
- **P8 无传感器优先**：任何依赖 F/T / 触觉的机制不得进入部署主线（可离线用带 F/T 的标定台做真值验证）。
- **P9 每个贡献都要有分离要素**：没有 separating element 的贡献不进主线（FTO 约束）；有法律风险的想法进"防御性公开"而非"商业化叙述"。
- **P10 空白带 ∩ 瓶颈**：只在"专利空白 ∧ 任务瓶颈"的交集投入；两者不重叠时**收缩**，不为发论文而加复杂度。
- **P11 负结果可发表**：预注册"协同增益消失"的判据；负结果也作为防御性公开，形成 prior art。
- **P12 可审计的复杂度**：每加一层门控必须证明其延迟/失败模式不劣化基线；否则砍掉。

## 6. 最小可提交闭环（MVP）与退化链

**MVP = SAGE 主干 + IP-C1（协调域分类器）+ IP-C2（相对坐标 + 滑移重估，仅 bimanual-static 激活）+ IP-C3（无传感器内力带）+ IP-C4（权利要求树门控）+ E801（关键路径假设检验）。**

**严格退化链（任一环节不可用 ⇒ 行为回退而非漂移）**：

- **L0** 协调域分类器低置信 ⇒ 退回**独立双臂**（SAGE）；
- **L1** 滑移检测失效 ⇒ 退回**保守夹持 + 减速**（不重估）；
- **L2** 内力代理不可信（透明/软/遮挡）⇒ 退回**固定闭合 + 视觉伺服**；
- **L3** 门控不确定 ⇒ 退回**根节点通才**；
- **L4** 整棵树失效 ⇒ 退回**纯 SAGE 基线**（永远保留一份能跑通、可信度合规的最小提交）；
- **L5** FTO 未过 ⇒ 只发**防御性公开 + 基准**，不做商业化叙述。

## 7. 预期贡献（可验收）

1. **一个 landscape-driven 的空白带定位**：把"无 F/T / 1-DoF / 抓握不确定 / 学习型 VLA / 标准化远程 API"写成候选分离要素，给出可辩护的权利要求草稿与 claim chart（**非法律意见**）。
2. **一个对象中介的无传感器协同控制器**：相对坐标 + 滑移重估 + 力带，只在 bimanual-static 相位激活。
3. **一个权利要求树架构**：把专利的独立/从属/fallback 结构变成可运行的门控策略树，并给出弱占优与 regret 条件。
4. **一个数据驱动的假设检验**：用 32 任务元数据 + episode 级并发分析，判定"协同是否打在关键路径上"；负结果也公开。
5. **一套防御性公开 + 协同基准**：六因子诊断（SAGE）+ 双臂并发基准 + FTO claim chart，形成公共品。

## 8. 下一轮迭代计划（先杀假设，再谈创新）

- **先做 E801（go / no-go）**：episode 级统计"双手并发时长占比"，并对最难任务做归因（是单臂插入失败，还是双臂对齐失败）。若双臂并发率 <20%，协同降级为从属权利要求，主线回到 SAGE 的插入闭环。
- **若 go**：深化滑移重估与无传感器力带；把相对坐标控制与 SAGE 的抓握确认共用同一个隐变量。
- **若 no-go**：把本轮成果转成**防御性公开 + 基准**（仍有价值），并诚实报告"协同不是 UniBot 的主瓶颈"。
- **专利**：用专业数据库做同族/引证/权利要求逐项比对，产出正式 claim chart 与 FTO 备忘录；在此之前不做任何"专利已布局"的表述。
- **保留项**：SAGE 主干、六因子诊断、审计层，三项在任何情况下不砍。

---

**本轮最大风险（一句话）**：**"专利空白 ≠ 技术价值"——协同控制的空白带可能只覆盖 bimanual-static 的中等任务，而真正拉低均分的插入/旋转任务若仍是单臂主导（E801 未证实），则权利要求树只是给基线加了一层门控复杂度，组合的期望增益趋近于零，却仍要承担 FTO 与可信度审计的成本。**

# 第 1 轮产物 · 创新点清单 v1（UniBot 线）：**CLAIM-PORT**

> **CLAIM-PORT = CLAIM-structured PORTfolio**（权利要求树经营的协同操作组合）。
> 域名对齐 `unibot.unitree.com` / UniBot-V1 Challenge；承接 SAGE（U1–U12 / L1–L7 / IP-01–IP-08 / E601–E618 已封存），本轮启用 **CC1–CC14 / CL1–CL8 / E801–E820**。
> **数据纪律**：榜单数字来自 `unibot.unitree.com/leaderboard_data.json`（**teaser / 占位表**，检索 2026-11-17），仅作结构参考；32 任务元数据为本地离线统计（2026-11-19）；专利情报为关键词初检（2026-11-19，**非法律意见**）；本轮**无真机实测**，§7 给的是可执行实验规格，凡假设均显式标注。

## 0. 本轮结论摘要

**一句话路线**：不去正面撞"双臂相对阻抗"的拥挤专利区，而是把"**无 F/T 内力代理 + 滑移触发的约束重估 + 权利要求树门控**"作为分离要素，把协同控制做成**挂在 SAGE 主线下的从属权利要求**，只在 bimanual-static 相位激活。

**四条可执行判断（含本轮离线证据）**：

| 判断 | 证据 | 推出的设计 |
|---|---|---|
| 动态全身协同不值得投入 | 32 任务中 `max(pivot_std)>0.02` 仅 4 个，`>0.05` 仅 3 个（OrganizeTools 0.147、StorePaddle 0.065、FoldTowel 0.060） | 把 pivot 降级为**静态姿态先验**（IP-C5），省算力给滑移重估 |
| 双臂协同有面但不可全局化 | 双夹爪大行程（左右 `q90−q10>2.0`）22/32；bimanual-static（双夹爪>2.0 且 pivot 静态）19/32 | 协同必须被**协调域分类器**门控（IP-C1） |
| 协同是否命中关键路径仍未知 | teaser 最难项中 PlugInEthernet / Unlock / OrganizeStationery 双夹爪大行程，但 SpellRobot / PickOutBatteries 明显单臂 | **E801 先做 go/no-go**，再决定组合是否收缩 |
| 法律空白在"传感器缺失"而非"更准的阻抗" | 相对阻抗/势场/闭链（US12779694B2 等）、内外力分解 + 6D F/T（CN119283031A 等）均为拥挤区 | 分离要素 = 无 F/T 力带 + 滑移重估 + 门控树（IP-C2/C3/C4） |

**合规红线（沿用 P5/P6）**：对外仍是**单一 checkpoint、单一 API 服务**；协同控制器是内部模块（不是第二个学习模型/ensemble）；不依赖未声明执行语义；FTO 未过不做"已布局"的表述。

## 2. 创新点详述

### IP-C1 · CoordinationRegime 协调域分类器（P0）

- **动机**：协同只在耦合相位有用（第一性原理 D）。数据：双夹爪大行程 22/32，但动态全身仅 3/32 ⇒ 必须区分"该协同"与"不该协同"。
- **与现有方案的差异**：现有双臂工作默认"双臂协同"或"主从"；我们**显式分类并门控**，把"不协同"作为一等选项。
- **技术可行性**：高。特征 = 语言指令 embedding（任务 token）+ 左右腕帧相对运动 + 双夹爪时序相关 + EE 相对速度 + pivot 活动度。标签可用 episode 级双臂并发 + VLM 批量伪标。
- **所需资源**：数据 = 官方 32 数据集；算力 = 轻量分类器（MLP/时序卷积）单卡数小时；接口 = 无新增字段。
- **落地步骤**：①定义五类协调域与判定规则（§3 CC1）；②用 episode 级信号自动伪标 + 人工抽检 5%；③训练 + 校准（可靠性图）；④高阈值门控 + 低置信回退 IND；⑤在 E802 上测宏平均 AUROC 与误激活率。
- **风险**：①伪标噪声（夹爪开合 ≠ 同时使用）⇒ 用腕部帧相对运动与物体随动交叉验证；②类别不平衡（动态全身极少）⇒ 合并为 WBS，动态类只做二分类探测；③误激活伤害基线 ⇒ 高阈值 + IP-C4 兜底。

### IP-C2 · ObjectMediatedCoordinator 对象中介相对坐标 + 滑移重估（P0）

- **动机**：共模误差可被相对坐标消掉（第一性原理 A / CL1）；抓握不确定使闭链约束漂移（第一性原理 C）。
- **与现有方案的差异**：现有相对阻抗/闭链方案假设**已知闭链 + 有力传感**（US12779694B2、CN119283031A 等）；我们把相对变换当**隐变量**，用**滑移残差**在线重估，且只在 bimanual-static 激活。
- **技术可行性**：中–高。EE 位姿、腕部帧、夹爪标量均在观测中；滑移残差可由"运动学预测 vs 视觉观测"计算；相对坐标分解是标准闭链控制，但**增益用学习残差而非固定阻抗模型**（这也是 FTO 分离点之一）。
- **所需资源**：数据 = 官方数据（EE + 腕部 + 夹爪）；算力 = 小（残差头 + 视觉跟踪）；接口 = 无新增字段。
- **落地步骤**：①用官方 client 复刻评测语义（chunk 执行/插值/EE 跟踪）；②实现相对坐标分解 `J_c`（CC5）；③实现滑移残差与重估（CC3）；④实现"重估 → 重规划 → 退非抓取"的恢复链；⑤只在 bimanual-static 相位激活；⑥E803/E804/E807/E808 验证。
- **风险**：①滑移漏检（以为没滑其实滑了）⇒ 保守阈值 + 最大重试 3 次；②相对控制依赖 EE 跟踪精度（若评测端 EE 跟踪差则退化）⇒ 先做零成本探测，必要时退回 joint + 内部 IK 代理；③相对坐标在基座漂移大时仍需绝对锚点 ⇒ 保留低频绝对校正。

### IP-C3 · SensorlessForceBand 无传感器内力带（P0）

- **动机**：无 F/T，但需要"别夹碎 / 别松脱"；现有内外力分解依赖 6D 力传感器（CN119283031A、CN118617411B）。
- **与现有方案的差异**：不估计绝对牛顿力，而是估计**力带**（LOW/OK/HIGH）；特征是闭合动力学、腕部爪-物间隙/形变、滑移残差、伺服误差。**这是最关键的 FTO 分离要素**。
- **技术可行性**：中。离线可用带 F/T 的标定台验证单调性（部署时无 F/T）；视觉间隙用腕部帧分割/光流即可。
- **所需资源**：数据 = 官方数据 + 少量带 F/T 的标定数据（仅离线）；算力 = 小 CNN；接口 = 无。
- **落地步骤**：①定义代理特征 `p_t`（CC4）；②离线标定"代理—真值力"单调性；③训练三带分类器 + 置信度；④带控制器：LOW → 增闭合/减速；HIGH → 减闭合/松；OK → 保持；⑤不可信时回退固定闭合 + 视觉伺服；⑥E805/E806 验证。
- **风险**：①透明/软/遮挡物体上单调性失效 ⇒ 置信度门控 + 回退；②视觉间隙受腕部相机视野限制 ⇒ 用头相机补；③过度调节引入抖动 ⇒ 只在带边界做离散小步调整。

### IP-C4 · ClaimTree 权利要求树门控（P0）

- **动机**：从属权利要求 = 退化（第一性原理 E）；避免协同伤害 SAGE 主线。
- **与现有方案的差异**：现有工作多为单体策略或 ensemble；我们把专利的**独立/从属/fallback** 结构变成带 scope/gate 的 DAG，运行时选"根到叶路径上最深的、所有祖先门控都通过的节点"。
- **技术可行性**：高（工程 + 校准）。
- **所需资源**：接口 = 无；算力 = 极小；数据 = 门控校准集。
- **落地步骤**：①定义树（§3 CC8）；②为每个节点定义 scope 与门控特征（协调域、力带置信、滑移置信、任务 token）；③校准门控（ECE、误激活率）；④实现层次化 early-exit 仲裁；⑤审计每次激活/回退；⑥E809/E810/E811 验证。
- **风险**：①门控误判 ⇒ CL3 条件 + 高阈值；②树太深导致延迟/复杂度 ⇒ CL8 上界 + 最大深度限制；③"看起来像多模型" ⇒ 对外仍单 checkpoint/单 API，树是内部规则化路由（需合规确认）。

### IP-C5 · StaticPosture 全身静态姿态先验（P1）

- **动机**：pivot 动态仅 3/32，但静态姿态影响可达性与平衡；SAGE IP-05 已提出，本轮**降级**为静态 + 少量补偿。
- **与现有方案的差异**：不做动态全身协同；只在 episode 开始时选一个可达 pivot 并保持，必要时做低频补偿。
- **落地步骤**：①零成本探测 pivot 是否被评测端跟踪；②静态姿态先验（手部目标 → pivot 分布）；③低频补偿（仅当 EE 跟踪误差超阈值）；④E813 验证。
- **风险**：pivot 语义未知/被忽略 ⇒ 探测后再投入；动态补偿可能引入抖动 ⇒ 只做低频、限幅。

### IP-C6 · ClaimChart / FTO 审计（P0，meta）

- **动机**：专利布局；避免撞车；找空白。
- **与现有方案的差异**：多数研究不做 FTO；我们把 FTO 作为**设计约束**，并用要素矩阵显式记录"哪些特征读了现有技术、哪些是分离要素"。
- **落地步骤**：①建要素矩阵（§10）；②用 incoPat/PatSnap/Espacenet 做同族/引证/权利要求逐项比对；③为每条独立权利要求找 ≥1 个 separating element；④产出 FTO 备忘录（**非法律意见**）；⑤设计绕开方案。
- **风险**：①初检不充分 ⇒ 明确标注"初检"；②非显而易见性不可证 ⇒ 交专业法律复核；③绕开可能牺牲性能 ⇒ 用门控/回退保住主线。

### IP-C7 · DefensivePublication 防御性公开 + 协同基准（P1）

- **动机**：防止被他人专利堵死；形成公共品；负结果也有价值。
- **落地步骤**：①公开六因子诊断口径（SAGE）；②公开双臂并发基准与 episode 级统计脚本；③公开 E801/E807 的负结果；④保留模型权重与低层实现作为商业秘密。
- **风险**：公开过多削弱商业优势 ⇒ 只公开"方法/基准/负结果"，不公开权重与关键实现。

### IP-C8 · AuditIsolation 审计与端口隔离（P0）

- **动机**：官方采集 per-step 延迟/波动/动作规律性；N 端口并发。
- **落地步骤**：①复用 SAGE IP-08 的延迟/jerk/离群埋点；②增加协同层切换率、门控激活率、重估次数；③N×8 h 压测 + 串扰检测；④导出报告；⑤E820 验证。
- **风险**：协同切换使动作统计不规则 ⇒ 切换处速度连续 + 限幅 + 保留固有随机性。

## 3. 符号与定义（CC1–CC14）

| 符号 | 含义 |
|---|---|
| `o_t` | 观测（4 相机 + 关节 + EE 位姿 + 夹爪标量 + lower_body + 语言） |
| `ℓ` | 语言指令 |
| `R_t` | 协调域 ∈ {IND, LF, RDG, WBS, WBD} |
| `T_L, T_R` | 左右 EE 位姿（基座系） |
| `T_rel` | 相对变换 `T_L^{-1}T_R` |
| `M, M̂_t` | 对象中介约束流形及其估计 |
| `Σ_t` | 约束估计不确定度 |
| `s_t` | 滑移残差 ∈ se(3) |
| `p_t` | 无传感器内力代理特征 |
| `b_t` | 力带 ∈ {LOW, OK, HIGH} |
| `ξ_o, ξ_rel` | 对象运动 / 内部（相对）运动 twist |
| `J_c` | 协同雅可比 |
| `J_wb` | 全身雅可比 `[J_arm, J_pivot]` |
| `c=(S_c,γ_c,π_c,k_c,ν_c)` | 权利要求节点 |
| `T=(C,E)` | 权利要求树（DAG） |
| `c*` | 运行时选中的最深通过节点 |
| `V(C)` | 组合价值 |
| `E_{f,p}` | 要素矩阵（特征 f 是否出现在现有技术 p） |
| `W(f)` | 空白带分数 |

**定义 CC1（协调域）** `R_t = g_R(o_t, ℓ) ∈ {IND, LF, RDG, WBS, WBD}`：IND 独立双臂；LF 主从（一手稳定、一手操作）；RDG 刚性双臂抓握同一物体；WBS 静态全身；WBD 动态全身。

**定义 CC2（对象中介约束）** `T_rel = T_L^{-1}T_R`；约束流形 `M = {T_rel : 与物体几何/抓握一致}`；估计 `M̂_t` 与 `Σ_t`。RDG 下 `T_rel` 近似常量；LF 下 `T_rel` 由任务轨迹给定。

**定义 CC3（滑移残差与事件）** `s_t = Log(T_rel^{obs}(T_rel^{pred})^{-1}) ∈ se(3)`，其中 `T_rel^{pred}` 由 `M̂_{t-1}` 与运动学预测；滑移事件当 `‖s_t‖_{Σ_t} > τ_s`。重估 `M̂_t = RE(o_{t-k:t}, s_t)`。

**定义 CC4（无传感器内力代理）** `p_t = φ(g_t, Δg_t, I^{wrist}_t, s_t, e^{servo}_t)`，`g_t` 夹爪标量，`Δg_t` 闭合速率，`I^{wrist}` 腕部爪-物间隙/形变特征，`e^{servo}` 伺服跟踪误差；力带 `b_t = h(p_t) ∈ {LOW, OK, HIGH}`，`h` 为带置信度的分类器。

**定义 CC5（相对坐标协同）** 在共同坐标系下 `ξ_L = ξ_o − ½ξ_rel`、`ξ_R = ξ_o + ½ξ_rel`；`J_c = [J_L; J_R]` 把 `(ξ_o, ξ_rel)` 映到 `(q̇_L, q̇_R)`；`q̇ = J_c^+[ξ_o; ξ_rel] + (I − J_c^+J_c)z`。内部运动落在对象运动的零空间，不移动物体、只改变夹持。

**定义 CC6（全身协同）** `J_wb = [∂x/∂q_arm, ∂x/∂q_pivot]`；保持 EE 目标时 `q̇_arm = −J_arm^+J_pivot q̇_pivot + J_arm^+ẋ_des`；仅低频、限幅启用。

**定义 CC7（权利要求）** `c = (S_c, γ_c, π_c, k_c, ν_c)`：`S_c` scope（任务 × 相位 × 协调域）；`γ_c(o)∈[0,1]` 门控；`π_c` 控制器；`k_c` 计算/延迟成本；`ν_c ∈ {white, crowded, adjacent}` 新颖性状态。

**定义 CC8（权利要求树）** `T=(C,E)`；`(c_i→c_j)` 表示 `c_j` 是 `c_i` 的从属权利要求，`S_j ⊆ S_i`；根 `c_0 = SAGE`。允许 DAG（一个节点可有多个父，表示"多重从属"），运行时取最深的可行节点。

**定义 CC9（仲裁规则）** `c*(o_t) = argmax_{c ∈ P(o_t)} depth(c)`，`P(o_t)` 为所有满足"自身及全部祖先 `γ ≥ τ`"的节点；若无，取根。输出 `a_t = π_{c*}(o_t)`。

**定义 CC10（组合价值）** `V(C) = E_{o∼D}[R(π_{c*(o)})] − λE[k_{c*}]`，`R` 为任务成功/分数，`λ` 为成本权重。

**定义 CC11（覆盖与子模性）** 把任务 × 相位离散为单元 `u`；`F_c(A)=Σ_{u∈A} w_u 1[u∈S_c]`；`F(A)=Σ_c w_c F_c(A)`。在单元独立、权重非负时 `F` 单调子模。

**定义 CC12（要素矩阵与空白带）** `E∈{0,1}^{|F|×|P|}`，`E_{f,p}=1` 表示特征 `f` 出现在现有技术 `p`；空白带分数 `W(f)=rel(f)·(1−density(f))`，`density(f)=Σ_p E_{f,p}/|P|`。

**定义 CC13（FTO 分离要素）** 权利要求 `c` 的要素集 `elem(c)`；若对每篇现有技术 `p` 都存在 `f∈elem(c)` 使 `E_{f,p}=0`，则称 `c` 有分离要素、不被单篇现有技术**完全覆盖**（anticipation 的必要条件，非充分条件）。

**定义 CC14（门控校准）** `ECE(γ)=Σ_b (n_b/N)|acc(b)−conf(b)|`；误激活率 `α=P(γ≥τ | c 无增益)`；regret `= E[R_oracle] − E[R_claimtree]`。

```python
# ===== CLAIM-PORT：单 checkpoint、单 API，协同作为从属权利要求 =====
class ClaimPortPolicy:
    def __init__(self, sage_ckpt, tree, tau_gate=0.8):
        self.sage   = load_sage(sage_ckpt)          # SAGE 主干（唯一学习主体）
        self.regime = CoordinationRegimeClassifier() # IP-C1 / CC1
        self.coord  = ObjectMediatedCoordinator()    # IP-C2 / CC2-CC5
        self.force  = SensorlessForceBand()          # IP-C3 / CC4
        self.tree   = tree                           # IP-C4 / CC8
        self.tau    = tau_gate
        self.sessions = {}                           # port -> Session（隔离）

    def reset(self, port):
        self.sessions.setdefault(port, Session()).reset()

    def get_action(self, obs, port):
        s = self.sessions[port]
        R  = self.regime.predict(obs)                # 协调域
        b  = self.force.band(obs)                    # 力带 + 置信
        slip = self.coord.slip_residual(obs, s.M_hat) # CC3

        # 层次化 early-exit：选根到叶路径上最深的、所有祖先门控都通过的节点
        c = self.tree.select(obs, R, b, slip, s)     # CC8/CC9

        if c is None or c.is_root:
            a = self.sage.act(obs)                   # L3/L4 回退
        elif c.kind == "relative":
            a = self.coord.act(obs, R, b, s)         # 相对坐标 + 滑移重估
        elif c.kind == "whole_static":
            a = self.sage.act(obs, pivot_prior=True) # 静态姿态
        else:
            a = c.controller.act(obs)

        a = self.audit(a, obs, c, R, b, s)           # IP-C8
        s.last_action = a
        return self.pack(a)
```

```python
# ===== IP-C2：对象中介相对坐标 + 滑移重估（CC2/CC3/CC5）=====
class ObjectMediatedCoordinator:
    def act(self, obs, R, band, s):
        T_rel = relative_transform(obs)              # T_L^{-1} T_R
        s.slip = log_se3(T_rel @ inv(s.T_rel_pred))  # CC3 滑移残差
        if norm_weighted(s.slip, s.Sigma) > TAU_S:
            s.M_hat = self.reestimate(obs, s.slip)   # 约束流形重估
            s.n_retry += 1
            if s.n_retry > 3:
                return self.sage_fallback(obs)       # 退 SAGE / 非抓取原语
        xi_obj = self.object_controller(obs)         # 对象运动
        xi_rel = self.internal_controller(obs, band, s.M_hat)  # 相对/内力
        qdot = self.Jc_pinv(obs) @ concat(xi_obj, xi_rel)      # CC5
        return qdot_to_action(qdot, obs)

    def internal_controller(self, obs, band, M_hat):
        # 不用固定阻抗模型；用学习残差 + 离散力带调节（FTO 分离点）
        base = self.learned_rel_residual(obs, M_hat)
        if band == LOW:  return base + self.close_and_slow(obs)
        if band == HIGH: return base + self.release_or_backoff(obs)
        return base
```

```python
class ClaimTree:
```

## 5. 推导（引理 CL1–CL8）

**引理 CL1（共模误差抵消）** 设臂 `i` 的闭环位置误差 `e_i(z) = S_i(z)d(z) + n_i(z)`，`d` 为共模扰动（躯干漂移、标定偏置、负载），`S_i` 为闭环灵敏度，`n_i` 为独立噪声。则 `e_rel = e_R − e_L = (S_R − S_L)d + (n_R − n_L)`。当 `S_L = S_R` 时共模项**精确相消**；相对控制的收益因子为 `‖S_R−S_L‖/‖S‖`，随灵敏度失配与共模扰动增大而增大。∎
*含义*：协同在"两臂动力学不同（负载/接触）或躯干漂移大"时最有价值；这是可测的，而不是口号。

**引理 CL2（滑移重估的净收益）** 设每步滑移概率 `p_s`、检测召回 `r`、误触发率 `α`、真检测后恢复成功率 `g`、误触发损失 `L`、开销 `c`。每步期望变化 `Δ = r p_s g − α(1−p_s)L − c`；`Δ>0` 当且仅当 `r p_s g > α(1−p_s)L + c`。取 `τ_s` 使 `α ≤ α_max` 即可保证净收益。∎
*含义*：与 SAGE L3 同构——保守介入（高精度低召回）是滑移重估的默认形态。

**引理 CL3（权利要求树弱占优）** 设根 `c_0` 在 scope `S_0` 上成功率 `P_0`；子节点 `c` 在 `S_c⊆S_0` 上成功率 `P_c ≥ P_0 + Δ_c`，门控误激活率 `α_c`，误激活损失 `L_c`。若门控校准且层次化，则 `E[Δ] = Σ_c [P(S_c)Δ_c − α_c L_c]`；只要对每个 `c` 有 `P(S_c)Δ_c ≥ α_c L_c`，组合弱占优于根。∎
*含义*：从属权利要求只在"门控足够准"时才不伤害主线；否则应删掉该从属权利要求（P10 收缩）。

**引理 CL4（力带充分性）** 设真实内力 `f_int` 在任务分布上对代理 `p_t` 单调（`∂f/∂p>0`），且带边界 `[p_lo,p_hi]` 满足 `p<p_lo ⇒ 滑脱风险>ε_s`、`p>p_hi ⇒ 夹碎风险>ε_c`。则把 `p` 保持在 `[p_lo,p_hi]` 的控制器把两类风险分别压到 `ε_s, ε_c` 以下。若单调性失效（透明/软/遮挡），力带不可识别，必须回退固定闭合 + 视觉伺服。∎
*含义*：这是"无 F/T 也能做内力安全"的**条件性**保证，不是无条件保证。

**引理 CL5（组合子模性与贪心界）** 若任务-相位单元独立、覆盖可加，则覆盖函数 `F(A)` 单调子模，贪心达到 `≥(1−1/e)F(A*)`。带成功率权重与交互项时子模性只是近似，故把贪心当启发式，并在小规模实例上与穷举对比报告 gap。∎
*含义*：组合设计可计算，但不要假装它有严格最优保证。

**引理 CL6（FTO 必要条件）** 若权利要求 `c` 对每篇现有技术 `p` 都存在分离要素 `f`（`E_{f,p}=0`），则 `c` 不被任何单篇现有技术**完全覆盖**（anticipation 的必要条件）。但**创造性/非显而易见性**与权利要求解释是法律判断，本引理不构成 FTO 结论。∎
*含义*：claim chart 能帮我们设计绕开，但不能替代律师。

**引理 CL7（协同价值与耦合系数）** 设 `κ` 为任务成功 logit 中由相对误差解释的比例（耦合系数），`G_rel` 为相对控制的增益，`C_coord` 为协同开销。净收益 `≈ κG_rel − (1−κ)C_coord`；协同有利当且仅当 `κ > C_coord/(G_rel+C_coord)`。∎
*含义*：这直接给出 IP-C1 的门控阈值应随任务耦合度变化，而不是固定开关。

**引理 CL8（仲裁成本）** 层次化 early-exit 下，期望门控成本 `E[k]=Σ_d P(到达深度 d)·k_d ≤ D·max k_d`；最坏 `O(n)`，门控稀疏时期望 `O(D)`。取 `k_gate≤2ms`、`k_arbiter≤1ms`，协同层新增 p99 ≤3ms，仍在 SAGE 的 ~105ms 预算内。∎

### 10.3 权利要求草稿（工程版，非法律文本）

**独立权利要求（宽）**：一种在仅有 1 自由度夹爪、无力/触觉传感器、且抓握状态不确定的条件下运行双臂/人形机器人的方法，包括：
1. 从观测与语言指令判定协调域（独立/主从/刚性双臂/静态全身/动态全身）；
2. 将双臂相对变换建模为**带不确定度的隐变量**，估计对象中介约束流形；
3. 由夹爪闭合动力学、腕部视觉间隙/形变、滑移残差与伺服误差推断**内力带**（非绝对力）；
4. 当滑移残差超过阈值时，**重估约束流形并重规划**；
5. 通过**权利要求树**对协同控制器进行分层门控与逐级退化，仅在门控通过时接管。

**从属权利要求（窄/fallback）**：
- C1a 主从柔顺：一手稳定、一手操作的导纳分配；
- C1b 刚性双臂抓握：相对位姿软约束 + 内部运动零空间投影；
- C2 静态全身姿态先验 + 低频 pivot 补偿；
- C3 非抓取原语回退（承接 SAGE IP-02：推/扫/倾倒/钩）；
- C4 力带控制器：LOW→增闭合/减速，HIGH→减闭合/松，OK→保持；
- C5 门控校准与审计：ECE、误激活率、切换率、延迟。

**分离要素（separating elements）**：**F8（无 F/T 力带）+ F9（滑移重估）+ F10（门控树）+ F12（1-DoF 抓握不确定性）**。只要每篇现有技术至少缺其中之一，独立权利要求就不被单篇完全覆盖（CL6 的必要条件）。

**设计绕开（design-around）**：
- 不用"相对阻抗模型"作为必要特征 ⇒ 用**学习残差 + 离散力带**；
- 不用 6D F/T ⇒ 用**视觉-运动代理**；
- 不用"主从动态切换" ⇒ 用**权利要求树门控**；
- 不假设已知闭链 ⇒ 把约束当**滑移可变的隐变量**。
