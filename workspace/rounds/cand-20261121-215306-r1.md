# 第 1 轮（灵感循环第 1 轮；基线 v20；本轮灵感：「迁移学习」×「智能体」）

> **基线**：v20 产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（感知层：PCA / CTS / CFC / HPC / CFCtrl）。
> 本轮纪律：**迁移是「可证伪的安全域搬运」，智能体是「持有拒绝权的证书主体」**。不推倒 v20：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v19 的 DCM/OGCC/CCV/DRS/OGC、v20 的 PCA/CTS/CFC/HPC/CFCtrl 全部保留。本轮只做一件事：**让安全证书能在「不同本体 / 不同任务 / 不同智能体」之间迁移，同时让负迁移可被主动证伪、可被智能体自主拒绝**。

## 0. 直觉与动机

**灵感 1（迁移学习 → 迁移的不是知识，而是「可证伪的安全域」）**
直觉：人把「我端过这只杯子」迁移到「我端那只杯子」时，搬运的不是动作参数，而是「我知道哪里安全」的边界；一旦换了手（本体）或换了杯子（任务），这个边界必须缩水。v20 的 HPC 是**本体绑定**的：证书只对产生它的机器人、任务、传感器标定成立。把它直接复制给另一个智能体，等于把「我的盲区」伪装成「你的安全域」——这正是负迁移（negative transfer）最危险的地方：**它看起来像正迁移**。核心创新：**可证伪证书迁移（Falsifiable Certificate Transfer, FCT）**。迁移载体不是策略参数，而是**公共任务流形 X 上的安全子集 S_src**；每个智能体有一个**本体提升映射 L_a: X ⇀ Θ_a**（部分定义，因为不是所有任务位姿都可实现）；迁移只在 `S_src ∩ Reach_{a_tgt} ∩ Compatible(τ)` 上进行，且**必须携带一个「能失败」的证伪计划**（在目标本体上主动搜反例）。关键反直觉点：**安全迁移的价值不在于「能复用多少」，而在于「能证明何时不该复用」**。

**灵感 2（智能体 → 自主性不是自由探索，而是「拒绝权 + 证伪义务」）**
直觉：一个真正的具身智能体不应被动接受云端下发的安全证书；它更像持有护照的旅行者，随身携带自己的安全履历，并有权在入境时拒绝一张可疑签证。核心创新：**智能体证书护照（Agent Certificate Passport, ACP）**。护照封装 `(本体签名 E_a, 证书集合 {HPC_i}, 反例库, 版本, provenance, merkle_root)`，可跨本体升级、跨任务复用、跨智能体交换。配套 **智能体证书经纪人（Agentic Certificate Broker, ACB）**：源智能体发布可迁移证书与证伪计划，目标智能体**自主决定**是否接受、以多大预算证伪、失败后如何降级。关键反直觉点：**智能体的自主性越高，其安全域反而越保守**——因为拒绝迁移的默认动作是「本地重新验证」，而验证只会收缩域。自主性在此被重新定义为 **P36 拒绝权律**，而不是「自由探索」。

**灵感 3（两者统一：迁移的「汇率」由本体距离决定）**
直觉：把安全证书从 A 迁到 B 类似货币兑换：需要一个**汇率 τ(A,B)**，且汇率随本体差异、标定漂移、时间衰减而下降；汇率跌破阈值时交易自动关闭、退回本地验证。核心创新：**本体迁移率（Embodiment Transferability, ET）**。用 `d_E`（运动链编辑距离、连杆比、关节限位比、传感器配置重叠度、控制增益距离）与 `d_T(x)`（任务流形局部几何差异）共同定义 τ，并把 τ 显式乘进迁移域 `S_tgt = Φ(S_src) ∩ {x : τ(A,B,x) ≥ τ_th}`。关键反直觉点：**迁移率不是全局常数，而是任务流形上的标量场**——同一对智能体在「桌面抓取」上迁移率可能很高，在「狭窄通道」上可能接近 0。

**三者如何统一**
统一为 **v20 证书体系之上的迁移—智能体层**：v20 回答「当前智能体在 θ 下是否安全」，v21 回答「这个安全结论能否被另一本体/任务可信搬运，以及目标智能体是否愿意接受」。FCT 是迁移算子侧（安全域如何搬运），ET 是汇率侧（本体间可信度场），ACP 是载体侧（安全履历如何随身携带），ACB 是协议侧（智能体如何自主协商）。共享状态 `ζ_tr = (E_a, S_src, Φ, τ_field, passport, counterexample_lib, mode_transfer)`。统一接口：**若 FCT 的覆盖 / 收缩 / 无反例三条件通过且 τ ≥ τ_th，则目标智能体接受迁移域；否则退化为本地 v20 HPC 重验证**。安全继承仍成立：`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。

## 1. 研究问题（轮次升级版）

- **Q1（可证伪迁移的可靠性）**：如何构造证伪计划，使「无反例」不是采样偶然，而是一个可报告、可审计的置信下界？证伪预算 k 与误接受率 δ 如何权衡？当证伪样本本身受目标本体感知噪声污染时，如何避免「用污染的证据证明安全」？

- **Q2（本体距离与迁移率）**：`d_E`、`d_T(x)` 如何定义才满足「相似本体靠近、差异本体远离」，且对尺度缩放、自由度增减、关节重参数化保持稳定？τ 的阈值 τ_th 如何随任务流形位置自适应，而非全局固定？

- **Q3（负迁移的可检测性）**：当源证书本身已含 v20 的分布式盲区（「众口铄金」型系统性误判），目标智能体如何避免把源盲区当作自身安全域？反例库如何跨智能体共享而不传播污染？是否需要「跨源冗余」——至少两个独立本体/传感器对同一 S_transfer 一致？

- **Q4（智能体自主性与安全）**：拒绝迁移的默认路径如何保证不损失过多活性？ACB 的协商如何在 N ≤ 10、通信受限、部分智能体故障时收敛？当所有智能体都拒绝时，系统是否退化为「各自本地验证」的 v20，且活性有下界？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 迁移可证伪律（Transfer Falsifiability）**
任何迁移证书 `TC = (a_src, a_tgt, S_src, Φ, S_transfer, τ_field, falsification_plan, merkle_root)` 必须携带**可失败的证伪计划**：在目标本体上，从 S_transfer 按分布 D 采 k 个反例候选，逐一执行目标本地 CCV；只有**全部 SAFE 且证伪计划如实记录了搜索空间、预算与失败模式**时，迁移才被接受。**没有证伪计划的迁移一律拒绝**（fail-closed）。迁移接受的是「暂时未被证伪的安全域」，不是「已证明的安全域」——这一区分是负迁移可检测性的前提。

**P35 本体漂移保守律（Embodiment Drift Conservatism）**
迁移率 τ 随本体距离与时间单调不增：`τ(a_src, a_tgt, x, t) = τ_E · τ_T(x) · τ_fresh(t)`，其中 `τ_E = exp(-d_E/σ_E)`、`τ_T(x) = exp(-d_T(x)/σ_T)`、`τ_fresh(t) = exp(-age/τ_0)`。当 `τ < τ_th(x)` 时迁移关闭，退回本地 v20 重验证。**漂移只会让域收缩，不会让域扩张**：τ 的任一分量下降都使 S_transfer 单调收缩。

**P36 智能体拒绝权律（Agent Refusal Right）**
目标智能体对任何迁移证书拥有**无条件拒绝权**，且拒绝不被惩罚、不被记为失败；拒绝的默认后果是**本地重验证**（等价 v20），而非「无动作」。自主性被定义为「**有权保守 + 有义务证伪**」：智能体可以拒绝，但不能跳过证伪就接受。**拒绝单调性**：增加拒绝选项只会使可执行集合收缩，不会引入新的碰撞风险。

## 3. 与基线的接口（如何退化）

- FCT 失效（无法构造公共任务流形 / 提升映射不可用）⇒ 只接受同一本体的 HPC ⇒ 等价 v20；
- ET 失效（本体签名缺失 / 标定未知）⇒ τ 取 0 ⇒ 全部迁移被拒绝 ⇒ 等价 v20 本地重验证；
- ACP 失效（护照损坏 / 版本不兼容）⇒ 智能体无历史证书 ⇒ 从零本地验证 ⇒ 等价 v19/v20；
- ACB 失效（网络分区 / 协商超时）⇒ 不进行跨智能体迁移 ⇒ 各自本地执行 ⇒ 等价 v20；
- 证伪计划无法执行（目标本体离线）⇒ 拒绝迁移 ⇒ 本地重验证 ⇒ 等价 v20；
- **安全继承**：FCT 只能搬运并收缩域、ET 只能关闭或收缩迁移、ACP 只提供可审计历史、ACB 只做筛选；任意失效都使域收敛性增强，`Exec_v21 ⊆ Exec_v20` 由引理 162 保证。

## 4. 预期贡献

1. **可证伪迁移**：首次把「迁移学习」在安全关键场景中改写为「带证伪计划的安全域搬运」，使「不复用」本身成为可证明的、可审计的决策，而非启发式失败；
2. **本体迁移率场**：提出任务流形上的标量场 τ(A,B,x)，把跨本体/跨任务的泛化从「二值接受」升级为「随位置变化的连续可信度」，并给出单调收缩保证；
3. **智能体证书护照**：把安全证书从「一次性运行时产物」升级为「可随身携带、可跨本体升级、可追溯 provenance 的履历载体」，并给出 Merkle 可审计结构；
4. **负迁移的主动防御**：给出反例库、跨源冗余与污染过滤机制，使「源盲区→目标安全域」的系统性误判可被检测与阻断；
5. **自主性—安全性统一**：证明「拒绝权 + 证伪义务」的智能体协议在任意拒绝率下都保持 `Exec_v21 ⊆ Exec_v20`，并给出活性下界，实现「越自主越保守」的反直觉安全闭环。

## 5. 本轮最大风险

**一句话**：FCT 的证伪计划在目标本体上采样，但若目标本体与源本体共享**同一类未建模的几何/感知误差**（如同一厂商深度相机、同一标定流程），则证伪样本会「一致地通过」，负迁移检测器本身被系统性偏差污染——护照把源盲区当作目标安全域，形成**「证伪也证不出来的安全幻觉」**。

# IP-426 Embodiment Transferability Field
class EmbodimentTransferabilityField:
    def __init__(self, sigma_E=0.5, sigma_T=0.5, tau0=600.0):
        self.sigma_E, self.sigma_T, self.tau0 = sigma_E, sigma_T, tau0

    def embodiment_distance(self, E1, E2):
        d_chain = edit_distance(E1.K, E2.K)                 # 运动链编辑距离
        d_link = sum(abs(log(r1 / r2)) for r1, r2 in zip(E1.ell, E2.ell))
        d_joint = sum(abs(q1 - q2) / max(1e-6, q1 + q2) for q1, q2 in zip(E1.q, E2.q))
        d_sensor = 1.0 - jaccard(E1.Sigma, E2.Sigma)        # 传感器配置重叠度
        d_gain = norm(E1.G - E2.G) / max(1e-6, norm(E1.G))
        return w_chain*d_chain + w_link*d_link + w_joint*d_joint + w_sensor*d_sensor + w_gain*d_gain

    def tau(self, E1, E2, x, t, t_cert):
        dE = self.embodiment_distance(E1, E2)
        dT = self.task_divergence(x)                        # 相对源任务分布
        age = t - t_cert
        return math.exp(-dE/self.sigma_E) * math.exp(-dT/self.sigma_T) * math.exp(-age/self.tau0)

    def tau_threshold(self, x, risk):
        # 高风险任务位置抬高阈值：越靠近奇异/狭窄区域，越难迁移
        return tau_min + (1.0 - tau_min) * risk(x)


# IP-425 Falsifiable Certificate Transfer
class FalsifiableCertificateTransfer:
    def __init__(self, etf, nts, delta=0.05):
        self.etf, self.nts, self.delta = etf, nts, delta

    def construct(self, src, tgt, S_src, plan, now):
        # C1 覆盖：只保留目标本体可达的任务点
        lifted = {x for x in S_src if tgt.lift(x) is not None}
        # C2 收缩：τ 场与源盲区惩罚只能收缩
        S_tr = {x for x in lifted
                if self.etf.tau(src.E, tgt.E, x, now, src.cert_time)
                   >= self.etf.tau_threshold(x, tgt.risk)
                and x not in self.nts.blind_source(src, x)}
        if not S_tr:
            return None, "EMPTY_TRANSFER"
        tc = TransferCertificate(src=src, tgt=tgt, S_src=S_src,
                                 S_transfer=S_tr, plan=plan)
        return tc, "OK"

    def falsify(self, tc):
        # P34：证伪计划必须能失败；失败即拒绝
        if tc.plan is None or tc.plan.k <= 0:
            return "REFUSE_NO_PLAN"
        samples = sample(tc.plan.D, tc.S_transfer, tc.plan.k)
        for x in samples:
            theta = tc.tgt.lift(x)
            if tc.tgt.ccv(theta) != "SAFE":     # 复用 v19 CCV / v20 HPC
                tc.tgt.passport.add_counterexample(x, "UNSAFE")
                return "REFUSE_COUNTEREXAMPLE"
        # 交换性假设下的误接受上界，写入证书供审计
        tc.confidence = 1.0 - (1.0 - self.delta) ** tc.plan.k
        return "ACCEPT"

    def transfer(self, src, tgt, S_src, plan, now):
        tc, st = self.construct(src, tgt, S_src, plan, now)
        if st != "OK":
            return None, st
        verdict = self.falsify(tc)
        if verdict != "ACCEPT":
            return None, verdict
        return tc, "ACCEPT"

class AgenticCertificateBroker:
    def __init__(self, fct, nts, max_rounds=3):
        self.fct, self.nts, self.max_rounds = fct, nts, max_rounds

    def negotiate(self, src, tgt, S_src, plan, now):
        # 目标智能体拥有无条件拒绝权（P36）
        if not tgt.willing_to_verify():
            return None, "REFUSE_AUTONOMY"
        tc, status = self.fct.transfer(src, tgt, S_src, plan, now)
        if status != "ACCEPT":
            # 拒绝的默认后果是本地重验证，而非无动作
            return None, "LOCAL_FALLBACK"
        if self.nts.redundancy_ok(tc) is False:
            return None, "REFUSE_LOW_REDUNDANCY"
        return tc, "TRANSFER"

    def round(self, agents, requests, now):
        # 通信受限：每轮只允许一次 offer/response；超时即本地回退
        accepted = {}
        for src, tgt, S_src, plan in requests[:self.max_rounds]:
            tc, st = self.negotiate(src, tgt, S_src, plan, now)
            if st == "TRANSFER":
                accepted[(src.id, tgt.id)] = tc
        return accepted


# IP-429 Negative-Transfer Sentinel
class NegativeTransferSentinel:
    def __init__(self, min_redundancy=2, blind_penalty=0.15):
        self.min_redundancy, self.blind_penalty = min_redundancy, blind_penalty

    def redundancy_ok(self, tc):
        # 跨源冗余：至少 min_redundancy 个独立本体/传感器对 S_transfer 一致
        return tc.redundancy >= self.min_redundancy

    def blind_source(self, src, x):
        # 源证书中由 v20 的「众口铄金」标记为盲区的位置，直接惩罚排除
        if src.hpc.is_blind(x):
            return True
        return False

    def filter_counterexamples(self, CE_lib):
        # 反例库共享时，用 v20 CFC 的 Mahalanobis 剔除污染条目
        return [ce for ce in CE_lib
                if mahalanobis(ce.feature, mean_feat(CE_lib), cov_feat(CE_lib)) < 3.0]

## 3. 推导

**引理 157（迁移可靠性）** 若迁移证书 TC 满足 (C1) `S_transfer ⊆ Φ(S_src) ∩ Dom(L_tgt)`、(C2) `S_transfer ⊆ S_tgt^local`、(C3) 证伪计划 k 个样本全部 SAFE，则在交换性假设下，对 `x ∈ S_transfer` 目标本体执行零碰撞的概率 ≥ `1 - (1-δ)^k`。∎

**引理 158（负迁移上界及其失效条件）** 在证伪样本与真实执行分布可交换时，未检测负迁移概率 ≤ `(1-δ)^k`；当目标与源共享同一未建模误差（协变量偏移/相关噪声）时交换性破坏，该上界**不成立**——这是 v21 的核心失效模式。∎

**引理 159（护照防篡改）** ACP 的 `merkle_root` 覆盖证书集、反例库与 provenance；任何字段修改都会改变根哈希，故可机械检测篡改。∎

**引理 160（拒绝单调性）** 引入拒绝谓词 ref(a,TC) 只会从可执行集合中删除迁移域，不新增动作；故 `Exec_v21(ref) ⊆ Exec_v21(¬ref)`，拒绝不增加碰撞风险。∎

**引理 161（漂移单调收缩）** τ 的每个分量（τ_E、τ_T、τ_fresh）均单调不增且阈值 τ_th 固定，故随时间/距离增长，`{x : τ ≥ τ_th}` 单调收缩，`S_transfer` 单调收缩。∎

**引理 162（v21 整体安全继承）** 同一几何快照、同一智能体集合下，FCT 只搬运并收缩域、ETF 只关闭/收缩迁移、ACP 只提供可审计历史、ACB 只筛选、NTS 只惩罚排除，故 `Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 7. 已知风险与失效模式

1. **共享系统性偏差（最致命）**：源/目标本体共享同一相机、同一标定、同一控制器族时，证伪样本会一致通过，负迁移不可检测。缓解：异构传感器、独立标定、跨厂商冗余、主动扰动探针。
2. **公共任务流形失真**：X 的定义（物体位姿+力上界）若遗漏关键自由度（如接触力矩方向），提升映射会把不安全点映成安全点。缓解：扩展 X、加入接触模式维度、在线残差监测。
3. **τ 场过保守**：σ_E、σ_T 取小会使 τ 迅速跌破阈值，迁移几乎不可用，活性退化。缓解：分任务校准、自适应阈值、活性反馈闭环。
4. **反例库污染**：跨智能体共享反例可能被恶意/故障条目污染，反而误杀安全域。缓解：CFC 异常过滤、签名验证、来源信誉。
5. **护照版本兼容性**：跨代本体签名格式变化导致护照不可解析。缓解：模式版本化、向后兼容解析、降级到本地验证。
6. **证伪预算与实时性冲突**：k 大则误接受低但延迟高，可能与 50Hz 控制环冲突。缓解：离线预证伪 + 在线增量证伪、异步证伪、TTL 回退。
7. **协商死锁**：所有智能体互相拒绝导致无迁移、活性骤降。缓解：本地回退保证、活性下界监控、随机化提议顺序。

## 8. 本轮最大风险

**一句话**：FCT 的证伪计划在目标本体上采样，但若目标本体与源本体共享**同一类未建模的几何/感知误差**（同一深度相机、同一标定流程、同一控制器族），则证伪样本会「一致地通过」，负迁移检测器本身被系统性偏差污染——护照把源盲区当作目标安全域，形成**「证伪也证不出来的安全幻觉」**。
