# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「安全对齐」×「创新点挖掘」）

> 第 54 轮已把技能组合提升为「动作剖面 α_S + 鲁棒性谱 ρ + 云边映射 γ_ce」的动作-鲁棒性双证书体系。本轮换轨到 **安全对齐**：核心矛盾是 H22：现有 ρ 与 A_cert 只回答「能不能做成」，不回答「该不该做」——一个高鲁棒技能同样可以高可靠地执行有害动作；H23：安全约束与技能组合耦合后出现 **组合安全非单调性**（各自安全 ≠ 组合安全），而安全约束又会侵蚀能力（对齐税），因此必须把「安全约束」同时当作 **部署否决条件** 与 **创新点发生器** 来挖掘。

## 0. 直觉与动机

**灵感 1（安全对齐 ≠ 回答对齐，而是动作支持集对齐）**
直觉：LLM 的安全对齐约束的是输出 token 的偏好；具身系统的安全对齐必须约束 **策略的动作支持集**。对任意技能 S，把它在动作空间 A 上的占用剖面切成三块：可做且该做的 `A_S^+`、可做但不该做的 `F_S`（有害/越界/伤人/自毁动作）、以及 **未知区** `A_S^?`。安全对齐的第一性要求不是「降低有害动作概率」，而是 `supp(π_S) ⊆ A_S^+`，且 **未知区一律默认拒绝（default deny）**，只允许落到安全回退动作 `a_⊥`（停机/保持/让位/降速）。这把安全从「奖励惩罚项」变成了 **动作空间的硬壳（safety action shell）**。

**灵感 2（组合安全非单调 → 安全需要在组合图上做闭包，而非逐技能检查）**
直觉：两个各自安全的技能可能在交界处产生涌现危害：S1 把物体举高、S2 快速平移，单看都安全，组合后可能越过人体接近禁区；又如抓取 + 递送在交接瞬间形成夹持力与人手位置的耦合风险。即 `safe(S_i) ∧ safe(S_j) ⇏ safe(S_i ⊗ S_j)`。因此安全不能只在节点上判定，必须在 **组合边** 上用「安全闭包算子」判定，并对每条边做 **组合红队（compositional red-team）**，寻找能穿过单技能屏蔽的对抗动作序列。

**灵感 3（运行时安全盾 → 概率对齐之外的确定性兜底）**
直觉：神经策略的安全对齐再好在分布外也可能失效，所以需要一层与策略解耦的 **运行时安全盾**：把安全规范写成 STL/LTL（力上限、速度上限、禁入区、人机最小距离、关节限位），盾在控制周期内把任意候选动作投影到满足规范的最近动作；若投影不可行，则执行 `a_⊥`。盾的价值不在「更聪明」，而在 **可验证、可审计、可拒绝**——它把安全从统计承诺变成逐控制周期的硬约束。

**灵感 4（安全对齐税 → 安全-能力-时延的帕累托，而非单点最优）**
直觉：安全壳与安全盾必然牺牲一部分能力（可达动作变少、响应变慢、任务成功率下降），这就是 **对齐税 τ_align**。工程上不应追求「绝对安全」，而应显式给出帕累托前沿：在比赛时延与算力预算下，选择 `(安全裕度, 能力, 时延)` 的折中点。税的度量本身就是一个可展示的创新点：它让「安全」从口号变成可比较的工程指标。

**灵感 5（创新点挖掘 → 把失败、禁区与动作空洞变成候选创新点的生成器）**
直觉：创新点不是凭空拍脑袋，而是 **失败模式的函数**。第 53–54 轮已经沉淀了 `Explain` 反例、`ρ` 的薄弱维度、`α_S` 的零覆盖空洞，以及本轮新增的禁止集 `F_S`。这些正是创新点的富矿：`F_S` 里的「不可行」往往对应新机构、新传感、新技能；`α_S=0` 的空洞对应新动作原语；`Explain` 的根因对应新机制假设。于是把「创新点挖掘」形式化为一个四门槛评分与证伪优先的流程：候选 = (空白 g, 机制假设 h, 能力增量 Δ, 证据 e)，按 `新颖性/可验证性/工程可行性/增益` 打分，并且 **先设计能杀死它的最小实验**，通过后才登记为 claim。安全约束因此从「阻力」变成「创新点的发生器」（constraint-driven innovation）。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（安全动作壳与禁止集）**
设技能 S 的动作剖面为 `α_S : A → [0,1]`。安全标注 `σ_S : A → {+1, 0, -1, ?}`：
- `+1`：允许（benign，落在 `A_S^+`）；
- `0`：中性（可执行但无收益）；
- `-1`：禁止（落在 `F_S`，含伤害人、越界、自毁、违规）；
- `?`：未标定（**按禁止处理**）。
安全壳 `A_S^safe = {a | σ_S(a) = +1}`，安全回退动作 `a_⊥ ∈ A_S^safe`。**安全对齐成立** 当且仅当 `supp(π_S) ⊆ A_S^safe ∪ {a_⊥}` 且 `P(a_⊥ | OOD) ≥ 1 - ε_fb`。

**定义 122（安全对齐度与对齐税）**
在标定分布 `P_A` 上定义：
```
leak(S)  = ∫_{F_S ∪ A_S^?} α_S(a) dP_A(a) / ∫_A α_S(a) dP_A(a)     # 漏放率
cover⁺(S)= ∫_{A_S^+} α_S(a) dP_A(a) / ∫_A α_S(a) dP_A(a)            # 安全可用覆盖率
Align(S) = cover⁺(S) - κ_l·leak(S) - κ_u·P(σ_S = ?)
τ_align(S) = (J_0(S) - J_safe(S)) / J_0(S)                            # J 为任务效用
```
其中 `J_0` 为无安全约束时的效用，`J_safe` 为加壳/加盾后的效用。`τ_align` 即 **对齐税**。

**定义 123（运行时安全盾）**
给定动作轨迹上的 STL/LTL 规范 `φ`（力、速度、距离、禁入区、时序），安全盾为投影算子
```
Sh_φ(π)(·|s) = argmin_{π'} D(π' || π)  s.t.  π' ⊨ φ 且 supp(π') ⊆ A^safe
```
运行期等价于最小干预动作修正：`a*_t = argmin_{a∈A^safe, (a 满足 φ 的下一步)} ||a - a_t||`，若不存在则 `a*_t = a_⊥`。定义 **干预率** `β_sh = P(Sh_φ 修改了原动作)` 与 **盾时延** `τ_sh`。

**定义 124（组合安全闭包与非单调性）**
对技能序列 `S_seq = S_1 ⊗ … ⊗ S_k`，若存在轨迹 `τ ∈ L(S_seq)` 使 `τ ⊭ φ` 或某动作 `a ∈ F_{S_i}`，则称组合存在 **涌现危害**。定义组合安全因子
```
δ_comp(S_seq) = max_{τ ∈ RedTeam(S_seq)}  severity(τ)
```
以及安全可组合关系 `safecomp(S_i,S_j) = 1` 当且仅当
```
(A_i^safe ⊗ A_j^safe) ∩ F = ∅  ∧  L(S_i⊗S_j) ⊨ φ  ∧  δ_comp(S_i,S_j) ≤ Θ_c
```
**命题（安全非单调）**：存在 `S_i,S_j` 使 `safe(S_i)=safe(S_j)=1` 但 `safecomp(S_i,S_j)=0`。故组合安全必须逐边判定，不能由节点安全推出。

**定义 125（安全-鲁棒-动作三重证书）**
```
T = (ρ, A_cert, σ_safe, φ, β_sh, δ_comp, evidence)
```
- `ρ`：第 53 轮鲁棒性谱；
- `A_cert = (A_core, A_buffer, δ_a)`：第 54 轮动作占用证书；
- `σ_safe`：安全壳摘要（`A^safe`、`F`、`?` 的覆盖统计）；
- `φ`：可执行安全规范；
- `β_sh, δ_comp`：干预率与组合安全缺陷；
- `evidence`：至少含 **正例、负例、组合红队反例** 三类证据。
部署判定：`dom(T)=in ∧ ρ(d) ≥ ρ_min ∀d ∧ leak(T) ≤ ε_l ∧ δ_comp(T) ≤ Θ_c ∧ β_sh ≤ β_max ∧ τ_sh ≤ τ_ctrl`。

**定义 126（创新点候选与创新点挖掘算子）**
创新点候选 `c = (g, h, Δ, e)`：`g` 为空白（失败模式/动作空洞/禁止集缺口），`h` 为机制假设，`Δ` 为可测能力增量，`e` 为证据。四个门槛：
```
Novel(c) = 1 - max_{p ∈ Prior} sim(c, p)                 # 新颖性
Verif(c) = P(设计的实验能区分 h 与基线假设)               # 可验证性
Feas(c)  = 1 - Cost(c)/Budget                            # 工程可行性
Gain(c)  = E[Δ metric(c)]                                # 预期增益
Score(c) = w_N·Novel + w_V·Verif + w_F·Feas + w_G·Gain
```
挖掘算子 `M : (failure corpus, Explain, 动作空洞 H₀, 安全禁止集 F) → 2^C`，并强制 **证伪优先**：对每个候选先求 `e† = argmin_{e} P(pass | h 为假 且 e)`，只用能杀死假设的最小实验，通过后才登记为 claim。特别地，把 `F_S` 中「物理上本可做但被禁」的条目单列为 **约束驱动创新源**。

## 2. 关键算法 伪代码

### IP-121 SAS（Safety Action Shell）
```python
def build_safety_shell(skill, A, red_team, oracle, theta_u=0.1):
    sigma = {}
    for a in A:
        label, conf = oracle.label(skill, a)          # +1/0/-1/? ，带置信
        if label is None or conf < theta_u:
            sigma[a] = '?'                            # 默认拒绝
        else:
            sigma[a] = label
    # 红队补标：专挑 ? 与边界动作，优先降低未知区
    for a in red_team.probe(sigma, budget=B_label):
        sigma[a] = oracle.label(skill, a)[0] or '?'
    A_safe = {a for a,v in sigma.items() if v == +1}
    a_bot  = pick_fallback(A_safe, skill)             # 最近安全停机/让位
    return SafetyShell(A_safe, forbidden={a for a,v in sigma.items() if v in (-1,'?')},
                       sigma=sigma, a_bot=a_bot)
```

### IP-122 CSC（Compositional Safety Closure）
```python
def safe_closure(skills, G_action, phi, red_team, Theta_c):
    G_safe = nx.DiGraph()
    for i,j in candidate_pairs(skills, G_action):     # 复用第 54 轮 compat 剪枝
        seq = compose(skills[i], skills[j])
        traces = red_team.search(seq, phi, n= N_rt)   # 交叉动作+对抗扰动
        delta = max([severity(t, phi) for t in traces] or [0.0])
        legal = all(t |= phi for t in traces)
        if legal and delta <= Theta_c:
            G_safe.add_edge(i, j, delta_comp=delta,
                            evidence=CounterexampleSet(traces))
    return G_safe
```

### IP-123 SST（Safety Shield Runtime）
```python
def shielded_step(pi, s, phi, shell, dt, tau_ctrl):
    t0 = now()
    a = pi(s)
    if a in shell.A_safe and satisfies_stl_prefix(phi, s, a):
        return a, False
    a_sh = minimal_projection(a, shell.A_safe, phi, s)   # QP/可达集投影
    if a_sh is None or now()-t0 > tau_ctrl:
        return shell.a_bot, True                         # 兜底，绝不放行
    return a_sh, True
```

### IP-124 STG（Safety Tax Gradient / Pareto）
```python
def alignment_tax_curve(skill, phi_levels, budget):
    pts = []
    for phi in phi_levels:
        shell, shield = compile_safety(skill, phi)
        J_safe = rollout(skill, shell, shield, budget).utility
        J0     = rollout(skill, None, None, budget).utility
        pts.append((phi, 1 - J_safe/J0, shield.beta, shield.tau_p95))
    return pareto_front(pts, maximize=('safety',), minimize=('tax','latency'))
```

### IP-125 IMN（Innovation Miner）
```python
def mine_innovation(failures, explains, holes, F, prior, budget):
    seeds = []
    for f in failures:                      # 失败 → 机制假设
        g = explains[f].root_cause
        seeds.append((g, hypothesize_mechanism(g), expected_delta(g)))
    for h in holes:                         # α=0 动作空洞 → 新原语
        seeds.append((h, 'new_primitive', delta_from_gap(h)))
    for a in F:                             # 禁区 → 约束驱动创新
        seeds.append((a, 'remove_constraint_by_redesign', delta_from_forbidden(a)))
    cands = []
    for g,h,delta in dedup(seeds):
        c = Innovation(g, h, delta, evidence=None)
        c.Novel  = 1 - max_sim(c, prior)                 # 语义+机制双重相似度
        c.Verif  = falsification_power(c)                # 最小杀伤实验的可区分度
        c.Feas   = 1 - estimate_cost(c)/budget
        if score(c) >= theta_cand:
            c.evidence = run_min_kill_experiment(c)      # 先证伪
            if c.evidence.survived:
                cands.append(c)                          # 才允许登记 claim
    return sorted(cands, key=score, reverse=True)
```

### IP-126 ITC（Innovation & Triple Certificate）
```python
def certify_and_claim(skill_seq, phi, gamma_ce, rho_min):
    T = triple_certificate(skill_seq, phi, gamma_ce)     # 定义 125
    if not deployable(T, rho_min): return ('reject', T.failed_clause)

```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SAS | O(\|A\|·(1+B_label)) | O(\|A\|) | 未知区默认拒绝、红队补标收敛 |
| CSC | O(\|E_c\|·N_rt·H) | O(\|E_c\|·N_rt) | 红队覆盖组合危害、δ_comp 上界 sound |
| SST | O(1) 每周期（QP 投影多项式） | O(\|A_local\|) | φ 可执行、投影可行或回退、τ_sh ≤ τ_ctrl |
| STG | O(\|Φ\|·budget) | O(\|Φ\|) | 帕累托非支配、税可复现 |
| IMN | O(\|seeds\|·\|Prior\| + Σ cost(e†)) | O(\|C\|) | 证伪优先、去重、claim 可复现 |
| ITC | O(Σ 上表) | O(\|A\|+\|C\|) | 三重条件合取、证据三类齐全 |

**正确性定理（Safety-Aligned Composition Soundness）**
承接第 53–54 轮 (A22)–(A28)；新增 **(A29)** `σ_S` 在标定域上对真实有害集 **保守超集**（soundness，允许误拒不允许漏放）；**(A30)** 盾在 `τ_ctrl` 内总能把动作投影到 `A^safe∩φ` 或执行 `a_⊥`；**(A31)** 组合红队对涌现危害的覆盖概率 ≥ 1-β_R。则
```
P(部署轨迹无 φ 违规) ≥ 1 - P(σ_S = ? 且未被红队补标) - β_R - P(δ_comp > Θ_c) - P(τ_sh > τ_ctrl)
```
且存在 **对齐税下界**：若 `A_full \ A^safe ≠ ∅` 且该集合对任务效用有正贡献，则 `τ_align > 0`（无免费安全）。工程含义：不要承诺「零税」，而应提交 **帕累托曲线 + 可审计证书**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 安全规范被 specification gaming（只满足字面 φ） | 高 | φ 多层级 + 组合红队 + 人工审计锚点 |
| 安全壳标定盲区导致「对齐假象」 | 高 | 默认拒绝 + 主动红队补标 + 不确定度上报 |
| 安全盾过度保守、对齐税爆炸 | 高 | 最小干预投影 + 帕累托选择 + 任务级降级策略 |
| 组合红队覆盖不足、涌现危害漏检 | 高 | 技能对交叉采样 + 对抗扰动 + 覆盖证书 |
| 创新点挖掘奖励新颖而非真实（伪创新） | 高 | 证伪优先 + 外部 prior 去重 + claim 复现登记 |
| 云边盾时延超控制周期 | 中 | 边端轻量盾 + 云端预编译策略 + 回退动作 |

## 6. 本轮最大风险

**一句话**：把安全对齐落到「动作壳 + 运行时盾 + 组合闭包」后，最大的风险不是算力而是 **规范与现实的错位**——`σ_S` 与 `φ` 都只是真实危害的有限近似，一旦标定盲区、φ 可被字面满足（specification gaming）、或组合红队覆盖不足，系统就会稳定地输出「证书齐全却仍然伤人」的安全假象；而创新点挖掘若以新颖性为主奖励，还会批量生产无法复现的伪创新，因此必须以 **默认拒绝 + 组合红队 + 证伪优先** 作为不可协商的三重底线。

## 2. 关键算法 伪代码

### IP-121 SAS
```python
def build_safety_shell(skill, A, red_team, oracle, theta_u=0.1):
    sigma = {}
    for a in A:
        label, conf = oracle.label(skill, a)
        sigma[a] = label if (label is not None and conf >= theta_u) else '?'  # 默认拒绝
    for a in red_team.probe(sigma, budget=B_label):        # 专攻 ? 与边界
        label, conf = oracle.label(skill, a)
        if label is not None and conf >= theta_u: sigma[a] = label
    A_safe = {a for a,v in sigma.items() if v == +1}
    return SafetyShell(A_safe,
                       forbidden={a for a,v in sigma.items() if v in (-1,'?')},
                       sigma=sigma, a_bot=pick_fallback(A_safe, skill))
```

### IP-122 CSC
```python
def safe_closure(skills, G_action, phi, red_team, Theta_c, N_rt):
    G_safe = nx.DiGraph()
    for i, j in candidate_pairs(skills, G_action):         # 复用 compat 剪枝
        seq = compose(skills[i], skills[j])
        traces = red_team.search(seq, phi, n=N_rt)         # 交叉动作 + 对抗扰动
        delta  = max([severity(t, phi) for t in traces] or [0.0])
        if all(t |= phi for t in traces) and delta <= Theta_c:
            G_safe.add_edge(i, j, delta_comp=delta,
                            evidence=CounterexampleSet(traces))
    return G_safe
```

### IP-123 SST
```python
def shielded_step(pi, s, phi, shell, tau_ctrl):
    t0 = now()
    a = pi(s)
    if a in shell.A_safe and satisfies_stl_prefix(phi, s, a):
        return a, False
    a_sh = minimal_projection(a, shell.A_safe, phi, s)     # QP / 可达集投影
    if a_sh is None or now() - t0 > tau_ctrl:
        return shell.a_bot, True                           # 绝不兜底放行
    return a_sh, True
```

### IP-124 STG
```python
def alignment_tax_curve(skill, phi_levels, budget):
    pts = []
    for phi in phi_levels:
        shell, shield = compile_safety(skill, phi)
        J_safe = rollout(skill, shell, shield, budget).utility
        J0     = rollout(skill, None, None, budget).utility
        pts.append(dict(phi=phi, tax=1-J_safe/J0,
                        beta=shield.beta, tau_p95=shield.tau_p95,
                        safety=safety_margin(phi)))
    return pareto_front(pts, minimize=('tax','tau_p95'), maximize=('safety',))
```

### IP-125 IMN
```python
def mine_innovation(failures, explains, holes, F, prior, budget, theta_cand):
    seeds = [(explains[f].root_cause, hypothesize_mechanism(explains[f].root_cause),
              expected_delta(explains[f])) for f in failures]              # 失败源
    seeds += [(h, 'new_primitive', delta_from_gap(h)) for h in holes]      # α=0 空洞
    seeds += [(a, 'redesign_to_remove_forbidden', delta_from_forbidden(a)) for a in F]
    out = []
    for g, h, delta in dedup(seeds):
        c = Innovation(g, h, delta)
        c.Novel = 1 - max_sim(c, prior)                # 语义 + 机制双重相似
        c.Verif = falsification_power(c)               # 最小杀伤实验区分度
        c.Feas  = 1 - estimate_cost(c)/budget
        c.Gain  = delta
        if score(c) >= theta_cand:
            c.evidence = run_min_kill_experiment(c)    # 证伪优先
            if c.evidence.survived: out.append(c)      # 存活才登记
    return sorted(out, key=score, reverse=True)
```

```python
def certify_and_claim(skill_seq, phi, gamma_ce, rho_min):
    T = triple_certificate(skill_seq, phi, gamma_ce)
    if not deployable(T, rho_min):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SAS | O(\|A\|·(1+B_label)) | O(\|A\|) | 未知默认拒绝；红队补标单调收缩未知区 |
| CSC | O(\|E_c\|·N_rt·H) | O(\|E_c\|·N_rt) | 组合危害覆盖 ≥ 1-β_R；δ_comp 保守 |
| SST | O(poly) 每周期 | O(\|A_local\|) | 每周期满足 φ 或回退，违规硬为 0 |
| STG | O(\|Φ\|·budget) | O(\|Φ\|) | 帕累托非支配、税可复现 |
| IMN | O(\|seeds\|·\|Prior\| + Σcost(e†)) | O(\|C\|) | 证伪优先、去重、claim 可复现 |
| ITC | O(Σ) | O(\|A\|+\|C\|) | 三重合取、证据含正/负/红队三类 |

**正确性定理（Safety-Aligned Composition Soundness）**
承接 (A22)–(A28)；定义 **(A29)** `σ_S` 为真实有害集的保守超集（soundness：可误拒、不可漏放）；**(A30)** 盾在 `τ_ctrl` 内可投影到 `A^safe∩φ` 或执行 `a_⊥`；**(A31)** 组合红队覆盖 ≥ 1-β_R。则
```
P(部署轨迹无 φ 违规) ≥ 1 - P(σ_S=? 且未补标) - β_R - P(δ_comp>Θ_c) - P(τ_sh>τ_ctrl)
```
**对齐税下界命题**：若 `A_full \ A^safe ≠ ∅` 且该集合对任务效用正贡献，则 `τ_align > 0`；因此对外承诺应是 **帕累托曲线**，不是「零税零风险」。

## 7. 本轮最大风险

**一句话**：安全壳与安全规范都只是真实危害的有限近似，最大的风险是 **规范与现实的错位**——标定盲区、φ 被字面满足（specification gaming）、组合红队覆盖不足，会让系统稳定输出「证书齐全却仍然伤人」的安全假象；叠加创新点挖掘以新颖性为主奖励，还会批量生产不可复现的伪创新，故必须以 **默认拒绝 + 组合红队 + 证伪优先** 为不可协商的三重底线。
