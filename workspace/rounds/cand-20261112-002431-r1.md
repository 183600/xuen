# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「能耗优化」×「数据集构建」）

> 第 54 轮把技能从“能力黑箱”推进为动作空间剖面 `α_S` + 动作-鲁棒性联合证书 `J`，并建立了云边协同闭环。本轮把两个长期被当作“外部成本”的量拉进第一性约束：**能耗**与**数据**。核心矛盾：H22：能耗在动作空间上非均匀、非可加（转换区与热节流贡献显著），而现有 `A_cert/ρ` 证书不携带能耗，导致“最稳/最覆盖”的组合往往最费电，能耗预算在部署时被动超支；H23：`α_S` 与 `ρ` 的校准依赖数据集，但数据集构建本身消耗能耗与时间，且覆盖不足会制造“鲁棒性-覆盖假象”——证书在未采样动作上系统性失效。

## 0. 直觉与动机

**灵感 1（能耗剖面化 → 能耗不是标量，而是动作空间上的密度场）**
直觉：把能耗从“一次执行的总焦耳数”升级为动作空间上的密度 `e_S : A → ℝ≥0`，单位动作的瞬时功率积分。技能 S 在任务动作序列 `A_T` 上的能耗是路径积分 `E_S(A_T)=∫_{A_T} e_S(a) dμ(a)`。这样，“省电”不再是选一个低功耗技能，而是**在动作空间里选一条低能耗路径**；与第 54 轮的 `α_S` 共用同一坐标系，能耗与覆盖/鲁棒性第一次可逐点对齐。

**灵感 2（能耗非可加 → 组合能耗含转换项与热节流项）**
直觉：两个技能单独能耗相加并不等于组合能耗。动作切换存在**转换走廊能耗** `E_trans`，连续高负载存在**热节流惩罚** `E_thermal`（功率-温度-降频的非线性回馈）。因此组合能耗写成 `E_{S_i⊗S_j}=E_{S_i}+E_{S_j}+E_trans(S_i,S_j)+E_thermal(S_i,S_j)`。这把第 54 轮 `compat/c_trans/ρ` 的边权扩展为四元约束，组合规划从“满足鲁棒性”变为**资源受限最短路**（能耗是第二维资源）。

**灵感 3（数据集作为证书的底座 → 覆盖度是可判定的先验）**
直觉：`α_S`、`e_S`、`ρ` 都不是先验真理，而是由数据集 `D` 支撑的后验估计。数据集应升格为**证书对象** `D_cert=(cov, prov_hash, conf)`：`cov` 为动作空间覆盖度，`prov` 为采样来源与不可篡改哈希，`conf` 为覆盖下界置信度。任何联合证书都必须声明“我的结论只在 `cov` 覆盖的区域内 sound”。这把“数据够不够”从经验判断变成**可拒绝部署的硬门槛**。

**灵感 4（能耗感知的主动数据构建 → 每焦耳信息增益最大化）**
直觉：采样要耗能，因此数据构建本身是一个**能耗预算下的实验设计问题**。目标不是均匀铺满动作空间，而是最大化“每焦耳的信息增益” `η(D)=IG(D)/E(D)`：优先采那些能最大幅度降低 `α/e/ρ` 后验方差、且采集成本低的动作。信息增益对动作子集近似子模，于是可用贪心 `(1-1/e)` 近似。这直接回应“能耗优化”与“数据集构建”的耦合：**用最少的电，买到最可信的证书**。

**灵感 5（三目标 Pareto 与金字塔扩展）**
直觉：部署不再是单目标“最鲁棒”，而是 `(鲁棒性 ρ_min ↑, 覆盖 cov ↑, 能耗 E ↓)` 的三目标权衡。在第 54 轮动作-协同层 `𝔸` 之上叠加 **能耗-数据层 `𝔼`**：`𝔼_0` 物理功率极限，`𝔼_1` 技能能耗剖面，`𝔼_2` 组合能耗与热节流，`𝔼_3` 数据集能耗预算与覆盖。跨层证书同时携带 `ρ, A_cert, E_cert, D_cert`，形成**四证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（能耗密度剖面）**
技能 `S` 的能耗密度 `e_S : A → ℝ≥0`，满足对任意可测动作子集 `U⊆A`，`E_S(U)=∫_U e_S(a) dμ(a)`。任务动作序列 `A_T` 的能耗 `E_S(A_T)` 为上述积分。采样能耗单独记为 `E_data(D)`，**必须计入总预算**（无免费数据假设）。

**定义 122（能耗感知组合与可行性）**
组合能耗
```
E_{S_i⊗S_j} = E_{S_i} + E_{S_j} + E_trans(S_i,S_j) + E_thermal(S_i,S_j)
```
其中 `E_trans` 为转换走廊积分，`E_thermal` 为热节流惩罚。组合可判定条件在第 54 轮定义 116 上追加能耗约束：
```
compat(S_i,S_j) ≥ θ_a ∧ c_trans ≤ τ_e ∧ ρ_{S_i⊗S_j}(d) ≥ ρ_min ∀d ∧ E_{S_i⊗S_j} + E_data ≤ E_budget
```

**定义 123（证书数据集）**
证书数据集 `D = {(a_i, α_i, e_i, ρ_i, y_i, prov_i)}_{i=1}^N`，`prov_i` 为来源、时间戳与哈希。动作空间覆盖度
```
cov(D) = μ( ⋃_{i=1}^N B(a_i, r) ) / μ(A)
```
其中 `B(a_i,r)` 为动作空间中半径 `r` 的覆盖球。

**定义 124（覆盖-能耗效率与信息增益）**
`η(D) = IG(D) / E_data(D)`，`IG(D)` 为数据集对 `α/e/ρ` 后验方差的下降量（互信息近似）。`IG` 对 `D` 近似子模且单调，`E_data` 可加，故 `η` 的预算化最大化可用贪心近似。

**定义 125（能耗-数据联合证书）**
```
ED = (ρ, A_cert, E_cert, D_cert, γ_ce, δ_a)
```
- `E_cert = (E_core, E_margin, thermal_budget)`：核心能耗、容错余量、热预算；
- `D_cert = (cov, cov_lb, prov_hash, uncovered)`：覆盖度、置信下界、来源哈希、未覆盖区；
- 其余继承第 54 轮定义 120。**部署必要条件**：`dom_ED(T)=in ∧ δ_a<Θ_a ∧ cov_lb ≥ θ_cov ∧ E_core+E_margin ≤ E_budget`。

**定义 126（三目标部署前沿）**
可行部署解集按 `(ρ_min, cov, -E)` 定义 Pareto 前沿 `𝒫`。任务 T 可部署当且仅当存在解 `x∈𝒫` 满足全部预算约束；规划目标从“最大化 ρ”改为“在 `𝒫` 上按任务偏好选择 knee point”。

## 2. 关键算法 伪代码

### IP-121 EPC（Energy Profile Characterization）

```python
def energy_profile(skill, A_c, A_e, power_sampler, sample_budget):
    e = {}
    for a in sample_actions(A_c, A_e, sample_budget):
        p_t = power_sampler.measure(skill, a)
        e[a] = integrate_power(p_t, duration(a))
    # 对负载/速度维施加单调约束，避免外推出现负能耗
    gp = fit_gp(e, monotone_dims=('load', 'speed'), noise=power_sampler.noise)
    return EnergyProfile(gp, total_cost=power_sampler.energy_spent)
```

### IP-122 EAC（Energy-Aware Composition）

```python
def energy_aware_plan(G, T, E_budget, rho_min, theta_a):
    # 资源受限最短路（RCSP）：能耗作为第二维资源
    labels = rcsp_labels(G, source='root', target=T,
                         resource=lambda e: e.energy, cap=E_budget)
    feasible = [p for p in labels
                if p.rho_min >= rho_min and p.compat >= theta_a
                and p.energy + E_data_est <= E_budget]
    if not feasible:
        return None
    return min(feasible, key=lambda p: p.cost_align + lam * p.energy)
```

### IP-123 EADC（Energy-Aware Dataset Construction）

```python
def build_dataset_budgeted(skills, A, E_budget, r, beta=1.0):
    D, spent = [], 0.0
    while spent < E_budget:
        cand = max(A - covered(A, D, r),
                   key=lambda a: (coverage_gain(D, a, r)
                                  + beta * info_gain(D, a)) / energy_cost(a))
        y = run_structured_sim_or_real(skills, cand)
        cost = energy_cost(cand)
        if spent + cost > E_budget:
            break
        D.append(Sample(cand, y, prov=provenance_hash(cand, y)))
        spent += cost
        update_posterior(D, y)
    return D, spent
```

### IP-124 DCC（Dataset Coverage Certificate）

```python
def coverage_certificate(D, A, r, conf=0.95):
    covered = union_of_balls([s.a for s in D], r)
    cov = mu(covered) / mu(A)
    # DKW / bootstrap 给出覆盖度置信下界
    cov_lb = lower_confidence_bound(cov, n=len(D), conf=conf)
    return DatasetCert(cov=cov, cov_lb=cov_lb,
                       prov_hash=merkle_hash([s.prov for s in D]),
                       uncovered=A - covered)
```

### IP-125 EJC（Energy-Joint Certificate）

```python
def energy_data_joint_cert(skill_seq, D_cert, E_budget, gamma_ce, budgets):
    if D_cert.cov_lb < budgets.theta_cov:
        return ('reject', 'dataset_coverage', D_cert.uncovered)
    E_comp = compose_energy(skill_seq, transition_model, thermal_model)
    if E_comp.total + E_data_est > E_budget:
        return ('reject', 'energy_budget', E_comp)
    if E_comp.thermal_peak > budgets.thermal_budget:
        return ('reject', 'thermal_peak', E_comp.thermal_peak)
    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    if delta_a > budgets.delta_a:
        return ('reject', 'action_mismatch', delta_a)
    rho = compose_robustness_chain([s.rho for s in skill_seq], K)
    return ('ok', EnergyDataCert(rho, A_cert(A_core), E_comp, D_cert, gamma_ce, delta_a))
```

### IP-126 PTF（Pareto Tri-Front）

```python
def pareto_tri_front(candidates):
    # 非支配排序：最大化 rho/cov，最小化 E
    front = []
    for c in candidates:
        dominated = any((d.rho >= c.rho and d.cov >= c.cov and d.E <= c.E)
                        and (d.rho > c.rho or d.cov > c.cov or d.E < c.E)
                        for d in candidates)
        if not dominated:
            front.append(c)
    return knee_point(front)  # 按任务偏好返回折中解
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EPC | O(|A_sample|·T_power + n³) | O(|A_sample|) | 功率积分一致、GP 单调外推 |
| EAC | O((|V| log|V| + |E|)·B_E) | O(|V|·B_E) | RCSP 标签支配正确、能耗可加近似误差有界 |
| EADC | O(k·|A|·cost_IG) | O(|D|) | 子模贪心 (1-1/e) 近似、采样能耗入账 |
| DCC | O(|D|·|A|) | O(|A|) | 覆盖球并集精确、置信下界 sound |
| EJC | O(|S|·|A| + |𝔇_ρ|) | O(|A|) | 预算闭合、四证书联合 sound |
| PTF | O(n²·|𝒫|) | O(n·|𝒫|) | 非支配排序完备、knee 选择可解释 |

**正确性定理（Energy-Data-Aware Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `e_S` 在 `D` 上校准误差 `MAPE ≤ ε_e`；**(A30)** `D_cert.cov_lb` 以置信度 `1-δ` 成立；**(A31)** 能耗非可加项满足 `|E_thermal+E_trans - E_model| ≤ β_E`；**(A32)** 数据采样能耗 `E_data` 全额计入预算。则对任意满足定义 125 的部署解：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - (1-cov_lb) - P(E_core+E_margin > E_budget)
```
关键：**覆盖是 soundness 的前置条件**，**能耗预算必须含数据成本**，**热节流误差有界**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 能耗剖面在热节流区外推失真 | 高 | 分段 GP + 温度分层采样 + 峰值实测校验 |
| 数据覆盖度置信下界过保守，导致无法部署 | 中 | 分层覆盖证书 + 主动补采 + 覆盖球半径自适应 |
| 主动采样被“便宜区域”吸引，形成自证循环 | 高 | 对抗性能耗探针 + 强制未覆盖区配额 + 留出集 |
| RCSP 状态空间爆炸 | 中 | 标签支配剪枝 + 能耗离散化 + A* 上界 |
| 三目标 Pareto 前沿不可解释 | 中 | knee point + 证书证据链 + 决策日志 |

## 6. 本轮最大风险

**一句话**：能耗剖面与证书数据集把组合从“动作-鲁棒性双证书”升级为“能耗-覆盖-鲁棒性三目标四证书”，但其 soundness **双重依赖能耗剖面的热区外推精度与数据集覆盖的置信下界**；一旦主动采样被低能耗区域吸引、形成“哪里便宜采哪里、哪里采了哪里就 sound”的自证循环，`cov_lb` 会在真实高负载动作上系统性高估，导致组合在热节流极限处能耗爆表或动作错位——故必须以 **对抗性能耗探针 + 未覆盖区强制配额 + 数据成本全额入账** 三重护栏，宁可少部署，绝不把“省电的采样”误当成“可信的覆盖”。

```python
    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    if delta_a > budgets.delta_a:
        return ('reject', 'action_mismatch', delta_a)
    rho = compose_robustness_chain([s.rho for s in skill_seq], K)
    return ('ok', EnergyDataCert(rho, A_cert(A_core), E_comp, D_cert, gamma_ce, delta_a))
```

## 5. 本轮最大风险

**一句话**：能耗剖面与证书数据集把组合升级为“能耗-覆盖-鲁棒性三目标四证书”，但其 soundness **双重依赖能耗剖面的热区外推精度与数据集覆盖的置信下界**；一旦主动采样被低能耗区域吸引、形成“哪里便宜采哪里、哪里采了哪里就 sound”的自证循环，`cov_lb` 会在真实高负载动作上系统性高估，导致组合在热节流极限处能耗爆表或动作错位——故必须以 **对抗性能耗探针 + 未覆盖区强制配额 + 数据成本全额入账** 三重护栏，宁可少部署，绝不把“省电的采样”误当成“可信的覆盖”。
