### 第 6 轮灵感驱动研究记录

**灵感词**：可扩展性、常识推理

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把框架从「规则系统」推广为「认证的生成式执行」（CGE）：流匹配提议器 FMPP、嵌入记忆与固化 LMEM-v2、面部情感调制 FAMK；七硬门与执行集嵌套 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29 保持不变。v5 明确把「舰队联邦、跨站价值/情绪异构、实机验证」留给第 6 轮。本轮灵感词「可扩展性」「常识推理」正命中 v5 两笔未偿还负债：(a) 认证成本随站点/物体/领域线性膨胀，每换一站就要人重新标定 Φ_global、阈值与证书；(b) 提议与门只有几何/物理/统计语义，读不懂「递刀时刃朝外」「闭口瓶不能倒」这类常识。二者统一为主题「可认证的语义可扩展」（Certified Semantic Scaling, CSS），形成 CADVS-v6（IP-497~500）。本轮自律：**仍不增硬门**（七门不变，延续 R52 负债控制），常识只走「保守收紧 + 提议条件」两条不进信任边界的通道；可扩展性走「证书代数 + 认证传输」而非「再训一个大模型」。执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ …。

**直觉与动机**：

1. **可扩展性 → 瓶颈不是算力而是「认证劳动」，把证书做成可组合、可传输的对象**。v5 的流提议能在一个域内泛化，但每新增站点仍要人重标定、每新增物体仍要教师示范；随规模爆炸的是**每个 (站点, 领域, 物体) 三元组的重新认证成本**，不是推理成本。类比硬件形式验证：不重证整块芯片，而靠 assume-guarantee 组合与抽象精化。于是引入**证书代数 SCAK**：证书 κ=(P,R,m) 为（安全谓词, 有效域, 认证边际）；组合 κ_A⊗κ_B=(P_A∧P_B, R_A∩R_B, min(m_A,m_B))；**认证传输**沿域同态 f=(f_x,f_c) 进行——若 f 对各门评分函数的失真 τ_i 有**可证上界**且源证书边际 m_i>τ_i，则证书搬到目标域、边际降为 m_i−τ_i，否则弃权。**定理 9（传输可靠性）**：可证失真 + 边际严格大于失真 ⇒ 传输后门仍成立；成本从「每轨迹重证」降为「每域对证一次失真」。这把 v5 的「同门」升级为「可跨域组合的同一门」。

2. **常识推理 → 常识不完备且不可靠，绝不能进信任边界，只能当「只会收紧的语义先验」**。v5 定理 6 已说明：提议可任意换，执行边界只由门定义。常识最安全的用法不是新增「常识门」（那会立刻制造不可验证的信任根），而是把常识编译成对**已有门**的收紧。引入**语义先验核 SPK**：基础模型/知识图谱在受限**类型化语义 DSL** 上产出约束（Support / Containment / Occlusion / Fragility / ToolAffordance / Proxemics…），再由**保守接地函子 Γ** 映到七门阈值增量 δτ_i≥0、提议支撑限制 S⊆supp(π)、语义置信 η_sem。**定理 10（接地安全单调）**：只要 Γ 每条规则满足 δτ_i≥0 且 S 只缩，任意常识输出（含错误）都满足 Exec_v6⊆Exec_v5；常识犯错只可能**误拒（可用性损失）**，绝不可能**误放（安全性损失）**；低置信/超语法/与已证事实矛盾时 Γ 弃权（恒等），精确退化 v5。诚实边界：这条性质是「不放大信任面」，代价是常识**无法覆盖门评分函数里根本不存在的危险维度**——它提升已知危险轴上的精度，不提升覆盖。

3. **可扩展性 × 常识 → 语义也要能传输，否则每个新物体都要重问一次常识**。若常识接地只在单物体成立，规模一大就退化为 O(物体数) 次昂贵基础模型调用与人工复核。引入**语义传输与概念格 STCL**：以本体子sumption 加校准嵌入邻域定义概念距离 d(C',C)；在概念 C 上认证的约束沿 C'⊑C 传输并加**单调缓冲 b(d)**（d 越大越保守）。**定理 11（带校准缓冲的语义传输）**：若缓冲在概念邻域内以概率 ≥1−δ 支配真实所需收紧量，则传输后仍保守；成本从每物体一次降为每概念一次 + O(1) 查表。常识随概念格而非物体数扩展。

4. **舰队总装 → 全局安全 = 各站传输后局部执行集的交，规模只缩不放**。**定理 12（assume-guarantee 舰队组合）**：以接口契约 A_i/G_i 分解非干涉，全局执行集 ⊆ ∩_i Transport_i(Exec_local_i)；认证成本 O(N·|contract| + E·|interface|) 而非 O(N²)；新增站点在保守传输下只能使全局安全集单调缩小。这把 v5 单机 CGE 推广为可扩展联邦 CGE。

**关键洞见**：v4 问「提议=规则时七门是否足够」；v5 问「提议=任意生成器时证书边界能否不动」；v6 问「当认证要跨站点/物体规模化、且语义先验不完备时，如何让规模只放大覆盖而不放大信任面」。答案不是更强模型，而是把**认证本身做成可组合、可传输的代数对象**，把**语义做成执行集上的保守收缩函子**（只缩不扩），并用**概念格 + 校准缓冲**让语义随概念而非物体扩展。规模放大的必须是「复用」，不能是「信任假设」。

**形式化目标（增量）**：
1. 证书代数：κ=(P,R,m)；κ_A⊗κ_B=(P_A∧P_B, R_A∩R_B, min(m_A,m_B))；传输 Transport_{f,τ}(κ)。
2. 失真界：域同态 f=(f_x,f_c)，τ_i=sup_x|s_i(f_x(x),f_c(c))−s_i(x,c)|，要求可证（区间/Lipschitz），禁止用学习估计冒充。
3. 语义 DSL：类型集 T 与类型化约束 g=(type,args,pol,conf)；接地函子 Γ(g,c)→(δτ∈R_{≥0}^7, S⊆supp(π), η_sem)。
4. 定理 9（传输可靠性）、定理 10（接地安全单调）、定理 11（语义传输保守）、定理 12（舰队 assume-guarantee）。
5. EFA-v6 总装：七门不变，τ_i^6=τ_i^5+δτ_i；候选先过语义支撑 S；ECS_v6=ECS_v5·η_sem。
6. Exec_CADVS-v6={x∈S∩supp(π_FM): ∧_i kc_i(x,c; τ_i^5+δτ_i)=1} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**传输/接地层成为「静默的可靠性单点」**——失真界 τ 与语义接地的保守性都是（半）学习/统计得来的经验断言而非机械可验证定理，一旦某个 τ 被低估或某条 DSL 接地规则悄悄放松，错误证书会沿传输与概念格在整支舰队里复制放大，而系统表面上仍「全部通过」，形成规模放大的静默不可靠。

### IP-497 SCAK：证书代数与认证传输核（离线/慢时域）

```python
@dataclass
class ScalableCertificateAlgebraKernel:
    """SCAK：证书组合 + 认证传输 + 舰队契约。
    红线：仅当失真 τ 可证且边际严格大于 τ 才传输，否则弃权；绝不外推"""
    contracts: dict[str, Contract]
    dist_bounds: dict[tuple[str, str], DistortionBound]   # 区间/Lipschitz，可证

    def compose(self, a: Cert, b: Cert) -> Cert:
        # 谓词合取、域交、边际取 min：组合后只会更难通过
        return Cert(P=a.P and b.P, R=a.R & b.R, m=min(a.m, b.m))

    def transport(self, kappa: Cert, src: str, dst: str) -> Cert | None:
        bound = self.dist_bounds[(src, dst)]        # τ_i 可证上界
        m_new = kappa.m - bound.tau
        if m_new <= 0:
            return None                              # 弃权：不可传输，绝不外推
        return Cert(P=kappa.P, R=pullback(kappa.R, bound.f), m=m_new)

    def global_exec(self, locals_: dict[str, ExecSet]) -> ExecSet:
        out = universe
        for site, ex in locals_.items():
            tr = self.transport_exec(ex, src=site, dst='global')
            # 不可传输的站点回退其保守包络，仍只缩不放
            out = out & (tr if tr is not None else conservative_envelope(ex))
        return out                                   # ⊆ 各站局部安全集
```

### IP-498 SPK：语义先验核（离线/异步；与控制环解耦）

```python
@dataclass
class SemanticPriorKernel:
    """SPK：常识只在信任边界外。接地只允许收紧（δτ≥0, S 只缩）。
    定理 10：常识错误 → 只会误拒，绝不误放"""
    model: Any                    # 基础模型/知识图谱（离线/异步，可换可关）
    dsl: SemanticDSL              # 类型化受限语法，拒绝自由文本
    c_min: float = 0.6            # 接地置信下限，低于则弃权
    delta_tau_max: float = 0.15   # 单约束收紧上限，防执行集塌缩

    def parse(self, context, x) -> list[Constraint]:
        raw = self.model.propose_constraints(context, x)   # 仅 DSL 内类型
        return [g for g in self.dsl.typecheck(raw) if g.conf >= self.c_min]

    def ground(self, g: Constraint, c: Context) -> Grounding:
        """Γ：类型化约束 → 现有七门的阈值增量/支撑限制。
        未覆盖、超语法、或与已证事实矛盾 → 恒等（弃权，精确退化 v5）"""
        rule = self.dsl.grounding_rules.get(g.type)
        if rule is None or self._contradicts_certified(g, c):
            return Grounding(delta_tau=zeros(7), S=supp_all(), eta_sem=1.0)
        dt = rule.to_delta_tau(g.args, c)          # 构造上保证 ≥ 0
        assert (dt >= 0).all()                      # 运行时机械断言
        return Grounding(delta_tau=clip(dt, 0, self.delta_tau_max),
                         S=rule.support_restriction(g.args, c),   # ⊆ supp
                         eta_sem=g.conf)

    def combine(self, gs: list[Grounding]) -> Grounding:
        """多条约束取收紧格上确界：δτ 逐点 max、S 取交、η 取 min。
        冲突时偏保守（宁可误拒），永不放松任何一门"""
```

### IP-499 STCL：语义传输与概念格（离线索引，在线 O(log|C|)）

```python
@dataclass
class SemanticTransferConceptLattice:
    """STCL：概念格 + 校准邻域传输。
    定理 11：缓冲 b(d) 以概率 ≥1−δ 支配真实收紧量时，传输保守"""
    ontology: Any                  # 子sumption 图
    emb: Any                       # 概念/物体嵌入（温度校准）
    buffer: Callable[[float], float] = lambda d: b0 + b1 * d

    def lookup(self, obj) -> Concept:
        return self.ontology.nearest(self.emb(obj))    # O(log|C|)

    def transfer(self, g: GroundedConstraint, src: Concept, obj) -> Grounding:
        c = self.lookup(obj)
        if not (c <= src):                             # 不在已证概念邻域
            return abstain()                           # 弃权，退回逐物体接地
        d = self.concept_distance(c, src)
        return tighten(g, by=self.buffer(d))           # 只加缓冲，不放松

    def audit(self, heldout) -> float:
        """校准审计：估计缓冲违约率；违约率 > δ 则整体禁用传输（fail-closed）"""
```

### IP-500 EFA-v6：七硬门 + 语义收紧 + 传输契约

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变（阈值 τ^6=τ^5+δτ，只增）+ 语义支撑限制 + 传输证书"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    scak: ScalableCertificateAlgebraKernel
    spk: SemanticPriorKernel
    stcl: SemanticTransferConceptLattice
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context):
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)                       # 全 1.0 = 退 v4 静态
        gs = self.spk.parse(context, preview_state(context))
        gnd = self.spk.combine([self.stcl.transfer(g, g.src, context.obj)
                                for g in gs])
        tau6 = clip(gamma * TAU5 + gnd.delta_tau, TAU5, TAU_CAP)   # 只增不减
        c = build_ctx(context, s_emo, self.lmem, gnd)        # 含语义 token σ_sem
        cands = [x for x in self.fmpp.propose(c, self.fmpp.K) if x in gnd.S]
        # 级联同 v5：廉价门 → VACK（调制 τ_val^6）→ BCK 预览
        ok = self.v5._cascade(cands, tau6, s_emo, context)
        if not ok:
            return self.v5._fallback_rule_proposal(gamma)    # fail-closed 回退
        best = max(ok, key=certified_margin)
        cert = self.scak.compose(*[g.cert for g in ok])      # 组合证书
        return True, best, 'FORGED_CSS', cert

    def ecs_v6(self, ..., n_flow: float, s_emo, eta_sem: float) -> float:
        return self.v5.ecs_v5(..., n_flow, s_emo) * eta_sem
```

### 集成流水线（v5 → v6）

```
离线/慢时域：
  证书代数编译：每 (域对) 证失真上界 τ（区间/Lipschitz）──▶ SCAK.dist_bounds
  语义编译：基础模型 ──▶ DSL 约束 ──▶ 人工复核 ──▶ Γ 规则库（版本化，CI 断言 δτ≥0）
  概念格构建：本体 + 校准嵌入 + 缓冲 b(d) 拟合 ──▶ STCL
  校准审计：heldout 缓冲违约率 ≤ δ，否则禁用传输（fail-closed）
  固化/联邦：同 v5（只改提议器；门、τ^4、δτ 均冻结只读）

在线准入（异步，秒级）：
  FAMK.observe ──▶ γ
  SPK.parse ──▶ STCL.transfer ──▶ SPK.combine ──▶ (δτ, S, η_sem)
  τ^6 = γ·τ^4 + δτ（逐门 clip，只增）
  FMPP.propose（支撑 ∩ S）──▶ 廉价门 ──▶ VACK ──▶ BCK 预览 ──▶ 边际最大者 + 组合证书

在线控制环（目标维持 < 0.6 ms）：
  只消费预计算 τ^6 与缓存证书；语义/传输/舰队组合全在慢时域，控制环零新增
```

## 4. 正确性论证（增量更新）

### 引理 45（传输边际代数）

**陈述**：若 κ_A 在 f 下失真 ≤ τ_i 且 m_i>τ_i，则对任意 x∈R_B，s_i(x) ≥ s_i(f(x))−τ_i ≥ τ_i^5 + (m_i−τ_i)。组合 ⊗ 的域交与边际 min 满足结合律、交换律，构成交换半群。∎

### 引理 46（收紧格）

**陈述**：δτ 逐点 max、S 取交、η 取 min 构成有界 join-半格；其上确界对应执行集之交；⊤（δτ→cap）可使执行集为空（可用性归零但安全）。任何合成都不会降低 δτ 或扩大 S。∎

### 定理 9（证书传输可靠性）

**陈述**：设失真界 τ 可证（区间/Lipschitz，非学习估计），κ_A 在 A 上成立且 m>τ，则 Transport_{f,τ}(κ_A) 在 B 上成立；且 Exec_B ⊆ f^{-1}(Exec_A)（在失真容差内）。**证明**：引理 45 + 评分函数连续性。∎ **诚实边界**：τ 被低估则传输不成立——τ 的可证性是本定理唯一信任根。

### 定理 10（语义接地的安全单调性）

**陈述**：若 Γ 每条规则满足 δτ_i≥0 且 S⊆supp(π)，则对任意常识输出（含错误输出）Exec_v6⊆Exec_v5；弃权（Γ=恒等）时 Exec_v6=Exec_v5；故常识错误只造成误拒，不造成误放。**证明**：阈值单调升 ⇒ 各门通过集缩；S 只缩 ⇒ 支撑缩；交集缩。∎ **诚实边界**：不覆盖门评分函数 span 之外的语义危险（开放世界盲区）。

### 定理 11（带校准缓冲的语义传输）

**陈述**：若在概念邻域 {o': d(C',C)≤d} 内，真实所需收紧量 ≤ 基准 + b(d) 以概率 ≥1−δ 成立，则 STCL.transfer 的约束以概率 ≥1−δ 保守；期望接地成本从 O(物体数) 降为 O(概念数)+O(1) 查表。**证明**：缓冲支配 + 定理 10。∎ **诚实边界**：δ 由校准审计给出；跨域漂移会使 δ 失效，需重审计。

### 定理 12（舰队 assume-guarantee 组合）

**陈述**：若每站契约 Contract_i 的保证 G_i 在其假设 A_i 下成立，且接口图无未良基循环假设，则 Exec_fleet=∩_i Transport_i(Exec_local_i) ⊆ 全局安全集；认证成本 O(N·|contract|+E·|interface|)；新增站点在保守传输下使 Exec_fleet 单调不增。**证明**：组合推理 + 定理 9 + 交集单调。∎

### 定理 v6（总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 失真界可证、(B9) Γ 保守、(B10) 缓冲校准有效下：(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；(ii) 传输/语义/舰队组合均只缩；(iii) 常识与情感都只收紧，弃权精确退化；(iv) v5 全部定理保持。**证明**：定理 5~12。∎

**诚实声明**：(B8)(B9)(B10) 都是**经验/工程断言**而非纯定理——τ 的可证性依赖抽象域选择，Γ 的保守性依赖 DSL 规则的机械检查，b(d) 依赖校准分布；三者任一失效都会静默破坏可靠性。这正是本轮最大风险。

## 5. 实验设计与初步结果（仿真；实机/跨组织联邦列入第 7 轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX 舰队 N∈{8,32,128} 仿真站点；跨站物体/几何/摩擦/相机异构；语义测试集（闭口瓶倾倒、刀刃朝向人、热杯握持、遮挡取物、易碎物夹持力）。
- **对照**：v5-full、v6-full；消融 A11（传输用学习 τ 而非可证界——预期假证书）、A12（接地允许放松——预期不安全）、A13（无概念传输）、A14（SPK 关闭，精确退化 v5）、A15（语义自由文本而非 DSL）。
- **场景**：(a) 跨站新域快速部署；(b) 语义危险集注入；(c) 概念格长尾物体；(d) 舰队接口违约/循环假设；(e) 校准审计漂移。
- **指标**：每站认证人时、认证成本随 N 的增长指数、跨站新域安全违例率、语义危险捕获率、误收紧率、弃权率、缓冲违约率、全局执行集收缩比、控制环 P99、联邦通信量。
- 语义/传输均在慢时域；控制环保持 v5 预算。

## 7. 本轮最大风险（最终确认）

**一句话**：**传输/接地层成为「静默的可靠性单点」**——失真界 τ 与语义接地的保守性都是（半）学习/统计得来的经验断言而非机械可验证定理，一旦某个 τ 被低估或某条 DSL 接地规则悄悄放松，错误证书会沿传输与概念格在整支舰队里复制放大，而系统表面上仍「全部通过」，形成规模放大的静默不可靠。
