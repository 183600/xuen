# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「遥操作」×「演示数据」）

> R69 把不确定性一分为二，并问出「**我该向谁求证、还能问什么**」。但它暗含两个未言明的前提：其一，被问的人只是一个**廉价标签源**（说一句"左"或"右"）；其二，策略自己吐出的模态分布可信。R69 自陈的最大风险正是第二个前提——流模型可能幻觉出不存在的模态，于是系统"自信地追问一个幻影"。这说明**模型对自己的无知是不可靠的**：一个从没见过某状态的策略，恰恰最可能在那里给出高置信度的错误。
>
> 本轮两个灵感正好把"信息来源"从"标签"升级为"能力"：
> - **遥操作**给出一种比"问"更强的交互——**接管**：人不是给一个答案，而是直接驾驶一段，且这段接管既是安全兜底、又是新数据；但它引入**权限交接**这一新的安全面（接管延迟、无扰切换、交还时机）。
> - **演示数据**给出"能力"的**来源与边界**：策略会什么，只等于它的演示覆盖了什么。U_epi 是模型内部的、可幻觉的；**覆盖度 U_sup 是数据侧的、不可幻觉的**。
>
> 核心命题：**在 R69 的 (U_ale, U_epi) 之外增加第三种、数据地基的不确定性 U_sup（演示覆盖缺口）；把遥操作接管建模为"决策价值 + 学习价值"双重价值的最高保真信息动作；用演示血统治理和延迟学习不变式保证这条「边做边学」通道不被污染、不放大自身错误；当覆盖充足且接管预算为零时严格退化为 R69。** 命名 **PILOT-RAS**（Provenance-aware Interactive Learning from Operator Takeover）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我什么时候该停下、把方向盘交出去，并从这一交里学到什么**」——不确定性不只是刹车和提问，也可以是一次**交权**和一段**示范**。

## 0. 直觉与动机

**灵感 1（演示数据 → 能力的来源与边界）**
直觉：一个人说"我会骑车"，这个"会"的边界就是他骑过的路况。R69 里 U_epi 来自策略对同一观测的多次采样：它问的是"我内部有几种做法"，却问不出"这些做法有没有一个是我见过的"。一个在冰面上从没被演示过的策略，可能同时幻化出"绕左"和"绕右"两个模态、权重还挺自信——这正是 R69 的幻影模态。**换一个数据地基的问法**：当前 (o,a) 落在演示流形上吗？离最近的演示有多远？覆盖缺口 U_sup 不是模型自省的产物，而是外部证据。它把"我不确定"从"我在纠结"变成"我没学过"。

**灵感 2（遥操作 → 接管是一种更高阶的信息动作）**
直觉：R69 的信息动作是看、问、触——都是**索取一个观测/标签**。但人类遇到不会的事，最有效的是"你让开，我来"，然后示范一遍。接管同时是三件事：(a) 安全兜底（人直接驾驶，风险立刻下降）；(b) 最高保真的示范（人的动作就是真值动作，不是一句可能撒谎的话）；(c) 权限转移（R66 的"谁控制"从静态切换变成动态交接）。因此接管的信息价值应同时计入"这一次怎么决策"和"以后这类状态学到了什么"——这是 R69 的单步 VoI 所缺的第二项。

**灵感 3（覆盖门控 → 慢下来不能创造能力）**
直觉：R68/R69 的万能药是 λ_floor——不确定就收紧。但"没学过"这件事，**收紧不会让它学会**。对一个覆盖缺口，正确的动作不是"更慢地做不会的事"，而是"别做，交给人，并把这一段变成示范"。所以本轮的风险缩放要从两级升到三级：覆盖足→R69；覆盖缺但能交接→交权；覆盖缺且交接不可行（延迟大、操作员过载）→超保守。这把 R69 的"只收紧"从"唯一退路"降级为"交接不可用时的最后退路"。

**灵感 4（演示是双刃剑 → 血统治理与延迟学习）**
直觉：一旦把"人的示范"当训练数据，就打开了新的污染面：操作员有偏见、有习惯、有疲劳；演示可能被延迟污染（今天的状态配昨天的动作）；更危险的是自举——系统把自己接管时收集的数据喂回自己，于是"它犯过的错"被当成"世界的规律"。所以演示必须有**血统**（谁、何时、熟练度、是否被一致确认），且学习必须是**延迟的**（实时环路仍然零学习写操作，离线更新 + 影子验证 + 冠军挑战者），绝不"边接管边改权"。

**灵感 5（对偶通道 → 正面回应 R69 的幻影模态）**
直觉：R69 的流似然 a_score 在分布外（OOD）没有意义——模型可以高似然地在无数据处"幻化"。但覆盖度天然能判 OOD：如果 (o,a) 离演示流形很远，那么再高的模型似然也只是外推。于是 (a_score, U_sup) 联合起来能区分三种截然不同的情况：**真新奇**（模型与数据一致报警）、**模型幻觉**（模型自信但无数据支撑）、**数据有覆盖但当前行为异常**（R69 的缓变故障疑）。这直接补上 R69 最脆弱处，也让"追问幻影"变得可被拦截。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（PILOT-RAS 总览）** PILOT-RAS = (DEM, COV, TSU, HOT, DVG, DGP, LRN, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）：接管产生的新数据只进缓冲，不改变实时策略，离线更新且经影子验证；
(ii) **权限交接安全**：任何 AUTO↔TELEOP 转换必须无扰（bumpless）、有延迟补偿、经 C-RAS-WM 认证；
(iii) **覆盖门控**：U_sup > τ_sup 时不得声称"有能力处理"，必须交接或超保守，**不得用单纯收紧冒充解决**；
(iv) **演示血统纪律**：任何进入训练缓冲的演示必须携带血统元组；污染演示隔离；单一操作员不得单独定义"已覆盖"。

**定义 311（演示语料与血统元组）** D = {(o_i, ξ_i, ρ_i)}_{i=1}^N，其中 ξ_i 为动作块，ρ_i = (op_id, ŝ_op, t_i, L_obs, mode_i, κ_i) 为血统：操作员身份、估计熟练度、时刻、遥操作观测延迟、录制模式（自由/定向）、污染标志。演示的"新鲜度"和"一致性"是血统的一部分，而非事后审计。

**定义 312（覆盖度 / 支撑函数 COV）** 在共享表征 z=Φ(o) 与动作空间上定义到演示流形的距离 d_D(z,a)（kNN / 密度比 / 马氏距离）。覆盖 c(z,a) = exp(−d_D²/2σ_c²) ∈ [0,1]，或等价地用**共形分位数**给出 ε-覆盖：c_ε(z,a) = 1 ⇔ 该样本落在演示集 ε-分位球内。覆盖缺口 U_sup = 1 − c_ε，**数据侧、可证伪**（对任意新样本可判定是否在覆盖内）。COV 的校准（共形覆盖率 ≠ 名义覆盖率）由定义 324 门控。

**定义 313（三分解不确定性）** U = (U_ale, U_epi, U_sup)。U_ale 由 R69 定义 297（模态内、不可约）→ R68 λ_floor；U_epi 由 R69 定义 297（模态间、可约）→ R69 MINT；U_sup 由定义 312（覆盖缺口、只能靠示范消解）→ 接管/定向示范。三者**正交分解、分别处置，不做简单加和**：aleatoric 收紧正确，epistemic 提问可解，support 只能学习。

**定义 314（权限状态与交接 HOT）** 权威 α_t ∈ {AUTO, SHARED, TELEOP}。转换（AUTO→TELEOP、TELEOP→AUTO、AUTO→SHARED）由交接控制器 HOT 决策，输入为 (U_sup, U_epi, 操作员负载 ℓ_op, 延迟 L_h, 预算)。**无扰条件**：切换瞬间 |a_auto(t) − a_teleop(t)| ≤ δ_s，且切换后参考轨迹速率受限；延迟 L_h 由 R67 VISTA 的 H 步预测补偿，L_h > L_max 时禁止 AUTO→TELEOP（转为超保守）。

**定义 315（增广信息动作：接管与定向示范）** 在 R69 定义 294 的 𝒜_info 上扩展 𝒜_info+ = 𝒜_info ∪ {g_TO, g_DEMO}。g_TO 为**接管请求**（把权威交给操作员，产出接管轨迹）；g_DEMO 为**定向示范请求**（指定要示范的状态区域 R_req 与目标技能，操作员在离线/低速下示范）。二者的"回答"不是标签，而是**动作轨迹**，因此既是信息、也是数据。

**定义 316（双重价值 DVG）** 对信息动作 g，定义 VoI_tot(g) = VoI_task(g) + β·VoI_learn(g) − c(g)。其中 VoI_task 沿用 R69 定义 298（对当前决策的信息增益）；VoI_learn(g) = E_{y~g}[ΔU_sup(D ∪ y)] · p_enc(R_req)，即"这一示范让相关区域覆盖提升多少 × 该区域未来被遭遇的概率"；β 为学习价值折扣。选择 g* = argmax VoI_tot，s.t. 安全与预算。R69 的 MINT 是 β=0、𝒜_info+=𝒜_info 的退化情形。

**定义 317（覆盖感知仲裁）** 决策树（按优先级）：(1) U_sup ≤ τ_sup 且 U_epi > τ_epi → R69 交互（问/看/触）；(2) U_sup > τ_sup 且 g_TO 可行 → 接管/定向示范（取 VoI_tot 最大者）；(3) U_sup > τ_sup 且 g_TO 不可行 → 超保守（λ_floor(U_ale+U_epi+U_sup)）并记一条"能力缺口"事件；(4) 否则常规执行。**这条树把"没学过"从"慢下来"里独立出来**。

**定义 318（无扰交接与安全认证）** 交接动作经 C-RAS-WM 前缀认证：切换前后控制连续、参考轨迹速率受限、安全包络不变；用 VISTA 预测在 L_h 内做前馈补偿。认证通过才允许切换；失败则保持当前权威并退化为保守。**接管窗口内 U_sup 视为 0**（人在驾驶，覆盖问题暂时由人承担），但交还时必须重新评估 U_sup（人的演示未必已覆盖）。

**定义 319（演示血统治理 DGP）** 进入缓冲前过三道门：
(a) **熟练度门**：ŝ_op < τ_skill 的演示不用于正样本（可作负样本/对比）；
(b) **一致性门**：同一区域多操作员示范的离散度 > τ_cons 时不标"已覆盖"，标"有争议"；
(c) **污染门**：血统中的延迟/模式异常、与多源共识矛盾的演示隔离进 quarantine，不进入训练。
通过者按**重要性权重** w = p_deploy(o)/p_demo(o) 校正协变量漂移（DAgger 式：策略自己到达的状态要用专家动作重标注）。

**定义 320（延迟学习与影子晋升 LRN）** 接管/定向示范进 D_buf；离线按批次更新候选策略 π'；π' 必须在**影子验证集**（含专门构造的覆盖缺口集与安全边界集）上不劣于当前 π 才可晋升；晋升是原子换装且保留回滚。实时环路内 π 不变（继承定义 310-i）。这保证"边做边学"不破坏实时安全与可复现性。

**定义 321（三级风险缩放）** (a) 覆盖足、epistemic 已消解：λ = λ_floor(U_ale)（R69 resolution bonus 保留）；(b) 覆盖缺、已交权：人在环，机器人指令 λ 取保守值且以交接轨迹为准（权限不在机器人）；(c) 覆盖缺、无法交权：λ = λ_floor(U_ale+U_epi+U_sup)（**未学过的区域按最坏情形处理**）。当 τ_sup→0（处处覆盖）且 g_TO 预算为 0 时，逐指令退化为 R69。安全侧永不弱于 R69。

**定义 322（演示污染干扰集 ℰ_demo）** 恶意/偏见示范、延迟污染（状态-动作错配）、自举漂移（把自身错误当示范）、操作员分布失衡导致的模式坍缩、以"示范"为名的对抗注入。并入 AIC：ℰ_PILOT = ℰ_FLUID × ℰ_demo。

**定义 323（证书 J_PILOT）** J_PILOT = (J_FLUID, U_sup_p95, coverage_ece, handoff_count, bumpless_p99, provenance_hash, demo_quarantine_rate, pilot_ver)。Valid ⇔ Valid(J_FLUID) ∧ coverage_ece ≤ τ_cov ∧ 交接安全认证通过 ∧ 血统纪律满足。

**定义 324（覆盖校准门 CCG）** 覆盖估计本身必须校准：用共形预测检验名义覆盖率与实际覆盖率的偏差，及"覆盖预测"的 ECE。若 coverage_ece > τ_cov，则**禁用 U_sup 断言**，退化为 R69（此时系统承认"我不知道自己覆没覆盖"，按 R69 的模型侧不确定处理并加保守）。这是 R68 表征坍缩、R69 模态坍缩的"数据度量版"。**最危险的失败是"覆盖估计高置信地错误"——它会把没学过的地方标成已覆盖。**

**定义 325（操作员负载与交接质量 QoH）** 操作员负载 ℓ_op（注意力占用、同时监控的任务数）决定接管可行性与接管质量；QoH = f(ℓ_op, L_h, 熟练度)。ℓ_op 过高时，即使 U_sup 大也**不得**请求接管（避免"名义有人、实际无人"）；此时按定义 321(c) 超保守。预算约束并入定义 293-ii。

**定义 326（定向示范请求 DRE）** g_DEMO 指定区域 R_req 与目标技能，最大化单位操作员时间的覆盖增益：R_req* = argmax_R E[ΔU_sup(R)] / 操作员时间成本。这是主动学习/实验设计在"人给示范"通道上的实例；与 R69 的问句（语言输出）不同，示范是**动作输出**，信息密度更高但成本也更高。

**定义 327（覆盖-似然对偶）** R69 的流似然 a_score 在 OOD 处不可靠（高似然幻觉）；覆盖 U_sup 是它的数据侧镜像。二者联合：(a_score↑, U_sup↑) → 真新奇（模型与数据一致报警）；(a_score↓, U_sup↑) → 可能模型幻觉/外推（模型自信但无数据支撑，**禁止**据此追问幻影，改为接管或保守）；(a_score↑, U_sup↓) → 数据有覆盖但当前行为异常（R69 的 FMA 缓变故障疑）。这是对 R69 定义 309 的扩展，把"标定不可吸收"升级为"外推不可采信"。

# IP-264 DEM：演示语料与血统
class DemonstrationStore:
    def add(self, o, xi, rho):               # rho 血统元组
        self.buf.append((o, xi, rho))
    def support_index(self):                 # 供 COV 用的 kNN/密度索引
        return self.index

# IP-265 COV：覆盖估计（共形支撑，数据侧）
class CoverageEstimator:
    def __init__(self, store, eps=0.05):
        self.index = store.support_index()
        self.eps = eps                        # 名义覆盖率
    def cover(self, z, a):
        d = self.index.dist(z, a)             # 到演示流形距离
        return conformal_inclusion(d, self.eps)   # bool 或 [0,1]
    def U_sup(self, z, a):
        return 1.0 - self.cover(z, a)

# IP-266 TSU：三分解（扩展 R69 AUD）

    return U_ale, U_epi, U_sup, modes

        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

        answer = M.cia.execute(g)                             # 看/问/触/接管/示范

        U_epi_after = U_epi if is_takeover(g) else M.cia.update_belief(modes, answer)
    # 4) 三级风险缩放
    U_floor = U_ale + (U_epi_after if g is None else 0.0) + \
              (U_sup if (g is None and reliable) else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(g, U_sup, a_hat, provenance=...)
    return k, lam, mode, (U_ale, U_epi, U_sup)
```

## 3. 推导

**引理 19（覆盖的不可吸收性 / 幻影模态的本质是外推）** 设演示集 D 的 ε-覆盖为 C_ε。对任意 (z,a) ∉ C_ε，模型似然 a_score 只依赖速度场外推，不提供关于真实可靠性的信息；而覆盖给出可证伪的判定 (z,a)∉C_ε。故 **R69 的"幻影模态"恰是 (U_sup 高, 模型似然高) 的子集**，可被定义 327 的对偶判据拦截。系：覆盖把"模型自陈的 epistemic"替换为"数据侧可验证的 support 缺口"。

**引理 20（双重价值阈值：问 vs 接管）** 比较 g_ask 与 g_TO：取接管的额外成本 Δc = c_TO − c_ask，额外收益为 β·p_enc·ΔU_sup。则接管优于提问 ⇔ β·p_enc·ΔU_sup > Δc。系：**当某类状态会反复遇到（p_enc 高）且当前完全没覆盖（ΔU_sup 大）时，即使接管很贵也应接管**——因为一次接管买到了"以后都会"，而一次提问只买到"这一次"。这为 R69 只算单步 VoI 的短视给出了修正阈值。

**引理 21（无扰交接的连续性界）** 在延迟 L_h ≤ L_max、VISTA 前馈补偿误差 ≤ ε_v、参考速率受限的条件下，AUTO→TELEOP→AUTO 切换引入的控制量跳变 ≤ δ_s + ε_v，且安全包络不变。故权限切换不破坏 R68 定理 15 的换装不变式。系：**接管不是安全漏洞，而是认证过的"有界中断"**。

**定理 18（PILOT 严格包含 FLUID）** 在 A99–A101 下（覆盖校准、血统纪律、无扰交接成立），PILOT 的期望风险 ≤ FLUID；且当 U_sup 处处 ≤ τ_sup（覆盖充足）且 g_TO/g_DEMO 预算为 0 时，两者**逐指令相同**（定义 321）。因此 FLUID 是 PILOT 在"永远覆盖充足、永不接管"边界上的退化——安全侧不让步，能力侧获得"学习型 resolution bonus"。

**引理 22（示范反馈的漂移界）** 在 DAgger 式协变量校正下，若污染比例为 δ_c、重要性权重有效样本量为 ESS，则候选策略的误差 ≤ 基准误差 + O(δ_c/√ESS) + L·D_shift；当 δ_c 或 D_shift 超阈值时，自举更新可能放大误差。故定义 319 的三道门与定义 320 的影子验证是**稳定性前提而非工程细节**。

**定理 19（交接的安全与无突变）** 交接动作经 C-RAS-WM 认证（定义 318）后物理风险 ≤ ε_int；U_sup 高时交接使机器人让出权威而非继续执行，安全侧单调不降；交接失败/超时/负载过高时 λ 单调不降地退化为保守；实时环零学习写操作保持 ⇒ 控制连续、可复现、无在线漂移。

## 6. 本轮最大风险

**一句话**：PILOT-RAS 把"能力"押在「演示数据诚实且覆盖充分、覆盖估计又足够准」这一前提上——**若演示被偏见/延迟/对抗污染，或覆盖估计高置信地判错（把没学过的地方标成已覆盖），系统就会在最不该自信的地方最自信，并把接管收集来的自身错误当作世界的规律反复学习**；遥操作于是把 R69 的「问错」升级成「**学错**」——**向错误的人学，比不学更危险**。

**次级风险与缓解**：
1. **覆盖估计失真**（潜空间畸变、度量失效）→ CCG 共形校准门，ECE 越界即禁用 U_sup、退回 R69；
2. **自举放大**（DAgger 漂移、模式坍缩）→ 重要性权重 + 影子验证 + 冠军挑战者 + E309；
3. **交接安全**（延迟、跳变、操作员过载）→ 无扰认证 + VISTA 前馈 + 负载门 + E306/E307/E312；
4. **演示投毒**（恶意/偏见示范）→ 血统三道门 + 多操作员一致性 + 隔离区 + E308；
5. **覆盖门控被滥用为"永远保守"**（一有缺口就停机）→ 用 VoI_tot 权衡接管收益，E305/E315 度量利用率而非只度量安全。

class DemonstrationStore:
    def add(self, o, xi, rho):               # rho 血统元组
        self.buf.append((o, xi, rho))
    def support_index(self):                 # 供 COV 用的 kNN/密度索引

    def __init__(self, store, eps=0.05):
        self.index, self.eps = store.support_index(), eps
    def cover(self, z, a):
        return conformal_inclusion(self.index.dist(z, a), self.eps)
    def U_sup(self, z, a):
        return 1.0 - self.cover(z, a)

    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(g, U_sup, a_hat, provenance=...)
    return k, lam, mode, (U_ale, U_epi, U_sup)
```

## 4. 推导

**引理 19（覆盖的不可吸收性 / 幻影模态的本质是外推）** 对 `(z,a)∉C_ε`，模型似然只依赖速度场外推、不提供真实可靠性信息；覆盖给出可证伪判定。故 R69 的幻影模态是 `(U_sup↑, 模型似然↑)` 的子集，可被定义 327 对偶判据拦截。

**引理 20（双重价值阈值：问 vs 接管）** `Δc = c_TO − c_ask`，额外收益 `β·p_enc·ΔU_sup`。接管优于提问 ⇔ `β·p_enc·ΔU_sup > Δc`。系：状态反复遇到（p_enc 高）且完全没覆盖（ΔU_sup 大）时，即使接管很贵也应接管——一次接管买到"以后都会"，一次提问只买到"这一次"。

**引理 21（无扰交接的连续性界）** 在 `L_h≤L_max`、VISTA 前馈误差 `≤ε_v`、参考速率受限下，AUTO→TELEOP→AUTO 的控制跳变 `≤δ_s+ε_v`，安全包络不变，不破坏 R68 定理 15 换装不变式。系：接管是认证过的"有界中断"。

**定理 18（PILOT 严格包含 FLUID）** A99–A101 下 PILOT 期望风险 ≤ FLUID；且当 `U_sup≤τ_sup` 处处成立且接管/示范预算为 0 时逐指令相同（定义 321）。FLUID = 「永远覆盖充足、永不接管」边界；安全不让步，能力获学习型 resolution bonus。

**引理 22（示范反馈的漂移界）** DAgger 式校正下，污染比例 `δ_c`、有效样本量 ESS，则误差 `≤ 基准 + O(δ_c/√ESS) + L·D_shift`；超阈值时自举会放大误差。故血统门 + 影子验证是稳定性前提而非工程细节。

**定理 19（交接的安全与无突变）** 交接经 C-RAS-WM 认证后物理风险 `≤ε_int`；U_sup 高时交权使机器人让出权威，安全侧单调不降；失败/超时/过载时 λ 单调不降地退化；实时环零学习写操作保持 ⇒ 控制连续、可复现、无在线漂移。

## 7. 本轮最大风险

**一句话**：PILOT-RAS 把"能力"押在「演示诚实且覆盖充分、覆盖估计又足够准」上——**若演示被偏见/延迟/对抗污染，或覆盖估计高置信地判错（把没学过的地方标成已覆盖），系统就会在最不该自信的地方最自信，并把接管收集来的自身错误当作世界的规律反复学习**；遥操作于是把 R69 的「问错」升级成「**学错**」——**向错误的人学，比不学更危险**。

**次级风险与缓解**：覆盖估计失真（CCG 共形校准门，越界退回 R69）；自举放大/模式坍缩（重要性权重 + 影子验证 + 冠军挑战者 + E309）；交接安全（无扰认证 + VISTA 前馈 + 负载门 + E306/E307/E312）；演示投毒（血统三道门 + 多操作员一致 + 隔离区 + E308）；覆盖门控被滥用为"永远保守"（VoI_tot 权衡 + E305/E315 度量利用率）。
