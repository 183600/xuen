# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「语义建图」×「跌倒恢复」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书体系（ACS/SCOM/CEC/AEC/JTC）。本轮聚焦 **语义可恢复性地图、语义条件化动作剖面、恢复技能树、语义不确定性门控**。核心矛盾：H22：恢复技能的可行性由局部语义结构决定（支撑面、可借力物、净空、坡度、落差、地面稳定性），而第 54 轮的 `α_S(a)` 仅在几何动作空间标定，缺少语义条件，导致“同动作、异语义”下恢复动作在真实斑块上不可用；H23：跌倒多发生在语义地图稀疏/过期/遮挡处，云端先验语义标签在恢复点最可能错误，若不以语义不确定性门控恢复决策，系统会在错误先验上“自信地失败”。

## 0. 直觉与动机

**灵感 1（语义建图 → 语义可恢复性地图 SRAM）**
直觉：普通语义地图回答“这是什么”（地板/地毯/斜坡/台阶/床沿），而对跌倒恢复真正重要的是“这里能做什么来恢复”——是否有可借力的墙、可撑的台面、可滚动的净空、地面是否打滑、边缘下方是否有落差。于是把语义图层从 label 升级为 **恢复可及度向量** `σ ↦ rec(σ)` 及其置信度 `u(σ)`。跌倒恢复不再是“从倒地位姿站起来”的单一技能，而是在语义斑块上寻找一条 **可行恢复动作链**。这把“语义”从感知标签变成 **可执行性的一等约束**。

**灵感 2（语义条件化动作剖面 `α_S(a|σ)`）**
直觉：技能的动作可行性不是动作空间的齐次属性，而是被语义斑块条件化：同一个“翻身-撑起”动作在硬平地可行，在软床、斜坡、边缘附近不可行或高代价。故第 54 轮的 `α_S(a)` 应扩展为 `α_S(a|σ)`，恢复动作空间是随 `σ` 变形的 **恢复流形** `R_S = {(σ,a) | α_S(a|σ) ≥ θ_cov ∧ rec(σ) ⊨ pre(S)}`。语义建图因此不是给规划“加标签”，而是给动作剖面“加定义域”。

**灵感 3（跌倒恢复 → 恢复技能树 + 阶段语义护栏）**
直觉：恢复是分阶段过程（制动/护头 → 姿态判定 → 翻身 → 支撑 → 爬起 → 站稳），每阶段有语义前置条件与退出条件。把它建模为 **恢复技能树 `T_rec`**，边带语义护栏 `g(σ)` 与鲁棒性下界。组合不再是任意技能图上的最短路径，而是“在语义护栏允许的子树内，找风险有界的阶段序列”。这把第 54 轮的 SCOM 从“动作兼容图”收紧为“语义可判定恢复树”。

**灵感 4（云边语义分工 + 语义不确定性门控）**
直觉：云端维护全局 SRAM 与恢复先验（哪类语义斑块常出现哪类跌倒），边端做局部语义细化、跌倒检测与恢复执行。跌倒点常是地图稀疏/过期处，故必须引入 **语义不确定性门控 `u_σ`**：当恢复点语义置信度低于阈值、或云边语义冲突时，不执行激进恢复，而退回 **保守恢复 `R_cons`**（低能量、护头、缓慢试探、呼救/等待），把“自信地失败”换成“有界地保守”。这把第 54 轮的 CEC 闭环从“动作对齐”升级为“语义对齐 + 风险分级”。

**灵感 5（语义-动作-鲁棒性三元联合证书）**
直觉：第 54 轮联合证书 `J=(ρ,A_cert,γ_ce,δ_a)` 只覆盖动作与鲁棒性。恢复场景必须再绑定 **语义有效期 `Σ_sem`** 与语义不确定度 `u_σ`，得到 `J_sem=(ρ,A_cert,Σ_sem,u_σ,γ_ce,δ_a,evidence)`。证书在语义漂移或斑块越界时 **自动失效**，恢复计划必须重规划而非带病执行。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（语义地图与语义斑块）**
语义地图 `M : X → Δ(L) × [0,1]`，`x ↦ (p_x, u_x)`，`p_x` 为标签分布，`u_x` 为认知不确定度。语义斑块 `σ ⊆ X` 为满足标签稳定与恢复可及特征同质的连通区域；记 `σ(x)` 为 `x` 所属斑块。SRAM 即 `𝔐 = {(σ, rec(σ), u(σ))}`。

**定义 122（恢复可及度向量）**
`rec(σ) = (s_sup, s_brc, s_roll, s_slope, s_drop, s_stab) ∈ [0,1]^6`，分别表示支撑面质量、可借力结构、可滚动净空、坡度可行性、边缘落差安全度（落差风险取补）、地面稳定性。恢复前置 `pre(S)` 是 `rec(σ)` 上的可判定谓词。

**定义 123（语义条件化动作剖面与恢复流形）**
`α_S : A × Σ → [0,1]`，`α_S(a|σ)` 为技能 `S` 在语义斑块 `σ` 下执行动作 `a` 的可行度；语义动作域 `A_S(σ) = {a | α_S(a|σ) ≥ θ_cov}`；恢复流形
`R_S = {(σ,a) | α_S(a|σ) ≥ θ_cov ∧ rec(σ) ⊨ pre(S)}`。

**定义 124（恢复技能树与语义护栏）**
恢复技能树 `T_rec = (V_r, E_r, g, ρ_min)`：节点为恢复阶段 `S_i`，边 `(S_i,S_j) ∈ E_r` 当且仅当存在斑块 `σ` 使 `A_{S_i}(σ) ∩ A_{S_j}(σ) ≠ ∅` 且阶段退出条件可满足；语义护栏 `g : E_r × Σ → {0,1}`，`g=1` 当且仅当 `σ` 满足该边的语义前置；边附鲁棒性下界 `ρ_min`。恢复计划为 `T_rec` 中满足 `g` 的阶段路径。

**定义 125（语义不确定性门控）**
恢复触发门控
`G_rec = 1[conf_fall ≥ θ_f ∧ u_σ(x_fall) ≤ θ_u ∧ agree(M_c(x), M_e(x))]`，
其中 `conf_fall` 为跌倒检测置信度，`agree` 为云边语义一致性。`G_rec=0` 时执行保守恢复 `R_cons`，且 `R_cons` 必须满足 `ρ_cons ≥ ρ_safe` 与能量上界 `E_max`。

**定义 126（语义-动作联合证书）**
`J_sem = (ρ, A_cert, Σ_sem, u_σ, γ_ce, δ_a, evidence)`，`Σ_sem` 为证书语义有效期（允许的斑块集合与最大语义漂移），`u_σ` 为斑块不确定度界。若 `dom_J(T)=in`、`δ_a<Θ_a`、`u_σ<Θ_u` 且实际斑块 `σ* ∈ Σ_sem`，则恢复计划可部署；否则证书失效并触发重规划。

**定义 127（恢复负迁移风险）**
语义迁移 `σ→σ'` 下的负迁移风险
`NT(S,σ→σ') = E_{a~π_S(·|σ')}[ℓ(a,σ')] - E_{a~π_S(·|σ)}[ℓ(a,σ)]`，
其中 `ℓ` 为语义违例损失。`NT>0` 表示把 `σ` 上成功的恢复策略直接搬到 `σ'` 会变差。证书要求 `NT ≤ NT_max`。

## 2. 关键算法 伪代码

### IP-121 SRAM（Semantic Recovery Affordance Map）

```python
def build_sram(cloud_map, edge_obs):
    M = fuse_semantics(cloud_map, edge_obs)          # p_x, u_x
    sram = {}
    for patch in connected_components(M, stable=True):
        rec = {
            'support': estimate_support(patch, edge_obs),
            'brace':   detect_brace_surfaces(patch, edge_obs),
            'roll':    free_clearance(patch, edge_obs),
            'slope':   slope_feasible(patch),
            'drop':    1.0 - edge_drop_risk(patch),
            'stab':    ground_stability(patch),
        }
        sram[patch.id] = (rec, patch.uncertainty)
    return sram
```

### IP-122 SCS（Semantic-Conditioned Skill Profile）

```python
def semantic_profile(skill, sram, A, theta_cov=0.8):
    alpha = {}
    for sigma, (rec, u) in sram.items():
        if not satisfies_pre(skill, rec):
            for a in A:
                alpha[(a, sigma)] = 0.0
            continue
        for a in A:
            feas, conf = skill.sampler.query(a, rec)
            alpha[(a, sigma)] = conf if feas else 0.0
    return alpha

def semantic_domain(alpha, sigma, theta_cov=0.8):
    return {a for (a, s), v in alpha.items() if s == sigma and v >= theta_cov}
```

### IP-123 RST（Recovery Skill Tree）

```python
def build_recovery_tree(stages, sram, K, rho_min):
    T = nx.DiGraph()
    T.add_nodes_from(stages)
    for Si, Sj in candidate_edges(stages):
        best = None
        for sigma, (rec, u) in sram.items():
            if not semantic_guard(Si, Sj, rec):
                continue
            if not (semantic_domain(Si.alpha, sigma)
                    & semantic_domain(Sj.alpha, sigma)):
                continue
            rho = compose_robustness(Si.rho, Sj.rho, K)
            if min(rho.values()) < rho_min:
                continue
            cand = (min(rho.values()), sigma, rho)
            best = max(best, cand) if best else cand   # 保留风险最小的斑块
        if best:
            _, sigma, rho = best
            T.add_edge(Si, Sj, sigma=sigma, guard=1, rho=rho)
    return T

def plan_recovery(T, sigma_star):
    sub = nx.edge_subgraph(
        T, [(u, v) for u, v, d in T.edges(data=True)
            if d['sigma'] == sigma_star and d['guard'] == 1])
    return min_risk_path(sub, start='brake', goal='stand')
```

### IP-124 SUG（Semantic Uncertainty Gate）

```python
def recovery_gate(M_c, M_e, x_fall, conf_fall, theta_f=0.9, theta_u=0.2):
    u = M_e.uncertainty(x_fall)
    agree = semantic_agreement(M_c, M_e, region(x_fall))
    if conf_fall >= theta_f and u <= theta_u and agree:
        return ('aggressive', None)
    return ('conservative', R_cons)   # 低能量、护头、缓慢试探、呼救/等待
```

### IP-125 REC（Recovery Edge Contract）

```python
def edge_recover(x_fall, M_c, M_e, sram, T_rec, sim):
    mode, plan = recovery_gate(M_c, M_e, x_fall, fall_conf(x_fall))
    if mode == 'conservative':
        return execute_bounded(R_cons, E_max, rho_safe)
    cert = semantic_joint_certificate(plan, sram, gamma_ce, Theta_a, Theta_u)
    if cert.status != 'ok':
        return ('replan', cert.explain)     # 证书失效 → 回传云端重剖分
    res = sim.run(plan)
    if not res.success:
        exp = explain_failure(res, sim)
        return ('edge_feedback', exp)       # 语义护栏失效 → 局部 SRAM 重标定
    return ('ok', cert)
```

### IP-126 SAC（Semantic-Action Certificate）

```python
def semantic_joint_certificate(plan, sram, gamma_ce, Theta_a, Theta_u):
    sigma_star = locate(plan.x_fall)
    A_core = reduce(intersection,
                    [semantic_domain(s.alpha, sigma_star) for s in plan])
    delta_a = max_alignment_error(gamma_ce, A_core)
    Sigma_sem = semantic_envelope(plan, sram, sigma_star)
    u_sigma = max(sram[s].uncertainty for s in Sigma_sem)
    NT = max(negative_transfer_risk(s, sigma_star) for s in plan)
    if delta_a > Theta_a:
        return ('reject', 'action_mismatch', delta_a)
    if u_sigma > Theta_u or NT > NT_max:
        return ('reject', 'semantic_risk', (u_sigma, NT))
    rho = compose_robustness_chain([s.rho for s in plan], K)
    return ('ok', J_sem(rho, A_cert(A_core), Sigma_sem, u_sigma,
                        gamma_ce, delta_a))
```

### IP-127 NTR（Negative Transfer Radar）

```python
def negative_transfer_risk(skill, sigma_to, sigma_from, sim, n=64):
    direct = simulate(skill.policy, sigma_to, n)
    ported = simulate(skill.policy_from(sigma_from), sigma_to, n)
    return violation_loss(ported, sigma_to) - violation_loss(direct, sigma_to)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SRAM | O(|X| + |Σ|·|F|) | O(|Σ|) | 斑块同质、u_x 可校准 |
| SCS | O(|A|·|Σ|·|S|) | O(|A|·|Σ|) | 语义剖面完备、pre 条件 sound |
| RST | O(|V_r|²·|Σ| + |E_r| log|V_r|) | O(|V_r|²) | 语义护栏 sound、风险单调 |
| SUG | O(|X_fall| + |Σ|) | O(1) | u_σ 校准、云边一致性可判 |
| REC | O(|P_rec|·|A|) | O(|A|) | 保守恢复有界、回传收敛 |
| SAC | O(|S|·|Σ| + |𝔇_ρ|) | O(|A|+|Σ|) | 语义包络 sound、NT 有界 |
| NTR | O(n·|A|) | O(1) | 采样充分、违例损失可测 |

**正确性定理（Semantically-Gated Recovery Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `u_σ` 经校准（ECE ≤ ε_u）；**(A30)** `T_rec` 的语义护栏 `g` sound（`g=1` 的必要条件真实成立）；**(A31)** `R_cons` 满足能量上界 `E_max` 且 `ρ_cons ≥ ρ_safe`；**(A32)** 云边语义一致性检查延迟 `τ_gate` 满足 `τ_gate + τ_rec ≤ τ_fall`。
则恢复成功概率：
```
P_rec ≥ 1 - Σ_d (1-ρ_min(d)) - β_E - P(σ* ∉ Σ_sem)
        - P(NT > NT_max) - P(G_rec=0)·(1-ρ_cons)
```
关键：**先判语义门控，再谈恢复动作**；**证书绑定语义有效期**；**保守恢复是门控失败时的有界兜底**，而非额外的不确定性来源。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 语义标签体系与恢复动作不对齐 | 高 | 恢复本体（affordance-first）+ 专家校验 + 双向映射测试 |
| `u_σ` 校准漂移 | 高 | conformal prediction + 在线温度标定 + 分布外拒识 |
| 保守恢复过久导致二次风险 | 中 | 分级保守 + 超时升级（呼救/远端监督） |
| 恢复技能树组合爆炸 | 中 | 阶段剪枝 + 语义哈希 + 计划缓存 |
| 跌倒检测漏检/误检 | 高 | 多模态融合 + 不确定性输出 + 迟滞 |

## 6. 本轮最大风险

**一句话**：本轮把“语义建图”当作恢复决策的可信先验，但语义标签恰恰在跌倒点最稀疏、最易错——一旦 `u_σ` 校准失效或语义护栏欠约束，系统就会在错误斑块上执行“看似可行”的恢复动作链并系统性失败；故必须以 **conformal 语义置信度 + 语义护栏 soundness 证明 + 保守恢复兜底** 三重护栏，任何“语义清楚”的假设都不得凌驾于可验证的可恢复性证书之上。

```python
def build_sram(cloud_map, edge_obs):
```

### IP-122 SCS

```python
def semantic_profile(skill, sram, A, theta_cov=0.8):
    alpha = {}
    for sigma, (rec, u) in sram.items():
        if not satisfies_pre(skill, rec):
            for a in A:
                alpha[(a, sigma)] = 0.0
            continue
        for a in A:
            feas, conf = skill.sampler.query(a, rec)
            alpha[(a, sigma)] = conf if feas else 0.0
    return alpha

def semantic_domain(alpha, sigma, theta_cov=0.8):
    return {a for (a, s), v in alpha.items() if s == sigma and v >= theta_cov}
```

### IP-123 RST

```python
def build_recovery_tree(stages, sram, K, rho_min):
    T = nx.DiGraph()
    T.add_nodes_from(stages)
    for Si, Sj in candidate_edges(stages):
        best = None
        for sigma, (rec, u) in sram.items():
            if not semantic_guard(Si, Sj, rec):
                continue
            if not (semantic_domain(Si.alpha, sigma)
                    & semantic_domain(Sj.alpha, sigma)):
                continue
            rho = compose_robustness(Si.rho, Sj.rho, K)
            if min(rho.values()) < rho_min:
                continue
            cand = (min(rho.values()), sigma, rho)
            best = max(best, cand) if best else cand
        if best:
            _, sigma, rho = best
            T.add_edge(Si, Sj, sigma=sigma, guard=1, rho=rho)
    return T

def plan_recovery(T, sigma_star):
    sub = nx.edge_subgraph(
        T, [(u, v) for u, v, d in T.edges(data=True)
            if d['sigma'] == sigma_star and d['guard'] == 1])
    return min_risk_path(sub, start='brake', goal='stand')
```

### IP-124 SUG

```python
def recovery_gate(M_c, M_e, x_fall, conf_fall, theta_f=0.9, theta_u=0.2):
    u = M_e.uncertainty(x_fall)
    agree = semantic_agreement(M_c, M_e, region(x_fall))
    if conf_fall >= theta_f and u <= theta_u and agree:
        return ('aggressive', None)
    return ('conservative', R_cons)
```

```python
def edge_recover(x_fall, M_c, M_e, sram, T_rec, sim):
```

### IP-126 SAC

```python
def semantic_joint_certificate(plan, sram, gamma_ce, Theta_a, Theta_u):
    sigma_star = locate(plan.x_fall)
    A_core = reduce(intersection,
                    [semantic_domain(s.alpha, sigma_star) for s in plan])
    delta_a = max_alignment_error(gamma_ce, A_core)
    Sigma_sem = semantic_envelope(plan, sram, sigma_star)
    u_sigma = max(sram[s].uncertainty for s in Sigma_sem)
    NT = max(negative_transfer_risk(s, sigma_star) for s in plan)
    if delta_a > Theta_a:
        return ('reject', 'action_mismatch', delta_a)
    if u_sigma > Theta_u or NT > NT_max:
        return ('reject', 'semantic_risk', (u_sigma, NT))
    rho = compose_robustness_chain([s.rho for s in plan], K)
    return ('ok', J_sem(rho, A_cert(A_core), Sigma_sem, u_sigma,
                        gamma_ce, delta_a))
```

### IP-127 NTR

```python
def negative_transfer_risk(skill, sigma_to, sigma_from, sim, n=64):
    direct = simulate(skill.policy, sigma_to, n)
    ported = simulate(skill.policy_from(sigma_from), sigma_to, n)
    return violation_loss(ported, sigma_to) - violation_loss(direct, sigma_to)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SRAM | O(|X| + |Σ|·|F|) | O(|Σ|) | 斑块同质、u_x 可校准 |
| SCS | O(|A|·|Σ|·|S|) | O(|A|·|Σ|) | 语义剖面完备、pre sound |
| RST | O(|V_r|²·|Σ| + |E_r| log|V_r|) | O(|V_r|²) | 语义护栏 sound、风险单调 |
| SUG | O(|X_fall| + |Σ|) | O(1) | u_σ 校准、云边一致性可判 |
| REC | O(|P_rec|·|A| + |V|+|E|) | O(|A|+|V|) | 保守恢复有界、回传收敛 |
| SAC | O(|S|·|Σ| + |𝔇_ρ|) | O(|A|+|Σ|) | 语义包络 sound、NT 有界 |
| NTR | O(n·|A|) | O(1) | 采样充分、违例损失可测 |

**正确性定理（Semantically-Gated Recovery Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `u_σ` 经校准（ECE ≤ ε_u）；**(A30)** `T_rec` 的语义护栏 `g` sound；**(A31)** `R_cons` 满足 `E_max` 且 `ρ_cons ≥ ρ_safe`；**(A32)** `τ_gate + τ_rec ≤ τ_fall`。
则恢复成功概率：
```
P_rec ≥ 1 - Σ_d (1-ρ_min(d)) - β_E - P(σ* ∉ Σ_sem)
        - P(NT > NT_max) - P(G_rec=0)·(1-ρ_cons)
```
关键：**先判语义门控，再谈恢复动作**；**证书绑定语义有效期**；**保守恢复是门控失败时的有界兜底**。

## 5. 本轮最大风险

**一句话**：本轮把“语义建图”当作恢复决策的可信先验，但语义标签恰恰在跌倒点最稀疏、最易错——一旦 `u_σ` 校准失效或语义护栏欠约束，系统就会在错误斑块上执行“看似可行”的恢复动作链并系统性失败；故必须以 **conformal 语义置信度 + 语义护栏 soundness 证明 + 保守恢复兜底** 三重护栏，任何“语义清楚”的假设都不得凌驾于可验证的可恢复性证书之上。
