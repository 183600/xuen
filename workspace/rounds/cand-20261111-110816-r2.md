# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「自主导航」×「轮足机器人」）

> 第 54 轮把技能组合推进为动作空间剖面 α_S、技能组合图 G_S 与云边动作-鲁棒性联合证书 J。本轮把镜头拉到真实移动平台：轮足机器人在「自主导航」中必须在 **地形 τ、运动模式 m、动作原语 u** 三者之间做联合决策。核心矛盾：H22：地图上的导航路径只是地形基底上的一条曲线，未必能被提升为可执行的模式-动作序列；H23：轮↔足切换被当成离散标签切换，真实却是带瞬态、占空间、会失败的动力学机动；H24：能耗最优会把机器人推向轮式高置信平地假设，而地形分类误差恰在最危险的模式边界处最大。

## 0. 直觉与动机

**灵感 1（移动性纤维丛 → 导航的本质是可提升性而非路径长度）**
直觉：把地形类别 τ 看作底空间 T，每个 τ 上挂着该地形可用的模式-动作空间 `A_τ = M × U_τ`，整体 `A_nav = ⊔_{τ∈T} A_τ`，并有投影 `π: A_nav → T`。一条导航路径 `γ:[0,1]→T` 只是底空间曲线；真正可执行的是它的 **提升** `γ̃(t)=(γ(t), m(t), u(t))`，且在每个时刻满足 `μ_ρ(γ(t),m(t)) ≥ μ_min`。导航失败往往不是“路走错了”，而是 **提升不存在**：地图上有路，但没有任何模式能在该地形上安全走完。这把自主导航从最短路问题变成 **纤维丛截面存在性 + 提升搜索** 问题，也让“可达性”第一次带上了模式与动力学语义。

**灵感 2（轮足切换 → 把模式切换当作受验证的机动，而非标签）**
直觉：轮式与足式不是两个 enum 标签，而是两种接触动力学。切换需要时间 `t_sw`、空间 `ℓ_sw`，并伴随稳定性裕度 `s_sw` 与打滑风险 `p_slip`。若导航计划在悬崖边或窄梁上安排切换，即使两端模式各自可行，切换瞬态也可能致命。故引入 **切换证书 S_cert** 与 **切换区 z_sw**：导航计划必须为每次切换预留可验证的时空窗口；切换被提升为一等公民动作，而不是规划后处理。

**灵感 3（能耗-时间-风险三目标 → 证书是 Pareto 面而非标量）**
直觉：轮式在硬质平地又快又省，足式在碎石/楼梯稳但慢且耗能，混合模式介于其间。把三者压成单一 `cost` 会掩盖部署风险：一条“平均最优”的路径可能在关键悬崖段恰好选了低裕度模式。导航证书应给出 `(E, T_nav, R)` 的 **Pareto 前沿**，并声明所选工作点的预算、支配关系与退化路径。云端按任务偏好选点，边端按实测能耗/时延重投影；只有工作点仍在预算内且被前沿支配时，契约才成立。

**灵感 4（地形信念 → 机会约束下的保守提升）**
直觉：地形分类器输出的是信念 `b(τ)` 而非真值，地图还会过期。按 `argmax b` 做规划，误差最大处恰是模式边界：草地/泥地、薄冰、松动碎石、湿滑金属。故导航成功应 **信念鲁棒**：在 `b` 的 TV 球内取最坏地形，要求提升仍存在；否则降级到更保守模式（足式低速）或请求重观测。保守不是怯懦，而是把“地形误判”从不可控事故转成可计价的重观测成本。

**灵感 5（在线模式校准 → 本体感受驱动的模式-地形图更新）**
直觉：轮足机器人自带丰富本体感受（电流、滑移、振动、俯仰、足端力）。用残差 `r = (E_obs - E_pred, slip_obs - slip_pred, …)` 在线更新胜任度 μ，并让云端聚合跨机器人共享先验、边端保留个性化校准。这把第 54 轮的云边闭环具体化为 **云先验 - 边残差 - 图谱版本更新**：不是云端下发一张静态地形表，而是下发一张带不确定度与版本号的移动性图谱。

**灵感 6（层级契约 → 云路线 / 边模式表 / 接触控制）**
直觉：云端输出地形分段与任务偏好，边端输出模式调度与切换区，控制器执行接触级动作。三层之间以 `N_cert` 契约耦合；一旦边端残差超预算，触发 **模式表重协商**，而非简单重规划整条路线。这样导航的“重规划”被分解为三种粒度：路线重选、模式重排、切换区重定位，避免一有偏差就全盘推翻。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（地形索引的导航动作空间 / 移动性纤维）**
地形类别集合 `T`，模式集合 `M = {W, L, H}`（轮、足、混合），动作原语集合 `U`。地形 τ 上的动作空间 `A_τ = M × U_τ`，整体 `A_nav = ⊔_{τ∈T} A_τ`，投影 `π: A_nav → T`，`π(τ,m,u)=τ`。对地形路径 `γ:[0,1]→T`，其 **提升** 为分段映射 `γ̃(t)=(γ(t),m(t),u(t))`，满足 `π∘γ̃=γ`。

**定义 122（移动性胜任剖面与移动性证书）**
模式 m 在地形 τ 上的胜任度 `μ(τ,m,u)=P(success | τ,m,u)`；对第 53 轮鲁棒维度族 `𝔇_ρ` 定义下确界 `μ_ρ(τ,m)=inf_{d∈𝔇_ρ} μ_d(τ,m)`。**移动性证书**
`M_cert = (τ_core, m*, μ_min, E_max, N_ev)`，
其中 `τ_core` 为核心覆盖地形集，`μ_min` 为校准下置信界，`E_max` 为单位距离能耗上限，`N_ev` 为证据量。要求 `∀τ∈τ_core: μ_ρ(τ,m*) ≥ μ_min`。

**定义 123（导航提升与可提升性）**
导航计划 `P = ⟨(γ_i, m_i, u_i)⟩_{i=1..k}`。称 P 在 `M_cert` 下 **可提升**，当且仅当存在分段常量 `m(t),u(t)` 使
```
∀t: μ_ρ(γ(t),m(t)) ≥ μ_min  ∧  每次模式切换处 S_cert 可容许
```
提升成本 `cost_lift(P) = Σ_i (w_E·E_i + w_T·T_i + w_R·R_i)`，其中 `E_i,T_i,R_i` 为第 i 段的能耗、时间与风险积分。

**定义 124（切换证书）**
模式切换 `m→m'` 在地形 τ 上的证书
`S_cert(m→m'|τ) = (t_sw, ℓ_sw, s_margin, p_slip, z_sw)`，
其中 `t_sw` 为瞬态时长，`ℓ_sw` 为所需纵向空间，`s_margin` 为稳定裕度，`p_slip` 为打滑概率，`z_sw` 为预留切换区。可容许条件：
```
t_sw ≤ τ_sw  ∧  ℓ_sw ≤ ℓ_avail  ∧  s_margin ≥ s_min  ∧  p_slip ≤ p_max
```
任一不满足则切换不可容许；导航计划不得以“标签已切换”替代“机动已验证”。

**定义 125（导航证书与 Pareto 前沿）**
导航证书
`N_cert = (M_cert, {S_cert}, E, T_nav, R, ρ_nav, b_τ, frontier, evidence)`：
- `E,T_nav,R` 为整条计划的三目标实测/保守估计；
- `ρ_nav` 为第 53 轮鲁棒性谱在导航任务上的投影；
- `b_τ` 为规划时使用的地形信念；
- `frontier` 为 `(E,T_nav,R)` 的 Pareto 工作点集合；
- `evidence` 至少包含模式-地形标定集、切换仿真反例与地图版本。
部署条件：`P` 可提升 ∧ 所有 `S_cert` 可容许 ∧ `(E,T_nav,R)` 在预算内 ∧ 信念鲁棒成功率 `≥ 1-δ`。

**定义 126（信念鲁棒提升）**
地形信念 `b∈Δ(T)`，漂移半径 `ε_b`（TV 距离）。定义
```
success_robust(P) = inf_{b': ||b'-b||_TV ≤ ε_b} E_{τ~b'}[ 1{P 在 τ 上可提升} ]
```
机会约束 `success_robust(P) ≥ 1-δ` 是导航证书可部署的必要条件；当约束不可满足时，执行保守降级 `fallback = (m=L, u=slow, reobserve=true)`。

## 2. 关键算法 伪代码

### IP-121 MTA（Mode-Terrain Atlas）

```python
def build_mode_terrain_atlas(traj_db, terrains, modes, alpha=0.1):
    stats = defaultdict(list)
    for tr in traj_db:
        for seg in tr.segments:
            t = terrain_label(seg, terrains)
            stats[(t, seg.mode)].append(seg.success)
    mu, support = {}, {}
    for (t, m), xs in stats.items():
        mu[(t, m)] = clopper_pearson_lower(xs, alpha)   # 保守下界
        support[(t, m)] = len(xs)
    return MobilityAtlas(mu, support, alpha)             # 带证据量与置信下界
```

### IP-122 MLS（Mobility Lift Search）

```python
def mobility_lift_search(terrain_path, atlas, switch_model, budget):
    # 状态 = (地形段索引 i, 当前模式 m)；标签 = (E, T, R)
    open_set = [(0.0, 0, None, (0.0, 0.0, 0.0))]        # 段 0 尚无模式
    frontier = []
    while open_set:
        _, i, m_prev, cost = heappop(open_set)
        if i == len(terrain_path):
            frontier.append(cost); continue
        tau = terrain_path[i]
        for m in MODES:
            if atlas.mu_rho(tau, m) < atlas.mu_min:
                continue
            seg_cost = estimate_segment(tau, m, budget)
            if m_prev is not None and m_prev != m:
                s_cert = verify_switch(m_prev, m, tau, switch_model)
                if not s_cert.admissible:
                    continue
                seg_cost = add_switch_cost(seg_cost, s_cert)   # 预留 z_sw
            heappush(open_set, (dominance_key(cost+seg_cost), i+1, m, cost+seg_cost))
    return pareto_prune(frontier)                        # 不压成标量
```

### IP-123 SVE（Switch Verification Engine）

```python
def verify_switch(m, m2, terrain, dynamics, n_samples=256):
    outcomes = [simulate_switch(dynamics, m, m2, terrain, rng)
                for _ in range(n_samples)]
    fails = [o for o in outcomes if o.unstable or o.slip > p_max]
    if fails:
        return ('reject', min_counterexample(fails))     # 反例驱动，而非阈值拍脑袋
    s_cert = estimate_cert(outcomes)                      # t_sw, l_sw, s_margin, p_slip
    ok = (s_cert.t_sw <= TAU_SW and s_cert.l_sw <= L_AVAIL
          and s_cert.s_margin >= S_MIN and s_cert.p_slip <= P_MAX)
    return ('ok', s_cert) if ok else ('reject', s_cert)
```

### IP-124 NCE（Navigation Certificate Engine）

```python
def navigation_certificate(plan, atlas, switch_certs, belief, eps_b, budget):
    if not lift_exists(plan, atlas):
        return ('reject', 'no_lift')
    if any(not c.admissible for c in switch_certs):
        return ('reject', 'switch_infeasible')
    if not belief_robust_success(plan, belief, eps_b, atlas) >= 1 - budget.delta:
        return ('reject', 'belief_risk')
    E, T_nav, R = aggregate(plan)
    if E > budget.E_max or T_nav > budget.T_max or R > budget.R_max:
        return ('reject', 'budget_exceeded', (E, T_nav, R))
    return ('ok', N_cert(atlas.M_cert, switch_certs, E, T_nav, R,
                         rho_nav=project_robustness(plan),
                         b_tau=belief, frontier=pareto_front(plan)))
```

### IP-125 BRC（Belief-Robust Controller）

```python
def belief_robust_lift(terrain_path, belief, eps_b, atlas, budget):
    worst = worst_case_terrain(belief, eps_b)             # TV 球内最坏地形分配
    plan = mobility_lift_search_under(worst, atlas, budget)
    if plan is None or not navigation_certificate(plan, atlas, ..., budget)[0] == 'ok':
        return fallback(mode='L', primitive='slow', reobserve=True, replan_scope='segment')
    return plan
```

### IP-126 OMC（Online Mode Calibration）

```python
def online_mode_calibration(atlas, residuals, eta, version):
    for (tau, m), r in residuals.items():                 # r = obs - pred
        delta = eta * sign(r.energy) + eta * sign(r.slip)
        atlas.mu[(tau, m)] = project_interval(atlas.mu[(tau, m)] - delta)
        atlas.support[(tau, m)] += 1
    atlas.version = bump(version)
    return atlas                                          # 云聚合先验，边端个性化
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MTA | O(N_seg·\|T\|·\|M\|) | O(\|T\|·\|M\|) | 保守下界、分层采样覆盖 |
| MLS | O(\|T_seg\|·\|M\|·\|U\|·log) | O(\|T_seg\|·\|M\|) | 提升完备、切换边 sound |
| SVE | O(N_samples·H_switch) | O(N_samples) | 反例完备、瞬态建模 |
| NCE | O(\|P\|·\|𝔇_ρ\| + F) | O(\|P\|+F) | 三目标预算闭合、前沿未丢点 |
| BRC | O(\|T_seg\|·\|M\|·\|U\|·\|B\|) | O(\|T_seg\|·\|M\|) | 最坏信念可枚举/可近似 |
| OMC | O(\|T\|·\|M\|) / 更新 | O(\|T\|·\|M\|) | 残差有界、版本单调 |

**正确性定理（Liftable Navigation Soundness）**
承接第 53–54 轮 (A22)–(A28)；新增假设：**(A29)** `μ_ρ` 为保守校准下置信界，覆盖真实成功率至少 `1-δ_μ`；**(A30)** `SVE` 的切换验证对反例 sound，误收率 `≤ δ_sw`；**(A31)** 地形信念漂移 `||b-b_true||_TV ≤ ε_b` 且地图分段完整覆盖路径；**(A32)** 能耗/时间/风险模型为上界单调估计。则
```
P(navigation success) ≥ 1 - δ_μ - δ_sw - δ_b - P((E,T_nav,R) ∉ budget)
```
其中 `δ_b` 为信念鲁棒约束的违反概率。直觉：导航成功 = 提升存在 × 切换可容许 × 预算内 × 信念未漂出保护球；四项各自有保守界，故总失败概率被其和上界。

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：把导航建模为“地形基底上的模式-动作提升”并把切换证书化，能把轮足机器人的模式选择从经验调参变成可验证契约，但其 soundness **同时依赖模式-地形胜任度的保守校准、切换瞬态的反例完备、以及地形信念漂移的有界**；一旦仿真高估了轮式在湿滑/松软边界的胜任度，或切换验证漏掉一个接触瞬态反例，导航证书就会以“能量最优”的名义把机器人自信地送进它实际无法提升的地形，故必须以 **保守下置信界 + 切换反例库 + 最坏信念提升** 三重护栏，宁可多切一次足式、多花一档能量，也不把“地图可走”误当成“模式可执行”。

| `A_nav = ⊔_{τ∈T} A_τ` | 地形索引的导航动作空间（移动性纤维） |
| `π: A_nav → T` | 到地形基底的投影 |
| `μ(τ,m,u)` | 模式 m 在地形 τ 上执行 u 的胜任度 |

| `M_cert=(τ_core,m*,μ_min,E_max,N_ev)` | 移动性证书 |
| `γ̃=(γ(t),m(t),u(t))` | 地形路径 γ 的可执行提升 |

### IP-121 MTA

```python
def build_mode_terrain_atlas(traj_db, terrains, modes, alpha=0.1):
    stats = defaultdict(list)
    for tr in traj_db:
        for seg in tr.segments:
            t = terrain_label(seg, terrains)
            stats[(t, seg.mode)].append(seg.success)
    mu, support = {}, {}
    for (t, m), xs in stats.items():
        mu[(t, m)] = clopper_pearson_lower(xs, alpha)   # 保守下置信界
        support[(t, m)] = len(xs)
    return MobilityAtlas(mu, support, alpha)
```

### IP-122 MLS

```python
def mobility_lift_search(terrain_path, atlas, switch_model, budget):
    open_set = [(0.0, 0, None, (0.0, 0.0, 0.0))]
    frontier = []
    while open_set:
        _, i, m_prev, cost = heappop(open_set)
        if i == len(terrain_path):
            frontier.append(cost); continue
        tau = terrain_path[i]
        for m in MODES:
            if atlas.mu_rho(tau, m) < atlas.mu_min:
                continue
            seg_cost = estimate_segment(tau, m, budget)
            if m_prev is not None and m_prev != m:
                s_cert = verify_switch(m_prev, m, tau, switch_model)
                if not s_cert.admissible:
                    continue
                seg_cost = add_switch_cost(seg_cost, s_cert)   # 预留 z_sw
            heappush(open_set, (dominance_key(cost+seg_cost), i+1, m, cost+seg_cost))
    return pareto_prune(frontier)
```

### IP-123 SVE

```python
def verify_switch(m, m2, terrain, dynamics, n_samples=256):
    outcomes = [simulate_switch(dynamics, m, m2, terrain, rng)
                for _ in range(n_samples)]
    fails = [o for o in outcomes if o.unstable or o.slip > P_MAX]
    if fails:
        return ('reject', min_counterexample(fails))
    s_cert = estimate_cert(outcomes)
    ok = (s_cert.t_sw <= TAU_SW and s_cert.l_sw <= L_AVAIL
          and s_cert.s_margin >= S_MIN and s_cert.p_slip <= P_MAX)
    return ('ok', s_cert) if ok else ('reject', s_cert)
```

### IP-124 NCE

```python
def navigation_certificate(plan, atlas, switch_certs, belief, eps_b, budget):
    if not lift_exists(plan, atlas):
        return ('reject', 'no_lift')
    if any(not c.admissible for c in switch_certs):
        return ('reject', 'switch_infeasible')
    if not belief_robust_success(plan, belief, eps_b, atlas) >= 1 - budget.delta:
        return ('reject', 'belief_risk')
    E, T_nav, R = aggregate(plan)
    if E > budget.E_max or T_nav > budget.T_max or R > budget.R_max:
        return ('reject', 'budget_exceeded', (E, T_nav, R))
    return ('ok', N_cert(atlas.M_cert, switch_certs, E, T_nav, R,
                         rho_nav=project_robustness(plan),
                         b_tau=belief, frontier=pareto_front(plan)))
```

### IP-125 BRC

```python
def belief_robust_lift(terrain_path, belief, eps_b, atlas, budget):
    worst = worst_case_terrain(belief, eps_b)             # TV 球内最坏分配
```

### IP-126 OMC

```python
def online_mode_calibration(atlas, residuals, eta, version):
    for (tau, m), r in residuals.items():                 # r = obs - pred
        delta = eta * sign(r.energy) + eta * sign(r.slip)
        atlas.mu[(tau, m)] = project_interval(atlas.mu[(tau, m)] - delta)
        atlas.support[(tau, m)] += 1
    atlas.version = bump(version)
    return atlas
```

```python
def build_composition_graph_v2(skills, theta_a, switch_model):
    G = nx.DiGraph()
    for s1, s2 in ordered_pairs(skills):
        inter = jaccard(s1.alpha, s2.alpha)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MTA | O(N_seg·\|T\|·\|M\|) | O(\|T\|·\|M\|) | 保守下界，覆盖率 ≥ 90% |
| MLS | O(\|T_seg\|·\|M\|·\|U\|·log) | O(\|T_seg\|·\|M\|) | 提升完备，Pareto 前沿不丢点 |
| SVE | O(N_samples·H_switch) | O(N_samples) | 反例 sound，误收 ≤ 3% |
| NCE | O(\|P\|·\|𝔇_ρ\|+F) | O(\|P\|+F) | 预算闭合，四条件合取 |
| BRC | O(\|T_seg\|·\|M\|·\|U\|·\|B\|) | O(\|T_seg\|·\|M\|) | 最坏信念下仍 sound 或降级 |
| OMC | O(\|T\|·\|M\|) / 更新 | O(\|T\|·\|M\|) | 残差有界，版本单调 |

**正确性定理（Liftable Navigation Soundness）**
承接 (A22)–(A28)；新增：**(A29)** `μ_ρ` 为保守校准下置信界，真实覆盖率 `≥1-δ_μ`；**(A30)** SVE 切换验证对反例 sound，误收率 `≤δ_sw`；**(A31)** 地形信念 TV 漂移 `≤ε_b` 且地图分段完整覆盖路径；**(A32)** 能耗/时间/风险模型为上界单调估计。则
```
P(navigation success) ≥ 1 - δ_μ - δ_sw - δ_b - P((E,T_nav,R) ∉ budget)
```
其中 `δ_b` 为信念鲁棒约束违反概率。关键：**先证提升存在，再证切换可容许，再证最坏信念不越界，最后才谈能耗最优**；顺序不可交换，否则“最优”只是对错误地形的精确解。

## 6. 本轮最大风险

**一句话**：把导航建模为“地形基底上的模式-动作提升”并把切换证书化，能把轮足机器人的模式选择从经验调参变成可验证契约，但其 soundness **同时依赖模式-地形胜任度的保守校准、切换瞬态的反例完备、以及地形信念漂移的有界**；一旦仿真高估了轮式在湿滑/松软边界的胜任度，或切换验证漏掉一个接触瞬态反例，导航证书就会以“能量最优”的名义把机器人自信地送进它实际无法提升的地形，故必须以 **保守下置信界 + 切换反例库 + 最坏信念提升** 三重护栏，宁可多切一次足式、多花一档能量，也不把“地图可走”误当成“模式可执行”。
