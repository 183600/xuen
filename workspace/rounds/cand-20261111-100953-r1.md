# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮（新循环）；本轮灵感：「意图识别」×「对比实验」）

> 第 54 轮把技能组合建立在动作空间剖面 `α_S`、组合图 `G_S` 与云边联合证书 `J` 上。但该体系隐含一个从未被检验的前提：**任务 T 是正确、唯一且已给定的**。真实交互中，`T` 只是潜在意图 `I` 的一个带噪、不完整观测；系统先"猜"一个 `T`，再为它签发证书，冲突时再解释——这在意图歧义下会产生"证书正确、对象错误"的系统性失效。本轮把 **意图识别** 重写为**决策相关消歧**，把 **对比实验** 重写为**一种需要自身安全证书、可购买信息的动作**，并用 anytime-valid 证据控制停止偏差。核心矛盾：H22（单意图证书在歧义下不 sound）、H23（对比实验的安全/成本未被现有证书覆盖）、H24（意图空间开放，有限假设集必然漏检）。

## 0. 直觉与动机

**灵感 1（意图识别 = 决策相关消歧，而非分类精度）**
直觉：用户说"把那个拿过来"时，系统不需要知道"那个"的全部语义，只需要知道**哪些意图会导致不同的可部署计划**。如果两个意图最终都选中同一个已认证计划，区分它们毫无价值。把意图空间按"计划等价类"做商，意图识别的目标就不是识别 `I`，而是把商空间压到单点。这把意图识别从"多分类准确率"变成"决策风险下降"，也直接砍掉大量无用的对比实验。

**灵感 2（对比实验 = 用动作购买信息的证书行为）**
直觉：对比实验不是被动的问句，而是一段真实动作序列 `e`（转头看一眼、轻推一下、换个抓取位），它会改变世界、消耗时间、也可能失败。因此 `e` 必须先用第 54 轮的 `J` 证书证明**对所有可信意图都安全**，再谈信息增益。对比实验于是成为"动作空间里的探针"，其选择是**安全约束下的信息购买**，而不是自由的信息论游戏。

**灵感 3（意图感知证书 = 对歧义集承诺，而非对单点承诺）**
直觉：证书不该写"若 `T` 是 A 则成功"，而应写"对可信集 `ℐ_α` 内的**每一个**意图，要么计划都成立，要么系统明确弃权/继续实验"。这把"猜错"从静默失败变成可审计的三种输出：`resolved / robust / abstain`。弃权不是失败，而是证书体系诚实性的体现。

**灵感 4（对比实验的统计 = anytime-valid，而非固定 p 值）**
直觉：对比实验是"看够了就停"，停时点本身依赖数据；若用固定样本量的 t 检验/p 值，可选停止会让第一类错误膨胀。正确工具是 e-value / 置信序列：每次实验后乘上似然比，证据超过 `1/α` 才拒绝，任意停止时刻都保持错误率 `≤ α`。这把"对比实验"从一次性 A/B 升级为**可随时停、可跨轮累积**的证据账本。

**灵感 5（意图-对比层的金字塔扩展）**
直觉：在第 54 轮动作层 `𝔸` 之上加一层意图层 `𝕀`：`𝕀_0` 多模态观测，`𝕀_1` 意图信念 `b`，`𝕀_2` 决策商 `Q`，`𝕀_3` 对比实验协议。跨层证书同时携带 `(J, b, ℐ_α, Q, e_ev)`：动作层保证"做得到"，意图层保证"做的是对的事"。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（意图信念与可信集）**
直觉：意图是隐变量，我们只拥有它的后验，且必须为后验的"漏检"留出概率预算。
设潜在意图 `I ∈ ℐ`，多模态观测史 `o_{1:t}`，信念 `b_t(I)=P(I|o_{1:t})`。可信集 `ℐ_α(b_t)` 为满足 `Σ_{I∈S} b_t(I) ≥ 1-α` 的最小集合（按后验降序取）。校准条件：`P(I* ∈ ℐ_α) ≥ 1-α`，其中 `I*` 为真实意图。开放世界下 `ℐ` 可能不完备，故另设开放集守卫分数 `ood_t ∈ [0,1]`。

**定义 122（决策相关意图商）**
直觉：只在"会改变计划"的维度上区分意图。
设规划映射 `Π: ℐ → Plans ∪ {⊥}`，`⊥` 表示无可行计划。定义等价关系 `I ≈_Π I'` 当且仅当 `Π(I)=Π(I')` 且两者证书签名 `sig(J)` 相同。商空间 `Q = ℐ_α / ≈_Π`，分辨率 `res = |Q|`。**决策相关意图识别**即通过观测/实验把 `res` 降到 1；若只能降到 `res>1`，则必须给出对所有单元都成立的鲁棒计划或弃权。

**定义 123（对比实验）**
直觉：实验是"能改变后验、且自身安全的动作"，其价值按决策风险下降而非纯信息量计。
对比实验 `e = (A_e, 𝒴_e, c_e, Safe_e)`：`A_e ⊆ A` 为动作序列（承接定义 115），`𝒴_e` 为结果空间，`c_e` 为执行成本，`Safe_e` 为安全谓词。结果 `Y_e ~ P(·|I,e)`。信息增益 `IG(e|b)=I(I;Y_e|e)=H(b)-E_{Y_e}[H(b|Y_e,e)]`；决策增益 `DG(e|b)=R(b;Π)-E_{Y_e}[R(b|Y_e;Π)]`，其中 `R(b;Π)=Σ_I b(I)(1-succ(Π(I),I))`。选择分数 `score(e)=DG(e|b)/c_e`。安全约束：`Safe_e=1 ⇔ ∀I∈ℐ_α, J(Π_e,I)` 有效，即实验本身被第 54 轮证书覆盖。

**定义 124（意图感知证书）**
直觉：一张证书要么覆盖整个可信集，要么明确写下"我还不确定"。
意图感知证书 `J_I = (J, b, ℐ_α, Q, res, D_ev, e_ev, δ_I, ood)`，其中 `J` 为第 54 轮联合证书，`D_ev` 为对比实验证据账本，`e_ev` 为 anytime-valid 证据过程，`δ_I` 为意图相关失败预算。`J_I` **有效**当且仅当：
```
(i)  ∀ q∈Q, ∀ I∈q: J 对 Π(I) 有效（逐单元 soundness）；
(ii) res=1，或存在鲁棒计划 π_R 使 max_{I∈ℐ_α}(1-succ(π_R,I)) ≤ δ_I；
(iii) e_ev 为有效 e-value/置信序列，且在停止时刻未越界；
(iv) ood ≤ θ_ood（开放集守卫未报警）。
```
部署条件：`(i)∧(iii)∧(iv) ∧ (res=1 ∨ π_R 存在)`；否则输出 `abstain` 或继续执行 `CEDP`。

**定义 125（对比实验规划问题）**
直觉：在"实验成本 + 部署风险"之间做预算分配，且必须边做边停。
```
min_{e_1,...,e_k, τ}  E[ Σ_{k<τ} c(e_k) + λ·(1-succ(π_τ,I*)) ]
s.t.  Safe_{e_k}=1 ∀k<τ;  Σ c(e_k) ≤ B;  τ = min{k: res(Q_k)=1 ∨ π_R feasible}
```
这是带安全约束的信念空间自适应规划（POMDP）；当 `DG` 关于实验集满足自适应子模性时，贪心 `DG/c` 有 `(1-1/e)` 近似保证（命题 2）。

**定义 126（意图诱导鲁棒性缺口）**
直觉：不同意图会让同一技能落在不同鲁棒性区域，这个差异必须显式记账。
`ρ_d(I)` 为意图 `I` 下维度 `d` 的鲁棒性谱，`G_I = max_{I,I'∈ℐ_α} ||ρ(I)-ρ(I')||_∞`，`Δ_int(d)=G_I(d)`。若 `Δ_int(d) > Θ_ρ(d)`，则单意图鲁棒性证书不可外推到可信集，必须实验或弃权。

## 2. 关键算法 伪代码

### IP-121 IBS（Intent Belief State）

```python
def credible_set(b, alpha=0.05):
    items = sorted(b.items(), key=lambda kv: -kv[1])
    out, mass = [], 0.0
    for I, p in items:
        out.append(I); mass += p
        if mass >= 1 - alpha:
            break
    return frozenset(out)

def update_belief(b, o, H, ood_model, alpha=0.05):
    post = {I: b[I] * H[I].likelihood(o) for I in b}
    z = sum(post.values())
    b = {I: v / z for I, v in post.items()} if z > 0 else b
    return BeliefState(b, credible_set(b, alpha), ood_model.score(o))
```

### IP-122 DRQ（Decision-Relevant Quotient）

```python
def decision_quotient(I_alpha, planner, cert):
    cells = {}
    for I in I_alpha:
        pi = planner(I)
        sig = ('abstain',) if pi is None else (pi.id, cert.signature(pi, I))
        cells.setdefault(sig, []).append(I)
    return [frozenset(v) for v in cells.values()]

def resolution(quotient):
    return len(quotient)            # res = 1 表示决策等价类唯一
```

### IP-123 CEDP（Comparative Experiment Design & Planning）

```python
def plan_experiments(b, quotient, experiments, budget, shield, alpha=0.05):
    plan, spent, cells = [], 0.0, quotient
    while resolution(cells) > 1 and spent < budget:
        scored = []
        for e in experiments:
            if not shield.certifies_all(e, b.I_alpha):   # 安全先于信息
                continue
            if e.cost > budget - spent:
                continue
            dg = expected_decision_gain(e, b, cells, policy=planner)
            scored.append((dg / max(e.cost, eps), dg, e))
        if not scored:
            break
        _, dg, e = max(scored, key=lambda t: t[0])
        if dg <= 0:                                       # 信息已无决策价值
            break
        plan.append(e); spent += e.cost
        # 在线执行后：b, cells = update_belief(...), decision_quotient(...)
    return plan, spent, cells

def expected_decision_gain(e, b, cells, policy):
    r0 = expected_risk(b, cells, policy)
    return r0 - sum(P(y | e, b) * expected_risk(update(b, e, y), cells, policy)
                    for y in e.outcomes)
```

### IP-124 IAC（Intent-Aware Certificate）

```python
def intent_aware_certificate(J, b, planner, cert, delta_I, theta_ood):
    if b.ood > theta_ood:
        return ('abstain', 'open_world', b.ood)
    Q = decision_quotient(b.I_alpha, planner, cert)
    if len(Q) == 1:
        I0 = next(iter(Q[0]))
        return ('deploy', certify(J, planner(I0), I0, delta_I))
    pi_R = robust_plan(Q, planner)                        # 跨单元取交集/最坏情况
    if pi_R is not None and worst_case_failure(pi_R, b.I_alpha) <= delta_I:
        return ('deploy_robust', certify(J, pi_R, b.I_alpha, delta_I))
    return ('need_experiment', Q)
```

### IP-125 CECR（Comparative Evidence Certificate，anytime-valid）

```python
def e_value_update(e_val, y, e, H0, H1, eps=1e-12):
    lr = H1.likelihood(y, e) / max(H0.likelihood(y, e), eps)
    return e_val * lr

def anytime_stop(e_val, alpha=0.05):
    return e_val >= 1.0 / alpha        # 可选停止下仍控制第一类错误
```

### IP-126 IOG（Intent Open-set Guard）

```python
def open_set_guard(obs, ood_model, conformal_p, theta_ood, theta_p=0.05):
    score = ood_model.score(obs)
    p = conformal_p(score)
    if score >= theta_ood or p <= theta_p:
        return ('abstain', 'out_of_distribution', score, p)
    return ('ok', score, p)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IBS | O(|ℐ|·|𝒴|) | O(|ℐ|) | 似然校准、可信集覆盖率 |
| DRQ | O(|ℐ_α|·(plan+cert)) | O(|ℐ_α|) | 计划签名稳定、证书可比较 |
| CEDP | O(k·|ℰ|·|ℐ_α|·|𝒴|) | O(|ℰ|·|ℐ_α|) | 安全过滤 sound、DG 自适应子模 |
| IAC | O(|Q|·cert) | O(|Q|+|ℐ_α|) | 逐单元 sound、鲁棒计划覆盖 |
| CECR | O(k·|𝒴|) | O(k) | e-value 有效、可选停止合法 |
| IOG | O(1) 增量 | O(1) | 共形覆盖、OOD 漏检受控 |

**正确性定理（Intent-Aware Comparative Certification Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 信念校准：`P(I*∈ℐ_α) ≥ 1-α`；**(A30)** 在 `ℐ_α` 上意图空间闭合（真实意图未被漏掉）；**(A31)** 每个被执行的对比实验 `e` 均通过 `J` 证书且动作被 `α_S` 覆盖，安全盾无假阴性；**(A32)** 证据过程 `e_ev` 为有效 e-value（`E[e_ev|H0] ≤ 1`），允许可选停止；**(A33)** 每单元计划认证失败概率 `≤ δ`。
则：
```
P(部署后失败) ≤ α + δ + β_ood + β_ev
```
其中 `β_ood` 为开放集守卫漏检率，`β_ev` 为证据过程失效概率。若预算耗尽仍未消歧，则系统输出 `abstain`，不产生"沉默失败"；因此上式约束的是**所有已部署**的轮次。

**命题 1（决策商的实验下界优势）**
在无噪、存在完美二元区分实验的设定下，把 `res` 降到 1 至少需要 `⌈log2 |Q|⌉` 次实验；若直接做完整意图分类则需 `⌈log2 |ℐ_α|⌉` 次。当 `|Q| ≪ |ℐ_α|` 时可任意倍数节省。

**命题 2（贪心近优）**
若决策增益 `DG` 关于实验集自适应子模、成本模块可加，则安全过滤后的贪心 `DG/c` 达到最优期望决策增益的 `(1-1/e)` 近似；安全盾仅收缩可行域，不破坏子模性。

## 4. 实验设计 E162–E168

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 意图后验校准 | ECE、`ℐ_α` 覆盖率 | ECE ≤ 0.05，覆盖率 ≥ 1-α |
| E163 决策商效率 | 达到 `res=1` 的实验数 vs 全分类 | 实验数下降 ≥ 50% |
| E164 意图感知证书有效性 | 歧义下部署失败率 vs 单意图证书 | 失败率 ≤ α+δ+β，且显著低于基线 |
| E165 对比实验安全性 | 不安全实验比例、成本开销 | 不安全率 = 0，成本开销 ≤ 15% |
| E166 开放世界压力 | OOD 弃权召回、误自信率 | 召回 ≥ 90%，误自信 ≤ 5% |
| E167 对比实验（研究层） | 配对风险差、95% CI、效应量 | 相对 4 个基线显著更优 |
| E168 消融 | 去 DRQ / 去安全盾 / 去 e-value / 去 IOG | 各组件贡献可分离且显著 |

**E167 对比实验协议（把"对比实验"也做成可审计的研究方法）**
- 预注册 H22–H24 与主指标（歧义下部署失败率），次指标（实验数、弃权率、成本）；
- 配对场景：同一场景种子、同一初始状态，系统间做配对差，报告均值差与 95% CI；
- 基线：B1 顶-1 意图+单意图证书；B2 主动澄清问句（用户回答）；B3 随机安全实验；B4 全意图枚举/分类；B5 本轮 `DRQ+CEDP+CECR`；
- 统计：自适应停止用 anytime-valid e-value，消融用 Holm–Bonferroni 校正，报告效应量（风险差/Cohen's h）与最小可检测效应；
- 负结果也算结果：若 `|Q|≈|ℐ_α|` 导致无节省，则说明决策商假设在该域不成立。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 意图空间不闭合/开放世界 | 高 | 共形可信集 + OOD 守卫 + 强制弃权 + 人工澄清回退 |
| 后验校准漂移 | 高 | 温度缩放 + 在线重校准 + 覆盖率监控 |
| 对比实验安全与信息冲突 | 高 | 安全盾先行 + 受限贝叶斯优化 + 不可证书则换实验 |
| 实验预算耗尽 | 中 | 预算化停止 + 鲁棒计划兜底 + 明确 abstain |
| 可选停止/多重比较偏差 | 中 | e-value/置信序列 + 预注册 + Holm 校正 |
| 决策商计算爆炸 | 中 | 计划签名哈希 + 分层聚类 + 廉价代理规划 |

## 6. 本轮最大风险

**一句话**：把意图识别改写成"决策商消歧 + 安全对比实验"能显著减少无效实验并让证书诚实，但其 soundness **首先依赖 `ℐ_α` 真的包含真实意图**；一旦意图空间开放而开放集守卫又漏检，系统会在一个自洽但错误的假设集上把 `res` 压到 1，并用对比实验不断自我确认，形成"越实验越自信"的回音室，故必须以 **共形可信集 + OOD 守卫 + 弃权优先 + 外部澄清** 作为不可省略的前置护栏，宁可 `abstain`，也绝不把"商空间单点"误当作"意图已被识别"。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（IBS×DRQ×CEDP×IAC×CECR×IOG）

> 承接第 54 轮产物 v31。第 54 轮解决了"技能在动作空间里能否组合、云边能否对齐"；本轮补上被长期默认的前提——**任务/意图本身是正确且唯一的**。新增六个算子：
> - **IBS（Intent Belief State）**：意图后验与可信集，显式保留"可能猜错"的概率预算；
> - **DRQ（Decision-Relevant Quotient）**：按"是否改变可部署计划"对意图做商，识别目标从分类精度改为决策风险；
> - **CEDP（Comparative Experiment Design & Planning）**：安全约束下按决策增益/成本选择对比实验；
> - **IAC（Intent-Aware Certificate）**：对可信集逐单元签发的意图感知证书；
> - **CECR（Comparative Evidence Certificate）**：anytime-valid 的 e-value 证据账本，合法支持"看够就停"；
> - **IOG（Intent Open-set Guard）**：开放世界 OOD 守卫与弃权，防止在错误假设集上自我确认。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/116/118/120 以纳入意图维度。体系命名 `GroundEdge-GenSim++++`，意图-对比子体系简称 **IntentComp**。

**与既有 IP 的关系**
- IP-115（ACS）升级为**意图条件动作剖面** `α_S(·|I)`：同一技能在不同意图下的动作占用可不同；
- IP-116（SCOM）升级为**意图条件组合图** `G_S(I)`：兼容性阈值随意图变化；
- IP-118（AEC）升级为 `J(I)`：联合证书按意图单元签发；
- IP-120（JTC）升级为**意图-动作联合迁移**：迁移证书需同时声明源/目标意图集与 `Δ_int`。

## 2. 关键算法 伪代码

### IP-121 IBS

```python
def credible_set(b, alpha=0.05):
    out, mass = [], 0.0
    for I, p in sorted(b.items(), key=lambda kv: -kv[1]):
        out.append(I); mass += p
        if mass >= 1 - alpha:
            break
    return frozenset(out)

def update_belief(b, o, H, ood_model, alpha=0.05):
    post = {I: b[I] * H[I].likelihood(o) for I in b}
    z = sum(post.values())
    b = {I: v / z for I, v in post.items()} if z > 0 else b
    return BeliefState(b=b, I_alpha=credible_set(b, alpha),
                       ood=ood_model.score(o))
```

### IP-122 DRQ

```python
def decision_quotient(I_alpha, planner, cert):
    cells = {}
    for I in I_alpha:
        pi = planner(I)
        sig = ('abstain',) if pi is None else (pi.id, cert.signature(pi, I))
        cells.setdefault(sig, []).append(I)
    return [frozenset(v) for v in cells.values()]

def res(quotient):
    return len(quotient)
```

### IP-123 CEDP

```python
def expected_decision_gain(e, b, cells, planner):
    r0 = expected_risk(b, cells, planner)
    r1 = sum(P(y | e, b) * expected_risk(update(b, e, y), cells, planner)
             for y in e.outcomes)
    return r0 - r1

def plan_experiments(b, cells, experiments, budget, shield, planner):
    plan, spent = [], 0.0
    while res(cells) > 1 and spent < budget:
        cand = []
        for e in experiments:
            if not shield.certifies_all(e, b.I_alpha):   # 安全先于信息
                continue
            if e.cost > budget - spent:
                continue
            dg = expected_decision_gain(e, b, cells, planner)
            cand.append((dg / max(e.cost, 1e-12), dg, e))
        if not cand:
            break
        _, dg, e = max(cand, key=lambda t: t[0])
        if dg <= 0:
            break
        plan.append(e); spent += e.cost
        # 执行后：b = update_belief(...); cells = decision_quotient(...)
    return plan, spent, cells
```

### IP-124 IAC

```python
def intent_aware_certificate(J, b, planner, cert, delta_I, theta_ood):
    if b.ood > theta_ood:
        return ('abstain', 'open_world', b.ood)
    Q = decision_quotient(b.I_alpha, planner, cert)
    if len(Q) == 1:
        I0 = next(iter(Q[0]))
        return ('deploy', certify(J, planner(I0), I0, delta_I))
    pi_R = robust_plan(Q, planner)
    if pi_R is not None and worst_case_failure(pi_R, b.I_alpha) <= delta_I:
        return ('deploy_robust', certify(J, pi_R, b.I_alpha, delta_I))
    return ('need_experiment', Q)

def deployable(outcome):
    return outcome[0] in ('deploy', 'deploy_robust')
```

### IP-125 CECR

```python
def e_value_update(e_val, y, e, H0, H1, eps=1e-12):
    return e_val * (H1.likelihood(y, e) / max(H0.likelihood(y, e), eps))

def anytime_stop(e_val, alpha=0.05):
    return e_val >= 1.0 / alpha      # 可选停止下仍控制 FWER ≤ alpha

def cell_evidence(records, alpha=0.05):
    # 多单元：对每对相邻单元做 e-value，阈值用 alpha/|Q| 的 Holm 式分配
    return {pair: e_value_update(1.0, **r) for pair, r in records.items()}
```

### IP-126 IOG

```python
def open_set_guard(obs, ood_model, conformal_p, theta_ood, theta_p=0.05):
    score = ood_model.score(obs)
    p = conformal_p(score)
    if score >= theta_ood or p <= theta_p:
        return ('abstain', 'out_of_distribution', score, p)
    return ('ok', score, p)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IBS | O(|ℐ|·|𝒴|) | O(|ℐ|) | 似然校准，`ℐ_α` 覆盖 `≥1-α` |
| DRQ | O(|ℐ_α|·(plan+cert)) | O(|ℐ_α|) | 签名稳定，商等价类划分 sound |
| CEDP | O(k·|ℰ|·|ℐ_α|·|𝒴|) | O(|ℰ|·|ℐ_α|) | 安全过滤 sound，自适应子模 `(1-1/e)` |
| IAC | O(|Q|·cert + |ℐ_α|) | O(|Q|+|ℐ_α|) | 逐单元 sound，鲁棒计划覆盖可信集 |
| CECR | O(k·|𝒴|) | O(k) | e-value 有效，可选停止合法 |
| IOG | O(1) 增量 | O(1) | 共形覆盖，OOD 漏检 `≤β_ood` |

**正确性定理（Intent-Aware Comparative Certification Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `P(I*∈ℐ_α) ≥ 1-α`；**(A30)** `ℐ_α` 上意图空间闭合；**(A31)** 每个对比实验 `e` 均通过 `J` 证书且动作覆盖，安全盾无假阴性；**(A32)** `e_ev` 为有效 e-value，允许可选停止；**(A33)** 每单元计划认证失败率 `≤ δ`。则
```
P(部署后失败) ≤ α + δ + β_ood + β_ev
```
且预算耗尽时系统 `abstain`，故上式覆盖所有**实际部署**轮次。

**命题 1（决策商下界）**
无噪且存在完美二元区分实验时，`⌈log2 |Q|⌉ ≤ #experiments ≤ ⌈log2 |ℐ_α|⌉`；若 `|Q| ≪ |ℐ_α|`，相对全分类可任意倍数节省。

**命题 2（贪心近优）**
`DG` 自适应子模、成本模块可加时，安全过滤后贪心 `DG/c` 达到最优期望决策增益的 `(1-1/e)` 近似；安全盾只收缩可行域。

**命题 3（弃权诚实性）**
若 `ood > θ_ood` 或无可证书鲁棒计划，`IAC` 必输出 `abstain`；因此"沉默失败"只能来自 `β_ood` 漏检，而不能来自证书逻辑本身。

## 4. 实验设计与对比实验协议 E162–E168

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 意图后验校准 | ECE、可信集覆盖率 | ECE ≤ 0.05，覆盖率 ≥ 1-α |
| E163 决策商效率 | `res=1` 所需实验数 vs 全分类 | 实验数下降 ≥ 50% |
| E164 意图感知证书 | 歧义下部署失败率 vs 单意图证书 | ≤ α+δ+β_ood，显著优于基线 |
| E165 实验安全性 | 不安全实验率、成本开销 | 0 不安全；开销 ≤ 15% |
| E166 开放世界压力 | OOD 弃权召回、误自信率 | 召回 ≥ 90%，误自信 ≤ 5% |
| E167 研究层对比实验 | 配对风险差、95% CI、效应量 | 相对 B1–B4 显著更优 |
| E168 消融 | 去 DRQ / 安全盾 / e-value / IOG | 各组件贡献可分离 |

**E167 预注册对比实验协议**
1. **假设**：H22 单意图证书在歧义下不 sound；H23 安全约束会改变最优实验序；H24 决策商比全分类更省实验。
2. **设计**：配对场景（同种子/同初始状态），B5=`DRQ+CEDP+CECR` vs B1 顶-1 意图+单意图证书、B2 主动澄清问句、B3 随机安全实验、B4 全意图枚举。
3. **主指标**：歧义下部署失败率；**次指标**：实验数、弃权率、执行成本、OOD 召回。
4. **统计**：自适应停止用 anytime-valid e-value；消融用 Holm–Bonferroni；报告配对均值差、95% CI、效应量（风险差/Cohen's h）与最小可检测效应；预注册失败即判负结果，不允许事后改指标。

## 6. 本轮最大风险

**一句话**：IntentComp 把"猜任务"变成可审计的决策商消歧与安全对比实验，但其 soundness **首先依赖 `ℐ_α` 真的包含真实意图**；一旦意图开放而 IOG 漏检，系统会在自洽但错误的假设集上把 `res` 压到 1，并用对比实验不断自我确认，形成"越实验越自信"的回音室，故必须以 **共形可信集 + OOD 守卫 + 弃权优先 + 外部澄清** 为不可省略的前置护栏，宁可 `abstain`，也绝不把"商空间单点"误当作"意图已被识别"。
