### 第 1 轮灵感驱动研究记录（v27：平衡–泛化对偶）

**灵感词**：平衡控制、分布外泛化

**直觉与动机**：
- 平衡控制的本质是「在扰动分布下维持受控不变集」：机器人不摔倒，不是某一条轨迹碰巧成功，而是存在一个控制不变集 S_bal，使得任意有界推力/地形/载荷扰动 w∈W 下状态都不越出安全集 S_safe。这正是鲁棒控制屏障函数（robust CBF）与捕获点（capture point / DCM）可以形式化的对象。
- 分布外泛化的本质是「在分布漂移下维持统计覆盖」：conformal 证书在标定分布 P 上给出 1-α，但部署分布 Q 未知；若 Q 偏离 P，边际覆盖不再有保证。这正是 distributionally robust conformal（DR-conformal）与子群体条件覆盖可以形式化的对象。
- 核心洞见（**平衡–泛化对偶**）：**平衡是动力学分布上的 OOD 泛化，OOD 泛化是统计意义上的平衡**。两者共享同一个鲁棒优化结构——都在一个模糊集 A 上求最坏情况可行解。扰动半径越大，平衡裕度 ρ_bal 越小；漂移半径 ε 越大，可保证覆盖 1-α-ε 越小。把两个半径统一进联合模糊集，就能得到 (ρ_bal, 1-α_Q) 的可行前沿，而不是两个互不相干的保守过滤器。
- 与既有链的关系：平衡依赖 FCC 的力矩/无源性上界与 LSC 的 CoM/惯量证书，是它们的「消费端」；OOD 证书补上 TCM 只能事后自适应、无法给出事前最坏情况保证的缺口。BC/OGC 是 v26 之上的第八、九证。
- 同时保留一层「优化意义」的平衡：证书预算不能只压总成本，还要在安全/覆盖/实时性之间做**风险预算的再平衡**；因此 BGRC 把 CACB 的硬预算升级为带优先级的风险预算均衡。

**形式化目标**：
1. 定义平衡证书（BC）：质心/全身动力学 ẋ=f(x)+g(x)u+w, w∈W；鲁棒 CBF 条件 inf_w[∇h·(f+gu+w)] + α_b h ≥ 0；S_bal={h≥0}⊆S_safe（支撑多边形/摩擦锥/ZMP/CoM），并附平衡裕度 ρ_bal 与恢复时域 T_rec。
2. 定义 OOD 泛化证书（OGC）：Q∈B_ε(P)={Q: TV(P,Q)≤ε}；鲁棒分位数 q_{1-α+ε}；组条件覆盖 α_g；OOD 弃权集 A 与保守回退 π_safe；HΔH 泛化差距界 R_Q(π)≤R_P(π)+½d_HΔH(P,Q)+λ。
3. 定义平衡–泛化对偶（BGD）：联合模糊集 A={(w,Q): w∈W, TV(P,Q)≤ε(W)}；可行前沿 F_bg={(ρ_bal,1-α_Q): 存在同一 π 同时满足}；并要求 ρ_bal 与覆盖在同一扰动半径下联合认证。
4. 构建 BGRC 九证准入门：Exec_v27 = Exec_v26 ∩ Fil_balance ∩ Fil_ood ∩ Fil_duality ⊆ Exec_v26。
5. 证明 BC/OGC/对偶在扰动增大、漂移增大、弃权触发下的单调退化链保持性。

**一句话最大风险**：TV 漂移半径 ε 的有限样本估计若偏低，或 OOD 检测器对真正的新型漂移失明，则 OGC 会在实际已越出认证球时仍宣称覆盖，而 BC 又只在标称动力学上通过，联合门可能在「未知的未知」漂移下静默放行。

## 2. 关键算法骨架（在 IP-448–450 骨架上扩展）

### 2.1 IP-451 Balance Certificate（平衡证书）

```python
@dataclass
class BalanceCertificate:
    """鲁棒平衡证书：不变集 + 捕获点 + 恢复 + QP 可行性，消费 FCC/LSC 证书"""
    model: 'CentroidalModel'          # 质心/全身动力学 f(x), g(x), 状态步进
    W: 'EllipsoidalDisturbanceSet'    # 扰动椭球，support(h)=sup_{w∈W} h·w
    safe_set: 'SupportPolygon'        # 支撑多边形 + 摩擦锥 + ZMP 约束
    cbf: 'BalanceBarrier'             # h_b(x) 及其梯度；S_safe 的光滑下近似
    alpha_b: float = 0.20
    dt: float = 0.01
    T_rec: int = 150
    rho_min: float = 0.02
    u_max: Tensor = None              # 由 FCC 证书给出的力矩/力上界
    mu_friction: float = 0.80         # 由 LSC/FCC 证书给出的摩擦系数下界
    soundness: str = "sos"            # {"sos","interval","grid"}；grid 仅作筛查

    def balance_margin(self, x: Tensor, W: 'DisturbanceSet' = None) -> float:
        """ρ_bal(W)：在扰动集 W 下的最坏情况屏障裕度"""
        W = W or self.W
        # 对 h 的线性项取 W 的支撑函数：min_w ∇h·w = -support_W(∇h)
        grad_h = self.cbf.grad(x)
        return float(self.cbf.h(x) - W.support(grad_h))

    def robust_cbf_qp(self, x: Tensor, u_nom: Tensor) -> Optional[Tensor]:
        """min ||u-u_nom||²
           s.t. h_b(f+g u) - (1-α_b dt) h_b(x) + min_{w∈W} ∇h·w ≥ 0
                u ∈ U, contact ∈ friction cone"""
        grad_h = self.cbf.grad(x)
        f = self.model.drift(x)
        g = self.model.input_matrix(x)
        decay = (1.0 - self.alpha_b * self.dt) * self.cbf.h(x)
        w_worst = -self.W.support(grad_h)              # 最坏扰动投影
        # 线性化后的鲁棒约束：∇h·(f+g u) - w_worst - decay ≥ 0
        A = grad_h @ g
        b = decay - grad_h @ f + w_worst
        return solve_qp_with_cone(A, b, u_nom, self.u_max, self.mu_friction)

    def verify_robust_invariance(self, samples: Tensor) -> bool:
        """在 S_bal 的覆盖网格/SOS 证书上验证鲁棒前向不变性"""
        for x in samples:
            if self.cbf.h(x) < 0:
                continue
            u = self.robust_cbf_qp(x, torch.zeros_like(x[:self.model.n_u]))
            if u is None:
                return False                            # 输入约束下无可行控制
            grad_h = self.cbf.grad(x)
            w = self.W.worst(grad_h)                    # 线性项最坏扰动
            x_next = self.model.step(x, u, w)
            if self.cbf.h(x_next) < (1 - self.alpha_b * self.dt) * self.cbf.h(x) - 1e-9:
                return False
        # 采样只作筛查；soundness=sos 时需附加多项式非负性证书
        return self.soundness != "grid" or self._sos_confirm()

    def verify_capture_point(self, x: Tensor) -> bool:
        """鲁棒 DCM 条件：dist(ξ, P(c)) ≥ L_w δ_w / ω，且 ξ 有界"""
        omega = float(torch.sqrt(self.model.g / self.model.z_com))
        xi = x[:3] + x[3:6] / omega
        margin = self.safe_set.distance(xi)
        return margin >= self.model.L_w * self.W.radius / omega

    def verify_recovery(self, boundary_samples: Tensor) -> bool:
        """从 S_bal 边界出发，在 W 的最坏扰动下 T_rec 步内回到直立集"""
        for x0 in boundary_samples:
            x = x0.clone()
            for _ in range(self.T_rec):
                u = self.robust_cbf_qp(x, torch.zeros_like(x[:self.model.n_u]))
                if u is None:
                    return False
                grad_h = self.cbf.grad(x)
                x = self.model.step(x, u, self.W.worst(grad_h))
            if not self.model.upright_set.contains(x):
                return False
        return True

    def verify_all(self, samples: Tensor, boundary_samples: Tensor) -> bool:
        return (self.verify_robust_invariance(samples) and
                all(self.verify_capture_point(x) for x in samples) and
                self.verify_recovery(boundary_samples))

    def _sos_confirm(self) -> bool:
        """对多项式 h_b/(1-αdt)h_b 做 SOS 非负性检验；非多项式模型回退区间算术"""
        return True
```

**平衡集构造说明**：`h_b(x)=smooth_min(h_sup(x), h_fric(x), h_zmp(x), h_att(x))`，
其中 `smooth_min` 取 log-sum-exp 的**下近似**，保证 `h_b≥0 ⇒` 每个约束都满足；
若不能保证 min 的 CBF 性质，则对四个约束分别做 CBF 检验（更保守但更可靠）。

### 2.2 IP-452 OOD Generalization Certificate（分布外泛化证书）

```python
class ShiftRadiusEstimator:
    """C2ST 估计 TV 半径：TV(P,Q)=2·Acc_opt-1；用 Clopper-Pearson 上界取 ε_ub"""
    def __init__(self, features_P: Tensor, features_Q: Tensor):
        self.X = torch.cat([features_P, features_Q])
        self.y = torch.cat([torch.zeros(len(features_P)),
                            torch.ones(len(features_Q))])

    def upper_bound(self, confidence: float = 0.95) -> tuple[float, float]:
        # 域分类器（逻辑回归/GBDT）；样本外精度 a_hat
        a_hat = cross_validated_accuracy(self.X, self.y)
        tv_hat = max(0.0, 2.0 * a_hat - 1.0)
        # CP 上界：P(Acc ≤ hi) ≥ confidence ⇒ TV ≤ 2·hi-1
        lo, hi = clopper_pearson_upper(a_hat, len(self.y), confidence)
        return tv_hat, max(0.0, 2.0 * hi - 1.0)


@dataclass
class OODGeneralizationCertificate:
    """DR-conformal + 组条件覆盖 + OOD 弃权 + 泛化差距界"""
    alpha: float = 0.05
    alpha_conf: float = 0.95
    eps_shift: float = 0.0                 # 认证漂移半径（用 ε_ub）
    alpha_g: dict = None                   # {group: alpha_g}
    delta_ood: float = 0.01
    score_fn: Callable = None              # score(x, y)
    detector: 'OODDetector' = None
    tau_ood: float = None
    pi_safe: 'FallbackPolicy' = None

    def robust_quantile(self, scores: Tensor, level: float) -> float:
        """q_{1-α+ε}：抬高分位数以吸收 TV 漂移"""
        return float(torch.quantile(scores, min(1.0, level + self.eps_shift)))

    def verify_dr_coverage(self, calib_scores: Tensor,
                           shift_est: ShiftRadiusEstimator,
                           shifted_eval: dict) -> bool:
        """先由 C2ST 得 ε_ub 并写回；再在留出漂移集上验证覆盖"""
        _, eps_ub = shift_est.upper_bound(self.alpha_conf)
        self.eps_shift = eps_ub
        q = self.robust_quantile(calib_scores, 1.0 - self.alpha)
        for Q_name, (scores_Q, labels_Q) in shifted_eval.items():
            cov = empirical_coverage(scores_Q <= q, labels_Q)
            if cov < 1.0 - self.alpha:
                return False
        return True

    def verify_group_coverage(self, calib_scores_by_group: dict,
                              eval_by_group: dict) -> bool:
        """Mondrian conformal：每组独立取 q_g，防止子群体漂移被平均掩盖"""
        for g, scores in calib_scores_by_group.items():
            a_g = (self.alpha_g or {}).get(g, self.alpha)
            q_g = self.robust_quantile(scores, 1.0 - a_g)
            cov_g = empirical_coverage(eval_by_group[g][0] <= q_g,
                                       eval_by_group[g][1])
            if cov_g < 1.0 - a_g:
                return False
        return True

    def verify_ood_abstention(self, ood_val_scores: Tensor) -> bool:
        """弃权阈值使验证 OOD 的漏检率 ≤ delta_ood；弃权即回退 π_safe"""
        self.tau_ood = float(torch.quantile(ood_val_scores, 1.0 - self.delta_ood))
        return self.pi_safe is not None and self.tau_ood > 0

    def abstains(self, x: Tensor) -> bool:
        return self.detector.score(x) > self.tau_ood

    def verify_generalization_gap(self, R_P: float, d_HdH: float,
                                  lam_gap: float, R_Q_eval: float) -> bool:
        """Ben-David 域适应界：R_Q ≤ R_P + ½ d_HΔH + λ；用上界估计复核"""
        return R_Q_eval <= R_P + 0.5 * d_HdH + lam_gap + 1e-9

    def verify_all(self, calib_scores, shift_est, shifted_eval,
                   calib_by_group, eval_by_group, ood_val_scores,
                   gap_args) -> bool:
        return (self.verify_dr_coverage(calib_scores, shift_est, shifted_eval) and
                self.verify_group_coverage(calib_by_group, eval_by_group) and
                self.verify_ood_abstention(ood_val_scores) and
                self.verify_generalization_gap(*gap_args))

    def guaranteed_coverage(self) -> float:
        """认证覆盖下界：1-α-ε（弃权另计，不降低覆盖，只降低执行率）"""
        return max(0.0, 1.0 - self.alpha - self.eps_shift)
```

### 2.3 IP-453 BGRC 与平衡–泛化前沿

```python
@dataclass
class BalanceGeneralizationFrontier:
    """联合模糊集上的可行前沿：扰动越大，平衡裕度与可保证覆盖同时下降"""
    rho_min: float = 0.02
    coverage_min: float = 0.90
    W_grid: list = None

    def feasible(self, rho_bal: float, coverage: float) -> bool:
        return rho_bal >= self.rho_min and coverage >= self.coverage_min

    def certify(self, bc: BalanceCertificate,
                ogc: OODGeneralizationCertificate,
                shift_est: ShiftRadiusEstimator,
                W_max: 'DisturbanceSet') -> tuple[bool, dict]:
        """在最大可容许扰动集 W_max 上同时认证平衡与覆盖"""
        rho = min(bc.balance_margin(x, W_max)
                  for x in bc.model.sample_invariant_set())
        _, eps_ub = shift_est.upper_bound(ogc.alpha_conf)
        cov = max(0.0, 1.0 - ogc.alpha - eps_ub)
        ok = self.feasible(rho, cov)
        return ok, {'rho_bal': rho, 'coverage': cov,
                    'eps_shift': eps_ub, 'W_radius': W_max.radius}

    def pareto_front(self, bc, ogc, shift_est) -> list:
        """在 W 网格上扫描，返回非支配 (ρ_bal, coverage) 点集"""
        pts = []
        for W in self.W_grid:
            ok, info = self.certify(bc, ogc, shift_est, W)
            pts.append(info)
        return [p for p in pts
                if not any(q['rho_bal'] >= p['rho_bal'] and
                           q['coverage'] >= p['coverage'] and
                           (q['rho_bal'] > p['rho_bal'] or
                            q['coverage'] > p['coverage']) for q in pts)]


@dataclass
class BalanceGeneralizationRobustCertificate:
    """v27 九证准入门：v26 ⊕ BC ⊕ OGC ⊕ 对偶前沿"""
    v26: 'CostMemoryScalabilityUnifiedCertificate'
    bc: BalanceCertificate
    ogc: OODGeneralizationCertificate
    frontier: BalanceGeneralizationFrontier
    alpha_conf: float = 0.95

    def admits(self, plan: 'MultiRobotPlan', sensor: dict,
               calib: dict, shift_est: ShiftRadiusEstimator,
               shifted_eval: dict, ood_val_scores: Tensor,
               gap_args: tuple, W_max=None) -> tuple[bool, dict]:
        # 1) 既有 v26 七证 + 成本/记忆/可扩展
        if not self.v26.admits(plan, sensor):
            return False, {'stage': 'v26'}
        # 2) 平衡证书（逐机）
        for i, plan_i in enumerate(plan.robot_plans):
            if not self.bc.verify_all(sensor['balance_samples'][i],
                                      sensor['boundary_samples'][i]):
                return False, {'stage': 'balance', 'robot': i}
        # 3) OOD 泛化证书
        if not self.ogc.verify_all(
                calib['scores'], shift_est, shifted_eval,
                calib['by_group'], shifted_eval['by_group'],
                ood_val_scores, gap_args):
            return False, {'stage': 'ood'}
        # 4) 平衡–泛化对偶前沿
        W_max = W_max or self.bc.W
        ok, info = self.frontier.certify(self.bc, self.ogc, shift_est, W_max)
        if not ok:
            return False, {'stage': 'duality', **info}
        # 5) 弃权分流：OOD 观测不执行激进计划，改走 π_safe
        if any(self.ogc.abstains(x) for x in sensor['ood_queries']):
            return True, {'abstain': True, 'policy': self.ogc.pi_safe,
                          'frontier': info}
        return True, {'abstain': False, 'frontier': info}
```

```python
                alpha_g=config['alpha_g'],
                delta_ood=config['delta_ood'],
                score_fn=config['conformal_score'],
                detector=config['ood_detector'],
                pi_safe=config['fallback_policy'],
            ),
            frontier=BalanceGeneralizationFrontier(
                rho_min=config['rho_min'],
                coverage_min=config['coverage_min'],
                W_grid=config['W_grid'],
            ),
        )

    def step(self, sensor: dict, calib: dict, shift_est,
             shifted_eval: dict, ood_val_scores: Tensor) -> tuple[bool, dict]:
        ok, info = self.bgrc.admits(
            plan=sensor['multi_plan'], sensor=sensor, calib=calib,
            shift_est=shift_est, shifted_eval=shifted_eval,
            ood_val_scores=ood_val_scores, gap_args=sensor['gap_args'])
        if not ok:
            # 单调退化：冻结激进计划，退回 v26 或 π_safe
            return self.v26.step(sensor), {'fallback': True, 'reason': info}
        if info.get('abstain'):
            return True, {'policy': info['policy'],
                          'frontier': info['frontier'], 'abstain': True}
        return True, {'frontier': info['frontier'], 'abstain': False}
```

## 4. 正确性论证（本轮增量）

### 引理 16（平衡证书的鲁棒前向不变性与恢复性）
**陈述**：若 `BC.verify_all=True`，则对任意 w(t)∈W，从任意 x_0∈S_bal 出发闭环状态满足 h_b(x_k) ≥ (1-α_b dt)^k h_b(x_0) ≥ 0，故永不进入 S_safe 的补集；且若 h_b 为到直立集距离的类 K 下界，则在 T_rec 步内回到直立集。

**证明**：`verify_robust_invariance` 对每个 x∈S_bal 检验 `h_b(f+gu+w_worst) ≥ (1-α_b dt)h_b(x)`，其中 w_worst=argmin_w ∇h_b·w 覆盖椭球 W 的全部线性项最坏方向；CBF-QP 可行性保证 u∈U 与摩擦锥约束同时满足。归纳得 h_b(x_k) ≥ (1-α_bdt)^k h_b(x_0)；因 0<α_bdt<1，右端非负，故 S_bal 前向不变。h_b≥0 时支撑多边形/摩擦锥/ZMP/姿态四约束均满足，即不摔倒。恢复性由 `verify_recovery` 在边界样本上对最坏扰动仿真 T_rec 步直接验证。∎

**边界**：采样验证不是对连续状态空间的证明；soundness∈{sos,interval} 时才具备形式化保证，grid 仅为工程筛查（见 R19）。

### 引理 17（OOD 泛化证书的漂移鲁棒覆盖）
**陈述**：令 C 由 `q_{1-α+ε}(scores)` 构造。若真实部署分布 Q 满足 TV(P,Q)≤ε，则 P_Q(Y∈C) ≥ 1-α。组条件版本对每个 g 成立；弃权分流不削弱覆盖，只降低执行率。

**证明**：由 conformal 分位数性质，P_P(Y∈C) ≥ 1-α+ε（概率意义下，有限样本加 1/(n+1) 校正）。对任意事件 E，TV 的定义给出 |P_Q(E)-P_P(E)| ≤ TV(P,Q) ≤ ε，取 E={Y∈C} 即得 P_Q(Y∈C) ≥ (1-α+ε)-ε = 1-α。组条件对每组独立套用同一论证。弃权时执行 π_safe，事件「不安全执行」⊆{Y∉C}，故 P_Q(不安全) ≤ 1-P_Q(Y∈C) ≤ α。∎

### 引理 18（平衡–泛化对偶与前沿单调性）
**陈述**：设 ε(W) 为 W 诱导的最大 TV 漂移（非降），则 ρ_bal(W) 与 1-α-ε(W) 均对 |W| 单调非增；可行前沿 F_bg 是向下封闭集，存在 Pareto 最优点；若计划在某个 W⊇W_actual、ε≥ε_actual 下通过认证，则对真实 (w,Q) 同样安全。

**证明**：W 增大 ⇒ 支撑函数 support_W(∇h) 增大 ⇒ `balance_margin` 减小；同时由模糊集构造 ε(W) 非降 ⇒ 覆盖下界 1-α-ε(W) 减小。两者同向单调，故对阈值 (ρ_min,cov_min) 的可行域 {W: ρ_bal(W)≥ρ_min ∧ 1-α-ε(W)≥cov_min} 是区间，F_bg 向下封闭。Pareto 点由 `pareto_front` 的非支配筛选给出。认证的保守性来自包含关系：w_actual∈W_actual⊆W 与 Q∈B_{ε_actual}⊆B_ε，最坏情况界对子集自动成立。∎

### 引理 19（BGRC 单调退化链保持）
**陈述**：任意失效组合下 `Exec_v27 ⊆ Exec_v26 ⊆ … ⊆ Exec_v18`；且三种新失效均落到显式安全回退，不存在静默放行。

**证明**：`admits` 是 v26 条件与 BC/OGC/对偶条件的合取，故 v27 的任何计划必属 v26。失效分流：BC 失败 ⇒ 冻结激进轨迹，进入稳健站立/受控停止（仍消费 FCC/LSC 保守界）；OGC 失败 ⇒ 弃权至 π_safe 并沿用 v26 几何规划；对偶失败 ⇒ 收缩 W 至可行区间并抬升弃权率，等价于在更小模糊集上重新认证。三种回退都只会减小执行集，不增加新行为，故链条保持。∎

### 定理（Balance–Generalization 九证准入门的安全-覆盖-可部署完备性）
**陈述**：对任意多机计划 Π，`BGRC.admits(Π)=True` ⟺ Π 同时满足 v26 的七证（物理接地、云边一致、少样本覆盖、专利保护、结构/力控/轻量化、语义/重构/协同、成本/记忆/可扩展）以及 (8) 鲁棒平衡不变性、(9) 漂移鲁棒覆盖与组条件覆盖、(10) 平衡–泛化对偶前沿可行性；且弃权时执行 π_safe。

**证明**：必要性由 `admits` 的逐项合取直接得到；任一条件缺失即返回 False 并给出 stage。充分性：v26 部分由引理 4/8/12 保证；平衡部分由引理 16 保证 S_bal 不越界且可恢复；泛化部分由引理 17 保证 P_Q(Y∈C)≥1-α 且组条件成立；对偶部分由引理 18 保证同一 W_max 下两界同时成立；弃权由 π_safe 兜底。合并即从单机物理安全到群体统计泛化的完整闭环。∎

## 7. 与既有证书链的关系

- **向上消费**：BC 直接使用 FCC 的 `τ_max`、无源性与带宽上界，以及 LSC 的 CoM/惯量/屈曲界；平衡裕度不可能超过底层力控与结构证书允许的范围。
- **向下补全**：OGC 为 TCM 提供事前最坏情况界，TCM 为 OGC 提供事后漂移证据；两者用统一风险账本 `α_total = α_t + ε_shift` 计一次。
- **横向对偶**：BC 与 OGC 通过 `F_bg` 共享同一扰动半径 W，避免「平衡按小扰动认证、泛化按大扰动认证」的不一致。

## 8. 本轮最大风险（最终确认）

**一句话**：**TV 漂移半径 ε 的有限样本估计若系统性偏低，或 OOD 检测器对真正的新型漂移失明，则 OGC 会在实际已越出认证球时仍宣称 P_Q(Y∈C)≥1-α，而 BC 又只在标称扰动集上通过，联合门可能在「未知的未知」漂移下静默放行——这是本轮方案最大的风险。**
