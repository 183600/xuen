# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮，上一循环为第 55–57 轮；本轮灵感：「具身智能」×「机器人操作系统」）

> 第 57 轮的证据体系已经能回答"这条证据有多可信"，但仍默认了三件从未被检验的事：**(a) 测量仪器是常量**——身体被当作已知、无漂移、无磨损的传感器与执行器；**(b) 安全是世界标签的函数**——"这是冰面"被当成安全判定的充分输入，而同样一块冰面对空载/满载、硬足/软足、走/跑并不是同一个可供性；**(c) 证据日志是单一进程内的连贯账本**——真实机器人跑在 ROS 2 的分布式节点图上，证据会过期、重放、被重启节点清空、经不同 QoS 乱序到达，甚至由"支持该决策的下游输出"反向自证。本轮两个灵感各补一个被忽略的本体论层次：**具身智能**把"身体"从常量变成必须被估计、被归因、被条件化的变量——身体既是证据的来源，也是系统性偏置的来源；**机器人操作系统**把"证据链"从单机账本变成必须带溯源、租约、版本与实时预算的分布式对象。核心命题由"证据说可信"升级为 **"身体可归因、可供性可条件、来源可追溯的证据说可信"**（Soma-Attributed, Affordance-Conditioned, Provenance-Sound Evidence，SOMA-OS）。

核心矛盾：
- **H29（体-境混淆）**：传感器漂移、足端磨损、负载变化与真实地形变化在观测上不可分；更危险的是，所有模态共享同一具身体，跨模态一致可能是"同一个身体错了两遍"。第 57 轮越强调跨模态对账，越可能把身体诱导的共因误差误判为环境真值。
- **H30（可供性非平稳）**：环境标签是身体无关的，安全却不是。同一表面在换负载、换步态、换足端、换形态后，安全动作集可能完全翻转；在第 57 轮采集的证据若不绑定身体上下文，换一次负载就会悄悄失效，而系统仍把它当"已验证"。
- **H31（分布式证据失真）**：ROS 2 的节点会重启、模型会热更新、QoS 会丢帧、时钟会漂移；证据可能来自旧 epoch、被重复转发、经环回路径自证，或由一个已被攻陷的节点签名。集中式 `probe_log` 的"账本完整性"假设在分布式中间件上不成立。
- **H32（干预相关性）**：探针是动作而不是被动观测。同一动作在未变化状态下重复十次，是"把同一个问题问了十遍"；动作还会改变世界与身体（压实土壤、磨损足端、升温关节）。第 57 轮的 VOI 把探针近似为独立观测，会系统性高估重复探针的信息量。

## 0. 直觉与动机

**灵感 1（具身智能 → 身体是仪器，不是常量）**
直觉：人不会把"手麻了"当成"物体变滑了"，因为人有本体感觉与自校准。机器人同样需要一个可被证据修正的**身体图式**：传感器零偏、执行器健康、足端磨损、负载、形态配置、热状态。环境证据只有在"身体歧义"足够小、且安全判定对身体可信集内的所有可能状态都一致时，才允许进入不可逆承诺。否则先做**自探针**（在空中做已知动作、触碰刚性参考面、空载抬腿）把"自己"估清楚；估计不清就降低可供性（慢走、轻触、换足），而不是继续问世界。

**灵感 2（具身智能 → 安全是三元关系：环境×身体×动作）**
直觉：一把椅子对成年人是"可坐"，对幼儿是"可爬"，对满载机器人可能是"不可压"。安全不是区域标签的属性，而是 `(区域, 身体状态, 动作/步态/负载)` 的关系。第 57 轮的地图证据必须增加一个**身体上下文哈希**：换负载、换足端、换形态、换控制器版本，旧证据自动降级为"待复验"，而不是继续躺在证书里冒充已验证。这把"证据新鲜度"从时间维度扩展到**身体维度**。

**灵感 3（具身智能 → 干预式证据：探针是 do(a)）**
直觉：被动看五遍和主动用五种不同方式碰一遍，信息量完全不同。把探针写成干预 `do(a)`，用**有效样本量** `k_eff` 与**干预多样性** `Div` 替代朴素计数 k：同一动作的重复观测因共享隐状态而高度相关，`k_eff` 饱和；只有改变动作几何/力方向/接触点的探针才产生新的 Fisher 信息。这样"重复探五遍"在第 57 轮跨模态层之外，又在动作层被第二次拦截。

**灵感 4（机器人操作系统 → 证据是分布式对象）**
直觉：ROS 2 里没有"唯一真相"，只有带时间戳、QoS、生命周期与版本的消息图。安全的证据门必须像零信任系统：每条证据带签名、来源节点、模型版本、会话 epoch、TTL 与祖先 DAG；过期、重启、版本错配、环路自证、时钟乱序一律 **fail-closed**。证据不是"存下来就永久有效"，而是**租约**：节点重启即失效，模型热更新即隔离，实时预算内验不完就当没有。第 57 轮"一切判定器走隔离"在本轮推广为"**一切证据走租约与溯源**"。

**灵感 5（合流 → SOMA-OS：身体感知的探-诺-演³）**
直觉：PGP/证据门/PCE 仍然是对的，但要加一个前置的"自我检查"和一层"来源检查"。每个检查点先问三件事：**我现在信得过自己吗？**（身体歧义/自探针）、**这个安全结论在当前身体配置下还成立吗？**（可供性条件/上下文失效）、**这条证据真的来自它声称的地方且还没过期吗？**（溯源/租约/实时预算）。三者任一不满足，就只允许更保守的动作。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（身体图式信念与体-境归因 SSAM）**
身体状态 `β=(c_s,c_a,w,p,m,θ_th)`：传感器标定偏移、执行器健康、足端磨损、负载、形态配置、热状态。观测模型 `p(o|ξ,β,a)`，`ξ` 为环境参数，`a` 为动作。身体后验 `p(β|D_self,D_world)` 给可信集 `B_α^s={β: 后验密度≥c_α}`，要求 `P(β∈B_α^s)≥1−α_s` 且体积有界。**决策相关归因歧义**定义为
`A_soma(q)=1[∃β,β'∈B_α^s: 1[R(q;β)≤δ_f]≠1[R(q;β')≤δ_f]]`；
`q=(r,a,g,p)` 为供性查询，`R` 为失败风险。`A_soma=1` 时，世界证据对不可逆承诺**不可采信**，必须先执行自探针 `a_s`（已知参考环境 `ξ_ref`，如空中运动/刚性校准面）得到 `z_s=h(β,a_s)+ν` 并收缩 `B_α^s`。自探针证书 `Cal_soma=(B_α^s,α_s,ε_β,A_soma,self_probe_log)`。**身体证据不可充当世界证据**；它只决定"世界证据是否可用"。

**定义 140（可供性条件风险 ACR）**
供性查询 `q=(r,a,g,p)`，环境可信集 `Ξ_α(r)` 来自第 57 轮证据。稳健风险
`R̄(q)=sup_{ξ∈Ξ_α(r), β∈B_α^s} P_fail(q;ξ,β)`；
只有 `R̄(q)≤δ_f` 才允许承诺。可供性包络 `E(q;β)={ξ:R(q;ξ,β)≤δ_f}`。证据带**身体上下文哈希** `h_β=(c_s,c_a,w,p,m,controller_version)`，上下文有效条件 `valid_ctx(e)=1[dist(h_β,h_β^e)≤ε_ctx]`；超出容差即**上下文失效**，证据降级为"待复验"，不得继续满足证据门。同一环境标签 `ℓ` 在不同 `β` 下不自动可迁移；跨配置迁移必须重过 ACR。

**定义 141（干预式探针语义与有效样本量 IPS）**
探针是干预 `do(a)`，返回 `o`，历史 `H`。单步干预信息增益 `ΔI(a|H)=I(ξ;O|do(a),H)`。对探针集 `A={a_1..a_k}`，用相关矩阵 `Σ_A`（由共享隐状态、同动作重复、同接触几何估计）定义
`k_eff(A)=(1ᵀΣ_A^{-1}1)^{-1}`（交换相关近似下退化为 `k/(1+(k−1)ρ̄)`）；
多样性 `Div(A)=λ_min(Σ_{a∈A}I_a)/λ_max(Σ_{a∈A}I_a)`，并要求动作几何/力方向/接触点最小距离 `≥d_0`。世界探针证书 `Cert_probe=(k,k_eff,Div,ΔI_tail)`，`EV-probe*` 要求 `k_eff≥k*(w*) ∧ Div≥d_0 ∧ ΔI_tail≤θ_stop`。自探针的 Fisher 信息记为 `I_self=I(β;O|do(a_s))`，与世界探针 `I_world=I(ξ;O|do(a),β)` 分账；重复自探针同样受 `k_eff` 惩罚。

**定义 142（溯源感知证据总线 PAEB）**
证据记录 `e=(eid,payload,n,v,z,t_e,qos,parents,T,σ)`：节点身份、版本、会话 epoch、时间戳、QoS、祖先证据、变换史、签名。祖先集 `Anc(e)`。可采信条件
`Adm_prov(e,t)=SigValid(e) ∧ NodeAttested(n) ∧ Fresh(e,t) ∧ Deadline(e,t) ∧ (Dep(decision)∩Anc(e)=∅) ∧ (v=v_cert) ∧ (z=z_n(t)) ∧ ClockConsistent(e,t)`。
其中 `Fresh` 由 QoS 的 deadline/lifespan/lease 推导；`Dep(decision)∩Anc(e)=∅` 排除"用决策的下游输出反向证明决策"的循环自证；版本错配直接拒绝。证据对 `(e,e')` 的独立性 `Indep=1[Anc(e)∩Anc(e')⊆C_common]`，否则有效权重 `w_eff=min(w_e,w_e')·κ_common`（`κ_common∈[0,1]` 为共因折减），共享来源的重复转发不重复计分。

**定义 143（证据租约与生命周期隔离 ELLQ）**
每个节点会话有单调 epoch `z_n`，重启、升级、配置变更即自增；证据租约 `L(e)=(z_e,t_exp,key_ver)`。租约有效 `Valid_lease(e,t)=1[z_e=z_n(t) ∧ t≤t_exp ∧ key_ver=key_ver_cert]`。模型/判定器更新继承第 57 轮隔离规则：影子模式运行 + 校准回归测试通过才接管。实时语义：证据门在独立有界执行器中运行，最坏执行时间 `C_gate`；若在 `t_commit−C_gate` 前无法完成全部证据校验，门返回 `INSUFFICIENT` 并触发保守降档，**禁止阻塞等待**。时钟一致性要求 `|t_i−t_j|≤ε_clk`，超限则证据序不确定，按不可采信处理。

**定义 144（身体感知证据门与 PCE³，证书 J_s）**
证据类：`EV-soma`（仅身体标定）/`EV-probe*`/`EV-visit`/`EV-margin`/`EV-xmodal`（仅 L1）/`EV-human`。不可逆接触必要证据集
`= ({EV-probe*∨EV-margin} ∧ SomaAdm(q) ∧ Adm_prov∧Valid_lease) ∪ 人佐证`，
其中 `SomaAdm(q)=1[A_soma(q)=0]`；`EV-soma` 只能满足 `SomaAdm` 的身体部分，永不满足世界证据位；`EV-xmodal` 仍仅限 L1。证书
`J_s=(J_p, Cal_soma, attribution_log, intervention_log, G_e, lease_log, qos_log, ACR_eval, invalidation_log)`，继承 `J_p` 全检。
`PCE³` 每个检查点：①事件失效（负载/形态/节点重启/模型更新/时钟异常）；②身体更新，若 `A_soma=1` 或 `diam(B_α^s)>ε_β` 则优先自探针（预算 `k_self`）或降低可供性，仍不清则禁止不可逆承诺；③用 `R̄(q)` 做稳健可供性风险；④按干预多样性选世界探针，跨模态对账，证据经 PAEB/ELLQ 校验；⑤承诺当且仅当 `R̄(q)≤δ_f ∧` 证据门过 ∧ `SomaAdm ∧` 溯源/租约全过；否则绕行→降档→L2 协商→安全停。

```python
def soma_update_and_gate(M, r, q, body, self_log):
    B = body.posterior()                                # 身体可信集 B_alpha
    A = decision_ambiguity(q, B)                        # 定义 139
    if A or body.diam(B) > body.eps_beta:
        for a_s in body.self_probe_plan(B):             # 优先自探针
            z = execute(a_s, env=body.xi_ref)           # 已知参考环境
            B = body.update(B, a_s, z); self_log.append((a_s, z))
            if not decision_ambiguity(q, B): break
    return B, Cal_soma(B, body.alpha_s, A, self_log)

def robust_affordance_risk(q, Xi, B):
    return max(P_fail(q, xi, beta) for xi in Xi for beta in B)   # 定义 140

def interventional_probe_cert(history, cands):
    A = select_diverse(cands, history)                  # Div >= d_0
    k_eff = effective_sample_size(history + A)          # 定义 141
    return A, Cert_probe(len(history)+len(A), k_eff, Div(A), tail_gain(A))

def provenance_admit(e, t, trust_root):
    return (sig_ok(e, trust_root) and node_attested(e.n) and
            fresh(e, t) and deadline_ok(e, t) and
            not circular(e, decision=e.supports) and
            e.v == trust_root.cert_version and
            e.z == session_epoch(e.n, t) and clock_consistent(e, t,
                                                               eps_clk=EPS_CLK))

def pce3(x0, M, task, budget, personas):
    route = plan_on_map(M, task)
    sched, log = [], []
    for cp in route.checkpoints:
        invalidate_on_events(M, cp, events=['payload','morphology','restart',
                                            'model_update','clock_skew'])
        q = query(cp, task)
        B, cal = soma_update_and_gate(M, cp.region, q, body, self_log)
        if decision_ambiguity(q, B):
            route = downgrade_affordance(route, cp)      # 降低可供性，不硬赌
            continue
        Rbar = robust_affordance_risk(q, credible_env(M, cp.region), B)
        while Rbar > delta_f and budget.world_left > 0:
            cands = admissible_world_probes(cp, M, F_abs)
            badmissible = [c for c in cands
                           if provenance_admit(c.evidence, now(), trust_root)]
            A, cert = interventional_probe_cert(M.history[cp.region], badmissible)
            if cert.k_eff < k_star or cert.Div < d_0: break
            p = argmax(A, key=lambda a: voi_robust(a, M, cert) - cost(a))
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
                M, _, _ = xmodal_fuse(M, cp.region,
                                      execute_most_disagreeing(cp, M, F_abs))
                cp.done.add('consensus')
            Rbar = robust_affordance_risk(q, credible_env(M, cp.region), B)
        if Rbar <= delta_f and few_shot_evidence_gate(cp, M, personas,
                                                      provenance_ok=True)[0] == 'ok':
            sched.append(commit(cp, select_gait(Rbar))); continue
        route = reroute_or_downgrade(M, cp, Rbar)
    return sched, J_s(M, cal, intervention_log, provenance_dag, lease_log)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SSAM | O(d_β)/更新；自探针 O(k_self·d_β) | O(N_self·d_β) | 可信集覆盖 ≥1−α_s、自探针不可作世界证据 |
| ACR | O(\|Ξ\|·\|B\|·d_q)/检查点 | O(\|Ξ\|·\|B\|) | 对可信集取上确界、上下文失效即降级 |
| IPS | O(k²·d)（相关矩阵） | O(k·d) | `k_eff` 不超真实独立信息、`Div` 可审计 |
| PAEB | O(\|V\|+\|E\|)/记录 | O(\|V\|+\|E\|) | 签名/版本/epoch/环路全检、共因折减 |
| ELLQ | O(1)+O(log N_node) | O(\|节点\|) | 租约到期/重启即失效、WCET 超限 fail-closed |
| PCE³ | O(\|CP\|·(k_self+k_world+k_cons)·(C_VOI+d_β)+\|CP\|·A*) | O(\|V\|+\|σ\|) | 身体优先、稳健可供性、有限预算终止 |

**正确性定理（Soma-Attributed Affordance-Soundness, SAAS 概要）**：在 A33–A40 上增加 **(A41)** 身体可信集覆盖 `P(β∈B_α^s)≥1−α_s`，自探针观测模型诚实且不宣称世界信息；**(A42)** 稳健可供性：承诺时 `R̄(q)≤δ_f` 对 `B_α^s` 与 `Ξ_α` 内所有点成立；**(A43)** 干预信息证书诚实：`k_eff` 为真实有效样本量的上界、`Div` 下界可审计，重复/共线探针不重复计分；**(A44)** 溯源健全：签名不可伪造、`Adm_prov` 对伪造/过期/环路/版本错配返回拒绝，共因折减保守；**(A45)** 实时证据门有 WCET 上界且超时 fail-closed；**(A46)** 上下文失效在 `Δ_t` 内传播，变更后旧证据不再满足证据门。则：

1. **体-境误归因界**：因身体误差导致的错误承诺 `≤ δ_β + δ_self + δ_prov`；`A_soma=1` 时不可逆承诺率严格为 0（除非人工降级为 L1）。
2. **可供性条件健全性**：`P(fail) ≤ δ_f + ε_meta(k_eff) + δ_probe(k_eff) + δ_h(w_max) + δ_β + δ_prov + δ_rt + δ_ood·α_conf + δ_xm·1[L1]`，其中 `δ_probe(k_eff)` 随 `k_eff` 而非名义 `k` 下降——重复探针无法伪造置信。
3. **分布式证据健全性**：被攻陷/重启/过期/环路/版本错配的单节点最多让其自身证据失效，不能单独构造通过证据门的证书；多节点共谋的成功率受共因折减 `κ_common` 与信任根约束。
4. **交互单调性强化**：身体不确定性只扩大可信集、上下文失效只删除证据、自探针只增加身体信息、溯源失败只拒绝证据——四个新机制均只能使动作更保守，不存在升险路径。
5. **终止性**：每检查点自探针 ≤`k_self`、世界探针 ≤`k_world`、共识探针 ≤`k_cons`，租约有限、协商有限，终止于 `{承诺, 绕行, 降档, L2 协商, 安全停}`。

**部署界（对检查点取联合界）**：

### IP-139 SSAM（身体图式信念与体-境归因）

```python
def body_posterior_update(body, D_self, D_world, a_hist):
    # beta=(c_s, c_a, w, p, m, theta_th)；观测模型 p(o | xi, beta, a)
    body.post = bayes_update(body.prior, like=D_self + D_world,
                             model=body.obs_model, actions=a_hist)
    body.B = hpd_set(body.post, coverage=1 - body.alpha_s)   # 可信集
    return body

def decision_ambiguity(q, B, delta_f):
    labels = {int(risk(q, beta) <= delta_f) for beta in B}
    return len(labels) > 1                                  # 定义 139：判定翻转

def soma_update_and_gate(M, r, q, body, self_log):
    B = body.posterior()
    if decision_ambiguity(q, B, delta_f) or diam(B) > body.eps_beta:
        for a_s in body.self_probe_plan(B):                 # 空中动作/刚性参考面
            z = execute(a_s, env=body.xi_ref)               # xi_ref 已知
            body = body_posterior_update(body, [(a_s, z)], [], [a_s])
            self_log.append((a_s, z, now()))
            if not decision_ambiguity(q, body.B, delta_f):
                break
    A = decision_ambiguity(q, body.B, delta_f)
    cal = Cal_soma(body.B, body.alpha_s, body.eps_beta, A, self_log)
    return body, cal, A

def self_probe_plan(B):
    # 选择使 B 的决策相关熵下降最大、且不接触不可逆环境的自探针
    return sorted(SELF_PROBES, key=lambda a: -decision_entropy_gain(a, B))
```

**要点**：自探针必须在**参考环境**中执行（空中、刚性校准面、空载），其观测只进入 `D_self`；不得把自探针结果记入世界证据。`A_soma=1` 时，`EV-probe*` 与 `EV-margin` 对不可逆接触一律不可采信。

### IP-141 IPS（干预式探针语义）

```python
def effective_sample_size(history, cands):
    A = history + cands
    Sigma = correlation_matrix(A, model='shared_state+same_action+geom')
    ones = np.ones(len(A))
    return 1.0 / (ones @ np.linalg.inv(Sigma) @ ones)      # 定义 141

def diversity(A):
    if len(A) < 2: return 0.0
    infos = [fisher_world(a) for a in A]
    return min_eig(sum(infos)) / max_eig(sum(infos))

def tail_gain(A, H):
    return sum(interventional_gain(a, H + A[:i]) for i, a in enumerate(A))

def interventional_probe_cert(history, cands):
    A = diversify(cands, min_action_distance=D_0)          # 几何/力向/接触点
    k_eff = effective_sample_size(history, A)
    cert = Cert_probe(len(history) + len(A), k_eff, diversity(history + A),
                      tail_gain(A, history))
    return A, cert

def world_probe_qualified(cert, k_star, d_0, theta_stop):
    return cert.k_eff >= k_star and cert.Div >= d_0 and cert.tail <= theta_stop
```

**要点**：同一动作重复观测因共享隐状态而相关，`k_eff` 饱和；只有改变动作几何、力方向、接触点或时相的探针才增加独立 Fisher 信息。`EV-probe*` 的门槛从名义 `k` 改为 `k_eff`，从动作层再次拦截"把同一个问题问五遍"。自探针 `I_self` 与世界探针 `I_world` 分账，互不冒充。

### IP-142 PAEB（溯源感知证据总线）

```python
def provenance_dag(records):
    G = {}
    for e in records:
        G[e.eid] = set(e.parents)
    return G

def circular(e, decision):
    # 若证据祖先包含该证据所支持决策的下游输出，则为循环自证
    return bool(ancestors(e, G) & Dep(decision))

def coindependence(e1, e2, common_causes):
    shared = ancestors(e1, G) & ancestors(e2, G)
    return shared <= common_causes

def provenance_admit(e, t, trust_root):
    if not sig_ok(e, trust_root):                 return False, 'sig'
    if not node_attested(e.n, trust_root):        return False, 'attest'
    if not fresh(e, t):                            return False, 'stale'
    if not deadline_ok(e, t):                      return False, 'deadline'
    if circular(e, decision=e.supports):           return False, 'loop'
    if e.v != trust_root.cert_version:             return False, 'version'
    if e.z != session_epoch(e.n, t):               return False, 'epoch'
    if not clock_consistent(e, t, EPS_CLK):        return False, 'clock'
    return True, 'ok'

def fuse_with_provenance(evs, weights, common_causes):
    total = 0.0
    for i, e in enumerate(sorted(evs, key=lambda x: x.t_e)):
        if not provenance_admit(e, now(), trust_root)[0]:
            continue
        w = weights[e.eid]
        for j in range(i):
            if not coindependence(e, evs[j], common_causes):
                w = min(w, weights[evs[j].eid]) * kappa_common(e, evs[j])
        total += w
    return total
```

**要点**：`Fresh` 由 QoS 的 deadline/lifespan/lease 推导：reliable+transient-local 可给较长 TTL，best-effort 给较短 TTL；deadline 到期即拒绝。祖先 DAG 同时用于环路自证检测与共因折减：两个节点若共享同一上游感知或同一模型，不能算两份独立口供。签名、节点证明、版本哈希、会话 epoch 缺一不可。

### IP-143 ELLQ（证据租约与生命周期隔离）

```python
def session_epoch(node, t):
    return node.epoch(t)                          # 重启/升级/配置变更自增

def lease_valid(e, t, cert):

def evidence_gate_bounded(required, t_commit, C_gate, trust_root):
    t_start = now()
    if t_commit - t_start < C_gate:
        return 'INSUFFICIENT'                     # fail-closed，不阻塞等待
    for e in required:

def on_lifecycle_event(node, event):
    if event in ('restart', 'upgrade', 'config_change', 'model_swap'):
        node.epoch += 1
        quarantine_evidence(node)                 # 旧 epoch 证据全部失效

```

**要点**：证据是租约而非永久资产；节点重启/升级/配置变更/模型热更新都会使旧证据失效。证据门在独立有界执行器中运行，WCET 超限或校验来不及完成时返回 `INSUFFICIENT` 并触发保守降档，而不是让控制回路等待。时钟漂移超过 `ε_clk` 时证据顺序不可信，按不可采信处理。

| ACR | O(\|Ξ\|·\|B\|·d_q)/检查点 | O(\|Ξ\|·\|B\|) | 上确界稳健、上下文失效即降级（A42/A46） |
| IPS | O(k²·d) | O(k·d) | `k_eff` 为有效样本上界、`Div` 可审计（A43） |
| PAEB | O(\|V\|+\|E\|)/记录 | O(\|V\|+\|E\|) | 签名/版本/epoch/环路全检、共因折减（A44） |
| ELLQ | O(1)+O(log N_node) | O(\|节点\|) | 租约过期/重启失效、WCET fail-closed（A45） |
| PCE³ | O(\|CP\|·(k_self+k_world+k_cons)·(C_VOI+d_β)+\|CP\|·A*) | O(\|V\|+\|σ\|) | 身体优先、稳健可供性、有限预算终止 |

**正确性定理（Soma-Attributed Affordance-Soundness, SAAS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；并增加：

- **(A41) 身体可信集**：`P(β∈B_α^s)≥1−α_s`，`diam(B_α^s)≤ε_β` 或已触发保守降级；自探针观测模型诚实，且 `EV-soma` 从不在世界证据账中出现。
- **(A42) 稳健可供性**：承诺时 `R̄(q)=sup_{ξ∈Ξ_α,β∈B_α^s}P_fail(q;ξ,β)≤δ_f`；上下文哈希容差 `ε_ctx` 诚实。
- **(A43) 干预信息诚实**：`k_eff` 是真实有效样本量的上界，`Div` 下界可审计，重复/共线探针不重复计分，`ΔI_tail` 真实。
- **(A44) 溯源健全**：签名不可伪造、节点证明有效、`Adm_prov` 对伪造/过期/环路/版本错配/epoch 不符返回拒绝，共因折减 `κ_common` 保守。
- **(A45) 实时证据门**：`C_gate` 有 WCET 上界，超时 fail-closed；时钟漂移 ≤`ε_clk`，否则证据不可采信。
- **(A46) 上下文失效传播**：负载/形态/节点/模型/时钟事件在 `Δ_t` 内使相关证据失效，失效后旧证据不再满足证据门。

则：

1. **体-境误归因界**：因身体误差导致的错误承诺概率 `≤ δ_β + δ_self + δ_prov`；当 `A_soma=1` 时，不可逆接触的自动承诺率为 0（只能人工降级为 L1 或执行自探针）。
2. **可供性条件健全性**：
   `P(fail) ≤ δ_f + ε_meta(k_eff) + δ_probe(k_eff) + δ_h(w_max) + δ_β + δ_self + δ_prov + δ_rt + δ_ood·α_conf + δ_xm·1[L1]`。
   关键：`δ_probe` 随 `k_eff` 而非名义 `k` 下降；重复探针无法伪造置信；换身体配置未复验则 `valid_ctx=0`，旧证据贡献为 0。
3. **分布式证据健全性**：任一被攻陷/重启/过期/环路自证/版本错配的节点最多使其自身证据失效，不能单独构造通过 `J_s` 的证书；多节点共谋成功率受 `κ_common` 与信任根约束；证据门在 WCET 内无法完成时保守拒绝。
4. **交互单调性强化**：身体不确定性只扩大可信集；上下文失效只删除证据；自探针只增加身体信息（不增加世界证据）；溯源失败/租约过期只拒绝证据；四个新机制均只经"信念更宽"或"动作更保守"影响系统，不存在升险路径。
5. **终止性**：每检查点自探针 ≤`k_self`、世界探针 ≤`k_world`、共识探针 ≤`k_cons`；证据租约有限；协商有界，终止于 `{承诺, 绕行, 降档, L2 协商, 安全停}`。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp [δ_f + ε_meta(k_eff) + δ_probe(k_eff) + δ_h + δ_β + δ_self
                  + δ_prov + δ_rt + δ_ood·α_conf + δ_xm·1[L1]]
             − P(身体模型系统性偏差未检出)
             − P(信任根/签名失效)
             − P(上下文失效传播超时 ∧ 安全停失效)
```

**证明直觉**：把每次承诺分解为四个必要条件——(i) 身体可信集内判定不变（否则自探针或降级）；(ii) 环境可信集与身体可信集上的上确界风险低于阈值；(iii) 探针证书给出的是有效独立信息而非名义计数；(iv) 每条证据在承诺时刻通过签名/版本/epoch/租约/环路/QoS 检查。四个条件同时失败才可能产生错误承诺，故取联合界；上下文失效与实时超时只会使证据不足，不会使证据变强，因此不引入升险项。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是把"身体"变成了新的未建模先验——若身体图式与自探针模型本身系统性错误或在体-境强混淆下不可辨识，系统会高度自信地把身体诱导的失败归因于环境（或反之），而 ROS 的分布式证据总线只会让这类错误证据传播得更快；必须以可信集而非点估计、自探针不可充当世界证据、证据租约/版本/环路 fail-closed 三重护栏，宁可把"自己"当作最可疑的传感器。
