# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；本轮灵感：「痛点分析」×「深度相机」）

> R69 把「不确定性」一分为二，用 VoI 决定「要不要问、问谁」，并用流似然给标定层补了一条第二意见。但它默认了一个从未被检验的假设：**不确定的地方就是要处理的地方**。该假设在信息论里成立（熵高 → 信息量大），在任务里常常不成立——**熵最大的地方可能恰恰是任务最不关心的地方**（远处墙面的一团深度噪声），而真正致命的地方可能只有几厘米的不确定（桌沿、杯柄、台阶边缘）。于是 R69 的系统会「很努力地看错地方」。
>
> 本轮两个灵感正好把这件事掰开：
> - **痛点分析**：不问「哪里不确定」，而是问「**哪里不确定会真的疼**」。把不确定性从「熵」重标定为「**任务损失敏感度 × 不确定度**」，得到一张有物理坐标的**痛点图**（pain map），并给出「不疼就别动」的可辨识门。
> - **深度相机**：深度是最典型、最常部署、也最会「自信地错」的几何通道——透明/镜面/低纹理/强光/多路径会让它给出**低残差却错误**的深度。它给痛点一个**物理坐标系**（碰撞余量、抓取位姿、落脚点），也给出一个**解析的、空间变化的噪声模型**，让痛点第一次可以被真正计算；同时，它的主动探测（换视角/改基线/结构光/跨模态）正是消解几何痛点的天然手段。
>
> 核心命题：**把「解开不确定性」升级为「只在会疼的地方解开不确定性」；用深度相机的物理失效模型识别「低残差但几何错误」的自信错误；用主动几何探测消解痛点；当痛点不可辨识、深度自信错误、或预算耗尽时，单调退化为 R69。** 命名 **PAIN-RAS**（Perceptual Attribution of Information Need — Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**到底疼在哪**」——不确定性不是均匀的雾，而是有坐标、有价格、有真假的局部刺痛；触觉告诉你「碰到了什么」，痛觉告诉你「哪里不能信」。

## 0. 直觉与动机

**灵感 1（痛点分析 → 不确定 ≠ 痛点）**
直觉：R69 的 VoI 用「后验熵的下降」当收益，这是一个**代理指标**：它衡量「我知道了更多」，却不衡量「我少疼了多少」。在所有不确定都同样致命的玩具环境里二者等价；在真实任务里，绝大多数不确定是**任务无关**的。痛点分析的洞见是：先做**归因**——把总任务风险拆到观测的各个局部，找到真正贡献损失的那一小块；然后只对它花预算。这等价于把「信息价值」换成「**损失价值**」。

**灵感 2（深度相机 → 痛点有物理坐标，也有物理骗局）**
直觉：深度相机给的是稠密度量几何，而机器人的疼痛几乎都发生在几何上——撞上、抓空、踩空、蹭到。给定深度像素 c 的误差 δD_c，任务损失的一阶变化是 ⟨∂L/∂D_c, δD_c⟩，于是「这个像素的痛」= 敏感度 × 不确定度，可直接算。另一方面，深度相机有一套**众所周知却常被软件层忽略**的失效谱：透明（看穿到背景）、镜面（把反射当表面）、低纹理/深色（孔洞）、强光/多机干扰（IR 过曝）、多路径（凹面/反光室内）、飞点（深度不连续处）。这些失效的共同点是**残差小、置信度高、几何错**——正是 R69 最脆弱的「epistemic 伪装成 aleatoric」。

**灵感 3（从「算熵」到「算敏感度」→ 可辨识性）**
直觉：痛点是「敏感度 × 不确定度」。这里有个常被忽视的退化：如果任务对某块观测的敏感度接近零（不确定的方向与任务梯度正交），那么该处再不确定也**不疼**，交互是纯浪费；如果敏感度矩阵病态（多个误差方向几乎抵消或强耦合），则痛点的**符号都算不准**，此时任何基于痛点的选择都不可信。于是需要一个**痛点可辨识门（PIG）**：只允许在「敏感度良态且足够大」的区域探测。这既是效率，也是安全——否则你会为了一个算不准的痛点去冒险。

**灵感 4（自信错误 → R69 对偶判据的几何侧镜像）**
直觉：R69 用「残差低 + 行为似然高」揪出被标定吸收的缓变故障。本轮在几何侧有一个结构完全相同的对偶：**残差/置信度高 + 几何一致性低** ⇒ 深度在骗你。几何一致性有三条正交渠道：多视角刚体一致性（抓多路径/飞点/标定偏差）、外观-深度耦合（抓镜面高光随视角的异常移动）、跨模态一致性（单目度量深度/语义/触觉，抓透明与「空处有物」）。三条渠道都不通过才退避；单条通过不足以定案（沿用 R69 的证据纪律）。

**灵感 5（选择性本身就是新威胁 → 假阴性比假阳性致命）**
直觉：R69 的失败模式是「问错」，代价是浪费预算与被投毒。R70 的失败模式更阴险：**痛点图把真正疼的地方判成不疼**。一旦如此，系统不但不去探测，还因为「那里不疼」而**免除了 R69 的保守退避**——它会在最该小心处自信地省事。也就是说，**假阳性只花预算，假阴性直接吃掉安全**。这决定了本轮的设计重心：痛点的**漏报**必须由独立的几何/安全证据兜底，而不能只靠「平均归因误差小」。深度相机的自信错误恰好是制造这种漏报的最佳工具：低方差错误几何让痛点图看不出疼。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（PAIN-RAS 总览与三不变式）** PAIN-RAS = (PAD, DRM, CIV, GAP, GCA, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **痛点门控**：只有通过 PIG（定义 313）且痛点超过阈值 τ_pain 的区域才允许触发交互/探测；否则不探测（这是「不疼就别动」）；
(iii) **几何证据纪律**：接触关键动作（抓取/落足/对接）的局部几何需 ≥2 个正交证据源一致；痛点归因不得单独免除 R69 的保守退避，除非几何证据也支持。

**定义 311（痛点泛函 Pain Functional）** 给定观测 o = (D, I, …)、对状态的信念 p(s|o)、已知任务策略 a = π(o) 与任务损失 L(a, s)。对观测的任一局部 c（深度像素块 / 通道 / 区域），定义其**反事实痛点**
Pain(c) := E_{s∼p}[L(π(o), s)] − E_{s∼p}[L(π(o_{⊕c}), s)]，其中 o_{⊕c} 表示「把 c 处的不确定性理想地抹平」（用真值替换）。语义是「若我免费知道了 c，任务期望损失能降多少」。π 最优时 Pain(c) ≥ 0。**一阶可算版**：Pain(c) ≈ E_{s∼p}|⟨∇_{D_c}L, δD_c⟩| ≈ ‖J_c‖·σ_D(c)，其中 J_c = ∂L/∂D_c 为任务敏感度，σ_D(c) 为 c 的后验标准差。这是「敏感度 × 不确定度」，也是 PAD 实际计算的量。

**定义 312（痛点图与归因 PAD）** 痛点图 P : 𝒞 → ℝ_{≥0}，P(c) = Pain(c)。归因用 Integrated Gradients / 区域 Shapley，满足**完备性**：Σ_c P(c) = 总任务风险 − 交互项残差（定义见引理 19）。实时实现：粗网格（16×16）由一个蒸馏的 pain_head(z) 一次前向预测，只对 P > τ_pain 的 top-k 区域做 Jacobian 细化。痛点图带哈希，进审计。

**定义 313（痛点可辨识门 PIG）** 取高不确定子空间 U = {方向 : σ_D ≥ τ_σ}，J_U = ∂L/∂D 限制在 U 上。定义可辨识裕度 m = σ_min(J_U) / (σ_max(J_U) + ε)。若 m < m_pig 或 ‖J_U‖_F < j_min，则「这点不确定碰不到任务，或任务敏感度病态」⇒ 该区 Pain 置零、禁止探测，走 R69 兜底。**PIG 是本轮全部安全收益的关键，也是假阴性的主要来源（见风险）。**

**定义 314（深度可靠性物理模型 DRM）** 轴向噪声 σ_z(z) = α·z²，横向噪声 σ_xy(z) = β·z/f；孔洞概率 p_hole = σ(κ(ρ_min − ρ) + λ(θ − θ_max) + μ|∇D|)（ρ 反射率、θ 入射角、|∇D| 深度梯度）；飞点出现在深度不连续处的 w_f 像素带内；多路径集中在凹面/反光区。材质集 ℳ = {diffuse, specular, transparent, dark, textureless}。于是 p(D | s, ℳ) 是「物理测量噪声（aleatoric）× 材质/表面歧义（epistemic）」的混合。

**定义 315（深度不确定性的二分）** U_ale^D(c) = 物理噪声方差（解析已知，沿用 αz²、βz/f、p_hole）；U_epi^D(c) = 给定 (D, I) 对材质/表面假设 m 的后验熵，可由视角、偏振、跨模态降低。二者仍分通道处置（沿用定义 297 的精神），不做简单加和。

**定义 316（代价加权信息价值 CIV）** 候选几何信息动作 g 的价值 VoI_pain(g) = E_{y∼p(·|o,g)}[Pain(o) − Pain(o|y)] − c(g)。选择 g* = argmax_g VoI_pain(g)，s.t. PIG 通过、安全认证、预算未超。若 max VoI_pain ≤ 0：不探测（任务最优或回退 R69）。**当 Pain ≡ 常数且信息增益线性时，VoI_pain ∝ R69 的 VoI ⇒ R69 是本定义在「均匀痛点」边界上的特例。**

**定义 317（几何主动探测空间 GAP）** 信息动作 g = (g_view, g_base, g_pattern, g_modality) ∈ 𝒜_geo：g_view ∈ SE(3) 小视角位移（产生视差）；g_base 立体基线 / 对焦 / 曝光；g_pattern 结构光图案 / 偏振；g_modality 跨模态查询（单目度量深度 / 触觉 / 本体）。约束：运动安全（C-RAS-WM 前缀认证）、ROI 不得被自身遮挡、时间预算。

**定义 318（几何一致性门 GCA）** 多视角 warp 残差 r_mv = ‖D_i − warp(D_j; T_ij)‖（刚体场景应 ≈ 测量噪声）；跨模态 r_xm = 归一化 |D − D_mono|（接触给出局部精确深度）；外观-深度耦合 r_app = 高光/明暗随视角移动是否与假定的朗伯表面自洽。三者中任一显著越界即记为不一致。

**定义 319（自信错误深度警报 CWA）** 区域 c 为「自信错误」⇔ 传感器自信高（低自模型残差 / 高 ToF 幅值）∧ 几何不一致（r_mv > τ_mv ∨ r_xm > τ_xm ∨ r_app > τ_app）∧ 材质先验支持镜面/透明/低纹理。cwa(c) ∈ [0,1] 为综合分。这是定义 301 的几何侧对偶：残差测「传感器是否自洽」，几何一致性测「在对的地方是否真」。

**定义 320（疼痛门控退避，含 Pain Resolution Bonus）** 若痛点被探测消解：λ = max(λ_task-optimal, λ_floor(U_ale_total))（获得 pain resolution bonus，比 R69 更不保守但不更低安全）；若 PIG 失败 / CWA 报警 / 预算耗尽 / 探测被投毒：λ = λ_floor(U_ale + 未消解 U_epi + 未归因 pain)，并回 R69 的保守档。⇒ R69 恰为「均匀痛点 + 深度可靠 + 不探测」边界。

**定义 321（几何证据纪律）** 接触关键动作（抓取、落足、对接、插拔）的局部表面必须由 ≥2 个正交几何源一致确认（深度 + 单目度量深度 / 触觉 / 本体 / 语义先验）；否则该局部深度视为未知、按保守值膨胀不确定度并退避。单源几何不单独定案（沿用 R69 定义 293-iii）。

**定义 322（痛点审计 VQAuditor-P）** 审计新增：痛点归因是否与反事实一致、是否忽略了高痛区（假阴性）、痛点图是否被场景/对手塑形、几何探测是否安全；结论回灌 AuditBuf，成为下一轮 PAD 的校准先验与探测成本先验。

**定义 323（几何投毒干扰集 ℰ_geo）** 红外投影欺骗、反光诱饵面（把假表面做得「几何上合法」）、遮挡或移除痛点区、痛点图对抗塑形（让真痛区看起来廉价）、深度重放、运动透明物。并入 AIC：ℰ_PAIN = ℰ_FLUID × ℰ_geo。

**定义 324（证书 J_PAIN）** J_PAIN = (J_FLUID, pain_map_hash, pig_margin, cwa_rate, probe_log_hash, depth_reliability_ece, pain_false_negative_rate, pain_ver)。Valid ⇔ Valid(J_FLUID) ∧（PIG 满足 ∨ 已退避）∧ CWA 已处置 ∧ 几何证据纪律满足 ∧ 探测预算未越界。

**定义 325（痛点-几何对偶）** 标定残差通道测「传感器自洽」，行为似然通道（R69）测「行为自洽」，本轮几何通道测「**在对的地方几何是否为真**」。三者构成正交证据：单看残差会被自信错误骗过；单看多视角会被「几何上合法的诱饵」骗过；单看痛点会被归因假阴性骗过。于是 (r_res, Δa, r_mv, P) 的联合分布才是判据——这是 R68 引理 13、R69 定义 309 在几何-任务侧的又一次镜像。

## 2. 关键算法骨架

```python
# IP-264 PAD：痛点归因（粗网格 pain_head + 仅对 top-k 高痛区做 Jacobian 细化）
class PainAttributor:
    def __init__(self, trunk, pain_head, jac_solver, grid=16):
        self.trunk, self.pain_head = trunk, pain_head   # z -> 16x16 痛点图
        self.jac = jac_solver                           # c -> ∂L/∂D_c（可微仿真/敏感度场）

    def pain_map(self, o, D, belief):
        z = self.trunk(o)
        P = self.pain_head(z)                            # 一次前向 <0.05ms
        roi = topk_cells(P, k=8)                         # 仅细化最疼的 8 格
        for c in roi:
            J_c = self.jac.task_jacobian(c, D, belief)   # 任务敏感度
            P[c] = norm(J_c) * belief.std_depth(c)       # 敏感度 × 不确定度
        return P, roi

    def identifiability(self, P, roi, D, belief):        # PIG（定义 313）
        J_U = self.jac.restrict(high_uncertainty_subspace(belief))
        m = sigma_min(J_U) / (sigma_max(J_U) + EPS)
        ok = (m >= M_PIG) and (norm(J_U) >= J_MIN)
        return ok, m

# IP-266 DRM：解析深度可靠性物理模型（定义 314）
def depth_reliability(D, refl, angle, grad):
    sig_z  = ALPHA * D**2
    sig_xy = BETA * D / F
    p_hole = sigmoid(K_HOLE*(RHO_MIN-refl) + L_ANGLE*(angle-THETA_MAX) + M_GRAD*grad)
    mat    = material_prior(D, refl, angle)              # specular/transparent/dark 先验
    return sig_z, sig_xy, p_hole, mat

# IP-269/270 GCA + CWA：几何一致性审计与自信错误警报（定义 318-319）
def geometric_audit(D_now, frame_hist, D_mono, contact, mat):
    r_mv  = min(warp_residual(D_now, D_h, T) for (D_h, T) in frame_hist)  # 刚体应≈噪声
    r_xm  = normalized_abs(D_now - D_mono)               # 跨模态
    r_app = appearance_depth_consistency(D_now, frame_hist)  # 高光随视角移动
    conf  = depth_confidence(D_now)                      # 低自模型残差 / 高幅值
    cwa   = conf * max(r_mv > TAU_MV, r_xm > TAU_XM, r_app > TAU_APP) * risky(mat)
    return r_mv, r_xm, r_app, cwa

# IP-267 CIV：痛点加权信息价值（定义 316）
def choose_probe(P, o, budget, pig_ok):
    if not pig_ok:                                       # 不疼就别动
        return None
    best = None
    for g in geo_candidates(P):                          # view/base/pattern/modality
        if not budget.allow(g):                    continue
        if not c_ras_wm.certify_geo(g, o):         continue   # 探测也要过安全认证
        voi = expected_pain_drop(P, g, o) - cost(g)      # 是痛点降幅，不是熵降
        if best is None or voi > best.voi: best = (g, voi)
    return best[0] if best and best.voi > 0 else None    # VoI_pain<=0 → R69

# IP-275 主闭环：在 R69 的不确定性处置处换成「痛点门控 + 几何第二意见」
def PAIN_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                            # R68/R69 一次前向
    c, U_cal, thr = M.cof.step(...)                      # R68 标定
    U_ale, U_epi, modes, _ = M.aud.decompose(...)        # R69 不确定性二分
    a_hat = M.fma.flow_anomaly(...)                      # R69 行为似然第二意见
    # 1) 本轮新增：痛点归因 + 可辨识门 + 几何审计
    P, roi = M.pad.pain_map(o, obs.D, M.belief)
    pig_ok, pig_m = M.pad.identifiability(P, roi, obs.D, M.belief)
    r_mv, r_xm, r_app, cwa = M.gca.audit(obs.D, M.frame_hist, obs.D_mono,
                                         obs.contact, M.mat)
    # 2) 只在高痛、可辨识、非自信错误处做几何探测
    g = None
    if pig_ok and max(P[c] for c in roi) > TAU_PAIN and max(cwa) < TAU_CWA:
        g = M.civ.choose_probe(P, o, M.budget, pig_ok)
    if g is not None:
        y = M.gap.execute(g)                             # 换视角/基线/结构光/跨模态，过认证
        P = M.pad.update_pain(P, y)
        r_mv, r_xm, r_app, cwa = M.gca.audit(...)        # 探测后复检
    # 3) 疼痛门控退避：只对 aleatoric + 未消解 epistemic + 未归因痛收紧
    U_floor = U_ale + (U_epi if g is None else residual_epi(U_epi, y))
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    retreat = (not pig_ok) or (max(cwa) > TAU_CWA) or M.budget.exhausted()
    if retreat:                                          # 回 R69 保守档
        lam = max(lam, lam_floor(U_ale + U_epi)); lam = max(lam, 0.8)
    # 4) 几何证据纪律：接触关键动作必须多源一致
    k = M.c_ras_wm.certified_prefix(...)
    if obs.contact_critical and not geo_evidence_agree(obs.D, obs.D_mono, obs.contact):
        lam = max(lam, 0.8); k = min(k, shrink_local(roi))
    # 5) 选模态执行 + 参与式审计 + 证书
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(P, pig_m, cwa, g, lam, evidence_hash(obs))
    return k, lam, mode, (U_ale, U_epi, P)
```

## 3. 推导

**引理 19（痛点一阶展开与归因完备性）** 设 L 对 D 为 C²、Hessian 有界，深度扰动 δD 零均值。则对每个局部 c：
Pain(c) = E|⟨∇_{D_c}L, δD_c⟩| + O(E‖δD_c‖²)，
即「敏感度 × 不确定度」是反事实痛点的一阶精确刻画。进一步，若 L 在区域上**可加**（无跨区耦合项），则 Σ_c Pain(c) = E[L(π(o), s)] − E[L(π(o^{all}), s)]（全部不确定性抹平后的损失），归因**完备**。残差恰为跨区耦合项，称为「痛点耦合」——它告诉我们线性归因在何处失效（相邻区域的误差互相抵消或放大），也是 PAD 需要 ROI 联合细化的原因。

**引理 20（自信错误深度的可检测性与不可检测下界）** 令 𝒜_geo 为定义 317 的允许探测集。对材质 m，若存在 g ∈ 𝒜_geo 使其某一几何通道（r_mv、r_xm、r_app）的期望不一致度 ≥ 阈值，则 CWA 在 k 次正交探测下检出概率 ≥ 1 − δ_k（δ_k 随 k 指数下降）；这覆盖多路径、飞点、标定偏差、镜面高光、透明物（当存在语义/单目/接触线索时）。反之，**存在不可检测集**：一个「几何上合法的刚体诱饵面」（或背景完全匹配、无任何语义/接触线索的透明物）在两视角内都可与真实表面一致，此时**任何纯几何策略都无法把它与真几何区分**——这是信息论下界，只能靠语义先验或接触（而接触即碰撞）来打破。该下界是定义 321 证据纪律与定理 19 存在的前提。

**引理 21（选择性风险：假阴性主导）** 设痛点稀疏（仅比例 η 的区域 P ≥ τ），归因假阴性率 β（漏掉真痛区）。由于 PAIN 的 resolution bonus 只在「被判为疼」处生效，一个被漏掉的痛区既不会被探测、也不会被保守退避补偿；因此任务风险增量 ≈ β（按痛质量加权）·L_max，其量级由**漏掉的最大痛点**控制，而非平均归因误差。系：**平均归因误差小并不保证安全**；必须给痛点归因置信设安全下界（PIG 的保守侧 + CWA 独立通道 + 几何证据纪律），否则「精准」本身就是风险（对应灵感 5）。

**引理 22（痛点门控的预算效率）** 若痛质量集中于有效支撑 m ≪ N（N 为观测局部数），且 L 可加，则达到与「全图熵门控」相同的期望痛点下降，所需探测次数约降为 N/m 倍。系：这是本轮相对 R69 的效率来源——不是更会问，而是**只问会疼的那几处**。

**定理 18（PAIN 严格包含 R69）** 在 A99–A102 下：(i) 当痛点均匀（P ≡ 常数于所有不确定区）且深度可靠（CWA ≡ 0）时，VoI_pain ∝ R69 的 VoI、PIG 恒通过，PAIN 与 R69 选中同一 g、给出同一 λ；(ii) 当 PIG 失败 / CWA 报警 / 预算耗尽时，PAIN 单调退避到 R69 的纯保守档；(iii) 当痛点稀疏且可辨识时，PAIN 只增加「期望痛点下降为正」的探测、其余与 R69 相同，故期望风险 ≤ R69。因此 R69 是 PAIN 在「均匀痛点 + 深度可靠 + 不探测」边界上的严格退化：安全侧不让步，效率侧获得痛点分辨率红利。

**定理 19（几何探测的安全与无突变）** 几何信息动作 g 经 C-RAS-WM 认证（运动/遮挡/时间）后物理风险 ≤ ε_geo；探测只改变「哪块几何被信任」，不改变安全包络；探测失败/超时/被投毒/CWA 报警时 λ 单调不降地退化为 R69；R68 的提交/换装不变式（定理 15）保持 ⇒ 控制连续、无突变。对不可检测集（引理 20 下界），系统按定义 321 对接触关键动作维持保守——即「无法证伪就默认它可能骗我」。

## 6. 本轮最大风险

**一句话**：PAIN-RAS 的全部效率收益押在「痛点图是真的」这一前提上——**痛点归因本身是估计量，而系统越精准地只处理「疼的地方」，一次假阴性（把真痛点判成不疼）就越无法被其它区域的保守补偿**：它会既不去探测、又免除 R69 的退避，在最该小心处自信地省事；深度相机的自信错误（透明/镜面/多路径给出低方差却错误的几何）恰好是最擅长制造这种假阴性的工具，而它又让基于方差的痛点图「看不出疼」——**归因漏掉的痛点，比任何噪声都致命**。

**次级风险与缓解**：
1. **痛点不可辨识却强行探测**（敏感度病态、符号算错）→ PIG 门控 + 病态即退避；
2. **几何探测本身不安全**（换视角撞物、遮挡 ROI、超时）→ C-RAS-WM 认证 + 定理 19 无突变；
3. **几何投毒/诱饵面**（引理 20 不可检测集）→ 多源证据纪律 + 接触关键动作默认保守 + ℰ_geo 对抗训练；
4. **归因模型被场景塑形**（真痛区显廉价）→ VQAuditor-P + PIG 保守侧 + E313；
5. **实时预算被多视角 warp 击穿** → 仅在 ROI 上算、复用已有位姿、探测低频异步。

# IP-264 PAD：痛点归因（粗网格 + ROI 细化）
class PainAttributor:
    def pain_map(self, o, D, belief):
        P = self.pain_head(self.trunk(o))                # 16x16，<0.05ms
        roi = topk_cells(P, k=8)
        for c in roi:
            J_c = self.jac.task_jacobian(c, D, belief)   # 任务敏感度
            P[c] = norm(J_c) * belief.std_depth(c)       # 敏感度 × 不确定度
        return P, roi

    def identifiability(self, belief):                   # PIG
        J_U = self.jac.restrict(high_uncertainty_subspace(belief))
        m = sigma_min(J_U) / (sigma_max(J_U) + EPS)
        return (m >= M_PIG and norm(J_U) >= J_MIN), m

# IP-266 DRM：深度可靠性物理模型
def depth_reliability(D, refl, angle, grad):
    sig_z  = ALPHA * D**2
    sig_xy = BETA * D / F
    p_hole = sigmoid(K_HOLE*(RHO_MIN-refl) + L_ANGLE*(angle-THETA_MAX) + M_GRAD*grad)
    return sig_z, sig_xy, p_hole, material_prior(D, refl, angle)

# IP-269/270 GCA + CWA：几何一致性 + 自信错误
def geometric_audit(D_now, frame_hist, D_mono, contact, mat):
    r_mv  = min(warp_residual(D_now, D_h, T) for (D_h, T) in frame_hist)
    r_xm  = normalized_abs(D_now - D_mono)
    r_app = appearance_depth_consistency(D_now, frame_hist)
    conf  = depth_confidence(D_now)
    cwa   = conf * max(r_mv > TAU_MV, r_xm > TAU_XM, r_app > TAU_APP) * risky(mat)
    return r_mv, r_xm, r_app, cwa

    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    U_ale, U_epi, modes, _ = M.aud.decompose(...)        # R69 二分
    a_hat = M.fma.flow_anomaly(...)                      # R69 行为似然
    P, roi = M.pad.pain_map(o, obs.D, M.belief)          # 本轮：痛点
    pig_ok, pig_m = M.pad.identifiability(M.belief)
    r_mv, r_xm, r_app, cwa = M.gca.audit(obs.D, M.frame_hist, obs.D_mono,
                                         obs.contact, M.mat)
    g = None
    if pig_ok and max(P[c] for c in roi) > TAU_PAIN and max(cwa) < TAU_CWA:
        g = M.civ.choose_probe(P, o, M.budget, pig_ok)
    if g is not None:
        y = M.gap.execute(g)                             # 过 C-RAS-WM 认证
        P = M.pad.update_pain(P, y)
        r_mv, r_xm, r_app, cwa = M.gca.audit(...)
    U_floor = U_ale + (U_epi if g is None else residual_epi(U_epi, y))
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if (not pig_ok) or (max(cwa) > TAU_CWA) or M.budget.exhausted():
        lam = max(lam, lam_floor(U_ale + U_epi)); lam = max(lam, 0.8)   # R69 保守档
    k = M.c_ras_wm.certified_prefix(...)
    if obs.contact_critical and not geo_evidence_agree(obs.D, obs.D_mono, obs.contact):
        lam = max(lam, 0.8); k = min(k, shrink_local(roi))              # 证据纪律
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(P, pig_m, cwa, g, lam, evidence_hash(obs))
    return k, lam, mode, (U_ale, U_epi, P)

## 4. 推导

**引理 19（痛点一阶展开与归因完备性）** L 对 D 为 C²、Hessian 有界、δD 零均值 ⇒ `Pain(c)=E|⟨∇_{D_c}L,δD_c⟩|+O(E‖δD_c‖²)`；若 L 区域可加，则 `Σ_c Pain(c)=E[L(π(o),s)]−E[L(π(o^{all}),s)]`，归因完备，残差为跨区「痛点耦合」。

**引理 20（自信错误可检测性与不可检测下界）** 若存在允许探测 g 使某几何通道期望不一致 ≥ 阈值，则 k 次正交探测的 CWA 检出概率 ≥ 1−δ_k（δ_k 随 k 指数下降），覆盖多路径/飞点/标定偏差/镜面高光/带语义或接触线索的透明物；但存在「几何上合法的刚体诱饵面」与「背景完全匹配且无线索的透明物」，两视角内与真几何不可区分 ⇒ **纯几何策略的不可检测下界**，只能靠语义先验或接触打破（而接触即碰撞）。系：定义 321 证据纪律与定理 19 的必要性。

**引理 21（选择性风险：假阴性主导）** 痛点稀疏（比例 η）、归因假阴性率 β ⇒ 任务风险增量 ≈ β（痛质量加权）·L_max，由**漏掉的最大痛点**控制，而非平均归因误差。系：平均误差小不保证安全，须给归因置信设安全下界（PIG 保守侧 + CWA 独立通道 + 证据纪律）。

**引理 22（痛点门控预算效率）** 痛质量集中于有效支撑 m≪N 且 L 可加 ⇒ 达到与全图熵门控相同期望痛点下降，探测次数约降为 N/m 倍。

**定理 18（PAIN 严格包含 R69）** A99–A102 下：(i) 痛点均匀且深度可靠 ⇒ VoI_pain ∝ VoI、PIG 恒通过，PAIN 与 R69 同 g 同 λ；(ii) PIG 失败/CWA/预算耗尽 ⇒ 单调退避到 R69 纯保守；(iii) 痛点稀疏可辨识 ⇒ 期望风险 ≤ R69。R69 = 「均匀痛点 + 深度可靠 + 不探测」边界；安全不让步，效率获痛点分辨率红利。

**定理 19（几何探测安全与无突变）** g 经 C-RAS-WM 认证后物理风险 ≤ ε_geo；探测只改「信任哪块几何」，不改安全包络；失败/超时/投毒/CWA 时 λ 单调不降退化为 R69；R68 换装不变式保持 ⇒ 连续、无突变；对不可检测集（引理 20）按证据纪律默认保守。

## 7. 本轮最大风险

**一句话**：PAIN-RAS 的全部效率收益押在「痛点图是真的」这一前提上——**痛点归因是估计量，系统越精准地只处理「疼的地方」，一次假阴性（把真痛点判成不疼）就越无法被其它区域的保守补偿**：它既不去探测、又免除 R69 退避，在最该小心处自信地省事；深度相机的自信错误（透明/镜面/多路径给出低方差却错误的几何）恰好最擅长制造这种假阴性，还让基于方差的痛点图「看不出疼」——**归因漏掉的痛点，比任何噪声都致命**。

**次级风险与缓解**：痛点不可辨识却强行探测（PIG + 病态即退避）；探测本身不安全（C-RAS-WM 认证 + 定理 19）；几何投毒/诱饵面（引理 20 下界 → 多源纪律 + 接触关键动作默认保守 + ℰ_geo 对抗训练）；痛点图被场景塑形（VQAuditor-P + PIG 保守侧 + E313）；实时预算被多视角 warp 击穿（仅 ROI、复用位姿、探测低频异步）。
