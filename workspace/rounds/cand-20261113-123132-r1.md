# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「开源硬件」×「实时控制」）

> 第 65 轮把「可证伪」升级为「可归因」，其自述的最大风险极其准确：**归因依赖"故障属于有限假设集"且"视觉与几何失效相互独立"；透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，未知复合故障被强行归入最近假设，系统因"已归因"而更自信地继续执行。** 本轮不增加第四个语义模态，而是把问题再往下压一层：第 65 轮问「哪一层坏了」，HALO 问「**你说的那一层，真的就是刚刚在电机相线上、在这个时钟沿内发生的事吗**」。本轮核心命题是：
>
> **把"语义可归因"升级为"执行可证"：用开源硬件把执行器内部（相电流、母线电压、编码器、驱动故障、温度、固件任务时序）变成第三条物理独立证据通道；用实时控制把每条证据与每条命令钉在同一个同步时钟上；证书只在"证据足够新、命令确已按认证前缀执行、硬件包络未被突破、监控在截止期前完成"时有效。**

## 0. 直觉与动机

**灵感 1（开源硬件 → 把执行器内部变成第三条、可审计的证据通道）**
直觉：第 65 轮的三条证据（几何、视觉、力）都位于"机器人外部或末端"，它们仍可能共因失效。但执行器本身——FOC 的 i_d/i_q、母线电压 v_bus、MOSFET 结温、编码器原始计数与插值误差、驱动器 fault flag、固件任务执行时间——是**物理上另一条链路**。闭源平台把这些藏在黑盒里；开源硬件（ODrive/moteus/SimpleFOC/开源 EtherCAT 从站）不仅暴露它们，还允许审计固件到底怎么采样、怎么限幅、怎么通信、怎么处理故障。因此开源硬件不是"更便宜的替代品"，而是**让安全证书第一次可以向下接地到相线**，并让"最后一层安全盾"从 Python 语义层搬到有 WCET 保证的固件/硬件层。但必须诚实：开源 ≠ 可信；硬件会坏、固件有 bug、社区分叉会让 HCD 语义漂移。所以需要"可审计抽象 + 测量启动 + 固件哈希 + 独立模拟通道交叉校验"，而不是盲目信任。

**灵感 2（实时控制 → 时间是一等安全变量，不是调度约束）**
直觉：第 65 轮的证书默认"观测→归因→认证→执行"瞬时完成。真实系统里，证据有年龄，认证有计算时间，命令有传输与执行延迟，时钟有漂移，采样有混叠。一个在 t 时刻被认证为安全的命令，到 t+Δ 才作用到植物上时，植物早已漂出证书假设的集合。于是安全裕度被时间**侵蚀**：m_t = m_sem − L·(Δ_react+ε_clk) − δ_hw。实时控制的价值不只是"更快"，而是**让这个 Δ 可测、可界、可证**（WCET、抖动上界、EtherCAT 分布式时钟、PTP、看门狗、优先级分析）。这把"实时性"从性能指标变成**安全预算的一部分**；也让"高采样率"成为防时间混叠的必要条件——接触颤振/冲击若高于 Nyquist，会被折叠成低频残差并误归因为几何/模型故障。

**灵感 3（开源硬件 × 实时控制 → 电流触觉：不接触也能做系统辨识与故障判别）**
直觉：第 65 轮的 AFA 主动探针要"碰"物体，易损物体上代价高。开源硬件暴露相电流，实时控制允许 kHz 级波形注入；于是可以在**完全不接触物体**的情况下，向电机注入安全幅度内的 d 轴/啁啾电流，观测编码器响应，辨识惯量 J、阻尼 b、摩擦 τ_f、backlash、传动刚度，并用扰动观测器估计外力矩。这把"电流"变成一种**免接触的触觉**：既为 H_model 提供独立证据，又在施力前给出执行器侧安全力下界 f_safe^act，还能在 VISTA 判 ambiguous 时用零接触探针打破僵局。

**灵感 4（三灵感合流 → HALO：Hardware-Attested Latency-Ordered safety，硬件担保、时延有序的执行接地闭环）**
闭环：开源硬件桥 OHB 把执行器内部归一化为硬件证据 h_t → 时间证据账本 TEL 给每条证据/命令同步时间戳、年龄、带宽与有效期 → 执行包络认证 EEA 检查"植物是否还在模型假设内" → 时序故障归因 TFA 把硬件签名与时间签名并入 FIR → 免接触系统辨识 CSI 提供零接触探针 → 语义×实时证书编译器 RTC 求 k*=min(k*_sem,k*_tmp) → 时间域盾 TDS 做截止期感知的 fail-closed → 可移植证书代数 PCA 让证书跨开源 BOM 迁移 → AIC-T 认证时钟/时序/共因攻击。第 65 轮把"接触"拆成前中后；HALO 把"执行"拆成**证据时间、决策时间、通信时间、作用时间**，并要求四段时间被同一个同步时钟与同一份证书覆盖。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → TFA**：证据向量加入硬件通道与时间通道；新增 H_hw（电流/电压/温度/编码器/驱动故障）与 H_time（延迟/抖动/丢帧/时钟漂移/优先级反转）；新增 H_common 表示共因。
- **AFA → AFA-CSI**：探针集加入零接触电流探针（chirp/step/d 轴注入），易损物体优先 CSI，物理接触探针降为最后手段。
- **RSC-V → RSC-X**：增加 r_hw 与 r_time 两个半径，只膨胀被归因者；r_time=v_max·(age_max+ε_clk) 直接吃掉语义裕度。
- **CSC → CSC-T**：认证前缀同时受语义安全与实时可调度性约束，k*=min(k*_sem,k*_tmp,k_max)。
- **WCV-V → WCV-T**：搜索域交集增加"时间有效域"𝒯 与"硬件包络"Ω。
- **Shield → TDS**：安全监控本身是有 WCET 的实时任务；错过截止期即 fail-closed，而不是执行未认证命令。
- **CSP-V → CSP-T**：块边需 Valid(J_halo) 且端到端响应时间 R_edge≤D_edge；块签名增时间签名。
- **OLP/DIR/SSB**：在线学习使用带时间戳证据，但实时流仍零学习写；DIR 增时序错位/重放/时钟漂移样本。
- **J_vista → J_halo**：证书增 hardware_attest、hcd_hash、clock_sync_ver、evidence_age_max、latency_bound、envelope_ok、wcet_margin、temporal_conflict、firmware_hash。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（HALO 闭环）**：HALO = (VISTA, OHB, TEL, EEA, TFA, CSI, RTC, TDS, PCA, AIC-T, J_halo)。定位：VISTA 的"执行接地 + 时间接地"升级。不变式：**所有学习、归因、证书编译只在语义流；实时流只做带时间戳的硬件证据采集、年龄/包络/截止期检查、认证前缀执行与 fail-closed，零学习写操作。** 三层时间尺度：L0 FOC/电流环（10–40 kHz，µs 级，MCU/FPGA）；L1 实时运动与安全流（100–1000 Hz，1–2.7 ms，PREEMPT_RT/EtherCAT）；L2 语义流（1–20 Hz，学习/归因/规划）。
- **定义 234（硬件能力描述与开源硬件桥 OHB）**：HCD=(传感器清单, 采样率, 量程, 分辨率, WCET, 抖动, 同步方式, 固件哈希)。OHB 把厂商寄存器归一化为硬件证据 h_t=[i_d,i_q,v_bus,T_mos,enc_age,enc_err,drv_flags,cpu_slack,τ_sync]∈ℝ^{d_h}。h_t 是"执行器视角"，与视觉/力在物理链路上独立；HCD 可审计、可比较，是证书可移植的前提。
- **定义 235（时间证据账本 TEL 与证据带宽）**：每条证据 e 带同步时间戳 τ_e、发布时刻 p_e、年龄 age_e(t)=t−τ_e、带宽 B_e（采样率/抗混叠滤波截止）。时钟同步误差 |τ_e−τ_e^true|≤ε_clk。TEL 为证书维护证据年龄上界 Δ_E 与有效期 [t_c,t_c+Δ_cert]。证据"新鲜"⇔age_e≤Δ_e 且 τ_e 落在证书窗口内；"可表征"⇔被认证事件的最高频率 < B_e/2（Nyquist）。**证书不得对超出证据带宽的现象作安全承诺**，否则发生时间混叠。
- **定义 236（执行包络认证 EEA）**：模型假设的包络 Ω={电流-力矩线性区, 母线电压范围, 温度上限, 编码器无丢步, 无驱动降额, CPU 有正 slack}。EEA 每个实时周期检查 h_t∈Ω 并输出包络违背指示。包络违背 ⇒ 语义层模型不再可信，必须**先归因 H_hw/H_time，再谈 H_model/H_geo**。
- **定义 237（免接触系统辨识 CSI）**：在安全幅度内注入探针电流 i_p(t)（chirp 或 step），测量编码器 q(t)，辨识 θ_act=(J,b,τ_f,T_backlash,k_t)，满足 τ_m=k_t·i_q，J·q̈+b·q̇+τ_f+τ_ext=τ_m；用扰动观测器估 τ̂_ext。约束 |i_p|≤i_safe、|τ̂_ext|≤τ_strain、且**不接触物体**。输出执行器侧安全力下界 f_safe^act，供 AFA 与 CSC 使用。
- **定义 238（时序故障归因 TFA）**：扩展签名 ρ⁺=[ρ,ρ_hw,ρ_time]（ρ 为第 65 轮 15 维）。新增假设 H_hw（电流/电压/温度/编码器/驱动故障）与 H_time（延迟/抖动/丢帧/时钟漂移/优先级反转/混叠）；H_common 表示视觉×几何×硬件共因。时间签名含证据年龄分布、命令延迟、抖动、deadline miss、时钟偏差、带宽裕度。处置：H_hw→限流/降温/降额/切冗余通道；H_time→缩短 k*、提优先级、切安全模式、提高采样率或加抗混叠滤波。
- **定义 239（时间裕度侵蚀）**：设语义安全裕度 m_sem、安全裕度对状态的 Lipschitz 常数 L_m、状态漂移速度上界 v_max、端到端反应时间 Δ_react=t_act−t_obs、时钟误差 ε_clk、硬件包络不确定 δ_hw。执行时刻真实裕度满足 m_true ≥ m_sem − L·(Δ_react+ε_clk) − δ_hw，其中 L=L_m·v_max。定义时间有效裕度 m_t=m_sem−L·(Δ_react+ε_clk)−δ_hw；仅当 m_t≥0 证书可执行。
- **定义 240（实时证书编译器 RTC）**：给定固定优先级任务集、WCET C_i、阻塞 B_i、周期 T_i、截止期 D，响应时间 R_i=C_i+B_i+Σ_{j∈hp(i)}⌈R_i/T_j⌉C_j；监控任务须 R_monitor≤D_monitor。语义前缀 k*_sem；时间可执行前缀 k*_tmp=min(H,⌊(D_react−R_monitor)/T_step⌋)（D_react 由不可逆视界 m 与 v_max 反解）。输出 k*=min(k*_sem,k*_tmp,k_max)；若 k*=0，进入 safe_hold。RTC 同时输出 wcet_margin 与 latency_bound。
- **定义 241（时间域盾 TDS）**：安全监控是有 WCET 的实时任务；命令提交前必须完成"证据新鲜性 + 时间可表征性 + 包络 + 越界"四项检查。若监控未在截止期前完成，**缺省执行安全动作**（保持/柔顺回退/梯度断使能），而不是执行未认证命令。安全动作本身须落在无新证据也可证的 fail-safe 不变集 𝒮_hold 内（由可达集/生存核离线计算）。
- **定义 242（可移植证书代数 PCA）**：硬件精化偏序 HCD_new⊒HCD_old 表示新硬件至少提供旧硬件的能力（采样率、量程、同步精度、包络监测不降）。若存在保不变映射 ψ:H_new→H_old 且 |ψ(h)−h_old|≤δ_map，则 J_halo 可从旧硬件迁移到新硬件，安全裕度损失 ≤L_map·δ_map。证书携 firmware_hash 与 HCD 版本；BOM/固件变更即触发再认证。
- **定义 243（硬件根信任与测量启动）**：开源可审计 ≠ 可信。证书要求 signed firmware + measured boot + 运行时 HCD 哈希一致 + 单调计数器防重放；attest=(firmware_hash,hcd_hash,clock_sync_ver,nonce)。并鼓励用**独立模拟通道**（外部功率计/母线电流/编码器 A/B 相）交叉校验数字证据，防止固件谎报。
- **定义 244（WCV-T 时间-硬件联合压缩）**：搜索域 B(φ̂,r)∩𝒢∩K∩ℱ∩𝒱∩𝒯∩Ω，其中 𝒯 为时间有效域（年龄/延迟/带宽），Ω 为执行包络。交集为空则回退 B(φ̂,r)∩Ω 并置 `temporal_conflict=True` 写入 J_halo。
- **定义 245（CSP-T 时间感知块规划）**：块边需 Valid(J_halo) 且端到端响应时间 R_edge≤D_edge；TSL 技能签名增时间签名分布，时间 OOD（抖动/延迟/带宽分布偏移）即不入图；可插入 `null_test`、`csi_probe`、`clock_probe`、`power_probe` 元技能。
- **定义 246（AIC-T 时序/硬件对抗认证）**：干扰集 ℰ_T=ℰ_V×ℰ_hw×ℰ_time，ℰ_hw 含电流饱和、母线暂降、热降额、编码器丢步、驱动 fault、固件谎报；ℰ_time 含时钟偏斜、重放、优先级反转、通信延迟、deadline miss、采样混叠；共因含共享电源/时钟/地/散热。ρ_dir 在 ℰ_T 上重算（n_cert 128→160，其中 32 给时序/硬件），J_dir 增 timing_calib_ver、hardware_profile_ver。
- **定义 247（HALO 证书 J_halo）**：J_halo=(J_vista, hardware_attest, hcd_hash, firmware_hash, clock_sync_ver, evidence_age_max, latency_bound, envelope_ok, temporal_valid, wcet_margin, k*, temporal_conflict)。Valid ⇔ Valid(J_vista) ∧ attest 有效且哈希一致 ∧ 证据新鲜且可表征 ∧ envelope_ok ∧ m_t≥0 ∧ k*≥1 ∧ 监控满足截止期 ∧ temporal_conflict=False。
- **定义 248（HALO 闭环算子）**：语义流 [VISTA 全链→OHB 硬件证据→TEL 账本→EEA 包络→TFA 归因→CSI/AFA-CSI→RTC 编译→PCA 迁移/再认证→CSP-T 块规划→J_halo]；实时流 [同步采样→硬件证据→年龄/带宽/包络检查→TDS 截止期检查→k* 前缀派发→attest 记录→J_halo 构建]。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（时间裕度侵蚀）**：若安全裕度对状态 L_m-Lipschitz、状态速度 ≤v_max、端到端反应时间 Δ_react、时钟误差 ε_clk，则 m_true≥m_sem−L_m·v_max·(Δ_react+ε_clk)−δ_hw。故实时预算不是性能开销，而是**从安全裕度里直接扣款**。
- **引理 10（可调度性 ⇒ 可执行性）**：若 R_monitor≤D_monitor 且 k*·T_step+R_monitor≤D_react，则认证前缀在截止期内完整执行，且监控结果在首个动作提交前可用；否则 RTC 必返回 k*=0 或触发 safe_hold。
- **定理 9（执行接地可靠性）**：Valid(J_halo) ⇒ 实际执行命令等于认证前缀 ∧ 证据年龄/带宽满足证书假设 ∧ 植物在作用时刻仍处语义证书的 Ω∩𝒯 内（至 m_t 边界）∧ 监控未错过截止期。证书链从"几何-技能-干扰-接触-归因"扩到"**执行-时间-硬件**"。
- **定理 10（第三通道可辨识性）**：令 J_2=S₂ᵀΣ₂⁻¹S₂、J_3=J_2+S_hᵀΣ_h⁻¹S_h。故障方向 v 在 VISTA 下不可辨（vᵀJ_2v=0）而在 HALO 下可辨 ⇔ S_h v≠0。因此当视觉×几何共因使 S₂ 列共线时，只要硬件通道在该方向有非零投影，共因即可被分离或至少判 ambiguous；CSI 可在**零接触**下提供该投影。
- **定理 11（可移植性）**：HCD_new⊒HCD_old 且存在保不变映射 ψ、|ψ(h_new)−h_old|≤δ_map ⇒ 旧证书在 new 上有效，裕度损失 ≤L_map·δ_map；精化失败或哈希不一致则拒绝迁移。
- **实时性**：L0 由 MCU/FPGA 承担（µs），OHB 取数 <0.1ms、TEL/年龄/带宽 <0.03ms、EEA <0.05ms、TDS 检查 <0.03ms；L1 总预算 ≤2.7ms（A94 修订契约），L2 全部卸载。

## 2. 形式化定义（完整版）

**定义 233（HALO 闭环）** HALO 是 VISTA 的"执行接地 + 时间接地"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 OHB（开源硬件桥）、TEL（时间证据账本）、EEA（执行包络认证）、CSI（免接触系统辨识）、TFA（时序故障归因）、RTC（实时证书编译器）、TDS（时间域盾）、PCA（可移植证书代数），并原位升级 FIR→TFA、AFA→AFA-CSI、RSC-V→RSC-X、CSC→CSC-T、WCV-V→WCV-T、CSP-V→CSP-T、AIC-V→AIC-T、J_vista→J_halo。

时间尺度分三层：

| 层 | 频率 | 平台 | 职责 | 证书角色 |
|---|---|---|---|---|
| L0 | 10–40 kHz | MCU/FPGA（开源 FOC） | 电流环、硬件限流/限位、编码器采样、h_t、硬件 interlock | 产生µs级证据，执行最后一道硬约束 |
| L1 | 100–1000 Hz | PREEMPT_RT + EtherCAT/CAN-FD | 运动/安全流、TDS、k* 派发、attest 记录 | 实时证书的作用域 |
| L2 | 1–20 Hz | Linux 语义流 | 学习、归因、规划、证书编译 | 语义证书的生成域 |

不变式：**所有学习、归因、证书编译只在 L2；L1 只做带时间戳的证据采集、年龄/带宽/包络/截止期检查、认证前缀执行与 fail-closed；L0 只做确定性控制与硬件 interlock。实时路径零学习写操作。**

**定义 234（硬件能力描述与开源硬件桥 OHB）** HCD 是开源硬件栈的可审计能力声明：
HCD=(sensors, f_s, range, resolution, C_wcet, J_jitter, sync_method, firmware_hash, hcd_version)。
OHB 把不同厂商（ODrive/moteus/SimpleFOC/开源 EtherCAT 从站）的寄存器归一化为硬件证据
h_t=[i_d,i_q,v_bus,T_mos,enc_age,enc_err,drv_flags,cpu_slack,τ_sync]∈ℝ^{d_h}。
其中 enc_age 为编码器采样到发布的年龄，enc_err 为编码器预测残差（丢步/插值误差），drv_flags 为过流/过压/过温/编码器错误位，cpu_slack 为当前周期剩余 WCET 裕度，τ_sync 为本地时钟相对全局时钟的偏差。**h_t 是执行器视角，与几何、视觉、力在物理链路上独立**；HCD 可比较、可审计，是 PCA 的前提。

**定义 235（时间证据账本 TEL 与证据带宽）** 每条证据 e 附同步时间戳 τ_e、发布时刻 p_e、年龄 age_e(t)=t−τ_e、带宽 B_e（采样率与抗混叠滤波截止的较小者）。全局时钟同步误差满足 |τ_e−τ_e^true|≤ε_clk。TEL 为每个证书维护证据年龄上界 Δ_E 与有效期 [t_c,t_c+Δ_cert]。
- **新鲜**：age_e(t_use)≤Δ_e，且 τ_e 落在证书窗口内。
- **可表征**：被认证事件的最高频率 f_event<B_e/2（Nyquist）。**证书不承诺超出证据带宽的安全**；否则发生时间混叠（见命题 2）。
TEL 还记录命令的 dispatch 时刻与编码器中断中读取的实际作用时刻，形成可审计的"观测→决策→派发→作用"时间链。

**定义 236（执行包络认证 EEA）** 语义模型只在包络
Ω={ |i_q|≤i_lin_max（电流-力矩线性区）, v_min≤v_bus≤v_max 且纹波≤v_rip, T_mos≤T_max−ΔT_derate, enc_err≤ε_enc 且无丢步, drv_flags=0, cpu_slack≥0, τ_sync≤ε_clk }
内成立。EEA 每个 L0/L1 周期检查 h_t∈Ω，并在违背时置包络标志。**包络违背意味着语义层模型不再可信：必须先归因 H_hw/H_time，再谈 H_model/H_geo。** 这把第 65 轮"模型错"从抽象假设变成可测的物理事件。

**定义 237（免接触系统辨识 CSI）** 在安全幅度内注入探针电流 i_p(t)（对数啁啾或阶跃），覆盖电流环带宽内的多个模态，测量编码器 q(t)。执行器-传动模型：
τ_m=k_t·i_q,  J·q̈+b·q̇+τ_f·sign(q̇)+τ_ext=τ_m。
用最小二乘/递推辨识 θ_act=(J,b,τ_f,T_backlash,k_t)；用扰动观测器
τ̂_ext=τ_m−(Ĵ·q̈+b̂·q̇+τ̂_f)
估计外力矩。约束：
|i_p|≤i_safe, |τ̂_ext|≤τ_strain, 温升≤ΔT_probe, 且**末端不接触物体**。
输出执行器侧安全力下界 f_safe^act=min(f_lim, τ_safe/r_ee)，供 AFA-CSI 与 CSC-T 使用。CSI 的价值：在易损物体上，用**零接触的执行器内部激励**替代第 65 轮必须"压一下"的物理探针。

**定义 238（时序故障归因 TFA）** 扩展签名为
ρ⁺=[ρ, ρ_hw, ρ_time] ∈ ℝ^{15+d_hw+d_time}，
其中 ρ 为第 65 轮的阶段化力/视觉/块签名，ρ_hw 为硬件证据的残差统计（电流/电压/温度/编码器/驱动/时序），ρ_time 为证据年龄分布、命令延迟、抖动、deadline miss、时钟偏差、带宽裕度。
故障假设集扩展为
ℋ⁺={H0 健康, H_geo 几何幻觉, H_force F/T 偏置, H_model 接触模型错, H_vis 视觉错, H_policy 策略 OOD, H_hw 执行器硬件故障, H_time 时序/实时故障, H_common 共因}。
后验 P(H|ρ⁺)∝p(ρ⁺|H)P(H)，用离线故障注入 + 真机标定台拟合 p(ρ⁺|H)。定向处置：
- **H_hw**：限流/降额/切冗余电流或编码器通道/停用故障相；先保硬件，不谈几何。
- **H_time**：缩短 H 与 k*、提高监控优先级、启用抗混叠、切更高速率或安全模式；记录 deadline miss。
- **H_common**：不强行归因，进入 safe_hold + 多通道交叉校验，等待共因源（电源/时钟/散热/对抗物体）被隔离。
- H_geo/H_force/H_model/H_vis/H_policy 沿用第 65 轮处置，但**必须在 Ω 成立且证据新鲜时**才允许。

**定义 239（时间裕度侵蚀）** 设语义安全裕度 m_sem（证书给出的约束距离），安全裕度对状态的 Lipschitz 常数为 L_m，状态漂移速度上界 v_max，端到端反应时间 Δ_react=t_act−t_obs，时钟误差 ε_clk，硬件包络不确定 δ_hw。则执行时刻的真实裕度
m_true ≥ m_sem − L_m·v_max·(Δ_react+ε_clk) − δ_hw = m_sem − L·(Δ_react+ε_clk) − δ_hw，
其中 L=L_m·v_max。定义**时间有效裕度**
m_t=m_sem−L·(Δ_react+ε_clk)−δ_hw。
仅当 m_t≥0 时证书可执行；m_t<0 必须缩短 k*、提高速率或进入 safe_hold。**实时延迟不是性能开销，而是从安全裕度里直接扣款。**

**定义 240（实时证书编译器 RTC）** 给定固定优先级抢占任务集 {τ_i}，响应时间分析：
R_i=C_i+B_i+Σ_{j∈hp(i)}⌈R_i/T_j⌉·C_j。
监控任务须满足 R_monitor≤D_monitor。设不可逆视界为 m，状态速度 v_max，则反应预算 D_react=m/v_max。语义认证前缀 k*_sem（第 65 轮 CSC）；时间可执行前缀
k*_tmp=min(H, ⌊(D_react−R_monitor)/T_step⌋)。
最终 k*=min(k*_sem,k*_tmp,k_max)。若 k*=0，进入 safe_hold。RTC 同时输出 wcet_margin=D_monitor−R_monitor 与 latency_bound=Δ_react^max。这把"语义安全"和"实时可调度"编译成同一个前缀长度。

**定义 241（时间域盾 TDS）** 安全监控本身是有 WCET 的实时任务，检查四项：证据新鲜性、时间可表征性（带宽/Nyquist）、执行包络、安全边界。命令提交前，监控必须完成且结果为正。若监控未在截止期前完成、或任一检查失败，则**缺省执行安全动作**（保持/柔顺回退/梯度断使能），而不是执行未认证命令。安全动作必须落在 fail-safe 不变集 𝒮_hold 内（由离线可达集/生存核计算：对任意 Δ_fail 内的状态漂移，动作仍安全）。L0 另设独立硬件 interlock（过流/过压/超温/超限位/看门狗），不依赖 Linux 是否存活。

**定义 242（可移植证书代数 PCA）** 定义硬件精化偏序：HCD_new⊒HCD_old 当且仅当新硬件的采样率、量程、分辨率、同步精度、WCET、包络监测能力均不劣于旧硬件。若存在保不变映射 ψ:H_new→H_old（把新硬件的 h 映射到旧语义）且 |ψ(h_new)−h_old|≤δ_map，则旧硬件的 J_halo 可迁移到新硬件，安全裕度损失 ≤L_map·δ_map。证书必须携带 firmware_hash、hcd_hash、标定版本；BOM/固件变更即触发再认证。这样开源硬件的"可替换性"才不等于"安全性漂移"。

**定义 243（硬件根信任与测量启动）** 开源可审计 ≠ 可信。证书要求：
signed firmware + measured boot + 运行时 HCD 哈希与固件哈希一致 + 单调计数器/nonce 防重放；
attest=(firmware_hash,hcd_hash,clock_sync_ver,nonce)。
并尽量用**独立模拟通道**交叉校验数字证据（外部功率计校验 i_q/v_bus，编码器 A/B 相原始信号校验解析位置，独立温度传感器校验结温），防止固件谎报或单点传感器故障。

**定义 244（WCV-T 时间-硬件联合压缩）** 搜索域
B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ 𝒯 ∩ Ω，
其中 𝒯 为时间有效域（证据年龄、延迟界、带宽），Ω 为执行包络。CVaR 尾部 n_worst=8；归因模糊时按后验加权做边缘化尾部。交集为空则回退 B(φ̂,r)∩Ω，置 `temporal_conflict=True` 写入 J_halo。

**定义 245（CSP-T 时间感知块规划）** 在 CSP 的层级 A* 上以块为边：每条块边需 Valid(J_halo) 且端到端响应时间 R_edge≤D_edge。TSL 技能 σ 绑定块签名分布与**时间签名分布**（延迟/抖动/带宽）；实际签名到分布的 Mahalanobis 距离>τ_chunk 即判 OOD，不入图。新增元技能：`null_test`（零力窗标定）、`csi_probe`（电流触觉）、`clock_probe`（时钟同步校验）、`power_probe`（母线/功率校验）。

**定义 246（AIC-T 时序/硬件对抗认证）** 干扰集
ℰ_T=ℰ_V×ℰ_hw×ℰ_time，
ℰ_hw 含电流饱和、母线暂降、热降额、编码器丢步、驱动 fault、固件谎报、传感器单点故障；ℰ_time 含时钟偏斜、重放、优先级反转、通信延迟、deadline miss、采样混叠；共因含共享电源/时钟/地/散热。ρ_dir 在 ℰ_T 上重算（n_cert 128→160，其中 32 用于时序/硬件/共因）；ρ_force 在最坏偏置与最坏时序下取最坏；J_dir 增 timing_calib_ver、hardware_profile_ver。**共因/时序攻击下不要求归因正确，只要求判 ambiguous 并 fail-closed 降级。**

**定义 247（HALO 证书 J_halo）** J_halo=(J_vista, hardware_attest, hcd_hash, firmware_hash, clock_sync_ver, evidence_age_max, latency_bound, envelope_ok, temporal_valid, wcet_margin, k*, temporal_conflict)。验证规则：
Valid(J_halo) ⇔ Valid(J_vista)
∧ hardware_attest 有效且哈希一致
∧ evidence_age_max≤Δ_E 且所有证据可表征
∧ envelope_ok ∧ m_t≥0
∧ k*≥1 ∧ R_monitor≤D_monitor
∧ temporal_conflict=False。
审计链新增：证据何时采样（age）、命令何时真正作用（attest）、硬件是否在包络内（Ω）、监控是否赶上截止期（wcet_margin）、证书在哪种硬件能力上有效（HCD）。

**定义 248（HALO 闭环算子）** 伪代码见 IP-233。语义流：[VISTA 全链→OHB 硬件证据→TEL 账本→EEA 包络→TFA 归因→CSI/AFA-CSI→RTC 编译→PCA 迁移/再认证→CSP-T 块规划→J_halo]；实时流：[同步采样→硬件证据→年龄/带宽/包络检查→TDS 截止期检查→k* 前缀派发→attest 记录→J_halo 构建]。

class OpenHardwareBridge:
    """归一化开源硬件证据；不信任厂商语义，只暴露可审计量。"""
    FIELDS = ('i_d', 'i_q', 'v_bus', 'T_mos', 'enc_age', 'enc_err',
              'drv_flags', 'cpu_slack', 'tau_sync')

    def __init__(self, hcd, transport):
        self.hcd = hcd                    # 采样率/量程/同步方式/固件哈希
        self.transport = transport        # EtherCAT / CAN-FD / SPI

    def read(self):
        raw = self.transport.latest()     # 从 L0 共享内存/DC 同步帧读取
        h = np.array([raw[k] for k in self.FIELDS], dtype=np.float64)
        h[-1] = self.clock.offset_to_global()   # τ_sync
        return h

    def envelope_ok(self, h, omega):
        i_d, i_q, v_bus, T, enc_age, enc_err, flags, slack, tau = h
        return (abs(i_q) <= omega.i_lin_max
                and omega.v_min <= v_bus <= omega.v_max
                and T <= omega.T_max - omega.dT_derate
                and enc_err <= omega.eps_enc
                and flags == 0
                and slack >= 0.0
                and abs(tau) <= omega.eps_clk)


class TemporalEvidenceLedger:
    """每条证据带时间戳/年龄/带宽；证书只引用窗口内的证据。"""
    def __init__(self, eps_clk, delta_E):
        self.eps_clk, self.delta_E = eps_clk, delta_E
        self.items = deque(maxlen=4096)

    def put(self, key, value, t_sample, bandwidth):
        self.items.append(dict(key=key, value=value, tau=t_sample,
                               p=now(), B=bandwidth))

    def fresh_and_representable(self, keys, t_use, f_event):
        for it in self._latest(keys):
            age = t_use - it['tau']
            if age < -self.eps_clk or age > self.delta_E:
                return False, 'stale'
            if 2.0 * f_event >= it['B']:
                return False, 'alias'
        return True, 'ok'

class ExecutionEnvelopeAttestation:
    def check(self, h, omega):
        ok = OpenHardwareBridge.envelope_ok(None, h, omega)
        # 包络外：先硬件/时间，后几何/模型
        return {'ok': ok,
                'reason': None if ok else self._classify(h, omega)}

    def _classify(self, h, omega):
        if abs(h[1]) > omega.i_lin_max: return 'current_saturation'
        if not (omega.v_min <= h[2] <= omega.v_max): return 'bus_sag'
        if h[3] > omega.T_max - omega.dT_derate: return 'thermal_derate'
        if h[4] > omega.eps_enc or h[5] > omega.eps_enc: return 'encoder_loss'
        if h[6] != 0: return 'driver_fault'
        return 'timing_slack'


class CurrentSystemIdentifier:
    """零接触电流触觉：在安全幅度内注入 chirp，辨识执行器/传动。"""
    def identify(self, i_safe, encoder, dt, band=(20.0, 2000.0)):
        i_p = log_chirp(amp=i_safe, f0=band[0], f1=band[1], dt=dt)
        q, qd, qdd = self._excite_and_measure(i_p, encoder, dt)
        tau_m = self.k_t * i_p
        theta = fit_model(tau_m, q, qd, qdd,
                          model='J*qdd + b*qd + tau_f*sign(qd)')
        cond = persistent_excitation_condition(i_p, q, qd)
        return theta, cond            # cond 差 ⇒ 不可辨识，拒绝用于证书

    def disturbance_observer(self, i_q, q, qd, qdd, theta):
        tau_m = self.k_t * i_q
        return tau_m - (theta.J * qdd + theta.b * qd + theta.tau_f * np.sign(qd))

    def safe_force(self, theta, r_ee, strain_limit):
        tau_safe = strain_limit * theta.k_t / max(theta.k_t, 1e-9)
        return min(self.f_lim, tau_safe / max(r_ee, 1e-6))

class TemporalFaultAttribution:
    HYP = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis',
           'H_policy', 'H_hw', 'H_time', 'H_common')

    def signature(self, phases, hw, tel):
        return np.concatenate([
            np.asarray(phases['approach']), np.asarray(phases['touch']),
            np.asarray(phases['load']),
            hw_stats(hw), tel_stats(tel)])          # 15 + d_hw + d_time

    def attribute(self, rho_plus):
        logp = {h: np.log(self.lik[h](rho_plus) + 1e-12) + np.log(self.prior[h])
                for h in self.HYP}
        z = np.array(list(logp.values())); z -= z.max()
        post = {h: float(np.exp(v) / np.exp(z).sum()) for h, v in logp.items()}
        h_star = max(post, key=post.get)
        return post, h_star, post[h_star] < 1.0 - self.delta_fi

    def directed_demote(self, h_star, balls, w_vis, H, omega):
        if h_star == 'H_hw':
            limit_current(); thermal_derate(); switch_redundant_sense()
        elif h_star == 'H_time':
            H = max(H_MIN, H // 2); raise_monitor_priority(); enable_antialias()
        elif h_star == 'H_common':
            return balls, w_vis, H, 'safe_hold'      # 不强行归因
        elif h_star == 'H_geo':
            balls['r_geo'] = min(R_MAX, self.kappa_infl * balls['r_geo'])
        elif h_star == 'H_force':
            balls['r_force'] = min(R_MAX, self.kappa_infl * balls['r_force'])
            request_null_window_recalibration()
        elif h_star == 'H_model':
            balls['r_model'] = min(R_MAX, self.kappa_infl * balls['r_model'])
            switch_compliant_control()
        elif h_star == 'H_vis':
            w_vis = max(0.0, self.kappa_vis * w_vis)
        elif h_star == 'H_policy':
            H = max(H_MIN, H // 2)
        return balls, w_vis, H, 'continue'

class RealTimeCertificateCompiler:
    def response_time(self, taskset, i):
        R = taskset[i].C + taskset[i].B
        while True:
            R_new = taskset[i].C + taskset[i].B + sum(
                math.ceil(R / taskset[j].T) * taskset[j].C
                for j in taskset.higher_priority(i))
            if R_new == R:
                return R
            if R_new > taskset[i].D:
                return R_new
            R = R_new

    def compile(self, A, post, m, v_max, monitor, step):
        k_sem = csc.certified_prefix(A, post, m, ALPHA_CHUNK)
        R = self.response_time(TASKSET, monitor.id)
        D_react = m / max(v_max, 1e-6)
        if R > monitor.D:
            return 0, {'reason': 'monitor_deadline_miss', 'R': R}
        k_tmp = min(len(A), int((D_react - R) // step))
        k_star = max(0, min(k_sem, k_tmp, K_MAX))
        m_t = margin_temporal(m_sem=SAFETY_MARGIN, Lmargin=L_M * v_max,
                              d_react=D_react, eps_clk=EPS_CLK, d_hw=DELTA_HW)
        if m_t < 0:
            return 0, {'reason': 'temporal_margin_negative', 'm_t': m_t}
        return k_star, {'R': R, 'k_sem': k_sem, 'k_tmp': k_tmp, 'm_t': m_t}

def HALO_round(M, obs, delta_f_req):

## 4. 推导

**引理 9（时间裕度侵蚀）** 设安全裕度函数 m(x,a) 对状态 x 满足 |m(x,a)−m(x',a)|≤L_m‖x−x'‖，真实状态速度 ‖ẋ‖≤v_max。证书在观测状态 x_obs 上给出 m(x_obs,a)≥m_sem。到实际作用时刻 t_act，状态漂移满足
‖x(t_act)−x_obs‖ ≤ ∫_{t_obs}^{t_act}‖ẋ‖dt + v_max·ε_clk ≤ v_max·Δ_react + v_max·ε_clk。
于是
m(x_act,a) ≥ m_sem − L_m·v_max·(Δ_react+ε_clk) = m_sem − L·(Δ_react+ε_clk)。
再计入硬件包络不确定 δ_hw，得 m_true≥m_sem−L·(Δ_react+ε_clk)−δ_hw。∎
**含义**：实时系统的端到端延迟与时钟误差以"每秒消耗多少安全裕度"的方式直接进入安全预算；这解释了为什么"语义上安全、执行上超时"仍可能危险。

**引理 10（可调度性 ⇒ 可执行性）** 设监控任务 τ_m 的响应时间 R_m 由固定优先级响应时间分析给出。若 R_m≤D_m 且 k*·T_step+R_m≤D_react，则：
(i) 首个动作提交前监控已完成并经 TDS 检查；
(ii) 前 k* 步在 D_react 内执行完，故障即使块首发生也能在越过不可逆点前停下。
若 R_m>D_m 或 k*=0，RTC 返回 0 并触发 safe_hold。∎

**定理 9（执行接地可靠性）** 在 A94–A98 下，若 Valid(J_halo)，则：
1. **命令一致**：attest 记录的实际执行命令序列等于被认证的 A[:k*]，无替换、无重放（nonce/哈希/单调计数器）。
2. **时间有效**：所有参与认证的证据年龄≤Δ_E 且被认证事件的频率<B_e/2，故无陈旧/混叠证据进入证书。
3. **包络成立**：h_t∈Ω，语义层的电流-力矩线性、电压、温度、编码器、驱动假设在执行期间成立，故 H_model/H_geo 的物理解释未被硬件违背污染。
4. **时序安全**：m_t≥0 且 R_monitor≤D_monitor，由引理 9/10，真实裕度在作用时刻仍非负，监控在首个动作前完成。
5. **失败闭合**：任一检查失败时 TDS 执行 𝒮_hold 内动作，而非未认证命令。
因此 J_vista 的语义保证被"接地"为执行时刻的物理保证；证书链从"几何-技能-干扰-接触-归因"扩到"**执行-时间-硬件**"。∎

**定理 10（第三通道可辨识性）** 设 VISTA 的 Fisher 信息 J₂=S₂ᵀΣ₂⁻¹S₂，加入硬件证据后
J₃=J₂+S_hᵀΣ_h⁻¹S_h（视觉/力与硬件在物理链路上独立时协方差块对角）。
对故障方向 v，vᵀJ₃v=vᵀJ₂v+‖Σ_h^{-1/2}S_h v‖²。
故若 v 在 VISTA 下不可辨（vᵀJ₂v=0）而 S_h v≠0，则 v 在 HALO 下可辨。
特别地，当视觉与几何共因失效时，二者签名列近似共线、S₂ 在共因方向秩亏；只要执行器硬件通道在该方向有非零投影（例如透明物体不改变电流-力矩关系，但真实接触/负载会），共因方向即可被分离或至少判 ambiguous。CSI 通过零接触电流激励主动增加 S_h 的可辨识性。∎

**定理 11（可移植性）** 若 HCD_new⊒HCD_old、存在保不变映射 ψ 且 |ψ(h_new)−h_old|≤δ_map，则由 m 对证据的 Lipschitz 性，旧证书在新硬件上的裕度损失 ≤L_map·δ_map。若 δ_map 超过阈值、固件/HCD 哈希不一致、或精化不成立，则 PCA 拒绝迁移并要求再认证。故开源硬件的可替换性被转换为**有界退化**而非无界漂移。∎

**命题 1（CSI 的零接触破僵局）** 在易损物体上，VISTA 的物理探针被 f_safe 禁止。CSI 只激励执行器内部电流、末端不接触物体，故对物体施加的接触力为 0；若执行器-传动模型参数可辨识（持续激励条件数 κ_pe<∞），则 H_model/H_hw 可在零接触下获得独立证据。代价是 CSI 只能辨识**执行器侧**模型，不能直接测量接触刚度；因此它打破的是"几何×视觉×F/T 共因"的执行器侧方向，而非替代接触物理。∎

**命题 2（时间混叠）** 设证据带宽为 B_e，某接触事件含频率 f>B_e/2 的分量。采样后该分量折叠到 f_alias=|f−k·B_e|（k 使 f_alias<B_e/2），在低频残差中表现为虚假的慢变力/位置偏差。若证书用该证据宣称安全，则可能把高频颤振/冲击误归因为 H_force 或 H_model。故 J_halo 要求被认证事件频率<B_e/2；对高频事件必须使用 L0（10–40 kHz）证据，而非 L2 语义残差。∎

| CSI 电流触觉（L0/L1） | chirp 20–200ms，异步 | O(N_fft) | 持续激励条件数门控 |

| RTC（L2） | 响应时间分析 + O(m) **<1ms** | O(m) | 引理 10：R≤D ⇒ 可执行 |
| TDS（L1） | 四项检查 **<0.03ms** | O(1) | 错过截止期 fail-closed |
| PCA（L2/离线） | 精化+映射 **<5ms** | O(|HCD|) | 定理 11：退化有界 |
| WCV-T（L1） | n_worst=8 **<1ms** | O(n_worst) | 时间/包络交集 |
| CSP-T（L2） | 块级 A* **<5ms** | O(|V|·|blocks|) | 时间签名 OOD 检测 |
| AIC-T（L2） | n_cert=160 **<60ms** | O(n_cert) | 时序/硬件/共因最坏 |
| HALO L1 总路径 | OHB 0.1 + TEL 0.03 + EEA 0.05 + TDS 0.03 + 其余同 VISTA ≈ **<2.7ms** | — | 零学习写操作（A94） |

**正确性定理（HALO-Complete）** 见定理 9；核心是**把第 65 轮"语义上可归因"升级为"执行时刻仍可证"**：证据被时间戳与带宽约束，命令被 attest 确认真正执行，植物被包络认证仍在模型内，监控被 WCET 保证赶上截止期，失败一律 fail-closed。

## 7. 已知风险

**一句话**：HALO 的"执行可证"依赖开源硬件暴露的内部信号真实、固件未被篡改、时钟同步误差有界；一旦开源固件被改、社区分叉导致 HCD 语义漂移，或攻击者同时操纵电源/时钟/传感器（共因），证书会"形式有效而物理失效"——**系统会因为拿到了硬件签名与时间戳而比第 65 轮更自信地 fail-open；这是本轮全部执行接地论证共同依赖的隐藏假设（A94）。**

**次级风险与缓解**：
1. **开源 ≠ 可信 / 供应链与固件篡改**：开源只保证可审计，不保证运行的是被审计的二进制。缓解：signed firmware + measured boot + 运行时哈希 + nonce/单调计数器；关键证据用独立模拟通道交叉校验；社区可复现构建。
2. **HCD 语义漂移 / 社区分叉**：同名信号在不同固件版本含义不同（单位、符号、滤波、限幅）。缓解：HCD 版本化 + 语义测试套件 + 精化偏序 + 迁移前自动再认证；PCA 失败即拒绝。
3. **时钟同步失效**：PTP/EtherCAT DC 在大抖动/断链/攻击下失准，导致年龄与作用时刻错判。缓解：本地单调时钟兜底 + 同步健康度作为证书条件 + 同步丢失即缩 k*/safe_hold；ε_clk 显式进入 m_t。
4. **安全动作本身不安全**：fail-closed 若选错动作（如突然断使能导致重力掉落）反而危险。缓解：𝒮_hold 由可达集/生存核离线计算并硬件 interlock 兜底；按故障类型选择"保持/柔顺回退/梯度断使能"而非一刀切。
5. **CSI 适用域与安全**：chirp 可能激发未建模高频模态、磨损减速器、在柔性物体上引起振动。缓解：幅值/带宽/温升硬约束；持续激励条件数门控；只在零接触时使用；与传统辨识交叉验证。
6. **包络 Ω 过保守或过宽松**：保守导致频繁 safe_hold，宽松导致 H_hw 漏检。缓解：用故障注入标定 Ω；在线估计余量；Ω 分安全/性能两档。
7. **实时预算挤压**：L1 从 2.5ms 增到 2.7ms，边缘设备可能超预算。缓解：OHB/EEA/TDS 下沉到 MCU/FPGA；硬件时间戳；把非关键检查移出 L1；以 WCET 而非平均时间做预算。
8. **共因仍是根本威胁**：共享电源/时钟/地/散热可同时污染硬件与时间证据。缓解：AIC-T 显式建模共因；共因下只要求判 ambiguous + fail-closed，不要求归因正确；物理隔离（独立供电/独立时钟/独立传感）作为硬件设计要求。
9. **证书可移植性的理论缺口**：保不变映射 ψ 在真实非线性系统中难以构造，δ_map 可能随工况变化。缓解：先做同族 BOM，跨族要求重新标定；把 PCA 作为"筛选器"而非"证明器"；对 δ_map 做区间/分布鲁棒化。
