灵感驱动研究循环 · v23 轮；本轮灵感二元组：「多任务学习」×「机器人基础模型」

> **基线**：v22 产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（HDL/ACSC/DCSC/HPC-E/CFC++；其上承 v21 的 SDC/CAC/DCL/GIC、v20 的 PCA/CTS/CFC/HPC/CFCtrl、v19 的 DCM/OGCC/CCV/DRS/OGC、v17 的 CLP/S2C/HCG/PSV/APS/AMC）。不推倒 v22：分层 PGEV、机械臂配空间证书、深度 conformal 校准全部保留。
> 本轮纪律：**基础模型只提案、证书才放行；共享表示必须被证明"结构独立"而不是"看起来不同"；安全任务在联合优化中不可被辅助任务牺牲**。本轮只做一件事：把 v22 的"多模态共识"升级为**可审计的证据独立性 + 提案-验证分离 + 开放词汇规则接地**（IP-436–441），并顺手封堵 v22 最大风险（层级退化振荡 / 配空间活性坍缩）在基础模型语境下的新变体——**"经认证的相关性幻觉"**。

## 0. 直觉与动机

### 灵感 1（多任务学习 → 把"证据独立"从数模态变成证独立）

**直觉**：v22 的 CFC++ 用"模态数 ≥ 2"来防相关故障。但在机器人基础模型时代，"模态"常常只是**同一个共享主干上的不同任务头**（检测头、分割头、深度头、手势头、可通行性头）。它们被记成多个模态，实际共享同一套特征——一旦主干抓到虚假捷径（强逆光、反光地面、走廊纹理、训练集里"人与某类背景"的伪相关），所有头会**同时、同向地错**。这不是"多数派被少数派污染"，而是"多数派本来就是同一个人的多个影子"。计量直觉：**梯度不打架 ≠ 错误不相关**。因此必须把"独立"拆成两件不同的事：训练期的**优化冲突**（用来保护安全任务不被辅助任务拉低）与推理期的**共同模式失败质量 ρ**（用来判定若干证据能否真的组成法定人数）。

**严谨定义**：设安全任务集 `𝒯_S`、辅助任务集 `𝒜`，共享编码器 `f_θ`、任务头 `g_φ`。对安全事件
`E_τ = 1[头 τ 在 x 实际不安全时输出 SAFE]`，定义共同模式失败质量
`ρ_S = sup_{校准/压力分布 D} [ P(∩_{τ∈S} E_τ | D) − ∏_{τ∈S} P(E_τ | D) ]`。
在"存在潜在混淆变量 `Z`（环境/光照/遮挡组），给定 `Z` 后 `E_τ` 条件独立"的模型下（产物区引理 1010）：若 `P(Z∈M) ≤ ρ`，且 `Z∉M` 时各 `P(E_τ|Z) ≤ p_τ`，则 `P(∩E_τ) ≤ ρ + ∏p_τ`。于是 CFC+++ 的接受条件从 `计数≥N−F ∧ 模态≥2` 升级为
`计数≥N−F ∧ α(G_ρ)≥M_min ∧ ρ+∏p_τ ≤ δ_fed`，
其中 `G_ρ` 以"共同模式质量超阈"在证据间连边，`α(·)` 是独立集大小。**TIC 证明不了独立，就退回 v22 的硬件模态法定人数；仍不满足就退化成单证据保守。**

**关键反直觉点**：低梯度冲突是训练期非退化的必要条件，却**绝不是**推理期独立的充分条件；把二者混为一谈正是"经认证的相关性幻觉"的入口。

### 灵感 2（机器人基础模型 → 提案-验证分离 + 开放词汇规则接地）

**直觉**：VLA/机器人基础模型能在开放指令下提出人类没想到的可行计划，也能把"禁止在有人作业区快速穿行"这种自然语言规则接成状态谓词。但它**没有证书**：它的泛化是分布意义上的，不是逐例可证的；它可能流畅地、自信地、错误地行动。正确架构不是"用证书微调基础模型"，而是**把基础模型关进提案-验证的笼子**：基础模型只负责产生候选（计划、类别、规则接地），证书层逐例验证并放行。于是它的贡献是**活性**（找到更多本来就在安全集里的解，正好补救 v22 因配空间能量过度保守而损失的活性），而不是**扩大安全集**。数学上 `Exec_v23 = Valid(Propose_RFM) ∩ Exec_v22 ⊆ Exec_v22`，且 `Valid` 是恒等映射的子集。

第二个反直觉点：开放词汇规则接地本身必须被 conformal 校准，且**歧义一律取最严接地**。设规则 `r` 的接地预测集 `Γ_R(r)`，则 F 规则取 `∪_{π∈Γ_R} Forb(π)`、O 规则取 `∩_{π∈Γ_R} Req(π)`、P 规则取 `∩_{π∈Γ_R} Perm(π)`；只要真接地 `π*∈Γ_R`，最严执行仍满足真规则（产物区引理 1012）。这把"模型可能理解错规则"的风险，转化为"预测集覆盖 + 最严消解"，而不是祈祷模型理解正确。

**严谨定义**：提案-验证分离律（P44）要求准入门与 v22 的 HPC-E 做**逻辑与**而非或；RFM 的任何输出只能作为候选/先验/搜索启发，不能充当证据独立性的来源，也不能绕过 P34 的语义证据单调律（障碍只增、自由有偿赎回）。RFM 对感知的贡献必须走 SDC/CAC 的 conformal 通道；对规范的贡献必须走 OVDGC 的"预测集→最严"通道；对计划的贡献必须走 CMTR/HDL 的层级过滤。

### 灵感 3（二者的交集 → 任务化证书、证书迁移与安全任务字典序）

**直觉**：多任务学习让一个基础模型同时服务感知/规范/规划，但也意味着**证书是任务索引的**：为任务 A 校准的 1-α 覆盖，不能免费迁移到任务 B（负迁移）。因此每张证书必须标注 `(谓词, 任务分布, 校准集 id, α, TTL)` 并定义**证书迁移差距**。更深一层：安全任务与辅助任务共享主干时，辅助任务可能"偷走"安全任务需要的容量；反直觉的解法是**字典序更新**——安全任务的损失不许因辅助任务梯度而上升（一阶意义），冲突时把辅助梯度投影到安全梯度的正交补。这把"多任务"从"平均主义加权"改成"安全任务享有一票否决的字典序"。

**严谨定义**：任务化证书 `C = (pred, D_task, S_cal, α, ttl)`；迁移差距 `Δ_tr(C, A→B) = sup_x |cover_A(x) − cover_B(x)|`。P43 的字典序非退化条件：候选更新 `u = g_S + λ·g_A^proj`，其中当 `g_A·g_S < 0` 时 `g_A^proj = g_A − (g_A·g_S/‖g_S‖²)g_S`，则一阶 `ΔL_S = −η g_S·u ≤ −η‖g_S‖² < 0`。安全任务之间也会冲突时，用**偏序**（危害等级的分层偏序）而非全序，冲突不可消解则升级 SafeStop。

**三者如何统一**：v23 = v22 + **TIC/CMTR（多任务独立与安全优先）** + **FMPG/OVDGC（基础模型提案与规则接地）** + **CFC+++/HPC-F（独立感知共识与统一准入门）**。共享状态扩展为 `ζ_fm = ζ_pgev ∪ (θ_shared, task_routing, Γ_R, proposal_log, G_ρ, transfer_gap)`。安全继承链 `Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 由"AND 门 + Valid 是恒等子集"机械保持。

## 2. 设计原则（在 P34–P42 基础上新增 P43–P47）

**P43 安全任务字典序律（Safety-Task Lexicographic Priority）**
多任务联合更新中，安全任务损失不得因辅助任务梯度而一阶上升。冲突时投影辅助梯度；安全任务之间按危害等级偏序仲裁，不可消解则升级 SafeStop。安全头享有固定算力预留 `R_S`，辅助任务不得抢占。

**P44 提案-验证分离律（Propose-Certify Separation）**
基础模型只能产生候选，不能扩集：`Exec_v23 = Valid(Propose_RFM) ∩ Exec_v22 ⊆ Exec_v22`。准入门必须与 HPC-E 做逻辑与；RFM 对感知/规范/计划的贡献分别只能经 SDC-CAC / OVDGC / CMTR-HDL 通道，绝不绕过 P34 的障碍单调与自由有偿赎回。

**P45 结构独立性证据律（Structural Evidence Independence）**
共享主干上的多条证据只有在**共同模式失败质量**被 TIC 认证 `ρ_S ≤ ρ_max` 时才可计入法定人数；否则只能作为一条证据。CFC+++ 以独立集 `α(G_ρ) ≥ M_min` 取代"模态标签计数"；独立集不足即退回 v22 的硬件模态法定人数。

**P46 开放词汇最严接地律（Open-Vocabulary Strictest Grounding）**
自然语言规则经 conformal 预测集 `Γ_R(r)` 接地；F 取并、O/P 取交（最严）；只要 `π*∈Γ_R`，最严执行满足真规则。约束不可满足→可审计 SafeStop/人类接管，禁止静默死锁或擅自放宽。

**P47 证书任务索引与迁移律（Task-Indexed Certificates）**
每张证书绑定 `(pred, D_task, S_cal, α, ttl)`；跨任务复用须满足迁移差距 `Δ_tr ≤ Δ_max` 且未过期，否则强制重校准；过期/超差证书不得作为放行依据。

## 3. 与基线的接口（如何退化）

- TIC 无法认证 `ρ`（穿支路样本不足/估计被污染）⇒ 退回 v22 CFC++ 的硬件模态计数 ⇒ 更保守；
- CMTR 失效（路由崩溃）⇒ 冻结共享主干，只跑安全头、关闭辅助头 ⇒ `Exec ⊆ v22`；
- FMPG 失效（RFM 超时/OOD/崩溃）⇒ 回退 v22 经典规划器 ⇒ 等价 v22（活性降低，安全不变）；
- OVDGC 失效（接地模型不可用）⇒ 规则回落人工签名版本，歧义取全域最严；不可满足 ⇒ SafeStop；
- 任务化证书过期或迁移差距超阈 ⇒ 拒绝跨任务复用，强制重校准 ⇒ 更保守；
- 全部失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
- **安全继承**：TIC 只减不加法定人数、FMPG 只收窄不放宽、CMTR 只做字典序保护、OVDGC 只取最严；任意失效都向保守方向退化，继承链由 AND 门机械保持。

## 4. 预期贡献

1. **证据独立性的可证化**：TIC + 共同模式失败质量 `ρ` + 条件独立引理，把"多模态"从标签升级为结构，并明确"低梯度冲突 ≠ 独立"；
2. **独立性感知共识 CFC+++**：以证据图独立集而非标签数确定法定人数，直接封堵"共享主干相关故障冒充独立共识"；
3. **提案-验证分离的形式接口**：FMPG + 提案覆盖证书，使基础模型可证地只提升活性、不扩安全集，并诚实区分"没找到"与"不存在"；
4. **安全任务字典序多任务优化**：P43 的梯度投影非退化保证 + 任务化证书迁移差距，处理负迁移对证书有效性的侵蚀；
5. **开放词汇规则接地的 conformal 最严消解**：把"模型可能理解错规则"变成"覆盖 + 最严"的可审计风险，并接入 merkle 版本链；
6. **HPC-F 统一准入门**：HPC-E ∧ TIC ∧ FMPG ∧ OVDGC，闭合 `Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

## 5. 本轮最大风险

**一句话**：本轮把"证据独立"从硬件/模态层面的结构性事实，降级为共享主干上一个可被虚假捷径欺骗的**统计估计**——当所有安全任务恰好都依赖同一个背景/光照/遮挡线索时，TIC 会测出很低的共同模式质量 `ρ`，CFC+++ 于是把同源相关故障认证成"独立共识"，机器人以可审计的方式撞上系统从未真正看见的东西，即**"经认证的相关性幻觉"**。

        per_g = {}                      # g -> {tau: [假 SAFE 指示]}
        for x, unsafe in calib_loader:
            if not unsafe:
                continue
            g = self.group_key(x)
            preds = self._safe_predictions(x)     # tau -> bool
            per_g.setdefault(g, {t: [] for t in self.S})
            for t in self.S:
                per_g[g][t].append(preds[t])
        rho_hat = 0.0
        for g, d in per_g.items():
            joint = self._mean(all(d[t]) for t in d)   # 全任务同时假 SAFE
            marg = 1.0
            for t in d:
                marg *= self._mean(d[t])
            rho_hat = max(rho_hat, joint - marg)
        # Clopper–Pearson 上界 + 组间 Bonferroni
        return self._cp_upper(rho_hat, n=len(per_g), alpha=self.alpha_ci / max(1, len(per_g)))

    def independence_graph(self, votes):
        # 任一对证据的共同模式质量超阈 -> 视为同源，连边
        G = {k: set() for k in votes}
        keys = list(votes)
        for i in range(len(keys)):
            for j in range(i + 1, len(keys)):
                rho_ij = self._pair_rho(keys[i], keys[j])
                if rho_ij > self.tau_rho:
                    G[keys[i]].add(keys[j]); G[keys[j]].add(keys[i])
        return G

    def certify_quorum(self, G, p_by_key, delta_fed):
        M = max_independent_set_size(G)           # 贪心/分支定界，证据数很小
        prod_p = 1.0
        for p in p_by_key.values():
            prod_p *= p
        return (M >= 2) and (self.rho_upper + prod_p <= delta_fed)


# IP-437 Foundation Model Proposal Gate
class FoundationModelProposalGate:
    def __init__(self, rfm, hpc_e, tic, k=8, rfm_timeout_ms=200):
        self.rfm, self.hpc_e, self.tic = rfm, hpc_e, tic
        self.k, self.timeout = k, rfm_timeout_ms

    def propose(self, obs, instruction):
        try:
            return self.rfm.sample(obs, instruction, k=self.k, timeout_ms=self.timeout)
        except (TimeoutError, RuntimeError):
            return []                            # 提案失败 ≠ 不安全；只是活性损失

    def admit(self, plan, quorum_ctx):
        # AND 门：HPC-E 已蕴含 Exec_v22；TIC 不通过则不认“多证据共识”
        if plan not in self.hpc_e.exec_v22:
            return False
        return self.tic.certify_quorum(quorum_ctx.G, quorum_ctx.p_by_key, quorum_ctx.delta_fed)

    def proposal_coverage(self, proposal_bank, exec_v22_region, eps=0.05):
        # 只影响“活性诚实性”，不影响安全：报告候选对安全域的可达覆盖
        hit = sum(1 for p in proposal_bank if distance(p, exec_v22_region) <= eps)
        return hit / max(1, len(proposal_bank))  # 低覆盖 -> 声明“没找到”，非“不存在”


# IP-438 Certified Multi-Task Router（安全任务字典序）
class CertifiedMultiTaskRouter:
    def __init__(self, model, lambda_aux=0.5, reserve_R_S=0.6):
        self.model, self.lam, self.reserve = model, lambda_aux, reserve_R_S

    def lexicographic_step(self, batch):
        gS = self.model.grad_safety(batch)
        gA = self.model.grad_aux(batch)
        if dot(gA, gS) < 0:                       # 冲突：投影到安全梯度正交补
            gA = gA - (dot(gA, gS) / (dot(gS, gS) + 1e-12)) * gS
        u = gS + self.lam * gA
        # 一阶保证 gS·u = ||gS||^2 + λ·gS·gA^proj = ||gS||^2 > 0（安全损失下降）
        self.model.apply(-u)
        return {"safety_first_order_delta": -dot(gS, u)}   # 应恒为负

    def route(self, task):
        # 辅助任务只能在安全头算力预留之后使用剩余预算；不允许抢占
        return self.model.run(task) if self.model.free_capacity() > 0 else ABSTAIN


# IP-439 Open-Vocabulary Deontic Grounding Certificate
class OpenVocabularyDeonticGroundingCertificate:
    def __init__(self, grounder, conformal, alpha=0.01):
        self.grounder, self.cp, self.alpha = grounder, conformal, alpha

    def ground(self, rule_text):
        cands = self.grounder.propose_predicates(rule_text)   # 多个候选谓词
        scores = [self.grounder.score(rule_text, c) for c in cands]
        return self.cp.prediction_set(cands, scores, alpha=self.alpha)  # Γ_R

    def compile(self, rule, gamma):
        if not gamma:
            return EMPTY_CONSTRAINTS
        if rule.kind == "F":                       # 禁止：并 => 最严
            return union_of_forbidden(gamma)
        if rule.kind == "O":                       # 义务：交 => 最严
            return intersection_of_required(gamma)
        if rule.kind == "P":                       # 许可：交 => 最严
            return intersection_of_permitted(gamma)
        raise ValueError(rule.kind)

    def compile_and_check(self, rules):
        constraints = [self.compile(r, self.ground(r.text)) for r in rules]
        if constraints_infeasible(constraints):
            # 可审计升级：记录触发规则、Γ_R、证书版本；绝不静默死锁或放宽
            return ESCALATE_SAFESTOP
        return intersect(constraints)

class CertificateFederatedConsensusPlusPlus(CertificateFederatedConsensusPlusHierarchical):
    M_MIN_INDEPENDENT = 2

    def consensus_round(self, timeout=5.0):

## 2. 形式化引理与证明草图

**引理 1010（共同模式法定人数界）**　设安全事件 `{E_τ}_{τ∈S}` 关于潜在变量 `Z` 条件独立。若存在共同模式区域 `M` 使 `P(Z∈M) ≤ ρ`，且对所有 `z∉M` 有 `P(E_τ|Z=z) ≤ p_τ`，则
`P(∩_{τ∈S} E_τ) ≤ ρ + ∏_{τ∈S} p_τ`。
*证明*．按 `Z∈M` 分解：`P(∩E) = P(∩E|Z∈M)P(Z∈M) + P(∩E|Z∉M)P(Z∉M) ≤ 1·ρ + P(∩E|Z∉M)`。在 `Z∉M` 上由条件独立得 `P(∩E|Z∉M) = E[∏ P(E_τ|Z) | Z∉M] ≤ ∏ p_τ`。∎
*推论 1010′（CFC+++ 可靠性）*．若 TIC 认证 `ρ_upper` 与 `p_τ`，且 `ρ_upper + ∏ p_τ ≤ δ_fed`，则一次法定人数放行的假 SAFE 概率不超过 `δ_fed`（多 key 用 Bonferroni 分摊）。

**引理 1011（提案-验证子集）**　若 `Valid(a) ⇒ HPC-F(a) ⇒ HPC-E(a) ⇒ a ∈ Exec_v22`，则 `Exec_v23 = {a ∈ Propose_RFM : Valid(a)} ⊆ Exec_v22`。
*证明*．逐点蕴含，取集合即得。∎ 因此 RFM 只能改变"找到哪些 `Exec_v22` 内计划"，不能改变 `Exec_v22` 本身。

**引理 1012（最严接地可靠性）**　若真接地 `π* ∈ Γ_R(r)`，则按 F 取并、O/P 取交编译出的约束满足真规则 `π*`。
*证明*．F：`Forb(π*) ⊆ ∪_{π∈Γ_R} Forb(π)`，避开并即避开 `Forb(π*)`；O：`Req(π*) ⊇ ∩_{π∈Γ_R} Req(π)`，落在交内即落在 `Req(π*)`；P：`Perm(π*) ⊇ ∩_{π∈Γ_R} Perm(π)`，落在交内必被 `π*` 许可。∎

**引理 1013（字典序一阶非退化）**　令 `u = g_S + λ g_A^proj`，其中若 `g_A·g_S<0` 则 `g_A^proj = g_A − (g_A·g_S/‖g_S‖²)g_S`，否则 `g_A^proj = g_A`。则 `g_S·u ≥ ‖g_S‖² > 0`，故小步长 `ΔL_S ≤ −η‖g_S‖²`。
*证明*．冲突时 `g_S·g_A^proj = 0`；非冲突时 `g_S·g_A ≥ 0`。两种情况均有 `g_S·u ≥ ‖g_S‖²`。∎

**引理 1014（迁移差距的必要性）**　存在任务对 `(A,B)` 使 `cover_A = 1−α` 而 `cover_B < 1−α`（负迁移），故证书不得无标注地跨任务复用；P47 的 `Δ_tr ≤ Δ_max` 是可审计的拒绝条件而非充分保证。

## 5. 本轮最大风险

**一句话**：本轮把"证据独立"从硬件/模态层面的结构性事实，降级为共享主干上一个可被虚假捷径欺骗的**统计估计**——当所有安全任务恰好都依赖同一个背景/光照/遮挡线索时，TIC 会测出很低的共同模式质量 `ρ`，CFC+++ 于是把同源相关故障认证成"独立共识"，机器人以可审计的方式撞上系统从未真正看见的东西，即**"经认证的相关性幻觉"**。
