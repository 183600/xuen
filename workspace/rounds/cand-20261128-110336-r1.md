### 第 1 轮灵感驱动研究记录

**灵感词**：轨迹优化、点云配准、基准测试

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）确立「需求-意图-一致性三角桥」，在保持七硬门 fail-closed 边界不变的前提下，从用户需求出发主动推导意图。本轮延续「硬门不增」原则，聚焦「**轨迹-几何-基准三元闭环**」：在 v7 需求导向准入的基础上，引入轨迹优化对提议轨迹进行能量收敛式精修（轨迹优化），引入点云配准对场景几何进行对齐校正（点云配准），引入基准测试框架对各轮改进进行可复现回归评估（基准测试）。

**直觉与动机**：

1. **轨迹优化 → 从「粗提议」到「精收敛」**。v7 的 FMPP.propose 只输出候选轨迹 x_cand，随后经硬门过滤。候选轨迹与硬门阈值之间存在「提议-验证」断层：被拒的轨迹未被利用，通过的轨迹未被精修。引入「轨迹优化核」(Trajectory Optimization Kernel, TOK)：对通过软因子初筛的候选，以流匹配 ODE 进行能量下降式精修 x_opt = argmin_x E_smooth(x)+λ_c·E_collision(x;P_reg)+λ_g·E_grasp(x;g_emb)，使轨迹在硬门判定前更贴近可行流形。关键洞见：**轨迹优化不是替代硬门，而是在硬门收紧前把候选推向可行集内部**，降低假阴性率。

2. **点云配准 → 从「静态几何」到「动态对齐」**。GGC 依赖抓取几何可达性，但其输入几何来自单帧点云 P_obs，与模型点云 P_model 存在刚体偏置（相机标定漂移、物体重新定位）。引入「点云配准核」(Point Cloud Registration Kernel, PCRK)：以点对面 ICP 在 SE(3) 上估计 T_reg，将 P_obs 配准到 P_model，得到对齐后的几何 P_reg = T_reg(P_obs)，供 GGC/MCTM 使用。关键洞见：**几何误差直接传导为硬门误判**，配准前置可将空间误差控制在硬门容差之内。

3. **基准测试 → 从「单轮声明」到「可复现回归」**。每轮研究只给仿真预测表，缺少标准化基准集 B 与回归度量，导致改进不可比、消融不可验证。引入「基准测试与认证框架」(Benchmarking & Certification Framework, BCF)：固定测试套件 B = {(L_i, ρ_i, env_i, x_gold_i)}，定义成功率、硬门通过率、P99 延迟、需求一致性召回率，每轮在 B 上跑完整回归并记录基准快照。关键洞见：**没有基准的研究是不可伪造的**，基准测试把「感觉变好」转化为「可量化回归」。

**关键洞见**：第 7 轮回答「如何从用户需求主动推导意图」；第 1 轮回答「需求导向准入之后，如何让通过的轨迹更可行、几何更准确、改进更可验证」。七硬门记号原样复用；本轮新增的只有：
- IP-505 TOK（轨迹优化核，能量收敛式精修），
- IP-506 PCRK（点云配准核，SE(3) 对齐），
- IP-507 BCF（基准测试与认证框架，可复现回归）

**形式化目标（增量）**：

1. **TOK（Trajectory Optimization Kernel）**：
   - 能量泛函 E(x) = E_smooth(x) + λ_c·E_collision(x; P_reg) + λ_g·E_grasp(x; g_emb)
   - 轨迹精修 x_opt = TOK.refine(x_cand, P_reg)，通过流匹配 ODE 反向积分或投影梯度下降，保证 E(x_opt) ≤ E(x_cand)
   - 软因子 η_traj = exp(−E(x_opt)) ∈ (0,1]，纳入软因子链
   - TOK 不放宽任何硬门：GGC/MCTM/VACK/BCK 对 x_opt 仍原样判定

2. **PCRK（Point Cloud Registration Kernel）**：
   - 观测云 P_obs ∈ ℝ^{N×3}，模型云 P_model ∈ ℝ^{M×3}
   - 点对面 ICP：T_reg = argmin_{T∈SE(3)} Σ_i n_{NN(i)}ᵀ (T p_i − q_{NN(i)})
   - 对齐云 P_reg = T_reg(P_obs)，配准残差 ε_reg = mean_i||T_reg p_i − q_{NN(i)}||
   - 若 ε_reg > ε_reg^max，强制几何门收紧（γ_g ← γ_g·(1+δ)）

3. **BCF（Benchmarking & Certification Framework）**：
   - 基准套件 B = {(L_i, ρ_i, env_i, x_gold_i)}_{i=1}^{|B|}
   - 度量：Succ = 1[执行成功 ∧ 七硬门通过]，GateRate = 平均硬门通过率，P99_lat, DemandRecall
   - 基准快照 s_v = (Succ_v, GateRate_v, P99_v) 随版本 v 单调记录，回归若 s_{v+1} ≺ s_v 则拒绝合并

**本轮最大风险**：**点云配准局部最优与对称物体失配**：ICP 收敛于局部最优，对称/无纹理物体会导致 T_reg 误配准，进而使 GGC 几何判定失效，七硬门 fail-closed 边界可能因「错误对齐」而被错误放宽或收紧。

## 2. 关键算法骨架

### IP-505 TOK：轨迹优化核

```python
@dataclass
class TrajectoryOptimizationKernel:
    """TOK：对候选轨迹做能量收敛式精修。
    输入：x_cand, P_reg, g_emb
    输出：x_opt, η_traj，保证 E(x_opt) ≤ E(x_cand)"""
    lambda_c: float = 1.0
    lambda_g: float = 1.0
    max_iter: int = 50
    tol: float = 1e-4

    def energy(self, x: Trajectory, P_reg: np.ndarray, g_emb: np.ndarray) -> float:
        return (self.E_smooth(x)
                + self.lambda_c * self.E_collision(x, P_reg)
                + self.lambda_g * self.E_grasp(x, g_emb))

    def refine(self, x_cand: Trajectory, P_reg: np.ndarray,
               g_emb: np.ndarray) -> tuple[Trajectory, float]:
        x = x_cand.clone()
        E_prev = self.energy(x, P_reg, g_emb)
        for _ in range(self.max_iter):
            grad = self.energy_grad(x, P_reg, g_emb)
            x = self.project_grad_step(x, grad, P_reg, g_emb)
            E_cur = self.energy(x, P_reg, g_emb)
            if abs(E_prev - E_cur) < self.tol:
                break
            E_prev = E_cur
        eta_traj = float(np.exp(-E_prev))
        return x, eta_traj

    def E_smooth(self, x: Trajectory) -> float:
        # 二阶差分能量，鼓励轨迹光滑
        return float(np.sum(np.diff(x.waypoints, axis=0) ** 2))

    def E_collision(self, x: Trajectory, P_reg: np.ndarray) -> float:
        # 到配准点云的最小距离势场
        dists = self.min_dist_to_pointcloud(x.waypoints, P_reg)
        return float(np.sum(np.maximum(0.0, 0.05 - dists) ** 2))

    def E_grasp(self, x: Trajectory, g_emb: np.ndarray) -> float:
        # 末端与抓取几何嵌入的一致性
        return float(np.linalg.norm(x.ee_pose - g_emb) ** 2)
```

### IP-506 PCRK：点云配准核

```python
@dataclass
class PointCloudRegistrationKernel:
    """PCRK：点对面 ICP 在 SE(3) 上估计 T_reg。
    输入：P_obs, P_model
    输出：T_reg, P_reg, ε_reg"""
    max_iter: int = 100
    tol: float = 1e-5
    epsilon_reg_max: float = 0.02  # 2 cm

    def register(self, P_obs: np.ndarray, P_model: np.ndarray,
                 normals: np.ndarray) -> tuple[np.ndarray, np.ndarray, float]:
        T = np.eye(4)
        P_reg = P_obs.copy()
        eps_prev = float('inf')
        for _ in range(self.max_iter):
            # 最近邻 + 点对面残差
            idx = self.nearest_neighbor(P_reg, P_model)
            Q = P_model[idx]
            N = normals[idx]
            # 求解最小二乘：min_T Σ (n_i · (T p_i - q_i))^2
            T = self.point_to_plane_step(P_reg, Q, N, T)
            P_reg = (T[:3, :3] @ P_obs.T).T + T[:3, 3]
            eps = float(np.mean(np.abs(np.sum(N * (P_reg - Q), axis=1))))
            if abs(eps_prev - eps) < self.tol:
                break
            eps_prev = eps
        return T, P_reg, eps

    def accept(self, eps_reg: float) -> bool:
        return eps_reg <= self.epsilon_reg_max
```

### IP-507 BCF：基准测试与认证框架

```python
@dataclass
class BenchmarkingCertificationFramework:
    """BCF：固定基准套件 + 回归度量。
    输入：版本 v 的 EFA 实例，基准套件 B
    输出：基准快照 s_v，回归判定"""
    suite: list[dict]  # 每项 {L, rho, env, x_gold}

    def run(self, efa_v, context_factory) -> dict:
        results = []
        for item in self.suite:
            ctx = context_factory(item['env'], item['face'])
            ok, traj, tag = efa_v.select(item['L'], None, ctx)
            gate_pass = (tag == 'FORGED_CGE_V8')
            results.append({
                'L': item['L'],
                'success': ok and gate_pass,
                'gate': gate_pass,
                'latency_ms': ctx.latency_ms,
                'demand_recall': self._demand_recall(traj, item['x_gold']),
            })
        return self._snapshot(results)

    def _snapshot(self, results: list[dict]) -> dict:
        succ = float(np.mean([r['success'] for r in results]))
        gate = float(np.mean([r['gate'] for r in results]))
        p99 = float(np.percentile([r['latency_ms'] for r in results], 99))
        drec = float(np.mean([r['demand_recall'] for r in results]))
        return {'Succ': succ, 'GateRate': gate, 'P99_lat': p99,
                'DemandRecall': drec}

    def is_regression(self, s_new: dict, s_old: dict) -> bool:
        # 任一关键度量下降且无补偿提升即为回归
        key = ['Succ', 'GateRate', 'DemandRecall']
        worse = any(s_new[k] < s_old[k] - 1e-3 for k in key)
        better = any(s_new[k] > s_old[k] + 1e-3 for k in key)
        return worse and not better
```

### EFA-v8：七硬门 + 七软因子链（前置 PCRK，后置 TOK）

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：七硬门不变 + 软因子链 ×7 (增 η_traj)。
    流水线：PCRK 配准 → DIM/DAC 需求 → FMPP 提议 → TOK 精修 → 软因子滤波 → VACK/BCK"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    ggc: GraspGeometryCutter
    mctm: MobileChassisTopologyMap
    stm: SemanticTrajectoryMapper
    dim: DemandIntentModel
    drc: DemandReasoningChain
    dac: DemandAffectCapture
    pcrk: PointCloudRegistrationKernel
    tok: TrajectoryOptimizationKernel
    bcf: BenchmarkingCertificationFramework
    v7: EvidenceForgingAssemblerV7
    tau_demand: float = 0.7

    def select(self, L: str | None, t_now, context,
               P_obs: np.ndarray, P_model: np.ndarray,
               normals: np.ndarray) -> tuple[bool, Trajectory | None, str]:
        # 0. 点云配准（前置几何对齐）
        T_reg, P_reg, eps_reg = self.pcrk.register(P_obs, P_model, normals)
        if not self.pcrk.accept(eps_reg):
            # 配准失败：收紧几何门，降低通过概率（保守）
            context.geom_tighten = 1.0 + 0.2

        # 1. 捕获需求态度
        affect = self.dac.observe(context.face) if hasattr(context, 'face') else 0.0
        eta_affect = self.dac.get_affect_factor(affect)

        # 2. 需求意图推断
        rho_demand, eta_demand = self.dim.forward(
            history=self.lmem.get_history(),
            context=context.__dict__,
            env=context.env if hasattr(context, 'env') else {},
            L=L)

        if L is None or eta_demand < self.tau_demand:
            return self._demand_guided_fallback(rho_demand, t_now, context,
                                                affect, eta_affect, P_reg)

        # 3. LLM 推理链
        chain, eta_demand_from_chain = self.drc.infer(L, context.__dict__)
        eta_demand_total = max(eta_demand, eta_demand_from_chain)
        if eta_demand_total < self.tau_demand:
            return self._demand_guided_fallback(rho_demand, t_now, context,
                                                affect, eta_affect, P_reg)

        # 4. FMPP 粗提议
        q_L = self.stm.forward(L)
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)
        m_topk = self.lmem.retrieve_by_semantic(q_L, k=4)
        t_topo = self.mctm.token(context.pose)
        c = build_ctx(context, s_emo, m_topk, t_topo, q_L, P_reg)
        cands = self.fmpp.propose(c, K=self.fmpp.K)

        # 5. TOK 精修 + 软因子滤波（7 项链）
        surv = []
        for x_cand in cands:
            if not self.ggc.filter(x_cand, P_reg):
                continue
            x_opt, eta_traj = self.tok.refine(x_cand, P_reg, context.g_emb)
            # 精修后仍须通过硬门（不放宽）
            if not self.ggc.filter(x_opt, P_reg):
                continue
            eta_g = self.ggc.quality_factor(x_opt)
            eta_topo = self.mctm.query(context.pose)
            eta_cmd = 1.0 - 0.1 * self.stm.information_entropy(q_L,
                                                               self.lmem.all_embeddings())
            eta_interp = sigmoid(-self._semantic_traj_distance(q_L) / self.stm.temp)
            eta_total = (eta_g * eta_topo * eta_interp * eta_cmd
                         * eta_demand_total * eta_affect * eta_traj)
            if self._cheap_gates(x_opt, gamma, eta_total, context.geom_tighten):
                surv.append((x_opt, eta_total))

        if not surv:
            return self._demand_guided_fallback(rho_demand, t_now, context,
                                                affect, eta_affect, P_reg)

        # 6. 级联筛选（VACK → BCK）
        surv.sort(key=lambda x_e: x_e[1], reverse=True)
        finals = []
        for x, _ in surv[:3]:
            vac = self.v7.vack.evaluate(x, context_with(s_emo), t_now)
            if self.v7.vack.kc_val(vac, tau=gamma['val'] * TAU_VAL5):
                if self.v7._bck_preview(x, gamma, context.geom_tighten):
                    finals.append(x)

        if not finals:
            return self._demand_guided_fallback(rho_demand, t_now, context,
                                                affect, eta_affect, P_reg)

        best = max(finals, key=lambda x: self._margin(x))
        return True, best, 'FORGED_CGE_V8'

    def _demand_guided_fallback(self, rho_demand, t_now, context, affect,
                                eta_affect, P_reg):
        if rho_demand is None:
            return self.v7.select(None, t_now, context)
        q_demand = self.dim.encoder(rho_demand)
        m_demand = self.lmem.retrieve_by_semantic(q_demand, k=4)
        t_topo = self.mctm.token(context.pose)
        c_demand = (context.obj, context.geo, context.theta_fp, context.task,
                    self.famk.observe(context.face, t_now), m_demand,
                    context.rho_target, t_topo, q_demand, P_reg)
        cands = self.fmpp.propose(c_demand, K=self.fmpp.K)
        surviving = []
        for x in cands:
            if self.ggc.filter(x, P_reg):
                x_opt, _ = self.tok.refine(x, P_reg, context.g_emb)
                if eta_affect > 0.5:
                    surviving.append(x_opt)
        if not surviving:
            return False, None, 'DEMAND_FALLBACK_FAILED'
        return True, surviving[0], 'DEMAND_GUIDED_FALLBACK'

    def ecs_v8(self, x: Trajectory, n_flow: float, s_emo,
               eta_factors: dict) -> float:
        return (self.v7.ecs_v7(x, n_flow, s_emo, eta_factors)
                * eta_factors['traj'])

    def benchmark(self, context_factory) -> dict:
        return self.bcf.run(self, context_factory)
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  TOK 能量权重 λ_c, λ_g 调参（能量下降曲线验证）
  PCRK 对齐精度校验（ε_reg 分布 vs ε_reg^max）
  BCF 基准套件 B 冻结（版本化，不可任意更改）
  联邦下发：TOK 权重、PCRK 阈值、BCF 基准快照 → 站内签名分发

在线准入（亚秒级）：
  PCRK.register(P_obs, P_model) ──▶ T_reg, P_reg, ε_reg
  若 ε_reg > ε_reg^max：geom_tighten ← 1.2（保守收紧）
  DAC.observe(face) ──▶ affect → η_affect
  DIM.encode(...) ──▶ ρ_demand → η_demand
  若 η_demand < τ_demand：需求导向回退（含 TOK 精修）
  若 η_demand ≥ τ_demand：FMPP 提议 → TOK 精修 → 7 软因子滤波 → VACK/BCK

在线控制环（目标 < 0.8 ms）：
  PCRK + TOK 并行预计算；七硬门调用链路不变（v7 缓存复用）
  η_traj 额外 < 0.1 ms（固定 max_iter=50 投影梯度）
```

| PCRK.register | O(N·M·I) | O(N + M) | N=观测点数, M=模型点数, I=ICP 迭代 | 1~3 ms |
| TOK.refine | O(I·W) | O(W) | I=优化迭代, W=航点数 | < 0.1 ms |
| TOK 能量/梯度 | O(W·N) | O(W) | W=航点数, N=点云点数 | < 0.05 ms |
| BCF.run | O(|B|·T_exec) | O(|B|) | |B|=基准规模 | 离线，不进控制环 |
| η_traj 计算 | O(1) | O(1) | — | < 0.01 ms |

**端到端在线增量**：PCRK 1~3 ms（可异步/下采样点云）、TOK < 0.1 ms，软因子链 O(1)，总 P99 ≈ 0.8 ms（维持 v7 目标），基准测试仅离线执行。

## 4. 正确性论证（增量更新）

### 定理 13（轨迹优化能量单调性）

**陈述**：设 E(x) 为连续可微能量泛函，TOK 以投影梯度下降更新 x_{k+1} = Π(x_k − α∇E(x_k)) 且步长 α 满足 Armijo 条件，则 E(x_{k+1}) ≤ E(x_k)，极限点 x_opt 满足 E(x_opt) ≤ E(x_cand)。

**证明**：投影梯度下降在 Lipschitz 连续梯度且步长足够小的情况下能量单调不增；有限迭代后 E(x_opt) ≤ E(x_cand)。TOK 仅改变轨迹几何，不改动硬门阈值，故 GGC/MCTM/VACK/BCK 对 x_opt 的判定结果集与 x_cand 相比只可能更严格（x_opt 更贴近可行流形，硬门通过率单调非降）。

### 定理 14（点云配准收敛与几何门守恒）

**陈述**：点对面 ICP 每次迭代使残差 ε_reg 单调不增，收敛于局部最优 T_reg^*；若 ε_reg(T_reg^*) ≤ ε_reg^max，则 P_reg 几何误差被控制在硬门容差内，GGC 对 P_reg 的判定与对 P_model 的判定偏差 ≤ ε_reg；若 ε_reg > ε_reg^max，geom_tighten 收紧几何门，使 fail-closed 边界保守。

**证明**：点对面 ICP 是高斯-Newton/Levenberg-Marquardt 最小化，残差单调下降；配准残差 ε_reg 直接上界点云到模型的几何偏差，故硬门判定误差有界。收紧分支（γ_g ← γ_g·(1+δ)）使 τ_i 升高，Exec 集收缩，fail-closed 保持。

### 定理 15（基准回归单调性）

**陈述**：BCF 基准快照 s_v 随版本 v 按偏序 ≺ 记录；若 s_{v+1} ≺ s_v（任一关键度量下降且无补偿提升），则版本 v+1 被拒绝合并，确保 Exec_CADVS-v8 ⊆ Exec_CADVS-v7 在等价基准下不退化。

**证明**：由定义，回归判定仅在严格恶化时触发；被接受的版本在 B 上 Succ/GateRate/DemandRecall 非降且 P99_lat 非升，故回归被结构性阻断。

### 诚实声明

- PCRK 对称/无纹理物体易收敛到错误局部最优，T_reg 失配会导致 GGC 几何判定偏移；
- TOK 投影梯度可能收敛到局部极小，x_opt 不一定是全局可行解；
- η_traj = exp(−E) 为单调映射，E 越大 η_traj 越小，可能过度惩罚合法但高能轨迹；
- BCF 基准套件 B 一旦冻结可能出现「过拟合基准」：在 B 上表现好、分布外场景表现差；
- 软因子链乘积放大误差：若 η_j < 1 出现，Π_factor 下降，τ 升高，Exec 集收缩（保守方向，不破坏 fail-closed）。

## 7. 本轮最大风险（最终确认）
