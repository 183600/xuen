# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「最小可行产品」×「灵巧操作」）

> 第 54 轮回答了「技能能否组合、组合能否部署」，但它回答的是**全局可行性**，不是**最小可信交付**。MVP 视角追问：在灵巧操作里，**最少交付哪一块、并诚实声明哪些不做**？核心矛盾：H22：灵巧操作的能力由**接触模式的可达与切换**决定，而非动作空间体积；按体积裁剪出的「最小」核心会恰好切掉 stick↔slip、抓取↔再抓取之间的桥，导致局部可部署、任务边界崩塌。H23：MVP 的「最小」天然想省略接触边界，而接触边界恰恰是真实灵巧手最易失效处；因此 MVP 的诚实性完全取决于**证书债是否在接触层被正确计价**——债记少了，MVP 就从「最小可行」退化为「最小骗局」。

## 0. 直觉与动机

**灵感 1（灵巧操作的动作空间是接触分层流形，不是欧氏盒子）**
直觉：第 54 轮的 `α_S : A → [0,1]` 把动作当成一个可积体积。但灵巧手的动作是**接触签名** `σ = (接触点集, 每点模式{stick/slip/rolling/impact}, 内力可行性)`；同一关节指令在 stick 与 slip 两种模式下是两种物理技能。动作空间应写成**分层流形** `A = ⊔_{σ∈Σ_c} A_σ`。MVP 的第一性单位因此不是动作点，而是**一个接触层（contact stratum）**。

**灵感 2（最小可行技能 = 接触闭合的最小核心 + 显式证书债）**
直觉：产品 MVP 的精髓不是"做最少功能"，而是"只承诺能被证据支撑的部分，并把其余部分明确标为不做"。对应地，**最小可行技能 MVS** 是一个二元组：可证明的**接触闭合核心** `(σ_core, A_mv)` 加上一份显式的**证书债** `D_cert`——即核心之外那些"我们知道没验证"的动作/接触体积。MVP 的力量来自**诚实划界**，不是来自体积小。

**灵感 3（证书债是 MVP 的诚实来源，也是最大隐患）**
直觉：把未验证区域记为债，可以防止"仿真里全绿、真机上全崩"的错觉。但债的计价依赖**暴露密度** `u(a)`：如果边界接触被低估，债就是假的；一旦部署扰动把系统推入这些未计价区域，隐性负债就变成真实故障。MVP 的风险不是"做少了"，而是"少做的那部分被悄悄当成已做"。

**灵感 4（灵巧阶梯：MVP 不是静态集合，而是可攀爬的接触模式图）**
直觉：灵巧能力有天然阶梯——`M_0` 准静态抓取 → `M_1` 抓取内调整（in-hand） → `M_2` 再抓取/手指步态（regrasp/finger gait） → `M_3` 动态/冲击操作。每一级都是**接触模式图 `G_C` 上的一条边**，边权是转换风险与转换证书成本。MVP 应是一个阶梯游标：只在 **边际已验证能力 / 边际证书成本** 最优时向上爬，且每次爬升都必须保持接触闭合。

**灵感 5（组合需要对接裕度：局部 MVP 相加 ≠ 灵巧组合）**
直觉：两个局部 MVS 各自可部署，不代表拼接后仍灵巧——它们可能在接触模式上"接不上"。因此每个 MVS 必须在边界保留**对接带 `B_dock`**，组合时检查共享任务接口上的接触模式兼容性与切换时延。这把第 54 轮的 `compat` 从"动作交集"深化为"接触模式对接"。

**灵感 6（对研究方法本身也用 MVP：最小证伪实验集）**
直觉：第 54 轮列了 E157–E161，却没回答"最少做哪几个实验就能推翻 MVS 证书"。把实验选择建成**子模覆盖**：每个实验覆盖一组失效假设 `H`，选最小成本、最大证伪力的实验子集。方法论的 MVP = 用最少实验买到最大推翻概率，而不是把实验表铺满。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（接触分层动作流形）**
接触签名 `σ = (C_σ, M_σ, λ_σ)`：`C_σ` 为接触点/面集合，`M_σ : C_σ → {stick, slip, roll, impact}` 为接触模式，`λ_σ` 为内力分配参数。动作流形分层为
```
A = ⊔_{σ∈Σ_c} A_σ ,   A_σ = { a ∈ A : 执行 a 的接触签名为 σ }
```
技能 `S` 的支撑集 `M_S = {(σ,a) : a∈A_σ, α_S^{σ}(a) ≥ θ_cov}`，其中 `α_S^{σ}` 是**层内**动作剖面（第 54 轮 `α_S` 在层 σ 上的限制）。

**定义 122（力闭合与可操作裕度）**
在层 σ 上，动作 a 的力闭合裕度 `μ_fc(a)`（摩擦锥内最大扰动旋量半径）与可操作裕度 `μ_op(a)`。给定下限 `μ_min`，**接触可行域**
```
V_S = { (σ,a) ∈ M_S : μ_fc(a) ≥ μ_min ∧ μ_op(a) ≥ μ_op^min ∧ ρ_S^{σ}(d,a) ≥ ρ_min ∀d }
```

**定义 123（最小可行技能 MVS）**
令任务 `T` 的关键接触签名集为 `Σ_T`（覆盖任务所需接触模式的集合），认证成本 `cert(σ)`、部署暴露密度 `u(σ,a) ≥ 0`、债预算 `D_max`。MVS 为
```
M* = (σ_core*, A_mv*, J_mv, D_cert*)
σ_core* , A_mv* = argmin_{σ_core, A_mv} [ Σ_{σ∈σ_core} cert(σ) + λ·D_cert(A_mv) ]
s.t.  Σ_T ⊆ σ_core                         (任务接触覆盖)
      A_mv ⊆ ⋃_{σ∈σ_core} V_S ,  J 在 A_mv 上 sound
      D_cert(A_mv) = ∫_{M_S \ A_mv} u(σ,a) dσ da ≤ D_max
      A_mv 在任务迁移集 E_T 下接触闭合（定义 124）
```
注意：`A_mv` 是**最小认证闭包**，不是最小演示体积；`D_cert` 是显式负债，不是被优化掉的误差项。

**定义 124（任务迁移集与接触闭合）**
任务执行中允许的接触层转移集 `E_T ⊆ Σ_c × Σ_c`（如 stick→slip 恢复、抓取→再抓取）。称 `A_mv` 在 `E_T` 下**接触闭合**，若
```
∀(σ,σ')∈E_T, ∀a∈A_mv∩A_σ, 转移目标 trans(a;σ→σ') ∈ A_mv∪B_dock
```
即核心内任一允许转移的落点仍在核心或对接带内。**闭合缺陷** `gap_closure = |E_T \ E(A_mv)|`，必须为 0 或显式计入 `D_cert`。

**定义 125（接触模式图与灵巧阶梯）**
接触模式图 `G_C = (Σ_c, E_C)`；边 `(σ,σ')` 携带转换证书 `C_trans = (μ_fc^{min}, τ_trans, p_fail)`。灵巧阶梯 `L = {M_0 ⊂ M_1 ⊂ ...}`，其中 `M_k` 对应 `G_C` 上一个**闭合于其内部转移**的子图。相邻级差 `ΔM_k = M_k \ M_{k-1}` 是本次爬升交付的新接触能力。

**定义 126（对接裕度、MVP 证书与最小性见证）**
MVS 的第 i 个实例带对接带 `B_dock,i ⊂ ∂A_mv,i`。两 MVS 的**对接裕度**
```
δ_dock(i,j) = min_{ (σ,a) ∈ shared(∂A_mv,i, ∂A_mv,j) } [ compat_σ(a) · (1 - τ_trans/τ_max) ]
```
`δ_dock ≥ δ_min` 才允许组合。MVP 证书
```
J_mv = (σ_core, A_mv, ρ_mv, δ_dock, D_cert, u, W_min, W_debt, evidence)
```
- `W_min` 最小性见证：`∀ e∈A_mv`，删除 e 后有最小反例违反覆盖/力闭合/鲁棒之一；
- `W_debt` 债务见证：边界偏置采样给出 `D_cert` 的 conformal 上界；
- `evidence`：真机最少反例集（定义 126 的方法论 MVP）。
**MVP 闭环算子**：`Shrink`（失败→收缩 A_mv，抬高保守性）、`Climb`（成功→仅在边际能力/边际成本最优时加一层）、`Reprofile`（重估 u 与 Σ_c）。三者构成 `deploy → measure → shrink/climb → reprofile`。

## 2. 关键算法 伪代码

### IP-121 CSF（Contact Stratification & force-closure profiling）

```python
def contact_profile(skill, A, contact_sampler, rho_min, mu_min):
    M_S = {}
    for a in A:
        sigma, mu_fc, mu_op = contact_sampler.eval(skill, a)
        if mu_fc >= mu_min and mu_op >= mu_op_min:
            rho = robustness_spectrum(skill, a)
            if min(rho.values()) >= rho_min:
                M_S.setdefault(sigma, {})[a] = (rho, mu_fc, mu_op)
    return M_S          # {(sigma): {a: (rho, mu_fc, mu_op)}}
```

### IP-122 MVX（Minimum Viable core eXtraction）

```python
def extract_mvs(M_S, Sigma_T, E_T, cert_cost, debt_density, D_max, lam):
    # 1) 任务接触覆盖：候选层必须覆盖 Sigma_T
    cand = cover_strata(M_S, Sigma_T)
    # 2) 闭包：只保留对 E_T 闭合的层组合（否则把缺口计入债）
    cand = [s for s in cand if gap_closure(s, E_T) == 0]
    # 3) 带债预算的最小认证成本覆盖（分支定界 + LP 松弛）
    best = None
    for core in branch_and_bound(cand, cost=lambda c: sum(cert_cost[s] for s in c),
                                 lower_bound=lp_cover_lb):
        A_mv = minimal_certified_subset(core, M_S)     # 删除冗余动作，保留最小性见证
        debt = integrate_debt(M_S, A_mv, debt_density)
        if debt > D_max:
            continue
        val = sum(cert_cost[s] for s in core) + lam * debt
        if best is None or val < best.val:
            best = MVS(core, A_mv, debt, minimality_witness(A_mv))
    return best if best else ('infeasible', min_violation_witness(M_S, Sigma_T, E_T))
```

### IP-123 VLC（Viability Ladder Climb）

```python
def viability_ladder(M_0, G_C, task_dist, budgets, delta_min):
    ladder = [M_0]
    while True:
        cands = frontier_edges(G_C, ladder[-1], task_dist)   # 任务分布加权的候选下一层
        best = None
        for e in cands:
            M_new = close_under(ladder[-1].add(e), G_C)       # 必须接触闭合
            if not docking_ok(M_new, delta_min):             # 保持可组合对接裕度
                continue
            dval = expected_capability_gain(M_new, task_dist)
            dcost = certification_cost(M_new) + integrate_debt(M_new)
            score = dval / max(dcost, eps)
            if best is None or score > best.score:
                best = (M_new, score, dval, dcost)
        if best is None or best.score <= 0 or budget_exceeded(best, budgets):
            break
        ladder.append(best[0])
    return ladder
```

### IP-124 CDB（Certificate Debt Bookkeeping）

```python
def integrate_debt(M_S, A_mv, u, conf_alpha=0.05):
    # 边界偏置暴露采样：靠近 A_mv 边界的未验证动作权重更高
    samples = boundary_biased_sample(M_S, A_mv, n=N_debt)
    w = [u(s, a) for (s, a) in samples]
    point = mean(w) * volume(M_S - A_mv)
    slack = conformal_quantile(w, 1 - conf_alpha) * volume(M_S - A_mv)
    return point + slack     # 报出上界，而非乐观点估计
```

### IP-125 DMC（Docking-aware MVS Composition）

```python
def compose_mvs(M_i, M_j, delta_min):
    delta = docking_margin(M_i.B_dock, M_j.B_dock)      # 共享接口上的接触模式兼容
    if delta < delta_min:
        return ('reject', 'docking_gap', delta,
                minimal_docking_witness(M_i, M_j))
    J = merge_joint_certificate(M_i.J, M_j.J, delta)     # 升级第 54 轮 J
    debt = max(M_i.D_cert, M_j.D_cert) + transfer_debt(M_i, M_j)
    return ('ok', J, debt) if debt <= D_max else ('reject', 'debt_exceeded', debt)
```

### IP-126 MRL（MVP Research Loop）

```python
def mvp_research_loop(M, task_dist, sim, robot, exp_budget):
    while exp_budget > 0:
        trials = select_min_falsifying_experiments(M, task_dist, exp_budget)  # 子模覆盖
        ev = run_trials(robot, sim, trials)
        if ev.counterexample is None:
            return ('certified', M, minimality_witness(M), ev)
        if ev.counterexample.inside(A_mv):
            M = shrink(M, ev.counterexample)       # 核心不可信 → 收缩并重认证
        else:
            M = climb_or_reprice(M, ev.counterexample)  # 债区暴露 → 重估 u / 爬梯
    return ('budget_exceeded', M, ev)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CSF | O(|Σ_c|·|A|·(contact_check + |𝔇_ρ|)) | O(|M_S|) | 层枚举完备、力闭合标定 |
| MVX | O(2^{|Σ_c|}·|A|)（NP-hard） | O(|M_S|) | 覆盖 sound、闭包检查、债预算 |
| VLC | O(|E_C|·|Σ_c|·|A|) | O(|L|·|M_k|) | 贪心阶次、闭合保持、对接保持 |
| CDB | O(N_debt + |A|) | O(N_debt) | 边界偏置、conformal 覆盖 |
| DMC | O(|∂A_i|·|∂A_j|) | O(|∂A|) | 对接裕度 sound |
| MRL | O(|E|·|ℍ|)（子模覆盖贪心） | O(|ℍ|) | 反例集覆盖失效假设 |

**命题 1（MVX 的 NP-hard 性）**
将每个技能/接触层视作覆盖任务接触签名子集、成本为 `cert(σ)`，`D_max` 为覆盖外惩罚上限，则 MVS 最小化是带预算的**加权集合覆盖**，由经典集合覆盖归约得 NP-hard；故 MVX 采用分支定界 + LP 下界，或贪心得 `H(|Σ_T|)` 近似。

**命题 2（接触闭合引理）**
若 `E_T ⊄ E(A_mv)`（即存在任务允许的接触转移落点在 `A_mv` 之外且未计入 `B_dock`），则存在任务扰动分布下的正测度路径使系统在有限步内离开 `A_mv`，即使 `A_mv` 内每个动作都单独满足 `V_S`。故「按动作体积最小」得到的核心对任务**不是 sound 的**；闭包是灵巧 MVP 的必要条件，而非工程偏好。

**正确性定理（Contact-Closed Scoped MVS Soundness）**
假设承接第 54 轮 (A26)–(A28)，并新增：**(A29)** 任务相关接触签名 `Σ_T` 与转移集 `E_T` 枚举完备；(A30) `μ_fc, μ_op` 的标定误差 ≤ ε_μ；**(A31)** `A_mv` 在 `E_T` 下接触闭合；(A32) 债密度 `u` 由边界偏置采样以 `1−α` conformal 覆盖率估计。则
```
∀ (σ,a) ∈ A_mv:  P_success ≥ 1 − Σ_d (1−ρ_min(d)) − β_E − ε_μ
组合: P_success(M_i ⊗ M_j) ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − P(δ_dock < δ_min)
域外:  P(failure | (σ,a) ∉ A_mv) ≤ D_cert / vol(M_S \ A_mv)   (以 1−α 置信)
```
**关键**：该证书**只对 `A_mv` 作承诺**；`A_mv` 之外不作全局声明。这不是缺陷，而是 MVP 的定义——**诚实的范围化 soundness 优于虚假的全局 soundness**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 接触签名枚举不完备（漏 slip/impact） | 高 | 红队接触采样 + 冲击/滑移专项压力集 + 未枚举即计入债 |
| 力闭合裕度在软接触/摩擦锥误差下失真 | 高 | 鲁棒摩擦锥 + 真机标定 + `μ_min` 分层保守 |
| 证书债密度 `u` 低估边界接触 | 高 | 边界偏置采样 + conformal 上界 + 债超预算硬否决 |
| 阶梯贪心局部乐观（仿真边际 ≠ 真机边际） | 中 | 留出任务 + 影子价格预算 + 爬升后强制小样本真机校验 |
| 对接带过保守导致组合不可行 | 中 | 自适应对接缓冲 + 分层对接（先模式后动作） |
| MVP 退化为 demo-ware | 中 | 预注册任务分布 + 对抗任务采样 + 最小性/债务见证公开 |

## 6. 本轮最大风险

**一句话**：把 MVP 引入灵巧操作，等于用「接触闭合的最小核心 + 显式证书债」换取范围化的诚实 soundness；但它的全部可信度压在**接触签名枚举完备、力闭合裕度标定、以及债密度由边界偏置采样正确计价**这三根柱子上——一旦漏掉 slip↔stick/impact 层或低估边界暴露，所谓「最小可行」就只是**仿真流形上的最小**，真实手会在未计价的接触层上系统性崩溃，把证书债变成隐藏故障；故必须以 **接触层红队枚举 + 鲁棒力闭合标定 + 债上界硬门** 三重护栏，宁可让 MVP 更小更保守，也绝不把未验证的接触层伪装成已验证。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（CSF×MVX×VLC×CDB×DMC×MRL）

> 承接第 54 轮产物 v31。本轮把「能否组合/能否部署」推进到「**最少可信交付什么**」，并针对灵巧操作的接触本质，增加 **接触分层、最小可行技能、灵巧阶梯、证书债、对接组网、MVP 研究闭环** 六个算子：
> - **CSF（Contact Stratification & force-closure profiling）**：接触分层动作剖面 + 力闭合裕度；
> - **MVX（Minimum Viable core eXtraction）**：接触闭合的最小认证核心 + 证书债预算；
> - **VLC（Viability Ladder Climb）**：按边际能力/成本攀爬灵巧阶梯；
> - **CDB（Certificate Debt Bookkeeping）**：域外未验证体积的 conformal 上界记账；
> - **DMC（Docking-aware MVS Composition）**：带对接裕度的 MVS 组合；
> - **MRL（MVP Research Loop）**：最小证伪实验 + deploy/measure/shrink/climb/reprofile 闭环。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118/120 以纳入接触分层与证书债。核心转向：**从「全局 soundness」改为「范围化 soundness + 显式域外负债」**。

## 2. 关键算法 伪代码

### IP-121 CSF

```python
def contact_profile(skill, A, contact_sampler, rho_min, mu_min, mu_op_min):
    M_S = {}
    for a in A:
        sigma, mu_fc, mu_op = contact_sampler.eval(skill, a)
        if mu_fc >= mu_min and mu_op >= mu_op_min:
            rho = robustness_spectrum(skill, a)
            if min(rho.values()) >= rho_min:
                M_S.setdefault(sigma, {})[a] = (rho, mu_fc, mu_op)
    return M_S          # {(sigma): {a: (rho, mu_fc, mu_op)}}
```

### IP-122 MVX

```python
def extract_mvs(M_S, Sigma_T, E_T, cert_cost, debt_density, D_max, lam):
    cand = cover_strata(M_S, Sigma_T)
    cand = [s for s in cand if gap_closure(s, E_T) == 0]   # 接触闭合硬约束
    best = None
    for core in branch_and_bound(cand,
                                 cost=lambda c: sum(cert_cost[x] for x in c),
                                 lower_bound=lp_cover_lb):
        A_mv = minimal_certified_subset(core, M_S)
        debt = integrate_debt(M_S, A_mv, debt_density)
        if debt > D_max:
            continue
        val = sum(cert_cost[x] for x in core) + lam * debt
        if best is None or val < best.val:
            best = MVS(core, A_mv, debt, minimality_witness(A_mv))
    return best if best else ('infeasible', min_violation_witness(M_S, Sigma_T, E_T))
```

### IP-123 VLC

```python
def viability_ladder(M_0, G_C, task_dist, budgets, delta_min):
    ladder = [M_0]
    while True:
        best = None
        for e in frontier_edges(G_C, ladder[-1], task_dist):
            M_new = close_under(ladder[-1].add(e), G_C)   # 爬升保持接触闭合
            if not docking_ok(M_new, delta_min):
                continue
            dval = expected_capability_gain(M_new, task_dist)
            dcost = certification_cost(M_new) + integrate_debt(M_new)
            score = dval / max(dcost, eps)
            if best is None or score > best.score:
                best = (M_new, score, dval, dcost)
        if best is None or best.score <= 0 or budget_exceeded(best, budgets):
            break
        ladder.append(best[0])
    return ladder
```

### IP-124 CDB

```python
def integrate_debt(M_S, A_mv, u, conf_alpha=0.05):
    samples = boundary_biased_sample(M_S, A_mv, n=N_debt)   # 边界权重更高
    w = [u(s, a) for (s, a) in samples]
    volume = volume_of(M_S - A_mv)
    point = mean(w) * volume
    slack = conformal_quantile(w, 1 - conf_alpha) * volume
    return point + slack    # 始终报上界
```

### IP-125 DMC

```python
def compose_mvs(M_i, M_j, delta_min, D_max):
    delta = docking_margin(M_i.B_dock, M_j.B_dock)
    if delta < delta_min:
        return ('reject', 'docking_gap', delta, minimal_docking_witness(M_i, M_j))
    J = merge_joint_certificate(M_i.J, M_j.J, delta)   # 升级第 54 轮联合证书
    debt = max(M_i.D_cert, M_j.D_cert) + transfer_debt(M_i, M_j)
    return ('ok', J, debt) if debt <= D_max else ('reject', 'debt_exceeded', debt)
```

### IP-126 MRL

```python
def mvp_research_loop(M, task_dist, sim, robot, exp_budget):
    while exp_budget > 0:
        trials = select_min_falsifying_experiments(M, task_dist, exp_budget)  # 子模覆盖
        ev = run_trials(robot, sim, trials)
        if ev.counterexample is None:
            return ('certified', M, minimality_witness(M), ev)
        if ev.counterexample.inside(M.A_mv):
            M = shrink(M, ev.counterexample)            # 核心不可信 → 收缩
        else:
            M = climb_or_reprice(M, ev.counterexample)  # 债区暴露 → 重估 u / 爬梯
    return ('budget_exceeded', M, ev)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CSF | O(|Σ_c|·|A|·(|𝔇_ρ|+contact_check)) | O(|M_S|) | 层枚举完备、力闭合标定 |
| MVX | O(2^{|Σ_c|}·|A|)（NP-hard） | O(|M_S|) | 覆盖 sound、闭包检查、债预算 |
| VLC | O(|E_C|·|Σ_c|·|A|) | O(|L|·|M_k|) | 贪心阶次、闭合/对接保持 |
| CDB | O(N_debt+|A|) | O(N_debt) | 边界偏置、conformal 覆盖 |
| DMC | O(|∂A_i|·|∂A_j|) | O(|∂A|) | 对接裕度 sound |
| MRL | O(|E|·|ℍ|) | O(|ℍ|) | 反例集覆盖失效假设 |

**命题 1（MVX 的 NP-hard 性）**
MVS 最小化等价于带预算惩罚的加权集合覆盖（接触层覆盖 `Σ_T`、成本 `cert(σ)`、域外惩罚 `λ·D_cert`），由经典集合覆盖归约得 NP-hard；故用分支定界 + LP 下界，或贪心得 `H(|Σ_T|)` 近似。

**命题 2（接触闭合引理）**
若 `E_T ⊄ E(A_mv)`，则存在任务扰动分布下的正测度路径使系统在有限步内离开 `A_mv`，即使 `A_mv` 内每个动作单独满足 `V_S`。故「按动作体积最小」的核心对任务不 sound；**接触闭合是灵巧 MVP 的必要条件**。

**正确性定理（Contact-Closed Scoped MVS Soundness）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** `Σ_T, E_T` 枚举完备；**(A30)** `μ_fc, μ_op` 标定误差 ≤ ε_μ；**(A31)** `A_mv` 在 `E_T` 下接触闭合；**(A32)** `u` 由边界偏置采样以 `1−α` conformal 覆盖率估计。则
```
∀ (σ,a) ∈ A_mv:  P_success ≥ 1 − Σ_d(1-ρ_min(d)) − β_E − ε_μ
组合:  P_success(M_i⊗M_j) ≥ 1 − Σ_d(1-ρ_min(d)) − β_E − P(δ_dock<δ_min)
域外:  P(failure | (σ,a)∉A_mv) ≤ D_cert / vol(M_S\A_mv)   (置信 1−α)
```
**关键**：证书只对 `A_mv` 承诺，域外以显式债上界代替虚假全局保证——**范围化 soundness + 可审计负债**优于全局假绿。

## 6. 本轮最大风险

**一句话**：MVP × 灵巧操作把「全局部署证书」换成「接触闭合最小核心 + 显式证书债」的范围化诚实方案，但其可信度全部压在**接触签名枚举完备、力闭合裕度标定、债密度边界偏置计价**三根柱子上；一旦漏掉 slip↔stick/impact 层或低估边界暴露，「最小可行」就只是**仿真流形上的最小**，真实手会在未计价的接触层系统性崩溃，把证书债变成隐藏故障；故必须以 **接触层红队枚举 + 鲁棒力闭合标定 + 债上界硬门** 三重护栏，宁可更小更保守，也绝不把未验证的接触层伪装成已验证。
