# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「知识图谱」×「多模态融合」）

> R69 把不确定性拆成 aleatoric / epistemic，并给 epistemic 开了一条出路：主动去看、去问、去触。它用一条纪律兜底——**「k 个正交证据源一致才定案」**。但 R69 从未真正定义「正交」：它默认**测不同物理量 = 统计独立**。这是它最深的裂缝。**通道正交 ≠ 统计独立**：一个撒谎的人可以同时控制表情、语气、姿态；一块被篡改的标定表可以让多个传感器同向漂移；一次幻觉能让「视觉说的」和「语言说的」共享同一个错误先验。此时「k 个源一致」不是 k 份证据，而是**同一个原因说了 k 遍**。R69 引理 18 里那个 ρ 是写死的，没人去估它——而它恰恰是决定生死的那一个数。
>
> 本轮两个灵感正好补这块：
> - **知识图谱**把「谁从谁那里知道」变成可计算的图结构：独立性 = 图上的 d-分离，有效证据数 k_eff 由共同祖先结构导出；多跳路径给出「链式求证」；符号接地让问题可被证伪；缺失的预期观测带来负证据。
> - **多模态融合**从「投票 / 加权平均」升级为「图条件化融合」：可靠性沿边传播、缺失模态沿接地路径补全、违反本体约束的模态组合产生矛盾证据。
>
> 核心命题：**把 R69 的「扁平证据集 + 声明的正交」升级为「证据图 + 推导的有效独立性 k_eff」；只有 k_eff ≥ k 且接地可验证时，交互得到的答案才算证据；图不可信时逐指令退化回 FLUID-RAS，再退化回 R68。** 命名 **GRID-RAS**（Graph-grounded Reliability & Independence-aware Disambiguation）——「网格」既是结构也是约束：证词必须在网格上找得到来源，独立性必须在网格上算得出来。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的证人真的独立吗，他们又是听谁说的**」——证据的**结构**，和证据的**内容**一样可以被欺骗。

## 0. 直觉与动机

**灵感 1（知识图谱 → 独立性是图的性质，不是通道的性质）**
直觉：法庭上，两个证人都说自己「亲耳听见」，但若他们听的是同一个八卦，法官只算**一个**证人——法律上叫「同源」。传感器亦然：每条证据都有来源谱系。一台相机和一个麦克风在物理上正交（不同模态、不同噪声底），却可能被**同一个隐变量**驱动（同一个操纵者、同一次打光故障、同一个被污染的时钟）。反过来，同一传感器在相近时刻的两次读数，若噪声是「新鲜的」，反而可能统计独立。所以独立不是「通道标签」决定的，而是**祖先结构**决定的。知识图谱恰好记录 `caused_by / derived_from / observed_by / reports / corroborates / same_as` 这些关系。把「独立性」从一句声明变成一个**图上可计算量**，是 R69 到 R70 的核心跃迁。

**灵感 2（多模态融合 → 融合是图条件化的，不是加权投票）**
直觉：R69 用 `argmax IG(M; r_ij | g*)` 选「最有判别力的模态对」。但模态从来不是一个扁平集合：它们挂在**实体与关系**上。融合应当条件在一个子图上——哪些模态在说同一个实体（可对照）、哪些在说同一实体的不同谓词（互补）、哪些在说同一谓词的不同通道（冗余）、哪些组合被本体排除了（矛盾）。图条件融合有三个天然好处：缺失模态可沿接地路径**补全**（并标注「这是推断不是观测」）；可靠性可沿边**传播**（来源差的证据自动降权）；矛盾本身成为**证据**（违反物理/本体约束的模态组合比单纯的「不一致」信息量更大）。当图退化为无边、候选只剩一对时，它精确回落到 R69 的 CIA。

**灵感 3（负证据 → 狗没有叫）**
直觉：福尔摩斯的「没叫的狗」。知识图谱不只描述「有什么」，还编码「若某假设成立，应当能观测到什么」。如果假设是「有人闯入」，图预言「狗叫 / 运动传感器触发」；这些**应当出现却没出现**，本身就是强证据。R69 的融合只累计**出现**的观测，把缺席当成「缺失数据」去补——这是在丢掉信息。有了「期望」，缺席就变成**证伪**。而且这是最安全的证据类型：它不需要你相信任何人说的话，只需要世界**没有出示**假设所要求的东西。代价是：它可以被「故意隐藏」制造（人不作为），故仍需共同模式检测来区分「世界没给」与「有人不让给」。

**灵感 4（符号接地 → 不能被证伪的问题不值得问）**
直觉：R69 最大的次级风险是语言接地幻觉——LLM 吐出一句流畅问题，其实并不对应任何传感器能检查的东西；人回答了，这个答案就进入后验成了「证据」。知识图谱的接地映射 `grounds` 把每个声明原子绑到可观测谓词上。**一个答案若无法对任何谓词构成可检验的似然比，它就是「漂浮声明」**：可以微调先验，永远不能定案。这把「随便问」收紧成「只问可证伪的事」——既是安全，也是效率（不问无信息的问题）。

**灵感 5（共同模式欺骗 → R69「k 一致纪律」的致命盲点）**
直觉：R69 引理 18 假设各源欺骗相关 ρ<1，给出错误率 ≤ δ_p·ρ^{k−1}；但它从不**估计** ρ。协调一致的欺骗让 ρ→1：一个人同时演表情、语气、姿态；一块对抗补丁同时污染多路相机；一份被投毒的 schema 让「视觉」和「语言」都朝同一个错。这时 k 一致买不到任何鲁棒性。更阴险的是：**共同模式欺骗看起来比诚实证据「更好」**——它太一致了，一致到超过图在诚实模型下预测的水平。所以要两个统计量：**结构**上算 k_eff（祖先是否坍缩）、**内容**上算超额一致 r_cons（是否比诚实更整齐）。

**灵感 6（图也会错 → 用图审计图，R69 是退化边界）**
直觉：加一张 KG 就多一个攻击面——过期 schema、投毒边、伪造 provenance。而且与「可以再问一次的撒谎者」不同，**图很难被重新盘问**。所以 GRID 必须能审计自己的图：把同一套 d-分离 / k_eff 机器**递归地用在 provenance 图上**，检查一条声称「独立佐证」的来源是不是真的独立（是不是又共享了同一个祖先）。若图可疑 → 不相信结构 → 逐指令退化 FLUID-RAS 的扁平融合；若 FLUID 也不可用 → 退化 R68。**每一级新层都必须是旧层在明确边界上的严格退化，否则每加一层就多一个需要独立信任的黑箱。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GRID-RAS 总览与四不变式）** GRID-RAS = (EG, PAI, GBF, GQ, SGV, CMK, KGI, FLUID-RAS)。四不变式：
(i) **继承 FLUID-RAS 三不变式**（零学习写操作、交互预算硬约束、证据纪律）；
(ii) **独立性必须由图推导**：任何「多源一致」的采纳必须附带 k_eff ≥ k 的 d-分离证书，禁止声明式正交；
(iii) **可证伪性**：任何进入后验的声明必须存在接地路径到可观测谓词；无接地路径者为「漂浮声明」，只可乘性微调先验、不可定案；
(iv) **图可审计**：EG 自身须通过 KGI 自审计；图不可信 ⇒ 逐指令退化 FLUID-RAS。

**定义 311（证据图 EG）** EG_t = (V, R, W, τ)。V = V_C ∪ V_O ∪ V_H ∪ V_P ∪ V_A，分别为隐因节点、观测/证据节点、假设/声明节点、接地谓词节点、信息源主体。R = {caused_by, derived_from, observed_by, reports, corroborates, contradicts, grounds, same_as, part_of}；边带可靠度 w∈[0,1] 与时戳 τ。`lin(e)` 为证据 e 到 V_A 的全部来源路径集合。

**定义 312（图诱导独立性与 d-分离）** 给定观测集 O（已观测或可条件化的节点），记 e_i ⟂_G e_j | O 当且仅当 e_i、e_j 在 EG 的祖先图（ancestral graph）中被 O d-分离。定义有效依赖图 G_eff[S]：在候选证据集 S 上连边 (i,j) ⟺ e_i 与 e_j 在给定 O 下 d-连通（即统计相关）。

**定义 313（有效证据数 k_eff）** k_eff(S) = α(G_eff[S])，即有效依赖图的最大独立集（|S|≤5 时精确求解，更大时用贪心/分数松弛）。语义：k_eff 是「互相独立的证人数」，不是「发言次数」。性质：单一未观测共同祖先（一个撒谎者）⇒ G_eff 成团 ⇒ k_eff = 1；k 条互不相交的来源链 ⇒ k_eff = |S|。

**定义 314（来源相关性 ρ_eff 与投毒上界接口）** 对任意 i,j，令 ρ_eff(i,j) 为二者共享未观测祖先的可靠度质量（按路径长度指数衰减）。图诱导的成对相关代理 ρ̄ = 1 − (k_eff − 1)/(|S| − 1)（|S|>1）。据此把 R69 引理 18 中写死的 ρ 替换为由图**估计**的 ρ̄。

**定义 315（图条件融合 GBF）** 融合算子 F_EG({z_m}, G_S, EG) 在 S 诱导子图上做可靠性消息传递，输出后验 p(H | obs, EG)。三机制：
(a) **可靠性传播**：节点后验按边可靠度加权，坏来源自动降权；
(b) **缺失模态补全**：缺失维沿接地/关联路径从可观测邻居推断（图插补），并显式标注「推断来源」；
(c) **矛盾证据**：违反本体/物理解释约束的模态组合生成 `contradicts` 边，矛盾本身作为证据进入融合。
当 EG 无边且 S 仅含一对时，GBF 精确退化为 R69 的 CIA。

**定义 316（负证据 NEG）** 对假设 h 与接地谓词 P，KG 给出「若 h 则 P 应以概率 p 可观测」。执行一次针对 P 的感知/交互，在检测功效 β 下：观测到 P 时 LR₊ = βp / βp′；未观测到 P 时 LR₋ = (1−βp)/(1−βp′)，其中 p′ = P(P | ¬h)。负证据进入 GBF；R69 只累计 LR₊，等价于丢弃 P(¬obs) 项。

**定义 317（图查询 VoI GQ）** 信息动作扩展为图查询 q = (g, target, P_target, path)，path 为 EG 上长度 ≤ h 的有向链。VoI_G(q) = H(H|o) − E_{y~p(·|q,o)}[H(H|o,y)]，沿链逐跳条件化。选择 q* = argmax_q [VoI_G(q) − c(q)]，s.t. 预算与安全。单跳查询退化为 R69 的 MINT；多跳查询是「先看 A，若为红再看 B」的链式求证。

**定义 318（符号接地验证 SGV）** 接地映射 gr: 原子声明 c ↦ {(m, P, β)}，即可验证的（模态、谓词、检测功效）集合。声明 c 入后验的必要条件：gr(c) ≠ ∅ 且存在可达信息动作使 P 可被观测（可证伪性）。不满足者标记 floating，只允许乘性先验调整 κ∈(0,1)，不得作为定案证据。

**定义 319（共同模式欺骗检测 CMK）** 两个统计量：
(a) **结构**：k_eff(S)/|S| < κ_struct（祖先坍缩）；
(b) **内容**：超额一致 r_cons = a_obs − E[a | 诚实, G_eff]，其中 a_obs 为观测成对一致率，E[·] 由图结构与各源错误率预测。
任一越界 ⇒ S 不可用于定案，U_epi 保持未消解。直觉：**诚实的独立证人不会「过分整齐」**。

**定义 320（KG 完整性自审计 KGI）** 每条边 e 的 provenance 证书要求 ≥2 条**图独立**的来源路径（对 provenance 图递归使用定义 313 的 k_eff）。KGI = 通过审计的边可靠度占比。检测三类病态：**陈旧**（时戳超期）、**来源伪造**（声称独立实为同祖先）、**矛盾环**（EG 出现 h → … → ¬h 的环）。KGI < τ_kg 或检出矛盾环 ⇒ EG 不可信。

**定义 321（三级保守退避链）** GRID（图可信 ∧ 接地 ∧ k_eff≥k）→ FLUID（图不可信/无结构时，逐指令退化）→ R68（VoI≤成本 / ECE 越界 / 缓变故障疑）。每级都是下一级在明确边界上的**严格退化**，形成 R68 ⊆ FLUID ⊆ GRID 的包含链，安全侧每级不让步、只在上层多拿 efficiency/resolution bonus。

**定义 322（证书 J_GRID）** J_GRID = (J_FLUID, k_eff, dsep_cert_hash, grounding_coverage, floating_ratio, cmk_score, r_cons, kgi_score, provenance_hash, grid_ver)。Valid ⇔ Valid(J_FLUID) ∧ kgi ≥ τ_kg ∧ grounding_coverage ≥ γ ∧ 证据纪律(k_eff ≥ k) ∧ 预算未越界。

**定义 323（图演化与慢变漂移）** EG 带时戳；对 EG_t 与 EG_{t−τ} 做边级差异。慢变漂移在图中表现为关系可靠度/结构的缓慢改变。与 FMA（定义 301）联立：**动作似然正常但图关系漂移** ⇒ 另一类缓变故障信号（补 R68/R69 只盯传感器与行为、不盯「世界关系」的盲区）。

**定义 324（参与式审计 VQAuditor-G）** 审计对象新增：图查询是否越界、k_eff 证书是否真实、漂浮声明是否被误采纳、provenance 是否伪造、负证据是否被忽略。结论回灌 AuditBuf，成为下一轮 KGI 与 MINT 的成本先验。

**定义 325（交互投毒干扰集 AIC-GRID）** ℰ_GRID = ℰ_FLUID × ℰ_graph，新增：共同模式共谋欺骗、provenance 伪造、schema 投毒、陈旧事实、负证据制造（故意不出现在该出现处）、图诱导的错误多跳。

**定义 326（实时预算与降级）** 图操作仅在候选子图（h ≤ 2，邻域上限 B ≤ 32）上做，缓存实体邻域；GRID 增量开销 δ_t 超预算即退化 FLUID-RAS。图的「深度」本身是被预算约束的自由度。

# IP-264 EG：证据图构建（复用 R69 的 z_t 与残差五元组，零重复感知）
class EvidenceGraph:
    def ingest(self, obs, residuals, claims, sources):
        # 观测/隐因/假设/接地谓词/信息源节点 + 因果/来源/接地边
        self.cache_neighborhood(obs.entities, B=32)
    def lineage(self, e):                    # e 到 V_A 的全部来源路径
        return bounded_paths(e, self, hops=6, B=32)

# IP-265 PAI：图诱导独立性（独立性从声明变成计算）
def k_eff(S, EG, observed):
    G_eff = dependency_graph(S, EG, observed)   # d-连通 => 连边
    return max_independent_set(G_eff)           # |S|<=5 精确，否则贪心/分数松弛

def dsep_certificate(S, EG, observed):
    G_eff = dependency_graph(S, EG, observed)
    return all(not G_eff.has_edge(i, j) for i, j in pairs(S))

# IP-266 GBF：图条件融合（可靠性传播 + 缺失补全 + 负证据 + 矛盾）
def graph_fusion(modalities, H, EG, observed):
    S    = induced_subgraph(EG, modalities, H, hops=2, B=32)
    post = message_pass(S, modalities, rounds=2)     # (a) 可靠性传播
    post = impute_missing(post, S)                   # (b) 缺失沿接地路径补全
    post = apply_negative_evidence(post, S, observed)# 定义 316
    return post, contradictions(S)                   # (c) 矛盾作为证据

# IP-267 GQ：图查询 VoI（多跳链式求证）
def graph_query(modes, EG, o_t, budget):
    best = None
    for path in bounded_chains(EG, hops=2, B=32):
        for g in info_action_candidates(path):
            if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t): continue
            score = voi_on_chain(path, g, o_t) - cost(g)
            if best is None or score > best.score: best = (path, g, score)
    return best if best and best.score > 0 else None   # 无利可图 → FLUID/R68

# IP-268 SGV：接地验证（拦截漂浮声明）
def grounding_ok(claim, EG):
    gr = grounding_atoms(claim, EG)
    return bool(gr) and any(reachable_action(m, P) for (m, P, beta) in gr)

# IP-269 CMK：共同模式欺骗（结构坍缩 + 超额一致）
def common_mode(S, EG, observed, agree):
    struct = k_eff(S, EG, observed) / len(S)
    r_cons = agree.observed - agree.expected_under(EG, S)
    return (struct < KAPPA_STRUCT) or (r_cons > TAU_CMK)

# IP-270 KGI：图自审计（用图审计图）
def kg_integrity(EG):
    ok = 0.0
    for e in EG.edges:
        if e.stale(): continue
        paths = independent_provenance_paths(e, EG)   # 对 provenance 图算 k_eff
        if k_eff(paths, EG, observed=None) >= 2 and not in_contradiction_cycle(e, EG):
            ok += e.w
    return ok / max(total_weight(EG), 1e-9)

        else:
            U_epi_after = U_epi
    U_floor = U_ale + (U_epi_after if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))   # R68 兜底
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_g.submit_async(g, agree, M.eg, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after, M.kgi.audit(M.eg))
```

## 3. 推导

**引理 19（图诱导有效独立性下的投毒上界）** 设一致集 S，各源错误率 ≤ δ_p，有效依赖图 G_eff 给出有效证据数 k_eff。在「取 k_eff 个图独立源做多数」纪律下，错误采纳率 ≤ Σ_{i=⌈k_eff/2⌉}^{k_eff} C(k_eff,i) δ_p^i (1−δ_p)^{k_eff−i}；δ_p 小时主项为 Θ(δ_p^{⌈k_eff/2⌉})。系：**真正决定鲁棒性指数的是图诱导的 k_eff，而不是数出来的 k**；R69 引理 18 的 ρ 只是 k_eff 的粗代理。共同模式共谋把 G_eff 压成团、k_eff→1，指数退化为 1，k 一致纪律失效——这也解释了「越一致越危险」：ρ→1 时错误同向，投票无法抵消。

**引理 20（负证据的信息增益与不可欺骗性）** 设接地谓词 P，P(观测到 P | h) = p，P(观测到 P | ¬h) = p′，p>p′。检查 P 的互信息 I(H; O_P) ≥ 2π(1−π)(p−p′)²（Pinsker 型），其中 π=P(h)；且当 p′→0 时，观测到 ¬P 的似然比 (1−p)/(1−p′)→1−p，对 ¬h 的支持无界增长。系：**负证据只需世界不出示预期，不需信任任何人的嘴**，是唯一几乎不可被「花言巧语」伪造的证据；但它可被「故意隐藏」制造（人不作为），故必须由 CMK 区分「世界没给」与「有人不让给」。

**引理 21（KG 投毒的可检测上界）** 设边 e 需 ≥2 条图独立 provenance 路径认证。若攻击者须同时伪造 m 条独立路径才能让毒边通过 KGI，且每条路径被污染概率 ≤ δ_K，则毒边通过审计概率 ≤ δ_K^m。未被认证的毒边对后验的影响 ≤ w_e·‖Δlogit‖，且其会人为抬高一致率，触发 CMK 的 r_cons 项。系：**图的安全性由图自身的 k_eff 保证**——同一条纪律递归作用在 provenance 层。

**定理 18（GRID 严格包含 FLUID，FLUID 为无边图边界）** 在 A99（EG 对相关结构因果忠实：d-分离 ⇒ 统计独立）、A100（接地覆盖 ≥ γ）、A101（KGI ≥ τ_kg）下，对任意状态 s，GRID 的期望风险 ≤ FLUID；且当 EG 无边、或 KGI < τ_kg、或接地覆盖不足时，GRID 与 FLUID **逐指令相同**；再叠加 FLUID 的退化条件，与 R68 逐指令相同。故 R68 ⊆ FLUID ⊆ GRID 构成严格包含链，安全侧每级不让步。

**定理 19（图查询安全与无突变）** 图查询 q 分解为至多 h 个单跳信息动作，每个都过 C-RAS-WM 前缀认证（定义 302）；多跳共享一次预算，任一跳失败/超时即整链作废、U_epi 不消解；查询只改变「选哪个模态 / 采纳哪条证据」，不改变安全包络；三级退化时 λ 单调不降。故控制连续、无突变，物理风险 ≤ ε_int，且继承 R68 定理 15 与 R69 定理 17 的换装/提交不变式。

## 6. 本轮最大风险

**一句话**：GRID-RAS 的全部收益押在「证据图是因果忠实的」这一前提上——**若图缺少共同原因边、schema 过期或 provenance 被伪造，k_eff 就会在错误的独立性模型上计算，系统会把「同一张嘴通过多个模态说话」认证成「k 个独立证人一致」；这比 R69 更危险：R69 只是听错一句话，R70 可能把同一个骗子数成多个证人**。

**次级风险与缓解**：
1. **图的因果忠实性不可验证**（缺边/错边）→ KGI 自审计 + 反事实扰动抽检 + A101 显式假设，越界即退化 FLUID；
2. **共同模式欺骗伪装成高一致** → CMK 结构/内容双统计量 + 引理 19，绝不让 r_cons 异常的集合定案；
3. **负证据被「主动隐藏」利用** → 区分「未观测」与「被阻止观测」，将后者计入交互投毒集 ℰ_graph；
4. **实时预算被图操作击穿** → 邻域缓存 + 有界跳数 h≤2 + 超预算即退化 FLUID；
5. **接地映射不全导致过度保守**（漂浮声明过多）→ 允许 κ 先验微调 + E306 度量 floating_ratio，避免把「不能证伪」误当「一定假」。

# IP-265 PAI：独立性从「声明」变成「计算」
def k_eff(S, EG, observed):
    G_eff = dependency_graph(S, EG, observed)   # d-连通 => 连边
    return max_independent_set(G_eff)           # |S|<=5 精确；否则贪心/分数松弛

# IP-266 GBF：图条件融合（可靠性 + 缺失 + 负证据 + 矛盾）
def graph_fusion(modalities, H, EG, observed):
    S    = induced_subgraph(EG, modalities, H, hops=2, B=32)
    post = message_pass(S, modalities, rounds=2)      # 可靠性传播
    post = impute_missing(post, S)                    # 缺失沿接地路径补全
    post = apply_negative_evidence(post, S, observed) # LR_- 项
    return post, contradictions(S)                    # 矛盾即证据

# IP-267 GQ：多跳图查询
def graph_query(modes, EG, o_t, budget):
    best = None
    for path in bounded_chains(EG, hops=2, B=32):
        for g in info_action_candidates(path):
            if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t): continue
            score = voi_on_chain(path, g, o_t) - cost(g)
            if best is None or score > best.score: best = (path, g, score)
    return best if best and best.score > 0 else None

# IP-269 CMK：共同模式（结构坍缩 + 超额一致）
def common_mode(S, EG, observed, agree):
    struct = k_eff(S, EG, observed) / len(S)
    r_cons = agree.observed - agree.expected_under(EG, S)
    return (struct < KAPPA_STRUCT) or (r_cons > TAU_CMK)

# IP-270 KGI：用图审计图
def kg_integrity(EG):
    ok = 0.0
    for e in EG.edges:
        if e.stale(): continue
        paths = independent_provenance_paths(e, EG)    # 对 provenance 图算 k_eff
        if k_eff(paths, EG, observed=None) >= 2 and not in_contradiction_cycle(e, EG):
            ok += e.w
    return ok / max(total_weight(EG), 1e-9)

    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))   # R68 兜底
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_g.submit_async(g, agree, M.eg, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after, M.kgi.audit(M.eg))
```

## 4. 推导

**引理 19（图诱导有效独立性下的投毒上界）** 在「取 k_eff 个图独立源多数」纪律下，错误采纳率 ≤ `Σ_{i=⌈k_eff/2⌉}^{k_eff} C(k_eff,i) δ_p^i (1−δ_p)^{k_eff−i}`，小 δ_p 时主项为 `Θ(δ_p^{⌈k_eff/2⌉})`。系：决定鲁棒性指数的是**图诱导的 k_eff**，不是数出来的 k；R69 的 ρ 只是 k_eff 的粗代理；共同模式共谋使 G_eff 成团、k_eff→1，指数退化为 1，k 一致纪律失效——越一致越危险。

**引理 20（负证据的信息增益与不可欺骗性）** 检查接地谓词 P 的互信息 `I(H;O_P) ≥ 2π(1−π)(p−p′)²`；`p′→0` 时 `LR₋→1−p`，对 ¬h 支持无界。系：负证据不需信任任何人的嘴，最难被花言巧语伪造；但可被「故意隐藏」制造，须由 CMK 区分「世界没给」与「有人不让给」。

**引理 21（KG 投毒的可检测上界）** 若毒边须伪造 m 条图独立 provenance 路径方能过 KGI，各路径污染概率 ≤ δ_K，则通过概率 ≤ `δ_K^m`；未认证毒边影响 ≤ `w_e·‖Δlogit‖`，且会抬高一致率触发 CMK 的 `r_cons`。系：图的安全性由图自身的 k_eff 保证，同一纪律递归作用在 provenance 层。

**定理 18（GRID 严格包含 FLUID，FLUID 为无边图边界）** 在 A99（EG 因果忠实：d-分离 ⇒ 独立）、A100（接地覆盖 ≥ γ）、A101（KGI ≥ τ_kg）下，GRID 任意状态期望风险 ≤ FLUID；且 EG 无边 / KGI 越界 / 接地不足时二者逐指令相同；再叠加 FLUID 退化条件与 R68 逐指令相同。故 `R68 ⊆ FLUID ⊆ GRID`，安全侧每级不让步。

**定理 19（图查询安全与无突变）** 图查询分解为 ≤ h 个单跳信息动作，均过 C-RAS-WM 认证；多跳共享一次预算，任一跳失败即整链作废、U_epi 不消解；查询只改「选哪个模态/采纳哪条证据」，不改安全包络；三级退化时 λ 单调不降。控制连续、无突变，物理风险 ≤ ε_int，继承 R68 定理 15 / R69 定理 17。

## 7. 本轮最大风险

**一句话**：GRID-RAS 的全部收益押在「证据图是因果忠实的」这一前提上——**若图缺少共同原因边、schema 过期或 provenance 被伪造，k_eff 就会在错误的独立性模型上计算，系统会把「同一张嘴通过多个模态说话」认证成「k 个独立证人一致」；这比 R69 更危险：R69 只是听错一句话，R70 可能把同一个骗子数成多个证人**。

**次级风险与缓解**：图的因果忠实性不可验证（KGI 自审计 + 反事实抽检 + A101，越界退 FLUID）；共同模式伪装高一致（CMK 双统计量 + 引理 19）；负证据被主动隐藏利用（区分未观测/被阻止，计入 ℰ_graph）；实时预算被图操作击穿（邻域缓存 + h≤2 + 退化）；接地不全致过度保守（κ 先验微调 + E306 控 floating_ratio）。
