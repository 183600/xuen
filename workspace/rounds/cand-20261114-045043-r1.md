# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「少样本学习」×「应用落地」）

> R69 把不确定性做成了有形状的对象，并把「问」变成动作。但 R69 仍是一个**实验室里的闭环**：它默认（P1）策略已经在足够大的数据上训好了；（P2）部署环境就是训练分布；（P3）证书是对「一台机器人、一个任务、一段短时间」说的。把 FLUID-RAS 从论文搬到现场，最先撞上的不是算法，而是三件事：**冷启动只有 k 个演示**、**现场分布与训练分布不同**、**要为一支车队而不是一台机器负责**。
> - **少样本学习**给出冷启动的语法：不是「用小数据重训」，而是「用一个先验 + 一个支撑集，构造一个带泛化证书的任务后验」；
> - **应用落地**给出部署的语法：交付单位不是模型而是**可回滚的变更包 + 运维者 + 运行设计域（ODD）**；要优化的是尾部、成本、维护与相关失效，而不是均值。
>
> 核心命题：**把「支撑集」提升为一等、可审计、可议价的对象；把「落地」形式化为覆盖-风险-成本的三方权衡；并让 few-shot 的泛化界成为证书的一部分，而不是一句「效果不错」。** 命名 **SEED-RAS**（Support-set Epistemic Envelope Deployment for Risk-Adaptive Systems：支撑集认知包络部署的风险自适应系统）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我只用 k 个样本、在一支车队的现场，凭什么敢说它安全**」——落地不是把 k 调大，而是让每一个 k 都附带一份说得出边界的证书。

## 0. 直觉与动机

**灵感 1（少样本学习 → k 个样本买的是「后验」，不是「参数」）**
直觉：few-shot 常被误讲成「用 k 个样本微调」。但在 k 很小时，梯度更新几乎不改变网络，真正起作用的始终是**先验**：模型看似「学会了新任务」，其实多半是在「回忆某个旧任务」。所以 few-shot 的第一性产物不应只是参数，而应是一个**任务后验** `q(h|D_k)`，以及「这个后验在多大范围、以多大概率成立」的**泛化证书**。小样本最危险的不是欠拟合，而是**把先验误当证据**：k 越小，系统越自信地重复它已经会的东西，而现场的例外恰好落在它不会的部分。

**灵感 2（应用落地 → 部署是尾部工程，不是均值工程）**
直觉：实验室看平均成功率，现场看 P99 延迟、每千小时事故率、维护工时、监管合规、操作员信任，以及「day-0 没有任何数据」时能不能开机。落地的交付单位不是 `model.pt`，而是一个**变更包**：版本、配置、ODD、监控、回滚、责任人。核心概念是**运行设计域（ODD）**——只在证书覆盖的状态上自主运行，包络外降级或交接。再往上一层是**车队**：多台设备共享同批硬件、同批演示、同一套操作员培训，稀有失效高度相关；单机覆盖率再高，也不能简单相加成车队证据。

**灵感 3（两者交汇 → k 是经济量，包络是风险量）**
直觉：k 越大，泛化界越紧，但标注成本越高；ODD 越窄越安全，但可用性越低。二者都是旋钮，不应拍脑袋，而应由信息价值与总拥有成本（TCO）联合决定：`k* = argmax[信息增益(k) − k·c_demo]`。few-shot 的边际收益递减，因此存在**内点最优**——「样本越多越好」是把成本忽略后的错觉。

**灵感 4（与 R69 的关系 → 多出两类 epistemic，且消解动作不同）**
直觉：R69 的 `U_epi` 是「这一次观测的歧义」；落地还多出两类：
- `U_task`：这是哪个任务 / 哪个用户 / 哪个本体？（由演示消解）
- `U_support`：k 个样本的抽样误差与覆盖不足（由更多、更广的演示消解）

二者仍属 epistemic，但**消解动作不同**：`U_epi` 用交互（看/问/触），`U_task`/`U_support` 用演示（要一段示范 / 标注 / 校准）。于是 R69 的 MINT 动作空间扩为 `A_info ∪ A_demo`。关键是它们属于同一族：k→∞、ODD=全空间、车队 N=1 时，SEED 逐指令退化为 FLUID。R70 不是另起炉灶，而是给 R69 加「落地坐标」。

**灵感 5（暗面 → 支撑集是新的攻击面，也是新的责任面）**
直觉：R69 的攻击面是「回答」，R70 的攻击面是「示范」。投毒的 demo 比投毒的回答更隐蔽：它直接改写「先验→任务」的映射，且会被 k-shot 放大（标签翻转 / 轨迹漂移 / 后门触发）。更隐蔽的是「同源支撑集」：整支车队用同一批演示，则每台机器的覆盖率都达标，但失效是**相关的**——一次共因失效可以同时击穿所有证书。还有落地版「证书洗白」：把 k 压小、把 ODD 放大、把 SLO 写成均值，证书就变成市场材料。对策必须是结构性的：来源与同意、trimmed/median 聚合、留一法、负迁移门、相关感知车队界、canary、强制回滚演练。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SEED-RAS 总览与六不变式）** SEED-RAS = (FMP†, AUD†, SSA, TPI, FSR, DEG, BA, NTG, DQ, FCC, RRP, VQAuditor-D, J_SEED, RAS-WM‡)。六不变式：
(i) 继承 R69 定义 276-i 的**实时流零学习写操作**；
(ii) **适配局部性**：部署期只允许有界适配器 Δθ、且 ‖Δθ‖≤ρ_ad；骨干与安全头冻结；适配只在影子/调试期发生，实时环只消费**已认证快照**；
(iii) **支撑集溯源与同意**：每个演示带来源、时间、操作者、同意与用途；未通过 SSA 的支撑集不得进入适配；
(iv) **运行设计域**：只在 DEG 认证覆盖的状态上自主运行；包络外必须降级（R68 保守）或交接；
(v) **车队诚实**：单机证书不可直接相加；发布需相关感知车队界 + canary + 回滚；
(vi) **成本诚实**：k、算力、运维都是证书字段，不存在「免费的自适应」。

**定义 311（支撑集与任务后验）** 支撑集 `D_k = {(o_i, ξ_i, c_i)}_{i=1}^k`（观测、动作块、上下文/任务标签）。元先验 `p(h)`（跨部署 episode 的离线经验），任务后验 `q(h|D_k) ∝ p(h)Π_i p(ξ_i|o_i,h)`，预测 `p(ξ|o,D_k)=∫ p(ξ|o,h) q(h|D_k) dh`。定义**有效样本量**
`n_eff = k / (1 + (k−1)ρ_s)`，
其中 `ρ_s` 为支撑集内相关性（同源、同操作者、同场景）。当 `n_eff ≪ k` 时，「k 个样本」实际上只是「1 个样本的 k 次复制」——这直接解释了为什么「多录几遍同一个人」替代不了「多找几个人」。

**定义 312（少样本风险三分与 PAC-Bayes 界）** 把 R69 的不确定性再细分：
- `U_task = E_{h,h'~q}[D(π_h ‖ π_h')]`：任务后验内部分歧（epistemic，由更「有区分度」的演示消解）；
- `U_support`：有限支撑集导致的泛化界（epistemic，由更多/更广/更独立的演示消解）；
- `U_ale`：R69 的模态内不可约噪声（继承）。
对任意 δ∈(0,1)，以概率 ≥1−δ：
`R(q) ≤ R̂_{D_k}(q) + sqrt( (KL(q‖p) + ln(2√k/δ)) / (2 n_eff) ) + U_ale`，
记右端第二项为 `U_support`。三者语义不同、不做简单加和；只有失败时共同进入保守上界（定义 325）。

**定义 313（支撑集审计 SSA）** 五元审计：
- 覆盖 `r_cov = sup_{o∈ODD} min_i d(o,o_i)/σ_o`（支撑集离 ODD 最远处有多远）；
- 边界 `m_sup`（kNN 距离 / 任务标签间隔）；
- 一致性 `e_loo`（留一法泛化误差）；
- 溯源/同意 `p_prov`；
- 投毒影响 `I_poi = max_i |∂R̂/∂z_i|`（影响函数）或 trimmed-loss gap。
通过 ⇔ `r_cov≤τ_c ∧ m_sup≥τ_m ∧ e_loo≤τ_e ∧ p_prov 合法 ∧ I_poi≤τ_i`。SSA 输出**原因码**（覆盖/边界/一致/溯源/投毒），供 DQ 决定「补哪一类样本」，而不是笼统地「再要几个样本」。

**定义 314（演示询问 DQ 与最优 k）** 演示动作 `g_demo ∈ A_demo`：请求一段示范、一次标注、一次校准。其价值
`VoI_demo(k) = E[U_task(D_k)+U_support(D_k) − U_task(D_{k+1})−U_support(D_{k+1})] − c_demo`，
`k* = argmax_{k≤k_max} Σ_{j<k} VoI_demo(j)`，s.t. 预算；边际增益 < c_demo 时停止。对可交换数据，信息增益关于 k **次模**（submodular），故贪心达到 (1−1/e) 近似且存在内点最优。DQ 在线下/调试期执行；实时环最多发起「请演示」的**异步请求**，绝不自学。

**定义 315（部署包络 DEG）** `ODD = (S_ODD, T_ODD, E_ODD, O_ODD)`：状态、任务族、环境条件、操作者能力。证书只在 ODD 上有定义。**覆盖-服务曲线**：对给定风险 ε，`V(ε) = max{ volume(ODD) : sup_{s∈ODD} R(s) ≤ ε }`。部署选择 (ε*, V*) 落在 Pareto 前沿上。`s∉ODD` ⇒ 降级/交接。**部署是一个覆盖决策，不是一个布尔开关。**

**定义 316（有界适配 BA）** 只允许适配器 `Δθ`，`‖Δθ‖≤ρ_ad`；骨干 `θ`、安全头 `φ_safe`、认证器 C-RAS-WM 冻结。适配只在 commissioning/shadow 发生；通过 SSA 与 NTG 后在安全点**原子换装**（复用 R68 定理 15）。设动作映射关于参数 `L_π`-Lipschitz（A101），则 `‖π_{θ+Δθ}(o)−π_θ(o)‖ ≤ L_π ρ_ad`。因安全头与认证器不参与适配，安全包络不变；认证对适配后的动作重新执行。

**定义 317（负迁移门 NTG）** 在 probe 集 `P`（覆盖 ODD 的保留样本 + 已见任务）上要求 `ΔR_probe = R(θ+Δθ) − R(θ) ≤ 0`（工程上 ≤ ε_nt）。否则拒绝适配、保留先验。这是 few-shot 版的「首先不伤害」：**适配必须先证明确实更好，而不是先上线再观察。**

**定义 318（车队证书 FCC）** N 台设备，单机失效概率 `p_i`，支撑集/硬件/培训相关 `ρ_f`，`N_eff = N/(1+(N−1)ρ_f)`。车队失效界
`P(any) ≤ min( Σ_i p_i, 1 − (1−p̄)^{N_eff} )`。
发布用 canary `m` 台 + 序贯概率比检验（SPRT），控制误放行 ≤ δ_fleet。回滚触发：canary 失效 / SLO 越界 / 相关性突变。爆炸半径 ≤ m。

**定义 319（冷启动降级 CSD）** k=0：只用元先验 `p(h)`，进入「先验模式」，ODD 收紧到**先验证书覆盖集**；若先验证书不覆盖当前状态 ⇒ 请求演示/DQ 或交接。**绝不无证书自主运行。**

**定义 320（部署成本与 TCO）**
`C_total(k, ODD) = k·c_demo + c_compute + c_maint + P_incident(k,ODD)·C_incident + c_handoff·(1 − V(ε)/V_0)`。
联合选择 `(k*, ODD*)` 最小化 C_total，s.t. 风险 ≤ ε。注意「便宜但投毒/同源的样本」会让后三项爆炸——成本模型必须给**支撑集质量**定价，否则优化器会自动学会买垃圾样本。

**定义 321（SEED 干扰集 AIC-SEED）** `E_SEED = E_FLUID × E_support × E_transfer × E_fleet × E_deploy`：`E_support` 标签翻转 / 轨迹漂移 / 后门触发 / 同源复制；`E_transfer` 负迁移、先验错配；`E_fleet` 共因失效、同批硬件、同批演示；`E_deploy` 为过 SLO 而缩 k / 放 ODD 的「证书洗白」压力。自然漂移与对抗攻击按同一标准建模——对安全而言二者无法区分。

**定义 322（发布与回滚协议 RRP）** 阶段 0 影子（只观测）、阶段 1 canary m 台、阶段 2 分阶段扩量、阶段 3 全量。每阶段有前置条件、监控指标、回滚触发器与最大爆炸半径；回滚必须**演练过**（回滚哈希入证书）。**没有回滚演练的发布等于没有发布。**

**定义 323（参与式审计 VQAuditor-D）** 审计：支撑集来源/同意、k 与成本理由、SSA 原因码、NTG 结果、ODD 覆盖、车队相关性与 canary、回滚就绪、操作者交接记录。结论不可篡改地回灌元先验、成本先验与 ODD 边界。

**定义 324（元先验离线更新与部署学习曲线）** 跨部署 episode 的支撑集只用于**离线**更新 `p(h)`（及 SSA/DQ 的成本先验）；实时环永不写学习参数。定义**部署学习曲线** `k_t`：达到同一证书强度所需样本数。若 `k_t` 不随部署次数下降，说明「经验」没有变成「先验」，few-shot 只是在重复付标注费。

**定义 325（证书 J_SEED）** `J_SEED = (J_FLUID, support_audit_hash, n_eff, pacbayes_bound, k, ODD_coverage, adapter_norm, nt_gain, fleet_stats, canary_result, rollback_hash, seed_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ SSA 通过 ∧ PAC-Bayes 界 ≤ ε ∧ 运行状态∈ODD ∧ NTG 通过 ∧ canary 通过 ∧ 回滚就绪`。

**定义 326（严格包含阶梯）**
- `k→∞, n_eff→∞, ODD=全空间, N=1, 无 DQ` ⇒ `U_support→0, U_task→0`、DEG 恒真，SEED 逐指令退化为 FLUID（R69）；
- 再令永不交互、ECE 越界 ⇒ CALM（R68）。
故 `R68 ⊆ R69 ⊆ R70`。安全侧：SEED 在 ODD 内以概率 1−δ 满足风险 ≤ ε，ODD 外退 R68；**R70 的能力只在证书内增加，安全侧不后退。**

## 2. 关键算法骨架

```python
# IP-264 SSA：支撑集五元审计，输出原因码而非一句“够不够”
def support_audit(Dk, ODD, probe):
    r_cov = max(min_dist(o, Dk) for o in sample(ODD))
    m_sup = knn_margin(Dk)
    e_loo = leave_one_out_error(Dk, fit_bounded_adapter)
    p_prov = all(valid_provenance_and_consent(d) for d in Dk)
    I_poi = influence_score(Dk, probe)          # 影响函数 / trimmed-loss gap
    ok = (r_cov <= TAU_C and m_sup >= TAU_M and e_loo <= TAU_E
          and p_prov and I_poi <= TAU_I)
    return ok, reason_codes(r_cov, m_sup, e_loo, p_prov, I_poi)

# IP-265/266 TPI + FSR：任务后验 + 有效样本量 + PAC-Bayes 界
def task_posterior_and_bound(Dk, prior, delta):
    q      = fit_posterior(prior, Dk)                 # 适配器集成 / Laplace
    n_eff  = len(Dk) / (1 + (len(Dk)-1) * rho_support(Dk))
    R_emp  = empirical_risk(q, Dk)
    kl     = kl_divergence(q, prior)
    U_sup  = sqrt((kl + log(2*sqrt(len(Dk))/delta)) / (2*n_eff))
    U_task = expected_pairwise_divergence(q)
    return q, U_task, U_sup, R_emp + U_sup            # 界 = 经验风险 + U_support

# IP-267 DQ：演示作为信息动作；次模 ⇒ 贪心 / 内点最优 k
def best_k(Dk, budget):
    k, total = 0, 0.0
    while k < budget.k_max:
        g = expected_info_gain(Dk, k) - budget.c_demo
        if g <= 0: break
        total += g; k += 1
    return k if total > 0 else 0                      # 无利可图 → 不买样本

# IP-268 DEG：部署是覆盖决策；包络外一律降级/交接
def deploy_gate(s, cert, ODD):
    if not inside(s, ODD):   return Fallback('out_of_ODD',  R68_conservative)
    if not cert.covers(s):   return Fallback('no_certificate', Handoff)
    return Autonomous(cert)

# IP-269/270 BA + NTG：有界适配 + 负迁移拒绝
def commission(Dk, prior, probe, ODD):
    ok, why = support_audit(Dk, ODD, probe)
    if not ok: return Reject(why)                     # 先补样本，不硬上
    adapter = fit_bounded_adapter(prior, Dk, max_norm=MAX_NORM)
    if risk(adapter, probe) - risk(prior, probe) > EPS_NT:
        return Reject('negative_transfer')            # 首先不伤害
    return adapter                                    # 影子期验证 → 原子换装

# IP-271 FCC：相关感知车队界 + canary
def fleet_release(N, mean_p, rho_f, delta_fleet):
    N_eff = N / (1 + (N-1) * rho_f)
    bound = 1 - (1 - mean_p) ** N_eff
    if bound > delta_fleet: return Block('fleet_bound', N_eff)
    return Canary(stages=[0.01, 0.1, 1.0], sprT=True,
                  rollback=Rollback(rehearsed=True))

# IP-277 主闭环：实时环只消费已认证快照；在线只记录、不学习
def SEED_RAS_round(M, obs):
    gate = M.deg.gate(obs.state, M.cert, M.ODD)
    if not isinstance(gate, Autonomous):
        return gate.execute()                          # 降级 / 交接，绝不无证书自主
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)      # 以下逐指令复用 R69
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 把已认证快照里的 U_task / U_support 作为保守先验项并入上界
    U_floor = U_ale + U_epi + M.cert.U_task + M.cert.U_support
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    if M.ssa.needs_support(obs):                       # 异步请求，不自学
        M.dq.request_async(reason=M.ssa.reason_codes)
    M.vqa_d.submit_async(gate, M.cert, U_epi, lam)
    return k, lam, mode, (U_ale, U_epi, M.cert.U_task, M.cert.U_support)

## 3. 推导

**引理 19（少样本 PAC-Bayes 界与 n_eff）** 设支撑集内相关性使有效样本量 `n_eff = k/(1+(k−1)ρ_s)`。对任意先验 p、后验 q，以概率 ≥1−δ：
`R(q) ≤ R̂_{D_k}(q) + sqrt( (KL(q‖p) + ln(2√k/δ)) / (2 n_eff) )`。
系：当 `ρ_s>0`，增加 k 的收益按 `n_eff` 而非 k 增长；复制同一操作者的 k 个样本几乎不收紧界。**「样本独立性」是比「样本数量」更稀缺的资源。**

**引理 20（最优 k 与边际递减）** 若 `U_task + U_support` 关于 k 次模（A102：可交换数据、信息不可增），则净增益 `G(k)=Σ_{j<k} VoI_demo(j) − k·c_demo` 凹，`k* = min{k : ΔVoI(k) < c_demo}`，贪心取得 (1−1/e) 近似。系：存在内点最优；「k 越大越好」只在成本为零时成立。

**引理 21（支撑集投毒 / 同源的界）** 设污染比例 δ_p，采用 trimmed / median 聚合，击穿点 ≤ floor(k/2)，则风险增量 ≤ `δ_p/(1−δ_p)·C + ε_σ`；若 provenance 与 LOO 构成 m 个独立审计源，有效污染率可压到 `δ_p·ρ^{m}`。系：**k 小不仅界松，而且击穿点低**——few-shot 的鲁棒性天然弱于大样本，这正是「少样本 + 落地」必须配审计、不能只配期望的原因。

**引理 22（有界适配的安全不变）** A101（动作映射 Lipschitz）+ 安全头与认证器冻结 ⇒ 适配后动作偏移 ≤ `L_π ρ_ad`，且认证仍对适配后动作执行，安全包络不变；原子换装（R68 定理 15）⇒ 控制连续、无突变。故适配只在**性能侧**改变，不在**安全侧**让步。

**定理 18（SEED 严格包含 FLUID）** 令 `k→∞、n_eff→∞、ODD=全空间、N=1、无 DQ`，则 `U_support→0、U_task→0`、DEG 恒真，主闭环逐指令退化为 R69；再令交互无效、ECE 越界，则退化为 R68。故 `R68 ⊆ R69 ⊆ R70`，安全侧期望风险沿阶梯单调不增。

**定理 19（车队相关失效与 canary）** 若 `p_i ≤ p̄`、相关系数 `ρ_f`，则 `P(any) ≤ 1−(1−p̄)^{N_eff}`，`N_eff = N/(1+(N−1)ρ_f)`；canary 的 SPRT 在误放行概率 ≤ δ_fleet 下停止，且爆炸半径 ≤ 当前阶段规模。系：`ρ_f→1` 时 `N_eff→1`——**同源支撑集是共因失效的种子**，单机覆盖率再高也不构成车队证据。

**定理 20（部署门无伤害）** `s∉ODD` 或证书不覆盖 ⇒ 退 R68 保守 / 交接，其风险 ≤ 基线；`s∈ODD` 且证书有效 ⇒ 以概率 ≥1−δ 风险 ≤ ε。故 SEED 不引入「证书外自主」这一新风险类别，只把不可用性显式化为交接/降级。

**定理 21（负迁移与冷启动的安全界）** NTG 拒绝任何 probe 风险不降的适配；k=0 时 CSD 仅在先验证书覆盖内运行。故适配与冷启动的期望风险 ≤ 其先验证书的风险上界；few-shot 只在**证明确实更好**时才被允许上线。

## 6. 本轮最大风险

**一句话**：SEED-RAS 把「能不能落地」压缩成「支撑集是否可信 + 包络是否守得住」，但**所有证书（PAC-Bayes 界、ODD 覆盖、车队界）都是对支撑集所代表的世界说的**——若那 k 个演示有偏、同源、被投毒，或 `n_eff` 因隐藏相关被高估，系统就会带着一份数学上合法、语义上空洞的证书，以更小的 k、更宽的 ODD、更高的车队覆盖率上线；**落地版最危险的失败不是没有证书，而是证书覆盖的是一个不存在的世界。**

**次级风险与缓解**：
1. **同源支撑集导致车队共因失效** → 定义 318 相关感知 `N_eff` + canary + 强制异源演示抽样；
2. **支撑集投毒 / 后门** → SSA 影响函数 + trimmed/median + 溯源同意 + ℰ_support 红队；
3. **负迁移被均值掩盖** → NTG probe 门 + 拒绝选项 + E307；
4. **为过 SLO 缩 k / 放 ODD 的证书洗白** → J_SEED 强制记录 k 与 ODD 覆盖 + 审计不可篡改 + TCO 给质量定价；
5. **冷启动 day-0 无数据** → CSD 先验模式 + 收紧包络 + 请求演示 / 交接，绝不无证书自主。

def support_audit(Dk, ODD, probe):
    r_cov = max(min_dist(o, Dk) for o in sample(ODD))
    m_sup = knn_margin(Dk)
    e_loo = leave_one_out_error(Dk, fit_bounded_adapter)
    p_prov = all(valid_provenance_and_consent(d) for d in Dk)
    I_poi = influence_score(Dk, probe)
    ok = (r_cov<=TAU_C and m_sup>=TAU_M and e_loo<=TAU_E
          and p_prov and I_poi<=TAU_I)
    return ok, reason_codes(r_cov, m_sup, e_loo, p_prov, I_poi)

# IP-265/266 TPI + FSR：任务后验、有效样本量、PAC-Bayes 界
def task_posterior_and_bound(Dk, prior, delta):
    q      = fit_posterior(prior, Dk)
    n_eff  = len(Dk) / (1 + (len(Dk)-1)*rho_support(Dk))
    R_emp  = empirical_risk(q, Dk)
    U_sup  = sqrt((kl_divergence(q,prior) + log(2*sqrt(len(Dk))/delta))
                  / (2*n_eff))
    U_task = expected_pairwise_divergence(q)
    return q, U_task, U_sup, R_emp + U_sup

        if g <= 0: break
        total += g; k += 1
    return k if total > 0 else 0

    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    if M.ssa.needs_support(obs): M.dq.request_async(M.ssa.reason_codes)
    M.vqa_d.submit_async(gate, M.cert, U_epi, lam)
    return k, lam, mode, (U_ale, U_epi, M.cert.U_task, M.cert.U_support)
```

## 4. 推导

**引理 19（少样本 PAC-Bayes 界与 n_eff）** `R(q) ≤ R̂_{D_k}(q) + sqrt((KL(q‖p)+ln(2√k/δ))/(2 n_eff))`，以概率 ≥1−δ。系：相关性 `ρ_s>0` 时，k 的收益按 `n_eff` 打折；**样本独立性比样本数量更稀缺**。

**引理 20（最优 k 与边际递减）** `U_task+U_support` 关于 k 次模 ⇒ 净增益凹，`k*=min{k: ΔVoI(k)<c_demo}`，贪心 (1−1/e) 近似；存在内点最优。

**引理 21（支撑集投毒 / 同源的界）** trimmed/median 聚合击穿点 ≤ floor(k/2)，风险增量 ≤ `δ_p/(1−δ_p)C+ε_σ`；m 个独立审计源把有效污染率压到 `δ_p ρ^m`。系：**k 小不仅界松，击穿点也低**——few-shot 必须配审计。

**引理 22（有界适配的安全不变）** A101 与冻结安全头/认证器 ⇒ 动作偏移 ≤ `L_π ρ_ad`，认证仍对适配后动作执行，安全包络不变；原子换装 ⇒ 无突变。

**定理 18（严格包含 FLUID）** `k→∞、ODD 全空间、N=1、无 DQ` ⇒ `U_support→0、U_task→0`、DEG 恒真，逐指令退化为 R69；再令交互无效、ECE 越界 ⇒ R68。故 `R68⊆R69⊆R70`，安全侧风险单调不增。

**定理 19（车队相关失效与 canary）** `P(any)≤1−(1−p̄)^{N_eff}`，`N_eff=N/(1+(N−1)ρ_f)`；SPRT 控制误放行 ≤ δ_fleet，爆炸半径 ≤ 阶段规模。系：`ρ_f→1 ⇒ N_eff→1`，**同源支撑集是共因失效的种子**。

**定理 20（部署门无伤害）** 包络外/无证书 ⇒ 退 R68 或交接，风险 ≤ 基线；包络内且证书有效 ⇒ 以概率 ≥1−δ 风险 ≤ ε。SEED 不引入「证书外自主」的新风险。

**定理 21（负迁移与冷启动的安全界）** NTG 拒绝任何 probe 风险不降的适配；CSD 仅在先验证书覆盖内运行 ⇒ 适配与冷启动期望风险 ≤ 先验证书上界；few-shot 只在证明确实更好时上线。

## 5. 复杂度分析

| 组件 | 时间 | 空间 | 正确性保证 |

## 7. 预期结果与判据

若方案成立，三条独立证据链应同时成立：
1. **统计层**：PAC-Bayes 界覆盖真实误差（E302 覆盖率 ≥95%），且 `n_eff` 正确预测同源支撑集的风险膨胀（E303 误差 ≤15%）；
2. **审计层**：SSA 与 NTG 能在上线前拦住坏支撑集与负迁移（E305 AUROC≥0.88、E306 检出≥95%、E307 拒绝≥95%）；
3. **部署层**：ODD 内实测风险 ≤ 名义 ε（E308），出界自主违规 = 0（E309），车队失效率符合相关感知界（E310），canary 误放行 ≤ δ_fleet 且回滚 ≤5min（E311）。
任一链断裂即判定本轮失败——**尤其是第一条**：若界不能覆盖真实误差，则整份证书退化为营销材料。

## 8. 本轮最大风险

**一句话**：SEED-RAS 把「能不能落地」压缩成「支撑集是否可信 + 包络是否守得住」，但**所有证书（PAC-Bayes 界、ODD 覆盖、车队界）都是对支撑集所代表的世界说的**——若那 k 个演示有偏、同源、被投毒，或 `n_eff` 因隐藏相关被高估，系统就会带着一份数学上合法、语义上空洞的证书，以更小的 k、更宽的 ODD、更高的车队覆盖率上线；**落地版最危险的失败不是没有证书，而是证书覆盖的是一个不存在的世界。**

**次级风险与缓解**：同源支撑集致共因失效（相关感知 `N_eff` + canary + 异源抽样）；支撑集投毒/后门（SSA 影响函数 + trimmed/median + 溯源同意 + ℰ_support 红队）；负迁移被均值掩盖（NTG probe 门 + 拒绝选项 + E307）；为过 SLO 缩 k/放 ODD 的证书洗白（J_SEED 强制记录 + 不可篡改审计 + TCO 给质量定价）；冷启动 day-0 无数据（CSD 先验模式 + 收紧包络 + 请求演示/交接，绝不无证书自主）。
