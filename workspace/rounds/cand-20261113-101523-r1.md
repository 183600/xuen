# 第 66 轮（承接第 65 轮「VISTA 视觉知情的安全时序归因」IP-214~223；灵感循环第 1 轮；本轮灵感：「深度相机」×「跨物体泛化」）

> 第 65 轮把「可证伪」升级为「可归因」，其自述的最大风险很尖锐：**归因依赖「故障属于有限假设集、且视觉与几何的失效相互独立」；透明/镜面/对抗 patch 会让二者共享同一个分布外失效源，FIR 把未知复合故障强行塞进最近假设、只膨胀错误的球，系统反而因「已经归因」而更自信地继续执行。** 本轮不再增加假设或模态，而是退回到一个更靠前、更根本的问题：**第 65 轮的归因与证书，是在哪些物体上标定的？它们对一台从未见过的物体还成立吗？** 本轮核心命题是：
>
> **把「故障可归因」升级为「可信几何可在物体间迁移」：用深度相机的结构化失效（缺失即证据、材质指纹、多视几何证伪）把「看不见 / 看得不对」变成可归因的证据；用物体嵌入与漂移半径显式声明证书的有效域；用不变/特化签名分解让可迁移的部分免费迁移、不可迁移的部分少量自适应；用少样本主动迁移探针把漂移半径收缩回可信域，否则安全回退。**

## 0. 直觉与动机

**灵感 1（深度相机 → 失效结构本身是一种证据）**
直觉：深度相机不是「几何真值」，而是一台有明确物理失效模式的仪器。透明物体会让深度「穿过去」或直接丢失；镜面会产生飞点与多峰；深色低反射会低信噪比；薄壁/细结构会稀疏缺失；多台结构光会互相干扰；ToF 多径会在边缘产生「鬼影」。关键洞察：**深度缺失不是随机噪声，而是缺失非随机（MNAR, missing-not-at-random）——缺失模式是材质与几何的函数**。因此「那里没有深度」本身就是关于「那里可能是透明/镜面/薄壁」的证据。第 65 轮把视觉当作「接触之前/之外的第三条证据」，却仍默认观测是干净的；本轮把**缺失、飞点、多峰、穿透深度、背表面**全部纳入证据，并把每像素不确定性建模为**空间相关的场**，而不是 i.i.d. 噪声。

**灵感 2（深度相机 → 主动几何证伪，而不是被动相信）**
直觉：透明与镜面最怕「换一个角度」。多视重投影一致性、运动视差、相位/编码光往返时间，都能在没有标签的情况下证伪一个几何假设：若深度图在 A 视角给出一张面、在 B 视角重投影却对不上，那不是噪声，而是几何假设错了。深度相机还能主动改变视角或投影图案，去**最大化「几何假设/材质假设是否正确」的互信息**（下一最佳视角 NBV）。这把第 65 轮「视觉世界模型预测残差」升级为物理可解释的多视几何证伪，减少对学习世界模型的依赖。

**灵感 3（跨物体泛化 → 物体不是标签，而是「物理上下文」）**
直觉：逐物体泛化是不可能的（无穷多物体），人类泛化靠的是**材质与可供性**。深度失效指纹恰好给出一张「材质身份证」（透明/镜面/漫反射/吸光/薄壁/可变形），材质决定物理先验（摩擦、刚度、折射、接触模型）。于是跨物体泛化的正确轴不是物体 ID，而是**物体嵌入 z_obj = 几何描述 + 材质后验 + 动力学代理**。故障签名也随之分裂：零力窗 F/T 偏置、时钟同步、传感器漂移这些是**物体无关**的（可免费跨物体迁移）；接触模型误差、刚度/摩擦失配是**物体特化**的（必须针对新物体自适应）。这正是不变风险最小化（IRM）/因果不变性的用武之地。

**灵感 4（跨物体泛化 → 证书必须携带「有效域」，否则是空头支票）**
直觉：第 65 轮的 conformal 覆盖与故障后验都默认「标定物体与部署物体可交换（exchangeable）」。新物体打破可交换性，q_vis 会静默欠覆盖，而证书仍然「看起来有效」。严谨的做法不是假装保证是全局的，而是让每张证书**显式携带有效域**：物体漂移半径 ε、材质后验置信度、不变子空间掩码。域内给出（分布漂移修正后的）保证；域外证书作废、回退保守策略或请求人类。**一张不声明适用范围的保证书没有意义**——这是本轮的方法论立场。

**灵感 5（合流 → DELTA：Depth-Evidence Layered Trust Attribution，深度证据分层可信归因）**
闭环：深度证据场 DEF（缺失/飞点/多峰/背表面 + 空间相关不确定度 + MNAR 缺失模型）→ 材质指纹 MFP → 主动几何证伪 AGF（多视一致性 + NBV）→ 物体嵌入与漂移估计 OEL（z_obj、ε、可信域 T_ε）→ 不变/特化签名分解 ISD → 物体条件归因 OC-FIR → 少样本主动迁移探针 ATP（收缩 ε，受 f_safe 约束）→ 迁移校准证书 TCC（DRO conformal + ACI，携带 ε）→ 域外安全回退 SRT。第 65 轮是「几何-技能-干扰-接触-归因」五层，DELTA 在其外再包一层「**物体/材质上下文 + 有效域**」，并把「看见/看不见」统一为深度证据的两个方向：**有而不对（飞点/多峰/假面）与该有却没有（透明缺失）**。

**灵感 6（GRIP/VISTA 组件的原位升级）**
- **LSF/MEL → LSF-D/MEL-D**：几何先验由深度证据场加权；透明区不生成「实心面」，而生成「折射/背表面」假设。
- **CGG → CGG-D**：几何可证伪的证据从「视觉残差」扩为「深度 MNAR 缺失 + 多视不一致」。
- **VCV → MCV**（材质条件接触验证）：接触斑验证按材质后验选模型（漫反射用光度、透明用折射/背表面、可变形用形变）。
- **VPG → VPG-D**：世界模型残差按材质与有效域分层校准 `q_vis(α|m,ε)`。
- **FIR → OC-FIR**：`p(ρ|H,z_obj)`；不变子空间全局、特化子空间自适应。
- **AFA → ATP**：探针目标从「故障假设熵」改为「物体参数 Fisher 信息 + 材质后验熵」，直接收缩 ε。
- **CSC → CSC-D**：前缀证书在支持集上再加「有效域约束」；ε>ε_max 时 k*=0。
- **RSC-V → RSC-D**：新增 r_obj（物体/材质不确定半径），只对被归因/被漂移的项膨胀。
- **AIC-V → AIC-X**：干扰集加「深度材质伪装/透明贴膜/多机干扰/视角依赖失效」，并加「静默 OOD」（在 z_obj 上看似在域内的新物体）。
- **J_vista → J_delta**：证书增 object_posterior、material_post、z_obj、ε、invariant_mask、validity_domain、depth_evidence_hash。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（DELTA 闭环）**：DELTA = (VISTA, DEF, MFP, AGF, OEL, ISD, OC-FIR, ATP, TCC, CSC-D, RSC-D, SRT, AIC-X, J_delta)。定位：VISTA 的「物体上下文 + 有效域」外层。不变式：**深度证据场、材质推断、几何证伪、漂移估计、迁移校准只发生在语义流/低频线程；实时流只做深度 ROI 采集、区域不确定性查表、前缀执行与早停，零学习写操作。**
- **定义 234（深度证据场 DEF）**：深度观测 D_t 与其缺失掩码 M_t(x)∈{0,1}、逐区域不确定度 u_t(x)、失效标记 f_t(x)∈{飞点, 多峰, 穿透/背表面, 低信噪比, 掠射缺失}。DEF 是一个带空间相关的随机场，协方差由相关长度 ℓ 刻画；**缺失服从 MNAR 模型** P(M=1|m,g,v)（材质 m、局部几何 g、视角 v）。每区域聚合证据 `d_t=[丢失去比率, 飞点密度, 多峰比例, 背表面一致性, 掠射比例]`。
- **定义 235（材质指纹 MFP）**：材质后验 `P(m|d_t) ∝ P(d_t|m)P(m)`，`m∈{diffuse, specular, transparent, absorbing, thin, deformable}`。材质后验不是新真值，而是选择物理先验与接触模型的**上下文变量**；低置信度触发 ATP/SRT。
- **定义 236（主动几何证伪 AGF）**：多视一致性分数 `G=Σ_views ρ_reproj(D_t, view)`；当 `G>τ_G` 时几何假设 h_geo 被证伪。下一最佳视角 `a_view*=argmax_a I(h_geo,m; D_new | D_{1:t})`，受可达性与时间约束。证伪是**无标签**的，不依赖世界模型。
- **定义 237（物体嵌入 OEL）**：`z_obj=[φ_geo, P(m|d), θ_dyn]`，φ_geo 为尺寸/曲率/厚度/长宽比等几何描述，θ_dyn 为质量/刚度/摩擦/质心代理（由轻抬、轻压、侧滑的微力响应估计）。z_obj 是跨物体迁移的坐标。
- **定义 238（物体漂移半径与可信域）**：`ε=D_f(P̂_z^cal ‖ P̂_z^deploy)`（KL/χ² 密度比估计，或 MMD/W1 代理，配 bootstrap 置信上界）；可信域 `T_ε={z: novelty(z)≤τ_ε, H(m|d)≤h_max, ε≤ε_max}`。**ε 与 T_ε 不是诊断结论，而是证书的适用条件。**
- **定义 239（不变/特化签名分解 ISD）**：`ρ=[ρ_inv; ρ_obj]`，线性化 `E[ρ|θ,z]=B_inv θ_inv + B_obj(z) θ_obj`。ρ_inv 覆盖传感器偏置/标定/时钟/同步等**物体无关**故障；ρ_obj 覆盖接触模型/刚度/摩擦/形变等**物体特化**故障。B_inv 由多物体 IRM/不变性惩罚从 K 个物体数据中辨识。
- **定义 240（物体条件归因 OC-FIR）**：`P(H|ρ,z_obj) ∝ p(ρ|H,z_obj)P(H|z_obj)`，似然在「物体 × 故障」元数据上元学习；新物体上只更新特化分量。归因顺序为**不变优先**：先在 ρ_inv 上做全局归因（可迁移），再在 ρ_obj 上做少样本条件归因。材质低置信或 ε 过大时输出 ambiguous 并触发 ATP。
- **定义 241（迁移校准证书 TCC）**：分组/块 conformal（按材质与区域分块）+ 分布漂移修正 + ACI 在线更新。对违反指示 ℓ∈[0,1]，用 Pinsker/χ² 给出 `P_deploy[unsafe] ≤ P_cal[unsafe] + sqrt(2·KL(P_deploy‖P_cal))`；在线用 `α_{t+1}=α_t+γ(α_target−err_t)` 抗漂移。阈值写作 `q_vis(α; m, h, ε)`，随材质、视界与漂移分层。
- **定义 242（主动迁移探针 ATP）**：探针集 `{depth_multiview, lift_soft, press_soft, lateral_slip, tap}`；选择 `a*=argmax_a I(z_obj; y_new | a)/cost_force(a)`，s.t. 预测 `f_n≤f_safe`、形变 `≤ε_strain`、视觉/深度可早停。目标从第 65 轮「分清楚谁坏了」改为「**认清这是什么物体 / 把 ε 收缩到域内**」。
- **定义 243（安全域迁移与回退 SRT）**：若 `ε>ε_max` 或 `max_m P(m|d)<1−δ_m` 或 `novelty>τ_ε`，则 `Valid(J_delta)=False`，切换到物体无关的保守模式（低力、柔顺、深度/视觉 only、k=1），必要时请求人类。SRT 是「证书作废」而非「硬闯」。
- **定义 244（漂移下块级认证前缀 CSC-D）**：`k*(A;post,ε)=max k` s.t. 对支持集内所有 H、可信域 T_ε 内所有 z、前缀所有步，安全裕度≥0 且越界概率≤α_chunk+δ_fi+δ(ε)；若不存在则 k*=0，转 SRT。仍约束 k*≤m（不可逆视界）。
- **定义 245（RSC-D 物体感知定向校准）**：`r=√(r_geo²+r_force²+r_model²+r_obj²)`，r_obj 由 ε 与材质熵导出。与第 65 轮一致，只膨胀被归因的那一项；新物体默认抬升 r_obj，但不无差别膨胀 r_geo/r_force。
- **定义 246（AIC-X 物体/几何对抗认证）**：`ℰ_X=ℰ_V×ℰ_obj`；ℰ_obj 含材质伪装（透明贴纹理膜）、几何欺骗、多机结构光干扰、铰接/大形变、**静默 OOD**（在 z_obj 上看似在域内的新物体）。最坏情形认证；J_dir 增 `depth_calib_ver, object_ood_ver, validity_domain_hash`。
- **定义 247（DELTA 证书 J_delta）**：`J_delta=(J_vista, object_posterior, material_post, z_obj, ε, invariant_mask, validity_domain, depth_evidence_hash, transfer_ver)`。`Valid(J_delta) ⇔ Valid(J_vista) ∧ (ε≤ε_max ∧ 材质可信) ∧ (归因确定 ∨ 已执行 ATP) ∧ k*≥1 ∧ 未在域外使用证书`。
- **定义 248（DELTA 闭环算子）**：语义流 `[LiDAR→LSF-D→USR/MEL-D→DEF→MFP→AGF→OEL→ISD→OC-FIR→ATP/FPE→WCV-D→CSP-V/TSL→CSC-D→TCC→SRT→执行 k*→EV_exec→RSC-D→OLP→DIR→SSB→AIC-X]`；实时流 `[深度 ROI 读→区域不确定度查表→MNAR 缺失标记→阶段判定→CSC-D 早停→前缀派发→J_delta 构建]`。

```python
    a = atp.choose(z, m_post, f_safe, fragile)    # 收缩 ε，而不是硬归因

        execute_gentle_probe(a); post = oc_fir.attribute(*reobserve())

# —— 证书 + 执行 ——
q = tcc.threshold(alpha, m_post, H, eps)          # 分层 conformal + 漂移修正
k_star = csc_d.prefix(A, post, eps, m, alpha_chunk)
if not within_domain(m_post, eps) or k_star == 0:
    K_safe, EV = srt.fallback(x_prime)            # 证书作废，保守回退
else:
    K_safe, EV = execute_prefix(A, k_star, q)
    tcc.aci_update(err=violation(EV))             # 在线覆盖校准
print(build_j_delta(J_vista, m_post, z, eps, domain=T_eps, k_star=k_star))
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（MNAR + 空间相关破坏 i.i.d. conformal）**：若深度缺失率在标定/部署间由 p_cal 变为 p_dep，且只在观测像素上标定，则存在材质驱动场景使实际覆盖从 1−α 降到约 `(1−p_dep)(1−α)`；正相关下有效样本量 `n_eff≈n/(1+(d/ℓ)²)`，覆盖误差随 `sqrt(log(1/δ)/n_eff)` 放大。故必须用**块/分组 conformal + 缺失感知代价（缺失记最大代价）**，并把材质作为校准分层。
- **引理 10（不变/特化的可迁移辨识性）**：`ρ_k=B_inv θ_inv + B_obj(z_k) θ_obj,k + ξ_k`。若 B_inv 列满秩且 `R(B_inv) ∩ ⋂_k R(B_obj(z_k)) = {0}`（物体特化子空间彼此变化、与不变子空间横截），则 θ_inv 由多个物体数据唯一辨识；θ_obj,k 只能由该物体数据或少样本元映射辨识。**「不变」本身就是跨物体可辨识性的来源。**
- **定理 9（物体漂移下的安全）**：设部署物体分布与标定分布满足 `KL(P_deploy‖P_cal)≤ε`，违反指示 ℓ∈[0,1]，则 `P_deploy[unsafe] ≤ P_cal[unsafe] + sqrt(2ε)`；与引理 8 合流得 `P[unsafe] ≤ α_chunk+δ_fi+α_vis+sqrt(2ε)`。ε=0 时退化为第 65 轮。ε>ε_max 时 TCC 不再可用，SRT 接管。**保证第一次带上了「适用范围」这个自变量。**
- **定理 10（少样本漂移收缩）**：标量物体参数、先验方差 σ0²、探针 Fisher 信息 `I_F(a)=s(a)²/σ²`，则 n 次探针后 `σ_n²=1/(σ0^{-2}+Σ_i I_F(a_i))`，`ε_n=√σ_n²` 单调收缩；按「每单位力 Fisher 信息」选探针可在 f_safe 约束下最大化收缩。故 ATP 是「有预算、有安全约束的系统辨识」，而非盲目试探。
- **命题（有效域避免虚假自信 / 减少过度保守）**：第 65 轮对所有新物体用一个全局 q_vis 与全局故障先验；DELTA 在域内用更紧的分层阈值（不牺牲正确几何），域外显式作废（不假装安全）。二者分别对冲「静默欠覆盖」与「无差别保守」。
- **实时性**：DEF 的 ROI 深度采集与区域查表 <0.25ms、MNAR 缺失标记 <0.05ms、阶段判定 <0.05ms、CSC-D 早停 <0.02ms；材质/AGF/OEL/ISD/OC-FIR/TCC 全在语义流，目标实时路径 ≤3ms（A94 契约，需与 LSF 共享深度编码）。

## 2. 形式化定义（完整版）

**定义 233（DELTA 闭环）** DELTA 是 VISTA 的「物体上下文 + 有效域」外层：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 DEF（深度证据场）、MFP（材质指纹）、AGF（主动几何证伪）、OEL（物体嵌入与漂移估计）、ISD（不变/特化分解）、OC-FIR（物体条件归因）、ATP（主动迁移探针）、TCC（迁移校准证书）、SRT（安全域回退），并原位升级 CSC→CSC-D、RSC-V→RSC-D、AIC-V→AIC-X、J_vista→J_delta。不变式：**深度证据场、材质推断、几何证伪、漂移估计、迁移校准只发生在语义流/低频线程；实时路径只做深度 ROI 采集、区域不确定度查表、前缀执行、早停与派发，零学习写操作。**

**定义 234（深度证据场 DEF）** 深度观测 `D_t: Ω→ℝ` 与缺失掩码 `M_t: Ω→{0,1}` 组成证据场。逐区域不确定度 `u_t(x)=u_ale(x)+u_epi(x)`，其中 `u_ale` 来自传感器信噪比/多径，`u_epi` 来自几何假设的不可观测性。空间相关用精度矩阵 `Λ`（相关长度 ℓ）建模，残差 `e_dep` 服从 `N(0,Λ⁻¹)` 而非 i.i.d.。失效标记 `f_t(x)` 区分飞点、多峰、穿透/背表面、低信噪比、掠射缺失。关键：**缺失不是需要插补的空洞，而是服从 MNAR 模型 `P(M=1|m,g,v)` 的观测**；`P(M=1|transparent)≫P(M=1|diffuse)`，故缺失模式携带材质信息。区域证据 `d_t=[丢失去比率, 飞点密度, 多峰比例, 背表面一致性, 掠射比例]`。

**定义 235（材质指纹 MFP）** `P(m|d_t) ∝ P(d_t|m)P(m)`，类别 `m∈{diffuse, specular, transparent, absorbing, thin, deformable}`。材质后验由物理失效模式驱动（例如透明→高缺失+背表面深度；镜面→飞点+多峰；薄壁→稀疏缺失+掠射），可离线用少量标定物体拟合 `P(d|m)`，不依赖海量物体标签。**材质不是分类终点，而是选择物理先验（摩擦/刚度/折射/接触模型）的上下文变量。** 低置信度 `max_m P(m|d)<1−δ_m` 触发 ATP 或 SRT。

**定义 236（主动几何证伪 AGF）** 给定几何假设 h_geo（来自 LSF-D/MEL-D）与多视角深度 `{D_t^{(v)}}`，多视一致性分数 `G=Σ_v ρ_reproj(D_t, view_v)`，`ρ_reproj` 为重投影深度/光度/法向一致性残差。若 `G>τ_G`，h_geo 被证伪。下一最佳视角
`a_view*=argmax_{a∈A_view} I(h_geo,m; D_new | D_{1:t})`，
受可达性、时间与实时预算约束。与第 65 轮 VPG 的差别：证伪是**物理的、无标签的、可解释的**，不依赖学习世界模型，因此对透明/镜面这类「世界模型最容易过拟合错」的场景更稳。

**定义 237（物体嵌入 OEL）** `z_obj=[φ_geo, P(m|d), θ_dyn]`。`φ_geo` 为尺寸/曲率/厚度/长宽比/凸性等几何描述；`P(m|d)` 为材质后验；`θ_dyn` 为质量/刚度/摩擦/质心代理，由轻抬（质量/质心）、轻压（刚度）、侧滑（摩擦）的微力响应估计。z_obj 是跨物体迁移的**低维坐标**：不是物体 ID，而是物理上下文。`novelty(z)` 用 z 空间能量分数或 Mahalanobis 距离度量。

**定义 238（物体漂移半径与可信域）** `ε=D_f(P̂_z^cal ‖ P̂_z^deploy)`，用密度比估计（KL/χ²）、MMD 或 W1 代理，并以 bootstrap 给出置信上界 `ε̂_ucb`。可信域
`T_ε={z: novelty(z)≤τ_ε, H(m|d)≤h_max, ε̂_ucb≤ε_max}`。
**ε 与 T_ε 不是诊断结论，而是证书的适用条件**：J_delta 只在 T_ε 内有效。这直接对冲第 65 轮「默认全局可交换」的隐含假设。

**定义 239（不变/特化签名分解 ISD）** 把阶段签名拆成 `ρ=[ρ_inv;ρ_obj]`，线性化
`E[ρ|θ,z]=B_inv θ_inv + B_obj(z) θ_obj`。
`ρ_inv` 覆盖传感器偏置、零力窗 DC、时钟/同步、通信延迟等**物体无关**故障；`ρ_obj` 覆盖接触模型误差、刚度/摩擦失配、形变模式等**物体特化**故障。`B_inv` 通过多物体不变风险最小化（IRM）辨识：
`min_f Σ_k R_k(f) s.t. ‖∇_{w|w=1}R_k(w∘f)‖² ≤ β ∀k`，
即在 K 个物体上同时最小化风险并惩罚「随物体变化的预测机制」。不变子空间即跨物体稳定的故障方向。

**定义 240（物体条件归因 OC-FIR）** 故障后验
`P(H|ρ,z_obj) ∝ p(ρ|H,z_obj)P(H|z_obj)`，
似然在「物体 × 故障」元数据上元学习（MAML/条件归一化流）。归因顺序为**不变优先**：先在 ρ_inv 上做全局归因（可跨物体迁移），再在 ρ_obj 上做少样本条件归因。材质低置信、ε 过大或后验不集中时输出 ambiguous 并触发 ATP（定义 242），而不是像第 65 轮那样直接选最近假设。

**定义 241（迁移校准证书 TCC）** 校准按材质与空间区域分块（block conformal），并对部署漂移做修正。对违反指示 ℓ∈[0,1]，由 Pinsker/Cauchy–Schwarz
`|E_{P_deploy}ℓ − E_{P_cal}ℓ| ≤ 2·TV(P_deploy,P_cal) ≤ sqrt(2·KL(P_deploy‖P_cal))`，
故 `P_deploy[unsafe] ≤ P_cal[unsafe] + sqrt(2ε)`。在线用自适应 conformal（ACI）`α_{t+1}=α_t+γ(α_target−err_t)` 抗渐进漂移。阈值 `q_vis(α;m,h,ε)` 按材质、视界 h 与漂移分层；缺失区域记最大代价（保守），避免 MNAR 欠覆盖。

**定义 242（主动迁移探针 ATP）** 探针集 `A={depth_multiview, lift_soft, press_soft, lateral_slip, tap}`。选择
`a*=argmax_{a∈A} I(z_obj; y_new | a) / cost_force(a)`，
s.t. 预测 `f_n≤f_safe(φ̂,f̂_vis)`、形变 `≤ε_strain`、支持深度/视觉早停。目标从第 65 轮「最大化故障假设互信息」改为「**最大化物体参数/材质的 Fisher 信息，从而收缩 ε**」——探针的首要目的从「分清楚谁坏了」变成「认清这是什么物体」。易损物体禁用接触探针，只走 depth_multiview。

**定义 243（安全域迁移与回退 SRT）** 若 `ε̂_ucb>ε_max`、`max_m P(m|d)<1−δ_m` 或 `novelty>τ_ε`，则 `Valid(J_delta)=False`，切换物体无关保守模式：低力限、柔顺控制、深度/视觉-only、k=1、禁止主动接触探针，必要时请求人类。SRT 的语义是「**证书作废、诚实降级**」，而不是「带着错误有效域硬闯」。

**定义 244（漂移下块级认证前缀 CSC-D）** `k*(A;post,ε)=max k`，使得对支持集 `supp_δ(post)` 内所有 H、可信域 T_ε 内所有 z、前缀所有步 s≤k，安全裕度≥0，且
`P[∃s≤k: 越界] ≤ α_chunk + δ_fi + α_vis + sqrt(2ε)`。
若不存在则 k*=0，转 SRT。仍约束 `k*≤m`（不可逆视界），保持第 65 轮「长预测、短执行」。

**定义 245（RSC-D 物体感知定向校准）** 维护 `r_geo, r_force, r_model, r_obj` 与视觉信任 `w_vis`。`r_obj` 由 ε 与材质熵导出：`r_obj=clip(c₁ε̂_ucb+c₂H(m|d), 0, r_max)`。融合半径 `r=√(r_geo²+r_force²+r_model²+r_obj²)`。与第 65 轮一致，只膨胀被归因/被漂移的那一项：H_force→r_force↑（零力窗重标定，不动几何）；H_geo→r_geo↑；H_model→r_model↑；新物体→默认抬升 r_obj；H_vis→w_vis↓；H_policy→H↓、k↓。**新物体不等于几何错，也不等于力传感器坏**，故不无差别膨胀。

**定义 246（AIC-X 物体/几何对抗认证）** 干扰集
`ℰ_X=ℰ_V×ℰ_obj`，
ℰ_obj 含：材质伪装（透明贴漫反射膜、镜面贴纹理）、几何欺骗（假面/背表面误导）、多机结构光/ToF 互相干扰、铰接与大形变、**静默 OOD**（在 z_obj 上看似在域内、却改变未建模物理机制的新物体）。ρ_dir 在 ℰ_X 上重算（n_cert 128→160，其中 32 用于物体/材质/静默 OOD）；J_dir 增 `depth_calib_ver, object_ood_ver, validity_domain_hash`。**静默 OOD 下不要求归因正确，只要求 ε 上界与 novelty 能触发 SRT。**

**定义 247（DELTA 证书 J_delta）** `J_delta=(J_vista, object_posterior, material_post, z_obj, ε, invariant_mask, validity_domain, depth_evidence_hash, transfer_ver)`。验证规则：
`Valid(J_delta) ⇔ Valid(J_vista) ∧ (ε̂_ucb≤ε_max ∧ max_m P(m|d)≥1−δ_m) ∧ (归因确定 ∨ 已执行 ATP) ∧ k*≥1 ∧ 未在域外使用证书 ∧ transfer_ver 为当前版本`。
审计链新增：**这张证书对什么物体有效（validity_domain）、为什么认为它在这个域内（ε、material_post）、哪些故障是可迁移的（invariant_mask）、深度证据是否可信（depth_evidence_hash）。**

**定义 248（DELTA 闭环算子）** 见 IP-233 伪代码。语义流：`[LiDAR→LSF-D→USR/MEL-D→DEF→MFP→AGF→OEL→ISD→OC-FIR→ATP/FPE→WCV-D→CSP-V/TSL→CSC-D→TCC→SRT→Shield-Skill→OCB-Skill→执行 k*→EV_exec→RSC-D→OLP→DIR→SSB→AIC-X]`；实时流：`[深度 ROI 读→区域不确定度查表→MNAR 缺失标记→阶段判定→CSC-D 早停→前缀派发→J_delta 构建]`。

## 3. 关键算法伪代码

### IP-224 DEF + IP-225 MFP（深度证据 → 材质）

```python
class DepthEvidenceField:
    """把深度失效建成空间相关场 + MNAR 缺失模型；缺失即证据。"""
    def __init__(self, corr_len=0.03, sigma_sensor=0.004):
        self.ell, self.sig = corr_len, sigma_sensor

    def compute(self, D, valid, views, calib):
        M = (~valid).astype(np.float32)
        flyer = detect_flying_pixels(D, calib)
        multimode = detect_multimodal(D, views)
        back = back_surface_consistency(D, views, calib)
        grazing = grazing_fraction(D, calib)
        u_ale = self.sig ** 2 * (1.0 + M)          # 缺失区域 aleatoric 抬升
        u_epi = geometric_unobservability(D, calib) # 掠射/遮挡/薄壁
        regions = superpixels(D, target=64)
        d = region_aggregate(regions, {
            'dropout': M.mean(), 'flyer': flyer.mean(),
            'multimode': multimode.mean(), 'back': back.mean(),
            'grazing': grazing.mean()})
        return {'D': D, 'M': M, 'u': u_ale + u_epi, 'd': d,
                'regions': regions, 'views': views}


class MaterialFingerprint:
    """P(m|d) 由物理失效模式驱动；低置信度触发 ATP/SRT。"""
    def __init__(self, likelihoods, priors, delta_m=0.2):
        self.lik, self.prior, self.delta_m = likelihoods, priors, delta_m

    def infer(self, d):
        logp = {m: np.log(self.lik[m](d) + 1e-12) + np.log(self.prior[m])
                for m in self.prior}
        z = np.array(list(logp.values())); z -= z.max()
        post = {m: float(np.exp(v) / np.exp(z).sum()) for m, v in logp.items()}
        m_star = max(post, key=post.get)
        return post, m_star, post[m_star] < 1.0 - self.delta_m
```

```python
def shift_radius(z, calib_z, alpha=0.05):
    # 密度比/MMD 估计 + bootstrap 置信上界；返回 ε̂_ucb
    eps_hat = mmd(z[None, :], calib_z)
    boot = [mmd(z[None, :], calib_z[idx]) for idx in bootstrap_idx(len(calib_z))]
    return float(np.quantile(boot, 1 - alpha) + eps_hat)


def invariant_split(rho_stage, B_inv, B_obj, z):
    # 投影到不变子空间与特化子空间（B_inv 由多物体 IRM 离线辨识）
    P_inv = B_inv @ np.linalg.pinv(B_inv)
    rho_inv = P_inv @ rho_stage
    rho_obj = (np.eye(len(rho_stage)) - P_inv) @ rho_stage
    return rho_inv, rho_obj
```

```python
class ObjectConditionedFIR:
    HYP = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis', 'H_policy')
```

### IP-231 TCC + IP-232 CSC-D/SRT（迁移校准 + 认证前缀 + 回退）

```python
class TransferCalibratedCertificate:
    def __init__(self, alpha_target=0.05, gamma=0.02, eps_max=0.1):
        self.alpha_t, self.alpha_target, self.gamma, self.eps_max = \
            alpha_target, alpha_target, gamma, eps_max

    def threshold(self, m_post, h, eps_ucb, region):
        # 按材质/区域分块的 conformal 阈值 + Pinsker 漂移修正
        q = self.block_quantile(m_post, h, region)
        return q + np.sqrt(2.0 * eps_ucb)          # 缺失区域另记最大代价

    def aci_update(self, violated):
        err = float(violated)
        self.alpha_t = self.alpha_t + self.gamma * (self.alpha_target - err)
        return self.alpha_t


def csc_d_prefix(A, post, eps_ucb, m, alpha_chunk, delta=0.05):
    support = {h: p for h, p in post.items() if p >= delta}
    top = sorted(support, key=support.get, reverse=True)[:2]
    k_best = 0
    for k in range(1, min(len(A), m) + 1):
        if not all(safety_margin(A[s], h) >= 0
                   for h in top for s in range(k)):
            break
        if violation_prob(A[:k], top) <= alpha_chunk + np.sqrt(2.0 * eps_ucb):
            k_best = k
        else:
            break
    return k_best
```

### IP-233 DELTA 闭环算子（整合）

```python
def DELTA_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow, views = obs
    # ———— 语义流（10–100Hz）————
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) DEF + MFP：深度证据 → 材质
    E = M.def_field.compute(depth, flow.valid, views, M.depth_calib)
    m_post, m_star, m_uncertain = M.mfp.infer(E['d'])
    # 2) AGF：主动几何证伪
    G, falsified, view_next = active_geom_falsify(E, M.mel.geom_prior)
    if view_next is not None:
        E = M.def_field.compute(acquire_depth(view_next), True, views + [view_next],
                                M.depth_calib)
    # 3) OEL：物体嵌入 + 漂移
    z = M.oel.infer(E, m_post, M.gentle_force_log)
    eps_ucb = shift_radius(z, M.calib_z)
    # 4) ISD + OC-FIR：不变优先归因
    rho_inv, rho_obj = invariant_split(M.residual_log, M.B_inv, M.B_obj, z)
    post, h_star, ambiguous = M.oc_fir.attribute(rho_inv, rho_obj, z)
    # 5) ATP：材质/漂移不确定时收缩 ε
    if m_uncertain or eps_ucb > M.eps_max or ambiguous:
        a = M.atp.choose(z, m_post, M.f_safe, M.object_fragile)
        if a is not None:
            M.execute_gentle_probe(a)
            z = M.oel.infer(E, m_post, M.gentle_force_log)
            eps_ucb = shift_radius(z, M.calib_z)
            post, h_star, ambiguous = M.oc_fir.attribute(
                *invariant_split(M.residual_log, M.B_inv, M.B_obj, z))
    # 6) TCC + CSC-D：证书带有效域
    q = M.tcc.threshold(m_post, M.H, eps_ucb, E['regions'])
    A = M.ach.propose(x_prime, H=M.H)
    k_star = csc_d_prefix(A, post, eps_ucb, M.m, M.alpha_chunk)
    in_domain = (eps_ucb <= M.eps_max) and (not m_uncertain)
    if (not in_domain) or k_star == 0:
        K_safe, EV_exec = srt_fallback(x_prime)
    else:
        K_safe, EV_exec, cert_exec = execute_prefix(A, k_star, q)
        M.tcc.aci_update(violation(EV_exec))
    # 7) 在线更新（纯语义流）
    M.rsc_d.update(EV_exec, W_meas, m_post, eps_ucb)
    M.dir.update(sample_batch_from_history(32))
    rho_dir = M.aic_x.certify(A, x_prime, z, eps_ucb, m_post)
    return M, K_safe, EV_exec, build_j_delta(
        J_vista=M.j_vista, object_posterior=z, material_post=m_post,
        z_obj=z, epsilon=eps_ucb, invariant_mask=M.inv_mask,
        validity_domain={'eps': eps_ucb, 'm_conf': max(m_post.values()),
                         'novelty': novelty(z)},
        depth_evidence_hash=hash(E['d']), transfer_ver=TRANSFER_VERSION)
```

## 4. 推导

**引理 9（MNAR + 空间相关破坏 i.i.d. conformal）** 设标定集缺失率为 `p_cal≈0`、部署集为 `p_dep`，且只在观测像素（M=0）上取 conformal 阈值 `q_obs`，缺失区域按最坏代价 `e=∞` 计。则部署覆盖
`P_deploy[e≤q_obs] = (1−p_dep)·P[e≤q_obs | M=0] + p_dep·0 ≈ (1−p_dep)(1−α)`。
对透明物体 `p_dep` 可从 0.01 跃升到 0.6，覆盖被系统性压低。另一方面，若残差场在区域直径 d 上相关长度 ℓ，则有效独立样本 `n_eff≈n/(1+(d/ℓ)²)`，经验分位数的覆盖误差以 `O(sqrt(log(1/δ)/n_eff))` 放大。故 DEF 必须 (i) 用块/分组 conformal，(ii) 把缺失当 MNAR 证据并记最大代价，(iii) 按材质分层校准 `q_vis(α;m,h,ε)`。∎

**引理 10（不变/特化的可迁移辨识性）** 模型 `ρ_k=B_inv θ_inv + B_obj(z_k) θ_obj,k + ξ_k`，k=1..K。给定 ρ_k 与 z_k，候选 θ_inv 与 θ_inv' 不可区分当且仅当
`B_inv(θ_inv−θ_inv') ∈ ⋂_k R(B_obj(z_k))`。
因此若 B_inv 列满秩且 `R(B_inv) ∩ ⋂_k R(B_obj(z_k)) = {0}`（即物体特化子空间随物体变化、与不变子空间横截），则 θ_inv 唯一可辨识；而 θ_obj,k 只能由第 k 个物体的数据（或元学习映射 `z↦B_obj(z)`）辨识。直觉：**「在多个物体上保持不变」正是把不变故障从物体特化故障中分离出来的识别条件**；K≥2 且特化方向随 z 变化时，交集一般为 {0}。∎

**定理 9（物体漂移下的安全）** 设部署与标定物体分布满足 `KL(P_deploy‖P_cal)≤ε`，安全违反指示 ℓ∈[0,1]。由 Pinsker 不等式 `TV≤sqrt(KL/2)` 与 `|E_Pℓ−E_Qℓ|≤2TV` 得
`P_deploy[unsafe] ≤ P_cal[unsafe] + sqrt(2ε)`。
与引理 8（认证前缀）合流：
`P[unsafe] ≤ α_chunk + δ_fi + α_vis + sqrt(2ε) + α_geo`。
ε=0 时严格退化为第 65 轮。当 `ε̂_ucb>ε_max`，TCC 的前提不成立，证书置为无效并由 SRT 接管——因此**不存在「域外仍声称安全」的路径**。∎

**定理 10（少样本漂移收缩）** 设物体参数为标量 θ、先验 `N(θ0,σ0²)`、第 i 次探针测量 `y_i=θ+ε_i, ε_i∼N(0,σ²/s_i²)`，Fisher 信息 `I_F(a_i)=s_i²/σ²`。贝叶斯后验方差
`σ_n² = 1/(σ0^{-2} + Σ_{i=1}^n I_F(a_i))`，
故漂移半径 `ε_n=√σ_n²` 单调收缩，且 `ε_n→0`（n→∞）。在力预算约束 `Σ cost_force(a_i)≤B` 与 `f≤f_safe` 下，按「每单位力 Fisher 信息」贪心选探针最大化收缩。故 ATP 不是盲目试探，而是**带安全约束与预算的系统辨识**；它与第 65 轮 AFA 同源（互信息），但目标从故障假设变为物体参数。∎

**命题（有效域避免虚假自信并减少过度保守）** 第 65 轮对新物体沿用全局 q_vis 与全局故障先验：要么静默欠覆盖（透明/镜面导致假安全），要么为安全而全局过度保守（在正确几何上降级）。DELTA 在 `T_ε` 内使用按材质/区域分层的更紧阈值（不牺牲正确几何），在 `T_ε` 外显式作废并 SRT（不假装安全）。因此它同时改善「覆盖有效性」与「保守性」两端，代价是必须付出 ε 估计与 ATP 的少量交互预算。∎

## 7. 已知风险

**一句话**：DELTA 用同一套深度证据同时定义「有效域」并「在域内保证安全」，一旦新物体在 z_obj 上投影得很平常、却改变了未建模的物理机制（新形变模式、铰接结构、未收录材质、视角依赖的深度伪装），ε 会被系统性低估，证书就在一个**错误声明的有效域**内成立——系统把「没见过的物体」误当「见过的物体」，比第 65 轮的归因错误更隐蔽，因为它连「自己不知道」都不知道。

**次级风险与缓解**：
1. **有效域自指（循环信任）**：ε 与材质后验都由被认证的深度证据定义；若证据本身系统性偏差，域会被错误地判为「在域内」。缓解：用与深度物理独立的通道（F/T 微力、本体感觉、IMU）交叉校验 z_obj 与 ε；AIC-X 显式注入静默 OOD；设置不可学习的硬 novelty 闸门（如深度失效模式与任何已收录材质的似然比低于阈值即拒）。
2. **材质指纹库不完备**：未收录材质会被最近材质吸收。缓解：开放集识别（拒识阈值 + 证据下界），低置信直接 ATP/SRT；持续扩充材质库并记录未知类。
3. **MNAR 缺失模型误设**：`P(M|m,g,v)` 在极端光照/多机干扰下漂移。缓解：在线重估缺失率、按环境分层校准；缺失记最大代价保证保守方向。
4. **不变/特化分解错误**：IRM 在物体数少或特化方向共线时可能把特化故障误判为不变。缓解：引理 10 的横截条件在线检验（`R(B_inv)∩⋂R(B_obj)` 的奇异值监控），不满足则退回联合归因并标 ambiguous。
5. **漂移估计高维退化**：z_obj 维度高、样本少，MMD/密度比估计方差大。缓解：降维 + 半监督密度比 + bootstrap 上界；ε 只用上界进入证书。
6. **ATP 交互成本与伤害**：新物体必须交互才能收缩 ε，可能与「不碰未知物体」的安全直觉冲突。缓解：优先 depth_multiview 等非接触探针；接触探针受 f_safe/形变双约束；易损物体禁用接触探针。
7. **静默 OOD 不可判**：在 z_obj 上分布内、机制分布外的新物体本质上不可由现有证据识别。缓解：这是本方案的根本边界，只能靠保守回退与人类接管兜底，不能靠更强的归因解决。
8. **实时预算**：DEF ROI 与深度编码逼近 3ms；缓解：ROI 降采样、事件触发、与 LSF 共享深度编码，把 AGF/OEL/TCC 全部留在语义流。
