# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「SLAM」×「异常检测」）

> 第 54 轮已把技能组合与云边协同建立在动作空间剖面 α_S 与鲁棒性谱 ρ 之上。但这些证书都默认了一个从未言明的前提：**位姿与地图是可信且静态的**。本轮把 SLAM 的状态估计与地图异常检测提升为一等公民，提出 **地理信任层（Geo-Trust）**。核心矛盾：H22：ρ、A_cert、γ_ce 都是在某个固定坐标系与地图上签发的，一旦定位漂移或地图被污染，证书会「静默失效」——系统仍以为自己在证书有效域内；H23：异常检测本应是最早的分布漂移信号，但它所依赖的残差恰恰来自被怀疑的同一套 SLAM 状态，容易形成 **循环信任**，把「地图坏了」误判成「传感器噪声」。

## 0. 直觉与动机

**灵感 1（证书的定位前提 → 有效域而非全局有效）**
直觉：证书 C 不是「永远成立」，而是「在某个位姿-地图邻域内成立」。SLAM 给出 `x_t ~ N(μ_t, Σ_t)` 与地图 M_t，证书应携带一个 **有效域 `V(C) ⊆ SE(3)×M`**。运行时先判断 `x_t ∈ V(C)`，再谈 ρ、A_cert 是否成立。这把「证书有效性」从布尔值升级为 **带边界的区域**，也让定位漂移第一次成为可被证书系统感知的一等失效源，而不是被悄悄吸收进仿真误差里。

**灵感 2（异常 = 证书有效域的越界信号）**
直觉：异常检测不必外挂一个孤立模块，它可以被重新表述为「当前状态是否正在离开所有相关证书的有效域」。扫描匹配残差、回环残差、动态物体占比、地图新颖度共同构成残差向量 r_t；异常分数 s_t 高，等价于「有效域边界正在逼近」。于是异常检测与证书体系共享同一套语义，而不是事后拼接。

**灵感 3（瞬态 vs 持久 → 持续性判别）**
直觉：路人走过、门开合是 **瞬态** 异常，不应吊销证书；kidnapping、地图被搬动、回环错误是 **持久** 异常，必须吊销。仅靠单帧阈值必然在高动态场景误报爆炸。因此引入时间持续性 `p_t` + 空间一致性 `coh_t` 双重判据，把「异常分数」升级为「异常事件 E_t」。

**灵感 4（异常触发的证书吊销/降级 + 安全回退）**
直觉：一旦确认持久异常且其覆盖区域 R 与证书有效域相交，就触发 **吊销与降级**：full → local → conservative → stop。关键是吊销必须沿云边反向信道传播，让云端规划不再签发落在污染区域的证书。这把第 54 轮的 Explain 回传升级为 **吊销回传**，也把「负迁移」从动作空间扩展到地图空间。

**灵感 5（主动 SLAM 修复 → 为证书而探索）**
直觉：与其被动等待定位收敛，不如让机器人 **为恢复证书有效性而主动探索**。把下一最佳视角（NBV）的目标从「降低地图熵」改为「最大化证书有效域体积的期望恢复」，并设动作预算，防止异常追逐导致原地打转。于是探索本身成为一种技能，接入第 54 轮的动作空间与技能组合图。

**灵感 6（地理信任金字塔层）**
直觉：在鲁棒性层 𝕃 与动作层 𝔸 之下再加一层 **𝔾**：`𝔾_0` 传感器原始一致性，`𝔾_1` 里程计/IMU 死推，`𝔾_2` 局部地图，`𝔾_3` 全局位姿图。跨层证书必须同时携带 `(ρ, A_cert, V, anomaly_evidence)`，形成 **四元联合证书**，任一层失效都能被上层定位。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（SLAM 可信状态与可信域）**
`S_t = (x_t, Σ_t, M_t, G_t)`，其中 `x_t ∈ SE(3)` 为位姿估计，`Σ_t` 为其协方差，`M_t` 为局部占据/新颖度地图，`G_t` 为全局位姿图。定义 **可信域** `V_geo(Σ_max, ε_M) = {(x,M) : Σ_t ⪯ Σ_max ∧ D(M_t, M_ref) ≤ ε_M}`，`D` 为地图差异度（占据栅格 JS 散度 + 特征描述子距离）。`⪯` 为半正定序。

**定义 122（定位条件化证书 LCC）**
证书 `C|V = (C, V(C), φ)`，`V(C) ⊆ V_geo` 为证书有效域，`φ: SE(3) → [0,1]` 为有效度。**条件可部署** 当且仅当
```
dom_J(T)=in ∧ x_t ∈ V(C) ∧ m_V(x_t) ≥ m_min,   m_V(x) = dist(x, ∂V(C))
```
注意：ρ 与 A_cert 只在 `x_t ∈ V(C)` 内被赋予语义，域外它们的数值「无定义」而非「成立」。

**定义 123（地图异常残差与分数）**
残差向量 `r_t = (r_scan, r_loop, r_dyn, r_novel)`：扫描匹配残差、回环残差、动态物体占比、地图新颖度。异常分数 `s_t = σ(⟨w, r_t⟩ + b) ∈ [0,1]`；单帧异常为 `s_t > θ_anom`。

**定义 124（异常事件：持续性与空间一致性）**
时间持续性 `p_t = (1/κ) Σ_{i=0}^{κ-1} 1[s_{t-i} > θ_anom] ≥ η`；空间一致性 `coh_t = |R_t ∩ R_{t-1}| / |R_t ∪ R_{t-1}| ≥ ζ`，`R_t` 为高残差栅格集合。**异常事件** `E_t = 1[p_t ≥ η ∧ coh_t ≥ ζ ∧ |R_t| ≥ ν]`。瞬态噪声被持续性滤掉，真实污染被空间一致性确认。

**定义 125（证书吊销与降级算子）**
吊销算子 `revoke(C|V, R, E_t)` 返回信任等级 `ℓ ∈ {full, local, conservative, stop}`。规则：若 `R ∩ V(C) ≠ ∅ ∧ E_t=1` 则降级；降级沿依赖图传递（若 C' 依赖 C 的坐标系，则 C' 至少降一级）。定义 **信任格 `(ℓ, ≤)`**，要求运行时 **单调不升**，只有独立证据与新证书才能提升。

**定义 126（证书修复型主动 SLAM 与四元联合证书）**
动作 a 的证书信息增益
```
IG_C(a) = E_o[ vol(V_{t+1}(a) ∩ dom(C_total)) - vol(V_t ∩ dom(C_total)) ]
```
选择 `a* = argmax_a IG_C(a) - λ_cost(a)`，约束 `Σ cost ≤ B_active`，终止条件 `IG_C < ε_ig`。**四元联合证书** `Q = (ρ, A_cert, V(C), E_t, γ_ce, evidence)`，部署条件：
```
x_t ∈ V(C) ∧ E_t=0 ∧ δ_a ≤ Θ_a ∧ min_d ρ(d) ≥ ρ_min
```

## 2. 关键算法 伪代码

### IP-121 LCC（Localization-Conditioned Certificate）

```python
def condition_certificate(cert, S_t, sigma_max, eps_M, m_min):
    if not psd_leq(S_t.Sigma, sigma_max):
        return ('out', 'pose_drift', trace(S_t.Sigma))
    d = map_distance(S_t.M, cert.map_ref)
    if d > eps_M:
        return ('out', 'map_drift', d)
    m = margin(S_t.x, cert.V)
    if m < m_min:
        return ('out', 'near_boundary', m)
    return ('in', m, cert)          # 证书语义仅在域内有效
```

### IP-122 MAD（Map Anomaly Detection）

```python
def map_anomaly(S_t, scan, ref_map, theta, eta, zeta, nu, kappa):
    r = residuals(S_t, scan, ref_map)       # scan / loop / dyn / novel
    s = sigmoid(dot(w, r) + b)
    hist.append(s); hist[:] = hist[-kappa:]
    p = mean([1.0 if v > theta else 0.0 for v in hist])
    R = anomaly_cells(r, S_t)
    coh = jaccard(R, R_prev) if R_prev else 0.0
    R_prev = R
    active = (p >= eta) and (coh >= zeta) and (len(R) >= nu)
    return AnomalyEvent(active, s, R, p, coh)
```

### IP-123 CRD（Certificate Revocation & Downgrade）

```python
def revoke_cascade(certs, event, dep_graph, cloud_channel):
    impacted = [c for c in certs if intersects(event.R, c.V)]
    for c in impacted:
        c.level = downgrade(c.level)         # full→local→conservative→stop
    frontier = list(impacted)
    while frontier:                          # 沿依赖图单调传播，不回升
        c = frontier.pop()
        for c2 in dep_graph.successors(c):
            if c2.level < c.level:
                c2.level = downgrade(c2.level)
                frontier.append(c2)
    cloud_channel.send(RevocationMsg(impacted, event))
    return impacted
```

### IP-124 ASR（Active SLAM Repair / NBV）

```python
def repair_action(belief, certs, candidates, B_active, eps_ig):
    spent, best = 0.0, None
    while spent < B_active:
        scored = [(expected_validity_gain(predict_belief(belief, a), certs)
                   - lambda_cost * action_cost(a), a) for a in candidates]
        gain, a = max(scored)
        if gain < eps_ig:
            break
        best = a
        belief = predict_belief(belief, a)
        spent += action_cost(a)
    return best
```

### IP-125 GTC（Geo-Trust Joint Certificate）

```python
def geo_trust_certify(C, S_t, event, rho_min, delta_a_budget, Theta_a):
    cond = condition_certificate(C, S_t, sigma_max, eps_M, m_min)
    if cond[0] == 'out':
        return ('reject', cond)
    if event.active:
        return ('reject', 'anomaly_active', event.R)
    if min(C.rho.values()) < rho_min:
        return ('reject', 'robustness_fail', C.rho)
    if C.delta_a > Theta_a:
        return ('reject', 'alignment_fail', C.delta_a)
    return ('ok', QuadCert(C.rho, C.A_cert, C.V, event.evidence, C.gamma_ce))
```

### IP-126 ACG（Anomaly-aware Composition Gate）

```python
def composition_allowed(path, S_traj, certs):
    for skill, Vreq in path:                 # 组合路径逐位姿校验有效域
        for x in S_traj:
            if not inside(x, Vreq):
                return ('reject', skill, x)
    return ('ok',)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| LCC | O(|Σ|³ + |M|) | O(|M|) | 协方差 PSD 序、域边界可计算 |
| MAD | O(|M| + κ) | O(|M| + κ) | 残差独立、持续性判别 |
| CRD | O(|C| + |E_dep|) | O(|C|) | 吊销传播闭包、等级单调不升 |
| ASR | O(B_active·|A_cand|·|C|) | O(|M|) | 增益估计无偏、预算终止 |
| GTC | O(|C|·|Σ|³) | O(|C|) | 四元条件合取、证据非空 |
| ACG | O(|path|·|S_traj|) | O(|path|) | 有效域逐点覆盖 |

**正确性定理（Geo-Trust Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 异常检测在持久地图污染上的漏检率 ≤ β_anom；**(A30)** 吊销沿云边传播延迟 ≤ τ_rev；**(A31)** 存在 **独立锚**（IMU/轮速/外部路标）使 `r_t` 在 SLAM 自身失效时仍可判别，且主动修复在 L 步内使 `Σ_t ⪯ Σ_max`。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - β_anom - P(τ_rev>τ_rev^max)
```
**关键**：A31 是打断「循环信任」的唯一支点。若删除独立锚，异常检测与 SLAM 共享同一失效模式，`β_anom` 不再可界，定理退化为空洞；此即本轮所有形式化工作的边界。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 异常漏检导致污染地图被签发 | 高 | 独立锚 + 多模态交叉校验 + 红队伪造 |
| 循环信任 / 相关性失效 | 高 | 死推/外部路标解耦 + 残差独立性审计 |
| 误报引发过度吊销与停滞 | 高 | 持续性+滞后阈值 + 成本感知降级 |
| 主动 SLAM 异常追逐 livelock | 中 | 增益预算 B_active + 终止条件 + 回滚 |
| 云边地图版本漂移 | 中 | 版本化地图 + 差异证书 + 单调合并 |

## 6. 本轮最大风险

**一句话**：地理信任层把所有证书都条件化在 SLAM 状态上，而异常检测器又消费同一套 SLAM 残差，于是 **地图污染与检测器失明是相关性失效**；若无独立锚打断这一循环，系统会对一张坏地图签发「有效」证书——这种失败是静默的、系统级的，比完全没有证书更危险。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GeoTrust（LCC×MAD×CRD×ASR×GTC×ACG）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之下补上 **地理信任基座**，解决「所有证书都默认位姿与地图可信」这一隐性前提：
> - **LCC（Localization-Conditioned Certificate）**：证书携带有效域 `V(C)`，把全局有效降级为定位条件有效；
> - **MAD（Map Anomaly Detection）**：残差 → 异常分数 → 异常事件，区分瞬态与持久污染；
> - **CRD（Certificate Revocation & Downgrade）**：异常触发吊销，沿依赖图单调降级并回传云端；
> - **ASR（Active SLAM Repair）**：以证书信息增益驱动主动探索，为恢复有效性而行动；
> - **GTC（Geo-Trust Certificate）**：四元联合证书 `Q=(ρ,A_cert,V,E)`，统一域内判定；
> - **ACG（Anomaly-aware Composition Gate）**：技能组合路径逐位姿校验有效域。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-117/118/120 以纳入 `V(C)` 与异常证据。

```python
        return ('reject', 'robustness_fail', C.rho)
    if C.delta_a > Theta_a:
        return ('reject', 'alignment_fail', C.delta_a)
    return ('ok', QuadCert(C.rho, C.A_cert, C.V, event.evidence, C.gamma_ce))
```

**正确性定理（Geo-Trust Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 异常检测在持久地图污染上漏检率 ≤ β_anom；**(A30)** 吊销传播延迟 ≤ τ_rev；**(A31)** 存在独立锚（IMU/轮速/外部路标）使 `r_t` 在 SLAM 失效时仍可判别，主动修复在 L 步内使 `Σ_t ⪯ Σ_max`。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - β_anom - P(τ_rev>τ_rev^max)
```
关键：**A31 不可省**。抽掉独立锚后，异常检测与 SLAM 共享失效模式，`β_anom` 无界，定理退化为空洞；这也是 v32 相对 v31 新增的最强外部假设。

## 5. 本轮最大风险

**一句话**：地理信任层把所有证书都条件化在 SLAM 状态上，而异常检测器又消费同一套 SLAM 残差，于是 **地图污染与检测器失明是相关性失效**；若无独立锚打断这一循环，系统会对一张坏地图签发「有效」证书——这种失败是静默的、系统级的，比完全没有证书更危险。
