# 第 1 轮（灵感循环第 1 轮；基线：第 7 轮 MetricVoiceGauge-OTL-GC-ER，定义 493–525，引理 73–76，实验 E513–E525）

> 本轮灵感：「数据增强」×「工具调用」
> 本轮纪律：**覆盖可信 + 调用可证**。数据增强把「一个部署点」扩成「一个语义邻域」，工具调用把「一条语音指令」扩成「一段可检查的程序」；二者交汇成一条硬要求：*只有能在增强邻域上被证书验证的工具程序才允许执行，否则沿降级格退回 v7*。

## 0. 直觉与动机

### 灵感 1：数据增强不是训练技巧，而是「测试分布的生成器」

直觉：前七轮的所有判据——OTL 的阈值、GCT 的抓取几何、ER 的情感权重——都只在**当前观测到的那一个点**上被检验。但机器人在部署时遇到的是**邻域**：同一句「把杯子拿起来」会以不同口音、语速、背景噪声出现；同一个杯子会以不同位姿、尺寸、光照出现。只用单点数据评估，等于用一条样本估计整个分布。

数据增强的真正价值不是「多喂点数据」，而是**把评估对象从点变成邻域**：如果一条指令在它的保义增强邻域内都能被正确执行，我们才敢说它「被覆盖」了。这自然导出一个可审计的对象——**覆盖证书**：增强算子集、增强强度 ε、保义率 ρ_pres、有效语义覆盖数 N_eff、以及该邻域上的风险上界 R_ub。证书把「我觉得它泛化」变成「它在多大邻域内、以多大概率、保持语义不变地泛化」。

关键区分：**保义增强 A⁺**（改写口音/光照/位姿但任务语义不变）与**变义增强 A⁻**（把「抓取」改成「放下」、把目标物体换掉）。A⁺ 用来**发证书**，A⁻ 用来**做负测试与退化触发**。两者混在一起，覆盖率会被语义漂移灌水，证书就失去意义。

### 灵感 2：工具调用不是「让模型多调几个 API」，而是「把指令编译成有契约的程序」

直觉：第 7 轮的 VoiceCommandTyping 把一条语音映射成**一个**类型化意图 ι。但真实指令是复合的：「先到桌边，找到红杯子，抓起来，放到托盘上」。这不是一条命令，而是一段**程序**：导航工具 → 感知查询工具 → 抓取规划工具 → 控制器工具。

工具调用的价值在于：每个工具都有**类型签名 + 前置/后置条件 + 安全不变式 + 延迟/资源预算 + 失败类型**。于是「机器人是否理解了指令」被替换成一个更可判定的问题：*是否存在一段类型正确、前置可满足、后置与安全不变式可证的程序 P 实现它？* 这比「意图分类准确率」更接近系统真正需要的东西。

但工具调用有一个致命弱点：**幻觉调用**。模型可能编造不存在的工具、传错参数、跳过前置检查。解决办法不是「让模型更小心」，而是把注册表、schema 校验、前置条件检查和后置验证放在**编译器与运行时**，而不是放在模型的自觉里。

### 交汇：增强邻域上的工具契约（Augmented Tool Contract）

两个灵感不是拼接，而是互为因果：

- **工具调用是数据增强的执行器**：增强不是凭空采样，而是调用仿真器/渲染器/语音重合成器这些**工具**来生成 `x' = a(x)`；工具契约保证增强本身是保义的（例如渲染器只改光照，不改物体身份）。
- **数据增强是工具调用的验证器**：一段程序 P 在当前点执行成功不算数，必须在 `B_ε(x)` 上仍然满足后置条件与安全不变式，才被接受；失败的增强样本就是一个**反例见证**，驱动程序修复或降级。

于是本轮的核心算法是 **ATCL（Augmentation-calibrated Typed Tool-Call Layer）**：先编译，再在增强邻域上验证，失败则用见证修复，修复预算耗尽则沿降级格退回 v7。它把「数据增强」从训练阶段前移到**准入控制**，把「工具调用」从提示词工程抬到**契约验证**。

一句话概括本轮判断：v7 解决的是「在看得见的状态下不违反约束」，ATCL 要解决的是「在看不见的邻域里也不违反约束」。

## 1. 研究问题

- **Q1（保义增强与覆盖）**：如何定义保义增强算子、语义等价与覆盖证书，使「邻域经验风险 + 半径项」能给部署风险一个可计算上界？当增强算子集不覆盖真实偏移时，如何检测而不是假装有保证？
- **Q2（指令→工具程序）**：如何把复合语音指令编译成类型正确的工具程序，使工具/参数不幻觉、前置条件可满足、延迟/资源不超预算？
- **Q3（增强邻域验证）**：如何在有限算力与 50Hz 主路径约束下，验证程序在 ε-邻域上的后置条件与安全不变式，并把失败见证转化为修复或降级？
- **Q4（增强校准）**：如何用增强 rollout 校准 OTL 阈值 τ 与 ER 权重 w，使最坏情况违背下降，同时不把系统过拟合到增强分布？

## 2. 设计原则（P10–P13，继承 P7–P9）

**P10 保义增强分层（Label-Preserving Augmentation, LPA）**
`A = A⁺ ⊔ A⁻`；A⁺ 只做语义保持变换，A⁻ 专门制造语义漂移与危险近邻；两者使用不同的证书与触发逻辑。保义与否由独立的等价判定器给出，而不是由生成增强的模型自证。

**P11 覆盖证书（Coverage Certificate, CovCert）**
证书必须是可审计五元组 `(A⁺_ε, ρ_pres, N_eff, m, R_ub)`：保义率、去重后的有效语义覆盖、样本数、风险上界。缺任一项则证书无效；证书必须显式携带「相对于 A⁺」的限定词。

**P12 类型化工具契约（Typed Tool Contract, TTC）**
工具只能从注册表取；每次调用必须通过 schema、前置条件、资源与延迟预算；组合必须满足 `Eff_i ⇒ Pre_{i+1}`。模型只负责**提议**程序，不负责**批准**程序。

**P13 见证驱动修复与降级格（Witness-driven Repair & Degradation Lattice, WRDL）**
验证失败产生反例 `x_w`；修复算子有预算 K；预算耗尽按 `P → P_safe → P₀ → ι₀` 逐级降级，每级都保持 Safety。失败不是 crash，而是一次有界、可证明保安全的降级。

## 3. 与基线接口（如何退化）

- 增强模块缺失 ⇒ 退化为单点 SoftCert（v7），证书不再声称邻域保证；
- 工具调用模块缺失 ⇒ 复合指令退化为 v7 的单意图 VoiceCommandTyping（GCT/OTL/ER 保留）；
- 验证器缺失 ⇒ 程序先执行、由 v7 运行时监控兜底，证书降级为「未验证」；
- 校准器缺失 ⇒ τ、w 使用 v7 的在线/风险公式；
- 所有退化都不放松 M₀，都不改变 50Hz 主路径 WCET。

## 4. 预期贡献

1. 把数据增强形式化为**覆盖算子**，给出 CovCert 与「邻域经验风险 + 半径」泛化上界；
2. 把语音指令提升为**有契约的工具程序**，给出组合健全性与幻觉调用的静态拦截；
3. **见证驱动修复 + 降级格**：验证失败不是崩溃，而是有预算、可证明保安全的降级；
4. 用增强 rollout 做**鲁棒校准**，把 OTL/ER 从平均情况推向最坏情况；
5. 明确刻画**增强间隙**（augmentation gap）这一不可消除的负结果，并给出检测手段；
6. 实验 E526–E545 覆盖覆盖证书、工具组合、修复、校准与 WCET。

## 5. 本轮最大风险

**一句话**：如果增强算子集的方向与真实部署偏移不一致，覆盖证书会在自造邻域上「完美成立」却在真实长尾上失效，而工具程序会把这种虚假保证沿组合链放大成更长的错误。

# 第 1 轮产物 · 创新点清单 v8：**MetricVoiceGauge-ATCL**（Augmentation-calibrated Typed Tool-Call Layer）

> 背景：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–525；引理 73–76；实验 E513–E525）。
> 本轮灵感：「数据增强」×「工具调用」
> **继承纪律**：v7 的全部不变式（CVC 闭环、SpatialCert、RT-CVC 任务模型、FaultCert 闭环、PrimitiveGraph 接地、严格退化链、50Hz WCET）保留。ATCL 是**准入层**，不改变已有控制回路，只在「指令 → 程序 → 执行」之间插入编译、验证、修复与降级。

- `AugmentationOperatorSet` / `CoverageCertificateBuilder` 失效 ⇒ 单点 SoftCert，等价于 v7；

**定义 526（场景与语义等价）**
```
x = (ℓ, o, e) ∈ X = L × O × E
Eq_X(x, x') ∈ {0,1}          # 任务语义层等价，不是字节级相等
dist_X: X × X → R_{≥0}       # 满足三角不等式（实现上用加权 L1/L2）
```

**定义 527（保义增强算子与强度）**
```
a = (op, u, ε),  op ∈ 𝒪,  u ~ U_op,  ε ∈ [0, ε_max]
x' = a(x),  pres_a(x) = Eq_X(x, a(x))
A⁺_ε(x) = {a : pres_a(x) = 1, intensity(a) ≤ ε}
A⁻_ε(x) = {a : pres_a(x) = 0, intensity(a) ≤ ε}
```
`intensity` 是算子内部的归一化强度（口音重、噪声 SNR、位姿扰动半径……）。保义判定必须由与增强生成器**独立**的等价判定器给出，避免「自己生成、自己批准」。

**定义 528（增强邻域与增强分布）**
```
B_ε(x)    = {a(x) : a ∈ A⁺_ε(x)}
D_ε(x)    = Unif(B_ε(x))
D̂_ε^m(x)  = {a_j(x)}_{j=1}^m,  a_j ~ Unif(A⁺_ε)
```

**定义 529（覆盖证书）**
```
CovCert(x) = (A⁺_ε, ρ_pres, N_eff, m, R_ub)
ρ_pres = (1/m) · Σ_{j=1}^m pres_{a_j}(x)
N_eff  = |{ cell(a_j(x)) : j = 1..m }|      # cell 为 Eq_X 商空间中的语义格
R_ub   = R̂_{D̂_ε} + L·ε + sqrt((log N(ε) + log(1/δ)) / (2m))
```
证书有效当且仅当 `ρ_pres ≥ 1−δ_p`、`N_eff ≥ N_min`、`R_ub ≤ R_max`，且 `A⁺_ε` 通过覆盖审计（是部署支撑的 ε-网）。

**定义 530（工具契约）**
```
κ_t = (In_t, Out_t, Pre_t, Eff_t, Safety_t, Lat_t, Res_t, Fail_t)
```
`Pre/Eff/Safety` 是状态谓词；`Fail_t` 是声明式失败类型集合。工具只能在 `Pre_t` 成立时调用；正常返回必须满足 `Eff_t`；任何返回路径都必须保持 `Safety_t`。

**定义 531（工具程序与良型）**
```
P = t₁; t₂; …; tₙ
⊢ P : (Pre₁, Effₙ)  ⇔  Out_{t_i} ⊑ In_{t_{i+1}}          (∀ i < n)
                     ∧  (Eff_{t_i} ⇒ Pre_{t_{i+1}})       (∀ i < n)
                     ∧  Σ_i Lat_{t_i} ≤ Lat_budget
                     ∧  Σ_i Res_{t_i} ≤ Res_budget
```

**定义 532（程序执行语义）**
```
⟦P⟧(s) ⊆ (S × Fail) ∪ S_term
```
执行是关系而非函数：感知与抓取存在非确定性；结果要么是满足后置条件的终止状态，要么是某个声明式失败。

**定义 533（增强邻域的鲁棒满足）**
```
P ⊨_ε^δ (Pre, Post, Safety) at x
⇔ Pr_{a ~ Unif(A⁺_ε)}[
     ∀ s' ∈ ⟦P⟧(s(a(x))) :
        (s' ∈ S_term ⇒ s' ⊨ Post ∧ Safety)
        ∧ (s' = (s_f, f) ⇒ s_f ⊨ Safety)
   ] ≥ 1 − δ
```

**定义 534（鲁棒半径）**
```
rad(P,x)  = sup{ ε ∈ [0, ε_max] : P ⊨_ε^δ (Pre, Post, Safety) at x }
rad̂(P,x) = 网格二分 + Clopper–Pearson 单侧下界的保守估计
```

**定义 535（指令→程序编译）**
```
compile(ℓ, s) = argmin_{P ∈ 𝒫_reg} Cost(P)
  s.t.  ⊢ P : (Pre, Post)
        ∧ s ⊨ Pre
        ∧ rad̂(P, x) ≥ ε_req
        ∧ P 中所有工具与参数均接地到注册表与当前观测
```
不存在满足约束的 P 时返回 `P₀`（v7 的单意图默认程序）。

**定义 536（见证驱动修复）**
```
Repair(P, x_w) ∈ {
    Guard(P, φ),              # 为失败分支补前置守卫
    Replace(t_i, t'_i),       # 换更保守/更强感知的同型工具
    Insert(perceive|verify),  # 插入一次确认或复核
    Tighten(param),           # 收紧速度/力/抓取宽度
    Split(P)                  # 分解为可分别验证的子程序
}
```
修复目标：在预算 K 内最大化 `Δrad̂ / Δlatency`；每一步都必须保持 `⊢` 与 Safety。

**定义 537（降级程序格）**
```
P  ⟶  P_safe  ⟶  P₀  ⟶  ι₀
```
- `P_safe`：删除可选工具，只保留带 Safety 证明的核心前缀；
- `P₀`：单工具默认程序；
- `ι₀`：v7 的默认单意图。
每一级都满足 Safety，且 `P₀/ι₀` 与 v7 语义等价。

**定义 538（增强 rollout 与鲁棒校准）**
```
D_aug = {(x_j, a_j, P_j, outcome_j)}_{j=1}^m
(τ*, w*) = argmin_{τ ∈ T, w ∈ Δ} [ max_{x' ∈ D_aug} V(x'; τ, w)
                                  + λ‖τ − τ₀‖² + μ‖w − w₀‖² ]
```
`V` 是软层级违背量；`T` 是 clip 后的阈值盒；`Δ` 是权重单纯形。

**定义 539（覆盖-泛化证书）**
```
GenCert = (R̂_{D̂_ε}, L·ε, sqrt((log N(ε) + log(1/δ)) / (2m)), ℋ)
```
它把增强样本上的经验风险转成部署风险上界，但**只相对于 `A⁺_ε` 张成的邻域**成立。

**定义 540（ATCL 闭环签名）**
```
Φ_ATCL = (⊢P, CovCert, ⊨_ε^δ, rad̂, D_aug, (τ*, w*))
Φ_v7   = (ι, SoftCert, 单点监控, τ(t), w(s))
```
`Φ_ATCL` 的每一项都可在缺失时替换为 `Φ_v7` 的对应项。

## 2. 关键引理与命题

**引理 77（覆盖-泛化上界）** 设部署分布 `D` 的支撑被 `A⁺_ε(x)` 以 ε-网覆盖，覆盖数为 `N(ε)`；违背指示函数 `f` 关于 `dist_X` 是 L-Lipschitz。对 m 个独立增强样本，以概率至少 `1−δ`：
```
R_D(f) ≤ R̂_{D̂_ε}(f) + L·ε + sqrt((log N(ε) + log(1/δ)) / (2m))
```
证明要点：ε-网把每个部署点到某个增强点的距离压到 ε，Lipschitz 给出函数差 ≤ Lε；剩余项是对覆盖数做 Hoeffding 联合界。该引理是**条件性**的：前提是 `A⁺_ε` 真覆盖 `D`，否则只有相对保证（命题 1）。

**引理 78（工具组合健全性）** 若每个 `t_i` 满足 `κ_{t_i}`、`⊢ P` 成立且初始 `s ⊨ Pre₁`，则 P 的每次正常终止都满足 `Effₙ`，且所有终止路径保持 Safety。
证明：对 i 归纳。`Eff_i ⇒ Pre_{i+1}` 保证下一步可调用；Safety 逐步保持；延迟与资源预算由良型合取项给出。

**引理 79（鲁棒满足的单调性与见证可信性）** 若 `ε₁ ≤ ε₂`，则 `P ⊨_{ε₂}^δ ⇒ P ⊨_{ε₁}^δ`。若在样本 `a_j` 上观察到违背，则 `a_j(x)` 是一个真实反例：它证伪「该点满足」，但不证伪「存在某程序满足」。
证明：`B_ε` 随 ε 单调；执行是关系，样本违背意味着存在一条不满足 Post 或 Safety 的路径。

**引理 80（降级格安全性）** 沿 `P → P_safe → P₀ → ι₀` 的每一级都保持 Safety，且 `ι₀` 与 v7 等价。
证明：`P_safe` 只删除可选后缀，核心前缀的 Safety 证明不受影响；`P₀` 的 Safety 由单工具契约给出；`ι₀` 由 v7 的退化链保证。因此验证失败最多损失性能，不损失 M₀。

**引理 81（鲁棒校准的退化一致性）** 当 `A⁺_ε = {id}` 且 `μ → ∞` 时，定义 538 退化为 v7 的经验校准；当 `β = 0` 时 `w*` 退化为风险权重。
证明：目标函数逐项对应；增强样本退化为单点；`μ → ∞` 把 w 钉在 `w₀`；`β = 0` 时情感项消失。故增强/情感模块缺失时 ATCL 与 v7 一致。

**引理 82（运行时预算）** 编译与邻域验证在离线/异步阶段完成，在线主路径只做 `O(|P|)` 的类型与前置检查以及一次 `rad̂` 查表；在线增量 ≤ 1.5ms，指令总延迟 ≤ 40ms，50Hz WCET 不变。
证明：在线不做增强采样；m 次增强与修复预算 K 都在准入阶段；查表 O(1)。

**命题 1（增强间隙不可消除）** 对任意有限算子集 `A⁺` 与任意 ε，存在部署分布 D，使 D 在 `A⁺` 的 ε-邻域之外有质量，从而 CovCert 无绝对保证。
构造：`A⁺` 只改光照，D 把物体质量改到超出抓取力矩上限；两者在 `dist_X` 下距离大于 ε。因此证书必须显式携带「相对于 `A⁺`」的限定词，并在线做新语义格审计。

```python
from dataclasses import dataclass
from math import log, sqrt
from typing import Callable


@dataclass(frozen=True)
class ToolContract:
    name: str
    in_schema: dict
    out_schema: dict
    pre: Callable          # State -> bool
    eff: Callable          # State -> bool
    safety: Callable       # State -> bool
    lat_ms: float
    res: float
    fails: tuple


class ToolRegistry:
    """IP-352：只允许注册过的工具与参数进入程序。"""

    def __init__(self):
        self._tools = {}

    def register(self, c: ToolContract):
        self._tools[c.name] = c

    def get(self, name):
        return self._tools.get(name)          # 未注册 -> None（拦截幻觉调用）

    def names(self):
        return tuple(self._tools)

    def cost(self, program):
        return sum(self._tools[t].lat_ms + self._tools[t].res for t in program)

    def typecheck(self, program, s):
        """定义 531：类型链 + 前置可满足 + 预算。"""
        if not program:
            return False
        prev = None
        lat = res = 0.0
        for name in program:
            t = self.get(name)
            if t is None:
                return False
            if prev is not None:
                if not schema_sub(prev.out_schema, t.in_schema):
                    return False
                if not implies(prev.eff, t.pre):
                    return False
            lat += t.lat_ms
            res += t.res
            prev = t
        return (satisfies(s, self.get(program[0]).pre)
                and lat <= LAT_BUDGET and res <= RES_BUDGET)


class AugmentationOperatorSet:
    """IP-350：A⁺ 发证书，A⁻ 做负测试；保义由独立判定器给出。"""

    def __init__(self, ops, oracle, eps_max=1.0):
        self.ops = ops
        self.oracle = oracle
        self.eps_max = eps_max

    def sample(self, x, eps, m, positive=True):
        out = []
        for _ in range(m):
            a = self._draw(eps)
            x2 = a(x)
            keep = self.oracle.eq(x, x2)
            if keep == positive:
                out.append((a, x2))
        return out

    def _draw(self, eps):
        import random
        op = random.choice(self.ops)
        return op.sample(eps)


class CoverageCertificateBuilder:
    """IP-351：ρ_pres + N_eff + R_ub；缺项即无效。"""

    def build(self, x, ops, m=64, eps=0.3, delta=0.05, lip=1.0):
        pos = ops.sample(x, eps, m, positive=True)
        neg = ops.sample(x, eps, m, positive=False)
        rho = len(pos) / max(1, m)
        cells = {cell_id(x2) for _, x2 in pos}
        r_hat = empirical_risk(pos)
        n_eps = max(1, len(cells))
        r_ub = r_hat + lip * eps + sqrt((log(n_eps) + log(1 / delta)) / (2 * max(1, m)))
        cert = {"A": ops, "eps": eps, "rho": rho, "n_eff": len(cells),
                "m": m, "R_ub": r_ub, "neg_rate": len(neg) / max(1, m)}
        cert["valid"] = (rho >= 1 - delta and len(cells) >= N_MIN and r_ub <= R_MAX)
        return cert


class TypedToolCallCompiler:
    """IP-353：模型只提议，注册表与类型检查器批准。"""

    def __init__(self, registry, llm_proposer, fallback_program):
        self.reg = registry
        self.propose = llm_proposer
        self.fallback = fallback_program

    def compile(self, ell, s, verifier, eps_req):
        best, best_cost = None, float("inf")
        for cand in self.propose(ell, s, self.reg.names(), k=8):
            if not self.reg.typecheck(cand, s):
                continue
            ok, witness, rad = verifier.verify(cand, x=s, eps=eps_req)
            if not ok or rad < eps_req:
                continue
            cost = self.reg.cost(cand)
            if cost < best_cost:
                best, best_cost = cand, cost
        return best if best is not None else self.fallback


class AugmentedContractVerifier:
    """IP-354：在 B_ε(x) 上抽样，返回 (ok, witness, rad_hat)。"""

    def __init__(self, runner, ops, m=64, delta=0.05):
        self.run = runner                     # 抽象执行 / dry-run
        self.ops = ops
        self.m = m
        self.delta = delta

    def verify(self, program, x, eps):
        samples = self.ops.sample(x, eps, self.m, positive=True)
        ok_n = 0
        for a, x2 in samples:
            outs = self.run(program, x2)
            if all(post_ok(o) and safety_ok(o) for o in outs):
                ok_n += 1
            else:
                return False, (a, x2), 0.0   # 反例见证
        # Clopper–Pearson 单侧下界（实现用 scipy.stats.beta）
        lower = cp_lower(ok_n, len(samples), self.delta)
        if lower < 1 - self.delta:
            return False, None, 0.0
        lo, hi = 0.0, eps
        for _ in range(8):                    # 网格二分估计 rad
            mid = (lo + hi) / 2
            if self._passes(program, x, mid):
                lo = mid
            else:
                hi = mid
        return True, None, lo


class WitnessDrivenRepairer:
    """IP-355：用反例选择修复算子；每步保持 ⊢ 与 Safety。"""

    REPAIRS = ("guard", "replace", "insert", "tighten", "split")

    def __init__(self, registry, budget=3):
        self.reg = registry
        self.K = budget

    def repair(self, program, witness):
        a, x2 = witness
        for kind in self.REPAIRS:
            cand = self._apply(kind, program, a, x2)
            if cand and self.reg.typecheck(cand, x2):
                return cand
        return program


class DegradationLattice:
    """IP-356：P -> P_safe -> P0 -> iota0，每级保持 Safety。"""

    def __init__(self, safe_program, default_program, iota0):
        self.chain = [safe_program, default_program, iota0]
        self.level = 0

    def fallback(self, program):
        self.level = min(self.level + 1, len(self.chain) - 1)
        return self.chain[self.level]

    def on_runtime_failure(self, program, failure):
        if not failure.safety_ok:
            self.level = len(self.chain) - 1     # 直接到最保守
        return self.chain[self.level]


class RobustCalibrator:
    """IP-357：用增强 rollout 做 min-max 校准。"""

    def __init__(self, tau0, w0, lam=0.1, mu=0.1):
        self.tau0, self.w0 = tau0, w0
        self.lam, self.mu = lam, mu
        self.rollouts = []

    def add(self, x, a, program, outcome):
        self.rollouts.append((x, a, program, outcome))

    def calibrate(self, V, grid_iters=20):
        tau = dict(self.tau0)
        w = list(self.w0)
        for _ in range(grid_iters):
            # 坐标下降：先固定 w 调 tau，再固定 tau 投影 w 到单纯形
            tau = self._descend_tau(tau, w, V)
            w = project_simplex(self._descend_w(tau, w, V))
        return tau, w


def atcl_round(M, x, ell, registry, compiler, verifier, repairer, lattice, calibrator):
    """IP-358：ATCL 主闭环（在线部分；编译/验证可异步预计算）。"""
    # 1) 覆盖证书：准入阶段，不在 50Hz 路径
    cov = M.coverage.build(x, M.aug_ops, m=64, eps=M.eps_req)
    if not cov["valid"]:
        M.log.warn("覆盖证书无效，降级为单点证书")

    # 2) 指令 -> 工具程序
    program = compiler.compile(ell, x.state, verifier, M.eps_req)

    # 3) 增强邻域验证
    ok, witness, rad = verifier.verify(program, x, M.eps_req)

    # 4) 见证驱动修复（预算 K）
    k = 0
    while not ok and k < repairer.K:
        program = repairer.repair(program, witness)
        ok, witness, rad = verifier.verify(program, x, M.eps_req)
        k += 1

    # 5) 预算耗尽：沿降级格退回
    if not ok:
        program = lattice.fallback(program)
        rad = 0.0

    # 6) 执行 + 运行时监控
    outcome = M.execute_typed(program)
    if is_failure(outcome):
        program = lattice.on_runtime_failure(program, outcome)

    # 7) rollout 回收（异步）
    calibrator.add(x, cov["A"], program, outcome)
    if calibrator.ready():
        tau, w = calibrator.calibrate(V=M.violation)
        M.metric_ladder.set_thresholds(tau)
        M.meta_weight.set_base(w)

    return outcome, cov, rad, program
```
