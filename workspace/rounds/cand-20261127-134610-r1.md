### 第 1 轮灵感驱动研究记录

**灵感词**：视觉感知、SLAM

**直觉与动机**：
前几轮把安全性逐步外包给证书：从九证到十二证，判据越来越精细。但所有证书都默认了一件事——状态 x 是真的。真实双足机器人上，x 来自视觉 SLAM，是一个带协方差的估计量；地图 M 本身也在被同一套视觉不断改写。于是证书链条的「根」其实是感知，而根一旦错了，上面十二证越一致，错得越自信。

三个直觉转向：

1. **从「状态即真值」到「信念状态」**：控制器真正能消费的不是 x，而是 b_t=(x̂_t, Σ_t, M_t)。所有常识约束、价值约束都应写成对信念的鲁棒约束：约束裕度必须吃掉位姿不确定度 r_s 与语义 grounding 误差 e_g。这把「感知噪声」从外生干扰变成证书里显式的一项预算。

2. **从「被动感知」到「主动感知」**：若证书裕度不足以覆盖感知不确定度，正确的动作未必是继续控制，而可能是「减速、转头、重定位」——感知本身是可规划、可认证的动作。关键是把 look/relocalize 限制在一个前向不变的安全包络内（刹车距离 ≤ 净空），否则「边看边走」会把机器人带进危险。

3. **视觉语义让常识可被「看见」地实例化**：KC 里的 wet_floor、glass_door、human_near、traversability 都可以由分割/深度 ground 成谓词。但视觉 grounding 会犯「高置信的错」——玻璃被当成空地、镜面被当成走廊。必须用 conformal 预测集合把误标风险控制在 α_g，并允许「谓词不唯一 → 主动再看一眼」。

**关键洞见**：感知不是证书之外的噪声源，而是证书链的根节点。必须把根也证书化（SVC/LCC/VGC），并让系统在根不可信时有权降级或主动修复；否则「十二证自证循环」只是把共因失效从控制层挪到了感知层，反而更隐蔽。

**形式化目标（增量）**：
1. 定义信念状态 b_t=(x̂_t, Σ_t, M_t)，以及状态有效性证书 SVC：P(e_x^T Σ^{-1} e_x ≤ χ²_{d,1−δ_s}) ≥ 1−δ_s，且回环/地图一致性 LCC 成立。
2. 定义视觉 grounding 证书 VGC：用 split conformal 给出谓词集合 P̂_p，使真标签以概率 ≥ 1−α_g 落入集合；集合基数 >1 视为语义歧义，触发主动感知。
3. 定义感知膨胀鲁棒约束：g(x̂,u) ≥ θ + L_x·r_s + L_p·e_g，并证明其以 ≥1−δ_s−δ_g 概率推出真实约束满足。
4. 定义主动感知动作 a_look ∈ A_p 及其安全包络 S_look（前向不变、刹车距离约束），以及信息增益 IG(a_look) 与证书修复时间 τ_repair。
5. 定义 PA-KTCG = v29 十二证 + SVC + VGC + LCC（十五证）；名义分支 Exec_v30^nom ⊆ Exec_v29，降级分支 Exec_v30^deg ⊆ SafeStop ∪ SafeLook，并分别给出安全论证。
6. 实验目标：在光照/雨雾/动态行人/玻璃镜面/重复走廊等视觉扰动下，KC 违规率较 v29 降低 ≥50%，look 动作占比 <5%，任务完成率下降 <3%，假回环灾难事件为 0。

**本轮最大风险**：**感知根节点的同源共因失效**——视觉语义的「高置信错误」（玻璃/镜面/水面被判为可通行）会让 SVC、VGC 与下游十二证基于同一套错误像素一致地放行；conformal 只保校准分布内的边际覆盖，域漂移下覆盖率会静默崩塌，而主动感知还可能「看得越多越确信错误」，形成感知层的自证循环。这比 v29 的多组件共因失效更靠上游，也更难在线归因。

## 2. 关键算法骨架（在 IP-467~472 骨架上扩展）

### IP-473 Visual-Semantic Commonsense Grounder (VSCG)

```python
@dataclass
class VisualSemanticCommonsenseGrounder:
    """VSCG：视觉证据 ground 成 KC 谓词，split conformal 控制误标风险"""
    segmenter: Callable              # 语义/实例分割网络（独立骨干）
    predicate_bank: list             # [wet_floor, glass_door, human_near, traversability]
    alpha_g: float = 0.05
    q_hat: float = None

    def ground(self, rgb, depth, pose, map_) -> dict:
        masks = self.segmenter(rgb)
        feats = self._predicate_features(masks, depth, pose, map_)
        return {p: self._score(p, feats) for p in self.predicate_bank}

    def conformal_calibrate(self, calib_set):
        """calib_set: [(visual_input, {predicate: true_label})]；交换性假设下
        非一致性分数 s = 1 − score(true_label)，取 1−α_g 分位"""
        scores = []
        for v, labels in calib_set:
            g = self.ground(*v)
            for p, lbl in labels.items():
                scores.append(1.0 - g[p][lbl])
        self.q_hat = float(np.quantile(scores, 1.0 - self.alpha_g))
        return self.q_hat

    def predicate_set(self, visual_input, p) -> set:
        """P̂_p：真标签以 ≥1−α_g 概率落入的预测集合（仅边际覆盖）"""
        scores = self.ground(*visual_input)[p]
        return {lbl for lbl, s in scores.items() if s >= 1.0 - self.q_hat}

    def semantic_error(self, visual_input, p) -> float:
        """e_g：集合外保守误差；集合单元素时退化为 1−max score"""
        scores = self.ground(*visual_input)[p]
        P = self.predicate_set(visual_input, p)
        if len(P) == 1:
            return 1.0 - max(scores[lbl] for lbl in P)
        return 1.0                       # 歧义即视为最大不确定，交给 APP
```

### IP-474 SLAM State-Estimation Certificate (SSEC)

```python
@dataclass
class SLAMStateEstimationCertificate:
    """SSEC：检验 SLAM 位姿/地图是否可信，输出 SVC 与 LCC"""
    chi2_gate: float = 0.99
    lc_res_max: float = 0.02          # 回环几何残差阈值（相对地图尺度）
    lc_inlier_min: float = 0.6
    map_consistency_max: float = 0.05

    def svc(self, x_hat, Sigma, residuals) -> bool:
        """NEES 一致性：E[e^T Σ^{-1} e]=d；超门限说明 Σ 过度自信"""
        nees = float(residuals.T @ np.linalg.inv(Sigma) @ residuals)
        self.nees = nees
        self.nees_ok = nees <= chi2.ppf(self.chi2_gate, df=len(residuals))
        return self.nees_ok and self._observability_ok(x_hat)

    def lcc(self, loop_closures, map_) -> bool:
        """回环一致性：几何残差 + 内点率 + 地图一致性，拒绝可疑回环"""
        ok = all(lc.residual <= self.lc_res_max
                 and lc.inlier_ratio >= self.lc_inlier_min
                 for lc in loop_closures)
        self.map_consistency = self._map_consistency(map_)
        return ok and self.map_consistency <= self.map_consistency_max

    def trust_radius(self, Sigma) -> float:
        """r_s：信任半径，供 PC-KTMPC 的约束膨胀使用"""
        d = Sigma.shape[0]
        return float(np.sqrt(chi2.ppf(self.chi2_gate, df=d)
                             * np.linalg.eigvalsh(Sigma).max()))
```

### IP-475 Perception-Conditioned Robust KT-MPC (PC-KTMPC)

```python
@dataclass
class PerceptionConditionedKTMPC:
    """PC-KTMPC：以信念状态为输入，把感知不确定度折进约束裕度"""
    kempc: 'KnowledgeTransilientMPC'     # v29 教师（目标/权重原样）
    ssec: SLAMStateEstimationCertificate
    vscg: VisualSemanticCommonsenseGrounder
    L_x: float = 1.0                     # 校准集估计后取 L̂+2·SE
    L_p: float = 0.5

    def solve(self, x_hat, Sigma, visual_input, u_prev):
        r_s = self.ssec.trust_radius(Sigma)
        e_g = self.vscg.semantic_error(visual_input, p='traversability')
        inflation = self.L_x * r_s + self.L_p * e_g
        # 原约束 g(x,u) >= theta → 对 x_hat 的鲁棒约束 g(x_hat,u) >= theta+inflation
        # 价值违约罚 lambda_v * value_penalty 原样保留，作用在 x_hat 上
        return self.kempc.solve(
            x_hat, u_prev,
            constraint_margin=inflation,
            grounded_predicates=self.vscg.predicate_set(visual_input, 'traversability'))
```

### IP-476 Active Perception Planner (APP)

```python
class ActivePerceptionPlanner:
    """APP：裕度不足以覆盖感知不确定度时，先修复证书再控制"""
    def __init__(self, pc_ktmpc, ssec, v_look=0.2, tau_repair=1.5):
        self.pc, self.ssec = pc_ktmpc, ssec
        self.v_look, self.tau_repair = v_look, tau_repair

    def certify_or_look(self, rho_t, r_s, e_g, state):
        need = self.pc.L_x * r_s + self.pc.L_p * e_g
        if rho_t >= need:
            return 'control', None
        if self._can_look_safely(state):
            return 'look', self._max_info_gain_action(state)
        return 'stop', self._brake_action(state)

    def _can_look_safely(self, state) -> bool:
        """刹车距离 + 感知窗口位移 <= 净空，保证 look 期间在不变集内"""
        brake = state.v ** 2 / (2 * state.a_max)
        return state.clearance >= brake + state.v * self.tau_repair

    def _max_info_gain_action(self, state):
        """朝不确定度最高、且位于安全扇区内的方向减速转向；
        以 IG(a)=H(b_t)−E[H(b_{t+1}|a)] 选动作，动作幅值受 v_look 约束"""
        candidates = self._safe_look_candidates(state)
        return max(candidates, key=lambda a: self._mutual_information(state, a))
```

### IP-477 Aliasing-Aware Covariance Inflator (AACI)

```python
class AliasingAwareCovarianceInflator:
    """AACI：重复走廊/相似场景易假回环；混叠越强，Σ 越要保守膨胀"""
    kappa_max: float = 0.75
    gamma: float = 3.0

    def inflate(self, Sigma, kappa_ali):
        if kappa_ali <= self.kappa_max:
            return Sigma
        return Sigma * (1.0 + self.gamma * (kappa_ali - self.kappa_max))

    def kappa(self, place_scores, neighbor_ids):
        """κ_ali：最高 place-recognition 相似度若来自非邻居，则混叠风险高"""
        top_id, top_s = max(place_scores.items(), key=lambda kv: kv[1])
        return top_s if top_id not in neighbor_ids else 0.0
```

### IP-478 Perception-Aware Cert Gate (PA-KTCG)

```python
@dataclass
class PerceptionAwareCertGate:
    """PA-KTCG：v29 十二证 + SVC/VGC/LCC；名义条件化 + 降级安全包络"""
    v29_gate: 'ValueAlignedDistillationCertGate'
    ssec: SLAMStateEstimationCertificate
    vscg: VisualSemanticCommonsenseGrounder
    app: ActivePerceptionPlanner
    aaci: AliasingAwareCovarianceInflator

    def admits(self, plan, sensor):
        # 1) SVC：状态估计可信；失败先修复（look/relocalize）或安全停
        if not self.ssec.svc(sensor.x_hat, sensor.Sigma, sensor.residuals):
            return self._degraded(plan, sensor, 'relocalize')
        # 2) LCC：回环/地图一致；可疑回环 → 重定位，绝不让假回环进入地图
        if not self.ssec.lcc(sensor.loop_closures, sensor.map):
            return self._degraded(plan, sensor, 'relocalize')
        # 3) VGC：语义集合必须单元素；歧义（如玻璃 vs 空地）→ 主动看
        P = self.vscg.predicate_set(sensor.visual, 'traversability')
        if len(P) > 1:
            return self._degraded(plan, sensor, 'look')
        # 4) 名义分支：v29 十二证作用在 x_hat 上（鲁棒约束已含膨胀）
        ok, u, path = self.v29_gate.admits(plan.with_state(sensor.x_hat), sensor)
        return ok, u, path

    def _degraded(self, plan, sensor, mode):
        """降级分支只允许认证过的 look/relocalize/stop，绝不输出普通控制"""
        r_s = self.ssec.trust_radius(sensor.Sigma)
        e_g = self.vscg.semantic_error(sensor.visual, 'traversability')
        m, a = self.app.certify_or_look(0.0, r_s, e_g, sensor)
        if m == 'stop' or mode == 'stop':
            return True, self.app._brake_action(sensor), 'stop'
        if mode == 'relocalize' and self.app._can_look_safely(sensor):
            return True, self.app._relocalize_action(sensor), 'relocalize'
        if self.app._can_look_safely(sensor):
            return True, a, 'look'
        return True, self.app._brake_action(sensor), 'stop'
```

**与 v29 的接口约定**：v29 的 VAD-KTCG 原样复用，仅新增 `plan.with_state(x_hat)` 的只读适配；APP 的所有动作必须经 `_can_look_safely` 过滤，否则退化为 stop。

## 3. 复杂度分析（增量更新）

## 4. 正确性论证（增量更新）

### 引理 29（感知膨胀的鲁棒约束）

**陈述**：设约束 g(x,u) 对状态 L_x-Lipschitz、对语义 grounding 误差 L_p-Lipschitz。若 SVC 成立使 ‖x−x̂‖ ≤ r_s 以概率 ≥1−δ_s，VGC 使 e_g ≤ ε_g 以概率 ≥1−δ_g，且控制器强制 g(x̂,u) − θ ≥ L_x r_s + L_p ε_g，则真实约束满足 g(x,u) ≥ θ 的概率 ≥ 1−δ_s−δ_g。

**证明**：|g(x,u)−g(x̂,u)| ≤ L_x‖x−x̂‖ + L_p e_g ≤ L_x r_s + L_p ε_g。故 g(x,u) ≥ g(x̂,u) − (L_x r_s + L_p ε_g) ≥ θ。两个概率事件取并集界即得。∎

**工程含义**：感知不确定度不是拍脑袋的保守系数，而是可测的 r_s 与 ε_g；证书裕度必须显式覆盖它，否则 v29 的十二证只是在错误状态上正确地推理。

### 引理 30（视觉 grounding 的 conformal 边际覆盖）

**陈述**：在校准集与部署样本可交换的假设下，VSCG 的预测集合 P̂_p 满足 P(true_label ∈ P̂_p) ≥ 1−α_g。

**证明**：split conformal 的标准结论：非一致性分数在交换序列上秩均匀，取 ⌈(n+1)(1−α_g)⌉/n 分位即可。∎

**诚实声明**：这是**边际**覆盖，不是条件覆盖；光照/天气/新场景导致的分布漂移会破坏可交换性，覆盖率可能静默低于 1−α_g。PADM 必须在部署中持续估计实际覆盖率，跌破 1−α_g−η 即重校准并收紧 α_g。

### 引理 31（混叠膨胀的保守一致性）

**陈述**：若真实位姿误差协方差为 Σ_true，报告协方差为 Σ，则在混叠层 κ_ali 上取膨胀 Σ' = (1+γ(κ_ali−κ_max))Σ，且 γ ≥ sup_{κ>κ_max}(λ_max(Σ_true)/λ_max(Σ)−1)/(κ−κ_max)，则 E[NEES'] ≤ χ²_{d,1−δ_s}。

**证明思路**：NEES 关于 Σ 单调递减；膨胀使 λ_max(Σ') ≥ λ_max(Σ_true)，逐层取上确界即可保证期望 NEES 不超门限。这是**校准性**结论，依赖混叠分层上确界可估，不是无分布保证。∎

### 定理（PA-KTCG 的双分支安全）

**陈述**：PA-KTCG 准入的轨迹分两支：名义分支满足 SVC ∧ LCC ∧ VGC（单元素）∧ Exec_v29，故 Exec_v30^nom ⊆ Exec_v29；降级分支只输出 look/relocalize/stop，且每个动作经 `_can_look_safely` 过滤，其轨迹保持在 S_look 内，而 S_look 在刹车能力约束下前向不变且与障碍净空为正。

**证明**：名义分支逐字节复用 v29 十二证，并额外叠加 SVC/LCC/VGC 三个合取项，故收缩。降级分支由构造只可能落在 A_p；`_can_look_safely` 要求 clearance ≥ v²/(2a_max)+v·τ_repair，即最坏刹车轨迹仍在净空内，故 S_look 前向不变。两分支均不输出未经认证的普通控制。∎

**边界声明**：降级分支不是 Exec_v29 的子集——look 是新动作。我们不对它宣称「十二证兼容」，而是单独证明其安全包络；这是本轮相对前几轮「执行集单调收缩」叙事的一次诚实修正。

## 5. 实验设计（可执行）

- **平台**：MuJoCo/Isaac Gym 双足 + 照片级渲染；SLAM 用 ORB-SLAM3，另以 DROID-SLAM 做交叉验证。

## 7. 本轮最大风险（最终确认）

**一句话**：**感知根节点的同源共因失效**——视觉语义的「高置信错误」（玻璃/镜面/水面被判为可通行）会让 SVC、VGC 与下游十二证基于同一套错误像素一致放行；conformal 只保校准分布内的边际覆盖，域漂移下覆盖率静默崩塌，主动感知还可能「越看越确信错误」，形成比 v29 更靠上游、更难在线归因的感知层自证循环。
