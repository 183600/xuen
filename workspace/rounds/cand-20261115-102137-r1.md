# 第 5 轮（灵感循环第 5 轮；本轮灵感：「比赛策略」×「运动规划」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E467）。第 3 轮 InstructGauge、第 2 轮 ToolGauge、第 1 轮 LeanGauge/MODGAUGE 全部继承。
> 本轮纪律：**对抗可测 + 段级可证 + 严格退化**。比赛策略与运动规划各补一个 v4 的结构缺口；任一环节不可用都必须能一键退回 v4。

## 0. 直觉与动机

### 灵感 A：比赛策略 → 把「分布外」拆成有预算的对手

直觉：v4 的腕部相机可以检测漂移，但它的默认假设是「扰动是小而零均值的噪声」。真实世界里，遮挡、反光、移动的人或另一台机器人并不是随机噪声，而是**会在你最长的开环块里挑最坏时刻出现**。比赛策略给我的不是「让机器人参加比赛」，而是三个可迁移的结构：

1. **对手模型**：把扰动写成对手的（非预期）策略 `w_{1:K}`，受显式预算 `(W, δ, B)` 约束；
2. **承诺与应急**：leader 先承诺一个块（策略），follower 再在预算内 best-respond——这正是 Stackelberg 博弈；块长 `K` 就是承诺 horizon；
3. **遗憾 / 组合**：面对不确定的对手类型，用 minimax regret 与策略组合（多同伦类备选）而不是单点最优。

关键转折：v4 问「漂移有没有超阈」，本轮问「**对手在预算内能不能让漂移必然超阈**」。前者是检测，后者才是可证伪的稳健性。这两者不是同一件事：一个在名义数据上 99% 准确的检测器，可能恰好被一个有预算的对手在第 `K` 步击穿。

### 灵感 B：运动规划 → 块是一段连续轨迹，不是几个采样点

直觉：v4 的 `KinematicAdmissibleSet` 只检查每个动作点上的 IK 与碰撞。但块是**连续执行**的：两个端点都无碰撞，完全可能在中点撞上，或者速度/加速度超限导致跟踪误差爆炸。运动规划把「点可行」升级为「段可行」：时间参数化 `s(t)`、扫掠体连续碰撞检测、速度/加速度/关节全程约束、同伦类与 anytime 应急计划。直觉上，块的安全证书必须覆盖整段轨迹的**扫掠体积**，而不是给采样点盖章。

### 灵感 C：耦合 → 鲁棒管道与「证据半衰期」

直觉可以写成一句话：

```text
比赛策略给「对手多强、承诺多久」；运动规划给「这段承诺在几何上还剩多少余量」。
两者相乘 = 一条名义轨迹 + 一个包住所有对手可达状态的管道。
```

管道在时间上能维持不撞的长度，就是块的**证据半衰期** `h`；块长必须满足 `K ≤ h`。超过 `h` 不是「风险变大」，而是「稳健证书已经不存在」。这让第 3 轮「分块放大错误」从经验判断变成可计算的 `K_max`。最危险的并不是单个组件，而是**用名义轨迹的余量去支付对手预算**——一旦预算估计偏小，证书会在最坏时刻恰好失效。

## 1. 研究问题（本轮要回答什么）

- **Q1（对手可测性）**：如何让「对手」成为可证伪、可比较的对象，而不是万能背锅的「分布外」？
- **Q2（承诺 horizon）**：在预算 `(W, δ, B)`、Lipschitz 误差传播常数 `L`、初始裕度 `m₀` 下，稳健可分块的充要条件是什么？`K*` 如何求，收益与稳健性的边界在哪？
- **Q3（段级可证）**：连续时间运动证书相对逐点证书能补回多少漏检？能否构造「两端安全、中点碰撞」的反例，说明 v4 存在结构性缺口？
- **Q4（回退的 anytime 性）**：当当前同伦类被对手封死，能否在有限时间内找到同伦应急或安全停止，而不是退化成「盲执行 / 全停」二选一？

## 2. 四条设计原则（正式化见产物区定义 468–481）

**P1 对手预算显式化（Explicit Adversary Budget）**
任何稳健声明必须附带 `(W, δ, B)` 与校准分位数；预算外事件触发回退，而不是继续声称稳健。没有预算的「鲁棒」是不可证伪的。

**P2 承诺-应急二元性（Commitment–Contingency Duality）**
每个提交的块必须带一个应急集 `Cont(C)`（多同伦类 + 停止），且激活代价有上界；没有应急 ⇒ `K=1`。承诺而不准备应急，等于把开环窗口交给对手。

**P3 连续时间不可豁免（Continuous-Time Non-Exemption）**
任何块级安全声明必须在时间参数化轨迹的扫掠体上验证；逐点检查只能作为退化路径，不能作为主路径。

**P4 稳健同伦回退（Robust Homotopy Fallback）**
当前同伦类的管道失效 ⇒ 切换同伦应急；全部失效 ⇒ `K=1` 反应式；反应式也失效 ⇒ 安全停止。禁止「无证书执行」。这条给的是 anytime 安全性，而不是「总能成功」。

## 3. 与基线的接口（严格退化）

- `W={0}` 或 `B=0` ⇒ 管道退化为名义轨迹 ⇒ v4 的 `SpatialCert`；
- 不做连续时间检查 / 只查采样点 ⇒ v4 `Kinematic-Loop`；
- 应急集为空或同伦切换超时 ⇒ 强制 `K=1`；
- 博弈求解超时 ⇒ 取保守 `K=1`（或上一轮已验证的 `K`）；
- 腕部相机失效 ⇒ v4 单帧漂移；ROS 失效 ⇒ 本地证书；全部失效 ⇒ InstructGauge v3 ⇒ ToolGauge。

## 4. 预期贡献

1. 一个把「分布外」拆成 `(W, δ, B, L)` 的可测对手预算口径，并给出共形校准与预算外回退语义；
2. 一个 Stackelberg 分块博弈与「证据半衰期」`h`，给出 `K* = min(h, K_plan)` 的闭式 / 半闭式条件；
3. 一个连续时间运动证书（时间参数化 + 扫掠体 + 动态可行），并用分离反例证明它严格强于 v4 的逐点证书；
4. 一个同伦应急的 anytime 回退结构，保证「要么有证书执行、要么安全停止」；
5. 一条完整可证伪路径：E473–E490 覆盖预算校准、管道紧致度、`K*`、段级漏检、同伦切换、对抗注入、过度保守与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：如果对手预算 `(W, δ, B)` 校准得偏小，或运动规划的管道过近似过松，系统会陷入两难——要么在预算外被真实对手击穿（证书失效），要么因过度保守把 `K` 压到 1、使「分块收益」名存实亡；真正的风险是**预算校准误差与管道保守性共同决定的鲁棒性-效用前沿**，而不是单个模块的实现。

## 2. 形式化定义（要点）

**定义 468（对抗预算 AdversaryBudget）** 对手是**非预期**的：`w_t = π(w_{1:t-1}, x_{1:t})`，且满足

```text
A = (W, δ, B, Q):  w_t ∈ W,  ‖w_t‖_Q ≤ δ,  Σ_{t=1}^{K} ‖w_t‖_Q ≤ B.
```

`W` 是几何上可解释的扰动模式集（相机遮挡、反光、移动障碍、关节编码器噪声、TF 抖动），不是任意范数球。预算 `(δ,B)` 把「分布外」拆成两个可测量：单步强度与总能量。

**定义 469（预算共形校准 CalibratedBudget）** 在标定轨迹集上，对每个块长 `K` 取单步残差的经验分位数：

```text
Cal_α(B) = Quantile_{1−α} { Σ_{t=1}^{K} ‖w_t‖_Q : K ≤ K_max }。
```

若在线观测到 `Σ‖w_t‖ > Cal_α(B)`，记为**预算外事件**：GM 证书立即作废，转入 P4 回退，而不是继续沿用旧证书。

**定义 470（鲁棒管道 RobustTube）** 给定名义轨迹 `ξ^C` 与预算 `A`，

```text
R_t(C; A) = { x ∈ X : ∃ w_{1:t} ∈ A,  x = φ_t(x_0, a_{1:t}, w_{1:t}) },
Z_t ⊇ R_t,   Z_t 为 zonotope / 椭球过近似。
```

**定义 471（管道传播 TubePropagation）** 误差动力学 `e_{t+1} = A_t e_t + w_t`，`‖A_t‖ ≤ L`。以 Minkowski 和传播：

```text
Z_{t+1} = A_t Z_t ⊕ W,   Z_0 = {0}。
```

候选的 `A_t` 由跟踪控制器与机械臂刚体模型给出；`L` 是 `‖A_t‖` 的上界。

**定义 472（鲁棒安全 RobustSafe）**

```text
RobustSafe(C; A) ⟺ ∀t∈[t_s,t_e]:
   Z_t ∩ O_t = ∅  ∧  Z_t ⊆ X_joint  ∧  DynamicFeasible(Φ, Z_t)。
```

注意：`O_t` 也允许在预算内移动（移动障碍 / 竞争机器人），因此 `O_t = O_t(w_{1:t})`。

**定义 473（证据半衰期 EvidenceHalfLife）**

```text
h(C; A) = sup{ k ≤ K : RobustSafe(C_{1:k}; A) }。
```

`h` 是「这条承诺最多还能被证书支撑多久」的物理量；`K > h` 表示稳健证书不存在，而不是概率变小。

**定义 474（Stackelberg 分块博弈 StackelbergChunkGame）** 博弈 `G=(P,D; S_P, S_D; J)`：

- leader `P`（规划器）先承诺 `(C,K)`，`K ≤ K_max`；
- follower `D`（对手 / 环境）在预算 `A` 内非预期地选 `w_{1:K}`；
- 收益 `J(C,K,w) = U(C,K) − λ·1[∃t: x_t ∉ X_safe] − μ·cost(C)`；
- 稳健值 `V(C,K) = inf_{w∈A} J(C,K,w)`，规划器取 `argmax_{C,K} V`。

这是 Stackelberg（leader 先承诺）而非 Nash：块一旦提交就是承诺，对手可以针对它 best-respond。开环窗口的长度 `K` 直接等于对手的 best-response 时间。

**定义 475（稳健可分块 RobustChunkability）** 给定初始裕度 `m₀`、所需余量 `ε`，块长 `K` 稳健可分块当且仅当

```text
K ≤ h(C; A)  且  K ≤ floor(B/δ)（若以单步满预算保守估计）。
```

`m₀ ≤ ε` ⇒ `K_safe=0`，即必须 `K=1` 或停止。

**定义 476（连续时间运动证书 CTMC）**

```text
CTMC(C) = (Φ, SV(ξ^C), v_max, a_max, clearance)
```

满足：`Φ:[0,T]→X` 为 `C²` 时间参数化，`|ṡ(t)|≤v_max`，`|s̈(t)|≤a_max`，`Φ(t)` 全程在关节限位内，且 `SV(ξ^C) ∩ O = ∅`。与 v4 的逐点检查不同，`Φ` 与 `SV` 覆盖整段时间区间。

**定义 477（扫掠体 SweptVolume）**

```text
SV(ξ^C) = ⋃_{t∈[0,T]} { (1−u)·Φ(t) + u·Φ(t+dt) : u∈[0,1] }。
```

实现上用保守推进（conservative advancement）或连续碰撞检测（CCD）在有界时间内给出「无碰撞」或「首次碰撞时刻」。

**定义 478（同伦应急集 HomotopyContingency）**

```text
Cont(C) = { C^1, …, C^q, STOP },   ℋ(C^j) ≠ ℋ(C^{j'}) (j≠j')。
```

每个 `C^j` 都预先通过 `CTMC` 与 `RobustSafe` 检查；`STOP` 是零动作安全停止。

**定义 479（应急激活代价 ContingencyActivationCost）**

```text
κ(C→C^j) = α·‖x_{t_switch} − x^j_{t_switch}‖ + β·switch_time + γ·lost_progress。
```

要求 `κ ≤ κ_max`，否则该应急不可用（防止「名义上可回退、实际切不过去」）。

**定义 480（博弈-运动联合证书 GM-Certificate）**

```text
Cert_GM(C) = ( A, Cal_α(B), ξ^C, {Z_t}, h, CTMC(C), Cont(C), κ_max, V(C,K*), K* )。
```

证书必须可独立重放：给定 `A`、`ξ^C`、`{Z_t}`、`Φ`，第三方能复核 `RobustSafe` 与 `CTMC`，不依赖运行时隐藏状态。

**定义 481（鲁棒接地遗憾 RobustGroundingRegret）** 当指令 `ℓ` 仍有歧义集 `A(ℓ)` 时，接地不再取单点 argmax，而取 minimax regret：

```text
ι* = argmin_{ι∈A(ℓ)} max_{ι'∈A(ℓ)} [ cost(ι') − cost(ι) ]，  s.t. tools(ι) ⊆ T₀。
```

若 `A(ℓ)` 的遗憾超过阈值，直接退回默认 `ι₀`（v3 的 ToolGauge 目标），不让语义歧义进入博弈层。

## 3. 关键算法骨架

```python
# IP-334 Adversary-Budget Model + 共形校准
class AdversaryBudget:
    def __init__(self, W, delta, B, Q, alpha=0.05):
        self.W, self.delta, self.B, self.Q, self.alpha = W, delta, B, Q, alpha

    def calibrate(self, residuals_by_K):
        # 每个 block 长度 K 的经验残差总量 -> 1-alpha 分位
        self.cal = {
            K: np.quantile(np.asarray(r), 1.0 - self.alpha)
            for K, r in residuals_by_K.items()
        }
        return self.cal

    def is_within_budget(self, w_seq, K):
        total = sum(self.norm(w) for w in w_seq)
        per_step = all(self.norm(w) <= self.delta + 1e-9 for w in w_seq)
        cap = self.cal.get(K, self.B)
        return per_step and total <= min(cap, self.B)

    def norm(self, w):
        return float(np.sqrt(w @ self.Q @ w))

# IP-335 Robust-Tube Certificate
class RobustTube:
    def __init__(self, dynamics, W_zonotope, lipschitz_L):
        self.f, self.Wz, self.L = dynamics, W_zonotope, lipschitz_L

    def propagate(self, x0, actions, K):
        """Z_{t+1} = A_t Z_t (+) W，返回每个时刻的 zonotope 与名义轨迹"""
        Z = Zonotope.point(x0)
        xi, Zs = [x0], [Z]
        for t in range(K):
            A = self.f.linearization(xi[-1], actions[t])   # ||A|| <= L
            Zn = Zonotope.linear_map(Z, A) + self.Wz       # Minkowski sum
            Z = Zn.reduce(max_generators=64)               # 有界过近似
            xi.append(self.f.nominal(xi[-1], actions[t]))
            Zs.append(Z)
        return xi, Zs

    def robust_safe(self, xi, Zs, obstacle_seq, joint_lim, eps=0.0):
        for t, Z in enumerate(Zs):
            if Z.intersects(obstacle_seq[t], eps=eps):
                return False, t          # 首次失效时刻
            if not Z.within(joint_lim, eps=eps):
                return False, t
        return True, len(Zs)

# IP-336 Stackelberg-Chunk Game: 闭式 K* + 证据半衰期
def evidence_half_life(m0, eps, delta, B, L):
    """引理 63/64 的闭式上界；返回 h 与版本标记"""
    if m0 <= eps:
        return 0
    budget_cap = int(np.floor(B / max(delta, 1e-12)))
    if abs(L - 1.0) < 1e-9:
        geom = int(np.floor((m0 - eps) / max(delta, 1e-12)))
    else:
        ratio = 1.0 + (m0 - eps) * (L - 1.0) / max(delta, 1e-12)
        if ratio <= 0:
            geom = 0
        elif L < 1.0 and m0 - eps >= delta / (1.0 - L):
            geom = budget_cap          # 几何衰减，长期有界
        else:
            geom = int(np.floor(np.log(ratio) / np.log(L)))
    return max(0, min(geom, budget_cap))

def stackelberg_chunk(game, C_candidates, utility, K_plan):
    best = None
    for C in C_candidates:
        h = evidence_half_life(C.m0, C.eps, game.delta, game.B, game.L)
        K = min(h, K_plan)
        if K <= 0:
            continue
        V = utility(C, K)              # 硬安全约束：K>h 直接不可行
        if best is None or V > best.V:
            best = (C, K, V)
    return best                         # 无可行块 -> 退回 K=1 / STOP

# IP-337 CT-Motion Certificate
class ContinuousTimeMotionCert:
    def __init__(self, robot, ccd, v_max, a_max):
        self.robot, self.ccd, self.v_max, self.a_max = robot, ccd, v_max, a_max

    def verify(self, path, obstacles, T):
        s = TimeParameterization(path, T, self.v_max, self.a_max)
        if not s.feasible():
            return False, "dynamic_infeasible"
        for t in np.linspace(0.0, T, max(16, int(T * 100))):
            q = s.configuration(t)
            if not self.robot.within_joint_limits(q):
                return False, ("joint_limit", t)
        hit = self.ccd.first_contact(path, obstacles)   # 扫掠体
        if hit is not None:
            return False, ("swept_collision", hit)
        return True, s

# IP-338 Homotopy-Contingency Set
class HomotopyContingency:
    def __init__(self, planners, kappa_max):
        self.planners, self.kappa_max = planners, kappa_max

    def build(self, start, goal, obstacles, budget):
        cont = {}
        for name, planner in self.planners.items():
            path = planner.plan(start, goal, obstacles)
            if path is None:
                continue
            cert = ContinuousTimeMotionCert.verify(path, obstacles, budget.T)
            if cert[0]:
                cont[homotopy_class(path, obstacles)] = path
        return cont

    def activate(self, committed, cont, current_state):
        best, best_kappa = None, float("inf")
        for path in cont.values():
            k = activation_cost(committed, path, current_state)
            if k <= self.kappa_max and k < best_kappa:
                best, best_kappa = path, k
        return best, best_kappa         # None -> STOP

# IP-339 GM-8C 闭环
def instructgauge_gm(M, s, ell=None):
    # 1. 指令接地（含稳健遗憾）
    iota = robust_ground(M.nlib, ell, M.scene, M.ontology) if ell else M.default_iota
    if iota is None:
        iota = M.default_iota

    # 2. 候选块生成
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    C_cands = M.iac.plan_chunk_candidates(iota, H, M.tools,
                                          M.budget_left(s), M.drift_bound(s))

    # 3. 博弈选块：K* = min(h, K_plan)，无可行块则 K=1
    pick = stackelberg_chunk(M.game, C_cands, M.utility, M.K_plan)
    if pick is None:
        C, K = M.iac.plan_chunk(iota, H, M.tools, 1, M.drift_bound(s)), 1
    else:
        C, K = pick[0], pick[1]

    # 4. 连续时间运动证书（段级，而非点级）
    ok, info = M.ctmc.verify(C.path, M.env.obstacles(), C.duration())
    if not ok:
        C, K = M.iac.plan_chunk(iota, H, M.tools, 1, M.drift_bound(s)), 1

    # 5. 鲁棒管道证书
    xi, Zs = M.tube.propagate(C.x0, C.actions[:K], K)
    safe, t_fail = M.tube.robust_safe(xi, Zs, M.env.obstacle_seq(K), M.joint_lim)
    if not safe:
        C = C.truncate(max(0, t_fail - 1))
        K = len(C.actions)

    # 6. 执行：每个提交边界复核预算内 / 接地有效 / 管道安全
    executed = []
    for t in range(K):
        if not M.cvc.joint_pre(C.actions[t]) or not still_grounded(iota, M.env):
            break
        if not M.budget.is_within_budget(M.adversary.observed(), len(executed) + 1):
            C, K = M.contingency.activate(C, M.cont, M.env.state())   # 预算外回退
            break
        if not M.tube.robust_safe(xi[:t + 1], Zs[:t + 1],
                                  M.env.obstacle_seq(t + 1), M.joint_lim)[0]:
            C, K = M.contingency.activate(C, M.cont, M.env.state())
            break
        M.env.apply(C.actions[t])
        executed.append(C.actions[t])

    # 7. 生成联合证书并绑定主张
    cert = build_gm_cert(M, C, executed, xi, Zs, info)
    claims = bind_claims(C, iota, M.tcv.get_receipts(), cert)
    M.ros_cvc.publish_gm_cert(cert)
    return C, cert, claims

# IP-340 主闭环：50Hz 路径不变，只在块提交边界异步求解
def InstructGauge_GM_round(M, obs, audio, tac, depth, det, ell=None):
```

## 4. 推导

**引理 63（管道增长界）** 设误差动力学 `e_{t+1} = A_t e_t + w_t`、`‖A_t‖ ≤ L`、`‖w_t‖ ≤ δ`、`e_0=0`，则

```text
e_K ≤ δ·(L^K − 1)/(L − 1)   (L ≠ 1),        e_K ≤ K·δ   (L = 1)。
```

若 `L < 1`，则 `e_K ≤ δ/(1−L)`，管道半径有上界。证明：对 `e_{k+1} ≤ L e_k + δ` 归纳，等比求和即得；`L<1` 时令 `K→∞` 取极限。

**引理 64（稳健可分块条件）** 记 `m₀` 为块起点有符号裕度、`ε` 为所需余量。令 `K_dyn` 为满足 `e_K ≤ m₀ − ε` 的最大整数，`K_bud = floor(B/δ)`，则

```text
K_safe = min(K_dyn, K_bud),     RobustChunkable(C, K) ⇒ K ≤ K_safe。
```

`L > 1` 时 `K_dyn = floor( log(1 + (m₀−ε)(L−1)/δ) / log L )`；`L = 1` 时 `K_dyn = floor((m₀−ε)/δ)`；`L < 1` 且 `m₀−ε ≥ δ/(1−L)` 时 `K_dyn = ∞`（仍受 `K_bud` 限制）。证明：由引理 63 的 `e_K` 单调性直接解不等式；预算上限由定义 468 的 `Σ‖w_t‖ ≤ B` 与最坏情形每步花满 `δ` 得到。

**引理 65（证据半衰期单调性）** 固定几何与轨迹，`h(C;A)` 关于 `m₀` 非减、关于 `δ` 与 `L` 非增、关于总预算 `B` 非减（总预算越小，对手能维持满强度扰动的时间越短，故可承诺更长）。证明：由引理 64 的闭式表达式逐项检查单调性。

**引理 66（硬安全下的最优块长）** 若稳健性作为硬约束（`K > h` 时 `V=−∞`）、且块效用 `U(C,K)` 关于 `K` 非减，则

```text
K* = min(h(C;A), K_plan)。
```

若 `U` 在 `K_util` 处饱和（边际收益转负），则 `K* = min(h, K_plan, K_util)`。证明：可行域为 `[1,min(h,K_plan)]`，效用非减 ⇒ 取最大可行点；饱和情形取 `U` 的最大值点。软惩罚版本 `J = U − λ·risk` 在 `risk` 关于 `K` 非减、`U` 凹时单峰，可用三分搜索，是硬约束在 `λ→∞` 的极限。

**引理 67（段级严格强于点级：分离反例）** 存在块 `C` 与障碍 `O`，使得 v4 的逐点检查全部通过，但 `CTMC(C)` 失败。构造：二维平面中名义路径两端点 `(0,0)` 与 `(2,0)`，关节均在限位内、端点均无碰撞；障碍为圆心 `(1,0)`、半径 `0.2` 的圆盘。逐点采样 `{0,2}` 通过，但扫掠体中点 `(1,0)` 碰撞。另一构造：两路点空间距离很小但时间间隔趋于 0，则 `|ṡ|` 超 `v_max` 而端点均「可达」。因此 `CTMC ⇒ v4 点级`，反之不成立，`CTMC` 严格更强。

**引理 68（同伦应急的 anytime 安全性）** 设 `Cont(C)` 覆盖预算内所有可达同伦类且包含 `STOP`，切换代价满足 `κ ≤ κ_max`。则 GM 执行器满足安全不变式：

```text
每一步执行的动作，要么属于当前已通过 RobustSafe 与 CTMC 的前缀，
要么在执行前已切换到同样通过双证书的应急前缀，否则 STOP。
```

证明：对每一步分情况。若当前前缀仍稳健，直接执行；若管道失效或预算外，`Cont` 非空则由定义 478 给出双证书应急，`κ` 有界保证切换可完成；若 `Cont` 为空或 `κ>κ_max`，执行 `STOP`。不存在「无证书执行」分支。

**引理 69（退化等价性）** `W={0}` 或 `B=0` ⇒ `Z_t={ξ_t}`，`RobustSafe` 退化为名义轨迹的逐点碰撞检查；关闭 CCD 只查采样点 ⇒ `CTMC` 退化为 v4 `Kinematic-Loop`；`Cont=∅` ⇒ `K=1` ⇒ v4 逐步执行；`A(ℓ)` 单点 ⇒ 定义 481 退化为 v3 的 `Γ` 接地。故整条增强链在关闭开关时逐字回到 v4/v3。

**引理 70（复杂度与不可解边界）**

| 组件 | 时间 | 空间 |
|---|---|---|
| 预算校准 | `O(N_cal log N_cal)` | `O(N_cal)` |
| 管道传播 | `O(K·d·n_g)`（`n_g` 为 zonotope 生成元数，`d` 为状态维数） | `O(K·n_g·d)` |
| `K*` | `O(1)` 闭式 | `O(1)` |
| CTMC | `O(K·n_pair)`（CCD，加细粒度） | `O(K)` |
| 同伦应急选择 | `O(m·cost(CTMC))` | `O(m·K)` |
| 稳健接地 | `O(|A(ℓ)|·|H|)` | `O(|A(ℓ)|)` |

一般情形下，允许障碍任意移动且同伦类不受限的最优应急规划是 PSPACE-hard（contingency planning）；本方案只在一个**预计算的有限同伦类集**上求解，因此是多项式时间但**非完备**：可能错过预算内的可行同伦类。这是明确的表达能力边界，不是实现细节。

## 8. 本轮最大风险

**一句话**：真正决定成败的是**预算校准误差与管道保守性的乘积**——预算估小则对手在 `K` 步内击穿证书，管道估松则 `h` 被压到 1、分块收益归零；因此本轮的核心残余风险不是某个模块的精度，而是「鲁棒性-效用前沿」上是否存在一个既非空洞、又不过度保守的可部署点。
