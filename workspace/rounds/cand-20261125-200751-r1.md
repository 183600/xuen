## 1. 两个灵感的第一性原理

### 灵感 1 ·「数据集」→ 数据集是「规格 + 供应链 + 测量仪」，不是语料堆

- **数据集是规格（specification）**：它定义了任务分布本身。32 项 × 每项约 1k episode 的**刻意均衡**说明：名义规模衡量的是"重复了多少次"，而不是"覆盖了哪些轴"。真正的规格是**五轴覆盖向量** `c(D)∈[0,1]^5`（位置 / 物体 / 干扰物 / 语言 / 人为干扰）加技能原语覆盖；覆盖空洞就是**必然会暴露的失败模式**。数据工程的靶点应由覆盖空洞决定，而不是由 episode 总量决定。
- **数据集是供应链（provenance）**：数据从哪来、评测集与训练集是否共享近重复、排序是否可复现。110 项 Dex1 与 32 项挑战至少有 4 个精确同名近重复；若把全量语料当预训练集、又在挑战集上出代理分，测到的不是泛化而是**记忆**（L16）。在"人人拿得到同一份大语料"的世界里，护城河不是数据，而是**可复现的泄漏安全划分 + 选择策略**。
- **数据集是测量仪（metrology）**：有效多样性而非名义 episode 数决定数据价值。相关样本的有效样本量 `N_eff = N/(1+(N−1)ρ̄)`（L14）；高相关语料上，边际数据价值趋零，去冗余/coreset 能以很小的损失替代全集。**"我用了 110 个任务"不是卖点，"我的 N_eff 是多少、λ 是多少"才是。**
- **元教训**：上轮之所以误判"语料暂停"，是因为我们用列表 API 的截断字段当成全量。**审计数据的第一步是审计你读取数据的管道**——这正是 IP-16 的第 0 步。

### 灵感 2 ·「多机协作」→ 协作 = 共享状态 + 角色分工 + 成对约束；而它已经躺在官方数据里

- **统一抽象**：协作的对象不是"另一台机器"，而是 **N 个共享工作空间的行为体（effector）**——可以是一台 G1 的左右臂（双手协同，**在挑战面内**），也可以是两台 G1（双机清桌，**在语料里**）。协作的五件事：共享世界状态、角色/任务分解、交接（handoff）、碰撞与同步约束、伙伴故障下的鲁棒性。
- **挑战面内的最小形态是双手协同**：challenges 页明确把 "bimanual coordination" 列为 32 项覆盖范围。单机双臂 = 两个效体共享同一场景图与同一本体，是**天然的、合规的多效体问题**，不需要任何跨机通信。这让我们不必把"多机"当科幻。
- **双机语料是预训练与未来项，不是挑战捷径**：`Two_Robot_Left/Right` 各 300 eps、各 20 条指令变体、逐机分别录制，是**角色条件（左/右）**的协作演示；`DualRobot_Clean_Table` 200 eps 是双机协同原始记录。它们没有同步的联合动作标签，因此**不能直接训练集中式联合策略**；但可以学"角色条件 + 共享任务相位"的表征，作为双手协同的预训练（E638），并在挑战扩到双机时兑付（未来项，须过 Q9）。
- **技术落点是把 IP-13 从单效体扩到多效体**：`SceneState`（U16）只有单目标档案；`CoopState`（U19）加入**逐效体位姿/协方差、共享场景图、角色分配、成对约束** `Π`。当 `|E|=1` 时严格退化为 IP-13；共享状态不可用时按 P14 退化为逐效体独立 `SceneState`。这是"加深"而非"另起一套"。
- **协作要过步数账**（L15）：同步有成本、重复劳动与碰撞重试有代价；只有工作空间重叠足够高时，共享 `CoopState` 才净赚。**协作不是默认开**——低重叠任务上独立规划更省，这正是 P14 退化链存在的理由。

**策略含义**：把两个灵感合流成一句——**先把「数据 → 分数」这条测量链的泄漏与覆盖审计干净（守），再把 IP-13 从单效体扩到多效体并吃掉官方协作语料（攻）；前者决定结论真假，后者决定上行空间。**

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（覆盖与泄漏）**：32 项挑战任务相对 110 项公开语料的**近重复泄漏率 λ** 有多大？五轴覆盖向量能否预测代理评测的失败分布，并在泄漏安全划分下保持？(E634/E635)
- **Q14（有效多样性与数据预算）**：名义 33k episode 的**有效样本量 N_eff** 是多少？在固定算力下，去冗余 coreset（如 20%）能否匹配全集、从而把数据预算换成模型/评测预算？(E636)
- **Q15（多效体协作的迁移）**：把 `CoopState`（共享图+角色+成对约束）用于挑战内的双手协同能带来多少增益？双机语料（Left/Right 各 300 eps）预训练能否正迁移到双手协同，还是负迁移？(E637/E638/E639)

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（泄漏即污染 / provenance-first）**：任何代理评测结论必须报告泄漏率 λ，并只在 λ=0 的泄漏安全划分上成立；与评测任务近重复的样本不得进入训练或必须显式标记并从结论中剔除。宁可不报分，也不报被污染的分数。
- **P14（协作=共享状态+角色+成对约束）**：多效体协调必须以显式共享状态、显式角色、显式成对约束表达，禁止用端到端黑箱通道替代；共享状态不可用时退化为逐效体独立 `SceneState`（`|E|=1` 形态），协作只保留最保守碰撞约束。
- **P15（数据预算）**：数据侧的一切投入以**有效多样性/覆盖增益**计量，不以名义 episode 数计量；去冗余、coreset、泄漏安全划分是数据侧的第一优先级，先于任何生成式扩增。

## 5. 本轮最大风险

**数据泄漏造成的代理评测幻觉**：110 项公开语料与 32 项挑战任务至少 4 个精确近重复（还可能更多语义近重复），若直接用全量语料预训练再在挑战集上出代理分，测到的是**记忆而非泛化**，整条栈会在一个被系统性抬高的"幻影"上优化——而榜单尚未开放（F7），我们甚至没有真值来戳破它；这比"没有数据"更危险。对冲：P13 provenance-first + IP-16/G0 闸门（λ 全报、λ=0 划分、留一任务交叉验证）+ 语义近重复人工复核 + 预训练只用 105 项非挑战任务。次要风险：协作范围蔓延（为单机 32 项去做双机基础设施）→ 双手先行、双机仅预训练且以 E637/E638 为闸；覆盖标注主观 → 双标注 κ + 自动特征、只用于排序不作绝对分。

## 3. 新增 IP 详述

### IP-16 · DataAudit 数据审计：覆盖图谱 + 泄漏审计 + 有效多样性（P0·G0，新）

- **动机**：本轮实测发现公开语料远比上轮以为的大（Dex1 110 / WBT 55），且与 32 项挑战任务存在至少 4 个精确近重复。在榜单未开放（F7）的情况下，代理评测是我们唯一的信号源；若信号本身被泄漏污染，所有下游优化都失去意义。**必须先建立"数据 → 分数"的可信度量。**
- **与现有方案差异**：不是新模型，而是**测量层**。它输出三件可复现的"数据体温计"：①五轴覆盖向量 `c(D)`；②泄漏率 `λ` 与泄漏安全划分；③有效样本量 `N_eff` 与 coreset。它把 IP-06 从"能出分"升级为"能证明分数可信"。
- **三根支柱**：
  1. **覆盖（spec）**：对 32 项逐任务标注五轴覆盖（位置/物体/干扰物/语言/人为干扰）+ 技能原语；双标注者 κ 达标后用于排序；覆盖空洞与代理失败做秩相关，验证"洞即失败"。
  2. **供应链（provenance）**：归一化名 + 行为/视觉嵌入距离 ε 双通道检测近重复；计算 λ；生成 λ=0 的泄漏安全划分（训练只用 105 项非挑战任务；对语义近邻人工复核）。
  3. **测量仪（metrology）**：用行为嵌入两两相关 `ρ̄` 估计 ESS `N_eff`（L14）；构建去冗余 coreset，检验"小核心≈全集"。
- **技术可行性**：高。全部基于公开 metadata 与现成编码器；无接口改动；单卡小时级。
- **资源**：HF 元数据 + 32 项标注；小算力；无新增提交字段。
- **落地步骤**：①修数据情报管道（详情 API + 逐 repo `meta/info.json`，别再用列表截断字段）；②覆盖向量与双标注协议；③近重复双通道检测与 λ 估计；④泄漏安全划分；⑤N_eff/coreset（E636）；⑥**G0 闸门接入 IP-06 出分流程**（未过 G0 的出分标记为"不可信"）。
- **风险**：近重复阈值 ε 主观（用双通道交叉验证 + 人工复核边界样本）；覆盖标注噪声（κ 门槛，只作排序不作绝对分）；ESS 依赖嵌入质量（多嵌入投票）。

### IP-17 · CoopState 多效体协作状态：共享图 + 角色 + 成对约束（P1，新）

- **动机**：挑战明确包含双手协同；官方语料另有双机清桌（Left/Right 各 300 eps、DualRobot 200 eps）。v3 的 `SceneState` 只有单目标档案，无法表达"两个效体共享一个工作空间"的角色、互斥与碰撞约束。多机协作的正确落点不是另训一个联合策略，而是把状态层升级为**多效体**。
- **与现有方案差异**：`CoopState` 在 `SceneState` 上增加：逐效体位姿/协方差、共享场景图、角色分配（含 handoff）、成对约束集 `Π`（最小间距、互斥占用、同步谓词）。`|E|=1` 时严格退化为 IP-13。**双手协同**用同一台 G1 的左右臂（合规、无需跨机通信）；**双机**只做角色/相位表征预训练，跨机部署须过 Q9。
- **技术可行性**：中高。双臂碰撞约束可直接用本体运动学（无需学习）；角色条件可从 Left/Right 各 20 条指令变体中学；双手协同的评测在挑战面内。
- **资源**：Two_Robot（600 eps）+ DualRobot（200 eps）做预训练；挑战内双手协同子集做评测；小–中算力。
- **落地步骤**：①`CoopState` schema 与角色定义（左/右/交接）；②由运动学导出的成对安全约束；③handoff 谓词（何时让另一臂接管）；④挑战内双手协同 A/B（E637）；⑤双机语料角色条件预训练与迁移（E638）；⑥伙伴延迟/停摆/换角色扰动鲁棒性（E639）。
- **风险**：双机→双手**负迁移**（E638 设零容忍保护）；协作范围蔓延（双手先行，双机只预训练）；20 条指令的角色语义含糊（人工裁定 + 不确定性降级）；跨机状态共享可能违规（Q9 未清前只做离线表征）。

## 5. 符号与定义（新增 U19–U21；U1–U18 沿用第 1–3 轮）

- **定义 U19（协作状态 CoopState）**：`C = (E, r, Π, M)`；`E={e_1..e_n}` 为效体集（双臂/双机），每效体带位姿 `(x̂_e, Σ_e)`（共享参考系 F）；`r: E → Role` 为角色分配（可经 handoff 切换）；`Π` 为成对约束集 `{ 间距(e_i,e_j) ≥ d_min, 互斥占用, handoff(e_i→e_j) 的互斥锁, sync(谓词) }`；`M` 为 U16 共享场景图。`|E|=1` 时退化为 IP-13 的 `SceneState`。跨机版（不同本体共享状态）须过 Q9。
- **定义 U20（覆盖向量、有效多样性与泄漏率）**：任务/语料的覆盖向量 `c(D) ∈ [0,1]^5`，分量对应位置/物体/干扰物/语言/人为干扰，由 episode 元数据 + 标注估计；有效样本量 `N_eff = N / (1 + (N−1)·ρ̄)`，`ρ̄` 为行为嵌入两两平均相关；泄漏率 `λ = |{e ∈ D_eval : ∃ t ∈ D_train, 近重复(e,t)}| / |D_eval|`，近重复定义为归一化名相同 **或** 嵌入距离 `< ε`。
- **定义 U21（泄漏安全划分）**：将语料划分为 `(D_pretrain, D_cal, D_test)`，满足：①归一化任务名两两不交；②跨划分行为/视觉嵌入距离 `≥ ε`；③物体/实例不相交。任何代理结论必须标注其使用的划分与 `λ`（要求 λ=0）。

```python
# ===== IP-16: 数据审计（G0 闸门）=====
class DataAudit:
    def coverage(self, corpus):
        # 逐任务五轴覆盖向量；双标注 + κ
        return {task: {ax: annotate_axis(task, ax) for ax in AXES} for task in corpus}

    def near_dups(self, evalset, trainset, eps):
        out = []
        for e in evalset:
            for t in trainset:
                if name_norm(e) == name_norm(t) or emb_dist(e, t) < eps:
                    out.append((e, t))
        return out

    def leakage(self, evalset, trainset, eps):
        dups = self.near_dups(evalset, trainset, eps)
        lam = len({e for e, _ in dups}) / max(len(evalset), 1)
        return lam, dups

    def ess(self, embeddings):
        n = len(embeddings)
        rho = mean_pairwise_corr(embeddings)          # 行为嵌入相关
        return n / (1 + (n - 1) * max(rho, 0.0))      # L14

def leakage_safe_split(corpus, eval_tasks, eps):
    audit = DataAudit()
    lam, dups = audit.leakage(eval_tasks, corpus, eps)
    banned = {t for _, t in dups}
    train = [t for t in corpus if t not in banned and name_norm(t) not in {name_norm(e) for e in eval_tasks}]
    return train, lam, dups      # 只用 train 预训练；λ>0 -> G0 不通过
```

# ===== IP-17: 多效体协作状态（|E|=1 时退化为 IP-13）=====
class CoopState:
    def __init__(self, effectors, shared_scene):
        self.E = {e: EffectorState() for e in effectors}
        self.M = shared_scene                 # U16 共享场景图
        self.roles = assign_roles(effectors)  # 左/右/交接

    def update(self, obs, force=False):
        self.M.update(obs, force)             # 低频 + 事件触发
        for e in self.E:
            self.E[e].pose, self.E[e].Sigma = self.estimate(e, obs)

    def feasible(self, action_map):
        for i, j in combinations(self.E, 2):
            if min_dist(action_map[i], action_map[j]) < D_MIN:
                return False                  # 成对安全约束
            if self.roles[i] == self.roles[j] and self.roles[i].exclusive:
                return False                  # 互斥占用
        return True

    def maybe_handoff(self, pred):
        if pred:                               # 交接：角色互换 + 互斥锁
            self.roles.swap_lockstep()

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（有效多样性决定数据价值）** 设名义 episode 数 `N`、行为嵌入两两平均相关 `ρ̄`，则相关样本的有效样本量 `N_eff = N/(1+(N−1)ρ̄)`；当 `ρ̄→1`（近重复）时 `N_eff→1`，边际数据价值趋于零；当 `ρ̄→0` 时 `N_eff≈N`。泛化误差随 `1/√N_eff` 下降，故语料价值 `∝ N_eff` 而非 `∝ N`。推论：在高 `ρ̄` 语料上，按多样性抽取的 `ρ` 比例 coreset 可用远小于全集的规模逼近全集性能。∎

**引理 L15（协作的步数经济学）** 两效体共享工作空间，每 `k` 步同步一次、单步同步成本 `c_s/k`；独立规划产生重复劳动 `R` 步，并以概率 `p_c` 发生碰撞、每次重试代价 `r_c`。共享 `CoopState` 的净收益 `Δ = R + p_c·r_c − c_s/k`，角色分工可把重复劳动进一步降为 `R(1−η_role)`。协作占优 ⇔ `Δ>0` ⇔ 工作空间重叠超过阈值。⇒ **协作不是默认开**：低重叠任务上逐效体独立 `SceneState` 更省（P14 退化链）。∎

**引理 L16（泄漏对代理评测的污染）** 设评测集泄漏比例 `λ`，泄漏 episode 的记忆化成功率 `s_mem`、干净成功率 `s_clean`，则测得 `ŝ = (1−λ)s_clean + λ·s_mem`，偏差 `ŝ − s_clean = λ(s_mem − s_clean)`。当该偏差超过任意两模型真实差距的一半时，代理排名可反转。⇒ 任何代理结论必须报告 `λ`，且只在 `λ=0` 的泄漏安全划分上成立；E635 是 G0 闸门。∎
