# 第 7 轮（灵感循环第 7 轮；本轮灵感：「应用落地」×「谐波减速器」）

> **基线**：第 6 轮 MetricVoiceGauge（定义 493–520；引理 69–72；实验 E493–E512）。
> **本轮纪律**：不再增加新的输入模态，而是把已有证书链（CVC / SpatialCert / SoftCert）**压到真实关节上**。所有新组件必须在识别失败时退回 MetricVoiceGauge 的保守证书，不允许出现「只在仿真里成立」的新保证。

## 0. 直觉与动机

### 0.1 谐波减速器：一个「有记忆的弹簧」

直觉上，谐波减速器的输出不是输入的线性缩放。波发生器把柔轮撑成椭圆，柔轮每转一圈经历两次啮合周期，所以输出角误差里天然有一个**二次谐波**；齿隙与柔轮滞回让误差依赖**加载方向**（同一输入角，正转与反转的输出差出一个滞回环）；柔轮/刚轮的扭转柔度让误差随**力矩**增大；磨损与热膨胀让误差随**时间**缓慢漂移。换句话说，关节不是一个理想减速比 `1/N`，而是一个**周期项 + 滞回项 + 力矩项 + 漂移项**叠加的弹簧。这些误差量级常在角分级（≈0.1–1 mrad），在宽松任务里可以忽略，但在前几轮追求的毫米级 SpatialCert 里，它恰好落在误差预算的同一量级。

### 0.2 应用落地：证书不是结论，是合约

直觉上，「实验室里验证过的证书」常被当成可以直接搬上真机的结论。但落地意味着三件事：**单元有差异**（同一批减速器每个的误差参数不同）、**状态会漂移**（磨损、热）、**运行条件会变**（负载谱、速度）。因此证书不应是「这个策略安全」的无条件断言，而应是**带硬件假设的合约**：`Cert = (H, E, ε)`。只有当部署单元的实际误差区间 `E_u` 被实验室认证区间 `E_lab` 包含时，证书才可迁移。这样「落地」从口号变成一个**可检查的包含关系**。

### 0.3 合起来：证书—落地鸿沟

把两者放在一起，问题就清楚了：前几轮的 SpatialCert 假设 `θ_out = θ_in/N`。真实关节的传动误差 `e` 让末端位姿产生 `J·e` 的偏移。若继续用点估计，证书要么过松（把 ε 放大到失去意义），要么过紧（在真机上**静默失效**——证书说安全，实际已越界）。本轮的核心直觉是：**把传动误差当成一个可认证的区间算子，而不是噪声**；让区间在雅可比下传播，让证书携带来源假设，让降额与维护都由这个区间**反推**出来。

## 1. 研究问题（本轮要回答什么）

- **Q1（误差可证性）**：如何把谐波传动误差从「平均噪声」提升为带覆盖保证的**区间**，并把它无损失地传播到末端位姿证书？
- **Q2（证书可迁移性）**：实验室签发的证书，在什么可检查的条件下可以迁移到某一台具体部署单元，而不是整批一起打折？
- **Q3（退化与维护）**：当在线识别不可用、或误差界随磨损超出认证半径时，系统如何**一步退化**到安全状态，并把「何时维护」变成证书的推论而不是经验规则？

## 2. 三条设计原则（雏形，正式化见产物区定义 521–540）

**P7 误差即区间（Error-as-Interval）**
不对传动误差做点估计，也不把它当零均值噪声。用一个结构化的误差模型给出预测 `ê`，再用**分裂保形预测（split conformal）**在校准集上取残差分位数 `q_α`，得到 `E(x) = [ê(x)+q_{α/2}, ê(x)+q_{1-α/2}]`。只要校准样本与部署样本**可交换**，就有边际覆盖 `P(e ∈ E) ≥ 1-α`，无需假设误差服从高斯。区间随雅可比传播：`Σ_x = J·E ⊕ O(‖E‖²)`。

**P8 证书即合约（Certificate-as-Contract）**
证书显式携带硬件假设：`Cert = (H, E_lab, ε_lab)`。迁移判据是**区间包含** `E_u^env ⊆ E_lab`（在完整运行包络上取并集），而不是比较均值或标称型号。包含失败就必须重新认证；不允许「同型号所以同证书」的隐含假设。

**P9 降额即证明（Derating-as-Proof）**
安全裕度不再是一个手工调的速度上限。因为误差界 `R_u(τ, θ̇)` 对 `|τ|`、`|θ̇|` 单调，认证包络 `V_cert = {(τ,θ̇) : R_u ≤ ε_lab}` 是**下闭集**；最大降额因子 `s*` 由「使 `R_u` 回到 ε_lab 以内」反推。降额因此是证书的**推论**，而不是经验参数。

## 3. 与基线的接口（如何退化）

- 双编码器/外部位姿不可用，且相机辨识失败 ⇒ 采用出厂保守界 `E_factory`，进入 D₂（降额），等价于 MetricVoiceGauge 配一个**放大后的 ε**；
- 在线再标定超时或残差交换性检验失败 ⇒ 冻结当前区间并进入 D₂，不签发新证书；
- 误差界超出 `ε_deploy` 或 `V_cert` 为空 ⇒ 一步进入 D₃，退回 MetricVoiceGauge 的保守证书或安全停机；
- 任意新增组件失效 ⇒ 整个 DeployCert 退化为 MetricVoiceGauge + `ε' = ε + ε_max`，不产生新的安全性主张。

## 4. 预期贡献

1. 一个**传动误差区间模型**：把谐波减速器的周期、滞回、柔度、磨损四项写成可辨识、可保形校准的区间算子；
2. 一条**证书迁移合约**：用区间包含判断「实验室证书能否用于这台机器」，并给出拒绝时的再认证路径；
3. 一种**证书保持降额**：由误差界反推速度-力矩包络，把安全裕度从经验参数变成可证明约束；
4. 一条**磨损-寿命证书**：在磨损单调假设下给出认证寿命下界 `T_cert`，把预测性维护接入证书链；
5. 一组**合成模型实验**（E513–E519 已跑）：量化「用出厂标定看 100 小时后，覆盖率从 94.7% 跌到 60.0%、假安全率 40.0%」这一落地风险，并验证再标定可把覆盖率恢复到 94.8%。

## 5. 本轮最大风险

**一句话**：整套方案的安全性建立在两个统计/物理假设上——保形区间的**可交换性**（校准与部署同分布）与磨损漂移的**单调性**；一旦真实部署的温度、负载谱或跑合期让这两个假设失效，证书会在统计上「看起来合格」，却在特定单元/工况上系统性失效，形成比没有证书更危险的假安全。

## 2. 形式化定义

**定义 521（谐波传动误差区间模型 HarmonicErrorModel）**

真实输出角满足
```
θ_out = θ_in / N + e
e = e_per(θ_in) + e_hys(τ, sgn θ̇) + e_comp(τ) + e_wear(t) + η
```
其中各项满足先验界
```
|e_per| ≤ a₁ + a₂                      （二次谐波主导）
|e_hys| ≤ β                           （方向相关滞回）
|e_comp| ≤ |τ| / K_t                   （扭转柔度）
0 ≤ e_wear(t) ≤ ρ_max(1 − e^{−t/τ_w})  （单调磨损）
η ~ 未知分布，E[η]=0
```
用特征 `φ(x)` 拟合 `ê(x)=wᵀφ(x)`（`x=(θ_in,τ)`），在独立校准集 `D_cal` 上取残差 `r_i = e_i − ê(x_i)` 的经验分位数，定义
```
E(x) = [ ê(x) + q_{α/2},  ê(x) + q_{1−α/2} ]
```
**覆盖性**：若 `D_cal` 与部署样本可交换，则 `P(e ∈ E(x)) ≥ 1 − α − 1/(n+1)`。

**定义 522（落地阶梯 DeployLadder）**

```
D = (D₀, D₁, D₂, D₃)
```
- `D₀` 认证通行：`R_u ≤ ε_lab` 且 `λ_obs ≥ λ_min`，使用完整包络；
- `D₁` 在线再标定：区间收到新数据后重新校准；`R_u` 仍在 `ε_dep` 内，缩短块长、重签证书；
- `D₂` 证书保持降额：全速下 `R_u > ε_dep`，但 `V_cert(ε_dep) ≠ ∅`，投影到 `V_cert`；
- `D₃` 安全退化：`V_cert(ε_deploy) = ∅` 或可观测性失效，退回 MetricVoiceGauge 保守证书或停机。

**单调性要求**：`Capability(D_{i+1}) ⊆ Capability(D_i)`，且 `D₂ → D₃` 为**一步**转移（中间不存在半可信状态）。

**定义 523（证书迁移合约 CertTransfer）**

实验室签发 `Cert_lab = (H_lab, E_lab, ε_lab)`。对部署单元 `u`，先在运行包络 `V` 上取区间并
```
E_u^V = ∪_{x∈V} E_u(x)
```
迁移判据
```
Transfer(u) = 1  ⇔  E_u^V ⊆ E_lab  且  λ_obs(u) ≥ λ_min
```
包含是**充分**条件（保守）；拒绝时进入再认证（新 `E_u`、新 `ε`）而不是沿用型号级证书。

**定义 524（磨损-寿命证书 WearLifeCert）**

设跑合期 `[0, t_run]` 结束后 `ρ(t)` 单调不减，且 `R_u(t)` 随 `ρ` 单调不减。定义
```
T_cert(u) = inf { t ≥ t_run : R_u(t) > ε_lab }
```
维护调度在 `T_cert − Δ_m` 之前执行。由于 `R_u` 单调，`T_cert` 是真实首次越界时间的**下界**（保守）。

**定义 525（证书保持降额 CertifiedEnvelope）**

设 `R_u(τ, θ̇)` 对 `|τ|`、`|θ̇|` 单调不减（假设 A-monotone）。认证包络
```
V_cert(ε) = { (τ,θ̇) : |τ| ≤ τ_max, |θ̇| ≤ θ̇_max, R_u(τ,θ̇) ≤ ε }
```
是一族**下闭集**。降额因子
```
s* = max { s ∈ (0,1] : (τ_max s², θ̇_max s) ∈ V_cert(ε_lab) }
```
若 `s*` 不存在（包络为空）则直接 `D₃`。`s*` 是证书的推论，不是人工裕度。

**定义 526（DeployCert 组合证书与区间运动学）**

给定关节区间 `Θ = q ⊕ E^q`，末端可达集
```
X = { f(ξ) : ξ ∈ Θ }
X ⊆ box( f(q) + J̄(q,Θ)·E^q ) ⊕ B(0, L‖E^q‖²/2)
```
其中 `J̄` 是区间雅可比，`L` 是 `f` 在 `Θ` 上的 Hessian 界。定义
```
ε_pose = max_{x∈X} ‖x − f(q)‖_∞
```
SpatialCert 的判据从 `ε_vis ≤ ε_task` 改为
```
ε_vis + ε_pose ≤ ε_task
```
组合证书
```
DeployCert = ( SpatialCert, HarmonicCert=(E, J̄, ε_pose), D, T_cert, V_cert )
```

**定义 527（可观测性门 ObservabilityGate）**

- 双编码器：`e_meas = θ_out^enc − θ_in^enc / N`，观测噪声 `σ_obs = sqrt(σ_in²/N² + σ_out²)`；
- 腕部相机/外部位姿：`e_meas = L^{-1}(x_meas − f(q_nom))`，`σ_obs = σ_x / L`；
- 单样本可辨识：`|e_meas| > k·σ_obs`；`λ_obs` 为可辨识样本比例。
- 仅有电机侧编码器、无外部位姿参考时，`e` 与 `θ_out` 只以和的形式进入观测，**结构不可辨识**，必须使用先验界 `E_factory`。

**定义 528（DeployGauge 主闭环）**

在 `W→R→C→E(rt-chunk)→Spatial-C→Diag→Recover→V→U` 上追加
```
H(monitor) → E(interval) → J̄(propagate) → T(transfer) → D(ladder) → M(maintenance)
```
`H` 与主控制回路解耦，采样频率可低于 50Hz；`D` 的输出只修改 `V`（速度/力矩/块长）与证书参数，不修改任务语义。

## 3. 关键算法骨架

```python
import math

class HarmonicErrorModel:
    """IP-347 误差区间模型：结构预测 + 分裂保形校准。"""
    def __init__(self, alpha=0.05):
        self.alpha = alpha
        self.w = None          # 结构模型权重
        self.q_lo = None       # 残差下分位
        self.q_hi = None       # 残差上分位

    def features(self, theta, tau):
        return [1.0, tau, math.sin(theta), math.cos(theta),
                math.sin(2 * theta), math.cos(2 * theta)]

    def fit(self, samples):
        # samples: [(theta, tau, e_true)]
        # 正规方程 + 高斯消元（略）
        self.w = self._least_squares(samples)

    def calibrate(self, cal_samples):
        # 独立校准集；分裂保形
        res = sorted(e - self.predict(theta, tau)
                     for theta, tau, e in cal_samples)
        n = len(res)
        self.q_lo = res[max(0, int(math.floor(self.alpha / 2 * n)))]
        self.q_hi = res[min(n - 1, int(math.ceil((1 - self.alpha / 2) * n)) - 1)]

    def predict(self, theta, tau):
        f = self.features(theta, tau)
        return sum(wi * fi for wi, fi in zip(self.w, f))

    def interval(self, theta, tau):
        e_hat = self.predict(theta, tau)
        return e_hat + self.q_lo, e_hat + self.q_hi

    def radius(self, envelope):
        # R_u = max over V of max(|e^-|, |e^+|)
        r = 0.0
        for theta, tau in envelope:
            lo, hi = self.interval(theta, tau)
            r = max(r, abs(lo), abs(hi))
        return r


class DeployLadder:
    """IP-349 落地阶梯：单调、一步退化。"""
    def __init__(self, eps_lab, eps_dep, eps_max, lam_min):
        self.eps_lab, self.eps_dep = eps_lab, eps_dep
        self.eps_max, self.lam_min = eps_max, lam_min

    def decide(self, radius, lam_obs, envelope_nonempty):
        if lam_obs < self.lam_min:
            return "D2"                      # 不可观测：保守界
        if radius <= self.eps_lab:
            return "D0"
        if radius <= self.eps_dep:
            return "D1"
        if envelope_nonempty:
            return "D2"
        return "D3"                          # 一步到底


class CertTransfer:
    """IP-350 证书迁移：区间包含，而非型号默认。"""
    def __init__(self, eps_lab):
        self.eps_lab = eps_lab

    def accepts(self, e_u_env_lo, e_u_env_hi, lam_obs, lam_min):
        contained = all(lo >= -self.eps_lab and hi <= self.eps_lab
                        for lo, hi in zip(e_u_env_lo, e_u_env_hi))
        return contained and lam_obs >= lam_min


class CertifiedEnvelope:
    """IP-352 证书保持降额：由误差界反推速度-力矩包络。"""
    def __init__(self, model, eps_lab, tau_max, qd_max):
        self.model, self.eps_lab = model, eps_lab
        self.tau_max, self.qd_max = tau_max, qd_max

    def radius_at(self, s):
        # 力矩 ~ s^2（惯性主导），速度 ~ s
        tau = self.tau_max * s * s
        qd = self.qd_max * s
        r = self.model.radius([(theta, tau) for theta in self._grid()])
        return r + self._dynamic(qd)          # 速度相关项（略）

    def max_factor(self):
        lo, hi = 0.0, 1.0
        for _ in range(24):                   # 单调 => 二分
            mid = (lo + hi) / 2
            if self.radius_at(mid) <= self.eps_lab:
                lo = mid
            else:
                hi = mid
        return lo if lo > 0.0 else None       # None => D3


class StaleCertMonitor:
    """IP-354 陈旧证书监控：残差漂移检验。"""
    def __init__(self, window=500, delta=0.15, alpha=0.05):
        self.buf, self.window = [], window
        self.delta, self.alpha = delta, alpha

    def update(self, residual):
        self.buf.append(residual)
        if len(self.buf) > self.window:
            self.buf.pop(0)

    def drifted(self, q_hi_baseline):
        # 用滑动窗口上分位与基线比较；超 delta 即判漂移
        if len(self.buf) < self.window // 2:
            return False
        s = sorted(self.buf)
        q_hi_now = s[min(len(s) - 1,
                         int(math.ceil((1 - self.alpha / 2) * len(s)) - 1))]
        return (q_hi_now - q_hi_baseline) > self.delta


def deploy_cert_round(M, obs, s, ell=None):
    """IP-355/356：DeployCert 主闭环（与 MetricVoiceGauge 兼容）。"""
    # 1. 谐波监控（与主回路解耦）
    theta_in, tau = M.joint_state.read()
    theta_out = M.output_enc.read() if M.output_enc else None
    e_meas = (theta_out - theta_in / M.N) if theta_out is not None else None

    # 2. 区间预测 + 漂移检测
    e_lo, e_hi = M.harmonic.interval(theta_in, tau)
    if e_meas is not None:
        M.stale_monitor.update(e_meas - M.harmonic.predict(theta_in, tau))
        if M.stale_monitor.drifted(M.harmonic.q_hi):
            M.ladder.force_recalibrate()      # 交换性可能被破坏

    # 3. 区间运动学 -> SpatialCert 的 ε_pose
    E = [(lo, hi) for lo, hi in zip(e_lo, e_hi)]
    eps_pose = M.interval_kinematics.cert_radius(M.q, E)

    # 4. 可观测性门 + 落地阶梯
    lam_obs = M.obs_gate.rate(e_meas, M.sigma_obs)
    radius = M.harmonic.radius(M.operating_envelope)
    level = M.ladder.decide(radius, lam_obs,
                            M.envelope.nonempty(radius))

    # 5. 降额（D2）或退化（D3）
    if level == "D2":
        s_star = M.envelope.max_factor()
        if s_star is None:
            level = "D3"
        else:
            M.velocity_limit = M.qd_max * s_star
            M.effort_limit = M.tau_max * s_star * s_star
    if level == "D3":
        return M.metricvoicegauge_rtdi(obs, s,
                                       inflate_eps=eps_pose + M.eps_max,
                                       ell=ell)

    # 6. 正常路径：MetricVoiceGauge + 膨胀 ε + 证书字段
    C, spatial_cert, claims, metrics, rewards = \
        M.metricvoicegauge_rtdi(obs, s, inflate_eps=eps_pose, ell=ell)
    cert = {
        "deploy_level": level,
        "e_interval": (e_lo, e_hi),
        "eps_pose": eps_pose,
        "T_cert_h": M.wear_life.remaining(radius),
        "V_cert": (M.velocity_limit, M.effort_limit),
        "transfer_ok": M.transfer.accepts([e_lo], [e_hi], lam_obs, M.lam_min),
    }
    return C, spatial_cert, claims, metrics, rewards, cert
```

## 4. 推导

**引理 73（区间组合可靠性）**
设 `e_true ∈ E`（逐分量），`q_true ∈ Θ = q ⊕ E`，且区间雅可比 `J̄` 包含线段 `[q, q+e]` 上所有真实 `J(ξ)`。则
```
f(q_true) ∈ box( f(q) + J̄·E ) ⊕ B(0, L‖E‖²/2)
```
**证明**：对 `f` 在 `q` 处做带拉格朗日余项的一阶展开，`f(q+e) = f(q) + J(ξ)e`，`ξ` 在线段上；区间算术对 `J(ξ)e` 逐分量取包络；余项由 Hessian 界 `L` 控制。∎

**引理 74（分裂保形覆盖）**
若校准样本 `(x_i,e_i)` 与部署样本可交换，则对定义 521 的区间
```
P(e_test ∈ E(x_test)) ≥ 1 − α − 1/(n+1)
```
**证明**：标准分裂保形排序论证；测试残差在 `n+1` 个残差中的秩均匀分布，取 `⌈(n+1)(1−α)⌉` 分位即得。∎

**引理 75（迁移可靠性）**
若 `E_u^V ⊆ E_lab` 且 `Cert_lab` 对 `E_lab` 内所有误差成立，则 `Cert_lab` 对单元 `u` 在 `V` 上成立。
**证明**：证书谓词 `Safe(ε; e)` 关于误差区间**向下闭合**：`E ⊆ E'` 且 `Safe(ε;E')` ⇒ `Safe(ε;E)`。由包含关系直接得。∎

**引理 76（降额包络存在性与一步退化）**
在 A-monotone 下，`V_cert(ε)` 是下闭集且关于 `ε` 单调；`s*` 存在当且仅当 `V_cert(ε_lab) ≠ ∅`。若 `V_cert(ε_deploy)=∅`，则 `D₂→D₃` 为一步转移，不存在中间可信级。
**证明**：下闭性由 `R_u` 对 `|τ|,|θ̇|` 单调得到；二分搜索在单调函数上有定义；`D` 的定义 522 已把 `D₃` 设为空包络的唯一出口。∎

**引理 77（寿命下界）**
跑合期后若 `ρ(t)` 单调不减且 `R_u` 对 `ρ` 单调，则 `T_cert(u)` 是真实首次越界时间的下界；在 `T_cert − Δ_m` 前维护可保持证书有效。
**证明**：`R_u(t)` 单调 ⇒ 首次超 `ε_lab` 的时刻不早于 `T_cert`；维护后重置磨损参考点，证书重新生效。∎

**引理 78（退化等价）**
`D₃` 使用 `ε' = ε + ε_max` 与标称模型时，DeployCert 的证书与 MetricVoiceGauge 的证书**逐字段等价**。
**证明**：区间退化为点误差并加上先验上界；`ε_pose ≤ L·ε_max`；代入 SpatialCert 判据即得基线判据。∎

**命题 79（陈旧证书的不可靠性）**
若时刻 `t` 的磨损漂移增量 `Δρ(t)` 超过上残差分位 `q_{1−α/2}`，则陈旧校准下的覆盖率严格低于 `1−α`；在合成模型中 100h 时平均覆盖率降至 **60.0%**，假安全率 **40.0%**（见 §6）。
**证明思路**：磨损使残差分布整体右移 `Δρ`；所有满足 `e > ê + q_hi` 的样本失去覆盖，右尾质量近似为 `1−F(q_hi − Δρ)`，随 `Δρ` 单调增大。∎

**引理 80（可观测性必要性）**
仅有电机侧编码器、无外部位姿参考时，`e` 结构不可辨识；任何声称有限的认证半径都必须来自先验界。
**证明**：电机编码器观测方程只含 `θ_in`，与 `θ_out` 无关；`e = θ_out − θ_in/N` 的任意取值都不改变观测，故不可辨识。∎

### 6.1 本轮已跑：合成模型实验（E513–E519，非实机）

模型：40 个合成减速器单元，误差 = 一次/二次谐波 + 方向滞回 + 力矩柔度 + 指数磨损 + 高斯残余；`N=100`，等效力臂 `L=0.40m`，`ε_lab = 1.00 mrad`（对应 0.40mm），目标覆盖 95%，分裂保形校准 `n=3000`，测试 `n=2000`，时间点 `t=0` 与 `t=100h`。脚本：`exp/harmonic_cert_sim.py`，结果：`exp/harmonic_cert_results.json`。

| 量 | 模拟结果 | 对应实验 |
|---|---|---|
| `t=0` 平均覆盖率 / 最差单元 | **94.69% / 93.05%** | E515 |
| `t=0` 区间保守比（半径/真实最大误差） | **1.12×** | E514 |
| `t=100h` 沿用出厂标定的覆盖率 | **60.03%** | E519 |
| `t=100h` 沿用出厂标定的假安全率 | **39.97%** | E519 |
| `t=100h` 再标定后的覆盖率 | **94.83%** | E515 |
| 证书迁移接受率 `t=0 → t=100h` | **82.5% → 70.0%** | E516 |
| `t=100h` 需降额比例 / 需降额时中位 `s*` | **25.0% / 0.85** | E517 |
| 中位认证寿命 `T_cert` | **275 h** | E518 |
| 降额后仍无法满足 `ε_lab` 的比例 | **0.0%** | E517 |

**读法**：`t=0` 时区间既覆盖（94.7%≈95%）又不过度保守（1.12×），说明「误差即区间」可行；但**同一份证书在 100h 后若不再标定，覆盖率跌到 60%、40% 的样本「证书说安全而实际越界」**——这正是「应用落地」中最危险的失败模式，也是 IP-354 存在的理由。再标定把覆盖率恢复到 94.8%，代价是 30% 的单元无法维持 D₀/D₁，需要降额（D₂）或维护/退役（D₃）。

**诚实边界**：以上是合成模型，不是实机。合成模型里磨损被假设为单调、误差可交换、滞回有界；真实减速器还存在跑合期、温度耦合与载荷谱非平稳，这些会直接冲击命题 79 的前提，因此 E528–E531 必须在真机上重跑。

## 8. 本轮最大风险

**一句话**：整套方案的安全性建立在两个统计/物理假设上——保形区间的**可交换性**（校准与部署同分布）与磨损漂移的**单调性**；一旦真实部署的温度、负载谱或跑合期让这两个假设失效，证书会在统计上「看起来合格」，却在特定单元/工况上系统性失效，形成比没有证书更危险的假安全。
