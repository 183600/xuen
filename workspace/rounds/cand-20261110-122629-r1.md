# 第 44 轮（新循环第 4 轮） · Reg-Cert × Compete-Cert：把「点云配准」与「竞赛策略」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约求交为空」，但它仍压着两个未言明的单点假设：**(H5) 几何证书的坐标基准是可信的**——v20 把 LIO 输出当作精确位姿，所有几何边际都在「地图坐标系」里计算，却从未认证配准变换本身的误差；**(H6) 证书策略的选择是离线、静态、贪心的**——v20 默认「用哪条证书链（查表/INT8 监控/几何/租约）」是工程调参，而不是一个会被环境对抗性击穿的决策。本轮灵感词「点云配准」「竞赛策略」精确命中这两点：**点云配准**迫使我们承认「尺子本身有误差」，把配准变换的认证误差 ε_T 与退化指数提升为证书链条的一等量；**竞赛策略**迫使我们把「选哪条证书链、押哪个配准假设」从静态启发式提升为对抗博弈 + 无遗憾组合 + 竞速式预算分配。二者耦合处是本轮真正的新问题：对抗者恰恰就是配准失效过程，而组合学习只能保证平均遗憾、无法天然保证单次灾难性违例。

## 0. 直觉与动机

**灵感 1（点云配准 → 配准不是前端细节，而是所有几何证书的「地基」）**：直觉上，安全边际像一把尺子量出来的距离；但尺子本身若歪了 5cm，量得再精细也无意义。v20 的几何证书、交互不变集、CBF 约束都活在地图坐标系里，而进入地图坐标系的唯一通道就是点云配准。真实配准会在长廊/隧道/对称大厅退化，会被动态物体与错误闭环拉飞，收敛到错误局部极小。于是必须先认证「尺子」：在**有界噪声 + 有界离群比例**下给出变换误差上界 ε_T，用法方程条件数/信息矩阵最小特征值给出**退化指数 d_deg**，并保留**多假设集 H**（每个假设各带证书）而不是只信一个 argmax。一句话：**配准误差不消失，只能被显式膨胀进安全半径。**

**灵感 2（竞赛策略 → 不是选一个「最好的」证书器，而是在对抗中持续选一组「不被击穿」的证书器）**：直觉上，「竞赛策略」有两层：其一是**对弈**——环境/配准失效会 adversarially 选择扰动与对应点投毒，我们选择配准假设与证书链，这是一个最小最大博弈；其二是**竞速与锦标赛**——在有限仿真/认证预算下，用 successive halving 淘汰明显更差的策略，把预算集中到有希望的候选上。关键分野是：**soundness 不能被学习，只能被屏蔽（shield）**；可学习的只是效率与可用性。于是组合器在「当前已被证明 sound 的策略集」内做 EXP3/Hedge，外部遗憾 O(√(T log K)) 只用于解释效率，安全违例由屏蔽保证为零；屏蔽为空则回退到保守单策略。一句话：**学习负责更划算，屏蔽负责永不越界。**

**灵感 3（耦合 → 对抗者就是配准失效，组合动作是「配准假设 × 证书链」）**：把配准的多假设 H 与证书链组合成联合策略 π=(h, chain)。对抗者 η 在扰动集 N 内选择：对应点投毒、对称别名、动态遮挡、退化几何、错误闭环。防守方在每轮选 π，收益是安全性、时延、可用性的加权。博弈值 V*=min_σ max_η E[ℓ] 给出「最坏配准失效下仍成立」的证书要求；竞赛/竞速负责把认证预算花在刀刃上。还要补一个 v20 没管的漏洞：**错误闭环**。闭环若不经「配准-证书对齐」认证，会把一个错误变换注入整条证书链；因此闭环门控必须要求局部证书与地图证书在 ε_T 内一致，否则拒绝。

**耦合升级**：CRF（可认证配准前端）把每个配准输出变成带 ε_T/退化/多假设的证书；CSP（竞赛策略组合器）在安全屏蔽内做无遗憾选择并用认证支配做竞速淘汰；RGV（配准-认证博弈验证器）用对抗点云与博弈均衡压力测试整条链。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9 的「仿真-检索-边缘飞轮 + 人格契约层 + 并发证书层 + 可认证配准/竞赛策略层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（可认证点云配准证书）**：配准证书 R=(T̂, U, ε_T, d_deg, H)。U 为扰动集（每点噪声 ||η_i||≤σ、离群比例 ≤f、地图误差 ≤ε_map）；d_deg=λ_min(JᵀJ)/λ_max(JᵀJ) 为退化指数（J 为配准残差雅可比）；H 为经非支配筛选的多假设集。**认证语义**：∀η∈U，d_SE3(T(η), T̂) ≤ ε_T，其中 ε_T 由鲁棒残差界、离群上界与退化指数共同给出（退化处按 1/max(d_deg,d_min) 放大）。**命题**：若残差界与离群比例假设成立且 ε_map 已知，则 R 的误差上界 sound；d_deg→0 时 ε_T→∞，系统应显式拒绝而非静默输出。

**定义 45（配准感知的边际收缩与安全半径膨胀）**：设证书谓词在真实变换 T 下要求 m(T)≥θ，且 m 关于 SE(3) 是 L_reg-Lipschitz。已知 d_SE3(T,T̂)≤ε_T，则 m(T) ≥ m(T̂) − L_reg·ε_T。**配准感知守卫**：m(T̂) − L_reg·ε_T ≥ θ；等价地安全半径 r_safe ← r_safe + L_reg·ε_T。**命题（sound）**：只要 ε_T 是真上界，则守卫通过 ⇒ 真实构型下 m(T)≥θ。**推论**：配准退化不是「感知噪声」，而是可用性的直接税；ε_T 越松，可行域越窄，故必须同时优化 ε_T 的紧致性。

**定义 46（配准-认证对抗博弈）**：策略集 Π={(h,chain)}（配准假设 × 证书链），扰动集 N（投毒/别名/遮挡/退化/错误闭环）。零和重复博弈值 V*=min_{σ∈ΔΠ} max_{η∈N} E_{π∼σ}[ℓ(π,η)]，ℓ=C·1[violation]+λ_c·cost+λ_a·avail_loss。**策略 sound 性**：π 在 N 上 sound ⇔ ∀η∈N，其证书域内不产生违例。**可被利用度** Expl(σ)=max_η E[ℓ(σ,η)]−V*，作为验证器指标；正则可利用度为 0 的 σ 才是均衡候选。

**定义 47（安全屏蔽的无遗憾证书组合）**：维护已证明 sound 的策略集 Shield_t⊆Π；每轮只在 Shield_t 上用 EXP3/Hedge 依损失估计更新权重；Shield 只由证书判定增删，绝不由观测损失增删。**遗憾界**：对任意自适应对抗损失，Reg_T=∑_t ℓ(π_t,η_t)−min_{π∈Π}∑_t ℓ(π,η_t)=O(√(T K log K))。**安全命题**：若 Shield_t 判定 sound 且非空，则实际违例=0；若 Shield_t=∅ 则触发保守回退。**关键警告**：遗憾界只约束平均损失，不能阻止单次灾难；因此 soundness 必须由屏蔽与回退独立保证。

**定义 48（竞速/锦标赛预算分配与认证支配）**：候选策略/假设按置信区间 [L_t(c),U_t(c)] 维护风险界。仅当 L_t(c) > U_t(c*)（c* 为当前上界最小者）时淘汰 c，称为**认证支配**；用 successive halving 几何式分配认证预算 B。**PAC 命题**：若每轮界以 1−δ 成立且认证预算 B≥Ω((1/ε²)log(K/δ))，则以 ≥1−δ 选出与最优风险相差 ≤ε 的策略。**sound 命题**：认证支配只淘汰「可证明更差」的候选，故淘汰不会移除更安全策略；统计噪声导致的错误支配由 δ 控制并可审计。

**定义 49（配准-证书对齐与闭环门控）**：局部证书 C_local 与地图证书 C_map 在 ε_T 下 **ε-一致**，当且仅当存在 d_SE3(T,T̂)≤ε_T 使重叠区残差 ≤γ，且重叠区内不存在「局部判安全、地图判不安全且差距超过 L_reg·ε_T」的谓词冲突。**闭环门控**：仅当存在认证对齐时接受闭环并更新地图；否则拒绝。**命题**：被接受的闭环只能把 ≤ε_T 的误差引入证书链，从而错误闭环不能再绕过定义 45 的膨胀。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERTIFIED-REGISTRATION-FRONTEND（可认证配准前端 CRF）
1. **鲁棒配准 + 误差认证**：GNC/特征初值 + 多起点 ICP，输出 T̂ 与鲁棒残差；用离群上界与退化指数计算 ε_T。
2. **退化指数与拒绝语义**：监测 λ_min(JᵀJ)、可观测方向；长廊/隧道/对称场景显式标记 d_deg 并放大 ε_T 或拒绝服务。
3. **多假设证书集**：保留非支配假设 H（含正确局部极小与镜像解），每个带独立 ε_T；供下游博弈/竞速选择。
4. **认证闭环门控**：按定义 49 检查局部-地图证书一致性，拒绝未认证闭环。

### 2.2 IP-61 COMPETITION-STRATEGY-PORTFOLIO（竞赛策略组合器 CSP）
1. **安全屏蔽**：对每个 π=(配准假设, 证书链) 维护 sound 证书；屏蔽只依证书增删，不依损失。
2. **无遗憾选择**：在 Shield 内跑 EXP3/Hedge，输出策略混合；对效率/可用性给出遗憾界。
3. **认证竞速**：successive halving + 认证支配淘汰，几何式压缩认证预算。
4. **对弈接口**：接收 RGV 的对抗 witness，把被击穿策略移出 Shield 并回灌课程。

### 2.3 IP-62 REGISTRATION-CERT-GAME-VALIDATOR（配准-认证博弈验证器 RGV）
1. **对抗点云生成**：对应点投毒、对称别名、动态遮挡、退化几何、错误闭环。
2. **博弈求解与可利用度**：best-response / 遗憾最小化近似均衡，报告 Expl 与均衡间隙。
3. **多假设对抗审计**：检查错误局部极小是否被多假设覆盖、是否被认证支配误淘汰。
4. **Sim 内配准压力测试**：按退化指数/离群比例分层，产出安全-可用性曲线。

## 5. 本轮最大风险

**一句话**：安全屏蔽与配准误差上界都建立在「鲁棒配准假设（有界噪声、离群比例、退化可观测）成立」之上；一旦真实退化或投毒突破该假设，无遗憾组合只保证平均损失、无法阻止单次灾难性违例——因此 E95（ε_T soundness）与 E99（可利用度）必须设为红线，并默认回退到「保守 ε_T 膨胀 + 单一已验证配准 + 最坏情况守卫」这条永不失 sound 的底线。

## 2. 关键算法（伪代码）

### IP-60 CRF：可认证配准、误差界与闭环门控
```
def certified_registration(scan, map, U, max_hyps=8):
    hyps = robust_multistart(scan, map)          # 特征/GNC 初值 + 多起点 ICP
    certs = []
    for T in hyps:
        J   = residual_jacobian(T, scan, map)
        d   = lambda_min(J.T @ J) / max(lambda_max(J.T @ J), EPS)
        r   = robust_residuals(T)                # 截断/核加权残差
        eps = eps_residual(r, U, d, eps_map)     # ε_T≈ρ_max/sqrt(λ_min)+ε_map
        certs.append(RegCert(T, eps, d, r))
    return pareto_prune(certs)                   # 只留非支配 sound 假设

def eps_residual(r, U, d_deg, eps_map):
    # 有界离群 f 与噪声 σ 下的鲁棒界；退化处按 1/d_deg 放大
    return (max_norm(r) / sqrt(max(d_deg, D_MIN))) + sigma_bound(U) + eps_map

def certified_loop_closure(scan, map, C_local, C_map, eps_T, L_reg):
    T, eps = best_registration(scan, map)
    if eps > eps_T:
        return Reject("alignment exceeds eps_T")
    if predicate_conflict(C_local, C_map, T, L_reg * eps):
        return Reject("certificate conflict in overlap")
    return Accept(T, eps)
```

### IP-61 CSP：安全屏蔽、无遗憾选择与认证竞速
```
def shielded_exp3(strategies, T, eta):
    w = {s: 1.0 for s in strategies}
    for t in range(T):
        safe = [s for s in strategies if cert_shield_ok(s, t)]   # 仅证书判定
        if not safe:
            return conservative_fallback()                       # 空屏蔽回退
        p = normalize({s: w[s] for s in safe})
        s = sample(p)
        loss = play_and_observe(s)                                # 含对抗实现
        w[s] *= exp(-eta * loss / p[s])                           # 重要性加权
    return weighted_mixture(w)

def certified_successive_halving(cands, B, delta):
    active = list(cands)
    while len(active) > 1 and B > 0:
        per = max(1, B // len(active))
        for c in active:
            c.observe(per)
            c.L, c.U = risk_bounds(c, delta)             # 置信界
        best = min(active, key=lambda c: c.U)
        active = [c for c in active if c.L <= best.U]    # 仅认证支配才淘汰
        B //= 2
    return min(active, key=lambda c: c.U)

def update_shield(strategies, witnesses):
    # 只由证书/对抗 witness 增删，绝不因平均损失把策略移回
    for pi, eta in witnesses:
        if violates(pi, eta):
            cert_shield.remove(pi)
    return cert_shield
```

def adversarial_registration_game(strategies, adv, rounds):
    sigma = uniform(strategies)
    witnesses = []
    for k in range(rounds):
        eta = adv.best_response(sigma)      # 投毒/别名/遮挡/退化/错误闭环
        pi  = sample(sigma)
        if violates(pi, eta):

## 6. 本轮最大风险

**一句话**：安全屏蔽与配准误差上界都建立在「鲁棒配准假设（有界噪声、离群比例、退化可观测）成立」之上；一旦真实退化或投毒突破该假设，无遗憾组合只保证平均损失、无法阻止单次灾难性违例——因此 E95（ε_T soundness）与 E99（可利用度）必须设为红线，并默认回退到「保守 ε_T 膨胀 + 单一已验证配准 + 最坏情况守卫」这条永不失 sound 的底线。
