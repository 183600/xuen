# 第 44 轮（新循环第 4 轮） · Grasp-Set-Cert × Handover-Contact-Cert：把「抓取位姿多义性」与「人机接触并发」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形仅边际覆盖 + 多用户契约求交可空」，但它仍压着两个未言明的单点假设：**(H1) 抓取位姿被当作单点最优**——真实抓取位姿估计是**多峰、受对称群与遮挡支配**的分布，取 argmax 等于把尾部质量当噪声丢掉，几何证书（IP-49）只在单点上验证，真值落尾时静默不 sound；**(H2) 人机交互被当作单向意图/避障**——物理 HCI 的本质是**人与机对同一物体共同施加作用**（交接、共同操作、抢取），v20 的「并发」停在推理线程级，从未覆盖**接触级并发**（custody、力同意、接触模态切换）。本轮灵感词「抓取位姿估计」「人机交互」精确命中这两个假设：前者迫使我们把抓取从「点」升级为**带覆盖证书的对称商集**；后者迫使我们把「人」从意图分布升级为**共享物体的物理共-agent**，用保管权令牌 + 接触级 rely-guarantee 让物理并发可验证。二者耦合处——**交接瞬间**——是本轮真正的新问题：它是混合系统的模态切换点，不确定性在此达到峰值，分模式都 sound 也不保证切换点 sound。

## 0. 直觉与动机

**灵感 1（抓取位姿估计 → 「单点最优是谎言，集合覆盖才诚实」）**：一个杯子绕轴旋转任意角抓起来都一样，一个方块有多个对称等价抓法，遮挡下手部/物体的 6-DoF 估计天然多峰。若估计器只输出一个 argmax 抓取，执行器就继承了一个**未经证明的单点假设**：真实最优抓取落在尾部的概率并不为零。于是把抓取定义为**对称商空间上的集合** Ĝ_o^α，用（按对称类 × 遮挡等级的 Mondrian）共形给出覆盖 ≥1−α；但「真值在集合里」只保证位置对，不保证**每个候选都抓得稳**——所以再加**鲁棒质量证书** Q̂(Ĝ;Σ_o)：在集合与物体位姿不确定度上取最坏情形，只有 Q̂ ≥ θ_grasp 的候选才可执行。空集时不是悄悄退回 argmax，而是重定位/换姿/人工确认。

**灵感 2（人机交互 → 从「人作为扰动」到「人作为接触级并发者」）**：v20 把人类建模成意图集合 Ĥ_u^α 与动作收缩契约 Π_u，本质仍是**单向**的——机器人避让人、或按人的偏好收缩自己。但递物、共同搬抬、灵巧手交接里，人和机器人会**同时握住同一个物体**：这是共享资源的并发访问，需要**保管权令牌 χ_o**（同一时刻谁有权 committed grasp）与**接触切换原子协议**（claim→lock→establish→verify→transfer→release）。人类侧无法用形式 rely-guarantee 约束（人不会遵守证明），只能作为**受监控假设**：用共形手部模型 + 力/触觉实时校验，越界即降级串行。一句话：**机器人之间的并发靠证明，人机之间的并发靠证明 + 监控 + 快速串行化**。

**灵感 3（耦合 → 交接是混合系统切换，必须显式守卫「闭合集」）**：交接发生在接触模态从「机持」切到「人持」（或共享）的一瞬，物体位姿、手部位姿、覆盖置信度同时最差。两个模态内各自 sound 的证书，**不会自动复合到切换点**：若切换时状态不在两不变式之交，就会出现「模式内都安全、切换点掉落/挤压」的静默失效。因此引入**交接闭合集** H_close = I_pre ∩ I_post 作为重叠守卫带，只在带内允许切换；abort 必须单调（只释放/后撤，绝不带病 transfer）。

**耦合升级**：GSC（抓取集合证书）把感知不确定性编译成可执行的鲁棒抓取约束；HCR（交接接触运行时）用保管权令牌与接触级 rely-guarantee 保证物理并发安全，并把人类当作受监控假设做快速串行化；PHV（物理 HCI 验证器）在仿真中注入对称/遮挡/抢取/共同操作对抗，把反例回灌 SCV 与 CKB。四层架构由此从 v8 的「人格契约 + 并发证书」升级为 v9 的「人格契约 + 并发证书 + **抓取集合证书 + 交接接触证书**」，把可验证闭环从推理栈延伸到**物理接触面**。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（抓取位姿多义性与对称商集）**：给定物体 o 与观测 x_obs，抓取位姿 g∈SE(3) 的估计不是一个点，而是分布 P(g|o,x_obs)。物体对称群 Sym(o)⊂SE(3)（圆柱绕轴 S¹、立方体 24 阶、平面对称 Z₂…）使 g 与 s·g（s∈Sym(o)）物理不可区分。定义**规范抓取空间** G_o = SE(3)/Sym(o)，估计器输出候选集合 Ĝ_o={g_1..g_n}，多义度 H(g) 取分布熵或模态数。**命题**：若执行 argmax_g Q(g)，则对称等价类中的其它位姿与遮挡下的次优模态所承载的尾部质量被丢弃；当真值落在尾部（概率非零）时，单点证书不 sound。**推论**：必须把「选择」与「覆盖」解耦——覆盖由集合承担，选择由鲁棒质量承担。

**定义 45（分层共形抓取位姿集合）**：用 Mondrian 共形预测，按（物体类别 × 对称类 × 遮挡等级）分层维护非一致性分数。Ĝ_o^α 的半径 q 由该层秩统计给出，目标满足 P(g*∈Ĝ_o^α | 层) ≥ 1−α（**条件覆盖**，而非仅边际）。**注**：真值 g* 落入集合只说明「位置覆盖」，不代表集合内每个 g 都可安全执行——后者由定义 46 承担；两层不可互相替代。

**定义 46（鲁棒抓取质量证书）**：抓取质量向量 Q(g)=(ε_fc, μ, c_clear, m_manip, w_margin)，分别为力封闭裕度、摩擦裕度、碰撞间隙、可操作度、接触力矩裕度。物体位姿不确定度 Σ_o 经抓取帧传播。**鲁棒证书** Q̂(Ĝ_o^α;Σ_o) = min_{g∈Ĝ_o^α, δo∼Σ_o} Q(g⊕δo)。**选择规则**：a* = argmax_{g∈Ĝ} Q̂(g) 且 Q̂(g) ≥ θ_grasp 且 c_clear ≥ θ_clear；若无可执行候选，则请求重定位/换姿/人工确认，**绝不**为凑出结果而放宽阈值。**命题（集合鲁棒性）**：若对每个 g 在 Σ_o 内的最坏情形都通过阈值，且真值以 ≥1−α 概率在集合内，则执行质量达标；单点 argmax 无此保证。

**定义 47（保管权令牌与人-机接触互斥）**：共享物体 o 的保管权 χ_o∈{FREE, ROBOT, HUMAN, SHARED}。**接触互斥不变式**：χ_o=ROBOT 时人类不得处于 committed grasp，反之亦然；χ_o=SHARED 仅当共同操作证书（定义 48）激活。**接触切换协议（原子）**：claim → lock → establish → verify(H) → transfer → release；任一步 verify 失败则 abort 且**单调回退**（松手/后撤），禁止带病 transfer。这把 v20 的线程级 rely-guarantee 升为**接触级 rely-guarantee**：每个 agent 的 guarantee 是「不越权写共享物体接触状态」。

**定义 48（协商接触与共同操作证书）**：共同操作仅当 (a) 合成 wrench w_r+w_h ∈ W_o（物体可承受/易碎约束集）；(b) 各自力/速度 ≤ 人格契约的物理同意界 F_u,V_u（IP-57 扩展）；(c) 人类侧为**受监控假设**而非形式保证——用共形手部模型 Ĥ_u^α 与力/触觉实时校验，越界即降级串行。**共同操作证书** C_co = (w_r+w_h∈W_o) ∧ (w_r≤F_u) ∧ (h∈Ĥ_u^α) ∧ (χ_o=SHARED)。**注**：人机协作的 soundness 是「带监控假设的」，不是无条件的——这是它与纯机器并发（定义 40）的本质区别。

**定义 49（交接闭合集与接触切换 sound 性）**：交接是混合系统在接触模态间的切换。定义**交接闭合集** H_close = I_pre ∩ I_post，仅当状态处于其**重叠守卫带**内才允许切换。**交接不变式** H：∃g∈Ĝ_o^α, Q̂(g)≥θ_fc；人类在舒适包络内；无意外接触；χ_o 一致；分层覆盖 ≥1−α。**定理（交接闭合 sound 性）**：若 (1) 切换前 I_pre 成立；(2) 切换原子且只把状态从 I_pre 移到 I_pre∩I_post；(3) abort 单调（只释放/后撤），则任意接触切换不产生掉落/挤压/碰撞，即使 Ĝ_o^α 多峰。**引理（不连续风险）**：分别在两模态 sound 的两个证书**不能**自动复合到切换点——必须显式用 H_close 守卫，否则称「模式内 sound、切换点静默不 sound」。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 GRASP-SET-CERT（抓取集合证书 GSC）
1. **对称商集估计**：按 Sym(o) 把候选抓取商化到 G_o=SE(3)/Sym(o)，保留多峰而非塌缩为 argmax。
2. **分层共形覆盖**：按（物体类别 × 对称类 × 遮挡等级）做 Mondrian 校准，输出 Ĝ_o^α 与半径 q。
3. **鲁棒质量证书**：在集合与 Σ_o 最坏情形上算 Q̂；只放行 Q̂≥θ_grasp 且碰撞间隙达标的候选，空集走协商/重定位。
4. **与几何证书求交**：Ĝ_o^α ∩ C_geom（IP-49）∩ Π_u（IP-57），三者交集为空即停，不静默放宽。

### 2.2 IP-61 HANDOVER-CONTACT-RUNTIME（交接接触运行时 HCR）
1. **保管权令牌表**：每个共享物体维护 χ_o 与版本号，claim/release 走原子 CAS，杜绝双方的 committed grasp 交叠。
2. **接触切换状态机**：claim→lock→establish→verify→transfer→release；verify 不过即 abort 且单调回退。
3. **共同操作证书闸门**：合成 wrench ∈ W_o、各自力/速度 ≤ F_u/V_u、人类受监控；任一不满足即降级为串行。
4. **受监控假设降级**：共形手部覆盖失效或力越界时，立即撤销 SHARED、回到单方 custody，绝不“相信人不会动”。

### 2.3 IP-62 PHYSICAL-HCI-VALIDATOR（物理交互验证器 PHV）
1. **对称/遮挡 fuzz**：按对称群与遮挡等级批量生成抓取位姿歧义场景，测条件覆盖与尾部失效。
2. **接触并发 fuzz**：枚举 claim/transfer/release 交错，做 token 竞态与撕裂检查。
3. **人类抢取对抗采样**：快速抓取、假动作、交接中途松手、遮挡下换手、物体替换。
4. **Sim-to-real 抓取差距**：在 Isaac Sim + 真机测覆盖迁移与掉落率，差距超阈即回退单点保守抓取。

## 5. 本轮最大风险

**一句话**：交接 soundness 依赖**接触切换瞬间的混合模态连续性**，而最危险事件是「对称/遮挡导致的歧义抓取 ∧ 手部遮挡 ∧ 人类抢取」在测度零的切换点上的**联合尾部事件**——若 H_close 守卫带被实现误差、时钟抖动或渲染延迟吞掉，方案会在「每个模式都 sound」的假象下于交接瞬间静默失效，因此 E97/E99 必须设为红线并默认回退「固定夹具串行交接」。

# 第 44 轮产物 · 创新点清单 v21：Grasp-Set-Cert × Handover-Contact-Cert（GSC × HCR × PHV）× 可验证物理交互闭环（四层架构 v9）

> 承接第 43 轮产物 v20。本轮**增量插入** IP-60/61/62，并升级 IP-45/47/49/50/51/52/53/54/55/56；不推倒任何既有层级。核心是把 v20 的「个性化 + 推理并发」闭环，延伸到**物理接触面**：抓取位姿由单点升级为**带覆盖证书的对称商集**，人机交互由单向意图升级为**共享物体的接触级并发**，并用交接闭合集把混合模态切换纳入可验证范围。

## 2. 关键算法（伪代码）

### IP-60 GSC：对称商集、分层共形与鲁棒选择
```
def grasp_set_certificate(o, obs, alpha):
    cls  = classify_object(o)
    sym  = symmetry_group(o)                 # S1 / 24阶 / Z2 ...
    G    = [canonicalize(g, sym)             # 商到 SE(3)/Sym(o)
            for g in estimator_grasps(o, obs)]
    layer = (cls, sym_class(sym), occlusion_level(obs))
    q     = quantile(calibration_scores[layer], 1 - alpha)   # 秩统计
    return GraspSet(candidates=G, radius=q, coverage=1 - alpha)

def robust_grasp_certificate(Ghat, Sigma_o, theta_grasp, theta_clear):
    best = None
    for g in Ghat.candidates:
        Q = None
        for dO in sigma_samples(Sigma_o):     # 位姿不确定度传播
            q = quality(g, dO)                # 力封闭/摩擦/间隙/可操作度
            Q = q if Q is None else componentwise_min(Q, q)
        if Q.epsilon_fc >= theta_grasp and Q.c_clear >= theta_clear:
            if best is None or dominates(Q, best.Q):
                best = Candidate(g, Q)
    return best                               # None => 无认证抓取

def certified_grasp_select(Ghat, Sigma_o, C_geom, Pi_u, ...):
    best = robust_grasp_certificate(Ghat, Sigma_o, ...)
    if best is None or not subset(best.reach, intersect(C_geom, Pi_u)):
        return request_reposition_or_human_confirm()   # 绝不放宽阈值
    return best
```

### IP-61 HCR：保管权令牌、接触状态机与共同操作
```
def contact_transition(obj, agent, state):
    # 原子接触切换；只允许从 H_close 重叠带内 transfer
    if not compare_and_claim(obj.token, expected=FREE_or(agent)):
        return Wait                         # 接触互斥：他人持有时不抢
    lock(obj.token, agent)
    if not handover_invariant(state):
        monotone_abort(obj); release(obj.token); return Abort   # 只释放/后撤
    establish_contact(obj)
    if not stable_force_closure(obj):
        monotone_abort(obj); release(obj.token); return Abort
    if not in_closure_set(state, H_close):
        monotone_abort(obj); release(obj.token); return Abort   # 切换点守卫
    transfer_custody(obj.token, agent)
    release(obj.token)
    return Ok

def co_manipulation_admit(w_robot, w_human, W_o, F_u, V_u, human_state):
    if (w_robot + w_human) in W_o \
       and norm(w_robot) <= F_u and norm(v_robot) <= V_u \
       and human_state in human_hand_alpha_set:      # 受监控假设
        return SharedContact()
    return Serialize()                               # 越界即降级串行

def handover_invariant(state):
    return (exists_g(state.Ghat, lambda g: robust_Q(g) >= theta_fc)
            and within_comfort_envelope(state.human)
            and not unexpected_contact(state)
            and custody_consistent(state.token))

def monotone_abort(obj):
    # abort 只允许释放/后撤，绝不新增接触或加力
    open_gripper_soft(obj); retreat_along_safe_axis(obj)
```

### IP-51/53 升级：抓取-交接感知的自动机与监控
```
def car_transition_guard_v9(e, x, cert_obj, persona, lease, grasp_set, token, t):
    theta    = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_cap    = persona_cap[e](persona)
    q_robust = robust_grasp_certificate(grasp_set, Sigma_o(x), ...)
    custody_ok = (token.owner in custody_allowed(e))
    return (min(m_lookup, m_lease, m_cap) >= theta
            and lease_valid(lease, theta, t)
            and q_robust is not None and q_robust.q >= theta_grasp
            and custody_ok)

def monitor_contact_snapshot(state):
    # 力/触觉 + 接触模态的一致性快照；模态与令牌不符即降级
    e1 = state.epoch; snap = state.value; e2 = state.epoch
    if e1 != e2:
        return downgrade_contact(state)          # 撕裂读 -> 撤销 SHARED
    if snap.mode == SHARED and not co_manipulation_admit_ok(snap):
        revoke_shared(state)
    return snap
```

## 6. 本轮最大风险

**一句话**：交接 soundness 依赖**接触切换瞬间的混合模态连续性**，而最危险事件是「对称/遮挡导致的歧义抓取 ∧ 手部遮挡 ∧ 人类抢取」在测度零的切换点上的**联合尾部事件**——若 H_close 守卫带被实现误差、时钟抖动或渲染延迟吞掉，方案会在「每个模式都 sound」的假象下于交接瞬间静默失效，因此 E97/E99 必须设为红线并默认回退「固定夹具串行交接」。
