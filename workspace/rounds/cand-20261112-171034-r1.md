# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环（新）第 1 轮；本轮灵感：「人机协作」×「通信延迟」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 让场景成为阻抗先验、CIEC 把意图锁定为实时约束、EPIR 保证 EV-exec 消息完整性、SERC 统一闭环、PCE++++ 扩展认知预算。但**三处「时间盲区」**在本轮必须被揭开：
> 1. **CIEC 把人类当成瞬时意图预言机**：它假设「收到意图」等于「意图此刻为真」，既没有人的反应时延、注意力与信任建模，也没有意图在通信途中漂移的模型。通信延迟一旦存在，机器人执行的其实是**人若干百毫秒之前的想法**——「认知先行」可能变成「用旧认知驱动新状态」。
> 2. **EPIR 只保证证据「最终完整」，不保证「及时有效」**：丢包/乱序被修复了，但一条 500ms 后才到达的接触事件，其数值再正确也已是**过期证据**；在协作中「迟到证据」与「丢失证据」同样危险，因为机器人与人对「现在」的认知已经错开。
> 3. **SERC 没有「共享权限与共同基础」**：它优化场景→约束，却没有刻画谁在决策、人此刻能知道什么、谁该为一次动作负责。延迟会制造**责任真空**（两人都以为对方在做）与**共同基础破裂**（机器人已经切换模式，人还停留在旧模式），而第 60 轮没有任何机制检测「静默分歧」，也没有审计「静默权限转移」。

## 0. 直觉与动机

**灵感 1（人机协作 → 人类协作状态模型 HCSM）**
直觉：人不该被建模成一张意图查找表，而应被建模成一个**有惯性、有延迟、会疲劳、会建立信任的随机同伴**。机器人维护对人的信念 h_t=(β_t, λ_t, ρ_t, w_t, κ_t)：意图后验 β、反应时延分布 λ、对机器人的信任 ρ、工作负荷 w、指令一致性 κ。关键洞见：**SSM 给的是「场景先验」，HCSM 给的是「人的意图先验 + 意图漂移核 T^d」**——正是第 60 轮 CIEC 缺失的那一项。有了 T^d，机器人才能在意图消息在途的 d 毫秒里预测「人下一步大概想要什么」，而不是傻等或误用旧值。

**灵感 2（通信延迟 → 通信延迟语义 CDS）**
直觉：每条消息不是「当前状态」，而是**一份关于过去某时刻的、带误差棒的声明**。延迟 d=t_recv−t_emit 与新鲜度 s=t−t_emit 必须成为一等公民。意图是有「半衰期」的：'危险' 应长有效期并快速触发，'轻触' 则在任务推进后迅速失效。关键洞见：**契约必须投影到 x̂(t+δ̂) 的预测安全集，而不是消息到达时刻的安全集**；且用 d_hi（延迟上界）而非均值做安全投影，把时钟偏移、队列抖动都计入裕度 m_d。

**灵感 3（人机协作 × 通信延迟 → 时序共同基础 TCG）**
直觉：协作真正需要的不是「共享同一状态」，而是「共享同一段**可知**状态」。定义共同基础视界 H_cg(t)=t−D_up(t)，D_up 取人→机、机→人、云同步三条链路上界延迟的最大值。任何其含义依赖「比 H_cg 更新的事件」的动作，都必须走 announce-and-wait：先广播新状态，等人确认（往返 2·D_up）后再执行。关键洞见：**这是「你看到我看到的东西了吗」的时间版本**；它把第 60 轮 EPIR 的「消息因果一致」升级为「**认知因果一致**」。

**灵感 4（延迟下的契约 → 延迟感知契约 DAC + 预测共享控制 PSC）**
直觉：既然意图会迟到、会过期，就不该「收到即生效」，而应签发一份**带签发时刻、有效期、epoch、延迟裕度、来源的契约**。契约有效期内默认履行；过期未续则回退基线或请求确认。当契约已 stale 而任务仍在推进时，机器人用 HCSM 预测人的意图，在**约束空间**里做加权融合（而非动作空间混合，避免绕过安全集），并让权限权重 w 随信任、staleness、意图熵变化。关键洞见：**预测共享控制只能「在硬安全集内更聪明地跟随人」，永远不能「替人扩大安全集」**。

**灵感 5（等待还是行动 → 协作延迟预算 CLB / PCE+++++）**
直觉：延迟语境下，**等待有时是安全，有时是危险**。该等一条 80ms 的澄清，还是立刻按保守策略动？这是一个 VOI 问题：VOI_wait(τ)=E[收到消息后行动的效用]−U(立即行动)−λ_w·τ−λ_h·1[询问]−λ_r·risk(τ)。若为正且在截止期内且还有「人类注意力预算」，就等/问；否则按预测共享控制行动。关键洞见：**人的注意力是比算力更稀缺的预算**，必须显式建 B_human，否则机器人会用无穷追问把协作拖死。

**灵感 6（协作取证 → 协作证据链 CAC + 时序分歧修复 TDR）**
直觉：事故复盘时最关键的问题不是「机器人是否合规」，而是「**在它动作的那一刻，人可能知道什么、它是否有权这么动**」。因此把 EPIR 从「消息完整性」扩展为「**决策溯源**」：记录意图签发/接收时刻、应用契约、延迟、预测、权限权重、信任快照，并用哈希链锚定。同时在线监测时序分歧 D_cg=KL(β_robot‖β_human)+staleness 偏差+ACK 超龄；一旦 D_cg>θ_cg，按成本从低到高执行修复阶梯：减速→播报→询问→接管→安全保持。关键洞见：**要专门检测「延迟诱发的假一致」——双方都以为对方知道，其实谁都不知道**。

**灵感 7（合流 → HALO 人机延迟感知协同闭环）**
直觉：HCSM 预测「人想要什么」，CDS 判定「这条意图是否还作数」，TCG 回答「人此刻能知道什么」，DAC 把有效意图固化成带时效的契约，PSC 在契约 stale 时于硬安全集内跟随预测意图，CLB 决定「等/问/动」，CAC 留下责任证据，TDR 修复认知分歧。形成闭环：**人意图→(延迟)→HCSM→CDS→TCG→DAC→PSC→执行→CAC→TDR→共同基础修复**，把第 60 轮的「认知先行」修正为「**在共同基础上的、延迟感知的认知先行**」。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（人类协作状态模型 HCSM）** 人的隐状态 ξ_t=(i_t, θ_t)，其中 i_t∈I 为意图，θ_t=(λ_t, ρ_t, w_t, κ_t) 为反应时延、信任、负荷、指令一致性。机器人维护信念
b_t^h = P(ξ_t | m_{1:t}) = (β_t, π_t(λ), ρ_t, w_t, κ_t)。
- **意图漂移核**：β_t^- = T^d(β_{t-d})，即把 d 步意图转移算子作用在「签发时刻的后验」上，显式补偿消息在途期间的意图演化。
- **观测更新**：β_t ∝ P(m_t | i_t)·β_t^-；λ_t 用观测到的指令响应时延做对数正态在线标定；ρ_{t+1}=clip(ρ_t+η_ρ·(r_t−E_h[r]),0,1)。
- **人的策略模型**：P(a_t^h | ξ_t, s_t)，供预测共享控制积分使用。
关键：HCSM 输出的不是单一意图，而是**「意图后验 + 其随延迟漂移的速率」**，这是后续 τ_valid 与权限权重 w 的输入。

**定义 162（通信延迟语义 CDS）** 消息 m=(seq, t_emit, t_recv, payload, hash)。经时钟偏移 θ_c 校正后，延迟 d∈[d_lo,d_hi]（含排队抖动与时钟偏斜）。在决策时刻 t 的新鲜度 s=t−t_emit。
- **意图有效期**：用漂移风险 h_I(s)=P(i_t≠i_emit | s) 定义，τ_valid(I)=h_I^{-1}(ε_drift)。'危险' 取长有效期 + 短响应截止；'轻触' 取短有效期（任务推进后即失效）。
- **可采纳性**：Adm(m,t) ⟺ [s ≤ τ_valid(I)] ∧ [d_hi ≤ τ_deadline(I)] ∧ hash_ok。
- **延迟补偿投影**：C_emit(t)=Π_{K_safe(x̂(t+δ̂))}(C)，其中 δ̂=d_hi（保守取上界）。
- **致命语义**：过期意图不得「夹带生效」；只可触发「再确认」或回退默认约束。

**定义 163（时序共同基础 TCG）** 令 D_up(t)=max{δ̂_hr, δ̂_rh, δ̂_sync} 为各链路上界延迟，则
H_cg(t)=t−D_up(t)。
事件 e∈CG(t) ⟺ t_emit(e) ≤ H_cg(t)。**认知滞后** L_e(t)=t−H_cg(t)。
- **共同基础一致**：机器人应用的有效契约，其签发时刻必须落在 CG(t) 内；否则该动作属于「静默权限转移」。
- **announce-and-wait**：模式切换等语义动作需先 announce，再等 ACK，最短握手时长 2·D_up。
- **静默分歧**：机器人在事件进入 CG 之前改变了共享状态，且未收到 ACK。

**定义 164（延迟感知契约 DAC）** 契约 c=(id, epoch, C, prov, t_emit, t_expire, m_d, τ_valid, auth)。
- **事件时间优先**：冲突按 (t_emit, epoch) 解析，**绝不按到达时间**，保证重放/乱序下语义不变。
- **有效约束**：C_eff(t)=⋂_{c∈Live(t)} Π_{m_d}(c.C; x̂(t+δ̂))，Live(t)={c | t_emit ≤ t ≤ min(t_emit+τ_valid, t_expire)}。
- **承诺语义**：有效期内默认履行；安全可抢占但必须置 safety_preempt 旗标并播报；过期契约自动失效并触发续签或回退。

**定义 165（预测共享控制 PSC）** 人意图预测 p̂(a_h|s_t,b_t^h,δ)=∫P(a_h|ξ,s_t)b_t^h(ξ)dξ。
- **权限权重**：w_t=σ(α(1−ρ_t)+β·s/τ_valid+γ·H(β_t))，并硬性截断 w_t∈[0, w_max]（w_max<1）。
- **约束空间融合**：C_soft=w_t·C_pred+(1−w_t)·C_human；**最终动作集 A_t = A(C_hard(t) ∩ C_soft)**。
- **不扩权原则**：预测只能收窄或平移软约束，**永远不能扩大硬安全集**；预测不确定时以裕度收缩代替猜测。

**定义 166（协作延迟预算 CLB 与 PCE+++++）** B_lat=(B_comm, B_human, B_predict, B_sync, B_exec)。
- B_comm：重传/心跳额度；B_human：澄清询问次数（人类注意力）；B_predict：意图预测算力；B_sync：时钟同步质量；B_exec：原执行预算。
- **延迟 VOI**：VOI_wait(τ)=E_{m~pending}[U(act|m)]−U(act|now)−λ_w·τ−λ_h·1[query]−λ_r·risk(τ)。
- **决策**：若 VOI_wait>0 ∧ τ≤τ_deadline ∧ B_human>0 ⇒ WAIT/ASK；否则 ACT（PSC）。
- **降级**：σ_δ>θ_δ ⇒ 膨胀 m_d、收缩 K_safe；B_human 耗尽 ⇒ 降 w_max、减速、只保持；B_comm 耗尽 ⇒ 本地自主 + 缓存播报、重连后对账；B_sync 恶化 ⇒ 扩大 D_up、更多 announce-and-wait；B_predict 耗尽 ⇒ 用未过期显式契约，过期即 HOLD。

**定义 167（协作证据链 CAC）** 记录 CE=(t_emit, t_recv, t_apply, seq, intent, C_emit, C_eff, delay, H(b_t^h), prediction, w_authority, action, safety_preempt, hash_prev)，按 episode 成链。
- **协作合规谓词**：CC(a,t) ⟺ safety_preempt(a) ∨ ∃c∈Live(t): t_emit(c) ≤ H_cg(t) ∧ a∈A(C_eff(c,t))。
- **审计目标**：任意动作都能回答「人当时可能知道什么、依据哪份契约、以多大权限执行」；把 EPIR 的消息完整性升级为**决策溯源完整性**。

**定义 168（时序分歧修复 TDR）** 分歧度
D_cg(t)=KL(β_t^robot‖β_t^human)+|L_e(t)−L_e^expected|/τ_norm+1[ack_age>D_up]。
当 D_cg>θ_cg，按修复阶梯 R=[SLOW, ANNOUNCE, ASK, HANDOVER, HOLD] 选择 argmax_r ΔD(r)/cost(r)，受 B_human 约束；HOLD 恒可用，保证不死锁。
- **延迟诱发假一致**：双方均以为对方已知，但 ack_age>D_up 或检测到静默分歧；必须用主动 ACK 探测而非假设。

**定义 169（HALO 人机延迟感知协同闭环）** 算子 HALO(M, task, m_intent)：
```
① CDS.stamp(m_intent) → m；HCSM.update(m)
② 若 CDS.Adm(m, now)：c ← DAC.issue(HCSM.map(m.intent), m.t_emit, τ_valid(I), m_d)
③ H_cg ← TCG.horizon(now)；若 TDR.diverged(H_cg)：repair ← TDR.repair()
④ d ← CLB.wait_or_act(pending=m, deadline, HCSM)
⑤ 若 d==WAIT：m' ← wait()；goto ②
⑥ C_eff ← DAC.effective(contracts, now, x̂(now+δ̂))
⑦ a ← PSC.act(s, HCSM, C_eff, w_t)  // 硬安全集内
⑧ execute(a)；CE ← CAC.record(m, c, b_t^h, a, w_t, safety_preempt)
⑨ SERC.update(scene, EV-exec, CE)；返回 (a, C_eff, CE)
```

### IP-161 HCSM（人类协作状态模型）

```python
class HumanCollaborationStateModel:
    def __init__(self, intents, reaction_prior):
        self.beta   = {i: 1.0/len(intents) for i in intents}
        self.react  = reaction_prior            # LogNormal(mu, sigma)
        self.trust  = 0.5
        self.load   = 0.5
        self.consist= 0.8
        self.T      = self._intent_transition() # Markov kernel

    def drift(self, delay):
        # 关键：意图在消息在途期间会漂移，作用 d 步转移核
        b = dict(self.beta)
        for _ in range(int(delay / self.tick)):
            b = {j: sum(self.T[i][j]*b[i] for i in b) for j in b}
        return b

    def update(self, msg, delay):
        self.beta = self.drift(delay)
        lik = {i: self._obs_likelihood(msg.intent, i) for i in self.beta}
        self.beta = self._normalize({i: self.beta[i]*lik[i] for i in self.beta})
        self.react.update(max(delay, 1e-3))
        self.trust = clip(self.trust + 0.1*(msg.reward - 0.5), 0.0, 1.0)

    def intent_entropy(self):
        return -sum(p*math.log(p+1e-9) for p in self.beta.values())
```

### IP-162 CDS（通信延迟语义）

```python
class DelaySemantics:
    def __init__(self, sync):
        self.offset, self.sigma = sync.offset, sync.sigma

    def delay_interval(self, m):
        d = (time.time() - m.t_emit) - self.offset
        return (max(0, d - 3*self.sigma), d + 3*self.sigma)

    def admissible(self, m, t, tau_valid, tau_deadline):
        d_lo, d_hi = self.delay_interval(m)
        age = t - (m.t_emit + self.offset)
        return (age <= tau_valid) and (d_hi <= tau_deadline) and m.hash_ok

    def compensate(self, C, t, d_hi, x_hat):
        # 保守：投影到延迟上界时刻的预测安全集
        return project_safe(C, x_hat(t + d_hi))
```

### IP-163 TCG（时序共同基础）

```python
class TemporalCommonGround:
    def __init__(self, links):            # links: hr, rh, sync
        self.links = links

    def horizon(self, t):
        return t - max(l.upper_delay for l in self.links.values())

    def in_cg(self, event, t):
        return event.t_emit <= self.horizon(t)

    def announce_and_wait(self, event):
        self.broadcast(event)
        return self.wait_ack(timeout=2*self.links['rh'].upper_delay)
```

### IP-164 DAC（延迟感知契约）

```python
class DelayAwareContract:
    def issue(self, C, prov, t_emit, tau_valid, margin):
        self.epoch += 1
        return Contract(id=next_id(), epoch=self.epoch, C=C, prov=prov,
                        t_emit=t_emit, t_expire=t_emit+tau_valid, m_d=margin)

    def effective(self, contracts, t, x_hat):
        live = [c for c in contracts if c.t_emit <= t <= c.t_expire]
        live.sort(key=lambda c: (c.t_emit, c.epoch))   # 事件时间优先
        if not live:
            return None
        return intersect(project_safe(c.C, x_hat(t+c.m_d)) for c in live)
```

### IP-165 PSC（预测共享控制）

```python
class PredictiveSharedController:
    def act(self, s, hcm, C_eff, t):
        C_hard = hard_safe_set(s)
        if C_eff is None or self.is_stale(C_eff, t):
            a_pred = self.predict_human(s, hcm)
            w = clip(sigmoid(0.8*(1-hcm.trust) + 0.5*self.staleness(t)
                             + 0.3*hcm.intent_entropy()), 0.0, self.w_max)
            C_soft = blend(constraint_of(a_pred), constraint_of(C_eff), w)
            C = C_hard & C_soft                     # 不扩权
        else:
            C = C_hard & constraint_of(C_eff)
        return argmax_{a in A(C)} expected_utility(a, s)
```

### IP-166 CLB（协作延迟预算 / PCE+++++）

```python
class CollaborationLatencyBudget:
    def __init__(self, comm, human, predict, sync, exec_budget):
        self.B = dict(comm=comm, human=human, predict=predict,
                      sync=sync, exec=exec_budget)

    def wait_or_act(self, pending, deadline, hcm):
        if pending is None:
            return 'ACT'
        tau = pending.d_hi
        voi = (self.expected_gain(pending) - self.cost_now()
               - 0.2*tau - 0.3*self.risk(tau))
        if voi > 0 and tau <= deadline and self.B['human'] > 0:
            self.B['human'] -= 1
            return 'WAIT'
        return 'ACT'

    def degradation(self, sigma_d):
        if sigma_d > self.theta_d:
            return 'inflate_margin'      # 收缩 K_safe
        if self.B['human'] <= 0:
            return 'reduce_authority'    # 降 w_max、减速
        if self.B['comm'] <= 0:
            return 'local_autonomy'
        return 'normal'
```

### IP-167 CAC（协作证据链）

```python
class CollaborationAuditChain:
    def record(self, msg, contract, belief, action, authority, preempt):
        ce = dict(t_emit=msg.t_emit, t_recv=now(), t_apply=now(),
                  seq=msg.seq, intent=msg.intent,
                  C_emit=contract.C if contract else None,
                  C_eff=self.last_eff, delay=self.last_delay,
                  belief_hash=hash_state(belief), authority=authority,
                  action=action, safety_preempt=preempt, prev=self.tail)
        ce['hash'] = sha256(canonical(ce))
        self.chain.append(ce); self.tail = ce['hash']
        return ce

    def audit(self, t, H_cg):
        for ce in self.chain:
            if ce['safety_preempt']:
                continue
            ok = any(c.t_emit <= H_cg(t) and ce['action'] in safe(c, t)
                     for c in self.contracts)
            if not ok:
                return ('SILENT_AUTHORITY_TRANSFER', ce)
```

```python
class TemporalDivergenceRepair:
    LADDER = ['SLOW', 'ANNOUNCE', 'ASK', 'HANDOVER', 'HOLD']

    def diverged(self, beta_robot, beta_human, ack_age, D_up):

            score = self.delta_d(r, d) / self.cost(r)

        return best[1] if best else 'HOLD'
```

## 2. 关键形式化与推导

**延迟补偿的保守性**：设真实状态 x(t)，预测 x̂(t+δ̂)。若预测误差满足 ‖x̂−x‖≤ε_x(δ̂)，则把契约投影到 K_safe(x̂(t+δ̂)) 并对 ε_x 追加鲁棒裕度 m_d=m_0+c·ε_x，可保证 x(t)∈K_safe 的充分性。由此得**延迟单调性**：δ̂↑ ⇒ ε_x↑ ⇒ m_d↑ ⇒ K_safe↓；当 δ̂→0 时恢复第 60 轮包络。

**意图有效期推导**：设意图漂移为风险率 h_I(s) 的生存过程，P(i_t=i_emit | s)=exp(−∫_0^s h_I(u)du)。令其 ≥1−ε_drift 得 τ_valid(I)=max{s | ∫_0^s h_I(u)du ≤ −ln(1−ε_drift)}。对 '危险' 取 h_I 小（长有效期）但 τ_deadline 短（快响应）；对 '轻触' 取 h_I 大（短有效期）。

**等待-行动最优性（VOI）**：设 pending 消息 m 到达后能带来的期望效用增益为 ΔU(m)，等待时间 τ。则
VOI_wait(τ)=E[ΔU(m)]−λ_w·τ−λ_h·1[ask]−λ_r·risk(τ)。
仅当 VOI_wait>0 且在截止期内、且仍有 B_human 时才等待；否则按 PSC 行动。该式是第 60 轮 VOI_cog 在时间维度上的对偶。

**共同基础一致性定理**：若动作 a 所依据契约 c 满足 t_emit(c)≤H_cg(t)，则人最迟在时刻 t 已具备获知 c 的条件（A68），故 a 不会依赖「人不可能知道的事件」。反之 t_emit(c)>H_cg(t) 的动作即静默权限转移。

**协作合规谓词**：CC(a,t) ⟺ safety_preempt(a) ∨ ∃c∈Live(t): t_emit(c)≤H_cg(t) ∧ a∈A(C_eff(c,t))。它把「安全」与「知情同意」统一进一个可审计布尔式。
