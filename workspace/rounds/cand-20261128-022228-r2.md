### 第 5 轮灵感驱动研究记录

**灵感词**：面部表情识别、UniBot-V1

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（空间 3DCF、物理 MSRG、人因 HICK、末点 EEK、记忆 LTEM，加联邦 FFA）之上加入价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4，fail-closed；执行集 Exec_CADVS-v4 ⊆ v3 ⊆ v2 ⊆ v1 ⊆ Exec_v29。本轮不推翻 v4，而是引入两条「弱证据、高能力」通道——面部表情识别（FER）与统一机器人基座模型 UniBot-V1——并用同一设计原则驯服它们，形成 CADVS-v5（IP-493~496），执行集嵌套升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **面部表情识别：把「人因锚」从显式否决扩展到隐性不适**。v4 的 HICK 依赖手势/语音/显式 veto，捕捉不到「人还没来得及说、但脸上已出现疼痛/恐惧/困惑」的早期信号。引入面部情感证书 AFC，用校准后的 FER（含 conformal 不确定度、跨人群分组校准）输出舒适/不适连续得分 α_aff 与疼痛/恐惧/困惑/信任子概率。但关键不是「再加一个更强的感知器」，而是**承认表情是内在状态的弱代理**：表情 ≠ 内在状态（masking、alexithymia、文化显示规则），且可被主动伪装。因此把 kc_aff 设计为**单侧门（veto-only）**：它只能否决/软化（检测到可能的负性情感即保守处理），**绝不能用于放行**任何被物理/人因/平衡锚拒绝的执行。单侧门保证：即便 FER 有偏，最坏也只是过度保守，而不会出现「因为对方笑了所以判定安全」的致命误判。

2. **UniBot-V1：把「提议」与「认证」彻底分离**。UniBot-V1 是一体化视觉-语言-动作（VLA）基座策略，能给出强泛化的动作提议，但其输出不可验证、可能受分布漂移/提示注入/后门影响。引入 UniBot 提议桥 UPB：UniBot-V1 只负责**提议候选**（Propose），所有候选仍须穿过 v5 全部硬门（Certify）。执行集 = 提议集 ∩ 认证集。于是得到**能力-安全正交性**：换更强/更弱的提议器，安全边界由认证器决定、几乎不变；更强提议器只是在已认证安全集内提高召回与任务成功率。同时禁止**自我认证**：UniBot-V1 不能同时充当自己提议的 fallback 教师（递归信任），教师必须来自独立锚点（物理/独立人类通道）或异模型。

3. **统一原则：能力可以增加，权威不能增加（capability without authority）**。FER 是「只能减」的否决通道，UniBot-V1 是「只能在认证集内加」的提议通道。两者都不扩大安全执行集，因此单调收缩定理继续成立。这把 v4 的「加硬门」升级为「加通道但守边界」的可扩展范式：未来再接入任何弱信号/强模型，只需判定它是 veto-only 还是 propose-only，即可保证安全边界不被侵蚀。

**关键洞见**：v4 回答「覆盖/物理/人因/末点/记忆/价值/平衡」；v5 追问「人因里那些未被说出口的不适（表情）能否被安全地纳入」以及「通用基座模型能否被安全地使用」。答案是：可以，但必须剥夺其权威——FER 只准否决、UniBot 只准提议。八硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_aff（kc_aff 为单侧否决门，仅作合取中的否决项），执行集 Exec_v5 = Propose_UB ∩ Certify_v5。

**形式化目标（增量）**：
1. 定义面部情感证书 AFC = (α_aff, p_pain, p_fear, p_confusion, p_trust, u_unc, cov_g, high_conf_negative, t)，单侧硬门 kc_aff = (¬high_conf_negative)，软因子 η_aff = α_aff。
2. 定义 UniBot 提议桥 UPB：提议集 Propose_UB(o,ℓ) = {a : π_UB(a|o,ℓ) ≥ τ_prop}；提议证书 PC = (candidates, conf, prov, t)；提议须经 Certify_v5。
3. 定义单侧证据原则与能力-安全正交定理：Exec_v5 = Propose_UB ∩ Certify_v5 ⊆ Certify_v5 ⊆ Exec_v4；安全概率只依赖 Certify，与提议器能力无关。
4. 定义禁自证/接地定理：认证证据须与提议器误差在给定真实状态下条件独立，否则能力越强的错误教师会诱发相关假证书。
5. 定义 conformal 情感风险控制与分组覆盖：边际漏检 ≤ α，分组（Mondrian）漏检 ≤ α，代价是分组校准集变小导致预测集变宽。
6. 定义 EFA-v5 八硬门 + 软评分 ECS_v5 = ECS_v4 · η_aff · η_prop（η_prop 为提议可信度，缺省 1）。
7. 定义 Exec_CADVS-v5 ⊆ Exec_CADVS-v4：新增 kc_aff（只缩）与提议集求交（只缩），故只缩不涨。

**本轮最大风险**：把面部表情当作「人因证据」的根本脆弱性——表情 ≠ 内在状态、跨文化/跨个体/跨人群的系统性偏差与可伪装性，使「基于表情的不适否决」既可能系统性漏检真实疼痛（安全/公平失败），又可能过度否决而损害可用性，并带来面部生物特征隐私与合规风险。

### IP-493 FACK：面部情感证书（异步 ~20–40 ms，控制环只读缓存）

```python
@dataclass
class FacialAffectiveCertificateKernel:
    """FACK：校准 FER + conformal 不确定度 + 分组覆盖；kc_aff 为单侧否决门（只准否决，不准放行）"""
    tau_neg: float = 0.5          # 负性情感高置信阈值
    tau_unc: float = 0.2          # 不确定度容忍上限，超限进入保守软化
    alpha: float = 0.1            # conformal 漏检率上界
    groups: tuple = ("adult", "elder", "child")   # 分组校准（端侧匿名，标签不联网）
    on_device: bool = True        # 原始图像/视频不出端

    def evaluate(self, frames: list[Frame], context: Context, t_now: float) -> AFC:
        # 1) 端侧 FER：表情类别分布 + 动作单元强度（原始帧不出设备）
        probs = self.fer.infer(frames)     # {neutral,happy,sad,fear,pain,anger,confusion}
        # 2) 不确定度：预测熵 + 集成方差 + OOD 检测
        u_unc = self._uncertainty(probs, frames)
        # 3) conformal 校准：分组（Mondrian）预测集 C_alpha
        g = self.group_of(context)
        C_alpha = self.conformal.predict_set(probs, g)
        # 4) 单侧判定：高置信负性 或 不确定且非零负性 → 保守视为负性
        p_neg = self._negative_mass(probs)             # pain+fear+强不适
        hcn = (p_neg >= self.tau_neg) or (u_unc > self.tau_unc and p_neg > 0.3)
        alpha_aff = 1.0 - p_neg                         # 舒适得分（仅软层惩罚）
        return AFC(alpha_aff=alpha_aff, p_pain=probs["pain"], p_fear=probs["fear"],
                   p_confusion=probs["confusion"], p_trust=probs["neutral"],
                   u_unc=u_unc, cov_g=self.conformal.coverage(g), hcn=hcn, t=t_now)

    def kc_aff(self, afc: AFC) -> bool:
        """单侧否决门：True 仅表示“未检测到高置信负性情感”，绝不构成放行授权。
        最终放行仍由其余七门决定；任何把 kc_aff 当正向证据的调用视为接口违规。"""
        return not afc.hcn

    def conservative_soften(self, afc: AFC) -> float:
        """负性/不确定 → 返回阻抗软化系数 κ ∈ (0,1]；仅用于收缩，不用于放行。"""
        return 0.6 if afc.hcn else (0.85 if afc.u_unc > self.tau_unc else 1.0)

    def _uncertainty(self, probs, frames) -> float: ...
    def _negative_mass(self, probs) -> float: ...
```

### IP-494 UPB：UniBot-V1 提议桥（提议 ≠ 认证）

```python
@dataclass
class UniBotProposerBridge:
    """UPB：UniBot-V1 仅提议，不认证；执行集 = 提议集 ∩ Certify_v5"""
    policy: Any = None                  # UniBot-V1 VLA 基座策略（或端侧蒸馏小模型）
    tau_prop: float = 0.05              # 提议阈值（低阈值保召回）
    distilled_rules: RuleLibrary | None = None

    def propose(self, obs, lang, t_now) -> ProposalCertificate:
        # 1) 基座模型前向：动作 token / 轨迹 / 技能序列（可能含不可验证输出）
        raw = self.policy.act(obs, lang)
        # 2) 候选集 = top-k 采样 ∪ 已蒸馏规则候选 ∪ DAKI 规则候选
        candidates = (self._topk(raw, k=8)
                      | (self.distilled_rules.candidates(obs) if self.distilled_rules else set()))
        # 3) 提议证书只声明来源与置信，不声明安全
        return ProposalCertificate(candidates=candidates, conf=self._conf(raw),
                                   prov=hash_model(self.policy), t=t_now)

    def distill(self, certified_traj: Trajectory, cert_snapshot: CertSnapshot):
        """把“由 UniBot 提议且通过全部硬门”的轨迹蒸馏为符号规则，进入 DAKI 候选池；
        蒸馏产物仍走正常准入，绝不直接授予执行权。"""
        if not cert_snapshot.all_passed:
            return
        self.distilled_rules.add(self._to_symbolic(certified_traj), source="unibot")

    # 关键：不存在 policy 直接返回“可执行”的路径；所有输出必须经 EFA-v5.certify
```

### IP-495 CERTCALC-v5：单侧证据与信任代数（离线理论，不在控制环）

```python
def theorem_capability_safety_orthogonality() -> str:
    """
    定理 5（能力-安全正交）：设 Propose_π(o) 为提议器 π 的候选集，Certify_v5(x) 为八门认证集。
    Exec_v5(π) = Propose_π(o) ∩ Certify_v5(x)。
    则 ∀π,π′：Exec_v5(π) ⊆ Certify_v5 ⊆ Exec_v4；
    安全概率 P(unsafe | Exec_v5(π)) 与 π 无关，仅由 Certify_v5 的可靠度决定；
    更强的 π 只提高 |Propose_π ∩ Certify_v5|（认证集内召回），不改变安全上界。
    证明：交集对第一项单调（∩ 只会缩小）；Certify_v5 ⊆ Exec_v4 由 v4 认证集继承；
    由归纳假设 P(unsafe | Certify_v5) ≤ ε 与 π 无关。
    前提：认证器 sound（见定理 6 的接地条件）。
    """
    return "Proven (conditional on verifier soundness)"

def theorem_no_self_certification() -> str:
    """
    定理 6（禁自证/接地）：设认证证据 E 与提议器误差 ε_T 在给定真实状态 s 下条件独立
    （E ⊥ ε_T | s，假设 B8）。则 P(unsafe | cert) 的安全界由 E 决定，与 T 的错误率无关。
    反之，若 E 依赖 T（如用 T 自身置信度/自身蒸馏产物作证书），则存在“能力越强、错误越相关”
    的对抗教师，使 P(unsafe | cert) 随 T 能力上升而上升（相关假证书）。
    推论：UniBot-V1 不得作为其自身提议的 fallback 教师；教师须来自独立锚点或异模型。
    证明：独立情形下误差项可分解且交叉项为零；相关情形构造 ε_T 与 E 共线的反例。
    """
    return "Proven (independence vs. correlated counterexample)"

def theorem_conformal_affect_risk() -> str:
    """
    定理 7（conformal 情感风险）：在可交换性（B7）下，split conformal 预测集满足
    P(Y ∈ C_α) ≥ 1−α，故单侧否决的漏检率 P(pain ∧ kc_aff=True) ≤ α。
    分组（Mondrian）校准下，∀g：P(miss | g) ≤ α，代价是 |C_α| 增大约 O(√(log(1/δ)/m_g))。
    分布漂移破坏可交换性 → 需加权 conformal / 在线重校准，否则界失效（保守方向仍安全）。
    """
    return "Proven (exchangeability; drift caveat)"

def theorem_one_sided_evidence() -> str:
    """
    定理 8（单侧证据不扩张）：设 kc_aff 仅以合取项进入认证（Certify_v5 = Certify_v4 ∧ kc_aff），
    Propose_UB 仅与认证集求交（Exec_v5 = Propose_UB ∩ Certify_v5）。
    则无论 FER 的偏差/UniBot 的能力如何，Exec_v5 ⊆ Exec_v4 恒成立；
    弱通道只能在既有安全集内“减”或“选”，无法“加”。
    """
    return "Proven (set monotonicity)"
```

### IP-496 EFA-v5：八硬门 + 提议集交 + 软评分

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：八硬门 fail-closed（kc_aff 单侧否决）；执行集 = Propose_UB ∩ Certify_v5
    软评分 ECS_v5 = ECS_v4 · η_aff · η_prop"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    fack: FacialAffectiveCertificateKernel
    upb: UniBotProposerBridge
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec: EEC, bcc: BCC, afc: AFC,
                  object_class, geo_sig, theta_domain_fp, traj, context) -> tuple[bool, str]:
        # 优先级：HIC 显式 veto > kc_aff 隐式否决 > 其余六门（并行评估，任一失败即拒）
        if self.hic.veto_active(hic):          return False, 'HIC_STOP'
        if not self.fack.kc_aff(afc):          return False, 'AFFECT_NEGATIVE'
        if not self.scf.kc_coverage(x, t_now): return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):            return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc):           return False, 'BALANCE_UNSTABLE'
        pass_mem, eta_mem, novelty = self.ltem.query(object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                       return False, 'MEMORY_REJECT'
        vac = self.vack.evaluate(traj, context, t_now)
        if not self.vack.kc_val(vac):          return False, 'VALUE_MISALIGNED'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def certify(self, pc: ProposalCertificate, obs, ctx, **kw) -> list:
        """执行集 = Propose ∩ Certify：逐候选认证，返回被认证子集。"""
        accepted = []
        for a in pc.candidates:
            ok, _ = self.hard_gate(a, ctx.t_now, a.rule_id, ctx.hic, ctx.eec, ctx.bcc,
                                   ctx.afc, ctx.object_class, ctx.geo_sig,
                                   ctx.theta_domain_fp, a.traj, ctx)
            if ok:
                accepted.append(a)
        return accepted

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5, eta_aff=1.0, eta_prop=1.0) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        return base * eta_mem * eta_val * eta_bal * eta_aff * eta_prop
```

```
  FER(frames) ──▶ conformal(分组) ──▶ AFC ──▶ kc_aff（只读缓存进控制环）

  EFA-v5.certify(ProposalCertificate, ...)：
    Exec_v5 = Propose_UB ∩ Certify_v5
      ├─ HIC_STOP           → S_stop（显式最高优先）
      ├─ AFFECT_NEGATIVE    → 阻抗软化(κ)/减速/拉开距离 + 教师    ← 新增（单侧）
      ├─ COVERAGE_BLIND     → 回退 STCK + 独立教师
      ├─ PHYSICS_UNPROVEN   → 规则降权
      ├─ EE_UNPROVEN        → 末端复位/重触 + 教师
      ├─ BALANCE_UNSTABLE   → 阻抗软化/回退姿态 + 教师
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| FACK.evaluate（FER 推理） | O(F·d_fer) | O(d_fer) | F=帧数, d_fer=视觉主干维度 | ~20–40 ms（异步，端侧 NPU） |
| FACK.kc_aff | **O(1)** | O(1) | — | < 0.01 ms/周期（读缓存） |
| UPB.propose | O(L_ctx·d_vla + k) | O(d_vla) | L_ctx 上下文长度, k=8 | ~30–200 ms（异步/低频） |
| UPB.distill | O(L_traj) | O(规则数) | — | 离线/秒级 |
| Certify_v5 逐候选 | O(\|C\|·1) | O(\|C\|) | \|C\|≈8 | < 0.2 ms（8 候选 × O(1) 门） |
| EFA-v5 单门 | **O(1)** | O(1) | — | < 0.03 ms |
| 端到端在线增量（控制环） | **O(1)** | — | 仅读缓存 AFC/BCC/EEC | **< 0.1 ms（v5 新增通道全异步）** |

**通信开销**：AFC 仅 8 维证书（端侧计算，原始帧不出设备）；PC 候选集 + 来源哈希 ~1–4 KB/次（低频）；FFA Δ_i 增加分组情感统计（DP 聚合量）与提议校准参数 ~1–2 KB/站点。

**实时性缓解**（回应 v4 的最大风险）：
- 情感与提议通道**完全移出 1 kHz 控制环**：FER 异步出 AFC，UniBot 低频出 PC，控制环只读缓存并做 O(1) 门判定；v5 不再增加控制环预算。
- UniBot-V1 可端侧蒸馏为小策略 + 规则，云端大模型仅离线蒸馏/低频提议。

## 4. 正确性论证（增量更新）

### 引理 43（conformal 情感风险与分组覆盖）

**陈述**：在校准集与部署分布可交换（B7）下，split conformal 预测集 C_α 满足 P(Y ∈ C_α) ≥ 1−α。定义单侧否决：仅当 C_α 不含任何疼痛状态时 kc_aff 才可放行，则漏检率 P(pain ∧ kc_aff=True) ≤ α。分组（Mondrian）校准下，对每个组 g 有 P(miss | g) ≤ α，且 |C_α^{(g)}| 随校准样本 m_g 以 O(√(log(1/δ)/m_g)) 增宽。

**证明**：由 conformal 的边际覆盖保证；单侧否决把「预测集含疼痛」映射为拒绝，故漏检 ⊆ 未覆盖事件。分组情形对每组独立套用；有限样本修正用 Clopper–Pearson / Hoeffding 得增宽项。∎

**工程含义**：把「表情→不适」从不可靠的硬分类变为**带分布无关漏检上界**的保守否决；分组校准显式约束跨人群公平性（至少不漏检）。漂移时界失效，但保守方向仍安全（宁可误拒）。

### 引理 44（能力-安全正交）

**陈述**：设认证集 Certify_v5 ⊆ Exec_v4，提议集 Propose_π(o)。则 Exec_v5(π) = Propose_π(o) ∩ Certify_v5 ⊆ Exec_v4，且对任意提议器 π、π′ 有 P(unsafe | Exec_v5(π)) = P(unsafe | Exec_v5(π′))，只要两者都满足认证 soundness。

**证明**：交集单调性给出包含关系；不安全事件只可能来自 Certify_v5 的误放（认证不可靠），与提议器无关；提议器只决定在安全集内的取舍。∎

**工程含义**：可放心升级 UniBot-V1 而不担心「越强越危险」；安全投入应集中在认证器（锚点）而非提议器。

### 引理 45（禁自证/接地）

**陈述**：若认证证据 E 与提议器误差 ε_T 在给定真实状态 s 下条件独立（B8），则 P(unsafe | cert) 的安全界与 T 的错误率无关。若 E 依赖 T（自证），存在对抗教师使 P(unsafe | cert) 随 T 能力上升而上升。

**证明**：独立时 P(unsafe|cert) = Σ_s P(unsafe|s)P(s|E)，ε_T 的边缘化不改变该式；相关时构造 ε_T 与 E 共线，令高置信错误被同源证据「背书」。∎

**工程含义**：UniBot-V1 不能给自己的提议当教师；fallback 教师必须是独立人类/异模型，证书必须锚定独立物理/人类证据。

### 定理 v5（单侧证据下的严格收缩与八锚点扩展）

**陈述**：在 (B1)~(B6) 继承 v4，新增 (B7) 情感可交换性、(B8) 认证接地 下：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4（严格，若 kc_aff 非恒真且 Propose_UB ≠ 全动作空间）；
(ii) 情感漏检率 ≤ α（边际）且分组 ≤ α（引理 43）；
(iii) 能力-安全正交（引理 44）：安全与提议器能力无关；
(iv) 禁自证/接地（引理 45）：教师不可自证；
(v) 单侧证据不扩张（定理 8）：FER/UniBot 只能减或选，不能加；
(vi) 八锚点 {3DCF,MSRG,HICK,EEK,LTEM,VACK,BCK,FACK} 中 FACK 为**单侧锚**：只补「隐性人因否决」，不承担放行，故其不完备不破坏其余七锚的 soundness。

**证明**：(i) Certify_v5 = Certify_v4 ∧ kc_aff ⊆ Certify_v4，且 Exec_v5 = Propose ∩ Certify_v5 ⊆ Certify_v5；严格性由 kc_aff 非恒真（存在负性样本）与提议集非全域给出。(ii) 引理 43。(iii) 引理 44。(iv) 引理 45。(v) 定理 8。(vi) 由单侧门定义，FACK 仅出现在合取否决位。∎

**诚实声明**：(B7) 在真实部署中常被违反（人群/光照/文化漂移），conformal 界会失效；此时仅保留「保守方向安全」，公平性无法保证。(B8) 要求认证证据与基座模型误差独立，但若锚点本身由同一基座模型生成（如用 UniBot 标注训练 MSRG），独立性被破坏——必须审计数据血缘。FER 的「表情≠内在状态」是**不可消除**的语义鸿沟，单侧门只能限制其危害，不能使其成为可靠的正向证据。

## 7. 本轮最大风险（最终确认）

**一句话**：**把面部表情当作「人因证据」的根本脆弱性**——表情 ≠ 内在状态，跨文化/跨个体/跨人群的系统性偏差与可伪装性，使「基于表情的不适否决」既可能系统性漏检真实疼痛（安全/公平失败），又可能因过度否决而损害可用性，并伴随不可回避的面部生物特征隐私与合规风险；单侧门只能限制其危害，无法把弱代理变成可靠证据。
