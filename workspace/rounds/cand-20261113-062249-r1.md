# 第 3 轮迭代（灵感循环 v3：「开源硬件」×「力矩控制」）—— 位置接口下的"隐式力觉"：把摸不到的东西算出来

> **一句话直觉**：v2 的旗舰 RHPV-D 用"看"来判断步骤是否被撤回；但插网线、拧瓶盖、拉拉链、叠毛巾这些最值钱、最接触密集的步骤，恰好是"手挡住眼睛、物体透明、动作细微"的地方——**看得见的时候不需要判，需要判的时候看不见**。本轮两个词指向缺失的模态：力/力矩。但把官方接口翻到底会发现一个硬事实：**评测只给你位置（关节角、末端位姿、夹爪开合），既不给力矩/电流，也不收力矩；动作是位置目标；一次调用的整块动作会被完整执行、中途不能抢占**。所以"力矩控制"不能字面照搬，只能**从"我命令的位置"与"它实际到达的位置"之间的跟踪误差里，把力反算出来**，再用开源硬件的 URDF/动力学与低成本测力台做物理锚定。本轮核心动作：**把不可观测的力矩，变成可计算的隐式力觉**。（承接状态文件中的 v2，本轮按循环推进计为 v3。）

## 1. 上轮清单诊断（v3 该动哪里）

- **旗舰升级 UIP-01′ → UIP-01″**：撤回检测从"纯视觉"升级为**视觉（物体级）+ 隐式力觉（接触级）双通道**。理由：`human_*` 撤回有两种情形——(a) 机器人正握着物体被反向拉走（力可测）；(b) 物体被移走而机器人没接触（只能看）。单通道必然漏检。
- **升级 UIP-09′、UIP-11、UIP-12**：分别获得力觉判据、接触力真值、力标注的扰动回放。
- **修剪 UIP-13**：`action_chunk_size` 全局固定（F4），"自适应块长"改为**块长选型 + 块内安全尾**；这也暴露了一个此前没算清的账：**块长既决定反应延迟，也决定力觉采样率**。
- **升级 UIP-15**：导纳控制/力触发修正会制造动作抖动，必须加"平滑 + 速率限 + 权限上限"，否则可信度判罚会吃掉收益。
- **新增（命中两词）**：UIP-16 IHFT（隐式力/力矩观测器）、UIP-17 PAAC（位置空间导纳 + 力引导接触原语）、UIP-18 WFPP（力/功进度原语）、UIP-19 OHTL（开源硬件测力孪生台）。
- **封存不变**：UIP-04（世界模型 MPC）、UIP-10（joint/ee 双空间仲裁）继续封存；`control_space` 全局二选一（F6）进一步坐实 UIP-10 封存。

## 2. 两个灵感词的解读（先直觉，后定义）

### 2.1 「力矩控制」

**直觉**：机器人"使了多大劲"是它与世界之间最直接的物理量。看到的是结果，摸到的是过程。插入是否到底、瓶盖是否拧动、拉链是否卡住、物体是否在手里打滑——这些在力信号上都是一条条有形状的曲线。

**严谨定义（在本接口约束下）**：本赛题不允许下发/回传力矩（F1/F2），因此"力矩控制"被重新定义为两层：

1. **隐式力矩观测**：由已知指令位置 `q*_t` 与实测位置 `q_t` 的偏差，结合开源 URDF 的动力学模型，估计外部广义力 `τ̂_ext(t)`（扰动观测器），并投影为末端 6D 力旋量 `f̂_ext = (J⁺)ᵀ τ̂_ext`；
2. **位置空间导纳控制**：不直接改力矩，而是把估计到的外力映射成**位置目标的偏置** `Δx`，让位置环"表现得像弹簧-阻尼"，从而在位置接口上实现柔顺与力引导。

### 2.2 「开源硬件」

**直觉**：真机贵、不可反复试、且不给力标签；但"力"这件事，物体的力指纹是**物体固有的**（插头多紧、拉链多涩、瓶盖多少牛·厘米），不是机器人固有的。所以用便宜、可改、可标定的开源硬件做出**物体的力真值**，再迁移到 G1，是性价比最高的一条路。

**严谨定义**：开源硬件在本方案中承担三种角色：

1. **动力学先验**：开源 URDF/关节限位/传动比 → 反算力所需的 `M(q), C(q,q̇), g(q)` 与归一化尺度（含 `pivot`/腰部的额外自由度）；
2. **测力标定台**：开源 MCU + 称重传感器/编码器 + 3D 打印道具 → 逐物体的"力-位移 / 力-角度"指纹真值，以及 `(q*, q_obs, force)` 三元组用于标定隐式观测器；
3. **扰动回放与 HIL**：小型开源机械臂/舵机按 `human_*` 文本复现"反向撤回"并记录力/时序；把策略接到真控制率的台架上测延迟与抖动，补 Gazebo 的接触保真缺口。

## 3. 瓶颈假设（v3）

- **H1（可观测性，最高风险）**：跟踪误差只有在低层位置环"足够软"时才携带力信息；若位置环很硬，`q_t → q*_t`，误差被刚度和量化噪声淹没，隐式力觉失效。
- **H2（互补性）**：力只能感知"接触中的撤回"；物体被移走而机器人未接触时只能靠视觉。双通道缺一不可。
- **H3（带宽=块长）**：整块执行不可抢占（F6），力反馈的采样/反应率约为 控制频率/`T_a`；小 `T_a` 换来反应性却抬高往返次数与延迟暴露面。
- **H4（可信度反噬）**：导纳与力触发修正是"非平滑"动作源；动作统计规律性异常会被判罚，必须限幅、低通、速率限制。
- **H5（跨体迁移）**：物体的力指纹跨本体可迁移；机器人特定的 `K_p`、摩擦、重力项不可迁移，必须逐体标定或在策略内学习残差。

## 5. 本轮最大风险（一句话）

**最大风险：若 G1 低层位置环过硬、跟踪误差被刚度与量化噪声淹没，隐式力觉在本接口上不可观测，则 v3 的整条力觉链路建立在无法验证的假设上——所以第 1 周必须先做 E201 可观测性 go/no-go，失败就退回纯视觉，并让力信号只做离线分析。**

## 1. 接口现实核查：为什么必须"反算"力

| 需要的能力 | 接口是否提供 | 结论 |
|---|---|---|
| 读取关节力矩/电流/腕部 F-T | ❌ 观测目录无此键（F1） | 不能直接测力 |
| 读取关节速度 | ❌ 无，只有位置 | 用时间堆叠帧做差分/滤波 |
| 下发力矩或阻抗参数 | ❌ 动作只有位置/位姿目标（F2） | 只能做"位置空间导纳" |
| 读取夹爪力 | ❌ 只有开合位置 | 用"命令开合 vs 实测开合"做滑移/夹持代理 |
| 运行期改块长 | ❌ 形状必须严格等于 `(T_a,…)`（F4） | `T_a` 全局选型，块内预留安全尾 |

## 2. 旗舰深潜：UIP-01″ · RHPV-DF

### 2.1 双通道验证器

- **视觉通道** `V_img(o_t, l, g_k)`：判物体级状态 ∈ `{done, ongoing, regressed, occluded}`。沿用 v2 的几何/语言规则，零额外模型。
- **力觉通道** `V_ft(q*_{t-1}, q_t, g_k)`：判接触级状态 ∈ `{no_contact, contacting, opposing, jam, slip}`。其中 `opposing` = 外部力旋量沿"该计分步的负进度方向"持续做功；`jam` = 轴向力高而位移≈0；`slip` = 夹爪实测开合增大且负载高。

### 2.2 融合决策表（把"撤回"与"卡住"分开）

| 视觉 | 力觉 | 决策 | 理由 |
|---|---|---|---|
| done | any | `advance`（若 contact 未释放则先 `release`） | 物体级已完成 |
| regressed | any | `redo` | 直接证据 |
| occluded/ongoing | **opposing** | `redo`（高置信） | 接触级撤回：人正把物体拉回 |
| occluded/ongoing | **jam** | `not redo` → `wiggle/reverse_small` | 卡住≠撤回，重做只会更糟 |
| ongoing | contacting | `continue` | 正常接触推进 |
| ongoing | no_contact | `continue`；若视觉也 occluded → `reobserve` | 双盲时先退一点恢复视野（预算内） |
| regressed | opposing | `redo`（最高置信） | 双通道一致 |
| occluded | opposing | `redo` | 力通道单独足够（接触中） |

> 关键分辨：**"被撤回"与"插不进去"在力上是相反符号的**——撤回是外力沿负方向做负功；卡住是机器人自己沿正方向持续做功而位移停滞。v2 只有"失败"一个标签，会把两者混为一谈。

### 2.3 状态机（块边界执行）

```python
class RHPVDF_Policy:                 # UIP-01″ = 双通道验证 + 16 + 17 + 13′ + 15+
    def reset(self):
        self.policy.reset()
        self.k = 0                   # 当前计分步索引
        self.hist_cmd = []           # 我们发过的指令位置（算跟踪误差用）
        self.redo = 0
        self.buf = None
        self.pending = None          # 上一块最后一步的指令（对齐观测）

    def get_action(self, obs):
        # 1) 用"上一块末步指令 vs 当前实测"更新力觉观测量
        w_hat, contact, states = self.ihft.update(self.pending, obs)   # UIP-16
        # 2) 双通道判定当前计分步
        vis = self.v_img(obs, self.lang, self.k)
        ft  = self.v_ft(states, self.g_k)                              # UIP-18
        decision = self.fuse(vis, ft)                                  # §2.2 表
        if decision == "advance":  self.k += 1; self.redo = 0
        if decision == "redo" and self.redo < self.max_redo: self.redo += 1
        if decision in ("wiggle", "reobserve", "release"):
            return self.safe_tail(decision, obs)                       # 小动作，整块返回
        # 3) 生成标称块 + 位置空间导纳修正
        nom = self.policy.get_action(obs)                              # (T_a, …)
        if contact and self.need_compliance(self.k):
            nom = self.paac.apply(nom, w_hat, obs)                     # UIP-17
        return self.guard(nom)                                         # UIP-15+
```

## 3. UIP-16 · IHFT（Implicit Haptic Force/Torque observer）

### 3.1 推导：从跟踪误差到外部力

设关节指令 `q*`、实测 `q`，低层位置环近似 PD：

```text
τ_act = K_p (q* − q) + K_d (q̇* − q̇) + τ_ff
```

刚体动力学：

```text
M(q) q̈ + C(q, q̇) q̇ + g(q) + τ_ext = τ_act
```

于是外部广义力（扰动观测器）：

```text
τ̂_ext = K_p (q* − q) + K_d (q̇* − q̇) + τ_ff − [ M(q) q̈ + C(q, q̇) q̇ + g(q) ]
```

- `M, C, g` 来自开源 URDF（G1 + Dex1），`τ_max` 来自关节额定/峰值力矩 → 归一化 `ẽ = τ̂_ext / τ_max`；
- `q̇, q̈` 由时间堆叠观测做 **Savitzky–Golay 差分**（比裸差分抗量化噪声）；
- `K_p, K_d` 未必公开 → 用对角可学习尺度 `α_j` 吸收：`τ̂_ext,j = α_j(q*_j − q_j) + β_j − model_j`，`α, β` 在 OHTL/Gazebo 上标定；
- 末端力旋量：`f̂_ext = (J⁺)ᵀ τ̂_ext`（7 自由度 → 6D + 1 维零空间；零空间分量用于检测"内部挤压"）。

### 3.2 从残余到状态

```text
contact   : ||f̂_ext|| > c1                         (接触判据)
opposing  : <f̂_ext, u_k^progress> < −c2  且  ∫ <f̂_ext, u_k> dt < 0   (反向做功)
jam       : |f_axial| > c3  且  |Δx|/Δt < v_min 且 机器人仍在推     (卡住)
slip      : (g_obs − g_cmd) > c4  且  ||f̂_ext|| > c5               (夹持打滑)
```

`u_k^progress` 是第 k 步的**规范进度方向**，由 UIP-18 的力指纹模板给出（插入=轴向下压、拧盖=−θ、拉拉链=+s）。阈值 `c·` 用"空载噪声的 3σ"起步，再用测力台标定绝对量纲。

### 3.3 观测器头部（与主骨干共享，满足单模型）

```python
class IHFT(nn.Module):                       # 输入窗口~4个块边界，输出力旋量代理
    def forward(self, e_hist, dq_hist, grip_cmd_hist, grip_obs_hist):
        z = self.trunk(torch.cat([e_hist, dq_hist], -1))   # 与策略共享编码器
        w = self.wrench_head(z)               # 6D 力旋量代理
        c = torch.sigmoid(self.contact_head(z))
        return w, c
```

- 监督来源：OHTL 测力台真值（`L1 + 余弦方向损失`）、GSO-F 的仿真接触力（只学形状/符号/单调性，不学绝对量级）；
- 推理时零外部请求；观测器只是策略对象内部的一个小头，不违反"单模型多任务"的外部解释。

### 3.4 失败模式与对策

| 失败模式 | 表现 | 对策 |
|---|---|---|
| 位置环过硬 | `q*−q` ≈ 噪声 | E201 go/no-go；主动微抖动探针（幅度受 UIP-15+ 限） |
| `K_p` 未知/变化 | 力的尺度漂移 | 只用**方向/符号/时序**做判据，绝对量级仅参考；在线估 `α` |
| 时延/对齐 | 误差与力错时相 | 用块末指令对齐；滑动互相关估计延迟 |
| 重力/摩擦未建模 | 静态偏置 | 减去 `g(q)`；摩擦用速度符号项补偿 |
| 观测量化 | 小力不可辨 | 报告"最小可辨力"，低于它一律 `no_contact` |

## 4. UIP-18 · WFPP（Work/Force Progress Primitives）

### 4.1 每类计分步的力指纹

| 步类型 | 代表任务 | 观测量 | 指纹形状 | 进度坐标 | 撤回判据 |
|---|---|---|---|---|---|
| 插入/压合 | T10, T12, T26 | 轴向力 F vs 位移 d | 上升→峰值→**跌落（咔哒）** | d | d 回退或反向力 |
| 拧动/旋盖 | T12, T14, T32 | 力矩 T vs 角 θ | 斜坡 + 周期滑移 | 累计 \|θ\| | θ 反向（拧回） |
| 拉链 | T17, T19, T31 | 张力 F vs 行程 s | 粘滑周期纹 | s | s 回退或反向张力尖峰 |
| 折叠/堆叠 | T16, T20, T27 | 接触事件 + 高度 | 离散事件序列 | 完成折/层数 | 层数下降（视觉主判） |
| 夹持/搬运 | 全部抓取 | 夹爪开合误差 + 负载 | 稳定/滑移 | 稳定抓持 | 开合增大=滑出 |
| 倾倒/转移 | T14, T32 | 姿态 + 力/压力代理 | 流量相关 | 剩余量（视觉） | — |

> 结论：**力觉对"插入/拧动/拉链/夹持"贡献最大；对"折叠/堆叠/倾倒"仍以视觉为主**——这正好覆盖 v2 最容易误判的接触密集步。

### 4.2 机械功进度（无绝对力标定也能用）

```text
W_k(t) = Σ_{s≤t} Σ_j  ẽ_j(s) · Δq_j(s)          # 归一化接触功
```

- 对插入/拧动等**单调做功**步：`W_k` 上升即推进；`dW_k/dt < −ε` 即"被反向做功"→ `opposing`；
- 对往复步（拉链）：用**绝对功/行程**而非净值；
- 阈值用空载噪声标定，避免依赖 `K_p` 绝对值。

### 4.3 模板对齐（DTW）避免时间伸缩误判

```python
def progress_and_regression(effort_seq, template_k):
    u = dtw_align(effort_seq, template_k)      # 返回观测在模板上的归一化坐标 u∈[0,1]
    if u < last_u - h:                          # h=滞回，防抖动
        return "regressed"
    if u > 1 - eps:
        return "done"
    return "ongoing"
```

- 模板 `T_k` 由 OHTL P1 采集（同物体、多次、统计均值±方差）；跨本体只对齐**形状**；
- 滞回 `h` 与最小驻留时间共同抑制"来回抖"的误判。

## 5. UIP-17 · PAAC（Position-space Admittance & Active Contact）

### 5.1 导纳更新（位置目标偏置）

```text
准静态：  Δx = K_a^{-1} (f_des − f̂_ext)
含阻尼：  Δx = K_a^{-1} (f_des − f̂_ext) − D_a^{-1} ẋ
限幅：    ||Δx|| ≤ Δx_max,  ||Δθ|| ≤ Δθ_max
新块：    x*_new = clip( x*_nominal + Δx )，再经 IK 映回关节（或 ee 空间直接叠加）
```

- `K_a, D_a` 是"虚拟刚度/阻尼"，不是驱动器参数 → 完全在位置接口内可实现；
- 权限上限 `Δx_max`（如每块 ≤2 cm / ≤3°）是 UIP-15+ 的硬约束，防"用力过猛"和动作异常。

### 5.2 力引导插入（螺旋搜索，经典 peg-in-hole 的接口内版本）

```text
r_{m+1} = r_m + δr ;  φ_{m+1} = φ_m + δφ          # 每块推进一次
x_target = x_hole_estimate + r_m [cos φ_m, sin φ_m, 0]
终止：轴向力出现"峰值后跌落" 且 插入深度增加 → seated
退让：|f_lateral| 超限 → 回退 2mm 再搜索
```

适用于 T10 插插头、T12 开锁、T26 插网线、T32 针管对位。搜索是**在块边界一步步进行**的，不需要块内抢占。

### 5.3 夹持滑移自适应（直接吃 `unseen_object` 轴）

```text
若 g_obs − g_cmd > ε 且 ||f̂_ext|| > c5:        # 物体在滑
    g_cmd ← g_cmd − δ_g                         # 再闭合一点，增大夹持力
    若物体易碎(任务先验) → 封顶 + 改为降低加速度/减小姿态倾斜
```

对未见过的重物/滑物，视觉无法预知摩擦，力/滑移闭环是更可靠的泛化。

### 5.4 释放检测

放置类任务中，**接触力突变 + 高度到位**才释放，避免从高处掉落（T20/T27 纸杯/碗、T29 手机）。这比纯视觉"看起来到了"更稳。

## 6. UIP-19 · OHTL（Open-Hardware Twin & Labeler）

### 6.1 物料（全部离线，不进入评测链路）

| 组件 | 作用 | 备注 |
|---|---|---|
| RP2040 / ESP32 开发板 | 200 Hz 采集与时间戳 | 开源硬件生态；逐件核实 |
| 称重传感器 + HX711/ADS1232 | 轴向力 / 拉力真值 | 插入、拉链、倾倒 |
| 旋转编码器 / 电位器 | 位移 / 角度 | 插入深度、拧盖角 |
| FSR / 柔性弯曲传感器 | 接触/折叠事件 | 折叠、贴合 |
| 3D 打印道具 | RJ45 插头插座、瓶+盖、拉链布、毛巾、碗 | 与赛题物体同形 |
| 小型开源机械臂/舵机 | 扰动回放 / HIL | 如 LeRobot 生态 SO-101 类（候选） |

### 6.2 四个协议

- **P1 指纹采集**：准静态扫掠，记录 `(force, displacement/angle)`，重复 ≥30 次 → 每任务步模板 `T_k`（均值±方差），标定 `c·` 阈值。
- **P2 力标注演示**：遥操作小臂做任务，同步记录 `(q*, q_obs, 伺服负载/电流, 测力台真值)` → 标定 IHFT 的 `α, β` 与验证方向性。
- **P3 扰动回放**：按 `human_*` 文本录制"人的拉力/时机"，用舵机台复现 → 生成 `(干扰前状态, 撤回动作+力迹, 撤回后状态, 恢复)` 四元组，供 UIP-12-F。
- **P4 HIL**：把策略服务接到台架，以目标控制率跑，测 `p50/p95` 延迟、抖动、接触响应；只做工程验证，**不算真机成绩**。

### 6.3 跨体迁移的边界（必须写清）

- **可迁移**：物体力指纹的形状/顺序/符号/单调性（物体固有）；
- **不可迁移**：`K_p`、摩擦、重力、传动比、臂长（本体固有）→ 需逐体标定或策略内学残差；
- **结论**：OHTL 是"物体力先验 + 观测器结构验证"，不是"直接替代 G1 真机"。

## 7. 升级项：UIP-11-F / UIP-12-F / UIP-13′ / UIP-15+

### 7.1 UIP-11-F · GSO-F（力知情计分神谕）

- 在 v2 的几何谓词之外，读取 Gazebo/Isaac 的**关节反作用力/接触力**，为每个计分步生成力的**形状模板**与事件（contact、seated、jam）。
- **只信形状**：仿真接触刚度/摩擦不可靠 → 用"符号、顺序、单调性、事件时序"判分，绝对量级不进判据。
- 产出两类资产：① 给 IHFT 的合成力标签；② 给 WFPP 的模板冷启动（再由 OHTL 真值校正）。

### 7.2 UIP-12-F · DRF-F（力标注扰动工厂）

- 在 v2 "脚本化反向撤回"基础上，增加**力控撤回**（按力/按速度两种模式）并记录力迹；
- 输出 `(pre, undo_action + force_trace, regressed_state, recovery)` 四元组，既训练 `opposing` 检测，也训练"恢复"策略；
- 仿真扰动形态≠真人 → 用 OHTL P3 的真实力迹做域随机化锚点。

### 7.3 UIP-13′ · ACS′（块长选型 + 安全尾）

- **修正**：`T_a` 全局固定（F4），不能运行期变。只能离线选一个 `T_a*`，在"反应性 vs 往返/延迟"间取最优（E204）。
- **块内安全尾**：既然块内不能抢占，就让块的**后几步**趋近"低风险保持/回退"形态（例如接触步的末 1–2 步减小推进增量），使未知事件发生时的最坏后果可控。
- 力觉采样率 = 控制频率/`T_a`；`T_a` 越小力觉越灵，但往返越多、延迟暴露越大 → 用 `T_a ∈ {1,2,4,8,16}` 扫描定标。

### 7.4 UIP-15+ · CSG+（可信度守卫加强）

- 对导纳/搜索/修复动作：**速率限 + 低通 + 权限上限 + 振荡检测（能量/过零率）**；一旦检测到极限环，自动降增益。
- 监控动作统计量（每维均值/方差/过零率/抖动），与标称策略分布对齐，避免"力控一开就异常"。
- 重做/重试设次数与时间预算，超限则退回安全姿态，防止"反复重做"拖垮整集。

def update_force_state(q_cmd_last, obs, ft):
    q = obs["observation.state.right_arm"]            # (stack,7) 取最新帧
    dq = savgol_diff(q)                               # 速度/加速度估计

def v_ft(f_ext, dq, grip_cmd, grip_obs, template, g_k):

## 10. 合规与风险

- **单模型**：IHFT/WFPP/PAAC 均为策略对象内部的头或解析模块，共享骨干，不调用外部服务；OHTL 仅离线工具。外部 VLM 验证器仍不采用。
- **接口红线**：动作形状严格 `(T_a, …)`、`float32`、token 双处校验；不得返回变长块。
- **动作规律性**：力控修正必须限幅/低通/速率限；否则可信度判罚可能抵消收益（E208）。
- **不夸大**：本方案不是"力矩控制"，而是"位置接口下的隐式力估计 + 导纳"；所有力觉结论先标"观测器估计"，有真值才升级为"测量"。
- **未取到手册**：控制频率、episode 时限、state 是实测还是指令回显、评测轮次仍未知 → 这些都是 Gate 0 的前置确认项。
