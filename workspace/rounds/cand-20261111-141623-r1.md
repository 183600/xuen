# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「最小可行产品」×「抗干扰」）

> 第 54 轮把技能组合推进到「动作空间剖面 + 云边闭环 + 动作-鲁棒性联合证书」。但一个被忽略的工程事实是：**证书证明的是“可以部署”，不是“值得部署”**。本轮用 MVP 的克制视角追问：在给定干扰预算下，**能通过验证的最小技能包到底是哪一小块**？核心矛盾：H22 最小化会削掉抗干扰所需的冗余，全量部署又放大耦合面与验证成本；H23 离线仿真里的干扰裕度不等于部署现场的干扰裕度，MVP 可能在“干净”测试集上过关、在真实扰动下失稳。

## 0. 直觉与动机

**灵感 1（从“全量证书”到“最小可行技能包”）**
直觉：第 54 轮的 J 证书是对“整套技能序列”盖章。真实交付时，应只交付 **能覆盖任务动作序列 A_T、且干扰半径达标的最小子集 S_min**。MVP 的第一性含义不是“少做”，而是“只承诺可被证据支撑的那部分”。这把组合问题从“找一条可行路径”变成“在可行路径上找最小承载集”——一个带鲁棒性约束的加权集合覆盖。

**灵感 2（抗干扰不是附加分，而是可行域边界）**
直觉：一个技能再便宜，如果其干扰半径 `r_S < ε_req`，它在部署域里就是不可行点。定义干扰剖面 `β_S(e)`（扰动幅度 ≤ e 的最坏情况成功率），得到与 `α_S` 对偶的第二维剖面：`α_S` 说“能在哪些动作上做”，`β_S` 说“能扛多大扰动”。于是 MVSS 的约束是 `cover ∧ J sound ∧ r_{S_min} ≥ ε_req`，三者缺一不可。

**灵感 3（MVP 的开发节奏 = 反例驱动的最小扩张）**
直觉：不要一开始就猜全量集合。从最小核心 `S_0` 出发，用对抗压力测试找反例；**只有出现反例才扩张**：要么加入覆盖失败动作区的技能（expand），要么加缓冲/重试/降级（harden）。每次扩张都记录 **最小性见证**——每个元素被删后违反哪条约束的最小反例。这是把产品 MVP 的“上线-度量-迭代”搬到技能组合上。

**灵感 4（双层部署：名义 MVP + 安全降级 MVP）**
直觉：单层 MVP 在扰动的“肩部”会突然崩塌。部署两层：名义 MVP `S_nom` 追求任务性能，安全 MVP `S_safe ⊆ S_nom` 只在监测到扰动代理量超阈值时接管。切换需要 **切换证书**：`S_safe` 在 `ε_switch` 下仍满足 `r ≥ ε_req` 且切换延迟 `≤ τ_sw`。抗干扰由结构而非调参保证。

**灵感 5（对研究方法本身也用 MVP：最小证伪实验）**
直觉：第 54 轮列了 E157–E161，却没回答“最少做哪几个实验就能推翻证书”。把实验选择建模为 **子模覆盖**：每个实验覆盖一组失效假设 H，成本 `c_E`，选最小成本覆盖高风险假设集的实验子集。方法论上的 MVP：用最少的实验买到最大的证伪力。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（部署干扰模型）**
部署扰动 `δ = (δ_o, δ_a, δ_t, δ_env) ∈ Δ_ε`，分别作用于观测、动作、时序与环境；归一化范数 `‖δ‖ = max(‖δ_o‖/ε_o, ‖δ_a‖/ε_a, ‖δ_t‖/ε_t, ‖δ_env‖/ε_env) ≤ 1`。受扰执行记为 `τ' = D_δ(τ)`。

**定义 122（抗干扰剖面与干扰半径）**
技能 S 的抗干扰剖面 `β_S(e) = inf_{‖δ‖≤e} Pr[success | S, δ]`，关于 e 单调不增。干扰半径 `r_S(γ) = sup{ e : β_S(e) ≥ 1-γ }`。组合序列的 β 由第 54 轮 K 与动作剖面 α 联合决定：
```
β_{S1⊗S2}(e) ≤ min(β_{S1}(e), β_{S2}(e)) - κ(α_{S1}, α_{S2})
```
其中 κ 为动作错配惩罚，体现“组合可能比任一单技能更怕扰动”。

**定义 123（最小可行技能集 MVSS）**
给定技能库 `𝕊`、任务动作序列 `A_T`、部署成本 `c(S') = Σ_{s∈S'} (c_dep(s)+c_val(s))`、目标失败率 γ、干扰需求 `ε_req`：
```
S_min = argmin_{S'⊆𝕊} c(S')
s.t.  cover(S', A_T) = 1
      J(S') 可部署（第 54 轮定义 120）
      r_{S'}(γ) ≥ ε_req
```
在一般技能库上这是带鲁棒约束的加权集合覆盖，**NP-hard**（见 §3 命题 1）。

**定义 124（MVP 证书）**
`M = (S_min, A_core, r_min, ε_req, J, W_min, W_int)`：
- `W_min` 最小性见证：`∀ s∈S_min`，`S_min\{s}` 至少违反一条约束，并附最小反例；
- `W_int` 干扰见证：边界扰动 `δ*` 使 `β_{S_min}(r_min) ≈ 1-γ`，即“刚好站得住”的证据。

**定义 125（干扰冗余与吸收容量）**
冗余 `red(S) = |A_buffer(S)| / |A_core(S)|`（动作容错带相对核心覆盖的比例）。吸收容量 `I_cap(S) = max{ e : ∃ a_r∈A_buffer(S), β_{S∪{a_r}}(e) ≥ 1-γ }`。MVP 要求 `red(S) ≥ ρ_red`，防止“最小”退化为“单点故障”。

**定义 126（反例驱动扩张算子）**
失败反例 `(δ*, a*, region)` 触发：
```
Ex(S) = S ∪ { argmax_{s∈𝕊\S, s 覆盖 region} Δβ_s(ε_req) / c(s) }
Hd(S) = S ⊕ { 增加 δ_a 缓冲 / retry 预算 / 降级策略 }
```
每步选择 `argmax(Δβ/c)`，直到压力测试集上无存活反例，并记录最小性见证。

## 2. 关键算法 伪代码

### IP-121 AIR（Anti-Interference Radius）

```python
def interference_radius(skill_set, gamma, eps_grid, stress_gen, sim):
    lo, hi = 0.0, max(eps_grid)
    while hi - lo > tol:
        e = (lo + hi) / 2
        worst = min(rollout(sim, skill_set, d).success
                    for d in stress_gen(e, n=N_stress))
        if worst >= 1 - gamma:
            lo = e
        else:
            hi = e
    return conformal_lower(lo, calib_set, alpha)
```

### IP-122 MVSS（最小可行技能集）

```python
def mvss(library, A_T, eps_req, gamma, budget):
    # 1) 用第 54 轮 G_S 剪掉动作不兼容组合
    G = build_composition_graph(library, theta_a, tau_e, K)
    # 2) 分支定界 + LP 松弛下界（集合覆盖）
    best = None
    for S in branch_and_bound(G, cover=A_T, lower_bound=lp_cover_lb):
        if not deployable(S):            # 定义 120 联合证书
            continue
        if interference_radius(S, gamma, ...) < eps_req:
            continue
        if best is None or cost(S) < cost(best):
            best = S
    return best if best else ('infeasible', min_violation_witness(G))
```

### IP-123 FDE（反例驱动最小扩张）

```python
def falsification_driven_expand(S0, stress_suite, eps_req, budget):
    S = S0
    for _ in range(max_rounds):
        cex = first_counterexample(stress_suite, S, eps_req)
        if cex is None:
            return ('ok', S, minimality_witness(S), interference_witness(S))
        gain = {s: delta_beta(S, s, eps_req) / cost(s)
                for s in candidates(G, cex.region)}
        s_star = argmax(gain)
        if gain[s_star] <= 0:
            S = harden(S, cex)          # 加缓冲/重试/降级
        else:
            S = S | {s_star}            # 扩张
    return ('budget_exceeded', S, cex)
```

### IP-124 TDS（双层降级切换）

```python
def two_tier_deploy(S_nom, eps_req):
    S_safe = safe_core(S_nom)           # A_core + 最小恢复动作
    assert interference_radius(S_safe, gamma, ...) >= eps_switch
    def policy(obs, disturb_proxy):
        if disturb_proxy > tau_sw and switch_latency() <= tau_sw_max:
            return act(S_safe, obs)     # 降级
        return act(S_nom, obs)
    return policy, switch_cert(S_nom, S_safe, eps_switch, tau_sw)
```

### IP-125 MFE（最小证伪实验选择）

```python
def minimum_falsifying_experiments(experiments, risk_hypotheses, budget):
    chosen, covered = [], set()
    while covered != risk_hypotheses and cost(chosen) < budget:
        E = max((e for e in experiments if e not in chosen),
                key=lambda e: len(e.covers() - covered) / e.cost)
        chosen.append(E)
        covered |= E.covers()        # 子模覆盖，贪心 1-1/e
    return chosen
```

### IP-126 MVPC（MVP 证书装配）

```python
def assemble_mvp_cert(S_min, J, gamma, eps_req):
    W_min = {s: minimal_violation(S_min - {s}) for s in S_min}
    W_int = boundary_witness(S_min, eps_req, gamma)
    r_min = interference_radius(S_min, gamma, ...)
    if r_min < eps_req or any(W_min.values()):
        return ('reject', W_min, W_int)
    return ('ok', MVP_Cert(S_min, A_core(S_min), r_min, eps_req, J, W_min, W_int))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| AIR | O(N_stress·\|E\|·T_rollout·log(1/tol)) | O(N_stress) | 压力集 ε-覆盖 + conformal 下界 |
| MVSS | NP-hard；B&B 最坏 O(2^\|𝕊\|)，贪心 O(\|𝕊\|²·\|A\|) | O(\|𝕊\|²+\|A\|) | LP 对偶下界 + 最小性见证 |
| FDE | O(K·\|𝕊\|·\|A\|·T) | O(\|𝕊\|·\|A\|) | 反例 sound + 边际增益单调 |
| TDS | O(\|A_core\|) 在线 | O(\|A_core\|) | 切换延迟上界 + 降级证书 |
| MFE | O(\|chosen\|·\|H\|·\|𝔼\|) | O(\|H\|) | 子模 1-1/e 近似 |

**命题 1（MVSS 的 NP-hardness）**
令 `β_S ≡ 1` 且 J 恒真，则 MVSS 退化为加权集合覆盖，故 NP-hard；无单调性时不存在常数近似。加单调覆盖假设后，贪心给出 `H(|𝕊|)` 近似，B&B + LP 松弛给出可验证下界。

**正确性定理（MVP Interference-Soundness）**
在 (A22)–(A28) 成立的前提下，再假设：
- **(A29)** 压力集 `Δ_stress` 对真实部署扰动族 `Δ_ε` 是 ε-覆盖的；
- **(A30)** 在 G_S 的可行子图上，扩张/加固算子对 β 单调不减（无负干扰）；
- **(A31)** conformal 校准给出 `r_hat ≤ r_true` 的覆盖率 ≥ 1-α。

则对 `ε_req ≤ r_hat` 的 MVSS：
```
Pr[success on D] ≥ 1 - γ - α - β_E - P(W_min invalid)
```
其中 `β_E` 为仿真到现实的模型误差，`P(W_min invalid)` 是最小性见证被新反例推翻的概率。**注意**：若 A29 或 A30 破裂——压力集没覆盖到真实扰动，或加技能反而引入负迁移——定理不成立，这正是 MVP 最脆弱处。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 干扰预算 ε 低估 → 虚假抗干扰 | 高 | 自适应 conformal + 红队 + 在线异常代理监测 |
| “最小”退化为单点故障（技能强相关） | 高 | 依赖感知覆盖 + 多样性下界 `red ≥ ρ_red` |
| MVSS 规模爆炸 / NP-hard | 中 | 分层 B&B + LP 松弛 + 图剪枝 |
| 成本模型被 Goodhart 化 | 中 | 多目标帕累托 + 成本审计 |
| 双层切换抖动 / 振荡 | 中 | hysteresis + 切换冷却 + 形式化切换预算 |

## 6. 本轮最大风险

**一句话**：MVP 把“能否部署”收紧为“最小且抗干扰地部署”，但它把全部赌注压在 **压力集对真实扰动的覆盖性** 与 **技能间无负干扰的单调性** 上；一旦压力集漏掉部署现场的某类扰动，或“最小”集合里几个技能共享同一个失效模式，证书会在最需要它的边界处恰好失效——因此必须以 **ε-覆盖压力集 + 依赖感知的冗余下界 + 在线切换绊线** 三重护栏，让“最小”永远带着可被反例推翻的自觉，而不是把最小性当成鲁棒性。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-MVP（MVSS×AIR×FDE×TDS×MFE×MVPC）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮把“可部署”推进到“**最小可行且抗干扰地部署**”，新增六个算子：
> - **MVSS（Minimum Viable Skill Set）**：满足覆盖 + 联合证书 + 干扰半径的最小成本技能子集；
> - **AIR（Anti-Interference Radius）**：最坏扰动下的干扰半径估计与 conformal 下界；
> - **FDE（Falsification-Driven Expansion）**：只有反例才扩张/加固的最小化迭代；
> - **TDS（Two-tier Degradation Switch）**：名义 MVP + 安全降级 MVP 的切换证书；
> - **MFE（Minimum Falsifying Experiments）**：以子模覆盖选最小证伪实验集；
> - **MVPC（MVP Certificate）**：最小性见证 + 干扰见证 + 联合证书的装配。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-116/117/118 以把“最小性 + 抗干扰”纳入组合与云边闭环。

```python
    if r_min < eps_req or redundancy(S_min) < rho_red or any(W_min.values()):
        return ('reject', W_min, W_int, r_min)
    return ('ok', MVP_Cert(S_min, A_core(S_min), r_min, eps_req,
                           J, W_min, W_int))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AIR | O(N_stress·\|E\|·T·log(1/tol)) | O(N_stress) | 压力集 ε-覆盖 + conformal 覆盖 ≥ 1-α |
| MVSS | NP-hard；B&B 最坏 O(2^\|𝕊\|)，贪心 O(\|𝕊\|²·\|A\|) | O(\|𝕊\|²+\|A\|) | LP 对偶下界，最小性见证可复核 |
| FDE | O(K·\|𝕊\|·\|A\|·T) | O(\|𝕊\|·\|A\|) | 反例 sound，边际增益单调时收敛 |
| TDS | O(\|A_core\|) 在线 | O(\|A_core\|) | 切换延迟 ≤ τ_sw，降级证书 sound |
| MFE | O(\|chosen\|·\|H\|·\|𝔼\|) | O(\|H\|) | 子模 1-1/e 近似 |

**命题 1（MVSS 的 NP-hardness）**
取 `β_S ≡ 1`、J 恒真，MVSS 退化为加权集合覆盖，故 NP-hard；若放弃覆盖单调性，则连常数因子近似都不存在。在单调性下贪心给 `H(|𝕊|)` 近似，分支定界配合 LP 对偶下界给出可验证的最优性间隙。

**正确性定理（MVP Interference-Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并额外要求：
- **(A29)** 压力集 `Δ_stress` 对真实部署扰动族 `Δ_ε` 是 ε-覆盖的；
- **(A30)** 在 `G_S` 的可行子图上，扩张/加固算子对 `β` 单调不减（无负干扰）；
- **(A31)** conformal 校准满足 `r_hat ≤ r_true` 的覆盖率 ≥ 1-α。

则对满足 `ε_req ≤ r_hat` 的最小可行集：
```
P_success ≥ 1 - γ - α - β_E - P(W_min invalid)
```
关键：**最小性在压力闭包上成立**、**抗干扰半径取保守下界**、**冗余有下界**。若 A29/A30 任一破裂，证书失效——这正是本轮立论的全部风险所在。

## 5. 本轮最大风险

**一句话**：MVP 把“能否部署”收紧为“最小且抗干扰地部署”，但它把全部赌注压在 **压力集对真实扰动的覆盖性** 与 **技能间无负干扰的单调性** 上；一旦压力集漏掉部署现场的某类扰动，或“最小”集合里几个技能共享同一个失效模式，证书会在最需要它的边界处恰好失效——因此必须以 **ε-覆盖压力集 + 依赖感知的冗余下界 + 在线切换绊线** 三重护栏，让“最小”永远带着可被反例推翻的自觉，而不是把最小性当成鲁棒性。
