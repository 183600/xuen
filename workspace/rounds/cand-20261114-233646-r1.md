# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「通用操作」×「通信延迟」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配多模态策略呈现歧义，用 VoI 选「看/问/触」的信息动作，用 k-正交一致纪律防止被谎言骗。但 R69 的交互是**隐式同步**的——发出请求、立刻拿到答案、立刻更新信念、立刻动作。它把「通信」当成一个零延迟的本地函数调用。
>
> 两个灵感正好击穿这一假设：
> - **通信延迟**：答案要过 Δ 才回来。到的时候，**决策窗口**可能已经关了，或者**模态本身**已经变了（你问「你现在走左边还是右边」，等他答完他已经走过去了）。信息不是「有没有价值」，而是「**在到达时刻、对到达时刻的决策、还有没有价值**」。R69 的 VoI 必须升级为时间的函数。
> - **通用操作**：若有一组可组合、跨任务复用的操作原语（看/问/触/等/占位/交接），等待就不再是干等——可以像 CPU 流水线一样**预取**，用不依赖答案的独立操作填满等待窗口，**把延迟藏进并行**而不是硬等。通用性提供可替换性与并行度，是延迟隐藏的前提。
>
> 核心命题：**把 R69 的「同步、实例定制的交互」升级为「异步、时间参数化、可流水线化的通用操作中继」；交互价值按到达时刻折价，信息按时间戳与租约决定是否可信，投机操作可回退而绝不改变已认证的安全包络。** 命名 **RELAY-RAS**（Repertoire-based, Latency-aware Asynchronous Yield 闭环 / 通用操作中继）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我现在问，还来得及吗；我这份答案，还新鲜吗**」——交互不只是「问什么」，更是「**什么时候问、什么时候用**」。

## 0. 直觉与动机

**灵感 1（通信延迟 → 交互价值有了时间轴）**
直觉：R69 的 `VoI(g) = H(M|o) − E[H(M|o,y)]` 隐含假设「问完立刻知道」。真实世界里答案要经过 Δ 才回来。到的时候两件事可能已经变了：**决策窗口**（你还在岔口吗）与**模态本身**（人已经走过去、世界已经改变）。同一句问话，早 200ms 问是金子，晚 200ms 问是废纸。信息不是「有没有价值」，而是「**在到达时刻、对到达时刻的决策、还有没有价值**」。一句话：**问得早是资产，问得晚是噪声。**

**灵感 2（通用操作 → 把「等待」变成可并行的资源，从而隐藏延迟）**
直觉：R69 的信息动作是「为当前决策临时定制的一次性动作」。若有一组**通用操作原语**——看、问、触、等、占位、交接——可组合、跨任务复用，那么等待就不再是「干等」：在答案沿延迟管道飞回来的同时，可以并行执行**不依赖该答案**的独立操作。这正是经典流水线的 latency hiding：不是把延迟变短，而是**用并行把延迟填满**。通用性提供可替换性和可并行性，是延迟隐藏的前提；没有通用操作库，延迟只能硬等。

**灵感 3（通用 ≠ 免证 → 能力可组合，证书不可组合）**
直觉：通用操作最诱人的是「学一次，处处用」。但安全证书有作用域：原语 o 在域 D_o（任务分布 × 状态集 × 动态范围）内被认证过。把它复用到新任务、或与别的原语组合时，**能力的组合不等于证书的组合**。一个动作在 A 任务里安全，组合进 B 任务的流水线后可能悄悄越界。R69 的 C-RAS-WM 前缀认证是「就地认证」；R70 一旦谈复用，就必须谈**域的迁移与闭合**。这是本轮最深的裂缝。

**灵感 4（旧的真值 = 新的谎言 → 延迟是投毒的新维度）**
直觉：R69 的投毒是「给错答案」。有了延迟，出现更隐蔽的时间轴攻击：**把 5 秒前的正确答案现在送达**。若系统没有时间戳，会把旧真相当成此刻真相，还天然满足「多源一致」——旧的真值就是新的谎言。重放（旧真值）、拖延（扣住正确答案让系统在错误假设下多走几步）、乱序（把 A 的答案贴到 B 的问上）、共谋延迟（先演后答，配合 R69 跨模态欺骗）构成新威胁类。所以 R69 的「k-正交一致」必须升级为「**同窗 k-一致**」：不仅要多源一致，还要在同一个新鲜时间窗内一致且版本单调。

**灵感 5（流水线是双刃剑 → 投机必须可回退且可审计）**
直觉：预取/投机执行能隐藏延迟，但投机是在「猜」。猜错的预取会浪费预算、污染信念，甚至在答案到达前就基于错误假设动作。所以 RELAY 必须同时交付：投机深度可证上界、投机操作**可回退**、投机后缀失败时回滚到已认证前缀，以及「投机只改变信息获取时机，绝不改变安全动作集」的隔离定理。否则 R70 就是把 R69 的「问错更危险」升级成「提前问错，还按错的做」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（RELAY-RAS 总览）** RELAY-RAS = (UOA, LVoI, AOS, SLG, DPM, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **时间戳纪律**：所有外部信息携带签发时间戳 τ 与单调版本号 ver，采纳前必经 SLG（定义 315），过期/乱序一律降权或丢弃；
(iii) **投机隔离**：任何投机/预取操作不得改变已认证动作前缀的安全包络；投机失败只损失预算、不损失安全（定义 318、定理 19）。

**定义 311（通用操作代数 UOA）** 操作原语库 𝒪 = 𝒪_task ∪ 𝒪_info ∪ 𝒪_wait。每个原语 o = (φ_o, pre_o, post_o, D_o, c_o)：φ_o 为效果算子，pre/post 为前后条件，D_o 为**证书域**（定义 319），c_o 为成本。组合算子 ∘（串行）、∥（并行）、≃（同域内等价替换）。操作图 G 为以原语为节点、数据/时序依赖为边的 DAG。

**定义 312（操作的时间签名）** 操作实例 ο = (o, t_issue, t_eff, τ_dep)：t_issue 为发出时刻，t_eff 为生效时刻，τ_dep 为其依赖信息的最新签发时刻。通信延迟 Δ = t_arrive − t_issue ~ D_Δ（可含随机与对抗分量）。

**定义 313（延迟感知 VoI，LVoI）** 对信息动作 g 于 t 发出、预计 t+Δ 到达：
`VoI_Δ(g;t) = E_{Δ,y}[ 1{t+Δ ≤ t_deadline} · ρ(Δ) · (H(M_{t+Δ}|o_t) − H(M_{t+Δ}|o_t,y)) ]`，
其中 ρ(Δ) 为**模态持久性因子**（模态在 Δ 内不变的概率，单调不增）。硬截断：答案晚于决策截止则价值为 0。

**定义 314（通用操作调度 AOS）** 给定操作图 G，调度 σ 为每个操作分配 (t_issue, t_eff)，满足依赖与预算，最小化期望风险。**投机深度** d 为允许在依赖信息未到达前就发出的最大层数。AOS 用就绪队列把独立操作填入等待窗口以隐藏延迟（引理 20）。

**定义 315（新鲜度/租约门 SLG）** 每条信息携带 (τ, ver)。采纳规则：age = now − τ；w_age = e^{−κ·age}；若 age > TTL(m) 或 ver < ver_seen ⇒ 丢弃并请求异步刷新（不阻塞主环路）。TTL 按模态半衰期设定。

**定义 316（延迟投毒模型 DPM）** 新威胁类 ℰ_DELAY：重放（旧真值当新真值）、拖延（扣留正确答案使系统在错误假设下动作）、乱序（答案错绑问题）、共谋延迟（与 R69 跨模态欺骗配合，先演后答）。ℰ_RELAY = ℰ_FLUID × ℰ_DELAY。

**定义 317（同窗时间一致性证据纪律）** R69 的 k-正交一致升级为：要求 k 个正交源在窗口 [τ−W, τ] 内一致且版本单调；单源、跨窗拼接、或版本回退均不得定案。回答须带 nonce 绑定到具体问句（防乱序）。

**定义 318（投机安全隔离）** 投机操作 s 的物理效果必须落在**可回退包络** ℬ_rev 内（可撤销或可停在安全集）。对 (已认证前缀 P ∥ 投机后缀 S) 做条件认证：若 S 任一步失败，回滚至 P 的最后安全态；S 不修改 P 的已认证动作。

**定义 319（证书作用域与闭合）** cert(o) 仅在 D_o 内有效。组合 ξ = o_1∘…∘o_n 认证当且仅当沿轨迹 D_ξ = ∩_i D_{o_i} 非空且轨迹闭合于 D_ξ；任一原语离开其域即证书失效（定理 20）。**通用 ≠ 免证。**

**定义 320（延迟-价值对偶临界）** 存在临界延迟 Δ* 使 VoI_{Δ*}(g)=c(g)：Δ<Δ* 值得问，Δ>Δ* 不如不问。Δ* 由持久性 ρ、决策紧迫度、成本共同决定。系统维持**预取队列**使有效延迟 ≤ Δ*。

**定义 321（复用迁移风险与域守卫）** 跨任务 T 复用原语 o 的迁移风险 `R_tr(o→T) = P_{s~T}(s ∉ D_o)`。通用库为每个原语配在线**域守卫** guard_o(s)，越界即禁用该原语或退化为 R69 专用动作。

**定义 322（预算-年龄联合约束）** 单位时间操作数 ≤ B、信息年龄加权和 ≤ A_max、投机浪费率 ≤ r_s，三者共同刻画调度可行域；AOS 在可行域内求最优深度 d。

**定义 323（证书 J_RELAY）** J_RELAY = (J_FLUID, max_age, version_monotone, schedule_feasible, speculative_waste, cert_domain_margin, relay_ver)。Valid ⇔ Valid(J_FLUID) ∧ SLG 全过 ∧ 调度可行 ∧ 证书域未越界。

**定义 324（延迟对抗鲁棒）** 时间戳+版本单调防重放；超时重发+多路径防拖延；nonce 绑问-答防乱序；同窗多源防共谋。

**定义 325（严格包含与退化）** 当 Δ≡0、TTL→∞、d=0、且 𝒪 退化为 R69 的任务+信息动作时，RELAY 逐指令退化为 FLUID-RAS。⇒ R69 是 RELAY 的「零延迟、无复用、无投机」边界。

**定义 326（时间预算下自适应深度）** 投机深度 d 与流采样 K 联合优化：d 越大延迟隐藏越好但浪费越多；用模式熵与延迟分布预测选 d，守 P99 实时预算与浪费率 r_s。

## 2. 关键算法骨架

```python
# IP-264 UOA：通用操作代数（原语 + 组合 + 域守卫）
class OpAlgebra:
    def __init__(self, primitives):            # {name: (phi, pre, post, D, cost)}
        self.ops = primitives
    def compose(self, *names):                 # 串行组合，证书域取交
        domain = intersect(self.ops[n].D for n in names)
        if domain.is_empty():                  # 空交 ⇒ 拒绝组合（定理 20）
            raise CertDomainGap(names)
        return Composite(names, domain)
    def guard(self, name, s):                  # 在线域守卫（定义 321）
        return self.ops[name].D.contains(s)

# IP-265 LVoI：延迟折价的交互价值（硬截止 + 持久性）
def latency_voi(g, t, t_deadline, D_delta, rho):
    val = 0.0
    for delta, p in D_delta.samples():
        if t + delta > t_deadline:             # 答案晚于决策截止 → 价值 0
            continue
        val += p * rho(delta) * (H(M, t + delta, o)
                 - expected_entropy(M, t + delta, o, g))
    return val

# IP-266 AOS：就绪队列 + 投机深度，用并行隐藏延迟
def schedule(G, budget, d_max):
    inflight = {}
    for op in topo_ready(G):                   # 先发不依赖回报的操作
        if budget.allow(op): inflight[op] = issue(op)
    for depth in range(1, d_max + 1):          # 逐层预取
        for op in speculative_layer(G, depth):
            if budget.allow(op) and op.in_envelope(B_rev):
                inflight[op] = issue(op)
    return inflight                            # 答案按到达时刻回填

# IP-267 SLG：时间戳 / 租约门
def admit(msg, now, ttl, ver_seen):
    age = now - msg.tau
    if age > ttl[msg.mode]:  return REFRESH    # 过期 → 异步刷新
    if msg.ver < ver_seen:   return DROP       # 重放 / 乱序
    return (msg, w_age(age))                   # 降权后采纳

# IP-268 同窗 k-一致证据纪律（升级 R69）
def update_belief_time(modes, answers, W):
    win = [a for a in answers if a.tau >= max_tau - W]
    groups = bucket_by_question_nonce(win)     # 防乱序
    if orthogonal_agree(groups) >= k and version_monotone(win):
        return bayes_update(modes, groups)     # 定案
    return modes, UNDECIDED                    # 保持未消解，走 R69 兜底

# IP-276 主闭环（继承 R69，插入时间轴与流水线）
def RELAY_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) 清理在途信息：过期/乱序一律拒收
    fresh = [m for m in M.inflight if M.slg.admit(m, M.now) is not REFRESH]
    # 2) 延迟感知 VoI + 调度：预取未来的问题
    g_star = M.aos.select(modes, o, M.budget, M.D_delta,
                          t_deadline=M.t_deadline)
    M.aos.dispatch(g_star)                      # 发出，不阻塞
    # 3) 通用操作域守卫：越界的复用立即禁用
    ops = [op for op in M.ops if M.uoa.guard(op, o.state)]
    # 4) 风险：未消解 epistemic 仍走 R69 两级退避
    U_floor = U_ale + (U_epi if U_epi > TAU_EPI else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 5) 投机后缀：可回退，绝不改已认证前缀
    if M.aos.has_speculative():
        k = M.c_ras_wm.cond_certify(A, k, M.aos.spec_suffix(), B_rev=M.B_rev)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(g_star, fresh, M.inflight)
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（延迟折价的 VoI 上界）** 在持久性 ρ(Δ) 单调不增且硬截止下，`VoI_Δ(g;t) ≤ ρ(Δ)·VoI_0(g;t)`，且 t+Δ > t_deadline 时为 0。临界延迟 Δ* 由 `ρ(Δ*)·VoI_0 = c(g)` 解出。系：**交互应尽早发出（prefetch）**；若预计到达晚于截止，正确动作是「不问、直接保守（R69）」。

**引理 20（流水线延迟隐藏上界）** 设操作图关键路径长度 L、可并行宽度 W、单操作时延 τ_op，则最优调度下有效等待约从 Δ 降至 `max(0, Δ − (L−1)·τ_op)`，并受预算 B 与可回退比 r_s 约束。⇒ 通用操作库越宽、依赖越松，可隐藏延迟越多；但宽度受证书域与预算共同限制。

**引理 21（时间戳纪律恢复投毒上界）** 无时间戳时，重放使 R69 引理 18 的 k-一致上界退化为 δ_p（旧答案天然「一致」）；加入版本单调 + 同窗约束后，错误采纳率 ≤ `δ_p·ρ^{k−1} + ε_σ + ε_replay`，ε_replay 由时钟漂移与延迟抖动决定。⇒ **新鲜度是证据纪律的前置条件**，不是可选项。

**定理 18（RELAY 严格包含 FLUID）** 在 Δ≡0、TTL→∞、d=0 边界下逐指令等价。一般情形下，因系统总可选择「不采纳过期信息 / 不使用投机」，其期望风险 ≤ FLUID，安全侧不增；效率侧由延迟隐藏与预取获得增益。

**定理 19（投机隔离无突变）** 若投机操作满足可回退包络（定义 318）且 C-RAS-WM 做条件认证，则投机失败可回滚至已认证前缀，控制序列连续、无安全突变；投机只改变信息获取时机，不改变安全动作集。

**定理 20（证书域闭合的必要性）** 通用操作组合沿轨迹保持认证，当且仅当轨迹恒位于 D_ξ = ∩ D_{o_i} 内；一旦越界，存在对抗场景使组合失效概率 ≥ 1−ε。⇒ 通用性必须以在线域守卫为前提，「学一次处处用」若无域守卫就是安全幻觉。

## 6. 本轮最大风险

**一句话**：RELAY-RAS 把效率押在「通用操作可安全复用 + 流水线可隐藏延迟」上——但**能力可以组合，证书不能自动组合**：一旦跨任务复用的原语或投机后缀悄悄离开了原认证域，系统会在整条流水线上自信地运行在**未认证域**里，而延迟恰好把越界证据推迟到事故之后才到达——**「通用」把能力规模化，也把「证书域失配」规模化**。

**次级风险与缓解**：
1. **投机预测错误**（猜错预取、浪费预算、污染信念）→ 可回退包络 ℬ_rev + 条件认证 + 投机浪费率上界 r_s（定理 19）；
2. **延迟投毒**（重放/拖延/乱序/共谋）→ 时间戳+版本单调 + nonce 绑定 + 同窗 k-一致（引理 21）；
3. **延迟分布估计失配**（真实 Δ 与 D_Δ 不符）→ 在线更新 D_Δ + 保守分位 + E311；
4. **预算-年龄冲突**（预取挤占实时预算）→ 预算-年龄联合约束 + 自适应深度 d（定义 322/326）；
5. **证书域守卫误判**（守卫放过越界状态）→ 域交闭合检查 + E304/E310 + 越界即回退 R69 专用动作。

```python
class OpAlgebra:
    def compose(self, *names):                 # 串行组合，证书域取交
        domain = intersect(self.ops[n].D for n in names)
        if domain.is_empty(): raise CertDomainGap(names)   # 定理 20
        return Composite(names, domain)

        return self.ops[name].D.contains(s)    # 在线域守卫

# IP-265 LVoI：延迟折价的交互价值
def latency_voi(g, t, t_deadline, D_delta, rho):
    return sum(p * rho(dl) * (H(M,t+dl,o) - expected_entropy(M,t+dl,o,g))
               for dl, p in D_delta.samples() if t + dl <= t_deadline)

# IP-266 AOS：就绪队列 + 投机深度，隐藏延迟
def schedule(G, budget, d_max):

    for depth in range(1, d_max + 1):
        for op in speculative_layer(G, depth):

    return inflight                            # 答案按到达时刻回填

def admit(msg, now, ttl, ver_seen):

    return (msg, w_age(now - msg.tau))
```

## 4. 推导

**引理 19（延迟折价上界）** `VoI_Δ ≤ ρ(Δ)·VoI_0`，`t+Δ>t_deadline` 时为 0；临界延迟 `Δ*` 由 `ρ(Δ*)·VoI_0=c` 解出。系：交互应尽早发出；预计晚于截止时正确动作是「不问，直接走 R69 保守」。

**引理 20（流水线延迟隐藏上界）** 关键路径 L、并行宽度 W、单操作时延 τ_op 下，有效等待约降至 `max(0, Δ−(L−1)τ_op)`，受预算 B 与可回退比 r_s 约束。系：操作库越宽、依赖越松，可隐藏延迟越多，但宽度受证书域与预算共同限制。

**引理 21（时间戳恢复投毒上界）** 无时间戳时重放使 R69 引理 18 上界退化为 δ_p；版本单调 + 同窗约束后错误采纳率 ≤ `δ_p·ρ^{k−1}+ε_σ+ε_replay`。系：新鲜度是证据纪律的前置条件。

**定理 18（RELAY 严格包含 FLUID）** Δ≡0、TTL→∞、d=0 时逐指令等价。一般情形下系统总可选择不采纳过期信息/不使用投机，故期望风险 ≤ FLUID、安全侧不增，效率侧由延迟隐藏与预取获益。

**定理 19（投机隔离无突变）** 投机满足可回退包络且条件认证时，失败可回滚至已认证前缀，控制连续、无安全突变；投机只改信息获取时机，不改安全动作集。

**定理 20（证书域闭合必要性）** 组合认证当且仅当轨迹恒在 `D_ξ=∩D_{o_i}` 内；越界则存在对抗场景使失效概率 ≥ 1−ε。⇒ 无域守卫的「学一次处处用」是安全幻觉。
