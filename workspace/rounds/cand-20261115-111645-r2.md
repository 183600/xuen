# 第 5 轮（灵感循环；本轮灵感：「基线复现」×「热管理」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。ToolGauge / InstructGauge / LeanGauge / MODGAUGE 骨架继续按原退化链继承不变。
> 本轮纪律：**先复现、再改进**；热是隐变量，必须显式进入漂移界与时延界；任一热相关信息缺失，都必须能退回「无热假设」的 v4，而不是悄悄用一个未经校准的阈值。

## 0. 直觉与动机

**灵感 1（基线复现 = 内建的控制实验，而不是一次性复现实验）**
直觉：一个会自我改进的检测系统，最大的敌人不是「改不动」，而是「以为改动了」。当硬件与场景缓慢漂移时，热漂移、时序抖动、相机老化都会被误读成「新方法的增益」。因此「基线复现」不应只在论文里做一次，而应成为闭环里**周期性的控制实验**：冻结一小套规范复现场景与「黄金轨迹」，每轮在可比条件下重放基线；只有重放通过（等价证书），新组件的增益才被承认为**归因增益**，而不是环境噪声。这把复现从「事后检查」提升为「运行时因果归因的门禁」。

**灵感 2（热管理 = 同时调制能力、漂移与算力的隐状态）**
直觉：机械臂跑久了关节发热、连杆热膨胀、腕部相机发热导致噪声与内参漂移，边缘 GPU 过热降频；被检对象本身也可能处于高温。热不是一个附加传感器读数，而是**同时进入三条通路的隐变量**：(i) 运动学——连杆膨胀改变末端位姿，直接注入 TF 残差；(ii) 感知——相机热噪声与内参漂移让时空一致性阈值失效；(iii) 算力——GPU 降频拖慢决策，使 50Hz 与分块决策的时序承诺被静默破坏。忽略它，既会让「时空一致性证书」在高温段静默失效，也会让基线复现出现假等价或假差异。

**灵感 3（两者耦合 → 热条件化复现，以及一个「热可行域」）**
直觉：热漂移是基线复现最大的混杂项——「冷机录的黄金轨迹」与「热机重放」的差异不该算到算法头上。所以复现必须**按热状态分层**：同层内比较，或显式扣除热致漂移。更深一层的张力是：GPU 降频会逼你把块长 K 调大以保住 50Hz（吞吐要求 K↑），而升温又会逼你把 K 调小以保住漂移界（安全要求 K↓）。于是自然出现一个**热可行域**：当两条约束不相交时，系统必须主动降载/降温/降级，而不是偷偷违约。这把热管理从「贴一个温度阈值」升级为「一个带可行性判据的调度问题」。

## 1. 研究问题（本轮要回答什么）

- **Q1（复现的可判定性）**：如何把「基线复现」变成闭环内可自动判定、且允许拒绝的运行时门禁，而不是一次性实验？
- **Q2（热的可建模性）**：热状态如何定量地进入漂移界、时空一致性阈值与决策时延？新界是否仍可证、且可几何退化？
- **Q3（可行性与归因）**：吞吐（50Hz）与安全（漂移界）在热约束下的可行域如何刻画？不可行时如何优雅降级而不静默违约？热分层后「改进」是否可被因果归因？

## 2. 设计原则（雏形，正式化见产物区定义 468–482）

**P1 复现门禁（Reproduction Gate）**
任何「改进」主张必须先通过规范复现集（CRS）的重放等价；未通过、样本不足或热层外，一律标为 `uncertified`，不参与归因。门禁作用于**认证时刻的结论**，不在 50Hz 实时路径上，故不侵蚀时序。

**P2 热分层等价（Thermal-Stratified Equivalence）**
只在同一热层 `S_k` 内比较，或用保守热漂移模型扣除；热层外 → 拒证，而不是外推。

**P3 热预算守恒（Thermal Budget Conservation）**
把热致时延与热致漂移显式并入 K 的选择：`K_min(τ)`（吞吐下界）与 `K_max(τ)`（安全上界）不相交时判为**热不可行**，触发降载/降温/退化为 K=1，绝不静默超时。

**P4 一切增强可退（可退化）**
热传感器缺失 → `λ(τ)` 取仅基于时延的保守常数；CRS 缺失 → 门禁空过但所有增益标 `uncertified`（诚实性优先）；热模型失效 → 回退 v4；任一环节失效 → v4 → v3 → ToolGauge。

## 3. 与基线的接口（如何退化）

- 无热传感器 ⇒ `λ(τ)` 退化为仅时延项，`D_eff = D_base + const`，等价于 v4 的漂移界（常数吸收进阈值）；
- CRS 不可用 ⇒ 门禁空过，所有改进主张标 `uncertified`，但仍可运行；
- 热不可行 ⇒ 降低传感/决策频率或 K=1；仍不可行 ⇒ 安全停机并降温（显式报 SLA 违约）；
- ToolGauge/InstructGauge 链 ⇒ 逐级回退至 MODGAUGE 原样。

## 4. 预期贡献

1. 一个「先复现、后改进」的**运行时复现门禁**，用热分层配对把环境漂移与算法增益解耦，给出可拒绝的因果归因；
2. 一个热致漂移/时延的显式模型，收紧 `K` 与 `ε_vis` 的**有效界**且保持可证与可退化；
3. 一个热可行性判据 `K_min(τ) ≤ K_max(τ)` 及对应降级策略，避免 50Hz 与时空证书在高热段静默失效；
4. 一条可证伪路径 E473–E490：复现保真、热层覆盖、漂移修正、降频时序、可行域临界温度、假等价抑制与长期漂移。

## 5. 本轮最大风险

**一句话**：热状态与热致漂移的估计一旦系统性偏低，会同时污染「复现等价」与「分块安全」两个证书，使系统在最需要警惕的高温段反而最自信。

## 2. 形式化定义（要点）

**定义 468（热状态与热层）**
```
τ_t = (T_mot, T_drv, T_cmp, T_tgt) ∈ ℝ⁴_+
S_k = { τ : ||τ - c_k||_∞ ≤ h/2 },   {S_k}_{k=1..K_th} 覆盖标定工作域
```
仅当 `τ_t ∈ ∪_k S_k`（在工作域内）才允许给出等价证书；否则 `out_of_calibration`。

**定义 469（规范复现集与黄金轨迹）**
```
CRS = {(σ_r, G_r)}_{r=1}^m
σ_r = (seed, 初始位姿, 对象, 光照, 热工况)
G_r = (a_{1:T}, TF_seq, o_r, τ_{1:T}),   且 sha256(G_r) = h_r（冻结承诺）
```

**定义 470（热致漂移泛函）**
```
δ_th(τ) = δ_kin(τ) ⊕ δ_cam(τ) ⊕ δ_lat(τ)
δ_kin(τ) = J(q) · diag(α) · (T_mot - T_ref)        # 连杆热膨胀 → 末端位姿偏移
δ_cam(τ) = (Δf(T_cmp), Δc(T_cmp))                  # 焦距/主点热漂移
δ_lat(τ) = d₀ · (1/f(τ) - 1)                        # 降频带来的额外决策时延
||δ_th(τ)|| ≤ λ(τ) := λ₁(T_mot-T_ref) + λ₂(T_cmp-T_ref) + λ₃ d₀(1/f(τ)-1)
```
`λ(τ)` 对 `T_mot、T_cmp` 单调不减，对 `f` 单调不增；`λ_i` 由离线标定给出。

**定义 471（有效漂移界与热修正阈值）**
```
D_eff(τ,t) = D_base(t) + λ(τ)
ε_vis^eff(τ) = ε_vis - λ_cam(τ)          # 先扣掉可预测的相机热残差再判定
```

**定义 472（热可行性）**
```
吞吐： t_step(K,τ) = c_mon + d₀ / (f(τ)·K) ≤ T_s = 1/50 s
        ⇒ K ≥ K_min(τ) = d₀ / (f(τ)·(T_s - c_mon))
安全： D_base(K·Δt) + λ(τ) ≤ ε_drift
        ⇒ K ≤ K_max(τ) = D_base^{-1}(ε_drift - λ(τ)) / Δt
Feasible(τ) ⟺ K_min(τ) ≤ K_max(τ),   可行集 K*(τ) = [K_min, K_max] ∩ ℤ
```

**定义 473（热预算）**
```
B_th = (T_lat_max = T_s, T_drift_max = ε_drift, T_thermal_max)
调度器在 K*(τ) 内选 K，同时保证采样率与计算频率不越过 T_thermal_max。
```

**定义 474（热条件等价与复现证书）**
```
对热层 S_k：  ρ_r = W₁( O_cur|S_k , G_r|S_k )   （先做 δ_th 修正）
ReplayCert_r = (σ_r, S_k, ρ_r, 1[ρ_r ≤ β_k], corrections)
聚合接受：Holm–Bonferroni 于 m 个场景上控制族错误率
```

**定义 475（归因增益）**
```
Δ_attr = E[ o_new - o_base | S_k ]
（同层配对、热修正后；要求 positivity：每个 S_k 内两种算法均有观测）
```

**定义 476（热不可行降级算子）**
```
degrade(τ) = cool_down,    若 T_mot 或 T_cmp 超安全上限
           = shed_sensing, 若仅时延不可行（降采样/降频率）
           = K=1,          若仅漂移不可行（最保守仍安全）
           = safe_stop,    若上述均不可行（显式报 SLA 违约）
```

**定义 477（热预算守恒不变量）**
```
Inv_th(τ) : ( K ∈ K*(τ) ) ∨ ( 已显式降级 ∨ 已安全停机 )
```

**定义 478（门禁状态机）**
```
status ∈ {accept, reject, uncertified}
accept: ∀r, ρ_r ≤ β_{k(r)} 且无 out_of_calibration
reject: 存在 r 使 ρ_r > β_{k(r)}（检出回归/漂移）
uncertified: 样本不足、越界或 CRS 缺失（诚实性优先，不冒充 accept）
```

**定义 479（退化映射）**
```
D_TR→WR : τ 不可观测 ⇒ λ = λ_lat（仅时延项）⇒ D_eff = D_base + const
          CRS 缺失   ⇒ 门禁 = uncertified，安全路径不变
```

# IP-335 ThermoState：热状态估计
class ThermoState:
    def __init__(self, T_throttle=85.0, T_ref=25.0):
        self.T_throttle, self.T_ref = T_throttle, T_ref
        rospy.Subscriber('/joint_states', JointState, self._joint_cb)
        rospy.Subscriber('/thermal/compute', ThermalMsg, self._cmp_cb)
        rospy.Subscriber('/thermal/target', ThermalMsg, self._tgt_cb)

    def estimate(self):
        return ThermoVector(T_mot=self.T_mot, T_drv=self.T_drv,
                            T_cmp=self.T_cmp, T_tgt=self.T_tgt)

    def stratum(self, tau):
        return min(range(self.K_th), key=lambda k: dist(tau, self.centers[k]))

    def in_calibration(self, tau):
        return min(dist(tau, c) for c in self.centers) <= self.h / 2

# IP-336 ThermalDrift：热致漂移 / 时延模型
class ThermalDriftModel:
    def __init__(self, d0, c_mon, T_ref=25.0, T_throttle=85.0):
        self.d0, self.c_mon = d0, c_mon
        self.T_ref, self.T_throttle = T_ref, T_throttle

    def f(self, tau):
        # 过热降频：T_cmp 越高，f 越低（分段线性保守下界）
        return min(1.0, self.f_nom * max(0.0,
            (self.T_throttle - tau.T_cmp) / (self.T_throttle - self.T_ref)))

    def lam(self, tau):
        return (self.l1 * max(0.0, tau.T_mot - self.T_ref)
              + self.l2 * max(0.0, tau.T_cmp - self.T_ref)
              + self.l3 * self.d0 * (1.0 / self.f(tau) - 1.0))

    def delta(self, tau, q):
        d_kin = self.J(q) @ (self.alpha * (tau.T_mot - self.T_ref))
        d_cam = self.cam_drift(tau.T_cmp)
        d_lat = self.d0 * (1.0 / self.f(tau) - 1.0)
        return d_kin, d_cam, d_lat

    def eps_vis_eff(self, tau, eps_vis):
        return max(0.0, eps_vis - self.l2 * max(0.0, tau.T_cmp - self.T_ref))

# IP-338 ThermalBudget：热可行域内选块长
def choose_K(tau, env, budget, model, K_pref):
    T_s = 1.0 / 50.0
    f = model.f(tau)
    K_min = ceil(model.d0 / (f * (T_s - model.c_mon)))
    slack = budget.eps_drift - model.lam(tau)
    if slack <= 0.0:
        return None                      # 热不可行（漂移预算已耗尽）
    K_max = floor(D_base_inv(slack, env) / env.dt)
    if K_min > K_max:
        return None                      # 吞吐与安全不可兼得
    return int(clamp(K_pref, K_min, K_max))

# IP-334 / IP-337 CRS 复现门禁（异步、非实时路径）
class CRSHarness:
    def __init__(self, crs, thermo, beta):
        self.crs, self.thermo, self.beta = crs, thermo, beta

    def replay(self, runner, r):
        sigma, G, h = self.crs[r]
        assert sha256(G) == h           # 黄金轨迹完整性
        tau = self.thermo.estimate()
        k = self.thermo.stratum(tau)
        O = runner.run(sigma)           # 当前流水线在相同场景重放
        O_corr = self.thermo.correct(O, G, tau)   # 扣除 δ_th
        rho = wasserstein1(O_corr.outcome, G.outcome_stratum(k))
        return ReplayCert(sigma, k, rho, rho <= self.beta[k],
                          corrections=(tau,))

    def gate(self, runner):
        certs = [self.replay(runner, r) for r in range(len(self.crs))]
        if any(not self.thermo.in_calibration(c.tau) for c in certs):
            return "uncertified", certs
        ok = holm_bonferroni([c.rho <= self.beta[c.k] for c in certs])
        return ("accept" if ok else "reject"), certs

# IP-339 TR-7C：实时路径内只做热预算 + 复用 v4；门禁异步
def instructgauge_tr(M, s, ell=None):
    # 0. 热状态与热预算（实时、O(1)）
    tau = M.thermo.estimate()
    K = choose_K(tau, M.env, M.budget, M.tdrift, M.K_pref)
    if K is None:                        # 热不可行：显式降级，绝不静默违约
        return M.degrade(tau, reason="thermal_infeasible")

    # 1. 接地与假设（同 v4）
    iota = M.nlib.ground(ell, M.scene, M.ontology) if ell else M.default_iota
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)

    # 2. 用热修正后的漂移界规划分块
    C = M.iac.plan_chunk(iota, H, M.tools, K,
                         M.drift_bound(s, tau=tau))     # D_eff(τ,t)

    # 3. 刚体前缀封闭（同 v4）
    if not M.kloop.verify_prefix_closed(C)[0]:
        C = M.iac.plan_chunk(iota, H, M.tools, 1, M.drift_bound(s, tau=tau))

    # 4. 时空一致性检查使用热修正阈值 ε_vis^eff(τ)
    tf_seq = M.wristcam.get_spatial_trajectory(M.env.time(),
                                               M.env.time() + C.duration())
    eps_eff = M.tdrift.eps_vis_eff(tau, M.epsilon_vis)
    pre_cert = generate_spatial_cert(C, tf_seq, eps_eff)

    # 5. 执行 + 实时 TF 监控（同 v4，阈值改用 eps_eff）
    for t, action in enumerate(C.actions):
        if not M.cvc.joint_pre(action) or not still_grounded(iota, M.env):
            break
        M.env.apply(action)
        cur = M.wristcam.get_latest_tf()
        if cur and not M.ros_cvc.verify_tf_consistency(cur, C.psi_post, eps_eff):
            C = C.truncate(t)
            break

    # 6. 证书与主张（同 v4）
    spatial_cert = generate_spatial_cert(C, tf_seq, eps_eff)
    receipts = M.tcv.get_receipts()
    run = M.runner_factory(C, iota)
    claims = bind_claims(C, iota, receipts)

    # 7. 复现门禁：异步提交，不阻塞 50Hz；未通过则主张降级为 uncertified
    spawn_async(M.crs_async.submit, run, claims)
    return C, spatial_cert, claims

# IP-340 主闭环：50Hz 只增热预算 O(1)，门禁在空闲/认证时刻
def InstructGauge_TR_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            spawn_async(instructgauge_tr, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 63（复现门禁的因果归因）** 设热状态 `τ` 是「基线漂移」与「观测结果」的共同原因，且每个热层 `S_k` 内两种算法都有正概率被观测（positivity）。则在同一热层内比较、并扣除 `δ_th` 后，测得的 `Δ_attr = E[o_new - o_base | S_k]` 沿后门路径 `τ → o` 被阻断，可解释为算法改动的因果效应。证明：对 `τ` 分层等价于对混杂做后门调整；`δ_th` 修正移除了 `τ` 对结果的直接可预测分量，故剩余差异不含热混杂。

**引理 64（有效漂移界的可证性与单调性）** `D_eff(τ,·) = D_base(·) + λ(τ)` 对 `K` 与 `ΔT` 均单调不减，且 `λ` 为真漂移的上界。因此 `K_max(τ) = D_base^{-1}(ε_drift - λ(τ))/Δt` 有定义且随 `T` 单调不增；任意 `K ∈ [K_min, K_max]` 同时满足安全与吞吐。证明：`D_base` 可逆且单调，`λ` 非减，复合后 `ε_drift - λ` 非增，故上界存在且单调。

**引理 65（热可行域随温度收缩）** `f(τ)` 对 `T_cmp` 单调不增，`λ(τ)` 对 `T_mot、T_cmp` 单调不减，故 `K_min(τ)` 单调不减、`K_max(τ)` 单调不增。于是可行域 `[K_min, K_max]` 随温度单调收缩，存在临界温度 `T*` 使其由非空转空。证明：由定义 472 直接对温度求单调性即得；`K_min > K_max` 的首次发生点即 `T*`。

**引理 66（时序守恒或显式降级）** 若 `Feasible(τ)` 为真，调度器选出的 `K ∈ K*(τ)` 保证 `t_step ≤ T_s` 且 `D_eff ≤ ε_drift`；若为假，`degrade(τ)` 必进入四种显式分支之一。故系统绝不出现「既超时又不报告」的静默违约。证明：由 `Inv_th` 不变量（定义 477）与 `degrade` 的分支穷举即得。

**引理 67（接受证书的可靠性）** 若 `λ(τ)` 是真实热漂移的保守上界，且 `β_k` 由热层内共形校准给出，则 `accept` ⇒ 真等价（soundness）；假接受率不超过共形误覆盖率 `α_k`。证明：保守上界保证扣除后不残留系统性热偏差；共形阈值的边际覆盖保证 `ρ > β_k` 的越界概率受 `α_k` 控制，Holm 校正控制多场景族错误率。

**引理 68（几何退化等价）** 当 `τ` 不可观测时取 `λ = λ_lat`（仅时延项），`D_eff = D_base + const`；将常数吸收进 `ε_drift` 后与 v4 的 `drift_bound` 等价，`ε_vis^eff → ε_vis`。故热组件缺失时严格退回 InstructGauge-WR。

**定理 1（热可行域与安全时序相容）** 在定义 468–477 下：若 `Feasible(τ)`，则存在 `K` 使分块既满足 50Hz 又不突破有效漂移界；若 `¬Feasible(τ)`，则任何 `K` 都不可能同时满足两者，`degrade(τ)` 是唯一不失诚实的处置。证明：综合引理 64（两约束的单调上下界）与引理 66（不变量与分支完备）即得。

## 5. 复杂度分析

| 组件 | 域 | 时间 | 空间 | 正确性锚 |
|---|---|---|---|---|
| ThermoState | 传感 | O(1)/采样 | O(1) | 定义 468 |
| ThermalDrift `.lam/.f` | 估计 | O(1) | O(1) | 定义 470 |
| `delta(τ,q)` | 估计 | O(d·dim q) | O(d) | 定义 470 |

## 8. 本轮最大风险

**一句话**：热状态与热致漂移的估计一旦系统性偏低，会同时污染「复现等价」与「分块安全」两个证书，使系统在最需要警惕的高温段反而最自信；缓解靠保守上界、越界拒证与多模态冗余（关节温度 + 驱动电流 + 相机暗电流），代价是更高的降级/停机频率。
