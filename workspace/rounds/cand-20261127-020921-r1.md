# 研究循环·新灵感第 1 轮：低成本方案 × 多轮对话

> **基线**：MetricVoiceGauge-NCD-HUTDH-v23 + IP-425–439（v23 已有 HDL/PGEV 分层义务、ACSC 机械臂配空间证书、DCSC 深度 conformal 语义证书、CESC 云边原子切换、FSVC 少样本有效证书、IPAM 知识产权认证、HPC-E+ 四证准入门与 CFC+++ 分层共识；其上承 v21 语义-规范层 SDC/CAC/DCL/GIC 与 v19/v17 感知证书链）。
> **本轮纪律**：不推倒 v23。PCA/CTS/CFC/HPC/CFCtrl、SDC/CAC/DCL/GIC、HDL/ACSC/DCSC/CESC/FSVC/IPAM、HPC-E+ 与 `Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 全部保留。本轮只做一件事：**在 v23 的“全量证据、全量验证”之上加一层“证据经济学 + 多轮对话证据”层，把“每帧都买最贵证据”改成“在预算内购买能改变决策的证据”，把“对话”从命令通道改造成带统计覆盖与安全不对称性的昂贵证据通道，并给出低成本下的安全继承证明**。

## 0. 直觉与动机

### 0.1 灵感一：低成本方案——安全不是“每帧都买最贵的证据”

**直觉。** v23 的默认操作是“全量证据、全量验证”：每帧跑检测/能量/云边/少样本/IP 四证，每个机器人都参与共识，必要时还要人确认。这在安全上无可指摘，却把成本压到最高：算力、能耗、带宽、人的注意力都被当作免费资源。真实部署中，成本不是工程细节，而是**安全策略的一部分**：如果每帧都贵，系统就会被迫降低频率、减少机器人、关掉某些检查，最后以“降本”的名义破坏安全。低成本的正确目标不是“少做检查”，而是**只在证据能改变决策时购买证据**。

更反直觉的是：**便宜证据可以比昂贵证据更安全——只要它保守**。便宜的单目/低分辨率/蒸馏模型可能漏检，但它可以把障碍物膨胀得更大、把自由空间收缩得更小；这样的证书虽然损失活性，却不会制造假自由空间。昂贵证据的作用不是“从无到有地产生安全”，而是**把保守性赎回来，换回活性**。因此可以把证书看成一种“商品”：有价格、有精度、有新鲜度、有独立性；安全策略是一个**预算约束下的证据采购问题**。

严谨地说，“低成本方案”覆盖五类成本，而不是只指硬件价格：

1. **硬件成本**：LiDAR → 单目/超声/低线束雷达；
2. **算力成本**：大模型 → 蒸馏模型、早退网络、级联分类器；
3. **通信成本**：全量点云/证据 → 压缩证书、哈希+区间、按需审计；
4. **人时成本**：自由对话 → 模板问答/手势提示/零轮默认；
5. **能耗成本**：证书计算本身的能耗也必须计入 PGEV 的能量账户。

它们统一进一个成本向量 `c_p`，而不是分别打补丁。关键纪律：**碰撞检查、STOP、DCL 禁止项、当前障碍物更新、在场复核属于“不可交易的安全核”，永远不参与成本优化**；只有“精化证据 / 赎回活性 / 澄清意图”可以按预算采购。

### 0.2 灵感二：多轮对话——对话是“昂贵的证据采集动作”，不是命令通道

**直觉。** 单轮意图识别很脆：一句“你走吧”可能是让行、可能是反讽、可能是对别人说。多轮对话的价值在于**用上下文和一致性消解歧义**。但对话也是所有证据里最贵、最不可靠的一种：它消耗人的注意力，可能被误解、敷衍、欺骗，接上 LLM 还会幻觉和被提示注入。因此不能把“多轮对话”理解成“让机器人更自然地聊天”，而应理解成**一个带预算、带期限、带安全不对称性的证据协议**：多数时候最优轮数是 0；只有当“问一句”的信息价值超过人时成本与风险时，才值得开口。

关键安全不对称：**收紧可以便宜，解锁必须昂贵**。任何回答都可以立即增加限制（例如“这里不能进”），但只有满足“高置信意图 + 身份/角色 + 目标区缺席证书 + 独立佐证 + 无 STOP”的**许可见证 (Permission Witness)** 才允许解锁。矛盾的回答取交集/最严者，连续矛盾升级为交接或 SafeStop；LLM 只产生“未验证的槽位提议”，永远不能直接驱动执行。

多轮对话还有一个漂亮的结构性事实：**任何人类回答都构造性地证明“至少某处有人”**（哪怕回答是“没人”）。因此对话通道是人体检测的独立召回冗余：一旦有回答，与之空间支撑重叠的缺席证书必须拒发。反过来，**沉默不等于无人**：没有回答只说明“没有证据”，不能赎回自由空间。这是低成本对话与 v23 缺席证书之间最重要的安全接口。

### 0.3 统一：成本感知的多轮证据协商（CAMTEN）

把两者统一为 v23 之上的**证据经济学层 (Cost-Aware Multi-Turn Evidence Negotiation, CAMTEN)**：

- **证书是带价格的保守近似**：`C = (Obs, Free, β, τ, v, κ_ind, price, proof)`；便宜证书满足 `Obs` 更大、`Free` 更小，因此 `Exec(C_cheap) ⊆ Exec(C_exact) ⊆ Exec_v23`。
- **调度器是预算约束下的证据采购器**：按“认证信息价值 / 成本”选下一个证据动作；预算耗尽就停在当前保守证书上，绝不跳过安全检查。
- **对话是证据动作之一**：价格含人时、延迟与风险；默认零轮；高门槛解锁、低门槛收紧；多轮用 sequential e-process 维持 anytime-valid 覆盖。
- **缓存/复用/联邦/蒸馏都是“降低同一证据的价格”**，但必须携带新鲜度与独立性证明，不能把“省成本”变成“省掉缺席证据”。

统一准入门：`HPC-EC = HPC-E+ ∧ BudgetFeasible ∧ ReuseSound ∧ DialogueValid ∧ NonTradableCore`；`Exec_v24 = Exec_v23 ∩ Fil_cost ∩ Fil_dlg ⊆ Exec_v23`。

## 1. 研究问题

- **Q1（便宜证书的保守精化代数）**：如何定义带成本、新鲜度、独立性与失败概率的证书，使“任意调度前缀”都安全？保守证书的偏序 `⊑`、精化算子与组合规则如何形式化，才能保证 `Exec(C_cheap) ⊆ Exec(C_exact)` 且不会因近似而制造假自由空间？蒸馏/早退/低线束传感器如何通过 conformal 膨胀获得 soundness 契约？

- **Q2（预算与信息价值）**：在有限预算 `B_t`（延迟/能耗/带宽/人时）下，如何分配证据采购以最大化“安全约束下的活性”？`VoI/cost` 在什么条件下是单调子模的，贪心有何近似保证？若子模性不成立，在线 bandit 如何只损失效率而不损失 anytime 安全性？证书计算能耗如何并入 PGEV 的 `E_res` 账户？

- **Q3（时空复用与缺席证据）**：证书在时间/空间/机器人之间复用的 soundness 条件是什么？如何用状态漂移、相对定位误差、时间同步误差给出 staleness 上界 `ε_reuse`？缺席证书能否缓存——如果不能，短 TTL + 在场复核的最小安全条件是什么？版本切换（CESC）、分布漂移（FSVC/DCSC）如何强制失效？

- **Q4（多轮对话的统计有效性与安全不对称）**：如何让每一轮回答的意图/槽位预测集具有 `1-α` 覆盖，并在“机器人可选停止提问”的多轮情形下保持 anytime-valid？如何设计许可见证，使 LLM 幻觉、提示注入、用户误答/撒谎都不能造成假许可？矛盾回答如何融合为最严约束？对话轮数、TTL、截止时间如何与 50Hz 控制环协调？

- **Q5（成本感知联邦与审计）**：如何避免“多个便宜且相关的传感器/模型”形成伪共识？独立性如何标注、去重、加权？压缩证书 + 随机审计能否在低带宽下检测不诚实/失配证书？成本账本如何进入 Merkle 审计链，使“当时为什么买/不买这条证据”可回放？

- **Q6（低成本巡检与漂移）**：当预算长期偏低时，如何保证低频的高成本证据不被系统性饿死（尤其缺席/在场证据）？风险敏感（CVaR/长尾重要性采样）的预算保留如何设计？新用户、新环境、新光照下的 conformal 重校准如何以 O(1) 开销触发？

## 2. 设计原则（在 P34–P42 基础上新增 P43–P48）

**P43 证据定价与预算可行律（Evidence Pricing & Budget Feasibility）**
每个证据提供者 `p` 携带成本向量 `c_p = (c_lat, c_E, c_bw, c_h, c_risk)` 与 soundness 契约 `β_p`。调度序列 `σ` 必须满足 `Σ_{p∈σ} price_w(p) ≤ B_t` 且 `Σ c_E ≤ B_E`；预算不足时退化为更便宜的**保守**提供者或停机，绝不跳过安全核。`NonTradableCore = {STOP, 当前 Obs 碰撞检查, DCL 禁止项, 在场复核}` 永不参与交易。证书计算能耗计入 PGEV：`E_res ≥ E_motion + E_cert + E_fallback + E_reach_safe + E_margin`。

**P44 Anytime 保守精化律（Anytime Conservative Refinement）**
便宜提供者返回保守证书：`Obs_cheap ⊇ Occ(w)`、`Free_cheap ⊆ Free(w)`。精化只能通过**完成的**证书进行；若超时、崩溃或 soundness 检查失败，保留旧证书。任意调度前缀返回的 `C_t` 都满足 soundness；计划执行集随精化单调扩张但始终 `Exec(C_t) ⊆ Exec_v23`。控制路径最多一个 pending 精化，其余异步；控制环只做 O(1) 的 `Exec(C_t)` 成员查询。

**P45 时空证书复用律（Spatiotemporal Certificate Reuse）**
缓存证书 `C_{t0}` 在 `t` 可复用，仅当 staleness 上界 `ε_reuse = L_obs Δt + L_pose‖Δpose‖ + L_dyn Δt² + ε_model` 不超过当前决策裕度 `margin`，且版本（CESC）与漂移检查通过。缺席证书的复用额外要求 `Δt ≤ τ_abs` 且当前时刻通过**独立在场复核**；一旦有空间支撑重叠的在场证据，缺席缓存立即撤销。跨机器人复用还必须计入相对定位与时钟误差。任何不确定都向保守方向失效。

**P46 信息价值/成本调度律（Value-of-Information per Cost）**
在当前信念 `H_t` 下，证据动作 `a` 的认证信息价值下界为
`\underline{VoI}(a|H_t) = \underline U(Exec(C_a)|H_t) − U(π*|H_t) − \overline{price}(a)`。
选择使 `\underline{VoI}/price` 为正且最大的动作；若不存在正下界，立即停止并返回当前保守证书。对话提问 `q` 是一种动作，其价格含人时 `c_h`、延迟 `c_lat` 与误解放大风险 `c_risk`；仅当 `\underline{VoI}(q) > price(q)`、轮数/截止时间允许且预算可负担时才提问。**零轮是默认策略**。若活动效用对证据集是单调子模的，成本效益贪心有常数因子近似；否则用在线 bandit 学习调度，安全性不依赖学习质量。

**P47 多轮对话证据律（Multi-Turn Dialogue Evidence）**
每轮回答产生槽位预测集 `Γ_i` 与 e-value `E_i`；在“未授权”零假设下 `E[E_i] ≤ 1`，乘积 `M_t = ∏ E_i` 是非负鞅，Ville 不等式给出 `P(∃t: M_t ≥ 1/α) ≤ α`，从而支持可选停止下的 anytime-valid 假许可控制。**收紧无条件立即生效；解锁必须同时满足许可见证**：
`W_perm = 明确允许 ∧ Γ_allow ⊆ {ALLOW} ∧ M_t ≥ 1/α ∧ 角色授权 ∧ 目标区 AbsCert 有效 ∧ ≥2 个独立模态佐证 ∧ ¬STOP ∧ 轮数≤K_max ∧ ¬过期`。
矛盾回答取交集/最严者；连续矛盾 `κ_conf ≥ K_conf` 升级为交接或 SafeStop。LLM 只做受约束槽位解析，输出是未验证提议，DCL 复核后才能改变状态；任何回答都更新在场证据，沉默不更新缺席。

**P48 成本感知共识与审计律（Cost-Aware Consensus & Audit）**
共识按**独立证据类**加权计数，而不是按便宜副本计数：同 `(类别, 框)` 的 NMS 去重；同一模型/传感器/软件栈的票按相关类折扣。压缩证书只广播摘要（哈希 + 区间 + 证明），验证者可按需请求全量证据；以概率 `p_audit` 随机审计，失配即撤销并保守回退。若预算不足以完成独立 quorum 或审计，退回本地保守证书，而不是用未审计的便宜共识放行。所有价格、实际成本、证据购买、对话轮次、缓存命中与最终决策写入 Merkle 成本账本。

## 3. 与基线的接口（如何退化）

- **预算耗尽 / 调度器崩溃** ⇒ 停在最后一个 sound 的保守证书；速度上限只降不升；必要时 SafeStop。安全仍 ⊆ v23。
- **便宜代理 conformal 误差界过宽** ⇒ 升级到昂贵提供者；若昂贵提供者不可用，则按膨胀后的保守证书执行或停机。
- **缓存过期 / 漂移检测触发 / CESC 版本切换** ⇒ 立即失效；重算或退回保守默认。缺席缓存失效时按“可能有人”处理。
- **对话不可用 / 解析失败 / 用户不答** ⇒ 无解锁，回落静态合规默认；只保留已确认的收紧约束。
- **对话矛盾 / 提示注入 / LLM 幻觉** ⇒ 视为未验证证据，只能收紧；达到矛盾阈值转人工或 SafeStop。
- **成本模型严重低估** ⇒ 预算守卫用实测成本强制终止采购，保留安全核与保守证书；安全不受影响，只损失活性。
- **全部新模块失效** ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

## 4. 预期贡献

1. **证书经济学**：首次把“便宜但保守”的证书形式化为带价格、失败概率、新鲜度与独立性的证据商品，并给出 anytime 精化偏序与安全继承条件；
2. **预算化证据调度**：`VoI/price` 调度 + 不可交易安全核 + 实测成本守卫，使低成本只影响活性、不直接影响安全性；证书计算能耗并入 PGEV；
3. **时空复用证书**：给出带漂移/定位/时钟误差的 staleness 上界与缺席缓存的短 TTL + 在场复核规则，降低重复计算与通信成本；
4. **多轮对话证据协议**：以 sequential e-process 保证可选停止下的假许可 ≤ α，以许可见证和矛盾取交保证“误解/幻觉/注入/撒谎不能解锁”，并把“任何回答⇒有人”接入缺席证书；
5. **成本感知联邦共识**：独立性加权 + 压缩证书 + 随机审计，封堵“便宜相关证据的伪共识”；
6. **HPC-EC 统一准入门**：`HPC-E+ ∪ 预算可行 ∪ 复用可靠 ∪ 对话有效 ∪ 安全核` 五证一体，闭环 `Exec_v24 ⊆ Exec_v23`；
7. **可回放的成本审计**：价格、采购、对话、缓存与决策的 Merkle 账本，使“为什么省了这条证据”可审计、可追责。

## 5. 本轮最大风险

**一句话**：成本优化会把“证据”变成可省项——当调度器系统性地低估稀有但关键的证据（尤其是缺席证据、低频高风险场景和对话澄清）时，系统会以“平均成本更低、统计上仍然覆盖”的方式饿死真正能救命的那一次检查，形成**便宜、可审计、但事实错误的证据盲区**。

## 1. 增量符号体系（定义 1000–1060）

| 符号 | 含义 |
|---|---|
| `p ∈ P` | 证据提供者（传感器/模型/机器人/对话提问/审计） |
| `c_p = (c_lat, c_E, c_bw, c_h, c_risk)` | 成本向量：延迟、能耗、带宽、人时、风险 |
| `price_w(p) = w·c_p` | 标量价格；`w` 为任务权重 |
| `B_t = (B_lat, B_E, B_bw, B_h)` | 本轮/本周期预算；`R_t` 为扣除安全核保留后的余额 |
| `C = (Obs, Free, β, τ, v, κ_ind, price, proof)` | 成本标注证书；`β` 为失败概率上界 |
| `Obs ⊇ Occ(w)`，`Free ⊆ Free(w)` | 保守 soundness 契约（以概率 `≥1-β`） |
| `Exec(C) = {π : sweep(π) ⊆ Free ∧ sweep(π)∩Obs=∅ ∧ π⊨DCL}` | 证书允许的计划集 |
| `C_a ⊑ C_b ⇔ Exec(C_a) ⊆ Exec(C_b)` | 精化偏序（`C_b` 更精、活性更大） |
| `σ = (p_1,…,p_k)` | 证据调度序列；任意前缀均可返回 |
| `H_t` | 当前信念（占用、在场、意图、规则适用性、漂移） |
| `\underline{VoI}(a|H_t)` | 认证信息价值下界：效用增益下界 − 价格上界 |
| `ε_reuse` | 缓存 staleness 上界（漂移 + 定位 + 时钟 + 模型误差） |
| `τ_abs` | 缺席缓存的最大安全 TTL |
| `d_t = (b_t, slots, commitments, κ_conf, turns, deadline, transcript_root)` | 对话状态 |
| `Γ_i` | 第 `i` 轮槽位/意图预测集（conformal，覆盖 `≥1-α_parse`） |
| `E_i` | 第 `i` 轮 e-value；`E_{H0}[E_i] ≤ 1` |
| `M_t = ∏_{i=1}^t E_i` | 对话证据 e-process；`M_t ≥ 1/α` 才可解锁 |
| `W_perm` | 许可见证（见 P47） |
| `BudgetFeasible(t)` | `Σ price ≤ B_t ∧ Σ c_E ≤ B_E ∧ R_t ≥ 0` |
| `ReuseSound(C, π)` | `ε_reuse(C,t) ≤ margin(π)` 且版本/漂移/在场检查通过 |
| `DialogueValid(d_t)` | 未过期、轮数受限、无未消解矛盾、解析受约束 |
| `NonTradableCore(t)` | 四项安全核全部开启且通过 |
| `Exec_v24 = Exec_v23 ∩ {π : HPC-EC.admits(π)}` | v24 执行集 |
| `CFC-C` | 成本感知联邦共识：独立性加权 + 压缩证书 + 随机审计 |
| `p_audit` | 随机审计概率；`k` 次审计的检测概率 `≥1-(1-p_audit)^k` |

```python
# ============================================================
# 公共数据结构
# ============================================================
@dataclass(frozen=True)
class CostVector:
    latency_s: float
    energy_j: float
    bandwidth_b: float
    human_s: float
    risk: float = 0.0

    def price(self, w: "CostWeights") -> float:
        return (w.lat * self.latency_s + w.energy * self.energy_j
                + w.bw * self.bandwidth_b + w.human * self.human_s
                + w.risk * self.risk)


@dataclass
class Certificate:
    obs: OccupancySet          # 障碍物 over-approximation
    free: FreeSpace            # 自由空间 under-approximation
    beta: float                # 失败概率上界
    t: float
    version: "VersionTuple"
    indep_class: str           # 传感器/模型/软件栈独立类
    price: CostVector
    proof: bytes               # provider 的 soundness 证明/校准元数据
    cache_key: bytes
    fresh: bool = True         # True=本轮新生成；False=来自缓存，需 ReuseSound 复核

    def exec_set(self, dcl) -> PlanSet:
        return PlanSet(plans_inside(self.free) & avoids(self.obs) & dcl.allowed())


@dataclass(frozen=True)
class CostWeights:
    lat: float = 1.0
    energy: float = 1.0
    bw: float = 1.0
    human: float = 10.0       # 人时通常最贵
    risk: float = 100.0


class Provider(Protocol):
    name: str
    indep_class: str
    def estimate_cost(self, H) -> CostVector: ...
    def is_applicable(self, H) -> bool: ...
    def produce(self, H, deadline: float) -> Certificate: ...
    def sound_contract(self, C: Certificate) -> bool: ...


# ============================================================
# IP-440 Evidence Cost Ledger (ECL) — 成本账本与预算守卫
# ============================================================
class EvidenceCostLedger:
    def __init__(self, budget: dict, weights: CostWeights, merkle: "MerkleLog"):
        self.B = budget                  # {'lat':..., 'E':..., 'bw':..., 'human':...}
        self.spent = {k: 0.0 for k in budget}
        self.w = weights
        self.merkle = merkle
        self.safety_reserve = {
            'lat': 0.0,
            'E': 0.10 * budget['E'],     # 预留 10% 给安全核/急停
            'bw': 0.0,
            'human': 0.0,
        }

    def remaining(self, kind: str) -> float:
        return self.B[kind] - self.spent[kind] - self.safety_reserve[kind]

    def can_afford(self, c: CostVector) -> bool:
        demand = {'lat': c.latency_s, 'E': c.energy_j,
                  'bw': c.bandwidth_b, 'human': c.human_s}
        return all(self.remaining(k) >= demand[k] for k in demand)

    def spend(self, p: Provider, measured: CostVector, C: Certificate,
              decision: str, estimated: CostVector = None) -> None:
        for k, v in {'lat': measured.latency_s, 'E': measured.energy_j,
                     'bw': measured.bandwidth_b, 'human': measured.human_s}.items():
            self.spent[k] += v
        self.merkle.append({
            't': C.t, 'provider': p.name,
            'estimated': asdict(estimated) if estimated else asdict(measured),
            'measured': asdict(measured), 'cert_hash': sha256(C.proof),
            'beta': C.beta, 'indep': C.indep_class, 'decision': decision,
            'remaining': dict(self.spent),
        })

    def budget_feasible(self) -> bool:
        return all(self.remaining(k) >= 0 for k in self.B)


# ============================================================
# IP-449 Non-Tradable Safety Core (NTSC) — 永不参与成本优化
# ============================================================
class NonTradableSafetyCore:
    def __init__(self, stop_button, dcl, presence_sensor):
        self.stop_button = stop_button
        self.dcl = dcl
        self.presence_sensor = presence_sensor

    def all_on(self, H, C: Certificate) -> bool:
        return (not self.stop_button.pressed()
                and self.dcl.no_active_prohibition(H)
                and not collides(H.robot_sweep, C.obs)
                and self.presence_sensor.recheck(H).consistent_with(H.presence))


# ============================================================
# IP-441 Anytime Certificate Scheduler (ACS) — 预算化证据采购
# ============================================================
class AnytimeCertificateScheduler:
    def __init__(self, providers: list[Provider], ledger: EvidenceCostLedger,
                 weights: CostWeights, beta_max: float = 1e-6):
        self.providers = providers
        self.ledger = ledger
        self.w = weights
        self.beta_max = beta_max

    def next_action(self, H, deadline: float) -> Optional[Provider]:
        candidates = [p for p in self.providers
                      if p.is_applicable(H) and self.ledger.can_afford(p.estimate_cost(H))]
        if not candidates:
            return None
        # 认证下界：用 conformal/贝叶斯下界估计效用增益，避免乐观偏差
        scored = []
        for p in candidates:
            voi_lb = certified_voi_lower_bound(p, H, self.w)
            price = max(p.estimate_cost(H).price(self.w), 1e-9)
            if voi_lb > 0:
                scored.append((voi_lb / price, p))
        return max(scored, key=lambda x: x[0])[1] if scored else None

    def run_until(self, H, default: Certificate, deadline: float) -> Certificate:
        C = default                       # 保守默认：大 Obs、小 Free
        while time.now() < deadline:
            p = self.next_action(H, deadline)
            if p is None:
                break
            C_new = p.produce(H, deadline)
            # 只接受完成且 sound 的精化；超时/失败保留旧证书
            if (time.now() <= deadline
                    and p.sound_contract(C_new)
                    and C_new.beta <= self.beta_max):
                if refines(C, C_new):     # 只在精化方向上替换，伪代码：Exec(C) ⊆ Exec(C_new)
                    C = C_new
            self.ledger.spend(p, C.price, C, decision="refine/stop",
                              estimated=p.estimate_cost(H))  # 实际部署传入实测成本
        return C                          # 任意前缀均 sound


# ============================================================
# IP-442 Spatiotemporal Certificate Cache (STCC) — 时空复用
# ============================================================
class SpatiotemporalCertificateCache:
    def __init__(self, L_obs=0.5, L_pose=0.1, L_dyn=0.02,
                 tau_abs=0.1, version_checker=None):
        self.entries: dict[bytes, tuple[Certificate, Pose, bool]] = {}
        self.L_obs, self.L_pose, self.L_dyn = L_obs, L_pose, L_dyn
        self.tau_abs = tau_abs
        self.version_checker = version_checker

    def staleness_bound(self, C, t, pose_now) -> float:
        e, pose_t0, is_absence = self.entries[C.cache_key]
        dt = max(0.0, t - e.t)
        dpose = pose_distance(pose_now, pose_t0)
        return (self.L_obs * dt + self.L_pose * dpose
                + self.L_dyn * dt * dt + e.beta)

    def lookup(self, C, t, pose_now, margin, presence_now) -> Optional[Certificate]:
        if C.cache_key not in self.entries:
            return None
        e, _, is_absence = self.entries[C.cache_key]
        if self.version_checker and not self.version_checker.same(e.version):
            return None
        if self.staleness_bound(C, t, pose_now) > margin:
            return None
        if is_absence:
            # 缺席缓存：短 TTL + 当前独立在场复核；回答/进入事件即撤销
            if t - e.t > self.tau_abs:
                return None
            if presence_now.overlaps(e.obs) or presence_now.unknown():
                return None
        return e


# ============================================================
# IP-443 Conformal Cheap Surrogate (CCS) — 便宜代理 + 误差膨胀
# ============================================================
class ConformalCheapSurrogate:
    def __init__(self, cheap_provider, calibrator, alpha=0.01, beta_max=1e-6):
        self.cheap = cheap_provider
        self.cal = calibrator
        self.alpha = alpha
        self.beta_max = beta_max

    def certificate(self, H) -> Certificate:
        raw = self.cheap(H)
        q = self.cal.quantile(raw.score, self.alpha)     # 位置/漏检误差分位数
        # 保守膨胀：障碍物变大、自由空间变小；先验失配则进一步收缩 Free
        C = inflate(raw, eps_loc=q, eps_recall=self.cal.recall_margin(self.alpha))
        C.beta = self.beta_max
        return C

    def should_escalate(self, C: Certificate, margin: float) -> bool:
        return (C.beta > self.beta_max or decision_margin(C) < margin
                or self.cal.drift_detected())

# IP-444 Multi-Turn Dialogue Protocol (MTDP) — 对话是证据动作
# ============================================================
@dataclass
class DialogueState:
    slots: dict
    commitments: list
    contradictions: int = 0
    turns: int = 0
    deadline: float = math.inf
    transcript_root: bytes = b""
    presence_support: "SpatialSupport" = None

    def expired(self, now): return now > self.deadline


class MultiTurnDialogueProtocol:
    def __init__(self, parser, validator, schema, ledger,
                 K_max=3, K_conf=2, tau_dlg=4.0, alpha=0.01):
        self.parser = parser            # 受约束槽位解析器（LLM 仅提议）
        self.validator = validator      # IP-445 sequential validator
        self.schema = schema
        self.ledger = ledger
        self.K_max, self.K_conf, self.tau_dlg, self.alpha = K_max, K_conf, tau_dlg, alpha
        self.state = DialogueState(slots={}, commitments=[])

    def should_ask(self, q, H, budget, deadline) -> bool:
        # 零轮默认；只有认证 VoI 超过人时+延迟+风险才提问
        voi_lb = certified_voi_lower_bound(q, H, budget.w)
        c = q.estimate_cost(H)
        return (voi_lb > c.price(budget.w)
                and self.state.turns < self.K_max
                and time.now() + c.latency_s < deadline - self.tau_dlg
                and budget.can_afford(c)
                and not self.state.expired(time.now()))

    def step(self, utterance: str, H) -> str:
        e = self.parser.parse(utterance, self.schema)
        self.state.turns += 1
        self.state.transcript_root = merkle_append(self.state.transcript_root, e)
        # 任何回答都是“至少某处有人”的构造性证据；按空间支撑撤销缺席
        self.state.presence_support = e.presence_support or UNKNOWN_SUPPORT
        # 收紧无条件生效；解锁需许可见证
        new = fuse_constraints(self.state.slots, e.slots)
        self.state.slots = new
        self.state.commitments.append(e.commitment)
        self.state.contradictions += int(e.conflicts_with(self.state.commitments))
        if self.state.contradictions >= self.K_conf:
            return "HANDOVER_OR_SAFE_STOP"
        self.validator.update(e.e_value)
        if self.permission_witness(e, H):
            return "UNLOCK_WITHIN_DCL"
        return "TIGHTEN_ONLY"

    def permission_witness(self, e, H) -> bool:
        return (e.explicit_allow
                and e.intent_set == {"ALLOW"}
                and self.validator.anytime_pass(self.alpha)
                and e.role.authorized(H.target_zone)
                and H.target_zone.absence_cert_valid(H)
                and len(e.independent_corroboration) >= 2
                and not H.stop
                and self.state.turns <= self.K_max
                and not self.state.expired(time.now()))

    def dialogue_valid(self) -> bool:
        return (not self.state.expired(time.now())
                and self.state.turns <= self.K_max
                and self.state.contradictions < self.K_conf)

    def request(self, q) -> None:
        # 异步投递问题；回答在下一次 step 通过 step(utterance, H) 注入
        self.pending_question = q

# IP-445 Sequential Dialogue Validator (SDV) — anytime-valid 覆盖
# ============================================================
class SequentialDialogueValidator:
    def __init__(self, alpha=0.01):
        self.M = 1.0
        self.alpha = alpha
        self.history = []

    def update(self, e_value: float):
        # e-value 由每轮 conformal 非一致性分数构造，零假设下 E[E_i] ≤ 1
        self.M *= max(e_value, 1e-12)
        self.history.append(self.M)

    def anytime_pass(self, alpha=None) -> bool:
        # Ville 不等式：P(∃t: M_t ≥ 1/α) ≤ α，支持可选停止
        return self.M >= 1.0 / (alpha or self.alpha)

    def recalibrate(self, new_calibration_stream):
        self.M = 1.0
        self.history.clear()
        self.calibrator.update(new_calibration_stream)

# IP-446 Cost-Aware Federated Consensus (CFC-C)
# ============================================================
class CostAwareFederatedConsensus:
    def __init__(self, N, F, ledger, p_audit=0.05, M_MIN_MODALITIES=2):
        self.N, self.F = N, F
        self.ledger = ledger
        self.p_audit = p_audit
        self.M_MIN_MODALITIES = M_MIN_MODALITIES
        self.votes = defaultdict(dict)

    def consensus_round(self):
        results = {}
        for key, votes in self.votes.items():
            indep = dedup_by_key_and_iou(votes)          # NMS 去重
            weighted = independence_weighted_count(indep)
            modalities = {v.modality for v in indep.values()}
            if (weighted >= self.N - self.F
                    and len(modalities) >= self.M_MIN_MODALITIES
                    and self.audit_ok(indep)
                    and self.ledger.budget_feasible()):
                results[key] = majority_with_outlier_filter(indep)
            else:
                # 预算/审计/独立性不足：退回本地保守证书
                results[key] = local_conservative_certificate(key)
        return results

    def audit_ok(self, votes) -> bool:
        for v in votes.values():
            if random.random() < self.p_audit:
                if not verify_full_evidence(v.compressed):
                    return False
        return True

@dataclass
class HPCEconomyGate:
    hpc_e_plus: "HPCEPlus"          # v23 四证：物理/合规/负信息/能量/IP
    ledger: EvidenceCostLedger
    cache: SpatiotemporalCertificateCache
    dialogue: MultiTurnDialogueProtocol
    safe_core: NonTradableSafetyCore

    def admits(self, plan, C: Certificate, H, modules: list[str]) -> bool:
        return (self.safe_core.all_on(H, C)
                and self.hpc_e_plus.admits(plan, H.x, H.v, H.z,
                                           H.E_res, H.margin_req, modules)
                and self.ledger.budget_feasible()
                and (C.fresh or self.cache.lookup(
                    C, H.t, H.pose, plan.margin, H.presence) is not None)
                and self.dialogue.dialogue_valid()
                and C.exec_set(H.dcl).contains(plan))


# ============================================================
# 端到端：低成本证据经济学流水线
# ============================================================
class EconomicalEvidencePipeline:
    def __init__(self, config):
        self.config = config
        self.ledger = EvidenceCostLedger(config['budget'], config['weights'], config['merkle'])
        self.safe_core = NonTradableSafetyCore(config['stop'], config['dcl'], config['presence'])
        self.cheap = ConformalCheapSurrogate(config['cheap_provider'], config['calibrator'])
        self.providers = [self.cheap, *config['providers']]
        self.scheduler = AnytimeCertificateScheduler(self.providers, self.ledger, config['weights'])
        self.cache = SpatiotemporalCertificateCache(version_checker=config['cesc'])
        self.cesc = config['cesc']
        self.cfc = CostAwareFederatedConsensus(
            config['N'], config['F'], self.ledger, config.get('p_audit', 0.05))
        self.dialogue = MultiTurnDialogueProtocol(
            config['parser'], SequentialDialogueValidator(config['alpha']),
            config['schema'], self.ledger)
        self.gate = HPCEconomyGate(config['hpc_e_plus'], self.ledger,
                                   self.cache, self.dialogue, self.safe_core)

    def step(self, sensor_data, deadline, cloud_update=None):
        # 1) 先跑不可交易安全核（永不被预算裁剪）
        if not self.safe_core.all_on(sensor_data.H, self._default_cert(sensor_data)):
            return False, {'reason': 'non_tradable_core'}
        # 2) 处理云边版本（异步；版本变化使缓存失效）
        if cloud_update:
            self.cesc.receive_cloud_update(cloud_update['V'], cloud_update['artifacts'])
        # 3) 便宜优先：命中缓存则直接复用；否则跑 anytime 调度
        C = self._default_cert(sensor_data)
        cached = self.cache.lookup(C, sensor_data.t, sensor_data.pose,
                                   sensor_data.margin, sensor_data.presence)
        if cached is not None:
            C = cached
            C.fresh = False            # 缓存复用：HPC-EC 会再做 ReuseSound 复核
        else:
            C = self.scheduler.run_until(sensor_data.H, C, deadline)
        # 4) 对话作为异步证据动作（只在值得问时）
        if self.dialogue.should_ask(sensor_data.pending_question, sensor_data.H,
                                    self.ledger, deadline):
            # 非阻塞：回答在下一次 step 注入；控制路径只做 O(1) 状态查询
            self.dialogue.request(sensor_data.pending_question)
        # 5) 共识、规划、准入
        consensus = self.cfc.consensus_round()
        plan = self._plan_from_consensus(consensus, C)
        admitted = self.gate.admits(plan, C, sensor_data.H, self._modules(plan))
        return admitted, {
            'certificate': C, 'cache_hit': cached is not None,
            'budget_remaining': self.ledger.spent,
            'dialogue': self.dialogue.state,
            'admitted': admitted,
        }

    def _default_cert(self, sensor_data) -> Certificate:
        # 设计期预置的保守默认证书：全域障碍、空自由空间
        return self.config['default_cert']

    def _plan_from_consensus(self, consensus, C: Certificate):
        return plan_from_consensus(consensus, C)

    def _modules(self, plan) -> list[str]:
        return modules_of(plan)
```

## 3. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| ECL 记账 | O(1) / 证据 | O(证据数) | 账本 Merkle 追加 O(log n) |
| ACS 调度 | O(|P|) ~ O(|P| log |P|) / 决策 | O(|P|) | `|P| ≤ 12`，安全核常数开销 |
| STCC 查询 | O(1) 哈希 + O(1) 上界 | O(缓存条目) | 单机器人缓存 ≤ 200 条 |
| CCS 代理证书 | O(d) 前向 + O(1) 分位数 | O(模型) | 蒸馏模型 < 5MB，早退层 |
| MTDP 单轮 | O(|slots|) + 异步解析 | O(轮数·槽位) | `K_max=3`，`τ_dlg=4s` |
| SDV e-process | O(1) / 轮 | O(K_max) | e-value 数值稳定化 |
| CFC-C 共识 | O(N·M·L + 审计) | O(N·M) | `p_audit=0.05`，N≤16 |
| HPC-EC 准入 | O(|modules| + log|rules|) | O(1) 增量 | 控制路径查询 O(1) |
| 端到端单步 | O(|P| + |slots| + N·M·L) | O(缓存 + 账本) | 控制环 <20ms，对话离线 |

**实时性保证**：控制路径上的 `HPC-EC.admits` 只做 O(1) 查询（当前证书、预算余额、对话有效标志、安全核），不阻塞等待对话/云端/全量检测。昂贵 provider 与对话解析在独立工作线程中运行，超时即放弃并保留保守证书。预算账本每步只追加 O(1)，Merkle 根按周期批量结算。

## 4. 正确性论证

### 引理 1（Anytime 保守 soundness）
**陈述**：在证书 provider 的 soundness 契约成立的前提下，对任意调度前缀 `σ_t`，当前证书 `C_t` 满足：以概率 `≥1-Σ_{p∈σ_t} β_p`，`Occ(w_t) ⊆ Obs_t` 且 `Free_t ⊆ Free(w_t)`；因此 `Exec(C_t) ⊆ Exec_v23`。

**证明**：初始默认证书取全域障碍/空自由空间，显然保守。每次替换只接受满足 `sound_contract` 且 `β ≤ β_max` 的证书；超时、异常或不可比时保留旧证书。由归纳与 union bound 得失败概率不超过累计 `β`。`Exec(C_t)` 只使用 `Obs_t`/`Free_t` 与 v23 的 DCL，故 `Exec(C_t) ⊆ Exec_v23`。∎

### 引理 2（精化单调性与活性扩张的安全边界）
**陈述**：若 `C_a ⊑ C_b`，则 `Exec(C_a) ⊆ Exec(C_b)`；任何精化都不会越过真实安全集，`Exec_v24 ⊆ Exec_v23` 恒成立。

**证明**：由 `⊑` 定义直接得执行集包含关系。精化只把障碍物缩小、自由空间扩大，且扩张由新证书的 soundness 契约与 `β` 预算担保；未完成的精化不改变 `C_t`，故不存在“超时乐观扩张”。HPC-EC 仅接受 `C.exec_set(H.dcl).contains(plan)` 的计划，且包含 v23 的 HPC-E+ 检查，故 `Exec_v24 ⊆ Exec_v23`。∎

### 引理 3（时空复用 soundness）
**陈述**：若 `ε_reuse(C,t) ≤ margin(π)` 且版本/漂移检查通过，则复用 `C` 对计划 `π` 仍 sound；缺席证书在 `Δt ≤ τ_abs` 且独立在场复核通过时 sound，否则按“可能有人”处理。

**证明**：由三角不等式，真实占用与缓存占用之间的 Hausdorff 距离不超过 `ε_reuse`；当 `ε_reuse ≤ margin` 时，缓存证书的保守性仍足以覆盖计划的安全裕度。缺席证书若超过 `τ_abs` 或存在重叠在场证据，则撤销并回退到保守默认；任何回答按空间支撑撤销相应缺席。故复用不引入假自由空间。∎

### 引理 4（多轮对话假许可上界）
**陈述**：在 e-value 构造满足零假设下 `E[E_i] ≤ 1`、解析器覆盖 `≥1-α_parse`、缺席证书 soundness 为 `β_abs` 的前提下，多轮协议产生假解锁的概率不超过 `α + β_abs + α_parse`（取相应预算；若共享 α 预算则更小）。

**证明**：`M_t` 为零假设下的非负鞅，Ville 不等式给出 `P(∃t: M_t ≥ 1/α) ≤ α`，且该界对可选停止（机器人决定是否继续问）仍成立。解锁还要求许可见证：明确允许、意图集不包含其他值、角色授权、目标区 AbsCert 有效、至少两个独立模态佐证、无 STOP、未过期。任一条件缺失即只能收紧，不能解锁。矛盾回答取交集/最严者，连续矛盾升级为交接或 SafeStop。LLM 只产生受约束槽位提议，任何幻觉/注入都是未验证证据，不能单独满足见证。故假解锁概率由上述统计界与 AbsCert/解析失败概率共同控制。∎

### 引理 5（预算降级不损害安全）
**陈述**：若 `BudgetFeasible` 失败或调度器无正 VoI 动作，HPC-EC 返回保守证书/停机；`NonTradableCore` 始终运行，故安全性不因降级而降低。

**证明**：`ACS.run_until` 在预算不足时直接返回当前 `C`；`HPC-EC` 仍执行 `safe_core.all_on` 与 v23 的 `HPC-E+` 检查。降级只减少精化，因而只损失活性，不扩大 `Exec`。∎

### 引理 6（成本感知共识不制造伪共识）
**陈述**：CFC-C 只按独立证据类加权计数；相关副本被 NMS/独立类折扣去重；随机审计以 `≥1-(1-p_audit)^k` 概率检出被审计的不诚实证书。若独立性或审计预算不足，退回本地保守证书。

**证明**：NMS 去重消除同一 `(类别, 框)` 的相关副本；独立类加权使同一模型/传感器/软件栈的票不能重复计数。审计抽样独立，至少一次抽中的概率由二项分布给出。预算不足时 `consensus_round` 明确返回 `local_conservative_certificate`，不会用未审计票放行。∎

### 定理（HPC-EC 的安全-成本-可审计继承）
**陈述**：在引理 1–6 的契约成立时，对任意计划 `π`：
`HPC-EC.admits(π) ⇒ π ∈ Exec_v23`，且
`Exec_v24 = Exec_v23 ∩ {π: HPC-EC.admits(π)} ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。
低成本只改变“在多大预算内获得多少活性”，不改变上述包含链；任何契约违反都触发保守回退或 SafeStop。

**证明**：`HPC-EC` 是 `safe_core ∧ HPC-E+ ∧ BudgetFeasible ∧ ReuseSound ∧ DialogueValid ∧ C.exec_set.contains(π)` 的合取。`HPC-E+` 已保证 `π ∈ Exec_v23`；其余条件只可能进一步收缩或保持执行集（精化在真实安全集内扩张，复用/对话/预算失败均回退保守）。因此包含链成立。成本账本记录每次采购与拒绝，支持离线重放与审计。∎

## 7. 本轮最大风险（最终确认）

**一句话**：当“低成本”被实现为预算优化时，最危险的失败不是算错一次，而是**系统性地不再购买那类很少发生、但一旦发生就致命的证据**——尤其缺席证据与低频高风险场景的对话澄清；它会让系统在统计上仍然“覆盖”、在账本上完全“合规”，却在现实中把一次本可避免的碰撞省成了成本节约。
