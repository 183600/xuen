# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；新灵感循环第 1 轮；本轮灵感：「姿态估计」×「创新点提炼」）

> 第 57 轮把安全赌注押在"证据质量"上：元推断解决少样本、跨模态对账解决单模态共谋、单向信任状态机解决人的不确定性。但所有这些证据都默认了一个未被审计的坐标系——区域 r 是同一个 r、裕度是在正确位姿下算的、两次到访可以池化。姿态估计把这个默认撕开：证据不是标量，而是挂在 SE(3) 帧上的量；帧错了，所有模态会一起错，这是比单模态共谋更深的**几何共模失败**。同时，57 轮、138 个 IP 已出现"创新通胀"：新增机制的边际安全增益递减，评审无法从清单里提炼卖点。本轮用「创新点提炼」把研究本身也做成可证伪对象：以消融实验找承重墙，用最小创新基（IB）替代 IP 堆叠；消融恰好暴露"帧假设"是第 53–57 轮最大的未审计承重假设。核心命题从"证据说可信"升级为 **"坐标系说可信、承重墙说清楚"**。

核心矛盾：
- **H32（证据 vs 坐标系）**：所有证据都在某个帧里测量，但前 57 轮把帧当成免费真值；帧误差不是噪声，而是**乘性偏移**——它会让整片区域的所有模态证据自洽地偏到同一个错误答案上，跨模态对账反而会强化这种一致性。
- **H33（可观测 vs 自信）**：姿态估计在纹理缺失、几何对称、平面接触、打滑时存在不可观测方向；模型仍会给出一个"最像"的位姿和一个小协方差。把不可观测方向当成可观测，就是把无限不确定性伪装成有限不确定性。
- **H34（创新通胀 vs 可证伪）**：机制越加越多，定理越来越长，但每个新机制是否承重、是否与旧机制冗余、是否只是换名，从未被系统审计；成果无法被提炼成三句话，也无法被外部红队有效证伪。

## 0. 直觉与动机

**灵感 1（姿态估计 → 证据必须带帧与方向性协方差）**
直觉：机器人说的每一句"这里能踩"，都隐含"在当前估计的落脚点位姿下能踩"。位姿估计不是感知的前置模块，而是所有证据的**计量单位**。因此每条证据应携带 `(帧来源, 帧到锚帧的 SE(3) 变换, 6×6 协方差, 承重泛函)`，并且只允许报告**沿承重方向**的不确定度，而不是协方差的迹。一个直观例子：平面砂地上单次接触只能观测高度与法向，沿平面的平移与偏航不可观测；用接触把两次到访认成同一区域，等于把不可观测方向当成零不确定性。帧误差还是乘性的：旋转错 3°，十米外的净空就错半米，且所有模态会一起错。

**灵感 2（几何退化 → 不可观测方向即无限不确定性）**
直觉：位姿估计的失败往往不是"估计得不准"，而是"某些方向根本没被约束住"——长走廊、对称隧道、玻璃幕墙、无纹理坡面、单脚平面接触。正确的做法不是给这些方向硬塞一个数值，而是显式维护**可观测子空间**：Fisher 信息矩阵的小特征值方向就是不可观测方向；若承重泛函在该方向有投影，则其不确定度直接置为 ∞。可观测性应成为接触级别的必要条件：O0 不允许不可逆接触，O1 只允许保守动作，O2 才允许正常承诺。

**灵感 3（主动位姿探索 → 用动作买可观测性）**
直觉：如果某个方向不可观测，正确的下一步不是"更相信模型"，而是"做一个能让它变得可观测的动作"——微转、侧移、回环重访、趋近基准物、轻触。这与第 57 轮的探针不同：探针买的是"表面标签"，位姿探针买的是"证据的坐标系"。用 VOI_pose 统一定价，并且严格限制为非破坏性动作与有限预算；位姿探针永远不能把接触级别抬高，只能把不确定性降低或把动作变保守。

**灵感 4（创新点提炼 → 消融找承重墙、最小创新基）**
直觉：57 轮、138 个 IP 已出现边际收益递减。创新点提炼不是写摘要，而是一次可证伪的消融实验：删掉某个机制，安全定理是否还成立？关键指标是否还达标？失败签名是否与另一个机制相同？只有删不掉的才是承重墙；失败签名相同的是冗余，应折叠；既非承重也非冗余的，应归档而不是继续堆叠。最终交付一个**最小创新基 IB**：一组覆盖全部待保性质、依赖关系清晰、每个元素都带新颖性证书与证伪测试的机制。

**灵感 5（三灵感合流 → 从"证据质量"到"坐标系质量 + 创新质量"）**
直觉：姿态估计补上了证据的几何底座，创新点提炼补上了研究的经济学底座。两者共享同一个数学结构——**可辨识性**：位姿估计要问"这个方向被观测到了吗"，创新提炼要问"这个机制被消融验证了吗"；前者是坐标系的规范与可观测性，后者是贡献的规范与可辨识性。安全纵深因此从五层扩展到七层：元先验、OOD、跨模态、裕度、人、**帧/退化**、**证书/消融**。击穿安全需要帧错 ∧ 退化漏检 ∧ 回环假合并 ∧ 跨模态一致 ∧ 无裕度 ∧ 人错 ∧ 证书无效，风险被进一步稀释。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（帧绑定证据 FAE）** 证据 e=(κ_e,y_e,F_e,T_e,Σ_e,t_e)，κ_e 为证据类，y_e 为载荷，F_e 为证据帧（视觉/触觉/本体/接触/地图），T_e∈SE(3) 为 F_e 到地图锚帧的变换，Σ_e∈R^{6×6} 为其协方差。承重泛函 ℓ_e:SE(3)→R^{d_ℓ} 把位姿映射为安全相关量（净空、坡度、接触高度、可落脚面积）。方向性不确定度 u_ℓ(e)=√(tr(∇ℓ_e^T Σ_e ∇ℓ_e))（或沿 ℓ 的最大特征值）。e 在接触级 L 可入证 ⇔ ①帧来源链完整；②配准残差 ≤ρ_max(L)；③u_ℓ(e)≤u_max(L)；④区域身份后验 ≥1−δ_id。帧复合 T_{a→c}=T_{b→c}T_{a→b}，Σ 经伴随一阶传播 Σ_c≈Ad_{T_{b→c}}Σ_bAd_{T_{b→c}}^T+Σ_{b→c}。**只报绝对地图坐标而不报锚帧与协方差的证据一律不合法。**

**定义 146（规范不变对账 GIR 与区域身份假设）** 位姿图 G=(V,E)：节点为到访与地标，边为腿式里程计/视觉/接触/回环/基准物，配 switchable constraints 鲁棒核。区域身份假设 H_{ij}:T_{ij}≈I，其后验由回环似然计算，假合并率 ≤δ_lc。证据池化 ⇔ p(H_{ij}|z)≥1−δ_id 且沿 ℓ 的相对协方差 ≤u_pool；否则保留多假设，不平均、不合并。规范固定：锚定首次到访帧 F_0，所有决策只依赖规范不变量（相对位姿、距离、夹角、法向），绝对坐标只作记录。边缘协方差由 Schur 补给出；漂移定义为沿路径累积的 Σ 增长率。

**定义 147（方向性可观测度与几何退化 DDA）** 测量模型 z=h(x)+ε，J=∂h/∂x，信息矩阵 F=Σ J^T Ω J。特征分解 F=UΛU^T；λ_min≤ε_obs 或 κ=λ_max/λ_min≥κ_max ⇒ 退化。可观测子空间 O=span{u_i:λ_i≥ε_obs}，不可观测子空间 U 为其正交补。方向性不确定度 u_ℓ=√(∇ℓ^T F^+ ∇ℓ)；若 ∇ℓ 在 U 上有非零投影，则 u_ℓ=∞。可观测级 OPL∈{O2,O1,O0}：O2 全 6 自由度；O1 存在弱方向但承重方向可观测且有余量；O0 承重方向不可观测。接触级 L 的必要条件为 OPL≥O_req(L)。

**定义 148（主动位姿探索 APX）** 位姿探针动作 a∈A_pose（微转、侧移、回环重访、趋近基准物、轻触），每动作带风险 r(a) 与信息增益。VOI_pose(a)=E[H(u_ℓ)−H(u_ℓ|a,z')]/cost(a)，用最坏噪声做悲观估计；选择 a*=argmax VOI_pose s.t. r(a)≤B_pose 且 a 非破坏。仅当 u_ℓ≤u_max(L) ∧ OPL≥O_req(L) 才允许承诺；否则在预算 k_pose 内继续探、绕行或进入 L2 协商。位姿探针不得升级接触级别。

**定义 149（帧接地证书 J_g 与 J_pg）** J_g=(G 快照, 锚帧 F_0, 边缘协方差 {Σ_ij}, 回环日志, 退化账本, 地点识别校准, 帧来源链)。J_pg=J_p∪J_g。验证器按日志重放位姿图，检查协方差经验覆盖、回环假阳性率 ≤δ_lc、退化标记与实际一致、每个承诺都引用帧与 u_ℓ。无 J_g 的 J_p 不完整；无帧引用的承诺无效。

**定义 150（创新蒸馏协议 IDP）** 创新组合 P={p_i}，声明 c_i=(m_i,φ_i,a_i,f_i,k_i)（机制/待保性质/依赖假设/证伪测试/成本）。消融算子 A_i：移除 m_i 后重跑证明与关键实验，输出（定理是否仍成立，指标向量，失败签名）。承重集 LB={i: A_i 导致定理失败或关键指标下降 >τ}。冗余 i~j：对所有 φ 的消融效果等价且失败签名相同，保留成本低/确定性高者。依赖 DAG D：p_i 依赖 p_j 的假设。创新基 IB=覆盖全部 φ 的最小 LB 子集（带依赖的集合覆盖；并列时取新颖距离 d_prior 大者）。新颖性证书 N_i=(d_prior, 区分性声明, 证伪测试, 消融增量)。IBC=(IB,D,消融表,N,一句话卖点)。**本轮用 IDP 反审自身：若 FAE/GIR/DDA/APX 不改变安全定理或指标，则它们不是创新，只是工程。**

## 2. 关键算法伪代码（完整版见产物区）

def frame_aware_evidence_gate(e, L, G):
    T, S = compose_frames(e, G)                  # SE(3) 复合 + 伴随协方差传播
    u = directional_uncertainty(e.ell, S)        # 只算沿承重泛函
    if not provenance_ok(e) or u > u_max(L):
        return 'reject', 'frame_uncertain'
    h = region_identity_posterior(e.region, G)
    if h < 1 - delta_id:
        return 'hold', 'identity_ambiguous'      # 多假设，绝不池化
    return 'accept', (T, S, u)

def reconcile_pose_graph(G, edges):
    G = robust_solve(G, edges, kernel='switchable')
    for c in loop_candidates(G):
        if p_false_merge(c) > delta_lc:
            G = fork_hypothesis(G, c)            # 分叉而非合并
    return gauge_fix(G, anchor='first_visit')    # 只保留规范不变量

def observability(F, ell):
    lam, U = eigh(F)
    OPL = level_from_spectrum(lam, eps_obs, kappa_max)
    if norm(project(U[:, lam < eps_obs], grad(ell))) > 0:
        return OPL, inf                         # 承重方向不可观测
    return OPL, directional_u(F, grad(ell))

def active_pose_probe(cp, G, budget):
    while u_ell(cp) > u_max(contact_level(cp)) and budget.pose_left > 0:
        a = argmax(A_pose, key=lambda a: voi_pose_pessimistic(a, G) - risk(a))
        if voi_pose_pessimistic(a, G) < theta_voi_pose: break
        G = execute_pose_action(a); budget.spend_pose(a)
    return G

def innovation_distill(P, theorem, oracle, tau):
    LB = [i for i in P if oracle.ablate(i).theorem_fails
                          or oracle.ablate(i).metric_drop > tau]
    D  = dependency_dag(P)
    IB = min_set_cover(LB, cover=properties(P), dag=D)
    return IBC(IB, D, oracle.ablation_table(), novelty_certificates(IB))

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| FAE | O(1)/证据 + O(d_ℓ²) | O(1)/证据 | 协方差诚实、帧来源完整 |
| GIR | 稀疏求解 O(\|V\|+\|E\|)；选定方向边缘协方差 O(\|V\|) | O(\|V\|+\|E\|) | 回环假合并 ≤δ_lc、歧义不池化 |
| DDA | O(d_x³)，d_x≤6 | O(d_x²) | 退化检测漏报 ≤δ_deg、u_ℓ=∞ 保守 |
| APX | O(k_pose·(\|A\|·(C_voi+d))) | O(\|A\|) | 非破坏、预算终止、不升接触级 |
| FGC | O(\|J_g\|) | O(\|J_g\|) | 可重放、无帧不承诺 |
| IDP | 离线 O(\|P\|·T_ablate + 集合覆盖) | O(\|P\|²) | 消融可复现、依赖 DAG 诚实 |

**正确性定理（Gauge-Aware Soundness, GAS 概要）**：在 A33–A40 上加 (A41) 帧协方差诚实：报告的 Σ_e 在承重方向上的经验覆盖 ≥1−δ_frame；(A42) 回环与区域身份：假合并率 ≤δ_lc，歧义时禁止池化；(A43) 退化检测可靠：OPL≥O_req 时承重方向确实可观测，漏报 ≤δ_deg；(A44) 规范不变：所有决策只依赖 gauge 不变量，J_g 记录锚帧。则：
(i) 帧感知承诺失效率 ≤ 原界 + δ_frame + δ_lc + δ_deg；几何共模失败需要帧错 ∧ 退化漏检 ∧ 回环假合并 ∧ 无保守回退同时发生；
(ii) 交互单调性继续强化：FAE/GIR/DDA/APX 只能经"更诚实的协方差（含置 ∞）"或"更保守的动作（降档/绕行/L2）"影响系统；
(iii) PCE++ 在 k_probes+k_cons+k_pose 内终止于 {承诺, 绕行, L2 协商, 安全停}；
(iv) IDP 条件性：若消融 oracle 与依赖 DAG 诚实，则 IB 之外的 IP 要么冗余、要么不承重；IBC 是最小充分创新证书。

## 6. 本轮最大风险

**一句话**：本轮真正的风险不是"姿态估计不准"，而是**几何共模失败**——一旦帧/配准错误未被检出，所有模态会在同一个错误坐标系里自洽地一致，跨模态对账、元先验、个性化授权都会把这份"一致的错误"加速为承诺；因此必须把区域身份当作假设而非事实，用回环、退化检测与帧接地证书 J_g 三重护栏，任何无帧引用的证据都不得进入承重证据集。

## 2. 关键算法伪代码

### IP-139 FAE（帧绑定证据）

```python
def compose_frames(e, G):
    chain = provenance_chain(e.frame_id, G)          # 接触/传感器 → ... → 地图锚帧
    T, S = G.anchor_T, zeros(6, 6)
    for (T_ab, S_ab) in chain:                        # 逐级复合 + 伴随传播
        T = T_ab @ T
        S = Ad(T_ab) @ S @ Ad(T_ab).T + S_ab
    return T, S

def directional_uncertainty(ell, S, eps=1e-12):
    g = grad(ell)                                    # 承重方向，而非全协方差迹
    return sqrt(max(eps, float(g.T @ S @ g)))

def frame_aware_evidence_gate(e, L, G):
    T, S = compose_frames(e, G)
    u = directional_uncertainty(e.ell, S)
    if not provenance_ok(e) or u > u_max(L):
        return ('reject', 'frame_uncertain', u)
    if region_identity_posterior(e.region, G) < 1 - delta_id:
        return ('hold', 'identity_ambiguous', u)      # 多假设：不池化、不平均
    return ('accept', (T, S, u))
```

### IP-140 GIR（规范不变对账与区域身份）

```python
def gauge_invariant_reconcile(G, odom, loops, fiducials):
    for e in odom + fiducials:
        G.add_factor(e, kernel='huber')
    for c in loops:
        if place_recognition_p_fp(c) > delta_lc:      # 对称走廊/重复纹理防假合并
            continue
        G.add_factor(c, kernel='switchable', switch_prior=p_fp(c))
    G.optimize()
    H = G.marginal_information()                      # 稀疏 Schur 补
    for (i, j) in ambiguous_pairs(G):
        if directional_cov(H, i, j, ell) > u_pool:
            G = fork_identity(G, i, j)                # 保留两个区域假设
    return gauge_fix(G, anchor=G.first_visit)         # 只暴露规范不变量

def pool_evidence(e1, e2, G):
    h = region_identity_posterior(e1.region, e2.region, G)
    if h < 1 - delta_id or directional_cov(G, e1.frame, e2.frame, e1.ell) > u_pool:
        return keep_separate(e1, e2)                  # 身份不明 → 证据不可合并
    return fuse_in_frame(e1, e2, G)                   # 在共同锚帧内融合
```

### IP-141 DDA（方向性可观测度与退化动作）

```python
def observability_ladder(F, ell, L):
    lam, U = eigh(F)
    weak = lam < eps_obs
    Uw = U[:, weak]
    if norm(Uw.T @ grad(ell)) >= tol:                 # 承重方向落在不可观测子空间
        return 'O0', inf
    OPL = 'O2' if not weak.any() else 'O1'
    u = sqrt(float(grad(ell).T @ pinv(F) @ grad(ell)))
    return OPL, u

def degeneracy_action(OPL, L):
    if rank(OPL) < rank(O_req(L)):
        return {'O0': 'defer_or_reroute', 'O1': 'slow_widen'}[OPL]
    return 'nominal'

def apply_observability_to_commit(cp, G):
    OPL, u = observability_ladder(information(G, cp), cp.ell, contact_level(cp))
    if u > u_max(contact_level(cp)):
        return 'defer'                                # 不把不可观测伪装成小方差
    return degeneracy_action(OPL, contact_level(cp))
```

### IP-142 APX（主动位姿探索）

```python
def pose_voi(a, G, cp):
    H0 = entropy(directional_cov(G, cp.frame, cp.ell))
    Hs = [entropy(directional_cov(propagate(G, a, z), cp.frame, cp.ell))
          for z in worst_case_noise_samples(a)]      # 悲观估计，不用均值增益
    return (H0 - max(Hs)) / (cost(a) + risk(a))

def active_pose_probe(cp, G, budget):
    while directional_cov(G, cp.frame, cp.ell) > u_max(contact_level(cp)) \
          and budget.pose_left > 0:
        cands = [a for a in A_pose if not destructive(a) and risk(a) <= budget.b_pose]
        if not cands: break
        a = max(cands, key=lambda a: pose_voi(a, G, cp))
        if pose_voi(a, G, cp) < theta_voi_pose: break
        G = execute_pose_action(a); budget.spend_pose(a)
        if contact_level_after(a) > contact_level(cp):  # 位姿探针永不升接触级
            raise InvariantViolation('pose_probe_escalated_contact')
    return G
```

def ablate(p, theorem, experiments):
    proof = recheck(theorem, removed=p)
    metrics = rerun(experiments, without=p)
    return Ablation(theorem_fails=not proof.holds,
                    metric_drop=max_drop(metrics, baseline),
                    signature=failure_signature(proof, metrics))

def distill(P, theorem, experiments, tau):
    abl = {p: ablate(p, theorem, experiments) for p in P}
    LB = {p for p, a in abl.items() if a.theorem_fails or a.metric_drop > tau}
    nonred = collapse_equivalent(LB, abl)             # 相同失败签名 → 冗余，保留低成本者

               pitch=one_sentence_per_basis_element(IB))

## 3. 关键推导

**命题 58.1（平面接触的三维不可观测性）** 单次接触约束脚端位于一个平面面元上时，测量只约束法向距离与两个切向姿态角；沿平面的两个平移与绕法向的偏航不改变高度与法向读数，因此位于测量雅可比的零空间。其信息矩阵维数为 3，`OPL=O0`（对平面内定位而言）。**推论**：不能用接触证据单独建立区域身份；必须引入外感受回环、基准物或主动位姿探索，否则会把不可观测方向当成零不确定性。

**命题 58.2（帧误差下界）** 若证据 e₁,e₂ 在相对帧误差 ΔT（协方差 Σ_Δ）下被池化，则真实融合协方差满足 `Σ_fused = Σ₁ + Σ₂ + J_Δ Σ_Δ J_Δᵀ`。忽略帧项会使沿方向 v 的声称方差至少低估 `√(vᵀJ_ΔΣ_ΔJ_Δᵀv)`，从而出现"声称覆盖 1−α、实际覆盖更低"的静默失效。**推论**：证据门必须把帧项计入 u_ℓ；无帧引用的证据不得进入承重证据集。

**命题 58.3（创新基覆盖下界）** 若安全定理依赖 k 个相互独立的性质 φ₁..φ_k，则任何可证伪的创新基 IB 必须满足 `|IB|≥k` 且每个 φ_i 至少被一个承重元素覆盖；否则定理不可由 IB 推出。IDP 的最小集合覆盖正是该下界的一个构造性上界。

## 4. 复杂度与正确性

**正确性定理（Gauge-Aware Soundness, GAS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 帧协方差诚实：报告的 Σ_e 在承重方向上的经验覆盖 ≥1−δ_frame；**(A42)** 回环与区域身份：假合并率 ≤δ_lc，身份歧义时禁止池化，规范锚定完整；**(A43)** 退化检测可靠：OPL≥O_req 时承重方向确实可观测，漏报率 ≤δ_deg；**(A44)** 规范不变：所有决策只依赖 gauge 不变量，J_g 记录锚帧与来源链。则：

1. **帧感知承诺健全性**：ID 路径 `P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h(w_max) + δ_frame + δ_lc + δ_deg`；几何共模失败需要帧错 ∧ 退化漏检 ∧ 回环假合并 ∧ 无保守回退同时发生，概率 ≤ δ_frame·δ_deg·δ_lc + o(δ²)。
2. **交互单调性强化**：FAE/GIR/DDA/APX 只能经 (a) 更诚实的信念（含协方差膨胀与 u_ℓ=∞）或 (b) 更保守的动作（降档、绕行、L2、安全停）影响系统；位姿探针不升接触级，不存在升险路径。
3. **终止性**：每检查点 `k_probes+k_cons+k_pose` 有限，PCE++ 终止于 {承诺, 绕行, L2 协商, 安全停} 四态。
4. **部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_frame + δ_lc + δ_deg + δ_xm·1[L1])
             − P(位姿图陈旧未检出) − P(gauge 锚定错误) − P(护盾回退失败)
```

5. **创新蒸馏条件性**：若消融 oracle 与依赖 DAG 诚实，则 IB 之外的 IP 要么冗余、要么不承重；IBC 是覆盖定理全部性质的最小充分创新证书（命题 58.3）。

关键：**坐标系是证据的计量单位**（无帧不承诺）；**不可观测就置 ∞**而不是硬填一个数；**区域身份是假设**，歧义时宁可分叉也不合并；**创新基用消融找承重墙**，删不掉的才进入三句话卖点。

## 7. 本轮最大风险

**一句话**：本轮真正的风险不是"姿态估计不准"，而是**几何共模失败**——一旦帧/配准错误未被检出，所有模态会在同一个错误坐标系里自洽地一致，跨模态对账、元先验与个性化授权都会把这份"一致的错误"加速为承诺；因此必须把区域身份当作假设而非事实，用回环、退化检测与帧接地证书 J_g 三重护栏，任何无帧引用的证据都不得进入承重证据集。
