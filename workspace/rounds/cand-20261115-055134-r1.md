# 第 4 轮（研究线累计；灵感循环第 2 轮；本轮灵感：「数据规模」×「深度相机」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 1/2 轮 MODGAUGE / LeanGauge / ToolGauge 骨架继续原样继承。
> **编号说明**：状态文件当前是研究线第 3 轮，本轮任务把它标为“灵感循环第 2 轮”。为避免跨轮谱系回退，正文保留累计编号“第 4 轮”，括号内保留任务给定的循环编号。
> **本轮纪律**：数据规模只增加“可审计证据的信用”，深度相机只增加“几何证据的凭证”。二者都是可选增强：任一不可用都必须逐级退回 InstructGauge → ToolGauge → LeanGauge → MODGAUGE。

## 0. 直觉与动机

### 灵感 1（数据规模 → 不是“更多样本”，而是“有效证据的信用额度”）

直觉：第 3 轮的 SC-Cal 已经知道“要分层校准”，但它默认每个样本都独立、可用、不过期。真实数据不是这样：同一场景的连续帧高度相关，同一批回执可能既用于拟合又用于校准，旧数据在漂移后会系统性偏斜，众包/日志数据还可能被污染。于是“数据规模”真正要回答的不是“我有多少条样本”，而是“我到底拥有多少条**可交换、未复用、未过期、未被污染**的证据”。名义样本量 `N` 会撒谎；有效样本量 `n_eff` 才是能换成覆盖率的硬通货。

把这个直觉推到底：数据应当被当作一条**信用额度**，而不是一堆原料。系统只能在某个 stratum 上“花”它已经审计过的信用去承诺覆盖率；信用不足时就应当诚实地拒绝认证，而不是用一个大 `N` 假装自信。更隐蔽的是**跨轮复用**：同一个回执如果在第 3 轮用于拟合、第 4 轮又用于校准，名义样本量在涨，可交换性已经破了——这正是多轮研究循环里最容易被忽视的覆盖泄漏。由此得到本轮第一条升级轴：**把数据规模从标量 `N` 升级为四元组 `(n_eff, ε_reuse, ε_contam, age)` 的信用账本**。

### 灵感 2（深度相机 → 不是“多一路图像”，而是“把看见变成量到”）

直觉：深度相机不是又一路 RGB。它把“我看见那里有个东西”升级为“该表面落在一条可计算的误差管内，且相机到该表面的视线是空的”。这天然适合做**几何见证**：第 3 轮的 CVC 只能用回执/漂移做一维否决，而深度可以在三维里直接问“你预测的表面真的在那里吗？有没有被遮挡？自由空间是否成立？”——这是一种比像素回执强得多的证据。

但深度相机的错误是**结构化的**：透明、镜面、多路径、边缘混合像素、低纹理、强光，都会让点云“错得很有自信”。所以深度不能以“一张漂亮的点云”进场，而必须以**证书**进场：逐区域的有效性掩码、偏差校正、误差管、自由空间证书；无效区域一律返回 `⊥`。更重要的是，深度只应被允许做**单向否决**：它能说“预测被几何证据反驳”，但不能说“这个动作安全”。安全权威仍然在盾与 CVC 手里；深度只是把动作集**缩小**，绝不扩大。这样即使深度模型错了，最坏结果是可用性下降，而不是安全性下降。由此得到第二条升级轴：**把深度相机从感知通道升级为带有效域的几何计量仪器**。

### 灵感 3（两者耦合 → 深度数据越多，越容易在罕见 stratum 上“自信地错”）

直觉：深度校准天然是分层的：材质 × 距离 × 入射角 × 光照。数据规模决定你能认证哪些层。一个百万帧的“哑光塑料、室内、0.3–0.8 m”数据集，不能自动认证“抛光金属、强光、75° 掠射”；后者需要它自己的有效样本。**数据规模买的是 stratum 的认证前沿，不是全局的置信度。**

更危险的是相关性：一帧 100 万像素来自一个场景，只是一次 session 级观测，不是 100 万条独立样本。若按像素做共形校准，名义 `n` 会被虚增几个数量级，区间会变得又窄又自信，而真实覆盖率远低于 `1−α`——这就是**尺度幻觉**。再叠加深度相机的**几何幻觉**（点云看起来很完整，但镜面/透明区域其实无效），两者相乘会产生本轮最需要防的失效模式：**系统恰好在最缺少有效证据的罕见 stratum 上，给出最窄、最自信的深度证书。**

解法不是禁用深度或数据，而是把“买证据”也变成一个受控动作：**账本审计**（复用/污染/时效）、**有效样本量**（相关性与设计效应）、**乘积 stratum 上的层次池化**（低样本层向父层收缩）、**scene/session 级 block conformal**（像素不独立）、**几何 VoI 视点规划**（主动去欠认证的层买证据）、**单向否决**（未知即不否决）、**严格退化**（任一证书无效就退回 InstructGauge/ToolGauge）。这条耦合线不是把两个模块拼起来，而是让“数据的信用”和“几何的凭证”互相约束。

## 1. 研究问题（本轮要回答什么）

- **Q1（数据规模的信用）**：在相关、复用、污染、漂移的数据上，如何定义一个可审计的有效样本量，并让共形覆盖保证随 `n_eff` 正确缩放，而不是随名义 `N` 虚胖？
- **Q2（深度的度量）**：如何把深度相机的结构化误差变成带有效域的区域几何证书（误差管 + 自由空间 + 有效性掩码），而不是一张“看起来可信”的点云？
- **Q3（耦合的尺度幻觉）**：当深度校准按乘积 stratum 进行时，数据规模如何决定哪些层可被认证？如何用层次池化、block conformal、主动采样与单向否决，把“又窄又自信”的证书压回可证伪的范围？
- **Q4（退化与实时性）**：当深度不可用、数据信用不足、或账本检测到复用/污染/漂移时，能否严格退回 InstructGauge / ToolGauge，且 50Hz 主路径与热替换纪律不变？

## 2. 设计原则（雏形，正式化见产物区定义 448–463）

**P1 证据信用（Evidence Credit）**
只有同时通过账本审计、相关性折减、时效检查与污染上界的样本，才计入某 stratum 的认证信用。名义 `N` 不是信用；`n_eff`、`ε_reuse`、`ε_contam`、`age` 才是。信用不足 ⇒ 拒绝认证或向父层收缩，绝不用大 `N` 冒充高覆盖。

**P2 深度只在有效域内是证据（Certified Depth, Not Pretty Point Cloud）**
深度证书必须包含：偏差校正、逐区域误差管、有效性掩码、自由空间证书。无效区域（透明/镜面/多路径/边缘/低纹理/强光）返回 `⊥`；`⊥` 就是没有几何证据，退回 2D/偏振/触觉回执，而不是“将就着用点云”。

**P3 单向否决（One-Sided Veto）**
深度一致性检查只能截断或否决，不能扩张动作集；未知或证书无效时不否决。形式化目标：`Exec(DCV(C)) ⊆ Exec(C)`。深度错误最多导致误否决（可用性损失），不能导致越界执行（安全性损失）。

**P4 尺度感知的层次认证（Scale-Aware Hierarchical Certification）**
认证按乘积 stratum `s = (指令层, 深度 regime)` 进行；低样本层向父层部分池化，池化权重由 `n_eff` 决定；跨层借用必须显式记账，不能把“池化”当成免费数据。层内覆盖失败时，逐级向上回退到父层/全局。

**P5 主动采样是受安全门控的动作（Data Acquisition Is an Action）**
当某层信用不足时，系统可以规划视点去“买”证据；但采集本身有移动成本、时间成本与安全风险，必须经过盾与 `q_quiesce` 门控，并在边际 VoI 低于阈值或预算耗尽时停止。数据规模因此不只是离线数据集属性，而是闭环里的一个可控制变量。

## 3. 与基线的接口（如何退化）

- 深度不可用 / `DepthCert = ⊥` / 有效掩码不足 / 区域误差超 `e_max` ⇒ 关闭 DCV 与 GVP，退回 InstructGauge 的 CVC（2D/偏振/触觉回执）；
- 数据信用不足 / 复用泄漏 / 污染超限 / 时效超限 / 漂移超限 ⇒ HSC 退回 SC-Cal 全局阈值 ⇒ ToolGauge；
- ASL 不安全 / 预算耗尽 / 无静默点 / 视点不可达 ⇒ 不做主动采集，使用当前证书；
- 任一新增组件异常 ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE；
- 50Hz 主路径不变；深度采集、账本更新、主动采样与重校准只在异步探测域/块静默点执行。

## 4. 预期贡献

1. 一个“有效证据信用”口径：把数据规模从名义 `N` 拆成 `n_eff`、复用、污染、时效四元组，并给出覆盖随 `n_eff` 的显式缩放与审计证书；
2. 一个漂移下的**最优数据保留尺度律**：证明数据不是越多越好，最优有效样本量随漂移/噪声比按 `(σ/v)^{2/3}` 缩放，为“保留多久、丢弃多少”提供可证伪的定量依据；
3. 一个**深度区域证书 + 几何见证 + 单向否决**：把“看见”升级为“在误差管内量到”，并证明深度模块只会缩小动作集，不会扩大；
4. 一个**尺度感知的层次共形校准 + 几何 VoI 主动采样**：按 stratum 购买证据，低样本层优雅回退，避免“像素当样本”的尺度幻觉；
5. 一条完整可证伪路径：E457–E472 覆盖跨轮复用、`n_eff`、尺度律、层次池化、分层预算、污染、深度校准、block conformal、几何否决、视点规划、主动采样、端到端、消融、时序、sim→real 与对抗投毒。

## 5. 本轮最大风险

**一句话**：数据规模会制造“证据很多”的错觉，深度相机会制造“几何已看见”的错觉；两者在罕见材质/光照 stratum 上相乘，会给出一个又窄又自信、但有效样本量近乎为零的深度证书——系统恰好在最需要保守的地方最自信。

## 2. 形式化定义（要点）

**定义 448（数据台账 DLE 与角色不相交）** `D_N = {(x_i, y_i, p_i)}_{i=1}^{N}`，其中 `p_i = (t_i, scene_i, sensor_i, pose_i, material_i, regime_i, role_i, h_i, nonce_i)`；`role_i ∈ {FIT, CAL, VAL, TEST}`。台账维护 `ledger_root`（Merkle 链）与逐层索引。**角色不相交公理**：在任一认证时刻，`C_cal^s` 与 `C_val^s` 在 **scene/session 级**不相交，而不仅是样本级不相交；同一 scene 不得同时出现在拟合与校准中。`nonce` 防止旧样本重放，`h_i` 绑定原始载荷。

**定义 449（有效样本量）** 对带权重 `w_i` 的样本集，先算时效有效数 `n_t = (Σ_i w_i)^2 / Σ_i w_i^2`；再以组内相关 `ρ`（scene/session 级 ICC 或变差函数估计）做设计效应折减：
`n_eff = n_t / (1 + (n_t − 1)ρ)`。
对空间数据，`ρ` 由区域级变差函数/ICC 估计；对时间数据，`ρ` 由自相关估计。`n_eff ≤ n_nom` 恒成立。

**定义 450（数据信用与尺度膨胀）** `DataCredit(s) = (n_eff^s, n_nom^s, κ_scale^s, ε_reuse^s, ε_contam^s, age_max^s)`，其中 `κ_scale^s = n_nom^s / max(n_eff^s, ε_0) ≥ 1`。层 `s` **可认证**当且仅当 `n_eff^s ≥ n_min`、`κ_scale^s ≤ κ_max`、`ε_reuse^s = 0`、`ε_contam^s ≤ ε_max`、`age_max^s ≤ H*`；否则返回 `⊥`，触发父层池化或全局回退。

**定义 451（乘积证据层）** `s = (s_instr, s_depth)`；`s_instr` 沿用 SC-Cal 的「目标类型 × 指代个数 × 是否含条件」；`s_depth = (material, range_bin, incidence_bin, lighting_bin)`。父子关系 `s ⊑ s'` 表示 `s` 的每个坐标都在 `s'` 的粗化区间内；父层用于部分池化。认证单位是**区域** `R`（平面片/超像素/语义部件），不是单个像素。

**定义 452（HSC 层次化尺度感知共形阈值）** 对层 `s`，先算局部有效分位
`q_s^local = Quantile_{1−α+δ(n_eff^s)}({R_i : i ∈ C_cal^s})`，
其中 `δ(n_eff) = sqrt(log(1/β) / (2 n_eff))` 为有限样本修正。再向父层部分池化：
`q_s = λ_s q_s^local + (1−λ_s) q_{parent(s)}`，`λ_s = n_eff^s / (n_eff^s + κ_s)`。
若 `s` 不可认证，则 `λ_s = 0`，直接用父层；父层也不可认证则用全局阈值。覆盖目标：
`P(h* ∈ H_s | s) ≥ 1−α − δ(n_eff^s) − bias_pool(s)`。

**定义 453（污染/复用鲁棒共形）** 设校准残差可能被 `ε` 比例污染。先以 `ε_hat` 估计污染率（交叉验证 + 物理一致性 + 残差截断），修剪最大的 `⌊ε_hat n_eff⌋` 个残差，再取分位。覆盖下界：
`P(h* ∈ H_s | s) ≥ 1−α − ε_hat/(1−ε_hat) − δ(n_eff^s)`。
若 `ε_hat > ε_max` 或台账检测到角色重叠/重放 ⇒ `⊥`。**复用泄漏**单独记账为 `ε_reuse`，不混入污染率。

**定义 454（深度观测模型与度量校准）** 对像素 `u`：
`z(u) = ζ(u) + b(u; m, r, θ) + ε(u)`，
`E[ε(u)] = 0`，`Var[ε(u)] = σ²(u)`，`Cov(ε(u), ε(u')) = σ(u)σ(u') ρ_s(‖u−u'‖/ℓ)`。
`b` 为系统偏差，依赖材质 `m`、距离 `r`、入射角 `θ`；`σ` 异方差（距离、反射率、纹理、边缘）；`ρ_s` 为空间相关函数，`ℓ` 为相关长度。用标定靶（平面/球/阶梯）在多材质、多距离、多角度、多光照下拟合 `b̂, σ̂, ℓ̂`，得到偏差校正深度 `z̃ = z − b̂`。校准表本身入台账，附 `role=CAL`。

**定义 455（有效性掩码与区域深度证书）** `mask(u) ∈ {VALID, INVALID, UNKNOWN}`，由多视角一致性、强度/散斑、偏振线索、距离上下限、边缘混合像素检测联合判定。对区域 `R`，鲁棒拟合表面 `Ŝ_R`，取残差分位得 `e_R`，构造误差管
`T_R = {x : dist(x, Ŝ_R) ≤ e_R}`。
`DepthCert(R) = (Ŝ_R, e_R, mask_R, vis_R, ledger_ref)`；若 `mask_R` 的有效比例 `< 1−η` 或 `e_R > e_max`，返回 `⊥`。覆盖目标（层内可交换、session 级 block conformal 下）：
`P(S_R ⊂ T_R) ≥ 1−α − δ(n_eff^R) − b_max`。

**定义 456（几何见证与自由空间证书）** 对假设表面区域 `R`，定义三值见证
`witness(R) = +1` 若 `T_R` 与预测表面一致且自由空间 `F_R` 被认证；`−1` 若 `T_R` 与预测表面矛盾；`0` 若未知/`⊥`。
自由空间证书 `F_R`：从传感器到 `R` 的每条射线在到达 `T_R` 前不存在实测点（在 `e_R` 容差内）；其置信度由 `1−α` 与有效掩码共同给出。

**定义 457（几何漂移与深度否决）** 对块 `C`，预测点云 `P_pred(C)`、实测点云 `P_obs`，定义截尾几何漂移
`drift_geo(C) = max(d_H^trim(P_pred, P_obs), d_H^trim(P_obs, P_pred))`。
若 `witness(R) = −1` 且 `R` 是块 `C` 声称覆盖的区域，或 `drift_geo(C) > δ_g` 且见证为反驳，则在导致不一致的动作前截断；若 `witness = 0`，不否决。**单向性**：否决只删除动作，不新增动作。

**定义 458（几何 VoI 与视点规划）** 候选视点 `v ∈ V`，其价值
`VoI(v) = E[Δ CertifiedCoverage | v] / (c_move(v) + c_capture + λ_risk·risk(v))`。
在安全盾、可达性、`q_quiesce` 与预算约束下取 `v* = argmax VoI(v)`；若无可行视点或 `VoI < λ_stop`，返回 `⊥`。`risk(v)` 包含碰撞、不可逆动作邻近度、遮挡与运动学极限。

**定义 459（主动采样与停止）** `ASL`：当 `B_data > 0`、层 `s` 的 `n_eff^s < n_min`、存在安全可行视点且 `VoI(v*) ≥ λ_stop` 时，采集一帧/一组标定样本，写入台账 `role=CAL`，更新 `n_eff` 并重新认证。终止条件：预算耗尽、`VoI < λ_stop`、达到 `N_max`、层已可认证、或安全盾拒绝。`N_max` 是良基终止的兜底。

**定义 460（数据时效与保留时域）** 权重 `w_i = exp(−λ(t − t_i))`，`n_eff(t)` 由定义 449 计算。漂移-方差权衡给出最优遗忘率 `λ*` 与保留时域 `H*`（引理 61）；`age_i > H*` 的样本不进入认证。检测到 P-Quarantine 漂移事件时，重置窗口并降权旧样本。

**定义 461（对抗数据模型）** 对手可控制不超过 `ε` 比例的样本，可任意选择 `(x, y)`，也可重放旧样本或伪造深度帧。防线：台账 `nonce`/角色不相交、物理一致性检查、跨模态回执交叉验证、修剪共形、`ε_hat > ε_max ⇒ ⊥`。对手不能同时伪造足够多的独立 scene/session 而不被台账发现。

**定义 462（尺度感知修复证书 RepairCert″）** `RepairCert″(s) = (ι, C, ChunkCert, DepthCerts, receipts, claims, LedgerRef, DataCredit)`；人类审计可沿「指令 → 块 → 几何证书 → 逐步回执 → 主张 → 数据来源」六级证据链复现一次修复。`claims` 仍是纯投影（继承定义 441）。

**定义 463（SDG-8C 闭环与退化映射）** 阶段为
`I（指令接地）→ H（假设）→ D（数据信用）→ C（块规划）→ E（执行，含 CVC）→ G（几何见证/否决）→ V（校准/交叉验证）→ U（更新/审计）`。
退化映射：`D = ⊥` ⇒ 用 SC-Cal 全局；`G = ⊥` ⇒ 用 InstructGauge CVC；`V` 失败 ⇒ `stub_and_red`；任一阶段异常 ⇒ 逐级回退。`D` 是横切账本，`G` 是单向否决，二者都不改变 50Hz 主路径。

# IP-328 DLE：数据台账、有效样本量与信用
class DataLedger:
    def add(self, sample, role):
        assert role in {FIT, CAL, VAL, TEST}
        self._assert_scene_disjoint(sample.scene, role)   # scene/session 级不相交
        self.chain.append(sha256(self.chain[-1] + sample.digest()).digest())
        self.samples[role].append(sample)
        return self.merkle_root()

    def credit(self, s, now):
        xs  = self.samples_for(s)
        w   = [exp(-LAM * (now - x.t)) for x in xs if now - x.t <= H_MAX]
        n   = len(w)
        if n == 0: return Credit.empty()
        n_t = sum(w) ** 2 / sum(wi * wi for wi in w)
        rho = self.estimate_icc(xs, level="scene")         # 不是像素级！
        n_eff = n_t / (1 + (n_t - 1) * rho)
        return Credit(n_eff=n_eff, n_nom=n, kappa=n / max(n_eff, EPS),
                      reuse=self.reuse_leak(s), contam=self.contam_hat(s),
                      age=max((now - x.t for x in xs), default=INF))

# IP-329 HSC：层次化尺度感知共形
class HSC:
    def quantile(self, s, alpha, now):
        c = self.ledger.credit(s, now)
        if not c.certifiable(N_MIN, KAPPA_MAX, EPS_MAX):
            return self.quantile(s.parent(), alpha, now) if s.parent() else GLOBAL_Q
        delta   = sqrt(log(1 / BETA) / (2 * max(c.n_eff, 1.0)))
        q_local = weighted_trimmed_quantile(self.residuals(s),
                                            1 - alpha + delta,
                                            trim=floor(c.contam * c.n_eff))
        if s.parent() is None:
            return q_local
        q_parent = self.quantile(s.parent(), alpha, now)
        lam      = c.n_eff / (c.n_eff + KAPPA_S)
        return lam * q_local + (1 - lam) * q_parent

# IP-330 DMC：深度区域证书（偏差校正 + 有效掩码 + 误差管 + 自由空间）
class DepthCertifier:
    def certify(self, frame, region):
        z    = self.bias_correct(frame)                    # z - b_hat(m, r, theta)
        mask = self.validity_mask(frame)                   # 多视角/强度/偏振/边缘
        if mask.valid_fraction(region) < 1 - ETA:
            return None                                    # ⊥：无几何证据
        surf = robust_surface_fit(z, region)
        e    = self.block_conformal_quantile(residuals(z, surf, region),
                                             frame.session, 1 - ALPHA)
        if e > E_MAX:
            return None
        return DepthCert(region, surf, e, mask, self.free_space(frame, surf))

# IP-332 DCV：深度一致性否决（只能截断）

        if cert is None:
            return KEEP                                    # 未知 ⇒ 不否决
        w = witness(C.pred[t], cert)
        if w == CONTRADICTED:

# IP-331 GVP：几何 VoI 视点规划
class VoIPlanner:
    def best_view(self, regions, budget):
        best = None
        for v in self.candidates(regions):
            if not self.shield.safe(v, budget) or not self.quiescent(v):
                continue
            gain = self.expected_certified_gain(v, regions)
            cost = self.move_cost(v) + self.capture_cost + LAMBDA_RISK * self.risk(v)
            if cost <= 0: continue
            if best is None or gain / cost > best.voi:
                best = View(v, gain / cost, cost)
        return best

# IP-333 ASL：主动采样与停止
class ActiveSampler:
    def acquire(self, s, budget):
        while budget > 0 and self.ledger.credit(s, self.now()).n_eff < N_MIN:
            v = self.planner.best_view(s.regions, budget)
            if v is None or v.voi < LAMBDA_STOP:
                break
            frame = self.capture(v)
            self.ledger.add(frame, role=CAL)
            budget -= v.cost
            self.recertify(s)
        return self.ledger.credit(s, self.now())

## 4. 推导

**引理 59（有效样本量与覆盖修正）** 设样本在 scene/session 级有平均成对相关 `ρ`，则设计效应 `DEFF = 1 + (n−1)ρ`，`n_eff = n/DEFF`。把共形校准中的 `n` 替换为 `n_eff`，并以 `δ(n_eff) = sqrt(log(1/β)/(2 n_eff))` 做有限样本修正，则在无非交换性时
`P(h* ∈ H) ≥ 1−α − δ(n_eff)`。
若存在复用泄漏 `ε_reuse` 与污染 `ε_contam`，则
`P(h* ∈ H) ≥ 1−α − δ(n_eff) − ε_reuse − ε_contam/(1−ε_contam)`。
*证明骨架*：相关样本的经验 CDF 方差被 `DEFF` 放大，故有效样本数为 `n/DEFF`；DKW/Hoeffding 给出经验 CDF 的一致偏差界；复用把校准集拆成“真独立部分 + 泄漏部分”，泄漏部分的交换性失效，其最坏贡献不超过 `ε_reuse`；污染部分用修剪共形，标准结果给出 `ε/(1−ε)` 的覆盖损失。推论：只报告名义 `N` 的证书不可审计；`κ_scale` 是覆盖虚胖的放大因子。

**引理 60（层次化部分池化的覆盖-偏差权衡）** 设子层与父层分布差异 `TV_s ≤ η_s`。直接用父层分位，子层覆盖至少下降 `η_s`；用子层局部分位，估计方差约为 `σ²/(λ_s n_eff^s)`；部分池化的偏差不超过 `λ_s η_s`。于是
`MSE_s(λ_s) ≤ λ_s² η_s² + σ²/(λ_s n_eff^s)`，
最优 `λ_s* = n_eff^s/(n_eff^s + σ²/η_s²) = n_eff^s/(n_eff^s + κ_s)`。当 `n_eff^s → 0` 时 `λ_s* → 0`，覆盖优雅退化为父层；当 `n_eff^s → ∞` 时 `λ_s* → 1`，收敛到局部分位。*证明*：偏差-方差分解；TV 对覆盖的 Lipschitz 界；对 `λ_s` 求一阶条件并验证二阶导正。推论：低样本层不应被丢弃，也不应被当成独立层；应显式收缩。

**引理 61（漂移下的最优数据保留尺度律）** 设目标以速度 `v` 漂移，样本噪声方差 `σ²`，指数权重遗忘率 `λ`。加权均值的偏差约为 `v/λ`，方差约为 `σ² λ/2`，故
`MSE(λ) ≈ v²/λ² + σ² λ/2`。
一阶条件给 `λ* = (2v/σ)^{2/3}`，最优有效样本数
`n_eff* ≈ 2/λ* ∝ (σ/v)^{2/3}`，保留时域 `H* ≈ 1/λ* ∝ (σ/v)^{2/3}`。
随机游走漂移给出同一指数。*证明*：指数权重的平均年龄为 `1/λ`，方差为 `λ/(2−λ) ≈ λ/2`；对 `λ` 求导并验证二阶导正。推论：**数据不是越多越好**；漂移越大，最优窗口越短；把旧数据无差别加入校准会同时增加偏差、降低 `n_eff`，可能使覆盖变差。这正是 E459 要检验的可证伪尺度律。

**引理 62（深度区域证书的覆盖）** 在深度校准层内可交换、且以 scene/session 为块做 block conformal 时，偏差校正后的区域残差可交换，故
`P(S_R ⊂ T_R) ≥ 1−α − δ(n_eff^R) − b_max`，
其中 `b_max` 是残余偏差上界。若有效性掩码把透明/镜面/多路径区域判为 `INVALID`，则 `DepthCert = ⊥`，不产生误导性覆盖。若错误地按像素做共形，则名义 `n_pix` 与有效 `n_eff^session` 之间相差 `κ_scale = n_pix/n_eff^session`，覆盖损失约 `1 − sqrt(n_eff^session/n_pix)`（最坏情形），即“像素越多，证书越假”。*证明*：session 级块交换性；鲁棒表面拟合的残差；共形分位；偏差校正；设计效应用引理 59。

**引理 63（深度否决的单向安全性）** 对任意块 `C`，`Exec(DCV(C)) ⊆ Exec(C)`；若 `DepthCert = ⊥` 或 `witness = 0`，则 `Exec` 不变。因此深度模块只能删除动作，不能新增动作；深度错误最多导致误否决（可用性损失），不能导致越界执行（安全性损失）。*证明*：DCV 的实现只在 `witness = −1` 时截断；截断保持前缀封闭（定义 434）；对步数归纳，CVC 已保证每步 `Inv`；删除动作不会破坏 `Inv`。推论：深度是“可选的安全增强”，不是安全依赖；这与严格退化链一致。

**引理 64（主动采样的终止与单调改进）** 在有限预算 `B_data`、安全盾与 `λ_stop > 0` 下，ASL 终止；每次成功采集使正权重样本集增大，`n_eff` 单调不减（在固定 `ρ` 与 `λ` 下）；层内可交换时认证覆盖单调不减；若漂移超阈，台账丢弃过期样本并回退，覆盖由引理 59/60 接管。*证明*：`B_data` 严格递减且非负，构成良基测度；`N_max` 兜底；正权重样本的 `n_t` 与 `n_eff` 单调；盾保证采集不跨不可逆屏障。推论：主动采样是“有预算的证据购买”，不是无限探索。

**引理 65（数据规模 × 深度的复合风险界）** 设 `P_data` 为数据信用失效（`n_eff` 不足、复用、污染、漂移）导致覆盖失败的概率，`P_depth` 为深度无效未被掩码识别的概率，`P_couple` 为深度校准层与当前任务层不匹配的概率。则
`P_fail ≤ P_data + P_depth + P_couple`。
若任一模块证书为 `⊥` 或 `κ_scale > κ_max`，SDG 严格退化为 InstructGauge，故
`P_fail ≤ P_fail^InstructGauge`。
*证明*：并集界；退化映射（定义 463）；引理 63 的单向性保证深度不会把失败放大成越界动作；引理 59/60 保证数据侧失败被 `n_eff`/池化/回退吸收。推论：耦合风险是**加性可界**的，而不是乘性爆炸；真正需要主动证伪的是 `P_couple`（罕见材质/光照层的层错配），对应 E463/E464/E471/E472。

| GVP 视点规划 | 异步 | O(\|V\|·\|R\|) < 10 ms，可 anytime | O(\|V\|) | 定义 458 |
| ASL 主动采样 | 异步/静默点 | 受 `B_data` 与 `N_max` 限制 | O(N) | 定义 459、引理 64 |
| 50Hz 主路径 | 内联 | 不变 < 20 ms；新增 < 0.2 ms | 不变 | 继承引理 50/58 |

## 6. 实验设计 E457–E472

## 8. 本轮最大风险

**一句话**：`DLE` 的有效样本量会因相关/复用/漂移被高估，而 `DMC` 的深度证书会在罕见材质/光照层上因 `n_eff` 近乎为零而“窄而自信”；两者相乘的 `P_couple` 是唯一不会被单向否决自动吸收的风险——必须用 E457/E459/E463/E464/E471/E472 主动证伪，否则系统会在最需要保守的地方最自信。
