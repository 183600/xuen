# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「模型量化」×「深度相机」）

> 第 57 轮把安全赌注压到"证据承诺"，并用元少样本、跨模态对账、个性化信任把它垫成五层纵深。但它的结论默默假设了两件事：**(a) 证书是在实数纸上算出来的，而部署是在低比特、算子融合、TF32 与动态量化的真实运行时里执行的**——比特宽度一改，校准契约 ECE_k≤ε_meta(k) 就作废，裕度被舍入误差吞掉，证书却还挂着原来的签名；更阴险的是，共享的低精度瓶颈会把本来独立的视觉与触觉误差"焊"到一起，让第 57 轮 EV-xmodal 的独立性前提在数值层面悄悄失效。**(b) 新加一个传感器不等于新加一个见证**——深度相机带来稠密几何，却与视觉共享光学路径与标定误差；透明冰面、镜面金属、吸光绒布会让两者同时失效；十万个深度像素也不是十万份证据，空间相关把有效样本折成 N_eff≪N。本轮两个灵感正好各拆一个"隐形前提"：**模型量化**迫使证书显式携带比特标号与舍入界，把"估计器可量化、守卫不可量化、分辨率以下无证据"变成硬规则；**深度相机**给地图提供几何见证，但也迫使我们用"失效机制"而非"传感器数量"来定义独立性。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"精度可计量、相关可折减、几何可对账的证据承诺"**。

核心矛盾：
- **H29（量化 vs 证书有效性）**：正确性定理在实数里证，运行时在低比特里跑。量化误差让点估计漂移、校准失效、裕度缩水；沿用旧证书则静默不 sound，一律按最坏精度保守则可用性崩塌。而且量化是*数值共因*：同一条低精度融合瓶颈会让多模态误差相关，凭空制造第 57 轮最怕的"物理共谋"的替身。
- **H30（深度相机 vs 独立见证）**：深度是新的物理通道，却不是免费的独立见证。它与视觉共享光子传输、镜头、标定与场景；透明/镜面/吸光/散射使二者同时出错。稠密像素给出的是*空间相关*观测，N_eff=A/ℓ_c²，把像素数当证据数就是第 57 轮"把同一个问题问五遍"的平方级重演；同一传感器的系统性偏差无法靠更多帧自证。
- **H31（精度预算 vs 可博弈性）**：bit、能耗、延迟是有限资源，精度分配本身可被优化——但优化的对象正是"什么算足够准"。在线自适应精度可能被分布漂移或对抗输入诱导到刚好卡在分辨率下限；把守卫也纳入量化搜索，等于让优化器去优化掉安全。

## 0. 直觉与动机

**灵感 1（模型量化 → 证书必须带"比特标号"）**
直觉：量化像工程图纸上的有效数字。图上标 12.3 mm，就不能拿去证明 12.34 mm 的间隙；同理，一个用 INT8 执行的后验，不能签署一份按 FP32 校准的证书。比特宽度不是部署细节，而是**模型版本**：每换一次精度，校准、覆盖、裕度都换了一个函数。于是本轮把证书改成**精度条件证书**：证书参数写成 (p, Δ_p, ε_meta(k,p))，Δ_p 由区间界传播给出；守卫（证据门、证书检查器、风险累加器、同意状态机）只许跑在**认证精度**或精确整数上，估计器（感知、VOI、元后验均值）才允许低精度。更关键的是**分辨率下限**：当裕度小于量化噪声半径，裕度的符号不可辨识，它就不是证据，必须拒绝或升精度。

**灵感 2（模型量化 → 人工制造的跨模态相关）**
直觉：第 57 轮担心"一个物理机制同时骗过两个模态"。量化制造了一个更隐蔽的版本：**一个数值机制同时作用于两个模态**。若视觉分支与深度分支共享同一低精度瓶颈，输入的小扰动会经由共享的舍入格点产生同向误差——两个"独立"模态在数值层被焊死。EV-xmodal 的独立性必须在**失效机制**层面声明，而不是传感器名字层面；量化共因要计入共模预算 δ_cm，不能靠"视觉+深度两个名字"免单。

**灵感 3（深度相机 → 稠密却相关的几何见证）**
直觉：深度相机给机器人一副"几何卷尺"，可独立复核地图与落脚面——这是它最大的价值。但它是**相关采样**：一块玻璃在深度图上是一整片同向错误，不是十万个独立掷骰。空间统计告诉我们有效样本 N_eff≈A/ℓ_c²，ℓ_c 在深度不连续处更大。深度还自带一套可自检的内部冗余：左右一致性、时序重投影、主动/被动一致、强度-深度边缘对齐；它们能抓住空洞与飞点，却抓不住"平滑而错误"的透明/镜面。因此深度可靠性必须**按材质条件化** ρ_depth(c)，未知材质取 ρ_min，且残余共模失效概率 δ_D 不随像素增多而下降。

**灵感 4（深度相机 → 共享光学路径的共谋）**
直觉：深度和视觉都靠光子，而很多失败恰好是**光子层面的**：透明冰面让两者都"看穿"到背景，于是深度与视觉一致地给出错误答案——这种"一致"不是独立见证，而是同谋。真正的独立见证往往来自另一条物理链：机械接触、本体感受、惯性积分。因此本轮引入**见证代数**：用失效基 ℬ={光子,接触,惯性,数值,人类} 给每个模态打"机制载荷"矩阵；两种证据只有在失效机制近正交时才算独立；不可逆接触必须保留一条非光子、非数值的独立见证，EV-xmodal 与 EV-geo 永远不能替代它。

**灵感 5（合流 → 精度预算交换与探-诺-演++）**
直觉：既然精度是资源，就让它像探针一样被"花在刀刃上"。**精度 VOI** = 每多一个 bit 能消除多少决策歧义；在接近不可逆接触时临时升精度，往往比多发一次探针更便宜。但精度分配策略必须离线认证、单向保守、守卫有硬下限——在线只能"更准或更保守"，不能"更敢赌"。深度几何预检则成为每个检查点的廉价 L0.5 见证：先看地图与落脚面是否仍被深度支持，再决定探不探、走不走、要不要升精度。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（精度条件证书 QCC）** 精度剖面 p=(p_1,…,p_n)，第 i 个组件量化算子 Q_{p_i}，逐层误差界 Δ_{p_i}（由区间界传播/仿射算术给出，含算子融合与动态量化）。对估计器 f，报告满足 ∀x∈X_decl: f(x)∈[f̄_p(x)−r_p(x), f̄_p(x)+r_p(x)] 的**保守区间**；守卫集合 𝒢（证据门/证书检查器/风险累加器/同意状态机）要求 p_i≥p_guard 且以精确整数或区间算术执行。校准契约按精度重签：∀k≤k_max，ECE_k(q_{φ,p})≤ε_meta(k,p)。**分辨率下限** m_min(p)=r_p+κ_s·m_safe；裕度 |m|≤m_min(p) 判为不可辨识，不得作为 EV-margin。比特标号进入证书签名，**换精度即换模型**。

**定义 140（见证代数与失效基 WAB）** 失效基 ℬ={pho,con,ine,num,hum}；模态-机制载荷 A∈[0,1]^{ℳ×ℬ}，A_{m,b} 为机制 b 对模态 m 失效的载荷上界；共模预算 δ_cm(m,m')=Σ_b min(A_{m,b},A_{m',b})+δ_cm^decl。见证图 G_I 中 (m,m') 可声明独立 ⇔ δ_cm(m,m')≤δ_xm 且同侧一致。数值共因：凡经过同一低精度融合/共享瓶颈的模态，A_{·,num}=1。EV-xmodal 仅当 G_I 中无公共机制边时成立；任何光子模态对不得在透明/镜面类场景声明与视觉独立。

**定义 141（深度几何见证 GWD）** 深度模态 m=depth 输出稠密深度 D_r 与异方差不确定度场 σ_D(x)，空间相关长度 ℓ_c(c) 按材质/光照类 c 估计（取上界）。区域 𝒜 的有效样本 N_eff(𝒜)=|𝒜|/(2πℓ_c²)，证据权 w_depth=min(1,N_eff/N_ref)；共形覆盖用**块共形/块自助**（空间块交换性）保证 ≥1−α_D。几何残差 e_geo=dist(D_r,proj(𝓜_r))；自检套件 𝒯={左右一致,时序重投影,主动/被动一致,强度-深度边缘,多视角一致}。材质条件可靠度 ρ_depth(c)，未知 c 取 ρ_min；残余共模失效概率 δ_D(c) 与像素数无关。EV-geo ⇔ 自检通过 ∧ e_geo≤τ_geo ∧ N_eff≥N_min ∧ 证据支撑覆盖整个落脚面。

**定义 142（精度预算交换 PBX）** 精度阶梯 𝒫={INT4,INT8,FP16,FP32}，预算 B=(bits,energy,latency)；精度 VOI：pVOI_i=∂E[决策歧义]/∂bits_i，决策歧义用保守区间对阈值 τ 的穿越概率/宽度度量。分配策略 π_B 离线认证：优先降低风险区间半径最大且敏感度最高的组件；守卫与独立性路径设硬下限 p_guard、p_ind；OOD 时退最高精度；在线仅允许升精度或加宽区间，不允许降到下限以下。

**定义 143（精度-几何证据门 PGE 与证书 J_q）** 证据类扩为 EV-probe*/EV-visit/EV-margin/EV-xmodal/EV-human/EV-geo。约束：EV-margin 需 |m|>m_min(p) 且 p≥p_margin；EV-xmodal 需 δ_cm≤δ_xm 且仅 L0/L1；EV-geo 需定义 141 全部条件且仅 L0/L1；不可逆接触必要证据集={EV-probe*∨EV-margin}∪佐证∪**至少一条非光子、非数值独立见证**，EV-xmodal/EV-geo 不得计入。J_q=(J_p, precision_log, Δ_p 界, w_depth/N_eff/ℓ_c, depth_selfdiag_log, A 矩阵与 δ_cm, material_class, bitwidth_provenance, runtime_precision_attestation)。

**定义 144（探-诺-演++ PCE++/PCX++）** 每检查点：①元推断（精度条件、ID/OOD）；②深度几何预检（自检+地图一致性；失败则失效地图格、降 ρ_depth(c) 并触发探询/绕行）；③精度分配（裕度落入分辨率下限时：升精度或探针，二选一，禁止直接承诺）；④见证代数对账（EV-xmodal/EV-geo 只在机制独立时计入）；⑤承诺 ⇔ 保守区间上界 R̄≤δ_f ∧ 证据门过 ∧ 分辨率足够；否则按 VOI_元悲观 + 精度 VOI 选动作；⑥探尽→绕行→降档→L2 协商或安全停。精度升级次数 ≤k_prec/检查点。

```python
def certified_infer(M, r, obs, meta, p):
    inf = meta.q_phi_p(obs, z=ctx(r), p=p)            # 精度条件后验
    lo, hi = inf.bound - meta.radius(p), inf.bound + meta.radius(p)
    if inf.cls == 'OOD':                              # 保守区间，守卫可读
        belt = conformal_belt_p(meta.res, p, alpha_conf)
        lo, hi = belt.lo, belt.hi
    return inf, (lo, hi), meta.ece_decl[len(obs)][p]

def precision_allocate(cp, M, interval, budget):
    amb = interval_gap(interval, cp.tau)              # 决策歧义
    if amb <= 0: return 'no_need'
    cands = [(i, pVOI(i, amb)/cost(i)) for i in components if p_up(i) <= p_max]
    i = argmax(cands, key=lambda t: t[1])
    return 'upgrade' if pVOI(i) >= theta_pvoi else 'probe'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| QCC | O(\|𝒢\|·d) IBP/仿射；守卫精确 | O(Σp_i) | 区间必含真值（A41）、校准按 p 重签 |
| WAB | O(\|ℳ\|²·\|ℬ\|) | O(\|ℳ\|·\|ℬ\|) | A 为上界、量化共因计入（A42） |
| GWD | O(N_pix) 一次深度；块共形 O(\|𝒜\|/ℓ_c²) | O(\|𝒜\|) | ℓ_c 上界、块覆盖 ≥1−α_D（A43） |
| PBX | 离线 O(\|𝒫\|·\|𝒢\|)；在线 O(\|𝒫\|·d) | O(\|𝒢\|) | 守卫硬下限、单向保守（A44） |
| PGE | O(\|σ\|·\|ℬ\|) | O(\|σ\|) | 分辨率不足即拒、独立见证不可替代 |
| PCE++ | +O(k_prec·d) | +O(\|𝒢\|) | 探针+精度双预算有限终止 |

**正确性定理（PGCS 概要）**：在 A37–A40 之上加 (A41) 量化区间必含真值且校准按 (p,分布) 重签；(A42) 失效基载荷与 δ_cm 为诚实上界、量化共因入账；(A43) ℓ_c 为区域上界、块共形覆盖 ≥1−α_D、δ_D 不随像素数下降；(A44) 守卫精度硬下限、在线精度分配单向保守。则：(i) 承诺失效 ≤ δ_f(p)+ε_meta(k,p)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1∧独立]+δ_D·1[geo]+δ_cm·1[xmodal/geo]；(ii) 分辨率下限把 |m|≤m_min 的证据排除在承诺之外，消除了"假裕度"这一最隐蔽的不 sound 路径；(iii) 降精度只允许加宽区间、不允许改动守卫规则，因此安全性不随量化下降，代价只体现在可用性；(iv) PCE++ 在 k_probes+k_cons+k_prec 内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 运行时精度与声明不符（编译器/TF32/动态量化） | 高 | 运行时精度证明 + 区间自检 + 定期高精度差分回归 + 保守上界 |
| 失效基载荷/δ_cm 估计不足，独立性虚报 | 高 | 保守默认（未知=共因）、透明/镜面类禁止光子对独立、接触见证不可替代 |
| 深度相关长度低估导致 N_eff 虚高 | 高 | ℓ_c 取上界、块共形、材质分层审计、N_eff 上限法规 |
| 精度分配被 Goodhart/对抗诱导 | 中 | 离线认证策略 + 守卫硬下限 + OOD 退最高精度 + 审计 |
| 深度自检与视觉同谋（平滑错误） | 中 | 声明 δ_D 残余、不可逆接触必须有接触/本体见证 |
| 精度预算拖慢实时控制 | 中低 | 只在承诺点升精度、预取、失败退回保守路径 |

## 6. 本轮最大风险

**一句话**：本轮把 soundness 的最后一环押在一份关于"精度与相关性"的**元数据**上——比特标号、区间界 Δ_p、相关长度 ℓ_c、共模预算 δ_cm 与失效基矩阵；物理传感器失效还能被自检看见，而"运行时实际精度与声明不符"或"ℓ_c/δ_cm 被低估"是纯数值/统计的静默失效，系统会在证书看似有效的情况下不 sound；必须以运行时精度证明、区间必含真值的硬校验、块共形与失效基的保守默认三重兜底，宁可把未知材质当共因、把未知精度当最低精度，也不让一份过时的精度元数据替系统签字。

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"精度可计量、相关可折减、几何可对账的证据承诺"**：证书显式携带比特标号与舍入界，独立性按失效机制而非传感器名字判定，深度相机作为几何见证但按有效样本与材质条件计权。第 57 轮"一切判定器走隔离"在本轮推广为"**一切判定都必须在声明的精度与失效基下成立，换比特即换证书、换传感器不等于换见证**"。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-137/138 以纳入精度、见证基与几何维度。

### IP-139 QCC（精度条件证书与分辨率下限）

```python
def certified_interval(f, x, p):
    lo, hi = x.lo, x.hi
    for layer in f.layers:                             # 区间界传播（IBP/仿射）
        lo, hi = layer.propagate(lo, hi, quant_err(p[layer.name]))
    assert lo <= f_fp32_reference(x) <= hi, 'bound must contain truth'  # A41
    return lo, hi

def guard_eval(g, interval, p):
    assert p >= p_guard[g], 'guard below certified precision'  # A44
    return g.eval_exact_or_interval(interval)         # 守卫不做低精度近似

def resolution_ok(margin, p, kappa_s, m_safe):
    r_p = quant_radius(p)
    return abs(margin) > r_p + kappa_s * m_safe       # 否则裕度不可辨识

def sign_certificate(model, p, dist_id):
    model.cert[p] = {
        'Delta_p': ibp_bound(model, p),               # 逐层误差上界
        'ece': measure_ece(model.q_phi_p, p, dist_id),# 按 (p,分布) 重签
        'guard_floor': p_guard,
        'bitwidth_provenance': deployment_manifest(), # 运行时精度清单
    }
    return model.cert[p]                               # 换比特 = 换证书
```

### IP-140 WAB（见证代数与失效基）

```python
def declare_witness(A, m1, m2, delta_decl):
    delta_cm = sum(min(A[m1][b], A[m2][b]) for b in BASIS) + delta_decl
    return delta_cm <= delta_xm                        # A42 诚实上界

def quantized_common_cause(A, modalities, shared_graph):
    for m in modalities:
        if m in shared_graph.low_precision_bottleneck:
            A[m]['num'] = 1.0                          # 数值共因，不能免单
    return A

def xmodal_allowed(m1, m2, A, delta_decl, level, material_class):
    if level not in ('L0', 'L1'): return False
    if material_class in ('transparent', 'specular') and is_photonic(m1, m2):
        return False                                   # 共享光学路径，禁止声明独立
    return declare_witness(A, m1, m2, delta_decl)

def irreversible_witness_ok(witnesses):
    return any((w.basis & {'pho', 'num'}) == set() for w in witnesses)  # 必须有非光子/非数值见证
```

### IP-141 GWD（深度几何见证）

```python
def depth_witness(D, M, r, region, material_class):
    diag = run_selfchecks(D, region)                   # 左右/时序/主被动/边缘/多视角
    lc   = correlation_length_upper(D, region, material_class)  # 上界，非点估计
    Neff = area(region) / (2 * pi * lc ** 2)
    w    = min(1.0, Neff / N_ref)
    geo  = dist(D, project(M.r, r))                    # 几何残差
    lo, hi = block_conformal(D, region, block=lc, alpha=alpha_D)  # 空间块交换性
    rho_depth[region] = rho_min if material_class is None else rho_by_material(material_class)
    delta_D[region]   = delta_D_by_material(material_class)       # 与像素数无关
    ok = diag.passed and geo <= tau_geo and Neff >= N_min and covers(region, foothold(r))
    return Evidence('EV-geo', ok, w=w, Neff=Neff, lc=lc,
                    rho=rho_depth[region], delta_cm=delta_D[region], ci=(lo, hi))
```

### IP-142 PBX（精度预算交换）

```python
def allocate_precision(cp, comps, interval, budget, ood):
    if ood: return max_precision(comps)                # OOD 退最高精度
    amb = interval_gap(interval, cp.tau)              # 区间跨越阈值的宽度
    if amb <= 0: return current_precision(comps)
    ranked = sorted(comps, key=lambda i: -sensitivity(i, interval) * radius(i) / cost(i))
    alloc = dict(current_precision(comps))
    for i in ranked:
        if budget.exhausted(): break
        if alloc[i] < p_floor[i]: alloc[i] = p_floor[i]  # 守卫/独立性硬下限
        step = next_precision(alloc[i])
        if pVOI(i, amb, step) >= theta_pvoi and budget.pay(cost(i, step)):
            alloc[i] = step
        if interval_gap(rescaled(interval, alloc), cp.tau) <= 0: break
    return alloc

def promote_at_commit(cp, interval, alloc, budget):
    if interval_gap(interval, cp.tau) <= 0: return alloc
    if cp.contact_level in ('L1', 'L2'):              # 只在承诺点临时升精度
        alloc = raise_to(alloc, 'FP16' if budget.allows('FP16') else max_precision(alloc))
    return alloc
```

```python
def precision_geometric_gate(c, M, interval, p, persona, witnesses, ood_reg):
    ev = c.ev
    if ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k, p)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified_at(p))
    elif ev == 'EV-margin':
        ok = c.p >= p_margin and resolution_ok(c.margin, p, kappa_s, m_safe)
    elif ev == 'EV-xmodal':
        ok = c.level in ('L0', 'L1') and xmodal_allowed(
                 c.m1, c.m2, c.A, c.delta_decl, c.level, c.material_class)
    elif ev == 'EV-geo':
        ok = c.level in ('L0', 'L1') and c.ev_geo.ok and c.ev_geo.rho >= rho_min
    elif ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and c.corrob >= quarantine_exit(persona[c.op].auth)
    elif ev == 'EV-visit':
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible:
        if ev in ('EV-xmodal', 'EV-geo'):
            return ('reject', 'xmodal_or_geo_on_irreversible', c)  # 硬禁令
        if not irreversible_witness_ok(witnesses):
            return ('reject', 'no_mechanism_independent_witness', c)
    return ('ok', c)

def certificate_jq(sched, log, M, consent_log, auth_log, ood_reg):
    for c in contacts(sched):
        st = precision_geometric_gate(c, M, c.interval, c.p, persona_of(c),
                                      witnesses(c), ood_reg)
        if st[0] != 'ok': return st
    if not runtime_precision_attestation_matches(sched.map.p):  # 静默精度漂移
        return ('reject', 'precision_attestation_mismatch')
    if min(x.K_margin for x in sched) < budgets.theta_K:       return ('reject', 'K_margin')
    if rho_sem(sched, M) < budgets.rho_min:                    return ('reject', 'rho_sem')
    if semantic_perturbation(M.core) > budgets.Theta_s:        return ('reject', 'delta_s')
    if not all(l2.resolved for l2 in consent_log):             return ('reject', 'consent_open')
    return ('ok', Jq(Jp(M.core, core_contacts(sched), K_margin, rho_sem,
                        probe_log, consent_log, meta_cal_log, xmodal_log,
                        auth_log, ood_reg),
                     precision_log(sched), Delta_p(sched),
                     depth_log(sched), witness_matrix(sched),
                     bitwidth_provenance(sched), runtime_precision_attestation(sched)))
```

### IP-144 PCE++（探-诺-演++：深度预检 × 精度分配 × 见证对账）

```python
def probe_commit_evolve_plusplus(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf, interval, ece = certified_infer(M, cp.region, M.obs[cp.region], meta, p=current(cp))
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)

        geo = depth_witness(M.depth[cp.region], M, cp, foothold_patch(cp), material_of(cp))
        if not geo.ok:                                 # ② 深度预检失败
            M.invalidate(cp.region, reason='geo_inconsistent')
            M.rho_depth[material_of(cp)] *= gamma_down
            cp.need_probe = True

        if resolution_ok(cp.margin(interval), current(cp), kappa_s, m_safe) is False:
            act = allocate_precision(cp, comps(cp), interval, budget.precision, inf.cls == 'OOD')
            if act == 'probe' and budget.probes_left > 0: cp.need_probe = True
            else: cp.p_alloc = act                    # ③ 升精度或探针，二选一

        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while (select_gait(R) == 'halt' or cp.need_probe) and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p_probe = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p_probe, M, inf) < theta_voi: break
            e = execute_probe(p_probe, cap=F_abs)
            M, interval, D = xmodal_witness_fuse(M, cp.region, e, A=M.A, p=cp.p_alloc)
            if D > theta_D and 'consensus' not in cp.done:
                M, interval, D = xmodal_witness_fuse(
                    M, cp.region, execute_probe(most_disagreeing_probe(M, cp.region), F_abs),
                    A=M.A, p=cp.p_alloc)
                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p_probe)
        cp.done.add('probe_round') if cp.need_probe else None

        cp.p_alloc = promote_at_commit(cp, interval, cp.p_alloc, budget.precision)
        lv = contact_level(cp)
        witnesses = collect_witnesses(sigma, M, lv, geo, A=M.A)
        if select_gait(R) != 'halt' and \
           precision_geometric_gate(core_contact(cp), M, interval, cp.p_alloc,
                                    personas, witnesses, ood_reg)[0] == 'ok':
            sched.append(commit(sigma, select_gait(R))); log.append(tag_evidence_p(sigma, M, lv))
            continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QCC | O(\|𝒢\|·d) IBP/仿射；守卫精确 | O(Σp_i) | 区间必含真值、校准按 (p,分布) 重签（A41） |
| WAB | O(\|ℳ\|²·\|ℬ\|) | O(\|ℳ\|·\|ℬ\|) | A 为上界、量化共因入账（A42） |
| GWD | O(N_pix)；块共形 O(\|𝒜\|/ℓ_c²) | O(\|𝒜\|) | ℓ_c 上界、块覆盖 ≥1−α_D、δ_D 与 N 无关（A43） |
| PBX | 离线 O(\|𝒫\|·\|𝒢\|)；在线 O(\|𝒫\|·d) | O(\|𝒢\|) | 守卫硬下限、在线单向保守（A44） |
| PGE | O(\|σ\|·\|ℬ\|) | O(\|σ\|) | 分辨率不足即拒、独立见证不可替代 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d)+\|CP\|·k_prec·d) | O(\|V\|+\|σ\|) | 双预算有限终止、四态完备 |

**正确性定理（Precision-Geometry-Correlation Soundness, PGCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；并新增：
**(A41) 量化健全性**：每个组件在精度 p 下报告的保守区间必含真实输出（IBP/仿射界 sound）；校准 ECE 按 (p, 输入分布) 重新测量并如实声明；比特标号与运行时精度证明可核验。
**(A42) 见证诚实性**：失效基载荷 A 与共模预算 δ_cm 为失效概率的诚实上界；凡经同一低精度瓶颈的模态计入数值共因；独立声明仅用于 δ_cm≤δ_xm 的模态对。
**(A43) 深度相关性与覆盖**：ℓ_c(c) 为区域内相关长度上界；N_eff 由该上界计算；块共形覆盖 ≥1−α_D；材质条件 ρ_depth、δ_D 诚实且 δ_D 不因像素数增加而降低。
**(A44) 精度分配单调性**：守卫与独立性路径不低于硬下限 p_guard/p_ind；在线分配只允许升精度或加宽区间，不允许把守卫规则或门拓扑纳入量化搜索；策略 π_B 离线认证；OOD 时退最高精度。

则：
1. **承诺健全性**：对任一不可逆承诺，
   `P(fail) ≤ δ_f(p) + ε_meta(k,p) + δ_probe + ε_h(w_max) + δ_ood·α_conf + δ_xm·1[L1∧独立] + δ_D·1[geo] + δ_cm·1[xmodal/geo]`。
   其中分辨率下限规则使 |m|≤m_min(p) 的裕度不进入证据集，故"假裕度"贡献为 0；守卫以精确/区间算术执行，故量化不直接引入门判定误差，只通过加宽区间影响可用性（若运行时精度与声明不符，则以上界全部失效——这正是 A41 的必要性）。
2. **见证不可伪造性**：任何不可逆接触至少含一条 A 的对应列在 {pho,num} 上载荷为 0 的见证；EV-xmodal/EV-geo 不能计入必要证据集，因此"共享光学路径共谋"与"共享量化瓶颈共因"都不能单独产生承诺。
3. **保守可用性权衡**：对同一决策规则，降低估计器精度只会加宽保守区间（在 A41/A44 的构造下），可使承诺集单调收缩；PCE++ 用精度 VOI 把 bit 花在区间最宽且最敏感处，从而在同等安全下恢复可用性。
4. **终止性**：每检查点探针 ≤k_probes+k_cons、升精度 ≤k_prec，精度阶梯有限，故 PCE++ 终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp ( δ_f(p) + ε_meta(k,p) + δ_probe + ε_h + δ_ood·α_conf
                   + δ_xm·1[L1∧独立] + δ_D·1[geo] + δ_cm·1[xmodal/geo] )
             − P(𝓜 陈旧未被深度预检发现) − P(精度证明与实际不符)
             − P(ℓ_c/δ_cm 被低估) − P(护盾回退失败) − P(τ_int∧τ_mm 超时∧安全停失效)
```

关键：**精度是证书的签名，不是部署的脚注**（换比特=换模型=换证书）；**独立性是失效机制的性质，不是传感器数量的性质**（深度相机不免费提供独立见证，量化瓶颈还会销毁独立性）；**稠密不等于独立**（深度证据按 N_eff 折减）；**守卫精确、估计器可量化**（安全不随 bit 下降，代价只在可用性）。

云边协议 CEB++ → **CEB+++**：云端可下发量化模型增量，但必须同时下发**精度清单、逐层区间界、按精度重签的校准证书与失效基矩阵**；边端先以影子模式跑"精度回归测试"——(i) 区间必含高精度参考输出，(ii) ECE(p) 不劣化，(iii) OOD 检出率不降，(iv) EV-xmodal 共模预算 δ_cm 不升——四项全过才可接管承诺判定。边端回传深度自检失败谱、ℓ_c 上界估计、材质-失效对照与运行时精度证明异常，作为云端量化感知训练与见证基更新的依据。第 57 轮"一切判定器走隔离"在本轮推广为"**一切判定器都必须在声明的精度与失效基下走隔离；换比特、换传感器、换相关长度估计都是需要重新认证的变更**"。

## 6. 本轮最大风险

**一句话**：本轮把 soundness 的最后一环押在一份关于"精度与相关性"的**元数据**上——比特标号、区间界 Δ_p、相关长度 ℓ_c、共模预算 δ_cm 与失效基矩阵；物理传感器失效还能被自检看见，而"运行时实际精度与声明不符"（编译器融合、TF32、动态量化）或"ℓ_c/δ_cm 被低估"是纯数值/统计的静默失效，系统会在证书看似有效的情况下不 sound；必须以运行时精度证明、区间必含真值的硬校验、块共形与失效基的保守默认三重兜底，宁可把未知材质当共因、把未知精度当最低精度，也不让一份过时的精度元数据替系统签字。
