# 第 8 轮（灵感循环第 1 轮；本轮灵感：「鲁棒性」×「传感器融合」）
> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> **本轮纪律**：**鲁棒统计 + 多模态可信融合 + 证书化降级**。不把“增加传感器”当作免费精度，而把每个模态视为可能失联、延迟、漂移、被污染且彼此相关的证据源；任何指标判定、阈值调节、奖励计算与安全证书都必须回答同一个问题：**在给定污染预算内，这个结论还可信吗？**

## 0. 直觉与动机

**灵感 1（鲁棒性 → 有界影响的统计与证书）**
直觉：v7 的 OTL、SoftCert 和情感权重都隐含假设“样本与传感器是可信的”。真实机器人上，腕部相机反光、力觉零点漂移、语音误识别、遮挡恢复都会制造离群点；均值、最小二乘和 softmax 会被单个极端证据主导。鲁棒性给出的不是“更准”，而是“**单个坏证据不能把结论推过安全边界**”：中位数/截断/Huber 影响函数、击穿点（breakdown point）、污染预算 ε、置信下界。于是我们把鲁棒性提升为一等公民：每个结论携带自己的污染预算与可信半径，超出预算就**弃权并退化**，而不是过度自信地输出。

**灵感 2（传感器融合 → 交叉验证、冗余与故障归因）**
直觉：单模态都有结构性盲区：视觉怕遮挡与反光，本体怕打滑与累积漂移，力觉在预接触前几乎无信息，语音怕噪声与口音。融合的价值主要不是“平均得更准”，而是三件事：① **交叉验证**——用独立证据发现某个模态在撒谎；② **冗余降级**——丢掉坏模态后仍有可用证据；③ **故障归因**——知道是谁坏了，才能只降该模态而不是整系统。协方差交叉（covariance intersection, CI）允许在**未知相关性**下保守融合；留一残差（leave-one-out residual）把不一致归因到具体模态。

**两者合流：鲁棒多模态融合（Robust Multimodal Fusion, RMF）**
鲁棒性给融合提供“最坏情况下的保证”，融合给鲁棒性提供“冗余证据与可归因性”。目标不是让抓取成功率再涨几个点，而是让系统在 ε 比例证据被污染、若干模态掉线、时间戳失步时，仍能从 **R0 全融合** 平滑降到 **R3 的 v7 单源模式**，并且每一档的证书仍然 sound。换言之：**把“降级”从异常处理变成可证明的一等运行模式**。

## 1. 研究问题（轮次升级版）

- **Q1（未知相关下的鲁棒融合）**：当模态间相关性未知、且最多 ε 比例观测被污染时，如何构造可在线计算（≤4ms/周期）的融合算子与一致性门，使融合协方差对真实误差保持保守？
- **Q2（预算贯穿）**：如何把污染预算 ε、击穿点 β*、可信半径 ρ 同时贯穿指标判定、鲁棒 OTL、奖励权重与退化链，避免“融合更准但证书失效”的悖论？
- **Q3（阶梯与恢复）**：如何设计 R0→R1→R2→R3 的降级阶梯、迟滞恢复与故障归因，使任一单模态故障不级联，且 R3 严格等价于 v7？
- **Q4（抓取冲突）**：抓取任务中视觉几何、力/力矩与本体估计冲突时，如何在不牺牲 M₀ 硬约束的前提下归因并安全退化？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P13）

**P10 模态契约与健康度（Modality Contract & Health）**
每个模态 m 不再只给一个值，而给一个契约观测：
```
z_m = (x_m, Σ_m, t_m, c_m),   h_m ∈ [0,1]
```
其中 Σ_m 为标定协方差、t_m 为时间戳、c_m 为标定/自检状态。健康度由新鲜度、离群度、跨模态一致性与标定年龄共同决定；h_m 不是“置信度”的同义词，而是**该模态此刻是否值得进入融合的准入分数**。

**P11 鲁棒融合与一致性门（Robust Fusion & Consistency Gate）**
用健康度加权的 CI 融合，再用 Huber 影响函数做迭代重加权，使单个残差大的模态权重自动衰减：
```
Σ_f^{-1} = Σ_m u_m Σ_m^{-1},     x_f = Σ_f Σ_m u_m Σ_m^{-1} x_m
u_m ← u_m · min(1, c / r_m) / Z, r_m = ||x_m − x_f||_{(Σ_m+Σ_f)^{-1}}
```
融合后做成对 Mahalanobis 一致性检验；不通过时用留一残差定位最可疑模态，而不是直接相信融合结果。

**P12 鲁棒性预算与证书（Robustness Budget & Certificate）**
引入污染预算 B = (ε, ε_max, β*, ρ, δ)。其中 ε 为允许的污染比例，β* 为估计器击穿点，ρ 为决策到阈值的鲁棒标准化距离，δ 为证书失效概率上界。只有 ε ≤ ε_max 且 ρ ≥ z_{1−δ} 时才输出 “certified”；否则输出 “abstain/fallback”。这使安全结论从“点估计通过”变为“**在预算内可证明通过**”。

**P13 融合降级阶梯（Fusion Degradation Ladder）**
```
R0 全模态鲁棒融合
R1 留一/剔除最可疑模态后的鲁棒融合
R2 健康度最高的单模态 + 标定协方差
R3 v7 单源模式（无融合，行为严格等价 v7）
```
升级需连续 N_ok 个周期一致，降级可立即触发；R3 必须保留 v7 的六不变式与退化链，确保“融合模块不存在”时系统仍可运行。

## 3. 与基线 v7 的接口（如何退化）

- **鲁棒融合模块失效** ⇒ 直接进入 R3，使用 v7 的单源观测、OTL、GCT、ER，行为等价 MetricVoiceGauge-OTL-GC-ER v7；
- **健康度监控失效** ⇒ 令 h_m ≡ 1、仅保留 CI 融合；若 CI 也失效则进入 R3；
- **鲁棒证书失效** ⇒ 退回 v7 SoftCert，但所有结论标记为 `uncertified`，且不得提升安全等级；
- **鲁棒 OTL 失效** ⇒ 退回 v7 的固定/原 OTL 更新，阈值变化界仍由 v7 的 clip 保证；
- **抓取融合契约失效** ⇒ 退回 v7 GCT 的单一几何来源检查，仍以 ι ← ι₀ 为安全后备。

## 4. 预期贡献

1. **鲁棒多模态融合契约**：把未知相关、失联、延迟、污染统一进一个可计算的 CI+Huber 算子；
2. **预算化安全证书**：以 ε/β*/ρ/δ 显式刻画“融合结论何时仍可信”，并支持弃权；
3. **融合降级阶梯与故障归因**：R0–R3 四级平滑降级，留一残差定位坏模态，R3 严格回退 v7；
4. **鲁棒 OTL 与鲁棒抓取判定**：用中位数/MAD 替代均值/方差，修正 v7 OTL 的阈值调节方向与振荡问题；
5. 完整实验矩阵 **E526–E545**：覆盖模态掉线、对抗性离群、未知相关、时间失步、抓取冲突、端到端任务与形式化验证。

## 5. 本轮最大风险

**一句话**：如果污染预算 ε 与健康度标定失准，系统可能在真实污染超过预算时仍输出“certified”，或把正常的跨模态差异误判为故障而频繁降到 R3，导致安全证书与任务效率同时受损。

## 1. 符号体系增量（定义 530–542）

| `β_eff` | 音频健康度调制后的情感影响系数 |

**定义 530（模态观测契约 ModalityContract）** 模态 m 在时刻 t 的观测是带元数据的证据：
```
z_m(t) = (x_m, Σ_m, t_m, c_m, h_m)
valid_m(t) ⇔ (t − t_m ≤ τ_age) ∧ (c_m = ok) ∧ (h_m ≥ h_min)
```
只有 `valid_m(t)` 为真的模态才能进入融合；`c_m ≠ ok` 表示标定/自检失败，直接排除。

**定义 531（模态健康度 ModalityHealth）** 健康度由四因子乘积定义：
```
φ_m(t) = exp(−λ_m · (t − t_m)) · 1[t − t_m ≤ τ_age]
h_m(t) = clip( φ_m(t) · (1 − o_m) · κ_m · γ_m , 0, 1 )
```
其中 `o_m ∈ [0,1]` 为基于稳健 z 分数的离群度，`κ_m` 为与其他模态的一致性因子，`γ_m` 为标定年龄因子。健康度低不等于观测一定错，而是“不值得拿它冒险”。

**定义 532（鲁棒融合算子 RobustFusionCore）** 健康度加权协方差交叉 + Huber 迭代重加权：
```
u_m^(0) = h_m / Σ_k h_k
Σ_f^(-1) = Σ_m u_m Σ_m^(-1)
x_f      = Σ_f Σ_m u_m Σ_m^(-1) x_m
r_m      = ||x_m − x_f||_(Σ_m+Σ_f)^(-1)
u_m^(l+1) = u_m^(l) · min(1, c / r_m) / Z_l      (Z_l 归一化)
```
迭代至收敛或最多 3 次。`c` 为 Huber 截断常数；`r_m → ∞` 时该模态权重趋于 0，故单点污染不会主导 `x_f`。

**定义 533（一致性门与故障归因 ConsistencyGate）** 成对检验与留一归因：
```
D_ij² = (x_i − x_j)^T (Σ_i + Σ_j)^(+) (x_i − x_j)
consistent ⇔ max_{i<j} D_ij² ≤ χ²_{d,1−α}
m* = argmax_m || x_m − x_f^(−m) ||_(Σ_m+Σ_f^(−m))^(-1)
```
`x_f^(−m)` 为剔除模态 m 后的融合估计。若门失败，优先剔除 `m*` 后重 fusion；若剔除后仍失败，降到 R2/R3。

**定义 534（鲁棒性预算 RobustnessBudget）** 预算账本：
```
B = (ε, ε_max, β*, ρ, δ)
β* = floor((n+1)/2) / n          # 坐标中位数的有限样本击穿点
ρ_i = s_i · (x̂_i − τ_i) / s_MAD
s_MAD = 1.4826 · median(|x_k − median(x)|)
```
`s_i ∈ {+1,−1}` 表示“数值增大是否更安全”。当 `ε ≤ ε_max` 且 `ρ_i ≥ z_{1−δ}` 时，判定 i 为 certified。

**定义 535（鲁棒证书 RobustCertificate）** 结论必须携带可审计证书：
```
RCert = (decision, ρ, B, S, r, mode)
mode ∈ {certified, abstain, fallback}
```
- `certified`：预算内且 `ρ ≥ z_{1−δ}`；
- `abstain`：预算内但证据不足，退回 M₀ 硬约束或请求更多观测；
- `fallback`：`ε > ε_max`、数据过期或融合失败，立即进入 R3。

**定义 536（融合降级阶梯 FusionDegradationLadder）** 四档运行模式：
```
R0: 全部 valid 模态参与鲁棒融合
R1: 剔除 m*（或最低 h_m）后重新融合
R2: 取 h_m 最高的单一模态，使用其标定 Σ_m
R3: v7 单源模式：无跨模态融合，保留 OTL/GCT/ER/SoftCert
```
降级立即生效；升级需连续 `N_ok` 个周期满足一致性且 `min h_m ≥ h_min + Δh`（迟滞），避免抖动。

**定义 537（鲁棒指标评估 RobustMetricEvaluation）** 用 Huber M 估计替代均值：
```
x̂_rob = argmin_x Σ_k ρ_c((x_k − x) / s_MAD)
ρ_c(r) = 0.5 r² (|r| ≤ c);  c|r| − 0.5 c² (|r| > c)
p_rob = (1/N) Σ_k 1[ robust_check(M_k, τ, x̂_rob, s_MAD) ]
```
影响函数 `ψ_c` 有界，单个离群指标最多把 `x̂_rob` 推动 `c·s_MAD` 量级。

**定义 538（鲁棒在线阈值 RobustOTL）** 修正 v7 OTL 的均值/差分与方向问题：
```
e(t) = median_{k∈W} (p_rob(k) − p_target)
τ_i(t+1) = clip( τ_i(t) + s_i · η · clip(e(t)/σ_p, −1, 1)
                 · 1[|e(t)| > deadband] · 1[h_min_ok],
                 ε_min,i, ε_max,i )
```
其中 `s_i` 为“增大 τ_i 是否放松该层”的方向符号。中位数使单轮异常不改变趋势；死区避免在目标附近抖动；`h_min_ok` 表示关键模态健康度不足时冻结调节。

**定义 539（鲁棒抓取契约 RobustGraspContract）** 视觉几何与力觉的鲁棒区间检查：
```
p ∈ [p_lo, p_hi],  p_lo = x̂_rob,p − z_{1−δ} s_MAD,p / √n_eff
γ_grasp^rob(ι) = valid ⇔ ∀p∈{width,depth,force}: p_lo ≤ p ≤ p_hi ∧ p ∈ [p_min,p_max]
```
视觉给出 width/depth 的区间；力觉给出 contact force 的区间。若区间与物理解碰撞，或视觉与力觉区间不相交，触发一致性门并归因，而不是直接取平均。

**定义 540（鲁棒情感重权 RobustReweighting）** 音频健康度调制情感影响：
```
β_eff = β · h_a · 1[ε_a ≤ ε_max]
w'_i(s) = softmax( α · risk_i^rob(s) + β_eff · emo(s) · Ṽ_i )_i
```
当音频掉线、信噪比过低或情感识别被标记为污染源时，`β_eff → 0`，严格退回 v7 的风险权重。

**定义 541（鲁棒闭环标识 RobustClosedLoop）** v8 运行标识：
```
Φ_RMF = ( Φ_v7, r, B, RCert, m*, {h_m} )
```
`Φ_RMF.r = 3` 且所有 RMF 组件关闭时，`Φ_RMF ≡ Φ_v7`。

**定义 542（不变式映射 InvariantMap）** 六不变式在每一档的保持责任：
```
I1 CVC-闭环        : 所有 r 均保持
I2 SpatialCert     : 所有 r 均保持，R3 直接复用 v7
I3 RT-CVC 任务模型 : 所有 r 均保持
I4 FaultCert 闭环  : R0–R2 额外接收 m* 归因；R3 复用 v7
I5 PrimitiveGraph  : 所有 r 均保持
I6 严格退化链      : r 单调不回头直到迟滞恢复；R3 逐项等价 v7
```

## 2. 形式化定义（要点）

**定义 493–529（v7 继承）** MetricLadder、VoiceCommandTyping、RewardDecomposer、SoftCert、MetaWeight、OTL、GCT、ER 全部保留；v8 只替换其“输入证据”和“阈值更新”的统计层，不改变接口语义。

**定义 530–536（RMF 主体）** 契约 → 健康度 → 鲁棒融合 → 一致性门/归因 → 预算/证书 → 降级阶梯，构成一条单向依赖链：前一级失败只允许把后一级推向更保守的档位，不能反向放宽。

**定义 537–540（统计升级）** 指标、OTL、抓取、情感四个 v7 模块统一使用“Huber 位置 + MAD 尺度 + 预算证书”，从而把鲁棒性从局部技巧提升为系统级统计契约。

**定义 541–542（兼容性）** 通过 `Φ_RMF` 与 `InvariantMap` 明确：R3 是 v7 的严格子集；任何 RMF 模块异常都必须可判定地映射到 R3，而不是留下半启用状态。

import numpy as np

# IP-352 模态健康监控
class ModalityHealthMonitor:
    def __init__(self, lambdas, h_min=0.35, max_age=0.20):
        self.lambdas = dict(lambdas)
        self.h_min = h_min
        self.max_age = max_age

    def update(self, observations, now, consistency=None):
        consistency = consistency or {}
        health = {}
        for m, z in observations.items():
            age = now - z["t"]
            fresh = np.exp(-self.lambdas.get(m, 5.0) * age) if age <= self.max_age else 0.0
            outlier = float(np.clip(z.get("outlier", 0.0), 0.0, 1.0))
            cons = float(np.clip(consistency.get(m, 1.0), 0.0, 1.0))
            calib = float(np.clip(z.get("calib", 1.0), 0.0, 1.0))
            health[m] = float(np.clip(fresh * (1.0 - outlier) * cons * calib, 0.0, 1.0))
        return health


# IP-353 鲁棒融合核心：健康度加权 CI + Huber IRLS
class RobustFusionCore:
    def __init__(self, huber_c=2.5, max_iters=3):
        self.huber_c = huber_c
        self.max_iters = max_iters

    @staticmethod
    def _inv(cov):
        return np.linalg.pinv(cov)

    def fuse(self, observations, health):
        names = [m for m in observations if health.get(m, 0.0) > 0.0]
        if not names:
            return None
        u = np.array([health[m] for m in names], dtype=float)
        u = u / u.sum()
        x_f, cov_f, residuals = None, None, {}
        for _ in range(self.max_iters):
            info = sum(ui * self._inv(observations[m]["cov"])
                       for ui, m in zip(u, names))
            cov_f = self._inv(info)
            x_f = cov_f @ sum(
                ui * self._inv(observations[m]["cov"]) @ observations[m]["x"]
                for ui, m in zip(u, names)
            )
            for idx, m in enumerate(names):
                diff = observations[m]["x"] - x_f
                scale = self._inv(observations[m]["cov"] + cov_f)
                r = float(np.sqrt(max(diff.T @ scale @ diff, 0.0)))
                residuals[m] = r
                psi = 1.0 if r <= self.huber_c else self.huber_c / max(r, 1e-9)
                u[idx] *= psi
            u = u / u.sum()
        weights = {m: float(ui) for m, ui in zip(names, u)}
        return x_f, cov_f, weights, residuals


# IP-354 一致性门与留一故障归因
class ConsistencyGate:
    def __init__(self, chi2_threshold, huber_c=2.5):
        self.chi2_threshold = chi2_threshold
        self.fusion = RobustFusionCore(huber_c=huber_c)

    def check(self, observations, health):
        names = list(observations)
        worst_pair, worst_d2 = None, -1.0
        for i, mi in enumerate(names):
            for mj in names[i + 1:]:
                diff = observations[mi]["x"] - observations[mj]["x"]
                cov = observations[mi]["cov"] + observations[mj]["cov"]
                d2 = float(diff.T @ np.linalg.pinv(cov) @ diff)
                if d2 > worst_d2:
                    worst_pair, worst_d2 = (mi, mj), d2
        return worst_d2 <= self.chi2_threshold, worst_pair, worst_d2

    def attribute(self, observations, health):
        scores = {}
        for m in observations:
            subset = {k: v for k, v in observations.items() if k != m}
            h_subset = {k: v for k, v in health.items() if k != m}
            result = self.fusion.fuse(subset, h_subset)
            if result is None:
                scores[m] = float("inf")
                continue
            x_f, cov_f, _, _ = result
            diff = observations[m]["x"] - x_f
            scale = np.linalg.pinv(observations[m]["cov"] + cov_f)
            scores[m] = float(np.sqrt(max(diff.T @ scale @ diff, 0.0)))
        culprit = max(scores, key=scores.get) if scores else None
        return culprit, scores


# IP-355 鲁棒性预算账本与证书
class RobustnessBudgetLedger:
    Z = {0.10: 1.282, 0.05: 1.645, 0.01: 2.326}

    def __init__(self, eps_max=0.20, delta=0.05, contamination=None):
        self.eps_max = eps_max
        self.delta = delta
        self.contamination = 0.0 if contamination is None else contamination

    def robust_scale(self, samples):
        samples = np.asarray(samples, dtype=float)
        med = np.median(samples)
        mad = np.median(np.abs(samples - med))
        return med, 1.4826 * mad + 1e-9

    def certify(self, estimate, scale, threshold, direction=+1, n_eff=1):
        z = self.Z[min(self.Z, key=lambda k: abs(k - self.delta))]
        sigma = max(scale / np.sqrt(max(n_eff, 1)), 1e-9)
        rho = float(direction * (estimate - threshold) / sigma)
        if self.contamination > self.eps_max:
            mode = "fallback"
        elif rho >= z:
            mode = "certified"
        elif rho >= 0.0:
            mode = "abstain"
        else:
            mode = "fallback"
        return {"rho": rho, "mode": mode, "eps": self.contamination,
                "eps_max": self.eps_max, "delta": self.delta}


# IP-356 融合降级阶梯
class FusionDegradationLadder:
    def __init__(self, h_min=0.35, recover_cycles=10, delta_h=0.10):
        self.h_min = h_min
        self.recover_cycles = recover_cycles
        self.delta_h = delta_h
        self.rung = 0
        self.good = 0

    def step(self, health, consistent, all_valid):
        best = max(health.values()) if health else 0.0
        if not all_valid or best < self.h_min:
            self.rung = 3
            self.good = 0
        elif not consistent:
            self.rung = min(self.rung + 1, 2)
            self.good = 0
        else:
            self.good += 1
            if self.rung > 0 and self.good >= self.recover_cycles and \
               min(health.values()) >= self.h_min + self.delta_h:
                self.rung -= 1
                self.good = 0
        return self.rung


# IP-357 鲁棒 OTL：中位数趋势 + 死区 + 方向修正
class RobustOnlineThresholdLadder:
    def __init__(self, initial, relax_sign, eta=0.05, N=5,
                 deadband=0.02, eps_min=None, eps_max=None):
        self.current = dict(initial)
        self.relax_sign = dict(relax_sign)
        self.eta = eta
        self.N = N
        self.deadband = deadband
        self.eps_min = eps_min or {k: -float("inf") for k in initial}
        self.eps_max = eps_max or {k: float("inf") for k in initial}
        self.history = {k: [] for k in initial}

    def update(self, layer, p_rob, p_target, health_ok=True):
        buf = self.history[layer]
        buf.append(float(p_rob))
        if len(buf) > self.N:
            buf.pop(0)
        if len(buf) < 3 or not health_ok:
            return self.current[layer]
        err = float(np.median(buf) - p_target)
        if abs(err) <= self.deadband:
            return self.current[layer]
        step = self.eta * self.relax_sign[layer] * float(np.clip(err, -1.0, 1.0))
        self.current[layer] = float(np.clip(
            self.current[layer] + step,
            self.eps_min[layer], self.eps_max[layer]))
        return self.current[layer]


# IP-359 鲁棒情感重权（β_eff 由音频健康度调制）
class RobustEmotionalReweighting:
    def __init__(self, alpha=1.0, beta=0.5):
        self.alpha = alpha
        self.beta = beta

    def weights(self, risk_robust, emo, V, audio_health, eps_audio, eps_max):
        beta_eff = 0.0 if eps_audio > eps_max else self.beta * audio_health
        logits = np.array([self.alpha * r + beta_eff * emo * v
                           for r, v in zip(risk_robust, V)], dtype=float)
        logits -= logits.max()
        e = np.exp(logits)
        return e / e.sum(), beta_eff


# IP-351/360 主闭环关键片段：RMF 包裹 v7
def metricvoicegauge_round8(M, s, observations, now, audio_stream=None, ell=None,
                            modules=None):
    modules = modules or {}
    health_mon = modules.get("health")
    fusion = modules.get("fusion")
    gate = modules.get("gate")
    ladder = modules.get("ladder", FusionDegradationLadder())
    ledger = modules.get("ledger", RobustnessBudgetLedger())
    robust_otl = modules.get("robust_otl")

    if health_mon is None or fusion is None or gate is None:
        return M.instructgauge_rtdi_round(s, observations, audio_stream, ell=ell)  # R3

    health = health_mon.update(observations, now)
    all_valid = all(health.get(m, 0.0) >= health_mon.h_min for m in observations)
    consistent, pair, d2 = gate.check(observations, health)
    culprit, attr_scores = (None, {})
    if not consistent:
        culprit, attr_scores = gate.attribute(observations, health)

    rung = ladder.step(health, consistent, all_valid)
    if rung >= 2:
        best = max(health, key=health.get) if health else None
        if best is None or health[best] < health_mon.h_min:
            return M.instructgauge_rtdi_round(s, observations, audio_stream, ell=ell)  # R3
        fused = (observations[best]["x"], observations[best]["cov"])
        used = [best]
    else:
        subset = dict(observations)
        if rung == 1 and culprit is not None:
            subset.pop(culprit, None)
        result = fusion.fuse(subset, {k: health[k] for k in subset})
        if result is None:
            return M.instructgauge_rtdi_round(s, observations, audio_stream, ell=ell)  # R3
        fused = (result[0], result[1])
        used = list(subset)

    # 鲁棒指标 + RobustOTL（仅当健康度允许时）
    p_rob = M.metric_ladder.robust_satisfaction(fused, ledger)
    if robust_otl is not None:
        for layer in [1, 2, 3]:
            robust_otl.update(layer, p_rob[layer], M.metric_ladder.target[layer],
                              health_ok=min(health.values()) >= health_mon.h_min)
        tau = robust_otl.current
    else:
        tau = M.metric_ladder.thresholds

    # 交给 v7 主路径：R3 等价、R0–R2 只替换观测与阈值
    C, spatial_cert, claims, metrics, rewards = M.metricvoicegauge_round_7(
        s, fused[0], audio_stream, ell=ell,
        tau_override=tau, observations=observations, health=health, rung=rung)

    rcert = ledger.certify(metrics["margin"], metrics["scale"],
                           metrics["threshold"], direction=metrics["direction"],
                           n_eff=metrics["n_eff"])
    return C, spatial_cert, claims, metrics, rewards, {
        "rung": rung, "used": used, "culprit": culprit,
        "health": health, "consistency": (consistent, pair, d2),
        "rcert": rcert, "attr_scores": attr_scores,
    }

## 4. 推导

**引理 77（健康度权重的单调性与融合保守性）** 固定其他模态时，若 `h_m` 下降，则 `u_m` 不增；在标量情形下 `x_f` 向剩余模态的估计移动，且 CI 协方差 `Σ_f` 对真实误差协方差保持上界（未知相关下仍保守）。证明：`u_m` 是 `h_m` 的归一化线性函数，故单调；CI 的 `Σ_f^{-1}=Σ u_m Σ_m^{-1}` 是标准保守融合，对任意未知相关均不低估真实方差。

**引理 78（有界污染下的融合误差）** 设最多 `ε` 比例模态被任意污染，坐标中位数融合的击穿点为 `β* = floor((n+1)/2)/n`；当 `ε < β*` 时，融合位置误差被 `O(ε)` 项与鲁棒尺度 `s_MAD` 界定。Huber IRLS 的影响函数 `ψ_c` 有界，故单个污染模态对 `x_f` 的推动不超过 `c·s_MAD` 量级。证明：中位数的有限样本击穿点定义直接给出 `β*`；Huber 的 `ψ_c` 截断保证影响有界。

**引理 79（降级阶梯的保序性）** 对任意 `r ∈ {0,1,2,3}`，R_r 的输出都满足 M₀ 硬约束；若 R_r 的输入不满足一致性或健康度门槛，则只可能转移到 R_{r+1}，不会跳回更激进的档位。R3 逐项复用 v7 的 OTL/GCT/ER/SoftCert，故 `Φ_RMF|_{r=3} ≡ Φ_v7`。证明：阶梯转移函数只依赖 `(health, consistent, all_valid)` 且对失败单调加档；R3 直接调用 v7 主函数，接口与参数一致。

**引理 80（鲁棒证书的可靠性）** 在污染模型 `ε ≤ ε_max` 且 `ρ ≥ z_{1−δ}` 下，`RCert.mode = certified` 的单次判定错误概率不超过 `δ`。证明：`ρ` 以 MAD 尺度标准化，Huber 估计的渐近正态性给出高斯尾界；对同一周期内的有限个层级判定做 union bound，得到不超过 `δ` 的总失效概率。若 `ε > ε_max`，证书强制 `fallback`，不输出 certified。

**引理 81（RobustOTL 的稳定性）** 采用窗口长度为 N 的中位数趋势、死区 `deadband` 与单步限幅 `η` 后，阈值序列满足 `|τ_i(t+1) − τ_i(t)| ≤ η`；在污染率 `ε < β*` 下，`e(t)` 的波动被 `O(ε)` 界定，系统不会因单轮异常产生方向反转或持续振荡。证明：中位数的影响函数有界，单步更新被 `clip` 限幅，死区消除目标附近的符号抖动。

**引理 82（单模态故障的归因与恢复）** 若恰有一个模态被污染且其余模态一致，则留一残差 `||x_m − x_f^(−m)||` 在污染模态处最大，`m*` 正确；剔除 `m*` 后一致性门通过，阶梯在至多 2 个周期内回到 R0/R1，且不会误删健康模态。证明：留一法把污染源从参照融合中移除，污染模态的残差保留完整偏差，其余模态的残差仅受 `O(ε)` 影响；阈值 `χ²` 给出分离条件。

**定理 1（v8 的六不变式保持）** 在 R0–R3 任一档，v7 的六不变式均保持；新增的 RMF 只在观测层与阈值统计层增强，不改变 CVC/SpatialCert/RT-CVC/FaultCert/PrimitiveGraph 的语义；R3 严格等价 v7。证明：由 InvariantMap（定义 542）逐项检查，结合引理 79 的 R3 等价性。

| 消融（E542/E543） | 分别下降 ≥ 30%/40% | 确认 RMF 组件真实生效 |
| 功耗（E544） | 增量 ≤ 6W | 降低融合频率、事件触发更新 |

## 8. 本轮最大风险

**一句话**：如果污染预算 ε 与健康度标定失准，系统可能在真实污染超过预算时仍输出“certified”，或把正常的跨模态差异误判为故障而频繁降到 R3，导致安全证书与任务效率同时受损。
