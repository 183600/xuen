# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环第 3 轮；本轮灵感：「LoRA」×「扩散策略」）

> R69 问出了「**我该向谁求证、还能问什么**」，并交付了 FLUID-RAS。但它整套「epistemic」机器有一个隐蔽的偷换：**U_epi 是同一个流模型采样 K 次得到的模态熵**。单模型的多峰性测的是「这个模型认为世界有几种可能」，而不是「这个模型自己不知道什么」。一个自信而错误的世界模型，可以在一个完全错误的假设下吐出漂亮的单峰；一个正确但面对真歧义的世界模型，也会因为世界的多峰而被判为高 epistemic。R69 把**世界的歧义（ambiguity）**与**模型的 ignorance（无知）**压进了同一个标量，于是「要不要问」这个决策从一开始就建立在错误的轴上。
>
> 本轮两个灵感各自给出了一根 R69 缺失的轴：
> - **LoRA** 把「模型不确定性」放进**参数空间**——一个由低秩增量张成、可枚举、可签名、可审计的小空间。采「适配器」而不只是采「噪声」，才能在参数轴上看见 ignorance；而低秩这个让集成变便宜的假设，也正好是它的盲区（见 §6）。
> - **扩散策略** 把「歧义」铺在**噪声尺度轴**上——模态在去噪过程中有生有死。真模态**持久**，幻觉模态**瞬逝**；这一条直接正面回应 R69 自陈的最大风险。扩散的 score 还允许把「交互获得的证据」写成**可逆的能量引导项**，而不是像 R69 那样把一个可能被投毒的答案永久写进后验。
>
> 核心命题：**不确定性至少有三根轴——响应空间的噪声（U_ale）、响应空间同一参数假设下的世界歧义（U_amb）、参数空间的模型无知（U_epi）；外加一个看不见的第四项：落在适配器张成空间正交补里的秩盲区（U_blind）。四者对应四种完全不同的处置：收紧、交互、换用/拒绝已验证适配器、保守升级。** 命名 **PRISM-RAS**（Parameter-space Rank-Informed Separation of Multimodality）。理论姿态不变：R69 是本轮在「单适配器 + 单噪声尺度」边界上的严格退化，R68 是再往前的「永不交互」边界；安全侧只增不减。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信我的犹豫不是因为我根本没学会？**」——在开口提问之前，先分清「世界在犹豫」还是「我在无知」。

## 0. 直觉与动机

**灵感 1（LoRA →  epistemic 住在参数里，不在样本里）**
直觉：想知道「模型到底懂不懂」，你不会把同一个学生考十遍，再看他十次答案的分散度——那测的是题目本身的歧义和答题噪声。你要找的是**十个不同但都合格的学生**，看他们是否一致。R69 做的是前者（同一网络采 K 次），R70 做后者（K 个低秩适配器 {θ₀+B_kA_k}）。LoRA 让「十个学生」非常便宜：每个只差一个秩 r≪d 的增量，可以全部装进显存、逐个签名、逐个审计。关键是三件事：(a) 适配器分歧 = 参数轴上的 epistemic；(b) 单个适配器内部的多峰 = 世界歧义/生成多模态；(c) 低秩意味着行为改变量可由 ‖Δθ‖ 界定，于是「换适配器」这件事本身可以被认证。

**灵感 2（扩散策略 → 歧义有尺度，幻觉有寿命）**
直觉：扩散模型在噪声尺度 t 上做去噪。t 很大时只看得到粗结构，细模态还没分开；t 很小时细模态才出现。于是「两个模态到底分不分得开」不该是一个数，而应是曲线 Δ_min(t)。更重要的是：**真模态会在很大一段 t 区间里持续存在，采样噪声催生的假模态只在很窄的 t 带内闪现**。这就是模态的「出生–死亡持久性」。R69 用一次聚类判定模态，天然会把一次采样偶然形成的假簇当成真模态；R70 用跨尺度的持久性过滤——这是一个**免训练**的幻觉模态判据，直接打在 R69 最大风险上。

**灵感 3（分层方差分解 → 把「epistemic」拆对）**
直觉：对任意标量泛函 φ（如轨迹代价），先在每个适配器内部按模态分解，再跨适配器分解，正好应用两次全方差公式：
Var_total = Σ_k π_k Σ_m w_{k,m} σ²_{k,m}〔模态内 = U_ale〕 + Σ_k π_k Var_m(μ_{k,m})〔适配器内跨模态 = U_amb〕 + Var_k(Σ_m w_{k,m} μ_{k,m})〔跨适配器 = U_epi〕。
三项**严格可加、可辨识**，不靠人为加权。它们的处置完全不同：U_ale 再问也问不出（收紧）；U_amb 正是 R69 的交互对象（问/看/触）；U_epi 是模型容量问题，**问世界也问不出来**（换已验证适配器、或拒绝、或离线补数据）——把 U_epi 当成 U_amb 去追问，正是 R69「追问幻影」的根源。

**灵感 4（引导式证据合成 → 交互应当可逆）**
直觉：R69 的 `update_belief` 用贝叶斯把答案写进模态后验。一旦答案被投毒，污染就永久留在信念里。扩散策略的 score 允许另一种做法：把证据写成**能量引导** s = s_base + λ∇log p(y|x)。它有三个好处：(a) 基础先验 p_base 永远保留，λ 可退火到 0 → 可逆；(b) 多源证据是 product-of-experts，几何平均天然实现「k 源一致」；(c) **投毒不再是「低置信地采纳」，而会表现为专家冲突（product 质量塌陷）**——冲突本身是可检测信号，比 R69 更早暴露共谋欺骗。

**灵感 5（低秩的双刃 → 秩盲区与「适配即吸收」）**
直觉：低秩既是效率，也是盲点。若真实的模型误差落在 span{Δθ_k} 的正交补里，所有适配器会**一致地**给出同一个错误答案——跨适配器方差≈0，系统在最该保守的时刻报告「没有 epistemic」。更隐蔽的是 R68 的老问题会借尸还魂：R68 怕标定层「吸收」缓变故障；R70 引入适配器层，就多了一个更强的吸收器——**换一个适配器把故障遮住，看起来指标恢复了，其实故障被参数化了**。所以本轮必须交付「适配即吸收」对偶监控：只有当性能恢复能被独立证据（R69 的 Δa 通道、来源证明、子空间覆盖）支撑时，才允许热切换。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PRISM-RAS 总览）** PRISM-RAS = (LAP, AUD², DSS, GEC, RBB, PAA, RAS-WM†)。三不变式：
(i) **零在线学习写**（强于 R68 定义 276-i）：基座与适配器全程只读；运行时允许**选择/组合已完成签名的适配器**，禁止在线创建、训练或微调任何参数；
(ii) **秩与行为预算**：总激活秩 ≤ r_max，组合偏差 ‖Δθ_comp‖_* ≤ δ_max，且任何组合须过 RBB 认证；
(iii) **可逆与来源**：每条交互证据以可退火的引导项注入（保留未引导先验），每个适配器带签名来源；证据/适配器不可追溯即视为未消解。

**定义 311（低秩适配器后验 LAP）** 基座 θ₀，适配器库 𝒟 = {Δθ_k = B_k A_k | B_k∈ℝ^{d×r_k}, A_k∈ℝ^{r_k×m}, r_k ≤ r_max}，每个带签名清单 (hash, 训练分布, rank, ‖Δθ_k‖_*)。后验 q(Δθ) = Σ_{k=1}^{K_p} π_k δ_{Δθ_k}（或对角高斯变分）。预测分布 p(ξ|o) = Σ_k π_k p_{θ₀+Δθ_k}(ξ|o)。**响应空间只由基座定义，参数空间只由库定义**——这是两根轴的分离点。

**定义 312（分层双轴分解 AUD²）** 对泛函 φ(ξ)，令第 k 个适配器的模态为 {m}、模态权重 w_{k,m}、模态均值 μ_{k,m}、模态内方差 σ²_{k,m}，适配器权重 π_k。定义
U_ale = Σ_k π_k Σ_m w_{k,m} σ²_{k,m}（模态内、不可约）；
U_amb = Σ_k π_k Var_m(μ_{k,m})（同一参数假设下的世界歧义、可由观测消解）；
U_epi = Var_k(Σ_m w_{k,m} μ_{k,m})（跨参数假设的模型无知、观测不可解，只能靠数据/换适配器）。
三者满足 Var_total = U_ale + U_amb + U_epi（全方差公式两次）。多维 φ 时用 Fréchet 方差 / MMD 对偶，保持可加性的近似版本并给出误差界。**不做简单加权和**：三者进入不同通道（定义 320）。

**定义 313（扩散策略与噪声尺度谱 DSS）** 去噪器 ε_θ(x_t,t|o)，score s_θ(x,t) = −ε_θ(x_t,t)/σ_t。在尺度网格 t_1>…>t_M 上做**确定性去噪**得后验均值估计 x̂₀(t) = (x_t − σ_t ε_θ)/α_t。对每个 t 聚类得候选原型；跨 t 跟踪原型轨迹，形成模态树。可分性定义为一个**谱**：Δ_min(t) = min_{i≠j} W₂(ξ̄_i(t), ξ̄_j(t)) / √(tr Σ_max(t))，只在模态确实存在（持久性达标，定义 314）的区间上取值。

**定义 314（模态持久性与幻觉判据）** 模态 m 在尺度 t 的「可见带」为 [t_d(m), t_b(m)]（t 越大越噪）。持久性 pers(m) = t_b − t_d。**可靠模态权重** w̃_k = w_k · σ(pers_k − τ_pers)（σ 为软阈值），其中 τ_pers 由校准集给出。**幻觉判据**：pers(m) < τ_pers ⇒ 判为瞬逝假模态，从模态集合中剔除后再计算 U_amb、U_epi。该判据**不训练新参数**，只做跨尺度一致性检验，是对 R69 定义 296 的直接修补。

**定义 315（引导式证据合成 GEC）** 交互动作 g 执行后得证据 y。注入方式为 score 倾斜：
s_guided(x,t) = s_base(x,t) + Σ_{i=1}^{n} λ_i ∇_x log p(y_i | x, t, g_i)。
对应的引导分布 p_λ ∝ p_base · Π_i p(y_i|·)^{λ_i}（product-of-experts）。定义**专家冲突** κ = 平均成对 KL(p(y_i|·) ‖ p(y_j|·)) 与引导前后有效样本量塌陷量。规则：(a) 单源证据只给似然、不定案（继承 R69 证据纪律）；(b) κ > τ_κ ⇒ 判为投毒/共谋，λ 整体收缩；(c) λ 可退火至 0，基础先验 p_base 永不改写 ⇒ 可逆。

**定义 316（秩-行为预算与安全轨道 RBB）** 设速度场/去噪器对参数为 L_θ-Lipschitz、对状态为 L_x-Lipschitz，H 为时域。对组合偏差 Δθ_comp 有行为界 ‖v_{θ₀+Δθ} − v_{θ₀}‖ ≤ L_θ‖Δθ‖_*‖x‖ + o(‖Δθ‖)。定义认证安全轨道半径 ρ_cert = L_θ·δ_max·H·C_x。RBB 强制 ‖Δθ_comp‖_* ≤ δ_max、rank(Δθ_comp) ≤ r_max，并输出 ρ_cert 作为「换适配器后仍留在基座安全包络内」的证书。

**定义 317（来源与组合证书）** 每个适配器可验证签名 prov(Δθ_k)。组合 Δθ_comp = Σ_k α_k Δθ_k 须满足三角预算 Σ_k |α_k|‖Δθ_k‖_* ≤ δ_max（即使单项良性，和也可能越界——这是组合攻击）。来源伪造、清单缺失、或组合越界 ⇒ 该组合不可用。

**定义 318（适配器校准门 ACG）** 跨适配器分歧须校准：以 (U_epi^{obs}, 实际误差) 作可靠图，ECE_epi ≤ τ_ece。越界 ⇒ 禁用「参数轴驱动」的决策（不据此换适配器、不据此判幻觉），退化为单基座 + R69 响应轴行为。对应 R69 MCG 在参数轴上的镜像。

**定义 319（秩盲区与子空间覆盖 β）** 设适配器差分张成子空间 𝒮 = span{Δθ_k − Δθ_{k'} }。真实模型误差的「可观测部分」在其上的投影记为 P_𝒮，正交补为 P_⊥。定义子空间覆盖 β = E[‖P_⊥ error‖²] / E[‖error‖²]，在留出校准集上估计。**U_epi^{obs} = Var_k(·) 只是 U_epi^{true} 的一个下界**：当 β 高时，跨适配器一致并不代表正确。于是 U_blind = β·(U_epi^{obs} + U_amb) 作为必须额外承担的不可观测项。同时把 U_epi 分为可选择的 U_epi^{sel}（落在认证适配器差分张成内，可靠证据/探针选定）与新颖的 U_epi^{nov}（落在正交补内，任何交互都问不出来）。

**定义 320（四级不确定性的四级处置）** U_ale → 收紧 λ_floor（不问）；U_amb → MINT 交互（看/问/触，R69 机制）；U_epi^{sel} → 用探针/证据在**已验证适配器库**内做离散选择，不得创建新适配器；U_epi^{nov} 与 U_blind → **禁止交互追问**（问不出），换用最保守的已验证基座或拒绝，并上报离线补数据。任一环节证据不足 ⇒ U_amb 保持未消解并回落 R68 兜底。

**定义 321（威胁模型 ℰ_PRISM）** ℰ_PRISM = ℰ_FLUID × ℰ_adapter × ℰ_guide。ℰ_adapter：投毒/后门适配器、秩膨胀（低秩名义下偷塞高秩行为）、组合攻击（良性 + 良性 → 恶意）、来源伪造。ℰ_guide：引导注入、过冲导致模式坍缩、可逆性攻击（反复微调 λ 把先验记住）。

**定义 322（证书 J_PRISM）** J_PRISM = (J_FLUID, adapter_prov_hash, rank_used, delta_bound, rho_cert, ECE_epi, mode_pers_min, subspace_coverage_beta, guidance_lambda_max, prism_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_epi ≤ τ_ece ∧ ‖Δθ_comp‖_* ≤ δ_max ∧ 证据可逆且可追溯 ∧ β ≤ τ_β（否则必须携带 U_blind 降级标记）。

**定义 323（可逆引导审计 VQAuditor-P）** 在 R69 VQAuditor-I 上新增：问句/探针是否只为区分「已验证适配器」而非凭空创建；λ 是否被过量使用（过冲）；是否存在用适配器「吸收」故障（见定义 326）；引导是否可完全退火回 p_base。结论回灌 AuditBuf，作为下一轮 RBB/ACG 先验。

**定义 324（适配器热切换与时序）** 适配器选择为离散事件，只允许在 R68 定理 15 的换装不变式成立时发生（安全静止点/认证边界），禁止运动中热切换；切换前后须满足 ρ_cert 内的行为连续，λ 轨迹连续，审计记录切前/切后。

**定义 325（自适应适配器与尺度预算）** 默认 K_p=1（仅基座）、N_step 固定、t 网格稀疏；仅当 mode_head 报歧义或 U_epi^{sel} 非零时升 K_p=3、加密 t 网格，且总计算受预算硬约束。K_p 与 t 网格的联合选择是「参数轴分辨率 × 噪声轴分辨率」的预算折中。

**定义 326（适配即吸收对偶 AAA）** 性能恢复可能来自两种本质不同原因：(a) 真实的任务/本体偏移，可被低秩子空间表示（β 低、Δa 不升、来源合法）；(b) 传感器/执行器缓变故障被新适配器「参数化吸收」（β 高或 Δa 升、且恢复随时间漂移）。定义 AAA 监控量 comb = (β, Δa, 恢复曲线斜率)。仅当 (a) 的三个证据一致时才允许热切换；否则视为吸收，退回 R68 最保守并告警。这是 R68 定义 309 在参数轴的镜像。

## 2. 关键算法骨架

```python
# IP-264 LAP：只读低秩适配器集合（签名验证 + 后验采样）
class LowRankAdapterEnsemble:
    def __init__(self, base, library, pi):
        self.base, self.pi = base, pi                  # base 只读，library 已签名只读
        self.library = [a for a in library if a.verify_sig()]   # 来源不可信的直接剔除

    def sample(self, o, Kp, K, N, t_grid):
        out = []
        for k, adapt in enumerate(self.select(Kp)):    # 选择，不是训练
            theta = compose(self.base, adapt)          # θ₀ + B_k A_k
            out.append([diffusion_sample(theta, o, N, t_grid) for _ in range(K)])
        return out                                     # 每个适配器内的 K 条样本

# IP-265 AUD²：分层全方差分解（两次）
def decompose_two_axis(samples_by_adapter, pi, pers):
    U_ale = U_amb = U_epi = 0.0
    mus_k = []
    for k, S in enumerate(samples_by_adapter):
        modes = cluster_trajectories(S)
        w     = reliable_weights(mode_weights(modes), pers[k])  # 用持久性重加权
        # 剔除瞬逝假模态后再分解
        keep  = [m for m in modes if pers[k][m] >= TAU_PERS]
        if not keep: keep = modes
        U_ale += pi[k] * sum(w[m]*trace(cov(m)) for m in keep)
        U_amb += pi[k] * frechet_var([mean(m) for m in keep], weights=w)
        mus_k.append(frechet_barycenter([mean(m) for m in keep], weights=w))
    U_epi = frechet_var(mus_k, weights=pi)             # 跨适配器原型分歧
    return U_ale, U_amb, U_epi

# IP-266 DSS：跨噪声尺度的模态持久性（免训练幻觉判据）
def mode_persistence(denoiser, o, t_grid):
    tracks = track_prototypes(denoiser, o, t_grid)     # 跨 t 跟踪去噪原型
    pers = {}
    for m, ts in tracks.items():
        pers[m] = max(ts) - min(ts)                     # 可见带宽度
    return pers                                         # pers 小 ⇒ 幻觉模态

# IP-267 GEC：可逆、可冲突检测的证据引导
class GuidedEvidenceComposer:
    def compose(self, score_base, evidence, lam):
        score = score_base
        for (yi, gi), li in zip(evidence, lam):
            score = lambda x, t: score(x,t) + li * grad_loglik(yi, x, t, gi)
        kappa = pairwise_kl_conflict(evidence)          # 专家冲突
        if kappa > TAU_KAPPA:
            lam = [l * TAU_KAPPA / kappa for l in lam]  # 投毒/共谋 ⇒ 收缩
        return score, lam, kappa                        # lam→0 可完全退回 p_base

# IP-268 RBB：秩-行为预算与安全轨道证书
def certify_composition(base, adapters, coeffs):
    delta = sum(abs(a)*norm_star(adapters[k]) for k, a in coeffs.items())
    rank  = effective_rank(adapters, coeffs)
    if delta > DELTA_MAX or rank > R_MAX: return None   # 组合越界/秩膨胀
    rho   = L_THETA * delta * H * C_X                 # 行为界 → 安全轨道半径
    return Cert(delta=delta, rank=rank, rho_cert=rho)

# IP-274 PRISM 主闭环（在 FLUID-RAS 的不确定性处置处替换为四通道）
def PRISM_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 1) 参数轴：默认仅基座；歧义/选择态才升 Kp
    Kp = 1 if (M.fmp.mode_head(z) < TAU_MODE and M.last_epi_sel == 0) else 3
    S  = M.lap.sample(o, Kp, K=4, N=2, t_grid=M.grid(Z=Kp))
    # 2) 噪声轴：模态持久性 → 幻觉过滤；子空间覆盖 → 秩盲区
    pers = M.dss.mode_persistence(M.fmp.denoiser, o, M.grid(Kp))
    U_ale, U_amb, U_epi = M.aud2.decompose_two_axis(S, M.lap.pi, pers)
    beta = M.aaa.coverage_beta(M.calib_holdout)        # 留出集估计
    U_epi_sel, U_epi_nov = M.aaa.split_epi(U_epi, beta)
    U_blind = beta * (U_epi + U_amb)
    # 3) 门控：参数轴不可信 ⇒ 禁止用参数轴做决策
    if M.acg.ece_epi > TAU_ECE:
        return conservative_round(M, o, lam_floor(U_ale + U_amb + U_epi + U_blind))
    # 4) 四通道处置：只有 U_amb 与 U_epi_sel 允许交互
    g = (M.mint.choose_interaction([], M.budget)
         if (U_amb + U_epi_sel > TAU_AMB) else None)
    if g is not None:
        y = M.cia.execute(g)                           # 看/问/触，带认证
        score, lam_g, kappa = M.gec.compose(M.fmp.score, y, M.lam0)
        if kappa > TAU_KAPPA:                          # 冲突/投毒 ⇒ 不作数
            U_amb, U_epi_sel = U_amb, U_epi_sel
        else:
            U_amb = M.gec.entropy_after(M.gec.sample(score), U_amb)
    # 5) U_epi_nov / U_blind 只能换已验证基座或拒绝（禁止追问）
    if U_epi_nov + U_blind > TAU_NOV:
        plan = M.aaa.switch_or_refuse(M.lap.library)   # 只选，不造
        if plan is None: return refuse(M, U_epi_nov + U_blind)
    # 6) 风险缩放：可解项消解则只收紧 U_ale + 不可观测项
    U_floor = U_ale + U_epi_nov + U_blind + (U_amb + U_epi_sel if g is None else 0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ...)
    # 7) 换装须通过 RBB + AAA + 换装不变式
    cert = M.rbb.certify_composition(M.lap.base, M.lap.library, M.plan)
    if cert is None or not M.aaa.not_absorption(beta, M.fma.last):
        return conservative_round(M, o, max(lam, 0.8))
    mode = M.select_mode(S, U_amb, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(g, U_amb, U_epi_sel, U_blind, cert, lam_g, kappa)
    return k, lam, mode, (U_ale, U_amb, U_epi, U_blind)
```

## 3. 推导

**引理 19（分层方差分解的严格可加性）** 设 (K, M, Ξ) 为分层随机变量：适配器 K∼π，模态 M|K∼w_{·,m}，动作 Ξ|M,K∼p_{k,m}。则对任意标量 φ(Ξ)，
Var φ = E_K E_M Var(φ|K,M) + E_K Var_M(E[φ|K,M]) + Var_K(E[φ|K,M])。
括号三项即 U_ale、U_amb、U_epi，非负且可辨识（在适配器/模态可区分的可辨识性条件下）。系：**R69 的 U_epi 是 U_amb 在「单参数假设」下的投影**；把 K 固定为一个适配器，定义 312 退化为 R69 定义 297。多维情形用 Fréchet 方差替代，可加性变为带 O(W₂ 曲率) 误差的近似，误差界由 A99（动作块曲率有界）给出。

**引理 20（模态持久性抗幻觉上界）** 设采样噪声诱导的假模态在尺度轴上的可见带长度服从分布 F_spur，真模态持久性 ≥ τ_true。取阈值 τ_pers ∈ (F_spur^{-1}(1−ε), τ_true)，则被误纳的假模态比例 ≤ ε，且被误删的真模态比例 = 0（A100：真模态持久性下界）。系：**持久性是免训练的幻觉过滤器**——不依赖再训练一个判别器，因此不会把判别器的偏差带进闭环。对 R69 定义 296 的 K 次单尺度聚类，等价于 τ_pers = 0，即无过滤。

**引理 21（低秩行为界与组合安全）** 在定义 316 的 Lipschitz 条件下，对任意组合 Δθ_comp，存在常数使 ‖v_{θ₀+Δθ} − v_{θ₀}‖ ≤ L_θ‖Δθ‖_*·C_x + o(‖Δθ‖)；于是 ρ_cert = L_θ·δ_max·H·C_x 给出一个可计算的安全轨道半径，适配器切换后的轨迹不越出基座包络外 ρ_cert。又由三角不等式，Σ_k |α_k|‖Δθ_k‖_* 是组合偏差的严格上界，故可用线性预算在**组合前**拦截组合攻击与秩膨胀。系：**低秩不只省算力，它让「换适配器」成为可认证动作**——这是 R69 完全不具备的安全性质（R69 的流模型可任意改变行为）。

**引理 22（引导可逆性与投毒可检测）** 令 p_λ ∝ p_base·Π_i p_i^{λ_i}。当 λ→0，p_λ → p_base（可逆）；单源投毒 y_bad 在 product-of-experts 下与其它源的有效支持重叠小时，专家冲突 κ 增大、引导后有效样本量塌陷，故存在阈值 τ_κ 使投毒被检出。进一步，若 ρ 个源的欺骗相关 <1，则 κ 的期望随 k 增大而增大（A101：专家条件独立性）。系：**R69 的「k 源一致」纪律被实现为一个几何量 κ，而不是事后规则**；且污染不会写进永久后验。

**引理 23（适配即吸收的不可判定性与可检测充分条件）** 仅凭性能恢复，无法区分「真实偏移被适配器正确建模」与「故障被适配器吸收」（两者都使任务指标恢复）。但在 (β 低 ∧ Δa 不升 ∧ 来源合法 ∧ 恢复曲线收敛) 同时成立时，吸收概率 ≤ ε_abs（A102：故障方向与任务子空间近似正交）。故 AAA 只能给**充分检测条件**，不能给充要判据——这与 R68 引理 13 的「标定吸收」同构，是参数轴上的结构性极限。

**定理 18（PRISM 严格包含 FLUID 与 CALM）** 在 A95–A102 下：
(i) 取 K_p=1（仅基座）、λ_g≡0、τ_pers=0、β=0，PRISM 的决策与 FLUID-RAS 逐指令相同；
(ii) 再取 VoI ≤ 成本，退化为 R68 逐指令相同；
(iii) 一般情形下，PRISM 在任意状态上的期望风险 ≤ FLUID-RAS ≤ CALM（安全侧只增不减）：新增的 U_blind、U_epi_nov 只会抬高 λ_floor 或触发拒绝，永不降低；可解项消解后获得的 resolution bonus 不越过 λ_floor(U_ale + U_blind)。
因此 R68 ⊂ R69 ⊂ R70 是**嵌套**的，而不是并列替换。

**定理 19（四通道处置的安全性与无突变）** 信息动作与适配器切换分别通过 C-RAS-WM 与 RBB+换装不变式认证后：(i) 物理风险 ≤ max(ε_int, ρ_cert)；(ii) 切换只改变「用哪个已认证参数假设」，不改变安全包络；(iii) 任一通道失败（门控越界/冲突超阈/组合越界/吸收可疑）时 λ 单调不降地退化为更保守层，控制连续、无突变。证明用逐通道的单调性与 R68 定理 15 的换装不变式拼接。

## 6. 本轮最大风险

**一句话**：PRISM 把「我是否该问、该不该换模型」押在「参数轴上的分歧能被低秩子空间看清」这个前提上，而**低秩既是它的效率来源，也正是它的盲区**——当真实的模型无知落在适配器张成的正交补里时，所有适配器会一致地自信（U_epi^{obs}≈0），系统就在最该保守、最该拒绝的时刻报告「没有歧义」，把结构性不知道误当成世界噪声而沉默；更糟的是，它引入的适配器层会成为比标定层更强的故障吸收器，一次「看起来修好了」的热切换可能只是把缓变故障参数化藏起来。

**次级风险与缓解**：
1. **秩盲区（最大风险的具体化）** → 定义 319 的子空间覆盖 β + U_blind 显式抬升 λ_floor；β 越界即禁止参数轴决策（E308）；但只能缓解、不能消除。
2. **适配即吸收（R68 风险在高层的复现）** → 定义 326 AAA 的双证据（Δa + β + 恢复曲线）+ 引理 23 的充分条件；检测不足时拒绝切换（E309）。
3. **组合攻击/后门/来源伪造** → 引理 21 的三角预算 + 签名来源 + 组合前拦截（E305、E312）。
4. **交互投毒/共谋** → GEC product-of-experts 的冲突 κ + 引理 22 + 可逆退火（E306）。
5. **实时预算被 K_p×尺度双升击穿** → 自适应 K_p/稀疏 t 网格 + 常规 K_p=1 路径（E310）。
6. **引导过冲/模态坍缩** → λ 上限 + 退火 + 保留 p_base 的模态覆盖（E313）。

**定义 312（AUD²）** 两次全方差分解：`U_ale` 模态内、`U_amb` 适配器内跨模态、`U_epi` 跨适配器；三者严格可加、分通道处置，不做加权和。

**定义 313–314（DSS + 持久性）** score `s=−ε/σ`；跨 t 跟踪去噪原型得模态树；`Δ_min(t)` 为可分支谱；可靠权重 `w̃=w·σ(pers−τ_pers)`，`pers<τ_pers` 判为瞬逝幻影并剔除。

**定义 315（GEC）** `s_guided = s_base + Σλ_i∇log p(y_i|·)`，`p_λ ∝ p_base·Πp_i^{λ_i}`；κ 为专家冲突；λ→0 可复原；单源不定案，κ 超阈判投毒。

**定义 316–317（RBB/组合证书）** Lipschitz 行为界 ⇒ `ρ_cert`；组合三角预算 `Σ|α_k|‖Δθ_k‖_* ≤ δ_max`、`rank ≤ r_max`；来源伪造/越界即禁用。

**定义 318–319（ACG/秩盲区）** 跨适配器分歧须校准 `ECE_epi ≤ τ_ece`；子空间覆盖 `β` 给出下界意识：`U_blind=β(U_epi+U_amb)`，并把 epi 拆为 `epi^{sel}`（库内可选）与 `epi^{nov}`（正交补、问不出）。

**定义 320（四通道处置）** `U_ale→收紧`；`U_amb→交互`；`U_epi^{sel}→库内离散选择`；`U_epi^{nov}+U_blind→禁止追问、换最保守基座或拒绝`。

**定义 321–323（威胁/证书/审计）** ℰ_PRISM=ℰ_FLUID×ℰ_adapter×ℰ_guide；J_PRISM 并入 provenance/rank/δ/ρ/ECE_epi/pers/β/λ_max；VQAuditor-P 审凭空造适配器、过冲、吸收。

**定义 324–325（热切换/预算）** 热切换仅在换装不变式成立时发生、无运动中切换、行为连续；自适应 `K_p`（默认 1，歧义升 3）与稀疏 t 网格受硬预算。

**定义 326（AAA）** `comb=(β, Δa, 恢复曲线斜率)`；仅当三者一致指向「真实偏移」才允许切换，否则判为吸收、退回 R68。

```python
class LowRankAdapterEnsemble:
    def sample(self, o, Kp, K, N, t_grid):
        out = []
        for adapt in self.select(Kp):                  # 选择，不训练
            theta = compose(self.base, adapt)          # θ₀ + B_k A_k
            out.append([diffusion_sample(theta, o, N, t_grid) for _ in range(K)])
        return out                                     # [适配器][样本]

# IP-265 AUD²：两次全方差分解 + 持久性重加权
def decompose_two_axis(S, pi, pers):
    U_ale = U_amb = 0.0; mus = []
    for k, samples in enumerate(S):
        modes = cluster_trajectories(samples)
        keep  = [m for m in modes if pers[k][m] >= TAU_PERS] or modes
        w     = mode_weights(keep)
        U_ale += pi[k] * sum(w[m]*trace(cov(m)) for m in keep)
        U_amb += pi[k] * frechet_var([mean(m) for m in keep], weights=w)
        mus.append(frechet_barycenter([mean(m) for m in keep], weights=w))
    U_epi = frechet_var(mus, weights=pi)               # 跨适配器原型分歧
    return U_ale, U_amb, U_epi

# IP-266 DSS：跨尺度持久性（免训练幻觉过滤）
def mode_persistence(denoiser, o, t_grid):
    tracks = track_prototypes(denoiser, o, t_grid)
    return {m: max(ts) - min(ts) for m, ts in tracks.items()}

# IP-267 GEC：可逆、可冲突检测的证据引导
def compose_evidence(score_base, evidence, lam):
    score = score_base
    for (yi, gi), li in zip(evidence, lam):
        score = lambda x, t: score(x, t) + li * grad_loglik(yi, x, t, gi)
    kappa = pairwise_kl_conflict(evidence)
    if kappa > TAU_KAPPA:                              # 投毒/共谋 ⇒ 收缩
        lam = [l * TAU_KAPPA / kappa for l in lam]
    return score, lam, kappa                           # lam→0 退回 p_base

# IP-268 RBB：秩-行为预算
def certify_composition(base, adapters, coeffs):
    delta = sum(abs(a)*norm_star(adapters[k]) for k, a in coeffs.items())
    if delta > DELTA_MAX or effective_rank(adapters, coeffs) > R_MAX:
        return None
    rho = L_THETA * delta * H * C_X
    return Cert(delta=delta, rho_cert=rho)

# IP-274 主闭环
def PRISM_RAS_round(M, obs):

    U_floor = U_ale + U_epi_nov + U_blind + (U_amb + U_epi_sel if g is None else 0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
```

## 4. 推导

**引理 19（分层方差分解）** 对 (K,M,Ξ) 分层，`Var φ = E_K E_M Var(φ|K,M) + E_K Var_M(E[φ|K,M]) + Var_K(E[φ|K,M])`，三项即 U_ale/U_amb/U_epi，非负可辨识。系：R69 的 U_epi 是 U_amb 在单参数假设下的投影（K 固定即退化）。

**引理 20（持久性抗幻觉上界）** 假模态可见带长度分布 F_spur，真模态持久性 ≥ τ_true；取 τ_pers ∈ (F_spur⁻¹(1−ε), τ_true)，误纳假模态 ≤ ε、误删真模态 = 0。系：持久性是**免训练**过滤器；R69 单尺度聚类等价于 τ_pers=0。

**引理 21（低秩行为界与组合安全）** Lipschitz 下 `‖v_{θ₀+Δθ}−v_{θ₀}‖ ≤ L_θ‖Δθ‖_*C_x + o(‖Δθ‖)`，故 `ρ_cert` 可计算；三角不等式给组合偏差的严格上界，可在**组合前**拦截组合攻击/秩膨胀。系：低秩让「换适配器」成为可认证动作。

**引理 22（引导可逆与投毒检测）** `p_λ ∝ p_base Πp_i^{λ_i}`，λ→0 复原；单源投毒与其它源支持重叠小时 κ 增大、有效样本量塌陷 ⇒ 可检出；k 源欺骗相关 <1 时 κ 期望随 k 增大。系：R69 的「k 源一致」被实现为几何量 κ，且污染不写进永久后验。

**引理 23（适配即吸收的不可判定性）** 仅凭性能恢复无法区分「真实偏移被正确建模」与「故障被吸收」；但 (β 低 ∧ Δa 不升 ∧ 来源合法 ∧ 恢复收敛) 同时成立时吸收概率 ≤ ε_abs。故 AAA 只给充分条件——与 R68 引理 13 同构，是参数轴的结构性极限。

**定理 18（PRISM 严格包含 FLUID 与 CALM）** 在 A95–A102 下：K_p=1、λ_g≡0、τ_pers=0、β=0 时与 FLUID-RAS 逐指令相同；再 VoI≤成本时与 R68 逐指令相同。一般情形期望风险 ≤ FLUID ≤ CALM：U_blind/U_epi_nov 只抬高 λ_floor 或触发拒绝；resolution bonus 不越过 λ_floor(U_ale+U_blind)。故 **R68 ⊂ R69 ⊂ R70 嵌套**。

**定理 19（四通道处置安全与无突变）** 信息动作过 C-RAS-WM、切换过 RBB+换装不变式后：物理风险 ≤ max(ε_int, ρ_cert)；切换只改「用哪个已认证参数假设」、不改安全包络；任一通道失败时 λ 单调不降地退化，控制连续无突变。

## 7. 本轮最大风险

**一句话**：PRISM 把「我是否该问、该不该换模型」押在「参数轴上的分歧能被低秩子空间看清」这个前提上，而**低秩既是效率来源、也正是盲区**——当真实的模型无知落在适配器张成的正交补里时，所有适配器会一致地自信（U_epi^{obs}≈0），系统就在最该保守、最该拒绝的时刻报告「没有歧义」，把结构性不知道误当成世界噪声而沉默；更糟的是，适配器层会成为比标定层更强的故障吸收器，一次「看起来修好了」的热切换可能只是把缓变故障参数化藏起来。

**次级风险与缓解**：秩盲区（定义 319 的 β + U_blind 显式抬升、β 越界禁参数轴决策，E308，只能缓解不能消除）；适配即吸收（定义 326 AAA 双证据 + 引理 23 充分条件，E309）；组合/后门/来源伪造（引理 21 三角预算 + 签名拦截，E305/E312）；交互投毒（GEC 冲突 κ + 引理 22 + 可逆退火，E306）；实时预算被 K_p×尺度双升击穿（自适应 K_p + 稀疏 t 网格，E310）；引导过冲/模态坍缩（λ 上限 + 退火 + 保留 p_base，E313）。
