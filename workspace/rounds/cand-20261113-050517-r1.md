# 第 65 轮（承接第 64 轮「GRIP 接触接地」IP-204~213；灵感循环 II 第 4 轮；本轮灵感：「Gazebo」×「基准测试」）

> 第 64 轮把安全链扩到「几何-技能-干扰-接触」四层，但其最大风险同样尖锐：**力/触觉的偏置、漂移、饱和与接触模型错误会让 CGG 把"传感器错误"误判为"几何幻觉"，力觉从接地真值反变为新的单点故障与物理伤害源**。把 63→64 连起来看，会出现一个结构性病症：**每一轮都在"加一层鲁棒性"，而每一层的新假设都会成为下一轮的最大风险——风险被逐层转嫁，认证的"假设债务"越滚越大**（A77→A83→…），且这些假设从未作为一个**端到端系统**被独立证伪过。本轮从两个词得到正面回应：
>
> **Gazebo 提供的不是"真值"，而是一个可编程、可复现、可对抗的证伪环境；基准测试提供的不是"跑分"，而是把"安全"从论文里的证明变成"在覆盖充分、统计显著、sim-to-real gap 有界、可位精确回放的反例搜索下仍然成立"的证据。**
>
> 核心命题：**从"逐层加固、层层证明"转向"端到端证伪、债务清算、保真度认证"——评测是一等公民，数字孪生必须带信任域，sim-to-real gap 必须是可认证量而非免责声明。**

## 0. 直觉与动机

**灵感 1（Gazebo → 数字孪生是可编程的证伪器，不是真值：GDT）**
直觉：Gazebo 能在 SDF 世界里随意改重力、摩擦、接触刚度、传感器噪声与延迟，还能固定随机种子做可复现回放——这让它成为**反例制造机**。但 Gazebo 的接触模型（ODE/Bullet/DART 的刚性/惩罚接触）恰恰在 GRIP 最依赖的**微滑移、软接触、粘-滑振荡**上保真度最低。所以正确用法不是"信仿真"，而是：**只在经真实锚点校准过的信任域 𝒯 内，把孪生结果当证据；域外一律标记为不可用**。孪生不是 oracle，是 falsifier。

**灵感 2（基准测试 → 认证 = 覆盖 + 统计置信 + 可复现：CFB）**
直觉：一张"Valid"证书若没有说明它**在什么任务分布上、被搜过多少反例、覆盖了多少证书声明**，就是空头支票。CFB 把 J_grip 的每个声明（ρ_force≥0、ρ_slip≥0、geo_degraded⇒r≥δ_hall/σ_J…）变成**证伪义务**，用基准实例逐条尝试推翻；证书附带覆盖向量与置信区间，覆盖不足即判 `vacuous`（空洞证书）。这把"有没有证明"改成"有没有被认真找过反例"。

**灵感 3（基准测试 → 假设债务账本：ADL）**
直觉：A77–A87 是层层堆叠的假设，很多未经实测。把它们建成**假设债务图**：节点=假设，边=依赖，证据=覆盖/反例/真实锚点，criticality=失效后果。证书强度不是由最漂亮的那条定理决定，而是由**关键路径上最弱、最未经验证的那个假设**决定（最弱环节）。ADL 让"还欠哪些实验"变成可计算、可排序、可审计的债务，而不是藏在附录里。

**灵感 4（sim-to-real → gap 是可认证量：S2R-Cert + MFE + Goodhart 检测）**
直觉：若指标 M 对场景分布是 L-Lipschitz，且 sim 与 real 的分布 Wasserstein 距离 ≤ δ_gap，则 |E_sim M − E_real M| ≤ L·δ_gap，于是**真机风险 ≤ 仿真风险界 + L·δ_gap**；δ_gap 无界时，仿真证据不可迁移。用少量真实锚点 + 大量 Gazebo 样本做**多保真控制变量**估计，可把真实样本需求降 (1−ρ²) 倍；同时用**隐藏 holdout 基准**监测"基准过拟合/Goodhart"，防止把证书刷成基准特供。

**灵感 5（合流 → FORGE：Falsification-Oriented Reproducible Gazebo-grounded Evaluation）**
闭环（全部离线/低频，实时路径不动）：GDT 建孪生与信任域 → S2R-Cert 标定 gap 与迁移界 → CFB 生成证伪义务 → AFS 覆盖引导搜索反例 → MFE 融合 sim/real 得无偏风险与 CI → ADL 结算假设债务 → 若有反例/债务超标则**降级或判 Invalid**（回灌 GRIP 修复）→ DRP 位精确回放存证 → J_forge 分级签发。**第 64 轮 GRIP 是"系统怎么安全"，FORGE 是"凭什么相信它安全，以及不信时怎么办"。**

## 1. 形式化定义（增量：定义 217–232）

- **定义 217（基准实例与任务族）**：β = (𝒲, τ, η, ℳ, s)。𝒲 为 SDF 世界 + 物理参数（引擎/步长/接触模型/摩擦/刚度）；τ 为任务；η 为干扰编排（含 GRIP 的 ℰ_F 与物理扰动）；ℳ 为指标族；s 为随机种子。任务族 D_bench = {β}。
- **定义 218（证书证伪义务）**：对 J_grip 中每条可判定声明 C，定义义务 O_C = (C, 𝔒_C, Pred_C)，𝔒_C 为判定 oracle，Pred_C: trace→{0,1}。一次运行 r 若 Pred_C(r)=0 则产生**反例见证** w。义务集 𝒪(J_grip) 覆盖全部安全声明。
- **定义 219（证据状态与覆盖）**：e_C ∈ {vacuous 空洞, witnessed 有支持, falsified 被推翻, unproven 未测}。覆盖 cov(C) = μ({β∈D_bench : β 触发 C 的判定路径}) / μ(D_bench)；cov(C) < δ_cov ⇒ e_C=vacuous。整体覆盖向量 Cov=(cov(C_1),…)。
- **定义 220（Gazebo 数字孪生与信任域）**：T=(engine, contact_model, sensor_models, θ_phys)。信任域 𝒯_δ = {β : gap_M(β) ≤ δ, ∀M∈ℳ}，gap 由真实锚点估计。**域外仿真结果不进入 J_forge，只能产生"待验证猜想"**。
- **定义 221（sim-to-real gap 认证）**：δ_gap(M)=sup_{β∈D_bench}|M_sim(β)−M_real(β)|（或 W₁(D_sim^M, D_real^M)）；认证上界 δ̂_gap 满足 P[δ_gap ≤ δ̂_gap] ≥ 1−α_gap，由真实锚点 + Bootstrap/保序回归给出。gap_cert=(M, δ̂_gap, N_real, α_gap)。
- **定义 222（可迁移风险界）**：对 L-Lipschitz 指标，ρ_real(M) ≤ ρ_sim(M) + L·δ̂_gap。若 δ̂_gap=∞（无真实锚点/校准失败），迁移界为空，证书不得进入 Valid-A。
- **定义 223（假设债务图 ADL）**：ADL=(V,E,ev,crit)，V={A77…A87 及新增}，E 为依赖边，ev:V→{witnessed,falsified,unproven}×coverage，crit:V→ℝ⁺。路径债务 Γ(path)=Σ_{v∈path} crit(v)·1[ev(v)≠witnessed]；系统债务 Γ=max_{关键路径} Γ(path)（最弱环节）。证书要求关键路径全 witnessed 且 Γ ≤ δ_Γ。
- **定义 224（债务化证书有效性）**：Valid_debt(J) ⇔ 所有 critical 声明所在关键路径假设 ev=witnessed ∧ 无 falsified ∧ Γ≤δ_Γ ∧ Cov≥δ_cov。
- **定义 225（对抗证伪搜索 AFS）**：max_{β∈D_bench} Σ_C 1[Pred_C(run(β))=0] + λ·novelty，s.t. β 物理可实现。覆盖引导变异，输出见证集 W 与覆盖热图。
- **定义 226（覆盖引导场景变异）**：变异算子含几何/拓扑、透明/镜面/吸光（承接第 63 轮幻觉）、摩擦锥、接触刚度/阻尼、传感器偏置/饱和/延迟、质量/惯量、接触丢失；用物理可实现过滤器剔除非法参数。
- **定义 227（多保真证据融合 MFE）**：控制变量 μ̂ = μ̂_real + λ(μ̂_sim − E_sim)，λ* = ρ·σ_real/σ_sim，Var=(1−ρ²)σ_real²/N_real；偏差项 λ·bias_sim 需 ≤ δ_gap 并计入保守界。
- **定义 228（基准过拟合与 Goodhart 检测）**：meta split：D_bench（公开/训练）与 D_holdout（隐藏）；overfit gap=|R_bench−R_holdout|；当 gap>τ_goodhart 或 W₁(D_holdout,D_real)>δ_gap 时告警。证书只能基于 holdout + real。
- **定义 229（确定性回放协议 DRP）**：h=H(canonical(SDF, engine+version, params, seed, trace, noise_seed))；位精确或容差回放；任何 mismatch ⇒ 证据作废，跨版本漂移需重签。
- **定义 230（oracle 独立性与真实锚点）**：仿真 oracle 不得与被评系统共享同一接触/传感器模型代码或同一组未验证参数；真实锚点集 𝒜_real（N_real 个代表任务）用于 gap 校准与最终抽查，否则构成"自证"。
- **定义 231（J_forge 证书与分级）**：J_forge=(J_grip, Cov, δ̂_gap, Γ, replay_hash, meta_split_score, oracle_indep_ver, falsification_log_hash)。分级：**Valid-A**（关键假设全 witnessed + 真实 gap 有界 + holdout 无反例 + 回放一致）；**Valid-B**（仅信任域内仿真证据 + gap 有界，限域部署）；**Degraded**（出信任域或债务超阈，仅保守模式）；**Invalid**（有反例或回放/独立性失败）。
- **定义 232（FORGE 闭环算子）**：离线 [GDT→S2R-Cert→CFB 义务→AFS 搜索→MFE 融合→ADL 结算→分级→DRP 存证]；部署时仅读取分级与信任域开关，**实时路径与 A87 完全不变**。

## 2. 关键算法骨架

```python
# GDT + S2R-Cert：孪生校准与可迁移风险界
twin = GazeboDigitalTwin(world, physics_params, sensor_models)
gap_cert = twin.calibrate(real_anchor_set, metrics, alpha_gap)   # δ̂_gap per metric
trust = twin.trust_region(gap_cert, delta=DELTA_T)
rho_real_bound = rho_sim + L * gap_cert.delta_hat                # 定理 7

# CFB + AFS：把证书声明变成义务，并主动找反例
obligations = CFB.obligations(J_grip)                            # 每条声明 -> Pred_C
witnesses = AFS.search(twin, obligations, budget, coverage_guided=True)
if witnesses: return "Invalid", witnesses

# MFE：少量真机 + 大量仿真，无偏且方差缩减
mu_hat, var = multifidelity_risk(real_runs, sim_runs, rho_hat)   # λ* = ρ σ_r/σ_s

# ADL：假设债务结算（最弱环节）
debt, critical_path = ADL.settle(evidence, crit)                 # Γ = max path debt
if debt > DELTA_DEBT or not ADL.all_witnessed(critical_path):
    return "Degraded", debt

# Goodhart 检测 + 回放存证 + 分级签发
score = meta_split.evaluate(system, D_holdout, D_real)
replay_hash = DRP.hash(config, seed, trace)
grade = "Valid-A" if gap_cert.bounded and score.gap <= TAU_GOODHART else "Valid-B"
return grade, build_j_forge(J_grip, Cov, gap_cert, debt, replay_hash, score)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（多保真方差缩减）**：控制变量估计 μ̂ 的方差为 (1−ρ²)σ_real²/N_real；达到同一置信区间所需真实样本降为 (1−ρ²) 倍（ρ=0.9 时 −81%）。但若仿真均值有偏，偏差 λ·bias_sim 必须由 δ_gap 保守吸收。
- **引理 8（证伪覆盖的必要性）**：要在置信 1−δ 下认证违规概率 ≤ ε，独立采样需 N ≳ (1/ε)ln(1/δ)；若基准分布与部署分布的密度比无界（覆盖不足），所需样本发散。**证书的强度上限由覆盖决定，而非由定理的漂亮程度决定。**
- **定理 7（Lipschitz 风险迁移）**：若 M 对场景 L-Lipschitz 且 W₁(D_sim,D_real)≤δ_gap，则 |E_sim M−E_real M|≤Lδ_gap，故 ρ_real≤ρ_sim+Lδ_gap；δ_gap 无界则迁移失败——**仿真永远不能单独完成认证**。
- **定理 8（最弱环节 / 风险转嫁）**：把每条假设看作一个有效性集合 V_i，则加一层 = 与新集合求交：V_new=∩_{i}V_i ⊆ V_old。未验证的新假设使交集收缩甚至为空 ⇒ 认证覆盖不升反降。**局部鲁棒性↑不蕴含全局认证↑；唯一能提升认证的是把 unproven 变成 witnessed，而不是再叠一层机制。**
- **命题（认证预算的边际递减）**：覆盖最大化是次模问题，贪心达 (1−1/e) 近似；应按"信息增益/成本"优先清算低置信、高 criticality 的假设。
- **实时性**：FORGE 全在离线/低频完成；部署仅读取 J_forge 分级与信任域开关，实时路径 ≤2ms 契约与零学习写操作（A87）保持不变。

| `ADL = (V,E,ev,crit)` | 假设债务图；`Γ` 为系统债务（关键路径最弱环节） |
| `Γ(path)=Σ crit(v)·1[ev(v)≠witnessed]` | 路径债务 |
| `W`，`falsification_log_hash` | AFS 找到的反例见证集与其审计哈希 |
| `μ̂ = μ̂_real + λ(μ̂_sim−E_sim)`，`λ*=ρσ_real/σ_sim` | 多保真控制变量估计 |
| `Var = (1−ρ²)σ_real²/N_real` | 融合后方差（引理 7） |
| `overfit_gap = |R_bench−R_holdout|` | Goodhart / 基准过拟合指标 |
| `h = H(SDF, engine, params, seed, trace, noise_seed)` | 确定性回放哈希 |
| `𝒜_real`，`N_real` | 真实锚点集与样本量 |
| `J_forge = (J_grip, Cov, δ̂_gap, Γ, replay_hash, meta_split_score, oracle_indep_ver, falsification_log_hash)` | 分级认证证书 |
| 等级 | `Valid-A > Valid-B > Degraded > Invalid`（见定义 231） |

## 2. 形式化定义（完整版）

**定义 217（基准实例与任务族）** 基准实例 β = (𝒲, τ, η, ℳ, s)：𝒲 为 Gazebo SDF 世界与物理参数（引擎 ODE/Bullet/DART、步长、接触模型、摩擦、刚度、阻尼）；τ 为任务规格（抓取/搬运/插入/人机共融接触等）；η 为干扰编排，显式包含第 63 轮视觉幻觉（透明/镜面/吸光）、第 64 轮力觉干扰 ℰ_F（偏置/饱和/噪声/接触丢失）与物理扰动；ℳ 为指标族（成功率、ρ_rob、ρ_dir、ρ_slip、ρ_force、实时抖动、sim-to-real gap）；s 为随机种子。任务族 D_bench = {β}，并区分 D_bench / D_holdout / D_real。

**定义 218（证书证伪义务）** 给定 J_grip 中一条可判定声明 C（如 `ρ_force ≥ 0`、`ρ_slip ≥ 0`、`geo_degraded ⇒ r ≥ δ_hall/σ_J`、`Valid(J_liro)`），其证伪义务为 O_C = (C, 𝔒_C, Pred_C)，其中 𝔒_C 为判定 oracle（可为仿真 ground truth、真实传感器真值或独立模型），Pred_C: trace → {0,1}。一次运行 r 若 Pred_C(r)=0，则称 r 是 C 的**反例见证** w。义务集 𝒪(J_grip) 必须覆盖 J_grip 的每一条安全声明，未覆盖的声明自动标记为 unproven。

**定义 219（证据状态与覆盖）** 对每条声明 C，证据状态
e_C ∈ {vacuous（空洞）, witnessed（有支持证据）, falsified（被推翻）, unproven（未测）}。
覆盖度 cov(C) = μ({β ∈ D_bench : β 触发 C 的判定路径}) / μ(D_bench)，μ 为任务族测度。若 cov(C) < δ_cov，则 e_C = vacuous（即使跑过很多次，只要没触及该声明的判定区域，证据无效）。整体覆盖向量 Cov = (cov(C_1), …, cov(C_k))。**证书强度以覆盖向量而非运行次数计。**

**定义 220（Gazebo 数字孪生与信任域）** 数字孪生 T = (engine, contact_model, sensor_models, θ_phys)，其中 contact_model 明确记录其刚性/惩罚接触假设，sensor_models 记录 F/T、触觉、LiDAR、相机的噪声与延迟模型。信任域
𝒯_δ = {β : gap_M(β) ≤ δ, ∀M ∈ ℳ}，
gap_M(β) 由真实锚点在 β 邻域内估计。**规则：β ∉ 𝒯_δ 时，仿真结果不得进入 J_forge 作为证据，只能作为"待验证猜想"写入 `conjecture_log`。** 这条规则是对"仿真即真值"幻觉的硬性阻断。

**定义 221（sim-to-real gap 认证）** 对指标 M，gap 真值
δ_gap(M) = sup_{β∈D_bench} |M_sim(β) − M_real(β)|（或分布距离 W₁(D_sim^M, D_real^M)）。
认证上界 δ̂_gap 满足 P[δ_gap(M) ≤ δ̂_gap] ≥ 1 − α_gap，由真实锚点 𝒜_real 上的配对差 + Bootstrap/保序回归给出。gap_cert = (M, δ̂_gap, N_real, α_gap)。**N_real 不足或锚点不具代表性时，δ̂_gap 取 +∞（保守拒绝），而非取一个乐观小数。**

**定义 222（可迁移风险界）** 设 M 对场景 β 在度量 d 下 L-Lipschitz，且 W₁(D_sim, D_real) ≤ δ_gap。则
|E_sim[M] − E_real[M]| ≤ L·δ_gap，
故若仿真在 𝒯_δ 内认证 ρ_sim（分位数/CVaR 界），则
ρ_real ≤ ρ_sim + L·δ̂_gap。
若 δ̂_gap = +∞，迁移界为空，证书不得进入 Valid-A（只能 Valid-B 限域，或 Degraded）。**这是"仿真永远不能单独完成认证"的形式化。**

**定义 223（假设债务图 ADL）** 假设债务图 ADL = (V, E, ev, crit)：V = {A77, …, A87} ∪ 新增假设；E 为依赖边（如 A84 依赖 A83 的传感器有效性）；ev: V → {witnessed, falsified, unproven} × coverage；crit: V → ℝ⁺ 为失效后果权重（可由 ρ 的敏感度 ∂ρ/∂A_i 估计）。路径债务
Γ(path) = Σ_{v∈path} crit(v)·1[ev(v) ≠ witnessed]，
系统债务 Γ = max_{关键路径} Γ(path)（最弱环节，而非平均值）。**证书强度由关键路径最弱环节决定。**

**定义 224（债务化证书有效性）** Valid_debt(J) ⇔ 所有 critical 声明所在关键路径上的假设 ev = witnessed ∧ 不存在 falsified 假设 ∧ Γ ≤ δ_Γ ∧ Cov ≥ δ_cov。任何一条不满足，证书降级。

**定义 225（对抗证伪搜索 AFS）** 在基准任务族上求解
max_{β∈D_bench} Σ_{C∈𝒪} 1[Pred_C(run(β)) = 0] + λ·novelty(β)，
s.t. β 物理可实现（参数在物理可行域内，排除"非物理参数制造的假反例"）。
搜索采用覆盖引导的进化/MAP-Elites：维护场景-覆盖档案，优先变异能进入未覆盖声明区域的方向。输出反例见证集 W 与覆盖热图，写入 `falsification_log`。

**定义 226（覆盖引导场景变异）** 变异算子集合：
- 几何/拓扑：新增/删除/形变物体、遮挡关系；
- 外观欺骗：透明、镜面、吸光、低纹理（承接第 63 轮 E_geo 幻觉）；
- 接触物理：摩擦锥 μ、接触刚度 k、阻尼 c、软接触/粘-滑；
- 传感器：F/T 偏置 b（‖b‖∞ ≤ ε_b）、饱和、触觉噪声、接触丢失、延迟；
- 动力学：质量/惯量、负载、关节间隙；
- 任务/干扰时序：干扰注入时刻、持续时长、组合。
物理可实现过滤器：任何变异必须能映射回真实可制造/可发生的场景，否则丢弃。

**定义 227（多保真证据融合 MFE）** 设真机估计 μ̂_real（N_real 个 iid，方差 σ_real²）、仿真估计 μ̂_sim（N_sim 个，方差 σ_sim²），二者相关系数 ρ。控制变量估计
μ̂ = μ̂_real + λ(μ̂_sim − E_sim)，λ* = ρ·σ_real/σ_sim，
Var(μ̂) = (1−ρ²)σ_real²/N_real（N_sim ≫ N_real 时）。若仿真均值有偏 bias_sim，则偏差 λ·bias_sim 必须 ≤ δ_gap 并计入保守界。**这使少量真实锚点即可获得紧置信区间。**

**定义 228（基准过拟合与 Goodhart 检测）** meta split：D_bench（公开/训练）与 D_holdout（隐藏、与 D_real 同源）。定义 overfit_gap = |R_bench − R_holdout|。当 overfit_gap > τ_goodhart 或 W₁(D_holdout, D_real) > δ_gap 时触发 **Goodhart 警报**：证书只能基于 D_holdout + D_real 签发，D_bench 成绩不得作为认证依据。**防止把证书刷成基准特供。**

**定义 229（确定性回放协议 DRP）** 回放哈希
h = H(canonical(SDF, engine+version, physics_params, seed, trace, sensor_noise_seed))。
证据必须能在相同配置下位精确（或给定容差内）复现；任何 replay mismatch ⇒ 该证据作废（evidence invalid）。跨 Gazebo/引擎版本升级导致的行为漂移必须重签，不得沿用旧证书。

**定义 230（oracle 独立性与真实锚点 OHR）** oracle 独立性：仿真 oracle 不得与被评系统共享同一接触/传感器模型代码，或同一组未经验证的参数；否则构成"自证"（self-certification）。真实锚点集 𝒜_real（N_real 个代表任务，覆盖主要材质/几何/接触模式）用于 (i) 校准 δ̂_gap，(ii) 对 Valid-A 做最终抽查。**oracle 与被评系统必须至少有一条独立的物理/软件证据链。**

**定义 231（J_forge 证书与分级）** J_forge = (J_grip, Cov, δ̂_gap, Γ, replay_hash, meta_split_score, oracle_indep_ver, falsification_log_hash)。
- **Valid-A（全证据）**：关键路径假设全 witnessed，真实锚点 gap 有界，D_holdout 无反例，回放一致，oracle 独立。
- **Valid-B（限域）**：仅在信任域 𝒯_δ 内由仿真证据支持，gap 有界但 N_real 较小；允许部署，但运行时必须检查 β∈𝒯_δ，域外自动降级。
- **Degraded（保守）**：出信任域或 Γ>δ_Γ；只允许 safe_idle / compliant retreat（承接 GRIP 的降级语义）。
- **Invalid**：存在反例见证，或回放/独立性失败；禁止部署。
审计链：Cov 追溯覆盖，falsification_log_hash 追溯反例搜索，Γ 追溯假设债务，replay_hash 追溯可复现性，meta_split_score 追溯 Goodhart。

**定义 232（FORGE 闭环算子）** 见 IP-223 伪代码。**离线/低频**：[GDT 建孪生 → S2R-Cert 标定 gap → CFB 生成义务 → AFS 覆盖引导搜索反例 → MFE 融合 sim/real → ADL 结算债务 → BCG/Goodhart 检查 → 分级（Invalid/Degraded/Valid-B/Valid-A）→ DRP 存证]。**部署时**：仅读取 J_forge 分级与信任域开关；实时路径仍为 GRIP 的 ≤2ms 契约（A87），零学习写操作，FORGE 不进入控制回路。

```python
class CertificateFalsificationBenchmark:
    """把 J_grip 的每条声明变成证伪义务；基准只负责'尝试推翻'。"""
    def __init__(self, task_family, oracle, coverage_measure):
        self.D = task_family
        self.oracle = oracle
        self.cov = coverage_measure

    def obligations(self, J_grip):
        obs = []
        obs.append(Claim('rho_force>=0',
                         lambda tr: tr.rho_force >= 0,
                         self.oracle.force_gt))
        obs.append(Claim('rho_slip>=0',
                         lambda tr: tr.rho_slip >= 0,
                         self.oracle.slip_gt))
        obs.append(Claim('geo_degraded_implies_inflated',
                         lambda tr: (not tr.geo_degraded) or
                                    tr.r >= tr.delta_hall / tr.sigma_J,
                         self.oracle.geometry_gt))
        obs.append(Claim('realtime<=2ms',
                         lambda tr: tr.rt_latency <= 2e-3,
                         self.oracle.timing))
        obs.append(Claim('liro_valid',
                         lambda tr: tr.J_liro_valid,
                         self.oracle.cert_gt))
        return obs

    def run(self, system, budget):
        evidence = {o.name: Evidence(vacuous=True) for o in self.obligations(system.J)}
        for beta in schedule(self.D, budget):
            tr = gz.run(system, beta)                    # Gazebo 回放
            for o in self.obligations(system.J):
                if not self.cov.reaches(o, beta):
                    continue
                evidence[o.name].mark_tested(beta)
                if not o.pred(tr):
                    evidence[o.name].falsify(witness=tr)
        for o in evidence.values():
            o.finalize(delta_cov=DELTA_COV)              # 覆盖不足 -> vacuous
        return evidence
```

### IP-215/216 GDT + S2R-Cert（孪生信任域与可迁移界）

```python
class GazeboDigitalTwin:
    def __init__(self, world_sdf, engine='dart', step=1e-3,
                 contact_model='rigid_penalty', sensor_models=None):
        self.world = load_sdf(world_sdf)
        self.engine, self.step = engine, step
        self.contact_model = contact_model
        self.sensors = sensor_models or default_sensor_models()
        self.trust = None

    def calibrate(self, real_anchor, metrics, alpha_gap=0.05, n_boot=2000):
        """真实锚点上配对 sim/real，Bootstrap 出每个指标的 δ̂_gap。"""
        gap_cert = {}
        for M in metrics:
            diffs = [abs(self.simulate(beta)[M] - real_anchor[beta][M])
                     for beta in real_anchor]
            boot = bootstrap_max(diffs, n_boot=n_boot, alpha=alpha_gap)
            gap_cert[M] = GapCert(delta_hat=boot.upper, N_real=len(real_anchor),
                                  alpha=alpha_gap)
        return gap_cert

    def trust_region(self, gap_cert, delta):
        self.trust = {beta for beta in self.world.tasks
                      if all(g.delta_hat <= delta for g in gap_cert.values())}
        return self.trust

    def transfer_bound(self, rho_sim, L, gap_cert):
        if not np.isfinite(gap_cert.delta_hat):
            return np.inf                                  # 不可迁移
        return rho_sim + L * gap_cert.delta_hat            # 定理 7
```

### IP-217 ADL（假设债务账本）

```python
class AssumptionDebtLedger:
    def __init__(self):
        self.nodes = {}   # name -> (status, coverage, criticality)
        self.edges = {}   # name -> [deps]

    def add(self, name, deps=(), criticality=1.0):
        self.nodes[name] = {'status': 'unproven', 'cov': 0.0,
                            'crit': criticality}
        self.edges[name] = list(deps)

    def witness(self, name, coverage):
        self.nodes[name]['status'] = 'witnessed'
        self.nodes[name]['cov'] = coverage

    def falsify(self, name):
        self.nodes[name]['status'] = 'falsified'

    def critical_path_debt(self, target):
        """最弱环节：目标声明依赖闭包中，最差路径的未验证债务。"""
        best = 0.0
        for path in all_dependency_paths(self.edges, target):
            debt = sum(self.nodes[v]['crit']
                       for v in path
                       if self.nodes[v]['status'] != 'witnessed')
            best = max(best, debt)
        return best

    def settle(self, targets):
        if any(n['status'] == 'falsified' for n in self.nodes.values()):
            return np.inf, None
        debts = {t: self.critical_path_debt(t) for t in targets}
        return max(debts.values()), max(debts, key=debts.get)
```

### IP-218 AFS（覆盖引导对抗证伪搜索）

```python
class AdversarialFalsificationSearch:
    def __init__(self, twin, mutators, physics_filter, archive_size=256):
        self.twin, self.mutators = twin, mutators
        self.physics_filter, self.archive = physics_filter, {}
        self.archive_size = archive_size

    def mutate(self, beta):
        child = deepcopy(beta)
        for op in sample(self.mutators, k=1 + poisson(2)):
            child = op(child)                    # 几何/摩擦/接触/传感/动力学
        return child if self.physics_filter(child) else None

    def novelty(self, beta):
        cell = coverage_cell(self.twin, beta)
        return 0.0 if cell in self.archive else 1.0

    def search(self, obligations, budget, lam=0.5):
        frontier = [self.twin.random_instance() for _ in range(64)]
        witnesses = []
        for _ in range(budget):
            beta = choice(frontier)
            child = self.mutate(beta)
            if child is None:
                continue
            tr = self.twin.run(child)
            violated = [o for o in obligations if not o.pred(tr)]
            score = len(violated) + lam * self.novelty(child)
            if violated:
                witnesses.append((child, violated, tr))
            self._archive(child, score)
            frontier = self._select(frontier + [child])
        return witnesses

    def _archive(self, beta, score):
        cell = coverage_cell(self.twin, beta)
        if cell not in self.archive or score > self.archive[cell][1]:
            self.archive[cell] = (beta, score)
```

### IP-219 MFE（多保真证据融合）

```python
def multifidelity_risk(real_runs, sim_runs, E_sim, eps=1e-9):
    """real_runs, sim_runs: 1-D arrays of metric values (paired scenario ids)."""
    mu_r, mu_s = np.mean(real_runs), np.mean(sim_runs)
    s_r, s_s = np.std(real_runs, ddof=1), np.std(sim_runs, ddof=1)
    rho = np.corrcoef(real_runs, sim_runs)[0, 1]
    lam = rho * s_r / (s_s + eps)
    mu_hat = mu_r + lam * (mu_s - E_sim)
    var_hat = (1 - rho ** 2) * s_r ** 2 / len(real_runs)
    bias_bound = abs(lam) * abs(E_sim - mu_s)       # 计入 δ_gap 保守界
    return mu_hat, np.sqrt(var_hat), bias_bound, rho
```

### IP-220/221 BCG + DRP（覆盖治理、Goodhart 与回放）

```python
class BenchmarkCoverageGovernor:
    def __init__(self, delta_cov=0.2, tau_goodhart=0.05, delta_gap=0.1):
        self.delta_cov, self.tau_goodhart, self.delta_gap = \
            delta_cov, tau_goodhart, delta_gap

    def grade_evidence(self, evidence, holdout):
        if any(e.status == 'falsified' for e in evidence.values()):
            return 'Invalid'
        if any(e.cov < self.delta_cov for e in evidence.values()):
            return 'Degraded'                     # 空洞证书 -> 不得 Valid
        gap = abs(holdout.R_bench - holdout.R_holdout)
        if gap > self.tau_goodhart:
            return 'Degraded'                     # Goodhart 警报
        return None                               # 交由 S2R-Cert 分级

def replay_hash(config, seed, trace):
    canon = canonical_json({
        'sdf': config.sdf_hash,
        'engine': config.engine + '@' + config.engine_version,
        'physics': config.physics_params,
        'seed': seed,
        'noise_seed': config.noise_seed,
        'trace': trace.to_canonical(),
    })
    return sha256(canon)

def verify_replay(config, seed, trace, expected_hash, tol=1e-9):
    if replay_hash(config, seed, trace) != expected_hash:
        return False                              # 证据作废
    return np.max(np.abs(trace.canonical_array -
                         replay(config, seed).canonical_array)) <= tol
```

### IP-223 FORGE 闭环算子（整合）

```python
def FORGE_certify(system, J_grip, task_family, real_anchor,
                  budget=10_000, delta_T=0.1, delta_debt=0.5):
    # 0) 离线准备：孪生与真实锚点
    twin = GazeboDigitalTwin(task_family.world_sdf,
                             engine=task_family.engine,
                             contact_model=task_family.contact_model)
    gap_cert = twin.calibrate(real_anchor, metrics=task_family.metrics)
    trust = twin.trust_region(gap_cert, delta=delta_T)

    # 1) CFB：把证书声明变成义务
    cfb = CertificateFalsificationBenchmark(task_family, oracle=twin.oracle,
                                            coverage_measure=twin.coverage)
    obligations = cfb.obligations(J_grip)

    # 2) AFS：在信任域内覆盖引导地找反例
    afs = AdversarialFalsificationSearch(twin, task_family.mutators,
                                         physics_filter=task_family.physics_ok)
    witnesses = afs.search(obligations, budget=budget)
    if witnesses:
        return build_j_forge(J_grip, grade='Invalid',
                             falsification_log_hash=hash(witnesses))

    # 3) CFB 证据 + 覆盖判定
    evidence = cfb.run(system, budget=budget)
    grade = BenchmarkCoverageGovernor().grade_evidence(evidence,
                                                       task_family.holdout)
    if grade is not None:
        return build_j_forge(J_grip, grade=grade, evidence=evidence)

    # 4) MFE：少量真机 + 大量仿真，无偏风险与紧 CI
    real = [run_on_real(system, beta) for beta in real_anchor]
    sim = [twin.run(beta) for beta in real_anchor]      # 配对场景
    mu, sd, bias, rho = multifidelity_risk(real, sim, E_sim=twin.E_sim)
    if bias > delta_T:
        return build_j_forge(J_grip, grade='Degraded', bias=bias)

    # 5) ADL：结算假设债务（最弱环节）
    adl = AssumptionDebtLedger()
    seed_assumptions(adl, evidence, gap_cert, real_anchor)   # A77..A87
    debt, worst = adl.settle(targets=J_grip.critical_claims)
    if debt > delta_debt:
        return build_j_forge(J_grip, grade='Degraded', debt=debt, worst=worst)

    # 6) S2R-Cert：迁移界
    rho_sim = J_grip.rho_rob
    rho_real_bound = twin.transfer_bound(rho_sim, L=task_family.L,
                                         gap_cert=gap_cert['rho'])
    grade = 'Valid-A' if np.isfinite(rho_real_bound) else 'Valid-B'

    # 7) DRP：回放存证
    h = replay_hash(task_family.config, task_family.seed, evidence.trace)

    return build_j_forge(J_grip, Cov=evidence.Cov, gap_cert=gap_cert,
                         debt=debt, replay_hash=h, grade=grade,
                         meta_split_score=task_family.holdout.score,
                         oracle_indep_ver=twin.oracle_independence_ok,
                         falsification_log_hash=hash([]))
```

## 4. 推导

**引理 7（多保真证据的方差缩减）** 设真机样本 R_i iid，均值 μ、方差 σ_R²；仿真样本 S_j iid，均值 μ_S、方差 σ_S²；Cov(R,S)=ρσ_Rσ_S。控制变量估计
μ̂ = R̄ + λ(S̄ − μ_S)，
其方差
Var(μ̂) = σ_R²/N_r + λ²σ_S²/N_s − 2λρσ_Rσ_S/√(N_rN_s)。
当 N_s ≫ N_r，取 λ* = ρσ_R/σ_S 得 Var(μ̂) = (1−ρ²)σ_R²/N_r。达到目标方差 V 所需真机样本
N_r ≥ (1−ρ²)σ_R²/V，
相比只用真机的 σ_R²/V，真实成本降低为 (1−ρ²) 倍；ρ=0.9 时降低 81%。若仿真均值有偏 bias_sim，估计偏差为 λ·bias_sim，必须用 δ_gap 保守吸收（否则方差缩减是"用偏差换精度"）。∎

**引理 8（证伪覆盖的必要性）** 设部署分布 D 下违规概率为 p。用 iid 样本认证 p ≤ ε（置信 1−δ），由 Clopper-Pearson/经验 Bernstein，所需样本
N ≥ ln(1/δ)/(−ln(1−ε)) ≈ (1/ε)ln(1/δ)。
若基准分布 q 与 D 的密度比 r=dD/dq 在违规区域很大（基准很少触及违规区），重要性采样估计方差 ∝ E_q[r²·1[V]]，有效样本量按 r_max² 衰减；当违规区域覆盖 cov(C)→0，所需样本发散。故**证书的可信度上限由覆盖决定，而非由运行次数或定理漂亮程度决定**；这正是 CFB 引入 cov(C) 与 vacuous 状态的依据。∎

**定理 7（Lipschitz 风险迁移）** 设指标 M(β) 对场景 β 在度量 d 下 L-Lipschitz，即 |M(β)−M(β')| ≤ L·d(β,β')，且场景分布满足 W₁(D_sim,D_real) ≤ δ_gap。由 Kantorovich-Rubinstein 对偶，
|E_sim[M] − E_real[M]| ≤ L·W₁(D_sim,D_real) ≤ L·δ_gap。
因此若仿真在信任域内给出风险界 ρ_sim，则真机风险
ρ_real ≤ ρ_sim + L·δ_gap。
对 CVaR 等尾部指标，结论形式不变，L 需换成相应尾部 Lipschitz 常数（如 L/(1−α)）。当 δ_gap 未认证（=∞）时迁移界为空，仿真证据不得单独支撑 Valid-A。∎

**定理 8（最弱环节 / 风险转嫁）** 将第 i 条假设的有效性建模为集合 V_i（该假设成立的场景集）。一份证书的认证覆盖为
V_cert = ∩_{i∈Crit} V_i，
证书保证 G 在 V_cert 上成立且随 V_cert 单调不增。加入第 64 轮式的新机制即引入新假设 V_{k+1}：
V_new = V_old ∩ V_{k+1} ⊆ V_old。
故**新增一层只会收缩（或保持不变）认证覆盖**；若 V_{k+1} 未被验证（可能为空/极大不确定），交集可能为空，证书退化为空洞。于是"局部鲁棒性提升"（在某子场景上 ρ 更紧）与"全局认证提升"（V_cert 更大、G 更强）是两回事：前者是机制层，后者只能靠把 unproven 变成 witnessed 获得。**推论：第 63→64 轮式的"每轮加一层"若不同时清算新假设，认证强度不升反降。**∎

**命题（认证预算的边际递减与贪心）** 设每次基准测试覆盖一组声明（集合覆盖），目标是最大化被 witnessed 的关键声明覆盖。该覆盖函数次模，预算约束下的最大覆盖用贪心可达 (1−1/e) 近似；边际信息增益随已覆盖声明增多而递减。因此 ADL 应按"信息增益/成本"排序，优先清算低置信、高 criticality 的假设，而不是均匀跑量。∎

**命题（基准过拟合的泛化界）** 设策略/证书从假设类 ℋ 中按 D_bench 经验风险选出，|ℋ| 有限，样本数 N。则 D_holdout 上风险与 D_bench 经验风险的差以 O(√(log|ℋ|/N)) 概率有界；若 D_holdout 与 D_real 仍有 W₁ 距离 δ'，再叠加 Lδ'。故当 overfit_gap 超过 τ_goodhart 或 δ' 过大时，必须判定为基准特供（Goodhart），证书只能基于 D_holdout+D_real 重签。∎

|---|---|---|---|

| CFB 基准运行 | 离线，O(budget)·单次仿真 | O(|𝒪|·budget) | 反例见证可追溯，覆盖向量可审计 |

| MFE 融合 | O(N_real) | O(N_real) | 引理 7：Var=(1−ρ²)σ_R²/N_r |

**正确性定理（FORGE-Sound）** 综合定理 7、定理 8 与引理 7/8：若 (i) 证书每条声明都有证伪义务且覆盖 cov ≥ δ_cov；(ii) 关键路径假设全 witnessed 且无 falsified；(iii) δ̂_gap 有限且 MFE 偏差 ≤ δ_T；(iv) 回放与 oracle 独立性通过；则 Valid-A 蕴含"真机风险 ≤ ρ_sim + Lδ̂_gap 且未被任何基准反例推翻"。若任一条件失败，证书被降级而非"带病通过"——**这是把"过度自信"结构性地转化为"显式降级"**。

## 7. 已知风险

**一句话**：基准与数字孪生本身会成为新的单点故障——若 Gazebo 的接触物理、传感器噪声模型与任务分布系统性偏离真实，FORGE 会把"在基准上安全"误当成"在现实中安全"（Goodhart / 基准过拟合），而 δ̂_gap 又依赖真实锚点自证；证伪机制可能退化为舒适毯，**"我们测过了"取代"我们证明了"，认证从数学上的过度自信变成工程上的过度自信**。

**次级风险与缓解**：
1. **Gazebo 接触模型保真度不足**：ODE/Bullet/DART 的刚性/惩罚接触难以复现微滑移、软接触、粘-滑，恰是 SLD/FPE 的核心场景。缓解：GDT 显式记录接触模型假设；𝒯_δ 在这些场景上自动收缩；关键声明（ρ_slip、μ̂）必须由真实锚点见证，不能只靠仿真。
2. **真实锚点昂贵/危险/不可代表**：N_real 小、分布偏移会让 δ̂_gap 乐观。缓解：锚点按材质/几何/接触模式分层抽样；δ̂_gap 用 Bootstrap 上界而非点估计；N_real 不足时直接取 +∞（拒绝 Valid-A）。
3. **oracle 自证 / 循环论证**：仿真 oracle 与被评系统共享模型代码或参数，等于自己批改自己的卷子。缓解：OHR 强制独立证据链；oracle 参数来自独立标定；人工抽查 holdout。
4. **基准过拟合 / Goodhart**：反复在同一基准上调参，证书变成基准特供。缓解：隐藏 D_holdout、定期换题、meta-split 报警、证书只认 holdout+real。
5. **覆盖度量可被游戏**：cov(C) 的定义若可被低质量样本刷高，空洞证书仍可能混过。缓解：覆盖按"判定路径触发"而非"运行次数"计；覆盖热图人工审计；引入反例密度作为辅助指标。
6. **确定性回放的脆弱性**：多线程物理、浮点非确定性、驱动/版本差异会破坏位精确复现。缓解：固定单线程/固定步长/固定种子；容差回放 + 版本重签；对不可复现证据直接作废。
7. **债务度量的主观性**：crit 权重与 δ_Γ 的选取会影响分级。缓解：用 ∂ρ/∂A_i 的敏感度自动估 crit；报告债务的敏感性分析；不把 Γ 当唯一裁决，保留人工复核。
8. **安全剧场（safety theater）**：跑完一套漂亮基准不等于真安全，可能只证明了"在已知干扰下安全"。缓解：AFS 持续寻找未知反例；把"未发现反例"表述为"在覆盖 X、置信 Y 下未被推翻"，而非"已证明安全"。
9. **认证成本与实时性**：FORGE 离线成本高。缓解：离线/低频执行；J_forge 部署时 O(1) 读取；实时路径与 A87 完全隔离。
