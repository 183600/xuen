## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（视觉编码器 → 这场考试的五个泛化轴，本质都是「眼睛」的分布偏移）**
直觉：32 任务的计分轴里，外观、背景、位置、干扰物、未见物品——没有一条能绕开视觉编码器。但官方默认配方把 VLM 整段冻死，只训动作头（F21）：动作头是在**原 VLM 特征流形**上学会「看到什么→怎么动」的，视觉编码器却从未被评测分布校准过。大多数队伍会在两个极端之间选：要么全冻（表征与赛场光照/相机/物体不匹配），要么整段 LoRA（容量与遗忘风险都大）。中间的正确做法是**外科手术**：先用探针问清楚「哪一层编码了哪个轴」，再只动该动的层。更关键的是，视觉 token 是 DiT 的 cross-attention key（F22）——**改视觉表征不是旁路优化，而是直接改写动作头的条件分布**；所以任何改动都必须恒等初始化、可回退、漂移可测。核心反直觉点：**在外观轴上，继续堆增广数据的边际收益会被冻结视觉编码器的风格主导特征截断；先修表征，再喂数据，数据才兑现。**

**灵感 2（开源生态 → 视觉编码器是唯一可以「跨本体白嫖」的模块）**
直觉：动作数据必须同本体、同任务、带标注；但**视觉表征不需要动作标签**。开源生态里有海量机器人/第一人称视频、DiverseManip、仿真帧，以及 DINOv2/3、SAM2、Depth Anything、GroundingDINO 等强教师——这些都能在**离线**把无标签像素变成监督（深度、分割、对应、可供性），再蒸馏进官方单模型的视觉适配器。竞赛的「单模型」边界与 66ms 预算决定了：这些模型**不能**出现在推理链上（PR7），但可以出现在训练链上。核心反直觉点：**开源生态的正确用法不是「推理时加模块」，而是「离线教师、单模型学生」——把生态的算力换成视觉编码器的鲁棒性，而不是换成推理时的依赖。**

**两者统一**：视觉编码器回答「数据以什么形式被看见」，开源生态回答「上哪找不用动作标签的监督」。第 2 轮说中期胜负手在数据引擎；本轮修正为**乘性关系**：数据引擎决定上限，视觉表征决定数据能否被兑现。落地为 I10（探针定层的分轴视觉适配）与 I11（跨本体无标签视觉预训练 + 开源教师离线蒸馏）；I6 增加视觉 token/中间层预算子项；I3/I9 改用适配后的表征与教师几何。

## 2. 对第 2 轮的增量修订

- P2（泛化缺口）再细化：从「训练分布没覆盖考纲」进一步定位到「视觉表征对考纲轴不敏感/风格主导」——I1 是数据侧解，I10/I11 是表征侧解，二者乘性。
- P3（人手干扰）补充：手腕相机是判断「手是否进入视野/是否被干预」的最直接通道（F26），I4 的输入应优先手腕视角而非全局视角。
- P4（无触觉）补充：训练语料含 stereo（F25），可离线生成深度作接触段辅助监督，喂给 I3 的「训练期辅助、推理期纯端到端」降级路径。
- P5（时间压力）补充：DiT 已有中间层选项（F20）与 4 步推理，视觉 token 数是延迟主项；I6 需要显式的 token/层预算。
- 新增 P9（表征漂移）：默认冻结动作头，任何视觉改动都会在 DiT 输入端制造分布偏移，动作头无法自行补偿。
- 新增 P10（单模型边界 vs 生态诱惑）：推理期外挂视觉模型最省事，但最可能违规/超时。
- 新增 P11（生态版本漂移）：110 语料仍在更新、基座权重与第三方许可会变，需版本冻结与可复现清单。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（探针→适配）**：Qwen3-VL 视觉塔的哪些层/通道分别编码外观（风格/纹理/光照）、几何（位姿/深度/接触）与语义（物体类别/可供性）？在恒等初始化与漂移约束下，最小适配哪几层、用什么秩，能在外观轴上提升且不伤标称？
- **Q10（离线教师可信度）**：DINOv2/3、SAM2、Depth Anything、GroundingDINO 在 G1 第一人称图像上的伪标签误差有多大？哪些教师的监督经蒸馏后能在 L0 探针上兑现为「保持几何 + 提升不变性」，哪些只会教出教师偏差？
- **Q11（跨本体无标签数据的杠杆率）**：DiverseManip/仿真/开源视频的纯视觉数据，对视觉适配器的增益随数据量/多样性如何变化？在什么规模上饱和？与「同任务有标签数据」的边际增益比是多少？

## 4. 设计原则（新增 PR6–PR8，其余保留）

- **PR6 表征-轴匹配律**：每一个视觉表征干预必须写明它瞄准的计分轴，并给出该轴上的探针指标；说不出「哪个探针会动」的干预不做。
- **PR7 离线教师、单模型学生**：所有开源模型默认只在训练/离线阶段使用；推理链只允许官方单模型 + 可合并的适配器 + 许可干净的预处理。任何推理期外挂必须先拿到组委会书面确认，否则不上计分通道。
- **PR8 恒等初始化干预律**：任何视觉编码器改动必须恒等初始化（适配器初值使 \(z'=z\)，如 LoRA 的 B=0），并在标称 G1 留出集上约束特征漂移 \(\lVert z'-z\rVert\le\epsilon_{drift}\)；先保证「不动时等于原模型」，再谈增益。
- PR1–PR5 保留。

## 6. 本轮最大风险（一句话）

**I10/I11 的最大风险是「表征漂移」：冻结的动作头是在原 VLM 特征流形上训练的，视觉适配器一旦把特征推离该流形，离线探针会变好而真机分数下降——必须用 PR8 的恒等初始化 + L0 漂移门禁 + 小步动作头重对齐把这条风险锁死，确认前不放量。**

## 7. 下轮迭代计划（深化与修剪，不推倒）

- **深化**：I10——先在 Qwen3-VL 上实做探针矩阵（需用 `named_modules()` 定位视觉塔模块名），产出「层×轴」敏感性表，再定 vision LoRA 的 `target_modules` 与秩预算；I11——在 G1 图像上评估各教师伪标签误差，选 2 个教师做最小蒸馏原型，确定「无标签视觉数据:有标签 G1 数据」采样比。
- **修剪**：I7 继续待裁撤；I6 的视觉 token 子项若 p99 余量不足则只保留中间层条件；I11 若教师误差超阈值则降级为「仅用 stereo 深度（F25）+ 仿真精确几何（F14）」。

# UniBot-V1 参赛创新点清单（第 3 轮 v1.2）

> 检索日期：2026-11-26（第 1 轮）、2026-11-27（第 2/3 轮）；来源见 §5。承接 v1.1：I10/I11 新增，I3/I6/I9 深化，I1/I2/I4/I5/I7/I8 维持。清单只增改不重置。本轮主轴：**表征引擎**。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 v3 考纲校准五轴增广引擎 ★★★★★（维持深化）
- **动机**：计分的 320 次真机评测每次都在 5 轴上偏离训练分布（P2/F2）。
- **本轮深化（视觉编码器联动）**：增广器不只产「训练样本」，还产「视觉自监督多视图对」——同一场景在考纲轴上的两个扰动版本，作为 I11 的不变性损失 \(L_{inv}\) 的输入对；考纲卡仍是唯一的扰动分布来源，避免视觉自监督引入考纲外分布。
- **六要素其余项**：与 v1.1 相同（考纲卡、剂量-响应、轴间析因、单卡 inpainting、L0 先行）。
- **风险**：增广对的「同一语义」若被破坏（重拼接改变物体身份），会把错误不变性教给视觉编码器——用物体掩码/身份标签做配对门禁。

### I2 v3 数据引擎 2.0：110 语料孪生迁移 + 加权共训 ★★★★★（维持深化）
- **动机**：单模型平均分被最弱任务支配（P1）；示教语料与质量双重浪费（P8）。
- **本轮深化（视觉语料复用）**：110 语料（F10）与 DiverseManip（F13）同时作为 I11 的**无标签视觉语料**——动作标签只用于动作头，像素可用于视觉适配器，二者共用同一份下载与缓存；新增「视觉数据:动作数据」双采样器（视觉桶不参与动作损失）。
- **六要素其余项**：与 v1.1 相同（孪生表、loader 加权 patch、质量加权、族级 L0 止损）。
- **风险**：视觉桶与动作桶的采样比失衡会拖慢动作收敛——视觉桶只在视觉适配阶段开启，动作头阶段关闭或降至 ≤10%。

### I3 v3 接触任务族关键点视觉伺服回退 ★★★★（维持，路径收敛到 I3'）
- **动机**：无触觉（F8），接触段（插网线、扣充电器、拧药瓶）对几何精度要求最高。
- **本轮深化（训练期几何、推理期纯视觉）**：默认走 **I3' 训练期辅助监督**——用 stereo 深度（F25）/仿真精确几何（F14）生成接触点、接近方向、插入轴的辅助标签，训练视觉适配器/注意力关注接触段；推理仍是纯端到端单模型，不触碰单模型边界。只有组委会书面确认「混合推理」合规后，才启用几何伺服回退。
- **与现有方案差异**：v1.1 把几何伺服放在推理链（合规风险最大）；v3 把它降级为训练期归纳偏置，风险从「合规」变成「辅助任务设计」。
- **所需资源**：stereo/仿真深度管线 1 人周；辅助头 1 GPU 日/任务族。
- **落地步骤**：① stereo 深度/仿真几何生成；② 接触段关键点标签；③ 辅助头与视觉适配器联合训练；④ 推理期丢弃辅助头；⑤ L0 接触段误差 + L2 抽测。
- **风险**：辅助任务与主任务梯度冲突——辅助损失权重退火到 0，主损失优先。

### I4 人手干预感知门控 + 自适应 chunk ★★★★（维持）
- 六要素同 v1.1；本轮补充：干预判别优先用**手腕相机**（手进入夹爪工作区最先出现在腕部视野，F26），全局相机做二次确认；`obs_delta_indices` 给腕部视角 2–4 帧历史。

### I5 v2 非标称示教合成 + 得分点对齐恢复 ★★★★（维持）

- **本轮新增子项：视觉 token/中间层预算（F20/F26）**：

### I10 探针定层的分轴视觉适配（新）★★★★★
- **动机**：五个泛化轴都是视觉分布偏移；官方默认冻结 VLM（F21），视觉 token 又是 DiT 的条件 key（F22）——视觉表征既未被评测分布校准，改动又会直接影响动作头。全冻与整段 LoRA 都不是最优。
- **直觉**：视觉塔的不同层分工不同：浅层偏风格/纹理/光照（nuisance），中深层偏物体语义/几何/接触（task）。应当**只在「携带 nuisance 但任务特异性低」的层上做小秩适配**，并用恒等初始化保证「不动时等于原模型」。
- **严谨定义**：
  - 设视觉塔第 \(\ell\) 层特征为 \(f^{(\ell)}(I)\)，属性 \(k\) 的线性探针准确率为 \(S_{\ell,k}\)。
  - **层选择分**：\(r_\ell=\dfrac{S_{\ell,\text{style}}+S_{\ell,\text{background}}}{S_{\ell,\text{object}}+S_{\ell,\text{pose}}+S_{\ell,\text{contact}}+\varepsilon}\)，选 top-\(b\) 层（默认 \(b=4\)）。
  - **恒等初始化残差适配器**：\(z'=z+\alpha\,B A z\)，\(B_0=0\)（或 LoRA 的 \(B=0\)），故初始 \(z'=z\)。
  - **训练目标**：\(\mathcal{L}=\mathcal{L}_{inv}+\lambda_1\mathcal{L}_{pres}+\lambda_2\mathcal{L}_{drift}\)，其中
    \[
    \mathcal{L}_{inv}=\mathbb{E}_{I,\tau\in\mathcal{G}_{nui}}\lVert z'(\tau I)-z'(I)\rVert^2,\quad
    \mathcal{L}_{pres}=\sum_k\mathbb{E}\lVert p_k(z'(I))-y_k(I)\rVert^2,\quad
    \mathcal{L}_{drift}=\mathbb{E}_{I\in\mathcal{D}_{G1}^{nom}}\lVert z'(I)-z(I)\rVert^2.
    \]
  - 推理期丢弃探针头 \(p_k\)，只留可合并的适配器；单模型边界不破。
- **与现有方案差异**：全冻队伍不校准表征；整段 LoRA 队伍用容量换鲁棒性、易遗忘且无法定位；本点是「探针定位 + 最小干预 + 漂移可测」。
- **技术可行性**：中-高。需先用 `named_modules()` 定位 Qwen3-VL 视觉塔模块名（官方文档只给语言侧 LoRA 目标，F21）；PEFT 对 vision 侧 target 需实测；探针是线性层，成本极低；适配器可合并/单独分发（F28）。
- **所需资源**：1×24GB GPU；探针 1 GPU 日；适配器训练 1–2 GPU 日；标注复用数据集元数据 + stereo/教师（I11）。
- **落地步骤**：① 定位视觉塔模块与可 LoRA 目标；② 构建探针数据集（身份/风格/背景/位姿/接触/目标距离）；③ 拟合「层×轴」敏感性表；④ 按 \(r_\ell\) 选层与秩；⑤ 训练恒等初始化适配器；⑥ L0 探针 + 漂移门禁；⑦ 动作头 LoRA 小步重对齐（因为默认动作头冻结，F21）；⑧ L2 抽测。
- **风险**：探针属性不等于控制相关（缓解：只把探针当 veto，最终以动作/得分验证）；漂移伤标称（缓解：PR8 恒等初始化 + \(\mathcal{L}_{drift}\) + 动作头重对齐）；vision LoRA 不受支持（缓解：退回「塔后残差适配器」，不改原权重）。

### I11 跨本体无标签视觉预训练 + 开源教师离线蒸馏（新）★★★★
- **动机**：视觉表征不需要动作标签，因此可以白嫖开源生态的**无标签视觉数据**与**强教师**；但竞赛单模型 + 66ms 预算禁止推理期外挂（P10）。
- **直觉**：把「生态算力」换成「视觉鲁棒性」——教师只在离线出标签，学生仍是官方单模型 + 可合并适配器。
- **严谨定义**：设无标签视觉集 \(\mathcal{D}_{vis}=\mathcal{D}_{110}\cup\mathcal{D}_{DiverseManip}\cup\mathcal{D}_{sim}\cup\mathcal{D}_{open}\)，教师 \(T=\{\text{DepthAnything},\text{SAM2},\text{DINOv3},\text{GroundingDINO}\}\)。离线生成伪标签 \(\hat y_k=T_k(I)\)，用 I10 的 \(\mathcal{L}_{pres}\) 蒸馏；教师误差用真实 stereo 深度（F25）与仿真精确几何（F14）做锚点校准。**视觉数据杠杆率** \(L_{vis}=|\mathcal{D}_{vis}|/|\mathcal{D}_{G1}^{labeled}|\)；主张：视觉编码器增益随 \(L_{vis}\) 增长，动作头增益只随有标签 G1 数据增长。
- **数据分层（重要）**：同域无标签（110/DiverseManip/仿真，同机器人同相机）权重最高；跨本体开源视频只做多样性补充、低权重；仿真提供**精确**几何标签，教师提供真实图像伪标签，stereo 深度做校准锚点——三者互补。
- **与现有方案差异**：别人把开源模型当推理外挂（违规/超时风险）或完全不用；本点把生态严格限制在离线训练链，推理零额外依赖。
- **技术可行性**：中。教师推理与伪标签管线是工程活；主要不确定性是教师域差与许可。
- **所需资源**：教师推理 1–2 GPU 日（子集）；数据管线 1 人周；磁盘增量 ≈0.5–1TB（视觉帧可降采样存储）。
- **落地步骤**：① 教师候选与许可核对（F24 只覆盖主干，不覆盖外部教师）；② 在 G1 图像上评估教师误差（深度用 stereo、分割用抽检）；③ 伪标签 110/DiverseManip/仿真子集；④ 蒸馏进 I10 适配器；⑤ L0 探针验证；⑥ 误差大的教师降级为辅助或剔除；⑦ 版本冻结（P11）。
- **风险**：教师偏差被蒸馏进学生（缓解：stereo/仿真锚点 + 逐教师 L0 + 只做辅助）；跨本体域差（缓解：同域权重优先）；许可不可商用（缓解：优先 Apache/MIT，非商用教师只做研究验证不上交付链）；版本漂移（缓解：数据集/权重/教师版本哈希冻结）。

### 1.1 视觉探针矩阵与层选择（I10）

```python
# 先定位：for n, m in vlm.named_modules(): if "visual" in n: print(n)
VIS_LAYERS = [f"visual.blocks.{i}" for i in range(n_vis_blocks)]
ATTRS = ["object", "style", "background", "pose", "gripper_dist", "contact", "goal_dist"]

def fit_probe_matrix(feats, labels):
    S = {}
    for l in VIS_LAYERS:
        for k in ATTRS:
            S[l, k] = linear_probe_cv(feats[l], labels[k])   # acc or R^2
    return S

def select_layers(S, b=4, eps=1e-6):
    # 适配「携带 nuisance、任务特异性低」的层：先除风格，保几何/语义
    score = {
        l: (S[l, "style"] + S[l, "background"])
           / (S[l, "object"] + S[l, "pose"] + S[l, "contact"] + eps)
        for l in VIS_LAYERS
    }
    return sorted(VIS_LAYERS, key=score.get, reverse=True)[:b]
```

### 1.2 恒等初始化残差适配器 + 三项损失（I10）

```python
class ResidualVisionAdapter(nn.Module):
    def __init__(self, d, r=16):
        super().__init__()
        self.A = nn.Linear(d, r, bias=False)
        self.B = nn.Linear(r, d, bias=False)
        nn.init.zeros_(self.B.weight)          # 恒等初始化：初始 z' == z
        self.alpha = 1.0
    def forward(self, z):
        return z + self.alpha * self.B(self.A(z))

def L_inv(ad, f, I, aug):
    return F.mse_loss(ad(f(aug(I))), ad(f(I)))          # 风格/背景不变

def L_pres(ad, f, I, teacher):
    z = ad(f(I))
    return sum(F.mse_loss(head[k](z), teacher[k](I))    # 深度/分割/对应
               for k in teacher)

def L_drift(ad, f, I_nominal_g1):
    return F.mse_loss(ad(f(I_nominal_g1)), f(I_nominal_g1))

# total = L_inv + lambda1 * L_pres + lambda2 * L_drift
# 推理：丢弃 head[*]，只留可合并的 ad；单模型边界不破
```

## 2. 实验设计（分级消融协议 v3）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| L0-V | 视觉探针矩阵；漂移 \(\Delta_{drift}\)；不变性 gap；几何保持 | 离线（免费） | 目标轴探针↑、标称漂移 ≤ ε、几何保持不降 |
| L0-A | I1 各轴剂量-响应；I2 孪生正/负迁移；I9 先验不伤标称；I5 合成示教质量 | 离线（免费） | 同 v1.1 |
| L1 | 析因：{vision 适配 on/off} × {层集 early/mid/late} × {秩 4/16} × {蒸馏 on/off} × {动作头重对齐步数 0/小} | 离线 + 少量真机 | 主效应显著的 ≤3 组进 L2 |
| L2 | top 组合：≥2 任务（外观重：FruitSorting/ColorArrangement；接触重：PlugCharger/ZipUp）× 各 2 次 | 单任务通道 | 真机增益 ≥ 离线预测的 50%，且标称不降 |
| 门禁 | PR4 + 单模型合规 + p99 < 40ms + 漂移 ≤ ε | 本地 stub | 0 拒绝动作、0 外挂依赖、漂移达标 |

**首批 L2 排队**：① I2 共训基线 → ② I10 视觉适配（先动作头重对齐）→ ③ I11 蒸馏消融 → ④ I9 换表征后的未见轴抽测。**I10/I11 必须排在 I2 之后**：先有稳定动作基线，才能分离表征增益。
