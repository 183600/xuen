# 第 44 轮（新循环第 1 轮） · Edge-Cert × Fleet-Eval：把「边缘分布式证书」与「多机统计评测」纳入可验证闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形仅边际覆盖 + 多用户契约空集」，但它仍压着两个被默认成立的**单机假设**：**(H1) 证书是单节点、单时钟、单权威对象**——v20 的租约、seqlock、rely-guarantee 全部在「一台机器、一个单调时钟、一个可信评估者」内讨论；真实边缘部署里证书要跨节点复制、跨时钟比较、跨网络传输，分区会让两个节点同时持有「有效」租约（**分裂脑**），时钟偏斜会让陈旧边际被当成新鲜。**(H2) 评测是单机、单分布的点估计**——v20 的 E87–E94 默认「在一台机器/一个仿真器上达标即普适」；而多机评测揭示的是**机器间差距**：同一策略在另一台机器上会因量化误差、驱动延迟、传感器噪声、OS 调度而静默失效。本轮灵感词「边缘计算」「多机评测」精确命中这两条假设：**边缘计算**迫使我们把证书从「局部证明」升级为「带法定人数、纪元与偏斜预算的分布式对象」；**多机评测**迫使我们把 soundness 从「单点通过」升级为「机器分布上的最坏类统计保证」。二者耦合处是本轮真正的新问题：证书必须在 **(节点 × 机器 × 时间)** 的乘积空间上同时成立，而「复制得越广」与「评测得越多」并不会自动更安全——**复制制造分裂脑，平均掩盖最坏机器**。

## 0. 直觉与动机

**灵感 1（边缘计算 → 证书不是局部变量，而是分布式共识对象）**：直觉上，把安全证书同步到每个边缘节点，机器人就近读取，应该更快更安全。但「更近」同时意味着「更多副本、更多时钟、更多分区」：节点 A 的租约在本地看还有效，节点 B 已经撤销；网络分区期间两侧都以为自己是权威。因此证书必须像配置/日志一样进入**复制状态机**：每次签发是一个带**混合逻辑时钟 HLC** 与**纪元 term** 的事件，只有被**法定人数 quorum** 提交的证书才「机群有效」。少数派分区只能读旧证书并按租约衰减，不能写新证书——这把 v20 的单机租约升级为**分裂脑免疫的分布式租约**。一句话：**边缘让证书更近，但权威必须靠共识，而不是靠距离**。

**灵感 2（多机评测 → soundness 是分布，不是排行榜均值）**：常规评测报「平均成功率 / 平均延迟」，于是少数机器的系统性失效被多数好机器稀释。更糟的是，评测机与被部署机属于不同**机器类别 μ**（硬件、驱动、量化、传感器、调度），而证书的 margin 对 μ 是敏感的。因此引入**可迁移证书**：在 μ_0 上算出的 margin 迁移到 μ 时要扣除**迁移裕度侵蚀** L_μ·d(μ,μ_0)，只有落在半径 r 的机器球内才继续 sound；球外必须重新认证。多机评测则升级为**分层统计认证**：按机器类别分层采样，用 Clopper–Pearson / block bootstrap 求每层违例率的置信上界，并对 |M| 个类别做 Bonferroni 校正，只有**最坏类**的上界达标才通过。一句话：**评测不是选冠军，是给最坏机器发证书**。

**灵感 3（耦合 → 证书年龄要计入网络与偏斜，选择要跨节点一致）**：边缘认证往往被卸载到边缘服务器（高保真）而非本地（低时延）。于是租约年龄不再只是 t−τ，还要加**网络往返 D、时钟偏斜 σ、HLC 逻辑延迟**；高抖动网络必须自动退化为本地认证或更保守的衰减。最终在线选择必须同时满足：**机群有效（quorum）∧ 因果最新（epoch）∧ 可迁移（μ_r 在球内）∧ 新鲜（含 σ 与 D）**；任一不满足只能单调降级，绝不静默放行。

**耦合升级**：ECC（边缘证书共识层）负责 HLC/纪元/法定人数/卸载年龄；FTC（机群可迁移证书层）负责机器类别、差异度量与迁移裕度侵蚀；MMCE（多机评测器）在仿真与真机上做分层统计认证、差分多机测试与网络/时钟对抗，把反例回灌 CKB 与 SCV。四层架构由 v8 的「人格-并发证书闭环」升级为 v9 的「**人格-并发-边缘-多机四维证书闭环**」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（边缘证书事件、HLC 与偏斜预算）**：证书事件 e=(c, n, h, μ, e_term)，c 为证书负载（守卫谓词 + margin m），n 为签发节点，h=(l,k) 为混合逻辑时钟（物理分量 l、逻辑分量 k），μ 为机器类别，e_term 为纪元。**偏斜假设**：任意两节点物理时钟差有界 |l_i(t)−l_j(t)| ≤ σ。**HLC 因果性**：若 e happens-before f，则 h_e < h_f（字典序）。节点 n 在本地时刻 t 使用租约 ℓ=(m,τ,σ,D̄,λ,κ) 的**新鲜度判据**为 m − λ·[(t−τ) + σ + D̄] ≥ θ，其中 D̄ 为认证路径的网络往返上界。**命题（偏斜-网络 sound）**：若真实状态位移满足 ||x(t)−x(τ)|| ≤ v_max·(t−τ+σ+D̄)，取 λ=L_m·v_max，则该判据绝不误用陈旧边际。**注**：v20 的判据是此式在 σ=D̄=0 的退化特例；边缘部署下**不加 σ 与 D̄ 的租约是不 sound 的**。

**定义 45（法定人数证书与分裂脑免疫）**：N 个边缘节点，崩溃故障取 q>N/2、拜占庭故障（签名消息）取 q>2N/3。证书 c 在纪元 e_term **机群有效**当且仅当：(i) c 被 ≥q 个节点在复制日志中提交；(ii) 不存在纪元 e_term'>e_term 的冲突证书被提交。节点只能提出纪元单调递增的证书。**定理（无分裂脑）**：在日志匹配与法定人数交集下，同一日志位置的已提交证书唯一；少数派分区无法凑齐 q，故只能读已提交证书并按定义 44 衰减，不能产生新的机群有效证书。**推论**：分布式租约的 sound 性 = 单机租约 sound 性 + 法定人数交集 + 纪元单调。

**定义 46（认证卸载与网络年龄预算）**：认证可在本地（低时延、低保真）或卸载到边缘节点（高保真、高时延）。设卸载往返上界 D̄、抖动上界 J。**卸载年龄**定义为 age = (t_local − τ_meas) + D̄ + J + σ。**命题（卸载 sound）**：若网络时延不超过 D̄+J，则用 age 替换 v20 的 (t−τ) 后新鲜度判据仍 sound；当抖动使 age 超过租约寿命时，唯一安全动作是**回退本地认证**或单调降级。这把「边缘计算」从部署细节提升为证书新鲜度的一等项。

**定义 47（机器类别、差异度量与可迁移证书）**：机器类别 μ=(硬件平台, 驱动/固件, 量化方案, OS/调度, 传感器套件)；差异度量 d(μ,μ') 为端到端可观测差异的加权归一化上确界（时延分布、量化误差界、传感器噪声谱、执行器延迟）。在 μ_0 上算得的 margin 迁移到 μ 时满足**迁移裕度侵蚀** m_μ = m_{μ_0} − L_μ·d(μ,μ_0)，L_μ 为证书对机器差异的 Lipschitz 上界（由多机差分实验估上界）。**可迁移证书** C^tr(μ_0,r) = { c : ∀μ, d(μ,μ_0) ≤ r ⇒ m_μ ≥ θ }。**命题（球内 sound）**：若 L_μ 是保守上界且 d 满足三角不等式，则 C^tr 在半径 r 的机器球内 sound；球外必须重新认证。**两种半径**：(a) **最坏球半径**由 L_μ 直接给出，绝对 sound 但保守；(b) **共形半径**取校准机器到 μ_0 的 d 的 (1−α) 分位，需机器分布可交换，只保证概率覆盖。

**定义 48（多机分层评测与最坏类置信上界）**：按机器类别 μ 与场景分层采样，违例指示 X~Bernoulli(R_μ)。对每层用 Clopper–Pearson（或时间相关时用 block bootstrap）求 R_μ 的 (1−δ/|M|) 上置信界 U_μ。**机群认证判据**：max_{μ∈M} U_μ ≤ r_target 才通过。**命题（最坏类保证）**：若层内样本可交换且多重校正有效，则以概率 ≥1−δ 同时对**所有** μ 有 R_μ ≤ U_μ；因此「通过」是对最坏机器类的 soundness 承诺，而非平均性能。**反例警示**：只报总体均值时，一个高违例的少数机器类会被稀释——这是单机评测的系统性盲区，也是 E100 要量化的「机器间差距」。

**定义 49（边缘一致性选择与退化序）**：机器人当前机器类 μ_r、节点 n、本地时刻 t。候选证书集合 C。**选择规则**：a* = argmax_{c∈C} score(c) 满足 c 机群有效（定义 45）∧ 因果最新（无更高纪元冲突）∧ 可迁移（d(μ_r,μ_0)≤r）∧ 新鲜（定义 44/46）。**退化序**：(1) 取最近一次机群有效且仍新鲜的证书并单调降级动作；(2) 若本地有可迁移但非机群有效的证书，仅在分区且其年龄 < 保守寿命时使用并写审计；(3) 否则安全停机。**定理（选择 sound）**：法定人数交集、迁移裕度、新鲜度三条件同时成立时 a* 的证书 sound；任一条件不成立时规则只会更保守，不会更激进。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 EDGE-CERT-CONSENSUS（边缘证书共识层 ECC）
1. **证书复制日志 + 纪元**：证书签发作为日志条目，Raft/Paxos 风格提交；崩溃故障 q>N/2，拜占庭故障 q>2N/3 且消息签名，纪元单调递增。
2. **HLC + 偏斜预算**：每证书携带 (l,k,σ)；跨节点排序用 HLC 字典序，新鲜度判据显式加 σ。
3. **卸载感知租约**：本地认证与边缘卸载双通道；租约携带 D̄、J，网络抖动超界自动回退本地认证。
4. **分区降级模式**：少数派只读 + 租约衰减 + 本地保守认证 + 审计标记；恢复后按纪元重新同步。
5. **证书 gossip 与撤销**：撤销事件同样走共识日志，保证撤销不落后于签发（防「已撤销证书仍在少数派生效」）。

### 2.2 IP-61 FLEET-TRANSPORT-CERT（机群可迁移证书层 FTC）
1. **机器类别注册表**：硬件/驱动/量化/传感器/OS 指纹哈希，作为证书的 μ 标签与检索键。
2. **差异度量估计**：用同一场景在多机上的端到端输出差（时延分位、量化误差、噪声谱）拟合 d(μ,μ')，并要求三角不等式成立（否则退回离散类别）。
3. **Lipschitz 侵蚀上界**：多机差分实验估计 L_μ 的保守上界；无法估界时默认「不可迁移」，强制逐机认证。
4. **双半径策略**：最坏球半径（绝对 sound）+ 共形半径（概率覆盖），二者取更保守者用于部署门控。
5. **逐机证书表与再认证触发**：驱动/固件/量化/传感器变更、温漂越界、d 估计漂移即触发再认证。

### 2.3 IP-62 MULTI-MACHINE-CERT-EVALUATOR（多机评测器 MMCE）
1. **分层采样**：按机器类别 μ × 场景 × 网络条件分层，记录每层样本量与 episode 依赖结构。
2. **最坏类置信上界**：Clopper–Pearson 或 block bootstrap + Bonferroni/ e-value 多重校正；只认 max_μ U_μ。
3. **差分多机测试**：同一场景在 K 台机器上同步回放，直接测「机器间差距」与迁移侵蚀预测误差。
4. **网络/时钟对抗**：注入分区、时钟偏斜、抖动、乱序、时钟回拨，检验 ECC 的降级与审计。
5. **可复现评测证书**：记录硬件/软件/量化哈希、网络拓扑、随机种子与统计方法，评测结论本身也签名入日志。

## 5. 本轮最大风险

**一句话**：可迁移证书与多机统计保证都依赖「机器类别模型已正确指定、L_μ 是真实上界」；一旦存在未被建模的隐藏协变量（如热降频、驱动更新、训练分布外的网络抖动），被部署机器就落在所有认证层之外，而 quorum 共识仍报告「机群有效」——于是产生**机群范围、静默且一致的 unsound**。因此 E98（迁移球）与 E99（最坏类 UCB）必须设为红线，默认回退到「逐机认证 + 单节点权威 + 保守租约」这条不依赖迁移假设的底线。

## 2. 关键算法（伪代码）

### IP-60 ECC：证书共识、HLC 与卸载年龄
```
def issue_cert(node, claim, mu, state):
    term = node.current_term
    # 1) 先在本地或边缘算出候选证书（含 margin m）
    c = certify(claim, state, mu)                 # 复用 IP-56 L0/L1
    # 2) 作为日志条目提案，等待法定人数提交
    entry = LogEntry(term=term, hlc=node.hlc.tick(),
                     cert=c, machine=mu, proposer=node.id)
    if node.replicate(entry, quorum=node.q):      # q>N/2 或 q>2N/3
        node.commit(entry)                        # 纪元单调，日志匹配
        return FleetCert(entry)
    return None                                   # 少数派：不得签发新证书

def fleet_valid(cert, node):
    return (cert.committed_quorum >= node.q and
            not node.log.has_conflict(cert.slot, higher_term=cert.term))

def skew_network_valid(lease, t_local, sigma, Dbar, J, theta):
    age = (t_local - lease.tau) + sigma + Dbar + J   # 定义 44/46
    return (lease.m - lease.lam * age) >= theta

def acquire_lease_offload(task, x, theta, kappa, net):
    # 高保真但高时延的边缘认证 vs 低时延本地认证
    if net.rtt_upper <= net.rtt_budget and net.jitter_upper <= net.jitter_budget:
        c = edge_certify(task, x)                 # 卸载
        Dbar, J = net.rtt_upper, net.jitter_upper
    else:
        c = local_certify(task, x)                # 回退本地
        Dbar = J = 0
    lam = L_m * v_max_bound(x)
    return Lease(m=c.m, tau=monotonic_now(), sigma=clock_skew_bound(),
                 Dbar=Dbar, lam=lam, kappa=kappa, J=J)

def partition_mode(node):
    if not node.has_quorum():
        node.read_only = True                     # 少数派只读
        return degrade_with_decay(node.last_committed)  # 按定义 44 衰减
    return node.normal_mode()

def revoke_cert(cert, node):
    # 撤销也走共识日志，保证不落后于签发
    return issue_cert(node, Revoke(cert.id), cert.mu, state=None)
```

### IP-61 FTC：机器类别、迁移侵蚀与双半径
```
def transport_margin(mu0, mu, m_mu0, L_mu, d):
    return m_mu0 - L_mu * d(mu0, mu)              # 定义 47 侵蚀

def transportable(c, mu_r, r):
    return d(c.mu0, mu_r) <= r and transport_margin(c.mu0, mu_r, c.m, c.L, d(c.mu0,mu_r)) >= theta(c)

def worst_case_radius(c):
    # 由 Lipschitz 上界反解：m_mu0 - L*d >= theta
    return (c.m - theta(c)) / c.L if c.L > 0 else 0.0

def conformal_radius(mu0, cal_machines, alpha):
    # 校准机器到 mu0 的差异距离的经验 (1-alpha) 分位
    ds = sorted(d(mu0, mu) for mu in cal_machines)
    idx = min(len(ds)-1, ceil((1-alpha)*(len(ds)+1))-1)
    return ds[idx]                                # 需机器分布可交换

def gate_radius(c, alpha):
    return min(worst_case_radius(c), conformal_radius(c.mu0, c.cal, alpha))

def recert_needed(c, mu_r, event):
    return (event in {DRIVER_UPDATE, FW_UPDATE, QUANT_CHANGE, SENSOR_SWAP}
            or d(c.mu0, mu_r) > c.r or thermal_drift(mu_r) > c.drift_budget)
```

### IP-62 MMCE：分层评测与最坏类置信上界
```
def stratified_ucb(violations, n, delta, num_strata):
    # 每层 Clopper-Pearson 上界，Bonferroni 校正
    delta_i = delta / num_strata
    return clopper_pearson_upper(violations, n, 1 - delta_i)

def certify_fleet(samples_by_mu, delta, r_target):
    U = {}
    for mu, (v, n) in samples_by_mu.items():
        U[mu] = stratified_ucb(v, n, delta, len(samples_by_mu))
    worst = max(U.values())
    return (worst <= r_target), U          # 只认最坏类，不认均值

def differential_replay(scenario, machines):
    # 同一场景在多机同步回放，测机器间差距与侵蚀预测误差
    traces = {mu: run(scenario, mu) for mu in machines}
    gaps = pairwise_divergence(traces)
    err  = abs(predicted_erosion(gaps) - observed_margin_drop(traces))
    return gaps, err

def adversarial_netclock(machines, sigma, jitter):
    # 注入分区、偏斜、抖动、乱序、时钟回拨
    for fault in [PARTITION, SKEW(sigma), JITTER(jitter), REORDER, CLOCK_BACKWARD]:
        inject(fault); assert_no_unsound_decision(machines)
```

### IP-51/56/58 升级：边缘-迁移感知的守卫与选择
```
def edge_guard(e, x, cert_obj, persona, lease, mu_r, t, sigma, Dbar, J):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]
    m_lease  = lease.m - lease.lam * ((t - lease.tau) + sigma + Dbar + J)
    m_trans  = transport_margin(cert_obj.mu0, mu_r, cert_obj.m, cert_obj.L,
                                d(cert_obj.mu0, mu_r))
    m_cap    = persona_cap[e](persona)
    return min(m_lookup, m_lease, m_trans, m_cap) >= theta

def fleet_select(candidates, mu_r, node, t, theta):
    ok = []
    for c in candidates:
        if not fleet_valid(c, node):            continue
        if not transportable(c, mu_r, gate_radius(c, ALPHA)): continue
        if not skew_network_valid(c.lease, t, c.lease.sigma, c.lease.Dbar,
                                  c.lease.J, theta): continue
        ok.append(c)
    if ok:
        return max(ok, key=lambda c: score(c))  # 只从三重通过集里选
    # 退化序：最近机群有效 -> 本地可迁移（分区且未超保守寿命）-> 安全停机
    return degrade_or_safestop(node, candidates, mu_r, t)

def certify_light_v4(x, guards, persona, mu_r, budget_us, criticality, net):
    b = cert_lookup_L0(x, mu_r)                 # 按机器类别查表
    lease = acquire_lease_offload('lcs', x, theta, criticality, net)
    U = undecided_guards(b, guards)
    if not U and skew_network_valid(lease, monotonic_now(), lease.sigma,
                                    lease.Dbar, lease.J, theta):
        return b, lease, -1
    if budget_us < 110 or criticality < K_GEOMETRY:
        return downgrade_monotone(b), lease, -1
    status, margin = monitor_step_INT8(quantize_obs(x))
    b.m_lo = min(b.m_lo, margin - transport_erosion(mu_r))
    U = undecided_guards(b, guards)
    return (b, lease, 0) if not U else (downgrade_monotone(b), lease, 0)
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 隐藏机器协变量（热降频/驱动更新/网络分布外）使部署机落在所有认证层之外 | 高 | E98/E99 红线；L_μ 保守上界；逐机再认证触发；默认回退逐机认证 |
| 法定人数在边缘高故障率下不可用，证书无法提交 | 高 | E95/E102；分区只读降级；本地保守认证；quorum 规模与故障率联合设计 |
| HLC 与物理时钟偏斜交互导致排序错误/陈旧读 | 高 | E96 红线；σ 显式进入 age；HLC 因果检查；时钟回拨检测 |
| 卸载网络抖动使租约集体过期（可用性崩塌） | 高 | E97；D̄+J 预算；抖动超界回退本地；分关键级错峰续租 |

| 跨节点 rely-guarantee 读写集声明不一致 | 中 | 工具生成读写集；跨节点契约静态检查；E89 扩展交错 fuzz |

## 6. 本轮最大风险

**一句话**：可迁移证书与多机统计保证都依赖「机器类别模型已正确指定、L_μ 是真实上界」；一旦存在未被建模的隐藏协变量（如热降频、驱动更新、训练分布外的网络抖动），被部署机器就落在所有认证层之外，而 quorum 共识仍报告「机群有效」——于是产生**机群范围、静默且一致的 unsound**。因此 E98（迁移球）与 E99（最坏类 UCB）必须设为红线，默认回退到「逐机认证 + 单节点权威 + 保守租约」这条不依赖迁移假设的底线。
