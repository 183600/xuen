# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「自主导航」×「语义地图」）

> 第 54 轮把技能从“能力”拆成动作空间剖面 `α_S`，又用云边映射 `γ_ce` 把粗动作接到细动作上。但它默认了两件事：动作空间是**给定的**，世界坐标是**已对齐的**。本轮用「自主导航 × 语义地图」补上这个缺口：**动作空间不是漂浮的，它长在语义地图上；语义地图本身是一个带不确定性的、会漂移的模型**。核心矛盾：H22：技能适用性不是技能单独的性质，而是 `(技能, 地图状态)` 的联合性质，对地图做边缘化会制造**虚假兼容**；H23：感知混叠与定位漂移会让同一语义标签落到不同物理位置，产生**系统性而非随机**的动作错配，这是第 54 轮“剖面欠采样”背后的结构性根因。

## 0. 直觉与动机

**灵感 1（语义地图是动作空间的坐标系，而不是背景板）**
直觉：第 54 轮的 `α_S : A → [0,1]` 隐含假设动作 `a` 在任何地方含义相同。但“前进 1 米”在走廊和台阶上是两个动作。语义地图给出的是**动作的坐标系**：同一符号动作 `a` 在不同地图状态 `m` 下落到不同物理效果。因此正确的对象不是 `α_S(a)`，而是**地图条件剖面** `α_S(a | m)`——动作空间是语义地图上的一个**丛（bundle）**，每个地图状态对应一根纤维。

**灵感 2（自主导航 = 符号航点向度量动作的持续接地）**
直觉：导航不是“规划一条线”，而是不断把“去厨房”“绕过湿地”这类**语义航点**接成**度量动作**。接地函数 `ground: 语义航点 × 地图 → 动作序列` 一旦错位，越精确的控制器反而越快地把机器人送到错误的地方。这解释了为什么第 54 轮的 `cost_align` 在仿真里很小、上真机却失败：它只对齐了粗细动作粒度，没有对齐**语义位置**。

**灵感 3（感知混叠是虚假兼容的结构性根源）**
直觉：两个不同地点外观相似（两条一样的走廊、两个一样的门口），语义地图给它们相同标签，技能剖面在两处都判“可执行”。第 54 轮的 `compat(S_i,S_j)` 在边缘化剖面上为正，但真实地图条件下交集为空。**虚假兼容不是采样噪声，而是地图的分辨率不足**：地图把不同物理状态折叠成同一符号状态，这叫**语义混叠（semantic aliasing）**。

**灵感 4（地图不确定性是一等公民，不是误差项）**
直觉：语义地图的每个节点/边都带标签置信度与占用熵。导航路线的成功率不该由最弱的**技能**决定，而由路线上最弱的**地图边**决定。把地图证书 `M_cert` 与第 54 轮的联合证书 `J` 并列，鲁棒性谱就变成**地图条件谱** `ρ(d | m)`——同一技能在清晰地图区与模糊地图区的鲁棒性不同。

**灵感 5（Explain 驱动的主动语义建图）**
直觉：第 54 轮的 Explain 只回传“哪个动作失败”，本轮让它回传“**哪个地图节点不可信**”。一旦根因定位到 `V_bad`，就主动选择观测动作（转个视角、靠近看一眼、换个传感器）来最大化信息增益，重标注后重规划。这把被动失败变成**导航—失败—解释—补图—再导航**的闭环。

**灵感 6（云边语义地图对齐是 `γ_ce` 的地图级版本）**
直觉：云端持有全局语义地图 `M_c`，边端持有局部实测地图 `M_e`。真正的云边错位常常不是动作粒度，而是**两张地图不是同一张**：云端以为 A 口通向 B 厅，边端实测 A 口封了。需要地图级映射 `γ_ce^M` 与地图漂移 `δ_M`，作为部署前的新否决项。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（分层语义地图）**
语义地图 `M = (G_M, L, U, ψ, emb)`：
- `G_M = (V_M, E_M)` 为可导航拓扑图，节点/边带可导航性 `nav(·) ∈ {0,1}`；
- `L : V_M ∪ E_M → 2^Σ` 为语义标签集（本体 `Σ`）；
- `U : V_M ∪ E_M → [0,1]` 为不确定性场（标签/占用熵归一化）；
- `ψ : 𝒳_pose → V_M` 为定位接地函数，`emb : V_M → ℝ³` 为度量嵌入。
地图状态集合记 `ℳ`。**语义混叠对** `Alias(M) = {(u,v) : u≠v, d_emb(u,v) > Δ_far, sim_sensor(u,v) > θ_sim, L(u)=L(v)}`。

**定义 122（地图条件动作纤维与接地适用域）**
动作空间构成丛 `π : 𝒜 → ℳ`，纤维 `𝒜_m` 为地图状态 `m` 下物理可执行的动作集。技能的地图条件剖面 `α_S : 𝒜 × ℳ → [0,1]`。**接地适用域**
```
Dom(S, M) = { m ∈ ℳ : ∫_{𝒜_T(m)} α_S(a,m) da ≥ θ_cov }
```
第 54 轮实际使用的是其边缘化 `ᾱ_S(a) = E_{m∼P_M}[α_S(a,m)]`。定义**语义混叠间隙** `gap_alias(S) = sup_{a,m} |ᾱ_S(a) − α_S(a,m)|`。

**定义 123（语义地图证书）**
`M_cert = (κ_top, κ_lab, ψ_drift, ι_alias, evidence)`：
- `κ_top = min_{e∈E_M} conf(e)` 为拓扑置信度下界；
- `κ_lab = min_{v∈V_M} conf(L(v))` 为标签置信度下界；
- `ψ_drift = sup_{x} d(ψ(x), ψ_true(x))` 为定位漂移上界；
- `ι_alias = max_{(u,v)∈Alias(M)} sim_sensor(u,v)` 为感知混叠指数；
- `evidence` 至少含标定帧、混叠负样本对与地图版本哈希。

**定义 124（地图条件鲁棒性谱与地图耦合）**
鲁棒性谱按地图状态条件化：`ρ(d | m) = ρ(d | m₀) − K_M[d]·(1 − κ(m))`，其中 `κ(m)=min(conf(m), conf(∂m))`，`K_M` 为**地图-鲁棒性耦合矩阵**（第 53 轮 `K` 的地图维扩展）。路线鲁棒性取最弱边：
```
ρ_route(d) = min_{v∈route} ρ(d | m_v),   m_v = M.state(v)
```

**定义 125（云边语义地图对齐）**
地图级映射 `γ_ce^M : V_M^c → V_M^e`。地图漂移与语义分歧：
```
δ_M = max_{v∈V_M^c} [ d_emb(v, γ_ce^M(v)) + λ_s · D_sem(L_c(v), L_e(γ_ce^M(v))) ]
D_sem(A,B) = 1 − |A∩B| / |A∪B|
```
若 `δ_M > Θ_M` 或存在 `D_sem > Θ_sem` 的节点，则云边地图契约不成立，组合计划不得下发。

**定义 126（Explain 驱动的主动地图修复）**
失败经 Explain 得到根因节点集 `V_bad ⊆ V_M`。观测动作集 `O` 满足预算 `cost(O) ≤ B`，修复为
```
O* = argmax_{O: cost(O)≤B} I(M ; z_O | V_bad)
M' = bayes_update(M, O*, z_{O*})
```
**修复收敛**：每轮至少降熵 `ε`，即 `H(M' | z) ≤ (1−ε)·H(M | z)`；否则判为不可约不确定性，转入保守模式而非无限补图。

## 2. 关键算法 伪代码

### IP-121 SMG（Semantic Map Grounding）

```python
def map_conditioned_profile(skill, M, sampler, m_states):
    alpha = {}
    for m in m_states:
        A_m = feasible_actions(M, m)              # 动作丛纤维
        for a in sample(A_m, sampler):
            alpha[(a.id, m.id)] = sampler.confidence(skill, a, m)
    alpha_bar = marginalize(alpha, weights=M.prior)   # 第 54 轮的退化剖面
    gap = max(abs(alpha_bar[a] - alpha[(a, m)])
              for (a, m) in alpha)
    return MapProfile(alpha, alpha_bar, gap)


def applicability(skill, M, m, A_T, theta_cov=0.8):
    return all(skill.alpha.get((a.id, m.id), 0.0) >= theta_cov for a in A_T)
```

### IP-122 SMC（Semantic Map Certificate）

```python
def semantic_map_certificate(M, calib_frames, alias_pairs):
    k_top = min(e.conf for e in M.G.edges)
    k_lab = min(v.label_conf for v in M.G.nodes)
    drift = max(localize_err(M.psi, f) for f in calib_frames)
    i_alias = max((sensor_similarity(M, u, v)
                   for (u, v) in alias_pairs if u != v), default=0.0)
    evidence = bundle(calib_frames, alias_pairs, M.version_hash)
    return MapCert(k_top, k_lab, drift, i_alias, evidence)
```

### IP-123 MRC（Map-conditioned Robustness Coupling）

```python
def map_conditioned_robustness(skill, m, dims, K_M, rho0):
    kappa = min(m.node_conf, m.edge_conf)
    return {d: rho0[skill][d] - K_M[d] * (1 - kappa) for d in dims}


def route_robustness(route, M, dims, K_M, rho0):
    per_node = [map_conditioned_robustness(M.skill_at(v), M.state(v),
                                           dims, K_M, rho0)
                for v in route]
    return {d: min(r[d] for r in per_node) for d in dims}
```

### IP-124 MSA（Map Semantic Alignment）

```python
def align_semantic_maps(M_c, M_e, delta_emb, theta_sem, theta_M):
    gamma, delta_M, divergence = {}, 0.0, {}
    for v in M_c.G.nodes:
        cand = nearest_embed(M_c.emb[v], M_e)
        u = match_by_semantics(cand, M_c.L[v], M_e,
                               within=delta_emb)     # 几何 + 语义双门
        gamma[v] = u
        d_emb = dist(M_c.emb[v], M_e.emb[u])
        d_sem = 1 - jaccard(M_c.L[v], M_e.L[u])
        divergence[v] = d_sem
        delta_M = max(delta_M, d_emb + lambda_s * d_sem)
    bad = [v for v, d in divergence.items() if d > theta_sem]
    return (delta_M <= theta_M and not bad), gamma, delta_M, divergence, bad
```

### IP-125 AMR（Active Map Repair）

```python
def active_map_repair(M, explain, budget, eps):
    V_bad = explain.root_cause_nodes(M)
    if not V_bad:
        return ('noop', M, semantic_map_certificate(M, [], []))
    best = None
    for O in candidate_observations(V_bad, M):
        if obs_cost(O) > budget:
            continue
        ig = expected_information_gain(M, O, V_bad)
        if best is None or ig > best.ig:
            best = (O, ig)
    if best is None:
        return ('exhausted', M, None)
    z = execute_observation(best[0])
    M2 = bayesian_relabel(M, best[0], z)
    if entropy(M2) > (1 - eps) * entropy(M):
        return ('stalled', M2, None)          # 防修复振荡，转保守
    return ('repaired', M2, semantic_map_certificate(M2, [], []))
```

### IP-126 TAG（Topological Action Grounding）

```python
def ground_semantic_route(route_sem, M, gamma_ce, sampler, theta_cov):
    P_e = []
    for (v_prev, v_next) in edges(route_sem):
        m = M.state(v_next)
        if not M.nav(v_next):
            return ('reject', 'unreachable', v_next)
        skill = skill_for(v_next)
        alpha = map_conditioned_profile(skill, M, sampler, [m])
        for a_c in semantic_coarse_actions(v_prev, v_next):
            a_e = gamma_ce(a_c, m)            # 语义 → 度量接地
            if alpha.alpha.get((a_e.id, m.id), 0.0) < theta_cov:
                exp = explain_grounding(M, v_next, a_e, a_c)
                return ('reject', 'grounding_gap', (v_next, a_e), exp)
            P_e.append((v_next, a_c, a_e, m.id))
    return ('ok', P_e)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SMG | O(\|ℳ_s\|·\|𝒜_m\|·\|S\|) | O(\|𝒜\|·\|ℳ_s\|) | 纤维采样覆盖、混叠负样本 |
| SMC | O(\|V_M\|+\|E_M\|+\|Alias\|) | O(\|V_M\|+\|E_M\|) | 标定帧独立、置信度校准 |
| MRC | O(\|route\|·\|dims\|) | O(\|dims\|) | `K_M` 单调、最弱边取 min |
| MSA | O(\|V_M\|·log\|V_M\|) | O(\|V_M\|) | 几何+语义双门、漂移有界 |
| AMR | O(\|O_cand\|·IG) | O(\|V_bad\|) | 每轮降熵 ≥ ε、预算闭合 |
| TAG | O(\|route\|·\|𝒜_m\|) | O(\|𝒜_m\|) | 接地覆盖、语义航点可导航 |

**正确性定理（Map-Grounded Navigation Soundness）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** `α_S(a,m)` 对 `m` 是 ξ-Lipschitz，且 `ψ_drift ≤ Δ_ψ`；**(A30)** 地图证书各分量可独立校准，`ι_alias < 1`；**(A31)** 主动修复每轮降熵 ≥ ε 且在 `τ_repair` 内收敛。则对通过 `J` 与 `M_cert` 双重校验的计划：
```
P_success ≥ 1 − Σ_d (1−ρ_min(d)) − β_E − P(δ_a > Θ_a)
            − Σ_{v∈route} (1−κ_top(v)) − P(ι_alias > Θ_alias) − P(δ_M > Θ_M)
```

**关键推导（语义混叠导致的虚假兼容上界）**
设 `Δ_S = sup_{a,m} |α_S(a,m) − ᾱ_S(a)|`。Jaccard 兼容性对剖面的 L1 扰动满足
`|compat_m(S_i,S_j) − compat_marg(S_i,S_j)| ≤ 2(Δ_{S_i}+Δ_{S_j})/|𝒜|`。
于是，边缘化判定为兼容、而真实地图条件不兼容的概率被一个**边界带**与混叠指数共同控制：
```
P_false-compat ≤ P( compat_marg ∈ [θ_a, θ_a + 2(Δ_i+Δ_j)/|𝒜|] ) + P(ι_alias > Θ_alias)
```
这解释了第 54 轮“组合图误报”从何而来，并给出 E163 的直接检验对象：压缩 `Δ_S` 与 `ι_alias` 应让误报率单调下降。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 地图状态空间爆炸（`\|ℳ\|` 过大） | 高 | 语义等价类聚类 + 局部纤维采样 + 只在路线邻域展开 |
| 语义混叠被误判为可导航 | 高 | 顶视/外观硬负样本、主动探针、混叠指数入证书 |
| 主动修复振荡或预算耗尽 | 中 | 降熵阈值 ε + 最大轮数 + stalled 转保守 |
| 定位漂移使 `ψ` 非单调 | 高 | 多传感器锚点 + 漂移包络 + 超阈值拒绝下发 |
| 云边地图版本不一致 | 中 | 版本哈希 + `δ_M` 否决 + 地图级回滚 |

## 6. 本轮最大风险

**一句话**：把动作空间接到语义地图上、并让地图自身带证书与主动修复，能把第 54 轮的“虚假兼容”从采样问题提升为可诊断的地图分辨率问题；但最大风险是**语义地图是一个可自我一致的模型**——当定位漂移与感知混叠互相强化时，地图会“自圆其说”地给出一张内部一致却整体错误的世界图，此时 `M_cert` 与主动补图都会沿错误先验收敛，故必须引入**独立于地图的外部锚点（UWB/轮速/已知地标）与对抗性混叠探针**，宁可把不确定性留在地图上，也不让一张自洽的假图通过部署门槛。

## 2. 关键算法 伪代码

### IP-121 SMG

```python
def map_conditioned_profile(skill, M, sampler, m_states):
    alpha = {}
    for m in m_states:
        for a in sample(feasible_actions(M, m), sampler):
            alpha[(a.id, m.id)] = sampler.confidence(skill, a, m)
    alpha_bar = marginalize(alpha, weights=M.prior)
    gap = max(abs(alpha_bar[a] - alpha[(a, m)]) for (a, m) in alpha)
    return MapProfile(alpha, alpha_bar, gap)

def grounded_applicability(skill, M, m, A_T, theta_cov=0.8):
    return all(skill.alpha.get((a.id, m.id), 0.0) >= theta_cov for a in A_T)
```

### IP-122 SMC

```python
def semantic_map_certificate(M, calib_frames, alias_pairs):
    k_top = min(e.conf for e in M.G.edges)
    k_lab = min(v.label_conf for v in M.G.nodes)
    drift = max(localize_err(M.psi, f) for f in calib_frames)
    i_alias = max((sensor_similarity(M, u, v)
                   for (u, v) in alias_pairs if u != v), default=0.0)
    return MapCert(k_top, k_lab, drift, i_alias,
                   evidence=bundle(calib_frames, alias_pairs, M.version_hash))
```

### IP-123 MRC

```python
def map_conditioned_robustness(skill, m, dims, K_M, rho0):
    kappa = min(m.node_conf, m.edge_conf)
    return {d: rho0[skill][d] - K_M[d] * (1 - kappa) for d in dims}

def route_robustness(route, M, dims, K_M, rho0):
    per_node = [map_conditioned_robustness(M.skill_at(v), M.state(v),
                                           dims, K_M, rho0) for v in route]
    return {d: min(r[d] for r in per_node) for d in dims}
```

### IP-124 MSA

```python
def align_semantic_maps(M_c, M_e, delta_emb, theta_sem, theta_M):
    gamma, delta_M, divergence = {}, 0.0, {}
    for v in M_c.G.nodes:
        u = match_by_semantics(nearest_embed(M_c.emb[v], M_e),
                               M_c.L[v], M_e, within=delta_emb)
        gamma[v] = u
        d_emb = dist(M_c.emb[v], M_e.emb[u])
        d_sem = 1 - jaccard(M_c.L[v], M_e.L[u])
        divergence[v] = d_sem
        delta_M = max(delta_M, d_emb + lambda_s * d_sem)
    bad = [v for v, d in divergence.items() if d > theta_sem]
    return (delta_M <= theta_M and not bad), gamma, delta_M, divergence, bad
```

### IP-125 AMR

```python
def active_map_repair(M, explain, budget, eps, max_rounds=3):
    V_bad = explain.root_cause_nodes(M)
    if not V_bad:
        return ('noop', M, semantic_map_certificate(M, [], []))
    for _ in range(max_rounds):
        cands = [O for O in candidate_observations(V_bad, M)
                 if obs_cost(O) <= budget]
        if not cands:
            return ('exhausted', M, None)
        O = max(cands, key=lambda o: expected_information_gain(M, o, V_bad))
        M2 = bayesian_relabel(M, O, execute_observation(O))
        if entropy(M2) > (1 - eps) * entropy(M):
            return ('stalled', M2, None)          # 转保守模式
        M = M2
    return ('repaired', M, semantic_map_certificate(M, [], []))
```

### IP-126 TAG

```python
def ground_semantic_route(route_sem, M, gamma_ce, sampler, theta_cov):
    P_e = []
    for (v_prev, v_next) in edges(route_sem):
        m = M.state(v_next)
        if not M.nav(v_next):
            return ('reject', 'unreachable', v_next)
        alpha = map_conditioned_profile(skill_for(v_next), M, sampler, [m])
        for a_c in semantic_coarse_actions(v_prev, v_next):
            a_e = gamma_ce(a_c, m)
            if alpha.alpha.get((a_e.id, m.id), 0.0) < theta_cov:
                return ('reject', 'grounding_gap',
                        (v_next, a_e), explain_grounding(M, v_next, a_e, a_c))
            P_e.append((v_next, a_c, a_e, m.id))
    return ('ok', P_e)
```

def joint_certificate_v32(skill_seq, route, M, gamma_ce, M_cert,
                          delta_a_budget, rho_min):

## 3. 关键推导：虚假兼容上界（E163 的理论靶）

设 `compat_marg` 为第 54 轮用 `ᾱ_S` 算出的兼容性，`compat_m` 为真实地图条件兼容性，`Δ_S = sup_{a,m}|α_S(a,m)−ᾱ_S(a)|`。Jaccard 对剖面 L1 扰动满足
```
|compat_m(S_i,S_j) − compat_marg(S_i,S_j)| ≤ 2(Δ_{S_i}+Δ_{S_j}) / |𝒜|
```
因此
```
P_false-compat ≤ P( compat_marg ∈ [θ_a, θ_a + 2(Δ_i+Δ_j)/|𝒜|] )
                  + P(ι_alias > Θ_alias)
```
该上界把第 54 轮的组合误报拆成两项可分别干预的项：**剖面混叠误差**（降低 `Δ_S`：更细的地图状态、更多纤维采样）与**感知混叠**（降低 `ι_alias`：硬负样本、主动探针）。E163 通过分别扫动两项验证其单调性。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SMG | O(\|ℳ_s\|·\|𝒜_m\|·\|S\|) | O(\|𝒜\|·\|ℳ_s\|) | 纤维采样覆盖 ≥ 95%，`gap_alias` 有界 |
| SMC | O(\|V_M\|+\|E_M\|+\|Alias\|) | O(\|V_M\|+\|E_M\|) | 标定独立、置信度校准 |
| MRC | O(\|route\|·\|𝔇_ρ\|) | O(\|𝔇_ρ\|) | `K_M` 单调、最弱边取 min |
| MSA | O(\|V_M\|·log\|V_M\|) | O(\|V_M\|) | 几何+语义双门、`δ_M` 有界 |
| AMR | O(R·\|O_cand\|·IG) | O(\|V_bad\|+\|O_cand\|) | 每轮降熵 ≥ ε，R≤max_rounds |
| TAG | O(\|route\|·\|𝒜_m\|) | O(\|𝒜_m\|) | 接地覆盖、可导航性闭合 |

**正确性定理（Map-Grounded Navigation Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `α_S(a,m)` 对 `m` 为 ξ-Lipschitz 且 `ψ_drift ≤ Δ_ψ`；**(A30)** `M_cert` 各分量可独立校准，`ι_alias < 1`；**(A31)** AMR 每轮降熵 ≥ ε 且在 `τ_repair` 内收敛。则通过双重证书（`J_v32` 与 `M_cert`）的计划满足：
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − P(δ_a > Θ_a)
            − Σ_{v∈route}(1−κ_top(v)) − P(ι_alias > Θ_alias) − P(δ_M > Θ_M)
```
其中 `Σ_v(1−κ_top(v))` 是路线最弱地图边的 union bound，`P(δ_M>Θ_M)` 是云边地图不同源导致的结构性否决概率。

## 6. 本轮最大风险

**一句话**：把动作空间接到语义地图上、并让地图自身带证书与主动修复，能把第 54 轮的“虚假兼容”从采样问题提升为可诊断的地图分辨率问题；但最大风险是**语义地图是一个可自我一致的模型**——当定位漂移与感知混叠互相强化时，地图会“自圆其说”地给出一张内部一致却整体错误的世界图，此时 `M_cert` 与主动补图都会沿错误先验收敛，故必须引入**独立于地图的外部锚点（UWB/轮速/已知地标）与对抗性混叠探针**，宁可把不确定性留在地图上，也不让一张自洽的假图通过部署门槛。
