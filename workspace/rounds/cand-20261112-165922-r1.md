# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；新灵感循环第 1 轮；本轮灵感：「指令泛化」×「演示方案」）

> 第 60 轮把「场景语义 SSM → 认知意图 CIEC → 实时约束锁定 → 阻抗编译 → EV-exec 证据链」串成了 SERC 闭环，安全性来自「场景置信度回退 + 约束锁定 + EPIR 双保险 + SIC 三元校验」。但**三个结构性缺口**被这一轮的成功掩盖了：
> 1. **指令泛化是查找表伪装成的理解**：CIEC 的意图集 `I = {'slow','light','stable','danger'}` 与映射 `ϕ` 是一张有限字典。比赛现场的指令是开放、组合、带指代与歧义的（「轻一点但别松手」「绕过杯子把盒子推过去」）。未收录指令会静默落到 `mapping.get(intent, {})` 的 `{}`——系统既不报错也不澄清，产生**「看起来听懂了、其实没约束」的静默失效**。
> 2. **演示方案与安全机制割裂**：第 60 轮有大量在线安全机制，却没有一个可复现、可审计、能把「泛化」演示出来的方案。绝大多数 Demo 只跑脚本化金路径，证明的是「背台词」而非「会迁移」；而**演示数据本身是最廉价、最贴近真实分布的监督信号**，却被完全浪费。
> 3. **泛化与安全的内在对立没有形式化**：把自然语言直接映射为大模型输出的参数，天然可能**扩张**约束（例如把「轻放但压住」误读成「加大力」），一旦越出 `K_safe`，第 60 轮再精密的事后护栏也只能事后补救。缺少一种「任何解析结果都不可能撑破安全包络」的**构造性保证**。

## 0. 直觉与动机

**灵感 1（指令泛化 → 组合式指令语法 CIS）**
直觉：人对新指令的理解不是「检索相似句」，而是**把句子拆成有限个修饰子再组合**。「稍微快一点」= 速度修饰子(+小, 方向↑)；「轻触但稳住」= 力修饰子(上限↓) ∧ 柔顺修饰子(阻尼↑) ∧ 谨慎修饰子(↑)。关键洞见：**泛化的单位不是句子，而是「修饰子组合的覆盖度」**——只要新指令能被已有修饰子 + 有限组合算子解析，它就是「被覆盖的泛化」，而不是「没见过的句子」。

**灵感 2（安全泛化 → 指令-约束代数 ICA）**
直觉：如果每个修饰子对 ERTC 契约的作用都是**单调且收缩**的（只做交集、只收紧上下界），那么无论解析对错，组合结果一定是基础安全契约 `C_base` 的子集。**错误只能让机器人「更保守/更差」，永远不能让它「更放得开」**。关键洞见：把「语义理解的不确定性」转译为「可行域的单调收缩」，用代数结构把安全事故转化为性能损失。

**灵感 3（演示方案 → 演示即规约 DCL）**
直觉：与其人工标注「这句话→什么参数」，不如让人示教同一指令在多种场景下的轨迹，反推「该修饰子的可行约束多面体」。演示给出的是**约束的边界证据**（哪些力/速度/柔顺度被人类接受），不是离散标签。关键洞见：**指令泛化 = 修饰子约束的可分解迁移**；若组合约束可因子化到修饰子上，就能对未见指令做最小一致包络外推。

**灵感 4（演示方案 → 可复现演示协议 RDP）**
直觉：竞赛 Demo 的价值不在于「一次成功」，而在于**可复现地展示「在留出组合上仍然成功、失败时优雅降级」**。把演示拆成三条道：金路径（脚本化、低风险）、泛化探针（现场留出的指令×场景组合）、故障注入（ROS 丢包、场景突变、歧义指令）。关键洞见：**演示方案本身应是一个带覆盖矩阵与不变量的实验设计**，而不是演出脚本。

**灵感 5（风险控制 → 新颖性门控 NG × 演示预算 DBR）**
直觉：泛化必须承认「不知道自己不知道」。当解析只用已知修饰子且置信度足够时放行；当出现未知修饰子/低置信解析时，走**澄清或保守默认**，绝不静默外推。同时给「未脚本化探针」设风险配额，按「单位风险覆盖增益」挑选探针。关键洞见：**把「会不会泛化」变成可测量的 IGG，把「敢不敢泛化」变成可预算的风险配额**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（组合式指令语法 CIS）** 指令泛化系统 `G = (P, Ω, Parse, 𝓘)`：
- **修饰子集**：`P = {p_speed, p_force, p_compliance, p_caution, p_scope}`，每个修饰子取值 `v_p ∈ ℝ ∪ {↑,↓,0}` 或枚举标签。
- **组合算子集**：`Ω = {∘_seq, ∘_and, ∘_scope}`（顺序、合取、作用域绑定），带类型以避免角色混淆（「把 B 放到 A 上」≠「把 A 放到 B 上」）。
- **解析器**：`Parse: 𝓘 → (G_parse, θ)`，`G_parse` 是修饰子构成的有向无环组合图，`θ` 为数值参数。
- **覆盖度**：`cov(I) = 1 − novelty_mass(Parse(I))`，其中 `novelty_mass` 由「未见修饰子质量 + 未见组合算子质量」加权。
- **可泛化判定**：`I'` 被覆盖当且仅当 `Parse(I')` 仅使用 `P` 与 `Ω`，且 `cov(I') ≥ c_min`。

**定义 162（指令-约束代数 ICA）** 给定基础安全契约 `C_base = ERTC 可行域 ∩ K_safe^scene`（承接第 60 轮），每个修饰子 `p` 与参数 `v` 诱导算子 `T_p(v): 2^{C_base} → 2^{C_base}`，满足：
- **收缩性（deflationary）**：`∀C ⊆ C_base, T_p(v)(C) ⊆ C`；
- **单调性**：`C₁ ⊆ C₂ ⇒ T_p(v)(C₁) ⊆ T_p(v)(C₂)`；
- **指令语义**：`C(I) = ⋂_{p∈G_parse} T_p(θ_p)(C_base)`。
- **命题 61-A（安全保序）**：对任意（可被解析的）指令 `I`，`C(I) ⊆ C_base`。证明：由收缩性逐项归纳 + 交集子集。**推论**：解析错误只能导致过度约束，不能扩张安全包络。
- **命题 61-B（顺序无关）**：因交集满足交换律与幂等律，`C(I)` 与组合图遍历顺序无关，故 ROS 异步/乱序不改变约束语义。

**定义 163（演示规约学习 DCL）** 演示集 `D = {(ξ_j, I_j, s_j)}_{j=1..n}`（轨迹、指令、场景）。对指令 `I`：
- **一致参数集**：`V(I) = {θ : ∀j, I_j = I ⇒ ξ_j ∈ Feasible(C(I; θ))}`。
- **选择规则**：`θ*_I = argmax_{θ ∈ V(I)} |C(I; θ)|`，即「与全部演示一致的最宽松约束」（安全性已由 `C_base` 与 ICA 保证，此处只最大化任务性能），并要求演示充分性 `n ≥ n_min` 且修饰子覆盖达标。
- **可分解迁移**：若约束可因子化，则未见指令 `I'` 的参数由修饰子参数合并 `θ*_{I'} = ⨁_{p∈G_parse(I')} θ*_p`，`⨁` 对「上限类」取 min、对「增益类」取 max、对「谨慎类」取 max，且 `⨁` 满足结合律。
- **假设 A-DCL（可分解性）**：组合指令的可行约束可写成各修饰子约束的交；违反该假设时退回 `C_default` 并标记「不可因子化」。

**定义 164（指令泛化度量 IGG）** 设 `R(I)` 为指令 `I` 的执行风险（失败/代价的期望），`𝓘_ID`/`𝓘_OOD` 为分布内/外指令集：
- **泛化间隙**：`IGG = sup_{I'∈𝓘_OOD} [R(I') − R_ID]`。
- **泛化证书**：若 `IGG ≤ ε_IGG` 且 `∀I'∈𝓘_OOD: cov(I') ≥ c_min`，则签发 `Cert_gen`。
- **经验估计**：用「留出修饰子组合」交叉验证，测量 `ÎGG` 及其置信上界。

**定义 165（新颖性门控 NG）** 新颖度 `ν(I) = 1 − max_{I_j∈D} sim(Parse(I), Parse(I_j))`，`sim` 为组合图上的结构相似度。门控规则：
```
if cov(I) < c_min or parse_conf(I) < τ_parse or ν(I) > τ_new:
    if 指令涉及安全关键动作: return CLARIFY(I)        # 澄清
    elif 有保守默认:            return C_default       # 默认约束
    else:                       return REFUSE
else:
    return C(I)
```
关键性质：**NG 阻止任何未覆盖解析的静默外推**，把「不知道」显式暴露为一次澄清或一次保守降级。

**定义 166（可复现演示协议 RDP）** 演示方案 `Π = ⟨(s_k, I_k, Inv_k, Seed_k, Lane_k)⟩_{k=1..K}`：
- **三车道**：`L1` 金路径（脚本化、低风险、必过）；`L2` 泛化探针（现场留出的修饰子×场景组合）；`L3` 故障注入（ROS 丢包、场景突变、歧义指令）。
- **覆盖矩阵**：`M[p, s] ∈ {0,1}` 记录「修饰子 p 在场景 s 是否被演示覆盖」，`Coverage(Π) = Σ M / |P|·|S|`。
- **不变量**：`Inv_k` 为每条演示必须成立的安全/正确性断言（如 `F ≤ F_max`、证据链完整、约束不越界）。
- **可复现性**：`Seed_k`、场景包哈希 `H(s_k)`、回放日志；判定 `pass_k = Inv_k ∧ 成功准则`，且重放差异须为零。
- **泛化演示分**：`GDS = (L2 无澄清通过数 + 正确门控数) / |L2|`。

**定义 167（演示预算与风险配额 DBR）** `B_demo = (B_try, B_clarify, B_abort)`：
- 每个 L2 探针消耗风险配额 `risk(I) = UB(IGG | Parse(I))`；选择规则为
  `argmax_{I} ΔCoverage(I) / (risk(I)+ε)`，即「单位风险覆盖增益」。
- 若 `B_try` 或风险余量不足：探针转「影子模式」（只推理不执行）或跳过；若 `B_clarify` 耗尽：强制 `C_default`。

**定义 168（DIGL 闭环算子）** 算子 `DIGL(M, I, s, D)`：
```
① Parse: (G_parse, θ) ← CIS.Parse(I)
② Gate:  if NG.novel(G_parse, θ): return (CLARIFY | C_default | REFUSE)
③ Compose: C(I) ← ICA.compose(G_parse, θ, C_base)
④ Transfer: θ*_{I} ← DCL.transfer(G_parse, D)    # 可分解迁移
⑤ Execute: ξ ← ERTC.run(C(I) ∩ C(I; θ*), scene=s)  # 复用第 60 轮 SERC
⑥ Evidence: EV ← build_exec_evidence(ξ); EPIR.append(EV)
⑦ Learn: D ← D ∪ {(ξ, I, s)}; DCL.update(D)        # 演示即训练
⑧ Gauge: ÎGG ← IGG.estimate(D, held_out_combos)
⑨ Return: (C(I), ξ, EV, Cert_gen, ÎGG)
```

## 2. 关键算法伪代码

### IP-161 CIS（组合式指令语法）

```python
PRIMITIVES = ['speed', 'force', 'compliance', 'caution', 'scope']
OPS = ['seq', 'and', 'scope']

class CompositionalInstructionSyntax:
    def __init__(self, tau_parse=0.6):
        self.tau_parse = tau_parse
        self.primitives = PRIMITIVES

    def parse(self, text, context):
        nodes = self._extract_modifiers(text)       # 语义+词法+上下文
        graph = self._build_dag(nodes, OPS)         # 类型检查
        used = {n.primitive for n in graph.nodes}
        novelty = 1.0 - len(used & set(self.primitives)) / len(self.primitives)
        conf = self._parse_confidence(graph)
        return ParseResult(graph=graph, novelty=novelty, confidence=conf,
                           coverage=1.0 - novelty)
```

### IP-162 ICA（指令-约束代数）

```python
class InstructionConstraintAlgebra:
    def __init__(self, c_base):
        self.C_base = c_base

    def T(self, primitive, value, C):
        # 全部算子只做「交集式收紧」，禁止扩张
        if primitive == 'force':
            return C.intersect(F_upper=min(C.F_max, value))
        if primitive == 'speed':
            return C.intersect(V_upper=min(C.v_max, value))
        if primitive == 'compliance':
            return C.intersect(K_p_upper=min(C.K_p, value),
                               K_d_lower=max(C.K_d, value))
        if primitive == 'caution':
            return C.intersect(F_tol=min(C.F_tol, value),
                               eps=min(C.eps_traj, value))
        if primitive == 'scope':
            return C.bind_region(value)
        return C

    def compose(self, graph, theta, C_base):
        C = C_base
        for node in graph.topo_order():          # 顺序无关
            C = self.T(node.primitive, theta[node.id], C)
        assert C.subset_of(C_base)               # 命题 61-A 运行时断言
        return C
```

### IP-163 DCL（演示规约学习）

```python
class DemonstrationConstrainedLearner:
    def __init__(self, n_min=3):
        self.n_min = n_min
        self.V = defaultdict(list)               # primitive -> feasible params
        self.demos = []

    def update(self, demo):
        self.demos.append(demo)
        if demo.instruction_is_decomposable:
            for p, v in demo.primitive_params.items():
                if self._consistent(p, v, demo.trajectory):
                    self.V[p].append(v)

    def transfer(self, graph):
        params = {}
        for p in graph.primitives:
            vals = self.V.get(p, [])
            if len(vals) < self.n_min:
                return None                      # 不满足可分解性/充分性
            params[p] = self._merge(p, vals)     # 上限 min / 增益 max
        return params

    def _merge(self, p, vals):
        return min(vals) if p in ('force', 'speed', 'compliance') else max(vals)
```

### IP-164 NG（新颖性门控）

```python
class NoveltyGate:
    def __init__(self, c_min=0.5, tau_new=0.4):
        self.c_min, self.tau_new = c_min, tau_new

    def decide(self, parse, safety_critical):
        if parse.coverage < self.c_min or parse.novelty > self.tau_new \
           or parse.confidence < self.tau_parse:
            if safety_critical:
                return GateDecision.CLARIFY
            return GateDecision.DEFAULT if self.has_default else GateDecision.REFUSE
        return GateDecision.ACCEPT
```

### IP-165 RDP（可复现演示协议）

```python
LANES = ['golden_path', 'generalization_probe', 'fault_injection']

class ReproducibleDemoProtocol:
    def __init__(self, scene_pack, seeds):
        self.scene_pack = scene_pack
        self.seeds = seeds
        self.coverage = np.zeros((len(PRIMITIVES), len(scene_pack.scenes)))

    def run(self, demo):
        try:
            result = self._replay(demo, seed=demo.seed)
            ok = all(inv.check(result) for inv in demo.invariants)
            self.coverage[demo.primitive_idx, demo.scene_idx] = int(ok)
            return DemoOutcome(demo.id, ok, result.log_hash)
        except SafetyViolation:
            return DemoOutcome(demo.id, False, 'ABORT')
```

### IP-166 DIGL（闭环）

```python
def demonstration_induced_generalization_loop(M, instruction, scene, D):
    parse = M.cis.parse(instruction, context=scene)
    gate = M.ng.decide(parse, safety_critical=scene.is_safety_critical)
    if gate is not GateDecision.ACCEPT:
        return gate, None
    C = M.ica.compose(parse.graph, parse.theta, M.c_base)
    theta = M.dcl.transfer(parse.graph)
    if theta is not None:
        C = C.intersect(M.ica.compose(parse.graph, theta, M.c_base))
    xi = M.ertc.run(C, scene=scene)
    ev = build_exec_evidence(xi)
    M.epir.append(ev)
    D.add((xi, instruction, scene))
    M.dcl.update(D[-1])
    igg = M.igg.estimate(D, held_out=M.held_out_combos)
    return C, CertGen(igg, coverage=parse.coverage)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CIS | O(|G_parse|) 解析 | O(|P|+|Ω|) | 覆盖度 `cov` 可计算；角色混淆由类型系统排除 |
| ICA | O(|G_parse|·d) 交集 | O(d) | `C(I) ⊆ C_base`（命题 61-A）；顺序无关（61-B） |
| DCL | O(n) 更新 / O(|P|) 迁移 | O(n·d) | 与演示一致；可分解性假设下泛化到未见组合 |
| NG | O(1) 门控 | O(1) | 未覆盖解析零静默外推 |
| RDP | O(K) 回放 | O(K·L) | 覆盖矩阵 + 不变量 + 重放零差异 |
| DIGL | O(闭环) | 复用 | 泛化间隙 `IGG ≤ ε_IGG` 时签发证书 |

**正确性定理（DIG）**：假设 A61–A68 成立：
- **(A66)** CIS：任意可解析指令的 `used ⊆ P`，`cov` 与 `parse_conf` 可观测。
- **(A67)** ICA：所有 `T_p` 收缩且单调；`C_base` 为第 60 轮已证明的安全包络。
- **(A68)** DCL：演示满足可分解性（A-DCL）且每个修饰子样本数 `≥ n_min`；IGG 可由留出组合无偏估计。

则：
1. **构造性安全泛化**：`∀I, C(I) ⊆ C_base`，即任何解析错误不扩张安全包络（命题 61-A）。
2. **组合稳健性**：约束结果与组合算子执行顺序无关，ROS 乱序不改变语义（命题 61-B）。
3. **泛化可证**：若 `IGG ≤ ε_IGG` 且 `cov ≥ c_min`，则未见指令集合上的超额风险有界，签发 `Cert_gen`。
4. **诚实降级**：未覆盖/低置信指令必触发 NG 的澄清/默认/拒绝，不发生静默外推。

### IP-161 CIS（组合式指令语法）

```python
PRIMITIVES = ['speed', 'force', 'compliance', 'caution', 'scope']
OPS = ['seq', 'and', 'scope']

class CompositionalInstructionSyntax:
    def __init__(self, tau_parse=0.6):
        self.tau_parse = tau_parse
        self.primitives = PRIMITIVES

    def parse(self, text, context):
        nodes = self._extract_modifiers(text)       # 语义+词法+上下文
        graph = self._build_dag(nodes, OPS)         # 类型检查，防角色混淆
        used = {n.primitive for n in graph.nodes}
        novelty = 1.0 - len(used & set(self.primitives)) / len(self.primitives)
        conf = self._parse_confidence(graph)
        return ParseResult(graph=graph, novelty=novelty, confidence=conf,
                           coverage=1.0 - novelty)

    def _build_dag(self, nodes, ops):
        # 作用域绑定：把「把 B 放到 A 上」与「把 A 放到 B 上」区分为不同图
        return TypedDAG(nodes, ops).validate()
```

### IP-162 ICA（指令-约束代数）

```python
class InstructionConstraintAlgebra:
    def __init__(self, c_base):
        self.C_base = c_base

    def T(self, primitive, value, C):
        # 全部算子只做「交集式收紧」，禁止扩张
        if primitive == 'force':
            return C.intersect(F_max=min(C.F_max, value))
        if primitive == 'speed':
            return C.intersect(v_max=min(C.v_max, value))
        if primitive == 'compliance':
            return C.intersect(K_p=min(C.K_p, value), K_d=max(C.K_d, value))
        if primitive == 'caution':
            return C.intersect(F_tol=min(C.F_tol, value),
                               eps=min(C.eps_traj, value))
        if primitive == 'scope':
            return C.bind_region(value)
        return C

    def compose(self, graph, theta, C_base):
        C = C_base
        for node in graph.topo_order():          # 顺序无关（命题 61-B）
            C = self.T(node.primitive, theta[node.id], C)
        assert C.subset_of(C_base)               # 命题 61-A 运行时断言
        return C
```

### IP-163 DCL（演示规约学习）

```python
class DemonstrationConstrainedLearner:
    def __init__(self, n_min=3):
        self.n_min = n_min
        self.V = defaultdict(list)               # primitive -> feasible params
        self.demos = []

    def update(self, demo):
        self.demos.append(demo)
        if demo.instruction_is_decomposable:
            for p, v in demo.primitive_params.items():
                if self._consistent(p, v, demo.trajectory):
                    self.V[p].append(v)

    def transfer(self, graph):
        params = {}
        for p in graph.primitives:
            vals = self.V.get(p, [])
            if len(vals) < self.n_min:
                return None                      # 可分解性/充分性不满足
            params[p] = self._merge(p, vals)
        return params

    def _merge(self, p, vals):
        # 上限类取 min 更安全；增益类取 max 更贴合人类演示
        return min(vals) if p in ('force', 'speed', 'compliance') else max(vals)

    def _consistent(self, p, v, trajectory):
        return trajectory.satisfies(self._constraint(p, v))
```

```python
class NoveltyGate:
    def __init__(self, c_min=0.5, tau_new=0.4, tau_parse=0.6):
```

### IP-165 RDP（可复现演示协议）

```python
LANES = ['golden_path', 'generalization_probe', 'fault_injection']

class ReproducibleDemoProtocol:
    def __init__(self, scene_pack):
        self.scene_pack = scene_pack
        self.coverage = np.zeros((len(PRIMITIVES), len(scene_pack.scenes)))

    def run(self, demo):
        try:
            result = self._replay(demo, seed=demo.seed)
            ok = all(inv.check(result) for inv in demo.invariants)
            self.coverage[demo.primitive_idx, demo.scene_idx] = int(ok)
            return DemoOutcome(demo.id, ok, result.log_hash)
        except SafetyViolation:
            return DemoOutcome(demo.id, False, 'ABORT')

    def generalization_demo_score(self, l2_outcomes):
        passed = sum(o.ok for o in l2_outcomes if o.lane == 'generalization_probe')
        gated = sum(o.gated_correctly for o in l2_outcomes)
        return (passed + gated) / max(1, len(l2_outcomes))

    def replay_diff(self, demo):
        a = self._replay(demo, seed=demo.seed).log_hash
        b = self._replay(demo, seed=demo.seed).log_hash
        return 0 if a == b else 1
```

### IP-166 DBR（演示预算与风险配额）

```python
class DemonstrationBudget:
    def __init__(self, b_try=5, b_clarify=3, b_abort=1):
        self.B_try, self.B_clarify, self.B_abort = b_try, b_clarify, b_abort
        self.used_try = self.used_clarify = self.used_abort = 0

    def select_probe(self, candidates, risk_ub, coverage_gain):
        scored = [(coverage_gain[c] / (risk_ub[c] + 1e-6), c) for c in candidates]
        scored.sort(reverse=True)
        return scored[0][1] if scored and self.used_try < self.B_try else None

    def consume(self, kind):
        if kind == 'try' and self.used_try < self.B_try:
            self.used_try += 1; return True
        if kind == 'clarify' and self.used_clarify < self.B_clarify:
            self.used_clarify += 1; return True
        return False
```

### IP-167 DIGL（闭环）

```python
def demonstration_induced_generalization_loop(M, instruction, scene, D):
    parse = M.cis.parse(instruction, context=scene)
    gate = M.ng.decide(parse, safety_critical=scene.is_safety_critical)
    if gate is not GateDecision.ACCEPT:
        return gate, None
    C = M.ica.compose(parse.graph, parse.theta, M.c_base)
    theta = M.dcl.transfer(parse.graph)
    if theta is not None:
        C = C.intersect(M.ica.compose(parse.graph, theta, M.c_base))
    xi = M.ertc.run(C, scene=scene)
    ev = build_exec_evidence(xi)
    M.epir.append(ev)
    D.add((xi, instruction, scene))
    M.dcl.update(D[-1])
    igg = M.igg.estimate(D, held_out=M.held_out_combos)
    return C, CertGen(igg, coverage=parse.coverage)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| CIS | O(|G_parse|) | O(|P|+|Ω|) | 覆盖度可计算；角色混淆由类型系统排除 |
| ICA | O(|G_parse|·d) | O(d) | `C(I) ⊆ C_base`；顺序无关 |
| DCL | O(n) / O(|P|) | O(n·d) | 与演示一致；可分解迁移 |
| NG | O(1) | O(1) | 未覆盖解析零静默外推 |
| RDP | O(K) | O(K·L) | 覆盖矩阵 + 不变量 + 重放零差异 |
| DIGL | O(闭环) | 复用 | `IGG ≤ ε_IGG` 时签发证书 |

**正确性定理（DIG）**：若 A66–A68 成立，则：
1. **构造性安全泛化**：`∀I, C(I) ⊆ C_base`（命题 61-A：收缩算子 + 交集）。
2. **组合稳健性**：约束与组合遍历顺序无关（命题 61-B：交集交换/幂等），ROS 乱序不改变语义。
3. **泛化可证**：`IGG ≤ ε_IGG ∧ cov ≥ c_min ⇒ Cert_gen`，OOD 超额风险有界。
4. **诚实降级**：未覆盖/低置信指令必触发 NG，澄清/默认/拒绝三选一。

**命题 61-A（安全保序）证明**：对 `C_base` 逐项施加收缩算子 `T_p`，由 deflationary 得每次结果仍为前一次的子集；有限次后 `C(I) = ⋂ T_p(...) ⊆ C_base`。∎

**命题 61-B（顺序无关）证明**：`T_p` 作用于约束的分量上下界，交集满足交换律与幂等律，故按任意拓扑序求交结果相同。∎
