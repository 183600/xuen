# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 1 轮；本轮灵感：「场景理解」×「技术融合」）

> R72 把 GAUGE 从「认知层审计」下沉为「具身实时闭环」（REG×IRL×DMEM×EREFLEX×ERVOI×S2R-UQ），确立了「调度即可信」「意图进风险分母」「接触四分量」「三域分离」。但 R72 仍有两个未开箱的假设：
> - **场景理解（Scene Understanding）视角**：R72 的 s 是一个**无结构的物理状态向量**，默认「观测—状态」是点对点映射。真实场景里，机器人面对的从来不是孤立的状态，而是**结构化的场景**：有哪些物体/部件、谁支撑谁、谁装在谁里、谁被谁挡住、每个部件有什么可供性（可抓/可推/可切/可承重/易碎/烫）、自由空间在哪、哪些区域未被观测。这些是**解释所有底层观测的先验**。场景先验一旦错（把「电熨斗」认成「鼠标」、把「支撑」认成「相邻」、把「虚掩的抽屉」认成「关着的」），**所有下游证据会被同一个错误先验同时污染**：意图 z 被错误可供性诱导、接触 c 被错误部件几何诱导、风险 λ 被错误材质诱导。更糟的是，**场景理解器（多为基础模型）会语义幻觉**：以高置信输出物理上荒谬的场景图，而 ECE/不变性审计只测「识别得准不准」，测不出「**共同模式的错**」。
> - **技术融合（Technology Fusion）视角**：R72 的融合是**隐式的、无溯源的、默认条件独立的**（视觉×语言×触觉×本体×世界模型×意图识别器一起乘）。但真实的多技术栈**高度相关**：同一个 foundation model 提供语义先验、同一批标注数据训练多个 head、同一套标定祖先派生多个传感器通道、同一个仿真器生成 sim2real 参数。**相关误差下做朴素乘积融合，方差会按 1/N 塌缩，但偏差不塌缩**——证书上的 `u` 越来越小、置信区间越来越窄、真实误差却纹丝不动。这是一种新型 Goodhart：**「不确定性洗白」（uncertainty laundering）**——系统不是自信于正确，而是**自信于「融合后的数字很小」**。
>
> 本轮两个灵感正好补两块，且互为因果：
> - **场景理解**：把世界状态升级为**结构化场景潜变量 g**（场景图 + 关系 + 可供性场 + 自由/未知空间），引入**场景证据模型 p_scene(y|g,s,ψ)**、**场景不确定度五分量** u_scene、**共同模式语义偏置** b_cm 的显式度量；场景不确定度进入**风险缩放分母**与**非补偿性否决**。
> - **技术融合**：把隐式融合升级为**可追溯的融合代数**：provenance DAG、**认知独立性证书 κ**、**相关感知保守融合（CI + 共同模式地板）**、**不确定性洗白检测器 L**、**跨技术时延对齐 u_sync**、**融合非补偿性否决**（融合不能把任一源的否决平均掉）。
>
> 核心命题：**R72 问「我的测量链在实时调度/模糊意图/灵巧接触下能否兑现风险界」；R73 再问「当我的测量链本身建立在一张可能幻觉的场景图上、又由一群共享先验的技术拼合而成时，融合出来的『小不确定度』到底是真信息，还是相关误差制造的幻觉？」** 把 R72 的 EMBODIED-GAUGE 升级为 **SCENE-FUSION-GAUGE-RAS**（Scene-grounded, Fusion-audited, Common-mode-aware GAUGE for RAS）——**场景落地 × 融合可审计的计量闭环**。

## 0. 直觉与动机

**灵感 1（场景理解 → 场景不是「又一个观测」，是「解释所有观测的先验」）**
直觉：R72 把视觉/语言/触觉都当成 `y`，各自有一个似然，然后乘起来。但人看到「桌上有只马克杯」时，这不是一个观测，而是一个**解释框架**：它同时告诉你「可以抓杯柄」「杯里有液体所以要竖直」「杯子在桌沿所以先别碰桌」「桌下是未知而不是空」。场景理解输出的是一张**场景图** `g = (O, R, A, F)`：物体/部件节点 O、空间-功能关系 R（支撑/容纳/遮挡/相邻/可及）、可供性场 A（可抓/可推/可切/可承重/易碎/危险）、自由/未知空间 F。**g 错了，不是「某个 y 噪声大」，而是「所有 y 被同一个错误先验同向拉扯」。** 这是 R72 的独立噪声模型**根本无法表达**的错误结构。

**灵感 2（技术融合 → 融合不是免费降方差，相关误差下融合制造虚假确定性）**
直觉：我们习惯「多传感器融合更准」。这只在**误差独立**时成立。若几何、语义、触觉、语言、世界模型共享同一套训练数据/同一 foundation model/同一标定祖先，它们的误差是**相关**的。设 N 个源的估计为 `x_i = θ + b_cm + ε_i`，`ε_i` 独立、`b_cm` 是共同模式偏置。朴素平均的方差 = `σ²/N + u_cm²`——**N 再大，也只能消掉 σ²/N，消不掉 u_cm²**。可信区间会收缩到 `u_cm` 附近并围绕一个错误值。这就是 **1+1 < 1 的融合幻觉**：融合让数字更漂亮，却没让世界更清楚。

**灵感 3（不确定性洗白 → 对「u」做 Goodhart，比对自己的错误还危险）**
直觉：R72 的整套证书建立在「u 是真不确定度」上。若融合层用相关误差把 u 压低，那么 IVG 门控、λ_floor、VoI 增益、证书有效性**全部被同一个被低估的 u 骗过**。系统会进入一种**「全绿」的退化**：所有指标都在阈值内，所有契约都通过，所有证书都盖章——因为**度量本身被融合洗白了**。必须在融合层引入**独立于融合的覆盖性审计**（SEAL-Scene 上的经验覆盖率），并设**共同模式地板** `u ≥ u_cm_floor`，让融合永远不能把 u 压到地板以下。

**灵感 4（共同模式语义偏置 → 多模态投票救不了共享先验）**
直觉：我们天然想「多模态投票」来抗幻觉。但如果所有模态都通过同一个场景图/同一个 foundation model 解释世界，投票是**相关投票**：它们会一致地错。因此**语义幻觉不能靠「再多一个模态」解决，只能靠「与先验无关的外部锚点」解决**：物理交互探针（去碰一下）、独立标定的几何测量、隐藏审计集、跨本体/跨场景的不变性检验。**融合的价值不在于「更多源」，而在于「源之间的独立性能被证明」。**

**灵感 5（场景条件化 → g 同时改写意图、接触与风险）**
直觉：R72 里 z、c、s 近似并列。但场景 `g` 是**条件层的条件**：桌上没有可抓的杯柄时，「递给我」这个意图的可供性不成立（应改为「问」或「换目标」）；部件是薄壁易碎时，「捏」这个接触模式危险；地面是湿滑材质时，同样 λ 下应更保守。因此 `p(z|g)`、`p(c|g,part)`、`λ(g)` 都必须显式条件化。**场景不是背景板，是安全约束的生成器。**

**灵感 6（技术融合的时序 → 10Hz 的场景图与 1kHz 的控制不在同一时间刻度）**
直觉：场景理解通常 5–15Hz、触觉 200Hz、控制 1kHz、语言事件触发。融合这些异步技术时，控制域读到的是**不同时刻的世界快照**。若用「最新到达」拼一个场景图，会引入**时序错位不确定度** u_sync：物体在移动、人在改主意、手在滑移，而场景图还停留在 80ms 前。必须**按时间戳对齐 + 外推不确定度**，并把 u_sync 显式并入融合不确定度与 λ。**融合的正确性首先是时间上的正确性。**

## 1. 形式化定义（增量：定义 366–385）

**定义 366（SCENE-FUSION-GAUGE-RAS 总览与六不变式）** SCENE-FUSION-GAUGE-RAS = (SGR, SCM, FUSE, EIC, ULD, TFA, GAUGE-RAS†)。六不变式：
(i) **场景结构化**：世界状态必须携带场景图后验 b_t(g)（物体/关系/可供性/自由空间），禁止把 g 折叠回无边界的 s；
(ii) **融合可追溯**：任何被融合的估计必须携带 provenance DAG 与认知独立性证书 κ；无溯源不融合；
(iii) **共同模式地板**：融合后的不确定度必须满足 u_fused ≥ u_cm_floor（共同模式语义偏置下界），除非在独立锚点上证明偏置为零；
(iv) **非补偿性场景/融合否决**：任一源的有效域失效或场景失效，融合不得用其他源的平均把它补掉；
(v) **时序对齐**：跨技术融合必须按时间戳对齐并计入 u_sync，控制域只读对齐快照；
(vi) **严格退化链**：场景失效 ⇒ 几何/触觉驱动 + R72；融合失效 ⇒ 单最可信源保守 + R72；两者全失效 ⇒ R68。**新层只在「场景可解释、融合可审计」时启用。**

**定义 367（结构化场景潜变量与场景图后验）** 场景潜变量
g = (O, R, A, F)，
O = {o_i} 为物体/部件节点（位姿、尺度、材质、类别分布、可动性），R ⊆ O×O×ℛ 为关系集 ℛ = {support, contain, occlude, part-of, adjacent, reachable, movable}，A: O×𝒜_manip → Δ(可供性) 为可供性场（可抓/可推/可切/可承重/易碎/高温/危险），F 为自由/占据/未知空间场。场景后验
b_t(g) ∝ p(g) · Π_k p_scene(y_k | g, s, ψ)，
以**粒子场景图集合** {g^(j), w^(j)}_{j=1..N} 表示（含 MCMC/图神经 proposal）；边缘查询 b_t(o_i)、b_t(r_ij)、b_t(a_i)、b_t(F) 均由粒子集诱导。**场景后验必须携带 (φ_g, m_g, u_g, D_g, τ_g, I⊥)** 六元组（沿用定义 332）。

**定义 368（场景证据模型与语义校准）** 多模态场景观测 y_scene = (rgbd, lang, wm, prior)
p_scene(y_scene | g, s, ψ) = Σ_k ω_k(ψ) · p_k(y_scene | g, s)，
其中 ω(ψ) 复用 R71 情感混合权重（合作/敷衍/对抗/困惑）。**场景识别器输出 (ĝ, b_t(g), ECE_scene, ι_scene, OOD_scene)**：ECE_scene 为结构级校准误差（检测/关系/可供性分层），ι_scene 为跨场景/跨本体/跨光照的不变性间隙。**语义校准必须按「结构单元」分层，禁止用整图平均精度掩盖关系/可供性层的系统性错误。**

**定义 369（场景不确定度五分量）** 与 DMEM 四分量对偶，场景不确定度分解为
u_scene² = u_det² + u_rel² + u_aff² + u_phys² + u_occ²，
分别为：检测/分割/位姿不确定度 u_det、关系/空间推理不确定度 u_rel、可供性预测不确定度 u_aff、常识/物理合理性不确定度 u_phys、遮挡/未观测覆盖不确定度 u_occ。**每一项有独立追溯链 τ_scene,i；u_occ 尤其关键——「没看见」必须被计量为不确定度，而不是被当成「不存在」。**

**定义 370（共同模式语义偏置 b_cm）** 设所有依赖场景先验的源 i 的估计为
x_i = f_i(θ, g) + b_cm + ε_i，
其中 b_cm 是**跨源共享**的语义偏置（源于共享 foundation model、共享标注、共享场景先验），E[b_cm]=μ_cm、Cov(b_cm)=Σ_cm。**共同模式不确定度 u_cm = tr(Σ_cm)^{1/2} 不随源数增加而下降**。系统必须维护 b_cm 的在线/离线估计（跨本体/跨场景残差、反事实场景扰动、交互探针），并输出 **u_cm_floor**。**缺失 u_cm_floor 的融合一律视为未计量。**

**定义 371（技术融合图与 provenance DAG）** 融合图 FG = (V_f, E_f, ⊛)：
- V_f 为证据源/变换节点（geo, sem, tac, lang, wm, intent, s2r, …）；
- E_f 为**数据/参数/标定/训练语料**流动边，每条边带 hash 与时间戳；
- ⊛ 为融合算子族（见定义 373）。
**provenance DAG 要求无环、叶节点可审计、每条边可复算**。若两个源在 DAG 中存在**共同祖先（diamond）**，则在统计上**不得默认独立**，必须计算其相关性下界。

**定义 372（认知独立性证书 EIC）** 对任意源对 (i,j)，证书
κ_ij ∈ [0,1]，κ_ij = 1 ⇔ 已证明「训练语料、标定祖先、场景先验、世界模型参数」均不共享。
由 provenance DAG 计算：κ_ij = exp(−λ_shared · s_ij)，s_ij 为共享祖先的质量加权和；未申报共享默认 κ_ij = 0。**融合时使用相关性下界 ρ_ij ≥ 1 − κ_ij**。**κ 是融合的前置条件，不是事后解释。**

**定义 373（相关感知保守融合 ⊛_CI）** 对源估计 (x_i, Σ_i, κ_ij)：
- 基线采用 **协方差交集（CI）**：Σ_fused^{-1} = Σ_i w_i Σ_i^{-1}，Σ_i w_i = 1，w 由最小化 det/trace 求得；CI 对任意未知相关**保证不低估**（在输入一致的前提下）；
- 再叠加**共同模式地板**：Σ_fused⁺ = Σ_fused + u_cm_floor² · I；
- 若 κ_ij 未达阈值，则额外膨胀：Σ_fused⁺ ← Σ_fused⁺ + Δ(κ_ij)（Δ 随独立性下降单调增）。
**融合输出必须携带 (x_fused, Σ_fused⁺, FG_fused, κ_min, u_cm_floor, τ_fused)**，缺一不可进入风险缩放。

**定义 374（不确定性洗白与洗白分数）** 设融合前后不确定度 u_naive、u_fused，隐藏审计集 SEAL-Scene 上的真实误差 e_true、名义覆盖率 cov。定义洗白分数
L = max(0, log(u_true / u_fused)) + λ_cov · max(0, cov_nominal − cov_empirical) + λ_shrink · max(0, shrink_rate_expected − shrink_rate_observed)。
**L > τ_L ⇒ 判定为洗白，融合不确定度被禁止进入 λ/IVG/证书，必须膨胀或弃权。** 洗白分数是**独立于被审计融合过程**的外部覆盖性检验。

**定义 375（跨技术时延对齐 TFA）** 每个技术/模态 i 有速率 f_i、端到端时延 ℓ_i、时间戳 ts_i。控制时刻 t 的对齐估计
x_i^aligned(t) = τ_i(x_i(ts_i), t − ts_i)，带外推不确定度 u_i^sync(t) = L_v · |t − ts_i| + u_i^stamp，其中 L_v 为状态变化率上界、u_stamp 为时间戳抖动。**融合不确定度必须包含 u_sync = (Σ_i (u_i^sync)²)^{1/2}；控制域只读对齐后的版本化快照，禁止「最新到达拼接」。**

**定义 376（场景条件化的意图/接触/风险）**
- 意图：p(z | g, ψ) 由场景可供性调制——不可达/不可抓的物体降低「递交」先验、提高「指示/询问」先验；
- 接触：p(c | g, part) 由部件几何/材质/可动性调制——薄壁/易碎部件的 `sliding/breaking` 先验上升；
- 风险：λ 的基线与地板都显式依赖 g（易碎/高温/危险/湿滑材质 ⇒ 抬高 λ_floor）。
**场景条件化是单向的：g 只能收紧安全约束，不能放宽 R72 已成立的约束。**

**定义 377（非补偿性融合否决 NFV）** 融合有效当且仅当
Valid_fused = (∧_{i∈sources} Valid_i) ∧ Consensus_fused ∧ Coverage_invariant，
其中 Valid_i 为第 i 源在定义 359 下的有效域检查，Consensus_fused 为源间分歧不超过由 κ 与 Σ 解释的上界，Coverage_invariant 为定义 373 的地板约束。**融合是有效域的「交集」而非「并集」**：任一源否决 ⇒ 整个融合相关维度否决；**融合不能把一个被否决的源平均成「可接受」。**

**定义 378（融合感知风险缩放 SCENE-RISK）** 风险缩放因子
λ = max( M_efs.risk_scale(U_ale, U_epi, H[b_t(z)], u_tac, H[b_t(g)], u_scene, u_sync),
         λ_floor(U_ale + U_epi + H[b_t(z)] + u_tac + u_scene + u_sync) ) · (1 + β_L · 𝟙[L > τ_L]) · (1 + β_cm · 𝟙[u_fused < u_cm_floor])。
**场景/融合/时序不确定度与物理/意图/接触同权进入分母**；洗白或破地板触发额外放大。**没有「主要/次要」，任一维度把 u 洗白都必须抬高 λ，强制软化动作或弃权。**

**定义 379（场景/融合 IVG：S-IVG 与 F-IVG）** 在 E-IVG（定义 359）上新增：
- **S-IVG（场景）**：ECE_scene > τ_ece_scene、ι_scene > τ_ι_scene、H[b_t(g)] > τ_Hg、OOD_scene 触发、u_occ > τ_occ（未观测区域过大）、u_phys > τ_phys（物理荒谬）；
- **F-IVG（融合）**：κ_min < τ_κ、L > τ_L、u_fused < u_cm_floor、源间分歧 > τ_consensus、provenance 断链、u_sync > τ_sync。
任一成立 ⇒ 相关维度失效：场景失效 ⇒ 退化到几何/触觉驱动 + R72；融合失效 ⇒ 单最可信源保守 + R72；时序失效 ⇒ 控制域改用上一次对齐快照 + 提高 λ。

**定义 380（场景/融合证书 J_SCENE）** J_SCENE = (J_EMB, scene_graph_hash, ECE_scene, ι_scene, u_scene_breakdown, u_cm_floor, provenance_root, κ_min, L_score, sync_bound, seal_scene_ver)。Valid ⇔ Valid(J_EMB) ∧ 场景六元组完整 ∧ provenance DAG 无断链 ∧ κ_min ≥ τ_κ ∧ L ≤ τ_L ∧ u_fused ≥ u_cm_floor ∧ 覆盖率审计通过。

**定义 381（威胁模型 AIC-SCENE）** ℰ_SCENE = ℰ_EMB × ℰ_scene × ℰ_fusion：
ℰ_scene = {语义幻觉（高置信错误场景图）、对抗性场景补丁、关系/可供性系统性偏置、遮挡诱导的「空世界」错觉、跨光照/材质 OOD、场景图投毒}；
ℰ_fusion = {相关性伪装（声称独立实为共享先验）、provenance 伪造/断链洗白、κ 证书投毒、共同模式偏置注入、时延欺骗、多数源共谋（colluding sources）}。

**定义 382（场景/融合扩展的严格退化链）** 在定义 364 基础上逐指令等价：
- 场景失效 + 融合有效 ⇒ 几何/触觉证据驱动 + R72；
- 场景有效 + 融合失效 ⇒ 场景先验 + 单最可信源 + R72；
- 场景失效 + 融合失效 ⇒ R72（若无 R72 元数据则 R68）；
- 全有效 ⇒ SCENE-FUSION 完整形态。
**安全侧只增不减：任何退化都保留 R68 硬安全包络、R72 三域分离与 λ_floor。**

**定义 383（场景主动取证 SAA）** 当 H[b_t(g)] 或 u_occ 超阈，系统主动选择信息获取动作 g_probe ∈ {移动视角, 触碰探针, 询问, 抓取试探}，最大化
VoI_scene(g_probe) = H[b_t(g)] − E[H[b_{t+1}(g)]] − c_probe − c_reflex^joint − γ·risk(g_probe)，
并受三层反作用预算与 REG 时序约束。**探针必须「与场景先验无关」才计入独立性增益（例如物理接触而非再问一次同一个模型）。**

**定义 384（融合源选择与融合预算）** 源子集 S ⊆ sources，融合成本 c_fuse(S) 与边际独立增益
ΔIG(S) = H[b_t(θ)] − E[H[b_t(θ) | S]]。
选择 S* = argmax [ΔIG(S) − c_fuse(S)] s.t. κ_min(S) ≥ τ_κ、REG 时序可行、预算未超。**当新增源与已有源高度相关（κ 低）时，ΔIG ≈ 0，融合预算应拒绝该源——「多一个相关源」不是增益，是洗白风险。**

**定义 385（运行时场景监控器 RSM）** 与 RTM（定义 365）并列的最高优先级监控节点：每场景周期自测场景后验覆盖率、provenance 哈希、κ 窗口、u_cm_floor 漂移、时延对齐误差；超阈即冻结场景/融合维度并降级。**RSM 自身零依赖、静态内存、形式化验证，是场景/融合层的「信任锚点」。**

# IP-295 SGR：结构化场景图后验（计量域 5-15Hz，软实时）
class SceneGraphPosterior:
    def __init__(self, proposal_net, scene_lik, calib, n_particles=256):
        self.prop, self.lik, self.calib, self.N = proposal_net, scene_lik, calib, n_particles
    def update(self, y_scene, psi_hat, b_prev):
        # y_scene = (rgbd, lang_emb, wm_prior, obs_mask)
        cand = [self.prop.sample(y_scene, g) for g in b_prev.particles]   # MCMC/图神经 proposal
        logw = [b_prev.logw[j] + self.lik.logp(y_scene, g, psi_hat) for j, g in enumerate(cand)]
        parts, w = self._normalize(cand, logw)                            # b_t(g)
        u_det  = self.calib.detection_unc(parts)
        u_rel  = self.calib.relation_unc(parts)
        u_aff  = self.calib.affordance_unc(parts)
        u_phys = self.calib.physics_plausibility_unc(parts)
        u_occ  = self.calib.occlusion_coverage_unc(parts, y_scene.obs_mask)
        return SceneBelief(g_parts=parts, w=w,
                           u_scene=sqrt(u_det**2+u_rel**2+u_aff**2+u_phys**2+u_occ**2),
                           breakdown=(u_det,u_rel,u_aff,u_phys,u_occ),
                           ece=self.calib.ece_scene, iota=self.calib.iota_scene,
                           tau=self.calib.tchain)

# IP-296 SCM：语义校准与幻觉计量（离线 SEAL-Scene + 在线 OOD）
class SemanticCalibrator:
    def score(self, b_g, seal):
        # 结构级校准：检测/关系/可供性分层 ECE，而非整图平均
        ece = {k: ece_binned(b_g, seal, layer=k) for k in ('det','rel','aff')}
        iota = invariance_gap(b_g, seal, groups=('scene','embodiment','lighting'))
        ood  = ood_score(b_g, seal)                     # 语义幻觉/OOD 分
        return ece, iota, ood

# IP-297 FUSE-PROV：provenance DAG + 共享祖先检测
class ProvenanceFusion:
    def build(self, sources):
        dag = DAG()
        for s in sources:
            dag.add_source(s.id, s.tchain, s.train_corpus_hash,
                           s.calib_ancestors, s.prior_hash, s.wm_params)
        return dag
    def shared_mass(self, i, j):
        # 共享训练语料/标定祖先/先验/世界模型参数的加权质量
        anc_i, anc_j = self.dag.ancestors(i), self.dag.ancestors(j)
        return mass(anc_i & anc_j, weights=self.dag.edge_weights)

# IP-298 EIC：认知独立性证书
class IndependenceCert:
    def certify(self, dag, i, j):
        s_ij = dag.shared_mass(i, j)
        kappa = exp(-LAM_SHARED * s_ij) if dag.acyclic and dag.auditable(i, j) else 0.0
        return Kappa(k_ij=kappa, rho_floor=1.0 - kappa, tau=dag.hash_path(i, j))

# IP-299 ULD：不确定性洗白检测（独立于融合过程的覆盖性审计）
class LaunderingDetector:
    def __init__(self, seal_scene, window=512):
        self.seal, self.buf = seal_scene, deque(maxlen=window)
    def update(self, x_fused, Sigma_fused, b_g):
        e_true = self.seal.error(x_fused, b_g)          # 隐藏审计集上的真实误差
        self.buf.append((u_of(Sigma_fused), e_true))
        u_naive = u_of(naive_fuse_var(b_g))
        L = (max(0.0, log(u_true(self.buf) / u_of(Sigma_fused)))
             + LAM_COV * max(0.0, cov_nominal - cov_empirical(self.buf))
             + LAM_SHRINK * max(0.0, shrink_expected - shrink_observed(self.buf)))
        return LaunderingScore(L=L, alarm=(L > TAU_L), coverage=cov_empirical(self.buf))

# IP-300 TFA：跨技术时延对齐
def temporal_align(sources, t_ctrl, L_v, u_stamp):
    aligned, us = [], []
    for s in sources:
        dt = abs(t_ctrl - s.ts)
        if dt > s.max_age: return None, None          # 过期源弃用，不拼接
        x = s.extrapolate(t_ctrl)                     # 带模型的外推
        aligned.append((x, s.Sigma))
        us.append(sqrt((L_v * dt)**2 + u_stamp**2))
    u_sync = sqrt(sum(u2**2 for u2 in us))
    return aligned, u_sync

# IP-301 S-RISK：非补偿性融合风险缩放
def scene_risk_scale(U_ale, U_epi, H_z, u_tac, H_g, u_scene, u_sync,
                     u_cm_floor, L, params):
    denom = U_ale + U_epi + H_z + u_tac + u_scene + u_sync
    lam = max(params.lam_base * (1 + denom / params.lam_scale),
              params.lam_floor * (1 + denom))
    lam *= (1 + params.beta_L * float(L > params.tau_L))          # 洗白惩罚
    lam *= (1 + params.beta_cm * float(u_of_fused < u_cm_floor)) # 破地板惩罚
    return lam

# IP-302 SCENE 主闭环：在 R72 三域上插入场景域（计量域内）+ 融合审计
def SCENE_FUSION_ROUND(M, obs, audio, tac_frame, y_scene):
    # ---- 控制域 1kHz（只读对齐快照，零分配）----
    snap = M.snapshot.read_aligned(t_ctrl=M.clock.now())          # 含 b_g / fused / u_sync
    b_t  = M.bse.step_ctrl(snap.b_prev, obs, M.last_action, M.last_g, M.last_y)
    U_ale, U_epi = decompose_ctrl(b_t, M.fmp, obs)
    lam = scene_risk_scale(U_ale, U_epi, snap.H_z, snap.u_tac,
                           snap.H_g, snap.u_scene, snap.u_sync,
                           snap.u_cm_floor, snap.L, M.risk_params)
    A = M.ach.propose_ctrl(...); k = M.c_ras_wm.certified_prefix(A, lam, snap.b_g)
    M.ctrl_out.publish(k, lam)
    # ---- 计量域 5-50Hz（场景图 + 意图 + 接触 + 融合审计）----
    if M.clock.due_metric():
        b_g = M.sgr.update(y_scene, M.psi_hat, M.b_g_prev)         # IP-295
        b_t_full = M.bse.step_full(M.b_prev, obs, M.last_action, M.last_g, M.last_y)
        z_dist, *_ = M.irl.update(M.y_intent_buf, M.psi_hat, b_t_full, b_g)  # 场景条件化
        tac_ev = M.dmem.update(tac_frame, M.last_action, b_g)      # 场景条件化接触

        prov = M.fuse.build(M.sources(b_g, b_t_full, z_dist, tac_ev, M.acoust))
        kappa = M.eic.certify_all(prov)
        fused = M.fuse.ci_fuse(M.sources(...), kappa, u_cm_floor=M.ucm.estimate())
        L = M.uld.update(fused.x, fused.Sigma, b_g)                # IP-299
        aligned, u_sync = temporal_align(M.sources(...), M.clock.now(), M.L_v, M.u_stamp)
        gate = M.s_ivg.check(b_g, fused, L, u_sync, M.seal_scene)
        if not gate.valid:
            M.mode = gate.fallback                                  # R72 / R68
            M.registry.freeze(gate.reason)
        M.snapshot.write_aligned(b_t_full, z_dist, b_g, fused, L, u_sync, gate)
    # ---- 感知域异步（AURA/DMEM/场景观测缓冲/主动取证）----
    if M.mode == 'FULL' and (b_g.entropy() > TAU_HG or b_g.u_occ > TAU_OCC):
        g_probe = M.saa.choose(b_g, M.budget, M.sources)            # IP-303
        if g_probe: M.cia.execute(g_probe)
    return k, lam, J_SCENE(M)

## 3. 推导

**引理 33（融合的共同模式误差地板）** 设 N 个源 `x_i = θ + b_cm + ε_i`，`ε_i` 独立同方差 σ²，`b_cm` 方差 u_cm²。朴素均值的均方误差为 `σ²/N + u_cm²`。当 N→∞ 时方差下确界为 u_cm² > 0。系：**融合只能消除独立噪声，不能消除共享语义偏置；任何声称「源越多越确定」的证书，若无 b_cm 项，必然过度自信。**

**引理 34（相关感知 CI 的一致性）** 在输入估计一致的条件下，协方差交集对任意未知相关 ρ_ij ∈ [0,1] 产生的 Σ_CI 满足 `Σ_CI ⪰ E[(x_fused−θ)(x_fused−θ)ᵀ]`（不低估）。若存在共同模式偏置，则仅 CI 仍会低估；叠加 `Σ_CI + u_cm²I` 后重新满足一致性。系：**CI 保证的是「不被独立源的假象骗」，共同模式地板保证的是「不被共享先验的假象骗」，二者缺一不可。**

**引理 35（非补偿性否决的必要性）** 设源 i 的有效域 D_i 失效（例如触觉处于未知接触模式），其余源均有效且一致。存在场景使得其余源的一致估计偏离真值（共享语义偏置），而源 i 本可否决该动作。任何对源做**加权平均**的融合都会给出落入「其余源一致但错误」的估计；只有**有效域交集合取**能保留否决。系：**融合的正确语义是「证据取交」，不是「证据取平均」；平均会把否决权洗掉。**

**引理 36（时序错位不确定度上界）** 若状态变化率被 L_v 界住，时间戳抖动被 u_stamp 界住，则用 ts_i 时刻估计替代 t 时刻真值的误差 ≤ L_v·|t−ts_i| + u_stamp（在局部线性化模型下）。多源融合的 u_sync 为其平方和的平方根。系：**「最新到达拼接」在异步技术融合中是一个未申报的偏置源，必须显式计量。**

**引理 37（洗白分数的可检出性）** 若融合后不确定度 u_fused < u_cm_floor 且 SEAL-Scene 上经验覆盖率低于名义覆盖率，则洗白分数 L 的覆盖率项以概率 1−δ 超过阈值（由 DKW 不等式，样本数 m ≥ ln(2/δ)/(2ε²)）。系：**洗白不是不可检测的；只要审计集独立于融合过程，有限样本即可给出高置信告警。**

**引理 38（场景条件化的风险单调性）** 若场景后验熵 H[b_t(g)] 与 u_scene 单调增加，则定义 378 的 λ 单调不减；在 NFV（定义 377）下，场景错误只能抬高或保持 λ，不能降低 R72 已成立的风险界。系：**场景理解是安全的「增益器」而非「豁免器」——它可以让机器人更聪明地保守，不能让机器人更激进。**

**定理 27（场景/融合严格包含与安全单调）** 在 A111–A116（场景图后验可校准、κ 证书可靠、共同模式地板有效、CI 一致性、时序界成立、SEAL-Scene 独立）下：SCENE-FUSION 在退化条件下逐指令等于 EMBODIED/R71/R68（定义 382），且对任意有效执行其风险界 ≤ R72 风险界（定理 23）。**安全单调不减，效率仅在「场景可解释、融合可审计」时获益。**

**定理 28（J_SCENE 有效性 ⇒ 无洗白）** 若一次执行通过 J_SCENE，则：(i) provenance DAG 无断链且 κ_min ≥ τ_κ ⇒ 融合时使用了可证的相关下界；(ii) u_fused ≥ u_cm_floor 且覆盖率审计通过 ⇒ 融合不确定度是真实误差的上界（在声明的共同模式模型下）；(iii) L ≤ τ_L ⇒ 未检测到洗白；(iv) J_EMB 有效 ⇒ R72 风险界成立。综上，**融合后的风险界在「SEAL-Scene 代表性 + κ 证书不可伪造」两个前提下成立。** 证明重量正落在这两个前提上。

**定理 29（非补偿性融合保持否决权）** 在定义 377 下，任何有效执行的动作必属于 ⋂_i SafeSet_i（各源有效域诱导的安全动作交集），因此不存在「用其他源平均掉失效源否决」的执行。**融合只收窄安全集，不扩张安全集。**

**定理 30（场景/融合层不破坏三域时序）** 场景图更新、provenance 构建、CI 融合、洗白检测、时延对齐全部运行在计量域（软实时、可抢占）或部署期；控制域只读版本化对齐快照、零分配、不回写。因此 R72 定理 25（无活锁/死锁）与引理 28（控制环时序隔离）继续成立。**新增的场景/融合复杂度不进入控制环的临界路径。**

## 6. 本轮最大风险

**一句话**：SCENE-FUSION-GAUGE-RAS 把安全从「相信具身实时契约」进一步转移到「相信 **场景图后验代表了真实世界**、相信 **provenance/κ 证书真的刻画了源间相关**、相信 **SEAL-Scene 真的覆盖了部署分布**」——**如果场景理解器在部署分布外以高置信输出一张物理上合理、语义上自洽、但与现实系统性偏差的场景图（例如把湿滑地面认成干燥、把薄壁件认成实心、把「虚掩」认成「关闭」），而所有下游模态又共享这张图的先验、因而无法通过「多模态一致」暴露它；同时融合层用一组共享 foundation model/训练语料/标定祖先的源，靠 CI 之外的隐式独立性假设把 u 压到 u_cm_floor 以下，而 κ 证书因共享关系申报不全而给出虚高的独立性、SEAL-Scene 又恰好不含这类场景——那么系统会拿着一份「场景校准通过、融合覆盖率达标、洗白分数为零、所有证书盖章」的报告，在真实的湿滑地面/薄壁件/虚掩抽屉前，用一套**被自己的不确定性度量洗白过的自信**去抓、去推、去撞，事后审计发现所有指标都在有效域内、所有 provenance 都完整，唯独**「有效域」和「审计集」本身就是错的**。** 这就是场景理解与多技术融合叠加后的**共同模式盲区**：不是「不知道自己不知道」，而是「知道了一个错误的知道」。

次级风险与缓解：
1. **共同模式偏置不可观** → 引入**与场景先验无关的外部锚点**：物理探针、独立几何测量、跨本体交叉验证；u_cm_floor 由这些锚点的残差估得，禁止用场景自身估计 u_cm。
2. **κ 证书申报不全** → provenance 强制包含训练语料/权重/标定祖先哈希；**默认 κ=0（未申报即不独立）**；部署前做**共谋源注入测试**验证 CI+地板能拦住。
3. **SEAL-Scene 分布漂移** → 在线监测「覆盖缺口 + 场景特征漂移」，触发时降低融合信任、扩大 u、提高 λ；SEAL-Scene 定期轮换并对融合过程保密。
4. **场景幻觉通过多模态一致伪装** → **反事实场景扰动测试**：交换/删除关键场景节点，看融合估计变化幅度；变化小说明不依赖该先验（好），变化大但审计集未覆盖（坏），强制标记为高 u_cm。
5. **时序错位被「最新拼接」掩盖** → 控制域只读**带时间戳的对齐快照**，禁止无戳拼接；u_sync 超阈即弃用过期源并提高 λ。
6. **融合复杂度爆炸** → 模块化上限：|sources|≤12、粒子 ≤256、关系类型 ≤8、provenance 节点 ≤64；融合源选择（定义 384）主动拒绝低 κ 源。
7. **场景层拖慢计量环** → 场景图在独立节点/线程、只写版本化快照；控制域零依赖；RSM 监控场景节点 WCET，超阈即冻结场景维度。

**最大风险的一句话（本轮结论）**：真正的危险不是场景理解错了或融合错了，而是**场景先验与融合独立性这两个「测量之外的前提」同时不可观测地错了，而系统用被它们污染的 u 给自己出具了「一切正常」的证书**。

# IP-295 SGR：结构化场景图后验（计量域 5-15Hz）
class SceneGraphPosterior:
    def __init__(self, proposal_net, scene_lik, calib, n_particles=256):
        self.prop, self.lik, self.calib, self.N = proposal_net, scene_lik, calib, n_particles
    def update(self, y_scene, psi_hat, b_prev):
        cand = [self.prop.sample(y_scene, g) for g in b_prev.particles]
        logw = [b_prev.logw[j] + self.lik.logp(y_scene, g, psi_hat)
                for j, g in enumerate(cand)]
        parts, w = normalize(cand, logw)
        u_det  = self.calib.detection_unc(parts)
        u_rel  = self.calib.relation_unc(parts)
        u_aff  = self.calib.affordance_unc(parts)
        u_phys = self.calib.physics_plausibility_unc(parts)
        u_occ  = self.calib.occlusion_coverage_unc(parts, y_scene.obs_mask)
        return SceneBelief(
            g_parts=parts, w=w,
            u_scene=sqrt(u_det**2+u_rel**2+u_aff**2+u_phys**2+u_occ**2),
            breakdown=(u_det,u_rel,u_aff,u_phys,u_occ),
            ece=self.calib.ece_scene, iota=self.calib.iota_scene,
            tau=self.calib.tchain)

        return ece, iota, ood          # 分层校准，禁止整图平均掩盖偏差

# IP-297 FUSE-PROV：provenance DAG + 共享祖先检测
class ProvenanceFusion:
    def build(self, sources):
        dag = DAG()
        for s in sources:
            dag.add_source(s.id, s.tchain, s.train_corpus_hash,
                           s.calib_ancestors, s.prior_hash, s.wm_params)
        return dag
    def shared_mass(self, i, j):
        return mass(self.dag.ancestors(i) & self.dag.ancestors(j),
                    weights=self.dag.edge_weights)

# IP-298 EIC：认知独立性证书
class IndependenceCert:
    def certify(self, dag, i, j):
        s_ij = dag.shared_mass(i, j)
        kappa = exp(-LAM_SHARED * s_ij) if dag.acyclic and dag.auditable(i, j) else 0.0
        return Kappa(k_ij=kappa, rho_floor=1.0 - kappa, tau=dag.hash_path(i, j))

# IP-299 ULD：不确定性洗白检测（独立覆盖性审计）
class LaunderingDetector:
    def __init__(self, seal_scene, window=512):
        self.seal, self.buf = seal_scene, deque(maxlen=window)
    def update(self, x_fused, Sigma_fused, b_g):
        e_true = self.seal.error(x_fused, b_g)
        self.buf.append((u_of(Sigma_fused), e_true))
        u_naive = u_of(naive_fuse_var(b_g))
        L = (max(0.0, log(u_true(self.buf) / u_of(Sigma_fused)))
             + LAM_COV * max(0.0, cov_nominal - cov_empirical(self.buf))
             + LAM_SHRINK * max(0.0, shrink_expected - shrink_observed(self.buf)))
        return LaunderingScore(L=L, alarm=(L > TAU_L), coverage=cov_empirical(self.buf))

# IP-300 TFA：跨技术时延对齐
def temporal_align(sources, t_ctrl, L_v, u_stamp):
    aligned, us = [], []
    for s in sources:
        dt = abs(t_ctrl - s.ts)
        if dt > s.max_age: return None, None            # 过期源弃用，禁止拼接
        aligned.append((s.extrapolate(t_ctrl), s.Sigma))
        us.append(sqrt((L_v * dt)**2 + u_stamp**2))
    return aligned, sqrt(sum(u2**2 for u2 in us))

# IP-301 S-RISK：非补偿性融合风险缩放（控制域 <0.06ms）
def scene_risk_scale(U_ale, U_epi, H_z, u_tac, H_g, u_scene, u_sync,
                     u_cm_floor, u_fused, L, params):
    denom = U_ale + U_epi + H_z + u_tac + u_scene + u_sync
    lam = max(params.lam_base * (1 + denom / params.lam_scale),
              params.lam_floor * (1 + denom))
    lam *= (1 + params.beta_L  * float(L > params.tau_L))
    lam *= (1 + params.beta_cm * float(u_fused < u_cm_floor))
    return lam

# IP-303 SAA：场景主动取证
def scene_active_acquisition(b_g, budget, sources):
    best = None
    for g_probe in probe_candidates(b_g, top_k=4):
        if not budget.allow(g_probe) or not independent_of_prior(g_probe):
            continue
        voI = (b_g.entropy() - expected_post_entropy_scene(b_g, g_probe)
               - cost(g_probe) - expected_reflex_cost(g_probe)
               - GAMMA * expected_risk(g_probe))
        if best is None or voI > best.score: best = (g_probe, voI)
    return best if best and best.score > 0 else None

# IP-302 SCENE 主闭环：R72 三域 + 场景域 + 融合审计
def SCENE_FUSION_ROUND(M, obs, audio, tac_frame, y_scene):

## 4. 推导

**引理 33（融合的共同模式误差地板）** `x_i=θ+b_cm+ε_i`，`ε_i` 独立同方差 σ²，`b_cm` 方差 u_cm²。朴素均值 MSE=`σ²/N+u_cm²`，N→∞ 时下确界 u_cm²>0。系：**融合只消独立噪声，不消共享语义偏置。**

**引理 34（相关感知 CI 的一致性）** 输入一致时，CI 对任意未知相关 ρ∈[0,1] 不低估；存在共同模式偏置时仅 CI 仍低估，叠加 `u_cm²I` 后恢复一致。系：**CI 防「独立假象」，地板防「共享先验假象」。**

**引理 35（非补偿性否决的必要性）** 源 i 失效、其余源一致但共同偏置错时，任何加权平均都落入「一致但错」的估计；只有有效域交集保留否决。系：**融合语义是取交，不是取平均。**

**引理 36（时序错位上界）** 状态变化率 ≤L_v、时间戳抖动 ≤u_stamp 时，用 ts_i 估计替代 t 真值误差 ≤ L_v·|t−ts_i|+u_stamp；多源 u_sync 为平方和根。系：**「最新到达拼接」是未申报偏置。**

**引理 37（洗白可检出性）** 若 u_fused<u_cm_floor 且 SEAL 覆盖率低于名义，则 L 覆盖率项以概率 1−δ 超阈（DKW：m≥ln(2/δ)/(2ε²)）。系：**独立审计集上的有限样本即可高置信告警。**

**引理 38（场景条件化风险单调）** H[b(g)]、u_scene 增 ⇒ λ 不减；NFV 下场景错误只能抬高/保持 λ。系：**场景是安全增益器，不是豁免器。**

**定理 27（严格包含与安全单调）** 在 A111–A116 下，SCENE-FUSION 退化逐指令等于 EMBODIED/R71/R68，且有效执行风险界 ≤ R72 风险界。**安全单调不减。**

**定理 28（J_SCENE 有效 ⇒ 无洗白）** provenance 无断链 ∧ κ_min≥τ_κ ⇒ 用了可证相关下界；u_fused≥u_cm_floor ∧ 覆盖率通过 ⇒ u 是真实误差上界；L≤τ_L ⇒ 未检测到洗白；J_EMB 有效 ⇒ R72 风险界成立。**证明重量落在「SEAL-Scene 代表性」与「κ 不可伪造」上。**

**定理 29（非补偿性融合保持否决）** 有效执行动作 ⊆ ⋂_i SafeSet_i，不存在用他源平均掉失效源否决的执行。**融合只收窄安全集。**

**定理 30（不破坏三域时序）** 场景图/溯源/CI/洗白/对齐均在计量域或部署期；控制域只读版本化对齐快照。R72 定理 25、引理 28 继续成立。**新增复杂度不进入控制临界路径。**

## 7. 本轮最大风险

**一句话**：SCENE-FUSION-GAUGE-RAS 把安全从「相信具身实时契约」进一步转移到「相信 **场景图后验代表真实世界**、相信 **provenance/κ 证书真的刻画源间相关**、相信 **SEAL-Scene 真的覆盖部署分布**」——**如果场景理解器在分布外以高置信输出一张物理自洽、语义自洽、却与现实系统性偏差的场景图，而所有下游模态共享该图先验因而「多模态一致」无法暴露它；同时融合层用一组共享 foundation model/语料/标定祖先的源，靠未申报的独立性假设把 u 压到 u_cm_floor 以下，κ 因共享申报不全而虚高、SEAL-Scene 又恰不含这类场景——系统就会拿着一份「场景校准通过、融合覆盖率达标、洗白分数为零、证书齐全」的报告，在湿滑地面/薄壁件/虚掩抽屉前，用被自己的不确定性度量洗白过的自信去抓、去推、去撞。** 这就是**共同模式盲区**：不是「不知道自己不知道」，而是「知道了一个错误的知道」。

**最大风险的一句话（本轮结论）**：真正的危险不是场景理解错了或融合错了，而是**场景先验与融合独立性这两个「测量之外的前提」同时不可观测地错了，而系统用被它们污染的 u 给自己出具了「一切正常」的证书**。
