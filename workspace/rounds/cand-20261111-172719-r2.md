# 第 56 轮（承接第 55 轮语义-接触生存核；灵感循环第 1 轮；本轮灵感：「开源硬件」×「视觉问答」）

> 第 55 轮把“感知标签”升级成“可执行的语义-接触约束”，并用生存核 + 护盾把单次接触的可信性写进证书 `J_s`。但这条证书链仍悄悄假设了两件事：**身体是同一台、已知且可信的**；**人机接口是被动的、只由机器人单向出证书**。本轮引入「开源硬件」与「视觉问答」正是来拆这两个假设：开源硬件让身体从常量变成可复制、可改装、也可被篡改的分布；视觉问答让语言成为人主动询问机器人信念的通道，而语言恰恰最容易把不确定性“洗白”成一句流畅的肯定。核心矛盾：**H24（身体变量化）**：开源硬件的跨构型差异不是感知噪声，而是直接改写 `f_B`、运动学与执行器限幅，因而旧证书在新身体上可能“看起来仍然可行”；**H25（语言洗白）**：VQA 把多维证据压缩成一句自然语言答案，若答案不经过证据蕴含与弃权，就会把“身体未认证 / 证据缺失” laundering 成“机器人说可以”。

## 0. 直觉与动机

**灵感 1（开源硬件 → 身体护照，而非固定本体）**
直觉：开源硬件最重要的不是便宜，而是**可复制 + 可检查 + 可变异**。同一个策略会被装到不同打印件、不同电机、不同 IMU 的社区构型上。因此每台身体都应携带一份机器可读的 **身体护照** `B=(h,𝒮,𝒜,K_cal,Π_tol,ℱ)`，证书不是“对机器人成立”，而是“对身体签名 `β(B)` 及其容差邻域成立”。这把“部署”从一次移植变成一次 **身体认证**。

**灵感 2（开源硬件车队 → 异构即测试覆盖，而非负担）**
直觉：闭源时代你只有一台身体，证书的泛化只能靠仿真猜。开源硬件车队反而提供了真实的身体分布：不同打印误差、装配误差、传感器版本天然构成一组 **差分测试**。若某构型的生存核裕度系统性偏离同类，它要么是装配故障，要么是证书的隐藏假设被打破。**异构性从风险变成证据来源**，但必须防“社区数据投毒”。

**灵感 3（视觉问答 → 问题即证据请求编译器）**
直觉：用户问“我能踩上那块草地吗？”不是在要一个标签，而是在要一组证据：它是否可支撑、摩擦是否足够、边界是否远离脚掌、当前身体是否在可迁移构型内。VQA 的正确定位不是“看图说话”，而是 **把自然语言问题编译成证据 DAG**，再沿证书与传感器去取证据。问题因此成为 **可审计的安全规格**。

**灵感 4（视觉问答 → 可回答性、弃权与证据蕴含是一等公民）**
直觉：最危险的 VQA 不是答错，而是**该说“不知道”时仍然流畅地回答**。因此答案 `Ans(q)=(a,E,Γ,abstain)` 必须是证据 `E` 与推导 `Γ` 的函数：`yes` 只在 `E ⊢ P_q` 时给出，`no` 只在 `E ⊢ ¬P_q` 时给出，否则弃权并指出缺哪块证据。自然语言只是 `(a,E,Γ)` 的**渲染层**，不是独立信念。

**灵感 5（语言触发的主动标定 → 把提问变成一次低风险实验）**
直觉：当问题不可回答时，不应猜，而应**做一个测量**：轻触测摩擦、慢推测承重、短程移动测编码器方向。开源硬件的低成本传感器/执行器正好支持这种“问答即实验”。选择测量动作时最大化 **单位风险的信息增益**，并让第 55 轮的语义护盾为测量动作兜底。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（身体护照与身体签名）**
身体护照 `B=(h, 𝒮, 𝒜, K_cal, Π_tol, ℱ)`：`h` 为 BOM/固件/CAD/URDF 的溯源哈希；`𝒮` 为传感器型号、安装位与量程；`𝒜` 为执行器力矩/速度/热限；`K_cal` 为带协方差的标定参数；`Π_tol` 为制造/装配容差包络；`ℱ` 为已声明故障集。身体签名
`β(B)=(β_kin, β_dyn, β_sens, β_cal)`，并在签名空间定义构型等价类
`[B]_τ = {B' | d_β(β(B),β(B')) ≤ τ}`。

**定义 128（身体条件生存核与证书可迁移包络）**
把第 55 轮定义 122 的动力学显式条件到身体：
`K_B(Σ) = {x | ∃u∈A_WB, λ: f_B(x,u,λ)=ẋ ∧ supp(λ)⊆C^+(Σ) ∧ λ∈FC(μ_B) ∧ x_{t+1}∈𝒳_safe}`。
证书 `J` 从参考身体 `B` 到 `B'` 的**可迁移包络**为
`Π(J,B') = sup{ε | ∀B''∈[B']_τ, d_H(K_{B''}^{in}, K_B^{in}) ≤ ε ∧ K_margin(B'') ≥ θ_K}`。
仅当 `B'∈[B]_τ` 且 `Π(J,B')` 覆盖部署所需裕度时，`J` 才可迁移。关键是 `δ_B = d_H(K_B, K_{B'})` 是**动力学层面的位移**，不是感知噪声。

**定义 129（问题→证据查询）**
问题 `q` 经受限本体编译为证据查询 `Q(q)=(P_q, G_q, b_q)`：`P_q` 为待判命题集（如“表面 s 可承重”“摩擦 ≥ μ0”“身体 B' 属于已认证类”）；`G_q` 为证据 DAG，叶节点是可获取证据（证书字段、传感器读数、主动测量结果），内部节点是蕴含规则；`b_q` 为时间/风险预算。`q` 在状态 `(B,Σ,J)` 下**可回答**当且仅当存在证据赋值 `E` 与推导 `Γ`，使 `E ⊢ P_q` 或 `E ⊢ ¬P_q`，且 `coverage(E) ≥ γ`、`conf(E) ≥ 1-α`、`cost(E) ≤ b_q`；否则不可回答。

**定义 130（有据答案与弃权）**
`Ans(q)=(a,E,Γ,abstain)`，`a∈{yes,no,unknown}`：
- `a=yes ⇒ E ⊢ P_q`；`a=no ⇒ E ⊢ ¬P_q`；
- `a=unknown ⇔ q` 不可回答，且附带缺口 `Gap(q)=G_q \ E`；
- 自然语言渲染 `ℓ(q)=render(a,E,Γ)` 必须由模板或受约束解码产生，并满足 `faithful(ℓ,(a,E,Γ))=1`。

**幻觉**定义为 `a≠unknown ∧ ¬(E ⊢ ±P_q)`；**洗白**定义为 `a=yes` 但 `E` 中缺身体认证或可迁移包络证据。

**定义 131（车队差分证书）**
车队 `ℬ={B_i}_{i=1}^n`，每台有本地证书 `J_i`。对等价类 `[B]_τ`，车队证书
`J_fleet = ⋂_{B_i∈[B]_τ} J_i`，并要求
`r_fleet = P_{B'∼𝒟_ℬ}(¬sound(J_fleet,B')) ≤ ρ_port`。
若某 `B_i` 的裕度剖面 `m(B_i)` 相对同类偏离超过 `k` 个稳健标准差，则标记为**构型离群**（装配故障/隐性改装/数据投毒候选），并触发重标定而非直接信任其证书。

**定义 132（语言条件主动标定）**
当 `q` 不可回答时，从可执行测量动作 `A_meas` 中选
`a_m^* = argmax_{a∈A_meas, shield.feasible(a)} I(P_q; Y_a | E) / (c(a) + λ·r(a))`，
其中 `I` 为期望信息增益，`r(a)` 为测量风险（由第 55 轮语义护盾上界），`c(a)` 为时间/磨损成本。执行后更新 `E`，重新判定可回答性；若仍不可回答则弃权。这把 VQA 从“一次性回答”变成“提问→取证→回答/弃权”的闭环。

def attest_body(manifest, reference, fixtures):

### IP-128 PCB（Portable Body Certificate）

```python
def portable_certificate(J_ref, B_ref, B_new, Sigma, tau, eps):
    if d_beta(signature(B_new), signature(B_ref)) > tau:
        return ('reject', 'body_out_of_class')
    K_ref = viability_kernel(Sigma, B_ref)
    K_new = viability_kernel(Sigma, B_new)
    dH = hausdorff(K_ref.inner, K_new.inner)       # conservative bound
    if dH > eps:
        return ('reject', 'kernel_shift', dH)
    J_new = retarget(J_ref, B_new, dH)
    if J_new.K_margin < theta_K or J_new.rho_sem < rho_min:
        return ('reject', 'margin_lost', J_new.K_margin)
    return ('ok', J_new)
```

### IP-129 QEC（Question-to-Evidence Compiler）

```python
def compile_question(q, J, B, ontology, budget):
    P = constrained_parse(q, ontology)        # schema: propositions, no free text
    if not well_typed(P):
        return ('reject', 'ambiguous_question')
    G = build_evidence_dag(P, fields=J.fields | B.fields)
    E = available_evidence(G, J, B)
    if entails(E, P) or entails(E, neg(P)):
        return ('answerable', P, G, E)
    a_m = select_measurement(Gap(G, E), budget)   # IP-132
    return ('unanswerable', P, G, Gap(G, E), a_m)
```

### IP-130 GVA（Grounded VQA with Abstention）

```python
def grounded_answer(q, J, B, budget):
    status = compile_question(q, J, B, ontology, budget)
    if status.kind == 'reject':
        return Answer('unknown', evidence=None, reason='ambiguous')
    if status.kind == 'unanswerable':
        return Answer('unknown', evidence=status.gap,
                      plan=status.next_measurement)
    E, Gamma = derive(status)
    if entails(E, status.P):
        a = 'yes'
    elif entails(E, neg(status.P)):
        a = 'no'
    else:
        return Answer('unknown', evidence=status.gap)
    text = render_template(q, a, E, Gamma)       # no free-form safety claims
    assert faithful(text, a, E, Gamma)
    return Answer(a, E, Gamma, text=text)
```

### IP-131 FDC（Fleet Differential Certification）

```python
def fleet_certificate(fleet, Sigma, tau, rho_port, k=3.0):
    classes = cluster_by_signature(fleet, tau)
    out = []
    for B_class in classes:
        margins = [local_margin(B, Sigma) for B in B_class]
        anomalies = robust_outliers(margins, k=k)
        J_cls = intersect([local_certificate(B, Sigma)
                           for B in B_class if B not in anomalies])
        if J_cls is None or portability_risk(J_cls, B_class) > rho_port:
            out.append(('gap', B_class, anomalies, 'recalibrate'))
        else:
            out.append(('ok', J_cls, anomalies))
    return FleetCertificate(out)
```

### IP-132 LAC（Language-Conditioned Active Calibration）

```python
def select_measurement(gap, budget, shield):
    best, best_score = None, -1.0
    for a in measurement_actions(gap):
        if not shield.feasible(a):
            continue
        ig = expected_info_gain(gap, a)
        score = ig / (cost(a) + budget.lam * shield.risk(a))
        if score > best_score:
            best, best_score = a, score
    return best if best_score > 0 else None
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| BMR | O(\|𝒮\|+\|𝒜\|+\|Π\|) + 标定 | O(\|B\|) | 溯源哈希、标定可复现、容差包络 |
| PCB | O(\|X\|·T·QP) | O(\|X\|) | 核差 `d_H` 保守上界、签名 Lipschitz |
| QEC | O(\|P\|·\|G\|) + LLM 解析 | O(\|G\|) | 受限本体、命题良构、证据缺口可枚举 |
| GVA | O(QEC + 蕴含检查) | O(\|E\|+\|Γ\|) | 只允许证据蕴含的答案、模板渲染 |
| FDC | O(n·\|X\| + n log n) | O(n) | 同类聚类稳健、离群不参与交集 |
| LAC | O(\|A_meas\|·IG) | O(\|A_meas\|) | 测量动作经护盾可行性过滤 |

**正确性定理（Open-Body Grounded Answer Soundness）**
假设第 55 轮 (A29)–(A32) 成立；新增
**(A33)** 身体签名到生存核的 Hausdorff 位移满足 `d_H(K_B,K_{B'}) ≤ L_B·d_β(β(B),β(B'))`；
**(A34)** 部署身体 `B'` 的溯源通过认证且 `B'∈[B_ref]_τ`，其标定在容差包络内；
**(A35)** 问题编译只接受良构命题，蕴含检查器单侧错误率 ≤ `ε_ent`，渲染器满足忠实性契约；
**(A36)** 不可回答的问题要么触发经护盾约束的主动测量，要么弃权，绝不直接生成 `yes/no`。
则对任意问题 `q`，部署后同时“答案有据”且“动作安全”的概率满足
```
P(faithful ∧ safe) ≥ 1 - P(B'∉[B_ref]_τ) - P(provenance_fail)
                     - P(portability_gap) - P(ε_ent)
                     - P(render_unfaithful) - P(shield_fallback_fails)
```
关键：**身体是变量、语言是视图、证据是唯一事实来源**；任何一层都不能把“同款开源硬件”当作“同一台可信身体”，也不能把“模型说 yes”当作“证据已蕴含”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| VQA 流畅幻觉把不确定性洗白 | 高 | 证据蕴含 + 强制弃权 + 模板渲染 + 忠实性断言 |
| 问题编译歧义/越界命题 | 高 | 受限本体 + 良构性检查 + 歧义即弃权 |
| 身体签名欠定义、溯源可伪造 | 高 | 多模态签名 + 硬件根信任/签名固件 + 开源可复现构建 |
| 车队数据投毒/恶意构型 | 高 | 稳健离群检测 + 可信锚点 + 证书交集不吞并离群 |
| 可迁移包络过保守导致普遍拒答 | 中 | 分层签名 + 主动标定缩小包络 + 可迁移预算 |
| 主动测量本身引入风险/磨损 | 中 | 护盾约束 + 单位风险信息增益 + 测量预算 |

## 6. 本轮最大风险

**一句话**：开源硬件车队与有据 VQA 把“身体可信”与“语言回答”都变成可审计对象，但其 soundness **三重依赖身体签名覆盖真实构型分布、车队证书交集不被恶意/离群构型污染、以及语言渲染始终忠实于证据蕴含**；一旦签名漏掉关键动力学子空间、或 VQA 在证据缺口处仍给出流畅肯定，系统就会在未认证的身体上执行“语言认证过”的动作——因此必须以 **身体护照 + 稳健车队交集 + 强制弃权/模板渲染** 三重护栏，宁可回答“不知道并去测量”，也绝不把一句自然语言当成接触安全的证明。

# 第 56 轮产物 · 创新点清单 v32：OpenBody-GroundedVQA（BMR×PCB×QEC×GVA×FDC×LAC）

> 承接第 55 轮语义-接触层与第 54 轮 v31 GroundEdge-GenSim+++。v32 把证书体系里两个从未被显式审计的前提——**身体假设**与**人机语言接口**——提升为一等公民：

| `J_s` | 语义-接触联合证书（第 55 轮） |
| `B=(h,𝒮,𝒜,K_cal,Π_tol,ℱ)` | 身体护照：溯源、传感器、执行器、标定、容差、故障集 |
| `β(B)` | 身体签名 `(β_kin,β_dyn,β_sens,β_cal)` |
| `[B]_τ` | 身体签名等价类 |
| `Π(J,B')` | 证书从参考身体到 `B'` 的可迁移包络 |
| `δ_B = d_H(K_B,K_B')` | 身体条件核的 Hausdorff 位移 |
| `Q(q)=(P_q,G_q,b_q)` | 问题→证据查询：命题、证据 DAG、预算 |
| `Gap(q)=G_q\E` | 证据缺口 |
| `Ans(q)=(a,E,Γ,abstain)` | 有据答案：结论、证据、推导、弃权标志 |
| `J_fleet, r_fleet` | 车队差分证书、车队可迁移风险 |
| `a_m^*` | 语言条件主动标定选出的测量动作 |

**定义 127（身体护照与身体签名）**
`B=(h, 𝒮, 𝒜, K_cal, Π_tol, ℱ)`；`β(B)=(β_kin, β_dyn, β_sens, β_cal)`；`[B]_τ={B' | d_β(β(B),β(B')) ≤ τ}`。

**定义 128（身体条件生存核与可迁移包络）**
`K_B(Σ) = {x | ∃u∈A_WB, λ: f_B(x,u,λ)=ẋ ∧ supp(λ)⊆C^+(Σ) ∧ λ∈FC(μ_B) ∧ x_{t+1}∈𝒳_safe}`；
`Π(J,B') = sup{ε | ∀B''∈[B']_τ, d_H(K_{B''}^{in},K_B^{in}) ≤ ε ∧ K_margin(B'') ≥ θ_K}`。

**定义 129（问题→证据查询）**
`Q(q)=(P_q,G_q,b_q)`；可回答性要求 `E ⊢ P_q` 或 `E ⊢ ¬P_q`，且 `coverage(E) ≥ γ`、`conf(E) ≥ 1-α`、`cost(E) ≤ b_q`。

**定义 130（有据答案与弃权）**
`Ans(q)=(a,E,Γ,abstain)`，`a=yes ⇒ E⊢P_q`，`a=no ⇒ E⊢¬P_q`，`a=unknown ⇔` 不可回答；`ℓ(q)=render(a,E,Γ)` 必须忠实。

**定义 131（车队差分证书）**
`J_fleet = ⋂_{B_i∈[B]_τ} J_i`，`r_fleet = P_{B'∼𝒟_ℬ}(¬sound(J_fleet,B')) ≤ ρ_port`；裕度剖面离群超过 `k` 个稳健标准差即触发重标定。

**定义 132（语言条件主动标定）**
`a_m^* = argmax_{a∈A_meas, shield.feasible(a)} I(P_q;Y_a|E)/(c(a)+λ·r(a))`。

### IP-128 PCB

```python
def portable_certificate(J_ref, B_ref, B_new, Sigma, tau, eps):
    if d_beta(signature(B_new), signature(B_ref)) > tau:
        return ('reject', 'body_out_of_class')
    K_ref = viability_kernel(Sigma, B_ref)
    K_new = viability_kernel(Sigma, B_new)
    dH = hausdorff(K_ref.inner, K_new.inner)        # conservative bound
    if dH > eps:
        return ('reject', 'kernel_shift', dH)
    J_new = retarget(J_ref, B_new, dH)
    if J_new.K_margin < theta_K or J_new.rho_sem < rho_min:
        return ('reject', 'margin_lost', J_new.K_margin)
    return ('ok', J_new)
```

### IP-129 QEC

```python
def compile_question(q, J, B, ontology, budget):
    P = constrained_parse(q, ontology)              # propositions only
    if not well_typed(P):
        return ('reject', 'ambiguous_question')
    G = build_evidence_dag(P, fields=J.fields | B.fields)
    E = available_evidence(G, J, B)
    if entails(E, P) or entails(E, neg(P)):
        return ('answerable', P, G, E)
    return ('unanswerable', P, G, Gap(G, E),
            select_measurement(Gap(G, E), budget))  # IP-132
```

### IP-130 GVA

```python
def grounded_answer(q, J, B, budget):
    status = compile_question(q, J, B, ontology, budget)
    if status.kind == 'reject':
        return Answer('unknown', evidence=None, reason='ambiguous')
    if status.kind == 'unanswerable':
        return Answer('unknown', evidence=status.gap,
                      plan=status.next_measurement)
    E, Gamma = derive(status)
    if entails(E, status.P):
        a = 'yes'
    elif entails(E, neg(status.P)):
        a = 'no'
    else:
        return Answer('unknown', evidence=status.gap)
    text = render_template(q, a, E, Gamma)          # no free-form safety claims
    assert faithful(text, a, E, Gamma)
    return Answer(a, E, Gamma, text=text)
```

### IP-131 FDC

```python
def fleet_certificate(fleet, Sigma, tau, rho_port, k=3.0):
    classes = cluster_by_signature(fleet, tau)
    out = []
    for B_class in classes:
        margins = [local_margin(B, Sigma) for B in B_class]
        anomalies = robust_outliers(margins, k=k)
        J_cls = intersect([local_certificate(B, Sigma)
                           for B in B_class if B not in anomalies])
        if J_cls is None or portability_risk(J_cls, B_class) > rho_port:
            out.append(('gap', B_class, anomalies, 'recalibrate'))
        else:
            out.append(('ok', J_cls, anomalies))
    return FleetCertificate(out)
```

### IP-132 LAC

```python
def select_measurement(gap, budget, shield):
    best, best_score = None, -1.0
    for a in measurement_actions(gap):
        if not shield.feasible(a):
            continue
        score = expected_info_gain(gap, a) / (
            cost(a) + budget.lam * shield.risk(a))
        if score > best_score:
            best, best_score = a, score
    return best if best_score > 0 else None
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| BMR | O(\|𝒮\|+\|𝒜\|+\|Π\|) + 标定 | O(\|B\|) | 溯源哈希、标定可复现、容差包络 |
| PCB | O(\|X\|·T·QP) | O(\|X\|) | `d_H` 保守上界、签名 Lipschitz |
| QEC | O(\|P\|·\|G\|) + 解析 | O(\|G\|) | 受限本体、命题良构、缺口可枚举 |
| GVA | O(QEC + 蕴含检查) | O(\|E\|+\|Γ\|) | 只允许证据蕴含的答案、模板渲染 |
| FDC | O(n·\|X\| + n log n) | O(n) | 同类聚类稳健、离群不参与交集 |
| LAC | O(\|A_meas\|·IG) | O(\|A_meas\|) | 测量动作经护盾可行性过滤 |

**正确性定理（Open-Body Grounded Answer Soundness）**
假设第 55 轮 (A29)–(A32) 成立；新增
**(A33)** `d_H(K_B,K_{B'}) ≤ L_B·d_β(β(B),β(B'))`；
**(A34)** 部署身体 `B'` 溯源通过认证、`B'∈[B_ref]_τ` 且标定在容差包络内；
**(A35)** 问题编译只接受良构命题，蕴含检查器单侧错误率 ≤ `ε_ent`，渲染器满足忠实性契约；
**(A36)** 不可回答问题要么触发经护盾约束的主动测量，要么弃权，绝不直接生成 `yes/no`。
则部署后“答案有据且动作安全”的概率满足：
```
P(faithful ∧ safe) ≥ 1 - P(B'∉[B_ref]_τ) - P(provenance_fail)
                     - P(portability_gap) - P(ε_ent)
                     - P(render_unfaithful) - P(shield_fallback_fails)
```
关键：**身体是变量、语言是视图、证据是唯一事实来源**。

## 6. 本轮最大风险

**一句话**：开源硬件车队与有据 VQA 把“身体可信”与“语言回答”都变成可审计对象，但其 soundness **三重依赖身体签名覆盖真实构型分布、车队证书交集不被恶意/离群构型污染、以及语言渲染始终忠实于证据蕴含**；一旦签名漏掉关键动力学子空间、或 VQA 在证据缺口处仍给出流畅肯定，系统就会在未认证的身体上执行“语言认证过”的动作——故必须以 **身体护照 + 稳健车队交集 + 强制弃权/模板渲染** 三重护栏，宁可回答“不知道并去测量”，也绝不把一句自然语言当成接触安全的证明。
