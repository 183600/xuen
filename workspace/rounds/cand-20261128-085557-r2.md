### 第 8 轮灵感驱动研究记录

**灵感词**：嵌入式系统、场景驱动创新

**继承关系**：第 7 轮 EFA-v7（IP-501~IP-504）把系统从「指令驱动」推进到「需求驱动」，用 DIM/DRC/DAC 三个智能软因子推断用户意图。但 v7 隐含假设「算力无界」：DRC 是 5~50 ms 的 LLM 推理，DIM/DAC 是浮点神经网络，而机器人嵌入式控制器只有有界算力、有界内存和硬实时约束。本轮延续「零新增硬门」原则，聚焦「**算力-安全-场景三角约束**」：把「场景」提升为一等公民，用「场景契约」把每个部署场景编译成「资源预算 + 配置格」，并证明「计算降级只收紧不扩张执行集」——让 fail-closed 从「逻辑维度」扩展到「资源维度」。

**直觉与动机**：

1. **嵌入式系统 → 从「无界智能」到「有界计算」**。v7 的软因子链默认可以「随时算」。嵌入式视角逼问：这段智能的 WCET 是多少？占多少 SRAM？电池场景下能耗多少？直觉上，智能必须被「预算化」：DRC 的 LLM 在线推理被搬到离线，在线只做「场景索引的缓存推理链查表」；DIM/DAC 量化为 int8 定点并附 (wcet, mem) 证书。软因子从「任意精度浮点」变成「带资源标签的有界算子」。

2. **场景驱动创新 → 从「技术推动」到「场景牵引」**。不是让系统在所有场景都跑满 v7，而是让「场景契约」决定「用多少智能」。定义场景契约 σ = (场景指纹 φ_scene, 预算 b, 安全等级 r)，编译到配置格 L(σ)：MCU 仓储场景退化为 v6 规则，边缘 GPU 家庭场景跑满 v7，两者共享同一套硬门证书。关键洞见：**创新发生在场景边界，而不是模型内部**——同一份智能按场景特化，而不是无差别堆叠。

3. **混合关键度 → 从「统一调度」到「分级调度」**。把七硬门划为 HI-criticality（不可抢占、WCET 认证、预算优先保障），把软因子划为 LO-criticality（弹性、可裁剪）。丢弃软因子时，把它置为中性 1.0 而不是 0——阈值只会回落到 v6 水平，执行集始终 ⊆ Exec(v6)。这让「资源不足」不再是安全漏洞，而是可证明的保守退化。

**关键洞见**：第 7 轮回答「如何主动推导需求」；第 8 轮回答「如何让这种推导在有界算力的嵌入式平台上仍然 fail-closed」。七硬门原样复用、零新增硬门；本轮新增：
- IP-505 SCC（场景契约编译器），
- IP-506 MCB（混合关键度预算器），
- IP-507 WQSF（WCET 量化软因子 + 场景缓存推理链），
- IP-508 EFA-v8（资源弹性装配器）。

**形式化目标（增量）**：

1. **SCC（Scenario Contract Compiler）**：<br>
   - 场景指纹 φ_scene = Hash(task_type, env_class, user_cluster)<br>
   - 场景契约 σ = (φ_scene, b_wcet, b_mem, b_energy, r_safety)，离线编译、签名、版本化<br>
   - 配置格 L(σ) = {允许运行的软因子子集}，按成本单调排序<br>
   - 未命中契约 → 保守默认契约（只跑硬门，软因子全中性）

2. **MCB（Mixed-Criticality Budgeter）**：<br>
   - 任务集 T = T_HI ∪ T_LO，T_HI = 七硬门 + GGC/MCTM/STM/FAMK，T_LO = DIM/DRC/DAC<br>
   - 编译期断言 b_HI = Σ wcet_hi ≤ b_wcet，否则拒绝部署该场景<br>
   - 在线 b_LO = b_wcet − b_HI，按 η 贡献/成本比贪心选择 LO 子集<br>
   - 裁剪的软因子置为中性 1.0（不是 0），保证阈值只回落不越界

3. **WQSF（WCET-Quantized Soft-Factor）**：<br>
   - η_j^{int8} = Quantize(η_j)，定点 softmax，附 (wcet_j, mem_j) 证书<br>
   - DRC 在线 = R_DRC[φ_scene] 查表，O(1)；LLM 只在离线/慢时域<br>
   - 量化后强制 clamp 到 [1, 1+ε]，防止 η < 1 破坏单调性

4. **EFA-v8（零新增硬门 + 预算弹性软因子链）**：<br>
   - Exec(D_b(EFA-v8)) ⊆ Exec(EFA-v6)，对所有预算 b 成立（计算-安全单调性）<br>
   - HI 任务不可抢占、WCET 认证；超证书 → 看门狗安全停机<br>
   - 软因子链按预算裁剪，Πη ∈ [1, 1.3] 恒成立

5. **形式化定义**：给定场景上下文 C、指令 L：<br>
   - φ = SCC.fingerprint(C)；σ = SCC.compile(φ)<br>
   - sched = MCB.schedule(σ)；η_set = MCB.shed(sched)<br>
   - η_demand = WQSF.eta_demand(φ, L)；η_affect = WQSF.quantized_dac.eta(C.face)<br>
   - x = EFA-v7.select_with_factors(L, t_now, C, η_set)<br>
   - 若 sched.degraded：记录降级审计，执行集仍 ⊆ Exec(v6)

**本轮最大风险**：**场景契约的静态完备性假设**——假设所有部署场景都能被预先枚举并编译成契约，但真实场景存在长尾漂移与组合爆炸；一旦场景误分类，预算分配与配置选择将偏离实际，混合关键度的 WCET 保障与 fail-closed 边界可能同时失效。

## 2. 关键算法骨架

### IP-505 SCC：场景契约编译器

```python
@dataclass
class ScenarioContractCompiler:
    """SCC：把场景编译为「资源预算 + 配置格」。
    输入：场景指纹 φ_scene；输出：签名契约 σ 与配置格 L(σ)。
    契约离线编译、签名、版本化，在线只做哈希 + 查表。"""
    contracts: dict[str, ScenarioContract]   # φ_scene → σ
    fallback: str = "SCENE_CONSERVATIVE"      # 只跑硬门，软因子全中性

    def fingerprint(self, context) -> str:
        """φ_scene：任务类型 × 环境类别 × 用户历史簇，离散化为可查表指纹"""
        return self._hash(context.task, context.env_class, context.user_cluster)

    def compile(self, phi: str) -> ScenarioContract:
        """查表；未命中返回保守默认契约（预算最小、只跑硬门）"""
        return self.contracts.get(phi, self.contracts[self.fallback])

    def config_lattice(self, sigma) -> list[SoftFactorSet]:
        """配置格：按成本单调排序的软因子子集，保证降级路径单调"""
        return sorted(sigma.allowed_subsets, key=lambda s: s.cost)
```

### IP-506 MCB：混合关键度预算器

```python
@dataclass
class MixedCriticalityBudgeter:
    """MCB：混合关键度预算器。
    T_HI = {七硬门 + GGC/MCTM/STM/FAMK}：不可抢占、WCET 认证；
    T_LO = {DIM/DRC/DAC 软因子}：弹性、可裁剪。
    不变量：任何超预算只裁剪 T_LO，绝不跳过 T_HI。"""
    hi_tasks: list[Task]      # 每个 task 带 wcet_hi 证书
    lo_tasks: list[Task]      # 每个 task 带 wcet_lo 与 η 贡献
    deadline_ms: float

    def schedule(self, sigma, t_now) -> Schedule:
        b_hi = sum(t.wcet_hi for t in self.hi_tasks)
        assert b_hi <= sigma.b_wcet, "HI 预算不足 → 场景不可部署（编译期拒绝）"
        b_lo = sigma.b_wcet - b_hi
        # 按 η 贡献/成本比贪心选择 LO 子集
        chosen, spent = [], 0.0
        for task in sorted(self.lo_tasks, key=lambda t: t.value_per_ms, reverse=True):
            if spent + task.wcet_lo <= b_lo:
                chosen.append(task)
                spent += task.wcet_lo
        return Schedule(hi=self.hi_tasks, lo=chosen,
                        degraded=len(chosen) < len(self.lo_tasks))

    def shed(self, schedule) -> SoftFactorSet:
        """被裁剪的软因子置为中性 1.0（不是 0！）——阈值只回落到 v6 水平"""
        active = {j: 1.0 for j in ALL_SOFT}
        active.update(schedule.active_factors())
        return SoftFactorSet(active)
```

### IP-507 WQSF：WCET 量化软因子

```python
@dataclass
class WCETQuantizedSoftFactor:
    """WQSF：把 v7 软因子变为有界定点算子。
    DIM/DAC：int8 量化 + 定点 softmax，输出 clamp 到 [1, 1+ε]；
    DRC：在线不做 LLM，改为场景缓存推理链查表 R_DRC[φ_scene]。"""
    quantized_dim: QuantizedModule
    quantized_dac: QuantizedModule
    reasoning_cache: dict[str, CachedChain]   # 离线 LLM 采样，按 φ_scene 索引

    def eta_demand(self, phi: str, L: str) -> float:
        """在线 O(1)：查缓存推理链；未命中则回退中性 1.0（保守）"""
        chain = self.reasoning_cache.get(phi)
        if chain is None:
            return 1.0
        return max(1.0, min(1.0 + EPS, chain.eta))   # 防止量化误差使 η < 1

    def certify(self) -> dict[str, WCET]:
        """返回每个软因子的 (wcet, mem) 证书，供 MCB 做预算"""
        return {'dim': self.quantized_dim.wcet,
                'dac': self.quantized_dac.wcet,
                'drc': WCET(wcet=LOOKUP_MS, mem=CHAIN_BYTES)}
```

### IP-508 EFA-v8：资源弹性装配器

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：零新增硬门 + 预算弹性软因子链 + 计算-安全单调性。
    不变量：Exec(D_b(EFA-v8)) ⊆ Exec(EFA-v6) 对所有预算 b 成立。"""
    scc: ScenarioContractCompiler
    mcb: MixedCriticalityBudgeter
    wqsf: WCETQuantizedSoftFactor
    v7: EvidenceForgingAssemblerV7   # 复用软因子语义与七硬门
    v6: EvidenceForgingAssemblerV6   # 保守基线（执行集上界）

    def select(self, L, t_now, context):
        # 1. 场景编译（离线缓存，在线查表）
        phi = self.scc.fingerprint(context)
        sigma = self.scc.compile(phi)

        # 2. 混合关键度调度：先保障 HI（七硬门），再分配 LO（软因子）
        sched = self.mcb.schedule(sigma, t_now)
        eta_set = self.mcb.shed(sched)          # 被裁剪项 = 中性 1.0

        # 3. 有界软因子（在线只做 int8 前向 + 查表）
        eta_set['demand'] = self.wqsf.eta_demand(phi, L)
        eta_set['affect'] = self.wqsf.quantized_dac.eta(context.face)

        # 4. 复用 v7 软因子语义与七硬门，软因子链按预算裁剪
        ok, x, tag = self.v7.select_with_factors(L, t_now, context, eta_set)
        return ok, x, tag, sched.degraded

    def degrade(self, b: float) -> Config:
        """降级算子 D_b：预算越少 → 软因子子集越小 → Πη 越接近 1
        → 阈值回落到 τ^v6（而非低于），执行集单调收缩到 Exec(v6)"""
        return self.scc.config_lattice_under(b)

    def watchdog(self, hi_elapsed_ms: float, hi_budget_ms: float):
        """HI 任务超过 WCET 证书 → 安全停机（fail-closed），绝不静默续跑"""
        if hi_elapsed_ms > hi_budget_ms:
            raise SafeStop("HI_WCET_OVERRUN")
```

### 集成流水线（v7 → v8）

```
离线/慢时域（分钟~小时级）：
  场景枚举 → SCC 编译签名契约 σ（预算 + 配置格）→ 版本化下发
  LLM 采样场景推理链 → R_DRC[φ_scene] 缓存表
  DIM/DAC int8 量化 + 硬件在环 WCET 标定 → (wcet, mem) 证书

在线准入（亚毫秒级，固定内存、无动态分配）：
  φ = SCC.fingerprint(context) ──▶ σ = SCC.compile(φ)
  sched = MCB.schedule(σ) ──▶ η_set = MCB.shed(sched)   # HI 先保障
  η_demand = WQSF.eta_demand(φ, L)  # 查表 O(1)，不再在线跑 LLM
  η_affect = WQSF.quantized_dac.eta(face)
  EFA-v7.select_with_factors(..., η_set) ──▶ (ok, x, tag, degraded)

在线控制环（目标 < 0.6 ms，优于 v7 的 0.8 ms）：
  HI 任务（七硬门）不可抢占、WCET 认证；LO 任务填剩余预算
  超 HI 证书 → 看门狗 SafeStop；软因子裁剪只记录审计、不改硬门
```

## 4. 正确性论证（增量更新）

### 定理 13（计算-安全单调性）

**陈述**：设 D_b 为预算 b 下的降级算子，它只把部分软因子置为中性 1.0。则对所有预算 b：
- Exec(D_b(EFA-v8)) ⊆ Exec(EFA-v6)
- 且 D_b 关于 b 单调：b₁ ≤ b₂ ⇒ Exec(D_{b₂}) ⊆ Exec(D_{b₁})

**证明**：任一软因子 η_j ∈ [1, 1+ε]（WQSF 强制 clamp）。软阈值 τ_i^v8 = γ_i·τ_i^v6·Πη，其中 Πη = ∏_{j∈active} η_j ∈ [1, 1+ε]，被裁剪项取 1.0 不改变下界。故 τ_i^v8 ≥ τ_i^v6 恒成立；判定 s_i ≥ τ_i^v8 ⇒ s_i ≥ τ_i^v6，所以执行集 ⊆ Exec(v6)。预算减少只会移除软因子，使 Πη 单调趋近 1，τ_i^v8 单调下移至 τ_i^v6 但永不跌破，故执行集随 b 减小而单调扩张，但上界始终为 Exec(v6)。∎

### 定理 14（混合关键度 WCET 保障）

**陈述**：若场景契约在编译期满足 b_HI = Σ wcet_hi ≤ b_wcet，且每个 HI 任务持有有效 WCET 证书，则在线控制环在任意 LO 负载下都不错过 deadline，且 HI 任务永不被裁剪。

**证明**：HI 任务不可抢占且优先调度，其最坏完成时间由证书上界 Σ wcet_hi 给出；LO 任务只在剩余预算 b_LO = b_wcet − b_HI 内被贪心填充，裁剪 LO 不影响 HI 完成时刻，故总耗时 ≤ b_HI + b_LO = b_wcet = deadline。若某 HI 任务实测超过证书，watchdog 触发 SafeStop，而非静默续跑——fail-closed 在资源维度成立。∎

### 诚实声明

- 场景指纹离散化会漏掉长尾场景，未命中只能走保守默认契约，创新收益归零；
- WCET 证书依赖硬件/编译器/缓存状态，跨平台迁移需重新标定，证书可能失真；
- int8 量化会改变 η 数值，须离线验证量化误差不使 η < 1（否则破坏定理 13）；
- 缓存推理链是离线采样的，场景演化后缓存过期，η_demand 退化为中性 1.0（保守但失智）；
- 混合关键度依赖任务级隔离；若 HI/LO 共享缓存或内存带宽，仍可能发生 timing interference，证书需包含干扰上界。

### 5.1 实验设计

- **平台**：STM32H7（MCU，int8-only，无 OS）+ Jetson Orin Nano（边缘 GPU）+ UR10e（6DOF）+ 移动底盘（2DOF）+ 摄像头
- **场景契约**：仓储拣选（deadline 最紧）、厨房协助（能耗预算最紧）、老人陪护（安全等级最高）
- **对照**：v6-full、v7-full、v8-full、消融 A21（无 SCC，固定 v7 配置）、A22（无 MCB，全部按 HI 调度）、A23（无 WQSF，浮点 DIM/DAC + 在线 LLM）、A24（裁剪置 0 而非中性 1.0）
- **场景**：
  - (a) MCU 仓储：预算仅够硬门 + DAC，DIM/DRC 被裁剪 → 执行集应 ⊆ Exec(v6)
  - (b) 边缘 GPU 家庭：预算充足跑满 v7 软因子 → 行为与 v7 等价
  - (c) 长尾未命中：未见场景 → 保守默认契约，只跑硬门，审计记录
  - (d) WCET 压力：注入缓存干扰使 HI 超证书 → watchdog SafeStop
- **指标**：deadline 违约率、WCET 超证书率、每任务能耗、执行集包含关系（安全审计）、场景覆盖率、降级频率、端到端 P99

## 6. 风险表（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R67 | **场景契约静态完备性** | **极高** | 长尾场景在线检测、保守默认契约、契约版本回滚 | 场景组合爆炸与漂移，契约格无法覆盖 |

## 7. 本轮最大风险（最终确认）

**一句话**：**场景契约的静态完备性假设**——假设所有部署场景都能被预先枚举并编译成契约，但真实场景存在长尾漂移与组合爆炸；一旦场景误分类，预算分配与配置选择将偏离实际，混合关键度的 WCET 保障与 fail-closed 边界可能同时失效。
