### 第 1 轮灵感驱动研究记录

**灵感词**：自主导航、灵巧手

**直觉与动机**：
现有框架已从「感知-合规-能量」→「结构-力学」→「语义-重构-协同」逐层堆叠出七证一体的 SRC-USC，但它仍是"静态本体 + 群体几何"的证书体系，缺失机器人最基础的两类具身能力：**在未知环境中自主抵达（导航）**与**在接触中稳定操控（灵巧手）**。受「自主导航」启发，导航的本质不是"规划一条路径"，而是"在定位不确定性传播下证明存在一条安全走廊"——这是存在性证书；受「灵巧手」启发，抓取的本质不是"闭合手指"，而是"证明外力旋量被摩擦锥的正张成包络"——这是包含性证书。二者的深层同构在于：**导航在环境流形上证明"可达"，灵巧手在接触流形上证明"可握"，移动灵巧操作则要求二者在同一个任务流形上同时可达且连通**。核心洞见：**导航是可通行流形上的存在性证书，灵巧手是接触流形上的包含性证书，移动灵巧操作是任务流形上的连通性证书**。更关键的是，导航只把真实位姿约束在可信集 X̂ 内而非精确送达，因此抓取必须是**集合值抓取**（∀x∈X̂ 力封闭），否则会产生"导航漂移 × 接触失配"的复合假阳性。

**形式化目标**：
1. 定义导航可行性证书（NFC）：可信状态集 ℙ(x_t∈X̂_t)≥1-δ_loc、安全走廊 (X̂_t⊕ℬ)⊆C_t⊆ℱ、动力学可行 |ξ̇|≤v_max ∧ |ξ̈|≤a_max ∧ |κ|≤κ_max、可通行裕度 τ≥τ_min 四重保证
2. 定义灵巧抓取证书（DGC）：力封闭 ℝ^6⊆span_+(G)、外力包络 𝒲_ext⊆𝒲_grasp/γ_g、摩擦锥裕度 |f_t|≤μf_n ∧ f_n≥f_min、关节/可操作度可达性 ρ_manip≥ρ_min，且对整条可信状态集 X̂ 做集合值验证
3. 定义任务流形可达性证书（TMRC）：T={(x,g): x∈ℱ_nav ∧ g∈ForceClosure(x)} 非空、连通、且对 (X̂,Ĝ) 鲁棒；联合覆盖用并集界 ℙ≥1-(δ_loc+δ_grasp)，不依赖独立性
4. 构建自主导航-灵巧操作统一准入门（AND-UC）：SRC-USC∪NFC∪DGC∪TMRC 十证一体，Exec_v26=Exec_v25∩Fil_nav∩Fil_dex∩Fil_task⊆Exec_v25
5. 证明定位漂移/接触滑移/任务流形断裂三条退化路径下单调链保持，并显式区分"采样概率完备"与"完备证明"的边界

```python
# ============================================================
# IP-448 Navigation Feasibility Certificate (NFC) — 导航可行性证书
# ============================================================
@dataclass
class NavigationFeasibilityCertificate:
    """定位-走廊-动力学-可通行 四重保证（存在性证书）"""
    traj: Tensor                        # [T, 3] 或 SE(3) 路点
    state_sets: list['Ellipsoid']       # X̂_t 可信状态集
    corridor: list['ConvexPolytope']    # C_t 安全走廊
    footprint: 'InflatedShape'          # ℬ 膨胀足迹
    free_space: 'FreeSpaceOracle'       # ℱ 碰撞查询
    terrain: 'TerrainMap'               # 坡度/台阶/粗糙度
    robot_capability: 'TerrainCapability' = None
    delta_loc: float = 0.05             # 定位失效风险
    v_max: float = 1.0
    a_max: float = 2.0
    kappa_max: float = 1.0
    tau_min: float = 0.3                # 最小可通行裕度

    def verify_localization_bound(self) -> bool:
        """ℙ(x_t ∈ X̂_t) ≥ 1-δ_loc（EKF 协方差/区间传播/离线 conformal 校准）"""
        for X in self.state_sets:
            if X.coverage < 1.0 - self.delta_loc:
                return False
        return True

    def verify_safe_corridor(self) -> bool:
        """(X̂_t ⊕ ℬ) ⊆ C_t ⊆ ℱ 且 C_t 凸（IRIS/凸分解式走廊）"""
        for X, C in zip(self.state_sets, self.corridor):
            inflated = X.minkowski_sum(self.footprint)
            if not C.is_convex():
                return False
            if not C.contains(inflated):
                return False
            if not self.free_space.contains(C):
                return False
        return True

    def verify_kinodynamic(self) -> bool:
        """|ξ̇|≤v_max ∧ |ξ̈|≤a_max ∧ |κ|≤κ_max"""
        v = finite_difference(self.traj)
        a = finite_difference(v)
        kappa = curvature(self.traj)
        return (v.abs().max() <= self.v_max and
                a.abs().max() <= self.a_max and
                kappa.abs().max() <= self.kappa_max)

    def verify_traversability(self) -> bool:
        """τ(ξ)=min(坡度,台阶,粗糙度) ≥ τ_min"""
        for p in self.traj:
            tau = self.terrain.traversability_margin(p, self.robot_capability)
            if tau < self.tau_min:
                return False
        return True

    def verify_all(self) -> bool:
        return (self.verify_localization_bound() and
                self.verify_safe_corridor() and
                self.verify_kinodynamic() and
                self.verify_traversability())

    def min_margin(self) -> float:
        """四类约束的最小归一化裕度（供 TMRC 组合）"""
        return min(self._loc_margin(), self._corridor_margin(),
                   self._dyn_margin(), self._trav_margin())


# ============================================================
# IP-449 Dexterous Grasp Certificate (DGC) — 灵巧抓取证书
# ============================================================
@dataclass
class DexterousGraspCertificate:
    """力封闭-外力包络-摩擦锥-可达性 四重保证（包含性证书）"""
    contact_points: Tensor               # [m, 3] 接触点（手部系）
    contact_normals: Tensor              # [m, 3] 内法向
    grasp_matrix: Tensor                 # G ∈ ℝ^{6×m}
    mu: float = 0.5                      # 摩擦系数
    w_ext_set: 'WrenchPolytope' = None   # 外力旋量集
    joint_config: Tensor = None          # 手部关节角
    joint_limits: tuple = None           # (q_min, q_max)
    manipulability: float = None
    gamma_g: float = 1.2                 # 外力包络安全系数
    rho_min: float = 0.02
    f_min: float = 0.5                   # 最小法向力
    delta_grasp: float = 0.03            # 抓取覆盖风险
    n_dir: int = 512                     # 力封闭方向采样数

    def verify_force_closure(self) -> bool:
        """ℝ^6 ⊆ span_+{G_i}：方向可达性 SOCP 检验"""
        for d in unit_sphere_samples(6, self.n_dir):
            if not self._direction_reachable(d):
                return False
        return True

    def _direction_reachable(self, d: Tensor) -> bool:
        """∃λ∈∏_i FrictionCone_i(μ): Gλ = d 且法向分量 ≥ f_min"""
        import cvxpy as cp
        lam = cp.Variable(self.m, 3)
        constraints = [self.grasp_matrix @ lam.reshape(-1) == d]
        for i in range(self.m):
            n = self.contact_normals[i]
            fn = lam[i] @ n
            constraints += [cp.norm(lam[i] - fn * n) <= self.mu * fn,
                            fn >= self.f_min]
        prob = cp.Problem(cp.Minimize(0), constraints)
        prob.solve()
        return prob.status == cp.OPTIMAL

    def verify_external_wrench_envelope(self) -> bool:
        """𝒲_ext ⊆ 𝒲_grasp/γ_g：多面体顶点逐一可达"""
        if self.w_ext_set is None:
            return False
        for v in self.w_ext_set.vertices:
            if not self._direction_reachable(v / self.gamma_g):
                return False
        return True

    def verify_contact_stability(self) -> bool:
        """|f_t| ≤ μ f_n ∧ f_n ≥ f_min（由力分配解逐接触点核验）"""
        lam = self._solve_force_allocation()
        for i in range(self.m):
            n = self.contact_normals[i]
            fn = lam[i] @ n
            ft = torch.norm(lam[i] - fn * n)
            if ft > self.mu * fn or fn < self.f_min:
                return False
        return True

    def verify_reachability(self) -> bool:
        """q∈[q_min,q_max] ∧ ρ_manip ≥ ρ_min"""
        if self.joint_config is None or self.joint_limits is None:
            return False
        qmin, qmax = self.joint_limits
        if (self.joint_config < qmin).any() or (self.joint_config > qmax).any():
            return False
        return self.manipulability >= self.rho_min

    def verify_all(self) -> bool:
        return (self.verify_force_closure() and
                self.verify_external_wrench_envelope() and
                self.verify_contact_stability() and
                self.verify_reachability())

    def min_margin(self) -> float:
        """力封闭/摩擦/可达 的最小归一化裕度"""
        return min(self._fc_margin(), self._friction_margin(),
                   self._reach_margin())


# ============================================================
# IP-450 Task-Manifold Reachability Certificate (TMRC)
# 导航与灵巧手的桥接：非空-连通-鲁棒
# ============================================================
@dataclass
class TaskManifoldReachabilityCertificate:
    """T ⊆ X × 𝒢 非空、连通、对联合不确定性鲁棒"""
    nfc: NavigationFeasibilityCertificate
    dgc: DexterousGraspCertificate
    task_manifold: 'TaskManifold'        # contains(x, g)
    start_state: tuple                   # (x0, g0)
    goal_state: tuple                    # (x*, g*)
    delta_task: float = 0.10             # 任务级联合风险预算
    path_samples: int = 2000
    n_base_samples: int = 64             # X̂ 上抓取鲁棒采样

    def verify_nonempty(self) -> bool:
        """∃(x*,g*)∈T：导航终点存在，且集合值抓取在该位形上力封闭"""
        if self.goal_state is None:
            return False
        x_star, g_star = self.goal_state
        return (self.task_manifold.contains(x_star, g_star) and
                self.nfc.verify_all() and
                self.dgc.verify_all())

    def verify_connectivity(self) -> bool:
        """∃连续路径 γ:[0,1]→T，γ(0)=(x0,g0), γ(1)=(x*,g*)
        注意：PRM 仅概率完备，False 表示『未找到』而非『不存在』"""
        roadmap = self._build_task_roadmap(self.path_samples)
        return roadmap.connected(self.start_state, self.goal_state)

    def verify_robustness(self) -> bool:
        """∀x∈X̂_goal: DGC(x) 成立；联合覆盖用并集界（不依赖独立性）"""
        # 并集界：ℙ(导航 ∧ 抓取) ≥ 1-(δ_loc+δ_grasp)，与相关性无关
        if self.nfc.delta_loc + self.dgc.delta_grasp > self.delta_task:
            return False
        # 集合值抓取：导航只保证落在 X̂ 内，必须对整条可信集验证
        for x in self.nfc.state_sets[-1].samples(self.n_base_samples):
            if not self._dgc_at_base(x).verify_all():
                return False
        return self.nfc.min_margin() > 0 and self.dgc.min_margin() > 0

    def verify_all(self) -> bool:
        return (self.verify_nonempty() and
                self.verify_connectivity() and
                self.verify_robustness())

    def _dgc_at_base(self, x: 'Pose') -> DexterousGraspCertificate:
        """把抓取证书平移到基座位形 x，重算 G 与可达性"""
        return self.dgc.retarget(x)


# ============================================================
# IP-451 AND-UC 自主导航-灵巧操作统一准入门（十证一体）
# ============================================================
@dataclass
class AutonomousNavigationDexterityUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # 旧七证
    nfc: NavigationFeasibilityCertificate
    dgc: DexterousGraspCertificate
    tmrc: TaskManifoldReachabilityCertificate

    def admits(self, plan: 'MobileManipulationPlan',
               sensor_data: dict) -> bool:
        # 1. 旧七证（单机 USMC + SMC + RMC + MCC）
        if not self.src_usc.admits(
            plan, sensor_data,
            gt_entities=sensor_data.get('gt_entities'),
            queries=sensor_data.get('queries'),
            retrieved=sensor_data.get('retrieved')):
            return False
        # 2. 导航可行性
        if not self.nfc.verify_all():
            return False
        # 3. 灵巧抓取（集合值）
        if not self.dgc.verify_all():
            return False
        # 4. 任务流形可达性（桥接）
        if not self.tmrc.verify_all():
            return False
        return True


# ============================================================
# 扩展：移动灵巧操作流水线加入导航-抓取-任务流形证书链
# ============================================================
class MobileDexterousPipeline:
    def __init__(self, config: dict):
        self.and_uc = AutonomousNavigationDexterityUnifiedCertificate(
            src_usc=config['src_usc'],
            nfc=NavigationFeasibilityCertificate(**config['nfc']),
            dgc=DexterousGraspCertificate(**config['dgc']),
            tmrc=TaskManifoldReachabilityCertificate(
                nfc=config['nfc_obj'], dgc=config['dgc_obj'],
                task_manifold=config['task_manifold'],
                start_state=config['start_state'],
                goal_state=config['goal_state'],
                delta_task=config['delta_task']))

    def step(self, sensor_data: dict) -> tuple[bool, dict]:
        # 1. 导航层：定位→走廊→动力学→可通行
        nav_ok = self.and_uc.nfc.verify_all()
        if not nav_ok:
            return False, {'reason': 'NFC_reject',
                           'nav': self._nav_detail()}
        # 2. 感知/抓取层：集合值力封闭
        dex_ok = self.and_uc.dgc.verify_all()
        if not dex_ok:
            return False, {'reason': 'DGC_reject',
                           'dex': self._dex_detail()}
        # 3. 任务流形：非空-连通-鲁棒
        task_ok = self.and_uc.tmrc.verify_all()
        if not task_ok:
            return False, {'reason': 'TMRC_reject',
                           'task': self._task_detail()}
        # 4. 旧七证
        plan = self._compose_plan(sensor_data)
        admitted = self.and_uc.admits(plan, sensor_data)
        return admitted, {
            'plan': plan if admitted else None,
            'nav': self._nav_detail(),
            'dex': self._dex_detail(),
            'task': self._task_detail(),
        }


# 辅助函数
def finite_difference(x: Tensor) -> Tensor:
    return torch.diff(x, dim=0)

def curvature(traj: Tensor) -> Tensor:
    """离散曲率 κ \u2248 |v × a| / |v|³（2D/3D 路点）"""
    v = finite_difference(traj)
    a = finite_difference(v)
    cross = torch.cross(v[:-1], a, dim=-1)
    return cross.norm(dim=-1) / (v[:-1].norm(dim=-1).clamp_min(1e-6) ** 3)

def unit_sphere_samples(dim: int, n: int) -> Tensor:
    z = torch.randn(n, dim)
    return z / z.norm(dim=-1, keepdim=True)
```

## 3. 正确性论证（增量）

### 引理 13（NFC 的定位-走廊-动力学-可通行四重保证）
**陈述**：`NFC.verify_all() = True` ⟺ 导航方案同时满足：
(1) 可信定位 ℙ(x_t∈X̂_t)≥1-δ_loc，
(2) 安全走廊 (X̂_t⊕ℬ)⊆C_t⊆ℱ，
(3) 动力学可行 |ξ̇|≤v_max∧|ξ̈|≤a_max∧|κ|≤κ_max，
(4) 地形可通行 τ(ξ)≥τ_min。

**证明**：
1. (1) 由 EKF 协方差的卡方界或离线 conformal 校准给出边际覆盖；对时变系统用区间/椭球传播保持上界（非独立步需联合传播，否则逐步边际不保证轨迹级覆盖——见 R16）。
2. (2) 由凸走廊构造（IRIS/安全飞行走廊）保证凸性，Minkowski 和把定位不确定性与足迹一并膨胀，包含关系可多项式时间核验。
3. (3)(4) 为逐点不等式核验，必要且充分。
4. 四项分别对应"知道自己在哪/不撞/动得了/走得过去"，任一失败即该路径不可执行。
∎

### 引理 14（DGC 的力封闭-包络-摩擦-可达四重保证）
**陈述**：`DGC.verify_all() = True` ⟺ 抓取同时满足：
(1) 力封闭 ℝ^6⊆span_+{G_i}，
(2) 外力包络 𝒲_ext⊆𝒲_grasp/γ_g，
(3) 摩擦锥裕度 |f_t|≤μf_n∧f_n≥f_min，
(4) 关节限位与可操作度 ρ_manip≥ρ_min。

**证明**：
1. (1) 方向可达性对单位球采样做 SOCP 可行性；采样完备性由球面 ε-网给出（n_dir=512 对应角分辨率≈7°，需按任务收紧）。
2. (2) 多面体 𝒲_ext 的顶点均在 𝒲_grasp/γ_g 内，由 𝒲_grasp 的凸性（摩擦锥凸、线性映射保凸）推出整个多面体被包含。
3. (3) 由力分配解逐接触点核验，摩擦锥模型为线性化锥（各向异性用 μ̄ 上界包住）。
4. (4) 关节限位为盒约束，可操作度下界排除奇异抓取。
∎

### 引理 15（TMRC 的桥接与组合保守性）
**陈述**：`TMRC.verify_all() = True` ⟹ 存在从 (x0,g0) 到 (x*,g*) 的任务流形路径，且对联合不确定性以概率 ≥1-(δ_loc+δ_grasp) 保持可行；反之不一定（连通性判定为概率完备）。

**证明**：
1. **非空**：`verify_nonempty` 直接构造 (x*,g*)∈T 并复用引理 13/14。
2. **连通**：PRM 在 T 上采样并以局部可行边连接；若找到路径则路径存在（可靠性方向成立）。反向不成立：PRM 未找到路径只说明采样未覆盖，T 可能仍连通甚至路径存在——故 `False` 是保守拒证而非"不存在"证明。
3. **鲁棒**：导航只保证 x∈X̂_goal，故对 X̂_goal 的 B 个代表点逐一 `retarget` 后重验 DGC，覆盖"到达误差 → 抓取失败"的耦合。联合覆盖用并集界 ℙ(A∧B) ≥ 1-δ_loc-δ_grasp，**与 A、B 是否独立无关**；若误用独立乘积 (1-δ_loc)(1-δ_grasp) 会高估覆盖，属非保守错误。
4. 三条件合起来即"到得了、抓得住、且误差内仍抓得住"。
∎

### 引理 16（十证一体单调退化链终极延伸）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加三条退化路径：
- 定位漂移/走廊失效/地形不可通行 → `NFC.verify_all=false` → AND-UC 拒证 → 退回 `Exec_v25`（冻结导航，原地保守执行或请求重定位）。
- 接触滑移/力封闭失配/可达性不足 → `DGC.verify_all=false` → AND-UC 拒证 → 退回 `Exec_v25`（放弃抓取，切换至非接触/推拨策略或换抓取位）。
- 任务流形断裂/联合风险超预算 → `TMRC.verify_all=false` → AND-UC 拒证 → 退回 `Exec_v25`（拆分为"先导航后抓取"两段，由旧七证分别兜底）。
- 组合失效取交集，单调性保持。
∎

### 定理（AND-UC 十证准入门的完备性）
**陈述**：对任意移动灵巧操作计划 Π，`AND-UC.admits(Π) = True` ⟺ Π 同时满足：
(1)–(7) SRC-USC 的七类条件（安全/覆盖/适应/保护/结构/力控/轻量/语义/重构/协同，由引理 1–12 归并），
(8) 导航四重保证（引理 13），
(9) 灵巧抓取四重保证（引理 14，且为集合值），
(10) 任务流形非空-连通-鲁棒（引理 15）。

**证明**：由 `admits` 的四个连言直接得必要性；充分性由引理 4/8/12/16 保证执行集单调链，由引理 13–15 保证导航、抓取、任务流形三层各自的可靠性，从而构成"单机物理 → 群体语义 → 自主抵达 → 接触操控"的完整闭环。注意第 (10) 项的连通性为概率完备，故充分性是"在采样覆盖到路径时"的充分性，不构成对不存在路径的完备判定。
∎

## 6. 本轮最大风险（最终确认）

**一句话**：**NFC 的轨迹级定位覆盖在 GNSS 拒止/感知混叠下可能被逐步协方差高估、DGC 的力封闭在软指尖/未知摩擦材质下可能名义成立而实际滑移、TMRC 的任务流形连通性是非凸 NP-hard 且 PRM 仅概率完备——三者与"导航误差→抓取偏移"的集合值耦合叠加，可能让 AND-UC 的十证准入在"先证明存在/包含/连通"这一步就已失真：要么因采样不完备而假阴性（把可执行方案拒掉，Exec_v26 趋空），要么因接触与定位模型分布外而假阳性（证明了一个现实中不存在的可行域），使"事前拦截"退化为"事后发现"。**
