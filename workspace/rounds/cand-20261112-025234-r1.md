# 第 58 轮（承接第 57 轮「元少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「模仿学习」×「开源生态」）

> 第 57 轮把安全的赌注从"手工先验"换到"跨区域摊销的元先验 + 共形保底"，并让证据按模态分账、让人从常量变成单向信任状态机；但它自陈的最大风险——"坏先验普遍"——恰恰暴露了一个更根本的问题：**机器人不只需要从"自己的探针史"里学，还会不可避免地借用"他者的知识"**。人类示范是最直接的他者知识（"我这样走过，安全"）；开源生态则是他者知识的规模化形态（元模型、校准集、步态策略、地形地图乃至示范数据集，都以"包"的形式在舰队与社区间流通）。二者共享同一个认识论结构：**我们拿到的是"某人在某个世界里的成功轨迹 / 成功构建"，却要把它当作"我们的世界里的可信先验"**。第 57 轮的元学习只回答了"如何从自己的经验摊销"，没有回答"如何从他者的经验摊销而不被其世界绑架"。本轮补三件事：**(i) 模仿学习**把示范变成策略先验，但示范是"反事实盲区"——它只证明某条轨迹活过一次，不证明策略泛化；故模仿只能提案、不能承诺，且须过支撑界与因果认证。**(ii) 开源生态**把"能力"变成可组合的供应链，但供应链完整性（签名、SBOM、可复现）只证明"来源与一致性"，不证明"语义有效"；故他者证据必须过来源门、传递信任最弱链界与本地复现门。**(iii) 合流**给出统一原则：**他者知识只能降低探询成本，不能替代本地实证；借用可以加速"提案"，永远不能加速"承诺"**。核心命题由"少样本可校准、跨模态可对账、个性化有界"升级为 **"可溯源、有支撑、可复现的他者知识，方可入证；本地实证，方能承诺"**。

核心矛盾：
- **H29（模仿 vs 分布漂移）**：示范只覆盖示范者的状态分布；行为克隆在 off-support 状态上误差复合，且示范从不告诉你"如果那样做会怎样"——反事实盲区让"看起来对"与"真的对"分家。
- **H30（溯源 vs 语义有效）**：签名、SBOM、可复现构建证明的是"谁在何时如何造了它"，不是"它对不对"；一条完全合规的供应链可以稳定地交付一个系统性错误的先验。
- **H31（社区复用 vs 责任真空）**：开源式复用带来规模与鲁棒性，也把责任稀释到依赖闭包里；依赖混淆 / 近似名 / 分叉漂移 / 维护停滞会让一个弱环节"洗白"整条信任链，而一次错误会随复用规模在舰队内同步放大。

## 0. 直觉与动机

**灵感 1（模仿学习 → 示范是提案，不是证据）**
直觉：看师傅走一遍，比自己瞎试快得多；但"师傅在他的世界里走通了"不等于"我照做在我的世界里安全"。模仿学习最贵的教训是分布漂移——你只在示范覆盖的状态附近可信，一旦走到示范没见过的坡 / 材质，策略会自信地外推。于是本轮把示范降级为**提案先验 π_demo**：它只负责"建议先试哪条路、哪个步态"，不负责"允许承诺"。提案要变成承诺，仍须过第 57 轮的本地证据门；且 π_demo 的每一步都挂一个**支撑度** supp(s)（部署状态分布与示范状态分布的重叠）与**因果认证**（它学到的是原因还是相关）。off-support 或未认证 ⇒ 策略弃权（abstain），退回探询。DAgger 式"请师傅补一个示范"是允许的，但补示范的请求要过第 57 轮的个性化信任门（auth），补进来的仍是 EV-demo（受限证据）。

**灵感 2（开源生态 → 能力是可组合的供应链，不是可信任的整体）**
直觉：现代机器人栈不可能全部自研——元模型、校准集、步态库、地图都像 npm / pip 包一样被复用。开源生态的成熟经验是：**不要信"这个包很有名"，要信"这个包的来源、依赖闭包、构建过程可被独立核验"**。本轮把每个证据承载组件打包成带签名的 pkg，附 SBOM（依赖闭包）、构建时校准指标、许可 / 责任声明；采纳前必须在本地边端探针流上**复现**其声明的校准（reproducible build 的统计版）。但关键认识论刹车是：**供应链完整性 ≠ 语义有效性**——一个签名完好、依赖干净、可复现构建的元模型，完全可能编码了一个来自"另一个世界"的系统性错误先验。所以来源门只决定"能不能进入候选"，本地实证才决定"能不能承诺"。

**灵感 3（传递信任 → 信任不超过最弱依赖）**
直觉：你信任 A，A 依赖 B，B 依赖一个被投毒的 C——你对 A 的信任不该高于对 C 的信任。开源供应链攻击（依赖混淆、typosquatting、维护者失守）正是利用"信任不传递却常被默认为传递"。本轮定义**传递信任界**：trust(c) ≤ min_{d∈closure(c)} trust(d)，任何采纳不得使有效信任超过本地已验证证据。并显式检测：近似名依赖、版本漂移 / 分叉偏离、维护停滞（bus factor）。分叉不是罪，但**分叉必须重新证明**——被证明的是那个版本，不是你改过的那个。

**灵感 4（可复现知识 → 可复现 ≠ 正确，但不可复现必须降权）**
直觉：开源社区用"可复现构建"对抗"作者说它是对的"。可复现只保证"同样的输入得到同样的输出"，不保证输出正确；但它把"无法核验"的知识隔离出来。本轮给每条知识主张挂**溯源格**（本地复现 / 远程证明 / 未证明 × 支撑内 / 支撑外 × 信任高低），证据权重随格下降；未证明或 off-support 的知识只能作提示，不能单独入证，尤其不能支撑不可逆接触。

**灵感 5（双先验合流 + PCE++ → 模仿先行、越界即探、采纳先复现）**
直觉：第 57 轮的元先验管"信念"，本轮的模仿先验管"策略"；两者都是"借来的效率"，都必须挂证书。PCE++ 的执行序变成：**先用 π_demo 提案 → 检查支撑 / 因果 / 来源 → 在支撑内且已复现才省探针；一旦越界或来源可疑，立即回落到探询；任何不可逆接触，永远要求本地实证**。模仿与复用只走"更少探针 / 更快提案"这条效率通道，绝不走"更敢承诺"这条升险通道——这是对第 57 轮交互单调性的再次收窄。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（支撑加权模仿 DIL）** 示范集 𝒟_demo={(s_t,a_t,c_t,p_t)}（状态 / 动作 / 上下文 / 溯源），行为克隆策略 π_demo(a|s)。支撑度 supp(s)=1−TV(p_demo(s),p_deploy(s))（或用截断密度比 w(s)=min(w_max,p_deploy(s)/p_demo(s)) 的 kNN 估计）。模仿优势 A_im(s)=supp(s)·cert_causal(s)·W_ev(prov(π_demo))。**提案规则**：π_demo 仅在 A_im(s)≥A_0 时给出提案（proposal），提案不构成任何承诺；A_im<A_0 ⇒ abstain，回第 57 轮探询。修正查询（DAgger）经 PTM 授权门，补入示范仍记为 EV-demo。

**定义 140（能力供应链证明 CSA）** 组件 c 的包 pkg(c)=(id,ver,origin,hash,SBOM(c),ECE_build,OOD_build,license,liability,sig)。信任根 RT，撤销表 CRL。采纳门 Adopt(pkg) ⇔ (i) sig 链到 RT 且不在 CRL；(ii) 依赖闭包 closure(c) 全部可信；(iii) 本地复现 |ECE_local−ECE_build|≤ε_rep ∧ OOD 检出率不降；(iv) 硬件 / 地形兼容声明成立。未过门 ⇒ 只能进影子模式（继承第 57 轮隔离），不得接管承诺判定；采纳后可被 CRL 与舰队证伪广播即时撤回。

**定义 141（传递信任与依赖守卫 DEP）** 依赖图 G=(V,E)。trust(c)=min_{d∈closure(c)} trust(d)（最弱链界，含 c 自身）。检测：(i) 依赖混淆：声明名解析到非 RT 源，或与可信名编辑距离≤1 且非同名 ⇒ 拒；(ii) 分叉漂移：本地 fork 与被证明版本 Δ_fork>δ_fork 且无新证明 ⇒ trust 降为 fork 本地证据；(iii) 维护停滞：staleness 与 bus-factor 超阈 ⇒ 降权并触发再验证。约束：任何采纳的有效信任 ≤ min(trust(c), trust_local_evidence(c))。

**定义 142（可复现知识溯源 RKP）** 知识主张 k 的溯源记录 prov(k)=(ρ_rep,hash(inputs),容差,env_fingerprint)，ρ_rep∈{local_repro,attested_remote,unattested}。证据权重 W_ev(k)=f(ρ_rep,supp,trust(origin))，偏序 local_repro>attested_remote>unattested，且 off-support 一律降一档。W_ev(k)<w_irrev ⇒ k 不得进入不可逆接触必要证据集，只能作提案 / 提示。

**定义 143（因果混淆过滤 CCF）** 对候选特征 f 施加干预探针 π_f（do(f←f′)，保持任务相关量不变）。若 π_demo 的行为改变方向与 f 的因果效应一致，且跨示范反事实对（f 不同、其余匹配）上行为系统随 f 变化，则 cert_causal(f)=1；否则 0 并标"因果混淆"。仅 cert_causal=1 的特征可使 π_demo 进入 EV-demo；未认证特征只能作为"待检验假设"驱动探询。

**定义 144（来源证据门 FSE+ 与证书 J_s）** 证据类：EV-probe* / visit / margin / xmodal（继承第 57 轮）/ EV-human（继承）/ **EV-demo**（须 supp≥supp_0 ∧ cert_causal ∧ W_ev≥w_demo，仅限 L1，且不得单独支撑不可逆接触）/ **EV-repro**（本地复现的外部证据，可替代一次非不可逆探针）。**铁律**：不可逆接触必要证据集仍须含本地实证 {EV-probe*∨EV-margin}∪佐证；他者证据（demo / repro）只能降低探询成本，不能替代本地实证。J_s=(M_core,C_core,K_margin,ρ_sem,δ_s,probe_log,consent_log,evidence,meta_cal_log,xmodal_log,auth_log,ood_registry,SBOM,dep_trust,prov_lattice,repro_log,demo_support_map,causal_cert_log,CRL_version)，继承 J_p 全检。**PCX+ 算子（PCE++）**：每检查点 ①π_demo 提案（A_im 检查，off-support / 未认证即弃权）；②来源与复现检查（Adopt 未过 ⇒ 弃用外部先验）；③本地探询（第 57 轮 PCX）；④承诺 ⇔ 本地证据门过；否则绕行→降档→L2。预算 k_probes+k_cons+k_im。

## 2. 关键算法伪代码（完整版见产物区）

```python
def imitation_proposal(pi_demo, s, demo, deploy, prov):   # IP-139/143
    supp = support_overlap(deploy, demo, s)               # 1 - TV / 截断密度比
    cc   = causal_cert(pi_demo, s)                        # 干预去相关
    w    = evidence_weight(prov, supp)                    # IP-142 溯源格
    if supp < SUPP_0 or cc < 1 or w < W_DEMO:
        return None                                       # 弃权 → 回本地探询
    return Proposal(pi_demo(s), supp=supp, cc=cc, w=w)    # 仅提案，不承诺

def sourced_gate(c, M, persona, ood_reg, prov, trust, CRL):  # IP-144
    if c.ev == 'EV-demo':
        ok = c.level == 'L1' and c.supp >= SUPP_0 and c.cc == 1 and c.w >= W_DEMO
        if c.irreversible: return ('reject', 'demo_on_irreversible', c)
    elif c.ev == 'EV-repro':
        ok = c.rho_rep == 'local_repro' and trust(c.origin) >= TAU and c.id not in CRL
    else:
        ok = round57_gate(c, M, persona, ood_reg)         # 继承第 57 轮
    return ('ok', c) if ok else ('reject', 'sourced_evidence_insufficient', c)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DIL | O(kNN)/提案；O(d_π)/推理 | O(\|𝒟_demo\|) | 支撑诚实、off-support 必弃权（A41） |
| CSA | O(\|SBOM\|)+O(N_cal) | O(\|pkg\|) | 签名链 + 本地复现（A42/A43） |
| DEP | O(\|V\|+\|E\|) | O(\|V\|) | 最弱链界、分叉重证（A42） |
| RKP | O(1)/主张 | O(\|prov\|) | 溯源格偏序、未证降权（A43） |
| CCF | O(k_im·d) | O(\|f\|) | 干预去相关、反事实一致（A44） |
| FSE+/PCE++ | O(\|CP\|·(k_p+k_c+k_im)·(C_VOI+d_π)) | O(\|V\|+\|σ\|+\|SBOM\|) | 他者证据不替代本地实证、k 预算终止 |

**正确性定理（Sourced-Transfer Calibrated Soundness, STCS 概要）**：在第 57 轮 A37–A40 上加 (A41) 示范支撑与 off-support 弃权诚实；(A42) 签名 / SBOM / 依赖闭包诚实且信任根未被攻破；(A43) 本地复现容差内、不可复现知识被降权；(A44) 干预探针足以去相关伪特征、因果认证可靠。则：(i) **模仿不升险**：π_demo 只产生提案，所有提案仍过本地证据门，off-support / 未认证 / 未复现者不产生承诺，故失效率不高于第 57 轮；(ii) **传递信任界**：有效信任 ≤ 依赖闭包最弱链，采纳不得使信任超过本地实证；(iii) **来源证据健全性**：P(fail) ≤ 第 57 轮界 + δ_demo·1[L1∧supp∧causal] + δ_repro + δ_dep + δ_prov；(iv) PCE++ 在 k_probes+k_cons+k_im 内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 模仿先验在 off-support 自信外推 | 高 | 支撑界 + 弃权 + 本地探询回退 + DAgger 修正（经 auth 门） |
| 伪相关被当成因果（因果混淆） | 高 | 干预去相关探针 + 跨示范反事实一致性 + 未认证只作假设 |
| 供应链完整被误当语义有效（溯源幻觉） | 高 | 来源门只进候选、本地复现 + 本地实证才承诺 + 影子模式 |
| 依赖混淆 / 传递信任洗白 | 高 | 最弱链界 + 近似名检测 + 分叉重证 + CRL / 舰队撤回 |
| 复用规模放大错误 | 中高 | 证伪广播（CVE 式）+ 快速撤回 + 采纳即隔离 |

## 6. 本轮最大风险

**一句话**：本轮把"他者知识"引入证据链，最大的风险从第 57 轮的"坏先验普遍"升级为"**借来的自信**"——签名、SBOM、可复现构建与社区共识共同制造了一种"过程完整性"的幻觉，让人误以为"来源可信、构建可复现"就等于"语义正确"；于是一个完全合规、全程可审计、甚至因果"认证"过的、却编码了另一个世界系统性错误的先验，会随着开源式复用在整个舰队同步放大，且恰恰因为复用效率高而在任何单点本地证伪之前就完成了大规模承诺——必须以"他者证据永不替代本地实证、传递信任不超最弱链、不可复现必降权、采纳即隔离并保留 CRL 撤回"四重护栏，宁可放弃复用带来的速度，也不让合规的供应链替我们承担世界的真实性。

# 第 58 轮产物 · 创新点清单 v34：Q-Cert（证伪式视觉问答 × 创新点纪律，QIC×FQG×NQ×SBM×ACQ×PCE-Q）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"可被证伪提问、且能自证新在哪的证据承诺"**：证据从"系统内部日志"升级为"可审讯的语义预设 + 有据答案/弃权"；创新从"人肉清单"升级为"非冗余、可归因、可证伪、已验证的问题证书"；盲区从"元模型不知道的沉默缺口"升级为"问不出来/三方不一致的显式地图"。第 57 轮"一切判定器走隔离"在本轮推广为 **"一切语义预设走审讯，一切创新声明走证伪"**。

### IP-139 QIC（可审讯证书与语义预设）

```python
def semantic_presuppositions(c, M):
    atoms = []
    for prop in task_props(c):                 # 承重/摩擦/边界/材质/拓扑
        p = Atom(prop, prov=evidence_source(prop, M),
                 amb=conformal_answer_set(prop, M, alpha),
                 dep=dependency_dag(prop, M))
        atoms.append(p)
    return dedup(atoms)

def interrogable_certificate(c, M, qcert):
    P = semantic_presuppositions(c, M)
    Q, Ans = qcert.Q, qcert.Ans
    uncovered = [p for p in P if not any(q.atom == p for q in Q)]
    r_res = residual_risk(uncovered)          # 未审讯 = 风险，不是安全
    return Jq(J_p=qcert.J_p, P=P, Q=Q, Ans=Ans,
              Gamma=qcert.Gamma, NQ=qcert.NQ, r_res=r_res)
```

### IP-140 FQG（证伪问题生成与预注册）

```python
def forge_and_preregister(p, c, M, corpus):
    cands = [q for q in generate_candidates(p, c, M) if well_formed(q)]
    def FP(q):
        flip = block_prob(q, M)                # P(答案触发 block/escalate)
        return (flip * delta_risk(c) - cost(q)
                - lam_red * redundancy(q, corpus)
                - lam_att * attention_cost(q, active_persona()))
    q = max(cands, key=FP)
    q.fals_map = {a: decide_commit_action(q, a) for a in answer_space(q)}
    q.reg_hash = hash_chain_append(q.fals_map)  # 答案前固定，不可篡改
    return q

def question_priority(Q, persona):
    mandatory = [q for q in Q if q.critical or q.block_prob > theta_block]
    free = sorted([q for q in Q if q not in mandatory],
                  key=lambda q: FP(q) / max(attention_cost(q, persona), eps))
    return mandatory + [q for q in free if FP(q) >= theta_q(persona)]
```

### IP-141 NQ（创新点证书）

```python
def novelty_certificate(q, a, E_old, E_new, verdict):
    g = entropy(answer_dist(q, E_old)) - entropy(answer_dist(q, E_new))
    red = (g <= theta_red or
           tv(answer_dist(q, E_old), answer_dist(q, E_new)) <= eps_red)
    attr = provenance_complete(a) and independent_of_policy(E_new)
    fals = q.fals_map is not None and nondegenerate(q.fals_map)
    if not (attr and fals):
        return ('reject', 'unattributed_or_unfalsifiable', q)
    if red:
        return ('reject', 'redundant', q)
    if verdict not in ('confirmed', 'independent_corroborated'):
        return ('hypothesis_pool', q)          # 未验证新颖不入创新点
    if g < theta_nov:
        return ('reject', 'low_gain', q)
    return ('innovation', NQ(q, a, g, attr, fals, verdict))
```

def sbm_update(M, P):
    for p in P:
        views = [meta_view(p, M), vqa_view(p, M), phys_view(p, M)]
        p.kappa = min(agree(views[i], views[j])
                      for i in range(3) for j in range(i + 1, 3))

            M.blind.add(p)
        elif p in M.blind and validated(p, M):

### IP-144 PCE-Q / FSE-Q（承诺前审讯）

```python
def few_shot_evidence_gate_q(c, M, persona, ood_reg, qcert):
    base = few_shot_evidence_gate(c, M, persona, ood_reg)   # 第 57 轮五类门
    if base[0] != 'ok':
        return base
    if c.ev == 'EV-answer':
        ok = (c.level == 'L1' and c.indep_declared and c.entailed
              and c.prereg and not c.redundant)
        return ('ok', c) if ok else ('reject', 'answer_not_admissible', c)
    if c.irreversible:
        P = semantic_presuppositions(c, M)
        if any(p in M.blind for p in P):
            return ('reject', 'semantic_blind_spot', c)
        if any(not covered(p, qcert.Q) for p in P):
            return ('reject', 'presupposition_uncovered', c)
    return ('ok', c)

def probe_commit_evolve_q(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        # ---- ④ 审讯（PCE-Q 新增，先于承诺）----
        P = semantic_presuppositions(core_contact(cp), M)
        Q = [forge_and_preregister(p, core_contact(cp), M, qcorpus) for p in P]
        for q in question_priority(Q, personas.active):
            a, E, Gamma, abstain = grounded_answer(q, M)
            if not abstain and q.fals_map[a] != 'commit':
                return negotiate_or_stop(cp, M, None, None, consent,
                                         tau_int=tau_int(personas.active.auth),
                                         reason='falsified')
            if abstain:
                M.blind.add(q.atom)
        qcert = update_qcert(M, P, Q, persona=personas.active)
        if M.blind & set(P):
            route = reroute(M, cp, risk_model) or route
            continue
        # ---- 第 57 轮探询/承诺循环 ----
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi:
                break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        g = select_gait(R); lv = contact_level(cp); ev = tag_evidence_p(sigma, M, lv)
        if g != 'halt' and few_shot_evidence_gate_q(
                core_contact(cp), M, personas, ood_reg, qcert)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(ev); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QIC | O(\|P\|·(d_φ+C_α)) | O(\|P\|+\|Q\|) | 预设覆盖诚实、未覆盖入 r_res（A41） |
| FQG | O(\|Cand\|·(C_ans+C_red)) | O(\|Q\|) | 预注册不可篡改、问题良构（A42） |
| NQ | O(\|E\|+d_dist) | O(\|Q\|) | 非冗余/归因/验证、反 Goodhart（A43） |
| SBM | O(\|P\|·\|V\|²) | O(\|P\|) | 三方一致度诚实、问过≠解决（A44） |
| ACQ | O(1) | O(\|操作者\|) | 强制地板不可裁、auth 不改规则 |
| PCE-Q | O(\|CP\|·(\|P\|+\|Q\|)·C_ans + \|CP\|·(k_p+k_c)·C_VOI) | O(\|V\|+\|Q\|) | 审讯先于承诺、block/盲区即拒、终止 |

**正确性定理（Interrogable-Falsifiable Soundness, IFS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 语义预设原子集覆盖承诺所依赖的语义事实，未覆盖部分显式计入 `r_res`；**(A42)** 证伪映射在观测答案前固定且不可篡改，答案只由证据蕴含（单侧错误 ≤ε_ent），弃权诚实；**(A43)** 创新证书可审计，新颖分不被奖励函数直接优化，`spurious` 回溯降权；**(A44)** 盲区门与三方一致度估计诚实。则：

1. **语义承诺健全性**：ID 路径 `P(fail) ≤ δ_f+ε_meta+ε_ent+ε_abstain+r_res+ε_blind·1[漏检]`；OOD 路径沿用第 57 轮 `δ_ood·α_conf`；`EV-answer` 仅在 L1 贡献 `≤δ_ans`。
2. **交互单调性**：审讯、问题生成、创新记账只能经 (a) 加宽信念、(b) 否决/降档、(c) 要求更多佐证影响系统；问题本身不产生承诺，只有"证据蕴含的答案 ∧ 过门"才产生，不存在升险路径。
3. **终止性**：每检查点自由裁量问题 `≤N_q`、强制问题 `≤|P(c)|`，PCE-Q 在 `k_probes+k_cons+N_q+|P|` 内终止于 {承诺, 绕行, L2 协商, 安全停}。
4. **创新可审计性**：创新点集合恰为"非冗余 ∧ 可归因 ∧ 可证伪 ∧ 已验证"问题之子集；未验证新颖只入假设池。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + ε_ent + ε_abstain + r_res + ε_blind + δ_ood·α_conf + δ_ans·1[L1])
             − P(预注册被篡改未检出) − P(问题生成器与元模型共谋) − P(护盾回退失败)
```

关键：**物理证书给 soundness，语义审讯给相关性**（证书不再"算错题"）；**预注册把问题变成实验、验证把新颖变成创新**（创新点=活下来的致命问题）；**盲区图把"没问出来"显式记为风险**（沉默不是通过）。

## 4. 创新点自证协议（本轮新增，逐 IP 审查）

每个 IP 必须回答三问，否则视为重命名而非创新：
1. **移除了哪条旧假设？** 例：QIC 移除"语义预设无需取证"；NQ 移除"新颖无需验证"；SBM 移除"没问到=安全"。
2. **哪个参数量匹配的强基线能在同一指标上打平？** 例：GVA/普通 VQA + 人工问题集；若打平，该 IP 降级为工程实现。
3. **哪个预注册问题能证伪它？** 例：在语义欺骗集上，若"盲区原子进入承诺次数"不为 0，则 SBM 失效。

## 7. 本轮最大风险

**一句话**：本轮把"证据是否可信"的判定权交给了"系统自己会不会问出致命问题"——风险从"坏先验普遍"变成"**坏问题缺席**"：若问题生成器与元模型共享盲区（只问自己能答的问题），证书会在从未被提问的维度上"通过审讯"，创新点清单也会把"没问到的空白"误记成"已验证的安全"；必须以独立红队问题生成、留出对抗问题集、不可篡改预注册与"未覆盖即残差风险"四重护栏，宁可承认"问不出来"，绝不把沉默当成通过。
