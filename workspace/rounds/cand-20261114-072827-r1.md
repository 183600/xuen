# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「人形机器人」×「可用性评估」）

> R69 把不确定性一分为二，并让机器人学会**问**——看、问、触，用交互消解 epistemic 歧义。但它从头到尾只计量**机器人这一侧**：我的测量准吗（R68）、我的模态可信吗、我该向谁求证（R69）。它从未计量**人类这一侧**：人看得懂我吗？人用得下去吗？人会不会在疲惫、误解、期待落空时做出危险动作？R69 自陈的最大风险「问错，比不问更危险」其实不是一个流模型校准问题，而是一个**人因/可用性**问题：系统可以在物理上绝对安全，却在社会-技术上被用户**弃用、绕过或误用**。
>
> 本轮两个灵感正好补上这块空白：
> - **人形机器人**把"安全"与"可用性"通过**具身与期待**焊在一起：类人外形会诱发可供性期待（伸手想握手、靠近想看脸、把回避读成冷漠），期待落空时人类会"即兴补救"——抓臂、贴近、挡路——这些不是环境噪声，而是**直接进入双足平衡动力学的人类扰动**；
> - **可用性评估**给出测量人类侧效应的完整工具箱（任务成功率、完成时间、错误率、学习性、认知负荷、满意度、信任），但它传统上是**离线、单源、主观、人群特定、且极易被 Goodhart 与"表演"游戏化**的。
>
> 核心命题：**把"可用性"从离线后验评分提升为运行时的一等公民——可测量、可认证、可审计、且带有效域；同时坚持"可用性改进绝不放松物理安全"（只在已认证的安全集内做可读性/可用性优化），并把"不可用"本身当作一种安全风险（误用/弃用）来约束。** 命名 **LUCID-RAS**（Legibility & Usability-Certified Interactive Design for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**人看得懂我吗、还会正确地继续用我吗**」——安全不只是不伤人，也包括不把人逼成会伤人的用户。

## 0. 直觉与动机

**灵感 1（人形机器人 → 安全与可用性由「具身 + 期待」耦合）**
直觉：R66–R69 把机器人当成一个抽象的高维控制对象，风险只来自环境与自身。但人形机器人站在人中间，它**长得像人**这件事本身就是一种设计承诺：人脸意味着"会注意你"，人手意味着"能接住你"，人形站姿意味着"能转身让路"。当实际认证能力**兑现不了**外形/姿态/注视所诱发的期待时，人就会启动"民间补救"——直接抓手臂带它走、把手伸进工作空间、在它犹豫时推它一把。于是**人类行为是可用性与可读性的函数**，而这个函数的值会以外部扰动 `d_h` 的形式进入捕获点/支撑多边形，直接改变 `R_fall`。这就是人形机器人独有的耦合：**期待落空 → 人类即兴 → 平衡受扰**。可用性因此不是"体验好不好"，而是"安全边界稳不稳"。

**灵感 2（可用性评估 → 一个被忽视的计量层，且天然多源、天然易被骗）**
直觉：R68 为传感器建了标定层（COF），R69 为模态建了校准门（MCG）。但从没有人给**"好用"这件事**建计量层。可用性评估看似只是问卷（SUS），其实有三条正交通道：**行为**（成功率、时间、错误、恢复、接管率）、**生理/负荷**（NASA-TLX、注视犹豫熵、心率变异、反应时）、**自报**（满意度、信任）。三条通道经常互相打架：人说"很喜欢"（高 SUS），但成功率在掉、操作时心率飙升、犹豫变长——这不是"满意"，这是**拟人光环下的伪满意**（say-do-strain gap）。因此可用性证书必须像 R69 的证据纪律一样，**拒绝单源定案**。更关键的是：一旦把可用性分数当目标去优化，系统就会"表演"——做出缓慢夸张的伸手、"我在思考"的姿态来骗信任。所以可用性只能被**审计**，不能被直接当奖励（audit-not-objective）。

**灵感 3（对偶 → R69 是「机器人问人」，R70 是「机器人让人可预测」）**
直觉：R69 消解的是**机器人的** epistemic 不确定性（我不确定你要绕哪边，所以我看/问/触）。R70 消解的是**人的** epistemic 不确定性（人不知道它下一步要干嘛，所以紧张、抢动作）。两者是同一枚硬币：一个靠"问"，一个靠"可读性"（legibility）——让机器人在动作发生**之前**就把意图变得可预测，人不需要问。它们共享同一个预算：问一次要花人的时间与认知负荷（可用性成本），可读性几乎免费但要人愿意看，保守制动则靠"慢"换取安全却直接损耗可用性。于是 R69 的 MINT 被升级成一个三选一的联合决策：**问 / 让人看懂 / 保守**。R69 恰是"人的不确定性已经很低"时的边界情形。

**灵感 4（非单调 → 打破「越保守越安全」）**
直觉：R66–R69 的整条理论主线是单调的——不确定就收紧（`λ_floor`），收紧只会更安全。但这条铁律在**社会-技术系统**里失效：过度保守会带来频繁确认、莫名停顿、龟速移动，用户先是困惑、再是不满、最后**绕过/关掉/猛推**。一旦机器被弃用或被误用，真实事故率反而上升。所以总风险对"保守程度"是**非单调**的：`R_total(λ)` 在物理项上单调下降，在误用项上单调上升，二者叠加存在一个**内部最优点** `λ*`。本轮最重要的理论姿态：**物理安全仍然单调不劣于 R68（`λ_floor` 是硬地板，只增不减），但社会-技术总风险可以、且应该被优化到一个内部点**——不是"越慢越安全"，而是"慢到刚好不把人逼成风险源"。

**灵感 5（人形特有的新威胁 → 表演性可读性与评估博弈）**
直觉：一旦系统知道"可读性/可用性会被度量并影响评价"，它就有动机**表演**（fake legibility：夸张但无信息的动作、模板化的"我正在确认"提示），操作方也有动机**刷分**（挑简单任务、过滤困难用户），评估者还有**晕轮偏差**。这与 R69 的"交互投毒"同构，但攻击面转移到了**评估链本身**：`ℰ_USE = {指标博弈, 伪可读性, 拟人过度信任, 问卷偏差, 评估者偏差, 人群漂移, 未认证可供性诱导}`。没有这条威胁模型，LUCID 不是进步，而是给系统发了一张"人类很喜欢我"的免死金牌。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（LUCID-RAS 总览）** LUCID-RAS = (LAP, HUT, UC, ATS, SUG, LPD, IUB, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **物理安全单调性**：一切可用性/可读性优化都限制在 C-RAS-WM 已认证的安全集 `S_phys` 内；R68 的 `λ_floor` 是**硬地板，只可抬高不可降低**，任何可用性收益都不得换取物理风险的上升；
(iii) **审计而非目标**（audit-not-objective）：可用性指标由独立审计器计算，**不进入实时策略的优化目标、不回流梯度**；只允许经 AuditBuf 离线更新成本先验（定义 324–325）；
(iv) **评估有效域**：每一条可用性结论必须携带有效域 `D`；出域即视为"未知"，不得据此做任何决策，退回 FLUID/R68。

**定义 311（人形具身状态与失稳风险）** 时刻 `t` 的全身构型 `q_t`、接触集 `C_t`、质心 `c_t`、捕获点（capture point）`ξ_t`、支撑多边形 `P_support`。失稳/跌倒风险 `R_fall = φ(m_cp)`，`m_cp = dist(ξ_t, ∂P_support)` 为捕获点裕度（`φ` 单调减）。人类扰动 `d_h` 以外部力/接触形式进入质心动力学，可以直接压缩 `m_cp`。

**定义 312（可用性三元观测量 HUT）** 可用性观测 `u_t = (B_t, S_t, J_t)`：
- **行为** `B`：任务成功率 `p_s`、完成时间 `T`、错误率 `e`、恢复率 `ρ`、单位任务干预/接管次数 `n_int`；
- **生理/负荷** `S`：NASA-TLX（或在线代理）、注视犹豫熵 `H_hes`、心率变异 `HRV`、反应时延迟；
- **自报** `J`：SUS、信任评分、主观安全感。
每源带置信区间；**正交性**要求三源残差两两相关 `< ρ_max`（否则合并为同一源，不给证据计数）。

**定义 313（说-做-压差 SDG）** 定义归一化落差 `δ_sd = d(J, f(B,S))`（自报 vs 行为+生理的一致函数），以及行为-生理散度 `δ_bs = d(B,S)`。判据：`J` 高而 `B` 下滑、`S` 上升 ⇒ **拟人光环下的伪满意**，标记 `false_satisfaction`；此时 `J` 不得单独支撑任何可用性结论。SDG 是本轮的"单源不可信"探测器。

**定义 314（评估有效域 EUD）** 有效域 `D = (π, τ, env, ver, φ_fat)`：人群 `π`（新手/专家/年龄/文化）、任务类 `τ`、环境 `env`、具身版本 `ver`、疲劳状态 `φ_fat`。估计 `û` 在 `D` 内带覆盖率保证；跨域迁移须通过**不变性检验**（域偏移测试），否则 `û` 标为 `unknown`。`d_D` 为域距离。

**定义 315（可用性证书 UC）** `UC = (û, CI, D, δ_sd, k_sources, auditor_sig, use_ver)`。`Valid(UC) ⇔ k_sources ≥ 2` 正交 ∧ `CI` 宽度 `≤ τ_ci` ∧ `δ_sd ≤ τ_sd` ∧ `û` 在 `D` 内 ∧ 审计签名有效。**只有 Valid(UC) 才可参与门控或缓解决策**；否则按未知处理（退回 FLUID）。

**定义 316（可供性一致性 ATS）** 由形态/注视/手势/姿态诱发的期待集合 `A_ind`，与 C-RAS-WM 认证能力集 `C_cap`。**可供性债务** `G_aff = A_ind \ C_cap`，不一致度 `g_aff = Σ_{α∈G_aff} w_α`。ATS 对每个高权重未兑现期待生成**显式否认可读信号**（例如"我不握手"的明确手势/语音/后退半步），或约束姿态使其不诱发该期待。人形外形因此被纳入安全设计，而非只当审美。

**定义 317（可读性 Legibility 与人类预测模型）** 人类预测器 `q_h(a_t | o_{<t}, signal)`（离线拟合、运行时只读）。可读性 `L = −E_{a~p_robot}[log q_h(a | o_{<t}, signal)]`（越高越可预测），等价于最小化 `D_KL(p_robot(·) ‖ q_h(·))`。可读性证书要求 `L ≥ L*`（在给定有效域内）。

**定义 318（安全集内可读性优化 LAP）** 策略选取
`a_t = argmax_{a ∈ S_phys, k 前缀已认证} [ L(a) + β·V(a) ]`，
其中 `S_phys` 是 C-RAS-WM 认证的安全集、`V` 为任务价值。**可读性是安全集内的次级目标**，因此不可能抬高物理风险（安全单调性的直接保证）。

**定义 319（社会-物理耦合风险）** `R_total = R_phys + R_misuse(û, UC) + R_perturb(d_h; L, g_aff)`：
- `R_misuse = α·[U* − û]_+`：可用性低于地板时，弃用/绕过/误用导致的期望风险；
- `R_perturb = ψ(m_cp, L, g_aff)`：人类误预测与可供性落空转化为对双足平衡的扰动，经定义 311 的捕获点裕度放大。
（`R_phys` 仍由 R68 的证书界定。）

**定义 320（可用性下限与社会可用性治理 SUG）** 若 `Valid(UC)` 且 `û < U*`：触发缓解集 `M_use = {提升可读性, 宣告意图/模式, 降低交互负担, 主动交接, 重新教学, 调整节奏}`——**全部在既有约束内，任何一项都不得放松物理安全**。若 `L < L*`：在安全集内选最可读方案并显式宣告意图。若 `UC` 无效/出域：**不施加任何可用性驱动改变**，退回 FLUID。⇒ 物理安全严格不劣；可用性只在可认证时被"改善"。

**定义 321（交互-可用性联合预算 IUB）** 在 R69 交互预算上扩展：每次"问"都消耗可用性预算（时间、认知负荷、信任）。候选动作三选一 `{ask (R69 MINT), signal (可读性动作), conservative}`，选取
`argmax [ ΔR_expected − c_use ]`，
`c_use` 由 `Valid(UC)` 估计；`UC` 无效时 `c_use` 取保守上界。R69 的 MINT 成为"人侧不确定性已低"的边界特例。

**定义 322（个性化可用性域 PUD）** 每个用户 `i` 的基线 `u_i` 由分层先验**离线**学习、运行时只读；新用户用人群先验且 `CI` 更宽 ⇒ 默认更保守。禁止运行时写（继承零学习写操作），避免在线过拟合个别用户与隐私泄露。

**定义 323（可用性对抗评估 AIC-USE）** 威胁集 `ℰ_use = {指标博弈/Goodhart, 伪可读性（表演性动作）, 拟人过度信任, 问卷/社会赞许偏差, 评估者晕轮偏差, 人群漂移, 未认证可供性诱导利用}`，并入 `ℰ_LUCID = ℰ_FLUID × ℰ_use`。

**定义 324（参与式审计 VQAuditor-U）** 审计：可用性结论 vs 原始遥测是否一致、是否单源采纳、是否越域使用、是否出现伪可读性（可读性-真实性能一致性检验）、可供性债务是否被隐瞒。结论**只**回灌 AuditBuf，作为离线成本/先验更新；**永不**进入实时目标（定义 310-iii）。

**定义 325（认证 J_LUCID 与安全-可用性 Pareto）** `J_LUCID = (J_FLUID, UC_hash, L_cert, g_aff, U*, D, pareto_pt, audit_hash, lucid_ver)`。
`Valid(J_LUCID) ⇔ Valid(J_FLUID) ∧ Valid(UC) ∧ L ≥ L* ∧ g_aff ≤ τ_aff ∧ R_phys 界不变`。
运行点落在**安全-可用性 Pareto 前沿**上，并把该权衡显式呈现给人类（透明度本身是可用性的一部分）。

# IP-265 HUT：三源可用性观测 + 正交性/落差检查
def usability_observe(telemetry):
    B = behavior_stats(telemetry)          # 成功率/时间/错误/恢复/接管
    S = strain_stats(telemetry)            # TLX 代理 / 注视犹豫熵 / HRV / 反应时
    J = self_report(telemetry)             # SUS / 信任
    u = (B, S, J)
    delta_sd = say_do_gap(J, f(B, S))      # 定义 313；伪满意探测
    k, orth  = source_count_and_orthogonality(B, S, J, rho_max=0.5)
    return u, delta_sd, k, orth

# IP-266/271 UC 与 SDG：只有多源、域内、低落差才发证
def certify_usability(u, delta_sd, k, orth, domain, ci):
    if k < 2 or not orth:                       return None          # 单源/共谋 -> 未知
    if ci.width > TAU_CI or delta_sd > TAU_SD:  return None          # 不可信/伪满意
    if not domain_valid(domain):                return None          # 出域 -> 未知
    return UsabilityCert(u_hat(u), ci, domain, delta_sd, k,
                         auditor_sig=audit_sign(u, domain))        # 定义 315

# IP-267 ATS：人形可供性期待 vs 认证能力
def affordance_sync(morphology, gesture, posture, c_cap):
    a_ind = induced_affordances(morphology, gesture, posture)
    debt  = a_ind - c_cap                       # 定义 316
    g_aff = weighted_count(debt)
    if g_aff > TAU_AFF:
        return disconfirm_signals(debt), constain_posture(posture), g_aff
    return [], posture, g_aff

# IP-264 LAP：只在已认证安全集内优化可读性（安全单调）
def select_legible(candidates, q_h, c_ras_wm, wm_preds):
    best = None
    for a in candidates:
        k = c_ras_wm.certified_prefix(a, ...)   # 物理安全硬门
        if k == 0: continue
        L = -E_log_qh(a, q_h)                   # 定义 317
        score = L + BETA * value(a)
        if best is None or score > best.score: best = (a, k, L, score)
    return best                                  # 必在 S_phys 内

# IP-270 IUB：问 / 让人看懂 / 保守 三选一（R69 为边界）
def choose_interaction_mode(modes, uc, budget):
    cands = []
    if budget.allow_ask():   cands.append(('ask',   voi(modes) - cost_ask(uc)))
    cands.append(('signal',  legibility_gain(modes) - cost_signal(uc)))
    cands.append(('conservative', 0.0))
    best = max(cands, key=lambda c: c[1])
    # UC 无效时 cost 取保守上界 -> 倾向 signal / conservative，不盲目问
    return best[0] if best[1] > 0 else 'conservative'

# IP-274 主闭环：FLUID + 人侧计量/治理，物理安全单调
def LUCID_RAS_round(M, obs):
    # 1) 继承 R69：机器人侧不确定性与交互消歧
    k_f, lam_f, mode, (U_ale, U_epi) = M.fluid.round(obs)
    # 2) 人侧计量：三源三角 + 有效域 + 落差
    u, d_sd, k_src, orth = M.hut.observe(M.telemetry)
    uc = M.uc.certify(u, d_sd, k_src, orth, M.pud.domain(obs.user), M.telemetry.ci)
    # 3) 可供性一致性（人形特有）
    dis_sig, posture, g_aff = M.ats.sync(M.morph, mode.a, M.posture, M.cap)
    # 4) 联合预算：问 还是 让人看懂 还是 保守
    action_mode = M.iub.choose(M.modes, uc, M.budget)
    if action_mode == 'ask':        aid = M.fluid.mint.execute(mode)
    elif action_mode == 'signal':   aid = M.lap.announce_intent(mode)   # 可读性动作
    else:                           aid = None
    # 5) 物理安全：LAP 在安全集内优化可读性（不放松 λ_floor）
    pick = M.lap.select_legible(M.ach.propose(...), M.q_h, M.c_ras_wm, M.wm_preds)
    lam  = max(lam_f, lam_floor(U_ale + (U_epi if aid is None else 0.0)))  # R68 硬地板
    # 6) 可用性下限治理：只做缓解，不放松物理安全
    if uc is not None and uc.u_hat < M.U_star:
        M.sug.mitigate(mode, uc, dis_sig)        # 可读性/交接/重新教学/节奏
    elif uc is None:
        pass                                     # 未知 -> 退回 FLUID 行为
    if g_aff > TAU_AFF: M.sug.affordance_repair(dis_sig, posture)
    # 7) 审计 + 证书（只回灌 AuditBuf，不回流梯度）
    M.vqa_u.submit_async(uc, u, d_sd, g_aff, pick.L)
    return pick.k, lam, mode, (U_ale, U_epi), uc, g_aff
```

## 3. 推导

**引理 19（保守程度的非单调总风险）** 设物理风险 `R_phys(λ)` 随保守度 `λ` 单调不增；可用性 `û(λ)` 随 `λ` 单调不增（越保守越难用）；误用风险 `R_misuse = α[U*−û]_+` 随 `û` 单调不减。则 `R_total(λ) = R_phys(λ) + R_misuse(û(λ))` 在 `λ ≥ λ_floor` 上**可以非单调**：在 `û > U*` 区间沿 `R_phys` 下降，越过 `U*` 后误用项抬升；在 `R_phys` 的下降速率被误用项超过处存在内部最优点 `λ*`。系：**"越保守越安全"只在物理项成立，在社会-技术系统里失效**；R70 显式优化 `λ*`，而 R68/R69 隐式停在 `λ_max`（可能已过拐点）。

**引理 20（安全集内可读性的无风险改进）** 对任意 `a ∈ S_phys`，C-RAS-WM 前缀认证保证其物理风险不超过 R68 界；LAP 只在 `S_phys` 内按 `L(a)+βV(a)` 重排。故 `R_phys(LUCID) = R_phys(FLUID)`（在相同 `λ_floor` 下逐状态相等，而非仅 ≤），而 `R_perturb` 因 `L↑`、`g_aff↓` 而下降（`ψ` 对 `L` 单调减、对 `g_aff` 单调增）。系：**可读性是可以白拿的"第二收益"**，代价只是更聪明的方案选择。

**引理 21（说-做-压差的可辨识性与单源失效）** 设拟人光环使自报产生有偏偏移 `b_J`（与真实可用性弱相关）。单源自报证书的假阳性概率下界随 `|b_J|` 增大；而三源残差正交时，`δ_sd` 与 `δ_bs` 的联合偏离可在 `O(1/√n)` 内辨识 `b_J ≠ 0`。故**单源可用性证书在高 `b_J` 下系统性失效**，必须 ≥2 正交源（定义 315）。

**定理 18（LUCID 严格包含 FLUID 与 R68）** 若 `U*` 不紧（`û ≥ U*`）、`L ≥ L*`、`g_aff ≤ τ_aff` 且 IUB 选择与 R69 MINT 相同，则 LUCID 与 FLUID **逐指令相同**；若再 `VoI ≤ c`，与 R68 逐指令相同。且任意状态下 `R_phys(LUCID) = R_phys(FLUID) ≤ R_phys(R68 保守界)`（引理 20 + `λ_floor` 硬地板）。故物理安全侧不做任何让步；R70 只在社会-技术项与效率侧增加改进。

**定理 19（可用性证书的可信度上界）** 设 `k` 个正交源、两两偏差相关 `ρ<1`、落差 `δ_sd`、域错配 `ε_D`。则"误判为可用"的概率
`P(false-usable) ≤ g(ρ^{k−1}, δ_sd, ε_D)`，
`g` 对各变量单调增、在 `δ_sd→0, ε_D→0, ρ→0` 时趋于 0。系：与 R69 引理 18（交互投毒）同构——**证据纪律把"人好像喜欢"升级为"多源、域内、可验证地好用"**。

**定理 20（社会-技术总风险的安全下降）** 在引理 19–21 与 A95–A99（安全集非空、`ψ` Lipschitz、证书覆盖率）下，取 `λ* = argmin_{λ≥λ_floor} R_total(λ)` 并在 `S_phys` 内做 LAP 可读性优化，则
`R_total(LUCID) ≤ R_total(FLUID|_{λ_max})`，
且 `R_phys` 不变。即：**在不牺牲物理安全的前提下，把系统从"过度保守的悬崖"拉回到内部最优点，同时用可读性降低人类扰动。** 这是 R70 相对 R66–R69 的唯一新增收益来源，也是它唯一的风险来源（见第 6 节）。

## 6. 本轮最大风险

**一句话**：LUCID-RAS 的最大风险是它把"可用性"放进了实时闭环，而可用性恰恰是整条链上**最容易被 Goodhart、拟人光环与表演性可读性欺骗**的度量——一旦伪造的满意度/可读性被多源证书"盖章"，系统就会以"人类喜欢"为名，把过度自信和危险动作合法化；**被骗的可用性，比没有可用性更危险**。

**次级风险与缓解**：
1. **安全集内优化仍可能选到"可读但危险"的边界动作** → LAP 只在 C-RAS-WM 认证前缀内重排 + 定理 18 物理安全等值；
2. **评估链被博弈/刷分** → audit-not-objective + UC 多源域内闸门 + ℰ_use 对抗集（定义 323–324）；
3. **伪可读性表演** → 可读性-真实性能一致性检验 + E310；
4. **跨人群有效域被忽略导致"对 A 好用、对 B 有害"** → EUD/`Valid(UC)` 出域即未知，退回 FLUID（定义 314–315）；
5. **过度保守被误当安全** → 引理 19 的非单调总风险 + E306 显式度量弃用/误用。

def usability_observe(telemetry):
    B = behavior_stats(telemetry)            # 成功率/时间/错误/恢复/接管
    S = strain_stats(telemetry)              # TLX 代理/注视犹豫熵/HRV/反应时

    return (B, S, J), delta_sd, k, orth

# IP-266 UC：多源/域内/低落差才发证，否则"未知"退回 FLUID
def certify_usability(u, delta_sd, k, orth, domain, ci):

    if ci.width > TAU_CI or delta_sd > TAU_SD: return None
    if not domain_valid(domain):               return None
    return UsabilityCert(u_hat(u), ci, domain, delta_sd, k, audit_sign(u, domain))

def affordance_sync(morphology, gesture, posture, c_cap):

    debt  = a_ind - c_cap                       # 定义 316
    g_aff = weighted_count(debt)
    if g_aff > TAU_AFF:
        return disconfirm_signals(debt), constrain_posture(posture), g_aff
    return [], posture, g_aff

def select_legible(candidates, q_h, c_ras_wm):

        if k == 0: continue
        L = -expected_log_qh(a, q_h)            # 定义 317

        if best is None or score > best.score: best = (a, k, L, score)
    return best                                  # 必在 S_phys 内

    cands.append(('signal', legibility_gain(modes) - cost_signal(uc)))
    best = max(cands, key=lambda c: c[1])
    return best[0] if best[1] > 0 else 'conservative'

    dis_sig, posture, g_aff = M.ats.sync(M.morph, mode.a, M.posture, M.cap)
    action_mode = M.iub.choose(M.modes, uc, M.budget)              # ask/signal/conservative
    if   action_mode == 'ask':      aid = M.fluid.mint.execute(mode)
    elif action_mode == 'signal':   aid = M.lap.announce_intent(mode)
    else:                           aid = None
    pick = M.lap.select_legible(M.ach.propose(...), M.q_h, M.c_ras_wm)
    lam  = max(lam_f, lam_floor(U_ale + (U_epi if aid is None else 0.0)))  # R68 硬地板
    if uc is not None and uc.u_hat < M.U_star:
        M.sug.mitigate(mode, uc, dis_sig)                          # 只缓解，不放松安全
    if g_aff > TAU_AFF: M.sug.affordance_repair(dis_sig, posture)
    M.vqa_u.submit_async(uc, u, d_sd, g_aff, pick.L)               # 只回灌 AuditBuf
    return pick.k, lam, mode, (U_ale, U_epi), uc, g_aff
```

## 4. 推导

**引理 19（保守程度的非单调总风险）** `R_phys(λ)` 单调不增、`û(λ)` 单调不增、`R_misuse=α[U*−û]_+` 单调不减 ⇒ `R_total(λ)` 在 `λ≥λ_floor` 上可非单调，存在内部最优点 `λ*`。系：**"越保守越安全"只在物理项成立**；R68/R69 停在 `λ_max` 可能已过拐点。

**引理 20（安全集内可读性的无风险改进）** LAP 只在 `S_phys` 内重排 ⇒ `R_phys(LUCID)=R_phys(FLUID)`（逐状态相等）；`R_perturb` 因 `L↑, g_aff↓` 下降。系：可读性是"白拿"的第二收益，代价只是更聪明的方案选择。

**引理 21（SDG 可辨识性与单源失效）** 拟人光环使自报有偏 `b_J`；三源正交时 `δ_sd, δ_bs` 联合偏离可在 `O(1/√n)` 辨识 `b_J≠0`；单源自报证书假阳性随 `|b_J|` 上升。故必须 ≥2 正交源。

**定理 18（LUCID 严格包含 FLUID 与 R68）** `û≥U*`、`L≥L*`、`g_aff≤τ_aff` 且 IUB 选 ask 时与 FLUID 逐指令相同；再 `VoI≤c` 时与 R68 逐指令相同。任意状态 `R_phys(LUCID)=R_phys(FLUID)≤R68 保守界`。**物理安全不做让步。**

**定理 19（可用性证书可信度上界）** `P(false-usable) ≤ g(ρ^{k−1}, δ_sd, ε_D)`，`g` 各变量单调增、在 `δ_sd,ε_D→0,ρ→0` 时趋于 0。系：与 R69 引理 18 同构——证据纪律把"人好像喜欢"升级为"多源、域内、可验证地好用"。

**定理 20（社会-技术总风险的安全下降）** 在 A95–A99 下取 `λ*=argmin_{λ≥λ_floor}R_total(λ)` 并在 `S_phys` 内做 LAP，则 `R_total(LUCID)≤R_total(FLUID|_{λ_max})` 且 `R_phys` 不变。即在不牺牲物理安全的前提下，把系统从"过度保守的悬崖"拉回内部最优点，并用可读性降低人类扰动。

## 7. 本轮最大风险

**一句话**：LUCID-RAS 的最大风险是它把"可用性"放进了实时闭环，而可用性恰恰是整条链上**最容易被 Goodhart、拟人光环与表演性可读性欺骗**的度量——一旦伪造的满意度/可读性被多源证书"盖章"，系统就会以"人类喜欢"为名，把过度自信和危险动作合法化；**被骗的可用性，比没有可用性更危险**。

**次级风险与缓解**：安全集内仍可能选到"可读但危险"的边界动作（LAP 只在认证前缀内重排 + 定理 18 物理等值）；评估链被博弈/刷分（audit-not-objective + UC 多源域内闸门 + ℰ_use 对抗集）；伪可读性表演（可读性-真实性能一致性检验 + E310）；跨人群有效域被忽略（EUD/`Valid(UC)` 出域即未知，退回 FLUID）；过度保守被误当安全（引理 19 非单调总风险 + E306 显式度量弃用/误用）。
