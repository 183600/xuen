# 第 56 轮（承接第 55 轮语义-接触生存核；本轮灵感：「实例分割」×「行为克隆」）

> 第 55 轮把“语义标签”升级为“可执行接触约束”，但其语义图 `Σ` 是 **类级** 的：它知道“前面是椅子”，却不知道“是哪一把椅子”。本轮引入 **实例分割** 与 **行为克隆**：前者把状态从“类级语义”下推到“实例级身份”，后者把策略从“手写规则/技能库”替换为“从示范中克隆”。核心矛盾：**H24**：行为克隆的动作是 **实例指涉** 的——示范里“抓住那只杯子”的 `a` 一旦离开 `id(杯子)` 就没有意义，而传统 BC 在类级或像素级状态上训练，会把不同实例混为一谈；**H25**：BC 的失败不只是状态漂移，而是 **实例配置支撑漂移**——测试时的物体组合、遮挡、身份切换落在示范支撑集之外，策略会自信地输出未定义动作，并被全身控制器放大为不可逆接触。

## 0. 直觉与动机

**灵感 1（实例分割 → 从“是什么类”到“是哪一个”）**
直觉：语义分割回答“这块像素是杯子”，实例分割回答“这是 3 号杯子，那是 5 号杯子”。对模仿学习而言，后者才是动作的指涉对象：示范里的抓取、推压、避让都绑定到具体实例。因此状态抽象应从 `Σ: Ω→Δ(L)` 升级为 **实例图** `G_I=(V_I,E_I)`，节点携带持久身份 `id`、掩码、6-DoF 位姿与可供性，边携带接触/支撑/包含关系。BC 的动作应显式写成 `(id_target, u_interact)`，而不是一个与对象无关的关节向量。

**灵感 2（行为克隆 → 克隆“实例接触程序”，而不是克隆底层动作）**
直觉：直接克隆关节轨迹会把示范者的本体差异、动力学误差以及非马尔可夫性一并抄进来，误差随轨迹复合。更好的做法是把示范压缩为 **实例接触程序**：`P = {(τ_j, id_j, c_j, T_rel,j)}`——“在第 τ_j 阶段，对实例 id_j 以相对位姿 T_rel,j 施加接触 c_j”。高层克隆“对哪个实例做什么”，低层由第 55 轮的全身生存核去“怎么安全地做到”。这把 BC 从动作回归变成 **结构化程序克隆**，既降低复合误差，又能与第 54 轮的技能组合图直接对接。

**灵感 3（实例交换 → 可检验的虚假相关与反事实增广）**
直觉：BC 最危险的不是过拟合，而是 **抄了错误的因果线索**：背景颜色、场景布局、同类别实例的位置。实例分割给了我们一个可操作的干预：保持目标实例不变、交换背景实例（`swap_ctx`），或保持场景不变、替换同类别目标实例（`swap_id`）。一个因果正确的策略应对 `swap_ctx` 不敏感、对 `swap_id` 敏感。于是定义 **实例交换反事实检验**，并把交换样本用于增广训练，逼策略绑定到实例本身而非上下文。

**灵感 4（行为支撑核 → 把“分布外”从状态空间搬到实例配置空间）**
直觉：BC 的可靠性边界不是“状态离示范多远”，而是“当前实例配置是否落在示范覆盖内”。因此用一个 **行为支撑核** `B_π` 同时约束三件事：示范密度（见过没有）、集成不确定性（模型分歧大不大）、关系一致性（实例图与最近示范图是否同构）。护盾只在 `φ_I∈B_π` 且动作落在策略高密度区时放行；否则回退到最近示范程序、主动重观测或安全制动。

**灵感 5（云边实例库 → 云端检索、边端核验、身份对账）**
直觉：云端可维护大规模 **实例-示范库**（按外观嵌入、可供性、程序索引），边端做实时实例跟踪与支撑核验。两者以 **实例身份** 对账：边端回传 ID 切换、掩码漂移、支撑失配证据，云端据此重检索/重标注。这把第 55 轮的“语义-动作联合重剖分”升级为 **实例-行为联合重剖分**。

## 1. 形式化定义（增量：定义 127–133）

**定义 127（实例图状态抽象）**
时刻 t 的实例分割输出 `Σ_I(t)={(m_k, id_k, c_k, T_k, a_k)}_{k=1}^{N_t}`：掩码 `m_k⊆Ω`、持久身份 `id_k∈ℕ`、类别 `c_k`、位姿 `T_k∈SE(3)`、属性 `a_k`（可供性/材质/可动性）。实例关系图 `G_I(t)=(V_I,E_I)`，边 `e=(i,j,r,g)`，`r∈{接触,支撑,包含,邻近}`、`g` 为几何量（距离、法向、重叠）。状态抽象 `φ_I(s)=(G_I(t), q_t)`，`q_t` 为本体感受。身份持久性由匹配算子 `M: Σ_I(t-1)×Σ_I(t)→id` 维持。

**定义 128（实例接触程序）**
`P=(π_task, {(τ_j, id_j, c_j, T_rel,j, κ_j)}_{j=1}^{M})`：`τ_j` 为阶段/时序，`id_j` 为目标实例，`c_j∈C` 为接触类型，`T_rel,j` 为目标接触帧相对实例坐标系的位姿，`κ_j` 为期望接触力/阻抗剖面。程序是 **中层级动作**：高层指定“对谁、在哪、做何种接触”，低层由全身控制器实现。

**定义 129（实例接地行为克隆 IRBC）**
示范集 `D={(s_t, P_t^demo, G_I(t))}`。学习 `π_θ(P | φ_I(s))`（或分解为 `π_task` 与 `π_contact`）。关系编码器在 `G_I` 上做实例级消息传递；动作以 `(id_target, u_interact)` 分解。训练目标
`L = L_program + λ_c L_counter + λ_r L_rel + λ_s L_smooth`，
其中 `L_counter` 为实例交换反事实一致性，`L_rel` 为关系图重建/对比损失。关键约束：策略必须以目标实例特征为条件，而非全局场景特征。

**定义 130（行为支撑核 BSK）**
`B_π = {φ_I | ρ_D(φ_I) ≥ θ_den ∧ U_π(φ_I) ≤ θ_u ∧ R_I(φ_I) ≤ θ_g}`：
- `ρ_D`：示范实例图密度（kNN 距离或归一化流）；
- `U_π(φ_I)=Var_k[π_{θ_k}(·|φ_I)]`：深度集成/多头分歧；
- `R_I`：当前实例图到最近示范图的归一化图编辑距离（关系一致性）。
动作支撑 `A_π(φ_I)={u | (u-μ_π)^TΣ_π^{-1}(u-μ_π) ≤ r_α²}`（高斯策略的 `1-α` 置信椭球）。`φ_I∉B_π` 即 **实例配置分布外**。

**定义 131（实例交换反事实与虚假相关度）**
对实例配置施加两类干预：`swap_ctx`（替换与任务无关的上下文实例）与 `swap_id`（替换同类别目标实例）。定义
`Δ_ctx=E||π(φ_I)-π(swap_ctx φ_I)||`，`Δ_id=E||π(φ_I)-π(swap_id φ_I)||`，
**虚假相关度** `S=Δ_ctx/(Δ_id+ε)`。因果正确的策略应有 `Δ_ctx≈0`、`Δ_id>0`，即 `S` 小；`S` 大说明策略把上下文当成了动作依据。

**定义 132（实例-行为护盾 IBS）**
给定名义程序/动作 `P_nom=π_θ(φ_I)`，护盾求解
`u* = argmin_u ||u-u_nom||²_{Σ_π^{-1}}`
`s.t. u∈A_π(φ_I), φ_I∈B_π, x_{t+1}∈K_in(Σ_I), supp(λ)⊆C^+(Σ_I), λ∈FC(μ), u∈A_WB`。
若不可行，按优先级回退：① 检索最近示范程序 `P_ret`；② 实例级主动重观测（移动机械臂/头部消除遮挡）；③ 最小风险制动 `u_stop∈𝒳_safe`。

**定义 133（实例-行为证书 IBC）**
`J_I=(I_core, φ_core, B_margin, ρ_bc, δ_id, δ_mask, S, evidence)`：
- `I_core`：轨迹使用的持久实例 ID 集，`φ_core`：核心实例图与支撑点；
- `B_margin=dist(φ_core, ∂B_π)`：支撑核裕度；
- `ρ_bc(ε)=inf_{d_I(φ,φ̂)≤ε}P(success|φ)`：实例图扰动球内的最坏成功率（实例鲁棒性谱）；
- `δ_id`：身份切换率，`δ_mask`：掩码边界误差，`S`：虚假相关度；
- `evidence`：交换反事实结果、接触/力反馈日志、ID 切换事件。
若 `φ_core∈B_π`、`B_margin≥θ_B`、`ρ_bc≥ρ_min`、`δ_id<Θ_id`、`δ_mask<Θ_mask`、`S≤θ_S`，则实例-行为可部署。

## 2. 关键算法 伪代码

### IP-127 IGG（Instance Grounding Graph）

```python
def build_instance_graph(seg, prev=None, appearance_emb=None):
    insts = seg.predict_instances()              # masks, classes, poses
    ids, phi = [], {}
    for k, ins in enumerate(insts):
        id_k = associate(ins, prev, appearance_emb,
                         cost=mask_iou + pose_dist + emb_dist)
        phi[id_k] = dict(mask=ins.mask, cls=ins.cls, T=ins.pose, attr=ins.attr)
    edges = []
    for i in phi:
        for j in phi:
            if i != j:
                r, g = relation(phi[i], phi[j])   # contact/support/contain/adjacent
                edges.append((i, j, r, g))
    return InstanceGraph(phi, edges)
```

### IP-128 ICP（Instance-Contact Program compiler）

```python
def demo_to_program(traj, G_I_seq, contact_model):
    prog = []
    for t in range(len(traj)):
        contacts = contact_model(traj[t], G_I_seq[t])   # eef-object contacts
        for (eef, id_j, c_j, T_rel) in contacts:
            if is_keyframe(t, contacts, traj):
                prog.append(Phase(tau=t, id=id_j, c=c_j, T_rel=T_rel,
                                  kappa=force_profile(traj, t)))
    return compress_program(prog)                # merge redundant phases
```

### IP-129 IRBC（Instance-Relational Behavior Cloning）

```python
def train_irbc(D, encoder, policy, lam):
    for (phi_I, P_demo) in D:
        h = encoder(phi_I)                        # instance message passing
        P_hat = policy(h, target_ids=phi_I.ids)
        L_bc = program_loss(P_hat, P_demo)
        phi_ctx = swap_context(phi_I)
        phi_id  = swap_target(phi_I)
        L_cnt = (||policy(encoder(phi_ctx)) - P_hat||**2
                 + relu(margin - ||policy(encoder(phi_id)) - P_hat||)**2)
        L_rel = relational_contrastive(encoder(phi_I), encoder(augment(phi_I)))
        update(L_bc + lam.c * L_cnt + lam.r * L_rel)
    return policy
```

### IP-130 BSK（Behavioral Support Kernel）

```python
def behavioral_support(phi_I, demo_bank, ensemble, theta):
    rho = demo_bank.knn_density(phi_I)                 # 1/(dist+eps) or flow
    U   = ensemble.disagreement(phi_I)                 # action variance
    R   = graph_edit_distance(phi_I, demo_bank.nearest(phi_I))
    in_support = rho >= theta.den and U <= theta.u and R <= theta.g
    margin = min(normalize(rho, theta.den), 1 - U/theta.u, 1 - R/theta.g)
    return in_support, margin
```

### IP-131 ISCT（Instance-Swap Counterfactual Test）

```python
def spurious_score(policy, phi_I, bank, n=32):
    d_id, d_ctx = [], []
    for _ in range(n):
        phi_id  = bank.sample_same_class_different_instance(phi_I)
        phi_ctx = bank.sample_context_swap(phi_I)
        d_id.append(dist(policy(phi_I), policy(phi_id)))
        d_ctx.append(dist(policy(phi_I), policy(phi_ctx)))
    return mean(d_ctx) / (mean(d_id) + EPS), mean(d_id), mean(d_ctx)
```

### IP-132 IBS（Instance-Behavior Shield）

```python
def instance_behavior_shield(phi_I, policy, Kernel, C_plus, demo_bank, W):
    P_nom, mu, Sigma = policy.sample(phi_I)
    ok, margin = behavioral_support(phi_I, demo_bank, policy.ensemble, theta)
    if not ok:
        P_ret = demo_bank.retrieve(phi_I)
        if P_ret is not None:
            return P_ret, 'support_retrieve', margin
        return reobserve(phi_I), 'support_reobserve', margin
    u = qp_solve(H=W, g=-W @ mu, constraints=[
        action_ellipsoid(mu, Sigma, r_alpha),
        viability_constraint(phi_I, Kernel.K_in),
        instance_contact_constraint(phi_I, C_plus),
        friction_cone_constraint(mu),
        joint_limit_constraint(),
    ])
    if u is None:
        return safe_brake(phi_I), 'shield_infeasible', margin
    return u, 'ok', margin
```

### IP-133 IBC（Instance-Behavior Certificate）

```python
def instance_behavior_certificate(traj, G_I_seq, policy, rho_bc, budgets):
    I_core = persistent_ids(traj, G_I_seq)
    phi_core = canonical_graph(G_I_seq, I_core)
    ok, B_margin = behavioral_support(phi_core, demo_bank, policy.ensemble, theta)
    S, d_id, d_ctx = spurious_score(policy, phi_core, demo_bank)
    delta_id = id_switch_rate(traj, G_I_seq)
    delta_mask = mask_boundary_error(traj, G_I_seq)
    if not ok or B_margin < budgets.theta_B:
        return ('reject', 'outside_support', B_margin)
    if delta_id > budgets.Theta_id or delta_mask > budgets.Theta_mask:
        return ('reject', 'instance_grounding_fail', delta_id, delta_mask)
    if S > budgets.theta_S or rho_bc(delta_id) < budgets.rho_min:
        return ('reject', 'spurious_or_fragile', S, rho_bc)
    return ('ok', InstanceCert(I_core, phi_core, B_margin, rho_bc,
                               delta_id, delta_mask, S))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IGG | O(N²·(IoU+emb)) | O(N²) | 身份匹配稳定、关系标签完备 |
| ICP | O(T·N·C_c) | O(M) | 接触检测准确、关键帧压缩保序 |
| IRBC | O(|D|·(|V_I|+|E_I|)·d) | O(θ) | 实例条件充分、反事实一致 |
| BSK | O(N_demo·d + K·d) | O(N_demo·d) | 密度/分歧/图距校准 |
| ISCT | O(n·d) | O(1) | 同类别交换可行、干预可复现 |
| IBS/IBC | O(QP + N_demo·d) | O(|A_WB|) | 支撑不足即回退、δ_id/δ_mask 可测 |

**正确性定理（Instance-Grounded Behavioral Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 实例关联错误率 ≤ δ_id、掩码边界误差 ≤ δ_mask；**(A34)** 在 `φ_I∈B_π` 上，克隆策略单步动作误差 ≤ ε_bc 的概率 ≥ 1-β_bc；**(A35)** 护盾在支撑或生存核不可行时回退到 `𝒳_safe` 或最近示范程序。则部署后单步安全概率
```
P_safe ≥ 1 - P(φ_I∉B_π) - β_bc - P(δ_id>Θ_id) - P(δ_mask>Θ_mask) - P(fallback fails)
```
关键：**实例身份是 BC 支撑可判定的桥**，**支撑核把分布外挡在不可逆接触之前**，**护盾兜底**。三层任一失守，都不能把“策略在训练集上很像示范”当作“它对当前这个实例是可信的”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 实例 ID 切换导致对错物体执行 | 高 | 多线索匹配 + 身份不确定性进入 `B_π` + 切换即回退重观测 |
| 交换增广产生物理不可行样本 | 中高 | 物理可行性过滤 + 仅用于关系/反事实损失，不直接回归动作 |
| 示范实例配置稀疏，支撑核过保守 | 中 | 主动示范采集 + 支撑核分层（近邻/流模型）+ 保守度预算 |
| BC 因果混淆（非马尔可夫、隐藏状态） | 高 | 历史实例图 + 反事实检验 + 集成分歧 + 运行时支撑检查 |
| 云边实例本体/外观嵌入不一致 | 高 | 共享实例本体 + 外观嵌入对齐 + 身份对账证据回传 |

## 6. 本轮最大风险

**一句话**：实例接地行为克隆把“模仿动作”升级为“模仿对哪个实例做什么接触”，但其 soundness **三重依赖实例身份的持续正确、行为支撑核在实例配置空间的因果充分性、以及交换反事实分布与真实部署分布的一致性**；一旦 ID 在遮挡后切换、或支撑核只覆盖了外观特征而遗漏了动力学隐性状态，护盾会在“自认为在支撑内”的情况下让策略对错误实例执行未定义接触——因此必须以 **身份不确定性进核 + 反事实因果检验 + 支撑不足即回退重观测** 三重护栏，宁可请求新示范，绝不把“看起来像示范”当作“对当前实例可执行”。

# 第 56 轮产物 · 创新点清单 v32：InstanceClone（IGG×ICP×IRBC×BSK×ISCT×IBS×IBC）

> 承接 v31（GroundEdge-GenSim+++）与第 55 轮语义-接触层（IP-121~126）。本轮把“语义-接触约束”推进到 **实例级身份**，并把策略来源从手写规则/技能库升级为 **行为克隆**，形成“实例接地 → 程序克隆 → 支撑核验 → 护盾兜底”的闭环：
> - **IGG（Instance Grounding Graph）**：实例图状态抽象，持久 ID + 关系边；
> - **ICP（Instance-Contact Program）**：把示范编译成实例指涉的接触程序；
> - **IRBC（Instance-Relational Behavior Cloning）**：以实例图为条件、以程序为输出的克隆；
> - **BSK（Behavioral Support Kernel）**：示范密度 + 集成分歧 + 关系一致性的支撑核；
> - **ISCT（Instance-Swap Counterfactual Test）**：用实例交换检验虚假相关；
> - **IBS（Instance-Behavior Shield）**：支撑核 + 生存核 + 动作椭球的安全投影；
> - **IBC（Instance-Behavior Certificate）**：把身份误差、掩码误差、支撑裕度写进部署证书。
>
> IP 编号：IP-127~IP-133（7 个新增），升级 IP-121/124/126 以纳入实例维度。

```python
def build_instance_graph(seg, prev=None, emb=None):
    phi, edges = {}, []
    for ins in seg.predict_instances():
        id_k = associate(ins, prev, emb,
                         cost=mask_iou + pose_dist + emb_dist)
        phi[id_k] = dict(mask=ins.mask, cls=ins.cls, T=ins.pose, attr=ins.attr)
    for i in phi:
        for j in phi:
            if i != j:
                r, g = relation(phi[i], phi[j])
                edges.append((i, j, r, g))
    return InstanceGraph(phi, edges)
```

def train_irbc(D, encoder, policy, lam):

### IP-130 BSK + IP-131 ISCT

```python
def behavioral_support(phi_I, bank, ensemble, theta):
    rho = bank.knn_density(phi_I)
    U   = ensemble.disagreement(phi_I)
    R   = graph_edit_distance(phi_I, bank.nearest(phi_I))
    ok  = rho >= theta.den and U <= theta.u and R <= theta.g
    margin = min(normalize(rho, theta.den), 1 - U/theta.u, 1 - R/theta.g)
    return ok, margin

def spurious_score(policy, phi_I, bank, n=32):
    d_id, d_ctx = [], []
    for _ in range(n):
        d_id.append(dist(policy(phi_I),
                         policy(bank.same_class_other_instance(phi_I))))
        d_ctx.append(dist(policy(phi_I),
                          policy(bank.context_swap(phi_I))))
    return mean(d_ctx) / (mean(d_id) + EPS)
```

def instance_behavior_shield(phi_I, policy, Kernel, C_plus, bank, W):
    P_nom, mu, Sigma = policy.sample(phi_I)
    ok, margin = behavioral_support(phi_I, bank, policy.ensemble, theta)

### IP-133 IBC

```python
def instance_behavior_certificate(traj, G_I_seq, policy, rho_bc, budgets):
    I_core, phi_core = persistent_ids(traj, G_I_seq), canonical_graph(traj, G_I_seq)
    ok, B_margin = behavioral_support(phi_core, bank, policy.ensemble, theta)
    S = spurious_score(policy, phi_core, bank)
    delta_id, delta_mask = id_switch_rate(traj), mask_boundary_error(traj)
    if not ok or B_margin < budgets.theta_B:
        return ('reject', 'outside_support', B_margin)
    if delta_id > budgets.Theta_id or delta_mask > budgets.Theta_mask:
        return ('reject', 'instance_grounding_fail', delta_id, delta_mask)
    if S > budgets.theta_S or rho_bc(delta_id) < budgets.rho_min:
        return ('reject', 'spurious_or_fragile', S, rho_bc)
    return ('ok', InstanceCert(I_core, phi_core, B_margin, rho_bc,
                               delta_id, delta_mask, S))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IGG | O(N²·(IoU+emb)) | O(N²) | 身份匹配稳定，关系边完备 |
| ICP | O(T·N·C_c) | O(M) | 接触检测准确，关键帧压缩保序 |
| IRBC | O(|D|·(|V_I|+|E_I|)·d) | O(θ) | 实例条件充分，反事实一致 |
| BSK/ISCT | O(N_demo·d + n·d) | O(N_demo·d) | 密度/分歧/图距校准，干预可复现 |
| IBS/IBC | O(QP + N_demo·d) | O(|A_WB|) | 支撑不足即回退，预算闭合 |

**正确性定理（Instance-Grounded Behavioral Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 实例关联错误率 ≤ δ_id、掩码边界误差 ≤ δ_mask；**(A34)** 在 `φ_I∈B_π` 上，克隆策略单步动作误差 ≤ ε_bc 的概率 ≥ 1-β_bc；**(A35)** 护盾在支撑或生存核不可行时回退到 `𝒳_safe` 或最近示范程序。则部署后单步安全概率
```
P_safe ≥ 1 - P(φ_I∉B_π) - β_bc - P(δ_id>Θ_id) - P(δ_mask>Θ_mask) - P(fallback fails)
```
关键：**实例身份是 BC 支撑可判定的桥**，**支撑核把分布外挡在不可逆接触之前**，**护盾兜底**；三者缺一，都不能把“策略在训练集上像示范”当作“它对当前实例可信”。

## 6. 本轮最大风险

**一句话**：实例接地行为克隆把“模仿动作”升级为“模仿对哪个实例做什么接触”，但其 soundness **三重依赖实例身份的持续正确、行为支撑核在实例配置空间的因果充分性、以及交换反事实分布与真实部署分布的一致性**；一旦 ID 在遮挡后切换、或支撑核只覆盖了外观特征而遗漏了动力学隐性状态，护盾会在“自认为在支撑内”的情况下让策略对错误实例执行未定义接触——因此必须以 **身份不确定性进核 + 反事实因果检验 + 支撑不足即回退重观测** 三重护栏，宁可请求新示范，绝不把“看起来像示范”当作“对当前实例可执行”。
