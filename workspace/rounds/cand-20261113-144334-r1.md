# 第 68 轮（承接第 67 轮「SimRAS 仿真增强闭环」IP-233~242；灵感循环第 5 轮；本轮灵感：「协同控制」×「物体泛化」）

> 第 67 轮 SimRAS 把闭环推到「离线仿真预训练 + 在线世界模型 + 视觉问答审计」，但它的所有证书、所有风险预算、所有世界模型都仍然属于**单一个体、单一物体分布**。它默认：存在一个“我”，能独立地为一个“已知物体”签发安全前缀。
>
> 本轮两个灵感正好刺穿这两个默认：
> - **协同控制** → 安全证书不是单体的私有属性，而是多体共享风险的**可组合凭证**；
> - **物体泛化** → 世界模型与审计器在仿真物体上学到的能力，面对新物体时存在**系统性的语义迁移缺口**。
>
> 核心命题：
>
> **把「单体、已知物体」的 SimRAS 证书，升级为「多体共识 + 物体构形化」的可组合证书 —— CoGenRAS（Cooperative Generalization-aware Risk-aware Adaptive Closure）。**
>
> CoGenRAS 问的是新问题：**在多个体共享有限风险预算、且面对从未见过的物体时，“这张证书还能不能签”？**

## 0. 直觉与动机

**灵感 1（协同控制 → 证书的可组合性）**
直觉：SimRAS 的证书是一张“单体私签”：每个智能体独立算出 k*RAS，独立决定 λ_risk。可一旦多个体共享同一工作空间与同一安全预算，单体证书就不再可加：A 的“安全前缀”可能恰好把风险推给 B；B 的“高置信”可能来自与 A 相同的错误先验。协同控制真正追问的是：**安全证书能不能像货币一样在个体间转移、汇总、兑付？** 于是必须把“我安全”升级为“我们可组合地安全”。

**灵感 2（物体泛化 → 证书的语义域外延）**
直觉：SimRAS 的 SimEngine / WorldModel / VQAuditor 全都在一组“见过的物体”上训练。新物体不是简单噪声，而是**语义层面的分布漂移**：外形相似但材质不同（玻璃杯 vs 塑料杯）、功能相似但受力不同（毛巾 vs 绳索）。OOD 分数低不代表安全——这正是“语义别名（semantic alias）”陷阱。因此需要把“物体”从一个被动输入，提升为证书里的一个**显式风险维度** H_obj。

**灵感 3（两灵感合流 → 为什么必须一起做）**
直觉：单一物体的 OOD 分数是**单视角、单模型**的估计，噪声大；但多个体从不同视角看同一物体，其物体嵌入的**一致性**恰好提供了一个免费的、跨视角的 OOD 校验。反过来，协同控制若没有物体级校准，多个体可能“一致地错”——共识不能替代独立证据。所以：
- **跨体一致性**负责“这物体我们是否看岔了”；
- **物体构形化**负责“这物体我们是否见过同类”；
- 二者正交，缺一不可。

**灵感 4（合流框架 CoGenRAS：CoWM × OGA × CBP × CCert × CoAudit）**
1. **CoWM Cooperative World Model**：每体局部世界模型 + 鲁棒共识潜状态，把“共识误差”当作新的故障观测量；
2. **OGA Object Generalization Adapter**：输出 `(φ(o), s_obj, g_obj, C_α(o))`，把物体泛化缺口变成可计算的风险上界；
3. **CBP Cooperative Budget Protocol**：用 Nash 议价在共享预算 `Λ_max` 下分配每体风险额度 `a_i`；
4. **CCert Cooperative Certificate**：认证前缀同时受每体 SimRAS、物体构形化、共识误差、预算账本四重约束；
5. **CoAudit Cooperative Auditor**：多视角渲染 + 跨体交叉审计 + 共享审计缓冲；
6. **J_CoGen**：可组合证书，定义证书组合算子 `⊕`。

**灵感 5（相对第 67 轮的升级点）**
- **WM → CoWM**：单模型滚动 → 多体共识滚动，新增干扰 `ℰ_cons`（共识失效/拜占庭/延迟）；
- **SimEngine → SimEngine+ObjGen**：新增物体随机化与“语义别名”对抗生成；
- **VQAuditor → CoAudit**：单视角审计 → 多视角交叉审计 + 跨体审计复用；
- **AIC-SimRAS → AIC-CoGen**：新增 `ℰ_obj`（物体分布漂移）、`ℰ_cons`、`ℰ_budget`（预算博弈）；
- **J_SimRAS → J_CoGen**：引入组合算子与预算账本，使证书在团队层面可验证。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（CoGenRAS 总览）**：`CoGenRAS = (CoWM, OGA, CBP, CCert, CoAudit, J_CoGen)`。定位：SimRAS 的「单体证书」升级为「团队可组合证书」。不变式：共识、预算分配、物体共形校准、证书签发只在语义流；实时流只做局部 WM 推理、局部认证、共识误差检查与预算早停，零学习写操作。
- **定义 267（协同图）**：`G = (V, E)`，`|V| = n`，邻接矩阵 `A ∈ {0,1}^{n×n}`，通信延迟上界 `τ_comm`，邻居集 `N_i`。`G` 连通是团队证书可组合的必要条件。
- **定义 268（局部/共识潜状态与共识误差）**：`z_i,t = Enc_i(obs_i,t)`；`z_cons,t = Agg({z_i,t}_{i∈V}, f)`，其中 `f` 为可容忍故障体数，`Agg` 采用逐坐标截尾均值（去掉 `f` 个最大与 `f` 个最小）。共识误差 `ε_cons,t = max_i ||z_i,t − z_cons,t||`。
- **定义 269（物体嵌入与 OOD 分数）**：物体 `o` 经 OGA 编码为 `φ(o) ∈ ℝ^d`；已校准原型集 `P_K = {φ(o_k)}`；OOD 分数 `s_obj(o) = min_k sqrt((φ(o)−φ_k)^T Σ^{-1} (φ(o)−φ_k))`；泛化置信 `g_obj = exp(−s_obj / τ_obj) ∈ (0,1]`。
- **定义 270（物体泛化故障假设）**：`H_obj ∈ {O0 已知实例, O1 同类别新实例, O2 新类别, O3 语义别名/欺骗}`。先验 `P(H_obj)` 由 `s_obj`、类别分类器熵、跨体一致性共同给出。
- **定义 271（跨体物体一致性）**：各体对同一物体给出 `φ_i(o)`，物体关联后，`d_obj(o) = max_{i,j} ||φ_i(o) − φ_j(o)||`。若 `d_obj ≤ τ_obj_cons`，称物体通过跨体共识；否则标记 `object_ambiguous = True`。
- **定义 272（物体构形化风险集）**：在校准集上用非一致性分数 `V_k = |r_k − r̂_k| / σ̂(s_obj)`，取经验分位数 `q_{1−α}`。预测集 `C_α(o) = [r̂(o) − q_{1−α}·σ̂, r̂(o) + q_{1−α}·σ̂] ∩ [0,1]`，风险上界 `r_ub(o) = sup C_α(o)`。
- **定义 273（层次共形校正）**：对可能的新类别，用 `q_α^cat = q_{1−α} + κ·s_obj` 膨胀分位数；`κ` 由类别漂移标定。有效上界记为 `r_ub^cat(o)`。
- **定义 274（共享风险预算）**：每体风险额度 `a_i ≥ a_i^min ≥ 0`，团队预算 `Σ_i w_i a_i ≤ Λ_max`，`w_i` 为任务权重。实际风险 `r_i` 必须满足 `r_i ≤ a_i`；预算账本 `L = {(a_i, r_i, λ_i)}` 随证书一同签发。
- **定义 275（CBP 预算分配）**：求解 `max ∏_i (a_i − a_i^min)^{w_i}` s.t. `Σ_i w_i a_i ≤ Λ_max`。闭式解为等绝对余量分配：`a_i = a_i^min + (Λ_max − Σ_j w_j a_j^min) / Σ_j w_j`（需 `Λ_max ≥ Σ_j w_j a_j^min`）。
- **定义 276（协同认证前缀）**：`k*_Co = min( min_i k_i^SimRAS, min_i k_i^obj, k_cons, k_budget )`，其中 `k_i^obj` 由 `r_ub^cat(o_i) ≤ a_i` 决定，`k_cons` 是使 `ε_cons,t+i ≤ ε_max` 成立的最大步数，`k_budget` 是使团队累计风险不超预算的最大步数。
- **定义 277（共识安全条件）**：证书可签发当且仅当：1) `ε_cons,t ≤ ε_max`；2) `d_obj ≤ τ_obj_cons`；3) `Σ_i w_i a_i ≤ Λ_max`；4) `∀i: r_ub^cat(o_i) ≤ a_i`。
- **定义 278（CoWM 物体条件三头）**：`CoWM = (Enc, dyn_head, risk_head, afford_head)`；每个头以 `[z_cons; φ_cons(o)]` 为条件，其中 `φ_cons(o)` 为跨体物体嵌入的鲁棒聚合。输出 `(z_{t+1}, P(H_{t+1}), r̂_{t+1}(o))`。
- **定义 279（OGA 适配器）**：`OGA = (ObjEnc, ProtoBank, ConformalCal, AliasDetector)`。`AliasDetector` 用“外形近、功能远”的不一致分数 `alias(o) = ||φ_shape(o) − φ_afford(o)||` 专门捕捉语义别名，并把 `alias(o) > τ_alias` 送入 `H_obj=O3`。
- **定义 280（CoAudit 多视角审计）**：每体渲染自己的 WM 滚动视频 `vid_i`，VQA 产出 `AuditReport_i`；跨体审计一致性 `agree = 1 − (1/n)Σ_i 1[AuditReport_i ≠ median_j AuditReport_j]`。`agree < τ_agree` 时证书降级。
- **定义 281（审计缓冲共享）**：`CoObjBuf[(scene_hash, object_hash)] = AuditReport`；`object_hash` 含 `φ_cons(o)` 与 `H_obj`。跨体命中复用前须通过共形过滤，避免把一个物体的审计结论错误迁移到语义别名物体。
- **定义 282（J_CoGen 证书）**：`J_CoGen = ( {J_SimRAS^{(i)}}_i, consensus_hash, d_obj, s_obj, r_ub^cat, budget_ledger, g_obj, agree, aic_cogen_ver )`。`Valid ⇔ ∀i Valid(J_SimRAS^{(i)}) ∧ 定义 277 ∧ agree ≥ τ_agree`。
- **定义 283（证书组合算子 ⊕）**：给定两个子团队证书 `J_A, J_B`，若 `G` 中存在连接边、且 `Λ_A + Λ_B ≤ Λ_max`，则 `J_{A⊕B}` 由合并预算账本、取 `min` 认证前缀、重算 `d_obj/ε_cons` 得到。组合安全由定理 14 保证。
- **定义 284（物体条件风险界）**：`r_real(o) ≤ r_sim(o) + L_φ·s_obj(o) + ε_sim`，其中 `L_φ` 为风险函数对物体嵌入的 Lipschitz 常数，`ε_sim` 为第 67 轮 Sim2Real 误差。该界把“物体泛化”变成可扣减的安全余量。
- **定义 285（CoGenRAS 在线部署不变式）**：实时环路仅含局部 WM 推理、OGA 前向、共识误差检查、CCert 认证与预算早停。共识聚合周期 ≥ 控制周期，`τ_comm` 必须小于认证前缀的执行时长，否则 `k_cons = 0`。

## 2. 关键算法骨架

```python
# CoWM：共识世界模型
class CooperativeWorldModel:
    def __init__(self, local_wms, f_byzantine=1, tau_cons=0.15):
        self.wms, self.f, self.tau_cons = local_wms, f_byzantine, tau_cons

    def consensus_state(self, zs):
        stack = torch.stack(zs)                 # [n, d]
        sorted_z, _ = stack.sort(dim=0)
        f = self.f
        trimmed = sorted_z[f:len(zs) - f]       # 逐坐标截尾
        return trimmed.mean(dim=0)

    def rollout(self, zs, obj_embeds, act_seqs, k=5):
        z_cons = self.consensus_state(zs)
        phi_cons = self.consensus_state(obj_embeds)
        eps = max(torch.norm(z - z_cons) for z in zs)
        preds = []
        for t in range(k):
            cond = torch.cat([z_cons, phi_cons])
            z_cons = self.wms[0].dyn(cond)
            pH = self.wms[0].risk(cond)
            r_obj = self.wms[0].afford(cond)
            preds.append({'pH': pH, 'r': r_ub(r_obj), 'eps': eps})
        return preds


# OGA：物体泛化适配器
class ObjectGeneralizationAdapter:
    def __init__(self, obj_enc, proto_bank, conformal, tau_obj=0.3, tau_alias=0.5):
        self.enc, self.proto = obj_enc, proto_bank
        self.cal, self.tau_obj, self.tau_alias = conformal, tau_obj, tau_alias

    def analyze(self, obj_img, cross_obj_embeds=None):
        phi = self.enc(obj_img)
        s_obj = self.proto.mahalanobis(phi)
        g_obj = math.exp(-s_obj / self.tau_obj)
        alias = self.enc.alias_score(phi)      # 外形-功能不一致度
        H_obj = ('O3' if alias > self.tau_alias
                 else 'O2' if s_obj > self.tau_obj else 'O0')
        if cross_obj_embeds:
            d_obj = max(torch.norm(phi - p) for p in cross_obj_embeds)
        else:
            d_obj = 0.0
        C = self.cal.prediction_set(phi, s_obj)     # 定义 272
        r_ub_cat = self.cal.inflate(C, s_obj)       # 定义 273
        return {'phi': phi, 's_obj': s_obj, 'g_obj': g_obj, 'alias': alias,
                'H_obj': H_obj, 'd_obj': d_obj, 'r_ub': r_ub_cat}


# CBP：协同预算协议
class CooperativeBudgetProtocol:
    def __init__(self, Lambda_max, w, a_min):
        self.Lambda, self.w, self.a_min = Lambda_max, w, a_min

    def allocate(self):
        base = sum(wi * ai for wi, ai in zip(self.w, self.a_min))
        if self.Lambda < base:
            raise ValueError('budget infeasible')
        slack = (self.Lambda - base) / sum(self.w)
        return [ai + slack for ai in self.a_min]      # 定义 275 闭式解

    def check(self, r_ub, a):
        return all(r <= ai for r, ai in zip(r_ub, a))


# CCert：协同证书
class CooperativeCertificate:
    def __init__(self, csc_simras, cbp, eps_max=0.15, tau_obj_cons=0.4):
        self.csc, self.cbp = csc_simras, cbp
        self.eps_max, self.tau_obj = eps_max, tau_obj_cons

    def certified_prefix_co(self, agents, oga_reports, wm_preds):
        k_sim = min(a.k_simras for a in agents)
        k_obj = min(a.k_obj for a in agents)
        k_cons = sum(1 for p in wm_preds if p['eps'] <= self.eps_max)
        k_budget = self._budget_horizon(wm_preds, agents)
        d_obj = max(r['d_obj'] for r in oga_reports)
        if d_obj > self.tau_obj:
            return 0
        return min(k_sim, k_obj, k_cons, k_budget)


# CoGenRAS：在线协同环路
def CoGenRAS_round(team, obs_batch):
    zs, phis = [], []
    for i, agent in enumerate(team.agents):
        obs = obs_batch[i]
        zs.append(agent.enc(obs))
        oga_i = agent.oga.analyze(obs['object_img'], cross_obj_embeds=None)
        phis.append(oga_i['phi'])

    # 1) 跨体物体一致性
    oga_reports = []
    for i, agent in enumerate(team.agents):
        others = [phis[j] for j in range(len(team.agents)) if j != i]
        oga_reports.append(agent.oga.analyze(obs_batch[i]['object_img'], others))

    # 2) 共识滚动
    z_cons = team.cowm.consensus_state(zs)
    wm_preds = team.cowm.rollout(zs, phis, team.act_seqs)

    # 3) 预算分配
    budget = team.cbp.allocate()
    if not team.cbp.check([r['r_ub'] for r in oga_reports], budget):
        return 0, budget, 'BUDGET_REJECT'

    # 4) 协同认证前缀
    k_co = team.ccert.certified_prefix_co(team.agents, oga_reports, wm_preds)

    # 5) 各体执行 + 共享审计
    for i, agent in enumerate(team.agents):
        agent.dispatch(k_co, lambda_i=1.0 - agent.risk_scale())
        agent.coaudit.submit_async(wm_preds, oga_reports[i])
    return k_co, budget, 'CERTIFIED'
```

## 3. 推导

**引理 13（共识聚合误差界）** 设 `n` 个体中至多 `f < n/2` 个故障体，每体正常误差 `||z_i − z*|| ≤ ε_i`。逐坐标截尾均值满足 `||z_cons − z*|| ≤ ε_(f+1) + diam_f`，其中 `diam_f` 是被截掉两端后剩余样本的离散度。推论：`ε_cons ≤ 2(ε_(f+1) + diam_f)`，且 `f` 越大、共识的独立性越差。

**引理 14（物体共形覆盖的类别漂移界）** 若校准集与新物体同分布，分裂共形保证 `P(r(o) ∈ C_α(o)) ≥ 1 − α`。若发生类别漂移，层次校正后的覆盖满足 `P(r(o) ∈ C_α(o)) ≥ 1 − α − δ_cat(s_obj)`，其中 `δ_cat(s_obj) ≤ min(1, L_φ·s_obj / τ_obj)`。即 OOD 距离越大，覆盖保证越松，必须用 `r_ub^cat` 而非名义 `q_{1−α}`。

**定理 14（组合安全定理）** 若每个智能体的 `J_SimRAS^{(i)}` 有效、`ε_cons ≤ ε_max`、`d_obj ≤ τ_obj_cons`、且 `Σ_i w_i a_i ≤ Λ_max`，则团队违规概率满足
`P(∃i: r_i > a_i) ≤ Σ_i α_i + P(consensus failure) + P(alias miss)`。
证书组合算子 `⊕` 在该条件下保序：`Valid(J_A) ∧ Valid(J_B) ⇒ Valid(J_{A⊕B})`。

**定理 15（物体泛化到协同的迁移界）** 结合定义 284 与引理 14，协同风险上界为
`r_ub^team(o) ≤ max_i [ r_sim(o_i) + L_φ·s_obj(o_i) + ε_sim ] + κ·d_obj`。
当 `s_obj → 0` 且 `d_obj → 0` 时退化为第 67 轮 SimRAS 的 `r_ub`。这说明 CoGenRAS 是 SimRAS 的严格保守扩展，而非替代。

**定理 16（预算分配的 Pareto 最优性）** 定义 275 的 Nash 议价解是唯一满足 Pareto 最优、对称性（按权重）与无关备选独立性的分配；当 `Λ_max ≥ Σ w_i a_i^min` 时闭式解存在，且每体余量相等。任何偏离该解的分配都会使至少一个体的余量下降而不提升团队总余量。

**引理 15（语义别名不可由 OOD 单独识别）** 存在物体对 `(o, o')` 使 `s_obj(o') < τ_obj` 但 `|r(o) − r(o')| > 2L_φ τ_obj`。因此仅靠 OOD 阈值的证书必然在该对上失效；必须引入 `alias(o)` 这一“外形-功能不一致”通道。这是定理 14 中 `P(alias miss)` 项不可消去的原因。

## 6. 本轮最大风险

**一句话**：CoGenRAS 把 `s_obj` 与跨体共识当作“未知物体危险度”的充分统计量，但语义别名会让 OOD 分数很低而真实风险很高，且多体共享同一预训练骨干使共识高度相关而非独立——于是团队可能**一致且自信地把新物体签成“已知安全物体”**，并把共享预算配置到错误对象上，使“协同”从冗余变成了错误放大。

**次级风险与缓解**：
1. **相关误差**：强制多体使用不同骨干/不同视角/不同传感器模态，降低共识相关性；
2. **别名漏检**：AliasDetector 用外形-功能双通道，必要时主动交互（抓取试探/轻推）获取功能证据；
3. **预算博弈作弊**：预算账本纳入证书哈希，跨体交叉校验 `a_i` 与 `r_i`；
4. **通信延迟**：`τ_comm` 超过认证前缀时长时强制 `k_cons=0`，退化为单体 SimRAS；
5. **共形失效**：新类别上启用保守膨胀 `κ·s_obj`，宁可多降级也不误签。

## 2. 形式化定义（完整版）

**定义 266（CoGenRAS 总览）** CoGenRAS 是把 SimRAS 的「单体证书」升级为「团队可组合证书」的六元组：
```
CoGenRAS = (CoWM, OGA, CBP, CCert, CoAudit, J_CoGen)
```
不变式：共识聚合、预算分配、物体共形校准、证书签发只在语义流；实时流只做局部 WM 推理、局部认证、共识误差检查与预算早停，零学习写操作。

**定义 267（协同图）** `G = (V, E)`，`|V| = n`，邻接矩阵 `A ∈ {0,1}^{n×n}`，通信延迟上界 `τ_comm`，邻居集 `N_i`。`G` 连通且 `τ_comm < k*_Co·Δt_ctrl` 是团队证书可组合的必要条件。

**定义 268（局部/共识潜状态与共识误差）**
```
z_i,t = Enc_i(obs_i,t)
z_cons,t = Agg({z_i,t}_{i∈V}, f)          # 逐坐标截尾均值，去 f 大 f 小
ε_cons,t = max_i ||z_i,t − z_cons,t||
```
`f` 为可容忍故障体数，要求 `2f < n`。

**定义 269（物体嵌入与 OOD 分数）**
```
φ(o) ∈ ℝ^d
s_obj(o) = min_{φ_k ∈ P_K} sqrt((φ(o)−φ_k)^T Σ^{-1} (φ(o)−φ_k))
g_obj = exp(−s_obj / τ_obj) ∈ (0,1]
```

**定义 270（物体泛化故障假设）**
```
H_obj ∈ {O0 已知实例, O1 同类别新实例, O2 新类别, O3 语义别名/欺骗}
P(H_obj) ∝ exp(−s_obj/τ_obj) · CatEntropy(o) · ConsensusPrior(d_obj)
```
`CatEntropy` 为类别分类器熵，`ConsensusPrior` 由跨体一致性给出。

**定义 271（跨体物体一致性）** 关联后
```
d_obj(o) = max_{i,j} ||φ_i(o) − φ_j(o)||
object_ambiguous = [d_obj > τ_obj_cons]
```

**定义 272（物体构形化风险集）** 校准集非一致性分数
```
V_k = |r_k − r̂_k| / σ̂(s_obj)
q_{1−α} = EmpiricalQuantile({V_k}, 1−α)
C_α(o) = [r̂(o) − q_{1−α}·σ̂, r̂(o) + q_{1−α}·σ̂] ∩ [0,1]
r_ub(o) = sup C_α(o)
```
同分布下 `P(r(o) ∈ C_α(o)) ≥ 1−α`。

**定义 273（层次共形校正）** 对可能的新类别
```
q_α^cat = q_{1−α} + κ·s_obj
r_ub^cat(o) = min(1, r_ub(o) + κ·s_obj)
```
`κ` 由类别漂移标定；`s_obj→0` 时退化为定义 272。

**定义 274（共享风险预算）** 每体风险额度 `a_i ≥ a_i^min ≥ 0`，
```
Σ_i w_i a_i ≤ Λ_max,    r_i ≤ a_i,    L = {(a_i, r_i, λ_i)}
```

**定义 275（CBP 预算分配）** 求解
```
max_{a} ∏_i (a_i − a_i^min)^{w_i}
s.t.  Σ_i w_i a_i ≤ Λ_max,  a_i ≥ a_i^min
```
闭式解（Kuhn–Tucker）：
```
a_i = a_i^min + (Λ_max − Σ_j w_j a_j^min) / Σ_j w_j
```
要求 `Λ_max ≥ Σ_j w_j a_j^min`，此时每体绝对余量相等。

**定义 276（协同认证前缀）**
```
k*_Co = min( min_i k_i^SimRAS,
             min_i k_i^obj,        # 由 r_ub^cat(o_i) ≤ a_i 决定
             k_cons,               # 使 ε_cons,t+i ≤ ε_max 的最大步数
             k_budget )            # 团队累计风险不超预算的最大步数
```

**定义 277（共识安全条件）** 证书可签发当且仅当
1. `ε_cons,t ≤ ε_max`；
2. `d_obj ≤ τ_obj_cons`；
3. `Σ_i w_i a_i ≤ Λ_max`；
4. `∀i: r_ub^cat(o_i) ≤ a_i`。

**定义 278（CoWM 物体条件三头）**
```
CoWM = (Enc, dyn_head, risk_head, afford_head)
输入条件 c = [z_cons; φ_cons(o)]
dyn_head(c)    → z_{t+1}
risk_head(c)   → P(H_{t+1}), r̂_{t+1}(o)
afford_head(c) → 可抓取/受力/可变形参数
```

**定义 279（OGA 适配器）**
```
OGA = (ObjEnc, ProtoBank, ConformalCal, AliasDetector)
alias(o) = ||φ_shape(o) − φ_afford(o)||
H_obj = O3 if alias(o) > τ_alias else (O2 if s_obj > τ_obj else O0)
```

**定义 280（CoAudit 多视角审计）** 每体渲染 `vid_i`，VQA 产出 `AuditReport_i`，
```
agree = 1 − (1/n) Σ_i 1[AuditReport_i ≠ median_j AuditReport_j]
agree < τ_agree ⇒ 证书降级（k*_Co ← 0）
```

```
J_{A⊕B} = ( merge(budget_ledger_A, budget_ledger_B),
```

```python
# IP-243 CoWM：共识世界模型
class CooperativeWorldModel:
    def __init__(self, local_wms, f_byzantine=1, tau_cons=0.15):
        self.wms, self.f, self.tau_cons = local_wms, f_byzantine, tau_cons

    def consensus_state(self, states):
        stack = torch.stack(states)              # [n, d]
        sorted_z, _ = stack.sort(dim=0)
        f = self.f
        return sorted_z[f:len(states) - f].mean(dim=0)   # 逐坐标截尾

    def rollout(self, zs, obj_embeds, act_seqs, k=5):
        z_cons = self.consensus_state(zs)
        phi_cons = self.consensus_state(obj_embeds)
        eps = max(torch.norm(z - z_cons) for z in zs)
        preds, hard_fail = [], eps > self.tau_cons
        for _ in range(k):
            cond = torch.cat([z_cons, phi_cons])
            z_cons = self.wms[0].dyn(cond)
            pH = self.wms[0].risk(cond)
            r_obj = self.wms[0].afford(cond)
            preds.append({'pH': pH, 'r': r_obj, 'eps': eps})
        return preds, hard_fail


# IP-244/IP-245 OGA + AliasDetector
class ObjectGeneralizationAdapter:
    def __init__(self, obj_enc, proto_bank, conformal,
                 tau_obj=0.3, tau_alias=0.5):
        self.enc, self.proto, self.cal = obj_enc, proto_bank, conformal
        self.tau_obj, self.tau_alias = tau_obj, tau_alias

    def alias_score(self, phi_shape, phi_afford):
        return torch.norm(phi_shape - phi_afford)

    def analyze(self, obj_img, cross_obj_embeds=None):
        phi_shape = self.enc.shape(obj_img)
        phi_afford = self.enc.afford(obj_img)
        phi = torch.cat([phi_shape, phi_afford])
        s_obj = self.proto.mahalanobis(phi)
        g_obj = math.exp(-s_obj / self.tau_obj)
        alias = self.alias_score(phi_shape, phi_afford)
        H_obj = ('O3' if alias > self.tau_alias
                 else 'O2' if s_obj > self.tau_obj else 'O0')
        d_obj = max((torch.norm(phi - p) for p in cross_obj_embeds),
                    default=0.0)
        C = self.cal.prediction_set(phi, s_obj)
        r_ub = self.cal.inflate(C, s_obj)         # 定义 273
        return {'phi': phi, 's_obj': s_obj, 'g_obj': g_obj,
                'alias': alias, 'H_obj': H_obj, 'd_obj': d_obj,
                'r_ub': r_ub}


# IP-246 CBP：Nash 预算分配
class CooperativeBudgetProtocol:
    def __init__(self, Lambda_max, w, a_min):
        self.Lambda, self.w, self.a_min = Lambda_max, w, a_min

    def allocate(self):
        base = sum(wi * ai for wi, ai in zip(self.w, self.a_min))
        if self.Lambda < base:
            raise ValueError('budget infeasible: increase Lambda or lower a_min')
        slack = (self.Lambda - base) / sum(self.w)
        return [ai + slack for ai in self.a_min]   # 定义 275 闭式解

    def check(self, r_ub, a):
        return all(r <= ai for r, ai in zip(r_ub, a))


# IP-247 CCert：协同认证前缀
class CooperativeCertificate:
    def __init__(self, eps_max=0.15, tau_obj_cons=0.4):
        self.eps_max, self.tau_obj_cons = eps_max, tau_obj_cons

    def certified_prefix_co(self, agents, oga_reports, wm_preds):
        k_sim = min(a.k_simras for a in agents)
        k_obj = min(a.k_obj for a in agents)
        k_cons = sum(1 for p in wm_preds if p['eps'] <= self.eps_max)
        k_budget = self._budget_horizon(wm_preds, agents)
        d_obj = max(r['d_obj'] for r in oga_reports)
        if d_obj > self.tau_obj_cons:
            return 0                                  # 物体未共识
        return min(k_sim, k_obj, k_cons, k_budget)

    def _budget_horizon(self, wm_preds, agents):
        spent, k = 0.0, 0
        for p in wm_preds:
            spent += sum(w_i * p['r'] for w_i in agents[0].task_weights)
            if spent > agents[0].Lambda_max:
                break
            k += 1
        return k


# IP-248 CoAudit：多视角交叉审计
class CooperativeAuditor:
    def __init__(self, vqa, renderer, tau_agree=0.8):
        self.vqa, self.render, self.tau_agree = vqa, renderer, tau_agree

    def audit(self, wm_preds_by_agent, scene_ctx):
        reports = []
        for i, preds in enumerate(wm_preds_by_agent):
            vid = self.render.render_rollout(preds, view_id=i)
            reports.append(self.vqa.audit_video(vid, scene_ctx))
        agree = self._agreement(reports)
        return {'reports': reports, 'agree': agree,
                'pass': agree >= self.tau_agree}

    def _agreement(self, reports):
        med = median_report(reports)
        return 1.0 - sum(r != med for r in reports) / len(reports)

# IP-252 CoGenRAS 在线协同环路
def CoGenRAS_round(team, obs_batch):
    zs, phis = [], []
    for i, agent in enumerate(team.agents):
        obs = obs_batch[i]
        zs.append(agent.enc(obs))
        phis.append(agent.oga.encode(obs['object_img']))

    # 1) 跨体物体一致性（每体看到其余体的嵌入）
    oga_reports = []
    for i, agent in enumerate(team.agents):
        others = [phis[j] for j in range(len(team.agents)) if j != i]
        oga_reports.append(
            agent.oga.analyze(obs_batch[i]['object_img'], others))

    # 2) 共识滚动
    wm_preds, hard_fail = team.cowm.rollout(zs, phis, team.act_seqs)
    if hard_fail:
        return 0, None, 'CONSENSUS_FAIL'

    # 3) 预算分配与校验
    budget = team.cbp.allocate()
    if not team.cbp.check([r['r_ub'] for r in oga_reports], budget):
        return 0, budget, 'BUDGET_REJECT'

    # 4) 多视角审计（异步）
    audit = team.coaudit.audit([p for p in wm_preds], team.scene_ctx)
    if not audit['pass']:
        return 0, budget, 'AUDIT_DISAGREE'

    # 5) 协同认证前缀
    k_co = team.ccert.certified_prefix_co(team.agents, oga_reports, wm_preds)
    if k_co == 0:
        return 0, budget, 'NO_CERT'

    # 6) 各体执行 + 证书签发
    for i, agent in enumerate(team.agents):
        agent.dispatch(k_co, lambda_i=1.0 - oga_reports[i]['r_ub'] / budget[i])
        agent.coaudit.cache(wm_preds, oga_reports[i])

    cert = build_J_CoGen(team, oga_reports, budget, wm_preds, audit, k_co)
    return k_co, cert, 'CERTIFIED'
```

## 4. 推导

**引理 13（共识聚合误差界）** 设 `n` 体中至多 `f < n/2` 个故障，正常体误差 `||z_i − z*|| ≤ ε_i`。逐坐标截尾均值满足 `||z_cons − z*|| ≤ ε_(f+1) + diam_f`，其中 `diam_f` 为截尾后样本离散度。故 `ε_cons ≤ 2(ε_(f+1) + diam_f)`。

**引理 14（物体共形覆盖的类别漂移界）** 同分布时分裂共形保证 `P(r(o) ∈ C_α(o)) ≥ 1−α`。类别漂移下层次校正后
```
P(r(o) ∈ C_α(o)) ≥ 1 − α − δ_cat(s_obj),   δ_cat(s_obj) ≤ min(1, L_φ·s_obj/τ_obj)
```
即 OOD 越远，覆盖保证越松，必须用 `r_ub^cat` 而非名义 `q_{1−α}`。

**引理 15（语义别名不可由 OOD 单独识别）** 存在物体对 `(o, o')` 使 `s_obj(o') < τ_obj` 但 `|r(o) − r(o')| > 2L_φ τ_obj`。因此仅靠 OOD 阈值的证书必然在该对上失效，必须引入 `alias(o)` 通道；这也是定理 14 中 `P(alias miss)` 项不可消去的原因。

**定理 14（组合安全定理）** 若每体 `J_SimRAS^{(i)}` 有效、`ε_cons ≤ ε_max`、`d_obj ≤ τ_obj_cons`、`Σ_i w_i a_i ≤ Λ_max`，则
```
P(∃i: r_i > a_i) ≤ Σ_i α_i + P(consensus failure) + P(alias miss)
```
且 `Valid(J_A) ∧ Valid(J_B) ⇒ Valid(J_{A⊕B})`。

**定理 15（物体泛化到协同的迁移界）** 结合定义 284 与引理 14，
```
r_ub^team(o) ≤ max_i [r_sim(o_i) + L_φ·s_obj(o_i) + ε_sim] + κ·d_obj
```
当 `s_obj → 0`、`d_obj → 0` 时退化为第 67 轮 SimRAS 的 `r_ub`。CoGenRAS 是 SimRAS 的严格保守扩展。

**定理 16（预算分配的 Pareto 最优性）** 定义 275 的 Nash 议价解是唯一满足 Pareto 最优、按权重对称、无关备选独立的分配；当 `Λ_max ≥ Σ w_i a_i^min` 时闭式解存在且每体绝对余量相等。任何偏离都会使至少一个体余量下降而不提升团队总余量。

## 7. 本轮最大风险

**一句话**：CoGenRAS 把 `s_obj` 与跨体共识当作“未知物体危险度”的充分统计量，但语义别名会让 OOD 分数很低而真实风险很高，且多体共享同一预训练骨干使共识高度相关而非独立——于是团队可能**一致且自信地把新物体签成“已知安全物体”**，并把共享预算配置到错误对象上，使“协同”从冗余变成了错误放大。

**次级风险与缓解**：
1. **相关误差**：强制多体使用不同骨干/视角/传感模态，降低共识相关性；
2. **别名漏检**：AliasDetector 用外形-功能双通道，必要时主动交互（抓取试探/轻推）获取功能证据；
3. **预算博弈作弊**：预算账本纳入证书哈希，跨体交叉校验 `a_i` 与 `r_i`；
4. **通信延迟**：`τ_comm` 超过认证前缀时长时强制 `k_cons=0`，退化为单体 SimRAS；
5. **共形失效**：新类别上启用保守膨胀 `κ·s_obj`，宁可多降级也不误签。
