# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++ / v31；灵感循环第 6 轮；本轮灵感：「情感计算」×「具身智能」）

> 第 54 轮把技能组合提升为「动作-鲁棒性双证书 + 云边闭环」。本轮引入 **情感计算** 与 **具身智能**，把情感从「外挂识别模块」改写为 **具身内感受控制变量**，追问：当机器人在人类身边长期运行时，「动作正确 + 鲁棒达标」是否足够？核心矛盾：**H22** 情感是隐变量，估计误差会沿技能组合与云边回路放大，形成「伪共情」调节；**H23** 情感表达受身体约束（affective affordance），跨本体迁移时情感语义漂移，情感证书在目标本体上失效。

## 0. 直觉与动机

**灵感 1（情感是内感受，不是表情分类器）**
直觉：具身智能强调「身体在回路中」。情感计算若只做面部/语音分类，就丢掉了身体。真正的具身情感由 (i) 内感受 `b`（能量、温度、负载、关节应力）与 (ii) 情境评估 Appraisal 共同生成的 **控制状态** `e` 构成。机器人不是在「识别情绪」，而是在「用情感调节自己」：负载升高 → 唤醒度上升 → 主动降低动作幅度。这把情感从感知任务变成控制变量，也让它可被形式化、可被约束。

**灵感 2（情感包络，而非情感最大化）**
直觉：不应追求「让人类一直开心」，而应维持 **情感稳态包络 `E*`**：在可接受区间内波动即为健康。定义 `affective risk` 为「未来情感轨迹越出 `E*` 的概率」，用控制障碍函数（CBF）/模型预测控制把动作选择约束在包络内。这样情感成为与第 53/54 轮鲁棒性谱 `ρ`、动作占用证书 `A_cert` 并列的安全维度，而不是软性 KPI。

**灵感 3（情感是失败的先导信号）**
直觉：技能组合与云边协同中，几何/鲁棒性失败往往滞后；而人类犹豫、语速下降、交互节奏紊乱、机器人内感受异常，常 **先于** 失败出现。把情感偏差作为 CUSUM 序贯检测量，可在 `ρ` 跌破阈值前触发第 54 轮的 Explain 反向通道，换来 `τ_warn` 的提前量。这把情感层直接接进「云规划-边校验-反向解释-重剖分」闭环。

**灵感 4（情感可负担性 → 跨本体迁移的硬约束）**
直觉：不同本体可表达的情感子空间不同：有脸/无脸、有臂/无臂、轮式/足式。定义 **affective affordance** `Aff(q) ⊆ E`：本体 `q` 能可靠表达与调节的情感子空间。跨本体迁移不只是技能迁移，还要保证「人类对情感表达的解读一致」，即 grounding error `ε_ground ≤ Θ_g`。否则同一动作在目标本体上表达出不同情感，造成误读甚至操纵。

**灵感 5（情感-具身层叠加到金字塔）**
直觉：在第 54 轮动作-协同层 `𝔸` 之上叠加 **情感-具身层 `𝔼`**：`𝔼_0` 内感受/生理约束，`𝔼_1` 情感评估 App，`𝔼_2` 情感表达动作与可负担性，`𝔼_3` 人际情感契约（谁在何时可被如何安抚/激励）。跨层证书同时携带 `ρ, A_cert, AECert`，形成可解释的「动作-鲁棒-情感」三证书体系。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（情感-具身状态）**
情感-具身状态 `z_t = (e_t, b_t)`，其中 `e_t = (v, a, d) ∈ [-1,1]^3` 为效价/唤醒/支配的校准估计，`b_t ∈ B ⊆ R^m` 为内感受向量（能量、温度、负载、关节应力、电池健康）。**情感稳态包络** `E* ⊆ [-1,1]^3 × B` 为可测、且在调节策略 `π_H` 下 **控制不变** 的目标集：`∀ z∈E*, ∃ a∈A: P(App(z,a,o)∈E*) ≥ 1-δ_H`。

**定义 122（情感评估算子与接地）**
情感评估算子 `App_θ : Z × A × O → Δ(Z)`，给定状态、动作、观测给出下一情感状态的分布；`App̄` 为其期望。**接地假设**：存在可观测代理 `y_t`（面部、语音、姿态、皮电/心率、任务节奏）与校准器 `g_φ`，使 `e_t = g_φ(y_t, b_t) + η_t`，且 `g_φ` 在留出集上满足 conformal 覆盖 `P(e_t ∈ Ĉ_α(y_t)) ≥ 1-α`。**我们只认证该校准代理，不宣称测到「真实情绪」**——这是本层Soundness 的诚实前提。

**定义 123（情感风险与先导预警）**
给定 `z` 与动作 `a`，情感风险 `AR(a|z) = P_{o~O}[App_θ(z,a,o) ∉ E*]`，其 conformal 上界记为 `AR_ub`。序贯预警统计量 `W_t = max(0, W_{t-1} + D(z_t, E*) - h)`，`D` 为到包络的 Mahalanobis 距离；当 `W_t > h_th` 触发预警。**先导时间** `L = t_fail - t_warn`，要求 `L ≥ τ_warn` 才有部署价值。

**定义 124（情感可负担性与表达接地）**
本体 `q` 的情感可负担集 `Aff(q) ⊆ E`，表达映射 `expr_q : Aff(q) → A_q^expr`，调节映射 `reg_q : E × A → A`。两本体 `q,q'` 的 **情感接地误差**：
```
ε_ground(q,q') = sup_{e ∈ Aff(q) ∩ Aff(q')} d_H( human_interpret(expr_q(e)),
                                                     human_interpret(expr_{q'}(φ(e))) )
```
其中 `φ: Aff(q) → Aff(q')` 为表达对齐映射，`d_H` 为人类解读分布间的 Hellinger 距离。

**定义 125（情感兼容性与组合成本）**
技能 `S_i,S_j` 在状态 `z` 下的情感兼容性 `acompat(S_i,S_j|z) = P(transition(S_i→S_j) 全程 ∈ E*)`。扩展第 54 轮对齐成本：
```
cost_aff(S_i,S_j) = w_a(1-compat) + w_ρ(1-ρ_comp) + w_ce||γ_ce - id||
                    + w_e·AR_ub(S_i⊗S_j) + w_g·ε_ground(q,q')
```
组合可部署当且仅当第 54 轮全部门槛成立，且 `AR_ub ≤ Θ_aff ∧ ε_ground ≤ Θ_g`。

**定义 126（情感-具身证书）**
`AECert = (E*, τ_E, AR_ub, Aff(q), ε_ground, evidence)`，其中 `evidence` 至少包含校准情感轨迹、人类解读试验记录、反事实评估 rollout。判定 `dom(AECert) = in` 当且仅当：
```
AR_ub ≤ Θ_aff ∧ ε_ground ≤ Θ_g ∧ E* 在 π_H 下控制不变
```

## 2. 关键算法 伪代码

### IP-121 AES（Affective-Embodied State Estimation）

```python
def estimate_affective_state(obs, body, calibrator):
    y = fuse(obs.face, obs.voice, obs.posture, obs.task_rhythm, body.intero)
    z = encoder(y)                        # (v,a,d,b)
    e_hat, C = calibrator.predict(z)      # conformal set
    return AffectiveState(e_hat, C, body)

def conformal_calibrate(g_phi, calib_set, alpha):
    scores = [distance(e, g_phi(y, b)) for (y, b, e) in calib_set]
    q = quantile(scores, 1 - alpha)
    return Calibrator(g_phi, q)           # 覆盖保证 1-alpha
```

### IP-122 AHC（Affective Homeostatic Control）

```python
def homeostatic_policy(z, skill, E_star, horizon):
    best = None
    for a in skill.available_actions():
        dist = predict_affect_distance(z, a, horizon)
        risk = ar_upper_bound(z, a)
        if risk <= THETA_AFF and dist <= 0.0:        # CBF 型不变性
            score = skill.cost(a) + LAM*dist + MU*risk
            if best is None or score < best.score:
                best = (a, score)
    return best if best else SAFE_FALLBACK           # stop / ask / soothe
```

### IP-123 AEW（Affective Early Warning）

```python
def affective_guard(stream, E_star, h, h_th, tau_warn):
    W = 0.0
    for t, z in enumerate(stream):
        dev = mahalanobis(z.e, E_star.center, E_star.cov)
        W = max(0.0, W + dev - h)                    # CUSUM
        if W > h_th:
            lead = predict_time_to_failure(z)
            if lead < tau_warn:
                return ('warn', t, explain(z))
    return ('ok', None, None)
```

### IP-124 ACM（Affective Composition Metric）

```python
def affective_edge_cost(s1, s2, z, E_star):
    acts = transition_actions(s1, s2)
    ar = max(ar_upper_bound(z, a) for a in acts)
    ac = 1.0 - affective_compat(s1, s2, z, E_star)
    return W_AR*ar + W_AC*ac

def compose_with_affect(G, z, E_star, path):
    return sum(G[e].cost + affective_edge_cost(*e, z, E_star) for e in path)
```

### IP-125 ASC（Affective Safety Certificate）

```python
def affective_certificate(skill_seq, z0, E_star, robot, theta_aff, theta_g):
    z = z0
    for s in skill_seq:
        z = app_mean(z, s)
        if z not in E_star:
            return ('reject', 'envelope_violation', z)
    ar = max_ar_upper_bound(skill_seq, z0)
    g  = grounding_error(robot, robot)               # 单本体先验
    if ar > theta_aff or g > theta_g:
        return ('reject', 'affective_risk', ar, g)
    return ('ok', AECert(E_star, TAU_E, ar, robot.affordance, g))
```

### IP-126 AXT（Affective Transfer）

```python
def transfer_affect(src_cert, src_q, dst_q, human_eval, theta_g):
    phi = align_expressive_actions(src_q.affordance, dst_q.affordance)
    g_err = human_interpretation_error(phi, human_eval)   # Hellinger 均值
    if g_err > theta_g:
        return ('reject', 'grounding_mismatch', g_err)
    dst_cert = AECert(src_cert.E_star, src_cert.tau_E,
                      src_cert.AR_ub, dst_q.affordance, g_err)
    return ('ok', dst_cert)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| AES | O(T·(\|y\|·d_φ + C_cal)) | O(\|Z\| + N_cal) | conformal 覆盖、接地假设 |
| AHC | O(H·\|A\|·(\|Z\|+\|O\|)) | O(\|Z\|) | E* 控制不变、CBF 约束 |
| AEW | O(T·\|Z\|) | O(\|Z\|) | CUSUM 虚警率、先导时间 |
| ACM | O(\|S\|²·\|A\|·H) | O(\|S\|²+\|E\|) | 风险上界 sound、成本单调 |
| ASC | O(k·H·\|A\| + N_cal) | O(\|Z\|) | 包络可达、证书可组合 |
| AXT | O(\|Aff\|·\|A_expr\| + N_human) | O(\|Aff\|) | 人类解读一致、φ 可逆 |

**正确性定理（Affective-Embodied Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增：**(A29)** `g_φ` 在留出集上 conformal 覆盖 `≥ 1-α`；**(A30)** `E*` 在 `π_H` 下对时域 `H` 控制不变；**(A31)** 跨本体 `ε_ground ≤ Θ_g`；**(A32)** 先导时间 `L ≥ τ_warn`。则「任务成功且情感不越界」的概率：
```
P_success∧safe ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a) - P(compat < θ_a)
                    - α - P(AR_ub > Θ_aff) - ε_ground - P(L < τ_warn)
```
关键：**情感层不替代鲁棒性，而是把「人-机共同失败」纳入同一个上界**；任一护栏失效都直接扣减部署概率，而非被平均掉。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 情感测量构念效度不足 | 高 | 多模态 + 人类金标 + 只认证校准代理 |
| 情感反馈环震荡/情感传染 | 高 | hysteresis + 冷却期 + 人类可覆盖开关 |
| 隐私与情感操纵 | 高 | 不落原始生理流、最小必要、知情同意 |
| 过保守导致任务失败 | 中 | 分场景包络 + 可恢复放宽 + 回滚 |
| 跨本体 grounding 漂移 | 高 | 人类解读试验 + AXT 拒绝部署 |

## 6. 本轮最大风险

**一句话**：把情感写成具身控制变量、并叠加到动作-鲁棒性证书上，逻辑自洽，但其全部收益都押在「情感代理的构念效度 + `E*` 的控制不变性 + 跨本体表达接地」三点上；一旦校准代理只学到了表情而没学到内感受、或 `E*` 在真实扰动下不可控、或表达接地在目标本体上漂移，系统就会以「高置信的伪共情」系统性地误读人类并做出错误调节，这比不做情感计算更危险。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-Affect++（AES×AHC×AEW×ACM×ASC×AXT）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书 + 云边闭环」之上，把 **情感计算** 与 **具身智能** 融合为可形式化、可约束、可迁移的 **情感-具身层**：
> - **AES（Affective-Embodied State）**：内感受 + 情境评估生成的校准情感状态 `z=(e,b)`；
> - **AHC（Affective Homeostatic Control）**：以情感稳态包络 `E*` 为约束的 CBF/MPC 调节；
> - **AEW（Affective Early Warning）**：情感偏差的 CUSUM 先导预警，接入 Explain 反向通道；
> - **ACM（Affective Composition Metric）**：把 `AR_ub` 与 `ε_ground` 注入技能组合图边权；
> - **ASC（Affective Safety Certificate）**：情感安全证书 `AECert`；
> - **AXT（Affective Transfer）**：跨本体情感表达接地迁移。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-116/117/118 以纳入情感-具身维度。

```python
def full_loop(P_c, G, z, E_star, sim_model):

    if P_e.status == 'reject':
        return ('replan', P_e.explain)
    warn = affective_guard(trace(z), E_star, H_CUSUM, H_TH, TAU_WARN)
    if warn.status == 'warn':
        return ('reprofile', warn.explain)                # 情感先于 ρ 触发重剖分
    cert = affective_certificate([s for s,_,_ in P_e.plan], z, E_star)
    return ('deploy', cert) if cert.status == 'ok' else ('reject', cert.reason)
```
