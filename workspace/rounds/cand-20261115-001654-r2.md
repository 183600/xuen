**一句话**：ToolGauge 把每个物理观测都变成了带不确定度的回执，却把「人/模型给的标签」和「榜单上的名次」当成免费的真值。

## 1. 二元映射（同一件事的两面）

| 灵感词 | ToolGauge 对象 | 升级为 | 动机 |
|---|---|---|---|
| 数据标注 | C_cal / F_* / MP-Φ 的标签 | **A-Box**：标注契约 + 标签回执 + 标注者可靠性 + 噪声传播 + 主动标注/随机审计 | 标签是另一类传感器，不是真值 |
| 排行榜 | E426–E439 的自设阈值比较 | **B-Box**：榜单契约 + 隐藏留出 + 配对置信区间 + 多重比较 + 红队竞技场 | 「谁更好」是假设，不是结论 |
| （合流） | 证据消费 | **证据市场**：标注者与修复策略都是可被评分的证据生产者 | 同一套适当评分/同行预测，同时治理两类证据 |

**核心命题**：ToolGauge 审计了「证据」（回执），但没有审计「证据的生产者」与「证据的竞争」。
ArenaGauge 把标注和排名都变成**带契约、带不确定度、带反事实**的可撤回主张：
标注只以「带 σ_label 的测量」进入校准，排名只以「带区间的假设」进入策略选择；
数值真值仍由计量层独占，语言与标签仍不直接进入数值通道。

**不变式保持**：
- MODGAUGE 五不变式全部保留；
- 主张绑定不变式扩展为**三级证据绑定**：数值主张→回执；语义主张→标签回执；改进主张→榜单协议版本 + 隐藏留出哈希（定义 444）；
- 严格退化链延长：ArenaGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。A-Box/B-Box 是增强项，不是依赖项。

## 2. 直觉

**直觉 1（数据标注 → 计量学一路到底）**
ToolGauge 已经相信「没有 σ 的观测不是测量」。但标签恰恰是最常被当成无噪声的观测：
标注者看一张图说「这是镜面反射」，和红外探针返回一个 μ±σ，本质上都是**对潜变量的带噪测量**。
区别只是标签的噪声来自人/模型的先验、疲劳、协议歧义和类别不平衡。若不给标签配噪声模型，
AP-Cal 会把「所有标注者都系统性高估反射率」学成一个自信的先验，然后摊销到每个盲区。
因此本轮的第一条直觉是：**给标签发回执，给标注者估混淆矩阵，把标签方差加进 AP-Cal 的观测方差**。
标签不是真值，是另一个传感器；它必须和探针一样被校准、被抽查、被追责。

**直觉 2（主动标注会污染校准集）**
标注预算有限，当然应该优先标注「最可能改变决策」的格子——这正是定义 435 的标注价值 VoI。
但一旦按价值选样，C_cal 就不再是部署分布的无偏样本，引理 48 的可交换性被系统自己破坏：
模型越确信哪里重要，就越只标注那里，校准集越来越像模型的先验，覆盖保证变成自我实现。
解法不是放弃主动标注，而是**强制随机审计配额 ρ**：至少 ρ 比例的标注必须均匀随机抽，
只用于估计覆盖与标注者可靠性；其余主动标注用重要性加权进入校准。
这是制造业「首件检验 + 抽检」的思路，不是机器学习的新技巧，但在这里是保证统计有效性的硬约束。

**直觉 3（排行榜是 Goodhart 机器）**
ToolGauge 的实验是自设阈值、自设场景、自选指标；没有隐藏留出，也没有红队。
一旦把「谁修得好」做成榜单，策略就会朝可见指标进化：只修好演示的材质、只在公开格子上提升、
只报告显著的子集。此时榜单测到的是「谁最擅长榜单」，不是「谁最擅长修复」。
因此榜单必须像临床 trial 一样预注册：冻结测试集哈希、隐藏留出、配对随机种子、
排名区间、Holm 多重比较校正、失败提交也入账。更进一步，**榜单应该是双向的**：
蓝队提交修复证书，红队提交证伪尝试（伪造回执、投毒标签、重放篡改、公开集过拟合），
按「最坏红队下的存活率下界」排名。冠军不是分数最高者，而是**最难被证伪者**。

**直觉 4（标注者与策略是同一个数学对象）**
标注者给潜变量一个信号，修复策略给「哪套修复更好」一个信号；两者都在没有完整真值时竞争可信度。
所以可以用同一套语言：适当评分规则、同行预测、金标准抽查、可靠性后验。
这就是为什么「数据标注」和「排行榜」在本轮不是两个模块，而是**一个证据市场**的两侧：
一侧定价标签，一侧定价策略；两侧共用随机审计、隐藏留出和证据账本。

## 3. 形式化定义（增量 432–447）

**定义 432（标注契约 AC 与标签回执）** 一条标注 ℓ = (x, v, π, a, ts, prov, c_ℓ, sig)：
- x：标注目标（格子 s、材质标签、假设 h、或一条修复证书）；
- v ∈ {1, 0, ⊥}：`VERIFIED_BLIND` / `VERIFIED_CLEAR` / `UNKNOWN`（三值，⊥ 不是 0）；
- π：预注册标注协议（问题措辞、参考标准、允许的辅助信息）；
- a：标注者身份（人/模型/通道），prov：来源证据（引用的工具回执或原始帧哈希）；
- c_ℓ：标注成本；sig：签名。
valid(ℓ) ⇔ Schema_π(x,v) ∧ π ∈ Π_ann ∧ Verify(prov) ∧ Verify(sig) ∧ 未过期。
无效标签一律作废；**作废标签永不进入校准集，也不被插补**。

**定义 433（标注噪声模型与标注者可靠性 LQ-Φ）**
每个标注者 a 在上下文 c 下有混淆矩阵 θ_a(c) = P(v | y*, c)；以分层先验 θ_a ~ Dir(α) 估计，
金标准子集 G（由计量通道提供，比例 ρ_gold）用于校准 θ_a。
聚合后验 q(y* | ℓ_{1:k}) 输出 (p̂, σ_label²)，其中 σ_label² 由后验熵给出方差下界。
进入 AP-Cal 时，观测方差取 **σ_obs² = σ_tool² + σ_label²**（异方差、保守）：
标签越不可靠，后验越宽，风险门 λ 越容易要求补测——标注质量自动转化为探测需求。
可靠性 κ = 1 − H(p̂)/log|𝒴|；κ < κ_min 的标签视为 ⊥，不得用于契约更新。

**定义 434（负标注与格子三态）**
每个格子 s 的状态 state(s) ∈ {CLEAR, BLIND, UNKNOWN}，只能由有效标签或有效回执显式迁移；
**缺失不等于 CLEAR**。定义负标注完备度 NC = |CLEAR| / (|CLEAR| + |BLIND|)（仅在已标注集合上），
以及标注覆盖率 η_lab = (|CLEAR|+|BLIND|) / |R|。η_lab < η_min 的格子不得进入「已修复」集合。
这修复 A3：覆盖矩阵不再把「没查」与「查过正常」混为一谈。

**定义 435（主动标注与标注价值 VoI）**
候选标注 ℓ 的价值 V(ℓ) = ΔRisk(ℓ) − c_ℓ，其中 ΔRisk 为三部分期望下降之和：
共形集大小、契约后验方差、排名区间宽度（定义 439）。
在预算 B_ann 下选取 A_t，使 Σ V 最大；V 在条件熵下单调子模，贪心给 (1−1/e) 近似（引理 52）。
**随机审计配额**：每批标注中至少 ρ 比例从候选全集均匀随机抽取（不看 V），记 U_t；
U_t 是覆盖估计与标注者可靠性的无偏锚，A_t \ U_t 只能用重要性权重进入校准（定义 437）。

**定义 436（标签-回执绑定）**
用于校准或契约更新的每条标签必须引用至少一条有效工具回执或预注册协议产物；
无来源、来源哈希不匹配、或来源已过期的标签，在 EC 序列化时**剥离**（不改变任何数值行为）。
标签到数值先验的映射必须预注册且可审计；标签永远不直接写入 u_fields 或 χ_R。
这是定义 423「主张-回执绑定」向标注侧的扩展，堵住「用标注绕过计量」的后门。

**定义 437（选择偏差修正的共形校准）**
C_cal = U（均匀审计子集，大小 m=ρn）∪ A（主动子集）。在 U 上估计分位数 q_U 与覆盖；
在 A 上使用倾向权重 w(x)=1/e(x)，e(x)=P(x∈A | x)（预注册选择模型）。
有效样本量 n_eff = (Σw)² / Σw²；若 n_eff < n_min(α,δ)，则**不给出 1−α 保证**，
退回保守分位数或 H_s := {UNKNOWN}（退化链第 1 级）。
样本级覆盖界见引理 53；这修复 A4，使「主动」与「可交换」不再互相矛盾。

**定义 438（榜单契约 LC）**
LC = (TaskSuite, Metrics, π_rank, H_hid, Agg, CI, Multiplicity, t_freeze, RedPool)：
- TaskSuite/Metrics 在 t_freeze 前冻结；H_hid 为隐藏留出集的哈希承诺；
- Agg 为聚合规则（均值/中位数/稳健分位数），CI 为区间方法（配对 bootstrap 或 Bradley–Terry）；
- Multiplicity 为多重比较方法（默认 Holm，FWER ≤ α）；
- RedPool 为预注册红队策略池（见定义 442）。
有效改进主张 ⇔ 预注册 ∧ 数据未泄漏 ∧ **所有提交（含失败）入账** ∧ 只用隐藏留出出结论。

**定义 439（排名统计与排名区间）**
对 N 个配对任务（同种子、同初始状态）计算 d_i = score_A(i) − score_B(i)；
均值 δ 的 (1−β) 配对 bootstrap 区间为 [δ_lo, δ_hi]。
多策略用 Bradley–Terry 拟合能力参数并 bootstrap 得排名区间 [r_lo, r_hi]。
主张「A 优于 B」需同时满足：δ_lo > MDE 且两者排名区间不重叠；
否则只能报「tie / undetermined」，不得用点估计排序。
MDE 由任务方差与功效分析预注册，不得事后调整。

**定义 440（预注册与多重比较）**
所有比较在 t_freeze 前登记，共 K 项；用 Holm–Bonferroni 控制 FWER ≤ α（或预注册 BH 控制 FDR）。
K、检验族、缺失数据处理规则全部入账；**禁止事后挑指标、挑子集、挑种子**。
K 个独立估计的最大值存在赢家诅咒，期望膨胀约 σ√(2 ln K)（引理 55）；
因此冠军主张必须用区间下界，而不是最大值。

**定义 441（隐藏留出与排名膨胀）**
公开榜分数 s_pub（可见）与影子榜分数 s_hid（隐藏留出）之差 Δ_infl = s_pub − s_hid。
若 Δ_infl 的置信下界 > τ_infl ⇒ 判定公开集过拟合/泄漏/投毒，冻结相关主张并触发审计；
**对外主张只允许引用 s_hid**。隐藏留出的哈希在 t_freeze 前承诺，事后不可更换。
这把「榜单分数」从宣传数字变成可检验的泛化差距。

**定义 442（红队竞技场与稳健排名）**
红队池 RedPool = {red_1,…,red_R}，每个 red_j 生成一类证伪尝试：
伪造回执/标签、公开集过拟合、重放篡改、选择性报告、分布外材质。
蓝队策略 b 的稳健分 g_j(b) = E[survival(b, red_j)]，稳健总分 G(b) = min_j g_j(b)。
排名用每个 g_j 的置信下界再取 min（保守 LCB），即 LCB(G(b)) = min_j LCB(g_j(b))；
按 LCB 降序排名。**冠军 = 最难被证伪者**，不是平均分最高者。
红队本身也入账、可复现；红队策略的更新不能看到隐藏留出。

**定义 443（排名即假设的策略选择）**
系统内部可用榜单选择修复策略，但排名是假设：
仅当候选策略的稳健 LCB 超过默认 ToolGauge 策略至少 δ_min 时采用；否则用默认策略。
同时最多保留 2 个候选，避免「在噪声上选冠军」；选择记录进入证据账本。
这防止元过拟合：把排名误差当成修复收益。

**定义 444（证据账本 EL 与「无孤儿数字」）**
EL 是只追加哈希链，条目类型：
`label`（标签回执哈希）、`receipt`（工具回执哈希）、`protocol`（AC/LC 版本与哈希）、
`holdout`（隐藏留出哈希）、`rank`（排名统计与区间）、`decision`（热替换/拒绝/退化）、
`counterfactual`（同种子「不修复」分支的 stub 哈希）。
**无孤儿数字**：任何对外主张中的数值必须引用 ≥1 条正确类型的 EL 条目；
否则在契约序列化时剥离。证书 = 可一键重放的 EL 切片，而不是一段叙述。

**定义 445（标注/竞技场预算与退化）**
TB-Contract 扩展为 AB-Contract = (B_ann, B_rank, τ_ann, ρ, κ_min, n_min, τ_infl, δ_min)：
标注预算、榜单查询预算、标注时延上限、随机审计比例、可靠性门槛、有效样本门槛、膨胀阈值、选择裕度。
预算耗尽或 κ/η_lab 不达标 ⇒ **标记 UNKNOWN 并退化，绝不插补标签**；
榜单不可用或被判定投毒 ⇒ 只保留数值修复，不产生改进主张；
再失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

**定义 446（ArenaGauge 8C 闭环）**
H → C → E → **A** → Cal → V → **R** → U：
1. H/C/E/Cal/V 继承 ToolGauge 6C；
2. **A（Annotate）**：对需要语义标签/校准目标的格子，按定义 435 采集并校验标签，
   更新三态、标注者后验、σ_label，并把标签方差并入 Cal；
3. **R（Rank）**：若本轮要产生「改进」主张，则在隐藏留出上按定义 438–442 做预注册配对比较与红队评估；
   数值修复本身只需要 V 通过，R 失败只剥夺「改进」主张，不阻止数值热替换（分离原则）；
4. **U**：热替换仍由 V + 契约回归决定；EL 记录全部证据；无孤儿数字检查后写证书。
A/R 均可跳过并记录 `skipped(reason)`；跳过时不得声称相应结论。

**定义 447（继承与退化语义）**
未被重定义的第 2 轮记号（R、s、r、Π_s、H_s、λ、β、MP-Φ、EC、M_ver、P-Quarantine 等）沿用定义 416–431。
令 Π_ann=∅、LC=∅ ⇒ ArenaGauge ≡ ToolGauge；再令 VLA=∅、T₀={被动观测}、MP-Φ=物理先验 GP ⇒ ToolGauge ≡ LeanGauge ⇒ MODGAUGE。

## 4. 关键算法骨架

```python
# IP-321 A-Box：标签回执、三态、来源绑定
@dataclass
class LabelReceipt:
    x: Cell | Hyp | Cert
    v: Literal[1, 0, None]          # 1=BLIND, 0=CLEAR, None=UNKNOWN（⊥ 不是 0）
    protocol: str; annotator: str
    prov: list[str]                  # 引用的工具回执哈希
    ts: float; cost: float; sig: str

def accept_label(l, ac):
    return (l.protocol in ac.protocols and verify_sig(l.sig)
            and all(verify_prov(p) for p in l.prov)
            and not expired(l) and l.v is not None)

def update_state(state, l):
    if not accept_label(l): return state          # 作废：不插补
    return {**state, l.x: {1: "BLIND", 0: "CLEAR"}[l.v]}

# IP-322 LQ-Φ：标注者可靠性 + 噪声进入观测方差
class LabelQuality:
    def posterior(self, labels, gold):
        # 分层 Dawid-Skene / EM：θ_a ~ Dir(α)，gold 校准
        theta = self.fit_reliability(labels, gold)
        p, H = self.aggregate(labels, theta)
        kappa = 1 - H / log(self.n_classes)
        return p, kappa, var_from_entropy(H)
    def obs_var(self, sigma_tool2, p, H):
        return sigma_tool2 + var_from_entropy(H)   # σ_obs² = σ_tool² + σ_label²

# IP-323 V-Act：VoI 贪心 + 强制随机审计
def select_annotations(cands, B_ann, rho, rng):
    U = rng.sample(cands, max(1, int(rho * B_ann)))          # 无偏锚，不看 V
    rest = [c for c in cands if c not in U]
    A = greedy_max_coverage(rest, B_ann - len(U), value=voi)
    return U, A                                              # U 用于覆盖估计

# IP-324 B-Box：预注册、配对区间、多重比较
class BBox:
    def compare(self, A, B, tasks, lc):
        d = [score(A, t) - score(B, t) for t in tasks]       # 同种子配对
        lo, hi = paired_bootstrap(d, level=1 - lc.beta)
        return lo, hi, (lo > lc.mde)                          # 只用下界主张
    def rank(self, subs, lc):
        stats = bradley_terry_bootstrap(subs, lc.tasks, B=lc.B)
        return adjust_holm(stats, lc.K, lc.alpha)             # 排名区间 + Holm

# IP-325 R-Arena：红队证伪 + 稳健 LCB
def robust_rank(blues, reds, tasks, lc):
    out = {}
    for b in blues:
        g = [paired_lcb(survival(b, r, tasks), 1 - lc.beta) for r in reds]
        out[b] = min(g)                                      # 最坏红队下的 LCB
    return sorted(out, key=out.get, reverse=True)            # 冠军 = 最难被证伪

# IP-326 ArenaGauge 8C（A/R 可跳过但必须记录）
def arenagauge_8c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                         # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))      # C
    receipts = M.tcv.execute(prog, M.env)                          # E
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")
    U, A = M.vact.select_annotations(M.cands(s, H), M.b_ann, M.rho, M.rng)  # A
    labels = M.abox.collect(U + A, M.annotators)
    p, kappa, var_lab = M.lq.posterior(labels, M.gold(s))
    if kappa < M.kappa_min or n_eff(U, A) < M.n_min:
        return stub_and_red(s, "label_quality")                    # 不插补
    mu, Sig = M.apcal.calibrate(receipts, H, s, extra_var=var_lab) # Cal（含 σ_label²）
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):    # V
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    claim_ok = True
    if M.want_improvement_claim(s):                                # R（可选）
        claim_ok = M.bbox.claim(new_ec, M.shadow, M.lc) and M.arena.survives(new_ec, M.reds)
    M.mreg.hot_replace(M.dpe, new_ec)                              # U：数值修复独立于 R
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_evidence(new_ec, labels, receipts, M.bbox.last_protocol, claim_ok)  # 定义 444
    return True
```

## 5. 推导

**引理 51（带噪标签的共形覆盖下界）** 设分数 φ∈[0,1]，标签噪声使 TV(P_{X,ŷ}, P_{X,y*}) ≤ ε_lab。
在带噪校准集上取标准 split-conformal 分位数 q̂，则对真实标签
P(φ(X,y*) ≤ q̂) ≥ 1 − α − ε_lab。
证明：对任意阈值 q，|P(φ(X,ŷ)≤q) − P(φ(X,y*)≤q)| ≤ TV ≤ ε_lab；再代入 split-conformal 的 1−α。
系：若只在 κ < κ_min 的标签上校准，ε_lab 无界 ⇒ 不给出保证（定义 437 的硬门槛）。
这是「标签方差进 AP-Cal」的分布级理由；σ_label² 是有限样本版本。

**引理 52（标注价值的子模性与贪心近似）** 令风险 R(A) = H(Y_{U\A} | ℓ_A)（或期望对数损失），
则 ΔRisk(A) 单调、子模；在基数预算 B_ann 下，贪心选择满足
ΔRisk(A_greedy) ≥ (1−1/e)·ΔRisk(A*)。
证明：条件熵的边际收益递减（信息从不增加），标准 Nemhauser–Wolsey–Fisher 子模最大化。
系：随机审计配额 U 只占预算 ρB_ann，贪心在剩余预算上仍有 (1−1/e) 的近似（预算切分）。

**引理 53（选择偏差下的覆盖与有效样本量）** 设审计子集 U 为均匀抽样、主动子集 A 依 e(x) 选择。
在 U 上估计的覆盖是目标分布的无偏估计，二项置信区间宽 O(√(log(1/δ)/m))；
在 A 上用 w=1/e(x) 加权，加权共形覆盖相对名义 1−α 的缺口满足
Δ_w ≤ O(√(χ²(P_A‖P_U)/m))，且当 n_eff=(Σw)²/Σw² < n_min 时不等式失效。
操作规则：n_eff < n_min ⇒ 不给保证、退回保守分位或 UNKNOWN。
证明思路：加权经验过程 + 有效样本量；χ² 项度量主动分布与审计分布的偏离。
系：ρ 不是超参数，而是**用覆盖缺口换标注效率**的显式旋钮。

**引理 54（排名区间覆盖与选择后悔）** K 个策略、N 个配对任务、差值次高斯(σ)。
配对 bootstrap 的边际区间覆盖 → 1−β；对 K(K−1)/2 个成对比较取联合界后同时覆盖 ≥ 1−β。
若按 LCB 选择且要求 δ_min 裕度，则以概率 ≥ 1−β 选中策略的真实均值与最优之差 ≤ δ_min + 2·区间半宽；
当区间半宽 < δ_min/2 时后悔 ≤ 2δ_min。证明：同时置信区间 + 并集界。

**引理 55（多重比较与赢家诅咒）** Holm 在任意相依结构下控制 FWER ≤ α。
K 个独立次高斯估计的最大值期望膨胀 ≤ σ√(2 ln K)（标准极值界）。
系：冠军主张必须用 LCB；点估计冠军的「领先幅度」不可作为效应量。

**引理 56（红队稳健排名的保守性）** 有限红队池 R 下，min_j LCB(g_j) 是 G(b)=min_j g_j(b) 的有效下界；
按此 LCB 排序，选中策略的真实 G 与最优 G 之差 ≤ 2δ（以概率 ≥ 1−β），
其中 δ 为单侧区间半宽。证明：min 的下界 ≤ 每个分量下界 ⇒ ≤ 最小值；再套引理 54 的并集界。
系：红队越强，排名越保守——这正是「冠军 = 最难被证伪」的形式化。

**引理 57（证据层不破坏热替换等价性与硬实时）**
A-Box/B-Box 只影响：H_s 的成员、Cal 的观测方差、U 阶段是否允许「改进」主张；
不修改 u_fields、χ_R 或任何数值子图指令。无来源标签/无 EL 引用的数字在序列化时剥离，是纯投影。
因此引理 49 的子图数值等价性、引理 50 的时序结论保持不变。
标注/榜单全异步，50Hz 路径新增仅 EL 追加 O(1) < 0.2ms；预算由 AB-Contract 硬顶。

## 8. 本轮最大风险（一句话）

**一句话**：A-Box 的主动标注与 B-Box 的公开榜单会形成正反馈——系统越按自己的价值函数选标注、
越按自己的可见指标选策略，证据链就越自洽，而部署分布上的真实误差越不可见；
这是一种由**证据生产机制本身**制造的、P-Quarantine 无法察觉的系统性偏差（随机审计 ρ、隐藏留出与红队是仅有的三道外部锚）。

**次级风险与缓解**：
1. 标注者相关偏差（同一培训/同一模型）→ 标注者多样性配额 + 金标准抽查 + 分层可靠性；
2. ρ 太小导致 n_eff 不足 → 预算规则强制 ρ·B_ann ≥ n_min，否则不做标注结论；
3. 红队过强导致所有策略「不可区分」→ 预注册 δ_min 与功效分析，允许报 tie；
4. 榜单泄漏/投毒 → 隐藏留出哈希承诺 + Δ_infl 监控 + 提交全入账；
5. 标注成本失控 → VoI 贪心 + AB-Contract 硬预算 + 退化到 ToolGauge；
6. 过度保守导致修复率下降 → 分离原则：数值修复不被 R 阻断，R 只约束「改进」主张；
7. 标签仍可能绕过数值通道 → 定义 436 预注册映射 + EL 无孤儿数字检查（E449/E450）。

## 2. 形式化定义（要点）

**定义 432（AC / 标签回执）** 标签必须带协议、标注者、来源证据、成本与签名；`valid(ℓ)` 需 schema、协议、来源、签名、时效全部通过。无效标签作废且**永不插补**。

**定义 433（LQ-Φ）** 每个标注者有混淆矩阵；分层先验 + 金标准子集校准；输出 `(p̂, σ_label², κ)`。标签方差以 `σ_obs²=σ_tool²+σ_label²` 进入 AP-Cal 的观测模型——标签越不可靠，后验越宽，探测需求越高。

**定义 434（三态与负标注）** 格子状态只能由有效标签/回执显式迁移；缺失 ≠ CLEAR。`NC=|CLEAR|/(|CLEAR|+|BLIND|)`，`η_lab=(|CLEAR|+|BLIND|)/|R|`；`η_lab<η_min` 不得进入「已修复」。

**定义 435（VoI / 随机审计）** `V(ℓ)=ΔRisk−c`，在预算 `B_ann` 下贪心；但至少 `ρB_ann` 个标注必须均匀随机抽取，作为覆盖估计与可靠性估计的无偏锚；其余用重要性权重进入校准。

**定义 436（标签-回执绑定）** 用于校准/契约的标签必须引用有效回执或预注册协议产物；无来源标签在 EC 序列化时剥离。标签到数值先验的映射预注册且可审计，标签不直接写入 `u_fields`/`χ_R`。

**定义 437（选择偏差修正共形）** `C_cal=U∪A`；U 上估分位数，A 上加权 `w=1/e(x)`；`n_eff=(Σw)²/Σw²`；`n_eff<n_min` ⇒ 不给 1−α 保证，退回保守分位或 `H_s={UNKNOWN}`。

**定义 438（LC）** 测试集/指标冻结、隐藏留出哈希承诺、聚合与区间方法、Holm 校正、红队池；有效改进主张 = 预注册 ∧ 未泄漏 ∧ 全部提交入账 ∧ 只用隐藏留出。

**定义 439（排名区间）** 同种子配对差值 → 配对 bootstrap；多策略 Bradley–Terry + bootstrap；只有 `δ_lo>MDE` 且排名区间不重叠才允许说「优于」，否则报 tie/undetermined。

**定义 440（预注册/多重比较）** K 项比较预注册；Holm 控 FWER ≤ α；禁止事后挑指标/子集/种子；冠军必须用 LCB（赢家诅咒）。

**定义 441（隐藏留出/膨胀）** `Δ_infl=s_pub−s_hid`；置信下界 > `τ_infl` ⇒ 判定公开集过拟合/泄漏/投毒，冻结主张；对外只引用影子榜。

**定义 442（R-Arena）** 红队池生成证伪尝试；蓝队稳健分 `G(b)=min_j g_j(b)`；排名用 `min_j LCB(g_j)`；冠军 = 最难被证伪者。红队更新不得看隐藏留出。

**定义 443（排名即假设）** 内部策略选择仅在稳健 LCB 超过默认策略 `δ_min` 时采用；最多 2 个候选；选择入账，防止在噪声上选冠军。

**定义 444（EL / 无孤儿数字）** 只追加哈希链，条目类型 `label/receipt/protocol/holdout/rank/decision/counterfactual`；任何对外数值必须引用正确类型条目，否则剥离；证书 = 可重放 EL 切片。

**定义 445（AB-Contract）** TB-Contract 扩展；预算/可靠性/有效样本/膨胀/选择裕度全部硬约束；不达标标记 UNKNOWN 并退化，绝不插补。

**定义 446（8C）** H→C→E→A→Cal→V→R→U。A 采标签并把 σ_label 并入 Cal；R 只在要产生改进主张时运行；数值热替换只由 V+回归决定，R 失败只剥夺主张（分离原则）。A/R 可 `skipped(reason)`，跳过不得声称对应结论。

**定义 447（继承/退化）** 未重定义的 416–431 全部沿用；`Π_ann=∅,LC=∅ ⇒ ArenaGauge≡ToolGauge`；再退化到 LeanGauge、MODGAUGE。

## 3. 关键算法骨架

```python
# IP-321 A-Box：标签回执 + 三态（⊥ 不是 0）
@dataclass
class LabelReceipt:
    x: Cell | Hyp | Cert
    v: Literal[1, 0, None]
    protocol: str; annotator: str; prov: list[str]
    ts: float; cost: float; sig: str

def accept_label(l, ac):
    return (l.protocol in ac.protocols and verify_sig(l.sig)
            and all(verify_prov(p) for p in l.prov)
            and not expired(l) and l.v is not None)

# IP-322 LQ-Φ：可靠性 + σ_label² 进入观测方差
class LabelQuality:
    def posterior(self, labels, gold):
        theta = fit_reliability_em(labels, gold)       # 分层 Dirichlet
        p, H = aggregate(labels, theta)
        return p, 1 - H / log(self.n_classes), var_from_entropy(H)

# IP-323 V-Act：VoI 贪心 + 强制随机审计
def select_annotations(cands, B_ann, rho, rng):
    U = rng.sample(cands, max(1, int(rho * B_ann)))    # 不看 V，保证无偏锚
    A = greedy_submodular(cands - U, B_ann - len(U), value=voi)
    return U, A

# IP-324 B-Box：配对区间 + Holm + 影子榜
class BBox:
    def claim(self, new_ec, shadow, lc):
        d = [score(new_ec, t) - score(lc.baseline, t) for t in shadow]
        lo, hi = paired_bootstrap(d, 1 - lc.beta)
        return lo > lc.mde and lc.hidden_hash_ok and lc.all_submissions_logged

# IP-325 R-Arena：最坏红队 LCB 排名
def robust_rank(blues, reds, tasks, beta):
    return sorted(blues, key=lambda b: min(
        paired_lcb(survival(b, r, tasks), 1 - beta) for r in reds), reverse=True)

# IP-326 ArenaGauge-8C：A/R 可跳过，但数值修复与主张分离
def arenagauge_8c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                        # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))     # C
    receipts = M.tcv.execute(prog, M.env)                         # E
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")
    U, A = M.vact.select_annotations(M.cands(s, H), M.b_ann, M.rho, M.rng)  # A
    p, kappa, var_lab = M.lq.posterior(M.abox.collect(U + A), M.gold(s))
    if kappa < M.kappa_min or n_eff(U, A) < M.n_min:
        return stub_and_red(s, "label_quality")                   # 不插补
    mu, Sig = M.apcal.calibrate(receipts, H, s, extra_var=var_lab) # Cal
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):   # V
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    claim_ok = (not M.want_improvement_claim(s)) or (
        M.bbox.claim(new_ec, M.shadow, M.lc) and M.arena.survives(new_ec, M.reds))  # R
    M.mreg.hot_replace(M.dpe, new_ec)                             # U：数值修复独立于 R
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_evidence(new_ec, receipts, M.bbox.last_protocol, claim_ok)  # EL
    return True
```

## 4. 推导

**引理 51（带噪标签共形）** `TV(P_{X,ŷ},P_{X,y*})≤ε_lab` ⇒ `P(φ(X,y*)≤q̂) ≥ 1−α−ε_lab`。证明：TV 控制任意阈值下的指示函数期望差，再代入 split-conformal。系：低可靠标签不得用于校准。

**引理 52（标注价值子模）** `ΔRisk(A)` 单调子模（条件熵边际递减）⇒ 贪心 `≥(1−1/e)` 最优；随机审计切分预算后仍保持近似。

**引理 53（选择偏差覆盖）** U 上覆盖无偏，二项区间宽 `O(√(log(1/δ)/m))`；A 上加权共形缺口 `Δ_w=O(√(χ²(P_A‖P_U)/m))`；`n_eff<n_min` 时失效 ⇒ 退化。

**引理 54（排名区间/后悔）** 配对 bootstrap 边际覆盖 →1−β；K(K−1)/2 联合界后同时覆盖；按 LCB + δ_min 选择，后悔 ≤ `δ_min+2·半宽`，半宽<δ_min/2 时 ≤2δ_min。

**引理 55（多重比较/赢家诅咒）** Holm 控 FWER≤α；K 个独立次高斯最大值的期望膨胀 ≤ `σ√(2 ln K)`；冠军必须用 LCB。

**引理 56（红队稳健排名）** `min_j LCB(g_j)` 是 `G(b)` 的有效下界；按此排序的真实 G 后悔 ≤2δ（概率 ≥1−β）；红队越强排名越保守。

**引理 57（等价性/实时）** A-Box/B-Box 只影响 H_s 成员、Cal 方差、改进主张；不改 `u_fields/χ_R`/数值子图；剥离为纯投影；引理 49/50 保持；50Hz 仅多 O(1) EL 追加 <0.2ms。

## 8. 本轮最大风险

**一句话**：A-Box 的主动标注与 B-Box 的公开榜单会形成正反馈——系统越按自己的价值函数选标注、
越按自己的可见指标选策略，证据链就越自洽，而部署分布上的真实误差越不可见；
这是由**证据生产机制本身**制造的、P-Quarantine 无法察觉的系统性偏差，
仅靠随机审计 ρ、隐藏留出与红队三道外部锚兜底（E443/E446/E451 为证伪实验）。

**次级风险与缓解**：
1. 标注者相关偏差 → 多样性配额 + 金标准抽查 + 分层可靠性（E442）；
2. ρ 太小 / `n_eff` 不足 → 预算强制 `ρB_ann≥n_min`，否则不给保证（E443）；
3. 红队过强导致全 tie → 预注册 δ_min 与功效分析，允许报 tie（E445/E451）；
4. 榜单泄漏/投毒 → 隐藏留出哈希承诺 + `Δ_infl` 监控 + 提交全入账（E446/E450）；
5. 标注成本失控 → VoI 贪心 + AB-Contract 硬预算 + 退化（E453）；
6. 过度保守降低修复率 → 数值修复与改进主张分离，R 不阻断热替换（E448/E452）；
7. 标签绕过数值通道 → 预注册映射 + EL 无孤儿数字检查（E449/E450）。
