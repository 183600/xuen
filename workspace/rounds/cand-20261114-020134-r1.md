# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「任务规划」×「数据配比」）

> R69 做了两件漂亮的事：把不确定性一分为二（aleatoric 收紧、epistemic 去问），并让「问」成为一个可通过安全认证、可被审计的动作。但它悄悄把两件事当成了已知量：
> - **问的时机**：MINT 用的是逐时刻贪心 VoI，`argmax_g[VoI(g)−c(g)]`。它知道「该问什么」，却不知道「现在问、还是走到不可逆点前再问」。在一个分叉会重新汇合的任务里，早问是白问；在一个「松手就收不回」的承诺点前，晚问就废了。
> - **问的资格**：模态权重 `ŵ_k` 与校准 `ECE` 都是**训练数据混合比**的下游产物。R69 的 ECE 只证明「我见过的模态权重是准的」，却完全没证明「我有没有见过这个模态」。一个在示范数据里只出现 0.5% 的「左手递物」模态，流策略可能根本没学会；此时系统不是「知道自己不知道」，而是**自信地不知道**。
>
> 本轮两个灵感正好补上这两块缺失：
> - **任务规划**给出时间结构——子目标 DAG、分叉点、**承诺边界（commitment frontier）**。信息动作不再是每步的贪心查询，而是**布置在计划边上的查询点**；VoI 从「此刻模态熵下降」升级为「**计划级遗憾下降**」。提问于是有了一个正确的时间：**在不可逆之前、但在还来得及改变计划之时**（just-in-time asking）。
> - **数据配比**给出模态分布的原因——哪些模态存在、权重多少、校准是否有意义，全由训练混合决定。于是配比成为**一等控制变量**：为安全关键模态设数据质量下界（coverage floor），并把每一次交互当成**双用途样本**——既消解当下歧义，又填补一个数据空洞。
>
> 核心命题：**R69 的两把预算（交互预算、采样预算）其实是同一个资源分配问题的两个投影：控制环花「交互」买「此刻的确定性」，训练环花「数据质量」买「未来的可辨识性」。R70 把它们统一成一个「单位资源边际风险下降」的配给问题（water-filling / KKT），并证明 R69 是「计划只有一步、无承诺边界、数据配比固定且已覆盖」的退化边界。** 命名 **AIDA-RAS**（Allocation of Information, Data, and Action：信息—数据—动作三重配给的资源自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**什么时候问最值、以及我到底有没有资格问**」——不确定性不只是刹车踏板，也不只是一句提问，还是一本**把有限注意力和有限数据花在刀刃上的会计账**。

## 0. 直觉与动机

**灵感 1（任务规划 → 提问有「时机」，不只是「目标」）**
直觉：想象机器人把一杯水递给用户。分叉是「递左手还是右手」。如果两条手臂在任务空间中会重新汇合（用户反正会自己换手），那问「哪只手」几乎没有价值；如果机器人在松手瞬间就不可撤回（water已离开末端执行器），那这一问价值极高。R69 的逐时刻 VoI 对这两种情形给出同一个数——因为它只看「模态熵」，不看「选错之后能不能改」。任务规划补上的正是后者：计划是子目标 DAG，边上有**可逆性权重 ι**，节点上有**承诺边界 τ_c**——过了 τ_c，分支选择就变成不可逆的遗憾。信息动作因此是一个**带发布时间的查询**：同一句问话，放在 τ_c 之前是保险，放在 τ_c 之后是遗言。最优策略不是「有歧义就问」，而是「**在承诺边界前买最后一张可退的票**」。

**灵感 2（数据配比 → 模态分布的「因」，校准的「前提」）**
直觉：R69 的 MCG 用 ECE 判断「模态权重可不可信」。但 ECE 是在**策略见过的模态**上算的。若某安全关键模态在训练混合里只有极小质量，流模型会把它坍缩掉，或者在采样时根本生成不出来；这时 ECE 依旧漂亮，因为分母里根本没有它。**校准（calibration）之前必须先有覆盖（coverage）**。数据配比正是决定覆盖的旋钮：选哪些数据池、各占多少，决定了每个模态的有效样本量与可学习性。把配比当成静态超参，等于把「我有没有资格做 VoI」交给一个没人检查的默认值；把它当成受约束的决策变量——最坏覆盖最大化、安全关键模态设下界、总数据预算受限——才能给 ECE 补上前提。

**灵感 3（交互是双用途的 → 一次提问同时买当下确定性和未来数据）**
直觉：R69 把交互当成纯推理动作，日志只是审计材料。但从学习视角看，每一次「问—答」都产生一个**带标签的歧义样本**：状态 o、问题 g、回答 y、真实模态。这恰好是训练里最稀缺的东西。于是交互有两条收益：`VoI_plan`（当下计划遗憾下降）与 `DV`（数据价值：把某个覆盖不足模态的有效样本量往上推）。把两者相加，就得到一个非常自然的准则：**优先问那些「现在最值钱、而且顺便补上最危险数据空洞」的问题**。这也是本轮最优雅的耦合——控制环的信息采集，天然就是训练环的数据配给。

**灵感 4（两个预算是同一个问题 → 边际价值配给）**
直觉：R69 有交互预算 B_info 与采样预算（K 的升采样）。R70 再加数据预算 B_data。三个旋钮看似不同，其实都在回答同一个问题：**下一单位资源投到哪里，风险下降最多？** 控制环里是「多问一次」；训练环里是「多给某个数据池 1% 的质量」。若把风险写成资源的函数，最优性条件就是 KKT：所有被资助的机会，其**单位成本边际风险下降相等**（water-filling）；未被资助的机会，其边际价值不超过这个公共价格 μ。这给了一个可执行、可解释、可审计的分配器，而不是三个各自拍脑袋的阈值。

**灵感 5（支持度是第三种「我该不该信自己」→ SCoPE）**
直觉：R69 的 FMA 检测「行为是否偏离策略密度」，但还有一种更隐蔽的失败：行为**仍在**策略密度支持内，只是那一片区域在训练混合里几乎没数据。就像一个人对某个话题「有话可说」，但每句都是从两三个例子里过度概括出来的。定义**支持覆盖分** ρ(o)：部署观测相对训练混合的密度比 / kNN 距离 / conformal p 值。ρ 低 ⇒ 覆盖不足 ⇒ 不是简单加噪声，而是**同时**放大 epistemic 不确定性、并对模态权重降信（等价于抬高有效 ECE）。覆盖不足到阈值以下，MCG 直接关门，退回 R68 纯保守。这是比「模型不确定」更前置的一问：**不是「我有多确定」，而是「我凭什么确定」。**

**灵感 6（双刃剑 → 战略歧义、问循环、数据自证）**
直觉：给系统装上「问」和「按数据配比自调」的权力，等于给了它两个新的作弊口。
- **战略歧义（weaponized incompetence）**：如果「报告歧义」能换来人类接管或降低执行责任，策略会学会**假装不确定**，把「我不知道」变成免死金牌。必须有一条纪律：声称的 U_epi 要与事后的分支切换遗憾对账，长期谎报会被审计扣分。
- **问循环（ask-loop）**：在承诺边界前无限期提问、永不承诺，任务永远完不成。必须硬上限 + **承诺强制**（VoI ≤ 成本或预算耗尽时，必须在边界前做决定）。
- **数据自证（self-certifying data）**：系统自己问出来的样本若又拿去训练同一个模态，等于用自己的偏见给自己发证书。安全关键模态必须至少有一个**外部锚点**（人类标签 / 异构传感器 / 另一个策略），且数据池要有溯源与投毒威胁模型。
这三个风险若不先堵住，AIDA 就不是「更聪明的分配」，而是「更聪明的偷懒」。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（AIDA-RAS 总览与四不变式）** AIDA-RAS = (TAP, NIM, MIX, SCoPE, DUE, RAS-WM§)。四不变式：
(i) **热环零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）：MIX 的配比更新只在隔离的训练节奏发生，绝不在控制环内改写数据或权重；
(ii) **资源可行性**：交互次数/时长受 B_info，数据采集/标注受 B_data，任何分配必须同时满足，且不得以「未来数据收益」为由越过当下安全包络；
(iii) **覆盖优先**：安全关键模态的数据覆盖下界未满足时，其模态权重与 VoI 一律不可信，自动降级（定义 317、319）；
(iv) **数据溯源与不自证**：交互样本携带 provenance，安全关键模态不得仅由当前策略在同模态下自生成的标签单独认证（定义 323）。

**定义 311（任务计划与承诺边界）** 任务计划为子目标 DAG `𝒢=(V,E)`，节点 `v` 对应一个 option（子目标策略），边 `e` 携带：
- 不可逆权重 `ι_e ∈ [0,1]`（0 完全可逆，1 越过即不可撤回）；
- 承诺边界 `τ_c(e)`：该边之后「选错分支」的遗憾不再能被后续观测或动作弥补的最后决策时刻；
- 免费观测事件 `𝒪_e`：下游无需主动交互即可获得的观测（如用户自己把手伸出来）。
执行状态是分支后验 `b`。计划可随时重规划，但已越过 `τ_c` 的分支视为**已承诺**。

**定义 312（计划级风险与遗憾）** 对计划 π 与信念 b，
`R(π|b) = E_{b}[Σ_{v} cost(v) + Σ_{e} λ_irr·ι_e·1{wrong(e)}]`；
`Reg(π|b) = R(π|b) − R(π*|b)`，π* 为完全信息下的最优计划。承诺边界之后，`wrong(e)` 的指示不可逆；之前可通过重规划修正。

**定义 313（信息机会与查询布置）** 信息动作 `g`（继承 R69 定义 294 的注视/探针/问句）可被布置在计划节点/边上，形成查询 `q=(g, v, τ)`，τ 为执行时刻。`q` **可采纳**当且仅当：过 C-RAS-WM 前缀认证（定义 302）、满足 B_info、且 τ 位于其目标分支的承诺边界之前。

**定义 314（非短视计划级 VoI）** 给定置于 τ 的查询 q，
`VoI_plan(q) = E_{b}[Reg(π|b)] − E_{b,y~p(·|q)}[Reg(π_q|b_y)] − V_free(q)`；
其中 `b_y` 为回答后的后验，`V_free(q)` 为「即使不问，下游免费观测 𝒪 也会带来的遗憾下降」的期望（避免为即将免费得到的信息付费）。当计划只有一步、无免费观测、无承诺边界时，`VoI_plan` 退化为 R69 的 `H(M|o)−E[H(M|o,y)]`。

**定义 315（即时提问调度 JIT）** 对边 e 上的候选查询，若分支在 `(τ, τ_c)` 之间的动作不能利用该信息（信息无提前适应价值），则最优布置为承诺边界前最后一个可采纳时刻 `τ* = τ_c⁻`；若提前信息可改变 `τ_c` 之前的动作，则提前的**期权价值** `OV(q,τ)` 须补偿提前提问的成本与风险，问当且仅当 `VoI_plan(q@τ*) + OV > c(q)`。

**定义 316（数据配比作为决策变量）** 数据池 `{P_j}_{j=1..J}`（示范、交互样本、恢复/失败模态、异构传感器、仿真等），配比 `w ∈ Δ^{J−1}`。模态 `k` 的有效数据质量 `m_k(w) = Σ_j w_j·n_{jk}`，需求 `m_req,k`，覆盖 `Cov_k(w)=min(1, m_k(w)/m_req,k)`。

**定义 317（模态覆盖证书 MCC）** 最坏覆盖 `γ(w)=min_k Cov_k(w)`。MCC 有效当且仅当 `γ(w) ≥ γ_min` 且安全关键集 `K_safe` 满足 `Cov_k(w) ≥ γ_safe`（逐模态下界）。**关键判据**：`Cov_k(w) < 1` 的模态，其权重与 VoI 不可认证（未覆盖的模态只能被幻觉，不能被校准）。

**定义 318（交互的数据价值 DUE）** 一次交互样本 x 的数据价值
`DV(x) = Σ_{k∈K_safe} ω_k·[γ_k(w ⊕ x) − γ_k(w)]_+`，
即它对最坏安全覆盖的边际提升（ω_k 为安全权重）。交互的总效用
`U(q) = VoI_plan(q) + β·DV(q) − c(q)`，
β 为数据与交互成本之间的兑换率（由定义 320 的配给最优性内生确定，而非手调）。

**定义 319（支持覆盖分 SCoPE）** 支持覆盖分 `ρ(o) ∈ [0,1]`，可取部署/训练混合密度比、kNN 距离映射或 conformal p 值。据此做**覆盖感知重加权**：
`U_epi' = U_epi·(1 + κ·[1−ρ(o)]_+)`，且 `trust(o) = (ρ(o) ≥ ρ_min) ∧ (ECE ≤ τ_ece)`。`trust=false ⇒ MCG 关门`，禁用 VoI 决策、退回 R68 纯保守。

**定义 320（统一边际配给 AIDA-Alloc）** 设风险泛函 `ℛ(r)` 对资源向量 `r`（交互机会与数据池质量）单调不增。最优分配满足一阶条件：存在公共价格 μ，使所有被资助机会 i 满足 `|∂ℛ/∂r_i| / cost_i = μ`，未被资助者 `≤ μ`。信息增益的次模性保证贪心分配达到 `(1−1/e)` 近似（在基数预算下）。

**定义 321（配比控制器 MIX）** 在训练节奏求解受约束问题
`min_{w∈Δ} max_{P∈𝒫_DRO} R_train(w; P) + λ_mix·Reg_mix(w)`
s.t. 单纯形、`MCC` 下界、`data_budget(w) ≤ B_data`。
采用分布鲁棒（DRO）以抵御数据池偏移；新配比先在**影子评估**通过后才进入下一训练周期（热环零写）。

**定义 322（反问循环与反战略歧义）** 每任务硬上限 `N_ask`；**承诺强制**：当 `VoI_plan(q)+βDV(q) ≤ c(q)`、预算耗尽、或到达 `τ_c` 时，必须提交一个分支（不得以「再问一次」无限推迟）。**歧义对账**：审计器比较声称的 `U_epi` 与实际发生的分支切换遗憾；长期「声称高歧义但从未因此改变决策」的策略被扣减交互额度。

**定义 323（数据溯源与不自证）** 每个样本带 provenance `(来源, 时间, 生成策略版本, 认证状态)`。规则：用于认证/校准模态 k 的样本，不得**全部**来自当前策略在同一模态下自生成的标签；`K_safe` 模态至少需一个外部锚点（人类 / 异构传感器 / 异构策略）。投毒干扰集 `ℰ_mix` 并入 AIC：坏池污染、伪标签自举、按配比操纵的定向投毒。

**定义 324（证书 J_AIDA）** `J_AIDA = (J_FLUID, plan_cert, MCC, scpe_p95, alloc_gap, provenance_hash, ask_count, aida_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ MCC 有效 ∧ 数据不自证 ∧ 反问循环未越界 ∧ 分配可行`。当 `J_FLUID` 在真实数据配比下不再成立（覆盖不足或偏移）时，J_AIDA 拒绝为它背书。

## 2. 关键算法骨架

```python
# IP-264 TAP：子目标 DAG + 不可逆权重 + 承诺边界
class TaskPlanner:
    def plan(self, o, z):
        dag = self.subgoal_head(z)                  # 选项/子目标 DAG
        for e in dag.edges:
            e.iota      = self.irrev_head(z, e)     # 不可逆权重 ι_e
            e.tau_commit = last_decision_before(e)  # 承诺边界 τ_c
            e.free_obs   = self.free_obs_head(z, e) # 下游免费观测
        return dag
    def expected_regret(self, dag, b):
        return self.value(dag, b, full_info=False) - self.value(dag, b, full_info=True)

# IP-265 NIM：计划级非短视 VoI + 即时提问
def plan_voi(planner, dag, b, q):
    r0   = planner.expected_regret(dag, b)
    r1   = sum(py * planner.expected_regret(dag, planner.update(b, y))
               for y, py in planner.observe(q))
    free = planner.free_observation_value(dag, b, exclude=q)
    return (r0 - r1) - free                         # 扣掉「反正会免费知道」的部分

def choose_query(planner, dag, b, budget, mixref):
    best = None
    for v in planner.commitment_nodes(dag, b):      # 只在承诺边界前候选
        for q in planner.admissible_queries(v, budget):
            u = plan_voi(planner, dag, b, q) + BETA * due_value(q, mixref) - cost(q)
            if best is None or u > best.u:
                best = (q, u)
    return best if best and best.u > 0 else None    # 无利可图 -> 承诺/走 R69

# IP-266 MIX：数据配比（离线、隔离、影子评估）
def update_mixture(pools, floors, budget):
    w = solve_dro(
        objective   = worst_case_risk(pools, w) + LAM_MIX * mixture_regret(pools, w),
        constraints = [simplex(w),
                       coverage_floor(pools, w) >= FLOOR_SAFE,   # 定义 317
                       data_budget(pools, w) <= budget])         # 定义 321
    shadow_eval(w)                                  # 不通过则不进入训练
    return w

# IP-267 SCoPE：支持覆盖分 + 覆盖感知门控
def support_score(o, mixref):
    return sigmoid(density_ratio(o, mixref))        # 低覆盖 -> 低分

def gate_uncertainty(U_epi, rho, ece):
    U_epi_s = U_epi * (1.0 + KAPPA * max(0.0, 1.0 - rho))
    trust   = (rho >= RHO_MIN) and (ece <= TAU_ECE)
    return U_epi_s, trust                           # trust=False -> MCG 关门

# IP-269 AIDA-Alloc：统一边际配给（water-filling，次模贪心）
def allocate(opportunities, pools, B_info, B_data):
    mu = bisect(lambda m: total_cost(m, opportunities, pools) - (B_info + B_data))
    funded = [x for x in opportunities + pools
              if marginal_value(x) / cost(x) >= mu]  # 单位成本边际价值相等
    return funded, mu

# IP-274 主闭环（继承 R69，插入计划层、覆盖层、双用途层）
def AIDA_RAS_task(M, o):
    dag, b = M.tap.plan(o), M.belief
    while not M.executor.done(dag, b):
        z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
        U_ale, U_epi, modes = M.fluid.decompose(...)          # R69 分解
        rho   = M.scope.score(o, M.mixref)                     # R70 覆盖分
        U_epi, trust = M.scope.gate(U_epi, rho, M.mcg.ece())   # 覆盖感知门控
        q = None
        if trust and U_epi > TAU_EPI and not M.fma.slow():
            q = M.nim.choose_query(dag, b, M.budget, M.mixref)
            if q is not None:
                y = M.cia.execute(q); b = M.cia.update(b, y)
                M.duel.record(q, y, provenance=...)            # 双用途 -> 隔离数据池
        a = M.executor.commit_or_act(dag, b, modes, M.guard)   # 承诺强制
        lam = M.fluid.two_level_scale(U_ale, U_epi if q is None else 0.0)
        k   = M.c_ras_wm.certified_prefix(a, ..., wm_preds)
        M.vqa_a.submit_async(dag, q, rho, U_epi, M.budget)     # 审计（含歧义对账）
        yield k, lam
    M.mix.update_at_training_cadence()                        # 热环外、隔离
```

## 3. 推导

**引理 19（即时提问的占优条件）** 设边 e 上的查询成本随时间单调不减，且 `(τ, τ_c)` 区间内没有动作能利用该信息（无提前适应价值）。则把查询从任意 τ 移到 `τ* = τ_c⁻` 弱占优：期望遗憾不变，而提问成本与暴露风险不增。若存在提前适应价值 `OV(q,τ)`，则最优时机由 `max_τ [VoI_plan(q@τ) + OV(q,τ) − c(q,τ)]` 给出；JIT 是 `OV≡0` 的特例。系：**「早问」只有在能改变承诺前的动作时才值得，否则就是为闲置保险付保费**。

**引理 20（短视 VoI 可系统性错号）** 存在两类计划使 R69 的即时 VoI 与计划级 VoI 符号相反：
(a) **重新汇合分叉**：两分支在 `τ_c` 后汇合，选错不产生终局差异 ⇒ 即时模态熵下降 >0，但 `VoI_plan≈0`；此时 R69 会白问。
(b) **下游免费观测**：`τ_c` 之前必有一次无需主动交互的揭示（用户自己伸手）⇒ 即时 VoI>0，而扣除 `V_free` 后 `VoI_plan≤0`；此时 R69 会提前付费买即将免费的答案。
故即时 VoI 既不是计划 VoI 的上界也不是下界；E301/E302 直接检验该错号率。

**引理 21（覆盖对校准的下界）** 设模态 k 的真实部署质量 `p_k>0`，训练配比给出的有效覆盖 `Cov_k(w)=c_k<1`。则任何仅由已覆盖样本估计的模态权重，在模态 k 上的最坏情况误差至少为 `(1−c_k)·p_k`；若 `c_k=0`，误差下界为 `p_k`（预测权重必为 0）。故 **ECE 无法为未覆盖模态背书**，MCC 下界（定义 317）是 MCG 可用的必要前提。系：低覆盖模态的 VoI 必须先打折或直接视为不可用，而不是照常代入。

**引理 22（双用途的边界与自证陷阱）** 交互样本对覆盖的边际提升 `DV ≥ 0` 仅当其 provenance 独立于被认证模态；若样本全部由当前策略在同模态自生成，则有效独立样本增量 `Δn_eff = 0`，`DV ≤ 0`（自证只增加参数自信、不增加信息）。故定义 323 的外部锚点条件不是保守癖好，而是 `DV>0` 的充分必要条件之一。

**定理 18（配给最优性与贪心近似）** 在风险泛函对资源凸、且各机会的边际信息增益次模的假设下，AIDA-Alloc 的 KKT 条件（定义 320）刻画全局最优；基数预算下贪心分配达到 `(1−1/e)` 近似。系：**控制环的「多问一次」与训练环的「多给一个数据池」应在同一价格 μ 下比较**，任何把两者预算割裂、各自设阈值的做法至多只能达到局部最优。

**定理 19（AIDA 严格包含 FLUID）** 当计划为单步（无承诺边界、`ι≡0`）、无免费观测、且数据配比固定并满足 MCC 时：`VoI_plan ≡ VoI_FLUID`，`trust≡true`，配给退化为 R69 的交互/采样预算。故 R69 是 AIDA 在「无计划结构、无覆盖问题」边界上的逐指令退化；当覆盖不足或支持分低时，AIDA 主动关门退回 R68，安全侧永不弱于 R69。

**定理 20（反问循环有界且不延迟安全承诺）** 在硬上限 `N_ask`、承诺强制与安全动作优先的约束下，每任务交互次数 ≤ `min(N_ask, |V_decision|)`，且安全关键分支在 `τ_c` 处必被提交（`VoI ≤ c` 或预算耗尽即提交）。因此：不存在无限推迟，也不存在「用提问替代制动」；策略声称的歧义若长期不改变决策，按定义 322 被审计扣减额度。

```python
# IP-264 TAP：子目标 DAG、不可逆权重、承诺边界、免费观测
class TaskPlanner:
    def plan(self, o, z):
        dag = self.subgoal_head(z)
        for e in dag.edges:
            e.iota       = self.irrev_head(z, e)
            e.tau_commit = last_decision_before(e)
            e.free_obs   = self.free_obs_head(z, e)
        return dag
    def expected_regret(self, dag, b):
        return self.value(dag, b, full_info=False) - self.value(dag, b, full_info=True)

# IP-265 NIM：计划级 VoI + 即时提问（JIT）
def plan_voi(planner, dag, b, q):
    r0   = planner.expected_regret(dag, b)
    r1   = sum(py * planner.expected_regret(dag, planner.update(b, y))
               for y, py in planner.observe(q))
    return (r0 - r1) - planner.free_observation_value(dag, b, exclude=q)

def choose_query(planner, dag, b, budget, mixref):
    best = None
    for v in planner.commitment_nodes(dag, b):
        for q in planner.admissible_queries(v, budget):
            u = plan_voi(planner, dag, b, q) + BETA * due_value(q, mixref) - cost(q)
            if best is None or u > best.u: best = (q, u)
    return best if best and best.u > 0 else None       # 无利可图 -> 承诺/走 R69

# IP-266 MIX：受约束数据配比（DRO，离线隔离）
def update_mixture(pools, floors, budget):
    w = solve_dro(
        objective   = worst_case_risk(pools, w) + LAM_MIX * mixture_regret(pools, w),
        constraints = [simplex(w), coverage_floor(pools, w) >= FLOOR_SAFE,
                       data_budget(pools, w) <= budget])
    if shadow_eval(w): return w                        # 不通过则不进入训练
    return current_mixture

# IP-267 SCoPE：支持覆盖分与覆盖感知门控
def support_score(o, mixref):
    return sigmoid(density_ratio(o, mixref))

def gate_uncertainty(U_epi, rho, ece):
    return (U_epi * (1.0 + KAPPA * max(0.0, 1.0 - rho)),
            (rho >= RHO_MIN) and (ece <= TAU_ECE))     # trust=False -> R68

# IP-269 AIDA-Alloc：统一边际配给（water-filling / 次模贪心）
def allocate(opportunities, pools, B_info, B_data):
    mu = bisect(lambda m: total_cost(m, opportunities, pools) - (B_info + B_data))
    return [x for x in opportunities + pools
            if marginal_value(x) / cost(x) >= mu], mu

# IP-274 主闭环（继承 R69）
def AIDA_RAS_task(M, o):
    dag, b = M.tap.plan(o), M.belief
    while not M.executor.done(dag, b):
        z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
        U_ale, U_epi, modes = M.fluid.decompose(...)
        rho   = M.scope.score(o, M.mixref)
        U_epi, trust = M.scope.gate(U_epi, rho, M.mcg.ece())
        q = None
        if trust and U_epi > TAU_EPI and not M.fma.slow():
            q = M.nim.choose_query(dag, b, M.budget, M.mixref)
            if q is not None:
                y = M.cia.execute(q); b = M.cia.update(b, y)
                M.duel.record(q, y, provenance=M.prov.tag(q))
        a   = M.executor.commit_or_act(dag, b, modes, M.guard)   # 承诺强制
        lam = M.fluid.two_level_scale(U_ale, U_epi if q is None else 0.0)
        k   = M.c_ras_wm.certified_prefix(a, ..., wm_preds)
        M.vqa_a.submit_async(dag, q, rho, U_epi, M.budget)
        yield k, lam
    M.mix.update_at_training_cadence()                  # 热环外、隔离
```

## 4. 推导

**引理 19（即时提问占优条件）** 查询成本随时间单调不减、且 `(τ,τ_c)` 内无提前适应价值时，把查询移到 `τ_c⁻` 弱占优（遗憾不变、成本与暴露不增）；存在提前适应价值 `OV` 时由 `max_τ[VoI_plan+OV−c]` 定时机。系：「早问」只有在能改变承诺前动作时才值得。

**引理 20（短视 VoI 可系统性错号）** 重新汇合分叉使即时 VoI>0 而 `VoI_plan≈0`（白问）；下游免费观测使即时 VoI>0 而扣除 `V_free` 后 `VoI_plan≤0`（提前付费买免费答案）。故即时 VoI 既非上界也非下界。

**引理 21（覆盖是校准的前提）** 覆盖 `Cov_k=c_k<1` 时，模态 k 权重的任何已覆盖样本估计，最坏误差至少 `(1−c_k)p_k`；`c_k=0` 时下界为 `p_k`。故 ECE 不能为未覆盖模态背书，MCC 下界是 MCG 可用的必要前提。

**引理 22（双用途的边界）** `DV≥0` 仅当样本 provenance 独立于被认证模态；同模态自生成样本的有效独立增量 `Δn_eff=0`，`DV≤0`。故「外部锚点」是 `DV>0` 的条件之一，而非保守癖好。

**定理 18（配给最优性）** 风险对资源凸、边际信息增益次模时，AIDA-Alloc 的 KKT 条件（各被资助机会单位成本边际价值相等）刻画最优；基数预算下贪心达 `(1−1/e)`。系：交互预算与数据预算必须放在同一价格 μ 下比较，分预算各自设阈值至多局部最优。

**定理 19（AIDA 严格包含 FLUID）** 单步计划（`ι≡0`）、无免费观测、配比固定且满足 MCC 时，`VoI_plan≡VoI_FLUID`、`trust≡true`、配给退化为 R69 预算 ⇒ 逐指令相同；覆盖不足/低支持时 AIDA 主动关门退回 R68，安全侧永不弱于 R69。

**定理 20（反问循环有界且不延迟安全承诺）** 硬上限 + 承诺强制 + 安全动作优先下，交互次数 ≤ `min(N_ask,|V_decision|)`，安全关键分支在 `τ_c` 必被提交；不存在无限推迟，也不存在「用提问替代制动」；长期谎报歧义被审计扣减额度。

## 7. 本轮最大风险

**一句话**：AIDA-RAS 的全部收益押在「计划结构与数据覆盖这两个自报量可信」这一前提上——**若承诺边界判错（该问时已越过不可逆点）、或覆盖被自证/投毒数据刷高（没见过的模态被记为已覆盖），系统就会用最经济的分配方式做出最昂贵且不可逆的错误**——它不再是「问错」，而是「在错误的时机、凭虚假的资格，自信地不问或不该问」。

**次级风险与缓解**：承诺边界/不可逆权重误判（E303 + 用 FMA 行为似然做旁证，边界不确定时保守取更早 `τ_c`）；覆盖被自证数据刷高（定义 323 外部锚点 + 引理 22 + ℰ_mix 投毒训练）；反问循环/战略歧义（定义 322 硬上限 + 承诺强制 + 歧义对账 + E309/E310）；配比偏移导致训练不稳（DRO + 影子评估 + 热环零写）；计划级 VoI 计算超预算（解析遗憾回放 + DAG 缓存 + 仅在 `U_epi>τ` 时触发）。
