# 第 41 轮 · 双灵感落地 v1：桌面对象级 SLAM 活证书 × 证书搬运 × 步分感知主动建图（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「UniBot-V1、同步定位与建图」驱动的是一次**赛道事实校正**，而不是继续加层：v17 把几何证书押在 LiDAR-LIO 上，但 UniBot-V1 是定基座桌面操作，官方观测只有 4 路 RGB + 本体状态 + episode 级语言，没有 LiDAR/深度/障碍通道；排行榜又按「平均成功率 + 步骤分」综合排序。于是「SLAM」在本赛道最诚实的翻译不是移动建图，而是**桌面对象级度量语义 SLAM**：机器人已由定基座 + 正运动学定位，真正未知的是物体位姿、身份与遮挡关系；证书必须锚定在对象相对坐标上，并随抓放与回环被「搬运」，而不是被重建。本轮把 v17 的「可认证」从「空间上成立」推进到「对象上成立、步数上划算」。

## 0. 赛道事实校正（先事实后推理；检索口径 2026-11-10）

- **事实 U1（UniBot-V1 评分与形态，unibot.unitree.com 2026-11-10）**：32 项真实桌面操作任务（抓取/放置/双手协调），单模型多任务，真机评测，按「平均成功率 + 步骤分」综合排序；提交接口为 PolicyService（metadata / get_action / reset），动作按 chunk 返回。
- **事实 U2（可用观测，沿用 F40/K2 复核）**：官方 obs 仅含 4 路 RGB（cam_{left,right}_{high,wrist}）、双臂关节[7]、双 ee 位姿[6]、双夹爪[1]、lower_body[15] 与 episode 级 language；无 lidar/depth/obstacle/collision 通道，基座固定。
- **事实 U3（资产与几何，沿用 F42/A17）**：官方未公开 URDF/MJCF 与任务物体 mesh；FK 可由 (arms, ee_pose) 配对回归，物体几何只能用原语代理 + 示教统计。
- **校正结论**：v17 的 LiDAR 漂移球 B_t 与点云 ESDF 在本赛道**不可得**（遵守规则 27/31：不以不存在的通道进入、不造幽灵需求）；但其「证书需要几何锚点」的判断仍正确——锚点应从 LiDAR 迁移到 **双目伪深度（IP-31）+ FK + 示教先验 + 对象级数据关联**。

## 1. 直觉与动机

**直觉 1（定基座把 SLAM 的「定位」消掉，把「建图/数据关联」放大）**：固定基座 + 关节编码器 + 手眼标定意味着机器人位姿几乎已知，移动 SLAM 的全局漂移问题在这条赛道基本不存在；但桌面物体小、纹理弱、频繁被机械臂遮挡，且机器人自己会把物体拿起来再放下——于是真正的状态估计问题是**对象级 SLAM**：维护一组物体的位姿、身份与关系，并在抓取/放置/遮挡后保持一致。v17 的 LiDAR 锚定是把「移动巡检」的解法误搬到了「桌面操作」；本轮做的是同一数学对象的**正确降维**。

**直觉 2（SLAM 的三个真问题正好对应桌面操作的三个失败源）**：(a) **数据关联**——相似物体/遮挡下的重识别就是「回环」，错关联会把 A 的证书贴到 B 上，是灾难性错误；(b) **位姿图一致性**——抓取是已知刚体变换约束，放置是新的位姿观测，回环（再次看到同一物体）应修正累计放置漂移，而不是各帧独立估计；(c) **主动建图**——抓取前用腕部相机「看一眼」以消除位姿歧义，但每一步都计入步骤分，所以看与不看是一个**带成本的决策**。把三者合起来，SLAM 就从「建环境地图」变成「维护一个可被证书消费的对象信念」。

**直觉 3（UniBot-V1 的评分把证书从「安全」推向「划算」）**：排行榜是「成功率 + 步骤分」的综合，v17 的证书只回答「会不会违约」，不回答「要花多少步」。一个安全但反复重定位、反复试抓的策略会赢成功率却输步骤分。因此本轮定义**步分感知证书**：技能 a 的证书是 (p_a, s_a)——成功概率下界与完成步数上界；只有同时满足 p_a ≥ p_min 与 s_a ≤ S_budget 才准入。主动建图的花费因此有了统一口径：**用 Δs 步换 ΔD 的证书赤字下降，只有边际收益为正才看**。

**三线耦合**：对象级 SLAM 提供「对象上成立」的信念，证书搬运提供「抓放/回环后仍成立」的维护机制，步分感知主动建图提供「以最少步数让证书成立」的决策——三者把 v17 的几何证书从「一张静态地图上的断言」改造成「随对象世界线移动、按步骤计费的活证书」。

## 2. 形式化定义

**定义 27（桌面对象 SLAM 状态）**：对象 o 的状态 X_o = (T_o, c_o, id_o, e_o)，T_o ∈ SE(3) 为对象在基座/相机坐标系中的位姿，c_o 为类别/形状，id_o 为身份，e_o ∈ {0,1} 为存在性。地图 M_t = {X_o}_{o∈O}。机器人位姿由定基座与 FK 给出（几乎无漂移），手眼外参由标定给出。观测 z_t = h(M_t; 4×RGB, FK, gripper)（无深度，用 IP-31 双目伪深度与物体先验补尺度）。运动模型分两类：未被操作时 T_o 静止（但可能被另一条臂推动，需成对臂-物交互约束）；被抓取时 T_o' = T_ee · T_grasp（已知变换，含滑移噪声）；放置后重新作为观测约束入图。**回环** = 物体在遮挡/操作后再次被观测，产生相对位姿约束并触发位姿图优化。

**定义 28（身份条件化度量语义类型 C_ms^id）**：C_ms = (φ_sem, B, Id)。φ_sem 为对象几何/关系谓词，B 为位姿不确定球，Id 为身份的信念（分布或可容许身份集合）。蕴含：C_ms ⊢ C_ms' ⟺ φ_sem ⊨ φ_sem' ∧ B ⊆ B' ∧ supp(Id) ⊆ supp(Id')。技能契约与 CertBundle 均改为身份条件化：**cert(h|o) 仅在 P(id_o = target) ≥ 1−δ_id 时有效**，否则只能以身份集合上的保守证书形式存在。

**定义 29（证书搬运 CertTransport）**：证书锚定在对象帧。被抓取搬运时，按已知 T_ee·T_grasp 推送：B' = (T_ee·T_grasp)_* B ⊕ Σ_slip，φ' = (·)_*φ；位姿图回环给出更新 ΔT 时，对受影响对象批量搬运，并重算余量 margin = min_{x∈B'} dist(φ', ∂C)。**失效判据**：若搬运后 margin < 0，或身份后验跌破 1−δ_id，或回环一致性检验（χ²）拒绝，则证书标记 stale，交由 RCA 重颁。**规范不变性**：证书只依赖对象相对坐标，故任何全局地图帧重锚定（含位姿图 gauge 固定方式变化）都不改变证书；只有相对更新能使其失效。

**定义 30（步分感知证书 StepCert）**：对技能 a 与任务 τ，StepCert(a,τ) = (p_a, s_a)，p_a 为在 ValidRegion 与身份条件下成功概率下界，s_a 为完成步数的 (1−δ) 上界（由示教步数分布 + 证书保守膨胀给出）。准入：p_a ≥ p_min ∧ s_a ≤ S_budget(τ)。定义**步分调整裕度** Λ(a) = p_a − λ·max(0, s_a − s*(τ))/s*(τ)（s* 为示教中位步数，λ 为成功率/步分权重），用于同一任务内的技能选择与主动感知决策。

**定义 31（证书赤字与步分感知主动建图 CAB）**：信念 b 下证书赤字 D(b) = E_{x~b}[risk(x)]，risk 为最坏技能违约概率（由 C_ms^id、StepCert 与 B 导出）。可选「看一眼」动作 v（腕部相机重定向/小幅臂动，动作空间内，步数成本 Δs_v），观测 z 后信念 b' = b(·|z)。定义价值 VOI(v) = E_z[max_a Λ(a|b')] − max_a Λ(a|b) − c·Δs_v；选择 v* = argmax_v VOI(v) s.t. s_a + Δs_v ≤ S_budget。**停止规则**：VOI(v*) ≤ 0 或 D(b) 已低于证书阈值即执行。这样主动建图不会为了信息而信息，而是被步骤分预算约束。

**定理 6（搬运可靠性）**：若 B 以概率 ≥ 1−δ 包含真实 T_o，搬运变换误差 ‖T̂−T‖ ≤ η 且 Σ_slip 按 η 膨胀，则搬运后 B' 以概率 ≥ 1−δ−δ_slip 包含新真值；若搬运后 margin ≥ 0，则证书后置条件仍被支持。

**定理 7（规范不变性）**：只依赖对象相对坐标与身份后验的证书，在任意全局帧变换 g ∈ SE(3) 下不变；因此回环引起的 gauge 变化不会使证书失效，只有对象间相对位姿更新会。

**命题 8（主动感知的单步最优性）**：在一步 lookahead 下，v* = argmax VOI 最大化期望 Λ；若 risk 对观测分割满足次模性，则贪心序列相对最优有 1−1/e 近似（条件性结论，需 E76 验证次模性）。

## 3. 三大产出设计

### 3.1 IP-51 TABLE-SLAM（桌面对象级度量语义 SLAM）
1. 输入：4×RGB + 双臂 FK + 夹爪状态 + episode 语言；双目（left/right high）伪深度 + wrist 近景补几何；无深度时用物体先验与示教尺寸做尺度正则。
2. 对象表示：类别 + 原语几何（cuboid/cylinder/sphere）+ 6DoF 位姿 + 身份描述子；对象-关系图（on/in/next_to/held_by）。
3. 因子图：FK 位姿先验、手眼外参、对象观测、抓取刚体约束、放置观测、回环重识别；鲁棒核 + χ² 一致性检验防错回环；回环采用「先在候选集内做身份验证，再入图」的两段式。
4. 操作感知：grasp 前锁定目标身份；持物期间用 T_ee·T_grasp 预测，不重复检测；放置后重新观测并触发局部优化。
5. 输出：M_t 与每个对象的 (T_o, B_o, Id_o)，供 IP-52/53 消费；不确定度大或身份冲突时显式上报「不可认证」。

### 3.2 IP-52 CERT-TRANSPORT（身份条件化证书搬运）
1. 证书改为对象帧锚定，契约 SemanticType 升级为 C_ms^id，CertBundle 增 {B_o, Id 后验, margin, stale}。
2. 抓取/放置/回环后按定义 29 批量搬运；维护证书-对象索引，避免全量重建。
3. stale 检测与重颁：margin < 0 / 身份跌破阈值 / 一致性检验拒绝 → 标记 stale → RCA 重颁 → IP-45 总线热更新。
4. 组合证书：h₁;h₂ 的搬运按对象世界线串联，组合身份条件取交集；冲突时拒绝组合而非静默降级。

### 3.3 IP-53 CAB（证书赤字主动建图）
1. 证书赤字 D(b) 与 VOI 计算（定义 31）；候选动作限制在动作空间内的腕部「看一眼」与小幅重定向。
2. 步分预算：Δs 计入 S_budget，与 IP-48 的流采样步数、IP-50 的课程步数轴统一核算。
3. 触发式感知：只在身份歧义/位姿球过大/遮挡关键面时触发；否则直接执行，避免无谓步骤。
4. 与 IP-50 联动：把「主动感知花费 vs 证书赤字下降」作为课程难度的第七类边际，课程主动生成「需要看一眼」的困难任务。

## 4. 四层架构 v6

```
L1: TRI-FUSE + IP-51 TABLE-SLAM（4×RGB+FK+夹爪+语言 → 对象图 + B_o + Id）
L2: CTC + VLM + IP-35 仲裁 → R_φ(w₁~w₆)
L3: IP-47 任务代数（C_ms^id 类型检查）→ IP-39 规划 → IP-45 总线（对象化证书路由/熔断）
    → IP-53 CAB（步分感知主动建图）→ IP-48 认证流执行 + IP-43 韵律 → RCA（流证书+对象证书）
L4: IP-44 蒸馏 + IP-50 课程（第七类边际=主动感知性价比）→ RCA 重颁 → 契约热更新
运行期：技能总线 + 对象级 RCA + 证书搬运 + 步分预算 + 主动建图 + 自适应流采样
```

（v17 的 LiDAR/ESDF 组件降级为「若将来有深度/雷达通道则即插即用」的可选后端，不在 UniBot-V1 主路径。）

## 5. 实验设计（E73-E79 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 对象位姿校准 | B_o 的经验覆盖率；遮挡下重识别 | ≥98%；≥95% |

| E76 主动建图性价比 | 成功率/步数 vs 被动；VOI 预测增益 | 成功率≥被动；步数−≥15% |
| E77 步分证书准入 | 32 任务代理上成功率与步骤分 vs v17 | 成功率不降；步骤分+≥10% |

## 6. 本轮最大风险

**一句话**：整套设计押在「无深度、无 LiDAR、相似纹理物体」条件下的对象位姿与身份估计精度上——若 B_o 常态过大或重识别频繁出错，证书会被迫过度保守（成功率先掉），主动建图又会为消除歧义烧掉大量步骤（步骤分再掉），桌面对象级 SLAM 就从「活证书」退化为「昂贵的不确定性记录本」。

## 2. 关键算法

### IP-51 TABLE-SLAM（对象级因子图）
```
def table_slam_step(rgb4, q, ee, grip, lang, graph):
    Z = detect_and_pseudo_depth(rgb4, prior=demo_prior, scale=stereo_baseline)
    for det in Z:
        cand = associate(det, graph.objects, desc=appearance+shape+relation)
        if cand.ambiguous:
            graph.mark_ambiguous(cand); continue          # 交给 IP-53
        if is_loop(cand, det):                            # 回环
            if chi2_gate(cand, det) and verify_identity(det):
                graph.add_loop_factor(cand, det)          # 两段式：先验身份再入图
            else:
                graph.reject(det, reason="alias_or_inconsistent")
        else:
            graph.add_object_factor(cand, det)
    for o in graph.grasped_objects:                       # 抓取刚体约束
        graph.add_prior(o.pose == ee * o.T_grasp, cov=Sigma_slip)
    graph.optimize(robust_kernel="huber")
    return graph.objects    # (T_o, B_o, Id_posterior)
```

### IP-52 CERT-TRANSPORT（抓放/回环后的证书搬运）
```
def transport_certs(graph, delta, affected):
    for o in affected:
        T_new = delta @ graph.T[o]                        # 或 T_ee*T_grasp
        for c in cert_index[o]:
            c.B      = pushforward(c.B, T_new) ⊕ Sigma_slip
            c.margin = min_margin(c.phi, c.B)
            if c.margin < 0 or id_below(c, 1-delta_id) or not chi2_ok(o):
                c.stale = True
                RCA.reissue(c.skill, o)
    return Registry.hot_reload_if_any_stale()
```

### IP-53 CAB（证书赤字 + 步分预算的主动建图）
```
def cab_step(b, budget, cost):
    base = max_a Lambda(a, b)
    best_v, best = None, 0.0
    for v in feasible_look_actions(b, budget):            # 动作空间内腕部看一眼
        b2   = predict_belief(b, v)
        gain = E_z[max_a Lambda(a, b2)] - base - cost(v)  # VOI - c*Δs
        if gain > best:
            best_v, best = v, gain
    if best_v is None or best <= 0:
        return execute_greedy(b)                          # 停止规则：不看
    return best_v
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| TABLE-SLAM 关联 | 每帧 O(|O|·d_desc + k·|O|)，|O|≈32 任务物体规模 | 两段式身份验证 + χ² 门控降低错回环 |
| 位姿图优化 | 增量 O(ΔE)（iSAM2 式） | 回环约束一致时全局一致；拒绝不一致约束 |
| 证书搬运 | 每受影响对象 O(|cert_o|)，索引避免全量 | **定理 6**：搬运后球含真值 ≥1−δ−δ_slip |
| 规范不变性 | O(1) | **定理 7**：全局帧变换不改证书，仅相对更新使其失效 |
| StepCert 准入 | O(1)/技能 | p_a/s_a 为保守下/上界，准入即满足预算 |
| CAB | 每决策 O(|V|·|Z|)（候选看一眼动作数×观测假设） | **命题 8**：单步 VOI 最优；次模时贪心 1−1/e |
| 课程 | O(7)/任务；带采样 O(1) | Robbins-Monro 依概率收敛到目标成功率 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 无深度/弱纹理导致 B_o 过大 | 高 | 双目伪深度 + 示教尺寸先验 + 主动看一眼；E73 第一守门 |
| 相似物体错关联（感知别名） | 高 | 身份描述子 + 关系约束 + 两段式回环 + χ² 门控；E75 守门 |
| CAB 烧掉步骤分 | 高 | VOI/step 停止规则 + 预算硬约束 + 仅在歧义时触发；E76 守门 |
| 抓取滑移使搬运证书失效 | 中 | Σ_slip 膨胀 + stale 重颁 + 抓后复检 |
| 身份条件使证书过于保守 | 中 | 身份概率阈值可调 + 身份集合上的保守证书；E79 消融 |
| 课程第七边际与步分目标冲突 | 低 | 双时间尺度 + 权重上限 + 步分预算硬约束 |

## 6. 本轮最大风险

**一句话**：共同命门是「无深度、无 LiDAR、相似纹理」下的对象位姿/身份精度——若 B_o 常态过大或重识别频繁出错，证书会被迫过度保守（成功率先掉），主动建图又会为消除歧义烧掉大量步骤（步骤分再掉），桌面对象级 SLAM 将从「活证书」退化为「昂贵的不确定性记录本」，故 E73/E75 为本轮第一守门实验。
