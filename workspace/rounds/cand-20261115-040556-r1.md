# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据标注」×「腕部相机」）

> R69 给系统装上了「嘴」：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略显式表示歧义，用注视 / 探针 / 问句主动消解，并用「k 个正交证据源一致」防止投毒。但 R69 有两个它自己没意识到的前提：
> （a）**证据源是正交的**——可它的 r_geo、r_sync、r_zero、r_emo、r_wm 大多来自同一批外部相机、同一次标定、同一个预训练模型；所谓「多源一致」，可能只是「同一台相机自说自话五次」。
> （b）**标签是真理**——整套策略、模态校准、ECE、异常检测都建立在训练标注之上；但标注本身也是一种测量，有噪声、有偏置、有来源、有利益。R69 只审计「回答」，从不审计「它自己是怎么被教出来的」。
>
> 本轮两个灵感正好戳中这两点：
> - **腕部相机**给出一条与外部视角**失效模式互补**的近距离证据——外部相机被机械臂挡住时，腕部相机正看着接触点；它不是「又一个摄像头」，而是**来自身体内部的视角**（proprioceptive–exteroceptive bridge）。
> - **数据标注**把「标签」从一个离线准备步骤，变成闭环里**一类可溯源、可反驳、可主动获取的证据**。
>
> 核心命题：**为整条安全链补上缺失的「来源层」（provenance layer）——每一个标签（人标的 / 腕部自标的 / 仿真给的）都带来源与质量分，进入一张标注溯源图；安全证书只在标签溯源质量达标时成立；腕部相机把机器人自身的操作经验变成在线自标注信号，但自标注只允许「提出疑问、上调不确定性」，绝不允许单独「盖章认证」。** 命名 **PALM-RAS**（Provenance-Aware Label Management for wrist-egocentric risk-adaptive safety；PALM 亦指手掌——手的视角）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信我所学到的、以及我用来求证的一切**」——安全链的最后一环，不是传感器，不是策略，而是**证据与标签的来源**。

## 0. 直觉与动机

**灵感 1（腕部相机 → 与外部视角「失效模式互补」，而不是「再多一个传感器」）**
直觉：R69 的证据纪律假设 k 个来源正交，但它的残差大多由同一组外部相机、同一次标定、同一个预训练模型派生。机械臂伸向目标做精细操作时，外部相机恰恰被手臂自身挡住——而这正是最需要判断的时刻；此时腕部相机正对着夹爪与接触点，看得最清楚。反过来，高速运动时腕部相机运动模糊、外部相机却相对稳定。两种视角的**失败时刻几乎错开**。所以腕部相机的价值不在「更高分辨率」，而在于它提供了一条**失效模式与外部视角分离**的证据：它不是「第 k+1 个同源证人」，而是「来自身体内部、在别人失明时看见的证人」。

**灵感 2（数据标注 → 标签是测量，不是真理）**
直觉：R66–R69 把全部信任建立在一个隐式前提上——训练标签是对的。但标签由人、规则、仿真器、甚至 LLM 产生，每一类都有自己的偏置与噪声：标注员疲劳、协议歧义、仿真—现实间隙（sim2real gap）、LLM 幻觉。标签不是「数据自带的地面真值」，而是**一种带来源的测量**，和传感器读数一样有 aleatoric（标注抖动）与 epistemic（协议 / 来源歧义）。既然 R68 已经学会校准传感器、R69 已经学会质疑回答，下一步就必须质疑**教它的一切**：标签的准确度、独立性、新鲜度，以及「我是不是一直在同一个来源上过拟合」。

**灵感 3（标注溯源图 → 安全领域的「标签 SBOM」）**
直觉：软件供应链用 SBOM（物料清单）回答「这个二进制里到底有哪些来源」。安全闭环同样需要一张**标签物料清单**：每个标签来自哪个视角、哪个标注者、哪个模型版本、哪次标定，派生关系如何。图上若存在覆盖关键训练集合的「共同祖先」或「割点」，就说明有**标注单一化（label monoculture）**——十份标注看似独立，实则同源，误差高度相关。R69 的「多源一致」在这种图上会被识别为「其实只有一个源」，从而不再被当作证据。

**灵感 4（腕部自标注 → 机器人给自己出题，但只判「疑」不判「对」）**
直觉：接触起始、滑动、夹持成功、物体相对位姿——这些量在腕部视角下直接可观测，几乎不需要人。于是机器人可以边干边给自己打标签，把「经验」即时变成「训练信号」，绕开昂贵的人工标注。但这恰恰是最危险的地方：自己出题、自己判卷、自己给自己发证书，会形成回声室。所以纪律必须是：**自标注可以提出假设、可以提高不确定性，但永远不能单独降低风险、不能单独通过认证**。

**灵感 5（主动标注 → R69 的 VoI 再上一层：从「问世界」到「教自己」）**
直觉：R69 的 VoI 选的是「此刻问什么」能降低**当前状态**的 epistemic 不确定；R70 选的是「这段经验值不值得标」能降低**模型本身**的不确定。这是两个时间尺度：毫秒级控制环里模型冻结，分钟 / 小时级标注环里才更新。更关键的是，标注也要按安全价值排序——优先标注那些**证书最薄、风险最高、来源最少**的状态，而不是最「有趣」或最「难」的样本。

**灵感 6（对 R69 最大风险的正面回应）**
直觉：R69 自陈「若模态权重未校准，VoI 就在错误信念上计算，系统会自信地追问一个幻影」。模态权重从哪来？从标注来。所以 R70 不是再加一层黑箱，而是**把 R69 的信任前提显式化、可测量化**：标注噪声率 δ、来源相关性 ρ_f、回声分 echo 一旦越界，R69 的 ECE 门与 λ_floor 就提前收紧。换言之，R70 让「问错」的根因——**教错了**——变得可检测。

**灵感 7（自标注是双刃剑 → 回声室与模型坍缩）**
直觉：伪标签自我训练是经典的确认偏差放大器：模型把偶然错误写成标签，再学回去，错误从「偶然」变成「自洽」。若自标注误差与模型误差正相关（确认系数 γ>0），误差会被放大到 1/(1−γ) 倍；γ→1 时发散。这不是理论洁癖，而是部署中最常见的「越跑越偏、却越来越自信」。因此 R70 必须内置回声检测与回滚，并让自标注在**认证路径**上的 γ 恒为 0。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（PALM-RAS 总览与四不变式）** PALM-RAS = (WAL, LPG, LNA, RIB, ALV, PLG, ECH, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）：控制环内 θ 冻结，只有快环读、慢环写；
(ii) **标签溯源完备**：任何进入训练、校准或证书的标签必须能在溯源图上解析出完整来源路径，缺失即质量记 0；
(iii) **自标注不盖章**：腕部自标注只能上调不确定性或提出待核验假设，单独不得降低 λ、不得通过证书；
(iv) **标注预算与来源多样性硬约束**：单位时间标注 / 人机问答 ≤ b_a，关键标签来源多样性 ≥ d_min，且标注动作本身须过 C-RAS-WM 认证。

**定义 311（标签对象与标注溯源图 LPG）** 标签 ℓ = (y, x, t, s, a, v, q)，其中 y 为标签值、x 为样本、t 为时刻、s ∈ {human, wrist_self, sim, llm} 为来源类型、a 为标注者 / 模型 id、v 为视角、q 为质量向量。溯源图 G_L = (V_L, E_L)，V_L 含标签、数据分片、模型、标定版本，E_L 表示派生关系。对任意关键标签集合 S，定义**共源风险** cr(S) = 覆盖 S 的最大单源祖先所占比例；cr(S) 越接近 1，S 越像「一个证人说了很多遍」。

**定义 312（标注质量向量与溯源分）** q(ℓ) = (q_acc, q_cal, q_ind, q_fresh) ∈ [0,1]^4，分别表示准确度、标定一致性、来源独立性、新鲜度。溯源分 π(ℓ) = q_acc·q_cal·q_ind·q_fresh（或取 min，见消融）；有效噪声上界 δ_eff(π) 由定义 316 给出。

**定义 313（腕部自标注算子 WAL）** 给定腕部视频流 w_t 与本体感知 p_t，WAL 输出自标签 ℓ_self = (ĉ_t, ŝ_t, ĝ_t, T̂_t)，分别为接触、滑动、夹持成功、物体相对位姿，并附带置信度与**失效模式标签** fm ∈ {motion_blur, finger_occlusion, specular, low_texture, none}。WAL 的监督来自物理一致性（接触 ⇒ 力信号变化、滑动 ⇒ 位姿残差），而非人工真值。

**定义 314（失效模式正交性）** 两个视角 u、v 的错误事件 E_u、E_v 通常并不独立。定义 **ρ_f-分离**：P(E_u ∧ E_v) ≤ ρ_f·min(P(E_u), P(E_v))，ρ_f ∈ [0,1]。R69 的「正交证据源」应替换为「ρ_f-分离证据源」；腕部—外部视角的 ρ_f 小，是因为单目遮挡与运动模糊在时间上互补。**注意**：ρ_f 小不等于统计独立，更不等于不可被同一物理原因（镜头污染、共同光照）同时击穿——这是 R70 的首要威胁。

**定义 315（跨视角标注一致性与噪声估计 LNA）** 以多视角 / 多来源为多个「标注器」，用带溯源先验的 Dawid–Skene 估计每个来源的混淆矩阵 T_s 与相关性 ρ̂_f，得到全局噪声率 δ̂ 及各类别噪声率 δ̂_c。估计在新标签累积到阈值后离线刷新，不进入快环。

**定义 316（标注噪声下的风险膨胀半径 RIB）** 设噪声转移矩阵为 T，σ_min(T) 为其最小奇异值。证书风险满足 R_true ≤ κ(δ̂)·R_emp + b，其中 κ = 1/σ_min(T)（二分类对称噪声下 κ = 1/(1−2δ̂)）。据此定义标注感知的保守下界 **λ_floor^PALM(U, δ̂) = min(1, κ(δ̂)·λ_floor^FLUID(U))**。**标签越脏，同一个「不确定」就要收得越紧。**

**定义 317（主动标注价值 ALV）** 对候选经验 x：ALV(x) = w_safe(x)·E[ΔH_model | x] − c_annot(x)，其中 w_safe(x) 为证书薄弱度 / 风险权重，c_annot 为人工或计算成本。选择 argmax 且 ALV>0 的批次，受定义 310-iv 预算约束。**只标「最需要被证明」的，不标「最有趣」的。**

**定义 318（溯源门 PLG）** 标签可用于认证当且仅当 π(ℓ) ≥ τ_π、来源多样性 ≥ d_min、且非「仅腕部自标」。不达标的标签只能用于探索 / 上调不确定性，不得进入基于引理 19 的风险论证。

**定义 319（自标注证据纪律）** 自标签 ℓ_self 允许：(a) 作为 CIA 的又一条残差参与跨视角一致性；(b) 提出新的 epistemic 候选；(c) 以带溯源标签的身份进入慢环训练候选。禁止：(d) 单独降低 λ；(e) 单独通过证书；(f) 覆盖人标 / 仿真标签。任何「定案」仍需至少一个非自源一致，或 ALV 增益超阈值且外部视角交叉一致。

**定义 320（标签投毒干扰集 ℰ_label）** 标签翻转、标注者共谋、腕部视角伪造（重放 / 注入假画面）、溯源元数据伪造、回声注入（把模型错误包装成「新标注」）。并入 AIC：ℰ_PALM = ℰ_FLUID × ℰ_label。

**定义 321（证书 J_PALM）** J_PALM = (J_FLUID, provenance_coverage, π_min^crit, δ̂, ρ̂_f, self_label_ratio, echo_score, label_audit_hash, palm_ver)。Valid ⇔ Valid(J_FLUID) ∧ provenance_coverage = 1 ∧ δ̂ ≤ τ_δ ∧ echo_score ≤ τ_echo ∧ 不变式 310-iii。

**定义 322（自我确认 / 回声检测 ECH）** echo_score = corr(模型在自标样本上的误差, 自标相对外部核验的误差)，在滑窗上估计；或等价地取「自训练在留出外部标签上的增益」的负值。echo_score > τ_echo ⇒ 冻结自训练、回滚到上一个外部验证过的检查点，并上调 λ。系：自标注的确认系数 γ 必须被持续估到 <1。

**定义 323（两时间尺度闭环）** 快环 = R69 控制（ms，θ 冻结）；慢环 = 标注 / 筛选 / 训练（min–hr）。慢环产出的 θ′ 只能在**证书有效且 PLG 通过**的检查点换装（继承 R68/R69 换装不变式）。两环通过 LPG 与 AuditBuf 通信，不共享可写学习状态。

**定义 324（对 R69 的严格包含）** 当无腕部相机、无自标注、所有标签均人工核验（π=1、δ̂=0、echo=0）且 ALV 永不触发时，PALM 逐指令退化为 FLUID-RAS；安全侧不做任何让步。

**定义 325（溯源审计 VQAuditor-L）** 审计对象新增：溯源完整性、标注者 / 来源偏置、自标回声、标签投毒、共源风险；结论回灌 AuditBuf，作为 τ_π、d_min、τ_echo 的自适应先验。

# IP-265 LPG：标签溯源图（快环只读、慢环写）
def add_label(G, ell):
    G.add_node(ell, prov=(ell.t, ell.s, ell.a, ell.v))
    for par in ell.parents: G.add_edge(par, ell)
def provenance_score(G, ell):
    return ell.q_acc * ell.q_cal * q_ind(G, ell) * q_fresh(ell)

# IP-266 LNA：带溯源先验的噪声估计（离线）
def estimate_noise(G, labels):
    return dawid_skene_prov(labels)          # -> T_hat, delta_hat, rho_f_hat

# IP-267 RIB：标注噪声下的风险膨胀
def kappa(delta, T=None):
    return 1.0/max(1e-3, 1.0-2.0*delta) if T is None else 1.0/svd(T).min()

# IP-268 ALV：安全加权的主动标注（慢环）
def select_annotation(cands, model, budget):
    scored = [(w_safe(x)*exp_model_gain(x)-cost(x), x)
              for x in cands if budget.allow(x)]
    return [x for v, x in sorted(scored, reverse=True) if v > 0][:budget.batch]

# IP-269 PLG：溯源门（低质标签不得认证）
def allow_certify(G, ell, d_min, tau_pi):
    return (provenance_score(G, ell) >= tau_pi
            and source_diversity(G, ell) >= d_min
            and ell.s != 'wrist_self_only')

# IP-270 ECH：回声 / 确认偏差检测（离线）
def echo_score(model, self_labels, ext_labels):
    return corr(model.error_on(self_labels), self_label_err_vs(ext_labels))

# IP-276 主闭环：快环继承 R69，慢环旁路
def PALM_RAS_round(M, obs):
    k, lam, mode, U = M.fluid.round(obs)              # R69 快环，θ 冻结
    ell = M.wal.label(obs.wrist, obs.p)                # 腕部自标注
    U = M.cia.add_evidence(U, ell, mode='raise_only')  # 只升疑，不降安全
    if not M.plg.allow_certify(M.lpg, ell, M.d_min, M.tau_pi):
        lam = max(lam, M.efs.lam_floor(U))             # 不可认证 ⇒ 不许放松
    M.lpg.add_label(M.lpg, ell)                        # 溯源图增量（无学习写）
    if M.alv.should(M.lpg):                            # 慢环触发，入队不阻塞
        M.annot_queue.push(M.alv.select(M.lpg.candidates(), M.model, M.budget))
    d, rho = M.lna.cached()                            # 慢环缓存，快环只读
    lam = max(lam, M.efs.risk_scale(...), M.efs.lam_floor(U)*M.kappa(d))
    if M.ech.cached() > M.tau_echo:                    # 回声越界
        M.freeze_self_training(); lam = max(lam, 0.8)
    M.vqa_l.submit_async(ell, d, rho, M.ech.cached())
    return k, lam, mode

## 3. 推导

**引理 19（标注噪声 → 证书风险膨胀）** 设训练 / 校准标签由噪声转移矩阵 T 生成，σ_min(T) 为其最小奇异值。在 A99（噪声只依赖标签、与输入条件独立）下，真实风险满足 R_true ≤ R_emp/σ_min(T) + b；二分类对称噪声率 δ 时退化为 R_true ≤ R_emp/(1−2δ) + b。系：**标注越脏，同一个 U 对应的 λ 必须越保守**——这给出定义 316 的 κ，并说明「标签问题」必须在安全侧、而非仅仅在精度侧处理。

**引理 20（失效模式正交性下的联合漏检增益）** 两视角错误事件满足定义 314 的 ρ_f-分离。若各自单独漏检概率为 p_u、p_v，单一视角漏检 min(p_u, p_v)，则两视角联合漏检 ≤ ρ_f·min(p_u, p_v) + O(p_u p_v)。系：**腕部相机对 R69 证据链的增益约为 (1−ρ_f) 倍**；若 ρ_f→1（共同镜头污染、同步光照故障），增益归零——这正是 R70 必须监测共源风险、而不能假设独立的原因。

**引理 21（自标注回声放大）** 设自训练中模型误差 e 与伪标签误差线性相关，确认系数 γ = ∂e_label/∂e_model ∈ [0,1)。则一次自训练迭代后的误差不动点为 e* = e_0/(1−γ)。若 γ ≥ 1 或形成正反馈闭环，误差发散。系：**定义 319 让自标注在认证路径上只走「升疑」分支（等价于 γ_eff = 0），从而把认证链与回声放大隔离**；训练链上的 γ 由 ECH（定义 322）估计并压住。

**定理 18（PALM 严格包含 R69）** 在 A99–A101 下，PALM 在任意状态 s 的期望风险 ≤ FLUID-RAS；且当无腕部相机 / 无自标注 / 标签 π=1 且 ALV≤0 时，两者逐指令相同。R69 是 PALM 在「标签全可信、无自标注」边界上的退化；安全侧不做让步。

**定理 19（自标注保守性）** 若自标注只经定义 319 的「升疑」通道进入快环，则对任意观测，PALM 的 λ 不小于同状态下 FLUID-RAS 的 λ；自标注失败 / 缺失 / 被投毒时，系统单调不降地退化为 R69。故自标注**不可能**因引入新证据而降低安全性。

**定理 20（两时间尺度无突变）** 慢环更新只在证书有效且 PLG 通过的检查点换装（定义 323），快环内 θ 冻结、零学习写操作；换装时刻满足 R68/R69 的提交不变式，且 λ 在换装前后连续（以回溯证书为界）。故控制无突变，标注 / 训练故障不会在轨迹中途改变安全包络。

（A99：标签噪声条件独立；A100：ρ_f-分离且各源混淆矩阵可辨识；A101：慢环换装检查点可证书化。）

## 6. 本轮最大风险

**一句话**：PALM-RAS 把安全证书最终锚定在**标签的来源与质量**上，但溯源图本身是由系统自己（或一个可能疲劳、可能被贿赂、可能被同一物理原因击穿的标注过程）填写的——**若标签被系统性污染（标注者共谋、腕部视角被重放、共同镜头污染让 ρ_f→1），溯源分可以很漂亮而证据其实同源，系统就会用「看起来证据充分」的假象去认证一个被教错的模型**；自标注回声更会把「错」固化成「自洽」，让系统越跑越自信地错——**标错，比不标更危险。**

**次级风险与缓解**：
1. **自标注回声 / 模型坍缩** → 定义 319 只升疑 + ECH 检测 + 检查点回滚（引理 21、定理 19）；
2. **共源失效使 ρ_f→1** → LPG 共源风险 cr(S) 监测 + 来源多样性 d_min 硬约束（定义 311/318、引理 20）；
3. **标签投毒与视角伪造** → ℰ_label 对抗集 + 溯源元数据签名 + E309/E310；
4. **标注预算击穿实时性** → 慢环旁路 + ALV 批处理 + 快环只读缓存（定义 323、复杂度表）；
5. **溯源门过严导致「永不认证」** → τ_π / d_min 由 AuditBuf 自适应，并保留 R69 兜底路径（定理 18）。

**收束一句**：真正的风险不是「没有证据」，而是「证据全是同一个来源的复印件」——**当溯源本身也可被伪造时，越完整的溯源图，越可能是一张精心伪造的证书。**

**定义 317（ALV）** `ALV(x)=w_safe(x)·E[ΔH_model|x]−c_annot(x)`，取 argmax 且 >0 的批次；优先「最需要被证明」的状态。

**定义 318–319（PLG 与证据纪律）** 认证需 `π≥τ_π ∧ 来源多样性≥d_min ∧ 非仅腕部自标`；自标注可升疑 / 提假设 / 入慢环候选，禁止单独降 λ、单独过证书、覆盖人标 / 仿真标。

**定义 320–321（干扰集与证书）** `ℰ_PALM=ℰ_FLUID×ℰ_label`（翻转 / 共谋 / 视角伪造 / 溯源伪造 / 回声注入）；`J_PALM` 增溯源覆盖、π_min、δ̂、ρ̂_f、自标比例、回声分。

**定义 322（ECH）** 回声分 = 模型自标误差与相对外部核验误差的相关；越界即冻结自训练、回滚、上调 λ；等价要求确认系数 γ<1。

# IP-264 WAL：腕部视角自标注（带失效模式标签）
class WristAnnotator:

        c = contact_head(w_t); s = slip_head(w_t); g = grasp_head(w_t)
        return SelfLabel(c, s, g, fm=failure_mode(w_t), conf=...)

# IP-265 LPG：标签溯源图（快环只读、慢环写）
def add_label(G, ell):
    G.add_node(ell, prov=(ell.t, ell.s, ell.a, ell.v))
    for par in ell.parents: G.add_edge(par, ell)
def provenance_score(G, ell):
    return ell.q_acc * ell.q_cal * q_ind(G, ell) * q_fresh(ell)

# IP-266 LNA：带溯源先验的噪声估计（离线）
def estimate_noise(G, labels):
    return dawid_skene_prov(labels)              # -> T_hat, delta_hat, rho_f_hat

# IP-267 RIB：标注噪声下的风险膨胀
def kappa(delta, T=None):
    return 1.0/max(1e-3, 1.0-2.0*delta) if T is None else 1.0/svd(T).min()

# IP-268 ALV：安全加权的主动标注（慢环）
def select_annotation(cands, model, budget):
    scored = [(w_safe(x)*exp_model_gain(x)-cost(x), x)
              for x in cands if budget.allow(x)]
    return [x for v, x in sorted(scored, reverse=True) if v > 0][:budget.batch]

# IP-269 PLG：溯源门（低质标签不得认证）
def allow_certify(G, ell, d_min, tau_pi):
    return (provenance_score(G, ell) >= tau_pi
            and source_diversity(G, ell) >= d_min
            and ell.s != 'wrist_self_only')

# IP-270 ECH：回声 / 确认偏差检测（离线）
def echo_score(model, self_labels, ext_labels):
    return corr(model.error_on(self_labels), self_label_err_vs(ext_labels))

# IP-276 主闭环：快环继承 R69，慢环旁路
def PALM_RAS_round(M, obs):
    k, lam, mode, U = M.fluid.round(obs)              # R69 快环，θ 冻结
    ell = M.wal.label(obs.wrist, obs.p)                # 腕部自标注
    U = M.cia.add_evidence(U, ell, mode='raise_only')  # 只升疑，不降安全
    if not M.plg.allow_certify(M.lpg, ell, M.d_min, M.tau_pi):
        lam = max(lam, M.efs.lam_floor(U))             # 不可认证 ⇒ 不许放松
    M.lpg.add_label(M.lpg, ell)                        # 溯源图增量（无学习写）
    if M.alv.should(M.lpg):                            # 慢环触发，入队不阻塞
        M.annot_queue.push(M.alv.select(M.lpg.candidates(), M.model, M.budget))
    d, rho = M.lna.cached()                            # 慢环缓存，快环只读
    lam = max(lam, M.efs.risk_scale(...), M.efs.lam_floor(U)*M.kappa(d))
    if M.ech.cached() > M.tau_echo:                    # 回声越界
        M.freeze_self_training(); lam = max(lam, 0.8)
    M.vqa_l.submit_async(ell, d, rho, M.ech.cached())
    return k, lam, mode

## 4. 推导

**引理 19（标注噪声 → 证书风险膨胀）** 噪声转移矩阵 T、`σ_min(T)` 最小奇异值，A99（噪声条件独立）下 `R_true ≤ R_emp/σ_min(T)+b`；对称二分类率 δ 时 `R_true ≤ R_emp/(1−2δ)+b`。系：标注越脏，同一个 U 对应的 λ 必须越保守——标签问题必须在安全侧处理。

**引理 20（失效模式正交性下的联合漏检增益）** ρ_f-分离下，两视角联合漏检 ≤ `ρ_f·min(p_u,p_v)+O(p_u p_v)`。系：腕部对 R69 证据链增益约 `(1−ρ_f)`；若共同污染使 ρ_f→1，增益归零——故必须监测共源风险，不能假设独立。

**引理 21（自标注回声放大）** 模型误差 e 与伪标签误差线性相关、确认系数 γ∈[0,1)，一次自训练后误差不动点 `e*=e_0/(1−γ)`；γ≥1 发散。系：定义 319 让认证链取 γ_eff=0，把认证与回声放大隔离；训练链的 γ 由 ECH 压住。

**定理 18（PALM 严格包含 R69）** A99–A101 下，任意状态期望风险 ≤ FLUID-RAS；无腕部 / 无自标注 / π=1 且 ALV≤0 时逐指令相同。R69 是「标签全可信、无自标注」边界上的退化，安全不让步。

**定理 19（自标注保守性）** 自标注只经「升疑」通道进入快环时，任意观测下 PALM 的 λ ≥ 同状态 FLUID-RAS 的 λ；自标注失败 / 缺失 / 被投毒时单调不降地退化为 R69。故自标注不可能因引入新证据而降低安全性。

**定理 20（两时间尺度无突变）** 慢环更新只在证书有效且 PLG 通过的检查点换装；快环 θ 冻结、零学习写；换装满足 R68/R69 提交不变式且 λ 连续。故控制无突变，标注 / 训练故障不在轨迹中途改变安全包络。

（A99：标签噪声条件独立；A100：ρ_f-分离且各源混淆矩阵可辨识；A101：慢环换装检查点可证书化。）

## 7. 本轮最大风险

**一句话**：PALM-RAS 把安全证书最终锚定在**标签的来源与质量**上，但溯源图本身是由系统自己（或一个可能疲劳、可能被贿赂、可能被同一物理原因击穿的标注过程）填写的——**若标签被系统性污染（标注者共谋、腕部视角被重放、共同镜头污染让 ρ_f→1），溯源分可以很漂亮而证据其实同源，系统就会用「看起来证据充分」的假象去认证一个被教错的模型**；自标注回声更会把「错」固化成「自洽」，让系统越跑越自信地错——**标错，比不标更危险。**

**次级风险与缓解**：自标注回声 / 模型坍缩（定义 319 只升疑 + ECH + 回滚，引理 21、定理 19）；共源失效使 ρ_f→1（LPG 共源风险 cr(S) + d_min 硬约束，定义 311/318、引理 20）；标签投毒与视角伪造（ℰ_label + 溯源签名 + E309/E310）；标注预算击穿实时性（慢环旁路 + ALV 批处理 + 只读缓存，定义 323）；溯源门过严导致「永不认证」（τ_π/d_min 由 AuditBuf 自适应 + R69 兜底，定理 18）。

**收束一句**：真正的风险不是「没有证据」，而是「证据全是同一个来源的复印件」——**当溯源本身也可被伪造时，越完整的溯源图，越可能是一张精心伪造的证书。**
