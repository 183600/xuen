# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 1 轮；本轮灵感：「Gazebo」×「手势识别」）

> R73 把证据计量做成了可组合的契约（MMS/DPEM/CCA/ΣREFLEX/CPB/ECG），也诚实承认最大风险是「**契约表达力**」——真实噪声一旦超出契约可表达空间，组合定理会在「所有模块证书有效、所有组合校验通过」时给出错误安全界。但 R73 把两个最硬的假设留在了证明的**外面**：
>
> - **表达力无法被证伪**：R73 的实验（E371–E395）绝大多数是**观测式**的。真实世界不能做单变量干预——你没法只改材质不改光照、只改视角不改人手、只改一个因果父节点而不动其余变量。于是「契约是否漏了一个因果项」只能等事故来告诉我们。这是**校准方法学**的缺口，不是定义数量的缺口。
> - **证据源被默认为非策略性**：DPEM 的深度、DMEM 的接触，噪声再复杂也**没有意图**。可具身系统最关键的证据常常来自**人**——手势、指点、示范、拒绝。人不是固定的随机过程，而是会**配合、误解、改变表达、甚至欺骗**的理性主体。R73 的 CCA/ΣREFLEX 建立在「噪声通道 Lipschitz + 期望预算」上，这对策略性证据源在结构上不成立。
>
> 本轮两个灵感正好各补一刀：
>
> - **Gazebo** → **TBM（Twin-Bound Metrology，孪生约束计量）+ DIC（Do-Interventional Calibration，干预式校准）+ XCA（eXpressiveness Contract Audit，表达力反证审计）**：把仿真器从「数据生成器」升格为**带声明偏差的参考仪器**；用只有仿真才提供的 do() 干预去**主动证伪**契约；同时用「锚点不可全仿真」硬约束，防止仿真悄悄变成真理。这把 R73 的最大风险从「祈祷契约够宽」改成「在声明干预族内、有限时间内可执行的证伪程序」。
> - **手势识别** → **CEM（Communicative Evidence Metrology，交际证据计量）**：手势六分量（运动学/识别器/共同基础/视角/时序/策略）+ Gricean 生成链 + 共同基础隐变量 g_t + 策略类别 K。手势是「社交证据」的第一个示范实例：证据质量不仅取决于传感器，还取决于**对方想不想让你懂**。
> - 二者交汇 → **SEG（Strategic Evidence Game，策略性证据博弈）+ DCA（Deictic Cross-modal Audit，指称跨模态审计）+ 双源证书**：仿真能提供物理与脚本化社会的 ground truth，但**仿真中的人永远是 NPC**——δ_beh（行为现实差）无法由仿真自己标定，只能由**非仿真锚点（真人标注/受控人因实验）**与**稳健/弃权策略**承担。
>
> 核心命题：**证据计量的下一道关口不是「能否组合」，而是「组合所依赖的契约能否在部署前被主动证伪」——仿真给出干预能力，人给出策略边界；证书必须同时携带「仿真内有效」与「迁移到真实/策略性主体仍有效」两半，且两半的锚点不得全部来自仿真。**

## 0. 直觉与动机

**灵感 1（Gazebo → 仿真是「能做反事实实验的仪器」，不是「真理」）**
直觉：真实世界的数据是**被纠缠过的**。你观测到深度方差变大，无法判定是材质变镜面、距离变远、外参漂移、还是多机互扰——这些因果父节点在观测数据里高度共线，任何回归都只能给出相关性的分解，不能给出**干预效应**。Gazebo 的独特价值恰恰是 `do()`：只把材质从漫反射改成镜面、只把基线减半、只把物理求解器迭代数降一档、只往 IR 频段注入互扰——其余全保持不变。这是真实实验做不到的**干预式可识别性**，也是把「契约漏项」从不可检验的哲学问题变成可跑的工程审计的关键。
但同一枚硬币的反面是：仿真器自身的物理/渲染/接触/人模参数也是**建模选择**。它们的误差是**偏差（bias）而非噪声**——采样再多样本，偏差也不会均值归零。所以正确定位是：**Gazebo = 带声明偏差的参考仪器**。它给干预能力，但读数要经过一条**迁移契约**才能进入真实认证；迁移差 δ_sim 必须是一等公民，而不是被「仿真里 SOTA」掩盖。直觉一句话：**仿真是让你能问「如果只改这一个原因会怎样」的仪器，不是替你回答「真实世界是什么」的裁判。**

**灵感 2（手势识别 → 社交证据的源头是策略性主体，不是传感器）**
直觉：深度与触觉再难，噪声源也**没有意图**。手势不同：同一个「指向」动作，可能是「拿那个杯子」，可能是「你看那边」，也可能是「我在逗你/骗你」；语义取决于**共同基础**（文化、约定、先前对话、共享场景），而共同基础是隐变量。更麻烦的是：**对方会根据机器人的反应改变表达**——机器人歪头，人就放大手势；机器人问「哪个？」，人就改指；机器人显得不懂，人可能干脆放弃或故意乱指。这意味着手势证据质量是**机器人动作的函数**，而这个函数由一个有策略的人实现：可能配合（cooperative）、可能无所谓（indifferent）、可能对抗（adversarial）。
R73 的 ΣREFLEX 假设通道 Lipschitz、预算按期望合算；对策略性主体，这两条都不成立（人可以给你一个「期望很好、最坏无界」的信号）。于是手势暴露了 R73 的第二个隐藏假设：**证据源非策略性**。我们必须把「来源策略类别 k_t」写进证据契约，把「拒绝/追问（abstain + grounding）」设为合法的一等输出，而不是把分类器输出硬塞进贝叶斯更新。

**灵感 3（交汇 → 双源证书与「不可自证」锚点）**
直觉：Gazebo 给得了物理 ground truth，也给得了脚本化手势；但**仿真中的人永远是 NPC**。于是「用仿真校准手势契约」有一个致命结构：δ_sim 的物理/渲染/传感器分量可以被真实物理锚点标定，**但 δ_beh（行为现实差）不能由仿真自己标定**——NPC 不会欺骗、不会疲倦、不会因为不信任机器人而改变策略。所以本轮的核心纪律不是「仿真越多越好」，而是**证书双源**：
- 一半是「仿真内有效」（internal validity，靠 DIC/XCA）；
- 一半是「迁移后仍有效」（external validity，靠非仿真锚点 + 策略支撑集 K_support + 弃权策略）。
并加一条硬不变式：**任何证书的追溯链不得全部终止于仿真**；全仿真链只能得到 `SIM_ONLY` 证书，隔离在部署认证之外。这在结构上对应 R73 的「深度自标定自举循环」风险，但更狠：自举从「用深度标定深度」升级为「用仿真验证仿真」。

**灵感 4（否定性直觉：模块化代数对策略性证据失效，而非只是变难）**
直觉：R73 的并联缩窄（PAR）本质是「两个证据在名义分布上一致 ⇒ 可以更自信」。对物理传感器，这成立；对策略性人类，**一致性本身可以被生产**——对抗者可以同时伪造手势与深度/场景线索，让跨模态审计通过，然后在最坏情况下给出无界误差。所以「期望值组合 + conformal 名义覆盖」对社交证据是**不健全**的。这不是调参问题，是代数问题：需要把 leader–follower（Stackelberg）结构写进组合算子，把「最坏情况覆盖」替代「期望覆盖」，并把「弃权」当成合法动作。**承认失效点，比再加十个定义更有价值。**

**灵感 5（论文创新点，继承 R73 的蒸馏纪律）**
R73 已经把体系蒸馏成 C1/C2/C3。本轮不新增「工程附件」，只追加三条**可隔离、可证伪**的主张，并且每条都必须能用一个最小基准 + 一个隔离消融 + 预注册指标说清：
- **C4（仿真可追溯契约）**：把仿真当「声明偏差参考仪器」+ 用 do() 干预式校准 + 非仿真锚点，其在**迁移校准（ECE/覆盖率）与缺陷检出**上优于纯仿真校准（过度自信）与纯真实校准（稀有事件覆盖不足）。
- **C5（社交证据计量）**：手势六分量（含共同基础与策略分量）在**约定漂移、视角变化、欺骗手势**下，误解释率与人类交互成本显著优于「通用意图分类器 + 名义 conformal」。
- **C6（策略稳健组合）**：Stackelberg 最坏情况审计 + 非补偿欺骗否决，在对抗性人类下**最坏误差与不安全决策率**显著优于期望值 CCA，代价是更高的弃权率（效率不承诺）。
定位声明：domain randomization、sim-to-real、system identification、conformal prediction、POMDP 人模、Stackelberg 博弈、Gricean HRI、共同基础与指称（Clark）都是已知工作；**本方案的创新不在其中任何单项，而在「审计 + 契约 + 组合 + 不可自证锚点」这一层**——仿真偏差成为被记账的证书字段，「策略支撑集」成为证书的有效域，「弃权」成为一等公民，而契约缺陷可以被干预实验主动证伪。

## 1. 严谨定义（增量：定义 383–395）

**定义 383（SIMSOC-GAUGE-RAS 总览与六不变式）**
SIMSOC-GAUGE-RAS = (MODGAUGE-RAS†, TBM, DIC, XCA, CEM, SEG, DCA)。在 R73 五不变式上追加：
- (i) **契约完整性**（继承）：无完整 EC 不入图；
- (ii) **组合单调性**（继承，社交子域替换为稳健单调）：物理证据走 CCA；社交证据走 SEG；
- (iii) **反作用通道完备**（继承）：新增社交反作用通道 χ_H 必须声明（可为「不适用」）；
- (iv) **主张绑定**（继承并扩展）：组件 ∈ {C1…C6, 工程附件}，附件不进核心认证路径；
- (v) **严格退化链**（继承）：模块级 stub；
- (vi) **不可自证锚点（Anchor Non-Circularity，新增硬约束）**：任一进入部署认证的证书，其追溯链终端至少包含一个**非仿真锚点**（真实物理基准 / 人体受试标注 / 已知几何 / 接触真值）。若全链终止于仿真，证书标记 `SIM_ONLY`，不得进入真实认证路径，也不得用于主张 C4/C5/C6 的外部有效性声明。

**定义 384（迁移契约 STC 与仿真偏差五分量）**
仿真器 S = (𝓜_phys, 𝓡_rend, 𝓢_sens, 𝓐_act, 𝓗_beh)：物理模型、渲染器、传感器模型、执行器模型、人行为模型。
迁移契约 STC = (T_sim, T_real, δ_sim, L_sim, D_sim, Anchors)，其中
δ_sim² = δ_phys² + δ_rend² + δ_sens² + δ_act² + δ_beh²。
对在 D_sim 上 Lipschitz 常数为 L_sim 的模块：u_real ≤ u_sim + L_sim·δ_sim（逐分量取 sup 范数）。
关键性质：δ_sim 是**偏差**，不随仿真样本数 N 缩小（u_sim 的统计误差 ∝ N^{-1/2} 会缩，L_sim·δ_sim 不会缩）；δ_beh 在策略维度上**无先验有限上界**，只能由 K_support 或弃权承担。每个偏差分量必须绑定独立追溯锚点。

**定义 385（DIC 干预式校准）**
在 ECG（IP-302）声明的因果父集 Pa 上定义干预族 𝓘 = {do(X=x) : X∈Pa}。干预响应
R_i(X→x) = E[u_i | do(X=x)]，平均因果效应 ACE(i,X) = E_x[R_i(X→x)] − R_i(X=x₀)。
仿真允许精确 do()：物理参数（时间步、求解器迭代、接触刚度）、渲染材质（漫反射/镜面/透明/黑体）、传感器基线/曝光/内外参、互扰注入、手势类别、共同基础约定、遮挡、策略类别。输出：
(a) 敏感度矩阵 S[i,X]；(b) 契约预测残差矩阵 Z[i,X]；(c) **未覆盖干预集** 𝓤 = {(i,X) : |Z| > τ}。
DIC 的关键收益：把「观测共线」变成「单变量干预」，从而**可识别**每个分量对总不确定度的边际贡献。

**定义 386（XCA 表达力反证审计与契约缺陷 XCD）**
对干预对比 c = (X, x, x′)，残差 z_c = (u_obs(c) − u_pred(c)) / σ_pred(c)。
**契约缺陷** XCD(i) 存在当且仅当存在 c∈𝓘，使 |z_c| > τ 且在多种子下符号一致。
XCA 输出**缺陷证书**：(因果父 X，残差 z_c，受影响模块 i，建议修复——新增 u 字段 / 收紧有效域 / 新增否决指示)，并同时输出**干预族覆盖声明 𝓘**。
XCA 是**证伪器**：检出 ⇒ 契约在 𝓘 上确实失配（在 A115 下）；未检出 ⇏ 无缺陷（只在 𝓘 内未被证伪）。**功效 = 干预族完备性**，而算法本身不是瓶颈。

**定义 387（CEM 的 Gricean 生成链）**
意图 i∈𝓘_int、共同基础 g∈𝓖、交际动作 a∈𝓐、手部运动学 κ、观测 y_g。生成模型
P(y_g, κ, a | i, g, q, v, r) = P(i) P(g) P(a | i, g, q, k) P(κ | a, g, style) P(y_g | κ, v, r, occl)。
q 为机器人接地动作，k 为策略类别，r 为识别器，v 为视角（与 DPEM 的 χ_v 耦合），occl 为遮挡。
与物理传感器本质差异：**此模型含第二个智能体的策略项**，故证据 = 信号 × 策略；「观测到的动作」不是「意图的噪声版」，而是「意图在策略约束下的最优（或次优）表达」。

**定义 388（共同基础隐变量与接地动作 SGR）**
b_t(g) 为共同基础后验；接地动作 q∈Q = {ask, demonstrate, point-back, move-viewpoint, show-scene}。
**社会接地反作用（SGR）**：
q* = argmax_q [ ΔH(b_t(g)) − λ·cost(q) − c_reflex^social(q) ]，s.t. 时序契约。
仅在 **cooperative 支撑**下可证有限停止（引理 41）；非合作时退化为「弃权 / 安全拒绝」，而不是继续追问。

**定义 389（手势六分量不确定度）**
u_gest² = u_kin² + u_rec² + u_cg² + u_view² + u_temp² + u_strat²。
- u_kin：关键点/手姿态噪声与自遮挡；u_rec：识别器量化与校准误差；
- u_cg：共同基础失配（约定/词表/参照系）；u_view：视角误差（与 DPEM χ_v 同源）；
- u_temp：动作时序/相位/起止点分割；u_strat：策略残差。
**u_strat 只有在 k_t∈K_support 内才有有限上界**；k_t∉K_support ⇒ u_strat = ∞ ⇒ stub/弃权。
有效域 D_gest = {support(b_t(g)) ≥ τ_g} ∧ {k_t∈K_support} ∧ {occl ≤ τ_o}。

**定义 390（社交证据契约 SEC）**
SEC = EC ∪ (production_model, K_support, dialogue_budget, cg_support, human_anchors, abstain_policy)。
新增否决指示：`CG_MISMATCH`、`STRATEGY_OUT_OF_SUPPORT`、`DEICTIC_CONFLICT`、`REPLAY_SUSPECTED`。
**契约义务**：社交模块必须能 abstain/ask，不得对全部意图命题投「决定票」；人类锚点必须声明覆盖的人群与文化范围（锚点也有有效域，不是万能真值）。

**定义 391（SEG 策略性证据博弈）**
机器人先动作 q（leader），人按策略 k 最优响应 a∈BR(q;k)（follower）。
**Stackelberg 一致性审计**：仅当 sup_{k∈K_support} ConformalCoverage(r;k) ≥ 1−α 才允许 PAR 缩窄；否则不许缩窄。
**稳健预算**：Σ_i c_reflex^i + c_social ≤ B，其中 c_social = Stackelberg regret（或 worst-case ΔH）。
**对 k = adversarial（或检测到欺骗指示）：禁止 PAR，只许 VETO + abstain/ask。**
注意：这不是 R73 「期望预算」的加项，而是**换了一套结算语义**——期望值被最坏情况替换。

**定义 392（DCA 指称跨模态审计）**
指点射线 ℓ = (o_h, d̂)（从人手出发的方向）与 DPEM 深度面、BSE 语义物体假设的一致性带 C_α^deictic。
若手势指称 r_g 与几何/语义指称 r_s 在带外不一致 ⇒ `DEICTIC_CONFLICT`，**单源不定案**（继承 E356/E357 原则）。
DCA 覆盖：假指点（decoy）、镜面反射造成的指称偏移、透明屏障后的错误深度、复现攻击（replay）。

**定义 393（双源证书 J_SIMSOC 与锚点闭合）**
J_SIMSOC = J_sim_int ⊗ J_transfer ⊗ J_comp。
J_transfer 校验：
(a) δ_sim 已声明；(b) 每个偏差分量有非仿真锚点（δ_beh 必须有人因锚点）；(c) L_sim 在 D_sim 内成立；(d) K_support 覆盖部署人群（否则 abstain_policy 必须生效）。
Valid(J_SIMSOC) ⇒ 在声明域内 Valid(J_MOD)（R73）；否则证书为 `SIM_ONLY` 或 `CONDITIONAL(K_support)`，二者都不得用于外部安全声明。

**定义 394（类型化严格包含）**
R73 MODGAUGE = SIMSOC 的特例：δ_sim = 0、手势 stub、K = {cooperative}、Q = ∅、无 abstain。
在**非社交子域**，逐指令等价；在**社交子域**，SEG **替换**（而非保守扩展）期望值 CCA（因引理 40）。
故包含是**类型化**的：**安全侧单调不减**（更多拒绝/弃权），**效率侧不保证**。这不是免费午餐，是显式承认的代价。

**定义 395（MBench MB4/MB5）**
MB4：Gazebo 干预台——do(物理/渲染/传感器/互扰/手势/约定/遮挡)，带 depth/contact/gesture ground truth。
MB5：社交台——脚本 NPC + Wizard-of-Oz + 真人策略组；覆盖约定漂移、欺骗手势、假指点、复现攻击。
各 ≤3h 单卡可复现；预注册脚本 + 固定种子 + 密封保持集 SEAL-MB。

# 第 74 轮产物 · 创新点清单 v5：SIMSOC-GAUGE-RAS（Simulation-grounded, SOCial-evidence metrology with GAUGE audits；Gazebo 干预式校准 × 手势社交证据 × 策略稳健组合 × 双源证书；TBM×DIC×XCA×CEM×SEG×DCA×MODGAUGE†）

> 承接第 73 轮 IP-295~302（MODGAUGE-RAS：MMS/DPEM/CCA/ΣREFLEX/CPB/ECG/MIC）。R73 确立了「计量契约可组合」与「热替换保持系统性质」，并把最大风险点名在**契约表达力**与**反作用通道**上；但其校准协议几乎全是观测式的，且证据源被默认为非策略性。本轮以「Gazebo × 手势识别」两刀切开这两个盲区：
>
> - **TBM/DIC/XCA**：仿真器 = 带声明偏差的参考仪器；用 only-in-simulation 的 do() 干预做**契约证伪**；偏差分解 δ_sim² = δ_phys²+δ_rend²+δ_sens²+δ_act²+δ_beh²；证书必须锚点闭合（不可自证）。
> - **CEM/SEG/DCA**：手势 = 第一个「社交证据」模块；六分量含共同基础 u_cg 与策略 u_strat；Stackelberg 最坏情况审计替换期望值 PAR；指称跨模态单源不定案。

> - **否定性结果（本轮核心）**：R73 的期望值组合对策略性证据源**不健全**（引理 40），因此社交子域是**替换**而非保守扩展（类型化包含，定理 31）。
>
> 核心命题：**契约的价值不在「写得多全」，而在「能否在部署前被主动证伪、且其证书的终点不全在仿真里」。** 安全侧只增不减，效率侧显式不承诺。

## 2. 形式化定义（要点版 383–395）

**定义 383（总览与六不变式）** 在 R73 五不变式上追加 (vi) **不可自证锚点**：进入部署认证的证书，追溯链终端至少一个非仿真锚点；全仿真链 ⇒ `SIM_ONLY`，不得用于外部有效性声明。

**定义 384（STC 与偏差五分量）** 仿真器 S = (𝓜_phys, 𝓡_rend, 𝓢_sens, 𝓐_act, 𝓗_beh)；δ_sim² 五分量各有独立锚点；δ_sim 是偏差不是方差，不随 N 缩小；δ_beh 在策略维度无先验有限上界。

**定义 385（DIC）** 在 ECG 因果父集上做 do() 干预；输出敏感度矩阵、残差矩阵、未覆盖干预集 𝓤；把观测共线转为单变量可识别。

**定义 386（XCA / XCD）** 对比残差 z_c；缺陷 ⇔ ∃c∈𝓘, |z_c|>τ 且多种子符号一致；输出缺陷证书 + 干预族覆盖声明；**证伪器**（检出⇒确有问题；未检出⇏无问题）。

**定义 387（CEM Gricean 链）** P(y_g,κ,a|i,g,q,k) = P(i)P(g)P(a|i,g,q,k)P(κ|a,g,style)P(y_g|κ,v,r,occl)；含第二智能体策略项，证据 = 信号 × 策略。

**定义 388（共同基础与 SGR）** b_t(g) 后验；q* = argmax_q [ΔH(b_t(g)) − λ·cost(q) − c_reflex^social(q)]；仅合作支撑下可证有限停止（引理 41）。

**定义 389（手势六分量）** u_gest² = u_kin²+u_rec²+u_cg²+u_view²+u_temp²+u_strat²；k_t∉K_support ⇒ u_strat=∞ ⇒ stub/弃权；D_gest = {support(b_t(g))≥τ_g} ∧ {k_t∈K_support} ∧ {occl≤τ_o}。

**定义 390（SEC）** EC ∪ (production_model, K_support, dialogue_budget, cg_support, human_anchors, abstain_policy)；否决 `CG_MISMATCH` / `STRATEGY_OUT_OF_SUPPORT` / `DEICTIC_CONFLICT` / `REPLAY_SUSPECTED`；社交模块必须能 abstain/ask，不得对全部意图命题投决定票；人类锚点自身有有效域。

**定义 391（SEG）** 机器人 leader、人 follower；仅当 sup_{k∈K_support} ConformalCoverage(r;k) ≥ 1−α 才允许 PAR 缩窄；稳健预算 Σc_reflex + c_social ≤ B；对抗类禁 PAR，只 VETO+abstain/ask。

**定义 392（DCA）** 指点射线与深度/语义指称的一致性带 C_α^deictic；带外不一致 ⇒ `DEICTIC_CONFLICT`，单源不定案；覆盖假指点、镜面偏移、透明屏障、replay。

**定义 393（J_SIMSOC）** J_sim_int ⊗ J_transfer ⊗ J_comp；J_transfer 校验 δ_sim 声明、每分量非仿真锚点（δ_beh 需人因锚点）、L_sim 在 D_sim 成立、K_support 覆盖部署人群；否则 `SIM_ONLY` 或 `CONDITIONAL(K_support)`。

**定义 394（类型化严格包含）** R73 = SIMSOC(δ_sim=0, 手势 stub, K={coop}, Q=∅, 无 abstain)；非社交子域逐指令等价；社交子域 SEG **替换**期望值 CCA（引理 40），安全侧单调不减、效率侧不承诺。

**定义 395（MBench MB4/MB5）** MB4 Gazebo 干预台（do 物理/渲染/传感/互扰/手势/约定/遮挡 + ground truth）；MB5 社交台（脚本 NPC + WoZ + 真人策略组；约定漂移/欺骗/假指点/replay）；各 ≤3h 单卡、预注册、SEAL-MB。

```python
# IP-303 TBM：仿真器 = 带声明偏差的参考仪器（迁移契约）
@dataclass(frozen=True)
class TransferContract:
    sim: str; real: str
    delta: Dict[str, float]           # δ_phys, δ_rend, δ_sens, δ_act, δ_beh
    lipschitz: float                  # L_sim on D_sim
    domain: Predicate                 # D_sim
    anchors: FrozenSet[str]           # 非仿真终端；每个 δ 分量必须被覆盖
    def bound(self, u_sim, comp):
        assert any(a.startswith('real:') for a in self.anchors)   # 不可自证
        return u_sim + self.lipschitz * self.delta[comp]

# IP-304 DIC：在 ECG 因果父上做干预式校准
def interventional_calibrate(mod, ecg, interventions, sim, n=512):
    S, Z = {}, {}
    for X, xs in interventions.items():          # do(X=x)，仿真中精确可控
        for x in xs:
            u_obs  = sim.run(mod, do={X: x}, n=n).u
            u_pred = mod.ec.predict(do={X: x})
            S[(mod.id, X, x)] = u_obs
            Z[(mod.id, X, x)] = (u_obs - u_pred) / mod.ec.sigma(X)
    return SensitivityMatrix(S), ResidualMatrix(Z), uncovered(Z, tau=TAU_XCA)

# IP-305 XCA：主动证伪契约（找漏掉的因果父）
def falsify_contract(mod, ecg, interventions, sim, tau=3.0, seeds=8):
    defects = []
    for c in contrast_set(interventions):        # c = (X, x, x')
        zs = [residual(mod, sim, c, seed=s) for s in range(seeds)]
        if abs(mean(zs)) > tau and same_sign(zs):
            defects.append(Defect(parent=c.X, residual=mean(zs),
                                  module=mod.id,
                                  fix=suggest_field(mod.ec, c)))
    return ContractVerdict(
        defects=defects,
        family=set(interventions),               # 公开盲区：XCA 只在 𝓘 内有效
        status='FALSIFIED' if defects else 'NOT_FALSIFIED_IN_FAMILY')

# IP-306 CEM：带共同基础与策略类别的交际证据
class CommunicativeEvidence:
    def update(self, video, depth_ev, b_g, k_t, r):
        kp    = self.pose.estimate(video)                  # κ
        p_i   = self.recog.classify(kp, r)                 # p(i | κ, r)
        u_kin = self.calib.kin_unc(kp, video.occl)
        u_rec = self.calib.rec_unc(p_i)
        u_cg  = self.calib.cg_unc(b_g)                     # 共同基础失配
        u_view= self.calib.view_unc(depth_ev.v, video)     # 与 DPEM χ_v 耦合
        u_temp= self.calib.temp_unc(kp, self.phase)        # 时序/相位/起止
        u_str = 0.0 if k_t in K_SUPPORT else math.inf      # 策略残差
        u = math.sqrt(u_kin**2+u_rec**2+u_cg**2+u_view**2+u_temp**2+u_str**2)
        valid = (u_str < math.inf) and (support(b_g) >= TAU_G) \
                and (video.occl <= TAU_O)
        return GestureEvidence(p_i=p_i, b_g=b_g, k_t=k_t, u=u,
              breakdown=(u_kin,u_rec,u_cg,u_view,u_temp,u_str), valid=valid,
              abstain=(u_str == math.inf or not valid))

# IP-307 SEG：Stackelberg 稳健组合（替换期望值 PAR）
def social_compose(a_ev, b_ev, K_support, alpha, audit):
    # 1) 策略越界 / 对抗：禁止缩窄
    if a_ev.k_t not in K_support or b_ev.k_t not in K_support:
        return Veto(a_ev, b_ev, reason='STRATEGY_OUT_OF_SUPPORT')
    # 2) 最坏情况 conformal 覆盖（不是期望覆盖）
    ok = all(audit.coverage(signal=a_ev.signal, k=k) >= 1 - alpha
             for k in K_support)
    if not ok:
        return Ev(u=max(a_ev.u, b_ev.u), valid=False,
                  veto=a_ev.veto | b_ev.veto | {'STACKELBERG_AUDIT_FAIL'})
    # 3) 通过最坏情况审计后，才允许融合与缩窄
    return fuse(a_ev, b_ev, rho=audit.estimate_corr(a_ev, b_ev))

def social_budget_step(modules, q, state, budget):
    total = 0.0
    for m in modules:
        c = m.social_cost(state[m], q)          # regret / worst-case ΔH
        if c is None:                           # 无有限最坏界 ⇒ 弃权
            return None, total
        total += c
    return (state, total) if budget.spent + total <= budget.B else (None, total)

# IP-308 DCA：指称跨模态审计（单源不定案）
def deictic_audit(p_i, pointing_ray, depth_ev, scene_belief, audit):
    r_g  = scene_belief.referent(p_i)                       # 手势指称
    r_s  = intersect(pointing_ray, depth_ev.geometry, scene_belief)  # 几何指称
    band = audit.conformal_band(alpha=ALPHA_DEICTIC)
    if r_g != r_s and distance(r_g, r_s) > band:
        return Veto(reason='DEICTIC_CONFLICT', r_g=r_g, r_s=r_s)
    return Evidence(valid=True, u=min(depth_ev.u, p_i.u), support={r_g, r_s})

# IP-309 SIMSOC 主闭环 + 双源证书
def SIMSOC_round(M, obs, audio, tac_frame, depth_img, video, human):
    # === 感知域（异步 100Hz，Best-effort）===
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    if not d_ev.valid: d_ev = stub(M.dpe)                    # R73 模块级降级
    t_ev = M.dmem.update(tac_frame, M.last_action)
    g_ev = M.cem.update(video, d_ev, M.b_g, human.k_t, M.rec_r)   # IP-306
    if g_ev.abstain:                                         # 弃权/追问
        g_ev = stub(M.cem); M.q = M.sgr.choose(M.b_g)        # SGR（定义 388）
    # === 计量域（50Hz，软实时）===
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev, g_ev=g_ev)
        z_dist, ece_z, iota_z = M.irl.update(M.y_intent_buf, psi_hat, b_t)
        # 物理证据走 R73 CCA；社交证据走 SEG；指称走 DCA
        M.mreg.compose_physical(d_ev, t_ev)
        M.mreg.compose_social(g_ev, K_support=M.K, alpha=M.alpha)
        M.deictic = deictic_audit(g_ev.p_i, g_ev.ray, d_ev, b_t.scene, M.audit)
        g = M.ervoi.choose(b_t, psi_hat, z_dist, t_ev.c_dist, g_ev,
                           M.budget, M.fmp, M.bse)
        if g:
            s2, c = sigmareflex_step(M.mods, g, M.state, M.budget)
            s2, c = social_budget_step(M.social_mods, M.q, s2, M.budget)
            if s2 is not None: M.last_g, M.state = g, s2
        M.snapshot.write(b_t, z_dist, d_ev, t_ev, g_ev, M.state)
        M.mreg.audit()
    # === 控制域（1kHz，硬实时，只读快照，零分配）===
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.g_ev.u),
                              M.risk_params)
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop); k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam)
    M.cert_ctrl.write(k=k, lam=lam, wcet=M.rtm.wcet_us(), breaker=M.breaker.status())
    return k, lam, J_SIMSOC(M)     # 双源证书（定义 393）
```

## 4. 推导

先列本轮新增假设（它们是**可被质疑的**，不是公理）：
- **A114（迁移 Lipschitz）**：在 D_sim∩D_real 上，模块不确定度对偏差源 Lipschitz，常数 L_sim 可估。
- **A115（干预保真）**：仿真对每个 do() 机制忠实实现（否则 XCA 检出的可能是仿真实现错误，不是契约缺陷）。
- **A116（策略支撑覆盖）**：部署人群的策略类别落在 K_support 内，或 abstain_policy 生效。
- **A117（锚点独立）**：非仿真锚点与仿真模型无共享未建模误差（否则锚点不独立，锚点闭合是形式上的）。

**引理 38（迁移界与偏差不收敛）**
设模块在 D_sim 上 Lipschitz 常数 L_sim，STC 声明 δ_sim。则对任一真实读数 u_real：u_real ≤ u_sim + L_sim·δ_sim。且增加仿真样本 N 只降低 u_sim 的统计误差（∝N^{-1/2}），不降低 L_sim·δ_sim。
*证明*：三角不等式 + Lipschitz 定义；δ_sim 是系统性偏差（分布间距离），与样本量无关。∎
系：**「仿真里更准」不等于「更接近真实」；偏差项必须由真实锚点单独估计。**

**引理 39（干预可识别性与 XCA 检出功效）**
在 A115 与因果忠实性下，若契约遗漏因果父 X 且 ACE(X) ≥ ε，则存在干预对比 c∈𝓘 使 |z_c| ≥ ε/σ_pred；随种子数增大，XCA 检出概率 → 1（符号一致性检验）。若 X ∉ 𝓘，XCA 结构性失明。
*证明*：do() 切断 X 的入边，遗漏项只经 X 影响 u；对比 x→x′ 的残差即 ACE/σ；独立种子下符号检验的势 → 1。∎
系：**XCA 的功效 = 干预族完备性，而非算法；证书必须公开 𝓘。**

**引理 40（期望值社交组合的不健全）**
存在策略性人类 k*∈K（对抗），使 R73 的期望值 PAR 缩窄通过名义 conformal 审计，但 worst-case 误差无上界：sup_k E_k[err] = ∞。
*构造*：对抗者以概率 1−η 产生与场景一致的「真手势」，以 η 产生同时伪造手势与场景线索（深度贴片/遮挡）的「假指点」；名义分布下跨模态残差落在 C_α 内，期望误差 ≈ η·小；当 η→0 而假指点代价 →∞（错误抓取危险物），worst-case 超期望的比值无界。∎
系：**R73 CCA 对社交证据不是「更难」，而是「不健全」；必须替换为 SEG（最坏情况覆盖 + 非补偿否决）。**

**引理 41（合作支撑下的接地有限停止）**
在 k=cooperative 且 g 落在声明约定支撑内时，接地动作对 u_cg 的边际下降有正下界、成本有上界，且总边际增益非增 ⇒ SGR 存在有限 q*。若 k∈{indifferent, adversarial}，边际下降可为零或为负（人可故意给反信号），有限停止不成立。
*证明*：合作者按共同基础更新其表达，ΔH 单调；非合作者可自由选择 a，ΔH 无下界。∎
系：**「对话式消歧」只在合作假设下可证终止；对策略性主体必须用弃权边界，而非无限追问。**

**引理 42（指称冲突的单源不可判定）**
若指点射线与深度/语义指称在 C_α^deictic 带外不一致，则 {gesture, geometry, common-ground} 中至少一者错；在对称先验下任选单源的错误概率 ≥ 1/2。故必须 VETO + 接地动作。
*证明*：三者互斥一致性约束；单源无信息选择的最坏/平均错误由对称性给出。∎
系：**跨模态一致性把「哪个对」变成「谁也不能单独定案」，与 R71 非补偿原则同构。**

**定理 30（双源证书可靠性）**
若 (i) J_sim_int 有效；(ii) δ_sim 已声明且锚点闭合（每分量有非仿真终端，δ_beh 有人因锚点）；(iii) L_sim 在 D_sim 成立；(iv) 部署时 k_t∈K_support 或 abstain_policy 生效；则真实执行风险 ≤ ε_sim + L_sim·δ_sim。若 (iv) 不成立，系统退化为**弃权-安全**（不执行有风险动作），而非给出错误安全界。
*证明*：引理 38 给界；SEG 保证越界即弃权；弃权动作集合的风险由控制器安全前缀（R72）界定。∎
系：**证书不能证明「在任意人面前安全」，只能证明「在声明策略支撑内安全，支撑外弃权」。**

**定理 31（类型化严格包含）**
取 δ_sim=0、手势 stub、K={cooperative}、Q=∅，SIMSOC 在非社交子域与 R73 MODGAUGE 逐指令等价。在社交子域，SEG 的 worst-case 安全 ≥ 期望值 CCA（引理 40），但期望性能可下降（更多弃权）。
*证明*：退化参数下 SEG 退化为 CCA（cooperative 单点支撑 + 期望=最坏），DCA/SEC 退化为平凡；社交子域由引理 40 与最坏情况覆盖定义直接得。∎
系：**安全侧单调不减，效率侧不承诺——这是有意的类型化包含，而非无条件泛化。**

**定理 32（XCA 的证伪可靠性与固有不完备）**
A115 下，XCA 报出缺陷 ⇒ 契约在 𝓘 上确实失配。反之，未报缺陷只说明「在 𝓘 内未被证伪」。故 XCA 把 R73 的「希望契约够宽」变成「在声明干预族内、有限时间内可执行的证伪」，但不提供完备性。
*证明*：引理 39 的正向与反向；反向依赖于 𝓘 的覆盖，非算法可补。∎
系：**可证伪性是可交付的；正确性不是。**

**定理 33（锚定认证成本）**
CertCost_SIMSOC = Σ_i (sim 内部认证 + 迁移锚点分摊) + 组合校验。锚点成本不可消除（不可自证），但当 m 个模块共享同一锚点集时按 m 分摊；只要锚点集大小 ≪ 系统状态空间，CertCost_SIMSOC < 全真实系统认证成本。C4 可证伪形式：仿真+锚点相对纯真实认证成本比 > 5×，且迁移 ECE 不劣于纯真实校准。
*证明*：成本可加性与分摊；锚点数为系统级常数。∎

## 7. 本轮最大风险

**一句话**：仿真只能证伪它建模过的因果路径，而手势最关键的社会策略维度恰恰最容易被 Gazebo 脚本化成「必然配合的 NPC」——于是系统会在一个「人类会配合」的孪生世界里拿到双源证书，却在真实策略性人类面前把「证书齐全」误当成「社交安全」。

次级风险与缓解：
1. **A115 自指（用仿真验证仿真）** → 交叉引擎（Gazebo/MuJoCo/Isaac）差分 + 真实物理锚点；XCA 结论必须声明引擎，不得跨引擎默认迁移。
2. **A117 锚点不独立** → 锚点设计与仿真模型解耦（独立传感器/独立标注流程/人因实验双盲）；SEAL-Anchor 审计集。
3. **δ_beh 不可估/策略支撑可被游戏** → 弃权优先 + 人类在环（WoZ/询问）+ K_support 显式声明；绝不声称支撑外安全。
4. **XCA 盲区** → 把 𝓘 作为证书字段公开；红队持续扩展干预族；盲区内只允许 `SIM_ONLY` 声明。
5. **仿真过拟合 / 基准泄漏** → SEAL-MB 密封保持集 + 预注册 + 三方复现（E410）；主张只认预注册指标。
6. **Stackelberg 审计过于保守导致可用性下降** → 弃权-完成率 Pareto 预注册（E411）；在低风险任务允许 `CONDITIONAL` 放宽，但不进安全关键路径。
7. **手势伦理与隐私**（采集人类影像）→ 端上骨架化、数据最小化、知情同意、可撤回；人因实验独立伦理审查。
8. **DCA 对弱势群体/文化差异的误判** → 多文化约定覆盖声明 + 弃权；锚点人群范围写入证书有效域。
9. **物理求解器伪影被当作真实接触真值** → 接触刚度/时间步敏感性扫描 + 真实力台锚点（δ_phys 独立估计）。
