# 第 44 轮（新循环第 4 轮） · Semantic-Cert-Atlas × Differentiated-Positioning：把「语义地图」与「差异化定位」从感知产物升级为可验证的空间证书（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把「个性化」与「并发」纳入证书闭环，但它仍默认了第三个未言明的单点假设：**(H3) 定位是全局同质的、地图是静态正确的。** 真实边缘机器人恰恰相反：同一条走廊的不同语义区域（玻璃幕墙、白墙长廊、人群大厅）定位质量可差一个数量级；而语义地图会随家具移动、光照季节、店铺改造静默漂移。本轮灵感词「语义地图」「差异化定位」精确命中这个假设：**语义地图**不该只是规划用的标签图，而应升级为「空间证书索引」；**差异化定位**不该是按经验挑模态，而应成为「可被选择性证明」的证书。二者耦合处是新的真问题：**选择本身破坏了共形覆盖**，而**区域归属是隐藏变量**。

## 0. 直觉与动机

**灵感 0（词的双关 → 同一个结构）**：「定位」在机器人里是 localization，在商业里是 positioning。二者共享同一件事——**先有地图，才有位置；而差异化，本质是「在哪个区域、用哪种证据，你比别人更强」**。UniBot 的创新点因此不是「做一个更准的定位」，而是「做一个能证明自己在每个语义区域该信哪种定位」的定位。

**灵感 1（语义地图 → 从标签图升级为「封存证书图谱」）**：普通语义地图回答「这是门/墙/桌」。证书图谱多回答三件事：**这个区域的定位误差分布是什么、这份档案由哪批校准数据背书、它从何时起可能已经过期**。于是每个语义区域 R_i 携带 Φ_i（按模态子集校准的误差分位）、h_i（数据与地图的哈希，防篡改）、ℓ_i^map（地图租约，随时间和漂移衰减）。语义地图第一次成为 L1 定位证书的**索引**，而不是规划器的附属物。

**灵感 2（差异化定位 → 不是「挑最好的」，而是「证明挑选是合法的」）**：直觉上，玻璃幕墙旁该信 LiDAR 还是视觉？白墙长廊里视觉退化、几何更强；人群大厅里动态遮挡使两者都差，UWB/轮速先验反而稳。分区域、分模态地选，是巨大的保守性收益。但这里有一个反直觉的陷阱：**你在校准集上挑「表现最好」的模态，等价于对数据做了选择（winner's curse / optional stopping）；朴素共形在数据依赖选择之后不再保证覆盖**。所以本轮的核心不是「怎么选」，而是「**怎么让选择这一步本身持证**」：选择规则 π 必须在校准前冻结或由独立数据背书，否则只能退回全局保守证书。

**灵感 3（耦合 → 边界与漂移是隐藏的条件变量）**：区域条件覆盖 P(e≤L | x∈R_i) 只在「x 真的在 R_i」时成立；而位置估计有协方差、语义边界有标注误差、地图还会漂移。边界附近或漂移之后，系统会用「错误的区域档案」给出「看似 sound」的证书——这正是第 43 轮「边际 vs 条件覆盖」风险在空间域的复现。因此必须加两把锁：**边界守护带**（只在 R_i 的收缩证书域内使用 Φ_i，否则取候选区域的最坏分位或全局回退）与**地图租约 + 语义-几何一致性**（漂移/矛盾即失效，先重定位/重测绘再发证）。

**耦合升级**：SCA（证书图谱）把语义地图编译成带哈希、校准、租约的区域档案；DPE（差异化定位引擎）做边界安全 + 选择性共形背书的模态组合选择；SDV（空间漂移验证器）用定位残差、回环一致性、语义-几何谓词与对抗重贴图验证漂移，把反例回灌 CKB/SCV。四层架构由 v8 的「人格 Cert × 并发 Cert」升级为 v9 的「空间 Cert × 人格 Cert × 并发 Cert」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（语义证书图谱 SCA）**：M^cert = {(R_i, s_i, Φ_i, h_i, ℓ_i^map, v_i)}。R_i 语义区域；s_i 语义类；Φ_i = {(S, q_{i,S,1−α}, n_{i,S}, σ_i(S)) | S ⊆ 𝕄} 为模态子集 S 的区域校准档案（q 为误差分位、n 为样本量、σ 为健康签名）；h_i 为区域几何 + 语义 + 校准集哈希；ℓ_i^map = (τ_i, η_i, μ_i) 为地图/校准租约（验证时刻、漂移阈值、漂移速率上限）；v_i 图谱版本。**封存根** H = Merkle(∪ h_i, v)。运行期只加载 H 可验证的图谱；任何单区域档案与根不一致即拒绝。**命题（可审计性）**：给定 H，任一区域证书可被离线复算与溯源（数据、量化、分位、阈值）。

**定义 45（区域条件定位证书）**：对区域 R_i、模态子集 S，令误差 e = ||x̂_S − x||。校准集内按区域与模态分层，取 q_{i,S,1−α} 为 (1−α) 秩统计分位，并加 Lipschitz 修正项 β_S·Δt。区域证书 **L_m^{i,S}(x) = q_{i,S,1−α} + β_S·(t−τ_S)**。**覆盖命题**：若 (x, e) 在 R_i 内可交换且 S 的选取与校准集独立，则 P(e ≤ L_m^{i,S} | x∈R_i) ≥ 1−α。**注意**：这是**按区域的条件覆盖**，不是全局边际覆盖；也是与 v8 定义 41 的本质区别（那里只租约时间，这里还条件化空间与模态）。

**定义 46（边界守护与区域集证书）**：位置不确定集 X̂ = {x : (x−x̂)^T Σ^{-1} (x−x̂) ≤ χ²_{1−γ}}。用共形区域集预测给候选语义区域集合 Ŝ(x̂) 满足 P(x ∈ ∪_{i∈Ŝ} R_i) ≥ 1−α_R。定义**证书可用域** R_i^cert = {x̂ : Ŝ(x̂) = {i}} 再收缩边界守护 δ_b(Σ, δ_map)。**边界安全证书**：若 |Ŝ| > 1，取 L_m = max_{i∈Ŝ} max_{S∈Adm_i} L_m^{i,S}（最坏区域的最坏模态），并打上 RegionMode = Transition；若 R_i^cert 外且无档案，退回 v8 全局保守证书。**命题**：区域集覆盖 + 最坏取 max ⟹ 边界处仍 sound；代价是边界带宽内的保守性（显式记账，而非静默）。**迟滞**：进入/离开 R_i^cert 用不同阈值 h_in < h_out，防噪声抖振导致证书震荡。

**定义 47（差异化定位的选择性证书）**：选择规则 π: 观测上下文 c → 模态子集 S。**合法差异化**有两种可证形式：
(a) **冻结选择**：π 在见校准数据前从有限类 Π 中固定；对每个 π 在独立校准集上共形化，保证 P(e_{π(c)} ≤ L^π_{1−α}(c)) ≥ 1−α；多 π 同时报告用 Bonferroni / e-value 控制族错误率。
(b) **在线自适应**：π_t 随观测更新（bandit / 元学习），则用**在线共形 / e-value betting**：维护可赌过程使长期误覆盖率 ≤ α + o(1)，漂移下用加权或重启。
**选择证书** = (π 的哈希 id, 校准集哈希, 覆盖口径, α, 生成时刻)。**反例命题（winner's curse）**：若在校准集上取 S*(c) = argmin_S q_{i,S} 再直接沿用同一批数据定阈值，则覆盖不再有保证（存在分布使实际误覆盖 → 1）。故**未持证的选择一律不得进入守卫**，只能作为候选排序交给持证兜底。

**定义 48（地图租约与漂移衰减）**：每区域维护漂移统计 D_i(t)（定位残差、scan-to-map 失配、回环一致性、place novelty）。**地图不确定性下界** δ_i(t) = δ_{i,0} + μ_i·(t−τ_i)。区域档案可用当且仅当 D_i(t) ≤ η_i ∧ t−τ_i ≤ T_map。**漂移命题（带假设）**：若语义/几何变化速率 ≤ μ_i（先验上界），且检测器对超过 η_i 的变化有检出功效 ≥ 1−β，则「检测前」证书通过 δ_i(t) 膨胀保持 sound；代价是随时间的保守性增长，需周期性重验证来「续租」。**诚实边界**：对低于检测下限的慢漂移，任何在线方法都无法保证；只能靠 δ 随时间膨胀 + 定期离线重测绘兜底。

**定义 49（语义-几何一致性证书）**：对区域 R_i，几何证书 g_i（IP-49 LIO 的占据/自由/可通行）与语义 s_i 需满足谓词集 χ：free(s_i) ⇒ traversable(g_i)、glass(s_i) ⇒ ¬solid_for_LiDAR(g_i)、door(s_i) ⇒ passable(g_i)、dynamic(s_i) ⇒ not_in_static_map(g_i)。**一致性判据**：χ(s_i, g_i) = ⊤ 才允许签发区域证书；若为 ⊥，将 R_i 标为 Contested，触发重定位/重测绘并把反例写入 CKB。**命题**：若 χ 为健全的物理约束（对真实世界恒真），则其违例必对应语义/几何至少一方错误，故拒绝发证是 sound 的（不会误用矛盾地图），代价是 Contested 区域的可用性损失。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 SEMANTIC-CERT-ATLAS（语义证书图谱 SCA）
1. **区域档案编译**：语义分区 × 模态分层校准 → Φ_i；小样本区域用层次贝叶斯 / 邻域借力（但借力必须记入协变量偏移修正）。
2. **封存与溯源**：Merkle 根 + 每区域哈希（几何/语义/校准/量化参数），部署可验证、可复算。
3. **边界守护带**：由 Σ 与地图标注误差 δ_b 计算 ρ_i；输出 RegionMode ∈ {Interior, Transition, Contested}。
4. **地图租约表**：每区域 (τ_i, η_i, μ_i)，随漂移膨胀 δ_i(t)，超限即失效。

### 2.2 IP-61 DIFFERENTIATED-POSITIONING-ENGINE（差异化定位引擎 DPE）
1. **模态健康门**：每模态先过健康证书（退化检测、外参漂移、时间同步、动态遮挡率），不健康者不进候选。
2. **合法选择器**：冻结类 + 独立校准（或在线 e-value）；输出带「选择证书」的 S，绝不未持证使用 argmin。
3. **边界/过渡模式**：|Ŝ| > 1 时取 max 分位并降级；R_i^cert 外回退全局证书。
4. **任务差异化服务水平**：θ_task 由下游任务给出（导航分米级、抓取毫米级），DPE 只在「证书满足 θ_task」时宣称可用，否则请求重定位/减速/换模态。

### 2.3 IP-62 SPATIAL-DRIFT-VALIDATOR（空间漂移验证器 SDV）
1. **漂移注入仿真**：移动家具、重贴纹理、光照/季节变化、玻璃反光、人群遮挡；测量检出时延与漏检窗口。
2. **语义-几何一致性 fuzz**：标签翻转、门变墙、玻璃当实体、动态物刻入静态图；检查 χ 违例检出。
3. **边界对抗采样**：把真值放在 ρ_i 带内/带外、区域集非唯一的退化位形，测「错误档案被使用」的次数。
4. **校准沙漠审计**：按区域统计 n_{i,S}、覆盖条件误差与可用率，检出系统性被饿死的区域。

## 5. 本轮最大风险

**一句话**：差异化定位本质是在数据上做「选择」（选模态、选区域），而共形覆盖在**数据依赖选择 + 区域归属隐藏变量 + 地图静默漂移**下只剩边际保证——一旦边界误判或慢漂移漏检，系统会用错误的区域档案签发「看似 sound」的定位证书；因此 E96（选择性覆盖）、E97（边界）、E98（漂移）必须设为红线，且默认回退到「全局最坏证书 + 单模态 + 保守地图」这条永不失 sound 的底线。

# 第 44 轮产物 · 创新点清单 v21：Semantic-Cert-Atlas × Differentiated-Positioning（SCA × DPE × SDV）× 空间证书闭环（四层架构 v9）

## 2. 关键算法（伪代码）

### IP-60 SCA：图谱编译、边界守护与租约

```
def build_atlas(semantic_map, geo_map, calib_log, alpha, n_min):
    atlas = {}
    for R in partition(semantic_map):                  # 语义分区 R_i
        if not consistency_ok(R, geo_map):             # 定义 49 的 χ
            atlas[R.id] = ContestedRegion(R); continue
        Phi = {}
        for S in modality_subsets(calib_log[R.id]):
            scores = [err(x, S) for x in calib_log[R.id] if has(S, x)]
            n = len(scores)
            # 小样本借力必须显式记协变量偏移，不得假装同分布
            q = (borrow_neighbor(R, S, n, alpha) if n < n_min
                 else rank_quantile(scores, 1 - alpha))
            Phi[S] = Profile(q=q, n=n, health=health_signature(R.id, S))
        atlas[R.id] = Region(
            R=R, s=semantic_class(R), Phi=Phi,
            h=hash_region(R, geo_map, calib_log[R.id], Phi),
            lease=MapLease(tau=now(), eta=eta(R.id), mu=mu_bound(R.id)),
            rho=guard_width(Sigma_max, delta_map(R.id)))
    return SealedAtlas(regions=atlas, root=merkle_root([r.h for r in atlas]))
```

### IP-61 DPE：区域集查询、合法选择与边界回退

```
def query_atlas(atlas, x_hat, Sigma):
    S_hat = conformal_region_set(atlas, x_hat, Sigma, alpha_R)   # 覆盖 1-alpha_R
    if len(S_hat) == 1:
        R = atlas[S_hat[0]]
        mode = "Interior" if outside_band(x_hat, R.rho) else "Transition"
        return ([R], mode)
    return ([atlas[i] for i in S_hat], "Transition")            # 多归属，取最坏

def certified_position(atlas, x_hat, Sigma, theta_task, t):
    cand, mode = query_atlas(atlas, x_hat, Sigma)
    if mode == "Transition":                                    # 边界安全：取 max
        L = max(bound(R, S, t) for R in cand for S in admissible(R, t))
        return Cert(L=L, mode=mode, ok=(L <= theta_task))
    R = cand[0]
    if R.is_contested: return fallback_global(x_hat, Sigma)     # 定义 49
    if drift(R, t) > R.lease.eta or t - R.lease.tau > T_MAP:
        R.mark_contested(); return fallback_global(x_hat, Sigma)  # 定义 48
    S = select_modalities(R, x_hat, theta_task, t)             # 带选择证书
    L = bound(R, S, t)
    return Cert(L=L, mode="Interior", selection=S.cert, ok=(L <= theta_task))

def select_modalities(R, x_hat, theta_task, t):
    healthy = [S for S in R.Phi if health_ok(S, t)]            # 模态健康门
    if FROZEN_PI:                                              # 定义 47(a)
        S = FROZEN_PI[R.s](x_hat)                              # 校准前冻结
        return S.with_cert(pi_hash=hash(FROZEN_PI[R.s]),
                           calib_hash=R.Phi[S].calib_hash, alpha=ALPHA)
    # 定义 47(b)：禁止直接 argmin 分位；用在线共形/e-value 控制长程误覆盖
    return online_conformal_select(R, healthy, x_hat, theta_task, t)

def online_conformal_select(R, healthy, x_hat, theta_task, t):
    # 维护每个候选 S 的可赌过程（capital）；只允许在 capital 支持的选择上投标
    for S in healthy: update_evalue(S, observed_errors[S], t)
    S = pick_with_valid_evalue(healthy, theta_task)            # 无有效者 => 回退全局
    return S.with_cert(pi_hash=hash("online"), calib_hash=R.epoch_hash, alpha=ALPHA)
```

### IP-61/62：漂移监测、一致性验证与边界对抗

```
def drift_monitor(R, t):
    D = max(residual_score(R), scan_map_mismatch(R),
            loop_closure_inconsistency(R), place_novelty(R))
    delta = R.lease.delta0 + R.lease.mu * (t - R.lease.tau)   # 定义 48 膨胀
    if D > R.lease.eta or (t - R.lease.tau) > T_MAP:
        R.invalidate()                                         # -> Contested
    return delta

def consistency_ok(R, geo):
    for clause in CHI:                                         # 定义 49
        if not clause(R.semantics, geo.region(R)): return False
    return True

def boundary_adversarial_audit(atlas, poses):
    used_wrong = 0
    for x_true, x_hat, Sigma in poses:                         # 真值/估计分离
        cand, mode = query_atlas(atlas, x_hat, Sigma)
        cert = certified_position(atlas, x_hat, Sigma, THETA, now())
        ok = cert.mode == "Transition" or contains_truth(cand, x_true)
        used_wrong += (not ok)                                 # 错误档案被使用
    return used_wrong
```

### IP-51/52 升级：区域条件守卫与查表

```
def car_transition_guard(e, x, cert_obj, persona, lease, atlas, t):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    R, mode = query_atlas(atlas, x, cert_obj.Sigma)
    m_lookup = cert_lookup_L0(x, region=R, mode=mode).m_lo[e]
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_cap    = persona_cap[e](persona)
    m_region = max(bound(r, S, t) for r in R for S in admissible(r, t)) \
               if mode == "Transition" else bound(R[0], lease.S, t)
    return min(m_lookup, m_lease, m_cap, m_region) >= theta

def certify_light_v4(x, guards, persona, budget_us, criticality, atlas):
    R, mode = query_atlas(atlas, x, persona.Sigma)
    b = cert_lookup_L0(x, R, mode); lease = acquire_lease(x, mode, criticality)
    U = undecided_guards(b, guards)
    if not U and lease_valid(lease, perimeter(theta), monotonic_now()):
        return b, lease, -1
    if mode == "Transition" or budget_us < 110 or criticality < K_GEOMETRY:
        return downgrade_monotone(b), lease, -1               # 过渡/过载：保守降级
    status, margin = monitor_step_INT8(quantize_obs(x))
    b.m_lo = min(b.m_lo, margin)
    return (b, lease, 0) if not undecided_guards(b, guards) \
           else (downgrade_monotone(b), lease, 0)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 图谱编译 | O(Σ_i Σ_S n_{i,S} log n) 离线 | 区域档案 O(Σ_i |𝕄|) + 哈希 | Merkle 根 ⟹ 档案可溯源、不可静默替换 |
| IP-60 边界守护 | O(log |R|) 空间索引 | 每区域 O(1) | 守护带 + 区域集覆盖 ⟹ 边界不误用错误档案 |
| IP-61 区域条件证书 | O(1) 查表 + O(d) 协方差 | 分位表 O(1) | 区域内可交换 + 选择独立 ⟹ 条件覆盖 ≥1−α |
| IP-61 冻结选择 | O(1) 规则查表 | π 表 O(|Π|) | 预注册 π + 独立校准 ⟹ 覆盖 ≥1−α（Bonferroni 控族错误） |
| IP-61 在线选择 | O(k) 每步更新 | e-value O(k) | 可赌过程 ⟹ 长程误覆盖 ≤α+o(1) |
| IP-61 边界取 max | O(|Ŝ|·|S|) | O(1) | 最坏区域最坏模态 ⟹ 多归属下 sound，保守性显式 |
| IP-62 漂移监测 | O(1) 增量（残差已算） | O(1) 每区域 | 变化率 ≤μ + 检出功效 ⟹ 漏检窗口由 δ(t) 兜底 |
| IP-62 一致性 | O(#χ 谓词) | O(1) | χ 物理健全 ⟹ 违例必为数据错误，拒发 sound |
| IP-62 边界对抗 | O(#pos × 查询) 离线 | 轨迹 O(N) | 覆盖带内/带外 ⟹ 记录错误档案使用次数 |
| IP-51 区域守卫 | O(|E|) 比较 | 同 L0 + 租约 | min(查表, 租约, persona, 区域) ⟹ 无陈旧、无越界放行 |
| IP-52 v4 查表 | O(log N) 定位 + O(|E|) | 表 O(#区域×#模态) | Transition/过载单调降级 ⟹ 只保守不激进 |

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| Winner's curse：按校准集选模态/区域后再定阈值，共形覆盖失效（静默不 sound） | 高 | E96 红线；选择规则校准前冻结或独立数据拆分；在线用 e-value/可赌过程；未持证选择只作排序不作守卫 |
| 边界误判/区域集非唯一，用错区域档案发证 | 高 | E97 红线；区域集共形覆盖；边界守护带 + 迟滞；Transition 取最坏分位 |
| 慢漂移低于检测下限，语义地图静默过期 | 高 | E98 红线；地图租约 δ(t) 随时间膨胀；定期离线重测绘；高漂移区域降为 Contested |
| 校准沙漠：稀疏数据区域覆盖差且被机器人回避，进一步缺数据（自强化） | 中-高 | E102 审计；主动校准 + 邻域借力（记协变量偏移）；按区域报告最小覆盖而非仅平均 |
| 语义-几何矛盾（门变墙、玻璃当实体、动态物刻入静态图） | 中 | χ 谓词联合校验；Contested 触发重定位/重测绘；E99 |
| AtlasEpoch 与 L0 查表版本错位，读到旧区域档案 | 中 | 哈希绑定 + 原子切换；区域切换/续租触发租约重签；总线版本号单调 |
| 区域切换恰好发生在证书选择中途，产生撕裂读 | 中 | 复用 v8 seqlock/epoch 快照；ICV 增交错场景；切换只保守不激进 |
| 台账/哈希开销拖慢边缘端 | 低-中 | 区域档案预编译为只读表；Merkle 校验仅在加载/续租时做；在线只查 O(1) |

## 6. 本轮最大风险

**一句话**：差异化定位本质是在数据上做「选择」（选模态、选区域），而共形覆盖在**数据依赖选择 + 区域归属隐藏变量 + 地图静默漂移**下只剩边际保证——一旦边界误判或慢漂移漏检，系统会用错误的区域档案签发「看似 sound」的定位证书；因此 E96（选择性覆盖）、E97（边界）、E98（漂移）必须设为红线，且默认回退到「全局最坏证书 + 单模态 + 保守地图」这条永不失 sound 的底线。
