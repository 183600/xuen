# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环新周期第 1 轮；本轮灵感：「可重构机构」×「本体感知」）

> 第 66 轮 RAS 把闭环控制从「故障响应」推进到「意图感知」，回答的是「谁该控制、控制多少」。但 RAS 与 VISTA 共享一个从未被质疑的隐含前提：**机器人对自己身体的模型是固定且可信的**。VISTA 的残差归因、RAS 的风险缩放、认证前缀的安全裕度，全部建立在一个静态运动学/动力学模型 ĝ(·; M) 之上。
>
> 本轮灵感正好击穿这个前提：**可重构机构**让 M 本身成为随时间变化的变量（拓扑、连杆、关节类型、耦合约束都可被重写）；**本体感知**则是唯一能在没有外部相机时持续回答「我现在这具身体是什么」的通道。
>
> 核心命题：
>
> **在「故障闭环」（VISTA）与「意图闭环」（RAS）之上补上第三层「自模型闭环」：用本体感知在线辨识可重构机构的当前形态，把「重配置」与「故障」在贝叶斯框架中分离，并在形态后验上构造形态鲁棒的安全证书——记为 RePro（Reconfigurable Proprioceptive Closure）。**
>
> RePro 问的是：「**我这具身体，还是控制器以为的那具身体吗？**」三层闭环由此闭合：VISTA 问「世界是否如我所测」，RAS 问「谁该控制、控制多少」，RePro 问「我是否还是我自己」。

## 0. 直觉与动机

**灵感 1（可重构机构 → 自模型从常量变成隐变量）**
直觉：传统机器人控制里，正/逆运动学模型写在固件里，是常量。可重构机构（模块化关节、可变形连杆、可变拓扑锁定机构）把这个常量变成了**随配置变化的隐变量 M**。于是「标定一次、用一辈子」的范式失效：每一次锁定/解锁/换装，控制器手里的 ĝ 都可能瞬间过期。更关键的是，**旧的故障归因会把「合法的重配置」误判成「故障」**——因为两者在残差上都表现为「模型与观测不符」。

**灵感 2（本体感知 → 唯一连续的自观测通道）**
直觉：视觉看的是世界，本体感知（关节编码器 q、速度 q̇、力矩 τ、IMU）看的是**自己**。它对遮挡、光照、反光免疫，天然适合回答「我的身体此刻是什么结构」。形式化地，本体感知给出一条**逆动力学残差**：
`ε_t = τ_t - ĝ(q_t, q̇_t, q̈_t; M)`。
如果当前形态真的是 M，则 ε_t 是零均值小噪声；如果不是，则 ε_t 会呈现**由结构错配导致的系统性偏置**。这就是「自模型似然」的物理来源。本体感知因此不是「又一路传感器」，而是**自模型闭环的观测量**。

**灵感 3（重配置 vs 故障 → 同一残差，两种时间签名与结构一致性）**
直觉：重配置和故障都会让 ε_t 变大，但它们的「指纹」不同：
- **重配置**：有一个**短促冲激**（锁扣咬合、模块插拔、刚度切换），随后残差被一个新的、自洽的形态 M′ **重新解释**为小残差——「换了个身体，然后一切恢复正常」；
- **故障**：没有可解释它的合法 M′，残差会**持续偏置**或随负载放大——「身体没换，但坏了」。

所以判别器不该只看「残差大不大」，而要看两件事：**(i) 瞬态冲激是否出现；(ii) 是否存在一个结构上合法的 M′ 使整段窗口的残差恢复自洽。** 这把 RePro 的归因从「幅度阈值」升级为「结构一致性检验」。

**灵感 4（主动本体感知 → 用小激励换取自模型信息）**
直觉：静态站立时，许多形态在动力学上**不可区分**（例如两个连杆长度组合在某个姿态下产生相同力矩）。这与第 66 轮「表情识别是主动学习」同构：要最大化 `I(M; z_{t+1} | u)`，就必须**主动施加小幅、安全、信息量大的激励**，让原本不可观测的形态参数在残差中显形。RePro 因此不是被动观测者，而是一个会「扭一扭身体来自我确认」的主动辨识器。

**灵感 5（三闭环合流 → RePro 架构）**
沿用 VISTA/RAS 的时序骨架，插入自模型闭环：
1. **PMS Proprioceptive Morphology Sensor**：采集 (q, q̇, τ, IMU)，在候选形态下计算逆动力学残差；
2. **RCI Reconfiguration-Change Identifier**：检测锁扣/换装的瞬态冲激，输出「可能正在重配置」；
3. **SME Self-Model Estimator**：对离散拓扑用粒子、对连续参数用 Rao-Blackwellized EKF，维护形态后验 p(M | z_{1:t})；
4. **MFA Morphology-Fault Attribution**：把 H_recon（重配置）、H_fault（真故障）、H_proprio（本体感知自身退化）纳入统一归因；
5. **ARI Active Reconfiguration Inquiry**：在结构熵高时，规划小幅激励以最大化 Fisher 信息；
6. **SMG Self-Model Guard**：结构熵 H_self 超过阈值时，封锁不可逆/承载动作；
7. **C-RePro Morphology-Robust Certified Prefix**：认证前缀必须对**形态后验的可信集 ℳ_δ 中所有形态**同时安全；
8. **J_RePro**：证书增补形态后验、结构熵、重配置状态、激励预算与形态哈希。

## 1. 形式化定义（增量：定义 245–260）

- **定义 245（RePro 总览）**：`RePro = (PMS, RCI, SME, MFA, ARI, SMG, C-RePro)`。定位：VISTA 的「故障闭环」与 RAS 的「意图闭环」之上的「自模型闭环」。不变式：本体感知残差、形态后验、归因与证书只走语义流；实时流只做关节级残差、瞬态检测、结构熵门槛与激励安全裁剪，零学习写操作。
- **定义 246（可重构机构状态）**：可重构机构 `M = (G, Λ, J, C)`，其中 G 为拓扑图、Λ 为连杆参数、J 为关节类型（转动/移动/锁定）、C 为耦合约束。形态空间为离散-连续混合：`ℳ = ⋃_{g∈G} ℳ_g`。重配置状态 `r_t ∈ {stable, transitioning, reconfigured}`。
- **定义 247（本体感知观测与残差）**：`z_t = (q_t, q̇_t, τ_t, a_t^{imu})`，逆动力学残差 `ε_t(M) = τ_t - ĝ(q_t, q̇_t, q̈_t; M)`。似然 `p(z_t | M) = N(ε_t(M); 0, Σ_ε(M))`。
- **定义 248（自模型后验）**：`p(M | z_{1:t}, a_{1:t}) ∝ p(z_t | M, a_t) · p(M | z_{1:t-1})`，其中先验在重配置事件后按 `P(M′ | M, r=reconfigured)` 迁移。
- **定义 249（结构一致性判别）**：对窗口 W 定义 `C(M) = Σ_{s=t-W}^{t} ε_s(M)ᵀ Σ_ε^{-1} ε_s(M)`。若 `min_{M′∈ℳ} C(M′) < γ_cons` 且存在瞬态冲激，则判为 `H_recon`；若无任何 M′ 可解释，则判为 `H_fault`。
- **定义 250（瞬态冲激签名）**：`b_t = ||highpass(τ_t, f_c)||²`，锁扣/插拔在 `[f_c, f_s]` 频带产生短时能量峰；`b_t > τ_burst` 且持续 `≤ T_burst` 记为 `reconf_burst = True`。
- **定义 251（结构熵与自模型守卫）**：`H_self(t) = -Σ_M p(M | z_{1:t}) log p(M | z_{1:t})`。守卫规则：`H_self(t) > τ_self ⇒ block_irreversible_actions()`。
- **定义 252（形态鲁棒安全）**：对可信集 `ℳ_δ(t) = {M : p(M | z_{1:t}) ≥ 1-δ}`，前缀 `k*` 需满足 `∀s≤k, ∀M∈ℳ_δ(t): ρ_safe(M, a_s) ≥ 0`。即以**最坏形态**而非 MAP 形态做认证。
- **定义 253（主动自辨识激励）**：`u* = argmax_{u∈𝒰_safe} I(M; z_{t+1} | z_{1:t}, u)`，约束 `||u|| ≤ u_max`、`ρ_safe(M, u) ≥ 0`。以结构 Fisher 信息 `F_M = E[∇_M ε · ∇_M εᵀ]` 近似信息增益。
- **定义 254（重配置过渡相）**：连续参数按 `M_t = (1-α(t))M ⊕ α(t)M′` 迁移，`α(t)∈(0,1)`；安全裕度在过渡相按 Lipschitz 界膨胀：`ρ_safe^trans = ρ_safe - L_M·|α̇|·Δt`。离散拓扑切换在锁扣事件时刻发生。
- **定义 255（本体感知退化故障）**：`H_proprio = {编码器偏置, 力矩传感器漂移, IMU 饱和}`。因本体感知是自模型闭环的唯一输入，必须与外部感知（视觉/触觉）做交叉校验；本体感知失效时 RePro 必须降级为「冻结形态假设 + 保守包络」。
- **定义 256（形态-故障-情绪联合归因）**：在 RAS 的 `ℋ_RAS × E` 上再乘 `{H_recon, H_fault, H_proprio}`，联合后验 `P(H_fault, E, M | ρ, face, z) ∝ p(ρ|H)p(face|E)p(z|M)P(H)P(E|H)P(M)`。
- **定义 257（激励预算）**：主动激励消耗预算 B，分配规则 `argmax Σ_i (期望信息增益_i / 风险成本_i)`，s.t. `Σ cost_i ≤ B`。
- **定义 258（可辨识性）**：称形态参数在轨迹上可辨识，若结构 Fisher 信息 `F_M` 满秩；否则存在不可辨识子空间，需靠主动激励或跨模态先验补足。
- **定义 259（形态不确定性收缩的安全包络）**：`ρ_safe(t) = ρ_0 - κ·H_self(t) - κ′·tr(Σ_M)`，把形态不确定性直接折进安全半径。
- **定义 260（RePro 证书）**：`J_RePro = (J_RAS, M_posterior, H_self, reconf_state, excitation_budget, morpho_hash, morpho_robust_δ)`。`Valid ⇔ Valid(J_RAS) ∧ H_self ≤ τ_self ∧ reeval(ℳ_δ) ∧ (r_t = stable ∨ transition_guard_active)`。

# PMS：本体感知形态传感器
class ProprioceptiveMorphologySensor:
    def residual(self, z, M):
        q, qd, tau, imu, qdd = z
        return tau - inverse_dynamics(q, qd, qdd, M)

    def burst(self, tau_hist, fc=8.0):
        return band_energy(highpass(tau_hist, fc))


# RCI + SME：重配置识别与自模型估计（Rao-Blackwellized 粒子）
class SelfModelEstimator:
    def __init__(self, topologies, n_particles=64):
        self.particles = [(M, 1.0/n_particles) for M in topologies for _ in range(n_particles)]

    def update(self, z):
        for i, (M, w) in enumerate(self.particles):
            eps = proprio.residual(z, M)
            w *= gaussian_likelihood(eps, M.sigma)
            M = ekf_update(M, eps)              # 连续参数逐粒子 EKF
            self.particles[i] = (M, w)
        self._normalize()
        return self

    def posterior(self):
        agg = {}
        for M, w in self.particles:
            key = M.topo_hash
            agg[key] = agg.get(key, 0.0) + w
        return agg

    def entropy(self):
        return -sum(w * log(w) for w in self.posterior().values() if w > 0)


# MFA：重配置 vs 故障 vs 本体感知退化
class MorphologyFaultAttribution:
    def attribute(self, z_win, post_M, burst):
        best = min(post_M, key=lambda M: consistency(z_win, M))
        if burst and consistency(z_win, best) < self.gamma_cons:
            return 'H_recon', best
        if consistency(z_win, best) < self.gamma_cons:
            return 'H_fault', best
        if self.proprio_inconsistent(z_win):
            return 'H_proprio', best
        return 'H_recon', best


# ARI：主动自辨识
class ActiveReconfigurationInquiry:
    def plan(self, post_M, budget):
        cands = small_safe_excitations(post_M)
        scored = [(u, expected_info_gain(u, post_M) / risk_cost(u)) for u in cands]
        chosen = [u for u, s in sorted(scored, key=lambda x: -x[1]) if s > 0][:budget]
        return chosen


# C-RePro：形态鲁棒认证前缀
class MorphologyRobustCertificate:
    def certified_prefix_repro(self, A, post_M, delta, m):
        M_delta = credible_set(post_M, delta)          # ℳ_δ
        k_best = 0
        for k in range(1, min(len(A), m) + 1):
            ok = all(safety_margin(A[k-1], M) >= 0 for M in M_delta)
            if ok:
                k_best = k
            else:
                break
        return k_best, M_delta


# RePro 闭环主循环
def RePro_round(M_sys, obs):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow, z = obs
    M_sys.lsf.update_geometry(P_cloud)
    x_prime = M_sys.lsf.fuse(M_sys.usr.fuse(V, T, P, L))

    # 1) 本体感知自模型闭环
    burst = M_sys.pms.burst(z.tau_hist)
    M_sys.sme.update(z)
    post_M = M_sys.sme.posterior()
    H_self = M_sys.sme.entropy()
    hyp, M_hat = M_sys.mfa.attribute(z.window, post_M, burst)

    # 2) 结构熵守卫 + 主动激励
    if H_self > M_sys.tau_self:
        M_sys.smg.block_irreversible()
        for u in M_sys.ari.plan(post_M, M_sys.budget):
            M_sys.execute_small_excitation(u)
            M_sys.sme.update(M_sys.pms.read())
        post_M = M_sys.sme.posterior(); H_self = M_sys.sme.entropy()

    # 3) 接入 RAS 的故障/情绪归因
    face_gate = M_sys.er.recognize(img)
    A = M_sys.vista.ach.propose(x_prime, H=M_sys.vista.H)
    rho = M_sys.vista.fir.signature(M_sys.vista.stage.split(M_sys.vista.residual_log))
    joint_post, _ = M_sys.efs.synthesize(rho, face_gate)

    # 4) 形态鲁棒证书
    M_delta = credible_set(post_M, M_sys.delta)
    m_ras = min(M_sys.vista.m, M_sys.er.max_m_emotion, M_sys.sme.max_m_morpho)
    k_ras = M_sys.csc_ras.certified_prefix_ras(A, joint_post, m_ras, M_sys.alpha_chunk)
    k_repro, _ = M_sys.csc_repro.certified_prefix_repro(A[:k_ras], post_M, M_sys.delta, m_ras)
    k_star = min(k_ras, k_repro)

    # 5) 风险缩放（形态不确定性折进安全包络）
    lambda_risk = M_sys.efs.risk_scale(joint_post)
    envelope = max(0.0, 1.0 - M_sys.kappa*H_self - M_sys.kappa2*trace_cov(post_M))

    tau_cmd = M_sys.vista.pi_sigma.prefix_dispatch(A[:k_star])
    tau_cmd = tau_cmd * lambda_risk * envelope
    tau_cmd = M_sys.ers.shaping(tau_cmd, joint_post)
    return k_star, M_delta, H_self, hyp, joint_post

## 3. 推导

**引理 11（重配置的可辨识条件）** 对有限拓扑集合 G，若轨迹的结构 Fisher 信息 F_M 在参数子空间上满秩，则自模型后验以指数速率收缩；若存在不可辨识方向 v（F_M v = 0），则该方向的形态误差无法由被动观测消除，必须由主动激励 u* 引入 `vᵀ F_M(u*) v > 0`。直觉：不动就分不清双连杆与单长杆；动一动，力矩指纹就把它们分开。

**引理 12（重配置误报抑制）** 设重配置冲激能量集中在 `[f_c, f_s]`，故障残差主要落在低频。用「瞬态冲激 + 结构一致性」双条件判别，可将重配置诱发的假故障率从 `P(ε>τ)` 降到 `P(ε>τ | no burst, no M′)`，其比值约为 `exp(-(Δf/σ_f)²)`；在 f_c = 8Hz、T_burst ≤ 60ms 时，误报下降一个数量级以上。

**引理 13（过渡相安全）** 过渡相 α(t) 变化率有界 `|α̇| ≤ v_max`。若守卫延迟 `τ_g` 满足 `v_max·τ_g < Δρ/L_M`（Δρ 为当前裕度余量），则任何承载动作都在形态越过安全边界前被封锁。这把「重配置瞬态」变成可证明的安全窗口，而非靠运气。

**定理 11（形态鲁棒证书的正确性）** 若 C-RePro 对可信集 `ℳ_δ` 中所有形态都认证前缀 k*，且真实形态 `M* ∈ ℳ_δ` 以概率 ≥ 1-δ 成立，则执行 k* 前缀的真实安全概率 ≥ 1-δ。证明：由可信集定义，`P(M* ∈ ℳ_δ) ≥ 1-δ`；对每个 M∈ℳ_δ 前缀均安全，故条件于 M*∈ℳ_δ 时安全；全概率即得。

**定理 12（自模型熵与吞吐的权衡）** 令守卫在 `H_self > τ_self` 时封锁不可逆动作。若每轮以预算 B 做主动激励，期望信息增益为 `ΔH(B)`，则期望封锁时长 `E[T_block]` 满足 `E[T_block] ≤ (H_0 - τ_self)/ΔH(B) · T_round`。即：**激励预算把「安全停摆」兑换成可预测的辨识时间**；预算翻倍，停摆期望减半（近似线性）。

**定理 13（联合可分离性的失效边界）** 若本体感知自身退化 `H_proprio` 与形态错配 `H_recon` 的观测协方差非零（例如力矩传感器零漂恰好伪装成连杆长度变化），则联合归因的可辨识度 `κ_repro < min(κ_fi, κ_ri, κ_morpho)`。此时必须引入外部锚点（视觉/触觉）打破退化；否则 RePro 会在一个**自洽但错误**的自模型上给出合法证书——即「自模型幻觉」。

**定义 245（RePro 总览）**
```

```
不变式：本体感知残差、形态后验、归因、证书只走语义流；实时流只做关节级残差、瞬态检测、结构熵门槛与激励安全裁剪，零学习写操作。

**定义 246（可重构机构状态）** 形态 `M = (G, Λ, J, C)`；形态空间 `ℳ = ⋃_{g∈G} ℳ_g`；重配置状态 `r_t ∈ {stable, transitioning, reconfigured}`。

**定义 247（本体感知观测与残差）**
```
ε_t(M) = τ_t - ĝ(q_t, q̇_t, q̈_t; M)
p(z_t | M) = N(ε_t(M); 0, Σ_ε(M))
```

**定义 248（自模型后验）**
```
p(M | z_{1:t}, a_{1:t}) ∝ p(z_t | M, a_t) · p(M | z_{1:t-1})
```
重配置事件后先验按 `P(M′ | M, r=reconfigured)` 迁移。

**定义 249（结构一致性判别）**
```
C(M) = Σ_{s=t-W}^{t} ε_s(M)ᵀ Σ_ε^{-1} ε_s(M)
```
若 `min_{M′∈ℳ} C(M′) < γ_cons` 且有瞬态冲激 → `H_recon`；若无任何 M′ 可解释 → `H_fault`。

**定义 251（结构熵与自模型守卫）**

H_self(t) = -Σ_M p(M | z_{1:t}) log p(M | z_{1:t})
H_self(t) > τ_self ⇒ block_irreversible_actions()
```

**定义 252（形态鲁棒安全）**
```
k* = max k  s.t.  ∀s≤k, ∀M∈ℳ_δ(t): ρ_safe(M, a_s) ≥ 0
```

**定义 253（主动自辨识激励）**

u* = argmax_{u∈𝒰_safe} I(M; z_{t+1} | z_{1:t}, u),  ||u|| ≤ u_max

# IP-234 PMS：本体感知形态传感器
class ProprioceptiveMorphologySensor:
    def residual(self, z, M):
        q, qd, tau, imu, qdd = z
        return tau - inverse_dynamics(q, qd, qdd, M)

    def burst(self, tau_hist, fc=8.0):
        return band_energy(highpass(tau_hist, fc))


# IP-235/236 RCI + SME：重配置识别与自模型估计
class SelfModelEstimator:
    def __init__(self, topologies, n_particles=64):
        self.particles = [(M, 1.0 / n_particles)
                          for M in topologies for _ in range(n_particles)]

    def update(self, z):
        for i, (M, w) in enumerate(self.particles):
            eps = proprio.residual(z, M)
            w *= gaussian_likelihood(eps, M.sigma)
            M = ekf_update(M, eps)            # 连续参数逐粒子 EKF
            self.particles[i] = (M, w)
        self._normalize()
        return self

    def posterior(self):
        agg = {}
        for M, w in self.particles:
            agg[M.topo_hash] = agg.get(M.topo_hash, 0.0) + w
        return agg

    def entropy(self):
        return -sum(w * log(w) for w in self.posterior().values() if w > 0)


# IP-237 MFA：重配置 vs 故障 vs 本体感知退化
class MorphologyFaultAttribution:
    def attribute(self, z_win, post_M, burst):
        best = min(post_M, key=lambda M: consistency(z_win, M))
        if burst and consistency(z_win, best) < self.gamma_cons:
            return 'H_recon', best
        if consistency(z_win, best) < self.gamma_cons:
            return 'H_fault', best
        if self.proprio_inconsistent(z_win):
            return 'H_proprio', best
        return 'H_recon', best


# IP-238 ARI：主动自辨识
class ActiveReconfigurationInquiry:
    def plan(self, post_M, budget):
        cands = small_safe_excitations(post_M)
        scored = [(u, expected_info_gain(u, post_M) / risk_cost(u)) for u in cands]
        return [u for u, s in sorted(scored, key=lambda x: -x[1]) if s > 0][:budget]


# IP-239 C-RePro：形态鲁棒认证前缀
class MorphologyRobustCertificate:
    def certified_prefix_repro(self, A, post_M, delta, m):
        M_delta = credible_set(post_M, delta)      # ℳ_δ
        k_best = 0
        for k in range(1, min(len(A), m) + 1):
            ok = all(safety_margin(A[k - 1], M) >= 0 for M in M_delta)
            if ok:
                k_best = k
            else:
                break
        return k_best, M_delta


# IP-243 RePro 闭环集成
def RePro_round(M_sys, obs):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow, z = obs
    M_sys.lsf.update_geometry(P_cloud)
    x_prime = M_sys.lsf.fuse(M_sys.usr.fuse(V, T, P, L))

    # 1) 自模型闭环
    burst = M_sys.pms.burst(z.tau_hist)
    M_sys.sme.update(z)
    post_M = M_sys.sme.posterior()
    H_self = M_sys.sme.entropy()
    hyp, M_hat = M_sys.mfa.attribute(z.window, post_M, burst)

    # 2) 结构熵守卫 + 主动激励
    if H_self > M_sys.tau_self:
        M_sys.smg.block_irreversible()
        for u in M_sys.ari.plan(post_M, M_sys.budget):
            M_sys.execute_small_excitation(u)
            M_sys.sme.update(M_sys.pms.read())
        post_M = M_sys.sme.posterior()
        H_self = M_sys.sme.entropy()

    # 3) 故障/情绪归因（RAS 前向）
    face_gate = M_sys.er.recognize(img)
    A = M_sys.vista.ach.propose(x_prime, H=M_sys.vista.H)
    rho = M_sys.vista.fir.signature(M_sys.vista.stage.split(M_sys.vista.residual_log))
    joint_post, _ = M_sys.efs.synthesize(rho, face_gate)

    # 4) 形态鲁棒证书
    M_delta = credible_set(post_M, M_sys.delta)
    m_ras = min(M_sys.vista.m, M_sys.er.max_m_emotion, M_sys.sme.max_m_morpho)
    k_ras = M_sys.csc_ras.certified_prefix_ras(A, joint_post, m_ras, M_sys.alpha_chunk)
    k_repro, _ = M_sys.csc_repro.certified_prefix_repro(A[:k_ras], post_M, M_sys.delta, m_ras)
    k_star = min(k_ras, k_repro)

    # 5) 风险缩放 × 形态不确定性包络
    lambda_risk = M_sys.efs.risk_scale(joint_post)
    envelope = max(0.0, 1.0 - M_sys.kappa * H_self
                   - M_sys.kappa2 * trace_cov(post_M))

    tau_cmd = M_sys.vista.pi_sigma.prefix_dispatch(A[:k_star])
    tau_cmd = tau_cmd * lambda_risk * envelope
    tau_cmd = M_sys.ers.shaping(tau_cmd, joint_post)
    return k_star, M_delta, H_self, hyp, joint_post

## 4. 推导

**引理 11（重配置的可辨识条件）** 对有限拓扑集合 G，若结构 Fisher 信息 `F_M` 在参数子空间满秩，则自模型后验指数收缩；若存在不可辨识方向 v（`F_M v = 0`），该方向形态误差无法由被动观测消除，必须由主动激励 u* 使 `vᵀ F_M(u*) v > 0`。直觉：不动就分不清双连杆与单长杆；动一动，力矩指纹把它们分开。

**引理 12（重配置误报抑制）** 重配置冲激能量集中在 `[f_c, f_s]`，故障残差主要在低频。用「瞬态冲激 + 结构一致性」双条件判别，可将重配置诱发的假故障率从 `P(ε>τ)` 降到 `P(ε>τ | no burst, no M′)`，比值约 `exp(-(Δf/σ_f)²)`；f_c=8Hz、T_burst≤60ms 时误报下降一个数量级以上。

**引理 13（过渡相安全）** 过渡相 `|α̇| ≤ v_max`。若守卫延迟 `τ_g` 满足 `v_max·τ_g < Δρ/L_M`，则任何承载动作都在形态越过安全边界前被封锁，把重配置瞬态变成可证明的安全窗口。

**定理 11（形态鲁棒证书的正确性）** 若 C-RePro 对可信集 `ℳ_δ` 中所有形态认证前缀 k*，且真实形态 `M* ∈ ℳ_δ` 以概率 ≥ 1-δ 成立，则执行 k* 的真实安全概率 ≥ 1-δ。证明：`P(M*∈ℳ_δ) ≥ 1-δ`；对每个 M∈ℳ_δ 前缀均安全，条件于 M*∈ℳ_δ 时安全，全概率即得。

**定理 12（自模型熵与吞吐的权衡）** 守卫在 `H_self > τ_self` 时封锁不可逆动作。每轮预算 B 的期望信息增益为 `ΔH(B)`，则 `E[T_block] ≤ (H_0 - τ_self)/ΔH(B) · T_round`。激励预算把「安全停摆」兑换成可预测的辨识时间，近似线性。

**定理 13（联合可分离性的失效边界）** 若 `H_proprio` 与 `H_recon` 的观测协方差非零（如力矩零漂伪装成连杆长度变化），则 `κ_repro < min(κ_fi, κ_ri, κ_morpho)`。此时必须引入视觉/触觉锚点打破退化；否则 RePro 会在自洽但错误的自模型上给出合法证书——即「自模型幻觉」。
