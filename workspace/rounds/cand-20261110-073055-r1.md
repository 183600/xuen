# 第 1 轮 · 双灵感落地 v18：课程即同伦 × 最优控制即课程生成器（「可解性平面」Σ-Plane，四层架构 v6）

> 承接 v17（第 40 轮：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹）。本轮灵感词「最优控制 / 课程学习」。这两个词在文献里常被视为两套工具箱，但本轮的判断是：**它们是同一件事的两个视角**——课程学习最严格的一种解释就是「同伦/延续法」（把难问题拆成一串由易到难的子问题，用前一解热启动后一解）；而最优控制恰好提供「什么叫易、什么叫难、上一解是什么」的严格载体。v17 的两块短板正好卡在这个接缝上：IP-50 的 TO 是**一次性、带硬 deadline 的 iLQR**（在窄通道、接触丰富、精密放置上易陷局部解，超时就整段退回 VLA）；IP-44 的课程是**训练期、手设计的蒸馏阶段**（与运行期脱节，也没有难度定义）。v18 的主轴因此是：**把课程从训练技巧提升为运行期的「可解性路径」，把最优控制提升为训练的「课程生成器与难度评分器」，再以「最优性缺口 Δ」把两边粘成一个可测量的闭环（Σ-Plane，与 v17 的 Δ-Plane 正交）**。

## 0. 联网核实（先事实后推理；口径 2026-11-10，来源见产物区 §5）

- **事实 F67（公开数据比 v17 以为的多，但口径要分清）**：HF 的 `unitreerobotics/unibot-v1-challenge` **collection** 页面可访问，挂出约 30 个 `G1_Dex1_*` 桌面任务（如 HangCup 44 eps、Unlock 87、ZipUp 82、ArrangePlates 115、ArrangeTestTubes 108、OrganizePencilCase 146、SpellRobot 166 等），并关联 `UnifoLM_G1_Dex1_Dataset`（72 items）；但具名 dataset `unitreerobotics/unibot-v1-challenge` 仍返回 401（F61 保留）。**collection ≠ dataset**：可用性/许可/是否与评测同分布必须逐任务核验（A39）。这为 p_s 先验、难度分桶与 OCP 校准提供了真实语料，不再只能「自采」。
- **事实 F68（URDF/MJCF 比 v17 以为的更可得）**：`lerobot/unitree-g1-mujoco` 公开提供 G1 的 MuJoCo 模型仓库，含 Dex1/Dex3/裸机三种配置的 **URDF、MJCF 与 meshes**，Dex3 为 29 body、含 head+双腕相机配置；说明 v17 的 A17（URDF 不可得）可降级为「URDF/MJCF 可得，但**接触/摩擦/惯量仍需与官方评测机标定**（A40）」。TO 的几何/自碰撞门与 MuJoCo 预校验从「条件可行」变为「可开工」。
- **事实 F69（课程学习 = 延续法的理论与新近化）**：Bengio 等 2009 的原始论述已把 CL 视作延续方法（continuation method）；Arora, Wang & Zhang, NeurIPS 2025《When Does Curriculum Learning Help? A Theoretical Perspective》把 CL 严格形式化为延续方法并给出「何时有用」的条件；Pathak & Paffenroth 2025（arXiv 2507.22089）《Principled Curriculum Learning using Parameter Continuation Methods》给出参数延续的课程化训练。**关键限制**：CL 的收益主要出现在非凸、算力/数据受限的情形；在无约束、算力充足的设定里 anti-curriculum/随机顺序可与之相当。
- **事实 F70（同伦在机器人轨迹/操作上已有硬结果）**：Lin 等 ICML 2023（PMLR 202）《Continuation Path Learning for Homotopy Optimization》指出经典同伦对**延续路径/调度极敏感**，并提出学习整条延续路径、支持实时取中间解；DexTrack（ICLR 2025，arXiv 2502.09614）用同伦优化解困难的跟踪问题并生成示教；2025 年窄通道操作工作用「碰撞约束插值」的同伦保证全程可行。→ 同伦不是新概念，但**把它接到「官方 chunk deadline + 有限步数 + 可验证门」上**仍是空白。
- **事实 F71（反向/自动课程已成熟，且必须安全约束）**：Florensa 等 CoRL 2017 的反向课程；RFCL（ICLR 2024，arXiv 2405.03379）反向+前向课程在极少示教下解决高精度任务；Safety-Prioritizing Curricula（ICLR 2025）指出自动课程必须显式约束安全违规；CURATE（ICML 2025 workshop）按能力自适应选任务。→ 反向课程可用，但**难度必须有可计算的定义，且生成器不能生成不安全任务**。
- **事实 F72（系统辨识的主动探索 = 对模型不确定性的课程）**：ASID（ICLR 2024，arXiv 2404.12308）用 Fisher 信息最大的探索策略做操作任务系统辨识；SPI-Active（CoRL 2025）把同样的思想用于腿式 sim2real。→ 这给出了「先辨识什么、后辨识什么」的课程，且与 v17 的 A38（跟踪模型需辨识）直接对接。
- **事实 F73（任意时刻可停与最优停止有现成工具）**：anytime-feasible SQP MPC（arXiv 2401.02194）证明带硬时限的次优 MPC 可保持递归可行；anytime 轨迹修复（IEEE OJITS 2025）给出「任意阶段可返回次优解」的定义；STEP（RSS 2025，arXiv 2503.10966）把策略比较化为近最优停止问题。→ 「按预算截断课程」「按信念阈值升级策略」都有理论脚手架。
- **诚实记录**：F61（具名挑战数据集 401）仍成立；F66 榜单仍未发布（A34 假说）；F68 是 LeRobot 社区模型，不等于官方评测机（A40）；F67 的 episode 数来自 collection 页面摘要，未逐集下载核对（A39）。

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（课程学习不是训练技巧，而是一条从易问题到难问题的连续路径）。** 我最初把「课程学习」理解成训练时先喂简单样本；但 F69/F70 把我纠正了：最严格、最可操作的 CL 定义是**延续法**——解一列问题 \(P(\lambda_0),P(\lambda_1),\dots,P(\lambda_K)\)，\(\lambda\) 从「松弛」走到「真实」，每一级的解作为下一级的热启动。这对 v17 的 IP-50 是致命贴合的：TO 在窄通道/接触/精密放置上失败，本质不是「算得不够快」，而是**非凸 + 病态 + 冷启动差**；同伦恰好就是治这个的。于是本轮第一个动作是：**把课程从训练期搬到推理期**——IP-50 不再是「一次性 iLQR，超时就退回 VLA」，而是「前一级 VLA 解 → 松弛几何 → 加自碰撞/关节限位 → 加跟踪动力学/接触 → 收紧精度」的同伦链，链走到哪里由 chunk 截止期决定。这叫**任意时刻最优控制**：任何时刻停下，都返回当时最好的可行解。

**直觉 2（最优控制是课程的老师，不只是求解器）。** 反过来，OCP 能定义「难度」：一个任务的最优代价 \(J^*\) 越大、约束越紧、间隙越小，它就越难。于是可以用仿真里的 OCP 做三件事：(a) **反向生成课程**——从目标状态向前回溯，按 \(J^*\) 或约束活跃度给状态分难度；(b) **生成专家数据**——精密放置/插入/双臂交接的 OCP 解，经 MuJoCo 门过滤后作为示教，缓解 F61 的数据门控；(c) **给 p_s 先验分桶**——难度桶而不是只按「5 类泛化轴」分桶，使 IP-49 的期望得分更可估。这里最关键的不是「用仿真生成数据」（这很常见），而是**用 OCP 的最优值给任务一个可计算、可复现的难度标尺**。

**直觉 3（缺口 Δ 是 v17 缺的那一个可测量）。** v17 结尾自述最大风险是「热-步数-精度三角退化为三个不可验证的估计量」。本轮的解法不是再估一个量，而是引入一个**能在仿真里算出来的对照量**：给定任务 \(\tau\) 与策略 \(\pi\)，定义最优性缺口 \(\Delta(\pi,\tau)=(J(\pi)-J^*)/J^*\)。它把「策略不行」与「优化器没走到」分开：\(\Delta\) 大、成功低 → 策略表征不够；\(\Delta\) 大、成功高 → 精修还能赚分；\(\Delta\) 小、成功低 → 问题在感知/接触/模型失配；\(\Delta\) 小、成功高 → 该升难度了。**一个标量，四种诊断**——这比 v17 的三个代理估计更接近可证伪。必须诚实：\(\Delta\) 在真机上不可直接观测，只能作为**训练期/仿真期信号与运行时精修触发**，并用真机失败率做校准（E74）。

**直觉 4（课程与控制共享同一根预算轴，所以退化不再是悬崖）。** 官方 chunk 语义意味着每次 `get_action` 有一个天然的时间预算 \(L\)；每个同伦级有成本 \(c_k\) 与收益 \(\Delta J_k\)。于是「走多远的课程」与「花多少算力」是**同一个变量**：\(\Delta\)-Plane 管「有多少预算」，\(\Sigma\)-Plane 管「拿预算去买哪一级问题」。这消掉了 v17 的「TO 成功或整段 fallback」的二元悬崖：预算短 → 停在 VLA 种子；预算中等 → 几何/碰撞级；预算长或可异步 → 走到精度级。更妙的是，动作分块执行期间后台还能继续算下一块的同伦链，所以「时延预算」不必是死墙。

**直觉 5（测试期也有课程：升级策略本身就是最优停止）。** 官方排行榜=成功率+步骤分（F59）。那么一个 episode 内最自然的课程不是「难度递增的任务」，而是**策略阶梯**：直抓 → 换抓取点/重接近 → 推-抓 → 双手协同 → 重新定位 → 放弃。何时放弃当前策略、升级到下一个，是一个带步数成本的**最优停止问题**：继续的期望收益 vs 升级的期望收益 vs 已耗步数。这把 v17 的「失败记忆库：不要原地重试」从一个经验规则升级为**有阈值的策略**，并且直接优化官方指标（而不只是成功率）。这是本轮最「得分导向」的一条线。

**直觉 6（诚实：课程不是免费午餐，且模型保真决定一切）。** F69 明确说 CL 的收益有条件；在算力充足、凸的设定里 anti-curriculum 可能一样好。所以我不把 IP-52 卖成「一定涨点」，而卖成「在数据门控 + 硬 deadline + 非凸接触下，用可验证的难度与可截断的求解换取样本效率」，并用抗课程基线做证伪（E76）。更根本的风险是 F68 只给了几何模型：如果接触/摩擦/跟踪模型不对，\(J^*\)、\(\Delta\) 与同伦路径都会变成仿真器里的自洽幻觉；因此本轮把「模型保真」列为生死线（E77）。

## 2. 灵感词 → 落地线（新增 + 重构 + 修剪登记）

- 「**最优控制**」→ **IP-51 HOMOTOPY-OCP（P0 新增，升级 IP-50）**：把 OCP 写成 \(\lambda\)-族 \(P(\lambda)\)（几何膨胀/接触罚/动力学保真/终端精度/时域长度/信赖域），运行时按「VLA 种子 → 几何可行 → 自碰撞/限位 → 跟踪/接触 → 精度」的延续链求解；每级经 MuJoCo 门与 CBF 验收，**只接受使真实目标 \(J_1\) 下降的级**；任何时刻按 \(L\) 截断，故最坏等于 VLA 种子。与 IP-43 联动：chunk 执行期后台继续跑下一块的同伦；与 IP-48 联动：热/时延预算决定可走级数。
- 「**课程学习**」→ **IP-52 GAP-CURRICULUM（P0 新增，重构 IP-44）**：用 OCP 的 \(J^*\) 定义难度 \(d(\tau)\)、用反向 OCP 可行性生成课程、用最优性缺口 \(\Delta\) 做晋级/降级与诊断；OCP 解经 MuJoCo 过滤后作为精密任务的辅助示教（混合 F67 真实数据）；p_s 先验按「难度桶 × 场景」分桶；训练调度用学习进度/缺口而非固定三阶段。
- 「**两词交叉（测试期）**」→ **IP-53 ESCALATION-STOPPING（P1 新增）**：episode 内策略阶梯的最优停止；信念 \(b_t\)（当前策略能成）由进度/失败签名更新；继续 iff 继续的期望得分 ≥ 升级的期望得分；保证「同类失败不原样重试」，并把步数成本写进停止条件。
- 「**两词交叉（模型侧）**」→ **IP-54 ACTIVE-ID-CURRICULUM（P1 新增，条件启用）**：对跟踪/接触参数做 Fisher 信息最大的安全探索；课程顺序按「参数对任务代价的敏感度 × 不确定度」排；只在低风险阶段/仿真预热期做，不在精密放置阶段探险。
- **横切**：**Σ-Plane（可解性平面）**——坐标是 \((\lambda,\ J^*,\ \Delta,\ \text{escalation state})\)；回答「现在解的是哪一个问题、离最优多远、要不要换问题/升级策略」。它与 Δ-Plane 正交：Δ 管「花多少」，Σ 管「解哪个」。
- 升级：**IP-50**（一次性 TO → 同伦/anytime，接受门保证不劣于种子）、**IP-49**（p_s 按难度桶；E_score 的失败项吃 Δ）、**IP-48**（预算 = min(chunk deadline, 热允许量)，级数入账本）、**IP-44**（三阶段蒸馏 → 缺口课程 + OCP 数据）、**IP-25/46**（把「同伦级完成度」并入 SLO/证书：p99 时延内至少完成几级）、**IP-38**（升级/放弃作为恢复档）、**IP-24**（失败签名接升级阶梯）、**IP-35**（MuJoCo 代理并入 IP-51 的逐级门，不再单列）。
- 修剪登记：**IP-42 跨本体运动 → P2**（单一 G1/Dex1 本体，测试价值近零）；**IP-26 物理增广轴 → P2**（F68 虽给了 URDF，但公开真实数据 + OCP 课程已覆盖多样性，增广边际低）；**IP-35 单列 → 并入 IP-51**（避免两套仿真门）。

## 3. 形式化直觉（严格版见产物区 §3）

**定义 34（课程参数化的 OCP 族）**：令 \(\lambda\in[0,1]^m\)，\(P(\lambda)\) 为
\[
\min_{x_{0:N},u_{0:N-1}}\ J_\lambda=\sum_{t=0}^{N-1}\ell_\lambda(x_t,u_t)+\ell_{T,\lambda}(x_N)
\quad\text{s.t.}\quad x_{t+1}=f_\lambda(x_t,u_t),\ g_\lambda(x_t,u_t)\le 0 .
\]
\(P(0)\) 是松弛问题（膨胀障碍/软接触/运动学/松精度），\(P(1)\) 是真实问题。假设每级存在局部解 \(x^\*(\lambda)\)。

**定义 35（课程=延续调度）**：调度 \(\Lambda=(\lambda_0=0,\dots,\lambda_K=1)\)；成本 \(C(\Lambda)=\sum_k c_k\)，质量 \(Q(\Lambda)=J_1(x_K)\)。若每级热启动落在下一级的收敛域，则称调度**可行**。**课程设计本身是一个最优控制问题**：\(\min_\Lambda \mathbb E[C(\Lambda)]\) s.t. \(\mathbb E[Q(\Lambda)]\le Q_{\max}\)——状态是求解器状态，控制是下一级 \(\lambda\)。这形成了「用最优控制设计课程、用课程解最优控制」的递归；离线可用 DP/学习整条延续路径（F70）。

**定义 36（预算任意时刻同伦）**：给定时限 \(L\) 与级成本 \(c_k\)，取 \(K^\*(L)=\max\{K:\sum_{k\le K}c_k\le L\}\)；边际收益 \(\rho_k=(J_{\lambda_{k-1}}-J_{\lambda_k})/c_k\)，当 \(\rho_k<\rho_{\min}\) 提前停。输出 \(x_{K^\*}\)；由接受门（只收 \(J_1\) 下降且过门者）保证 \(J_1(x_{K^\*})\le J_1(x_{\text{seed}})\)。

**定义 37（难度与缺口）**：任务难度 \(d(\tau)=J^*_1(\tau)/J_{\text{ref}}\)（或分位）；策略 \(\pi\) 的**最优性缺口**
\[
\Delta(\pi,\tau)=\frac{J_1(\pi;\tau)-J^*_1(\tau)}{\max(J^*_1(\tau),\varepsilon)} .
\]
模型失配时用 \(J^*_{\text{sim}}\)，并给**认证缺口** \(\Delta_{\text{cert}}=\Delta_{\text{sim}}+L_J\,\varepsilon_{\text{model}}\)（\(L_J\) 为代价对模型参数的 Lipschitz 常数）。**诊断表**：\(\Delta\) 大/成功低=表征不足；\(\Delta\) 大/成功高=还有精修空间；\(\Delta\) 小/成功低=感知/接触/模型问题；\(\Delta\) 小/成功高=可升难度。

**定义 38（缺口驱动课程）**：训练第 \(t\) 轮在难度桶分布 \(q_t\) 上采样；更新 \(q_{t+1}(b)\propto q_t(b)e^{\eta\,\mathrm{LP}_t(b)}\)（\(\mathrm{LP}\) 为学习进度），并加安全约束 \(q_t(b)=0\) 于违规桶（F71）。晋级：\(\hat s(b)\ge s_{\rm hi}\wedge \overline{\Delta}(b)\le\delta_{\rm hi}\)；降级：\(\hat s(b)<s_{\rm lo}\vee \overline{\Delta}(b)>\delta_{\rm lo}\)。

**定义 39（测试期升级=最优停止）**：策略阶梯 \(s_0\prec\dots\prec s_m\)；信念 \(b_t=\Pr(\text{当前策略最终成功}\mid \text{历史})\)；剩余步数 \(r\)。Bellman：
\[
V_m(b,r)=\max\Big\{ b\,R-(1-b)\,c\,n,\ \max_{s>m}\big[-c_{\rm sw}+\mathbb E[V_s(b',r')]\big]\Big\},
\]
其中 \(R\) 为成功回报（含步骤分 \(g(N)\)），\(c\) 为每步成本。在常风险率与单调似然比条件下，最优策略是 \(b\) 的阈值策略：\(b\ge b^\*(m,r)\) 继续，否则升级。**同类失败不原样重试**由 \(b\) 的更新与阶梯单调性保证。

**定义 40（对偶/主动辨识课程）**：\(\min_{u_{0:T}}\mathbb E[\sum\ell_{\rm task}]+c_{\rm step}T+\beta\,H(\theta\mid y_{0:T})\)，或等价最大化互信息 \(I(\theta;y_{0:T})\)；按参数敏感度 \(s_i=\mathbb E[|\partial J/\partial\theta_i|]\cdot\sigma_i\) 排序，先辨识 \(s_i\) 大者；探索动作受 CBF/任务进度约束。

## 4. 关键决断

1. **课程=同伦**：把 CL 从训练期搬到推理期，IP-50 从「一次性 TO」变成「可截断的同伦链」；接受门保证最坏不劣于 VLA 种子。
2. **最优控制=课程生成器/评分器**：\(J^*\) 定义难度，反向 OCP 生成课程，OCP 解生成精密示教；不再手设计三阶段。
3. **缺口 Δ=唯一诊断量**：用一个可仿真计算的标量替代 v17 的三个不可验证估计；真机只做校准，不做实时 \(J^*\) 声称。
4. **同一预算轴**：Δ-Plane 的时延/热预算直接选 Σ-Plane 的课程深度；退化是连续的，不是悬崖。

### 3.2 IP-51 HOMOTOPY-OCP（课程同伦最优控制，完整设计）

**IP 卡片（六字段）**
- **动机**：v17 的 IP-50 是**一次性 iLQR + 硬 deadline**；在窄通道/接触丰富/精密放置上，冷启动的非凸 OCP 易陷局部解或超时，且超时即整段退回 VLA（悬崖）。F70 证明同伦/延续学习能解这类硬问题；F73 证明 anytime 可行。官方 chunk 语义（F60）正好给出「预算 → 级数」的天然接口。
- **与现有方案差异**：不是「TO 替代学习」，也不是「多阶段蒸馏」（IP-44），而是**推理期的可截断延续求解器**：课程不是训练超参，而是运行时的一条 \(\lambda\) 路径；每一级都是可验证的「更接近真实问题」的 OCP。接受门使最坏情况严格等于 VLA 种子，从而**把 v17 的 TO 风险从「可能变差」变成「只可能不变或变好」**。
- **技术可行性**：F68 提供 G1 的 URDF/MJCF/meshes，几何/自碰撞/可达门可开工（A40 只余接触/摩擦标定）；\(\lambda\)-族的每一级仍是小规模 NLP/iLQR（状态≤21、控制≤20）；F70 的延续路径学习可把级数压到 3–5；MuJoCo 门与 CBF 都是 v17 已有组件。
- **所需资源**：数据=F67 公开任务（约 30 个）做离线 \(\lambda\)-路径与级成本标定；算力=单级 iLQR CPU 毫秒–十毫秒，链总 < 0.5·chunk 窗口（可后台异步）；接口=官方 joint/ee 目标 + chunk，零改造。
- **落地步骤**：① 用 F68 建 MuJoCo 场景与自碰撞/限位门（A40 标定）；② 定义 \(\lambda\) 六轴与默认顺序（A41）；③ 在 F67 任务上测每级成本 \(c_k\) 与收益、训练延续路径（A42）；④ 接 IP-43 后台精修 + IP-48 预算；⑤ E73/E77 验收。
- **风险**：\(\lambda\) 顺序不当 → 级间热启动落在错误盆地（用「可行优先 + 接受门 + 自适应步长」兜底）；接触模型失配 → 精度级不可信（E77 门，退化到几何级）；同伦级数过多 → 超时（预算截断，最坏种子）。

| 1 几何 | 障碍膨胀/物体缩小、无自碰撞 | 精确包络 + 自碰撞 | 窄通道/干扰物 | SQP/gradient |
| 2 运动学 | 忽略关节限位/速度 | 限位+速度+腰/支撑约束 | 可达/奇异/平衡 | QP/iLQR |
| 3 动力学 | 运动学/刚性、无接触 | \(f_{\rm track}\) + 接触/摩擦 | 跟踪误差/接触一致性 | iLQR + 平滑接触 |
| 4 精度 | \(w_P=0,\epsilon=cm\) | \(w_P=1,\epsilon=mm\) | 放置/插入/交接 | iLQR 末段 |
| 5 时域 | 粗分段/短视界 | 全段/密离散 | 长程一致性 | multi-shooting |

> 默认顺序 0→1→2→3→4；级 5 仅在剩余预算充足且长程误差主导时启用。**每一级都必须有独立的 MuJoCo 几何/动力学检查 + CBF**；不通过则停在该级之前。

**算法（预算任意时刻同伦 + 接受门）**
```python
def homotopy_ocp(task, seed, budget, f_track, env):
    # seed: VLA chunk 头或上一块的解（IP-43/IP-50）
    best, J_best = seed, J1(seed, task)
    x = seed
    for k, lam in enumerate(default_schedule(task)):
        c_est = stage_cost[k](task)
        if remaining(budget) < c_est:          # deadline / thermal 预算
            break
        x_try = solve_ocp(P(lam), warm=x, deadline=remaining(budget),
                          f_track=f_track)
        feasible = env.mujoco_gate(x_try, task) and cbf.check(x_try)
        # 接受门：只接受 J1 严格下降且通过可行性者（保证不劣于种子）
        if feasible and J1(x_try, task) < J_best:
            best, J_best = x_try, J1(x_try, task)
        x = x_try if feasible else x           # 热启动用最接近的解
        if marginal_gain(k) < RHO_MIN:         # 边际收益过低，提前停
            break
    return best                                 # 任何时刻均为可行解
```

**任意时刻与后台精修（与 IP-43 的接缝）**：官方 `get_action` 返回 \(T_a\) 步后，评测端顺序执行；在执行当前 chunk 的这段时间里，后端可继续对**下一块**跑同伦链（不占当前调用的时延），于是「预算」实际上是 \(T_a\cdot dt\) 的执行窗口，而不是单次 RPC 的几毫秒。这使 IP-51 的级数上限显著高于 v17 的同步 TO；同时 IP-48 只在热/并发压力下才把后台精修降级。

**正确性论证**
- **P51（无回归/anytime）**：`best` 初始化为 seed，且仅在 `feasible ∧ J1 < J_best` 时更新；因此对任意截断预算 \(L\)，输出 \(J_1(x)\le J_1(\text{seed})\)。故加入同伦**不可能**比 VLA 种子更差（在 \(J_1\) 与门的口径内）。这把 v17「TO 可能伤成功率」的风险消掉。
- **P52（预算单调性）**：级成本 \(c_k>0\)、级序列确定；预算增加只可能多执行若干级，且每级只在改进时更新，故输出质量对 \(L\) 弱单调不降。注意：这是**接受门**给的保证，不依赖同伦路径本身单调；F70 已指出经典同伦对调度敏感，因此我们不假设路径单调，只假设门可靠。
- **P53（热启动降迭代，经验命题）**：若相邻级的解映射 Lipschitz 且 \(x_{k}\) 落在 \(P(\lambda_{k+1})\) 的收敛域，则第 \(k+1\) 级迭代数 ≤ 冷启动；离线用 F67 任务测「级数 vs 冷启动迭代」验证（E73），不达门槛则退化为单级 iLQR（IP-50 原样）。

**复杂度**：状态 ≤ 21、控制 ≤ 20；单级 iLQR \(O(N d^2)\) 毫秒–十毫秒；默认 4 级、学习路径后 3–5 级；总预算 ≈ 0.5·chunk 窗口，超时即停。

**已知风险**：接触/摩擦模型失配使级 3/4 过门但真机失败（E77 门；退化到级 1/2）；\(\lambda\) 路径在窄通道中仍可能卡住（用碰撞约束插值/障碍膨胀的连续 \(\lambda_g\)，F70）；后台精修的线程/显存争用触碰 F60 §6 时延可信度（IP-48 准入 + 单 worker 后台队列）。

### 3.3 IP-52 GAP-CURRICULUM（最优控制生成/评分的课程，完整设计）

**IP 卡片（六字段）**
- **动机**：F61 具名数据集门控，F67 虽给公开任务但分布未必等于评测；v17 的 p_s 没有难度概念，IP-44 的课程是手设计三阶段、与运行期脱节。F69/F71 给出「课程=延续 + 反向生成」的理论与工具；OCP 提供唯一可复现的难度标尺 \(J^*\)。
- **与现有方案差异**：现有自动课程多用「成功率/学习进度/距离」定义难度（F71）；我们**用 OCP 的最优代价定义难度**，并用**最优性缺口 \(\Delta\)** 同时做晋级信号与四象限诊断；把「生成课程—生成示教—评估难度」统一到一个 OCP 教师上，且课程生成受安全约束（F71）。
- **技术可行性**：F67 约 30 任务可做难度分桶；F68 可做反向 OCP 可行性检查；小规模 NLP 在离线可承受；\(\Delta\) 在仿真可算；真实数据只做混合与校准。
- **所需资源**：数据=F67 真实轨迹 + OCP 仿真轨迹 + MuJoCo 过滤；算力=离线 OCP 求解（可并行，非实时）；接口=任务描述/物体位姿（仿真）+ 语言（真实）。
- **落地步骤**：① 在 F67 任务上算 \(J^*\)/难度表（A42）；② 反向课程生成器（A43）；③ OCP 示教 + MuJoCo 过滤 + 混合真实数据训练；④ 缺口调度器与安全桶；⑤ E74/E75/E76 验收。
- **风险**：\(J^*\) 的模型误差 → 难度标尺偏移（E74/E77）；反向生成的课程不安全 → 安全桶硬约束；OCP 示教与真机接触不一致 → 只作辅助/初始化，混合真实数据与域随机化。

**核心：四象限诊断表（把 \(\Delta\) 用起来）**

| 最优性缺口 \(\Delta\) | 成功率 | 诊断 | 动作 |
|---|---|---|---|
| 高 | 低 | 策略表征/优化都不够 | 降难度、加 OCP 示教、先学该技能 |
| 高 | 高 | 优化器没走到最优，仍有精修空间 | 触发 IP-51 精度级、增加 \(w_P\) |
| 低 | 低 | 策略已近最优但仍失败 → 感知/接触/模型失配 | 触发 IP-54 主动辨识、E77 标定 |
| 低 | 高 | 已饱和 | 晋级更难桶 / 减少该桶采样 |

> 这张表是 v18 相对 v17 的核心增量：v17 的三个账本只能告诉你「花了多少」，\(\Delta\) 告诉你「差在哪」。

**难度与反向课程**
```python
def task_difficulty(tau, ocp):
    J_star = solve_ocp(P(1), tau, generous_budget)   # 或强局部最优
    return normalize(J_star, J_ref), J_star

def reverse_curriculum(goal_state, ocp, env, K=6):
    # Florensa 式反向扩张 + OCP 可行性判定（F71）
    levels = {0: [goal_state]}; frontier = [goal_state]
    for k in range(1, K+1):
        cand = sample_backward(frontier, env)        # 可逆动力学/状态重置
        ok = [s for s in cand
              if env.safe(s) and ocp.feasible(s, goal_state, budget=...) ]
        levels[k] = ok
        frontier = ok
        if not ok: break
    return levels                                    # 每级附 J* 难度标签
```

**缺口调度器**
```python
def gap_schedule(q, stats, eta=0.1):
    # 安全优先：违规桶权重置零（F71）
    for b in q:
        if stats[b].violations > 0: q[b] = 0
    # 学习进度加权（F69/F71）
    for b in q:
        q[b] *= exp(eta * stats[b].learning_progress)
    q = normalize(q)
    # 晋级/降级（基于成功率与缺口）
    for b in q:
        if stats[b].success >= S_HI and stats[b].mean_gap <= D_HI:
            q[harder(b)] += promote_mass; q[b] -= promote_mass
        if stats[b].success < S_LO or stats[b].mean_gap > D_LO:
            q[easier(b)] += demote_mass; q[b] -= demote_mass
    return normalize(q)
```

**数据管线（OCP 教师 → VLA 学生）**：`OCP 解 x*_{0:N}` → MuJoCo 过滤（自碰撞/可达/接触稳定）→ 加噪/域随机化 → 与 F67 真实数据按难度桶混合 → LoRA/RARA 微调（F65）→ 用 \(\Delta\) 与成功率评估；**只把 OCP 数据当辅助/初始化，不当唯一真实分布**。

**正确性论证**
- **P54（缺口是模型误差下的有序诊断）**：若 \(J_1\) 对模型参数 Lipschitz（常数 \(L_J\)），则 \(|\Delta_{\rm real}-\Delta_{\rm sim}|\le L_J\varepsilon_{\rm model}/J^*\)；故 \(\Delta_{\rm cert}=\Delta_{\rm sim}+L_J\varepsilon_{\rm model}/J^*\) 是保守上界。它不能保证真机最优，但能在模型误差有界时保持「相对难度排序」不变（E74 验证秩相关）。
- **P55（课程调度的安全可行性）**：安全桶权重为零 + 每桶任务先过 `env.safe`，故生成课程不会把不安全任务送入训练；晋级只在成功率与缺口双达标时发生，避免「虚假晋级」。

### 3.4 IP-53 ESCALATION-STOPPING（测试期升级=最优停止，完整设计）

**IP 卡片（六字段）**
- **动机**：F59 榜单=成功率+步骤分；v17 的失败记忆只规定「不要原地重试」，没有规定**何时换策略**。F73 的最优停止工具正好适配：每次尝试花步数，升级花切换成本，目标是期望得分。
- **与现有方案差异**：现有重试策略多为固定次数/固定顺序；我们把升级建成**信念状态上的最优停止**，阈值随剩余步数与策略先验变化，并把官方步骤分函数 \(g(N)\) 写进回报。
- **技术可行性**：策略阶梯 ≤6；信念由 IP-28v2 进度 + IP-24 失败签名更新；阈值可离线在仿真/公开数据校准（A44）；运行时 O(1)。
- **所需资源**：数据=p_s（按技能×难度桶）+ 各策略的失败率；算力=纯查表/阈值；接口=现有失败监测与动作通道。
- **落地步骤**：① 定义阶梯与切换成本；② 用 F67 数据估计各策略成功率先验；③ 校准 \(b^\*\) 与 \(g\) 两种口径；④ 接 IP-49/24；⑤ E78 验收。
- **风险**：先验偏差 → 过早/过晚升级（用在线贝叶斯更新 + 保守切换）；升级本身耗步 → 把切换成本计入 Bellman；策略阶梯不全 → 保留「放弃并最小化步数」档。

**策略阶梯（默认）**

| 档 | 策略 | 适用失败签名 | 相对成本 |
|---|---|---|---|
| 0 | 直抓/直放（VLA） | 无 | 最低步数 |
| 1 | 换抓取点/重接近 | 抓空、滑移 | +少量步 |
| 2 | 推-抓/拨正 | 物体姿态不可抓 | +中量步 |
| 3 | 双手协同/支撑 | 单臂不可达/需稳定 | +中高 |
| 4 | 重定位（pivot/腰，预算内） | 工作空间边缘 | +高 |
| 5 | 放弃并最小化剩余步 | 证书违约/不可恢复 | 终止 |

**Bellman 与阈值**
\[
V_m(b,r)=\max\Big\{\underbrace{b\,R(n)-(1-b)c\,n}_{\text{继续}},\ \underbrace{\max_{s>m}\big[-c_{\rm sw}+\mathbb E[V_s(b',r')]\big]}_{\text{升级}}\Big\}
\]
其中 \(R(n)=R_{\rm succ}-g(n)\)（成功回报减步骤分惩罚），\(c\) 为每步成本，\(b\) 由进度/失败签名更新。在常风险率与单调似然比下，最优策略为阈值 \(b\ge b^\*(m,r)\)：继续；否则升级。

**算法**
```python
def escalation_policy(belief, m, steps_left, stats, g):
    cont = belief * (R_SUCC - g(steps_used + est_steps)) - (1-belief)*STEP_COST
    best_esc, s_best = -inf, None
    for s in ladder[m+1:]:
        v = -SWITCH_COST + expected_value(s, belief, steps_left, stats, g)
        if v > best_esc: best_esc, s_best = v, s
    return ("continue", m) if cont >= best_esc else ("escalate", s_best)

def update_belief(b, progress_signal, fail_sig):
    # 进度上升 -> b 上升；失败签名命中 -> 按该签名的似然比降 b
    return bayes_update(b, likelihood(progress_signal, fail_sig))
```

**正确性论证**
- **P56（阈值策略存在性）**：在 \(R(n)\) 对 \(n\) 单调减、似然比单调、切换成本常数下，继续的价值对 \(b\) 单调增，升级价值与 \(b\) 无关或更弱，故差函数单交叉 ⇒ 阈值策略最优（Topkis/单交叉论证）。
- **P57（不原样重试）**：阶梯严格上升且失败签名并入 \(b\)，同一 (对象, 技能, 签名) 在 \(b\) 未恢复前不会回到同档；由失败记忆与阈值共同保证，避免 v17 的原地重试浪费。

### 3.5 IP-54 ACTIVE-ID-CURRICULUM（主动辨识课程，P1 条件）

**IP 卡片（六字段）**
- **动机**：F68 给了几何模型，但 A38/A40 的跟踪/接触参数仍需辨识；F72 证明 Fisher 信息探索可用极少真实数据校准仿真。v17 的域随机化是「盲」的，本 IP 用「先辨识高影响参数」的课程替代。

- **技术可行性**：参数维度低（跟踪增益/摩擦/质量/延迟）；Fisher 信息可由仿真轨迹数值估计；ASID/SPI-Active 已验证。

**对偶目标**：\(\min_{u_{0:T}}\mathbb E[\sum_t \ell_{\rm task}(x_t,u_t)]+c_{\rm step}T+\beta H(\theta\mid y_{0:T})\)，或 \(\max I(\theta;y_{0:T})\)；参数排序 \(s_i=\mathbb E[|\partial J/\partial\theta_i|]\cdot\sigma_i\)，先辨识 \(s_i\) 大者。

```python
    if not guard.cbf_check(chunk):
        chunk = resample_or_fallback(state, r=2)
    q_cmd = adapt(chunk, control_space=state.control_space)
    # 5) 失败/进度 → 信念、失败记忆、Δ 诊断（IP-24/28v2/52）
    sig = failure_monitor(obs)
    state.belief = update_belief(state.belief, progress(obs), sig)
    if sig:
        state.gap_mem.log(state.task, state.strategy, sig, state.gap_est)
        state.need_plan = state.need_refine = True
    return q_cmd

# ===== 后台：chunk 执行期继续精修下一块（IP-51×IP-43）=====
def background_refine(state, knobs):
    if knobs.thermal_ok and knobs.bg_slots > 0:
        state.traj = homotopy_ocp(state.next_task, state.current_tail,
                                  budget=knobs.bg_window,
                                  f_track=state.f_track, env=state.env)
```
