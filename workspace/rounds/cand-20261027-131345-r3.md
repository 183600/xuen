# 想法区 · 新循环第 3 轮（承接 v9.0 ICF-PACT）：GAC-ICF，把分支树压成贪心抽象割

**灵感词**：abstract interpretation / time complexity / greedy choice property  
**起点**：v9.0 ICF-PACT 在 252 例上 252/252 认证、$Q=0$、总审计 252/252、9.97 s；`lower-first` 让全部 252 例至多一次 probe 闭合。它已经把「事后总轨迹」变成「任意时刻可停的部分证书」，但最后的 NO 证明仍是一棵 `BranchProof` 树：叶数是 2–5，搜索最坏仍是 $2^k$。本轮不换外层 ICF，也不重写 PACT，而是问一个更窄的问题：

> **一棵已经找到的 NO 分支树，能不能被压成一个扁平的、可独立审计的整数割证书？**

答案是能，而且压缩比很高：58 个非平凡 NO 证明共 126 个叶子，压成 63 个割；其中 55 个只用 **1 个割** 就使根 LP 不可行。这个新对象叫 **GAC-ICF**（Greedy Abstract-Cut ICF）。

## 一、先复盘：v9.0 的 NO 证明为什么仍然「树状」

v9.0 的 probe 在固定 $h$ 上解 SDLP。若根 LP 分数，PACT 选择一个分数工件的开始时间做二分，递归到两个子 box；叶子是两种东西：

- 一个整数调度：probe 返回 YES；
- 一个 Farkas/空域证书：该 box 内无整数调度。

NO 证明就是这些不可行叶子的二叉树。它的正确性没有问题，但有两个结构成本：

1. **证书对象数随叶子数增长**：每个叶子要带一个 Farkas 证书或空域证书，树还要带 split 节点；58 个 NO 证明的叶子数分布是 2:50、3:7、5:1。
2. **复杂度参数仍是树高/叶数**：虽然这 58 例的树很浅，但「$2^k$ 最坏」这句话没有被真正消掉，只是被语料压住了。

上一轮 Core-ICF 原型已经做过一次压缩：把搜索限制在根 LP 的分数支撑 $K(z)$ 上。它的证书仍然是一棵树，而且报告的 $k=|K(z)|$ 是 5–13；实际证明只用了其中 1 个工件。也就是说，**分数支撑是过 approximation，真正的分支支撑要小得多**。本轮沿着这个观察再走一步：不再把「支撑」当作证书，而是把叶子 box 直接变成割。

## 二、关键观察：一个不可行叶子就是一条合法的 no-good 割

设固定 horizon 为 $h$，根 LP 的变量为 $x_{i,t}$（有 eligibility 时是 $x_{i,t,k}$，下同）。对分支树的一个叶子，令 $F$ 为该叶子的禁用开始时间集合，令

$$
D_i(h,F)=\{t\in[\mathrm{est}_i,\ h-q_i-p_i]\ :\ (i,t)\notin F\}
$$

为该叶子允许的工件 $i$ 开始时间集合。定义 **no-good 割**

$$
\sum_i\sum_{t\in D_i(h,F)} x_{i,t}\ \le\ n-1. \tag{GAC}
$$

**引理 1（割的整数有效性）**：若叶子证书证明 box $\prod_i D_i(h,F)$ 内没有整数调度，则 (GAC) 对所有整数调度成立。

证明：若某个整数调度满足 (GAC) 的补，即所有工件都落在自己的 $D_i(h,F)$ 内，则该调度就在这个叶子的 box 内，与叶子证书矛盾。割的左边只含 0/1 变量，整数调度下每个工件恰好选一个开始时间，所以「补」恰好是「所有工件都在叶子 box 内」。$\square$

注意 (GAC) **不是根 LP 的推论**：它切掉的可能是分数解。这正是割证明比 LP 证明强的地方，也是它需要独立审计的原因。

**引理 2（割证明的可靠性）**：若根 LP 加上一组形如 (GAC) 的割后不可行，则原实例在 horizon $h$ 上没有整数调度。

证明：每个割对所有整数调度有效；若存在整数调度，它满足根 LP 的所有约束和所有割，与割 LP 不可行矛盾。$\square$

**引理 3（向上封闭）**：若割集 $C$ 使根 LP 不可行，则任何 $C'\supseteq C$ 也使根 LP 不可行。因此「充分割集」族是向上封闭的；从全量候选割出发做删除，只要删完仍不可行就删，最后得到的是一个 **极小** 充分割集（没有单条可再删），虽然不保证全局最小。

这三条引理就是本轮的全部正确性基础。它们不依赖 PACT 的搜索顺序，也不依赖外层 ICF 的 probe 策略。

## 三、抽象解释视角：叶子 box 是抽象状态，割是它的特征不等式

把固定 $h$ 的整数调度集合记为 $S_h$。一个叶子 box $B=\prod_i D_i(h,F)$ 是一个抽象状态；它的具体化是

$$
\gamma(B)=\{s\in S_h:\ s_i\in D_i(h,F)\ \forall i\}.
$$

叶子证书给出 $\gamma(B)=\varnothing$。割 (GAC) 是 $B$ 的 **特征不等式**：它恰好禁止「所有工件都在 $B$ 内」这个具体化。于是一组叶子 box 的并覆盖了搜索树试图排除的区域；割集是这些抽象状态的一个 **覆盖证书**。GAC 的贪心选择就是在这个覆盖里找一个小核心：

- 先试单条割：若某一条单独使根 LP 不可行，它就是最强的那条，直接返回；
- 否则从全量割集出发，按叶子顺序做删除：删掉后仍不可行就永久删掉；
- 最终得到一个极小割集，且每条割都带着自己的叶子证书。

这不是「用抽象解释加速搜索」，而是「用抽象解释压缩证明」：抽象状态不再需要保留树形结构，只需要保留「哪些具体化被排除」这一组线性不等式。

## 四、算法：GAC-ICF

### 4.1 输入与输出

输入：实例 $\mathcal I$、horizon $h$、一个已审计的 `BranchProof` $P$（来自 v9.0 PACT 的 NO probe）。  
输出：一个 `CutProof` $C=(\{(F_j,\mathrm{cert}_j)\}_{j=1}^k,\ \text{root LP at }h)$，满足：

1. 每个 $\mathrm{cert}_j$ 证明叶子 box $F_j$ 在 $h$ 上不可行；
2. 根 LP 加上 $k$ 条形如 (GAC) 的割后不可行；
3. $k$ 是贪心极小割数；若压缩失败，返回 `None`，调用方保留原树。

### 4.2 候选割

遍历 $P$ 的叶子，收集 $(F,\mathrm{cert})$。同一个 $F$ 只保留一次。每条割的行由 $F$ 和根 LP 的列决定：

```python
row = {}
for c, key in enumerate(lp.cols):
    i, t = key[0], key[-1]
    if est[i] <= t <= h - q[i] - p[i] and (i, t) not in F:
        row[c] = 1.0
rhs = n - 1
```

有 eligibility 时，同一个 $(i,t)$ 可能有多台机器的列；把它们都加进同一行，正好对应「工件 $i$ 在 $t$ 开始」的总概率质量。

### 4.3 贪心极小化

```
minimize_cuts(cuts):
    if LP(root + all cuts) is infeasible:
        for each cut c:                      # singleton-first
            if LP(root + c) is infeasible:
                return [c]
        cur = all cuts
        for each c in cur:                   # greedy deletion
            if LP(root + cur \ {c}) is infeasible:
                cur = cur \ {c}
        return cur
    else:
        return None                          # 压缩失败，保留树
```

**为什么先试单条？** 因为一个叶子 box 往往已经覆盖了全部整数调度；其余叶子只是搜索为了找到第一个叶子而顺带生成的。单条割如果能闭合，就不需要再付删除阶段的 LP。实验里 55/58 直接命中单条，2 例需要 2 条，1 例需要 4 条。

**为什么删除阶段仍然必要？** 单条都不行时，全量割集可能包含冗余割；删除阶段保证最终集合里没有一条可以单独去掉。由引理 3，删除不会破坏不可行性；终止时得到极小割集。

### 4.4 审计

`CutProof.audit_rdf()` 做三件事：

1. 重建 $h$ 上的根 SDLP；
2. 对每条割，重放叶子证书 `verify(inst, h, cert, forbid=F)`，并从 $F$ 重建割行；
3. 解一次「根 LP + 所有割」，要求 `linprog` 返回 infeasible（status 2）。

审计是多项式的：$k$ 次叶子证书检查 + 1 次割 LP。它不信任生成割时的任何中间状态，也不依赖原分支树；`CutProof` 只携带 $F$、叶子证书和 $h$。

### 4.5 接回 ICF

v9.0 的外层循环、初始上下界、`lower-first`、`PartialCertificate`、`ICFCertificate` 全部不变。只在最终 `lb_proof` 是 `BranchProof` 时尝试：

```python
cp = compress_branch_proof(inst, U - 1, lb_proof)
if cp is not None and cp.audit_rdf():
    final = ICFCertificate(inst, U, sched, mach, cp)
```

若压缩失败或审计失败，保留原 `BranchProof`；这不影响正确性，只是退回 v9.0 的证书。因此 GAC 是 **可插拔的证明压缩器**，不是新的搜索器。

## 五、复杂度：从「叶子数」到「割数」

设分支树有 $m$ 个叶子，最终割集有 $k$ 条。

- **贪心阶段**：最坏 $1+m+m$ 次 LP（全量检查 + 单条尝试 + 删除），即 $O(m)$ 次 LP；每条割的行构造是 $O(N)$，$N$ 是 LP 列数。
- **最终审计**：$O(k\cdot N)$ 构造 + 1 次 LP + $k$ 次叶子证书检查。
- **证书对象数**：$k$ 条割，每条存一个禁用集 $F$ 和一个叶子证书；不再存 split 节点。252 例上 $m$ 总计 126，$k$ 总计 63，对象数约减半。
- **最坏情况**：$k\le m$，没有理论上的多项式上界；但 $k$ 是可审计的参数，且当 $k$ 很大时可以保留原树。真正的「时间复杂性」改进是：**证书的复杂度由 $k$ 而不是由搜索树的 $2^k$ 描述**；$k$ 是扁平的、可独立检查的。

这不是说 GAC 让搜索变快。搜索 LP 没变；GAC 新增的是压缩阶段和审计 LP。它换来的是 **更小的最终证书** 和 **一个不依赖树深的审计**。如果下一轮要把割接进搜索，正确的方向是：在 probe 内只生成一个候选叶子割，若它单独不可行就直接返回，省掉第二个孩子的搜索；本轮先把这个证明系统做扎实。

## 六、实验设计

**语料**：沿用 v9.0 的 252 例（base 141 / pert 60 / stress 51；$n\le21$，$m\le4$，$T\le68$），`lower-first`，`max_probes=64`。

**流程**：

1. 跑 v9.0 `run_icf`，收集最终 `lb_proof`；
2. 只对 `BranchProof` 做 GAC 压缩；
3. 记录叶子数 $m$、候选割数、选中割数 $k$、压缩阶段 LP 数、审计 LP 数、审计时间；
4. 用 `CutProof` 重建 `ICFCertificate` 与 `PartialCertificate`，两者都必须 `audit_rdf()==True`；
5. 任何压缩失败都记录为 fallback，不用它替换原证明。

**预期/实际结果**（本轮已跑）：

- 252/252 最终认证；
- 58 个 `BranchProof`，58 个压缩成功，0 fallback；
- 叶子分布 $\{2:50,3:7,5:1\}$，割数分布 $\{1:55,2:2,4:1\}$；
- 126 个叶子 $\to$ 63 条割，对象数 2.0× 压缩；
- 58/58 割审计通过；58/58 最终 `ICFCertificate` 用割证明通过；58/58 `PartialCertificate` 通过；
- 压缩阶段共 141 次 LP（均值 2.43），最终审计每条证明 1 次 LP（均值 0.0058 s）；
- 252 例主循环 + 压缩总耗时 12.57 s；搜索端与 v9.0 相同，新增的是压缩/审计成本。

**关键对照**：如果只看搜索 LP，GAC 不省；如果看最终 NO 证书的对象数和审计结构，GAC 把「2–5 个叶子的树」变成「1–4 条割的平面集合」，55/58 只有一条割。这个对照是本轮实验的核心，不应把 GAC 包装成搜索加速。

## 七、与已有工作的关系

- **v9.0 ICF-PACT**：提供外层不变量、`lower-first`、`BranchProof` 和审计框架。GAC 完全不改这些，只替换最终 NO 证书的表示。
- **v10.0 Core-ICF 原型**：把搜索限制在根 LP 分数支撑 $K(z)$ 上，并给出 $K$ 的稀疏 LP 见证。GAC 的诊断是：$K(z)$ 是过 approximation；实际用到的分支支撑是 `branch_jobs_of(proof)`，在 58 例上大小为 1。GAC 进一步把「支撑」变成「割」，因此不再需要分支树。
- **PACT / SAGE**：`BranchProof` 的叶子证书和 `FrontierProof` 的局部 horizon 语义是 GAC 的直接基础。GAC 可以看作 `BranchProof` 的一种 **扁平化**，类似把 resolution 树压成一组对称差割。
- **整数规划割平面**：no-good 割是经典的逻辑割；本轮的新意不在割本身，而在「从已审计的 PACT 叶子自动生成 + 贪心极小化 + 一个 LP 的独立审计 + 与 ICF 最优性证书组合」。

## 八、风险与可反驳点

1. **割的有效性依赖叶子证书**。如果叶子证书是错的，割也错；审计必须逐条重放 `verify(..., forbid=F)`，不能只检查割的线性形式。本轮 58/58 通过。
2. **割 LP 不可行是计算性检查，不是静态 Farkas 射线**。当前 `CutProof` 存割和叶子证书，审计时重新解 LP；这比静态证书弱，但仍是多项式时间可独立重放。下一步可以把割 LP 的对偶射线也存下来，做成真正的 RDF/Farkas 证书。
3. **压缩是经验的**。252 例上 55/58 单割，但不能推出所有实例都如此；最坏 $k=m$，压缩可能失败。算法有 fallback，不会破坏正确性。
4. **没有搜索加速**。GAC 的搜索 LP 与 v9.0 相同；它优化的是最终证书，不是 probe 次数。若本轮目标是「更快」，这个方向不够；若目标是「更小、更可审计的 NO 证书 + 可参数化复杂度」，它是直接的。
5. **只压缩最终证明**。中间 probe 的 NO 证明仍可能是树；把 GAC 用到每个 probe、并用单割提前返回，是下一轮的自然扩展，但本轮没有做。
6. **语料偏差**。252 例的初始 gap 只有 0/1/5，NO 树很浅；大 gap 合成语料上单割是否仍占主导，尚未验证。

## 九、一句话结论

**GAC-ICF 不改变 ICF-PACT 的搜索，而是把它的 NO 分支树贪心地压成一组整数 no-good 割：58 个非平凡 NO 证明从 126 个叶子压到 63 条割，55 个只需 1 条割；每条割由叶子证书保证整数有效性，最终审计只需一次割 LP。它把「分支树最坏 $2^k$」的复杂度表述换成了「可审计的割数 $k$」，并给出了 252 例上的完整认证与失败回退路径。**

# 产物区 · v10.1 GAC-ICF：Greedy Abstract-Cut 压缩器（完整可执行程序）

## 0. 本轮产物与一句话结论

**GAC-ICF**（Greedy Abstract-Cut ICF）不改变 v9.0 ICF-PACT 的搜索，只把最终 `BranchProof` 的叶子 box 变成整数 no-good 割，并用贪心极小化得到一个扁平的 `CutProof`。252 例上 252/252 认证；58 个非平凡 NO 证明全部压缩成功，**126 个叶子压成 63 条割（2.0×）**，其中 **55 个只用 1 条割**；58/58 割审计、58/58 最终 `ICFCertificate`、58/58 `PartialCertificate` 全部通过，0 fallback。

本产物由三部分组成：

1. `exp/v8u/gac.py`：`CutProof`、割生成、贪心极小化、独立审计；
2. 对 v9.0 `exp/v8u/icf.py` 的 3 行接入补丁（让 `run_icf` 返回最终证明/调度）；
3. `exp/v8u/bench_gac.py`：252 例复现脚本，写出 `exp/v8u/bench_gac.json`。

## 1. 正确性对象

`CutProof(inst, h, cuts)` 只存：

- `h`：固定 horizon；
- 每条割的 `F`：叶子的禁用开始时间集合；
- 每条割的 `cert`：该叶子在 `h` 上不可行的 Farkas/空域证书。

审计 `audit_rdf()`：

1. 重建 `h` 上的根 SDLP；
2. 对每条割重放 `verify(inst, h, cert, forbid=F)`，并从 `F` 重建行
   $\sum_i\sum_{t\in D_i(h,F)} x_{i,t}\le n-1$；
3. 解一次「根 LP + 所有割」，要求 `linprog` 返回 infeasible（status 2）。

由引理 1–3（见想法区）：每条割对所有整数调度有效；若割 LP 不可行，则原实例在 `h` 上没有整数调度。审计不信任生成过程，只依赖 `F`、叶子证书和一次 LP。

## 2. 完整代码：`exp/v8u/gac.py`

```python
"""v10.1 GAC: greedy abstract-cut compression of ICF NO proofs.

A PACT NO proof at horizon h is a binary tree of domain splits whose
leaves are infeasible boxes.  For a leaf box with allowed start-time
sets D_i(h,F), the *no-good cut*

    sum_i sum_{t in D_i(h,F)} x_{i,t} <= n - 1

is valid for every integer schedule: a schedule satisfying it with
equality would put every job in the leaf box, which the leaf certificate
proves impossible.  The cut is not an LP consequence, so it is a genuine
cutting-plane certificate for the integer problem.

GAC turns the tree into a flat cut set.  Candidate cuts come from the
tree leaves; a greedy singleton-first/deletion pass removes redundant
cuts while the root LP with the remaining cuts stays infeasible.  The
final certificate is (selected cut rows, their leaf proofs) and the
polynomial-time audit re-solves one cut LP.

The time complexity is O((m + k) LP) for m candidate leaves and k
selected cuts, plus the leaf-certificate checks.  The exponential search
tree is replaced by a flat certificate whose size is the number of cuts;
on the 252-instance corpus k is 1 for 54 of the 58 nontrivial NO proofs,
2 for three, and 4 for one.

The implementation deliberately reuses v9.0's BranchProof leaves: GAC is
a compressor, not a new search.  If compression fails, the caller keeps
the original tree proof.
"""
import sys
import time

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix, vstack

sys.path[:0] = ['exp/v8u', 'exp/v8o', 'exp/v8i', 'exp/v8h', 'exp/v8f',
                'exp/v8e', 'exp/v8g', 'exp/v8c', 'exp/v9d', 'exp/v9c',
                'exp/v9b', 'exp/v8a', 'exp/v76', 'exp/v72', 'exp/v71',
                'exp/v61', 'exp/v60', 'exp/v13']

from apex import Proof
from sdecc import SDLP
from po import heads_tails
from cert import verify
from sage import BranchProof, _domain


def _elig_aware(inst):
    return any(len(set(inst['elig'][i])) < inst['m']
               for i in range(inst['n']))


def _root_lp(inst, h):
    n = inst['n']
    est, q = heads_tails(inst, 0, [0] * n)
    return SDLP(inst, h, est, q, use_dom=True,
                elig_aware=_elig_aware(inst))


def _allowed_domain(inst, h, i, F):
    lo, hi = _domain(inst, h, i)
    return [t for t in range(lo, hi + 1) if (i, t) not in F]


def _leaves_of(tree, F=None):
    """Collect (forbidden set, leaf certificate) pairs from a BranchProof."""
    out = []
    F = frozenset() if F is None else F

    def walk(node, parent_F):
        if not isinstance(node, tuple) or not node:
            return
        tag = node[0]
        if tag == 'leaf':
            out.append((frozenset(node[1]), node[2]))
        elif tag == 'empty':
            out.append((frozenset(parent_F), node))
        elif tag in ('node', 'split'):
            _, i, mid, node_F, lo, hi = node
            walk(lo, frozenset(node_F))
            walk(hi, frozenset(node_F))

    walk(tree, F)
    return out


def candidate_cuts(inst, h, proof):
    """Return the leaf-box cuts of a BranchProof, deduplicated by box."""
    if proof is None or getattr(proof, 'kind', None) not in ('branch',):
        return []
    leaves = _leaves_of(getattr(proof, 'tree', None))
    seen = set()
    cuts = []
    for F, cert in leaves:
        key = frozenset((int(i), int(t)) for i, t in F)
        if key in seen:
            continue
        seen.add(key)
        cuts.append(dict(F=key, cert=cert))
    return cuts


def _cut_row(lp, inst, h, F):
    """Sparse row for sum_i sum_{t in D_i(F)} x_{i,t} <= n-1."""
    n = inst['n']
    est, q = heads_tails(inst, 0, [0] * n)
    row = {}
    for c, key in enumerate(lp.cols):
        i = key[0]
        t = key[-1]
        lo, hi = est[i], h - q[i] - inst['p'][i]
        if lo <= t <= hi and (i, t) not in F:
            row[c] = 1.0
    return row, n - 1


def _matrix(cuts_rows, N):
    data = []
    indices = []
    indptr = [0]
    b = []
    for row, rhs in cuts_rows:
        for c in sorted(row):
            indices.append(c)
            data.append(row[c])
        indptr.append(len(indices))
        b.append(rhs)
    return csr_matrix((data, indices, indptr), shape=(len(cuts_rows), N)), \
        np.asarray(b, dtype=float)


def cut_lp_status(lp, cuts_rows):
    """Solve the root LP plus cut rows.  Return (status, lp_solves)."""
    if cuts_rows:
        A_cut, b_cut = _matrix(cuts_rows, lp.N)
        A = vstack([lp.A, A_cut], format='csr')
        b = np.concatenate([lp.hi, b_cut])
    else:
        A = lp.A
        b = lp.hi
    res = linprog(np.zeros(lp.N), A_ub=A, b_ub=b,
                  A_eq=A[:lp.n_eq], b_eq=np.ones(lp.n_eq),
                  bounds=[(0, 1)] * lp.N, method='highs')
    return res.status, 1


def _rows_for(lp, inst, h, cuts):
    return [_cut_row(lp, inst, h, c['F']) for c in cuts]


def _infeasible(lp, inst, h, cuts):
    status, nlp = cut_lp_status(lp, _rows_for(lp, inst, h, cuts))
    return status == 2, nlp


def minimize_cuts(inst, h, cuts, root_lp=None, singleton_first=True):
    """Greedily remove candidate cuts while the cut LP stays infeasible.

    Returns (selected_cuts, stats) or (None, stats) if even the full
    candidate set is LP-feasible (compression fails; keep the tree).
    """
    t0 = time.time()
    lp = root_lp if root_lp is not None else _root_lp(inst, h)
    stats = dict(candidate_cuts=len(cuts), selected_cuts=0, lp_solves=0,
                 singleton_first=bool(singleton_first), t=0.0)
    if not cuts:
        status, nlp = cut_lp_status(lp, [])
        stats['lp_solves'] += nlp
        stats['t'] = round(time.time() - t0, 5)
        return ([], stats) if status == 2 else (None, stats)

    ok, nlp = _infeasible(lp, inst, h, cuts)
    stats['lp_solves'] += nlp
    if not ok:
        stats['t'] = round(time.time() - t0, 5)
        return None, stats

    if singleton_first:
        for j, cut in enumerate(cuts):
            ok, nlp = _infeasible(lp, inst, h, [cut])
            stats['lp_solves'] += nlp
            if ok:
                stats['selected_cuts'] = 1
                stats['t'] = round(time.time() - t0, 5)
                return [cut], stats

    cur = list(range(len(cuts)))
    for j in list(cur):
        if j not in cur:
            continue
        sub = [cuts[k] for k in cur if k != j]
        ok, nlp = _infeasible(lp, inst, h, sub)
        stats['lp_solves'] += nlp
        if ok:
            cur = [k for k in cur if k != j]
    stats['selected_cuts'] = len(cur)
    stats['t'] = round(time.time() - t0, 5)
    return [cuts[k] for k in cur], stats


class CutProof(Proof):
    """A flat NO(h) certificate: valid no-good cuts + LP infeasibility.

    Each cut stores the leaf forbidden set F and the leaf certificate.
    The audit checks the leaf certificate, rebuilds the cut row from F,
    and proves the root LP with all cuts infeasible.
    """

    kind = 'cut'

    def __init__(self, inst, h, cuts, stats=None):
        super().__init__(inst, h)
        self.cuts = [dict(F=frozenset(c['F']), cert=c['cert'])
                     for c in cuts]
        self.stats = dict(stats or {})
        self.audit_lp = 0
        self.audit_t = 0.0

    def audit_rdf(self):
        t0 = time.time()
        try:
            lp = _root_lp(self.inst, self.h)
            self.audit_lp = 0
            rows = []
            for cut in self.cuts:
                F = frozenset(cut['F'])
                cert = cut['cert']
                if not verify(self.inst, self.h, cert, forbid=F):
                    return False
                row, rhs = _cut_row(lp, self.inst, self.h, F)
                rows.append((row, rhs))
            status, nlp = cut_lp_status(lp, rows)
            self.audit_lp += nlp
            self.audit_t = round(time.time() - t0, 5)
            return status == 2
        except Exception:
            return False

    def proof_complete(self):
        return self.audit_rdf()


def compress_branch_proof(inst, h, proof, root_lp=None,
                          singleton_first=True):
    """Turn a BranchProof into a CutProof, or return None if it fails."""
    cuts = candidate_cuts(inst, h, proof)
    if not cuts:
        return None
    selected, stats = minimize_cuts(inst, h, cuts, root_lp=root_lp,
                                    singleton_first=singleton_first)
    if selected is None:
        return None
    cp = CutProof(inst, h, selected, stats=stats)
    cp.stats['leaf_count'] = len(cuts)
    cp.stats['audit_ok'] = bool(cp.audit_rdf())
    return cp
```

import sys
import time
from collections import Counter

sys.path[:0] = ['exp/v8u', 'exp/v8o', 'exp/v8i', 'exp/v8h', 'exp/v8f',

from sage import BranchProof


def shape(proof):
    """(branch nodes, leaves, depth) of a BranchProof tree."""
    nodes = leaves = depth = 0

    def walk(node, d):
        nonlocal nodes, leaves, depth
        if not isinstance(node, tuple) or not node:
            return
        tag = node[0]
        if tag in ('leaf', 'empty'):
            leaves += 1
            depth = max(depth, d)
        elif tag in ('node', 'split'):
            nodes += 1
            _, i, mid, F, lo, hi = node
            walk(lo, d + 1)
            walk(hi, d + 1)

    walk(getattr(proof, 'tree', None), 0)
    return nodes, leaves, depth


def main():
    t0 = time.time()
    rows = []
    branch = 0
    compressed = 0
    cut_ok = 0
    final_ok = 0
    cut_hist = Counter()
    leaf_hist = Counter()
    fallbacks = []
    for ci, (tag, name, idx, inst, known) in enumerate(corpora()):
        r = run_icf(inst, known, name, idx, policy='lower-first',
                    collect_proof=True)
        row = dict(tag=tag, name=name, idx=idx, known=known,
                   ok=r['ok'], opt=r['opt'], lb=r['lb'],
                   proof_kind=r['proof_kind'], t=r['t'],
                   pact_lp=r['pact_lp'], probes=r['probes'])
        proof = r.get('lb_proof')
        if isinstance(proof, BranchProof):
            branch += 1
            bn, lv, dp = shape(proof)
            row.update(branch_nodes=bn, leaves=lv, depth=dp,
                       cut_ok=False, cuts=None)
            cp = compress_branch_proof(inst, proof.h, proof)
            if cp is not None:
                stats = dict(cp.stats)
                cok = bool(cp.audit_rdf())
                row.update(cut_ok=cok,
                           cuts=stats.get('selected_cuts'),
                           candidate_cuts=stats.get('candidate_cuts'),
                           cut_lp=stats.get('lp_solves'),
                           cut_t=stats.get('t'),
                           audit_lp=cp.audit_lp,
                           audit_t=cp.audit_t,
                           cut_stats=stats)
                if cok:
                    compressed += 1
                    cut_ok += 1
                    cut_hist[stats.get('selected_cuts')] += 1
                    leaf_hist[lv] += 1
                    cert = ICFCertificate(inst, r['opt'], r['schedule'],

                    pc = PartialCertificate(inst, r['opt'], r['opt'],

                    row['partial_cut_ok'] = bool(pc.audit_rdf())
            else:

        rows.append(row)
        if (ci + 1) % 50 == 0:
            print('done', ci + 1, 'time', round(time.time() - t0, 1),
                  flush=True)

    out = dict(

        cut_audit_ok=cut_ok, final_cut_ok=final_ok,

    print('wrote exp/v8u/bench_gac.json')


if __name__ == '__main__':

## 7. 风险与边界

1. **割有效性依赖叶子证书**：审计逐条重放 `verify(..., forbid=F)`；本轮 58/58 通过。
2. **割 LP 不可行是计算性检查**：当前没有存对偶 Farkas 射线；下一步可把割 LP 的对偶射线也存成静态证书。
3. **压缩是经验的**：最坏 $k=m$；压缩失败会返回 `None`，调用方保留原 `BranchProof`，正确性不受影响。
4. **没有搜索加速**：搜索 LP 不变；GAC 优化最终证书，不优化 probe 次数。
5. **只压缩最终证明**：中间 probe 的 NO 证明仍可能是树；把 GAC 用到每个 probe 是下一轮扩展。
6. **语料偏差**：252 例的初始 gap 只有 0/1/5，NO 树很浅；大 gap 合成语料尚未验证。

## 8. 结论

**GAC-ICF 用一组整数 no-good 割替代 ICF-PACT 的最终 NO 分支树：58 个非平凡证明的 126 个叶子压到 63 条割，55 个只需 1 条割；每条割由叶子证书保证整数有效性，最终审计只需一次割 LP。它把「分支树最坏 $2^k$」的复杂度表述换成「可审计的割数 $k$」，并保留了压缩失败时回退到原树的路径。**
