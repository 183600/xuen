# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「材料选型」×「商业模式」）

> **基线**：上一轮（灵感「演示学习」×「物体泛化」×「碰撞证书」）MetricVoiceGauge-NCD-HUTDH-v19（定义 727–766；引理 143–150；实验 E731–E750）。
> 本轮纪律：**材料是证书参数、商业是证书契约、证据预算是唯一货币**。不推倒 v19：v19 的 DCM/OGCC/CCV/DRS/OGC、v18 的 SAS/影子晋升、v17 的 CLP/S2C/HCG/PSV/APS/AMC、v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v15 的 SCD/DSD/DCA/EDC、v14 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v13 的 USG/TGC/BAA/GAGP/UC、v12 的 HAS/HCC/HATD/HDT、v11 的 NGE/DSL/CC/CWM/CAE/NCP、v10 的 AC/MW/ID、v9 的 DA/SPR/Cal 与历轮不变式全部保留。六个新组件——MCC（材料条件化证书）、MDC（材料域编目）、SLC（服务级证书）、CCP（合同→证书投影器）、CPPO（证书定价组合优化器）、CFW（商业防火墙）——一律以**离线提议、在线零授权**的方式接入 v19 之上；失效即严格退回 v19（引理 157），再沿 v19→v18→v17→v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化链退回。本轮只做三件事：把"材料选型"改写为**证书域选择**、把"商业模式"改写为**可证承诺的承保**、把"成本/收入"改写为**证据预算的两种用途**。

## 0. 直觉与动机

**灵感 1（材料选型 → 材料是证书的参数，不是背景常数）**
直觉：过去所有证书都隐含假设一个固定的机器人本体材料（刚性、干摩擦、无磨损）。但真实系统里，换一个软指尖、换一种涂层、换一根更软的连杆，同一个行为节点的安全域会整体平移。传统做法把材料当"工程选型"离线拍板、把证书当"软件属性"在线验证，二者脱节：材料表写的是标称值，证书用的是上一版标定，安全域在两者之间悄悄漏掉。核心创新：**材料条件化证书（Material-Conditioned Certificate, MCC）**：节点证书从 `NC_n` 升级为 `MC_n(m) = (NC_n, M_n, ε_mat, margin_m, proof)`，只在材料属性 `μ ∈ M_n` 时有效；`M_n` 是使接触稳定、碰撞安全、跟踪有界三类证书**同时成立**的材料可行域。关键反直觉点：**材料选型不是挑"性能最好"的材料，而是挑"证书域与需求分布最匹配、且对材料不确定性最不敏感"的材料**——更硬的材料精度高但安全域窄，更软的材料安全域宽但精度域窄；选型是在**证书 Pareto 前沿**上选点，而不是在性能排行榜上选点。进一步地，我们定义**材料弹性** `ε_mat(n) = −d log vol(M_n) / d log vol(U(m))`：它度量"材料不确定一点，证书域缩多少"，是比材料参数本身更该被优化的量。

**灵感 2（商业模式 → 商业模式是可证承诺的承保，不是证书之外的目标）**
直觉：机器人公司卖的不是"机器人"，而是"在约定环境下、以约定失败率完成某类任务的承诺"。传统商业模式把销售目标与安全证书分开：销售承诺能力、工程事后补救；压力一大就"放宽一点阈值"，于是证书成了商业的橡皮筋。核心创新：**服务级证书（Service-Level Certificate, SLC）+ 合同→证书投影器（Contract-to-Certificate Projector, CCP）**：每份商业合同 `SLA = (任务类 T, 环境分布 D_env, 失败率上界 ε_fail, 延迟上界 L_lat, 材料快照 m_snap)` 必须被投影为一份证书要求 `SLC`，再与当前 `Exec_v20` 求交；投影落空（⊥）则**拒单**，绝不反向放宽证书。关键反直觉点：**商业层是"选择器"而不是"授权器"**——它能做的只有在 `Exec` 内部挑选卖哪些、卖多少钱，永远不能扩大 `Exec` 一个比特；`Sellable ⊆ Exec` 是硬约束。由此，"商业模式创新"被严格限制为三种合法动作：改变**卖哪个子集**、改变**价格**、改变**证据预算的投向**。

**灵感 3（二者统一 → 材料与商业共用一种货币：单位成本的证书覆盖）**
直觉：材料选型决定"买得起多大的证书域"，商业模式决定"哪些证书域值得买"，二者看似两个部门，实则是同一个资源分配问题的两端：**证据预算（材料标定、演示采集、锚点晋升、碰撞验证、磨损监测）是唯一货币**。核心创新：**证书定价组合优化器（Certificate-Priced Portfolio Optimizer, CPPO）+ 证据预算分配器（Evidence Budget Allocator, EBA）**：在材料选择 `σ` 与证据投入 `B` 上最大化 `Cov(σ, D) / Cost(σ, B)`，其中 `Cov` 是需求分布被证书覆盖的测度。关键反直觉点：**最优材料不是性能最优，而是"证书覆盖/成本"最优；最优商业模式不是价格最高，而是"承诺全部可承保"**——收入只是证据预算的来源，不是证书的替代品；把收入当目标会诱导"卖得比能证的多"，而把承保当目标会自然收敛到"只卖能证的"。

**三者如何统一**
统一为 **v19 之上的"证书经济学层"**：v19 回答"给定材料快照，哪些演示衍生计划可安全执行"（`Exec_v19(m*)`），v20 回答"选哪种材料、卖哪些承诺、把证据预算投到哪里，使得可售承诺全部落在 `Exec_v19(m*)` 内"（`Exec_v20`）。MCC 是材料侧（证书参数化），MDC 是编目侧（材料属性与不确定性），SLC/CCP 是合同侧（承诺→证书），CPPO/EBA 是配置侧（材料×证据的最优组合），CFW 是边界侧（商业零授权）。共享状态 `ζ_econ = (material_catalog, m*, sel, sla_book, price_book, evidence_budget, demand_model, drift_def, mode_econ)`。**MCC 回答"这种材料下还能证什么"，MDC 回答"材料属性有多不确定"，CCP 回答"这份合同能不能被证"，CPPO 回答"买哪种材料/投多少证据最划算"，CFW 回答"商业压力能不能越过证书"（永远不能）**。五者不是五个补丁，而是"参数化—编目—承保—配置—边界"的实现链。

## 1. 研究问题（轮次升级版）

- **Q1（材料条件化证书与材料弹性）**：`M_n` 如何从接触/碰撞/跟踪三类证书求交得到？材料属性区间 `U(m)` 与 `M_n` 的关系是"标定盒 ∩ 数据表盒"还是别的？`ε_mat(n)` 如何无偏估计？材料不确定性与证书域体积之间是否存在可证明的单调/凸结构，使选型可解？
- **Q2（材料迁移与切换事务）**：跨材料 `T_{s→t}` 的保守性如何保证？`def_mat ≤ δ_mat` 的独立探针如何避免与源/目标共享同一接触模型盲区？材料切换的在线事务如何保证"切换中只执行旧快照、切换后只执行新快照"？非局部耦合（换材料改变动力学，影响其他节点的缝证书）如何处理？
- **Q3（服务级证书的语义与可测性）**：`CCP` 如何把自然语言/商务条款里的"失败"变成可测事件？任务类 `T` 与环境分布 `D_env` 的覆盖如何量化？`ε_fail` 与证书 margin、校准集分位数如何换算？SLA 不可覆盖时如何给出**最小修改建议**，而不是悄悄放宽？
- **Q4（定价、预算与商业防火墙）**：`Price ≥ Cost + RiskReserve` 如何用一致风险测度（CVaR）实现并估计尾部？`Cov/Cost` 的组合优化在需求漂移下如何稳健？CFW 如何对抗"重定义失败""拆单""跨合同补贴""以量压价"等商业侧规避？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P34）

**P31 材料即证书参数律（Material as Certificate Parameter）**
`MC_n(m)` 仅在 `μ ∈ M_n` 时授权；材料变更而未重认证 ⇒ 证书失效；不存在"材料无关"的证书。任何执行路径在读取节点证书时必须同时校验当前材料快照 `m*` 落在 `M_n` 内，校验失败按证书失效处理（回退，不放宽）。

**P32 材料迁移只收缩律（Material Transfer Only Contracts）**
`M_n(m_t) ⊆ M_n(m_s)`；迁移不得扩张材料域；`δ_mat` 由**异构探针**（解析接触界 + 标定数据 + 对抗采样）给出保守上界；材料切换是**原子事务**：切换期间在线只执行旧快照 `m_s`，重认证/迁移完成前新快照不生效。

**P33 商业无授权律（Commerce Has No Authority）**
`Sellable ⊆ Exec_v20`；`CCP` 落空即拒单；商业层只能**选择子集**、只能**提高价格**、只能**申请证据预算**，不能放宽任何证书、阈值、任务类或失败定义。任何"为拿单而放宽"的请求在 CFW 处被硬拒并留审计。

**P34 风险定价下界律（Risk-Priced Lower Bound）**
`Price ≥ Cost + RiskReserve`，其中 `RiskReserve = CVaR_β(loss | SLA)`；折扣只来自已证 margin，不来自乐观估计；低于下界的合同一律拒签。定价不是营销变量，而是证书的**对偶变量**：证书越薄，价格越高，直到无人购买或证据预算被追加。

## 3. 与基线的接口（如何退化）

- MCC 失效（材料证书服务不可用）⇒ 退回 v19 的"固定材料快照"证书——**等价 v19**；
- MDC 失效（材料编目损坏）⇒ 只允许当前已标定材料，禁止迁移——**等价 v19（活性下降）**；
- SLC/CCP 失效 ⇒ 关闭销售，只执行内部任务——**等价 v19**；
- CPPO/EBA 失效 ⇒ 固定材料、固定证据预算——**等价 v19（配置次优但安全）**；
- CFW 失效 ⇒ **最危险**：立即进入"只读模式"，所有新合同拒绝，只履行已承保合同——**等价 v19 的保守子集**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v19，再沿 v19→v18→v17→v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化；
- **安全继承**：MCC 只缩域、MDC 只保守编目、SLC/CCP 只拒单、CPPO/EBA 只提议不写证书、CFW 只否决。六端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v20 ⊆ Exec_v19(m*)` 由引理 157 保证。

## 4. 预期贡献

1. **材料条件化证书**：首次把材料选型从"工程经验"改写为"证书域选择"，给出材料弹性 `ε_mat`、证书 Pareto 前沿与迁移收缩，使"换材料"从拍板变成可证决策；
2. **服务级证书与合同投影**：首次把商业模式从"销售目标"改写为"可证承诺的承保"，给出 `Sellable ⊆ Exec` 的硬边界与拒单语义；
3. **证书定价与不破产**：用一致风险测度（CVaR）给出定价下界，关闭"为拿单而乐观"的激励，把定价变成证书的对偶；
4. **证据预算统一配置**：把材料采购与证书采集放进同一个 `Cov/Cost` 优化，给出需求漂移下的稳健配置；
5. **商业防火墙**：证明商业压力在任何路径上都不能扩大授权，只能选择子集，且拆单/补贴/定义漂移可审计；
6. **六层分离**：v19 管"演示能挖出什么"，v20 管"用什么材料、卖什么承诺、证据投哪里"，用 `Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18 ⊆ …` 把物理、语言、行为、路线、商业全解耦；E751–E770 覆盖材料证书、迁移、SLA 投影、定价、防火墙、端到端与消融。

## 5. 本轮最大风险

**一句话**：MCC 与 CCP 都依赖一个**稳定且可测的"失败"定义**与**稳定的材料属性快照**；如果商业层能够重定义 SLA 中的"失败事件/任务分布"（合同措辞、拆单、跨合同补贴），或材料在服役中老化/磨损使 `M_n` 漂移，那么系统可以在"证书形式成立、定价形式合规"的前提下**承保一份真实未被覆盖的承诺**——即"证书相对一个由商业控制的定义是可靠的"，而这个定义漂移不被任何证书机制覆盖。

## 0. 核心符号体系（定义 767–806）

| 符号 | 含义 |
|---|---|
| `μ_m = (μ_f, E, ν, c_d, κ_w, ρ_th, …)` | 材料属性向量：摩擦系数、杨氏模量、泊松比、阻尼、磨损率、导热（定义 767） |
| `U(m) = ∏_i [l_i, u_i]` | 材料属性不确定盒：数据表盒 ∩ 标定盒（定义 768） |
| `Θ_n(m) ⊆ Θ_n` | 材料条件化参数域：材料 `μ` 下节点 `n` 的合法参数集（定义 769） |
| `M_n = { μ ∈ U(m) : 接触 ∧ 碰撞 ∧ 跟踪证书同时成立 }` | 材料可行域（定义 770） |
| `MC_n(m) = (NC_n, M_n, ε_mat, margin_m, proof)` | 材料条件化证书（定义 771） |
| `ε_mat(n) = −∂ log vol(M_n) / ∂ log vol(U(m))` | 材料弹性：材料不确定一点，证书域缩多少（定义 772） |
| `T_{s→t}(MC_n)` | 材料迁移算子：源材料证书 → 目标材料证书（定义 773） |
| `def_mat(n) = vol(M_n(m_s)) − vol(M_n(m_t))` | 迁移亏空：材料可行域体积损失（定义 774） |
| `δ_mat(n)` | 异构探针给出的迁移亏空保守上界（定义 775） |
| 迁移接受规则 | `M_n(m_t) ≠ ∅ ∧ vol(M_n(m_t)) ≥ margin_mat ∧ def_mat ≤ δ_mat ∧ CCV(m_t) 通过`（定义 776） |
| `MDC(m) = (prop_box, contact_model, wear_model, sim_cache)` | 材料编目条目（定义 777） |
| `contact_model(m)` | 材料相关接触模型：摩擦锥、粘滑、法向刚度（定义 778） |
| `wear_model(m)` | 材料相关磨损模型：磨损率 `κ_w`、寿命 `T_wear`（定义 779） |
| `sim_mat(m_s, m_t) ∈ [0,1]` | 材料相似度：用于迁移候选排序，不用于授权（定义 780） |
| `T_wear(n, m)` | 节点 `n` 在材料 `m` 下的证书失效时间（定义 781） |
| `σ : TaskClass → Material` | 材料选择映射（定义 782） |
| `D` | 需求分布：任务类 × 环境 × 频次的联合测度（定义 783） |
| `Cov(σ, D)` | 组合覆盖：需求分布中被 `σ` 证书覆盖的测度（定义 784） |
| `Cost(σ, B)` | 组合成本：材料采购 + 标定 + 证据采集 + 磨损监测（定义 785） |
| 材料选择问题 | `max_{σ,B} Cov(σ,D)/Cost(σ,B)` s.t. `Cost ≤ Budget`（定义 786） |
| `SLA = (T, D_env, ε_fail, L_lat, m_snap)` | 服务级协议：任务类、环境分布、失败率上界、延迟上界、材料快照（定义 787） |
| `SLC = (T, D_env, ε_fail, L_lat, fam, margin_sla)` | 服务级证书：SLA 的证书化形态（定义 788） |
| `CCP(SLA) → SLC ∪ {⊥}` | 合同→证书投影器（定义 789） |
| `Sell_v20 = { SLA : CCP(SLA) ≠ ⊥ ∧ CFW.admit(SLA) }` | 可售集（定义 790） |
| `RiskReserve = CVaR_β(loss | SLC)` | 风险准备金：β 尾部的条件风险价值（定义 791） |
| `Price(SLA) = Cost_ev(SLC) + RiskReserve + margin_floor` | 风险定价函数（定义 792） |

# IP-420 Material-Conditioned Certificate：材料条件化证书
class MaterialConditionedCertificate:
    def __init__(self, mdc, ccv, margin_mat):
        self.mdc = mdc
        self.ccv = ccv
        self.margin_mat = margin_mat

    def certify(self, n, m):
        # 1. 取材料不确定盒（数据表 ∩ 标定）
        U = self.mdc.property_box(m)

        # 2. 三类证书在材料维上的可行域求交
        M_contact = self.contact_feasible_domain(n, U)     # 摩擦锥/粘滑/法向刚度
        M_collision = self.collision_feasible_domain(n, U) # 复用 v19 OGCC/CCV
        M_tracking = self.tracking_feasible_domain(n, U)   # 跟踪误差界随刚度/阻尼变化
        M_n = intersect(M_contact, M_collision, M_tracking)
        if M_n is None or volume(M_n) < self.margin_mat:
            return None, 'MCC_EMPTY'

        # 3. 材料弹性：局部对数敏感度
        eps_mat = self.material_elasticity(n, M_n, U)

        # 4. 只在 M_n 上采样式复验（UNKNOWN→UNSAFE，复用 v19 CCV）
        if not self.verify_domain(n, M_n):
            return None, 'MCC_CCV_REJECT'

        return MaterialCert(n=n, M_n=M_n, eps_mat=eps_mat,
                            margin_m=volume(M_n), proof=self.proof(n, M_n)), 'OK'

    def valid(self, mc, mu):
        # 材料参数落在可行域内才授权；否则证书失效（回退，不放宽）
        return mc is not None and mu in mc.M_n

    def material_elasticity(self, n, M_n, U):
        # 有限差分估计 ∂log vol(M_n)/∂log vol(U)
        h = 0.01
        U_hi = inflate(U, 1 + h)
        U_lo = inflate(U, 1 - h)
        M_hi = self.intersect_domains(n, U_hi)
        M_lo = self.intersect_domains(n, U_lo)
        dlog_M = log(volume(M_hi)) - log(volume(M_lo))
        dlog_U = log(volume(U_hi)) - log(volume(U_lo))
        return -dlog_M / max(dlog_U, 1e-12)


# IP-421 Material Domain Catalog：材料编目 + 迁移上界
class MaterialDomainCatalog:
    def __init__(self, contact_lib, wear_lib, delta_probe):
        self.contact_lib = contact_lib
        self.wear_lib = wear_lib
        self.delta_probe = delta_probe          # 异构探针（解析+标定+对抗）
        self.catalog = {}                       # m_id -> MDCEntry

    def register(self, m_id, datasheet, calibration):
        # 数据表盒与标定盒求交：保守取小
        U = intersect_box(datasheet_box(datasheet), calibration_box(calibration))
        contact = self.contact_lib.fit(U)
        wear = self.wear_lib.fit(U)
        self.catalog[m_id] = MDCEntry(U, contact, wear)

    def property_box(self, m_id):
        return self.catalog[m_id].U

    def transfer_bound(self, n, m_s, m_t):

        return self.delta_probe.upper_bound(n, self.catalog[m_s], self.catalog[m_t])

# IP-422/423 Service-Level Certificate + Contract-to-Certificate Projector
class ContractToCertificateProjector:
    def __init__(self, exec_v20, calib, margin_sla):
        self.exec_v20 = exec_v20
        self.calib = calib                  # 已执行 (上下文, 计划, 结局) 校准集
        self.margin_sla = margin_sla

    def project(self, sla, m_star):
        T, D_env, eps_fail, L_lat, m_snap = sla

        # 1. 材料快照必须与在线快照一致；否则拒（不自动迁移）
        if m_snap != m_star:
            return None, 'STALE_MATERIAL_SNAPSHOT'

        # 2. 在 Exec_v20 内找覆盖任务类/环境分布的证书族
        fam = self.cover(T, D_env, self.exec_v20)
        if fam is None:
            return None, 'UNCOVERABLE'

        # 3. 失败上界换算：证书 margin + 校准集分位数 ⇒ 保守失败率
        fail_upper = self.failure_upper_bound(fam, self.calib)
        if fail_upper > eps_fail:
            return None, ('FAILURE_BOUND_EXCEEDED', fail_upper, eps_fail)

                   margin_sla=self.margin_sla), 'OK'

# IP-424 Certificate-Priced Portfolio Optimizer：材料×证据预算 + 风险定价
class CertificatePricedPortfolioOptimizer:
    def __init__(self, mcc, mdc, eba, beta=0.99):
        self.mcc = mcc
        self.mdc = mdc
        self.eba = eba
        self.beta = beta

    def optimize(self, demand, budget, materials):
        best = None
        for sigma in material_subsets(materials):
            for alloc in self.eba.candidate_allocations(budget):
                cost = self.cost(sigma, alloc)
                if cost > budget:
                    continue
                cov = self.coverage(sigma, demand)
                score = cov / max(cost, 1e-9)
                if best is None or score > best.score:
                    best = Config(sigma=sigma, alloc=alloc, cov=cov, cost=cost)
        return best

    def price(self, sla, slc):
        # 证据成本 + CVaR 尾部 + 最小毛利；只提议，不写入证书
        cost_ev = self.evidence_cost(slc)
        reserve = self.cvar_loss(slc, beta=self.beta)
        return cost_ev + reserve + self.margin_floor(slc)

    def cvar_loss(self, slc, beta):
        losses = self.simulate_losses(slc)          # 用校准集 + 尾部模型
        var = quantile(losses, beta)
        tail = [l for l in losses if l >= var]
        return mean(tail) if tail else var


# IP-425 Commercial Firewall：商业零授权
class CommercialFirewall:
    def __init__(self, exec_v20, pricing, drift_max=0.05):
        self.exec_v20 = exec_v20
        self.pricing = pricing
        self.drift_max = drift_max
        self.audit = []

    def admit(self, sla, slc, price):
        # 1. 证书必须存在且严格属于 Exec
        if slc is None:
            return self._reject(sla, 'NO_CERTIFICATE')
        if not self.subset_of_exec(slc, self.exec_v20):
            return self._reject(sla, 'OUTSIDE_EXEC')

        # 2. 定价下界：不得低于 成本 + CVaR 准备金
        if price < self.pricing.price(sla, slc):
            return self._reject(sla, 'UNDERPRICED')

        # 3. 失败定义漂移：SLA 的失败事件必须与校准集定义一致
        if self.definition_drift(sla) > self.drift_max:
            return self._reject(sla, 'DEFINITION_DRIFT')

        # 4. 拆单/补贴检测：单合同失败上界不得低于组合分摊
        if not self.no_split_arbitrage(sla):
            return self._reject(sla, 'SPLIT_ARBITRAGE')

        # 5. 任何"放宽证书"请求一律拒绝（零授权）
        if sla.request_relax:
            return self._reject(sla, 'RELAX_FORBIDDEN')

        self.audit.append(audit_entry(sla, slc, price))
        return True, 'ADMITTED'

    def _reject(self, sla, reason):
        self.audit.append(audit_entry(sla, None, None, reason))
        return False, reason

## 3. 推导

**引理 151（材料条件化证书可靠性）** 设 `MC_n(m)` 由接触、碰撞、跟踪三类证书的材料可行域求交构造，且 `μ ∈ M_n`。则 `NC_n` 在材料 `μ` 下成立。证明：接触证书保证摩擦锥内稳定、碰撞证书（复用 v19 CCV）保证零碰撞、跟踪证书保证误差有界；`M_n` 定义为三者可行域的交，故 `μ ∈ M_n ⇒ 三者同时成立 ⇒ NC_n`。`verify_domain` 的 `UNKNOWN→UNSAFE` 保证采样盲区不被乐观放过。∎ 推论：**材料条件化证书不会比其最弱的分量证书更强**。

**引理 152（材料迁移非扩张）** 设 `M_n(m_t) = M_n(m_s) ∩ U(m_t)`，`def_mat = vol(M_n(m_s)) − vol(M_n(m_t)) ≤ δ_mat`，且 `CCV` 在 `M_n(m_t)` 上全通过。则 `Auth(MC_n(m_t)) ⊆ Auth(MC_n(m_s)) ∩ U(m_t)`，进而 `Exec_v20(m_t) ⊆ Exec_v19(m_s)`。证明：交集天然收缩；独立异构探针保证亏空上界不被低估；CCV 在收缩域复验排除近似构造的盲区（在采样覆盖范围内）。故目标材料授权是源授权与目标材料不确定盒的子集。∎ 推论：**迁移只能让系统"在更少材料参数下做同一件事"，永远不能"做新事"或"在更多材料参数下做旧事"**。

**引理 153（材料切换事务原子性）** 材料切换 `switch(m_s → m_t)` 在重认证/迁移完成前不改变在线快照 `m*`；在线执行始终读取 `m*`；切换成功后新快照只包含经 MCC 重认证或迁移收缩的节点。则切换期间 `Exec_online ⊆ Exec_v19(m_s)`，切换后 `Exec_online ⊆ Exec_v19(m_t)`，不存在"半旧半新"的中间态。证明：`m*` 是单写者原子变量；`switch` 在影子侧完成全部证书构造后才提交 `m*`；执行侧只读 `m*`。故任一时刻执行证书都对应同一材料快照。∎ 推论：**材料切换的失效模式是"切换失败、保持旧快照"，而不是"切换到一半"**。

**引理 154（服务级证书保守性）** 若 `CCP(SLA) = SLC ≠ ⊥`，则存在覆盖证书族使真实失败率 `≤ ε_fail` 且延迟 `≤ L_lat`；即 `SLA ∈ Sell_v20 ⇒ SLA 可被 Exec_v20 覆盖`。证明：`CCP` 的覆盖查找只从 `Exec_v20` 取证书族；失败上界由证书 margin 与校准集分位数联合给出，任一不满足即返回 ⊥；延迟上界复用 v17 APS 的 p99 证书。故非 ⊥ 蕴含覆盖。∎ 推论：**`Sell_v20 ⊆ Exec_v20`；拒单不是失败，而是证书的诚实表达**。

**引理 155（商业防火墙零授权）** CFW 的 `admit` 只做五类检查（证书存在、子集、定价下界、定义漂移、拆单/放宽），任一失败即拒绝；系统中不存在从商业请求到证书写入的路径。则 `|NewAuth| = 0` 且 `Sell_v20 ⊆ Exec_v20`。证明：CFW 位于商业层与执行层之间，是唯一入口；`request` 的四种形态（放宽/改价/追加预算/拆单）中，放宽被硬拒、改价受下界约束、追加预算只进 EBA、拆单被分摊检测；均不触及证书。∎ 推论：**商业压力只能改变"卖不卖"，不能改变"能不能"**。

**引理 156（风险定价不破产）** 若每份合同 `Price ≥ Cost_ev + CVaR_β(loss | SLC)`，损失有界，则任意合同组合的期望净收益 `≥ 0`，且以概率 `≥ 1−β` 不耗尽准备金（在 CVaR 估计准确的前提下）。证明：CVaR 是一致风险测度，满足单调、次可加、正齐次、平移不变；逐合同下界经次可加性传递到组合；准备金覆盖 β 尾部。∎ 推论：**定价不是营销变量而是证书的对偶变量；薄证书只能高价，否则拒签**。

**引理 157（v20 整体安全继承）** 在材料快照 `m*`、材料编目快照、证据预算快照固定时，`Exec_v20 ⊆ Exec_v19(m*)`。证明：MCC 只缩域（引理 151/152），MDC 只保守编目，材料切换原子（引理 153），CCP 只拒单（引理 154），CFW 零授权（引理 155），CPPO/EBA 只提议不写证书。六端口复合只能产生 `Exec_v19(m*)` 的子集。∎

## 7. 已知风险与失效模式

1. **材料属性不确定盒偏乐观**：数据表给的是标称值、标定样本少，`U(m)` 可能低估真实散布，导致 `M_n` 偏大、`μ ∈ M_n` 误判。缓解：数据表盒与标定盒取交、贝叶斯区间、批次抽检、保守 margin_mat。
2. **接触/磨损模型的 sim-to-real 鸿沟**：摩擦锥、粘滑、法向刚度、磨损非线性在仿真里被简化，`M_n` 在真实接触下不成立。缓解：在线接触辨识、摩擦锥膨胀、磨损在线监测、异构接触模型集成。
3. **材料迁移的非局部耦合**：换材料改变整机动力学，可能影响**其他节点**乃至**缝证书**，而 MCC 只逐节点验证。缓解：迁移后全链缝证书复验、耦合敏感度分析、迁移影响半径估计。
4. **材料时变（老化/磨损/温漂）**：`M_n` 随服役漂移，证书"签发时成立、执行时不成立"。缓解：`T_wear` 硬到期、在线材料状态估计、证书 TTL 与材料监测联动、到期强制重认证。
5. **需求模型/商业预测误差**：`D` 估计偏差导致材料与证据投向错误——通常只损活性（少卖），但若与定价交互可能放大尾部。缓解：在线需求估计、稳健优化、预算预留。
6. **SLA "失败"定义不可测/可重定义**：合同措辞可把失败定义为"可观测但不可归因"的事件，或把失败转移到客户侧，导致 `ε_fail` 形式合规而真实承诺未覆盖。缓解：失败事件形式化 schema、定义版本锁、审计轨迹、定义漂移检测。
7. **商业防火墙的组织性绕过**：CFW 是代码，但销售 KPI、合同措辞、拆单、跨合同补贴可能从**定义层**绕过。缓解：定义变更需双人审批、拆单分摊、跨合同审计、红队演练、销售权限隔离。
8. **证据预算饥饿**：预算不足 → 影子锚不晋升、材料不标定、可售集塌缩；若为保收入而削减证据，长期安全边际被侵蚀。缓解：预算下界、证据预算与收入解耦、活性/安全双监控。
9. **CVaR 尾部估计误差**：厚尾、样本少、损失不可观测时 `RiskReserve` 低估，导致系统性低价。缓解：极值理论、情景分析、准备金上限、压力测试。
10. **材料选择与业务组合的组合爆炸**：材料子集 × 证据分配 × 合同组合可能极大，`Cov/Cost` 优化不可解。缓解：分层优化、贪心+局部搜索、相似材料聚类、按需重优化。
11. **多合同风险相关性**：合同并非独立（同一材料/环境/任务族），CVaR 次可加但估计难，组合尾部可能被低估。缓解：相关性建模、共同因子压力测试、组合级准备金。
12. **审计轨迹不完整**：事后无法归责"证书为何成立、价格为何合规"，导致组织学习失效。缓解：全链路审计、不可篡改日志、定义版本与材料快照绑定。

## 8. 本轮最大风险

**一句话**：MCC 的 `M_n` 与 CCP 的 `SLC` 都相对于两个**上游定义**成立——材料属性快照（供应商数据 + 标定）与 SLA 的"失败事件/任务分布"（合同措辞）；若材料在服役中老化/磨损使 `M_n` 漂移，或商业层通过拆单、跨合同补贴、重定义失败把承诺挪出校准集，则系统会在"证书形式成立、定价形式合规、CFW 形式通过"的前提下**承保一份真实未被覆盖的承诺**——即"证书相对一个由上游控制的定义是可靠的"，而这个定义漂移是 v20 所有证书机制共同的、未被覆盖的盲区。
