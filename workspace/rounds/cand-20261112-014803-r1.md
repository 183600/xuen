# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「多机评测」×「双臂协作」）

> 第 57 轮把证据承诺升级为"少样本可校准、跨模态可对账、个性化有界"，但它仍隐含三个**单机、单体、单源**假设：证据归属于采集它的那台机器人、跨模态与跨源独立性被当作声明、人类信任只按操作者个体结算。本轮两个灵感恰好从两个方向撕开这些假设：**多机评测**把"更多机器"摆上桌——看起来是 N 倍独立佐证，实则近克隆车队共享批次、固件、站点、基座与操作者，"多机"很容易退化为"一台机器戴 N 张面具"；同时跨机复用证据还藏着一个从未被认证的**实施例不变性**假设（A 机探的区域，B 机凭什么敢踩）。**双臂协作**则把"更多肢体"摆上桌——看起来是冗余互检，实则两臂共享基座、时钟、感知与控制器，恰恰在耦合最紧处独立性最弱，一次共模错误会让两条手臂"自信地一起错"；而耦合又让单臂失效沿任务约束级联到整机。于是本轮的核心命题从"证据说可信"再升一级为 **"可移植、共模可计、耦合可退化的团队证据说可信"**：证据必须先证出处可移植（FET），跨源一致必须先扣掉共模成分（CMR），双臂承诺必须在耦合不成立时退回保守单臂（DAC），多机评测必须对"伪独立"报警（FEP）。

核心矛盾：
- **H29（多机评测 ≠ 多机独立）**：车队级一致看起来是天然的交叉验证，但同批/同固件/同站点的机器误差高度相关；把 N 台近克隆机器的同意当成 N 份证据，会制造"评测越多越自信、校准越差"的逆火。评测协议若不做共模聚类，本身就是一台伪独立放大器。
- **H30（双臂协作：冗余还是共谋）**：协作提供单臂不可及的能力（支撑、交接、内力闭合），其安全论证却依赖两臂的独立佐证；而共享基座/感知让两臂的残差同向，耦合越紧、任务越难、越需要独立佐证时，独立性恰恰最弱。协作把能力与共模风险捆绑销售。
- **H31（可移植证据 vs 责任归属）**：复用他机证据省掉现场探询，却把失效原因迁移到一台不在场的机器上：谁标定漂了、谁磨损了、哪批固件有问题？没有出处与转移证书的"共享地图"实为责任真空，也让"坏证据长寿"升级为"坏证据跨机传染"。

## 0. 直觉与动机

**灵感 1（多机评测 → 从离线基准到在线互评审计）**
直觉：传统"评测"是一次性、集中式、离线跑分；而车队里最便宜、最贴近部署分布的评测者不是评测台，而是**另一台机器人**。让机器互相在对方声称的区域上做盲化重评，评测就从"发榜"变成"持续审计"：A 说这块能走，B 蒙住 A 的结论自己去走一遍。这样评测直接进入承诺回路，且能持续抓标定漂移与磨损。但互评只有在审计者与声称者**不共享同一套错误**时才叫独立——于是评测协议的第一等公民不是分数，而是**共模簇**。

**灵感 2（多机评测的暗面 → 近克隆车队的伪独立）**
直觉：十台同批采购、同固件、同场地、同一操作班组的机器人，对一个区域的判断会高度一致——这不是因为它们各自独立验证了世界，而是因为它们共享同一个"世界观"。这与第 57 轮"同一模态问五遍"是同一错误的放大版：**同一潜因子问十台机器**。所以"多机一致"必须过一道折扣：先估计这批一致里有多少来自共享潜状态，只有超出共享成分的私有残差才计数。多机评测的价值不在"多"，而在"异构"。

**灵感 3（双臂协作 → 能力耦合与共模退化）**
直觉：双臂不是两台小机器人拼在一起。共享基座把它们变成一个有公共自由度的耦合体：一臂为另一臂提供支撑与反力，交接时两臂必须同时到位。能力因此倍增，但安全必须按**联合约束**结算：σ_L 安全 ∧ σ_R 安全 ∧ 耦合不变量 Φ_c 成立，三者缺一即整体不安全。更关键的是，共享基座/时钟/感知使两臂的"一致"极可能来自同一个错误源——双臂互检在耦合最紧处最不可信。因此双臂协作的正确姿态不是"互相担保"，而是"**耦合可行则联合承诺，耦合失效则保守退化，一致只在扣除共模后才算佐证**"。

**灵感 4（两灵感合流 → 共模残差分解 CMR：把"独立性"从声明变成可计算的折扣）**
直觉：前几轮把独立性当作一个 Bool——要么声明独立（EV-xmodal），要么不独立。但真实世界是连续的：两源总有一点共享、也总有一点私有。CMR 把观测写成 o=g(s,η)，显式建模共享潜 s，用**私有残差在共享子空间正交补上的投影**来计数有效独立源 k_eff。这样"多机一致""跨模态一致""双臂一致"共享同一把尺子，且这把尺子只会让佐证**变少**、绝不会凭空变多——延续第 56 轮以来的交互单调性。

**灵感 5（TCE → 移植、互评、耦合全部只经两条安全通道）**
直觉：三个新机制都只通过两个通道影响系统——**(a) 让信念更保守（转移加宽、共模折扣、耦合违约即退化）**；**(b) 让动作更保守（无证书即现场重探、伪独立即拒绝、双臂退化单臂或停）**。它们都不允许"因为别的机器/另一条手臂说安全，所以更敢赌"。尤其不可逆接触，永远只认本机实证与耦合认证，团队一致只能用于非不可逆层。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（共模残差分解 CMR）** 观测生成模型 o_e=g_e(s,η_e)，e=(源,时刻)，s 为共享潜状态（基座位姿/IMU 偏置/时钟漂移/环境真值/批次与固件），η_e 为源私有噪声。对源集合 S，共模系数 γ_cm(i|S)=Cov_s 解释的方差占 Cov(o_i,o_{S\i}) 的比例，附估计误差 ε_cm。**有效独立计数** k_eff(S)=1+Σ_{i∈S}[(1−γ_cm(i|S))·1{Π_{s^⊥}r_i≠0}]_+；独立性权重 w_ind(S)=clamp(k_eff(S)/|S|,1/|S|,1)。规则：(C1) 一切"一致即证据"（EV-xmodal/peer/joint）必须乘 w_ind，禁止按原始源数计；(C2) γ_cm>θ_cm ⇒ 佐证权重塌缩为 1（等价单源），只可作"排除操作失误"的同源复核，不得提升置信；(C3) 共享潜因子集必须显式登记，未登记成分记为 γ_unk 并直接计入风险上界。

**定义 140（跨机证据移植 FET）** 机器指纹 e_r=(传感器批号,H_calib,磨损态,固件 hash,运动学参数)。证据带出处 π_e=(r,e_r,站点 c,t,标定版本)。转移残差 δ_{m→n}(c)=E[|θ̂_m−θ̂_n||c]。**转移证书** T_{m→n}(c) 成立 ⇔ (i) 以指纹相似度 ω_{m→n} 为权重的加权共形覆盖 ≥1−α_tr；(ii) 目标机在锚集 A_c（≥n_anchor 个已测区域）重探，源标签落在容差 ε_a 内；(iii) 有效样本量 ESS≥N_min（否则判无重叠、拒绝移植）。无证书的复用只能进 L0/L1 且后验强制加宽 Δ_tr；**不可逆接触必要证据集永不含 EV-transfer**。证书带 TTL，站点/磨损/固件变化或锚检验失败即失效并回溯标记历史证据。

**定义 141（多机互评协议 FEP）** 车队 𝒩，每机维护留出审计集。周期性地由审计机 n 在隐藏原证据（盲化）下重评 m 声称的区域，产出混淆张量 K_{m,n}(c)。**共模簇** C_cm(m)={n:γ_cm(m,n)>θ_cm ∨ 共享(批次,固件,站点,基座/操作者)}。EV-peer 计数规则：仅当 n∉C_cm(m) 且盲化成立时计 1，并按 w_ind 折扣；簇内互评只算同源复核。评测算子输出车队校准张量、覆盖矩阵与**伪独立告警**（原始一致数↑而 k_eff 不增时触发）。

**定义 142（双臂耦合承诺 DAC）** 双臂构型 q=(q_L,q_R)，共享基座状态 s_b。任务约束 C=C_L×C_R×Φ_c，耦合不变量 Φ_c（相对位姿 g(q_L,q_R)∈G、内力旋量 w_int∈W、共享物体平衡、握手时序）。**耦合承诺** σ_J=(σ_L,σ_R,Φ_c) ⇔ 两臂各自证据门通过 ∧ Φ_c 在裕度 θ_Φ 内可验 ∧ s_b 一致性检查通过。耦合紧密度 κ=∂(Φ_c 可行域)/∂(单臂退化)。退化级联：(D1) 任一臂证据失效 ⇒ 立即退到更保守单臂模式或停，除非"支撑/交接"模式本身有独立证据类 EV-brace/EV-handover；(D2) 禁止一臂替另一臂担保（no proxy guarantee）；(D3) 共享基座导致的双臂一致按 CMR 折扣，不计独立佐证。

**定义 143（车队/团队证据门 FTE 与证书 J_f/J_t）** 在第 57 轮五类证据上增：EV-transfer（须 T_{m→n} 且非不可逆）/EV-peer（跨共模簇、盲化、w_ind 折扣）/EV-joint（限 L1、Φ_c 通过、CMR 折扣）。**不可逆接触必要证据集** = 本机 EV-probe\*/EV-margin ∪ 耦合认证 Φ_c；EV-transfer/EV-peer/EV-joint 均不得单独顶替不可逆证据。J_f=(provenance,T_{m→n},K_{m,n},C_cm,γ_cm,ε_cm,γ_unk,audit_log,pseudo_indep_flags)；J_t=(σ_J,Φ_c 证书,κ,退化级联日志,每臂 J_p)，二者均继承 J_p 全检。

**定义 144（团队探-诺-演算子 TCE）** 每检查点：①本机元推断（第 57 轮）；②复用他机证据先过 FET（无证书→现场重探或加宽）；③共模对账：本机/他机/双臂一致统一送 CMR 折扣；④双臂任务先验耦合可行性，不成立⇒分解为单臂/绕行/交接；⑤承诺 ⇔ 本机证据门 ∧（团队场景）J_f/J_t 完整；否则探询→互评审计→绕行→降档→L2；退化代价计入 VOI。

## 2. 关键算法伪代码（完整版见产物区）

```python
def common_mode_discount(sources, resid):        # IP-139: 唯一"一致"计价器
    k_eff, basis = 1.0, shared_span(resid, [])
    for e in sources:
        r = resid.private(e)                     # o_e - g_e(s)
        if norm(project(r, basis)) > eps_proj:   # 有私有残差才可能计数
            k_eff += 1.0 - gamma_cm(e, sources, resid)
        basis = span(basis, shared_dirs(e))
    w = clamp(k_eff / len(sources), 1/len(sources), 1.0)
    return w, k_eff, (len(sources) > 1 and w < w_warn)

def transfer_admit(M, src, dst, c, meta):        # IP-140: 无证书不移植
    T = meta.transfer_cert(src.fp, dst.fp, c)
    if T is None or T.ess < N_MIN: return 'no_transfer'
    if not dst.reprobe_anchor(c, M, n=T.n_anchor).within(EPS_A):
        meta.invalidate(T); return 'anchor_fail'
    return 'ok', T                               # 仅 L0/L1，且加宽 Δ_tr

def fleet_peer_audit(fleet, M, region):          # IP-141: 盲化 + 跨簇
    cl = fleet.claimer(region)
    audits = [n.blind_reevaluate(region, cl.label) for n in fleet
              if n not in C_cm(cl.robot)]
    w, k_eff, pseudo = common_mode_discount([cl.ev] + audits, M.resid)
    if pseudo: fleet.flag('pseudo_independence', region, k_eff)
    return 'EV-peer' if agree(audits) and not pseudo and w >= w_min else None

def joint_commit(L, R, task, M):                 # IP-142: 耦合承诺与退化
    if not (L.gate_ok and R.gate_ok):
        return degrade_to('conservative_single', L if L.ok else R)
    Phi = verify_coupling(task.Phi, L, R, margin=THETA_PHI)
    if not Phi.ok: return 'halt_or_decompose'
    w, _, pseudo = common_mode_discount([L.ev, R.ev], M.resid)
    if pseudo: L.ev = R.ev = 'review_only'        # 共享基座→一致≠独立
    return ('committed', sigma_J(L, R, Phi), Phi.cert, kappa(task.Phi), w)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CMR | O(\|S\|²·d_s)/检查点 | O(\|S\|·d_s) | 潜因子登记完整、γ_cm 估计误差 ≤ε_cm |
| FET | O(d_φ+n_anchor·C_probe) | O(\|𝒟_meta\|) | 加权共形覆盖、锚检、ESS≥N_min |
| FEP | O(\|𝒩\|·\|A\|) 摊销 | O(\|𝒩\|²) | 跨簇 + 盲化 + w_ind 折扣 |
| DAC | O(d_Φ) | O(\|σ_J\|) | 耦合裕度、退化级联、无代理担保 |
| FTE | O(\|σ\|+\|J\|) | O(\|J_f\|+\|J_t\|) | 不可逆层禁团队证据单独顶替 |
| TCE | PCE+ + O(\|𝒩\|+d_Φ) | PCE+ + O(\|𝒩\|) | 移植/折扣/耦合只增保守性 |

**正确性定理（TPCS 概要）**：在 A33–A40 上增 (A41) 转移诚实（加权共形覆盖、锚检、ESS）；(A42) 共模核算诚实（潜因子登记完备、γ_cm 误差有界、未登记量计入 γ_unk）；(A43) 耦合健全（Φ_c 可验、单臂失效传播到保守模式）；(A44) 互评跨簇且盲化。则 (i) 团队承诺失效率 ≤ 单机界 + Σ_TR(δ_tr+ε_cm) + Σ_J(δ_couple+κ·δ_arm) + γ_unk；(ii) 交互单调性再强化：移植/互评/耦合只能使后验加宽或动作降档，不存在"借他机/他臂升险"的路径；(iii) TCE 在 k_probes+k_cons+k_audit 内终止。

## 6. 本轮最大风险

**一句话**：本轮把"独立性"从一个声明变成了一个**可计算的折扣**，而折扣的分母——共享潜因子集合——永远只能是列举出来的；只要漏掉一个共享潜因子（同批电池衰减、同一场地松软层、同一班组的操作习惯、双臂共享的同一个 IMU），"多机评测"就会退化成"一台机器戴 N 张面具"、"双臂协作"退化成"一次失效穿两条手臂"，且系统会在物理耦合最强处最自信地高估佐证；必须以显式潜因子登记+γ_unk 上界、近克隆默认塌缩为单源、跨簇盲化互评、以及不可逆层禁用一切跨机/跨臂一致来兜底。

## 2. 关键算法伪代码

### IP-139 CMR（共模残差分解与独立性折扣）

```python
def common_mode_discount(sources, resid):
    """唯一的"一致"计价器：所有跨源一致都必须经过它。"""
    k_eff, basis = 1.0, shared_span(resid, [])       # 已登记的共享潜方向
    for e in sources:
        r = resid.private(e)                          # o_e - g_e(s)
        priv = project(r, orthogonal(basis))          # 私有残差在共享正交补
        if norm(priv) > eps_proj:                     # 无私有成分则纯共模
            k_eff += max(0.0, 1.0 - gamma_cm(e, sources, resid))
        basis = span(basis, shared_dirs(e))
    w_ind = clamp(k_eff / len(sources), 1.0/len(sources), 1.0)
    pseudo = len(sources) > 1 and w_ind < w_warn
    return w_ind, k_eff, pseudo

def corroboration_weight(evidence_list, resid):
    w_ind, k_eff, pseudo = common_mode_discount(evidence_list, resid)
    if pseudo:                                        # 伪独立：塌缩为单源
        return 1.0, 'review_only'
    return w_ind, 'independent'
```

### IP-140 FET（跨机证据移植与转移证书）

```python
def transfer_admit(M, src, dst, region_class, meta):
    T = meta.transfer_cert(src.fp, dst.fp, region_class)
    if T is None or T.ess < meta.N_MIN or not T.overlap_ok:
        return ('no_transfer', 'need_local_probe')    # 无重叠：现场重探
    anchor = dst.reprobe_anchor(region_class, M, n=T.n_anchor)
    if not anchor.within(meta.eps_a):
        meta.invalidate(T)                            # 目标机不认账→作废
        return ('anchor_fail', 'need_local_probe')
    return ('ok', T)                                  # 仅 L0/L1，且加宽 Δ_tr
```

### IP-141 FEP（多机盲化互评与共模簇）

```python
def fleet_peer_audit(fleet, M, region):
    claim = fleet.claimer(region)
    auditors = [n for n in fleet if n not in C_cm(claim.robot)]
    results = [n.blind_reevaluate(region, claim.label) for n in auditors]
    K[claim.robot][:] = confusion(results, claim.label)
    w_ind, k_eff, pseudo = common_mode_discount([claim.ev] + results, M.resid)
    if pseudo:
        fleet.audit.flag(('pseudo_independence', region, k_eff))
    ok = agree(results) and not pseudo and w_ind >= w_min
    return ('EV-peer' if ok else None, w_ind, k_eff, pseudo)

def near_clone_cluster(fleet, M):
    """近克隆：共享潜因子过多 ⇒ 互评不增信，默认 w_ind=1/|S|。"""
    return {m: {n for n in fleet if fingerprint_dist(m, n) < d_clone}
            for m in fleet}
```

### IP-142 DAC（双臂耦合承诺与退化级联）

```python
def joint_commit(L, R, task, M):
    if not (L.gate_ok and R.gate_ok):
        if task.mode in ('brace', 'handover') and task.has_ev_brace:
            return 'degrage_with_own_evidence'        # 支撑/交接需独立证据类
        return degrade_to('conservative_single', L if L.gate_ok else R)  # D1
    if not base_consistency(L, R, M.s_b):             # 共享基座一致性
        return 'halt_or_decompose'
    Phi = verify_coupling(task.Phi, L, R, margin=THETA_PHI)
    if not Phi.ok:
        return 'halt_or_decompose'
    w_ind, _, pseudo = common_mode_discount([L.ev, R.ev], M.resid)
    if pseudo:                                        # D3: 共享基座→同源复核
        L.ev = R.ev = 'review_only'
    return ('committed', sigma_J(L, R, Phi), Phi.cert, kappa(task.Phi), w_ind)
```

### IP-143 FTE（车队/团队证据门与证书 J_f/J_t）

```python
def fleet_team_evidence_gate(c, M, persona, ood_reg, fleet):
    if c.ev == 'EV-transfer':
        ok = c.level != 'irreversible' and c.T.valid and c.T.region == c.region

def team_certificates(sched, M, fleet, coupling_log):
```

### IP-144 TCE（团队探-诺-演）

```python
def team_probe_commit_evolve(x0, M, task, budget, fleet, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        # ① 复用他机证据前先过 FET
        if cp.ev_origin != self:
            st = transfer_admit(M, cp.ev_origin, self, cp.region_class, meta)
            if st[0] != 'ok': schedule_local_probe(cp, budget)
        # ② 双臂任务先检耦合可行性
        if task.bimanual and not coupling_feasible(task, M):
            task = decompose(task)                    # 单臂/支撑/交接/绕行
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M), key=voi_meta_pessimistic)
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p))
            if D > theta_D: M, D = consensus_probe(M, cp)   # 第 57 轮共识探针
            budget.spend(p)
        if task.bimanual:
            res = joint_commit(*task.arms, task, M)          # 耦合承诺/退化
            if res == 'halt_or_decompose': route = reroute(M, cp); continue
        if fleet_team_evidence_gate(core_contact(cp), M, personas,
                                    ood_reg, fleet)[0] == 'ok':
            sched.append(commit(sigma, select_gait(R))); log.append(tag_evidence(cp))
            continue
        return negotiate_or_stop(cp, M, sigma, R, consent)
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CMR | O(\|S\|²·d_s)/检查点 | O(\|S\|·d_s) | 潜因子登记完整、γ_cm 误差 ≤ε_cm（A42） |
| FET | O(d_φ+n_anchor·C_probe) | O(\|𝒟_meta\|) | 加权共形覆盖、锚检、ESS≥N_min（A41） |
| FEP | O(\|𝒩\|·\|A\|) 摊销 | O(\|𝒩\|²) | 跨簇+盲化+w_ind 折扣（A44） |
| DAC | O(d_Φ) | O(\|σ_J\|) | 耦合裕度、退化级联、无代理担保（A43） |
| FTE | O(\|σ\|+\|J\|) | O(\|J_f\|+\|J_t\|) | 不可逆层禁团队证据单独顶替 |
| TCE | PCE+ + O(\|𝒩\|+d_Φ) | PCE+ + O(\|𝒩\|) | 移植/折扣/耦合只增保守性 |

**正确性定理（Team Portable Common-mode Soundness, TPCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 转移诚实：加权共形覆盖 ≥1−α_tr、锚检容差 ε_a、ESS≥N_min，证书 TTL 与失效回溯诚实；**(A42)** 共模核算诚实：共享潜因子集登记完备，γ_cm 估计误差 ≤ε_cm，未登记成分计入 γ_unk；**(A43)** 耦合健全：Φ_c 在裕度 θ_Φ 内可验，单臂失效必传播到保守模式，支撑/交接有独立证据类；**(A44)** 互评跨共模簇且盲化，w_ind 折扣按定义 139 执行。则：

1. **团队承诺健全性**：单机路径界保持第 57 轮；新增项为 Σ_TR(δ_tr+ε_cm) + Σ_J(δ_couple+κ·δ_arm) + γ_unk；EV-peer/EV-joint 仅在非不可逆层贡献且被 w_ind 折扣。
2. **交互单调性再强化**：FET 只能拒绝/加宽，CMR 只能减少佐证，DAC 只能降档/停；不存在"借他机/他臂升险"的通道；伪独立告警使系统自动落回单源权重。
3. **终止性**：TCE 在 k_probes+k_cons+k_audit 内终止于 {承诺, 绕行, 单臂退化, L2 协商, 安全停}。
4. **部署界**（对检查点与证书取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − Σ_TR (δ_tr + ε_cm)
             − Σ_J  (δ_couple + κ·δ_arm)
             − P(共模潜因子漏检) − P(证书过期未检出) − P(伪独立未告警)
```

关键：**独立性不是声明而是折扣**——CMR 用同一把尺子给跨模态/跨机/跨臂一致计价，折扣只会让佐证变少；**移植靠证书而非信任**——FET 以指纹+锚集+ESS 把"实施例不变性"从假设变成可失败检验；**协作靠退化而非担保**——DAC 以耦合不变量与级联把双臂的联合风险钉死在保守模式；三个新机制只经"信念更保守/动作更保守"两个通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把"独立性"从一个声明变成了一个**可计算的折扣**，而折扣的分母——共享潜因子集合——永远只能是列举出来的；只要漏掉一个共享潜因子（同批电池衰减、同一场地松软层、同一班组的操作习惯、双臂共享的同一个 IMU），"多机评测"就会退化成"一台机器戴 N 张面具"、"双臂协作"退化成"一次失效穿两条手臂"，且系统会在物理耦合最强处最自信地高估佐证；必须以显式潜因子登记+γ_unk 上界、近克隆默认塌缩为单源、跨簇盲化互评、以及不可逆层禁用一切跨机/跨臂一致来兜底。
