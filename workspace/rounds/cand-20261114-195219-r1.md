# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「人机交互」×「迁移学习」）

> R69 把不确定性一分为二，让系统学会「问」：看、问、触、等被纳入同一个动作空间，用流匹配生成，用 VoI 决定值不值得问。但 R69 里的「人」是一个**静止的证据源**：欺骗率 δ_p 是常数、证据源「正交」是假设、交互成本是一次性的、交互策略训好就到处用。这四条在 HCI 与迁移学习的视角下同时失效：
> - 人的可靠性不是常数，而是被机器的交互策略**内生塑造**的：问得越多，人越可能停止独立检查（过度依赖/技能退化）；问得越「诱导」，回答越像谄媚；机器越替人做决定，人越没有能力在下一次充当第二意见。
> - 「正交证据」不是假设而是**可测量量**：多个模态可能通过同一个心智模型或同一个传感器相关，k=2 的一致性可能只等于 1 个证据。
> - 一次交互的收益不只落在「机器对模态的判断」上，还落在**人身上**（信任、胜任度），这是一笔被 R69 忽略的长期外部性。
> - 交互技能（怎么问、问哪个证据对）可能跨任务迁移，但**回答的标定**（这个用户怎么答、有多可信）不迁移；把标定一起迁移就是负迁移，而 R69 会把这个负迁移的结论盖上「已验证」的章。
>
> 核心命题：**把人从「证据源」升级为「共适应伙伴」，把交互从「一次性信息交易」升级为「双向迁移」——机器把「怎么看」教给人，人把「该信什么」教给机器；真正能跨任务迁移的是「问题」，不是「答案」。** 命名 **COTEACH-RAS**（Co-adaptive Transfer of Evidence And Competence Handoff）。
>
> 理论姿态：与 R69 一致，新层必须是旧层的严格泛化。三级退避——完整共适应 → 冻结迁移退回 FLUID → 破坏人因不变式退回 R68 纯保守——保证安全侧永不让步，R69/R68 都是本轮的边界退化。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**问完之后，我们各自变成了谁**」——交互不是一次信息交易，而是一场会改变双方的迁移。

## 0. 直觉与动机

**灵感 1（HCI：人不是神谕，可靠性是内生的）**
直觉：R69 的 δ_p 是一个写在证书里的常数，仿佛同一个人在被问一百次时都同样可靠。真实世界里恰恰相反：一个被频繁询问的操作员会逐渐放弃独立判断（automation complacency），一个总被机器纠正的专家会变得不自信（deskilling），一个总被机器附和的人会开始相信自己没验证过的直觉。**可靠性不是人的属性，是「人–机关系」的属性**。所以 h_t 必须进入状态，δ_p 必须写成 ε(h,g)。

**灵感 2（HCI：问题塑造答案，也塑造回答者）**
直觉：同一个信息需求，「这里是不是 A？」和「这里是 A 还是 B？」会得到不同的答案——前者是诱导，后者是询问。更隐蔽的是，机器选择「替人做」还是「解释给人做」，会改变人下一次的判断能力。于是交互动作有两个作用面：**更新机器的信念**（R69 的 VoI）与**更新人的状态**（信任、胜任度）。只优化前者，等于在透支后者。

**灵感 3（迁移学习：迁移「问题」，不迁移「答案」）**
直觉：一个成熟的医生换到新医院，**问诊的结构**（先问什么、怎么交叉验证）能带过去，但**对某个新病人的判断阈值**带不过去。交互策略同理：查询结构 φ 是可迁移的不变量，回答标定 ψ 是上下文相关的变量。R69 没有做这个切分，于是一次在 A 任务上学到的「这个人很可信」，会被原样搬到 B 任务当作「已验证」。

**灵感 4（迁移学习：负迁移才是主要敌人）**
直觉：迁移学习不是「迁移越多越好」，而是「该迁的迁、不该迁的坚决不迁」。当源域的结构与目标域相悖时，迁移会**比从零学更差**（负迁移）。在人机交互里，负迁移的后果被放大：它不会被当成一次失败的统计，而会被盖上「来自已验证源」的证书。所以本轮必须交付可迁移性证书与负迁移检测门，而不是一个默认开启的迁移开关。

**灵感 5（HCI×迁移：正交性与公平性都可测量、可约束）**
直觉：R69 的「k 个正交证据源」是对相关性的一个祈祷；但相关性可在线估计，于是「正交」应升级为「有效独立源数 k_eff ≥ 2」的门控。同理，不同用户群体的回答标定系统性不同，把多数群体的 ψ 迁给少数群体是一种**结构性负迁移**；公平约束因此不是伦理附加，而是迁移正确性的一个坐标。

**灵感 6（双向适应可能失稳）**
直觉：人会适应机器，机器也在适应人。过度信任 → 少检查 → 人的判断更差 → 机器更不可信 → 更依赖……这是一个正反馈。共适应不总是收敛的；必须有一个「耦合治理器」，在耦合增益过大时主动降频、冻结迁移，退回 R69 的静态假设，而不是让系统与人一起滑向一个自洽但错误的均衡。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（COTEACH-RAS 总览）** COTEACH-RAS = (USM, ERC, SID, E-VoI, IIT, NTD, CEE, CPI, QLM, HFP, MAL, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；USM/IIT 只做冻结参数的推断，不做梯度写入）；
(ii) **人因不变式**：期望胜任度 ≥ κ_floor、信任标定误差 ≤ τ_trust、交互外部性预算 ≤ B（定义 322）；
(iii) **迁移纪律**：交互策略分解为不变结构 φ 与上下文标定 ψ；跨上下文只迁移 φ，ψ 必须在线重标定，未经可迁移性证书不得复用 ψ（定义 315–316）；
(iv) **证据纪律升级**：R69 的「k 个正交源」替换为「有效独立源 k_eff ≥ 2」（定义 317）。

**定义 311（用户状态模型 USM）** 潜状态 h_t = (κ_t, τ_t, ℓ_t) ∈ [0,1]³（胜任度 / 对机器的信任 / 认知负荷）。由冻结参数的贝叶斯滤波从可观测交互量 o^H_t =（回答、反应时、是否复核、纠正行为）推断：b_t(h) ∝ p(o^H_t | h) ∫ A(h | h') b_{t-1}(h') dh'。USM 只用于推断与风险缩放，不产生实时学习写操作。

**定义 312（内生响应信道 ERC）** P(y | M, g, h) = (1 − ε(h,g))·δ(y = M) + ε(h,g)·ν(y)，其中误差率 ε(h,g) = clip(ε_0 + α_ℓ·ℓ + α_κ·(1−κ) + b(g), 0, 1)，b(g) 为问句框架的**诱导偏置**（有符号；正偏置把质量推向机器暗示的模态 M_0）。R69 的常数 δ_p 是本式在 h 固定、b(g)=0 时的一个切片。

**定义 313（状态-交互耦合动力学 SID）**
κ_{t+1} = κ_t + η_κ·[u(g_t) − d·1(g_t 为接管)]，u 为解释/共同决策带来的增能，d 为被接管导致的技能退化；
τ_{t+1} = τ_t + η_τ·[suc·1(采纳) − fail·1(采纳) − λ_oa·1(过度询问)]；
ℓ_{t+1} = clip(ℓ_t + η_ℓ·[查询负荷] − η_r·[休息], 0, 1)。
这组式子刻画「机器怎么问 → 人变成什么样」，是本轮相对 R69 最关键的状态增量。

**定义 314（内生价值 E-VoI）**
VoI_endo(g) = I(M; y | o, g, h_t) + γ·E[Φ(h_{t+1}) − Φ(h_t) | g, h_t] − c(g)，
Φ(h) = −λ_τ(τ − τ*)² − λ_ℓ·ℓ + λ_κ·κ 为人因势函数（τ* 为标定信任目标）。R69 的 VoI 是 γ=0 的特例；γ>0 使系统愿意为「让人保持能查、愿意查」支付短期信息收益。

**定义 315（不变/可变分解与交互迁移 IIT）** 交互策略参数 θ = (φ, ψ)。φ 为**不变查询结构**（选哪个证据对、何时问、以何种中性框架问）；ψ 为**上下文标定**（该用户/任务下回答的可信度映射）。在环境族 ℰ（任务、用户群体、仿真/真机）上做 IRM 式元训练：
min_{φ,{ψ_e}} Σ_e L_e(φ, ψ_e) + λ Σ_e ‖∇_{ψ_e} L_e(φ, ψ_e)‖²。
部署时 φ 直接迁移，ψ 由目标上下文少量交互在线重标定。

**定义 316（可迁移性证书与负迁移检测 NTD）** 源上下文 s 到目标 t 的可迁移性
T(s→t) = 1 − [ECE_t(ψ_s) − ECE_t(ψ_t)]_+ / ECE_t(ψ_t) − novelty_penalty。
当 T < τ_T、或胜任度裕度 < 0、或 k_eff < 2：判为负迁移，冻结 ψ_s，改用目标上下文重标定的 ψ_t，必要时退回 R69。证书记录 (φ 版本, s, t, T, ECE, 样本量)。

**定义 317（有效独立性 CEE）** 证据源误差的成对相关均值 ρ̄；有效独立源数 k_eff = k / (1 + (k−1)·ρ̄)（设计效应）。证据纪律要求 k_eff ≥ 2；k_eff 由 CEE 在线估计并写入证书。

**定义 318（保胜任交互 CPI 与自主权分配）** 动作集扩展为 {解释 g_exp, 延迟/移交 g_def, 接管 g_take}。选择自主权 α ∈ {解释, 移交, 接管}，约束 E[κ_{t+T}] ≥ κ_floor 且 |τ_{t+T} − τ*| ≤ τ_band。原则：κ 高时优先「解释/移交」把人留在环内，κ 低时才「接管」，接管须登记为技能退化风险。

**定义 319（诱导性与谄媚监测 QLM）** 诱导偏置 b(g) 用「同义重述反事实」估计：同一信息需求以中性框架重问，比较回答分布位移 Δ_b；约束 |b(g)| ≤ b_max。超过则改写问句或改用非语言证据，防止把「确认」误当「证据」。

**定义 320（分层公平先验与群体校准 HFP）** 用户群体 g 的分层先验 p(ψ | group) + 个体后验 ψ_i；公平约束 sup_g |ECE_g − ECE| ≤ τ_fair。禁止把多数群体的 ψ 直接迁移给少数群体（一种结构性负迁移）。

**定义 321（双向适应动力学与稳定门 MAL）** 人机耦合映射 F = (F_h, F_m) 在两个时间尺度上演化（人快 η_h > η_m 机器慢）。若 F 的雅可比谱半径 ρ_J < 1，共适应收敛到唯一不动点；若 ρ_J ≥ 1，耦合治理器降低交互频率、冻结 ψ，回到 R69 的静态交互假设，避免「过度信任 → 少检查 → 更不可信 → 更依赖」的正反馈。

**定义 322（交互外部性预算 EIB）** 单位时间累计外部性
E_ext = Σ[|Δτ|/τ_band + max(0, κ_floor − κ)/κ_floor + ℓ/ℓ_max] + Σ c(g) ≤ B。
R69 的交互预算只计物理/社交成本；本式把「对人做了什么」也计入预算。

**定义 323（证书 J_COTEACH）** J_COTEACH = (J_FLUID, user_state_coverage, k_eff, transferability T, competence_margin, trust_cal_err, fairness_gap, coadapt_ρ_J, coteach_ver)。Valid ⇔ Valid(J_FLUID) ∧ k_eff ≥ 2 ∧ 迁移纪律满足 ∧ 人因不变式满足。

**定义 324（扰动集 ℰ_COTEACH）** ℰ_COTEACH = ℰ_FLUID × ℰ_transfer（负迁移、群体偏移）× ℰ_human（谄媚、诱导、共谋、游戏化/故意示弱）× ℰ_corr（证据相关、k_eff 坍缩）。

**定义 325（三级退避与严格包含）** 一级：可迁移且 k_eff ≥ 2 且人因不变式满足 → 完整 COTEACH；二级：可迁移性/独立性存疑 → 冻结 ψ、禁用迁移，退回 FLUID-RAS（R69）；三级：人因不变式破坏或共适应失稳 → 退回 R68 纯保守 λ_floor。三级逐级单调收紧 ⇒ R69 与 R68 都是本轮的边界退化。

# IP-264 USM：用户状态贝叶斯滤波（冻结参数，实时零学习写）
class UserStateModel:
    def update(self, belief, oH):                       # oH: 回答/反应时/复核/纠正
        return bayes_filter(belief, oH, self.frozen_likelihood)

# IP-266 E-VoI：把交互对人的长期外部性计入收益（γ=0 退化为 R69 VoI）
def endogenous_voi(g, modes, h, gamma=0.2):
    info  = mutual_info(mode_identity, answer, g, h)    # I(M; y | o, g, h)
    ext   = expected_phi(next_state(h, g)) - phi(h)     # 信任/胜任度势差
    return info + gamma * ext - cost(g)

# IP-265 CEE：有效独立源数（正交性从假设变为测量）
def effective_independence(source_errors):
    rho = mean_pairwise_corr(source_errors)
    k   = len(source_errors)
    return k / (1.0 + (k - 1) * rho)                    # 设计效应折减

# IP-268 NTD：可迁移性证书与负迁移门
def transfer_gate(phi, psi_src, target_ctx, ece_t):
    T = 1 - max(0.0, ece_t(psi_src) - ece_t(psi_tgt(target_ctx))) / ece_t(...)
    T -= novelty_penalty(phi, target_ctx)
    if T < TAU_T or target_ctx.competence_margin < 0: 
        return None                                     # 冻结迁移，重标定或回 R69
    return phi                                           # 只迁结构，不迁标定

# IP-270 CPI：保胜任自主权分配（解释/移交/接管）
def competence_preserving_action(kappa, tau, modes, lam):
    if kappa >= KAPPA_HI:  return explain_or_defer(modes)   # 把人留在环内
    if kappa <  KAPPA_LO:  return takeover(modes)           # 仅在低胜任时接管
    return mixed_handoff(modes, lam)                        # 受 κ_floor 约束的 QP

# IP-271 QLM：诱导偏置估计（同义重述反事实）
def leading_bias(ask_fn, info_need):
    y_neutral, y_leading = ask_fn(info_need, neutral=True), ask_fn(info_need, neutral=False)
    b = distribution_shift(y_leading, y_neutral)
    return b if abs(b) <= B_MAX else REWRITE_OR_SWITCH_MODALITY

# IP-276 主闭环（继承 R69，在交互决策处插入 COTEACH 层）
def COTEACH_RAS_round(M, obs, belief, ctx):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    h    = M.usm.update(belief, obs.oH)                 # 1) 估计用户状态
    samples = M.fmp.sample(o, K=1 if M.fmp.mode_head(z) < TAU_MODE else 4)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    k_eff = M.cee.effective_independence(M.last_source_errors)
    phi   = M.ntd.transfer_gate(M.iit.phi, M.iit.psi, ctx, M.ece_t)   # 2) 迁移门
    if phi is None: return M.fluid_round(obs)           # 负迁移 → 退回 R69

    if g is not None and k_eff < 2: g = None            # 3) 独立源不足 → 不作验证式定案

        belief = M.usm.update(belief, reward)           # 交互改变人，也改变对 h 的估计

## 3. 推导

**引理 19（内生外部性：短视 VoI 高估长期价值）** 设 SID 中 d>0 且只接管不解释（u=0）。若单位时间交互 n 次，则 κ_{t+T} ≤ κ_t − d·n·T，且 ε(h) ≥ ε_0 + α_κ(1−κ)。R69 在任何单步用固定 δ_p 计算 VoI 与引理 18 上界，得到的只是 ε(h_t) 的切片。故存在 T 与 n，使「每步局部正收益」的交互序列在 T 步后的总成功概率低于「少问、保持 κ」的序列。即 **逐指令安全 ≠ 长时程安全**；R69 的 resolution bonus 有一部分是向未来借的。

**引理 20（有效独立性下证据纪律的退化）** 设 k 个误差相关源、成对相关均值 ρ̄，则多数投票错误率上界由 k_eff 替代 k：P_err ≤ δ_p·ρ̄^{k_eff−1} + ε_σ。证明要点：相关源的有效信息量按设计效应折减；ρ̄→1 时 k_eff→1，上界退化为单源 δ_p。这正是 R69 引理 18 要求 ρ<1 的隐含量，本轮把它从「假设」变成「可测门控 k_eff ≥ 2」。

**引理 21（迁移分解与负迁移阈值）** 目标上下文 t 上的适应误差可分解为
Err_t(φ_s, ψ_s) = [Err_t(φ_s, ψ_t) − Err_t(φ_t, ψ_t)]_bias + [Err_t(φ_t, ψ_t) − Err_t*]_variance(n_t)。
迁移 φ 降低 variance（样本效率），但若源结构 φ_s 与目标最优结构不一致，bias>0。当 bias > variance saving 时发生负迁移；定义 316 的 T(s→t) 即二者比较的可操作代理。
**推论（迁移问题，不迁移答案）** 可迁移的是「怎么问」（φ，查询结构），不可迁移的是「这个回答有多可信」（ψ，标定）。R69 把二者混为一谈，是其在跨任务部署时最危险的一处。

**定理 18（COTEACH 严格包含 FLUID）** 在 A99–A104（SID 收缩、k_eff ≥ 2、迁移证书、胜任度地板）下，COTEACH 在任意状态 s 的期望风险 ≤ FLUID-RAS；且当迁移门失败 / k_eff < 2 / 人因不变式破坏 / 共适应失稳时，二者**逐指令相同**（定义 316、321、325）。因此 R69 是 COTEACH 在「不迁移、不使用弱独立证据、不做共适应」边界上的退化：安全侧不做任何让步。

**定理 19（双向适应稳定性）** 若耦合映射 F 的雅可比谱半径 ρ_J < 1 且交互率不超过 EIB 预算，则共适应收敛到唯一不动点，信任标定误差被 1/(1−ρ_J) 倍的单步噪声界约束；若 ρ_J ≥ 1，耦合治理器单调降低交互率并冻结 ψ，系统退化为 R69 的静态交互，控制连续、无振荡。系：**「多问」不是免费的**，问题在于问得是否让耦合更稳定，而不是是否让单步熵更低。

## 6. 本轮最大风险

**一句话**：用户状态模型与被优化的对象构成反馈回路——机器用来估计信任/胜任度的交互，恰恰在改变信任/胜任度；一旦 USM 设定错误或迁移了错误的 ψ，系统会共适应到一个稳定但错误的均衡（把「顺从」误读为「胜任」，把「沉默」误读为「认同」），然后在负迁移下把这个均衡自信地搬到每个新任务——**教出来的错误，比问出来的错误更隐蔽**。

**次级风险与缓解**：
1. **共适应正反馈**（过度信任→少检查→更依赖）→ MAL 谱半径门 + 耦合治理器降频回 R69；
2. **负迁移被证书背书** → NTD 可迁移性门 + 三级退避，未认证不得复用 ψ；
3. **相关证据冒充正交** → CEE 在线 k_eff + k_eff<2 禁止验证式定案；
4. **诱导/谄媚污染训练** → QLM 反事实重述 + b_max 约束 + ℰ_human 对抗训练；
5. **群体性结构性负迁移** → HFP 分层先验 + ECE 公平约束，绝不让多数 ψ 直接覆盖少数。

## 4. 推导

**引理 19（内生外部性：短视 VoI 高估长期价值）** 若 SID 中 d>0 且只接管不解释，则 κ_{t+T} ≤ κ_t − d·n·T，ε(h) ≥ ε_0 + α_κ(1−κ)。R69 用固定 δ_p 计算的 VoI 只是 ε(h_t) 的切片；故存在 T、n 使「每步局部正收益」的交互序列在 T 步后总成功概率低于「少问、保持 κ」的序列。**逐指令安全 ≠ 长时程安全。**

**引理 20（有效独立性下证据纪律的退化）** k 个相关源、成对相关均值 ρ̄，多数投票错误上界为 `δ_p·ρ̄^{k_eff−1} + ε_σ`，其中 `k_eff=k/(1+(k−1)ρ̄)`。ρ̄→1 时 k_eff→1、上界退化为单源 δ_p；R69 引理 18 的 ρ<1 要求由此成为可测门控 k_eff≥2。

**引理 21（迁移分解与负迁移阈值）** `Err_t(φ_s,ψ_s) = bias(φ_s) + variance(n_t)`；迁移 φ 降 variance，结构不一致则增 bias；当 bias > variance saving 即负迁移。定义 316 的 T(s→t) 是二者的可操作代理。
**推论（迁移问题，不迁移答案）** φ（怎么问）可迁，ψ（这个回答多可信）不可迁；R69 混淆二者是其跨任务部署最危险处。

**定理 18（COTEACH 严格包含 FLUID）** A99–A104 下，COTEACH 任意状态期望风险 ≤ FLUID-RAS；当迁移门失败 / k_eff<2 / 人因不变式破坏 / 共适应失稳时逐指令相同。R69 是本轮在「不迁移、不用弱独立证据、不做共适应」边界的退化：安全不让步。

**定理 19（双向适应稳定性）** ρ_J<1 且交互率 ≤ EIB 预算时，共适应收敛到唯一不动点，信任标定误差受 1/(1−ρ_J) 倍单步噪声界约束；ρ_J≥1 时治理器单调降频并冻结 ψ，退化为 R69 静态交互，控制连续、无振荡。系：**「多问」不免费，关键看它让耦合更稳还是更不稳。**

## 7. 本轮最大风险

**一句话**：用户状态模型与被优化对象构成反馈回路——机器用来估计信任/胜任度的交互，恰恰在改变信任/胜任度；一旦 USM 设定错误或迁移了错误的 ψ，系统会共适应到一个稳定但错误的均衡（把「顺从」误读为「胜任」，把「沉默」误读为「认同」），再在负迁移下把这个均衡自信地搬到每个新任务——**教出来的错误，比问出来的错误更隐蔽**。

**次级风险与缓解**：共适应正反馈（MAL 谱半径门 + 降频回 R69）；负迁移被证书背书（NTD 可迁移性门 + 三级退避）；相关证据冒充正交（CEE 在线 k_eff + k_eff<2 禁止验证式定案）；诱导/谄媚污染（QLM 反事实重述 + b_max + ℰ_human 对抗训练）；群体性结构性负迁移（HFP 分层先验 + ECE 公平约束）。
