# 第 1 轮（灵感循环 · 语义课程层奠基版；本轮灵感：「视觉语言模型」×「课程学习」）

> **承接声明**：本轮以状态文件中的 **UniBot-SAGE v1**（2026-11-17，UniBot-V1 通才赛道；U1–U12 / L1–L7 / E601–E618 / IP-01…IP-08）为基线，不推倒、不重开题。第 1 轮的三条结论继续有效：**终态成功是唯一计分货币；时长与成功无关；断点在最后一环（插入/旋转/细放置）**。本轮只追加一层此前被所有队伍默认忽略的东西——**「难度」到底属于谁，以及语义模型能在哪里可靠地监督几何操作**。编号续用：定义 U13–U24、引理 L8–L14、实验 E619–E636；新增 IP-09…IP-13。
>
> **检索/复核日期**：2026-11-21（UTC）。接口事实以官方 `unibot_submission` README 为准；榜单数字沿用状态文件 §0 的 **teaser** 口径，并用本地快照 `exp/r16_leaderboard_data.json`（8 模型 × 32 任务，retrieved 2026-11-04）复算；来源见产物区 §11。

## 0. 本轮先做一个真实的小实验：难度不是任务的属性

在写任何方案之前，我先问了一个会决定整轮方向的问题：**课程学习需要一个「由易到难」的排序，那么这个「难」是任务的属性，还是（策略，任务，场景）的属性？** 用本地 8×32 的 teaser 矩阵直接算，得到一个很强的负结果：

| 量 | 结果 | 含义 |
|---|---|---|
| 跨模型难度一致性（Kendall W） | **0.058**；只用前两名模型时 **0.0007** | 不存在一个全局的「任务难度」；连最强的两个模型都不一致 |
| 两两 Spearman（32 任务） | 均值 **0.098**，范围 **[−0.155, 0.291]** | 不是弱模型噪声：top-2 也几乎不相关 |
| 廉价元数据预测难度（rubric 步数 + 名称词数） | LOOCV **R² = −0.222**，Spearman = **−0.310** | 训练前就能拿到的元数据几乎无信息，甚至反向 |
| 再加「任务平均时长」 | LOOCV **R² = −0.291**，Spearman = **−0.400** | 时长也救不了；需要语义/rollout 信号 |
| 方差分解（任务 / 模型 / 交互） | **16.4% / 23.3% / 60.2%** | 60% 是模型×任务交互 ⇒ 课程必须按技能/专家分，而不是按任务分 |
| 最难四分位 vs 最易四分位的 headroom | **10.03 vs 8.38** | 难任务仍有可学空间，不能简单丢弃 |
| Spearman(难度, 单任务最高成功率) | **−0.537** | 越难的任务天花板越低 ⇒ 需要「可学性门」 |
| oracle 增益落在最难四分位的比例 | **28.5%** | 略高于均匀的 25%：该聚焦，但不能全押 |

**四条推论（本轮的地基）**：

- **A. 全局任务课程是 ill-posed 的。** 若难度是任务属性，8 个模型对「哪些任务难」应有正相关；实测 W≈0.06、top-2 W≈0.0007。任何按「任务平均成功率」排出的课程，对某一个具体策略而言，其排序信息量接近零。
- **B. 难度信号必须来自策略自己的 rollout（或一个以 rollout 为条件的语义模型）。** 廉价元数据 LOOCV R² 为负，说明「任务名/步骤数/时长」不能替代「这个策略在这个任务上到底会不会」。这正是 VLM 的用武之地：不是让它猜任务难度，而是让它**看当前策略的失败现场**，判断「它卡在哪个子目标」。
- **C. 课程要带可学性门。** 难任务 headroom 更大，但天花板更低（ρ=−0.537）；盲目给难任务加权，会把预算烧在「不可约的难」上。门要同时看 headroom 与 ceiling。
- **D. 课程必须按技能/专家分。** 60% 的交互方差说明「任务」不是最小的课程单元；最小单元应是 **(任务 token × 相位 × OOD 轴)**，与 IP-01 的专家划分对齐。

> 这四条不是文献口号，是本轮在 `exp/vlm_curriculum_probe.py` / `probe2.py` 里真实算出来的。它们直接决定了下面的方案：**不做「任务级课程」，做「自步的、按技能条件的、带可学性门的语义课程」。**

## 1. 直觉：两个灵感各自的第一性原理

### 1.1 灵感一 ·「视觉语言模型」：它是一个语义先验，不是一个传感器

**人话直觉**：VLM 像一个读过很多书、但从没上过手的人。你给它一张图和一句话，它能告诉你「这是杯子」「插头在孔的左边」「这一步应该先对准再推」。但它**摸不到**：它不知道夹爪是否真的夹住了、插头是否真的进了孔、力是否传上去了。它的强项是「这是什么、该做什么、大概在哪」，弱项是「接触没有、差几毫米、有没有滑」。

**第一性原理**：

1. **VLM 的监督信号是语义的、粗粒度的**：物体身份、空间关系、动作动词、可供性（affordance）、子目标完成与否。这些恰好是**任务分解与进度判断**需要的。
2. **任务瓶颈是几何的、细粒度的**：第 1 轮已定位断点在插入/旋转/细放置。这些事件的判别信号是接触、位姿误差、随动一致性——**恰好是 VLM 最不可靠的地方**。
3. **存在「语义—几何鸿沟」**：VLM 的置信度在语义层最高，在接触层最低；而分数由接触层决定。因此**不能让 VLM 的置信度直接决定是否介入**，否则会在最需要判断的地方最自信地错。
4. **VLM 已经在这个系统里了**：官方参考架构 ER-1-4B(Qwen3-VL-4B) 本身就是 VLM，VLA 主干里已经有视觉-语言特征。所以「用 VLM」不是新意；新意是**把它的语义判断蒸馏成一个小的、带校准与弃权契约的 head，挂在现有主干特征上**，既拿到语义监督，又不付大模型延迟。
5. **离线 VLM 是免费的老师，在线大 VLM 是昂贵的风险**：训练期用大 VLM 打子目标/难度/失败归因标签；部署期只跑小 head。这条分工同时解决延迟与合规。

**一句话**：**VLM 负责「说清楚这一步是什么、该到哪」，几何负责「确认真的到了」；两者用一条校准/弃权契约缝合，而不是互相覆盖。**

### 1.2 灵感二 ·「课程学习」：难度是（策略，任务，场景）的属性

**人话直觉**：课程学习就是「先学简单的，再学难的，始终待在跳一跳够得着的地方」。但这句话藏着一个致命的隐含假设：**存在一个客观的难度标尺**。本轮实验把这个假设打掉了：同一个任务，对模型 A 是简单题，对模型 B 是难题；连前两名模型对「哪些题难」都几乎不相关。所以「先学简单任务」这个朴素版本在这里是错的。

**第一性原理**：

1. **课程 = 对经验的排序**；排序需要一个难度信号。若难度不是任务属性，就必须是**策略相对的**（self-paced）：用这个策略自己的成功率/失败模式来定义「当前够得着」。
2. **「最近发展区」（ZPD）是策略相对的**：训练样本应集中在「当前会一点、但还不稳」的区域。这个区域只能从 rollout 里估计，不能从任务名里读出来。
3. **课程不是免费的**：改变训练分布会带来覆盖偏移，可能牺牲长尾；必须用 **uniform replay** 把 KL(q‖u) 压住（引理 L11）。
4. **难任务要过「可学性门」**：headroom 大但 ceiling 低的任务，梯度里混着不可约噪声；先判「可学」再加权（引理 L9）。
5. **课程也可以发生在测试时**：第 1 轮的「退化链」本质就是一个**按能力排序的课程阶梯**——先试最激进的高阶技能，失败就降一档。把这条阶梯显式化，并用语义 critic 判断「该不该降档」，就是「测试时课程」。

**一句话**：**课程学习在这里不是「按任务难度排序」，而是「按当前策略的失败现场，动态选择下一批该练什么、以及失败时该退到哪一档」。**

### 1.3 合成：SAGE-C = 语义难度场 × 自步课程 × 能力阶梯

把两个灵感接起来，得到一个**不改接口、不改单模型合规形态、只加训练调度与一个小 critic head** 的层：

1. **Semantic Scaffold（离线语义脚手架）**：用大 VLM 从语言指令 + 初始帧生成**子目标图**（reach→grasp→lift→transport→align→insert/place→release），并对每条演示的每个阶段打上「子目标是否完成」的标签。这把 32 个长任务拆成可复用、可课程的短子目标。
2. **SemCritic（蒸馏后的选择性 critic）**：在 VLA 主干冻结特征上训练一个小 head，蒸馏大 VLM 的进度判断，输出 `(进度分 s, 是否可信 κ)`。**只在可信区进入损失/介入**；接触级判断仍交给 IP-02 的几何信号。
3. **SelfPaced Curriculum（自步课程）**：以 `D̂(τ, phase, ood_axis)`（来自 rollout + SemCritic）为中心，采样「当前 ZPD」附近的 (任务 × 相位 × OOD 轴)，并用可学性门过滤、用 uniform replay 保覆盖。**这是训练期的事，不涉及在线权重更新，合规风险最低。**
4. **Hindsight Subgoal Curriculum（回溯子目标课程）**：把成功演示在相位边界「倒带」，用 VLM 重新标注后缀子目标，生成大量**短时域、目标条件化**的训练样本；这是在不采集新真机数据的前提下，最便宜的数据增广。
5. **Curriculum Ladder（测试时能力阶梯）**：把第 1 轮的静态退化链升级为按「验证成功率」排序的阶梯；SemCritic 检测到当前档失败就降档，而不是等到超时。

**闭环**：VLM 先验 → 课程选样 → 策略 rollout（含失败）→ 校准 SemCritic → 更新难度场 → 课程再选样。**这是一个「语义模型与策略互相校准」的循环，而不是单向蒸馏。**

## 2. 为什么是现在（与第 1 轮基线的差异）

- **第 1 轮把 VLM 只当离线打标器**（IP-01 的相位伪标、IP-06 的六因子标注）。本轮把它升级为**带校准/弃权契约的在线选择性 critic**，并明确它的能力边界——这正好回应第 1 轮风险登记册里「伪标签在未见物品上漂移」的隐患：不是让伪标签更准，而是让 critic **知道自己什么时候不该说话**。
- **第 1 轮把「技能路由」当静态结构**（IP-01 的 K 个专家）。本轮补上「这些专家该按什么顺序、用什么数据训」——**路由是结构，课程是训练这个结构的调度器**；没有课程，MoE 的专家很容易在长尾任务上饿死。
- **第 1 轮的退化链是手写的**（Level-0…Level-4）。本轮把它变成**由能力估计驱动的阶梯**，并用实验数据说明「难度是策略相对的」，所以阶梯也必须按策略排序。
- **本轮的负结果直接排除了一个便宜方案**：既然任务级课程 ill-posed、廉价元数据反预测，那么「按任务平均成功率排序」这条最容易做的课程路线可以直接砍掉，把预算集中在**自步 + 语义条件**上。这是负结果的价值：它省掉了一整条弯路。
- **5 类泛化场景天然就是课程的 5 个轴**：位置 / 干扰物 / 背景 / 未见物品 / 人为干扰。课程学习在这里不是比喻，而是**对 5 个 OOD 轴的难度调度**；这与 IP-04 的上下文适配互补——IP-04 在推理期吸收偏移，本轮在训练期按偏移轴安排经验。

## 3. 研究问题（本轮版）

- **Q1（语义—几何边界）**：VLM/SemCritic 在哪些子目标上可靠（物体、关系、粗进度），在哪些上不可靠（接触、插入、滑移）？能否画出一条**可验证的能力边界**，并让 critic 在边界外弃权？
- **Q2（难度可估性）**：既然任务级难度 ill-posed、廉价元数据反预测，那么「以策略 rollout 为条件」的 VLM 难度估计，能否显著优于元数据基线（我们的 LOO R²=−0.22）？它的排序与策略真实失败率的相关性能到多少？
- **Q3（自步课程）**：在等算力下，按 (任务 × 相位 × OOD 轴) 的自步课程 + 可学性门 + uniform replay，能否提升 OOD 成功率？覆盖/遗忘的代价多大？
- **Q4（回溯子目标）**：相位倒带 + VLM 子目标重标注，能否用**已有成功演示**造出有用的短时域课程？它对最后一环的恢复能力有多少迁移？注意：它只能造「在轨子目标达成」样本，造不出「离轨恢复」样本——后者需要扰动/WMA，属于高风险扩展。
- **Q5（延迟与合规）**：蒸馏小 head 的 p99 能否守住预算？课程是训练期行为，是否完全规避「跨 episode 在线更新」的合规疑问？测试时只用**冻结**的能力估计，是否足够？
- **Q6（与 SAGE 的交互）**：课程层对 IP-01 路由、IP-02 抓握确认、IP-06 代理评测的边际贡献分别是多少？是互补还是重复？

## 4. 设计原则（在 P1–P6 之上新增）

- **P14 语义模型不是传感器**：VLM/SemCritic 只负责语义与粗进度；接触、插入、滑移的最终判据必须来自几何信号（IP-02）。任何让语义置信度覆盖几何证据的设计一律进黑名单。
- **P15 难度是策略相对的**：禁止用「任务平均成功率」当课程难度；课程难度必须由当前策略的 rollout（或以其为条件的语义模型）估计。本轮实验是这条原则的实证依据。
- **P16 课程要带覆盖护栏**：任何非均匀采样都必须满足 `KL(q‖u) ≤ ε` 并保留 uniform replay 概率 λ；没有护栏的自步课程不进主线。
- **P17 可学性门**：只有同时满足 headroom ≥ h₀ 与 ceiling ≥ c₀ 的样本才允许加权；不可学的难任务只做诊断，不做主训练目标。
- **P18 能离线就离线**：优先训练期课程与离线蒸馏；测试时只读**冻结**的能力估计，不做在线权重更新（合规风险最低）。
- **P19 先证伪再投入**：每个新组件都必须有一个「若 X 不成立就砍掉」的预注册判据；本轮尤其针对「VLM 难度是否优于元数据基线」。

## 5. 最小可提交闭环（MVP）与退化链

**MVP = MVP-0（难度探针）+ MVP-1（自步课程，纯 rollout，不用 VLM）+ MVP-2-lite（SemCritic 只做相位进度，带弃权）+ 覆盖护栏。**

理由：MVP-0 决定「VLM 难度」这条线值不值得做；MVP-1 不依赖 VLM，是**即使语义线全砍也能独立成立**的机制改动；MVP-2-lite 只做最可靠的「相位进度」，不碰接触判断；覆盖护栏保证课程不会把长尾饿死。

**严格退化链（任一环节不可用 ⇒ 回退而不是漂移）**：

- **Level-0** VLM 难度不优于元数据基线（Spearman ≤ 0.3）⇒ **砍掉 VLM 难度估计**，课程只用 rollout 自步信号。
- **Level-1** SemCritic 校准不达标（ECE > 0.1 或可信区错误率 > 5%）⇒ **关闭 critic 的介入权**，只保留其诊断输出。
- **Level-2** 自步课程导致覆盖坍缩/长尾下降 ⇒ 提高 λ（uniform replay）直至退回均匀采样。
- **Level-3** 回溯子目标标签噪声过大 ⇒ **砍掉 IP-11**，只用原始长任务数据。
- **Level-4** 能力阶梯切换抖动/误降档 ⇒ 退回第 1 轮的静态退化链。
- **Level-5** 整层失效 ⇒ 提交**纯 SAGE 基线**（始终保留一个能跑、可信、可审计的最小提交）。

## 6. 预期贡献（可验收）

1. **一个可复现的负结果**：证明「任务级难度」在 8×32 teaser 上 ill-posed（W≈0.06、top-2 W≈0.0007），且廉价元数据反预测（LOO R²<0）。这把「按任务难度排课程」这条常见路线正式排除，是公共品。
2. **一个难度是策略相对的课程框架**：自步难度场 + 可学性门 + 覆盖护栏，给出与 IP-01 专家划分对齐的最小课程单元。
3. **一个带校准/弃权契约的蒸馏 critic**：把大 VLM 的语义判断压缩到 VLA 主干特征上的小 head，给出「能力边界」的实测曲线（覆盖率—风险曲线），并证明它不会在接触层越权。
4. **一个数据效率杠杆**：相位倒带 + VLM 子目标重标注，在不采集新真机数据的前提下生成短时域课程；诚实区分「在轨子目标样本」与「离轨恢复样本」。
5. **一个测试时课程阶梯**：把静态退化链升级为按能力排序的阶梯，并给出「何时降档」的可验证判据。

## 7. 本轮最大风险（一句话）

**语义—几何鸿沟：VLM 及其蒸馏 critic 在粗粒度语义子目标上最自信、在决定分数的细粒度接触/插入上最不可靠，而自步课程又可能把训练预算从稀有的最后一环样本上抽走——于是整层可能「平均校准得很好」，却恰好在最该判对的地方判错。**

# 第 1 轮产物 · 创新点清单 v1（UniBot 线）：**SAGE-C**
> **SAGE-C = SAGE + Self-paced semantic Curriculum**（语义课程层）。

## 0. 本轮结论摘要

**一句话路线**：第 1 轮把「抓取 / 技能 / 适应」编译成 SAGE；本轮补上**训练调度层**——用「视觉语言模型」提供**语义子目标与（以 rollout 为条件的）难度先验**，用「课程学习」把这些先验变成**自步的、带可学性门与覆盖护栏的采样器**，并在测试时把静态退化链升级为**能力阶梯**。对外仍是**单 checkpoint、单 API**；新增的只是一个离线蒸馏的小 critic head 与训练期采样器。

**为什么是这个组合（四条量化依据，本轮真实复算，n=8×32 teaser）**：

| 证据 | 数值 | 推出的设计 |
|---|---|---|
| 跨模型难度一致性（Kendall W） | **0.058**（top-2 仅 **0.0007**） | 不存在全局「任务难度」⇒ 课程必须**策略相对（self-paced）**，不能按任务均值排序 |
| 廉价元数据预测难度（rubric 步数 + 名称词数） | LOOCV **R²=−0.222**，Spearman **−0.310** | 训练前元数据几乎无信息 ⇒ 难度信号必须来自 **rollout 或以其为条件的语义模型** |
| 方差分解（任务 / 模型 / 交互） | **16.4% / 23.3% / 60.2%** | 60% 是模型×任务交互 ⇒ 课程最小单元是 **(任务 × 相位 × OOD 轴)**，与 IP-01 专家对齐 |

## 1. 本轮真实实验：难度到底属于谁？（负结果 + 结构性正结果）

### 1.1 设计

- **数据**：`exp/r16_leaderboard_data.json`，8 个通才模型 × 32 个任务的成功率矩阵 `S ∈ R^{8×32}`；任务元数据取自 `exp/r16_leaderboard_stats.json`（`rubric_steps`、任务名等）。
- **脚本**：`exp/vlm_curriculum_probe.py`（主分析）、`exp/vlm_curriculum_probe2.py`（top-k 一致性、leader 画像）；结果落盘 `exp/vlm_curriculum_probe_results.json`。
- **问题**：课程学习需要「由易到难」的排序；这个「难」是**任务属性** `D(τ)`，还是**策略相对量** `D(τ | π)`？
- **方法**：(a) 跨模型难度排序一致性（Kendall W、两两 Spearman）；(b) 用训练前就能拿到的廉价元数据做留一任务线性回归（LOOCV R²），预测任务平均成功率；(c) 方差分解；(d) 难/易四分位的 headroom 与天花板对比；(e) oracle 增益的难度分布。

### 1.2 结果

| 量 | 结果 | 解释 |
|---|---|---|
| Kendall W（8 模型对 32 任务的难度排序） | **0.0581** | 几乎不一致 |
| Kendall W（仅 top-2 模型） | **0.0007** | 连最强两模型都不一致 ⇒ 不是弱模型噪声 |
| 两两 Spearman | 均值 **0.0977**，范围 **[−0.155, 0.291]** | 接近正交，与第 1 轮 τ≈0.064 同源 |
| 廉价元数据（rubric 步数 + 名称词数）LOOCV R² | **−0.2224** | 比直接猜均值还差 |
| 上述预测的 Spearman（预测 vs 真难度） | **−0.3105** | 方向甚至是反的 |
| 加入「任务平均时长」后的 LOOCV R² / Spearman | **−0.2909 / −0.4003** | 时长也救不了 |
| 方差分解：任务 / 模型 / 交互 | **16.4% / 23.3% / 60.2%** | 交互主导 |
| 最难四分位平均 headroom vs 最易四分位 | **10.03 vs 8.38** | 难任务仍有可学空间 |
| Spearman(难度, 单任务最高成功率) | **−0.5370** | 越难天花板越低 |
| oracle 增益落在最难四分位的比例 | **28.5%** | 略高于均匀（25%） |
| 任务内跨模型成功率标准差（均值） | **5.597** | 与第 1 轮 5.60 一致 |

**最难 8 任务**（按 8 模型均值）：Plug In Ethernet、Unlock、Spell robot、Organize Stationery、Open Pill Bottle、Hang the Cup、Pick Out Battery、Zip Up。**最易 8 任务**：Color Arrangement、Remove Pinned Note、Fruit Basket Collection、Store Earphones、Place Photo Frames、Paper Cup Stacking、Conveyor Food Sorting、Stack Cups。

### 1.3 四条推论（直接决定设计）

1. **任务级课程是 ill-posed 的**：W≈0.06、top-2 W≈0.0007。按任务平均成功率排出的「由易到难」，对任意一个具体策略的排序信息量接近零。**这条常见路线可以正式砍掉。**
2. **难度信号必须条件于策略**：廉价元数据 LOOCV R²<0 且 Spearman 为负。能用的信号只有两类：**策略自己的 proxy rollout 成功率**，或**以该 rollout 为条件的语义模型判断**（VLM 看失败现场，判断卡在哪个子目标）。
3. **课程要带可学性门**：难任务 headroom 更大（10.03>8.38）但天花板更低（ρ=−0.537）。只按「难」加权会把预算烧在不可约的难上；门要同时看 headroom 与 ceiling。
4. **课程单元必须细于任务**：交互方差 60.2% 说明「任务」不是最小可辨识单元；最小单元应是 **(任务 token × 相位 × OOD 轴)**，与 IP-01 的专家、IP-06 的六因子对齐。

### 1.4 这个实验不能证明什么（诚实边界）

- 它是**回溯性结构分析**，不是训练实验：**不能**证明课程一定涨点，只能证明「任务级难度排序」这条最便宜的路线 ill-posed。
- teaser 表由 `gen_leaderboard.py` 生成、官方未正式发布；数字的**量级**可能变，但「排序一致性极低」这一结论对**秩**敏感、对绝对分数不敏感，故结构性结论相对稳健。真正结论仍须真机/正式榜复核（E620 预注册）。
- 8 个模型是不同团队的不同架构；低一致性也可能部分来自「评测噪声」。因此我们不把 W 当作「难度不存在」的证明，而当作「**不能用任务均值当课程难度**」的充分理由。

## 3. 创新点详述

### IP-09 · SemCritic：蒸馏选择性 critic（P0）

- **动机**：第 1 轮的 VLM 只做离线伪标（IP-01 相位、IP-06 六因子）。但伪标的核心风险不是「不够准」，而是「在未见物品上整体漂移且不自知」。一个**知道自己何时不该说话**的 critic，比一个平均更准的 critic 更安全。
- **与现有方案的差异**：现有做法要么把大 VLM 放进推理环（延迟爆），要么只用它离线打标（无法在线判进度）。我们做**离线大 VLM 教师 → 主干特征上的小 head 学生**：学生只读 VLA 已计算的视觉-语言特征，额外延迟极小；学生输出 `(s, κ)`，`κ` 由校准集上的可信区 `C` 决定，边界外弃权。
- **技术可行性**：高。①大 VLM 离线给每条演示的每个子目标打「完成/未完成」标签（可人工抽检 5%）；②学生在冻结主干特征上做二分类/回归；③用 held-out 校准集画可靠性图，选 `C` 使可信区错误率 ≤α；④部署只跑小 head（≤6 ms）。
- **所需资源**：数据 = 官方 32 数据集 + 离线 VLM 标签；算力 = 小 head 单卡数小时；接口 = 无新增字段（纯策略内部）。
- **落地步骤**：①定义子目标图（U13）；②大 VLM 批量打进度标签 + 人工抽检；③训练小 head + 温度标定；④画覆盖率—风险曲线，定可信区 `C`；⑤把 `(s,κ)` 接到 IP-01 相位 token、IP-02 抓握第二意见、IP-12 降档判据；⑥**接触级判断强制走 IP-02 几何信号**，SemCritic 只做语义旁证。
- **风险**：①语义—几何鸿沟 ⇒ 用 P14 硬隔离，接触级永不采纳 critic；②学生蒸馏失真 ⇒ 监控学生-教师一致率，低于阈值就扩大弃权区；③标签噪声在未见物品上放大 ⇒ 弃权区随 OOD 轴自适应扩大。

### IP-10 · SelfPaced Curriculum：自步语义课程（P0）

- **动机**：本轮实验证明任务级难度 ill-posed、廉价元数据反预测。课程必须策略相对，且单元要细到 (任务 × 相位 × OOD 轴)。
- **与现有方案的差异**：常见做法是「按任务难度/课程阶段手工排序」或「先训简单任务」。我们改为**自步**：用 IP-06 代理评测给出当前策略在 (任务, 相位, OOD 轴) 上的失败率 `D̂`，在 `|D̂ − ρ|` 小的 ZPD 区域采样；用可学性门过滤不可学项；用 uniform replay 保覆盖。
- **技术可行性**：中–高。核心是一个带约束的采样器，不要求新模型；难度估计可先用纯 rollout（不依赖 VLM），再叠加 SemCritic 先验。
- **所需资源**：数据 = 官方 32 数据集 + 自建 5 轴 OOD 增强；算力 = 训练调度，无额外推理；接口 = 无。
- **落地步骤**：①把 5 类泛化场景实现为 5 个可调难度旋钮（U23）；②用 IP-06 的代理评测估计 `D̂`；③实现 ZPD 采样 + 可学性门 + uniform replay；④等算力对比均匀采样；⑤消融门/护栏；⑥把课程与 IP-01 的专家划分对齐（每个专家只吃自己负责的相位段）。
- **风险**：①覆盖坍缩/长尾遗忘 ⇒ KL 护栏 + λ replay（L11）；②难度估计噪声 ⇒ 用滑动窗口 + 置信区间，低置信时退回均匀；③课程与专家耦合过紧 ⇒ 保留全局 replay 专家。

### IP-11 · Hindsight Subgoal Curriculum：回溯子目标课程（P1）

- **动机**：真机数据只有 32 份成功演示，采集新数据极贵。成功轨迹里其实蕴含大量「从中间状态完成后续子目标」的短时域样本，只是没有被显式标注。
- **与现有方案的差异**：常见做法是整条轨迹训练。我们在相位边界 `t` 处「倒带」，把后缀 `(a_{t:T})` 重新标注为「从 `o_t` 达成子目标 `g_{t:T}`」的样本；用 VLM 给子目标命名/校验。这等价于把长任务拆成课程化的短任务。
- **技术可行性**：中。**必须诚实**：倒带样本是**在轨**的（原始动作确实能到达子目标），因此它教的是「从轨迹中间继续」，**不是**「从偏离状态恢复」。要造离轨恢复样本，需要扰动或官方 WMA 反事实 rollout——这是高风险扩展，不进 MVP。
- **所需资源**：数据 = 官方演示（无需新采集）；算力 = 小；接口 = 无。
- **落地步骤**：①相位边界检测（复用 IP-01/IP-06）；②VLM 子目标标注 + 一致性校验；③生成短时域样本；④课程按剩余时域长度排序（短→长）；⑤与原始长任务数据混合训练；⑥消融「倒带样本」的边际贡献。
- **风险**：①子目标标签噪声 ⇒ 双标注 + 弃权；②在轨样本被误当恢复样本 ⇒ 在报告中明确区分，不宣称恢复能力；③短时域过拟合 ⇒ 保留长任务比例。

### IP-12 · Curriculum Ladder：测试时能力阶梯（P1）

- **动机**：第 1 轮的退化链是手写静态的。既然难度是策略相对的，退到哪一档也应由当前策略的**能力估计**决定，而不是固定顺序。
- **与现有方案的差异**：把「Level-0…Level-4」重排为按**验证成功率**排序的阶梯；每档有可验证的成功判据 `θ_r`；SemCritic/IP-02 检测到当前档失败就降档，而不是等超时。
- **技术可行性**：中。需要每档的离线成功率估计与在线失败检测；降档动作要平滑，避免抖动。
- **所需资源**：接口 = 无；算力 = 极小；数据 = 无（用现有档位的离线 A/B）。
- **落地步骤**：①给每档估计成功率与切换代价；②实现「最高可用档」选择 + 失败降档；③加滞回（最小驻留时间）防抖；④与静态链 A/B；⑤审计降档日志。
- **风险**：①误降档损失成功率 ⇒ 滞回 + 只在强证据下降档；②档间切换抖动 ⇒ 最小驻留 + 代价惩罚；③测试时读能力估计是否合规 ⇒ 只用冻结值（P18）。

### IP-13 · VLM Affordance Gate：开放词表可抓性门（P2）

- **动机**：IP-02 的可抓性判定是规则/几何启发式，在未见物品上可能失效；VLM 的开放词表常识正好补这一块。
- **与现有方案的差异**：把「该抓法在单自由度夹爪下是否可行」交给 VLM 做**粗判**，几何做**细判**；不可行则路由到非抓取原语。
- **技术可行性**：中。VLM 对「宽物夹不住」「旋转类需要指端」有常识，但对精确开口宽度不可靠 ⇒ 只做粗门，阈值由几何复核。
- **所需资源**：离线 VLM + IP-02 原语库；算力小。
- **落地步骤**：①构建开放词表可抓性问答集；②VLM 粗判 + 几何细判级联；③未见物品 A/B；④与规则版对比。
- **风险**：VLM 高置信错误 ⇒ 几何复核有一票否决；类别偏置 ⇒ 用 5 轴 OOD 评测。

## 4. 符号与定义（U13–U24）

| 符号 | 含义 |
|---|---|
| `G=(V,E)` | 子目标图：节点为语言接地子目标，边为先后约束 |
| `v ∈ V` | 子目标（reach/grasp/lift/transport/align/insert/place/release） |
| `s_t(v)` | SemCritic 给出的「子目标 v 在 t 时刻已完成」概率 |
| `κ_t(v)` | 可信标记 ∈{trust, abstain} |
| `C` | 校准后的可信区（critic 允许发言的输入集合） |
| `D_VLM(τ,v,s)` | 以 rollout 为条件的 VLM 难度场 |
| `D_π(τ,v)` | 策略相对难度（proxy rollout 失败率） |
| `a ∈ {pos,dist,bg,unseen,human}` | 5 类泛化（OOD）轴 |
| `k_a` | OOD 轴 a 的难度旋钮 ∈[0,1] |
| `q_t` | 第 t 步的课程采样分布 |
| `u` | 训练支持集上的均匀分布 |
| `ρ` | ZPD 目标难度中心 |
| `β` | 课程步长/锐度 |
| `g(τ,v)` | 可学性门 ∈{0,1} |
| `h, c` | headroom（max−mean）与 ceiling（max） |
| `λ` | uniform replay 概率 |
| `L=(r_1,…,r_m)` | 测试时能力阶梯（档位） |
| `θ_r` | 档位 r 的降档阈值 |
| `H(ξ,t)` | 相位倒带重标注算子 |
| `(α,δ)` | 选择性风险契约：可信区错误率 α、覆盖率下界 1−δ |

**定义 U13（子目标图）** 由离线 VLM 从 `(ℓ, o_0)` 生成有向无环图 `G=(V,E)`；`V` 覆盖从初始到终态的必要子目标，`E` 为先后约束；终态子目标谓词等价于任务成功谓词。生成后用人工抽检 5% 校验。

**定义 U14（选择性进度 critic）** `f_c(φ(o_t), v) → (s_t(v), κ_t(v))`，其中 `φ` 为 VLA 主干冻结特征；`κ_t(v)=trust` 当且仅当 `φ(o_t)` 落在校准可信区 `C` 内，否则 `abstain`。**只有 `trust` 的输出允许进入损失或介入逻辑。**

**定义 U15（VLM 难度场）** `D_VLM(τ,v,s) = P(fail | τ, v, s, ξ_{t-k:t})`，其中 `s` 为场景描述子、`ξ_{t-k:t}` 为当前策略最近 rollout 片段。**关键：条件于 rollout，而不是只条件于任务名**——这是本轮负结果要求的。

**定义 U16（策略相对难度）** `D_π(τ,v) = 1 − \hat{P}_π(success | τ,v)`，由 IP-06 代理评测的 rollout 估计；带滑动窗口与置信区间。**这是课程的主信号；`D_VLM` 只是先验。**

**定义 U17（自步采样）** `q_t(τ,v,a) ∝ g(τ,v) · exp(−β|D̂(τ,v,a) − ρ|)`，其中 `D̂` 为 `D_π` 与 `D_VLM` 的融合估计；最终采样 `q'_t = (1−λ) q_t + λ u`。

**定义 U18（可学性门）** `g(τ,v) = 1[h ≥ h_0] · 1[c ≥ c_0] · 1[σ_label ≤ ν]`；`h` 为 headroom、`c` 为 ceiling、`σ_label` 为标签噪声估计。

**定义 U19（能力阶梯）** `L=(r_1,…,r_m)`，按验证成功率降序、鲁棒性升序排列；在状态 `o_t` 选择最高档 `r*` 使 `ŝ_r(o_t) ≥ θ_r`；若连续 `n_drop` 步 `ŝ_{r*} < θ_{r*}`，降到下一档，并受最小驻留时间约束。

**定义 U20（相位倒带重标注）** 对成功轨迹 `ξ=(o_0,a_0,…,o_T)` 与相位边界 `t`，`H(ξ,t) = (o_t, a_{t:T}, g_{t:T})`，`g_{t:T}` 为 VLM 标注的后缀子目标序列。**仅对在轨状态有效**；离轨恢复样本需额外扰动算子（不在 MVP）。

**定义 U21（选择性风险契约）** critic 在 `C` 上 `(α,δ)`-valid：`P(error | trust) ≤ α` 且 `P(trust) ≥ 1−δ`（在标定分布上）。部署前必须报告覆盖率—风险曲线。

**定义 U22（覆盖护栏）** 约束 `KL(q'_t ‖ u) ≤ ε_t`；`λ` 保证 `q'_t` 在 `u` 的每个支撑点上有正概率，从而不永久饿死任何任务/相位。

**定义 U23（OOD 难度旋钮）** `k=(k_1,…,k_5) ∈ [0,1]^5`，`P_k` 为对应增强分布；课程按轴单调提升 `k_a(t)`，可一次只升一个轴（block curriculum）或联合升。

**定义 U24（critic 延迟预算）** 摊销延迟 `c_feat + c_head/K`；要求总 p99 ≤ `τ_budget`（沿用第 1 轮 105 ms 量级）。`K` 为 critic 调用间隔。

## 5. 关键算法骨架

```python
# ===== IP-09：选择性语义 critic（学生 head 读主干冻结特征）=====
class SemCritic:
    def __init__(self, ckpt, trust_region):          # trust_region 来自校准集
        self.head = load_small_head(ckpt)            # ≤6 ms
        self.C = trust_region

    @torch.no_grad()
    def score(self, feat, v):
        s = torch.sigmoid(self.head(feat, v)).item() # U14 进度分
        kappa = "trust" if in_region(feat, self.C) else "abstain"
        return s, kappa

# ===== IP-10：自步语义课程采样器 =====
class SelfPacedSampler:
    def __init__(self, rho=0.5, beta=4.0, h0=2.0, c0=20.0, lam=0.3, eps=0.5):
        self.rho, self.beta, self.h0, self.c0, self.lam, self.eps = rho, beta, h0, c0, lam, eps
        self.D = {}                                  # (tau,v,a) -> D_hat (U16)
        self.h = {}; self.c = {}                     # headroom / ceiling

    def gate(self, key):                             # U18 可学性门
        return int(self.h.get(key, 0) >= self.h0 and self.c.get(key, 0) >= self.c0)

    def probs(self):
        keys = list(self.D)
        w = np.array([self.gate(k) * math.exp(-self.beta * abs(self.D[k] - self.rho))
                      for k in keys], float)
        q = w / max(w.sum(), 1e-9)
        u = np.full(len(keys), 1.0 / len(keys))
        q = (1 - self.lam) * q + self.lam * u      # U17 + U22
        # 若 KL(q||u) > eps，进一步向 u 回拉
        return keys, project_kl(q, u, self.eps)

    def update(self, key, success, max_success):
        self.D[key] = 0.9 * self.D.get(key, 0.5) + 0.1 * (1 - success)   # U16
        self.h[key] = max_success - success
        self.c[key] = max_success

# ===== IP-11：相位倒带重标注 =====
def hindsight_relabel(traj, boundaries, vlm):
    out = []
    for t in boundaries:
        suffix = traj[t:]
        goals = vlm.label_subgoals(traj.obs[t], suffix.obs)   # U20
        if goals.is_consistent and goals.confidence >= TAU_G:
            out.append((traj.obs[t], suffix.actions, goals.sequence))
    return out                                   # 仅在轨；不宣称恢复能力

# ===== IP-12：测试时能力阶梯 =====
class CurriculumLadder:
    def __init__(self, rungs, thetas, n_drop=3, dwell=5):
        self.rungs, self.thetas = rungs, thetas
        self.n_drop, self.dwell = n_drop, dwell
        self.cur, self.cnt, self.stay = 0, 0, 0

    def act(self, obs, critic):
        if self.stay < self.dwell:
            self.stay += 1
            return self.rungs[self.cur].act(obs)
        s, kappa = critic.score(features(obs), self.rungs[self.cur].goal)
        bad = (kappa == "trust" and s < self.thetas[self.cur])
        self.cnt = self.cnt + 1 if bad else 0
        if self.cnt >= self.n_drop and self.cur + 1 < len(self.rungs):
            self.cur += 1; self.cnt = 0; self.stay = 0     # 降档（带滞回）
        return self.rungs[self.cur].act(obs)

# ===== 与 SAGE 策略的集成（仍是单 checkpoint、单 API）=====
class UniBotSAGECPolicy(UniBotSAGEPolicy):
    def train_step(self, batch, sampler, critic):
        keys, q = sampler.probs()
        batch = resample(batch, keys, q)                  # IP-10 课程
        loss = self.model.loss(batch)
        # IP-09：只有 trust 的语义监督进损失，且不覆盖几何抓握损失
        for v, (s, kappa) in critic_labels(batch):
            if kappa == "trust":
                loss += self.lambda_sem * bce(self.model.progress_head(batch), s)
        return loss
```

## 6. 推导（引理 L8–L14）

**引理 L8（难度是模型相对的 ⇒ 任务级课程的信息上界）** 设 `S_{ij} = μ + a_i + b_j + ε_{ij}`，`a_i` 为模型效应、`b_j` 为任务效应、`ε_{ij}` 为交互。若课程按任务效应 `b_j` 排序，则它只能解释任务主效应所占的方差份额；交互方差 `σ_ε²` 无法被任何任务级排序利用。本轮实测：任务 **16.4%**、模型 **23.3%**、交互 **60.2%**，且 Kendall W=**0.058**。故任务级课程对具体策略的排序信息量上界约为任务主效应份额，**不足以支撑「按任务难度排课程」**；必须引入策略相对信号。∎（注：方差份额与 Spearman 不是同一量，此处给的是信息上界的量级论证，不是精确等式。）

**引理 L9（可学性门）** 设任务 `(τ,v)` 当前成功率 `p`、天花板 `c`、headroom `h=c−p`。对其增加一单位训练预算的期望边际增益近似 `η·h·1[p∈ZPD] − η·noise(c)`；当 `c` 低于阈值 `c_0` 时，`noise(c)` 主导，增益可变为负。故门 `g=1[h≥h_0]·1[c≥c_0]` 防止课程把预算烧在不可约的难上。本轮实测：难四分位 `h=10.03` > 易四分位 `8.38`，但 `c` 随难度下降（Spearman **−0.537**），说明两个条件都非平凡。∎

**引理 L10（选择性监督的风险界）** 若 critic 在可信区 `C` 上错误率 ≤α、弃权区回退监督错误率 ≤α₀，则期望监督误差 `E ≤ α·P(C) + α₀·(1−P(C))`。选择 `C` 使 `α` 最小化即可最小化上界；结合第 1 轮 L3 的非对称代价，令 `α ≤ α_max` 即保证介入净收益为正。∎（标准选择性预测界。）

**引理 L11（课程覆盖护栏）** 用 `q` 替代均匀 `u` 训练，测试分布上的泛化间隙含一项 `O(KL(q‖u))`（重要性加权/覆盖论证的量级）。约束 `KL(q'_t‖u) ≤ ε` 并以 `λ` 混入 `u`，使 `KL(q'_t‖u) ≤ (1−λ)KL(q_t‖u)`，从而把「课程的代价」压到 `O(ε+λ)`。这是 uniform replay 的形式化理由，不是「课程一定有益」的证明。∎

**引理 L12（回溯重标注的有效性与边界）** 对成功轨迹的后缀 `(o_t,a_{t:T})`，原始动作确实从 `o_t` 到达了后续子目标 `g_{t:T}`，故 `(o_t,a_{t:T},g_{t:T})` 是**目标条件化**目标的有效在轨演示；其偏差由子目标标签误差界定。**但它不是离轨恢复样本**：`o_t` 在原始成功路径上，未覆盖「偏离后如何回来」。要获得恢复样本必须引入扰动/WMA 反事实，属于额外假设。∎

**引理 L13（critic 延迟摊销）** 若 critic 每 `K` 步在缓存特征上运行一次，单次成本 `c_c`，则摊销延迟 `c_c/K`。取 `K=8`、`c_c≈40 ms`，摊销 ≈**5 ms**，相对第 1 轮 105 ms 预算可忽略；`p99` 由 `c_feat + c_c/K` 主导。∎

**引理 L14（能力阶梯优于固定档的条件）** 将每档视为一个「成功率随状态变化」的臂。若顶层档在某些可检测状态上成功率高于底层、且 critic 的失败检测 AUC > 0.5，则「先试顶层、失败降档」的期望成功率不低于固定底层档，增益随 `(AUC−0.5)` 与顶层档成功率的**状态间方差**增大；当 `AUC=0.5` 时退化为固定档。故阶梯的收益来自「状态相关的可检测性」，不是来自档位本身。∎（启发式/bandit 论证，非精确定理。）
