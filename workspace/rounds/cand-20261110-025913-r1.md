# 第 41 轮 · 双灵感落地 v18：物性场 × 接触选型 × 语言-物理互校验（「材料-语言-接触」回路，Δ-Plane 四账本，四层架构 v6）

> 承接第 40 轮（v17：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹，四层架构 v5）。本轮灵感词「材料选型 / 语音交互」。这两个词乍看离「远程 VLA 服务化」很远：材料是硬件工程师的事，语音是交互设计师的事。但把 v17 的 P0 假设逐条摊开后会发现，它们戳中的是同一个被默认掉的变量——**v17 把物体压缩成「几何包络 + 类别先验」，把语言压缩成「一次性任务标签」，而真实桌面任务里，决定抓得住抓不住、放得准放不准的，往往是几何与类别之间的第三维度：物性（摩擦、质量、柔顺、光泽/透明、热容）**。材料不是我们能选的硬件，但「材料 → 选型」是一个可计算的决策：识别物性后选择接触模式（抓取位、法向力、加速度上限、释放策略、感知模式、专家分支）。语音也不是实时对话——官方只给单条静态文本（F60），但**语言里的物性形容词（fragile/soft/heavy/slippery）本身就是物性先验**，而「交互」可以诚实地落在「语言先验 ↔ 物理探测」的互相校验上。**v18 的主轴：把「物性」升格为可辨识、可记账、可被语言初始化、可被接触验证的一等状态，形成 语言→物性先验→主动探测→物性后验→接触选型→滑移/变形观测→更新 的物性接地回路（Material Grounding Loop, MGL）；Δ-Plane 从三账本扩为四账本（新增物性不确定性 U_mat）。**

## 0. 联网核实（先事实后推理；检索口径 2026-11-10，来源链接见产物区 §5）

- **事实 F67（触觉操作综述，arXiv 2610.30438，2026-10-21）**：触觉可推断对操作至关重要的物性——质心、硬度、表面粗糙度、摩擦、乃至液体黏度；这类估计通常依赖**交互式感知（interactive perception）**：机器人主动探测并解释触觉响应，感知与动作紧耦合。**含义：物性不是「看一眼就知道」的属性，而是要靠动作去问的隐变量。**
- **事实 F68（视触觉物体感知综述，Autonomous Robots 2023，DOI 10.1007/s10514-023-10091-y）**：重量、材料、纹理无法仅靠视觉获得；且视觉本身在**半透明、反光、遮挡**物体上会失效。**含义：透明杯/金属罐/塑料袋恰好同时打击 v17 的深度感知与几何包络。**
- **事实 F69（物理接地 VLM，PHYSOBJECTS，ICRA 2024，DOI 10.1109/ICRA57147.2024.10610090）**：现有 VLM 对材料、易碎性等物理概念理解有限；39.6K 众包 + 417K 自动标注的物体级物理概念数据可显著改善 VLM 的物理概念理解，并提升 LLM 规划器在需物理推理任务上的成功率。**含义：物性可以先验地由视觉语言模型给出，但必须被下游接触验证，否则只是「看起来像」。**
- **事实 F70（物性语言需要接触本地接地，EMNLP 2026，aclanthology 2026.emnlp-main.1120「Touch What You Say」）**：fragile、coarse-grained 这类物性形容词在视觉上常**歧义**，其约束应主要在**接触阶段**调制行为；CLSA 用语言引导的触觉瓶颈 + 接触门控残差，在 140 次真机对比与 240 次 APC 扫描中提升指令敏感性、接触阶段误差较无触觉基线降约 20%，并在视觉不可辨的黑袋任务上靠接触区分材料。**含义：语言给的是「接触阶段该谨慎」的先验，而不是全程的硬约束；这正好是我们没有触觉时的设计约束。**
- **事实 F71（无触觉/无力传感器的力与滑移估计）**：Expert Systems with Applications 2023（DOI 10.1016/j.eswa.2022.118441）用 RGB+D + 机器人位姿 + 电流估计交互力，已知/未见物体误差 <3%；VFTS（arXiv 2210.00051）用外部鱼眼相机估计软爪 6 轴力/力矩；FingerVision（Yamaguchi & Atkeson, Humanoids 2017）用透明指皮直接观测物体相对位移来做**与接触力无关的滑移检测**，可无损伤抓取折纸。**含义：官方接口虽无触觉/力矩，但「视觉相对位移 + 位姿 + 目标轨迹残差」可作为滑移/力的代理观测——这是 A39 的可行退路。**
- **事实 F72（语音来源文本的鲁棒性）**：HRI 语音理解长期处理 disfluency（填充词、被放弃的词、自我修正）、省略与指代（Cantrell et al., Tufts HRI Lab）；ASR 对同音词/最小对立对尤其脆弱；Seq2Seq + 噪声注入（Frontiers in Robotics and AI 2019）可提升机器人指令在 ASR 错误下的语义解析；词识别难度受韵律、词汇、流畅性多因素影响（Goldwater/Jurafsky/Manning, Speech Communication 2009）。**含义：若官方指令是「说出来的文本」，物性形容词正是同音/断句噪声的高危词；若官方只给纯文本，则「语音交互」只能退化为「口语来源文本鲁棒 + 物性形容词接地 + 机器人侧非语言信号」。**

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（材料选型 → 物体不是刚体几何，是「物性场」）**。v17 的语义图存的是物体位姿 + 碰撞包络，IP-49 的 p_s 按「物体类别 × 技能」分桶，IP-50 的摩擦锥是一个常数。但同一个「杯子」可以是玻璃（低摩擦、易碎、透明）、陶瓷（较重、硬、反光）、纸杯（轻、软、可压溃）、塑料瓶（可变形、低摩擦、高回弹）。几何一样、类别一样，**接触可行性完全不同**：μ 决定多大的切向力会滑，m 决定加速时需要多大的法向力，κ 决定多大的夹持力会压坏，光学属性决定深度/位姿估计是否可信。更要命的是，**我们无法「选硬件材料」**——G1 的指皮与夹爪是固定的；能选的是**接触模式**（抓取位、法向力、加速度/速度上限、释放曲线、感知模式、专家分支）与**对象实例**（在视觉相似的一堆东西里选对那个「软的/重的/易碎的」）。所以「材料选型」在本赛道的严谨落地是：**物性辨识 → 接触模式选型（Material-Conditioned Contact Selection）**，而不是换材料。

**直觉 2（语音交互 → 语言是物性的先验，也是可被物理证伪的假设）**。官方语言指令是单条静态文本（F60），没有实时对话。但文本里天然带物性形容词与比较/对比焦点：「把**易碎**的杯子拿过来」「拿**软**的那个，不是硬的」「**小心**，是玻璃」。这些词在视觉上常常歧义（F70 的 CLSA 正是为此而生），所以正确用法不是把形容词当硬约束，而是把它当**物性先验**：`p(Φ|l)`。然后机器人用一次**可逆的微探测**（微抬、微压、短距拖拽）去获得似然 `p(z|Φ,a)`，得到后验。语言与物理如果一致，先验降低了探测次数（省步数）；如果不一致，**这个冲突本身就是信息**——可能是形容词指错了对象、可能是同音词听错、也可能是 VLM 的视觉先验错了。于是「语音交互」被重新定义为**语言-物理互校验（language-physics cross-validation）**：语言和接触互相提问、互相纠错。这既尊重了接口现实，又把「交互」从人类对话转成了「语义先验 ↔ 物理证据」的交互。

**直觉 3（语音交互的通道诚实：不能假装有麦克风）**。必须把话说死：F60 的观测里语言是一个 `str`，全 episode 不变、无时间轴，**没有音频、没有韵律、没有澄清回合**。所以 v18 只做三件可辩护的事：(a) **口语来源文本鲁棒**——若指令由语音转写而来，物性词是同音/断句高危词，需物性词表约束的重解析与自我修正检测；(b) **形容词/对比焦点接地**——把「软的、重的、易碎的、滑的」映射到物性约束，把「不是那个」映射到对象间序关系；(c) **机器人侧的非语言「发声」**——在人为干扰场景里，用停顿、减速、退让、转向等韵律信号（IP-43）向人表达「我需要空间」，作为 P2 条件机制，绝不声称是语音对话。这条通道诚实原则会写进规则 55。

**直觉 4（物性账与 v17 三账本同构，且是它们的耦合算子）**。物性不确定性 U_mat 不是第五个孤岛，而是把热、步数、时延重新耦合起来：低 μ 需要更大的法向力 → 更大的关节力矩 → 更多发热（接 P43）；主动探测要花步数、时延与热（接 IP-48/IP-49）；物性后验越不确定，TO 的摩擦锥与力约束越保守，运动越慢、步数越多（接 IP-50）。因此探测本身必须做**价值判断**：只有当「探测带来的期望得分增益」大于「步数 + 热 + 时延成本」时才探。这把 v17 的 E_score 从「技能序列选择」扩展为「技能序列 + 探测动作」的联合规划。

**直觉 5（修剪：v18 只买两样东西）**。规则 51 要求每轮剪。对照本赛道现实（唯一本体 G1、官方已开源 VLA 基座、桌面序列任务），v17 中 **IP-42 跨本体运动预训练**（单一本体，边际得分低）与 **IP-44 三阶段渐进蒸馏**（基座 + LoRA/RARA 已覆盖，数据/算力门槛最高）是典型的「能力展示型而非得分型」。本轮把这两项降 P2，兑换给 IP-51/IP-52 两个真正补 v17 短板的 P0，并把 IP-53 作为 P1 的语言侧配套。

## 2. 灵感词 → 落地线（新增 + 重构 + 修剪登记）

- 「**材料选型**」→ **IP-51 MATTER-FIELD（物性场，P0 新增）**：每物体物性后验 `Φ=(μ,m,κ,e,α,c)`（摩擦/质量/柔顺/回弹/光学/热容）+ 视觉-语言先验 + 可逆主动探测（微抬/微压/短拖）+ 滑移/变形/跟踪残差似然 + 透明度/反光感知降级模式 + 物性不确定性 U_mat（第四本账）。定位是「几何与类别之间的第三维状态」。
- 「**材料选型**」→ **IP-52 CONTACT-SELECTOR（接触选型，P0 新增，重构 IP-50 约束层）**：以物性后验为条件，选择抓取位/抓取模式、法向力 F_n、加速度与速度上限、释放曲线、感知模式与专家分支；约束为**分布鲁棒摩擦锥** `|F_t| ≤ μ_lo F_n` 与**压溃上界** `F_n ≤ F_crush(κ_lo)`；目标是把「滑移概率 ≤ δ、损伤概率 ≤ ε」写成机会约束，并显式计入热（低 μ ⇒ 高 F_n ⇒ 高力矩 ⇒ 高温升）。
- 「**语音交互**」→ **IP-53 LANG-MATTER-INTERACTION（语言-物性互校验，P1 新增，重构 IP-32）**：物性形容词/比较/对比焦点 → 物性约束 `p(Φ|l)`；口语来源文本的同音/断句/自我修正鲁棒；语言-物理一致性检验（KL/Bayes 因子）→ 冲突触发重探测/重解析/换对象；机器人侧非语言「发声」作为 P2 条件机制（人为干扰协商）。
- 升级：**IP-36**（语义图增物性场 Φ̂ 与光学属性，供感知模式切换）、**IP-49**（p_s 从 `p_s(s|σ)` 升级为 `p_s(s|σ,Φ)`；探测作为可交易动作进入 E_score 与 VoI 判据）、**IP-50**（摩擦锥/力上界/加速度上限改为分布鲁棒，接 IP-51/52）、**IP-48**（三账本 → 四账本，新增 U_mat；物性→力矩→热的耦合项）、**IP-35**（MuJoCo 代理场景加入物性参数域随机化）、**IP-24/28v2**（滑移/变形/位姿相对位移作为失败信号）、**IP-30**（VLM 判别增加「物性假设是否被观测支持」）、**IP-26**（物理增广轴细化为物性轴：μ/m/κ/光学）、**IP-43**（prosody 兼作非语言「发声」P2）、**IP-21**（物性条件专家路由）。
- 修剪登记：**IP-42 CROSS-EMBODIMENT-MOTION → P2 挂起**（唯一本体 G1，跨本体表征边际得分低）；**IP-44 PROGRESSIVE-CURRICULUM-DISTILL → P2 挂起**（官方/开源基座 + LoRA/RARA 已覆盖，三阶段蒸馏门槛最高）。

## 3. 形式化直觉（严格版见产物区 §3）

**定义 29（物性场 Φ 与后验）**：对物体 i，`Φ_i=(μ_i,m_i,κ_i,e_i,α_i,c_i)∈ℝ^6`，分别为等效摩擦系数（可各向异性）、质量、柔顺（刚度倒数）、回弹、光学属性（反照率/高光/透明度）、热容代理。后验 `p(Φ_i | l, I_{1:t}, a_{1:t}, z_{1:t}) ∝ p(Φ_i) · p(l|Φ_i) · ∏_k p(z_k | Φ_i, a_k)`。**可辨识性警告**：官方观测无触觉/力矩/电流（A39），`Φ` 只能由「视觉外观 + 动作后的相对位移/变形/跟踪残差」间接辨识；某些分量（如 μ 与 m 的乘积效应）可能不可分辨，故 Φ 以**任务相关低维投影** `ψ(Φ)=(μ m, μ, κ, α)` 进入控制，而不是假装六维都可辨识。

**定义 30（物性条件接触选型）**：给定 Φ 后验与任务 τ，选接触计划 `c=(抓取位 p_g, 抓取模式 g, 法向力 F_n, 速度上限 v_max, 加速度上限 a_max, 释放曲线 r)`：
`max_c E_{Φ~p(Φ|·)}[Score(c,Φ,τ)]  s.t.  P_Φ(slip(c,Φ) > s_0) ≤ δ,  P_Φ(damage(c,Φ) > d_0) ≤ ε`
其中滑移条件由切向需求 `F_t = m‖a+g‖ + 外力` 与摩擦锥 `μF_n` 比较给出，压溃条件由 `F_n ≤ F_crush(κ)` 给出。**分布鲁棒化**：用后验下界 `μ_lo=μ̂−z_{1−α}σ_μ`、`κ_lo` 代替点估计，得到「在物性不确定下仍满足机会约束」的保守接触计划；不确定度越高，F_n 上调、a_max 下调（慢而稳），这与 v17 的「高热→降额」同构。

**定义 31（语言→物性先验）**：物性词表 `A` 中每个形容词 a 映射为约束 `C_a ⊆ ℝ^6`（区间或序关系），如 fragile→κ 低/强度低、heavy→m 高、slippery→μ 低、soft→κ 高、hot→c 与初始温度高。语言先验 `p(Φ|l) ∝ p(Φ) · ∏_{a∈A(l)} 1[Φ∈C_a]`（软化为势函数）。对比/焦点结构（「软的那个，不是硬的」）给出对象间约束 `Φ_i ≺_κ Φ_j`。**关键**：这是先验不是事实；F70 已证明物性形容词视觉歧义，故必须允许被接触证据推翻。

**定义 32（语言-物理互校验）**：定义先验与后验的失配度 `D = KL(p(Φ|l) ‖ p(Φ|z,a))`（或用 Bayes 因子 `B = p(z|a, l)/p(z|a)`）。若 `D > θ_mismatch`，判定「语言-物理冲突」，按优先级处置：(i) 重探测（证据不足）；(ii) 重解析/同音纠错（词错）；(iii) 重指涉（形容词指错对象）；(iv) 放弃形容词先验、回退保守接触（先验系统性错误）。**这是「语音交互」在没有对话通道时的可操作定义**。

**定义 33（物性账 U_mat 与探测价值 VoI）**：`U_mat = Σ_i H(Φ_i | ·)`（后验熵）或任务相关投影的协方差迹。探测动作 `u_p` 的价值 `VoI(u_p)=E_z[ΔE_score | u_p] − λ_s·Δsteps − λ_h·Δheat − λ_l·Δlatency`；仅当 `VoI(u_p)>0` 且探测可逆（不改变物体目标状态）时执行。**Δ-Plane 四账本**：`Ledger={H_gpu, Ĥ_motor, S_used, L_p99, U_mat}`，任一越界触发 IP-48 降额；U_mat 越界（太不确定）触发**保守接触 + 探测或回退**，而非硬中止。

## 4. 关键决断

1. **物性一等公民**：Φ 后验与 U_mat 进入 Δ-Plane，接触计划不得在无物性裕度的情况下下发；物性从「感知附属」升为「控制前提」。
2. **选型而非换料**：承认不能改硬件材料；「材料选型」落地为接触模式选型 + 对象实例选择 + 专家分支选择。
3. **语言是先验不是真理**：物性形容词只初始化 `p(Φ|l)`；语言-物理失配是信息，触发重探测/重解析/重指涉，绝不静默信任。
4. **探测要记账**：探测是花步数/热/时延的动作，用 VoI 判据决定；探测必须可逆、有界、可放弃。
5. **修剪两项**：IP-42、IP-44 降 P2，兑换给物性场与接触选型。

## 5. 本轮最大风险（一句话）

**若官方接口确实没有任何力/触觉/电流观测（A39）、物性分量在单目外观 + 稀疏探测下不可辨识（A40）、且指令里根本不含物性形容词或形容词系统性地与外观不符（A41），那么 U_mat 会退化为一个「看似有统计意义、实则不可验证」的隐变量，接触选型可能比「固定保守接触」更差；必须以 E73（物性辨识）/E74（接触选型 A/B）/E75（语言接地）/E76（探测经济学）四重守门，任一失败即回退到「物性无关的保守接触（低加速度、中法向力、视觉滑移检测）」，而不是把不可观测的物性越估越自信。**

# 第 41 轮产物 · 创新点清单 v18：物性场 × 接触选型 × 语言-物理互校验（「材料-语言-接触」回路，Δ-Plane 四账本，四层架构 v6）

> 承接 v17（第 40 轮）。本轮灵感词「材料选型 / 语音交互」经联网核实（口径 2026-11-10）后指向 v17 的同一盲区：v17 把物体压成「几何包络 + 类别先验」，把语言压成「一次性任务标签」，默认物性（摩擦/质量/柔顺/光学/热容）已知或无关。但真实桌面任务的成功率天花板，很大一块恰恰在**几何与类别之间的第三维——物性**；而「语音」在没有实时对话接口（F60 只有单条静态 `str`）时，唯一可辩护的落点是**语言里的物性形容词作为先验，再被物理接触证伪/确认**。v18 新增 **2 项核心 P0（IP-51 物性场 / IP-52 接触选型）+ 1 项 P1（IP-53 语言-物性互校验）+ 第四本账 U_mat**，升级 10 项协作 IP，**修剪 2 项 v17 过度设计（IP-42 跨本体运动、IP-44 三阶段蒸馏 → P2）**。主轴：**从「几何交付」升级为「物性交付」——抓得住、放得稳、不压坏，才算交付。**

## 0. 结论

- **物性场（IP-51，P0 新增）**：每物体后验 `Φ=(μ,m,κ,e,α,c)`（摩擦/质量/柔顺/回弹/光学/热容）+ 视觉-语言先验 + 可逆主动探测 + 滑移/变形/跟踪残差似然 + 透明/反光感知降级 + 物性不确定性 `U_mat`（Δ-Plane 第四本账）。核心不是「估一个材料标签」，而是「估出进入控制的任务相关投影 `ψ(Φ)=(μm, μ, κ, α)` 及其不确定度」。
- **接触选型（IP-52，P0 新增）**：以物性后验为条件选择抓取位/模式、法向力策略、加速度/速度上限、释放曲线、感知模式与专家分支；用**分布鲁棒摩擦锥** `|F_t|≤μ_lo F_n` 与**压溃上界** `F_n≤F_crush(κ_lo)` 写成机会约束；低 μ 导致高 F_n 再导致高力矩/高温升，与 v17 热账本显式耦合。**承认接口只给夹爪标量、不给力控**，故力是「闭环夹到滑移停止」而非开环设定。
- **语言-物性互校验（IP-53，P1 新增）**：物性形容词/比较/对比焦点 → 先验 `p(Φ|l)`；口语来源文本的同音/断句/自我修正鲁棒；语言-物理失配度 `D=KL(p(Φ|l)‖p(Φ|z,a))` 触发重探测/重解析/重指涉/回退保守；机器人侧非语言「发声」仅作 P2 条件机制。**不假装有麦克风与对话回合。**
- **修剪（规则 51）**：IP-42 跨本体运动 → P2（唯一本体 G1）；IP-44 三阶段渐进蒸馏 → P2（官方/开源基座 + LoRA/RARA 已覆盖）。
- **诚实缺口（A39–A43）**：官方接口无触觉/力/电流观测（A39）；物性无标注、数据集门控（A40）；语言是静态 `str`、无音频/韵律/回合（A41）；5 泛化轴是否含材料变化未知（A42）；夹爪指皮材料/最大夹持力未知（A43）。
- **行动项**：A16–A38 延续；**A39–A43 新增**。

## 1. 事实卡（新增 F67–F72，检索日期 2026-11-10）

- **F67（触觉操作综述，arXiv 2610.30438，2026-10-21）**：触觉可推断质心、硬度、粗糙度、摩擦、黏度等操作关键物性；估计通常依赖**交互式感知**——机器人主动探测并解释触觉响应，感知与动作紧耦合。
- **F68（视触觉感知综述，Autonomous Robots 2023，DOI 10.1007/s10514-023-10091-y）**：重量、材料、纹理无法仅靠视觉获得；视觉在半透明、反光、遮挡物体上会失效。**透明/反光正是 v17 深度与几何包络的软肋。**
- **F69（PHYSOBJECTS，ICRA 2024，DOI 10.1109/ICRA57147.2024.10610090）**：现有 VLM 对材料、易碎性等物理概念理解有限；39.6K 众包 + 417K 自动标注的物体级物理概念可改善 VLM 物理理解，并提升 LLM 规划器在物理推理任务上的成功率。
- **F70（CLSA「Touch What You Say」，EMNLP 2026，aclanthology 2026.emnlp-main.1120）**：fragile、coarse-grained 等物性形容词在视觉上常歧义，其约束应主要在**接触阶段**调制行为；CLSA 用语言引导的触觉瓶颈 + 接触门控残差，140 次真机对比中提升指令敏感性、接触阶段误差较无触觉基线降约 20%，并在视觉不可辨的黑袋任务上靠接触区分材料。
- **F71（无触觉/无力传感器的力与滑移估计）**：ESWA 2023（DOI 10.1016/j.eswa.2022.118441）用 RGB+D + 位姿 + 电流估计交互力，已知/未见物体误差 <3%；VFTS（arXiv 2210.00051）用外部鱼眼相机估计软爪 6 轴 F/T；FingerVision（Yamaguchi & Atkeson, Humanoids 2017）用透明指皮直接观测物体相对位移做**与接触力无关的滑移检测**，可无损伤抓取折纸。**三者共同给出 A39 的退路：用视觉相对位移 + 位姿 + 跟踪残差做滑移/力的代理观测。**
- **F72（语音来源文本鲁棒性）**：HRI 语音理解需处理 disfluency（填充词、放弃词、自我修正）、省略、指代（Cantrell et al., Tufts HRI Lab）；ASR 对同音词/最小对立对脆弱；Seq2Seq + 噪声注入（Frontiers in Robotics and AI 2019）可提升 ASR 错误下的机器人指令解析；词识别难度受韵律、词汇、流畅性影响（Goldwater/Jurafsky/Manning, Speech Communication 2009）。**若指令是「说出来的文本」，物性词是噪声高危词；若只给纯文本，则「语音交互」退化为口语来源鲁棒 + 形容词接地 + 非语言信号。**

### 3.2 IP-51 MATTER-FIELD（物性场，完整设计）

**IP 卡片（六字段）**：
- **动机**：F67/F68 证明物性需交互式感知、且视觉在透明/反光/遮挡上失效；F69 证明 VLM 可给物理概念先验但有限；F70 证明物性形容词视觉歧义、需接触阶段调制；F71 证明无触觉时可用视觉相对位移/位姿/跟踪残差做滑移代理。v17 的 p_s 与 TO 完全 material-blind，是本轮最大盲区。
- **与现有方案差异**：现有物性估计几乎都依赖触觉/力/电流（F67/F68/F71 的传感器版），本赛道接口**没有这些通道**（A39）；我们做的是「**无触觉物性辨识**」：视觉外观先验 + 语言先验 + 可逆微探测 + 结果残差似然，并把**可辨识性**写进设计（只估任务相关投影，不假装六维全可辨）。
- **技术可行性**：VLM 物理概念先验（F69）可离线/在线获得；滑移可用「物体相对夹爪的视觉位移」检测（F71 FingerVision 原理，但用外部相机近似）；探测原语（微抬 1–2cm、微压、短距拖拽）都在官方 joint/EE/gripper 接口内；后验用轻量 GP/贝叶斯滤波，<5ms/步。
- **所需资源**：数据=自采物性标定集（玻璃/陶瓷/纸/塑料/织物/金属各若干，离线测 μ/m/κ）+ 在线探测日志；算力=VLM 先验离线批处理 + 在线 GP <5ms；接口=4 相机 + joint/EE + gripper + 语言 `str`，零改造。
- **落地步骤**：① E73 建物性标定集与辨识基线；② 外观/语言先验接入；③ 可逆探测原语与似然模型；④ 滑移/变形观测器；⑤ U_mat 入 Δ-Plane；⑥ E74/E75/E76 验收。
- **风险**：不可辨识（→只估投影 + 保守裕度）；探测本身致损/掉落（→可逆、限幅、失败即停）；透明/反光（→切换感知模式 + 多视角/运动视差）。

**符号表**：

| 符号 | 含义 | 取值/来源 |
|---|---|---|
| `Φ_i` | 物性向量 (μ,m,κ,e,α,c) | 后验；A39 下仅间接可辨 |
| `ψ(Φ)` | 任务相关投影 (μm, μ, κ, α) | 进入控制/约束的低维量 |
| `p(Φ\|l)` | 语言先验 | 物性形容词势函数（IP-53） |
| `z_k` | 探测/执行观测（相对位移、变形、跟踪残差） | 视觉 + 位姿 |
| `U_mat` | 物性不确定性 | `Σ_i H(Φ_i)` 或投影协方差迹 |
| `u_p` | 可逆探测动作 | 微抬/微压/短拖 |
| `VoI(u_p)` | 探测价值 | 期望得分增益 − 步/热/时延成本 |

**算法（后验更新 + 探测选择）**：
```
输入：语言 l、外观 I、当前 Φ 后验、预算 knobs
1. 初始化：p(Φ) ← VLM 物理概念先验(F69) ；p(Φ|l) ← IP-53 势函数
2. 若 U_mat > θ_mat 且 VoI(best_probe) > 0：
     选 u_p* = argmax_u E_z[ H(Φ)-H(Φ|z,u) ] − λ·cost(u)   # 信息增益/成本
     执行可逆探测（限幅：位移≤2cm、力/时长≤安全界）；观测 z
3. 后验更新：p(Φ|z,u) ∝ p(Φ|·)·p(z|Φ,u)
   - 滑移似然：相对位移 > 0 且与指令运动不一致 → 低 μ 证据
   - 变形似然：外观形变/接触面积变化 → 高 κ 证据
   - 跟踪残差：实际 EE 落后于指令 → 高 m 或低 μ 证据
4. 投影 ψ̂=(μ̂m̂, μ̂, κ̂, α̂)，同时输出下界 μ_lo, κ_lo（用于 IP-52/50）
5. 更新 U_mat；写入 Δ-Plane；若 U_mat 仍高 → 标记「不可辨识」，交 IP-52 走保守策略
6. 执行期持续用滑移/变形残差做在线更新（无需额外探测）
```

**正确性论证**：
- **P51（后验一致性）**：在似然正确、探测可交换的前提下，贝叶斯后验以真值邻域收敛；因 A39 下部分分量不可辨，只对投影 `ψ` 声明收敛，`U_mat` 用后验熵给出诚实不确定度，避免过度自信。
- **P52（探测安全性）**：探测动作限幅且可逆（不改变物体目标位姿、不进入不可恢复接触），单次探测的最坏位移/力有上界；失败即停止并回退保守接触。
- **P53（信息增益单调性）**：在给定探测族下，`U_mat` 随观测数单调不增；若某探测对 `ψ` 的 Fisher 信息为 0，则 VoI 判据自动不选它（避免无效探测）。

**已知风险**：视觉滑移在低分辨率/遮挡下漏检 → 多视角 + 相对位姿校验；VLM 先验在未见材料上偏置 → 先验只作初始化、以物理证据为准；探测成本高 → VoI 门控 + 只在关键对象上探。

### 3.3 IP-52 CONTACT-SELECTOR（接触选型，完整设计）

**IP 卡片（六字段）**：
- **动机**：物性决定接触可行性：低 μ 会滑、低 κ/低强度会压坏、高 m 需要更大法向力与更小加速度；v17 的 TO 用常数摩擦锥、p_s 用类别先验，均 material-blind。F70 进一步说明物性语言应在接触阶段调制行为。
- **与现有方案差异**：不是换硬件材料，而是**接触模式选型 + 分布鲁棒机会约束**；并且**承认夹爪接口只给标量目标、不给力控**（F60），所以力不是开环设定，而是「闭环夹到滑移停止/达到安全上界」的反馈策略（FingerVision 式 holding，F71）。
- **技术可行性**：G1 双臂平行夹爪，动作接口含 gripper `[1]×2`；抓取位由 IP-31/36 几何 + 物性区域（如避开易碎处）给出；力策略用「逐步闭合 + 滑移/变形反馈」实现；加速度上限由 `μ_lo` 与 m 估计给出；专家分支路由接 IP-45/IP-21。
- **所需资源**：数据=E73/E74 的滑移/压溃日志；算力=选型查表 + 小规模优化 <2ms；接口=joint/EE + gripper + 视觉，零改造。
- **落地步骤**：① 从 Φ 后验算 μ_lo/κ_lo；② 生成候选抓取位/模式；③ 机会约束筛选（滑移≤δ、损伤≤ε）；④ 闭环夹持策略；⑤ 加速度/速度/释放曲线；⑥ 热耦合权重；⑦ E74 验收。
- **风险**：力不可直接控制（→闭环 + 视觉滑移，不承诺精确力）；物性后验偏保守致动作慢/步数增（→VoI/成功率自动回松）；压溃不可逆（→上限硬约束 + 先探后压）。

**符号表**：`c=(p_g,g,F_n^*,v_max,a_max,r)` 接触计划；`μ_lo=μ̂−z_{1−α}σ_μ`；`κ_lo` 同理；`F_t` 切向需求；`F_crush(κ)` 压溃阈值；`δ,ε` 滑移/损伤机会约束；`w_H` 热权重。

**算法（接触选型）**：
```
输入：任务 τ、ψ̂ 与下界(μ_lo,κ_lo)、几何包络、账本 knobs
1. 候选抓取位/模式：从 IP-31/36 生成 K 个候选（含避让易碎区/重心对齐）
2. 对每个候选估计需求：F_t = m̂‖a+g‖ + 外力上界；滑移裕度 = μ_lo·F_n − F_t
3. 机会约束筛选：P(slip)≤δ 且 P(damage)≤ε；损伤用 F_n ≤ F_crush(κ_lo)
4. 目标：max E[Score] − w_H·Δheat(a_max,F_n)
   - 放置/插入：精度优先（慢接近、末端小步）
   - 转移：时间优先（在 μ_lo 允许下取较大 a_max）
   - 易碎：力优先（F_n 上限 + 闭环微调）
5. 执行夹持：闭环闭合直到「滑移停止」或达 F_n 安全上界（F71 holding 策略）
6. 执行中：视觉相对位移 > s_0 → 立即增夹持/减速（IP-24 失败信号）
7. 释放：按 μ/κ 与目标面选择「轻放/贴合后松/先降速再松」
```

**正确性论证**：
- **P54（机会约束保守性）**：用后验下界 μ_lo、κ_lo 代替点估计，使 `P(slip)≤δ`、`P(damage)≤ε` 在 CP/贝叶斯可信下成立；不确定度越高越保守，不会比固定保守策略更冒险。
- **P55（闭环夹持不劣化）**：若滑移可被视觉检测（F71），闭环「滑移即增夹」在有限步内达到稳定夹持；若检测失效，则退化为固定安全上界，最坏等于保守基线。
- **P56（热耦合不增）**：低 μ 场景下 F_n 上调会增加力矩/热，但 `w_H` 与 IP-48 降额会同时限制 a_max；整体热预算由 Δ-Plane 守门，不允许接触选型突破热账本。

**已知风险**：夹爪标量接口无法精确控力 → 只承诺「滑移/损伤机会约束下的闭环策略」，不承诺精确 F_n；物性后验错误 → 机会约束可能失效，需在线滑移/变形监控兜底。

### 3.4 IP-53 LANG-MATTER-INTERACTION（语言-物性互校验，完整设计）

**IP 卡片（六字段）**：
- **动机**：F60 语言是单条静态 `str`，无时间轴/音频；但真实指令常带物性形容词与对比焦点，且物性词在视觉上歧义（F70）。F72 说明口语来源文本的同音/断句/自我修正会直接污染物性词。
- **与现有方案差异**：不是语音对话系统（接口不允许），而是**语言先验 + 物理证伪**的闭环；把「形容词」从一次性语义标签变成可被接触推翻的假设；把「交互」定义为语言-物理互校验，而非人机回合。
- **技术可行性**：物性词表小（数十词）、约束映射可手工+LLM 生成；同音纠错用领域词表 + 拼音/编辑距离；失配检测用 KL/Bayes 因子；全部在文本层完成，无需音频。
- **所需资源**：数据=物性形容词-约束词表、少量人工标注；算力=解析 <10ms；接口=语言 `str`（F60）。
- **落地步骤**：① 建物性词表与约束映射；② 对比/焦点/否定解析；③ 同音/断句/自我修正鲁棒；④ 失配检测与处置；⑤ 与 IP-51/52 联动；⑥ E75 验收。
- **风险**：指令无物性词（→回退视觉先验）；形容词与外观系统性冲突（→以物理为准 + 记录数据）；同音纠错过纠（→保守重解析 + 置信阈值）。

**符号表**：`A(l)` 物性形容词集；`C_a` 词 a 的物性约束；`D` 语言-物理失配度；`θ_mismatch` 失配阈值；`H` 同音混淆集。

**算法**：
```
输入：指令 l（静态 str）、Φ 先验/后验、观测 z
1. 解析 A(l)：物性形容词、比较（更软/更重）、否定（不是硬的）、焦点（软的那个）
2. 生成约束：p(Φ|l) ∝ p(Φ)·∏ 1[Φ∈C_a]；对比→对象间序约束 Φ_i ≺ Φ_j
3. 口语来源鲁棒：
   - 同音混淆集 H（如「玻璃/剥离」「轻/清」）→ 候选重解析
   - disfluency/自我修正（「不是…是…」）→ 取最后修正
   - 断句歧义 → 保留 top-2 解析，接触后消歧
4. 与物理证据融合后计算失配 D=KL(p(Φ|l)‖p(Φ|z,a))
5. 处置：
   D>θ 且证据少 → 重探测（IP-51）
   D>θ 且证据足 → 重解析/同音纠错/重指涉
   仍冲突 → 放弃形容词先验，回退保守接触（IP-52）
6. 非语言「发声」（P2，条件）：人为干扰场景用停顿/减速/退让/转向表达「需要空间」，
   不声称语音对话；仅在检测到人进入工作空间且任务可暂停时启用
```

**正确性论证**：
- **P57（先验不害）**：语言先验只在 `p(Φ|l)` 层作用，且失配可被物理证据推翻；当形容词错误时，失配检测 + 回退保证不劣于「无语言先验」的视觉-only 基线。
- **P58（省探测）**：若语言先验与真实物性一致，则后验熵下降更快，达到同一 U_mat 阈值所需探测数不增；E75 要求探测数降 ≥30%。
- **P59（通道诚实）**：所有「语音」收益均可归因到文本/词表/失配机制；无音频输入时系统行为不依赖未观测通道，避免自我指涉的伪能力。

### 3.6 训练/服务伪代码（v18 增量版）

```python
# ===== 离线：物性标定集 + 语言词表（E73/E75 依赖）=====
def build_material_assets():
    calib = collect_material_calibration(
        objects=["glass","ceramic","paper","plastic","cloth","metal"],
        measure=["mu","mass","kappa","reflectance","transparency"])
    lexicon = build_material_adjective_lexicon()   # fragile/soft/heavy/slippery/hot...
    homophones = build_domain_homophone_set()      # 玻璃/剥离、轻/清 ...
    return calib, lexicon, homophones

# ===== 运行期：物性回路 + 接触选型 + Δ-Plane =====
def act_v18(obs, state):
    # 1. 账本（1Hz + 每步轻量）
    ledger = update_ledger(H_gpu=telemetry(), H_motor=motor_heat_proxy(q_cmd_hist),
                           S_used=state.steps, L=L_ewma, U_mat=state.matter.entropy())
    knobs = governor(ledger)

    # 2. 语言先验（IP-53）：静态指令 → 物性约束/对比焦点
    if state.need_lang_parse:
        prior = parse_material_language(obs.language, state.lexicon, state.homophones)
        state.matter.apply_language_prior(prior)

    # 3. 物性后验 + 探测（IP-51）：U_mat 高且 VoI>0 才探
    if state.matter.needs_probe(threshold=knobs.u_mat_thr):
        probe = select_probe(state.matter, budget=knobs)      # 可逆、限幅
        if probe is not None:
            z = execute_probe(probe, obs)                     # 微抬/微压/短拖
            state.matter.update(z, probe)
    psi = state.matter.project()                              # (mu*m, mu, kappa, alpha)
    mu_lo, kappa_lo = state.matter.lower_bounds(alpha=knobs.alpha)

    # 4. 规划（IP-49）：p_s 条件于 Φ；探测动作已在步骤 3 记账
    if state.need_plan:
        state.plan = step_efficient_planner(
            obs.language, state.semantic_map, p_s_prior=state.p_s,
            matter=psi, scenario=state.sigma, budget=knobs)

    # 5. 接触选型（IP-52）+ 学习-TO（IP-50，分布鲁棒）
    if state.need_contact:
        contact = contact_selector(
            task=state.plan.skill, psi=psi, mu_lo=mu_lo, kappa_lo=kappa_lo,
            envelopes=state.semantic_map.objects, budget=knobs)
        task = midlevel(state.waypoints, contact, budget=knobs)
        warm = stream_policy_head(state.plan.skill, obs)
        refined = hybrid_to(task, warm, friction_lo=mu_lo,
                            force_cap=contact.F_n_cap, accel_cap=contact.a_max,
                            f_track=state.f_track)
        state.traj = refined if refined is not None else warm

    # 6. 执行 + 滑移/变形兜底（IP-24/IP-33）
    chunk = state.traj.next_chunk(knobs.T_a_eff)
    if state.matter.detect_slip(obs) or state.matter.detect_deform(obs):
        state.matter.update_from_slip(obs)                    # 在线物性更新
        chunk = contact.regrip_or_slow(chunk)                 # 闭环夹持/减速
    if not guard.cbf_check(chunk):
        chunk = resample_or_fallback(state, r=2)

    # 7. 语言-物理互校验（IP-53）
    if state.matter.mismatch(state.lang_prior) > knobs.theta_mismatch:
        state.need_lang_parse = True                          # 重解析/同音纠错/重指涉
        state.matter.relax_language_prior()                   # 先验降权

    return adapt(chunk, control_space=state.control_space)
```

## 6. 清单迭代规则（继承 27–51 + 本轮新增 52–55）

- 继承规则 27–51（通道诚实/映射验证/SLO/fail-safe/灵感-现实校验/单模型合规/步骤分双解释/稠密监督/方法论遗产/元数据重照亮/语言口径分离/摊销/验证器分级/灵感词落地/层级联合规划/跨本体运动/流式韵律/渐进蒸馏/服务化/证书化/组合代数/热预算/期望得分/学习-TO/修剪优先）。
- **52（新增）：物性一等公民原则**——物性后验 `Φ` 与不确定度 `U_mat` 是 Δ-Plane 的一等账本；任何接触计划下发前必须有物性裕度（`μ_lo/κ_lo`）或明确的「不可辨识→保守」标记；物性只以任务相关低维投影进入控制，不假装全维可辨。
- **53（新增）：语言-物理互校验原则**——物性形容词是**先验不是事实**；语言与物理证据失配时必须触发重探测/重解析/重指涉/回退保守；不得静默信任语言先验；语言收益必须可归因到文本/词表机制，禁止依赖未观测的音频通道。
- **54（新增）：探测价值原则**——探测是花步数/热/时延的动作，必须用 VoI 门控；探测必须可逆、限幅、可放弃，且不得改变物体目标状态；探测失败即回退保守接触。
- **55（新增）：通道诚实原则（语音专项）**——官方无音频/韵律/对话回合时，只允许做「口语来源文本鲁棒 + 形容词接地 + 非语言信号（P2）」；任何「语音交互」表述必须标注其文本/条件性质，禁止把 P2 机制写成已实现能力。

**本轮最大风险一句话**：无触觉/力/电流（A39）、物性不可辨（A40）、语言无物性词或系统性错误（A41）三者叠加时，物性场会退化为不可验证的隐变量，接触选型可能劣于固定保守策略；以 E73–E76 四重守门，任一失败即回退「物性无关保守接触（低加速度、中法向力、视觉滑移检测）」。

**当前最值得押注**：**IP-52 CONTACT-SELECTOR（接触选型）**——它是「物性 → 得分」的唯一物理出口：IP-51 估得再准，不改变接触计划就不涨分；IP-53 语言先验再漂亮，也要经 IP-52 落到抓取位/力/加速度/释放上。它同时可被 E74 一个 A/B 快速证实/证伪（滑/碎/重三类对抗集），且不依赖触觉硬件（用 F71 的视觉滑移 + 闭环夹持即可），失败也能干净回退到固定保守接触。IP-51 与 IP-53 都围绕它的输入与先验服务。
