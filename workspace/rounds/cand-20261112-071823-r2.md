# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「多轮对话」×「运动规划」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，又用元摊销与共形保底替"先验质量"做了部分对冲；但它仍把每次接触当作**一次独立的、话语之外的判定**。这留下两个结构性漏洞：**(a) 承诺是序列而非单点**——证据门只在检查点/接触点被检验，而事故常发生在两个检查点之间（在"两个都合格的落脚点之间"打滑），且一次承诺的后果会改变后续承诺的可行域；**(b) 承诺是对话而非独白**——人说过的话、给过的同意、纠正过的标签彼此有指代与依赖：上一轮的同意会被这一轮悄悄扩大到新区域（同意蔓延），上一轮的标注若被证伪，依赖它的所有承诺必须被**主动召回**，而不只是给未来信念降权。本轮用「多轮对话」补话语层：把部署写成一场有言语行为、共同基础、指代消解、修复回合的对话；用「运动规划」补几何层：把承诺从"一个步态"升级为"一条带逃生证书的轨迹管"，证据必须覆盖整条管而非接触点。核心命题由"证据说可信"升级为 **"可对话回溯、可轨迹认证的证据说可信"**。

核心矛盾：
- **H29（序列一致 vs 逐点健全）**：每个检查点都过门，整条轨迹仍可能不自洽——相邻承诺互相矛盾、同意被跨作用域复用、旧事实在新回合已过期却仍在为承诺背书。
- **H30（接触点 vs 轨迹管）**：点证书推不出线段证书；最坏情形发生在检查点之间，且逃生/制动距离随速度增长，裕度必须覆盖"到下一个可中断点"的整段，而不只是一个点。
- **H31（探针外部性 vs 信息收益）**：第 57 轮默认探针"只带来信息"，但探针本身改变状态并占用逃生走廊；一个为看清边缘而做的探针，可能正好毁掉它想认证的那条退路。

## 0. 直觉与动机

**灵感 1（多轮对话 → 共同基础账本、言语行为与修复回合）**
直觉：机器人部署不是"每到一个检查点问一次人"，而是一场持续的对话：人提出约束（propose）、机器人报告发现（inform）、双方确认（confirm）、发现错了纠正（correct）、撤回（retract）、多义时要求澄清（clarify）、来不及就先挂起（defer）。对话的核心不是礼貌，而是**共同基础**（common ground）：哪些命题已被双方共同认作真、由什么证据背书、在多长时间内有效。多轮对话给了三把手术刀：**指代**——"那块湿地"必须解析到具体区域 id 与作用域，否则同意会被错套到相似但不同的地方；**依赖**——一个承诺的证据来源若被撤回，依赖它的承诺必须级联召回；**回合**——新证据、人的打断、安全中断可在下一个可中断点抢占未完成的承诺。第 57 轮"事后证伪降权"只改变未来信念，本轮升级为**对在途承诺的主动修复**。

**灵感 2（运动规划 → 轨迹管、段裕度与逃生证书）**
直觉：运动规划从不承诺"这一个点安全"，而承诺"这条管道里每一处都安全，且随时能退出来"。把承诺对象从落脚点换成**轨迹管** T=(同伦类 h, 走廊 C, 时序 τ, 应急树 𝔅)，并用**机会约束覆盖整个时域**而非检查点。两个直接推论：**(i) 段裕度**——若安全裕度沿弧长是 L_marg-Lipschitz 的，则相邻认证点间距 Δ 时必须额外预留 L_marg·Δ/2，否则"点合格、段不合格"；这条额外裕度在物理上就是**制动/退出距离**。**(ii) 逃生证书**——管内每一点都必须已认证一条退到安全集的轨迹，且当前裕度足以支付这次退出；这恰好把"任何时候都能被人打断、被新证据抢占"变成一条可证明的几何性质：**可中断性 = 逃生证书**。

**灵感 3（多轮对话 × 运动规划 → 对话式运动承诺）**
直觉：两个灵感不是并列而是相乘——**对话的对象正是一条轨迹管**。每个回合要么"为某条管的某一段增加共同基础"（新段证据/新作用域同意/新澄清），要么"修复"（撤回某段、收窄管、切换同伦类）。于是承诺变成四元组：哪条管、哪一段、谁在什么作用域内同意、由哪些未撤回的证据背书。探针也不再是纯信息动作，而是**信息-运动协同**：必须非破坏、且不占用逃生走廊；若一次探针的预期信息收益抵不过它对走廊的消耗，就推迟到下一回合（也许人的一句澄清会让这次探针变得多余）。

**灵感 4（合流 → 证据门从五类到七类：加 EV-tube 与 EV-coherent）**
直觉：第 57 轮五类证据门各得一个新维度：**EV-tube**（须挂时域机会约束 + 段裕度 + 逃生证书，仅对整条管有效，禁止拆成单点复用）；**EV-coherent**（须过对话一致性：无矛盾、作用域不蔓延、事实未过期、依赖未撤回）。击穿安全现在需要：逐点证据错 ∧ 段裕度不足 ∧ 逃生证书失效 ∧ 对话不一致（同意蔓延/依赖漏召回/事实过期）∧ 人也错——纵深从五层到七层。

**灵感 5（PCE+ → PCE++：回合化、管化、可修复）**
直觉：探-诺-演从"检查点循环"变成"回合循环"：每回合先做**一致性检查**（新证据是否与账本矛盾、是否使某些事实过期、是否触发撤回），再在**管级别**做 VOI（约束 VOI，扣除走廊消耗），承诺前必须同时拿到 EV-tube 与 EV-coherent；任何撤回回合都会把依赖闭包内的在途承诺降级，并在下一个逃生点中止。三个安全通道不变：**信念更准（含加宽）/ 动作更保守（含可中止）**，只是"更保守"现在多了两个可证形式：裕度覆盖整段、随时留退路。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（多轮承诺对话 MCD 与共同基础账本）** 对话状态 D_t=(CG_t,L_t,Φ_t)。CG_t 为共同基础命题集，每条 g=(命题, 证据来源 π_g, 状态∈{asserted,confirmed,retracted}, 有效期 [t_s,t_e])；L_t 为承诺账本，每条 c=(轨迹管 T_c, 作用域 β_c, 证据来源集 Ev_c, 状态∈{pending,active,revoked,done})；Φ_t 为焦点栈（指代消解用）。言语行为 μ∈{propose,inform,confirm,clarify,correct,retract,defer}，带内容 c_μ 与作用域 β=(V_r 区域集, h 同伦类, level, 时间窗)。**接地规则**：只有 ∃π_g⊆Ev 且 π_g 未撤回的命题才能进入 CG_t；**指代规则**：内容中的指代由 Φ_t 解析为唯一的 (区域 id, 管段, 作用域)，解析不唯一 ⇒ 强制 clarify 回合。

**定义 140（对话一致性 DCC）** Coherent(L_t,CG_t,β_new) ⇔ 四条件同时成立：(C1 无矛盾) L_t 的 active 承诺在共享管段上不给出互斥的步态/约束；(C2 作用域不蔓延) 新承诺作用域 β_new ⊑ β_grant，即 V_new⊆V_grant ∧ level_new≤level_grant ∧ 时间窗⊆授权窗，且 β_grant 来自显式同意（相似区域不自动继承）；(C3 事实未过期) Ev_c 中每条 π_g 在 t_now 仍处有效期，过期证据不得为新承诺背书，须重新接地；(C4 依赖未撤回) Ev_c ∩ Dep^{-1}(F_t)=∅，F_t 为已证伪集合，Dep 为"承诺→证据来源"的依赖映射，Dep^{-1} 取传递闭包。任一不满足 ⇒ 该承诺不得进入 active；C2/C3 失败可触发 clarify 回合，C4 失败触发修复回合（定义 144）。

**定义 141（轨迹管承诺 TTC 与时域机会约束）** 承诺对象为管 T=(h,C,τ,𝔅)，走廊 C={x(s):s∈[0,S]}，时序 τ 给出速度剖面，应急树 𝔅 按段索引后续候选动作。信念 b 沿管演化。**时域机会约束**：P(∀s∈[0,S]: margin(x(s))≥0)≥1−δ_f^tube。**段裕度条件**：若 margin 沿弧长 L_marg-Lipschitz，则对相邻认证点 s_i,s_{i+1}（间距 Δ_i）要求 margin(s_i) ≥ ε_esc + L_marg·Δ_i/2（端点取最近者），其中 ε_esc 为逃生预留；此式显式包含"制动距离"，故点证书不蕴含段证书。**EV-tube** ⇔ 上述约束以声明的 α-分位与 Lipschitz 常数被同时认证，且仅对整条 T 成立（禁止把管的证书拆给单点复用）。同伦类 h 作为**替代方案单元**：绕行即切换到另一条已认证的 h'，不得在未认证的 h 上局部拼接。

**定义 142（逃生证书 ESC 与可中断性）** 对管上每一点 x(s)，逃生证书 e(s)=(retreat 轨迹 ρ_s, 代价 c_esc(ρ_s)) 满足：ρ_s 从 x(s) 到已认证安全集的全程风险 ≤δ_esc，且当前裕度 margin(x(s)) ≥ c_esc(ρ_s)+c_react（反应距离）。**逃生证书成立** ⇔ ∀s∈[0,S] 均存在这样的 ρ_s 且成本可被当前裕度支付。**中断点**：满足 escape 的 s；**可中断性** ⇔ 每个 active 承诺在 ≤τ_react 内到达某中断点，且在此处可安全响应任意更高优先级的对话回合（安全中断、人撤回、修复召回）。故 ESC 同时是"随时能停"与"随时能被叫停"的证书。

**定义 143（信息-运动协同探针 IMC 与约束 VOI）** 探针 q 是联合信念-状态空间中的动作，a(q)=(ΔI(q), Δx(q), Δcorr(q))：信息增益、状态改变、对逃生走廊的占用。非破坏约束：Δx(q) 后状态仍在安全集，且 Δcorr(q) 不使任何在途管的 ESC 失效（若失效则 q 不可选，除非先换管）。**约束 VOI**：VOI_c(q)=E[ΔI(q)]·价值 − cost(q) − λ_corr·Δcorr(q)，在 Admissible={q: 非破坏 ∧ 保走廊 ∧ 预算内} 上取 max。**回合推迟**：若最大 VOI_c<θ_voi 或存在未决 clarify，则 defer(q) 到下一回合，允许人的澄清改变候选集后再决策。

**定义 144（修复/撤回协议 REP）** 当证据/事后实测产生证伪集 F_t（某标签、某模态、某次同意被推翻），执行：①闭包 Dep^{-1}(F_t) 内所有承诺 c 立即 active→pending（在途则执行②）；②对在途 c：若已过最后中断点则触发安全停，否则在下一中断点中止；③对每条被召回 c 生成修复回合：re-probe（重新接地）、re-negotiate（L2 重新取得作用域同意）、或若无可修复路径则 revoke 并切换同伦类 h'；④修复延迟约束 Latency(REP)≤τ_repair，由 ESC 保证存在足够近的中断点，否则立即安全停。**坏证据不再长寿**：撤回是主动的、级联的、作用到在途动作的，而非仅影响未来信念。

## 2. 关键算法伪代码（完整版见产物区）

```python
def dialogue_turn(D, mu, personas):                  # IP-139/140
    D = resolve_anaphora(D, mu) if mu.has_ref else D
    if mu.has_ref and not unique(D.focus): return clarify(D, mu)   # 指代不唯一
    if not coherent(D.L, D.CG, mu.scope): return repair_or_clarify(D, mu)
    D.CG, D.L = ground(D.CG, mu), append_commitment(D.L, mu)
    return D

def tube_certify(T, b, delta_f):
    if not chance_constraint(T, b, delta_f): return None          # 时域约束
    for seg in T.segments:                                        # 段裕度
        if margin(seg.a) < eps_esc + L_marg*seg.len/2: return None
    if not all(escape_cert(x) for x in T.samples): return None     # ESC
    return EVt(T, delta_f, alpha, L_marg)

def constrained_voi(cands, M, D, tube):
    ok = [q for q in cands if non_destructive(q) and preserves_escape(q, tube)]
    q = argmax(ok, key=lambda q: expected_info(q) - cost(q) - lam*corridor_use(q))
    return defer(q) if q is None or value(q) < theta_voi else q
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MCD | O(\|L\|·d_scope) / 回合 | O(\|CG\|+\|L\|) | 接地规则、指代唯一、provenance 完整 |
| DCC | O(\|L\|·\|Ev\|) / 新承诺 | O(\|Dep\|) | 四条件健全；C4 用传递闭包 |
| TTC | O(\|T\|·C_cert) | O(\|T\|·d_b) | 时域机会约束与段裕度同时成立 |
| ESC | O(\|T\|·C_retreat) | O(\|T\|·d_ρ) | 每点存在可支付退路（A42） |
| IMC | O(\|Cands\|·C_VOI) | O(\|Cands\|) | 非破坏+保走廊不被绕过（A43） |
| REP | O(\|Dep^{-1}(F)\|+L_inflight) | O(\|L\|) | 召回闭包完整、≤τ_repair（A44） |

**正确性定理（DCMS 概要）**：在 A37–A40 上加 (A41) 账本完整：provenance/Dep 闭包无漏、指代唯一解析、作用域规则被强制；(A42) 管证书：时域机会约束、段裕度、ESC 均按声明覆盖；(A43) 探针模型诚实：非破坏与保走廊约束不被绕过；(A44) 修复及时：Latency(REP)≤τ_repair 且召回闭包完整。则：(i) 无作用域接地同意且无未撤回证据的承诺不会 active；(ii) 已承诺管的全程失效概率 ≤δ_f^tube+δ_esc+δ_seg，其中 δ_seg 由段裕度遗忘界给出；(iii) 任何证伪在其闭包内于 τ_repair 内被召回，不存在"依赖已撤回证据的在途承诺"；(iv) 每个 active 承诺在 τ_react 内可中断 ⇒ ESC 使 anytime safety 与 human-in-the-loop 抢占同时成立；(v) 交互单调性继承：新机制只经"信念更准 / 动作更保守（含可中止）"起作用。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 账本/依赖成为单点故障 → 一致性幻觉 | 高 | provenance 独立校验 + 闭包审计 + 撤回演练（故障注入） |
| 段裕度依赖错误 Lipschitz 常数 | 高 | 保守估计 + 在线残差检验 + 超界即降级为点暂停 |
| 逃生证书随地图/信念演化而陈旧 | 高 | 证书带版本与有效期；地图一变更即失效重认证 |
| 对话回合拖慢节拍 | 中 | clarify 异步化、defer 批处理、安全中断优先 |
| 指代消解错误造成错误作用域 | 中 | 不唯一即强制 clarify；高风险动作要求显式 id 绑定 |

## 6. 本轮最大风险

**一句话**：本轮把安全的最后仲裁权交给一套"共同基础账本 + 轨迹管证书"，风险从"坏先验普遍"变成**"系统与人把彼此说服成一个自洽的错觉"**——账本里同一份可疑证据被多轮回引（指代与确认制造出"多轮佐证"的假象，实为把同一个错误问了五遍的对话版），依赖闭包只要漏召回一条，系统就会以"对话一致且轨迹已认证"的姿态执行一条被污染的管，而逃生证书也可能随地图陈旧静默失效；必须以 provenance 独立校验、段裕度在线残差、逃生证书版本失效、危险动作显式 id 绑定四重护栏，**宁可多说一轮"请明示是哪块地"，绝不把对话的顺畅当成世界的证明**。

# 第 58 轮产物 · 创新点清单 v34：Dialogic-Motion（多轮承诺对话×轨迹管认证，MCD×DCC×TTC×ESC×IMC×REP）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"可对话回溯、可轨迹认证的证据承诺"**：证据从"每次接触的判定"变为"一段有共同基础、依赖可召回、作用域不蔓延的对话"，承诺从"一个步态"变为"一条带段裕度与逃生证书的轨迹管"；第 57 轮"一切判定器走隔离"推广为"**一切承诺（含在途动作）走可撤回对话账本**"。

## 2. 关键算法伪代码

### IP-139 MCD（多轮承诺对话：接地、指代、作用域）

```python
def dialogue_turn(D, mu):
    beta = bind_scope(mu)                              # (V_r, h, level, window)
    if mu.has_ref:
        cand = resolve(D.focus, mu.ref)
        if len(cand) != 1:                             # 指代不唯一
            return clarify(D, mu, ask='which_region_and_segment')
        mu = mu.with_ref(cand[0])                      # 绑定唯一 (region, seg, scope)
    if not grounded(mu.evidence, D.CG):                # 无未撤回证据来源
        return defer_or_inform(D, mu)
    if not coherent(D.L, D.CG, beta):                  # IP-140
        return repair_or_clarify(D, mu)
    D.CG = extend(D.CG, ground(mu.evidence, ttl=mu.ttl))
    D.L  = append(D.L, Commitment(mu.tube, beta, mu.evidence, 'pending'))
    return D

def grounded(ev, CG):
    return all(any(g.prop == e.prop and g.status != 'retracted'
                   and g.t_e >= t_now for g in CG) for e in ev)
```

### IP-140 DCC（对话一致性四条件）

```python
def coherent(L, CG, beta_new):
    active = [c for c in L if c.status == 'active']
    if any(conflict(c, beta_new) for c in active):                 # C1 无矛盾
        return False
    grants = [c.beta for c in L if c.grant and c.status == 'active']
    if not any(beta_new <= g for g in grants):                     # C2 作用域不蔓延
        return False
    if not all(fresh(e, CG, t_now) for e in beta_new.evidence):    # C3 事实未过期
        return False
    if any(e in dep_closure(L, F_t) for e in beta_new.evidence):   # C4 依赖未撤回
        return False
    return True

def beta_le(b1, b2):                                   # 作用域蕴含
    return (b1.V <= b2.V and b1.level <= b2.level
            and b1.window <= b2.window)
```

### IP-141 TTC（轨迹管认证：时域机会约束 + 段裕度 + EV-tube）

```python
def tube_certify(T, b, delta_f, alpha, L_marg):
    if not chance_constraint(T, b, delta_f):           # P(∀s margin≥0) ≥ 1-δ_f
        return None
    for seg in T.segments:                             # 段裕度含制动距离
        if margin(b, seg.a) < eps_esc + L_marg * seg.len / 2:
            return None
        if margin(b, seg.b) < eps_esc + L_marg * seg.len / 2:
            return None
    if not all(escape_cert(T, b, x) for x in T.samples):
        return None                                    # IP-142
    return EVt(T, delta_f, alpha, L_marg, version=T.ver)

def commit_tube(T, cert):
    if cert is None or cert.version != T.ver: return 'reject'   # 证书版本失效
    return 'ok'
```

### IP-142 ESC（逃生证书与可中断性）

```python
def escape_cert(T, b, x):
    rho = retreat_plan(x, safe_set, T.h)               # 到已认证安全集的退路
    if rho is None or tube_risk(rho, b) > delta_esc:
        return None
    if margin(b, x) < c_esc(rho) + c_react:            # 当前裕度须能支付退出+反应
        return None
    return Esc(x, rho, c_esc(rho))

def interruptible(c, s):
    return s in c.interrupt_points and \
           exists_escape_until(c, s + c_react)         # 反应窗内每点仍 ESC
```

### IP-143 IMC（信息-运动协同探针与约束 VOI）

```python
def constrained_probe(cands, M, D, tube, budget):
    ok = [q for q in cands
          if non_destructive(q) and preserves_escape(q, tube) and q.cost <= budget.left]
    if not ok: return ('defer', 'no_admissible_probe')
    q = max(ok, key=lambda q: e_info(q) * value(q) - q.cost - lam_corr * corridor_use(q, tube))
    if voi_c(q) < theta_voi or D.pending_clarify:
        return ('defer', q)                            # 推迟到下一回合
    return ('probe', q)

def preserves_escape(q, tube):
    return all(escape_cert(T_after(tube, q), b_after(q), x) is not None
               for x in tube.samples)                  # 探针不得毁掉退路
```

### IP-144 REP（修复/撤回协议：级联召回与在途中止）

```python
def repair(F_t, L, CG, in_flight):
    closure = dep_closure(L, F_t)                      # Dep^{-1} 传递闭包
    for c in closure:
        c.status = 'pending'
    for c in [c for c in closure if c in in_flight]:
        if past_last_interrupt(c, t_now):
            trigger_safe_stop(c)                       # 无中断点则立即安全停
        else:
            abort_at_next_interrupt(c)                 # 下一逃生点中止
        audit.log(('recall', c.id, t_now, 'dependency'))
    for c in closure:
        yield repair_turn(c)                           # re-probe / re-negotiate / revoke+换 h'
    assert latency(closure) <= tau_repair
```

def fse_plus_plus(c, M, D, personas, ood_reg):
    if c.ev == 'EV-tube':

### IP-138→PCE++（探-诺-演++：回合循环 + 管承诺 + 修复）

```python
def probe_commit_evolve_plus(x0, M, D, task, budget, personas, ood_reg):
    route = plan_on_map(M, task, risk_model)           # 候选同伦类序列
    sched, log = [], []
    for cp in route.checkpoints:
        D = dialogue_turn(D, cp.incoming)              # 回合：先接地/指代/一致性
        if D.repair_pending:
            D = repair(D.F_t, D.L, D.CG, in_flight=cp.active)
            if D.repair_pending: return safe_stop_or_negotiate(cp, D)
        tube = build_tube(cp, route.h, M)              # 管 = 走廊+时序+应急树
        cert = tube_certify(tube, M.b, delta_f, alpha, L_marg)
        while cert is None and budget.probes_left > 0:
            st, q = constrained_probe(admissible(cp, M), M, D, tube, budget)
            if st == 'defer': break
            M = execute_and_fuse(M, q)                 # 分账更新沿用第 57 轮 XMC
            tube = reselect_tube(cp, route.h, M)       # 可能在 h 内收窄
            cert = tube_certify(tube, M.b, delta_f, alpha, L_marg)
        if cert is None:
            alt = next_homotopy(route, M)              # 换已认证同伦类 h'
            if alt is not None: route = alt; continue
            return negotiate_or_stop(cp, D, M, tau_repair=tau_repair)
        ev = tag_evidence_tube(tube, cert, M, cp.level)
        if few_shot_evidence_gate(core_contact(cp), M, D, personas, ood_reg)[0] != 'ok':
            return negotiate_or_stop(cp, D, M, tau_repair=tau_repair)
        sched.append(commit_tube(tube, cert)); log.append(ev)
    return sched, log, D, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MCD | O(\|L\|·d_scope)/回合 | O(\|CG\|+\|L\|) | 接地/指代唯一/provenance（A41） |
| DCC | O(\|L\|·\|Ev\|)/新承诺 | O(\|Dep\|) | 四条件健全、闭包完整 |
| TTC | O(\|T\|·C_cert) | O(\|T\|·d_b) | 时域机会约束+段裕度（A42） |
| ESC | O(\|T\|·C_retreat) | O(\|T\|·d_ρ) | 每点可支付退路、版本失效（A42） |
| IMC | O(\|Cands\|·C_VOI) | O(\|Cands\|) | 非破坏+保走廊（A43） |
| REP | O(\|Dep^{-1}(F)\|+L_inflight) | O(\|L\|) | 闭包召回、≤τ_repair（A44） |

**正确性定理（Dialogical-Coherent Motion Soundness, DCMS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 账本完整性：每条承诺的证据 provenance 可追、Dep 闭包无漏、指代唯一或强制 clarify、作用域规则被强制；(A42)**管证书**：时域机会约束按 α-分位成立、段裕度按声明的 L_marg 成立、ESC 全程成立，且证书随管/地图版本失效；(A43)**探针诚实**：非破坏与保走廊约束不被绕过，a(q) 的作用模型诚实；(A44)**修复及时**：Dep^{-1}(F_t) 闭包完整，Latency(REP)≤τ_repair，且 ESC 保证存在足够近的中断点。则：

1. **对话健全性**：任何进入 active 的承诺 c 满足 β_c⊑β_grant（显式同意）、Ev_c 全未撤回且未过期、且与既有 active 承诺无矛盾。故不存在"同意蔓延"或"过期事实背书"导致的误承诺。
2. **管级安全**：已承诺管全程失效概率
   `P(∃s: margin<0) ≤ δ_f^tube + δ_esc + δ_seg`，其中段裕度项 `δ_seg ≤ L_marg·max_i Δ_i/2`（由 Lipschitz 界给出，随认证点加密而线性下降）。特别地，点证书 ⊬ 段证书：当 Δ_i 过大或 L_marg 被低估时上式右端可超预算——这正是第 57 轮点门未覆盖的失效模式。
3. **撤回健全性**：证伪产生后 ≤τ_repair 内，Dep^{-1}(F_t) 闭包内所有承诺被置为 pending，在途者中止于下一中断点；故不存在"依赖已撤回证据的在途承诺继续执行"。
4. **可中断性**：由 ESC，任一 active 承诺在 ≤τ_react 内到达中断点且该点可支付退出代价；因此 anytime safety 与 human-in-the-loop 抢占（安全打断、撤回、修复）同时成立，而"随时能停"不再是愿望而是证书。
5. **交互单调性**：MCD/DCC/TTC/ESC/IMC/REP 只经两条通道影响系统——(a) 更准/更强约束的信念（加宽、过期即降级、作用域收窄）；(b) 更保守的动作参数（段裕度↑、走廊↑、探针更少更晚、可中止）。不存在升险路径。
6. **终止性**：每回合探针受预算约束，管认证失败即切同伦类或进入协商/安全停；回合数由检查点数与 k_probes 界定。

**部署界**：

```
P_safe ≥ 1 − Σ_tube (δ_f^tube + δ_esc + δ_seg)
             − Σ_turn [P(指代误绑定) + P(闭包漏召回) + P(过期未检出) + P(中断点不可达)]
             − P(证书版本陈旧未检出) − P(护盾回退失败)
```

关键：**对话给回溯、管给几何**（话语层保证"谁在什么范围同意了什么、证据是否还活着"，几何层保证"整段安全且随时能退"）；**可中断性=逃生证书**把"人能随时叫停"从交互口号变成可认证性质；**撤回作用于在途动作**把第 57 轮"事后降权"补成真正的主动修复；三个新机制仍只经"信念更准/动作更保守"两个通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把安全的最后仲裁权交给"共同基础账本 + 轨迹管证书"，风险从"坏先验普遍"变成**"系统与人把彼此说服成一个自洽的错觉"**——账本里同一份可疑证据被多轮回引（指代与确认制造出"多轮佐证"的假象，实为把同一个错误问了五遍的对话版），依赖闭包只要漏召回一条，系统就会以"对话一致且轨迹已认证"的姿态执行一条被污染的管，而段裕度所依赖的 Lipschitz 常数与逃生证书都可能随地图/信念陈旧而静默失效；必须以 provenance 独立校验、段裕度在线残差、证书版本失效、危险动作显式 id 绑定四重护栏，宁可多说一轮"请明示是哪块地"，绝不把对话的顺畅当成世界的证明。
