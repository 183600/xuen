# 第 43 轮（新循环第 3 轮） · COMP-CERT-ARENA × VLA-CERT-GATE：把竞品变成证书的对抗数据源，把具身大模型关进证书的提议笼子（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮：SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」。本轮灵感词「竞品分析」「具身智能大模型」从外部再插两根钉子：**竞品分析**把别人的策略与失败轨迹变成我们仿真域覆盖的「外部标定集」和「免费对抗测试生成器」——竞品在哪摔，恰好暴露我们 Δ_dyn/Δ_sens 没覆盖到哪；**具身智能大模型**（VLA / 世界模型）提供 v19 缺失的开放世界语义泛化，但它无界、无保证、低频高延迟，恰好可以反过来把 v19 的证书层当作它的「安全壳」。一句话：v19 让证书可进化，v20 让证书**有对手可对拍、有大模型可驯服**。

## 0. 直觉与动机

**灵感 1（竞品分析 ≠ 营销对标，而是外部标定 + 对抗采样）**：我们一直在自家仿真里做域随机化，最大的盲区是「不知道自己没覆盖到什么」。竞品恰好提供了三类外部证据：(1) **公开评测/模型权重/遥操作数据集/失败视频**是另一种行为分布 D_comp 的样本，可以用来估迁移界，比只用少量自家实机标定更广；(2) **竞品的失败案例**是天然的对抗种子——竞品在「透明桌面、强反光、柔性物体、低摩擦地面、拥挤场景」上摔，说明这些轴正是我们 Δ 里弱的轴，把失败初态/语义标签回放进 SCV，等于让对手替我们做覆盖缺口探测；(3) **竞品指标**只报成功率、不报安全违例/可用性/成本，我们把它归一化成四维可审计记分卡，就能把不可比的营销数字变成可比较的 Pareto 前沿。直觉上：竞品不是用来「比谁强」，而是用来「比谁在哪里不安全」，以及「用他们的失败补齐我们的盲区」。

**灵感 2（具身大模型 = 低频语义提议者，证书 = 高频几何裁决者）**：VLA 强在开放世界语义与长程组合，弱在可靠性、延迟、可控性与可解释；证书层强在逐状态可证安全，弱在语义泛化。直觉是把二者放进一个**非对称契约**：VLA 只被允许输出**类型化技能程序**（不是原始电机指令），每个技能带前置/后置/不变式契约；证书层只做两件事——(a) 检查每个技能在当前状态的前置条件是否落在已证有效域 C 内；(b) 用 ECR 以控制频率守住执行。接不上的走三级升级：检索相似已证模板（CKB）→ 仿真快证（SCV）→ 安全降级。再往前一步是**证书感知约束解码**：在 VLA 生成技能 token 时，直接把「前置条件不在当前 C 内」的候选 mask 掉，让大模型从源头只提议「当下可证」的技能，而不是先生成再大量拒绝。这比「生成后过滤」省算力，也把大模型的无界输出压进一个有界可证的语言子集。

**灵感 3（耦合：竞品与大模型互为燃料）**：竞品失败轨迹 → SCV 反例 → CKB 技能契约先验 → VLA 约束解码更准；VLA 在开放世界发现的新技能/新语义 → ARENA 新任务 → 又一次竞品对拍。闭环从 v19 的 **Sim→RAG→Edge→Sim** 扩展为 **Comp→Sim→RAG→VLA→Edge→Comp**。证书第一次同时拥有「外部对手」和「内部提议者」。

**必须一开始就说清的边界**：证书只证「给定正确接地（grounding）的几何控制器」，**不证语义接地本身**。VLA 把「杯子」错认成「碗」，几何层完全可能毫无违例地执行一个错误的抓取。这是本轮新引入、且必须单列的风险；「接地残差」定义就是为了把这条边界显式化、可监控化，而不是假装它不存在。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（竞品行为分布与证书相关投影）**：竞品策略 π_c 在任务族 τ 与种子集 S 上诱导轨迹分布 D_c = {ξ ∼ π_c(·|τ,s)}。定义**证书相关投影** Φ_C(ξ) = (margin_min, L_m_est, regime_seq, contact_seq, slip_events) ∈ R^d。**竞品行为散度** D_bhv(π_us, π_c) = W_1(Φ_C#D_us, Φ_C#D_c)，其中 # 为推前测度。直觉：不比「动作像不像」，只比「证书关心的特征像不像」，从而比全状态 W_1 便宜得多，也更聚焦安全。

**定义 39（证书支配关系与归一化记分卡）**：四目标向量 v(π) = (Succ, −Viol, Nominal, −COT)。π_us **证书支配** π_c（π_us ≻_C π_c）当且仅当 v(π_us) ≥ v(π_c) 逐分量且至少一项严格。**记分卡** SC = Pareto 前沿 {v(π) : π ∈ 参赛者}，并额外保存每个竞品的安全违例集 V_c = {ξ : viol(ξ)=1}——因为「成功率」没有安全分母，1% 的高危违例会被 99% 的成功率掩盖。

**定义 40（类型化技能程序与语义-几何契约）**：技能程序 P = (s_1,…,s_K)，每个 s_i = (κ_i, θ_i, pre_i, post_i, inv_i)；κ 为技能类型（导航到 / 抓取 / 放置 / 按压 / 递物 / 插入…），θ 为连续参数，pre/post/inv 为语义-几何混合谓词。**接地映射** γ: Pred → 2^X，把语义谓词映到状态集（「桌上可抓的杯子」→ 位姿盒 × 可达性 × 未被遮挡）。P 可执行当且仅当存在 x_0…x_K 满足 x_i ∈ γ(pre_i)、控制器把 x_i 带到 γ(post_i)、且全程 inv_i。

**定义 41（提案条件证书与门控谓词）**：给定当前已证有效域 C_t（来自 v19 的 L0 表 / CMC 区间电路），技能 s 在状态 x 处**门控通过**当且仅当
G(s,x) := [ γ_x(pre_s) ⊆ C_t ] ∧ [ ρ_g(γ_x) ≤ τ_g ]，
其中 ρ_g 为定义 43 的接地残差。程序级门控 G*(P) := ∧_i G(s_i, x_i^pred)，x_i^pred 由前一步 post 的**证书包络**推进（不是由 VLA 自己声称的状态推进）。关键：门控是「必要不充分」——通过只代表几何层同意，不代表语义正确，这条诚实性必须写进接口文档。

**定义 42（证书感知约束解码，条件 soundness 命题）**：在 VLA 逐 token 生成技能程序时，mask 掉所有使 G(s,x) 为假的候选 token。**命题**：若 (i) mask 是 sound 的（不误放）；(ii) 每步 post_i 的证书包络 ⊆ pre_{i+1}（契约传递）；(iii) 接地残差 ≤ τ_g 蕴含接地正确的概率 ≥ 1−δ_g；则被接受程序的实际执行安全概率 ≥ 1−δ_g。**证明要点**：对接受程序逐技能归纳；每一步若接地正确且 pre ⊆ C_t，则由 v19 的证书 soundness 得控制器执行不越出 C_t；契约传递保证下一步的 pre 仍在包络内。**注意**：δ_g 不是被证出来的，而是被定义 43 的残差门限「外包」出去的假设——这是本方案最薄的接缝。

**定义 43（接地残差与语义-几何一致性）**：令 VLA 产出的语义场景图 G_sem（实体、关系、属性）与 IP-49 的度量语义图 C_ms 对齐，接地残差
ρ_g = max_{e∈G_sem} w·( ‖p_e − p_{al(e)}‖₂ , |log(scale_e/scale_{al(e)})| , 1[label_e ≠ label_{al(e)}] , 1[reach_e ≠ reach_{al(e)}] )，
按位姿/尺度/标签/可达性加权。只有当 ρ_g ≤ τ_g 才允许把 γ 作为证书输入。**诚实说明**：这是一个「可监控的残差假设」，不是语义正确性的证明；它把语义正确性降级为一个可标定、可告警的工程量。

**定义 44（竞品覆盖缺口与对抗课程增益）**：覆盖缺口 Gap(D_comp) = 1 − |{Φ_C(ξ) : ξ ∈ V_comp 且被 D_sim 支撑覆盖}| / |V_comp|。**命题**：若竞品失败集的证书相关投影被 D_sim 覆盖且 W_1(D_real, D_sim) ≤ ε_w，则未被覆盖的真实失效风险 ≤ Gap·(1 + Lip(Φ_C)·ε_w)。**竞品反例挖掘增益** = 新覆盖的 CAR 边数 / 回放轨迹数；它把「竞品分析」变成可度量的覆盖提升，而不是主观的竞品报告。

## 2. 四大产出设计（新增 IP-57/58 + 升级既有）

### 2.1 IP-57 COMP-CERT-ARENA（CCA，竞品证书对拍竞技场）

1. **统一评测协议**：同任务族、同种子、同仿真/实机、同成本模型；contestant 接口统一为 `obs → 类型化技能程序`，只输出原始动作的竞品用「动作→技能反投影」适配层接入（保证可比）。
2. **四维记分卡 + 证书支配**：Succ / −Viol / Nominal / −COT，输出 Pareto 前沿与支配证书（含每项置信区间，避免小样本噪声）。
3. **覆盖缺口分析**：把竞品失败轨迹投到 Φ_C，对照 D_sim 支撑，输出「哪条证书边没被覆盖」的热力图；Gap 直接作为 SCV 下一轮域随机化的权重。
4. **对抗反例回放**：竞品失败初态/参数 → SCV 域随机化重放 → 新反例入 CKB，带 `source='competitor'` 溯源，供定义 44 的增益统计。
5. **行为散度**：D_bhv 作为「迁移难度」的廉价代理，替代或补充 v19 的全状态 W_1。
6. **公共赛道的伦理与合规**：只用公开权重/公开数据集/公开评测；竞品轨迹脱敏、去实体身份；报告只发布聚合指标与失败类型，不复现可识别个体的数据。

### 2.2 IP-58 VLA-CERT-GATE（VCG，具身大模型证书门控）

1. **类型化技能 DSL + 契约库**：每个技能一个 pre/post/inv 三件套，契约来自 CKB 的可证模板；VLA **只许**输出 DSL，不许直接出电机指令（物理隔离）。
2. **证书感知约束解码**：token 级 mask，只放行 G 为真的技能；全 mask → 空提案 → 触发三级升级，而不是硬编一个动作。
3. **接地门控**：VLA 场景图 vs C_ms 的残差 ρ_g；超限先触发局部重感知/多视角复核，仍不行则升级。接地残差与门限写入证书对象，随版本回滚。
4. **异步提议 + 高频门控**：VLA 5–10 Hz 出程序草案，ECR 100 μs 级逐步门控；用「证书包络」对草案的预测状态 x^pred 预门控，保证等待期间也安全。
5. **三级升级**：CKB 检索近似已证技能 → SCV 快速仿真取证（秒级）→ SafeStop/Degraded；每一级都留审计记录与升级原因码。
6. **契约学习闭环**：被接受技能的成功/失败回写 CKB，形成「语义提议—几何裁决」的在线契约校准；失败案例同时进入 IP-57 的竞品对拍任务池，防止只在自家分布自嗨。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO(关键帧/定点) → 度量语义图 C_ms + 漂移界 B_t + 接地残差 ρ_g
L2: CTC + VLM + IP-58 VLA(低频技能提议) + IP-35 语义-几何仲裁
    → 类型化技能程序 P + 语义图 G_sem → 契约/接地门控
L3: IP-51 CAR(技能级转移 + 提案守卫) ← IP-52 LCS(新增 T-2 契约匹配) ← IP-56 ECR(L0查表 + L1 INT8监控 + 偏移监控)
    → IP-47 契约组合 → IP-39 规划(CBF margin=查表 m_lo) → IP-45 总线(记分卡/升级原因码)
    → IP-48 流匹配 + IP-43 韵律 → IP-53 CMC(看门狗=L1 INT8)
L4: IP-55 CKB(技能契约 + 竞品反例 + 散度索引) ← IP-54 SCV(竞品失败种子 + 域随机化 + 迁移界)
    → IP-57 CCA(统一协议 + 四维记分卡 + 覆盖缺口 + 证书支配)
    → IP-44 蒸馏 + IP-50 对抗课程 → RCA 重颁证书(技能契约版本化) → 契约热更新
运行期：VLA 5–10Hz 提议 → 证书感知解码 → ECR 100μs 门控 → 分级升级 → 反馈入 CKB → 竞品对拍 → Sim 补盲
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 接地残差标定 | ρ_g 对真实接地错误的 AUROC；错误接受的假阳率 | AUROC ≥ 0.95；假接受 < 1% |
| E88 门控安全性 | 对抗语义扰动下开启/关闭门控的不安全执行次数 | 开启 0 起；接受成功率 ≥ 无门控基线 60% |
| E89 约束解码效率 | 解码附加延迟；Nominal 场景空提案率 | 附加 < 30ms；空提案 < 10% |
| E90 异步实时性 | 控制回路被 VLA 阻塞比例；门控 p99 延迟 | 阻塞 0%；门控 p99 < 100μs |
| E91 覆盖缺口预测力 | Gap / D_bhv 与真实迁移误差的 Spearman 相关 | Spearman ≥ 0.8；Gap>ε 时实机违例显著升高 |
| E92 竞品反例增益 | 每 100 条竞品失败新覆盖 CAR 边数；对比随机采样 | ≥ 3x；并产生 ≥ 1 个此前未覆盖的真实失效类型 |
| E93 证书支配性 | 对 ≥3 个 VLA 基线（公开权重/评测）四维对比 | 安全性维度全部支配；成功率不低于最佳竞品 10%；Pareto 非支配 |
| E94 开放世界长时程 | 72h 新物体/新任务；不安全事件、升级率、恢复率 | 0 起；升级 < 5%；恢复 ≥ 90% |

回退：E87 残差无判别力 → 关闭语义门控，VLA 仅作建议、全部走证书或人工；E88 安全达标但成功率过低 → 放宽 τ_g 并加人工确认，禁止关闭门控；E91 覆盖缺口无预测力 → 竞品分析降级为「灵感来源」，仍用 W_1 标定；E92 无增益 → 停止竞品反例回放，只保留记分卡；E93 无法支配 → 退化为「安全但低效」的保守模式，明确对外只宣称安全不宣称通用性。

## 5. 本轮最大风险

**一句话**：证书只保「几何控制」、不保「语义接地」，而 VLA 最擅长的恰恰是语义——一旦接地出错，一个自信的大模型能让错误动作在几何层「合法」地通过所有门控，形成比 v19 的仿真偏差更隐蔽的**语义静默失效**；同时竞品对拍若只盯公开指标会诱发「对拍过拟合」，把「赢了记分卡」误当「赢了现实」。因此 E87（接地残差标定）与 E91（覆盖缺口预测力）必须作为红线实验，任一不达标即熔断：关闭语义门控、回退到「VLA 仅建议 + 全证书裁决」的保守模式。

# 第 43 轮产物 · 创新点清单 v20：COMP-CERT-ARENA × VLA-CERT-GATE（竞品对拍 × 大模型门控）× 四层架构 v8

> 承接第 42 轮产物 v19（SCV × CKB × ECR）。本轮**增量插入** IP-57/58，并升级 IP-35/44/45/47/49/50/51/52/53/55；不推倒任何既有层级。核心是把 v19 的「仿真验证→知识沉淀→边缘低成本→持续进化」闭环，从「自我循环」升级为「有外部对手（竞品）与内部提议者（VLA）的双向压力闭环」；同时明确划出证书的能力边界：**只证几何，不证语义**。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |

### IP-57 CCA：竞品证书对拍与覆盖缺口
```
def run_competitive_arena(task_suite, contestants, our_stack, n_ep=200):
    scorecard = {}
    for c in contestants:
        episodes = []
        for task in task_suite:
            for seed in seeds(n_ep):
                # 统一协议：同任务、同种子、同仿真/实机、同成本模型
                episodes.append(rollout(c, task, seed, cost_model=our_stack.cost))
        fails = [e for e in episodes if e.violation or not e.success]
        scorecard[c.id] = {
            'success':      mean(e.success for e in episodes),
            'violation':    mean(e.violation for e in episodes),
            'nominal':      mean(e.mode == 'Nominal' for e in episodes),
            'cot':          mean(e.cost for e in episodes),
            'coverage_gap': coverage_gap(fails, our_stack.sim_domain),
            'd_bhv':        wasserstein_1d(project_cert(episodes),
                                           project_cert(our_stack.real_log)),
        }
        c.failure_set = fails  # 供反例回放
    front = pareto_front(scorecard,
                         keys=('success','-violation','nominal','-cot'))
    return scorecard, front

def coverage_gap(competitor_failures, sim_domain):
    # 把失败轨迹投到证书相关特征，检查是否被 D_sim 的支撑覆盖
    proj = [phi_C(xi) for xi in competitor_failures]
    covered = [p for p in proj if sim_domain.supports(p)]
    return 1.0 - len(covered) / max(1, len(proj))

def mine_competitor_counterexamples(competitor_failures, SCV, CKB, budget):
    seeds = cluster(competitor_failures, key=phi_C)[:budget]  # 去重、选代表
    gain_edges = set()
    for s in seeds:
        # 用竞品失败初态/参数在 D_sim 中重放，逼出对应证书边
        traj = SCV.domain_random_replay(s.init_state, s.param_guess)
        if traj.margin < traj.theta or traj.new_edge not in gain_edges:
            CKB.insert_counterexample(traj, source='competitor',
                                      labels=SCV.auto_attribute(traj))
            gain_edges.update(traj.covered_edges)
    return len(gain_edges) / max(1, len(seeds))  # 定义 44 的增益
```

### IP-58 VCG：证书感知约束解码与门控
```
def vla_cert_gate(scene, x_t, cert_state, vla, grammar):
    # 1) 低频语义提议（5–10Hz），已在解码期做证书 mask
    prog = cert_aware_decode(vla, scene, x_t, cert_state.C, grammar)
    if prog is None:                       # 全 mask → 空提案
        return escalate('empty_proposal', cert_state)
    # 2) 接地门控：语义图 vs 度量语义图
    rho = grounding_residual(prog.scene_graph, x_t.map)
    if rho > cert_state.tau_g:
        return escalate('grounding', prog, rho)   # 先局部重感知，再升级
    # 3) 程序级门控：逐步用证书包络推进，而非信 VLA 自报状态
    x_pred = x_t
    for s in prog.skills:
        if not cert_implies(ground_pre(s, x_pred), cert_state.C):
            return escalate('uncertified_precondition', s)
        x_pred = certificate_envelope(s.post, x_pred)  # 保守包络
    return accept(prog)                    # 执行仍由 ECR 100us 级守护

def cert_aware_decode(vla, scene, x_t, C, grammar):
    out = []
    while not grammar.is_end(out):
        logits = vla.next_token_logits(scene, out)
        masked = {tok: NEG_INF for tok in grammar.all_tokens()}
        for tok in grammar.next_tokens(out):
            s = grammar.peek(out, tok)             # 当前候选技能
            if cert_implies(ground_pre(s, x_t), C) \
               and grounding_feasible(s, scene, x_t):
                masked[tok] = logits[tok]          # 只放行当下可证技能
        if all(v == NEG_INF for v in masked.values()):
            return None                            # 无可行技能 → 空提案
        out.append(sample_softmax(masked))
    return grammar.parse(out)

def grounding_residual(sem_graph, metric_map, w=(1.0,1.0,1.0,0.5)):
    errs = []
    for e in sem_graph.nodes:
        m = metric_map.nearest(e.pose_guess)
        errs.append(max(
            w[0]*dist(e.pose_guess, m.pose),
            w[1]*abs(log(max(e.scale,1e-6)/max(m.scale,1e-6))),
            w[2]*float(e.label != m.label),
            w[3]*float(e.reachable != m.reachable),
        ))
    return max(errs) if errs else 0.0

def escalate(reason, *ctx):
    # 三级升级：CKB 近似已证技能 → SCV 秒级快证 → SafeStop/Degraded
    cand = CKB.retrieve_skill_contract(reason, *ctx)
    if cand and cand.gate_passes(): return execute(cand)
    if SCV.fast_certify(ctx, budget_s=2.0): return execute(cand)
    return safe_stop_or_degrade(reason)
```

| 风险 | 等级 | 缓解措施 |

## 6. 本轮最大风险

**一句话**：证书只保「几何控制」、不保「语义接地」，而 VLA 最擅长的恰恰是语义——一旦接地出错，一个自信的大模型能让错误动作在几何层「合法」地通过所有门控，形成比 v19 仿真偏差更隐蔽的**语义静默失效**；同时竞品对拍若只盯公开指标会诱发「对拍过拟合」，把「赢了记分卡」误当「赢了现实」。因此 E87（接地残差标定）与 E91（覆盖缺口预测力）必须作为红线实验，任一不达标即熔断：关闭语义门控、回退到「VLA 仅建议 + 全证书裁决」的保守模式。
