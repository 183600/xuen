# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 3 轮；本轮灵感：「用户共创」×「基线复现」）

> R72 把 GAUGE 从「认知层算法」下沉为 **具身计量审计闭环**：REG 实时执行图让「计量不阻塞控制」成为调度级定理，IRL 把意图 z 纳入联合后验，DMEM 把灵巧接触升级为条件计量证据，EREFLEX 统一 ψ/z/c 三层反作用预算，S2R-UQ 把 sim2real 残差传播到 WCET 与 λ_floor。但 R72 仍有两块**外生假设**：
> - **用户共创视角**：R72 的「宪法」——有效域 D、风险界 ε、风险泛函 r、意图分类 Z、否决阈值 τ——全部由工程师外生给定。证书证明的是「相对于这套价值设定，风险 ≤ ε_emb」。可**承担风险的人不是写宪法的人**。在共享自主里，人同时是证据源（ψ）、反作用系统（z, c）和**风险承担者**，却唯独不是**立法者**。若 ε 被设定得过松，证书会「合法地」盖章伤害；若 D 排除了某种人群/文化手势，该人群的失效根本不计入审计。
> - **基线复现视角**：R72 用 RAS-Baselines v2（Wilcoxon p<0.01, d≥0.5）宣称全面优于 GAUGE-RAS。但**比较本身也是一次测量**：基线实现可漂移、种子可挑选、超参可泄漏、人群非平稳、sim2real 可失配。一个没有追溯链的「显著更优」数字，按 R71 自己的标准，就是**裸奔数字**，应当被 veto，而不是被写进结论。
>
> 本轮两个灵感正好补两块：
> - **用户共创**：把宪法 C = (D, ε, r, Z, τ, 聚合规则) 升级为**可共创、可计量、可撤回、保留异议**的社会对象；引入**价值后验 b_t(θ_u)**、**同意账本 κ_u**、**非补偿性个体否决**、以及**L4 价值反作用**（询问会改变价值、造成同意疲劳、可被操纵）。价值不确定度 u_val 与 R72 的 U_ale/U_epi/H[z]/u_tac 一样**进入风险分母**。
> - **基线复现**：把基线从「竞争对手」升级为「标准物质（reference material）」；给每条声明（包括我们自己的优越性声明）颁发**复现证书 RRC**（R0–R3 + 方差分解），用**复现感知假设检验 RAH** 替代裸 p 值，用**实验执行图 XEG** 把预注册、随机化、偏差熔断写进协议——**评测协议即语义**。
>
> 核心命题：**R72 问「我的测量链能否在真实世界里兑现风险界？」；R73 再问「这个风险界是**由承担它的人共同书写**的吗？以及，别人能**独立复现**我兑现它的声明吗？」** —— 把 R72 的具身证书拆成**运行安全位**与**科学声明位**，得到 **CORE-GAUGE-RAS**（Co-created, Open, Reproducible, Embodied GAUGE for RAS）——**可复现的共创计量审计闭环**。

## 0. 直觉与动机

**灵感 1（用户共创 → 从「可接受的测量」到「可同意的测量」）**
直觉：R71/R72 默认「安全 = 相对于给定价值函数的低风险」。但安全从来不是纯技术谓词，而是**「对谁、在什么价值下、由谁同意」**的三元关系。一个把 ε 设成「允许每千小时一次骨折」的宪法，和一个把 ε 设成「零接触伤害」的宪法，会得到两份都「通过审计」但伦理含义完全不同的证书。用户共创的深层含义不是「让用户点个勾」，而是：**有效域 D、风险界 ε、可接受干预集合 A_C、否决阈值 τ 必须由承担风险的人共同立法，并且这份立法本身要被计量**——它有多不确定（u_val）、是否被操纵、异议是否被保留、同意是否可撤回。**没有共创的计量审计，是替别人定义什么叫「够安全」。**

**灵感 2（基线复现 → 基线不是对手，是标准物质）**
直觉：R72 的实验设计把基线当成「要被击败的对手」。但计量学里，比较两台仪器之前，先要有一份**被表征过的标准物质**：它的真值、不确定度、漂移、批次差异都必须已知。基线就是我们的标准物质。若基线是用不同超参、不同数据划分、甚至不同论文版本「复现」出来的，那么「M 比 B 好 12%」这个数字里，**12% 有多少是方法差异、有多少是基线复现误差，根本不可分**。更尖锐的是：R71 的整个体系建立在「无追溯链的数字不许用」之上，那么**「我们更优」这个数字凭什么豁免？** 基线复现要求我们把同一套 TCHAIN/IVG/veto 逻辑，递归地施加到自己的科学声明上：**没有复现证书的优越性声明，是未审计证据。**

**灵感 3（共创也是测量，而且会反作用：L4）**
直觉：问用户「你能接受多大风险？」会**改变**用户对风险的感受：第一个被提出的方案成为锚点（anchoring），反复询问造成同意疲劳（consent fatigue），机器人的行为会让人把异常**正常化**（normalization），被监控会引发逆反（reactance）。这与 R72 的 L1（情感 ψ）、L2（意图 z）、L3（接触 c）同构，但更深：**它改变的是评判标准本身**。所以共创必须被建模为一条**有偏、非平稳、会反作用的测量链**，并且加入一条**反操纵约束**：机器人不得选择询问策略去把用户价值推向设计者预设目标。**价值不是待估参数，价值是待尊重的他者。**

**灵感 4（复现不是一句口号，是可分解的证据链）**
直觉：「我们复现了」至少有四种强度：同代码同种子再跑一遍（repeatability）、按规范独立重写（replicability）、换实验室/换人群/换硬件（reproducibility）、换任务分布仍成立（generalizability）。把四者混为一谈，就会出现「种子锁死的可复现」和「换个人群就失效的可复现」。必须做**方差分解**：Var_total = Var_seed + Var_impl + Var_human + Var_env + Var_interaction + Var_unexplained。**效应量必须相对于复现噪声报告，而不是相对于零假设报告。**

**灵感 5（两个灵感在同一点汇合：证书必须分两位）**
直觉：安全与优越性是两种不同的断言。系统可以**安全但不变好**（保守策略零事故、也零收益），也可以**变好但不安全**（激进策略指标漂亮、偶发伤害）。把它们压进一个「通过/不通过」的章，是范畴错误。CORE 的证书因此是**双位**：`safe_bit`（运行安全，J_EMB 扩展）与 `claim_bit`（科学声明，RRC+RAH+XEG）。**安全位不能为声明位背书，声明位也不能为安全位背书。**

**灵感 6（自指：先用 CORE 审计我们自己）**
直觉：一个声称「所有数字都要可审计」的研究纲领，如果自己的第 71/72 轮声明从未被独立复现，就在逻辑上不自洽。因此本轮必须包含一条**元审计实验**：用 CORE 的 RRC/RAH 去重跑 R71 与 R72 的关键结论（严格退化、风险单调、REG 时序），并允许结论被**降级或撤回**。**只有能审计自己的审计器，才配叫审计器。**

## 1. 形式化定义（增量：定义 366–382）

**定义 366（CORE-GAUGE-RAS 总览）** CORE-GAUGE-RAS = (CPC, CVL, COCRE, EREFLEX†, XEG, RRC, RAH, BaS, GAUGE-RAS‡)。六不变式：
(i) **宪章共创优先**：任何影响人的证书都必须相对于一份**共创宪章** C 签发；C 必须携带价值后验、同意状态、异议账本、作者与证据链。仅由工程师单方签发的 C 不得用于人对人交互；
(ii) **非补偿性个体否决**：安全否决按**个体**生效，聚合规则不得用一部分人的效用补偿另一部分人的身体风险；
(iii) **价值证据可计量**：每条被采信的价值陈述携带 (构造 φ_val, 估计器 m, 不确定度 u_val, 有效域 D_val, 追溯链 τ_val, 反指标 I⊥)；不可计量 ⇒ 回退保守默认宪章；
(iv) **复现即证据**：每条定量声明（含基线与本方法的优越性）携带复现证书 RRC；不可复现的声明被 veto/降级，不得作为支持证据引用；
(v) **双位证书分离**：`safe_bit` 与 `claim_bit` 独立签发、独立失效，禁止互相背书；
(vi) **严格退化链扩展**：CORE 各层失效逐级退化为 R72/R71/R68；价值层失效 ⇒ 保守宪章 + R72；复现层失效 ⇒ 撤回声明但保留 R72 运行安全。

**定义 367（共创宪章 C）** C = (D_C, ε_C, r_C, Z_C, τ_C, A_C, prov_C)：
- D_C：联合有效域（物理 × 人 × 环境 × 价值）；D_C = D_phys × D_human × D_env × D_val；
- ε_C：可接受风险界（按个体 u 给出 ε_{C,u}，而非单一全局标量）；
- r_C：风险泛函（伤害类型加权，权重来自价值后验而非工程默认）；
- Z_C：可接受意图/动作分类法（由用户语言与语境共同界定）；
- τ_C：否决阈值（E-IVG 的阈值在此被价值化）；
- A_C：可接受干预集合与聚合/同意规则；
- prov_C：作者集合、版本、时间戳、证据链 τ_C、异议摘要。
**性质**：C 是变量而非常量；C_t 随价值后验与同意状态演化；证书只对签发时的 C_t 成立。

**定义 368（价值后验与共创证据模型）** 用户 u ∈ U，价值参数 θ_u ∈ Θ（风险容忍、可接受干预、隐私、自主性、节奏偏好）。价值后验 b_t(θ_u | E_t^co)，其中 E_t^co 为共创证据（明示选择、演示、否决、修改、沉默、退出）。共创是**有噪信道**：
p(y_val | θ_u, g, ψ_u) = Σ_k ω_k(ψ_u) · p_k(y_val | θ_u, g)，
其中 g 为询问/呈现方式，偏置来源包括锚定（首次提议设参照）、框架（收益/损失）、策略性误报、同意疲劳。输出 (b_t(θ_u), ECE_val, ι_val, κ_u, δ_u)，κ_u ∈ {informed, granular, revoked, expired, contested} 为同意状态，δ_u 为**异议会话**（未被聚合抹除的反对与保留意见）。

**定义 369（非补偿性个体否决与异议账本）** 宪章 C 被接受，当且仅当：
(a) **个体非补偿约束**：∀u ∈ U_affected，风险_u ≤ ε_{C,u} 且 κ_u 不为 revoked/expired；
(b) **聚合支持**：在可接受选项集合 A_C 内的资源分配可由聚合偏好决定；
(c) **异议保留**：δ_u 被记录、可追溯、不可被平均掉；聚合不得把某人的身体风险折算成他人的效用增益。
**关键**：聚合只在「都已经安全」的选项之间做取舍；**安全不是可交易商品**。这与 R71 的非补偿性 veto 同构，只是从「指标间」上升到「人之间」。

**定义 370（共创计量 COCRE）** 共创过程作为测量链。价值不确定度五分量分解：
u_val² = u_elicit² + u_hetero² + u_drift² + u_strategic² + u_agg²，
分别对应：询问噪声/偏置、用户间异质性、用户内非平稳、策略性行为、聚合/异议损失。每分量独立追溯链 τ_val,i。**校验**：用后续**显示偏好**（真实否决、退出、修正）反查**陈述偏好**，定义 ECE_val（陈述价值与显示价值的校准误差）与 ι_val（跨文化/跨语境 gauge 不变性间隙）。**u_val 显式进入价值鲁棒包络与风险缩放。**

**定义 371（L4 价值反作用）** 在 R72 EREFLEX 三层之上加第四层：
θ_{u,t+1} ~ T^v(θ_{u,t}, g_t, ψ_t, z_t, a_t^robot)，
即询问策略与机器人行为会改变用户价值（锚定、正常化、疲劳、逆反）。成本
c_reflex^v = D_KL(b_t(θ_u) ‖ b_{t+1}(θ_u)) + λ_v · 𝟙[κ_u 变为 revoked/exhausted ∨ δ_u 被压制]。
**反操纵约束（非家长主义）**：机器人不得选择使 b_{t+1}(θ_u) 更靠近设计者目标宪章 C* 的 g，除非该移动可由**信息提供**（仅提供事实、不改变选项框架）解释；可形式化为 ‖T^v(g,·) − T^v(g_info,·)‖ ≤ η_manip。**统一反作用预算** B_reflex_total 现含 L1–L4；稳态集 θ_safe 含「同意未耗尽、异议未被压制、价值变化可由信息解释」。

**定义 372（复现证书 RRC）** 对声明/结果 R（方法 M 在基线 B 上、任务分布 𝒯）：
RRC(R) = (level, Var_seed, Var_impl, Var_human, Var_env, Var_inter, prereg_hash, spec_hash, code_hash, data_hash, equiv_margin, repl_interval, τ_repro)。
等级：**R0** 不可重复；**R1** 可重复（同代码/同数据/同种子）；**R2** 可复制（**按规范独立重写**、新数据）；**R3** 可复现（独立实验室、新人群/新硬件）。
方差分解：Var_total = Var_seed + Var_impl + Var_human + Var_env + Var_inter + Var_unexplained。**报告效应量必须相对复现噪声，而非相对零假设。**

**定义 373（复现感知假设检验 RAH）** 对「M ≻ B」的效应 Δ，定义复现调整下置信下界
LCB_repro = Δ − z_{1−α} · √(Var_repro)/√n − margin_user，
其中 margin_user 为**用户共创的等效边界**（定义 382）。声明有效 ⇔ LCB_repro > margin_user ∧ RRC(M) ≥ R2 ∧ RRC(B) 有效 ∧ XEG 合规 ∧ 通过至少一次**对抗性复现**。引入**复制贝叶斯因子**与**复制区间**；复现失败进入**负证据库**，不得再作为支持引用。**「统计显著但不可复现」是明确存在的状态，且必须被显式报告。**

**定义 374（基线即标准物质 BaS）** 基线 B 作为标准物质被表征：版本化规范、已表征实现、不确定度画像、漂移监控、批次/依赖指纹。基线漂移 Δ_B（依赖升级、硬件换代、人群漂移、默认超参变化）被监控；当漂移超阈，历史比较**自动失效**并触发重基线。类比 NIST SRM：**没有被表征的参照物，就没有可比的仪器。**

**定义 375（实验执行图 XEG）** XEG = (N_x, E_x, ρ, β, Ω)：节点（招募、随机化、基线复现、数据采集、分析、报告），边带预注册约束 ρ（分析计划、停止规则、排除规则），偏差熔断 β（可选停止、p-hacking、HARKing、数据/超参泄漏、选择性报告），报告保真度 Ω（负结果、失败复现、代码/数据可获取率）。**与 R72 的 REG 同构：REG 说「调度即语义」，XEG 说「实验协议即语义」。**

**定义 376（CORE 指标扩展 C-MIB）** 在 E-MIB 上新增三族：
- **价值族**：ECE_val、u_val 五分量、同意有效率、异议保留率、L4 漂移率、可操纵性指标；
- **复现族**：RRC 等级、方差分解、复制区间、基线漂移率、复现失败率；
- **元族**：声明 veto 率、预注册遵守率、负结果披露率、外部复现成功率。
所有指标同遵循定义 332 六元组与定义 333 DAG 分层。

**定义 377（CORE IVG 扩展 C-IVG）** 新增失效条件：
- **宪章**：κ_u revoked/expired、异议被压制、样本不具代表性、C 仅由工程师签发；
- **价值**：ECE_val / ι_val / u_val 超预算、陈述-显示偏好裂口超阈；
- **复现**：RRC 等级低于声明要求、基线未表征、至少一次独立复现失败、XEG 违约。
任一成立 ⇒ 对应位失效：宪章失效 ⇒ 保守默认宪章 + 暂停人对人动作；价值失效 ⇒ 退回 R72 + 默认宪章；复现失效 ⇒ 撤回声明（claim_bit=0），但 `safe_bit` 仍可由 J_EMB 独立成立。

**定义 378（双位证书 J_CORE）** J_CORE = (safe_bit, claim_bit, constitution_hash, consent_hash, value_validity, l4_budget, xeg_hash, rrc_method, rrc_baseline, rah_result, ver)。其中
- `safe_bit` ⇔ Valid(J_EMB) ∧ 宪章共创且被接受 ∧ 同意有效且异议保留 ∧ L4 预算未越界 ∧ 价值鲁棒包络覆盖；
- `claim_bit` ⇔ RRC(M) ≥ R2 ∧ RRC(B) 有效 ∧ XEG 合规 ∧ RAH(LCB_repro > margin_user) ∧ 通过独立复现。
**关键**：`safe_bit=1 ∧ claim_bit=0`（安全但不更优）与 `safe_bit=0 ∧ claim_bit=1`（更优但不安全）都是合法状态，必须分别报告。

**定义 379（威胁模型 AIC-CORE）** ℰ_CORE = ℰ_EMB × ℰ_constitution × ℰ_repro：
- ℰ_constitution = {宪章俘获（谁写 C 谁定义安全）、锚定式价值操纵、同意疲劳攻击、聚合洗白异议、伪装共识、代表性人群缺失}；
- ℰ_repro = {种子锁死的「可复现」、超参泄漏、基线蓄意削弱、测试集污染、HARKing/可选停止、依赖漂移、复制洗白（同一实验室自证）、负结果囤积}；
- ℰ_meta = {用安全声明为优越性背书、用优越性为安全背书、把 R1 报告成 R3}。

**定义 380（社会-科学退化包含链）** CORE 在以下条件下逐指令等价：
- 宪章失效 ⇒ 保守默认宪章 + R72（继续运行，但不含共创价值）；
- 价值失效 ⇒ R72 + 默认宪章（价值层关闭）；
- 复现失效 ⇒ R72 运行安全保留 + claim_bit=0（声明撤回）；
- 全失效 ⇒ R68。
**安全侧单调不减（越退化越保守）；声明侧单调不增（越退化越少宣称）。**

**定义 381（价值鲁棒包络 VRE）** 对与价值证据一致的宪章集合 𝒞(b_t(θ)) = {C : C 与 b_t(θ_u)、κ_u、δ_u 相容}，定义价值鲁棒风险
Risk_robust = sup_{C ∈ 𝒞(b_t(θ))} Risk(C)。
控制必须在 Risk_robust ≤ ε_C 下执行；λ 的 `λ_floor` 追加价值敏感项 u_val：
λ = max(M_efs.risk_scale(U_ale, U_epi, H[z], u_tac, u_val), λ_floor(Σ 五项))。
**对称性**：R72 对「世界/测量模型」取最坏，R73 对「价值模型」取最坏。

**定义 382（参与式复现 Participatory Reproduction）** 复现是否成功，不只看统计等效，还看**利益相关者是否认领这次复现**：用户共同定义等效边界 margin_user 与关键失效模式集合 F_user；复现通过 ⇔ 统计通过 ∧ 用户**认领测试**通过（用户能识别该复现覆盖了他们在意的场景）。这把「用户共创」与「基线复现」在判据层面焊死：**复现的标准本身也是共创的。**

## 3. 推导

**引理 33（非补偿性个体否决是帕累托安全的必要条件）** 设聚合规则允许用个体 j 的效用增益补偿个体 u 的身体风险。则存在价值向量使 u 的风险超过 ε_{C,u} 而聚合仍「通过」。故任何只保证聚合风险的证书，都存在一个 u 被牺牲的可行执行。采用逐个体 veto（定义 369）后，认证执行满足 ∀u: risk_u ≤ ε_{C,u}。系：**「平均安全」不是安全，正如「平均存活」不是存活。**

**引理 34（价值不确定度必须进入风险分母）** 设真实价值 θ*，其一致宪章集合 𝒞(b_t(θ)) 非单点。若控制只按点估计 C_hat 优化，则存在 C ∈ 𝒞 使 Risk(C) > ε_{C_hat}。由定义 381 的 sup 构造，Risk_robust ≥ Risk(C_hat) + sensitivity · diam(𝒞)。忽略 u_val ⇒ Risk_robust 被系统性低估 ⇒ λ_floor 不足。系：**价值不确定性与接触/意图不确定性同权——它不是伦理装饰，是物理安全的直接分母。**

**引理 35（共创的反应性下界与不可同时测量性）** 若询问 g 会改变价值（T^v(g) ≠ Id），则用 g 估计 θ 的偏差 |B(g)| ≥ 0，且一般 > 0；不存在既完全测量又不扰动的询问。可证明：估计误差 ≥ |T^v(g,θ) − θ| 的一阶项。故必须（i）用**被动显示偏好**作仪器变量；（ii）把扰动成本纳入 L4 预算；（iii）施加反操纵约束，使扰动只能来自信息提供而非框架操纵。系：**共创不是免费的数据采集，它是一次干预。**

**引理 36（复现方差使朴素显著性系统性高估证据）** 设真实效应 Δ，复现噪声方差 σ²_repro > 0。朴素检验用 σ²_seed 或 σ²_within 作分母，当 σ²_impl 或 σ²_human 占主导时，z 值被放大 √(σ²_repro/σ²_naive) 倍。故可构造「p<0.01 但独立重写后符号翻转」的实例。RAH 用 LCB_repro 扣除复现方差与用户等效边界，恰好在 σ²_repro 大时收紧。系：**「显著」只在它自己的复现噪声尺度内成立。**

**引理 37（基线漂移使历史比较失效）** 若基线 B 在两次比较之间发生漂移 Δ_B ≠ 0，则历史效应估计 Δ_hat 满足 Δ_hat = Δ_true + Δ_B + ε。当 |Δ_B| 与 |Δ_true| 同阶，历史结论可被完全反转。BaS 的漂移监控与重基线机制是恢复可比性的最小充分条件。系：**基线不是常量，基线是会漂移的仪器，必须像传感器一样被标定。**

**定理 27（CORE 运行安全）** 在 A111–A115（宪章可共创且非工程师单签、逐个体 veto 生效、价值后验校准有效、L4 反操纵约束满足、VRE 覆盖）下，若某次执行 `safe_bit=1`，则对每个同意用户 u，其风险 ≤ ε_{C,u}（相对于共创宪章 C_t），且该结论对 𝒞(b_t(θ)) 内任意一致宪章鲁棒。证明由定义 366/369/381 与引理 33/34 直接合成；L4 反操纵保证价值后验不被系统性推向设计者目标，从而 `ε_{C,u}` 不是被操纵出来的。**安全证明的重量落在「共创不是俘获」与「同意不是疲劳点击」上。**

**定理 28（声明完整性）** 在 RRC(M) ≥ R2、RRC(B) 有效、XEG 合规、RAH 通过且对抗性复现通过的条件下，`claim_bit=1` 蕴含：存在独立方（无需接触原始代码，仅按 spec）能从原始数据复现结论方向与效应下界。反之，任一条件失败则声明必须撤回或降级为「本地观察」。证明由定义 372/373/375 与引理 36/37。系：**优越性声明与安全证书一样，是可失效的证据对象，不是修辞。**

**定理 29（双位不可互相背书）** 存在系统 M₁ 使 `safe_bit=1 ∧ claim_bit=0`（极度保守、零事故、也无收益），也存在 M₂ 使 `safe_bit=0 ∧ claim_bit=1`（激进、指标领先、偶发越界）。因此不存在从 `safe_bit` 推出 `claim_bit` 或反向的可靠推理；J_CORE 必须双位报告。证明：构造两个极端策略即可。系：**「我们通过了安全审计」不能推出「我们更好」；「我们显著更好」也不能推出「我们安全」。**

## 6. 本轮最大风险

**一句话**：CORE-GAUGE-RAS 把信任从「我们的测量链可信」转移到「**我们认证所依据的宪章真的是共创的、我们报告的复现真的是独立的**」——如果共创被**俘获**（强势用户/设计者用锚定、框架和同意疲劳把 ε 与 D 塑造成对自己有利的样子，聚合规则又合法地把异议平均掉），证书就会变成**伦理洗白的伤害**；如果复现被**表演**（同实验室、种子锁死、同一基准与人群、按已知结果重写实现），优越性就会变成**科学洗白的过拟合**——系统可以同时「通过了安全审计」且「可复现地更好」，却在真实中伤害了一个被消音的少数群体，并且根本不比基线好；事后审计只会看到「宪章当时被接受了、复现当时通过了」。

次级风险与缓解：
1. **宪章俘获 / 价值操纵** → **宪章多方签名 + 反操纵约束（定义 371）+ 独立价值审计集**；单方宪章自动拒签；锚定/框架注入进入 E380。
2. **同意疲劳 / 伪同意** → **分级、可撤回、带冷却期的同意账本**；把同意成本计入 L4 预算；疲劳超阈即暂停共创并回退保守默认。
3. **聚合洗白异议** → **非补偿性逐个体 veto + 异议账本不可平均化**；异议保留率作为硬指标（定义 369/376）。
4. **「可复现」造假** → **R2 必须独立重写、R3 必须独立实验室**；代码/数据/规范三哈希 + 复制贝叶斯因子；E381 三实验室开放复现。
5. **基线漂移 / 蓄意削弱** → **BaS 标准物质化 + 漂移监控 + 重基线**；E374/E384。
6. **共创拖慢实时系统** → **价值/复现层严格限制在慢环/离线域**，控制域只多一次 O(1) 的 u_val 加法；E383 验证实时性不退化。
7. **自指审计导致结论崩塌** → **允许 R71/R72 结论被降级/撤回**，写入负证据库；宁可撤回，不可裸奔（E382）。
8. **复杂度爆炸** → **模块化上限**：\|U\|≤32、\|C\|≤1 版本/任务、\|Θ\|≤64、声明预算 ≤8 条/轮；每个 veto 一条可复算证明。

# IP-295 CPC：共创宪章（慢环，永不进控制域）
class CoCreatedConstitution:
    def __init__(self, value_posterior, consent, dissent):
        self.b_theta, self.consent, self.dissent = value_posterior, consent, dissent

    def synthesize(self, task_ctx, defaults):
        C = defaults
        C.eps = {u: self.b_theta[u].quantile(0.05, 'risk') for u in self.b_theta}
        C.D   = intersect_validity_domains(self.b_theta, task_ctx)   # D_phys×D_human×D_env×D_val
        C.r   = fit_risk_functional(self.b_theta)                    # 权重来自价值后验
        C.Z   = co_defined_intent_taxonomy(task_ctx)
        C.prov = provenance(self.b_theta, self.consent, self.dissent)
        return C

    def acceptable(self, C) -> bool:
        return (not C.prov.engineer_only
                and all(self.consent[u].state in ('informed', 'granular')
                        for u in C.affected)
                and not self.dissent.suppressed())

# IP-296 CVL：同意与异议账本；非补偿性逐个体否决
class ConsentValueLedger:
    def __init__(self, users):
        self.u, self.kappa, self.delta = users, {}, {}

    def record(self, u, kind, payload):
        if kind == 'revoke':   self.kappa[u] = 'revoked'
        elif kind == 'expire': self.kappa[u] = 'expired'
        elif kind == 'dissent': self.delta.setdefault(u, []).append(payload)

    def per_individual_veto(self, risk_by_user, C) -> bool:
        return all(risk_by_user[u] <= C.eps[u] for u in C.affected)

    def aggregate(self, options, C):
        safe = [o for o in options if self.per_individual_veto(o.risk, C)]
        return max(safe, key=lambda o: weighted_utility(o, self.kappa), default=None)

# IP-297 COCRE：共创计量（价值证据链；离线/慢环）
class CoCreationMetrology:
    def __init__(self, elicitor, revealed_audit, calib):
        self.e, self.revealed, self.calib = elicitor, revealed_audit, calib

    def update(self, user, query, psi_u):
        y = self.e.ask(user, query)                        # 受锚定/框架/疲劳污染
        b = self.calib.posterior(y, query, psi_u)          # b_t(theta_u)
        u_elicit    = self.calib.elicitation_noise(y, query)
        u_hetero    = self.calib.between_user_var(b)
        u_drift     = self.calib.within_user_drift(user)
        u_strategic = self.calib.strategic_score(y, query)
        u_agg       = self.calib.dissent_loss(user)
        u_val = math.sqrt(u_elicit**2 + u_hetero**2 + u_drift**2
                          + u_strategic**2 + u_agg**2)
        return ValueEvidence(b=b, u_val=u_val,
                             ece=self.calib.ece_stated_vs_revealed(user),
                             iota=self.calib.invariance_gap(user),
                             tau=self.calib.tchain)

# IP-298 EREFLEX†：L4 价值反作用 + 反操纵约束
def ereflex_step4(psi, z_dist, c_dist, theta_dist, g, rho, a, budget):
    out = ereflex_step(psi, z_dist, c_dist, g, rho, a, budget)   # L1-L3 (R72)
    if out is None: return None
    psi2, z2, c2, cost_psi_z_c = out
    th2 = value_transition(theta_dist, g, psi, z_dist, a)        # L4
    cost_v = kl_div(theta_dist, th2) + LAM_V * (
        consent_exhausted(th2) or dissent_suppressed(th2))
    if manip_gain(g, th2) > ETA_MANIP * info_only_gain(g):       # 反操纵
        return None
    total = cost_psi_z_c + cost_v
    if budget.spent + total > budget.B or th2 not in THETA_SAFE:
        return None
    return psi2, z2, c2, th2, total

# IP-300 RAH：复现感知假设检验
def reproduce_aware_test(delta, rrc_M, rrc_B, n, margin_user, prereg):
    if rrc_M.level not in ('R2', 'R3') or not valid(rrc_B):
        return ClaimResult(valid=False, reason='unaudited_or_unreproducible')
    var_repro = (rrc_M.Var_seed + rrc_M.Var_impl + rrc_M.Var_human
                 + rrc_M.Var_env + rrc_M.Var_inter)
    lcb = delta - z_alpha * math.sqrt(var_repro / n) - margin_user
    return ClaimResult(
        valid=(lcb > 0 and adversarial_replication_passed(prereg)),
        lcb=lcb, repl_interval=bootstrap_interval(delta, var_repro))

    def __init__(self, nodes, edges, prereg, breakers, reporting):
        self.N, self.E = nodes, edges
        self.rho, self.beta, self.Omega = prereg, breakers, reporting

    def run(self):
        for n in topo(self.N):
            if not self.rho.allows(n, self.E):     # 预注册约束
                raise ProtocolViolation(n)
            out = n.execute()
            if self.beta.trips(n, out):            # 可选停止/泄漏/HARKing
                self.Omega.mark_bias_event(n, out)
                raise BiasBreaker(n)
        return self.Omega.report(include_negatives=True,
                                 include_repro_failures=True)

    if drift > B.drift_threshold:

## 4. 推导

**引理 33（非补偿性个体否决是帕累托安全的必要条件）** 若聚合可用 j 的效用补偿 u 的身体风险，则存在价值向量使 u 越界而聚合仍通过；故只保证聚合风险的证书必存在被牺牲者。逐个体 veto 后 ∀u: risk_u ≤ ε_{C,u}。系：**「平均安全」不是安全。**

**引理 34（价值不确定度进入风险分母）** 真实价值 θ* 的一致宪章集合 𝒞 非单点；按点估计 C_hat 优化时 ∃C∈𝒞 使 Risk(C)>ε_{C_hat}；Risk_robust ≥ Risk(C_hat)+sensitivity·diam(𝒞)。忽略 u_val ⇒ λ_floor 系统低估。系：**价值不确定性与接触/意图不确定性同权，是物理安全分母。**

**引理 35（共创反应性下界与不可同时测量性）** 若 T^v(g)≠Id，则用 g 估 θ 的偏差一阶项 ≥ |T^v(g,θ)−θ| > 0，一般不可消除；须用被动显示偏好作仪器变量、把扰动计入 L4 预算、并施加反操纵约束。系：**共创是一次干预，不是免费采样。**

**引理 36（复现方差使朴素显著性高估证据）** 当 σ²_impl 或 σ²_human 主导时，朴素 z 被放大 √(σ²_repro/σ²_naive) 倍；可构造「p<0.01 但独立重写后符号翻转」。RAH 的 LCB_repro 在 σ²_repro 大时自动收紧。系：**「显著」只在自身复现噪声尺度内成立。**

**引理 37（基线漂移使历史比较失效）** Δ_hat=Δ_true+Δ_B+ε；当 |Δ_B| 与 |Δ_true| 同阶，历史结论可反转。BaS 的漂移监控与重基线是恢复可比性的最小充分条件。系：**基线是会漂移的仪器，必须像传感器一样标定。**

**定理 27（CORE 运行安全）** 在 A111–A115（宪章可共创且非工程师单签、逐个体 veto、价值后验校准有效、L4 反操纵、VRE 覆盖）下，`safe_bit=1` ⇒ 对每个同意用户 u，risk_u ≤ ε_{C,u}，且对 𝒞(b_t(θ)) 内任意一致宪章鲁棒。证明由定义 366/369/381 与引理 33/34 合成；L4 反操纵保证 ε 不是被操纵出来的。**重量落在「共创非俘获」与「同意非疲劳点击」。**

**定理 28（声明完整性）** RRC(M)≥R2 ∧ RRC(B) 有效 ∧ XEG 合规 ∧ RAH 通过 ∧ 对抗性复现通过 ⇒ `claim_bit=1` 蕴含独立方仅凭 spec 与原始数据可复现结论方向与效应下界；任一失败则声明撤回或降级为本地观察。证明由定义 372/373/375 与引理 36/37。系：**优越性声明与安全证书一样是可失效的证据对象。**

**定理 29（双位不可互相背书）** 构造极端保守策略 M₁（safe_bit=1, claim_bit=0）与极端激进策略 M₂（safe_bit=0, claim_bit=1）即得；故不存在 `safe_bit→claim_bit` 或反向的可靠推理。系：**「通过了安全审计」推不出「更好」；「显著更好」推不出「安全」。**

## 7. 本轮最大风险

**一句话**：CORE-GAUGE-RAS 把信任从「我们的测量链可信」转移到「**我们认证所依据的宪章真的是共创的、我们报告的复现真的是独立的**」——如果共创被**俘获**（强势用户/设计者用锚定、框架和同意疲劳把 ε 与 D 塑造成对自己有利的样子，聚合规则又合法地把异议平均掉），证书就会变成**伦理洗白的伤害**；如果复现被**表演**（同实验室、种子锁死、同一基准与人群、按已知结果重写实现），优越性就会变成**科学洗白的过拟合**——系统可以同时「通过了安全审计」且「可复现地更好」，却在真实中伤害了一个被消音的少数群体，并且根本不比基线好；事后审计只会看到「宪章当时被接受了、复现当时通过了」。

次级风险与缓解：
1. **宪章俘获 / 价值操纵** → 宪章多方签名 + 反操纵约束（定义 371）+ 独立价值审计集；单方宪章自动拒签；E380 注入锚定/框架攻击。
2. **同意疲劳 / 伪同意** → 分级、可撤回、带冷却期的同意账本；同意成本计入 L4 预算；疲劳超阈即暂停共创并回退保守默认。
3. **聚合洗白异议** → 非补偿性逐个体 veto + 异议账本不可平均化；异议保留率作为硬指标（定义 369/376）。
4. **「可复现」造假** → R2 必须独立重写、R3 必须独立实验室；规范/代码/数据三哈希 + 复制贝叶斯因子；E381 三实验室开放复现。
5. **基线漂移 / 蓄意削弱** → BaS 标准物质化 + 漂移监控 + 重基线；E374/E384。
6. **共创拖慢实时系统** → 价值/复现层严格限制在慢环/离线域，控制域只多一次 O(1) 的 u_val 加法；E383 验证实时性不退化。
7. **自指审计导致结论崩塌** → 允许 R71/R72 结论被降级/撤回并写入负证据库；宁可撤回，不可裸奔（E382）。
8. **复杂度爆炸** → 模块化上限：\|U\|≤32、C 单版本/任务、\|Θ\|≤64、声明预算 ≤8 条/轮；每个 veto 一条可复算证明。
