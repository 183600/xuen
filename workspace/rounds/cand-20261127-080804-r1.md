### 第 2 轮灵感驱动研究记录

**灵感词**：仿真到现实、谐波减速器

**直觉与动机**：
前两轮已把证书链从单机「感知-合规-能量」扩展到「结构-力学」（USMC v24）与「语义-重构-协同」（SRC-USC v25）。但所有这些证书都隐含一个从未被验证的前提：**被验证的动力学模型 = 真实机器人**。现实中这个前提最脆弱——策略在仿真里通过全部证书，部署到真机却因关节级未建模动力学而失效。而机器人关节中最普遍、最难精确建模的元件正是谐波减速器：它的传动误差、非线性扭转刚度与迟滞、Stribeck 摩擦、近零但非零的失动量、以及随温度/负载/寿命的磨损漂移，几乎构成了 sim-to-real 差距的主要物理来源。

关键洞见：**不要把 sim-to-real 当成黑箱域差距，而应把它分解为可辨识、可测量、可预算的关节级残差证书。**「仿真到现实」= 残差有界 + 证书裕度可传播；「谐波减速器」= 该残差的具体物理参数化。若仿真模型 f_sim 与真实模型 f_real 在可达工作包络 R 上满足 ‖f_real−f_sim(·;θ̂)‖≤Δ_res，则任何在仿真中带裕度 m_sim 证明安全的证书，在真实系统上仍以 m_real ≥ m_sim − L·Δ_res 成立（L 为证书对残差动力学的 Lipschitz 灵敏度）。当 m_real ≥ 0 时转移即被证书化。这样 sim-to-real 不再是「祈祷式迁移」，而是把 reality gap 变成一个显式、可分配、可审计的证书扣减项，并与 v25 的单调退化链自然衔接：Exec_v26 = Exec_v25 ∩ Fil_s2r ⊆ Exec_v25。

**形式化目标**：
1. 定义谐波减速器残差证书（HDRC）：传动误差 |e_te(t)|≤ε_te；非线性扭转刚度与迟滞 |Δθ−τ/K_hd(τ)|≤ε_hyst；摩擦 |τ_f−τ̂_f|≤ε_fric；失动量 |Δθ_lost|≤ε_lost；磨损漂移 ‖Δθ_wear(t)‖≤ε_wear，全部在关节工作包络上成立。
2. 定义系统辨识证书（SRIC）：参数置信椭球 ‖θ−θ̂‖_Σ≤ρ，残差动力学上界 ‖f_real−f_sim(·;θ̂)‖≤Δ_res（在可达集 R 上，含持久激励条件）。
3. 定义域随机化覆盖证书（DRTC）：真实参数以 ℙ(θ∈Θ_DR)≥1−α_dr 落入随机化支撑，conformal 校准 + 协变量漂移检测。
4. 定义转移裕度证书（TMC）：m_real,c ≥ m_sim,c − L_c·Δ_c 对每个子证书 c∈{SOC,FCC,LSC,SMC,RMC,MCC} 成立，且 Σ_c L_c·Δ_c ≤ slack。
5. 构建仿真-现实-谐波统一准入门（SRHA-UC v26）：SRC-USC ∪ HDRC ∪ SRIC ∪ DRTC ∪ TMC 十一证一体，Exec_v26 ⊆ Exec_v25。
6. 证明「转移缺口超限 / 磨损漂移 / 分布漂移」三重退化路径下单调退化链的保持性。

# ============================================================
# IP-448 Harmonic Drive Residual Certificate (HDRC) — 谐波减速器残差证书
# ============================================================
@dataclass
class HarmonicDriveParameters:
    N: float                          # 减速比
    K_hd: Callable[[Tensor], Tensor]  # 非线性扭转刚度 K_hd(tau)
    tau_c: float                      # 库仑摩擦
    b: float                          # 粘性摩擦
    omega_s: float                    # Stribeck 速度
    tau_s: float                      # 静摩擦
    eps_te: float = 1e-3              # 传动误差上界 (rad, 输出侧)
    eps_hyst: float = 5e-4            # 迟滞上界 (rad)
    eps_fric: float = 1e-2            # 摩擦残差上界 (Nm)
    eps_lost: float = 2e-4            # 失动量上界 (rad)
    eps_wear: float = 1e-3            # 磨损漂移上界 (rad)


@dataclass
class HarmonicDriveResidualCertificate:
    """逐关节谐波减速器五元残差证书，全部在工作包络上验证"""
    params: HarmonicDriveParameters
    joint_id: int
    envelope: 'OperatingEnvelope'      # (tau, omega, dtau) 工作包络采样

    def transmission_error(self, theta_in: Tensor) -> Tensor:
        """θ_out = θ_in/N + e_te, |e_te| ≤ ε_te"""
        return self._te_lookup(theta_in)  # 由高精度编码器离线标定表插值

    def torsional_residual(self, tau: Tensor, tau_dot: Tensor) -> Tensor:
        """Δθ - tau/K_hd(tau) = h(tau, tau_dot), |h| ≤ ε_hyst"""
        return self._hysteresis(tau, tau_dot)

    def friction_residual(self, omega: Tensor) -> Tensor:
        """Stribeck: tau_f = tau_c*sgn(w) + b*w + (tau_s-tau_c)*exp(-|w|/w_s)*sgn(w)"""
        p = self.params
        sgn = torch.sign(omega)
        tau_f = (p.tau_c * sgn + p.b * omega
                 + (p.tau_s - p.tau_c) * torch.exp(-omega.abs() / p.omega_s) * sgn)
        return tau_f - self._measured_friction(omega)

    def lost_motion(self, tau_sign: Tensor) -> Tensor:
        """换向失动量，|Δθ_lost| ≤ ε_lost"""
        return self._lost_motion_lookup(tau_sign)

    def verify_envelope(self) -> bool:
        """在工作包络所有采样点上验证五元残差界"""
        p = self.params
        for tau, omega, tau_dot in self.envelope.samples():
            if self.torsional_residual(tau, tau_dot).abs().max() > p.eps_hyst:
                return False
            if self.friction_residual(omega).abs().max() > p.eps_fric:
                return False
            if self.lost_motion(torch.sign(tau)).abs().max() > p.eps_lost:
                return False
            if self._te_bound_on(tau).max() > p.eps_te:
                return False
        return True

    def verify_wear(self, w_hist: Tensor) -> bool:
        """磨损漂移：|Δθ_wear(t)| = |∫ w(τ)dτ| ≤ ε_wear（或寿命内单调增界）"""
        accumulated = torch.cumsum(w_hist, dim=0)
        return accumulated.abs().max() <= self.params.eps_wear

    def verify_all(self, w_hist: Tensor) -> bool:
        return self.verify_envelope() and self.verify_wear(w_hist)


# ============================================================
# IP-449 Sim-to-Real Identification Certificate (SRIC) — 系统辨识证书
# ============================================================
@dataclass
class SimToRealIdentificationCertificate:
    """参数置信椭球 + 可达集残差动力学上界"""
    theta_hat: Tensor                  # 参数点估计
    Sigma_inv: Tensor                  # 信息矩阵（逆协方差）
    rho: float                         # 椭球半径（chi2 分位）
    delta_res: float                   # 残差上界 Δ_res
    reachable_set: 'ReachableSet'      # 工作包络 R
    n_samples: int = 1000
    delta_conf: float = 1e-3           # 残差界置信风险

    def verify_parameter_ellipsoid(self) -> bool:
        """‖θ-θ̂‖_Σ ≤ ρ，由最小二乘协方差 + 持久激励条件给出"""
        # 持久激励：信息矩阵最小特征值 > λ_min
        lam_min = torch.linalg.eigvalsh(self.Sigma_inv).min()
        if lam_min < 1e-6:
            return False
        # 真实参数（由独立标定或集员辨识上界）落在椭球内
        return self._true_theta_in_ellipsoid()

    def verify_residual_bound(self, rollout_fn: Callable) -> bool:
        """在 R 上经验残差 + Hoeffding/区间界 → Δ_res"""
        residuals = []
        for x, u in self.reachable_set.sample(self.n_samples):
            f_real = rollout_fn(x, u)
            f_sim = self._sim_dynamics(x, u, self.theta_hat)
            residuals.append(torch.norm(f_real - f_sim).item())
        empirical_max = max(residuals)
        # 有限样本上界（Hoeffding），r_max 为物理先验上界
        bound = empirical_max + self.reachable_set.r_max * math.sqrt(
            math.log(1.0 / self.delta_conf) / (2 * self.n_samples))
        return bound <= self.delta_res

    def verify_all(self, rollout_fn: Callable) -> bool:
        return (self.verify_parameter_ellipsoid()
                and self.verify_residual_bound(rollout_fn))

    def _sim_dynamics(self, x, u, theta):
        # 以谐波减速器参数化替换仿真关节模型
        return self.sim_model.step(x, u, theta)

# IP-450 Domain Randomization Transfer Certificate (DRTC) — 域随机化覆盖证书
# ============================================================
@dataclass
class DomainRandomizationTransferCertificate:
    """真实参数落入随机化支撑的 conformal 覆盖 + 协变量漂移检测"""
    dr_samples: Tensor                 # Θ_DR 的随机化采样
    alpha_dr: float = 0.05
    covariate_detector: 'OODDetector' = None

    def verify_coverage(self, theta_real_est: Tensor) -> bool:
        """conformal: 真实参数到 DR 支撑的最近邻距离 ≤ 校准分位"""
        d_cal = self._calibration_distances()
        q = torch.quantile(d_cal, 1 - self.alpha_dr)
        d_real = torch.cdist(theta_real_est[None], self.dr_samples).min()
        return d_real <= q

    def verify_no_covariate_shift(self, real_batch: Tensor) -> bool:
        """新负载/地形/温度导致的协变量漂移必须被检测并拒证"""
        if self.covariate_detector is None:
            return False
        return not self.covariate_detector.is_ood(real_batch)

    def verify_all(self, theta_real_est: Tensor, real_batch: Tensor) -> bool:
        return (self.verify_coverage(theta_real_est)
                and self.verify_no_covariate_shift(real_batch))

    def _calibration_distances(self) -> Tensor:
        # 留一最近邻距离作为 conformal 校准分数
        D = torch.cdist(self.dr_samples, self.dr_samples)
        D.fill_diagonal_(float('inf'))
        return D.min(dim=1).values

# IP-451 Transfer Margin Certificate (TMC) — 转移裕度传播证书
# ============================================================
@dataclass
class TransferMarginCertificate:
    """m_real,c ≥ m_sim,c - L_c·Δ_c ≥ 0，且 Σ L_c·Δ_c ≤ slack"""
    sim_margins: dict                  # c -> m_sim,c（v24/v25 各证书裕度）
    lipschitz: dict                    # c -> L_c（对残差动力学的灵敏度）
    delta_budget: dict                 # c -> Δ_c（可分配残差预算）
    slack: float = 0.0                 # 全链剩余裕度

    def real_margin(self, c: str) -> float:
        return self.sim_margins[c] - self.lipschitz[c] * self.delta_budget[c]

    def verify_per_certificate(self) -> bool:
        return all(self.real_margin(c) >= 0.0 for c in self.sim_margins)

    def verify_budget(self) -> bool:
        total = sum(self.lipschitz[c] * self.delta_budget[c]
                    for c in self.delta_budget)
        return total <= self.slack

    def verify_all(self) -> bool:
        return self.verify_per_certificate() and self.verify_budget()

    def allocate_budget(self, delta_res: float) -> dict:
        """按灵敏度反比分配 Δ_res，使 Σ L_c·Δ_c 最小化（水填充）"""
        weights = {c: 1.0 / max(self.lipschitz[c], 1e-9) for c in self.lipschitz}
        wsum = sum(weights.values())
        return {c: delta_res * w / wsum for c, w in weights.items()}

@dataclass
class SimToRealHarmonicAwareUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    hdrc: list[HarmonicDriveResidualCertificate]        # 逐关节
    sric: SimToRealIdentificationCertificate
    drtc: DomainRandomizationTransferCertificate

    def admits(self, multi_plan: 'MultiRobotPlan',
               sensor_data: dict,
               real_rollout_fn: Callable,
               theta_real_est: Tensor,
               real_batch: Tensor,
               w_hist: list[Tensor]) -> bool:
        # 1. v25 七证（仿真域）全部通过
        if not self.src_usc.admits(
            multi_plan, sensor_data,
            gt_entities=sensor_data.get('gt_entities'),
            queries=sensor_data.get('queries'),
            retrieved=sensor_data.get('retrieved')):
            return False
        # 2. 逐关节谐波残差证书
        for hdrc_j, w_j in zip(self.hdrc, w_hist):
            if not hdrc_j.verify_all(w_j):
                return False
        # 3. 系统辨识证书（参数椭球 + 残差界）
        if not self.sric.verify_all(real_rollout_fn):
            return False
        # 4. 域随机化覆盖证书（含协变量漂移）
        if not self.drtc.verify_all(theta_real_est, real_batch):
            return False
        # 5. 转移裕度证书：把 Δ_res 分配到各子证书后逐项非负
        if not self.tmc.verify_all():
            return False
        return True

# 辅助：谐波减速器 Stribeck 摩擦前馈 + 迟滞补偿
def harmonic_drive_compensate(tau_d: Tensor, omega: Tensor,
                              p: HarmonicDriveParameters) -> Tensor:
    """仿真中前馈补偿谐波减速器已知残差，缩小 Δ_res"""
    sgn = torch.sign(omega)
    tau_f = (p.tau_c * sgn + p.b * omega
             + (p.tau_s - p.tau_c) * torch.exp(-omega.abs() / p.omega_s) * sgn)
    delta_theta = tau_d / p.K_hd(tau_d) + p.eps_hyst * torch.tanh(tau_d / 1e-3)
    return tau_d + tau_f + p.K_hd(tau_d) * delta_theta

## 3. 正确性论证（增量）

### 引理 13（谐波减速器残差证书的五元可测性）
**陈述**：`HDRC.verify_all = True` ⟺ 在关节工作包络与寿命窗内，传动误差、扭转迟滞、摩擦、失动量、磨损漂移五项残差均不超过证书上界。

**证明**：
1. 传动误差由输出侧高精度编码器与输入侧编码器差分标定，|e_te|≤ε_te 为查表上界；
2. 扭转刚度 K_hd(τ) 用准静态加载曲线分段拟合，迟滞 h(τ,τ̇) 用正反行程差提取，|h|≤ε_hyst；
3. Stribeck 摩擦参数 (τ_c, τ_s, b, ω_s) 由恒速扫频辨识，残差上界 ε_fric 由留出集最大偏差给出；
4. 失动量在零转矩换向处测量，磨损漂移用寿命累积模型 ∫w dt 单调界定；
5. 五元残差共同张成关节真实力矩-角度映射的误差包络，任一超界即 HDRC 拒证。
∎

### 引理 14（辨识-覆盖联合残差界的概率有效性）
**陈述**：若 `SRIC.verify_all = True` 且 `DRTC.verify_all = True`，则以概率 ≥1−α_dr−δ_conf，真实系统在可达集 R 上的动力学残差满足 ‖f_real−f_sim(·;θ̂)‖≤Δ_res。

**证明**：
1. 持久激励下最小二乘估计 θ̂ 的误差落在 χ² 置信椭球内，半径 ρ 对应 1−δ_conf 置信度；
2. 在 R 上 N_s 个采样点的经验残差最大值加 Hoeffding 修正给出有限样本上界，覆盖概率 ≥1−δ_conf；
3. DRTC 的 conformal 校准保证真实参数到 Θ_DR 支撑的最近邻距离不超过 1−α_dr 分位，排除「真实参数在随机化分布之外」的失效；
4. 两者独立失效概率相加（union bound）得联合置信度 ≥1−α_dr−δ_conf，此时 Δ_res 为有效上界。
∎

### 引理 15（转移裕度的逐证书非负传播）
**陈述**：若对每个子证书 c 有 m_sim,c − L_c·Δ_c ≥ 0，则所有在仿真中通过 v25 七证的证书在真实系统上仍成立，且真实裕度 m_real,c ≥ m_sim,c − L_c·Δ_c。

**证明**：
1. 由残差界 ‖f_real−f_sim‖≤Δ_res 与证书裕度对动力学的 Lipschitz 连续性，|m_real,c−m_sim,c|≤L_c·Δ_res；
2. 预算分配满足 Σ_c Δ_c = Δ_res，按子证书拆分后每项 m_sim,c−L_c·Δ_c 为下界；
3. 非负性保证每个子证书在真实域仍有安全余量，故 v25 的十证连言在真实域不被残差击穿；
4. 预算总和约束 Σ_c L_c·Δ_c ≤ slack 保证全链裕度不被某一证书独占耗尽。
∎

### 引理 16（仿真-现实-谐波单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加三种退化路径：
- 转移缺口超限（Δ_res > 可分配 slack）→ `TMC.verify_all=false` → `SRHA-UC` 拒证 → 退回 `Exec_v25`（仅仿真域策略，禁止真机高速/大力执行，降级为低速保守真机模式）。
- 谐波磨损漂移（‖Δθ_wear‖>ε_wear）→ `HDRC.verify_all=false` → 拒证 → 退回 `Exec_v25`（触发维护/重标定，按新关节证书重认证）。
- 分布漂移（新负载/地形/温度使 DRTC 覆盖或漂移检测失败）→ `DRTC.verify_all=false` → 拒证 → 退回 `Exec_v25`（冻结当前工况，禁止迁移到未覆盖工况，重新随机化/辨识）。
- 组合失效：取交集，单调性保持。
∎

**证明**：直接由 `SRHA-UC.admits` 的十四个连言条件与引理 1–3、5–7、9–11、13–15 可得。必要性：任一条件缺失即拒证，对应十一类风险中的一种未被缓解。充分性：全部满足时，由引理 16 保证执行集单调链，且由引理 14–15 保证仿真证书在真实域仍有非负裕度，构成从单机物理、群体智能到物理世界迁移的完整闭环。
