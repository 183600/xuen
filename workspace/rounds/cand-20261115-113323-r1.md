# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「创新点」×「抗干扰」）

> R69 给闭环装上了眼睛和嘴：看不清就看、拿不准就问、质感不明就触。但它默认**假设空间是封闭的**——那 K 个模态全部来自在「过去经验」上训练出的流模型。当世界真的端出一个没见过的对象/地形/意图时，R69 只有两条路：
> - 把它**塞进一个熟悉的模态**（静默的错误泛化，最危险，因为它不报警）；
> - 或由 MCG 判定模态分布不可信，**退回 R68 的纯保守**（永久拒绝适应：世界变了，而它拒绝知道）。
>
> 它无法区分**真新颖（值得学的创新点）**与**干扰（噪声 / 对抗 / 瞬态扰动）**。而 R69 自陈的最大风险——模态权重不可信 ⇒ 追问一个幻影 / 给误导性回答盖上「已验证」的章——本质上就是这个区分没做。
>
> 本轮两个灵感正好补上这块：
> - **抗干扰**给出「抑制什么」的工程学：鲁棒统计、breakdown point、滤波通带。但它有一个悖论：**最强的抗干扰会杀死创新**——把所有偏离都当 outlier 平均掉，系统就做到完美抗干扰且永久失明。所以抗干扰必须是**定向的**：只在「测量过程的产物」那个子空间衰减，在「世界的性质」那个子空间恒等保留。
> - **创新点**给出「保留什么」的评审学：一篇稿的 innovation point 之所以成立，是因为它**新颖、显著、可复现、稳健、非平凡（非噪声）**。把这五条逐字翻译成对残差的可测检验，正好就是「真新颖 vs 干扰」的判别器：**干扰 = 过不了稳健性/结构性两关（伪影/噪声）；创新点 = 五关全过**。
>
> 核心命题：**把每一个「没见过」当成一篇待审稿。先用干预实验（换视角、重问、等待——都是 R69 已有的动作）估计它是「测量过程的产物」还是「世界的性质」；只有通过五关（新颖/显著/可复现/稳健/结构性）的偏差才成为创新点，被写入带溯源、范围、时效、可回滚的创新台账，且只在离线巩固；实时环只做「定向抗干扰」——在干扰子空间衰减、在创新子空间保留，绝不做各向同性平滑；一旦归因不可判/认证失败/被投毒，逐指令退化回 R69，再退 R68。** 命名 **NOVA-RAS**（Novelty-certified Operational Verification & Anti-interference：以同行评审为隐喻的创新点认证 × 定向抗干扰闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这个『没见过』是真的新，还是只是吵？它配不配成为我的创新点，写进去之后我还撤得回吗**」。

## 0. 直觉与动机

**灵感 1（抗干扰的悖论 → 最好的抗干扰会杀死创新）**
直觉：一个把「所有扰动」都滤掉的滤波器，也滤掉了它没被设计来接收的一切信号。鲁棒统计有 breakdown point：超过它，估计器会把真相当 outlier 丢掉。如果机器人把一个真实的新物体当成 outlier 稳健地平均掉，它做到了 100% 抗干扰，同时永久失明。所以抗干扰不能是标量的、各向同性的（R68/R69 的 λ_floor 正是如此：同时压低一切，包括新信号），而必须是**定向投影**：把残差空间分成「干扰子空间 N」与「新颖子空间 V」，只压 N、保留 V。R68/R69 的标量 λ 成为「N=全空间、V=∅」的退化特例。

**灵感 2（创新点的五项评审 → 运行时判别器）**
直觉：审稿人说一篇稿有创新点，意味着它（1）相对已有知识是新的、（2）重要、（3）可复现、（4）稳健（不是实验假象）、（5）非平凡（不是噪声）。这五条恰好就是区分「世界真的变了」与「我的测量在骗我」所需的全部性质。把它们变成对残差轨迹的五个可测子分：
- 新颖性 N：任何已知模态都解释不了它；
- 显著性 S：如果它是真的，最优动作会显著改变（不改变决策的「新」只是谈资）；
- 可复现性 R：跨独立通道、多次观测一致；
- 稳健性 B：在「破坏干扰」的干预下不消失（伪影会消失，真世界不会）；
- 结构性 K：可压缩/低秩/平滑，而不是白噪声。
五关**合取**（不是加权和）才算创新点——合取是对抗 Goodhart 的关键：攻击者必须同时骗过五道独立的门。

**灵感 3（干预即审稿 → R69 的动作被复用为因果实验）**
直觉：区分「世界新」与「测量骗我」的唯一办法是**动手看什么会变**。换个视角、重问一遍、等一会儿：如果异常消失，它是测量过程的函数（干扰）；如果它稳定存在且结构不变，它是世界的函数（创新）。R69 为消歧建的那套交互（gaze/ask/wait/probe）原封不动就是**归因实验台**。本轮不新增硬件、不扩动作空间，只新增一个**推断**：把 R69 的「信息动作」重新解释为「审稿经费」——按成本序先做便宜可逆的干预，只在证据仍不决且创新价值足够时才动用不可逆探针。

**灵感 4（创新通道本身是攻击面 → 抗干扰必须覆盖「学习」）**
直觉：R69 的威胁模型污染的是**动作**（误导性回答）。本轮威胁模型污染的是**学习**：让干扰伪装成被认证的新颖，就能给系统植入后门/毒模态；让真新颖伪装成干扰，就能把系统冻结在旧世界（认知冻结）。所以「抗干扰」有第二层更阴暗的含义——**抗「创新污染」**：证书要对一个**知道证书规则**的对手稳健，台账必须可回滚、可反学习。这产生一个核心对抗耦合：抗干扰越猛，越容易被「压制攻击」冻结；创新门越松，越容易被「注入攻击」投毒。没有因果干预与双侧误差记账，不存在两侧都安全的设置。

**灵感 5（严格包含 → 关掉新层必须逐指令回到 R69）**
直觉：每加一层就多一个黑箱。唯一安全的加法是让新层**关闭时逐指令退化为旧层**：无干预预算 / 归因不可信 / AIR 未认证时，NOVA ≡ R69（各向同性 λ、同样的模态、同样的退避）；再关交互 ≡ R68。安全侧单调不弱，全部收益只来自「五关通过且决策相关」的少数被认证创新点。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（NOVA-RAS 总览）** NOVA-RAS = (NIA, IAT, IVS, BCT, AIR, SPG, NPG, NCL, QAR, SCL, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）——任何由新颖性触发的更新只发生在离线巩固路径，实时环只读台账；
(ii) **双侧误差纪律**：认证门必须同时报告**伪新颖率**（把干扰当创新，污染）与**伪干扰率**（把创新当干扰，冻结），并对二者审计，不允许单侧优化；
(iii) **可撤销性**：每条入选创新点都带 scope、expiry、溯源与回滚指针；确认投毒或验证失败即回滚并反学习。

**定义 311（残差与异常）** 给定 o_t 与 R69 流策略 p_θ，已知模态流形 ℳ = ∪_k m_k。残差 φ_t = o_t − Proj_ℳ(o_t)。异常分 a_t = −log p_θ(·|o_t)（继承 R69 FMA）。φ 在时间窗 W 上构成残差轨迹 Φ = {φ_{t−W+1..t}}。

**定义 312（五关签名）** 对残差轨迹 Φ 定义五个可测子分：
- **新颖性 N(Φ)** = 1 − p_θ(Φ | ℳ)（任何已知模态解释不了的越界程度）；
- **显著性 S(Φ)** = Δ_decision(Φ) = sup_a |Q(o; a) − Q_ℳ(o; a)|（若把 Φ 当作真实世界变化，最优动作分布的变化，由 BCT 反事实估计）；
- **可复现性 R(Φ)** = ρ_ch·ρ_trial（跨独立通道与重复观测的一致性，取秩相关/互信息的最小值）；
- **稳健性 B(Φ)** = 1 − 在「破坏干扰」干预下异常消失的比例，干预集 ℐ_I = {换视角, 重问, 等待, 换通道}；
- **结构性 K(Φ)** = 1 − MDL(Φ)/MDL(iid 噪声)（低秩/稀疏/平滑则高）。
五关签名 Sig(Φ) = (N, S, R, B, K) ∈ [0,1]^5。

**定义 313（创新点 / 干扰 / 未定 的判定）**
- **创新点 H_N** ⇔ N≥τ_N ∧ S≥τ_S ∧ R≥τ_R ∧ B≥τ_B ∧ K≥τ_K（**合取**，非加权和，抵抗单维 Goodhart）；
- **干扰 H_I** ⇔ 新颖性高但 (B<τ_B ∨ K<τ_K)（看起来异常，却经不起干预或不可压缩 = 伪影/噪声）；
- **未定 H_?** ⇔ 其余（新颖但证据不足）→ 隔离，实时走 R69 保守。
这就是「同行评审」：B/K 是「拒稿：伪影/噪声」，N/S/R 是「接收：新颖且重要」，H_? 是「major revision：补实验」。

**定义 314（干预归因检验 IAT）** 干预序列 ι=(ι_1,…,ι_m)，成本 c(ι)。每步后重估 Sig；归因对数似然比 Λ(Φ)=log[P(Sig|H_N)/P(Sig|H_I)]。在预算内**序贯**选择使期望 Λ 增益最大、成本最小的下一步：
ι* = argmax_ι E[ΔH(H|ι)] − c(ι)。
成本序：先可逆（R69 的 gaze/ask/wait），仅当 Λ 仍不决且 IVS 足够时才允许不可逆探针（承接力控方向，但本轮只调用、不改其内核）。

**定义 315（创新价值 IVS）** 是否值得花预算认证一个候选新颖点：
IV(Φ) = E[未来决策增益 | 学会 Φ] − 认证成本 − λ_p·投毒风险(Φ) − 遗忘风险(Φ)。
只有 IV>0 的候选进入认证队列。这回答「哪些『没见过』配得上成为创新点」。与 R69 的 VoI 同构，但作用在**学习时间尺度**：VoI 决定「问不问」，IV 决定「学不学」。

**定义 316（定向抗干扰器 AIR）** 把残差空间分解为 N ⊕ V：
- N = span{通道特异、时变高频、干预下不可复现的分量}；
- V = span{跨通道一致、持续、干预下稳定的结构分量}。
实时输出 o# = P_V·o + α·P_N·o，α∈[0,1] 为干扰抑制增益（默认取认证给出的上界）。对比：R68/R69 的 λ 是**各向同性**衰减（对全空间乘 (1−λ)）；AIR 是**投影式**衰减（只压 N，V 上恒等）。当 N/V 不可辨识或归因不可信时，强制 N=全空间、V=∅ ⇒ 退化为 R68/R69 的标量保守（严格包含）。

**定义 317（稳定性-可塑性预算 SPG）** 借鉴神经科学的稳定性-可塑性困境：可塑性速率 ρ_plast ≤ κ·cert_quality，单次适应幅度 ≤ 认证效应量 |S(Φ)|，适应后必须通过 canary 状态集在线验证，否则回滚。实时环 ρ_plast=0；只有离线巩固路径允许写入。

**定义 318（创新台账 NCL）** 追加式、签名、版本化记录 N={ν_i}，每条 ν_i=(scope, expiry, prov, Sig, effect_estimate, evidence_hash, rollback_ptr, status∈{candidate, quarantined, certified, revoked})。支持两个查询：「系统为什么相信这是新的」与「撤回它会发生什么」。

**定义 319（创新污染威胁模型 ℰ_innov）**
(a) **新颖性注入**：构造持续、结构化、跨通道一致的伪新颖，诱导学习后门/毒模态；
(b) **新颖性压制**：伪造第二通道相关性，让真新颖看起来像相关噪声，使系统拒绝适应（认知冻结）；
(c) **证书伪造 / 范围蔓延**：重放合法证书到错误 scope 或过期时间；
(d) **干预博弈**：攻击者预知干预集，使异常在干预下消失（伪装干扰）或在非干预下消失（伪装新颖）；
(e) **Goodhart 自适应**：攻击者针对五关阈值优化。
并入 AIC：ℰ_NOVA = ℰ_FLUID × ℰ_innov。

**定义 320（抗干扰认证与 breakdown point）** 对 AIR 给出有限样本 breakdown point ε*（可被污染而不失效的样本比例上界）与**新颖保真度** η（V 子空间上的增益）。对归因给出 ℰ_innov 下的双侧错误上界（引理 19–21）。认证不通过 ⇒ 关闭新层，回退 R69。

**定义 321（可撤销巩固 QAR）** 离线巩固 = 重放取证 + 阴影验证 + canary 放量：先在影子环境（数字孪生）复现新颖效应，再在小流量 canary 上验证，最后才提升为正式模态；全过程可回滚。巩固产物写入 NCL 并记录 rollback_ptr。

**定义 322（范围与时效 SCL）** 每条创新点带 scope（状态/环境/对象子集）与 expiry（半衰期）。超出 scope 或过期 ⇒ 自动降级为 candidate，实时行为退回 R69 保守。防止「一次新事物被永久当作普遍真理」。

**定义 323（行为后果检验 BCT）** 反事实：若把 Φ 视为真实但不改变动作，则 S(Φ)≈0 ⇒ 不认证、不耗预算。创新点必须「显著」——决策相关，否则只是谈资。这是「创新点清单」中「显著性」的逐字落地。

**定义 324（证书 J_NOVA）** J_NOVA = (J_FLUID, attribution_confidence, sig_hash, innov_precision/recall@operating_point, ece_N, air_breakdown, air_fidelity, ncl_hash, rollback_version)。Valid ⇔ Valid(J_FLUID) ∧ 五关合取通过 ∧ NCL 一致 ∧ AIR 认证 ∧ 双侧误差在预算内。

**定义 325（零假设回退）** 任一门不可测 / 超预算 / 认证失败 / 被投毒 ⇒ 新颖性不可判 ⇒ 逐指令退化回 R69（再退 R68）。「不可判」必须显式记为 H_?，禁止默认判成 H_I（认知冻结）或 H_N（污染）。

**定义 326（创新点自评指标）** 把每次认证当成一篇稿：Innovation Precision = 认证为创新中事后被验证为真的比例；Innovation Recall = 真创新中被认证的比例；给出**抗干扰-创新 Pareto 前沿**。这是对「创新点」一词的正面回应：创新点不是形容词，而是**有精度与召回的可测量对象**。

**定义 327（与 R69 的组合）** 关闭 IAT/IVS/NPG、AIR 退化（V=∅）时，NOVA ≡ R69；再关闭 R69 交互则 ≡ R68。安全侧单调不弱。

**定义 328（认知封闭监测）** 监控被 AIR 抑制的残差与被 NCL 拒收的候选的长期统计；若抑制/拒收率持续上升而外部验证误差不降，判为过度抗干扰（认知封闭），触发强制降 α 并转人工审查。这是对「越抗干扰越瞎」的运行时哨兵。

```python
# IP-264/265 NIA+IAT：把「没见过」当成一篇待审稿，用干预实验做归因
def attribute_novelty(residual, o_t, budget):
    sig = five_gate_signature(residual, o_t)          # (N,S,R,B,K)
    if sig.N < TAU_N: return H_I, 0.0                 # 不新颖 → 不进入审稿
    lam = 0.0
    for iota in cost_ordered_interventions(budget):   # 先可逆：gaze/ask/wait
        if lam >= LAM_DECIDE or not budget.allow(iota): break
        o_t = execute(iota)                           # 复用 R69 的交互动作
        sig = five_gate_signature(residual, o_t)
        lam += expected_llr_gain(sig, iota)
    if all_gates_pass(sig):        return H_N, lam    # 五关全过 = 创新点
    if fails_robust_or_struct(sig): return H_I, lam   # 伪影/噪声 = 干扰
    return H_UNKNOWN, lam                              # 证据不足 → 隔离

# IP-266/267 IVS+BCT：这个创新点值不值得学
def innovation_value(residual, sig, budget):
    if decision_delta(residual) < TAU_S: return -inf   # 不显著 → 谈资，不学
    return (expected_future_gain(residual)
            - certify_cost(budget)
            - LAMBDA_P * poison_risk(residual)
            - forgetting_risk(residual))

# IP-268 AIR：定向抗干扰（只压干扰子空间，保留新颖子空间）
def air_filter(o, air):
    P_V, P_N, alpha = air.decompose(o)                # N ⊕ V，alpha 由认证给出
    return P_V @ o + alpha * (P_N @ o)

# IP-269/270 SPG+NPG：稳定性-可塑性预算内的受控写入（仅离线）
def guarded_plasticity(ncl, novel, canary):
    if ncl.get(novel.id).status != 'certified': return   # 未认证不写
    for cand in replay_shadow(novel):                     # QAR：影子复现
        if not validate(cand, canary): return             # 不过验证不写
    old = checkpoint()
    apply_update(novel, magnitude=novel.effect)           # 幅度 ≤ 认证效应量
    if not validate_online(canary):
        rollback(old); ncl.revoke(novel.id)               # 失败即回滚+反学习

# IP-277 主闭环（继承 R69；新层只在「异常归因」处插入）
def NOVA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated); phi = residual(o)
    # 1) 归因：是干扰还是创新？（只在异常显著时花预算）
    hyp, lam = (M.nia.attribute(phi, o, M.budget) if a_hat > TAU_FMA else (H_I, 0.0))
    # 2) 定向抗干扰：只压干扰子空间，绝不各向同性平滑
    o_rob = M.air.filter(o) if hyp == H_I else o
    # 3) 创新点：隔离、估值、绝不实时写
    if hyp == H_N and M.ivs.value(phi) > 0:
        M.ncl.quarantine(phi, sig=M.nia.last_sig)         # 候选入台账，实时只读
    # 4) 归因失败/不可判/AIR 未认证 → 严格退回 R69（再退 R68）
    if hyp == H_UNKNOWN or not M.air.certified:
        return M.fluid_ras_round(M, o_rob)                # 逐指令等价 R69
    U_floor = U_ale + (U_epi if hyp != H_N else 0.0)
    lam_c = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(o_rob, M.vista.H), ..., wm_preds)
    M.vqa_n.submit_async(hyp, lam, M.nia.last_sig)        # 审稿式审计
    return k, lam_c, select_mode(modes, U_epi, lam_c), (hyp, phi)
```

## 3. 推导

**引理 19（干预可分性）** 设 A99：存在干预集 ℐ_I 使干扰在 ℐ_I 下不可复现、真新颖保持不变。则归因对数似然比 Λ 的期望随干预次数 m 单调增；在独立通道数 ≥2、单次干预效力 1−β 下，错误归因率 ≤ e^{−2m·KL} + (1−β)^m。系：**干扰与创新的可分性不靠更大的模型，而靠「能动手」**；干预越便宜，归因越准——这把 R69 的交互预算重新解释为「审稿经费」。

**引理 20（创新污染上界）** 在 ℰ_innov 下，伪新颖通过五关合取门的概率 ≤ Π_g (1−power_g) + ρ_adv。攻击者要同时满足持续、跨通道、干预稳定、低 MDL、决策显著，其成本随门数与通道数指数上升；但**若某门可被预测（Goodhart），该门失效**——故阈值须随机化/保密并有独立审计（VQAuditor-N）。系：抗干扰强度 ≈ 攻击者必须同时欺骗的独立门数。

**引理 21（双侧不可能三角）** 在无干预（纯被动观测）且类先验不可分时，伪新颖率与伪干扰率不能同时趋零（与噪声/新颖的可分性下界一致）；二者下界由先验重叠面积决定，只有加入干预或外部标签才能突破。⇒ **纯靠更好的滤波器不能既抗干扰又不错杀创新**；这是本轮引入 IAT 的根本理由。

**定理 18（NOVA 严格包含 R69/R68）** 在 A99–A101 下：关闭归因（或 AIR 退化为各向同性）时 NOVA 逐指令等于 R69；再关闭交互等于 R68。故安全侧单调不弱，收益只来自「五关通过且决策相关」的被认证创新点。

**定理 19（受控可塑性与无灾难漂移）** 在 A102（可塑性 Lipschitz）与定义 317 的稳定性-可塑性预算下，单次适应后性能下降 ≤ L_plast·|S(Φ)|；canary 验证失败即回滚 ⇒ 系统性能包络始终落在「旧性能 − L_plast·Σ|S|」内；每条创新点在 scope 内且未过期时，长期漂移被 NCL 的 expiry/rollback 界定。⇒ 学习不会因一次污染或一次误判而不可逆。

**定理 20（抗干扰-创新 Pareto）** 设 α 为 AIR 抑制增益、τ 为认证门限。存在 Pareto 前沿：α↑ ⇒ 干扰引起的决策误差↓，但真新颖召回↓（V 子空间被误压）；τ↑ ⇒ 污染率↓但创新延迟↑。NOVA 不承诺同时最优，而是**显式暴露这条前沿并让审计选择工作点**——这与「创新点必须有精度/召回」是同一条陈述。

## 6. 本轮最大风险

**一句话**：NOVA-RAS 的全部收益押在「干预真的能把干扰从创新里分开」——若场景不允许足够强、足够便宜的干预（被动观测、干预危险或昂贵），归因就是不可辨识的，系统要么把真新颖当噪声滤掉（**过度抗干扰 = 认知封闭**，永远停在旧世界），要么把干扰/投毒当创新学进去（**创新污染**，一次错误写入不可逆）；而最阴险的是 Goodhart——任何固定的五关阈值都会被针对它优化的对手或分布漂移绕过，使「创新点」退化为「通过了我们的考试」而不是「真的值得学」。

**次级风险与缓解**：
1. **干预本身不安全/越界** → 复用 R69 定义 302 认证 + 定义 314 成本序；
2. **创新污染/后门** → 五关合取 + 阈值随机化 + QAR 影子验证 + 回滚/反学习；
3. **认知冻结/过度抑制** → 双侧误差纪律 + 定义 328 认知封闭哨兵 + IVS；
4. **灾难漂移/遗忘** → 稳定性-可塑性预算 + canary + scope/expiry；
5. **实时预算被归因击穿** → AIR 轻量投影 + 归因仅异常触发 + 巩固全离线。

```python
# IP-264/265 NIA+IAT：五关签名 + 序贯干预归因
def attribute_novelty(residual, o_t, budget):
    sig = five_gate_signature(residual, o_t)          # (N,S,R,B,K)
    if sig.N < TAU_N: return H_I, 0.0
    lam = 0.0
    for iota in cost_ordered_interventions(budget):   # 先可逆：gaze/ask/wait
        if lam >= LAM_DECIDE or not budget.allow(iota): break
        sig = five_gate_signature(residual, execute(iota))
        lam += expected_llr_gain(sig, iota)
    if all_gates_pass(sig):        return H_N, lam
    if fails_robust_or_struct(sig): return H_I, lam
    return H_UNKNOWN, lam

# IP-268 AIR：定向抗干扰，只压 N、保留 V
def air_filter(o, air):
    P_V, P_N, alpha = air.decompose(o)
    return P_V @ o + alpha * (P_N @ o)

# IP-269/270 SPG+NPG：受控可塑性（仅离线，失败回滚）
def guarded_plasticity(ncl, novel, canary):
    if ncl.get(novel.id).status != 'certified': return
    for cand in replay_shadow(novel):
        if not validate(cand, canary): return
    old = checkpoint(); apply_update(novel, magnitude=novel.effect)
    if not validate_online(canary):
        rollback(old); ncl.revoke(novel.id)

def NOVA_RAS_round(M, obs):
```

## 4. 推导

**引理 19（干预可分性）** 存在干预集使干扰不可复现、真新颖不变（A99）时，归因 LLR 期望随干预次数单调增；独立通道 ≥2、效力 1−β 下错误归因率 ≤ `e^{−2m·KL}+(1−β)^m`。系：可分性靠「能动手」，R69 的交互预算即「审稿经费」。

**引理 20（创新污染上界）** 伪新颖通过五关合取的概率 ≤ `Π_g(1−power_g)+ρ_adv`，攻击成本随独立门数与通道数指数上升；某门可预测（Goodhart）则该门失效，故阈值须随机化+独立审计。

**引理 21（双侧不可能三角）** 纯被动且类先验重叠时，伪新颖率与伪干扰率不能同时趋零；只有干预或外部标签能突破。⇒ 更好的滤波器不能既抗干扰又不错杀创新。

**定理 18（严格包含 R69/R68）** 关闭归因或 AIR 退化为各向同性时，NOVA 逐指令等于 R69；再关交互等于 R68。安全侧单调不弱。

**定理 19（受控可塑性与无灾难漂移）** 单次适应性能下降 ≤ `L_plast·|S(Φ)|`，canary 失败即回滚 ⇒ 性能包络不越界；scope/expiry/rollback 界定长期漂移，学习不会因一次污染不可逆。

**定理 20（抗干扰-创新 Pareto）** α↑ 干扰误差↓但真新颖召回↓；τ↑ 污染↓但创新延迟↑。NOVA 显式暴露前沿并让审计选工作点——即「创新点必须有精度/召回」。

## 7. 本轮最大风险

**一句话**：全部收益押在「干预真的能把干扰从创新里分开」——若场景不允许足够强、足够便宜的干预（被动观测、干预危险或昂贵），归因不可辨识，系统要么把真新颖当噪声滤掉（**过度抗干扰 = 认知封闭**，永远停在旧世界），要么把干扰/投毒当创新学进去（**创新污染**，一次错误写入不可逆）；而最阴险的是 Goodhart——固定的五关阈值终会被针对它优化的对手或分布漂移绕过，使「创新点」退化为「通过了我们的考试」而非「真的值得学」。

**次级风险与缓解**：干预越界（R69 定义 302 认证 + 成本序）；创新污染/后门（五关合取 + 阈值随机化 + QAR 影子验证 + 回滚反学习）；认知冻结/过度抑制（双侧误差纪律 + 认知封闭哨兵 + IVS）；灾难漂移/遗忘（稳定性-可塑性预算 + canary + scope/expiry）；实时预算（AIR 轻量投影 + 归因仅异常触发 + 巩固全离线）。

## 8. 创新点自评（对「创新点」灵感的正面回应）

| 评审维度 | 传统研究里怎么判 | NOVA 里怎么落地 | 为什么不是工程堆砌 |
|---|---|---|---|
| 新颖 | 相对 prior art | 残差对已知模态的似然越界 N | 首次把「新」定义成可拒绝的统计假设 |
| 显著 | 重要性/影响 | 反事实决策变化 S（BCT） | 把「重要」等价为「改变最优动作」 |
| 可复现 | 重复实验 | 跨通道×重复一致 R | 用传感器冗余做内部复现 |
| 稳健 | 抗扰动 | 破坏干扰干预下不消失 B | 用因果干预区分世界变化与测量伪影 |
| 非平凡 | 非噪声/非显然 | 低 MDL 结构 K | 用可压缩性拒绝白噪声式「新」 |

**本轮的元创新点**：把「创新点」从一个**事后由人类写进论文的形容词**，变成系统运行时**有精度/召回、可审计、可回滚的判定对象**；并把「抗干扰」从压掉一切扰动的标量保守，升级为只在干扰子空间生效的定向算子——两者是同一判别器的两面。
