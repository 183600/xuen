# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「场景理解」×「场景落地」）

> 第 54 轮把技能组合升级为动作-鲁棒性双证书 `J`，并让云端规划与边端校验形成闭环。但 `J` 是**任务级**证书：它回答“这个技能序列在动作空间能否组合”，却不回答“它被投放到哪个具体场景、该场景是否满足证书成立的前提”。本轮聚焦 **场景理解（从任务描述到场景图式）** 与 **场景落地（从已证计划到真实部署）**。核心矛盾：H22：证书有效性是**场景相对**的，同一任务在不同场景语义下，动作合法集与可供性不同，任务级证书会静默失效；H23：场景理解本质是**欠定溯因**，可供性误接地（affordance misgrounding）而非动作错配才是落地失败的主因；H24：落地不是一次性动作，而是**影子→金丝雀→放量**的渐进过程，必须由场景分歧度而非仅由成功率来驱动回退。

## 0. 直觉与动机

**灵感 1（场景理解 → 从“做什么”到“在什么条件下对什么可做什么”）**
直觉：任务描述只说“做什么”，场景才说“在什么条件下、对哪个实体、动作是否合法”。因此把场景建模为 **分层场景图式** `Σ = (E, R, Φ, Π, Θ)`：`E` 是实体（物体/区域/动态体），`R` 是空间-因果-功能关系，`Φ` 是**可供性函数**（场景侧把动作映射为可行度），`Π` 是角色/意图分配，`Θ` 是逐因素的认知不确定性。关键对齐：第 54 轮的 `α_S` 是**技能侧**的动作占用，`Φ` 是**场景侧**的动作合法度；二者相乘才得到“技能在场景中真正可执行的动作集” `A_exec = A_Σ ∩ supp(α_S)`。这把“场景理解”变成对动作空间的**合法性约束**，而不是一句自然语言描述。

**灵感 2（场景落地 → 把证书从任务级下沉为场景域级）**
直觉：`J` 的 soundness 隐含一组场景假设 `A_J`（地面可通行、目标可辨识、动态体可预测……）。真实落地应先做 **场景域判定** `dom_Σ(J) ∈ {in, out, unknown}`：只有 `in` 才允许继承 `J`；`out` 直接否决；`unknown` 触发主动感知。再叠加 **场景分歧度** `d_Σ` 与 **落地门槛 gate**，得到 **场景落地证书** `L = (J, 𝕊_cert, Σ_obs, d_Σ, SC_lb, gate, fallback, evidence)`。落地从此不是“部署”这个二值动作，而是一次可判定的**域包含检查**。

**灵感 3（场景理解的不确定性 → 用保形预测给“像不像”一个覆盖率保证）**
直觉：场景相似度容易被直觉滥用——“看起来差不多”不等于证书成立。因此把场景同构度 `sim_Σ = 1 - d_Σ` 的下界 `SC_lb` 用 **保形预测（conformal prediction）** 校准：在可交换假设下，`P(landing success | SC_lb ≥ 1-ε) ≥ 1-ε`。这把场景判断从“经验相似”升级为**有统计覆盖保证的可判定量**；同时保留三值域判定，绝不把 `unknown` 当作 `in`。

**灵感 4（渐进落地 → 场景分歧驱动的影子-金丝雀-放量状态机）**
直觉：真实部署不可能一次全量。用状态机 `M = (Shadow, Canary, Ramp, Live, Rollback)`，其 guard 同时看 `(dom_Σ, d_Σ, ρ_e, δ_a)`：影子期零反例且 `d_Σ ≤ Δ_Σ/2` 才进金丝雀；金丝雀期场景分歧漂移 `Δd_Σ ≤ η` 且成功率达标才放量；任意阶段一旦 `dom_Σ=out` 或 `d_Σ>Δ_Σ` 或连续 k 次 Explain 根因指向同一场景因素，立即回退。这样回退由**场景理解**驱动，而非等失败率飙升。

**灵感 5（理解-落地-回传-再理解的闭环金字塔）**
直觉：第 54 轮动作-鲁棒性金字塔 `𝕃×𝔸` 之上再加 **场景层 `𝕊`**：`𝕊_0` 物理场景（地形/光照/摩擦），`𝕊_1` 语义场景（实体/关系/可供性），`𝕊_2` 任务角色场景（谁对谁做什么），`𝕊_3` 部署场景（分布/版本/运维约束）。证书跨层传递时必须携带**场景假设集**；落地失败经 Explain 归因到具体场景因素后，更新 `Σ` 并重签 `J` 与 `L`，形成 **理解→落地→回传→再理解** 的闭环。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（场景图式 Scenario Schema）**
场景 `Σ = (E, R, Φ, Π, Θ)`：
- `E` 实体集（物体、区域、动态体），每实体带属性向量；
- `R ⊆ E×E×Rel` 空间/因果/功能关系；
- `Φ = {φ_e : A→[0,1]}` 可供性函数，场景侧动作合法度（与第 54 轮技能侧 `α_S` 对偶）；
- `Π` 角色/意图分配；
- `Θ` 逐因素认知不确定性。
场景动作合法集 `A_Σ = {a∈A | max_{e∈E} φ_e(a) ≥ θ_φ}`；技能真正可执行集 `A_exec = A_Σ ∩ supp(α_S)`。

**定义 122（场景分歧度）**
`d_Σ(Σ_1,Σ_2) = w_E·d_E + w_R·d_R + w_Φ·d_Φ + w_Π·d_Π`，各项为图编辑距离或语义嵌入距离归一化到 `[0,1]`；场景同构度 `sim_Σ = 1 - d_Σ`。

**定义 123（证书场景域与三值判定）**
联合证书 `J` 附带场景假设集 `A_J = {pred_1,...,pred_m}`，其场景域 `𝕊_cert(J) = {Σ | Σ ⊨ A_J}`。三值判定
```
dom_Σ(J) = in     若所有 pred 均被观测证据支持
          = out    若至少一个 pred 被否定
          = unknown 若证据不足
```
**只有 `in` 才允许继承 `J` 的 soundness 结论。**

**定义 124（场景落地证书）**
`L = (J, 𝕊_cert, Σ_obs, d_Σ, SC_lb, gate, fallback, evidence)`，其中 `SC_lb` 为场景同构度的保形下界。落地可行
```
land(L)=1 ⇔ dom_Σ(J)=in ∧ d_Σ(Σ_obs,𝕊_cert) ≤ Δ_Σ ∧ SC_lb ≥ 1-ε ∧ gate_ok(ρ,δ_a,d_Σ)
```
否则输出否决原因：`scenario_out / scenario_shift / evidence_insufficient / robustness_gate`。

**定义 125（场景落地信度，保形校准）**
在可交换假设下，用校准集把 `d_Σ` 映射为 `SC_lb`，使得
```
P(landing success | SC_lb ≥ 1-ε) ≥ 1-ε
```
即“场景像不像”被替换为“以至少 `1-ε` 的覆盖保证认为落地成功”。

**定义 126（渐进落地状态机）**
`M = (S_shadow, S_canary, S_ramp, S_live, S_rollback)`，转移 guard 由 `(dom_Σ, d_Σ, ρ_e, δ_a)` 组成：
- `Shadow→Canary`：影子期反例数 `=0` 且 `d_Σ ≤ Δ_Σ/2`；
- `Canary→Ramp`：漂移 `Δd_Σ ≤ η` 且成功率 `≥ π_min`；
- `Ramp→Live`：连续 `k` 窗口稳定；
- `*→Rollback`：`dom_Σ=out` 或 `d_Σ>Δ_Σ` 或连续 `k` 次 Explain 根因同属一个场景因素。

**定义 127（场景理解-落地闭环证书）**
`SL = (Σ, J, L, Update)`，`Update: (failure, attribution) → Σ'` 把失败归因到场景因素 `f∈{E,R,Φ,Π}`，更新场景图式与假设集，重签 `J`（复用第 54 轮 AEC）与 `L`。

## 2. 关键算法 伪代码

### IP-121 SCU（Scenario Understanding）

```python
def understand_scenario(obs, ontology, prior, A):
    E = detect_entities(obs, ontology)
    R = infer_relations(E, obs, ontology)          # 空间/因果/功能
    Phi = {}
    for e in E:
        for a in A:
            Phi[(e,a)] = affordance_score(e, a, obs, prior)
    Pi = assign_roles(E, R, prior)
    Theta = estimate_uncertainty(E, R, Phi, Pi)
    return ScenarioSchema(E, R, Phi, Pi, Theta)

def active_perceive(Sigma, obs_budget, A):
    while obs_budget > 0 and max(Sigma.Theta.values()) > theta_unk:
        a_obs = argmax_a expected_divergence_reduction(Sigma, a)   # 主动感知
        Sigma = understand_scenario(observe(a_obs), ontology, Sigma, A)
        obs_budget -= 1
    return Sigma
```

### IP-122 SGD（Scenario Grounding & Divergence）

```python
def scenario_domain_check(J, Sigma_obs):
    verdicts = [eval_pred(p, Sigma_obs) for p in J.assumptions]
    if any(v is False for v in verdicts): return 'out'
    if all(v is True for v in verdicts):  return 'in'
    return 'unknown'

def scenario_divergence(Sigma_obs, Sigma_cert, W):
    dE = graph_edit(Sigma_obs.E, Sigma_cert.E)
    dR = graph_edit(Sigma_obs.R, Sigma_cert.R)
    dPhi = affordance_divergence(Sigma_obs.Phi, Sigma_cert.Phi)
    dPi = role_divergence(Sigma_obs.Pi, Sigma_cert.Pi)
    return W['E']*dE + W['R']*dR + W['Phi']*dPhi + W['Pi']*dPi
```

### IP-123 SLC（Scenario Landing Certificate）

```python
def landing_certificate(J, Sigma_obs, calib, Delta_Sigma, eps):
    dom = scenario_domain_check(J, Sigma_obs)
    if dom != 'in':
        return ('reject', dom, J.failed_assumptions(Sigma_obs))
    d = scenario_divergence(Sigma_obs, J.scenario_domain, W)
    sc_lb = conformal_lower_bound(d, calib, eps)        # 保形下界
    if d > Delta_Sigma or sc_lb < 1 - eps:
        return ('reject', 'scenario_shift', d, sc_lb)
    gate = landing_gate(d, sc_lb, J.rho, J.delta_a)
    return ('ok', LandingCert(J, d, sc_lb, gate, fallback=fallback_policy(J)))
```

### IP-124 PLM（Progressive Landing Monitor）

```python
def progressive_landing(cert, env_stream, eta, k, pi_min):
    state = 'shadow'
    for t, obs in enumerate(env_stream):
        Sigma = active_perceive(understand_scenario(obs, ...), budget=1, A=A)
        dom = scenario_domain_check(cert.J, Sigma)
        d = scenario_divergence(Sigma, cert.J.scenario_domain, W)
        if dom == 'out' or d > cert.Delta_Sigma:
            return rollback(cert.fallback, reason=(dom, d))
        if state == 'shadow' and cert.n_neg == 0 and d <= cert.Delta_Sigma/2:
            state = 'canary'
        elif state == 'canary' and drift(d) <= eta and success_rate() >= pi_min:
            state = 'ramp'
        elif state == 'ramp' and stable(k):
            state = 'live'
        elif same_scenario_factor_k_times(cert.J, k):
            return rollback(cert.fallback, reason='scenario_factor_repeat')
    return ('live', state)
```

### IP-125 SFR（Scenario Feedback Re-understanding）

```python
def attribute_failure(Explain, Sigma_obs):
    evidence = {f: 0.0 for f in ('E','R','Phi','Pi')}
    for cause in Explain.root_causes():
        evidence[cause.factor] += cause.weight
    return max(evidence, key=evidence.get)

def reunderstand_and_recertify(Sigma, failure, ontology):
    f = attribute_failure(failure.Explain, Sigma)
    Sigma2 = Sigma.update(f, failure.observation, ontology)
    J2 = recertify(Sigma2, skill_lib)          # 复用第54轮 AEC
    return Sigma2, J2
```

### IP-126 SLT（Scenario-grounded Lifetime Transfer）

```python
def scenario_transfer(J_src, Sigma_tgt, Delta_Sigma, eps, calib):
    d = scenario_divergence(Sigma_tgt, J_src.scenario_domain, W)
    sc_lb = conformal_lower_bound(d, calib, eps)
    if scenario_domain_check(J_src, Sigma_tgt) != 'in' or sc_lb < 1-eps:
        Sigma_tgt, J_tgt = reunderstand_and_recertify(Sigma_tgt, J_src, ontology)
        return ('recertified', J_tgt)
    return ('transfer_ok', restrict(J_src, Sigma_tgt))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SCU | O(|E|·|A| + |R|) per obs | O(|E|+|R|+|Φ|) | 实体/关系召回、可供性校准 |
| SGD | O(|E|+|R|+|Φ|+|Π|) | O(1) 额外 | 图编辑距离度量有效、三值判定保守 |
| SLC | O(|A_J| + Cal) | O(Cal) | 保形可交换、`Δ_Σ` 预算闭合 |
| PLM | O(T·(|E|+|A|)) | O(1) 状态 | guard 单调、回退原子性 |
| SFR | O(|𝔇_ρ| + |Σ|) | O(|Σ|) | 归因 sound、重签可复现 |

**正确性定理（Scenario-Grounded Landing Soundness）**
假设第 53 轮 (A22)–(A25)、第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 场景理解已校准：`P(dom_Σ=in | 真实 in) ≥ 1-α_Σ`；**(A30)** 场景分歧度量与真实部署失败一致：`d_Σ ≤ Δ_Σ ⇒ P(证书失败源于场景) ≤ β_Σ`；**(A31)** 保形校准集与部署场景可交换。则落地后成功概率
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a) - α_Σ - β_Σ - P(d_Σ > Δ_Σ 于部署时)
```
关键：相对第 54 轮新增的是 **场景理解误判 `α_Σ`** 与 **场景分歧度量失真 `β_Σ`** 两项。也就是说，动作-鲁棒性再强，只要场景理解把 `unknown` 当作 `in`、或把“看起来像”当作“域内”，整个证书链都会静默失效。**场景理解成为新的 soundness 瓶颈。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 场景理解幻觉/可供性误接地 | 高 | 主动感知 + 保形校准 + 反例驱动重理解 |
| 场景距离度量与真实失败不相关 | 高 | 用真实落地失败做度量验证/学习，报告 proxy validity |
| 分布漂移使 gate 失效 | 中 | 在线漂移检测 + 保守 `Δ_Σ` + 硬回退 |
| 域判定过保守导致不可部署 | 中 | 分层 `Δ_Σ` + 人工复核 + 灰度放量 |
| 失败归因错误导致错误重签 | 高 | 多假设归因 + 反事实仿真交叉验证 |

## 6. 本轮最大风险

**一句话**：场景理解与场景落地把证书从“任务级 sound”下沉为“场景域级 sound”，使系统终于能回答“在哪个世界可部署”；但其 soundness 现在**主要押注在场景理解本身**——一旦可供性被误接地、场景分歧度量与真实失败脱钩、或保形校准的可交换假设在部署漂移下破裂，`dom_Σ=in` 就会变成一句昂贵的自我安慰，故必须以 **主动感知 + 保形覆盖 + 真实失败度量验证 + 硬回退** 四重护栏，宁可把场景判为 `unknown` 并多问几个观测，也绝不把“看起来像”当作“证书成立”。

def understand_scenario(obs, ontology, prior, A):
    E = detect_entities(obs, ontology)
    R = infer_relations(E, obs, ontology)
    Phi = {(e,a): affordance_score(e, a, obs, prior) for e in E for a in A}

def active_perceive(Sigma, obs_budget, A):
    while obs_budget > 0 and max(Sigma.Theta.values()) > theta_unk:
        a_obs = argmax_a expected_divergence_reduction(Sigma, a)
        Sigma = understand_scenario(observe(a_obs), ontology, Sigma, A)

### IP-122 SGD

```python
def scenario_domain_check(J, Sigma_obs):
    verdicts = [eval_pred(p, Sigma_obs) for p in J.assumptions]
    if any(v is False for v in verdicts): return 'out'
    if all(v is True for v in verdicts):  return 'in'
    return 'unknown'

def scenario_divergence(Sigma_obs, Sigma_cert, W):
    return (W['E']*graph_edit(Sigma_obs.E, Sigma_cert.E)
          + W['R']*graph_edit(Sigma_obs.R, Sigma_cert.R)
          + W['Phi']*affordance_divergence(Sigma_obs.Phi, Sigma_cert.Phi)
          + W['Pi']*role_divergence(Sigma_obs.Pi, Sigma_cert.Pi))
```

### IP-123 SLC

```python
def landing_certificate(J, Sigma_obs, calib, Delta_Sigma, eps, W):
    dom = scenario_domain_check(J, Sigma_obs)
    if dom != 'in':
        return ('reject', dom, J.failed_assumptions(Sigma_obs))
    d = scenario_divergence(Sigma_obs, J.scenario_domain, W)
    sc_lb = conformal_lower_bound(d, calib, eps)
    if d > Delta_Sigma or sc_lb < 1 - eps:
        return ('reject', 'scenario_shift', d, sc_lb)
    gate = landing_gate(d, sc_lb, J.rho, J.delta_a)
    return ('ok', LandingCert(J, d, sc_lb, gate, fallback_policy(J)))
```

### IP-124 PLM

```python
def progressive_landing(cert, env_stream, eta, k, pi_min, W):
    state = 'shadow'
    for obs in env_stream:
        Sigma = active_perceive(understand_scenario(obs, ...), 1, A)
        dom = scenario_domain_check(cert.J, Sigma)
        d = scenario_divergence(Sigma, cert.J.scenario_domain, W)
        if dom == 'out' or d > cert.Delta_Sigma:
            return rollback(cert.fallback, reason=(dom, d))
        if state == 'shadow' and cert.n_neg == 0 and d <= cert.Delta_Sigma/2:
            state = 'canary'
        elif state == 'canary' and drift(d) <= eta and success_rate() >= pi_min:
            state = 'ramp'
        elif state == 'ramp' and stable(k):
            state = 'live'
        elif same_scenario_factor_k_times(cert.J, k):
            return rollback(cert.fallback, reason='scenario_factor_repeat')
    return ('live', state)
```

def attribute_failure(Explain, Sigma_obs):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCU | O(|E|·|A| + |R|) per obs | O(|E|+|R|+|Φ|) | 实体/关系召回，可供性校准 |
| SGD | O(|E|+|R|+|Φ|) | O(1) 额外 | 三值判定保守，度量与失败一致 |
| SLC | O(|A_J| + Cal) | O(Cal) | 保形覆盖 `1-ε`，`Δ_Σ` 闭合 |
| PLM | O(T·(|E|+|A|)) | O(1) 状态 | guard 单调，回退原子 |
| SFR | O(|𝔇_ρ| + |Σ|) | O(|Σ|) | 归因 sound，重签可复现 |
| SLT | O(|Σ| + Cal) | O(|Σ|) | 域不保持则强制重签 |

**正确性定理（Scenario-Grounded Landing Soundness）**
假设第 53 轮 (A22)–(A25)、第 54 轮 (A26)–(A28) 成立；**(A29)** `P(dom_Σ=in | 真实 in) ≥ 1-α_Σ`；**(A30)** `d_Σ ≤ Δ_Σ ⇒ P(证书失败源于场景) ≤ β_Σ`；**(A31)** 保形校准可交换。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a) - α_Σ - β_Σ - P(d_Σ > Δ_Σ 于部署时)
```
**关键**：相对 v31，新增误差项 `α_Σ`（场景理解误判）与 `β_Σ`（分歧度量失真）压过了动作与鲁棒性项，说明 **场景理解已成为新瓶颈**。

## 5. 本轮最大风险

**一句话**：场景理解与场景落地把证书从“任务级 sound”下沉为“场景域级 sound”，使系统终于能回答“在哪个世界可部署”；但其 soundness 现在**主要押注在场景理解本身**——一旦可供性被误接地、场景分歧度量与真实失败脱钩、或保形校准的可交换假设在部署漂移下破裂，`dom_Σ=in` 就会变成一句昂贵的自我安慰，故必须以 **主动感知 + 保形覆盖 + 真实失败度量验证 + 硬回退** 四重护栏，宁可把场景判为 `unknown` 并多问几个观测，也绝不把“看起来像”当作“证书成立”。
