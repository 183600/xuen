# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「边缘计算」×「人形机器人」）

> R69 把不确定性一分为二（aleatoric / epistemic），并给 epistemic 一个主动通道：看、问、触。它隐含了两个从未被检验的前提：**(a) 决策者与执行者同位、同钟、同版本；(b) 信息动作是廉价的、可与任务动作并行叠加的观测。** 边缘部署打破 (a)：策略在世界某处、身体在另一处，中间隔着延迟、抖动、分区、版本差与算力争抢；人形机器人打破 (b)：转头会移动质心，前倾会吃掉 ZMP 裕度，探针改变接触状态，迈步是不可逆的承重承诺——**信息不是免费观测，而是从同一份控制权限里借支**。
>
> 于是出现 R69 无法命名的一类不确定性 **U_coord（对账不确定性）**：不是「世界是什么」不清楚，而是「我用来决策的那份世界，是否还是此刻这个身体所在的世界；算它的那个节点，是否还是我以为的那个版本」。它不能靠等（等只会更旧）、不能靠问世界（问不出节点版本）、也不能靠提精度（更高比特救不了过期），只能靠**对账/锚定**：时间戳、版本向量、栅栏令牌、与本地观测的对应性检验。
>
> 核心命题：**在边缘部署的人形机器人上，不确定性的消解本身是一个受「控制权限 × 时延 × 一致性」三重约束的分布式控制分配问题；正确的决策单位不是信息动作，而是一份「消解契约」（消解什么、在哪一层、何时前回来、花多少平衡裕度、失败锚定到哪）；远端只能提议，本地安全内核必须签字。** 命名 **ANCHOR-RAS**（Anchored Networked Criticality-aware Humanoid Operation under Risk）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这副身体在此刻的延迟与算力下还求证得起吗？答案回来时，它还在同一个世界里吗？**」

## 0. 直觉与动机

**灵感 1（边缘计算 → 「计算在哪里」本身进入不确定性）**
直觉：R69 的闭环像一个站在身体里的智者，所有推理、采样、对账都与感官同步。边缘部署把它拆成一个「隔着抖动视频线指挥身体」的远程大脑：流匹配策略可能在边缘服务器，似然复核可能在云端，安全环必须留在关节旁。中间多出来的不只是延迟，还有**版本漂移、时钟偏差、排队抖动、分区、共享算力被邻居抢占**。这时系统可能对世界判断得很准，却对「自己正在用哪份世界、哪版模型、哪个时间点」判断错。把这类不确定性记为 U_coord，它的独特签名是：**增加思考时间会让它变大而不是变小**——这是它与 aleatoric（等也无用）、epistemic（等/问可变清）最本质的区别。

**灵感 2（人形机器人 → 信息动作与任务动作共用一副身体、一份平衡预算）**
直觉：R69 的「看/问/触」像是给决策器加了一个旁路传感器，成本只是社交和一点位移。人形机器人没有这个奢侈：注视常伴随头部/躯干转动并移动质心；前倾探看会压缩 ZMP 裕度；触摸会改变接触力分配；迈步是不可逆的承重承诺；连「停下来想」都要靠踝/髋持续做功。信息动作因此有**双重效应**：一边降低 epistemic 不确定性，一边消耗 aleatoric 安全裕度。VoI 必须用「控制权限」计价，平衡裕度的影子价格 λ_a 成为信息与稳定之间的真实汇率：**身体越接近失衡，好奇心越昂贵**。

**灵感 3（可逆性 → 高不确定时先看后踩，不是启发式而是最优）**
直觉：信息动作不是同质的。看一眼可撤回；前倾可恢复；踩上未知地形不可逆。若一个信息动作在假设错误时会把你锁进危险接触状态，它的「信息收益」必须扣除「承诺成本」。在高 epistemic 不确定性下，先用可逆动作把歧义压到可承受，再做不可逆承诺，往往是唯一不后悔的顺序。这把 R69 的 VoI 从标量升级为**带承诺风险的有序决策**：不仅问「值不值」，还问「先做哪一步、能不能退回来」。

**灵感 4（合成 → 决策单位从「信息动作」升级为「消解契约」）**
直觉：把边缘与人形合起来，真正要选的不是某个 g，而是一份契约 ρ =（消解哪个不确定量、用本地/边缘/云哪一层、何时前必须回来、花多少控制权限与能量、需要几条正交证据、失败时锚定到哪个本地安全行为）。R69 的 VoI、边缘的 offloading、人形的平衡预算，本质上都在给同一份「消解预算」报价。一旦用契约做单位，「问不问」就变成一个**多资源联合可行性问题**：时延不够就物理上不可行，平衡不够就经济上不可行，版本不齐就语义上不可行。

**灵感 5（安全不可外包 → anchor-or-abstain，把认证从动作级提升到信念级）**
直觉：远端可以提议，但**认证必须发生在身体里**。本地安全内核是唯一不可抢占、不可远程改写、不可版本漂移的信任根。R68 已经要求动作前缀（certified prefix）本地认证；R70 进一步要求**产生该前缀的那份信念也要认证**——提案必须携带栅栏令牌（单调 epoch、观测时间戳、模型/配置版本）并通过「锚定检验」（它引用的世界元素能否与当前本地观测对应上，残差是否在容差内）。过不了就弃权（abstain），锚定到本地保守策略。原则一句话：**可以听远端的建议，不能借远端的手签字。**

**灵感 6（混合关键性 → 好奇心必须可被抢占，安全环必须被隔离）**
直觉：边缘算力是共享的。K=4 的流采样、Hutchinson 似然、模态聚类都是「低关键性」任务；安全环是「高关键性」任务。R69 在单机上看是 2.6ms 的预算问题，在共享边缘上是**调度隔离**问题：一个机器人的好奇心可以饿死另一个机器人的反射，或者被恶意负载挤掉自己的安全周期。因此必须采用混合关键性调度：HI（安全内核）预留、不可抢占；MID（任务策略）可降级；LO（消解采样）可抢占、可丢弃。**好奇心是 best-effort，安全是 hard real-time。** 这也是把「不确定性管理」从算法问题推进到系统问题的关键一步。

**灵感 7（身体作为证人 → 触觉/本体感觉是不可被云端欺骗的锚）**
直觉：R69 用动作似然做「标定不可吸收的第二意见」。人形机器人还有一条更强的本地通道：**接触与本体感觉**。视觉与云端可被延迟注入、重放、篡改，但脚下的接触力、关节力矩、IMU 是本地物理事实。把探针/落脚设计成一次**触觉查询**，可以在不可逆承诺前把视觉歧义转成触觉确定；代价是它改变接触状态，所以必须排在可逆动作之后，并附带恢复动作。身体既是风险的来源，也是最终的测谎仪。

**灵感 8（新最坏情况 → 「在一个已经不存在的世界里做对了动作」）**
直觉：R69 的最坏情况是「问错比不问更危险」；R70 的最坏情况更隐蔽：延迟注入、重放、版本回滚、分区可以让远端答案**看起来完美自洽**，因为它来自过去或另一份模型；本地与远端各自自洽，系统报告「证据一致、置信很高」，但它一致的是一个幽灵世界。更糟的是，人形机器人会把这个幽灵动作执行到物理世界。**答错尚可纠正，答对了一个过期的问题则无法挽回。** 本轮的核心安全目标因此不是「少犯错」，而是「**绝不在未对账的世界上行动**」。

## 1. 形式化定义（增量：定义 327–345）

**定义 327（ANCHOR-RAS 总览）** ANCHOR-RAS = (EIA, CABA, LAG, BRC, AAK, MCS, SRC, EBA, NAC, RAS-WM†)。三不变式：
(i) **安全根本地不可外包**：认证、限幅、急停只发生在本地安全内核 K_L；远端/边缘的任何输出都只是提案（继承并强化 R68 定义 276-i）；
(ii) **消解预算与执行预算同源**：任何消解动作（看/问/触/算）必须从同一控制权限账本计价，并附带一个在权限内可行的恢复动作；
(iii) **anchor-or-abstain**：未经栅栏令牌、锚定检验与本地认证的信念不得驱动执行；失败即弃权并锚定本地保守行为。

**定义 328（分层身体与分布式时钟）** 三层节点：本地安全内核 K_L（硬实时、固定版本、不可抢占）、边缘具身策略 P_E（流匹配策略与似然复核，软实时）、云端推理 R_C（最佳努力、可选）。节点 n 有本地时钟 κ_n、模型版本 ν_n、信念 b_n、端到端时延 L_n = L_up + L_queue + L_infer + L_down。安全周期 T_c，K_L 的最坏执行时间 W_L。**同位退化**指所有节点同钟、同版本、零延迟、共享同一信念。

**定义 329（控制权限状态与账本 CABA）** 控制权限状态 a(x) = (a_zmp, a_wrench, a_torque, a_dcm, a_energy, a_thermal) ∈ [0,1]^6 为各约束的归一化裕度；a_min 为安全下限。动作 u（含信息动作）有需求向量 d(u)。可行域 ℱ(x) = {u : a(x) − d(u) ≥ a_min 且 ∃ u_rec 使 a(x′) − d(u_rec) ≥ a_min}，其中 x′ 为执行 u 后的预测状态。**影子价格** λ_a(x) 为活跃约束的对偶变量：一单位平衡裕度折算成的任务风险。账本 L_a 记录每一笔借记（动作 id、需求、可逆性、恢复动作、时间戳）。

**定义 330（具身信息动作 EIA）** g = (g_gaze, g_lean, g_probe, g_step, g_ask) ∈ 𝒜_info，每个分量带五元签名 (d(g), rev(g), c_com(g), u_rec(g), τ_g)：需求向量、可逆性等级 rev(g) ∈ {R2 可逆, R1 可恢复, R0 不可逆}、承诺成本 c_com(g)（若假设错误而被锁进该状态后的损失）、恢复动作、有效期。注视/头部转动多为 R2；前倾探看为 R1；探针与落脚为 R0。**信息动作是带承诺的控制行为，不是旁路观测。**

**定义 331（消解契约）** ρ = (T, method, tier, deadline, b_res, ev_req, anchor)，其中 T 为待消解的不确定量（U_epi 的某个模态对/某个接触假设/某个坐标），method ∈ {gaze, ask, probe, step, compute}，tier ∈ {K_L, P_E, R_C}，deadline 为答案必须回来的时刻，b_res = (auth, time, energy, social, compute) 为预算向量，ev_req 为证据纪律要求，anchor 为失败时的本地安全行为。契约空间 ℛ(x)。求解目标是**在多重可行性约束下最大化单位预算的遗憾下降**，而不是最大化信息量。

**定义 332（延迟–有效期分离与有效 VoI）** 状态有效期 τ_valid(x) := sup{t : 在不做新决策的情况下系统保持安全的时间}；答案适用概率 P_app(ρ) := Pr[L(ρ) + t_exec ≤ τ_valid(x) ∧ 锚定残差 ≤ δ]。**有效信息价值** VoI_eff(ρ) := P_app(ρ)·VoI(ρ)。若 P_app(ρ) = 0，则任何外部消解契约都被本地保护性行为严格支配（引理 20）——这不是预算不够，而是**物理上已经太晚**。

**定义 333（对账不确定性与同世界谓词 BRC）** 对账不确定性 U_coord := E[loss(decision on b_R) − loss(decision on b_true) | divergence]，其中 b_R 为远端/历史信念。散度 D(b_L, b_R) 用 W₂ 或 KL；栅栏元组 F = (epoch, obs_ts, ν, config_hash)。**同世界谓词** SW(b_R, x) ⇔ epoch ≥ epoch_L ∧ obs_ts ≥ now − τ_valid ∧ ν 与本地兼容 ∧ anchor_residual(b_R, o_L) ≤ δ。U_coord 的唯一消除器是**对账/锚定**（交换、重放校验、与本地观测对应），不是时间、交互或精度。

**定义 334（平衡税下的契约选择）** 契约得分
score(ρ) = P_app(ρ)·VoI(ρ) − λ_a(x)·auth(ρ) − c_social(ρ) − c_energy(ρ)，
约束 auth(ρ) ≤ a(x) − a_min、deadline 可行、可逆性次序满足定义 335、证据纪律满足定义 293-iii。最优契约 ρ* = argmax_ρ score(ρ)；若 max score ≤ 0 或无可信契约，则不消解，走本地锚定。**λ_a 是价格而非单纯约束**：它解释了「越接近失衡，越不愿提问」这一人形机器人特有的行为。

**定义 335（可逆性偏序与 reversible-first）** 对两个信息动作 g₁ ≺ g₂ 当且仅当 rev(g₁) ≥ rev(g₂) 且 auth(g₁) ≤ auth(g₂)，且 g₁ 的预期信息增益不低于 g₂ 的 α 倍（α<1 为容忍系数）。**规则**：当 U_epi > τ_epi 时，任何最优契约的首个消解动作必须取偏序极小元（可逆优先），除非所有可逆动作的期望增益都 ≤ 0（引理 22）。

**定义 336（混合关键性调度 MCS）** 任务分三级：HI（安全内核、接触反射、限幅）、MID（任务策略、认证）、LO（K>1 采样、Hutchinson 似然、模态聚类、对账计算）。HI 预留预算 W_HI 且不可抢占；LO 可抢占、可丢弃、有配额；过载时按 LO→MID 顺序卸载，HI 绝不参与共享调度。**计算证明**（compute attestation）记录每个提案的实际执行等级、开始/完成时间与是否被抢占，而不只是标称时延。

**定义 337（社会消解契约 SRC）** 把「问人」作为一个 tier：人类可用度 α_h（注意力、是否正忙于他事）、可读性 ℓ_g（注视/接近/姿态是否先于动作被理解）、轮次时限 τ_turn、惊吓预算 s_max。只有 α_h 与 ℓ_g 过门、且不越过 τ_turn、不惊吓（s ≤ s_max）时才允许发起人类查询；人类回答仍受 R69 证据纪律约束（不得单源定案）。

**定义 338（双信念锚定 AAK）** 本地影子策略 π_L（保守、已认证、低能力）与远端富策略 π_R（流匹配、高能力、可能过期）。**锚集** 𝒜(x) := {x′ : 从 x′ 出发存在权限内的恢复动作使系统回到安全}。远端前缀 p 可采纳当且仅当预测末态 x′_p ∈ 𝒜(x) 且本地认证通过。锚集是「远端可以把你带到哪里、本地还能把你救回来」的可达集。

**定义 339（对账协议与栅栏令牌）** 提案 P = (ξ, F, anchor_ref, auth_proof, ev_set)。接受规则：
ACCEPT(P) ⇔ epoch(P) ≥ epoch_L ∧ obs_ts(P) ≥ now − τ_valid ∧ version_compatible(P) ∧ anchor_residual(P) ≤ δ ∧ EvidenceDiscipline(P)。
重放/乱序/回滚由单调 epoch 与时间戳拒绝；版本回滚由 ν/config_hash 拒绝；分区期间**禁止新增外部消解契约**，只允许本地锚定。

**定义 340（降级模式与优雅退化）** 模式 M2（云辅助）⊃ M1（边缘辅助）⊃ M0（纯本地）。降级由时延超阈、分区、版本不兼容、算力过载触发，且每次降级都保持安全不变量；升级必须重新对账（不能因为网络恢复就立刻相信积压的旧答案）。**未对账期间不提问**：先恢复同世界谓词，再谈好奇心。

**定义 341（网络锚定证书 J_ANCHOR）** J_ANCHOR = (J_FLUID, authority_ledger_hash, latency_ledger, reconciliation_proof, criticality_attestation, compute_attestation, degradation_mode, fallback_plan)。Valid ⇔ Valid(J_FLUID) ∧ 权限账本无越界 ∧ P_app 与实测时延一致 ∧ SW 为真 ∧ HI 无截止期错失 ∧ 存在可执行恢复动作。

**定义 342（分布式–具身威胁模型 AIC-ANCHOR）** ℰ_ANCHOR = ℰ_FLUID × ℰ_edge × ℰ_embodied：
ℰ_edge：延迟注入、重放/陈旧答案、版本回滚/冻结、边缘节点被控、计算饥饿（饿死安全环）、分区诱导的分裂脑、时钟偏移；
ℰ_embodied：用信息动作耗尽平衡预算、不可逆探针误判、接触状态欺骗、人类惊吓/社交工程、幽灵遥操作（用陈旧信念驱动真实身体）；
组合攻击：**陈旧但自洽的幽灵世界**——单独看每条证据都一致，合起来指向一个已经不存在的状态。

**定义 343（参与式审计 VQAuditor-A）** 审计新增：契约报价是否真实（时延/权限是否被低报）、是否在未对账世界执行、是否单源采纳、是否把 LO 挤占 HI、信息动作是否先可逆后不可逆、人类查询是否越过打扰契约。结论回灌 CABA 的价格先验、BRC 的容差与 MCS 的配额。

**定义 344（身体作为证人 EBA）** 本地接触/本体感觉残差 r_body；当远端或视觉主张与 r_body 冲突且 r_body 置信足够时，**身体优先**（physical anchor）。把探针/落脚建模为触觉查询：它给出关于接触假设的近乎确定的信息，但把系统锁进一个接触状态，故必须带恢复动作、且排在其他可逆动作之后。它是 R69 引理 17（标定不可吸收第二意见）在身体侧的镜像：**有些事实只能由身体核实，且核实本身会改变身体。**

**定义 345（严格包含与安全单调）** 在同位退化（L=0、V 一致、a=∞、同节点）下，契约退化为 R69 的信息动作 g，ANCHOR-RAS 与 FLUID-RAS 逐指令相同；令不发起任何消解契约，则进一步退化为 R68。对任意网络与权限配置，由于每条执行动作都由本地 K_L 认证，安全不变量不弱于纯本地基线；远端协助只能改善任务性能，不能降低安全下限。**远端最多让任务更好，永远不能让身体更不安全。**

## 3. 推导

**引理 19（平衡税与影子价格）** 将契约选择松弛为 max VoI(ρ) s.t. Σ_i d_i(ρ) ≤ a_i(x) − a_min,i。设 λ_a 为活跃约束的乘子。则在最优处，单位控制权限的边际信息价值等于 λ_a；若所有契约的 VoI/auth 比都低于 λ_a，最优解是不消解、本地锚定。系：λ_a 随裕度收缩而单调上升；当 a(x)→a_min 时 λ_a→∞，好奇心被物理地关闭，而不是被调参关闭。这把 R69 的「VoI − 成本」升级为「VoI − 平衡机会成本」，并解释了为什么人形机器人在临界步态下应当「先稳住再问」。

**引理 20（延迟–动力学分离 / 不问定理）** 记 τ_valid(x) 为状态有效期。若 L(ρ) + t_exec > τ_valid(x)，则 P_app(ρ) = 0，VoI_eff(ρ) = 0；而等待与执行远端动作仍消耗非负控制权限，并可能缩短 τ_valid。故任意依赖外部答案的契约都被「本地保护性锚定」严格支配。**证明要点**：把等待视为一个虚拟动作 u_wait，其 auth(u_wait) ≥ 0 且不改善任何本地约束；由定义 332 收益为 0，故 score ≤ 0。系：**问不了时，唯一正确的动作是把世界变慢（减速/止步/后退以增大 τ_valid）或用本地接触把问题变成立即事实**——这正是「先稳住再问」的物理根据。

**引理 21（anchor-or-abstain 的无干扰性）** 若每条被执行的动作要么来自本地影子策略 π_L，要么是经过 reconcile + 锚集 + 本地认证的远端前缀，则对任意被控的远端/边缘节点，执行轨迹都是本地 K_L 本会允许的轨迹；因此跌倒、越界接触等安全不变量不被破坏（前提：K_L 与本状态估计器正确）。**证明要点**：远端影响只通过「提案是否被接受」这一布尔门；被拒即回落到 π_L；被接受的提案满足本地认证，故与 π_L 的安全约束同属一个可行集。系：远端攻击可以把任务成功率降到本地基线，但不能把安全降到本地基线以下；安全与性能在架构上**解耦**。

**引理 22（可逆优先占优）** 设信息动作 g 的承诺成本 c_com(g) 为假设错误时被锁进该状态的损失；在 U_epi 足够大时，若存在可逆动作 g_R 且其单位权限信息增益 ≥ 任一不可逆动作 g_I，则任何以 g_I 开头的契约都被某个以 g_R 开头、随后按观测决定是否继续的契约弱占优。**证明要点**：交换论证——先做 g_R 可在不承诺的情况下降低错误概率；若结果已足以决断，则省下 c_com(g_I)；若仍不足，再执行 g_I，其期望损失不高于直接执行。系：「先看后踩」不是工程启发式，而是在承诺成本主导时的一类最优策略；R69 把信息动作当作同质的是本轮要修正的核心建模错误。

**定理 18（ANCHOR 严格包含 FLUID 与 R68）** 在同位退化（L=0、版本一致、a=∞、同节点）下，消解契约退化为 R69 的信息动作 g，平衡税为 0、时延门恒开，ANCHOR 与 FLUID 逐指令相同；禁止一切消解契约则进一步退化为 R68。对任意网络与权限配置，ANCHOR 的执行动作始终经本地认证，故事故风险 ≤ 纯本地基线；其性能集合 ⊇ 纯本地基线，且在存在正收益契约时严格更大。故 ANCHOR 是 FLUID/R68 的保守扩展：安全侧不让步，性能侧多出「在正确时间、正确层级、正确版本上消解」的自由度。

**定理 19（混合关键性的有界退化）** 在 HI 预留 W_HI、LO 可抢占且可丢弃的调度下，只要 HI 自身利用率 U_HI < 1，其截止期满足率与 LO 到达率无关；持续过载时，LO 任务在有限时间 T_deg 内被排空，系统进入 M0（纯本地），且 T_deg ≤ (LO 队列长度 / 卸载速率) + 一个安全周期。故「好奇心」最多被延迟，永远不会以安全环错失截止期为代价。系：多台人形机器人共享边缘时，跨机器人的 LO 竞争不会传导为 HI 竞争——**好奇心不可跨体传染**。

**定理 20（对账的非陈旧性）** 在单调 epoch 源可信、时钟偏移有界、版本哈希不可伪造的假设 A100 下，任何被 ACCEPT 的提案满足 obs_ts ≥ now − τ_valid 且版本兼容，故不存在超出容差的重放/回滚采纳；系统不会在「已知过期」的世界上行动。注意这是**条件性**结论：若 epoch 源本身被控或本地时钟被篡改，则 anchor 仍可能被欺骗——这正是 AIC-ANCHOR 的 ℰ_edge 要覆盖的残余风险，也构成本轮最大风险的来源之一。

## 6. 本轮最大风险

**一句话**：ANCHOR-RAS 把全部安全信任押在「本地安全内核是可信的物理事实源」上——**一旦本体感觉/接触模型本身漂移、被标定吸收或被物理欺骗，anchor-or-abstain 只是把「远端的幽灵」换成「本地自信的幻觉」，系统会以最高置信度执行一次真实的跌倒；更隐蔽的是，权限账本的加性/线性假设会低估连续小信息动作对平衡裕度的非线性侵蚀，让系统在账面上永远「还剩一点」，直到那一点不够用。**

**次级风险与缓解**：
1. **U_coord 被误当 U_epi**（网络分区时仍去问一个已不属于当下的世界）→ 定义 333 同世界谓词 + 定义 340 未对账不提问；
2. **延迟注入/重放/版本回滚**（幽灵世界自洽）→ 定义 339 栅栏令牌 + 单调 epoch + 引理 21 无干扰性 + E303；
3. **LO 好奇心饿死 HI 安全环**（尤其多机器人共享边缘）→ 定义 336 混合关键性调度 + 定理 19 有界退化 + E304/E312；
4. **不可逆信息动作误承诺**（探针/落脚）→ 定义 335 可逆优先 + 引理 22 + E305/E308；
5. **权限模型的加性偏差**（连续信息动作的平衡侵蚀）→ 账本按恢复动作与预测状态记账 + 真实硬件 E314 + 保守 a_min 余量；
6. **社会查询越界**（惊吓、打扰、诱导）→ 定义 337 社会契约 + R69 证据纪律 + E309。

## 2. 形式化定义（要点版）

**定义 327（总览与三不变式）** ANCHOR-RAS = (EIA, CABA, LAG, BRC, AAK, MCS, SRC, EBA, NAC)；安全根本地不可外包；消解预算与执行预算同源；anchor-or-abstain（未对账/未认证即弃权并锚定本地）。

**定义 328–329（分层身体与权限账本）** K_L / P_E / R_C 三层各有钟、版本、信念；端到端时延 L。控制权限 a(x) 六维；可行动作须 `a(x)−d(u) ≥ a_min` 且存在恢复动作；影子价格 λ_a 为活跃约束对偶变量。

**定义 330（EIA）** 具身信息动作带 (d, rev, c_com, u_rec, τ) 五元签名；注视/转头 R2、前倾 R1、探针/落脚 R0。信息动作不是旁路观测，而是带承诺的控制行为。

**定义 331–332（契约与延迟门）** 契约 ρ 规定消解对象、层级、截止期、预算向量、证据要求、失败锚点；`τ_valid` 为状态有效期，`P_app = Pr[L+t_exec ≤ τ_valid ∧ 锚定残差 ≤ δ]`，`VoI_eff = P_app·VoI`。P_app=0 ⇒ 物理上不可行。

**定义 333–334（对账与平衡税）** U_coord 由散度/陈旧度/版本差决定；同世界谓词需 epoch 单调、时间戳新鲜、版本兼容、锚定残差合格。契约得分 `P_app·VoI − λ_a·auth − c_social − c_energy`，正才做，否则锚定。

**定义 335（可逆优先）** 偏序 `g₁ ≺ g₂` 由可逆性、权限需求与信息增益共同定义；U_epi 大时首个消解动作必须取偏序极小元。

**定义 336–337（MCS 与 SRC）** HI/MID/LO 三级，HI 预留不可抢占，LO 可丢弃；过载 LO→MID 卸载。问人需人类可用度、可读性、轮次时限、惊吓预算，且回答仍受 R69 证据纪律约束。

**定义 338–339（AAK 与对账协议）** 本地影子 π_L、远端富策略 π_R、锚集 𝒜(x)；远端前缀须末态 ∈ 𝒜 且本地认证。提案携带 `(ξ, F, anchor_ref, auth_proof, ev_set)`；接受需 epoch 单调、时间戳新鲜、版本兼容、锚定残差合格、证据纪律满足；分区期间禁止新增外部消解。

# IP-264 CABA：控制权限账本 + 平衡裕度影子价格
class AuthorityLedger:
    def feasible(self, x, u):
        return all(self.a(x)[i] - u.d[i] >= self.a_min[i] for i in range(6)) \
               and self.has_recovery(x, u)
    def price(self, x):
        return self.dual_of_active_constraints(x)       # λ_a
    def charge(self, u):
        self.log(u.id, u.d, u.rev, u.rec, u.ts)

# IP-265 EIA：具身信息动作（可逆优先）
class EmbodiedInfoAction:
    def generate(self, modes, x):
        cands = [self.gaze(modes), self.lean(modes), self.probe(modes),
                 self.step(modes), self.ask(modes)]
        for g in cands:
            g.d, g.rev = self.wbc.perturbation(g), self.wbc.reversibility(g)
            g.rec = self.wbc.recovery(g)
        return sorted(cands, key=lambda g: (-g.rev, sum(g.d)))

# IP-266 LAG：延迟门（物理上太晚就不问）
def latency_gate(contract, x, net):
    L   = net.estimate(contract.tier) + contract.compute
    tau = dynamics.validity_horizon(x)
    p   = dynamics.applicability_prob(x, L, contract.anchor)
    return p * contract.voi, (L + contract.t_exec <= tau), p

def reconcile(proposal, local):

    if proposal.obs_ts < local.now - local.tau:  return REJECT_STALE
    if not compatible(proposal.ver, local.ver):  return REJECT_VERSION
    if anchor_residual(proposal.ref, local.obs) > DELTA_ANCHOR:
        return REJECT_UNANCHORED

# IP-269 MCS：混合关键性调度（安全环隔离）
class MixedCriticalityScheduler:
    HI, MID, LO = 0, 1, 2
    def submit(self, task):
        if task.crit == self.HI:
            return self.hi_reserved.run(task)          # 不可抢占、预留
        if task.crit == self.LO and self.overload():

# IP-275 主闭环
def ANCHOR_round(M, obs):
    x = M.estimator.local(obs)                 # 本体/接触优先
    if M.mcs.hi_overdue():
        return M.kernel.safe_stop(x), M.nac.issue(mode='M0')
    U = M.aud.decompose(M.fmp, obs, crit=MCS.LO)
    if not M.brc.same_world(M.remote_belief, x):
        return M.anchor.local(x, U), M.nac.issue(mode='M0')
    best = None
    for g in M.eia.generate(U.modes, x):
        if not M.authority.feasible(x, g):    continue
        if not M.safety.certify_info(g, x):   continue

                 - rho.social - rho.energy)
        if score > 0 and (best is None or score > best.score):

                                         M.pi_R.propose(x))

    M.vqa_a.submit(best, src, U, U2, M.authority.ledger, M.lag.ledger)
    return prefix, lam, U2, M.nac.issue(mode='M1')

## 4. 推导

**引理 19（平衡税与影子价格）** 松弛契约选择 `max VoI(ρ) s.t. Σ d_i(ρ) ≤ a_i(x)−a_min,i`，最优处单位权限边际信息价值 = λ_a；若所有契约的 VoI/auth 比低于 λ_a，则不消解、本地锚定。系：λ_a 随裕度收缩单调上升，`a→a_min` 时 λ_a→∞——好奇心被物理关闭，而非被调参关闭。

**引理 20（延迟–动力学分离 / 不问定理）** 若 `L(ρ)+t_exec > τ_valid(x)`，则 `P_app=0`、`VoI_eff=0`；等待仍消耗非负权限并可能缩短 τ_valid，故外部消解契约被本地保护性锚定严格支配。系：太晚时唯一正确的动作是**把世界变慢**（减速/止步/后退增大 τ_valid）或**用本地接触把问题变成即时事实**。

**引理 21（anchor-or-abstain 的无干扰性）** 执行动作若要么来自本地 π_L，要么是经 reconcile + 锚集 + 本地认证的远端前缀，则对任意被控远端/边缘节点，执行轨迹都是本地 K_L 本会允许的轨迹；跌倒、越界接触等安全不变量不被破坏（前提：K_L 与状态估计器正确）。系：远端攻击最多把任务成功率降到本地基线，不能把安全降到本地基线以下——安全与性能在架构上解耦。

**引理 22（可逆优先占优）** 设承诺成本 `c_com(g)` 为假设错误时被锁进该状态的损失。U_epi 足够大且存在可逆 g_R 的单位权限信息增益 ≥ 不可逆 g_I 时，任何以 g_I 开头的契约都被「先 g_R、按观测再决定是否 g_I」的契约弱占优（交换论证）。系：「先看后踩」是承诺成本主导下的最优策略，而非工程启发式；R69 把信息动作同质化是本轮修正的核心建模错误。

**定理 18（ANCHOR 严格包含 FLUID 与 R68）** 同位退化（L=0、版本一致、a=∞、同节点）下契约退化为 R69 的 g，平衡税为 0、时延门恒开 ⇒ 与 FLUID 逐指令相同；禁止消解 ⇒ 退化为 R68。任意配置下执行动作均经本地认证 ⇒ 风险 ≤ 纯本地基线；性能集合 ⊇ 纯本地基线，存在正收益契约时严格更大。

**定理 19（混合关键性的有界退化）** HI 预留 W_HI、LO 可抢占可丢弃，只要 U_HI<1，HI 截止期满足率与 LO 到达率无关；持续过载时 LO 在 `T_deg ≤ 队列长度/卸载速率 + T_c` 内排空并进入 M0。系：多机器人共享边缘时，LO 竞争不会传导为 HI 竞争——好奇心不可跨体传染。

**定理 20（对账的非陈旧性）** 在单调 epoch 源可信、时钟偏移有界、版本哈希不可伪造（A100）下，ACCEPT 的提案必满足观测新鲜且版本兼容，故不存在超出容差的重放/回滚采纳。**条件性**：若 epoch 源被控或本地时钟被篡改，anchor 仍可被欺骗——这是 AIC-ANCHOR 的残余风险与本轮最大风险来源。

## 7. 本轮最大风险

**一句话**：ANCHOR-RAS 把全部安全信任押在「本地安全内核是可信的物理事实源」上——**一旦本体感觉/接触模型本身漂移、被标定吸收或被物理欺骗，anchor-or-abstain 只是把「远端的幽灵」换成「本地自信的幻觉」，系统会以最高置信度执行一次真实的跌倒；而权限账本的加性/线性假设会低估连续小信息动作对平衡裕度的非线性侵蚀，让账面永远「还剩一点」，直到那一点不够用。**

**次级风险与缓解**：U_coord 被误当 U_epi（定义 333 同世界谓词 + 定义 340 未对账不提问）；延迟注入/重放/版本回滚（定义 339 栅栏令牌 + 引理 21 无干扰性 + E303）；LO 好奇心饿死 HI（定义 336 混合关键性 + 定理 19 + E304/E312）；不可逆信息动作误承诺（定义 335 可逆优先 + 引理 22 + E305/E308）；权限模型加性偏差（按恢复动作与预测状态记账 + 保守 a_min + E314）；社会查询越界（定义 337 社会契约 + R69 证据纪律 + E309）。
