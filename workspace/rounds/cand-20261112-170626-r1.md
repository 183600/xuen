# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「仿真到现实迁移」×「强化学习训练」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 让场景成为阻抗先验、CIEC 把意图锁定为实时约束、EPIR 保证 EV-exec 消息完整性、SERC 统一闭环、PCE++++ 扩展认知预算。但**三处未经审计的“信仰”**在第 61 轮必须被揭开：
> 1. **场景先验的来源未经检验**：π_scene(K|z) 被默认可用，现实中它只能来自仿真或离线训练；一旦仿真分布与真机不符，SSM 会**更早、更自信地**收敛到错误的 K_safe——第 60 轮警示的“抽象泄漏”换了个入口重新出现。
> 2. **意图-约束映射是手工字典**：CIEC 的 ϕ 是硬编码表，覆盖不了自然语言长尾与用户偏好漂移；RL 可学习 ϕ，但 RL 的探索不安全、策略是黑箱，直接部署会击穿 ERTC 的硬约束。
> 3. **证据链只审计“执行合规”，不审计“训练/迁移合规”**：EPIR 证明 EV-exec 未丢包，却不证明“部署策略来自与真机同分布的仿真、且训练中约束被遵守”；分布漂移可**静默失败且不留证据**。

## 0. 直觉与动机

**灵感 1（仿真到现实 → 差距即安全预算 Gap-as-Safety-Budget, GSB）**
直觉：主流 Sim2Real 用域随机化追**性能**；但本架构是**证书中心**的，仿真-现实差异 δ_sr 应被换算为可度量的**安全保证金 m(δ_sr)**，并据此**主动收缩**已认证阻抗包络 K_safe。关键洞见：**“仿真越真”买到的不是性能，而是可用安全包络的扩张**——“仿真越真 ⇒ δ↓ ⇒ m↓ ⇒ K_safe 越大”，安全与性能被统一到同一货币：证书余量（margin economics）。

**灵感 2（强化学习训练 → 盾牌内搜索 Shielded Search）**
直觉：RL 不该“带着软惩罚去冒险”，而应“在已认证的盾牌里搜索”。把 EEIS/ERTC 编译出的 K_safe 作为**硬投影算子 Π**：策略原始动作 a_raw 先投影到安全动作集 A(K_safe^sr)；探索噪声同样被投影。关键洞见：**把安全约束从“奖励项”提升为“动作空间几何约束”**，探索因此变成安全探索，硬违规在结构上为 0。

**灵感 3（序结构迁移 Ordinal-Structure Transfer, OST）**
直觉：仿真通常能把“地毯比光滑桌面摩擦大、楼梯比桌面阻抗高”的**相对次序**学对，但绝对增益尺度会偏。因此迁移应**保序不保值**：每个阻抗维度只标定一个单调仿射 T_φ（3–5 次真实接触），约束 Kendall τ 不降，把尺度误差以 O(1/√n) 压下去。关键洞见：**可迁移的不变量是“序”，不是“值”**。

**灵感 4（仿真-现实共校准 Sim-Real Co-Calibration, SRCC）**
直觉：真机 EV-exec 不是终点，而是**仿真参数的观测**。用贝叶斯系统辨识更新仿真参数后验 θ_sim|EV-exec，再用**后验域随机化 PDR**（从后验采样而非均匀盒）生成仿真分布。关键洞见：**每一份真实证据都“买回”一点安全保证金**——δ̂ 单调收敛 ⇒ 包络单调扩张，但永不越过证书。

**灵感 5（迁移预算 + 迁移取证 PCE+++++ / TEAC）**
直觉：迁移不是一次动作，而是**有预算的持续过程**：B_sim（仿真 rollout）、B_real（真机微调步数）、B_gap（差距估计查询）、B_margin（保证金松弛额度）。若差距不确定度 σ_δ 高 ⇒ 优先花 B_gap；若证书有效 ⇒ 花 B_real；若 B_gap 耗尽 ⇒ 膨胀保证金、收缩包络；若证书失效 ⇒ **禁用 RL，回退第 60 轮规则表 CIEC**。同时把数据集哈希、仿真后验快照、策略 checkpoint、盾牌版本、迁移证书钉入证据链（TEAC），使“训练-部署”可审计。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（仿真到现实迁移差异与证书 STR）** 设安全相关轨迹统计量 ψ(τ) = (F_contact, slip, tracking_error, τ_torque)。在部署支撑集 S_supp 上定义迁移差异：
- **差异度量**：δ_sr = sup_{π, K∈K_safe^sr} W₁( P_sim(ψ(τ)|π,K), P_real(ψ(τ)|π,K) )，用两样本 Wasserstein 上置信界估计 δ̂_sr。
- **迁移证书**：Cert_transfer(π) = (δ̂_sr, δ_hi, m(δ_hi), J_lb(π), S_supp.covers(), hash(π))，其中性能下界
  J_lb(π) = J_sim(π) − L_perf·δ_hi − ε_conf，L_perf 为性能对动力学的 Lipschitz 常数。
- **部署闸门**：DeployOK(π) ⟺ [δ_hi ≤ δ_max] ∧ [J_lb(π) ≥ J_req] ∧ [S_supp.covers(π)]。其中 **支撑覆盖** 要求真机数据覆盖策略访问的 (s,a) 区域，禁止证书外推。

**定义 162（差异感知安全包络收缩 GAS）** 给定基准包络 K_safe_base 与差距上界 δ_hi：
- **保证金函数**：m(δ) = m₀ + c·δ（线性证书；亦可替换为鲁棒不变集半径）。
- **有效包络**：K_safe^sr(δ_hi) = { K ∈ K_safe_base : ρ_rob(K) ≥ m(δ_hi) }，ρ_rob 为阻抗参数的鲁棒裕度。
- **单调性**：δ₁ ≤ δ₂ ⇒ K_safe^sr(δ₁) ⊇ K_safe^sr(δ₂)。若 K_safe^sr = ∅，触发保守回退（第 60 轮 K_safe_base）。
- **margin economics**：Δδ↓ ⇒ Δm↓ ⇒ 包络可扩张；每单位真实证据的边际价值 = ∂|K_safe^sr|/∂δ。

**定义 163（屏蔽约束策略优化 SCPO）** 策略 π_θ(a|s,I)，盾牌 Π：a_t ← Proj_{A(K_safe^sr)}(a_t^raw)，A 由阻抗/力矩/速度/接触力上界构成。优化为 CMDP：
```
max_θ  E[ Σ_t γ^t r_t ]
s.t.    E[ Σ_t C_i,t ] ≤ d_i ,  i ∈ {force, slip, torque}
        a_t ∈ A(K_safe^sr)   （硬约束，逐时刻投影）
```
用原始-对偶（拉格朗日乘子 λ_i 更新）求解；盾牌为硬投影，CMDP 约束为软预算。**定理（结构安全）**：若 A(K_safe^sr) 对真实被控对象可靠（由定义 162 保证金保证），则硬违规概率为 0，与策略探索无关。

**定义 164（序结构迁移 OST）** 对场景 z、阻抗维度 d，设仿真先验在场景间次序正确、尺度偏移。迁移为逐维单调仿射：
- **标定**：T_φ,d(x) = a_d·x + b_d，a_d > 0；用少量真机接触 D_real = {(z_i, K_d^i)}_{i=1..n}（n≈3–5）最小二乘拟合。
- **保序约束**：Kendall τ(π_sim(·|z), π_real(·|z)) ≥ τ_min。
- **校准先验**：π_real(K|z) = (T_φ)# π_sim(K|z)（push-forward）。
- **保证**：若仿真场景次序正确且 T_φ 单调，则校准先验保持次序；绝对误差以 O(1/√n) 收缩。

**定义 165（意图条件认证策略 ICP-RL）** 学习长尾意图映射 f_θ: I → C_intent，但输出**必须落在认证约束多面体** C_cert（由第 60 轮 CIEC 安全规格与 ERTC 契约导出）：
- ϕ_θ(I) = Proj_{C_cert}( f_θ(I) )。
- 训练：已知意图用 CIEC 手工表作标签（蒸馏），未知意图用最近邻/默认约束并上报不确定度 u(I)。
- **认证性**：∀I，ϕ_θ(I) ∈ C_cert ⇒ 第 60 轮的 τ_response 与硬约束保证原样保留；RL 只扩展覆盖范围，不扩大可行域。

**定义 166（仿真-现实共校准 SRCC）** 仿真参数 θ_sim（摩擦、质量、电机常数）。贝叶斯系统辨识：
- **后验更新**：p(θ_sim | EV-exec_{1:t}) ∝ p(EV-exec_t | θ_sim) · p(θ_sim | EV-exec_{1:t-1})，用粒子/拉普拉斯近似维护。
- **创新信号**：BUQ 残差 r_t = EV-exec_t − g(θ_sim) 作为似然驱动。
- **后验域随机化 PDR**：θ ~ p(θ_sim | EV-exec)，替代均匀盒随机化。
- **收敛保证**：后验方差收缩 ⇒ δ̂_sr 单调下降（期望意义）⇒ m(δ̂) 下降 ⇒ K_safe^sr 单调扩张。

**定义 167（迁移感知预算 PCE+++++）** B_trans = (B_sim, B_real, B_gap, B_margin)。VOI 扩展：
```
voi_trans(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_trans(π)
cost_trans = λ_sim·SimRollout + λ_real·RealFinetune + λ_gap·GapQuery + λ_margin·MarginRelax
```
分配规则：若 σ_δ（差距不确定度）> θ_gap ⇒ 优先 B_gap；若 Cert_transfer 有效 ⇒ 花 B_real 微调；若 B_gap 耗尽 ⇒ m 膨胀、包络收缩；若 Cert 失效 ⇒ **禁用 RL、回退第 60 轮 CIEC**；若 B_sim 耗尽 ⇒ 仅用 OST 少样本校准。

**定义 168（仿真到现实安全闭环 S2RSL + 迁移取证 TEAC）** 算子 S2RSL(M, π, sim_env)：
```
① SRCC: θ_post ← update(θ_post, EV-exec, BUQ)
② PDR:  sim_env ← resample(sim_env, θ_post)
③ OST:  π_real ← ordinal_structure_transfer(π_scene_sim, D_real)
④ GAS:  δ̂, δ_hi, Cert_transfer ← estimate_gap(π, K_safe_sr, sim_env, D_real)
⑤ GAS:  K_safe^sr ← compile_with_margin(K_safe_base, m(δ_hi))
⑥ Gate: if not DeployOK(Cert_transfer): return fallback_round60(M)
⑦ SCPO: π ← shielded_constrained_ppo(π, Shield(K_safe^sr), sim_env)
⑧ Deploy: send_policy(π, Shield(K_safe^sr), Cert_transfer)
⑨ Execute: EV-exec ← wait_contact(); EPIR.append(EV-exec)
⑩ TEAC: transfer_chain.append(dataset_hash, θ_post_snapshot, hash(π), shield_ver, Cert_transfer)
⑪ Return (π, K_safe^sr, Cert_transfer, TEAC.status)
```

## 2. 关键算法伪代码

### IP-161 STR（迁移差异与证书）

```python
def estimate_transfer_cert(policy, K_safe_sr, sim_env, real_buffer, alpha=0.05):
    supp = support_region(policy, real_buffer)
    sim_stats  = rollout_stats(sim_env, policy, K_safe_sr, n=2000)
    real_stats = [real_buffer.stat(m) for m in supp.members()]
    delta_hat, lo, hi = wasserstein_ucb(sim_stats, real_stats, alpha)
    L = lipschitz_perf_bound(policy)
    J_lb = sim_env.eval(policy) - L * hi - eps_conf
    cert = TransferCert(
        delta_hat=delta_hat, delta_hi=hi, margin=m_of(hi),
        J_lb=J_lb, support_ok=supp.covers(), policy_hash=hash_policy(policy))
    return cert

def deploy_gate(cert, J_req, delta_max):
    return (cert.delta_hi <= delta_max
            and cert.J_lb >= J_req
            and cert.support_ok)
```

### IP-162 GAS（差异感知包络收缩）

```python
def gap_aware_compile(eeis, delta_hi, K_safe_base, m0=0.02, c=1.5):
    m = m0 + c * delta_hi
    K_safe_sr = [K for K in K_safe_base if robustness_margin(K) >= m]
    if not K_safe_sr:
        return None                      # 触发第 60 轮保守回退
    return K_safe_sr                     # δ↓ ⇒ m↓ ⇒ 包络↑（单调）
```

### IP-163 SCPO（盾牌约束策略优化）

```python
def shielded_constrained_ppo(policy, shield, env, iters, constraints, eta=0.05):
    lagr = {c.name: 0.0 for c in constraints}
    for _ in range(iters):
        for traj in env.collect(policy):
            for t in range(len(traj)):
                traj.actions[t] = shield.project(traj.actions[t], traj.states[t])
        policy.update(ppo_loss(traj))
        for c in constraints:
            cost = traj.cost(c.name)
            lagr[c.name] = max(0.0, lagr[c.name] + eta * (cost - c.budget))
    return policy, lagr
```

### IP-164 OST（序结构迁移）

```python
def ordinal_structure_transfer(prior_sim, real_calib, tau_min=0.9):
    coeffs, taus = {}, {}
    for d in prior_sim.dims:
        xs = [prior_sim.mean(z)[d] for z in prior_sim.scenes]
        ys = [real_calib.mean(z)[d] for z in real_calib.scenes]
        a, b = fit_monotone_affine(xs, ys)     # 约束 a > 0
        coeffs[d] = (a, b)
        taus[d] = kendall_tau(xs, ys)
        if taus[d] < tau_min:
            coeffs[d] = (1.0, 0.0)             # 次序不可靠 -> 不迁移
    def transfer(prior):
        return pushforward(prior, lambda K: {
            d: coeffs[d][0] * K[d] + coeffs[d][1] for d in prior_sim.dims})
    return transfer, taus
```

### IP-165 ICP-RL（意图条件认证策略）

```python
def certified_intent_mapping(f_theta, C_cert, known_intents, eps=0.1):
    def phi(intent):
        if intent in known_intents:
            return known_intents[intent]               # 用 CIEC 手工表蒸馏
        raw = f_theta(intent)
        if raw.uncertainty > eps:
            return default_constraint(C_cert)          # 不确定 -> 保守默认
        return project_polytope(raw.value, C_cert)     # 硬投影到认证多面体
    return phi
```

```python
def sim_real_co_calibration(theta_post, ev_exec, buq):
    for ev in ev_exec:
        r = buq.residual(ev)                           # BUQ 创新
        theta_post.update(likelihood(ev, theta_post, r))
```

### IP-167 PCE+++++（迁移感知预算）

```python
class TransferBudget:
    def __init__(self, sim_rollouts, real_steps, gap_queries, margin_budget):
        self.B = dict(sim=sim_rollouts, real=real_steps,
                      gap=gap_queries, margin=margin_budget)

    def allocate(self, sigma_delta, theta_gap, cert_valid):
        if self.B['gap'] <= 0:
            return 'inflate_margin'          # 差距不可估 -> 更保守
        if sigma_delta > theta_gap:
            self.B['gap'] -= 1
            return 'spend_on_gap_estimation'
        if cert_valid:
            self.B['real'] -= 1
            return 'spend_on_real_finetune'
        return 'fallback_round60'
```

### IP-168 S2RSL（仿真到现实安全闭环）

```python
def sim2real_safety_loop(M, policy, sim_env, D_real):
    theta_post = M.srcc.posterior
    dr = M.srcc.pdr(theta_post)
    prior_real, taus = ordinal_structure_transfer(M.scene_prior_sim, D_real)
    cert = estimate_transfer_cert(policy, M.K_safe_sr, sim_env, D_real)
    K_safe_sr = gap_aware_compile(M.eeis, cert.delta_hi, M.K_safe_base)
    if K_safe_sr is None or not deploy_gate(cert, M.J_req, M.delta_max):
        return fallback_round60(M)                     # 回退 IP-154 规则表
    policy, lagr = shielded_constrained_ppo(
        policy, Shield(K_safe_sr), sim_env, M.iters, M.constraints)
    M.epir.append(transfer_evidence(cert, theta_post, policy, taus))
    return policy, K_safe_sr, cert, M.epir.chain_status()
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| STR | O(n_sim + n_real) 估计 / O(1) 闸门 | O(n_hist) | δ̂ 覆盖率 ≥ 1−α；禁止支撑外推 |
| GAS | O(\|K_base\|) 过滤 | O(\|K_base\|) | 包络单调收缩；空集即回退 |
| SCPO | O(迭代 × 样本 × \|A\|) | O(策略参数量) | 盾牌内硬违规 = 0 |
| OST | O(n·D) 拟合 | O(D) | 保序 τ ≥ τ_min；否则不迁移 |
| ICP-RL | O(1) 投影 / O(推理) | O(θ) | ∀I 输出 ∈ C_cert |
| SRCC | O(粒子数 × 维度) / 更新 | O(粒子数) | 后验方差单调收缩 |
| S2RSL | O(闭环) | 复用 | 证书有效才部署，否则回退 |

**正确性定理（S2R-Safety）**：假设 A66–A70 成立：
- **(A66)** δ̂_sr 是部署支撑集上 δ_sr 的 (1−α) 上置信界；
- **(A67)** 保证金 m(δ_hi) 使盾牌 A(K_safe^sr) 对真实对象可靠；
- **(A68)** OST 的单调仿射保持场景次序（τ ≥ τ_min）；
- **(A69)** SCPO 的 CMDP 满足 Slater 条件，乘子有界；
- **(A70)** PCE+++++ 各维预算单调消耗。

则：
1. **安全性**：P(真机硬约束违规) ≤ α（置信外），且盾牌内违规恒为 0。
2. **性能下界**：在支撑集内 J_real(π) ≥ J_sim(π) − L_perf·δ_sr。
3. **单调保证金**：真实证据累积使 δ̂ 期望单调下降 ⇒ K_safe^sr 期望单调扩张，不出现“越训越保守”的死锁。
4. **可审计性**：TEAC 可重建每次迁移决策；若 δ 被低估，可由事后 EV-exec 与证书对账检出。

## 5. 本轮最大风险

**一句话**：证书只在**有限真机样本的支撑集**上有效，而 RL 策略会持续漂移到低覆盖区域，使 δ̂_sr 静默退化为**外推值**、令“差距认证盾牌”虚假安全；必须以「支撑覆盖闸门 + 在线差距监控 + 保证金自动膨胀 + 证书失效即刻回退第 60 轮规则表 CIEC」四重护栏，确保“越训越激进”永远不越过“可审计的安全”。

> 承接第 60 轮 IP-153~160（场景感知闭环 SSM×CIEC×EPIR×SERC×PCE++++）。本轮把「场景-执行闭环」升级为 **「带证书的仿真到现实闭环」**：不再假设场景先验与意图映射凭空可用，也不再让 RL 黑箱直接落地。核心转变——**把仿真-现实差距 δ_sr 从一个“性能噪声”变成一张可度量、可消费、可审计的“安全证书”**：差距越大 ⇒ 保证金越大 ⇒ 已认证阻抗包络越小；真实证据越多 ⇒ 差距收敛 ⇒ 保证金释放 ⇒ 包络扩张。实现 **「仿真越真买安全、RL 只在盾牌内搜索、仿真先验保序迁移、真实证据反哺仿真」**。

## 2. 关键算法伪代码

### IP-161 STR（迁移差异与证书）

```python
def estimate_transfer_cert(policy, K_safe_sr, sim_env, real_buffer, alpha=0.05):
    supp = support_region(policy, real_buffer)
    sim_stats  = rollout_stats(sim_env, policy, K_safe_sr, n=2000)
    real_stats = [real_buffer.stat(m) for m in supp.members()]
    delta_hat, lo, hi = wasserstein_ucb(sim_stats, real_stats, alpha)
    L = lipschitz_perf_bound(policy)
    J_lb = sim_env.eval(policy) - L * hi - eps_conf
    return TransferCert(delta_hat=delta_hat, delta_hi=hi, margin=m_of(hi),
                        J_lb=J_lb, support_ok=supp.covers(),
                        policy_hash=hash_policy(policy))

def deploy_gate(cert, J_req, delta_max):
    return (cert.delta_hi <= delta_max
            and cert.J_lb >= J_req
            and cert.support_ok)
```

### IP-162 GAS（差异感知包络收缩）

```python
def gap_aware_compile(eeis, delta_hi, K_safe_base, m0=0.02, c=1.5):
    m = m0 + c * delta_hi
    K_safe_sr = [K for K in K_safe_base if robustness_margin(K) >= m]
    return K_safe_sr or None        # 空集 -> 第 60 轮保守回退
```

### IP-163 SCPO（盾牌约束策略优化）

```python
def shielded_constrained_ppo(policy, shield, env, iters, constraints, eta=0.05):
    lagr = {c.name: 0.0 for c in constraints}
    for _ in range(iters):
        for traj in env.collect(policy):
            for t in range(len(traj)):
                traj.actions[t] = shield.project(traj.actions[t], traj.states[t])
        policy.update(ppo_loss(traj))
        for c in constraints:
            lagr[c.name] = max(0.0, lagr[c.name]
                               + eta * (traj.cost(c.name) - c.budget))
    return policy, lagr
```

### IP-164 OST（序结构迁移）

```python
def ordinal_structure_transfer(prior_sim, real_calib, tau_min=0.9):
    coeffs, taus = {}, {}
    for d in prior_sim.dims:
        xs = [prior_sim.mean(z)[d] for z in prior_sim.scenes]
        ys = [real_calib.mean(z)[d] for z in real_calib.scenes]
        a, b = fit_monotone_affine(xs, ys)      # a > 0
        taus[d] = kendall_tau(xs, ys)
        coeffs[d] = (a, b) if taus[d] >= tau_min else (1.0, 0.0)
    def transfer(prior):
        return pushforward(prior, lambda K: {
            d: coeffs[d][0] * K[d] + coeffs[d][1] for d in prior_sim.dims})
    return transfer, taus
```

### IP-165 ICP-RL（意图条件认证策略）

```python
def certified_intent_mapping(f_theta, C_cert, known_intents, eps=0.1):
    def phi(intent):
        if intent in known_intents:
            return known_intents[intent]
        raw = f_theta(intent)
        if raw.uncertainty > eps:
            return default_constraint(C_cert)
        return project_polytope(raw.value, C_cert)
    return phi
```

### IP-166 SRCC（仿真-现实共校准）

```python
def sim_real_co_calibration(theta_post, ev_exec, buq):
    for ev in ev_exec:
        r = buq.residual(ev)
        theta_post.update(likelihood(ev, theta_post, r))
    if theta_post.variance_reduced():
        theta_post.freeze_baseline()
    return PosteriorDR(theta_post)
```

### IP-167 PCE+++++（迁移感知预算）

```python
class TransferBudget:
    def __init__(self, sim_rollouts, real_steps, gap_queries, margin_budget):
        self.B = dict(sim=sim_rollouts, real=real_steps,
                      gap=gap_queries, margin=margin_budget)

    def allocate(self, sigma_delta, theta_gap, cert_valid):
        if self.B['gap'] <= 0:
            return 'inflate_margin'
        if sigma_delta > theta_gap:
            self.B['gap'] -= 1
            return 'spend_on_gap_estimation'
        if cert_valid:
            self.B['real'] -= 1
            return 'spend_on_real_finetune'
        return 'fallback_round60'
```

### IP-168 S2RSL + TEAC（仿真到现实安全闭环）

```python
def sim2real_safety_loop(M, policy, sim_env, D_real):
    theta_post = M.srcc.posterior
    dr = M.srcc.pdr(theta_post)
    prior_real, taus = ordinal_structure_transfer(M.scene_prior_sim, D_real)
    cert = estimate_transfer_cert(policy, M.K_safe_sr, sim_env, D_real)
    K_safe_sr = gap_aware_compile(M.eeis, cert.delta_hi, M.K_safe_base)
    if K_safe_sr is None or not deploy_gate(cert, M.J_req, M.delta_max):
        return fallback_round60(M)
    policy, lagr = shielded_constrained_ppo(
        policy, Shield(K_safe_sr), sim_env, M.iters, M.constraints)
    M.epir.append(transfer_evidence(cert, theta_post, policy, taus))
    return policy, K_safe_sr, cert, M.epir.chain_status()
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| STR | O(n_sim+n_real) / O(1) 闸门 | O(n_hist) | δ̂ 覆盖率 ≥ 1−α |
| GAS | O(\|K_base\|) | O(\|K_base\|) | 包络单调收缩，空集回退 |
| SCPO | O(iter·batch·\|A\|) | O(θ) | 盾牌内硬违规 = 0 |
| OST | O(n·D) | O(D) | τ ≥ τ_min 否则不迁移 |
| ICP-RL | O(1) 投影 | O(θ) | 输出 ∈ C_cert |
| SRCC | O(N_particles·d) | O(N_particles) | 后验方差单调收缩 |
| S2RSL | O(闭环) | 复用 | 证书有效才部署 |

**正确性定理（S2R-Safety）**：若 A66–A70 成立，则：
1. P(真机硬约束违规) ≤ α，盾牌内违规恒为 0；
2. 支撑集内 J_real(π) ≥ J_sim(π) − L_perf·δ_sr；
3. 真实证据累积使 δ̂ 期望单调下降 ⇒ K_safe^sr 期望单调扩张；
4. TEAC 可事后对账，δ 低估必可检出。

## 5. 本轮最大风险

**一句话**：证书只在**有限真机样本的支撑集**上有效，而 RL 策略会持续漂移到低覆盖区域，使 δ̂_sr 静默退化为**外推值**、令“差距认证盾牌”虚假安全；必须以「支撑覆盖闸门 + 在线差距监控 + 保证金自动膨胀 + 证书失效即刻回退第 60 轮规则表 CIEC」四重护栏，确保“越训越激进”永远不越过“可审计的安全”。
