# 第 66 轮（承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；灵感循环第 2 轮；本轮灵感：「研究空白」×「用户共创」）

> 第 65 轮 VISTA 把「几何可证伪」升级为「故障可归因」，用视觉补接触前/接触外的证据、用动作分块的三阶段制造可辨识性、用「长预测短执行」截断块级承诺。它自述的最大风险同样尖锐：**归因依赖「故障属于有限假设集 ℋ、且视觉与几何失效相互独立」；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一分布外失效源。此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——系统还会因为「已经归因」而更自信地继续执行。** 本轮不再追问「该膨胀哪个球」，而是追问一个更上一层的问题：**当故障根本不在 ℋ 里时，系统凭什么知道自己不知道？知道之后，又该向谁、以什么方式补上这块知识？** 本轮核心命题是：
>
> **把「闭集故障归因」升级为「开放世界的研究空白共创」：用逐假设 conformal 检验显式地识别「不在任何已知假设支持范围内」的知识空白；把人类用户从「标注者/审批者」升级为「假设与安全边界的共创者」，但人类输入同样只是可证伪的证据而非真值；在空白被填补之前，系统只做保守包络或共签探索，绝不再强行归因。**

## 0. 直觉与动机

**灵感 1（研究空白 → 不是「哪个假设最像」，而是「根本没有假设覆盖这里」）**
直觉：第 65 轮的 softmax 归因有一个结构性缺陷——它永远输出一个已知标签，因为概率单纯形没有「以上都不是」这个选项。真实世界的「研究空白」在技术上有精确对应：观测签名 ρ 落在**所有已知假设的标定支持域之外**。这不是「归因模糊（ambiguous，两个已知假设五五开）」，而是**开放集问题（open-set）**：不是 H_geo 还是 H_force 的困惑，而是「它们都不对」。把空白显式建模成状态，比让模型在闭集上过度自信更重要；同时，空白不是均匀的——有些空白低频低危，有些空白高频高危，所以需要一个**空白地图**来排序「先补哪里」。

**灵感 2（研究空白 → 空白地图把「未知」变成可管理的资源分配问题）**
直觉：研究者不会平均地研究所有未知，而是优先研究「重要且没人做过」的空白。机器人也应如此：把任务/技能/物体/接触阶段划成上下文格，估计每格的**空白质量**（落在开放集空白中的概率 × 后果权重）与**覆盖度**，用「空白质量 × 任务价值」排序。这样「探索」不再是随机试错，而是**按代价-收益选择去填补哪一块空白**，并且能回答审计问题「你已经知道哪些、还差哪些、为什么先去那里」。

**灵感 3（用户共创 → 人类补的不是标签，而是「新假设的结构」）**
直觉：开放集下，系统最缺的不是更多同类数据，而是**新故障的语义与因果结构**——「这是一个之前没见过的软接触滑移」「这不是传感器坏了，是物体在渗水」。这类知识无法靠闭集标注得到，只能由人**共创**：人给一个最小演示、一个原型签名、一个作用域和一句解释，系统把它实例化为新假设 H_new，并立刻做两件事：(i) 用留出数据**证伪**这个新假设（防止人随手编一个能吸收一切的万能假设）；(ii) 检查它与旧假设的**可分离性**（防止新旧混在一起，等于没补）。因此用户共创的产物不是「标签」，而是一个**可证伪、可署名、可追溯的假设对象**。

**灵感 4（用户共创 → 风险偏好与被授权边界也必须共创，且只能收紧不能放宽）**
直觉：第 65 轮的 δ_fi、α_chunk、f_safe 都是设计者拍定的。真实部署里，「多保守算够」是用户的价值判断：产线要吞吐、家庭要安全、实验室要探索。于是让用户共创**风险不对称与探索包络**：用户可以在硬安全上限之内收紧力/速度/工作域、提高空白查询优先级、授权有限次数的「探索性接触」。但有一条不可协商：**共创只能收紧硬约束，不能放宽认证过的上限**；人类权威负责「值不值得冒险」，不负责「物理上安不安全」。

**灵感 5（三灵感合流 → CO-GAP：Co-created Open-world Gap-aware Attribution Protocol，空白共创协议）**
闭环：VISTA 的 FIR 之前加**开放集空白检测 OSH**（逐假设 conformal p 值，全部拒绝即判 gap，而非强行归因）→ **空白地图 GDM** 排序优先级 → **开放集假设检验 + 人类共创 HCP** 生成/准入 H_new → **人类可靠性 HRT** 把人当噪声证据并检测「元空白」（连人的可靠性模型都不对）→ **共签能力包络 CCE** 约束探索 → **空白感知查询分配 GQA** 在「物理探针 / 问人 / 共签探索 / 弃权」之间做决策论选择 → **临时假设隔离 PHT** 让未证伪的新假设只能收紧不能放宽 → **空白感知鲁棒包络 RSC-G/WCV-G** 在空白期用联合保守包络 → **AIC-G** 把「共创投毒/确认偏误」纳入对抗认证。第 65 轮把「接触」拆成接触前/中/后；CO-GAP 把「未知」拆成**已知的未知（低置信假设）/ 未知的未知（开放集空白）/ 关于未知的未知（人类可靠性也失效）**三层。

**灵感 6（VISTA 组件的原位升级）**
- **FIR → FIR-G**：softmax 前加开放集门；`max_H p_H < α_open` 时输出 `H_gap`，禁止定向膨胀任何已知球。
- **AFA → GQA**：探针目标从「故障假设互信息」升级为「模型结构互信息」（已知 vs 新分量 vs 人类可靠性）。
- **HCP（新增）**：人类教学信号 → H_new 原型/似然/作用域/署名人；准入需过留出证伪与可分离性双门。
- **HRT（新增）**：人类响应建噪声信道 P(z|truth,c)，可靠性在线校准；人机冲突升级为元空白。
- **CCE（新增）**：用户共签能力包络与风险预算；只能收紧硬限，探索有次数/时长/撤销。
- **PHT（新增）**：未通过证伪的临时假设进入隔离区，只允许触发「收紧」，不允许触发「几何降级/放行」。
- **RSC → RSC-G**：空白期不膨胀单个球，改用 r_all=√(Σr_i²) 的联合包络 + 共签探索包络。
- **WCV → WCV-G**：搜索域交集为空时不再回退到「最像的假设」，而是回退到联合包络并置 `open_world=True`。
- **CSP → CSP-G**：技能图节点记录覆盖度；低覆盖技能自动挂 `ask_human` / `explore_under_contract` 元技能。
- **AIC → AIC-G**：干扰集增「共创投毒」「确认偏误」「人机共因盲区」，并认证 J_cogap。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（CO-GAP 闭环）**：CO-GAP = (VISTA, OSH, GDM, HCP, HRT, CCE, GQA, PHT, RSC-G/WCV-G, CSP-G, AIC-G, J_cogap)。定位：VISTA 的「开放世界 + 人机共创」升级。不变式：**空白检测、假设共创、可靠性校准、证书构建只在语义流；实时流只做 p 值查表、包络执行、早停，零学习写操作；人类输入是带溯源的证据，不是真值。**
- **定义 234（逐假设 conformal 开放集检验 OSH）**：对每个已知假设 H∈ℋ，用其标定集定义非一致性分数 s^H(ρ)=−log p(ρ|H)，p 值 p_H(ρ)=(1+#{i:s_i^H≥s^H(ρ)})/(n_H+1)。令 novelty p 值 p_nov(ρ)=max_{H∈ℋ} p_H(ρ)，开放集门 α_open（家族错误率用 Bonferroni：α_open/|ℋ|）。**判空白 G_α={ρ:p_nov(ρ)<α_open}**；否则才允许在 ℋ 内做第 65 轮归因。注意：p_H 小是「与 H 不一致」，不是「属于别的已知 H」。
- **定义 235（空白地图与覆盖度 GDM）**：上下文格 c=(技能 σ, 物体类 o, 接触模式 m, 阶段 p)，后果权重 w(ρ,c) 来自共签风险偏好。空白质量 M(c)=∫_{ρ∈G_α} w(ρ,c) dμ_c(ρ)（用历史签名与重要性采样估），覆盖度 Cov(c)=exp(−M(c)/M_0)。研究空白优先级 Π(c)=M(c)·V(c)，V(c) 为任务价值×频次。地图按版本号写入证书，审计可查「哪些空白被已知、被谁补、还剩多少」。
- **定义 236（人类教学信号与共创假设 HCP）**：教学信号 τ=(ℓ, d, π_new, scope, E_new)：语义标签、最小演示、原型签名、作用域、探索包络。实例化 H_new=(π_new, p(ρ|H_new), scope, provenance)，p(ρ|H_new) 取原型邻域核密度或新混合分量。ℋ 用 Dirichlet 过程扩张：先验浓度 α_DP 惩罚无谓加分量，后验对分量数 K 给出 P(K+1|data)。**新假设必须同时通过三道门**（定义 238），否则只进临时隔离区 PHT。
- **定义 237（开放集结构熵）**：H_struct = H(B_known, K_new, R_human)，其中 B_known=1[p_nov≥α_open]，K_new 为后验分量数（截断到 K_max），R_human 为人类可靠性模型是否可信。它度量「该信闭集归因、信新分量、还是先修可靠性模型」，严格比第 65 轮的故障后验熵大一层。
- **定义 238（共创假设准入：可分离 + 可证伪 + 安全）**：H_new 准入 ⇔ (i) **可分离**：与每个旧 H 的签名分布分离度 D_sep(H_new,H)≥κ_sep（如对称 KL 或核 MMD）；(ii) **可证伪**：在独立于教学集的留出集上，含 H_new 的混合模型对数似然增益 Δℓ≥log(1/β)；(iii) **安全**：其验证只能在共签包络 E_new 内、有限次数、可撤销。未过门者置 `provisional=True`，**不得用于降低几何球或放行**（PHT）。
- **定义 239（人类可靠性 HRT 与元空白）**：人类响应 z 经噪声信道 P(z|y,c) 生成，y 为真实故障类别；用共创假设后续被证实/证伪的结果在线估计混淆矩阵与信任 w_h(c)。人类证据只进入似然，不覆盖硬安全约束。若多次人机冲突且后验指向「可靠性模型本身失效」，输出 `meta_gap=True`：暂停用人类输入更新假设集，转入保守包络与离线复核。
- **定义 240（共签能力包络 CCE）**：E=(f_max, v_max, workspace, T_exp, stop_distance, n_trials)，硬上限 f_hard、v_hard 由认证给出。用户可设 f_max≤f_hard、收紧工作域、提高空白查询预算；**不可反向放宽硬上限**。探索合同有到期、撤销与双签（用户意图 + 系统可执行性）。审计记录 authority_sig 与责任边界。
- **定义 241（空白感知决策 GQA）**：候选动作 A={probe_known, query_human, explore_new, abstain}。选择 a*=argmin_a { E_{ρ'}[risk(a,ρ')] + λ_h·cost_h(a) + λ_e·cost_e(a) − λ_I·I_struct(a) }，s.t. 预测力/形变在 CCE 内。人类查询的价值用「结构熵下降 / 人类成本」计量；易损物体只允许 query_human/visual_probe/null_test。
- **定义 242（临时假设隔离 PHT）**：provisional 假设可参与**收紧**（增大包络、降低速度、提高 α）但不可参与**放行/降级**；其证据权重乘以 w_prov<1；一旦留出证伪通过转正，失败则永久黑名单并回填 HRT。
- **定义 243（空白感知鲁棒包络 RSC-G/WCV-G）**：空白期令 r_all=√(r_geo²+r_force²+r_model²+r_gap²)，其中 r_gap 由开放集空白质量与共签探索包络导出；WCV-G 搜索域为 B(φ̂,r_all)∩𝒢∩K∩ℱ∩𝒱∩E，交集为空时回退 B(φ̂,r_all) 并置 `open_world=True`，**不再回退到「最像的已知假设」**。
- **定义 244（技能覆盖 CSP-G）**：技能图节点带 Cov(σ)；Cov(σ)<τ_cov 的块边必须挂 `ask_human`/`explore_under_contract` 元技能或显式标注 `known_gap`；未标注的已知空白不得进入自动执行路径。
- **定义 245（共创对抗认证 AIC-G）**：干扰集 ℰ_G=ℰ_V×ℰ_co，ℰ_co 含「共创投毒」（人故意教错/教一个能吸收一切的假设）、「确认偏误」（人只补符合自己预期的空白）、「人机共因盲区」（人和视觉共享同一训练分布偏差）。认证要求：共创投毒下坏假设不得转正；共因盲区下必须能判 meta_gap/ambiguous 并保守降级；J_dir 增 co_creation_ver、human_reliability_ver、envelope_ver。
- **定义 246（CO-GAP 证书 J_cogap）**：J_cogap=(J_vista, p_nov, gap_mass, gap_map_ver, hypothesis_lineage, human_reliability, envelope_hash, authority_sig, provisional_flags, meta_gap, aic_g_ver)。Valid ⇔ Valid(J_vista) ∧ (p_nov≥α_open ∨ 已判 gap 且用联合包络 ∨ 有共签探索包络) ∧ 无 provisional 假设参与放行/降级 ∧ 人类输入有溯源与可靠性记录 ∧ 硬限未被放宽 ∧ 实时流无共创写操作。
- **定义 247（共签探索合同）**：C=(E, purpose, n_trials, expiry, abort_condition, co_sign)。执行中任一步预测越界立即中止；到期未转正则自动失效并把结果写回空白地图（成功/失败都减少该格不确定性）。
- **定义 248（CO-GAP 闭环算子）**：语义流 [VISTA 语义链→OSH 开放集检验→GDM 空白地图→若 gap:HCP 共创/GQA 决策→HRT 可靠性→CCE 共签→AIC-G 认证→J_cogap]；实时流 [锚点读→p 值查表→包络执行→早停→J_cogap 构建]。

## 2. 关键算法骨架

```python
# OSH + FIR-G：先问「有没有假设覆盖这里」，再问「是哪一个」
pvals = {H: conformal_pvalue(H, rho) for H in H}          # 查表，O(|H|)
p_nov = max(pvals.values())
if p_nov < alpha_open:                                     # 开放集空白，不是 ambiguous
    gap = locate_gap(rho)                                  # 更新 GDM
    a = gqa.choose(post=None, gap=gap, envelope=CCE)       # 探针/问人/共签探索/弃权
else:
    post, h_star, ambiguous = fir_g.attribute(rho)         # 第 65 轮闭集归因，仅在已知域内

# HCP：人类共创一个可证伪的新假设
tau = human. teach(gap_context)                            # 标签+演示+原型+作用域+包络
H_new = Hypotheses.from_teaching(tau)
if separation(H_new, H) >= kappa_sep and heldout_gain(H_new, D_holdout) >= log(1/beta):
    H = H + [H_new]; H_new.provisional = False             # 转正，进入后续归因
else:
    PHT.quarantine(H_new)                                  # 只收紧，不放行

# GQA：结构熵 + 决策论
a_star = argmin_a E[risk(a)] + lam_h*cost_h(a) + lam_e*cost_e(a) - lam_I*I_struct(a)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（开放集误报控制）**：在逐假设可交换性下，对已知 H 的样本 P(p_H≤α)≤α；Bonferroni 后 P(把已知误判为 gap)≤α_open。更关键的是**结构性**：p_nov<α_open 时算法不输出任何已知 H，从机制上消灭第 65 轮「强行归入最近假设」的错误模式；代价是对「伪装成已知的未知」仍可能漏检（功效问题，诚实标注为开放风险）。
- **引理 10（共创假设准入的证伪保证）**：H_new 在独立留出集上需获得 Δℓ≥log(1/β) 的增益，故在「旧模型为真」的原假设下误纳概率≤β；再加分离门 D_sep≥κ_sep，使 H_new 不能退化为吸收一切的万能分量。故共创不是「人说了算」，而是「人提出、数据证伪、证书署名」。
- **定理 9（空白期安全）**：判 gap 后系统不使用任何已知假设专属的几何降级/放行，只走联合包络或共签探索；故未知复合故障不可能被静默塞进某个已知球。单块越界概率 ≤ α_chunk+δ_fi+α_vis+α_open+β+α_co。
- **定理 10（共创的覆盖改进）**：若人类查询响应优于随机（可靠性 >0.5）、空白质量函数关于查询集自适应次模，则贪心 GQA 的期望空白质量下降 ≥(1−1/e) 最优；每单位人类成本的结构熵下降单调。该定理**有条件**：它不保证发现人类也想不出的空白。
- **实时性**：OSH 只是每假设一次分位数查表（<0.1ms），GDM/HCP/HRT/AIC-G 全在语义流；实时路径新增 ≤0.1ms，总预算仍 ≤2.6ms。

**定义 233（CO-GAP 闭环）** CO-GAP 是 VISTA 的「开放世界 + 人机共创」升级：在 VISTA 的语义流/实时流骨架上挂载 OSH（开放集检验）、GDM（空白地图）、HCP（人类共创）、HRT（人类可靠性）、CCE（共签包络）、GQA（空白感知查询），并原位升级 RSC-V→RSC-G、WCV-V→WCV-G、CSP-V→CSP-G、AIC-V→AIC-G、J_vista→J_cogap，新增 PHT（临时假设隔离）。不变式：**空白检测、假设共创、可靠性校准、证书构建只在语义流；实时流只做 p 值查表、包络执行、早停与派发，零学习写操作；人类输入是带溯源的证据，不是真值。**

**定义 234（逐假设 conformal 开放集检验 OSH）** 对每个 H∈ℋ，标定集 D_H={ρ_i}，非一致性分数 s^H(ρ)=−log p(ρ|H)。测试样本 ρ 的 p 值
p_H(ρ)=(1+Σ_{i=1}^{n_H} 1[s_i^H ≥ s^H(ρ)])/(n_H+1)。
在 D_H 与测试样本关于 H 可交换时，P(p_H≤α)≤α。取 p_nov(ρ)=max_{H∈ℋ}p_H(ρ)，家族错误率控制在 α_open 时使用 α_open/|ℋ|。判据：
- `p_nov ≥ α_open`：**在已知域内**，交由第 65 轮 FIR-G 做闭集归因；
- `p_nov < α_open`：**开放集空白 H_gap**，不输出任何已知假设，进入 GDM/GQA。
关键语义：p_H 小意味着「与 H 不一致」，**不意味着「更属于另一个 H」**；后者正是第 65 轮 softmax 的结构性错误。OSH 只负责「有没有覆盖」，不负责「是哪一个」。

**定义 235（空白地图与覆盖度 GDM）** 把运行上下文划分为格 c=(σ,o,m,p)，σ 技能、o 物体类、m 接触模式、p 阶段。用历史签名与重要性采样估计
M(c)=∫_{ρ∈G_α} w(ρ,c) dμ_c(ρ)，Cov(c)=exp(−M(c)/M_0)，Π(c)=M(c)·V(c)，
其中 w(ρ,c) 为共签风险偏好诱导的后果权重（如力超限、滑移、任务失败），V(c) 为任务价值×频次。地图维护版本号 `gap_map_ver` 与每格样本量；样本不足的格标 `unknown_unknown_risk=True`，不得被当作低空白。**研究空白在此被操作化为「高 M、高 V、低样本」的格**，从而可排序、可审计、可追踪填补进度。

**定义 236（人类教学信号与共创假设 HCP）** 教学信号 τ=(ℓ,d,π_new,scope,E_new)：语义标签 ℓ、最小演示 d、原型签名 π_new（签名空间中的典型点/协方差）、作用域 scope（该假设适用的技能/物体/阶段）、探索包络 E_new。系统实例化

## 3. 关键算法伪代码

### IP-224 OSH（开放集门）

```python
class OpenSetGate:
    """逐假设 conformal p 值；只回答『有没有假设覆盖』，不回答『是哪一个』。"""
    def __init__(self, calib_scores, alpha_open=0.05):
        self.s = calib_scores                 # {H: sorted s_i^H}
        self.alpha = alpha_open

    def pvalue(self, H, rho):
        s = -np.log(self.lik[H](rho) + 1e-12)
        arr = self.s[H]
        return (1 + np.sum(arr >= s)) / (len(arr) + 1)

    def gate(self, rho):
        alpha_b = self.alpha / len(self.s)    # Bonferroni，家族错误率
        p = {H: self.pvalue(H, rho) for H in self.s}
        p_nov = max(p.values())
        return p_nov, (p_nov < alpha_b)      # True => H_gap，禁止闭集归因
```

### IP-225 GDM（空白地图）

```python
class GapMap:
    def __init__(self, n_cells, M0=1.0, tau_cov=0.6):
        self.M = np.zeros(n_cells)
        self.n = np.zeros(n_cells)
        self.V = np.zeros(n_cells)
        self.M0, self.tau_cov = M0, tau_cov

    def update(self, cell, rho, is_gap, w_consequence):
        self.n[cell] += 1
        if is_gap:
            self.M[cell] += w_consequence
        self.M[cell] *= (1 - 1.0 / max(self.n[cell], 1))   # EMA，抗漂移

    def coverage(self, cell):
        return float(np.exp(-self.M[cell] / self.M0))

    def priority(self, cell):
        return float(self.M[cell] * self.V[cell] / (1 + self.n[cell]))

    def insufficient(self, cell, n_min=30):
        return self.n[cell] < n_min                  # 标 unknown_unknown_risk
```

```python
class CoCreationProtocol:

                          provisional=True)

    def admissibility(self, H_new, H_old, D_holdout):
        sep = min(sym_kl(H_new.kdes, H.kdes) for H in H_old)
        gain = loglik_mixture(H_old + [H_new], D_holdout) - loglik_mixture(H_old, D_holdout)
        return {'separable': sep >= self.kappa_sep,
                'falsified_ok': gain >= np.log(1.0 / self.beta),   # 拒绝旧模型
                'sep': sep, 'gain': gain}

    def admit(self, H_new, H_old, D_holdout, envelope_ok):
        r = self.admissibility(H_new, H_old, D_holdout)
        if r['separable'] and r['falsified_ok'] and envelope_ok:
            H_new.provisional = False
            return 'admitted'
        return 'quarantined'                # PHT：只收紧，不放行
```

### IP-227 HRT（人类可靠性）

```python
class HumanReliability:
    def __init__(self, floor=0.5):
        self.conf = defaultdict(lambda: np.eye(2))   # P(z|y,c) 计数
        self.floor = floor

    def likelihood(self, z, y, c):
        return self.conf[c][y, z] / max(self.conf[c][y].sum(), 1)

    def update(self, c, y, z):
        self.conf[c][y, z] += 1

    def trust(self, c):
        P = self.conf[c] / np.maximum(self.conf[c].sum(1, keepdims=True), 1)
        return float(np.trace(P) / 2.0)              # 平均对角准确率

    def meta_gap(self, conflicts, n):
        return conflicts >= max(3, 0.3 * n) and self.trust  # 连接触发：可靠性模型本身失效
```

### IP-229 GQA（空白感知查询分配）

```python
class GapAwareQuery:
    ACTIONS = ('probe_known', 'query_human', 'explore_new', 'abstain')

    def choose(self, p_nov, post, gap_cell, envelope, fragile, budget):
        best, best_val = 'abstain', -np.inf
        for a in self.ACTIONS:
            if not envelope.permits(a):
                continue
            if fragile and a == 'explore_new':
                continue
            risk = expected_risk(a, post, gap_cell)
            cost = self.lam_h * human_cost(a, budget) + self.lam_e * explore_cost(a)
            info = self.lam_I * expected_struct_info_gain(a, p_nov, post)
            val = info - risk - cost
            if val > best_val:
                best, best_val = a, val
        return best, best_val
```

## 4. 推导

**引理 9（开放集误报控制与「禁止强行归因」）**
对固定 H，若标定样本与测试样本关于 H 可交换，则 conformal p 值满足 P(p_H(ρ)≤α)≤α。取 p_nov=max_H p_H 并对 |ℋ| 个假设做 Bonferroni，令门限 α_open/|ℋ|，则对真实来自某已知 H 的样本
P(p_nov<α_open/|ℋ|) ≤ α_open。
更重要的是**结构性保证**：算法在 p_nov<α_open 时不输出任何已知 H，因此第 65 轮「softmax 必然选一个最近假设」这一错误模式在机制上被消除。反向保证不成立：若未知故障在签名上恰好落在某个已知 H 的支持域内，p_nov 会偏大而漏检——这是开放集的功效限制，必须在实验 E241/E249 中诚实度量。∎

**引理 10（共创假设准入的证伪保证）**
设 D_holdout 独立于教学集 D_teach，原假设「旧混合模型已足够」为真。准入要求 Δℓ_holdout≥log(1/β)，这是单边似然比检验在水平 β 下的拒绝域；由 Markov/似然比不等式，误纳概率 ≤β。再加分离门 D_sep≥κ_sep：若 H_new 与旧假设的签名分布不可分，则其增益主要来自过拟合而非新结构，分离门把这类「万能吸收分量」挡在门外。故「人提出假设」不会自动变成「人定义真值」；H_new 必须同时被数据证实、被分离性约束、被共签包络限制。∎

**定理 9（空白期安全）**
在 A94–A99 下，若 OSH 判 gap，则系统：
1. 不执行任何「已知假设专属」的几何降级/放行（定义 234/243），故未知复合故障不可能被静默塞进某个已知球；
2. 只走 r_all 联合包络或共签探索合同（定义 240/247），探索的力/形变/工作域被 CCE 与硬上限双重约束；
3. provisional 假设只能收紧不能放行（定义 242）。
由联合界，单块执行 k* 步内发生越界（力/滑移/几何）的概率
P[越界] ≤ α_chunk + δ_fi + α_vis + α_open + β + α_co，
其中 α_co 为共签包络的执行/撤销失效概率。由于 k*≤m（沿用第 65 轮不可逆视界），即使空白故障在块首激活，检出或强制重规划仍发生在越过不可逆点之前。∎

**定理 10（共创的覆盖改进，条件性）**
把空白质量下降视为集合函数 f(S)=M(∪_{c∈S}covered(c))，查询选择在自适应观测下若满足自适应次模性，则贪心 GQA 的期望下降满足
E[f(S_greedy)] ≥ (1−1/e)·max_{|S|≤B} E[f(S)]。
人类查询的期望结构信息增益须为正，即人类可靠性高于随机（trust>0.5，定义 239）；若 trust≤0.5，HRT 将人类证据权重压到 0 并把动作切到 explore_new/abstain，此时定理退化为「无人类时的保守探索」界。**该定理不保证发现人类也想不出的空白**——这是本轮风险的数学位置。∎

**命题（从「闭集后验」到「开放集结构」的严格细化）**
第 65 轮的 FIR 后验 P(H|ρ) 定义在固定有限 ℋ 上，满足 Σ_H P(H|ρ)=1，因此永远无法表达「以上都不是」。CO-GAP 的判决空间是 {H_1,…,H_|ℋ|, H_gap}，且当 p_nov<α_open 时已知分量概率被强制置 0。故第 65 轮的归因是 CO-GAP 在 B_known=1 时的条件子问题；两者不是替代关系，而是「开放集外壳 ⊃ 闭集内核」。∎

## 7. 已知风险

**一句话**：CO-GAP 把「未知」的可见性托付给人类共创，但人只能补自己想象得到的空白——当用户与机器人共享同一训练分布、同一激励或同一确认偏误时，空白地图会退化为「人类已知边界的地图」，真正的未知之未知依旧不可见；更危险的是「已共创、已共签」会给出一张看似完备的证书，而数据依赖地扩张假设集还破坏了 conformal 的可交换性，使 α_open 的误报控制在最需要它的分布漂移下恰好失效。

**次级风险与缓解**：
1. **人类共创的确认偏误**：用户倾向补符合自身预期的空白；缓解：HCP 强制留出证伪 + 分离门 + 主动要求反例教学；AIC-G 显式建确认偏误干扰。
2. **共创投毒 / 恶意用户**：教一个吸收一切的坏假设；缓解：分离门 D_sep≥κ_sep + 留出增益检验 + provisional 隔离 + 双签；坏假设永远拿不到放行权。
3. **数据依赖假设集破坏 conformal**：ℋ 随共创扩张，标定集与测试集不再可交换；缓解：每轮扩张后用独立留出集重标定、记录 `calib_ver`；在重标定完成前 OSH 只收紧不放行。
4. **新颖性洪水 / 新颖性盲区**：分布漂移使一切看起来新（洪水）或一切看起来旧（盲区）；缓解：E249 漂移检测、分上下文 α_open、地图样本量门限、meta_gap。
5. **人类可靠性模型本身失准**：人与系统共因盲区；缓解：引入物理独立通道（IMU/本体感觉）作为第三方证据，冲突即 meta_gap；离线复核。
6. **空白地图维度灾难**：上下文格过细导致样本稀疏；缓解：层级格（技能→物体→阶段）自适应分裂，样本不足格标 unknown_unknown_risk。
7. **共签包络被误用为「免责声明」**：用户签了字系统就放松；缓解：硬限不可放宽、合同到期/撤销、审计责任边界、认证要求 envelope_ver 与 authority_sig。
8. **实时预算**：OSH 查表 + 包络判定逼近 2.6ms；缓解：预计算分位数、|ℋ| 上限与分层标定、把 GDM/HCP/AIC-G 全部留在语义流。
