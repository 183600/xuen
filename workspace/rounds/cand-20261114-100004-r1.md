# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「社会影响」×「姿态估计」）

> R69 把不确定性一分为二，并让系统学会「问」。但它有一个未经审视的前提：**被问的人是一个外生 oracle**——回答的分布 p(y｜g,o) 只取决于问题和观测，不取决于「我」之前做过什么，也不取决于「我」站在他面前这件事本身。真实的人不是 oracle，而是一个**社会响应者**：我凑近、注视、发问、等待的方式，会改变他的舒适、信任与表达，进而改变他的回答与身体姿态。于是 R69 的 VoI 是在一个被自己搅动的池子里测水位。
>
> 更尖锐地说：**R69 的观测通道里混进了机器人自己的行动。** 它读到的「犹豫」「抵触」「同意」，可能不是人的意图，而是**它自己造成的反应**。这就是本轮要处理的**反身性混淆（reflexive confound）**：观测者进入了被观测的系统。
>
> 本轮两个灵感正好构成一对：
> - **姿态估计**给出连续、非言语、半不自觉的社会通道——它比一句回答更「漏」，也因此更能揭示真实状态；但它同时是最**易被机器人行为调制**的通道（被注视会僵、被逼近会退、放松会倾身）。
> - **社会影响**给出回路本身——存在、注视、距离、语气、时机如何改变他者；它既是**信息源**，也是**动作**，既可增进坦诚，也可沦为操纵。
>
> 核心命题：**把人建模为「响应函数」而非 oracle；用姿态的前/后差分做因果去混杂，把「人的意图」从「机器人造成的影响」里分离出来；允许「影响类动作」（建立 rapport、降级紧张、调整站位）作为有预算的信息动作，但用「非操纵约束」锁死它只能提高表达保真度、不能改变真实偏好；并对人-机社会回路做稳定性控制，防止「我紧张→他更紧张→我更紧张」的升级。** 命名 **MIRROR-RAS**（Mutual-Influence-aware Reflexive Representation Of Responsive humans）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我问出去的话，有没有改变我要问的那个答案？**」——不确定性不只是刹车或提问，还可能是**我自己在对方身上留下的回声**。

## 0. 直觉与动机

**灵感 1（姿态估计 → 一条「漏得更多」的社会通道）**
直觉：语言回答是一次**低带宽、高审查**的采样——人有时间组织、修饰、撒谎。姿态是**高带宽、低审查**的：重心偏移、肩膀收紧、脚尖朝向、头部朝向与注视、手的自我触碰、倾身/后仰。这些半不自觉的信号更接近真实状态，因此对意图、压力、注意、参与度有独立信息量。直觉的严谨版本是：姿态流 Φ_t 是对社会潜状态 h_t 的**冗余观测**，在给定 h_t 时与语言回答条件独立——这正是它作为「第二意见」的价值（与 R69 的 FMA 对偶通道同构）。
但姿态不是免费的真值：它同时是**反应的产物**。人知道自己被看着，就会改变姿态。所以姿态是**信号 + 人造物**的叠加，必须被拆开。

**灵感 2（社会影响 → 观测会反作用，VoI 的独立性假设失效）**
直觉：你盯着一个人问「你是不是不想让我过去」，他后退半步——这半步是他本来就想退，还是被你的逼近逼出来的？R69 的 VoI 假设 y ⟂ g｜o（回答只是被问题「条件化」，不是被问题「制造」）。社会影响让这个假设系统性为假：u（注视/距离/语气/框架）→ h（舒适/信任）→ y（回答与姿态）。更隐蔽的是**自我实现预言**：机器人因不确定而频繁发问、贴身注视，把对方弄紧张，读到紧张，于是更不确定、更频繁发问。**不确定性被机器人的安抚行为放大了。**
严谨版本：观测方程里必须出现 u，即 y = O(h, u, ε)，而 R69 用的是 y = O(h, ε)。当 ∂O/∂u ≠ 0 时，朴素后验 p(M｜y) 的偏差正比于这个敏感度乘以 u 的幅度（引理 19）。

**灵感 3（姿态的因果用法 → 用「前处理姿态」当负对照）**
直觉：如果想扣除「我造成的影响」，最干净的办法是比较**我行动之前**和**行动之后**的同一个人：行动前的姿态没被我这次行动污染（假设他不能预知），是 h 的干净代理；行动后的变化量 ΔΦ 才是我这次影响 + 他真实状态演化的混合。再用「未被影响的基线姿态」校准「被影响后的读数」，就能把社会影响从意图估计里扣掉。这在因果推断里就是**前处理协变量 / 负对照暴露（negative control exposure）**：利用时间先后制造一个「不可能被处理影响」的参照。
严谨版本：在无预期（A99）下，Φ_before ⟂ u_t，故可作为 h_t 的代理进入后门调整；ΔΦ = Φ_after − Φ_before 中可分离出「影响响应」与「状态漂移」两部分（引理 20）。

**灵感 4（社会影响是动作 → 既能帮忙，也能作恶）**
直觉：既然机器人能影响人，它就可以**主动用影响来降低自己的不确定**：放慢语速、降低注视强度、后退到舒适距离、先共情再提问——这些不是操纵，而是让对方**更愿意如实表达**。这就是「影响类信息动作」。但同一种能力也能用来诱导：用权威感、紧迫感、情感压力让人说「是」。二者的分界不在「有没有影响」，而在**影响走的通道**：只允许经过「表达保真度」的通道（u→h→y，让人把真实 M 说出来），禁止经过「偏好本身」的通道（u→M 而不经证据）。严谨版本即中介分解：约束自然直接效应 NDE(u→M) ≤ δ_manip，只放行经由证据的中介效应 NIE（定理 18）。

**灵感 5（社会回路会振荡 → 需要回路增益与阻尼）**
直觉：人在被观察时会调整，机器人又在读这个调整后的人——这是一个闭环。若机器人「一不确定就靠近发问」，人「一被靠近就紧张」，机器人「一读到紧张就更不确定」，闭环增益可能 > 1，社会互动发散为对抗。需要像控制回路一样定义**社会回路增益**并在增益过大时插入「社会解耦动作」（撤回注视、后退、暂停、交还控制权）。这把 R69 的 λ 从「对测量不确定的刹车」升级为「对社会回路稳定性的阻尼」。

**灵感 6（对 R69 的姿态 → 严格包含，而非另起炉灶）**
直觉：当人完全不被影响（∂O/∂u = 0）且不使用姿态通道时，MIRROR 必须逐指令退化为 FLUID-RAS。这是本系列一贯的理论纪律：新层是旧层的**严格泛化**，安全侧永不让步；R70 增加的是「不把回声误当意图」的能力与「影响不越界」的伦理约束，而不是另一套需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（MIRROR-RAS 总览）** MIRROR-RAS = (PSE, SCM-R, DCD, IIA, NMC, SLG, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **影响预算与非操纵约束**：影响类动作受频率/幅度/知情同意约束，且其对社会偏好 M 的自然直接效应 ≤ δ_manip（定义 316、318）；
(iii) **反身性审计**：任何对社会信号的推断都必须同时报告「可归因于机器人自身行动的信号占比」ρ_infl，ρ_infl 不可解释则不采纳该信号（定义 324）。

**定义 311（姿态社会通道 PSE）** 姿态估计器 h_ψ 将 RGB-D / LiDAR / IMU 映射为带不确定性的身体参数分布：SMPL-X 体型/手势/面部 + 头姿与注视 + 骨架关节 + 近身距离。派生社会特征 f_soc = (attention, stress, engagement, approach/avoid, rapport)，每个特征带 aleatoric 与 epistemic 分量。观测记为 y_pose ~ q_ψ(·｜sensor)，与语言回答 y_ans 并列构成证据集 ℰ_social。

**定义 312（社会潜状态与响应模型 SCM-R）** 社会潜状态 h_t = (trust, comfort, arousal, M)，其中 M 为真实意图/偏好（准静态，A104）。机器人社会动作 u_t ⊂ 𝒜_soc（注视强度、站位距离、姿态朝向、语速、问句框架、等待时长）。反身 POMDP 的结构方程：
H_{t+1} = T(H_t, U_t, M, ε_H)，Y_pose,t = O_p(H_t, U_t, ε_p)，Y_ans,t = O_a(H_t, U_t, M, ε_a)，U_t = π(·｜bel(M), history)。
关键：**观测方程中出现 U_t**——这是与 R69 的 oracle 模型唯一但致命的差别。

**定义 313（反身混淆与影响敏感度）** 影响敏感度 I_u := ∂E[Y｜h,u]/∂u（姿态与回答两条通道分别记 I_u^p、I_u^a）。若 I_u ≠ 0，则 R69 的条件独立性 y ⟂ u｜o 失效，朴素后验 p(M｜y) 相对干预后验 p(M｜do(u), y) 的偏差随 ‖I_u‖·‖u‖ 增大。把机器人自身行动在观测中可解释的方差占比记为 ρ_infl ∈ [0,1]（定义 324）。

**定义 314（姿态因果去混杂器 DCD）** 依据前处理姿态 Φ_before（在 u_t 施加前测得）做负对照与后门调整（A99–A100）：
ĥ_t^base = E_DCD[h_t ｜ Φ_before, history]，ΔΦ_t = Φ_after − Φ_before，
社会影响响应 r̂_infl = Ĝ·(u_t − u_ref)（Ĝ 为在 SCM-R 下拟合的响应矩阵），
去混杂后的意图证据 ỹ_pose = φ(Φ_before) + (ΔΦ_t − r̂_infl)。
可辨识性依赖 A99（无预期）与 A100（在给定历史/前处理姿态下无未观测混杂）。

**定义 315（影响感知信息动作与反事实 VoI，IIA）** 增广信息动作集 𝒜_info† = 𝒜_info × 𝒜_soc。对社会动作 u 采用**干预式**（do-算子）信息增益：
VoI†(g) = H(M｜o, do(u)) − E_{y~p(·｜do(u),o)}[H(M｜o,y,do(u))]，
选择 argmax[VoI† − c(g) − c_soc(u)]，并额外约束非操纵（定义 316）与社会回路稳定（定义 319）。度量「若我不施加影响」的反事实：VoI_null(g) 用 u = u_ref（中性站位/中性注视）。只有 ΔVoI = VoI† − VoI_null 才是影响动作的净贡献。

**定义 316（非操纵约束 NMC）** 对 u→M 的因果效应做中介分解：总效应 TE = NDE + NIE，其中 NIE 经「证据通道 E」（机器人提供的信息/澄清）中介。约束：
NDE(u→M 不经 E) ≤ δ_manip，且 KL(p(M｜do(u)) ‖ p(M｜do(u_ref))) ≤ δ_shift。
直觉：影响可以让人**更愿意说真话**（提高表达保真度，走 H→Y 通道），不可以让人**改主意**（不经证据地改变 M）。利用权威/紧迫/情感压力绕过证据的通道被判为操纵并拒绝。

**定义 317（姿态不确定性与遮挡门控）** 姿态估计的 aleatoric（遮挡、运动模糊）与 epistemic（罕见姿态、个体体型外推）分量继承 R69 定义 297 的二分。以可靠图与 ECE 校准姿态通道权重 w_pose；当遮挡率 > τ_occ 或语义 OOD 分 > τ_sem 时，w_pose→0，信号不采纳，退回仅用语言证据（R69）。**不允许用不可信的姿态驱动社会推断。**

**定义 318（影响预算与同意治理器 IBG-S）** 单位时间影响动作 ≤ 1 次；注视强度/接近距离在个体舒适包络内；累计影响剂量 D_infl 有上限；需要「知情同意」态（显式或可靠推断，且可随时撤回）；任何隐瞒式影响（covert influence）直接判违规。超预算 ⇒ 影响动作作废，社会不确定性视为未消解。

**定义 319（社会回路增益与稳定化 SLG）** 对人-机闭环做局部线性化，回路增益 G_loop = ‖∂Y/∂U‖·‖∂U/∂bel‖·‖∂bel/∂Y‖。若谱半径 ρ(G_loop) < 1 且控制器关于感知不确定单调，则闭环稳定（定理 19）。若 ρ ≥ 1，插入**社会解耦动作** u_dec（撤回注视/后退/暂停/交还控制权）降低增益，或降低 R69 的 λ 上限，直到 ρ·λ < 1。防止「紧张—追问—更紧张」的正反馈。

**定义 320（姿态接地的模态先验 PGP）** 把 f_soc 映射为 R69 流策略模态 {m_k} 的先验：p_prior(m_k) ∝ ŵ_k · exp(⟨θ_m, f_soc⟩)。姿态用于**预选/排序**模态，但只在与去混杂后的语言证据一致、或满足 R69 定义 293-iii 的证据纪律时，才用于**定案**；否则仅改变采样预算分配（省算力/省交互），不改变最终决策。

**定义 321（反事实姿态估计 CFP，「若我不问」）** 定义反事实读数 Φ^{cf} = O_p(h_t, u_ref, ·)，估计「在以中性方式不打扰他时，他会呈现什么姿态」。因为无法在运行时观测反事实（A104 只能保证 M 准静态、不能保证反事实可验证），CFP 只作为**受约束的敏感性检查**：当直接读数与反事实读数差异过大（即当前读数主要是我的影响造成）时，**暂停社会推断**而非强行校正。这是对「反事实不可验证」的工程妥协。

**定义 322（个体/文化标定与语义 OOD，PCC）** 姿态语义（点头、交叉手臂、注视回避、近身距离）跨个体/文化差异大。用少量交互做 per-person 标定（校准社会特征基线），并做语义分布外检测：若当前姿态语义超出该个体/文化的标定支撑集，则姿态通道标注「语义未接地」，不得单独作为证据。**姿态不是普世语言。**

**定义 323（延迟影响与信用分配 DIC）** 社会影响有长尾：一次冒犯性接近可能使信任在数分钟后才下降。以带衰减的影响核 κ(Δt) 归因延迟效应，把「当前不确定」与「历史上的影响动作」做时序信用分配；避免把「过去的我」造成的紧张误记成「现在的他」的意图。

**定义 324（反身性证书 J_MIRROR）** J_MIRROR = (J_FLUID, pose_calibration_ece, rho_infl, delta_voi, nde_manip, loop_gain, consent_state, influence_dose, social_log_hash, mirror_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_pose ≤ τ_pose ∧ NDE ≤ δ_manip ∧ consent_state ∈ {granted} ∧ 影响剂量未越界 ∧ ρ_infl 可解释。**ρ_infl 不可解释（去混杂失败）⇒ 证书无效，退回 R69 纯 FLUID（不看姿态、不施加影响）。**

**定义 325（两级保守退避，包含 R69）** 若去混杂可信且社会信号在预算内降低 U_epi：λ = λ_floor(U_ale)（resolution bonus）；若去混杂失败/ECE_pose 越界/语义未接地/NDE 越界/回路不稳：λ = λ_floor(U_ale + U_epi)，并关闭姿态与社会影响通道，逐指令退化为 R69。安全侧永不弱于 R69。

**定义 326（社会干扰对抗集 ℰ_social）** 并入 AIC-FLUID：ℰ_social = { 表演性姿态（伪装紧张/伪装同意）、共谋式社会信号（表情+语气+姿态协同欺骗）、以「舒适/信任」为诱饵的社交工程、利用机器人注视诱发危险动作、姿态估计对抗补丁、隐私刺探（诱导机器人过度解读）}。ℰ_MIRROR = ℰ_FLUID × ℰ_social。

**定义 327（MIRROR-RAS 主闭环）** 在 R69 主环上插入四步：① 姿态估计与社会特征（带校准与遮挡门控）；② DCD 去混杂并估计 ρ_infl；③ 影响感知 VoI†（含非操纵与预算约束）；④ 社会回路稳定化；随后回到 R69 的「交互/保守 → 似然第二意见 → 证据纪律 → 风险缩放」。

# IP-264 PSE：姿态社会估计（带 aleatoric/epistemic 与遮挡门控）
class PoseSocialEstimator:
    def __init__(self, pose_net, social_head, calib):
        self.pose, self.soc, self.calib = pose_net, social_head, calib
    def observe(self, sensor):
        pose, unc = self.pose(sensor)                 # SMPL-X + 关节 + 注视
        feats = self.soc(pose)                        # attention/stress/...
        w = self.calib.reliability(unc, occlusion=unc.occ)
        if unc.occ > TAU_OCC or unc.sem_ood > TAU_SEM: w = 0.0
        return PoseObs(pose, feats, unc, w)

# IP-266 DCD：用前处理姿态做负对照，扣掉「我造成的影响」
def deconfound(pose_before, pose_after, u_t, scm):
    h_base = scm.posterior_h(pose_before)             # 干净代理（A99）
    delta  = pose_after.as_vec() - pose_before.as_vec()
    r_infl = scm.response(u_t - scm.u_ref)            # G_hat (u - u_ref)
    y_tilde = pose_before.as_vec() + (delta - r_infl) # 去混杂后的姿态证据
    rho_infl = explained_var(r_infl, delta)           # 可归因于我自己的占比
    return y_tilde, rho_infl

# IP-267 IIA：影响感知的反事实 VoI（do-算子 + 中性参照 u_ref）
def choose_info_action(modes, w, o, budget, scm):
    best = None
    for g in info_action_candidates(modes):           # R69: gaze/probe/ask
        for u in social_candidates(o):                # 影响类：rapport/解耦/退让
            if not budget.allow(g, u): continue
            if not c_ras_wm.certify_info(g, o): continue
            if not non_manipulation_ok(scm, u): continue     # IP-268
            voi     = do_voi(modes, w, g, u, scm)
            voi_ref = do_voi(modes, w, g, scm.u_ref, scm)
            score   = (voi - voi_ref) - cost(g) - social_cost(u)
            if best is None or score > best.score: best = (g, u, score)
    return best if best and best.score > 0 else None

# IP-268 NMC：中介分解，禁止「不经证据地改变偏好」
def non_manipulation_ok(scm, u):
    te = scm.total_effect(u, target='M')
    nie = scm.natural_indirect_effect(u, mediator='E')   # 经证据的通道
    nde = te - nie
    shift = kl(scm.posterior_M(do=u), scm.posterior_M(do=scm.u_ref))
    return (nde <= DELTA_MANIP) and (shift <= DELTA_SHIFT)

# IP-269 SLG：社会回路稳定性与解耦动作
def stabilize(lam, scm, history):
    G = scm.loop_gain(history)                        # rho(G_loop)
    if max(abs(eigvals(G))) * lam < 1.0:
        return lam, None
    return lam, 'decouple'                            # 撤回注视/后退/暂停

# IP-278 主闭环（继承 R69，在「观测—决策」之间插入反身层）
def MIRROR_RAS_round(M, obs):

    po = M.pse.observe(obs.sensor)                                   # 姿态通道
    y_t, rho = M.dcd.deconfound(M.pose_prev, po, M.last_u, M.scm)    # 去混杂
    if not M.cert.pose_ok(po, rho):                                  # 门控
        po.w = 0.0; rho = 1.0
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4                    # R69
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    pri = M.pgp.prior(modes, po.feats) if po.w > 0 else None         # 姿态先验
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs.o, obs.o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)           # R69
    g = None
    if U_epi > TAU_EPI and not slow and po.w > 0 and rho < TAU_INFL:
        g = M.iia.choose_info_action(modes, pri or {}, o, M.budget, M.scm)
    if g is not None:
        u = g[1]; ans = M.cia.execute(g[0])                          # 看/问/触
        U_epi = M.cia.update_belief(modes, ans, y_t, discipline='k_agree')
        M.ibg_s.charge(u)                                            # 影响预算
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    lam, dec = M.slg.stabilize(lam, M.scm, M.history)                # 回路阻尼
    if dec == 'decouple': M.ach.push_social_decoupling()
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(modes, U_epi, lam, pri)
    M.vqa_s.submit_async(po, rho, g, M.scm.last_nde, M.scm.last_voi) # 审计
    return k, lam, mode, (U_ale, U_epi, rho)

## 3. 推导

**引理 19（反身偏差与 VoI 高估）** 在 SCM-R（定义 312）下，若忽略 ∂O/∂u 而用 R69 的 p(M｜y)，则意图估计偏差 ‖E[M̂]−E[M]‖ ≤ ‖I_u‖·‖u−u_ref‖ + o(‖u‖)；且被影响制造的「伪消歧」使 VoI 被系统性高估：VoI_naive ≥ VoI†，等号仅当 I_u = 0。系：**当影响敏感度为正时，越频繁发问越自信地读到由自己制造的确定**——这就是自我实现预言的形式化。

**引理 20（前处理姿态负对照的有效性）** 在 A99（无预期）与 A100（给定历史与前处理姿态无未观测混杂）下，Φ_before ⟂ do(u_t)，故以 Φ_before 为协变量可阻断「u 的选取依赖于机器人既有信念」这一后门；ΔΦ − r̂_infl 给出对 h_t 演化的无偏代理，其残余偏差 ≤ ‖Ĝ−G‖·‖u‖ + σ_pose。系：去混杂质量的上界由**社会 SCM 的失配**与**姿态噪声**共同决定——这直接决定了本轮最大风险。

**引理 21（姿态通道的信息价值与对提问的替代）** 在给定 h_t、M 时若 y_pose ⟂ y_ans（A101，姿态与回答条件独立），则姿态可提供的意图信息 I(M; y_pose｜do(u)) 与语言回答信息可加；当 VoI(ask) 低而 I(M; y_pose｜do(u)) 高时，仅凭姿态即可达到同等消歧，从而省去一次社交成本为 c(ask) 的提问。系：**姿态是「免打扰的提问」**——这是它在社交成本上优于 R69 语言交互的根本原因，但前提是去混杂成立。

**定理 18（非操纵上界）** 在 A103（证据中介可分离）与 NMC（定义 316）下，机器人施加的一切影响动作对真实偏好的改变不超过 δ_shift；可获得的收益上界为「表达保真度」的提升，即把观测噪声 σ_rep 降到由姿态/证据决定的不可约水平，且其信息收益 ≤ I(M; y｜do(u)) − I(M; y｜do(u_ref))。特别地，不提供新证据的影响动作（纯权威/紧迫/情感施压）的合规净收益 ≤ 0。系：**允许「让人愿意说真话」，禁止「让人想说假话」。**

**定理 19（社会回路稳定性）** 在 A102（局部线性化有效）下，若 ρ(G_loop) < 1 且控制器关于感知不确定单调（R69 的 λ_floor 单调性），则人-机社会闭环局部渐近稳定，不存在持续的「紧张—追问」振荡；若 ρ ≥ 1，则社会解耦动作 u_dec 将增益乘子降至 ρ' < 1 所需的最小介入强度存在且有限。⇒ R70 把 R69 的「对测量不确定刹车」扩展为「对社会回路失稳刹车」。

**定理 20（MIRROR 严格包含 FLUID-RAS）** 当 I_u = 0（人完全不被影响）且关闭姿态通道（w_pose = 0）时，MIRROR 的每个决策与 R69 FLUID-RAS 逐指令相同；任意状态下 MIRROR 的安全侧（λ 下界、C-RAS-WM 认证、证据纪律）不弱于 R69。R69 是 MIRROR 在「无社会耦合」边界上的退化。

## 6. 本轮最大风险

**一句话**：MIRROR-RAS 的全部「清白」依赖一个**运行时不可验证的社会因果模型**——去混杂与反事实「若我不问」都建立在「无未观测混杂、无预期、偏好准静态」等强假设上；一旦社会 SCM 设定错误（而它恰恰无法在线检验），「非操纵证书」就会变成**洗白工具**：系统会自信地宣称「我没有影响他」，同时正用自己的存在系统性地改变对方的回答。**R69 的教训是「问错比不问更危险」，R70 的教训是「自以为没影响，比影响更危险」。**

**次级风险与缓解**：
1. **姿态语义并非普世**（文化/个体差异、伪装姿态）→ PCC 个体标定 + 语义 OOD 门控 + ℰ_social 对抗训练；
2. **去混杂失败被误当成功** → ρ_infl 不可解释即证书无效，退回 R69（定义 324–325）；
3. **社会回路失稳/升级** → SLG 回路增益监测 + 社会解耦动作（定义 319、定理 19）；
4. **隐私与过度解读**（把不自觉姿态当「真值」刺探）→ 同意治理 + 剂量上限 + 参与式审计 VQAuditor-S；
5. **影响滑向操纵**（双用途）→ NMC 中介约束 + 红队 E305/E316 + 「只提高表达保真、不改变偏好」的硬边界。

class PoseSocialEstimator:
    def observe(self, sensor):
        pose, unc = self.pose(sensor); feats = self.soc(pose)
        w = self.calib.reliability(unc)
        if unc.occ > TAU_OCC or unc.sem_ood > TAU_SEM: w = 0.0
        return PoseObs(pose, feats, unc, w)

# IP-266 DCD：前处理姿态作负对照，扣掉「我造成的影响」
def deconfound(pose_before, pose_after, u_t, scm):
    delta  = pose_after.as_vec() - pose_before.as_vec()
    r_infl = scm.response(u_t - scm.u_ref)            # G_hat (u - u_ref)
    y_tilde = pose_before.as_vec() + (delta - r_infl)
    return y_tilde, explained_var(r_infl, delta)      # rho_infl

# IP-267 IIA：do-算子反事实 VoI + 安全/预算/非操纵门控
def choose_info_action(modes, w, o, budget, scm):
    best = None
    for g in info_action_candidates(modes):
        for u in social_candidates(o):
            if not budget.allow(g, u) or not c_ras_wm.certify_info(g, o): continue
            if not non_manipulation_ok(scm, u): continue
            score = (do_voi(modes, w, g, u, scm)
                     - do_voi(modes, w, g, scm.u_ref, scm)
                     - cost(g) - social_cost(u))
            if best is None or score > best.score: best = (g, u, score)
    return best if best and best.score > 0 else None

# IP-268 NMC：中介分解，禁止不经证据的偏好改变
def non_manipulation_ok(scm, u):
    te  = scm.total_effect(u, target='M')
    nie = scm.natural_indirect_effect(u, mediator='E')
    return (te - nie) <= DELTA_MANIP and \
           kl(scm.posterior_M(do=u), scm.posterior_M(do=scm.u_ref)) <= DELTA_SHIFT

# IP-269 SLG：社会回路稳定化
def stabilize(lam, scm, history):
    G = scm.loop_gain(history)
    return (lam, None) if max(abs(eigvals(G))) * lam < 1.0 else (lam, 'decouple')

# IP-278 主闭环（继承 R69）
def MIRROR_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); M.cof.step(...)                       # R68
    po = M.pse.observe(obs.sensor)
    y_t, rho = M.dcd.deconfound(M.pose_prev, po, M.last_u, M.scm)
    if not M.cert.pose_ok(po, rho): po.w = 0.0; rho = 1.0
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4                    # R69
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    pri = M.pgp.prior(modes, po.feats) if po.w > 0 else None
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs.o, obs.o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = None
    if U_epi > TAU_EPI and not slow and po.w > 0 and rho < TAU_INFL:
        g = M.iia.choose_info_action(modes, pri or {}, o, M.budget, M.scm)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g[0]), y_t, 'k_agree')
        M.ibg_s.charge(g[1])
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    lam, dec = M.slg.stabilize(lam, M.scm, M.history)
    if dec == 'decouple': M.ach.push_social_decoupling()
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(modes, U_epi, lam, pri)
    M.vqa_s.submit_async(po, rho, g, M.scm.last_nde, M.scm.last_voi)
    return k, lam, mode, (U_ale, U_epi, rho)

## 4. 推导

**引理 19（反身偏差与 VoI 高估）** 忽略 `∂O/∂u` 时意图估计偏差 `≤ ‖I_u‖‖u−u_ref‖+o(‖u‖)`，且伪消歧使 `VoI_naive ≥ VoI†`，等号仅当 `I_u=0`。系：影响敏感度为正时，越频繁发问越自信地读到由自己制造的确定——自我实现预言的形式化。

**引理 20（前处理姿态负对照）** A99/A100 下 `Φ_before ⟂ do(u_t)`，可阻断「u 依赖既有信念」的后门；`ΔΦ−r̂_infl` 对 h_t 演化的残余偏差 `≤ ‖Ĝ−G‖‖u‖+σ_pose`。系：去混杂质量由**社会 SCM 失配**与**姿态噪声**共同决定（直指本轮最大风险）。

**引理 21（姿态的信息价值与替代性）** 若 `y_pose ⟂ y_ans｜h,M`，姿态信息与语言回答可加；当 `VoI(ask)` 低而 `I(M;y_pose｜do(u))` 高时，仅凭姿态即可消歧，省去社交成本 `c(ask)`。系：姿态是「免打扰的提问」，但前提是去混杂成立。

**定理 18（非操纵上界）** A103 + NMC 下，影响对真实偏好的改变 ≤ δ_shift；收益上界为表达保真度提升，信息收益 `≤ I(M;y｜do(u))−I(M;y｜do(u_ref))`；纯权威/紧迫/情感施压（不提供证据）的合规净收益 ≤ 0。系：允许「让人愿意说真话」，禁止「让人想说假话」。

**定理 19（社会回路稳定性）** A102 下，若 `ρ(G_loop)<1` 且控制器单调，则人-机社会闭环局部渐近稳定、无持续紧张—追问振荡；若 `ρ≥1`，社会解耦动作把增益乘子降到 <1 的最小介入强度存在且有限。

**定理 20（MIRROR 严格包含 FLUID-RAS）** `I_u=0` 且 `w_pose=0` 时每步决策与 R69 逐指令相同；任意状态安全侧（λ 下界、认证、证据纪律）不弱于 R69。

## 7. 本轮最大风险

**一句话**：MIRROR-RAS 的全部「清白」依赖一个**运行时不可验证的社会因果模型**——去混杂与反事实「若我不问」都建立在「无未观测混杂、无预期、偏好准静态」等强假设上；一旦社会 SCM 设定错误（而它恰恰无法在线检验），「非操纵证书」就会变成**洗白工具**：系统会自信地宣称「我没有影响他」，同时正用自己的存在系统性地改变对方的回答。**R69 的教训是「问错比不问更危险」，R70 的教训是「自以为没影响，比影响更危险」。**

**次级风险与缓解**：姿态语义非普世（PCC 标定 + 语义 OOD 门控 + ℰ_social）；去混杂失败被误当成功（ρ_infl 不可解释即证书无效、退回 R69）；社会回路失稳升级（SLG 增益监测 + 解耦动作）；隐私与过度解读（同意治理 + 剂量上限 + VQAuditor-S）；影响滑向操纵（NMC 中介约束 + E305/E316 红队 + 「只提高表达保真、不改变偏好」硬边界）。
