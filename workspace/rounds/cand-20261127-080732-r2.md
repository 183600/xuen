## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1（伦理审查 → 它不是合规税，而是对尾部风险定价）

**直觉**：这场比赛的最大损失不是「某任务少几分」，而是**尾部事件**：撞到人（人为干扰轴）、抓着重物失控、恢复动作暴走、用了许可不清的权重、混合推理被判定违反「单模型」而取消资格、或交互延迟抖动让主办方质疑可信度（F25）。这些事件单次概率不高，但一旦发生就是乘性归零。伦理审查的思维方式——枚举伤害、估计概率×严重度、要求缓解措施与证据——恰好是把这些「隐性尾部风险」变成可管理项的工具。反过来，若只在训练 loss 上优化，所有这些风险都是不可见的。**反直觉点：在没有死亡/事故反馈的比赛里，唯一能让你提前看到尾部风险的方法，是主动做一次「模拟伦理审查」。**

**严谨定义**：把伦理审查实例化为一个风险登记册

`R = { (h_i, p_i, s_i, m_i, g_i) }`

其中 `h_i` 为危害事件（人机碰撞、重物跌落、恢复动作超限、许可违规、单模型边界违规、可信度异常、合成数据误导……），`p_i` 为先验概率档，`s_i` 为严重度（1–5），`m_i` 为缓解（运行时 guard 或离线门），`g_i` 为证据（可复现实验、日志、书面确认）。定义**审计就绪**：对所有 `s_i ≥ 4` 的危害，必须同时满足
(a) 存在机器可检的 `m_i`（不是一个口头承诺）；
(b) 存在「移除 `m_i` 就会失败」的配对消融；
(c) `g_i` 可被第三方在无你的情况下复跑。
这把「伦理」转成了和准确率同构的工程对象：可度量、可消融、可回归。

### 灵感 2（MuJoCo → 它是物理可行性判据，不是任务仿真器）

**直觉**：官方仿真与 32 任务并无直接对齐（F14），想在 MuJoCo 里复刻 32 个真机桌面场景的视觉/接触/资产，是典型的「用大成本追一个不可闭合的 sim2real 差距」。但 MuJoCo 的强项不是图像真实感，而是**刚体动力学、接触求解、关节限位、运动学、自碰撞**。因此正确用法是把它当「物理 oracle」：给一段候选动作 chunk 和当前状态，问「这段动作在 G1 身上物理上做得到吗？会不会自碰撞/穿桌/超限位/够不到？」。这个判据对 I1 的位置重拼接、I5 的合成恢复示教、I9 的检索动作先验都直接可用，而且**确定、便宜、无需训练**。**反直觉点：MuJoCo 在这套方案里越「不像真的」越有用——因为我们要的是物理约束，不是像素。**

**严谨定义**：定义物理一致性算子

`Φ_MuJoCo(a_{t:t+H}, s_t) → {pass, flags}`

输入动作 chunk 与观测状态，加载官方 G1 MJCF（F20/F21），用位置/力矩执行器近似推进 H 步，输出一组违规计数：

- `JLM` 关节限位裕度（`min_j min(q_j - q_min, q_max - q_j)`）；
- `SC` 非相邻连杆自碰撞数；
- `TP` 桌面/地面穿透深度；
- `RC` 末端可达性（逆运动学残差或工作空间距离）；
- `BS` 基座稳定性（质心投影/倾角越过支撑多边形）；
- `CF` 接触法向冲量代理（无力/触觉通道 F8，仅作代理，不等于真实接触力）。

据此定义**物理不可行率** `PIR = 加权违规帧数 / H`。只保留 `PIR < τ_task` 的增广/合成片段；`τ_task` 由真机日志标定。关键限制必须写明：`Φ` 是**必要非充分**判据（PR7）——通过 MuJoCo 不代表真机能成，接触参数、执行器、物体资产都有差距；它只负责把明显不可能的样本挡在真机预算之外。

### 合流：可审计的物理—安全双闸

把两个灵感接起来，本轮的主线不是再加一个模型模块，而是给 v1.1 的数据引擎与部署栈加一层**可审计双闸**：

- 离线侧（喂给训练/真机的数据）：`I10` MuJoCo 物理一致性闸门 + `L0.5` 仿真回归层，替 I1/I5/I9 过滤物理不可行样本；
- 在线侧（真机评测时的行为）：`I11` 伦理审查驱动的风险登记册与 SSM 式安全包络，把人为干扰轴从「靠反应」变成「有分离距离判据 + 有停止证据」；同时 `I6 v2` 用可信度自审对齐 F25。

这与 v1.1 的结论「胜负手在数据引擎」不矛盾，而是补上数据引擎的**质量闸**与部署栈的**风险闸**：数据再多，物理不可行就是负资产；策略再准，一次安全事故就归零。

## 2. 对第 2 轮痛点的增量修订

- P2（泛化缺口）再补充：五轴里的「人为干扰」轴本质是安全/伦理问题，I11 给它一个可测的分离距离判据，而非纯数据增广。
- P4（无触觉）补充：MuJoCo 的接触冲量只能当离线代理（CF），不能补上在线力控；I11 的安全包络必须保守，不能假装有力反馈。
- P5（时间压力）补充：SSM 的 `S_r/S_s` 直接依赖实测响应延迟与停止距离，I6 的 p99 目标因此从「性能指标」升级为「安全参数」。
- P7（先手窗口）补充：I10/I11 都是低成本、低算力的「先手可做」项，适合在等待真机排期时并行完成。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（物理 oracle 的效度）**：MuJoCo 的哪些违规 flag 与真机「物理不可行」强相关？`τ_task` 如何用少量真机日志标定？把有用增广误杀的代价（false reject）有多大？
- **Q10（单目 SSM 的可用性）**：在无深度、无力/触觉（F8）且传感器非安全认证的条件下，仅用头部 RGB + G1 正运动学 + 地面单应，能否得到足够保守的分离距离代理？什么样的裕度/迟滞能在「人为干扰轴得分」与「安全」之间取得可接受折中？
- **Q11（审查即杠杆）**：把风险登记册、安全案例、可信度自审作为可消融对象，它们对尾部风险（异常延迟、动作统计异常、恢复暴走）与人为干扰轴步骤分的边际贡献是多少？是否值得在真机预算里单独占一个 A/B？

## 4. 设计原则（新增 PR6/PR7，其余保留）

- **PR6 可审计律**：任何可能造成尾部损失（人身安全、取消资格、可信度判定、许可）的组件，必须配备 (a) 机器可检门、(b) 移除该门的配对消融、(c) 可复跑证据。不可审计的「安全模块」视为不存在。
- **PR7 物理必要非充分律**：MuJoCo 通过只用于排除明显不可行样本与验证停止距离；禁止把「仿真通过」当作任务成功或真机安全的证据。真机仍是唯一计分证据。
- PR1–PR5 保留（第 1/2 轮 §4）。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 v3 考纲校准五轴增广引擎 ★★★★★
- **动机**：（v1.1 保留）计分的真机评测每次都在 5 轴上偏离训练分布（P2/F2），泛化缺口是全局乘性损失；且增广会产生物理不可行动作（位置重拼接风险）。
- **本轮深化（MuJoCo）**：增广从「按考纲采样」再加一道**物理可行性闸**——所有几何增广（位置重拼接、物体位姿扰动、抓取点偏移）生成的候选动作段，先过 I10 的 `Φ_MuJoCo`，`PIR < τ_task` 才入训。考纲卡仍负责「该往哪个方向扰动」，I10 负责「这个扰动物理上做不做得到」。
- **与现有方案差异**：直接 SFT 用标称数据；盲目增广不做物理校验；本点把「考纲对齐」与「物理可行」分开建模，各自可消融。
- **技术可行性**：高。考纲卡半自动（LLM 解析 wiki + 人工校对，约 10 min × 32）；I10 是现成 MJCF + Python。
- **所需资源**：分割/inpainting 1×24GB GPU；MuJoCo 判定 CPU 即可（F20/F21）。
- **落地步骤**：①32 张考纲卡；②背景/干扰物两轴放量；③外观/位置两轴 L0 消融；④剂量-响应定档；⑤位置重拼接先过 I10 的 PIR 闸，再做轴间交互析因。
- **风险**：考纲卡偏差（缓解：单任务通道抽测）；I10 的 sim-real 差距导致误杀（缓解：`τ_task` 用真机日志标定，先宽松后收紧）。

### I2 v3 数据引擎 2.0：110 语料孪生迁移 + 加权共训 + 溯源台账 ★★★★★
- **动机**：单模型平均分被最弱任务支配（P1）；示教语料与质量双重浪费（P8）；新增许可/溯源风险（P9/F28）。
- **本轮深化（伦理审查 → 数据治理）**：v1.1 的三件事保留：
  1. **孪生语料入训**：110 任务按技能孪生表（§1.1）选择性入训，提升流匹配动作头的多模态覆盖；

### 1.4 MuJoCo 物理一致性闸门（I10 核心）

```python
G1 = mujoco.MjModel.from_xml_path("unitree_mujoco/unitree_robots/g1/g1_29dof.xml")
DT, SUB = 0.002, 4                        # F23: timestep 2ms；每控制步 4 子步

def physics_consistency(chunk, state, tau_task=0.05):
    m, d = G1, mujoco.MjData(G1)
    set_free_base_and_joints(d, state)     # 基座位姿未知时按站立/单应估计，记录不确定度
    flags, acc = [], 0.0
    for a in chunk:
        ctrl, ik_res = map_action(a)       # joint: 直通；ee: DLS-IK
        if ik_res > IK_EPS:  flags.append("RC")
        for _ in range(SUB):
            d.ctrl[:] = ctrl
            mujoco.mj_step(m, d)
            acc += step_violation(
                d, d.ctrl,
                joint_margin=JLM_EPS,      # 关节限位裕度
                self_collision=True,       # 非相邻连杆 SC
                table_plane=TABLE_Z,       # 穿透 TP
                com_support=COM_EPS,       # 基座稳定 BS
                contact_force=F_PROXY_MAX, # 无力传感，仅冲量代理 CF
            )
    pir = acc / (len(chunk) * SUB)
    return GateResult(pass_=pir < tau_task, pir=pir, flags=Counter(flags))

# 用法：I1/I5/I9 生成的每个候选段先过此闸；I11 用它求停止距离。
# 纪律（PR7）：pass_ 只表示"物理上可能"，绝不表示真机能成功或安全。
```

```python
def ssm_supervise(obs, state, t_r, t_s):
    humans = detect_people(obs.images)                     # 无需深度，bbox/姿态
    d = mono_distance_to_robot(humans, state.joints, obs.cam_intrinsics)  # 保守取近
    S = V_H_MAX * (t_r + t_s) + stop_distance(state, t_s) + C_INTRUSION + Z_UNCERT
    S_hard = 0.5 * S
    if d < S_hard:            return HOLD               # 停持，记录证据
    if d < S:                 return scale_velocity((d - S_hard) / (S - S_hard))
    return NORMAL                                        # 迟滞恢复，防抖
```

### 1.6 可信度自审（I6 v2，对齐 F25）

```python
def credibility_report(log):
    lat = np.array([r.latency_ms for r in log])
    return {
        "p50_ms": float(np.percentile(lat, 50)),
        "p99_ms": float(np.percentile(lat, 99)),          # 目标 < 40ms（15Hz 参照 F12）
        "cv":     float(lat.std() / max(lat.mean(), 1e-9)),  # 目标 < 0.1
        "nonfinite_actions": int(sum(not np.isfinite(a).all() for a in log.actions)),
        "jerk_p99": float(np.percentile(action_jerk(log.actions), 99)),
        "determinism_max_dev": float(replay_max_dev(log)),  # 固定 obs/seed 重放
        "timeouts": int(sum(r.timeout for r in log)),
    }

def credibility_gate(rep):
    return (rep["p99_ms"] < 40 and rep["cv"] < 0.1
            and rep["nonfinite_actions"] == 0 and rep["determinism_max_dev"] < 1e-6)
```
