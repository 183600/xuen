# 第 10 轮（承接 v9；本轮灵感：「场景泛化」×「推理延迟」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**泛化证书 + 延迟耦合 + 可证伪信任**。两个灵感分别治理 v9 的两个隐性常数假设：其一，块证书的误差界 β 只在"信任域内"成立，却用单一标量 Δ_dom 的 20 帧滑窗去近似"域"；其二，整个安全论证默认"证书算完即可用"，把推理延迟当作调度问题而非安全问题。v10 的立场是：**安全余量必须是可计算、随时间与场景显式增长的量，而不是一个被假设为常数的 β**。

## 0. 直觉与动机

**灵感 1（场景泛化 → 证书随场景变宽，而不是"假设变宽后仍成立"）**
直觉：v9 用 Δ_dom < τ_dom 做"信任域"开关，但 Δ_dom 是"分布变了多少"的事后统计，且 τ_dom 与 β 都在源域标定。真实部署里最危险的不是"检测到陌生"，而是"看起来不陌生、前向模型其实已经错了"——即泛化误差落在域内估计不到的地方。因此把常数 β 升级为**泛化证书 β_gen**：用 OTL 域差异（Ben-David 域适应界中的 d_HΔH 项）加 PAC-Bayes 复杂度项，给出目标场景误差的有限样本上界；同时建**场景专家库**：每个场景簇拥有自己的前向模型与阈值，但切换必须通过**泛化防护盾**——候选专家的证书不优于现任就不切。这样"泛化"从"希望模型迁移"变成"只在证书允许的区域内迁移"。

**灵感 2（推理延迟 → 延迟进入安全距离，而不只进入截止期）**
直觉：v9 的停车不变式用当前速度算刹车距离，默认"感知到执行零延迟"；但块证书在 t0 计算、在 t0+τ_lat 才作用于执行器。多出来的 τ_lat 内机器人仍按旧速度前进，这段**反应距离 v·τ_lat 必须计入安全余量**，否则证书越"高效"（块越长、算得越久）反而越危险。更进一步：证书误差界会随**证书年龄**增长（状态漂移、预测发散），所以定义 β_eff = β0 + L_F·age + β_gen。推理延迟尖峰于是自动表现为"β_eff 上升 → K_eff 收缩"，把延迟从性能问题变成安全反馈；并引入**任意时间证书**：预算不足时返回更松但严格的区间界，算得越久越紧，永远不会"算不完就没有证书"。

**灵感 3（两个灵感的交点 → 用残差做"证伪器"）**
直觉：v9 的最大风险是 Δ_dom 滑窗滞后。解决它不需要更准的 Δ_dom，而需要一个**领先指标**：单步预测残差 r_t = ρ(s_{t+1}, F̂(s_t,a_t))。它在模型真正失效的那一步就跳起，比 20 帧滑窗早；一旦 r_t > β_eff，说明证书记载的误差界已被证伪，立即作废、K_eff←1、注入中立元。这把"信任"从"证书声称"改成"证书经受了证伪"——**可证伪认证律**。两个灵感在此闭环：场景泛化决定证书初始有多宽，推理延迟决定证书随时间变多宽，残差决定证书何时必须作废。

## 1. 研究问题（轮次升级版）

- **Q1（泛化证书的安全域）**：如何用可计算的场景差异量给出 β_gen 的有限样本上界，使 K_eff 取大时目标场景的证书仍保守？场景专家切换在什么条件下可证明不发生负迁移？
- **Q2（延迟-安全耦合）**：如何把推理延迟（含尾延迟）转成安全余量与 K_eff 门控，使停车不变式对任意 τ_lat ≤ τ_lat^max 成立？任意时间证书如何保证"提前停算仍然严格"？
- **Q3（可证伪性与滞后）**：残差证伪器在什么检测延迟与误报率下能先于 Δ_dom 滑窗捕获域跳变？证伪后的恢复（重标定、专家解冻）如何避免状态抖振？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 场景泛化证书律（Scene-Generalization Certificate, SGC）**
证书误差界必须是场景差异的可计算函数：β_gen(t) = β0 + c1·Δ_dom(t) + c2·sqrt((KL(Q‖P)+ln(2/δ_conc))/(2N_eff(t)))。K_eff 取大需 β_eff ≤ β_bar。未知场景（ν(t)=min_j d(φ_scene,e_j) > τ_novel）⇒ 保守模式：单专家、K_eff=1、全模块唤醒。专家切换受**泛化防护盾**约束：仅当 β_eff^{cand} + δ_switch ≤ β_eff^{incumbent} 且连续 N_confirm 周期成立才切；否则保留现任。

**P14 延迟-安全耦合律（Latency-Safety Coupling, LAC）**
所有安全距离含反应项：d_stop(p) = v_p·τ_lat^max + d_brake(v_p) + d_safe。证书年龄进入误差包络：β_eff = β0 + L_F·age + β_gen。任意时间证书是单调收窄的严格区间序列 {B^(0) ⊇ B^(1) ⊇ …)}，第 i 次迭代成本单调增、宽度单调减，停在任何一次都可用于守卫（越早越松）。age > a_max ⇒ 证书作废，不得复用陈旧证书。

**P15 可证伪认证律（Falsifiable Certificate, RSM）**
任何证书 C 在被观测残差证伪之前有效；r_t > β_eff ⇒ 立即作废、K_eff←1、注入 v^⊥。残差用 CUSUM/Page-Hinkley 检测，给出检测延迟上界与误报率（ARL_0）上界。证书"信誉"随未被证伪的时长增加，但一次证伪即清零，不允许历史洗白。

## 3. 与基线的接口（如何退化）

- SGC 失效 ⇒ 单专家、β_gen≡0，退回 v9 的 Δ_dom 门控（等价 v9）；
- LAC 失效 ⇒ τ_lat←0、改用固定安全余量，退回 v9 的"零延迟"假设（并记审计告警）；
- RSM 失效 ⇒ 仅靠 Δ_dom 检测（等价 v9，已知滞后）；
- SGC/LAC/RSM 全失效 ⇒ 完整退回 v9 MetricVoiceGauge-ACMD；
- v9 的 AC/MW/ID 任一失效 ⇒ 退回 v8；DA/SPR/Cal 失效 ⇒ v7；全失效 ⇒ v6。

## 4. 预期贡献

1. **泛化证书**：把"信任域"从开关量升级为 PAC-Bayes + 域差异的连续误差上界，并给出场景专家**无负迁移切换**的充要条件；
2. **延迟-安全耦合**：把推理延迟（含 p99.9 尾延迟）显式转成反应距离与误差包络增长项，使 K_eff 对延迟尖峰自动收缩；
3. **可证伪认证**：以单步残差作为证书的在线证伪器，直接补上 v9 最大风险中"Δ_dom 滑窗滞后"的漏洞；
4. **风险-预算-泛化三闭环**：E571–E590 覆盖跨场景泛化、延迟注入、尾延迟、证伪及时性、负迁移、组合压力与端到端任务。

## 5. 本轮最大风险

**一句话**：统一误差包络的两个关键量——误差增长常数 L_F 与残差证伪——都只能"事后"获得，若 L_F 被低估且延迟尖峰与场景跳变同拍发生，系统会在观测到证伪之前就把基于错误证书的动作执行下去，即「延迟越大、场景越新，证书越晚被证明是错的」。

**新增定义 540（场景指纹与场景库 SceneFingerprint / SceneBank）**
φ_scene(t) = E_{o∈o_{t−W:t}}[ψ(o)]，ψ 为冻结轻量编码器（W=200ms）。场景库 E 由离线聚类与在线质心更新维护。归属 j*(t)=argmin_j d(φ_scene,e_j)，新颖度 ν(t)=min_j d。ν(t) > τ_novel ⇒ 未知场景，直接进入保守模式（K_eff=1、单专家、ID 全唤醒）。

**新增定义 541（泛化证书 GeneralizationCertificate）** 由域适应界（Ben-David：目标风险 ≤ 源风险 + d_HΔH/2 + λ）与 PAC-Bayes 复杂度项合成：
```
β_gen(t) = β0 + c1·Δ_dom(t) + c2·sqrt( (KL(Q‖P) + ln(2/δ_conc)) / (2·N_eff(t)) )
```
β0 为源域经验误差上界（×1.2 安全系数），c1 把 OTL 的域差异估计映射到 d_HΔH/2，c2 为假设类复杂度常数。β_gen 对 Δ_dom 单调增、对 N_eff 单调减。N_eff 由目标场景在线样本的**有效**数目给出（去相关后的样本数，避免把 20 帧滑窗当 20 个独立样本）。

**新增定义 542（统一保守误差包络 UnifiedErrorEnvelope）**
```
β_eff(t) = β0 + L_F·age(t) + β_gen(t)
```
其中 age(t)=t−t_cert，L_F 为假设 A1 的误差时间增长率。A1：沿部署轨迹，‖F̂(s_{t+Δ})−F(s_{t+Δ})‖ ≤ ‖F̂(s_t)−F(s_t)‖ + L_F·Δ。L_F 由离线验证集估计并取上置信界；若 L_F 无法验证，则强制 K=1（分块关闭，退回 v9 逐步语义）。β_eff 对 age、Δ_dom 单调不减，故延迟与场景漂移只可能让 K_eff 变小，绝不会悄悄变大。

**新增定义 543（泛化防护盾 GeneralizationShield）** 专家切换谓词：
```
switch(t): j → j'  ⇔  β_eff^{j'}(t) + δ_switch ≤ β_eff^{j}(t)
                     ∧ cert_{j'} valid 连续 N_confirm 周期
                     ∧ ν(t) ≤ τ_novel
```
不满足则保留现任 j。被禁用的专家不删除，其输出注入中立元（等价 v9 的 dormant）。防护盾保证"证书意义上的切换单调不退化"（引理 89），从而排除负迁移。

**新增定义 544（延迟分解与反应距离 LatencyDecomposition）**
τ_lat(t) = τ_sense + τ_queue(t) + τ_compute(t) + τ_act。规划用 τ_lat^p99，硬安全用 τ_lat^max。反应距离 d_react(p) = v_p·τ_lat^max：命令在 t 发出、t+τ_lat 才生效，期间按旧速度前进。契约表中每模块的有效截止期改为 D'_m = D_m − τ_lat^p99（见定义 535 的升级）。

**新增定义 545（延迟感知停车不变式 LatencyAwareStopInvariant）**
```
d_safe + v_p·τ_lat^max + d_brake(v_p) ≤ dist(s_p, O) − |traj_{p:K}|
```
同时证书验收改为在执行时刻求值：`g_min − β_eff(t+τ_lat) ≥ d_safe`，即用"未来时刻"的包络检验"现在生成的块"，而非用"现在"的 β 检验整块。这是 v9 定义 534/533 的严格加强版本：令 τ_lat=0、L_F=0、β_gen=0 即逐项退化为 v9。

**新增定义 546（任意时间证书 AnytimeCertificate）** 细化序列 {B^(0) ⊇ B^(1) ⊇ … ⊇ B^(I)}：每次迭代用区间算术/分支定界把一个区间节点分裂，宽度 w_i = w_0·ρ^i（ρ<1），成本单调增。性质：(a) 每个前缀 B^(i) 都严格包含真值（可靠性）；(b) 宽度单调收窄（可用性递增）；(c) 预算耗尽停在 i 仍是合法证书，只是更松。守卫永远消费当前可用的 B^(i)，因此"算不完"退化为"更保守"，而非"没有证书"。

**新增定义 547（证书时效与污染 StalenessContamination）**
age(t) = t − t_cert。若 age(t) > a_max 或 τ_lat(t) > a_max，证书立即失效（不得以旧证书继续执行）。a_max 由 A1 反解：β0 + L_F·a_max + β_gen ≤ β_bar ⇒ a_max = (β_bar − β0 − β_gen)/L_F。证书被任何用于在线更新的观测"污染"后，其有效期从污染时刻重新起算，不得续用。

**新增定义 548（残差惊奇 CUSUM ResidualSurprise）**
```
r_t = ρ(s_{t+1}, F̂(s_t, a_t))
S_t = max(0, S_{t−1} + r_t − μ0 − k)
alarm_t ⇔ S_t > h
```
μ0 为源域残差均值，k 为容许漂移，h 由目标 ARL_0 反解。证伪规则：r_t > β_eff(t) ⇒ 立即 alarm（无需 CUSUM 累积），并把 β_eff 的下界抬到 r_t（已观测误差即为新下界）。CUSUM 负责"缓慢累积型"失效，单步阈值负责"突变型"失效，两者并联。

**新增定义 549（泛化视界与有效块长 GeneralizationHorizon）** 取代 v9 定义 539 的启发式公式，改为证书可行性求最大块长：
```
K_eff(t) = max{ k ∈ [1, K_max] :
               β_eff(t + k·Δt) ≤ β_bar
               ∧ ∀p ≤ k: 定义 545 停车不变式成立
               ∧ cert(t) 未超龄、未证伪
               ∧ ν(t) ≤ τ_novel }
```
集合为空 ⇒ K_eff=1。当 L_F=0、β_gen=c1·Δ_dom 时，该式退化为 v9 的 `K_max·(1−Δ_dom/τ_dom)` 门控（相差常数映射），故 v10 是 v9 的严格推广而非替换。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v9 不变。
**定义 521（DA-OTL）** 继承；Δ_dom 在 v10 中同时充当 β_gen 的输入，而非仅作开关。
**定义 535（中间件契约，v10 升级）** 契约增加三项：`lateness_budget`（τ_lat^p99 分摊）、`cert_age`（该模块输出证书的年龄）、`falsifiable`（是否接受残差证伪）。有效截止期 D'_m = D_m − τ_lat^p99。

# IP-357 SceneGeneralizationCertifier：场景泛化证书器
class SceneGeneralizationCertifier:
    def __init__(self, encoder, scene_bank, beta0, c1, c2,
                 delta_conc=1e-3, tau_novel=0.35, delta_switch=0.005,
                 n_confirm=3):
        self.psi, self.bank = encoder, scene_bank
        self.beta0, self.c1, self.c2 = beta0, c1, c2
        self.delta_conc, self.tau_novel = delta_conc, tau_novel
        self.delta_switch, self.n_confirm = delta_switch, n_confirm
        self.incumbent = None
        self._switch_streak = defaultdict(int)

    def fingerprint(self, obs_hist):
        return pool(self.psi(o) for o in obs_hist)

    def novelty(self, phi):
        return min(dist(phi, e) for e in self.bank)

    def beta_gen(self, delta_dom, kl_qp, n_eff):
        complexity = self.c2 * sqrt((kl_qp + log(2.0 / self.delta_conc))
                                    / (2.0 * max(1, n_eff)))
        return self.beta0 + self.c1 * delta_dom + complexity   # 定义 541

    def route(self, phi, experts, beta_of):
        """返回 (expert_id, beta_gen, unknown_flag)；防护盾见定义 543"""
        nu = self.novelty(phi)
        if nu > self.tau_novel:
            return None, beta_of[self.incumbent], True   # 保守模式
        cand = min(experts, key=lambda j: beta_of[j](phi))  # 证书最优候选
        inc = self.incumbent if self.incumbent is not None else cand
        if (beta_of[cand](phi) + self.delta_switch <= beta_of[inc](phi)):
            self._switch_streak[cand] += 1
            if self._switch_streak[cand] >= self.n_confirm:
                self.incumbent = cand                     # 单调不退化切换
                self._switch_streak.clear()
        else:
            self._switch_streak[cand] = 0
        return self.incumbent, beta_of[self.incumbent](phi), False


# IP-358 LatencyAwareCertifier：延迟感知证书器
class LatencyAwareCertifier:
    def __init__(self, L_F, beta_bar, a_max=None, rho=0.6, i_max=8):
        self.L_F, self.beta_bar = L_F, beta_bar
        self.rho, self.i_max = rho, i_max
        self.a_max = a_max or (beta_bar / max(L_F, 1e-9))

    def beta_eff(self, beta0, beta_gen, age):
        return beta0 + self.L_F * age + beta_gen      # 定义 542

    def stop_invariant(self, live, p, remaining_len, latency_max, d_safe):
        # 定义 545：多出的反应距离必须计入
        return (live.clearance[p]
                - live.speed[p] * latency_max
                - self.d_brake(live.speed[p])
                - d_safe) >= remaining_len

    def refine(self, cert, budget_ms):
        """任意时间证书：返回 (B_i, i, width)；预算耗尽即停，仍然严格"""
        B = cert.initial_interval()                   # 定义 546
        cost, i = 0.0, 0
        while (cost < budget_ms and i < self.i_max
               and B.width > cert.target_width):
            B = cert.split_widest_node(B)             # 宽度 ×rho，成本 +
            cost += cert.iteration_cost()
            i += 1
        return B, i, B.width

    def stale(self, cert_t, now, latency_now):
        return (now - cert_t > self.a_max
                or latency_now > self.a_max)          # 定义 547


# IP-359 ResidualSurpriseMonitor：残差惊奇证伪器
class ResidualSurpriseMonitor:
    def __init__(self, mu0, k_drift, h, beta_accessor):
        self.mu0, self.k, self.h = mu0, k_drift, h
        self.S, self.beta = 0.0, beta_accessor

    def update(self, s_next, s_pred, aborted=False):
        r = rho_metric(s_next, s_pred)                # 定义 548
        self.S = max(0.0, self.S + r - self.mu0 - self.k)
        hard = r > self.beta()                        # 单步证伪（突变型）
        cusum = self.S > self.h                       # 累积证伪（缓变型）
        if hard or cusum:
            self.S = 0.0
            self.beta().raise_floor(r)                # 已观测误差成为新下界
            return True                               # 证书作废
        return False

## 4. 推导

**引理 87（泛化证书保守性）** 设源域风险上界为 β0，域差异估计满足 |d̂_HΔH/2 − d_HΔH/2| ≤ ε_dom，假设类复杂度满足 PAC-Bayes 界，则对目标场景以概率 ≥ 1−δ_conc 有 E_target[ℓ] ≤ β_gen + O(ε_dom + sqrt(ln(1/δ_conc)/N_eff))。证明：域适应三角不等式给出 E_target ≤ E_source + d_HΔH/2 + λ；E_source ≤ β0；d_HΔH/2 ≤ Δ_dom + ε_dom；PAC-Bayes 给出 E_source 的经验估计到总体风险的复杂度项；合并即得。故 β_gen 是目标误差的有限样本上界，而非常数假设。∎

**引理 88（统一包络单调性与证伪及时性）** (i) β_eff 对 age 与 Δ_dom 单调不减，故任何延迟增加或场景漂移只会缩小 K_eff，不可能使 K_eff 悄悄增大；(ii) 若真实误差在 t 首次超过 β_eff，则单步阈值在 t 当拍告警；若误差缓慢爬升，CUSUM 在 ≤ (h+β_bar)/(k) 拍内告警。证明：(i) 由定义 542 逐项求导非负；(ii) 单步阈值直接比较 r_t 与 β_eff；CUSUM 每次至少净增 k（当 r_t−μ0 ≥ k），从 0 到 h 至多 ⌈h/k⌉ 拍。故残差证伪在检测延迟上有上界，且先于 20 帧滑窗的 Δ_dom。∎

**引理 89（防护盾无负迁移）** 在定义 543 的切换谓词下，任意一次被批准的切换都满足 β_eff^{after} ≤ β_eff^{before} − δ_switch；未被批准的切换不改变现任。故系统运行期间 β_eff 沿切换序列单调不增（在 Δ_dom、age 不变的同一拍内），证书保守性与安全性不因切换而退化。证明：对切换次数归纳。初始成立；每次批准切换由谓词直接给出不等式；不切换则 β_eff 不变。∎

**引理 90（延迟感知停车安全性）** 若在 p 处定义 545 的不变式成立，且实际 τ_lat ≤ τ_lat^max，则从 p 执行安全停驻后，轨迹终点与最近障碍距离 ≥ d_safe。证明：在 [t_p, t_p+τ_lat] 内速度不超过 v_p，位移 ≤ v_p·τ_lat^max；随后刹车位移为 d_brake(v_p)。总位移 ≤ v_p·τ_lat^max + d_brake(v_p) ≤ dist(s_p,O) − |traj_{p:K}| − d_safe，故终点距障碍 ≥ d_safe。令 τ_lat^max=0 即退化为 v9 引理 82(ii)。∎

**引理 91（任意时间证书的可靠性与可中止性）** 细化序列的每个前缀 B^(i) 都包含真值，且 w_i = w_0·ρ^i 单调递减；在任意预算处停止，B^(i) 仍是合法（可能更松）的证书；若证书被 RSM 证伪或超龄，则其可信度归零、不得继续使用。证明：可靠性由区间算术的包含性归纳；宽度由每次分裂最宽叶子并乘收缩因子 ρ 得；可中止性由"每个前缀都合法"直接推出；证伪由定义 548 的作废规则给出。∎
