# 第 42 轮（新循环第 2 轮） · 开放词汇 × 能耗优化：把「语义开放」与「能量预算」变成证书自动机的可证接口（四层架构 v7）

> 承接第 41 轮 v6（CAR × LCS × CMC，证书即转移守卫）。第 41 轮把证书从静态文档变成运行时守卫，但仍默认两件事：世界是**闭合**的（语义标签集固定）、算力是**免费**的（预算 Γ 与真实电池脱钩）。本轮灵感词「开放词汇」「能耗优化」正好拆掉这两个默认：**开放词汇**要求系统面对无界概念集仍能守住安全；**能耗优化**要求证书自身进入能量账本，而不是无限预算。核心主张：开放的是「任务与风险概念」，闭合的是「安全谓词基」；证书不仅是一张布尔门，更是一笔有 ROI 上限的能量投资。

## 0. 直觉与动机

**灵感 1（开放词汇 → 开放的是概念，闭合的是谓词）**：第 41 轮的每个 Guard 都绑定在固定的语义类与固定的证书边际上。一旦接入 VLM/CLIP 式开放感知（IP-36/IP-35），系统随时会冒出训练时没见过的概念——「湿滑地砖」「临时围栏」「抱着纸箱的人」——按旧设计，它们要么被无视（漏报），要么无法接地（瘫痪）。直觉的解法不是「让证书去认证任意语言」，而是**两级接地**：第一级开放且学出来（概念→固定风险基的权重），第二级闭合且可认证（风险基→几何边际）。证书只对第二级负责；第一级的开放性用**保形校准**换成分布无关的覆盖率，再用**保守闭包**把「不确定」压成「未知→更保守」。于是开放词汇不会污染安全证明，只是不断向自动机注入新的守卫候选。

**灵感 2（能耗优化 → 证书是能量投资，不是免费裁判）**：第 41 轮的 C_j 是抽象的「成本」，Γ 是与电池无关的常数。可现实里，跑一次 LipSDP 要电，绕开一个保守障碍也要电：更紧的证书让你贴边抄近路（省运动能量），但认证本身更费电（算力能量）。于是存在一个**证书能量投资回报率**——多花一焦耳算力，换回多少焦耳运动能量。更进一步，保持时间 T_hold=(m₀−θ)/L_m 天然把「重认证频率」变成库存问题：单次认证越贵、保持越久，单位时间认证能耗越低，结构上正对应 EOQ 的平方根律。还有一处漂亮的协同：降低 v_max 既省驱动能量，又降低 L_m、拉长 T_hold、省认证算力——「慢」同时节流了两本账。

**耦合**：开放词汇提供**能量语义**（地形→滚动阻力、人群→限速、充电桩→目标），使能量模型不再是常数；能量模型又反过来决定**哪些概念值得花算力认证**（边际能量收益高者优先）。开放让世界变大，能量让证书变贵，二者共同把「认证」从安全部门的开销变成调度器的决策变量。

## 1. 形式化定义

**定义 32（开放词汇守卫 OVG）**：概念宇宙 C 开放（语言定义、无界）；闭合风险基 B={b₁,…,b_K}，每个 b_k 带第 41 轮已认证的几何边际 m_k(x)。接地映射 g:C→Δ^K，阈值 τ，残差质量 r(c)=1−Σ_{k:w_k(c)≥τ}w_k(c)。概念 c 的守卫定义为
G_c(x)=min_{k:w_k(c)≥τ} m_k(x) − ε_g(c) − θ_c，
其中 ε_g(c) 为接地校准半径。**关键解耦**：证书只量化于闭合基 B 与标定误差 ε_g；开放性完全被封在 C 与 g 内，学习组件永不进入证书推导链。

**定义 33（保守语义闭包与分布无关保证）**：概念 c 的风险集 R_c={x:G_c(x)<0}，保守闭包 R̄_c=cl{x:∃g′∈B_ε(ĝ), G′_c(x)<0}。给定与测试可交换的校准集，分裂保形给出 P(m_c^true(x)≥G_c(x))≥1−α。**但**该保证以「概念与场景可交换」为前提；对分布外概念 OOD(c) 保证失效，须由新颖性检验改写为 P(safe)≥1−α−β_nov，其中 β_nov 为 OOD 漏检率。故 OVG 必须与新颖性检测器成对出现，缺一不可。

**定义 34（能量增广混合自动机 EAHA）**：在 CAHA 上增广能量变量 e∈R≥0 与功率映射 P:Q×V×J→R≥0，ė=−(P_act(q,v,terrain(c))+P_comp(j)+P_sense)。能量守卫 m_e(x,e)=e−e_stop(x)−e_reserve。新增 EnergySaver、Reserve 制度；不变式追加 e≥e_stop(x)+e_reserve，并要求从每个可达态存在一条到 SafeStop 且全程 e(t)≥0 的可生存轨迹（viability），而非仅存一条名义轨迹。

**定义 35（证书能量 ROI 与最优紧致度）**：记紧致度 t（越大界越接近真值、越允许贴边）。运动能量 E_m(t) 单调减且凸，认证能量 E_c(t) 单调增且凸。总能量 J(t)=E_m(t)+E_c(t)，可行性下限 t_sf（低于它 ValidRegion 缩空 / N* 发散）。最优 t*=argmin_{t≥t_sf}J(t)：内点满足 E_m′(t*)+E_c′(t*)=0，边界取 t_sf。边际 ROI=−E_m′/E_c′。调度规则：**把算力买到 ROI 最高的守卫上**。证书由此成为有收益率上限的资本支出，而非越紧越好的教条。

**定义 36（能量最优重认证与速度-证书协同）**：档 j 的单次认证能耗 a_j=E_comp(j)，保持时间 H_j=T_hold(j)；档位选择为 j*=argmin_j a_j/H_j，s.t. H_j≥τ_min。耦合速度时，L_m≈‖∇m‖·v ⟹ H∝1/v。设单位距离运动能耗 ≈p_act(v)/v，单位距离认证能耗 ≈a/(v·H)∝a‖∇m‖/((m₀−θ)v²)。于是单位距离总能耗
f(v)=p_act(v)/v + a‖∇m‖/((m₀−θ)v²)，
第一项随 v 增、第二项随 v 减，存在内点 v*；其「反平方」结构正是 EOQ 的连续版——**重认证间隔是被认证成本与风险共同定出的订货批量**。

**定义 37（开放词汇能量语义与悲观功率界）**：概念 c 参数化功率模型 P_act=P(terrain(c),v)。能量估计误差本身不破坏安全不变式，只影响 e_stop 可达性，故对剩余能量取**悲观界** P̄(c)=max_{c′∈R̄_c}P(terrain(c′),v)，保证真实轨迹的能量不低于证书值。开放词汇由此以「更坏的功率上界」进入安全证明，而非以概率风险进入。

**设计约束（开放单调性）**：任何新概念 c 只能**新增/收紧**守卫，绝不能放松既有守卫；当 OOD(c)、r(c)>r_max 或 ε_g 超界时，c 只能指向 Watch/Degraded。这把开放词汇的失效严格限制为可用性下降，与第 41 轮的单调保守性一脉相承。

## 2. 三大产出设计

### 2.1 IP-54 OPEN-VOCAB GUARD GROUNDING（开放词汇守卫接地 OVG）
1. 概念→风险基：VLM/CLIP 对区域嵌入打分，投影到 K 维风险基，输出软权重与残差质量 r(c)。
2. 风险基→几何边际：完全复用 IP-46/49 的已认证边际；证书链不含任何学习组件。
3. 保形校准器：按基谓词族分组的 Mondrian conformal 做分裂校准，得 ε_g(c) 与覆盖率；OOD 另训新颖性分数。
4. 保守闭包：对 ε 球内所有可行接地取最坏，生成 R̄_c；超界即降级。
5. 概念生命周期：新概念先进 Watch，累积校准样本后转正；守卫版本化、可回滚（接 IP-47 契约）。

### 2.2 IP-55 ENERGY-CERT ECONOMICS（能量-证书经济学 ECE）
1. 能量增广自动机 EAHA：Nominal / EnergySaver / Reserve / SafeStop，能量守卫与 e_stop 可达性。
2. 证书 ROI 调度：按 ROI 把每拍算力分配到守卫；紧致度取 t*=max(t_sf,t_econ)。
3. 重认证与速度联合优化：按 j*=argmin a_j/H_j 选档，并对 v 求 f(v)=p_act/v+a‖∇m‖/((m₀−θ)v²) 的内点最优。
4. 功率模型：开放词汇供地形/人群语义，取悲观 P̄(c)；电池健康与温度在线修正。
5. 任务级能量预算：按制度/任务阶段做 MPC 式分配，始终预留 SafeStop 储备。

### 2.3 IP-56 CONFORMAL OPEN-VOCAB MONITOR（保形开放词汇监控器 COVM）
1. 把 OVG 守卫与能量守卫编译为看门狗（复用 IP-53），额外挂保形 p 值与新颖性分数。
2. 单边可靠性升级：ok ⇒（证书成立 ∧ 覆盖率≥1−α）；任一新概念 p 值越界即 warn/trip。
3. 风险预算：α、β_nov 与能量储备作为可配置预算，超预算自动降档到 T0 / EnergySaver。
4. 审计链：记录每个新概念首次出现、校准样本量、经验覆盖率与降级次数，供事后归责。

## 5. 本轮最大风险

**一句话**：开放词汇的保形保证是**边际覆盖**而非条件覆盖，一旦遇到标定外概念或分布偏移，「1−α」会悄悄失效，而能耗优化又会诱导系统在省电方向上放宽操作与重认证——两者叠加，最可能的风险是系统在它最该谨慎的新奇场景里**既漏报又缺少校准证据**，把开放与节能一起做成虚假的安全感。

## 2. 关键算法（伪代码）

### IP-54 OVG：两级接地 + 保形 + 保守闭包
```
def ground_guard(x, concept_c, calib, tau, r_max, alpha):
    w = vlm_weights(c, x)                     # 开放：学习组件，仅产生基权重
    r = 1 - sum(w[k] for k in range(K) if w[k] >= tau)
    if r > r_max or novelty_score(c, calib) > d_max:
        return Guard(c, status="UNKNOWN")    # 单调保守：只能降级
    kset = [k for k in range(K) if w[k] >= tau]
    m_c = min(certified_margin(x, k) for k in kset)   # 闭合：已认证边际
    eps = conformal_radius(c, kset, calib, alpha)     # Mondrian 分组校准
    return Guard(c, margin=m_c - eps - theta[c],
                 coverage=1 - alpha, eps=eps, kset=kset)

def conservative_closure(guard, eps_ball):
    # 对 eps 球内所有可行接地取最坏，得到 R̄_c
    return worst_over(eps_ball, lambda g: {x: G(x, g) < 0})
```

### IP-55 ECE：ROI 紧致度 + EOQ 重认证 + 速度协同
```
def choose_tightness(guards, t_sf):
    # 每个守卫给出 E_m(t), E_c(t)，按总能量最小求 t*
    t = argmin_t (sum(E_m_i(t) + E_c_i(t)) for i in guards if t >= t_sf)
    return t                                  # 内点 E_m'+E_c'=0，否则 t_sf

def choose_tier(tiers, tau_min):
    # a_j=单次认证焦耳，H_j=保持时间
    return min(tiers, key=lambda j: a_j/H_j if H_j >= tau_min else +inf)

def energy_optimal_speed(p_act, grad_m, a, m0, theta):
    # f(v)=p_act(v)/v + a*||grad_m||/((m0-theta)*v^2)
    return argmin_v f(v)                      # 反平方项=EOQ 连续版

def power_bound(concept_c, closure):
    return max(P(terrain(c2), v) for c2 in closure)   # 悲观：保证 e 不低于证书
```

### IP-56 COVM：保形开放看门狗
```
def compile_open_guard(g_c, alpha, dtype=fixed):
    circuit = interval_arith(g_c, dtype)
    cov     = conformal_pvalue_circuit(g_c, alpha)
    nov     = novelty_score_circuit(g_c)
    return Monitor(circuit, cov, nov,
                   trip_if = lower(circuit) < theta_c or cov < alpha
                             or nov > d_max,
                   wcet = bound_wcet(circuit), mem = bound_mem(circuit))

def watch(M, obs, energy):
    s = M.step(obs)
    if s == TRIP or energy < e_stop(obs) + e_reserve:
        automaton.force(SAFE_STOP)            # 单边可靠：不确定或能量不足即停
```

## 6. 本轮最大风险

**一句话**：开放词汇的保形保证只是**边际覆盖**而非条件覆盖，一旦遇到标定外概念或分布偏移，「1−α」会悄悄失效，而能耗优化又会诱导系统在省电方向放宽操作与重认证——两者叠加，最大风险是系统在它最该谨慎的新奇场景里**既漏报又缺乏校准证据**，把开放与节能一起做成虚假的安全感。
