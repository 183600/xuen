# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 8 轮；本轮灵感：「因果推理」×「数据采集」）

> 第 61 轮用 USR×MEL×DMS×SRT-Dual×PCE+++++ 把「场景—意图—约束—阻抗—证据」统一进语义向量空间，解决了表征割裂、零样本物理推断、多轮对话与语义-实时时序解耦。但它建立在**相关性学习**之上，留下四个更深的局限：
> 1. **相关而非因果**：MEL 从 D_sim 中学到的是 `P(φ_phys | V,T,P)` 的观测相关性，USR 的 ℒ_align 同样是相关性对齐。材质纹理既影响视觉又影响摩擦，形成混淆；一旦分布移动或机器人主动干预，相关关系失效，模型却仍高置信。
> 2. **数据采集是被动的**：真实交互样本由「任务恰好经过哪里」决定，长尾事件（滑移、脆性断裂、低摩擦）极少被采到；域随机化只能覆盖想象得到的变化。缺少「为了识别因果量而主动设计实验」的能力——机器人不会问「我该先做哪个探针动作，才能最快分辨 μ 与 k？」
> 3. **失败归因是启发式的**：第 61 轮 EFGP 用「检测到滑移⇒降低 K_p」这类规则做反应，这是相关性的条件反射，不是因果归因。真实根因可能是低摩擦、传感器偏置、法向力不足或 K_p 过高；不做反事实就不能区分。
> 4. **证书不含因果有效性**：J_sem_exec 只证明「语义一致 + 执行证据完整」，不证明「当前约束在因果上安全」。高 C_sem 与安全之间没有必然联系，混淆因子可以让系统在语义上自洽却物理上危险。

## 0. 直觉与动机

**灵感 1（因果推理 → 具身结构因果模型 ESCM）**
直觉：机器人对世界的理解不应是一张「输入-输出」回归表，而应是一组**可干预、可反事实的结构方程**。把物理交互写成 SCM：材质 M 决定摩擦 μ 与刚度 k；阻抗 K 与位置 x 决定法向力 N；N、μ、K 共同决定切向力 F 与滑移 S；视觉 O_vis 同时受 M 与光照 L 影响，因此 **L 是 O_vis 与 μ 之间的混淆因子**——只做观测回归会把「光照暗⇒低摩擦」学成虚假规律。有了 SCM，`do(K=k')` 与「反事实：若当时用 k' 会怎样」都能形式化；MEL 的物理推断从 `P(φ|O)` 升级为 `P(φ|do(...), O)`，估计的是机制而非关联。

**灵感 2（因果推理 → 因果不变表征 CIR）**
直觉：sim2real 的根问题不是「数据不够多」，而是**学到的特征里混入了不随机制迁移的虚假相关**。因果不变表征要在多个环境 e∈E（仿真、不同真实工位、不同光照）中寻找 Φ，使 `P(Y | Φ(X), do(A))` 在环境间不变；只保留「机制稳定」的维度，主动丢弃随环境漂移的纹理/光照/背景。这样第 61 轮的零样本能力不再依赖域随机化「碰巧覆盖」，而是由**不变性**提供可检验的泛化保证。

**灵感 3（数据采集 → 主动因果数据采集 ACDC）**
直觉：既然数据昂贵且危险，就应该把每一次真实交互当作**一次实验设计**。机器人当前对 θ=(μ,k,η,σ) 有后验；候选探针动作 a（法向力扫描、切向轻推、轻敲、慢速拖拽、抬升）会以不同方式改变后验。选择使**期望信息增益 EIG(a)=I(θ;Y_a|D_t)** 最大、同时满足安全包络与预算的动作，这就是主动学习版的「数据采集」。它把「被动攒数据」变成「为了回答某个因果问题而做最小必要干预」。

**灵感 4（数据采集 → 因果分层经验回放 CLB 与采集协议 DCP）**
直觉：采集到的数据不是同质的。要按**因果 regime**（材质类 × 接触模式 × 速度档）分层存储，并给每条样本打上「是否干预、do 记录、传感器校准、来源哈希」。回放优先级不仅看 TD 误差，还看**稀有度、因果覆盖增益、数据价值 VOI**。采集协议则规定：哪些探针允许、安全包络多大、任务与探针如何交织、何时停止（EIG 低于阈值或预算耗尽）。

**灵感 5（合流 → 反事实安全护栏 CFS 与因果证据证书 CEC）**
直觉：实时控制来不及跑完整 SCM，但可以训练一个**反事实安全代理** g_φ(e,K)≈P(执行 K 后 F 超限/滑移/振动 | 证据 e)。每次派发前先问「若执行 K，反事实地会不会出事？」；若不安全，就在 K 空间投影到满足 `g_φ ≤ α-ε` 的最近点，找不到则回退保守约束。证书 CEC 在 J_sem_exec 之上追加因果图哈希、可识别性状态、do 轨迹、反事实安全裕度与数据来源，使「安全」从语义一致性升级为**因果可审计**。

**灵感 6（预算 → PCE++++++ 八维认知-因果-数据预算）**
直觉：主动探针要消耗真实时间、磨损与安全风险，因果推断要消耗图更新与反事实采样。把第 61 轮 B_cog5 扩展为 **B_cog6 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_causal, B_data)**：B_causal 管图更新/干预样本/反事实查询/可识别性容差；B_data 管探针次数/存储/标注/稀有事件配额。VOI 也扩展为 `voi_cog6 = voi_cog5 + VOI_causal + VOI_data - cost_probe - cost_store`；任一预算耗尽时**只降级学习与探索，不降级硬安全**。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（具身结构因果模型 ESCM）** M = (V, U, F, P(U), G, Θ)。其中：
- **变量三分**：V = V_O ∪ V_L ∪ V_A
  - V_O：可观测量（O_vis, O_tac, O_prop, F_contact, S_slip, Vib）
  - V_L：潜在物理量（M_material, μ_fric, k_stiff, η_damp, σ_brittle, N_normal）
  - V_A：干预/动作量（K_p, K_d, F_max, x_cmd）
- **外生变量**：U = {U_i}，P(U)=∏P(U_i)，捕捉未建模扰动与个体差异
- **结构方程**：每个 V_i = f_i(pa(V_i), U_i)，例如
  ```
  μ = f_μ(M, texture, U_μ)
  N = f_N(K_p, x_cmd, U_N)
  F = f_F(N, K_p, x_cmd, μ, U_F)
  S = 1[F_tangential > μ·N]
  Vib = f_Vib(k, η, v_cmd, U_vib)
  O_vis = f_O(M, lighting, U_vis)      # lighting 为混淆因子
  ```
- **因果图**：G 为有向无环图，混淆因子用双向边表示（M ↔ lighting → O_vis）
- **干预**：do(V_j=v) 删去指向 V_j 的边并令 f_j≡v（图手术）
- **反事实三步**：① 溯因 U* ~ P(U|E=e)；② 干预 G_{do(V_j=v')}；③ 预测 V' = F_{do(v')}(U*)
- **可识别性状态**：Θ_id ∈ {identified, bounded, unidentified}，由定义 183 判定

**定义 174（因果不变表征 CIR）** 给定环境集合 E（仿真 + 多个真实工位），学习 Φ: Obs → ℝ^d_c，使
```
∀e∈E: P_e(Y | Φ(X), do(A)) = P_{e'}(Y | Φ(X), do(A))
```
优化目标：
```
ℒ_CIR = Σ_e ℒ_e(Φ) + λ_var·Var_e(ℒ_e(Φ)) + λ_irm·Σ_e ‖∇_{w=1} ℒ_e(w·Φ)‖² + λ_sp·I(Z_spur; Y | Φ(X))
```
其中 Z_spur（光照、纹理、背景）为待压制维度；环境标签来自工位/日期/光照分组。CIR 只允许机制稳定的维度进入 USR，从而把第 61 轮的「语义嵌入」升级为「因果不变语义嵌入」。

**定义 175（主动因果数据采集 ACDC）** 数据采集被建模为贝叶斯实验设计：
- **状态**：s_data = (D_t, p(θ|D_t), B_data, task_context)，θ=(μ,k,η,σ, 图结构 G)
- **动作**：a ∈ A_probe ∪ {no_probe}，A_probe 见定义 180
- **期望信息增益**：
  ```
  EIG(a) = I(θ; Y_a | D_t) = H(θ|D_t) - E_{y~P(y|do(a),D_t)}[H(θ | D_t ∪ {(a,y)})]
  ```
- **选择规则**：
  ```
  a* = argmax_{a∈A_safe} [ EIG(a) - λ_c·cost(a) - λ_r·Risk(a) ]
  s.t. Risk(a) ≤ ε_probe, cost(a) ≤ B_data.remaining
  ```
- **停止规则**：EIG(a*) ≤ θ_eig 或 B_data 耗尽或任务截止；等价于 VOI_data(a*) ≤ cost(a*)（定义 184）

**定义 176（反事实安全护栏 CFS）** 对候选阻抗 K 与证据 e：
```
p_unsafe(K) = P_{U*~p(U|e)}[ ∃t∈[0,H]: F_t(K,U*) > F_max ∨ S_t(K,U*)=1 ∨ Vib_t(K,U*) > τ_vib ]
SafeCF(K) ⇔ p_unsafe(K) ≤ α_cf
```
实时实现用代理 g_φ(e,K)，并给出校准误差界：
```
|g_φ(e,K) - p_unsafe(K)| ≤ ε_cf   （在独立校准集上以 1-δ 成立）
```
若 `g_φ > α_cf - ε_cf`，执行投影：
```
K_proj = argmin_{K'∈K_space} ‖K' - K‖  s.t. g_φ(e,K') ≤ α_cf - ε_cf
```
无可行解则回退 K_cons（仅由 ERTC 硬限构造的保守约束）。CFS 的硬限部分永不因学习模块降级而放松。

**定义 177（因果证据证书 CEC）** 扩展 J_sem_exec：
```
CEC = ( J_sem_exec,
        G_hash,                 # 因果图版本哈希
        Θ_id,                   # identified / bounded / unidentified
        I_do,                   # 干预记录（探针动作 + 时间戳）
        p_unsafe,               # 反事实不安全概率
        cf_margin = α_cf - p_unsafe,
        D_prov,                 # 数据来源的哈希链
        CIR_version )
Valid(CEC) ⇔ Valid(J_sem_exec) ∧ Θ_id ∈ {identified, bounded}
             ∧ cf_margin ≥ τ_cf ∧ provenance_chain_ok(D_prov)
             ∧ coverage(D_prov) ≥ τ_cov
```
若 Θ_id=bounded，要求**上界** U(p_unsafe) ≤ α_cf；若 Θ_id=unidentified，证书不通过，CFS 只能使用保守硬限。

**定义 178（因果分层经验回放 CLB）** 样本
```
d_i = (o_i, a_i, r_i, o'_i, c_i, i_i, regime_i, τ_i, prov_i, w_i)
```
- regime_i ∈ M_material × ContactMode × SpeedBin（因果分层）
- 优先级：`p_i = α|δ_TD| + β·Rarity(regime_i) + γ·CovGain(regime_i) + δ·VOI_data(d_i)`
- 采样概率 `P(i) ∝ p_i^η / Σ_j p_j^η`，配合重要性权重 w_i
- 去重：因果签名 sig_i = hash(pa(V) 的离散化值)，距离 < ε_dup 视为重复
- 容量与逐出受 B_data 约束，按「价值密度 VOI/字节」逐出

**定义 179（因果根因诊断与信用分配 CRA）** 对失败谓词 Y_f、证据 e、候选原因 v：
```
Blame(v) = E_{U*~p(U|e)}[ Y_f(do(v=v_alt), U*) ] - Y_f(e)
```
- 根因集合 R = { v : |Blame(v)| ≥ θ_blame 且 v 可识别 }
- 归因解释供 DMS 使用：「失败主因是 μ 偏低（blame=0.62），而非 K_p 过高（blame=0.08）」
- RL 信用分配用反事实基线：A(s,a) = Q(s,a) - E_{a'~π}[Q(s,do(a'))]
- 与第 61 轮 EFGP 的区别：EFGP 是「看到滑移⇒降 Kp」的相关反射；CRA 先估计 `P(S|do(K_p))` 再决定是否降 Kp

**定义 180（数据采集协议 DCP）** Π_data = (A_probe, E_safe, S_sched, M_meta, Stop)：
- **探针库**：A_probe = {normal_force_sweep, tangential_probe, tap_test, slow_drag, lift_test, rotate_test}
- **安全包络**：F ≤ F_max^probe、v ≤ v_max^probe、τ ≤ τ_max^probe、|Δpose| ≤ δ_pose，且每个探针必须先过 CFS
- **调度**：信息导向交织——每 N_task 步或后验熵 > H_thresh 时插入探针；高风险探针只在任务空闲期执行
- **元数据 schema**：`(timestamp, frame_id, pose, wrench, action_id, do_record, sensor_calib, material_guess, regime, quality_flags, provenance_hash)`
- **停止**：EIG < θ_eig ∨ B_data 耗尽 ∨ 任务截止 ∨ 连续 K 次探针无信息增益

**定义 181（PCE++++++ 八维认知-因果-数据预算）** B_cog6 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_causal, B_data)：
- **B_causal** = (Graph_updates, Interventional_samples, CF_queries, Identifiability_tol)
- **B_data** = (Probe_budget, Storage_capacity, Label_budget, Rare_event_quota)
- **成本**：
  ```
  cost_cog6 = cost_cog5
            + λ_cf·(CF_queries/H_cf + EIG_est_cost)
            + λ_probe·(Probe_count/B_probe)
            + λ_store·(Storage_used/B_storage)
  ```
- **价值**：`voi_cog6 = voi_cog5 + VOI_causal + VOI_data - cost_probe - cost_store`
- **降级（学习降级、安全不降级）**：
  - B_data 耗尽 → 停止探针、冻结 CLB、使用缓存 CIR；任务继续
  - B_causal 耗尽 → 冻结因果图与反事实查询；CFS 退化为「上次校准代理 + 扩大 ε_cf + 硬限」，不信任过期因果模型
  - B_mel/B_usr 耗尽 → 沿用第 61 轮降级链

**定义 182（因果语义进化闭环 CSEC）** CSEC = (ESEC, DataLoop, CausalLoop, CFS, CEC)：
- **语义流（~10–100Hz）**：MEL + USR + DMS（承接第 61 轮）
- **因果-数据流（~0.1–1Hz，可异步）**：ACDC 选探针 → DCP 安全执行 → CLB 存储 → ESCM/CIR 更新
- **实时流（~1–10kHz）**：EEIS 编译 → CFS 反事实校验/投影 → ERTC 派发
- **闭环**：`MEL→USR→EEIS→执行→EV_exec→CLB→ESCM→CRA→DMS→约束更新`，且 `ACDC→探针→新证据→ESCM/CIR→MEL`

**定义 183（因果可识别性判定）** 对目标量 `P(V|do(K))`：
- **可识别（identified）**：存在满足后门准则的调整集 Z（`Z` 阻断 K 与 V 的所有后门路径），且正性 `0<P(K=k|Z)<1` 成立；或前后门/工具变量条件成立。例如以探针动作 a 作为工具变量，隔离「材质 M」这一潜在混淆。
- **有界（bounded）**：仅能部分识别，用 Balke–Pearl 给出区间 [L,U]；CFS 用 U 做最坏情况判断
- **不可识别（unidentified）**：无有效调整集且无工具变量；此时**禁止**用模型宣称安全，只能使用硬限
- 关键工程约束：**任何 CFS 结论必须携带 Θ_id 与所用调整集**；证书校验器拒绝未声明可识别性的反事实结论

**定义 184（数据价值 VOI_data）** 对采集动作 a：
```
VOI_data(a|D_t) = E_{y~P(y|do(a),D_t)}[ L(θ_{D_t}) - L(θ_{D_t∪{(a,y)}}) ]
```
其中 L 为「期望任务损失 + 安全风险」。采集规则：
```
collect(a) ⇔ VOI_data(a) > cost(a) + λ_r·Risk(a)
```
性质：VOI_data 随 |D_t| 单调不增（边际收益递减）；对 regime 覆盖是子模的，因此贪心 EIG 有 (1-1/e) 近似保证（在子模近似下）。

## 2. 关键算法伪代码

### IP-183 ESCM（具身结构因果模型）

```python
class EmbodiedStructuralCausalModel:
    def __init__(self, graph, structural_eqs, prior):
        self.G = graph                    # DAG over V_O ∪ V_L ∪ V_A
        self.f = structural_eqs           # dict: V_i -> f_i(pa, u_i)
        self.prior = prior                # P(U)
        self.posterior_U = None
        self.theta_id = 'unidentified'

    def abduction(self, evidence):
        """溯因：由证据反推外生变量后验 U* ~ P(U|E=e)"""
        self.posterior_U = self._infer_exogenous(evidence)   # 变分/粒子推断
        return self.posterior_U

    def do(self, var, value):
        """图手术：删去指向 var 的边，令 f_var ≡ value"""
        return self.G.mutilate(var, value)

    def counterfactual(self, evidence, intervention, horizon=50):
        U = self.abduction(evidence)
        G_do = self.do(*intervention)
        return self._rollout(G_do, U, horizon)

    def p_unsafe(self, evidence, K, n=256, horizon=50):
        """反事实不安全概率（离线/低频，供 CFS 校准）"""
        samples = [self.counterfactual(evidence, ('K', K), horizon)
                   for _ in range(n)]
        return np.mean([self._violates(s, K) for s in samples])

    def identify(self, target, treatment):
        """返回 (Theta_id, adjustment_set, [L,U])"""
        Z = self.G.backdoor_set(treatment, target)
        if Z is not None and self.G.positivity(treatment, Z):
            return 'identified', Z, None
        iv = self.G.instrumental_variable(treatment, target)
        if iv is not None:
            return 'identified', {'iv': iv}, None
        bounds = self.G.partial_identify(treatment, target)   # Balke-Pearl
        return ('bounded', None, bounds) if bounds else ('unidentified', None, None)
```

### IP-185 ACDC（主动因果数据采集）

```python
class ActiveCausalDataCollector:
    def __init__(self, escm, cir, probe_lib, cfs, budget):
        self.escm, self.cir = escm, cir
        self.probes = probe_lib
        self.cfs = cfs
        self.budget = budget
        self.lam_c, self.lam_r = 0.2, 1.0
        self.theta_eig = 0.05

    def eig(self, a, D_t, n=64):
        """EIG(a) = H(θ|D) - E_y[H(θ|D∪{(a,y)})]，嵌套蒙特卡洛估计"""
        H_prior = self.escm.entropy()
        ys, ws = self._predictive_sample(a, D_t, n)
        H_post = sum(w * self.escm.entropy_after(D_t, a, y)
                     for y, w in zip(ys, ws))
        return H_prior - H_post

    def select(self, context, D_t):
        best, best_u = None, -np.inf
        for a in self.probes:
            if not self.cfs.safe_probe(a, context):
                continue
            if not self.budget.can_probe(a):
                continue
            u = (self.eig(a, D_t)
                 - self.lam_c * a.cost
                 - self.lam_r * self.cfs.probe_risk(a, context))
            if u > best_u:
                best, best_u = a, u
        if best is None or best_u <= self.theta_eig:
            return None                      # 停止采集
        if self.budget.voi_data(best) <= best.cost:
            return None                      # VOI 不足
        return best

    def update(self, a, y):
        self.escm.posterior_update(a, y)
        self.cir.update_with_intervention(a, y)
        self.budget.consume('data', a.cost)
```

### IP-186 CFS（反事实安全护栏）

```python
class CounterfactualSafetyShield:
    def __init__(self, surrogate, escm, alpha_cf=0.01, eps_cf=0.005):
        self.g = surrogate                 # 蒸馏反事实头，~0.05ms
        self.escm = escm
        self.alpha, self.eps = alpha_cf, eps_cf
        self.hard_limits = ERTCHardLimits()

    def check(self, evidence, K):
        if not self.hard_limits.satisfied(K):
            return False, 1.0
        p = self.g(evidence, K)
        return p <= self.alpha - self.eps, p

    def project_safe(self, evidence, K, steps=8):
        """沿 K 空间正交方向二分投影到 {g ≤ α-ε}"""
        lo, hi = 0.0, 1.0
        K_cons = self.hard_limits.conservative()
        for _ in range(steps):
            mid = (lo + hi) / 2
            K_mid = (1 - mid) * K + mid * K_cons
            ok, _ = self.check(evidence, K_mid)
            if ok: lo = mid
            else:  hi = mid
        return (1 - lo) * K + lo * K_cons

    def guard(self, evidence, K):
        ok, p = self.check(evidence, K)
        if ok:
            return K, p, 'accepted'
        K_proj = self.project_safe(evidence, K)
        ok2, p2 = self.check(evidence, K_proj)
        if ok2:
            return K_proj, p2, 'projected'
        return self.hard_limits.conservative(), 1.0, 'fallback'
```

```python
class CausalLayeredBuffer:
    def __init__(self, capacity, budget):
        self.capacity = capacity
        self.budget = budget
        self.regimes = defaultdict(list)
        self.sig_index = {}

    def push(self, transition, intervention, regime, provenance):
        sig = causal_signature(transition, intervention)
        if self._near_duplicate(sig):
            return False
        item = BufferItem(transition, intervention, regime, provenance,
                          priority=self._initial_priority(regime))
        self.regimes[regime].append(item)
        self.sig_index[sig] = item
        self._evict_if_needed()
        return True

    def sample(self, n):
        strata = list(self.regimes)
        per = max(1, n // len(strata))
        out = []
        for r in strata:
            items = self.regimes[r]
            p = np.array([it.priority ** self.eta for it in items])
            idx = np.random.choice(len(items), min(per, len(items)),
                                   p=p / p.sum())
            out += [items[i] for i in idx]
        return out

    def coverage(self):
        return len([r for r in self.regimes if len(self.regimes[r]) >= 5]) \
               / max(1, len(ALL_REGIMES))
```

### IP-183 ESCM（具身结构因果模型）

```python
class EmbodiedStructuralCausalModel:
    def __init__(self, graph, structural_eqs, prior, horizon=50):
        self.G = graph                     # DAG over V_O ∪ V_L ∪ V_A
        self.f = structural_eqs            # V_i -> f_i(pa(V_i), U_i)
        self.prior = prior                 # P(U)
        self.posterior_U = None
        self.theta_id = 'unidentified'
        self.G_hash = graph.content_hash()
        self.horizon = horizon

    def abduction(self, evidence):
        """溯因：由证据反推外生变量后验 U* ~ P(U|E=e)"""
        self.posterior_U = self._infer_exogenous(evidence)   # 粒子/变分推断
        return self.posterior_U

    def do(self, var, value):
        """图手术：删去指向 var 的边，并令 f_var ≡ value"""
        return self.G.mutilate(var, value)

    def counterfactual(self, evidence, intervention):
        U = self.abduction(evidence)
        G_do = self.do(*intervention)
        return self._rollout(G_do, U, self.horizon)

    def p_unsafe(self, evidence, K, n=256):
        """反事实不安全概率（离线/低频，供 CFS 代理校准）"""
        viol = []
        for _ in range(n):
            traj = self.counterfactual(evidence, ('K', K))
            viol.append(self._violates(traj, K))
        return float(np.mean(viol))

    def identify(self, target, treatment):
        """返回 (Theta_id, adjustment_set, bounds)"""
        Z = self.G.backdoor_set(treatment, target)
        if Z is not None and self.G.positivity(treatment, Z):
            return 'identified', Z, None
        iv = self.G.instrumental_variable(treatment, target)
        if iv is not None:
            return 'identified', {'iv': iv}, None
        bounds = self.G.partial_identify(treatment, target)   # Balke–Pearl
        if bounds is not None:
            return 'bounded', None, bounds
        return 'unidentified', None, None

    def entropy(self):
        return self.posterior_U.entropy()

    def entropy_after(self, D, a, y):
        return self._posterior_update(D, a, y).entropy()

    def posterior_update(self, a, y):
        self.posterior_U = self._bayes_update(self.posterior_U, a, y)
        self.G.update_structure(a, y)          # 仅在通过可识别性检验后加边
        return self.posterior_U
```

```python
    def fit(self, epochs=50):
        for _ in range(epochs):
            losses = {}
            for e, data in self.envs.items():
                losses[e] = self._env_loss(e, data)
            mean = np.mean(list(losses.values()))
            var = np.var(list(losses.values()))
            irm = sum(self._irm_penalty(e) for e in self.envs)
            sp = self._spurious_mi_penalty()
            loss = mean + self.lam_var * var + self.lam_irm * irm + self.lam_sp * sp
            self._step(loss)
        self.version += 1
        return self._invariance_report()

    def _invariance_report(self):
        """跨环境 P(Y|Φ,do(A)) 的差异检验；失败的环境对标记为漂移"""
        return {pair: self._ks_test(pair) for pair in self._env_pairs()}

    def update_with_intervention(self, a, y):
        """干预数据只用于验证/收紧不变性，不直接拟合虚假相关"""
        self.envs.setdefault('probe', []).append((a, y))
        self.version += 1
```

```python
class ActiveCausalDataCollector:
    def __init__(self, escm, cir, probe_lib, cfs, budget,
                 lam_c=0.2, lam_r=1.0, theta_eig=0.05):
        self.escm, self.cir = escm, cir
        self.probes = probe_lib
        self.cfs = cfs
        self.budget = budget
        self.lam_c, self.lam_r = lam_c, lam_r
        self.theta_eig = theta_eig
        self.D = []

    def eig(self, a, n=64):
        """EIG(a) = H(θ|D) - E_y[H(θ|D∪{(a,y)})]，嵌套蒙特卡洛"""
        H_prior = self.escm.entropy()
        ys, ws = self._predictive_sample(a, n)
        H_post = sum(w * self.escm.entropy_after(self.D, a, y)
                     for y, w in zip(ys, ws))
        return H_prior - H_post

    def select(self, context):
        best, best_u = None, -np.inf
        for a in self.probes:
            if not self.cfs.safe_probe(a, context):
                continue
            if not self.budget.can_probe(a):
                continue
            u = (self.eig(a)
                 - self.lam_c * a.cost
                 - self.lam_r * self.cfs.probe_risk(a, context))
            if u > best_u:
                best, best_u = a, u
        if best is None or best_u <= self.theta_eig:
            return None
        if self.budget.voi_data(best) <= best.cost:
            return None
        return best

    def update(self, a, y):
        self.D.append((a, y))
        self.escm.posterior_update(a, y)
        self.cir.update_with_intervention(a, y)
        self.budget.consume('probe', 1.0)

    def _predictive_sample(self, a, n):
        """在 do(a) 下采样 (y, 权重)，用于 EIG 的嵌套估计"""
        return self.escm.sample_do(a, n)
```

### IP-186 CFS（反事实安全护栏）

```python
class CounterfactualSafetyShield:
    def __init__(self, surrogate, escm, alpha_cf=0.01, eps_cf=0.005):
        self.g = surrogate                 # 蒸馏反事实头，~0.05ms
        self.escm = escm
        self.alpha, self.eps = alpha_cf, eps_cf
        self.hard_limits = ERTCHardLimits()  # 独立、不可覆盖
        self.calibrated = True

    def check(self, evidence, K):
        if not self.hard_limits.satisfied(K):
            return False, 1.0
        p = self.g(evidence, K)
        return p <= self.alpha - self.eps, p

    def project_safe(self, evidence, K, steps=8):
        """沿 K→K_cons 连线二分，投影到 {g ≤ α-ε}"""
        lo, hi = 0.0, 1.0
        K_cons = self.hard_limits.conservative()
        for _ in range(steps):
            mid = (lo + hi) / 2
            K_mid = (1 - mid) * K + mid * K_cons
            if self.check(evidence, K_mid)[0]:
                lo = mid
            else:
                hi = mid
        return (1 - lo) * K + lo * K_cons

    def guard(self, evidence, K):
        ok, p = self.check(evidence, K)
        if ok:
            return K, p, 'accepted'
        K_proj = self.project_safe(evidence, K)
        ok2, p2 = self.check(evidence, K_proj)
        if ok2:
            return K_proj, p2, 'projected'
        return self.hard_limits.conservative(), 1.0, 'fallback'

    def safe_probe(self, a, context):
        """探针本身也要过反事实安全，高风险探针只在空闲期执行"""
        K_probe = a.as_impedance()
        ok, _ = self.check(context, K_probe)
        return ok and a.risk(context) <= context.probe_risk_budget

    def degrade_if_untrusted(self):
        """因果预算耗尽：扩大裕度，禁止信任过期因果模型"""
        if not self.calibrated:
            self.eps = min(0.5, self.eps * 2.0)
```

### IP-188 CLB（因果分层经验回放）

```python
class CausalLayeredBuffer:
    def __init__(self, capacity, budget, eta=0.6, eps_dup=0.05):
        self.capacity = capacity
        self.budget = budget
        self.eta, self.eps_dup = eta, eps_dup
        self.regimes = defaultdict(list)
        self.sig_index = {}

    def push(self, transition, intervention, regime, provenance):
        sig = self._causal_signature(transition, intervention)
        if sig in self.sig_index:
            self.sig_index[sig].hits += 1
            return False
        item = BufferItem(transition, intervention, regime, provenance,
                          hits=1, priority=self._initial_priority(regime))
        self.regimes[regime].append(item)
        self.sig_index[sig] = item
        self.budget.consume('store', item.nbytes)
        self._evict_if_needed()
        return True

    def sample(self, n):
        strata = [r for r in self.regimes if self.regimes[r]]
        if not strata:
            return []
        per = max(1, n // len(strata))
        out = []
        for r in strata:
            items = self.regimes[r]
            p = np.array([it.priority ** self.eta for it in items])
            k = min(per, len(items))
            idx = np.random.choice(len(items), k, p=p / p.sum())
            out += [items[i] for i in idx]
        return out

    def coverage(self):
        covered = sum(1 for r in ALL_REGIMES if len(self.regimes.get(r, [])) >= 5)
        return covered / len(ALL_REGIMES)

    def provenance_chain(self):
        return self._hash_chain

    def _causal_signature(self, transition, intervention):
        pa = transition.parent_values()          # 父变量离散化
        return hashlib.sha256(
            (str(intervention) + str(pa)).encode()).hexdigest()[:16]

    def _evict_if_needed(self):
        while self._size() > self.capacity:
            regime = min(self.regimes, key=lambda r: self._value_density(r))
            items = self.regimes[regime]
            victim = min(items, key=lambda it: it.priority)
            items.remove(victim)
            self.sig_index.pop(victim.sig, None)
```

### IP-189 CRA（因果根因诊断与信用分配）

```python
class CausalRootCauseAttribution:
    def __init__(self, escm, theta_blame=0.1):
        self.escm = escm
        self.theta_blame = theta_blame

    def blame(self, evidence, failure_pred):
        """对每个候选原因 v 做反事实对比"""
        base = self.escm.evaluate(evidence, failure_pred)
        out = {}
        for v in self.escm.candidate_causes(evidence):
            alt = self.escm.safe_alternative(v, evidence)
            cf = self.escm.counterfactual(evidence, (v, alt))
            out[v] = self.escm.evaluate(cf, failure_pred) - base
        return out

    def root_causes(self, evidence, failure_pred):
        B = self.blame(evidence, failure_pred)
        id_status = self.escm.theta_id
        R = {v: b for v, b in B.items()
             if abs(b) >= self.theta_blame and id_status != 'unidentified'}
        return dict(sorted(R.items(), key=lambda kv: -abs(kv[1])))

    def counterfactual_advantage(self, s, a, pi):
        """RL 信用分配：反事实基线而非观测基线"""
        q = self.escm.Q(s, a)
        q_cf = np.mean([self.escm.Q_cf(s, do(a')) for a' in pi.sample(s)])
        return q - q_cf
```

```python
class CausalDataBudget:
    def __init__(self, cocg5,
                 graph_updates=20, interv_samples=100, cf_queries=500, id_tol=0.1,

                           label=label_budget, rare=rare_quota)

        self.mode = {'causal': 'full', 'data': 'full'}

        return (self.mode['data'] != 'frozen'
                and self.used['probe'] + 1 <= self.B_data['probe']
                and self.used['rare'] + a.is_rare <= self.B_data['rare'])

                and eig - a.cost - a.risk >= 0
                and eig > self.b5.theta_eig)
```

```python
def CSEC(M, V, T, P, L, delta_f_req, context):
    # ---- 语义流（承接 ESEC，~10-100Hz）----
    phi_phys, z_scene, pi_intact, U_mel = M.mel.infer(V, T, P, L)
    a_diag, C_pending, b_intent = M.dms.step(U_mel)
    M.anchor = M.usr.commit(z_scene, M.usr.E_intent(b_intent), phi_phys, U_mel)

        y = M.dcp.execute(a_probe)                  # 安全探针
        M.clb.push(y, intervention=a_probe, regime=y.regime,
                   provenance=y.provenance)
        M.acdc.update(a_probe, y)                   # 更新 ESCM + CIR + 预算
        M.budget.consume('cf', estimate_cf_cost(a_probe))

    # ---- 实时流（~1-10kHz）----
    anchor, fresh = M.usr.read_latest_anchor()
    K_prior = (M.usr.project_to_impedance(anchor)
               if fresh else M.cached_prior)
    K_safe = M.eeis.compile(delta_f_req, M.fused, M.xi_exec, M.Z_env,
                            K_prior, phi_phys)

    # 反事实安全护栏：先问再做
    K_safe, p_unsafe, decision = M.cfs.guard(M.evidence, K_safe)

    cert = M.ertc.dispatch(K_safe)
    EV_exec = wait_contact_and_build_evidence()

    # ---- 证据、归因与证书 ----
    M.usr.push_evidence(EV_exec)

               provenance=EV_exec.provenance)
    if EV_exec.failure:
        R = M.cra.root_causes(EV_exec, failure_pred=EV_exec.failure)

    # ---- 预算降级（只降学习/探索）----
    if M.budget.mode['causal'] == 'frozen':
        M.cfs.degrade_if_untrusted()
    if M.budget.mode['data'] == 'frozen':
        M.acdc.freeze()
    return M, K_safe, EV_exec, cec
```

假设 A61–A70 及 **(A71)** ESCM 的观测集对目标充分，或潜在混淆已用后门/前门/工具变量处理；图无环且满足忠实性。**(A72)** CIR 的环境集合覆盖至少两种机制不同的真实工位，不变性检验显著性水平 α_inv。**(A73)** ACDC 的 EIG 估计量一致，安全动作集在预算内非空。**(A74)** CFS 代理校准误差 ≤ ε_cf，硬限模块独立于学习模块、不可被覆盖。**(A75)** CEC 哈希链与数据来源完整，可识别性声明与所用调整集一致。**(A76)** 预算单调消耗；B_causal/B_data 耗尽只冻结学习与探索，不放松硬安全。

1. **因果可识别性**：Θ_id=identified 时 `P(V|do(K))` 可一致估计；Θ_id=bounded 时真实值落在 [L,U] 内，且 CFS 使用上界 U 判定。
