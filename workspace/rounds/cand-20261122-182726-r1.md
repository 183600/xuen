# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「实时控制」×「语音合成」）

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v20+IP-420–424（v20 完整方案）。
> 本轮纪律：**实时是证书的时序语义、合成是证书的分层生成**。不推倒 v20：v20 的 PCA/CTS/CFC/HPC/CFCtrl 与 v19 的 DCM/OGCC/CCV/DRS/OGC、v17 的 CLP/S2C/HCG/PSV/APS/AMC 全部保留。本轮只做一件事：**把“证书的生成与消费”改写为一个带截止期、可流式合成、可优雅降级的安全过程**。

## 0. 直觉与动机

**灵感 1（实时控制 → 证书不是静态谓词，而是时间契约）**
直觉：传统安全证书被当作“若 θ∈Θ_safe 则安全”的永恒命题；但证书有签发时刻、计算延迟、抖动与过期。实时控制的核心不是“算得更快”，而是“时间本身进入安全语义”：迟到的证书与错误的证书同样危险。v20 的 HPC 已有 τ_consensus 与 TTL，但它把超时当作“回退开关”，没有把延迟、抖动、截止期作为一等安全量。核心创新：**实时证书契约 (Real-Time Certificate Contract, RTCC)**。每张证书携带 `(Θ_cert, t0, H, J_max, ℓ, C_fb)`：签发时刻 t0、有效视界 H、最坏可容忍抖动 J_max、降级层级 ℓ、回退证书 C_fb。执行侧只在 `t−t0 ≤ H` 且 `实测抖动 Ĵ ≤ J_max` 时消费；且安全域随年龄增长按 `margin_stale(Δt)=margin_col_fed+κ·v_max·Δt+½·a_max·Δt²` 收缩。关键反直觉点：**更快的证书不等于更安全的控制；只有带截止期、抖动界与过期语义的证书才可被安全消费**——deadline miss 是安全事件，不是性能事件。

**灵感 2（语音合成 → 证书的分层流式合成，而非一次性求解）**
直觉：TTS 不是“文本→波形”的一步映射，而是 文本→音素→韵律→声学特征→声码器→波形 的分层流水线；现代系统用**流式合成 + 有限前瞻**做到低延迟。安全证书同样可以分层：把任务分解为**安全音素 (certeme)**，用**风险韵律**分配采样预算，再用**声码器式渲染器**把符号安全原子连续化为可执行轨迹。v20 的 CCV 窄相位是“整体求解”，物体/场景一复杂就超时。核心创新：**证书韵律规划器 (Certificate Prosody Planner, CPP)** 与 **流式证书声码器 (Streaming Certificate Vocoder, SCV)**。CPP 把采样预算按风险密度做 Neyman 式分配（“重读”高风险区、压缩低风险区），并保留预算下界防止低风险区被饿死；SCV 用有界前瞻 L 把 certeme 增量渲染为满足速度/加速度约束的轨迹。关键反直觉点：**证书不是越完整越好，而是“在控制节拍内、以可证明的因果性，合成出当前节拍恰好需要的那一块”**——有限前瞻 + 单调对齐比全局最优更安全。

**灵感 3（二者统一 → 任意时间安全阶梯）**
直觉：实时控制提供“时间契约”，语音合成提供“分层流式生成”，二者在**任意时间算法 (anytime algorithm)** 处汇合：计算越多，可证明的安全域可越大（活性越高），但任何时刻中断都必须停在某个**已证明安全**的层级。核心创新：**任意时间证书阶梯 (Anytime Certificate Ladder, ACL)**。层级 `0..L` 的延迟递增、安全域单调扩张但始终 `⊆ 真实安全域`；调度器用**不精确计算模型**（mandatory + optional）保证 mandatory 段必达截止期，optional 段未完成只损失活性。关键反直觉点：**安全不是“全有或全无”，而是“每一层都可安全中断”**——最坏情况不是算不出来，而是算到一半却没有可用的低层级证书。

**三者如何统一**
统一为 **v20 感知证书之上的时序合成层**。v20 回答“给定分布式感知，节点 n 在 θ 下是否零碰撞”；v21 回答“这张证书何时有效、预算给谁、如何增量渲染、算不完怎么办”。RTCC 是契约侧（时间有效性），CPP 是预算侧（风险韵律），SCV 是渲染侧（流式轨迹），ACL 是调度侧（任意时间降级），MTA 是因果侧（单调对齐），JISE 是鲁棒侧（抖动不变包络）。共享状态 `ζ_rt = (cert_contract, prosody_budget, alignment, ladder_level, jitter_est, fallback_cert)`。统一接口：**若 RTCC 有效且 ACL 至少一层完成且 SCV 轨迹落在该层安全域内，则执行；否则回退到已完成的最低层，再否则回退 v20 HPC，再否则回退 v19 保守路径**。

## 1. 研究问题（轮次升级版）

- **Q1（时序契约的保守性）**：`margin_stale(Δt)` 如何同时覆盖感知过期与执行延迟？`H` 与 `J_max` 应由什么在线估计量给出（p99 延迟、时钟偏差、控制周期抖动）？证书过期瞬间如何做到“无扰动切换”到回退证书而不产生轨迹跳变？

- **Q2（风险韵律的采样理论）**：certeme 的粒度如何选，才能既让 CPP 有足够的分层自由度、又不使组合爆炸？Neyman 式预算分配在“风险密度估计本身有误差”时如何保持保守？预算下界 `b_min` 与总预算 `B` 的比值如何影响盲点与活性？

- **Q3（流式合成的因果性）**：单调对齐 `α(k)` 与前瞻 `L` 如何保证第 k 拍输出只依赖 `≤k+L` 的观测，从而不偷看未来？渲染 QP 不可行时，投影回安全域与触发回退之间的优先级如何判定？轨迹平滑性约束（jerk 有界）与安全域收缩如何权衡？

- **Q4（任意时间阶梯的调度与降级）**：在 WCET 估计有误差、CPU 存在争用的条件下，如何用不精确计算模型保证 mandatory 段可调度？层级安全域 `Θ_0⊆…⊆Θ_L` 的单调性如何被强制校验？中断发生在 optional 段任意位置时，如何保证“已完成的最高层”仍可安全执行？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P37）

**P34 时序契约律（Temporal Certificate Contract）**
证书是五元组 `C_rt=(Θ_cert, t0, H, J_max, ℓ, C_fb)`。定义有效消费谓词：
`Valid(C_rt, t, Ĵ) ⇔ (t−t0 ≤ H) ∧ (Ĵ ≤ J_max) ∧ (θ_plan(t) ∈ Θ_cert(t))`，
其中 `Θ_cert(t) = Erode(Θ_cert(t0), margin_stale(t−t0))`，`margin_stale(Δt)=margin_col_fed+κ·v_max·Δt+½·a_max·Δt²`。**过期证书只能触发回退，不能被“就近复用”**；回退证书本身也必须满足同一契约（递归直到 v19 的静态保守证书）。

**P35 风险韵律律（Risk Prosody Budget）**
把待验证参数域分解为 certeme 集合 `{e_i=(R_i, r_i, n_i, deps_i)}`，`r_i` 为区域风险密度（碰撞概率上界或 SDF margin 方差）。预算分配：
`n_i = max(b_min, B · sqrt(r_i) / Σ_j sqrt(r_j))`，并归一化保证 `Σ n_i ≤ B`。
**分配只改变采样密度与估计方差，不改变证书集合的真值**；`b_min` 是防盲点下界，`r_i` 必须用上界而非点估计，保证保守性。certeme 的粒度按“依赖深度 + 参数分辨率”自适应，不追求无限细。

**P36 因果流式律（Causal Streaming Synthesis）**
对齐函数 `α: ℕ→ℕ` 满足单调性 `α(k+1) ≥ α(k)`；第 k 拍只允许读取索引 `≤ α(k)+L` 的 certeme，`L` 为前瞻。渲染器 `R` 输出 `ξ_k = R(e_{≤α(k)+L}, π_{≤α(k)+L})`，并满足 `ξ_k ∈ Θ_ℓ`、速度/加速度/jerk 界。**任何非单调回退（如感知回溯修正）都必须先冻结当前层、再走回退证书，不能在流式通道内“倒带”**。

**P37 任意时间安全律（Anytime Safety Ladder）**
层级 `ℓ=0..L` 满足 `τ_0<…<τ_L` 与 `Θ_0 ⊆ Θ_1 ⊆ … ⊆ Θ_L ⊆ Θ_true`。每层任务拆为 mandatory（保证 `Θ_0`）与 optional（扩张到更高层）。调度采用 EDF + 不精确计算：若 mandatory 满足 `Σ(W_i^mand/T_i) ≤ 1`，则截止期可保证；optional 未完成只降低层级，不破坏安全。**中断安全**：在任意时刻，执行“已完成的最高层”，无完成层则执行 `C_fb`。

## 3. 与基线的接口（如何退化）

- RTCC 失效（时钟不同步/无法估计抖动）⇒ 只接受 `Δt=0` 的即时证书 ⇒ 等价 v20 的 HPC 单次消费（更保守）；
- CPP 失效（风险密度不可估）⇒ 均匀预算 `n_i=B/|E|` ⇒ 等价 v20 的均匀 CCV 采样；
- SCV/MTA 失效（流式渲染不可行）⇒ 整块求解后一次性输出 ⇒ 等价 v20 的窄相位批处理（延迟更高）；
- ACL 失效（调度器不可用）⇒ 只执行 `ℓ=0` 的 mandatory 证书 ⇒ 等价 v20 的最保守路径；
- JISE 失效（抖动界不可估）⇒ 取 `J_max=0` 的瞬时包络 ⇒ 等价 v20 的静态 margin；
- 全部失效 ⇒ 完全回退 v20 HPC，再回退 v19 CCV；
- **安全继承**：RTCC 只收缩消费窗口、CPP 只重分配采样、SCV 只做域内投影、ACL 只选择已完成层、JISE 只做包络交；任意失效都只会让可执行集变小，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19` 由引理 163 保证。

## 4. 预期贡献

1. **实时证书契约**：首次把“证书过期/延迟/抖动”写成可消费谓词与随龄收缩的安全域，使 deadline miss 成为可证明的安全事件而非性能事故；
2. **风险韵律采样**：把 TTS 的韵律/预算思想迁移为 certeme 上的 Neyman 式预算分配，并给出防盲点下界，使采样从“均匀铺满”升级为“按风险重读”；
3. **流式证书声码器**：用单调对齐 + 有界前瞻把符号安全原子增量渲染为满足动力学约束的轨迹，填补“证书求解”与“控制执行”之间的连续化缺口；
4. **任意时间安全阶梯**：把不精确计算模型引入碰撞证书，使任意时刻中断都停在已证明安全的层级，给出 mandatory/optional 的可调度性条件；
5. **抖动不变安全包络**：把执行延迟与感知过期统一为延迟可达集的交，得到对抖动鲁棒的收缩域，并与 v20 的联邦 margin 叠加；
6. **时序合成层闭环**：RTCC+CPP+SCV+MTA+ACL+JISE 构成 v21 时序层，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。

## 5. 本轮最大风险

**一句话**：若把实时性当作可调的性能参数而非安全前提，mandatory 段的 WCET 被低估或跨机器人时钟不同步，证书就会在过期后仍被消费，形成“时序伪安全”；同时风险韵律若缺少预算下界，采样会集中到高风险区而在低风险区制造新的未采样盲点——即“韵律性时序盲区”。

# IP-425 Real-Time Certificate Contract
@dataclass
class RTContract:
    theta_cert: Domain
    t0: float
    H: float
    J_max: float
    level: int
    fallback: "RTContract | None"

class RealTimeCertificateContract:
    def __init__(self, margin_col_fed, kappa=1.0):
        self.margin_col_fed = margin_col_fed
        self.kappa = kappa

    def stale_margin(self, dt, v_max, a_max):
        # 同时覆盖感知过期、执行延迟与运动可达集
        return (self.margin_col_fed
                + self.kappa * v_max * dt
                + 0.5 * a_max * dt * dt)

    def issue(self, theta_cert, level, H, J_max, fallback):
        return RTContract(theta_cert, time.monotonic(),
                          H, J_max, level, fallback)

    def valid(self, c, t, jitter_hat, theta_plan, v_max, a_max):
        dt = t - c.t0
        if dt > c.H:
            return False, "EXPIRED"
        if jitter_hat > c.J_max:
            return False, "JITTER_VIOLATION"
        theta_now = erode(c.theta_cert,
                          self.stale_margin(dt, v_max, a_max))
        if not theta_now.contains(theta_plan):
            return False, "STALE_VIOLATION"
        return True, "OK"

    def consume_or_fallback(self, c, t, jitter_hat, theta_plan,
                            v_max, a_max):
        # 过期证书只能逐级回退，绝不"就近复用"
        while c is not None:
            ok, why = self.valid(c, t, jitter_hat, theta_plan,
                                 v_max, a_max)
            if ok:
                return c, "OK"
            c = c.fallback
        return None, "NO_VALID_CERT"


# IP-426 Certificate Prosody Planner
class CertificateProsodyPlanner:
    def __init__(self, b_min=8, max_depth=4):
        self.b_min = b_min
        self.max_depth = max_depth

    def build_certemes(self, domain, risk_density, deps):
        # 自适应粒度：依赖越深越粗，参数分辨率越高越细
        certemes = []
        for region in adaptive_partition(domain,
                                         max_depth=self.max_depth,
                                         deps=deps):
            r_i = risk_density.upper_bound(region)   # 必须用上界
            certemes.append(Certeme(region, r_i, 0, deps))
        return certemes

    def allocate(self, certemes, B):
        # Neyman 式：n_i ∝ sqrt(r_i)，再用下界做 water-filling 归一
        weights = [math.sqrt(max(1e-12, e.r_i)) for e in certemes]
        total_w = sum(weights)
        n = [max(self.b_min, B * w / total_w) for w in weights]
        return self._waterfill_floor(n, B)

    def _waterfill_floor(self, n, B):
        # 在 Σn_i≤B 与 n_i≥b_min 下尽量保持比例
        if sum(n) <= B:
            return [int(x) for x in n]
        fixed = {i for i, x in enumerate(n) if x <= self.b_min}
        rest = B - self.b_min * len(fixed)
        free = [i for i in range(len(n)) if i not in fixed]
        wsum = sum(n[i] for i in free)
        return [self.b_min if i in fixed
                else int(rest * n[i] / wsum) for i in range(len(n))]

    def prosody(self, certemes, B):
        n = self.allocate(certemes, B)
        return Prosody(
            budget={e: ni for e, ni in zip(certemes, n)},
            emphasis=normalize([e.r_i for e in certemes]),
            duration=[ni / sample_rate for ni in n],
        )


# IP-428 Monotonic Temporal Aligner
class MonotonicTemporalAligner:
    def __init__(self, L):
        self.L = L
        self.alpha = []

    def update(self, k, certeme_ready):
        prev = self.alpha[-1] if self.alpha else 0
        cur = max(prev, certeme_ready)      # 单调：绝不倒带
        self.alpha.append(cur)
        return cur

    def horizon(self, k):
        return self.alpha[k] + self.L       # 只允许看到此处

    def check_monotone(self):
        return all(self.alpha[i + 1] >= self.alpha[i]
                   for i in range(len(self.alpha) - 1))


# IP-427 Streaming Certificate Vocoder
class StreamingCertificateVocoder:
    def __init__(self, aligner, qp_solver,
                 v_lim, a_lim, j_lim):
        self.aligner = aligner
        self.qp = qp_solver
        self.v_lim, self.a_lim, self.j_lim = v_lim, a_lim, j_lim

    def render_tick(self, k, certemes, prosody,
                    theta_prev, theta_ref, safe_domain):
        hi = self.aligner.horizon(k)
        active = [e for e in certemes[:hi + 1]]
        # 小规模 QP：平滑 + 跟踪 + 域约束 + 动力学约束
        xi = self.qp.solve(
            objective=lambda x: (norm(x - theta_ref) ** 2
                                 + 0.3 * norm(x - theta_prev) ** 2),
            constraints=[
                in_domain(safe_domain),
                velocity(theta_prev, self.v_lim),
                acceleration(self.v_lim, self.a_lim),
                jerk(self.a_lim, self.j_lim),
            ])
        if xi is not None:
            return xi, "OK"
        # 不可行：先投影回安全域，再不行则触发回退证书
        xi = project(theta_ref, safe_domain)
        if xi is not None:
            return xi, "PROJECTED"
        return None, "INFEASIBLE_FALLBACK"


# IP-429 Anytime Certificate Ladder
class AnytimeCertificateLadder:
    def __init__(self, levels, fallback):
        self.levels = levels          # 按 τ_ℓ 升序，Θ_0⊆Θ_1⊆…⊆Θ_L
        self.fallback = fallback

    def schedulable(self, tasks, T):
        # EDF + 不精确计算：只看 mandatory 段利用率
        U = sum(t.wcet_mand / t.period for t in tasks)
        return U <= 1.0

    def run(self, now, certemes, B, control_dt):
        completed = []
        for lvl in self.levels:
            if now + lvl.wcet > lvl.deadline:
                break
            cert = lvl.compute(certemes, B)
            if not self._monotone_ok(completed, cert):
                break                 # 非单调层直接丢弃，绝不扩张
            completed.append(cert)
        if completed:
            return completed[-1], "OK"
        return self.fallback, "FALLBACK"

    def _monotone_ok(self, completed, cert):
        # 高层的安全域必须是低层的超集，否则视为不安全
        return all(prev.theta_cert.subset_of(cert.theta_cert)
                   for prev in completed)


# IP-430 Jitter-Invariant Safety Envelope
class JitterInvariantSafetyEnvelope:
    def __init__(self, safe_domain, J_max, n_samples=8):
        self.safe_domain = safe_domain
        self.J_max = J_max
        self.n = n_samples

    def compute(self, reach_fn):
        env = self.safe_domain
        for delta in linspace(0.0, self.J_max, self.n):
            reach = reach_fn(delta)       # 延迟 δ 的可达集
            env = env.preimage_subtract(reach)   # ⋂ Pre_δ(Θ_safe)
        return env

## 2. 推导

**引理 157（时序保守性）** 设证书在 t0 时对 `Θ_cert(t0)` 安全，且 `margin_stale(Δt)` 不小于延迟 Δt 内执行/障碍运动可达集的 Hausdorff 半径。则对任意 `t=t0+Δt`，`Θ_cert(t)=Erode(Θ_cert(t0),margin_stale(Δt))` 中的任一 θ 在 t 时刻执行仍安全。证明：由 `margin_stale` 的单调性与侵蚀定义，`Θ_cert(t)` 到原边界的距离 ≥ 可达集半径，故可达扰动不越出 `Θ_cert(t0)`。∎ 推论：**证书越老，安全域越小；过期证书不得复用**。

**引理 158（截止期安全）** 若不精确计算任务的 mandatory 段满足 EDF 可调度条件 `Σ(W_i^mand/T_i)≤1`，则所有 mandatory 段在截止期内完成；optional 段未完成只使层级 ℓ 降低。若任意时刻无已完成层，则执行 `C_fb`（v20 HPC 或 v19）。故 deadline miss 不产生不安全执行。∎

**引理 159（韵律分配不扩张域）** CPP 只改变各 certeme 的采样数 `n_i`，不改变风险上界 `r_i` 与区域划分；第 i 个 certeme 只有在 `n_i` 个样本全部判 SAFE 且置信上界满足时才被认证。故认证集合对 `n_i` 单调不增，预算重分配只能使某些区域**不被认证**，不能使未采样区域被认证。`b_min>0` 进一步保证每个 certeme 至少被采样，避免“韵律性盲点”。∎

**引理 160（流式因果性）** 由 MTA 单调性 `α(k+1)≥α(k)`，第 k 拍渲染只读取 `≤α(k)+L` 的 certeme，故输出 `ξ_k` 不依赖任何 `>α(k)+L` 的观测；归纳可得输出因果。最坏延迟 ≤ `L` 个 certeme 的生成时间 + 单拍 QP 时间。∎

**引理 161（渲染安全）** SCV 的 QP 显式约束 `ξ_k∈Θ_ℓ`；若 QP 不可行，则先投影回 `Θ_ℓ`（仍安全），投影也失败时触发 `C_fb`。故任一输出轨迹点都在当前层安全域内；结合引理 158 的层级选择，`ξ_k∈Θ_ℓ⊆Θ_true`。∎

**引理 162（抖动不变性）** 定义 `E_J=⋂_{δ∈[0,J]}Pre_δ(Θ_safe)`。若 `J_1≤J_2`，则 `[0,J_1]⊆[0,J_2]`，交集索引集更大，故 `E_{J_2}⊆E_{J_1}`。即抖动上界越大，包络越小、越保守。∎

**引理 163（v21 整体安全继承）** 在同一几何快照、同一机器人集合、同一控制节拍下，RTCC 只收缩消费窗口，CPP 只重分配采样，SCV/MTA 只做域内因果渲染，ACL 只选择已完成且单调的层，JISE 只做延迟可达集的交。六者均不扩张认证域，故 `Exec_v21⊆Exec_v20⊆Exec_v19⊆Exec_v18`。∎

## 6. 已知风险与失效模式

1. **WCET 低估与尾延迟**：mandatory 段的 `W_i^mand` 若被低估，EDF 可调度性证明失效，证书可能在截止期后到达。缓解：测量 p99.9 + 安全系数、硬件隔离、看门狗强制回退。

2. **跨机器人时钟不同步**：v20 的 CFC 依赖时间戳，v21 的 RTCC 更依赖 `t0`。时钟偏差会让“新鲜证书”被误判为过期或反之。缓解：PTP/单调时钟、偏差上界进入 `J_max`、时钟域显式建模。

3. **韵律预算与活性矛盾**：`b_min` 太大则高风险区采样不足，太小则低风险区仍可能被饿死。缓解：按 certeme 数自适应下界、风险上界保守化、在线监测盲点。

4. **前瞻不足导致 QP 不可行/抖振**：`L` 太小使渲染器看不到足够 certeme，频繁投影会产生 chattering。缓解：自适应 L、投影后低通、不可行即回退而非硬投影。

5. **单调对齐与感知回溯冲突**：感知层（v20 PCA/CTS）可能回溯修正历史几何，而 MTA 禁止倒带；若强行对齐会用到过时 certeme。缓解：回溯只能通过“冻结当前层 + 新开流”处理，旧流进入回退。

6. **层级单调性被非单调启发式破坏**：optional 段若使用非单调剪枝，`Θ_ℓ` 可能不满足包含关系。缓解：每层输出前强制单调校验，不满足则丢弃该层。

7. **JISE 过度保守**：高抖动下 `E_J` 可能收缩到空集，导致活性崩溃。缓解：分段抖动模型、软包络、与 ACL 低层配合。

8. **连续化投影的局部最优**：QP/投影可能把轨迹推到安全域边界，导致后续拍不可行。缓解：预留边界裕度、滚动时域可行性检查。

## 7. 本轮最大风险

**一句话**：若 mandatory 段的 WCET 被低估或跨机器人时钟不同步，证书会在过期后仍被消费，形成“时序伪安全”；同时风险韵律若缺少预算下界，采样会集中到高风险区而在低风险区制造新的未采样盲点——即“韵律性时序盲区”。
