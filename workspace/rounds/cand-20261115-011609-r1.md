# 第 3 轮（灵感循环第 3 轮；本轮灵感：「对话管理」×「多机评测」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439），
> 再向前继承 **LeanGauge**（IP-310–314）与 **MODGAUGE** 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）。
> **本轮纪律：在前人基础上改进，而不是推倒重来。** ToolGauge 的三根支柱（工具契约 / 摊销校准 / 语义假设）原样保留，
> 只沿两条新灵感轴各加一层**证据包络**：把「一次性开环探测」收紧为「多轮接地对话」，把「单机自证的独立证据」收紧为「多机分层、可证伪的独立证据」。
> 同时审计并修复第 2 轮遗留的八处证据独立性与主张接地缺陷（见 §5）。

## 双轴映射（加包络，不换内核）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 对话管理 | IP-319 6C：编译一次、执行一次、校准一次；T-Box 对单个 h 贪心算 Ĝ | **E-Dialog + GLedger + VoI-π**：显式信念态 b_t(h,ν)、接地账本 G_t、按信息价值选择 {探测 / 问人 / 问对等机 / 确认 / 中止 / 提交} | 盲区修复本质是澄清式对话：证据不足时该追问，而不是「程序跑完就提交」；「被提到」不等于「被接地」 |
| 多机评测 | 定义 421.V 的「独立 cross.modal 回执」；MP-Φ 的池化先验 | **X-Peer + MS-Conformal + LOMO + X-Adjudication**：物理独立的对等机回执、分机共形覆盖、留一机评测、机器分歧裁决 | 独立证据不能自我声明；同机 cross.modal 共享镜头/光源/标定，往往是**伪独立**；跨机是真正的独立轴，但异构使它不免费 |

**核心命题**：把 ToolGauge 的「工具契约 → 摊销校准 → 单机交叉验证 → 热替换」升级为
「**多轮证据对话 → 接地账本 → 跨机独立裁决 → 分层认证后热替换**」。
两条灵感轴互补而非并列：对话管理决定「**该向谁、问什么、何时停**」，多机评测提供「**真正独立的对话方**」；
二者合起来把「独立性」从隐含公理变成**硬件扎根、可测量、可预算、可证伪**的一等对象。
一句话：**独立性不是免费的，也不是自证的。**

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 主张绑定不变式的**接地扩展**：语言主张必须被有效回执**蕴含**（不只是引用）且独立秩达标，否则不得提交、也不得进入策略上下文（定义 433/435/445）；
- 新增**独立性不变式**：独立秩 rank_ind 由可信监控器按硬件溯源与标定记录计算，任何参与者（VLA、对等机、操作员文本）不得自报（定义 436）；
- **严格退化链继续延长**：ParlayGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE；
  每次退化满足**独立性单调性**（rank_ind 下降 ⇒ 后验方差不得下降），原则是 **hold / abstain 优于错误提交**（定义 443）。

## 0. 直觉与动机

**灵感 1（对话管理 → 盲区修复是一场澄清式对话，不是一次开环执行）**

直觉：ToolGauge 的 6C 仍然是一条开环流水线——L-Box 先猜、T-Box 一次选程序、V 阶段一次性判真伪。但真实的计量修复更像任务型对话：
「我怀疑是镜面反射」→「先扫一下光照确认」→「结果有歧义」→「问另一台机器 / 问操作员」→「把假设收敛到可提交」。
对话管理给我们的三个关键概念正好补上 ToolGauge 的空白：
(a) **信念态**：系统应显式维护「哪些假设还活着、哪条证据通道此刻可信（ν）」；第 2 轮的 H_s 是一次性集合，不随证据演化；
(b) **接地（grounding）**：对话中的「提到 / 引用」不等于「已确证」；必须区分 mentioned → cited → entailed → grounded 四级，只在 grounded 后提交；
(c) **混合主动与信息价值**：该探测、该问人、该问对等机、还是该停，是按 VoI 决策的策略问题；第 2 轮的 β = Ĝ − c 只是它的一个特例，
且当 H_s 内有多个相关假设时，逐 h 贪心会重复购买同一信息。

风险对称：对话管理也带来新危险——LLM 自问自答会制造**虚假共识**，所以本轮把「禁止自证」上升为不变式（定义 446）。

**灵感 2（多机评测 → 独立证据是物理属性，不是文本声明）**

直觉：第 2 轮把一条 `cross.modal` 回执当作「独立证据」，但同机的 IR 与 RGB 往往共用镜头、光源、时基与标定——
它们的误差高度相关，标准化残差 |z| ≤ ε_cross 可能只是**同错**，而不是互证。
多机评测的启示是：真正的独立轴是**不同的物理传感路径 / 标定源 / 机型**；但跨机也引入异构（外参、时延、机型偏置），
所以「独立」必须用**共同世界契约**（时间、空间、变换对齐）来兑换，且跨机证据只在**分机分层**的意义上可信。
由此得到三个机制：
(a) **物理独立秩** rank_ind：按硬件与标定等价类计数，由可信监控器判定，替代第 2 轮含糊的「独立回执」；
(b) **分机共形**：池化覆盖达标会掩盖单机失败（Simpson 式反例），必须报告 worst-machine 覆盖与配额；
(c) **留一机评测（LOMO）+ 分歧裁决**：把「新机型能否部署」变成可预注册、可证伪的实验；机器分歧不是噪声，而是共享盲区或单机故障的信号，**禁止简单平均**。

**灵感 3（两轴交汇 → 用对话去购买独立性）**

直觉：单机再怎么增加探测，n_eff 也会被相关系数 ρ 卡住（引理 54：n_eff ≤ 1/ρ）；要突破这个天花板，唯一的办法是**引入新的独立通道**。
对话管理恰好提供了「主动选择独立通道」的机制：当信念在单机通道上饱和时，策略应把预算转向对等机 / 人工确认，而不是在同一通道上继续刷样本。
于是「多机」不再是部署层面的评测口号，而是**修复回路内部的一个动作**；「对话」也不再是界面修辞，而是**独立性预算的分配器**。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（证据对话与轮次）** 盲区 s 的一次修复是一个有限证据对话
D = (u₀, y₀, …, u_{T−1}, y_{T−1})，T ≤ T_max。
动作集 𝒰 = {Probe(Π_s), AskHuman(q), AskPeer(m′, q), Confirm(c), Hold, Abstain, Commit}；
响应 y 依次为有效回执集、带可靠度的人工作答、带签名的对等机回执 / 证明、确认结果、空。
每轮只允许一个证据获取动作；Hold / Abstain / Commit 为终止动作。历史 ℋ_t = (u_{<t}, y_{<t})。
所有 Probe 仍受 TCV（定义 418）与 TB-Contract（定义 424）约束；所有动作受 DB-Contract（定义 440）约束。

**定义 433（信念态与接地账本）** 信念 b_t(h, ν | ℋ_t) 定义在 H_s × 𝒱 上，ν 为证据通道有效性隐变量
（valid / biased / spoofed）。接地账本 G_t = {(c, state, supp(c), rank_ind(c))}，
state ∈ {mentioned, cited, entailed, grounded}，状态单调升级：
mentioned → cited（存在有效回执引用）→ entailed（回执的**类型化字段**确定性地蕴含主张，含单位、符号、容差）→
grounded（entailed 且 rank_ind(c) ≥ q 或经人工确认）。
**未 grounded 的主张不得进入策略上下文**（防 VLA 自我条件化）；这是对定义 423 的加强：第 2 轮只要求「引用有效回执」，本轮要求「蕴含 + 独立秩」。

**定义 434（信息价值策略 VoI-π）** 给定 b_t、剩余预算 B_t、截止期 D_t，策略 π 选择 u_t。定义
VoI_t(u) = E_{y∼p(·|b_t,u)}[H(h|b_t) − H(h|b_{t+1})] − c(u) − ρ·Risk(u)，
其中 Risk 为物理风险，c 为该动作代价（探测含工具代价，问人含操作员负担，问对等机含通信/标定代价）。
提交价值 V_commit = −L_commit·P(¬grounded | b_t)，中止价值 V_abstain = −L_abstain，且 L_commit > L_abstain > 0。
π 采用前向 1 步贪心（对话时域短、T_max ≤ 6），或对关键盲区做 2 步前瞻。
定义 419 的 λ/β 双门是 u = Probe 的特例：Risk = 风险门，VoI ≈ 增益注 − 代价。

**定义 435（接地-提交规则）** commit(c) 允许 ⇔ state(c) = grounded ∧ 无更强的反证回执 ∧
（高风险主张要求 rank_ind(c) ≥ q ≥ 2，且至少一个物理叶子）。若 cited 但未 entailed ⇒ 标记 `misquote` 并剥离；
若 entailed 但独立秩不足 ⇒ 记为 `pending`，不得进入契约或控制路径。
**引用有效 ≠ 主张为真**：这是第 2 轮定义 423/427 的实质补丁。

**定义 436（跨机回执与共同世界契约）** 对等机 m′ 的回执 r′ = (m′, t, args, obs, sig, ts, seq, T_{m′→m})。
跨机有效 ⇔ (i) 时间对齐：|ts − ts′| ≤ δ_t 且世界漂移 ≤ Δ_w；
(ii) 空间对齐：外参 T_{m′→m} 与配准误差在包络内；
(iii) 物理独立：传感硬件、标定源、传输路径、时基与 m 至少一项不同，由**硬件溯源表** R_ind 判定；
(iv) 变换后残差在跨机包络 ε_X 内。
定义独立秩 rank_ind(R) 为证据集 R 中两两物理独立的**通道等价类数**（按 R_ind 的等价类计数，等价类可加）。
**注意**：同机 cross.modal 往往共享镜头/光源/标定 ⇒ rank_ind 常为 1；第 2 轮的「独立回执」经常并不独立。

**定义 437（分机共形覆盖 MS-Conformal）** 校准集按机器分层 C_m；
对每台机 m 用分割共形分位数 q_{m,1−α_m} = 第 ⌈(n_m+1)(1−α_m)⌉ 个次序统计量，
保证 P(h* ∈ H_{s,m}) ≥ 1−α_m（机内可交换）。
池化覆盖 = Σ_m π_m·coverage_m。**池化达标不蕴含任一机达标**（引理 53 给出反例）。
α 分配：worst-machine 目标用 Bonferroni α_m = α/M（保守）或 e-value 自适应加权（更紧但需可交换性）。

**定义 438（留一机评测 LOMO）** 对每台机 m，用 M \ {m} 的预训练/校准构造先验与契约，在 m 上评测，
得到 R_m、coverage_m 与 machine-shift η_m = TV(D_m, D_{−m}) 的经验上界。
报告三元组 (mean_m R_m, max_m R_m, CI)，并单列 between-machine 方差。
LOMO 是唯一能暴露「池化掩盖单机失败」的预注册协议；新机型 ⇒ 重新 LOMO，不得用旧证书外推。

**定义 439（跨机分歧裁决 X-Adjudication）** 给定各机对同一世界量的估计 (μ_m, Σ_m) 与偏置界，
一致性统计量 S = min_w Σ_{m=1}^{M} (μ_m − w)ᵀ Σ_m^{−1} (μ_m − w)（一致时 S ~ χ²_{M−1}）。
若 S ≤ τ_χ ⇒ 一致，用协方差加权（BLUE）融合；若 S > τ_χ ⇒ 不一致，做留一机检验：
① 剔除 m 后一致 ⇒ m 机局部故障（隔离该机）；② 剔除任一机仍不一致 ⇒ 共享世界歧义或模型错；
③ 全部一致但远离先验 ⇒ 模型错。
**不一致时禁止简单平均**：相关偏置的平均只会让估计更自信。

**定义 440（对话预算与多机公平契约 DB-Contract）** DB = (B_global, {B_m}, q_m, D_t, T_max, ρ_fair, recovery)：
全局预算、单机预算上限（防「刷某台」）、每机最低评测配额 q_m、截止期、对话轮数上限、公平约束
（max_m risk_m − min_m coverage_m ≤ ρ_fair，或 min-max 覆盖）、恢复条件（预算耗尽 / 连续 hold ⇒ abstain + RED + 人工）。
DB-Contract 是 TB-Contract（424）与 IV-Contract（407）的多机扩展。

**定义 441（随时有效证据 e-value 与接地证书）** 对每个候选主张 c，证据流 {E_t(c)} 是一个非负 e-process：
在 H₀（c 不成立 / 未接地）下 E[E_t(c) | ℱ_{t−1}] ≤ 1。
多回执在条件独立时相乘，否则用可预测插件或 e-value 混合（对备择取混合先验的混合似然比）。
接地判据：E_τ(c) ≥ 1/α_g。由 Ville 不等式，任意停时 τ 下 P(∃t ≤ T_max：错误 commit) ≤ α_g。
这替代第 2 轮依赖固定 N_bl 的引理 47 第三项，使**自适应选证**合法。

**定义 442（跨机金丝雀与相关先验监测）** 预注册金丝雀集 S_can（真值由对等机共同标定，或使用已知回放）。
周期性抽取 s ∈ S_can，向对等机 m′ 请求独立回执，计算标准化残差；
若同向偏离累计 e-value 超阈 ⇒ 判定摊销先验出现**跨盲区相关偏差**（第 2 轮最大风险）。
检测功效由 rank_ind 与金丝雀数量决定。与 P-Quarantine（428）互补：P-Quarantine 是单机、后置；金丝雀是跨机、可主动设计。

**定义 443（提交语义与单调退化）** 三态：Commit（接地且证书达标）、Hold（保留旧契约，继续对话）、
Abstain（不提交 + RED + 人工）。序：correct commit ≻ hold(≡ old) ≻ abstain ≻ wrong commit。
严格退化链：ParlayGauge → ToolGauge → LeanGauge → MODGAUGE；
每次退化必须满足**独立性单调性**：rank_ind 降低 ⇒ 后验方差不得降低。这把第 2 轮的退化链从「行为约定」升级为「可检验条件」。

**定义 444（多机评测估计量与风险台账）** 估计量 θ = {(R_m, coverage_m, n_eff,m, rank_ind,m)}_{m=1..M} ∪ {R_max, between-var}。
评测报告必须含：①每机均值与 CI；②worst-case 上界；③between-machine 方差；④评测机集合、硬件/标定版本；⑤预注册分析计划。
部署证书只对**评测覆盖的机群**有效；任何机型/标定变更都视为新总体，必须重新 LOMO。

**定义 445（多方证明与主张语言）** 主张 c 可携带 attest(c) = {(m, sig_m, r_m)}；
grounded 需 quorum q 个物理独立的机器证明（rank_ind ≥ q）且无冲突证明；冲突 ⇒ 进入定义 439 裁决，不得择一引用。
语言层（VLA 解说）只能引用 grounded 的 attest；attest 集与独立秩写入 EC.claims（扩展定义 423/427）。

**定义 446（禁止自证 / 角色隔离）** 接地图中每条 derivation 必须至少有一个**物理回执叶子**；
VLA 可以提议、批评、解说，但不得作为叶子或唯一判据。提议者、批评者、裁决者的证据集必须满足：
裁决者不得仅依赖提议者生成的文本；若三方由同一 VLA 扮演，必须引入至少一个外部（物理或对等机）叶子。
接地图按轮次时间戳与签名 DAG 检查无环。**禁止「自言自语达成共识」。**

**定义 447（继承与编号约定）** 未被重定义的第 2 轮记号（MTC、TCV、T-Box、MP-Φ、AP-Cal、6C、H_s、EC、M_ver 等）沿用定义 416–431。
退化特例：令对等机集 = ∅、T = 1、G 退化为「引用检查」、π 退化为贪心 β ⇒ ParlayGauge ≡ ToolGauge；
再令 VLA = ∅、T₀ = {被动观测}、MP-Φ = 物理先验 GP ⇒ LeanGauge。

```python
# IP-321 E-Dialog：信念态 + VoI 策略（定义 432–435）
class EDialog:
    def run(self, s, H_s, M):
        b, G, hist = init_belief(H_s, M.mp_phi), GroundingLedger(M.ind), []
        for t in range(M.db.T_max):
            acts = M.tools.admissible(s) + [AskPeer(m, s) for m in M.peers] + [AskHuman(s)]
            best, best_v = None, -inf
            for u in acts:
                v = self.voi(b, u, M)
                if v > best_v: best, best_v = u, v
            if G.can_commit(s) and self.commit_value(b, G, s) >= best_v:
                return Commit(self.grounded_contract(b, G, s))      # 只在 grounded 后
            if best_v <= 0:
                return Hold(M.old_contract(s)) if G.can_commit(s) else Abstain("no_voi")
            y  = M.exec_act(best)                    # Probe→TCV；AskPeer→XPeer；AskHuman→接口
            rs = M.tcv.validate(y)                   # 无效回执作废（继承 417）
            b  = self.bayes_update(b, best, rs)
            G.update(best, rs)                       # 状态单调升级（定义 433）
            hist.append((best, rs))
        return Hold(M.old_contract(s)) if G.can_commit(s) else Abstain("horizon")
```

```python
# IP-322 GLedger：接地账本 + 独立性监控（定义 433/436/446）
class GroundingLedger:
    def update(self, u, rs):
        for c in touched_claims(u, rs):
            if any(valid(r) for r in rs): self.state[c] = max(self.state[c], "cited")
            if any(entails_fieldwise(c, r) for r in rs):                  # 确定性字段检查
                self.state[c] = max(self.state[c], "entailed")
                if self.rank_ind(c) >= self.q(c): self.state[c] = "grounded"
    def rank_ind(self, c):
        leaves = [r for r in supp(c) if r.provenance == "physical"]
        return self.monitor.equivalence_classes(leaves)   # 硬件溯源，非自报
    def grounded_derivation(self, c):                     # 定义 446
        return has_physical_leaf(c) and acyclic(c) and not self_only(c)
```

```python
# IP-323 X-Peer：跨机回执与共同世界契约（定义 436）
```

## 3. 推导

**引理 51（随时有效的接地错误界）** 若 {E_t(c)} 是 H₀ 下的非负 e-process，则对任意停时 τ ≤ T_max，
P(∃t：commit(c) 且 c 不成立) ≤ α_g（在 E_t ≥ 1/α_g 时提交）。
证明：Ville 不等式；自适应选证与 optional stopping 不改变该界。
系 51.1：第 2 轮引理 47 的第三项依赖固定 N_bl 与 i.i.d. 回执，在 T-Box 自适应选证下不成立；本引理给出合法替代，
代价是 e-value 的保守性（检测功效依赖证据质量与通道数）。

**引理 52（VoI 贪心的近似最优性）** 若给定 (h, ν) 时各证据动作的观测条件独立、熵减函数单调且自适应次模，
且风险门定义的可行动作集构成下闭可拟阵（如基数上限 L_max 的均匀拟阵），则贪心 VoI 策略的期望信息增益
≥ (1−1/e)·OPT。证明：Golovin–Krause 自适应次模 + 拟阵贪心。
系 52.1：定义 419 的 β 贪心是「L=1、单一 h」的退化特例；当 H_s 内假设高度相关时，逐 h 贪心可任意差
（重复探测同一信息），这正是第 2 轮需要 n_min 兜底的原因。

**引理 53（分机共形覆盖与池化陷阱）** 机内可交换时，每机覆盖 ≥ 1−α_m（有限样本为 ⌈(n_m+1)(1−α_m)⌉/(n_m+1)）；
池化覆盖 = Σ_m π_m·coverage_m ≥ 1 − Σ_m π_m α_m。
但池化覆盖 ≥ 1−α **不蕴含** min_m coverage_m ≥ 1−α：例如 M=2、π=(0.6,0.4)、coverage=(0.99,0.80)，
池化 = 0.914 ≥ 0.9，而第二台仅 0.80。
要在总预算 N 下保证 min_m coverage_m ≥ 1−α，必须每机 n_m ≥ n_min(α)（或按方差做 Neyman 分配），
即 worst-machine 认证需要**每机配额**，不能靠池化样本外推。

**引理 54（独立性天花板与有效样本量）** 设 k 条回执的误差等方差 σ²、两两相关 ρ，则融合均值方差
σ²/n_eff，n_eff = k/(1+(k−1)ρ) ≤ min(k, 1/ρ)。
故同机相关证据（ρ→1）的 n_eff 饱和在 1/ρ，继续刷同通道样本无法突破；跨机独立（ρ≈0）才有线性增益。
系 54.1：定义 426 的 n_min 应用于相关回执时会高估样本量；必须以 n_eff 替换 n，并据此重算提交门槛。

**引理 55（接地层保数值 + 禁止自证）** 接地/对话层只门控 commit 与 claims，不改变任何数值估计器；
在 grounded 时其数值行为与 ToolGauge 相同，故引理 44/49 的子图等价性保持。
禁止自证不变式（每条 derivation 至少一个物理叶子、接地图无环）保证：纯文本循环无法产生 commit；
按轮次归纳可得，任一 commit 时刻都至少存在一条有效物理回执。claims 仅在 grounded 后进入策略上下文，仍不在数值路径上。

**引理 56（多机评测的样本下界）** 在机器间无关联假设的最坏情形下，要以 1−δ 置信度把 max_m R_m 估到 ε 内，
至少需要每台机 Ω(ε⁻² log(1/δ)) 个样本，总样本 Ω(M·ε⁻² log(1/δ))；未评测的机器可能正是最差机。
证明思路：每台机可独立构造两点下界（Le Cam），max 需要逐机分辨；between-machine 方差不会因其他机器的样本而缩小。
系 56.1：LOMO + 每机配额 q_m 是 minimax 意义下的必要协议；「只报 pooled」在异质机群上不构成部署证据。

## 6. 本轮最大风险（一句话）

**一句话**：最大的风险是**独立性洗白（independence laundering）**——对话管理 + 多机互证会制造「多方独立同意」的外观，
但对等机可能共享同一标定源 / 同一场景模型 / 被同一攻击者控制，VLA 又可能在自问自答中把文本共识当成物理证据；
于是系统会在**独立性实际不存在时反而更自信**，而引理 51/54 的保证全部以 rank_ind 的真实性为前提（E448/E450/E455 为证伪实验，
硬件溯源监控 + 禁止自证 + 金丝雀为三重兜底）。

**次级风险与缓解**：
1. **共同世界契约失配**（时间/外参/配准误差）→ 把不同世界状态的观测当同一量；用变换协方差膨胀 + 对齐残差门槛，失配即降 rank_ind。
2. **分机样本太少** → 每机共形区间过宽导致 hold/abstain 风暴；用 DB-Contract 的最低配额 q_m + 主动选择高信息金丝雀。
3. **对话策略刷预算 / 无限澄清** → T_max + DB-Contract 硬顶 + 每轮 VoI > 0 才行动。
4. **e-value 过于保守** → 功效下降、长期 hold；用 e-value 混合与金丝雀提高功效，但不放松 α_g。
5. **对等机串谋 / 伪造证明** → quorum 跨独立类 + 硬件签名 + 可信监控器；E455 做串谋压力测试。
6. **接地蕴含检查器本身被 LLM 化** → 强制字段级确定性检查（单位/符号/容差），LLM 只做解说，不做判据。
7. **公平约束拖累整体覆盖** → min-max 覆盖作为约束而非目标，按风险调整配额；E451 量化。
8. **退化链被「保守提交」绕过** → 定义 443 的独立性单调性进契约回归测试；E453 验证。

## 2. 形式化定义（要点）

**定义 432（证据对话）** 修复是有界对话 D，每轮一个证据动作；Probe 受 TCV/TB-Contract，全部动作受 DB-Contract；Hold/Abstain/Commit 终止。
**定义 433（信念态与接地账本）** b_t(h,ν) 显式建模通道有效性；G_t 四级单调升级；**未 grounded 主张不得进入策略上下文**。
**定义 434（VoI-π）** VoI = 期望熵减 − 动作代价 − ρ·物理风险；Commit/Abstain 有非对称损失 L_commit > L_abstain；定义 419 的 λ/β 是 Probe 特例。
**定义 435（接地-提交）** commit ⇔ grounded ∧ 无反证 ∧（高风险要求 rank_ind ≥ q 且至少一个物理叶子）；cited 未 entailed ⇒ misquote；entailed 但秩不足 ⇒ pending。
**定义 436（跨机回执）** 跨机有效 ⇔ 时间/空间/变换对齐 + 物理独立（硬件溯源）+ 残差包络；rank_ind = 通道等价类数；同机 cross.modal 常为 rank_ind=1。
**定义 437（MS-Conformal）** 分机共形分位数；池化覆盖 = Σπ_m coverage_m；池化达标不蕴含单机达标；worst-machine 需每机配额。
**定义 438（LOMO）** 用其余机器训练、留一机评测；报告 mean/worst/CI/between-var；新机型必须重新 LOMO。
**定义 439（X-Adjudication）** 一致性统计量 S ~ χ²_{M−1}；不一致时留一机定位：单机故障 / 共享歧义 / 模型错；**禁止简单平均**。
**定义 440（DB-Contract）** 全局/单机预算、每机最低配额、轮数上限、公平约束、预算耗尽的 Hold/Abstain 恢复策略。
**定义 441（e-value 接地证书）** e-process + Ville：任意停时下 P(错误 commit) ≤ α_g；使自适应选证合法。
**定义 442（跨机金丝雀）** 预注册已知真值盲区，周期性向对等机取证；累计 e-value 超阈 ⇒ 暂停 AP-Cal，回退 BP-Cal。
**定义 443（提交三态与单调退化）** correct commit ≻ hold(≡old) ≻ abstain ≻ wrong commit；rank_ind↓ ⇒ 方差不得↓。
**定义 444（多机风险台账）** 报告每机 R_m/coverage_m/n_eff/rank_ind、worst-case、between-var、机型与标定版本、预注册计划；证书只覆盖评测机群。
**定义 445/446（多方证明与禁止自证）** grounded 需 q 个物理独立证明；接地图每条 derivation 至少一个物理叶子、无环、裁决者不得只依赖提议者文本。
**定义 447（继承）** 退化特例：对等机∅、T=1、G=引用检查、π=贪心 β ⇒ ToolGauge；再令 VLA=∅ 等 ⇒ LeanGauge。

```python
# IP-321 E-Dialog：信念态 + VoI 策略（定义 432–435）
class EDialog:
    def run(self, s, H_s, M):
        b, G = init_belief(H_s, M.mp_phi), GroundingLedger(M.ind)
        for t in range(M.db.T_max):
            acts = M.tools.admissible(s) + [AskPeer(m, s) for m in M.peers] + [AskHuman(s)]
            best, best_v = None, -inf
            for u in acts:
                v = self.voi(b, u, M)               # 熵减 − 代价 − 风险（定义 434）
                if v > best_v: best, best_v = u, v
            if G.can_commit(s) and self.commit_value(b, G, s) >= best_v:
                return Commit(self.grounded_contract(b, G, s))
            if best_v <= 0:
                return Hold(M.old_contract(s)) if G.can_commit(s) else Abstain("no_voi")
            y  = M.exec_act(best)                   # Probe→TCV；AskPeer→XPeer；AskHuman→接口
            rs = M.tcv.validate(y)                  # 无效回执作废（继承 417）
            b  = self.bayes_update(b, best, rs)
            G.update(best, rs)                      # 状态单调升级（定义 433）
        return Hold(M.old_contract(s)) if G.can_commit(s) else Abstain("horizon")
```

```python
# IP-322 GLedger：接地账本 + 独立性监控（定义 433/436/446）
class GroundingLedger:
    def update(self, u, rs):
        for c in touched_claims(u, rs):
            if any(valid(r) for r in rs): self.state[c] = max(self.state[c], "cited")
            if any(entails_fieldwise(c, r) for r in rs):        # 确定性字段检查
                self.state[c] = max(self.state[c], "entailed")
                if self.rank_ind(c) >= self.q(c): self.state[c] = "grounded"
    def rank_ind(self, c):
        leaves = [r for r in supp(c) if r.provenance == "physical"]
        return self.monitor.equivalence_classes(leaves)         # 硬件溯源，非自报
    def grounded_derivation(self, c):
        return has_physical_leaf(c) and acyclic(c) and not self_only(c)
```

```python
class XAdjudicator:
    def decide(self, ests):
        S = min_w sum((mu - w).T @ inv(Sig) @ (mu - w) for mu, Sig in ests)
```

## 4. 推导

**引理 51（随时有效接地界）** H₀ 下若 {E_t(c)} 为非负 e-process，则任意停时 τ 下 P(∃t：错误 commit) ≤ α_g（E_t ≥ 1/α_g 时提交）。证明：Ville；自适应选证与 optional stopping 不改变界。系：替代第 2 轮固定 N_bl 的引理 47 第三项，代价是 e-value 保守性。
**引理 52（VoI 贪心近似最优）** 给定 (h,ν) 时动作观测条件独立、熵减单调自适应次模、可行动作集为下闭拟阵 ⇒ 贪心 VoI ≥ (1−1/e)·OPT（Golovin–Krause）。系：定义 419 的 β 贪心是 L=1、单 h 的退化特例；H_s 相关时可任意差。
**引理 53（分机共形与池化陷阱）** 机内可交换 ⇒ 每机覆盖 ≥ 1−α_m（有限样本 ⌈(n_m+1)(1−α_m)⌉/(n_m+1)）；池化 = Σπ_m coverage_m ≥ 1−Σπ_m α_m；但池化 ≥1−α 不蕴含 min_m ≥1−α（M=2, π=(0.6,0.4), coverage=(0.99,0.80) ⇒ 池化 0.914，第二台 0.80）。worst-machine 认证必须每机配额。
**引理 54（独立性天花板）** k 条等方差、两两相关 ρ 的回执融合，n_eff = k/(1+(k−1)ρ) ≤ min(k,1/ρ)，融合方差 σ²/n_eff。系：同机相关证据饱和在 1/ρ；定义 426 的 n_min 必须以 n_eff 替换。
**引理 55（接地保数值 + 禁止自证）** 接地/对话只门控 commit 与 claims，不改数值估计器 ⇒ 子图等价性同引理 44/49；每条 derivation 至少一个物理叶子且无环 ⇒ 纯文本循环不能 commit；按轮次归纳，commit 时必存在有效物理回执。
**引理 56（多机评测下界）** 机器间无关联假设下，把 max_m R_m 估到 ε（置信 1−δ）需每机 Ω(ε⁻²log(1/δ)) 样本，总 Ω(M·ε⁻²log(1/δ))；未评测机器可能正是最差机（Le Cam 两点下界）。系：LOMO + 每机配额 q_m 是 minimax 必要协议；只报 pooled 不构成部署证据。

## 8. 本轮最大风险

**一句话**：最大的风险是**独立性洗白**——对话管理 + 多机互证会制造「多方独立同意」的外观，但对等机可能共享同一标定源 / 同一场景模型 / 被同一攻击者控制，VLA 又可能在自问自答中把文本共识当成物理证据；系统会在独立性实际不存在时反而更自信，而引理 51/54 的全部保证都以 rank_ind 的真实性为前提。以 E448/E450/E455 证伪，以硬件溯源监控 + 禁止自证 + 跨机金丝雀三重兜底。
