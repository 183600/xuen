# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「机械臂」×「UniBot-V1」）

> R69 把不确定性一分为二：aleatoric 交给 R68 的 λ_floor 收紧，epistemic 交给「流匹配多模态策略 + 主动多模态交互」去消解。这套叙事漂亮，但它悬在半空：`ξ=(a,g)` 里的注视、探针、问句都是**抽象软指令**，安全性只靠一个前缀认证；它自陈的最大风险也暴露了这一点——**当流模型的模态分布不可信时，系统会自信地追问一个幻影**。换言之，R69 的不确定性住在「心里」（我该选哪个意图/模态），而不是住在「身体」上。
>
> 本轮两个灵感把问题按回物理世界：
> - **机械臂**——真实机器人的 epistemic 不确定性是**参数化、持续、可由运动辨识**的：连杆长度、关节零位、摩擦、负载质量与质心、执行器延迟、关节柔顺。它们不是每帧重采样的「模态」，而是**身体常数**；它们不确定，安全裕度就必须膨胀，速度就必须下降。
> - **UniBot-V1**——一个「一套策略、多种身体」的跨具身基础模型。它在训练分布内很强，但新机械臂一旦落在分布外，先验会**自信地错**；R69 的模态校准门校准不了「我的身体参数是错的」。
>
> 核心命题：**把 R69 的 epistemic 不确定性物理化为具身参数 θ 的后验；把「信息动作」升级为「安全可观测的激励轨迹」（主动系统辨识）；把 θ 的后验不确定度通过一个显式的「安全裕度映射」兑换成速度/加速度的保守量。辨识成功且可信 → 裕度收缩（resolution bonus 终于有了物理汇率）；辨识不可观测 / 越过安全流形 / 具身 OOD / 被篡改 → 裕度按先验全量膨胀，逐指令退回 R69 再退回 R68。** 命名 **SOMA-RAS**（Self-Observing Manipulator-Arm, Risk-Adaptive Safety；soma = 身体）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的身体到底是什么**」——不确定性不只是刹车踏板、不只是提问，它还是**一段刻意的、安全的、有信息量的运动**。

## 0. 直觉与动机

**灵感 1（机械臂 → 不确定性长在身体上，而且会直接吃掉安全裕度）**
直觉：R69 的 `U_epi` 是「我对该做哪个动作有歧义」；机械臂的 `U_epi` 更像「我不知道自己有多长、多重、多涩、多慢」。后者是**参数**，一旦估出来就长期有效，而且它的不确定度会以牛顿·米为单位直接吃掉执行器余量。举例：负载质量 m 有后验标准差 σ_m，最远力臂 r，则重力力矩不确定度为 σ_m·g·r；扭矩预留必须 ≥ 它，剩余扭矩才允许用来加速。**辨识把 σ_m 缩小，裕度就收缩，速度上限就抬高**。这把 R69 抽象的「resolution bonus」第一次换算成了可测量的速度。

**灵感 2（UniBot-V1 → 一个策略、很多身体；分布外先验会自信地错）**
直觉：跨具身基础模型的价值在于把「怎么抓、怎么推、怎么绕障」的先验共享给所有机械臂；代价是它必须相信一个具身嵌入 e。若新机械臂的连杆比、关节零位、末端工具完全在预训练分布之外，模型仍会输出高置信度的动作——**错得很自信**。R69 用流似然（FMA）能发现「行为不自洽」，却说不清**是哪一个物理参数错了**。本轮要求：先验由 UniBot-V1 给，但必须配一个**具身 OOD 检测 + 可观测门**；先验不可信时，宁可不辨识、按先验最坏情况膨胀裕度。

**灵感 3（接触 → 机械臂真正的多模态是混合的，而流匹配会把它糊穿）**
直觉：机械臂的歧义常是接触模式的歧义——接触/非接触、粘滞/滑移、先碰食指还是拇指、从上方抓还是侧面抓。这是离散+连续的**混合**多模态，正是 R69 想要的「有形状的不确定性」。但 rectified flow 在连续轨迹上求平均，会把「先接触再抬升」和「悬空绕过」平均成一条**穿模轨迹**：穿过桌面、或在接触面上悬浮。所以本轮必须把接触模式 c 作为离散潜变量条件化流场，并在每一步做互补性投影，让多模态落在**接触策略**上。

**灵感 4（信息即力 → R69 的逐一认证不够，需要「可观测性–风险」联合优化）**
直觉：对机械臂，最有信息量的动作往往最危险——推一下才知道负载，探一下才知道刚度，抖一下才知道延迟。R69 的 `certify_info(g)` 是对每个 g 独立做安全认证，它回答「这个动作安全吗」，却不回答「这份信息值这条命吗」。正确的对象是**单位风险冲量换来的 Fisher 信息**：选激励使 `I_θ(g)` 最大而风险 `R(g)` 不越界。 existencia 的坏消息是：安全流形之外的那部分信息，**结构上拿不到**（引理 21）。

**灵感 5（不确定性 → 安全裕度 → 速度：resolution bonus 的物理汇率）**
直觉：这是本轮的理论核心。参数不确定度不是抽象标量，它通过约束的 Lipschitz 常数映射为**必须预留的扭矩/位置/时间余量**；裕度又单调地压低允许加速度与速度。于是「辨识收益」有了严格定义：`Δv_max / Δrisk`。它也立刻给出一个反直觉结论：**并非所有参数都值得辨识**——只有那些「不确定度→裕度」敏感、且「安全激励→信息」可观的参数才值得；两者都低的参数应直接按最坏情况兜底（这正好是 R69「VoI−成本≤0 就不问」的物理版）。

**灵感 6（自指 → 用身体认识身体：测量会改变被测对象；错辨识比不辨识更危险）**
直觉：激励会发热、磨损、改变摩擦与间隙；长时程下 θ 本身在漂移。更严重的是**错误辨识的认证效应**：一旦错误的 θ̂ 被写进证书，系统会带着一个错误的安全裕度全速运行，而辨识动作恰好把它推到那个错误极限。R69 说「问错比不问更危险」，本轮把它升级为「**认错身体比不认识身体更危险**」。因此必须交付：可观测门、偏差上界、可信集鲁棒 CBF、辨识诱导漂移预算，以及「不可信就全量膨胀裕度」的裕度诚实性不变式。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SOMA-RAS 总览与三不变式）** SOMA-RAS = (EMB, SID, CHM, OGC, EOD, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **辨识预算与风险硬约束**：单位时间窗激励冲量 ≤ J_max、接触力 ≤ f_max、任何激励必须对**整个后验可信集** Θ_δ 满足参数相关鲁棒 CBF，禁近奇异/自碰撞/越工作空间，且激励动作与任务动作同过 C-RAS-WM‡ 认证；
(iii) **裕度诚实性（margin honesty）**：任何未消解、不可观测、被可观测门拒绝、或具身 OOD 的参数不确定度，必须**全量**折算进安全裕度，绝不允许静默丢弃；只有观测 Gramian 条件数 ≤ τ_κ 且偏差上界 ≤ τ_bias 的辨识结果，才获准用来**收缩**裕度。

**定义 311（具身参数向量 θ）** θ ∈ Θ ⊂ ℝ^{d_θ}，分量含：连杆长度/关节偏置、关节零位、粘滞与库仑摩擦、负载质量与质心、执行器延迟与带宽、关节柔顺/背隙。UniBot-V1 给出具身嵌入 e 与先验 p_θ(θ|e)；在线维护后验 p(θ|D_t)。

**定义 312（具身信念 EMB 与三分）** U_epi^body = H(θ|D_t)（等价地 log det Σ_θ）；U_ale^body 为参数估计中不可约的传感/执行器噪声；把 body 的 epistemic 再分为**当前可辨识** U_epi^id 与**安全流形内结构不可辨识** U_epi^⊥。与 R69 的关系：R69 的意图/模态不确定性保留为 U_epi^task。总不确定性三分，不做简单加和，分别进不同通道。

**定义 313（接触混合动作与 CHM）** 接触调度 c = {c_t} 取离散接触模式（无接触 / 刚性接触 / 粘滞 / 滑移 / 各指先后），任务动作 a 连续。增广动作 ξ = (a, c)。接触混合流匹配 CHM 的速度场 v_θ(x_s, s | o, c)，连续量走流匹配、离散 c 由分类头采样；生成必须满足互补性 0 ≤ λ_n ⊥ φ(q) ≥ 0、|λ_t| ≤ μλ_n，并在每步做接触一致的投影 Π_comp。多模态 = 不同接触策略（上抓 / 侧抓 / 推倒再抓）。

**定义 314（安全裕度映射 MSM）** 对参数相关约束 g_i(q,a,θ) ≥ 0，定义轨迹裕度 M(θ, a) = min_{t,i} g_i。后验下**鲁棒裕度** M_rob(Θ_δ) = min_{θ∈Θ_δ} M(θ, a*)，Θ_δ 为 δ-可信集。允许加速度/速度由裕度单调决定：v_max = Ψ(M_rob)，Ψ 单调不减、Ψ(0)=0。显式例子：负载质量不确定 σ_m、力臂 r 时，扭矩预留 τ_res ≥ σ_m g r + τ_dyn，故 a_max ∝ (τ_max − τ_res)/I_eff，v_max = √(2 a_max d_brake)。

**定义 315（安全信息激励 SID）** Fisher 信息 I_θ(g) = E[∂_θ log p(y|θ,g) ∂_θ log p(y|θ,g)^T]。在安全流形内最大化「单位风险的信息换裕度」：
g* = argmax_{g∈G_safe} [M_rob(Θ_δ(D_t)) − E_y M_rob(Θ_δ(D_t ∪ y))] / (R(g) + λ_J J(g))，
s.t. R(g) ≤ ε_id、J(g) ≤ J_max、可观测门预检通过。若最优分子 ≤ 0（辨识收益不抵风险/成本）：**不辨识**，按定义 321 全量膨胀裕度。

**定义 316（安全激励流形 G_safe）** 对 ∀θ ∈ Θ_δ 满足鲁棒 CBF：h(θ,g) ≥ 0 且 ḣ + α(h) ≥ 0；叠加关节限位、自碰撞、奇异值下界 σ_min(J) ≥ σ_0、接触力/冲量上限、工作空间、以及**可恢复性**（任意时刻可在 Δt_stop 内安全停住）。任一不满足 ⇒ g ∉ G_safe。

**定义 317（可观测门 OGC）** 辨识结果可信需同时满足：κ(I_θ(g*)) ≤ τ_κ（良态）、参数持续激励（PE，激励方向覆盖 θ 的高敏方向）、偏差上界 ‖E θ̂ − θ‖ ≤ τ_bias、有效样本量足够。任一不满足 ⇒ θ 保持 U_epi^⊥，裕度按先验膨胀，**不得**用 θ̂ 收缩裕度。

**定义 318（具身 OOD 检测 EOD）** 用 UniBot-V1 的具身嵌入 e 到预训练具身流形的距离 s_e（马氏/密度比）作 OOD 分。s_e > τ_e ⇒ 先验不可信：加宽先验、禁用跨具身迁移缩放、必要时要求离线标定或退回 R68 纯保守。它是 R69 MCG 的物理可解释版本：校准的不是「模态权重」，而是「这副身体在不在我的经验里」。

**定义 319（接触模式信念与探询）** 接触模式 m_c 的后验与熵 H(m_c)；探询动作 = 低冲量力控轻触/微推。VoI_contact = H(m_c) − E_y H(m_c|y)。若 H(m_c) 高且探询 g ∉ G_safe，则不探询，按最坏接触模式算裕度。

**定义 320（辨识诱导漂移 IID）** 激励发热/磨损使 θ 缓慢变化：θ_{t+1} = θ_t + δ(g_t) + w_t。若漂移率 ‖δ‖ 超过辨识跟踪率，辨识就是在追一个移动目标 ⇒ 冻结辨识、膨胀裕度；漂移预算 D_max 并入证书。

**定义 321（两级裕度退避，含物理 resolution bonus）** 可信辨识成功 ⇒ M_rob(Θ_δ(D_t)) 用收缩后的后验，裕度下降、v_max 上升（物理 resolution bonus）；未消解 / OGC 拒绝 / EOD 报警 / 被篡改 / 超预算 ⇒ M_rob(先验 Θ_δ ∪ U_epi^⊥ 的最坏界)，裕度上升。R69/R68 恰为「永不辨识」边界。

**定义 322（证书 J_SOMA）** J_SOMA = (J_FLUID, θ 后验哈希, κ(I_θ), 裕度 before/after, 激励冲量, s_e, 接触模式置信, 漂移界 D, soma_ver)。Valid ⇔ Valid(J_FLUID) ∧ OGC 通过（或裕度已全量膨胀）∧ 鲁棒 CBF 全程满足 ∧ 辨识预算未越界 ∧ EOD 已裁决。

**定义 323（参与式审计 VQAuditor-B）** 审计对象新增：激励是否越出安全流形、裕度是否诚实（未把不可辨识量静默抹掉）、辨识结果是否被正确门控、OOD 先验是否被误信、接触探询是否越力/越位。结论回灌 AuditBuf，成为下一轮 SID 的风险/成本先验。

**定义 324（具身威胁模型 ℰ_SOMA）** 具身欺骗（谎报连杆/零位/工具）、负载篡改（质量/质心突变）、接触/力传感器投毒、UniBot-V1 先验「自信地错」、以及把磨损伪装成正常漂移的慢攻。并入 AIC：ℰ_SOMA = ℰ_FLUID × ℰ_emb × ℰ_contact。

**定义 325（自适应辨识调度）** 仅当「不确定度的裕度代价」> 「辨识风险 + 预算成本」时才辨识；带迟滞，避免抖动式过度激励（对应 R69 的交互疲劳，但这里是机械疲劳/热漂移）。

**定义 326（与 R69/R68 的关系）** SOMA-RAS 以 FLUID-RAS 为内核。当 G_safe = ∅、OGC 拒绝、EOD 报警或辨识预算耗尽时，SOMA-RAS **逐指令等于** FLUID-RAS；后者在 VoI≤成本时逐指令等于 R68。安全侧只做加法，效率侧才拿物理 resolution bonus。

# IP-264 EMB：具身信念（UniBot-V1 先验 + 在线后验；EKF/UKF，d_theta ~ 10）
class EmbodimentBelief:
    def __init__(self, unibot_prior, e):        # e = UniBot-V1 embodiment embedding
        self.prior = unibot_prior(e)            # p(theta | e)
        self.post  = self.prior
    def update(self, g, y):                     # 激励 g 下的观测 y
        self.post = bayes_update(self.post, y, g)
        return self.post
    def credible(self, delta):                  # delta-可信集 Theta_delta
        return credible_set(self.post, delta)

# IP-265 SID：安全信息激励（单位风险换 Fisher 信息 -> 换裕度）
def choose_excitation(belief, task_ctx, budget):
    best = None
    for g in excitation_candidates(task_ctx):          # 小幅摆动/轻触/缓慢加减速
        if not budget.allow(g):               continue
        if not in_safe_manifold(g, belief.credible(DELTA)): continue   # 定义 316
        if not pe_and_gramian_ok(g, belief):  continue                  # PE + kappa
        info = fisher_info(g, belief)                     # I_theta(g)
        gain = expected_margin_reduction(belief, g, info) # 定义 315 分子
        risk = risk_impulse(g) + lambda_j * impulse(g)
        score = gain / (risk + EPS)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None     # 无利可图 -> 不辨识

# IP-266 CHM：接触混合流匹配（离散接触模式 + 连续动作 + 互补性投影）
class ContactHybridFlow:
    def sample(self, o_t, K, N_step=2):
        z, xs = self.trunk(o_t), randn(K, D)
        for i in range(N_step):
            s = i / N_step
            xs = xs + (1.0 / N_step) * self.v(xs, s, z)  # 速度场
        c = self.contact_head(z).sample(K)               # 接触模式潜变量
        return [project_complementarity(self.decode(x), c[k])   # IP-270
                for k, x in enumerate(xs)]               # 保证不穿模/不越摩擦锥

# IP-269 MSM：安全裕度映射（参数后验 -> 鲁棒裕度 -> 速度上限）
def robust_margin(a, theta_belief, delta):
    return min(min_slack(a, th) for th in sample_credible(theta_belief, delta))

def velocity_limit(m_rob):
    return PSI(m_rob)                                # 单调不减；ASSUME A99

# IP-263' SOMA 主闭环（继承 R69，仅在「不确定性处置」处插入具身层）

    samples = M.fmp.sample(o, K)
    U_ale, U_epi_task, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 2) 具身层：先验是否可信？先验不可信就只膨胀，不辨识

    trusted_prior = (s_e <= TAU_EOD)
    # 3) 只在「裕度代价 > 辨识风险」且有安全激励时辨识

    if trusted_prior and M.sched.should_identify(M.emb, U_epi_task):

    if g is not None:

    else:

    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(cand, U_epi_task, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    tau  = min(tau, v_cap)                            # 裕度硬上限，绝不越
    # 7) 审计 + 证书（裕度诚实性必须可查）
    M.vqa_b.submit_async(g, M.emb.post, m_rob, s_e)
    return k, lam, mode, (U_ale, U_epi_task, m_rob)
```

## 3. 推导

**引理 19（裕度单调性 / margin honesty）** 设安全泛函 M(θ,a) 对 θ 为 L_θ-Lipschitz（A99）。则对可信集 Θ1 ⊆ Θ2 有 M_rob(Θ2) ≤ M_rob(Θ1)；且 v_max=Ψ(M_rob) 单调。**系**：任何未识别的参数不确定度只能降低速度上限、不能抬高它；任何「悄悄丢掉不确定度」的实现都直接违反安全，而不是提升效率。这把 R69 的 `λ_floor(U_ale+未消解U_epi)` 从标量启发式升级为有几何意义的鲁棒裕度。

**引理 20（Fisher–速度汇率）** 局部渐近正态下，后验协方差 Σ_θ|D ≈ (Σ_θ^{-1} + I_θ(g))^{-1}。设裕度为 M = m0 + L_θ‖θ−θ_nom‖ 形式，则一次激励带来的期望速度增益满足
`Δv/v0 ≈ c · L_θ (√trΣ_before − √trΣ_after) / (m0 + L_θ √trΣ_before)`。
要点：**收益正比于参数标准差收缩量，而收缩量由 Fisher 信息决定**；因此 `I_θ(g)` 就是「速度」的货币。系：可辨识性高的参数（高 L_θ、高 I_θ）值得辨识；高 L_θ 但低可辨识（如安全流形内激不起来的延迟）不值得，应按最坏情况兜底。

**引理 21（安全可辨识间隙 / 没有免费的辨识）** 对任意风险预算 ε_id，存在常数 C(ε_id) 使 ∀g ∈ G_safe 有 `tr I_θ(g) ≤ C(ε_id)`，且 C 单调不减于 ε_id。证明要点：Fisher 信息随激励幅值/带宽/接触力增长，而 G_safe 把幅值、速度、冲量、接触力都限死；与安全激励李代数正交的参数方向信息恒为零。**系**：总有一部分身体参数（如某些柔性模态、极端负载区）**结构上不可在线辨识**，它们的 U_epi^⊥ 必须永久计入裕度——这正是定义 310-iii 与定义 321 存在的理由。

**定理 18（SOMA 严格包含 FLUID / R69 / R68）** 在 A99–A102 下，SOMA-RAS 在任意状态上的期望风险 ≤ FLUID-RAS；且当 G_safe=∅、OGC 拒绝、EOD 报警或辨识预算耗尽时，两者**逐指令相同**；FLUID 在 VoI≤成本时逐指令等于 R68。故 R70 ⊃ R69 ⊃ R68 是严格包含链，安全侧不做任何让步，效率侧获得物理 resolution bonus。

**定理 19（鲁棒辨识安全 / 可信集内无违规）** 若真实 θ ∈ Θ_δ，且激励 g 对 ∀θ∈Θ_δ 满足鲁棒 CBF（定义 316），则执行 g 全程不违反任何约束。若 θ̂ 有偏但偏差上界 ≤ τ_bias，则用 θ̂ 并把偏置球并入可信集所得的裕度仍然有效。**系**：只要可信集包住真值，辨识动作与辨识结果都不会造成安全事故。

**定理 20（错误辨识的代价 / 门控是必需品）** 若 OGC 失败（κ(I_θ)>τ_κ）却仍用 θ̂ 收缩裕度，则最坏裕度缺口 ≤ `L_θ·(bias + amplification(κ))`，且存在具身/负载篡改攻击实现该缺口——即安全可被违反。因此可观测门不是可选的工程细节，而是定理 19 成立的前提；**认错身体比不认识身体更危险**。

**定理 21（接触混合流的无穿透性）** 若 CHM 每步施加互补性投影 Π_comp 且投影残差有界（A101），则生成的 (a,c) 以概率 ≥ 1−ε_p 满足非穿透 φ(q) ≥ 0 与摩擦锥 |λ_t| ≤ μλ_n；接触模式熵 H(m_c) 是未消解接触 epistemic 的有效上界。系：当 H(m_c) > τ_c 且探询 g ∉ G_safe 时，裕度按最坏接触模式计算——**接触歧义只能以裕度为代价保留，不能以穿模为代价消解**。

    g = (M.sid.choose_excitation(M.emb, o, M.budget)
         if trusted and M.sched.should_identify(M.emb, U_epi_task) else None)
    if g is not None: M.emb.update(g, M.sid.execute(g))
    theta_used = M.emb.post if M.ogc.accept(M.emb, g) else M.emb.prior  # 定义 317
    cand = M.chm.sample(o, K)                         # 接触混合动作
    m_rob = M.msm.robust_margin(cand, theta_used, DELTA)
    v_cap = M.msm.velocity_limit(m_rob)
    U_floor = U_ale + (U_epi_task if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(cand, U_epi_task, lam)
    tau  = min(M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam, v_cap)  # 裕度硬上限
    M.vqa_b.submit_async(g, M.emb.post, m_rob, s_e)
    return k, lam, mode, (U_ale, U_epi_task, m_rob)
```

## 4. 推导

**引理 19（裕度单调性 / margin honesty）** M(θ,a) 对 θ 为 L_θ-Lipschitz（A99）⇒ Θ1⊆Θ2 时 M_rob(Θ2)≤M_rob(Θ1)，v_max=Ψ(M_rob) 单调。系：未识别的不确定度只能降速、不能提速；悄悄丢不确定度即违反安全。

**引理 20（Fisher–速度汇率）** Σ_θ\|D ≈ (Σ_θ^{-1}+I_θ(g))^{-1}，且 `Δv/v0 ≈ c·L_θ(√trΣ_before−√trΣ_after)/(m0+L_θ√trΣ_before)`。系：Fisher 信息就是速度的货币；高 L_θ 低 I_θ 的参数不值得辨识，应按最坏兜底。

**引理 21（安全可辨识间隙）** 对任意风险预算 ε_id，存在单调的 C(ε_id) 使 ∀g∈G_safe 有 `tr I_θ(g) ≤ C(ε_id)`；与安全激励李代数正交的方向信息恒零。系：部分身体参数结构上不可在线辨识，其 U_epi^⊥ 必须永久计入裕度。

**定理 18（SOMA 严格包含 FLUID/R69/R68）** A99–A102 下期望风险 ≤ FLUID；G_safe=∅ / OGC 拒绝 / EOD 报警 / 预算耗尽时逐指令相同；FLUID 在 VoI≤成本时逐指令等于 R68 ⇒ R70⊃R69⊃R68 严格包含链。

**定理 19（鲁棒辨识安全）** 若真 θ∈Θ_δ 且 g 对 ∀θ∈Θ_δ 满足鲁棒 CBF，则执行 g 无违规；θ̂ 有偏但 bias≤τ_bias 时，把偏置球并入可信集所得裕度仍有效。

**定理 20（错误辨识的代价 / 门控必需）** κ(I_θ)>τ_κ 却用 θ̂ 收缩裕度时，最坏裕度缺口 ≤ `L_θ·(bias+amplification(κ))`，且存在具身/负载篡改攻击实现该缺口。故 OGC 是定理 19 的前提，不是可选工程细节。

**定理 21（接触混合流无穿透）** Π_comp 每步投影且残差有界（A101）⇒ 以概率 ≥1−ε_p 满足 φ(q)≥0 与 |λ_t|≤μλ_n；H(m_c) 是未消解接触 epistemic 的有效上界。系：接触歧义只能以裕度为代价保留，不能以穿模为代价消解。

## 7. 本轮最大风险

**一句话**：SOMA-RAS 的全部安全论证押在「后验可信集 Θ_δ 包住真实身体」这一前提上——**若 UniBot-V1 先验自信地错、负载被篡改、或接触/力传感器被骗，鲁棒 CBF 就是对着一个错误集合做认证，系统会带着「被证书盖章的错误安全裕度」全速运行，而辨识动作恰好把它推向那个错误极限；认错身体，比不认识身体更危险**。

**次级风险与缓解**：安全流形内结构不可辨识（引理 21 → U_epi^⊥ 永久计入裕度 + E312 量化）；错误辨识的认证效应（定理 20 → OGC 条件数/偏差门 + EOD + 裕度诚实性，不可信即全量膨胀）；接触混合流穿模/摩擦锥违反（互补性投影 + 最坏接触模式裕度，定理 21）；辨识诱导漂移/机械疲劳（定义 320 → D_max + 调度迟滞 + E308）；实时预算被可信集采样击穿（采样 ≤8 + K=1 默认 + CBF 稀疏化）。
