# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「参数高效微调」×「姿态估计」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**低秩适配证书 + 位姿不确定度传播 + 双空间共识**。两个灵感分别治理 v9 的两种债：**适配债**（DA-ML/OTL 的全参数在线更新不可度量、可能改写块证书所依赖的策略、且多域共存昂贵）与**状态债**（v9 的块证书把状态当精确已知，但 6-DoF 位姿误差正是清距/抓取误差的主源）。新增组件一律满足：失效 ⇒ α=0（零适配器=恒等）或固定保守余量 ⇒ **严格退回 v9**，不退化为行为漂移。

## 0. 直觉与动机

**灵感 1（参数高效微调 → 低秩适配银行 + 可写回证书的适配上界）**

直觉（先讲故事）：v9 的在线适应像"每周期给整台发动机换零件"——算力贵、改动无界，而且新零件会悄悄改变 v9 块证书所假设的动力学。PEFT 告诉我们：不必换零件，只在一小块可插拔的"低秩调音片"上拧旋钮。ΔW=BA，rank r 远小于维度。旋钮角度可度量（‖BA‖），所以**策略能偏离基座多远是有上界的**；把这个上界直接写进 v9 块证书的余量项，适配就从"证书之外的法外之地"回到"证书之内的可审计变更"。

严谨一点：设基座策略 π_W 冻结，适配策略 π_{W+BA}。若其余子网络对参数是 L_π-Lipschitz、特征范数 ≤Φ，则
```
‖π_{W+BA}(s) − π_W(s)‖ ≤ L_π·‖BA‖₂·Φ
                        ≤ L_π·Φ·Σ_i |α_i|·‖B_i‖₂·‖A_i‖₂ ≡ ε_pol
```
于是清距误差被 L_g·ε_pol 控制，块证书余量 β_adapt = L_g·ε_pol。这就是**停靠证**：适配不是免费的，它必须从安全余量里"付费"。

更深一层：低秩子空间 S 是一个**假设**——"世界的变化落在当前技能族张成的子空间里"。若真实所需更新有分量落在 S^⊥，优化救不了，那是**世界变了**。定义参数空间残差
```
ρ_res = ‖(I − P_S)·g‖ / (‖g‖ + η)
```
它是 v9 输入空间 Δ_dom 在另一个坐标系里的对偶。两个空间都报警才最可信；两者**分歧**本身就是危险信号。

**灵感 2（姿态估计 → 位姿不确定度的证书传播）**

直觉：清距证书 ĝ_min 把状态当精确的，但真正不确定的是物体 6-DoF 位姿。位姿误差 δξ 经清距雅可比 J_g 放大成间隙误差，旋转误差再乘力臂。固定 safety margin 是拍脑袋；正确做法是把位姿估计器输出的协方差 Σ_ξ **传播**到间隙：
```
σ_g² = J_g·Σ_ξ·J_gᵀ,     g_robust = g(ξ̂) − k_α·σ_g − β_model
```
k_α 不能默认高斯分位——用标定集上的 split-conformal 分位，协方差失配时仍保覆盖率。对称/遮挡物体上位姿是**多峰**的，单峰高斯会系统性低估，故用多假设混合方差
```
Σ_mix = Σ_j w_j·(Σ_j + (ξ_j − ξ̄)(ξ_j − ξ̄)ᵀ),   A_pose = 1 − max_j w_j
```
膨胀——这才诚实。

合流：位姿还能当**适配器的索引键**。按（物体类、位姿分箱、抓取类型、位姿不确定度）检索适配器；位姿越陌生/越歧义，越应退回零适配器（α=0）——与 v9"域越陌生块越短、模块越少"是同一条保守性单调律。

**综合直觉（最危险的地方）**：适配器会**吸收**位姿估计器的系统偏差——它用带偏的位姿去最小化任务损失，于是把偏差编码进 ΔW。结果位姿残差与参数残差同时变小，两个检测器一起静默，而真实位姿误差在增长。这不是调参问题，是**共谋**。对策不是再加一层阈值，而是结构约束：让适配更新与位姿敏感子空间正交（P16），使适配器"不能"吸收位姿偏差。

## 1. 研究问题（轮次升级版）

- **Q1（适配证书紧致性）**：rank-r 约束下的策略偏移上界能否写回 v9 块证书而不把安全余量吃光？ε_max 与 r 的 Pareto 边界在哪？低秩产品谱范数能否以 rank-r 代价精确计算，使证书不是估计而是等式？
- **Q2（位姿证书的诚实性）**：协方差失配与多峰歧义下，g_robust 的覆盖率能否由 conformal 兜底，而非依赖高斯假设？多假设混合方差能否消除对称物体的系统性低估？
- **Q3（双空间共识与共谋）**：Δ_dom 与 ρ_res 的共识/分歧如何定义为信任域 U_t^10？P16 正交约束能否**可证地**阻止适配器吸收位姿系统偏差，而不是仅降低其概率？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 低秩适配证书律（Certified Adaptation, LAB）**
适应限于低秩 ΔW_t = Σ_i α_i B_i A_i，rank ≤ r_max；每周期计算适配证书 ε_pol = L_π·Φ·Σ_i|α_i|·‖B_i‖₂·‖A_i‖₂，并将 β_adapt = L_g·ε_pol 计入 v9 块证书（定义 533/541）。ε_pol > ε_max 或超预算即 α=0（恒等退化）。

**P14 位姿不确定度传播律（Pose-Uncertainty Certificate, PUC）**
间隙证书使用 g_robust = g(ξ̂) − k_α·σ_g − β_model；多峰位姿用 Σ_mix 并附加歧义罚 A_pose；k_α 由标定集 conformal 分位给出，协方差不校准时退回固定保守余量（等价 v9 的证书形式）。

**P15 双空间偏移共识律（Dual-Space Shift Consensus, SSD）**
信任域 U_t^10 同时要求输入空间 Δ_dom < τ_dom、SLAM 风险 risk_SLAM < τ_SLAM、参数空间 ρ̄_res < θ_res、位姿 σ_g < σ_max。两空间**分歧**（一个高一个低）时取保守侧（视为同时越界），而非取平均。

**P16 位姿-适配解耦律（Pose-Adapter Disentanglement, PAD）**
适配更新投影出位姿敏感子空间：A_i ← A_i(I − Φ_pose Φ_poseᵀ)，使 A_iΦ_pose ≈ 0；若位姿敏感基不可估，则禁止适配（α=0）。这是对"适配器吸收位姿偏差"共谋的**结构性**防御，而非又一层阈值。

## 3. 与基线的接口（如何退化）

- LAB 失效/超预算/ε_pol > ε_max ⇒ α=0，等价 v9 冻结基座与 v9 块证书；
- PAD 失效（位姿敏感基不可估）⇒ α=0（禁止可能吸收位姿偏差的适配），等价 v9；
- PUC 失效（位姿丢帧/协方差不校准）⇒ g_robust = g − β_model，固定 d_safe，等价 v9 的证书形式；
- SSD 失效 ⇒ 信任域仅用 v9 的 Δ_dom/risk_SLAM 两条件；
- 全失效 ⇒ v9（ACMD）→ v8（DA-SPR-Cal）→ v7；
- 关键：所有退化都是**注入零适配器或固定余量**，不新增任何可达行为。

## 4. 预期贡献

1. **适配证书**：把 PEFT 的低秩结构从"省算力技巧"升级为"可写回安全证书的有界变更"，并用 rank-r 核心矩阵精确计算谱范数，使界不是估计；
2. **位姿不确定度证书**：把 6-DoF 位姿协方差（含多峰歧义）以可标定覆盖率传播进 v9 块证书，用 conformal 兜底协方差失配；
3. **双空间偏移检测与共谋防御**：输入空间 Δ_dom × 参数空间 ρ_res 的共识，以及 P16 正交解耦对"适配器吸收位姿偏差"的结构性阻断；
4. **预算-安全-适配三闭环**：v9 分块释放的算力供养低秩适配，适配余量反写证书；E571–E590 覆盖 rank 扫描、覆盖率、共谋、切换延迟与端到端。

## 5. 本轮最大风险

**一句话**：低秩适配器可能在最小化"带偏位姿"上的任务损失时，把位姿估计器的系统偏差编码进 ΔW，使位姿残差与子空间残差同时静默——两个检测器一起失明；而 P16 正交投影只能防"位姿敏感基可估"的情形，若 J_pose 本身在陌生位姿下估不准，共谋仍可能发生。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |

**新增定义 540（低秩适配银行 CertifiedAdapterBank, LAB）** 适配器集合 {(B_i,A_i)}_{i=1..m}，基座权重 W 冻结。活跃适配
```
ΔW_t = Σ_{i=1..m} α_i(t)·B_i A_i ,     α_i ∈ [−1,1],  rank(B_iA_i)=r_i≤r_max
```
零适配器（α≡0）为恒等元：forward(W+0)=forward(W)（逐位，未合并实现）。回滚为精确减去对应 α_i 项；多域适配可共存，切换只需改 α。

**新增定义 541（适配证书 AdaptationCertificate）** 设适配层其余子网络 L_π-Lipschitz、特征范数上界 Φ、清距对策略输出的 Lipschitz 常数为 L_g。定义
```
ε_pol(t) = L_π·Φ·‖ΔW_t‖₂ ,      β_adapt(t) = L_g·ε_pol(t)
ĝ_min^CAL = ĝ_min − β_adapt ,     ê_max^CAL = ê_max + β_adapt
```
证书有效 ⇔ ε_pol ≤ ε_max ∧ rank 预算可行。**精确谱范数**：对每个 B_i=Q_Bi R_Bi、A_i=R_Ai Q_Ai 做 QR，令 Q_B=[Q_B1…Q_Bm]（列正交）、Q_A=[Q_A1;…;Q_Am]（行正交）、核心块对角 M=diag(α_i R_Bi R_Ai)，则 ΔW=Q_B M Q_A 且 ‖ΔW‖₂=‖M‖₂（Q_B、Q_A 为等距嵌入）。故 ε_pol 可由 (Σr_i)×(Σr_i) 的核心矩阵**精确**求得，而非估计。

**新增定义 542（参数空间偏移残差 SubspaceShiftDetector, SSD）** 设 g_t 为在线适配目标对适配参数的梯度估计（在最近 T_ssd 个转移的小缓冲上取），P_S 为到 S_t 的正交投影。定义
```
ρ_res(t) = ‖(I − P_S)·g_t‖₂ / (‖g_t‖₂ + η) ,    ρ̄_res ← (1−β_ema)·ρ̄_res + β_ema·ρ_res
```
ρ_res 高 ⇔ 所需更新无法由现有适配器重加权解释 ⇒ 参数空间的"世界变了"。每 T_ssd=50 周期（1s）计算一次。

**新增定义 543（位姿不确定度证书 PoseUncertaintyCertifier, PUC）** 位姿估计输出 ξ̂∈SE(3) 与协方差 Σ_ξ（6×6）。清距雅可比 J_g=∂g/∂ξ（1×6），
```
σ_g² = J_g Σ_ξ J_gᵀ ,      g_robust = g(ξ̂) − k_α·σ_g − β_model
```
k_α 由标定集 {(ξ_i,g_i)} 的 split-conformal 非一致性分数 s_i=(g_i−g(ξ̂_i))/σ_g(ξ̂_i) 的 ⌈(n+1)(1−α)⌉ 分位给出；协方差不校准时 k_α 退回固定保守常数（等价 v9 的 d_safe 语义）。覆盖率：P(g_true ≥ g_robust) ≥ 1−α（引理 88）。

**新增定义 544（多假设位姿歧义 PoseAmbiguity）** 位姿多假设 {(ξ_j,Σ_j,w_j)}_{j=1..H}，Σw_j=1。混合估计
```
ξ̄ = Σ_j w_j ξ_j ,   Σ_mix = Σ_j w_j·(Σ_j + (ξ_j−ξ̄)(ξ_j−ξ̄)ᵀ) ,   A_pose = 1 − max_j w_j
```
A_pose > τ_amb 时用 Σ_mix 取代最高权重假设的 Σ_j；A_pose > τ_amb^hard 时拒绝抓取/改用静态保守余量（PUC 降级）。

**新增定义 545（v10 信任域与双空间共识 TrustDomain）**
```
U_t^10 = [Δ_dom<τ_dom] ∧ [risk_SLAM<τ_SLAM] ∧ [ρ̄_res<θ_res] ∧ [σ_g<σ_max] ∧ [Ĉ_t valid]
```
共识规则：令 s_dom=1[Δ_dom≥τ_dom]、s_res=1[ρ̄_res≥θ_res]。若 s_dom≠s_res（分歧），置 trust=false（**异议即保守**，不取平均）；若 A_pose>τ_amb，同样置 trust=false。

**新增定义 546（位姿条件适配检索 PoseConditionedRetrieval）** 键 k=(object_class, pose_bin, grasp_type, σ_g-bin)。检索表 w:k↦α 或 0；键密度 dens(k)<τ_dens 或 A_pose>τ_amb ⇒ α=0（OOD 位姿退回基座）。相邻桶间用 α-slew 限幅插值（定义 548/引理 93），避免指令跳变。

**新增定义 547（位姿-适配正交投影 PoseAdapterDisentanglement, PAD）** 设 Φ_pose 为位姿敏感输入子空间的正交基（如 ∂x/∂ξ 的前 m 个奇异向量）。约束适配器输入侧不作用于该子空间：
```
A_i ← A_i·(I − Φ_pose Φ_poseᵀ) ,    c_pose = ‖A_i Φ_pose‖_F / (‖A_i‖_F + η) ≤ θ_pose
```
若 Φ_pose 不可估（位姿雅可比病态/丢帧），则 α=0（禁止适配）。正交性使得位姿系统偏差方向**不可被适配器表示**，从结构上排除"共谋"（引理 90）。

**新增定义 548（适配预算调度 AdaptationBudgetScheduling, ABS）** 每周期适配开销 C_ad=Σ_i r_i(d_i+k_i) MACs，约束 C_ad ≤ B_ad（v9 分块释放的预算）且经 MW deadline_guard 保证总时延。按边际效用 u_i（取自 v9 ID 的贡献 c_m 或任务回报）贪心分配 rank：在 Σr_i(d_i+k_i)≤B_ad 下最大化 Σu_i r_i；超预算先丢弃最低效用适配器。切换时对 α 施加 slew 限幅 |Δα_i|/cycle ≤ δ_α。

**新增定义 549（v10 退化链）** 见第 0 节五级；形式化保证：L1/L2 ⇒ α=0；L3 ⇒ k_α=0、β_model=v9 值；L4 ⇒ U_t^10 去掉 ρ_res 条件退化为 v9 两条件；L5 ⇒ v9。任一降级路径的输出与对应 v9 代码路径逐位一致（引理 91）。

# IP-357 CertifiedAdapterBank：低秩适配银行
class CertifiedAdapterBank:
    def __init__(self, r_max=8, eps_max=0.05, L_pi=1.0, L_g=2.0, Phi=10.0):
        self.bank = []            # list of (B, A)
        self.r_max, self.eps_max = r_max, eps_max
        self.L_pi, self.L_g, self.Phi = L_pi, L_g, Phi

    def active_delta(self, alpha):
        dW = None
        for a, (B, A) in zip(alpha, self.bank):
            term = a * (B @ A)
            dW = term if dW is None else dW + term
        return dW                                   # alpha=0 → 零矩阵（恒等）

    def spectral_norm_exact(self, alpha):
        QBs, QAs, blocks = [], [], []
        for a, (B, A) in zip(alpha, self.bank):
            QB, RB = qr(B)                          # d×r, r×r
            QA, RA = qr(A.T)                        # k×r, r×r → A = RA.T @ QA.T
            QBs.append(QB); QAs.append(QA)
            blocks.append(a * (RB @ RA.T))          # r×r 核心块
        M = block_diag(blocks)                      # (Σr)×(Σr)
        return svdvals(M).max()                     # == ‖Σ a_i B_i A_i‖₂（定义 541）

    def certificate(self, alpha):
        dW = self.active_delta(alpha)
        eps_pol = self.L_pi * self.Phi * self.spectral_norm_exact(alpha)
        return eps_pol, self.L_g * eps_pol, eps_pol <= self.eps_max

    def project_out_pose(self, A, Phi_pose):
        if Phi_pose is None:
            return None                             # 不可估 → 调用方置 alpha=0
        return A @ (torch.eye(A.shape[1]) - Phi_pose @ Phi_pose.T)

    def rank_r_update(self, grad, lr):
        U, S, Vh = randomized_svd(-lr * grad, self.r_max)   # O(dk·r)
        return U @ torch.diag(S) @ Vh               # 新适配器（低秩截断）


# IP-358 PoseUncertaintyCertifier：位姿不确定度证书器
def robust_clearance(pose_est, J_g, k_alpha, beta_model):
    sigma_g = float(torch.sqrt(J_g @ pose_est.Sigma @ J_g.T + 1e-12))
    g = clearance(pose_est.xi)                       # 由位姿算清距
    return g - k_alpha * sigma_g - beta_model, sigma_g

def mix_pose(hypotheses):
    xibar = sum(w * xi for (xi, _, w) in hypotheses)
    Sigma = sum(w * (S + torch.outer(xi - xibar, xi - xibar))
                for (xi, S, w) in hypotheses)
    A_pose = 1.0 - max(w for (_, _, w) in hypotheses)
    return xibar, Sigma, A_pose

def conformal_k(scores, alpha):                      # split-conformal 分位
    n = len(scores)
    q = sorted(scores)[min(n - 1, math.ceil((n + 1) * (1 - alpha)) - 1)]
    return q


# IP-359 SubspaceShiftDetector：参数空间偏移检测器
def subspace_residual(g, S_basis, eta=1e-8):
    # S_basis: 正交列，张成当前适配器子空间 S_t
    g_par = S_basis @ (S_basis.T @ g)
    return torch.linalg.norm(g - g_par) / (torch.linalg.norm(g) + eta)


# IP-360 PoseAdapterCoupler：位姿条件检索 + 正交解耦
class PoseAdapterCoupler:
    def __init__(self, retriever, Phi_pose, theta_pose=0.05, tau_dens=...):
        self.retriever, self.Phi_pose, self.theta_pose = retriever, Phi_pose, theta_pose
        self.tau_dens = tau_dens

    def select(self, obj_class, pose_bin, grasp_type, sigma_g):
        if self.Phi_pose is None:                    # PAD 不可用 → 禁止适配
            return zeros_like_alpha(), "pad_unavailable"
        key = (obj_class, pose_bin, grasp_type, bin_sigma(sigma_g))
        if self.retriever.density(key) < self.tau_dens:
            return zeros_like_alpha(), "ood_pose"    # α=0 ⇒ v9
        alpha = self.retriever.lookup(key)
        for i, (B, A) in enumerate(self.retriever.bank):
            A_proj = A @ (I - self.Phi_pose @ self.Phi_pose.T)
            if fro_norm(A_proj @ self.Phi_pose) > self.theta_pose * (fro_norm(A) + 1e-8):
                alpha[i] = 0.0                       # 违反正交性 ⇒ 该适配器禁用
        return alpha, "ok"


# 主闭环集成：MetricVoiceGauge-CALIPER
def metricvoicegauge_round_10(M, s, obs, audio_stream=None, ell=None, ...):

## 4. 推导

**引理 87（低秩适配偏移界与证书紧致性）** 对 ΔW=Σ_i α_i B_i A_i：
(i) ‖ΔW‖₂ ≤ Σ_i |α_i|·‖B_i‖₂·‖A_i‖₂（次乘性 + 三角不等式）；
(ii) 精确谱范数可由 (Σr_i)×(Σr_i) 核心矩阵 M=diag(α_i R_Bi R_Ai) 求得，因 ΔW=Q_B M Q_A 且 Q_B 列正交、Q_A 行正交，故 ‖ΔW‖₂=‖M‖₂，代价 O((Σr)²(d+k)+(Σr)³)；
(iii) 于是 ε_pol ≤ L_π Φ Σ_i|α_i|‖B_i‖₂‖A_i‖₂，β_adapt=L_g ε_pol 是合法的证书膨胀；把 v9 引理 82 中的 d_safe 换成 d_safe+β_adapt 后安全性结论不变。
证明：(i)(ii) 如上；(iii) 策略输出差 = ΔW·φ(s)，取范数并用 (i)，再由清距对输出的 L_g-Lipschitz 得清距误差 ≤ L_g ε_pol。紧致性：存在对齐的 rank-1 B、A 使 (i) 取等，故该界在最坏情况下不可改进（平均意义可更松，需 E572 标定）。∎

**引理 88（位姿证书覆盖率与块证书合成）** 设标定集与测试位姿可交换。则 split-conformal 给出
```
P(g_true ≥ g(ξ̂) − k_α·σ_g) ≥ 1 − α
```
再计入前向模型误差违反概率 δ_m（v9 β_model 的标定保证），有
```
P(Ĉ_t valid ⇒ g_true ≥ d_safe) ≥ 1 − α − δ_m
```
证明：conformal 边际覆盖定理给出非一致性分数 s≤k_α 的概率 ≥1−α；模型误差事件与位姿误差事件取并集上界（union bound）。当协方差失配时，conformal 仍以经验分位保证边际覆盖；当 k_α 不可标定时退回固定保守常数，此时退化为 v9 的确定性余量。∎

**引理 89（子空间残差的可检测间隙）** 设 g_t=g_t^∥+g_t^⊥，g_t^⊥∈S_t^⊥，‖g_t‖≤G。
(i) 分布内可表示：‖g_t^⊥‖ ≤ ε_res ⇒ ρ_res ≤ ε_res/(‖g_t‖+η)；
(ii) 参数空间偏移：‖g_t^⊥‖ ≥ γ ⇒ ρ_res ≥ γ/(G+η)。
故当 γ>ε_res 时存在阈值 θ_res∈(ε_res/(G+η), γ/(G+η)) 实现分离；在 T_ssd 个次高斯探针下，EMA 估计以速率 exp(−Ω(T_ssd Δ²)) 集中，可按目标虚警率 δ 选 θ_res。
证明：直接由范数比与投影的幂等性；集中不等式用 Hoeffding/Bernstein。注意该结论依赖"能取得低噪声梯度探针"这一假设，非平稳与梯度噪声会侵蚀间隙（E575 标定）。∎

**引理 90（双空间共识不足与解耦必要性）** 设位姿估计存在窗口内常值系统偏差 b（ξ̂=ξ_true+b），任务损失对位姿的一阶敏感方向为 j=∂L/∂ξ·b，且 j 落在适配器子空间 S_t 内。则在带偏数据上收敛的无约束适配器满足沿 j 方向的一阶最优条件，使参数残差 ρ_res 沿 j 近似为零、位姿残差也在任务损失中不可见；于是存在环境使真实清距误差 ‖J_g b‖>d_safe，而 v9/v10（未启用 PAD）的所有检测器均报"域内"。启用 PAD 后 A_iΦ_pose=0，位姿敏感方向不可被适配器表示，同一 b 无法被抵消，偏差只能留在 g_robust 的 k_ασ_g 项与任务损失中而保持可见。
证明：对 L(ΔW;ξ̂) 在 ξ_true 处一阶展开，得 L(ΔW;ξ̂)=L(ΔW;ξ_true)+⟨j,vec(ΔW)⟩+O(‖b‖²)；j∈S_t 时适配器可令一阶项为零。PAD 将 vec(ΔW) 限制在 S_t∩(pose-sensitive)^⊥，当 j 有非零位姿敏感分量时 ⟨j,vec(ΔW)⟩ 不能为零，故偏差不可被吸收。∎

**引理 91（零适配器精确退化）** α=0 ⇒ ΔW=0 ⇒（未合并实现下）forward(W+ΔW)=forward(W) 逐位一致；PUC 失效令 k_α=0、β_model=v9 值，使 g_robust=g−β_model，回到 v9 定义 533 的证书形式；SSD 失效移除 U_t^10 的 ρ_res 条件，回到 v9 的两条件信任域。故 v10 在对应组件失效时与 v9 逐位等价，并可按 v9 引理 83 继续逐级退化到 v8/v7。∎

**引理 92（预算不变与 50Hz 守恒）** 每周期新增开销：适配前向 O(Σr_i(d+k))；证书谱范数 O((Σr)²(d+k)+(Σr)³)，仅在 5Hz 块边界计算，摊销 ≤1ms/cycle；PUC O(m²)=O(36)；SSD 每 T_ssd=50 周期一次 O(P·r)，摊销 O(1)/cycle；PAC 检索 O(1)。取 r_max=8 时 C_ad ≤ B_ad（v9 分块释放的预算），配合 MW deadline_guard 强制 Ŵ_m，总决策时延仍 ≤20ms，50Hz 守恒。相比全参数微调 O(dk)，适配计算降为 O(r(d+k))，约 d/r 倍。∎

**引理 93（切换平滑与无 Zeno）** 切换适配器仅改变 α，策略跳变 ≤ L_π Φ Σ_i|Δα_i|‖B_iA_i‖₂。取 slew 限幅 |Δα_i|/cycle ≤ δ_α，使单周期跳变 ≤ 证书余量 slack，则执行指令连续（无跳变）；α 的单调限幅同时限制单位时间切换次数，故无 Zeno 抖振。证明：离散 Lipschitz + 望远镜求和。∎

## 8. 本轮最大风险

**一句话**：低秩适配器可能在最小化"带偏位姿"上的任务损失时，把位姿估计器的系统偏差编码进 ΔW，使位姿残差与子空间残差同时静默——两个检测器一起失明；而 P16 正交投影只能防"位姿敏感基可估"的情形，若 J_pose 本身在陌生位姿下估不准，共谋仍可能发生。
