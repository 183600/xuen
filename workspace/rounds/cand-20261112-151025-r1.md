# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC、IP-153~160；灵感循环第 7 轮；本轮灵感：「动作分块」×「强化学习」）

> 第 60 轮用 SSM/CIEC/EPIR/SERC 把「认知先行」接入了场景-执行闭环。但**三个根本局限**仍未解决：
> 1. **单步决策的时间不一致**：SERC 每个接触周期独立重编译一次 K_safe，相邻周期的阻抗可任意跳变；SSM 只给了「空间先验」，没给「时间连续性」。结果是阻抗抖动、能量注入、以及场景边界上的「锯齿式」切换——设备被反复「掰」而不是被平稳「带」过去。
> 2. **证据只校验、不改进**：第 60 轮把 EV-exec/J_exec/D⁺ 用于 SIC 置信度更新和 EPIR 因果校验，但整个证据层从未反过来优化「场景/意图 → 阻抗」的决策映射。经验被存档却没有被学习，闭环缺了「学习」这一环。
> 3. **探索与安全的正面对撞**：一旦引入学习就必须探索；但执行层的硬安全约束（ERTC/CIEC）不允许「试错式」探索，而 EPIR 若把被 ROS 污染/乱序的证据喂给学习器，会「越学越坏」——学习反而放大抽象泄漏。

## 0. 直觉与动机

**灵感 1（动作分块 → 阻抗分块策略 ACI）**
直觉：人伸手拿杯子，不是每毫秒重算一次肌肉刚度，而是先「一次性规划一段动作」，再在执行中微调。第 60 轮的阻抗决策恰恰是「每毫秒重算一次刚度」：每个接触周期独立 argmin，K 序列没有时间结构。把「阻抗参数」当作动作，一次预测 H 步的阻抗轨迹 K_{t:t+H}，再用滚动时域 + 时间集成执行——用「块」把单步噪声平均掉（降低复合误差），用「重叠块」让阻抗在场景切换处平滑插值（从 Z_rigid 渐变到 Z_slope）。关键洞见：**分块不是降低决策频率，而是把「时间一致性」从一条约束变成策略的输出结构**。

**灵感 2（强化学习 → 证据驱动策略改进 EDRL）**
直觉：第 60 轮的 EV-exec、J_exec 证书、D⁺ 差异，本质上就是「执行后的打分」。既然每次执行都有分数，就能把「证据」变成「奖励」。用离线/保守强化学习在「已归档、且经 EPIR 因果校验」的轨迹上学习 π_θ(K_{t:t+H} | z_scene, C_intent)。关键洞见：**不在真实世界在线试错，而是在「已发生的证据」上做保守离线学习**——探索发生在样本重加权与视界选择里，而不是发生在危险的参数空间里。

**灵感 3（安全护盾 → 分块安全投影 SSRL）**
直觉：学习器为追奖励可能输出激进阻抗（例如为压低 D⁺ 把 K_p 拉到极限），撞坏工件。把第 60 轮的 ERTC 契约与 CIEC 意图锁定从「事后校验」升级为「动作投影护盾」：策略输出的每个 K 块先投影到安全域 K_safe^scene ∩ C_intent；投影距离过大就整块拒收、回退保守编译。关键洞见：**安全不是学习的一个惩罚项，而是学习的动作空间本身**——RL 只在「已证明安全」的集合内做选择。

**灵感 4（因果证据门控 → 学习数据净化 CER）**
直觉：若 EPIR 校验失败、或 ROS 证据乱序，这些样本进 replay buffer 会让策略学到「错误因果」。用第 60 轮的 seq_id+hash+timestamp 三重因果检验当「数据门」：通过的样本按时间衰减加权，未通过的隔离到 quarantine，永不参与训练。关键洞见：**证据链完整性不只保护「合规审计」，也保护「学习正确性」**——脏证据比没证据更危险。

**灵感 5（场景条件视界 → SCH）**
直觉：平滑桌面可以一次规划 H=10 步；临近湿滑边界或楼梯时，任何长块都会「把旧场景平均进新场景」。用 SSM 的场景转变概率 κ_scene 自适应缩短视界，并让时间集成在检测到场景切换时「杀死」跨边界的旧块。关键洞见：**分块视界必须由「场景确定性」驱动，而不是由算力预算驱动**。

**灵感 6（三灵感合流 → ACRL 闭环）**
场景（SSM）→ 视界（SCH）→ 策略分块（ACI）→ 安全投影（SSRL）→ 执行 → EV-exec → 因果门控（CER）→ replay → 离线策略改进（EDRL）→ 更新的策略。闭环从第 60 轮的「认知驱动执行」升级为「认知驱动执行，执行反哺学习」。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（动作分块阻抗策略 ACI）** 分块策略 π_θ：S → K^{H}，S=(z_scene, C_intent, ξ_telemetry)，输出 K_{t:t+H}=(K_t,...,K_{t+H-1})，H∈[H_min,H_max]。滚动时域只执行前 m≤H 步；执行时用时间集成：
K_exec(t) = Σ_{i=0}^{H-1} w_i(t)·K^{(i)}_t / Σ_i w_i(t)，w_i(t)=exp(−λ·(t−t_i))·1[t∈[t_i,t_i+H)]
其中 K^{(i)}_t 是第 i 个块对时刻 t 的预测，w_i 随块龄指数衰减。滚动的「块龄」与「剩余视界」共同决定一个块对当前执行时刻的话语权。

**定义 162（分块一致性契约 CCC）** 一个块 K_{t:t+H} 合法当且仅当：
(i) **平滑性**：||K_{s+1}−K_s||_∞ ≤ δ_K，∀s∈[t,t+H)；
(ii) **边界一致性**：||K^{(j)}_{t_j+H} − K^{(j+1)}_{t_j+H}||_∞ ≤ ε_chunk（相邻块在重叠边界的差）；
(iii) **可行性**：K_s ∈ K_safe^scene(z_s) ∩ C_intent，∀s。
CCC(K_{t:t+H}) = (smooth_witness, boundary_witness, feasibility_witness)，任一项失败则块不可签发。

**定义 163（证据驱动强化学习 EDRL）** 以执行证据构造 MDP：状态 S=(z_scene,C_intent,ξ)，动作 A=K_{t:t+H}，奖励
r_t = −λ_D·D⁺_t − λ_E·ECE_t − λ_C·cost_t − λ_V·1[violation_t] − λ_S·||K_{t+1}−K_t||_∞
离线数据集 D={(s,a,r,s')} 由 CER 门控后的 EV-exec 组成，样本权重 w。采用保守 Q 学习（CQL）目标：
L(θ)=E_{(s,a)~D}[(Q_θ(s,a)−(r+γ·E_{a'~π_θ}Q̄(s',a')))²] + α·(E_{s~D}[logΣ_a exp Q_θ(s,a)] − E_{(s,a)~D}[Q_θ(s,a)])
负项抑制「证据未覆盖区域」的过高估值，从而**不在分布外（OOD）阻抗上冒险**；α 即保守强度。

**定义 164（分块安全投影护盾 SSRL）** 护盾
Π_shield(K_{t:t+H}; z, C_intent) = argmin_{K'_{t:t+H}∈F} ||K'−K||_∞，
可行域 F={K' : CCC(K')=true ∧ K'_s∈K_safe^scene(z)∩C_intent}。
拒收规则：若 min_{K'∈F}||K'−K||_∞ > ε_shield，则整块拒收并回退保守块
K^cons = EEIS.compile_chunk_conservative(δ_f^req, H)。
探索只通过「视界 H / 集成宽度 / 采样温度」进行，不通过放大参数域进行。

**定义 165（因果证据门控 CER）** 对证据 e=(timestamp,seq_id,hash,content)：
admit(e)=1 当且仅当 seq 连续、hash 匹配、timestamp 单调、EPIR 因果图无环。
replay 权重 w_e = admit(e)·exp(−age(e)/τ_ev)·γ_EV。未通过者进入隔离区 Q；|Q| 超限则丢弃最旧样本。污染率上界由 admit 的假阳性率控制。

**定义 166（场景条件自适应视界 SCH）** H_t = clamp(round(H_max·(1−κ_scene(z_t))), H_min, H_max)，κ_scene 取 SSM 的场景转变后验。当 κ_scene>τ_switch 时：(i) H 缩到 H_min；(ii) 时间集成中旧块权重 w_i←0（kill stale chunk）；(iii) 触发一次保守整块编译。

**定义 167（五维学习预算 PCE+++++）** B = (B_scene, B_intent, B_ros, B_exec, B_learn)，新增
B_learn=(Chunk_compute, Ensemble_width, Replay_size, Train_ops)。
VOI 扩展：voi_learn(π)=VOI_cog(π)−cost_learn(π)，
cost_learn=λ_chunk·H·C_compile + λ_rl·Train_ops + λ_ens·H·Ensemble_width。
若 B_learn 耗尽：冻结 θ（沿用最近一次通过 CCC 的策略），H 退回 1；若 B_chunk 耗尽：禁用分块、退回单步；若 B_rl 耗尽：只推理不训练。

**定义 168（分块执行证书 J_chunk）** J_chunk = (Cert_eeis(t..t+H), smooth_wit, boundary_wit, shield_wit, hash_chain)，其中 hash_chain 把块内每步 EV-exec 的 hash 链接成链。J_chunk 可验证：∀s，K_s∈K_safe^scene∩C_intent ∧ ||K_{s+1}−K_s||≤δ_K ∧ Π_shield 距离≤ε_shield；且链头尾 hash 与 EPIR 记录一致。J_chunk 是第 59 轮 J_exec 的「时间维扩展」。

**定义 169（ACRL 闭环算子）** ACRL(M, intent, δ_f^req)：
```
① SSM:  z, κ ← scene_model.update(telem)
② SCH:  H ← clamp(round(H_max(1−κ)), H_min, H_max); if κ>τ_switch: policy.kill_stale()
③ CIEC: C_intent ← intent_ctrl.receive_intent(intent)
④ ACI:  K_chunk ← π_θ(z, C_intent, telem, H)
⑤ SSRL: (K_chunk^safe, ok) ← shield.project(K_chunk, z, C_intent)
        if not ok: K_chunk^safe ← EEIS.compile_chunk_conservative(δ_f^req, H)
⑥ 执行前 m 步：K_ens ← policy.temporal_ensemble(t); telem ← run_contact(K_ens)
⑦ EPIR: EV ← build_exec_evidence(telem, K_ens); S_shadow.append(EV)
⑧ CERT: J_chunk ← certify_chunk(K_chunk^safe)
⑨ CER:  for EV in drain_verified(): replay.offer(EV)
⑩ EDRL: if budget.allow_train(): rl.update(replay, π_θ, Q, Q̄)
⑪ return (z, K_chunk^safe, J_chunk, replay.status, budget.status)
```

## 2. 关键算法伪代码

### IP-161 / IP-166 ACI + SCH（分块策略与自适应视界）

```python
class ActionChunkedImpedancePolicy:
    def __init__(self, H_max=10, H_min=2, m_exec=1, lam=0.5):
        self.H_max, self.H_min, self.m_exec = H_max, H_min, m_exec
        self.lam = lam
        self.pending = deque(maxlen=H_max)      # (t0, K_chunk)
        self.theta = init_policy()

    def horizon(self, kappa_scene):
        H = int(round(self.H_max * (1.0 - kappa_scene)))
        return max(self.H_min, min(self.H_max, H))

    def predict(self, z_scene, c_intent, telemetry, H):
        return self.theta(z_scene, c_intent, telemetry, H)   # K_{t:t+H}

    def temporal_ensemble(self, t):
        num, den = None, 0.0
        for t0, chunk in self.pending:
            i = t - t0
            if 0 <= i < len(chunk):
                w = math.exp(-self.lam * i)
                num = w * chunk[i] if num is None else num + w * chunk[i]
                den += w
        return None if den == 0 else num / den

    def kill_stale(self):
        self.pending.clear()                    # 场景切换：丢弃跨边界旧块
```

### IP-164 SSRL（分块安全投影护盾）

```python
class ChunkSafetyShield:
    def __init__(self, eeis, ertc, eps_shield=0.15):
        self.eeis, self.ertc, self.eps = eeis, ertc, eps_shield

    def _feasible(self, K, z_scene, c_intent):
        return (self.eeis.in_scene_safe_set(K, z_scene)
                and self.ertc.satisfies(K)
                and self.ertc.intent_mask_satisfies(K, c_intent))

    def project(self, chunk, z_scene, c_intent):
        if all(self._feasible(K, z_scene, c_intent) for K in chunk):
            return chunk, True
        K_cons = self.eeis.compile_chunk_conservative(z_scene, len(chunk))
        d = max(inf_norm(a - b) for a, b in zip(chunk, K_cons))
        if d > self.eps:
            return K_cons, False                # 整块拒收，回退保守
        return self._clip_chain(chunk, z_scene, c_intent), True
```

### IP-163 / IP-165 EDRL + CER（证据驱动学习与门控）

```python
class CausalEvidenceReplay:
    def __init__(self, cap=10000, tau_ev=1e3):
        self.buf, self.quarantine = [], []
        self.cap, self.tau = cap, tau_ev

    def offer(self, ev, now):
        ok = (ev.seq_continuous and ev.hash_match
              and ev.timestamp_monotone and ev.causal_acyclic)
        if not ok:
            self.quarantine.append(ev)
            return 0.0
        w = math.exp(-(now - ev.timestamp) / self.tau)
        self.buf.append((ev, w))
        if len(self.buf) > self.cap:
            self.buf.pop(0)
        return w

class EvidenceDrivenRL:
    def __init__(self, alpha=0.5, gamma=0.99):
        self.alpha, self.gamma = alpha, gamma

    def update(self, replay, pi, Q, Qbar, batch=256):
        for s, a, r, s2, w in replay.sample(batch):
            target = r + self.gamma * Qbar(s2, pi(s2))
            q_loss = w * (Q(s, a) - target) ** 2
            cql = self.alpha * (logsumexp(Q(s, .)) - Q(s, a))
            backward(q_loss.mean() + cql)
```

### IP-169 ACRL（分块强化学习闭环）

```python
def action_chunked_rl_loop(M, intent, delta_f_req):
    z, kappa = M.scene_model.update(M.telem_force, M.telem_pos)
    H = M.policy.horizon(kappa)
    if kappa > M.tau_switch:
        M.policy.kill_stale()

    c_intent = M.intent_ctrl.receive_intent(intent) if intent else None
    K_chunk = M.policy.predict(z, c_intent, M.telem, H)

    K_safe_chunk, accepted = M.shield.project(K_chunk, z, c_intent)
    if not accepted:
        K_safe_chunk = M.eeis.compile_chunk_conservative(delta_f_req, H)
    J_chunk = M.certifier.certify(K_safe_chunk)

    for _ in range(min(M.policy.m_exec, H)):
        K_ens = M.policy.temporal_ensemble(M.t)
        M.telemetry = run_contact(K_ens)
        EV = build_exec_evidence(M.telemetry, K_ens)
        M.epir.append(EV)
        M.policy.pending.append((M.t, K_safe_chunk))
        M.t += 1

    for EV in M.epir.drain_verified():
        M.replay.offer(EV, now=M.t)

    if M.budget.allow_train() and len(M.replay) >= M.batch:
        M.rl.update(M.replay, M.policy.theta, M.Q, M.Qbar)
        M.budget.consume_train()

    return M, z, K_safe_chunk, J_chunk
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ACI | O(H·|K|) 预测 + O(H) 集成 | O(H·|K|) | 时间集成降低方差；复合误差随 H 有界 |
| CCC | O(H) | O(H) | 平滑/边界/可行三见证可验证 |
| EDRL | O(batch·|A|) | O(|D|) | CQL 给出保守价值下界 |
| SSRL | O(H·proj) | O(H) | 执行动作恒在安全域 |
| CER | O(1)/样本 | O(cap) | 脏证据隔离，污染偏差 ≤ 假阳性率 |
| SCH | O(1) | O(1) | 场景切换响应 ≤ 1 周期 |
| ACRL | O(闭环) | 复用 | 端到端安全不变量 |

**正确性定理（ACRL）**：假设 A66–A70 成立。
(A66) ACI：时间集成权重 w_i 指数衰减，块内预测误差 ε_H 随 H 线性有界，集成后方差 ≤ 单步方差/(Σw_i)²。
(A67) CCC：平滑、边界、可行三见证均由 EEIS/ERTC 生成，见证不可伪造。
(A68) EDRL：CQL 的保守项保证 Q_θ 在分布外动作上不高于真实回报加 α 松弛，故策略改进不会因 OOD 高估而崩坏。
(A69) SSRL：Π_shield 的值域 F 是安全域子集，且拒收规则覆盖投影失败，故任何被执行的动作都在安全域内。
(A70) CER：admit 只依赖 EPIR 已验证字段，未验证样本不进 replay，故 replay 污染率 ≤ 假阳性率。
则：
1. **时序平滑性**：CCC 成立 ⇒ 执行阻抗满足 ||K_{s+1}−K_s||∞≤δ_K，切换能量与抖动有界。
2. **安全不变式**：∀ 执行步，K∈K_safe^scene∩C_intent，RL 永不越过 ERTC/CIEC 硬约束。
3. **策略改进性**：在 CER 门控证据上做保守离线更新 ⇒ 代理目标单调不降，且 J(π_new) ≥ J(π_old) − ε_conservative。
4. **证据可信性**：replay 中未验证样本数为 0，学习偏差受假阳性率控制。

## 5. 本轮最大风险

**一句话**：最大风险是「安全护盾把 RL 的探索空间压成只剩保守策略，证据驱动的改进退化为自我确认的保守回路」，同时「时间集成在场景突变处平均了过期块，把平滑变成迟钝」——必须在 κ_scene>τ_switch 时立即 kill_stale、用留出证据（held-out EV-exec）检验策略改进、并给护盾注入可审计的松弛额度，否则「分块 + 学习」会同时损失敏捷性与安全性。

# 第 61 轮产物 · 创新点清单 v1：ACRL（分块强化学习闭环：动作分块×证据驱动强化学习，ACI×CCC×EDRL×SSRL×CER×SCH×PCE+++++×J_chunk）

## 2. 关键算法伪代码

### IP-161 / IP-166 ACI + SCH（分块策略与自适应视界）

```python
class ActionChunkedImpedancePolicy:
    def __init__(self, H_max=10, H_min=2, m_exec=1, lam=0.5):
        self.H_max, self.H_min, self.m_exec = H_max, H_min, m_exec
        self.lam = lam
        self.pending = deque(maxlen=H_max)      # (t0, K_chunk)
        self.theta = init_policy()

    def horizon(self, kappa_scene):
        H = int(round(self.H_max * (1.0 - kappa_scene)))
        return max(self.H_min, min(self.H_max, H))

    def predict(self, z_scene, c_intent, telemetry, H):
        return self.theta(z_scene, c_intent, telemetry, H)   # K_{t:t+H}

    def temporal_ensemble(self, t):
        num, den = None, 0.0
        for t0, chunk in self.pending:
            i = t - t0
            if 0 <= i < len(chunk):
                w = math.exp(-self.lam * i)
                num = w * chunk[i] if num is None else num + w * chunk[i]
                den += w
        return None if den == 0 else num / den

    def kill_stale(self):
        self.pending.clear()                    # 场景切换：丢弃跨边界旧块
```

### IP-164 SSRL（分块安全投影护盾）

```python
class ChunkSafetyShield:
    def __init__(self, eeis, ertc, eps_shield=0.15):
        self.eeis, self.ertc, self.eps = eeis, ertc, eps_shield

    def _feasible(self, K, z_scene, c_intent):
        return (self.eeis.in_scene_safe_set(K, z_scene)
                and self.ertc.satisfies(K)
                and self.ertc.intent_mask_satisfies(K, c_intent))

    def project(self, chunk, z_scene, c_intent):
        if all(self._feasible(K, z_scene, c_intent) for K in chunk):
            return chunk, True
        K_cons = self.eeis.compile_chunk_conservative(z_scene, len(chunk))
        d = max(inf_norm(a - b) for a, b in zip(chunk, K_cons))
        if d > self.eps:
            return K_cons, False                # 整块拒收，回退保守
        return self._clip_chain(chunk, z_scene, c_intent), True
```

### IP-163 / IP-165 EDRL + CER（证据驱动学习与门控）

```python
class CausalEvidenceReplay:
    def __init__(self, cap=10000, tau_ev=1e3):
        self.buf, self.quarantine = [], []
        self.cap, self.tau = cap, tau_ev

    def offer(self, ev, now):
        ok = (ev.seq_continuous and ev.hash_match
              and ev.timestamp_monotone and ev.causal_acyclic)
        if not ok:
            self.quarantine.append(ev)
            return 0.0
        w = math.exp(-(now - ev.timestamp) / self.tau)
        self.buf.append((ev, w))
        if len(self.buf) > self.cap:
            self.buf.pop(0)
        return w

class EvidenceDrivenRL:
    def __init__(self, alpha=0.5, gamma=0.99):
        self.alpha, self.gamma = alpha, gamma

    def update(self, replay, pi, Q, Qbar, batch=256):
        for s, a, r, s2, w in replay.sample(batch):
            target = r + self.gamma * Qbar(s2, pi(s2))
            q_loss = w * (Q(s, a) - target) ** 2
            cql = self.alpha * (logsumexp(Q(s, .)) - Q(s, a))
            backward(q_loss.mean() + cql)
```

### IP-169 ACRL（分块强化学习闭环）

```python
def action_chunked_rl_loop(M, intent, delta_f_req):
    z, kappa = M.scene_model.update(M.telem_force, M.telem_pos)
    H = M.policy.horizon(kappa)
    if kappa > M.tau_switch:
        M.policy.kill_stale()

    c_intent = M.intent_ctrl.receive_intent(intent) if intent else None
    K_chunk = M.policy.predict(z, c_intent, M.telem, H)

    K_safe_chunk, accepted = M.shield.project(K_chunk, z, c_intent)
    if not accepted:
        K_safe_chunk = M.eeis.compile_chunk_conservative(delta_f_req, H)
    J_chunk = M.certifier.certify(K_safe_chunk)

    for _ in range(min(M.policy.m_exec, H)):
        K_ens = M.policy.temporal_ensemble(M.t)
        M.telemetry = run_contact(K_ens)
        EV = build_exec_evidence(M.telemetry, K_ens)
        M.epir.append(EV)
        M.policy.pending.append((M.t, K_safe_chunk))
        M.t += 1

    for EV in M.epir.drain_verified():
        M.replay.offer(EV, now=M.t)

    if M.budget.allow_train() and len(M.replay) >= M.batch:
        M.rl.update(M.replay, M.policy.theta, M.Q, M.Qbar)
        M.budget.consume_train()

    return M, z, K_safe_chunk, J_chunk
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| ACI | O(H·\|K\|) + O(H) | O(H·\|K\|) | 集成降方差，复合误差随 H 有界 |
| CCC | O(H) | O(H) | 三见证可验证 |
| EDRL | O(batch·\|A\|) | O(\|D\|) | CQL 保守下界，OOD 抑制 |
| SSRL | O(H·proj) | O(H) | 执行恒在安全域 |
| CER | O(1)/样本 | O(cap) | 脏证据隔离 |
| SCH | O(1) | O(1) | 场景切换 ≤ 1 周期响应 |
| ACRL | O(闭环) | 复用 | 安全不变式 |

**正确性定理（ACRL）**：若 A66–A70 成立，则：
1. **时序平滑性**：CCC 成立 ⇒ ||K_{s+1}−K_s||∞≤δ_K，切换能量与抖动有界。
2. **安全不变式**：∀ 执行步 K∈K_safe^scene∩C_intent，RL 永不越过 ERTC/CIEC 硬约束。
3. **策略改进性**：CER 门控证据 + 保守离线更新 ⇒ 代理目标单调不降，J(π_new)≥J(π_old)−ε_conservative。
4. **证据可信性**：replay 未验证样本数为 0，学习偏差受 admit 假阳性率控制。
5. **预算安全性**：任一 B_* 耗尽 ⇒ 冻结策略 / H=1 / 只推理不训练 / 本地闭环（沿用第 60 轮策略）。

## 5. 本轮最大风险

**一句话**：最大风险是「安全护盾把 RL 的探索空间压成只剩保守策略，证据驱动的改进退化为自我确认的保守回路」，同时「时间集成在场景突变处平均了过期块，把平滑变成迟钝」——必须以 κ_scene>τ_switch 时 kill_stale、held-out EV-exec 检验改进、以及可审计的护盾松弛额度三重护栏，避免「分块 + 学习」同时损失敏捷性与安全性。
