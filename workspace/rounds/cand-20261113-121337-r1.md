# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「嵌入式系统」×「状态隔离」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因依赖「故障属于有限假设集」与「视觉/几何失效相互独立」；真实复合/未知故障会被强行归入最近假设、只膨胀错误的球，而系统会因为「已经归因」而更自信地继续执行。** 根因不是估计器不够精确，而是**归因后验本身是一个全局共享、就地可变、只增不减的状态**：一次错误写入就污染全部下游决策，且无法撤销、无法回放、无法回滚。本轮不去把假设集再扩大一圈，而是换一个系统结构问题：

> **如何让一次错误归因在物理上「够不到」执行器？**

本轮核心命题：**把「故障可归因」升级为「故障可遏制」——用嵌入式系统的空间/时间分区把估计、归因、执行切成互不共享可变状态的故障遏制域（FCR）；归因只作为「推测性事务」，须经独立证据法定人数确认才提交，否则回滚或安全停机；执行器只由特权安全内核在认证时间槽内驱动。**

## 0. 直觉与动机

**灵感 1（嵌入式系统 → 不修软件，而是隔离软件）**
直觉：安全关键嵌入式系统从不假设「软件不会错」，它假设「软件一定会错」，于是让错误**够不到输出**：(i) **空间分区**——MPU/MMU、ARINC 653 分区、能力寻址，一个分区的野指针改不了另一个分区的内存；(ii) **时间分区**——时间触发调度 + WCET 预算，一个任务的超时不许拖垮控制环；(iii) **看门狗/心跳**——任务失联就复位或降级；(iv) **锁步/N-版本 + 输出投票**——单通道偏离被法定人数否决；(v) **失效运行（fail-operational）**——降级但不停机。映射到 VISTA：第 65 轮的 FIR「定向膨胀」恰恰是一个**非特权软件直接改写全局安全球**的动作，等于让应用线程直接写控制寄存器。

**灵感 2（状态隔离 → 把归因后验从共享内存变成事务）**
直觉：VISTA 的 15 维签名与 6 假设后验是典型的**共享可变状态**，却没有锁、没有版本、没有回滚。状态隔离给出四件武器：(i) **无共享可变状态**（actor/消息传递，域间只发不可变快照）；(ii) **快照隔离/MVCC**（读者只见一致视图，写者不阻塞读者）；(iii) **追加式不可变账本 + 事件溯源**（决策可确定性回放，可回滚到任一 epoch）；(iv) **能力门控写入**（没有 capability 就不能改状态）。于是「归因错了」从「全局灾难」退化为「一个沙箱里的事务失败了」——**错误被降级为可丢弃的草稿**。

**灵感 3（嵌入式的「提交」语义 → 从命令到提案、从生效到提交）**
直觉：真实嵌入式写共享状态都要走「准备—校验—提交」，数据库则用两阶段提交 + 回滚。VISTA 缺的正是这层：它把「归因后验」直接当命令执行。本轮把归因改成 `提案 ΔS → 佐证（独立域法定人数或物理探针）→ 提交 / 回滚`。**归因不再是「我相信谁」，而是「谁愿意为这次状态变更联署」**。这正面拆掉第 65 轮的风险链条：未知复合故障很难同时骗过 q 个独立分区；骗不过 → 不提交 → 全局状态不变 → 系统没有「已经归因」的理由变自信。

**灵感 4（三灵感合流 → HERMETIC：密封式归因-执行隔离架构）**
闭环：VISTA 的全部学习组件降为**非特权**，跑在各自 FCR 内 → 证据写入**不可变账本 LEL** → FIR-X 只在本地生成**推测事务 ACX**（不改全局）→ 由**独立证据域 + N-版本输出投票 VOTER** 做 q-of-N 佐证 → 特权**安全内核 SKR** 在两阶段提交通过后原子提交 → **时间分区 TPU** 在硬实时安全槽内执行认证前缀 k*，看门狗守超时 → **CMF** 监测共因（唯一能绕过隔离的通道）→ 不一致则**回滚 RBS** 或降级/安全停机。第 65 轮是「归因 → 定向膨胀 → 执行」，HERMETIC 是「归因 → 提案 → 佐证 → 提交/回滚 → 执行」：**多了一道结构性闸门，少了一个不可撤销的全局写。**

**灵感 5（原位升级映射，不推倒 VISTA）**
- **FIR → FIR-X**：归因输出改为「事务草案」，禁止直接改全局球；状态写入本域 S_i。
- **RSC-V → RSC-I**：`r_geo/r_force/r_model/r_vis/r_policy` 各自住进 FCR，只由本域事务提交；融合半径只读。
- **WCV-V → WCV-S**：编译器只读一致快照，产物不可回写全局。
- **CSC → CSC-T**：认证前缀绑定时间槽预算与 WCET，看门狗到点强制重规划/停机。
- **AFA → AFA-Q**：探针需 capability + 佐证；易损物体仍只走视觉/零力探针。
- **CSP-V → CSP-P**：规划器降为非特权提案者，无法阻塞安全槽（时间隔离）。
- **AIC-V → AIC-I**：干扰集新增**隔离机制自身**的故障（MPU 配置错、能力泄漏、DMA 旁路、优先级反转、seqlock 撕裂、投票器单点）与共因故障。
- **GRIP/VISTA → 运行在 FCR 内**：MEL/USR/LSF 等都成为非特权服务；只有 SKR 能写执行器。
- **J_vista → J_hermetic**：证书增 partition_hash、wcet_ver、isolation_attest、commit_receipt、voter_quorum、cmf_flag、rollback_epoch、replay_hash。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（HERMETIC 架构与特权分离）**：HERMETIC = (VISTA, SKR, {FCR_i}, SPU, TPU, LEL, ACX, VOTER, HMT, CMF, RBS, J_hermetic)。SKR 为裸机/特权安全内核，是**唯一**执行器写者；VISTA 的学习组件全部非特权。不变式：**任何学习组件既不能写执行器，也不能写其他 FCR 的可变状态，只能发布不可变消息或读取一致快照。**
- **定义 234（故障遏制域 FCR 与空间分区 SPU）**：全局状态 S = ⊎_i S_i；FCR_i=(S_i, Ê_i, w_i, cap_i)。SPU 用 MPU/MMU 强制：FCR_i 只能写 S_i、只能经 `cap_{i→j}∈{read_snapshot, send_msg, propose_txn}` 访问外部。直接写他人状态被硬件拒绝并记入 LEL。**遏制性来自「单故障至多激活一个 FCR」这一可由分区表证明的性质，而不是来自对估计器的信任。**
- **定义 235（不可变证据账本 LEL 与快照隔离）**：LEL 是只追加序列 L=e_1…e_T；epoch τ 的快照是前缀 L_{≤τ}。读者拿 MVCC 一致视图；归因写入是**事件**（作者域、证据哈希、父 epoch、nonce），不是就地修改。任何历史决策可确定性回放。读视图线性一致。
- **定义 236（时间分区 TPU 与 WCET 认证槽）**：时间触发调度槽 {safety, attribution, learning}，各槽预算 B_s，最坏执行时间 w_s，要求 w_s≤B_s 且 Σ_s w_s/B_s≤1。safety 槽固定最高优先级、优先级反转有界；每槽看门狗心跳，超时即升级为 safe-stop。安全槽经 seqlock/RCU 读一致快照，**读延迟与语义流时长解耦**。
- **定义 237（推测性归因事务 ACX）**：归因输出事务 T=(H, ΔS, ev_hash, cap, epoch, nonce)，ΔS 先写入影子区而**不生效**。两阶段提交：prepare 校验能力、前置条件与 epoch 冲突；commit 需**佐证法定人数**（≥q 个独立 FCR 一致）或物理探针确认；否则 abort 并回滚影子区。**未提交事务永不触碰执行器与全局球。**
- **定义 238（N-版本证据与输出投票 VOTER）**：N 条多样估计路径（LiDAR 几何 vs 视觉几何、F/T vs 视觉力代理等）各自给出候选指令提案 u_i；VOTER 仅在 ≥q 个提案落在容差 ε_u 内时输出该簇值，否则 SAFE_STOP/HOLD。多样性矩阵 D 度量通道独立性。
- **定义 239（健康表 HMT 与信任限速）**：每域信任 w_i∈[0,1]，单步变化受限 |Δw_i|≤ρ_w，心跳失联即隔离（quarantine）。**FCR_i 的错误归因最多改变 w_i，不能连锁改写其他域信任**——信任本身的状态隔离。
- **定义 240（共因故障检测 CMF）**：共因是唯一能同时污染 ≥q 个域的通道。用残差相关性/同窗越界比例定义共因指数 c_cm；若 c_cm>θ_cm 或同时偏离的域数 ≥q，判 common-mode：**禁止提交归因、进入 minimal/safe-stop**。**共因下不要求归因正确，只要求拒绝下注。**
- **定义 241（隔离的可认证性与 breach）**：隔离是须被证明的物理/配置属性，不是假设。`isolation_attest` 校验 MPU 区域表哈希、能力完整性、seqlock/RCU 协议、实测 WCET。若跨域 Fisher 耦合 |J_ij|>θ_cross（说明域间仍共享同一 OOD 源），置 `isolation_breach` 并进一步收紧。
- **定义 242（RSC-I 域内定向球）**：每个 FCR 维护自己的 r_i；事务提交只改本域 r_i。融合半径 r=√(Σ r_i²) 只由 WCV-S 只读使用，**绝不回写**，从而没有「一次归因全局膨胀」。
- **定义 243（WCV-S / CSC-T / CSP-P / AFA-Q）**：WCV-S 从快照只读编译；CSC-T 在 safety 槽内认证前缀 k* 并受看门狗约束（k*≤m，m 为不可逆视界）；CSP-P 是非特权规划提案者，不能阻塞安全槽；AFA-Q 探针需 capability + 佐证，且保留第 65 轮易损物体的视觉-only/零力探针限制。
- **定义 244（认证快照与回滚 RBS）**：执行前落 checkpoint（epoch+状态摘要）；执行后证据若与已提交归因矛盾，回滚到最近确认 epoch，并在**新 FCR** 中重新归因。恢复时间由 checkpoint 大小与重放长度界定。**归因第一次变成可撤销操作。**
- **定义 245（失效运行状态机）**：模式 M={full, degraded_vis, degraded_force, minimal, safe_stop}；迁移需 VOTER 法定人数 + HMT 健康门控；**任何单域都不能触发模式迁移**；看门狗可单向升级到 safe_stop。
- **定义 246（遏制半径与传播算子）**：以依赖图 G 描述 FCR→输出；遏制半径 r_contain(i)=从 FCR_i 可达的安全输出集。遏制不变式：**每条从 FCR_i 到执行器的路径都必须经过 VOTER**；单域排除（single-domain exclusion）即无单域可独立驱动执行器。
- **定义 247（HERMETIC 证书 J_hermetic）**：J_hermetic = (J_vista, partition_hash, wcet_ver, isolation_attest, commit_receipt, voter_quorum, cmf_flag, rollback_epoch, replay_hash)。Valid ⇔ Valid(J_vista) ∧ 隔离已认证 ∧ 当前状态来自已提交事务 ∧ 见证人数达标 ∧ 无未处理共因 ∧ 可选回放哈希一致。
- **定义 248（HERMETIC 闭环算子）**：语义流 [LSF→USR/MEL→VPG/ACH→阶段切分→FIR-X 事务草案→AFA-Q] 运行在 attribution/learning 槽；实时流 [safety 槽：RCU 快照→VOTER→SKR 提交/派发→看门狗→CMF→早停]；LEL 贯穿两流但**只有追加**；TPU 保证两流时间隔离。

```python
else:
    LEL.record('ambiguous', T); probe_or_safe_stop()
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（遏制）**：若空间隔离保证单故障至多激活一个 FCR，且 VOTER 要求 q-of-N（q≥2）、故障域之外的 N−1≥q−1 个正确提案一致，则单域故障**确定性地**被否决，执行器偏差≤ε_u；有共因致 k≥q 域同时被污染时才可能骗过投票，其概率以 P_escape≤p_c+(1−p_c)Σ_{k=q}^N C(N,k)p_e^k(1−p_e)^{N−k} 界定。**单点故障第一次不再等价于执行器故障。**
- **引理 10（推测提交消除了过度自信）**：归因只能经 SKR.commit(T) 影响执行器；abort 使影子区丢弃，快照 epoch 不变。因此误归因的危害上界从 VISTA 的 P[误归因] 降为 P[误归因被提交]≤P[≥q 域同时错]+ε_vote+ε_skr。第 65 轮「已归因→更自信」的链条在结构上被切断：**没有提交，就没有全局状态改变，也就没有新的自信来源。**
- **定理 9（HERMETIC 端到端遏制-安全）**：在 A94–A99 下，Valid(J_hermetic) ⇒ 执行器无单点故障路径 ∧ 误归因被遏制在影子区或由回滚撤销 ∧ 共因被 CMF 检出否则拒绝提交 ∧ 安全槽 WCET 不受语义流抖动影响 ∧ 失效运行状态机不会被单域劫持。
- **定理 10（隔离—可辨识性权衡与共因地板）**：空间隔离使每域只见块对角 Fisher 信息 J_iso=blkdiag(J_ii) ⪯ J_global（Loewner 序），故 κ_fi^iso≤κ_fi^global——**隔离以损失可辨识性换取遏制性**。系统代价 C(N,q)=c_c·P_escape(N,q)+c_d·(1−κ_fi^iso/κ_ref)+c_r·N+c_cm·p_c(N)；由于共享 OS/时钟/OOD 面使 p_c(N) 随 N 非减，最优 N* 有限；且**若 p_c≥α_safety，任何 (N,q) 都无法达标——遏制论证归零**。这是本轮必须诚实标注的地板。
- **实时性**：semantic/learning 全部移入低优先级槽；安全槽只做 RCU 读 + VOTER + SKR 派发 + 看门狗（目标 ≤1.8ms，A94 修订契约）；LEL 追加为 O(1) 环形缓冲，无学习写回。

## 5. 本轮最大风险

**一句话**：HERMETIC 的遏制性完全建立在「FCR 之间真正独立」这一物理假设上，但真实嵌入式栈里各域共享同一个 OS 内核、驱动、时钟/电源轨、标定表和往往同一个学习骨干——一次共因故障（或隔离机制自身的 bug：MPU 配置错、DMA 旁路、优先级反转、seqlock 撕裂、投票器单点）会**静默绕过全部分区**，而「已通过隔离认证」反而让系统显得更安全，使引理 9 的遏制上界在 p_c 升高时变成空话。

## 2. 形式化定义（完整版 233–248）

**定义 233（HERMETIC 架构与特权分离）** HERMETIC 是 VISTA 的「故障遏制」升级：保留 VISTA 的语义流/实时流划分，但把学习组件全部宿主化到非特权 FCR 内，并新增特权安全内核 SKR 作为执行器唯一写者。架构为
HERMETIC = (VISTA, SKR, {FCR_i}_{i=1..N}, SPU, TPU, LEL, ACX, VOTER, HMT, CMF, RBS, J_hermetic)。
不变式 H1：**任何非 SKR 组件不能写执行器；任何 FCR 不能写其他 FCR 的可变状态；跨域只能发送不可变消息或读取一致快照。** 该不变式由硬件（MPU/MMU）与能力表共同强制，而非由代码规范保证。

**定义 234（故障遏制域 FCR 与空间分区 SPU）** 将 VISTA 状态划分为六个 FCR：FCR_geo（几何/位姿估计）、FCR_force（力/触觉标定）、FCR_model（接触模型/刚度）、FCR_vis（视觉感知/世界模型）、FCR_policy（块策略/规划提案）、FCR_exec（认证前缀生成，仍非特权）。全局状态 S=⊎_i S_i。FCR_i=(S_i, Ê_i, w_i, cap_i)，其中 Ê_i 为本域估计器，w_i 为本域信任，cap_i 为本域持有的能力集。SPU（Spatial Partition Unit）用 MPU/MMU 区域表强制：
- 写：`write(FCR_i, x) ⇒ x ∈ S_i`，否则触发 protection fault 并写入 LEL；
- 读：跨域仅可 `read_snapshot(FCR_j, τ)`（不可变快照）；
- 消息：仅可 `send_msg(FCR_i→FCR_j, m)`，m 不可变；
- 事务：仅可 `propose_txn(FCR_i, T)`，T 的提交权在 SKR。
**单故障至多激活一个 FCR** 由区域表与能力表的静态可检查性给出（见定义 241）。

**定义 235（不可变证据账本 LEL 与快照隔离）** LEL 是只追加序列 L=e_1…e_T，每个事件不可变且带哈希链。epoch τ 的读快照是前缀 L_{≤τ}。归因写入不是就地修改，而是追加事件：
e_t = (author_FCR, evidence_hash, parent_epoch, txn_nonce, decision)。
采用 MVCC/快照隔离：读者在 epoch τ 看到一致视图，写者（仅 SKR 提交）产生 τ+1 而永不修改 τ。事件溯源（event sourcing）保证任意历史决策可确定性回放：
Replay(L_{≤τ}) = State(τ)，且 Hash(Replay) = replay_hash(τ)。
这为事后取证、认证与 RBS 回滚提供基础。**归因历史第一次成为不可篡改、可复现的审计对象。**

**定义 236（时间分区 TPU 与 WCET 认证槽）** 采用时间触发（time-triggered）静态调度，槽集 {safety, attribution, learning}，各槽预算 B_s，最坏执行时间 w_s，要求
w_s ≤ B_s，且 Σ_s w_s/B_s ≤ 1。
safety 槽固定最高优先级；非 safety 槽不得持有 safety 槽所需资源（无共享锁、无阻塞队列），优先级反转因此有界（仅经 SKR 的短临界区，且该临界区 WCET 可静态界定）。每槽设看门狗心跳：槽启动 kick、槽预算耗尽未完成即触发 watchdog，单向升级到 safe_stop。安全槽读取一致快照：
snap = rcu_read() / seqlock_read()，
其读路径**不获取写者锁**；seqlock 重试次数有上界 K，超限退化为上一有效快照。因此安全槽延迟满足
w_safety ≤ w_compute + K·w_retry + w_vote + w_commit，
与语义流/学习流时长无关。**时间隔离把「世界模型算得慢」从安全属性问题降级为性能问题。**

**定义 237（推测性归因事务 ACX）** 归因不再直接修改全局球或半径。FIR-X 产生事务
T = (H, ΔS, ev_hash, cap, epoch, nonce)，
其中 ΔS 是**影子状态增量**（例如「r_geo ← κ·r_geo」「w_vis ← κ_vis·w_vis」），先写入影子缓冲，不生效。ACX 执行两阶段提交：
1. **prepare**：SPU 校验 cap；LEL 校验 epoch 无冲突（乐观并发控制）；SKR 校验 T 不违反安全不变式（如不得把任何 r_i 置零、不得越过 f_lim）。
2. **commit**：仅当佐证法定人数达成——至少 q 个**独立** FCR 的证据支持同一 H（或物理探针 S 型确认）——SKR 原子地写 S 与 LEL，生成 commit_receipt。
3. 否则 **abort**：丢弃 ΔS，epoch 不变，记录 `ambiguous`，进入 AFA-Q 或 safe_stop。
不变式 H2：**未提交事务永不触碰执行器、全局球或执行器可达状态；提交是唯一写点，且提交原子。**

**定义 238（N-版本证据与输出投票 VOTER）** 至少 N 条**多样**估计路径产生候选指令提案 u_i。多样性来源示例：(i) 几何：LiDAR 点云 vs 单目/深度视觉；(ii) 力：F/T 传感器 vs 视觉力代理 f̂_vis；(iii) 模型：解析接触模型 vs 学习残差模型。VOTER 取容差 ε_u，输出
u = u_k，若 ∃ 簇 C: |C|≥q 且 ∀i,j∈C, ‖u_i−u_j‖≤ε_u；否则输出 SAFE_STOP/HOLD。
定义多样性矩阵 D_{ij}=1−corr(e_i,e_j)（残差相关越低越独立）。**D 不是数字装饰：它是引理 9 中「独立域」假设的可测代理。**

**定义 239（健康表 HMT 与信任限速）** 每域维护 w_i∈[0,1] 与心跳 h_i。更新规则
w_i(t+1) = clip(w_i(t) + η·score_i(t), 0, 1)，且 |w_i(t+1)−w_i(t)| ≤ ρ_w。
心跳缺失超过 θ_hb 即 quarantine(FCR_i)：其提案权重置零、其状态只读、不参与法定人数。关键性质：**错误归因只改变它所属域的 w_i，不能连锁改写其他域**——信任是状态隔离的，不允许「一次错误归因让全局信任崩塌」。

**定义 240（共因故障检测 CMF）** 共因是唯一可绕过空间隔离的通道（共享 OS/驱动/时钟/电源/标定/学习骨干）。定义窗口 W 内的共因指数
c_cm = max( simultaneous_exceed_fraction, max_{i≠j} |corr(res_i, res_j)| )。
若 c_cm > θ_cm，或同窗内 ≥q 个域同时越界，则判 common-mode：
**禁止一切 ACX 提交，VOTER 输出 SAFE_STOP，模式迁移到 minimal/safe_stop。**
注意 CMF 的语义是「拒绝下注」而非「定位故障」：共因下不要求归因正确，只要求系统不因错误归因而继续执行。**这是第 65 轮「未知复合故障」风险的正面结构回应。**

**定义 241（隔离的可认证性与 breach）** 隔离必须被证明而非被假设。`isolation_attest` 包含：
1. `partition_hash`：MPU/MMU 区域表、能力表的哈希；
2. `wcet_ver`：各槽实测 WCET 与预算；
3. `protocol_check`：seqlock/RCU 的读写屏障、重试上界、无 DMA 旁路（IOMMU 配置）；
4. `coupling_test`：跨域残差/ Fisher 耦合 |J_ij|。
若 |J_ij|>θ_cross（说明两域仍共享同一分布外失效源），置 `isolation_breach=True`：相关域合并为一个更大的 FCR 并要求更高法定人数，或直接降级。
**隔离认证使「分区」从架构图上的方框变成可被攻击测试的物理属性。**

**定义 242（RSC-I 域内定向球）** 每个 FCR 维护自己的不确定半径 r_i（i∈{geo,force,model,vis,policy}）；事务提交只改本域 r_i。WCV-S 使用只读融合半径
r = √(Σ_i r_i²)
做搜索域编译，且**绝不回写** r_i。这与第 65 轮 RSC-V 的区别是：RSC-V 仍有一个全局可写的球集合；RSC-I 的球是分区状态，只能经 ACX 提交，因而「一次误归因 → 全局膨胀」在结构上不可能。

**定义 243（WCV-S / CSC-T / CSP-P / AFA-Q 原位隔离化）**
- **WCV-S**：从 epoch τ 的一致快照只读编译搜索域 B(φ̂,r)∩𝒢∩K∩ℱ∩𝒱；产物是不可变证书片段，不可回写全局。
- **CSC-T**：认证前缀 k* 与 safety 槽预算绑定；k*≤m（不可逆视界），且 k* 步必须在 B_safety 内完成；超预算由看门狗强制重规划/停机，**不允许「超时后继续猜」**。
- **CSP-P**：规划器是非特权提案者，只能在 attribution 槽运行、只能 propose_txn，不能阻塞 safety 槽；其长时搜索不进入执行路径。
- **AFA-Q**：探针选择沿用第 65 轮故障假设互信息目标，但执行需 capability + 佐证；易损物体仍只用 visual_probe/null_test；探针事务同样走 ACX。

**定义 244（认证快照与回滚 RBS）** 每次提交前，SKR 落 checkpoint：
cp(τ) = (epoch τ, Hash(S(τ)), commit_receipt(τ))。
执行后若新证据与已提交归因矛盾（例如执行后零力窗出现大 DC 偏置，而先前提交的是 H_geo），RBS 回滚到最近确认 epoch τ'，丢弃其后事务，并在**新建 FCR**（fresh domain，干净状态）中重新归因。恢复时间
T_recover ≤ T_load(cp) + T_replay(L_{τ'..τ})，
由 checkpoint 大小与重放长度界定。**归因成为可撤销操作，系统第一次拥有「我可能错了，撤回」的机制。**

**定义 245（失效运行状态机）** 模式集 M={full, degraded_vis, degraded_force, minimal, safe_stop}。迁移规则：
- 任一 FCR 降级 → 对应 degraded 模式（如 FCR_vis 隔离 → degraded_vis：VCV 停用、退回 F/T 主导）；
- CMF 触发或法定人数长期不足 → minimal（仅保持位姿/柔顺撤退）或 safe_stop；
- 所有迁移需 VOTER 法定人数 + HMT 健康门控；**单域不能触发迁移**；
- 看门狗可单向升级（只能更保守），不可由非特权组件复位。
**失效运行把「错误后继续跑」改造成「错误后受控降级」。**

**定义 246（遏制半径与传播算子）** 以依赖图 G=(V,E) 描述 FCR 与安全输出（执行器指令、力限、滑移判定）的依赖。遏制半径 r_contain(i)={o∈O : 存在从 FCR_i 到 o 的路径}。遏制不变式：
∀i, ∀o∈r_contain(i) 的每条路径，路径必经过 VOTER。
单域排除（single-domain exclusion）：不存在 i 使 VOTER 可在无其他域参与下输出 u。
形式化地，VOTER 的法定人数条件 q≥2 且依赖图中 FCR_i 到执行器的**最小割**≥q（按域计），则无单域能独立驱动执行器。

**定义 247（HERMETIC 证书 J_hermetic）**
J_hermetic = (J_vista, partition_hash, wcet_ver, isolation_attest, commit_receipt, voter_quorum, cmf_flag, rollback_epoch, replay_hash)。
验证规则：
Valid(J_hermetic) ⇔
  Valid(J_vista)
  ∧ isolation_attest 通过（无 breach）
  ∧ 当前可执行状态来自已提交事务（commit_receipt.epoch = 当前 epoch）
  ∧ voter_quorum ≥ q
  ∧ cmf_flag = False（或无共因下的显式 safe_stop 决策）
  ∧ replay_hash 与 LEL 回放一致
  ∧ 若 rollback_epoch 存在，则回滚后已在 fresh FCR 重新归因。
审计链新增：谁提交了这次归因（commit_receipt）、哪些独立域联署（voter_quorum）、隔离是否被证明（isolation_attest）、共因是否触发（cmf_flag）、是否撤回过（rollback_epoch）。

**定义 248（HERMETIC 闭环算子）** 语义流（attribution/learning 槽，10–100Hz）：[LSF→USR/MEL→VPG/ACH→阶段切分→FIR-X 事务草案→AFA-Q→ACX prepare]；实时流（safety 槽，≥500Hz）：[RCU 快照→VOTER q-of-N→SKR 提交/派发→CSC-T 前缀执行→看门狗→CMF→早停]。LEL 贯穿两流，但**只有 SKR 能提交写事件**；TPU 保证两流不互相阻塞；RBS 在矛盾时回滚。二者的耦合被严格限制为「不可变快照 + 已提交事务」两条窄接口。

## 3. 关键算法伪代码

### IP-224/225 SKR + SPU（唯一写点）

```python
class SafetyKernel:
    """特权、裸机、最小可信基（TCB）。只做：能力检查、原子提交、执行器写入。"""
    def __init__(self, mpu, lEL, voter, watchdog):
        self.mpu, self.ledger, self.voter, self.wd = mpu, lEL, voter, watchdog

    def commit(self, T):
        if not self.mpu.check_cap(T.cap, T.author, T.delta):
            self.ledger.record('deny', T); return False
        if self.ledger.conflict(T.epoch):
            self.ledger.record('abort_epoch', T); return False
        if not self.voter.corroborate(T, q=QUORUM):
            self.ledger.record('ambiguous', T); return False
        # 影子 → 原子生效；生成不可变回执
        self.apply_atomic(T.delta)
        self.ledger.append(('commit', T.hash, T.epoch + 1,
                            self.voter.quorum_receipt(T)))
        return True

    def write_actuator(self, u):
        if not self.wd.alive('safety'): return self.safe_stop()
        self.mpu.actuator_region.write(u)       # 仅此路径可达
```

```python
class SpatialPartitionUnit:
    def check_cap(self, cap, author, delta):
        # 写只能落在本域；跨域只能 read_snapshot/send_msg/propose_txn
        for addr in delta.writes:
            if not self.region_of(addr).owner == author:
                self.fault('protection', author, addr); return False
```

## 4. 推导

**引理 9（遏制引理）** 设 N 个 FCR、q-of-N 投票器（q≥2），并假设：
(A94) 空间隔离：一次物理故障在一个决策 epoch 内至多激活一个 FCR；
(A95) 投票器正确：仅在 ≥q 个提案落在 ε_u 内时输出簇值，否则 SAFE_STOP。
若仅 FCR_i 故障，则其余 N−1 个正确提案（N−1≥q≥2）落在同一 ε_u 簇内，构成合法法定人数；故障提案或为离群点被排除，或与正确簇偏差≤ε_u。故执行器输出要么为无故障值（偏差 0），要么偏差≤ε_u；若投票器无法形成正确簇则 SAFE_STOP。单域故障无法单独驱动执行器。
共因可同时污染 k≥q 个域。设单域错误概率 p_e、共因概率 p_c，在给定共因下各域条件独立，则错误逃逸
P_escape(N,q) ≤ p_c + (1−p_c)·Σ_{k=q}^{N} C(N,k) p_e^k (1−p_e)^{N−k}。
第一项是共因地板，第二项是独立错误同时发生的尾部。∎

**引理 10（推测提交消除过度自信）** 由定义 233/237，归因影响执行器与全局半径的唯一路径是 SKR.commit(T)。若 abort，影子 ΔS 被丢弃、epoch 不变、执行器不可达；故误归因的危害事件包含于「误归因被提交」事件。因此
P[误归因危害] ≤ P[提交错误假设]
  ≤ P[≥q 域同时支持错误假设] + ε_vote + ε_skr
  ≤ p_c + (1−p_c)Σ_{k=q}^N C(N,k)p_e^k(1−p_e)^{N−k} + ε_vote + ε_skr。
对比 VISTA：其定向膨胀直接写全局球，危害概率即 P[误归因]，而第 65 轮自述在未知复合故障下该值随故障类型增长。故 HERMETIC 把「越错越自信」的反馈回路切断：**未提交不改状态，已提交可回滚，回滚后在新域重估。** ∎

**定理 9（HERMETIC 端到端遏制-安全）** 在 A94–A99（空间隔离、投票正确、时间隔离、能力完整、CMF 有效、回滚可执行）下：
1. **无单点执行器故障**：由引理 9 与定义 246，任何单 FCR 故障被 q-of-N 否决；执行器依赖图中每域到执行器的最小割≥q。
2. **误归因被遏制**：由引理 10，误归因要么不提交（状态不变），要么被回滚（RBS），要么仅在 ≥q 域共同时才可能落地——而该情形被 CMF 显式监测。
3. **共因不赌**：CMF 触发即拒绝提交并 SAFE_STOP（定义 240），不要求归因正确。
4. **时间隔离**：安全槽 WCET 与语义流/学习流时长无关（定义 236），看门狗把超时变为安全停机而非继续猜测。
5. **可认证回放**：LEL 事件溯源使任意决策可复现，J_hermetic 的 replay_hash 与 commit_receipt 提供审计证据。
6. **失效运行**：模式迁移需法定人数 + 健康门控，单域不能劫持（定义 245）。
∎

**定理 10（隔离—可辨识性权衡与共因地板）** 设未隔离时故障幅度 θ 的 Fisher 信息为 J_global=SᵀΣ_ρ⁻¹S。空间隔离禁止跨域共享可变状态，每域只能使用自己的证据块，故有效信息为块对角
J_iso = blkdiag(J_11,…,J_NN) ⪯ J_global（Loewner 序）。
于是可辨识裕度
κ_fi^iso = λ_min(J_iso)/λ_max(J_iso) ≤ κ_fi^global。
即**隔离以损失跨域联合可辨识性为代价换取遏制性**（第 65 轮的三阶段辨识依赖跨阶段联合信息，被隔离后每域只剩本阶段，κ 下降）。
定义系统代价
C(N,q) = c_c·P_escape(N,q) + c_d·(1 − κ_fi^iso(N)/κ_ref) + c_r·N + c_cm·p_c(N)。
共享 OS/驱动/时钟/电源/学习骨干使 p_c(N) 随 N **非减**（组件越多，共享面越大）。当 N 增大：第二项尾部指数下降，但 c_r·N 与 c_cm·p_c(N) 上升，故 ∂C/∂N 至多变号一次，存在有限最优 N*。
**地板结论**：若 p_c(N) ≥ α_safety（目标失效概率），则 P_escape ≥ α_safety 对一切 (N,q) 成立，遏制上界失效。**隔离无法把安全性做到共因地板以下。** ∎

**命题（HERMETIC 相对 VISTA 的过度保守/过度自信双向改善）** VISTA 在误归因时把单一全局 r 膨胀 κ_infl 倍并使系统更自信；HERMETIC 中该膨胀只作为影子 ΔS 存在，未获法定人数即丢弃，几何/力/模型各自 r_i 不被误改。因此在「单域故障 + 独立证据」情形下：误降级率与过度自信事件同时下降；代价是决策延迟增加至「一次佐证窗口」与资源开销 N 份估计。该代价在定理 10 的成本函数中显式计费。

## 8. 已知风险

**一句话**：HERMETIC 的遏制性完全建立在「FCR 之间真正独立」这一物理假设上，但真实嵌入式栈里各域共享同一个 OS 内核、驱动、时钟/电源轨、标定表和往往同一个学习骨干——一次共因故障（或隔离机制自身的 bug：MPU 配置错、DMA 旁路、优先级反转、seqlock 撕裂、投票器单点）会**静默绕过全部分区**，而「已通过隔离认证」反而让系统显得更安全，使引理 9 的遏制上界在 p_c 升高时变成空话。

**次级风险与缓解**：
1. **共因地板（首要）**：P_escape 的 p_c 项不可由 N 消除。缓解：CMF 拒绝下注 + 引入物理独立通道（IMU、编码器、机械限位、独立电源域）+ 对共享组件做多样化实现（N-version OS/驱动），并把 p_c 作为证书中的显式上界而非隐藏假设。
2. **隔离机制自身是新的可信基**：SKR/MPU/IOMMU/VOTER 若有 bug，则「唯一写点」本身失效。缓解：SKR 保持极小 TCB（<2k LOC，形式化或高强度测试）、硬件隔离优先于软件隔离、投票器做双核锁步、对 MPU 表做启动时与运行时的双重哈希校验。
3. **时间隔离的 WCET 难题**：缓存/分支预测/中断抖动使 WCET 难精确；WCET 低估会破坏 sched 条件。缓解：测量 + 悲观上界、关闭/分区缓存、用时间触发调度与硬件定时器、留 30% 余量。
4. **快照隔离的读重试/活锁**：seqlock 读在写频繁时可能反复重试。缓解：重试上界 K + 退化为上一有效快照 + 写者频率限制（LEL 批量提交）。
5. **回滚的语义代价**：物理世界不可回滚（已发生的接触/位移不能撤销）。RBS 只能回滚**软件状态与决策**，不能回滚物理后果。缓解：把回滚与「物理不可逆视界 m」绑定，只回滚尚未越界的前缀；物理损害仍由 CSC-T 的 k*≤m 与力限保证。
6. **法定人数导致的过度保守**：q 过高 → 频繁 SAFE_STOP，任务效率下降。缓解：自适应 q（按 HMT 健康与 CMF 指数）、把「恢复」作为显式技能、用 minimal 模式而非直接停机。
7. **LEL 存储与完整性**：长期运行账本膨胀、哈希链被截断或篡改。缓解：环形缓冲 + 定期 checkpoint + Merkle 根 + 关键事件非易失存储。
8. **状态隔离与学习演化的冲突**：非特权学习组件无法跨域共享梯度/特征，可能降低样本效率。缓解：只允许共享**不可变、脱敏、带来源**的特征摘要；学习更新走离线/低优先级槽，绝不写实时状态。
9. **仿真—真机落差**：E241–E250 为单种子仿真，硬件故障、驱动 bug、时序异常在仿真中偏理想。缓解：多种子 + 故障注入真机台 + 红队攻击隔离机制。
10. **认证成本**：把隔离、WCET、回放纳入证书会显著增加验证工作量，可能拖慢迭代。缓解：把 J_hermetic 的关键字段做机器可检查的轻量断言，重认证只在分区表/TCB 变更时触发。

**结论**：第 65 轮问「谁坏了」，HERMETIC 问「坏了能不能够到输出、能不能撤回」。这不是把 VISTA 做得更聪明，而是把它放进一个嵌入式安全系统的**分区—提交—投票—看门狗**骨架里：让归因成为可丢弃的草稿、让错误成为可回滚的事务、让共因成为必须显式拒绝下注的例外。代价是资源、延迟与可辨识性（定理 10），收益是「单点故障不再等于执行器故障」。**最终安全上限仍由共因地板决定——这是本轮必须留给下一轮的问题。**
