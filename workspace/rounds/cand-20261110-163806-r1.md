# 第 44 轮（灵感循环第 1 轮，承接第 43 轮 v20） · Latency-Cert × Legged-Reflex：把「低延迟推理」与「四足机器人」升格为时延-稳定证书（四层架构 v9）

> 承接 v20（Persona-Cert × Concurrent-Cert）。v20 自陈风险是「边际覆盖被欺骗 + 多用户契约空集」，但它仍压着两个更底层的假设：**(H3) 时延只是性能指标**——证书租约把新鲜度建模为纯运动学 Lipschitz 衰减 λ=L_m·v_max，默认「证书一旦算出就能用到衰减为止」，却没把「推理到底何时算完、抖动多大」写进 soundness；**(H4) 推理输出只要正确就能用**——忽略「正确但太晚」在动态系统里等价于错误。四足机器人恰好是这两个假设的放大器：它是欠驱动、动态不稳定的控制对象，1 kHz 本体反射与 2–10 Hz VLM/个性化推理共享算力，慢推理一旦抢走反射预算，证书再正确也会摔倒。本轮灵感词**低延迟推理**迫使我们把时延（deadline/WCET/jitter）变成证书的一等维度；**四足机器人**则提供一个可独立认证的硬实时反射基底，使「慢的语义」与「快的稳定」解耦。二者耦合处是本轮真正的新问题：**时延抖动 × 步态相位**可能诱发谐振，而**量化/早退**会悄悄改变 CBF 的 Lipschitz 常数。

## 0. 直觉与动机

**灵感 1（时延是 soundness 的一部分，不是 perf 指标）**：直觉上，「这张证书在 τ 时刻成立」是关于一个集合的断言；如果世界在证书被用上之前已经跑远，断言就可能变假。v20 的租约用 λ=L_m·v_max 处理这件事，但这是「假设身体自由漂移」的悲观界；四足机器人身上其实有一条被独立认证的反射环，把身体约束在一个管（tube）里。于是可以把衰减率从「自由漂移」改成「反射约束漂移」——**反射背书租约**（reflex-backed lease），λ_eff 远小于 λ，证书可用窗口显著变长。关键洞察：**低延迟的价值不只是快，而是让 λ_eff 有意义地小、让证书更久不过期**。

**灵感 2（四足机器人自带一个「免费」的硬实时安全底座）**：本体反射（VMC/CPG/摆腿控制）跑在 MCU 1 kHz 上，可以脱离 GPU 单独认证。因此低延迟推理不应直接输出关节动作，而应只输出**受认证包络内的参数偏置/路点/步态选择**：`慢的只能拧旋钮，不能直接推身体`。这把「推理时延」从安全约束里几乎完全解放——只要包络 E 被守住，推理晚到只影响任务质量，不影响稳定性。

**灵感 3（低延迟推理的正确姿势：事件触发 + 早退阶梯 + 证书保全降级）**：不是每帧都要 VLM。用「惊讶度/风险」触发稀疏深度推理；用早退网络给出**证书阶梯**：早退得到弱但快、late-exit 得到强但慢，在 deadline 内能走到哪级就用哪级；若 deadline 失守，则退回「陈旧但仍在语义陈旧预算内」的语义，同时反射包络继续兜底。一句话：**快路径不保证强，但保证永不弱于反射底座**。

**灵感 4（耦合风险：抖动 × 步态相位，量化 × Lipschitz）**：四足步态是周期性的，推理抖动若与步态相位锁定，可能形成谐振/极限环；同时 INT8 量化与早退会改变各层输出的局部 Lipschitz 常数，使 v20 里按 FP32 标定的 CBF 证书静默失效。必须做**步态相位 × 抖动注入**的协同验证，并对每一档退出重标定 L_m。

**耦合升级**：LSC（时延-稳定证书）把 deadline/WCET/jitter 与 CBF 时延裕度绑定成一条可审计证书；RPR（反射优先运行时）用算力分区把推理降级为「可丢负载」；GLV（步态-时延验证器）在仿真里注入抖动与量化、枚举步态相位，把反例回灌 CKB 与 SCV。四层架构由 v8 的「人格 + 并发证书」升级为 v9 的「时延-稳定证书 + 反射优先运行时」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（时延-稳定证书 LSC）**：证书 c 扩展为五元组 c^Θ = (A_c, θ_safe, Θ, Δ, m_stab)，其中 A_c 为可容许动作/参数集，θ_safe 为安全阈值，Θ 为端到端最坏时延预算（WCET），Δ 为抖动上界，m_stab 为稳定性裕度。**时延裕度条件**：对测量时刻 τ 的证书，在使用时刻 t 可用，当且仅当 ∀t′∈[τ, τ+Θ+Δ]：m_stab − L_stab·(Θ+Δ) ≥ θ_safe，且 A_c 在反射管 T_ρ 内不变。**命题（时延 sound）**：若硬件/调度器保证 WCET ≤ Θ 且 jitter ≤ Δ，则在该窗口内使用 c^Θ 绝不误用失效证书。

**定义 45（反射基底与认证包络解耦）**：反射控制器 π_ref 在扰动界 W 下被认证使状态恒在管 T_ρ（不变集）。推理层只能选择参数 p∈E（认证包络），E 满足：∀p∈E、∀w∈W，π_ref(p,·) 仍使 T_ρ 不变。**解耦定理**：若推理输出被投影到 E，则系统稳定性与推理时延/抖动无关；时延只影响任务层目标，不影响安全层不变式。**推论**：低延迟推理的收益应记在「任务质量/保守性」账上，而不是「安全」账上——安全由 π_ref 独立兜底。

**定义 46（语义陈旧预算）**：设语义 s(τ) 在 t 时刻被使用。定义语义等价类 [s(τ)]_Δ = {s′ : 在陈旧窗口 Δ 内与 s(τ) 的可区分度 < ε_sem}。若对任意 s′∈[s(τ)]_Δ，任务级安全谓词仍成立，则称该语义**陈旧安全**，记 stale-usable(s, Δ)=true。**判据**：stale-usable 为真才允许 deadline 失守时沿用旧语义；否则必须触发「语义安全停机/减速」。

**定义 47（事件触发推理的最坏时延证书）**：触发函数 g(x)∈{0,1}，重推理仅在 g=1 时执行。**触发风暴界**：需认证任意滑动窗口内触发次数 ≤ N_trig，且单次重推理 WCET ≤ Θ_heavy；否则重推理不得进入安全关键路径。**引理**：若 N_trig·Θ_heavy + Θ_light ≤ Θ_budget，则事件触发不破坏端到端 deadline。

**定义 48（证书保全的早退阶梯）**：网络有 K 档退出 e_0..e_{K−1}，对应证书强度单调递增、时延单调递增：C(e_0) ⊇ C(e_1) ⊇ … ⊇ C(e_{K−1})，Θ(e_0) ≤ … ≤ Θ(e_{K−1})。**在线选择**：e* = max{e_i : Θ(e_i) ≤ remaining_deadline ∧ C(e_i) 可满足当前守卫}；若 e_0 仍不满足则走定义 46 的陈旧/停机分支。**命题**：早退只会降低证书强度、不会伪造强度，故阶梯 sound。

**定义 49（步态-时延耦合稳定性）**：定义相位相关时延敏感度 S(φ) = ∂m_stab/∂delay 在步态相位 φ 的取值。**无谐振条件**：对抖动频谱 J(f)，要求 ∀f 接近步态基频/谐波，不产生正反馈增益，即 |1 + S(φ)J(f)| > 1。**判据**：认证仅在 |S(φ)| ≤ S_max 的相位区间允许最大抖动 Δ；否则在该相位禁投重推理（延迟到支撑相）。

**定义 50（量化-证书一致性重标定）**：对每档退出 e_i 与量化方案 q，重算局部 Lipschitz 常数 L_m(e_i,q)，并要求 CBF 证书使用 L_m^cert = max_{i,q} L_m(e_i,q)·(1+δ_cal)。**定理（一致性）**：若所有在线路径的 L_m ≤ L_m^cert 且 δ_cal 覆盖标定误差，则量化/早退不破坏 v20 的 CBF soundness。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 LATENCY-STABILITY-CERTIFICATE（时延-稳定证书 LSC）
1. **证书五元组**：把 v20 的 (m,τ,λ,κ) 扩展为 (A_c,θ_safe,Θ,Δ,m_stab)，deadline 成为可审计字段。
2. **反射背书租约**：λ_eff 由「反射管约束漂移」而非「自由漂移」导出，显著延长可用窗口。
3. **时延裕度守卫**：CBF 条件在整个 [τ,τ+Θ+Δ] 上验证，而非仅在 τ 点。
4. **量化/早退重标定表**：维护 L_m(e_i,q) 表，证书只用其上界。

### 2.2 IP-61 REFLEX-PRIORITY-RUNTIME（反射优先运行时 RPR）
1. **算力硬分区**：MCU 反射核（1 kHz，独立认证）与 NPU 推理核隔离；推理核过载不得回压反射核。
2. **推理作为可丢负载**：推理任务标记 optional/droppable，deadline miss 时单调降级到早退档/陈旧语义，不回写安全路径。
3. **deadline 调度 + 准入控制**：新进重推理需通过 N_trig·Θ_heavy 准入；触发风暴直接拒绝。
4. **包络投影器**：所有推理输出先投影到认证包络 E，越界即裁剪并记录审计事件。

### 2.3 IP-62 GAIT-LATENCY-VALIDATOR（步态-时延验证器 GLV）
1. **相位 × 抖动注入**：在 Isaac Sim 按步态相位枚举注入抖动/延迟，测 m_stab 响应，拟合 S(φ)。
2. **谐振检测**：对抖动频谱与步态基频做增益分析，检出极限环/正反馈。
3. **量化回归**：INT8/早退前后跑同一轨迹，比对 L_m 漂移与 CBF 违例。
4. **反例回灌**：把「相位禁投区」与重标定表回写 LSC/CKB。

## 3. 四层架构 v9

```
L0 反射核(MCU, 1kHz, 独立认证): VMC/CPG/摆腿 → 管 T_ρ, 不依赖 GPU
L1 TRI-FUSE(INT8) + IP-49 LIO → C_ms + L_m^cert(e_i,q) + m_stab
   IP-60 LSC: 证书 (A_c,θ_safe,Θ,Δ,m_stab) + 反射背书 λ_eff
L2 CTC + VLM + 早退阶梯(e_0..e_K) + IP-35 仲裁 → 语义候选(带 ExitLevel)
   IP-61 RPR: 算力分区 / deadline 准入 / 包络投影 E / droppable 推理
L3 IP-51 CAR(时延裕度守卫 + LatencyMode/ExitLevel) ← IP-58 CCR(Θ/Δ 租约 + 并发)
   → IP-47 时延预算组合 → IP-39 CBF(按 worst-case latency 窗口) → IP-45 总线(deadline/jitter 审计)
   → IP-53 CMC(相位相关阈值 + deadline 监控)
L4 IP-60 LSC 标定表 + IP-55 CKB(步态相位/时延包络指纹)
   ← IP-62 GLV(相位×抖动注入 + 谐振检测 + 量化回归) + IP-54 SCV
   → IP-44 蒸馏 + IP-50 时延压力课程 → RCA 重颁(deadline-conditioned) → 参数热更新
运行期：反射恒跑 → 快路查表 + 短租约 → 事件触发重推理(deadline 内选退出档)
        → 包络投影 → 守卫(时延裕度) → 超时则陈旧语义/减速, 反射底座兜底
        → 抖动/谐振反例回灌 GLV → 重标定 L_m 与相位禁投区
```

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 时延-稳定 sound | 反射背书 λ_eff 下证书误用；real falls | 0；0 |
| E96 WCET/抖动可证 | 实测 p99.9 延迟 ≤ Θ；抖动 ≤ Δ；越界检出率 | 100%；100%；≥99% |
| E97 早退阶梯 | 退出档选择正确率；早退后 CBF 违例；证书强度单调违例 | ≥99%；0；0 |
| E98 事件触发准入 | 触发风暴拒绝率；端到端 deadline 违约；平均算力降幅 | 100%；0；≥40% |
| E99 反射优先隔离 | 推理过载下反射 WCET 漂移；优先级反转次数 | <2%；0 |

| E101 量化重标定 | L_m 漂移检出率；量化后 CBF 违例；标定误差 | ≥98%；0；<15% |
| E102 长时程时延压力 | 100h 摔倒/不安全；deadline miss 率；陈旧语义使用率 | 0；<1%；<10% |

回退：E96 WCET 不可证 → 关闭事件触发重推理、退回保守固定周期 + 更短租约；E97 阶梯不单调 → 只保留最低档 + 全局降速；E99 隔离失效 → 推理迁到独立 SoC/远端，本体只留反射；E100 谐振 → 全相位禁投重推理，支撑相批量更新；E101 漂移 → 回到 FP32 监控 + 收紧 L_m 上界。

## 5. 本轮最大风险

**一句话**：本方案把安全押在「WCET ≤ Θ、jitter ≤ Δ 可被硬件与调度器严格证明」上，而 GPU/NPU 在 DVFS、共享显存与并发推理下的最坏时延极难认证——一旦 WCET 被低估，时延裕度守卫会以 sound 的姿态放行一张实际已失效的证书，导致真实摔倒；因此 E96 必须设为红线，且默认回退到「反射核独立兜底 + 固定周期保守租约」这条不依赖推理时延证明的底线。

| [s]_Δ, stale-usable | 语义等价类/陈旧安全 | 陈旧窗口内仍满足任务级安全谓词 |
| e_i, C(e_i), Θ(e_i) | 早退档/证书/时延 | C 随 i 单调收缩，Θ 随 i 单调增大 |
| S(φ), J(f) | 相位时延敏感度/抖动谱 | 无谐振：|1+S(φ)J(f)|>1 |
| L_m^cert | 证书用 Lipschitz 上界 | max 跨退出档与量化的局部 L_m·(1+δ_cal) |
| N_trig, Θ_heavy, Θ_light | 触发界/重/轻推理 WCET | N_trig·Θ_heavy + Θ_light ≤ Θ_budget |

## 2. 关键算法（伪代码）

### IP-60 LSC：反射背书租约与时延裕度守卫
```
def reflex_backed_lambda(tube_rho, L_m, v_reflex_max):
    # 有反射约束时，状态只能在管 T_rho 内漂移，衰减比自由漂移小
    v_eff = min(v_reflex_max, tube_rho.escape_rate)
    return L_m * v_eff                    # lambda_eff <= L_m * v_max

def latency_stability_cert(x, theta_safe, Theta, Delta):
    b = cert_lookup_L0(x)
    lam = reflex_backed_lambda(T_rho, b.L_m_cert, v_max_bound(x))
    m_stab = stability_margin(x)
    return Cert(LSC, A_c=b.admissible, theta_safe=theta_safe,
                Theta=Theta, Delta=Delta,
                m_stab=m_stab - lam * (Theta + Delta))   # 预扣最坏窗口

def lsc_guard_ok(cert, t):
    # CBF 在整个最坏时延窗口上成立，而非仅测量点
    horizon = cert.Theta + cert.Delta
    return (cert.m_stab - cert.λ_eff * (t - cert.tau)) >= cert.theta_safe
```

### IP-61 RPR：算力分区、deadline 准入与包络投影
```
def admit_inference(req, now, window):
    if req.kind == HEAVY:
        if req.wcet > Theta_heavy: return False
        if count_triggers(window) + 1 > N_trig: return False   # 触发风暴拒绝
    return remaining_budget(req.npu_partition, now) >= req.wcet

def project_to_envelope(p, E):
    q = clip(p, E.lo, E.hi)
    if q != p: audit("envelope_clip", p, q)
    return q                               # 推理只能拧旋钮，不能越界

def reflex_priority_step(tasks):
    # 反射核独立核，不被推理核回压
    run_mcu_reflex(tasks.reflex)           # 1 kHz, 硬保证
    if not overloaded(tasks.inference):
        run_deadline_edf(tasks.inference)  # droppable, deadline 调度
    else:
        drop_lowest_criticality(tasks.inference)
```

### IP-52/56/51 升级：早退阶梯 + 时延感知守卫
```
def select_exit_level(remaining_deadline, guards, cert_ladder):
    # 证书强度随档位单调，时延随档位单调
    for i in reversed(range(K)):
        if cert_ladder[i].Theta <= remaining_deadline \
           and cert_ladder[i].satisfies(guards):
            return i
    return None

def certify_with_latency(x, guards, remaining_deadline, deadline):
    i = select_exit_level(remaining_deadline, guards, ladder)
    if i is None:
        if stale_usable(semantic_cache, semantic_staleness_budget):
            return USE_STALE                    # 旧语义 + 反射兜底
        return SAFE_STOP_OR_SLOWDOWN
    sem = early_exit_infer(x, i)
    lease = acquire_lease('lcs', x, guards.theta,
                          Theta=ladder[i].Theta, Delta=jitter_bound)
    if not lsc_guard_ok(lease, monotonic_now()):
        return downgrade_monotone(lease)        # 绝不使用过期证书
    return project_to_envelope(param_of(sem), E)

def car_transition_guard(e, x, cert, latency_mode, t):
    theta = cert.alpha_e[e] * cert.theta_sim[e]
    return (cert.m_stab - cert.lam * (t - cert.tau) >= theta
            and latency_mode.exit_level_is_safe(e))
```

### IP-62 GLV：相位 × 抖动谐振检测
```
def gait_latency_scan(sim, phases, jitters):
    S = {}
    for phi in phases:
        base = measure_margin(sim, phi, delay=0)
        for d in jitters:
            S[phi] = max(S.get(phi, 0),
                         (base - measure_margin(sim, phi, delay=d)) / d)
    return S

def resonant_phases(S, gait_freq, jitter_spectrum):
    banned = set()
    for phi, s in S.items():
        for f, amp in jitter_spectrum.items():
            if near_harmonic(f, gait_freq) and abs(1 + s * amp) <= 1.0:
                banned.add(phi)             # 该相位禁投重推理
    return banned

def recalibrate_lipschitz(paths):
    return max(local_lipschitz(traj, exit_level=e, quant=q)
               for traj in paths for e in exits for q in quants)
```

## 6. 本轮最大风险

**一句话**：本方案把安全押在「WCET ≤ Θ、jitter ≤ Δ 可被硬件与调度器严格证明」上，而 GPU/NPU 在 DVFS、共享显存与并发推理下的最坏时延极难认证——一旦 WCET 被低估，时延裕度守卫会以 sound 的姿态放行一张实际已失效的证书，导致真实摔倒；因此 E96 必须设为红线，且默认回退到「反射核独立兜底 + 固定周期保守租约」这条不依赖推理时延证明的底线。
