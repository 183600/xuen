# 第 62 轮（承接第 61 轮 ESEC/IP-173~182；灵感循环第 1 轮；本轮灵感：「伦理与合规」×「仿真训练」）

> 第 61 轮用 USR×MEL×DMS×SRT-Dual×PCE+++++ 实现了「语义统一表征、大模型零样本泛化、对话多轮接地、双流时序解耦」。但 **「安全」不等于「合规」**，留下五个根本缺口：
> 1. **物理安全只是合规的真子集**：ERTC 保证力/阻抗不越界，却不表达「未经同意不得接触」「不得将图像传出本地」「对旁观者的最小暴露」「不可逆动作需人类确认」「未成年人场景的额外限制」等**规范约束**。
> 2. **语义空间没有规范维度**：USR 的 scene/intent/impedance/evidence 四个编码器都不含道义定位（允许/禁止/义务），MEL 只回答「世界是什么」，不回答「我是否被允许这样做」。
> 3. **证书只证「做到」，不证「该做」**：J_sem_exec 证明了语义-执行一致性，却不含规范满足性、仿真覆盖证据与同意来源，无法审计「为什么允许」。
> 4. **规范长尾无法在真实世界采样**：伦理/合规事故罕见、危险、不可回滚，不能靠真实试错训练；缺仿真则永远覆盖不到「规范长尾」。
> 5. **仿真-现实存在双重鸿沟**：既有域随机化只随机物理参数，**规范/社会语境（司法辖区、同意假设、旁观者分布、数据边界）不可物理随机化且非平稳**，sim2real 的规范鸿沟被系统性忽视。

## 0. 直觉与动机

**灵感 1（伦理与合规 → 规范即控制器 NaC, Norms-as-Controllers）**
直觉：合规不应该是事后检查表，而应该是**实时控制流形的一个切面**。第 61 轮的 ERTC 已经把「安全」写成阻抗参数的可行域；伦理/合规同样可以写成「可行动作集 + 阻抗边界」的约束，只是约束的谓词从「力」扩展到「同意、旁观者、数据边界、可逆性、权限」。
关键洞见：**硬规范只做交集与投影，绝不做加权平均**。如果把「禁止接触」编码进 USR 再与「任务要接触」做 0.4/0.6 的语义加权，结果会变成「少接触」——这不是合规，而是把「禁止」软化成「打折」。因此硬规范必须是 **shield（屏蔽投影）**：先由任务/语义给出名义动作，再投影到规范可行集；投影不可行就升级给人类，而不是悄悄妥协。

**灵感 2（合规形式化 → 有界道义时序逻辑 DTL）**
直觉：法规文本要变成机器能在 kHz 环里检查的东西。完整的道义逻辑有 Chisholm 悖论等大量坑，工程上应只取**可监控片段**：道义算子 O（义务）/P（允许）/F（禁止）+ 度量时序的有界区间。
关键洞见：**有界视界 H ⇒ 有限状态进度自动机 ⇒ 每步 O(|φ|)、内存 O(H·|φ|)**，于是合规监测可以嵌进 1 kHz 实时环，而不依赖大模型。我们明确不追求「表达所有法律」，只追求「表达可被运行时证据判定的那部分」，并对不可形式化的条款显式标注为「需人类裁决」。

**灵感 3（仿真训练 → 合规压力测试 Gym CSG, Compliance Simulation Gym）**
直觉：像 fuzzing 一样去搜索「规范违规轨迹」，而不是等真实世界发生事故。CSG 生成的不是随机物理场景，而是**规范语境**：旁观者突然出现、同意被撤回、指令含糊（「轻一点……不对，是稳住」）、数据通道被请求外传、物体易碎、动作不可逆。
关键洞见：训练目标从「最大化任务回报」改为「**最大化规范覆盖**」——用覆盖引导的对抗搜索找出稀有的违规轨迹，再把它们蒸馏成运行时 monitor 与保守策略。仿真在这里不是「练技能」，而是「练红线」。

**灵感 4（仿真-现实规范鸿沟 → 规范化域随机化 NDR, Normative Domain Randomization）**
直觉：既然物理参数能域随机化，规范语境也能——随机司法辖区、用户偏好、同意默认值、旁观者密度、隐私容忍度。
关键洞见：但规范鸿沟与物理鸿沟不同，它**非平稳且对抗**（法规会变、用户会撒谎）。因此不能用「随机化越多越鲁棒」的朴素做法，而要用 **保形预测（conformal prediction）** 给出「违规风险 ≤ R̂ + L·δ_norm + 统计松弛」的可校准上界，并把 δ_norm 作为可观测的部署期健康指标。

**灵感 5（三灵感合流 → 证明携带的合规闭环 PCCL, Proof-Carrying Compliance Loop）**
直觉：每个动作都应携带一张 **J_eth 合规证书**，里面写明：适用了哪些规范、时序满足轨迹、仿真覆盖证据、同意来源、人工批准、规范不确定性。**硬规范「无证明不执行」；软规范「证明后按严重度折算」**。
关键洞见：把第 61 轮的 J_sem_exec 从「证据一致性证书」升级为「可审计的合规证明对象」，并在数字孪生里确定性回放，使「合规」从一次性判断变成**可复核、可追责、可复现**的过程。

**灵感 6（预算 → 八维 PCE++++++）**
直觉：规范检查要花算力、仿真验证要花样本、**伦理升级（停下来问人）是最贵的动作**。第 61 轮的 B_cog5（实含六项）缺「规范检查预算」和「仿真验证预算」。
关键洞见：升级问人本质是一次 **VOI 决策**——用后果严重度×违规概率去换人工时延。预算耗尽时，降级方向必须是「更保守/更常升级」，而不是「放过规范」。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（规范约束层 NCL, Normative Constraint Layer）** NCL = (AP, Φ_H, Φ_S, Compile, Shield, Weight)。其中：
- **原子命题** AP = AP_ctx ∪ AP_act ∪ AP_ev：
  - AP_ctx：旁观者存在、同意状态、数据通道允许、司法辖区、操作权限；
  - AP_act：接触发生、接触力、位移、数据传输、动作可逆性；
  - AP_ev：来自 EV-exec 的滑移/振动/力超限/覆盖范围等证据字段。
- **规范单元** φ = (id, modality, scope, ψ, [a,b], severity, hardness)：
  - modality ∈ {O, P, F}（义务/允许/禁止）；
  - ψ 为 DTL 公式（定义 174）；[a,b] ⊆ [0,H] 为相对触发事件的有界窗口；
  - severity ∈ [0,1] 为后果严重度；hardness ∈ {hard, soft}。
- **规范集合**：Φ_H 为硬规范（不可违反、不可折价），Φ_S 为软规范（可折价、可协商）。
- **编译** Compile: φ ↦ (A_φ, G_φ)，A_φ 为进度自动机，G_φ = (ActionMask_φ, KBound_φ) 为控制屏蔽。
- **屏蔽** Shield(s)：
  - A_adm(s) = A_nominal(s) ∩ ⋂_{φ∈Φ_H} {a : a ⊨ guard_φ(s)}
  - K_adm(s) = K_nominal(s) ∩ ⋂_{φ∈Φ_H} KBound_φ(s)
  - 若 A_adm = ∅：不降级、不平均，直接触发升级（定义 178）。
- **软规范权重** Weight: φ ∈ Φ_S ↦ 在 EEIS 目标中加入 w_φ·severity_φ·P̂(violation_φ)。

**定义 174（有界道义时序逻辑 DTL, Deontic Temporal Logic）** 在一个执行迹 σ = s_0 s_1 … 上定义：
- **语法**：φ ::= p | ¬φ | φ₁ ∧ φ₂ | φ₁ U_[a,b] φ₂ | O_[a,b] φ | P_[a,b] φ | F_[a,b] φ，p ∈ AP，[a,b] ⊆ [0,H]。
- **语义**（t 为当前步）：
  - (σ,t) ⊨ p ⇔ p ∈ L(s_t)
  - (σ,t) ⊨ φ₁ U_[a,b] φ₂ ⇔ ∃t'∈[t+a,t+b]: (σ,t')⊨φ₂ ∧ ∀t''∈[t,t'): (σ,t'')⊨φ₁
  - (σ,t) ⊨ O_[a,b] φ ⇔ ∀t'∈[t+a,t+b]: (σ,t')⊨φ
  - (σ,t) ⊨ P_[a,b] φ ⇔ ∃t'∈[t+a,t+b]: (σ,t')⊨φ
  - (σ,t) ⊨ F_[a,b] φ ⇔ ∀t'∈[t+a,t+b]: (σ,t')⊭φ
- **片段限制**：仅接受 H 有界、谓词可由 AP_ctx/AP_act/AP_ev 在有限延迟内判定的公式；其余条款标记 `unformalizable → human_review`，不伪装成可自动验证。
- **监测**：每个 φ 编译为进度自动机 A_φ，状态数 O(H·|φ|)，单步更新 O(|φ|)；整组 Φ 每步 O(|Φ|·max_φ|φ|)，与运行时长 t 无关（有限内存）。**这是它能进 1 kHz 实时环的根本原因。**

**定义 175（合规压力测试 Gym CSG）** CSG = (S_sim, Gen_ν, Adv, Cov, Distill)。其中：
- **规范语境** ν = (scene, agents, consent_state, data_channel, instruction_ambiguity, jurisdiction)；
- **语境生成器** Gen_ν: z ~ N(0,I) ↦ ν，且受现实性约束 D_KL(q(ν)‖q_real(ν)) ≤ ρ；
- **对抗搜索** Adv：在 K 步内求 argmax_{ν, a_0:K} severity(φ)·novelty(τ)，s.t. 现实性约束与规范可判定性约束；
- **覆盖度** C_cov = (Σ_{φ∈Φ} 1[φ 至少被触发一次且其违规类被覆盖]) / |Φ|，并配合轨迹类熵 H_trace 度量多样性；
- **蒸馏** Distill: D_cf ↦ (M_norm 运行时监视器集合, π_csg 保守策略, 回归测试集)。

**定义 176（规范化域随机化 NDR 与规范鸿沟）** 设训练规范语境分布 q_train(ν)，部署分布 p_deploy(ν)，在规范特征空间上的 1-Wasserstein 距离 δ_norm = W_1(q_train, p_deploy)。保形校准给出违规风险上界：
```
R_norm ≤ R̂_norm(q_train) + L_norm · δ_norm + Q_{1-α}(n)
```
其中 L_norm 为风险对语境扰动的 Lipschitz 常数，Q 为有限样本分位数松弛。δ_norm 作为部署期可观测健康指标，超阈值则扩大升级频率。

**定义 177（伦理-合规证书 J_eth）** J_eth = (J_sem_exec, Φ_applicable, τ_sat, cov_evidence, consent_provenance, human_approval, U_norm, h_proof)。其中：
- Φ_applicable 为本次动作触发的规范子集；τ_sat 为各 φ 的时序满足轨迹；
- cov_evidence 为 D_cf 上该规范类的覆盖证据摘要；consent_provenance 为同意来源（用户/默认/法规豁免）；
- human_approval 为升级后的人工批准凭证（无则 null）；U_norm 为规范不确定性；
- h_proof 为证书内容哈希链的末节点。
- **验证规则**：
```
Valid(J_eth) ⇔ Valid(J_sem_exec)
            ∧ (∀φ∈Φ_H: τ_sat ⊨ φ)
            ∧ (C_cov(Φ_H) ≥ θ_cov)
            ∧ ProvenanceValid(consent_provenance)
            ∧ (severity_max > θ_esc ⇒ human_approval ≠ null)
            ∧ U_norm ≤ θ_norm
```

**定义 178（伦理升级控制器 ESC, Ethical Escalation Controller）** ESC = (S_esc, A_esc, C_esc, π_esc)。其中：
- 状态 S_esc = (severity_max, reversibility, P̂(violation), U_norm, budget_left, PCE_health)；
- 动作 A_esc = {continue, slow_down, ask_human, abort}；
- 成本 C_esc(a) = λ_miss·P(violation | a, ν)·severity_max + λ_esc·cost(a) + λ_lat·latency(a)；
- 策略 π_esc：安全优先的阈值规则 + 在规则可行子空间内的期望成本最小化：
```
if ∃φ∈Φ_H: P̂(violation_φ) > τ_hard:        a = ask_human / abort
elif severity_max·P̂(violation) > τ_soft:   a = ask_human
elif U_norm > θ_norm:                       a = slow_down
else:                                       a = continue
```
- **预算耗尽语义**：B_norm 或 B_sim 耗尽 ⇒ 默认动作向更保守侧漂移（continue→slow_down→ask_human），**永不放宽硬规范**。

**定义 179（规范增强语义空间 NUSR, Norm-augmented USR）** NUSR = (U, E_norm, Π_norm, Shield)。其中：
- 规范编码器 E_norm: Φ_applicable × Context → ℝ^{d_norm}，映射到与 USR 物理子空间**分离**的道义子空间；
- Π_norm 仅用于「规范相似度/冲突检测/可解释检索」，**不参与阻抗目标的加权**；
- 最终执行参数由屏蔽投影给出：
```
K_nominal ← Π_usr(scene_emb + intent_emb)
K_safe    ← Proj_{K_adm(s)}(K_nominal)
if ‖K_nominal − K_safe‖ > ε_shield: 触发 ESC 升级
```
- 关键性质：**硬规范是投影/交集算子，不是加权算子**，因此不会被语义融合软化成「部分遵守」。

**定义 180（仿真覆盖-合规保证 SCCG, Simulation-Coverage Compliance Guarantee）** 在以下假设下：
- (i) DTL 监视器对硬规范片段是 sound 的（无漏报）；
- (ii) CSG 覆盖度 C_cov 是保守估计（低估真实覆盖）；
- (iii) 部署语境与训练语境规范鸿沟 ≤ δ_norm；
- (iv) 样本来自可交换的语境类；
则部署期硬规范违规概率满足
```
P_deploy(violation) ≤ (1 − C_cov) + L_norm·δ_norm + sqrt(ln(2/δ)/(2n))
```
该式是**设计目标与验收指标**，不是无条件定理；CSG 覆盖不足时它诚实地给出大上界，而不是给虚假保证。

**定义 181（后果严重度与可逆性指标 CSI）** CSI(s,a) = E_{ν~p}[ max_{t∈[0,K]} harm_t(s,a,ν) ]，由数字孪生 K 步 rollout 估计；可逆性 r(s,a) ∈ [0,1] 由孪生回滚测试估计。CSI 与 r 共同驱动 ESC：不可逆且高严重度动作必须有更高的人类批准门槛。

**定义 182（合规回放审计 CRA, Compliance Replay Audit）** 设数字孪生在给定 (seed, 动作迹, 证据迹) 下确定性。哈希链 h_t = H(h_{t-1}, s_t, a_t, cert_t)，其中 cert_t 为 J_sem_exec/J_eth 摘要。审计方只凭 h_T 与重放设备即可重建「当时为何允许」，并用重放结果与 τ_sat 交叉核验。**可回放性是合规证明的可信前提**。

**定义 183（八维预算 PCE++++++）** 在第 61 轮 B_cog5（实含 B_scene, B_intent, B_ros, B_exec, B_mel, B_usr 六项）基础上新增：
```
B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_norm, B_sim)
B_norm = (Monitor_freq, Formula_count, Escalation_latency, U_norm_thresh)
B_sim  = (Scenario_samples, DigitalTwin_fidelity, Coverage_target, Conformal_alpha)
```
- **成本**：cost_cog8 = cost_cog5 + λ_norm·(Monitor_load/B_norm) + λ_sim·(Samples/B_sim_samples)。
- **降级**：
  - B_norm 耗尽 ⇒ 关闭软规范监测，保留硬规范 + ESC（硬规范永不降级）；
  - B_sim 耗尽 ⇒ 冻结 CSG 新样本、复用缓存覆盖证据，并**提高**升级阈值。
- **VOI**：voi_eth(a) = 任务收益 − λ_miss·P(violation)·severity − λ_esc·escalation_cost − cost_norm − cost_sim。

**定义 184（伦理-合规-仿真闭环 ECSL, Ethical-Compliance Simulation Loop）** ECSL 是如下复合算子：
```
CSG → (M_norm, π_csg, D_cf)
    → NCL.Compile(Φ_H, Φ_S) → (A_φ, G_φ)
    → NUSR.Shield ∘ SRT-Dual.Realtime
    → J_eth（在线证书）
    → CRA（孪生回放审计）
    → 反馈 CSG（新违规轨迹 → 新语境 → 新 monitor）
```
其不动点条件：`C_cov ≥ θ_cov ∧ 硬规范违规 = 0 ∧ 证书验证通过率 ≥ θ_cert ∧ 审计可重建率 = 100%`。

## 2. 关键算法伪代码

### IP-183 NCL（规范约束层）

```python
class NormativeConstraintLayer:
    def __init__(self, dtl_horizon=H):
        self.Phi_H, self.Phi_S = [], []
        self.horizon = dtl_horizon
        self.monitors = {}      # phi.id -> DTLMonitor
        self.unformalizable = []  # 显式记录不可形式化条款

    def compile(self, norms):
        for phi in norms:
            try:
                auto = DTLProgressAutomaton(phi.psi, phi.window, self.horizon)
                self.monitors[phi.id] = DTLMonitor(auto)
                (self.Phi_H if phi.hardness == 'hard' else self.Phi_S).append(phi)
            except NotMonitorable:
                # 不伪装可验证：转人工裁决清单
                self.unformalizable.append(phi)
        return self

    def shield(self, state, A_nominal, K_nominal):
        A_adm, K_adm = set(A_nominal), dict(K_nominal)
        for phi in self.Phi_H:
            g = self.monitors[phi.id].guard(state)   # ActionMask + KBound
            A_adm &= g.action_mask
            K_adm = intersect_bounds(K_adm, g.k_bound)
        if not A_adm:
            return None, None, Escalation('hard_norm_infeasible')
        return A_adm, K_adm, None

    def soft_penalty(self, state, action):
        return sum(phi.severity * self.monitors[phi.id].violation_risk(state, action)
                   for phi in self.Phi_S)
```

### IP-184 DTL Monitor（有界道义时序监测器）

```python
class DTLMonitor:
    def __init__(self, auto):
        self.auto = auto          # 进度自动机，状态数 O(H*|phi|)
        self.q = auto.initial

    def step(self, state, action, evidence):
        # 每步 O(|phi|)，与运行时长无关（有界视界 => 有限内存）
        self.q = self.auto.delta(self.q, evaluate_AP(state, action, evidence))
        return {
            'satisfied':   self.auto.accept_sat(self.q),
            'violated':    self.auto.accept_viol(self.q),
            'risk':        self.auto.residual_risk(self.q),
        }

    def guard(self, state):
        # 把"下一步会必然违规"的动作从可选集中剔除
        return self.auto.pre_guard(state)
```

### IP-185 CSG（合规压力测试 Gym）

```python
class ComplianceSimulationGym:
    def __init__(self, sim, norms, realism_rho=0.1, steps=K):
        self.sim, self.norms = sim, norms
        self.rho, self.steps = realism_rho, steps
        self.covered = set()
        self.D_cf = []

    def adversarial_search(self, rounds):
        for _ in range(rounds):
            z = torch.randn(latent_dim)
            nu = self.gen_context(z)                      # 场景/旁观者/同意/数据边界
            if kl_divergence(nu, self.real_context) > self.rho:
                continue                                  # 现实性约束
            trace, sev = self.sim.rollout(nu, self.steps, adversary=True)
            phi_hit = [p for p in self.norms if violates(p, trace)]
            novelty = self.trace_class_entropy_novelty(trace)
            if phi_hit and novelty > 0:
                self.D_cf.append((nu, trace, phi_hit, sev))
                self.covered.update(p.id for p in phi_hit)
        return self.D_cf

    def coverage(self):
        return len(self.covered) / len(self.norms)

    def distill(self):
        # 违规轨迹 -> 运行时 monitor + 保守策略 + 回归测试
        return (train_monitors(self.D_cf),
                train_conservative_policy(self.D_cf),
                build_regression_suite(self.D_cf))
```

```python
class EthicalEscalationController:
    def __init__(self, lam_miss=10, lam_esc=1, lam_lat=0.5,
                 tau_hard=0.02, tau_soft=0.2, theta_norm=0.3):
        self.lam_miss, self.lam_esc, self.lam_lat = lam_miss, lam_esc, lam_lat
        self.tau_hard, self.tau_soft, self.theta_norm = tau_hard, tau_soft, theta_norm

    def decide(self, sev_max, p_viol, U_norm, budget):
        if p_viol['hard'] > self.tau_hard:
            return 'ask_human' if sev_max < 0.8 else 'abort'
        if sev_max * p_viol['any'] > self.tau_soft:
            return 'ask_human'
        if U_norm > self.theta_norm and budget.norm_left < 0.2:
            return 'slow_down'
        if budget.degraded:
            return 'slow_down' if sev_max > 0.3 else 'continue'
        return 'continue'

    def expected_cost(self, sev_max, p_viol):
        costs = {}
        for a in ['continue', 'slow_down', 'ask_human', 'abort']:
            miss = self.lam_miss * risk_given(a, p_viol) * sev_max
            costs[a] = miss + self.lam_esc * action_cost(a) + self.lam_lat * latency(a)
        return min(costs, key=costs.get)
```

### IP-183 NCL（规范约束层）

```python
class NormativeConstraintLayer:
    def __init__(self, horizon=H):
        self.Phi_H, self.Phi_S = [], []
        self.horizon = horizon
        self.monitors = {}
        self.unformalizable = []          # 显式：不可自动验证

    def compile(self, norms):
        for phi in norms:
            try:
                auto = DTLProgressAutomaton(phi.psi, phi.window, self.horizon)
                self.monitors[phi.id] = DTLMonitor(auto)
                (self.Phi_H if phi.hardness == 'hard' else self.Phi_S).append(phi)
            except NotMonitorable:
                self.unformalizable.append(phi)   # 转人工裁决，不伪装
        return self

    def shield(self, state, A_nominal, K_nominal):
        A_adm, K_adm = set(A_nominal), dict(K_nominal)
        for phi in self.Phi_H:
            g = self.monitors[phi.id].guard(state)
            A_adm &= g.action_mask                 # 交集，非加权
            K_adm = intersect_bounds(K_adm, g.k_bound)
        if not A_adm:
            return None, None, Escalation('hard_norm_infeasible')
        return A_adm, K_adm, None

    def soft_penalty(self, state, action):
        # 软规范才允许折价进入 EEIS 目标
        return sum(phi.severity * self.monitors[phi.id].violation_risk(state, action)
                   for phi in self.Phi_S)
```

### IP-184 DTL Monitor（有界道义时序监测器）

```python
class DTLProgressAutomaton:
    """把有界 DTL 公式编译为进度自动机；状态数 O(H*|phi|)。"""
    def __init__(self, psi, window, horizon):
        self.q0 = build_initial_states(psi, window, horizon)
        self.acc_sat = compute_accepting_sat(psi)
        self.acc_viol = compute_accepting_viol(psi)

    def delta(self, q, ap_valuation):
        return transition(q, ap_valuation)

    def accept_sat(self, q):  return q in self.acc_sat
    def accept_viol(self, q): return q in self.acc_viol
    def residual_risk(self, q): return residual(q)
    def pre_guard(self, state):
        # 剔除"下一步必然导致硬规范违规"的动作
        return ActionGuard.from_states(state, self.acc_viol)


class DTLMonitor:
    def __init__(self, auto):
        self.auto, self.q = auto, auto.q0

    def step(self, state, action, evidence):
        self.q = self.auto.delta(self.q, eval_AP(state, action, evidence))
        return {'satisfied': self.auto.accept_sat(self.q),
                'violated':  self.auto.accept_viol(self.q),
                'risk':      self.auto.residual_risk(self.q)}

    def guard(self, state):
        return self.auto.pre_guard(state)
```

```python
class ComplianceSimulationGym:
    def __init__(self, sim, norms, realism_rho=0.1, steps=K):
        self.sim, self.norms = sim, norms
        self.rho, self.steps = realism_rho, steps
        self.covered, self.D_cf = set(), []

    def gen_context(self, z):

    def adversarial_search(self, rounds):
        for _ in range(rounds):
            nu = self.gen_context(torch.randn(LATENT_DIM))
            if kl_divergence(nu, self.sim.real_context) > self.rho:
                continue                              # 现实性约束

            hit = [p for p in self.norms if violates(p, trace)]
            if hit and novelty(trace) > 0:
                self.D_cf.append((nu, trace, hit, sev))
                self.covered.update(p.id for p in hit)
        return self.D_cf

    def coverage(self):
        # 保守估计：未覆盖就是未覆盖，不插值、不外推
        return len(self.covered) / len(self.norms)

    def distill(self):
        return (train_runtime_monitors(self.D_cf),
                train_conservative_policy(self.D_cf),
                build_regression_suite(self.D_cf))
```

```python
class NormativeDomainRandomizer:
    def __init__(self, feature_map, alpha=0.1, lip=1.0):
        self.f, self.alpha, self.L = feature_map, alpha, lip
        self.calib_scores = []

    def fit(self, q_train_contexts):
        # 规范语境特征上的经验分布 + 保形校准分数
        self.feat_train = [self.f(nu) for nu in q_train_contexts]

    def delta_norm(self, p_deploy_contexts):
        return wasserstein_1(self.feat_train, [self.f(nu) for nu in p_deploy_contexts])

    def risk_upper_bound(self, r_hat, delta_norm, n):
        q = conformal_quantile(self.calib_scores, self.alpha)
        return min(1.0, r_hat + self.L * delta_norm + q / math.sqrt(n))
```

### IP-188 ESC（伦理升级控制器）

```python
class EthicalEscalationController:
    def __init__(self, lam_miss=10, lam_esc=1, lam_lat=0.5,
                 tau_hard=0.02, tau_soft=0.2, theta_norm=0.3):
        self.lam_miss, self.lam_esc, self.lam_lat = lam_miss, lam_esc, lam_lat
        self.tau_hard, self.tau_soft, self.theta_norm = tau_hard, tau_soft, theta_norm
        self.last_approval = None

    def decide(self, sev_max, p_viol, U_norm, budget):
        if p_viol['hard'] > self.tau_hard:
            return 'ask_human' if sev_max < 0.8 else 'abort'
        if sev_max * p_viol['any'] > self.tau_soft:
            return 'ask_human'
        if U_norm > self.theta_norm:
            return 'slow_down'
        if budget.degraded:                        # 预算耗尽 -> 更保守
            return 'slow_down' if sev_max > 0.3 else 'continue'
        return 'continue'

    def expected_cost(self, sev_max, p_viol, budget):
        best, best_c = 'abort', float('inf')
        for a in ['continue', 'slow_down', 'ask_human', 'abort']:
            c = (self.lam_miss * risk_given(a, p_viol) * sev_max
                 + self.lam_esc * action_cost(a)
                 + self.lam_lat * latency(a, budget))
            if c < best_c:
                best, best_c = a, c
        return best
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| NCL | 编译 O(Σ|φ|·H)；屏蔽 O(|Φ_H|·b) | O(Σ H·|φ|) | 硬规范交集/投影；不可行即升级 |
| DTL Monitor | 每步 O(|Φ|·max|φ|) | O(H·Σ|φ|) | 片段内 sound（无漏报） |
| CSG | 每轮 O(K·rollout) | O(|D_cf|) | 覆盖率保守；不可形式化条款隔离 |
| NDR | 离线 O(n·d) | O(n) | 保形覆盖 1-α（类内可交换） |
| J_eth | O(|Φ|·H) 构建/验证 | O(H·|Φ|) | 硬规范未满足即拒绝执行 |
| ESC | O(1) 决策 | O(1) | 预算耗尽向保守漂移 |
| NUSR | O(d_us + d_norm) | O(d_us + d_norm) | 屏蔽投影，硬规范不被平均 |
| CRA | O(1) 追加；O(T) 回放 | O(T) | 确定性回放 + 哈希链 |

**正确性定理（ECSL-Sound）**：假设 A71–A77：
**(A71)** DTL 监视器对硬规范片段 sound，不可判定谓词被隔离；
**(A72)** Shield 在 dispatch 前原子施加且不可被优化覆盖；
**(A73)** C_cov 为保守估计；
**(A74)** NDR 保形校准在语境类内可交换、δ_norm 有界；
**(A75)** ESC 在 B_norm 内决策，耗尽时向保守单调漂移；
**(A76)** 数字孪生确定性、哈希链无断裂；
**(A77)** 八维预算单调，硬规范屏蔽与 ESC 永不降级。

则：
1. **硬规范不可违反**：以 `Valid(J_eth)` 为执行前置 ⇒ 任一 dispatch 步不违反 Φ_H（A71+A72）。
2. **实时性**：监测+屏蔽开销有界且有限内存，不依赖大模型时序；语义流超时只触发保守升级。
3. **合规泛化**：在 A73+A74 下违规概率满足 SCCG 上界；覆盖不足时上界诚实变大。
4. **升级有效性**：ESC 在规则可行子空间最小化期望成本；不可逆高严重度动作的人类批准门槛单调更高。
5. **可审计性**：所有 dispatch 动作都有可验证 J_eth 与可重放哈希链（A76）。
6. **预算安全性**：任一预算耗尽只导致更保守或更多升级，绝不削弱硬规范（A77）。
