# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「遥操作」×「多模态交互」）

> R69 教会系统「问」：把不确定性拆成 (U_ale, U_epi)，用流匹配策略显式表示多模态，用 MINT 按 VoI 选择看/问/触，并自陈其最大风险——若模态权重不可信，系统会自信地追问一个幻影。
>
> 但 R69 有一个默认到几乎看不见的前提：**答话的人就在旁边，信道是即时的，答案是为当前决策服务的。** 一旦把系统放进遥操作，这个前提整个塌掉：操作员在远端，命令与回答要走一条**会延迟、会掉线、带宽有限、还可能上行下行不对称**的信道；回答到达时，决策窗口可能已经关闭；机器人不仅要「问」，还要让操作员「看得懂」，否则人无法在关键时刻接管。更微妙的是：**在延迟窗口里，权威本身是一个不确定量**——操作员以为自己在控制，机器人以为人在控制，两边都没在控制的「权限空档」正是最危险的一瞬。
>
> 本轮两个灵感咬合成一句新问题：
> - **遥操作**把「问答」变成一场**有时限、有损耗、双向的通信**：不是「该问谁」，而是「**问题与答案来得及吗、谁在信道两端、此刻究竟谁真的握着操纵权**」。
> - **多模态交互**不只是机器人向外「探询」，而是**人与机通过视觉/力觉/触觉/语言/注视共同维持一个共享心智模型**；多模态的价值不在于信息多，而在于**迟到的模态还能被正确降权**、**高风险意图能被及时确认**。
>
> 核心命题：**把「权限」从 0/1 开关改造成一份带到期时间与围栏令牌的租约（authority lease），把「交互」从一次性查询改造成受截止时间约束的双向投资（ask/tell），把「多模态」从同步融合改造成按信息年龄（AoI）加权的异步融合；只有在租约有效、证据在截止前到达、双向信任都校准时，才允许 FLUID 的 resolution bonus 生效，否则单调退化为认证过的安全保持。** 命名 **DUET-RAS**（Delay-aware, Uncertainty-aware Epistemic Teleoperation with bidirectional multimodal interaction）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我的问题来得及送到、答案来得及回来、而在这段时间里究竟谁在开车**」——遥操作不是「人在回路」，而是**两个人共用一条会延迟、会分区、会撒谎的信道，而物理世界不会因为分区而暂停**。

## 0. 直觉与动机

**灵感 1（遥操作 → 答案是会过期的期权）**
直觉：R69 的 VoI(g)=H(M|o)−E[H(M|o,y)] 隐含「答案在决策前必到」。真实遥操作有上行时延 τ_u、下行 τ_d、人的反应时延 τ_h，合起来一个往返。一个答案像一份**期权**：它有交割时间，过了决策截止就一文不值，甚至为负（占用信道、制造虚假的「已解决」）。所以正确的量是 **TVoI(g)=E[ΔH·1{到达≤截止}]−c−λ_τ·E[延迟]**。这条改动看似小，却直接改写 R69 的结论：**歧义大不代表该问；歧义大且「问得起、来得及」才该问。** 很多 R69 会去追问的场景，在延迟下最优策略是「不问，先按可分离性保守执行」。

**灵感 2（遥操作 → 人的意图是隐轨迹，不是标签）**
直觉：R69 的「模态」是机器人自身动作的多峰。遥操作还多一层：**操作员想要什么**本身是隐变量（目标、阻抗、速度偏好、风险容忍度），只能从延迟的多模态信号里估计；而且机器人一动，人的意图就变——这是**协同适应**。把它当「查表」会得出荒谬结论。正确对象是意图轨迹的后验 b(ι)，其观测似然随信号年龄衰减。由此不确定性必须三分：U_ale（人的固有抖动/反应噪声）、U_epi（现在就能问清的歧义）、U_stale（**只能靠等/预测/契约处理**的陈旧性）。

**灵感 3（多模态交互 → 迟到的模态必须被「年龄」降权）**
直觉：视觉 30Hz、力觉 1kHz、语言 0.5Hz 且常延迟一秒、注视是稀疏事件。把它们等权融合，等于让一条 1 秒前的视觉去「投票」当前力觉——**用旧地图指挥新战场**。信息年龄（age of information）给出正确姿态：每条模态的似然按 e^{−λA_m} 衰减，等价于带过程噪声的卡尔曼更新。于是「多模态」的关键指标不是通道数，而是**每路信号的新鲜度预算**；带宽有限时，调度问题变成「刷新哪一路最值」。

**灵感 4（双向 → 提问与解释抢同一份带宽）**
直觉：R69 的 g_ask 只向上问。但遥操作里，操作员也需要机器人**说**：此刻我不确定、我准备往哪走、我为什么停。这是**下行解释**。上行提问与下行解释共用一条带宽预算，二者都是信息投资：一个降低机器人对 ι 的熵，一个降低人对机器人状态的熵。把预算全用来问，人会在关键时刻「看不懂而不敢接管」；全用来解释，机器人会在歧义中盲走。BASE 就是这二者的最优分配。

**灵感 5（权限是租约，不是开关 → 分布式系统的直接类比）**
直觉：分布式系统里，节点不能假设对方还活着；它发一张**租约（lease）**：TTL 内你有权，过期不续就自动失效；命令带**单调围栏令牌（fencing token）**，旧 epoch 的命令一律拒绝，从而杜绝「脑裂（split-brain）」与「陈旧写入」。遥操作惊人地同构：信道会分区（掉线）、消息会陈旧（延迟）、可能被重放（攻击）。于是**操作员的控制权应当是一份租约**：TTL 由信道年龄与意图不确定性决定，命令带 epoch，机器人只执行 epoch 不旧于当前者。这样，延迟与重放攻击被**同一个机制**挡住。而物理世界比分布式系统更狠：分布式系统分区时可以「停止服务」，物理世界**不能暂停**——所以租约到期不能只是「拒绝」，必须有一个**认证过的安全保持（safe-hold）**控制器填补空档。这就是 no-gap 不变式的来源。

**灵感 6（信任是双向的 → 相互过度信任是新的失效模式）**
直觉：R69 只担心机器人被人类骗。遥操作还担心两件事同时发生：人过度信任自动化（automation bias，看到「系统正常」就不看路），机器人过度信任人（把人疲劳/分心时的输入当权威）。**双向过度信任 = 双方都以为对方在兜底 = 实际无人兜底。** 这与权限空档是同一枚硬币的两面。MTG 因此要双向校准：机器人把自己的不确定性**校准地显示**给人（避免虚假安心），同时用反应时、输入熵、跨模态一致性估计人的可靠度（避免盲信）。

**灵感 7（协同适应会振荡 → 稳定性要单独证明）**
直觉：机器人适应人、人适应机器人，两个自适应回路耦合，可能产生**权限抖动**（authority chattering：来回交接）或**追逐振荡**。这不是调参问题，而是小增益（small-gain）问题：耦合增益乘积 < 1 才收敛。R70 必须显式给出稳定性条件，否则「越交互越糟」——每一次交互都在放大对方的适应。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（DUET-RAS 总览）** DUET-RAS = (TEL, AMF, U3D, TAV, BASE, ALM, HCS, SHG, MTG, CAA, RAS-WM‡)。四不变式：
(i) 实时流零学习写操作（继承 R69 定义 293-i）；
(ii) **权限无空档且无双主**：任意时刻至多一个权威控制器，且权威覆盖 α_rob + α_hum_eff ≥ 1 − ε_gap，其中 α_hum_eff 按命令年龄衰减（定义 317–319）；
(iii) **截止时间纪律**：信息动作若期望到达晚于决策截止，则不得计入当前 U_epi 的消解，只能记到未来窗口（定义 315）；
(iv) **双向预算**：上行提问与下行解释共享同一通信预算，单侧不得独占（定义 316）。

**定义 311（遥操作认知信道 TEL）** 信道状态 χ_t = (τ_u, τ_d, τ_h, B_u, B_d, p_u, p_d, {A_m})，其中上下行可不对称、p 为丢包率、A_m = t − t_gen(m) 为模态 m 的信息年龄。有效速率 B_eff = B(1−p)。信道健康度 h(χ) ∈ [0,1] 为上述量的单调函数。

**定义 312（意图隐变量与协同适应）** 潜在意图轨迹 ι_t（目标、期望阻抗、速度/风险偏好），动力学 ι_{t+1}=f_H(ι_t, a_t, u_t, ε_t)，u_t 为人的原始输入，a_t 为机器人动作——人的策略本身随 a_t 改变（协同适应）。信念 b_t(ι)，观测似然 p(y^{(m)}_t | ι, χ_t)。

**定义 313（年龄加权多模态融合 AMF）** 融合似然 p(y|ι) ∝ Π_m p(y^{(m)}|ι)^{w_m}，w_m ∝ r_m e^{−λA_m}（r_m 为模态可靠度）。等价于把年龄当作过程噪声的卡尔曼更新；给出「陈旧模态信息上界」I(ι; y^{(m)})·e^{−λA_m}。

**定义 314（三分不确定性 U3D）** U_ale = E_b[Var(ι|ι,ε)]（人的固有噪声）；U_epi = H(b(ι)|y_{≤t}) 中可在截止前被交互消解的部分；U_stale = H(b(ι)) − H(b(ι)|y 若全新鲜) 的年龄诱导部分。关键：**U_stale 只能靠预测/等待/契约处理，不能被「现在问」消解**；R69 的 U_epi 在 τ→0 时等于 U_epi + U_stale。

**定义 315（时间感知 VoI，TAV）** TVoI(g) = E_y[ ΔH(M;y) · 1{arrival(g) ≤ d_k} ] − c(g) − λ_τ E[delay(g)]，arrival 分布由 χ 给出。选择 g* = argmax TVoI s.t. risk(g) ≤ ε_int、预算未超；若最大 TVoI ≤ 0 则不交互、退 FLUID/R68。R69 的 VoI 是「arrival 几乎必然 ≤ d_k」的乐观上界。

**定义 316（双向 ask/tell 预算 BASE）** 预算 C_tot 分为 C_ask（上行提问/探询）与 C_tell（下行解释/预览/不确定性显示）。目标 max_{C_ask+C_tell≤C_tot} [TVoI_ask + TVoI_tell]，其中 TVoI_tell = 降低「人对机器人状态/意图的熵」的期望收益。二者边际收益递减（次模）。

**定义 317（权限租约 AL）** 租约 L = (owner, epoch, t_issued, TTL, scope)，owner ∈ {human, robot, shared}，scope 限定可执行动作子集。TTL = clip(κ·h(χ)·(1−Û_epi)/ρ̂_hum, TTL_min, TTL_max)，ρ̂_hum 为人的可靠度估计。物理动作 a_t = α_t π_rob + (1−α_t) u_{t−τ}；α_hum_eff = (1−α_t)·e^{−A_u/τ_c}。

**定义 318（围栏令牌）** 每条命令携带单调 epoch e；机器人仅执行 e ≥ e_current 的命令，否则拒绝并记审计。epoch 由 ALM 在每次合法交接时自增。⇒ 延迟导致的陈旧命令与重放攻击被同一机制拒绝。

**定义 319（交接契约 HCS）** 交接在窗口 [t_s, t_e] 内以单调 α(t) 完成；契约规定：(a) 确认证据必须在窗口内到达，否则中止并回到更保守一侧；(b) 至多一个权威（no split-brain）；(c) 空档由 SHG 填补（no-gap）；(d) 交接期间不得改变安全包络。

**定义 320（安全保持 SHG / 延迟下的安全契约 SCC）** 对延迟观测一致意图集 ℐ_ε = {ι : b(ι) ≥ 1−ε}，要求 a_t ∈ Safe(ℐ_ε, χ)（对所有合理意图保持风险 ≤ ε_risk），否则进入认证安全保持态。这是 R68 包络在「信念索引」下的扩张。

**定义 321（双向信任校准门 MTG）** 下行：机器人以**校准后的**不确定性显示（而非原始高置信）向人呈现状态，抑制自动化偏差；上行：ρ̂_hum 由反应时、输入熵、跨模态一致性、历史纠错率估计。门控：ρ̂_hum < ρ_min 或机器人自校准 ECE > τ_ece ⇒ 降低人的租约权限、禁用 ask 消歧 ⇒ 退 FLUID/R68。

**定义 322（权限空档与相互过度信任）** gap_t = max(0, 1 − [α_t + (1−α_t)e^{−A_u/τ_c}])。相互过度信任判据：双方都报高置信（rob_confidence↑、hum_input_stability↑）但跨模态/跨模型分歧↑ ⇒ 触发主动「说明+复核」，而非继续静默。

**定义 323（协同适应稳定性 CAA）** 设机器人对人策略的适应增益 g_r、人对机器人策略的适应增益 g_h；耦合回路稳定当且仅当 g_r·g_h < 1（小增益条件）；否则权限抖动/追逐振荡，需抑制自适应速率。

**定义 324（通信攻击集 ℰ_comm）** 命令伪造、重放、延迟注入、带宽饥饿、模态丢弃、下行显示欺骗（fake certainty）、利用解释通道的社交工程。并入 AIC：ℰ_DUET = ℰ_FLUID × ℰ_comm。

**定义 325（时序与权限审计 VQAuditor-T）** 审计：答案是否在截止前到达并被使用、是否有过期证据被采纳、交接是否出现 gap/split-brain、epoch 是否单调、显示是否校准、交互是否均摊到操作员疲劳期。结论回灌 AuditBuf 作为 TAV/BASE 先验。

**定义 326（证书 J_DUET）** J_DUET = (J_FLUID, latency_p95, age_p95, gap_max, split_brain_count(应为 0), tvoi_ratio, trust_ece, handover_hash, comm_ver)。Valid ⇔ Valid(J_FLUID) ∧ gap_max ≤ ε_gap ∧ split_brain_count = 0 ∧ trust_ece ≤ τ ∧ 截止纪律满足。

**定义 327（自适应通信模式）** 模式 ∈ {local_autonomy, shared_authority, direct_teleop, safe_hold}，由 (h(χ), U_epi, ρ̂_hum, gap_t) 驱动切换，带滞回（hysteresis）避免抖振。

**定义 328（新鲜度预算下的风险分配）** 风险预算 ε_risk 按模态年龄分配：安全关键模态（力觉/碰撞）AoI 不得超过 A_max；带宽不足时优先刷新其边际风险削减最大的通道（调度器）。

```python
class AuthorityLeaseManager:
    def step(self, chi, U_epi, rho_hum):

def handover_and_hold(lease, b, chi, alpha_prev):

    U_ale, U_epi, U_stale = M.u3d.decompose3(b, chi, M.horizon)
    # 1) 截止时间约束的交互；下行解释与上行提问共享预算
    g_ask  = M.tav.choose_interaction_temporal(M.modes, b, chi, M.budget, M.deadline)
    g_tell = M.base.best_explanation(b, chi)
    C_ask, C_tell = M.base.allocate_budget(g_ask, g_tell, M.budget.total)
    # 2) 权限租约：TTL 随年龄/不确定性/信任缩短
    lease, epoch = M.alm.step(chi, U_epi, M.mtg.rho_hum)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g_ask else 0) + U_stale))
    # 3) 交接 + 无空档安全保持
    alpha = M.hcs.handover_and_hold(lease, b, chi, M.alpha_prev)
    if isinstance(alpha, SafeHold):                          # 认证安全保持
        k, lam = alpha.k, max(lam, 0.8)
    else:
        k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    # 4) 信任门越界则严格退化
    if M.mtg.mutual_trust_gate(M.mtg.rho_hum, M.ece, M.disagreement) != 'ok':
        return FLUID_RAS_round(M, obs)                        # R69 边界
    mode = select_mode(M.modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(g_ask, g_tell, alpha, epoch, chi)
    return k, lam, mode, alpha, (U_ale, U_epi, U_stale)
```

## 3. 推导

**引理 19（租约的新鲜度—权限上界）** 设命令年龄 A、意图不确定性 Û_epi、可靠度 ρ，则可安全授予人的权限 α*_hum ≤ e^{−A/τ_c}·ρ·(1−Û_epi)。系：存在阈值 TTL，A>TTL 时 α*_hum=0；R69 的权限模型是 A=0、ρ=1 的边界。**推论：延迟不是「慢一点」，而是「权限必须指数级收缩」。**

**引理 20（年龄加权融合的等价最优性）** 对独立高斯流与年龄指数过程噪声，AMF 的 e^{−λA} 权重恰等于带过程噪声 Q=λ² 的卡尔曼更新；陈旧模态的信息贡献上界为 I(ι;y)e^{−λA}。系：等权融合会把后验方差低估至少 (1−e^{−λA}) 倍，即**系统性过度自信**——R69 的 ECE 门在延迟场景会自动误判。

**引理 21（TVoI 对 VoI 的支配与包含）** 恒有 TVoI ≤ VoI；当 P(arrival≤d_k)=0 时 TVoI<0。故 R69 的 VoI 是乐观上界，**「该问」的集合在延迟下严格收缩**。系：τ→0 时 TVoI→VoI，R69 逐指令恢复。

**引理 22（租约的 no-split-brain / no-gap 不变式）** 若 epoch 严格单调、且 TTL ≤ 最小往返时延 + 时钟漂移上界的安全裕度，则任意时刻至多一个权威（no split-brain）；若同时 SHG 在 gap>ε 时接管认证安全保持，则权限覆盖 ≥ 1−ε_gap（no-gap），且有界切换次数（由 TTL_min 与滞回给出）。要点：**物理世界不能像分布式系统那样「停服」，所以租约到期必须伴随一个安全动作，而不是空转。**

**引理 23（协同适应的小增益稳定性）** 耦合自适应回路在 g_r·g_h < 1 时收敛；≥1 时出现权限抖动或追逐振荡。系：交互越频繁，g 越大，越需抑制自适应速率——**不是所有「更懂人」的适应都安全**。

**定理 18（DUET 严格包含 FLUID / R68）** 当 τ→0、B→∞、ρ=1、无对抗且意图可观测时，DUET 逐指令退化为 FLUID；当信道分区/信任越界/ECE 超阈时，DUET 的安全保持是 R68 保守包络的子集。故 **期望风险 ≤ R69 ≤ R68**（A95–A99）。安全侧不因新增通信层而让步。

**定理 19（交接连续性与最坏风险）** 在引理 22 与定义 319–320 下，交接期间控制连续、无 split-brain、无 gap>ε_gap；最坏风险 ≤ ε_int + P(ι∉ℐ_ε) + risk(safe_hold)，三项均可独立认证。系：**跨模态「看得懂」不是体验问题，而是风险上界中的 P(ι∉ℐ_ε) 项**。

**定理 20（双向预算的次模最优）** TVoI_ask + TVoI_tell 关于预算分配单调次模，故贪心给出 (1−1/e) 近似；在硬截止下退化为带延迟奖励的背包，用「收益/位数/到达概率」优先级索引近似最优。系：**问与说不是二选一，而是同一份信道的两个投资标的**。

```python
                        TTL_MIN, TTL_MAX)
        if self.lease.expired() or rho_hum < RHO_MIN:
            self.epoch += 1                               # 合法交接才自增
            self.lease = self.renew(self.pick_owner(chi, U_epi, rho_hum))
        return self.lease, self.epoch
    def accept(self, cmd_epoch):
        return cmd_epoch >= self.epoch                    # 陈旧/重放一律拒绝

# IP-270 HCS + IP-271 SHG：无缝交接与安全保持
def handover_and_hold(lease, b, chi, alpha_prev):
    if lease.owner == 'human':
        alpha = min(1.0, alpha_prev + HANDOVER_RATE)      # 单调
        if not confirm_evidence_arrived(b, chi):
            return 'abort_to_conservative'
    else:
        alpha = max(0.0, alpha_prev - HANDOVER_RATE)
    if 1 - (alpha + (1-alpha)*exp(-chi.age_u/TAU_C)) > EPS_GAP:
        return safe_hold(b, chi)                          # 物理世界不暂停
    return alpha

# IP-272 MTG：双向信任校准门
def mutual_trust_gate(rho_hum, self_ece, disagreement):
    if (rho_hum > RHO_HI and disagreement > DIS_TAU) \
       or rho_hum < RHO_MIN or self_ece > TAU_ECE:
        return 'disable_ask_and_shrink_authority'         # 退 FLUID/R68
    return 'ok'

# IP-275 主闭环（继承 FLUID_RAS_round）
def DUET_RAS_round(M, obs, human_input, cmd_epoch):
    z, b, chi = M.tel.update(obs, human_input, cmd_epoch)
    if not M.alm.accept(cmd_epoch):                       # 0) 围栏拒陈旧/重放
        M.vqa_t.log_stale(cmd_epoch); human_input = None
    U_ale, U_epi, U_stale = M.u3d.decompose3(b, chi, M.horizon)
    g_ask  = M.tav.choose_interaction_temporal(M.modes, b, chi, M.budget, M.deadline)
    g_tell = M.base.best_explanation(b, chi)
    M.base.allocate_budget(g_ask, g_tell, M.budget.total) # 1) 双向预算
    lease, epoch = M.alm.step(chi, U_epi, M.mtg.rho_hum)  # 2) 租约 TTL
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (U_epi if g_ask else 0) + U_stale))
    alpha = M.hcs.handover_and_hold(lease, b, chi, M.alpha_prev)  # 3) 交接
    if isinstance(alpha, SafeHold):
        k, lam = alpha.k, max(lam, 0.8)
    else:
        k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if M.mtg.mutual_trust_gate(M.mtg.rho_hum, M.ece, M.disagreement) != 'ok':
        return FLUID_RAS_round(M, obs)                    # 4) 严格退化
    mode = select_mode(M.modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(g_ask, g_tell, alpha, epoch, chi)
    return k, lam, mode, alpha, (U_ale, U_epi, U_stale)
```

## 4. 推导

**引理 19（租约的新鲜度—权限上界）** `α*_hum ≤ e^{−A/τ_c}·ρ·(1−Û_epi)`。系：存在 TTL，`A>TTL` 时人的安全权限为 0；R69 的权限模型是 `A=0, ρ=1` 的边界。延迟不是「慢一点」，而是**权限的指数级收缩**。

**引理 20（年龄加权融合的等价最优性）** 对独立高斯流与年龄指数过程噪声，`e^{−λA}` 权重恰等于带 `Q=λ²` 过程噪声的卡尔曼更新；陈旧模态信息贡献 `≤ I(ι;y)e^{−λA}`。系：等权融合会系统性低估后验方差——**R69 的 ECE 门在延迟场景会自动误判**。

**引理 21（TVoI 支配 VoI）** 恒有 `TVoI ≤ VoI`；当 `P(arrival≤d_k)=0` 时 `TVoI<0`。故「该问」的集合在延迟下严格收缩；`τ→0` 时 R69 逐指令恢复。

**引理 22（no-split-brain / no-gap 不变式）** epoch 严格单调且 TTL 含往返时延+时钟漂移安全裕度 ⇒ 至多一个权威；SHG 在 `gap>ε` 时接管认证安全保持 ⇒ 覆盖 `≥1−ε_gap`，切换次数有界。要点：**分布式系统可以停服，物理世界不能。**

**引理 23（协同适应小增益）** 耦合自适应回路在 `g_r·g_h<1` 时收敛，否则权限抖动/追逐振荡。交互越频繁，增益越大，越需抑制适应速率。

**定理 18（DUET 严格包含 FLUID/R68）** `τ→0、B→∞、ρ=1、无对抗、意图可观测` 时逐指令退化为 FLUID；信道分区/信任越界/ECE 超阈时安全保持是 R68 保守包络的子集。故期望风险 `≤ R69 ≤ R68`（A95–A99），安全侧不因新增通信层让步。

**定理 19（交接连续性与最坏风险）** 引理 22 与定义 319–320 下，交接控制连续、无 split-brain、无 `gap>ε_gap`；最坏风险 `≤ ε_int + P(ι∉ℐ_ε) + risk(safe_hold)`，三项均可独立认证。系：跨模态「看得懂」直接进入风险上界。

**定理 20（双向预算次模最优）** `TVoI_ask+TVoI_tell` 对预算分配单调次模 ⇒ 贪心 `(1−1/e)` 近似；硬截止下为带延迟奖励的背包，用「收益/位数/到达概率」优先级索引近似最优。

## 7. 本轮最大风险

**一句话**：DUET-RAS 把分布式系统的「租约 + 围栏」搬到物理世界，赌的是**时钟/epoch/信道健康度在延迟、分区、甚至被伪造时仍然可信**；可分布式系统在分区时可以「停止服务」，物理世界却**不能暂停**——一旦 epoch 同步被延迟或攻击骗过，机器人要么拒绝一条其实合法的人工命令（僵局/no-brain），要么执行一条其实陈旧或被重放的命令（脑裂/split-brain），而这两者都不是「信念错了」，而是**物理上真的撞上去了**。**问错比不问更危险，R70 把它升级为：交错权比不交权更危险。**

**次级风险与缓解**：① 时钟漂移/epoch 伪造 → 围栏 + 单调 epoch + 认证消息 + E308；② 安全保持在高速场景不可行（不能急停）→ 预认证的「最小风险动作集」+ 定理 19 的风险分解；③ 人的模型不可辨识 → 三分不确定性 + MTG 门控，宁可退 FLUID；④ 双向预算被单侧饿死 → BASE 次模分配 + 硬下限 `C_tell ≥ C_min`；⑤ 协同适应振荡 → CAA 小增益监测 + 自适应速率限幅；⑥ 显示欺骗导致虚假安心 → 校准化显示 + VQAuditor-T 审计。
