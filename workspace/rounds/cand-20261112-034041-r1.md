# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 1 轮；本轮灵感：「关节驱动」×「常识推理」）

> 第 57 轮把安全的赌注从"某个点踩下去会不会塌"换成了"证据够不够硬"——摊销先验、跨模态对账、单向有界信任，使单点过度自信不再足以产生承诺。但第 57 轮自陈的最大风险恰好暴露了两个更底层、此前一直被默认掉的假设：**(a)** 它用"从历史语料摊销的元先验"去补手工先验的不足，却覆盖不了语料里从未出现过的表面与危险——OOD 门只能识别"我见过的分布外"，识别不了"我根本没想到要当假设的世界"；而且 `EV-xmodal` 的"跨模态一致"可能被一个**共享的物理共同因**伪造（同一块冰让视觉、触探都指向"干而硬"）。**(b)** 它证明的是"探针/接触应当安全"，却从未证明"身体能按命令执行探针"——关节有扭矩/速度/热限、间隙、柔顺、编码器偏置与突发故障，任何一处失效都会让被证书盖章的接触变成一条从未被覆盖的运动。**(c)** 它还默认机器人知道该把哪些东西当作可能的世界——而真实长尾危险（要倒的堆叠、可能装着重物的箱子、会回弹的门、湿滑地面、被踩住的线缆）往往既不在地图类别里，也不在元语料里，需要常识才能"想到"。本轮把"证据承诺"从**世界/证据层**下沉到**身体层**，并给常识一个严格受限的角色：**常识只提案、本体可对账、执行有包络、自模型可证伪、物理有硬底**。核心矛盾是：**安全证书的每一层都假设了某个模型正确，而"身体"正是最后一个从未被当作可疑对象建模的模型，且它可能正是伪造跨模态一致的共同因**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"常识只提案、本体可对账、执行有包络、硬件有硬底的具身级证据承诺"**。

核心矛盾：
- **H32（执行缺口）**：第 57 轮认证的是"探针/接触应当安全"，真实接触由带限、带故障、带柔顺的关节执行；"执行=计划"一旦被打破，被认证的安全就与真实安全脱钩。身体是最后一个未建模的世界。
- **H33（常识的广而不可靠）**：第 57 轮的元先验只覆盖语料内的世界；常识能提出语料外的长尾危险，但它是可废止的、分布外易自信错误的先验；一旦允许常识"放行"，就重新制造了"越自信→越激进"的方向性错误。常识只能加假设、加保守，不能减。
- **H34（世界-身体归因困境）**：本体感受（扭矩/电流/编码器）能证伪常识与语义，也是识破"跨模态共同因"的独立通道；但一个残差既可能是"世界出乎意料"，也可能是"身体坏了"；归因错了，要么把故障解释成世界而继续跑，要么把世界误判成故障而永久冻结。

## 0. 直觉与动机

**灵感 1（关节驱动 → 从"计划安全"到"执行安全"，从"世界锚"到"身体锚"）**
直觉：前面所有轮次都在讨论"该不该探、该不该承诺"，本轮第一次讨论"命令下去身体能不能照做、做出来还是不是那条路"。关节驱动给的第一课是：**控制器的输出不是身体的实际运动**——命令是扭矩，运动是负载、摩擦、柔顺、间隙、时延与故障共同作用的产物。于是安全判据必须从 `R(π)` 换成 `max_{x∈𝕏_exec(π)} P_coll(x)`，其中 `𝕏_exec` 是"在健康关节集合下真实可能走出的轨迹"的过近似。更狠的一课是：**任何计算出来的包络都还是模型**。真正外生的锚不是几何模型，而是硬件物理——硬扭矩/电流限幅、抱闸、看门狗、被动柔顺。软件（含自模型和常识）可以在物理硬底之上更保守，永远不能越过它。

**灵感 2（常识推理 → 只提案、不放行的可废止先验）**
直觉：常识是"廉价而宽广的世界先验"：箱子可能很重、堆叠可能失稳、门可能回弹、湿地可能打滑、线缆可能被踩住。它的价值不在精度，而在**覆盖长尾**——它能把元语料与地图类别都没有的危险"提出来"，正好补第 57 轮元先验的语料盲区。但常识也正是最容易被分布外与对抗击穿的东西（自信地胡说）。所以给它的权限必须比元先验还低：元先验至少能在声明校准内进证据门，常识**连证据类都不是**。常识只能做三件事：向可信世界集**添加**假设、**增加**保守量、**发起**一次观测；它永远不能缩小假设集、不能减小裕度、不能授权动作。它的结论一律**可废止**，并携带一个可被物理证伪的预测。

**灵感 3（二者合流 → 本体感受是常识的物理对账通道，也是共同因的照妖镜）**
直觉：常识说"这个箱子应该很轻"，本体感受说"推它需要很大扭矩"——这个矛盾是金子。关节驱动给了我们一个**不经过语义、也不经过地图**的物理证据通道：期望扭矩/电流/速度签名 vs 实测签名。它比任何外部传感器更"贴身"，因为它测的是接触本身；它还能直接检验第 57 轮最怕的"跨模态共同因"——若视觉与触探都说"干而硬"，但踝/腕关节的扭矩签名说"在打滑"，则一致性是假的。但它有一个致命混淆：残差大，可能是世界（箱子重），也可能是身体（关节卡滞/摩擦变大/编码器偏）。所以对账必须带**归因**：跨关节一致性、负载相关性、主动自检运动，用来把"世界出乎意料"与"身体故障"分开。归因不了时，默认走最保守的那条：停。

**灵感 4（三灵感合流 → 证据门从五类到具身类，跨模态一致必须排除身体共同因）**
直觉：第 57 轮的 `EV-probe*/visit/margin/xmodal/human` 在本轮各加一道身体检查：任何接触证据必须挂在**执行可达集**上，且爬行以上运动必须有 `EV-act`（关节健康/跟踪在界内）；`EV-xmodal` 的独立性还须排除"身体作为共同因"（自模型报故障时，跨模态一致一律作废）；新增 `EV-prop`（本体对账，仅用于假设更新，永不单独作碰撞/接触证书）；`EV-common` 明确**不存在**。不可逆/高能接触的必要证据集升级为 `{EV-probe*_exec ∨ (anchor_ok ∧ EV-act ∧ 显式同意)}`。击穿安全需要：元先验盲 ∧ 语义/常识乐观 ∧ 自模型错 ∧ 硬件硬底失效 ∧ 常识误报被当证据 ∧ 归因错——纵深从五层到七层。

**灵感 5（探询预算 → 常识假设也要花预算、也要被排序）**
直觉：常识可以无限生成假设，若不设预算，安全机制会变成"冻结机"（一个可被利用的 availability 攻击面）。于是每个检查点给常识一个预算 `b_cs` 与一个排序：按"合理性 × 期望信息增益"选最多 `b_cs` 个活跃假设；其余假设不阻塞，只记录。这样常识既能提案，又不会把系统拖死。探询顺序变成：常识提案 → 本体/感知证伪（花 `b_cs`）→ 仍不确定则加保守 → 承诺或退锚/停。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（关节自模型 JSM）** 关节状态 `h=(h_1..h_n)`，`h_i=(τ_i^max, v_i^max, ε_i^backlash, c_i^compliance, θ_i^thermal, enc_i^health)`；名义健康域 `H_nom`。在线自模型 `ĥ_t` 与残差 `r_t=||x_t^meas−x_t^cmd||_Q + λ||τ_t^meas−τ_t^pred||`。跟踪包络 `ε_track(t)=c_0+c_v·v(t)+c_a·a(t)+c_l·load(t)+c_c·c_compliance`，仅在 `H_nom` 上有效。故障退出：`r_t>ε_track ∨` 热/电流/编码器异常 `⇒ h∉H_nom`。**自模型不变量**：`H_nom` 的声明必须可被在线残差与主动自检证伪，不得仅凭出厂参数长期信任。

**定义 140（执行包络与被动硬底 ESE/PSE）** 执行可达集 `𝕏_exec(π)={x:∃h∈H_nom, d(x(t),π(t))≤ε_track(t)}`（过近似）；故障退出时扩为制动包络或安全停。**执行证书**要求 `max_{x∈𝕏_exec(π)} P_coll(x)≤δ_coll`。**被动安全硬底 `𝒫`**：硬扭矩/电流限幅、抱闸、看门狗、被动柔顺构成的物理约束，任何软件（含 `ĥ`、常识、语义）都不得使其失效；证书只在 `x∈𝕏_exec∩𝒫` 上有意义。**`𝒫` 是唯一不依赖任何模型的锚**——`μ_floor` 是世界的模型，`H_nom` 是身体的模型，只有硬件限幅是被物理实现的。

**定义 141（常识假设生成器 CGH）** 可废止先验 `κ` 产出假设 `h_c=(命题, 预测签名 ŝ, 合理性 pl, 证伪器 f)`。允许操作仅两类：`Expand(𝕎_t)`（只增不减）与 `Conserve`（增 `Δ_sem`/请求观测）。禁止操作：`Shrink(𝕎_t)`、`Reduce(margin)`、`Authorize(action)`。每个 `h_c` 携带证伪器；物理证据可**非单调**地撤回它。预算 `b_cs`/检查点，活跃假设按 `pl·E[IG]` 排序。**常识无证据权**：`EV-common` 不是证据类。

**定义 142（本体感受对账与归因 PXR）** 对假设 `h_c` 的预测签名 `ŝ`（期望 `τ/i/v/F` 轮廓），实测 `s_t=(τ_t^meas,i_t^meas,v_t^meas,F_t^meas)`，残差 `z_t=D(s_t,ŝ)`（如 Mahalanobis）。归因 `attr(z_t)∈{world, body, unknown}`：跨关节一致性、负载相关性、主动自检（低风险往复运动）用于分离。`world ⇒` 更新 `β`/撤回或确认 `h_c`；`body ⇒` 降档/停并记录 `h∉H_nom`，同时**作废一切基于该时段的 `EV-xmodal` 一致**；`unknown ⇒` 取最保守分支。**`EV-prop` 只用于假设更新，永不单独充当碰撞/接触证书**。

**定义 143（具身-常识证据门 ECEG 与证书 J_e）** 证据类：`EV-probe*_exec`（元校准 + 执行包络）/`EV-visit`/`EV-margin`/`EV-xmodal`（须排除身体共同因，仅 L1）/`EV-human`（auth≥A1 且佐证达标）/`EV-act`（`h∈H_nom ∧ r_t≤ε_track ∧` 热/电流裕度达标，爬行以上运动必需）/`EV-prop`（仅假设更新）/`EV-common`（**不存在**）。不可逆/高能接触必要证据集 `={EV-probe*_exec ∨ (anchor_ok ∧ EV-act ∧ 显式同意)}`，不得由 `EV-xmodal`/`EV-common` 顶替。证书 `J_e=(H_nom, ε_track, 𝕏_exec, 𝒫 自检, actuation_log, commonsense_log, prop_residual, attr_log, meta_cal_log, xmodal_log, auth_log, ood_registry, consent)`，继承 `J_p` 全检。

**定义 144（具身探-诺-演 SPCX）** 每个重规划点：①元推断；②常识 `Expand` + 预测签名；③对活跃假设做本体/感知证伪（预算 `b_cs`），或加保守；④在 `𝕏_exec∩𝒫` 上算风险并要求 `EV-act`；⑤证据门过则承诺；否则改道 → 锚爬行 → L2 协商/安全停。终止于 `{承诺, 改道, 锚爬行, 协商, 安全停}`，每点预算 `b_cs+b_sem+b_probe+k_cons`。

## 2. 关键算法伪代码（完整版见产物区）

```python
def executed_risk(pi, H_nom, P, eps_track):          # IP-139/140
    X = executed_reachable_set(pi, H_nom, eps_track)  # 过近似真实执行轨迹
    X = X & passive_floor(P)                          # 硬件硬底，软件不可越
    return max(collision_prob(x) for x in X)          # 对执行可达集取最坏

def commonsense_expand(W, kappa, budget):             # IP-141: 只增不减
    H = kappa.propose(W)                              # (命题, ŝ, pl, 证伪器)
    H = sorted(H, key=lambda h: h.pl * exp_info_gain(h))[:budget.b_cs]
    W2 = W | {h.world for h in H}                     # 仅 Expand
    return W2, H                                      # 永不 Shrink/Authorize

def proprio_reconcile(h_c, s_t, robot):               # IP-142
    z = dist(s_t, h_c.predicted_signature)
    a = attribute(z, cross_joint=robot.cross_joint_consistency(),
                  load_dep=robot.load_correlation(),
                  self_test=robot.active_self_test())
    if a == 'world':  return ('update_world', retract_or_confirm(h_c))
    if a == 'body':   robot.derate_or_stop(); return ('body_fault', z)
    return ('unknown', 'stop')                        # 归因不了 → 最保守
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| JSM | O(n_joint) 更新 | O(n_joint) | `H_nom` 可被残差/自检证伪；故障检出 ≤τ_fd |
| ESE/PSE | O(\|𝕏_exec\|·N_cell) / 重规划 | O(\|𝕏_exec\|) | 过近似真实执行集；`𝒫` 不被软件削弱 |
| CGH | O(\|H_c\|·C_propose) | O(\|H_c\|) | 只增假设/加保守；无证据权；预算有界 |
| PXR | O(n_joint·d_s + C_attr) | O(n_joint) | 归因 world/body 可分离；EV-prop 不作证书 |
| ECEG/J_e | O(\|π\|·\|𝕏_exec\|) | O(\|π\|) | EV-common 不存在；不可逆须 EV-probe*_exec |
| SPCX | O(\|CP\|·(b_cs+b_sem+k_cons+\|𝕏_exec\|)·C_plan) | O(\|𝕎\|+\|𝕏_exec\|) | 每点预算终止、五态完备 |

**正确性定理（Embodied Commonsense Soundness, ECS 概要）**：在 A37–A40 上加 **(A41)** 自模型覆盖：`H_nom` 上执行轨迹落在 `ε_track` 内概率 ≥`1−α_exec`，故障检出时延 ≤`τ_fd`；**(A42)** 常识无权限：CGH 只增假设/加保守/发观测，永不缩集/减裕度/授权，假设可审计且预算有界；**(A43)** 归因：`world/body` 误分 ≤`α_attr`，`EV-prop` 仅更新假设，`body` 归因作废同时段 `EV-xmodal`；**(A44)** 执行包络过近似且硬底 `𝒫` 不可被软件削弱。则：(i) **执行地板**：`H_nom` 上 `𝕏_exec` 内碰撞 ≤`δ_coll`，故障退出后 `τ_fd`+制动内安全停（≤`δ_exec`）；(ii) **常识单向性**：常识只经"假设更多/更保守/多观测"影响系统，无升险通道，`EV-common` 永不授权；(iii) **归因有界**：故障不能被世界假设"解释掉"超过 `α_attr`，跨模态一致不能被身体共同因"洗白"；(iv) **部署界**：

```
P_safe ≥ 1 − Σ_cp [ δ_coll·1(执行) + α_exec + δ_exec·1(故障) + ε_meta(k) + α_map + α_attr ]
             − P(𝒫 硬底失效) − P(锚假设被违反) − P(共享图相关失准)
P_live ≥ 1 − P(常识预算耗尽且无法退锚) − P(归因 unknown 持续导致永久停)
```

关键：**自模型给效率、硬底给保底**（包络把执行误差算进去，但最终兜底是不依赖模型的 `𝒫`）；**常识只加假设**（把长尾危险"提出来"，但永不"放行"）；**本体对账把常识锚在物理上**（可废止先验必须能被扭矩/电流证伪）；三者把"身体正确性"从安全前提降级为可证伪的在线假设。

| 执行包络过保守 → 吞吐塌陷 | 中 | 在线收紧包络 + 只在风险区爬行，不全程爬行 |
| 硬件硬底维护缺失/被绕过（抱闸磨损/看门狗被关） | 中 | `𝒫` 周期自检 + 防篡改日志 + fail-safe 设计 |

## 6. 本轮最大风险

**一句话**：本轮把安全锚从"世界的模型/元先验"又向内推了一层到"身体的自模型"，但自模型恰恰由它所认证的同一套硬件维护——一个会撒谎的关节（编码器偏置/卡滞仍报正常）可以让 `H_nom` 静默地包含一个正在退化的关节，使 `𝕏_exec` 低估真实可达集，而常识与本体对账要么无证据权、要么被同一个故障混淆，救不了这个洞；因此最终的锚必须是被物理实现、周期自检、fail-safe 的 `𝒫`（硬限幅/抱闸/看门狗），而不是任何计算出来的包络——一旦 `𝒫` 本身不可信，"执行有包络"就只是把"世界不可知"换成了"身体不可知"。

def joint_self_model(robot, cmd, meas):
    h = {i: {'tau_max': spec(i).tau_max, 'v_max': spec(i).v_max,
             'backlash': estimate_backlash(i), 'compliance': est_compliance(i),
             'thermal': thermal_margin(i), 'enc': encoder_consistency(i)}
         for i in joints(robot)}
    r = norm(meas.x - cmd.x, Q) + LAM * norm(meas.tau - predict_tau(cmd), Q2)
    eps = (C0 + C_V*meas.v + C_A*meas.a
           + C_L*meas.load + C_C*h.compliance)

               and h.enc and not backlash_exceeded(h))

### IP-140 ESE/PSE（执行可达集 + 被动硬底）

def executed_reachable_set(pi, H_nom, eps_track):
    # 过近似：健康域内所有可能执行轨迹的包络
    return inflate_path(pi, eps_track) | {backlash_cone(pi, H_nom)}

def execution_certificate(pi, H_nom, eps_track, P, Wc, delta_coll):
    X = executed_reachable_set(pi, H_nom, eps_track)
    X = X & passive_floor(P)                     # 软硬件不可越过 𝒫
    risk = max(collision_prob(x, w) for x in X for w in Wc)
    if risk > delta_coll:
        return ('reject', 'executed_risk', risk)
    if not P.verified():                         # 硬底自检失败 → 不许动
        return ('reject', 'passive_floor_unverified', None)
    return ('ok', risk)

def passive_floor(P):
    # 物理实现的约束：硬限幅/抱闸/看门狗/被动柔顺
    return P.hard_torque_limit & P.hard_current_limit \
         & P.brake_envelope & P.watchdog_alive & P.passive_compliance

### IP-141 CGH（常识假设生成器，只增不减）

def commonsense_expand(W, beta, kappa, budget):
    H = kappa.propose(W, beta)                   # 长尾危险提案
    H = [h for h in H if h.falsifier is not None]  # 必须可证伪
    H = sorted(H, key=lambda h: h.pl * exp_info_gain(h, W))[:budget.b_cs]
    W2 = union_worlds(W, [h.world for h in H])    # 仅 Expand
    return W2, H                                  # 禁止 Shrink/Reduce/Authorize

def commonsense_conserve(h_c, margin_state):
    margin_state.d_sem += K_CS * h_c.pl          # 只加保守
    return margin_state

def retract_on_evidence(h_c, evidence):          # 非单调、可废止
    if satisfies(h_c.falsifier, evidence):
        return ('retracted', h_c)
    return ('kept', h_c)

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| JSM | O(n_joint) 更新；自检 O(n_joint·H_st) | O(n_joint) | `H_nom` 可被残差/自检证伪；故障检出 ≤τ_fd（A41） |
| ESE/PSE | O(\|𝕏_exec\|·N_cell·\|Wc\|) / 重规划 | O(\|𝕏_exec\|) | 过近似真实执行集；`𝒫` 不被软件削弱（A44） |
| CGH | O(\|H_c\|·C_propose+\|H_c\|log\|H_c\|) | O(\|H_c\|) | 只增假设/加保守；无证据权；预算有界（A42） |
| PXR | O(n_joint·d_s+C_attr) | O(n_joint) | 归因可分离；`EV-prop` 不作证书（A43） |
| ECEG/J_e | O(\|π\|·\|𝕏_exec\|·\|Wc\|) | O(\|π\|) | `EV-common` 不存在；不可逆须 `EV-probe*_exec` |
| SPCX | O(\|CP\|·(b_cs+b_sem+k_cons+\|𝕏_exec\|)·C_plan) | O(\|𝕎\|+\|𝕏_exec\|) | 每点预算终止、五态完备 |

**正确性定理（Embodied Commonsense Soundness, ECS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 自模型覆盖：`H_nom` 上真实执行轨迹落在 `ε_track` 内概率 ≥`1−α_exec`，故障检出时延 ≤`τ_fd`；**(A42)** 常识无权限：CGH 只增假设/加保守/发观测，永不缩集/减裕度/授权，假设可审计且预算有界；**(A43)** 归因：`world/body` 误分 ≤`α_attr`，`EV-prop` 仅更新假设，`body` 归因作废同时段 `EV-xmodal`；**(A44)** 执行包络过近似真实可达集，且硬底 `𝒫` 不可被任何软件削弱、其自检诚实。则：

1. **执行地板（不依赖"执行=计划"）**：在 `H_nom` 上，`𝕏_exec∩𝒫` 内的碰撞风险 ≤`δ_coll`；故障退出后，在 `τ_fd` 检出 + 制动包络内安全停，失效界 ≤`δ_exec`。即使名义轨迹安全而执行偏离，风险仍按 `𝕏_exec` 计。
2. **常识单向性（无升险通道）**：CGH 只能使 `𝕎` 变大、`Δ_sem` 变大、观测变多；`EV-common` 不进入证据门，故常识的任何（包括幻觉）输出都不能提高速度、缩小裕度或授权动作；常识的错只可能让系统更慢/更停，不可能让它更敢。
3. **归因有界（世界-身体不互相洗白）**：`EV-prop` 的 `world` 归因不能把持续的身体故障解释成世界超过 `α_attr`；`body` 归因也不能把一致的世界异常误判为故障超过 `α_attr`，且一旦判 `body` 即作废同时段 `EV-xmodal`，故跨模态一致不能被身体共同因伪造。`unknown` 一律走安全停。
4. **终止与活性**：每检查点常识/语义/探针预算之和有界，SPCX 终止于 `{承诺, 改道, 锚爬行, 协商, 安全停}`；常识致冻结受 `b_cs` 与退锚通道约束。
5. **部署界**（对检查点与假设取联合界）：

```
P_safe ≥ 1 − Σ_cp [ δ_coll·1(执行) + α_exec + δ_exec·1(故障) + ε_meta(k) + α_map + α_attr ]
             − P(𝒫 硬底失效) − P(锚假设被违反) − P(共享图相关失准)
P_live ≥ 1 − P(常识预算耗尽 ∧ 退锚不可达) − P(归因 unknown 持续 ∧ 无安全停)
```

关键：**自模型给效率、硬底给保底**（执行包络把误差算进来，最终兜底却是不依赖模型的 `𝒫`）；**常识只加假设**（把长尾危险提出来，永不放行）；**本体把常识钉在物理上**（可废止先验必须能被扭矩/电流证伪）；三者把"身体正确性"从安全前提降级为可在线证伪的假设。

`(..., q_φ/k*, D(r), ρ_ℳ, s_op/auth, m_E, ood_state, J_p, H_nom/ε_track, 𝕏_exec, 𝒫_state, h_c/κ, b_cs, s_t/z_t/attr, J_e)`

其中新增：`H_nom/ε_track` 关节健康域与跟踪包络；`𝕏_exec` 执行可达集；`𝒫_state` 被动硬底自检状态；`h_c/κ` 常识假设与先验版本；`b_cs` 常识预算；`s_t/z_t/attr` 本体实测/对账残差/归因；`J_e` 具身安全证书。

云边协议 CEB++ → **CEB+++**：云端可下发**常识本体与常识先验**（类别→可能的动力学/affordance/稳定性先验）以及**关节健康基线与故障签名库**，但两者都只能进入"提案层/自检参考层"：常识先验**永不携带授权**，只能扩大本地 `𝕎_t^α` 或触发保守；关节基线**永不替代**本地在线残差与 `𝒫` 自检。边端回传**常识假设的证伪统计**（哪些常识在本地被扭矩残差推翻）、**归因混淆案例**与**硬底自检结果**，作为云端常识补盲与故障签名库更新依据。第 57 轮"一切判定器（含元模型）走隔离"在本轮推广为"**共享常识只是提案、身体证据永不外包**"。

## 6. 本轮最大风险

**一句话**：本轮把安全锚从"世界的模型/元先验"又向内推了一层到"身体的自模型"，但自模型恰恰由它所认证的同一套硬件维护——一个会撒谎的关节（编码器偏置/卡滞仍报正常）可以让 `H_nom` 静默地包含一个正在退化的关节，使 `𝕏_exec` 低估真实可达集，而常识与本体对账要么无证据权、要么被同一个故障混淆，救不了这个洞；因此最终的锚必须是被物理实现、周期自检、fail-safe 的 `𝒫`（硬限幅/抱闸/看门狗），而不是任何计算出来的包络——一旦 `𝒫` 本身不可信，"执行有包络"就只是把"世界不可知"换成了"身体不可知"。
