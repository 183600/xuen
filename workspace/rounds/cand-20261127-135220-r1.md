### 第 1 轮灵感驱动研究记录

**灵感词**：技能学习、深度学习

**直觉与动机**：
v29 已经把「安全」外包给一组统计证书（VAC/DGC/CCC），并把执行集收缩为 Exec_v29。但 v29 的学生策略仍是「单步动作映射」：它把长时程任务压成一个扁平函数 π_θ(s)→u，既没有显式的技能结构，也无法解释「这一段为什么这样动」。本轮从两个灵感词出发：

1. **技能学习**：双足运动天然是分段的——起步、稳态行走、跨越、制动是不同技能。与其让一个扁平网络隐式切分，不如显式维护「技能契约」o=(I_o,π_o,β_o)：每个技能只在自己的胜任域 R_o 内被调用，并携带前置条件 Pre_o、后置条件 Post_o、不变式 Inv_o。技能学习提供的是「时间抽象」：MPC 从逐步优化变为在技能序列上优化，长时程规划的组合爆炸被显著压缩。关键不是「学会更多技能」，而是「每个技能都带可组合的安全合同」。

2. **深度学习**：深度网络在这里承担两个不同角色，必须分开：(a) 作为**技能先验/发现器**——从无标签轨迹中用 VAE/对比学习发现可复用技能，给出 p_φ(o|s)，为技能级 MPC 提供热启动；(b) 作为**证书候选生成器**——用神经网络拟合每个技能的 barrier/Lyapunov 函数 ĉ_o，但网络只负责「提出候选」，是否成立必须由采样残差 + Lipschitz 外推界来裁决。把「深度学习的泛化」与「证书的保守性」解耦，是本轮的核心设计原则。

**关键洞见**：v29 的证书是「点/轨迹级」的，v30 的证书必须是「技能级 + 接缝级」的。单个技能各自安全，不等于技能串接安全——真正的事故往往发生在技能切换的那几帧。因此新增 HOC（Handoff Certificate）把「后置条件 ⇒ 下一技能前置条件」显式化为带裕度的合同，并把技能边界从「隐式由网络决定」变成「显式由证书裁决」。

**形式化目标（增量）**：
1. 定义技能契约 C_o=(Pre_o,Post_o,Inv_o,R_o,δ_o)，以及技能组合算子 o_i∘o_j 的合法性条件。
2. 定义技能组合定理：若每个技能在其域内保持 Inv_o 且到达 Post_o，且交接满足 Post_{o_i} ⇒ Pre_{o_{i+1}} 且裕度 ≥ δ_h，则整条技能序列保持组合不变式。
3. 定义神经证书的三重裁决：经验残差 ε_c、Lipschitz 常数 L_c、覆盖半径 Δ_c，仅当 ε_c+Δ_c ≤ margin_o 才准入。
4. 定义技能先验热启动不改变可行域：p_φ(o|s) 只进入优化初值与代价塑形，最终动作仍过 v29 十二证，故 Exec_v30 ⊆ Exec_v29。
5. 定义分层蒸馏学生 π_θ^hi(o|s) + π_θ^lo(u|s,o)，高层只选「已认证技能」，低层动作仍受 VAC/DGC 否决。
6. 目标：技能级 MPC 将长时程求解时间降低 ≥50%，技能组合在 ≥20 个新任务上保持 >90% 成功率，接缝处违规率低于扁平 v29 的 50%。

**本轮最大风险**：**技能接缝处的证书外推幻觉**——每个技能的神经证书都只在各自采样域内被验证，而技能切换恰好发生在两个域的边缘/空隙；深度证书网络在未采样接缝上会「自信地外推」出一个安全值，HOC 又只用有限样本估计 Post⇒Pre 的裕度，于是可能出现「逐技能证书全绿、组合却在切换帧失稳」的共谋失效。它比 v29 的多组件共因失效更隐蔽：失效点不在任何单个技能的证书覆盖范围内，而是在证书与证书之间的缝隙里。

## 2. 关键算法骨架（在 IP-467~472 骨架上扩展）

### IP-473 Skill Contract Library (SCL)

```python
@dataclass
class SkillContract:
    \"\"\"技能契约：技能只在 R_o 内被调用，并承诺 Pre→Post 且全程 Inv\"\"\"
    name: str
    pre: Callable[[np.ndarray], bool]
    post: Callable[[np.ndarray], bool]
    inv: Callable[[np.ndarray], bool]
    region: Callable[[np.ndarray], bool]
    horizon: int = 10
    margin: float = 0.05          # δ_o

class SkillContractLibrary:
    \"\"\"SCL：注册技能、筛选可调用技能、判定组合合法性\"\"\"
    def __init__(self):
        self.skills = {}          # name -> (contract, policy, cert)

    def register(self, contract, policy, cert):
        assert contract.margin >= 0.0
        self.skills[contract.name] = (contract, policy, cert)

    def admissible(self, s):
        \"\"\"当前状态可启动的技能：域内 ∧ 前置 ∧ 不变式\"\"\"
        return [n for n, (c, _, _) in self.skills.items()
                if c.region(s) and c.pre(s) and c.inv(s)]

    def handoff_ok(self, o_i, o_j, s, delta_h):
        \"\"\"组合合法性：Post_i ⇒ Pre_j，且仍在 j 的胜任域内\"\"\"
        ci, _, _ = self.skills[o_i]
        cj, _, _ = self.skills[o_j]
        return (ci.post(s) and cj.pre(s) and cj.region(s)
                and self.signed_margin(o_i, o_j, s) >= delta_h)

    def signed_margin(self, o_i, o_j, s):
        \"\"\"带符号裕度：由证书/Lyapunov 值换算，>0 表示交接有正余量\"\"\"
        ci, _, cert_i = self.skills[o_i]
        cj, _, cert_j = self.skills[o_j]
        return min(cert_i.value(s) - ci.margin, cert_j.value(s) - cj.margin)
```

### IP-474 Deep Skill Discovery & Prior (DSDP)

```python
class DeepSkillDiscoveryPrior:
    \"\"\"DSDP：无标签轨迹上的技能发现；只产出先验，不产出安全声明\"\"\"
    def __init__(self, n_skills=8, latent_dim=16):
        self.n_skills = n_skills
        self.encoder = SkillVAE(latent_dim)       # q_ψ(z|s)
        self.prior_head = SkillPriorHead(n_skills)  # p_φ(o|s)

    def fit(self, trajs):
        # 1) VAE/InfoNCE 学习可复用技能隐变量
        # 2) 以隐变量聚类得到离散技能 id，训练 p_φ(o|s)
        self._fit_vae(trajs)
        self._fit_prior(trajs)
        return self

    def log_prior(self, s):
        \"\"\"技能先验 log p_φ(o|s)，仅用于 MPC 初值/候选排序\"\"\"
        return self.prior_head(s)

    def propose(self, s, top_k=3):
        \"\"\"返回先验最高的 k 个技能，作为热启动候选（可被 SCL 过滤）\"\"\"
        logits = self.log_prior(s)
        return np.argsort(-logits)[:top_k]
```

### IP-475 Neural Certificate Learner (NCL)

```python
class NeuralCertificateLearner:
    \"\"\"NCL：网络拟合 ĉ_o，但由残差 + Lipschitz 外推半径裁决\"\"\"
    def __init__(self, hidden=128, lip_reg=1e-3):
        self.hidden = hidden
        self.lip_reg = lip_reg

    def train(self, skill, safe_samples, unsafe_samples, epochs=200):
        \"\"\"损失：安全侧 ĉ≥margin，不安全侧 ĉ≤-margin，加 Lipschitz 正则\"\"\"
        net = CertificateNet(self.hidden)
        for _ in range(epochs):
            loss = (relu(skill.margin - net(safe_samples)).mean()
                    + relu(skill.margin + net(unsafe_samples)).mean()
                    + self.lip_reg * self._lip_penalty(net, safe_samples))
            # ... 反向传播
        return net

    def certify(self, skill, net, region_samples, eps_grid):
        \"\"\"三重裁决：ε_c + 2·L_c·ε_g ≤ margin_o 才发 SCC\"\"\"
        eps_c = max(relu(skill.margin - net(region_samples)).max(), 0.0)
        L_c = self._estimate_lipschitz(net, region_samples)
        delta_c = 2.0 * L_c * eps_grid
        ok = (eps_c + delta_c) <= skill.margin
        return ok, dict(eps_c=float(eps_c), L_c=float(L_c),
                        delta_c=float(delta_c), margin=skill.margin)

    def _estimate_lipschitz(self, net, samples, k=8):
        \"\"\"局部成对差分估计 L_c，取高分位保守值\"\"\"
        ratios = []
        for s in samples:
            for s2 in self._neighbors(s, samples, k):
                ratios.append(abs(net(s) - net(s2)) / max(np.linalg.norm(s - s2), 1e-6))
        return float(np.quantile(ratios, 0.95))
```

### IP-476 Skill Handoff Margin Auditor (SHMA)

```python
@dataclass
class SkillHandoffMarginAuditor:
    \"\"\"SHMA：在切换分布上估计 Post_i ⇒ Pre_j 的带符号裕度\"\"\"
    lib: SkillContractLibrary
    delta_h: float = 0.03
    n_min: int = 50
    z_conf: float = 1.96

    def audit(self, o_i, o_j, transition_samples):
        \"\"\"输出 HOC：下置信界 ≥ δ_h 且样本足够才通过\"\"\"
        margins = np.array([self.lib.signed_margin(o_i, o_j, s)
                            for s in transition_samples])
        if len(margins) < self.n_min:
            return False, dict(reason=\"insufficient_handoff_samples\")
        lcb = margins.mean() - self.z_conf * margins.std(ddof=1) / np.sqrt(len(margins))
        ok = lcb >= self.delta_h
        return ok, dict(lcb=float(lcb), n=len(margins), delta_h=self.delta_h)

    def seam_risk(self, o_i, o_j, transition_samples):
        \"\"\"返回接缝风险画像：负裕度占比，供风险表与在线告警使用\"\"\"
        margins = np.array([self.lib.signed_margin(o_i, o_j, s)
                            for s in transition_samples])
        return float((margins < 0).mean())
```

### IP-477 Skill-Aware Distilled Policy (SADP)

```python
class SkillAwareDistilledPolicy:
    \"\"\"SADP：高层选已认证技能，低层出动作；仅作否决器链路的一环\"\"\"
    def __init__(self, hi_net, lo_net, hvpm, vaos, lib, certs):
        self.hi_net, self.lo_net = hi_net, lo_net
        self.hvpm, self.vaos = hvpm, vaos
        self.lib, self.certs = lib, certs
        self.u_ens_max, self.ood_max = 0.10, 0.30

    def propose(self, s):
        # 1) 只允许已获 SCC 且当前可启动的技能进入 softmax
        allowed = [n for n in self.lib.admissible(s)
                   if self.certs.get(n, {}).get(\"SCC\", False)]
        if not allowed:
            return None, None, None, None, \"no_certified_skill\"
        logits = self.hi_net(s)
        masked = self._mask_to(logits, allowed)
        o = allowed[int(np.argmax(masked))]
        u = self.lo_net(s, o)
        u_ens = self._ensemble_action_std(s, o, n_boot=4)
        ood = self.ood_scorer(s)
        return o, u, float(u_ens), float(ood), None
```

### IP-478 Skill-Composed Cert Gate (SC-KTCG)

```python
@dataclass
class SkillComposedCertGate:
    \"\"\"SC-KTCG：v29 十二证 + SCC/HOC/SGC；技能规划-接缝裁决-动作重放\"\"\"
    v29_gate: 'ValueAlignedDistillationCertGate'   # 原样复用
    scl: SkillContractLibrary
    ncl: NeuralCertificateLearner
    shma: SkillHandoffMarginAuditor
    sadp: SkillAwareDistilledPolicy
    dsdp: DeepSkillDiscoveryPrior
    delta_h: float = 0.03

    def admits(self, robot_plan, sensor_data):
        \"\"\"返回 (admitted, u_cmd, path, skill_seq)\"\"\"
        s0 = robot_plan.init_state

        # 1) 技能级规划：先验热启动 + 仅候选已认证技能
        seq = self._plan_skill_sequence(s0, horizon=4)
        if not seq:
            return self._v29_path(robot_plan, sensor_data)

        # 2) SCC：每个技能契约 + 神经证书三重裁决
        for o in seq:
            c, _, cert = self.scl.skills[o]
            if not self._scc_ok(o, cert, s0):
                return self._v29_path(robot_plan, sensor_data)

        # 3) HOC：逐切换点检查带符号裕度（接缝证书）
        for o_i, o_j in zip(seq[:-1], seq[1:]):
            samples = self._transition_samples(o_i, o_j)
            ok, _ = self.shma.audit(o_i, o_j, samples)
            if not ok:
                return self._v29_path(robot_plan, sensor_data)

        # 4) SGC：技能级价值/泛化，复用 VAC 的 LCB 语义
        o, u_stu, u_ens, ood, err = self.sadp.propose(s0)
        if err is not None:
            return self._v29_path(robot_plan, sensor_data)
        if self.sadp.hvpm.lcb(s0, u_stu) < self.sadp.vaos.v_min:
            return self._v29_path(robot_plan, sensor_data)

        # 5) 动作级重放：v29 十二证对技能条件动作再裁一次
        ok, u29, path = self.v29_gate.admits(robot_plan, sensor_data)
        if not ok:
            return False, u29, \"fallback\", seq
        return True, u29, \"skill\", seq

    def _scc_ok(self, o, cert, s0):
        \"\"\"SCC = 契约在域内成立 ∧ 神经证书三重裁决通过\"\"\"
        c, _, _ = self.scl.skills[o]
        if not (c.region(s0) and c.pre(s0) and c.inv(s0)):
            return False
        return bool(cert.get(\"SCC\", False))

    def _v29_path(self, robot_plan, sensor_data):
        ok, u, path = self.v29_gate.admits(robot_plan, sensor_data)
        return ok, u, path, []
```

**与 v29 的接口约定**：SC-KTCG 只在最外层新增技能规划、SCC/HOC/SGC 三个合取项；动作级仍调用 `v29_gate.admits`，因此 v29 的十二证语义逐字节保留。DSDP 的 `propose` 只影响 `_plan_skill_sequence` 的候选排序，不改变可行集。

## 4. 正确性论证（增量更新）

### 引理 29（技能契约的组合封闭性）

**陈述**：设技能序列 o_1,…,o_K，初始状态 s_0 满足 Pre_{o_1}∧Inv_{o_1}。若对每个 o_k，从任意满足 Pre_{o_k}∧Inv_{o_k} 的状态出发，执行 π_{o_k} 在 h_k≤horizon 步内全程保持 Inv_{o_k} 并终止于 Post_{o_k}；且每个交接点 s_k 满足 Post_{o_k}(s_k) ⇒ Pre_{o_{k+1}}(s_k) 与 signed_margin(o_k,o_{k+1},s_k) ≥ δ_h。则整条序列全程满足组合不变式 ⋀_k Inv_{o_k}，并终止于 Post_{o_K}。

**证明**：对 k 归纳。k=1 由假设直接得到 Inv_{o_1} 与 Post_{o_1}。设第 k 段结束于 s_k 且 Post_{o_k}(s_k) 成立；由交接条件得 Pre_{o_{k+1}}(s_k)，且 signed_margin ≥ δ_h>0 保证 s_k 仍在 o_{k+1} 的胜任域与正裕度内，故第 k+1 段的前提成立，归纳继续。每一段内部保持自身 Inv，故整条序列保持全部 Inv；最后一段给出 Post_{o_K}。∎

**工程含义**：δ_h 是「接缝证书」的显式裕度，防止在两个技能各自刚好达标时于切换帧发生约束穿越。

### 引理 30（神经证书的外推半径）

**陈述**：设真实证书 c_o 与学习证书 ĉ_o 均为 L_c-Lipschitz（相对状态度量），R_o 被半径 ε_g 的网格覆盖，且在每个覆盖中心 s_i 上 |ĉ_o(s_i)−c_o(s_i)| ≤ ε_c。则对任意 s∈R_o，|ĉ_o(s)−c_o(s)| ≤ ε_c + 2L_cε_g。若进一步要求准入时 ĉ_o(s) ≥ margin_o 且 ε_c+2L_cε_g ≤ margin_o，则 c_o(s) ≥ 0，即 s 真实安全。

**证明**：取 s 最近的覆盖中心 s_i，‖s−s_i‖≤ε_g。由三角不等式与 Lipschitz 性，|ĉ_o(s)−c_o(s)| ≤ |ĉ_o(s)−ĉ_o(s_i)| + |ĉ_o(s_i)−c_o(s_i)| + |c_o(s_i)−c_o(s)| ≤ L_cε_g + ε_c + L_cε_g = ε_c+2L_cε_g。再由 ĉ_o(s) ≥ margin_o ≥ ε_c+2L_cε_g ≥ c_o(s) 的误差上界，得 c_o(s) ≥ ĉ_o(s) − (ε_c+2L_cε_g) ≥ 0。∎

**诚实声明**：这是「采样 + Lipschitz」证书，不是形式化验证；ε_g 之外的区域没有保证，正是 HOC 要显式覆盖接缝的原因。

### 引理 31（先验热启动的可行域不变性）

**陈述**：DSDP 的 p_φ(o|s) 只用于技能序列搜索的初值与候选排序，不修改 SCL 的 `admissible` 集合，也不修改 v29_gate 的可行动作集。故 SC-KTCG 准入的任意轨迹仍满足 v29 十二证，即 Exec_v30 ⊆ Exec_v29。

**证明**：先验只改变搜索顺序，`admissible` 与 `_scc_ok` 的判据由契约和证书布尔值决定，与 p_φ 无关；最终动作必须通过第 5 步 `v29_gate.admits`。因此任何被准入的执行路径都逐项满足 v29 的十二个合取证书，执行集只会收缩。∎

### 定理（SC-KTCG 十五证准入门的执行集收缩）

**陈述**：SC-KTCG.admits(Π)=True 当且仅当 Π 通过技能路径（SCC ∧ HOC ∧ SGC ∧ v29 十二证重放）或 v29 教师/兜底路径，故 Exec_v30 = Exec_v29 ∩ {π: SCC(π) ∧ HOC(π) ∧ SGC(π)} ⊆ Exec_v29。

**证明**：技能路径第 2 步逐技能检查 SCC（契约 + 引理 30 的证书裁决），第 3 步逐切换点检查 HOC（引理 29 的交接前提），第 4 步检查 SGC（价值 LCB 不低于 V_min），第 5 步把技能条件下的动作重新送入 v29 十二证门。教师路径逐字节复用 v29_gate。两条路径的并集是 Exec_v29 与三个新合取项的交集，故为子集。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**技能接缝处的证书外推幻觉**——每个技能的 SCC 只在各自采样域 R_o 内成立，HOC 又只用有限接缝样本估计 Post_i⇒Pre_j 的裕度，而深度证书网络恰在未采样的域边缘「自信外推」；于是可能出现逐技能证书全绿、组合却在切换帧失稳的共谋失效，且失效点落在任何单个证书的覆盖范围之外，比 v29 的多组件共因失效更难在线归因。
