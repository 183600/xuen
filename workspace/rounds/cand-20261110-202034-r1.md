# 第 47 轮（新循环第 1 轮；承接第 46 轮 v23；本轮灵感：云边协同 × 共情表达） · Empathy-Cloud-Edge：共情表达驱动的云边协同证书与表达租约（v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 把记忆检索、语音指令、安全绑定做成了全局决策，但隐含假设 H5：所有感知—推理—交互都在机载边缘闭环，且交互输出只有"执行/排队"两种，不包含"如何表达"。**云边协同**打破前半句：VLM/大模型/共情理解被切到云端，边缘只保留实时执行，但 RTT、带宽、掉线、隐私约束会让证书建立在过期证据上；**共情表达**打破后半句：机器人不仅要"做对"，还要"让人感到被理解"，而延迟/错误的共情表达会误导人类、破坏信任、诱发不安全协作。两词耦合出新问题：**当"读人"的共情推理在云端、"读己"的能力与安全在边缘、"表达"在边缘实时生成时，如何保证表达出的情绪状态与真实用户状态 + 机器人能力在时延与掉线下仍然一致且可证；否则错误共情比冷漠更危险**。

## 0. 直觉与动机

**灵感 1（云边协同 → 证据时效与切分证书）**
直觉：云端更"聪明"，边缘更"快"。把推理流水线在某个切分点 s 切开，云端结论不是真理，而是**带时戳 τ 与校准置信 κ 的证据**；边缘只能在 staleness 预算 Δ_max(φ) 内消费，超时即视为不存在。切分点不应固定，要按 RTT/带宽/隐私/能耗动态选择，并在弱网时 fail-local。关键心态转变：云端是"有保质期的外脑"，不是"永远正确的大脑"。

**灵感 2（共情表达 → 表达是有安全后果的输出）**
直觉：表达不是装饰。一次共情表达 a（内容、语气、强度、时机、接近速度、停顿）只在有限时间窗与一致性半径内有效，称为**表达租约** ℓ_x。表达与真实状态不一致——用户焦虑而机器人轻快、或能力不足却表达"没问题"——会比中性表达更伤害信任并诱发危险依赖。因此表达必须可证、可降级到 fail-neutral（中性而非错误），而不是"尽量热情"。

**灵感 3（耦合 → 共情一致性 = 读人 × 读己 × 时延）**
直觉：一致性不能只看云端。云端给用户情绪后验 q_c(e|u)，边缘给自身能力 cap_t 与安全边界；合成本地状态后再决定"能表达什么"。合成需要一致性谓词与证据时效，任一不满足则输出中性表达，绝不输出未经认证的强共情。换言之，**表达强度应当随着证据新鲜度和自身能力余量单调下降**。

**耦合升级**：在 v10 四层架构（根信任 + L1 几何 + L2 上下文记忆 + L3 CAR + L4 DCL）之上叠加 **共情交互层 EIL（Empathy Interaction Layer）**，形成 v11。根信任层新增表达租约 ℓ_x 与云边证据契约；L2 记忆库增加 affect-outcome；L3 CAR 守卫同时检查动作与表达；L4 DCL 采集"云边分歧/共情失配"样本。核心新增三个 IP：CECP（切分与证据契约）、EEX（表达执行）、ECC（共情一致性证书）。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（云边切分与证据契约）**
流水线在切分点 s 分为云端块 f_c 与边缘块 f_e。云端输出证据消息 (y, τ, κ)，τ 为时戳，κ 为校准置信。staleness Δ=t-τ。证据契约
Valid_s(t)=[Δ ≤ Δ_max(φ)] ∧ [κ ≥ κ_min(φ)]。
契约失效时边缘不得消费该证据，必须回退到边缘先验或 fail-neutral。**单调性要求**：融合权重 w(Δ,κ) 对 Δ 单调不增、对 κ 单调不减。

**定义 60（用户情绪隐状态与融合后验）**
用户情绪 e_t ∈ E 不可直接观测，线索 u_t（表情、语调、姿态、任务上下文）。边缘先验 p_e(e|u_t)，云端后验 q_c(e|u_t)。有效时融合
q(e) ∝ p_e(e)^(1-w) · q_c(e)^w，w=w(Δ,κ)，
无效时 q=q_e 且置信置低。**共情可判定**：仅当 max_e q(e) ≥ τ_e 才允许强表达；否则一律中性表达。

**定义 61（共情表达动作与表达租约）**
表达动作 a=(content, intensity, timing, prosody)，目标情绪 e。表达租约
ℓ_x=(τ_x, Δ_x, ρ_x, e_ref)。
**租约有效**：t-τ_x ≤ Δ_x 且 dist(a, g(e_ref, cap_t)) ≤ ρ_x。此处 g 把情绪与能力映射为"恰当表达"参考，dist 为表达空间距离。注意 cap_t 是"读己"的产物：能力不足时同一情绪对应的恰当表达强度更低。

**定义 62（共情一致性证书）**
对表达 a、融合后验 q、能力 cap，定义最坏偏差
D(a,q,cap)=max_{e∈supp(q)} dist(a, g(e,cap))。
证书 C_x 声称
P( D(a,q,cap) ≤ ρ_x ) ≥ 1-α_x，
其中 ρ_x 由独立审计集共形校准。**云边合成证书** C_ce=(C_x, Valid_s)：二者同时成立才允许"强共情"，否则按定义 63 降级。

**定义 63（云边共情决策与降级链）**
策略 π(u_t, cap_t, net_t)=(m_t, a_t) 满足
(m_t,a_t)=argmax U_task(m)+λ_e·U_emp(a;q)
s.t. ℓ_p 有效、ℓ_e 有效、ℓ_x 有效、C_ce 成立、B(v_t,P_t,a_t)≥θ_safe。
约束失败时按固定顺序降级：**强共情 → 中性表达 → 仅执行不表达 → fail-closed**。表达永远不能覆盖 CAR 的安全否决。

## 2. 新增产出与既有 IP 升级

**IP-69 CECP（Cloud-Edge Certificate Partitioner）**
- 动态切分点选择：按 RTT/带宽/隐私/能耗为候选切分打分
- 证据契约签发与消费：时戳、校准置信、staleness 预算、单调融合权重
- 弱网 fail-local：云端不可用时回退边缘小模型并同步降低表达强度
- 云端响应与边缘状态对齐：防止用旧用户状态驱动新动作

**IP-70 EEX（Empathy Expression Executive）**
- 情绪→表达参数映射（语气/强度/节奏/接近速度）
- 强度裁剪与时机门控：安全相关动作前禁止高唤醒表达
- fail-neutral：置信不足/租约失效时输出中性表达而非错误共情
- 表达与动作联合节流：避免高频切换造成"情绪闪烁"

**IP-71 ECC（Empathy Consistency Certificate）**
- 最坏偏差 D(a,q,cap) 计算与共形阈值 ρ_x
- 云边合成证书 C_ce 与失效传播
- 跨域校准：云端域与边缘域分布差异的加权/分组校准
- 审计回灌：失配样本进入 DCL

**既有 IP 升级**
IP-66 MVR：记忆元组加入 affect 与表达结果，检索增加情绪距离项
IP-67 VAD：语音槽位增加语调/紧迫度/情绪线索，需求分布叠加 affect
IP-68 SAB：绑定函数扩展为 B(v_t,P_t,a_t)，表达也参与安全判定
IP-63 ECPS：效用中加入云边时延与云端能耗，模态决策考虑是否上云
IP-61 DCL：采集云边分歧样本、共情失配样本、弱网降级轨迹
IP-62 CCA：新增弱网/掉线红队、云端过期证据注入、共情越界测试
IP-51 CAR：守卫加入 ℓ_x 有效、C_ce 成立、表达不覆盖安全
IP-45 总线：新增 cloud-evidence / empathy-state / expression-lease / net-status 话题

## 3. 算法骨架

每交互周期：
1. 估 RTT/带宽/隐私约束，CECP 选择切分 s
2. 云端（若可用）返回 (y,τ,κ)，边缘校验证据契约
3. 融合用户情绪 q，检查 max_e q(e) ≥ τ_e
4. 运行 v10 动作决策得 m_t（含能量/姿态/安全约束）
5. EEX 在表达租约内生成 a_t，ECC 校验 C_ce
6. 任一失效 → 降级中性表达；安全相关仍不满足 → fail-closed
7. 记录云边分歧与共情失配，回灌 DCL

## 4. 本轮最大风险

**一句话**：云端过期或幻觉的用户情绪会被边缘当作有效证据，驱动机器人做出过度自信的共情表达，导致人类信任错配并诱发不安全依赖；而表达本身不直接违反运动学安全谓词，故这种失效最隐蔽——必须以证据契约 + 共形一致性证书 + fail-neutral 三重门控，并明确"表达永远不能覆盖 CAR 的安全否决"。

## 2. 关键算法 伪代码

### IP-69 CECP
```
def partition(c_t, net, privacy, budget):
    best = None
    for s in SPLITS:                       # 云端块/边缘块切分候选
        lat  = est_latency(s, net.rtt, net.bw)
        risk = est_staleness_risk(s, c_t, lat)   # 证据过期导致的决策风险
        priv = privacy_leak(s, c_t)              # 上云数据敏感度
        if lat > budget.lat_max or priv > budget.priv_max:
            continue
        score = lat + lam_r * risk + lam_p * priv + lam_e * energy(s)
        if best is None or score < best.score:
            best = (s, score, lat)
    return best if best else EDGE_ONLY          # 弱网 fail-local

def consume_evidence(msg, t, phi):
    dt = t - msg.tau
    if dt <= delta_max(phi) and msg.kappa >= kappa_min(phi):
        return msg.y, msg.kappa, True
    return None, 0.0, False                     # 契约失效，视为不存在

def fuse_user_state(u_edge, cloud_msg, t, phi):
    y_c, kc, ok = consume_evidence(cloud_msg, t, phi)
    q_e = edge_posterior(u_edge)
    if not ok:
        return q_e, confidence(q_e) * 0.5       # 只用边缘先验，置信降级
    w = weight(t - cloud_msg.tau, kc)           # Δ↑ w↓, κ↑ w↑
    q = normalize(pow(q_e, 1 - w) * pow(y_c, w))
    return q, confidence(q)
```

### IP-70 EEX
```
def empathy_utility(a, q, cap, ctx):
    benefit = expectation(q, lambda e: human_reward(a, e, ctx))
    risk    = consistency_penalty(a, q, cap)     # 与 D(a,q,cap) 相关
    return benefit - lam_risk * risk

def express(q, cap, lease, candidates):
    if max_conf(q) < tau_e:
        return NEUTRAL_EXPRESSION, 'fail-neutral'
    valid = [a for a in candidates if lease_valid(a, lease, cap)]
    if not valid:
        return NEUTRAL_EXPRESSION, 'fail-neutral'
    a_star = max(valid, key=lambda a: empathy_utility(a, q, cap, ctx))
    if not certify_empathy(a_star, q, cap):       # ECC 校验
        return clip_to_neutral(a_star), 'clipped'
    return a_star, 'empathic'
```

### IP-71 ECC
```
def consistency_bound(a, q, cap):
    return max(dist(a, g(e, cap)) for e in support(q))

def calibrate_rho(audit_pairs, alpha_x):
    devs = sorted(consistency_bound(a, q, cap) for a, q, cap in audit_pairs)
    n = len(devs)
    idx = min(n - 1, ceil((n + 1) * (1 - alpha_x)) - 1)
    return devs[idx]                              # split-conformal 分位数

def certify_empathy(a, q, cap):
    rho = calibrate_rho(AUDIT, alpha_x)           # 离线/滚动校准
    return consistency_bound(a, q, cap) <= rho
```

### 云边共情全局决策 Π_v11
```
def global_decision_v11(u_t, cap_t, net, v_t, M, Q_safe):
    split = partition(ctx(u_t), net, privacy, budget)
    cloud_msg = run_cloud(split) if uses_cloud(split) else None
    q, conf = fuse_user_state(u_t, cloud_msg, t, phi)

    m_t, status = global_decision_v10(u_t, cap_t, v_t, M, Q_safe)  # 既有安全链路
    if status == 'fail-closed':
        return 'fail-closed', NEUTRAL_EXPRESSION

    a_t, ex_status = express(q, cap_t, lease_x, EXPR_SET)
    if not certify_empathy(a_t, q, cap_t):        # 双保险
        a_t, ex_status = NEUTRAL_EXPRESSION, 'fail-neutral'

    if not safety_bind(v_t, pose_certify(m_t), omega_t, a_t):
        push(Q_safe, (v_t, a_t))
        return m_t, NEUTRAL_EXPRESSION, 'queued'

    return m_t, a_t, ex_status
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CECP 切分选择 | O(\|SPLITS\|) 每周期 | O(\|SPLITS\|) | 契约有效才消费云端证据，弱网回退边缘 |
| 情绪融合 | O(\|E\|) | O(\|E\|) | 权重单调 ⇒ 证据越旧影响越小 |
| EEX 表达选择 | O(\|EXPR\|·\|E\|) | O(\|EXPR\|) | 置信<τ_e 或租约失效即中性表达 |
| ECC 证书 | O(\|E\|) 在线 + O(n log n) 校准 | O(n) | 共形覆盖 ≥ 1-α_x（可交换假设下） |
| Π_v11 | O(\|SPLITS\|+\|EXPR\|·\|E\|) | O(\|Q\|) | 动作安全与表达一致性双重门控 |

**正确性定理（非正式）**：设审计集与部署分布可交换，ECC 阈值 ρ_x 按 split-conformal 校准，则任意被认证的强共情表达满足 P(D(a,q,cap) ≤ ρ_x) ≥ 1-α_x。设 CAR 守卫仅在 ℓ_p、ℓ_e、ℓ_x 有效且 B(v_t,P_t,a_t) ≥ θ_safe 时执行，则执行事件蕴含动作安全谓词成立；表达不改变动作安全判据，只是附加约束。若证据契约失效，π 退回边缘先验并在 max q < τ_e 时输出中性表达，故"错误强共情"只可能发生在 τ_e 门限内的小概率事件，且被记录用于审计。"表达永不覆盖安全否决"由 Π_v11 的返回顺序强制。

| E120 云端代价与隐私 | 上行字节、能耗、敏感数据外发 | 能耗 ≤ 预算；敏感外发 = 0 |

回退策略：E115 stale > 5% → 切分前移/强制边缘推理；E116 覆盖不足 → 增大 ρ_x 并降表达强度；E117 错误强共情 > 0 → τ_e 上调 + 全局 fail-neutral；E118 信任提升不显著 → 关闭强共情，保留中性表达与安全链路。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 云端过期/幻觉情绪被当证据 | 高 | 证据契约 + 单调融合权重 + τ_e 门限 |
| 共情越界诱发危险依赖 | 高 | ECC 最坏偏差 + 强度裁剪 + 独立审计校准 |
| 弱网频繁降级导致交互生硬 | 中 | 边缘小模型 + 平滑节流 + 中性表达兜底 |
| 表达与动作时序错配（说一套做一套） | 中 | SAB 绑定 B(v_t,P_t,a_t)，同周期联合调度 |
| 跨域分布漂移使 ρ_x 失真 | 中 | 分组共形校准 + 滚动重校准 + 失配回灌 |
| 上云隐私泄露 | 高 | 隐私预算约束切分，敏感模态永不上云 |

## 6. 本轮最大风险

**一句话**：云端过期或幻觉的用户情绪一旦被边缘当作有效证据，会驱动机器人做出过度自信的共情表达，造成人类信任错配与危险依赖；而表达不直接违反运动学安全谓词，失效极其隐蔽——必须用证据契约 + 共形一致性证书 + fail-neutral 三重门控，并硬性规定"表达永远不能覆盖 CAR 的安全否决"。
