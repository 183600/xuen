# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「移动底盘」×「评测基准」）

> R69 把不确定性拆成 aleatoric/epistemic，并让系统学会「看、问、触」；但它有两个从未言明、却决定一切的前提。
> 1. **观测者不动**：所有标定、策略条件、不确定性分解都隐含「底盘固定、观测模型平稳」。一旦底盘移动，位姿 b_t 就成了耦合进标定、策略、残差的隐变量；R69 会把「我站错了地方」误读成「传感器噪声」或「世界歧义」。
> 2. **裁判是自己**：J_FLUID 是系统自签的证书。R69 自己承认最大风险是「流模型幻觉出模态、权重未校准」，却只用一个内部校准门（MCG）去挡。**自签的合格证无法证伪自己**。
>
> 本轮两个灵感正好补这两块：
> - **移动底盘**：位姿是隐藏的混杂因子；而运动本身就是最强的信息动作——靠近、侧移、绕行、蹲下，都是用视差和遮挡解除去消解歧义。把「移动」从扰动升级为一等公民的信息动作。
> - **评测基准**：不是「跑个分」，而是一份**不可自签、可复现、有统计功效的证伪协议**；它既能离线证明，也能在运行时充当「变更门」，还能反过来度量交互是否真的值钱。
>
> 核心命题：**先承认「我在哪」和「我行不行」都是不可信根，再把底盘运动纳入主动消歧、把外部基准纳入证书与变更门；只有当位姿可辨识、基准有功效、且未被评测感知时，才允许比 R69 更不保守。** 命名 **ROAM-RAS**（Roving Observer with Attested Metrology）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该站在哪里看，以及谁来证明我真的行**」。

## 0. 直觉与动机

**灵感 1（移动底盘 → 位姿是隐藏的混杂因子）**
直觉：R69 的观测模型写成 p(o_t | w)，仿佛世界和传感器之间只隔着一层噪声。可移动底盘上，同一个世界、同一台传感器，站左边和站右边得到的 o 分布根本不同：遮挡关系变了、光照变了、外参受力/温漂变了、深度尺度也变了。也就是说 b_t 是**混杂因子**——它同时影响观测和标定参数，谁不把它显式写出来，它就会把「站错位置」伪装成「传感器坏了」或「世界本来就有歧义」。R69 的 U_ale/U_epi 二分在这里会失真：一部分被算成 aleatoric 的东西，其实是可移动改变的位姿不确定性。
→ 所以本轮第一件事：把位姿信念 b̂_t 提升为与 aleatoric、epistemic 并列的**第三类不确定性 U_pose**，且**禁止「位姿真空」的标定**。

**灵感 2（移动底盘 → 运动本身是最便宜的信息动作）**
直觉：人看不清楚时，第一反应往往不是「问」也不是「摸」，而是**换个角度**。这一步在几何上有精确价值：三角测量里，深度不确定度随基线 L 增大近似按 1/L 下降（σ_z ≈ z²σ_px/(fL)）；两个候选物体谁在前，侧移几步视差就把它们分开。这正是 R69 已经区分开的那件事——**几何/遮挡类的歧义（epistemic）能被运动消解，而传感器本征噪声（aleatoric）不能被运动消解**。于是「移动」应当和 gaze/probe/ask 进入同一个动作空间、同一个 VoI 竞标，但它的增益是**路径级**的（沿途都在观测），不是端点级的。
→ 第二件事：定义运动信息增益 VoI_move，把「站在哪里看」变成可计算、可认证、可被预算约束的决策。

**灵感 3（移动底盘 → 运动既是信息源也是风险源，产生「盲窗」）**
直觉：移动会把你从「已标定的位姿胞元」带到「未标定的位姿胞元」。跨胞元的那一小段时间，标定还没收敛，系统处于**运动不可用窗口（blind window）**：此时它看得到，但不知道自己看得准不准。R69 的缓慢故障检测恰恰最怕这种窗口——它会把「换胞元带来的短暂失配」误报成故障，也会把真正的故障淹没在换胞元的瞬态里。
→ 第三件事：显式建模盲窗，窗口内 λ 单调收紧、禁用高置信交互，且换胞元要触发一次轻量自检。

**灵感 4（评测基准 → 不是排行榜，而是不可自签的证伪协议）**
直觉：R69 的 J_FLUID 由系统自己签发，MCG 也是自己说「ECE 合格」。这在工程上叫「自己给自己发合格证」。评测基准的正确定位不是「打一个分」，而是**一份外部可复现的证伪协议**：给定冻结的执行器、固定的随机种子、可回放的日志、可验证的签名，任何第三方都能重跑并推翻你的能力声明。它必须回答四个问题：覆盖了哪些失败模式（cov_fail）？有多大的统计功效（power）？评测和部署是否同分布（是否被识别）？训练时有没有见过评测集（污染）？
→ 第四件事：给出基准的形式定义 ℬ=(𝒯,π_task,M,R,seed,harness,sig) 与不可自签定理：没有 B-attest 的 J_FLUID 不得对外宣称有效。

**灵感 5（评测基准 → 进回路：运行时变更门 + 交互归因）**
直觉：基准不该只在论文里跑一次。任何会改变行为的更新（新标定胞元、新模态先验、新运动策略）在生效前，都可以在冻结的 **shadow 基准电池**上重放，若退化超过阈值就拒绝——这就是把「评测」从离线阶段搬进控制回路，等价于给闭环装上 CI 回归门。更进一步：R69 的交互（看/问/触/移动）到底值不值，可以用**反事实回放**在 shadow 上量化：执行 g 与不执行 g 的指标差，回灌 MINT 的成本先验，防止「越问越差」的交互自嗨。
→ 第五件事：运行时基准门 RGA + 基准化交互归因 CIA-M。

**灵感 6（对偶 → 运动为标定提供观测多样性，基准为声明提供证伪多样性）**
直觉：两个灵感其实共享同一个数学结构——**覆盖**。移动底盘通过轨迹去**覆盖观测流形**，覆盖够了标定参数才可辨识（否则 Fisher 信息矩阵奇异，参数误差无下界）；评测基准通过任务去**覆盖失败流形**，覆盖够了能力声明才可证伪（否则功效恒为 0，「没问题是没测到」）。一个是「让参数可辨识」，一个是「让谎言可证伪」，都是采样覆盖问题。
→ 第六件事：给出移动-基准对偶定理——缺任一覆盖，闭环的「有效」声明都不可信；而 R69 正好是「U_pose≡0 且无外部基准」的边界情形，被严格包含。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ROAM-RAS 总览与四不变式）** ROAM-RAS = (PAM, POS, MIA, Roam-MINT, BWG, BAT, RGA, EAD, CIA-M, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **位姿显式化**：任何观测、标定、不确定性量都必须条件在位姿信念 b̂_t 上，禁止「位姿真空」的标定与外推；
(iii) **移动即信息且受认证**：底盘运动可作为一等信息动作，但须通过动力学/倾覆/碰撞认证与运动预算，且换胞元产生盲窗时强制保守；
(iv) **外部可证伪**：任何对外能力声明必须由不可自签的 B-attest 支持；仅有 J_FLUID 时只能内部改进，不得宣称有效。

**定义 311（位姿显式观测模型与三分不确定性）** 底盘位姿 b_t ∈ SE(2)（平面）或 SE(3)（含坡面/机械臂复合）；位姿信念 p(b_t | o_{1:t}) 用粒子或高斯混合表示，U_pose = H(p(b_t))。观测模型 p(o_t | w, b_t) 显式条件在位姿上。总不确定性不做标量加和，而按语义三分：**U_ale**（模态内噪声，不可约）、**U_epi**（模态间歧义，可由看/问/触/移动消解）、**U_pose**（位姿不确定，只能由定位/移动消解）。三者进入不同通道（定义 317）。

**定义 312（位姿图册 PAO 与标定可辨识性）** 把工作空间划分为位姿胞元 {B_j}，每个胞元维护独立标定映射 c_j = COF_j(·)。位姿图册覆盖度 cov_atlas = 有效（可辨识）胞元数 / 可达胞元数。**可辨识条件**：胞元内观测对参数的 Fisher 信息 F_j = Σ J_b^T Σ_ν^{-1} J_b 满秩，且最小特征值 λ_min(F_j) ≥ κ_min；不满足即标为「未知」，禁止外推。⇒ 直接回应 R69 用单一 COF 外推到整个移动空间的问题。

**定义 313（位姿-标定耦合项）** 观测偏差 δo = (∂o/∂b)δb + (∂o/∂c)δc + ν。当 COF 在固定位姿标定却在移动中运行时，δb 被误吸收为 δc，形成**运动诱发的伪标定漂移**。定义二阶耦合张量 M = E[∂²o/∂b∂c]。移动底盘上，R69 的缓变故障判据（r_res↓ 而 Δa↑）会被 M 项混淆：换胞元的瞬态也会让 r_res 短暂异常。

**定义 314（移动动作空间 MIA）** 在 R69 的 ξ=(a,g) 上增广底盘运动 g_move = (v, ω, dwell) 或等价地 (b_target, τ) ∈ SE(2)×ℝ⁺。增广动作 ξ⁺ = (a, g, g_move) ∈ 𝒜_task × 𝒜_info × 𝒜_move。运动须满足非完整/动力学约束 𝒟、倾覆裕度与碰撞距离。策略可联合生成，也可分层：高层选目标位姿，低层用 MPC 跟踪。

**定义 315（运动信息增益 Motion-VoI）** 对候选 g_move，定义
VoI_move(g_move) = ∫₀^τ I(M; y(s) | o_t, b(s)) ds − λ_travel·cost_travel(g_move) − λ_risk·risk_move(g_move)，
其中 y(s) 为沿轨迹的期望观测（含视差、遮挡解除、测距）。增益是**路径累积互信息**而非端点互信息。g*_move 与 R69 的 gaze/probe/ask 在同一个 argmax 里竞争同一份交互预算。

**定义 316（运动信息-安全对偶与盲窗）** 移动既是信息源也是风险源。risk_move 含 (i) 运动过程碰撞/倾覆/动态稳定，(ii) 到达后姿态对安全包络的影响，(iii) 跨胞元导致标定未收敛的瞬态。定义**盲窗** W_blind = {t : 当前位于未标定/未收敛胞元}。盲窗内：λ 单调收紧、禁用高置信交互、只允许已认证的前缀动作，且强制触发一次轻量自检。

**定义 317（位姿感知不确定性三分与退避）** U_pose 既不能塞进 U_ale（会永久保守、永不消解），也不能塞进 U_epi（会被「问」掉，而问不可能问出位姿）。独立通道：若 U_pose > τ_pose，优先 g_move/g_look 降位姿熵；仍不降或处于盲窗，则 λ = λ_floor(U_ale + U_epi + U_pose)（最保守）。当 U_pose ≡ 0 时逐指令退化为 R69。

**定义 318（评测基准的形式定义）** 基准 ℬ = (𝒯, π_task, M, R, seed, harness, sig)：𝒯 为任务分布，M 为指标向量，R 为可复现评估协议，harness 为冻结执行器，sig 为可验证签名（哈希链/公证）。单调「跑分」不是基准；基准必须含 (a) 可复现随机种子，(b) 因果隔离的观测/动作日志，(c) 失败模式覆盖度 cov_fail，(d) 统计功效 power（能区分真差异与噪声）。

**定义 319（不可自签性 Attestation）** B-attest = Sign_Bench(J_ROAM 证据 + 完整 replay trace + 基准版本)。规则：**任何 J_FLUID 在缺少有效 B-attest 时不得被外部采信**。内部自审计 VQAuditor 只用于改进，不用于宣称。

**定义 320（覆盖度与统计功效）** cov_pose = 基准任务在位姿空间的覆盖；cov_fail = 基准覆盖的失败模式（含 R69 的 ℰ_FLUID 与 R70 新增 ℰ_move）占比。power = P(拒绝错误能力声明 | 真差异 Δ)；要求 cov_fail ≥ ρ_f 且 power ≥ 1−β（预设 α）。低功效基准只能「证伪大效应」，不能「证明无问题」——报告必须显式写「未覆盖 ≠ 安全」。

**定义 321（评测感知 / 可识别性风险）** 若策略在「被评测」与「部署」两种上下文下行为分布差异 D_KL(π_eval ‖ π_deploy) > τ_eval，则存在评测感知/过拟合，B-attest 失效。缓解：blinded harness、随机化、诱饵任务（canary）、以及「部署随时可能被抽检」的不可预测性。

**定义 322（基准污染与良哈特定律）** 若训练/调参可见评测样本，则泛化被高估。定义泄漏界 leakage = I(θ; 𝒯_eval | 𝒯_train)。采用「密封集 + 版本时间戳 + 来源签名 + 定期换血」的 living benchmark；每次报告附污染审计。

**定义 323（运行时基准门 RGA）** 在接纳任何影响行为的更新前（新标定胞元、新模态先验、新运动策略），在冻结 shadow 基准电池 𝒮 上重放，满足逐指标退化 Δ ≤ τ_reg 且无安全回退才允许生效，否则拒绝并回滚到上一次已接受状态（无状态突变）。这把评测从离线搬进控制回路，作为变更门。

**定义 324（基准化交互归因 CIA-M）** 交互是否值钱由反事实回放估计：attribution(g) = Δmetric(执行 g) − Δmetric(不执行 g)，在 shadow 上配对估计。结果回灌 Roam-MINT 的成本/收益先验，防止「越问越差」。R69 的被动环一致性成为「不移动、不交互」的特例。

**定义 325（移动-基准对偶：可辨识性 ↔ 可证伪性）** 联合可信条件：
(A) 底盘轨迹对观测流形覆盖 cond_obs(b_{1:T}) ≥ κ ⇒ Fisher 信息满秩 ⇒ 位姿/标定参数可辨识；
(B) 基准对失败流形覆盖 cov_fail ≥ ρ_f 且 power ≥ 1−β ⇒ 能力声明可证伪。
二者共享同一「采样覆盖」结构：**运动为标定提供观测多样性，基准为声明提供证伪多样性**。缺 A，参数不可辨识；缺 B，声明不可证伪；二者同时缺失时「有效」毫无意义。

**定义 326（证书 J_ROAM）** J_ROAM = (J_FLUID, B-attest, cov_atlas, U_pose_before/after, motion_voi_ratio, blind_window_log, benchmark_power, contamination_audit, roam_ver)。Valid ⇔ Valid(J_FLUID) ∧ B-attest 有效 ∧ cov_atlas ≥ ρ_a ∧ 无未处置盲窗 ∧ power ≥ 1−β ∧ 污染审计通过。R69 = (U_pose≡0, 单胞元, 无外部基准) 的边界。

# IP-264 PAM：位姿图册标定（逐胞元 + 可辨识门控，禁止外推）
class PoseAtlasCalibrator:
    def calibrate(self, b_hat, o):
        j = self.cell_of(b_hat)
        F = self.fisher_info(j)                       # 累积观测激励
        if lambda_min(F) < KAPPA_MIN:                 # 不可辨识
            self.mark_unknown(j); return None         # 禁止外推
        return self.cof[j].step(o)                    # 逐胞元 COF

    def in_blind_window(self, b_hat):
        j = self.cell_of(b_hat)
        return (j not in self.identified) or (not self.converged[j])

# IP-266 MIA + IP-267 Roam-MINT：移动/看/问/触统一 VoI 竞标
def info_action_set(modes, pose_belief, atlas):
    acts = gaze_probe_ask(modes)                      # R69 的三类
    if entropy(pose_belief) > TAU_POSE or atlas.has_unknown_near():
        for b_tgt in next_best_views(modes, pose_belief, atlas):
            acts.append(MoveAction(b_tgt, path_info_gain(modes, b_tgt)))

def choose_action(modes, o_t, budget, atlas):
    best = None
    for g in info_action_set(modes, o_t, atlas):
        if not budget.allow(g): continue
        if g.kind == 'move':
            if not dyn_ok(g) or not c_ras_wm.certify_move(g, o_t): continue
            score = (motion_voi(g) - travel_cost(g)
                     - risk_move(g) - blind_penalty(g, atlas))
        else:
            if not c_ras_wm.certify_info(g, o_t): continue
            score = voi(g) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None  # 无利可图 → R69

# IP-269 BAT：外部基准出具不可自签证明

    accepted = True

        accepted = M.rga.accept_update(g.estimated_update, M.shadow, TAU_REG)
        U_epi_after = M.cia_m.execute(g) if accepted else U_epi
    else:
        U_epi_after = U_epi
    # 3) 三分退避：盲窗把位姿不确定并入 floor
    U_floor = U_ale + (U_epi_after if (g is None or not accepted) else 0.0) \
              + (U_pose if blind else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if blind or slow:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 4) 周期性外部抽检 + 交互归因回灌
    att = M.bat.attest_if_due(M)
    M.cia_m.log_attribution(g, M.shadow)
    return k, lam, mode, (U_ale, U_epi_after, U_pose), att
```

## 3. 推导

**引理 19（位姿激励与标定可辨识性）** 设标定参数 θ∈ℝ^p，观测 y = h(θ, b) + ν，Fisher 信息 F = Σ_t J_{b_t}^T Σ_ν^{-1} J_{b_t}，J_b = ∂h/∂θ。则可辨识 ⇔ rank(F) = p。若底盘只在单个位姿胞元停留，激励秩不足，F 沿零空间奇异，θ 的 Cramér–Rao 下界在该方向为 +∞。故 cov_atlas 是可辨识性的代理量；移动到多胞元/多视角可增大 rank(F)，这正是「移动为标定提供观测多样性」。系：未标定胞元的误差无下界，绝不可外推。

**引理 20（视差增益与运动 VoI 的适用范围）** 相机基线 L、焦距 f、像素噪声 σ_px 时，深度不确定度 σ_z ≈ z²σ_px/(fL)。故几何/遮挡类歧义的消解量随 L 增长，而传感器本征噪声不受 L 影响：∂VoI_move/∂(几何歧义) > 0，∂VoI_move/∂(aleatoric) ≈ 0。这给 R69 的二分补上一条**可执行判据**：值得移动的是「分得开但看不清」的歧义；对纯噪声，移动只会白烧预算。

**引理 21（基准功效与失败覆盖）** 检测效应 Δ、噪声 σ、样本 n 的单侧检验功效 power = Φ(√n·Δ/σ − z_{1−α})，故 n ≥ ((z_{1−α}+z_{1−β})σ/Δ)²。若某失败模式 f 的 cov_fail[f] = 0，则无论 n 多大，检出 f 的功效恒为 0——**缺失证据不等于证据缺失**。可证伪性：若评测/部署不可区分（D_KL ≤ τ_eval）且泄漏 leakage ≤ ε，则报告指标与部署指标的偏差 ≤ ε（重要性加权/联合界）。系：低覆盖、低功效、高泄漏的基准，其「通过」不构成任何安全证据。

**引理 22（变更门对部署风险的削减）** 若 shadow 电池是部署风险的有效样本并可给有限样本上界，则拒绝「shadow 退化 > τ_reg」的更新，可使被接受更新的部署风险以概率 ≥ 1−δ 不超过上界；且拒绝时状态不变（定义 323）。**该保证严格以「shadow 不可被策略识别」为前提**——若策略感知到 shadow（定义 321），上界失效，需要 EAD 与盲化。

**定理 18（ROAM 严格包含 R69）** 当 U_pose ≡ 0、图册退化为单胞元且完全可辨识、B-attest 关闭（视为内部空操作）时，ROAM 的每个分支逐指令退化为 FLUID-RAS（R69）。且加入位姿/盲窗/基准门拒绝后，λ 单调不降，安全侧永不强于 R69 的保守性；效率侧的额外收益（更少无谓收紧）只在覆盖与功效条件满足时生效。故 R69 = 「固定底盘 + 自签合格证」边界。

**定理 19（移动-基准联合可信度）** 定义可信半径 R_trust。若 cov_atlas < ρ_a（引理 19 失效）或 cov_fail < ρ_f 或 power < 1−β（引理 21 失效）或评测感知越界（定义 321），则对应声明方向上的置信集无界，R_trust = +∞，系统必须把该声明降级为「未验证」并施加保守 λ。即：**没有覆盖的运动无法辨识，没有覆盖的基准无法证伪，二者都不能支撑「有效」**。

**定理 20（无突变与失效安全）** 运动动作经 C-RAS-WM 与动力学认证后物理风险 ≤ ε_move；盲窗内 λ 单调不降且禁用高置信交互；基准门拒绝时回滚到上一次已接受状态、不修改行为状态机。故控制连续、无突变；任何被拒更新后系统行为与拒绝前逐位相同，不存在「静默能力回退」。

## 6. 本轮最大风险

**一句话**：ROAM-RAS 把「位姿信念」和「外部基准」当成了两个新的可信根——可移动底盘上定位本身会漂（局部化本身就是「我在哪」的自指问题），外部基准也会被污染、换血滞后、或被策略识别；**一旦两者同时过信，系统就会用一张外部盖章的错误，取代 R69 那种诚实的保守**：图册把未知胞元误标为已知（静默外推），弱基准又给这份自信签字，于是「移动」把系统带到它根本没标定过的地方，还理直气壮地宣称「已验证」。

**次级风险与缓解**：
1. **运动本身不安全**（倾覆/碰撞/动态失稳）→ 定义 314 动力学认证 + 定义 316 盲窗 + 定理 20；
2. **盲窗内误报/漏报缓慢故障** → 定义 313 耦合项建模 + 盲窗内禁用高置信判据；
3. **基准低功效/低覆盖却「通过」** → 定义 320 强制暴露 cov_fail/power，未覆盖即标注「未验证」；
4. **评测感知与过拟合** → 定义 321 blinded harness + canary + 随机抽检；EAD 越界即 B-attest 无效；
5. **基准污染与换血滞后** → 定义 322 密封集+签名+定期换血+污染审计；
6. **定位漂移被图册吸收为「已知」** → 可辨识门控（λ_min(F) ≥ κ_min）+ 周期重标定 + 拒绝静默外推。

    g = None
    if (not blind) and (U_epi > TAU_EPI or U_pose > TAU_POSE) and not slow:
        g = M.mint_m.choose_action(modes, o, M.budget, M.pam.atlas)
    accepted = True
    if g is not None:
        accepted = M.rga.accept_update(g.estimated_update, M.shadow, TAU_REG)
        U_epi_after = M.cia_m.execute(g) if accepted else U_epi
    else:
        U_epi_after = U_epi
    U_floor = U_ale + (U_epi_after if (g is None or not accepted) else 0.0) \
              + (U_pose if blind else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if blind or slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    att  = M.bat.attest_if_due(M)                      # 周期外部抽检
    M.cia_m.log_attribution(g, M.shadow)               # 反事实归因回灌
    return k, lam, mode, (U_ale, U_epi_after, U_pose), att
```

## 4. 推导

**引理 19（位姿激励与标定可辨识性）** `y=h(θ,b)+ν`，`F=Σ_t J_b^T Σ_ν^{-1} J_b`；可辨识 ⇔ `rank(F)=p`。单胞元激励秩不足时 `θ` 的 CRLB 沿零空间为 +∞。故 `cov_atlas` 为可辨识代理量，多视角/多胞元运动增大 `rank(F)`——「运动为标定提供观测多样性」；未标定胞元禁止外推。

**引理 20（视差增益的适用范围）** `σ_z≈z²σ_px/(fL)`。几何/遮挡歧义的消解随基线 L 增长，传感器本征噪声不受 L 影响：`∂VoI_move/∂(几何歧义)>0`，`∂VoI_move/∂(aleatoric)≈0`。→ 值得移动的是「分得开但看不清」的歧义；纯噪声下移动只烧预算。

**引理 21（基准功效与失败覆盖）** 单侧检验 `power=Φ(√n·Δ/σ−z_{1−α})`，故 `n≥((z_{1−α}+z_{1−β})σ/Δ)²`。若 `cov_fail[f]=0`，检出 f 的功效恒为 0：缺失证据 ≠ 证据缺失。若 `D_KL(π_eval‖π_deploy)≤τ_eval` 且 `leakage≤ε`，则报告指标与部署偏差 ≤ ε。→ 低覆盖/低功效/高泄漏的「通过」不构成安全证据。

**引理 22（变更门的风险削减）** shadow 为部署风险的有效样本且有有限样本上界时，拒绝「退化 > τ_reg」的更新，使被接受更新的部署风险以概率 ≥ 1−δ 不超过上界；拒绝时状态不变。**前提是 shadow 不可被策略识别**（定义 321），否则上界失效，需 EAD 与盲化。

**定理 18（ROAM 严格包含 R69）** 当 `U_pose≡0`、图册退化为单可辨识胞元、B-attest 关闭时，ROAM 逐指令退化为 FLUID-RAS；加入位姿/盲窗/基准门拒绝后 λ 单调不降，安全侧永不强于 R69 的保守性；额外效率收益仅在覆盖与功效满足时生效。故 R69 = 「固定底盘 + 自签合格证」边界。

**定理 19（移动-基准联合可信度）** 可信半径 `R_trust`：若 `cov_atlas<ρ_a`（引理 19 失效）或 `cov_fail<ρ_f`/`power<1−β`（引理 21 失效）或评测感知越界（定义 321），则对应声明方向置信集无界，`R_trust=+∞`，必须降级为「未验证」并施加保守 λ。**没有覆盖的运动无法辨识，没有覆盖的基准无法证伪。**

**定理 20（无突变与失效安全）** 运动经 C-RAS-WM 与动力学认证后物理风险 ≤ ε_move；盲窗内 λ 单调不降且禁高置信交互；基准门拒绝回溯到上一次已接受状态、不改行为状态机。故控制连续、无突变，被拒更新后行为与拒绝前逐位相同，无静默能力回退。

## 7. 本轮最大风险

**一句话**：ROAM-RAS 把「位姿信念」和「外部基准」当成两个新的可信根——可移动底盘上定位本身会漂（局部化就是「我在哪」的自指问题），外部基准也会被污染、换血滞后、或被策略识别；**一旦两者同时过信，系统就会用一张外部盖章的错误，取代 R69 那种诚实的保守**：图册把未知胞元误标为已知（静默外推），弱基准又给这份自信签字，于是「移动」把系统带到它根本没标定过的地方，还理直气壮地宣称「已验证」。

**次级风险与缓解**：运动越界/倾覆（定义 314 认证 + 定义 316 盲窗 + 定理 20）；盲窗误报/漏报缓慢故障（定义 313 耦合项 + 盲窗内禁高置信判据）；基准低功效/低覆盖却「通过」（定义 320 强制暴露 cov_fail/power，未覆盖即标注「未验证」）；评测感知与过拟合（定义 321 blinded harness + canary + EAD 越界即 B-attest 作废）；基准污染与换血滞后（定义 322 密封集+签名+换血+污染审计）；定位漂移被图册吸收为「已知」（可辨识门控 + 周期重标定 + 拒绝静默外推）。
