# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 1 轮；本轮灵感：「UniBot」×「视觉问答」）

> 第 68 轮 CALM-RAS 用「在线标定 + 自监督 + 单模型多任务」给闭环补上了计量层，但它的自陈风险指出了这条路线的一个结构性死角：**标定器与被标定对象共享同一条信息回路，于是标定能力越强，落在标定带宽内的缓变故障越隐形**——系统在「测量越来越准」的自我确认中失去最后一道检出能力。根因不是参数没调好，而是**循环证据（circular evidence）**：用传感器诊断传感器，用模型监督模型。
>
> 本轮的灵感恰好提供了唯一一条**语义带宽外**的独立通道：
> - **UniBot**：把所有任务（感知 / 世界模型 / 控制 / 标定 / 审计）压进同一个通用具身骨干，使「同一个头脑」既能行动、也能**被提问**；
> - **视觉问答（VQA）**：语言是对世界独立、可组合、可物理核对的描述系统——它不来自传感器流，因此可以**打破标定的自证循环**。
>
> 核心命题：**把 VQA 从「事后审计器」升级为「主动计量探针」——用可验证的问题、以主动信息增益选择去问模型，让它的语义回答与几何/触觉测量构成三角一致性检验，从而把「世界变了 / 传感器歪了 / 模型漂了」从后验赌博变成可分辨的三分解——UBV-RAS（UniBot-VQA Reflective RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我对世界的描述，和我的测量对得上吗**」——当语义与测量互相矛盾且无法用任何单一慢变量解释时，系统必须承认「我可能不知道」，并全局收缩。

## 0. 直觉与动机

**灵感 1（UniBot → 从「模型动物园」到「一个可被提问的头脑」）**
直觉：R68 把 ERG/WM/校准压进 MTM 五头，但审计器（VQAuditor-C）仍是外挂的、异步的、与主模型不同源的「第二视角」。UniBot 的启示是：通用具身模型不该只有一个「做」的输出，还应有「说」的输出——同一个共享表征既能驱动机器人，也能回答关于场景的问题。同源带来两个红利：(i) 提问成本趋近于零（复用一次前向的 z_t）；(ii) 「说」与「做」共享表征，任何**言行不一致**都是模型内部可检测的裂缝，而不是两个模型各自漂移的不可分噪声。审计从「事后读日志」变成「在线一问一答」。

**灵感 2（视觉问答 → 语言是计量学里的「独立基准」）**
直觉：计量学的核心不是「多测几次」，而是**换一把不同原理的尺子**。R68 的标定用自己的传感器残差回归自己的标定参数——本质上是用同一把尺子校准自己，存在规范自由度（gauge freedom）：漂移与故障在某些方向上不可分辨。VQA 提供的是另一种原理的尺子：语言对「杯子在桌沿上」「夹爪已闭合」「左脚踩在斜坡上」的描述，来自语义世界模型，而非像素-力残差。把 VQA 答案与几何/触觉测量对齐，就得到一个**外部锚**，能剥离标定器无法自我发现的那部分偏差。

**灵感 3（可验证性 → 不是所有问题都算数）**
直觉：VQA 有两类病——幻觉（自信地胡说）与语言先验捷径（不看图、按常见答案猜）。如果问题本身可以从语言先验答对（「桌上通常有杯子」），那它就**没有计量价值**。因此必须给每个问题两个标量：可验证度 ν(q)（答案能否被物理/已知标定物独立核对）与先验可答度 π_lang(q)（不看视觉也能答对的概率）。只有 **ν 高且 π_lang 低** 的问题才是好探针。这把「提问」从随意聊天变成**主动实验设计**。

**灵感 4（主动提问 → 视觉问题即干预/实验）**
直觉：被动 VQA 只是在已有数据上打分；主动 VQA 是**选择最有信息量的问题去问**——这正是实验科学的本质。给定当前对隐状态（是否有故障 / 是否漂移 / 模型能力是否下降）的后验，选择使期望信息增益最大、且可物理核对的问题；必要时甚至选择「看哪里 / 动一下再看」（主动视角/主动探测动作）。这把 R68 的「静态段自标定」扩展为「**由问题驱动的主动标定**」。

**灵感 5（四灵感合流 → UBV-RAS 六组件）**
1. **UBM UniBot 统一具身骨干**：在 R68 MTM 上增 vqa_head 与 act_head，跨本体 tokenizer，一次前向同时产出动作、标定、以及可被查询的语义回答；
2. **VProbe 可验证探针**：从场景/动作生成候选问题，按 ν·(1−π_lang) 打分，答案与测量组成语义残差 r_sem；
3. **AQS 主动提问选择器**：以后验隐状态为目标做信息增益最大化，预算受限；
4. **RCB 反循环锚**：强制一定比例 ρ_anchor 的探针必须物理可核对（已知标定物/里程计/触点），用它们审计标定器，打破自证循环；
5. **ICC 内省能力校准**：用可验证探针上的准确率与置信度校准得到能力 κ，作为第三条独立不确定性来源进入 λ_floor；
6. **RAS-WM‡ 继承核**：CALM-RAS 全部保留，MTM 换成 UBM，归因新增第三分解支路（world/sensor/model）。

**灵感 6（对 R68/R67/R66 风险的对症下药）**
- R68「缓变故障被标定吸收」：VQA 语义残差对缓变故障**不带宽受限**（语义描述会随物理状态漂移），RCB 的物理可核对探针提供外部参照，定理 16 证明可恢复检出；
- R67「黑箱前瞻误放宽」：UBM 同源使「说」与「做」共模，言行不一致检验直击前瞻幻觉；
- R66「情绪被欺骗」：可问「这个人现在的表情与刚才的行为一致吗」这类反事实探针，语义与行为上下文一致性成为第三重校验；
- 统一纪律：λ_floor 扩展为 max(0.6, 0.8·1[U_cal>τ ∨ κ<τ_κ ∨ r_sem>τ_sem ∨ |z_anchor|>τ_anchor])——**三类不确定性任一触发都只收紧**。

## 1. 形式化定义（增量：定义 293–304）

**定义 293（UBV-RAS 总览）** UBV-RAS = (UBM, VProbe, AQS, RCB, ICC, RAS-WM‡)。在 CALM-RAS 三不变式上再加两条：
(iv) **反循环不变式**：任何用于审计标定/故障的证据，至少有比例 ρ_anchor ∈ [0.1, 0.3] 必须来自与标定状态「信息独立」的物理可核对探针；
(v) **提问零侵入**：提问只在推理期进行、复用 z_t，不向实时控制回路注入写操作；提问预算 B_q ≤ 8 次/秒。

**定义 294（UBM 统一具身骨干）** M_θ = (Φ_θ, {head_i}, {A_i})，头集扩展为 emo/fault/wm/cal/qual/**vqa**/**act**。Φ: (o_t, a_{t−1}, ctx, q?) → z_t ∈ ℝ^{256}；vqa_head: (z_t, q) → p(ans | q, z_t)；act_head: z_t → a_t。跨本体 tokenizer T_emb 把不同自由度映射到统一动作/观测空间（UniBot 迁移性）。共享 z_t 同时驱动「说」（vqa/qual）与「做」（act/wm）。

**定义 295（可验证探针与语义残差）** 问题集 Q 上一组探针 q 产生回答分布 p(ans|q)。参考答案分布 p_ref(ans|q) 由物理测量/已知标定物/几何模型独立给出。语义残差
r_sem(q) = D(p(ans|q) ‖ p_ref(ans|q))，
对多问题聚合 r_sem = Σ_q w_q r_sem(q)，权重 w_q 由信息量给出（定义 297）。

**定义 296（可验证度与先验可答度）** 对问题 q：
- 可验证度 ν(q) ∈ [0,1]：答案能被独立物理量核对的程度（已知标定物=1，纯主观描述≈0）；
- 先验可答度 π_lang(q) ∈ [0,1]：不看图像、仅凭语言先验答对的概率（用留出先验基线模型估计）；
- **探针价值** J(q) = ν(q)·(1 − π_lang(q))。J(q) < τ_J 的问题不得进入审计证据集。

**定义 297（主动提问选择 AQS）** 令 h 为待分辨隐状态（世界变化/传感漂移/模型退化/标定状态），H_t 为其当前后验。选择
q* = argmax_{q ∈ Q, J(q) ≥ τ_J} I(h; A_q | z_t, H_t)  s.t.  Σ cost(q) ≤ B_q，
其中互信息用 vqa_head 的预测熵与期望后验熵之差估计：IG(q) = H[p(h)] − E_{a~p(·|q)}[H[p(h|a)]]。若最大 IG < τ_IG，判定「无可问之问」，**如实做**（见定理 17）。

**定义 298（世界-传感器-模型三分归因）** 在定义 280 的 cause 集上扩展为三元：
P(d ∈ {world, sensor, model} | r_t, r_sem, κ_t) ∝ p(r_t, r_sem | d)·P(d)，
- d=world：测量一致、语义一致，但状态真变了（如地面材料变了）；
- d=sensor：几何残差大而**语义残差小**（VQA 说「还是那个杯子」，测量却漂了）→ 传感器/标定问题；
- d=model：语义残差大且**语义自身内部矛盾**（同一问题不同视角答案互斥、可验证探针准确率骤降 κ↓）→ 模型退化。
关键判别式：语义残差与几何残差的相关结构——world 使两者同向、sensor 只推高几何残差、model 只推高语义残差与内部矛盾。

**定义 299（反循环锚 RCB）** 设证据集 E = E_anchor ∪ E_circ，其中 E_anchor 来自物理可核对探针（ν ≥ ν_min 且答案不由 c 生成）。反循环审计统计量
z_anchor = (1/|E_anchor|) Σ_{q∈E_anchor} r_sem(q) / σ_q。
若 |z_anchor| > τ_anchor，则即使标定器自认为收敛（U < τ_cal），也判标定可疑、冻结 ĉ 并抬升 λ_floor。覆盖率约束 |E_anchor|/|E| ≥ ρ_anchor。

**定义 300（内省能力 ICC）** 能力 κ_t = 可验证探针上的校准准确率（confidence-calibrated accuracy）：κ = 1 − ECE − (1−Acc)。用滑窗估计并附不确定度。κ 与 U_cal 独立（一个衡量「传感器准不准」，一个衡量「模型会不会答错」）。κ 下降即触发 λ_floor，与标定无关。

**定义 301（言行-测量三角一致性）** 对当前计划动作 a_t，取三元组：
τ_tri = ( ⟨VQA: 「执行 a 后会发生什么」⟩, ⟨WM: ŝ_{t+1}⟩, ⟨实际 s_{t+1}⟩ )。
一致性残差 r_tri = D(p_vqa(a) ‖ p_wm(a)) + ‖s_{t+1} − ŝ_{t+1}‖。UBM 同源 ⇒ 前两项应共模；若二者显著分裂，说明「说」与「做」的表征已漂离（模型退化或头部失配）。

**定义 302（λ_floor 扩展）** λ_floor = max(0.6, 0.8·1[U_cal>τ_cal ∨ κ<τ_κ ∨ r_sem>τ_sem ∨ |z_anchor|>τ_anchor])。三类不确定性（标定/能力/语义）任一触发都只收紧。并令 τ_risk 随 r_sem 收紧：τ_risk = τ⁰(1 − κ_r U_cal − κ_s r_sem)。

**定义 303（J_UBV 证书）** J_UBV = (J_CALM, vqa_probe_hash, κ, ρ_anchor, z_anchor, r_sem, tri_res, ubv_ver)。Valid ⇔ Valid(J_CALM) ∧ κ ≥ τ_κ^hard ∧ ρ_anchor 达标 ∧ |z_anchor| ≤ τ_anchor^hard。

**定义 304（干扰集 ℰ_UBV）** ℰ_UBV = ℰ_CALM × ℰ_vqa × ℰ_probe；ℰ_vqa = {幻觉、语言先验捷径、问题投毒、对抗图像扰动}；ℰ_probe = {探针选择偏置、预算饥饿、锚覆盖不足、提问被模型反向利用}。

# IP-253 UBM：在 MTM 上加 vqa/act 头，一次前向“说+做”
class UniBotBackbone:
    def forward(self, obs, a_prev, ctx, q=None):
        z = self.trunk(self.tok(obs), a_prev, ctx)
        out = {'z': z, 'act': self.heads['act'](z),
               'cal': self.heads['cal'](z), 'wm': self.heads['wm'](z)}
        if q is not None:
            out['vqa'] = self.heads['vqa'](z, q)   # p(ans|q,z)
        return out

# IP-254 VProbe + IP-255 AQS：可验证探针与主动提问
class VisualProbe:
    def score(self, q):                            # 定义 296
        nu = self.verifiability(q)                 # 能否物理核对
        pi = self.prior_only_prob(q)               # 语言先验可答度
        return nu * (1 - pi)
    def ask(self, q, z):
        p = self.ubm.forward(q=q)['vqa']
        return p, self.semantic_residual(q, p)     # r_sem(q)

class ActiveQuestionSelector:
    def select(self, z, H, budget=8):              # 定义 297
        cands = [q for q in self.Q if self.probe.score(q) >= TAU_J]
        def ig(q):
            p = self.probe.ask(q, z)[0]
            return H_ent(H) - expected_ent(H, p)
        return sorted(cands, key=ig, reverse=True)[:budget]

# IP-256 RCB：反循环锚审计
def anchor_audit(probe, cfg):
    Ea = [q for q in probe.used if probe.verifiability(q) >= NU_MIN]
    if len(Ea) < cfg.rho_anchor * len(probe.used):
        return {'anchor_short': True, 'z': np.inf}
    z = mean([probe.r_sem(q) / probe.sigma(q) for q in Ea])
    return {'anchor_short': False, 'z': z, 'suspicious': abs(z) > TAU_ANCHOR}

# IP-258 三分归因
def tri_attribution(r, r_sem, kappa, post_CALM):
    corr = corr_within(r, r_sem)
    if corr > 0 and consistent(post_CALM):        d = 'world'
    elif r_sem < TAU_SEM and norm(r) > TAU_GEO:   d = 'sensor'
    elif r_sem > TAU_SEM and kappa < TAU_K:       d = 'model'
    else:                                         d = 'undecided'
    return normalize({d: ..., 'undecided': ...})

# IP-262 主闭环（继承 CALM-RAS）
def UBV_RAS_round(M, obs):
    o = M.ubm.forward(obs, M.a_prev, M.scene_ctx)
    r = residuals(obs, o, M.wm_cache)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))
    qs = M.aqs.select(o['z'], M.H, budget=B_Q)       # 主动探针
    r_sem, probe_log = 0.0, []
    for q in qs:
        p, rs = M.vprobe.ask(q, o['z'])
        r_sem += M.probe_weight(q) * rs; probe_log.append((q, p, rs))
    avid = M.rcb.audit(M.vprobe, probe_log)          # 反循环锚审计
    kappa = M.icc.update(probe_log)                  # 内省能力
    dpost = M.tri_attribution(r, r_sem, kappa, M.H,
                              M.cfa(r, o['pi'], c, U))    # 三分归因
    lam = max(M.efs.risk_scale(dpost), thr['lam_floor'],
              0.8 if (avid['suspicious'] or kappa < TAU_K or r_sem > TAU_SEM
                      or o['qual']['face'] < 0.8) else 0.6)
    A = M.ach.propose(obs, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, dpost, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.mtm.rollout(o['z'], A))
    if U > TAU_CAL or abs(avid['z']) > TAU_ANCHOR: k = min(k, k_cal_shrink(U))
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau = emotion_response_shaping_wm(tau, dpost, M.wm_preds)
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, dpost, (c, U, kappa, r_sem, avid['z'])

## 3. 推导

**引理 16（反循环可辨识性）** 设标定观测只依赖 (c, f)（c 漂移、f 故障）的某个线性组合，则标定-故障联合估计存在至少一维规范自由度（不可辨识方向 v: ∂r/∂c ∥ ∂r/∂f）。物理可核对探针的答案只依赖世界状态 ω 与 c、而不依赖 f，提供至少一维与 r 张成空间正交的约束，使秩提升，规范自由度被消除。因此当 ρ_anchor ≥ ρ_min 且锚探针在参数空间张成对应方向时，c 与 f 可分离——**标定器的自我确认盲区被外部尺子照亮**。

**引理 17（提问信息增益界）** 对问题 q，I(h; A_q) ≤ H(A_q) − H(A_q | 物理核对)，且若 π_lang(q)=1（纯先验可答），则 A_q 与 h 条件独立 ⇒ I=0。故探针价值 J(q)=ν(1−π_lang) 是信息增益的上界代理；AQS 在预算 B_q 下按 IG 贪心选择达到 1−1/e 近似最优（子模性假设 A95）。系：**问对问题比多问问题更重要**。

**引理 18（VQA 捷径可检出性）** 用反事实问题对 (q, q')（同一问题、最小图像/场景编辑）检测语言先验捷径：若 p(ans|q) ≈ p(ans|q') 而对应物理参考不同，则 π_lang 高、J 低，该 q 被降权。设捷径比例为 π_lang，则语义残差对故障的检验功效 ≤ 1−π_lang；将捷径问题从证据集剔除后功效恢复到 ≥ 1−τ_J。系：**可验证性筛选是 VQA 计量的前提，不是可选优化**。

**定理 16（三分归因一致性与缓变故障可恢复）** 在 A92（漂移慢）、A95（探针子模）与引理 16–18 下：
1. 若真实事件为 sensor（漂移），则几何残差 ↑ 而语义残差 r_sem 与 κ 保持（VQA 描述世界不变）⇒ P(d=sensor) → 1；
2. 若为 model（退化），则可验证探针 κ ↓、言行三角残差 r_tri ↑ ⇒ P(d=model) → 1；
3. 若为 world（真变化），则几何与语义残差同向 ⇒ P(d=world) → 1；
4. **区别于 R68**：即使故障频率落在标定带宽内（ω_f < ω_cal），语义残差不受该带宽限制，故 P(检出缓变故障) ≥ 1 − exp(−|E_anchor|·J_min·SNR)，**随锚探针数指数上升**——R68 的隐匿故障在此重新可见；
5. 三类误判之和 ≤ α_cal + α_sem + α_κ，任一项超阈 ⇒ λ_floor 抬升（定义 302），故**任何归因失败都只导致保守，不导致放宽**。

**定理 17（内省安全 / 无可信探针时退回最保守）** 若 AQS 找不到 J(q) ≥ τ_J 或 IG ≥ τ_IG 的问题（「无可问之问」），则 ICC 无法更新、κ 取先验下界 κ_min；由定义 302，λ_floor = 0.8，且定义 303 使 J_UBV 不 Valid，触发全局降级。系：**系统被设计为「问不出可信问题时不假装知道」**，从根本上杜绝 R68 最担心的「自信地无知」。

**定义 293（总览与两不变式）** 在 CALM-RAS 三不变式上增加：(iv) 反循环不变式——审计证据中物理可核对探针占比 ≥ ρ_anchor，且与标定状态信息独立；(v) 提问零侵入——提问仅推理期复用 z_t，不写控制回路，预算 B_q ≤ 8/s。

**定义 295（语义残差）** `r_sem(q) = D(p(ans|q) ‖ p_ref(ans|q))`，`r_sem = Σ_q w_q r_sem(q)`；p_ref 由物理测量/已知标定物/几何模型独立给出。

**定义 296（探针价值）** `J(q) = ν(q)·(1−π_lang(q))`；`J(q) < τ_J` 的问题禁止进入审计证据集——可验证性筛除是计量前提（引理 18）。

**定义 297（AQS）** `q* = argmax I(h; A_q | z_t, H_t)`，`Σ cost ≤ B_q`；`IG(q) = H[p(h)] − E_a[H[p(h|a)]]`；`max IG < τ_IG ⇒ 无可问之问`（定理 17）。

**定义 299（RCB）** `z_anchor = mean_{q∈E_anchor} r_sem(q)/σ_q`；`|z_anchor| > τ_anchor ⇒` 即使 `U<τ_cal` 也冻结 ĉ 并抬升 λ_floor； coverage `|E_anchor|/|E| ≥ ρ_anchor`。

**定义 300（ICC）** `κ = 1 − ECE − (1−Acc)` 在可验证探针滑窗估计；与 U_cal 独立；κ 下降独立触发 λ_floor。

## 4. 推导

**引理 16（反循环可辨识性）** 只用自身传感器的标定观测依赖 (c, f) 的同一线性组合，标定-故障联合估计存在至少一维规范自由度（`∂r/∂c ∥ ∂r/∂f`）。物理可核对探针只依赖世界状态与 c、不依赖 f，提供至少一维正交约束，使秩提升、规范自由度被消除。故 `ρ_anchor ≥ ρ_min` 且锚探针张成对应方向时 c 与 f 可分离——R68 的自我确认盲区被外部尺子照亮。

**引理 17（提问信息增益界）** `I(h; A_q) ≤ H(A_q) − H(A_q | 物理核对)`；若 `π_lang(q)=1` 则 `A_q ⟂ h`、`I=0`。故 `J=ν(1−π_lang)` 是 IG 的上界代理；AQS 在预算 B_q 下按 IG 贪心达 `1−1/e` 近似最优（A95 子模）。系：问对问题比多问问题更重要。

**引理 18（VQA 捷径可检出性）** 反事实问题对 `(q,q')`（最小场景编辑）上若 `p(ans|q) ≈ p(ans|q')` 而物理参考不同，则 π_lang 高、J 低、降权。捷径比例 π_lang 使语义残差对故障检验功效 ≤ `1−π_lang`；剔除后恢复至 `≥1−τ_J`。系：可验证性筛选是 VQA 计量前提。

**定理 16（三分归因一致性与缓变故障可恢复）** 在 A92、A95 与引理 16–18 下：sensor ⇒ `.r_sem` 平、几何残差升，`P(d=sensor)→1`；model ⇒ `κ↓`、`r_tri↑`，`P(d=model)→1`；world ⇒ 两者同向，`P(d=world)→1`。**关键**：故障频率落入标定带宽（`ω_f<ω_cal`）时语义残差不受带宽限制，`P(检出) ≥ 1−exp(−|E_anchor|·J_min·SNR)`，随锚探针数指数上升——R68 隐匿故障重新可见。任一项误判 ⇒ λ_floor 抬升，归因失败只导保守不导放宽。

**定理 17（内省安全 / 无可信探针即降级）** 若 AQS 无 `J≥τ_J` 或 `IG≥τ_IG` 的问题，则 κ 取先验下界、λ_floor=0.8、J_UBV 不 Valid ⇒ 全局降级。系：**问不出可信问题时不假装知道**，杜绝「自信地无知」。

## 7. 本轮最大风险

**一句话**：UBV-RAS 的全部安全性押在「VQA 是一个可信的外部锚」这一假设上——但 VQA 恰恰最容易被**幻觉与语言先验捷径**污染：若探针被系统性幻觉或对抗图像扰动欺骗（模型自信地回答「一切正常」），反循环锚反而会把错误的外部证据注入标定审计，使系统在「语义与测量一致」的假象下同时失去内部与外部两道防线——用一个可能说谎的证人，去证明另一个可能说谎的证人的清白。

**次级风险与缓解**：语言先验捷径（反事实问题对 + `ν(1−π_lang)` 筛选）；锚覆盖不足（覆盖率硬约束 + 不足即降级）；提问被反向利用/投毒（问题集签名 + 分布外检测 + 预算限幅）；跨本体语义错位（本体 ontology 校准 + 冷启动守门）；κ 分布漂移（滑窗 + 双重校准 + 仅在可验证集上更新）。
