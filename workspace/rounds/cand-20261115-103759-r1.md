# 第 5 轮（灵感循环第 5 轮；本轮灵感：「数据配比」×「谐波减速器」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。第 3 轮 InstructGauge、第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承。
> 本轮纪律：**增量升级 + 严格退化 + 物理接地**。谐波减速器只提供更真实的漂移结构，数据配比只提供更可靠的校准；任一环节不可用都必须退回第 4 轮，物理建模与统计校准是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 漂移不是一个标量，而是一个带记忆的分支状态）**
直觉：谐波减速器以「近零背隙、高减速比」著称，但柔轮在负载下会弹性扭转，齿啮合存在迟滞与失动量（lost motion）。同一个电机侧角度，从正向逼近与从反向逼近，输出端可以差出整个迟滞环宽（约 2ℓ）。这意味着第 4 轮把漂移当成「逐步可加的标量界」在回扫式检测轨迹上会丢掉一个关键量：**分支状态**。误差不一定随步数无界累积，但「同一终点、不同来路」的输出可以差 2ℓ；如果只按终点或按与方向无关的幅度界去认证，证书要么对**单侧间隙约束**不 sound（少算一侧偏移），要么把单侧 ℓ 当成双侧 2ℓ 而过度保守。正确对象是一个**由路径签名（方向反转次数、总行程、载荷符号变化）索引的迟滞状态集**，而不是一个数。

**灵感 2（数据配比 → 校准样本不是取平均，而是做最坏层分配）**
直觉：谐波传动的误差分布是异方差的：额定载荷、常温、低反转率下残差很小；高载荷、温度漂移、频繁换向、齿相位临近啮合边界时残差又重又偏。把校准数据「均匀混一混」会把绝大多数样本花在温和层，恰好把最需要覆盖的换向/高载层饿死。数据配比因此不是调参，而是一个**最坏层覆盖的样本分配问题**：在总预算 N 固定时，选择各操作层（stratum）的混合权重 w，使最大层覆盖缺口最小。更细一点，**拟合物理模型**与**校准证书分位数**对配比的要求不同：前者按残差方差分配（`w^fit ∝ σ²`），后者按分位数处的残差密度分配（`w^cal ∝ 1/f(q)²`）。一个「数据配比」其实至少是两个配比。

**灵感 3（两者耦合 → 会制造层的物理机制，也正好破坏可交换性）**
直觉：迟滞让轨迹成为非马尔可夫的：残差依赖「上一次换向」和「载荷历史」，所以跨层的残差不可交换，全局共形校准的覆盖保证在层内失效。更微妙的是，**分块规划器会反过来改变部署层分布**：为了省漂移预算，规划器会尽量避免换向；一旦部署中换向变少，按部署分布做配比就会进一步饿死换向层，而换向恰好是最危险、最容易在长块里被放大的情形。这是一个内生反馈：配比 → 证书 → 分块策略 → 部署分布 → 配比。安全的做法不是让规划器「用行为证明某层不重要」，而是给每个安全关键层预注册一个覆盖下限，规划器不得把它压到下限以下。

## 1. 研究问题（本轮要回答什么）

- **Q1（物理界是否 sound 且不空）**：能否用一个带记忆的迟滞 / 柔度 / 传动误差模型，给出 K 步块的**有符号**末端位姿漂移区间界，并证明它包含真实漂移、且在无换向路径上比方向无关界更紧、同时在有换向路径上仍然 sound？
- **Q2（配比能否改善最坏层覆盖）**：在固定校准预算 N 下，最优混合权重是什么？它相对均匀配比的改进是否有一个只依赖「层异质比 ρ」的可证分离？拟合配比与校准配比为何不同？
- **Q3（耦合能否被压成可退化）**：当规划器内生地改变部署层分布时，能否用「每层覆盖下限 + 覆盖债务账本 + 强制截断」避免「用部署分布饿死危险层」，并保持对第 4 轮的严格退化？

## 2. 设计原则（雏形，正式化见产物区定义 468–487）

**P4 路径签名完备（Path-Signature Completeness）**
漂移证书的输入必须包含路径签名，而不只是终点：至少含每关节的方向反转次数 `R_i(C)`、总行程 `L_i(C)`、载荷符号变化与分支可达集 `B(C)`。证书是一个**有符号区间值**函数 `D(C,s)`，满足「同一终点、不同来路可以给出不同区间」。这条把「迟滞是记忆」写进类型，而不是当噪声处理；也把第 4 轮只保证幅度、未保证单侧符号的缺口显式化。

**P5 双层最坏层配比（Two-Tier Minimax Mixture）**
校准预算拆成拟合预算与校准预算。拟合配比按最坏层残差方差分配（`w^fit_z ∝ σ_z²`），校准配比按分位数密度分配（`w^cal_z ∝ 1/f_z(q_z)²`）；两者都以「最大层缺口」而非平均误差为目标。任何层不得低于预注册有效样本下限 `n_min`，否则记为**覆盖债务**而不是静默降权。

**P6 内生配比的安全地板（Endogenous-Mixture Safety Floor）**
部署层分布 `P_π(z)` 是分块策略 π 的函数，而 π 又依赖证书。禁止策略通过「少走某层」来降低该层的配比需求：对每个安全关键层设覆盖下限，π 不得使 `P_π(z)` 低于该下限；覆盖债务未清偿时，进入该层的块必须膨胀阈值、在换向处切分，或退化为 K=1。

## 3. 与基线的接口（如何退化）

- 无输出端编码器 / 迟滞模型不可辨识 ⇒ 分支集强制为 `{+,−}`，用数据手册最坏包线膨胀，退化为第 4 轮的保守漂移界；
- 谐波模型完全不可用 ⇒ 直接使用 InstructGauge-WR 的方向无关 `drift_bound`，不新增风险；
- 分层校准不可用 / 某层样本不足 ⇒ 按预注册层级合并层，再回退全局共形阈值，并显式记录覆盖损失；
- 换向处无法切分 / 不可逆动作 ⇒ 强制 K=1，退回第 4 轮不可逆屏障；
- 所有增强失效 ⇒ InstructGauge-WR v4 ⇒ InstructGauge v3 ⇒ ToolGauge ⇒ LeanGauge / MODGAUGE 原样。

## 4. 预期贡献

1. 一个**迟滞分支感知的有符号漂移区间界**：证明单侧 ℓ 与双侧 2ℓ 的分支歧义，给出 reversal-free 与 reversal-heavy 路径的可证不同紧度，并说明幅度界为何不足以保证单侧间隙；
2. 一个**双层最坏层数据配比**：拟合配比 ∝ σ²、校准配比 ∝ 1/f(q)²，并给出相对均匀配比的分离因子 `ρ = max_z A_z / mean_z A_z`；
3. 一个**内生配比安全地板 + 覆盖债务账本**：把「规划器改变部署分布」从隐蔽偏差变成可审计约束；
4. 一条可证伪路径：E473–E488 覆盖台架辨识、区间 soundness、分支歧义、换向切分、层覆盖、拟合/校准分离、sim-to-real 配比、长时漂移与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：最危险的失败不是界算错，而是界「sound 但空」——数据手册最坏包线叠加逐层覆盖下限会把 HDB 推得极保守，使块长塌回 K=1；或者配比在可测层上把覆盖做得很好，而真正的物理失效（磨损、温升、未建模摩擦）恰好落在没有样本的层里，形成「证书剧场」。

## 2. 形式化定义（要点）

**定义 468（谐波关节传动模型）** 对关节 i，输入角 `u_i`、输出角 `y_i`、负载 `τ_i`：
```
y_i(t) = u_i(t)/N_i + δ^tm_i(u_i) + δ^el_i(τ_i) + h_i(t) + η_i(t)
δ^el_i(τ_i) = τ_i / k_i(τ_i)
|δ^tm_i| ≤ a_i,  周期 2π/N_i；可选线性项 ε_i u_i
```
状态 `x_i(t) = (u_i, τ_i, h_i, T_i)`，`T_i` 为温度。`h_i` 是下面 play 算子的偏移量，不是噪声：它由路径决定。

**定义 469（play 迟滞算子）** 给定输入序列 `v_t` 与初值 `h_0 ∈ [−ℓ, ℓ]`：
```
h_{t+1} = clip( h_t + (v_{t+1} - v_t), -ℓ, ℓ )
y_t     = v_t - h_t
```
性质：`|y_t - v_t| = |h_t| ≤ ℓ`；正向与反向逼近同一 `v` 的输出差可达 `2ℓ`（迟滞环宽）。

**定义 470（路径签名）** 对块 `C = (a_1…a_K)` 与关节 i，令 `Δu_t = u_{t+1} - u_t`，`s_t = sign(Δu_t)`（`|Δu_t| ≤ δ_min` 记 0）：
```
R_i(C) = #{ t : s_t ≠ 0 ∧ s_t ≠ s_{t-1} ∧ s_{t-1} ≠ 0 }
L_i(C) = Σ_t |Δu_t|
S_i(C) = 载荷 τ_i 的符号变化次数
B_i(C) = 分支可达集（定义 471）
σ(C)   = (R_i, L_i, S_i, B_i)_{i=1..m}
```
证书必须读取 `σ(C)`，而不能只读终点 `y_K`。

**定义 471（分支可达集与有符号迟滞区间）** 设块起点有最近一次输出侧测量给出分支 `b_0 ∈ {+1,−1}`：
```
B_i(C) = {b_0}                 若 R_i(C) = 0 且 b_0 已知
         {+1, −1}              若 R_i(C) ≥ 1 或 b_0 未知

H_i(C) = [max(-ℓ_i, ℓ_i b_0 - ℓ_i), min(ℓ_i, ℓ_i b_0 + ℓ_i)]  若 |B_i|=1
         [-ℓ_i, ℓ_i]                                            若 |B_i|=2
```
`|B_i|=1` 时区间宽 `ℓ_i`（单侧），`|B_i|=2` 时区间宽 `2ℓ_i`（双侧）。反转次数本身不会让误差无界增长，但它使**分支不可分辨**，从而把单侧区间扩成双侧区间。

**定义 472（柔度 / 传动误差区间）**
```
base_i(C) = a_i + ε_i L_i(C) + max(|τ_i^-|, |τ_i^+|) / k_i^-
Δ_i(C)    = H_i(C) ⊕ [-base_i, +base_i]        （Minkowski 和）
```
若有力矩传感器，用实测 `[τ_i^-, τ_i^+]` 收紧；若无输出端编码器，`B_i` 强制双侧。

**定义 473（末端有符号漂移区间盒）** 设关节误差盒 `∏_i Δ_i(C)`，`J_i(Θ)` 为几何雅可比，`J_{ki}^±` 为关节可达盒上的区间界：
```
D_k(C) = Σ_i [ min(J_{ki}^- l_i, J_{ki}^- u_i, J_{ki}^+ l_i, J_{ki}^+ u_i),
               max(J_{ki}^- l_i, J_{ki}^- u_i, J_{ki}^+ l_i, J_{ki}^+ u_i) ]
D(C)   = (D_1(C), …, D_6(C))
```
`D(C)` 是区间盒，不是标量；单侧约束需要 `D^+`，双侧约束需要 `max(|D^-|, |D^+|)`。

**定义 474（任务方向裕度与 HDB）** 对每个任务方向 `n ∈ N_task`，约束写作 `n·p ≤ c_n`（单侧）或 `|n·p| ≤ c_n`（双侧）：
```
margin_n(C) = c_n - n·D^+(C)                       （单侧）
margin_n(C) = c_n - max(|n·D^-(C)|, |n·D^+(C)|)    （双侧）
HDB(C,s)    = max_n ( -margin_n(C) )_+ + D_odom(s) + D_model
```
`D_odom` 为基座/里程计不确定度，`D_model` 为 v4 的非谐波残差界。`HDB ≤ ε_drift` 且所有 `margin_n ≥ 0` 才可采纳。关键：`HDB` 是**有符号盒**的导出量，不能用 `‖δ‖≤ℓ` 的幅度界替代单侧裕度。

**定义 475（反向感知分块与 K_max）**
```
K_max(s) = max{ j ≤ K : HDB(C_{1:j}, s) ≤ ε_drift ∧ margin_n(C_{1:j}) ≥ 0, ∀n }
Admissible(C,s) ⇔ HDB(C,s) ≤ ε_drift
                  ∧ (C 跨不可逆动作 ⇒ |C| = 1 且独立回执交叉验证)
Split(C) = 在换向点与「最后一个安全前缀」处切分
```

**定义 476（漂移证书对象）**
```
Cert_drift(C) = ( D(C), HDB(C,s), σ(C), B(C), Δ_i(C),
                  model_id, calib_version, coverage_state )
```
作为 `CVC_Spec.spatial_certs` 的同级字段序列化；无此证书则退回 v4 的 `drift_bound`。

**定义 477（操作层 stratum）**
```
z = ( b_τ, b_T, b_R, b_θ, b_v, b_w ) ∈ Z
```
分别为载荷桶、温度桶、换向率桶、齿相位桶（`θ mod 2π/N`）、速度桶、磨损/累计行程桶。层是「残差近似可交换」的最粗划分；层内可交换，层间不假设可交换。

**定义 478（混合权重与有效样本）** `w ∈ Δ^{|Z|}`，总校准预算 `N`：
```
n_z(w)   = N · w_z                         （重采样口径）
ESS_z(w) = (Σ_{i∈z} ω_i)² / Σ_{i∈z} ω_i²   （加权口径）
```
要求 `ESS_z(w) ≥ n_min`，否则进入覆盖债务。

**定义 479（分层共形分位数）** 归一化分数 `s_i = r_i / HDB_i`，`r_i` 为实测残差：
```
q_z^w = { s_i : i ∈ z } 的第 ⌈(n_z + 1)(1 − α)⌉ 个次序统计量
```
归一化使不同块的尺度可比；`HDB_i` 来自 IP-335。

**定义 480（最坏层覆盖缺口）**
```
Gap(w) = max_{z ∈ Z} | (1/n_z) Σ_{i∈z} 1[ s_i > q_z^w ] − α |
```
覆盖债务 `d_z = max(0, n_min − ESS_z) + β·1[Gap_z > α_tol]`；`Gap` 是层内经验缺口，`d_z` 是「是否允许在该层发证书」的账本量。

**定义 481（双层最坏层配比规划）**
```
Fit:  min_w max_z σ_z² / (w_z N_fit)                    ⇒ w^fit_z ∝ σ_z²
Cal:  min_w max_z A_z / (w_z N_cal),  A_z = α(1−α)/f_z(q_z)²
                                                       ⇒ w^cal_z ∝ A_z
s.t.  Σ_z w_z = 1,  w_z ≥ w_min,  N_fit + N_cal = N
```
若加入校准-部署漂移 `D_z(w)`（TV/MMD），目标改为 `max_z [A_z/(w_z N) + λ D_z(w)]`。拟合按**最坏层方差**、校准按**最坏层分位数方差**，所以两者一般不是同一个配比。

**定义 482（水填充与对偶）** 忽略漂移项、`w_min=0` 时，min-max 的 KKT 条件给出
```
w_z* = A_z / Σ_{z'} A_{z'},        t* = Σ_z A_z / N
μ   = 1/t* = N / Σ_z A_z            （一个样本在「最坏层」的影子价格）
```
带 `w_min` 时用投影水填充：`w_z = max(w_min, A_z/λ)`，对 `λ` 二分使 `Σw=1`。`μ_z` 的解释：把样本从层 z 移走一份，最坏缺口上升多少。

**定义 483（覆盖债务与安全地板）**
```
debt_z = 1[ ESS_z < n_min ] ∨ 1[ Gap_z > α_tol ] ∨ 1[ D_z > δ_z ]
```
`debt_z = 1` 时，进入层 z 的块必须至少做其一：(i) 用膨胀因子 `κ_z` 放大 `HDB`；(ii) 在换向处切分；(iii) 强制 K=1；(iv) 回退全局阈值并记录覆盖损失。禁止静默使用该层分位数。

**定义 484（混合条件覆盖保证）** 若 `∀z: ESS_z ≥ n_min` 且 `D_z ≤ δ_z`，则以概率 `≥ 1−β`：
```
Gap(w) ≤ α_tol + sqrt( log(2|Z|/β) / (2 n_min) ) + max_z δ_z
```
证明用 DKW 不等式 + 层间并集界 + 漂移三角不等式。若条件不成立，必须走定义 483 的退化路径。

**定义 485（内生配比不动点）** 设 `π(w)` 为使用 `w` 所生成证书的分块策略，`P_{π(w)}(z)` 为部署层分布：
```
w* = F(w*),  F(w) = argmin_{w'} max_z A_z/(w'_z N)
             s.t. Σ w' = 1,  w'_z ≥ w_min,  P_{π(w)}(z) ≥ p_min(z)
```
`p_min(z)` 是安全关键层的部署覆盖下限。可行域非空要求 `Σ_z p_min(z) ≤ 1`。这条把「规划器避开某层 ⇒ 该层无需校准」的循环论证堵死：即使部署中很少进入某层，只要它仍是安全关键层，`p_min` 就不允许把它压没。

**定义 486（退化映射）**

| 缺失/失效 | 退化动作 | 等价基线 |
|---|---|---|
| 输出端编码器 | `B_i = {+,−}`，只用模型界并膨胀 | v4 保守漂移界 |
| 迟滞模型不可辨识 | 用数据手册 `ℓ_max, a_max, k_min` 包线 | v4 + 包线 |
| 分层校准样本不足 | 按预注册层级合并 → 全局共形 | v3 全局共形 |
| 换向切分失败 | 强制 K=1 | v4 逐步执行 |
| 不可逆动作 | K=1 + 独立回执交叉验证 | v4 不可逆屏障 |
| 所有增强失效 | InstructGauge-WR v4 → v3 → ToolGauge | 原样 |

**定义 487（证书-配比绑定）** 每份 `Cert_drift` 必须记录其分位数所用的 `(w^cal, q_z^w, calib_version)`。证书不能脱离配比被引用；配比刷新后，旧证书标记为 `stale`，相关块需重认证或按定义 483 退化。

# IP-334 HD-TEM：迟滞 + 柔度 + 传动误差
class HarmonicDriveModel:
    def __init__(self, ratios, ell, k_min, a, eps_ratio):
        self.N = ratios          # 每个关节的减速比
        self.ell = ell           # 失动量半宽
        self.k_min = k_min
        self.a = a
        self.eps = eps_ratio

    def play(self, i, h, v_prev, v):
        # h 是输出相对输入的滞后偏移，限制在 [-ell_i, ell_i]
        return float(np.clip(h + (v - v_prev), -self.ell[i], self.ell[i]))

    def branch_interval(self, i, b0, had_reversal):
        # 返回 (lo, hi)；单侧宽度 ell_i，双侧宽度 2*ell_i
        if b0 is None or had_reversal:
            return (-self.ell[i], self.ell[i])
        return (0.0, self.ell[i]) if b0 > 0 else (-self.ell[i], 0.0)

    def joint_interval(self, i, tau_lo, tau_hi, L, b0, R):
        lo_h, hi_h = self.branch_interval(i, b0, R >= 1)
        base = self.a[i] + self.eps[i] * L + max(abs(tau_lo), abs(tau_hi)) / self.k_min[i]
        return (lo_h - base, hi_h + base)

# IP-335 HDB：区间传播 + 有符号任务裕度
def hdb_certificate(C, state, model, jac_interval, N_task, eps_drift):
    joint_boxes = []
    for i in range(model.n_joints):
        tau_lo, tau_hi = state.torque_box[i]
        joint_boxes.append(model.joint_interval(
            i, tau_lo, tau_hi, C.travel[i], state.branch[i], C.reversals[i]))
    D = propagate_interval_jacobian(jac_interval(state.q), joint_boxes)
    margins = {}
    for n, c in N_task:
        lo, hi = dot_interval(n, D)
        margins[n] = c - max(abs(lo), abs(hi)) if c.two_sided else c - hi
    hdb = max([-m for m in margins.values()] + [0.0]) + state.odom + state.model_residual
    return CertDrift(D=D, HDB=hdb, margins=margins, signature=C.signature,
                     model_id=model.id, calib_version=state.calib_version)

# IP-336 DMC：双层最坏层配比 + 分层共形
class MixtureCalibrator:
    def __init__(self, z_buckets, alpha=0.1, n_min=200, w_min=0.01):
        self.z_buckets = z_buckets
        self.alpha = alpha
        self.n_min = n_min
        self.w_min = w_min

    def water_fill(self, A, w_min):
        # w_z = max(w_min, A_z / lam)，二分 lam 使 sum(w)=1
        lo, hi = 1e-12, max(A.values()) if A else 1.0
        for _ in range(80):
            lam = 0.5 * (lo + hi)
            w = {z: max(w_min, A[z] / lam) for z in A}
            s = sum(w.values())
            if s > 1.0:
                lo = lam
            else:
                hi = lam
        w = {z: max(w_min, A[z] / hi) for z in A}
        s = sum(w.values())
        return {z: w[z] / s for z in w}

    def fit_weights(self, sigma):
        # 最坏层 MSE：w ∝ sigma^2
        return self.water_fill({z: sigma[z] ** 2 for z in sigma}, self.w_min)

    def cal_weights(self, residuals):
        # 最坏层分位数方差：w ∝ alpha(1-alpha)/f(q)^2
        A = {}
        for z, rs in residuals.items():
            f = kde_at_quantile(rs, 1.0 - self.alpha)
            A[z] = self.alpha * (1.0 - self.alpha) / max(f, 1e-9) ** 2
        return self.water_fill(A, self.w_min)

    def quantiles(self, scores, w):
        q, debt = {}, {}
        for z, ss in scores.items():
            ess = effective_sample_size(ss, w[z])
            if ess < self.n_min:
                q[z], debt[z] = None, True
            else:
                q[z] = order_statistic(ss, 1.0 - self.alpha)
                debt[z] = False
        return q, debt

# IP-337 RAC：反向切分 + K_max
def reversal_aware_plan(M, iota, H, s):
    C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.hdb, M.dmc)
    cuts = [0] + reversal_indices(C) + [len(C)]
    segments = [C[a:b] for a, b in zip(cuts[:-1], cuts[1:]) if b > a]
    out = []
    for seg in segments:
        if not M.hdb.admissible(seg, s) or M.dmc.has_debt(seg, s):
            return M.iac.plan_chunk(iota, H, M.tools, 1, M.hdb, M.dmc)  # K=1
        k = M.hdb.k_max(seg, s)
        out.append(seg.truncate(k) if k < len(seg) else seg)
    return concat(out)

# IP-338 HG-7C：主闭环（仅改动 C/E 两处）
def harmonicgauge_round(M, s, ell=None):
    iota = M.nlib.ground(ell, M.scene, M.ontology) if ell else M.default_iota
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    C = M.rac.plan(iota, H, M.tools, M.budget_left(s), M.hdb, M.dmc)

    certs = []
    for seg in M.rac.segments(C):
        cert = M.hdb.certificate(seg, M.env.state(), M.hdm,
                                 M.jac_interval, M.N_task, M.epsilon_drift)
        if cert.HDB > M.epsilon_drift or M.dmc.has_debt(seg, M.env.state()):
            seg = M.rac.split_or_single(seg)
        for t, action in enumerate(seg.actions):
            if not M.cvc.joint_pre(action) or not still_grounded(iota, M.env):
                break
            if M.irreversible(action):
                M.env.apply_verified(action)      # K=1 + 独立回执
            else:
                M.env.apply(action)
            if t % M.hdb.check_every == 0:
                M.ros_cvc.verify_tf_consistency(M.wristcam.get_latest_tf(), seg.psi_post)
        certs.append(cert)
        M.dmc.record(seg, cert)

    M.ros_cvc.publish_cvc(C.id, len(C.actions), C.actions, C.pre_conditions,
                          C.post_conditions, certs)
    M.ros_cvc.broadcast_block_tf(C.id, C.final_state)
    return C, certs, bind_claims(C, iota, M.tcv.get_receipts())

## 4. 推导

**引理 63（play 界与分支歧义）** 对任意输入路径，`|h_t| ≤ ℓ` 且 `|y_t − v_t| ≤ ℓ`；但存在两条**输入端点相同**的路径，其输出端点相差恰好 `2ℓ`：一条始终从正向逼近，另一条在末端从反向逼近。于是：(i) 幅度界 `‖δ‖ ≤ ℓ` 对双侧范数 sound，但对单侧约束 `n·δ ≤ c` **不 sound**，因为可行误差集可能整体偏到 `+ℓ` 一侧；(ii) 反转-free 且分支已知的块，迟滞区间半宽为 `ℓ`，反转后分支不可分辨，区间扩为 `2ℓ`。证明：由定义 469，`h` 的更新是斜率为 1 的饱和积分器；构造 `v` 单调升到 `v*` 与先升后降到 `v*` 两条路径，前者 `h=ℓ`，后者 `h=−ℓ`，输出差 `2ℓ`。单侧反例取 `c=0`、`n` 与误差同向即可。

**引理 64（有符号区间 soundness）** 若 `Δ_i(C)` 包含所有与观测一致的关节误差，且 `J_{ki}^±` 包含关节可达盒上的真实雅可比，则真实末端误差 `p_actual − p̂ ∈ D(C)`；从而 `HDB(C) > ε_drift ⇒ 真实漂移可能超限`，且 `margin_n ≥ 0 ⇒` 单侧约束在所有一致误差下成立。证明：区间算术的包含单调性 + 雅可比中值定理；对每个分量用区间乘法的端点组合取 min/max。

**引理 65（路径依赖与单调性）** `D(C)` 关于每个 `Δ_i` 的端点单调；`Δ_i` 关于 `base_i`（即 `L_i, |τ|, a_i`）单调；关于 `R_i`，当 `R_i=0` 时半宽 `ℓ_i`，当 `R_i ≥ 1` 时半宽 `2ℓ_i` 后饱和。因此：同一终点、不同 `R` 的两个块可以有不同 `D`；反转-free 块的可证单侧裕度严格优于反转块（差 `ℓ_i` 项）。证明：逐项比较定义 471–473。

**引理 66（最坏层配比的水填充解）** 对 `min_w max_z A_z/(w_z N) s.t. Σw=1, w≥0`，最优解 `w_z* = A_z/ΣA`，最优值 `t* = ΣA/N`。若 `A_z=σ_z²`，得 `w^fit ∝ σ_z²`；若 `A_z=α(1−α)/f_z(q_z)²`，得 `w^cal ∝ 1/f_z(q_z)²`。证明：令 `t = max_z A_z/(w_z N)`，约束 `w_z ≥ A_z/(tN)`；`Σw=1` 给出 `t ≥ ΣA/N`，取等即得；KKT 影子价格 `μ=N/ΣA`。

**引理 67（均匀配比的次优比恰为 ρ）** 令 `ρ = max_z A_z / mean_z A_z`。均匀 `w_z=1/|Z|` 的值为 `|Z| max_z A_z / N = ρ · (ΣA/N) = ρ · t*`。所以当且仅当各层 `A_z` 相等（`ρ=1`）时均匀配比最坏层最优；否则均匀配比的最坏缺口正好被 `ρ` 倍放大。证明：代入引理 66 并整理。

**引理 68（拟合配比与校准配比可分离）** 存在一组层使 `w^fit ≠ w^cal` 且两者都不能同时最优：拟合关心 `σ_z²`，校准关心 `1/f_z(q_z)²`；若某层方差大但分位数处密度也大，它的 `w^fit` 高而 `w^cal` 低；反之亦然。因此「一个数据配比」不足以同时最小化物理模型误差与证书覆盖缺口，必须双账本。证明：构造两层反例，令 `σ_1²=1, σ_2²=4` 而 `f_1(q)=0.1, f_2(q)=1`，则 `w^fit∝(1,4)`、`w^cal∝(100,1)`，排序相反。

**引理 69（严格退化）** 令 `ℓ_i=0, a_i=0, ε_i=0, τ_max=0`，则 `Δ_i(C)={0}`、`D(C)={0}`，HDB 退化为 v4 的 `drift_bound`；令 `Z={Z_all}`，则分层共形退化为全局共形；令输出端编码器每步可用，则 `B_i={b_0}`，退化到单侧半宽 `ℓ`；关闭 DMC，则使用全局阈值。故 v5 的每个组件都可独立关闭并逐字回到 v4。

**引理 70（安全地板与端到端风险分解）** 若 HDB 使用数据手册包线（`ℓ_max, a_max, k_min, τ_max`）且 DMC 使用 `w_min` + 逐层膨胀，则对任意路径 `HDB_v5 ≥ HDB_v4`，且 `q_v5 ≥ q_v4`（同 α、同有限样本修正下）；因此增强件在「地板模式」下不会比 v4 更不安全，只会在良性路径上更紧、在换向路径上更保守。端到端失败概率可分解为：
```
P_fail ≤ P_phys(模型包线被突破) + P_stat(访问层的覆盖缺口) + P_plan(换向签名预测错误)
```
决策代价 `C_dec(K) = c·⌈T/K⌉`。`K*` 取满足 `HDB ≤ ε_drift` 的最大前缀；换向切分后每段分支可分辨，段内区间宽至多 `2ℓ`，段界之和由三角不等式仍是整块的 sound 上界，因此反转增加的是**段数/决策代价**，而不是无界漂移。证明：包线代入 + 定义 480–484 的并集界 + 区间三角不等式。

## 8. 本轮最大风险

**一句话**：HDB 的 soundness 完全依赖「谐波误差落在我们建模的那几个区间里」这一假设，而真实失效往往来自未建模的摩擦爬行、温升导致的预紧变化与长期磨损；一旦这些落在没有样本的层里，数据配比会把覆盖做得「看起来很好」，证书却对真正的物理漂移失明——即「模型闭合但世界没闭合」。
