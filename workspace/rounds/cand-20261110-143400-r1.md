# 第 45 轮（承接第 44 轮 v21；本轮灵感：记忆检索 × ROS） · Memory-Cert × ROS-Cert：把「记忆检索」升为可证伪的迁移证书，把「ROS」升为可认证的因果传输层（四层架构 v10）

> 承接第 44 轮 v21（Pose-Cert × Data-Cert）。v21 自陈最大风险是「分层条件覆盖依赖审计独立性，否则沿自采流形自我确认（Goodhart）」。但它与 v19–v21 整个证书栈共享一个更隐蔽、更底层的未言明假设：**(H5) 证书所依赖的「历史记忆」与「消息传输」是免费且忠实的**。所有 L0 查表、CKB 检索、课程复用、标定半径、共形分位数都默认两件事：(a) 从记忆里取出的历史案例与当前情境**可交换**——不会被感知别名、工况漂移、投毒或过期租约污染；(b) 该记忆与当前证书在 ROS 图上以**因果一致、未丢失、时钟对齐**的方式送达决策节点。现实中两条都不成立：CKB 是相似度检索，最近邻不等于同分布；ROS/DDS 是异步 pub/sub，QoS 可静默丢包、transient-local 主题可回放陈旧证据、tf 可外推、时钟可跳变、节点可重启、rosbag 可重放，安全节点与执行节点甚至可能不在同一 DDS partition。**记忆检索**迫使我们把「取一个历史案例」升级为「签发一张可证伪的迁移证书，取不到就弃答」；**ROS** 迫使我们把「消息送达」升级为「证书信封的因果闭合与 QoS-声音性」。二者耦合出本轮真正的新问题：**记忆检索与消息传输共享同一个「身份/可交换性」失效面——你拿到的到底是『当前情境下仍然成立的那个记忆』，还是『看起来像、但属于另一个工况、另一条时间线、另一版图的一个记忆』？** 更糟的是二者在负载下正相关：网络拥塞既让消息变陈旧，又让检索回退到更旧的记忆。

## 0. 直觉与动机

**灵感 1（记忆检索 → 记忆不是事实，而是带租约的假设）**
直觉：检索系统最危险的输出不是「没找到」，而是「自信地找到了一个相似但不同分布的历史案例」。最近邻在三种情况下会给出 margin 看起来很紧、迁移后却不 sound 的证书：**感知别名**（两个视觉相似但物理不同的场景/物体）、**工况漂移**（标定、负载、光照、地面摩擦变了）、**时间线错位**（rosbag 重放、仿真重置、部署 epoch 不同）。于是每条记忆 m 不只是一个缓存值，而是 (证书 c_m, 护照 π_m, 版本 v_m, epoch e_m, 租约 ℓ_m, 吊销状态 ρ_m)。检索必须同时回答两件事：(i) 迁移风险 s(q,m) 是否被共形覆盖；(ii) 该记忆在动作时刻 t_act 是否仍然有效（未过期、未吊销、epoch 一致、承载它的信封被接受）。取不到「经认证的同情境记忆」时必须**弃答（ABSTAIN）**，退到保守先验，而不是取最近邻硬用。再用一个**情境见证**（可在 q 上独立验证的区分性证据：地标/几何一致性/拓扑签名/任务指纹）把「看起来像」与「确实是」分开。

**灵感 2（ROS → QoS 是藏在配置里的声音性参数）**
直觉：证书在生产者节点算对，不代表消费者节点用对。ROS/DDS 的 RELIABLE/BEST_EFFORT、DURABILITY（transient_local）、HISTORY depth、deadline、liveliness、partition、use_sim_time 这些参数，实际上偷偷决定了「证书会不会到、到了有多旧、是不是同一个 epoch」。best-effort 上的安全证书等于允许静默丢证；transient_local 可能把上一次运行的旧证据当新证据；depth 太小会在抖动时丢掉关键帧；时钟跳变会让新鲜度判据失真；节点重启会让单调计数器归零、被误认为「又年轻了」。所以要把证书装进**签名信封**，带内容哈希、源时间、时钟域、Lamport/向量时钟、QoS 域、run/epoch、单调序号、父证书哈希；消费者只有在「完整性 + epoch 一致 + 因果闭合 + 新鲜度 + 时钟兼容」全过时才接受，否则判为**因果缺口**并 fail-closed。

**灵感 3（耦合 → 双新根联合证书，且禁止边际相乘）**
直觉：v9 只有一根（姿态=真值），v10 再加两根：**记忆根**（可交换性）与**传输根**（忠实送达）。一份「用记忆加速的证书」要算数，必须同时满足：记忆迁移 sound、信封送达 sound、且两者在同一个 t_act 成立。最危险的错误是把两个边际 1−α 相乘冒充联合保证：网络退化时「变慢/丢包」与「检索回退到更旧记忆」正相关，联合尾部比乘积更差。因此引入**二维分层 (ω, ν)**：ω 是可观测性层（沿用定义 44），ν 是传输/负载域（带宽、丢包、节点数、DDS 域、时钟域）；只在联合层上校准 (迁移风险, 陈旧度, 因果缺口)。记忆回路还有自强化：检索日志驱动采集，采集又产生新记忆——若不给探索配额，系统会沿「自己爱检索的流形」收敛（记忆回音室）。

**耦合升级**：MCE（记忆证书引擎）产出带护照/租约/吊销的记忆项与检索证书；RCB（ROS 证书总线）产出签名信封、因果闭合与 QoS-声音性；MCA（记忆-传输一致性审计器）做别名红队、投毒/吊销传播、传输故障注入与回音室检测。四层架构由 v9 的「姿态根 + 数据治理」升级为 v10 的「真值 × 记忆 × 传输」三根 + 数据治理，形成「记忆可取 → 数据可靠 → 传输可信 → 证书可执行」的可审计闭环。

## 1. 形式化定义（增量：定义 50–56）

**定义 50（记忆项、记忆护照与记忆租约）**
记忆项 m = (c_m, π_m, v_m, e_m, ℓ_m, ρ_m)。c_m 为被缓存的历史证书/策略/标定；π_m 扩展定义 47 的数据护照（来源、task、scene、episode 块、传感器配置、标注置信、合成、审计重叠），并新增记忆字段（版本 v_m、部署 epoch e_m、吊销状态 ρ_m、被检索谱系）；ℓ_m = (τ_m, cd_m, λ_m, r_{m,0}) 为记忆租约，记忆有效半径 r_m(t) = r_{m,0} + λ_m(t−τ_m)。记忆在 t 有效当且仅当 ρ_m = active、e_m = e_now、r_m(t) ≤ r_m,max，且承载它的信封已被定义 54 接受。**记忆不是事实，而是带租约的假设**。

**定义 51（检索证书与情境等价）**
查询 q = (P_t, ω, task, scene, sensor_cfg, e_now, t_act)。检索算子返回 m 或 ABSTAIN。定义迁移风险 s(q,m) = 在 q 中使用 c_m 时下游证书的实际违例/误差。设情境度量 d_ctx，**情境等价集** E_δ(q) = {m : d_ctx(q,m) ≤ δ_ω}。**检索证书**：在 q ∈ Supp_Ω（校准支撑内）且 m ∈ E_δ(q) 时，
P(s(q,m) ≤ ε_m | q, ω) ≥ 1 − α_m。
校准集必须来自「同一检索策略在留出场景/块上的 (q,m) 对」，并按 scene/episode 划分以防泄漏。**弃答原则**：q ∉ Supp_Ω、无 m ∈ E_δ(q)、top-k 记忆的 c_m 相互冲突（别名歧义）、见证失败、或迁移风险上界超阈时，必须 ABSTAIN 并退回保守先验；**最近邻本身不构成 sound 证据**。

**定义 52（情境见证与感知别名）**
情境见证 wy(q,m) 是可在 q 上独立验证的区分性证据（地标一致性、几何一致性、拓扑签名、任务指纹、场景图匹配）。别名风险 alias(q) = max_{m′≠m} [sim(q,m)·sim(q,m′)·1{conflict(c_m,c_{m′})}]，在无见证或见证冲突时定义为 1。**别名安全命题**：若 wy(q,m) 通过且 top-k 冲突为零，则「m 与 q 同情境」的假阳性风险由见证假阳性率 β_w 界定；否则检索必须弃答。见证是可证伪的：它专门攻击「相似≠同分布」这一最近邻的默认假设。

**定义 53（记忆跨轮覆盖与回音室）**
记忆同时服务检索，又经检索日志驱动新采集/标定，形成反馈。设检索诱导分布 D_ret 与采集分布 D_acq，**回音室指标** Echo = TV(D_ret, D_acq)，以及未被检索层的覆盖衰减率。**覆盖命题**：若存在预注册探索配额 η（每次采集至少 η 比例来自与检索策略无关的分层抽样），且审计集独立（定义 49），则记忆更新只收缩/保持各层覆盖，不产生系统性回音室塌缩。重复检索同一记忆不构成独立证据：n_eff 需按被检索次数折减；禁止把「被自己重放 N 次」当作 N 条证据。

**定义 54（ROS 证书信封与因果闭合）**
证书信封 E = (cert, ctx, h, τ_src, cd, lc, ν, e, pid, seq, parents)，其中 h = H(cert,ctx)，cd 为时钟域，lc 为 Lamport/向量时钟，ν 为 QoS/传输域，e 为 run/epoch，seq 为单调序号，parents 为父证书哈希集合。消费者接受 E 当且仅当：
(i) **完整性** H(cert,ctx) = h；
(ii) **epoch 一致** e = e_now（重放/重启不得被当作新鲜）；
(iii) **因果闭合** parents 全部已被接受且 happens-before 当前；
(iv) **新鲜度** age = t_act − τ_src ≤ L_max(ν, φ)；
(v) **时钟兼容** τ_src 与消费者同 cd，或存在可证明的 cd 映射；use_sim_time/rosbag 重放必须切 epoch。
**传输声音性命题**：若 E 被接受，则以 ≥ 1−δ_transport 的概率，消费者使用的 cert 等于生产者的 cert，且其因果祖先均已送达；任一条件不满足即判**因果缺口**，下游证书按定义 46 的思路自记忆/传输根级联失效。

**定义 55（QoS-声音性映射）**
为每类安全证书定义最小 QoS 剖面：RELIABLE；DURABILITY 有界（transient_local 必须配 lifespan + epoch 校验，禁止无限期复用旧证据）；HISTORY depth ≥ 最大允许陈旧窗口；deadline/liveliness 监控；DDS partition/domain 归属。**映射命题**：若安全证书走 BEST_EFFORT 且无显式丢包检测，则存在使证书静默丢失的消息序列；故 best-effort 只能承载非安全/可重建证书，或必须配「丢包检测 + 保守回退」。由 depth d 与发布率 f 得最坏陈旧界 L_stale ≤ d/f + 传输时延上界，该界必须进入定义 54(iv)。

**定义 56（记忆-传输双根联合证书）**
不得假设迁移风险与传输陈旧/丢失独立。在二维分层 (ω, ν) 上定义联合分数
s_joint = max( s(q,m)/ε_m, age/L_max, 1{gap} )，
在联合层 (ω,ν) 的留出样本上做共形，给出
P(s_joint ≤ 1 | ω, ν) ≥ 1 − γ。
**联合命题**：只有联合证书成立且三根（姿态/记忆/传输）租约均有效时，动作才可认证；边际证书乘积不构成联合保证，尤其当 ν 与场景难度正相关（难场景数据率/节点数更高、网络更易退化）时，乘积会系统性高估联合覆盖。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-63 MEMORY-CERT-ENGINE（记忆证书引擎 MCE）
1. **记忆项与护照**：存储 c_m/π_m/v_m/e_m/ℓ_m/ρ_m；版本化与吊销；记录检索谱系与被检索次数。
2. **检索证书**：迁移风险共形校准；情境等价集；支撑外检测；不满足即弃答。
3. **别名防护**：情境见证 + top-k 冲突检测；歧义、见证失败即弃答。
4. **记忆租约与回音室控制**：过期/吊销/epoch 不符即失效；预注册探索配额 η；n_eff 按重复检索折减。

### 2.2 IP-64 ROS-CERT-BUS（ROS 证书总线 RCB）
1. **签名信封**：哈希、源时间、时钟域、Lamport/向量时钟、QoS 域、epoch、单调序号、父哈希。
2. **因果闭合**：父证书必须已被接受；缺口即判因果缺口并级联失效。
3. **QoS-声音性映射**：安全证书 QoS 剖面；丢包/陈旧/partition/liveliness 检测。
4. **时钟/重放/重启防护**：use_sim_time 与 rosbag 重放强制换 epoch；节点重启单调序号归零检测；tf/frame epoch 与 transform 护照。

### 2.3 IP-65 MEMORY-CONSISTENCY-AUDITOR（记忆-传输一致性审计器 MCA）
1. **别名红队**：对抗式构造视觉相似但物理不同的查询，检验弃答与情境见证。
2. **投毒/吊销传播**：注入错误/合成/过期记忆，验证吊销级联与隔离。
3. **传输故障注入**：丢包/重排/重复/延迟/陈旧/partition/时钟跳变/重放/重启。
4. **联合覆盖与回音室回归**：(ω,ν) 联合覆盖红队；检索反馈导致的层覆盖衰减与 Goodhart 检测。

## 3. 四层架构 v10

```
根信任层（v10 三根）:
  真值根: IP-60 PSE → ω_t 可观测性分层 → P_t 姿态证书 + ℓ_p 根租约
  记忆根(新): IP-63 MCE → 检索证书 / ABSTAIN + 记忆护照/租约/吊销
  传输根(新): IP-64 RCB → 签名信封 + 因果闭合 + QoS-声音性 + epoch/时钟
     └─ 任一根失效/缺口 → fail-closed（级联失效，禁止局部降级续用）

L1: 几何图元/物体 6D 位姿（以 P_t 为条件）→ C_ms, B_t, L_m；人/多用户 → H_u
     └─ 所有结论携带 parent hash 与记忆/信封 provenance
L2: IP-55 CKB 只返回带检索证书的记忆，否则弃答 → CTC + VLM + IP-35 仲裁 → 分支池
L3: IP-51 CAR(margin = min(查表, 租约衰减, persona 上限) − L_φ·rad(P_t) − 记忆/传输保守项)
    → IP-49 几何 □ 提升 → IP-47 因果组合 → IP-39 规划
    → IP-45 总线(信封/epoch/clock-domain/revocation) → IP-53 CMC 区间监控
L4: IP-61 DCL(探索配额 + 覆盖驱动采集 + 护照 + 分块加权共形)
    ← IP-62 CCA(覆盖红队 + 选择偏差 + 投毒 + 回归)
    ← IP-65 MCA(别名红队 + 吊销传播 + 传输故障注入 + 回音室)
    → 重校准/吊销 → IP-55 CKB(护照/谱系) + IP-54 SCV(ROS 故障与别名仿真)
    → IP-44 蒸馏 + IP-50 课程 → RCA 重颁 → 证书热更新
运行期: 姿态根 → 记忆根 → 传输根 → 谓词提升 → 守卫；任一缺口/弃答/过期 → 安全停机
        独立审计通过 → 提交新半径/新记忆；否则回滚
```

## 5. 本轮最大风险

**一句话**：记忆检索与 ROS 传输都是证书栈**控制不到的外部系统**，而它们的失效在真实负载下正相关（拥塞既让消息陈旧/丢失、又让检索回退到更旧记忆；感知别名既让最近邻自信又让见证与传输同时被绕过）——一旦把「检索」当纯性能优化、把「QoS」当纯工程配置，系统就会用一张**看似新鲜、实则属于另一工况/另一条时间线**的记忆去签一份数学上干净、语义上错误的证书（认证幻觉），因此 E103（检索证书/弃答）、E104（别名/吊销）与 E105/E106（因果闭合/QoS-声音性）必须设为红线，默认回退到「弃答即保守先验 + 同步点对点 + 安全停机」这条永不高估的底线。

### IP-63 MCE：记忆项、检索证书、别名防护与租约
```
def make_memory(cert, passport, epoch, tau, lam, r0, version):
    return Memory(c_m=cert, pi_m=passport, v_m=version, e_m=epoch,
                  lease=MemLease(tau=tau, cd=clock.domain,
                                 lam=lam, r0=r0), revoked=False,
                  retrieval_count=0)

def mem_valid(m, t_act, epoch_now):
    if m.revoked or m.e_m != epoch_now:
        return False
    return m.lease.r0 + m.lease.lam*(t_act - m.lease.tau) <= m.r_max

def context_witness(q, m):
    # 可证伪的区分性证据：把「看起来像」与「确实是」分开
    return (landmark_consistent(q, m)
            and geometric_consistency(q, m)
            and topology_match(q, m)
            and task_signature(q) == m.task_sig)

def conflicts(topk):
    # top-k 记忆的证书字段相互矛盾 => 感知别名歧义
    return any(disagree(a.c_m, b.c_m) for a, b in pairwise(topk))

def retrieval_certificate(q, index, alpha_m, eps_m, t_act):
    if not in_support(q, index.support):          # 支撑外：禁止最近邻硬补
        return ABSTAIN('out_of_support')
    topk = [m for m in index.search(q, k=K)
            if mem_valid(m, t_act, q.epoch_now)]
    if not topk:
        return ABSTAIN('no_valid_memory')
    if conflicts(topk):                            # 感知别名
        return ABSTAIN('alias_ambiguity')
    m = min(topk, key=lambda m: transfer_risk(q, m))
    if not context_witness(q, m):                  # 见证失败 = 别名风险
        return ABSTAIN('witness_failed')
    if upper_transfer_risk(q, m, alpha_m) > eps_m:
        return ABSTAIN('transfer_risk')
    m.retrieval_count += 1                         # 供 n_eff 折减与回音室审计
    return RetrievalCert(memory=m, eps=eps_m, alpha=alpha_m)

def exploration_quota(acquisition_plan, eta, strata):
    # 至少 eta 比例来自与检索策略无关的分层抽样，防记忆回音室
    quota = pre_registered_strata_sample(strata, n=int(len(acquisition_plan)*eta))
    return merge(acquisition_plan, quota)
```

### IP-64 RCB：签名信封、因果闭合、QoS-声音性与时钟/重放防护
```
def publish_cert(topic, cert, ctx, qos_profile, clock, epoch, parents):
    assert qos_profile.sound_for(cert.criticality)     # QoS-声音性映射
    env = Envelope(cert=cert, ctx=ctx, h=hash(cert, ctx),
                   tau_src=clock.now(), cd=clock.domain,
                   lc=lamport_tick(), nu=qos_profile.regime, e=epoch,
                   pid=node_id, seq=next_monotonic_seq(node_id),
                   parents=parents)
    bus.publish(topic, sign(env))

def accept_env(env, node, t_act, guard, nu):
    if not verify_signature(env) or hash(env.cert, env.ctx) != env.h:
        return CausalGap('integrity')
    if env.e != node.epoch:
        return CausalGap('epoch_mismatch')             # 重放/重启/另一条时间线
    if env.cd != node.clock.domain and not proven_cd_map(env.cd, node.clock.domain):
        return CausalGap('clock_domain')
    if not parents_accepted_and_before(env.parents, node):
        return CausalGap('causal_closure')             # 父证书缺失/被吊销
    if not seq_monotone(env.pid, env.seq, node):
        return CausalGap('seq_rewind')                 # 节点重启后序号回退
    if t_act - env.tau_src > L_max(nu, guard):
        return CausalGap('stale')                      # depth/丢包导致的陈旧
    node.accept(env)
    return OK

def qos_sound_for(criticality, qos):
    if criticality >= K_SAFETY:
        return (qos.reliability == 'RELIABLE'
                and qos.durability in ('VOLATILE', 'TRANSIENT_LOCAL')
                and (qos.durability != 'TRANSIENT_LOCAL'
                     or (qos.lifespan is not None and qos.epoch_checked))
                and qos.depth >= qos.required_depth
                and qos.deadline is not None)
    return True                                        # 非安全证书可放松

def on_drop_or_partition(node, topic):
    node.causal_gap[topic] = True                      # 静默丢证 => 因果缺口
    cascade_invalidate(node.lease_graph, root='transport')
```

### IP-65 MCA：别名红队、吊销传播、传输故障注入与回音室

def alias_redteam(index, generator, budget, alpha_m, eps_m):
    failures = []
    for _ in range(budget):
        q, twin = generator.similar_but_physically_different()
        cert = retrieval_certificate(q, index, alpha_m, eps_m, q.t_act)
        if cert is not ABSTAIN and not same_physics(q, cert.memory):
            failures.append(record_alias(q, cert.memory))   # 自信的错误检索
    return AliasReport(failures=failures)

def revocation_cascade(memory, reason):
    memory.revoked = True
    for child in dependents(memory):                   # 记忆/证书租约依赖图
        revocation_cascade(child, reason='parent_revoked')

def transport_fault_suite(topics, faults, node):
    report = []
    for f in faults:   # drop/reorder/duplicate/delay/stale/partition/clock_jump/replay/restart
        injected = inject(f)
        for env in injected.affected:
            accepted = accept_env(env, node, injected.t, guard, injected.nu)
            report.append((f, env, accepted))
            assert not (accepted is OK and f.violates_soundness(env))
    return report

def echo_chamber_audit(retrieval_log, strata, eta):
    D_ret = empirical_distribution(retrieval_log, key='stratum')
    D_acq = empirical_distribution(acquisition_log, key='stratum')
    decay = {w: coverage_decay(strata[w]) for w in strata}

                      decay=decay, eta_respected=(exploration_ratio >= eta))

回退：E103 覆盖不足 → 按层加保守常数、缩小 δ_ω、扩大弃答域；E104 别名/投毒失败 → 冻结该批记忆、吊销隔离、只认带见证+审计的记忆；E105/E106 传输失败 → 禁用 best-effort 安全路径、缩短深度窗口、提高重发率、退回纯同步/pull；E107 联合失败 → 立刻退回独立界的**保守并集**（1−α_m−δ_transport 而非相乘）并关闭记忆加速；E108 回音室 → 提高探索配额 η、引入检索策略不可见的审计查询；E109/E110 失败 → 熔断回「保守先验姿态盒 + 纯查表 + 同步点对点 + 安全停机」；任何红线失败 → 熔断。

## 6. 本轮最大风险

**一句话**：记忆检索与 ROS 传输都是证书栈**控制不到的外部系统**，而它们的失效在真实负载下正相关（拥塞既让消息陈旧/丢失、又让检索回退到更旧记忆；感知别名既让最近邻自信又让见证与传输同时被绕过）——一旦把「检索」当纯性能优化、把「QoS」当纯工程配置，系统就会用一张**看似新鲜、实则属于另一工况/另一条时间线**的记忆去签一份数学上干净、语义上错误的证书（认证幻觉），因此 E103（检索证书/弃答）、E104（别名/吊销）与 E105/E106（因果闭合/QoS-声音性）必须设为红线，默认回退到「弃答即保守先验 + 同步点对点 + 安全停机」这条永不高估的底线。
