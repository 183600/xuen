# 第 43 轮（新循环第 3 轮） · Cert-Middleware：把证书搬进机器人的神经系统（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差 + 检索幻觉导致的静默失效」。本轮灵感词「中间件」「机器人」补上了此前所有方案共同忽略的一层：**证书一直假设自己运行在单体进程里，而真实机器人是由 ROS 2 / DDS / TSN / AUTOSAR Adaptive 这类中间件粘起来的分布式系统**。证书中那些从未被显式写出的假设——最大端到端延迟、消息不丢、时钟同步、执行器优先级、节点存活、回调不饿死——恰好全部由中间件决定。于是本轮把中间件从「透明管道」提升为**证书的第一类执行体与执行边界**：消息携带证书信封，QoS 被编译成证书契约，节点故障时通过分布式证书片段重组实现「免疫式降级」。机器人不再是一个「跑证书的程序」，而是一个「证书在其中流动、复制、重组、失效」的具身系统。

## 0. 直觉与动机

**灵感 1（中间件 → 证书的「神经系统」与「契约执行体」）**：第 42 轮的 L0 查表、L1 INT8 监控器、LCS 档位都默认「输入在同一进程、同一时钟、同一调度域内」。真实机器人不是这样：相机节点到规划节点要经过序列化、DDS 发现、共享内存/网络、执行器回调，每一跳都可能延迟抖动或丢帧。而证书里 `m_lo`、`T_hold`、`θ` 的推导其实都隐含了一个「最大延迟 d_max、时间同步误差 s_max、最坏调度抖动 j_max」的假设。中间件的直觉是：**不要把这些假设藏在代码注释里，而是把它们变成可编译、可观测、可强制的契约**。每条消息带一个「证书信封」，每个话题/服务声明一份「QoS 证书契约」，中间件运行时逐跳验证；契约一破，下游证书立即失效，而不是继续「自信地安全」。

**灵感 2（机器人 → 从单体证书到「具身分布式免疫」）**：一台机器人不是一台计算机，而是一个由感知、规划、控制、安全 MCU 组成的**分布式生命体**。免疫系统的启发是：抗体不集中在中央，而是由无数细胞各自携带局部识别片段，通过淋巴/血液（中间件）交换、拼接、放大；某个细胞死亡，整体仍能靠幸存片段维持防御。对应到证书：每个节点持有局部证书片段 `F_i`（局部有效域、局部边际、版本、依赖），中间件做「证书 gossip」，全局证书 = 片段的保守合并。单节点崩溃时不是立刻 SafeStop，而是用幸存片段重组出更小但非空的有效域，**把「二进制安全」升级为「可伸缩的连续降级」**——这正面对冲第 41/42 轮反复出现的可用性崩塌风险。

**灵感 3（中间件 → Δ_comm 的真实故障台，弥合第 42 轮的 Sim-to-Real 缺口）**：第 42 轮的 `D_sim` 里有一个 `Δ_comm`（延迟/抖动/丢包），但它是 Isaac Sim 里「假装」的通信扰动。真实的 `Δ_comm` 恰恰就在中间件里：DDS 的 BEST_EFFORT、网络分区、PTP 时钟漂移、节点重启、executor 线程饿死。中间件因此是最便宜、最真实的「通信维度风洞」：用 `tc netem`、QoS 降级、节点 kill、时钟偏移注入，就能直接测出 `Δ_comm` 的真实分布，把第 42 轮 `W_1(D_real, D_sim)` 中最难测的通信维度变成**可回归、可重放的确定性实验**。中间件不再只是被测对象，它同时是测量仪器。

**耦合升级**：`IP-57 CMW` 负责「信封 + 契约 + 逐跳监控」，`IP-58 DCC` 负责「片段 + gossip + 崩溃容忍重组」，`IP-59 MFB` 负责「通信故障注入 + 可重放轨迹」。三者形成一条**运行期真值回路**：即使第 42 轮的仿真偏差与 RAG 幻觉都发生，中间件契约监控仍能在物理执行边界上观测到「延迟超标/丢包/节点死亡」，独立触发证书失效与飞轮更新。证书的信任链从「仿真说它安全」扩展为「仿真说它安全 ∧ 中间件能证明契约被履行」。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（证书信封）**：每条跨节点消息 `m` 附带 `E(m) = ⟨cid, t0, t1, D_cert, m_lo, L_m, A_qos, h_prov⟩`，其中 `cid` 证书标识，`[t0,t1]` 有效时间窗，`D_cert` 证书有效域，`m_lo` 发出时刻的边际下界，`L_m` 该证书的 Lipschitz 常数，`A_qos` 该消息成立所依赖的 QoS 假设，`h_prov` 溯源哈希（指向 CKB 版本）。**消费谓词**：节点在时刻 `t` 收到 `m` 后仅当 `t∈[t0,t1]`、其当前状态 `x_t∈D_cert`、且观测 QoS `q_obs ⊒ A_qos` 时才允许据此行动，否则必须走「无信封/过期信封」保守分支。信封不证明安全，它只**携带安全的适用条件**，把隐式假设显式化到线上。

**定义 39（QoS 证书契约与编译器）**：证书假设 `A = (d*, ρ*, s*, o*, ℓ*, j*)` 分别表示最大端到端延迟、最小可靠性、最大时钟偏斜、保序级别、最小存活声明、最大调度抖动。中间件契约 `CC = (d, r, s, o, l, j)` 是平台实际可提供的保证。**兼容**记作 `CC ⊒ A`，定义为 `d ≤ d* ∧ r ≥ ρ* ∧ s ≤ s* ∧ o ⊒ o* ∧ l ≥ ℓ* ∧ j ≤ j*`。**契约编译器** `μ : (A, platform_caps) → QoS_profile` 把证书假设翻译成 DDS/ROS 2 QoS（RELIABILITY、DEADLINE、LIVELINESS、DURABILITY、HISTORY）与 executor 配置（callback group、优先级、CPU 亲和）。**命题（编译健全性）**：若静态检查 `μ(A) ⊑ platform_caps` 成立，且运行时监控能证明 `q_obs ⊒ μ(A)`，则证书假设 `A` 在运行时成立；若任一侧失败，信封必须被下游拒绝。

**定义 40（端到端证书连续性与传播界）**：对路径 `p = n0 → n1 → … → nk`，令各节点局部证书 `C_i`、边际 `m_i`、逐跳延迟上界 `d_i`、时钟偏斜 `s_i`。定义 `C_p = ∩_i C_i`，`m_p = min_i m_i − L_m·(Σ_i d_i + max_i s_i)`。**定理 1（组合连续性）**：若每个节点局部证书在其自身模型下 sound，且每一跳观测 QoS 满足契约 `CC_i ⊒ A_i`，则 `(C_p, m_p)` 在端到端路径上 sound。证明要点：逐跳扰动经 Lipschitz 常数线性累积，把延迟/偏斜折算为状态空间中的等价扰动球，取交集与最小边际即可；需一个**时序会合假设**——存在公共时间窗使各节点证书同时有效，否则只能退化为「时间分段证书」。

**定义 41（证书片段与分布式免疫）**：节点 `i` 持有片段 `F_i = ⟨C_i, m_i, v_i, deps_i, lease_i, fence_i⟩`（有效域、边际、版本、依赖、租约、栅栏令牌）。中间件维护视图 `V_i(t) = ⊔_{j∈N_i(t)} F_j`，合并算子 `⊔` 定义为：有效域取交、边际取 min、版本取 max、租约取 min。**定理 2（崩溃容忍重组）**：若同时崩溃节点数 `≤ f`，且租约到期后通信最终同步，则每个活跃节点的视图只包含真实存活片段，因而保守合并**不会高估**安全；可用性随存活集合 `|S|` 单调不增（片段越少，有效域越小但非空则继续运行）。`fence_i` 用于施加单调栅栏令牌，阻止分区愈合前的双主「各自激活」。

**定义 42（中间件故障模型与 Δ_comm 实现）**：`M = {drop, delay, jitter, reorder, partition, clock_skew, qos_downgrade, node_restart}`，注入策略 `π_M`。它是第 42 轮 `Δ_comm` 的真实实现。**证书通信鲁棒性** `R_C(π_M) = Pr_{f∼π_M, x∼D}[C(x) 在故障 f 下仍有效]`。关键点：`R_C` 是**可直接测量**的，不依赖仿真保真度，因此可作为第 42 轮 `W_1` 估计的独立校准源。

**定义 43（证书健康度与真值触发）**：`H_t = w1·contract_violation_rate + w2·fragment_age + w3·view_divergence + w4·expired_envelope_rate`。若 `H_t < τ_H` 或出现任一硬违约（deadline miss 累计、fence 冲突、信封哈希失配），触发第 42 轮飞轮：SCV 重跑、CKB 插入故障轨迹、契约版本回滚。`H_t` 是**独立于仿真与 RAG 的运行期真值通道**，专门用于捕捉「仿真说安全、现实已违约」的静默失效。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-45/47/51/52/53/54/55/56）

### 2.1 IP-57 CERT-MIDDLEWARE（CMW，证书中间件）
1. **信封编解码**：在 CDR/fast-CDR 头部增加定长 48–64B 信封，零拷贝 loan 复用；过期/缺省信封映射为「最高保守档」而非直接丢弃。
2. **契约编译器**：`A_cert → QoS_profile`，静态校验平台能力，生成 `contract_bundle`（QoS 配置 + executor 配置 + 监控阈值 + 证书哈希），随 CKB 版本化下发。
3. **逐跳契约监控**：deadline miss、序列号缺口、重排窗口、时钟偏斜（PTP offset）、liveliness 超时，全部折算成 `q_obs` 并与 `A_qos` 比对。
4. **契约热更新与回滚**：`contract_bundle` 原子切换（双缓冲 + 栅栏令牌），违约自动回滚到上一已验证版本；所有切换写审计日志。
5. **保守降级接口**：契约不满足时不直接 crash，而是把下游证书有效域收缩到「无该消息也可安全」的残余域。

### 2.2 IP-58 DISTRIBUTED-CERT-CONSENSUS（DCC，分布式证书免疫）
1. **片段模式**：每节点导出 `F_i`，含有效域、边际、版本、依赖与租约；片段本身带签名，防止「伪造安全片段」。
2. **gossip / anti-entropy**：复用 DDS discovery + 共享内存，周期性与事件驱动双通道；分区期间只做本地保守推进。
3. **崩溃容忍重组**：`f` 故障容忍，视图合并保守（交/取 min），保证永不因「看到别人的乐观片段」而放松自身安全判定。
4. **双主防护**：租约 + 单调栅栏令牌 + 两阶段激活；分区愈合后旧主必须凭更高 fence 才能重新加入，杜绝两个节点各自认为「全局证书有效」。
5. **可用性优先的降级顺序**：先收缩有效域，再降档（T-1/T0），最后才 SafeStop；把第 41/42 轮的「可用性崩塌」变成「连续可伸缩的能力下降」。

### 2.3 IP-59 MW-FAULTBENCH（MFB，中间件故障台）
1. **故障注入面**：`tc netem` 延迟/抖动/丢包/重排、DDS QoS 在线降级、节点 kill/restart、PTP 时钟偏移、CPU 限频制造 executor 饿死。
2. **可重放轨迹**：每次注入记录 `(seed, 网络配置, QoS, 节点拓扑, 时间线)`，可在 Isaac Sim 与实机间 1:1 重放，形成通信维度的对照实验。
3. **通信维度 Sim-to-Real 校准**：直接在中间件上测 `Δ_comm` 的经验分布，替代/校准第 42 轮仿真里的通信扰动，输出 `W_1_comm` 与逐边 `α_e^comm`。
4. **认证回归套件**：把「罕见但致命」的通信故障（分区、时钟跳变、QoS 静默降级）固化成 CI 用例，任何契约改动必须全绿。

## 3. 四层架构 v8

```
L1: 传感器/融合节点(定点 TRI-FUSE) ── 证书信封 ──┐
L2: 感知/VLM/仲裁节点 ── 证书信封 + 环境指纹 ─────┤
L3: IP-57 CMW（DDS/Zenoh/TSN + 信封 + QoS 契约编译器 + 逐跳契约监控）
      ├─ IP-51 CAR（守卫 = 边际 ∧ 信封 ∧ 契约 ∧ 视图）
      ├─ IP-56 ECR（T-2 契约检查 5μs → L0 查表 → L1 INT8）
      ├─ IP-58 DCC（片段 gossip + 崩溃重组 + 租约/栅栏）
      └─ IP-45 总线（= CMW 数据面 + cert_health/fragment_view/fence_epoch）
L4: IP-59 MFB（通信故障注入 + 可重放轨迹 + Δ_comm 实测）
    → 校准 IP-54 SCV 的通信维度 → 故障轨迹入 IP-55 CKB
    → RCA 重颁「证书 + 契约包」→ 契约热更新（双缓冲 + 回滚）
运行期：信封/契约检查(µs) → T-2 快判 → 必要时 L0/L1 → H_t 健康度
        → 契约违约/节点崩溃/分布偏移 → 片段重组或飞轮 → Sim 重跑 → 热更新
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

## 5. 本轮最大风险

**一句话**：中间件契约若只停留在「参数声明」而非「可观测强制」，DDS/executor 会静默降级（`RELIABLE` 实际丢包、`DEADLINE` 参数被忽略、PTP 悄悄跳变），端到端证书就会在「每个节点都自认为契约满足」的分布式错觉中**组合失效**——这比第 42 轮的仿真偏差更隐蔽，因为故障发生在信任链的每一跳之间而非某一点；因此 E88（契约健全性）、E89（连续性）、E91（双主安全）必须作为红线实验，把契约从「配置」变成「可测量事实」，否则整条 CMW 链熔断回退到集中式 SafeStop。

# 第 43 轮产物 · 创新点清单 v20：Cert-Middleware × 分布式证书免疫 × 通信故障台（四层架构 v8）

> 承接第 42 轮产物 v19。本轮**增量插入** IP-57/58/59，并升级 IP-45/47/49/50/51/52/53/54/55/56；不推倒任何既有层级。核心是把 v19 的「单体在线可验证」升级为「**分布式系统里逐跳可验证、可重组、可观测的证书信任链**」：证书不再假设自己独占一个进程，而是活在中件间的信封、契约、片段与故障台之中。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |
|---|---|---|---|
| IP-57 | CERT-MIDDLEWARE (CMW) | 新增 | 证书信封（48–64B）；QoS 契约编译器 `A→QoS`；逐跳契约监控（deadline/丢包/偏斜/liveliness）；契约热更新+回滚 |
| IP-58 | DISTRIBUTED-CERT-CONSENSUS (DCC) | 新增 | 证书片段 `F_i`；gossip/anti-entropy；崩溃容忍保守重组；租约+栅栏令牌防双主；可用性优先降级 |
| IP-59 | MW-FAULTBENCH (MFB) | 新增 | 中间件故障注入（netem/QoS/节点 kill/PTP 偏移/限频）；可重放轨迹；实测 `Δ_comm` 校准 Sim-to-Real |
| IP-45 | 总线 | 升级 | 总线即 CMW 数据面；新增 `cert_health`/`fragment_view`/`fence_epoch` 元话题 |
| IP-47 | 组合代数 | 升级 | 乘积守卫在中间件边上求值；组合前检查跨节点契约兼容与时序会合 |
| IP-49 | 几何证书 | 升级 | 漂移界 `B_t` 增加通信延迟/时钟偏斜贡献项，由 MFB 标定 |
| IP-50 | 课程引擎 | 升级 | 新增「契约压力阶段」：低 QoS/高抖动下的保守行为训练 |
| IP-51 | CAR | 升级 | 守卫 = 边际 ∧ 信封有效 ∧ 契约满足 ∧ 视图非空；新增 ContractViolated/DegradedByCrash 转移 |
| IP-52 | LCS | 升级 | 新增最便宜档 `T-2`（仅信封/契约检查，<5μs）；多数正常拍停在 T-2 |
| IP-53 | CMC | 升级 | 导出 `contract_bundle` + 违约→降级映射；看门狗订阅 CMW 契约事件 |
| IP-54 | SCV | 升级 | `Δ_comm` 改由 MFB 实测校准；新增通信故障压力测试子实验 |
| IP-55 | CKB | 升级 | 索引契约包/故障轨迹；检索键增加中间件拓扑指纹；版本含契约版本 |
| IP-56 | ECR | 升级 | 导出证书片段；先查信封再查表；契约违约时回退到残余有效域 |

## 1. 符号体系（增量：定义 38–43 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| `E(m)=⟨cid,t0,t1,D_cert,m_lo,L_m,A_qos,h_prov⟩` | 证书信封 | 随消息传播的「安全适用条件」；不证明安全，只声明安全何时可用 |
| `A=(d*,ρ*,s*,o*,ℓ*,j*)` | 证书 QoS 假设 | 最大延迟、最小可靠、最大偏斜、保序、存活、最大抖动 |
| `CC⊒A` | 契约兼容 | 平台实际保证不弱于证书假设 |
| `μ:(A,platform_caps)→QoS_profile` | 契约编译器 | 假设→DDS/executor 配置；静态校验+运行时观测双重确认 |
| `C_p=∩_i C_i, m_p=min_i m_i−L_m(Σd_i+max s_i)` | 端到端证书 | 逐跳交集与扰动累积后的保守边际 |
| `F_i=⟨C_i,m_i,v_i,deps_i,lease_i,fence_i⟩` | 证书片段 | 分布式免疫的最小单元，带租约与栅栏 |
| `V_i=⊔_{j∈N_i}F_j` | 证书视图 | 交域、min 边际、max 版本、min 租约的保守合并 |
| `M={drop,delay,jitter,reorder,partition,skew,qos↓,restart}` | 中间件故障模型 | 第 42 轮 `Δ_comm` 的真实实现 |
| `R_C(π_M)=Pr_{f∼π_M,x∼D}[C 有效]` | 通信鲁棒性 | 可直接测量，不依赖仿真保真度 |
| `H_t=w1·viol+w2·age+w3·divergence+w4·expired` | 证书健康度 | 独立于 Sim/RAG 的运行期真值触发通道 |

## 2. 关键算法（伪代码）

### IP-57 CMW：信封、契约编译与逐跳监控
```
def pack_envelope(cert, x, now):
    # cert: RCA 颁发的证书对象；x: 发送时刻状态
    return Envelope(
        cid=cert.id, t0=now, t1=now + cert.T_hold,
        D_cert=cert.valid_domain_bbox,       # 压缩为 bbox/多面体摘要
        m_lo=cert.margin_lower(x),
        L_m=cert.L_m,
        A_qos=cert.qos_assumptions,          # (d*, rho*, s*, o*, l*, j*)
        h_prov=hash(cert.provenance)         # 指向 CKB 版本
    )

def envelope_accepts(env, x, t, q_obs):
    return (env.t0 <= t <= env.t1
            and inside(x, env.D_cert)
            and qos_dominates(q_obs, env.A_qos))

def compile_qos_contract(A, platform_caps):
    # 1) 静态：假设不得强于平台能力
    CC = { 'deadline': A.d_star,
           'reliability': max(A.rho_star, platform_caps.reliability),
           'skew_bound': min(A.s_star, platform_caps.skew),
           'ordering': strongest(A.o_star, platform_caps.ordering),
           'liveliness': max(A.l_star, platform_caps.liveliness),
           'jitter': min(A.j_star, platform_caps.jitter) }
    if not dominates(CC, A): raise ContractUnsat(A)
    # 2) 生成 DDS/executor 配置 + 监控阈值
    return ContractBundle(
        qos=dds_profile(CC),
        executor=ExecutorConfig(deadline=CC.deadline,
                                priority=A.priority,
                                affinity=A.cpus),
        monitors=thresholds_from(CC),
        cert_hash=hash(A.cert)
    )

def contract_monitor(topic_stats, CC):
    violations = []
    if topic_stats.deadline_miss_rate > CC.max_miss: violations.append('deadline')
    if topic_stats.seq_gap_rate > CC.max_gap:       violations.append('drop')
    if topic_stats.reorder_in_window > CC.max_reorder: violations.append('reorder')
    if topic_stats.clock_skew > CC.skew_bound:      violations.append('clock')
    if topic_stats.liveliness_age > CC.liveliness:  violations.append('liveness')
    return violations

def on_contract_violation(violations, downstream_cert):
    # 不 crash：先收缩到「无该消息也可安全」的残余域
    residual = downstream_cert.escape_region(violations)
    if residual.is_empty(): return SAFE_STOP
    return DEGRADE(downstream_cert.with_domain(residual))
```

### IP-58 DCC：片段 gossip、崩溃重组与双主防护
```
def export_fragment(node, cert, epoch):
    return Fragment(
        C=cert.valid_domain, m=cert.margin_lower_bound,
        v=cert.version, deps=cert.dependencies,
        lease=now() + LEASE_TTL, fence=epoch,
        sig=sign(node.key, (cert.version, epoch))
    )

def combine(fragments):
    # 保守合并：交域 / min 边际 / max 版本 / min 租约
    C = intersect_all([f.C for f in fragments])
    m = min([f.m for f in fragments])
    v = max([f.v for f in fragments])
    lease = min([f.lease for f in fragments])
    return View(C=C, m=m, version=v, lease=lease,
                fence=max([f.fence for f in fragments]))

def gossip_round(node, peers, now):
    live = [f for p in peers for f in p.fragments(now) if f.lease > now]
    # 只接受签名有效且依赖满足的片段
    live = [f for f in live if verify(f.sig) and deps_satisfied(f.deps)]
    return combine(live)

def on_node_crash(view, crashed, survivors):
    # 幸存片段重组；若交域为空则按降级顺序收缩
    view2 = gossip_round(self, survivors, now())
    if view2.C.is_empty():
        return try_degrade_order(view2)   # 先收缩域，再 T-2/T-1/T0，最后 SafeStop
    return ACTIVATE(view2)

def acquire_activation(view, lease_service):
    # 两阶段激活：租约 + 单调栅栏令牌，杜绝分区双主
    ticket = lease_service.request(fencing_token=view.fence + 1)
    if not ticket.granted: return HOLD(view)
    commit = lease_service.commit(ticket)
    if not commit.acked:  return HOLD(view)
    return ACTIVE(view.with_fence(commit.fence))
```

### IP-59 MFB：通信故障注入与 Δ_comm 校准
```
def inject_faults(topology, profile):
    # profile ∈ {drop, delay, jitter, reorder, partition, skew, qos_down, restart}
    apply_netem(topology.links, profile.netem)          # 延迟/抖动/丢包/重排
    set_dds_qos(topology.topics, profile.qos)           # 在线 QoS 降级
    set_ptp_offset(topology.clock, profile.skew_ppm)    # 时钟偏斜
    if profile.restart: kill_and_restart(topology.nodes, profile.restart)
    if profile.throttle: set_cpu_quota(topology.nodes, profile.throttle)  # executor 饿死
    return Trace(seed=profile.seed, timeline=profile.timeline)

def measure_delta_comm(traces):
    # 直接从中间件观测分布，替代/校准 Isaac Sim 的 Δ_comm
    feats = [project(t) for t in traces]   # (latency, jitter, gap_rate, skew)
    return empirical_distribution(feats)

def calibrate_sim_to_real_comm(sim_dist, real_dist):
    W1_comm = wasserstein_1d(sim_dist, real_dist)
    alpha_comm = 1.0 + L_m * W1_comm / max(1e-6, theta_sim)
    return min(max(alpha_comm, 1.0), 3.0)   # 逐边修正，夹在 [1,3]
```

### IP-51/52/56 升级：契约感知的自动机与运行时
```
def car_transition_guard_v8(e, x, env, view, q_obs):
    if not envelope_accepts(env, x, now(), q_obs): return False
    if not view.C.contains(x):                     return False
    theta_real = cert.alpha_e[e] * cert.theta_sim[e]
    margin = cert_lookup_L0(x).m_lo[e]             # 仍复用 L0 查表
    return margin >= theta_real

def certify_light_v3(x, guards, env, budget_us=200):
    # T-2: 信封 + 契约快判 (<5μs)，多数正常拍在此返回
    if not envelope_accepts(env, x, now(), q_obs): return SAFE_STOP, -2
    # T-1: L0 查表 (5μs)
    b = cert_lookup_L0(x)
    if not undecided_guards(b, guards): return b, -1
    # T0: L1 INT8 监控器 (100μs)
    if budget_us < 110: return downgrade_monotone(b), -1
    status, margin = monitor_step_INT8(quantize_obs(x))
    b.m_lo = margin
    return (b, 0) if not undecided_guards(b, guards) else (downgrade_monotone(b), 0)

def ecr_step_v8(x, env, view):
    # 契约违约或视图为空 → 不进正常证书路径
    if not envelope_accepts(env, x, now(), q_obs) or view.C.is_empty():
        return ecr_escape_path(x)
    b = cert_lookup_L0(x)
    b.contract_ok = True
    return b
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-57 信封编解码 | O(1) 定长 48–64B | 每消息 +64B | 有效域/时间窗/QoS 三重谓词；缺失即保守降级 |
| IP-57 契约编译 | O(1) 静态检查 | 每 topic 一份 bundle | 命题：`μ(A)⊑caps ∧ q_obs⊒μ(A) ⟹ A` 成立 |
| IP-57 逐跳监控 | O(1) 每跳 | O(#topics) 统计量 | 违约→信封拒绝→下游证书失效，不产生假阳性安全 |
| IP-58 片段合并 | O(f·|deps|) | O(|S|) 视图 | 定理 2：保守交/min 永不高于真实安全，崩溃不导致高估 |
| IP-58 gossip/anti-entropy | O(Δ·|S|) 每轮 | O(|S|) | 租约到期后视图收敛；签名验证防伪造片段 |
| IP-58 双主防护 | O(1) 租约 RPC | O(1) 栅栏令牌 | 单调 fence + 两阶段激活 ⟹ 至多一个激活主 |
| IP-59 故障注入 | O(|links|+|nodes|) 配置 | 轨迹 O(T) | 可重放：同 seed+profile ⟹ 同故障序列 |
| IP-59 Δ_comm 校准 | O(N·feature_dim) | O(N) 经验样本 | 实测分布不依赖仿真；`W_1_comm` 可独立验证 |
| IP-43 健康度 H_t | O(1) 每拍 | O(1) EWMA 状态 | 硬违约即时触发；软指标平滑防抖 |
| IP-51 CAR v8 | O(|E|) 谓词+查表 | 同 L0 | 信封∧契约∧视图∧边际 四重守卫，缺一即拒 |
| IP-52 LCS v3 | 正常拍 T-2 仅 <5μs | 同 L0+L1 | 决策等价：T-2 与全量在契约满足时决策一致 |

## 4. 实验设计（E87–E94，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 信封开销 | 单消息字节数；端到端 p99 增加 | < 64B；< 50μs |
| E88 契约编译器健全性 | 假设→QoS 覆盖率；静默不一致率 | 100%；0 起 |
| E89 端到端连续性 | `M` 全故障集注入后不安全事件；定理 1 预测 vs 实测 | 0 起；偏差 < 10% |
| E90 分布式免疫 | 1–2 节点 kill/restart 恢复时间；Nominal 占比 | < 500ms；≥ 85% |
| E91 双主/分区安全 | 分区愈合后 fence 冲突、双激活次数 | 0 次；视图最终一致 |
| E92 通信 Sim-to-Real | MFB 实测 `Δ_comm` vs 仿真 `W_1` | 实测误差 < 2x 理论界 |
| E93 长时程混合故障 | 100h：不安全事件、可用性、契约违约率 | 0 起；Nominal ≥ 85%；违约 < 1e-4 |
| E94 异构部署 | Orin Nano（DDS）+ STM32H7（精简信封）联调 | 全链路跑通；MCU 侧信封 < 32B |

回退：E87 超预算 → 信封压缩为 16B「证书摘要 + 侧表指针」；E88 契约不可强制 → 关闭契约执行，退回集中式 SafeStop；E89 连续性失效 → 仅静态拓扑启用 CMW，禁运行时换契约；E90/E91 免疫不收敛 → 关闭 DCC，退回单主+租约；E92 通信校准失败 → 通信维度回退最大保守界。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 契约幻觉：QoS 参数被声明但未被真正强制（DDS 静默降级） | 高 | E88/E89 红线；契约必须由「可观测统计量」证明，而非配置文件自证；违约即信封拒绝 |
| 分布式双主：分区期间两节点各自持乐观证书 | 高 | E91 红线；租约 + 单调栅栏令牌 + 两阶段激活；合并只取交，永不取并 |
| 信封/契约开销拖垮实时性 | 中 | 定长信封 + 零拷贝 + T-2 快判；超预算降级为 16B 摘要 |
| 片段合并过保守导致可用性再次崩塌 | 中 | 可用性优先的降级顺序；片段最少保留集 + 能力感知的任务重规划 |
| 时钟偏斜使「公共时间窗」不存在 | 中 | PTP + 偏斜上界入 `B_t`；无会合窗时切时间分段证书 |
| 通信故障台与真实车载网络分布不一致 | 中 | E92 用真实抓包校准 netem 参数；轨迹可重放对照 |
| 节点重启导致旧信封被重放 | 低-中 | `[t0,t1]` 时间窗 + `h_prov` 版本 + 单调 epoch；过期信封强制保守路径 |
| DCC 片段签名密钥管理复杂 | 低 | 硬件安全模块/TPM 托管；密钥轮换与证书版本联动 |

## 6. 本轮最大风险

**一句话**：中间件契约若只停留在「参数声明」而非「可观测强制」，DDS/executor 会静默降级（`RELIABLE` 实际丢包、`DEADLINE` 参数被忽略、PTP 悄悄跳变），端到端证书就会在「每个节点都自认为契约满足」的分布式错觉中**组合失效**——这比第 42 轮的仿真偏差更隐蔽，因为故障发生在信任链的每一跳之间而非某一点；因此 E88（契约健全性）、E89（连续性）、E91（双主安全）必须作为红线实验，把契约从「配置」变成「可测量事实」，否则整条 CMW 链熔断回退到集中式 SafeStop。
