# 第 4 轮（灵感驱动研究循环·新灵感对第 1 轮；本轮灵感：「世界模型」×「手眼标定」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21（IP-425–430；其上承 v20 联邦感知证书 PCA/CTS/CFC/HPC/CFCtrl、v19 证书体系 DCM/OGCC/CCV/DRS/OGC、v17 感知链 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**世界模型是"想象"，手眼标定是"标尺"；想象只能收紧、不能作证，标尺必须可监控、可退化**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 全部保留。本轮只做一件事：**给 v21 的语义-规范证书加上"时空接地"——用世界模型把安全视界从"当前快照"外推到"未来 H 步"，用手眼标定把证书从"假定正确的坐标系"钉到"可验证、可退化、可主动复校的物理标尺"上，并封堵二者互证产生的"自洽幻觉"。**

## 0. 直觉与动机

**灵感 1（世界模型 → 把安全从"现在"外推到"未来"，但想象不得作证）**
直觉：v21 的证书都是"快照证书"——它证明此刻碰撞域、缺席域、规范域，但对 t+Δ 一无所知，只能靠最坏情形保守化（这正是一部分活性损失的来源）。世界模型（latent dynamics + decoder）能"预演"未来：行人往哪走、被遮挡区何时显露、机器人自己的动作会把障碍推向哪里。核心创新：**预测安全包络 (Predictive Safety Envelope, PSE)**——对每个前瞻 h，用 conformal 校准 h 步预测误差分位数 q_h，把预测障碍集膨胀成以 ≥1-δ_h 覆盖真实未来障碍的包络 E_h。关键反直觉点：**世界模型的收益不是"更自由"，而是"更早"**——E_h 只允许把障碍提前并入 Obs（只增不减），于是执行集只缩不涨（安全继承保持），但规划器能提前绕行、避免急停，活性与平滑性来自"更早看见"而非"放宽标准"。同时用**惊讶门 (surprise gate)**：一步预测误差超校准阈值即判定分布外，立刻关闭预测、退回 v21 反应式——模型越不确定，系统越保守。

**灵感 2（手眼标定 → 证书的坐标系本身也需要一张证书）**
直觉：v21 所有证书都隐含假设"传感器量到的位置 = 世界里的位置"。手眼标定 X（相机↔末端/基座）正是这条假设的物理桥；一旦 X 有偏或漂移，CertBox、Cov_t、Hull 会**整体同向错位**——而且同批次、同工装、同标定流程的机器人会**一起错**，这是模态多样性（CFC+）根本抓不到的相关失效轴。核心创新：**手眼计量证书 (Hand-Eye Metrological Certificate, HEMC)**：把 X 视为带协方差 Σ_X 的随机量，把其 (1-δ_cal) 置信椭球**逐点传播**为位置不确定半径 ε_cal(p)，把每个几何证书膨胀成"标定感知证书"；并用运动残差 AX=XB 的在线 CUSUM 做漂移监测，用运动激励/可观测性（Fisher 信息）判定"当前标定是否配被信任"。关键反直觉点：**标定的可信度本身是可观测的**——退化运动（纯平移/单轴旋转/特征稀疏）会让 X 不可辨识，此时残差可能"看起来很小"却毫无意义；因此 HEMC 显式拒绝在不可观测运动下签发信任，信任下降只会让膨胀变大、速度上限变低。

**灵感 3（二者合流 → 接地：想象必须被标尺校验，标尺必须被证据复校）**
直觉：世界模型在错误坐标系里会"自洽地"外推错误未来；手眼标定在退化运动下会"自信地"给出错误标尺。单独看都合理，合起来会互证。核心创新：**标定接地世界模型 (Calibration-Grounded World Model, CGWM)**——世界模型预测的未来特征运动必须能被"当前手眼几何下的刚体运动"解释，接地残差 g_t 过大即判定预测不可信、拒用；反过来，**主动标定验证感知 (Active Calibration-Verified Perception, ACVP)** 在安全关键证书上做一次有界、自身安全的视差探测运动，用三角化位置去校验手眼投影，主动降低 ε_cal。二者构成"想象↔标尺"的交叉校验闭环。并新增 **CFC++**：把仲裁的独立性轴从"模态"扩展到"标定来源 (provenance)"——同批标定的多票不再算独立证据。

**三者如何统一**
统一为 **v21 之上的"时空接地层"**：PSE 回答"未来 H 步哪里可能有障碍（只增）"，HEMC 回答"此刻的坐标系值不值得信、误差多大"，CGWM/ACVP 回答"想象与标尺是否互相印证"。共享状态扩展为 **ζ_stg = ζ_sem ∪ (X̂, Σ_X, τ_cal, z_t, {E_h}, g_t, prov)**。统一准入门：**HPC★ = (HPC+, PSC, HEMC)**——几何安全 ∧ 规范允许 ∧ 负信息可靠 ∧ 未来包络安全 ∧ 坐标系可信；任一缺失向 v21 退化。执行集 **Exec_v22 = Exec_v21 ∩ Fil_pred ∩ Dom_cal ⊆ Exec_v21**，安全继承闭环。

## 1. 研究问题（轮次升级版）

## 2. 设计原则（在 P31–P36 基础上新增 P37–P39）

**P37 生成证据非作证律（Generative Non-Testimony）**
模型生成内容（预测、amodal 补全、想象未来）只能**增补约束**（障碍、限速、膨胀），**永不得**移除约束或签发缺席/自由空间。缺席与自由只能由"直接观测 + 召回下界 κ_c + 可信标尺"赎回。形式化：`Obs_t^{pred} = Obs_t ∪ ⋃_{h=1..H} E_h`，且 `Fil_pred` 只在 `Obs_t^{pred}` 上做保守过滤，不反向释放任何 AbsCert 已不覆盖的区域。

**P38 标尺信任单调律（Frame-Trust Monotonicity）**
所有几何证书按 ε_cal(p) 膨胀：`CertBox^cal = inflate(CertBox, max_corner ε_cal)`；标定信任 τ_cal **只降不升**（唯一例外是 ACVP 的独立三角化证据复校）；τ_cal 下降 ⇒ 膨胀只增、速度上限只降；不可观测运动（λ_min(I_motion) < λ_0）下禁止签发高信任，残差再小也不算数。

**P39 接地一致律（Grounding Consistency）**
进入规划的未来预测必须通过"手眼几何可解释"检验；接地残差 `g_t > g_τ` 即拒用预测并退回 v21 反应式；想象与标尺冲突时，二者同时降权、向保守退化。绝不允许"世界模型与标定互相印证"被当作外部正确性证据。

## 3. 与基线的接口（如何退化）

# IP-431 World-Model Predictive Envelope
class PredictiveSafetyEnvelope:
    def __init__(self, ensemble, horizons, delta=0.01, beta=1.0,
                 gamma=0.01):
        self.models = ensemble          # K 个世界模型（潜在动力学）
        self.H = horizons               # 前瞻步数
        self.delta = delta
        self.beta = beta
        self.gamma = gamma
        self.q = {}                     # 每前瞻 conformal 分位
        self.surprised = False
        self.calm = 0

    def calibrate(self, trajs):
        """逐前瞻非一致性 = Hausdorff(Ô_{t+h}, O_{t+h})；Bonferroni δ_h=δ/H"""
        for h in range(1, self.H + 1):
            scores = [hausdorff(self._predict_mean(tr, h), tr.obs[h])
                      for tr in trajs]
            self.q[h] = quantile(scores, 1.0 - self.delta / self.H)

    def _predict_mean(self, traj, h):
        return mean([m.rollout(traj.z0, traj.actions[:h]) for m in self.models])

    def envelope(self, z_t, actions, grounded=True):
        """P37：只增障碍。失效/惊讶/未接地 ⇒ 全工作空间（更保守）"""
        if self.surprised or not grounded:
            return FULL_WORKSPACE
        preds = [m.rollout(z_t, actions) for m in self.models]
        env = []
        for h in range(1, self.H + 1):
            o_hat = mean([p[h] for p in preds])
            sigma = std([p[h] for p in preds])        # 集成认知不确定度
            env.append(dilate(o_hat, self.q[h] + self.beta * sigma))
        return union(env)                              # 只并，不删

    def observe(self, o_hat_1, o_obs):
        """惊讶门：一步误差超 q_1 ⇒ OOD，关闭预测直到连续 calm 步"""
        e = hausdorff(o_hat_1, o_obs)
        if e > self.q[1]:
            self.surprised, self.calm = True, 0
        else:
            self.calm += 1
            if self.surprised and self.calm >= self.calm_required:
                self.surprised = False
        self._aci_update(covered=(e <= self.q[1]))

    def _aci_update(self, covered):
        """自适应 conformal：维持漂移下的长期覆盖"""
        self.delta = clip(self.delta + self.gamma *
                          (self.delta_target - (0.0 if covered else 1.0)),
                          1e-4, 0.5)


# IP-432 Hand-Eye Metrological Certificate
class HandEyeMetrologicalCertificate:
    def __init__(self, X_hat, Sigma_X, delta_cal=0.01, lambda0=1e-3):
        self.X_hat, self.Sigma_X = X_hat, Sigma_X
        self.chi2 = chi2_isf(delta_cal, df=6)
        self.lambda0 = lambda0
        self.tau_cal = 1.0

    def _J(self, p_cam):
        """SE(3) 左扰动对点位置的雅可比：[I, -[p]_x]（6 维作用于旋转+平移）"""
        return np.hstack([np.eye(3), -skew(p_cam)])

    def epsilon_cal(self, p_cam):
        """标定诱导位置不确定半径（上界）"""
        return np.sqrt(self.chi2) * np.linalg.norm(
            self._J(p_cam) @ sqrtm(self.Sigma_X), 2)

    def inflate(self, certbox):
        """P38：逐角点取最大 ε_cal，膨胀后仍是可靠包围盒（引理 163）"""
        eps = max(self.epsilon_cal(c) for c in corners(certbox))
        return minkowski_sum(certbox, Ball(eps))

    def motion_residual(self, A_i, B_i):
        return log_se3((inv(self.X_hat) @ A_i @ self.X_hat) @ inv(B_i))

    def drift_test(self, residuals, Sigma_r):
        r = np.sum(residuals, axis=0)
        T = r @ inv(len(residuals) * Sigma_r) @ r
        return T, T > chi2_isf(self.alpha_sprt, df=6)

    def observability(self, motions):
        """AX=XB 的 Fisher 信息；退化运动 ⇒ λ_min 低 ⇒ 不可辨识"""
        F = sum(J_i.T @ inv(Sigma_r) @ J_i for J_i in motions.jacobians())
        return np.min(np.linalg.eigvalsh(F))

    def update_trust(self, T, lam, acvp_evidence=None):
        if lam < self.lambda0:
            self.tau_cal = min(self.tau_cal, 0.2)     # 不可观测：拒绝高信任
        elif T > self.thr:
            self.tau_cal = max(self.tau_cal - self.step, 0.0)
        if acvp_evidence is not None and acvp_evidence.consistent:
            self.tau_cal = min(1.0, self.tau_cal + acvp_evidence.gain)
            self.Sigma_X = self._shrink(self.Sigma_X, acvp_evidence)
        return self.tau_cal

    def on_failure(self):
        """标定丢失：全额先验膨胀；无界 ⇒ SafeStop（更保守）"""
        return UnboundedInflationOrSafeStop()


# IP-433 Calibration-Grounded World Model
class CalibrationGroundedWorldModel:
    def __init__(self, hemc, g_tau):
        self.hemc, self.g_tau = hemc, g_tau

    def grounding_residual(self, pred_flow, obs_flow, ego_motion,
                           static_features):
        """预测特征流须等于手眼刚体解释下的投影流"""
        pred = project(self.hemc.X_hat, ego_motion, static_features)
        return huber(pred - obs_flow)

    def accept(self, g_t):
        """P39：未接地 ⇒ 拒用预测，退回 v21 反应式"""
        return g_t <= self.g_tau

    def diagnose(self, g_t, acvp_residual):
        """区分模型错与标定错：ACVP 一致而投影偏 ⇒ 模型错；两者皆偏 ⇒ 标定错"""
        if acvp_residual < self.acvp_tau and g_t > self.g_tau:
            return "MODEL_ERROR"
        if acvp_residual >= self.acvp_tau and g_t > self.g_tau:
            return "CALIBRATION_ERROR"
        return "CONSISTENT"

## 3. 推导

**引理 163（标定感知证书的包含性）** 设真值 X ∈ C_{δ_cal} 以概率 ≥1−δ_cal，且在参考 X̂ 下 CertBox 以 ≥1−δ_det 包含物体。SE(3) 左扰动 ξ~N(0,Σ_X) 经 J(p)=[I, −[p]_×] 线性化给出 `ε_cal(p) ≤ sqrt(χ²₆(1−δ_cal))·‖J(p)Σ_X^{1/2}‖₂`。取 `CertBox^cal = inflate(CertBox, max_corner ε_cal)`，则由联合界，CertBox^cal 在真值 X 下以 ≥1−δ_cal−δ_det 包含物体。∎

**引理 164（漂移与可观测性）** 无漂移时 r_i ~ N(0,Σ_r)，故 T_n ~ χ²₆；T_n 超阈即拒绝"无漂移"假设并令 τ_cal 单调下降。若运动激励 Fisher 信息 I_motion 的 λ_min 低于 λ₀，则 X 不可辨识，HEMC 拒绝签发高信任——此时残差可能因共模误差"同错相消"而偏小，故残差小不构成信任证据。时间偏移 τ_cam 使残差随角速度/线速度近似线性增长，可由变速探测与联合估计辨识。∎

**引理 165（预测包络的覆盖与单调）** 每前瞻 h 用 conformal 分位 q_h 使 P(O_{t+h} ⊆ E_h) ≥ 1−δ_h；取 δ_h=δ/H 得 H 步同时覆盖 ≥1−δ。P37 规定 `Obs_t^{pred}=Obs_t ∪ ⋃E_h` 只增，故 Fil_pred 只在增大的障碍集上过滤，`Exec_v22 ⊆ Exec_v21`。惊讶门关闭预测时 E_h 退化为全工作空间，方向更保守而非更激进。∎

**引理 166（接地一致与错误归因）** 若 g_t ≤ g_τ，预测的未来特征运动可被当前手眼几何的刚体运动解释，接受；否则拒用并退回反应式。归因判据：ACVP 三角化残差小（标尺自洽）而投影残差大 ⇒ MODEL_ERROR；两者皆大 ⇒ CALIBRATION_ERROR。故"想象与标尺互证"不被当作外部正确性证据，只被用作互相证伪。∎

**引理 167（provenance 多样共识）** Quorum★ = `#votes≥N−F ∧ |Mod|≥2 ∧ (|Prov|≥2 ∨ ACVP 验证)`。同批标定共模错误产生的"一致票"因 |Prov|=1 且无独立验证而不满足 Quorum★，落入 CI/保守；单 provenance 系统退化为 CFC+ 行为。provenance 轴与模态轴正交，二者可同时加严而不冲突。∎

**引理 168（v22 整体安全继承）** 同一快照、同一规则库与机器人集合下：PSE 只增障碍（引理 165）、HEMC 只增膨胀且信任单调（引理 163/164）、CGWM 只拒用（引理 166）、ACVP 只提供独立证据或不动、CFC++ 只加严仲裁（引理 167）。故 `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 7. 已知风险与失效模式

1. **自洽的时空幻觉**（最大风险，见第 8 节）：退化运动下 AX=XB 共模误差使残差偏小，世界模型在错误框架内自洽外推。缓解：可观测性判据拒签信任（E803）、provenance 多样（E814）、接地归因（E810）、ACVP 独立三角化（E811/E812）、惊讶门保守化（E806）。
2. **多步 conformal 仅边际覆盖**：H 步误差强相关，Bonferroni 保守、ACI 只保长期。缓解：时间一致 conformal 鞅、逐前瞻校准、集成认知不确定度并入膨胀（E805）。
3. **预测-失效振荡**：惊讶门频繁开关导致规划抖动。缓解：滞回 + calm 计数 + 开关代价建模（E806）。
4. **ACVP 探测本身不安全或超预算**：探测运动可能破坏当前安全证书。缓解：仅在 safe_domain 内、有界预算、形式化覆盖断言（E828）。
5. **标定协方差过时/模型误设**：Σ_X 不反映真实误差分布。缓解：在线 CUSUM 重估、ACVP 收缩、分布外时全额先验膨胀（E802/E817）。
6. **保守性叠加的活性坍缩**：PSE 膨胀 + ε_cal 膨胀 + v21 覆盖保守叠加。缓解：预测只用于"更早绕行"、膨胀按需分级、E819 监控活性。
7. **隐私与算力成本**：世界模型与视觉里程计处理生物特征/图像。缓解：原始图像不出设备、潜在状态/几何/证书外传（E826）、模型蒸馏与 10Hz 事件化（E818）。
