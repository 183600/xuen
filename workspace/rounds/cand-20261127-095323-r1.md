### 第 1 轮灵感驱动研究记录（实时控制 × 模仿学习）

**灵感词**：实时控制、模仿学习

**直觉与动机**：
现有 SRC-USC 证书链（v26，IP-447–450）已把安全、结构、力控、语义、重构、协同、成本、记忆、可扩展性纳入统一准入门，但它默认了一个未被形式化的前提：**证书判定本身可以在控制周期内无条件完成，且证书一经签发就持续有效**。然而真实机器人上，证书验证是带计算预算的实时任务：conformal 校准、Hausdorff 检查、纳什梯度、CBF-QP 都有 WCET；一旦验证超期，系统要么用过期证书放行，要么急停，二者都破坏「事前拦截」承诺。

另一方面，模仿学习（BC / DAgger / Diffusion Policy）提供了比手工规划更自然的技能来源，但它有两个结构性缺陷：(1) 分布外（OOD）观测导致动作外推；(2) 复合误差使闭环轨迹偏离示范支撑集。把学习策略直接接入证书链是危险的，正确姿势应当是：**策略只提出动作提议 a_prop，证书定义可行动作集 A_cert(x)，运行时盾牌把提议投影到 A_cert；投影距离过大则退回已认证的保守控制器**。

受「实时控制」启发，证书应从「布尔谓词」升级为「带 (WCET, 周期, 截止期, 关键度) 的可调度任务」，并支持 anytime 判定与截止期前降级；受「模仿学习」启发，证书应从「计划准入」升级为「动作级运行时过滤」，并显式携带示范支撑、conformal 动作覆盖、CBF 不变性与性能次优界。**核心洞见：实时控制把证书变成有截止期和时效的调度对象，模仿学习把策略变成需要被证书包裹的提议者；二者合流即「带时限的运行时安全盾牌」——证书不再只在计划生成时问一次，而是在每个控制拍上以可证明的时延与风险上界持续作答。**

**形式化目标**：
1. 定义实时证书任务模型 RTCS：每个证书任务 τ_j = (C_j, T_j, D_j, L_j)，其中 C_j 为认证平台上的 WCET、T_j 为周期、D_j 为相对截止期、L_j ∈ {0,1,2} 为关键度；用响应时间分析（RTA）与利用率判定可调度性，并要求安全关键证书不可被 anytime 降级。
2. 定义 anytime 判定：在预算 δ 内返回 (admit, β(δ))，要求风险上界 β(δ) 关于 δ 单调不增；预算不足时先降级低关键度证书并以保守 residual 计入风险，而非静默放行。
3. 定义证书时效证书 TVC：证书在 t_0 签发，携带 TTL 与状态漂移管道 ||x(t)-x(t_0)|| ≤ ρ(t)；仅当 age ≤ TTL 且漂移在管道内时证书有效，越界即失效。
4. 定义模仿策略证书 IPC：示范支撑覆盖 d(o, supp(D)) ≤ ε_support、conformal 动作集覆盖 ℙ(a_true∈C_a(o)) ≥ 1-α_act、CBF 闭环不变性 h(x_{t+1}) ≥ (1-γ)h(x_t)（在认证动作集内对所有动作成立）、以及相对专家的性能次优界 J(π_θ)-J(π_E) ≤ ε_perf。
5. 定义带时限模仿盾牌 CIS：a_safe = Proj_{A_cert(x)}(π_θ(x))，当投影残差 > ε_shield 或剩余时延 < WCET_shield 时退回已认证兜底控制器/上一认证动作。
6. 构造实时-模仿统一准入门 RTIC-UG：Exec_v27 = Exec_v26 ∩ Fil_deadline ∩ Fil_fresh ∩ Fil_imitation ⊆ Exec_v26，并证明在截止期错过、证书过期、策略 OOD 三类退化下单调链保持。

**与 v26 的衔接**：RTCS 为 IP-448 的成本预算增加「时间维度硬截止期」；TVC 为 IP-449 的长期记忆增加「有效期与漂移管道」，避免记忆被无限期信任；IPC/CIS 为 SRC-USC 增加动作级入口，使 USMC/SMC/RMC/MCC 从「计划过滤器」下沉为「每拍动作过滤器」。**证书的消费者从离线规划器变成了实时控制器，这既是能力扩展，也是本轮风险的根源。**

## 1. 关键算法骨架（在 IP-447–450 骨架上扩展）

```python
# ============================================================
# IP-451 Real-Time Certificate Scheduler (RTCS) — 实时证书调度
# ============================================================
@dataclass
class CertificateTask:
    name: str
    wcet: float                 # 认证平台上的最坏执行时间 (ms)
    period: float               # 周期 (ms)
    deadline: float             # 相对截止期 (ms)
    criticality: int            # 0=best-effort, 1=essential, 2=safety-critical
    risk_if_unchecked: float = 0.2   # 未检查时的保守残余风险
    risk_if_pass: float = 0.01       # 通过后的残余风险
    checker: Callable = None

@dataclass
class RealTimeCertificateScheduler:
    tasks: list[CertificateTask]
    epsilon_wcet: float = 1.2         # WCET 安全系数（实测上界 × 1.2）
    beta_max: float = 0.05            # 允许的最大残余风险

    def response_time(self, task: CertificateTask) -> float:
        """固定优先级 RTA 不动点：R = C + Σ ceil(R/T_k)·C_k"""
        R = task.wcet * self.epsilon_wcet
        for _ in range(100):
            interference = sum(
                math.ceil(R / t.period) * t.wcet * self.epsilon_wcet
                for t in self.tasks if t is not task
            )
            R_new = task.wcet * self.epsilon_wcet + interference
            if abs(R_new - R) < 1e-9:
                return R_new
            R = R_new
            if R > task.deadline:
                return R
        return R

    def utilization(self) -> float:
        return sum(t.wcet * self.epsilon_wcet / t.period for t in self.tasks)

    def is_schedulable(self) -> bool:
        if self.utilization() > 1.0:
            return False
        return all(self.response_time(t) <= t.deadline for t in self.tasks)

    def anytime_admit(self, state: dict, budget: float) -> tuple[bool, float]:
        """在预算内按关键度优先执行证书；返回 (admit, β(budget))。
        β 单调不增：检查越多，残余风险越小；未检查任务以 risk_if_unchecked 计入上界。"""
        remaining = budget
        admitted = set()
        beta = 1.0
        # 关键度降序、风险密度降序
        order = sorted(self.tasks, key=lambda t: (-t.criticality, -t.risk_if_unchecked / max(t.wcet, 1e-6)))
        for task in order:
            cost = task.wcet * self.epsilon_wcet
            if cost <= remaining and task.checker is not None:
                if not task.checker(state):
                    return False, 1.0            # 任一关键证书失败即拒绝
                admitted.add(task.name)
                remaining -= cost
                beta = min(beta, task.risk_if_pass)
            else:
                if task.criticality == 2:
                    return False, 1.0            # 安全关键证书不可降级
                beta = max(beta, task.risk_if_unchecked)  # 保守计入风险
        return (beta <= self.beta_max), beta


# ============================================================
# IP-452 Temporal Validity Certificate (TVC) — 证书时效
# ============================================================
@dataclass
class TemporalValidityCertificate:
    t_issue: float
    ttl: float
    x0: Tensor
    drift_rate: float = 0.05          # 认证漂移速率上界 (m/ms 或 rad/ms)
    residual_bound: float = 0.01      # 初始残差
    cert_payload: dict = None         # E_max, gamma_s, B_d eig, alpha_t 等

    def max_drift(self, t: float) -> float:
        return self.residual_bound + self.drift_rate * max(0.0, t - self.t_issue)

    def is_valid(self, t: float, x: Tensor) -> bool:
        if t - self.t_issue > self.ttl:
            return False
        return torch.norm(x - self.x0).item() <= self.max_drift(t)

    def conservative_payload(self, t: float) -> dict:
        """在漂移管道内对证书量做区间膨胀，禁止使用未膨胀的标称值。"""
        rho = self.max_drift(t)
        lip = self.cert_payload.get('lipschitz', 1.0)
        return {k: v + lip * rho for k, v in self.cert_payload.items()
                if isinstance(v, (int, float))}


# ============================================================
# IP-453 Imitation Policy Certificate (IPC) — 模仿策略证书
# ============================================================
@dataclass
class ImitationPolicyCertificate:
    demo_obs: Tensor                  # [N_d, d_o]
    demo_act: Tensor                  # [N_d, d_a]
    policy: Callable                  # π_θ: o -> a
    cbf: Callable = None              # h(x)
    dynamics: Callable = None         # x_{t+1} = f(x) + g(x)a
    action_calibrator: Callable = None
    alpha_act: float = 0.05
    eps_support: float = 0.10
    eps_perf: float = 0.10
    gamma: float = 0.1
    k_nn: int = 8

    def support_distance(self, o: Tensor) -> float:
        d = torch.cdist(o.reshape(1, -1), self.demo_obs)
        return d.min().item()

    def verify_support_coverage(self, o: Tensor) -> bool:
        return self.support_distance(o) <= self.eps_support

    def conformal_action_set(self, o: Tensor) -> Tensor:
        """基于 kNN 非一致性分数的动作预测集（简化：球半径）。"""
        if self.action_calibrator is None:
            return None
        return self.action_calibrator.predict_set(o, alpha=self.alpha_act)

    def verify_action_membership(self, o: Tensor, a: Tensor) -> bool:
        C_a = self.conformal_action_set(o)
        if C_a is None:
            return False
        return self.action_calibrator.contains(C_a, a)

    def verify_cbf_invariance(self, x: Tensor, A_cert: 'ActionSet') -> bool:
        """∀a∈A_cert: h(f(x)+g(x)a) ≥ (1-γ)h(x)。对凸多面体只需检查顶点。"""
        if self.cbf is None or self.dynamics is None:
            return False
        for a in A_cert.vertices():
            x_next = self.dynamics(x, a)
            if self.cbf(x_next) < (1 - self.gamma) * self.cbf(x):
                return False
        return True

    def verify_performance_bound(self, J_pi: float, J_expert: float) -> bool:
        return (J_pi - J_expert) <= self.eps_perf

    def verify_all(self, o: Tensor, x: Tensor, A_cert: 'ActionSet',
                   J_pi: float, J_expert: float) -> bool:
        return (self.verify_support_coverage(o) and
                self.verify_cbf_invariance(x, A_cert) and
                self.verify_performance_bound(J_pi, J_expert))


# ============================================================
# IP-454 Certified Imitation Shield (CIS) — 带时限模仿盾牌
# ============================================================
@dataclass
class CertifiedImitationShield:
    ipc: ImitationPolicyCertificate
    rtc: RealTimeCertificateScheduler
    fallback: Callable                # 已认证保守控制器（如 FCC 阻抗保持）
    wcet_shield: float = 0.2          # 盾牌 WCET (ms)，1kHz 内环下 < 1ms
    eps_shield: float = 0.05
    last_certified_action: Tensor = None

    def _action_set(self, x: Tensor) -> 'ActionSet':
        # 由力矩限幅、关节限位、CBF 线性约束、conformal 动作球共同交成多面体
        return build_certified_action_set(x, self.ipc)

    def step(self, x: Tensor, o: Tensor, t: float,
             deadline_remaining: float) -> tuple[Tensor, dict]:
        # 1) 时间维度：盾牌自身必须先满足截止期
        if deadline_remaining < self.wcet_shield:
            a = self.last_certified_action if self.last_certified_action is not None \
                else self.fallback(x)
            return a, {'degraded': 'deadline_hold', 'certified': self.last_certified_action is not None}

        # 2) 支撑维度：OOD 观测直接退回兜底
        if not self.ipc.verify_support_coverage(o):
            return self.fallback(x), {'degraded': 'ood_fallback'}

        # 3) 动作维度：提议 -> 投影 -> 残差检查
        a_prop = self.ipc.policy(o)
        if not self.ipc.verify_action_membership(o, a_prop):
            return self.fallback(x), {'degraded': 'action_uncovered'}
        A_cert = self._action_set(x)
        if not self.ipc.verify_cbf_invariance(x, A_cert):
            return self.fallback(x), {'degraded': 'cbf_no_invariant'}

        a_safe = project_to_set(a_prop, A_cert)
        if torch.norm(a_safe - a_prop).item() > self.eps_shield:
            return self.fallback(x), {'degraded': 'shield_fallback'}
        self.last_certified_action = a_safe
        return a_safe, {'degraded': None}


# ============================================================
# IP-455 RTIC-UG 实时-模仿统一准入门
# ============================================================
@dataclass
class RealTimeImitationUnifiedGate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    rtc: RealTimeCertificateScheduler
    tvc: TemporalValidityCertificate
    ipc: ImitationPolicyCertificate
    cis: CertifiedImitationShield
    beta_max: float = 0.05

    def admits(self, plan: 'MultiRobotPlan', x: Tensor, o: Tensor,
               t: float, budget: float) -> tuple[bool, dict]:
        # 0) 时效门：过期或漂移越界，一票否决
        if not self.tvc.is_valid(t, x):
            return False, {'reason': 'stale_or_drift', 't': t}

        # 1) 截止期门：不可调度则拒绝进入高频环（可在低频环降级运行）
        if not self.rtc.is_schedulable():
            return False, {'reason': 'unschedulable'}

        # 2) anytime 证书判定：预算内完成，安全关键证书不可降级
        ok, beta = self.rtc.anytime_admit({'x': x, 'o': o}, budget)
        if not ok or beta > self.beta_max:
            return False, {'reason': 'certificate_reject', 'beta': beta}

        # 3) 模仿策略证书：支撑/CBF/性能
        A_cert = self.cis._action_set(x)
        if not self.ipc.verify_all(o, x, A_cert, plan.J_pi, plan.J_expert):
            return False, {'reason': 'imitation_cert_reject'}

        # 4) 复用 v26 的计划级八证（USMC/SMC/RMC/MCC + 成本/记忆/可扩展）
        if not self.src_usc.admits(plan, plan.sensor_data):
            return False, {'reason': 'src_usc_reject'}

        return True, {'beta': beta, 'payload': self.tvc.conservative_payload(t)}


# ============================================================
# 端到端：双频环（外环 100Hz 证书，内环 1kHz 盾牌）
# ============================================================
class RealTimeImitationPipeline:
    def __init__(self, config):
        self.gate = RealTimeImitationUnifiedGate(
            src_usc=config['src_usc'],
            rtc=config['rtc'],
            tvc=config['tvc'],
            ipc=config['ipc'],
            cis=config['cis'],
        )
        self.T_outer = config.get('T_outer', 10.0)   # ms, 100Hz
        self.T_inner = config.get('T_inner', 1.0)    # ms, 1kHz

    def step(self, x, o, t, plan):
        # 外环：每 10ms 做一次完整证书准入
        if abs(t % self.T_outer) < 1e-6 or self.gate.tvc.t_issue is None:
            admitted, info = self.gate.admits(plan, x, o, t, self.T_outer)
            self.last_admit = admitted
            self.last_info = info
        if not getattr(self, 'last_admit', False):
            return self.gate.cis.fallback(x), {'reason': 'gate_reject', **self.last_info}
        # 内环：每 1ms 做一次带截止期的盾牌投影
        return self.gate.cis.step(x, o, t, self.T_inner)


# 辅助：多面体投影（QP）与动作集构造
def project_to_set(a: Tensor, A: 'ActionSet') -> Tensor:
    """min ||u-a||² s.t. H u ≤ h；小规模用 active-set / OSQP，热启动。"""
    return A.project(a)

def build_certified_action_set(x: Tensor, ipc: ImitationPolicyCertificate) -> 'ActionSet':
    """力矩上下界 ∩ 关节限位 ∩ CBF 线性约束 ∩ conformal 动作球 -> 凸多面体。"""
    H, h = [], []
    H.append(torch.eye(len(x))); h.append(x.new_tensor(TAU_MAX))
    H.append(-torch.eye(len(x))); h.append(x.new_tensor(TAU_MAX))
    # CBF: h(f(x)+g(x)a) ≥ (1-γ)h(x) 对仿射动力学可写成线性约束
    H_cbf, h_cbf = linearize_cbf(x, ipc.cbf, ipc.dynamics, ipc.gamma)
    H.append(H_cbf); h.append(h_cbf)
    return ConvexPolytope(torch.cat(H), torch.cat(h))
```

## 2. 复杂度与实时性分析（本轮增量）

| 模块 | 时间复杂度 | 空间复杂度 | 典型 WCET / 周期 | 说明 |
|---|---|---|---|---|
| RTCS 响应时间分析 | O(n² · iter) | O(n) | n≤12, <0.1ms（离线） | 证书集合变化时重算，不必每拍 |
| RTCS anytime 判定 | O(n · check_cost) | O(n) | 外环 10ms 预算内 | 关键度降序，安全关键不可降级 |
| TVC 时效验证 | O(d) | O(d) | <10μs | 一次范数比较 + TTL 比较 |
| TVC 保守区间膨胀 | O(|payload|) | O(|payload|) | <5μs | 标量膨胀，无迭代 |
| IPC 支撑覆盖 | O(N_d · d_o) | O(N_d · d_o) | 1kHz 下用 KD-tree O(d log N_d)，<50μs | N_d≤10⁴ |
| IPC conformal 动作集 | O(k · d_a) | O(k · d_a) | <30μs | k=8~32 近邻 |
| IPC CBF 不变性 | O(V · n) | O(V) | 顶点数 V≤2⁶=64，<100μs | 凸多面体只查顶点 |
| IPC 性能次优验证 | O(T) | O(1) | 离线 | 回放轨迹求 J |
| CIS 投影 QP | O(n³) 最坏 | O(n²) | n=6~7 → <150μs（OSQP 热启动） | 内环 1ms，占 15% |
| CIS 兜底切换 | O(1) | O(1) | <5μs | 查表/阻抗保持 |
| RTIC-UG 单拍准入 | O(n·check + N_d·d_o) | O(n + d) | 外环 P99 < 5ms | 预留 50% 余量 |
| 端到端双频环（增量） | 外环每 10ms + 内环每 1ms | — | 内环 P99 < 300μs | 内环不允许调用外环重活 |

**实时性保证（关键路径）**：外环证书链预算由 IP-448 的 Budget=10ms 扩展到「硬截止期 D=10ms + WCET 安全系数 1.2」，RTA 保证最坏响应时间 ≤ D；内环只保留 TVC 比较 + CIS 投影，WCET_shield=0.2ms，1ms 周期下利用率 0.2，留足抖动余量。**若 RTA 判定外环不可调度，则 RTIC-UG 直接拒绝进入实时模式，而不是带着不可证明的时延运行。**

## 3. 正确性论证（本轮增量）

### 引理 16（anytime 判定的风险单调性与截止期安全）
**陈述**：设任务按关键度降序执行，安全关键任务（L_j=2）永不降级。则对于任意预算 δ₁≤δ₂，有 β(δ₂)≤β(δ₁)；且若 RTCS.is_schedulable()=True，则所有任务在各自截止期内完成，不存在「检查未完成即放行」。

**证明**：
1. 预算增大只会使更多任务从「未检查」转为「通过」，通过任务以 risk_if_pass 替代 risk_if_unchecked；由于 risk_if_pass≤risk_if_unchecked，且 β 取各任务风险的最大值，故 β 关于已检查集合单调不增，从而关于 δ 单调不增。
2. 若 is_schedulable 为真，由 RTA 不动点定理（Joseph–Pandya）每条任务的响应时间 R_j≤D_j，故最坏情况下所有检查在截止期内完成；若某检查失败则直接返回拒绝，不存在「超时后默认通过」的分支。
3. 安全关键任务在预算不足时返回 False 而非计入风险，保证最低安全底线不因预算被交易。∎

### 引理 17（时效证书的漂移管道保持）
**陈述**：若证书在 t_0 签发且 payload 的量满足 Lipschitz 常数 L_p，则对任意 t∈[t_0, t_0+TTL]，只要 ‖x(t)-x(t_0)‖≤ρ(t)，用 conservative_payload(t) 膨胀后的证书仍覆盖真实系统状态，即真实残余风险 ≤ 标称风险 + L_p·ρ(t)。

**证明**：设证书量 q(x) 关于 x 是 L_q-Lipschitz。由中值定理 |q(x(t))-q(x(t_0))|≤L_q‖x(t)-x(t_0)‖≤L_q·ρ(t)。取 L_p=max_q L_q，对每个标量证书量加 L_p·ρ(t) 即得区间上界。TTL 保证未把漂移管道外推至模型失效区域；越界即 is_valid=False，直接拒绝而非外推。∎

### 引理 18（模仿盾牌的安全不变性）
**陈述**：若 IPC 的四条件成立（支撑覆盖、conformal 动作覆盖、CBF 不变性、性能次优界），且 CIS 在投影残差 >ε_shield 或截止期不足时切换到已认证兜底控制器，则闭环系统始终停留在安全集 S={x:h(x)≥0} 内。

**证明**：
1. 支撑覆盖保证观测 o 落在示范支撑的 ε_support 邻域内，降低 OOD 外推概率；动作覆盖保证真实动作以 ≥1-α_act 概率落在 C_a(o) 内。
2. CBF 不变性在 A_cert(x) 上逐顶点验证：对凸多面体，仿射动力学下 h 的线性约束若在所有顶点满足，则在整个多面体满足（线性函数在凸集上的极值在顶点取得）。因此 a_safe∈A_cert(x) ⇒ h(x_{t+1})≥(1-γ)h(x)≥0。
3. 当投影残差过大或截止期不足时，输出兜底控制器动作；兜底控制器本身已被 v26 的 USMC/FCC 认证，故仍在 S 内。
4. 两种分支都保持 h≥0，归纳得全程安全。∎

### 引理 19（实时-模仿退化链的单调性）
**陈述**：任意单点/组合失效下，Exec_v27 ⊆ Exec_v26 ⊆ … ⊆ Exec_v18 恒成立。

**证明**：增加三条退化路径：
- 截止期不可调度/预算不足 → `rtc.is_schedulable=false` 或 `anytime_admit=false` → RTIC-UG 拒绝进入实时模式，退回 Exec_v26 的低频认证计划（保留八证，但放弃高频学习策略）。
- 证书过期/漂移越界 → `tvc.is_valid=false` → 拒绝旧证书，冻结在最后一次有效认证状态或退回保守控制器；该状态属于 Exec_v26（其签发时已验证）。
- 策略 OOD/动作未覆盖/CBF 不成立/投影残差过大 → `cis.step` 返回兜底动作，RTIC-UG 的准入集合收缩为「兜底控制器可达集」，仍 ⊆ Exec_v26（因为兜底是已认证控制器）。
- 组合失效取交集；由于每条退化路径都映射到 Exec_v26 的子集，且新增过滤器均为交集项，单调链保持。∎

### 定理（RTIC-UG 实时-时效-模仿完备性）
**陈述**：对任意多机计划 Π 与状态 (x,o,t)，`RTIC-UG.admits(Π,x,o,t,δ)=True` ⟺ Π 同时满足：
(1) v26 的全部九项条件（物理/云边/少样本/专利/结构/力控/轻量/语义/重构/协同/成本/记忆/可扩展），
(2) 证书任务集可调度且 anytime 残余风险 β(δ)≤β_max，
(3) 证书在 TTL 与漂移管道内有效，
(4) 模仿策略满足支撑、动作覆盖、CBF 不变性与性能次优界，
(5) 运行时盾牌在截止期内完成投影，且投影残差 ≤ε_shield 或已切换兜底。

**证明**：由 `admits` 的五个连言分支直接可得必要性（任一分支 false 即拒绝）。充分性：(1) 由 v26 定理保证计划级安全；(2) 由引理 16 保证截止期与风险上界；(3) 由引理 17 保证时效；(4) 由 IPC 定义保证策略可信；(5) 由引理 18 保证动作级不变性；再由引理 19 保证退化单调链。故 RTIC-UG 把「计划级事前审查」与「动作级运行时过滤」闭合成一个带时限的完整证明链。∎

## 6. 本轮最大风险（最终确认）

**一句话**：当算力抖动使外环证书不可调度、同时观测落在示范支撑之外时，实时性保证与安全性保证会互相挤占——为赶 1kHz 内环截止期而启用的「上一认证动作保持」或兜底控制器，可能恰好在策略 OOD、证书过期的窗口内执行，使带时限盾牌退化为「用未验证的旧动作代替未验证的新动作」，这是实时-模仿融合方案最难证明、也最需要硬件级兜底的最大风险。
