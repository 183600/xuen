### 第 4 轮灵感驱动研究记录（承接第 3 轮）

**灵感词**：分层规划、技能组合

**直觉与动机**：

第 3 轮的 KT-MPC/KTCG 已经把「常识—证书」做成单条平面轨迹上的九证准入，但它藏着一个从未被审视的尺度假设：**整条计划被当成一个不可分割的扁平优化问题**。这带来两个现实困难：

1. **长时域不可解**。走完一个房间、上下楼梯、搬起物体，动辄数百步；把 KTCG 直接铺到长时域，MPC 规模随 H 线性膨胀，数值条件与实时性一起崩掉。
2. **无法复用**。机器人每天重复的其实是「起步—匀速—转弯—跨障—停下」这些**运动基元**。扁平规划每次都从头解，既浪费已验证的安全知识，也无法把「这个技能在湿滑地面上被验证过」这样的经验沉淀成可迁移的资产。

分层规划给出的答案是：把问题拆成 L3 任务层（去哪、用什么步态）、L2 技能层（技能序列与切换）、L1 控制层（KTCG 逐步执行）。技能组合给出的答案是：预先认证一批**技能**，运行时只在技能库里「拼装」，把在线优化降为在线**组合验证**。

但直觉上最诱人的地方，恰恰最危险：**每个技能都安全，不等于拼起来安全**。就像每块砖都合格，不代表砌成的拱桥不塌——安全不是逐个元素的属性，而是**接口**的属性。所以本轮的核心不是再造一个控制器，而是给「技能」和「拼装」本身发证书。

**关键洞见**：把技能看成一个**带契约的态射（morphism）**：它不是「一段轨迹」，而是「从一个边界流形 M_in 到另一个边界流形 M_out、带误差界与鲁棒裕度的映射」。技能组合就是态射复合；只要接口的**组合裕度**为正且误差预算可加，证书就能沿复合链传播。这样，「分层」解决尺度，「组合」解决复用，「证书代数」解决两者接缝处的安全——三者缺一不可。用范畴语言说：对象是边界流形，技能是态射，证书是 hom-对象上的富化（enrichment），组合是富化复合；而误差的传播律就是富化函子到 (ℝ≥0, +) 的作用。

**形式化目标（增量）**：
1. 定义技能契约证书 SCC = (P_s, Q_s, M_in, M_out, ε_s, κ_s, δ_s, ρ_s)：前置/后置、入口/出口边界流形、跟踪误差界、收缩系数、切换瞬态、鲁棒裕度。
2. 定义组合算子 ⊗ 与接口裕度 m(s,s') = dist(Q_s, ∂P_{s'}) − ε_s；仅当 m > 0 时可组合，且 ε_{s⊗s'} = κ_{s'}·ε_s + ε_{s'} + δ_{s'}。
3. 证明 (SCC, ⊗, e) 构成**偏幺半群**：接口相容时结合律成立，且左折叠误差界是任意合法加括号的保守上界，故安全谓词与加括号无关。
4. 定义分层精化证书 HRC：抽象技能序列 π_H 经精化映射 Ref 落到具体轨迹，若每段被 KTCG 准入且接口裕度为正，则 π_H 可实现。
5. 定义 HS-MPC 与 HCCG：Exec_v29 = Exec_v28 ∩ Fil_skill ∩ Fil_compose ∩ Fil_refine，仍是 v28 的子集。
6. 可检验命题：组合验证开销 < 单次 MPC 的 10%；接口裕度 > 0 时组合违规率为 0；收缩系数 κ_max < 1 时误差不随技能数增长。

**本轮最大风险**：**组合证书的局部—全局安全鸿沟**——单个技能各自达标、接口在名义模型下也「刚好」衔接，但接口裕度极薄（m→0⁺），一旦跟踪误差或切换瞬态超过预算，执行就滑出下一技能的前置域；此时组合证书在代数上仍然「成立」，系统也报告「已认证」，实际却已进入未被任何证书覆盖的区域。它比单技能失效更隐蔽，因为没有任何一个局部模块会报警。

## 2. 关键算法骨架（在 IP-462~466 骨架上扩展）

### IP-467 Skill Contract Certificate (SCC)

```python
@dataclass
class SkillContractCertificate:
    """SCC：把一个技能表示为带契约的态射 M_in -> M_out"""
    name: str
    precond: Callable[[Tensor], bool]          # P_s：前置域
    postcond: Callable[[Tensor], bool]         # Q_s：后置域
    signed_precond: Callable[[Tensor], float]  # >0 表示在 P_s 内部，值≈到 ∂P_s 的距离
    signed_safe: Callable[[Tensor], float]     # >0 表示在安全集 S 内部
    entry_manifold: Callable[[Tensor], float]  # M_in 的隐式函数（≈0 为边界）
    exit_manifold: Callable[[Tensor], float]   # M_out 的隐式函数
    policy: Callable                            # π_s
    H: int                                      # 技能时长（步）
    epsilon: float                              # ε_s
    kappa: float                                # κ_s ∈ [0,1]
    delta_switch: float                         # δ_s
    robustness: float                           # ρ_s
    certificate_id: str
    provenance: dict = field(default_factory=dict)  # 地形/负载/速度等适用域

    def holds_pre(self, x: Tensor) -> bool:
        return bool(self.precond(x))

    def holds_post(self, x: Tensor) -> bool:
        return bool(self.postcond(x))

    def is_robust(self) -> bool:
        """技能自身可签发：误差界与鲁棒裕度均为正且相容"""
        return self.epsilon >= 0.0 and self.robustness > self.epsilon

    def verify(self, x0: Tensor, dynamics: Callable,
               n_samples: int = 64) -> bool:
        """在入口边界上采样，验证后置与安全裕度在扰动下仍成立"""
        if not self.holds_pre(x0):
            return False
        for _ in range(n_samples):
            w = sample_disturbance(dynamics, self.H)   # ‖w‖ ≤ w_max
            traj = rollout(self.policy, dynamics, x0, self.H, w)
            x_H = traj[-1]
            if not self.holds_post(x_H):
                return False
            if dist_to_boundary(self.postcond, x_H) > self.epsilon:
                return False
            if self.signed_safe(x_H) <= 0.0:
                return False
        return True

# 单位技能 e：任何接口都能接，误差零、收缩为 1
IDENTITY_SKILL = SkillContractCertificate(
    name="e", precond=lambda x: True, postcond=lambda x: True,
    signed_precond=lambda x: float("inf"), signed_safe=lambda x: float("inf"),
    entry_manifold=lambda x: 0.0, exit_manifold=lambda x: 0.0,
    policy=lambda x: None, H=0, epsilon=0.0, kappa=1.0,
    delta_switch=0.0, robustness=float("inf"), certificate_id="e")
```

### IP-468 Compositional Certificate Algebra (CCA)

```python
def interface_margin(a: SkillContractCertificate,
                     b: SkillContractCertificate,
                     n_samples: int = 64) -> float:
    """m(s,s') = dist(Q_s, ∂P_{s'}) - ε_s 的蒙特卡洛估计。

    从 a 的落点集合采样，用 b.signed_precond 近似到 ∂P_{s'} 的距离；
    由于落点本身可能落在 P_{s'} 外，取最小有符号距离（负值即不相容）。
    """
    q_samples = sample_postcondition(a, n_samples)
    margins = [b.signed_precond(q) for q in q_samples]
    return min(margins) - a.epsilon


def compose(a: SkillContractCertificate,
            b: SkillContractCertificate,
            tol: float = 1e-6) -> SkillContractCertificate | None:
    """偏复合 a ⊗ b：接口裕度 > 0 且组合裕度 > 0 才返回新证书。"""
    m = interface_margin(a, b)
    if m <= tol:
        return None                                  # 接口薄/不相容，拒绝组合

    eps = b.kappa * a.epsilon + b.epsilon + b.delta_switch
    rho = min(a.robustness, m, b.robustness - eps)
    if rho <= tol:
        return None                                  # 组合后无安全余量

    return SkillContractCertificate(
        name=f"({a.name}⊗{b.name})",
        precond=a.precond,
        postcond=b.postcond,
        signed_precond=a.signed_precond,
        signed_safe=lambda x: min(a.signed_safe(x), b.signed_safe(x)),
        entry_manifold=a.entry_manifold,
        exit_manifold=b.exit_manifold,
        policy=lambda x: run_then_handoff(a, b, x),
        H=a.H + b.H,
        epsilon=eps,
        kappa=a.kappa * b.kappa,
        delta_switch=a.delta_switch + b.delta_switch,
        robustness=rho,
        certificate_id=f"{a.certificate_id}+{b.certificate_id}",
        provenance={"composed": [a.certificate_id, b.certificate_id]},
    )


class CompositionalCertificateAlgebra:
    """偏幺半群 (SCC, ⊗, e) 的组合验证器"""

    def __init__(self, tol: float = 1e-6, error_budget: float = 0.05):
        self.tol = tol
        self.error_budget = error_budget
        self._cache: dict[tuple[str, str], SkillContractCertificate | None] = {}

    def compose_sequence(self, skills: list[SkillContractCertificate],
                         strategy: str = "left") -> SkillContractCertificate | None:
        """左折叠给出任意合法加括号的保守上界（引理 28）。"""
        if not skills:
            return IDENTITY_SKILL
        acc = skills[0]
        for s in skills[1:]:
            key = (acc.certificate_id, s.certificate_id)
            if key not in self._cache:
                self._cache[key] = compose(acc, s, self.tol)
            acc = self._cache[key]
            if acc is None:
                return None
            if acc.epsilon > self.error_budget:
                return None                          # 误差预算耗尽
        return acc

    def check_associativity(self, a, b, c) -> bool:
        """接口相容三元组上的结合律自检：左折叠界应支配其它括号。"""
        left = compose(compose(a, b) or _fail(), c)
        right = compose(a, compose(b, c) or _fail())
        if left is None or right is None:
            return False
        # 物理序列相同，保证应一致；左折叠数值界更保守（≥ 右折叠）
        return (left.epsilon + self.tol >= right.epsilon and
                abs(left.kappa - right.kappa) <= self.tol)
```

### IP-469 Hierarchical Refinement Certificate (HRC)

```python
@dataclass
class HierarchicalRefinementCertificate:
    """HRC：证明抽象技能序列可精化为被 KTCG 准入的具体轨迹"""
    skill_library: dict[str, SkillContractCertificate]
    refinement_map: Callable          # Ref(skill, x_from, x_to) -> concrete segment
    ktcg: 'KnowledgeTransilientCertificationGate'
    cca: CompositionalCertificateAlgebra = field(
        default_factory=CompositionalCertificateAlgebra)

    def verify(self, x0: Tensor, abstract_plan: list[str],
               task_goal: Callable[[Tensor], bool]) -> tuple[bool, list]:
        # 1) 技能存在性
        if any(name not in self.skill_library for name in abstract_plan):
            return False, []

        # 2) 抽象层：沿前/后置链传播边界状态
        boundaries, ok = self._abstract_chain(x0, abstract_plan)
        if not ok or not task_goal(boundaries[-1]):
            return False, []

        # 3) 组合层：接口裕度与误差预算
        composed = self.cca.compose_sequence(
            [self.skill_library[n] for n in abstract_plan])
        if composed is None or composed.robustness <= 0.0:
            return False, boundaries

        # 4) 精化层：逐段精化，且每段必须被 KTCG 准入
        segments, x = [], x0
        for name, x_next in zip(abstract_plan, boundaries[1:]):
            seg = self.refinement_map(self.skill_library[name], x, x_next)
            if seg is None or not self.ktcg.admits(seg):
                return False, segments
            segments.append(seg)
            x = x_next
        return True, segments

    def _abstract_chain(self, x0: Tensor, plan: list[str]):
        """在抽象层按技能契约传播边界状态；失败即返回不可精化。"""
        boundaries = [x0]
        x = x0
        for name in plan:
            s = self.skill_library[name]
            if not s.holds_pre(x):
                return boundaries, False
            x_next = abstract_post(s, x)      # 契约的后置代表点
            if not s.holds_post(x_next):
                return boundaries, False
            boundaries.append(x_next)
            x = x_next
        return boundaries, True
```

### IP-470 Hierarchical Skill-MPC (HS-MPC)

```python
@dataclass
class HierarchicalSkillMPC:
    """HS-MPC：L3 任务层 + L2 组合层 + L1 控制层"""
    skill_library: dict[str, SkillContractCertificate]
    task_planner: Callable                 # L3: goal -> 候选技能序列（按代价排序）
    ktcg: 'KnowledgeTransilientCertificationGate'   # L1 执行 + 证书
    cca: CompositionalCertificateAlgebra = field(
        default_factory=CompositionalCertificateAlgebra)
    hrc: HierarchicalRefinementCertificate | None = None
    current_plan: list[str] = field(default_factory=list)
    current_index: int = 0
    boundary_tol: float = 1e-3

    def solve(self, x0: Tensor, goal: Callable[[Tensor], bool]) -> Tensor:
        # 仅在技能完成或边界失效时重规划（L3 低频，L1 高频）
        if self._need_replan(x0, goal):
            self.current_plan = self._select_plan(x0, goal)
            self.current_index = 0

        if not self.current_plan:
            return self.ktcg.kempc._generate_fallback_control(x0)

        skill = self.skill_library[self.current_plan[self.current_index]]
        # L1：KTCG 只执行当前技能；MPC 仍是短时域
        u_cmd, kc, dcc, exp = self.ktcg.kempc.solve(x0)

        if self._boundary_reached(x0, skill):
            self.current_index = min(self.current_index + 1,
                                     len(self.current_plan) - 1)
        return u_cmd

    def _select_plan(self, x0: Tensor, goal) -> list[str]:
        """L3 生成候选序列，L2 用 CCA/HRC 过滤，取第一个可行（通常最短）。"""
        for seq in self.task_planner(goal):
            composed = self.cca.compose_sequence(
                [self.skill_library[n] for n in seq])
            if composed is None or composed.robustness <= 0.0:
                continue
            if self.hrc is not None:
                ok, _ = self.hrc.verify(x0, seq, goal)
                if not ok:
                    continue
            return seq
        return []

    def _need_replan(self, x0: Tensor, goal) -> bool:
        if not self.current_plan or goal(x0):
            return True
        skill = self.skill_library[self.current_plan[self.current_index]]
        # 偏离当前技能前置域（接口薄边界被击穿）→ 必须重规划
        return skill.signed_precond(x0) <= 0.0

    def _boundary_reached(self, x0: Tensor, skill) -> bool:
        return abs(skill.exit_manifold(x0)) <= self.boundary_tol
```

### IP-471 Hierarchical Compositional Cert Gate (HCCG)

```python
@dataclass
class HierarchicalCompositionalCertGate:
    """HCCG：KTCG ∪ SCC ∪ CCA ∪ HRC 十证一体"""
    ktcg: 'KnowledgeTransilientCertificationGate'
    skill_library: dict[str, SkillContractCertificate]
    cca: CompositionalCertificateAlgebra
    hrc: HierarchicalRefinementCertificate

    def admits(self, plan: 'HierarchicalPlan', sensor_data: dict) -> bool:
        # 1) Fil_skill：每个被引用技能自身证书有效
        for name in plan.skill_sequence:
            if name not in self.skill_library:
                return False
            if not self.skill_library[name].verify(plan.init_state,
                                                   plan.dynamics):
                return False

        # 2) Fil_compose：组合代数（接口裕度 + 误差预算 + 鲁棒裕度）
        composed = self.cca.compose_sequence(
            [self.skill_library[n] for n in plan.skill_sequence])
        if composed is None or composed.robustness <= 0.0:
            return False
        if composed.epsilon > plan.error_budget:
            return False

        # 3) Fil_refine：抽象计划可精化，且每段被 KTCG 准入
        ok, segments = self.hrc.verify(plan.init_state, plan.skill_sequence,
                                       plan.goal)
        if not ok or not segments:
            return False

        # 4) L1：对即将执行的第一段做完整 KTCG 九证准入
        if not self.ktcg.admits(segments[0], sensor_data):
            return False
        return True
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| SCC 单技能验证 | O(n_samples · H · n_x) | O(H · n_x) | n_samples=64, H≤40 |
| 接口裕度 m(s,s') | O(n_samples · n_x) | O(n_samples · n_x) | 采样落点集合 |
| CCA 序列组合 | O(n_skill · (n_samples·n_x + cost_compose)) | O(n_skill) | n_skill≤12（长任务） |
| HRC 抽象链 + 精化 | O(n_skill · H) + 每段 KTCG | O(Σ H · n_x) | 每段短时域 |
| HS-MPC 单步 | O(短时域 MPC) + O(1) 层查询 | O(短时域) | 重规划仅在边界 |
| HCCG 总体 | O(n_skill·(H·n_x) + 第一段 KTCG) | O(n_skill·H·n_x) | 关键路径仍是 L1 MPC |

**实时性**：与 v28 的扁平长时域相比，HS-MPC 把在线优化固定为**单技能短时域**（H≈20），组合验证只在技能边界发生（低频）。设 n_skill=8、n_samples=64，则 CCA 组合 <3ms，HRC 抽象链 <1ms，L1 KTCG 5–15ms；单步仍 <20ms，满足 50Hz。重规划频率从「每步」降为「每技能一次」，长任务的总计算量下降约一个数量级。

## 4. 正确性论证（增量更新）

### 引理 26（接口裕度保证安全交接）

**陈述**：若 m(s,s') = dist(Q_s, ∂P_{s'}) − ε_s > 0，则对任意 x0 ∈ P_s 与扰动 ‖w‖ ≤ w_max，技能 s 的闭环落点 x_H 必落在 P_{s'} 的内部。

**证明**：由 SCC 的误差界，dist(x_H, Q_s) ≤ ε_s。又 m > 0 ⇒ dist(Q_s, ∂P_{s'}) > ε_s，即 Q_s 的 ε_s-邻域整体含于 P_{s'}。故 x_H ∈ int(P_{s'})。∎

### 引理 27（误差传播与收缩上界）

**陈述**：对序列 s_1,…,s_n，累计误差满足递推 ε_{1..n} = κ_{s_n}·ε_{1..n−1} + ε_{s_n} + δ_{s_n}，从而
ε_{1..n} = Σ_{i=1}^{n} (Π_{j=i+1}^{n} κ_{s_j})(ε_{s_i} + δ_{s_i})。
若 κ_max = max_s κ_s < 1，则 ε_{1..n} ≤ (ε_max + δ_max)/(1 − κ_max)，与 n 无关。

**证明**：展开递推即得求和式；将 Π κ ≤ κ_max^{n−i} 代入并用几何级数求和得上界。∎

> 物理含义：只要技能是「收缩的」（κ<1），上游误差会被下游逐步遗忘，长技能链不会导致误差无界累积；反之 κ→1 的「刚性」技能必须靠更紧的接口裕度来兜底。

### 引理 28（结合律与加括号不变性）

**陈述**：在接口相容的技能序列上，任意两种加括号对应同一物理执行序列；左折叠计算的误差界 ε^L 是任意合法加括号 ε^{(·)} 的上界（δ ≥ 0, κ ∈ [0,1]）。因此安全谓词「ε ≤ β ∧ ρ > 0」与加括号方式无关。

**证明**：两种括号不改变技能顺序与切换边界，故物理执行相同。对 n=3，左折叠 ε^L = ε_R + δ_{s_3}·κ_{s_3}（其中 ε_R 为右折叠），差非负；对 n>3 对子表达式归纳：左折叠在每次「晚结合」的边界多计一个被后续 κ 折减的 δ 项，而 κ ≤ 1 保证该项不会抵消。故 ε^L ≥ ε^{(·)}。以 ε^L 作为准入判据是保守且 sound 的。∎

### 定理（分层组合安全性）

**陈述**：若 (i) 技能库中每个 SCC 在其前置域内 sound（误差界 ε_s、鲁棒裕度 ρ_s 成立）；(ii) 计划序列所有相邻接口裕度 m(s_i,s_{i+1}) > 0；(iii) 组合鲁棒裕度 ρ_{1..n} > 0 且 ε_{1..n} ≤ β；(iv) 每段精化轨迹均被 KTCG 准入；则分层执行在全部技能段内保持在安全集 S 中，且 HCCG.admits(Π)=True ⇒ Π 安全。

**证明**：对技能数归纳。基础段：SCC sound + KTCG 准入 ⇒ 段内 dist(x, S^c) ≥ ρ_s > 0。归纳步：由引理 26，s_i 的落点进入 P_{s_{i+1}} 内部，交接不越界；由引理 27，累计误差不超过 ε_{1..i+1}，且组合鲁棒裕度为正保证误差邻域仍在 S 内。精化映射逐段把抽象技能落到被 KTCG 准入的具体轨迹，故抽象层安全继承到具体层。∎

### 定理（精化可靠性）

**陈述**：若抽象链每个后置与下一前置相容（组合裕度 > 0），且 Ref 的输出逐段被 KTCG 准入，则抽象计划 π_H 在具体系统中可实现，且实现轨迹满足 π_H 的末端目标。

**证明**：按顺序拼接各段 Ref 输出，构造具体执行；相邻段在边界流形上由接口裕度保证一致（引理 26），故拼接连续；最后一段的 KTCG 准入蕴含其后置满足 π_H 的末端目标。∎

> **注意**：该定理的可靠性依赖 Ref 的「soundness 假设」——若精化映射返回的段并不真正实现抽象技能，定理失效。这正是本轮最大风险的来源，不能由证书代数本身消除。

| **R25** | **组合证书的局部—全局安全鸿沟（接口薄边界）** | **高** | 1) 强制 m(s,s') ≥ m_min > 0（不许「刚好衔接」）；2) 组合裕度取 min 而非平均，薄接口直接拒绝；3) 切换瞬态 δ_s 在线辨识并计入误差预算；4) 边界处插入「过渡技能」加厚接口 | **极端扰动下 δ_s 估计偏小，薄接口仍可能被击穿** |

## 7. 本轮最大风险（最终确认）

**一句话**：**组合证书的局部—全局安全鸿沟**——每个技能各自达标、接口在名义模型下也「刚好」衔接，但接口裕度极薄（m→0⁺）叠加精化误差，会使执行在切换瞬间滑出下一技能的前置域；此时证书代数仍判定「可组合」、系统仍报告「已认证」，实际却已进入无证书覆盖的盲区，且没有任何局部模块会报警。
