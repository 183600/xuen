# 第 3 轮迭代（灵感循环 v3b：「模型预测控制」×「小样本学习」）——把“检测-重做”升级为“小样本自适应的滚动时域规划”

> **承接 v2 的 UIP-01′~15，本轮不是再加一层启发式，而是换控制架构。** v2 的旗舰 RHPV-D 本质上是一个**反应式状态机**：每个块边界判一次 `done / regressed / fail`，回退就重做。它有两个未检验的假设：**(a) 只看一步、只做一个决策**，因此无法在“重做当前步”和“先做更值钱的下一步/先让行”之间做期望分数比较；**(b) 任务适配靠 32 个数据集“平均地学”**，但在真正拉开差距的“未见物品 / 人为撤回 / 背景与干扰物”轴上，可用样本极少，平均地学必然把稀有轴淹没。对照本轮两个灵感词：**MPC** 提供“在短时域内比较候选动作序列的期望回报、只执行第一步、再滚动重规划”的框架；**小样本学习**提供“把跨任务共享的先验与任务/扰动特有的少量证据分开”的统计工具。两者合起来，正好补上 v2 的两个缺口：**决策从 1 步变成 H 步的期望分数比较，适配从平均学习变成先验 + 少量证据的后验更新。**

## 0. 本轮证据与三条“先钉死再规划”的接口事实

证据分级沿用 v2：**A**=官方参考实现/README；**B**=v2 缓存的 32 个 `info.json` 与 12 个任务的真实 state/action 轨迹；**D**=本轮新跑的机制检验（真实轨迹上的线性 ARX 迁移实验 + 预测时域校准），只证明机制，不作机器人结论。

| 事实 | 内容 | 出处/等级 |
|---|---|---|

| 步骤状态是隐变量 | 单帧谓词在遮挡/细接触（拉链、拧盖、插网线）下不可分；`regressed` 应是**信念的负向跳变**，不是单帧标签 | v2 的 `human_*` 证据 + 本轮推导；v3 校准，B |
| 预测有有效时域 | 真实轨迹上，恒速预测的归一化 RMSE：h=1 **0.060**、h=2 **0.117**、h=4 **0.243**、h=8 **0.509**、h=15 **0.984**；h≥15 时“按动作保持”反而更稳 | `exp/r4_state_est_closed_loop.json` 的 `real_prediction_nrmse`，B/D |
| 低层动力学近似任务不变 | 留一任务（leave-one-task-out）线性 ARX：**零样本跨任务先验**在 h=1/4/8 的 NRMSE = **0.027 / 0.053 / 0.068**；用目标任务全部数据从零拟合反而 **0.032 / 0.058 / 0.076**；朴素 k-shot 微调 k=1/8/32 在 h=1 为 **0.040 / 0.041 / 0.034**，仍不优于先验 | `exp/r2b_mpc_fewshot.json`（12 任务、右臂 ee pose、线性 ARX，D） |

**三条先钉死再规划的事实：**

1. **MPC 的“控制步”不是帧，而是“动作块”。** 因为 `T_a` 固定、块内不能重观测，滚动时域只能建在**块边界**上；帧级预测（`h≤4`）只够在块内做一次前向校验，不足以支撑多块开环外推。**推论：规划时域要分成两层——内层帧级动力学只预测 `≈1` 个块；外层在“计分步/技能图”上做 H_o 步期望分数比较。**
2. **v2 的 UIP-13（自适应块长）必须作废。** 它假设“每次返回 ≤k 步”，与严格 `(T_a,…)` 形状冲突；`T_a` 只能在**握手前离线选**。正确做法是用 MPC 的**期望净分数**（成功收益 − 延迟/重做代价）离线扫 `T_a`，而不是在线变块长。
3. **小样本的正确落点不是低层动力学。** D 级实验显示：同一台 G1 的 ee 动力学跨任务几乎不变，**跨任务先验已经比目标任务自拟合更好**；把宝贵的少量样本花在动力学微调上会**变差**。真正任务/扰动特有的、数据又最缺的是**计分步判据、技能先后关系、人为撤回的恢复策略**——小样本应集中在这三层。

## 1. 直觉解释（先直觉，后定义）

**模型预测控制：把“看到回退就重做”换成“先在心里预演几条后续路线，再只走第一步”。** 人做叠毛巾、拉拉链这类多步任务时，不会每完成一小段就机械地“检查—继续”；他会在心里比较：“现在布被翻开了，是立刻重折这一步，还是先把旁边那步做完再一起收拾？”这个比较天然是**有限时域、带代价、滚动执行**的：预演 H 步、只执行第一步、下一步再重算。机器人同理。v2 的状态机只会问“当前步是否 done”；MPC 会问“**在接下来 H 个计分步内，哪个选项序列的期望得分最高**”，而“重做”“让行”“先搏末步”都只是候选选项。由于计分是**有序且末步分值更大**，这个期望分数可以直接用“进度势函数”编码，不需要额外学一个奖励模型。

**小样本学习：不是“少数据也能平均地学会一切”，而是“把共享先验与少量任务证据分开”。** 32 个任务共享同一台机器人、同一套相机、同一类桌面物理，所以“动作→末端运动”这部分**跨任务先验极强**（D 级实验已见）；但“这个任务的第 3 步到底怎么算完成”“这个人的撤回是拧回还是拿走”几乎**没有共享结构**，只有 2–5 个计分步、极少数演示。正确的统计姿势是：共享部分用**零样本先验**直接迁，任务/扰动部分用**带强收缩的 k-shot 后验**去修，且**只在证据持续偏离先验时才修**（否则 k-shot 会把噪声当信号，D 级实验里朴素微调确实变差）。一句话：**小样本预算要花在“任务层”，不要花在“机器人层”。**

**合起来：内层快、外层慢的双层滚动时域。** 内层用任务不变的动力学先验做 1 个块的前向校验（负责“这个动作是否被外力改写”）；外层用技能图 + 计分势函数做 H_o 步的期望分数比较（负责“下一步该做什么/该不该重做/该不该让”）。小样本只在两层之间做**先验—证据的收缩**：证据少就信先验，证据持续冲突才更新后验。这比 v2 的“单步检测-重做”多了一个**可计算的决策边界**：不是“回退就重做”，而是“**期望恢复分数 > 重做的时间与延迟代价时才重做**”。

## 2. 严谨定义

**定义 1（信念状态）** 令 `z_t=(s_t,x_t,d_t)`：`s_t∈{0,…,m}` 为已完成计分步数，`x_t` 为物体/机器人连续状态，`d_t` 为外部（人为）扰动。信念 `b_t(z)=p(z_t | o_{1:kT_a}, u_{1:kT_a}, l)`。策略在块边界输出 `π(b_t,l) → A_t∈R^{T_a×d}`，且形状严格为 `(T_a,·)`。

**定义 2（技能图与选项）** 技能图 `G=(V,E)`：节点是技能/计分步 `v`，边是允许的先后关系。选项 `o=(v, π_base(·|v,l), β)`，其中 `β` 是终止条件。一次 MPC 规划选择长度 `H_o` 的选项序列 `o_{0:H_o-1}`，但**只执行 `o_0` 的一个完整 `T_a` 块**，然后观测、更新信念、重规划（滚动时域）。

**定义 3（计分进度势）** 对有序计分步 `1..m`，分值 `w_1..w_m`（末步 `w_m≥w_{m-1}`）。定义进度势 `Φ(s)=Σ_{j=1}^{s} w_j`，以及单步收益
`R(o,b)=E[Φ(s')-Φ(s) | b,o] - λ_reg·P(regressed|b,o)·w_{s}`
其中第二项惩罚“重做已得分步骤”的负向风险；`regressed` 是信念从 done 回落的概率，不是标签。

**定义 4（滚动时域目标）** 在边界 `t_k=kT_a`：
`o_{0:H_o-1}* = argmax E[ Σ_{i=0}^{H_o-1} γ^i R(o_i,b_{t_{k+i}}) ] - λ_L·E[latency] - λ_R·E[#redo] - λ_U·H(b)`
`s.t.  P(step_j done | b) ≥ 1-α`（机会约束，`α` 由保形校准给出）、`o_i` 与 `G` 的边一致、每个块形状 `(T_a,·)`。
执行 `o_0*`；下一块重新求解。`H_o=1` 退化为 v2 的反应式；`H_o≥2` 才能显式比较“重做 vs 先做下一步 vs 让行”。

**定义 5（有效预测时域）** 令 `h*(ε)=max{h: NRMSE_pred(h)≤ε}`。D 级校准给出 `h*(0.25)≈4` 帧（30 Hz 下约 0.13 s），`h*(0.5)≈8` 帧（约 0.27 s）。因此**帧级 MPC 的深度上限约为 1 个 `T_a`**；更长的规划必须上升到定义 2 的选项层（选项层用计分图，不靠像素外推）。

**定义 6（小样本元学习）** 任务/扰动分布 `p(T)`。共享先验参数 `θ_0`（动力学）与 `φ_0`（判据/选项值）。元训练用 32 任务做留一：
`φ_0 = argmin_φ Σ_{T≠T_test} L_T(φ)`。
测试任务用 `k` 条（弱）标注片段 `D_k` 做带先验的 MAP：
`φ_k = argmin_φ L(φ;D_k) + (λ_k/2)||φ-φ_0||^2`。
定义**任务特异度缺口** `Δ_T = E[L(full_T)] - E[L(prior)]`；只有当 `Δ_T` 的置信下界 `>0` 时才更新 `φ_0→φ_k`，否则保持先验（防止 D 级实验中的“k-shot 反而变差”）。

**定义 7（小样本收益上界）** 在 `λ_k` 收缩下，`k` 样本后验的期望超额风险满足 `E[L(φ_k)]-L(φ*) ≤ O(√(d_eff log(1/δ)/k))`，其中 `d_eff` 是**被先验收缩后的有效维数**。这解释了两件事：共享维（动力学）`d_eff≈0`，所以零样本已近最优；任务/扰动维 `d_eff` 大而 `k` 小，所以必须靠**强先验 + 主动选样**（见定义 8）而不是蛮力微调。

**定义 8（主动探针/对偶控制）** 当判据不确定性高、且该步分值大时，允许一次**小幅消歧动作** `u_probe`（轻推、保持、回撤 1 cm、移相机视角）。其价值为信息增益
`VoI = E_{y~p(y|b,u_probe)}[ H(b) - H(b'|y) ] · w_{s+1}`
只有当 `VoI > λ_t·(探针耗时) + λ_r·P(探针致损)` 时才执行；否则退化为保守 `VERIFY`。这使“小样本”不仅是离线先验，还能在部署时**主动买信息**。

## 3. 瓶颈假设（可证伪）

- **H1（最高杠杆：决策时域太短）** 人为撤回下的分数损失，主要来自“只比较当前步”，而不是策略网络容量；把 `H_o` 从 1 提到 2–3，在相同策略/数据下就能提升期望步骤分。
- **H2（期望分数 vs 启发式）** 用 `Φ` 的期望净收益决定“重做/让行/前进”，比“任何回退都重做”误重做更少，尤其当撤回发生在低分值步、而末步分值更高时。
- **H3（小样本落点）** 把 k-shot 预算从低层动力学转到任务判据/选项值，收益显著；反过来，微调动力学不仅无益，还可能变差（D 级证据支持）。
- **H4（先验—证据收缩）** 只在“任务特异度缺口”显著时更新，能避免 k-shot 过拟合；无门控的微调会随 `k` 增大先降后升。
- **H5（主动消歧的性价比）** 对低可观测步（拉链/拧盖/插网线），一次小探针的期望分数增益大于其时间与扰动代价；对高可观测步（大物体搬放）则不划算。
- **H6（双层时域匹配）** 帧级外推只在 `T_a≤h*` 时可信；当 `T_a>h*` 时，MPC 的内层预测必须截断到 `h*` 并交给外层选项层，否则“预测越远越自信”会反噬。

## 4. 从 v2 到 v3b 的清单变动

- **升级**：UIP-01′ → **UIP-16（技能图 MPC，SMPC）**；UIP-09′ 的撤回检测并入 UIP-16 的 `R(regressed)` 项；UIP-15 的安全阀并入 UIP-18 的机会约束。
- **新增（命中两词）**：UIP-16 SMPC（技能图滚动时域）、UIP-17 FTA（小样本任务适配）、UIP-18 CC-Redo（机会约束重做）、UIP-19 MVC（元校准验证器）、UIP-20 AFP（主动少样本探针）。
- **作废/改写**：UIP-13 自适应块长**作废**（与固定 `T_a` 冲突），由“离线 `T_a` 扫描 + 期望净分数”取代；UIP-02′ 降为**离线诊断**，不再作为在线目标。
- **保留**：UIP-05、08′、11、12、14；UIP-11/12 从“刷分工具”改为**MPC 的离线试验台与扰动生成器**。

## 5. 本轮押注

**押注：UIP-16（技能图 MPC）× UIP-17（小样本任务适配）× UIP-19（元校准验证器）组成的“先验—证据双层闭环”**，由 UIP-18 的机会约束限制重做、UIP-20 的主动探针在低可观测步买信息。它把 v2 的“检测-重做”从单步规则变成一个**有期望分数、有代价、有先验收缩、且严格遵守固定 `T_a` 接口**的控制器；而且每个部件都在选手 API 权限内（离线训练、握手选 `T_a`、块边界发动作、`reset()` 内维护状态）。

**→ 本轮最大风险（一句话）**：MPC 的模型在“人为撤回”这个训练分布外最自信——如果小样本适配把少量合成扰动当成真实分布、又用较长的 H_o 放大模型误差，方案会比 v2 的朴素反应式更差；因此必须用短 `H_o`、机会约束、无门控不更新、以及真机锚点把“模型自信”限制在可恢复范围内。

# 第 3 轮产物 · MAPLE v3b：元自适应预测式技能规划（UIP-16~20）

> 承接 v2（UIP-01′~15）。本轮把旗舰从**单步反应式状态机**改为**双层滚动时域规划**：外层在“计分步/技能图”上比较 H_o 步期望分数，内层用“任务不变的动力学先验”做 1 个块的前向校验；小样本只用于任务/扰动层的**带收缩后验**。
> 口径：接口以官方 `unibot_submission` README §1–§6 为准（`T_a` 固定、形状严格 `(T_a,·)`、块内开环、块边界反馈）；计分结构来自 v2 缓存的 32 个 `info.json`。所有真机结论提测前一律视为**代理结论**。
> 本轮新增证据全部标为 **D 级**：真实轨迹上的预测时域校准与小样本迁移实验，只证明机制存在，不是机器人结论。

## 1. 本轮 D 级证据审计

### 1.1 预测时域校准：MPC 的内层深度上限

数据：`exp/unibot_states/*.npz`，12 任务、右臂 `ee_pose_gripper_base`，30 Hz。两种开环预测器：

- `velocity`：`x̂_{t+h}=x_t + h·(x_t-x_{t-w})/w`（w=5）；
- `action_hold`：`x̂_{t+h}=a_t`（零阶保持，块内下发不变）。

归一化 RMSE（按每维轨迹标准差归一）：

| 时域 h | 1 | 2 | 4 | 8 | 15 | 30 |
|---|---:|---:|---:|---:|---:|---:|
| velocity | **0.060** | **0.117** | **0.243** | 0.509 | 0.984 | 1.913 |
| action_hold | 0.372 | 0.360 | 0.372 | **0.492** | **0.722** | **1.038** |

**判读**：
1. `h*(0.25)≈4` 帧（约 0.13 s），`h*(0.5)≈8` 帧（约 0.27 s）。若 `T_a=8`，帧级外推**最多覆盖约 1 个块**。
2. `h≥8` 时 `action_hold` 反超 `velocity`：**长时域外推会把速度噪声放大**，这正是“MPC 时域越长越好”的反例。
3. 因此 MAPLE 采用**双层时域**：内层帧级预测截断到 `min(T_a, h*)`；外层在选项/计分图上做 `H_o∈{1,2,3}` 的比较，选项层不依赖像素外推。

### 1.2 小样本迁移实验：先验该迁到哪一层

设置：12 任务、线性 ARX `Δx_{t+1}=θ^T[x_t;a_t]`（12 维输入、6 维输出，按目标任务尺度归一化），100 帧分段、60/40 分段划分；**留一任务**：用其余 11 任务估计先验 `θ_0`（ridge, λ=1e-2），在目标任务上做 k-shot MAP（λ_k=1），在目标任务的留出分段上做多步 rollout。数值为 3 个种子的任务平均 NRMSE。

| 方法 | h=1 | h=4 | h=8 |
|---|---:|---:|---:|
| 零样本跨任务先验 `θ_0` | **0.027** | **0.053** | **0.068** |
| 目标任务全量自拟合 | 0.032 | 0.058 | 0.076 |
| k-shot k=1 | 0.040 | 0.078 | 0.106 |
| k-shot k=2 | 0.038 | 0.073 | 0.099 |
| k-shot k=4 | 0.040 | 0.079 | 0.107 |
| k-shot k=8 | 0.041 | 0.081 | 0.108 |
| k-shot k=16 | 0.039 | 0.077 | 0.104 |
| k-shot k=32 | 0.034 | 0.066 | 0.088 |

**判读（本轮最重要的负结果）**：
1. **跨任务先验已经优于目标任务自拟合**——在同一台 G1 上，“动作→末端运动”几乎任务不变，共享先验的样本量优势压过任务差异。
2. **朴素 k-shot 微调全部变差**；`k=32` 也只是逼近而不能超过零样本先验。说明“少样本=微调动力学”是错误直觉。
3. 因此小样本预算应转向**任务判据、技能先后关系、撤回恢复策略**——这些才是 `d_eff` 大、样本又最少的部分（见 §3/§5）。
4. **限制**：这是线性 ARX 代理，未覆盖视觉/接触/高维策略；结论只能支持“低层动力学迁移应保守”，不能外推到整策略。需要 E303 在真实策略上复核。

### 1.3 相位跟踪 toy：信念 + 代价决策优于单帧

来自 `exp/r4_state_est_closed_loop.json` 的合成采样数据闭环（D 级，仅机制）：

| `T_a`（块） | 单帧判据 分数率 / 误重做 | 信念判据 分数率 / 误重做 | 平均检测延迟（单帧 / 信念） |
|---:|---:|---:|---:|
| 2 | 0.797 / 12.55 | **0.855 / 1.38** | 0.66 / 0.89 |
| 4 | 0.670 / 4.93 | **0.733 / 0.82** | 1.86 / 1.95 |
| 8 | 0.469 / 1.48 | **0.508 / 0.45** | 4.25 / 5.09 |

**判读**：信念换来更高的最终分数与低一个数量级的误重做，代价是检测略晚（多等约 0.2–0.8 个块）。这正是 MPC 需要的 trade-off 形态：**用可接受的延迟换误重做下降**。

### 1.4 三条硬约束（写进实现）

1. 动作块**必须**严格 `(T_a,·)`，索引 0 先执行；禁止运行期变块长。
2. 内层帧级预测**不得超过 `h*`**；超出部分由外层计分图承担。
3. 小样本更新**默认关闭**；只有任务特异度缺口显著时才打开（§3.3 的门控）。

## 2. UIP-16 · SMPC（Skill-graph Model-Predictive Controller）

### 2.1 形式化

在块边界 `t_k`：

```
候选：o_{0:H_o-1}，o_i ∈ V(G)，且与 G 的边一致（尊重计分顺序）
收益：R(o,b) = E[Φ(s')-Φ(s)|b,o] - λ_reg·P(regressed|b,o)·w_s
代价：C = λ_L·E[latency] + λ_R·E[#redo] + λ_U·H(b) + λ_S·P(violate)
目标：max  E[Σ γ^i R_i] - C
约束：P(step_j done|b) ≥ 1-α；块形状 (T_a,·)；oport 预算 ≤ L_max
执行：只执行 o_0* 的完整 T_a 块；下一边界重规划
```

其中 `Φ(s)=Σ_{j≤s} w_j`，`w` 来自 32 任务计分表（末步最大）。`P(regressed|b,o)` 由 UIP-19 的校准后验给出，**不是单帧标签**。

### 2.2 为什么是“技能图”而不是“关节序列 MPC”

- 关节/末端序列 MPC 的模型误差在 `h>h*` 后爆炸（§1.1），且接触丰富的插入/折叠不可微；
- 计分步是**天然离散、低维、长时域**的规划对象，且分值已知；
- 技能图上的 H_o 步枚举成本极低（每任务 `m≤5`，`H_o≤3`，候选数 ≤ `|V|^3` 的小子集），适合每个块边界实时跑。

### 2.3 伪代码

```python
class MAPLE:  # UIP-16 + 17 + 18 + 19 + 20
    def __init__(self, base, graph, dyn_prior, verifier, T_a,
                 H_o=2, alpha=0.1, max_redo=2, L_max=250):
        self.base, self.G, self.dyn = base, graph, dyn_prior
        self.V, self.T_a, self.H_o = verifier, T_a, H_o
        self.alpha, self.max_redo, self.L_max = alpha, max_redo, L_max

    def reset(self):
        self.g = 0                      # 已完成计分步索引
        self.redo = 0
        self.b = None
        self.hist = []                  # 仅本端口，天然隔离
        self.base.reset()

    def get_action(self, obs):
        self.b = self._update_belief(obs)                 # 融合 + 时序
        # 1) 机会约束：先过滤不可信的前进
        cand = self._feasible_options(self.b)             # 只保留图边一致、P(done)≥1-α
        # 2) 对每个候选序列做 H_o 步期望分数（外层）
        best, best_j = None, -1e9
        for seq in self._enumerate(cand, self.H_o):
            j = self._expected_score(seq, self.b)
            if j > best_j:
                best, best_j = seq, j
        # 3) 低可观测步：比较一次探针的 VoI（UIP-20）
        if self._worth_probe(best[0], self.b):
            best = [self._probe_option()] + list(best)
        # 4) 只执行第一步的完整块（形状严格 (T_a,·)）
        chunk = self.base.act(obs, option=best[0], T_a=self.T_a)
        # 5) 更新状态机（只在执行后）
        self._advance(best[0])
        return chunk

    def _expected_score(self, seq, b):
        score, bel, risk = 0.0, b, 0.0
        for i, o in enumerate(seq):
            r = self._step_reward(o, bel)                  # Φ 差 - 撤回惩罚
            # 内层帧级预测只到 h*（UIP-16/§1.1），超出由选项层承担
            bel = self.dyn.predict(bel, o, h=min(self.T_a, self.h_star))
            score += (self.gamma ** i) * r
            risk += self._constraint_risk(o, bel, self.alpha)
        return score - 10.0 * risk - self._cost(seq)

    def _step_reward(self, o, b):
        p_done = self.V.done_prob(b, self.G.step_of(o))     # 校准后验
        p_reg = self.V.regress_prob(b, self.G.step_of(o))
        w = self.G.weight(self.g + 1)
        return p_done * w - self.lam_reg * p_reg * w

    def _advance(self, o):
        if o.kind == "advance":
            self.g += 1; self.redo = 0
        elif o.kind == "redo":
            self.redo += 1
        elif o.kind == "yield":        # 让人，不扣进度
            pass
        elif o.kind == "retreat":
            self.g = max(0, self.g - 1); self.redo = 0
```

### 2.4 复杂度与实时性

- `|V|≤5`、`H_o≤3`、每层候选 ≤4 ⇒ 每次规划 ≤ `4^3=64` 条序列，纯 CPU 微秒级；
- 内层 `predict` 只前推 `min(T_a,h*)`，避免长时域误差；
- 规划时间必须计入 `L_max`；超预算时降级为 `H_o=1`（v2 行为）而不是继续算。

## 3. UIP-17 · FTA（Few-shot Task Adaptation）

### 3.1 先验—证据分解

把参数分成两层：

- **机器人层 `θ`**（动力学/运动学）：`d_eff` 小、跨任务共享 ⇒ **零样本迁移，默认不更新**（§1.2 证据）。
- **任务层 `φ`**（计分步判据、选项值、技能先后）：`d_eff` 大、每任务只有 2–5 个计分步 ⇒ **强先验收缩的 k-shot**。

任务层的 MAP：

```
φ_k = argmin_φ  L(φ; D_k) + (λ_k/2) ||φ - φ_0||^2
λ_k = λ_0 · k / (k + k_0)          # 样本越少，越信先验
```

`φ_0` 由 32 任务留一元学习得到；`D_k` 是 2–5 条片段（离线：数据集 + GSO 几何谓词弱标注；在线：本 episode 已完成的 `k` 个计分步的自监督信号）。

### 3.2 小样本数据从哪来（不假设额外评测局）

1. **离线**：32 个公开数据集 + v2 的 UIP-11 GSO 几何谓词，自动给“子目标完成/未完成”弱标签；每任务抽 2–5 条做 `D_k`。
2. **扰动层**：用 UIP-12 DRF 按 `human_*` 生成 `(干扰前 → 撤回 → 恢复)` 三元组；**留一扰动类型**做元训练，测试未见类型（E304）。
3. **在线**：`reset()` 后本局已完成的前 `k` 个计分步，用自监督（物体位姿变化、接触、夹爪开合）作为弱证据，更新 `φ` 的**低维子空间**（只改判据阈值/选项先验，不动主骨干）。

### 3.3 门控：只在“缺口显著”时适配

```
Δ_T = E[L(full_T)] - E[L(prior)]           # 用留出分段估计
if lower_CI(Δ_T) > 0 and k >= k_min:
    use φ_k
else:
    use φ_0                               # 默认零样本
```

D 级实验已显示：无门控的 k-shot 在动力学层会让误差从 0.027 升到 0.040（h=1）。**门控是必须的，不是可选项。**

### 3.4 与“单模型合规”

`φ` 是挂在主骨干上的**轻量适配头/阈值向量**，`θ` 是同一个动力学先验；不引入第二套大模型权重。小样本更新用闭式 ridge/Laplace，CPU 可完成。

## 4. UIP-18 · CC-Redo（Chance-Constrained Redo）

### 4.1 机会约束

对每个计分步 `j`，要求 `P(step_j done | b) ≥ 1-α` 才允许标记完成并前进；对“重做”要求
`P(regressed | b) ≥ q_reg` 且 `E[Δscore_recover] > λ_R·E[delay]`。
`α`、`q_reg` 由 UIP-19 的保形校准给出，保证在可交换性假设下
`P(标记 done | 实际未完成) ≤ α`。

### 4.2 抗饱和（Anti-windup）

- 每 episode 最多 `max_redo` 次重做；
- 连续两个块延迟超 `L_max` ⇒ 强制降级 `H_o=1` 并禁止探针；
- 连续两次误重做 ⇒ 提高 `q_reg`（更保守），但不改变 `α` 的统计口径。

这直接对抗 v2 的“反复重做→延迟爆炸”风险。

## 5. UIP-19 · MVC（Meta-Calibrated Verifier）

### 5.1 少样本校准

对任务 `T` 的计分步 `j`，用保形分位数
`q_{j,α} = Quantile_{1-α}({s_i : y_i = not done})`
其中 `s_i` 是验证器的完成分数。样本少时用**分层收缩**：

```
q_{j,α} = (1-β_j)·q_{j,α}^{(task)} + β_j·q_{α}^{(global)}
β_j = k_0 / (k_0 + k_j)
```

`k_j` 是该步的校准样本数；`k_j=0` 时完全回退到全局先验。这样每个任务只需 2–5 条片段，就能得到**分布无关的有限样本上界**（在可交换性下）。

### 5.2 输出

- `P(done|b)`、`P(regressed|b)` 及其不确定性；
- 每步的 `α` 与 `q_reg`；
- 置信度低于阈值时，MPC 自动选择 `VERIFY`/探针，而不是硬判。

## 6. UIP-20 · AFP（Active Few-shot Probe）

### 6.1 何时值得探针

```
VoI = E_y[ H(b) - H(b'|y) ] · w_{s+1}
worth = VoI > λ_t·T_probe + λ_r·P(probe causes damage)·w_s
```

只在 `P(done)` 处于不确定带（如 0.3–0.7）、该步分值高、且剩余时间充足时执行。

### 6.2 探针库（小、可逆、不改变任务语义）

| 探针 | 适用步 | 动作 | 为什么安全 |
|---|---|---|---|
| 轻推 | 堆叠/排列 | 末端轻触 2 mm 后回撤 | 不改变物体类别/顺序 |
| 保持+移视角 | 拉链/合盖 | 保持夹持，腕部相机微转 | 不改任务状态 |
| 回撤 1 cm | 插入 | 小幅回撤再看对齐 | 可逆，不丢抓取 |
| 二次夹持 | 抓取不确定 | 松-合一次 | 仅影响夹爪，不动机器人底座 |

**红线**：探针不得改变计分步语义（如把已插入的网线拔出）；探针总时长计入 `L_max`。

## 9. 合规、接口红线与风险

| 风险 | 触发 | 缓解 |
|---|---|---|
| 长时域模型自信 | `T_a>h*` 仍外推 | 内层截断到 `h*`，外层用计分图；`H_o` 上限 3 |
| k-shot 过拟合 | 扰动分布与先验不同 | 任务特异度门控 + 强收缩 `λ_k` + 留一扰动验证 |
| 误重做/延迟爆炸 | 撤回检测假阳性 | 机会约束 + `max_redo` + 延迟预算 + 抗饱和 |
| 探针致损 | 探针改变任务语义 | 探针库白名单 + 可逆性检查 + VoI 门控 |
| 单模型合规 | 引入外部 VLM/第二套权重 | 只用主骨干适配头 + 确定性后处理；审计权重数 |
| 仿真过拟合 | 只在 GSO/DRF 刷分 | GSO 只当结构裁判；真机锚点 E309 |
| 步骤分误用 | 把仿射影子当独立目标 | 以 success 为主；步骤分只用于离线诊断与顺序先验 |

**接口红线**：`meta.token` 每步携带；动作形状严格 `(T_a,·)`、dtype 正确、索引 0 先执行；不返回可变长度块；不声明未使用 obs 键；N 端口状态隔离；`reset()` 每 episode 一次。

## 11. 本轮最大风险 & 押注

**一句话**：MAPLE 最大的风险是“用模型代替证据”——在人为撤回这个训练分布外，较长的 `H_o` 与少量合成扰动的 k-shot 后验会互相放大误差，让一个自信但错误的前瞻比 v2 的朴素反应式更差；因此必须先保证短 `H_o`、机会约束、门控不更新与真机锚点，再谈自动化。

**→ 本轮最值得押注**：**UIP-16（技能图 MPC）× UIP-17（门控小样本任务适配）× UIP-19（元校准验证器）** 的“先验—证据双层闭环”。它精确利用了本轮两条硬证据——**低层动力学应零样本迁移、任务层才需要小样本**（§1.2）——并把 v2 的单步“检测-重做”升级为可计算的期望分数比较；所有部件都在固定 `T_a`、块内开环、`reset()` 内维护状态的接口约束之内。
