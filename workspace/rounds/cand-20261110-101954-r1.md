# 第 43 轮（新循环第 3 轮）· 语义-几何流证书：VLM 把「意图」编译成 barrier，流匹配把「动作」展开成可证明流管（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」。本轮两个灵感词不是外挂模块，而是**直插证书内核**：**流匹配策略**不是"又一个生成式策略"，它是一个由光滑速度场生成的**确定性 ODE**，天然携带三个可证明量——Lipschitz 界 L_v、可逆性、直度 straightness；**视觉语言模型**不是"又一个感知前端"，而是把自然语言指令与场景语义**编译成 barrier 约束 h(x)≥0** 的"规格编译器"。二者的交汇点是本轮的核心命题：**直度既是成本的通货，也是安全的通货**——把流"拉直"到 1-NFE，既满足第 42 轮 ECR 的边缘预算，又把可达集收缩成可解析证明的凸流管；而 VLM 把"别碰人""杯子易碎"变成可验证的屏障，让证书第一次覆盖到"任务意图"这一层。代价是风险迁移：几何求解的 soundness 越强，**规格本身出错**（语义误接地）被"合法证明"放大的后果越严重。

## 0. 直觉与动机

**灵感 1（流匹配策略 → 策略即 ODE，证书即流管）**：第 42 轮的策略侧（IP-48 认证流匹配）只把流匹配当作生成器，证书仍靠外部 CAR/LCS 事后验证。流匹配的直觉是：策略本身就是 `da/dt = v_θ(a, o, z, t)`，从噪声 a_0 积分到动作 a_1。若 v_θ 在动作空间是 L_v-Lipschitz、范数有界 V_max，则由 Gronwall 不等式，**任意两条轨迹的距离随时间最多按 e^{L_v t} 放大**——于是"初始噪声落在半径 ρ_0 的球里"直接推出"整条动作轨迹落在以名义轨迹为中心、半径 ρ_0·e^{L_v t} 的流管里"。这是**不采样、不建网格**的解析可达集上界，比第 42 轮的 L0 查表更便宜、更 sound。更进一步：**直度** S(θ)=E∫‖(a_1−a_0)−v(a_t,t)‖²dt 同时决定两件事——(i) 1-NFE 近似误差（拉直 → 一步出动作 → 边缘延迟↓）；(ii) 流管相对端点凸包的保守度（拉直 → 管≈凸包 → 证书更紧）。所以"reflow 直到 S≤ε_s"第一次把加速目标与证书收紧目标统一。

**灵感 2（VLM → 从语言到 barrier 的规格编译器）**：第 42 轮的证书只管几何安全（不撞、不失稳），管不到"任务意图"（别碰人、杯子易碎、走人右边）。VLM 的直觉是做一个**语义→屏障编译器**：从 (指令 l, 观测 o) 抽取一组安全原子 A={人存在, 易碎, 靠左通行, …}，每个原子编译成 barrier h_a(x)≥0 或一个障碍区域膨胀。危险在于 VLM 会幻觉。因此**不信任点估计，只信任覆盖集**：用 split conformal 校准，得到保证 P(A_true⊆A_ε)≥1−δ 的原子集 A_ε；证书必须对 A_ε 里的**最坏原子**成立。这样 VLM 的不确定性被翻译成证书的保守度，而不是被忽略。

**灵感 3（交汇：ODE 残差是"免费"的运行时监控）**：流匹配定义了一条流形——执行轨迹应当满足 ODE。定义残差 r_t=‖ȧ_t^exec − v_θ(a_t, o_t, z_t, t)‖。正常跟踪时 r_t 很小；一旦执行器饱和、外扰、或 VLM 在 chunk 中途改判（语义漂移），r_t 立刻抬高。**这个监控器不需要额外网络、不需要额外内存**（复用策略前向），且与流管半径共享同一个 Lipschitz 预算。它把"策略/证书/监控"焊成一体：同一个 v_θ 既生成动作、又定义可达集、又当异常探测器。

**耦合与飞轮**：VLM 选模式 m 与条件 z → 流匹配生成动作 → CBF 投影把动作限制在由 VLM 屏障定义的 U_safe → 流管证书给出 tube 半径 ρ(t) → CAR 守卫用 `h_i(x)≥L_{h_i}ρ(t)` 判定 → 残差监控触发重规划/降级 → 实机反例回灌第 42 轮 SCV/CKB。证书链从"几何安全"第一次延伸到"语义安全"。

## 1. 形式化定义（增量：定义 38–45）

**定义 38（语义条件流策略）**：π_θ(a|o,l) 是 ODE `da/dt = v_θ(a, o, z_l, t)`、a_0∼N(0,I)、a_1=φ_1(a_0) 的推前分布；z_l=E_VLM(l,o) 为冻结语义嵌入；离散模式 m=g_ψ(l,o)∈{1..M}，可用混合流 v=Σ_m w_m(z)v_m。输出动作 chunk a_{1:H}。

**定义 39（流管 / 解析可达集）**：设 v_θ 对 a 为 L_v-Lipschitz、‖v_θ‖≤V_max，初始集 X_0⊆B(x̄_0,ρ_0)。则时间 t 的可达集 R_t={φ_t(x_0):x_0∈X_0} 满足 `R_t ⊆ B(φ_t(x̄_0), ρ_0·e^{L_v t})`（Gronwall 直接推出）。计入投影/量化误差 δ 时，半径改为 ρ(t)=ρ_0·e^{L_v t}+δ。**证书安全条件**：对全部 i 与 t∈[0,T]，`h_i(x) ≥ L_{h_i}·ρ(t)`（h_i 为 L_{h_i}-Lipschitz 的 barrier）。

**定义 40（直度与一步误差）**：S(θ)=E_{t,a_0}‖(a_1−a_0)−v_θ(a_t,t)‖²，a_t=(1−t)a_0+t·a_1。**命题**：∫_0^1‖v_θ(a_t,t)−(a_1−a_0)‖dt ≤ √S（Cauchy–Schwarz），故流管相对端点凸包的额外膨胀 ≤ √S；且 1-NFE 误差 ≤ (L_v V_max)/2+max_t‖∂_t v‖，S→0 时误差→0。**推论：直度同时是边缘延迟与证书保守度的共同通货。**

**定义 41（屏障编译流 / CBF-Flow）**：仿射动力学 ẋ=f_0(x)+B(x)u，安全集 S=⋂_i{h_i≥0}。安全控制集 U_safe(x)={u: L_{f_0}h_i+L_B h_i u+α_i h_i≥0, ∀i}。投影流 `ũ=Proj_{U_safe(x)}(v_θ)`（二次投影 QP）。**定理（前向不变）**：若每步投影可行，则 S 对闭环前向不变；离散 chunk 版本用 `h_i(x_{k+1})≥(1−α_iΔ)h_i(x_k)` 并叠加 tube 裕度 L_{h_i}ρ。

**定义 42（语义接地证书）**：VLM 抽取原子集 A=Extract(l,o)⊆𝒜。以非一致性分数 s(a)=1−p_VLM(a) 做 split conformal，阈 q_δ 取校准集 (1−δ) 分位，得覆盖集 `A_ε={a:p_VLM(a)≥1−q_δ}`，保证 P(A_true⊆A_ε)≥1−δ。语义熵 H_sem=−Σ p·log p 作认知不确定性：H_sem>τ_sem → 扩大 A_ε、查询人类或 SafeStop。

**定义 43（语义鲁棒证书）**：`C_sem={x: ∀a∈A_ε, h_a(x)≥0}`；对无法几何核验（深度/分割/时序不一致）的原子打 `unknown` 标记，施加保守默认屏障（视为占用/易碎）。即证书对**最坏可能原子**成立，而非对点估计成立。

**定义 44（流残差监控）**：r_t=‖ȧ_t^exec−v_θ(a_t,o_t,z_t,t)‖，τ_res 取标定集 99.9 分位。r_t>τ_res → off-manifold，归因 {(执行器饱和),(外扰),(语义漂移)} 三类，触发重规划/降级。**命题**：残差上界与 tube 半径同源（均受 L_v,V_max 控制），故监控阈值可与证书裕度**联动标定**，无需独立实验。

**定义 45（端到端语义-几何证书）**：系统轨迹 x(t) 在 [0,T] 内安全，若同时满足 (i) 流管 sound（Def 39）、(ii) 屏障编译可行（Def 41）、(iii) 语义覆盖（Def 42–43）、(iv) 残差在预算内（Def 44）。**定理**：四条件成立时，以概率 ≥1−δ−δ_0（δ 为 conformal 漏检，δ_0 为噪声截尾）有 x(t)∈S；任一条件失效则降级路径接管（与第 42 轮 CAR/LCS 兼容）。

## 2. 产出设计（增量 IP-57/58/59/60 + 升级 IP-48/39/51/52/53/55/50/45）

### 2.1 IP-57 SEM-FLOW（语义条件直化流策略）
1. **双塔条件**：VLM 冻结编码器给 z_l 与原子 logits；小型动作专家做条件流匹配（线性插值路径），reflow 2–3 轮把 S 压到 ≤ε_s。
2. **模式混合**：按 VLM 模式 m 训练子流 v_m，推理按 w_m(z) 加权；模式切换处做流管拼接（取两管并集的外包）。
3. **1-NFE 蒸馏**：教师多步流 → 学生单步 `a_1≈a_0+v_θ(a_0,0)`，用 L_task+λ·L_flow 蒸馏，直接服务第 42 轮 ECR 的 <1ms 预算。

### 2.2 IP-58 FLOW-TUBE（流管证书器）
1. **L_v 上界**：对 v_θ 用区间界传播/谱范数估计（或 LipSDP），分模式给 L_{v,m}；V_max 由训练数据 99% 分位 + 1% 放大。
2. **Tube→guard**：把 ρ(t) 与 barrier Lipschitz L_h 相乘，得必须保留的裕度，写入 CAR 守卫；与 IP-56 L0 表联合，tube 半径预计算成 t 的查表函数。
3. **直度-保守度曲线**：对每个 S 档位输出 tube 体积/经验可达集体积比，供 E88 验收。

### 2.3 IP-59 SEM-BARRIER（VLM→屏障编译器）
1. **原子 schema**：{human_present, fragile, keep_left/right, no_reach_over, speed_limit, …}，每原子带几何 grounding 钩子。
2. **覆盖集 + 语义熵门控**：conformal 校准得 A_ε；几何核验（深度一致性、分割置信、时序稳定）决定是否 `unknown`。
3. **屏障合成**：原子→h_a 或其参数；最坏集 A_ε→屏障取交/取最保守；不可核验→默认保守屏障。输出带版本与适用域的 barrier 包，入 IP-55 CKB。

### 2.4 IP-60 RESIDUAL-GUARD（流残差监控）
1. 复用策略前向，计算 r_t；与 tube 半径联动阈值。
2. **归因**：饱和（u 触界）、外扰（残差 + 状态跳变）、语义漂移（残差 + o_t 特征突变）。
3. 与 IP-45 总线"语义心跳"、IP-56 偏移监控并联；触发 IP-51 降级。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

## 5. 本轮最大风险

**一句话**：本轮把风险从"求解器是否 sound"迁移到了"规格是否正确"——若 VLM 把"绕开人"静默误编译成"靠近人"，而 conformal 覆盖集又恰好没包住真值，那么流管证书会**为一个错误的安全命题提供合法证明**，且几何求解越严谨，这种"证明了错误命题"的失效越隐蔽、越难被残差监控发现（残差只查"是否沿着流走"，不查"流是否指向对的目标"）。

| r_t=‖ȧ_t^exec−v_θ(a_t,o_t,z_t,t)‖ | 流残差 | off-manifold 检测；τ_res 取 99.9 分位 |
| C_sem={x:∀a∈A_ε,h_a(x)≥0} | 语义鲁棒证书 | 对最坏可能原子成立 |

## 2. 关键算法（伪代码）

### IP-57 SEM-FLOW：直化训练与 1-NFE 蒸馏
```
def train_sem_flow(data, vlm, reflow_iters=3, eps_s=0.01):
    for x1, o, l in data:
        z, _ = vlm.encode(l, o)              # frozen semantic embedding
        x0 = randn_like(x1); t = uniform(0,1)
        xt = (1-t)*x0 + t*x1
        loss = || v_theta(xt, o, z, t) - (x1 - x0) ||**2   # conditional FM
        v_theta = step(v_theta, loss)
    for it in range(reflow_iters):           # reflow: straighten the flow
        pairs = [(x0, ode_solve(v_theta, x0, steps=10)) for x0 in sample_noise()]
        v_theta = fit_flow_matching(pairs)
        if estimate_straightness(v_theta) <= eps_s:
            break
    return v_theta

def distill_1nfe(v_teacher, calib, lam=0.5):
    v_student = init_from(v_teacher)
    for x0, o, z in calib:
        a_teacher = ode_solve(v_teacher, x0, o, z, steps=10)
        a_student = x0 + v_student(x0, o, z, 0.0)          # 1-NFE
        loss = ||a_student - a_teacher||**2 + lam*cert_penalty(a_student)
        v_student = step(v_student, loss)
    return v_student
```

### IP-58 FLOW-TUBE：解析流管与守卫裕度
```
def build_flow_tube(v_theta, modes, rho0, horizon, delta):
    for m in modes:
        L_v[m]   = interval_lipschitz(v_theta.m)   # 或 LipSDP / 谱范数
        V_max[m] = quantile(norms_of(v_theta.m), 0.99) * 1.01
    def rho(t, m):
        return rho0 * exp(L_v[m] * t) + delta
    return rho, L_v, V_max

def guard_with_tube(h_i, x_nom_t, t, rho, L_h):
    # 需保留裕度 > 管内最大偏差 -> 证书安全条件
    return h_i(x_nom_t) - L_h * rho(t) >= 0
```

### IP-59 SEM-BARRIER：覆盖集生成与最坏屏障
```
def compile_semantic_barriers(l, o, vlm, q_delta, tau_sem):
    p = softmax(vlm.atom_logits(l, o))
    A_eps = {a for a in ATOMS if p[a] >= 1 - q_delta}   # conformal coverage
    H_sem = -sum(p[a]*log(p[a]) for a in ATOMS)
    barriers = []
    for a in A_eps:
        if geometric_verify(a, o):          # depth/seg/temporal consistency
            barriers.append(atom_to_barrier(a, o))
        else:                               # cannot verify -> conservative default
            barriers.append(conservative_default(a))    # treat as occupied/fragile
    if H_sem > tau_sem:
        return barriers, NEED_HUMAN_OR_STOP
    return intersect(barriers), OK

def cert_sem_holds(x, barriers):
    return all(h(x) >= 0 for h in barriers)
```

### IP-41 CBF-Flow：把流输出投影进安全控制集
```
def cbf_project(u_nom, x, barriers, alpha, dt):
    rows, rhs = [], []
    for h in barriers:
        g = grad_h(h, x)
        Lf0h = g @ f0(x)
        LBh  = g @ B(x)
        rows.append(LBh)
        rhs.append(-Lf0h - alpha*h(x))       # 连续: h_dot + alpha*h >= 0
    u = solve_qp_min_norm(u_nom, rows, rhs)
    if u is None:                            # infeasible -> cannot certify
        return SAFE_STOP
    return u
```

### IP-60 RESIDUAL-GUARD：重用前向的残差监控
```
def residual_monitor(a_prev, a_now, o_t, z_t, t, dt, tau_res):
    a_dot = (a_now - a_prev) / dt
    r = norm(a_dot - v_theta(a_now, o_t, z_t, t))
    if r <= tau_res:
        return OK, None
    cause = attribute(r, u_saturated, observation_feature_jump(o_t))
    return TRIP, cause                        # saturation / disturbance / semantic drift
```

### IP-51/52/53 升级：语义边、T-2 档与证书导出
```
def car_guard_v3(e, x, cert, t):
    geo_ok = h_e(x) >= cert.L_h[e] * cert.rho(t)      # geometric edge via tube
    sem_ok = cert_sem_holds(x, cert.barriers)          # semantic edge via VLM barrier
    return geo_ok and sem_ok

def certify_light_v3(x, guards, cert, budget_us=200):
    # T-2: 1-NFE 流前向 + 残差检查 (<1ms)
    a1 = x0 + v_student(x0, o, z, 0.0)
    r  = residual_once(a1, x, o, z)
    if r > cert.tau_res: return downgrade_monotone(cert), -2
    # T-1: L0 查表；T0: L1 INT8 监控（承接第 42 轮）
    b = cert_lookup_L0(x)
    if not undecided_guards(b, guards): return b, -1
    if budget_us < 110: return downgrade_monotone(b), -1
    status, margin = monitor_step_INT8(quantize_obs(x))
    b.m_lo = margin
    return b, 0 if not undecided_guards(b, guards) else downgrade_monotone(b)

def export_flow_for_edge(v_student, v_teacher, rho_fn, target='tvm'):
    int8_model = export_int8(qat(v_student, calib), target=target)
```

## 6. 本轮最大风险

**一句话**：本轮把风险从"求解器是否 sound"迁移到了"规格是否正确"——若 VLM 把"绕开人"静默误编译成"靠近人"，而 conformal 覆盖集又恰好没包住真值，那么流管证书会**为一个错误的安全命题提供合法证明**，且几何求解越严谨，这种"证明了错误命题"的失效越隐蔽、越难被残差监控发现（残差只查"是否沿着流走"，不查"流是否指向对的目标"）。
