# 第 42 轮（新循环第 2 轮） · 地形适应 × 语音识别：把「地形」当作在线识别的隐语言，用假设格证书 + 主动探测把「不确定」从停机改为适应（四层架构 v7）

> 承接第 41 轮 v18（CAR × LCS × CMC）。第 41 轮自陈最大风险是「可用性崩塌」：状态机与轻量化都偏保守，系统可能长期困在 Degraded/SafeStop。本轮灵感词「地形适应」「语音识别」恰好提供一条反向通路：**语音识别**教我们把「地形」看成一条只在噪声观测中隐约可见的隐语言，用假设格（lattice）而不是单一标签去承载它；**地形适应**教我们不确定性不该只触发降级，而应触发主动探测与步态重配置——先「问清楚」，再「决定」。二者合起来把 v6 的「保守即安全」升级为「识别—探测—适应即安全且可用」。

## 0. 直觉与动机

**灵感 1（地形适应 → 证书的隐藏前提必须显式化）**：v18 的所有证书其实都偷偷假定了一个地形模型：摩擦系数 μ、坡度 α、地面刚度 k、离散步高、接触时序。一旦机器人从瓷砖走到碎石、从干地走到湿地，这些前提就失效，而证书却还挂在那里——这正是「证书太松/太假」的根因之一。地形适应的直觉是：地形不是一个标签，而是一个**随时间演化的隐状态**，它决定动力学 f_c、摩擦锥与可通行性，因此证书必须写成**地形条件证书** m_e(x;c)，并在 c 变化时被事件触发重认证。更深一层：适应不是「识别完再动」，而是「边动边识别、用动来识别」——落脚、打滑、足端振动本身就是探测信号。

**灵感 2（语音识别 → 假设格、置信度与端点在线的三重隐喻）**：ASR 面对的是「一句话到底是什么」的隐变量问题，它的整套工程恰好对症：
1. **n-best / lattice**：不赌单一地形标签，而保留一束假设及其概率；这直接对抗 v18 的可用性崩塌——过早坍缩到「最坏地形」才会长期 SafeStop。
2. **置信度校准（conformal / ECE）**：ASR 的 softmax 置信度天然过度自信，必须校准才能用于安全决策；我们同样需要「真地形落在假设集内」的分布无关覆盖率保证，才能把证书的 1−δ 落到实处。
3. **CTC blank 与 endpointing**：地形切换是稀疏事件，绝大多数控制拍应判为 blank（不变），端点检测给出「这一段地形已稳定」的时刻；这天然对应 v18 的滞回与 Zeno 消除。
4. **beam search + 语言模型**：地形有「语法」——草地之后更可能是土路而非冰面；用转移先验做剪枝，比纯逐帧分类抗噪得多。

**耦合**：地形识别器给 CAR 提供「我现在可能在哪些地形上」，CAR 据此用**假设格上的鲁棒边际**做守卫；当假设集过大、守卫符号不定时，v18 只会降级，而本轮引入**主动探测（epistemic action）**：在鲁棒安全的前提下执行一个最能把地形「问出来」的小动作（试探性落脚、降速半步、轻触），把不确定性**消解**掉再回到 Nominal。识别是「听」，探测是「问」，适应是「换步态」——三者构成一个闭环，把 v6 的保守死锁打开。

**与既有工作的区别**：地形分类/步态切换已有大量工作，但通常是「分类器 + 规则切换」，没有证书语义；ASR 的 lattice/置信度也未被引入足式安全。本轮的独特点是：**假设格本身就是证书的索引**，识别的不确定性直接进入安全守卫，而主动探测是「用证书约束下的信息增益」来选的，因此识别、控制、认证第一次共用同一个概率对象。

## 1. 形式化定义

**定义 32（地形隐语言模型 THLM）**：地形序列 c_{1:T}∈C^T，C 为有限地形类集（如 {瓷砖, 草地, 碎石, 沙地, 冰面, 台阶, 斜坡}）。转移先验 P(c_t|c_{t−1}) 称**地形语言模型**；观测似然 P(o_t|x_t,c_t) 由本体感受（关节力矩、足端接触、IMU 振动谱）与外感受（深度/点云几何）编码器给出，称**地形声学模型**。识别即对后验 P(c_{1:t}|o_{1:t}) 做前向推断，并以 CTC 式 blank 吸收「地形未变」的多数拍。

**定义 33（地形假设格与共形置信集）**：在时刻 t 维护束 B_t={h=(c_{1:t}^{(i)}, s_i)}，s_i 为声学+语言模型得分；取 top-k 并经**共形校准**得到置信集 H_t⊆C，满足分布无关覆盖 P(c_t^*∈H_t)≥1−δ（在可交换性下）。H_t 的大小 |H_t| 是「识别不确定性」的可操作度量；|H_t|=1 且后验集中称**已识别**。

**定义 34（地形条件证书与鲁棒边际）**：对守卫 e，定义地形条件边际 m_e(x;c)=在动力学 f_c、摩擦 μ_c 下沿候选控制的安全裕度。假设格上的**鲁棒边际**为 m_e^{rob}(x)=min_{c∈H_t} m_e(x;c)（最坏情形），风险加权版为 m_e^{ρ}=Q_ρ{m_e(x;c): c∈H_t}。转移 e 合法当且仅当 m_e^{rob}(x)≥θ_e 且 H_t 的覆盖成立（置信 1−δ）。注意：**不对不可行假设做安全剪枝**——不可行假设若为真恰恰最危险，只能靠探测消解或按其后验质量降级。

**定义 35（证书感知束搜索 CABS）**：束搜索的每步扩展地形转移，得分 score(h)=α·log P(o|c,x)+β·log P(c|c_prev)+γ·feas(h)，其中 feas(h) 由 m_e^{rob} 是否可行给出。**剪枝只按后验质量**，且被剪总质量 Σ_{h∉B_t}P(h)≤δ_prune；feas 仅用于**排序探测动作与降级优先级**，绝不用于把假设从安全最坏情形中删除。这样束宽与覆盖率可同时被证明。

**定义 36（主动地形探测 ATP）**：探测动作集 U_probe（小幅、短时、可逆）。探测策略选 u^*=argmax_{u∈U_probe} IG(u)，IG(u)=H(c^*|H_t)−E_{o}[H(c^*|H_t,o,u)]，约束为鲁棒探测安全 min_{c∈H_t} m_probe(x,u;c)≥θ_probe。仅在 Watch/Degraded 允许；若连探测都不满足鲁棒安全，则转 SafeStop。探测本质是**在证书允许的范围内买信息**。

**定义 37（适应时间与可用性恢复）**：地形切换后，T_adapt=从切换发生到 |H_t|=1（置信 1−δ）且守卫全部确定的时长；可用性恢复时间 T_rec=从不确定性尖峰到重新进入 Nominal 的时长。二者与 v18 的 T_hold 共同构成运行时的时间预算：T_adapt+T_hold ≤ 任务允许的暂停上限。

**设计约束（不确定性的三级处理，升级 v18 单调保守性）**：不确定时优先级为 **探测（若鲁棒安全）→ 降级（若探测不安全但运动安全）→ SafeStop（若运动不安全）**。这保持了「不确定不导致漏报警」的单边可靠性，同时把「不确定即停机」改为「不确定即获取信息」，从机制上缓解可用性崩塌。

## 2. 三大产出设计

### 2.1 IP-54 TERRAIN-LANGUAGE-RECOGNIZER（地形语言识别器 TLR）
1. 流式编码器：本体（力矩/接触/振动谱）+ 外感（深度几何）双通道，输出帧级地形后验；CTC blank 吸收未变拍。
2. 地形语言模型：地形转移先验 + 可行性先验（冰面不接台阶等物理语法），用于束搜索打分。
3. 共形校准：以 held-out 地形段做 split-conformal，输出覆盖集 H_t 与 ECE；分布漂移检测（见风险）触发保守扩张。
4. 端点检测：稳定段检测给出「地形段」边界，供 CAR 做稀疏事件转移，替代逐帧抖动。
5. 输出对象：不是标签，而是 (H_t, 后验, 覆盖证书, 端点标志)，直接作为 CAR 的状态分量。

### 2.2 IP-55 HYPOTHESIS-LATTICE-CERTIFICATE（假设格证书 HLC）
1. 把 v18 的证书从 m_e(x) 升级为 m_e(x;c)，并计算鲁棒/风险加权边际 m_e^{rob}、m_e^{ρ}。
2. 覆盖—紧致权衡：H_t 越大越安全但边际越松；用 ρ-分位在「覆盖率 1−δ」与「可用性」之间取点，纳入 LCS 的成本模型。
3. 二维 anytime 前沿：一维是证书档位（T0→T3），一维是假设覆盖（top-k）；调度器在预算 Γ 下同时选档位与束宽，最小化「未定守卫 + 可用性损失」。
4. 保持时间的地形版：T_hold 在假设集不变段内有效；地形端点或覆盖集变化即触发重认证。
5. 与 CMC 对接：把「c∈H_t ⇒ m_e≥θ」编译为区间算术看门狗，对每个假设分支做定点校验，任一分支不满足即 warn/trip。

### 2.3 IP-56 ACTIVE-TERRAIN-PROBING（主动地形探测 ATP）
1. 探测动作库：试探性落脚、半步、降速、轻触/点测、改变支撑相时序；均带鲁棒安全包络。
2. 信息增益估计：用识别器的后验熵与预期观测模型在线估计 IG，避免真跑一遍所有动作。
3. 探测调度：只在「未定守卫且探测安全」时触发；设探测预算（次数/时长）防止无限试探。
4. 探测—适应联动：探测结果直接驱动步态参数（步高、步长、刚度、速度）重配置，即「地形适应」。
5. 失败回退：探测导致边际下降过快或超预算 → 立即转 Degraded/SafeStop，并记录反例供离线重训。

## 4. 实验设计（E79–E84 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E79 地形识别与校准 | top-1 准确率、共形覆盖率、ECE | ≥95%；≥1−δ；ECE<0.05 |
| E80 适应时间 | 地形切换后 T_adapt median/p99 | median<0.3s；p99<1.0s |
| E81 主动探测收益（消融） | 有/无 ATP 的 SafeStop 停留占比、T_rec | SafeStop 降≥50%；T_rec<0.5s |
| E82 鲁棒证书有效性 | 真地形∈H_t 且边际≥θ 的时间占比；不安全事件 | ≥99%；0 起 |
| E83 二维 anytime 成本 | p99 延迟、束宽、档位分布 | p99<8ms；平均束宽≤5；T0/T1≥80% |
| E84 端到端地形基准 | 成功率、跌倒、Nominal 占比、T_adapt | ≥85%；0 跌倒；≥70%；p99<1s |

回退：E79 校准不达标（覆盖失败）→ 放弃共形、改用固定保守地形集 + 更宽 δ；E80 太慢 → 只用本体高频信号做快速端点、视觉仅做慢确认；E81 探测有害 → 关闭 ATP，退回 v18 降级路径；E82 出现不安全事件 → 立即收紧为「全地形最坏情形」并停用假设格剪枝。

## 5. 本轮最大风险

**一句话**：整套方案把安全性押在「真地形落在假设格内」这一覆盖保证上，一旦地形分布漂移（未见过的冰面/软沙）破坏共形可交换性，识别器会自信地把真地形排除在外，鲁棒证书就会在错误的地形模型上「证明」安全，而主动探测还可能把不确定性变成真实的不稳定。

## 2. 关键算法（伪代码）

### IP-54 TLR：地形语言识别 + 共形覆盖
```
def recognize(o_t, x_t, beam, LM):
    beam = ctc_blank_extend(beam)                    # 多数拍判 blank
    for h in beam:                                   # 扩展地形转移
        for c in C:
            h' = extend(h, c)
            h'.score = a*log P(o_t|x_t,c) + b*log LM(c|h.last) + g*feas(h')
    beam = topk_prune(beam, k)                       # 仅按后验质量剪枝
    assert pruned_mass(beam) <= delta_prune
    H_t = conformal_cover(beam, delta)               # 覆盖集，非单标签
    endpoint = detect_stable_segment(beam)           # CTC endpointing
    return H_t, posterior(beam), endpoint
```

### IP-55 HLC：假设格鲁棒证书 + 二维 anytime
```
def robust_margin(x, e, H_t, rho):
    ms = [margin(x, e, c) for c in H_t]              # 地形条件边际
    return min(ms), quantile(ms, rho)                # 最坏 / 风险加权

def certify_2d(x, guards, H_t, budget):
    for j in [0,1,2,3]:                              # 档位：更紧界
        for k in [1,2,3,5,8]:                        # 束宽：更多假设
            b = tier_j(x, H_t[:k]); cost = C_j + W_k
            U = {e : lo(b,m_e^{rob}) < 0 < hi(b,m_e^{rob})}
            if not U: return b, j, k                 # 决策等价（全假设下）
            if cost + next_cost(j,k) > budget:
                return triage_uncertainty(b, H_t)    # 探测→降级→SafeStop
    return b, 3, 8
```

### IP-56 ATP：主动地形探测
```
def probe_policy(x, H_t, U_probe):
    best, best_ig = None, -inf
    for u in U_probe:
        if min(margin_probe(x,u,c) for c in H_t) < theta_probe:
            continue                                  # 鲁棒探测安全
        ig = entropy(H_t) - expected_entropy(H_t, u)
        if ig > best_ig: best, best_ig = u, ig
    return best if best_ig > ig_min else None

def car_step(state, x, H_t):
    if guards_decided(x, H_t): return Nominal, adapt_gait(H_t)
    u = probe_policy(x, H_t, U_probe)
    if u is not None: return Probe(u), H_t            # 用动来识别
    if motion_safe(x, H_t): return Degraded, H_t
    return SafeStop, H_t
```

### IP-53 CMC（升级）：假设分支看门狗
```
def compile_lattice_guard(e, H_t, dtype=fixed):
    branches = [interval_arith(margin_expr(e,c), dtype) for c in H_t]
    return Monitor(branches,
                   trip_if = any(lower(br) < theta_e for br in branches),
                   warn_if = coverage_may_fail(H_t),
                   wcet    = sum(bound_wcet(br) for br in branches),
                   mem     = O(|H_t|))
```

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 分布漂移破坏共形覆盖 → 真地形被排除 | 高 | OOD 检测触发假设集扩张；固定兜底地形集；覆盖率在线审计（E82）；未知即并入最坏情形 |
| 主动探测本身不稳定/引发跌倒 | 高 | 鲁棒探测安全包络 min_c m_probe≥θ_probe；探测预算；失败即降级；只在小幅可逆动作集内 |
| 假设格过大 → 边际过松、可用性反降 | 中 | 风险加权 m^{ρ} 替代纯 min；二维 anytime 在覆盖与紧致间取点；束宽上限 |
| 地形语言模型先验错误 → 剪掉真地形 | 中 | 剪枝只按质量且 Σ≤δ_prune；LM 先验做保守平滑；对抗地形课程 |
| 地形识别延迟拖慢控制 | 中 | 本体高频通道做快速端点；视觉仅慢确认；识别与控制解耦、事件触发 |
| 探测—识别闭环振荡 | 中 | 探测冷却时间 + τ_min；端点滞回；IG 阈值 ig_min |
| 乘积自动机再增一维 → 状态爆炸 | 中 | 假设格取并后按质量截断；assume-guarantee 分解 |

## 6. 本轮最大风险

**一句话**：安全性依赖「真地形落在假设格内」的覆盖保证，而地形分布漂移会破坏共形可交换性，使识别器自信地排除真地形——此时鲁棒证书在错误模型上「证明」安全，主动探测还可能把不确定性放大为真实失稳；因此 OOD 检测、固定兜底地形集与 E82 在线覆盖审计必须作为不可绕过的安全门。
