# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 2 轮；本轮灵感：「状态隔离」×「技能组合」）

> R72 把 GAUGE 从「认知层」下沉到「具身层」：REG 实时执行图、IRL 意图隐变量、DMEM 灵巧接触计量、EREFLEX 三层反作用、S2R-UQ 桥接，并给出「调度可信、意图可辨、接触可计量」时的逐指令风险界。但 R72 仍默认系统是**一个被整体认证的闭环**：
> - **状态隔离视角**：R72 的三域分离只隔离了**时间与内存**，没有隔离**状态所有权与认知污染**。`b_t(s,z)`、`b_t(z)`、`b_t(c)`、`ψ`、接触证据、标定参数都被多个模块共享读写；一个技能产生的坏后验、被投毒的标定、被误判的接触模式，会沿着共享状态静默扩散到其他技能。系统没有「谁有权改哪个状态」的能力边界，没有 checkpoint/rollback/quarantine，也没有区分「世界状态」「技能私有状态」「协调状态」「安全状态」「执行器状态」。**共享一个 `b_t` 不是共享一个事实，而是共享一份责任。**
> - **技能组合视角**：R72 认证的是一条策略/一个认证前缀，但真实机器人是**技能的组合**：抓取→交接→插入→擦拭→开门→故障恢复，可能串行、并行、抢占、重试、人在环中改变目标。局部技能各自通过 `J_EMB`，**不蕴含**组合系统安全：前置/后置条件不匹配、资源超卖、交接暂态、隐藏耦合、一个技能的恢复动作破坏另一个技能的不变式，都会让「每个技能都对」变成「合起来错」。**局部证书不会自动组成全局证书。**
>
> 本轮两个灵感正好补两块：
> - **状态隔离**：把状态从「一堆共享变量」升级为 **带所有权、版本、能力、污点、检查点的状态隔离域（SID）**；用能力令牌约束读写，用单写者/版本事务防丢更新，用污点格与隔离区防污染扩散，用原子交接协议消除「双主/无主」缝隙。
> - **技能组合**：把技能从「函数调用」升级为 **带合同、资源账本、失败模式与证书的技能合约（SKC）**；定义串行/并行/抢占/选择/迭代组合算子，用 assume-guarantee 消解假设，用组合风险界把局部风险、干涉、交接、陈旧、漂移逐项记账。
> - **两者交汇**：**隔离是组合的前提，组合是隔离的代价**。隔离减少干涉，却制造状态复制、陈旧、交接暂态与接口税；组合获得能力，却必须为每个接口付「隔离税」。MOSAIC 的核心不是「无限隔离」，而是**在可证明的状态边界上做可证明的技能组合**。
>
> 核心命题：**R72 问「单条具身闭环能否兑现风险界？」R73 追问「当系统由许多各自被认证的技能组成、它们共享一个世界和一个人时，你凭什么相信组合后的系统仍然安全？」** 把 `EMBODIED-GAUGE-RAS` 升级为 **MOSAIC-GAUGE-RAS**（Modular, Ownership-based, State-isolated, Assumption-guaranteed, Interference-certified Composition of GAUGE-RAS）——**状态隔离 × 技能组合的具身计量闭环**。一句话：**先分清谁拥有哪个状态，再谈把哪些技能组合起来。**

## 0. 直觉与动机

**灵感 1（状态隔离不是「多开一个进程」，而是「谁有权改哪个状态」）**
直觉：操作系统里的隔离有三件事——地址空间隔离（看不见）、调度隔离（抢不走）、权限隔离（改不了）。机器人系统常常只做了第一件：把模块拆成不同进程，却仍然通过一个全局 `world_state` 共享内存互相写。真正的状态隔离必须回答三个问题：**(i) 这个状态属于谁？(ii) 谁有读/写/检查点/转移的权利？(iii) 权利何时失效？** 没有能力（capability）约束的共享内存，只是把数据竞争从线程搬到了进程。**隔离的单位不是进程，而是「被所有权与能力包围的状态帧」。**

**灵感 2（四种隔离缺一不可：空间、时间、认知、语义）**
直觉：
- **空间隔离**：技能 A 不能解引用技能 B 的私有内存；共享状态只能通过只读快照或事务写入。
- **时间隔离**：控制域只读某个版本的快照，不能等待计量域；技能切换不能让控制环看见半个更新。
- **认知隔离**：技能 A 的坏后验/坏标定/坏接触假设不能污染技能 B 的证据；不确定度要带「来源」与「污点」，不能合并成一个无出处的数。
- **语义隔离**：即使内存完全隔离，两个技能仍可能通过「同一个世界、同一个人、同一个接触面」发生语义耦合——一个技能把杯子挪了 2cm，另一个技能的抓取前提就失效了。
只做空间隔离会得到「内存安全但语义错误」的系统；只做语义隔离而没有能力边界，则只是文档约定。**MOSAIC 要求隔离等级是一个向量，而不是一个布尔值。**

**灵感 3（技能组合不是「首尾相接」，而是「合同与证书的组合」）**
直觉：把 `grasp()` 和 `handover()` 写成 `grasp(); handover()` 只是调用顺序，不是组合证明。真正的组合需要：`grasp` 的后置条件能推出 `handover` 的前置条件；`grasp` 释放的物体所有权能原子地转给 `handover`；`grasp` 占用的力矩/反应预算加上 `handover` 的不超总预算；`grasp` 对「人手位置」的假设能被 `handover` 的感知保证兑现。任何一条不成立，组合就只是「希望它们能接上」。**技能组合的正确单位是合约，不是代码块。**

**灵感 4（局部证书不会自动组合：三个反例）**
直觉：
- **反例一（资源超卖）**：抓取技能保证「峰值力矩 ≤ 20 N·m」，交接技能也保证「峰值力矩 ≤ 20 N·m」，但两者并行时峰值相加为 40 N·m，超过关节上限。局部都真，组合为假。
- **反例二（交接暂态）**：两个技能都保证稳态误差 ≤ 1mm，但切换瞬间目标位置跳变 5cm，控制器的微分项产生冲击。局部证书只覆盖各自稳态，不覆盖「交接窗口」。
- **反例三（隐藏耦合）**：视觉抓取技能与触觉擦拭技能内存完全隔离，但擦拭把物体表面弄湿，视觉反光改变，抓取技能的后验失效。**内存隔离挡不住世界耦合。**
因此组合证书必须显式增加：资源账本、交接证明、干涉界、语义耦合检查。**「各自正确」是最容易被误认为「整体正确」的幻觉。**

**灵感 5（隔离有税：状态复制、陈旧、交接与接口）**
直觉：隔离不是免费的。每个技能维护自己的估计器，就会产生**状态复制**；每个技能只读自己的快照，就会产生**陈旧**；每次切换都要**冻结-验证-转移-恢复**，就会产生**交接延迟**；每个共享变量都要走能力检查，就会产生**接口开销**。隔离度越高，干涉越小，但税越重。**MOSAIC 不追求「最大隔离」，而追求「在给定风险预算下，隔离税与干涉风险的最优交换」。**

**灵感 6（脏状态会传染，必须 quarantine 而不是「相信它」）**
直觉：一次 IVG 否决、一次碰撞、一次校准失效、一次人的不信任，都会让某个状态变量变成「脏」的。脏状态最危险的地方不是它错，而是它**看起来仍然是一个正常的数**，会被下一个技能当成干净输入。必须给状态打**污点标签**，定义污点格与传播规则；被污染的状态不能跨域使用，只能进入隔离区，由具备恢复证书的技能从最后一个干净检查点重建。**安全系统要能说「这块状态我现在不信」，而不是继续用它算一个漂亮的 λ。**

**灵感 7（最危险的缝隙是「没人拥有」的交接窗口）**
直觉：技能切换时，源技能已经停止写执行器，目标技能还没准备好，这段窗口里**执行器状态无人拥有**。另一个常见错误是「双主」：源技能还没释放，目标技能已经开始写，两个控制器同时发力。正确的做法是让**安全内核在交接窗口临时拥有执行器状态**，执行保持/阻尼/零力矩的安全动作；所有权通过两阶段提交原子转移，版本单调，旧能力立即失效。**交接不是两个技能的事，是第三个「安全所有者」的事。**

**灵感 8（组合风险不是局部风险的加法）**
直觉：如果两个技能完全隔离、无共享可写状态、无资源重叠、无语义耦合，组合风险可以近似相加；否则必须加三项：**干涉风险**（共享状态/共享执行器/共享人）、**交接风险**（暂态、双主、无主、初始化偏差）、**陈旧风险**（隔离导致的世界观过期）。再加一项**漂移风险**（技能运行久了，意图/接触/标定漂移使局部证书失效）。**组合证书的价值不在于给一个更小的数，而在于把「加法不成立」的地方逐项显式记账。**

**灵感 9（状态隔离也可能是「自信地错」的来源）**
直觉：如果每个技能都只相信自己的私有状态，系统可能分裂成多个互不一致的世界观：视觉技能认为杯子在左边，触觉技能认为已经抓住，交接技能认为物体还在桌上。它们各自都「内部一致」，但组合起来是幻觉。**隔离必须配一个共享的、可追溯的世界快照与一致性检查，否则隔离会制造「局部正确、全局分裂」。** 这就是「隔离诱导的发散」（isolation-induced divergence）。

## 1. 形式化定义（增量：定义 366–390）

**定义 366（MOSAIC-GAUGE-RAS 总览与六不变式）** MOSAIC-GAUGE-RAS = (SID, CAP, SKC, HND, QRN, CXR, J_MOS, EMBODIED†)。六不变式：
(i) **状态有主**：每个可写状态变量在任一时刻有且仅有一个所有者（或处于显式事务中）；无主/双主均为非法；
(ii) **能力中介**：所有跨域读写必须经由能力令牌与安全内核中介，禁止环境权限（ambient authority）；
(iii) **版本单调**：状态版本只增不减；控制域只读快照，绝不等待、绝不回写半更新；
(iv) **污点不洗白**：污染状态未经显式净化/重建不得进入干净域；污点传播单调；
(v) **组合有据**：技能组合必须满足合同良构性、资源账本、假设消解、交接证明与干涉界；局部证书不能直接当全局证书；
(vi) **严格逐指令退化**：隔离失效 ⇒ 隔离污染域并回退 R72；组合失效 ⇒ 只执行最大已认证子图；全部失效 ⇒ R68。**新层只在「状态可隔离、技能可组合」时启用。**

**定义 367（状态分类与状态帧）** 系统状态分为六个平面：
- **W（世界平面）**：`W_t = (s_t, b_t(s,z), O_t, H_t, t, ver)`，世界状态、联合后验、障碍集、人类意图/情感；对技能**只读**，由 BSE/IRL/AURA 统一发布；
- **S_i（技能私有平面）**：技能 i 的控制器状态、规划器状态、局部估计残差、接触假设、局部计数器；仅所有者可写；
- **C（协调平面）**：所有权表 `Ω`、任务图、租约、资源账本、版本表；仅经事务写；
- **H（人类平面）**：意图后验 `b_t(z)`、情感 `ψ`、信任；由 IRL/AURA 写，技能只读，任何技能不得直接改人的意图；
- **K（安全平面）**：障碍集增量、碰撞事件、隔离区、污点、全局速度/力矩帽；**只增不减**，由安全内核写；
- **A（执行器平面）**：最近指令 `u_{t-1}`、阻抗参数、接触模式、关节状态；任一时刻单一写者，交接窗口由安全内核持有。
状态帧 `F_i = (R_i, Wr_i)`，`R_i` 为技能 i 可读变量集，`Wr_i` 为可写变量集；`Wr_i ⊆ S_i ∪ {租约内的 C/A 变量}`。

**定义 368（状态隔离域 SID）** `SID_i = (id_i, owner_i, F_i, ver_i, epoch_i, τ_i, ckpt_i, cap_policy_i, iso_i)`：
- `owner_i`：当前拥有写权限的技能/恢复器/安全内核；
- `ver_i`：单调版本号；每次成功写入 +1；
- `epoch_i`：所有权纪元；交接/撤销时 +1，旧能力立即失效；
- `τ_i`：污点标签（定义 372）；
- `ckpt_i`：最近干净检查点 `(ver, digest, state_blob, provenance)`；
- `cap_policy_i`：允许的读/写/检查点/转移/撤销能力集合；
- `iso_i`：隔离等级向量（定义 370）。
**不变量**：`Wr` 在任一时刻最多由一个有效能力持有；`ver` 单调；`epoch` 单调；检查点只能由具备 `checkpoint` 能力的实体创建。

**定义 369（能力令牌与权限中介）** 能力 `κ = (sid, rights, epoch, lease_expiry, mac)`，`rights ⊆ {read, write, checkpoint, transfer, revoke, quarantine, recover}`。访问判定：
`Access(κ, op, var) = 1 ⇔ var ∈ SID(κ.sid) ∧ op ∈ κ.rights ∧ epoch(κ)=epoch(SID) ∧ now ≤ lease_expiry ∧ MAC_valid(κ)`。
**无环境权限**：技能代码只能持有显式传入的能力，不能凭全局名字/路径/指针访问状态。安全内核持有能力表与 epoch 生成器；撤销 `revoke(sid)` 使该 SID 的所有旧能力失效。**能力不是「建议」，是唯一入口。**

**定义 370（隔离等级向量与组合门槛）** `iso(i,j) = (ℓ_mem, ℓ_time, ℓ_epi, ℓ_auth, ℓ_sem)`，各分量 ∈ {0,1,2}：
- `ℓ_mem`：0 共享可变内存 / 1 进程地址空间隔离+只读共享 / 2 硬件保护域+显式 IPC；
- `ℓ_time`：0 无版本无租约 / 1 版本化快照+租约 / 2 实时域+截止时间+版本一致性证明；
- `ℓ_epi`：0 共享后验/标定 / 1 证据带来源与污点 / 2 每技能独立估计器+外部审计+污点格；
- `ℓ_auth`：0 无所有权 / 1 单写者+能力 / 2 原子交接+纪元撤销+安全内核兜底；
- `ℓ_sem`：0 无帧/单位/意图约定 / 1 显式状态帧与单位 / 2 语义耦合监控+一致性检查。
**门槛**：非干涉技能组合要求 `iso(i,j) ⊒ (1,1,1,1,1)`；存在共享可写状态要求 `ℓ_auth=2`；存在人/环境语义耦合要求 `ℓ_sem=2`；控制域相关技能要求 `ℓ_time=2`。**隔离等级是向量，任何一维为零都可能让其余维度失效。**

**定义 371（单写者与版本事务）** 状态写操作
`write(κ, var, expected_ver, delta) → (ok, new_ver)`，
若 `expected_ver ≠ ver(var)` 或能力无效，则拒绝（冲突）。成功则 `ver(var) += 1`，写入记录 `(writer, epoch, ver, provenance)`。
**性质**：在能力不可伪造、所有访问经内核、单写者不变量成立的前提下，不存在丢失更新；跨技能写只能通过 `transfer` 或协调事务。**版本不是装饰：它是「你读到的世界」与「你写回的世界」之间的契约。**

**定义 372（污点格与传播）** 污点格 `𝕋 = {⊥ clean ≺ suspect ≺ contaminated ≺ quarantined}`（偏序，join = max）：
- `suspect`：审计指标接近阈值、校准将过期、快照年龄偏大；
- `contaminated`：IVG 否决、估计不一致、接触模式误判、碰撞事件影响；
- `quarantined`：已隔离，禁止跨域读，只允许恢复器访问。
传播规则：
`τ(y) = ⊔_{x ∈ inputs(y)} τ(x) ⊔ τ_source(y)`；
任何从 `contaminated/quarantined` 到干净域的边必须经过**净化事件** `Decon(x)`（重新从干净证据估计、或重置到安全先验、或由恢复技能重建），并生成新的 `provenance` 与证书。**污点只能通过显式净化下降，不能通过「再算一遍」自动消失。**

**定义 373（隔离区 QRN 与检查点回滚）** 当 SID 失效（能力冲突、版本断层、污点越界、IVG 否决）时，安全内核执行：
1. `freeze(SID)`：撤销写能力，冻结版本；
2. `quarantine(SID, τ=quarantined)`：禁止其他技能读取，只保留恢复能力；
3. `restore(ckpt)`：从最近干净检查点恢复私有状态；
4. `reconcile(W_t)`：用当前世界快照重新初始化，执行无扰切换（定义 388）；
5. `resume`：只有在恢复证书 `J_rec` 有效后才重新授予能力。
**回滚不是「时光倒流」**：世界状态无法回滚，只能把技能私有状态对齐到当前世界。**回滚的目标是「重新成为一个诚实的观察者」，不是「假装什么都没发生」。**

**定义 374（技能合约 SKC）** 技能 i 的合约
`C_i = (ι_i, ρ_i, R_i^F, W_i^F, A_i, G_i, B_i, E_i, J_i)`：
- `ι_i`：接口类型（输入/输出变量、单位、坐标系、时间戳语义）；
- `ρ_i = (pre_i, post_i, inv_i)`：前置/后置/不变式；
- `R_i^F, W_i^F`：读/写状态帧；
- `A_i`：对世界、人类、其他技能、环境的假设（可被其他技能的保证消解）；
- `G_i`：保证向量 `(risk_i, time_i, contact_i, intent_i, state_i, post_i)`；
- `B_i`：资源账本 `(cpu, torque, force, reaction_budget, attention, energy, workspace)`；
- `E_i`：失败模式与恢复合约（异常、超时、接触失稳、意图漂移、隔离失效）；
- `J_i`：技能证书（定义 381 的局部实例）。
**合约必须声明「在什么假设下、保证什么、消耗什么、失败时怎么办」；没有失败模式的技能不是技能，是赌注。**

**定义 375（技能接口类型与精化）** 接口类型包含状态帧、单位、坐标系、时间戳、接触模式、意图作用域。精化偏序 `C_i ⊑ C_j` 表示 `C_i` 在相同接口下保证更强或假设更弱；组合只允许在精化方向上替换技能（`C_i ⊑ C_i'` 且 `C_i'` 可替换 `C_i`）。**同签名不同语义的技能不能互换；接口类型必须携带语义，而不只是参数个数。**

**定义 376（技能组合算子）**
- **串行** `C_1 ; C_2`：要求 `post_1 ⇒ pre_2`（在共享帧上），`W_1^F ∩ W_2^F = ∅` 或存在原子交接证明；资源 `B_1+B_2 ≤ B_task`；`A_2` 中关于 `C_1` 输出的假设由 `G_1` 消解；组合风险按定义 379 记账。
- **并行** `C_1 ∥ C_2`：要求 `W_1^F ∩ W_2^F = ∅`（或声明共享变量与干涉合约），`iso(1,2) ⊒ (1,1,1,1,1)`；资源按峰值/和（保守取和）不超预算；`A_1` 与 `A_2` 互相消解或由环境保证。
- **抢占/恢复** `C_1 ⊳ C_2`：`C_2` 是恢复/中断技能；要求在 `C_1` 的安全点抢占，`C_1` 的私有状态进入隔离区，`C_2` 不得读 `C_1` 的污染状态；`C_1` 恢复时必须重新验证 `pre_1` 并执行无扰重入。
- **选择** `C_1 | C_2`：守卫 `g_1, g_2` 互斥且覆盖；模式切换必须满足无扰条件（定义 388）；不得在两个技能都不满足守卫时继续执行。
- **有界迭代** `C^{[n]}≤N`：每轮资源、风险、污点单调记账；`N` 有界；终止条件与预算必须显式。
**组合不是语法糖：每个算子都引入新的证明义务。**

**定义 377（组合良构性 W1–W8）** 组合树 `T` 良构当且仅当：
W1 帧兼容：`W_i^F ∩ W_j^F = ∅`，除非有 `handoff` 或 `shared` 合约；
W2 假设消解：每个 `A_i` 的每个假设由 `G_j`、环境模型或人类合约显式兑现；
W3 资源不超卖：任一时刻活跃技能的资源向量之和 ≤ 全局预算（峰值而非均值）；
W4 隔离门槛：`iso(i,j)` 满足定义 370 的门槛；
W5 交接证明：每个边有原子交接协议与无扰界；
W6 污点闭合：组合不引入未经净化的跨域污点边；
W7 终止/有界：迭代有界，抢占不产生活锁，恢复不无限重试；
W8 证书单调：组合不得宣称比局部证书更强，除非有独立证明。
**违反任一条件，组合器必须拒绝，而不是「警告后继续」。**

**定义 378（原子交接协议 HND）** 交接 `Hnd = (src, dst, frame, lease, digest, ε_u, ε_x)`，五阶段：
1. **Quiesce**：源技能到达安全点，停止写 `A`，发布最终检查点；
2. **Freeze**：安全内核冻结 `frame` 的版本，计算 `digest`，临时接管 `A`，执行保持/阻尼/零力矩安全动作；
3. **Validate**：目标技能在只读快照上验证 `pre_dst`、资源、隔离等级、污点、意图/接触前提；
4. **Commit**：两阶段提交：`epoch++`，旧能力撤销，新能力授予，所有权表 `Ω` 原子更新；
5. **Reconcile & Resume**：目标技能用 `W_t` 与源最终状态初始化，满足无扰条件后恢复。
**原子性**：任一时刻 `A` 的所有者集合大小为 1（安全内核或某技能）；不存在双主；交接窗口内安全内核是唯一所有者，因此也不存在无主。**交接的失败模式必须是「回到安全保持」，而不是「两个控制器各说各话」。**

**定义 379（组合风险分解 CXR）** 组合执行的风险上界
`R_comp ≤ Σ_i R_i + Σ_{i<j} I_ij + R_handoff + R_stale + R_drift`，
其中：
- `I_ij = ∫_0^T [p_ij^access(t) + p_ij^taint(t)] · exposure_ij(t) dt` 为干涉项；完全隔离且无共享可写状态时 `I_ij=0`，否则用声明共享变量的保守上界；
- `R_handoff = Σ_h (ε_u,h + ε_x,h + P_abort,h · R_abort,h)`；
- `R_stale = Σ_i ∫_0^T L_i(τ) dτ`，`L_i` 为技能 i 的风险对快照年龄的 Lipschitz 常数；
- `R_drift = Σ_i (R_i^intent-drift + R_i^contact-drift + R_i^calib-drift)`。
**关键**：`Σ R_i` 只在隔离与假设消解成立时可加；否则必须加上四项桥接税。**组合证书不是「更小的风险」，而是「更诚实的风险账本」。**

**定义 380（干涉度量与暴露）** 对技能对 `(i,j)`：
`Exposure_ij(t) = 1[active_i(t) ∧ active_j(t)] · (1 + |W_i^F ∩ W_j^F| + |A_i ∩ A_j| + λ_H·1[共享人类] + λ_O·1[共享障碍/接触面])`；
`p_ij^access` 为访问冲突概率（版本冲突/能力冲突/执行器争用），`p_ij^taint` 为污点跨域概率。**干涉不是「有没有共享变量」的布尔值，而是「共享了什么、共享多久、污染多快」的积分。**

**定义 381（组合证书 J_MOS 与技能证书 J_SKI）**
`J_SKI_i = (J_EMB_i, contract_hash_i, sid_layout_i, cap_policy_hash_i, iso_vector_i, ownership_graph_i, handoff_proof_i, taint_proof_i, interference_bound_i, rec_cert_i, ski_ver)`。
`J_MOS = (J_SKI_1..n, composition_tree, resource_ledger, assumption_discharge, global_iso_proof, global_taint_proof, max_depth, max_width, mos_ver)`。
`Valid(J_MOS) ⇔` 所有 `J_SKI_i` 有效 ∧ 组合树良构（W1–W8）∧ 资源账本不超卖 ∧ 假设全部消解 ∧ 全局隔离/污点证明有效 ∧ 最大子图在预算内 ∧ 交接证明有效 ∧ 安全内核实测哈希匹配。**组合证书必须能回答「哪一条保证来自哪个技能，哪一条来自桥接证明」。**

**定义 382（MOSAIC 运行时架构）**
- **安全内核（SK）**：最高优先级、静态内存、零依赖、<500 行、形式化验证；拥有 `K`、能力表、epoch、隔离区、所有权表 `Ω` 与执行器 `A` 的兜底写权；
- **SID 运行时**：每个技能一个隔离域（进程/容器/保护域），私有内存 + 只读共享快照；技能崩溃不影响其他 SID；
- **状态代理（Broker）**：唯一允许跨域发布只读快照与事务写入 `C` 的组件；版本号单调；写路径必须经能力检查；
- **组合监督器（CS）**：执行技能图，选择最大已认证子图，处理切换、恢复、预算；运行在计量域/感知域，不阻塞控制域；
- **REG 映射**：控制域技能在控制域执行，恢复/组合监督在计量域，感知技能在感知域；每个 SID 映射到 REG 节点/容器/回调组；跨域通信只走无锁环形缓冲或状态代理。
**安全内核是唯一可以「否决」所有其他组件的地方；它不执行技能，只守住所有权与安全平面。**

**定义 383（技能图与最大已认证子图）** 技能图 `G_S = (V_S, E_S, guard, recovery)`，`E_S` 带组合算子与合约义务。执行语义：
- 只在当前守卫满足且目标技能证书有效时进入；
- 组合失败/证书撤销/污点越界时，立即收缩到**最大已认证子图** `G* ⊆ G_S`，`G*` 中所有边合同良构、所有技能有效、预算可行；
- 若 `G*` 只剩安全停止技能，则进入 R68。
**最大已认证子图不是「最优计划」，而是「当前仍可证明安全的最大计划」。**

**定义 384（MOSAIC 指标 M²-MIB）** 在 R72 E-MIB 上新增：
- **隔离族**：跨域访问违规数、共享可写变量数、所有权冲突数、版本断层/快照年龄、污点传播长度、隔离区数量、回滚成功率、交接延迟、切换不连续量、状态复制率；
- **组合族**：合同消解率、未消解假设数、资源超卖次数、干涉界与实测差、组合风险与实测差、切换失败率、组合树深度/宽度、恢复覆盖率、最大已认证子图收缩比；
- **分裂族**：多技能世界观不一致度（同一物体位姿的跨 SID 分歧）、语义耦合漏报率、隔离诱导的发散事件。
所有指标遵循定义 332 六元组 `(φ,m,u,D,τ,I⊥)` 与定义 333 DAG 分层（V/L/G/A）。

**定义 385（MOSAIC IVG 门控 M-IVG）** 新增失效条件：
- **隔离失效**：能力违规、所有权冲突、版本断层超限、跨域污点、检查点摘要不匹配、交接中止超限、隔离等级低于门槛；
- **组合失效**：假设未消解、资源超卖、干涉超界、组合深度/宽度超限、局部证书过期/撤销、语义帧不匹配（单位/坐标/意图作用域）、最大已认证子图为空；
- **分裂失效**：跨 SID 世界观不一致度超阈、语义耦合漏报、隔离诱发发散。
任一成立 ⇒ 相关 SID 进入隔离区，组合监督器收缩到 `G*`；隔离/组合同时失效 ⇒ R72/R68。**不得用「提高隔离等级」来掩盖语义耦合，也不得用「更多技能」来补偿单技能证书失效。**

**定义 386（严格退化包含链）** 
- 隔离有效 + 组合有效 ⇒ MOSAIC 完整形态；
- 状态隔离失效（能力/版本/污点）⇒ 冻结并隔离受影响 SID，回退到 R72 单闭环（仅使用干净 SID）；
- 技能组合失效（合同/资源/交接）⇒ 只执行最大已认证子图；若子图仅剩安全停止 ⇒ R68；
- 隔离与组合均失效 ⇒ R68（纯视觉/本体开环 + 硬安全包络）；
- 安全内核失效属于 TCB 失效，不在退化链内：直接硬件急停。
**安全侧只增不减：任何退化都保留 R68 的硬安全包络；隔离区只能让状态更不可信，不能让状态更可信。**

**定义 387（威胁模型 AIC-MOS）** `ℰ_MOS = ℰ_EMB × ℰ_state × ℰ_comp`：
- `ℰ_state`：能力伪造/重放、TOCTOU、检查点投毒、回滚攻击、污点洗白、共享内存侧信道、版本号回绕、租约过期竞争、快照重放；
- `ℰ_comp`：合同伪造、假设注入、资源耗尽、组合炸弹（深度/宽度爆炸）、恶意技能替换、交接劫持、恢复技能越权、隐藏共享执行器、语义耦合隐瞒；
- `ℰ_cross`：**证书挑选**——故意选择低隔离等级/弱假设以拿到一张「好看」的组合证书，同时把真实耦合藏在环境或人身上；**隔离-组合串谋**——用隔离证书证明「无干涉」，再用组合证书证明「覆盖全部技能」，两边都不覆盖「接口」。
**MOSAIC 的攻击面不在单个技能内部，而在状态边界与组合接口上。**

**定义 388（状态对账与无扰切换）** 技能切换/恢复时的初始化映射 `Init: (W_t, S_src, A_{t-1}) → S_dst`，满足：
- 状态误差 `||x_dst(t0) − x_src(t0−)||_{P_aud^{-1}} ≤ ε_x`；
- 控制不连续 `||u_dst(t0) − u_src(t0−)|| ≤ ε_u`；
- 接触模式一致或显式进入过渡技能 `contact_transition`；
- 若任一不满足，先执行**过渡技能**（减速、阻抗软化、松手重抓、回到安全位），直到满足再恢复。
**无扰不是「没有跳变」，而是「跳变被证明在安全包络内」。**

**定义 389（组合代数与精化）** 在帧不交、假设可消解、资源可加的条件下：
- 串行组合满足结合律（模精化）：`(C1;C2);C3 ⊑ C1;(C2;C3)`；
- 并行组合在帧不交时交换：`C1∥C2 ⊑ C2∥C1`；
- 存在恒等技能 `C_id`（无操作、无资源、无状态写），使 `C_id;C ⊑ C` 且 `C;C_id ⊑ C`；
- 选择在守卫互斥时满足分配律（模资源峰值）；
- 抢占不满足交换律，必须显式建模恢复次序。
**组合代数给出的是「可证明的等价/精化」，不是「看起来等价」。**

**定义 390（隔离债 D_iso 与组合税）** 
`D_iso = α·Dup + β·Stale + γ·Handoff + δ·Interface`，
其中 `Dup` 为状态复制率、`Stale` 为平均快照年龄、`Handoff` 为交接延迟、`Interface` 为能力检查/序列化开销。
组合风险可写为 `R_comp(D_iso) = R_local + I(D_iso) + T(D_iso)`：`I` 随 `D_iso` 增大而减小（隔离降低干涉），`T` 随 `D_iso` 增大而增大（交接/陈旧/接口税）。**因此存在一个「隔离-组合」交换前沿；不存在对所有任务都最优的隔离度。MOSAIC 的工程目标不是最大化隔离，而是把 `D_iso` 放在风险预算的等值线上。**

```python
# IP-295 SID/CAP：状态隔离域与能力令牌（安全内核内，静态内存）
@dataclass(frozen=True)
class Capability:
    sid: str
    rights: frozenset[str]        # read/write/checkpoint/transfer/revoke/quarantine/recover
    epoch: int
    lease_expiry_ns: int
    mac: bytes                    # 由安全内核密钥签发，技能不可伪造

@dataclass
class StateDomain:
    sid: str
    owner: str
    frame_R: frozenset[str]
    frame_W: frozenset[str]
    ver: int
    epoch: int
    taint: str                    # clean/suspect/contaminated/quarantined
    checkpoint: Optional[Checkpoint]
    iso: tuple[int, int, int, int, int]

def access_ok(cap: Capability, op: str, var: str, now_ns: int) -> bool:
    d = KERNEL.domains.get(cap.sid)
    return (d is not None and var in d.frame_R | d.frame_W
            and op in cap.rights and cap.epoch == d.epoch
            and now_ns <= cap.lease_expiry_ns
            and KERNEL.verify_mac(cap))

def write(cap: Capability, var: str, expected_ver: int, delta, now_ns: int):
    if not access_ok(cap, 'write', var, now_ns):
        return Reject('capability')
    d = KERNEL.domains[cap.sid]
    if expected_ver != d.ver:
        return Reject('version_conflict')          # 不覆盖、不猜测
    d.ver += 1
    d.apply(var, delta)
    KERNEL.audit.append((d.sid, var, d.ver, d.epoch, d.taint, now_ns))
    return Ok(d.ver)
```

```python
# IP-296 污点/隔离监控：单调传播 + 隔离区（计量域事件触发，控制域只读）
TAINT_ORDER = {'clean': 0, 'suspect': 1, 'contaminated': 2, 'quarantined': 3}

def taint_join(a: str, b: str) -> str:
    return a if TAINT_ORDER[a] >= TAINT_ORDER[b] else b

def propagate_taint(dag, sources):
    # dag: 数据流图；sources: {var: taint}
    t = dict(sources)
    for v in topological_order(dag):
        for u in dag.predecessors(v):
            t[v] = taint_join(t.get(v, 'clean'), t.get(u, 'clean'))
    return t

def quarantine(sid: str, reason: str):
    d = KERNEL.domains[sid]
    KERNEL.revoke_all(sid)                 # epoch++，旧能力立即失效
    d.taint = 'quarantined'
    KERNEL.safety.append(('quarantine', sid, reason, d.ver, d.epoch))
    KERNEL.executor.hold_safe()            # 安全内核接管执行器
```

```python
# IP-297 SKC：技能合约与静态组合验证（离线/部署期）
@dataclass
class SkillContract:
    name: str
    interface: Interface             # 单位/坐标系/时间戳/接触模式/意图作用域
    pre: Predicate; post: Predicate; inv: Predicate
    read_frame: frozenset[str]; write_frame: frozenset[str]
    assumptions: list[Predicate]
    guarantees: list[Predicate]
    resources: ResourceVector
    failure_modes: dict[str, RecoveryContract]
    cert: SkillCert

def compose_serial(c1: SkillContract, c2: SkillContract) -> Result:
    if not implies(c1.post, c2.pre): return Reject('post/pre mismatch')
    if c1.write_frame & c2.write_frame:
        if not has_handoff_proof(c1, c2): return Reject('frame overlap without handoff')
    if not resource_le(c1.resources + c2.resources, TASK_BUDGET):
        return Reject('resource overcommit')
    if not discharge(c2.assumptions, c1.guarantees, ENV_GUARANTEES):
        return Reject('undischarged assumption')
    if not iso_meets(c1.iso, c2.iso, required=(1,1,1,1,1)):
        return Reject('isolation below threshold')
    return Ok(ComposedContract.build(c1, c2))

def compose_parallel(c1: SkillContract, c2: SkillContract) -> Result:
    if c1.write_frame & c2.write_frame:
        return Reject('shared writer without interference contract')
    if not resource_le(peak_sum(c1.resources, c2.resources), TASK_BUDGET):
        return Reject('peak resource overcommit')
    if not (discharge(c1.assumptions, c2.guarantees, ENV_GUARANTEES)
            and discharge(c2.assumptions, c1.guarantees, ENV_GUARANTEES)):
        return Reject('circular/undischarged assumptions')
    return Ok(ComposedContract.build_parallel(c1, c2))
```

```python
# IP-298 HND：原子交接（两阶段提交 + 安全内核兜底）
def handoff(src: str, dst: str, frame: frozenset[str], eps_u, eps_x):
    s, d = KERNEL.domains[src], KERNEL.domains[dst]
    KERNEL.executor.hold_safe()                  # 先让安全内核成为唯一所有者
    src_ckpt = snapshot(s, frame)
    digest = hash_state(src_ckpt)
    if not validate_preconditions(dst, KERNEL.world.latest()):
        return abort_and_resume(src, 'precondition')
    if not taint_clean(frame) or not iso_meets(s.iso, d.iso, required=(1,1,2,2,1)):
        return abort_and_resume(src, 'isolation')
    KERNEL.txn.begin()

    KERNEL.revoke_all(src)                       # 旧能力全部失效

    KERNEL.grant(dst, frame, rights={'read','write'})
    KERNEL.txn.commit()
    d.init_from(KERNEL.world.latest(), src_ckpt, KERNEL.executor.last())
    if not bumpless(eps_u, eps_x):

    return Ok(d.epoch)
```

```python
def compose_risk(contracts, tree, interference, handoff_cost, stale_cost, drift_cost):
    r_local = sum(c.cert.risk_bound for c in contracts)
    r_inter = sum(interference[(i, j)] for i, j in active_pairs(tree))

    r_drift = sum(drift_cost[c.name] for c in contracts)
```

## 3. 推导

**引理 33（状态隔离的可靠性）** 在以下条件下：(i) 所有状态访问经安全内核中介；(ii) 能力不可伪造且 epoch 撤销立即生效；(iii) 每个可写变量满足单写者不变量；(iv) 写操作带版本检查——则不存在跨 SID 的未授权写、不存在丢失更新、不存在双主写。证明：任何写必须持有有效能力且版本匹配；能力只由安全内核签发，epoch 变更使旧能力失效；单写者不变量排除并发写；版本检查排除基于旧快照的覆盖。系：**「隔离」第一次成为可检查的访问控制属性，而不是模块划分的承诺。**

**引理 34（污点不洗白）** 污点格 `𝕋` 为有限偏序，`⊔` 单调；传播规则对每个数据流边单调不减；净化事件是唯一降低污点的操作且必须生成新 `provenance`。因此任何从 `contaminated` 到 `clean` 的路径必经过显式 `Decon`，不存在「静默洗白」。系：**坏状态不能靠「再算一遍」变成好状态；只能靠「重新从干净证据建立」。**

**引理 35（交接原子性与无扰界）** 在定义 378 的五阶段协议下，安全内核在 `Quiesce` 后、`Resume` 前持有 `A` 的唯一写权；`Commit` 中 `epoch++` 与旧能力撤销、新能力授予在同一事务内完成；`Reconcile` 强制满足 `ε_u, ε_x` 条件。因此：(i) 任一时刻 `A` 无主或双主的时间为零；(ii) 切换不连续量 ≤ `ε_u + ε_x`；(iii) 交接中止只能回到安全保持。系：**最危险的「缝隙」被安全内核这个第三方所有者填上了。**

**引理 36（组合风险上界）** 在 W1–W8 良构、技能局部风险界成立、干涉/交接/陈旧/漂移项按定义 379 记账的条件下，由联合界与 Lipschitz 传播：
`R_comp ≤ Σ_i R_i + Σ_{i<j} I_ij + R_handoff + R_stale + R_drift`。
证明要点：局部风险并集按 Boole 不等式相加；共享状态与共享执行器的交叉事件由 `I_ij` 的积分上界覆盖；交接事件的风险由 `ε_u, ε_x` 与中止概率覆盖；快照年龄通过 `L_i` 线性放大；漂移项由每技能的漂移界相加。系：**组合证书必须携带这五项，不能只报 `Σ R_i`。**

**引理 37（隔离-组合交换前沿）** 令 `D_iso` 为定义 390 的隔离债，`I(D_iso)` 为干涉风险，`T(D_iso)` 为交接/陈旧/接口税。若 `I` 随 `D_iso` 非增、`T` 随 `D_iso` 非减，则 `R_comp = R_local + I(D_iso) + T(D_iso)` 在紧约束下可能存在内点最优；不存在对所有任务都最优的隔离度。系：**「更强隔离总是更好」是错的；正确的目标是「风险预算下的最优隔离度」。**

**引理 38（组合代数的良构性）** 在帧不交、假设可消解、资源可加、精化关系保持合同义务的条件下，串行组合满足结合律（模精化），并行组合在帧不交时交换，存在恒等技能；抢占不交换，必须显式建模恢复次序。证明：逐条展开前置/后置/帧条件，利用 `⊑` 的传递性与资源向量的加法结合律；抢占的恢复次序改变 `A` 的历史，故不交换。系：**组合可以用代数化简，但只有在证明义务被保留时。**

**定理 27（MOSAIC 组合安全性）** 在 A111–A116（安全内核 TCB 正确、能力不可伪造、隔离/污点监控完备、所有技能 `J_SKI` 有效、组合树 W1–W8 良构、`J_MOS` 有效）下，组合执行的风险 ≤ `R_comp`（定义 379），且任一时刻不存在无主/双主执行器写。**证明重量落在「TCB 无漏洞」与「假设消解真实成立」上；证书只覆盖被声明的东西。**

**定理 28（严格包含与退化）** 在隔离/组合监控正常时，关闭 SKC/HND/QRN 任意组合，MOSAIC 逐指令退化为 R72 的单闭环（仅保留干净 SID）；关闭隔离与组合全部层，退化为 R68。且任何有效 MOSAIC 执行的风险界不高于对应 R72 执行。**安全单调不减，能力仅在「状态可隔离、技能可组合」时增加。**

**定理 29（最大已认证子图的安全性与极大性）** 若 `G*` 是当前技能图中满足 W1–W8 且所有证书有效的最大子图，则：(i) 执行 `G*` 的任意策略满足 MOSAIC 风险界；(ii) 不存在严格包含 `G*` 的已认证子图。证明：由 `G*` 的构造取所有可行子图的并，良构性对并封闭（帧/资源/假设逐边检查），极大性由并的定义直接得到。系：**系统在故障时不会「随便挑一个计划」，而是「执行仍可证明安全的最大计划」。**

**定理 30（安全内核非绕过性）** 若所有状态访问都经安全内核、安全内核代码/密钥/能力表未被篡改、硬件急停独立可用，则任何技能（包括恶意/被投毒技能）都不能绕过所有权与隔离检查写执行器或他人状态。**这是 MOSAIC 的信任锚点；它把「组合安全」还原为「一个小内核的正确性 + 每个技能证书的有效性」。**

## 6. 本轮最大风险

**一句话**：MOSAIC 把安全从「单技能证书」转移到「**状态边界与组合接口的证明**」——如果状态帧声明不完整、语义耦合被人/环境/接触面隐藏、交接暂态落在局部证书的盲区，那么每个技能都能各自通过 `J_SKI`、组合树也能通过 W1–W8 静态检查，系统却会在「没人拥有」或「双方都以为自己拥有」的缝隙里发生碰撞、丢物、任务失败，事后审计只看到一串相互盖章的证书，这就是**「隔离得很好、组合起来却错」的组合式虚假保证（compositional false assurance）**。

次级风险与缓解：
1. **状态帧漏报/隐藏耦合** → 运行时数据流追踪 + 语义耦合监控（共享人/障碍/接触面/反光/湿度），未声明耦合即隔离；离线用差分测试主动寻找「内存隔离但世界耦合」的反例。
2. **交接暂态未覆盖** → 强制过渡技能与无扰界 `ε_u, ε_x`；交接窗口由安全内核接管；把交接事件作为独立证书项，不能并入稳态风险。
3. **隔离诱导分裂** → 跨 SID 世界一致性检查（同一物体位姿/接触模式分歧），超阈即要求共享世界快照或重新观测；禁止「各自相信自己的杯子」。
4. **能力/TCB 漏洞** → 安全内核 <500 行、形式化验证、独立硬件急停、能力 MAC/epoch、最小权限；TCB 变更需重新认证所有技能。
5. **组合爆炸** → `|V_S|≤64`、组合深度 ≤8、并行宽度 ≤4、每边一条可复算证明；复杂度本身纳入审计指标。
6. **隔离税拖垮实时性** → 能力检查 O(1)、只读快照、控制域不做组合推理；把组合监督/证书组装全部放在计量域异步执行。
7. **证书挑选/Goodhart** → 隔离等级、风险界、资源账本、语义耦合联合审计；禁止只优化单一指标；用 E395 主动寻找「证书好看但系统更脆」的配置。

> - **技能组合（SKC/HND/CXR）**：技能合约包含接口/前后置/读写帧/假设/保证/资源/失败模式/证书；定义串行、并行、抢占、选择、有界迭代算子与 W1–W8 良构性；原子交接五阶段；组合风险显式分解为局部+干涉+交接+陈旧+漂移。
> - **两者交汇**：`J_MOS` 组合证书；最大已认证子图；隔离-组合交换前沿 `D_iso`；严格退化到 R72/R68。
>
> 核心命题：**从「单闭环是否兑现风险界」进化为「由多个各自被认证的技能组成、共享一个世界和一个人的系统，组合后是否仍然安全？」** 一句话：**先分清谁拥有哪个状态，再谈把哪些技能组合起来。**

## 2. 形式化定义（要点版）

**定义 366（MOSAIC 总览与六不变式）** 状态有主、能力中介、版本单调、污点不洗白、组合有据、严格逐指令退化。见想法区。

**定义 367（六状态平面）** `W` 世界（只读）、`S_i` 技能私有（单写者）、`C` 协调（事务）、`H` 人类（IRL/AURA 写、技能只读）、`K` 安全（只增不减）、`A` 执行器（单一写者，交接窗口由安全内核持有）。**技能不得直接改人的意图，也不得直接写他人私有状态。**

**定义 368（SID）** 每个 SID 携带 owner/frame/ver/epoch/taint/checkpoint/cap_policy/iso。`Wr` 任一时刻至多一个有效能力持有；`ver`、`epoch` 单调；检查点只能由具备 `checkpoint` 能力者创建。

**定义 369（能力与权限中介）** `Access(κ,op,var)=1 ⇔ var∈SID ∧ op∈rights ∧ epoch 匹配 ∧ 租约未过期 ∧ MAC 有效`。能力是唯一入口，禁止环境权限；`revoke` 使旧能力立即失效。**能力不是建议，是访问控制的全部。**

**定义 370（隔离等级向量与门槛）** `iso=(ℓ_mem,ℓ_time,ℓ_epi,ℓ_auth,ℓ_sem)`，各维 0/1/2。非干涉组合要求 `⊒(1,1,1,1,1)`；共享可写要求 `ℓ_auth=2`；人/环境语义耦合要求 `ℓ_sem=2`；控制域要求 `ℓ_time=2`。**任一维为零都可能让其余维失效。**

**定义 371（单写者与版本事务）** `write(κ,var,expected_ver,delta)` 在能力有效且版本匹配时成功，`ver+=1`；否则拒绝。**版本是「读到的世界」与「写回的世界」之间的契约。**

**定义 372（污点格与传播）** `τ(y)=⊔_{x∈inputs(y)}τ(x) ⊔ τ_source(y)`；`contaminated/quarantined` 到干净域的边必须经过 `Decon`。**再算一遍不等于洗干净。**

**定义 373（隔离区与检查点回滚）** `freeze→quarantine→restore(ckpt)→reconcile(W_t)→resume`。回滚只回滚技能私有状态，不回滚世界；目标是「重新成为诚实的观察者」。

**定义 374（技能合约 SKC）** `(ι,ρ,R^F,W^F,A,G,B,E,J)`。合约必须声明假设、保证、资源、失败模式；没有失败模式的技能不是技能，是赌注。

**定义 375（接口类型与精化）** 接口携带单位/坐标/时间戳/接触模式/意图作用域；`C_i⊑C_j` 表示保证更强或假设更弱；同签名不同语义不可互换。

**定义 376（组合算子）** 串行要求 `post_1⇒pre_2`、帧不交或交接证明、资源不超卖、假设消解；并行要求帧不交/干涉合约、隔离门槛、峰值资源不超卖；抢占进入隔离区并显式恢复；选择要求守卫互斥+无扰；迭代有界。**每个算子都引入新证明义务。**

**定义 377（W1–W8 良构性）** 帧兼容、假设消解、资源不超卖、隔离门槛、交接证明、污点闭合、有界终止、证书单调。违反任一 ⇒ 组合器拒绝，不许「警告后继续」。

**定义 378（原子交接 HND）** 六阶段：Quiesce→Freeze→Validate→Commit→Reconcile→Resume。`Commit` 中 `epoch++`、旧能力撤销、新能力授予原子完成；交接窗口安全内核唯一拥有 `A`。**因此无双主、无无主。**

**定义 379（组合风险 CXR）** `R_comp ≤ ΣR_i + ΣI_ij + R_handoff + R_stale + R_drift`。局部风险只有在隔离与假设消解成立时才可加；否则加桥接税。**组合证书不是更小的风险，而是更诚实的账本。**

**定义 380（干涉度量）** `Exposure_ij=1[both active]·(1+|共享写帧|+|共享执行器|+λ_H·共享人类+λ_O·共享障碍/接触面)`；`I_ij=∫[p_access+p_taint]·Exposure dt`。**干涉是积分，不是布尔值。**

**定义 381（J_SKI 与 J_MOS）** `Valid(J_MOS) ⇔` 所有 `J_SKI` 有效 ∧ W1–W8 ∧ 资源不超卖 ∧ 假设消解 ∧ 隔离/污点证明 ∧ 交接证明 ∧ TCB 哈希匹配。**每条保证必须可追溯到局部证书或桥接证明。**

**定义 382（运行时架构）** 安全内核（最高优先级、静态内存、<500 行、形式化验证）拥有 `K/能力表/epoch/Ω/A` 兜底；SID 运行时（进程/容器/保护域）；状态代理（只读快照+事务写）；组合监督器（计量/感知域）；REG 映射。**安全内核不执行技能，只守所有权与安全平面。**

**定义 383（技能图与最大已认证子图）** 只在守卫满足且证书有效时进入；故障时收缩到 `G*`；`G*` 为空则 R68。**最大已认证子图不是最优计划，而是当前仍可证明安全的最大计划。**

**定义 384（M²-MIB 指标）** 隔离族（违规/共享写变量/所有权冲突/版本断层/污点传播/隔离区/回滚/交接延迟/不连续量/复制率）、组合族（假设消解/超卖/干涉界/风险差/切换失败/深度宽度/恢复覆盖/收缩比）、分裂族（跨 SID 世界观分歧/语义耦合漏报/隔离诱导发散）。同遵循定义 332 六元组与定义 333 DAG 分层。

**定义 385（M-IVG 门控）** 隔离失效（能力/所有权/版本/污点/检查点/交接/隔离等级）、组合失效（假设/资源/干涉/深度/证书/语义帧/空子图）、分裂失效（世界观分歧/语义漏报）。任一成立 ⇒ 隔离 + 收缩 `G*`；同时失效 ⇒ R72/R68。**不得用更高隔离掩盖语义耦合，也不得用更多技能补偿单技能失效。**

**定义 386（严格退化链）** 隔离+组合有效 ⇒ MOSAIC；隔离失效 ⇒ 隔离 SID + R72；组合失效 ⇒ `G*`；两者失效 ⇒ R68；TCB 失效 ⇒ 硬件急停。**安全侧只增不减。**

**定义 387（威胁模型 AIC-MOS）** `ℰ_MOS=ℰ_EMB×ℰ_state×ℰ_comp`。状态：能力伪造/重放、TOCTOU、检查点投毒、回滚攻击、污点洗白、侧信道、版本回绕、租约竞争、快照重放。组合：合同伪造、假设注入、资源耗尽、组合炸弹、恶意技能替换、交接劫持、恢复技能越权、隐藏共享执行器、语义耦合隐瞒。交叉：证书挑选、隔离-组合串谋。**攻击面不在技能内部，在状态边界与组合接口。**

**定义 388（对账与无扰切换）** `Init:(W_t,S_src,A_{t-1})→S_dst`，满足 `||x_dst−x_src||_{P^{-1}}≤ε_x`、`||u_dst−u_src||≤ε_u`、接触模式一致或进入过渡技能；否则先减速/软化/重抓。**无扰不是无跳变，而是跳变在安全包络内。**

**定义 389（组合代数）** 帧不交时串行结合、并行交换、恒等技能存在；抢占不交换，必须显式恢复次序；选择在守卫互斥时分配（模资源峰值）。**组合可化简，但只能在证明义务被保留时。**

**定义 390（隔离债与组合税）** `D_iso=αDup+βStale+γHandoff+δInterface`；`R_comp(D_iso)=R_local+I(D_iso)+T(D_iso)`，`I` 非增、`T` 非减 ⇒ 存在内点最优。**「更强隔离总是更好」是错的。**

```python
# IP-295 SID/CAP：状态隔离域 + 能力令牌（安全内核，静态内存，<500 行）
@dataclass(frozen=True)
class Capability:
    sid: str
    rights: frozenset[str]       # read/write/checkpoint/transfer/revoke/quarantine/recover
    epoch: int
    lease_expiry_ns: int
    mac: bytes

@dataclass
class StateDomain:
    sid: str; owner: str
    frame_R: frozenset[str]; frame_W: frozenset[str]
    ver: int; epoch: int; taint: str
    checkpoint: Optional[Checkpoint]
    iso: tuple[int, int, int, int, int]

def access_ok(cap, op, var, now_ns):
    d = KERNEL.domains.get(cap.sid)
    return (d and var in (d.frame_R | d.frame_W)
            and op in cap.rights and cap.epoch == d.epoch
            and now_ns <= cap.lease_expiry_ns and KERNEL.verify_mac(cap))

def write(cap, var, expected_ver, delta, now_ns):
    if not access_ok(cap, 'write', var, now_ns): return Reject('capability')
    d = KERNEL.domains[cap.sid]
    if expected_ver != d.ver: return Reject('version_conflict')
    d.ver += 1; d.apply(var, delta)
    KERNEL.audit.append((d.sid, var, d.ver, d.epoch, d.taint, now_ns))
    return Ok(d.ver)              # 不覆盖、不猜测
```

```python
# IP-296 QRN/Taint：污点单调传播 + 隔离区 + 检查点回滚
TAINT_ORDER = {'clean': 0, 'suspect': 1, 'contaminated': 2, 'quarantined': 3}

def taint_join(a, b):
    return a if TAINT_ORDER[a] >= TAINT_ORDER[b] else b

def propagate_taint(dag, sources):
    t = dict(sources)
    for v in topological_order(dag):
        for u in dag.predecessors(v):
            t[v] = taint_join(t.get(v, 'clean'), t.get(u, 'clean'))
    return t

def quarantine(sid, reason):
    d = KERNEL.domains[sid]
    KERNEL.revoke_all(sid)        # epoch++，旧能力立即失效
    d.taint = 'quarantined'
    KERNEL.safety.append(('quarantine', sid, reason, d.ver, d.epoch))
    KERNEL.executor.hold_safe()

def recover(sid, rec_skill):
    d = KERNEL.domains[sid]
    if d.checkpoint is None: return Reject('no_clean_checkpoint')
    if not rec_skill.cert.valid: return Reject('recovery_cert')
    d.restore(d.checkpoint)
    d.reconcile(KERNEL.world.latest())
    d.taint = 'suspect'          # 恢复后仍需观察，不直接 clean
    return Ok(d.ver)
```

```python
# IP-297 SKC：合约 + W1–W8 组合验证（部署期/离线）
@dataclass
class SkillContract:
    name: str; interface: Interface
    pre: Predicate; post: Predicate; inv: Predicate
    read_frame: frozenset[str]; write_frame: frozenset[str]
    assumptions: list[Predicate]; guarantees: list[Predicate]
    resources: ResourceVector
    failure_modes: dict[str, RecoveryContract]
    cert: SkillCert

def compose_serial(c1, c2):
    if not implies(c1.post, c2.pre): return Reject('post/pre mismatch')
    if c1.write_frame & c2.write_frame and not has_handoff_proof(c1, c2):
        return Reject('frame overlap without handoff')
    if not resource_le(c1.resources + c2.resources, TASK_BUDGET):
        return Reject('resource overcommit')
    if not discharge(c2.assumptions, c1.guarantees, ENV_GUARANTEES):
        return Reject('undischarged assumption')
    if not iso_meets(c1.iso, c2.iso, required=(1,1,1,1,1)):
        return Reject('isolation below threshold')
    return Ok(ComposedContract.build(c1, c2))

def compose_parallel(c1, c2):
    if c1.write_frame & c2.write_frame:
        return Reject('shared writer without interference contract')
    if not resource_le(peak_sum(c1.resources, c2.resources), TASK_BUDGET):
        return Reject('peak resource overcommit')
    if not (discharge(c1.assumptions, c2.guarantees, ENV_GUARANTEES)
            and discharge(c2.assumptions, c1.guarantees, ENV_GUARANTEES)):
        return Reject('circular/undischarged assumptions')
    return Ok(ComposedContract.build_parallel(c1, c2))
```

```python
# IP-298 HND：原子交接（安全内核全程可抢占接管）
def handoff(src, dst, frame, eps_u, eps_x):
    s, d = KERNEL.domains[src], KERNEL.domains[dst]
    KERNEL.executor.hold_safe()               # 先确保唯一所有者
    src_ckpt = snapshot(s, frame)
    if not validate_preconditions(dst, KERNEL.world.latest()):
        return abort_and_resume(src, 'precondition')
    if not taint_clean(frame) or not iso_meets(s.iso, d.iso, (1,1,2,2,1)):
        return abort_and_resume(src, 'isolation')
    KERNEL.txn.begin()
    s.epoch += 1; d.epoch += 1
    KERNEL.revoke_all(src)
    KERNEL.ownership[frame] = dst
    KERNEL.grant(dst, frame, rights={'read','write'})
    KERNEL.txn.commit()
    d.init_from(KERNEL.world.latest(), src_ckpt, KERNEL.executor.last())
    if not bumpless(eps_u, eps_x):
        return run_transition_skill(src, dst) # 减速/软化/松手重抓
    KERNEL.executor.release_to(dst)
    return Ok(d.epoch)
```

```python
# IP-299 CXR：组合风险与 J_MOS（部署期 + 计量域增量）
def compose_risk(contracts, tree, interference, handoff_cost, stale_cost, drift_cost):
    return (sum(c.cert.risk_bound for c in contracts)
            + sum(interference[(i, j)] for i, j in active_pairs(tree))
            + sum(handoff_cost[e] for e in handoff_edges(tree))
            + sum(stale_cost[c.name] for c in contracts)
            + sum(drift_cost[c.name] for c in contracts))

def make_jmos(contracts, tree, ledger, proofs):
    assert all(c.cert.valid for c in contracts)
    assert well_formed(tree, W1_W8=ALL)
    assert ledger.peak() <= GLOBAL_BUDGET
    assert all_assumptions_discharged(tree)
    assert global_taint_closed(tree)
    assert isolation_meets_all_edges(tree)
    return JMOS(contracts, tree, ledger, proofs, ver=MOS_VER)
```

```python
    if not M.caps.access_ok(active, 'read', 'world', M.now()):
        return M.safety.stop('world_capability')
    lam = lam_AEG(snap.b_t, snap.audit, snap.tac, M.risk_params)
    A = active.policy(snap.b_t, M.private[active], lam)
    k = active.certified_prefix(A, lam, snap, M.safety)
    M.executor.publish(k, lam)                 # 安全内核验证所有权后放行
    M.executor.record(M.now(), k, lam, M.rtm.wcet())

    # ---- 计量域 20–50Hz ----
    if M.clock.due_metric():
        M.taint = propagate_taint(M.dataflow, M.taint_sources)
        if M.ivg.isolation_invalid(M.taint, M.caps, M.ownership):
            quarantine(M.ivg.offending_sid(), M.ivg.reason)
            M.supervisor.shrink_to_max_certified_subgraph()
        if M.ivg.composition_invalid(M.contracts, M.tree, M.ledger):
            M.supervisor.shrink_to_max_certified_subgraph()
        if M.supervisor.graph_empty(): M.mode = 'R68'
        M.broker.publish(W_t.next(M.bse, M.irl, M.aura))
        M.jmos = make_jmos(M.contracts, M.tree, M.ledger, M.proofs)

    # ---- 感知域 30–100Hz ----
    M.aura.update(events.audio)
    M.irl.update(events.intent_obs)
    M.dmem.update(events.tac_frame, M.executor.last())
    return M.executor.last(), M.jmos, M.mode
```

## 4. 推导

**引理 33（状态隔离可靠性）** 所有访问经内核、能力不可伪造、单写者、版本检查 ⇒ 无未授权跨 SID 写、无丢失更新、无双主写。证明：有效性判定排除无效能力；版本匹配排除旧快照覆盖；单写者排除并发写。系：**隔离成为可检查的访问控制属性。**

**引理 34（污点不洗白）** 污点格有限偏序、传播单调、净化唯一降污点且生成 provenance ⇒ 不存在静默洗白。系：**坏状态只能从干净证据重建。**

**引理 35（交接原子性与无扰界）** 安全内核在 Quiesce→Resume 间唯一拥有 `A`；Commit 原子撤销/授予；Reconcile 强制 `ε_u,ε_x` ⇒ 双主/无主时间为零，切换不连续 ≤ ε_u+ε_x，中止回到安全保持。系：**交接缝隙由第三方安全所有者填上。**

**引理 36（组合风险上界）** W1–W8 + 局部风险界 + 五项记账 ⇒ `R_comp ≤ ΣR_i+ΣI_ij+R_handoff+R_stale+R_drift`。由 Boole 不等式、Lipschitz 传播与交接事件界。系：**组合证书必须携带五项，不能只报 ΣR_i。**

**引理 37（隔离-组合交换前沿）** `I(D_iso)` 非增、`T(D_iso)` 非减 ⇒ `R_comp` 可能存在内点最优；不存在对所有任务最优的隔离度。系：**「更强隔离总是更好」是错的。**

**引理 38（组合代数良构性）** 帧不交、假设可消解、资源可加、精化保持义务 ⇒ 串行结合、并行交换、恒等存在；抢占不交换。系：**组合可化简，但证明义务必须保留。**

**定理 27（MOSAIC 组合安全性）** 在 A111–A116（TCB 正确、能力不可伪造、隔离/污点监控完备、所有 `J_SKI` 有效、W1–W8 良构、`J_MOS` 有效）下，组合执行风险 ≤ `R_comp`，且任一时刻无无主/双主执行器写。**证明重量在 TCB 与假设消解上。**

**定理 28（严格包含与退化）** 关闭 SKC/HND/QRN 任意组合，逐指令退化为 R72 单闭环（仅干净 SID）；全部关闭 ⇒ R68；有效 MOSAIC 风险界 ≤ 对应 R72。**安全单调不减。**

**定理 29（最大已认证子图安全且极大）** `G*` 为满足 W1–W8 且证书有效的最大子图 ⇒ 执行 `G*` 满足 MOSAIC 风险界，且不存在严格包含它的已认证子图。**故障时执行仍可证明安全的最大计划。**

**定理 30（安全内核非绕过性）** 所有访问经内核、内核/密钥/能力表未被篡改、硬件急停独立 ⇒ 任何技能（含恶意/投毒）不能绕过所有权与隔离检查写执行器或他人状态。**组合安全还原为「小内核正确 + 每个技能证书有效」。**

## 7. 本轮最大风险

**一句话**：MOSAIC 把安全从「单技能证书」转移到「**状态边界与组合接口的证明**」——如果状态帧声明不完整、语义耦合被人/环境/接触面隐藏、交接暂态落在局部证书的盲区，那么每个技能都能各自通过 `J_SKI`、组合树也能通过 W1–W8 静态检查，系统却会在「没人拥有」或「双方都以为自己拥有」的缝隙里发生碰撞、丢物、任务失败，事后审计只看到一串相互盖章的证书，这就是**「隔离得很好、组合起来却错」的组合式虚假保证（compositional false assurance）**。

次级风险与缓解：
1. **状态帧漏报/隐藏耦合** → 运行时数据流追踪 + 语义耦合监控（共享人/障碍/接触面/反光/湿度），未声明耦合即隔离；离线差分测试主动找「内存隔离但世界耦合」反例。
2. **交接暂态未覆盖** → 强制过渡技能与 `ε_u,ε_x`；交接窗口由安全内核接管；交接作为独立证书项，不并入稳态风险。
3. **隔离诱导分裂** → 跨 SID 世界一致性检查（同一物体位姿/接触模式分歧），超阈要求共享快照或重新观测；禁止「各自相信自己的杯子」。
4. **能力/TCB 漏洞** → 安全内核 <500 行、形式化验证、独立硬件急停、能力 MAC/epoch、最小权限；TCB 变更需全量重新认证。
5. **组合爆炸** → `|V_S|≤64`、深度 ≤8、并行宽度 ≤4、每边一条可复算证明；复杂度纳入审计指标。
6. **隔离税拖垮实时性** → 能力检查 O(1)、控制域只读快照、组合推理全部放计量域异步；证书组装不阻塞控制环。
7. **证书挑选/Goodhart** → 隔离等级、风险界、资源账本、语义耦合联合审计；禁止只优化单一指标；用 E395 主动寻找「证书好看但系统更脆」的配置。
