# 第 4 轮（灵感驱动研究循环·新灵感二元组第 1 轮；本轮灵感：「开源硬件」×「跨任务泛化」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21+IP-425–430（语义-合规层 SDC/CAC/DCL/GIC/HPC+/CFC+；其上承 v20 联邦感知证书 PCA/CTS/CFC/HPC/CFCtrl 与 v19/v17 全链）。
> 本轮纪律：**硬件配置是证书的第一等作用域；任务上下文是证书的第一等作用域；泛化是缩小有效域而非放大承诺**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 全部保留。本轮只做一件事：**给 v21 的每张证书补上"在什么硬件上、对什么任务、能活多久"的溯源-迁移作用域，把跨单元与跨任务的证书复用形式化为带证明的保守迁移算子，并封堵 v21 最大风险（κ_c 在异构硬件/新任务上的系统性失效）**。

## 0. 直觉与动机

**灵感 1（开源硬件 → 溯源是证书缺失的第三维：从"信任厂商"到"审计配置"）**
直觉：v21 隐含假设"硬件固定、标定可信"。开源硬件的现实恰好相反：机器人由社区 BOM 拼装，传感器随时被替换/维修/升级，固件来自各种 fork，没有厂商担保。于是证书最脆弱的失效点不在算法层，而在**硬件边界**——在 A 单元标定出的 CertBox/κ_c/AbsCert 被悄悄复用到 B 单元，形式正确、事实错误，且无人察觉。关键反直觉点：**开源硬件不是让认证更难，而是让认证第一次成为可能**——因为每个部件都能携带可哈希的溯源记录（BOM、固件 commit、标定产物、序列号）。真正危险的不是"异构"，而是"**未被见证的异构**"：不可审计的闭源黑盒，严格劣于可哈希的开源 BOM。核心创新：**硬件溯源与配置见证 (Hardware Provenance & Configuration Attestation, HPCA)**——把 `hw_fp = H(BOM ∥ fw_commit ∥ calib_hash ∥ serials)` 变成证书的显式作用域；硬件变更 ⇒ 证书**显式失效**（fail-safe），而非静默错误。副产物：**校准等价类 Eq_hw(ε_cal)**——同型号 ∧ 固件在认证补丁集内 ∧ 标定差 ≤ ε_cal 的单元可带膨胀共享证书，把"换件即全量重认证"降为"差量重认证"。

**灵感 2（跨任务泛化 → 泛化是缩小有效域，不是放大承诺）**
直觉：跨任务泛化的诱惑是"训练一次、到处部署"；危险是 A 任务的证书被静默套用到 B 任务（不同人体运动模型、不同物体类别、不同速度包络、不同动力参数）而失效。关键反直觉点：**一个真正安全的泛化证书不是"覆盖所有任务"的证书，而是"精确知道自己覆盖哪些任务、并拒绝其余任务"的证书**。安全域对作用域是单调的：作用域越窄越安全，因此"泛化"的正确形式是**缩小有效域 + 带证明的保守迁移**，而非放大承诺。核心创新：**跨任务证书迁移 (Cross-Task Certificate Transfer, CTCT)**——任务签名 `τ_task`、安全相关不变量集 `I`、认证动力包络 `Env_D`；迁移算子 `T(C, τ→τ')` 仅在 `I` 全满足且 `τ' ∈ Env_D` 时把证书重绑定并膨胀 margin，否则返回 `⊥` → 回退最严默认。副产物：**任务族泛化界 (Task-Family Generalization Bound, TFGB)**——用 meta-conformal 给任务族平均违规率以 1-α 覆盖，但**平均值绝不替代最坏值**：族平均只用于分配再验证预算与监控，逐任务安全仍由 `I`/`Env_D` 兜底。

**灵感 3（两者合流 → 组合是唯一出路：异构模块 × 多任务 = 证书代数）**
直觉：开源硬件意味着系统由异构模块拼成，跨任务意味着证书要在不同组合下复用；两者都逼出同一个运算——**证书的组合**。关键反直觉点：组合不是"把证书拼起来就更大"，而是"**接口条件成立才守恒，否则取交（更保守）**"。核心创新：**组合式证书代数 (Compositional Certificate Algebra, CCA)**——`C1 ⊗ C2` 需满足坐标框架对齐 ∧ 标定差 ≤ ε_cal ∧ 新鲜度在 v17 APS 阶梯内；满足则组合证书 sound（margin 取 meet/交），否则 `⊗ = ⊥` 并退化到各分量安全集的交。这样异构舰队与多任务切换都不会偷偷放大执行域。

**三者如何统一**
统一为 **v21 语义-合规层之上的"溯源-迁移"层**：HPCA 回答"这张证书凭什么绑在这台机器上"，PCDA/CTCT 回答"它还能安全复用到哪些单元/任务"，CCA 回答"多张证书如何拼而不放大"。共享状态 `ζ_sem` 扩展为 `ζ_prov = ζ_sem ∪ (Π_hw, hw_fp, Eq_hw, calib_cert, τ_scope, transfer_proofs, compose_proofs)`。统一准入门：**HPC++ = HPC+ ∧ Scope ∧ (Transfer ∨ τ∈τ_scope) ∧ Compose**——只有"几何 SAFE（v21 HPC+）∧ 硬件在作用域内 ∧ 任务在作用域内或迁移有证明 ∧ 组合接口守恒"才进入执行；任一缺失退回 v21 的保守收缩，再退 v20/v19/v18。所有作用域检查都是**单调收缩**：`Exec_v22 = Exec_v21 ∩ Fil_prov ⊆ Exec_v21`。

## 1. 研究问题（轮次升级版）

- **Q1（溯源粒度的等价类）**：`hw_fp` 如何定义，使得任何**安全相关**的硬件变更（换传感器型号、固件补丁、重标定、换镜头）必然改变指纹，而无关变更（外壳颜色、日志文件）不改变？`Eq_hw(ε_cal)` 的等价关系如何证明是**安全保持**的（等价类内共享证书不降低可靠性）？根信任（设备根密钥/测量）被攻破时，整条溯源链如何降级而不制造"认证剧场"？

- **Q2（标定可移植性）**：在什么容差 `ε_cal` 下，单元 u 的 CertBox/ε_loc(s) 可复用到 u'（膨胀多少才仍 sound）？如何在不做逐单元穷举标定的前提下**认证** `ε_cal`（用共享开源标定产物 + 差量标定）？在线漂移如何检测并把误报/漏报都压到可接受，且漂移超限即失效（fail-safe）？社区共享的标定产物如何防投毒（Byzantine 贡献者）？

- **Q3（跨任务迁移的充分条件）**：任务签名 `τ_task` 该捕获哪些安全相关因素？不变量集 `I` 与包络 `Env_D` 在什么意义上是迁移的**充分**条件？如何度量/界定 `I` 的**不完备性**（这是开放世界问题）？迁移如何与 v21 的 GIC 非对称门槛、DCL 义务期限叠加而不互相破坏？族平均界与逐任务最坏界的关系如何形式化，避免"平均掩盖长尾"？

- **Q4（组合与生命周期）**：异构模块证书在什么接口条件下可 sound 组合（坐标系、标定、时序新鲜度）？热插拔换件、固件升级、任务切换三种生命周期事件如何触发"失效—重见证—重迁移"流水线且全程 ≤12ms 控制预算（事件化+缓存+O(1) 查询）？组合失败时的退化（取交）如何保证活性损失可控？

## 2. 设计原则（在 P34–P36 基础上新增 P37–P39）

**P37 溯源绑定律（Provenance Binding）**
每张证书携带显式作用域 `Scope(C) = (hw_fp 或 Eq_hw, τ_scope, [t0,t1])`。证书只在作用域内**有定义**：`C 有效 ⇒ 当前 hw_fp ∈ Scope.hw ∧ τ ∈ Scope.τ_scope ∧ now ∈ Scope.t`。硬件/任务/时间任一越界 ⇒ 证书**失效**，绝不静默复用；未见证的配置一律落入空作用域 ⇒ 保守默认。溯源记录 Merkle 锚定，失效是**语法可判定**的，不依赖运行期猜测。

**P38 迁移保守律（Conservative Transfer）**
迁移算子只允许**带证明地缩小**或**带膨胀地等价**：`T(C, τ→τ') = C'` 仅当 `I(τ')` 全满足 ∧ `τ' ∈ Env_D`，且 `C'.margin ≥ C.margin ⊕ κ_transfer`（膨胀）；否则 `T = ⊥` ⇒ 回退最严默认。故 `Exec_{v22}(τ') ⊆ Exec_{v21}(τ')`。泛化单调：有效域越大，允许集越小；族平均界只用于预算/监控，**不得豁免**不变量检查。

**P39 组合守恒律（Compositional Soundness）**
`C1 ⊗ C2` 仅在接口条件（坐标系对齐 ∧ 标定差 ≤ ε_cal ∧ 新鲜度在 APS 阶梯内）成立时 sound，其内容取 **meet（交）**（保守）；任一接口条件失败 ⇒ `⊗ = ⊥` ⇒ 退化到各分量安全集的交，绝不取并。组合是**单调收缩**运算：`Exec(C1⊗C2) ⊆ Exec(C1) ∩ Exec(C2)`。

## 3. 与基线的接口（如何退化）

- HPCA 失效（溯源不可见证/根信任失守）⇒ 所有证书作用域置空 ⇒ 保守默认（比 v21 更保守）；安全继承方向不变；
- PCDA 失效（标定不可移植/漂移超限）⇒ 退回逐单元全量标定 + 不共享证书 ⇒ 等价 v21（活性下降但不越界）；
- CTCT 失效（不变量/包络不可判定）⇒ 拒绝一切迁移，逐任务重验证 ⇒ 等价 v21 逐任务行为；
- TFGB 失效（族分布漂移）⇒ 关闭族平均，仅用逐任务不变量兜底 ⇒ 更保守；
- CCA 失效（接口条件无法满足）⇒ 不做组合，取各分量安全集的交 ⇒ 比 v21 更保守；
- 全失效 ⇒ 完全回退 v21 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 168）。
- **安全继承**：HPCA 只做作用域裁剪（失效即空域）、PCDA 只膨胀误差界、CTCT 只带证明迁移或拒绝、TFGB 只分配预算、CCA 只取交/拒绝；任意失效都向更保守方向退化。作用域与迁移状态以事件方式接入 v17 APS 新鲜度阶梯，控制路径仅做 O(1) 作用域查询。

## 4. 预期贡献

1. **溯源绑定证书**：首次把"硬件配置指纹 + 任务作用域 + 有效期"提升为证书的第一等作用域，把"换件/升级后的静默错误"转成"语法可判定的显式失效"，使开源硬件从认证负担变成可审计资产；
2. **标定可移植性**：给出 `ε_cal` 容差下的证书跨单元复用与误差膨胀界，把"换件即全量重认证"降为差量重认证，并给出在线漂移失效与开源标定防投毒机制；
3. **跨任务保守迁移**：给出任务签名 + 不变量集 + 动力包络的迁移充分条件与 `⊥` 拒绝语义，明确"泛化=缩小有效域"；给出族平均（meta-conformal）与逐任务最坏（不变量）双层保证，杜绝平均掩盖长尾；
4. **组合式证书代数**：给出异构模块证书的 sound 组合接口条件与 meet 语义，组合失败即退化取交，覆盖热插拔/固件升级/任务切换的生命周期；
5. **统一门 HPC++ 与闭环**：`Exec_v22 = Exec_v21 ∩ Fil_prov ⊆ Exec_v21 ⊆ … ⊆ Exec_v18`，并把 v21 的 κ_c 风险纳入"配置相关召回退化"的显式监控；
6. **开源友好的可审计链**：溯源链可离线复放、标定产物可社区共享但需见证、组合与迁移证明可机械复核。

## 5. 本轮最大风险

**一句话**：迁移的充分性押在**不变量集 I 的完备性**这一开放世界假设上——一个任务可以通过全部不变量与包络检查，却仍因某个**未被建模**的因素（例如一种新的多人协同让位模式、或非刚性物体）而伤人；而溯源链再自洽也抓不到它，因为硬件"完全正确"，于是机器人会在**硬件可审计、迁移有证明、审计全通过**的情况下出事——即"完备性幻觉下的合规迁移"。

# IP-431 Hardware Provenance & Configuration Attestation
@dataclass
class Provenance:
    bom_hash: str
    fw_commit: str
    calib_hash: str
    serials: dict
    sig: bytes                      # 由设备根密钥签名

    def fingerprint(self):
        return H(canonical(self.bom_hash, self.fw_commit,
                           self.calib_hash, self.serials))

class ProvenanceAttestor:
    def __init__(self, trust_roots, eq_registry, ttl_hw=3600):
        self.trust_roots = trust_roots      # 已知根信任集合
        self.eq = eq_registry               # Eq_hw 等价类注册表（merkle 锚定）
        self.ttl_hw = ttl_hw

    def attest(self, unit):
        """验证签名链与 BOM 完整性；失败即空作用域（fail-safe）"""
        if not self._verify_chain(unit.provenance, self.trust_roots):
            return None, "ATTESTATION_FAIL"
        if not self._reproducible_build_ok(unit.provenance):
            return None, "BUILD_UNVERIFIED"
        return unit.provenance.fingerprint(), "OK"

    def scope_ok(self, cert, current_fp):
        """P37：证书仅在 hw_fp 相同或落在其 Eq_hw 等价类内有效"""
        return (cert.scope.hw_fp == current_fp
                or self.eq.contains(cert.scope.eq_id, current_fp))


# IP-432 Portable Calibration & Drift Attestation
class PortableCalibrator:
    def __init__(self, open_artifact, eps_cal, eps_drift, drift_model):
        self.artifact = open_artifact       # 社区共享开源标定产物（需见证）
        self.eps_cal = eps_cal
        self.eps_drift = eps_drift
        self.drift_model = drift_model

    def certify_equivalence(self, u, u_prime):
        """差量标定：返回 ε_cal 若可等价共享，否则 None"""
        if not (u.model == u_prime.model and u.fw in self.artifact.certified_patches):
            return None
        delta = self.artifact.differential_calib(u, u_prime)
        return delta if delta <= self.eps_cal else None

    def certified_error(self, unit, score, t):
        """误差界只膨胀不收缩：ε_loc'(s) = ε_loc(s) + ε_cal + drift(u,t)"""
        return (self._base_eps_loc(unit, score)
                + self.artifact.eps_cal(unit)
                + self.drift_model.estimate(unit, t))

    def detect_drift(self, unit, live_stats, t):
        """在线漂移检测；超过 ε_drift ⇒ 证书失效（fail-safe）"""
        d = self.drift_model.test(self.artifact, unit, live_stats)
        return ("DRIFT_OK" if d <= self.eps_drift else "INVALIDATE"), d

    dynamics: tuple
    def satisfies(self, invariants):
        return all(inv(self) for inv in invariants)

class CertificateTransfer:
    def __init__(self, invariants, envelope, kappa_transfer=1.05):
        self.I = invariants               # 安全相关不变量集
        self.Env = envelope               # 认证动力包络
        self.kappa = kappa_transfer

    def transfer(self, cert, target):
        """P38：仅当不变量全满足 ∧ 目标在包络内才带膨胀迁移，否则 ⊥"""
        if not target.satisfies(self.I):
            return None, "INVARIANT_VIOLATION"
        if not self.Env.contains(target.dynamics):
            return None, "OUT_OF_ENVELOPE"
        return cert.rebind(task=target, margin=self.kappa * cert.margin), "OK"

    def transfer_or_refuse(self, cert, target):
        c, status = self.transfer(cert, target)
        return (c, status) if c is not None else (conservative_default(target), "REFUSED")


# IP-434 Task-Family Generalization Bound（只用于预算/监控）
class TaskFamilyBound:
    def __init__(self, alpha=0.01):
        self.alpha = alpha
        self.scores = []

    def calibrate(self, task_samples):
        self.scores = [self._nonconformity(t) for t in task_samples]
        return self

    def family_coverage(self):
        """族平均：P_{τ~P_fam}(violation) ≤ α，概率 ≥1-α（meta-conformal）"""
        return conformal_quantile(self.scores, self.alpha)

    def budget_hint(self, target):
        """只返回再验证预算/监控频率，绝不返回'免检'"""
        return {"revalidate_every": self._hint(target), "monitor": True}


# IP-435 Compositional Certificate Algebra
class CertificateAlgebra:
    def __init__(self, eps_cal, aps):
        self.eps_cal = eps_cal
        self.aps = aps                    # v17 APS 新鲜度阶梯

    def compose(self, c1, c2):
        """P39：接口条件守恒才组合；内容取 meet；失败返回 ⊥"""
        if not self._frames_align(c1, c2):
            return None, "FRAME_MISMATCH"
        if self._calib_discrepancy(c1, c2) > self.eps_cal:
            return None, "CALIB_MISMATCH"
        if not self.aps.fresh_enough(c1, c2):
            return None, "STALE"
        return ComposedCert(
            scope=self._intersect_scope(c1.scope, c2.scope),
            content=meet(c1.safe_set, c2.safe_set),      # 交 = 保守
            proof=self._combine(c1.proof, c2.proof)), "OK"

    def degrade(self, certs):
        """组合失败：退化到各分量安全集的交（绝不取并）"""
        return meet_all([c.safe_set for c in certs])

## 3. 推导

**引理 163（溯源绑定的可靠性）** 每张证书携带 `Scope = (hw_fp 或 Eq_hw, τ_scope, [t0,t1])`，准入门 HPC++ 以合取方式检查作用域匹配。故若当前配置指纹/任务/时间越出作用域，证书在语法上不可被采用，由之导出的任何计划都无法进入 `Exec_v22`。未见证配置映射为空作用域 ⇒ 保守默认。该保证不依赖运行期对"是否变化"的猜测，只依赖指纹与作用域的相等/成员判定。∎

**引理 164（标定可移植性）** 若单元 u,u' 满足认证标定差 ≤ ε_cal（在关注工作区 W 上），则把 u 的标定用于 u' 时定位误差 ≤ ε_loc + ε_cal，故以 `inflate(b, ε_loc + ε_cal)` 构造的 CertBox 仍以 ≥1-δ 概率包含真物（承接引理 157）。若 `certify_equivalence` 返回 None 或在线漂移 > ε_drift，可移植性判定为 ⊥ ⇒ 全量重标定/保守默认。因此跨单元复用只**膨胀**误差界、绝不收缩，`Obs_t` 仍单调不减。∎

**引理 165（跨任务迁移的可靠性）** 设证书 C 对任务 τ 的允许集为 `S_τ`。若目标 `τ'` 满足不变量集 `I` 且 `τ' ∈ Env_D`，迁移算子返回带膨胀 `κ_transfer` 的 `C'`，其允许集 `S' = S_τ ∩ {τ' 约束}`（膨胀只会再缩小），故 `S' ⊆ S_τ` 且 `S'` 对 `τ'` sound（在不变量/包络所覆盖的因素上）。若 `I` 有任一不满足或 `τ' ∉ Env_D`，`T=⊥` ⇒ 取保守默认 `S_def(τ') ⊆ S_{τ'}`。故 `Exec_v22(τ') ⊆ Exec_v21(τ')`。∎

**引理 166（任务族泛化界，双层）** 设校准任务 `τ_1..τ_n ~ P_fam` 可交换、任务签名条件化后 conformal 非一致性分数在族内可交换，则对 `τ ~ P_fam` 有 `P_τ(violation) ≤ α`（以概率 ≥1-α，族平均覆盖）。但族平均**不蕴含**逐任务安全：单个高违规任务可被平均掩盖。故 TFGB 仅用于分配再验证预算与监控频率，任意 `τ ∈ Env_D` 的最坏情形仍由引理 165 逐任务兜底。二者缺一不可。∎

**引理 167（组合守恒）** 若 `C1,C2` sound 且 SideCond（坐标对齐 ∧ 标定差 ≤ ε_cal ∧ 新鲜度在 APS 阶梯内）成立，则 `C1⊗C2` 对组合系统 sound，其允许集取 `meet(S1,S2) ⊆ S1 ∩ S2`。任一 SideCond 失败 ⇒ `⊗=⊥`，退化到 `meet_all`（各分量安全集的交），仍是保守子集。故组合是单调收缩运算，`Exec(C1⊗C2) ⊆ Exec(C1) ∩ Exec(C2)`，绝不放大执行域。∎

**引理 168（v22 整体安全继承）** 同一几何快照、同一规则库、同一机器人集合下：HPCA 只做作用域裁剪（失效即空域，163）、PCDA 只膨胀误差界（164）、CTCT 只带证明迁移或拒绝（165）、TFGB 只分配预算（166）、CCA 只取交/拒绝（167）。故 `Exec_v22 = Exec_v21 ∩ Fil_prov ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 7. 已知风险与失效模式

1. **不变量集不完备**（最大风险，见第 8 节）：`I` 是有限检查清单，跨任务安全是开放世界属性；未建模因素可使"通过全部不变量"的任务仍不安全。缓解：E819 如实探测、持续扩充 I、拒绝比接受更便宜（P38）、族平均不豁免逐任务检查。
2. **根信任/见证剧场**：若设备根密钥泄漏或固件可谎报 `hw_fp`，溯源链内部自洽但与物理现实脱钩。缓解：可复现构建（E806）、二进制透明、多根交叉见证、受损模拟（E828）如实报告。
3. **开源标定投毒**：社区共享标定产物可能被恶意或错误污染，`ε_cal` 被虚报。缓解：贡献者信誉 + 交叉见证 + 差量标定抽检（E805/E820）。
4. **组合侧条件侵蚀**：大量微小容差违规（标定、时序）叠加可让组合"看似成立"实则越界。缓解：失败即退化取交、容差预算显式化（E813）。
5. **保守性叠加的活性坍缩**：作用域裁剪 + 迁移膨胀 + 组合取交叠加，异构多任务场景活性可能骤降。缓解：等价类与差量重认证减少全量重验（E809/E823），监控活性损失 ≤8%。
6. **生命周期状态错乱**：热插拔/升级/切换事件并发时的作用域竞态。缓解：事件化 + 版本号 + 单调失效（E815/E816）。
7. **隐私与硬件指纹**：溯源记录可能泄露设备身份/位置。缓解：指纹用加盐哈希、最小化外传、仅证书与几何特征出域（承接 v21 E794）。

## 8. 本轮最大风险

**一句话**：跨任务迁移的充分性押在**不变量集 I 的完备性**这一开放世界假设上——一个任务可以通过全部不变量与包络检查，却仍因某个未被建模的因素而伤人；而溯源链再自洽也抓不到它，因为硬件"完全正确"，于是机器人会在硬件可审计、迁移有证明、审计全通过的情况下出事：**"完备性幻觉下的合规迁移"**。
