# 第 43 轮 · 四足移动作业的「末端位姿可达管证书」：接触模式自动机上的浮基误差传播与交接义务（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 证书飞轮）。本轮灵感词「末端位姿」「四足机器人」把证书的**对象**与**载体**同时钉死：对象从关节/速度空间上移到 SE(3) 任务空间——人真正在乎的是夹爪/工具末端在什么位姿、姿态误差多大、会不会蹭到孔壁；载体从「抽象通用机器人」落到四足浮基移动操作——基座会漂、足端会换、接触会断。二者相遇暴露了前 42 轮一直回避的结构性问题：**证书在每一段连续动力学里都 sound，失效却恰恰发生在接触切换的那一瞬**。本轮把「末端位姿管」做成跨接触模式连续的证书对象，并引入「交接义务（handoff obligation）」，把模式切换本身变成**可证、可拒、可调度**的证书行为，而非默认成立的黑箱事件。

## 0. 直觉与动机

**直觉 1（末端位姿 → 把证书搬到人真正在意的地方）**：固定基机械臂的关节空间守卫与任务成功之间隔着一层非线性 FK，这层映射会让「关节都安全」却不「末端到位」，也会让「末端到位」被关节保守界误杀。正确做法是**直接在 SE(3) 里证**：把末端位姿误差参数化到 se(3) 扭曲坐标 ξ = log(T̄⁻¹T)，用一个加权管 Z(t)（平移 m / 旋转 rad 分别归一）包住所有可能位姿，证书 = 「管到任务安全集的加权有符号距离 ≥ θ_pose」。插孔、旋阀、采样这些任务的安全集本来就是位姿走廊（insertion corridor）、位姿锥，直接与之对齐，保守度立刻下降。

**直觉 2（四足机器人 → 浮基与接触是误差放大器）**：四足的基座位姿不是量出来的，而是被**支撑足的世界锚点闭链反解**出来的：p_i^w = T_b ⊕ r_i(q_leg)。站立足越多，T_b 越被过约束、管越紧；trot 只有两足支撑时，绕「两足连线」的滚转/偏航近乎欠约束，基座管骤胖。再加上足底打滑 B_slip、地形高程噪声、腿柔顺与负载变化，基座不确定球 B_b 会经机械臂**力臂放大**：末端位置误差 ≈ 基座转角误差 × 臂展。这解释了为什么四足移动操作「看着稳、插不准」——不是臂的问题，是基座转角误差在任务点被放大了。

**直觉 3（接缝即失效点 → 交接义务）**：混合系统的证书最容易在事件处破功：touchdown 冲击让基座状态跳变 Δ_impact，支撑腿数变化让欠约束方向翻转，任何「模式内线性化」在此失效。因此认证必须**前瞻**：在切换前 Δ_lead 内预测出手管 E_out，要求 E_out ⊕ B_impact ⊆ 入场模式的可容许集 A_in，否则不是「继续保守放行」，而是**拒绝该次切换**（延迟抬摆、缩短步长、降低质心、甚至冻结为稳定四足支撑）。这把 CAR 从「状态守卫」升级为「步态调度器」。

**耦合升级**：末端位姿管成为飞轮的**统一货币**——SCV 用它压力测试各步态/地形，CKB 以「任务位姿指纹 φ_pose × 步态指纹 ψ_gait」检索历史位姿管与交接证书，ECR 的 L0 表以步态相位为键、L1 INT8 监控器直接回归 6 维位姿边际，CAR 的状态空间新增步态相位变量。飞轮由此从「进化证书」升级为「进化**步态—位姿联合证书**」。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（接触模式自动机 / 步态相位）**：G = (M, →, m₀, T_switch)。模式 m ∈ M 是一个**支撑足集合**（如 walk 的 3–4 足、trot 的对角 2 足、bound 的前/后 2 足），每个 m 对应约束流形 C_m 与欠约束零空间 N_m（trot 的 N_m 含绕两足连线的滚转-偏航近似）。转移 e = (m→m′) 带计划切换时刻与冲击模型；运行时可见相位 τ 与到下次切换的剩余时间 Δ_switch。**关键**：pitch 的稳定性由 |N_m| 与足距共同决定，相位是有语义的证书维度，不是时间戳。

**定义 39（浮基不确定管）**：给定支撑足世界锚点 {p_i^w}、足底滑移界 B_slip、关节区间 [q_leg]，基座位姿可行集
B_b = { T_b : ∃q_leg∈[q_leg], ∀i∈stance(m), foot_i(T_b,q_leg) ∈ p_i^w ⊕ B_slip }。
在标称位姿处用 se(3) 扭曲参数化为椭球/zonotope。**命题（接触数—紧度单调性）**：在足距与滑移界相同下，|stance(m)| 越大，B_b 沿 N_m 方向的半轴越短；trot 的滚转-偏航半轴严格大于 walk。该单调性是后续相位相关阈值 θ_pose(m) 的依据。

**定义 40（末端位姿可达管与位姿边际）**：末端位姿 T_ee = T_b · T_b→body(q_leg) · T_body→arm(q_arm) · T_tool。以标称 T̄_ee 为锚，误差 ξ = log(T̄_ee⁻¹ T_ee) ∈ ℝ⁶，可达管
E(t) = { T̄_ee(t)·exp(ξ) : ξ ∈ Z(t) },  Z(t) 为 se(3) zonotope。
加权范数 ‖ξ‖_W，W = diag(1/ε_pos·I₃, 1/ε_rot·I₃)，使 m 与 rad 可比。对任务安全集 K_pose（位姿走廊/位姿锥/无碰半空间），定义**位姿边际**
m_pose(E) = dist_W(E, ∂K_pose) 的有符号版本，证书要求 m_pose(E) ≥ θ_pose(m) > 0，且保持 T_hold。注意 m_pose 直接吸收感知：目标物体由 6D 位姿估计给出 T_obj±Σ_obj，则 K_pose 按 Σ_obj 膨胀，无需另立一条感知证书。

**定义 41（交接义务 HandoffSound）**：对转移 e = (m→m′) 于计划时刻 t_s，令出手管 E_out = E_m(t_s⁻)、入场可容许集 A_in = {T : m_pose^{m′}(T) ≥ θ_pose(m′)}、冲击残差管 B_impact（由 touchdown 法向速度 v_td、地形不确定、腿柔顺界出）。定义
HandoffSound(e) ⟺ E_out ⊕ B_impact ⊆ A_in。
运行时在提前量 Δ_lead 内用 m′ 的传播器前推判定；不可证则触发**切换修正动作库** 𝒜_abort = {延迟抬摆 δt, 步长缩放 s∈(0,1], 质心下降 Δh, 冻结为 m*∈M_stable}，取最小代价可证动作。**定理（接缝 soundness）**：若每个 e 满足 HandoffSound 或已被 𝒜_abort 替换为可证模式，且模式内证书 sound，则整条混合轨迹的末端位姿证书 sound（对切换时刻也成立）。

**定义 42（相位索引证书族）**：C_m = (θ_pose(m), Z_m(·), T_hold(m), {HandoffSound(e)}_{e∈Out(m)})，有效域为相位区间 [τ_m^start, τ_m^end]。一张"证书"因此是**按相位索引的族**，而非单状态断言；CAR 的转移守卫读取当前相位选择对应 C_m，切换时消费交接义务。

**定义 43（位姿—步态联合指纹）**：φ_pose =（任务流形类型，目标位姿轨迹/位姿锥，工具帧），ψ_gait =（步态类型，接触时序，地形类，负载，传感器配置，足底摩擦类）。KB 检索 sim(φ_pose)·sim(ψ_gait) 返回历史位姿管模板、交接证书与失败相位序列；迁移时只在「管超界区域 Δ_tube」上重算，沿用可证的交接片段。

**定义 44（移动—操作组合契约）**：当「边走边抓/边插」时，操作证书在基座系表达，而安全集在世界系。组合成立需基座管 B_b ⊆ E_comp（补偿包络），且存在映射 κ：基座管半径 ↦ 允许的末端位姿修正幅度。契约 = (E_comp, κ, 任务容差)；违反则拆分为"先停稳再操作"的时序组合（用 CKB 检索已证片段拼装）。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-54/55/56/51/52/49/50/45/47）

### 2.1 IP-57 POSE-TUBE-CERT（末端位姿管认证器 PTC）
1. **se(3) 区间/zonotope 传播**：对每条腿/臂链做区间 FK，用旋量合成 T = exp(ξ₁)exp(ξ₂)…；支撑腿闭链先用定义 39 反解 B_b（区间最小二乘 + 零空间显式建模），再正向合成到工具帧。
2. **力臂放大项显式分离**：Z_ee ⊇ Z_arm ⊕ Ad(T_arm⁻¹)·Z_b，其中 Ad 为伴随作用，把基座滚转-偏航误差按力臂放大；这是把"看着稳、插不准"写成可证界的核心。
3. **加权位姿边际**：m_pose 分别报告平移/旋转最坏轴与综合值，输出到 CAR 守卫；阈值 θ_pose(m) 随相位由定义 39 单调性给出。
4. **感知耦合**：6D 位姿估计协方差 Σ_obj 膨胀 K_pose，位姿估计误差直接进入同一条管，不另设证书。

### 2.2 IP-58 GAIT-PHASE-CERT-AUTOMATON（步态相位证书自动机 GPCA）
1. **状态增广**：CAR 状态 (x, τ, m, Δ_switch)，转移表按相位分片；守卫阈值 θ_pose(m) 相位相关。
2. **前瞻证书前沿**：维护未来 K 次切换的"证书前沿"——每个候选步态序列是否每一步都存在可证交接；无则提前规划替代步态（如 trot→walk 降速）。
3. **相位相关安全停**：只在 M_stable（≥3 足支撑）允许 SafeStop；trot 相位下 SafeStop 先经"落一足成三角支撑"的过渡，禁止直接冻结。
4. **步态调度即认证**：输出不是"是否安全"，而是"哪条步态序列可采纳"，与规划器闭环。

### 2.3 IP-59 CONTACT-HANDOFF-CERT（交接证书 CHC）
1. **冲击残差管**：B_impact 由 touchdown 法向速度、地形高程分布、腿等效刚度、关节速度界出；保守取包络椭球。
2. **交接判定**：在 Δ_lead 内前推 m′ 传播器，检查 E_out ⊕ B_impact ⊆ A_in；失败时在 𝒜_abort 中搜索最小代价可证动作（延迟抬摆优先，其次步长缩放、降质心、冻结）。
3. **交接日志入 KB**：每次成功/失败交接记录 (m, m′, E_out, B_impact, 采纳动作)，成为 ψ_gait 指纹下的可检索先例。
4. **反例归因**：交接失败轨迹自动切片，标注 'impact_spike' / 'nullspace_flip' / 'slip_burst' / 'reach_saturation'，回灌 SCV 与 CKB。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO → 基座位姿 T_b ± B_b + 足端接触/滑移状态 + 地形语义
L2: CTC + VLM + IP-35 仲裁 → 目标物体 6D 位姿 T_obj±Σ_obj + 任务位姿走廊 K_pose
L3: IP-58 GPCA(相位增广 CAR) ← IP-57 PTC(se(3) 位姿管) + IP-59 CHC(交接义务)
    → IP-47 组合契约(定义 44) → IP-39 规划(margin=m_pose) → IP-45 总线(相位+交接心跳)
    → IP-52 LCS(位姿边际档位) → IP-48 认证流 → IP-53 CMC(看门狗=位姿边际)
L4: IP-55 CKB(φ_pose×ψ_gait 检索) ← IP-54 SCV(步态/地形/切换压测 + 反例归因)
    → IP-44 蒸馏(QAT→INT8 位姿边际) + IP-50 课程(步态序列迁移) → RCA 重颁相位索引证书
运行期：L0 相位键查表(p99<10μs) + L1 INT8 位姿边际(100μs) + 交接前推 → 飞轮触发 → 重颁
```

## 5. 本轮最大风险

**一句话**：本方案把 soundness 押在"模式内线性化 + 交接前推"上，但接触冲击与 trot 零空间翻转恰恰是**非光滑、线性化误差最大**的地方——若 B_impact 或 N_m 建模偏乐观，证书会在每次落脚瞬间产生**接缝盲区**，表现为"每段都对、整段错"，比第 42 轮的静默偏移更隐蔽；因此 E87/E88 必须作为红线（0 违例、0 静默失效），任一不达标即退回"trot 强制降 walk + 停稳操作"的保守时序。

## 1. 符号体系（增量：定义 38–44 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| G = (M, →, m₀, T_switch) | 接触模式自动机 | 模式=支撑足集合；转移带计划切换时刻与冲击模型 |
| C_m, N_m | 模式约束流形 / 欠约束零空间 | trot 的 N_m 含绕两足连线滚转-偏航近似 |
| B_b = {T_b : foot_i(T_b,q) ∈ p_i^w⊕B_slip} | 浮基不确定管 | 支撑足闭链 + 滑移/关节区间反解的可行位姿集 |
| ξ = log(T̄_ee⁻¹T_ee) ∈ ℝ⁶ | se(3) 位姿误差 | 加权范数 ‖ξ‖_W, W=diag(ε_pos⁻¹I₃, ε_rot⁻¹I₃) |
| E(t) = T̄_ee·exp(Z(t)) | 末端位姿可达管 | Z 为 se(3) zonotope |
| m_pose(E) = dist_W(E, ∂K_pose) | 位姿边际 | 到任务安全集边界的加权有符号距离 |
| HandoffSound(e) | 交接义务 | E_out ⊕ B_impact ⊆ A_in^{m′} |
| B_impact | 冲击残差管 | 由 v_td、地形高程、腿刚度、关节速度界出的包络 |
| C_m = (θ_pose(m), Z_m, T_hold(m), {HandoffSound}) | 相位索引证书 | 按相位索引的证书族，非单状态断言 |
| φ_pose, ψ_gait | 位姿/步态指纹 | 任务流形+目标位姿轨迹；步态+地形+负载+接触时序 |
| (E_comp, κ) | 移动—操作组合契约 | 基座管须 ⊆ 补偿包络；κ 把基座管半径映射到位姿修正幅度 |

**力臂放大的显式界（定义 40 的推导）**：设 T_ee = T_b·M，M = T_b⁻¹T_ee（臂+工具相对基座）。对基座施加体坐标右扰动 T_b ← T_b·exp(η_b)，则
T_ee′ = T_b exp(η_b) M = T_ee·exp(Ad_{M⁻¹} η_b) ⟹ η_ee = Ad_{M⁻¹} η_b。
Ad_{M⁻¹} 的平移块含 skew(p_M)·R_{M⁻¹} 项，模长 ~ ‖p_M‖（臂展）× ‖η_b,rot‖；这正是"基座转 1°、臂展 1m ⇒ 末端偏 ~1.7cm"的严格来源。于是
Z_ee ⊇ Z_arm ⊕ Ad_{M⁻¹} Z_b，L_pose = max(‖Ad_{M⁻¹}‖, L_arm)，管道传播用 L_pose 而非关节 L_m。

## 2. 关键算法（伪代码）

### IP-57 PTC：浮基管与末端位姿管传播
```
def floating_base_tube(mode, stance_feet_w, q_leg_boxes, slip_box, terrain_boxes):
    # 每个支撑足给出 3 个位置约束：p_i^w = T_b (+) r_i(q_leg)，i ∈ stance(mode)
    # 站立足多 -> 过约束；站立足少 -> 欠约束，显式保留零空间 N_m
    constraints = []
    for i in mode.stance:
        constraints.append( anchor_constraint(stance_feet_w[i], r_i, q_leg_boxes[i], slip_box) )
    T_b_nom, null_basis = interval_least_squares(constraints, terrain_boxes)
    # 沿 N_m 与残差方向展开为椭球/zonotope
    return SE3Tube(T_b_nom, null_basis, constraint_residual_box), null_basis

def pose_tube_propagate(T_ee_nom, B_b, q_arm_boxes, tool_box):
    Z_arm = interval_chain_fk_exp(q_arm_boxes, tool_box)   # se(3) 区间合成
    M = inv(T_base_nom) @ T_ee_nom                            # 臂+工具相对基座
    Ad_Minv = adjoint(inv(M))
    Z_b = Ad_Minv @ B_b                                      # 力臂放大
    Z_ee = zonotope_add(Z_arm, Z_b)                          # ⊕ 保守并
    return SE3Tube(T_ee_nom, Z_ee)

def pose_margin_se3(E, K_pose, W):
    # 平移/旋转解耦的有符号距离；最坏轴 + 综合
    box = se3_box(E.Z)                                       # 管在 se(3) 的区间外包
    d_pos = signed_dist_translation(box.trans, K_pose)
    d_rot = signed_dist_rotation(box.rot, K_pose)
    return weighted_min(d_pos/eps_pos, d_rot/eps_rot)         # 归一后取最小
```

### IP-58 GPCA：相位增广 CAR 与前证书前沿
```
def gpca_step(state, G, cert_family, horizon_K):
    x, tau, m, d_switch = state
    # 1) 相位相关守卫
    m_pose = pose_margin_se3(pose_tube_propagate(...), K_pose, W)
    if m_pose < cert_family[m].theta_pose:
        return DEGRADE, choose_stable_transition(m, G)        # 只允许向 M_stable 过渡
    # 2) 若临近切换，做交接前推
    if d_switch < Delta_lead:
        ok, act = handoff_certify(m, next_mode(m), cert_family, G)
        if not ok:
            return HANDFOFF_PENDING, act                       # 延迟抬摆/缩步/降质心/冻结
    # 3) 前证书前沿：未来 K 次切换是否都有可证交接
    seq = best_admissible_gait_sequence(G, m, horizon_K, cert_family)
    if seq is None:
        return DEGRADE, freeze_to(M_stable)
    return NOMINAL, seq
```

### IP-59 CHC：交接义务判定与最小代价修正
```
def impact_residual_box(v_touchdown, terrain_box, leg_stiffness, qd_box):
    dt = impact_settle_time(leg_stiffness, terrain_box)       # 保守接触建立窗口
    pos = v_touchdown * dt + 0.5 * a_max * dt**2
    rot = rot_rate_bound(v_touchdown, terrain_box) * dt
    return se3_box([-pos, pos], [-rot, rot])

def handoff_certify(m, m_next, cert_family, G):
    E_out = propagate_to_switch(m, t_schedule(m))
    B_imp = impact_residual_box(*touchdown_stats(m, m_next))
    A_in  = admissible_set(m_next, cert_family[m_next].theta_pose)
    if contains(E_out + B_imp, A_in):
        return True, None
    # 不可证：在 𝒜_abort 上按代价升序搜索最便宜的"可证"修正
    for act in sorted(ABORT_LIBRARY, key=cost):
        m2, t2 = apply_abort(act, m, m_next)                  # 延迟抬摆/步长缩放/降质心/冻结
        if contains(propagate_to_switch(m2, t2) + B_imp, admissible_set(m2, ...)):
            return True, act
    return False, freeze_to(M_stable)

def log_handoff(rec):
    KB.insert_handoff(phi=rec.phi_pose, psi=rec.psi_gait,
                      m=rec.m, m2=rec.m2, E_out=rec.E_out,
                      B_impact=rec.B_impact, action=rec.action,
                      labels=attribute(rec))                  # impact_spike / nullspace_flip / ...
```

## 6. 本轮最大风险

**一句话**：本方案把 soundness 押在"模式内线性化 + 交接前推"上，但接触冲击与 trot 零空间翻转恰恰是**非光滑、线性化误差最大**之处——若 B_impact 或 N_m 建模偏乐观，证书会在每次落脚瞬间产生**接缝盲区**，表现为"每段都对、整段错"，比第 42 轮的静默偏移更隐蔽；因此 E87/E88 必须作为红线（0 违例、0 静默失效），任一不达标即退回"trot 强制降 walk + 停稳操作"的保守时序。
