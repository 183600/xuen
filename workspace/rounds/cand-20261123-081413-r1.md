# 第 4 轮（灵感驱动研究循环·新灵感三元组第 1 轮；本轮灵感：「多机评测」×「语音合成」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21+IP-425–430（SDC/CAC/DCL/GIC/HPC+/CFC+ 语义-合规层；其上承 v20 联邦感知证书 PCA/CTS/CFC/HPC、v19 DCM/OGCC/CCV/DRS/OGC、v17 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**言语是可审计的承诺、可听是可验证的送达、评测是可证伪的独立调查**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 与 v20/v19/v17 全部保留。本轮只做一件事：**在 v21 的"语义-规范"层之上加一层"表述-评测"层，把"机器人会说话"升级为"说的话可证明、听得见、可被独立证伪"，并顺手给 v21 的最大风险（缺席幻觉）补上一条正交声学冗余**。

## 0. 直觉与动机

**灵感 1（语音合成 → 说过的话成为公开承诺，而不是装饰）**
直觉：v21 的证书是"沉默的"——它能证明几何安全、规范合规、意图置信，却无法向站在旁边的人解释"我打算怎么走"。语音合成看起来只是 HRI 的润色，实则补上两个结构性缺口。第一，**合成语音是生成式行动，不是输出设备**：一旦机器人说出"我将从你左侧通过"，这句话就在公共空间里成为一个**可被旁观者审计的约束**（Austin/Searle 的言语行为：警告是 directive，承诺是 commissive）。生成式 TTS 会"说错话"——幻觉式承诺、错误的急迫感、根本听不见——所以必须把 TTS 从"发声器"提升为**带证明的言语行为**。第二，**声学是正交感知通道**：机器人主动"喊一声—听回声/回应"，**即使不理解内容也能证明有人在场**（敲击、脚步、被惊动后的移动都算），其失效模式（怕噪声/混响）与视觉（怕遮挡/逆光）几乎不相关——这正是 v21 最大风险"合规的缺席幻觉"所需的第二条独立召回冗余。核心创新：**言语行为承诺证书 (Speech Act Commitment Certificate, SACC)** 与 **可听覆盖证书 (Audible Coverage Certificate, ACC)**。
反直觉点：**让机器人说话不是为了更友好，而是为了更安全、更可证伪**——它把"我心里的打算"变成"我在公共账本上的承诺"，并给评测提供了天然的真值 oracle：**言行是否一致**。

**灵感 2（多机评测 → "多台都通过"可能只是一台机器通过）**
直觉：v21 回答"这一步安全吗"，但没回答"我们**凭什么相信**这套证书在车队分布上可靠"。多机评测的朴素做法是让 N 台各跑一遍、通过率过阈值即发布。这在统计上是**假独立**：同型号、同模型、同数据、同盲区的 N 台机器，其失败高度相关。设失败相关 ρ，则均值的方差为 p(1−p)[1+(N−1)ρ]/N，**有效独立台数 N_eff = N/(1+(N−1)ρ)**；ρ→1 时 N_eff→1，"全队通过"并不比"一台通过"多任何信息。更糟的是，ρ 只能从**已观测故障**中估计，而全队共享的盲区恰恰是**永远观测不到**的故障（幸存者偏差）。于是评测协议本身必须被证明独立：协议先 merkle 预注册、留出集隐藏且轮换、跨实现/跨本体对同一快照做影子复核、**不一致即见证 (witness)**、用 N_eff 而非 N 做仲裁。核心创新：**联邦差分评测 (Federated Differential Evaluation, FDE)** 与 **预注册评测证书 (Pre-Registered Evaluation Certificate, PREC)**。
反直觉点：**评测的正确定位是波普尔式的——它只能证伪，不能证真**。PREC 记录的是"我们尽力找过反例而没找到，且这次找法事先已锁定"，而不是"我们证明了安全"。这个谦卑定位反而让它可审计、可复用、可反驳。

**灵感 3（统一：一个"说—做—评"的闭环）**
两者在 v21 之上合为 **表述-评测层 (Articulation-Evaluation Layer, AEL)**：
- **内环（表述）**：SACC 保证"**只说做得到的事**"（言语收缩执行域）；ACC 保证"**说了要能被听见**"（不可听就不记作已警告）；APC（声学在场证书）把"喊话—回应"变成缺席证书的正交证据。
- **外环（评测）**：FDE/PREC 把每次"说—做"日志当作**可证伪的测试样例**，跨机差分复核、估计 N_eff、给出评测证书。
- **闭环耦合**：言语是评测的 oracle（say-do consistency），评测是言语的审计（检出"狼来了"式警告通胀）。而多机语音真正交汇的地方是：**同一时刻多台机器一起喊会互相掩蔽**，因此必须把"发言权"当作共享稀缺资源，在"声学覆盖 × 紧迫度 × 风险"上做**跨机器人声学 NMS**——语音合成在多机系统里不是独立功能，而是会互相干扰的公共信道。
统一准入门 **HPC++ = (HPC, CC, AbsCert, SACC)** 外加"评测置信度不得被夸大"的部署门：`Exec_v22 = Exec_v21 ∩ ⋂_{u∈ActiveU_t} SpokenEnv(u) ⊆ Exec_v21`。

## 1. 研究问题（轮次升级版）

- **Q1（言语行为承诺的可证明性）**：如何判定 utterance 的命题 φ 在当前计划集上"全称成立"（∀π∈Exec, π ⊨_{[t,t+TTL]} φ）？承诺粒度（轨迹 / 走廊 / 区域 / 车道）如何选，才能在人类可读性与可满足性之间平衡？承诺到期、被人类打断、或计划必须偏离时，撤回 (retraction) 的可听性与时间裕度如何形式化为前置条件？"无法撤回"时如何保证只落到 `SpokenEnv ∩ Exec_v21` 或 SafeStop？

- **Q2（可听性的可标定性与共享声道）**：AudCov_t 如何由扬声器指向性、本体噪声谱、混响 RT60、掩蔽与人类听阈联合导出？可听性（intelligibility）如何用词识别率/WER 做 conformal 标定，使"在 AudCov 内被听懂"的概率 ≥1−ε_aud？多机器人同时发声的掩蔽如何建模为"声学 NMS"冲突图并在控制环外调度？警告预算如何防止"狼来了"式的警告通胀？

- **Q3（声学在场的可靠性与独立性）**：主动"喊话—听回声/回应"的召回下界 κ_aud 如何标定？主动探测本身是运动，如何严格限制在 v21 的安全子集内而不破坏安全继承？当声学与视觉两条召回通道正相关（同一个人既逆光又安静）时，乘积式漏检界 (1−κ_vis)(1−κ_aud) 失效，如何在独立性不可验证时退回可证明的保守界？

- **Q4（多机评测的独立性与可证伪性）**：N_eff 如何从 ICC/设计效应在线估计，同时显式承认"用看不见的故障估计相关性"的不可识别性？跨本体/跨实现的差分复核如何定义"同一快照"（时间同步、坐标对齐、传感器等效）？预注册如何阻止 p-hacking 与"教考合一"？当评测只能证伪时，部署门如何设置"未发现反例 ∧ N_eff ≥ N_min ∧ 覆盖达标"的三重条件？

## 2. 设计原则（在 P34–P36 基础上新增 P37–P39）

**P37 言行一致律（Say–Do Consistency / Commitment Soundness）**
只在 `∀π ∈ Exec_current, π ⊨_{[t,t+TTL]} φ` 时说出承诺 φ；一条有效承诺即刻收缩执行域 `SpokenEnv(u)`。执行器只允许留在所有 `ActiveU_t` 的承诺包络内；任何偏离必须**先发出可听的撤回**，撤回本身也是言语行为，需满足可听性与 ≥τ_retract 时间裕度；若撤回不可行，只能切换到仍位于包络内的更保守计划（减速/停），否则 SafeStop。故 `Exec_v22 = Exec_v21 ∩ ⋂_{u∈ActiveU_t} SpokenEnv(u) ⊆ Exec_v21`。

**P38 可听才算数律（No Silent Warning / Audible Credit）**
警告/承诺只有在接收者可能所在区域 ⊆ `AudCov_t` 且可理解概率 ≥1−ε_aud 时才被**记作已生效**；否则义务视为未满足，必须升级（切视觉通道 / 物理减速 / SafeStop），绝不"静默地记作已警告"。发言权是稀缺资源：按 `风险 × 紧迫度 / 掩蔽损失` 分配；跨机器人用声学 NMS 去冲突；警告预算 `B_t` 抑制冗余与"狼来了"。

**P39 评测独立性与可证伪律（Independent Falsification / No Grade Inflation）**
车队级可靠性主张必须使用 N_eff（相关折减）、隐藏轮换留出集、跨机差分见证与预注册哈希；EvalCert 只陈述"在覆盖分布上未发现反例"，**永不陈述"已证明安全"**。若 N_eff < N_min、留出覆盖不达标或见证超阈 → 评测无效（INVALID/REFUTED）→ 禁止新的部署主张；但单机 v21 安全继承不受影响（元层只限制"可声称的范围"，不放松执行）。

## 3. 与基线的接口（如何退化）

- SACC/语音合成失效 ⇒ 无语义言语行为：DCL 中"须口头警告"类义务无法靠"说"满足 ⇒ 转视觉警告或 SafeStop 升级；若无此类义务 ⇒ 等价 v21；
- ACC 失效（无法证明可听）⇒ 警告不记数 ⇒ 义务未满足 ⇒ 保守升级；绝不产生"已警告"的假记录；
- APC 失效（声学在场不可信）⇒ AbsCert 退回 v21 的视觉单通道 ⇒ 更保守；
- SACC 可行性失败（`SpokenEnv ∩ Exec_v21 = ∅`）⇒ 不发言或先撤回；仍无解 ⇒ SafeStop（可审计），执行仍为子集；
- FDE/PREC 失效（差分不可信/预注册损坏）⇒ 不产生新的车队级可靠性主张，退回 v21 的部署口径；单机安全不变；
- 全失效 ⇒ 完全回退 v21 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 169）；
- **安全继承**：言语只收缩、可听只"少记警告"、声学在场只增加障碍/否决缺席、评测只限制"可声称"的范围。任意失效都向更保守方向退化；语义/言语/评测状态以事件方式（10Hz 注入 + TTL）接入 v17 APS 新鲜度阶梯，控制路径仅 O(1) 查询。

## 4. 预期贡献

1. **首个"带证明的言语行为"**：把 TTS 从 HRI 装饰升级为可审计承诺，给出言行一致的全称语义、撤回协议与不可撤回回退，`Exec_v22 ⊆ Exec_v21` 可证；
2. **可听覆盖证书 + 跨机声学 NMS + 警告预算**：让"是否真的警告到了人"可被机械复核，并把多机喊话的相互掩蔽纳入发言权调度；
3. **声学在场证书**：以"不理解内容也能证明在场"的主动探测，为 v21 缺席幻觉提供正交冗余，并显式区分独立性与相关性下的不同召回界；
4. **预注册、N_eff 感知的联邦差分评测**：把"评测"本身变成可证伪证书，结构性封堵"假独立通过"与 p-hacking；
5. **说—做—评闭环**：言语日志作评测 oracle、评测反审计警告通胀，形成可自我纠正的治理回路；
6. **HPC++ 与链式继承**：`Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18` 闭环，且元层评测不确定性不污染单机安全结论。

## 5. 本轮最大风险

**一句话**：多机评测把"多台都通过"误当成独立性证据，而 N_eff 只能由已观测故障估计，恰好对"全队共享、永不观测"的盲区无能为力——车队会以形式上的高置信度为集体失明背书（"自证清白的评测幻觉"），而语音通道在改变人类行为后还可能把这层幻觉进一步掩盖。

## 1. 关键算法骨架

```python
# IP-431 Speech Act Commitment Certificate
class SpeechActCommitment:
    def __init__(self, tts, aud_cov, clock, retract_margin=0.15):
        self.tts = tts                      # 受控神经 TTS（流式、固定音色/语种）
        self.aud_cov = aud_cov              # IP-432 可听覆盖
        self.retract_margin = retract_margin
        self.active = {}                    # ActiveU_t
        self.ledger = WarnLedger()          # 供评测审计

    def can_utter(self, phi, exec_set, ttl, t):
        """P37 全称承诺：当前所有可行计划在 TTL 内都必须满足 phi，才允许说"""
        return all(implies_within(pi, phi, t, t + ttl) for pi in exec_set)

    def utter(self, act, phi, addressee, ttl, exec_set, t, urgency):
        if not self.can_utter(phi, exec_set, ttl, t):
            return None                                   # 只说做得到的事
        u = Utterance(act, phi, addressee, t, ttl, urgency)
        if not self.aud_cov.covers(addressee, u, t):
            return None                                   # 不可听 → 不算有效警告
        wav = self.tts.synthesize(u, urgency)             # 生成式，受控
        self.active[u.id] = u
        self.ledger.append(sign(u, wav_hash=hash(wav), aud_ref=self.aud_cov.proof(u, t)))
        return u

    def guard(self, plan, t):
        """执行前守门：留在所有有效承诺包络内；偏离须先可听撤回"""
        for u in self.active_at(t):
            if implies_within(plan, u.phi, t, t + u.remaining(t)):
                continue
            can_retract = (self.aud_cov.covers(u.addr, u, t)
                           and t + self.retract_margin <= plan_horizon(plan))
            if can_retract:
                self.retract(u, t)                        # 撤回本身也是言语行为
            else:
                return None         # 不可撤回 → 只能选包络内更保守计划或 SafeStop
        return plan

    def retract(self, u, t):
        # 撤回也要可听并记入账本；若不可听则不得"假装撤回"
        assert self.aud_cov.covers(u.addr, u, t)
        self.ledger.append(Retraction(u.id, t, aud_ref=self.aud_cov.proof(u, t)))
        del self.active[u.id]


# IP-432 Audible Coverage
class AudibleCoverage:
    def __init__(self, speaker_model, ego_noise, reverb_map, intelligibility_calib):
        self.speaker = speaker_model        # 指向性/频响
        self.noise = ego_noise              # 本体噪声谱
        self.reverb = reverb_map            # RT60 空间图
        self.calib = intelligibility_calib  # conformal：WER 分位标定

    def coverage(self, t, pose, others_utts=()):
        """AudCov = 声压 ≥ snr_min ∧ RT60 ≤ RT60_max ∧ 未被同时发声掩蔽"""
        raw = self._acoustic_field(pose)
        masked = subtract_masking(raw, others_utts)      # 跨机语音互相掩蔽
        return self.calib.region_at_least(1 - self.eps_aud,
                                          raw=masked, snr_min=snr_min,
                                          rt60_max=RT60_max)

    def covers(self, addr_region, u, t):
        # 受众可能区域（来自 CAC 的 possible-human 区域）必须整片落在 AudCov 内
        return addr_region <= self.coverage(t, u.pose, u.overlaps)

    def acoustic_nms(self, requests):
        """跨机器人发言权调度：冲突图=可听区重叠∧时间重叠；按 风险×紧迫度/掩蔽损失 贪心"""
        chosen, deferred = [], []
        for r in sorted(requests, key=lambda r: -(r.risk * r.urgency / r.mask_loss)):
            if all(not conficts(r, c) or r.priority > c.priority for c in chosen):
                chosen.append(r)
            else:
                deferred.append(r)        # 延后、改视觉通道，或转 SafeStop（绝不静默丢弃）
        return chosen, deferred

    def budget_ok(self, rule):
        return self.B_t[rule.priority] > 0   # 抑制冗余与"狼来了"


# IP-433 Acoustic Presence Certificate
class AcousticPresenceCertifier:
    def __init__(self, prober, detector, kappa_aud, kappa_vis, rho_ch_max=0.3):
        self.prober, self.detector = prober, detector
        self.ka, self.kv, self.rho_max = kappa_aud, kappa_vis, rho_ch_max

    def probe_and_listen(self, safe_static_subset):
        # 主动探测是感知动作：必须完全落在 v21 的静止/慢速安全子集内
        assert current_pose() in safe_static_subset
        return self.detector.detect(self.prober.emit(chirp_or_call=True), window=0.6)

    def issue(self, cov, events, rho_ch_est):
        # 任何声学事件（不懂内容）达到 q_low 即蕴含有人在声场内
        if any(ev.q >= Q_LOW for ev in events):
            return None, "HUMAN_PRESENT_BY_ACOUSTIC"
        # 独立性可辩护用乘积互补；否则退回可证明下界 max(κv,κa)
        if rho_ch_est <= self.rho_max:
            kappa = 1 - (1 - self.kv) * (1 - self.ka)
        else:
            kappa = max(self.kv, self.ka)      # 任意相关下 P(A∪B) ≥ max(P(A),P(B))
        return AbsCert(cov, kappa=kappa, delta=1 - kappa), "OK"


# IP-434 Federated Differential Evaluation
class FederatedDifferentialEvaluator:
    def __init__(self, prereg, peers, holdout):
        self.prereg, self.peers, self.holdout = prereg, peers, holdout

    def shadow_check(self, snapshot, cert, plan):
        """只传 (snapshot_hash, 证书/几何摘要)，原始图像与音频不出域（隐私）"""
        witnesses = []
        for peer in self.peers.sample_diverse(k=self.prereg.k_peers):
            if peer.stack_id != self.stack_id:        # 跨实现 / 跨本体
                verdict = peer.replay(snapshot.hash, cert.summary(), plan.summary())
                if verdict != "AGREE":
                    witnesses.append(Witness(snapshot.hash, self.id, peer.id, verdict))
        return witnesses

    def estimate_neff(self, failures_by_robot):
        """只用可观测故障估 ICC/ρ_fail；对"未观测共享盲区"显式标注不可识别"""
        rho = icc_binary(failures_by_robot)
        n = len(failures_by_robot)
        return n / (1 + (n - 1) * rho), rho        # 注意：真实 N_eff 只会更小

    def eval_cert(self, run):
        assert run.protocol_hash == self.prereg.protocol_hash   # 预注册，禁中途改协议
        neff, rho = self.estimate_neff(run.failures)
        coverage = self.holdout.coverage(run.test_distribution)
        if neff < self.prereg.N_min or coverage < self.prereg.cov_min:
            return EvalCert(self.prereg, neff, coverage, run.witnesses, "INVALID")
        if len(run.witnesses) > self.prereg.w_max:
            return EvalCert(self.prereg, neff, coverage, run.witnesses, "REFUTED")
        # 只声明"未发现反例"——不声称安全
        return EvalCert(self.prereg, neff, coverage, run.witnesses, "NO_COUNTEREXAMPLE")
```

## 2. 推导

**引理 163（言语行为的非扩张性）** 设 `Exec_v22(t) = Exec_v21(t) ∩ ⋂_{u∈ActiveU_t} SpokenEnv(u)`。SACC 只在 `SpokenEnv(u) ⊇ Exec_current` 时签发 u，签发仅做交运算；guard 遇到偏离时，要么先撤回（撤回是言语动作，不向运动动作集新增 v21 之外的计划），要么返回 `None` 迫使执行器改选 `SpokenEnv ∩ Exec_v21` 内的更保守计划或 SafeStop。故对任意 t 有 `Exec_v22(t) ⊆ Exec_v21(t)`；若 `SpokenEnv ∩ Exec_v21 = ∅`，则无可行计划 → SafeStop，仍不越界。∎

**引理 164（可听警告的有效性与"不静默"）** 若可听性标定满足 `P(Intelligible(x) | x ∈ AudCov_t) ≥ 1−ε_aud`，则被记作生效的警告在受众区域以 ≥1−ε_aud 可被理解。若受众区域不 ⊆ AudCov_t，SACC 拒绝签发、WarnLedger 不记"已警告"，相应 DCL 义务保持未满足并按 v21 规则升级（视觉/减速/SafeStop）；声学 NMS 若无法为必需警告分配发言权，只能延后/改通道/升级，绝不静默丢弃。故语音层只可能"少记警告"或"不发言"，绝不产生假生效记录。∎

**引理 165（声学在场的正交冗余与相关保守性）** 设视觉、声学在场通道召回下界分别为 κ_vis、κ_aud。若两通道失效独立可辩护，则联合漏检 ≤ (1−κ_vis)(1−κ_aud)，即联合召回 ≥ 1−(1−κ_vis)(1−κ_aud)；若独立性不可辩护（ρ_ch > ρ_ch_max），由 `P(A∪B) ≥ max(P(A),P(B))` 对**任意相关结构**成立，取 `max(κ_vis, κ_aud)` 为可证明联合召回下界，绝不使用乘积式乐观界。任一声学事件（哪怕是非语言敲击/脚步）达到 q_low 即构造性蕴含有人在声场内，APC 否决 AbsCert 并翻转为 HUMAN_PRESENT，故 v21 的缺席幻觉被一条失效模式互补的通道削弱。∎

**引理 166（有效独立性与估计的乐观性）** 对 N 台可交换、失败指示变量两两相关 ρ 的车队，`Var(p̂) = p(1−p)[1+(N−1)ρ]/N`，设计效应 `DEFF = 1+(N−1)ρ`，`N_eff = N/DEFF`；故以 N 代替 N_eff 会系统性低估方差、夸大置信度。进一步：ρ 只能由**已观测**故障估计，若存在全队共享而未被触发的盲区，真实 ρ 更大、真实 N_eff 更小，因此 `N_eff_hat` 是真实 N_eff 的**上界（乐观）**。PREC 因此必须叠加 N_min 裕度与隐藏轮换留出，而不是把 `N_eff_hat ≥ N_min` 当作安全证明。∎

**引理 167（差分见证的证伪可靠性）** 若两套**互不相同**的实现/本体在同一快照（哈希一致、时间同步、坐标对齐）上对同一规范判定给出不同 verdict，则至少一套相对规范是错的（在快照同一性成立的前提下）。故见证集 W 是**反例**：它证明"评测流水线并非处处正确"，但**不能指出谁对谁错**，更不能证明安全。因此 EvalCert 只能以 W 做证伪，verdict 至多为 `NO_COUNTEREXAMPLE`。∎

**引理 168（自证评测的不可识别性，负结果）** 令 B 为"全队同时失效"的状态子集，`P(B)=β>0`。任何仅使用车队自身运行结果（即使含 N_eff、留出集、差分见证）的统计量，对 B 的样本贡献恒为零——因为按定义 B 内没有观测到失败。故不存在仅凭车队自证数据即可给出 β 上界的估计量；β>0 与"全部通过"在观测上不可区分。要打破该不可识别性，只能引入**外部**信息：第三方隐藏留出、异构本体/独立实现、真实人类审计或形式化环境模型。此引理是 v22 最大风险的形式化，而非可修补的工程缺陷。∎

**引理 169（v22 整体安全继承）** 同一几何快照、同一规则库与机器人集合下：SACC 只收缩（引理 163）、ACC 只"少记警告"（164）、APC 只增加在场证据/收紧缺席（165）、FDE/PREC 只限制"可声称范围"而不放宽执行（166–168）。故 `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`；评测层的失效导致"不能声称"，而非"执行变宽"。∎

## 6. 已知风险与失效模式

1. **评测自证的不可识别性**（最大风险，见第 7 节）：N_eff 只能由已观测故障估，共享盲区结构性不可见。缓解：外部隐藏留出、异构本体/独立实现、真实人类审计、形式化模型（引理 168 已声明这是不可消除的边界）。
2. **承诺-行为耦合过紧导致活性坍缩**：承诺一旦签发就收缩执行域，环境变化时需要频繁撤回，可能陷入"不敢承诺/不敢动"。缓解：粒度自适应、撤回裕度 τ_retract、契约 TTL 短化、E821 活性监控。
3. **可听性的分布外失效**：AudCov 用标定听者/语种/设备训练，对听障人士、非母语者、不同年龄听阈可能系统性失效。缓解：多语种/多听阈标定、并发非语音提示（灯光/屏幕/触觉）、宁保守勿误记（E805/E806）。
4. **多机声学互相掩蔽与嘈杂**：多台同时喊话既掩蔽又制造噪声公害。缓解：声学 NMS + 警告预算 + 发言权优先级（E807/E808）。
5. **语音欺骗与冒名**：合成语音可被伪造/误认为权威指令，或机器人音色被滥用。缓解：固定可识别音色、语音水印/签名、许可类交互走高门槛与多因子确认（继承 v21 GIC 高门槛）。
6. **主动探测的安全与社交成本**：探测是运动，且"喊话"可能惊扰人、改变其行为。缓解：探测限制在安全子集、频率预算、失败即停（E811）。
7. **评测过拟合与观测者效应**：机器人的语音/行为改变了人类分布，留出集可能被"教考合一"或 treatment effect 污染。缓解：预注册、隐藏轮换留出、对照协议、记录并报告观测者效应（E817/E818）。
8. **跨实现差分并非真独立**：不同实现可能共享同一训练数据/同一先验，见证会系统性缺失。缓解：按数据/代码/本体来源计算 N_eff，不按进程数计（E814）。

## 7. 本轮最大风险

**一句话**：多机评测把"多台都通过"误当成独立性证据，而 N_eff 只能由已观测故障估计，恰好对"全队共享、永不观测"的盲区无能为力——车队会以形式上的高置信度为集体失明背书（"自证清白的评测幻觉"），而语音通道在改变人类行为后还可能把这层幻觉进一步掩盖。
