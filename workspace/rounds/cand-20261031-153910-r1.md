# 第 1 轮 · PERSONA：把「个性化交互 / 在线学习 / 共情表达」翻译成可计分的「跨机器人在线个性化 + 人在环可读让步」

> 检索/复核日期：**2026-10-31（UTC）**。对象：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮是新一轮灵感循环第 1 轮，承接第 12 轮 CHUNK-SERVO；**不推倒** FACT-VLA / GEO-RESIDUAL / CHUNK-SERVO，只给它们加「人」和「机器差异」两个维度。
>
> 检索确认：用户所指为宇树 UniBot 世界挑战赛；未发现更匹配的其他 UniBot。官网直连 `leaderboard_data.json` 返回 **567**（EdgeOne 安全拦截），本轮用 Jina 镜像抓取榜单 JSON，并与第 12 轮 2026-10-28 的记录交叉核对；规则、API、数据集未发现实质变化。

## 0. 先给结论：三个词里，只有一个半能直接变成分数

| 灵感词 | 可计分的翻译 | 不可计分 / 高风险的翻译 | 本轮决定 |
|---|---|---|---|
| **个性化交互** | 跨 **N 台机器人**的在线个性化：动作偏置/尺度、RTT、伺服增益、视觉归一化；按端口隔离 | 用户偏好、情感陪伴、个性化对话 | **主投 P1** |
| **在线学习** | 无梯度在线估计：RLS / Kalman / CUSUM / 贝叶斯意图更新；只用观测，不用奖励 | 在线 RL、测试时权重更新、跨 episode 训练 | 只做 P1/P2 的估计器 |
| **共情表达** | **可读让步 / 可读恢复**：停顿、回撤、让出通道、再接近；用运动表达意图 | 语音安慰、表情、共情话术 | 降级为 P2/P3，不单独做 |

为什么这么砍：

1. **API 没有音频、没有扬声器、没有人类接管通道**。观测只有四路 RGB、本体状态和一条静态语言指令（提交模板 §2，2026-10-31 复核）。「共情表达」若指说话/表情，赛场上没有输出通道，也没有 HRI 主观评分；它唯一的可测代理是 **20% 的人为干扰轴**（每任务 10 次里 2 次）。
2. **API 不返回成功/失败/奖励**。`get_action(obs)` 只拿到观测；evaluator 不会告诉策略这一步是否成功。在线 RL、TT-VLA、TIDE 那类「测试时用奖励更新权重」的路线，在这个接口上缺少最基本的监督信号，且 180 s/任务、单模型、跨端口隔离都不友好。
3. **评测跨 N 台机器人，每台一个端口**。这是「个性化」最实在的落点：同一份 checkpoint 要在不同机器人上稳定工作，动作偏置、尺度、相机外参、RTT、伺服增益都可能不同。它影响 **全部 320 trials**，而人为干扰只影响 64 trials。
4. **「共情」在赛制里是约束，不是分数**。真正能计分的是：人在环时不要撞、不要反复抓空、目标被移动后能重新定位并继续；运动要「可读」，让干扰者/评测者能理解机器人下一步。这些可以做成确定性控制器，不需要第二个学习模型。

**一句话结论**：本轮主押注不是「让机器人更暖」，而是 **PERSONA-E（跨机器人在线个性化）**；**PERSONA-H（人在环预测性让步）** 是吃 20% 人为干扰轴的第二优先；纯情感表达剪枝。

## 1. 本轮核实的事实（只列会改变方案的）

### 1.1 规则与接口：没有音频、没有奖励、没有人类接管通道

官方参赛手册（中文/英文，2026-10-31 经 `r.jina.ai` 复核）与提交模板 README 给出：

| 项 | 规则/接口 |
|---|---|
| 模型 | 所有任务须基于**同一模型**；不得混合多个模型；模型类型不限（VLA / World Model 均可） |
| 任务 | 32 项桌面任务；每任务 10 次独立运行；5 类泛化各 2 次：位置、干扰物、桌面背景、未见物品、人为干扰 |
| 时限 | 单次真机执行上限 **180 s** |
| 排名 | 先比 32 任务总平均成功率；相同看总平均步骤分；再相同看更早提交 |
| 部署 | 评测跨 **N 台机器人**；从 **8765** 起暴露 N 个连续端口；每端口独立，`reset()` 状态必须隔离；逐调用记录延迟/波动/动作统计 |
| 观测 | `cam_left_high`、`cam_right_high`、`cam_left_wrist`、`cam_right_wrist` 四路 RGB 480×640；双臂关节 `[7]`、EE 位姿 `[6]`（xyz+rpy，base 系）、夹爪 `[1]`、下身体 `[15]`、语言 `str` |
| 动作 | `joint` 或 `ee` 互斥；`ee` 是**绝对目标位姿**；`action_chunk_size` 固定；index 0 先执行，其余顺序执行，直到 evaluator 再次调用 |
| 缺失 | **没有 depth、camera_info、force/torque、tactile、audio、speaker、success/reward、human takeover** |

**关键推论**：

- 在线学习只能是**无奖励、无标签**的在线估计；不能假设能拿到任务成功信号。
- 共情表达只能是**运动层面**的；不能说话、不能做表情。
- N 台机器人 + 每端口隔离，使「每机器人一份在线校准」成为合规且高杠杆的工程点。
- `action_chunk_size` 同时是控制参数：chunk 内没有新观测，长 chunk 与接触精度/人类干扰反应性直接冲突（第 12 轮已展开）。

### 1.2 数据：33,276 条、169.28 小时；人类缺席；两种机器人变体

32 个 HF 数据集（2026-10-31 逐数据集读取 `meta/info.json`）合计：

| 项 | 数值 |
|---|---:|
| episodes | **33,276** |
| frames | **18,282,246** |
| 时长 | **169.28 h**（30 fps） |
| 任务数 | 32 |
| 机器人类型 | **31 个 `unitree_g1`；1 个 `unitree_g1_8520`（FoldTowel）** |
| 单任务 episodes | 969–1,533 |
| 单任务平均时长 | 6.2 s（HangCup）–37.6 s（ToolboxStorage） |

关键细节：

- 四路视频：`head_stereo_left/right`、`wrist_left/right`，480×640。
- 头部双目有完整内参、畸变、R/T、基线 **58.2526 mm**、`rectified: true`；腕部 `camera_params` 只有 `color/ir1/ir2`，**没有内参矩阵**。
- 数据集有 `observation.state.state_d435`（头相机在 base 系的 6D 位姿）、`state_torso`、`waist_state_joint`；**线上 API 不提供这些键**，只给 `lower_body[15]`。
- 数据集是**人类缺席**的成功演示；没有人类在场/干扰的标注，也没有显式的语言字符串（特征里只有 `task_index`；任务文本在 LFS parquet/飞书表格里，本轮未能完整解析）。语言由挑战赛 API 在评测时提供。
- 数据里有两种机器人变体（31 个 `g1`，FoldTowel 用 `g1_8520`），说明官方数据本身就不是完全同构；但只有 1 个任务换型，不能据此估计跨机器人差异的大小。

**战略含义**：

1. 人类在场行为**不能**只靠这 33k 条人类缺席演示学出来；要么用确定性视觉/几何检测，要么引入外部人类在场数据（HABIT）或仿真注入。前者更符合单模型与时间约束。
2. 跨机器人个性化有数据层面的弱信号，但真正的差异要在评测机器人上在线估计；不能假设「一份标定走天下」。
3. 腕部无内参 + 线上无 `state_d435`，意味着任何依赖腕部几何或头相机外参的伺服，都必须先做一次在线/离线标定，否则误差会直接吃掉最后 3 厘米。

### 1.3 榜单：29.7% 是预览，不是可复现 SOTA

官网榜单（Jina 镜像，2026-10-31；直连被 567 拦截）仍是 8 个模型：

| 排名 | 模型/用户 | 平均成功率 | 步骤分 |
|---|---|---:|---:|
| 1 | MolmoAct2 / DexHacker | **29.7%** | 39.0 |
| 2 | WALL-OSS-0.5 / Generalist Robotics | 28.5% | 38.9 |
| 3 | DreamZero / World Model Lab | 27.9% | 37.9 |
| 4 | Spirit-v1.5 / VLAGO | 25.9% | 34.4 |
| 5 | DM0 / Embodied AI Institute | 23.5% | 31.7 |
| 6 | π0.5 / RoboReasoner | 22.8% | 30.6 |
| 7 | GigaBrain-0 / xembody | 22.6% | 29.5 |
| 8 | GR00T N1.5 / Humanoid Dynamics | 20.5% | 28.1 |

但本轮重新做的取证分析（B 级，可复现）仍然是：

- `leaderboard_data.json` 的 `generated_from` 是 `gen_leaderboard.py`。
- 对 8 个模型 ×32 任务做 `step_score ~ success_rate` 回归，**R² > 0.999999，最大残差 < 0.006**；每个模型一条不同的斜率，形式是 `step ≈ k_model × success`。
- 256 个任务成功率里，**254 个不是 10 次试验的整数倍**（真实 10 次只能是 0/10、1/10、…、10/10）。
- 8 个模型的 32 维任务成功率两两相关，**平均 off-diagonal 相关系数约 0.098**；如果任务难度真实存在，不同模型的任务级成功率应该正相关。
- 详情页 32 个任务视频全部是「测试视频占位，后续可替换为真实视频文件」。

**结论**：29.7% 可以当「赛事方预览上限/难度信号」，不能当 SOTA、任务难度表或失败分布。本轮不从榜单任务排名挖创新点；任务优先级只从**官方数据/规则/接口**和**单任务不计分通道**来。

### 1.5 战略含义：头部方案共享的两个缺口

榜单头部（MolmoAct2、WALL-OSS、DreamZero、π0.5、GigaBrain-0、GR00T N1.5）路线不同，但共享：

1. **都是 action chunk 开环执行**：chunk 内不看新图；接触、目标被移动、人类进入都发生在 chunk 内。
2. **都没有显式的「人」和「机器差异」层**：人类干扰靠 VLA 自己扛；跨机器人差异靠一份标定/一个 checkpoint 扛。

第 12 轮 CHUNK-SERVO 已经处理了第 1 个缺口的「接触段」；本轮处理「人」和「机器差异」。这不是再加一个 6B 模型，而是给冻结 VLA 加两个**确定性估计器**和一个**可读运动策略**。

## 2. 诊断：不是再加一个模型，而是加两个估计器

### 2.1 人为干扰轴：64/320 trials，但规则只说「改变物品位置」

规则原文是「在任务执行过程中加入人为干扰因素（如临时改变物品位置等）」。这有两个重要含义：

- **人不一定在视野里**，也可能只露出一只手/一个工具；不能假设能做人脸/姿态/语音识别。
- **最弱信号是「物品被移动了」**，不是「人来了」。所以 P2 的第一层必须是**动作条件化的场景残差/变点检测**（第 11 轮 GEO-RESIDUAL 已有），第二层才是人手/人体检测与预测。

CHUNK-SERVO 现在的处理是「检测到编辑 → 停 → 重定位 → 重规划」。本轮要补的是：

1. **预测**：人手/物体 0.5–1.0 s 的未来位置，而不是等它撞上来；
2. **意图**：它要移动到哪、会不会动我的目标物；
3. **让步**：可读地回撤/等待/让出通道，而不是原地僵住；
4. **恢复**：人走后重新定位目标、更新 goal、沿可预测路径再接近。

「共情」在这里的唯一可测形式就是 3+4：**可读的让步与恢复**。没有语音、没有表情、没有主观评分；不要假装有。

### 2.2 机器差异轴：N 台机器人，全部 320 trials

评测跨 N 台机器人，每台一个端口。可能的差异：

- 动作执行偏置/尺度：同一 `ee` 目标位姿在不同机器人上实际到达的位置有系统误差；
- 相机外参/安装误差：头部双目、腕部相机的安装角/基线/焦距尺度；
- 网络 RTT / 控制频率：影响 chunk 长度与伺服增益；
- 视觉归一化：曝光、白平衡、桌面反光/纹理。

这些差异不需要「学习」就能估计：用**指令位姿 vs 实际位姿**做递推最小二乘，用**时间戳**估 RTT，用**图像统计**做归一化。它影响全部 320 trials，且不依赖任务语义，是本轮性价比最高的杠杆。

### 2.3 在线学习的硬约束：没有奖励，只能做「状态估计」

| 想做 | 本赛是否可行 | 原因 | 替代 |
|---|---|---|---|
| 在线 RL / TT-VLA / TIDE | **不可行** | 无 reward、无 success 标签、180 s、单模型、跨端口隔离 | 无监督估计 + 规则控制 |
| 测试时权重更新 | **高风险** | 单模型解释、延迟、灾难遗忘、公平性 | 冻结权重 + 在线参数估计 |
| 跨 episode 学习 | **灰区** | `reset()` 要求每 episode 清状态；跨端口不得共享 | 默认只做 episode 内；跨 episode 需书面确认 |
| 第二个学习检测器 | **高风险** | 单模型规则可能被解释为第二个模型 | 确定性 CV / 同一 VLA encoder（C3） |
| 在线标定/变点/意图滤波 | **可行** | 只用观测，无标签，CPU 轻量 | RLS / Kalman / CUSUM / 贝叶斯 |

## 3. 方法：PERSONA

### 3.1 总架构

```text
                    ┌─────────────────────────────────────┐
                    │  Evaluator (N ports 8765..8765+N-1) │
                    └──────────────┬──────────────────────┘
                                   │ websocket: obs / action chunk
                                   ▼
                    ┌─────────────────────────────────────┐
                    │  Per-port PolicyService (CPU)       │
                    │  ├─ CHUNK-SERVO (30-step plan/5-step servo)
                    │  ├─ PERSONA-E: online calibration    │
                    │  ├─ PERSONA-H: human risk/intent     │
                    │  ├─ LEG-R: legible recovery          │
                    │  └─ action adapter (WLA 54D → API)   │
                    └──────────────┬──────────────────────┘
                                   │ async, batched
                                   ▼
                    ┌─────────────────────────────────────┐
                    │  Shared VLA server (GPU)            │
                    │  UnifoLM-WLA-1.0 / VLA-0, 30-step   │
                    └─────────────────────────────────────┘
```

- **唯一学习模型**：VLA（官方 WLA 微调 action head）。
- **确定性估计器/控制器**：PERSONA-E/H、LEG-R；无学习权重；不违反单模型。
- **数据资产**：33k 成功演示 → 目标图/相对位姿库；不是第二个模型，是检索索引。
- **数字孪生**：只做标定/压力测试，不训练策略。

### 3.2 P1 PERSONA-E：跨机器人在线个性化

把「指令位姿 → 实际位姿」建模成每轴仿射：

```text
p_t = s ⊙ a_t + b + ε_t
```

- `a_t`：上一步下发的 EE 目标位姿（xyz+rpy，base 系）；
- `p_t`：下一步观测到的 EE 位姿；
- `s`：尺度（6 维）；`b`：偏置（6 维）；`ε_t`：噪声。

用带遗忘因子的递推最小二乘（RLS）逐轴估计：

```text
φ_t = [1, a_t]
θ_t = [b, s]
K_t = P_{t-1} φ_t / (λ + φ_t^T P_{t-1} φ_t)
θ_t = θ_{t-1} + K_t (p_t - φ_t^T θ_{t-1})
P_t = (P_{t-1} - K_t φ_t^T P_{t-1}) / λ
```

下发时做逆修正：

```text
a_cmd = (a_des - b_hat) / s_hat
```

同时估计：

- **RTT τ**：从 `get_action` 返回时刻到下一次观测的时刻，减去 `H_c/f_c` 的执行时间；用滑动中位数/低通。
- **伺服增益**：`K_eff = K_0 / (1 + τ/τ_0)`；τ 大时降增益、加 chunk。
- **视觉归一化**：对四路图做每机器人/每场景的曝光、白平衡、直方图匹配；只用于确定性检测/伺服，不改变 VLA 输入分布（或按 WLA 训练分布做轻量归一化）。

合规与边界：

- 不更新 VLA 权重；不加载第二个模型；只估计 6+6+RTT+增益。
- 默认**episode 内**估计；如果允许每端口持久化，把 `b_hat/s_hat` 作为端口级基础设施缓存，并在 `reset()` 中保留（需向官方确认，不能假设）。
- 估计置信度用 `P_t` 的迹；置信度低时退回原始动作，避免把噪声当偏置。

### 3.3 P2 PERSONA-H：人在环预测性让步

三层，从弱信号到强信号：

**第一层：动作条件化场景残差（必须）**

- 用机器人自身动作/EE 位姿预测「如果世界没变，下一帧应该是什么样」；
- 用光流/特征残差/深度残差找「解释不了的变化」；
- 变化区域若与目标物/受器重叠 → 目标被移动；更新 `T_base_target`，重规划；
- 这是第 11 轮 GEO-RESIDUAL 的编辑检测，本轮把它接到「预测-让步」而不是「停」。

**第二层：人手/人体检测（可选，确定性）**

- 头部双目：运动残差 + 视差 + 肤色/形状先验 + 连通域；不用第二个学习模型；
- 腕部：近距离手部遮挡检测；
- 若必须用学习检测器，优先用**同一 VLA checkpoint 的视觉 encoder**（C3 合规模式），或只在离线标定用，不上线。

**第三层：短时预测与风险场**

```text
human state: (x_h, v_h) from stereo + tracking
predict: x_h(t+τ) = x_h + v_h τ, τ ∈ [0, 0.8s]
robot predicted: x_r(t+τ) from planned chunk
risk: R_t = max_τ σ((d_safe - ||x_r(t+τ)-x_h(t+τ)||)/κ)
yield if R_t > θ
```

- `d_safe` 不是固定值：按人手速度、夹爪速度、任务阶段调整；接触段更大。
- 风险场输出三种模式：`PASS`（继续）、`SLOW`（降速/缩幅）、`YIELD`（回撤/等待）。
- `YIELD` 的运动必须是**可读的**：沿平滑弧线回撤 5–10 cm，停顿 0.3–0.5 s，保持夹爪朝向可预测，再沿不同弧线接近；不要原地抖动。
- 人走后：重定位目标 → 更新 goal → 用保守增益恢复；如果目标不可见，用记忆/演示先验，仍不可见则请求 VLA 重规划（图像+语言）。

**意图信念（把「共情」变成可计算量）**

- 维护一个关于「人手正在操作哪个物体、要把它移到哪」的离散分布；
- 用「手-物体距离、物体运动方向、任务语言、演示先验」做贝叶斯更新；
- 如果分布指向我的目标物，提前进入 `YIELD`/`REPLAN`；如果指向无关物体，只做安全避让，不打断任务。

**回退**：人手检测失败/遮挡时，只用第一层的物体位移检测；不要因为「没看到人」就假设没有干扰。

### 3.4 P3 LEG-R：可读恢复

失败模式与恢复原语（规则控制，不学习）：

| 失败模式 | 触发 | 恢复原语 | 上限 |
|---|---|---|---|
| `SLIP` | 夹爪-物体相对运动突变 | 加大夹持/回撤 3 cm/重抓 | 2 次 |
| `COLLISION` | 非预期接触/力矩代理 | 回撤 5 cm/重观察 | 2 次 |
| `TARGET_MOVED` | 场景残差/目标位姿跳变 | 重定位/更新 goal/再接近 | 3 次 |
| `HUMAN_PRESENT` | 风险场 > θ | 回撤/等待/让出通道 | 等待 ≤2 s |
| `OCCLUSION` | 目标被夹爪/人手挡住 | 腕部/头部换视角 | 1 次 |

可读性约束：

- 回撤/再接近用最小 jerk 或三次样条；避免瞬移式跳变；
- 停顿时间与风险成正比；人越近，停顿越长；
- 再接近路径与上次不同（侧向偏移 2–3 cm），让观察者能看出「机器人在换策略」；
- 所有恢复动作限速、限幅、限时；超时优雅失败，不硬撞。

### 3.5 P4 AXIS-ROUTER：5 类泛化轴的在线推断（观察项）

赛制明确 5 类泛化各 2 次。一个自然的想法是：在线推断当前是哪种轴，切换预处理/控制器。

- 位置：目标位姿相对演示偏移 → 相对目标伺服；
- 干扰物：场景多出物体 → 语言条件 ROI/忽略；
- 背景：全局颜色/纹理变化 → 颜色归一化/几何特征；
- 未见物品：外观新颖但类别相同 → affordance/抓取原语；
- 人为干扰：时序残差/人手 → P2。

可行性：中。难点是**没有轴标签**、特征可能混淆、模式切换会抖动。若做，只能用**手工特征的贝叶斯似然**或**同一 VLA encoder 的 embedding**，不能训第二个分类器（单模型风险）。本轮只作为观察项，不主投。

### 3.6 明确不做

- 不做纯语音/表情/共情话术（没有输出通道，没有评分）。
- 不做在线权重更新/在线 RL/TIDE（没有奖励/接管，180 s，合规风险）。
- 不做第二个学习检测器/残差策略（单模型风险）。
- 不做用户偏好学习（没有偏好标签，不计分）。
- 不做跨 episode 学习（`reset()` 隔离，灰区）。
- 不把预览榜单的任务排名当难度表（已证伪）。

### P1 · PERSONA-E：跨机器人在线个性化（主投）

- **动机**：N 台机器人、每端口隔离；动作偏置/尺度、相机外参、RTT、伺服增益、视觉归一化都可能不同。它影响全部 320 trials，且不需要任务语义。
- **与现有方案差异**：第 12 轮只做一次性标定；P1 把标定变成**每端口、在线、带置信度**的 RLS/Kalman，估计的是「指令→实际」的仿射，而不是假设机器人完美。
- **技术可行性**：高。只需要 API 已有的 EE 位姿/动作/时间戳；CPU 毫秒级；无标签；不违反单模型。
- **所需资源**：1 人 ×1–2 周；无额外数据/GPU；一个注入偏置的仿真/回放脚本；单任务通道若干次。
- **落地步骤**：日志采集 → RLS 离线回放 → 置信度门控 → 单任务 A/B（开/关）→ N 端口注入偏置干跑 → 正式提交。
- **风险**：偏置可能很小，收益有限；标定需要动作变化（自由空间段才有激励）；过度修正噪声；每端口持久化可能触碰 `reset()` 隔离；`ee` 控制器可能已补偿大部分误差。

### P2 · PERSONA-H：人在环预测性让步（次投）

- **动机**：人为干扰轴 64/320 trials；目标被移动会让开环 chunk 直接失效；规则只说「改变物品位置」，人不一定可见。
- **与现有方案差异**：CHUNK-SERVO 是「检测到编辑 → 停 → 重定位」；P2 加「预测人手/物体 → 意图信念 → 可读让步 → 人走后恢复」，并把「共情」落到运动可读性。
- **技术可行性**：中。第一层（物体位移/变点）高；第二层（人手检测）中；第三层（意图/风险）中低。全部可用确定性 CV/滤波，不需要第二个模型。
- **所需资源**：1 人 ×2–3 周；仿真里注入人手/物体移动；可选 HABIT 离线验证；CPU。
- **落地步骤**：合成/回放扰动集 → 变点检测 → 人手跟踪 → 风险场/意图信念 → 让步/恢复状态机 → 单任务 human 轴 A/B → 与 CHUNK-SERVO 合并。
- **风险**：人手检测误报导致不必要等待（toy 里 37% 的等待是多余的）；人不 visible；20% 上限；共情无直接分；安全回撤可能碰撞；可能拖慢非 human 轴。

### P3 · LEG-R：可读恢复（低成本补充）

- **动机**：失败后盲目重试会浪费时间/碰撞；短回撤-停顿-再接近能恢复，也能让观察者理解意图。

- **技术可行性**：高；无需数据；用现有信号（滑移、碰撞代理、目标跳变、遮挡）。
- **所需资源**：0.5 人 ×1 周；单任务 A/B。
- **落地步骤**：定义失败模式 → 实现原语 → 限速/限幅/限时 → 与 P2 的风险门控合并 → 测成功/步骤分/耗时。
- **风险**：额外动作可能降低步骤分/超时；恢复不一定比重试好；规则可能过拟合少量任务。
- **状态**：主投的附属项；与 P2 一起做。

## 7. 竞赛策略与算术

### 7.1 320 trials 是投资组合

- 总分 `S = (1/32) Σ p_t`，`p_t` 是任务 t 的 10 次平均成功率。
- 人为干扰轴 = 2/10 = **20%**；`ΔS_human = 0.2 Δp_h`。
- 跨机器人个性化影响 **100%** trials；但没有「轴权重」，只能靠 A/B 估计。
- 320 trials 下，`p≈0.25` 的单次标准误约 `sqrt(0.25×0.75/320)=2.42pp`；配对 A/B 会低一些，但**不要声称 +1–2pp 是结论**。

| 杠杆 | 覆盖 | 保守增益 | 乐观增益 | 备注 |
|---|---|---:|---:|---|
| P1 跨机器人在线标定 | 320 trials | +2pp（若 10% 失败与标定相关） | +5–6pp（若 20–25% 相关） | 需单任务 A/B + 注入偏置 |
| P2 human 轴让步 | 64 trials | +2pp（human +10pp） | +6pp（human +30pp） | 只在 human 轴生效 |
| P3 可读恢复 | 全部失败段 | +0–2pp | +3pp | 主要防超时/碰撞 |
| 第 12 轮接触伺服 | ~190 trials | +3pp | +7pp | 与本轮叠加 |

**不要**把四项简单相加；它们有重叠（接触失败可能也被人为干扰触发）。用配对 A/B 和 bootstrap 报告 95% CI。

### 7.2 单任务通道协议（不计分，但决定是否烧正式提交）

1. 选 5 个代表任务：PlugInEthernet（插入）、HangCup（挂）、ZipUp（拉链）、StackBowls（叠）、FoldTowel（变形/防回归）。
2. 每个任务 5 次 A/B：P1 off/on；P2 off/on；同一初始条件；记录成功、步骤分、耗时、p99 延迟、恢复次数、多余等待。
3. 通过标准：P1 至少 3/5 任务不回归且 2/5 +5pp；P2 至少 2/5 human 轴 +10pp；FoldTowel 不回归 >5pp。
4. 再扫 `H_c ∈ {3,5,8}`、`d_safe`、`θ`；选 p99 延迟和成功率的最佳折中。
5. 最后才跑 32×10 正式评测。

### 7.3 提交节奏

- **W0**：官方 WLA + API adapter + 基线；单任务 1 个任务跑通；测 RTT/端口。
- **W1**：P1 离线回放 + 单任务 A/B；若允许多次提交，先交安全基线锁 tie-break。
- **W2–W3**：P2 第一层（物体位移/变点）+ 风险门控；再做第二层人手检测。
- **W4**：LEG-R + 合并 CHUNK-SERVO；N 端口干跑。
- **W5**：32×10 干跑；最终提交；保留回滚开关。

## 8. 风险与合规

| 风险 | 影响 | 缓解 |
|---|---|---|
| 单模型解释 | 被判定为第二个模型 | P1/P2 无学习权重；人手检测用确定性 CV 或同 VLA encoder；提交材料写清 |
| 在线更新权重 | 合规/灾难遗忘 | 不更新权重；只估计 6+6+RTT/增益 |
| 跨 episode 记忆 | 违反 reset 隔离 | 默认 episode 内；持久化需书面确认 |
| 人手误报/多余等待 | 拖慢任务 | 风险门控 + 意图信念；先只做物体位移 |
| 人不 visible | P2 失效 | 第一层物体残差兜底；不假设人可见 |
| 动作偏置估计噪声 | 过度修正 | 置信度门控；置信度低回退原动作 |
| 标定激励不足 | 不可辨识 | 自由空间自然变化；必要时 ≤5 mm dither；不要影响接触 |
| RTT 高 | 伺服/预测失效 | 5 步 chunk；降增益；只做 PBVS/停等 |
| 安全 | 回撤/重抓碰撞 | 限速/限幅/最大重试；风险高即停 |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、重复实验；320 trials SE≈2.4pp |
| 预览榜单误导 | 工程投错任务 | 只在单任务通道排序；不把 29.7% 当 SOTA |
| 外部数据许可 | 不能用 HABIT | 先确认 license；P5 条件项 |

## 2. 问题形式化

### 2.1 评分模型

设任务 $t$ 的 10 次运行成功指示为 $y_{t,j}\in\{0,1\}$，则

$$p_t=\frac{1}{10}\sum_{j=1}^{10}y_{t,j},\qquad S=\frac{1}{32}\sum_{t=1}^{32}p_t.$$

人为干扰轴每任务 2 次，因此

$$\Delta S_{\text{human}}=0.2\,\Delta p_h.$$

320 trials 下，若 $p\approx0.25$，单次标准误约

$$\mathrm{SE}=\sqrt{\frac{0.25\times0.75}{320}}\approx2.42\text{ pp}.$$

配对 A/B 会降低方差，但**不要把 +1–2 pp 当结论**；至少报告 bootstrap 95% CI。

### 2.2 跨机器人标定（PERSONA-E）

对每轴 $k\in\{x,y,z,roll,pitch,yaw\}$，假设仿射：

$$p_{t,k}=s_k a_{t,k}+b_k+\varepsilon_{t,k},\qquad \varepsilon\sim\mathcal N(0,\sigma^2).$$

写成回归形式 $\phi_t=[1,a_t]\in\mathbb R^{7}$，$\theta_k=[b_k,s_k]^\top$。带遗忘因子 $\lambda\in(0,1]$ 的 RLS：

$$K_t=\frac{P_{t-1}\phi_t}{\lambda+\phi_t^\top P_{t-1}\phi_t},$$

$$\theta_t=\theta_{t-1}+K_t\left(p_t-\phi_t^\top\theta_{t-1}\right),$$

$$P_t=\frac{P_{t-1}-K_t\phi_t^\top P_{t-1}}{\lambda}.$$

下发时做逆修正：

$$a_{\text{cmd},k}=\frac{a_{\text{des},k}-\hat b_k}{\hat s_k}.$$

**可辨识性**：需要 $a_t$ 有足够变化；自由空间接近段通常有 5–15 cm 变化，足够估计偏置；若某轴几乎不动，$P_t$ 的方差大，置信度低，不修正。必要时注入 ≤5 mm dither（仅自由空间，接触段禁止）。

**置信度门控**：用 $P_t$ 的迹或 $\hat\sigma^2$ 构造

$$c_k=\frac{1}{1+\alpha\,\mathrm{tr}(P_{t,k})},$$

只有 $c_k>c_{\min}$ 才应用修正；否则回退原始动作。

**RTT/增益**：设 chunk 长度 $H_c$、控制频率 $f_c$、网络/执行延迟 $\tau$，则反馈周期

$$T_{\text{fb}}=\frac{H_c}{f_c}+\tau.$$

伺服增益按 $K_{\text{eff}}=K_0/(1+\tau/\tau_0)$ 降；$\tau$ 大时增大 $H_c$（第 12 轮已展开）。

**视觉归一化**：对四路图做每机器人/每场景的曝光/白平衡/直方图匹配；只用于确定性检测与伺服，不改变 VLA 的输入语义。若 VLA 对颜色敏感，保留原始图给 VLA，归一化图给检测器。

### 2.3 人在环风险（PERSONA-H）

**场景残差**：用机器人自身动作/EE 位姿预测下一帧（光流/特征/深度），残差

$$r_t=\|I_t-\hat I_t(a_t)\|.$$

若残差区域与目标物/受器重叠，则目标被移动；更新 $T_{\text{base}}^{\text{target}}$。

**短时预测**：人手状态 $(x_h,v_h)$，预测

$$\hat x_h(t+\tau)=x_h+v_h\tau,\qquad \tau\in[0,0.8\text{ s}].$$

机器人按计划 chunk 预测 $\hat x_r(t+\tau)$。风险

$$R_t=\max_{\tau\in[0,H]}\sigma\!\left(\frac{d_{\text{safe}}-\|\hat x_r(t+\tau)-\hat x_h(t+\tau)\|}{\kappa}\right).$$

若 $R_t>\theta$，进入 `YIELD`；否则 `PASS`/`SLOW`。

**意图信念**：维护 $P(o\mid z_{0:t})$，$o$ 是「人手当前操作/将要移动的物体」。用「手-物体距离、物体运动方向、语言、演示先验」做贝叶斯更新；若 $P(o=\text{my target})$ 高，提前 `REPLAN`；若指向无关物体，只做安全避让。

**多余等待**：定义

$$\text{FW}=P(\text{wait}\mid \min_t d(t)>d_{\text{safe}}).$$

P2 的目标不是「永不碰撞」，而是「在 FW 可控的前提下降低碰撞」。合成实验显示预测会把 FW 推到 37%，所以必须有意图信念/风险门控（见 §4.2）。

**回退**：人手不可见/遮挡时只用场景残差；不要假设「没看到人 = 没干扰」。

### 2.4 在线学习约束

| 方法 | 可行性 | 原因 |
|---|---|---|
| RLS/Kalman 标定 | 可行 | 只需观测；CPU；无标签 |
| CUSUM/变点检测 | 可行 | 只需时序残差 |
| 贝叶斯意图滤波 | 可行 | 离散状态；手工似然 |
| 演示检索 | 可行 | 冻结索引；非学习权重 |
| 在线 RL/TT-VLA/TIDE | 不可行 | 无 reward/接管；180 s；单模型 |
| 在线权重更新 | 高风险 | 合规/延迟/遗忘 |
| 跨 episode 学习 | 灰区 | `reset()` 隔离；默认不做 |
| 第二个学习检测器 | 高风险 | 单模型解释 |

## 3. 系统设计

### 3.1 架构

```text
Evaluator (N ports 8765..8765+N-1)
        │ obs: 4 RGB + state + language
        ▼
Per-port PolicyService (CPU, one process per port)
  ├─ CHUNK-SERVO: 30-step plan, 5-step servo, demo retrieval
  ├─ PERSONA-E: RLS calibration + RTT/gain + visual normalization
  ├─ PERSONA-H: scene residual + human track + risk/intent
  ├─ LEG-R: failure-mode recovery primitives
  └─ action adapter: WLA 54D -> API ee/joint chunk
        │ async batched inference
        ▼
Shared VLA server (GPU): UnifoLM-WLA-1.0 / VLA-0
```

- 唯一学习模型：VLA（官方 WLA 微调 action head）。
- PERSONA/LEG-R 无学习权重；不加载第二个模型。
- 每端口状态独立；VLA server 无 episode 状态。
- 数字孪生只做标定/压力测试，不训练策略。

### 3.2 状态机

```text
PLAN ──chunk done──> SERVO ──contact/insert──> SERVO
  │                    │
  │                    ├─ residual/target moved ──> RELOCALIZE ──> PLAN
  │                    ├─ human risk > θ ─────────> YIELD ──human gone──> RELOCALIZE
  │                    └─ failure mode ───────────> RECOVER ──ok──> PLAN
  └─ timeout/too many retries ──> SAFE_STOP
```

### 3.3 伪代码

```python
class PersonaPolicy:
    def __init__(self, vla, cfg):
        self.vla = vla
        self.calib = RLSCalibration(dim=6, lam=cfg.lam)
        self.human = HumanRisk(cfg)
        self.leg = LegibleRecovery(cfg)
        self.cfg = cfg
        self.reset()

    def reset(self):
        self.plan = None
        self.plan_idx = 0
        self.last_cmd = None
        self.human.reset()
        self.leg.reset()
        self.state = "PLAN"
        # 默认 episode 内标定；跨 episode 持久化需官方确认
        self.calib.reset_episode()

    def act(self, obs):
        self.calib.update(obs.ee_pose, self.last_cmd)
        self.human.update(obs)

        if self.human.risk(obs) > self.cfg.theta:
            self.state = "YIELD"
            return self._yield(obs)

        if self.human.target_moved(obs):
            self.state = "RELOCALIZE"
            self.plan = None

        if self.plan is None or self.plan_idx >= len(self.plan):
            self.plan = self._make_plan(obs)
            self.plan_idx = 0

        if self.leg.failure(obs):
            self.state = "RECOVER"
            return self._recover(obs)

        a_des = self._next_servo_action(obs)
        a_cmd = self.calib.inverse(a_des)
        self.last_cmd = a_cmd
        return self._to_api(a_cmd)

    def _make_plan(self, obs):
        # 30-step coarse plan from VLA + demo retrieval; no weights updated
        chunk = self.vla.infer(obs, horizon=self.cfg.H_plan)
        return self.servo.refine(chunk, obs)

    def _next_servo_action(self, obs):
        # 5-step visual servo / relative target; uses normalized images
        return self.servo.step(obs, self.plan, self.plan_idx)

    def _yield(self, obs):
        # smooth arc retract 5-10 cm, pause, hold; legible
        return self.leg.yield_chunk(obs, distance=self.cfg.yield_dist)

    def _recover(self, obs):
        return self.leg.recover_chunk(obs, self.leg.mode)
```

`RLSCalibration.update`：

```python
def update(self, p, a):
    if a is None or p is None:
        return
    for k in range(6):
        phi = np.array([1.0, a[k]])
        K = self.P[k] @ phi / (self.lam + phi @ self.P[k] @ phi)
        self.theta[k] += K * (p[k] - phi @ self.theta[k])
        self.P[k] = (self.P[k] - np.outer(K, phi) @ self.P[k]) / self.lam
```

`inverse`：

```python
def inverse(self, a_des):
    out = a_des.copy()
    for k in range(6):
        b, s = self.theta[k]
        if self.confidence(k) > self.c_min and abs(s) > 1e-3:
            out[k] = (a_des[k] - b) / s
    return out
```

### 3.5 合规设计

- **单模型**：VLA 是唯一学习模型；PERSONA/LEG-R 是确定性估计/控制；不加载第二个 checkpoint。
- **在线学习**：只更新 6+6 维仿射参数/RTT/增益/离散意图，不更新 VLA 权重。
- **reset 隔离**：每端口 `reset()` 清 episode 状态；默认不跨 episode 记忆；若允许端口级缓存，需书面确认并在材料中说明。
- **人手检测**：优先确定性 CV（运动/视差/肤色/形状）；若用学习检测器，只用同一 VLA encoder 或离线标定，不上线第二个模型。
- **安全**：恢复/让步限速、限幅、限时；风险高即 `SAFE_STOP`。

## 4. 实验与结果

### 4.1 合成实验 1：RLS 在线标定（C 级）

脚本：`/tmp/opencode/unibot/sim_persona.py`（numpy，30 步，3 轴，噪声 1 mm）。真值：`b=[8,-6,4] mm`，`s=[1.04,0.97,1.00]`。估计结果：

| 指标 | 结果 |
|---|---|
| 估计偏置 | `[8.027, -6.332, 4.020] mm` |
| 估计尺度 | `[1.04718, 0.96861, 1.00034]` |
| 偏置误差（初始） | **10.754 mm** |
| 偏置误差（第 5 步） | 0.672 mm |
| 偏置误差（第 10 步） | 0.574 mm |
| 偏置误差（第 30 步） | **0.334 mm** |
| 最终残差 | 1.137 mm（噪声 1 mm） |

**解释**：在 1 mm 观测噪声下，30 步能把 10.75 mm 的系统偏置压到 0.33 mm；尺度估计误差 <0.5%。这只是机制 sanity check，不代表真机；真机的偏置可能更小、激励可能不足、旋转轴可能有非线性。

**用途**：支持 P1 的「在线标定可行」假设；H1 的通过标准（30 步 ≤2 mm/0.5°）来自这里。

### 4.2 合成实验 2：人在环预测性让步（C 级，负结果）

脚本：`/tmp/opencode/unibot/sim_persona3.py`（2D toy，30 Hz，100 ms 延迟，5 mm 噪声，5% 检测漏报；人横穿机器人路径，可能停顿/折返；6,000 episodes）。三种策略：

| 策略 | 碰撞率 | 平均时间 | 等待率 | 等待中多余等待 |
|---|---:|---:|---:|---:|
| 无避让 | **27.05%** | 9.07 s | — | — |
| 反应式（看到才让） | 26.27% | 9.45 s | 28.02% | 11.18% |
| 预测 0.5 s | **19.10%** | 10.57 s | **49.33%** | **37.09%** |

**解释**：

- 预测确实降碰撞（27.1% → 19.1%，相对 -29%），但代价是等待率从 28% 涨到 49%，且 37% 的等待是多余的（最近距离仍大于安全距离）。
- 反应式几乎不降碰撞，说明「看到才让」太晚。
- **结论**：只靠短时预测不够；必须有**风险门控 + 意图信念**（人是否真的要穿过、是否要动我的目标），否则会把时间浪费在假阳性上。这直接指导 P2 的三层设计：场景残差（必要）→ 人手跟踪（可选）→ 意图/风险门控（决定是否让）。

**局限**：2D、无真实人手检测、无 VLA、无接触动力学；不能外推为真机增益。它的价值是暴露 trade-off，而不是证明 P2 能涨点。

### 4.3 榜单取证（B 级，真实数据）

见 §1.3：R² > 0.999999、254/256 非整数倍、平均跨模型任务相关 0.098。结论：预览数据；不用它做任务排序/失败分析。

### 4.4 计划中的真机/单任务实验（H0–H7）

| 门 | 设计 | 通过标准 | 失败动作 |
|---|---|---|---|
| H0 | API/端口/延迟 | N 端口隔离；`reset()` 干净；RTT 可测；无 567/超时 | 先修部署 |
| H1 | 标定离线回放 + 单任务 A/B | 30 步偏置误差 ≤2 mm/0.5°；开/关不回归 | 只做 RTT/增益 |
| H2 | 合成扰动注入 | 残差 recall ≥80%、precision ≥70%；延迟 ≤100 ms | 只做物体位移 |
| H3 | human 轴 A/B（单任务通道） | ≥2/5 任务 +10pp；非 human 不回归 >5pp | 不提交 P2 |
| H4 | 让步安全/可读 | 碰撞 ↓50%；多余等待 ≤10%；恢复 ≤3 s | 降级「停-等」 |
| H5 | 跨机器人注入偏置 | 3 组偏置下成功率不降 >3pp；无端口串扰 | 回退统一标定 |
| H6 | 32×10 干跑 | p99 ≤150 ms；内存稳定；端口隔离 | 回退基线 |
| H7 | 消融 | P1/P2 各自有正贡献；LEG-R 不回归 | 砍无效部分 |

**单任务选择**：PlugInEthernet（插入）、HangCup（挂）、ZipUp（拉链）、StackBowls（叠）、FoldTowel（变形/防回归）。每任务 5 次 A/B，同一初始条件；记录成功、步骤分、耗时、p99 延迟、恢复次数、多余等待。

### 4.5 统计与报告

- 成功率：Wilson 区间；A/B 用配对 bootstrap（10k 次）报告 Δ 的 95% CI。
- 延迟：p50/p95/p99；按端口分层。
- 恢复：失败模式计数、恢复成功/二次失败、额外耗时。
- 不把预览榜单的步骤分当真实步骤分；真实步骤分规则未知，先保成功率。
