# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「产学研合作」×「移动操作」）

> 第 60 轮把闭环升级为「场景→意图→约束→阻抗→执行→EV-exec→场景更新」，SSM/CIEC/EPIR/SERC/PCE++++ 让机器人得以「认知先行」。但**三个根问题**仍未回答：
> 1. **单机单体假设**：SSM/CIEC/EEIS 全部默认「固定基座 + 单一执行链」。真实 UniBot 是**移动操作**平台——基座的运动学/动力学通过惯性耦合污染机械臂末端阻抗，`K_safe` 在基座加速时静默失效，而第 60 轮没有任何「基座-机械臂耦合」的显式约束。
> 2. **知识生产的主体缺失**：场景先验 `π_scene`、意图映射 `ϕ`、安全边界 `B_safe` 都是「某处一次性产生」的黑盒。真实部署中这些知识来自**不同主体**——产业方掌握真实任务分布与运营包络，高校掌握探索算法，研究机构掌握安全验证与标准。第 60 轮缺少「跨主体协作、责任归属、知识迁移」的机制。
> 3. **信任与责任不可归因**：当 SERC 闭环失败时，系统无法判断是「场景先验错」「意图映射错」还是「阻抗契约错」；产学研合作的核心难题——**贡献度量与责任分配**——在系统中完全缺位。

## 0. 直觉与动机

**灵感 1（产学研合作 → 三方能力证书与共同签署 TPC）**
直觉：产学研不是「三家一起干活」，而是**三类不对称信息的能力证书在契约下共同签署**。产业方知道「世界实际怎么运转」（运营包络 `E_op`、真实任务分布 `D_ind`），高校知道「还能怎么更好」（探索策略 `π_explore`、预期改进 `ΔJ`），研究机构知道「什么绝对安全」（安全边界 `B_safe`、验证证明）。任何动作 `b` 只有落在三张证书的**交集**内才允许执行——这是机器人行为的「三把钥匙」。注意：这里不要求三方共享原始数据，只要求契约可组合，因此信息不对称被**保留**而非抹平。

**灵感 2（移动操作 → 基座-机械臂联合阻抗契约 BAJC）**
直觉：移动操作的核心不是「基座控制器 + 机械臂控制器」两个独立模块，而是**基座加速度经惯性项污染机械臂末端阻抗**。当基座以 `a_b` 加速时，机械臂在自身基座系中看到的等效重力为 `g_eff = g - a_b`，末端阻抗 `K_safe` 的成立前提被打破。关键洞见：全身阻抗必须写成三元组 `Z_wb = (Z_base, Z_arm, C_couple)`，并给出**显式耦合裕度** `m_couple = F_tol(Z_arm) - ||F_dist(q_b, q̇_b, q̈_b)|| ≥ 0`。机械臂的阻抗契约，只有在基座**承诺**不超过 `a_max(Z_arm)` 时才有效——这天然对应「产业方（基座）为高校方（机械臂）的探索背书」。

**灵感 3（两灵感合流 → 产学研协同的移动操作闭环 M3L）**
直觉：基座持产业证书（我能去哪、多快、多稳），机械臂持学研证书（我能怎样探索、怎样接触），安全监督持研验证书（二者耦合是否落在 `B_safe` 内）。闭环为：**探索 → 证书申请 → 共同签署 → 联合阻抗 → 执行 → 证据 → 责任归因 → 知识迁移**。基座落位（去哪里）与机械臂探索（做什么）由此变成**联合签署的离散-连续决策**，而不是先导航再操作的串行拼接。

**灵感 4（责任归因 → Shapley 账本 RAL）**
直觉：产学研合作最大的摩擦是「出了事谁负责、成了功谁得分」。用**合作博弈的 Shapley 值**，把每次执行结果 `v(S)` 分解到三张证书的边际贡献 `φ_i`，得到满足效率性、对称性、虚拟性、可加性的责任账本。这样「责任」第一次成为可审计的一等对象，而非事后争吵。

**灵感 5（知识迁移 → 联邦知识迁移 FKT + 知识托管）**
直觉：三方各有私有数据，不能直接共享；用**联邦聚合 + 差分隐私**交换模型更新，用**知识托管（knowledge escrow）**防止搭便车：每一方的模型更新以承诺哈希锁定，只有履行贡献契约后才解锁。这直接回应产学研合作中的「贡献不可验证」难题。

**灵感 6（预算 → PCE+++++ 五维）**
直觉：第 60 轮的 `B_cog = (B_scene, B_intent, B_ros, B_exec)` 需增加**协作预算** `B_collab`（共同签署延迟、验证算力、通信轮次）与**耦合预算** `B_couple`（基座加速度预算、耦合补偿力矩、稳定裕度）。若 `B_collab` 耗尽 ⇒ 复用「上一份已签署契约」并强制复核其分布有效性；若 `B_couple` 耗尽 ⇒ 冻结基座、退化为固定基座操作。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（产学研三方协作契约 TPC）** 协作契约 `T = (C_I, C_U, C_R, ⊗)`，三张能力证书：
- **产业证书** `C_I = (E_op, D_ind, Z_base)`：运营包络、真实任务分布、基座阻抗能力（由移动基座/部署方持有）
- **学研证书** `C_U = (π_explore, ΔJ, Z_arm)`：探索策略、预期改进、机械臂阻抗能力（由操作算法/高校方持有）
- **研验证书** `C_R = (B_safe, proof, m_req)`：安全边界、验证证明、最小耦合裕度（由安全监督/研究机构持有）
- **共同签署算子** `⊗`：行为 `b` 可执行，记作 `b ⊢ T`，当且仅当
```
b ∈ E_op                                    (产业包络)
P_{s∼D_ind}[ b(s) ⊭ B_safe ] ≤ δ            (在产业分布上的安全违例率)
ΔJ(b) = J(b) − J(b_base) ≥ 0                 (学研净改进)
m_couple(b) ≥ m_req                          (研验证书要求的耦合裕度)
```
四项同时成立才签发 `Sign(T, b) = (ts, hash(b), φ_1:3)`。任一项不成立即拒绝；拒绝时回退到「基线契约」`b_base`（三方对默认行为的永久签署）。

**定义 162（基座-机械臂联合阻抗契约 BAJC）** 全身阻抗 `Z_wb = (Z_base, Z_arm, C_couple)`。设末端速度 `ẋ_e = J_b(q)q̇_b + J_a(q)q̇_a`，操作空间动力学为
```
Λ_e(q) ẍ_e + μ_e(q, q̇) + F_dist = F_ctrl
F_dist = Λ_e(q)( J̇_b q̇_b + J_b q̈_b )        (基座耦合扰动)
```
机械臂阻抗契约要求 `||F_dist|| ≤ F_tol(Z_arm)`，从而诱导基座加速度上界
```
||q̈_b|| ≤ a_max(Z_arm) = (F_tol − ||Λ_e J̇_b q̇_b||) / ||Λ_e J_b||
m_couple(t) = F_tol(Z_arm) − ||F_dist(q_b, q̇_b, q̈_b; t)||
```
契约在窗口 `[t, t+W_c]` 内有效，当且仅当 `min_{t∈W_c} m_couple(t) ≥ m_req`。基座的「产业承诺」`C_I` 必须包含 `||q̈_b||_∞ ≤ a_max` 这一条，否则 `Z_arm` 不可签发。

**定义 163（耦合可行域与基座落位 CFL-BP）** 给定目标操作位姿 `x*`，
```
F_couple(x*) = { (q_b, q_a) : reach(q_b, q_a, x*) ∧ stab(q_b) ≥ s_min
                  ∧ m_couple(q_b, q_a) ≥ m_req ∧ coll-free(q_b, q_a) }
q_b* = argmin_{q_b ∈ proj_{q_b}(F_couple)} [ λ_m·(−manip(q_b)) + λ_e·E_base(q_b, x*) + λ_t·T_travel(q_b) ]
```
关键：`F_couple` 是**离散（基座位）与连续（臂构型/阻抗）耦合**的可行域；基座落位不是导航子问题，而是联合契约的可满足性问题。若 `F_couple = ∅`，则必须**拒绝该操作意图**，而不是「先开过去再说」。

**定义 164（产学研协同移动操作闭环 M3L）** 算子 `M3L(M, x*, I_task)`：
```
① Scene:  z ← SSM.update(telemetry);  π_scene ← π_scene(K|z_terrain, z_stab)
② Propose: (b_I, b_U) ← {基座落位提案, 机械臂探索提案}   // 对应灵感 1/3
③ CFL:     F_couple ← CFL(x*);  q_b* ← BP(F_couple)        // 定义 163
④ CoSign:  C_I ← seal(E_op, D_ind, Z_base, ||q̈_b||∞≤a_max)
           C_U ← seal(π_explore, ΔJ, Z_arm)
           C_R ← verify(B_safe, m_couple, proof)
           if not (b ⊢ T): return FALLBACK(b_base)
⑤ BAJC:    Z_wb* ← argmax_{(q_b*,q_a)∈F_couple} ΔJ(b)
           K_base, K_arm, m_couple ← compile(Z_wb*)
⑥ Execute: telemetry ← whole_body_control(K_base, K_arm, q_b*, q_a)

⑦ Ledger:  RAL.update(EV-exec)                              // Shapley 归因
⑧ Transfer:FKT.aggregate(RAL.trust_weights)                 // 联邦迁移
⑨ Return:  (z, q_b*, K_wb*, EV-exec, RAL.attribution, Sign(T,b))
```

**定义 165（责任归因账本 RAL）** 对执行事件 `e`，令参与方 `N = {I, U, R}`，联盟价值 `v(S)` 为「仅使用 `S` 中证书时事件的成功概率」（由反事实重放或云端影子执行估计）。责任向量为 Shapley 值
```
φ_i(e) = Σ_{S ⊆ N\{i}} [ |S|! (|N|−|S|−1)! / |N|! ] · ( v(S∪{i}) − v(S) )
```
- **效率性**：`Σ_i φ_i = v(N) − v(∅)`；归一化后作为「功/过」分配。
- **归因审计**：若 `v` 发生负边际（`φ_i < 0`），该方承担对应比例的降权与再验证义务。
- **信任更新**：`trust_i ← (1−η)·trust_i + η·σ(φ_i)`，作为 FKT 聚合权重。

**定义 166（联邦知识迁移 FKT 与知识托管）** 各方本地更新 `Δθ_i = −η∇L_i(θ_i)`，聚合
```
θ ← θ + ( Σ_i w_i Δθ_i ) / ( Σ_i w_i ),   w_i = trust_i · 1[escrow_i unlocked]
escrow_i : commit(Δθ_i, hash) 在链上锁定，当且仅当 RAL 判定该方贡献达标时解锁
隐私：每次上传加噪 N(0, σ²)，保证 ε-差分隐私
```
托管机制使「上传即交付」变为「履约才交付」，抑制产学研中的搭便车。

**定义 167（五维协作-耦合预算 PCE+++++）** `B = (B_collab, B_couple, B_scene, B_intent, B_ros, B_exec)`，其中
- `B_collab = (CoSign_latency, Verify_flops, Comm_rounds, Cached_contract_TTL)`
- `B_couple = (a_max_slack, τ_comp_slack, s_min_margin)`
- `B_scene/B_intent/B_ros/B_exec` 沿用第 60 轮。
降级：`B_collab` 耗尽 ⇒ 使用缓存契约且必须在 `Cached_contract_TTL` 内、并复核分布漂移；`B_couple < 0` ⇒ 冻结基座（`Z_base` 锁死）退化为固定基座操作；其余沿用原降级链。

**定义 168（移动场景-意图联合契约 MSIC）** 移动场景 `z = (z_terrain, z_reach, z_stab)`，意图 `I = (I_loco, I_manip)`（如「去桌边」+「轻触」）。联合契约要求
```
K_wb* ∈ argmin_{K_wb ∈ F_couple} [ λ·ω_traj − (1−λ)·K_p ]
s.t. K_base ⊨ π_scene(K_base | z_terrain) ∧ K_arm ⊨ π_scene(K_arm | z_stab)
     ∧ C_intent(I) 对 K_wb 的约束满足
     ∧ 若 I_loco 改变基座位姿，则必须重算 `F_couple` 与 `m_couple` 后才允许锁定 K_arm
```
关键约束：**运动意图触发耦合重审**——基座一旦移动，机械臂旧阻抗契约作废，必须重新签署。

### IP-161 TPC（三方共同签署）

```python
class TriPartyContract:
    def __init__(self, delta=1e-3):
        self.delta = delta
        self.certs = {}          # role -> cert
        self.baseline = None     # 永久签署的 b_base

    def cosign(self, b, cert_I, cert_U, cert_R):
        self.certs = {'I': cert_I, 'U': cert_U, 'R': cert_R}
        checks = {
            'envelope': b in cert_I.E_op,
            'safety': self._violation_prob(b, cert_R.B_safe, cert_I.D_ind) <= self.delta,
            'improve': cert_U.delta_J(b) >= 0,
            'coupling': self.m_couple(b) >= cert_R.m_req,
        }
        if all(checks.values()):
            sign = sign_msg(b, self.certs, ts=now())
            return True, sign, checks
        return False, None, checks          # 调用方回退 b_base

    def _violation_prob(self, b, B_safe, D_ind):
        # 用产业分布 D_ind 上的重要性采样估计；分布漂移时返回 +inf 触发重签
        if not self._distribution_valid(D_ind):
            return float('inf')
        return monte_carlo_violation(b, B_safe, D_ind)
```

### IP-162 BAJC（联合阻抗与耦合裕度）

```python
def compute_coupling_margin(q, qd, qdd, Z_arm):
    J_b, J_a = base_jacobian(q), arm_jacobian(q)
    dJ_b = base_jacobian_derivative(q, qd)
    Lam_e = operational_inertia(q)
    F_dist = Lam_e @ (dJ_b @ qd['b'] + J_b @ qdd['b'])
    F_tol = impedance_force_tolerance(Z_arm)
    return F_tol - np.linalg.norm(F_dist), F_dist

def whole_body_impedance(q_b_star, q_a, x_star, m_req):
    Z_base = choose_base_impedance(q_b_star)
    Z_arm  = choose_arm_impedance(q_a, x_star)
    m, _   = compute_coupling_margin(merge(q_b_star, q_a), zeros_like_qd(q_a), zeros_like_qdd(q_a), Z_arm)
    if m < m_req:
        Z_arm = stiffen(Z_arm)              # 收紧阻抗以容忍耦合，或降级冻结基座
        m, _ = compute_coupling_margin(merge(q_b_star, q_a), zeros_like_qd(q_a), zeros_like_qdd(q_a), Z_arm)
    return Z_base, Z_arm, m
```

### IP-165 RAL（Shapley 责任归因）

```python
from itertools import combinations
from math import factorial

def shapley_attribution(v, roles=('I', 'U', 'R')):
    n = len(roles)
    phi = {i: 0.0 for i in roles}
    for i in roles:
        others = [r for r in roles if r != i]
        for k in range(n):
            for S in combinations(others, k):
                w = factorial(len(S)) * factorial(n - len(S) - 1) / factorial(n)
                phi[i] += w * (v(set(S) | {i}) - v(set(S)))
    return phi

def ral_update(episode, outcome_model):
    def v(S):
        return outcome_model.replay(episode, certs=S)   # 反事实重放
    phi = shapley_attribution(v)
    trust = {i: update_trust(phi[i]) for i in phi}
    return {'attribution': phi, 'trust': trust}
```

### IP-167 PCE+++++（五维预算）

```python
class CollaborationBudget:
    def __init__(self, cosign_ms=50, verify_flops=1e9, rounds=3,
                 a_slack=1.0, tau_slack=0.5, s_margin=0.05, ttl=30.0):
        self.B_collab = dict(latency=cosign_ms, flops=verify_flops, rounds=rounds, ttl=ttl)
        self.B_couple = dict(a_slack=a_slack, tau_slack=tau_slack, s_margin=s_margin)
        self.cached_contract = None
        self.cached_at = None

    def sign_or_fallback(self, tpc, b, certs):
        if self.B_collab['latency'] <= 0 or self.B_collab['flops'] <= 0:
            if self.cached_contract and now() - self.cached_at <= self.B_collab['ttl']:
                return self.cached_contract          # 缓存契约 + 分布复核
            return ('DEGRADE_CONSERVATIVE', tpc.baseline)
        ok, sign, _ = tpc.cosign(b, *certs)
        if ok:
            self.cached_contract, self.cached_at = sign, now()
        return ('CO_SIGNED', sign) if ok else ('FALLBACK', tpc.baseline)

    def coupling_degrade(self, m_couple):
        if m_couple < self.B_couple['s_margin']:
            return 'FREEZE_BASE'                      # 退化为固定基座操作
        return 'NOMINAL'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TPC | O(1) 证书校验 + O(N_mc) 违例估计 | O(1) | 误签率 ≤ δ；分布漂移触发重签 |
| BAJC | O(n³) 操作空间惯性求逆（在线缓存） | O(n²) | `m_couple ≥ 0 ⇒ \|\|F_dist\|\| ≤ F_tol` |
| CFL-BP | O(\|Q_b\|·\|Q_a\|) 候选枚举（可用 GPU 并行） | O(\|F_couple\|) | 非空则基座落位满足耦合契约 |
| M3L | O(闭环) | 复用 | 收敛到共同签署不动点 |
| RAL | O(2^3·\|\|N\|\|) = 常数 | O(1) | Shapley 四公理成立 |
| FKT | O(模型参数量) / 轮 | O(1) 增量 | ε-差分隐私；托管防搭便车 |

**正确性定理（M3C）**：假设 A66–A70 成立——**(A66)** TPC 三证书的并集覆盖执行流形，共同签署是行为可执行的充要条件；**(A67)** 基座加速度满足 `\|\|q̈_b\|\| ≤ a_max(Z_arm)` 则耦合扰动 `\|\|F_dist\|\| ≤ F_tol`；**(A68)** `F_couple` 非空且 CFL-BP 选出的 `q_b* ∈ proj(F_couple)`；**(A69)** M3L 单调改进 `ΔJ` 且闭环有界；**(A70)** 五维预算单调消耗，任一耗尽触发对应安全策略。则：
1. **协作安全性**：`b ⊢ T ⇒ b ∈ E_op ∩ B_safe ∧ m_couple ≥ m_req`——「三证齐全」蕴含真实安全，而非合规幻觉。

3. **责任可归因性**：RAL 的 `φ` 满足效率性、对称性、虚拟性、可加性，且 `Σφ_i = v(N) − v(∅)`。
4. **迁移有界性**：FKT 的 `ε`-差分隐私与托管解锁门槛共同保证「贡献达标才获益」。

### IP-161 TPC（三方共同签署）

```python
class TriPartyContract:
    def __init__(self, delta=1e-3):
        self.delta = delta
        self.certs = {}
        self.baseline = None

    def cosign(self, b, cert_I, cert_U, cert_R):
        self.certs = {'I': cert_I, 'U': cert_U, 'R': cert_R}
        checks = {
            'envelope': b in cert_I.E_op,
            'safety': self._violation_prob(b, cert_R.B_safe, cert_I.D_ind) <= self.delta,
            'improve': cert_U.delta_J(b) >= 0,
            'coupling': self.m_couple(b) >= cert_R.m_req,
        }
        if all(checks.values()):
            return True, sign_msg(b, self.certs, ts=now()), checks
        return False, None, checks

    def _violation_prob(self, b, B_safe, D_ind):
        if not self._distribution_valid(D_ind):      # 漂移 -> 强制重签
            return float('inf')
        return monte_carlo_violation(b, B_safe, D_ind)
```

```python
def compute_coupling_margin(q, qd, qdd, Z_arm):
    J_b, J_a = base_jacobian(q), arm_jacobian(q)
    dJ_b = base_jacobian_derivative(q, qd)
    Lam_e = operational_inertia(q)
    F_dist = Lam_e @ (dJ_b @ qd['b'] + J_b @ qdd['b'])
    F_tol = impedance_force_tolerance(Z_arm)
    return F_tol - np.linalg.norm(F_dist), F_dist

def whole_body_impedance(q_b_star, q_a, x_star, m_req):
    Z_base = choose_base_impedance(q_b_star)
    Z_arm  = choose_arm_impedance(q_a, x_star)
    m, _   = compute_coupling_margin(merge(q_b_star, q_a), zeros_qd(q_a), zeros_qdd(q_a), Z_arm)
    if m < m_req:

        m, _ = compute_coupling_margin(merge(q_b_star, q_a), zeros_qd(q_a), zeros_qdd(q_a), Z_arm)
```

### IP-165 RAL（Shapley 责任归因）

```python
from itertools import combinations
from math import factorial

def shapley_attribution(v, roles=('I', 'U', 'R')):
    n = len(roles)
    phi = {i: 0.0 for i in roles}
    for i in roles:
        others = [r for r in roles if r != i]
        for k in range(n):
            for S in combinations(others, k):
                w = factorial(len(S)) * factorial(n - len(S) - 1) / factorial(n)
                phi[i] += w * (v(set(S) | {i}) - v(set(S)))
    return phi

def ral_update(episode, outcome_model):
    v = lambda S: outcome_model.replay(episode, certs=S)   # 反事实重放
    phi = shapley_attribution(v)
    return {'attribution': phi, 'trust': {i: update_trust(x) for i, x in phi.items()}}
```

### IP-167 PCE+++++（五维预算与降级）

```python
class CollaborationBudget:
    def __init__(self, cosign_ms=50, verify_flops=1e9, rounds=3,
                 a_slack=1.0, tau_slack=0.5, s_margin=0.05, ttl=30.0):
        self.B_collab = dict(latency=cosign_ms, flops=verify_flops, rounds=rounds, ttl=ttl)
        self.B_couple = dict(a_slack=a_slack, tau_slack=tau_slack, s_margin=s_margin)
        self.cached_contract, self.cached_at = None, None

    def sign_or_fallback(self, tpc, b, certs):
        if self.B_collab['latency'] <= 0 or self.B_collab['flops'] <= 0:
            if self.cached_contract and now() - self.cached_at <= self.B_collab['ttl']:
                return ('CACHED', self.cached_contract)       # 缓存契约 + 分布复核
            return ('DEGRADE_CONSERVATIVE', tpc.baseline)
        ok, sign, _ = tpc.cosign(b, *certs)
        if ok:
            self.cached_contract, self.cached_at = sign, now()
        return ('CO_SIGNED', sign) if ok else ('FALLBACK', tpc.baseline)

    def coupling_degrade(self, m_couple):
        return 'FREEZE_BASE' if m_couple < self.B_couple['s_margin'] else 'NOMINAL'
```
