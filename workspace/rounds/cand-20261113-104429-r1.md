# 第 67 轮（承接第 66 轮「RAS 情绪闭环」IP-224~233；本轮灵感：「移动底盘」×「跨任务泛化」）

> 第 66 轮 RAS 把闭环从「故障响应」升级为「意图感知」，但它仍默认两件事：**地面不动、任务唯一**——几何球、力限、情绪容差全部锚定在世界坐标系，证书只服务一个任务。移动底盘一上来就同时打破这两个默认：**世界帧会漂，任务帧会换**。
>
> 本轮的核心命题是：
>
> **移动底盘不是「把机器人搬来搬去」的附加轮子，而是「随身携带的安全坐标系」。把安全证书表达在底盘锚定、漂移补偿的坐标系里，就能让「任务不变的物理先验」跨任务复用，只用一个轻量残差适配新任务。**
>
> 框架命名 **TERRA**（Task-invariant Embodied Risk transfer with Rolling Anchor：滚动锚定 × 任务不变风险迁移）。它问的不再是「哪一层坏了」（VISTA）或「谁该控制、控制多少」（RAS），而是「**这套安全知识，能跟着底盘走到哪个新任务里，还依然成立**」。

## 0. 直觉与动机

**灵感 1（移动底盘 → 可移动的安全坐标系）**
直觉：固定基座时，「安全」是空间中一块静态几何；底盘一动，这块几何被「拖着走」，世界帧里的锚点立刻失效。真正不变的是**相对底盘的关系**——接触力、倾覆力矩、支撑多边形。所以底盘才是天然的安全原点：安全证书应锚在底盘上，而不是锚在世界的某个角落。

**灵感 2（移动底盘 → 惯性风险注入）**
直觉：手臂装在移动底盘上，底盘一加速，末端就凭空多出一份「虚拟力」。`F_eff = F_arm + M_eff(q)·a_B + Coriolis`。安全裕度不是常数，而是随加速度收缩；原本的几何球被拉成**沿加速度方向伸长的椭球**。移动越快、转向越急，安全边界越扁。

**灵感 3（跨任务泛化 → 任务不变的物理先验）**
直觉：倒水、擦桌、开门、递物……轨迹意图千差万别，但「加速度→惯性力」「摩擦」「柔顺」「质量分布」这些物理量是同一套。把故障签名拆成「任务不变子空间 + 任务残差」，跨任务迁移就退化为**冻结不变的、只学残差**——这比"每个任务重训一套安全模型"省得多，也更不容易遗忘。

**灵感 4（三灵感合流 → TERRA）**
闭环从 RAS 的 `ERG→EFS→C-RAS→ERS` 复制其时序骨架，换装为七件套：
1. **RAL Rolling Anchor Localization**：估计底盘位姿 `ξ_B` 与协方差 `Σ_B`，漂移超阈就重锚；
2. **CRI Chassis Risk Injection**：把 `a_B` 折进有效安全裕度 `ρ_safe^B` 与几何椭球 `Q_B`；
3. **TIR Task-Invariant Representation**：故障签名做 `Φ / Ψ` 分解，分离任务不变物理与任务残差；
4. **TCR Task-Conditioned Residual**：小容量头 `g_θ(z_inv, z_task)` 学任务偏移；
5. **CAR Chassis-Anchored Certificate**：把位姿、协方差、支撑多边形、椭球写进证书 `J_TERRA`；
6. **DGL Drift-Gated Lifelong transfer**：重锚 + 不变子空间正则，防跨任务遗忘；
7. **EBC Emotion-Base Coupling**：接近速度放大恐惧，升级第 66 轮的 `R_emotion`。

**灵感 5（对 RAS / VISTA 组件的底盘化升级）**
- `R_emotion → R_emotion^B(π, ||v_B - v_h||)`：同样的表情，在底盘高速逼近时风险更高；
- `λ_risk → λ_TERRA = λ_RAS · (1 + g_θ(z_inv, z_task))`：任务残差只在物理先验之上做微调；
- `ρ_safe → ρ_safe^B = ρ_safe - κ_a||a_B|| - κ_c||v_B × ω_B||`：惯性/离心项显式扣除；
- `C-RAS → C-TERRA`：认证前缀同时受 VISTA 安全、情绪容差、底盘稳定三重约束；
- `J_RAS → J_TERRA`：证书增 `ξ_B, Σ_B, a_B, Q_B, z_inv_hash, task_emb`；
- `AIC-RAS → AIC-TERRA`：干扰集增 `ℰ_base`（打滑、里程计漂移、任务混淆）。

## 1. 形式化定义（增量：定义 245–260）

- **定义 245（TERRA 总览）**：`TERRA = (RAL, CRI, TIR, TCR, CAR, DGL, EBC)`。定位：把 RAS 的「意图闭环」升级为「可移动、可迁移的安全闭环」。不变式：位姿融合、签名分解、迁移更新只在语义流；实时流只做锚点校验、椭球早停、支撑多边形判定，零在线学习写操作。
- **定义 246（滚动锚点）**：底盘位姿 `ξ_B(t) ∈ SE(3)`，协方差 `Σ_B(t)`；任务帧 `F_task(t) = ξ_B(t)·o_τ`。漂移 `d(t) = ||log(ξ_B(t)^{-1} ξ_B(t0))||`。当 `tr(Σ_B) > τ_drift` 或 `d(t) > τ_anchor` 时触发重锚，`Σ_B ← Σ_0`。
- **定义 247（底盘-末端惯性耦合）**：`F_eff = F_arm + M_eff(q)·a_B + C_c(q, v_B, ω_B)`，其中 `M_eff(q)` 由臂的质量/惯量分布与安装变换决定，`C_c` 为科氏/离心项。
- **定义 248（底盘风险注入的有效裕度）**：`ρ_safe^B = ρ_safe - κ_a||a_B|| - κ_c||v_B × ω_B||`，`κ_a, κ_c` 为标定系数。要求 `ρ_safe^B ≥ 0` 才允许执行。
- **定义 249（移动几何椭球）**：把固定几何球升级为 `E_B = {x : (x-x_c)^T Q_B^{-1}(x-x_c) ≤ 1}`，`Q_B = Q_0 + σ_a^2·a_B a_B^T`（沿加速度方向伸长）。
- **定义 250（任务不变分解）**：故障签名 `ρ = Φ z_inv + Ψ z_task + ε`，`Φ ∈ ℝ^{d×r}` 为任务不变基（惯量、摩擦、柔顺），`Ψ ∈ ℝ^{d×s}` 为任务残差基；`S_inv = span(Φ)`。
- **定义 251（任务条件残差与风险缩放）**：`λ_TERRA = λ_RAS · (1 + g_θ(z_inv, z_task))`，`g_θ` 为小容量头，`|g_θ| ≤ ε_g`，`λ_TERRA ∈ [0.5, 1.2]`。
- **定义 252（底盘锚定证书）**：`J_TERRA = (J_RAS, ξ_B, Σ_B, a_B, Q_B, z_inv_hash, task_emb, terra_ver)`。`Valid ⇔ Valid(J_RAS) ∧ ZMP ∈ S_support ∧ tr(Σ_B) ≤ τ_drift ∧ ρ_safe^B ≥ 0 ∧ |g_θ| ≤ ε_g`。
- **定义 253（漂移门控重锚）**：重锚带滞回：`tr(Σ_B) > τ_drift` 触发、`tr(Σ_B) < τ_drift/2` 解除，避免阈值附近抖动。
- **定义 254（支撑多边形稳定裕度）**：`m_zmp = dist(ZMP, ∂S_support)`，要求 `m_zmp ≥ d_min`；ZMP 由各轮接触力与底盘加速度合成。
- **定义 255（情绪-底盘耦合）**：`R_emotion^B = R_emotion(π) + κ_v·σ(||v_B - v_h||)`，`σ` 为饱和函数；底盘高速逼近叠加恐惧先验。
- **定义 256（跨任务迁移算子）**：`T_{τ→τ'}(θ) = (θ_inv, θ_task - η∇L_{τ'}(θ_task))`，`θ_inv` 冻结、`θ_task` 微调。
- **定义 257（不变子空间正则）**：`Ω(θ) = Σ_i F_i ⊙ (θ_inv - θ_inv*)^2`，Fisher 信息 `F_i` 只在 `S_inv` 上计算，抑制遗忘。
- **定义 258（跨任务安全预算）**：`B_task = α_chunk + δ_fi + α_emotion + δ_base + δ_transfer`，`δ_base` 为漂移越界概率，`δ_transfer` 为残差迁移尾部。
- **定义 259（AIC-TERRA 干扰与共因）**：`ℰ_TERRA = ℰ_RAS × ℰ_base × ℰ_task`，`ℰ_base`（打滑、里程计漂移、轮子悬空），`ℰ_task`（任务混淆、对象类别错判）；共因：打滑同时诱发位姿漂移与惯性失真。
- **定义 260（重认证与回退）**：`J_TERRA` 失效时，回退到 `J_RAS` 并冻结 `g_θ`；连续 `N_fail` 次失败则强制停车并重锚。

## 2. 关键算法骨架

```python
class RollingAnchor:
    def __init__(self, tau_drift=0.02, tau_anchor=0.05):
        self.tau_drift, self.tau_anchor = tau_drift, tau_anchor
        self.anchor, self.reanchor_count = None, 0

    def update(self, odom, scan):
        xi = fuse_pose(odom, scan)          # SE(3)
        Sigma = pose_covariance(odom, scan)
        drift = 0.0 if self.anchor is None else se3_log(inv(self.anchor) @ xi)
        if self.anchor is None or trace(Sigma) > self.tau_drift or drift > self.tau_anchor:
            self.anchor = xi
            self.reanchor_count += 1
        return self.anchor, xi, Sigma


class ChassisRiskInjection:
    def __init__(self, kappa_a=0.15, kappa_c=0.05, sigma_a=0.1):
        self.kappa_a, self.kappa_c, self.sigma_a = kappa_a, kappa_c, sigma_a

    def inject(self, a_B, v_B, w_B, rho_safe, Q0):
        rho_B = rho_safe - self.kappa_a * norm(a_B) - self.kappa_c * norm(cross(v_B, w_B))
        Q_B = Q0 + (self.sigma_a ** 2) * outer(a_B, a_B)
        return rho_B, Q_B


class TaskInvariantRepresentation:
    def __init__(self, Phi, Psi):
        self.Phi, self.Psi = Phi, Psi

    def factorize(self, rho):
        z_inv = lstsq(self.Phi, rho)
        z_task = lstsq(self.Psi, rho - self.Phi @ z_inv)
        return z_inv, z_task


class TaskConditionedResidual:
    def __init__(self, head, eps_g=0.2):
        self.head, self.eps_g = head, eps_g

    def scale(self, lam_ras, z_inv, z_task):
        g = clamp(self.head(z_inv, z_task), -self.eps_g, self.eps_g)
        return min(1.2, max(0.5, lam_ras * (1.0 + g)))


class ChassisAnchoredCertificate:
    def __init__(self, tau_drift=0.02, d_min=0.03):
        self.tau_drift, self.d_min = tau_drift, d_min

    def build(self, J_ras, xi, Sigma, a_B, Q_B, rho_B, zmp, support, z_inv, task):
        stable = trace(Sigma) <= self.tau_drift
        in_poly = dist_to_boundary(zmp, support) >= self.d_min
        valid = (J_ras.valid and stable and in_poly and rho_B >= 0)
        return {'valid': valid, 'xi': xi, 'Sigma': Sigma, 'a_B': a_B,
                'Q_B': Q_B, 'rho_B': rho_B, 'z_inv_hash': hash(z_inv),
                'task_emb': task, 'terra_ver': TERRA_VERSION}


def TERRA_round(M, obs, task_id):
    # 1) VISTA + RAS 前向
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    face_gate = M.er.recognize(img)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs.synthesize(rho, face_gate)

    # 2) RAL：滚动锚点
    anchor, xi, Sigma = M.ral.update(obs.odom, obs.scan)

    # 3) CRI：惯性风险注入
    a_B, v_B, w_B = M.imu.base_motion()
    rho_B, Q_B = M.cri.inject(a_B, v_B, w_B, M.vista.rho_safe, M.Q0)

    # 4) TIR：任务不变分解
    z_inv, z_task = M.tir.factorize(rho)

    # 5) TCR：任务残差缩放
    lam_ras = M.efs.risk_scale(joint_post)
    lam = M.tcr.scale(lam_ras, z_inv, z_task)

    # 6) C-TERRA：认证前缀（VISTA + 情绪 + 底盘三重约束）
    m_terra = min(M.vista.m, M.er.max_m_emotion, M.cri.max_horizon(a_B))
    k = M.csc.certified_prefix_terra(A, joint_post, rho_B, m_terra)

    # 7) CAR：证书
    zmp = M.stab.zmp(M.imu.wheel_forces(), a_B)
    J = M.car.build(M.csc.last_cert, xi, Sigma, a_B, Q_B, rho_B,
                    zmp, M.stab.support(), z_inv, task_id)
    if not J['valid']:
        M.ral.reanchor()
        M.freeze_residual()       # 冻结 g_θ，回退 RAS
        k = 0

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau_cmd = M.ers.shaping(tau_cmd, joint_post)
    return k, lam, J, z_inv, z_task
```

## 3. 推导

**引理 11（惯性耦合的任务不变性）** 串臂上 `a_B ↦ M_eff(q)a_B` 的映射只依赖臂的质量/惯量分布与安装变换，以及当前构型 `q`，不依赖任务指令。任务只通过参考轨迹进入 `F_arm` 项。因此 `∂F_eff/∂a_B = M_eff(q)` 是跨任务共享的不变量，可作为迁移先验。

**引理 12（漂移门控有效性）** 若位姿误差协方差为 `Σ_B`，且 `tr(Σ_B) > τ_drift` 即重锚，则锚定裕度损失满足 `E[Δρ] ≤ L·sqrt(tr(Σ_B)) ≤ L·sqrt(τ_drift)`，两次重锚之间证书有效概率 `≥ 1-δ`，`δ = P(tr(Σ_B) > τ_drift)`。重锚把 `Σ_B → Σ_0`，使误差不随行程无界累积。

**引理 13（迁移误差不随任务数增长）** 若 `ρ_τ = Φ z_inv + Ψ z_task^τ + ε`，`S_inv` 跨任务固定、残差头容量受限，则新任务 `τ'` 的证书误差 `≤ ||Ψ||·||z_task^{τ'} - ẑ_task^{τ'}|| + ||ε||`，与已学任务数 `|𝒯|` 无关（无容量干扰）。

**定理 11（TERRA 端到端移动安全）** 在 A87–A91 与底盘运动有界假设下，执行不安全的概率
`P(unsafe) ≤ α_chunk + δ_fi + α_emotion + δ_base + δ_transfer`；
且当 `ZMP ∈ S_support`、`tr(Σ_B) ≤ τ_drift`、`ρ_safe^B ≥ 0` 同时成立时，`λ_TERRA ≥ 0.6` 蕴含实际执行风险 ≤ 设定上限 × 1.2。

**定理 12（跨任务泛化与不遗忘）** 在 `S_inv` 上施加 Fisher 正则后，旧任务遗忘量 `≤ (η/2)·Σ_i F_i·||z_inv - z_inv*||² ≤ η·||Φ||²·C`，有界且不随任务数增长；同时新任务证书有效性在 `ε_task` 内保持。

## 6. 本轮最大风险

**一句话**：TERRA 把「底盘坐标系」当作跨任务泛化的万能不变量，但真正致命的跨任务危害（刀具 vs 海绵、刚性 vs 柔性对象）常常与底盘的几何/惯性无关，而属于语义层——一旦残差头容量不足，TERRA 会把「物理先验迁移成功」误当成「任务安全迁移成功」，在语义危害上给出虚假的证书有效性，从而在**从未见过的任务里以最高置信度执行最危险的动作**。

**次级风险与缓解**：
1. **语义与物理解耦失败**：残差头容量太小 → 引入任务语义探针与人工确认门；
2. **重锚抖动**：阈值附近反复重锚 → 滞回 + 最小驻留时间；
3. **`M_eff` 标定漂移**：负载变化使惯性参数失真 → 在线系统辨识 + 保守上界；
4. **情绪-速度耦合过激**：高速接近误触发降级 → 只在 `π(tense/fear)` 同时超阈时生效；
5. **仿真到实车差距**：轮地打滑模型不准 → 域随机化 + 打滑检测回退。

## 2. 形式化定义（完整版）

**定义 245（TERRA 总览）** TERRA 是 RAS 的「意图闭环」升级为「可移动、可迁移的安全闭环」：
```
TERRA = (RAL, CRI, TIR, TCR, CAR, DGL, EBC)
```
不变式：位姿融合、签名分解、迁移更新只在语义流；实时流只做锚点校验、椭球早停、支撑多边形判定，零在线学习写操作。

**定义 246（滚动锚点）** 底盘位姿 `ξ_B(t) ∈ SE(3)` 与协方差 `Σ_B(t)`，任务帧 `F_task(t) = ξ_B(t)·o_τ`。漂移 `d(t) = ||log(ξ_B(t)^{-1} ξ_B(t0))||`；`tr(Σ_B) > τ_drift` 或 `d(t) > τ_anchor` 时重锚，`Σ_B ← Σ_0`。

**定义 247（底盘-末端惯性耦合）**
```
F_eff = F_arm + M_eff(q)·a_B + C_c(q, v_B, ω_B)
```
`M_eff` 由臂质量/惯量分布与安装变换决定。

**定义 248（底盘风险注入的有效裕度）**
```
ρ_safe^B = ρ_safe - κ_a·||a_B|| - κ_c·||v_B × ω_B||
```
要求 `ρ_safe^B ≥ 0` 才允许执行。

**定义 249（移动几何椭球）**
```
E_B = {x : (x-x_c)^T Q_B^{-1}(x-x_c) ≤ 1},  Q_B = Q_0 + σ_a^2·a_B a_B^T
```

**定义 250（任务不变分解）**
```
ρ = Φ z_inv + Ψ z_task + ε,  S_inv = span(Φ)
```
`Φ` 承载惯量/摩擦/柔顺等任务不变物理，`Ψ` 承载任务残差。

**定义 251（任务条件残差与风险缩放）**
```
λ_TERRA = λ_RAS · (1 + g_θ(z_inv, z_task)),  |g_θ| ≤ ε_g,  λ_TERRA ∈ [0.5, 1.2]
```

**定义 252（底盘锚定证书）**
```
J_TERRA = (J_RAS, ξ_B, Σ_B, a_B, Q_B, z_inv_hash, task_emb, terra_ver)
```
`Valid ⇔ Valid(J_RAS) ∧ ZMP ∈ S_support ∧ tr(Σ_B) ≤ τ_drift ∧ ρ_safe^B ≥ 0 ∧ |g_θ| ≤ ε_g`。

**定义 253（漂移门控重锚）** 滞回重锚：`tr(Σ_B) > τ_drift` 触发、`< τ_drift/2` 解除。

**定义 254（支撑多边形稳定裕度）** `m_zmp = dist(ZMP, ∂S_support)`，要求 `m_zmp ≥ d_min`。

**定义 255（情绪-底盘耦合）**
```
R_emotion^B = R_emotion(π) + κ_v·σ(||v_B - v_h||)
```
`σ` 为饱和函数，底盘高速逼近叠加恐惧先验。

**定义 256（跨任务迁移算子）**
```
T_{τ→τ'}(θ) = (θ_inv,  θ_task - η∇L_{τ'}(θ_task))
```
`θ_inv` 冻结、`θ_task` 微调。

**定义 257（不变子空间正则）**
```
Ω(θ) = Σ_i F_i ⊙ (θ_inv - θ_inv*)^2,  F_i 只在 S_inv 上计算
```

**定义 258（跨任务安全预算）**
```
B_task = α_chunk + δ_fi + α_emotion + δ_base + δ_transfer
```

**定义 259（AIC-TERRA 干扰与共因）**
```
ℰ_TERRA = ℰ_RAS × ℰ_base × ℰ_task
```
`ℰ_base`：打滑、里程计漂移、轮子悬空；`ℰ_task`：任务混淆、对象类别错判。共因：打滑同时诱发位姿漂移与惯性失真。

**定义 260（重认证与回退）** `J_TERRA` 失效时回退 `J_RAS` 并冻结 `g_θ`；连续 `N_fail` 次失败强制停车并重锚。

```python
# IP-234 RAL
class RollingAnchor:
    def __init__(self, tau_drift=0.02, tau_anchor=0.05):
        self.tau_drift, self.tau_anchor = tau_drift, tau_anchor
        self.anchor, self.reanchor_count = None, 0

    def update(self, odom, scan):
        xi = fuse_pose(odom, scan)
        Sigma = pose_covariance(odom, scan)
        drift = 0.0 if self.anchor is None else se3_log(inv(self.anchor) @ xi)
        if self.anchor is None or trace(Sigma) > self.tau_drift or drift > self.tau_anchor:
            self.anchor = xi
            self.reanchor_count += 1
        return self.anchor, xi, Sigma


# IP-235 CRI
class ChassisRiskInjection:
    def inject(self, a_B, v_B, w_B, rho_safe, Q0):
        rho_B = rho_safe - 0.15*norm(a_B) - 0.05*norm(cross(v_B, w_B))
        Q_B = Q0 + 0.01 * outer(a_B, a_B)
        return rho_B, Q_B

    def max_horizon(self, a_B):
        return max(1, int(self.m0 / (1.0 + norm(a_B))))   # 加速度越大，可认证前缀越短


# IP-236 TIR
class TaskInvariantRepresentation:
    def factorize(self, rho):
        z_inv = lstsq(self.Phi, rho)
        z_task = lstsq(self.Psi, rho - self.Phi @ z_inv)
        return z_inv, z_task


# IP-237 TCR
class TaskConditionedResidual:
    def scale(self, lam_ras, z_inv, z_task):
        g = clamp(self.head(z_inv, z_task), -self.eps_g, self.eps_g)
        return min(1.2, max(0.5, lam_ras * (1.0 + g)))


# IP-238 CAR
class ChassisAnchoredCertificate:
    def build(self, J_ras, xi, Sigma, a_B, Q_B, rho_B, zmp, support, z_inv, task):
        stable = trace(Sigma) <= self.tau_drift
        in_poly = dist_to_boundary(zmp, support) >= self.d_min
        valid = J_ras.valid and stable and in_poly and rho_B >= 0
        return {'valid': valid, 'xi': xi, 'Sigma': Sigma, 'a_B': a_B, 'Q_B': Q_B,
                'rho_B': rho_B, 'z_inv_hash': hash(z_inv), 'task_emb': task,
                'terra_ver': TERRA_VERSION}


# IP-243 TERRA 闭环
def TERRA_round(M, obs, task_id):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    face_gate = M.er.recognize(img)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs.synthesize(rho, face_gate)

    anchor, xi, Sigma = M.ral.update(obs.odom, obs.scan)
    a_B, v_B, w_B = M.imu.base_motion()
    rho_B, Q_B = M.cri.inject(a_B, v_B, w_B, M.vista.rho_safe, M.Q0)

    z_inv, z_task = M.tir.factorize(rho)
    lam = M.tcr.scale(M.efs.risk_scale(joint_post), z_inv, z_task)

    m_terra = min(M.vista.m, M.er.max_m_emotion, M.cri.max_horizon(a_B))
    k = M.csc.certified_prefix_terra(A, joint_post, rho_B, m_terra)

    zmp = M.stab.zmp(M.imu.wheel_forces(), a_B)
    J = M.car.build(M.csc.last_cert, xi, Sigma, a_B, Q_B, rho_B,
                    zmp, M.stab.support(), z_inv, task_id)
    if not J['valid']:
        M.ral.reanchor()
        M.freeze_residual()
        k = 0

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau_cmd = M.ers.shaping(tau_cmd, joint_post)
    return k, lam, J, z_inv, z_task
```

## 4. 推导

**引理 11（惯性耦合的任务不变性）** `∂F_eff/∂a_B = M_eff(q)` 只依赖臂质量/惯量分布、安装变换与构型 `q`；任务只通过参考轨迹进入 `F_arm`。因此该映射是跨任务共享的不变量，可作为迁移先验。

**引理 12（漂移门控有效性）** `tr(Σ_B) > τ_drift` 即重锚时，锚定裕度损失 `E[Δρ] ≤ L·sqrt(τ_drift)`；两次重锚间证书有效概率 `≥ 1-δ`，`δ = P(tr(Σ_B) > τ_drift)`；重锚使误差不随行程无界累积。

**引理 13（迁移误差有界且不随任务数增长）** `ρ_τ = Φ z_inv + Ψ z_task^τ + ε` 下，新任务误差 `≤ ||Ψ||·||z_task^{τ'} - ẑ_task^{τ'}|| + ||ε||`，与已学任务数无关。

**定理 11（TERRA 端到端移动安全）** 在 A87–A91 与底盘运动有界假设下
```
P(unsafe) ≤ α_chunk + δ_fi + α_emotion + δ_base + δ_transfer
```
且 `ZMP ∈ S_support`、`tr(Σ_B) ≤ τ_drift`、`ρ_safe^B ≥ 0` 时，`λ_TERRA ≥ 0.6` 蕴含执行风险 ≤ 设定上限 × 1.2。

**定理 12（跨任务泛化与不遗忘）** `S_inv` 上 Fisher 正则使旧任务遗忘 `≤ (η/2)Σ_i F_i||z_inv - z_inv*||² ≤ η||Φ||²C`，有界且不随任务数增长；新任务证书有效性在 `ε_task` 内保持。

## 7. 本轮最大风险

**一句话**：TERRA 把「底盘坐标系」当作跨任务泛化的万能不变量，但真正致命的跨任务危害（刀具 vs 海绵、刚性 vs 柔性对象）常常与底盘的几何/惯性无关，而属于语义层——一旦残差头容量不足，TERRA 会把「物理先验迁移成功」误当成「任务安全迁移成功」，在语义危害上给出虚假的证书有效性，从而在**从未见过的任务里以最高置信度执行最危险的动作**。

**次级风险与缓解**：
1. **语义与物理解耦失败**：残差头容量小 → 任务语义探针 + 人工确认门；
2. **重锚抖动**：阈值附近来回重锚 → 滞回 + 最小驻留时间；
3. **`M_eff` 标定漂移**：负载变化致惯性参数失真 → 在线系统辨识 + 保守上界；
4. **情绪-速度耦合过激**：高速接近误降级 → 仅在 `π(tense/fear)` 同时超阈时生效；
5. **仿真到实车差距**：轮地打滑模型不准 → 域随机化 + 打滑检测回退。
