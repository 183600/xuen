# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；新灵感循环第 2 轮；本轮灵感：「视觉-语言-动作模型」×「语言指令」）

> 第 60 轮 SGEC 把「场景→意图→约束→阻抗→执行→证据」串成闭环，但它的「意图」来自一个**封闭的 5 词表**（慢点/加紧/轻触/稳定/危险）与手写映射 ϕ_intent→constraint。进入 VLA（视觉-语言-动作模型）时代，这留下三个结构性缺口：
> 1. **开放词汇接地缺失**：真实指令是开放的、组合的、指称视觉实体的（「把红色杯子轻轻放到桌上，别碰倒水杯」）。CIEC 的关键词查表无法把「红色杯子」「别碰倒」接地到场景实体与约束；词表外指令只能被**静默降级**为默认约束，而静默降级恰恰是最危险的失败模式。
> 2. **VLA 的端到端动作与约束层之间存在抽象泄漏**：VLA 直接吐 action chunk，训练于互联网数据，不具备力/阻抗安全保证；第 60 轮的 K_safe 无法约束 VLA 的原始输出，于是「VLA 语义上想对了、执行层却做不到或不安全」。
> 3. **语言→约束映射从未被证据校准**：「轻」到底多轻？手写 0.8·F_nom 只是设计者先验，不同用户/物体/场景差异巨大；第 60 轮有 EPIR 证据链，却完全没有反过来校准语言语义。

## 0. 直觉与动机

**灵感 1（VLA → 符号指令接地 SIG）**
直觉：VLA 的真正价值不只是「端到端出动作」，而在于它已把「语言—视觉」对齐进同一个语义空间。那就先用它当**翻译官**：把开放指令解析成可审计的**接地指令图**——指称（红色杯子→场景实体 e）、谓词（轻轻放→力/速度轨迹）、量词（一点/一半→参数标定）、安全限定（别碰倒→硬约束）。关键洞见：**先翻译成可检验的符号程序，再允许生成动作；否则 VLA 的隐空间不可审计、不可追责。** 这直接补上第 60 轮 CIEC 的封闭词表裂缝。

**灵感 2（语言指令 → 组合约束代数 CCA）**
直觉：语言天然组合，约束天然交集。「慢慢地把杯子放到桌上，别捏碎」= 速度上界 ∧ 位置目标 ∧ 夹持力上界 ∧ 禁止超阈。每个语义子项诱导一个约束算子，合成就是**在可行域上取交（meet）**；算子对包含关系单调，新增限定只能**收窄**、绝不放宽。而物理硬安全包络 H（骨骼力、关节矩、稳定性裕度）永远先求交。关键洞见：**「安全地做错」的根治办法不是「不安全地做对」，而是让语言只能在安全域内收窄，永远不能把 H 撑大。**

**灵感 3（VLA 幻觉 → 约束校验解码 CVD + 合规证书）**
直觉：VLA 会漂移、会幻觉，尤其最容易违反否定指令（「不要碰」）。不能先执行再后悔。用 C(ℓ) 给 VLA 解码加**可行性掩码**（token 级约束）；用（必然不完美的）世界模型预测动作后果做前置校验；执行后再用 EV-exec 生成**指令合规证书 J_instr**。关键洞见：**证书必须把「软违约可修复」与「硬安全违约不可修复」分开**——硬违约永远 REJECT，且 PASS 只能由**实测执行证据**签发，绝不能被一个漂亮但错误的世界模型伪造。

**灵感 4（三灵感合流 → 接地指令闭环 GIL）**
把 SIG、CCA、CVD 嵌回第 60 轮 SERC：指令 ℓ → 符号接地 → 组合约束 → VLA 约束解码 → EEIS 在 C(ℓ) 内编译阻抗 → 执行 → EV-exec → J_instr → 接地重标定 → 下一轮。闭环让「语言理解」与「执行证据」互相校正，而不是单向命令。

**灵感 5（语义预算 → PCE+++++ / B_ling）**
直觉：接地、VLA 推理、合规校验都很贵、都有延迟。PCE+++++ 必须新增**语义预算 B_ling=(B_ground,B_vla,B_verify,B_exec)**，并规定明确降级：接地耗尽回退第 60 轮固定意图、VLA 耗尽用最后已提交 chunk、校验耗尽收紧到只保留 H 的保守包络、执行耗尽走原有降级。关键洞见：**语义能力必须能被预算地、显式地关闭，而不是在实时性压力下默默拖垮整个闭环。**

## 1. 形式化定义（增量：定义 161–168）

**定义 161（符号指令接地 SIG）** 指令 ℓ∈L（开放词表）。解析映射 Π(ℓ)=(R,P,Q,S)：
- **指称项** R={r_i}：名词短语、属性、空间关系（「红色杯子」「桌上的」「左边」）
- **谓词项** P：动作/方式副词（放、抓、慢、轻）
- **量词项** Q：程度/数值（「一点」「一半」「2cm」）
- **安全限定** S：否定与禁令（「别碰倒」「不要捏」），具有 **veto 语义**
- **接地映射** Γ_θ:R×O_t→(E_t,g)：E_t⊆场景实体集（复用 SSM 的场景后验），接地置信度
  g(r,e)=σ(α·cos(φ_txt(r),φ_vis(e)) − β·d_spatial(r,e))
  其中 φ_txt/φ_vis 为共享视觉-语言嵌入。输出接地指令图 G_ℓ=(E,P,Q,S) 与接地矩阵 G=[g(r,e)]。
- **不可交换性**：S 中的否定项不参与软加权，直接注入硬约束 H_ℓ；「不要 X」不是「X 的负权重」，而是**禁区**。

**定义 162（组合约束代数 CCA）** 令执行参数 x=(v,F,K_p,K_d,traj)∈X。每个语义子项 ℓ_i 诱导约束算子 C_i⊆X。合成：
```
C(ℓ) = H ∩ ⋂_{ℓ_i∈P∪Q} C_i(ℓ_i) ∩ H_ℓ(S)
```
其中 H 为物理硬包络（F≤F_bone，τ≤τ_joint，稳定裕度≥0…），H_ℓ(S) 为禁令诱导的硬约束。满足：
- **单调收窄**：C(ℓ⊕新限定)⊆C(ℓ)——语言只能收窄；
- **安全不可放宽**：∀ℓ，H⊆C(ℓ)；
- **可行性**：C(ℓ)=∅ ⇒ 不可行，必须 REPAIR/REJECT；
- **欠定度**：diam(C(ℓ)) 过大 ⇒ 歧义，交给 ASR。

**定义 163（约束校验的 VLA 解码 CVD）** VLA 策略 π_θ(a_{t:t+k}|ℓ,O)。约束解码：
```
a_t ∼ π_θ(· | ℓ, O, M_t),   M_t = { token | Feasible(a_t⊕token, C(ℓ)) }
Feasible(a,C) ⇔ f̂(x_t,a)∈C ∧ margin_H(f̂(x_t,a)) ≥ 0
```
f̂ 为（近似）动力学/世界模型。若整段 chunk 被掩码 ⇒ 动作投影 Proj_{C(ℓ)}(a_chunk)（最小扰动可行化）；仍不可行则 REPAIR/REJECT。**VLA 不直接决定 K**：它给名义轨迹，EEIS 在 C(ℓ) 内编译 K_safe。

**定义 164（接地指令闭环 GIL）** 算子 GIL(M,ℓ)（伪代码见后）。要点：符号接地 → 组合约束 → 约束解码 → 第 60 轮 SERC → J_instr → 接地重标定，形成语义-执行双向校准。

**定义 165（指令合规证书 ICC / J_instr）** J_instr=(ρ_ground,ρ_constraint,ρ_temporal,margin_hard,decision)：
- **接地**：ρ_ground=∏_{r∈R} g(r,e_r)
- **约束**：ρ_constraint=1 − max_t dist(x_t,C(ℓ))/D_norm（越界量与越界时长归一化）
- **时序**：ρ_temporal 用子目标序列/LTL 检查「先…再…」
- **硬裕度**：margin_hard=min_t margin_H(x_t)（**基于 EV-exec 实测，非预测**）
- **三态+一态**：margin_hard<0 ⇒ REJECT（不可修复）；ρ_constraint<τ_c 但可由投影修复 ⇒ REPAIR；接地失败 ⇒ CLARIFY；全部达标 ⇒ PASS。

**定义 166（接地重标定 GRL）** 语言量词是主观的，需要按用户/物体类别标定 θ_ling（如「轻」→力的分位映射）。用 EV-exec 与人类纠正 u 做贝叶斯更新：
```
p(θ|ev,u) ∝ p(ev|θ,u)·p(θ);   θ ← MAP(p(θ|ev,u))
```
更新受三重约束：(i) 只在 H 内；(ii) 用稳健聚合（截尾均值/中位数）抑制噪声与恶意反馈；(iii) θ_ling^0 初始化为第 60 轮手写映射，保证冷启动不劣于基线。

**定义 167（PCE+++++ 语义预算 B_ling）** B_ling=(B_ground,B_vla,B_verify,B_exec)：
```
VOI_ling = E[gain(open-vocab)] − cost_ground − cost_vla − cost_verify − cost_exec
```
显式降级：B_ground 耗尽→回退第 60 轮固定意图 CIEC；B_vla 耗尽→停止生成、用最后已提交 chunk；B_verify 耗尽→丢弃软约束、只保留 H 的保守包络；B_exec 耗尽→第 60 轮降级。

**定义 168（歧义与安全路由 ASR）** 歧义度 A(ℓ)=H(E_t 接地后验)+λ·diam(C(ℓ))（归一化）。路由：
```
if H 冲突不可解:                 route = REJECT
elif A(ℓ) > τ_amb:               route = CLARIFY（主动提问）或 CONSERVATIVE（取 C 内最大安全裕度点）
else:                            route = EXECUTE
```
CLARIFY 有预算上界；超时转 CONSERVATIVE，**绝不默认放开约束**。

### IP-161 SIG（符号指令接地）

```python
class SymbolicInstructionGrounder:
    def __init__(self, phi_txt, phi_vis, tau_ground=0.6):
        self.phi_txt, self.phi_vis = phi_txt, phi_vis
        self.tau_ground = tau_ground

    def parse(self, instruction):
        return InstructionProgram(
            referents=extract_np(instruction),      # 指称 r_i
            predicates=extract_pred(instruction),   # 谓词 p_i
            quantifiers=extract_quant(instruction), # 量词 q_i
            safety=extract_negation(instruction),   # 否定/禁令 s_i（veto）
        )

    def ground(self, prog, scene_entities, obs):
        G, E = {}, []
        for r in prog.referents:
            scores = {e: sigmoid(ALPHA * cos(self.phi_txt(r), self.phi_vis(e, obs))
                                 - BETA * spatial_distance(r, e))
                      for e in scene_entities}
            e_star = max(scores, key=scores.get)
            G[r] = scores
            E.append((r, e_star, scores[e_star]))
        return GroundedInstruction(prog, E, G,
                                   confident=all(g >= self.tau_ground for _, _, g in E))
```

### IP-162 CCA（组合约束代数）

```python
class CompositionalConstraintAlgebra:
    def __init__(self, hard_envelope):
        self.H = hard_envelope            # 物理硬包络，永不被放宽

    def compile(self, grounded, theta_ling):
        C = self.H                        # 安全最先求交
        for p in grounded.program.predicates:
            C = C.intersect(op_from_predicate(p, theta_ling))
        for q in grounded.program.quantifiers:
            C = C.intersect(op_from_quantifier(q, theta_ling))
        for s in grounded.program.safety:     # veto：直接进硬约束
            C = C.intersect(forbidden_region(s))
        if C.is_empty():
            return C, 'INFEASIBLE'
        if C.diameter() > self.tau_width:      # 欠定
            return C, 'AMBIGUOUS'
        return C, 'FEASIBLE'
```

### IP-163 CVD（约束校验的 VLA 解码）

```python
def constraint_verified_decode(vla, instruction, obs, C, world_model, k=8):
    tokens = []
    a_prefix = []
    for t in range(k):
        logits = vla.logits(instruction, obs, tokens)
        mask = torch.full_like(logits, -float('inf'))
        for tok in topk_candidates(logits):
            a_next = decode_action(a_prefix + [tok])
            x_next = world_model.predict(obs.state, a_next)
            if inside(x_next, C) and margin_H(x_next) >= 0:
                mask[tok] = 0.0
        if torch.isinf(mask).all():               # 整个 chunk 不可行
            proj = project_to_feasible(a_prefix, C)  # 最小扰动可行化
            return proj, 'PROJECTED'
        tok = sample(logits + mask)
        tokens.append(tok)
        a_prefix.append(tok)
    return a_prefix, 'OK'
```

### IP-164 GIL（接地指令闭环）

```python
def grounded_instruction_loop(M, instruction):
    # ① 符号接地
    prog = M.sig.parse(instruction)
    grounded = M.sig.ground(prog, M.scene_model.entities, M.obs)
    # ② 组合约束（硬包络先求交）
    C, status = M.cca.compile(grounded, M.theta_ling)
    # ③ 歧义/安全路由
    route = M.asr.route(grounded, C, status)
    if route == 'REJECT':
        return M, J_instr_reject(grounded, C)
    if route == 'CLARIFY' and M.budget.B_ling.B_ground > 0:
        return M, ask_clarification(grounded)
    if route == 'CONSERVATIVE':
        C = conservative_subset(C)
    # ④ 约束校验的 VLA 解码（名义轨迹）
    a_nom, dec_status = constraint_verified_decode(
        M.vla, instruction, M.obs, C, M.world_model)
    # ⑤ 第 60 轮 SERC：在 C 内编译阻抗并执行
    M, fused, Dp, EV, cert = scenario_perception_evolution_loop(
        M, grounded.scene, grounded.intent, M.delta_f_req, constraint=C)
    # ⑥ 指令合规证书（基于 EV-exec 实测）
    J_instr = build_instruction_certificate(grounded, C, EV, M.epir)
    # ⑦ 接地重标定（仅 PASS/REPAIR 且证据可靠时）
    if J_instr.decision in ('PASS', 'REPAIR') and M.budget.B_ling.B_verify > 0:
        M.theta_ling = M.grl.update(M.theta_ling, EV, J_instr)
    return M, J_instr
```

### IP-165 ICC（指令合规证书）

```python
def build_instruction_certificate(grounded, C, ev_exec, epir):
    rho_ground = prod(g for _, _, g in grounded.entities)
    rho_constraint = 1.0 - max(dist(x_actual, C) for x_actual in ev_exec.traj) / D_NORM
    rho_temporal = check_subgoal_order(ev_exec, grounded.program.order)
    margin_hard = min(margin_H(x_actual) for x_actual in ev_exec.traj)  # 实测
    if margin_hard < 0:
        decision = 'REJECT'                       # 硬安全违约，永不可修复
    elif rho_constraint < TAU_C:
        decision = 'REPAIR' if projectable(ev_exec, C) else 'REJECT'
    elif rho_ground < TAU_G:
        decision = 'CLARIFY'
    else:
        decision = 'PASS'
    return InstructionCertificate(rho_ground, rho_constraint,
                                  rho_temporal, margin_hard, decision,
                                  evidence_ref=epir.last_received)
```

### IP-166 GRL（接地重标定）

```python
class GroundingRecalibrator:
    def __init__(self, theta0, eta=0.05, robust=True):
        self.theta = dict(theta0)      # 冷启动 = 第 60 轮手写映射
        self.eta, self.robust = eta, robust

    def update(self, theta, ev_exec, cert):
        feedback = ev_exec.human_correction      # 如「再轻一点」
        if feedback is None:
            return theta
        samples = quantifier_samples(ev_exec, feedback)   # (量词, 实测参数)
        # 稳健聚合抑制噪声/恶意反馈
        agg = trimmed_mean(samples) if self.robust else mean(samples)
        for q, val in agg.items():
            theta[q] = clip(theta[q] + self.eta * (val - theta[q]),
                            H_MIN[q], H_MAX[q])           # 永不超过硬包络
        return theta
```

### IP-167 PCE+++++（语义预算耦合）

```python
class SemanticBudget:
    def __init__(self, ground_ops=200, vla_tokens=256, verify_ops=200, exec_budget=None):
        self.B_ground, self.B_vla = ground_ops, vla_tokens
        self.B_verify = verify_ops
        self.B_exec = exec_budget or ExecBudget()
        self.ops_ground = self.tokens_vla = self.ops_verify = 0

    def grounding_exhausted(self):  return self.ops_ground >= self.B_ground
    def vla_exhausted(self):        return self.tokens_vla >= self.B_vla
    def verify_exhausted(self):     return self.ops_verify >= self.B_verify

    def degradation(self):
        if self.grounding_exhausted(): return 'fallback_fixed_intents'  # 第 60 轮 CIEC
        if self.vla_exhausted():       return 'reuse_last_chunk'
        if self.verify_exhausted():    return 'conservative_envelope_only'
        return 'full'
```

### IP-168 ASR（歧义与安全路由）

```python
class AmbiguitySafetyRouter:
    def __init__(self, tau_amb=0.5, clarify_budget=1):
        self.tau_amb, self.clarify_budget = tau_amb, clarify_budget

    def route(self, grounded, C, compile_status):
        if compile_status == 'INFEASIBLE' or has_hard_conflict(C):
            return 'REJECT'
        ambiguity = entropy(grounded.grounding_posterior) + LAMBDA * normalize(C.diameter())
        if ambiguity > self.tau_amb:
            if self.clarify_budget > 0:
                self.clarify_budget -= 1
                return 'CLARIFY'
            return 'CONSERVATIVE'
        return 'EXECUTE'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SIG | O(\|R\|·\|E\|·d) | O(\|R\|·\|E\|) | 接地置信度可阈值化；低置信不静默执行 |
| CCA | O(\|P∪Q\|·d_C) 交集 | O(\|P∪Q\|) | 语言只能收窄；H⊆C(ℓ) 永远成立 |
| CVD | O(k·V·T_f̂) 解码掩码 | O(k·V) | 可行掩码 + 投影；不可行即 REPAIR/REJECT |
| GIL | O(单闭环) | 复用 | 三方证书；PASS 需实测 EV-exec |
| GRL | O(\|Q\|) | O(\|Q\|) | 标定有界于 H；稳健聚合 |

**命题 1（约束单调收窄）** CCA 用交集合成，故对任意新限定 ℓ′，C(ℓ⊕ℓ′)=C(ℓ)∩C(ℓ′)⊆C(ℓ)。语言无法放宽既有约束。

**命题 2（安全不可放宽）** 因 C(ℓ)=H∩(…) 恒含 H，故任意 ℓ 下 x∈C(ℓ)⇒x∈H。即使接地完全错误，也只会落进「某个安全子集」而不会越出 H。

**命题 3（世界模型误差下的可行性界）** 若 f̂ 的单步预测误差 ≤ ε_f 且约束边界是 L_C-Lipschitz，则 Feasible 判定可能放过越界 ≤ L_C·ε_f 的动作。故 J_instr 的 PASS 必须以**实测 EV-exec** 复核（定义 165），预测只用于解码期降风险。

**命题 4（证书不可伪造）** J_instr 的 margin_hard 与 ρ_constraint 取自 EV-exec 实测轨迹而非世界模型预测，故一个错误的生成模型无法单独签发 PASS；REJECT 由实测硬违约触发，不可被语言或模型覆盖。

**定理（GIL 语义-执行一致性）** 在 A71–A76 与命题 1–4 成立时：若 J_instr=PASS，则实测轨迹落在 H 内（安全）且落在 C(ℓ) 的 ε 容差内（合规）；任一时刻语言都不能使 C(ℓ) 超出 H（安全不可放宽）；词表外/歧义指令只能走向 CLARIFY/REJECT 或显式保守化，而**不存在「静默降级为默认约束后继续执行」的路径**。即语义错误最多导致保守或请求澄清，不会导致「安全地做错却不被告知」。

## 4. 实验设计 E192–E196

### IP-161 SIG（符号指令接地）

```python
class SymbolicInstructionGrounder:
    def __init__(self, phi_txt, phi_vis, tau_ground=0.6):
        self.phi_txt, self.phi_vis = phi_txt, phi_vis
        self.tau_ground = tau_ground

    def parse(self, instruction):
        return InstructionProgram(
            referents=extract_np(instruction),
            predicates=extract_pred(instruction),
            quantifiers=extract_quant(instruction),
            safety=extract_negation(instruction),      # veto
        )

    def ground(self, prog, scene_entities, obs):
        G, E = {}, []
        for r in prog.referents:
            scores = {e: sigmoid(ALPHA * cos(self.phi_txt(r), self.phi_vis(e, obs))
                                 - BETA * spatial_distance(r, e))
                      for e in scene_entities}
            e_star = max(scores, key=scores.get)
            G[r] = scores
            E.append((r, e_star, scores[e_star]))
        return GroundedInstruction(prog, E, G,
                                   confident=all(g >= self.tau_ground for _, _, g in E))
```

### IP-162 CCA（组合约束代数）

```python
class CompositionalConstraintAlgebra:
    def __init__(self, hard_envelope):
        self.H = hard_envelope            # 物理硬包络，永不被放宽

    def compile(self, grounded, theta_ling):
        C = self.H
        for p in grounded.program.predicates:
            C = C.intersect(op_from_predicate(p, theta_ling))
        for q in grounded.program.quantifiers:
            C = C.intersect(op_from_quantifier(q, theta_ling))
        for s in grounded.program.safety:          # veto → 硬约束
            C = C.intersect(forbidden_region(s))
        if C.is_empty():
            return C, 'INFEASIBLE'
        if C.diameter() > self.tau_width:
            return C, 'AMBIGUOUS'
        return C, 'FEASIBLE'
```

### IP-163 CVD（约束校验的 VLA 解码）

```python
def constraint_verified_decode(vla, instruction, obs, C, world_model, k=8):
    tokens, a_prefix = [], []
    for t in range(k):
        logits = vla.logits(instruction, obs, tokens)
        mask = torch.full_like(logits, -float('inf'))
        for tok in topk_candidates(logits):
            a_next = decode_action(a_prefix + [tok])
            x_next = world_model.predict(obs.state, a_next)
            if inside(x_next, C) and margin_H(x_next) >= 0:
                mask[tok] = 0.0
        if torch.isinf(mask).all():
            return project_to_feasible(a_prefix, C), 'PROJECTED'
        tok = sample(logits + mask)
        tokens.append(tok)
        a_prefix.append(tok)
    return a_prefix, 'OK'
```

def grounded_instruction_loop(M, instruction):

### IP-165 ICC（指令合规证书）

```python
def build_instruction_certificate(grounded, C, ev_exec, epir):
    rho_ground = prod(g for _, _, g in grounded.entities)
    rho_constraint = 1.0 - max(dist(x_actual, C) for x_actual in ev_exec.traj) / D_NORM
    rho_temporal = check_subgoal_order(ev_exec, grounded.program.order)
    margin_hard = min(margin_H(x_actual) for x_actual in ev_exec.traj)   # 实测
    if margin_hard < 0:
        decision = 'REJECT'
    elif rho_constraint < TAU_C:
        decision = 'REPAIR' if projectable(ev_exec, C) else 'REJECT'
    elif rho_ground < TAU_G:
        decision = 'CLARIFY'
    else:
        decision = 'PASS'
    return InstructionCertificate(rho_ground, rho_constraint, rho_temporal,
                                  margin_hard, decision,
                                  evidence_ref=epir.last_received)

### IP-166 GRL（接地重标定）

class GroundingRecalibrator:
    def __init__(self, theta0, eta=0.05, robust=True):
        self.theta = dict(theta0)          # 冷启动 = 第 60 轮手写映射
        self.eta, self.robust = eta, robust

    def update(self, theta, ev_exec, cert):
        feedback = ev_exec.human_correction
        if feedback is None:
            return theta
        samples = quantifier_samples(ev_exec, feedback)
        agg = trimmed_mean(samples) if self.robust else mean(samples)
        for q, val in agg.items():
            theta[q] = clip(theta[q] + self.eta * (val - theta[q]),
                            H_MIN[q], H_MAX[q])          # 永不超过硬包络
        return theta
```

class SemanticBudget:
    def __init__(self, ground_ops=200, vla_tokens=256, verify_ops=200, exec_budget=None):
        self.B_ground, self.B_vla = ground_ops, vla_tokens
        self.B_verify = verify_ops

### IP-168 ASR（歧义与安全路由）

```python
class AmbiguitySafetyRouter:
    def __init__(self, tau_amb=0.5, clarify_budget=1):
        self.tau_amb, self.clarify_budget = tau_amb, clarify_budget

    def route(self, grounded, C, compile_status):
        if compile_status == 'INFEASIBLE' or has_hard_conflict(C):
            return 'REJECT'
        ambiguity = entropy(grounded.grounding_posterior) + LAMBDA * normalize(C.diameter())
        if ambiguity > self.tau_amb:
            if self.clarify_budget > 0:
                self.clarify_budget -= 1
                return 'CLARIFY'
            return 'CONSERVATIVE'
        return 'EXECUTE'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| SIG | O(\|R\|·\|E\|·d) | O(\|R\|·\|E\|) | 低接地置信不静默执行 |
| CCA | O(\|P∪Q\|·d_C) | O(\|P∪Q\|) | C(ℓ⊕ℓ′)⊆C(ℓ)；H⊆C(ℓ) |
| CVD | O(k·V·T_f̂) | O(k·V) | 掩码+投影；不可行即 REPAIR/REJECT |
| GIL | O(单闭环) | 复用 | PASS 需实测 EV-exec |
| GRL | O(\|Q\|) | O(\|Q\|) | 标定有界于 H、稳健聚合 |

**命题 1（约束单调收窄）** CCA 用交集合成，∀ℓ′：C(ℓ⊕ℓ′)=C(ℓ)∩C(ℓ′)⊆C(ℓ)。语言无法放宽既有约束。

**命题 2（安全不可放宽）** C(ℓ)=H∩(…) 恒含 H，故语义词表外接地错误也只能落入某个安全子集，绝不越出 H。

**命题 3（世界模型误差下的可行性界）** 若 f̂ 单步误差 ≤ ε_f、约束边界 L_C-Lipschitz，则 Feasible 可能放过越界 ≤ L_C·ε_f 的动作；故 PASS 必须由实测 EV-exec 复核。

**命题 4（证书不可伪造）** J_instr 的 margin_hard/ρ_constraint 取自 EV-exec 实测轨迹；错误的世界模型无法单独签发 PASS，REJECT 不可被语言覆盖。

**定理（GIL 语义-执行一致性）** 在 A71–A76 与命题 1–4 下：J_instr=PASS ⇒ 实测轨迹落在 H 内且落在 C(ℓ) 的 ε 容差内；任一时刻语言都不能使 C(ℓ) 超出 H；词表外/歧义指令只能走 CLARIFY/REJECT/显式保守化，**不存在静默降级为默认约束后继续执行的路径**。
