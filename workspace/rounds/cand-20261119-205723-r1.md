# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「结构优化」×「人机协作」；技术基线延续 v15）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（技能扩散版：SCD/DSD/DCA/EDC，定义 607–626；引理 125–130；实验 E661–E670）。
> **本轮纪律**：**结构只在证书复形内优化 + 人类只作结构提案与场景提供 + 权威交接必须持证 + 失效即退回 v15**。不推倒 v15：v15 的 SCD/DSD/DCA/EDC、v13 的 AIO/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。八个新组件——SCC（结构证书复形）、SPO（保结构优化器）、HSPG（人类结构提案治理器）、SAC（共享权威契约）、HRC（交接就绪证书）、ILC（意图—载荷证书）、SDL（结构退化阶梯）、SGA/CTA（结构间隙与协作轨迹审计）——一律以**收缩/中立元**接入：只收缩授权集、只增加场景/证据/交接余量；失效即严格退回 v15（引理 140），再沿 v15→v14→…→v6 退化链退回。本轮只做三件事：把"结构"从手工接线改写为**可证复形上的拓扑优化**、把"人"从紧急停止按钮改写为**不受信的结构提案者与共同权威**、把二者合成**人提议结构、机认证结构、共管权威、单调退化**的闭环。

## 0. 直觉与动机

**灵感 1（结构优化 → 证书复形上的拓扑优化）**
直觉：v15 的 SCD 已经能组合技能、DSD 已经能分配扩散步，但它优化的是"走多少步"，**技能之间怎么接线仍是手工的**：哪些技能串联、哪里加旁路、两臂是否协同、失败后回到哪条链，都是人预先写死的。现实里，代价和安全往往由拓扑而非参数决定——同一个"抓取—搬运—放置"任务，先退再抓与直接抓、单臂与双臂、刚性插入与柔顺搜索、加一条独立传感旁路还是加一条共享相机的旁路，代价与失效模态完全不同。把桁架拓扑优化的语言搬过来：地面结构 = 所有已认证技能/迁移/协同约束；设计变量 = 元素是否在结构中；载荷工况 = 任务、摩擦、位姿、人机状态；应力约束 = 证书余量；目标 = 期望代价 + 风险 + 复杂度。核心创新：**结构证书复形（Structural Certificate Complex, SCC）+ 保结构优化器（Structure-Preserving Optimizer, SPO）**。优化器只产生拓扑提案，提交必须通过复形认证；每个提交结构必须包含一条已认证的"脊线" `K_0`（安全回退链），且与 `K_0` 的编辑距离受限。关键反直觉点：**冗余不总等于安全**——两条并联路径若共享同一传感器/模型/校准集，增加冗余只会增加复杂度与虚假信心；因此目标应是"每单位代价的失效独立性"，而不是单纯最小化代价。

**灵感 2（人机协作 → 人类是结构提案者与共同权威）**
直觉：传统 `a_ask` 把人类当成一个"是/否"紧急停止按钮，这是对合作者能力的巨大浪费。人真正擅长的是**提供结构**：把任务拆成子任务、指出约束、演示一个动作、说明"这个场景下要小心什么"、在模糊时澄清意图。但人的输入并不自动安全：反应有延迟、意图有歧义、长期运行会疲劳、会过度信任自动化、态势感知可能落后于机器。核心创新：**人类结构提案治理器（Human Structural Proposal Governor, HSPG）+ 共享权威契约（Shared Authority Contract, SAC）+ 交接就绪证书（Handover Readiness Certificate, HRC）**。人的结构编辑与意图都只是**不受信提案**：经 HSPG 映射为候选结构与场景集，再由 SCC 认证；人不能扩张授权，只能重构已认证元素、增加约束或提供新场景。权威不是"谁最后按按钮"，而是一组带作用域、带有效期、带交接条件的契约；任何交接都要求接收方 HRC 有效（态势感知、反应时间、通信延迟、工作负荷、回退就绪），并用两阶段提交消除"无人掌舵"的缝隙。关键反直觉点：**更多人类权威不一定更安全**——歧义的人类意图比保守的机器回退更危险；因此"人说了算"必须被改写为"人提议、证书授权、契约交接"。

**灵感 3（结构优化 × 人机协作 → 人提议结构、机认证结构、共管权威、单调退化）**
直觉：既然人最擅长提供结构，机器最擅长认证结构，就该把二者接成一条闭环：人给出结构编辑与意图/载荷场景；SPO 在证书复形内做拓扑优化；SCC 认证候选；ILC 把模糊意图展开成一组场景而不是一个猜测；SAC/HRC 决定这一帧由谁掌舵；SDL 在漂移、场景覆盖不足、交接未就绪或人类离线时沿嵌套档位单调退化；SGA/CTA 审计"结构间隙"与"协作轨迹"，防止优化器和人共享同一个盲点。核心创新：**意图—载荷证书（Intent–Load Certificate, ILC）+ 结构退化阶梯（Structural Degradation Ladder, SDL）+ 结构间隙/协作轨迹审计（Structural Gap Auditor / Collaboration Trace Auditor, SGA/CTA）**。共享状态 `ζ_struct=(K, K_0, level, SC, α, HRC, D_ℓ, U_struct, U_cm, trace, drift)`。这把"结构优化"与"人机协作"合成同一个对象：**一张以证书为节点、以权威为边、以载荷场景为索引的可证结构图**。

**三者如何统一**
统一为 **v15 证书层之上的"结构—权威层"**：v15 回答"在状态 x 下哪些动作被物理/数据证书授权"（`Exec_v15`），v16 回答"这些授权动作应按哪张已认证结构接线、由谁在什么权威契约下执行"（`Exec_v16`）。SCC 把结构变成可检查的复形；SPO 把接线优化变成"提案—认证"；HSPG 把人类变成不受信结构提案者；ILC 把意图变成场景集；SAC/HRC 把权威交接变成可证动作；SDL 把风险升高变成单调退化；SGA/CTA 把结构间隙与共同模态显式化。**SCC 回答"这张结构是否被认证"，HSPG/ILC 回答"人想让它变成什么、在哪些场景下"，SAC/HRC 回答"这一帧谁掌舵"，SDL 回答"出问题时退到哪张结构"**。八者不是八个补丁，而是"结构—意图—权威—退化"的闭环。

## 1. 研究问题（轮次升级版）

- **Q1（结构证书复形的可证语义）**：如何定义"结构"才使任意拓扑编辑都可判定安全？顶点、迁移、协同约束的证书如何取交而不重复计错？"脊线 `K_0`"与"失效独立性"如何形式化，才能既保留安全回退又不把冗余误当安全？有限载荷场景集与真实分布之间的结构间隙如何给出单侧界？
- **Q2（人类提案治理与权威交接）**：如何把人类的结构编辑、约束、演示与意图映射成候选结构与场景集，同时保证永不扩张授权？意图歧义、冲突提案、过度信任、权威蠕变如何被检测与抑制？"交接就绪"需要哪些可测量量，反应时间/通信延迟的共形分位如何与危险到达时间比较？双向交接如何避免"无人掌舵"的缝隙？
- **Q3（拓扑优化与实时性）**：在证书约束、脊线包含、编辑距离与失效独立性约束下，如何构造拓扑优化问题并用伴随灵敏度求解？如何保证优化器只是提案器、提交前必须重认证？在线 50Hz 内不可能做完整重优化，如何把"在线选结构"与"离线优化/认证"分离？人类注意力与认证预算如何在"补场景、补证书、重新优化"之间分配？
- **Q4（与 v15 的兼容与活性）**：结构优化或人类提案是否可能绕过 v15 的 TGC/UC/四重证书？SCC/ILC 的间隙是否与 v15 的 DCA/EDC 同向叠加？退化到第 0 档是否会清空可行集、导致频繁 `a_ask`？新增模块能否守住 50Hz/p99≤22ms，并严格退回 v15？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 结构只在证书复形内优化律（Optimize Structure Only Inside the Certified Complex）**
每个被提交的结构 `K` 必须包含已认证脊线 `K_0⊆K`，每个顶点/迁移/协同约束都必须携带 v15 证书句柄；优化器只能产生提案，提交必须由 SCC 重新认证。禁止任何"未认证元素先接上、以后再补证"的拓扑；禁止用共享失效模态的冗余冒充安全；结构间隙 `U_struct` 与共同模态间隙 `U_cm` 必须显式计入预算。

**P26 人类提议不授权律（Human Proposes, Never Authorizes）**
人类的结构编辑、约束、演示与意图一律视为不受信提案。HSPG 必须先经 SCC 过滤、后排序；人类不得扩张 `Acc`、不得加入未认证元素、不得用未经验证的场景去**放宽**约束。新增已验证场景只能增加约束；歧义意图必须展开为多解释场景集或触发澄清，禁止收敛成单一猜测。权威请求只能交给 SAC，并由 HRC 门控。

**P27 权威交接必须持证且结构单调退化律（Certified Handover, Monotone Structural Degradation）**
权威状态按作用域划分，任何交接都要求接收方 HRC 有效、给出方完成状态转移，并用两阶段提交保证任意时刻每个作用域都有持证所有者。风险触发（漂移、场景覆盖不足、HRC 失效、人类离线、优化器/认证器故障）只能使 SDL 向更保守档位移动；升档必须经过完整重认证事件。最坏情形是 `K_0` 脊线或安全停/问，而不是一张未验证的结构。

## 3. 与基线的接口（如何退化）

- **SCC 失效** ⇒ 只保留单一脊线 `K_0`，无拓扑编辑、无复形认证，`Exec_v16=Exec_v15`，**等价 v15 固定结构路径**；
- **SPO 失效** ⇒ 不做拓扑优化，只执行 `K_0` 或人类提案经认证后的固定结构，**等价"v15 + 固定已认证结构"**；
- **HSPG 失效** ⇒ 忽略人类结构提案与意图编辑，只保留自主认证结构，**等价"v15 + 无人类结构输入"**；
- **SAC/HRC 失效** ⇒ 权威固定为自主 `A`，禁止任何交接，**等价"v15 + 纯自主"**；
- **ILC 失效** ⇒ 退回默认场景集 `D_default`，不做意图特化，**等价"v15 + 默认载荷"**；
- **SDL 失效** ⇒ 固定在 `K_0` 单档，无阶梯、无塌缩，**等价"v15 + 单一安全脊线"**；
- **SGA/CTA 失效** ⇒ 保守地拒绝任何结构间隙未验证的结构、不做协作自适应，**等价"v15 + 最保守结构"**；
- **八者全失效** ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→v13→…→v6 退化链退回；
- **安全继承**：SCC 只做取交与认证，SPO 只提案，HSPG 只过滤，SAC 只在契约内转移权威，HRC 只门控，ILC 只加场景，SDL 只降档，SGA/CTA 只拒绝/告警。八端口均不能新增授权或放宽任何 v15 阈值；`Exec_v16⊆Exec_v15` 由引理 131 保证，严格退化由引理 140 保证。

## 4. 预期贡献

1. **证书复形上的结构优化**：把 v15 的"技能组合"从手工接线提升为可证复形上的拓扑优化；优化器只提案、认证器才提交，脊线包含与信任域保证优化永远不会优化掉安全回退；
2. **失效独立性优先的冗余观**：把"加冗余"改写为"加独立证据/独立失效模态"，给出共同模态间隙 `U_cm`，纠正"并联即安全"的工程直觉；
3. **人类提案治理与持证权威交接**：把人类从紧急停止按钮提升为结构提案者与共同权威，同时用 HSPG/SAC/HRC 保证人类输入不扩张授权、交接不产生无人掌舵的缝隙；
4. **结构—意图—权威分离**：v15 管"能执行什么"，SCC 管"怎么接线"，ILC 管"在哪些场景下"，SAC 管"谁掌舵"；用 `Exec_v16⊆Exec_v15` 把结构优化、协作与安全解耦；E671–E690 覆盖结构 soundness、拓扑收益、共同模态、提案治理、交接就绪、歧义意图、退化与端到端。

## 5. 本轮最大风险

**一句话**：结构优化器与人类共享同一套载荷/意图模型，拓扑优化可能找到一个"在人类给出的场景集上处处可行、却恰好利用未覆盖工况"的结构，而人的批准只增加信心、不增加覆盖，最终在"结构最优、人类背书、证书可行"的表象下执行一个在真实世界未经验证的决定——即**结构可证的、协作自洽的、却绝对错误的安全决定**。

| `σ_e(K,ξ), c_e(K,ξ)` | 元素 `e` 在结构 `K` 与场景 `ξ` 下的需求应力与认证容量（均归一化，容量来自 v15 余量） |
| `Feas(K,D)` | 结构可行性：`K_0⊆K` 且 `∀ξ∈D,∀e∈K: σ_e(K,ξ)≤c_e(K,ξ)`，且所有协同面不变量成立 |
| `J(K,D)` | 结构代价：`E_q[cost(K,ξ)]+λ·Risk(K,D)+μ·Complexity(K)`，其中 `Complexity` 惩罚元素/面数量与共享依赖 |
| `SC(K,D)` | 结构证书：`(Feas, min_margin, U_struct, U_cm, coverage)`；`min_margin=min_{e,ξ}(c_e−σ_e)` |
| `U_struct(D)` | 场景覆盖间隙：真实载荷分布中未被 `D` 覆盖的质量上界（单侧共形/分布鲁棒上界） |
| `U_cm(K)` | 共同模态间隙：结构内（含人机之间）共享传感器/模型/校准/先验所导致的共同失效概率上界 |
| `T(K_0,k)` | 信任域：`{K:K_0⊆K, d_struct(K,K_0)≤k, |K|≤N_max}`；`d_struct` 为元素对称差/编辑距离 |
| `h=(edit,constraints,D_h,authority_req,rationale)` | 人类结构提案；`edit` 为增删/重接/拆分/合并元素，`authority_req` 只转交 SAC |
| `G_H(h,K,D)→(K_h,D_h,status)` | 人类提案治理映射；`status∈{certified,repaired,needs_cert,rejected,clarify,authority_forwarded}` |
| `α∈{A,S,H,STOP}` | 权威状态：自主、共享、人类、安全停；每个作用域 `o` 有唯一所有者 `owner(o)` |
| `C_auth={(o,owner,validity,handover_condition,fallback)}` | 共享权威契约；交接条件引用 HRC，`fallback` 必须指向已认证结构或 STOP |
| `HRC=(Aware,T_h^{1−β_h},L_c^{1−β_c},W_h,F_b)` | 交接就绪证书：态势感知、反应时间分位、通信延迟分位、工作负荷、回退就绪 |
| `T_crit` | 当前计划下危险到达时间；交接必须满足 `T_h^{1−β_h}+L_c^{1−β_c}≤T_crit` |
| `ILC(ℓ)=(D_ℓ,cov_ℓ,amb_ℓ)` | 意图 `ℓ` 的载荷证书：场景集、覆盖下界、歧义度（解释数/熵） |
| `SDL=(L_0⊆L_1⊆…⊆L_m)` | 结构退化阶梯；`L_0` 为停/问，`L_1=K_0`，`L_m` 为完整优化结构，授权集单调嵌套 |
| `Trace,ζ_struct` | 协作轨迹与共享状态：`ζ_struct=(K,K_0,level,SC,α,HRC,D_ℓ,U_struct,U_cm,trace,drift)` |

> 说明：定义 627–646 延续 v15 的 607–626。v15 的 DCA/EDC 管“技能组合的数据集校准与漂移”，v16 的 SCC/SGA 管“结构拓扑与场景覆盖”，二者正交；部署时先过 v15 证书，再过 v16 结构认证，最后过 SAC 权威契约。

# IP-402 Structural Certificate Complex：结构是一张可检查的证书复形
class StructuralCertificateComplex:
    def __init__(self, ground, v15_cert, spine, n_max=12, k_edit=3,
                 budget_struct=0.05):
        self.G = ground                 # 地面结构：已认证技能/迁移/面
        self.v15 = v15_cert             # v15 证书句柄
        self.K0 = spine                 # 已认证脊线，必须始终保留
        self.n_max = n_max              # 结构规模上限
        self.k_edit = k_edit            # 与脊线的最大编辑距离
        self.budget = budget_struct     # U_struct + U_cm 的预算

    def well_formed(self, K):
        return (self.K0.subcomplex_of(K)
                and K.size() <= self.n_max
                and edit_distance(K, self.K0) <= self.k_edit
                and K.is_dag()
                and all(self.v15.has_handle(e) for e in K.elements()))

    def authorized(self, K, x):
        if not self.well_formed(K):
            return set()
        acc = set(self.v15.authorized_actions(x))
        for v in K.vertices:      acc &= self.v15.acc_of(v, x)
        for e in K.edges:         acc &= self.v15.transition_acc(e, x)
        for f in K.faces:         acc &= self.v15.coordination_acc(f, x)
        return acc                 # 逐元素取交：只删不增

    def stress(self, K, xi):
        return {e: self.G.load(e, K, xi) for e in K.elements()}

    def capacity(self, K, xi):
        return {e: self.G.capacity(e, K, xi) for e in K.elements()}

    def feasible(self, K, D):
        if not self.well_formed(K):
            return False
        return all(self.stress(K, xi)[e] <= self.capacity(K, xi)[e]
                   for xi in D for e in K.elements())

    def certificate(self, K, D):
        if not self.well_formed(K):
            return Certificate(False, float("-inf"), float("inf"),
                               float("inf"), 0.0)
        margins = [self.capacity(K, xi)[e] - self.stress(K, xi)[e]
                   for xi in D for e in K.elements()]
        return Certificate(
            feasible=min(margins) >= 0,
            min_margin=min(margins),
            U_struct=self.G.scenario_gap(D),
            U_cm=self.G.common_mode_gap(K),
            coverage=self.G.coverage(D))


# IP-403 Structure-Preserving Optimizer：只提案，不提交
class StructurePreservingOptimizer:
    def __init__(self, scc, lam_risk=1.0, mu_complexity=0.1,
                 k_edit=3, n_max=12, iters=50):
        self.scc = scc
        self.lam, self.mu = lam_risk, mu_complexity
        self.k_edit, self.n_max, self.iters = k_edit, n_max, iters

    def relaxed_gradient(self, rho, D):
        # DAG 流上的伴随灵敏度：每个场景 O(|V|+|E|)
        cost = sum(self.scc.G.weight(xi) * self._cost(rho, xi) for xi in D)
        stress = [self._stress(rho, xi) for xi in D]
        return self._adjoint(cost, stress, rho, D)

    def propose(self, D, human_hint=None):
        # 连续松弛只用于生成候选，不构成任何安全承诺
        rho = self._init_from(self.scc.K0, human_hint)
        for _ in range(self.iters):
            g = self.relaxed_gradient(rho, D)
            rho = self._projected_step(rho, g)     # 投影到可行域
        K = self._discretize(rho)                   # SIMP 式阈值/投影
        return self._enforce_spine_and_trust(K)

    def commit(self, K, D):
        sc = self.scc.certificate(K, D)
        if not sc.feasible:
            return None, sc
        if sc.U_struct + sc.U_cm > self.scc.budget:
            return None, sc
        return K, sc                                # 只有认证通过才提交

    def _enforce_spine_and_trust(self, K):
        K = K.union(self.scc.K0)                    # 脊线不可被优化掉
        while edit_distance(K, self.scc.K0) > self.k_edit:
            K = K.remove_least_valuable()
        while K.size() > self.n_max:
            K = K.remove_least_valuable()
        return K


# IP-404 Human Structural Proposal Governor：人类只提案，不授权
class HumanStructuralProposalGovernor:
    def __init__(self, scc, spo, alpha_h=0.05):
        self.scc, self.spo = scc, spo
        self.alpha_h = alpha_h

    def govern(self, h, K, D):
        K_h = K.apply_edit(h.edit)                  # 人类编辑只是候选
        D_verified = D.union(h.verified_scenarios)
        D_unknown = set(h.unverified_scenarios)     # 未验证场景不得放宽约束
        if not self.scc.well_formed(K_h):
            return None, D, "rejected"
        if h.authority_req is not None:
            return K_h, D_verified, "authority_forwarded"   # 转交 SAC，HSPG 不授予
        sc = self.scc.certificate(K_h, D_verified)
        if sc.feasible and sc.U_struct + sc.U_cm <= self.scc.budget:
            return K_h, D_verified, "certified"
        # 人类结构不成立时，围绕它重新优化；仍须重认证
        K_opt = self.spo.propose(D_verified, human_hint=K_h)
        K_opt, sc2 = self.spo.commit(K_opt, D_verified)
        if K_opt is not None:
            return K_opt, D_verified, "repaired"
        if D_unknown:
            return None, D_verified, "needs_cert"
        return None, D_verified, "clarify"


# IP-405 Shared Authority Contract：两阶段提交，权威无缝隙
class SharedAuthorityContract:
    def __init__(self, scopes, hrc):
        self.owner = {o: "A" for o in scopes}
        self.hrc = hrc
        self.pending = {}

    def request(self, scope, requester, state, x):
        # 旧所有者在 ack 前保留权威，避免“无人掌舵”
        if requester == "H" and not self.hrc.valid(state.human,
                                                    state.comm, x,
                                                    state.fallback_cert):
            return False
        if requester == "A" and not self.hrc.machine_ready(state, x):
            return False
        self.pending[scope] = (requester, state)
        return True

    def ack(self, scope, state):
        if scope not in self.pending or not state.transfer_ack:
            return False
        requester, _ = self.pending.pop(scope)
        self.owner[scope] = requester
        return True

    def owner_of(self, scope):
        return self.owner[scope]


# IP-406 Handover Readiness Certificate：交接是一个可证动作
class HandoverReadinessCertificate:
    def __init__(self, alpha_h=0.05, alpha_c=0.05, a_min=0.8,
                 w_max=0.7):
        self.alpha_h, self.alpha_c = alpha_h, alpha_c
        self.a_min, self.w_max = a_min, w_max

    def valid(self, human, comm, x, fallback_cert):
        T_h = conformal_quantile(human.reaction_times, 1 - self.alpha_h)
        L_c = conformal_quantile(comm.latencies, 1 - self.alpha_c)
        aware = human.situation_awareness(x)
        workload = human.workload(x)
        T_crit = x.time_to_hazard()
        return (aware >= self.a_min
                and T_h + L_c <= T_crit
                and workload <= self.w_max
                and fallback_cert.feasible)

    def machine_ready(self, state, x):
        # 机器接回也必须持证：状态可解释、回退就绪、无未完成交接
        return state.explainable and state.fallback_cert.feasible \
            and not state.pending_handover


# IP-407 Intent–Load Certificate：模糊意图展开为场景集
class IntentLoadCertificate:
    def __init__(self, alpha_l=0.05, coverage_min=0.95, amb_max=2):
        self.alpha_l = alpha_l
        self.coverage_min, self.amb_max = coverage_min, amb_max

    def parse(self, ell, x):
        # 返回多解释；每个解释对应一个场景集，绝不提前合并成单一猜测
        interps = parse_intent(ell, x)
        return [self._scenarios(i, x) for i in interps]

    def certificate(self, ell, x):
        D_set = self.parse(ell, x)
        D_ell = set().union(*D_set) if D_set else set()
        cov = conformal_coverage(D_ell, self.alpha_l)
        amb = len(D_set)
        if cov < self.coverage_min or amb > self.amb_max:
            return ILC(D_ell, cov, amb, status="ask")
        return ILC(D_ell, cov, amb, status="ok")


# IP-408 Structural Degradation Ladder：风险升高只降不升
class StructuralDegradationLadder:
    LEVELS = ["stop_or_ask", "spine_K0", "spine_plus_bypass",
              "optimized_full"]

    def __init__(self, scc, sac, hrc, ilc):
        self.scc, self.sac, self.hrc, self.ilc = scc, sac, hrc, ilc
        self.level = len(self.LEVELS) - 1

    def step(self, x, K, D, human, comm):
        sc = self.scc.certificate(K, D)
        if x.drift or self.ilc.coverage(D) < self.ilc.coverage_min:
            self.level = 0
        elif human is None or not self.hrc.valid(
                human, comm, x, sc):
            self.level = max(0, self.level - 1)
        elif sc.U_struct + sc.U_cm > self.scc.budget:
            self.level = max(0, self.level - 1)
        # 升档必须由完整重认证事件显式调用 ascend()
        return self.LEVELS[self.level]

    def ascend(self, recert_event):
        if recert_event.complete and recert_event.sc.feasible:
            self.level = min(len(self.LEVELS) - 1, self.level + 1)


# IP-409 Structural Gap Auditor：场景覆盖与共同模态必须显式
class StructuralGapAuditor:
    def __init__(self, alpha_s=0.05, n_min=30, cm_budget=0.01):
        self.alpha_s, self.n_min = alpha_s, n_min
        self.cm_budget = cm_budget

    def audit(self, K, D, heldout):
        if len(D) < self.n_min:
            return Audit(False, float("inf"), float("inf"),
                         "insufficient_scenarios")
        U_struct = conformal_upper_gap(D, heldout, 1 - self.alpha_s)
        U_cm = common_mode_upper_bound(K, heldout)
        ok = U_struct + U_cm <= self.cm_budget
        return Audit(ok, U_struct, U_cm, "ok" if ok else "gap_too_large")


# IP-410 Collaboration Trace Auditor：过度信任与权威蠕变
class CollaborationTraceAuditor:
    def __init__(self, t_min=0.4, override_rate_max=0.2):
        self.t_min, self.override_rate_max = t_min, override_rate_max

    def audit(self, trace):
        flags = []
        if any(e.kind == "accept" and e.dt < self.t_min for e in trace):
            flags.append("over_trust")          # 接受快于可合理核验的时间
        overrides = [e for e in trace if e.kind == "override"]
        if overrides and (sum(not e.recertified for e in overrides)
                          / len(overrides)) > self.override_rate_max:
            flags.append("authority_creep")     # 未重认证的覆盖过多
        if any(e.human_ok and e.machine_ok and e.outcome_unsafe
               for e in trace):
            flags.append("common_mode_blind_spot")
        return flags

## 2. 推导（引理 131–140）

**引理 131（结构取交不扩张 v15 授权）**
若 `K_0⊆K` 且 `K` 的每个顶点/迁移/协同面都携带 v15 证书句柄，则对任意 `x`，
```
Acc(K,x) ⊆ Acc_v15(x)，
```
其中 `Acc(K,x)` 按定义 632 逐元素取交。若进一步 `Feas(K,D)` 成立，则沿 `K` 的执行在 `D` 内所有场景下安全。证明：`Acc(K,x)` 是 `Acc_v15(x)` 与若干证书集的交，交运算只删不增；`Feas` 保证每个元素的应力不超过其 v15 容量，故余量非负。∎ 推论：**结构优化只能改变“哪些已认证动作被如何接线”，不能改变“哪些动作被认证”**；这是整个结构层的安全地基。

**引理 132（脊线保留与信任域不变量）**
任何被提交的结构 `K` 都满足 `K_0⊆K` 且 `d_struct(K,K_0)≤k`。因此 `K` 始终保留一条已认证回退脊线；删除 `K_0`、超出编辑距离或超出 `N_max` 的编辑一律被拒绝。证明：由 `well_formed` 与 `_enforce_spine_and_trust` 的定义，提交前强制 `K←K∪K_0` 并逐步删除直到满足编辑距离与规模上限；删除过程只删除“最不 valuable”的非脊线元素。∎ 推论：**优化器不可能把自己的安全回退优化掉**；最坏情况下它退化为 `K_0`，而不是一张没有退路的“最优”结构。

**引理 133（优化器提案无关安全性）**
设 `K` 是任意被提交的结构。由于提交条件是 `SC(K,D).feasible` 且 `U_struct+U_cm≤budget`，`K` 的安全性只依赖认证器，不依赖 `K` 是如何被生成的。因此优化器的模型误差、伴随梯度误差或离散化误差只能导致“提案被拒/次优”，不能导致“不安全提交”。证明：`commit` 先调用 `scc.certificate`，只有 `feasible` 与间隙预算同时满足才返回 `K`；否则返回 `None`。认证过程不读取优化器的梯度或松弛变量。∎ 推论：**换优化器、退火策略或初始化都不改变安全语义**；关闭 SPO 只损失代价收益，不损失安全性。

**引理 134（人类提案收缩）**
对任意人类提案 `h`，HSPG 的输出满足 `Acc(K_h,x)⊆Acc_v15(x)`；未认证元素不会被加入；新增已验证场景只能增加约束；未验证场景不得用于放宽约束；意图歧义被展开为多解释场景集，取交而非取并来定义可行结构。因此人类输入不能扩张 `Exec_v16`。证明：`govern` 先 `apply_edit` 得到候选，再 `well_formed` 过滤；所有元素必须已有 v15 句柄；`D_verified` 只增不减约束，`D_unknown` 不进入 `certificate`；多解释在 `ILC` 中保留为集合，`Feas` 对所有解释同时成立才通过。∎ 推论：**人类可以增加结构、约束与场景，但不能增加授权**；“人说了算”被改写为“人提议、证书授权”。

**引理 135（交接就绪 soundness）**
若 `HRC` 在共形水平 `1−β_h,1−β_c` 下有效，则一次交接在 `T_crit` 之后完成或态势感知不足的概率不超过 `β_h+β_c+β_w`；若 `HRC` 无效，则不会发生向人类权威的交接。证明：反应时间与通信延迟分别取 `1−β_h`、`1−β_c` 共形上分位，由共形覆盖性，真实值超出分位的概率分别不超过 `β_h,β_c`；态势感知与工作负荷是确定性阈值检查，其误判概率记为 `β_w`；三者取并集界。`valid` 返回假时 `SAC.request` 直接拒绝。∎ 推论：**交接不是紧急逃生，而是一个必须持证的动作**；来不及交接时只能降档或安全停，不能“先把控制权塞给人”。

**引理 136（双向权威无缝隙）**
在 `SAC` 的两阶段提交下，任意作用域 `o` 在任意时刻都有一个持证所有者；不存在“旧所有者已释放、新所有者未就绪”的区间。证明：`request` 只写入 `pending`，不改变 `owner(o)`；只有 `ack` 且 `transfer_ack` 为真时才切换 `owner(o)`；若 `ack` 失败，旧所有者继续持有；`STOP` 始终是合法所有者。∎ 推论：**人机都不能“松手”**；机器接回人类权威时同样需要 `machine_ready`，避免“人类刚接管又被机器抢回”的惊讶。

**引理 137（意图覆盖与结构间隙）**
设 `ILC(ℓ)` 的覆盖下界为 `cov_ℓ`，结构 `K` 在 `D_ℓ` 上可行。则真实载荷落在 `D_ℓ` 之外（从而证书可能失效）的概率不超过
```
α_ℓ + U_struct(D_ℓ)，
```
其中 `α_ℓ=1−cov_ℓ`。若 `cov_ℓ<coverage_min` 或 `amb_ℓ>amb_max`，系统必须澄清或回退，不得提交结构。证明：由 `D_ℓ` 的共形覆盖性，真实场景不在 `D_ℓ` 的概率不超过 `α_ℓ`；`U_struct` 是未覆盖质量的上界，二者取并集界。∎ 推论：**歧义意图应导致更大的场景集与更保守的结构，而不是更自信的单一解释**；`ILC` 把“猜人心”变成“覆盖人心”。

**引理 138（结构退化单调且无越级）**
`SDL` 的档位按授权集嵌套：`L_0⊆L_1⊆…⊆L_m`；风险触发（漂移、覆盖不足、HRC 失效、间隙超预算、人类离线）只会使 `level` 不增；升档必须由 `ascend(recert_event)` 显式触发，且要求完整重认证事件 `recert_event.complete` 与 `sc.feasible`。因此不存在“越降越勇”或未认证升档。证明：`step` 中所有分支只会赋值 `0` 或 `max(0,level−1)`；唯一的增操作在 `ascend`，被完整重认证事件门控。∎ 推论：**最坏行为是 `K_0` 脊线或停/问**，而不是一张未验证的高档结构。

**引理 139（共同模态下界）**
若人类与机器（或两条并联路径）共享一个失效原因，其发生概率为 `P_common`，则联合失效概率至少为
```
max(P_H,P_M) ，
```
且任何假设独立性的证书至少低估 `P_common`；更精确地，联合失效概率下界为 `P_H+P_M−P_common`。证明：共同失效事件同时属于两个失效事件，故 `P(joint)≥max(P_H,P_M)`；由容斥，`P(H∪M)=P_H+P_M−P_common≤1`，在“只关心联合失效”的下界构造中取 `P_H+P_M−P_common`。∎ 推论：**人机一致同意不是证据**；只有当二者使用独立传感器/模型/校准集时，冗余才真正降低联合失效概率。`U_cm` 必须显式加入预算，`CTA` 必须检测“人机一致地错”。

**引理 140（全失效严格退回 v15）**
若 SCC、SPO、HSPG、SAC、HRC、ILC、SDL、SGA/CTA 八个端口全部注入中立元——`K=K_0`、无拓扑编辑、无优化、人类提案被忽略、权威固定为 `A`、禁止交接、`D=D_default`、`level` 固定为 `spine_K0`、审计恒通过——则 `Exec_v16=Exec_v15`，主闭环等价于 `metricvoicegauge_round_15_skill_diffusion`。若结构本身无效，主闭环第 3/6 步直接调用 `strict_fallback_v15`。证明：`K_0` 是 v15 的安全脊线，`Acc(K_0,x)=Acc_v15(x)`；其余端口只做过滤/降档/审计，不新增元素或场景；逐一代入即得执行集相等。∎ 推论：**v16 的每个端口都是可拔插的收缩/中立算子；最坏情形严格等价 v15，不会因结构或协作模块故障引入新授权。**

## 6. 已知风险与失效模式

1. **结构组合爆炸**：地面结构一大，拓扑候选数指数增长，离线优化与认证都可能不可行。缓解：限制 `N_max`、`k_edit`；按任务族预编译已认证结构库；用抽象/宏元素压缩；在线只选库。

2. **应力/容量模型失配**：`σ_e,c_e` 来自简化模型，真实力矩、摩擦、时延可能越界。缓解：保守安全因子、硬件在环、最坏场景校准、`Feas` 加鲁棒裕度、在线余量监控。

3. **共同模态被忽略**：并联路径或人机共享同一相机/模型/校准集，独立性假设失效。缓解：显式 `U_cm`；独立证据通道；SGA 审计；CTA 检测“人机一致地错”；禁止共享旁路计为冗余。

4. **人类提案的恶意/错误/冲突**：人类可能提出未认证元素、错误约束或互相冲突的编辑。缓解：HSPG 过滤；多提案取交；澄清；审计；拒绝后回退 `K_0`。

5. **意图歧义与误解析**：语言/演示可能指向多个任务或错误目标。缓解：ILC 多解释；覆盖下界；澄清；禁止单一猜测；语言只产生场景/约束，不产生授权。

6. **交接就绪误校准**：反应时间/通信延迟分布在新任务、疲劳、网络抖动下漂移。缓解：共形分位在线更新；保守先验；定期演练；HRC 失效即降档。

7. **权威蠕变与过度信任**：人类频繁秒批、机器频繁覆盖，导致契约名存实亡。缓解：CTA 审计；强制确认；UI 反事实提示；未重认证覆盖计入预算；定期重训。

8. **结构间隙低估**：场景集未覆盖尾部工况，`U_struct` 偏小；优化器恰好利用该缺口。缓解：held-out 场景；对抗载荷采样；EVT 尾部分位；分布鲁棒优化；SGA 超预算即拒绝。

9. **拓扑优化利用校准漏洞**：优化器可能把元素推到校准稀疏区以降低代价。缓解：优化器只提案；提交重认证；把校准覆盖率作为硬约束；对低覆盖元素加罚；禁止在空洞上接线。

10. **实时性开销**：结构认证、间隙审计、交接检查挤占控制预算。缓解：离线优化/认证；缓存结构；在线只做轻量重认证；watchdog；缓存未命中退 `K_0`。

11. **退化到第 0 档的活动性塌缩**：频繁澄清/降档导致系统长期停/问。缓解：分层澄清；把补证/澄清成本计入任务预算；优先修复高价值结构；允许退到最近已认证旁路而非直接停。

12. **跨平台迁移的隐性不匹配**：结构可复用，但物理边、时延、动力学不可复用。缓解：只复用结构拓扑，强制重认证物理边；平台专项校准；影子运行；迁移后先降档再升档。

## 7. 本轮最大风险

**一句话**：结构优化器与人类共享同一套载荷/意图模型，拓扑优化可能找到一个“在人类给出的场景集上处处可行、却恰好利用未覆盖工况”的结构，而人的批准只增加信心、不增加覆盖，最终在“结构最优、人类背书、证书可行”的表象下执行一个在真实世界未经验证的决定——即**结构可证的、协作自洽的、却绝对错误的安全决定**。
