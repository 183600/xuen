# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「抓取」×「嵌入式系统」）

> 第 68 轮 CALM-RAS 把「标定」升级为在线潜变量，用自监督持续驱动、用单模型多任务保证同源一致，回答了「我的测量还准吗」。但它自陈的最大风险是一个**结构性死角**：漂移与故障只靠**时间尺度/频域**分离（ω_cal vs ω_f），于是落在标定带宽内的**缓变故障**会被 COF 当漂移「标好」，在「测量越来越准」的假象下隐形。
>
> 这个死角的根源是**被动观测的可辨识性不足**：单一工作点上只有一条方程，却要同时估计「标定 c」和「故障 φ」两个未知量——慢故障与标定漂移在该点上是**不可分的**，频域只是把不可分性推迟到了慢频段。
>
> 本轮灵感的化学作用：
> - **抓取**：抓取不是单纯的操作，而是机器人**唯一能主动施加已知物理激励**的通道。改变夹持力、接触点、微滑移、负载，就是在做**系统辨识实验**——多个工作点让 (c, φ) 变得可辨识。标定误差是「换坐标」（规范变换，与激励**交换**），物理故障是「换物理」（与激励**不交换**）——于是可以用**代数/结构**而非频率把二者分开。
> - **嵌入式系统**：主动探针是安全攸关的物理动作（力太大会伤人/损物、能量太大会自热致漂移、错过截止期会用陈旧标定），必须住在一个**小、可验证、硬实时**的认证内核里，与大模型形成**异质冗余**。
>
> 核心命题：
>
> **PACE-RAS（Probe-Assisted Contact Excitation for Risk-Adaptive Systems）——把每一次抓取变成一个主动计量实验：用「规范一致性 / 非交换残差」在结构上分离慢故障与标定漂移，用嵌入式接触安全内核（CSK）保证探针本身安全、实时、可认证，用接触-视觉异质冗余把共模失效拆开。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我的测量还在测同一个东西吗——而且我能否用『摸一下』来证明？**」

## 0. 直觉与动机

**灵感 1（抓取 → 抓取是机器人唯一的主动计量探针）**
直觉：你无法用「称一个物体」判断秤是否零点漂了——因为读数偏差既可能是零点偏置（标定），也可能是秤本身坏了（故障），单一负载下二者同解。但如果你换三个已知/不同的负载再称：误差是**恒定偏置**（标定）还是**随负载变化**（故障），立刻可分。抓取就是机器人的「换负载称重」：夹持力从 2N 到 20N、接触点从指尖到指腹、叠加微滑移与不同刚度物体——每一次都是一个**工作点**。单点被动观测不可辨识的量，在多工作点主动激励下变得可辨识（持久激励，persistent excitation）。这正是 R68 缺失的那块：它只会「看」，不会「试探着摸」。

**灵感 2（规范群 → 标定是「换坐标」，故障是「换物理」）**
直觉：标定误差本质上是一个**规范变换**（gauge transform）：刚体位姿、尺度、力零偏、时间平移、曝光——它们是作用在测量上的可逆群元素，不改变物理响应函数的「形状」。因此标定误差与激励**交换**：先激励再标定 = 先标定再激励（对纯标定误差成立）。物理故障则改变 f 本身（裂纹、松动、弹性体老化、迟滞、非线性），一般**不交换**。形式化后得到一个极其干净的判据：**若「用一次抓取拟合出的标定」不能解释另一次抓取，则存在不可被标定吸收的故障**——这就是「规范不一致」，它与故障的时间常数**无关**。R68 的慢故障因此在结构上暴露，而不是在频域里躲藏。

必须诚实地说出边界：如果真实故障**恰好**落在规范群轨道内（例如整体刚度按比例缩放，可被尺度规范吸收），那它在原理上就是不可观测的——这不是算法缺陷，是物理/数学的硬极限。PACE-RAS 的价值在于**把可观测的部分全部拿回来，并明确标出不可观测的边界**，而不是假装能测一切。

**灵感 3（嵌入式系统 → 探针必须住进可认证的硬实时内核）**
直觉：主动探针不是免费的。力太大会压碎物体或伤人；反复激励会**加速磨损、产生热量**，而热又制造漂移——探针既是对故障的检测器，也是故障的制造者。更致命的是实时性：如果探针/检验错过了控制截止期，系统就会拿着**陈旧的标定**做安全决策。因此必须把「接触采集 + 包络约束 + 探针调度 + 非交换检验」放进一个**小到可以形式化验证**的 MCU/锁步核（CSK）：定点运算、硬件时间戳、WCET 有界、看门狗与掉电检测、独立时钟/电源域，并且能**独立于应用处理器**拉响 SAFE_STOP。大模型（MTM）继续跑在应用处理器上——两者物理通道不同（力/触觉 vs 视觉），共模失效相关系数 ρ_CM ≈ 0，这是航空级的**异质冗余**，而不是同质双份。

**灵感 4（合流 → PACE-RAS 七组件）**
1. **CMP Contact Metrology Probe**：在安全包络内设计持久激励的抓取探针集（力级/接触点/微滑移/负载）；
2. **GAT Gauge-Absorbing Transform fit**：逐探针拟合最优规范变换 ĉ_k；
3. **NCT Non-Commutativity Test**：用规范不一致 Δ_c 与规范不变残差 δ* 做**结构**故障判别；
4. **CSK Contact Safety Kernel**：嵌入式硬实时接触安全内核（采集/包络/调度/定点 NCT/看门狗）；
5. **PBC Probe Budget Controller**：力/应力/能量/热/时间预算，并前馈补偿探针自致热漂移；
6. **HRA Heterogeneous Redundancy Arbiter**：接触通道与视觉通道异质仲裁，接触优先；
7. **DGR Deadline-Graceful Degradation**：任何时限/看门狗/锁步/掉电异常 → 冻结标定 + 保守降级；
   —— 再叠加 **CALM-RAS† 继承核**（MTM / COF / CFA / CAC / RAS-WM† 全部保留）。

**灵感 5（对 R68 风险与遗留的对症下药）**
- R68「缓变故障被标定吸收」→ **引理 16**：非规范可吸收故障的 δ* 下界与时间常数无关，慢故障检出率不再随 ω_f→0 崩塌；
- R68「CAC 金标集可能没覆盖该故障」→ **GPC 抓取物理 canary**：每次抓取的成功/滑移/形变就是免费标签，是覆盖不到的模式也会在抓取成功率上先露头；
- R68「2.6ms / 500MB 影子 / 原子换装」这些未经验证的嵌入式假设 → **CSK/DGR** 把它们变成显式、可测、可降级的约束；
- R68「不确定只收紧」纪律 → 由 HRA/DGR 扩展到**接触不确定**与**嵌入式故障**，λ_floor 继续只升不降。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（PACE-RAS 总览）** PACE-RAS = (CMP, GAT, NCT, CSK, PBC, HRA, DGR, GPC, CALM-RAS†)。四条不变式：
(i) **抓取即实验**：每次接触都同时产出「已知激励」与「免费物理标签」，不允许纯被动等待；
(ii) **规范可分**：只有当故障不可被规范群吸收时才判故障；规范群 G 必须显式定义、版本化、随证书冻结；
(iii) **接触安全包络**：力/应力/能量/速度上限是硬约束而非软惩罚，任何探针不得越界；
(iv) **嵌入式时限**：探针与 NCT 的 WCET 有界；时限/看门狗/锁步/掉电异常 → 冻结计量 + 单调保守降级，绝不用陈旧标定。

**定义 294（接触测量模型）** y_t = T_{c_t}( f_{φ_t}(u_t, s_t) ) + n_t。c_t ∈ 𝒞 为标定潜变量（继承定义 278 的 12 维），φ_t ∈ Φ 为故障参数，u_t 为探针指令（力/位姿/滑移/负载），s_t 为物体/环境状态，T_c ∈ G 为规范变换，f_φ 为真实接触物理。

**定义 295（规范群与规范吸收）** G = SE(3) ⋉ (ℝ_+ × ℝ³ × ℝ × ℝ²)，分别作用刚体位姿、尺度、力零偏、时间平移、曝光/情绪阈值。故障 φ 称为**规范可吸收**，若 ∃g ∈ G 使 f_φ = g ∘ f_0（故障只是标定的另一种写法）；否则称为**规范不可吸收**。只有不可吸收故障在原理上可被本层检出；可吸收部分是显式的**可观测性盲区**，写入 J_PACE 的 known-blind 字段。

**定义 296（主动抓取激励 / 持久激励）** 探针集 U = {u^(k)}_{k=1}^K 覆盖不同力级、接触点、滑移速度与负载。U 称为对 (d_c, d_φ) **持久激励**，若映射 (c, φ) ↦ {O_{c,φ}(u^(k))}_{k=1}^K 局部单射，等价于激励雅可比 J_U 的秩 ≥ d_c + d_φ 且 σ_min(J_U) > 0。

**定义 297（逐探针规范拟合 GAT）** ĉ_k = argmin_{c∈G} ‖y^(k) − T_c f̂_0(u^(k), ŝ^(k))‖²_{R^{-1}}。定义：
- **规范一致性缺陷** Δ_c(U) = max_{k,l} d_G(ĉ_k, ĉ_l)（不同工作点拟合出的标定彼此有多不一致）；
- **规范不变残差** δ*(U) = min_{c∈G} max_k ‖y^(k) − T_c f̂_0(u^(k), ŝ^(k))‖（任何标定都解释不掉的部分）。

**定义 298（非交换检验 NCT）** 接触通道裁决 v_C = FAULT ⇔ (δ* > τ_δ) ∨ (Δ_c > τ_Δ)。语义：纯标定漂移下，同一规范能解释所有探针 ⇒ Δ_c≈0、δ*≈0；存在不可吸收故障时，**表观标定随工作点漂移**（Δ_c>0）且/或留下无法吸收的残差。关键性质：该判据是跨**工作点**而非跨**时间**的，故与故障时间常数 τ_φ 无关。

**定义 299（探针设计 CMP）** U* = argmax_{U ∈ 𝒰_adm} [ min_{φ: dist(f_φ, G·f_0) ≥ ε} δ*(U; φ) − λ_b·Cost(U) ]，其中 𝒰_adm 由定义 300 的包络给出，Cost 含能量/时间/磨损。在线用 D-optimal/E-optimal 近似：最大化 J_U 的最小奇异值，贪心增广，以标称抓取热启动。

**定义 300（接触安全包络与探针预算 PBC）** 探针可采纳 ⇔ F(t) ≤ F_max(s)、接触应力 ≤ σ_max(s)、接触能量 ∫F·v dt ≤ E_b、时长 ≤ T_p、温升 ΔT ≤ ΔT_max。PBC 同时预测探针自致热漂移 c_self(t) = ∫ h(t−τ) P_probe(τ) dτ，并在 NCT 前**前馈扣除**（定义 305）。

**定义 301（嵌入式接触安全内核 CSK）** 运行于认证 MCU / 锁步核，独立时钟与电源域。职责：≥1kHz 力/触觉 ADC+DMA 采集、硬件时间戳、包络监视、探针调度、定点 GAT/NCT。硬约束：WCET W_CSK ≤ D_CSK、定点量化误差 ε_q、可独立于应用处理器断言 SAFE_STOP。CSK 的规范群 G 与阈值编译进镜像并哈希进证书。

**定义 302（异质冗余仲裁 HRA）** 接触通道 v_C（CSK/NCT）与视觉-模型通道 v_M（MTM/CFA）物理异质，共模相关系数 ρ_CM ≈ 0。仲裁：
- v_C=OK ∧ v_M=OK → 正常（λ 由 RAS 给出）；
- v_C=FAULT → 保守：λ ≥ 0.9、k ≤ k_safe，**无视 v_M**；
- v_C=OK ∧ v_M=FAULT → λ ≥ 0.8、k 收缩，允许谨慎运行（视觉可能被欺骗）；
- v_C=UNAVAIL（时限/看门狗/锁步/掉电）→ SAFE_STOP（交 DGR）。
接触是物理地面真值，拥有优先级；这正是「视觉被假笑/光照/脏镜头欺骗而力觉不受影响」的冗余来源。

**定义 303（时限优雅降级 DGR）** 发生 WCET 超时、看门狗、掉电、锁步分歧或 NCT 超时：冻结标定（COF.freeze）、关闭主动探针、λ ≥ 0.8、k ≤ k_safe、记入 ℰ_embed。任何控制动作不得使用「年龄 > T_fresh」的标定；陈旧计量等同不可用计量。

**定义 304（抓取物理 canary GPC）** 每次抓取由滑移/力曲线/形变给出成功标签 ℓ_g ∈ {SUCCESS, SLIP, CRUSH, MISS}。若抓取成功率下降而 NCT 仍报 OK ⇒ 故障落在探针未激励的子空间（unexcited direction）⇒ 扩充 U 或升级 SAFE_STOP。GPC 是零成本、物理接地、覆盖 R68 CAC 金标集盲区的 canary。

**定义 305（热-探针耦合）** c_self 由已知探针日程确定，前馈扣除后残余热不确定 ε_thermal = O(ΔT·α) 并入 R_cal。因为 c_self 与**已知指令 u** 相关，它是可辨识的，不会被误当成未知故障；反之，与日程无关的残余才是故障候选。

**定义 306（J_PACE 证书）** J_PACE = (J_CALM, csk_hash, wcet_profile, lockstep_status, probe_budget_state, δ*, Δ_c, thermal_state, known_blind, pace_ver)。Valid ⇔ Valid(J_CALM) ∧ W_CSK ≤ D ∧ lockstep OK ∧ (NCT OK ∨ HRA=SAFE_STOP) ∧ 预算未越界 ∧ 标定年龄 ≤ T_fresh。

**定义 307（AIC-PACE 干扰集）** ℰ_PACE = ℰ_CALM × ℰ_grasp × ℰ_embed。ℰ_grasp = {物体滑落、易碎物损伤、人体接触、探针致磨损、探针致热漂移}；ℰ_embed = {WCET 超时、位翻转、时钟抖动、掉电、看门狗误跳、锁步分歧}。

**定义 308（管线）** 每次抓取：标称抓取规划 → CMP 选探针集 → PBC 采纳判定 → CSK 执行并硬件时间戳 → GAT 逐探针拟合 → NCT → HRA 仲裁 →（故障：交 CFA 重新归因；正常：限速更新标定 + CAC）→ GPC 记录抓取结局 → DGR 监视截止期。慢环：探针集重设计 + J_PACE 签发。

**定义 309（持久激励可辨识性）** 若 rank(J_U) = d_c + d_φ 且 σ_min(J_U) = σ_0 > 0，则 (c, φ) 局部可辨识；且对任意规范不可吸收故障，δ* ≥ σ_0·dist(f_φ, G·f_0) − η（η 为噪声裕度）。**故障时间常数不出现在该式中。**

**定义 310（实时预算）** W_total = W_CSK + W_link + W_app ≤ D_control。目标：W_CSK ≤ 0.3ms（200MHz MCU、定点、K=4、d_c=12）；探针使抓取时长增加 ≤ 15%、能量增加 ≤ 5% 预算。

```python
# IP-253 CMP：在安全包络内设计持久激励的抓取探针集
class ContactMetrologyProbe:
    def design(self, s_hat, nominal_grasp, budget):
        J = excitation_jacobian(nominal_grasp, s_hat)
        U = greedy_d_optimal(nominal_grasp, K=4, J=J, envelope=budget)
        return U                              # 力级/接触点/微滑移/负载

# IP-254/255 GAT + NCT：规范拟合 + 非交换检验
def gauge_fit_and_test(ys, us, f0, G):
    c_hat = [fit_gauge(y, f0(u)) for y, u in zip(ys, us)]
    delta_c = max(gauge_dist(a, b) for a in c_hat for b in c_hat)
    delta_star = min_over_gauge(lambda c: max_k(residual(ys[k], T(c, f0(us[k])))),
                                G)
    return delta_c, delta_star

# IP-256 CSK：嵌入式硬实时接触安全内核（定点、WCET 有界）
class ContactSafetyKernel:
    def isr_contact(self):                    # 1kHz，硬件时间戳
        y = adc_dma_read(); t = hw_timestamp()
        self.ring.push(y, t)

    def probe_cycle(self, U):
        ys = []
        for u in U:
            if not self.envelope.admit(u):     # 力/应力/能量/热
                return 'SAFE_STOP', None
            self.actuate(u)
            ys.append(self.ring.window())
        return gauge_fit_and_test(ys, U, self.f0, self.G)  # WCET ≤ D_CSK

    def watchdog(self):
        if self.wcet.overrun() or not self.lockstep.ok():
            return 'SAFE_STOP'

# IP-258/259 HRA + DGR：异质冗余仲裁 + 时限优雅降级
def arbitrate(v_C, v_M, lam_ras, k):
    if v_C == 'UNAVAIL': return 'SAFE_STOP', max(lam_ras, 1.0), 0
    if v_C == 'FAULT':   return 'STOP',     max(lam_ras, 0.9), min(k, K_SAFE)
    if v_M == 'FAULT':   return 'CAUTION',  max(lam_ras, 0.8), min(k, K_SAFE)
    return 'NORMAL', lam_ras, k

# IP-263 主闭环：PACE-RAS round
def PACE_RAS_round(M, obs, nominal_grasp):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)     # R68 一次前向
    c, Ucal, thr = M.cof.step(o['cal'], residuals(...), sigma_stat(M))

    # 1) 主动探针：设计 → 预算 → 执行
    U = M.cmp.design(M.object_state, nominal_grasp, M.pbc.budget)
    if not M.pbc.admit(U):
        U = passive_fallback(nominal_grasp)
    dc, ds = M.csk.probe_cycle(U)                              # 硬实时
    v_C = 'FAULT' if (ds > TAU_D or dc > TAU_DC) else 'OK'

    # 2) 视觉-模型通道（R68 的 CFA）
    v_M = M.cfa.verdict(o['pi'], c, Ucal)

    # 3) 异质仲裁 + 时限降级
    mode, lam, k = arbitrate(v_C, v_M, M.efs.risk_scale(...), k_ras)
    if M.dgr.missed_deadline():
        c = M.cof.freeze(); lam = max(lam, 0.8); k = min(k, K_SAFE)
        mode = 'DEGRADED'

    # 4) 控制 + 免费物理 canary + 影子提交
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.gpc.record_grasp_outcome(mode, dc, ds)
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return tau, (c, dc, ds, v_C, v_M, mode)
```

## 3. 推导

**引理 16（慢故障的结构可辨识性——直击 R68 最大风险）** 设故障 φ 规范不可吸收，且 dist(f_φ, G·f_0) ≥ ε。对持久激励的探针集 U（σ_min(J_U)=σ_0>0），规范不变残差满足 δ*(U;φ) ≥ σ_0·ε − η。式中**不含故障时间常数 τ_φ**：故当 τ_φ → ∞（落在 R68 的标定带宽内）时，检出裕度与快故障相同。证明要点：观测族 {O_{c,φ}(u^(k))} 位于规范轨道之外，到轨道的距离由最小奇异值与参数距离下界给出；时间不是该检验的坐标，因此频域不可分不再等于结构不可分。系：R68 的「标定越强、慢故障越隐形」被打破——标定只能吃掉轨道内的分量。

**引理 17（NCT 虚警与规范一致性）** 纯标定漂移下，各探针拟合的规范在噪声内一致：E[Δ_c] ≤ 2η/σ_0，虚警 ≤ α_NCT。存在不可吸收故障时 Δ_c ≥ 2σ_0·ε − η。故 NCT 的可分裕度随探针多样性（σ_0↑）与故障幅度（ε↑）增大；探针越「敢变」，判别越锐。

**引理 18（探针安全与自漂移可辨识）** 由定义 300，U 按构造满足力/应力/能量/热包络，故接触损伤概率 ≤ δ_grasp、人体受力 ≤ F_max。探针自致热漂移 c_self 是探针日程的已知泛函，前馈补偿后残余 ε_thermal = O(ΔT·α)。因 c_self 与已知 u 相关，它与未知故障**统计可分**，不会被误吸收进故障后验。

**引理 19（嵌入式时限与降级）** 若 W_CSK ≤ D_CSK（WCET 已证）且看门狗覆盖率 ≥ 1−p_wd，则任何时限超时、掉电或锁步分歧在一个控制周期内被检出，DGR 强制 λ ≥ 0.8、k ≤ k_safe、标定冻结。故「用陈旧计量执行动作」的概率 ≤ p_wd。系：嵌入式故障只可能让系统更保守，不可能让它更激进。

**定理 16（PACE-RAS 端到端风险一致性）** 在 A87–A94 与 A95（规范群完备性）、A96（包络模型正确性）下，输出 τ_cmd 满足：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_grasp + α_embed + α_nct**；
2. 对 τ_φ ≥ τ_thermal 的规范不可吸收故障，检出率 ≥ 1−β（引理 16）——**闭合 R68 的残余风险**；
3. 嵌入式故障/时限超时 ⇒ λ ≥ 0.8 ∧ k 收缩 ∧ 标定冻结（单调保守，引理 19）；
4. 接触通道 FAULT 覆盖视觉通道 OK（物理地面真值优先，定义 302）。

**定理 17（异质冗余安全性）** 设两通道失效事件相关系数 ρ_CM，则同时失效概率 P(both) = p_C p_M + ρ_CM·√(p_C(1−p_C)p_M(1−p_M))。接触（力物理）与视觉（统计外观）异质 ⇒ ρ_CM ≈ 0 ⇒ P(both) ≈ p_C·p_M；同质双份则 ρ_CM ≈ 1，几乎无增益。故在同等单通道可靠性下，HRA 的不安全失效概率严格低于任一单通道。

## 6. 本轮最大风险

**一句话**：PACE-RAS 把安全性押在「规范群 G 的完备性 + 探针本身不制造故障」上——**主动激励与故障源共用同一个物理执行器**：探针既能暴露磨损，也会加速磨损、产生热漂移并可能损伤脆弱物体；而若真实故障近似落在 G 的轨道内（例如整体刚度/尺度漂移伪装成标定缩放），NCT 会结构性失明——检测能力与制造故障的能力，是同一个抓取动作。

**次级风险与缓解**：
1. **规范群误设/不完备** → G 版本化 + known-blind 字段 + E300 负结果公开边界，绝不假装可测；
2. **探针加速磨损** → PBC 磨损预算 + 探针日程轮换 + 与维护周期联动；
3. **热-探针正反馈**（探针→热→漂移→更多探针）→ 前馈补偿 + 温升硬上限 + 冷却期；
4. **嵌入式认证成本** → CSK 只做小规模定点 NCT，规范群编译期固定，学习部分留在应用处理器；
5. **接触通道自身故障被当故障检出** → 与视觉通道交叉校验 + 锁步自检 + 看门狗，双通道都异常才 SAFE_STOP。

## 2. 形式化定义（要点版）

**定义 293（总览与四不变式）** 抓取即实验；规范可分（只判不可吸收故障，G 显式版本化）；接触安全包络为硬约束；嵌入式时限有界，异常即冻结计量 + 单调保守降级。

**定义 294–295（测量模型与规范吸收）** `y = T_c(f_φ(u,s)) + n`；故障规范可吸收 ⇔ `f_φ = g∘f_0`（g∈G），否则不可吸收。只有不可吸收故障原理上可检，可吸收部分是显式盲区。

**定义 296（持久激励）** 探针集覆盖多工作点，使 `(c,φ) ↦ {O_{c,φ}(u^(k))}` 局部单射；`rank(J_U) ≥ d_c+d_φ ∧ σ_min>0`。

**定义 297–298（GAT + NCT）** 逐探针拟合 `ĉ_k`；`Δ_c = max d_G(ĉ_k,ĉ_l)`，`δ* = min_c max_k 残差`；`v_C=FAULT ⇔ δ*>τ_δ ∨ Δ_c>τ_Δ`。判据跨工作点、不跨时间，故与 τ_φ 无关。

**定义 299（CMP）** `U* = argmax [ min_φ δ*(U;φ) − λ_b·Cost(U) ]`，包络内 D-optimal 贪心，标称抓取热启动。

**定义 300（PBC）** 可采纳 ⇔ 力/应力/能量/时长/温升全部达标；并前馈预测 `c_self`。

**定义 301（CSK）** 认证 MCU/锁步核，独立时钟/电源域；≥1kHz 采集 + 硬件时间戳 + 包络 + 定点 NCT；`W_CSK ≤ D_CSK`；可独立 SAFE_STOP；G 与阈值编译进镜像并哈希。

**定义 302（HRA）** 接触 OK/视觉 OK → 正常；接触 FAULT → λ≥0.9、k≤k_safe，无视视觉；接触 OK/视觉 FAULT → λ≥0.8、k 收缩；接触 UNAVAIL → SAFE_STOP。接触优先。

**定义 303（DGR）** WCET/看门狗/掉电/锁步/NCT 超时 → 冻结 COF、停探针、λ≥0.8、k≤k_safe、记 ℰ_embed；禁止使用年龄 > T_fresh 的标定。

**定义 304（GPC）** 抓取结局 ℓ_g 为免费物理标签；成功率下降而 NCT OK ⇒ 故障在未激励子空间 ⇒ 扩探针或 SAFE_STOP。

**定义 305（热-探针耦合）** `c_self` 与已知 u 相关 ⇒ 可辨识，前馈扣除；残余 `ε_thermal` 并入 R_cal。

**定义 309–310（可辨识性/实时预算）** 秩条件 + `σ_0>0` ⇒ 局部可辨识，且 `δ* ≥ σ_0·dist(f_φ,G·f_0) − η`；`W_total = W_CSK+W_link+W_app ≤ D_control`，`W_CSK ≤ 0.3ms`，探针开销 ≤15% 时长 / ≤5% 能量。

```python
class ContactMetrologyProbe:

def gauge_fit_and_test(ys, us, f0, G):

    delta_c = max(gauge_dist(a, b) for a in c_hat for b in c_hat)
    delta_star = min_over_gauge(lambda c: max_k(residual(ys[k], T(c, f0(us[k])))), G)
    return delta_c, delta_star

    def probe_cycle(self, U):

            self.actuate(u); ys.append(self.ring.window())

    if v_C == 'FAULT':   return 'STOP',      max(lam_ras, 0.9), min(k, K_SAFE)
    if v_M == 'FAULT':   return 'CAUTION',   max(lam_ras, 0.8), min(k, K_SAFE)
    return 'NORMAL', lam_ras, k

# IP-263 主闭环：PACE-RAS round
def PACE_RAS_round(M, obs, nominal_grasp):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)      # R68
    c, Ucal, thr = M.cof.step(o['cal'], residuals(...), sigma_stat(M))
    U = M.cmp.design(M.object_state, nominal_grasp, M.pbc.budget)
    if not M.pbc.admit(U): U = passive_fallback(nominal_grasp)
    dc, ds = M.csk.probe_cycle(U)                               # 硬实时
    v_C = 'FAULT' if (ds > TAU_D or dc > TAU_DC) else 'OK'
    v_M = M.cfa.verdict(o['pi'], c, Ucal)                       # 视觉-模型通道
    mode, lam, k = arbitrate(v_C, v_M, M.efs.risk_scale(...), k_ras)
    if M.dgr.missed_deadline():
        c = M.cof.freeze(); lam = max(lam, 0.8); k = min(k, K_SAFE); mode = 'DEGRADED'
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.gpc.record_grasp_outcome(mode, dc, ds)
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)      # R68
    return tau, (c, dc, ds, v_C, v_M, mode)
```

## 4. 推导

**引理 16（慢故障结构可辨识性——直击 R68 最大风险）** 非规范可吸收故障（dist ≥ ε）在持久激励探针集（σ_min(J_U)=σ_0>0）下满足 `δ* ≥ σ_0·ε − η`，式中**不含 τ_φ**。故 τ_φ→∞ 的慢故障检出裕度与快故障相同——标定只能吸收规范轨道内的分量，R68「标定越强、慢故障越隐形」被结构性打破。

**引理 17（NCT 虚警与一致性）** 纯漂移下 `E[Δ_c] ≤ 2η/σ_0`，虚警 ≤ α_NCT；不可吸收故障下 `Δ_c ≥ 2σ_0·ε − η`。可分裕度随探针多样性 σ_0 与故障幅度 ε 增大。

**引理 18（探针安全与自漂移）** 包络按构造保证损伤概率 ≤ δ_grasp、人体受力 ≤ F_max；自致热漂移 `c_self` 是已知日程的泛函，前馈后残余 `ε_thermal = O(ΔT·α)`；因与已知 u 相关，统计上不会被误判为未知故障。

**引理 19（嵌入式时限与降级）** `W_CSK ≤ D_CSK` 且看门狗覆盖 ≥1−p_wd ⇒ 时限/掉电/锁步异常在一个控制周期内被检出，DGR 强制 λ≥0.8、k≤k_safe、标定冻结；「用陈旧计量动作」概率 ≤ p_wd。系：嵌入式故障只使系统更保守。

**定理 16（端到端风险一致性）** A87–A94 + A95（G 完备）+ A96（包络模型正确）下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_grasp+α_embed+α_nct`；
2. `τ_φ ≥ τ_thermal` 的不可吸收故障检出率 ≥ 1−β（引理 16），闭合 R68 残余风险；
3. 嵌入式故障/时限超时 ⇒ λ≥0.8 ∧ k 收缩 ∧ 标定冻结（单调保守）；
4. 接触 FAULT 覆盖视觉 OK（物理地面真值优先）。

**定理 17（异质冗余安全性）** `P(both) = p_C p_M + ρ_CM√(p_C(1−p_C)p_M(1−p_M))`；ρ_CM≈0 ⇒ ≈ p_C p_M，严格低于任一单通道；同质双份 ρ_CM≈1 几无增益。接触-视觉物理异质是收益来源。

## 7. 本轮最大风险

**一句话**：PACE-RAS 把安全性押在「规范群 G 的完备性 + 探针本身不制造故障」上——**主动激励与故障源共用同一个物理执行器**：探针既能暴露磨损，也会加速磨损、产生热漂移并可能损伤脆弱物体；而若真实故障近似落在 G 的轨道内（例如整体刚度/尺度漂移伪装成标定缩放），NCT 会结构性失明——检测能力与制造故障的能力，是同一个抓取动作。

**次级风险与缓解**：规范群误设/不完备 → G 版本化 + known_blind + E300 公开边界；探针加速磨损 → PBC 磨损预算 + 日程轮换 + 维护周期联动；热-探针正反馈 → 前馈补偿 + 温升硬上限 + 冷却期；嵌入式认证成本 → CSK 只做小规模定点 NCT、G 编译期固定、学习留应用处理器；接触通道自身故障 → 视觉交叉校验 + 锁步自检 + 看门狗，双通道异常才 SAFE_STOP。
