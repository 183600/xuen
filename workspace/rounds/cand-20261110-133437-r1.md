# 第 44 轮（新循环第 4 轮） · Pose-Cert × Active-Disambiguation：把「6D 位姿估计」从感知点估计提升为可验证证书源（对称商空间 + 位姿模糊集 + 主动消歧证书）（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把「人」和「并发」纳入证书闭环，但整条证书栈仍压着一个从未被审计的前置假设：**(H0) 物体的 6D 位姿是一个已知的、唯一的点**。IP-49 几何证书、IP-51 CAR 守卫、CBF 规划的 margin 全部以某次位姿估计吐出的单点 T̂ 为输入。本轮灵感词「6D位姿估计」精确命中这个假设：真实 6D 位姿的误差不是高斯小噪声，而是**多峰、对称等价、随遮挡/反光/新视角漂移**的集合。把一个点当真值算 clearance，等于用「虚假精度」换「静默不 sound」。本轮把位姿从感知前端提升为一等证书源：**对称商空间**（消掉不可辨识自由度）+ **共形位姿集**（诚实表达不确定性）+ **持证主动消歧**（观测动作自身也纳入证书、以证书增益而非位姿误差为目标）。灵感词「创新点」用于对照现有 6D 位姿/主动感知文献，锚定四条可主张的新颖性。四层架构由 v8 升级为 v9：「仿真-检索-边缘飞轮 + 人格契约 + 并发证书 + 位姿证书源」。

## 0. 直觉与动机

**灵感 1（6D 位姿 → 位姿不是点，是「集合 + 对称商」）**：一个瓶子绕自身轴转 90° 看起来一模一样，估计器输出的两个 pose 在物体坐标系里是同一等价类；ADD/ADD-S 指标早就知道这一点，但我们的证书栈不知道——它把 T̂ 当点用。于是出现两类静默错误：**(a) 对称抖动被误判为真实运动**，污染跟踪与租约；**(b) 遮挡时估计落到错误模态**，而 clearance 只对那一个模态 sound，对真实位姿不 sound。第一刀：把位姿状态从 SE(3) 换成商空间 P = SE(3)/G_obj（G_obj 为物体模型的对称群），证书只在 P 上定义；任何下游谓词必须 G-不变，否则它承载的是「假精度」。

**灵感 2（不确定性 → 共形位姿集，而非高斯）**：位姿误差多峰、非欧、异方差，高斯/拉普拉斯假设不成立。用共形预测构造 S = {T̄∈P : s(T,obs) ≤ q_α}，s 取 **G-不变残差**（对称感知渲染/重投影误差 + 深度几何一致性）。可交换性下 P(T̄_true∈S) ≥ 1−α。关键在于证书 margin 用 **inf_{T∈S} m_φ(T)**（位姿鲁棒 margin），而不是 m_φ(T̂)。S 大时更保守（可用性下降），但绝不把「估计器猜错」翻译成「安全证书错误」。多峰时 S 允许不连通，不做单峰近似。

**灵感 3（主动消歧 → 观测也是动作，必须持证；目标是证书增益）**：当 inf-margin 低于阈值，与其保守停手，不如主动去看：移动相机/机械臂换取新视角缩小 S。但观测动作会改变场景、可能碰撞、可能把物体碰倒——所以观测动作必须自己先过安全证书 C_o。更关键的是优化目标不是「位姿误差最小」（经典 NBV/信息增益），而是 **证书增益 Δm = m_φ(S') − m_φ(S)**：有些视角大幅降位姿误差却对 clearance 毫无帮助，有些视角只需微动就能把证书从不可行变可行。这把主动感知从「估计问题」重写成「证书问题」，也避免「为了看清楚而撞上去」。

**灵感 4（耦合 → 位姿源成为证书栈的第六个源）**：与 v20 的租约/并发耦合——位姿有新鲜度（物体运动 → λ_pose），并发下多个任务共享同一 pose set，需要与证书租约一致的原子快照；与人格契约耦合——不同用户/任务对同一物体的操作（如「轻拿」「禁碰」）会改变下游谓词 φ 对位姿的敏感度与阈值。

**创新点定位（对照文献）**：
- **vs 经典 6D 位姿（PoseCNN/PVNet/FoundationPose 等）**：它们优化位姿精度与对称感知指标；我们把输出重定义为**带覆盖保证的位姿证书集**，并给出到安全证书的可靠性传递（inf-margin）。
- **vs 共形预测用于位姿**：多数只在欧氏/单峰上做误差条；我们做**商空间 G-不变共形 + 多峰集合表示 + 与下游证书的 inf-margin 传递**，并显式审计「假对称」。
- **vs 主动感知/NBV（信息增益、位姿熵）**：目标换成**证书增益 Δm**，且观测动作**本身持证**（安全主动感知）。
- **vs 安全控制证书（CBF/不变集）**：它们假设状态已知或误差有界；我们把感知不确定性以**集合形式端到端**传入证书并保持 soundness。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（物体位姿证书与对称商空间）**：物体模型 M，对称群 G = {g∈SE(3) : g·M ≅ M}（含连续旋转对称与离散翻转）。位姿状态空间 **P = SE(3)/G**。位姿证书是 P 的可测子集 S，配覆盖保证 P(T̄_true ∈ S) ≥ 1−α，T̄ 为商空间等价类。G-不变度量 d_G(T_1,T_2) = min_{g∈G} d_SE3(T_1, T_2 g)。**注**：G 需由 CAD/网格自动识别并与真值标定核对；G 识别错误是新的 soundness 风险（见定义 49）。

**定义 45（位姿鲁棒证书与 inf-margin 传递）**：下游谓词 φ（抓取可行性、碰撞间隙、可放置性）在 S 上**位姿鲁棒**当且仅当 ∀T∈S, φ(T) 成立。定义 **m_φ(S) = inf_{T∈S} m_φ(T)**。**传递引理**：若 S 覆盖真实位姿且 m_φ 对 T 连续（Lipschitz L_φ），则 m_φ(S) ≤ m_φ(T_true)；因此以 m_φ(S) ≥ θ 放行是 sound 的（失败只损失可用性）。**对照**：以 m_φ(T̂) 守卫可能在 T̂ 落错模态时**高估**真实 margin，产生静默违例。

**定义 46（G-不变共形位姿集）**：分数 s(T, obs) 为 G-不变残差（对称感知渲染/重投影误差 + 深度一致性 + 时序平滑残差）。校准集上取 q_α 为 ⌈(n+1)(1−α)⌉/n 分位；S = {T̄∈P : s(T,obs) ≤ q_α}。可交换性下边际覆盖 ≥ 1−α。**多峰**：S 允许不连通，不对其做单峰近似。**漂移**：新物体/新视角造成协变量偏移时用加权/在线共形，并维护对象级覆盖监控；覆盖失效则 S 退化为**保守先验可达集**（sound 但可用性差）。

**定义 47（持证主动消歧）**：观测动作 o∈O，其自身执行须满足安全证书 C_o（C_o sound 且在当前 S 下可执行）。观测后位姿集更新 S' = Update(S, o, y)。**证书增益** Δm(o) = m_φ(S') − m_φ(S)。**消歧问题**：o* = argmax_{o : C_o sound ∧ cost(o)≤B} Δm(o)。**定理（消歧保持 soundness）**：若每个中间动作单独持证，且每次更新后的 S' 仍满足覆盖（或退化为保守集），则消歧序列不降低 soundness，只降低保守性。**特例**：若最优 Δm ≤ 0（没有视角能提升证书），则不做无谓观测，直接协商/换策略/请求人工。

**定义 48（位姿租约与对象运动衰减）**：位姿结论附租约 ℓ_pose = (m_φ(S), τ, λ_pose, κ)，λ_pose = L_φ · v_obj_max（对象最大速度，可由跟踪/接触状态估计）。沿用定义 41 的新鲜度判据。**静态支路**：在桌面/已夹持且接触约束成立时 v_obj_max≈0，租约可长；**动态支路**：自由/被推动物体用短租约，过期即重估或降级。**命题**：λ_pose 由对象运动界出时，过期判据对「物体已移动导致 pose set 陈旧」sound。

**定义 49（对称/等变审计与假对称）**：下游证书函数 f 的 G-等变性要求 f(T g) = f(T) ∀g∈G。若实际只有近似对称 G_ε（最大形状偏差 ε），则对称违反量 δ_f = sup_{g∈G_ε, T} |f(Tg) − f(T)|，必须计入 margin：**m_φ^{audit}(S) = m_φ(S) − δ_f**。**审计**：用网格/渲染采样检测「声称对称但下游谓词不对称」（瓶盖螺纹、贴纸、把手——形状近似对称但抓取/语义不对称），把假对称从静默风险变成可量化惩罚。**注**：对称商越强，位姿证书越紧；但若对称是假的，商掉的正是区分「能不能抓」的自由度。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 SPC：SYMMETRY-POSE-CERT（对称位姿证书源）
1. **对称群识别**：从 CAD/网格 + 标定数据估计 G，输出 G 的近似度 ε；G 不确定时自动降级为 G=∅（不商化，保守）。
2. **G-不变共形位姿集**：多峰集合表示（占据网格/粒子/高斯混合 + 覆盖校验），在线覆盖监控与漂移检测。
3. **inf-margin 证书接口**：向 IP-49/51 输出 m_φ(S) 及 S 的紧凑摘要（用于并发快照）。
4. **位姿租约签发**：按对象运动状态给 λ_pose，接入 IP-58 租约表。

### 2.2 IP-61 ADP：ACTIVE-DISAMBIGUATION-PLANNER（持证主动消歧）
1. **证书增益估计**：对候选视角/微动估计 Δm(o) 及其**保守下界**（严禁乐观估计）。
2. **观测动作持证**：观测轨迹先过 C_o（碰撞/稳定性/可达），不可行则不观测。
3. **预算与停止**：cost 预算 + Δm≤0 停止 + 回退协商；与 IP-58 混合关键级一致（过载时不做投机观测）。
4. **NBV 对照**：记录「位姿误差降」与「证书增益」的错位率，作为新指标。

### 2.3 IP-62 PCV：POSE-CONSISTENCY-VALIDATOR（位姿一致性验证器）
1. **多视角一致性**：跨视角/跨时刻 S 的交集与冲突检测（冲突 = 覆盖失效或假对称信号）。
2. **等变审计**：对下游 f 采样检测 δ_f；维护对象级「对称可信度」。
3. **对抗位姿注入**：对称翻转、遮挡、反光、位姿跳变、投毒观测。
4. **与 ICV 联动**：位姿歧义 × 调度交错的组合压力测试。

## 5. 本轮最大风险

**一句话**：对称商与共形覆盖共享同一个脆弱前提——**交换性与对称群都只是近似成立**；一旦物体只是「近似对称」（有把手/螺纹/贴纸）或分布漂移（新物体、新视角），把 G 商掉会商掉真正的可行性自由度、把不可交换数据当成可交换，二者叠加会产出「覆盖看起来达标、certificate 却系统性高估 margin」的静默失效——因此 E95（条件覆盖）与 E97（假对称审计）必须设为红线，且默认回退到 G=∅ + 保守先验可达集这条永不失 sound 的底线。

## 2. 关键算法（伪代码）

### IP-60 SPC：对称识别、G-不变共形集与 inf-margin
```
def identify_symmetry_group(mesh, calib, eps_budget):
    G, eps = symmetry_solver(mesh, calib)          # 连续/离散对称 + 近似度
    if eps > eps_budget or not verified(G, calib):
        return SymGroup.trivial(eps=0.0)           # G=∅：不商化，保守
    return SymGroup(G, eps)

def pose_score_invariant(T, obs, G):
    # G-不变：对群元素取最小残差，避免对称抖动污染
    return min(render_residual(T * g, obs) + depth_consistency(T * g, obs)
               for g in sample(G))

def conformal_pose_set(obs, calib_scores, alpha, G):
    n = len(calib_scores)
    q = quantile(calib_scores, ceil((n + 1) * (1 - alpha)) / n)   # 秩统计
    return PoseSet([Tbar for Tbar in quotient(SE3, G)
                    if pose_score_invariant(Tbar, obs, G) <= q])  # 允许多峰/不连通

def pose_robust_margin(S, phi, G, delta_f):
    reps = sample_representatives(S, G)            # 代表姿态（覆盖式采样）
    return inf(phi.margin(T) for T in reps) - delta_f   # 假对称惩罚

def issue_pose_lease(S, phi, v_obj_max, kappa):
    m = pose_robust_margin(S, phi, phi.G, phi.delta_f)
    return Lease(m=m, tau=monotonic_now(), lam=phi.L * v_obj_max, kappa=kappa)
```

### IP-61 ADP：持证主动消歧（以证书增益为目标）
```
def certified_active_disambiguation(S, phi, budget):
    best = None
    for o in candidate_views(S):
        C_o = certify_observation(o, S)            # 观测动作自身持证（碰撞/稳定/可达）
        if not C_o.sound:
            continue
        S2 = predict_pose_set_conservative(S, o)    # 保守预测，不乐观
        gain = pose_robust_margin(S2, phi, phi.G, phi.delta_f) \
             - pose_robust_margin(S, phi, phi.G, phi.delta_f)
        if gain > 0 and (best is None or gain - cost(o) > best.score):
            best = Candidate(o, gain, C_o)
    if best is None or best.gain <= 0:
        return negotiate_or_conservative_strategy()   # Δm<=0：不做无谓观测
    execute_certified(best.o)                      # 执行后 S = Update(S, o, y)
    return best

def certify_observation(o, S):
    # 观测轨迹必须复用 IP-49 几何证书与 IP-58 租约，含位姿集 S 的碰撞检查
    traj = observation_trajectory(o)
    return geometric_certify(traj, S, margin=pose_robust_margin(S, phi, S.G, S.delta_f))
```

### IP-62 PCV：等变审计、多视角与时序一致性
```
def equivariance_audit(f, G, grid, delta_budget):
    delta_f = max(abs(f(T * g) - f(T))
                  for T in grid for g in sample(G))
    if delta_f > delta_budget:
        flag_false_symmetry(G, delta_f)            # 降级 G 或计入 margin 惩罚
    return delta_f

def cross_view_consistency(S_list):
    inter = intersect_all(S_list)
    if inter.empty():
        return CoverageFailure("inconsistent_or_false_symmetry")
    return inter                                   # 交集用于收紧位姿集

def temporal_conflict(S_prev, S_now, v_obj_max, dt):
    # 位姿跳变检测：S_now 不应逃出上一位姿集的运动膨胀
    return not S_now.issubset(dilate(S_prev, v_obj_max * dt))
```

### IP-51/52/53 升级：位姿集感知的守卫与证书栈
```
def car_transition_guard(e, x, cert_obj, persona, lease, S, t):
    theta   = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_cap    = persona_cap[e](persona)             # 人格契约只做上限收缩
    m_pose   = pose_robust_margin(S, phi_e, S.G, S.delta_f)
    return min(m_lookup, m_lease, m_cap, m_pose) >= theta and lease_valid(lease, theta, t)

def certify_light_v4(x, guards, persona, S, budget_us, criticality):
    b = cert_lookup_L0(x)                          # 键含 object_id + symmetry class
    lease = issue_pose_lease(S, phi, v_obj_max(x), criticality)
    U = undecided_guards(b, guards)
    if not U and lease_valid(lease, theta, monotonic_now()):
        return b, lease, -1
    if budget_us < 110 or criticality < K_GEOMETRY:
        return downgrade_monotone(b), lease, -1
    # 渲染式位姿监控：在代表姿态上采样，取最坏 margin
    status, margin = render_monitor_INT8(quantize_obs(x), sample_representatives(S, S.G))
    b.m_lo = min(b.m_lo, margin - S.delta_f)
    U = undecided_guards(b, guards)
    return (b, lease, 0) if not U else (downgrade_monotone(b), lease, 0)
```

## 6. 本轮最大风险

**一句话**：对称商与共形覆盖共享同一个脆弱前提——**交换性与对称群都只是近似成立**；一旦物体只是「近似对称」（有把手/螺纹/贴纸）或分布漂移（新物体、新视角），把 G 商掉会商掉真正的可行性自由度、把不可交换数据当成可交换，二者叠加会产出「覆盖看起来达标、certificate 却系统性高估 margin」的静默失效——因此 E95（条件覆盖）与 E97（假对称审计）必须设为红线，且默认回退到 G=∅ + 保守先验可达集这条永不失 sound 的底线。
