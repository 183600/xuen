### 第 1 轮灵感驱动研究记录

**灵感词**：UniBot、智能体

**直觉与动机**：

前序 v26 证书链（SRC-USC + CACB/TCM/HSC）本质上是一个**静态准入模型**：在计划执行前，对一组已给定的多机轨迹逐项验证七/九/十证书。然而「UniBot」与「智能体」揭示了这一范式的根本错配——

- **UniBot** 指向「统一机器人基础模型 / 跨具身通用体」：一个模型同时驱动机械臂、四足、人形、移动操作平台，感知-语言-动作（VLA）共享表征。其危险不在于单个动作，而在于**证书无法跨具身迁移**：在 A 具身上验证通过的能量/力/语义/协同证书，换到 B 具身后其物理含义、量纲与安全边界全部失效。
- **智能体** 指向「感知-推理-行动-反思-记忆」的闭环自治体：它在线生成计划、组合技能、调用工具、根据反馈修订策略。其计划**在执行前并不存在**，因此「事前准入」无法覆盖它——智能体既是证书的**生产者**（生成计划）又是**消费者**（依赖证书），还是一个会**改变自身**的开放系统。

核心洞见：**UniBot = 跨具身证书编译器（把异构具身编译到统一证书代数）；智能体 = 证书的在线生成-消费闭环；安全 = 假设-保证契约的运行时维持，而非一次性准入**。证书必须从「静态准入门」升级为「可组合契约 + 运行时盾」。

**形式化目标**：

1. **跨具身证书接口（CECI）**：定义具身范畴 Emb 到证书代数 CertAlg 的函子 F，给出证书沿具身态射迁移的自然变换 η 与迁移间隙 δ_emb 的保守界；证明若源具身证书裕度 ≥ L·δ_emb，则目标具身证书成立。
2. **技能组合证书（SCC）**：技能 σ_i 携带契约 (Pre_i, Post_i, Inv_i, Cost_i, ε_i)；证明组合闭合性（Hoare 式望远镜引理）与长程误差预算 Σε_i ≤ α_total；引入**可生存核（viability kernel）V**，要求每个技能的后置集 Post_i ⊆ V，保证任意时刻存在已认证的恢复技能。
3. **工具调用契约证书（TCC）**：工具 τ 携带能力契约 (Pre_τ, Post_τ, Eff_τ, W_τ, Trust_τ)，效应含 δ_eff 的 conformal 界与**局部性/框架公理**（副作用限于读写集 W_τ）；对不可信工具施加能力衰减沙箱。
4. **策略修订与记忆证书（PRMC）**：反思导致的策略更新 π→π' 需满足行为信赖域 D(π,π') ≤ δ_rev 且不破坏可生存核；长期记忆检索需满足**时序有效性**谓词 Fresh(m,t)，防止陈旧记忆诱导不安全计划。
5. **运行时证书盾（RCS）**：把每条证书编译为控制屏障函数（CBF）/控制不变集，在线 QP 过滤智能体动作：若 QP 可行则安全集前向不变；若不可行则触发可生存核内的恢复技能或安全停机。给出「证书-盾对偶」：证书是谓词，盾是保持谓词的执行策略。
6. **统一智能体准入门（UAG）**：Exec_v27 = Exec_v26 ∩ Fil_emb ∩ Fil_comp ∩ Fil_tool ∩ Fil_rev，且 Exec_v27 受 RCS 运行时监控；证明 Runtime_v27 ⊆ Runtime_v26 ⊆ … 的运行时单调退化链。

**与既有框架的衔接**：v26 的 SRC-USC 仍作为 UAG 的「计划级底座」——UAG 不替代它，而是在其之上加一层「策略级契约 + 运行时强制」。CECI 把 SOC/FCC/LSC/SMC/RMC/MCC 的物理量投影到统一规范空间；SCC/TCC 负责长程组合；RCS 负责把静态证书转成每个控制周期都能执行的约束。

**本轮最大风险（一句话）**：RCS 的运行时保证完全依赖屏障函数所用的动力学/感知模型，UniBot 在开放世界中的模型-现实失配会使盾在 OOD 状态下把不安全动作误判为安全，使「事中保证」退化为「事中误判」。

```python
# ============================================================
# IP-451 Sensor Calibration Certificate (SCC) — 传感器标定证书
# ============================================================
@dataclass
class SensorCalibrationCertificate:
    """标定点估计 + 可辨识性 + 概率误差椭球 + 在线漂移检测"""
    theta_hat: dict                       # {intrinsics, extrinsics, time_offsets}
    Sigma_theta: Tensor                   # [d, d] 标定后验协方差
    eps_rep: float = 1e-3                # 归一化残差阈值
    kappa_max: float = 1e3               # 条件数上界
    alpha_cal: float = 0.05              # 标定风险水平
    drift_stat: float = 0.0              # CUSUM 统计量 g_t
    drift_threshold: float = 5.0         # 告警阈值 h
    nu: float = 0.01                     # 漂移容忍量 ν
    estimated: bool = False

    def verify_reprojection(self, observations, model) -> bool:
        """ρ_rep = (1/M) rᵀΣ_z⁻¹r ≤ ε_rep"""
        r = model.residual(self.theta_hat, observations)        # [M]
        Sigma_z = model.noise_cov(observations)                 # [M, M]
        rho = float(r @ torch.linalg.solve(Sigma_z, r)) / len(r)
        return rho <= self.eps_rep

    def verify_identifiability(self, observations, model) -> bool:
        """rank(J)=d ∧ κ(H) ≤ κ_max，保证标定解唯一且数值稳定"""
        J = model.jacobian(self.theta_hat, observations)        # [M, d]
        Sigma_z = model.noise_cov(observations)
        H = J.T @ torch.linalg.solve(Sigma_z, J)                # Fisher 信息
        d = H.shape[0]
        if torch.linalg.matrix_rank(H) < d:
            return False
        return float(torch.linalg.cond(H)) <= self.kappa_max

    def verify_error_ellipsoid(self) -> bool:
        """Cramér-Rao 界：Σ_θ ⪰ H⁻¹ ⇒ ‖θ̂-θ*‖²_{Σ_θ⁻¹} ≤ χ²_{d,1-α_cal}"""
        d = self.Sigma_theta.shape[0]
        # 证书只在 Σ_θ 由 Fisher 信息下界合法构造时成立
        return bool(torch.all(torch.linalg.eigvalsh(self.Sigma_theta) > 0)) and \
            self._ellipsoid_radius() <= self._chi2_quantile(d, 1 - self.alpha_cal)

    def update_drift(self, e_cal: float) -> None:
        """CUSUM：g_t = max(0, g_{t-1} + e_cal - ν)"""
        self.drift_stat = max(0.0, self.drift_stat + e_cal - self.nu)

    def verify_drift(self) -> bool:
        """超过阈值即拒绝证书，冻结所有依赖该外参的下游证书"""
        return self.drift_stat <= self.drift_threshold

    def verify_all(self, observations, model) -> bool:
        self.estimated = (self.verify_reprojection(observations, model) and
                          self.verify_identifiability(observations, model) and
                          self.verify_error_ellipsoid() and
                          self.verify_drift())
        return self.estimated

    def _ellipsoid_radius(self) -> float:
        return float(torch.sqrt(torch.trace(self.Sigma_theta)))

    @staticmethod
    def _chi2_quantile(d: int, p: float) -> float:
        # 由 scipy.stats.chi2.ppf(p, d) 离线预计算并缓存
        from scipy.stats import chi2
        return float(chi2.ppf(p, d))

# IP-452 VLA Action Grounding Certificate (VAGC) — VLA 动作接地证书
# ============================================================
@dataclass
class VLAActionGroundingCertificate:
    """Conformal 动作集 + 跨模态对齐 + 动作时序一致性 + 语言蕴含"""
    policy: 'VLAPolicy'
    calibrator: 'ConformalCalibrator'     # 离线校准集 (o,ℓ,a*) 的分数分布
    alpha_vla: float = 0.05
    eps_align: float = 0.10               # 跨模态对齐容差
    delta_act: float = 0.5                # 单步动作变差上界
    horizon: int = 8
    verifier: 'LanguageActionVerifier' = None

    def conformal_action_set(self, obs, instruction) -> tuple[list, float]:
        """返回候选动作集与校准分位数 q_{1-α_vla}"""
        scores = self.calibrator.calibration_scores()          # 离线分数
        q = torch.quantile(scores, 1 - self.alpha_vla).item()
        candidates = self.policy.candidate_actions(obs, instruction)
        return candidates, q

    def verify_grounding_coverage(self, obs, instruction, gt_action) -> bool:
        """ℙ(a* ∈ C_{α_vla}) ≥ 1-α_vla：GT 动作的分数不超过分位数"""
        _, q = self.conformal_action_set(obs, instruction)
        score = self.policy.nonconformity(gt_action, obs, instruction)
        return float(score) <= q

    def verify_cross_modal_alignment(self, obs, instruction) -> bool:
        """d_align = 1 - cos(φ_v(o), φ_l(ℓ)) ≤ ε_align"""
        phi_v = self.policy.encode_vision(obs)
        phi_l = self.policy.encode_language(instruction)
        d = 1.0 - torch.dot(phi_v, phi_l) / (phi_v.norm() * phi_l.norm() + 1e-8)
        return float(d) <= self.eps_align

    def verify_action_temporal_consistency(self, action_seq: Tensor) -> bool:
        """TV(a_{t:t+H}) = Σ‖a_{t+1}-a_t‖ ≤ δ_act·(H-1)"""
        if len(action_seq) < 2:
            return True
        tv = sum(float(torch.norm(action_seq[t+1] - action_seq[t]))
                 for t in range(len(action_seq) - 1))
        return tv <= self.delta_act * (len(action_seq) - 1)

    def verify_language_entailment(self, action, instruction) -> bool:
        """V(a,ℓ)=1：用轻量 VLM 判别器校验动作是否执行了指令"""
        if self.verifier is None:
            return False
        return bool(self.verifier.entails(action, instruction))

    def verify_all(self, obs, instruction, gt_action,
                   action_seq: Tensor) -> bool:
        return (self.verify_grounding_coverage(obs, instruction, gt_action) and
                self.verify_cross_modal_alignment(obs, instruction) and
                self.verify_action_temporal_consistency(action_seq) and
                self.verify_language_entailment(action_seq[0], instruction))

# IP-453 Calibration-Aware Cross-Modal Certificate (CACC) — 标定感知跨模态证书
# ============================================================
@dataclass
class CalibrationAwareCrossModalCertificate:
    """把 Σ_θ 传播到 Σ_x，并用 Lipschitz 膨胀 conformal 分位数，给出端到端预算"""
    scc: SensorCalibrationCertificate
    vagc: VLAActionGroundingCertificate
    eps_cross: float = 0.02               # 语义-几何区域 Hausdorff 容差
    alpha_total: float = 0.10             # 端到端风险预算
    lip_score: float = 1.0                # L：非一致性分数对观测的 Lipschitz 常数
    lip_obs: float = 1.0                  # L_θ：观测对 θ 的 Lipschitz 常数

    def propagate_uncertainty(self, pixel, depth, model) -> Tensor:
        """Σ_x = J_θ Σ_θ J_θᵀ + J_z Σ_z J_zᵀ"""
        J_theta = model.jacobian_wrt_calib(pixel, depth, self.scc.theta_hat)
        J_z = model.jacobian_wrt_obs(pixel, depth, self.scc.theta_hat)
        Sigma_z = model.noise_cov(pixel, depth)
        return J_theta @ self.scc.Sigma_theta @ J_theta.T + J_z @ Sigma_z @ J_z.T

    def inflated_quantile(self, q: float) -> float:
        """稳健 conformal：q' = q + L·L_θ·ε_θ，吸收标定误差"""
        eps_theta = float(torch.sqrt(torch.trace(self.scc.Sigma_theta)))
        return q + self.lip_score * self.lip_obs * eps_theta

    def verify_robust_coverage(self, obs, instruction, gt_action) -> bool:
        """标定扰动下的覆盖：score ≤ q'（由引理 17 保证）"""
        _, q = self.vagc.conformal_action_set(obs, instruction)
        score = self.vagc.policy.nonconformity(gt_action, obs, instruction)
        return float(score) <= self.inflated_quantile(q)

    def verify_cross_modal_consistency(self, vla_region, geo_region) -> bool:
        """语义/动作区域与几何重建区域的 Hausdorff 一致"""
        return hausdorff_distance(vla_region, geo_region) <= self.eps_cross

    def verify_end_to_end_budget(self) -> bool:
        """联合界：α_e2e = 1 - Π(1-α_i) ≤ α_total"""
        alphas = [self.scc.alpha_cal, self.vagc.alpha_vla]
        survive = 1.0
        for a in alphas:
            survive *= (1.0 - a)
        return (1.0 - survive) <= self.alpha_total

    def verify_all(self, obs, instruction, gt_action,
                   vla_region, geo_region) -> bool:
        return (self.verify_robust_coverage(obs, instruction, gt_action) and
                self.verify_cross_modal_consistency(vla_region, geo_region) and
                self.verify_end_to_end_budget())

# IP-454 VLA-Calib Unified Certificate (VCUC) — v27 统一准入门

@dataclass
class VLACalibUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v26 九证
    scc: SensorCalibrationCertificate
    vagc: VLAActionGroundingCertificate
    cacc: CalibrationAwareCrossModalCertificate

    def admits(self, plan, sensor_data: dict) -> bool:
        # (1) 继承 v26：USMC ∧ SMC ∧ RMC ∧ MCC ∧ CACB ∧ TCM ∧ HSC
        if not self.src_usc.admits(
            plan, sensor_data,
            gt_entities=sensor_data.get('gt_entities'),
            queries=sensor_data.get('queries'),
            retrieved=sensor_data.get('retrieved')
        ):
            return False

        # (2) IP-451 标定证书：残差/可辨识/椭球/漂移
        if not self.scc.verify_all(
            sensor_data['calib_observations'], sensor_data['calib_model']
        ):
            return False

        # (3) IP-452 VLA 接地证书
        if not self.vagc.verify_all(
            sensor_data['vla_obs'], sensor_data['instruction'],
            sensor_data['gt_action'], sensor_data['action_seq']
        ):
            return False

        # (4) IP-453 跨模态耦合证书（含标定-动作端到端预算）
        if not self.cacc.verify_all(
            sensor_data['vla_obs'], sensor_data['instruction'],
            sensor_data['gt_action'],
            sensor_data['vla_region'], sensor_data['geo_region']
        ):
            return False

        return True

        self.vcuc.scc.Sigma_theta = sensor_data.get('Sigma_theta', self.vcuc.scc.Sigma_theta)
        self.vcuc.scc.update_drift(sensor_data.get('e_cal', 0.0))

        # 3. VLA 推理 → 动作集 → 接地校验
        obs, instr = sensor_data['vla_obs'], sensor_data['instruction']
        action_seq = self.vcuc.vagc.policy.act_sequence(obs, instr)
        sensor_data['action_seq'] = action_seq

        # 4. 跨模态区域提取与一致性
        sensor_data['vla_region'] = self.vcuc.vagc.policy.predict_region(obs, instr)
        sensor_data['geo_region'] = sensor_data['geo_region']

        # 5. VCUC 统一准入
        plan = self._plan_from_consensus(sensor_data)
        admitted = self.vcuc.admits(plan, sensor_data)
        return admitted, {
            'v27_plan': plan if admitted else None,
            'calib': {
                'reproj_ok': self.vcuc.scc.verify_reprojection(
                    sensor_data['calib_observations'], sensor_data['calib_model']),
                'identifiable_ok': self.vcuc.scc.verify_identifiability(
                    sensor_data['calib_observations'], sensor_data['calib_model']),
                'drift_stat': self.vcuc.scc.drift_stat,
            },
            'vla': {
                'grounding_ok': self.vcuc.vagc.verify_grounding_coverage(
                    obs, instr, sensor_data['gt_action']),
                'align_ok': self.vcuc.vagc.verify_cross_modal_alignment(obs, instr),
                'tv_ok': self.vcuc.vagc.verify_action_temporal_consistency(action_seq),
            },
            'cross': {
                'robust_coverage_ok': self.vcuc.cacc.verify_robust_coverage(
                    obs, instr, sensor_data['gt_action']),
                'cross_modal_ok': self.vcuc.cacc.verify_cross_modal_consistency(
                    sensor_data['vla_region'], sensor_data['geo_region']),
                'budget_ok': self.vcuc.cacc.verify_end_to_end_budget(),
            }
        }
```

## 3. 正确性论证（v27 增量）

### 引理 16（标定证书的可辨识-残差-椭球三重保证）
**陈述**：若 `SCC.verify_all(obs, model) = True`，则在置信水平 1-α_cal 下，标定真值 θ* 落在以 θ̂ 为中心、由 Σ_θ 定义的椭球内，且所有依赖该外参的世界坐标误差被 Σ_x 的 3σ 包络控制。

**证明**：
1. `verify_reprojection` 将归一化残差约束在 ε_rep 内，排除粗差与错误对应；`verify_identifiability` 要求 Fisher 信息 H=JᵀΣ_z⁻¹J 满秩且 κ(H)≤κ_max，保证 θ̂ 在局部唯一且对噪声不病态敏感。
2. 在零均值有界噪声与满秩条件下，极大似然估计的误差满足 Cramér-Rao 下界 Σ_θ ⪰ H⁻¹；对高斯噪声，二次型 (θ̂-θ*)ᵀΣ_θ⁻¹(θ̂-θ*) 渐近服从 χ²_d，故 `verify_error_ellipsoid` 的椭球界以 1-α_cal 概率成立。
3. 世界坐标 x_w=T(θ)π⁻¹(u,d) 的一阶泰勒展开给出 Σ_x=J_θΣ_θJ_θᵀ+J_zΣ_zJ_zᵀ，由 (1)(2) 的 θ 误差界即可把点云/像素的度量不确定性传递到几何层。
∎

### 引理 17（标定扰动下的 VLA 接地覆盖保持）
**陈述**：若标定误差满足 ‖θ̂-θ*‖ ≤ ε_θ、观测映射对 θ 为 L_θ-Lipschitz、非一致性分数对观测为 L-Lipschitz，则使用膨胀分位数 q' = q_{1-α_vla} + L·L_θ·ε_θ 的 conformal 动作集满足 ℙ(a*∈C_{α_vla}') ≥ 1-α_vla。

**证明**：
1. 标定误差使真实观测 o* 与证书使用的观测 o 满足 ‖o*-o‖ ≤ L_θ‖θ̂-θ*‖ ≤ L_θε_θ。
2. 由分数 Lipschitz 性，|s(a*;o*,ℓ)-s(a*;o,ℓ)| ≤ L‖o*-o‖ ≤ L·L_θ·ε_θ。
3. 原 conformal 保证 s(a*;o,ℓ) ≤ q_{1-α_vla} 以概率 ≥1-α_vla 成立（校准集与测试集可交换）；叠加 (2) 得 s(a*;o*,ℓ) ≤ q_{1-α_vla}+L·L_θ·ε_θ = q'，故覆盖保持。
4. 注意这是**边际覆盖**：条件覆盖不被保证，需在实验中显式测量按指令类别的覆盖差异（见实验设计）。
∎

### 引理 18（跨模态耦合与端到端风险预算）
**陈述**：`CACC.verify_all(...) = True` ⇒ 在标定、接地、跨模态三个环节同时成立时，端到端失效概率 ≤ α_e2e = 1-Π(1-α_i) ≤ Σα_i ≤ α_total；且语义区域与几何区域在 ε_cross 内一致。

**证明**：
1. 设三个失效事件 E_cal、E_vla、E_cross 分别以概率 α_cal、α_vla、α_cross 发生；由联合界 ℙ(∪E_i) ≤ Σα_i，而 1-Π(1-α_i) ≤ Σα_i，故 `verify_end_to_end_budget` 直接给出总风险上界。
2. `verify_robust_coverage` 由引理 17 保证标定扰动不破坏接地覆盖；`verify_cross_modal_consistency` 用 Hausdorff 距离约束 VLA 预测的可操作区域与几何重建区域，二者一致才允许动作落地。
3. 三个条件分别对应「度量原点可信」「语义-动作翻译可信」「两模态空间对齐」，任一不满足即拒证，避免单一环节的置信度掩盖系统性偏移。
∎

### 引理 19（VLA-标定单调退化链）
**陈述**：对任意计划 π，`VCUC.admits(π)=True ⇒ Exec_v27 ⊆ Exec_v26 ⊆ Exec_v25 ⊆ …`，且三条新退化路径均可回退到明确的下层执行集。

**证明**：
- VCUC 的准入是 v26 九证与 SCC∧VAGC∧CACC 的连言，增加合取项只能缩小集合，故单调性直接成立。
- 标定漂移（g_t>h）：SCC 拒证 → 回退 v26，冻结依赖该外参的语义/碰撞证书，改用保守几何包络。
- VLA 幻觉（接地/对齐/蕴含失败）：VAGC 拒证 → 回退 v26，禁用语言指令通道，降级为预定义技能或遥操作。
- 跨模态错配（d_H>ε_cross 或预算超限）：CACC 拒证 → 回退 v26，语义目标仅作为建议、由几何规划兜底。
- 组合失效取交集，单调性保持。
∎

### 定理（VLA-标定统一准入门的安全-度量-接地-耦合完备性）
**陈述**：对任意多机-多模态计划 Π，`VCUC.admits(Π)=True` ⟺ Π 同时满足：
(1) v26 的九类条件（物理接地、云边一致、conformal 覆盖、专利保护、结构/力控/轻量化、语义/重构/协同、预算、记忆、可扩展），
(2) 标定残差/可辨识/误差椭球/漂移四重达标，
(3) VLA 动作覆盖/跨模态对齐/时序一致/语言蕴含四重达标，
(4) 标定-动作协方差传播、Lipschitz 膨胀覆盖与端到端预算三重达标。

**证明**：充分性由连言与引理 16–18 直接得到；必要性由任一条件缺失即对应一类未被缓解的风险（度量偏移、翻译错误、耦合放大）可知。结合引理 19，执行集随过滤器增加而单调收缩，构成从「度量原点」到「语义-动作落地」再到「群体协同」的完整闭环。
∎
