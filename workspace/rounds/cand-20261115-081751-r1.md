# 第 4 轮（新一轮灵感循环第 1 轮；承接第 3 轮 InstructGauge；本轮灵感：「UniBot-V1」×「仿真到现实」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**先验加速 + 间隙有界 + 严格退化**。UniBot-V1 只提供先验与候选，不签发任何证书；仿真的任何结论只有在「间隙证书」覆盖范围内才允许迁移到现实；任一环节不可用都必须一键退回纯现实路径。

## 0. 直觉与动机

**灵感 1（UniBot-V1 → 通才先验，而不是新的信任根）**
直觉：UniBot-V1 这类统一机器人基础模型的诱惑在于「零样本就会做很多事」——它把跨本体的技能、动作 token 与动力学先验压缩进一个黑箱。对盲区探测而言，这能极大降低冷启动成本：它可以直接告诉系统「这类盲区通常先侧扫再补光」。但危险也在这里：一旦让先验**授权动作**，信任根就从「可复核的测量回执」悄悄迁移到「一个分布可能已经偏移的黑箱」。因此正确的接口不是「UniBot→执行器」，而是「UniBot→先验/候选排序」：**先验提议，计量裁决**（prior proposes, metrology disposes）。UniBot 的输出必须经过本体适配器与能力闭包投影，才能进入规划；它永远不能写契约、不能改安全盾、不能签发校准阈值。

**灵感 2（仿真到现实 → 间隙是有结构的偏差，不是可平均掉的噪声）**
直觉：仿真最大的误区是把它当成「免费的现实」——在仿真里验证通过的策略/契约，被默认可以直接搬到现实。但 sim-to-real 间隙不是零均值噪声，而是带结构、随状态-动作区域变化的**偏差**；平均掉它恰恰会把最危险的局部偏差藏起来。安全的对象不是「平均误差小」，而是「在可达域上有一个高概率上界 γ，且安全裕度大于 γ」。所以仿真只能做**加速器**：它产生候选、预训练先验、扩大覆盖；但迁移许可必须由成对锚点估计出的**间隙证书**给出。域随机化给的是一个分布，不是一条保证；没有锚点，就没有迁移证书。

**灵感 3（三者耦合 → 先验置信度 × 间隙 × 块长，是一个必须被显式夹住的乘积）**
直觉：第 3 轮已经知道「指令越稳、漂移越小，块可以越长」。现在多了两个乘数：UniBot 先验越自信，规划器越敢选长块；sim-to-real 间隙越大，同样长的块在现实里累积的偏差越大。最危险的组合是：**一个自信的黑箱先验 + 一个被低估的间隙 + 一个长动作块**——它会把一次「看起来在仿真里很合理」的决策，放大成 K 步已经执行、且偏离现实的物理动作。解法不是禁用先验或仿真，而是把间隙显式塞进块长约束：`K·γ ≤ margin`，并保留不可逆屏障与 K=1 退化；同时给间隙证书加**有效时域**与**漂移检测**，一旦现实偏离锚点邻域就作废证书、退回纯现实路径。

## 1. 研究问题（本轮要回答什么）

- **Q1（先验的安全性）**：UniBot-V1 能否只作为「候选生成与排序的先验」，而不成为新的信任根、能力泄漏通道或幻觉执行入口？
- **Q2（迁移的可证性）**：一个在仿真中成立的契约/不变量，在什么条件下可以带着保证迁移到现实？最少需要多少成对锚点，间隙证书的覆盖与有效期如何量化？
- **Q3（三者的放大效应）**：先验置信度、sim-to-real 间隙与动作块长如何相乘？能否用「γ-鲁棒裕度 + 间隙条件化块长 + 漂移作废」把复合风险压回可界、并在不可逆处退化为单步？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P1 先验-现实分离（Prior–Reality Separation）**
UniBot-V1 只能输出「假设先验 / 动作候选 / 技能提议」，必须经过本体适配器 `E` 与能力闭包投影 `Proj_T` 才能进入规划；它没有写契约、改安全盾、签发校准阈值的权限。形式化方向：证书计划集 `Plan_cert ⊆ Plan_ToolGauge`，先验只改变后验的排序与采样效率，不改变可行域。这把「黑箱先验」降级为**可拒绝的建议**。

**P2 间隙有界迁移（Gap-Bounded Transfer / γ-鲁棒）**
任何从仿真迁移到现实的不变量，必须满足两个条件：存在一个高概率间隙上界 `γ_δ`，且仿真中的安全裕度在 γ-膨胀后仍非空（即 `Inv_γ = {x : B(x,γ) ⊆ Inv}` 非空且被保持）。直观：只有当「现实可能偏离仿真的最大幅度」小于「安全边界到危险区的距离」时，迁移才是可证的；否则不许迁移，而不是「小心一点地迁移」。

**P3 间隙条件化退化（Gap-Conditioned Degradation）**
间隙未估计、锚点不足、证书过期、漂移检测触发、或跨不可逆动作 ⇒ 一律不迁移：块长强制 `K=1`，退回纯现实路径（InstructGauge / ToolGauge / LeanGauge / MODGAUGE）。仿真与先验都是**增强项**，不是依赖项；任一证书环节失败，系统仍能靠现实回执安全运行，只是慢一些、样本多一点。

## 3. 与基线的接口（如何退化）

- UniBot 不可用 / 先验 KL 超预算 / 本体适配失败 ⇒ 退回均匀先验，等价于 InstructGauge 无先验路径；
- 无成对锚点 / 间隙证书覆盖不足 / 证书过期 ⇒ 禁止任何 sim→real 迁移，全部结论只由现实回执给出，等价于纯 reality-only（LeanGauge/ToolGauge）；
- 间隙 `γ_δ` 大于块级安全裕度 / 跨不可逆屏障 ⇒ 强制 `K=1`，等价于 InstructGauge 逐步执行；
- 迁移共形有效样本不足 / 权重比超界 ⇒ 回退全局共形阈值（ToolGauge）；
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「先验只提议、不授权」的 UniBot-V1 接地口径，把黑箱先验的注入面压到可类型检查、可投影、可拒绝的范围内；
2. 一个带**有效时域**与**漂移作废**的 sim-to-real 间隙证书，把「仿真里通过」升级为「现实中可证」，并给出锚点预算与覆盖的定量关系；
3. 一个**间隙条件化块长**约束 `K·γ ≤ margin`，把先验置信度、间隙、块长三者的乘积显式夹住，在不可逆处退化为 K=1；
4. 一条完整可证伪路径：E457–E472 覆盖间隙覆盖、γ-鲁棒迁移、先验增益、先验误设、漂移检测、跨本体闭包、迁移共形与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：间隙证书只在成对锚点的邻域与有效时域内成立，一旦 UniBot 先验把系统推向锚点覆盖之外、或部署分布发生漂移，被低估的 `γ` 会与块长 `K` 相乘、悄悄吃掉安全裕度——真正的残余风险是「证书外推」，而不是 UniBot 或仿真本身。

## 2. 形式化定义（要点）

**定义 448（UniBot-V1 先验接口与能力闭包投影）** `U: (ℓ, x, e) → Δ(Θ) × Δ(A_U)`，输出仅为先验/候选。强制投影 `Proj_T: Δ(A_U) → Δ(Plan_ToolGauge)`；证书计划集 `Plan_cert = Proj_T(supp U) ∩ Plan_ToolGauge`。接口约束：`U` 无写契约、无改安全盾、无签发校准阈值的能力。先验可被 β-检验拒绝（定义 457）。这把「黑箱授权」改成「黑箱提议」。

**定义 449（本体适配器 E 与能力闭包 CC′）** `E: A_U × Emb → A_e ∪ {⊥}`，逐动作检查关节限位、力矩/速度包线、可达性与工具集：`a_e = E(a_U,e)` 仅当 `a_U ∈ A_U` 且落在 `M_env(e)` 内；否则 `⊥`，候选被丢弃。闭包公理：`Plan_cert ⊆ Plan_ToolGauge`、`tools ⊆ T₀`、`mag ⊆ M_phys`（继承定义 432 的 CC，并新增本体包线）。

**定义 450（sim-real 偏差与成对锚点）** `Δ(x,a) = D(P_r(·|x,a), P_s(·|x,a))`，`D` 为有界度量（如 Wasserstein-1 或回执指标上的绝对差）。锚点集 `A_R = {(x_i,a_i,y_i^s,y_i^r)}_{i=1}^n` 取自部署分布；`R_τ` 为有效时域 τ 内可达状态-动作集。关键：证书只对 `R_τ` 与锚点覆盖区域负责，**不做无锚外推**（这是定义 451 的诚实边界）。

**定义 451（S2R 间隙证书）** `S2R-Cert = (γ_δ, δ, τ, A_R, est, cover)`，满足
`P( sup_{(x,a)∈R_τ} Δ(x,a) ≤ γ_δ ) ≥ 1−δ`。
有限样本取 `γ_δ = γ̂ + B·sqrt((log(1/δ)+log N(ε))/(2n))`（有界差/覆盖数），或用锚点残差的上共形分位。`τ` 为有效期：到期或漂移触发（定义 456）即作废。`cover` 记录锚点对 `R_τ` 的覆盖方式（主动采样/网格/流形），**未被 cover 的区域视为 `γ_δ = ∞`**。

**定义 452（γ-鲁棒不变量 / 管状安全）** 令安全集为 `Inv`，定义其 γ-腐蚀 `Inv_γ = {x : B(x,γ) ⊆ Inv}`。若仿真策略在 `R_τ` 上保持 `Inv_γ`，且 `γ_δ ≤ γ`，则由三角不等式，现实轨迹保持在 `Inv` 内。直观：安全裕度必须**先**被间隙吃掉，仍有余量才算数。

**定义 453（迁移准入 PRA）** `Admit(s,C) = 1` 当且仅当：`S2R-Cert` 在 `t` 有效、`γ_δ ≤ margin(C)`、本体闭包 `E` 全程有定义、`B_transfer ≤ B_left`。否则 `Admit=0`，拒绝迁移并记录 fallback 原因；**拒绝是默认值**，不是异常。

**定义 454（间隙条件化块长 Γ-Chunk）** 设单步间隙累积率 `λ_γ`、块级安全裕度 `margin(C)`，
`K_γ = min( K_MAX(ι), K_sim, ⌊ margin(C) / (λ_γ · max(γ_δ, ε_0)) ⌋ )`。
若 `γ_δ ≥ margin(C)/λ_γ` 或块跨越 `I_irr`，强制 `K=1`。这把第 3 轮定义 440 的 `K_MAX(ι)` 与间隙相乘显式夹住。

**定义 455（可迁移共形校准 T-Cal）** 以仿真数据预训练、现实锚点校准；对分数 `s(x,y)` 用权重 `w(x) = p_r(x)/p_s(x)` 的加权共形分位。覆盖下界
`P(h*∈H) ≥ 1−α − ½·E_{p_r}|w(x)−1| ≥ 1−α − TV(p_r,p_s)`。
若 `sup w > W_max` 或 `ESS = (Σw)²/Σw² < n_min` ⇒ 判定不可迁移，回退全局/纯现实阈值。

**定义 456（数字孪生漂移检测 DTD）** 残差 `r_t = y_t^r − f_s(x_t,a_t)`；CUSUM
`S_t = max(0, S_{t−1} + |r_t| − ν)`，`S_t > h` ⇒ 作废 `S2R-Cert`、触发重新锚定并回退 reality-only。这样「间隙突然变大」不会被上一次证书永久掩盖。

**定义 457（先验误设预算）** 估计 `D_KL(p_r‖p_U) ≤ β`。先验只影响排序/采样效率：在 PAC-Bayes/后验采样意义下 `n(ε,δ) = O((β + log(1/δ))/ε²)`；**正确性不依赖先验**，因为证书由现实回执签发。若 `β̂ > β_max` ⇒ 弃用 UniBot 先验，退回均匀先验。

**定义 458（迁移期望损失界）** `L_tr(C) ≤ γ_δ·Σ_i ℓ(a_i) + p_U·c_skill + (1−Admit)·L_fallback`，其中 `p_U` 为先验技能误配概率。该界把「间隙项」「先验项」「拒绝后回退成本」分开，便于消融归因。

**定义 459（锚点主动分配）** 给定预算 `B_anchor`，选 `A_R` 最大化间隙覆盖/最小化后验方差：`A_R* = argmax_{|A_R|≤n} I(Δ; A_R) / cost(A_R)`（D-最优/最大熵等价形式）。优先覆盖高敏感区（定义 462）与不可逆动作邻域。

**定义 460（间隙未定时的安全探索）** 若 `γ_δ` 不可证，只允许 `A_rev` 内动作；任何 `a ∈ I_irr` 需 `γ_δ ≤ γ_irr` 且独立回执交叉验证通过（继承定义 445 的 Barrier）。这保证「没证书时只做可撤回的事」。

**定义 461（跨本体技能兼容）** 技能 `σ` 在 `e` 上可迁移当且仅当 `E` 在 `σ` 的动作序列上全定义、包线保持、且 `Inv_γ` 保持；否则重新接地/重规划。该定义把 UniBot 的「跨本体」能力限制在**可验证的适配**上。

**定义 462（仿真保真预算分配）** `B_sim` 优先投向间隙敏感度 `sens(x)=∂γ/∂fidelity` 最高且证书增益最大的区域：`allocate = argmax Σ sens(x)·Δγ_cert(x)`。仿真算力不是均匀撒，而是买「证书变紧」的地方。

**定义 463（迁移解释证书）** `TransferCert(s) = (id_U, S2R-Cert, A_R, γ_δ, τ, E, receipts, fallback_trace, claims)`，使审计可沿「先验→候选→本体适配→间隙证书→现实回执→主张」六级证据链复现一次迁移决策。

# IP-328 UBP：UniBot-V1 仅作先验，能力闭包投影后才可进入规划
class UniBotPrior:
    def propose(self, ell, scene, embodiment):
        raw = self.unibot.prior(ell, scene)            # 统一技能/动作 token
        cands = []
        for a_u in raw.actions:
            a_e = self.adapter.E(a_u, embodiment)      # 本体限位/力矩/速度
            if a_e is None:
                continue                               # 越包线 ⇒ 丢弃
            if not capability_closed(a_e, T0, M_PHYS, embodiment):
                continue
            cands.append(a_e)
        if self.kl_estimate(scene) > BETA_MAX:          # 先验误设过大
            return UniformPrior()                       # 退回 InstructGauge
        return Prior(cands, raw.skill_scores)           # 只重排，不授权

# IP-329/330/331：间隙证书 + 准入 + 间隙条件化块长
class TransferAdmission:
    def admit(self, s2r, C, embodiment):
        if s2r is None or not s2r.valid_now():          # 无证书/过期
            return False, "no_cert"
        if s2r.gamma > margin(C):                       # 裕度吃不下间隙
            return False, "gap_exceeds_margin"
        if not adapter_total(self.adapter, C, embodiment):
            return False, "embodiment_closure"
        if s2r.cost + chunk_cost(C) > self.budget_left:
            return False, "budget"
        return True, "ok"

    def chunk_len(self, iota, s2r, margin, lam):
        base = self.iac.chunk_len(iota, self.drift_bound)   # 第 3 轮 K_MAX(ι)
        if s2r is None:
            return 1                                        # 不迁移 ⇒ K=1
        if s2r.gamma >= margin / max(lam, 1e-9):
            return 1                                        # γ 太大 ⇒ 单步
        return max(1, min(base, int(margin / (lam * s2r.gamma))))

# IP-332 T-Cal：加权共形（仿真预训练 + 现实锚点）
class TransferCal:
    def threshold(self, sim_scores, real_anchors, alpha):
        w = density_ratio(real_anchors, sim_scores)     # p_r / p_s
        if w.max() > W_MAX or ess(w) < N_MIN:
            return global_quantile(sim_scores, alpha)   # 不可迁移 ⇒ 回退
        return weighted_quantile(sim_scores, w, alpha)

# IP-333 DTD：数字孪生漂移 → 作废证书
class TwinDrift:
    def update(self, y_real, y_sim):
        self.S = max(0.0, self.S + abs(y_real - y_sim) - self.nu)
        if self.S > self.h:
            self.s2r.invalidate()                       # 证书立即作废
            self.reanchor_requested = True
            return "drift"                              # 回退 reality-only
        return "ok"

# IP-334 TransferGauge-8C 闭环：P→I→H→C→E→C→V→U
def transfergauge_8c(M, s, ell):
    prior = M.ubp.propose(ell, M.scene, M.embodiment)
    out   = M.nlib.ground(ell, M.scene, M.ontology)
    iota  = out[0] if out else M.default_iota           # 第 3 轮退化
    H     = M.lbox.hypothesize(s, M.dbox.R[s], iota, prior)  # 先验仅重排
    K     = M.pra.chunk_len(iota, M.s2r, margin(s), LAMBDA_GAMMA)
    C     = M.iac.plan_chunk(iota, H, M.tools, K)       # 间隙条件化 K
    ok, why = M.pra.admit(M.s2r, C, M.embodiment)
    if not ok:
        return M.instructgauge_7c(M, s, ell)            # 拒绝迁移 ⇒ 纯现实
    cert = M.cvc.commit(C, M.env, iota)                 # 第 3 轮块证书
    if M.dtd.update(cert.last_real, cert.last_sim) == "drift":
        return M.instructgauge_7c(M, s, ell)            # 漂移 ⇒ 回退
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    bind_claims(cert, iota, receipts)
    return True

# IP-335 主闭环：50Hz 路径不变，先验/间隙估计异步
def TransferGauge_round(M, obs, audio, tac, depth, det, ell=None):
    submit_async(M.s2r.refresh, M.anchors, M.embodiment)  # 间隙证书异步刷新
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(transfergauge_8c, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 59（先验不扩张与 UniBot 能力闭包）** 若本体适配器 `E` 与闭包投影 `Proj_T` 按定义 448/449 执行，则 `Plan_cert ⊆ Plan_ToolGauge`；任何越包线或越本体候选要么被 `E` 映射为 `⊥`，要么被 `Proj_T` 滤除。故 UniBot-V1 只能改变候选的顺序与采样密度，不能扩大证书可行域。*证明*：`Plan_cert = Proj_T(supp U) ∩ Plan_ToolGauge`，对两个映射取交，天然是 `Plan_ToolGauge` 的子集；`E` 的定义域限制保证越界动作不进入 `supp U`。

**引理 60（γ-鲁棒迁移）** 若仿真在 `R_τ` 上保持 `Inv_γ`，且 `sup_{R_τ} Δ ≤ γ`，则现实轨迹在 `R_τ` 对应时域内保持 `Inv`。*证明*：对每一步，现实状态与仿真状态的偏差不超过 γ；`Inv_γ` 是 `Inv` 的 γ-腐蚀，故以仿真状态为中心的 γ-球仍在 `Inv` 内，现实状态落在该球内。归纳到整个块，得结论。这是定义 452 的管状论证。

**引理 61（间隙证书的有限样本有效性）** 在锚点可交换、偏差有界的条件下，`γ_δ = γ̂ + O(sqrt(log(1/δ)/n))` 满足 `P(sup_{A_R} Δ ≤ γ_δ) ≥ 1−δ`；若用上共形分位，则覆盖为 `1−δ` 的分布自由版本。**但证书只在 `A_R` 覆盖的 `R_τ` 上成立，对未覆盖区域视为 `γ_δ=∞`**。*证明*：有界差 Hoeffding/VC 一致收敛，或共形分位数的边际覆盖；覆盖外无样本，不能推出任何上界。

**引理 62（可迁移共形的覆盖退化）** 加权共形在协变量偏移下满足 `P(h*∈H) ≥ 1−α − TV(p_r,p_s)`；当 `sup w ≤ W_max` 且 `ESS ≥ n_min` 时，附加惩罚可被 `O(W_max/sqrt(ESS))` 控制；否则必须回退全局阈值。*证明*：重要性加权把 `p_r` 下的期望写成 `p_s` 下的加权期望，TV 项来自权重归一化误差；ESS 控制加权经验过程的有效样本量。

**引理 63（间隙-块长复合界）** 设单步偏差上界不随时间放大（或累积率 `λ_γ`），则 K 步块内累积偏差 `≤ K·λ_γ·γ_δ`。若取 `K_γ = ⌊margin/(λ_γ γ_δ)⌋`，则整块满足 `Inv`；当 `γ_δ ≥ margin/λ_γ` 时唯一安全选择是 `K=1`。*证明*：三角不等式逐项累加；`margin` 是到危险区的距离，`K·λ_γ·γ_δ ≤ margin` 即保证管状不变量；边界情形退化为单步。

**引理 64（先验误设只影响样本复杂度）** 在 `D_KL(p_r‖p_U) ≤ β` 下，用 UniBot 先验做后验/候选采样，达到 ε-最优所需现实样本 `n(ε,δ) = O((β + log(1/δ))/ε²)`；而任何证书的正确性只依赖现实回执，故先验误设**不改变安全结论**，只改变成本。若 `β̂ > β_max` 则弃用先验，退化为均匀先验的 `O(log(1/δ)/ε²)`。*证明*：PAC-Bayes 先验-后验 KL 分解；安全结论由定义 451/453 的证书链独立给出。

**引理 65（漂移检测与暴露界）** CUSUM 在均值漂移 `μ > ν` 下的期望检测延迟 `E[τ_d] ~ h/(μ−ν)`；在检测前证书仍被使用，故额外暴露 `≤ E[τ_d]·c_gap`。检测后证书立即作废并回退 reality-only，间隙不会被无限期低估。*证明*：CUSUM 的标准 ARL 近似；作废与回退由定义 456/453 保证。

**引理 66（50Hz 与摊销保全）** 先验推理与间隙证书刷新均在异步路径；主循环只做 `O(1)` 的证书查询、准入判定与块长计算。新增内联开销 `< 0.2ms`，继承光滑行 58 与 ToolGauge 引理 50 的硬实时结论。*证明*：把重计算移到 `submit_async`，内联只保留常数次比较与查表。

## 8. 本轮最大风险

**一句话**：间隙证书只在成对锚点覆盖的 `R_τ` 与有效时域内成立，UniBot 先验越自信、块越长，系统越容易被推向锚点之外；一旦那里 `γ` 被低估，误差就会以 `K·γ` 的形式静默吃掉安全裕度——所以最大风险始终是「证书外推」，而非 UniBot 或仿真本身。
