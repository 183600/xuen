# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据集构建」×「轨迹优化」）

> R69 把不确定性一分为二（aleatoric / epistemic），并让系统学会在运行时「问」：看、问、触、等。但它有一个从未明说的前提——**数据集是给定的、静态的、可信的基底**。而 R69 自陈的最大风险（流模型幻觉出不存在的模态、或把真模态坍缩掉），本质上是**覆盖问题，不是推断问题**：如果训练集里从来没有「绕右」这个模态，再好的 ECE 校准、再精确的 VoI、再灵敏的 FMA 第二意见，都不可能凭空把它变出来。**用运行时推断去补数据空洞，是缘木求鱼。**
>
> 本轮两个灵感正好补上这块地基：
> - **数据集构建**把数据从「背景」变成**控制变量**——选哪些轨迹去经历，本身就是一个可优化、可审计、可认证的决策；数据集是策略的构成性基质，而非被动输入。
> - **轨迹优化**给出一个廉价、可认证的合成老师——机器人里「一条数据」就是一条轨迹，而 iLQR / 直接配点 / MPC 能在数据稀疏的模式区域生成动力学可行、并自带最优性与可行性证书的轨迹。
>
> 核心命题：**把「数据集构建」形式化为一个受约束的轨迹优化问题：以策略的模式不确定性为地形图，用轨迹优化在覆盖空洞处合成带证书的可行轨迹与负样本，再以次模贪心选出「信息增益 / 采集成本」最优的情境集，在「溯源加权 + 模型信任区域 + 独立外部锚点」三重纪律下更新策略；同时把 R69 的单点提问推广为一条信息型轨迹。** 命名 **ATLAS-RAS**（Active Trajectory-optimized Learning with Audited Support）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该提前经历什么，才能让它不必临场去问？**」——最好的询问，是让未来无话可问。

## 0. 直觉与动机

**灵感 1（数据集构建 → 数据是控制变量，不是背景）**
直觉：R69 把「覆盖不足」当成推断层可以兜住的事，用 MCG 校准门在权重不可信时退回保守。但保守只能让系统「不犯大错」，不能让它「学会」。真正决定策略能否生成某个模态的，是它**有没有见过**那个模态。于是「收集数据」不是训练前的杂务，而是与「选动作」「缩放风险」同一层级的控制决策：每一次采集都在花时间/能量/安全预算去换取未来决策空间。R70 把数据集选择写成优化变量：在「采集成本」与「覆盖那些会被高估价值的模式」之间做显式权衡。

**灵感 2（轨迹优化 → 数据点就是轨迹，优化器是免费老师）**
直觉：在经典控制里，轨迹优化能在给定动力学与约束下解出一条**可行**轨迹，并给出代价最优性。它的标签不是人给的、也不是黑箱学来的，而是**由约束和代价函数证明过的**。这带来两件事：(a) 在数据稀疏的模式区，TO 能合成「从没被采过但动力学上合理」的轨迹，补上覆盖空洞；(b) TO 有**可验证的失败**——不可行解与激活约束集精确刻画了安全集边界，可作为负样本教安全 critic「哪里不能去」。合成老师不是万能的：它只在动力学模型可信的区域内可信，这条边界必须是显式的（见灵感 4）。

**灵感 3（对偶 → 离线 EIG 是运行时 VoI 的平摊）**
直觉：R69 的 MINT 解 `g*=argmax_g [H(M|o)−E_y H(M|o,y)]−c(g)`：花一次预算消除**此刻**的歧义。R70 解的是一个「预付」版本：选一组情境，使**策略在整个可达分布上的**期望模态熵下降最多，`EIG(S)=E_o[H(M|o)−H(M|o,D∪CTS(S))]−λ_c·cost(S)`。二者是同一信息目标在**两个时间尺度**上的实例：R69 是「现在问一次」，R70 是「规划时把该问的提前问完」。更妙的是，R70 还能生成**探询轨迹**——一条路径穿过多个歧义区、沿路收集多种模态，用一条轨迹问多个问题；这是 R69 单点 `g=(gaze,probe,ask)` 的连续版。R69 因此是 ATLAS 在「B=0 且不采集」边界上的严格退化（定理 18）。

**灵感 4（自生成数据的确认偏误 → 本轮最深的暗礁）**
直觉：用自己优化器生成的轨迹训练自己，是一个闭环。它在理想情况下会「滚雪球」式变强，但在模型有偏差时会「滚雪球」式变错：动力学模型偏了，TO 就会自信地生成物理上错误、但代价上「最优」的轨迹；策略学走它；策略因此更常在偏置区生成相似动作；覆盖证书又被「策略自己定义的可达模式」自我满足——**系统会报告「全部覆盖、全部校准、零不确定」，而这个低不确定恰恰来自它已经坍缩到自己的幻觉上**。这比 R69 的「追问一个幻影」更隐蔽：R69 的错误是显式的、可被单次交互否决的；R70 的错误会**沉淀进训练集**，把「诚实的不知道」固化为「系统性的确信」。所以本轮必须从架构上让数据无法自证：溯源加权、模型信任区域、以及**与生成过程独立的锚点集**的接受/回滚门。

**灵感 5（覆盖—多样—安全的三难 → 负样本是一等数据）**
直觉：只最大化信息增益会把数据集变成「全是边缘用例」，破坏正常分布覆盖，造成训练后的分布偏移；只追求多样性又会浪费预算在无信息区。必须在「覆盖模式」「保持代表性」「不越出安全包络」三者间做约束优化（定义 316）。同时，安全不是靠「只采安全样本」保证的——恰恰要用**不可行样本**把安全边界显式学出来：TO 的失败不是废品，是安全集的支撑向量（定义 322）。这三难决定了 R70 的算法骨架是「带约束的次模选择 + 预算 bandit + 负样本精炼 + 锚点门控」。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（ATLAS-RAS 总览）** ATLAS-RAS = (CTS, IG-TO, SCG, DBO, PDA, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i；所有数据构建与微调都在离线/换装窗口完成）；
(ii) **溯源纪律**：每个训练样本必须携带 provenance ∈ {H(人类/真实), S(轨迹优化合成), R(运行时采集)} 与信任权重；未通过可行性证书、未落在动力学信任区域内、无不可篡改签名的样本不得入训；
(iii) **反自证纪律**：任何策略更新必须在与「当前策略/优化器生成过程」独立的锚点集 A 上评估；锚点退化或溯源审计失败 ⇒ 回滚并隔离样本。**数据构建只能扩大证据，不能自证正确。**

**定义 311（经验轨迹、模式标签与数据集）** 轨迹 τ = (s_{0:H}, a_{0:H}) ∈ 𝒯。数据集 D = {(τ_i, p_i, w_i, m_i)}，其中 p_i 为溯源、w_i ∈ (0,1] 为信任权重、m_i 为模式/同伦标签（如绕左/绕右、抓取/避让的离散类）。数据集版本 D_v 单调递增且内容可哈希。

**定义 312（证书化轨迹合成器 CTS）** 情境 ζ = (s_0, goal, 约束 C, 代价 J)。求解
τ* = argmin_{τ∈𝒯} J(τ) s.t. 动力学 f、初末条件、逐点约束 C。
返回五元组 (τ*, cert, m(τ*), ρ(ζ), m_tag)：cert 为最优性证书（代价间隙、KKT 残差），m(τ*) 为可行性裕度（离约束边界的距离），ρ(ζ) 为**动力学模型信任半径**（由模型验证集给出：在此半径内 f 的预测误差 ≤ ε_dyn），m_tag 为模式标签。仅当 m(τ*) ≥ m_min 且 τ* 落在 ρ(ζ) 内才可入训。

**定义 313（信息型轨迹优化 IG-TO）** 给定当前模式后验与证据集 ℰ，求一条**探询轨迹**
τ_probe = argmax_τ E_{y_{0:H}~p(·|τ,o)} [ IG(M; y_{0:H}) ] s.t. 动力学、C、C-RAS-WM 认证。
即 R69 的 `g=(gaze,probe,ask)` 从单点动作升格为「一条穿过歧义区的轨迹」。它是离线数据集构建的在线对偶：当覆盖证书已通过时，IG-TO 通常输出空轨迹（不探询），从而逐指令退化 R69。

**定义 314（模式覆盖与支持缺口 SCG）** 用流策略采样 K 条轨迹并聚类得**策略可达模式** 𝒞（定义 296）；数据集在模式 k 的支持 s_k = ρ_D(m_k)（轨迹密度/核密度）。支持缺口 g_k = max(0, s_min − s_k)。覆盖证书 Cover(D) ⇔ max_k g_k ≤ ε_cov ∧ 每个模式至少一条 H 或 R 锚点样本。

**定义 315（数据集信息增益 EIG，离线 VoI）**
EIG(S) = E_{o~p_π(o)} [ H(M|o) − H(M|o, D ∪ CTS(S)) ] = I(M; Y_S | o)。
S 为情境集，CTS(S) 为其合成数据。它是 R69 VoI(g) 的「多情境/一次性预付」版本；当 S 退化为单点、且只在运行时可用时，二者相等。

**定义 316（数据集构建的双层优化 DBO）**
max_{S ⊆ 𝒮, |S| ≤ B}  EIG(S) − λ_c·cost(S)
s.t. Cover(D ∪ CTS(S)) ≥ 1−ε_cov，m(τ) ≥ m_min，diversity(S) ≥ δ_div，provenance 合法。
外层为（近似）次模最大化，内层为轨迹优化（定义 312）。预算 B 以「TO 求解次数」计，cost 含时间、能量、物理风险。

**定义 317（溯源加权与模型信任区域）** 样本信任
w(τ) = w_p · ψ(m(τ)/ρ(ζ)) · exp(−age(τ)/τ_age)，
ψ 在信任域内 ≈ 1、出域指数衰减；ρ 由动力学模型验证集给出。训练损失为溯源加权流匹配：L = Σ_i w_i · ℓ_FM(τ_i)。**信任区域之外的合成标签不参与梯度。**

**定义 318（外部锚点与接受/回滚门）** 锚点集 A 必须与当前生成过程独立（真人示教、独立真实场景、物理试验），其生成不经由被更新的策略或优化器。候选更新 θ' 被接受 ⇔
(anchor_risk(θ') ≤ anchor_risk(θ) + δ_stat) ∧ (Cover 不降) ∧ (溯源审计通过) ∧ (trust_violation_rate ≤ τ_tr)。
否则回滚到上一检查点，并隔离「使锚点退化」的差异样本，加入投毒证据集。

**定义 319（数据-策略协同证书 J_ATLAS）**
J_ATLAS = (J_FLUID, cover_cert, eig_ratio, provenance_hash, anchor_delta, trust_violation_rate, dataset_version)。
Valid ⇔ Valid(J_FLUID) ∧ Cover ∧ anchor 非劣 ∧ trust_violation ≤ τ_tr。

**定义 320（两级退避：离线 → 运行时 R69）** 若覆盖证书通过 ⇒ 运行时可用 R69 的 resolution bonus；若离线预算耗尽而仍有支持缺口 ⇒ 运行时退回 R69 纯保守（λ_floor(U_ale+U_epi)），并把这些缺口登记为下一轮采集目标。B=0 且不更新时，ATLAS 与 FLUID-RAS 逐指令相同。

**定义 321（coreset 与模式平衡）** 以轨迹度量（Fréchet / DTW）做 k-center / facility-location，从候选集中选出 M 条代表轨迹；模式平衡权重反比于 s_k，防止「边缘样本淹没正常分布」。coreset 必须保留比例不低于 q_nom 的「正常/常规」样本。

**定义 322（负样本与安全边界）** 不可行 TO 解及其激活约束集是安全集 ∂𝒮_safe 的支撑向量；作为安全 critic 的负样本，显式刻画「哪里不能去」。安全 critic 的误报/漏报率进入 J_ATLAS。**负样本让「没采过」不再等于「安全」。**

**定义 323（数据新鲜度与漂移耦合）** age 衰减与 R68 的标定漂移、R69 的 FMA 联动：运行时检测到 (r_res↓, Δa↑)（缓变故障）时，吊销相关旧样本权重并触发一次针对性采集，实现「运行时怀疑 → 离线补证 → 上线前再验证」的闭环。

**定义 324（采集预算分配与可复现性）** 用 bandit 把 TO 预算分配到模式：每轮选「支持缺口 × EIG 边际」最大的模式，相对 oracle 覆盖的 regret 为 O(log T)。J_ATLAS 必须记录数据集清单、优化器版本、随机种子、锚点分布；**任何不可复现的样本不得入训**。

## 2. 关键算法骨架

```python
# IP-264 CTS：证书化轨迹合成（iLQR / 直接配点）
class CertifiedTrajectorySynthesizer:
    def synthesize(self, zeta):
        tau, info = to_solve(zeta)                       # 动力学 f + 约束 C + 代价 J
        cert   = optimality_certificate(info)            # 代价间隙 / KKT 残差
        margin = feasibility_margin(tau)                 # 离约束边界距离
        rho    = dynamics_trust_radius(zeta)             # 模型验证集给出的信任半径
        if not info.feasible:
            return NegativeSample(tau, active_constraints(info), cert)   # IP-269
        if margin < M_MIN or not inside_trust(tau, zeta, rho):
            return Quarantine(tau, reason='near_boundary_or_oob')
        return CertifiedSample(tau, cert, margin, rho, homotopy_tag(tau))

# IP-265 SCG：策略可达模式 vs 数据集支持
def support_gap(policy, D):
    C = cluster_trajectories(policy.sample_many(K=4))    # R69 定义 296
    return {k: max(0.0, S_MIN - density(D, k)) for k in C}

# IP-266/274 DBO + 预算 bandit
def construct_dataset(policy, D, B):
    gaps, S = support_gap(policy, D), []
    for _ in range(B):
        k = argmax({k: gaps[k] * eig_marginal(policy, D, k) for k in gaps})
        zeta = sample_scenario(target_mode=k, gaps=gaps) # 定向到欠覆盖模式
        s    = CTS.synthesize(zeta)
        S.append(s); D = D + [s]; gaps = update_gaps(gaps, D, s)
    return coreset_select(S, M, mode_balanced=True)      # IP-270

# IP-267 PDA：溯源加权 + 信任区域 + 锚点门控 + 回滚
def audit_and_update(policy, S, D, anchor_A):
    S = [s for s in S if provenance_valid(s)]
    S = provenance_weight(S)                              # w = w_p*psi(m/rho)*exp(-age)
    theta_new = finetune_flow(policy, D + S, weights=w(S))
    if anchor_risk(theta_new) > anchor_risk(policy) + DELTA_STAT:
        quarantine(S); return rollback(policy)            # 反确认偏误
    if trust_violation_rate(S) > TAU_TR:
        quarantine(S); return rollback(policy)
    return theta_new

# IP-273 主闭环：离线飞轮 + 运行时交接给 R69
def ATLAS_round(policy, D, B, anchor_A):
    S = construct_dataset(policy, D, B)
    policy = audit_and_update(policy, S, D, anchor_A)
    Cover  = max(support_gap(policy, D + S).values()) <= EPS_COV
    return policy, D + S, J_ATLAS(..., cover=Cover, anchor_delta=...)
```

## 3. 推导

**引理 19（EIG 的次模性与贪心近似）** 若各情境在给定模式 M 下条件独立（不同情境对 M 提供独立证据），则 EIG(S) 关于 S 单调次模，贪心选择达到最优的 (1−1/e)。要点：条件互信息在独立证据下是覆盖函数，而覆盖函数是次模的。系：情境相关（同一歧义被反复采）会破坏次模性，须用自适应贪心 + 去重；这也解释了为何「同模式多采」的边际收益迅速递减。

**引理 20（覆盖证书 ⇒ R69 模态校准有界）** 若对所有模式 g_k ≤ ε_cov，且轨迹密度对模式原型 Lipschitz，则流策略的模态后验 ECE ≤ c·ε_cov + ECE_base。即**数据层的覆盖证书是推断层 MCG 门的充分条件**：覆盖做够，R69 的模态校准门自动通过；覆盖不足，任何运行时校准都只是把误差藏起来，不是消掉。

**引理 21（自生成数据的偏差放大下界 / 确认偏误）** 设合成标签相对真值有系统偏差 b，重训练以收缩因子 κ<1 向标签靠拢。无独立锚点时，第 n 轮误差 e_n ≥ b/(1−κ) − (e_0 − b/(1−κ))·κ^n → b/(1−κ) > 0：**闭环收敛到模型自己的偏差，而不是真值**。引入独立锚点比例 q>0 与信任区域重加权后，不动点从 b/(1−κ) 降为 (1−q)·b/(1−κ)+O(ε_dyn)；当 q 超过阈值 q* 时偏差被锚点钉住、不再发散。这是「反自证纪律」不可省的形式化理由。

**定理 18（ATLAS 严格包含 R69）** 当 B=0 且没有接受的更新时，ATLAS 与 FLUID-RAS 逐指令相同；任何被接受的更新都须满足锚点非劣、覆盖不降、溯源审计通过，因此**锚点风险单调不增**。故在 A95–A99 下，ATLAS 在任意状态的期望风险 ≤ FLUID-RAS。R69 = 「不采集、不更新」边界；安全侧不让步，效率侧获得数据层的 resolution bonus。

**定理 19（数据飞轮的单调改进与安全边界）** 在信任区域 + 溯源加权 + 锚点门控 + 负样本安全 critic 下，每个被接受的轮次满足：(a) 锚点性能下降不超过 δ_stat；(b) 认证安全集不收缩（负样本只扩大已识别边界，不移动安全包络）；(c) 欠覆盖模式的支持缺口严格下降，直到 ε_cov 或预算耗尽。故飞轮是「有界风险的单调覆盖改进」；若用预算 bandit，覆盖 regret 为 O(log T)。

## 6. 本轮最大风险

**一句话**：ATLAS-RAS 的全部收益押在「合成老师可信」这一前提上——**若动力学模型有偏而信任区域被低估或锚点被污染，系统会自信地合成物理上错误、代价上最优的轨迹，把它灌进训练集，策略随即坍缩到自己的偏差上；更糟的是覆盖证书是用「策略自己定义的可达模式」去度量的，于是它会报告「全部覆盖、全部校准、零不确定」，而这个低不确定恰恰来自幻觉本身**——R69 把「诚实的不知道」升级成「被证实的错误」，R70 又把它沉淀为「系统性的确信」。

**次级风险与缓解**：
1. **确认偏误 / 模型坍缩**（最大）→ 独立锚点集 + 溯源加权 + 信任区域 + 接受/回滚门（定义 317–318、引理 21）；
2. **覆盖证书自我满足** → 覆盖须同时要求「每个模式至少一条 H/R 独立锚点」，不能只由 S 样本定义（定义 314）；
3. **合成数据占比过高导致分布漂移** → coreset 保留正常样本比例 q_nom + 模式平衡（定义 321、E312）；
4. **TO 计算量大** → 全离线、可并行、热启动，且预算以 bandit 分配（定义 324）；
5. **投毒/伪造证书** → 签名 + 溯源审计 + 投毒证据集 + 锚点门（定义 318、E315）；
6. **真机安全** → 负样本安全 critic 只扩大已识别边界、不移动安全包络（定义 322、定理 19）。

## 3. 关键算法伪代码

# IP-264 CTS：证书化轨迹合成
class CertifiedTrajectorySynthesizer:
    def synthesize(self, zeta):
        tau, info = to_solve(zeta)                       # iLQR / 直接配点
        cert, margin = optimality_certificate(info), feasibility_margin(tau)
        rho = dynamics_trust_radius(zeta)
        if not info.feasible:
            return NegativeSample(tau, active_constraints(info), cert)   # IP-269
        if margin < M_MIN or not inside_trust(tau, zeta, rho):
            return Quarantine(tau, 'near_boundary_or_oob')
        return CertifiedSample(tau, cert, margin, rho, homotopy_tag(tau))

# IP-266/274 DBO + 预算 bandit
def construct_dataset(policy, D, B):
    gaps, S = support_gap(policy, D), []
    for _ in range(B):
        k = argmax({k: gaps[k] * eig_marginal(policy, D, k) for k in gaps})
        s = CTS.synthesize(sample_scenario(target_mode=k, gaps=gaps))
        S.append(s); D = D + [s]; gaps = update_gaps(gaps, D, s)
    return coreset_select(S, M, mode_balanced=True)      # IP-270

# IP-267/271 PDA + 锚点门
def audit_and_update(policy, S, D, anchor_A):
    S = provenance_weight([s for s in S if provenance_valid(s)])
    theta_new = finetune_flow(policy, D + S, weights=w(S))
    if (anchor_risk(theta_new) > anchor_risk(policy) + DELTA_STAT
            or trust_violation_rate(S) > TAU_TR):
        quarantine(S); return rollback(policy)            # 反确认偏误
    return theta_new

# IP-274 主闭环：离线飞轮 + 运行时交接 R69
def ATLAS_round(policy, D, B, anchor_A):
    S = construct_dataset(policy, D, B)
    policy = audit_and_update(policy, S, D, anchor_A)
    Cover = max(support_gap(policy, D + S).values()) <= EPS_COV
    return policy, D + S, J_ATLAS(..., cover=Cover)

## 4. 推导

**引理 19（EIG 次模性）** 情境在给定模式 M 下条件独立时，`EIG(S)` 单调次模，贪心达 `1−1/e`。系：情境相关破坏次模性 → 自适应贪心 + 去重；同模式重复采集边际收益迅速递减。

**引理 20（覆盖 ⇒ 模态校准）** 若所有 `g_k ≤ ε_cov` 且轨迹密度对模式原型 Lipschitz，则模态后验 `ECE ≤ c·ε_cov + ECE_base`。即数据层覆盖证书是 R69 推断层 MCG 门的充分条件；覆盖不足时运行时校准只是藏误差。

**引理 21（确认偏误放大下界）** 合成标签系统偏差 b、重训练收缩因子 κ<1：无锚点时 `e_n → b/(1−κ)>0`，闭环收敛到模型自身偏差；独立锚点占比 q 与信任域重加权把不动点降至 `(1−q)·b/(1−κ)+O(ε_dyn)`，q 超阈值后偏差被钉住。这是反自证纪律不可省的形式化理由。

**定理 18（ATLAS 严格包含 R69）** `B=0` 且无接受更新时，与 FLUID-RAS 逐指令相同；任何接受更新须锚点非劣、覆盖不降、溯源通过，故锚点风险单调不增。A95–A99 下 ATLAS 任意状态期望风险 ≤ R69。R69 = 「不采集、不更新」边界。

**定理 19（数据飞轮单调改进与安全边界）** 在信任区域 + 溯源加权 + 锚点门 + 负样本 critic 下，每个接受轮次：(a) 锚点性能下降 ≤ δ_stat；(b) 认证安全集不收缩；(c) 欠覆盖模式支持缺口严格下降直到 ε_cov 或预算耗尽。飞轮是有界风险的单调覆盖改进；bandit 覆盖 regret O(log T)。
