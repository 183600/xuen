# 第 3 轮迭代（灵感循环 v3：「状态估计」×「闭环控制」）——把“检测-重做”升级为“带信念的采样数据闭环”

> **承接 v2 的 UIP-01′~15，本轮做一次“控制论重写”，而不是再加一层技巧。** v2 的旗舰把子目标判据写成 `V(o,l,g) ∈ {done, ongoing, fail, regressed}`，隐含了两个未经检验的假设：**(a)** 每个块边界的观测足以独立判定步骤状态；**(b)** “检测到撤回就重做”天然是稳定的。对照本轮两个灵感词，这两个假设都不成立：步骤状态是**隐变量**，要从带噪、遮挡、且只在块边界到达的观测里**估计**；而接口是**块内开环、块边界反馈**的采样数据系统，“重做”是一个会消耗时间、改变延迟分布、甚至引入振荡的**控制动作**。所以本轮的问题不是“如何更准地判 done”，而是：**在采样周期 `T_a`、网络/推理死区 `L`、人为反向扰动 `d_t` 同时存在时，如何设计观测器 + 反馈律，使闭环稳定且分数最优。**

**三个当场纠正：**

1. **v2 的 UIP-13（自适应块长 ACS）作废。** 参考校验器要求动作形状严格 `(T_a, …)`，`T_a` 在握手时定死。所谓“按阶段动态选 k / 每次返回 ≤k 步”会被直接拒绝；实时性只能靠**握手前选对全局 `T_a`** + 服务层压稳延迟，块内只能做动作整形，不能重观测。这一条把“实时性”从“变块长”纠正为“**采样周期与估计器时域匹配**”。
2. **`V(o,l,g)` 不能是逐帧谓词，必须是信念。** 同一帧里“拉链差 2 mm”和“拉链已合上”可能几乎不可分；单帧判据在噪声/遮挡下会把“进行中”误判成“被撤回”。正确对象是 `b_t(s_t,x_t,d_t)`：离散计分相位 + 连续物体/本体状态 + 外部扰动。`regressed` 不是观测标签，而是**belief 的负向跳变**。
3. **“用动作块外推状态”有有效时域。** 真实轨迹上，恒速预测在 h≤4 很准（NRMSE≤0.24），h≈8 退化到 0.51，h≥15 已不如“按动作保持”。因此死区补偿不是越远越好：**当 `T_a` 超过估计器的可信预测时域 `h*` 时，带信念的外推会反噬**（合成闭环也复现了这一点）。这把“状态估计”和“块长选择”绑成了一个协同设计问题。

---

## 1. 直觉解释（先直觉，后定义）

**状态估计：策略需要一份“心理模型”，而不是每 `T_a` 步重新失忆。** 人叠毛巾时不会每两秒低头重新判断“这是第几步”；他维护一个正在被动作更新的心理状态：手到哪、布折到哪、刚才那一下有没有把布带回去。机器人同理：块边界看到的图像只是隐状态的一次带噪投影，块内发出的动作是已知的“控制输入”。把“上一刻的信念 + 刚发出的动作块”前向预测，再用新观测做校正，就得到比单帧判据更稳的进度估计；而**预测与实际之差（innovation）**恰好是“世界被外力改了”的证据。

**闭环控制：这是一个采样数据系统，不是连续反馈系统。** 评测端把整块动作执行完才再调用，等于**零阶保持**：`u(t)=u_k, t∈[kT_a,(k+1)T_a)`。反馈周期就是 `T_a`，再叠加网络与推理死区 `L`。因此系统存在一个硬带宽上限：任何在块内发生的人为撤回，最早只能在下一个边界被看见，**期望检测延迟约 `T_a/2`，最坏 `T_a`**。这决定了“重做”不是免费的：它要在“更早发现”与“更少往返/更低延迟”之间做权衡。控制论给的三件工具正好对症：**观测器**（状态估计）、**扰动观测器**（innovation 归因）、**事件触发 + 抗饱和**（只在期望分数损失超过代价时重做，且限制重做次数）。

**二者合起来：外环/内环。** 内环是机器人低层关节/位姿控制器（我们改不了增益，只能通过参考轨迹让它“柔”）；外环是我们能在 API 内控制的**任务级闭环**：估计 → 归因 → 决策 → 发块 → 预测。外环带宽 `≈1/(T_a+L)`，所以“状态估计”和“闭环控制”不是两个模块，而是同一个 observer-controller 的两面。

## 2. 严谨定义

**定义 1（任务隐状态与信念）**：`z_t=(s_t,x_t,d_t)`，其中 `s_t∈{0,…,m}` 是已完成计分步数（离散相位），`x_t∈X` 是物体与机器人连续状态，`d_t∈R^k` 是外部（人为）扰动输入。信念 `b_t(z)=p(z_t | o_{1:kT_a}, u_{1:kT_a}, l)`。策略是 `π(b_t,l) → A_t∈R^{T_a×d}`，且 `A_t` 形状必须严格为 `(T_a,·)`。

**定义 2（因子化观测模型）**：`o_t=(y_t^{prop}, I_t^{head}, I_t^{wrist})`。本体 `y^{prop}`（关节/末端/夹爪）低噪声、可高频；物体状态只能经视觉在边界观测。由于动作块由我们产生，本体可前向预测
`x̂^{prop}_{t+1}=g(x^{prop}_t,a_t)`（`g` 可用已知低层跟踪特性或学习残差）。这把估计问题拆成“本体用运动学、物体用视觉”，显著降低对视觉的依赖。

**定义 3（innovation 与扰动观测器）**：边界 `t_k=kT_a` 有先验 `b^-`，预测观测 `ŷ_k=h(b^-)`，innovation `ε_k=y_k-ŷ_k`。零假设 `H0`（无外部扰动、模型正确）下 `ε_k∼N(0,S_k)`，用归一化创新平方 `NIS=ε_k^T S_k^{-1} ε_k` 检验。若拒绝 `H0`，求最能解释残差的外部输入
`d̂_k=argmin_d ‖y_k-h(f(b^-,u_k,d))‖²`。
当 `d̂_k` 的“进度分量”显著为负时，判为**人为反向撤回**，而不是策略失败。这一步是本轮与 v2 的关键差别：v2 只看“进度有没有回退”，本轮看“**这个回退能否被我的动作解释**”。

**定义 4（采样数据闭环）**：`u(t)=u_k, t∈[t_k,t_{k+1})`，`t_k=kT_a`；有效延迟 `Δ=T_a+L_net+L_infer`。边界控制律
`u_k=μ(b_k)∈{advance, redo, hold, resync, final-audit}`。
若外部撤回发生在 `τ`，则检测延迟 `δ_det=t_k-τ`（`t_k` 为 `τ` 后第一个边界），`E[δ_det]≈T_a/2`，`max δ_det=T_a`；恢复时间 `δ_rec` 为补齐被撤回步骤所需时间。因此“撤回造成的分数损失”有一个可计算上界：`loss ≲ ρ_rev·(T_a/2+δ_rec)`，`ρ_rev` 为撤回发生率。

**定义 5（步骤可观测性指数）**：对计分步 `g`，`o_g = Pr[V(o,l,g)=done | 真完成] - Pr[V(o,l,g)=done | 真未完成]`（或探针 AUC）。`o_g` 低表示单帧不可辨（拉链、拧盖、插网线），必须借助历史、本体接触或**主动消歧动作**。

**定义 6（采样周期-估计器协同设计）**：令 `h*(ε)=max{h: NRMSE_pred(h)≤ε}`。选择
`(T_a*, Q, R, λ, B) = argmax J`
`s.t. T_a ≤ h*(ε_pred)`，`P(L>L_max)≤ε_L`，动作统计规律性通过，
其中 `J=E[score]-αE[time]-βE[#redo]-γE[uncertainty]`，`B` 为最大重做次数（抗饱和）。

## 3. 瓶颈假设（本轮可证伪）

- **H1（最高杠杆：反馈陈旧，而非策略能力）**：在人为撤回下，主要损失来自“块内看不见”，其量级由 `T_a/2+δ_rec` 决定，而不是策略网络不够大。可直接用 `T_a` 扫描验证。
- **H2（因子化估计优于单帧判据）**：本体+动作的运动学预测 + 视觉物体校正，比“每帧视觉重判”方差更低；在相同误报率下检测延迟更短。
- **H3（innovation 归因能区分“被撤回”与“没做成”）**：只做“进度回退”阈值会把策略失败误判为人为撤回，导致无谓重做；用动作条件残差归因可降低误重做。
- **H4（带宽匹配）**：状态估计只在 `T_a≤h*` 时优于记忆less 判据；当 `T_a>h*` 时，外推误差超过信号，应缩小 `T_a` 或退回直接测量。合成实验显示 `h*` 约 8（在 30 Hz 下约 0.27 s）。
- **H5（分数感知事件触发）**：重做应由“期望分数恢复 > 时间+延迟风险代价”触发，而不是“任何回退都重做”；末步分值最大，结尾应做一次 `final-audit`。
- **H6（低可观测步需要主动消歧）**：对 `o_g` 低的步骤，一次小幅“探针动作”（轻推/回撤/保持）比一次错误重做便宜；但只在剩余时间充足且该步分值高时值得。

## 4. 从 v2 到 v3 的清单变动

- **升级**：UIP-01′ → **UIP-01″（信念空间 RHPV-D）**；UIP-09′ 的“撤回检测”由新 UIP-17 的 innovation 归因实现；UIP-15（安全阀）保留并接入 UIP-19 的事件触发。
- **新增（命中两词）**：UIP-16 混合任务状态估计 HTSE；UIP-17 innovation 扰动观测器 IDO；UIP-18 死区/延迟补偿 DTC；UIP-19 分数感知事件触发控制器 SAEC；UIP-20 采样周期协同设计 SPC；UIP-21 主动状态消歧 ASD。
- **作废/改写**：UIP-13（自适应块长）作废，由 UIP-20 取代；UIP-02′ 保留但降为**条件性**（只在“部分分世界”优先，且必须服从 UIP-19 的分数-代价判据）。
- **保留**：UIP-05、08′、11、12、14、15；UIP-11/12 仍是离线判分与扰动数据工厂，但本轮把它们定位为**估计器与控制器的试验台**，而不是刷分工具。

## 5. 本轮押注

**押注：UIP-16（混合状态估计）× UIP-17（扰动观测器）× UIP-19（分数感知事件触发）组成的“信念闭环”**，由 UIP-20 约束 `T_a≤h*`、UIP-18 补偿死区。它把 v2 的“检测-重做”从启发式规则变成一个有观测器、有归因、有代价函数的控制器；而且它的每个部件都在选手 API 权限内（选择 `T_a`、声明 obs、在块边界发动作），不需要额外模型或外部服务。

**→ 本轮最大风险（一句话）**：人为撤回恰好是估计器训练分布之外的“恶意扰动”，一个**自信但错误**的信念会比朴素的单帧检查更糟——必须用不确定性门控 + 规则回退 + 最大重做次数把“错误信念”限制在可恢复范围内。

## 1. 旗舰深潜：UIP-01″ · BELIEF-RHPVD

### 1.1 与 v2 的差别

v2 的 `V(o,l,g)` 是 `o_t` 的函数，等于假设“单帧可判、且判完即真”。v3 改为对信念 `b_t` 做**混合状态估计**：

```text
s_t ∈ {0,…,m}         离散计分相位（m=该任务计分步数）
x_t ∈ R^d             物体位姿/关节/夹爪等连续状态
d_t ∈ R^k             外部扰动（人为撤回）
b_t = p(s_t, x_t, d_t | o_{1:kT_a}, u_{1:kT_a}, l)
```

三个状态转移来源：

1. **相位转移**：`s→s`（原地/失败）、`s→s+1`（完成）、`s→s-1`（被撤回）；
2. **连续转移**：本体用运动学/低层跟踪 `x^{prop}_{t+1}=g(x^{prop}_t,a_t)`；物体用学习动力学或几何约束；
3. **扰动输入**：`d_t` 只在 innovation 无法被动作解释时被激活。

### 1.2 控制律

边界上不是“if regressed then redo”，而是解一个带代价的模式选择：

```text
u_k = argmax_{u ∈ {advance, redo, hold, resync, final-audit}}
      E[ score_remaining | u, b_k, score_table ]
      - α·E[time | u] - β·E[#redo | u] - γ·uncertainty(u)
```

- `advance`：当前步后验 `P(s_t ≥ g+1) > τ_done`，发下一子目标动作；
- `redo`：`P(s_t < g) > τ_rev` 且 `E[recover] > cost_redo`；
- `hold`：后验不确定但时间预算紧，保持位姿等下一次观测；
- `resync`：扰动方向明确、只需把相位对齐（不重复大动作）；
- `final-audit`：剩余时间充足时，对全部计分步做一次复核，修补被撤回的前置步。

### 1.3 为什么不会“反复重做”

- `max_redo=B`（UIP-15 抗饱和）；
- 每次 redo 前要求 `P(regressed)` 的**后验**超过阈值，而不是单帧证据；
- `redo` 的代价随剩余时间、延迟预算、当前动作规律性动态上升；
- 若连续两次 redo 后后验仍不收敛，强制切到 `hold` 或 `final-audit`，避免振荡。

## 2. UIP-16 · HTSE（Hybrid Task-State Estimator）

### 2.1 因子化，而不是一个大 VLM

| 子状态 | 观测源 | 更新频率 | 方法 | 作用 |
|---|---|---|---|---|
| 本体 `x^{prop}` | `left/right_arm`、`left/right_ee_pose_gripper_base`、`left/right_gripper` | 每边界（可堆叠历史） | 运动学预测 + 低通/EKF | 精确知道“手在哪、夹爪开合” |
| 物体 `x^{obj}` | 4 路 RGB（head+wrist） | 每边界 | 几何谓词 / 小探针 / 关键点 | 知道“物体到哪、是否被拿走” |
| 相位 `s` | 上述融合 + 语言子目标 | 每边界 | HMM / 粒子滤波 | 知道“第几步、是否回退” |
| 扰动 `d` | innovation | 每边界 | 扰动观测器（UIP-17） | 知道“是谁改了世界” |

关键点：**本体不需要视觉**。参考实现的 `OBSERVATION_SPEC` 明确提供 7 维双臂、6 维末端位姿、1 维夹爪（`example/example_env.py:14-26`），只要在 `obs_delta_indices` 里声明即可获得。把“手的状态”从视觉里拿回来，视觉只需负责物体与接触，估计方差会显著下降。

### 2.2 混合滤波伪代码

```python
class HybridTaskStateEstimator:
    def __init__(self, m, probe, dyn, q_phase=0.02, q_cont=0.01, r_vis=0.3):
        self.m, self.probe, self.dyn = m, probe, dyn
        self.hmm = PhaseHMM(m, q_phase)          # 离散相位
        self.ekf = EKF(dyn, q_cont)              # 连续物体/本体
        self.prev_obs = None

    def prior(self, language):
        # 从语言 + 首帧给相位先验（可用 UIP-05 的关系分解）
        return Belief(phase=self.hmm.uniform(), cont=self.ekf.init(), dist=0.0)

    def predict(self, b, action_chunk):
        # 块内开环：用“我们发出的动作”前推本体，用动力学前推物体
        b.cont = self.ekf.predict(b.cont, action_chunk)
        b.phase = self.hmm.predict(b.phase)       # 相位通常不变（除非动作完成）
        b.cont_cov += self.ekf.Q * len(action_chunk)
        return b

    def correct(self, b, obs):
        # 1) 本体校正（低噪声，权重高）
        z_prop = extract_prop(obs)
        b = self.ekf.update_prop(b, z_prop)
        # 2) 视觉探针：每个计分步的 done 概率
        logits = self.probe(obs, b.phase)         # 小头，共享骨干
        # 3) HMM 前向更新（含 s→s-1 反向转移）
        b.phase = self.hmm.update(b.phase, logits)
        b.ekf.update_obj(b, obs)
        return b

    def innovation(self, b_prior, obs):
        y_hat = self.render_expected(b_prior, obs)   # 预测观测（特征/几何）
        eps = feature(obs) - y_hat
        S = self.ekf.H @ b_prior.cont_cov @ self.ekf.H.T + self.ekf.R
        return eps, S
```

## 3. UIP-17 · IDO（Innovation Disturbance Observer）

### 3.1 为什么“进度回退阈值”不够

设策略把“插网线”做失败了（没插进去），视觉进度也会回退。若只按“回退”触发 redo，就会把**策略失败**误判成**人为撤回**，反复重做同一个失败动作。IDO 的判据是动作条件残差：

```text
ε_k = y_k − h( f(b^-, u_k, d=0) )          # 假设无外力时的预测残差
NIS = ε_k^T S_k^{-1} ε_k
if NIS > χ²_{1-α}:
    d̂ = argmin_d ‖y_k − h(f(b^-, u_k, d))‖²
    if d̂.progress < −δ:      mode = "external-reversal"   # 有人把进度撤了
    else:                     mode = "policy-failure"      # 自己的动作没成
```

- 对 `external-reversal`：重做被撤回的**那一步**，并把相位后验拉回；
- 对 `policy-failure`：不要重做同一动作，换一个子目标/恢复技能（UIP-14），或 `hold` 等下一帧。

### 3.2 扰动方向的可解释性

`d̂` 不必是完整物理量；只需在**计分步谓词空间**里解释：例如 T16 的“折叠层数 −1”、T19 的“齿合长度 −L”、T27 的“堆叠数 −1”。这使 IDO 的输出可直接喂给 UIP-19 的代价函数，而不需要额外的大模型。

## 4. UIP-18 · DTC（Dead-Time Compensation）

### 4.1 两个死区

1. **采样死区 `T_a`**：块内看不见；
2. **传输/推理死区 `L`**：观测到达时已经旧了，动作生效还要等。

控制应基于**动作生效时刻**的状态，而不是观测时刻的状态：

```text
x̂_target = predict(x̂_t, issued_chunk, Δ),  Δ = T_a + L_net + L_infer
```

### 4.2 有效时域（真实轨迹证据）

用 12 个任务、20 条真实末端轨迹（30 Hz）比较两种开环预测（`exp/r4_state_est_closed_loop.py`）：

| 预测时域 h（控制步） | 恒速预测 NRMSE ↓ | 按动作保持 NRMSE ↓ |
|---:|---:|---:|
| 1 | **0.060** | 0.372 |
| 2 | **0.117** | 0.359 |
| 4 | **0.243** | 0.372 |
| 8 | 0.509 | **0.492** |
| 15 | 0.984 | **0.722** |
| 30 | 1.913 | **1.038** |

（NRMSE = RMSE / 各维轨迹标准差；越低越好。B/D 级：真实轨迹只用于校准预测误差，不构成机器人证据。）

**读法**：恒速预测在 h≤4 极准（≤0.24 个状态标准差），h≈8 退化到 0.51，h≥15 已不如“按动作保持”。所以：

- 死区补偿的有效窗口约 **4–8 个控制步**；
- 当 `T_a+L` 超过这个窗口时，**不要再外推**，应改为缩小 `T_a`、或退回直接测量 + 事件触发；
- 这也解释了为什么 v2 的“大块 + 预测”会脆弱：预测精度配不上块长。

## 5. UIP-19 · SAEC（Score-Aware Event-Triggered Controller）

### 5.1 代价函数

```text
J(u) = Σ_{g≥s} w_g · P(reach g | u, b)          # 期望步骤分（w_g 来自计分表）
       − α·T(u)                                  # 时间
       − β·N_redo(u)                             # 重做代价
       − γ·H(b)                                  # 不确定性惩罚
       − λ·P(L > L_max | u)                      # 延迟违约风险
```

`w_g` 直接取官网 `scoring_points`（2 步 50/50；3 步 30/30/40；4 步 25×4；5 步 20×5；末步恒 ≥ 前序步）。这使“先保前置、末步搏分”从口号变成可计算的目标。

### 5.2 事件触发条件

只在以下条件同时成立时 `redo`：

```text
P(s_t < g | b_t) > τ_rev
AND  E[score recovered] > β + α·E[redo time] + λ·latency_risk
AND  redo_count < B
AND  predicted_action_regularity_ok
```

否则 `hold`/`advance`。这直接防止“看到一点回退就重做”的抖动。

### 5.3 末端终审 `final-audit`

末步分值最大，且人为干扰会“叠好后翻开/拉上后拉开”。若剩余时间 > 预估审计时间，则在宣告完成前：

1. 用 HTSE 对全部计分步做一次后验复核；
2. 对 `P(done)<τ_done` 的前置步，按分值从高到低修补；
3. 若审计时间不足，则优先保末步与高权重前置步。

## 6. UIP-20 · SPC（Sampling-Period Co-Design，替代 UIP-13）

### 6.1 硬约束

参考实现 `ExampleEnv.step` 校验 `action[key].shape == (T_a, *spec)`（`example/example_env.py:164`）。因此：

- `T_a` 只能在握手时定一个全局值；
- 每次必须返回**完整 `T_a` 步**；
- 不能按阶段变块长，也不能少返回几步。

### 6.2 选择规则

```text
h*(ε) = max{ h : NRMSE_pred(h) ≤ ε }        # 由真实轨迹/仿真标定
T_a* = argmax_{T_a ∈ {1,2,4,8,15,30}} J(T_a)
       s.t. T_a ≤ h*(ε_pred),  P(L>L_max)≤ε_L,  action_regularity_ok
```

由 §4 的真实轨迹：`h*(0.25)≈4`，`h*(0.5)≈8`。因此：

- 接触密集、撤回型任务（T14/T16/T19/T26/T27）：优先 `T_a≤4`；
- 大范围搬运、低扰动任务（T02/T03/T20/T21）：可用 `T_a=8`；
- `T_a≥15` 只在“几乎无撤回 + 低延迟”时考虑，且估计器应切换为“直接测量 + 事件触发”，不要盲目外推。

## 7. UIP-21 · ASD（Active State Disambiguation）

对 `o_g` 低的步骤，单帧图像无法区分 done/undone。与其猜测，不如用一次**廉价探针动作**换取可观测性：

| 任务 | 探针动作 | 观测变化 | 成本 |
|---|---|---|---|
| T19 拉链 | 夹住拉链头轻拉 3–5 mm 后回位 | 齿合长度/阻力变化 | 小 |
| T14 瓶盖 | 反向轻拧 <10° 后回位 | 旋角/阻力 | 小 |
| T26 网线 | 沿插入轴轻推-回撤 | 插入深度/接触 | 小 |
| T16 毛巾 | 轻抬一角 | 层数分离 | 中 |
| T12 锁 | 轻转钥匙 | 转角/阻力 | 小 |

触发条件：`H(b) > H_thr` 且 `w_g·P(recover) > α·T_probe` 且剩余时间充足。ASD 不改变“单模型”合规性——它只是动作序列的一部分。

## 8. 关键算法：估计-归因-控制一体

```python
class BeliefRHPVD:
    def __init__(self, policy, est, ctrl, T_a, B=2,
                 tau_done=0.7, tau_rev=0.65, alpha=1.0, beta=1.0):
        self.policy, self.est, self.ctrl = policy, est, ctrl
        self.T_a, self.B = T_a, B
        self.tau_done, self.tau_rev = tau_done, tau_rev
        self.alpha, self.beta = alpha, beta

    def reset(self, language):
        self.b = self.est.prior(language)
        self.redo_count, self.last_mode = 0, "advance"

    def get_action(self, obs):
        # (1) 观测校正 + 相位后验
        b_prior = self.b
        self.b = self.est.correct(self.b, obs)
        # (2) 扰动观测器：区分“被撤回”与“没做成”
        eps, S = self.est.innovation(b_prior, obs)
        d_hat, kind = self.est.attribute(eps, S, b_prior, obs)
        # (3) 分数感知模式选择
        mode = self.ctrl.decide(
            belief=self.b, kind=kind, d_hat=d_hat,
            remaining_time=self.ctrl.remaining,
            redo_count=self.redo_count, score_table=self.ctrl.w)
        # (4) 抗饱和 + 安全阀
        if mode == "redo" and self.redo_count >= self.B:
            mode = "hold"
        if kind == "external-reversal" and d_hat.progress < 0:
            mode = "redo" if self.redo_count < self.B else "final-audit"
        # (5) 低可观测步：主动消歧
        if self.b.uncertainty > self.ctrl.H_thr and mode == "advance":
            mode = "probe" if self.ctrl.probe_worth_it(self.b) else mode
        # (6) 生成完整 T_a 步（形状严格 (T_a, ...)）
        g = self.ctrl.target_phase(self.b, mode)
        A = self.policy.act(self.b, obs, g, self.T_a)
        A = self.ctrl.shape(A, mode)     # 平滑/限幅/末段减速 + 统计规律性
        # (7) 块内前推信念（死区补偿）
        self.b = self.est.predict(self.b, A)
        if mode == "redo":
            self.redo_count += 1
        self.last_mode = mode
        return A
```

```python
# 伪：HMM 相位更新，含反向转移
def update_phase(prior, logits_done, p_rev=1e-3):
    trans = {
        "stay": 1 - p_done - p_rev,
        "advance": p_done * prior.advance_gate,
        "reverse": p_rev,                 # 人为撤回
    }
    posterior = normalize(prior @ trans.T * emission(logits_done))
    return posterior
```

## 9. 机制检验结果（D 级，合成；不可当机器人证据）

### 9.1 设置

`exp/r4_state_est_closed_loop.py`：m=4 个计分步，每步 dwell=25 控制步，horizon=300；外部撤回按均值 70 步的泊松过程发生，每次撤 1 步；观测每 `T_a` 步到达一次，噪声 σ=0.30；三种模式：

- `openloop`：从不校正信念；
- `memoryless`：每边界直接用带噪观测，回退超过 0.5 即视为撤回；
- `belief`：恒速预测 + innovation 门控的 EKF 校正。

指标：最终真实进度（0–4）、最终分数占比、重做次数、**误重做**次数、平均检测延迟。每格 120 个随机种子取均值。

### 9.2 结果

| `T_a` | 模式 | 最终进度 /4 | 分数占比 | 重做次数 | 误重做 | 平均检测延迟（步） |
|---:|---|---:|---:|---:|---:|---:|
| 2 | openloop | 0.485 | 0.121 | 0 | 0 | — |
| 2 | memoryless | 3.189 | 0.797 | 17.35 | 12.55 | 0.66 |
| 2 | **belief** | **3.420** | **0.855** | **5.79** | **1.38** | 0.89 |
| 4 | openloop | 0.485 | 0.121 | 0 | 0 | — |
| 4 | memoryless | 2.681 | 0.670 | 9.52 | 4.92 | 1.86 |
| 4 | **belief** | **2.931** | **0.733** | **4.57** | **0.82** | 1.95 |
| 8 | openloop | 0.485 | 0.121 | 0 | 0 | — |
| 8 | memoryless | 1.877 | 0.469 | 5.78 | 1.48 | 4.25 |
| 8 | **belief** | **2.033** | **0.508** | **3.57** | **0.45** | 5.09 |
| 15 | openloop | 0.485 | 0.121 | 0 | 0 | — |
| 15 | memoryless | **1.694** | **0.424** | 3.83 | 0.31 | 8.31 |
| 15 | belief | 1.340 | 0.335 | 2.77 | 0.32 | 11.83 |
| 30 | openloop | 0.485 | 0.121 | 0 | 0 | — |
| 30 | memoryless | **1.107** | **0.277** | 2.09 | 0.02 | 21.30 |
| 30 | belief | 0.798 | 0.200 | 2.44 | 0.25 | 31.85 |

### 9.3 结论

1. **开环在第一次撤回后就“卡死”**：它继续执行错误的子目标，真实进度不再增长（0.485 恒定，与撤回次数无关）。这正是“块内看不见 + 不校正信念”的失败模式。
2. **在 `T_a≤8` 时，belief 全面优于 memoryless**：分数 +6~9 个百分点，误重做降低 **6–9 倍**（T_a=2：12.55→1.38；T_a=4：4.92→0.82）。状态估计的主要收益不是“更早发现”（采样周期决定了下界），而是**更少把噪声当撤回**。
3. **在 `T_a≥15` 时，belief 反而变差**：外推时域超过 §4 的 `h*`，预测误差超过信号，直接测量更稳。这验证 H4：**`T_a` 与估计器可信时域必须匹配**，不能盲目“大块 + 预测”。
4. **检测延迟近似 `T_a/2` 到 `T_a`**：T_a=2→0.89，4→1.95，8→5.09，15→11.83，30→31.85。与定义 4 的界一致；这是采样数据系统的硬限制，任何估计器都无法突破。

> **边界声明**：这是合成 toy（D 级），用于验证机制与排序，不是 UniBot 真机结果；真实成功率必须由 E304 的真机/Gazebo 实验给出。

| E301 | 恒速预测 vs 动作保持 vs 融合 | h-step NRMSE、h*(ε) | 复现 §4；融合应把 h*(0.25) 推到 ≥6 |
| E302 | 单帧回退阈值 vs UIP-17 IDO | ROC-AUC、检测延迟、误报率 | 同误报率下延迟更低；AUC ≥0.9 |
| E303 | openloop vs memoryless vs belief（闭环 toy） | 最终进度、误重做 | T_a≤8 时 belief 分数 +5~10pp、误重做 −6× |
| E304 | 真实策略 ± 撤回（Gazebo UIP-12） | 成功率、步骤分、恢复时间 | 撤回任务上步骤分显著 +Δ |
| E305 | 无 ASD vs UIP-21 | 低可观测步的判对率/耗时 | 判对率 +Δ 且总时间不超预算 |
| E306 | 固定 T_a 网格 vs UIP-20 SPC | J、p95 延迟 | 验证 `T_a≤h*`；超域配置应被淘汰 |
| E307 | 任何回退即重做 vs UIP-19 SAEC | 重做次数、最终分数 | 同分数下重做次数 −30% |
| E308 | 无估计器 vs 全链路（16+17+18+19+20） | 榜单综合、延迟抖动、动作规律性 | 综合提升且可信度指标不恶化 |

**执行顺序**：E301（已部分完成）→ E302/E303（离线，最快）→ E305（低可观测步）→ E304（Gazebo/真机）→ E306/E307（调参）→ E308（端到端）。

## 11. 合规、风险与时间线

### 11.1 合规

- **单模型**：HTSE 的探针、IDO 的归因头都应是**共享骨干上的小头**，或纯几何/运动学规则；不要接外部 VLM（可能被判“非单模型”）。
- **接口红线**：动作形状严格 `(T_a,·)`；`obs_delta_indices` 只声明必要键；`language` 偏移必须 `[0]`；不返回超范围/异常动作。
- **可信度**：估计器/重做不得引入延迟尖峰或动作抖动；UIP-15 的预算约束必须在线生效。

### 11.2 风险

| 风险 | 表现 | 缓解 |
|---|---|---|
| 错误信念 | 自信地把“策略失败”当“被撤回”，反复重做 | 后验阈值 + 最大重做次数 + IDO 归因 |
| 外推失真 | `T_a>h*` 时预测比直接测量更差 | UIP-20 硬约束 `T_a≤h*`；超域退回直接测量 |
| 估计器 OOD | 人为撤回的形态/时机不在训练分布 | UIP-12 随机化时机/速度/轨迹；规则回退 |
| 延迟违约 | 估计+重做把 p95 推高 | 事件触发 + 预算 + 服务层隔离（08′） |
| 过度工程 | 小头上叠小头，算力/延迟反噬 | 先做纯规则/几何版，再逐步学习化 |

### 11.3 时间线（粗排）

- 第 1 周：E301 复现 + 估计器接口定义（本体/物体/相位）。
- 第 2–3 周：E302/E303；IDO 归因与事件触发控制离线调参。
- 第 4–5 周：E305 可观测性分级 + ASD；3–5 个代表任务（T19/T26/T16/T27/T14）。
- 第 6–7 周：UIP-12 脚本化撤回 + Gazebo 闭环（E304）；UIP-20 的 `T_a` 网格。
- 第 8 周：E306/E307/E308；真机时段做锚点校准。

## 12. 本轮最大风险 & 押注

**一句话**：最危险的不是“估计不准”，而是“估计器在人为撤回这个分布外事件上**过度自信**”——必须用不确定性门控、IDO 归因和最大重做次数把错误信念限制在可恢复范围内，否则闭环会比开环更不稳定。

**→ 押注：UIP-16 HTSE（状态估计）× UIP-17 IDO（扰动归因）× UIP-19 SAEC（分数感知事件触发）**，由 UIP-20 用真实轨迹标定的 `h*` 约束 `T_a`，由 UIP-18 补偿死区。它把 v2 的“检测-重做”从规则升级为**有观测器、有归因、有代价函数的采样数据闭环**；核心可证伪预测是：**在 `T_a≤8` 的撤回任务上，信念闭环比单帧判据的误重做低一个量级、步骤分更高；而 `T_a>h*` 时优势反转**。
