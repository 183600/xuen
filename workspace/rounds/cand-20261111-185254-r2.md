# 第 56 轮（承接第 55 轮语义-接触层 IP-121–126；灵感循环第 2 轮；本轮灵感：「用户画像」×「四足机器人」）

> 第 55 轮把“接触是否可信”写进了全身生存核。本轮把视角从**环境侧**翻到**人侧**：四足机器人若服务于人（跟随、导盲、负重、陪伴），真正决定安全与体验的不是它会不会走，而是它**对“这个具体的人能承受什么”的估计是否可信**。核心矛盾：**H24** 用户画像是“关于人的模型”而非人的真值，自我报告与行为推断在疲劳、伤病、策略性隐瞒下会系统性偏移，而四足机器人是物理贴身的——画像错一维，就会变成跟随距离、接近速度、牵引力上的真实危险；**H25** 个性化需要主动探索（试步速、试反应时），但探索本身消耗用户的安全余量，而人的物理系统不可逆；**H26** 画像非平稳且隐私敏感，跨设备共享画像会把个性化变成泄露，而隐私噪声又会污染安全证书。

## 0. 直觉与动机

**灵感 1（用户画像 → 人的能力包络，而非兴趣标签）**
直觉：服务机器人真正需要的画像不是“用户喜欢什么”，而是“用户能承受什么”。把画像定义为 **能力包络** `π=(v_walk, τ_react, h_reach, F_leash^max, r_risk, g_pref, fatigue)`。这使画像从推荐系统的偏好向量，变成 **联合人-机可行域的参数**：四足机器人跟随、导盲、负重都直接读这组参数，而不是读“用户喜欢蓝色”。

**灵感 2（四足机器人 → 画像条件生存核 + 步态即安全裕度）**
直觉：同一张环境语义图，对不同能力的人意味着不同的可行动集。老人需要更大的跟随间距与更慢的接近速度；术后用户不能承受牵引。于是把第 55 轮的 `K(Σ)` 扩成 `K(π)`。更关键的是四足独有：**静稳定步态（crawl）可以在画像高度不确定时，用“支撑多边形”换掉“动态平衡的激进性”**——步态选择因此成为画像不确定度的函数，而不是固定参数。

**灵感 3（画像不确定性 → 风险预算核与通用安全集）**
直觉：不要赌单一画像。要求在画像后验的 `(1-β)` 质量上可行，得到 `K_β(b)`。主动画像只能在 **通用安全集** `K_0 = ∩_{π∈可信集} K(π)` 内做——即无论用户是哪种可信类型都安全的动作，才允许被用来“试探”。这把个性化从“猜准了才安全”改造成“猜错也有保底”。

**灵感 4（非平稳 → 画像漂移护盾与证书有效期）**
直觉：画像会因疲劳、疼痛、情绪、病程而漂移。应在行为/生理残差上做变点检测；一旦报警就**膨胀后验、收紧 β、切换到更保守步态**，并给证书一个 **有效期** `T_valid`，过期即重认证。证书不再是一次性结论，而是带时标的临时许可。

**灵感 5（隐私 → 差分隐私画像联邦）**
直觉：画像是最敏感的个人数据之一。云端只应收到 **DP 画像草图**，边端本地细化；但隐私噪声会削弱画像精度，进而吃掉安全裕度，所以必须把 **`ε_DP` 显式写进证书**，让“隐私保护”不被当成“免费”。

**灵感 6（回到产物：v32 的六个算子）**
把它落成 UBP/PCK/SAP/PDS/PCG/PPF 六个 IP，并与第 55 轮的语义-接触层、v31 的动作-鲁棒性层对接：**环境语义决定“哪里能踩”，用户画像决定“怎么陪这个人走”**。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（用户能力画像与后验可信集）**
能力画像 `π ∈ Π ⊆ ℝ^d`，`π=(v_walk, τ_react, h_reach, F_leash^max, r_risk, g_pref, fatigue)`。观测 `o_t`（步态、反应延迟、语音、可穿戴生理、自报）。后验 `b_t(π)=P(π | o_{1:t})`；可信集取最高密度区 `Π_α(t)={π | b_t(π) ≥ q_α}`，要求经验覆盖率 `P(π*∈Π_α) ≥ 1-α-ε_cal`。画像草图 `s_t=𝔼_{b_t}[φ(π)]`。

**定义 128（画像条件生存核与风险预算核）**
联合状态 `x=(x_r, x_h)`（机器人 + 人状态估计），耦合约束 `g(x,u;π) ≤ 0` 包含
`dist(x_r,x_h) ≥ d_min(π)`、`||v_r|| ≤ v_max(π)`、`||F_leash|| ≤ F_leash^max(π)`、`|cadence_r-cadence_h| ≤ c_max(π)`。
`K(π) = {x | ∃u,λ : f(x,u,λ)=ẋ ∧ supp(λ)⊆C(Σ) ∧ g(x,u;π)≤0 ∧ x_{t+1}∈𝒳_safe}`。
风险预算核 `K_β(b) = {x | P_{π~b}(x∈K(π)) ≥ 1-β}`；通用安全集 `K_0 = ∩_{π∈Π_α} K(π)`。注意 `K_β` 一般非凸，用情景优化给内/外近似 `(K_β^in, K_β^out)`。

**定义 129（安全主动画像）**
试探动作 `u∈A_probe` 必须满足 `x_{t+1}∈K_0` 且单步风险 `R(u;b) ≤ R_step`、累计风险 `∑R ≤ R_budget`。目标
`u* = argmax_{u∈A_probe} I(π; o_{t+1} | u, b_t) - λ_r R(u;b_t)`，
即**带安全硬约束的贝叶斯实验设计**；`I` 为关于能力画像的互信息。

**定义 130（画像漂移与证书有效期）**
`π_t` 分段平稳，变点 `{τ_k}`。残差 `e_t=o_t-ĥ(b_t)`，检测器 `D_t=CUSUM(e_{1:t})`。报警时 `b ← b ⊕ U(δ_π)`（膨胀），`β ← β'>β`，步态转保守模式。定义漂移预算 `δ_π` 与检测延迟 `τ_d`；证书有效期
`T_valid = inf{t : P(||π_t-π_{t_0}|| > δ_π) > η}`。

**定义 131（画像-耦合证书）**
`J_π = (b, Π_α, K_margin, β, δ_π, τ_d, ε_DP, g_safe, evidence)`：
- `K_margin = min_{x∈轨迹} dist(x, ∂K_β^in(b))`；
- `g_safe` 为所用四足步态及其支撑裕度；
- `ε_DP` 为分享画像消耗的隐私预算。
可部署当且仅当：后验校准通过、`K_margin ≥ θ_K`、`β ≤ β_max`、`δ_π ≤ Θ_π`、`τ_d ≤ τ_max`、`ε_DP ≤ ε_max`。

**定义 132（隐私预算画像联邦）**
云端只接收机制 `M` 产出的草图 `s̃=M(s)`，`M` 满足 `(ε_DP,δ_DP)`-差分隐私（RDP 记账）。边端融合 `b_edge = fuse_local(b, s̃_cloud)`。总预算 `ε_total = Σ_k ε_DP^(k)`。个性化误差满足 `err_personal ≤ f(ε_DP) + ε_cal`，且 `f` 单调不增——隐私越强，证书必须越保守。

## 2. 关键算法 伪代码

### IP-127 UBP（User Bayesian Profile）

```python
def update_profile(b, o, motion_model, val_set, alpha, eps_cal):
    b_new = particle_filter(b, o, motion_model)     # 行为/生理/自报多源融合
    Pi_alpha = hpd_set(b_new, alpha)                # 最高密度可信集
    if coverage(Pi_alpha, val_set) < 1 - alpha - eps_cal:
        b_new = widen(b_new, deficit=eps_cal)       # 校准不足则膨胀后验
        Pi_alpha = hpd_set(b_new, alpha)
    return b_new, Pi_alpha
```

### IP-128 PCK（Profile-Conditioned Kernel）

```python
def profile_kernel(b, Pi_alpha, Sigma, C_plus, N, beta):
    samples = sample_profiles(b, N)                 # 情景采样
    boxes = {pi: inner_outer_kernel(pi, Sigma, C_plus) for pi in samples}
    keep = drop_worst_fraction(samples, beta)       # 情景优化去掉 beta 尾部
    K_beta_in  = intersect([boxes[p].K_in  for p in keep])
    K_beta_out = union([boxes[p].K_out for p in samples])
    K0 = intersect([boxes[p].K_in for p in Pi_alpha])   # 对所有可信画像都可行
    return K_beta_in, K_beta_out, K0
```

### IP-129 SAP（Safe Active Profiling）

```python
def safe_active_probe(x, b, K0, A_probe, R_step, R_budget, lambda_r):
    best, best_score = None, -inf
    for u in A_probe:
        if x_next(x, u) not in K0:                  # 硬约束：保底安全
            continue
        r = risk(u, b)                              # 跌倒/不适/牵引超限预测
        if r > R_step or r > R_budget:
            continue
        score = info_gain(b, u) - lambda_r * r      # 信息增益减风险
        if score > best_score:
            best, best_score = u, score
    return best if best is not None else safe_brake(x)
```

### IP-130 PDS（Profile Drift Shield）

```python
def drift_shield(o, b, e_hist, delta_pi, eta):
    e = o - predict_observation(b)
    if cusum(e_hist + [e], h, k):                   # 变点报警
        b = inflate(b, delta_pi)
        policy = {'beta': min(1.0, beta + dbeta),
                  'gait': 'crawl',
                  'T_valid': 0}                     # 立即失效，需重认证
        return b, policy, 'drift_alarm'
    return b, current_policy(), 'ok'
```

### IP-131 PCG（Profile-Conditioned Gait Shield）

```python
def profile_gait_shield(u_nom, x, b, Pi_alpha, K_beta_in, gaits, theta_m):
    # 四足专用：先按支撑多边形裕度从保守到激进排序
    for g in sorted(gaits, key=lambda g: min_support_margin(g, Pi_alpha),
                    reverse=True):
        if min_support_margin(g, Pi_alpha) < theta_m:
            continue                                # 该步态对某些可信用户不安全
        u = qp_filter(u_nom, x, K_beta_in, gait=g, beta=b)
        if u is not None:
            return u, g, 'ok'
    return safe_stop(x, gait='crawl'), 'crawl', 'infeasible_fallback'
```

### IP-132 PPF（Privacy-Preserving Profile Federation）

```python
def private_profile_federation(b, eps_DP, delta_DP, rounds):
    s = profile_sketch(b)
    s_tilde = dp_mechanism(s, eps_DP, delta_DP)     # 高斯/拉普拉斯机制
    b_cloud = fuse_cloud(s_tilde)
    b_edge = fuse_local(b, b_cloud)
    eps_total = rdp_account(eps_DP, rounds)
    return b_edge, eps_total                        # 写入证书 J_π
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| UBP | O(N_p·d) 每步 | O(N_p) | 后验校准、可信集覆盖率 |
| PCK | O(N·T·QP) | O(N·|X|) | 情景覆盖 beta 尾部、内近似 sound |
| SAP | O(|A_probe|·(IG+R)) | O(|A_probe|) | 只在 K_0 内试探、风险预算硬约束 |
| PDS | O(W) 每步 | O(W) | CUSUM 阈值、漂移预算、有效期 |
| PCG | O(|G|·QP) | O(|G|) | 步态支撑裕度、切换安全集 |
| PPF | O(|sketch|+记账) | O(|sketch|) | DP 记账有效、噪声界入证书 |

**正确性定理（Profile-Conditioned Human-Robot Safety Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 画像后验校准，可信集覆盖 `P(π*∈Π_α) ≥ 1-α-ε_cal`；**(A34)** `K_β^in(b) ⊆ K_β(b) ⊆ K_β^out(b)` 且护盾不可行时回退 `u_stop∈𝒳_safe`；**(A35)** 交付延迟内画像漂移 `||π_{t+τ_d}-π_t|| ≤ δ_π` 的概率 ≥ `1-η`；**(A36)** 所有试探动作落在 `K_0` 且累计风险 `≤ R_budget`；**(A37)** DP 记账有效且噪声落在 `ε_DP` 预算内。
则部署后单步安全概率：
```
P_safe ≥ 1 - (α + ε_cal) - η - P(K_β^out \ K_β^in ≠ ∅)
             - P(R_budget exceeded) - P(shield fallback fails)
             - P(ε_DP noise exceeds accounted bound)
```
关键：**画像不确定性进风险预算核、主动探索被 K_0 夹住、漂移被护盾截断、隐私损耗显式计价**。四层任一失守，都不允许把“画像看起来很像”当作“这个人真的能承受”。

## 4. 实验设计 E167–E171

| 实验 | 指标 | 目标 |
|---|---|---|
| E167 画像后验校准 | 可信集覆盖率、ECE | 覆盖率 ≥ 1-α-0.03，ECE ≤ 0.05 |
| E168 画像条件核准确性 | 预测可行 vs 真实可行的 P/R、保守间隙 | P/R ≥ 0.90，间隙 ≤ 12% |
| E169 安全主动画像 | 单位风险信息增益、约束违反率、遗憾 | 增益 ≥ 20%，违反率 ≤ 1%，遗憾有界 |
| E170 漂移检测与安全 | 检测延迟、误报率、疲劳诱发下跌倒率 | P95 延迟 ≤ 2s，误报 ≤ 5%，跌倒率下降 ≥ 80% |
| E171 隐私-效用-安全三角 | `ε_DP` vs 个性化成功率、泄露审计、安全裕度 | `ε_DP≤2` 时保留 ≥ 90% 非隐私性能，无原始画像泄露 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 自报/策略性隐瞒导致先验错误 | 高 | 多源观测 + 可信集膨胀 + 绝不把自报当真值 |
| 后验过度自信 → “伪个性化” | 高 | 校准 + conformal 可信集 + 风险预算 β |
| 主动画像本身造成伤害 | 高 | 硬约束 K_0 + 单步/累计风险预算 + 随时制动 |
| 漂移漏检或检测延迟 | 高 | 多信号 CUSUM + 保守步态回退 + 短证书有效期 |
| 隐私噪声吃掉安全裕度 | 中 | ε_DP 入证书 + 预算封顶 + 隐私-保守度联动 |
| 四足步态切换抖动/失稳 | 中 | 步态滞回 + 切换安全集 + 静稳定 crawl 兜底 |

## 6. 本轮最大风险

**一句话**：用户画像把“关于人的猜测”变成“物理贴身的安全约束”，但画像永远只是后验而非真值，且人会疲劳、受伤、甚至策略性隐瞒；一旦后验在关键能力维上自信却错误，四足机器人会把“个性化”执行成“针对性冒险”（更近的跟随距离、更快的接近速度、更激进的步态），而物理耦合使错误不可逆——因此必须以**通用安全集 K_0 + 风险预算主动画像 + 漂移护盾 + 隐私预算显式入证书**四重护栏，宁可“不个性化”，绝不把用户自报或模型推断当作人的真实能力。

# 第 56 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（UBP×PCK×SAP×PDS×PCG×PPF）

> 承接 v31（IP-115–120 动作-协同层）与第 55 轮语义-接触层（IP-121–126）。本轮新增**用户画像-四足耦合层**，把“个性化”从偏好匹配升级为**带风险预算的人-机联合可行性认证**：
> - **UBP（User Bayesian Profile）**：人的能力包络后验与可信集；
> - **PCK（Profile-Conditioned Kernel）**：画像条件生存核、风险预算核 `K_β` 与通用安全集 `K_0`；
> - **SAP（Safe Active Profiling）**：只在 `K_0` 内做信息增益最大化的主动画像；
> - **PDS（Profile Drift Shield）**：画像漂移变点检测与证书有效期；
> - **PCG（Profile-Conditioned Gait Shield）**：以四足步态支撑裕度换取画像不确定度的鲁棒性；
> - **PPF（Privacy-Preserving Profile Federation）**：DP 画像草图云边联邦，隐私预算入证书。
>
> IP 编号：IP-127~IP-132（共 6 个新增）。

```python
        score = info_gain(b, u) - lambda_r * r
        if score > best_score:
            best, best_score = u, score
    return best if best is not None else safe_brake(x)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| UBP | O(N_p·d) / step | O(N_p) | 后验校准、可信集覆盖率 |
| PCK | O(N·T·QP) | O(N·|X|) | 情景覆盖 β 尾部、内近似 sound |
| SAP | O(|A_probe|·(IG+R)) | O(|A_probe|) | 仅在 `K_0` 内试探、风险预算硬约束 |
| PDS | O(W) / step | O(W) | CUSUM 阈值、漂移预算、证书有效期 |
| PCG | O(|G|·QP) | O(|G|) | 步态支撑裕度、切换安全集 |
| PPF | O(|sketch|+记账) | O(|sketch|) | DP 记账有效、噪声界入证书 |

**正确性定理（Profile-Conditioned Human-Robot Safety Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `P(π*∈Π_α) ≥ 1-α-ε_cal`；**(A34)** `K_β^in ⊆ K_β ⊆ K_β^out` 且护盾不可行时回退 `u_stop∈𝒳_safe`；**(A35)** 检测延迟内漂移 `||π_{t+τ_d}-π_t|| ≤ δ_π` 的概率 ≥ `1-η`；**(A36)** 试探动作 ⊆ `K_0` 且累计风险 ≤ `R_budget`；**(A37)** DP 记账有效、噪声在 `ε_DP` 内。
则：
```
P_safe ≥ 1 - (α + ε_cal) - η - P(K_β^out \ K_β^in ≠ ∅)
             - P(R_budget exceeded) - P(shield fallback fails)
             - P(ε_DP noise exceeds accounted bound)
```
关键：**画像不确定性进风险预算核、主动探索被 K_0 夹住、漂移被护盾截断、隐私损耗显式计价**。

## 6. 本轮最大风险

**一句话**：用户画像把“关于人的猜测”变成“物理贴身的安全约束”，但画像永远只是后验而非真值，且人会疲劳、受伤、甚至策略性隐瞒；一旦后验在关键能力维上自信却错误，四足机器人会把“个性化”执行成“针对性冒险”，而物理耦合使错误不可逆——因此必须以 **K_0 通用安全集 + 风险预算主动画像 + 漂移护盾 + 隐私预算入证书** 四重护栏，宁可“不个性化”，绝不把用户自报或模型推断当作人的真实能力。
