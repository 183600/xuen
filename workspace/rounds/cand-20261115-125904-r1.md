# 第 6 轮 · 想法区（新一轮灵感循环第 1 轮；本轮灵感：「因果推理」×「多任务学习」）

> **基线**：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。LeanGauge → MODGAUGE → ToolGauge → InstructGauge v3 → InstructGauge-WR → InstructGauge-RTDI 的严格退化链全部继承。
> 本轮纪律：**只加「可识别的共享」，不加「想当然的共享」**。因果推理负责回答「证据是否真的足以支撑这一决策」，多任务学习负责回答「哪些经验可以安全地跨任务复用」；任一环节不可用都必须一键退回 RTDI。

## 0. 直觉与动机

**灵感 1（因果推理 → 主动感知本质上是干预，而不是围观）**
直觉：机器人补盲区时把反光镜挪一个角度，这不是「多拍一张照片」，而是对场景做了一次**干预** `do(A=a)`。于是「盲区是否补上了」不应该用「新画面覆盖了多少像素」来衡量，而应该问一个因果问题：**这次干预是否把目标属性 Y 与观测 X 之间的混淆路径切断了？** 看到一块亮斑 ≠ 知道了那是什么物体；角度对了、光照变了、材质相似，都可能让「相关」冒充「看见」。把证据升级为**干预证据**，并用后门/前门准则给出「可识别性」，才能把「看起来补上了」和「因果上补上了」分开。

**灵感 2（多任务学习 → 共享能省样本，但只在因果机制不变处才安全）**
直觉：补盲区任务成百上千，但底层的物理是共享的（光学反射、运动学、遮挡几何）。多任务学习让共享表征在任务间摊销样本，理论上每任务所需样本显著下降。危险在于**负迁移**：如果两个任务的「表面相似」只是训练集里的伪相关（同一批场景、同一种光照），共享模块会把伪相关当成规律，平均指标变好、稀有机制上系统性崩坏。因此正确的共享单位不是「任务」而是「**跨环境不变的因果机制**」：只共享 `P(Y|do(A), φ)` 在各环境下一致的那部分，其余隔离。

**灵感 3（两者耦合 → 因果给出"可共享的边界"，多任务给出"检验边界的统计功效"）**
直觉：因果不变性需要一个划分——哪些模块跨环境不变、哪些随环境漂移；多任务恰好提供了多个任务、多个环境，使这种不变性**可被统计检验**。反过来，多任务若没有因果约束，就极易把共享混淆因子（shared confounder）学成「共同规律」。所以二者是一对：**因果推理定义共享的合法性边界，多任务学习提供识别该边界的样本与统计功效**。耦合后的核心产物是「因果任务分解」：把策略拆成不变因果模块（共享）⊕ 任务/环境特异模块（隔离），再用路由保证「没有通过不变性检验的模块绝不被强制共享」。

## 1. 研究问题（本轮要回答什么）

- **Q1（证据的因果充分性）**：主动感知获得的证据，在什么条件下可以被判定为"因果上足以"支撑补盲决策，而不是仅仅"相关上覆盖"？不可识别时如何优雅降级而不假装闭合？
- **Q2（归因的稳定性）**：把故障归因从"相关性打分"升级为"反事实必要性/充分性"，能否消除模糊边界上的归因振荡，并给出可检验的稳定性界？
- **Q3（共享的合法性）**：多任务共享在什么条件下产生正迁移、在什么条件下产生因果负迁移？能否用不变性检验给出"共享 / 隔离"的可判定规则与样本复杂度收益界？

## 2. 三条设计原则（雏形，正式化见产物区定义 493–507）

**P1 干预即证据（Intervention-as-Evidence），充分性优先于覆盖率**
补盲的每次工具动作都记为干预节点 `do(A=a)`，并附带**因果充分性证书 CSC**：只有当后门/前门条件满足、目标效应的置信区间不跨决策边界时，才判 `IDENTIFIED`；条件不满足则输出 `BOUNDED`（给出上下界）或 `UNIDENTIFIED`。**绝不以像素覆盖率替代可识别性**——覆盖率高但因果不可识别的盲区，状态仍记为"未闭合"。

**P2 反事实归因（Counterfactual Attribution）**
故障归因不比较"哪类证据更相关"，而比较"若把该根因固定为标称值，故障是否还会发生"（必要性 PN）与"若强制该根因发生，故障是否出现"（充分性 PS）。只有当最优根因与次优根因的 PN/PS 差距超过 margin 时才下结论，否则输出 `UNKNOWN` 并退回相关性分类器。这条把"归因"从似然比较变成**干预比较**，直接针对边界振荡。

**P3 因果不变共享（Causally-Invariant Sharing）**
把策略分解为跨环境不变的因果模块 `M_inv`（可共享）与环境/任务特异模块 `ψ_spec`（隔离）。共享判定用不变性检验：`P(Y|do(A), φ_m)` 在任务各环境上的风险梯度方差 ≤ ε 才进入共享池。未通过检验的模块**默认隔离**，由因果任务路由器执行"不共享也是一种动作"。

## 3. 与基线的接口（如何退化）

- 因果图不可用 / 结构不可识别 ⇒ `CSC = UNIDENTIFIED` ⇒ 退回 SpatialCert + 覆盖率口径（v5 行为）；
- 反事实归因不稳定（PN/PS 差距 < margin）⇒ `cause = UNKNOWN` ⇒ 退回 v5 相关性 FaultCert（引理 68 保持）；
- 不变性检验失败或样本不足 ⇒ 路由器全隔离 ⇒ 每任务单任务学习，等价于 v5；
- 共享混淆因子告警 ⇒ 冻结该模块共享、回滚到上一版分解；
- 因果层全失效 ⇒ InstructGauge-RTDI；后续同 v5 → v4 → v3 → ToolGauge → LeanGauge → MODGAUGE 退化链。

## 4. 预期贡献

1. 一个**因果充分性证书**，把"补盲是否完成"从覆盖率问题升级为可识别的干预效应问题，并给出潜伏混淆下带敏感性参数 Γ 的保守界；
2. 一个**反事实故障诊断器**，用 PN/PS 与 margin 消除归因振荡，并证明其分类对残差扰动 Lipschitz 稳定；
3. 一个**因果任务分解 + 不变性路由**方案，给出"共享 / 隔离"的可判定规则，以及正迁移的样本复杂度收益界与负迁移的下界；
4. 一套**共享混淆因子告警**机制，专门检测"平均变好、稀有机制崩坏"的隐蔽负迁移；
5. 一条完整可证伪路径：E493–E512 覆盖因果结构恢复、可识别率、敏感性降级、反事实归因、不变性检验功效、负迁移检测、样本效率、跨机器人迁移与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：因果结论的可靠性完全受限于**因果图的正确性假设**——一旦存在未被建模的潜伏混淆因子（如材质-光照耦合），"可识别"证书会把伪相关误判为因果闭合，而多任务学习又会用共享模块把这个错误在任务间**同步放大**，使负迁移在平均指标上不可见；真正的残余风险不是单个组件失效，而是"错误的因果图 × 看似有效的跨任务共享"这一组合制造出的**系统性假阳性**。

## 2. 形式化定义（要点）

**定义 493（因果场景模型 CSM）**
设结构因果模型 `M_c = (U,V,F,P_U)`，`V = S ∪ A ∪ X ∪ Y`，结构方程：
```
S := f_S(U_S)
A := f_A(S, U_A)                 # 工具动作受场景影响（存在混淆）
X := f_X(S, A, U_X)              # 观测由场景与干预共同决定
Y := f_Y(S, U_Y)                 # 目标属性是场景的函数
```
干预 `do(A=a)` 将 `f_A` 替换为常数 `a`。**关键约定**：工具动作永远是 `A` 上的干预，而不是 `X` 的被动采样；因此"补盲"= 选择一个 `a` 使 `Y` 对 `X` 的识别路径被打开、混淆路径被阻断。

**定义 494（干预证据集与容许性）**
盲区 `b` 的证据集 `E_b = {(a_j, x_j)}`。称 `E_b` 对查询 `Q = P(Y | do(A=a), X)` 是**容许的**，若在 `M_c` 上满足下列之一：
```
后门准则：∃ Z ⊆ E_b 阻断 A 与 Y 间所有后门路径，且 Z 不含 A 的后代
前门准则：∃ 中介 M_e ⊆ E_b，A→M_e→Y 且 A→M_e 无后门、M_e→Y 被 A 完全阻断
```
容许性见证 `W_adm` 是具体的 `Z` 或 `M_e` 及其 d-分离证明。

**定义 495（因果充分性证书 CSC）**
```
certify(b, E_b, M_c):
  if W_adm exists:
      post = effect(Y, do(A=a), E_b)            # 调整/前门估计
      [l,u] = post.interval(1-α)
      if (l > τ) == (u > τ):  κ = IDENTIFIED    # 区间整体在决策边界 τ 一侧
      else:                   κ = BOUNDED
  else:
      [l,u] = partial_bounds(Y, do(A=a), E_b, Γ) # 敏感性界
      κ = BOUNDED  (Γ=1 时仍无法容许则为 UNIDENTIFIED)
  CSC = (b, E_b, G_c, W_adm, κ, [l,u])
```
补盲闭合判据：`Closed(b) ⇔ κ = IDENTIFIED ∧ ([l,u] 不跨 τ)`。**覆盖率不参与闭合判定**，只作为工具选择的启发式。

**定义 496（敏感性界 SensitivityBounder）**
对未观测混淆强度 `Γ`，定义
```
Γ = max_{u} [ P(Y|do(A), u) / P(Y|do(A'), u) ] / [ P(Y|A) / P(Y|A') ]
```
在 `Γ` 界下给出 `P(Y|do(a),X)` 的极值上下界 `[l_Γ, u_Γ]`（可交换性扰动模型）。`Γ` 可由留出环境上的可观测代理估计，估计失败时取 `Γ=Γ_max`（最保守）。

**定义 497（反事实故障证书 CF-Cert）**
对 SpatialCert violation `v`，在证据 `E` 下按 Pearl 三步：
```
1) Abduction:  给定 E，推断外生噪声 U 的后验 P(U|E)
2) Action:     对每个候选根因 c∈{SEN,MOD,EXE,SEM}，
               分别施加 do(cause=c) 与 do(cause=nominal)
3) Prediction: 计算反事实残差 r_cf，得到
               PN(c) = P(v 不发生 | E, do(cause=nominal))
               PS(c) = P(v 发生   | E, do(cause=c))
```
```
CF-Cert(v) = (vid, c*, PN(c*), PS(c*), E, rpid(c*))
c* = argmax_c  [ PN(c) + PS(c) ]
判定规则：若 PN(c*) - PN(c_2nd) < margin_attribution
          ⇒ c* := UNKNOWN（退回 v5 相关性分类器）
```

**定义 498（因果机制签名与机制散度）**
任务 `i` 在环境族 `𝓔_i` 上的因果机制签名
```
ς_i = (φ_1..φ_k, div_i),  div_i = max_{e,e'∈𝓔_i} D_KL( P(Y|do(A),φ) ‖ P_{e'}(Y|do(A),φ) )
```
`div_i` 度量任务内机制随环境漂移的程度，用于判定"该任务是否值得做因果分解"。

**定义 499（因果不变性与不变性得分）**
模块 `m`（参数 `φ_m`）在任务 `i` 的环境族上**因果不变**，若
```
∀ e,e' ∈ 𝓔_i :  P_e(Y | do(A), φ_m) = P_{e'}(Y | do(A), φ_m)
```
等价的实用判据（IRM 型风险梯度）：
```
Inv(m) = Var_{e∈𝓔_i}[ ∇_φ R_e(m) ],   不变 ⇔ Inv(m) ≤ ε
```

**定义 500（因果任务分解 ITF）**
策略分解 `π_θ = (⊕_{m∈M_inv} φ_m) ⊕ ψ_spec`，训练目标
```
L(θ) = Σ_i L_task^i(θ) + λ · Σ_{m} Inv(m) + μ · Σ_i ‖θ_i‖_2
s.t.  m ∈ M_inv ⇔ Inv(m) ≤ ε
```
其中 `M_inv` 为跨任务共享的因果不变模块集合，`ψ_spec` 为逐任务/逐环境隔离模块。

**定义 501（因果任务路由器 CTR）**
```
CTR(task=i, env=e):
  m = match_mechanism(i)                       # 按 ς_i 匹配候选模块
  if Inv(m) ≤ ε  ∧  SCA(m)=0:
      return M_inv[m]                          # 安全共享
  return ψ_spec[i] or ψ_new                    # 默认隔离（不共享也是动作）
```
共享块与隔离块必须接口类型兼容（`tools` 与 `ψ_post` 不变），否则强制隔离。

**定义 502（共享混淆告警 SCA）**
对共享模块 `m`，在留出环境 `e_hold` 与稀有子群 `g` 上监控
```
SCA(m) = 1  ⇔  ( R_{e_hold}(m) - R_{train}(m) > δ_drift )
            ∨ ( max_g R_g(m) - mean_g R_g(m) > δ_subgroup )
```
触发后冻结 `m` 的共享、回滚到上一版分解，并对相关任务切到隔离模块。

**定义 503（CGM-9C 闭环扩展）**
```
W:      感知（含 WristCam、环境/材质代理变量）
R:      推理（Hypothesis + Γ_parse）
C:      契约规划（IAC + Kinematic-Loop + RT-CVC-TaskModel）
E:      执行（rt-chunk，PP_C 可抢占，实时 SpatialCert）
Spatial-C: 时空一致性（v5 SpatialCert）
Causal-V: 因果验证（CSC 可识别性 + 敏感性界）
Diag_cf:  反事实诊断（CF-Cert）
MT-Route: 因果任务路由（Inv 检验 + SCA 门控）
U:      更新（Dbox + 主张绑定 + 因果任务分解统计）
```

**定义 504（因果能力闭包扩展）**
在 v5 能力闭包 `tools(ι) ⊆ T₀` 之上，新增证据侧约束：
```
interventions(E_b) ⊆ A₀             # 干预动作也只能取自预注册工具集
             ∧ measured(E_b) ⊆ Φ₀   # 只允许预注册观测量进入 CSC
```
防止"因果推理"通过构造新变量绕过能力闭包。

**定义 505（因果分解的退化映射）**
```
Degrade:
  ¬CSC.admissible            ⇒ SpatialCert 覆盖率口径 (v5)
  Γ 不可估                   ⇒ Γ=Γ_max, κ=BOUNDED, 最保守策略
  PN/PS margin 不足          ⇒ cause=UNKNOWN ⇒ v5 相关性 FaultCert
  Inv 检验样本不足           ⇒ M_inv=∅ ⇒ 全隔离（单任务，v5）
  SCA 告警                   ⇒ 回滚分解 + 隔离涉事任务
  CSM 结构学习失败           ⇒ 整个因果层旁路 ⇒ InstructGauge-RTDI
```

**定义 506（因果任务迁移声明）**
任务族 `𝒯` 的因果迁移矩阵
```
T_{ij} = E_{e∈𝓔_j}[ R_j(π 用 i 的 M_inv 初始化) - R_j(π 单任务) ]
```
`T_{ij} < 0` 即因果负迁移。SCA 的职责是尽量在部署前把 `T_{ij}<0` 的任务对移出共享池。

**定义 507（CGM 主张绑定）**
每个补盲主张 `claim = (b, Closed(b), CSC, CF-Cert, module_used)` 必须同时绑定：
- 因果闭合见证（`W_adm` 或 `Γ` 界）；
- 归因的 PN/PS 与 margin；
- 使用的共享/隔离模块以及其 `Inv` 与 `SCA` 状态。
缺任一项的主张降级为 `provisional`，不参与训练集回灌。

```python
# IP-340 CSM：干预、容许性、效应估计
class CausalSceneModel:
    def __init__(self, graph, fitter, gamma=1.0):
        self.G = graph            # DAG: S->A, S->X, A->X, S->Y
        self.fit = fitter         # 结构方程 / 条件分布估计器
        self.Gamma = gamma

    def intervene(self, a):
        return self.G.do({'A': a})

    def admissible(self, Y, X, A, E):
        """后门优先，失败再试前门；返回 (kind, witness) 或 None"""
        for Z in subsets(E):
            if self.G.blocks_backdoor(A, Y, Z) and not self.G.has_descendant(Z, A):
                return ('backdoor', Z)
        for Me in subsets(E):
            if self.G.frontdoor_ok(A, Y, Me):
                return ('frontdoor', Me)
        return None

    def effect(self, Y, A, E, a):
        kind, W = self.admissible(Y, None, A, E)
        if kind == 'backdoor':
            return self.fit.adjust(Y, A, a, W)          # Σ_W P(Y|a,W) P(W)
        return self.fit.frontdoor(Y, A, a, W)

    def partial_bounds(self, Y, A, E, gamma):
        return self.fit.sensitivity_bounds(Y, A, E, gamma)

# IP-341 / IP-342：因果充分性 + 敏感性
class CausalSufficiencyCertifier:
    def __init__(self, csm, alpha=0.05, tau=0.5):
        self.csm, self.alpha, self.tau = csm, alpha, tau

    def certify(self, b, E_b):
        adm = self.csm.admissible(b.Y, b.X, b.A, E_b)
        if adm is None:
            l, u = self.csm.partial_bounds(b.Y, b.A, E_b, self.csm.Gamma)
            return CSC(b, E_b, self.csm.G, None, 'BOUNDED', (l, u))
        kind, W = adm
        post = self.csm.effect(b.Y, b.A, E_b, b.a)
        l, u = post.interval(1 - self.alpha)
        kappa = 'IDENTIFIED' if (l > self.tau) == (u > self.tau) else 'BOUNDED'
        return CSC(b, E_b, self.csm.G, (kind, W), kappa, (l, u))

# IP-343：反事实故障诊断
class CounterfactualFaultDiagnoser:
    def __init__(self, csm, margin=0.1):
        self.csm, self.margin = csm, margin

    def diagnose(self, v, evidence):
        scores = {}
        for c in ('SEN', 'MOD', 'EXE', 'SEM'):
            pn = self._necessity(v, c, evidence)   # P(v̄ | do(c=nominal), E)
            ps = self._sufficiency(v, c, evidence) # P(v  | do(c=c), E)
            scores[c] = (pn, ps)
        ranked = sorted(scores.items(), key=lambda kv: kv[1][0] + kv[1][1], reverse=True)
        c1, (pn1, ps1) = ranked[0]
        pn2 = ranked[1][1][0]
        cause = c1 if (pn1 - pn2) >= self.margin else 'UNKNOWN'
        return CF_Cert(v.id, cause, pn1, ps1, evidence,
                       rp_id=cause if cause != 'UNKNOWN' else None)

    def _necessity(self, v, c, evidence):
        # abduction 后对 cause 施加 do(cause=nominal) 的预测
        U = self.csm.abduct(evidence)
        return self.csm.predict_counterfactual(v, U, do={c: 'nominal'})

    def _sufficiency(self, v, c, evidence):
        U = self.csm.abduct(evidence)
        return self.csm.predict_counterfactual(v, U, do={c: c})

# IP-344 / IP-345 / IP-346：因果分解 + 路由 + 告警
class InvariantTaskFactorizer:
    def __init__(self, tasks, env_splits, eps=1e-3, lam=1.0):
        self.tasks, self.envs, self.eps, self.lam = tasks, env_splits, eps, lam

    def invariance_score(self, module, task):
        grads = [self._risk_grad(module, e) for e in self.envs[task]]
        return float(np.var(grads, axis=0).sum())

    def factorize(self):
        self.M_inv, self.psi_spec = {}, {}
        for task in self.tasks:
            for m in self._candidate_modules(task):
                if self.invariance_score(m, task) <= self.eps:
                    self.M_inv[m.name] = m                # 可共享
                else:
                    self.psi_spec[(task, m.name)] = m     # 隔离
        return self.M_inv, self.psi_spec

    def train(self):
        loss = sum(self._task_loss(t) for t in self.tasks)
        loss += self.lam * sum(self.invariance_score(m, t)
                               for (t, _), m in self.psi_spec.items())
        return self._step(loss)

class CausalTaskRouter:
    def __init__(self, itf, sca, eps=1e-3):
        self.itf, self.sca, self.eps = itf, sca, eps

    def route(self, task, env):
        m = self._match(task)
        if self.itf.invariance_score(m, task) <= self.eps and not self.sca.alarm(m):
            return self.itf.M_inv[m.name]
        return self.itf.psi_spec.get((task, m.name)) or self._new_isolated(task, env)

class SharedConfounderAlarm:
    def __init__(self, delta_drift=0.05, delta_subgroup=0.10):
        self.dd, self.ds = delta_drift, delta_subgroup

    def alarm(self, m):
        return (self._holdout_gap(m) > self.dd) or (self._subgroup_gap(m) > self.ds)

# IP-347 / IP-348：CGM-9C 主闭环
def causalgauge_mtl(M, s, ell=None):
    # 1) W/R/C/E 同 v5（略）
    C = plan_and_commit_realtime(M, s, ell)

    # 2) Causal-V：证据是否因果充分
    csc = M.csc.certify(s.blind_spot, s.evidence)
    if csc.kappa == 'UNIDENTIFIED':
        # 不假装闭合；追加一次预注册干预后重估
        a = M.tools.select_intervention(s.blind_spot, budget=M.budget_left(s))
        s.evidence.append(M.env.intervene(a))
        csc = M.csc.certify(s.blind_spot, s.evidence)
    if csc.kappa != 'IDENTIFIED':
        return provisional_claim(s, csc)          # 降级：不进入训练集

    # 3) Diag_cf：反事实归因（仅当发生 violation）
    fault_certs = []
    for v in M.cvc.take_violations():
        fc = M.cfd.diagnose(v, s.evidence)
        if fc.cause == 'UNKNOWN':
            fc = M.fault_diagnoser.diagnose(v, C, s.tf_seq, s.iota)  # v5 退回
        fault_certs.append(fc)

    # 4) MT-Route：选择共享或隔离模块
    module = M.ctr.route(task=s.task_id, env=M.env.signature())
    if M.sca.alarm(module):
        module = M.ctr.isolate(s.task_id)         # 告警即隔离
    action = module.policy(C, s.iota)

    # 5) 执行 + 证书
    M.env.apply(action)
    cert = generate_spatial_cert(C, s.tf_seq, M.epsilon_vis)
    claim = bind_claim(s, Closed=Closed(csc), csc=csc,
                       cf=fault_certs, module=module,
                       inv=module.inv_score, sca=module.sca_flag)
    M.pgraph.record_execution(s.graph, C, cert, fault_certs=fault_certs)
    return claim
```

## 4. 推导

**引理 69（干预充分性 ⇒ 补盲闭合可靠性）**
若 `CSC(b)` 的容许性见证 `W_adm` 正确且 `κ=IDENTIFIED`、效应区间 `[l,u]` 不跨决策边界 `τ`，则在任意满足 `M_c` 的分布下，补盲决策与 `Y` 的真实状态一致。证明：后门/前门准则是 `P(Y|do(A))` 可识别的充分条件；区间不跨 `τ` 给出确定性判定；容许性保证无其他开放混淆路径。

**引理 70（潜伏混淆下的保守性）**
若真实混淆强度为 `Γ*` 而算法使用 `Γ ≥ Γ*`，则 `partial_bounds` 给出的 `[l_Γ,u_Γ] ⊇ [l_{Γ*},u_{Γ*}]`，且 `κ=BOUNDED` 时绝不输出"已闭合"。证明：敏感性界关于 `Γ` 单调扩张；保守界包含真实效应，故不会产生假阳性闭合。推论：`Γ_max→∞` 时退化为"永不判定闭合"，即 v5 保守策略。

**引理 71（反事实归因的稳定性）**
设残差扰动 `‖δ‖ ≤ ε` 使 PN/PS 变动不超过 `L·ε`（`L` 为 SCM 结构方程的 Lipschitz 常数）。若最优与次优的 PN 差距 `≥ margin + 2Lε`，则 `CF-Cert` 的根因标签不变。证明：三角不等式给出每个 PN 的扰动界，margin 条件保证排序不变；否则算法已回退 `UNKNOWN`，故无振荡输出。

**引理 72（因果负迁移下界 ⇒ 隔离最优）**
设模块 `m` 在任务 `i` 的环境上最优预测器相差 `div_i > 0`。则任何被强制共享的 `m` 在任务 `i` 上的近似偏差 `≥ div_i/2`，即 `R_i(shared) ≥ R_i(isolated) + Ω(div_i)`。证明：共享模块必须同时拟合所有环境，当各环境最优解不一致时，任何单点的期望风险至少是机制散度的一半（IRM 的近似偏差下界）；故当 `Inv(m)>ε` 时隔离严格不劣。

**引理 73（正迁移样本复杂度收益）**
设 `n` 个任务共享 `k` 个不变因果模块、每任务样本 `m`，共享模块总维数 `d_m`。则在标准 MTL 泛化界下，每任务目标风险满足
```
R_i^MTL ≤ R_i^single - Ω( sqrt(d_m/(n·m)) ) + O(k/m)
```
即共享带来的超额风险下降随任务数 `n` 增大，而每个新增不变模块仅引入 `O(1/m)` 的估计开销。证明：共享表征把 `k` 个模块的样本从 `m` 变为 `n·m`；对不变模块，跨任务聚合不改变其最优解（定义 499），故只降方差、不引偏差。**前提**：`Inv(m)≤ε`，否则引理 72 的负迁移项占优。

**引理 74（因果分解的可识别性）**
在因果机制签名 `ς_i` 给定时，`M_inv / ψ_spec` 的划分由不变性检验唯一确定（至多相差保持 `P(Y|do(A),φ)` 的机制保持变换）。证明：不变性得分 `Inv(m)` 是模块的分布函数；满足 `Inv≤ε` 的模块集合是唯一的；机制保持变换不改变该集合，故划分唯一到该等价类。

**引理 75（共享混淆告警的检测条件）**
若共享混淆导致稀有子群风险抬升 `Δ_g > δ_subgroup` 或留出环境漂移 `Δ_e > δ_drift`，则 `SCA(m)=1`。反之，若所有子群与环境风险差均 `≤ δ`，则不能告警（可能漏检小于阈值的负迁移）。证明：SCA 是上述事件的并；其检出力等于对超过阈值偏差的敏感性，漏检界由阈值 `δ_drift,δ_subgroup` 直接给出。**注意**：这是阈值型检测，不是万无一失的因果检验。

**引理 76（退化等价性扩展）**
```
CSM 不可用           ⇒ 因果层旁路，等价 InstructGauge-RTDI（引理 68 保持）
κ≠IDENTIFIED          ⇒ 仅覆盖率口径，等价 v5 SpatialCert
PN/PS margin 不足     ⇒ cause=UNKNOWN，等价 v5 相关性 FaultCert
Inv 检验失败/样本不足 ⇒ M_inv=∅，CTR 全隔离，等价单任务 v5
SCA 告警              ⇒ 回滚分解，等价上一版 v5
```
证明：逐项对照定义 505，旁路后各模块输入输出与 v5 一一对应。

## 8. 本轮最大风险

**一句话**：因果充分性证书的可靠性完全依赖**因果图与无未观测混淆假设**——一旦材质-光照-遮挡存在未建模的潜伏耦合，"可识别"会把伪相关判成因果闭合，而因果不变共享又把这个错误沿任务族同步复制，使负迁移在平均指标上不可见；因此最大风险是"**错误因果图 × 看似通过检验的共享**"共同制造的**系统性假阳性**，而非任一单点组件失效；缓解手段是把 `Γ` 敏感性界与 SCA 子群监控设为**部署前硬门**，任何 `BOUNDED/UNKNOWN/告警` 一律禁止回灌训练集。
