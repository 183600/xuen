# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「人机协作」×「人机交互」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**内静外响、接地解释、安全否决**。v9 把「模块失效」做成静默的中立元注入——对内是优雅的代数退化，对外却制造了危险的认知差：人类队友看到的仍是"正常运转的机器人"，而系统内部早已降级。人机协作的核心风险不是机器能力不足，而是**能力变化不可见**。本轮把 v9 的内部契约"抬升"到人类可读的联合承诺层，用可证明接地的解释通道把每一次能力变化外化，并用安全否决把人类权威约束在证书包络内。

## 0. 直觉与动机

**灵感 1（人机协作 → 联合承诺账本 JCL）**
直觉：人和机器人组队，本质是相互持有承诺——"我把杯子在 t 前送到你手里，你保持通道畅通"。v9 的模块契约 κ_m 是机器内部承诺；社会层承诺缺失。关键洞察：v9 的中立元注入是**静默**的（行为等价、仅日志可区分），但人类队友既看不到日志也不读中立元——承诺一旦因降级而无法兑现，若不以显式事件**重协商**，人类会基于过时的心智模型继续决策。核心创新：**联合承诺账本（JointCommitmentLedger, JCL）**：承诺 C_j=(债务人, 债权人, 谓词, 截止期, 范围, 释放条件)，用**承诺-证书蕴含**判定可证性 W(C,t,d)∈{guaranteed, probable, unprovable}，降级只会单调收缩可证集；当 W 由 guaranteed 跌破 probable 时系统必须**主动重协商**而非静默放弃。纪律：**内静外响律**——内部退化可静默，但触及活跃承诺的退化必须外化为人类可读事件。

**灵感 2（人机交互 → 接地解释通道 GEC）**
直觉：多数"机器人解释"是事后 LLM 自由发挥，最危险的是**幻觉式解释**——机器人说"我减速是因为看到人"，实际是因为 SLAM 风险；这样的人机交互会腐蚀信任校准。核心创新：**接地解释通道（GroundedExplanationChannel, GEC）**：解释不是自然语言生成问题，而是**携带证明的断言**。每条解释 E=(l, 𝒞, π)：l 是表层话术，𝒞 是生成它的证书/证明对象，π 是投影映射。接地可靠性要求 ⟦l⟧ ⊆ facts(𝒞)——**无证书支撑的话不许说**。幻觉在此定义下是"l 含 𝒞 不蕴含的事实"，由发射前的蕴含检查器拦截，故**构造性零幻觉**。澄清查询再受**交互预算** B_int 约束、按期望信息价值 EVI 排序，避免"提问风暴"骚扰人类。

**灵感 3（人机协作 → 权责仲裁器 AAA）**
直觉：协作最脆弱的瞬间是控制权交接，以及人类下达不安全指令——人类可能没意识到机器人已降级（K_eff=1），其指令可能超出当前能力包络。核心创新：**可调自主权责仲裁器（AdjustableAutonomyArbiter, AAA）**：控制权令牌 A∈{robot, human, shared}，两阶段交接（request/grant，超时安全停驻回退），且**安全否决权不可让渡**——无论谁发指令都必须穿过 M₀ 与证书包络检查；人控时机器人进入**守护模式**（M₁–M₃ 让权、M₀ 保留否决）。关键性质：不存在"机器人静默覆盖人类指令"的路径——任何否决/覆盖都附带接地解释。

## 1. 研究问题（轮次升级版）

- **Q1（承诺可证性）**：在何种证书/降级条件下，机器人的证书束**蕴含**其对人类的承诺？降级是否单调收缩可证承诺集？主动重协商能否消除"意外失约"？
- **Q2（解释接地）**：如何在有限延迟与交互预算下同时保证解释的**可靠性**（无无据断言）与**完备性**（每个影响承诺的事件都可解释）？受限解码 + 蕴含校验能否做到构造性零幻觉？
- **Q3（权责安全）**：如何设计权威转移，使 (i) M₀ 在任意权威分配下不变，(ii) 人类永不被静默覆盖，(iii) 交接无死锁且无控制抖动？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 内静外响律（Silence Inside, Loud Outside, JCL）**
内部模块退化可注入中立元保持静默（v9）；但若退化改变任一活跃承诺的可证性 W，JCL 必须发射且仅发射一个接地重协商事件。静默只允许存在于"不被承诺引用"的内部状态上。

**P14 解释接地律（Grounded Explanation, GEC）**
每条对外话术必须绑定证书引用；⟦l⟧ ⊆ facts(𝒞)（可靠性）；每个承诺事件在 ≤1 控制周期（反应式）或 ≤1s（慎思式）内可被解释（完备性）；澄清查询受预算 B_int 约束并按 EVI 优先。

**P15 安全否决律（Safety Veto, AAA）**
M₀ 硬检查与证书包络在任意权威分配下不变；人类权威仅在包络内有效；任何否决/覆盖都携带接地解释并留痕；交接为两阶段、超时安全停驻、无死锁。

## 3. 与基线的接口（如何退化）

- JCL 失效 ⇒ 承诺账本置空（承诺并运算单位元），承诺仅按 v9 内部契约跟踪，控制等价 v9；
- GEC 失效 ⇒ 退化为 v9 固定 ER 语气模板（"静音解释"），控制不受影响，但保留一次性降级横幅（不可完全静默）；
- AAA 失效 ⇒ 权威固定为 robot-only（全自主），人类仅保留硬件急停，控制等价 v9；
- v9 ACMD 失效 ⇒ 回退 Level-1（AC→K_eff=1 / MW→手写网关 / ID→全激活），等价 v8；
- v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入，等价 v7；全失效 ⇒ v7 → v6。
- 关键：JCL/GEC 是控制流的**只读侧信道**（除 AAA），故三者注入中立元后控制路径与 v9 逐位一致（引理 92），至多多出**一条**降级横幅事件。

## 4. 预期贡献

1. **承诺-证书蕴含**框架：把"能力退化"翻译成"人类可读的承诺重协商"，用可证性单调性给出"主动失约预警"的形式化定义；
2. **接地解释通道**：把解释从生成问题变为证明携带问题，给出构造性零幻觉的设计与验证；
3. **安全否决仲裁**：在可调自主性下保持 M₀ 不变式与"人类不被静默覆盖"，两阶段交接无死锁；
4. **内静外响的双层退化**：内部中性元 + 外部显式事件，二者由引理 92 桥接；E571–E590 覆盖承诺可证、解释接地、否决安全、交接与端到端人机任务。

## 5. 本轮最大风险

**一句话**：把人类引入安全关键回路，等于用"有界、可度量"的自主退化风险去交换"无界、不可度量"的人类响应时延与不可靠性——若在承诺 warrant 下降时同步阻塞等待人类澄清，系统会在最需要确定性的时刻依赖最不确定的仲裁者，协作可能把可控的静默退化变成不可控的人类等待（或人类误操作）。

**新增定义 540（联合承诺 JointCommitment）** C_j=(a,b,p,τ_j,S_j,ρ_j)：债务人 a 承诺在截止期 τ_j 前，在范围 S_j 内使谓词 p 成立，债权人 b 据此规划；ρ_j 为可显式释放的条件。状态格：proposed → active → {discharged, released, breached}，终态迁移不可逆且必须留痕。

**新增定义 541（承诺账本 JointCommitmentLedger）** 维护承诺集合与其状态迁移的单调格。操作 propose/activate/discharge/release/breach；**任何终态或弱化迁移都产生一条事件**（内静外响律 P13）。空账本是承诺并运算的单位元。

**新增定义 542（承诺可证性 Warrant）** 在时刻 t、降级级 d 下：
```
W(C,t,d) = G  若 𝒞(t,d) ⊨ □_{[t,τ_j]} p  对包络内所有计划成立（强可证）
         = P  若 Pr[𝒞(t,d) ⊨ □ p] ≥ 1−δ（统计可证）
         = U  否则（不可证）
```
𝒞(t,d) 为降级 d 下的可用证书束（K_eff、模块 active 集决定其大小）。

**新增定义 543（重协商事件 RenegotiationEvent）** W 跨阈（G→P、P→U 或反向恢复）或承诺进入终态时发射的事件：(C_j, W_old, W_new, cert_ref, reason)。带迟滞（跨阈需连续 2 周期确认）以防抖，保证每事件可被 GEC 接地解释。

**新增定义 544（接地解释 GroundedExplanation）** E=(l,𝒞,π)：l 由声明槽文法生成，每个命题槽强制绑定 𝒞 的字段；π 给出槽到证书字段的投影。解释对象可为重协商事件、否决事件或人类提问。

**新增定义 545（解释接地可靠性 GroundingSoundness）** 要求 ⟦l⟧ ⊆ facts(𝒞)。**幻觉** ≜ ∃f∈⟦l⟧ 使 f∉facts(𝒞)。发射前由蕴含检查器判定；不满足则拒绝发射并回退到安全模板。

**新增定义 546（澄清查询与交互预算 ClarificationQuery & Budget）** q=(Amb,Readings,EVI)：当意图/场景歧义集的期望信息价值 EVI(q)≥τ_query 且预算允许时发起。预算 B_int 每窗口重置，查询带去抖与优先级；EVI 估计"该答案对当前承诺可证性的提升"。

**新增定义 547（权责仲裁 AuthorityArbitration）** 执行瓶颈 exec(cmd,A) 仅当 cmd∈ℰ(𝒞_t,M₀) 才执行；否则返回 Veto(cmd,reason) 并发射接地解释。人类与机器人命令同源通过该瓶颈，故 M₀ 与权威分配无关（引理 89）。

**新增定义 548（守护模式 GuardianMode）** A=H 时置 guardian=1：在软层 M₁–M₃ 上让权给人类偏好，在 M₀ 与证书包络上保留否决；退出人控时清除。

**新增定义 549（两阶段交接 TwoPhaseHandover）** 交接 h=(request, grant, commit)，带超时 T_ho；超时则安全停驻（速度指数衰减）并把权威置回 R。FSM 无环等待（引理 90），交接时间 ≤ T_ho + t_stop。

# IP-357 JointCommitmentLedger：联合承诺账本
@dataclass
class Commitment:
    debtor: str; creditor: str; pred: Callable; deadline: float
    scope: frozenset; release_cond: Callable
    state: str = 'proposed'            # proposed|active|discharged|released|breached

class JointCommitmentLedger:
    G, P, U = 2, 1, 0
    def __init__(self, gec):
        self.gec = gec
        self.book = {}                  # cid -> Commitment
        self._last_w = {}               # cid -> W（迟滞用）
        self._cross = defaultdict(int)

    def _warrant(self, c, cert_bundle, d):        # 定义 542
        if self._provable(c, cert_bundle, strong=True):  return self.G
        if self._provable(c, cert_bundle, strong=False): return self.P
        return self.U

    def cycle(self, cert_bundle, d):
        for cid, c in self.book.items():
            if c.state not in ('proposed', 'active'):
                continue
            w = self._warrant(c, cert_bundle, d)
            w0 = self._last_w.get(cid, self.G)
            if w < w0:                            # 引理 87：降级单调收缩
                self._cross[cid] += 1
                if self._cross[cid] >= 2:         # 跨阈迟滞，防抖
                    self._emit_renegotiation(c, w0, w, cert_bundle)   # 定义 543
                    self._cross[cid] = 0
                    if w == self.U and c.release_cond():
                        self._transition(c, 'released', 'capability_lost')
            else:
                self._cross[cid] = 0
            self._last_w[cid] = w

    def _emit_renegotiation(self, c, w0, w1, cert):
        ev = RenegotiationEvent(c, w0, w1, cert.ref(),
                                reason=('degrade' if w1 < w0 else 'recover'))
        self.gec.explain(ev, cert)            # 外响：必带接地解释


# IP-358 GroundedExplanationChannel：接地解释通道
class GroundedExplanationChannel:
    def __init__(self, grammar, verifier, budget, tau_query=0.2):
        self.grammar = grammar                # 声明槽文法（每槽绑证书字段）
        self.verify = verifier                # ⟦l⟧ ⊆ facts(𝒞)
        self.budget, self.tau_query = budget, tau_query

    def explain(self, event, cert):
        facts = cert.facts()                  # 定义 544
        l = self.grammar.fill(event, facts)   # 槽强制绑定，无自由发挥
        if not self.verify(l, facts):         # 定义 545 最后闸门
            l = self.grammar.safe_template(event)   # 回退已证模板
        return GroundedExplanation(l, cert, self.grammar.projection)

    def maybe_query(self, ambiguity, now):    # 定义 546
        for q in sorted(ambiguity, key=lambda q: -q.evi):
            if q.evi < self.tau_query: break
            if not self.budget.take(now): break
            return q

## 4. 推导

**引理 87（承诺可证性对降级的单调性）** 设降级格 (D,⪯)，d₁⪯d₂（d₂ 退化更重）。对任一承诺 C 与固定时刻 t，W(C,t,d₂) ⪯_W W(C,t,d₁)。证明：d 越重 ⇒ 可用证书束 𝒞(t,d) 越小（K_eff 收缩、模块被 v^⊥ 替换，可用谓词集单调减少）；W 定义为"𝒞 中存在 p 的证明"，证明集收缩只能使 G→P→U，不可能反向。故 W 对 d 单调不增。推论：在每次降级跃迁处检查 W，即可在承诺由 G 跌落（尚可兑现的窗口）时提前重协商。∎

**引理 88（构造性零幻觉解释）** 若话术 l 由声明槽文法生成、每个命题槽强制绑定 𝒞 的字段，且在发射前经蕴含检查 ⟦l⟧⊆facts(𝒞)，则幻觉率恒为 0。证明：槽文法使 l 的每个命题对应一个证书字段；未绑定字段的命题无法被生成；校验器作为最后闸门拒绝不满足蕴含的 l。故不存在无据断言，改述自由度被限制在已证模板集合内。∎

**引理 89（安全否决不变式）** 任意 A∈{R,H,S}，exec(cmd,A) 仅当 cmd∈ℰ(𝒞_t,M₀) 才调用 execute；故 M₀ 安全不变式与权威分配无关。证明：AAA 位于"命令→执行"的唯一瓶颈，人类与机器人命令同源通过；veto 返回带解释的拒绝而非执行。∎

**引理 90（两阶段交接无死锁无活锁）** 交接 FSM 有限状态、每次 request 带超时 T_ho，超时迁移到安全停驻再置 A=R；grant/commit 仅在双方 ready 时达成，无环等待。故有限步内进入稳定权威，交接时间 ≤ T_ho + t_stop。∎

**引理 91（交互预算稳定性 / 无提问风暴）** 查询发射率受每窗口 B_int 与 EVI 阈值 τ_query 双重约束并带去抖；故单位时间查询数 ≤ B_int，有限，无提问风暴；与 v9 引理 85 同构。∎

**引理 92（v9 逐位等价退化）** 将 JCL 空账本、GEC 静音模板、AAA 权威≡R 作为中立元注入，则控制路径与 v9 ACMD 逐位一致，仅新增至多一条降级横幅事件。证明：JCL/GEC 对控制流只读（仅日志/语音），不改变任何模块输出；AAA 在 A=R 时退化为 M₀+包络直通，而 v9 本已强制 M₀；故执行序列相同。∎
