# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多机器人协作」×「云边协同」）

> R69 让单个机器人学会了「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配多模态策略显式表达歧义，用主动多模态交互（看/问/触）去消解，解不了才退回 R68 的保守铁律。但 R69 隐含了三个单机假设：**(1) 只有一个信念主体**——「我」的歧义只由「我」的观测与「我」的提问解决；**(2) 被问者就在身边、即时、独立**——人的回答像一个零延迟、零相关的神谕；**(3) 消歧所需算力免费且本地**——多步流采样、流似然、LLM 解码都在本机瞬间完成。
>
> 真实部署同时违反这三条：现场是**一群机器人**，最有用的知识可能在**别的机器人**或**云端**；云边之间横着**延迟、带宽与信任**；而全队往往共享同一个模型、同一次云更新——于是「很多机器人意见一致」可能只是**同一个幻觉的回声**。R69 的证据纪律（k 个正交源一致）在单机里成立，在机队里恰恰最容易被**共因相关**击穿。
>
> 本轮两个灵感正好补上两块：
> - **多机器人协作**：把不确定性从「单信念」扩展到「分布式信念」——我不知道的，同伴可能知道；但同伴的知识可能陈旧、与我不独立、甚至被投毒。**共识是双刃剑**。
> - **云边协同**：把消歧算力放到「延迟 × 信任 × 权威」的阶梯上——正确的问法不再是「这条信息值多少」，而是「**这条信息到达时还成不成立**」。**知识的价值有时限**。
>
> 核心命题：**把 R69 的 epistemic 再拆成 (local, social)，并用「信任 × 时限 × 独立性」三重门控；信息动作沿云边阶梯路由；共识只作为似然、永不覆盖安全笼。R69 是本方案在「单机、零延迟、完美独立同伴」边界上的严格退化。** 命名 **NEXUS-RAS**（Networked Epistemic eXchange under Uncertainty & Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**谁的知识可信，答案到达时还成立吗**」——不确定性不只是刹车与提问，也是**一份带时限与出处的证据账本**。

## 0. 直觉与动机

**灵感 1（多机器人协作 → 不确定性是分布式的，还多了一类「关系型」无知）**
直觉：单机时 U_epi 是「我不知道，因为观测不足」；机队里它分裂成两种——「**我**的观测不足，但**同伴**可能看得见」（专长/视角互补），和「**谁**都不知道，这是真正的新情况」。前者可解，后者不可解，混在一起就会让系统误以为「问一下就好」。更麻烦的是，同伴的答案有三个隐藏属性：**年龄**（它用的是 200ms 前的观测，我的决策窗是 100ms）、**相关性**（它和我跑同一个模型、吃同一次云更新，我们的错误是同一道题的两个副本）、**出处**（它的报告经了几跳转发，是否被改动）。所以分布式 epistemic 不能只算互信息，还得乘三个折扣：时效折扣、信任折扣、独立性折扣。**问同伴不等于获得独立证据；同源的一致只是回声。**

**灵感 2（云边协同 → 答案的价值随时间指数衰减，算力在阶梯上）**
直觉：消歧是重活——K 路流采样、瞬时变分似然、LLM 生成问句。边缘算得快但糙、视野窄；云端算得准、见过全队的数据，但慢、可能占用带宽、且是单点。一个 500ms 才到的完美答案，对 200ms 的决策窗等于零，甚至为负（它描述的是一个已经不存在的世界）。因此 VoI 必须乘时间折扣 e^{−τ/T_dec}，并**硬性要求 τ ≤ T_dec**：超窗的答案只能作为下一轮的软先验，不能进本轮的证据账本。阶梯升级本质上是在「时效 vs 精度 vs 信任」之间做预算分配；而边缘可做**推测式预取**——按预测的 (z, U_epi) 提前把最可能的高阶查询发出去、把云端延迟藏在决策窗之前。云边的正确关系不是「边缘求云」，而是「**边缘预测云**」。

**灵感 3（共识要有安全笼，安全笼必须主权）**
直觉：多机协作最自然的做法是「对齐信念、投票选动作」。但安全关键系统里，投票可以选出「大家都认为安全」的不安全动作（共因错误让全票通过）。正确姿态：共识只发生在**模态权重空间**（决定「选哪个模态」），执行动作仍必须在**本地状态**上过 C-RAS-WM 前缀认证；共识只能从「各自已逐条认证过的模态」里挑下标，**绝不能跨机平均动作向量**——平均两个各自安全但不兼容的动作，得到的往往是不安全的。一句话：**共识是似然，安全笼是法律。**

**灵感 4（R69 是零延迟单机边界 → 必须严格包含，才敢加层）**
直觉：关掉同伴、把云延迟设为 ∞（只走边缘 L0）时，NEXUS 必须**逐指令等于** FLUID-RAS；任何信任/时效/独立门控失败，λ 必须单调不降地退回 R69→R68 的保守 floor。这是 R69 立下的规矩（新层是旧层的严格泛化，不是并列替代），本轮必须继续遵守：机队与云边只能**买效率**，不能**动安全**。

**灵感 5（分布式带来新的攻击面 → 网络威胁模型）**
直觉：一旦信息跨节点流动，「单次交互不定案」就不够了。新攻击面包括：**Sybil**（一个坏节点伪装成很多个「独立」证人，直接刷高 k）、**重放**（旧答案当新答案）、**分裂脑**（网络分区两侧各自共识、各自行动）、**共因投毒**（污染共享的云更新，一次性骗过全队）、**延迟注入**（把答案拖到决策窗之后，让系统在信息真空里行动）、**拜占庭报告**（数值撒谎但格式合法）。R69 的「k 个正交源一致」必须升级为「**同一出处的多次一致仍只算一票**」，这就是本轮的 CIR（共因独立性检测）。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（NEXUS-RAS 总览）** NEXUS-RAS = (DED, TVoI, CEL, TGA, BCC, CIR, SCG, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **安全笼主权**：共识 / 云端 / 同伴只能重加权模态，绝不能扩大经认证的安全包络；
(iii) **答案时效窗**：任何外部信息必须 age ≤ 其决策时域，并通过陈旧-一致性门（SCG）；
(iv) **独立性记账**：证据源须过共因独立性检测（CIR）才计入 k-一致，共因相关源按有效独立度 k_eff 计。
另继承 R69 的交互预算与证据纪律。

**定义 311（分布式知识 / 信任图）** 节点集 V = 机器人 ∪ 云端 ∪ 人；信任边 T_{ij}(t) ∈ [0,1]；节点信念 B_j = (modes_j, w_j, t_j)；节点专长/能力向量 cap_j；信息来源出处 provenance_j（模型谱系、云更新版本、传感器链路）。信任随陈旧衰减：T_{ij}(τ) = T⁰_{ij}·e^{−τ/τ_T}。

**定义 312（分布式不确定性四分）** U_ale（模态内，不可约）；U_epi^loc（本地信息动作可解，即 R69 的 U_epi）；U_epi^soc（同伴可解，∝ I(M; B_j | o_i)，经信任与独立性折扣）；U_comm（通道不确定性：陈旧 + 信任 + 相关性）。四者语义不同，分别进入不同通道（定义 327），不做简单加和。

**定义 313（时限感知 VoI，T-VoI）** 对候选查询 g→j，往返时延 τ_j、决策时域 T_dec：
VoI_T(g) = e^{−τ_j/T_dec}·[H(M|o) − E_{y~p(·|g,o,τ)}H(M|o,y)] − c(g,τ_j)。
可执行条件：τ_j ≤ T_dec。若 VoI_T ≤ 0 或超窗：不查询，退化本地 / R68。这使 R69 的 VoI 成为 τ_j→0 的边界。

**定义 314（云边阶梯 CEL）** 四级：L0 边缘单样本（K=1，可缓存）；L1 边缘多采样 + 本地信息动作；L2 同伴查询；L3 云端查询（重 rollout / FMA / LLM）。每级有延迟预算、信任先验、单位成本。升级条件：下一级 T-VoI > 成本且 τ ≤ T_dec。**推测式预取**：边缘按预测的 (z, U_epi) 提前把最可能的高阶查询写入缓存，缓存键为 (provenance, query_hash, state_predicate)。

**定义 315（信任校准 TGA）** 节点自报置信须校准（ECE_j）；T_{ij} 由审计结果做稳健贝叶斯更新；伪造 / 重放 / 分裂脑事件降低 T 并触发复检，且永久记录 provenance 污点。

**定义 316（共识-安全分离 BCC）** 在模态权重空间做信任加权稳健聚合（trimmed median-of-means）得 M̄；执行时只从「本地逐条通过 C-RAS-WM 认证」的模态集合里选下标；绝不跨机平均动作向量。共识输出仅是一个后验，不是动作。

**定义 317（共因独立性检测 CIR）** 源 i, j 独立 iff provenance_i ≠ provenance_j 且共同输入下误差相关 < τ_cc。共因分 CC(i,j) = ρ(err_i, err_j | shared input)。有效独立度 k_eff = 1 + Σ_i (1 − CC_i)。R69 的「k 个正交源一致」纪律替换为「k_eff 个有效独立源一致」纪律。

**定义 318（陈旧-一致性门 SCG）** 外源答案 y（来自 j，时刻 t_j）可采纳 iff：(a) t_now − t_j ≤ H_dec；(b) y 依赖的状态谓词变化 ≤ δ_state；(c) T_{ij} ≥ τ_T。否则 y 仅作软先验或丢弃，U_epi^soc 视为未消解。

**定义 319（分布式流似然 FMA-D）** 各节点可算 a_score；边缘算本地 FMA；云端用**不同模型谱系**算独立似然；两者之差 Δa_net 作为共因稳健的第二意见（扩展 R69 定义 301 到分布式）。

**定义 320（网络信息预算 IBG-N）** 全队单位时间信息动作 ≤ B_net；单机 ≤ 1 / 单位时间；带宽 / 知识 token ≤ B_kb；防惊群：升级请求需令牌 + 去重 + 指数退避；并含公平性约束（单一机器人不得长期独占云端）。

**定义 321（参与式审计 VQAuditor-N）** 审计对象新增分布式决策：信任是否校准、共识是否共因、云答案是否陈旧、安全笼是否被覆盖。结论回灌信任图与 CEL 成本先验。

**定义 322（网络攻击干扰集 AIC-NEXUS）** Sybil / replay / split-brain / common-mode poisoning / latency injection / Byzantine report。ℰ_NEXUS = ℰ_FLUID × ℰ_net。

**定义 323（证书 J_NEXUS）** J_NEXUS = (J_FLUID, trust_graph_hash, k_eff, τ_p95, cloud_age, consensus_disagreement, cir_score, nexus_ver)。Valid ⇔ Valid(J_FLUID) ∧ 独立性满足 ∧ 时效满足 ∧ 安全笼完整。

**定义 324（退化边界）** 单节点、无同伴、云延迟 ∞（仅 L0）⇒ NEXUS 逐指令等于 FLUID-RAS；再叠加 VoI ≤ 成本 ⇒ 等于 R68。故 R69 / R68 是 NEXUS 的两个嵌套退化面。

**定义 325（共识可达集）** 执行动作 ∈ ∪_i Certified_i（各自本地已认证模态集合）。共识只在候选模态下标上取值，故可达集 ⊆ ∪_i Certified_i，不产生任何新动作。

**定义 326（分裂脑与愈合）** 分区期间各分区独立运行 R69 实例；愈合时按审计而非覆盖做信念合并：只在信任加权模态空间合并，安全笼不变，未审计前不改变执行。

**定义 327（复合退避）** 若信任 / 时效 / 独立性任一失败 ⇒ λ = λ_floor(U_ale + U_epi^loc + U_epi^soc)，即把未消解的社会 epistemic 视同 aleatoric；该值 ≥ R69 的 R68 floor（定义 307）。

**定义 328（阶梯深度的内生化）** 在带宽预算与时限约束下选深度 d* = argmax_d E[utility(d)] s.t. B_net；深度是预算与置信的折中，保证 P99 时限。预取命中率决定有效深度。

# IP-264 DED：分布式不确定性四分（扩展 R69 的 AUD）
def decompose_distributed(o_i, samples, peers, trust, provenance):
    U_ale, U_epi_loc, modes = FLUID.decompose(samples)   # R69 本地二分
    U_epi_soc = 0.0
    for j in peers:                                      # 只算「可能可解」的部分
        indep = c_ir.independence(i, j, provenance)      # 0..1，共因则趋 0
        U_epi_soc = max(U_epi_soc,
                        indep * trust.T(i, j, age=now - peers[j].t)
                        * mutual_info(modes, peers[j].belief))
    return U_ale, U_epi_loc, U_epi_soc, modes

# IP-265 TVoI：时限感知的价值 of information（R69 VoI 的 τ→0 边界）
def time_voi(g, j, o, deadline, budget):
    if budget.remaining() <= 0:                    return -inf
    tau = net.predict_rtt(j, g)                    # 含排队/带宽预测
    if tau > deadline:                             return -inf   # 到达即失效
    gain = H(modes) - expected_H_after(g, o, tau)
    return exp(-tau / deadline) * gain - cost(g, tau)

# IP-266 CEL：云边阶梯（含推测式预取）
def route(o, modes, deadline, budget):
    for level in (L1, L2, L3):                     # L0 永远可跑
        cands = candidates_at(level, modes, o)
        best  = max(cands, key=lambda g: time_voi(g, target(level), o, deadline, budget))
        if time_voi(best) > 0 and budget.allow(level):
            return level, best
    return L0, None                                # 无利可图 → R69/R68

def prefetch(o, z, deadline):                      # 把云端延迟藏到决策窗之前
    key = (provenance.self, query_hash(z), state_predicate(o))
    return cache.get(key) or async_query_cloud(o, key)

# IP-269 CIR：共因独立性检测（把「k 个一致」修成「k_eff 个一致」）
def effective_independence(sources):
    cc = [shared_cause_score(s, sources[0]) for s in sources[1:]]
    return 1.0 + sum(1.0 - c for c in cc)          # 同源 → k_eff → 1

# IP-268 BCC：共识只选模态，安全笼仍主权
def consensus_safe(modes_list, trust, local_state):
    M_bar = robust_aggregate(modes_list, weights=trust)      # trimmed median-of-means
    certified = [m for m in M_bar if c_ras_wm.certify(m.a, local_state)]
    if not certified:                                        # 共识不合格 → 退回本地
        return local_safe_mode(modes_list[0], local_state)
    return select_best(certified)                            # 只选下标，不平均动作

# IP-275 主闭环（继承 R69，仅在信息路由与共识处插入 NEXUS 层）
def NEXUS_round(M, o_i):
    z, o = M.mtm.forward(o_i);  M.cof.step(...)              # R68/R69 一次前向 + 标定
    U_ale, U_loc, U_soc, modes = M.ded.decompose(o, peers, trust, provenance)
    # 1) 第二意见：本地 FMA + 跨谱系云端 FMA-D
    a_local = M.fma.local(M.fmp, M.last_action, o)
    a_net   = M.fma.cloud_if_cached(o)                       # 预取命中才有，否则 None
    slow    = (a_local > TAU_FMA and M.last_r_res < TAU_RES) or \
              (a_net and abs(a_net - a_local) > TAU_NET)     # 共因稳健的缓变故障疑
    # 2) 时限感知路由：值钱且来得及才问，否则本地或保守
    lvl, g = (M.cel.route(o, modes, T_dec=M.vista.H, budget=M.ibg_n)
              if (U_loc + U_soc > TAU_EPI and not slow) else (L0, None))
    if g is not None:
        y = M.cel.execute(lvl, g)                            # 带 TGA 信任 + SCG 时效门
        y = M.scg.admit(y, origin=lvl_target(lvl))           # 陈旧/不一致 → 降级
        k_eff = M.cir.effective_independence(evidence_sources(y, modes))
        if k_eff >= K_EFF_MIN:
            modes = M.cia.update_belief(modes, y)            # 累计后验，不单源定案
            U_soc = 0.0
    # 3) 跨机共识只在模态空间；执行仍走本地安全笼
    mode = M.bcc.consensus_safe(modes, M.tga.trust, o) if fleet_consensus_ready() \
           else FLUID.select_mode(modes, U_soc, lam=None)
    # 4) 复合退避：信任/时效/独立任一失败 → 社会 epistemic 当 aleatoric
    U_floor = U_ale + U_loc + (U_soc if g is None or k_eff < K_EFF_MIN else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(mode.a, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(mode.a, M.last_U_cal))
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 5) 审计 + 证书 + 预取
    M.vqa_n.submit_async(lvl, g, k_eff, M.tga.audit_log(), a_local, a_net)
    M.cel.prefetch(o, z, M.vista.H)
    return k, lam, mode, dict(U_ale=U_ale, U_loc=U_loc, U_soc=U_soc, k_eff=k_eff)

## 3. 推导

**引理 19（时限信息增益与陈旧折扣）** 设答案在 τ 到达、决策时域为 T_dec，状态漂移使答案与当前模态的相关按 e^{−τ/T_dec} 衰减（A99：漂移有界、指数遗忘）。若 τ > T_dec，可用信息增益 ≤ 0（决策已做，且陈旧答案可能误导）；若 τ ≤ T_dec，可实现的期望误差下降 ≥ c·Δ_min·(1 − e^{−ΔH})·e^{−τ/T_dec}。系：**云端重算只对长时域决策划算，或必须靠预取把有效 τ 压到窗内**——这解释了为什么「边预测云」比「边求云」更关键。

**引理 20（共因有效独立度与投毒上界）** 设 k 个报告源，相对首个源的共因相关为 CC_i。有效独立度 k_eff = 1 + Σ_i (1 − CC_i) ≤ k。R69 引理 18 的错误采纳上界更新为 δ_p·ρ^{k_eff−1} + ε_σ。当共享模型 / 共享云更新使 CC_i→1 时 k_eff→1，上界退化到 δ_p——**机队的「一致」不提供任何鲁棒性**。这从数学上解释了为什么「全队同时被同一次云更新投毒」是最危险场景：不是 k 变小，而是 k 名义很大、k_eff 却是 1。

**引理 21（信任校准下的误信上界）** 设源 j 的真实可靠度 r_j、自报置信 c_j、校准误差 |c_j − r_j| ≤ η_j。以信任 T 采纳其答案的期望遗憾 ≤ (1−T)·L_wrong + T·(η_j·λ_calib + (1−r_j)·L_wrong)。系：**高信任 + 未校准 = 自信地错**；故 TGA 必须把「校准误差」而非「自报置信」作为信任的依据。

**定理 18（NEXUS 严格包含 FLUID / R68）** 在 A99–A101 下，NEXUS 在任意状态上的期望风险 ≤ FLUID-RAS ≤ R68；且当仅走 L0、无同伴、T-VoI ≤ 成本、或信任 / 时效 / 独立性任一失败时，NEXUS 与 FLUID-RAS **逐指令相同**（定义 324、327）。故 R69 与 R68 是 NEXUS 的嵌套退化面：安全侧不做任何让步，效率侧获得分布式 resolution bonus。

**定理 19（共识不改安全包络）** BCC 的每个候选动作都在本地状态上逐条通过 C-RAS-WM 认证；共识只在候选下标上取值；故执行动作的物理风险 ≤ ε（R69 定理 17 的界）。共识不能制造不安全动作，也不能扩大可达集（定义 325）。**投票可以改变选择，不能改变物理。**

**定理 20（分裂脑安全与无突变）** 分区期间每个分区都是合法的 R69 实例，其风险 ≤ R69 界；愈合时先审计后合并，合并只在模态权重空间进行，未审计前不改变执行，故控制连续、无突变（扩展 R68 定理 15 / R69 定理 17）。

## 6. 本轮最大风险

**一句话**：NEXUS 的全部分布式收益押在「**同伴 / 云端与我是独立证据源**」这一前提上——若全队共享同一模型谱系、同一次云更新或同一条数据回传链（真实部署中这几乎是默认配置），则 **k 名义很大而 k_eff→1，共识退化为一个幻觉的回声**；此时系统不是「被少数坏人骗」，而是**全体一起自信地错**，安全笼只能保证单步动作不越界，却挡不住整队协调一致地走向一个错误计划——**同源的一致不是证据，是回声；机队规模越大，回声越响。**

**次级风险与缓解**：
1. **共因相关难检测**（provenance 不可见、误差相关被共同噪声稀释）→ CIR 多信号交叉（模型哈希 / 更新版本 / 残差相关）+ 强制至少一个**异构谱系**源，否则 k_eff 上限封顶；
2. **云单点投毒**（一次污染骗过全队）→ 云端答案也须 SCG + 跨谱系 Δa_net 第二意见 + 审计回滚；
3. **延迟 / 分裂脑导致执行不一致** → 外部查询不阻塞安全环 + 分区独立运行合法 R69 + 愈合先审计后合并；
4. **Sybil 刷高 k** → 信任图 + provenance 去重 + k_eff 而非人头数 + IBG-N 配额；
5. **信任图本身被攻陷**（长期养号后背叛）→ 信任上限、周期性复检、审计不可绕过，安全侧始终回退本地保守。

def decompose_distributed(o_i, samples, peers, trust, provenance):
    U_ale, U_loc, modes = FLUID.decompose(samples)
    U_soc = max([c_ir.independence(i, j, provenance)
                 * trust.T(i, j, age=now - peers[j].t)
                 * mutual_info(modes, peers[j].belief) for j in peers] or [0.0])
    return U_ale, U_loc, U_soc, modes

# IP-265 TVoI：时限折扣（R69 VoI 是 τ→0 边界）
def time_voi(g, j, o, deadline, budget):
    if budget.remaining() <= 0: return -inf
    tau = net.predict_rtt(j, g)
    if tau > deadline:          return -inf          # 到达即失效
    return exp(-tau/deadline) * (H(modes) - expected_H_after(g, o, tau)) - cost(g, tau)

# IP-266 CEL：云边阶梯 + 推测式预取
def route(o, modes, deadline, budget):

                   key=lambda g: time_voi(g, target(level), o, deadline, budget))
        if time_voi(best) > 0 and budget.allow(level): return level, best
    return L0, None                                   # 无利可图 → R69/R68

## 4. 推导

**引理 19（时限信息增益与陈旧折扣）** 状态漂移使答案与当前模态的相关按 `e^{−τ/T_dec}` 衰减；`τ>T_dec` 时可用增益 ≤ 0，`τ≤T_dec` 时误差下降 ≥ `c·Δ_min·(1−e^{−ΔH})·e^{−τ/T_dec}`。系：云端只对长时域决策划算，或必须预取——「边预测云」优于「边求云」。

**引理 20（共因有效独立度与投毒上界）** `k_eff = 1+Σ_i(1−CC_i) ≤ k`；R69 引理 18 上界更新为 `δ_p·ρ^{k_eff−1}+ε_σ`。共享模型/更新使 `CC→1` 时 `k_eff→1`，上界退化到 `δ_p`——机队的「一致」不提供鲁棒性。全队同源投毒是最危险场景：k 名义大、k_eff 为 1。

**引理 21（信任校准误信上界）** 源真实可靠度 `r_j`、自报置信 `c_j`、校准误差 `|c_j−r_j|≤η_j`；以信任 T 采纳的期望遗憾 ≤ `(1−T)L_wrong + T(η_j·λ_calib + (1−r_j)L_wrong)`。系：高信任 + 未校准 = 自信地错。

**定理 18（NEXUS 严格包含 FLUID/R68）** 任意状态期望风险 ≤ FLUID ≤ R68；仅 L0、无同伴、T-VoI≤成本、或信任/时效/独立任一失败时逐指令相同。R69/R68 为嵌套退化面。

**定理 19（共识不改安全包络）** 共识候选均逐条本地过 C-RAS-WM；共识只选下标；故物理风险 ≤ ε（R69 定理 17 界），且可达集 ⊆ ∪Certified。投票改变选择，不改变物理。

**定理 20（分裂脑安全与无突变）** 分区各为合法 R69 实例；愈合先审计后合并、只在模态权重空间、未审计不改执行 ⇒ 控制连续无突变。

## 7. 本轮最大风险

**一句话**：NEXUS 的全部分布式收益押在「同伴/云端与我是独立证据源」这一前提上——若全队共享同一模型谱系、同一次云更新或同一条数据回传链（真实部署中几乎是默认），则 **k 名义很大而 k_eff→1，共识退化成一个幻觉的回声**；系统不是「被少数坏人骗」，而是**全体一起自信地错**，安全笼只保单步动作不越界，挡不住整队协调一致地走向错误计划——**同源的一致不是证据，是回声；机队规模越大，回声越响。**

**次级风险与缓解**：共因相关难检测（CIR 多信号交叉 + 强制异构谱系源，否则 k_eff 封顶）；云单点投毒（SCG + Δa_net 跨谱系第二意见 + 审计回滚）；延迟/分裂脑致执行不一致（外部查询不阻塞安全环 + 分区各跑合法 R69 + 愈合先审计后合并）；Sybil 刷高 k（信任图 + provenance 去重 + k_eff + IBG-N 配额）；信任图被长期养号攻陷（信任上限 + 周期复检 + 安全侧始终回退本地保守）。
