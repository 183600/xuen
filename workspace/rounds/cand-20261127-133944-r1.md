## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1：社会影响 → 示教是"一群老师在不同场次反复教同一件事"

**直觉**：数据里没有老师 ID，但官方明说采集跨场次、条目有差异（F23）。这意味着策略学到的是"**共识动作**"而非"最优动作"：不同示教者的接近方向、速度、抓取时机不同，均匀 BC 把多峰动作分布压成单峰 → **模式平均（mode averaging）**，在接触/装配任务上表现为"犹豫、偏移、半途改主意"。这是"社会影响"的第一层：策略继承了集体示教的共识偏差。第二层更硬：既然"影响"可被度量，就能用**影响函数/梯度相似度**量化"哪条数据对哪个任务有影响"，把上一轮靠 LLM 猜的孪生表换成**实测的任务影响矩阵**。

**严谨定义（示教异质性）**：对任务 t 的 episode 按无监督风格簇 c 分组（无 operator ID）；对动作维 d 在归一化进度 p 上做方差分解，定义组内相关
`ICC = σ²_between / (σ²_between + σ²_within)`。
ICC 高 ⇒ 风格是动作的强混杂 ⇒ 均匀 BC 的模式平均风险高 ⇒ 应显式平衡/条件化风格。

**反直觉点**：不是"示教越多越好"，而是"示教越同质越易学、越异质越鲁棒，但均匀训练只取到异质的平均值（最差折中）"。正确做法是**显式建模/平衡异质性**，而不是假装它不存在。

### 灵感 2：预训练 → Base 已经是"预训练产物"，比赛考的是"继续预训练 + 领域适配"

**直觉**：上一轮把 110 语料当作"未被利用的新信号"，但 Base 已在 ~2500h/64 任务上预训练（F20），官方微调路径就是冻结 VLM 训 action head；且 110 里不少任务与考题同名不同集（F22），很可能**已在 Base 的预训练分布内**。所以"预训练"的正确问题不是"要不要预训练"，而是：**Base 已经会什么（知识盘点）、还差什么（差值集 Δ）、域差多少（领域适配）**。盲目把 110 全量再混进去，很可能在重复学习已知任务，还引入相机/格式域偏移（F21/F24）。

**严谨定义（Base 新息量）**：对任务 t 的留出集 `D_t^ho`，令 `e(t) = median_{(o,a)~D_t^ho} ||π_Base(o) − a||_norm`（归一化动作误差；官方 eval 脚本可直接给逐维误差，F25）。定义新息量 `n(t) = e(t) / median_{t'∈C} e(t')`，差值集 `Δ = { t : n(t) > τ }`。直觉：**Base 误差高的任务，才是继续预训练真正能"教到新东西"的任务**。

**反直觉点**：预训练的收益不来自"更多数据"，而来自"数据的新息量"——先测量 Base 的盲区，再只对盲区做继续预训练，比全量混训更省、更准、更少域偏移。

### 灵感 3：统一 → 用影响矩阵选源、用新息量定 Δ、用风格平衡降共识偏差

**直觉**："社会影响"提供**数据选择与异质性控制**，"预训练"提供**阶段化课程**。两者相乘得到一个可执行配方：先盘点（novelty），再测影响（influence matrix），再分阶段（Stage A 继续预训练 Δ → Stage B 专精 32），全程用风格平衡与遗忘约束兜底。数据引擎从"加法"升级为"**测量 + 分期**"。

**严谨定义（影响矩阵）**：`T_{i→j} = L_j(θ) − L_j(θ after short training on D_i)`（正=正迁移，负=负迁移）。廉价近似用共享 checkpoint 上的梯度余弦 `cos(∇L_i, ∇L_j)` 或 TracIn；对 top 候选再用短微调探针校准。用途有三：给 Δ 排序、预警负迁移对、**生成实测版孪生表**替代语义猜测。

**三者统一**：上一轮结论"数据侧胜负手"不变，但度量从"数据量"转向"**数据的新息量 × 同质性**"。这是本轮对 v1.1 的实质修正。

## 2. 对第 2 轮痛点的增量修订

- P8（示教质量）深化：质量 ≠ 同质性；异质示教即使条条"成功"也会互相抵消（模式平均）。
- **新增 P9（预训练盲区未知）**：不做 Base 知识盘点就分配预训练算力，可能重复学习已知任务、忽略真正盲区。
- **新增 P10（域偏移）**：Base 预训练域（异构相机/格式）与挑战域（10 路 640px AV1）不一致，直接复用 action head 的归一化/统计量可能失配。
- P2（泛化缺口）补充：影响矩阵把"盲猜孪生"变成"实测迁移"，数据侧可解释性增强。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（Base 知识盘点）**：离线动作误差/进度指标能否可靠估计 Base 对每任务的"已知度"，并与闭环成功/泛化相关？novelty 阈值 τ 如何用 L0 校准？
- **Q10（影响矩阵）**：哪种廉价近似（梯度余弦 / TracIn / 短微调探针）足以替代 LLM 孪生表并预警负迁移？矩阵的稳定性与任务顺序敏感性如何？
- **Q11（示教异质性）**：无 operator ID 时如何无监督推断会话/风格簇，用 ICC 判断"风格建模是否值得"，并在风格平衡 / 风格条件化 / 规范风格选择之间取舍？

## 4. 设计原则（新增 PR6）

- **PR6 新息优先律**：预训练/共训的每一份数据，先测量它对 Base 的新息量 `n(t)`；新息低（Base 已会）的数据默认不重复投喂，除非它承担"防遗忘/领域覆盖"职责。与 PR5（数据杠杆律）互补：PR5 管"是否对齐计分轴"，PR6 管"是否带来新信息"。
- PR1–PR5 保留。

## 6. 本轮最大风险

**一句话**：整个方案的地基是"**离线动作误差 ≈ Base 的知识盲区 ≈ 闭环成功短板**"这一三重近似——若离线 action MAE 与闭环任务成功率/泛化弱相关（BC 评估的经典陷阱），则 novelty 表会错划 Δ、影响矩阵会误导预训练算力分配，我们可能在 Base 已会的任务上重复烧算力，却漏掉真正会失分的盲区。

## 7. 下轮迭代计划

- **深化**：I2 v3 的 Base 盘点脚本（复用官方 eval）+ novelty 阈值校准；影响矩阵的梯度近似与探针校准；I10 的风格特征与 ICC 报告模板。
- **修剪**：I7 正式归档；I11 仅在 I2 v3 Stage A 有余量时启动；I2 v2 的"110 全量加权混训"降级为 ablation 对照臂（不再作主方案）。
- **待核实**：Base 的 64 任务预训练清单（HF 卡片为空，只能靠 novelty 反推）；挑战评测是否使用与训练相同的 10 路相机子集；novelty 与真机成功的相关性（需首批 L2）。

### I1 v2 考纲校准五轴增广引擎 ★★★★★（维持）

- 六要素同 v1.1：按官方考纲（手册 §2.1 + 任务 wiki，F2/F17）校准五轴增广，剂量-响应 + 轴间析因。

### I2 v3 预训练差值 × 影响矩阵驱动的分阶段数据课程 ★★★★★

- **动机**：Base 已自带预训练 action expert（≈2500h/64 任务，F20）；110 语料与 32 考题部分**同名不同集**（F22）；跨源相机/格式/robot_type 异构（F21/F24）。v1.1 的"110 全量加权混训"隐含假设 110 全是新信号、孪生靠语义猜——可能重复学习、负迁移、域失配。
- **与 v2 差异**：v2 是一次性加权混采、依赖 loader patch（F11 权重不生效）；v3 **先测后训、分阶段、带遗忘约束**，且 Stage B 主要喂 32 任务，天然规避 loader 权重缺陷。
- **三步**：
  1. **Base 知识盘点（novelty audit，仅推理，F25）**：对 32 考题 + 110 语料逐任务留出集跑 Base action expert，得 `e(t)`、`n(t)`，划分 `Δ`（新息高）/`Known`（Base 已会）/中间带；τ 用 L0 闭环进度校准。
  2. **影响矩阵（influence matrix）**：共享 checkpoint 上用梯度余弦 / TracIn 近似 `T_{i→j}`，对 top-k 候选做短微调探针校准。用途：给 Δ 排序、预警负迁移对、**生成实测版孪生表**替代 LLM 猜测。
  3. **分阶段课程**：Stage A 只继续预训练 Δ 中高影响源（LoRA/低 LR，冻结 VLM）；Stage B 挑战任务专精（32 全量 + 正迁移孪生低权重），加 L2-SP/EWC/LoRA 约束 + Δ 小样本 rehearsal；度量 `forgetting = Known/Δ 留出集在 Stage B 前后的退化`。
- **技术可行性**：高-中。盘点仅推理（官方 eval 工具，F25）；影响矩阵梯度近似廉价；继续预训练为主要算力。
- **所需资源**：盘点 1 GPU 日；影响矩阵 1–2 GPU 日 + top-k 探针；Stage A Δ 继续预训练 4–8 GPU 日；Stage B 单卡 24GB（F20 官方默认）；数据按盘点选 Δ 子集，**不再全量下载 110**。
- **落地步骤**：①盘点脚本（复用 `eval_local_episode`）；②`n(t)` 表 + Δ/Known 划分 + τ 校准；③影响矩阵 + top-k 探针；④Stage A 只喂高影响 Δ（LoRA/低 LR/按 32 留出早停）；⑤Stage B 32 全量 + 正迁移孪生 + 遗忘约束；⑥forgetting 度量；⑦族级 L0 → L2。
- **风险**：novelty 用离线动作误差作代理，可能与闭环成功弱相关（见本轮最大风险）；Δ 估计错 → 算力错配；Stage A 域偏移反而伤 Base（缓解：先做域规范化、冻结 VLM、低 LR、按 32 留出早停）。

### I8 v3 评测运营闭环 + 分级消融注册表 ★★★★

- **动机**：真机通道稀缺 + 待验证组合爆炸（P7）；v1.2 新增多个"测量类"假设（novelty、影响矩阵、ICC），必须被证伪。
- **本轮升级（新增三个仪表）**：
  1. **novelty 表**：`e(t)/n(t)`，记录 P0 盘点结果与后续真机增益的相关性；
  2. **影响矩阵**：`T_{i→j}` 热图，滚动校验"离线预测迁移 vs 真机迁移"；
  3. **forgetting 曲线**：Stage A→B 后 Known/Δ 留出集的退化。
- **L0 代理升级**：不只 action MAE，加"闭环进度退化 Δprog"（复用 I5 进度头）；注册表增加"novelty 预测 vs 实际增益"的 Spearman。
- **首个用例**：I2 v3 的**三臂对比**——Δ 选择性预训练 / 110 全量混训（v2 对照）/ 只训 32（基线）。
- **判据**：若 novelty 与真机增益 Spearman < 0.4，则 novelty 仅作排序先验、不作硬筛选；影响矩阵同理。
- **可行性**：高（L0 纯离线）。**资源**：仪表 1 人周 + 盘点 1 GPU 日。**风险**：相关性建立慢（用历史真机结果回填对齐点）。

### I9 reset 期检索类比迁移 ★★★★（维持）

- 六要素同 v1.1（`reset()` 每 episode 一次，F18；DINOv2/VLM 嵌入 + FAISS；距离阈值门控；零权重更新）。
- 本轮交叉引用：检索库按 I2 v3 的 novelty **加权覆盖 Base 盲区**（n(t) 高的任务/物体优先建库），使检索先验投在真正需要的地方。

### I10 示教者/会话异质性感知 BC（新） ★★★★

- **动机**：无 operator/session ID（F23），官方承认跨场次差异；均匀 BC 把多峰动作压成单峰 → 模式平均（P8）。
- **与现有方案差异**：I2 v2 的"质量加权"是**删坏样本**（标量质量）；本点修正**分布形状**（多峰），二者正交。
- **方法**：
  1. **风格特征**：速度剖面、接近方向、抓取时机、动作二阶差分谱；
  2. **无监督聚类**：KMeans/谱聚类得风格簇 c（无 ID 可依）；
  3. **ICC 判定**：`ICC = σ²_between/(σ²_between+σ²_within)`，高才值得建模；
  4. **三选一控制**：①风格平衡采样（每簇等质量，最保守默认）；②风格条件化（style token/embedding，容量足时）；③规范风格选择（成功裕度最高簇作"标准教法"，供 I5 模仿）。
- **技术可行性**：高（纯数据分析 + 采样器，无额外训练）。
- **所需资源**：1 人周；无 GPU 增量。
- **落地步骤**：①风格特征；②聚类 + ICC 报告；③平衡采样器（单元测试：batch 内风格频率）；④L0 多峰任务对比（ZipUp / PourOutMedicine / PlugCharger）；⑤真机抽测。
- **风险**：风格与质量混杂（低质量簇被误当风格）；ICC 高但与任务无关（过度建模）。缓解：风格 × 成功裕度联合分析，仅当"风格显著且与质量正交"时启用条件化；默认走最保守的平衡采样。

### I11 动作专家辅助自监督预训练（新，缓） ★★

- **动机**：纯 BC 只学 `p(a|o)`，不显式学动力学；接触段需要动态理解。可在 Stage A 加辅助目标，提升 action head 的动态表征。
- **方法**：Stage A 加轻量辅助头（未来帧预测 / 动作一致性 / 掩码动作重建），主目标仍流匹配，辅助权重小；或用 WMA-0 特征蒸馏（I7 裁撤后资产复用）。
- **技术可行性**：中；算力高；收益不确定。
- **所需资源**：额外 4–8 GPU 日。
- **落地步骤**：①小规模代理（单任务族）验证辅助目标不与流匹配冲突；②若正收益再并入 Stage A；否则放弃。
- **风险**：辅助目标与动作生成目标冲突；收益可能被 I2 v3 的继续预训练覆盖。→ 定为"缓"，仅当 I2 v3 Stage A 有余量时启动。

## 1. 关键伪代码

### 1.1 Base 知识盘点（I2 v3 · P0）

```python
def base_audit(base_ckpt, tasks, eval_fn, tau, tau_lo):
    # eval_fn 直接复用官方 eval_local_episode 的逐 chunk 误差（F25），仅推理
    e = {}
    for t in tasks:                                   # 32 考题 + 110 语料
        errs = [eval_fn(base_ckpt, ep)["action_mae"] for ep in heldout(t)]
        e[t] = median(errs)
    med = median(e.values())
    novelty = {t: e[t] / med for t in e}              # n(t)
    Delta = {t for t in e if novelty[t] > tau}        # 新息集：继续预训练
    Known = {t for t in e if novelty[t] < tau_lo}     # Base 已会：防遗忘/跳过
    return novelty, Delta, Known
```

### 1.2 影响矩阵（I2 v3 · 梯度近似 + 探针校准）

```python
def influence_matrix(ckpt, sources, targets, probe_frac=0.05, k=20):
    g = {t: grad_of_loss(ckpt, sample_batch(t)) for t in sources + targets}
    T = {(i, j): cosine(g[i], g[j])                    # 廉价近似
         for i in sources for j in targets}
    for (i, j) in topk(T, k):                          # top-k 用短微调探针校准
        theta_i = short_finetune(ckpt, sample_batch(i, probe_frac))
        T[(i, j)] = loss(theta_i, heldout(j)) - loss(ckpt, heldout(j))
    return T                                           # >0 正迁移，<0 负迁移
```

### 1.3 示教风格聚类 + ICC + 平衡采样（I10）

```python
def style_icc(task_eps):
    feats  = [style_features(ep) for ep in task_eps]   # 速度剖面/接近方向/抓取时机
    labels = KMeans(n_clusters="auto").fit_predict(feats)   # 无 operator ID → 无监督
    b = between_var(task_eps, labels)                   # 进度对齐后的组间方差
    w = within_var(task_eps, labels)
    return labels, b / (b + w)                          # ICC

class StyleBalancedSampler:
    def __init__(self, labels, mode="balance"):         # 默认最保守：平衡
        n = {c: max(1, (labels == c).sum()) for c in set(labels)}
        self.w = {c: 1.0 / n[c] for c in n}
        self.mode = mode
    def weight(self, ep):
        return self.w[ep.style_cluster] if self.mode == "balance" else 1.0
```

### 1.4 分阶段课程（I2 v3）

```python
def staged_pretrain(base, Delta, T, challenge_32, Known):
    # Stage A：只继续预训练"对 32 有正影响"的 Δ 源，冻结 VLM、LoRA/低 LR
    sources = [i for i in Delta
               if max(T[(i, j)] for j in challenge_32) > 0]
    theta = continue_pretrain(base, sources, reg="lora", lr=1e-5)
    # Stage B：32 专精 + 正迁移孪生（低权重），带遗忘约束 + rehearsal
    theta = finetune(theta, challenge_32 + pos_twins(T),
                     reg="l2_sp", lr=1e-4, rehearsal=sample(Delta | Known))
    forgetting = {t: base_metric(t) - theta_metric(t) for t in (Delta | Known)}
    return theta, forgetting                            # forgetting 应≈0
```
