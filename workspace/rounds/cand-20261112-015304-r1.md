# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「开放词汇」×「最小可行产品」）

> 第 57 轮把赌注从"模型置信"换到"证据承诺"，再从"证据承诺"换到"元先验质量"：摊销先验给效率、共形带给保底、跨模态对账给分歧下限、个性化信任给单向有界。但它自陈的最大风险是"坏先验普遍"——语料盲区里的新材质，元模型会在 OOD 门学会的模式之外给出高度自信的错误后验。注意这个风险的**形状**：盲区之所以危险，不是因为它未知，而是因为它**不可名状**——系统只能说"这不像我见过的任何东西"，却无法把它变成一个可探、可问、可证伪的假设；OOD 门是一张只能报警、不能命名的烟雾探测器。本轮两个灵感正好从两端夹住这个缺口：**开放词汇**让未知第一次可以被语言命名、被组合推理、被定向探询——它扩大的是**假设空间**；**最小可行产品**让交付第一次被切成可证伪的能力台阶——它收缩的是**承诺空间**。二者合起来给出本轮命题：**命名只开假设、证伪才开能力、最小才可交付**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"开放可命名、最小可证伪、渐进可交付的证据说可信"**。

核心矛盾：
- **H29（开放命名 vs 校准）**：闭集校准在开放词表下失去意义——你无法为"尚未被命名的类"预先校准；更危险的是命名会**进口物理先验**（"像混凝土"就借来了混凝土的承载假设），错误接地会把未知伪装成已知，制造出一种"有名字的自信"。
- **H30（MVP vs 安全债务）**：MVP 的直觉是"先交付最小可用、在真实中学习"，但安全系统的"最小可用"若被理解成"最小功能"，就是把未验证的假设打包发货；必须有"证据债务"账本与还债预算，否则 MVP 退化为"先上线再说"。
- **H31（词汇-能力共谋）**：开放词表与能力台阶会共同演化——人给系统命名、系统按名字解锁能力、能力又反过来强化这套命名；一旦词汇没有切在现实的关节上，台账会自洽而世界不认账，形成"语义回声室"，比坏先验更隐蔽。

## 0. 直觉与动机

**灵感 1（开放词汇 → 开放的是假设空间，不是证据空间）**
直觉：第 57 轮的机器人面对新材质只能说"不像我认识的"，像一个只会说"不知道"的实习生。开放词汇让它能说"这像**一层薄壳盖着空洞**"——这句话立刻带来可检验的物理预测（薄壳会在载荷下破裂），于是"未知"被翻译成一个**定向探针**。这是开放词汇真正的价值：不是让它更敢踩，而是让它**更会问**。但名字是一种压缩，压缩就会进口先验："像混凝土"借来了混凝土的承载力。因此本轮立一条硬规矩：**名字只产生假设与探针提议，永不产生证据**；命名带来的物理先验只能在共形带内当先验用，且必须被真实探针接地（grounded）后才允许支撑能力。

**灵感 2（开放集共形 → 给"词表之外"留一个正式的名字）**
直觉：开放词表不可能穷举，所以校准不能只对 𝒱 内的类做。开放集共形的做法是给预测集加一个**空桶 ∅（∉𝒱，novel）**：无论真实概念在不在词表里，真值都以 ≥1−α 的概率落在 C_α(o)∪{∅} 中。∅ 不是失败，而是系统对"我还叫不出它的名字"的诚实表达；一旦 ∅ 进入预测集，系统必须提问或探询，而不是硬套一个最近的名字。这样"未知"从烟雾报警升级为**带覆盖保证的拒绝命名**。

**灵感 3（MVP → 最小可行安全包络，而非最小功能）**
直觉：在安全系统里，"viable"不是"功能最少能跑"，而是"**能被安全地证伪并继续学习的最小交付**"。所以本轮把 MVP 重新定义为最小可行安全包络 MVSE：选择一条能力台阶 ℓ，使得 (a) 该台阶的证据包络已过证据门，(b) 它依赖的未验证假设所构成的**证据债务**不超过上限 D_max，(c) 每个被交付的能力都有可运行的**证伪器**。省下的验证不是免费的，是借来的——必须用固定的还债预算 β_repay 在运行中偿还，债务不得单调上升，否则自动降阶。

**灵感 4（能力阶梯 + 证伪器必备 → 无证伪器，无能力）**
直觉：能力不是二元开关，而是有台阶的梯子：ℓ0 安全停/提问 → ℓ1 探后一步 → ℓ2 已知地形自主通行 → …。升级需要**真实证据 + 已接地概念 + 证伪器通过**，降级实时且不可讨价还价。最关键的工程纪律是"**no falsifier, no feature**"：一个能力若没有能在部署中真正把它证伪的廉价实验，就不许发布——否则你拥有的不是能力，只是一个还没被拆穿的假设。证伪器还必须独立于被检验的先验/模型，避免"用同一个错误去证明自己没错"。

**灵感 5（词汇-能力台账 + PCEO → 两本账，一本管"能说什么"，一本管"敢做什么"）**
直觉：把开放词汇与 MVP 接起来的是一个台账 VCL：每个开放词表概念记录其接地分 γ、支持的台阶、证伪器、证据债务与审计；每个台阶记录其解锁所依赖的概念与债务。PCEO（探-诺-演-开放）每个检查点先做开放感知与新颖性判定（OSCN），再做概念分诊（provisional→探针提议；grounded→共形先验），然后查 MVP 账本（此台阶是否允许、债务是否超限、证伪器是否齐备），最后才探询/承诺/降阶。命名账与能力账分离，正是"开放词汇扩大假设、MVP 收缩承诺"的落地形式。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（开放词汇接地概念归纳 OV-GCI）** 开放词表 𝒱（语言嵌入空间），闭集标签 ℒ⊂𝒱。命名算子 Name:𝒱×Ctx→c，概念 c=(desc,attrs,physics_hyp,support,provenance,state)，state∈{provisional,grounded,retired}。接地 Ground(c,Evidence)→(support,γ(c))，γ∈[0,1]；γ≥γ_0 且 support≥n_min 才转 grounded。概念代数：属性可组合、物理先验按最近 grounded 概念继承、矛盾检测（同一证据下两概念物理预测冲突）。规则：provisional 概念只可生成探针提议与提问，**不得进入证据门、不得参数化承诺先验**；grounded 概念的物理先验只能在共形带内当先验用，仍不单独构成证据。新颖度 ν(o)=dist(o,supp(grounded))，ν>θ_ν ⇒ 判"∉𝒱"，拒绝命名并转入保守通用探针。

**定义 140（开放集共形命名 OSCN）** 预测集 C_α(o)⊆𝒱∪{∅}，∅ 表示词表外新颖。覆盖契约：对任意真实概念 y（含 y∉𝒱），P(y∈C_α(o)∪{∅})≥1−α_open，其中 α_open=α_in+α_out（词表内覆盖与词表外新颖检出分别取界）。按已接地簇做条件校准；provisional 簇用保守先验使集合只增宽。别名一致性：同一指称的不同命名须落入同一簇，否则置 alias_flag 且不给接地信用。拒绝命名：∅∈C_α 或 |C_α|>1 ⇒ 必须先提问或探询，不得强行命名后进入承诺。

**定义 141（最小可行安全包络 MVSE）** 部署配置 d=(ℓ,E,F,D,B_learn)，ℓ 为能力台阶，E 为证据包络，F 为证伪器集，D 为证据债务，B_learn 为学习预算。效用 U(d)、残余风险 R(d)、证据债务 D(d)=Σ_{a∈未验证假设} p_a·cost_a（概率加权）。MVSE：max U(d) s.t. R(d)≤R_max ∧ D(d)≤D_max ∧ κ(d)=1（证伪器覆盖）∧ E(d) 过对应台阶的证据门。还债：运行预算中固定比例 β_repay 用于能注销债务的探针；期望债务在窗口内不得上升，否则自动降阶。

**定义 142（能力阶梯门控 CLG）** 台阶 ℓ_0<…<ℓ_L，ℓ_0=安全停/提问，ℓ_L=全自主。解锁谓词 Unlock(ℓ)=(概念接地覆盖≥c_ℓ)∧(D≤D_max(ℓ))∧(证伪器通过)∧(台阶专属校准达标)。升级只认真实证据（非命名、非纯仿真）；降级实时。Canary：新台阶先在子集 S_canary 上影子/小流量运行，证据回归（开放集错误率、新颖率、债务增速、证伪触发）超阈即自动回滚。单调性：台阶只改变动作保守度，高台阶仅在已验证包络内放松。

**定义 143（证伪器必备发布 FRR）** 每个被声明能力配证伪器 f=(scenario,observable,decision_rule)；触发即撤销该能力、降阶、概念重新接地、台账更新。发布前置：κ=1（每个关键假设至少一个证伪器）∧ 证伪器可运行（部署内廉价）或已预注册离线留出真实验证 ∧ 证伪器独立（不由被检验的先验/模型自身生成，须用真实锚点）。"无证伪器，无能力"。

**定义 144（词汇-能力台账 VCL 与 PCEO 算子、证书 J_ov）** 台账 L={(c,γ,supports,falsifiers,debt,audit)} 与台阶账 R={(ℓ,unlock_deps,debt,falsifiers,canary)}，两账通过"概念→台阶"边连接。PCEO 每检查点：①开放感知与 OSCN（含 ∅ 判定）；②概念分诊（provisional→探针提议；grounded→共形先验）；③MVP 查账（台阶许可/债务/证伪器）；④按概念假设做定向探针（VOI 由物理预测的不确定性驱动）；⑤证据门（继承第 57 轮 FSE，**不新增以名字为凭的证据类**）；⑥承诺/降阶/回滚。J_ov=(vocab_version,grounding_log,oscn_cal_log,alias_flags,novel_registry,rung_state,debt_ledger,falsifier_log,canary_log,rollback_log)。

## 2. 关键算法伪代码（完整版见产物区）

```python
def open_world_infer(M, r, obs, vocab, ledger):
    C = oscn_predict_set(obs, vocab, alpha_open)      # IP-140：含 ∅ 桶
    if NOVEL in C or len(C) > 1:                      # 拒绝命名
        return None, C, generic_conservative_probe(r) # 只提问/探询
    c = vocab.concept(next(iter(C)))                  # 名字 ≠ 证据
    return c, C, propose_targeted_probe(c)            # 用物理假设定向探询

def mvp_gate(ledger, rung):                           # IP-141/142
    if not ledger.unlock_deps_grounded(rung): return 'demote'
    if ledger.debt(rung) > debt_cap(rung):    return 'demote'
    if falsifier_coverage(rung) < 1.0:        return 'block'   # 无证伪器无能力
    if not canary_healthy(rung):              return 'rollback'
    return 'allow'                                     # 仍须再过证据门
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| OV-GCI | O(d_𝒱)/命名；接地 O(\|support\|) | O(\|𝒱\|+\|supp\|) | provisional 隔离、γ 诚实、别名一致 |
| OSCN | O(\|grounded\|)/查询；回退 O(N_cal) | O(N_cal) | ∅ 桶覆盖、α_open=α_in+α_out、拒绝命名 |
| MVSE | O(L·\|假设\|) 选择 | O(L) | 债务上界诚实、还债预算、κ=1 |
| CLG | O(1)+O(\|S_canary\|) | O(L+\|S_canary\|) | 升级有据、降级实时、回滚有效 |
| FRR | O(\|F\|) | O(\|F\|) | 证伪器可运行且独立 |
| PCEO | O(\|CP\|·(k_p+k_cons)·(C_VOI+d_𝒱)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|𝒱\|) | 分诊/查账/探询/证据门四段终止 |

**正确性定理（Open-World Staged Falsifiable Soundness, OWSFS 概要）**：在 A33–A40 上加 (A41) 开放集覆盖：对任意真实概念（含 y∉𝒱），P(y∈C_α(o)∪{∅})≥1−α_open，α_open=α_in+α_out，∅ 桶良定义，别名检测诚实；(A42) 命名隔离：provisional 不入证据门、接地只认真实探针、名字进口的物理先验只在共形带内作先验、不新增以名字为凭的证据类；(A43) 债务诚实：D(d) 上界未验证假设的风险、D_max 强制、β_repay 还债、债务上升即自动降阶；(A44) 证伪完备且独立：每个已发布能力的关键假设都有可运行或已预注册的证伪器，且证伪器不由被检验的先验/模型自身生成，canary 回滚有效。则：(i) 开放世界承诺失效率 ≤δ_f+α_open+ε_meta(k)+δ_probe+ε_h+δ_debt（词表外/新颖路径只经 α_open 贡献）；(ii) 表示-承诺分离：命名与概念代数只能经"改变探针目标/共形先验"或"触发提问/拒绝命名/降阶"影响系统，永不降低证据要求、永不放松台阶，交互单调性保持；(iii) PCEO 在 k_probes+k_cons 内终止，能力阶梯要么以已付证据升阶、要么降阶，债务不无限增长。

## 6. 本轮最大风险

**一句话**：开放词汇让"未知"第一次可以被廉价命名，MVP 让"能力"第一次可以被廉价发布，二者叠加的最大风险不是单点错误，而是**词汇通胀**——系统与人围绕一套并未切中现实关节的名字达成共识，台账自洽、台阶照升、债务看似还清，但所有"已付证据"都是用世界不承认的货币计价的；必须以"名字永不进证据门、接地只认真实探针、证伪器独立于被检验者、∅ 桶拒绝命名"四道硬闸，宁可对一个新东西保持"叫不出名字"的诚实，也不接受一套自洽却失真的词汇。

```python
def name_and_triage(phrase, obs, ctx, V, ledger):
    c = V.name(phrase, ctx)                       # 语言命名 → 概念
    if c is None:
        return None, generic_conservative_probe(ctx)
    c.state = 'provisional'                       # 默认临时：名字不是证据
    c.physics_hyp = inherit_physics(c, V.nearest_grounded(ctx))  # 进口先验
    if alias_conflict(c, V):
        c.alias_flag = True
        return c, alias_disambiguation(c)         # 别名冲突→先问再探
    return c, propose_targeted_probe(c.physics_hyp)

def ground_concept(c, ev, ledger):
    c.support.append(ev)
    c.gamma = grounding_score(c.support, c.physics_hyp)
    if c.gamma >= gamma_0 and len(c.support) >= n_min:
        c.state = 'grounded'                      # 只认真实探针接地
    if ev.falsifies(c):
        c.state = 'retired'                       # 证伪即退役
        ledger.revoke(c)                          # 回溯撤销其支撑过的台阶
    ledger.log(c, ev)
    return c

def concept_prior(c, conformal_belt):
    if c.state != 'grounded' or c.alias_flag:
        return None                               # provisional 不参数化承诺
    return project_into_belt(c.physics_hyp, conformal_belt)  # 仅共形带内
```

### IP-140 OSCN（开放集共形命名）

```python
def oscn_predict_set(obs, V, alpha_open):
    alpha_in, alpha_out = split_alpha(alpha_open)
    scores = {c: V.nonconformity(obs, c) for c in V.grounded}
    tau_in = V.calib_quantile(alpha_in)           # 已接地簇条件校准
    C = {c for c, s in scores.items() if s <= tau_in}
    nu = novelty(obs, V.support)                  # 到已接地支撑的距离
    tau_out = V.novelty_quantile(alpha_out)       # 真实新颖样本的校准分位
    if nu >= tau_out:
        C.add(NOVEL)                              # ∅：诚实地说"叫不出名字"
    return C                                      # 覆盖 ≥1-(alpha_in+alpha_out)

def refuse_to_name(C):
    return NOVEL in C or len(C) > 1               # ∅ 或歧义 ⇒ 禁止强行命名
```

### IP-141 MVSE（最小可行安全包络）

```python
def mvse_select(rungs, ledger, budgets, evidence_gate):
    best = None
    for l in rungs:
        if not ledger.unlock_deps_grounded(l):   continue
        if ledger.debt(l) > debt_cap(l):         continue
        if falsifier_coverage(l) < 1.0:          continue
        if not evidence_gate(l):                 continue
        score = utility(l) / (residual_risk(l) + eps)
        best = max(best, (score, l), key=lambda t: t[0])
    return best[1] if best else RUNG_SAFE_STOP    # 最小交付=安全停，不是硬发功能

def repay_debt(ledger, ev, beta_repay):
    for a in ev.retires_assumptions():
        ledger.debt -= weight(a)                  # 用真实探针注销债务
    return ledger
```

### IP-142 CLG（能力阶梯门控）

```python
def capability_update(rung, ev, ledger, canary):
    if ev.falsifier_triggered(rung):              # 证伪触发
        ledger.revoke_evidence(rung); canary.freeze(rung)
        return demote(rung)                       # 降级实时
    ledger.debt[rung] = repay(ledger.debt[rung], ev)
    if ledger.debt[rung] > debt_cap(rung):
        return demote(rung)                       # 债务超限即降
    if canary.regression(rung) > theta_canary:
        return rollback(rung)                     # 证据回归即回滚
    if unlock_predicate(rung + 1, ledger, ev):
        canary.promote(rung + 1)                  # 先 canary，不直接全量
    return rung

def unlock_predicate(l, ledger, ev):
    return (ledger.concept_coverage(l) >= c_l
            and ledger.debt(l) <= debt_cap(l)
            and falsifiers_pass(l, ev)
            and rung_calibration_ok(l, ev))       # 只认真实证据，不认命名
```

### IP-143 FRR（证伪器必备发布）

```python
def falsifier_required(rung, F, anchors, prior_or_model):
    for a in key_assumptions(rung):
        fs = [f for f in F if f.assumption == a]
        if not fs:
            return False                          # 无证伪器，无能力
        runnable = any(f.runnable() or f.preregistered(anchors) for f in fs)
        if not runnable:
            return False
        if all(f.generated_by(prior_or_model) for f in fs):
            return False                          # 必须独立于被检验者
    return True

def on_falsifier(f, rung, ledger):
    ledger.revoke(rung)                           # 撤销能力
    ledger.retire_concepts(f.evidence)            # 概念重新接地
    return demote(rung), f.observable             # 记录触发证据
```

```python
def pceo(x0, M, task, budget, consent, personas, ledger, vocab):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        c, C, proposal = open_world_infer(M, cp.region, M.obs[cp.region], vocab, ledger)
        if c is None or refuse_to_name(C):

            p = argmax(cands, key=lambda q: voi_open(q, M, c) - cost(q))
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if c is not None:
                c = ground_concept(c, last_evidence(M), ledger)
                proposal = propose_targeted_probe(c.physics_hyp) if c.state == 'grounded' else proposal
        gate = few_shot_evidence_gate_ov(core_contact(cp), M, personas, ledger)
        mv = mvp_gate(ledger, rung)
        if gate[0] == 'ok' and mv == 'allow':
            sched.append(commit(select_gait(schedule_risk(sigma, M)), M))
            log.append(tag_evidence_p(c, M, contact_level(cp))); continue
        if mv == 'demote' or mv == 'rollback':
            rung = demote(rung); ledger.current_rung = rung
        route = reroute(M, cp, risk_model) or route
        if route is None:
            return negotiate_or_stop(cp, M, consent,
                                     tau_int=tau_int(personas.active.auth))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OV-GCI | O(d_𝒱)/命名；接地 O(\|support\|) | O(\|𝒱\|+\|supp\|) | provisional 隔离、γ 诚实、别名一致（A42） |
| OSCN | O(\|grounded\|)/查询；回退 O(N_cal) | O(N_cal) | ∅ 桶覆盖、α_open=α_in+α_out、拒绝命名（A41） |
| MVSE | O(L·\|假设\|) 选择 | O(L) | 债务上界诚实、还债预算、κ=1（A43） |
| CLG | O(1)+O(\|S_canary\|) | O(L+\|S_canary\|) | 升级有据、降级实时、回滚有效（A44） |
| FRR | O(\|F\|) | O(\|F\|) | 证伪器可运行且独立（A44） |
| PCEO | O(\|CP\|·(k_p+k_cons)·(C_VOI+d_𝒱)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|𝒱\|) | 分诊/查账/探询/证据门四段终止 |

**正确性定理（Open-World Staged Falsifiable Soundness, OWSFS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 开放集覆盖：对任意真实概念（含 y∉𝒱），P(y∈C_α(o)∪{∅})≥1−α_open，α_open=α_in+α_out，∅ 桶良定义，别名检测诚实；**(A42)** 命名隔离：provisional 概念不进入证据门、接地只认真实探针、名字进口的物理先验只在共形带内作先验、不新增以名字为凭的证据类；**(A43)** 债务诚实：D(d) 上界未验证假设的风险、D_max 强制、β_repay 还债、债务上升即自动降阶；**(A44)** 证伪完备且独立：每个已发布能力的关键假设都有可运行或已预注册的证伪器，且证伪器不由被检验的先验/模型自身生成，canary 回滚有效。则：

1. **开放世界承诺健全性**：ID 且词表内路径 P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_debt；词表外/新颖路径贡献 ≤ α_open；命名隔离使"错误接地"不直接进入承诺，而先表现为额外探针、提问或降阶。
2. **表示-承诺分离（单调性保持）**：命名与概念代数只能经 (a) 改变探针目标/共形先验或 (b) 触发提问/拒绝命名/降阶影响系统，永不降低证据要求、永不放松台阶；MVP 只能收缩已交付能力面，不能收缩安全界；不存在"靠命名升阶"或"靠少交付降安全界"的路径。
3. **分级终止与债务有界**：PCEO 在 k_probes+k_cons 内终止；能力阶梯每次升级须付清对应债务且过证据门，债务在窗口内不上升，否则降阶。
4. **部署界**（对检查点与台阶取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + α_open + ε_meta(k) + δ_probe + ε_h + δ_debt)
             − P(接地错误未检出) − P(证伪器失效) − P(canary 回滚失败) − P(债务记账失真)
```

关键：**开放词汇给表达力、开放集共形给诚实、MVP 给交付纪律、证伪器给否决权**——四者都不增加"敢踩"的证据，只增加"会问、会等、会退"的能力；名字、能力、证据三者账目分离，是开放世界安全的最小可行结构。

## 6. 本轮最大风险

**一句话**：开放词汇让"未知"第一次可以被廉价命名，MVP 让"能力"第一次可以被廉价发布，二者叠加的最大风险不是单点错误，而是**词汇通胀**——系统与人围绕一套并未切中现实关节的名字达成共识，台账自洽、台阶照升、债务看似还清，但所有"已付证据"都是用世界不承认的货币计价的；必须以"名字永不进证据门、接地只认真实探针、证伪器独立于被检验者、∅ 桶拒绝命名"四道硬闸，宁可对一个新东西保持"叫不出名字"的诚实，也不接受一套自洽却失真的词汇。
