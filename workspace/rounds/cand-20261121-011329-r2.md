# 第 2 轮（新灵感循环第 2 轮；本轮灵感：「目标检测」×「零样本泛化」）

> **基线**：上一轮 MetricVoiceGauge-NCD-HUTDH-v17（定义 657–686；引理 137–142；实验 E691–E710）。
> 本轮纪律：**检测只产生假设、证书仍是唯一裁决、组合只能走已认证算子**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC，及 v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v13–v8 全部组件与不变式原样保留。六个新组件——OVCD（开放词表能力检测器）、CNA（能力非极大仲裁）、CPC（共形提议校准器）、ZSC（零样本组合认证器）、NDS（新颖度债务调度器）、ASM（属性原型记忆）——以**中立元接入 v17 语言层之上**，失效即严格退回 v17（引理 143），再沿 v17→v16→…→v6 退化。本轮只做三件事：把"语言 token→最近锚"的**闭集最近邻分类**改写为"**带背景类、多假设与 NMS 的开放词表能力检测**"；把"新颖组合靠共形外推"改写为"**只在组合证书代数内做零样本泛化**"；把"候选越多越好"改写为"**多重检验受控、新颖度只换活性**"。

## 0. 直觉与动机

**灵感 1（目标检测 → 能力不是被"分类"出来的，而是被"检测"出来的）**
直觉：v17 的 S2C 本质是一个**闭集最近邻分类器**：每个子任务 token 被硬投影到距离最近的单个认证锚，超过 τ 才输出 ⊥。但真实感知从不这么做。目标检测告诉我们三件事：(i) 同一区域常有**多个重叠假设**（"打开"可能是开门/开抽屉/开柜门），只取 top-1 会系统性丢召回；(ii) 检测器必须有一个**背景类**（background/null），否则"没有合适目标"会被迫误报成某个类；(iii) 多假设之后必须做 **NMS**，否则同一能力被重复执行。核心创新：**开放词表能力检测器（Open-Vocabulary Capability Detector, OVCD）**。每个 token 产生 K 个"能力提议" `p=(锚, 参数区域, objectness, 属性分解)`，并显式给出背景类；用**证书交并比（CIoU）**在能力区域上做**效应感知 NMS**：重叠且**效应等价**才是"重复"（抑制），重叠但**效应冲突**不抑制而是交给仲裁（不能同时执行）。关键反直觉点：**多一个假设不等于多一份授权**——OVCD 只是在 v17"存在一个可编译计划"这个存在量词下**枚举更多见证（witness）**，每个提议仍必须原路走 S2C→HCG→PSV；检测置信度永远只排序，不裁决。

**灵感 2（零样本泛化 → 零样本不是"零证书"，而是"把证书从实例搬到算子"）**
直觉：v17 最大的隐患正是"新颖组合"。标准监督学习靠"见过同类组合"来泛化；零样本泛化的真正教训是：**能泛化，靠的不是见过新组合，而是拥有正确的组合结构**——"给黄瓜削皮"里，"削皮"与"黄瓜"都见过，唯独"削皮×黄瓜"这个组合没见过；组合零样本（compositional zero-shot）要判断的不是"这个组合像不像训练样本"，而是"这个组合能否由已认证原子经**保持证书的组合算子**构造出来"。核心创新：**零样本组合认证器（Zero-Shot Composition Certifier, ZSC）+ 组合证书代数**。把每个子任务分解为属性原子（动作×对象×空间关系×约束），每个原子有属性证书；组合算子只有三类（顺序 `⊗`、参数插值 `⊞`、约束合取 `∧`），每类都有**认证开放（certified-open）**判定：缝隙非空、**效应足迹不相交或交互表判为良性**、参数域凸、约束可满足时，组合才落在**认证闭包 `Cl(F,Ω_open)`** 内。落不进去就是 ⊥，不是"外推一个分数"。关键反直觉点：**零样本的安全性不来自"新组合很像旧组合"，而来自"新组合是用保安全的算子拼出来的"**；因此它不依赖新组合上的可交换性，只依赖原子证书与算子代数——这正面对冲 v17 的风险。

**灵感 3（两者交汇 → 检测负责"有没有"，组合负责"能不能拼"，新颖度只买活性）**
直觉：检测解决"当前场景有哪些候选能力、哪个是背景"，组合解决"没见过的能力描述能否由已认证原子拼出"。两者接起来才完整：OVCD 给出多假设与背景类，ZSC 判断每个非背景提议是否在认证闭包内，CNA 在重复/冲突提议间做确定性仲裁，CPC 控制"这批提议里到底允许多少可能误报"，NDS 把剩余新颖度折算成**可执行长度与活性**。关键反直觉点：**新颖度不是授权货币，而是活性债务**——越新颖的组合，只能执行越短的前缀、越频繁回到 v17/v16；新颖度永远不会换来更大的动作集合。

**两者如何统一**
统一为 **v17 语言层之上的检测-泛化层**：v17 回答"哪些语言计划能被编译并在计划证书下执行"（`Exec_v17`），v18 回答"在开放词表与新颖组合下，哪些**能力提议**被检测、被组合证书认证、被多重检验控制，并以何种活性预算执行"（`Exec_v18`）。共享状态 `ζ_dg=(PropSet, β_set, Cl_open, q̂_prop, ν, D_novelty, proto_index, mode_dg)`。**OVCD 回答"候选有哪些、哪个是背景"，ZSC 回答"候选能否由已认证原子经开放算子拼出"，CNA 回答"重复与冲突如何确定性取舍"，CPC 回答"这批候选允许多少误报"，NDS 回答"这份新颖度只能换多长计划"**。六者不是六个补丁，而是"检测—组合—仲裁—校准—预算—记忆"的实现链；`Exec_v18⊆Exec_v17` 由引理 143 保证。

## 1. 研究问题

- **Q1（能力检测的几何与背景）**：能力区域 `R(p)` 如何在参数/状态空间定义，使 CIoU 有意义且高维不塌缩？objectness 如何与里程碑/阶层门控统一？背景类阈值如何校准才能既不强迫误报、又不吞掉合法零样本提议？K 与召回/延迟如何权衡？
- **Q2（组合证书代数）**：属性原子如何从自由语言中稳定分解（"轻轻把杯子放到桌沿"→动作/对象/关系/约束）？哪些算子可判为 certified-open？效应足迹与交互表如何获得、如何认证？认证闭包对未见交互是否封闭，还是必然留洞？
- **Q3（多重检验与重复/冲突）**：K 个提议同时接受时，如何用共形 p 值控制 FWER/FDR 而不与 v17 计划级 HCG 重复保守？效应感知 NMS 与冲突图最大权独立集如何确定性求解且不抑制互补能力？
- **Q4（新颖度、漂移与记忆）**：新颖度 `ν` 如何度量才不把"换个说法"误判为新颖？NDS 的"新颖度→活性"映射如何保证单调不增？ASM 的属性原型如何随词表漂移更新而**永不**把交互表标成 benign？组合零样本在长时程上的局部-全局缝隙如何暴露？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P33）

**P31 检测无特权律（Detection as Hypothesis, Certificate as Verdict）**
OVCD 只产生提议，不产生授权：每个提议必须能被 v17 的 S2C 编译为 `Anchors(m*,h*)` 内节点，并原路通过 v17 的 HCG/PSV；objectness、CIoU、NMS 分数一律只用于排序/抑制，**不得作为接受条件**。背景类只允许拒绝，不允许放行。K 增大只增加被过滤的候选，**不得提高单计划误接受率**（由 CPC 的多重检验保证）。

**P32 零样本组合证书律（Zero-Shot via Certified Combinators, Not Extrapolated Instances）**
新颖能力只能由 `Cl(F,Ω_open)` 中的表达式产生，其中 F 是已认证属性原子族，`Ω_open` 是当前认证开放的算子集；`Cl` 之外的表达式一律 ⊥。组合证书 `CC(e)` 必须逐原子给出属性证书、逐算子给出开放判定、逐缝给出适配器证书；**禁止对未见组合外推实例级共形分数**。开放算子集只能由离线认证/人工审计扩充，运行时（含 ASM 记忆）**不得新增**。

**P33 新颖度债务律（Novelty Buys Activity, Never Authority）**
新颖度 `ν(e)` 与允许执行长度 `k_ν` 满足：`ν` 越大 `k_ν` 单调不增；`D(e)=λ·ν(e)` 只作用于 NDS 的截断与重规划频率，不作用于任何证书阈值。`Exec_v18(ν↑)` 在集合意义下单调不增；新颖度不得换来新的锚、新的开放算子或更大的参数域。

## 3. 与基线的接口（如何退化）

- OVCD 失效（嵌入/检测服务不可用）⇒ 退回 v17 S2C 单假设最近邻——**等价 v17**；
- CNA 失效 ⇒ 保守模式：每条提议单独成计划、按 V(π) 串行、禁止并行——**等价 v17（活性下降）**；
- CPC 失效 ⇒ 退回 v17 HCG 计划级单检验、K 强制为 1——**等价 v17**；
- ZSC 失效 ⇒ 所有非背景提议按 v17 处理、**关闭零样本**（只允许校准集内组合）——**等价 v17（更保守）**；
- NDS 失效 ⇒ 新颖度债务置 0、完全交给 v17 APS 新鲜度阶梯——**等价 v17**；
- ASM 失效 ⇒ 空原型库：不做属性重排序——**等价 v17**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→…→v6 退化；
- **安全继承**：OVCD 只枚举 v17 存在量词下的见证、CNA 只抑制/丢弃、CPC 只拒绝、ZSC 只拒绝、NDS 只截短、ASM 只重排序。六端口互不相交，均不能新增锚、算子或放宽阈值；`Exec_v18⊆Exec_v17` 由引理 143 保证，`⊆Exec_v16` 由传递性。

## 4. 预期贡献

1. **开放词表能力检测**：首次把"语言→能力格"从最近邻闭集分类改写为带背景类的多假设检测，给出能力区域、CIoU 与效应感知 NMS，使"没有合适能力"不再被迫误报；
2. **组合证书代数与认证闭包**：把零样本泛化从"实例级共形外推"改写为"原子证书 + 保持证书的算子"，证明闭包内新颖组合无需新组合上的可交换性即可保持 `Exec` 覆盖，直接对冲 v17 的新颖组合风险；
3. **效应感知 NMS + 冲突图仲裁**：区分"重复"（效应等价、应抑制）与"冲突"（效应不相容、不可同时执行），用确定性 MWIS 取代 v17 的计划价值竞争，统一 Q4/E699 的仲裁问题；
4. **提议级多重检验**：把 v17 的单计划共形检验扩展为提议集合的 FWER/FDR 控制，使"检测更多候选"不抬高单计划误接受率；
5. **新颖度债务调度**：新颖度只兑换更短前缀与更高重规划频率，给出"新颖性↑ ⇒ 活性单调↓"的边界，避免零样本成为授权扩张的暗门；
6. **检测—组合—仲裁—校准—预算—记忆六层分离**：v12/v13/v15/v16/v17/v18 分别管允许什么、时限内实现多少、技能如何扩散、全身行为如何执行、语言计划如何编译调度、开放词表与新颖组合如何被检测与认证，用 `Exec_v18⊆Exec_v17⊆Exec_v16` 串起；E711–E730 覆盖能力检测、背景拒识、NMS/仲裁、多重检验、组合零样本、组合越狱、漂移与端到端消融。

## 5. 本轮最大风险

**一句话**：OVCD 能检测出"每个原子都与某种已认证能力相似"的新颖组合，ZSC 也能因为它由"缝隙非空、效应不相交、参数凸、约束可满足"的开放算子拼成而给出组合证书，但这类证书只保证**逐原子与逐缝的局部覆盖**，不保证**长时程全局效应**（累积接触图、力矩/重心漂移、不可逆状态）仍被覆盖——于是会出现"每一步都在证书内、整条轨迹却在证书外"的零样本组合：检测通过、组合证书通过、多重检验通过、里程碑许可满足，唯独没有任何一个局部证书为整条轨迹的全局安全负责。

## 1. 关键算法骨架

```python
# IP-415 Open-Vocabulary Capability Detector：多假设 + 背景类
class OpenVocabularyCapabilityDetector:
    def __init__(self, anchors, embedder, k_props=5, tau_bg=0.35):
        self.anchors = anchors          # [(n, mu_n, NC_n, m_n, h_n, Theta_n)]
        self.embed = embedder
        self.K = k_props
        self.tau_bg = tau_bg

    def objectness(self, e, mu, nc, x):
        # 只做校准分数（温度缩放/等渗），不含任何授权语义
        sim = cosine(e, mu)
        gate = 1.0 if nc.Pre.contains(x) else 0.0
        return calibrate(sim) * gate

    def detect(self, t, x, m_star, h_star):
        e = self.embed(t, x)
        props = []
        for (n, mu, nc, m_n, h_n, dom) in self.anchors:
            if m_n > m_star or h_n > h_star:
                continue                          # P28：永不向上投影
            o = self.objectness(e, mu, nc, x)
            if o < self.tau_bg:
                continue
            theta = project(dom, param_of(t))
            if theta is None:
                continue
            props.append(Proposal(n, theta, o, decompose(t)))
        props = sorted(props, key=lambda p: p.o, reverse=True)[:self.K]
        if not props:
            return [BACKGROUND]                   # 背景类：显式拒识
        # 每个提议生成一个"重词化"的语言见证，保证 v17 S2C 会投影到同一锚
        return [p.with_witness(relabel(t, p.n)) for p in props]

    def detect_plan(self, pi, x, m_star, h_star):
        # 受限 beam：每 token top-K，beam 宽度 B，返回 B 条候选语言计划
        layers = [self.detect(t, x, m_star, h_star) for t in pi.tokens]
        return beam_search(layers, beam=self.K)   # 产出仍是语言计划（v17 的见证）


# IP-416 Capability Non-maximum Arbitration：重复抑制 + 冲突仲裁
class CapabilityNonmaximumArbitration:
    def __init__(self, tau_nms=0.5, tau_conf=0.3):
        self.tau_nms, self.tau_conf = tau_nms, tau_conf

    def duplicate(self, p, q):
        return (self.ciou(p.R, q.R) > self.tau_nms
                and same_family(p.n, q.n) and effect_equiv(p, q))

    def conflict(self, p, q):
        if self.ciou(p.R, q.R) > self.tau_conf and not effect_equiv(p, q):
            return True
        # 交互表未知也算冲突（unknown 不容许并行），绝不默认 benign
        return not interaction_benign(p.beta, q.beta)

    @staticmethod
    def ciou(a, b):
        inter = volume(intersect(a, b))
        union = volume(a) + volume(b) - inter
        return inter / union if union > 0 else 0.0

    def arbitrate(self, props, value=lambda p: p.o):
        # 1) 重复抑制：保留 objectness 最高者，确定性 tie-break = 锚 id
        kept = []
        for p in sorted(props, key=lambda p: (-value(p), p.n)):
            if not any(self.duplicate(p, q) for q in kept):
                kept.append(p)
        # 2) 冲突图最大权独立集：K 小（≤8），精确分支定界 + 确定性顺序
        graph = {p: [q for q in kept if self.conflict(p, q)] for p in kept}
        return mwis_exact(graph, weight=value, tiebreak=lambda p: p.n)


# IP-417 Conformal Proposal Calibrator：提议级多重检验
class ConformalProposalCalibrator:
    def __init__(self, calib_scores, alpha=0.05, mode='BH', k_max=8):
        self.calib = sorted(calib_scores)   # 提议级非一致性分数
        self.alpha, self.mode, self.k_max = alpha, mode, k_max

    def p_value(self, s):
        ge = sum(1 for c in self.calib if c >= s)
        return (1 + ge) / (len(self.calib) + 1)

    def accept(self, props):
        if not props:
            return []
        ps = [self.p_value(p.score) for p in props]
        if self.mode == 'bonferroni':
            m = self.k_max                      # 用固定上界，避免随机 K
            return [p for p, pv in zip(props, ps) if pv <= self.alpha / m]
        # Benjamini-Hochberg：PRDS/独立下控 FDR ≤ alpha
        order = sorted(range(len(ps)), key=lambda i: ps[i])
        chosen = []
        for rank, i in enumerate(order, start=1):
            if ps[i] <= self.alpha * rank / len(ps):
                chosen = order[:rank]
        return [props[i] for i in chosen]


# IP-418 Zero-Shot Composition Certifier：组合证书代数
class ZeroShotCompositionCertifier:
    def __init__(self, attr_table, interaction_table, open_ops):
        self.attr = attr_table              # 已认证属性原子 -> AC_alpha
        self.int = interaction_table        # 认证交互表（运行时只读）
        self.open_ops = open_ops            # 离线认证的开放算子集

    def is_open(self, op, a, b):
        if op == 'seq':
            sc = intersect(self.attr[a].post, self.attr[b].pre)
            return (sc is not None and sc.volume() >= MARGIN_SC
                    and self.int(a, b) == 'benign'
                    and disjoint(EC(self.attr[a]), EC(self.attr[b])))
        if op == 'interp':
            return convex(self.attr[a].param) and convex(self.attr[b].param) \
                   and bounded_interp(self.attr[a], self.attr[b])
        if op == 'conj':
            return satisfiable(self.attr[a].cons, self.attr[b].cons) \
                   and margin_ok(self.attr[a], self.attr[b])
        return False

    def certify(self, expr):
        # 结构递归：所有原子已认证，所有算子认证开放且局部条件成立
        for atom in atoms(expr):
            if atom not in self.attr:
                return None                 # 闭包外：⊥，不外推
        for op, a, b in operators(expr):
            if op not in self.open_ops:
                return None                 # 未认证算子：⊥
            if not self.is_open(op, a, b):
                return None                 # 交互未知/效应相交/约束不可满足：⊥
        return CompositionCertificate(atoms(expr), operators(expr),
                                      adapters(expr), support=set(self.attr))


# IP-419 Novelty-Debt Scheduler：新颖度只买活性
class NoveltyDebtScheduler:
    def __init__(self, lam=0.5, min_len=1):
        self.lam, self.min_len = lam, min_len

    def novelty(self, expr, cert):
        n_atoms = len(atoms(expr))
        unsupported = sum(1 for a in atoms(expr) if a not in cert.support)
        unsupported += sum(1 for o in operators(expr) if o not in OPEN_SUPPORT)
        return min(1.0, unsupported / max(1, n_atoms + len(operators(expr))))

    def schedule(self, nodes, expr, cert):
        nu = self.novelty(expr, cert)
        k = max(self.min_len, int(len(nodes) / (1 + self.lam * nu)))
        return nodes[:k], k, nu       # 只截短；随后仍走 v17 APS 阶梯
```

## 3. 推导

**引理 143（检测-泛化层的保守扩张）** 设 (i) OVCD 只产出 v17 语言支持中的见证（重词化/属性分解后的语言计划），(ii) CNA 只抑制或丢弃提议，(iii) CPC 与 ZSC 只拒绝，(iv) NDS 只做前缀截断，(v) ASM 只重排序，(vi) 所有保留计划仍原路通过 v17 的 S2C/HCG/PSV，则 `Exec_v18 ⊆ Exec_v17`。证明：v17 的 `Exec_v17` 是存在量词定义——存在一个可被 S2C 编译、被 HCG 接受、被 PSV 预验通过的语言计划；OVCD 只枚举该存在量词的更多见证，不改变量词范围。CNA/CPC/ZSC/ASM 是对候选集的单调过滤或重排序，NDS 是前缀截断；前缀截断由 v17 引理 139/140 保证 PC 对前缀封闭。故任何被 v18 执行的计划原本就在 `Exec_v17` 中。∎ 推论：**v18 的六个端口都无法新增授权；检测更多、组合更新颖，最坏只是活性下降。**

**引理 144（效应感知 NMS 与冲突仲裁的确定性与不误抑）** 设 CNA 先按 objectness 降序、以锚 id 为确定性 tie-break 做重复抑制（仅当 CIoU > τ_nms ∧ 同族 ∧ 效应等价），再在冲突图上求最大权独立集（权重为 V，确定性顺序）。则 (i) 输出无重复对；(ii) 输出无冲突对；(iii) NMS 阶段永不抑制"非重复"提议；(iv) 整个算子在相同输入上输出唯一。证明：(i) 贪心只删除与已保留者构成 Dup 的项；(ii) MWIS 输出是冲突图的独立集；(iii) Dup 是抑制的唯一条件，非 Dup 对不可能在 NMS 阶段被删；(iv) 全序 tie-break（−V, 锚 id）消除平局，MWIS 分支定界按固定顺序展开。∎ 注：MWIS 是全局取舍，可能丢弃某条与已选项互补、却与另一已选项冲突的提议；被丢弃者必与某已选项冲突，故不违反"互补不误抑"的局部语义。

**引理 145（提议级共形多重检验）** 设校准提议与当前提议在同一分层内可交换、分数有界，共形 p 值 `ρ(p)=(1+#{c≥s_p})/(N+1)` 有效。则：(a) Bonferroni 规则 `ρ(p) ≤ α/K_max` 满足 `P(至少一个误接受) ≤ α`；(b) Benjamini–Hochberg 在 PRDS 或独立下满足 `FDR = E[FP/max(1,TP+FP)] ≤ α`。证明：(a) 对每个提议，有效 p 值满足 `P(ρ≤α/K_max)≤α/K_max`，并集界给出 FWER≤α；(b) BH 的标准 FDR 定理，PRDS 下成立；共形 p 值对单调选择规则保持有效性。∎ 推论：**K 增大只增加检验个数，不抬高每个计划的误接受率**；这也解释了为什么 OVCD 可以安全地多假设。

**引理 146（认证闭包的零样本覆盖）** 设表达式 `e ∈ Cl(F,Ω_open)`，每个原子 `α∈F` 的 `AC_α` 含于 v16 的 NC，且每个算子在 `Open` 判定下满足：`⊗` 需缝隙非空 + 交互良性 + 效应足迹不相交；`⊞` 需参数凸 + 有界；`∧` 需约束可满足 + 余量充分。则 `e` 的执行全程每一状态被某个原子 NC 或缝隙适配器证书覆盖，即 `Exec(e) ⊆ Exec_v16`；且该结论**不使用** `e` 与校准集的可交换性。证明：对表达式结构做归纳。基例：原子由 AC_α⊆NC 与 v16 引理 131 覆盖。归纳步：`⊗` 的缝隙由 v17 引理 139 的 SC 覆盖，效应不相交排除跨原子的新增副作用；`⊞` 在凸参数域内，任意插值点仍落在认证参数集；`∧` 的交集非空且带余量，仍落在两原子前置/运行域内。全程没有调用任何实例级共形分位数。∎ 推论：**零样本泛化的安全性来自算子代数，而不是"新组合像旧组合"；但结论是"证书覆盖"，不是"任务语义正确"或"长时程全局安全"（见引理 149）。**

**引理 147（新颖度债务的单调性）** 设 `k_ν(ν)=max(1,⌊T/(1+λν)⌋)` 关于 ν 单调不增，NDS 只做前缀截断，ASM 只重排序且不写开放算子/交互表，则 `Exec_v18` 关于 ν 单调不增，且 `Exec_v18` 不因记忆内容而扩大。证明：前缀截断由 PC 前缀封闭性保序；ν 增大只会缩短 k，不改变任何阈值；ASM 无 `update_open_ops`/`set_benign` 写接口，记忆仅作用于提议排序，排序不改变接受集的上界（与 v17 引理 141 同构）。∎ 推论：**新颖度是活性货币，不是授权货币；记忆投毒最多让系统更保守或更笨。**

**引理 148（背景类与开放集拒识）** 设背景阈值 τ_bg 由守留集共形校准，使真实可执行提议的 objectness 低于 τ_bg 的概率 ≤ β，且 OVCD 在无提议高于 τ_bg 时输出 ⊥_bg。则未知/不可组合输入被显式拒识，被迫误分类率 ≤ β；且背景类永不进入 S2C，故 `⊥_bg` 不产生任何授权。证明：阈值校准给出假背景率界；背景分支在代码路径上直接返回 `plan_nodes=None`，不经过任何编译或接受算子。∎ 推论：**"没有合适能力"第一次成为一个合法的、可校准的输出**，而不是被迫选最近的锚。

**引理 149（局部-全局不可传递性 / 组合安全不封闭）** 存在已认证原子 a,b，满足 `a,b∈Exec_v16`、缝隙 `Post_a∩Pre_b` 非空且带余量、交互表 `Int(a,b)=benign`、效应足迹在原子级不相交，但组合轨迹 `a⊗b` 违反 v16 只在已知 BT 结构上维持的全局不变式 I（如累积接触图、重心/力矩包络、不可逆状态）。证明：构造反例——a 为"夹持并保持"，b 为"沿未建模方向平移"，单步均在各自 NC 内、原子效应足迹也未相交，但连续执行使接触力沿未标定方向累积，越过全局稳定包络；v16 的 MCA/WCB 只在已枚举的里程碑/行为树上检查 I，未覆盖该新顺序。故逐原子 + 逐缝证书不蕴含全局安全。∎ 推论：**ZSC 证明的是"覆盖"，不是"无害"；新颖组合的全局安全必须另行由 v16 全局不变式或影子预演承担——这正是本轮最大风险。**

## 7. 已知风险与失效模式

1. **属性分解的语义错配**：安全地执行了"动作 A×对象 B"，但用户想说"动作 A×对象 C"；证书覆盖 ≠ 语义正确。缓解：多分解器投票、交互式澄清、语义一致性回传 HCG、把分解置信度计入 ν。
2. **认证闭包过小导致活性塌缩**：开放算子与良性交互表覆盖有限，零样本大量落 ⊥，系统长期退化为 v17。缓解：离线扩充交互表、算子族共享、活性监视、按里程碑放宽（但仍不扩权）。
3. **交互表不完整的两难**：未知交互默认 `unknown`（当作冲突）会过度保守；若默认 benign 则组合越狱。缓解：**永不默认 benign**、影子预演、离线认证队列、保守前沿。
4. **CIoU 高维塌缩**：能力区域体积随维度指数收缩，NMS 阈值失去意义。缓解：任务子空间投影、低维充分统计、自适应 τ_nms、按证书族归一化。
5. **MWIS 组合爆炸**：K 增大时精确解指数级。缓解：K 硬上限（≤8）、贪心近似 + 局部搜索、冲突图区间结构、异步仲裁。
6. **CPC 可交换性在开放词表下失效**：新词/新组合破坏校准分布。缓解：分层校准、按属性族校准、漂移触发重校准、保守 α。
7. **背景阈值两难**：τ_bg 过高吞掉合法零样本，过低强迫误报。缓解：共形阈值、双阈值迟滞、背景/未知/已知三分。
8. **ASM 原型投毒**：记忆可扭曲分解与排序，虽不能扩权但可系统性压制正确提议。缓解：投毒过滤、签名、单源配额、周期审计、排序不进入接受边界。
9. **效应足迹估计误差**：EC 低估导致 `disjoint` 误判为真，把不安全交互判成 benign。缓解：EC 上界估计、交互表人工抽检、影子预演、保守余量。
10. **局部-全局安全缝隙（核心风险）**：逐原子 + 逐缝证书不覆盖长时程累积效应。缓解：v16 全局不变式前置、影子预演、长计划强制分段回 v17、全局包络监视。
11. **检测延迟与 K 的开销**：K 个见证 × beam × S2C 编译可能拖慢接受路径。缓解：全程异步、K 小、ANN、缓存、只对 top-1 做完整 ZSC/PSV。
12. **多重保守叠加**：OVCD K 提议 × CPC × ZSC × HCG × PSV 五层过滤，通过率可能趋零。缓解：分层检验、只在最终候选做重检验、动态 α、活性报警、按证书族共享。

## 8. 本轮最大风险

**一句话**：OVCD 检测出"每个原子都与已认证能力相似"的新颖组合，ZSC 也因其由"缝隙非空、效应不相交、参数凸、约束可满足"的开放算子拼成而给出组合证书，但组合证书只保证**逐原子与逐缝的局部覆盖**（引理 146），不保证**长时程全局效应**（累积接触图、力矩/重心漂移、不可逆状态）仍被覆盖（引理 149）——于是出现"每一步都在证书内、整条轨迹却在证书外"的零样本组合：检测通过、组合证书通过、多重检验通过、里程碑许可满足，唯独没有任何一个局部证书为整条轨迹的全局安全负责。
