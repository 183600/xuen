# 第 43 轮（新循环第 1 轮） · Gait-Cert-Sim：步态相位混合证书 × 捕获点可行核 × 接触域虚拟仿真——让双足机器人在「接触切换」处也可认证（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。v19 自陈最大风险是「仿真偏差累积 + 检索幻觉」导致证书静默失效。本轮两个灵感词把问题推到更硬的场景：**「双足机器人」暴露了 v19 的连续 Lipschitz margin 假设在接触切换处必然破裂**——单/双支撑切换、脚跟触地、摆动腿落地、打滑都是离散事件，有效惯量与约束在瞬间改变，且系统欠驱动，不是所有状态都能被「守住」；**「虚拟仿真」则提供了唯一能在接触瞬间反复注入扰动的可控实验场**——可微接触、接触参数随机化、反向可达性、故障注入，把仿真从「状态风洞」升级为「接触证书铸造厂」。核心命题：**双足的证书载体不是全局安全集，而是「接触模式 × 步态相位」索引的混合证书 + 落脚点可捕获域（viability kernel）**；仿真要验证的不是 margin 的均值，而是**每次接触切换的重置条件**与**接触参数不确定集上的鲁棒性**。

## 0. 直觉与动机

**灵感 1（双足机器人 → 证书必须从「连续安全集」搬到「混合自动机 + 可行核」）**：v19 的全部界都写成 `|m(x)−m(x')| ≤ L_m‖x−x'‖`，并把安全理解为「margin 不低于阈值」。但双足的物理本质是**混合、欠驱动、接触丰富**：支撑腿切换使自由度与约束维数跳变，脚跟触地产生冲量，摆动腿落地改变质心动力学，打滑则让摩擦锥约束突然失效。每次接触事件，margin 可能不连续，甚至「上一模式安全、下一模式不可恢复」。直觉上正确的对象是**混合自动机上的相位条件证书**：每个接触模式 q（双支撑 DS、左单支撑 LS、右单支撑 RS、腾空 FL）各有局部证书 `(θ_q, L_{m,q}, Inv_q)`；每条模式转移 e=(q,q') 额外要求「出口不变式 ∧ 入口不变式 ∧ 守卫留白 ∧ 重置后 margin 不塌陷」。更深一层：双足不是「任意状态都能守」，而是「只有落在可捕获域里的状态才存在未来落脚序列」——所以安全证书的下半部分必须是**可行核（viability kernel）**，而不是简单的前向不变集；证书回答的是「还存在安全的下一步吗」，这与「当前状态是否安全」是不同问题。

**灵感 2（虚拟仿真 → 从「状态风洞」升级为「接触证书铸造厂」）**：v19 的 Isaac Sim 主要做域随机化与故障注入，仍是「状态压力测试」。双足的关键量是接触：摩擦系数 μ、接触刚度/阻尼、恢复系数、触地延迟、足底几何、地面坡度与软硬。虚拟仿真的独特价值有三点。其一是**可微/可重放的接触实验**：同一条触地事件可以改 μ、改刚度、改延迟反复重跑，测出切换重置映射 `R_e` 对接触参数的敏感度 κ_e，从而给出**接触感知的迁移界**，而不是用状态空间 W_1 粗放地兜底。其二是**反向可达性算可行核**：LIPM 下的 DCM 动力学是线性的，N 步可捕获域可由反向可达性递推成多面体；仿真负责补上全身动力学、关节限位、足底滚转与角动量修正。其三是**接触故障菜单**：滑面、软垫、台阶边缘、侧向推、落地延迟、单腿失效，把「罕见但致命」的接触切换变成可回归用例。仿真由此产出三类可直接部署的资产：相位证书参数、可行核查表、接触不确定集 Δ_contact 与逐边收缩系数。

**灵感 3（耦合 → 相位锁定的证书飞轮）**：v19 飞轮是 `Sim→RAG→Edge→Sim`，但边缘运行没有「相位」概念。双足要求运行时与步态相位同步：证书查询的键必须包含相位 φ（或接触模式 q 与相位桶），监控预算按相位分配（双支撑期便宜、触地瞬间昂贵），恢复动作也必须按相位可选（延长双支撑、调整落脚点、降速、下蹲）。耦合后的飞轮是 `Contact-Sim → 可行核/相位证书 → CKB 步态模板 → ECR 相位查表/INT8 → 实机接触事件与 GRF → 接触参数再辨识 → Contact-Sim`。这样 v19 的「偏移检测」被替换成更早期、更物理的信号：**触地冲量残差、打滑率、DCM 预测误差**，在真正失稳之前就触发重验证。

**与 v19 的差异（不推倒，只加层）**：v19 的证书是「连续状态 → 标量 margin」；v8 的证书是「(接触模式, 相位) → 局部 margin + 切换条件 + 可行核」；v19 的仿真验证 margin 分布；v8 额外验证重置映射与接触不确定集；v19 的成本优化是「离线换在线」；v8 增加「落脚点可行性查询」这一双足特有的低成本路径。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（步态接触混合自动机）**：`H = (Q, X, U, W, E, f_q, Guard, Reset)`。模式集 `Q = {DS, LS, RS, FL}`；连续状态 `x = (c, ċ, θ_b, θ̇_b, q_j, q̇_j) ∈ X` 含质心、躯干姿态与关节；`f_q` 为模式内动力学；转移边 `e=(q,q') ∈ E` 由接触事件触发，守卫 `Guard_e ⊆ X` 是触地/离地条件；`Reset_e : X → X` 是冲量映射（含速度跳变）。步态调度 `σ: φ ∈ [0,1) → Q` 给出相位到模式的映射。**要求**：相位估计误差有界 `|φ̂ − φ| ≤ δ_φ`，由此定义相位管 `Tube_φ = [φ̂−δ_φ, φ̂+δ_φ]`，运行时只允许在相位管内使用相位条件证书。

**定义 39（相位条件混合证书）**：对每个模式 q，证书 `C_q = (m_q, θ_q, L_{m,q}, Inv_q)`，其中安全集 `S_q = {x : m_q(x) ≥ θ_q}`，且仅要求在模式内满足 Lipschitz：`|m_q(x) − m_q(x')| ≤ L_{m,q}‖x − x'‖`。对每条转移边 `e=(q,q')`，**切换证书**定义为

`Trans_e(x) ⇔ x ∈ Inv_q ∩ Inv_{q'} ∧ h_e(x) ≥ ε_h ∧ m_{q'}(Reset_e(x)) ≥ θ_{q'} − L_{m,q'}·‖ΔR_e(x)‖`，

其中 `h_e(x)` 是到守卫面 `g_e(x)=0` 的有符号留白，`ε_h` 是切换留白下界，`ΔR_e` 是接触参数扰动导致的重置误差。**命题 39**：若模式内不变式、每条边的切换证书、以及初始条件同时成立，则混合轨迹在接触图上的拼接保持 sound；即使 `m` 在模式边界不连续，证书也不会因「跨模式套用同一 Lipschitz 常数」而失效。

**定义 40（DCM、N 步可捕获域与可行核）**：在 LIPM 近似下，质心水平动力学 `ẍ = ω²(x − p)`，`ω = √(g/z_c)`；发散运动分量（DCM）`ξ = x + ẋ/ω`，满足 `ξ̇ = ω(ξ − p)`。给定当前支撑多边形 `P_k` 与可行落脚点集 `F_k`，定义 **N 步可捕获域** 递推

`V_0 = {ξ : ξ ∈ P_k ⊖ B_{ρ_safe}}`，
`V_{k+1} = {ξ : ∃ p ∈ F_{k+1}, ξ_T(p) = p + (ξ − p)e^{ωT_step} ∈ V_k}`。

**落脚可行核**取 `K_viab = ⋃_{k=0}^{N_max} V_k`。**命题 40**：LIPM 下若 `P_k, F_k` 为多面体，则每个 `V_k` 仍为多面体（仿射预像与并集封闭），可精确递推；全身动力学与角动量修正作为 `V_k` 的收缩项 `V_k^full ⊆ V_k` 由仿真估计。运行时 `m_step(ξ, φ) = dist(ξ, ∂V_{k(φ)})`，`k(φ)` 为剩余步数。

**定义 41（接触不确定集与鲁棒混合证书）**：接触参数 `δ_c = (μ, k_c, c_c, e_r, τ_d, n_foot) ∈ Δ_contact`，其中 μ 为摩擦系数、`k_c/c_c` 为接触刚度/阻尼、`e_r` 为恢复系数、`τ_d` 为触地/执行延迟、`n_foot` 为足底接触点噪声。**鲁棒混合证书**要求 `Trans_e(x)` 对 **所有** `δ_c ∈ Δ_contact` 成立，而非名义值成立。对模式内 margin，采用区间/鲁棒对偶收缩：`m_q^rob(x) = min_{δ_c∈Δ_contact} m_q(x; δ_c)`。**命题 41**：若 `Δ_contact` 覆盖真实接触参数且 `m_q^rob` 在其上取下确界，则鲁棒证书在实机上保持 sound；覆盖度不足是主要失效源，必须由定义 42 的实测界兜底。

**定义 42（接触感知的 Sim-to-Real 迁移界）**：对每条转移边 e，令 `R_e^{δ}(x)` 为参数 δ 下的重置映射，`δ_0` 为仿真名义参数。定义**重置敏感度** `κ_e = sup_{x,δ} ‖R_e^{δ}(x) − R_e^{δ_0}(x)‖ / ‖δ − δ_0‖`，以及**接触冲量残差** `W_c = sup_e ‖Δp_e^real − Δp_e^sim‖`（冲量/动量差，而非状态分布距离）。则

`m_{q'}^real(x) ≥ m_{q'}^sim(x) − L_{m,q'}·κ_e·‖δ_c − δ_0‖ − L_{m,q'}·W_c/ω`，

取逐边收缩系数 `α_e = 1 + (κ_e‖δ_c−δ_0‖ + W_c/ω) / max(ε, θ_{q'})`，实机阈值 `θ_e^real = α_e·θ_e^sim`。**与 v19 的 W_1 界相比**：`W_c` 直接度量「接触瞬间错了多少动量」，对双足比状态分布 Wasserstein 更紧、更可观测（GRF/IMU 即可估）。

**定义 43（步态-接触知识库与相位检索）**：`KB = {(φ_i, ψ_i, Σ_i, C_i, V_i, Ξ_i, Π_i)}`，其中 `Σ_i` 是接触调度（步态类型、步长/步高、支撑时序），`C_i` 是相位条件证书模板，`V_i` 是可行核表，`Ξ_i` 是接触反例集（滑移、绊倒、落地冲量超限），`Π_i` 是步态课程相位序列。检索器 `R(φ, ψ, Σ) = Top-k(KB, sim_task(φ,φ_i)·sim_env(ψ,ψ_i)·sim_gait(Σ,Σ_i))`。**相位检索**：先按步态类型与地形类检索，再按当前相位只取相关的模式子证书，避免把不适用的整段步态模板硬拼。

**定义 44（双足成本模型 v3）**：`COT_biped = C_sim^contact/N_deploy + C_edge^gait·T_life + C_fall·E[N_fall] + C_human·N_verify`。其中 `C_edge^gait = Σ_φ P(φ)·(c_lookup + c_monitor(φ))`，双支撑相位只查表（≈5μs），触地窗口启用 INT8 监控（≈100μs）；`C_fall` 显式计入跌倒维修/停工成本，使「保守到不敢走」与「激进到摔」在同一目标下比较。**Pareto 前沿**在 `(COT_biped, 跌倒率, Nominal 步态占比)` 三维上给出。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-51/52/53/54/55/56/49/50/45/47）

### 2.1 IP-57 HYBRID-GAIT-CERTIFIER（HGC：混合步态证书器）
1. **相位证书模板**：每个模式用「DCM 二次型 + 关节限位 CBF + 角动量残差项」参数化 `m_q`；模板从 CKB 检索热启动。
2. **仿真引导 CEGAR**：在模式内找 margin 违反，在转移边找「重置后 margin 塌陷」与「守卫留白不足」反例；反例驱动收紧 `θ_q`、增大 `ε_h`、细化模式划分（如把「平足触地/脚尖触地」拆成子模式）。
3. **接触鲁棒收缩**：在 `Δ_contact` 上做鲁棒优化/区间传播，输出 `m_q^rob` 与逐边 `α_e`；敏感度高的边标记为「高接触风险边」，提高监控频率。
4. **相位管证书**：对 `δ_φ` 内的相位漂移，把 `m_q` 沿相位方向做管状保守化，输出 `m_q^tube(x, φ̂)`，避免相位抖动导致证书跳变。

### 2.2 IP-58 CAPTURE-VIABILITY-KERNEL（CVK：捕获点可行核）
1. **LIPM 精确递推**：多面体反向可达性算 `V_k`，给出解析/半解析的可捕获域；对步长、步高、支撑时序参数化。
2. **全身修正**：用仿真批量 rollout 估计 `V_k^full` 相对 `V_k` 的收缩量（角动量、腿长限制、滚转足、关节速度上限），学习一个保守残差 `r_full(ξ, φ)`，保证 `V_k^full = V_k ⊖ r_full`。
3. **落脚点安全查询**：在线只做 `dist(ξ, ∂V_{k(φ)})` 与候选落脚点包含测试，O(log N) 查表 + O(1) 比较；把「能否下一步」从规划器黑箱变成可审计证书。
4. **恢复策略库**：按 `m_step` 与相位映射到 {延长双支撑, 落脚点后撤, 步高加大, 降速, 下蹲}, 每个恢复策略自带可行核收缩与切换证书。

### 2.3 IP-59 CONTACT-DOMAIN-SIMULATOR（CDS：接触域仿真与迁移标定）
1. **接触参数随机化**：Sobol 覆盖 `μ∈[0.2,1.0]`、刚度/阻尼、恢复系数、触地延迟、足底形状，生成 `Δ_contact` 的覆盖证据（参数空间体积覆盖率）。
2. **可微接触辨识**：从 GRF/关节力矩/IMU 反演 `δ_c`，并输出**可辨识性矩阵**；不可辨识方向直接并入 `Δ_contact` 的不确定半径，禁止「假精确」。
3. **接触迁移界**：逐接触事件对齐冲量，估计 `W_c` 与 `κ_e`，输出 `α_e` 与红线边集合；把 v19 的全局 `W_1` 校准替换为逐边接触校准。
4. **接触故障菜单**：滑面、软垫、台阶边、侧推、落地延迟、单腿失效；每条故障生成「反例轨迹 + 语义标签 + 归属模式/相位」，入 KB `Ξ`。

## 5. 本轮最大风险

**一句话**：双足方案的最大风险是把 **LIPM/DCM 的可捕获域当成了全身动力学的证书**——一旦接触参数在实机上不可辨识、或角动量/腿长/滚转足带来的降阶误差超出收缩界，证书就会在最需要它的触地瞬间恰好失效，而且这种失效会被「仿真里明明能走」的假象掩盖；因此 E87（切换证书）与 E89（接触迁移界）必须作为红线实验，任何一项不达标即锁定步态并回退保守双支撑。

### IP-57 HGC：相位条件混合证书合成
```
def synthesize_hybrid_gait_certificate(H, D_contact, budget):
    cert = {}
    for q in H.Q:                       # DS / LS / RS / FL
        m_q = template_from_CKB(H, q)   # DCM 二次型 + 关节限位 CBF + 角动量残差
        while not budget.exhausted():
            ce = adversarial_sim(H, q, m_q, D_contact)
            if ce is None: break
            if ce.type == 'in_mode':
                m_q = tighten(m_q, ce)          # 收紧 θ_q / 加保守项
            elif ce.type == 'transition':
                ce.e.epsilon_h = max(ce.e.epsilon_h, ce.required_gap)
                ce.e.constraints += ce.reset_violation
        cert[q] = {
            'm': m_q, 'theta': m_q.theta,
            'L_m': empirical_lipschitz(m_q, q, D_contact),
            'Inv': invariant_from_sim(q, D_contact)
        }
    for e in H.E:                       # 逐边切换证书
        e.epsilon_h = solve_transition_gap(e, D_contact)
        e.kappa = estimate_reset_sensitivity(e, D_contact)
    return HybridCertificate(cert, H.E)

def hybrid_transition_guard(e, x, cert, phase_hat):
    # 1) 相位必须可信，否则退保守步态
    if phase_hat.uncertainty > DELTA_PHI_MAX: return False
    q, q_next = e.src, e.dst
    # 2) 出口/入口不变式
    if not (cert[q].Inv(x) and cert[q_next].Inv(x)): return False
    # 3) 守卫留白
    if signed_guard_gap(e, x) < e.epsilon_h: return False
    # 4) 重置后 margin 不塌陷（用 α_e 收缩后的实机阈值）
    x_plus = e.reset(x)
    rhs = cert[q_next].theta * e.alpha - cert[q_next].L_m * e.delta_R
    return cert[q_next].m(x_plus) >= rhs
```

### IP-58 CVK：N 步可捕获域与落脚查询
```
def compute_capture_kernel(steps, foot_sets, T_step, omega, residual={}):
    # V_0：当前支撑多边形内的安全 DCM 集（向内收缩 ρ_safe）
    V = [shrink_polytope(support_polygon(steps[0]), RHO_SAFE)]
    for k in range(1, N_MAX + 1):
        V_k = empty_polytope()
        for p in foot_sets[k]:
            # DCM 一步传播：ξ_T = p + (ξ - p) * exp(omega * T_step)
            pre = affine_preimage(V[k-1], p, exp(omega * T_step))
            V_k = union(V_k, intersect(pre, foot_reach_constraints(p)))
        # 全身修正：角动量/腿长/滚转足的保守收缩
        V_k = V_k.difference(residual.get(k, 0.0))
        V.append(V_k)
    return V   # 多面体并集，离线编译为 L0 表 + 轻量分类器

def footstep_viability(x, phase_hat, V_table):
    xi = dcm(estimate_state(x))
    k = steps_remaining(phase_hat)     # N_max - floor(phase * N_max)
    m_step = signed_distance(V_table[k], xi)   # >0 可行
    return m_step, k

def select_recovery(m_step, phase_hat):
    if m_step < 0 and m_step > -SMALL:   return 'extend_double_support'
    if m_step <= -SMALL and phase_hat < 0.5: return 'footstep_backtrack'
    if m_step <= -SMALL:                 return 'lower_com_decelerate'
    return 'nominal'
```

### IP-59 CDS：接触域仿真与迁移界
```
def contact_domain_randomize(N, coverage_target=0.9):
    # Sobol 低维覆盖核心参数；分层采样高维参数
    samples = []
    for s in sobol_sequence(N, dim=len(CONTACT_PARAMS)):
        delta = decode_contact_params(s)         # μ, k_c, c_c, e_r, τ_d, n_foot
        if parameter_space_volume_coverage(samples + [delta]) >= coverage_target:
            break
        samples.append(delta)
    return samples

def identify_contact_params(grf_window, joint_torque, imu):
    # 由足底力/力矩反演 μ 与接触刚度；带可辨识性分析
    theta_hat, J = robust_least_squares(contact_model, grf_window, joint_torque, imu)
    sigma = singular_values(J)
    unobservable = [i for i, sv in enumerate(sigma) if sv < SV_MIN]
    # 不可辨识方向并入 Δ_contact，不允许「假精确」
    return theta_hat, {'unobservable': unobservable, 'radius': 1.0 / max(min(sigma), EPS)}

def contact_transfer_bound(sim_trajs, real_trajs):
    # 逐接触事件对齐：make / break / slip / impact
    W_c, kappa = 0.0, {}
    for sim, real in align_contact_events(sim_trajs, real_trajs):
        impulse_err = norm(real.delta_momentum - sim.delta_momentum)
        W_c = max(W_c, impulse_err)
        for e in sim.contact_edges:
            kappa[e] = max(kappa.get(e, 0.0),
                           impulse_err / max(norm(real.delta_c), EPS))
    return W_c, kappa

def edge_alpha(theta_sim, L_m, kappa_e, delta_c, W_c, omega):
    raw = 1.0 + (kappa_e * norm(delta_c) + W_c / omega) / max(EPS, theta_sim)
    return max(1.0, min(raw, ALPHA_MAX))
```

# IP-51 CAR：混合自动机守卫
def car_step(x, phase_hat, cert, V_table):
    q = contact_mode(phase_hat)
    if phase_hat.uncertainty > DELTA_PHI_MAX:
        return {'action': 'conservative_double_support', 'margin': -INF}

| 接触参数不可辨识 / Δ_contact 覆盖不足，导致 `W_c` 低估 | 高 | 可辨识性矩阵审计；不可辨识方向并入不确定半径；E89 红线；实机 GRF 冲量残差在线复核 |
| 相位估计漂移：把错误相位的证书套到当前步态 | 高 | 相位管 + `δ_φ` 硬门限；超限退保守双支撑；接触事件而非纯时间推进相位 |
| 切换证书在「边缘触地」等稀有模式失效 | 中-高 | 模式细分（平足/脚尖/足边）；接触故障菜单；反例入 KB 并回归测试 |
| 可行核查询与规划器不一致：规划出的落脚点不在 `F_k` | 中 | 规划器与 CVK 共用同一 `F_k` 定义；接口契约检查；规划后二次 `m_step` 校验 |
| INT8 相位监控头量化误差破坏单边性 | 中 | `L_cert` 损失 + `α_e` 保守阈值；全量验证集零违例才放行；触地窗口可切回浮点小模型 |
| 恢复策略抖动：频繁在「延长双支撑/后撤步」间切换 | 中 | 恢复策略带迟滞与冷却期；按相位选择候选集；总线记录切换序列供审计 |

## 6. 本轮最大风险

**一句话**：双足方案的最大风险是把 **LIPM/DCM 的可捕获域当成了全身动力学的证书**——一旦接触参数在实机上不可辨识、或角动量/腿长/滚转足带来的降阶误差超出收缩界，证书就会在最需要它的触地瞬间恰好失效，而且这种失效会被「仿真里明明能走」的假象掩盖；因此 E87（切换证书）与 E89（接触迁移界）必须作为红线实验，任何一项不达标即锁定步态并回退保守双支撑。
