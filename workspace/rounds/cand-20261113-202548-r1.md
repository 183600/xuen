# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「动作空间」×「评测指标」）

> 第 68 轮把「标定」升级为在线潜变量，让系统第一次能问「我的测量还准吗」。但它自陈的最大风险暴露了一个更深的自指漏洞：**标定能不能成立，取决于机器人做了什么动作**。静态段能标出力零偏，却标不出绕未激励轴的外参旋转；低速温和运动能拟合温漂，却让缓变故障落在 COF 的 0.1 Hz 带宽内被「标好」。R68 把「测量可信度」当作数据的性质，而工程事实是：**可辨识性（identifiability）是动作的性质，不是数据的性质**。与此同时，R68 的全部评测（金标回归、AuditBuf 回放、风险界）都建立在「旧策略碰巧走过的动作」上——适配器只要把动作分布收窄，就能在覆盖率不足的评测集上「变安全」。这两个现象是同一枚硬币：**动作空间既是可观测性的来源，也是评测偏差的来源**。
>
> 本轮灵感「动作空间」×「评测指标」给出的核心命题：
>
> **把动作空间从「给定约束」升级为「可设计的一等公民实验设计变量」，把评测指标从「策略上的标量分数」升级为「动作空间覆盖测度上的泛函」；二者必须共同认证（co-certification）——动作空间决定什么可被测量，评测指标决定哪种动作空间可被采信。AMC-RAS（Action-space–Metric Co-certified RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我是否有资格、有能力去测**」——测量不可信时收缩；**可辨识性不足时，连「可信」本身都不许声称**。

## 0. 直觉与动机

**灵感 1（动作空间 → 标定与诊断本质上是主动实验设计）**
直觉：R68 的自标定默认「数据自己会说话」。但系统辨识的第一性事实是：**你要先动，参数才可辨识**。静止只能标定那些在零激励下暴露的变量（力零偏、静态外参）；绕某轴的外参旋转若从未被激励，其 Fisher 信息就是零，任何估计器都只能给出先验——这时声称「标定收敛」是统计谎言。更关键的是缓变故障：它的**自身频率**很低，会被 COF 当漂移吸收；但故障会改变系统对激励的**响应增益/相位**，只要我们在 3ω_cal 以上注入可辨识的探测动作，故障就在「响应差异」里显形。所以「反吸收」不能只靠被动速率限制（R68 引理 13），必须靠**主动激励**：不是等故障来，而是设计动作让故障无法藏。
推论：动作空间要显式拆出 `A_probe`（诊断探测子流形）与 `A_guard`（认证守卫动作，与学习参数解耦），并把「可辨识度」本身作为动作分布的一个评测指标。

**灵感 2（评测指标 → 指标是覆盖测度上的泛函，且必须反 Goodhart）**
直觉：R68 的 CAC 五关全都在「旧策略走过的动作」上评测。这是一个 on-policy 偏差：适配器可以把动作分布收窄到评测集恰好覆盖的狭窄扇形，于是「平均风险」下降而真实最坏风险不变；更隐蔽的是，它可以通过**收缩动作空间**来「改善」所有指标。指标必须从「策略上的标量」升级为「动作空间覆盖测度 μ_cov 上的泛函」，并在支持集受限的歧义集上取最坏情形；同时报告**支持缺陷 η**、**有效样本量 ESS**、**指标膨胀 Δ_inflate**。一句纪律：**被评测的动作集合本身必须被评测**——否则指标就是动作空间的函数，而不是能力的函数。

**灵感 3（二者对偶 → 共认证不动点）**
直觉：动作空间与评测指标不是两个并列话题，而是一对对偶约束。**指标决定哪些动作可被采纳（安全可采纳集 A_adm）**；**动作决定哪些指标可被估计（可辨识集 A_est）**。一个诚实的证书必须是二者交集里的不动点：存在动作集 A* 与指标向量 M*，使得 M* 恰好在 A* 上可估计（λ_min(F_V) ≥ F_min），且 A* 恰好在 M* 下可采纳（worst-case 风险 ≤ ε）。若交集为空——即「安全到足以采信的动作」与「可辨识到足以采信的动作」无交集——系统**没有资格给自己发证书**，只能退到守卫动作集。这把 R68 的「不确定就收缩」升级为「不可辨识就拒绝自我认证」。

**灵感 4（对 R68 风险的对症与新增盲区）**
- R68「缓变故障被标定吸收」：主动激励在 3ω_cal 以上制造响应差异，故障即使自身很慢也可辨识；U_cond 在激励不足时自动膨胀到 ∞，强制走最坏情形；
- R68「CAC 金标集未覆盖该故障」：覆盖加权 + 支持诊断把「金标集偏差」变成可度量的 η 与 ESS，偏差大即判指标 INVALID；
- R68「表征坍缩 / 负迁移 / 伪标签偏差」：全部继承 CALM-RAS†；
- **新增盲区（本轮自陈）**：探测动作本身要消耗安全裕度，且只能在已认证安全集内激励——最危险的故障偏偏只在安全集之外显形。这是「安全探测悖论」，也是本轮最大风险的种子。

## 1. 形式化定义（增量：定义 293–306）

**定义 293（AMC-RAS 总览与三不变式）** AMC-RAS = (CAME, DAM, DCG, OCC, AMC, GMA | CALM-RAS†)。不变式三升级：
(i) **动作空间可设计**：𝒜 = 𝒜_task ⊕ 𝒜_probe ⊕ 𝒜_guard，探测与守卫为一等公民，探测受预算与安全盾约束；
(ii) **指标覆盖化**：一切评测指标在覆盖测度 μ_cov 上以支持受限的最坏情形形式计算，禁止 on-policy 自证；
(iii) **共认证**：证书仅在动作-指标不动点 (A*, M*) 存在时有效；不存在则 guard-only 降级，宁可不可用，不可假安全。

**定义 294（动作空间分解与覆盖测度）** 动作空间三分解 𝒜 = 𝒜_task ⊔ 𝒜_probe ⊔ 𝒜_guard。覆盖测度
μ_cov = (1−ρ)·μ_task + ρ·μ_probe，ρ ∈ [0, ρ_max]，
其中 μ_probe 由激励基 {e_j}（张成故障子空间 V）生成，满足能量约束 E(μ_probe) ≤ E_max。ρ_max（默认 0.1）同时是探测预算与任务退化上界。

**定义 295（覆盖加权指标函子）** 对指标族 m_i ∈ {成功率, 违规率, 误降级率, 检出时延, 任务代价}，定义
M_i(π; μ_cov) = E_{s~d^{μ_cov}, a~μ_cov}[m_i(s, a, π)],
M_i^wc(π; μ_cov) = sup_{μ′ ∈ 𝒰(μ_cov, η)} M_i(π; μ′),
𝒰 为支持集受限（相对行为策略 π_b 的覆盖缺陷 ≤ η）的歧义集。证书携带**指标向量** M^wc，不再压成单一标量。

**定义 296（支持缺陷与有效样本量）** 对候选适配器 π_θ′ 与行为策略 π_b：
η(μ_cov) = μ_cov({a : π_b(a|s) < ε_sup})，
w = π_θ′/π_b，ESS = (Σw)² / Σw²。
若 η > η_max 或 ESS < ESS_min，则该适配器的全部指标判为 **INVALID**（不可用于放行）。

**定义 297（可辨识度与 Fisher 信息——动作空间上的指标）** 对故障假设 h、h′ 与动作测度 μ：
D(μ) = min_{h≠h′} E_{s,a~μ}[ KL( p(r | s,a,h) ‖ p(r | s,a,h′) ) ]，
F(μ) = Σ_a μ(a)·F_a，限制在故障子空间 V 上。称 μ **δ-可辨识**当且仅当 λ_min(F_V(μ)) ≥ F_min(δ)。注意 D、λ_min(F_V) 是定义在动作分布上的指标——它们评测的正是「动作空间够不够格」。

**定义 298（激励证书）** 探测序列 {a_t} 称为 **(δ, V)-激励**，若对每个 v ∈ V，其功率谱在 3ω_cal 以上的能量占比 ≥ δ。与 R68 引理 13 对接：COF 对 ω_f ≥ 3ω_cal 的抑制 ≤ 1/3，故该频带残差保留 ≥ 2/3；激励改变的是「故障对探测响应的可分性」而非故障自身频率。输出激励哈希 H_exc 进入证书。

**定义 299（守卫动作集与可达性）** 𝒜_guard = {安全停, 柔顺控制, 受控退避}，其控制器与一切学习参数解耦，出厂认证；要求在运行包络内从任意状态 T_guard 内可达，且构成控制不变集。输出 guard_reach_hash。

**定义 300（双控制动作目标）** 动作同时是控制与实验：
a_t = argmax_{a ∈ 𝒜_adm(s) ∩ 𝒜_cert} [ U_task(s,a) + β·IG(a; c, H | h_t) − γ·C_probe(a) ]，
s.t. 累计探测预算 Σ_t 1[a_t ∈ 𝒜_probe] ≤ ρ_max·T 与执行器磨损约束。IG 为对 (c,H) 的互信息增益。β = 0 退化为 R68 的纯利用闭环。

**定义 301（可观测条件化标定不确定度）** 
U_cond(ĉ) = U(ĉ) + κ_o·max(0, F_min / λ_min(F_V(μ_cov)) − 1)；
若 λ_min(F_V) < F_min 则 U_cond = ∞。语义：**只在动作能辨识的方向上声称标定可信**；不可辨识方向自动等价于 R68 的「超时冻结 + 最坏情形归因」。这把 R68 的 U(ĉ) 从「数据的函数」纠正为「数据 × 动作的函数」。

**定义 302（动作-指标共认证不动点）** 令
𝒜_adm(M) = {a : R(s,a) ≤ ε(M)}（在指标向量 M 下可采纳），
𝒜_est(δ) = {a : μ_cov 在 a 上支持充分且 λ_min(F_V) ≥ F_min(δ)}（可辨识）。
共认证即求 (A*, M*) 满足
A* ⊆ 𝒜_adm(M*) ∩ 𝒜_est(δ)，且 M* = M^wc(π; μ_{A*})。
若交集为空，则判定 **NO-CERT**，仅允许 𝒜_guard。该不动点是本轮的中心形式对象：证书不再是策略的属性，而是动作集与指标集的相互一致点。

**定义 303（Goodhart 指标审计）** 指标膨胀 Δ_inflate = M_reported − M^wc(μ_cov)。审计三律：
(a) **膨胀界**：Δ_inflate ≤ τ_infl；
(b) **单调性**：A ⊆ A′ ⇒ M^wc(A′) ≤ M^wc(A)（增加可选动作不得让真实最坏指标变好）；
(c) **参数化不变性**：对动作重参数化 φ，M^wc(φ(A)) = M^wc(A)。任一违反即判指标不可信，禁止放行。

**定义 304（J_AMC 证书）** J_AMC = (J_CALM, μ_cov_hash, η, ESS, λ_min(F_V), D(μ_cov), H_exc, guard_reach_hash, Δ_inflate, amc_ver)。Valid ⇔ Valid(J_CALM) ∧ η ≤ η_max ∧ ESS ≥ ESS_min ∧ λ_min(F_V) ≥ F_min ∧ guard 可达 ∧ Δ_inflate ≤ τ_infl。

**定义 305（管线）** 离线：从 D_sim 学故障子空间 V 与激励基、训练守卫盾、估计各动作下响应模型；在线：每轮估计 F(μ_cov) → 算 U_cond → 求共认证不动点 → 双控制选动作（任务 + 探测）→ 覆盖加权指标 → CAC 五关 + Goodhart 三律。影子流维护 μ_cov 与 ESS，实时流零学习写操作不变式保留。

**定义 306（探测预算与磨损代价）** 探测预算 B(T) = ρ_max·T；执行器磨损按 C_wear = c_w·Σ_t 1[a_t ∈ 𝒜_probe]·‖a_t‖² 计，进入动作目标（定义 300）。探测调度建模为带约束的 bandit，保证可辨识度 D(μ_cov) ≥ D_min 的最小探测率。

## 2. 关键算法骨架

```python
# IP-253 CAME：覆盖加权指标评测（影子流，反 on-policy 自证）
class CoverageAwareMetricEvaluator:
    def evaluate(self, policy, mu_cov, behavior_policy):
        eta = mu_cov.mass(lambda a: behavior_policy(a) < EPS_SUP)
        w   = policy.ratio(behavior_policy)
        ess = w.sum()**2 / (w**2).sum()
        metrics = {m: worst_case(integrate(m, policy, mu_cov)) for m in METRIC_SET}
        return metrics, {'eta': eta, 'ess': ess,
                         'valid': eta <= ETA_MAX and ess >= ESS_MIN}

# IP-254 DAM：诊断动作子流形（激励基 + 守卫）
class DiagnosticActionManifold:
    def excitation(self, F, budget):
        # 选使 λ_min(F_V) 最大化的探测组合，受预算/能量约束
        return solve_maximin(lambda_min_FV, budget, self.basis)

# IP-255 DCG：双控制动作选择（任务 + 信息增益）
def dual_control_select(task_actions, probe_actions, h, budget):
    return max(task_actions + probe_actions,
               key=lambda a: U_task(a) + BETA*info_gain(a, h) - GAMMA*probe_cost(a)
               if within_budget(a, budget) else -inf)

# IP-256 OCC：可观测条件化不确定度
def observability_conditional_U(U, F, V):
    lam = min_eigenvalue(restrict(F, V))
    if lam < F_MIN: return float('inf')
    return U + K_O * max(0.0, F_MIN/lam - 1.0)

# IP-257 AMC：共认证不动点（收缩迭代）
def co_certification(policy, mu_cov, delta, shield):
    A = mu_cov.support()
    for _ in range(MAX_IT):
        M = coverage_worst_case(policy, mu_cov.restrict(A))
        A_adm = shield.admissible(M)                 # R(s,a) <= eps(M)
        A_est = mu_cov.estimable(delta)              # lambda_min(F_V) >= F_min
        A_new = A & A_adm & A_est
        if A_new == A: return A, M
        if not A_new:  return None                   # NO-CERT -> guard only
        A = A_new
    return None

# IP-258 GMA：Goodhart 三律审计
def goodhart_audit(policy, mu_cov, M_report, M_true):
    inflate = M_report - M_true
    mono_ok = check_monotone(coverage_worst_case, policy, mu_cov)
    inv_ok  = check_reparam_invariance(coverage_worst_case, mu_cov)
    return inflate <= TAU_INFL and mono_ok and inv_ok

# IP-262 主闭环：AMC-RAS round
def AMC_RAS_round(M, obs):
    # 1) 估计动作条件可辨识度
    F = M.fim.estimate(M.mu_cov)
    U = M.cof.uncertainty()
    U_cond = observability_conditional_U(U, F, M.fault_subspace)   # 定义 301

    # 2) 共认证不动点（定义 302）
    cert = co_certification(M.policy, M.mu_cov, M.delta, M.shield)
    if cert is None:                     # 无资格自我认证 -> 守卫
        return M.guard_only()
    A_cert, M_cert = cert

    # 3) 双控制动作选择（任务 + 诊断探测，定义 300）
    a_task  = M.ach.propose_actions(obs, steps=5)
    a_probe = M.dam.excitation(F, M.probe_budget)
    a_star  = dual_control_select(a_task, a_probe, M.h, M.probe_budget)

    # 4) 继承 CALM-RAS† 的标定/归因/前缀/风险缩放
    z, o = M.mtm.forward(obs, M.a_prev, M.scene_ctx)
    c, Uc, thr = M.cof.step(o['cal'], residuals(obs, o), sigma_stat(M))
    joint = M.cfa(o['pi'], M.fir_signature(z), c, U_cond)
    k = M.c_ras_wm.certified_prefix(a_star, joint, M.m_ras, M.alpha_chunk)
    if U_cond > TAU_CAL: k = min(k, k_cal_shrink(a_star, U_cond))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
              0.8 if (o['qual']['face'] < 0.8 or wm_drift(o)) else 0.6)

    # 5) 覆盖加权指标 + Goodhart 审计 + CAC 五关
    M_metrics, diag = M.came.evaluate(M.policy, M.mu_cov, M.behavior)
    ok_metric = diag['valid'] and M.gma.audit(M.policy, M.mu_cov, M.reported, M_metrics)
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit, extra_gate=ok_metric)

    # 6) 控制输出（守卫可达性保留）
    tau = M.pi_sigma.prefix_dispatch(a_star[:k]) * lam
    return k, lam, joint, (c, U_cond), M_metrics
```

## 3. 推导

**引理 16（激励-可辨识性界）** 设故障方向 v ∈ V，且探测测度 μ_probe 为 (δ, V)-激励。对经过 COF（带宽 ω_cal）的残差，频带 3ω_cal 以上分量保留 ≥ 2/3；若故障表现为该频带的响应增益变化 Δg_v，则
D(μ_cov) ≥ δ·(2/3)²·D₀(v)，T_det ≤ log(τ_det / r₀) / D(μ_cov)。
**系**：缓变故障即使自身频谱远低于 ω_cal，也可通过「对高频探测的响应差异」被辨识——故障可辨识性来自响应，而非故障频率。这直接补上了 R68「缓变故障落入标定带宽即隐形」的漏洞。

**引理 17（on-policy 指标偏差界）** 对 L_m-Lipschitz 的指标 m，
|M_on(π) − M_cov(π)| ≤ L_m·TV(μ_on, μ_cov) ≤ L_m·η。
故适配器可将「报告指标」改善至多 L_m·η 而不改善真实能力（靠收缩动作支持集实现）；偏差对覆盖缺陷是一阶的。**系**：R68 的 CAC 在 η 大时天然可被 Goodhart 化。

**引理 18（指标膨胀界）** 若报告指标改善 Δ 而支持缺陷增加 η，则真实改善 ≤ Δ + L_m·η。单调性审计（定义 303-b）在 Δ > L_m·η + τ_infl 时必触发，故可拦截「以收缩换分数」的适配器。

**定理 16（共认证端到端风险）** 在 A87–A94 与 A95–A97（V 有界、激励可施加、守卫可达）下：
1. 若 J_AMC 有效，则 P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_metric + α_ident**，其中 α_metric ≤ L_m·η_max（引理 17），α_ident ≤ exp(−T_det·D_min)（引理 16）；
2. 若无共认证不动点：退守卫，违规率 = 0，但可用性 = 0——**以 liveness 换 safety，不由系统自行裁定**；
3. 探测引入的任务 regret ≤ β·IG_max·ρ_max·T + C_wear（定义 300/306）；
4. Goodhart 膨胀超过 τ_infl 的概率 ≤ exp(−ESS·τ_infl² / (2L_m²))（Hoeffding）。

**命题 1（自指不完备性——动作空间盲区）** 对任意有限动作集 A_cert 与故障子空间 V，总存在 h* ∉ span(V)，使得对所有 a ∈ A_cert 有 D_{h*}(a) = 0（在 A_cert 上不可辨识）。证明要点：诊断只使用 A_cert 上的响应；任何在可观测子空间正交补内的扰动对全部 a ∈ A_cert 响应为零，故不可见。**系**：共认证只对「自己选定的基」成立；A_est 为空也只能从基外被发现。这解释了为什么「越严谨的证书」可能越像一张对未知盲区的免责声明。

## 6. 本轮最大风险

**一句话**：AMC-RAS 的共认证只能在它自己选定的故障子空间 V 与已认证安全动作集 A_cert 内成立，而最危险的故障恰恰只在 A_cert 之外显形——系统越安全、探测越充分，越会对建模之外的失效视而不见，「可辨识」证书反而成为对未知盲区的免责声明。

**次级风险与缓解**：
1. **安全探测悖论**：探测只能发生在已认证安全集内，对「只在越界区域显形」的故障结构性失明 → 用影子仿真/数字孪生做越界探测、离线 canary、并把「基外未知」显式列为残差不确定性（U_cond 的不可约项），不假装已覆盖；
2. **指标过度保守导致空集**：ε(M) 收紧使 𝒜_adm ∩ 𝒜_est 经常为空 → 频繁 guard-only 冻结 → 引入「认证可用性预算」，区分安全性与可用性，并向运维报警而非静默降级；
3. **探测磨损与任务退化**：ρ_max 与 C_wear 约束，bandit 调度，必要时用被动激励（任务动作本身的丰富性）替代主动探测；
4. **Goodhart 的元层级**：μ_cov 由设计者选择，可能成为下一个被优化的目标 → 指标多样性 + 外部审计 + 随机化覆盖测度 + 命题 1 的显式不确定性；
5. **FIM/响应模型的 Sim2Real 偏移**：λ_min(F_V) 高估可辨识度 → 用真实残差在线校准 F，并在仿真-现实不一致时膨胀 U_cond。

# IP-253 CAME：覆盖加权指标 + 支持诊断（影子流）
class CoverageAwareMetricEvaluator:
    def evaluate(self, policy, mu_cov, behavior_policy):
        eta = mu_cov.mass(lambda a: behavior_policy(a) < EPS_SUP)
        w   = policy.ratio(behavior_policy)
        ess = w.sum()**2 / (w**2).sum()
        metrics = {m: worst_case(integrate(m, policy, mu_cov)) for m in METRIC_SET}
        return metrics, {'eta': eta, 'ess': ess,
                         'valid': eta <= ETA_MAX and ess >= ESS_MIN}

# IP-254 DAM：诊断动作子流形（激励基 + 守卫）
class DiagnosticActionManifold:
    def excitation(self, F, budget):
        return solve_maximin(lambda_min_FV, budget, self.basis)

# IP-255 DCG：双控制动作选择
def dual_control_select(task_actions, probe_actions, h, budget):
    return max(task_actions + probe_actions,
               key=lambda a: U_task(a) + BETA*info_gain(a, h) - GAMMA*probe_cost(a)
               if within_budget(a, budget) else -inf)

# IP-256 OCC：可观测条件化不确定度（修正 R68 的 U）
def observability_conditional_U(U, F, V):
    lam = min_eigenvalue(restrict(F, V))
    if lam < F_MIN: return float('inf')
    return U + K_O * max(0.0, F_MIN/lam - 1.0)

# IP-257 AMC：共认证不动点（收缩迭代，空集即 NO-CERT）
def co_certification(policy, mu_cov, delta, shield):
    A = mu_cov.support()
    for _ in range(MAX_IT):
        M = coverage_worst_case(policy, mu_cov.restrict(A))
        A_new = A & shield.admissible(M) & mu_cov.estimable(delta)
        if A_new == A: return A, M
        if not A_new:  return None            # guard-only
        A = A_new
    return None

# IP-258 GMA：Goodhart 三律审计
def goodhart_audit(policy, mu_cov, M_report, M_true):
    inflate = M_report - M_true
    return (inflate <= TAU_INFL
            and check_monotone(coverage_worst_case, policy, mu_cov)
            and check_reparam_invariance(coverage_worst_case, mu_cov))

# IP-262 主闭环
def AMC_RAS_round(M, obs):
    F = M.fim.estimate(M.mu_cov)                              # 动作条件可辨识度
    U_cond = observability_conditional_U(M.cof.uncertainty(), F, M.fault_subspace)
    cert = co_certification(M.policy, M.mu_cov, M.delta, M.shield)
    if cert is None: return M.guard_only()                    # 无资格自我认证
    A_cert, M_cert = cert

    a_task  = M.ach.propose_actions(obs, steps=5)
    a_probe = M.dam.excitation(F, M.probe_budget)
    a_star  = dual_control_select(a_task, a_probe, M.h, M.probe_budget)

    z, o = M.mtm.forward(obs, M.a_prev, M.scene_ctx)
    c, Uc, thr = M.cof.step(o['cal'], residuals(obs, o), sigma_stat(M))
    joint = M.cfa(o['pi'], M.fir_signature(z), c, U_cond)
    k = M.c_ras_wm.certified_prefix(a_star, joint, M.m_ras, M.alpha_chunk)
    if U_cond > TAU_CAL: k = min(k, k_cal_shrink(a_star, U_cond))

              0.8 if (o['qual']['face'] < 0.8 or wm_drift(o)) else 0.6)

    M.cac.maybe_commit(M.shadow, M.time_since_last_commit, extra_gate=ok)

    tau = M.pi_sigma.prefix_dispatch(a_star[:k]) * lam
    return k, lam, joint, (c, U_cond), metrics

## 4. 推导

**引理 16（激励-可辨识性界）** 对 (δ,V)-激励测度，COF 后 3ω_cal 以上残差保留 ≥ 2/3；故障在该频带的响应增益变化 Δg_v 满足 `D(μ_cov) ≥ δ·(2/3)²·D₀(v)`，`T_det ≤ log(τ_det/r₀)/D(μ_cov)`。**系**：缓变故障虽自身频谱低于 ω_cal，仍可经「对高频探测的响应差异」辨识——可辨识性来自响应，不是故障频率。补上 R68 的缓变吸收漏洞。

**引理 17（on-policy 指标偏差界）** `|M_on − M_cov| ≤ L_m·TV(μ_on,μ_cov) ≤ L_m·η`。适配器可靠收缩动作支持集把报告指标改善至多 L_m·η 而不提升真实能力——R68 的 CAC 在 η 大时天然可被 Goodhart 化。

**引理 18（指标膨胀界）** 报告改善 Δ、支持缺陷增 η ⇒ 真实改善 ≤ Δ + L_m·η；当 Δ > L_m·η + τ_infl 时单调性审计必触发，拦截「以收缩换分数」。

**定理 16（共认证端到端风险）** A87–A97 下：
1. J_AMC 有效 ⇒ `P(|τ_cmd−τ*|>ε) ≤ Σα_prev + α_metric + α_ident`，`α_metric ≤ L_m·η_max`（引理 17），`α_ident ≤ exp(−T_det·D_min)`（引理 16）；
2. 无不动点 ⇒ 守卫，违规 = 0、可用性 = 0（以 liveness 换 safety，不由系统自裁）；
3. 探测 regret ≤ `β·IG_max·ρ_max·T + C_wear`；
4. 膨胀 > τ_infl 的概率 ≤ `exp(−ESS·τ_infl²/(2L_m²))`。

**命题 1（自指不完备性——动作空间盲区）** 对任意有限 A_cert 与 V，存在 h* ∉ span(V) 使对所有 a ∈ A_cert 有 `D_{h*}(a)=0`：诊断只用 A_cert 上响应，可观测子空间正交补内的扰动对全部 a ∈ A_cert 不可见。故共认证只对其自选基成立，A_est 为空也只能从基外发现——严谨证书可能是一张对未知盲区的免责声明。

## 7. 本轮最大风险

**一句话**：AMC-RAS 的共认证只能在它自己选定的故障子空间 V 与已认证安全动作集 A_cert 内成立，而最危险的故障恰恰只在 A_cert 之外显形——系统越安全、探测越充分，越会对建模之外的失效视而不见，「可辨识」证书反而成为对未知盲区的免责声明。

**次级风险与缓解**：安全探测悖论（影子仿真越界探测 + 显式不可约 U_cond，不假装覆盖）；指标过保守致空集（认证可用性预算，区分安全与可用，报警而非静默冻结）；探测磨损/任务退化（ρ_max + C_wear + bandit，必要时用任务动作自身丰富性做被动激励）；Goodhart 元层级（覆盖测度随机化 + 指标多样性 + 外部审计 + 命题 1 显式不确定性）；FIM Sim2Real 高估（真实残差在线校准 F，不一致即膨胀 U_cond）。
