# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「真机评测」×「谐波减速器」）
> **基线**：第 10 轮 MetricVoiceGauge-NCD（定义 540–553；引理 87–95；实验 E571–E588），其基线为第 9 轮 MetricVoiceGauge-ACMD。
> 本轮纪律：**执行器要诚实，评测者要中立**。不推倒 v10：NGE/DSL/CC/CWM/CAE/NCP、MetricVoiceGauge 九不变式、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 全部保留；本轮新组件一律以**中立元**接入，失效即严格退回 v10（引理 103），再沿 v10 九级链退回 v9/v8/v7。本轮只做三件事：把"谐波传动误差"提升为证书的一等不确定源、把"真机评测"做成带统计保证的证书、用**可测-可执行间隙场**联合识别两者并禁止自证。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 执行器并不诚实地执行你的证书）**
直觉：v10 的所有证书（物理安全、接触、规范）都隐含一个假设：命令的关节力矩/位置就是真实发生的力矩/位置。但人形与协作臂最常用的谐波减速器恰恰以**滞回、摩擦、扭转柔度、传动误差、热漂移与磨损**著称：同一力矩命令在升温前后、正反向、不同载荷历史下，真实输出力矩可以相差额定力矩的 10%–20%。对一个接触力上限只有几十牛的灵巧任务，这个误差足以让"证书说安全"变成"实际越界"。更糟的是，v10 的 β_f/β_τ 只是接触模型误差余量，**并不包含传动实现误差**，所以证书在关节层面就已经错了。核心创新：**传动透明层（Harmonic Transmission Transparency, TTL）**——把谐波关节建模成带潜状态 z_hd=(滞回状态 h、温度 T、磨损 w、几何/刚度 θ) 的非线性系统，在线估计并用**自适应保形预测**给出有覆盖保证的力矩/位置实现误差界 β_hd；再用**证书膨胀算子** I_β 把这个界传播进 v10 的安全/接触/规范证书。它不是给控制器再加一个补偿器，而是给"命令→真实"这段被忽略的物理过程发证书。

**灵感 2（真机评测 → 评测者也不是中立的观察者）**
直觉：v10 的实验 E571–E588 大量是仿真或小样本真机演示；即使上了真机，"评测"本身也有偏差：样本少、单元（robot/hand/joint）间差异大、温度与磨损让分布漂移、指标是事后挑的、同一批数据反复用、赢家诅咒。于是"真机 ≥ v10 +10%"这种结论可能只是**在噪声上挑了个最大值**。核心创新：**真机评测协议（Real-Machine Evaluation Protocol, RMEP）+ 评测证书（Evaluation Certificate, EC）**。每个要写进论文或上线的声明 φ 必须先预注册（主终点、margin、样本量、停止规则），再用分层/配对/switchback 设计在多个单元上测，用层次模型 + 聚类稳健区间给出效应与功效；同时做**测量不变性**检验（单元/温度/磨损层是否可合并）、**漂移检验**与**评测泄漏审计**。EC 的判定不是"通过/不通过"，而是格：verified / bounded / not-transferable / refuted。没有真机 EC 的声明只能标成 simulation-only，禁止作为最终安全保证的前提。

**灵感 3（两者如何统一 → 同一个"间隙场"，两个来源，可能不可分）**
直觉：把"声称"与"真实"之差写成一个场：
G = y_real − y_claim = G_trans（传动实现误差）+ G_eval（评测偏差）+ G_sample（抽样误差）。
谐波减速器告诉我们 G_trans 有多大且会漂移；真机评测是唯一能测 G_trans 的手段——但评测本身又有 G_eval，而且用的是同一台会热、会磨损的机器。于是出现一个尖锐的问题：**当只有一个仪器、少量单元、分布还在漂移时，G_trans 与 G_eval 可能根本不可分，只能识别它们的和。** 这时若系统仍分别输出"传动已认证"和"评测已认证"，就是拿同源误差互相作证。核心创新：**可测-可执行间隙场（Executability–Measurability Gap Field, EMGF）** 与**对偶评测-控制规划（Dual Evaluation-Control, DECP）**：先用独立仪器/多单元/外部标定做可识别性判定；可识别则分别认证，不可识别则强制使用保守的和界 S=G_trans+G_eval 并降低结论等级；同时让机器人在安全证书内主动做**信息性激励**（persistent excitation），以最小任务代价把 z_hd 估得更准——评测不是部署之外的一次性动作，而是与控制共享同一批真机回合的对偶问题。

**三者如何统一**
在 v10 的块接口 ζ=(skills, Ĉ_safety, Ĉ_contact, Ĉ_norm, P) 之外，新增**可测性字段** ρ=(TTC, EC, G, id_status)。执行侧：v10 证书 → 用 TTC 膨胀 → 只有膨胀后仍有效的块才可执行；评测侧：每个声明 → RMEP → EC → 写入声明-测量账本；两侧共享同一个 G，且当 G 不可识别时，执行侧自动用和界、评测侧自动降级。**谐波回答"执行器到底给了多少"，评测回答"我们凭什么相信这个数"，间隙场回答"这两个问题何时能分开问"。**

## 1. 研究问题（轮次升级版）

- **Q1（传动可透明性）**：如何把谐波减速器的滞回、摩擦、柔度、热漂移与磨损压缩成一个可在线估计、带有限样本覆盖保证、且能传播进安全证书的力矩/位置实现误差界，而不是一个拍脑袋的静态 β？
- **Q2（评测可信性）**：如何让"真机 ≥ 基线 +x%"这类声明在单元异质、分布漂移、样本昂贵、可事后挑选的现实条件下仍然统计有效，并把"不可合并/不可迁移"显式判出来？
- **Q3（间隙可识别性）**：G_trans 与 G_eval 在什么仪器/单元/标定条件下可分别识别？不可识别时，如何用一个可证明保守的和界同时约束控制与声明，而不产生"同源自证"？
- **Q4（安全-活性-保守性三角）**：传动膨胀会不会把所有可行块都删光？评测驱动的信息性激励会不会为了测量而冒险？两者同时存在时，能否证明"要么安全执行，要么安全地失败/询问"，而不是既不敢动又给不出可信结论？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 传动透明律（Transmission Transparency, TTL）**
每个进入证书的关节/末端量必须给出"命令→真实"的实现误差界，且该界显式包含滞回、摩擦、柔度、热漂移与磨损；界必须有在线/有限样本覆盖保证，并声明运行包络 E（温度、磨损、力矩、速度、标定年龄）；禁止把 β_hd 隐含为零，禁止用接触模型余量冒充传动余量。

**P17 真机评测律（Real-Machine Attestation, RMEP）**
凡作为安全前提或主结论的声明，必须预注册主终点与 margin，在 ≥2 个独立单元上按分层/配对/switchback 设计测量，报告聚类稳健区间与功效；合并跨单元数据前必须通过测量不变性检验；未通过者为 not-transferable，只能分层报告；未经预注册的探索性分析不得升级为 verified。

**P18 间隙场保守律（Gap-Field Conservatism, GFE）**
当 G_trans 与 G_eval 不可分别识别时，只允许使用和界 S=G_trans+G_eval 并降低结论等级；禁止用同一批数据同时认证两个来源，禁止把 simulation-only 证据当作最终安全前提。执行侧只能因膨胀而变保守，不能因评测而放宽。

## 3. 与基线的接口（如何退化）

- TTL/TRC 失效 ⇒ β_hd≡0、I_β=id，控制路径逐位等价 v10；
- GFE/DECP 失效 ⇒ 使用预注册常数和界 S_const（不依赖在线识别），规划退回 v10 NCP；
- ECE/CML 失效 ⇒ 所有声明降级 simulation-only / 人工评审，控制路径不变，等价 v10；
- 三者全失效 ⇒ v10，再沿 v10 九级链退回 v9/v8/v7；
- **安全继承**：膨胀算子只删候选、不加候选；评测引擎不触碰控制；不可识别时和界只会更保守（引理 105）。

## 4. 预期贡献

1. **传动透明层**：把谐波减速器的滞回/摩擦/柔度/热/磨损统一为潜状态模型，用自适应保形预测给出可覆盖的力矩与位置实现界，并定义保序的证书膨胀算子，使"命令安全"升级为"实现安全"；
2. **真机评测证书**：把预注册、分层配对/switchback、层次聚类稳健区间、测量不变性、漂移与泄漏审计、判定格组合成可复用的 EC，使"真机结论"本身可被审计、可被否决；
3. **可测-可执行间隙场**：给出 G_trans 与 G_eval 的可识别性条件与不可识别时的和界，把"评测与执行何时能互相作证"变成一个可判定、可降级的问题；
4. **对偶评测-控制**：在安全证书内做信息性激励，用 VOI 分配昂贵的真机试验，使评测成为控制闭环的一部分而不是事后诸葛亮；
5. **可退化的第十二级链路与 E589–E608**：覆盖传动辨识、覆盖保证、热/磨损、单元异质、可识别性、Goodhart 对抗与端到端真机任务。

## 5. 本轮最大风险

**一句话**：在会发热、会磨损的真实谐波关节上，传动误差与评测误差共享同一台机器与同一批少量试验；一旦二者不可识别而系统仍分别给出"已认证的传动界"和"已认证的评测界"，它就会用同源误差互相作证，产生高置信度的**自证清白式假安全**。

**定义 554（传动实现误差与间隙分解 Transmission Realization Gap）** 对带谐波减速器的关节 j，在时刻 t：
```
τ_real,j(t) = N_j·η_j·τ_cmd,j(t) − τ_f,j(q̇_j,T_j,w_j) − τ_h,j(h_j,q_j,T_j) − τ_ripple,j(q_j) + ν_j(t)
e_hd,j(t) = τ_real,j(t) − τ_cmd,j(t)
```
其中 N_j 为减速比，η_j 为效率，τ_f 为摩擦（Coulomb+黏性+Stribeck），τ_h 为滞回力矩，τ_ripple 为传动误差引起的周期性力矩纹波，ν 为未建模残差。间隙分解记 e_hd = e_hyst + e_fric + e_comp + e_ripple + e_thermal + e_wear + ν；**接触证书中的力误差通过力臂 r 映射**：β_f^hd = β_hd/r。

**定义 555（传动潜状态与演化 Transmission Latent State）** z_hd=(h,T,w,θ)，其演化：
```
ḣ = f_h(h, q̇, τ, T)              # Bouc–Wen / Preisach 类滞回状态
Ṫ = a·|τ_f·q̇| − b·(T − T_amb)    # 摩擦生热与散热
ẇ = c·|τ|·|q̇|                    # 单调磨损（慢变量）
θ̇ = η_θ                          # 刚度/间隙参数的慢随机游走
```
观测 o_hd=(q, I, τ_s)（编码器、电机电流、可选关节力矩传感器）；在线滤波器（约束 UKF/粒子滤波）输出后验 (ẑ_hd, P_hd)。模型误差、装配差异与润滑差异由残差缓冲吸收，不强行塞进参数。

**定义 556（传动透明证书 Transmission Transparency Certificate, TTC）** 对块 ζ 的 K 步轨迹与置信水平 1−δ：
```
TTC_j(ζ,δ) = (β_hd,j, β_pos,j, β_stiff,j, env_ok, calib_age)
```
满足（对 j 与 k≤K 同时成立，概率 ≥1−δ）：
```
sup_k |τ_real,j(k) − τ̂_cmd→real,j(k)| ≤ β_hd,j
sup_k ‖x_real(k) − x̂(k)‖ ≤ β_pos,j
sup_k ‖K_real(k) − K̂(k)‖ ≤ β_stiff,j
```
β_hd 由**自适应保形预测（ACI）**在残差缓冲上取分位数得到：以 s=|e_hd|/σ(z_hd) 为非一致性分数，在线更新覆盖水平；热/磨损漂移下保持长程覆盖 ≥1−δ−o(1)。env_ok=1 当且仅当 z_hd∈E（定义 566）。**包络外 TTC 无效，不得外推。**

**定义 557（证书膨胀算子 Certificate Inflation Operator）** 设 v10 证书 C 是一组约束（f≤f_max、τ≤τ_max、d≥d_min、P_slip≤ε_slip、γ≥γ_min、规范鲁棒度 ρ_ν≥0）。定义：
```
I_β(C) = C 的每条不等式按 β 收紧：
  f_max ← f_max − β_hd/r,   τ_max ← τ_max − β_hd,
  d_min ← d_min + β_pos,    ρ_ν ← ρ_ν − L_ν·β_stiff
```
可执行集 A(C)={ζ: ζ 满足 C}。要求四条性质：(i) 可靠性：C 与 β 均为真界 ⇒ I_β(C) 有效；(ii) 保序性：β≤β' ⇒ A(I_{β'}(C))⊆A(I_β(C))，且 C⊆C' ⇒ A(I_β(C'))⊆A(I_β(C))；(iii) 恒等性：I_0(C)=C；(iv) 不扩张性：A(I_β(C))⊆A(C)。**膨胀只删不加。**

**定义 558（真机评测协议 Real-Machine Evaluation Protocol, RMEP）** 一个协议是七元组 (Φ, Y, U, D, R, S, A)：Φ={φ_j} 为预注册声明（主终点、margin、方向）；Y 为结果测量模型；U 为单元/站点/温度/磨损分层；D 为随机化与区组设计（配对、分层、switchback）；R 为预注册分析（层次模型、聚类稳健区间、多重性控制）；S 为序贯停止规则（α 花费）；A 为证明日志（数据哈希、代码哈希、环境、操作员）。**预注册先于取数冻结 Φ、margin、主终点与分析计划。**

**定义 559（评测证书与判定格 Evaluation Certificate）**
```
EC_j = (n_eff, Δ̂_j, CI_{1−α}, power, inv_test, drift_test, leakage_audit,
        id_status, verdict)
verdict ∈ {verified, bounded, not-transferable, refuted}
```
- verified：CI 完全落在 margin 内 ∧ power≥1−β_pow ∧ 不变性通过 ∧ 无泄漏 ∧ 漂移在包络内；
- bounded：只能给出区间界（功效不足/样本不足），声明降级为"界内成立"；
- not-transferable：测量不变性失败或漂移出包络，只能分层报告；
- refuted：CI 排除声称效应或方向相反。
判定格强度顺序 verified ≻ bounded ≻ not-transferable ≻ refuted；同一账本内共享数据的声明用 FWER/FDR 统一控制。

**定义 560（测量不变性 Measurement Invariance）** 对声明 φ 在单元 u、温度/磨损层 s 上：
```
Y = m_φ(Z) + b_u + b_s + ε,   γ_inv = sup_{u,u'} |b_u − b_u'| + sup_{s,s'} |b_s − b_s'|
```
γ_inv=0（或已知可估）才允许跨层合并；否则只能分层给 EC，并把 γ_inv 计入 G_eval。用多组测量不变性/方差成分检验估计 γ_inv 并报告置信上界。

**定义 561（可测-可执行间隙场 Executability–Measurability Gap Field）**
```
G_trans = sup_k |τ_real(k) − τ_cmd(k)| + 传动引起的末端位置误差
G_eval  = |Ê[Y] − E[Y]|     # 协议偏差：选择、非平稳、不变性缺口
G_sample = 统计区间的半宽
μ_real = μ_claim − G_trans − G_eval − G_sample
```
执行与声明都以 μ_real≥0 为可行条件。**G 是有符号的真实差值场；安全判定只用其保守上界。**

**定义 562（间隙场可识别性 Gap Identifiability）** 观测模型
```
y_i = x_i + Ψ(z_hd,i)·g_trans + g_eval + ε_i
```
其中 Ψ 为单元/潜状态相关的设计列。G_trans 与 G_eval 可分别识别 ⇔ 设计矩阵 [Ψ, 1] 列满秩。充分条件（任一）：
```
I1 独立第二仪器：关节力矩传感器与电流估计噪声独立；
I2 多单元：≥2 个单元共享协议但 z_hd 状态不同；
I3 外部标定：存在已知真值的标定回合。
```
若 Ψ 在观测间为常数（单单元、单状态、无第二仪器），则秩亏，**只有 S=g_trans+g_eval 可识别**；任何分开估计在零空间方向上的偏差至少为 min(G_trans,G_eval)。此时 id_status=joint-only，强制用 S 并降级。

**定义 563（对偶评测-控制目标 Dual Evaluation-Control Objective）** 在真实回合中选择块 ζ 与允许的探测激励 ξ：
```
max_{ζ,ξ}  E[ Σ_{k≤K} γ^k R_task(s_k) ] − cost_eval(ξ) + λ·IG(z_hd; o_{1:K} | ζ,ξ)
subject to  ζ ∈ A(I_β(C)),  ξ 安全（当前 TTC 下）
          ∧ P(安全 | ζ,ξ) ≥ 1−δ
          ∧ 探测能量/时间 ≤ B_probe
```
λ 由定义 564 的 VOI 选取；**信息增益只能在不越界的前提下换取，禁止为测量而冒险。**

**定义 564（评测预算与信息价值 Value of Evaluation）**
```
VOI(T) = E[ U(决策 | 加入测试 T 后) − U(决策 | 现状) ] / cost(T)
```
按预注册预算做贪心或约束最优选测；每次真机回合同时计入任务成本与评测成本。评测不是免费观测。

**定义 565（声明-测量账本 Claim-Measurement Ledger, CML）** 一张 DAG：节点为声明（定理/引理/实验主张）与测试；边表示"由…支持"。每个声明携带 EC、id_status、数据/代码哈希与依赖集；共享同一数据的声明构成多重性族，统一做 FWER/FDR；无真机 EC 的声明打 **simulation-only** 标签，**不得作为最终安全保证的前提**。

**定义 566（运行包络与推断护栏 Operating Envelope）**
```
E = { T_min≤T≤T_max, w≤w_max, τ_cmd≤τ_max, |q̇|≤v_max, calib_age≤t_calib }
```
z_hd∉E ⇒ TTC 无效、相关声明 not-transferable，必须重标定或退回包络内保守运行；**磨损/热外推不得静默通过。**

**定义 567（v11 中立元表 Neutral-Element Table）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| TTL 传动潜状态 | β_hd=β_pos=β_stiff≡0，无残差缓冲 | Level-3（v10） |

**定义 568（真机可测性谓词 Real-Machine Testability）** 声明 φ 真机可测 ⇔ 存在预注册 RMEP，使 (i) 主终点可测量；(ii) 在声称 margin 下功效≥1−β_pow；(iii) id_status 为 separate，或已声明使用和界 S；(iv) 测量不变性可检验。不满足者只能标 simulation-only 或 bounded。

**定义 569（仿真-真机等价边界 Sim–Real Equivalence Boundary）** 在 (z_hd, 任务, 环境) 空间定义区域 Ω_eq：在 Ω_eq 内仿真证书与真机 EC 的差异≤δ_eq；Ω_eq 外，仿真证据不得提升为真机结论，只能作为先验。Ω_eq 由 E603 与 E599 估计，并随磨损/温度更新。

class HarmonicTransmissionLayer:
    def __init__(self, model, filt, envelope, delta=0.01):
        self.M, self.f, self.env, self.delta = model, filt, envelope, delta
        self.residuals = deque(maxlen=4096)     # ACI 残差缓冲
        self.alpha = delta

    def update(self, obs, cmd):
        self.z, self.P = self.f.step(self.z, self.P, obs, cmd)  # 定义 555
        if obs.tau_sensor is not None:
            e = obs.tau_sensor - self.M.predict_torque(self.z, cmd)
            self.residuals.append(abs(e) / self.M.sigma(self.z))
            self.alpha = aci_update(self.alpha, e, self.delta)  # 自适应覆盖
        return self.z, self.P

    def bound(self, skill_chunk):
        beta_hd = self.M.sigma(self.z) * aci_quantile(self.residuals, self.alpha)
        beta_pos, beta_stiff = interval_propagate(self.M, self.z, self.P,
                                                  skill_chunk)      # 区间可达性
        return TransmissionBound(beta_hd, beta_pos, beta_stiff,

                                 calib_age=self.env.calib_age(self.z))

## 4. 推导

**引理 96（传动证书可靠性）** 设 (A1) 对块 ζ 的 ACI 残差给出 sup_k|e_hd(k)|≤β_hd 的概率≥1−δ；(A2) 膨胀算子按定义 557 收紧；(A3) v10 证书在真实状态上可靠。则执行 ζ∈A(I_β(C)) 时，真实接触力/力矩/位置满足 v10 规格的概率≥1−δ。证明：τ_real=τ̂+e_hd，区间包含真实值；膨胀把每个约束收紧 β，故真实量仍落在原约束内；对 v10 的可靠性逐项合取即得。∎

**引理 97（膨胀算子的保序与不扩张）** I_β 对证书包含关系与 β 均单调，且 I_0=id、A(I_β(C))⊆A(C)。证明：每条约束的收紧量在 β 上单调、在阈值上单调；区间算术保证包含关系保持；β=0 时收紧量为 0。故开启 TTL 只可能删去候选，不可能新增候选。∎

**引理 98（评测证书覆盖）** 在单元分层抽样与含单元随机效应的层次模型下，聚类稳健区间覆盖→1−α；层内可交换时，单元级保形区间给出有限样本覆盖≥1−α；分布漂移时，ACI 给出长程覆盖≥1−α−o(1)。若无法拒绝"单元可交换"，合并有效；否则必须分层。证明：前三式分别为聚类稳健渐近、保形覆盖与 ACI 定理；最后一句由不变性检验的控制错误率得出。∎

**引理 99（测量不变性与合并偏差界）** 若单元偏置的极差为 γ_inv，则跨单元合并估计相对任一单元的偏差≤γ_inv；不变性检验失败时合并估计的偏差不可控，必须判 not-transferable。证明：把 y_u=m+b_u+ε_u 代入合并均值，偏置项为 b̄；与真实 m 的差由 b_u−b̄ 界定，取极值即 γ_inv。∎

**引理 100（间隙场可识别性）** 观测模型 y=x+Ψ·g_trans+g_eval+ε 中，G_trans 与 G_eval 可分别识别 ⇔ [Ψ,1] 列满秩；秩亏时只有 S=g_trans+g_eval 可识别，且任何分开估计在零空间方向上的偏差≥min(G_trans,G_eval)。I1/I2/I3 任一成立即可恢复满秩。证明：可识别性等价于设计矩阵零空间为零；秩亏时零空间含 (δg, −Ψδg) 方向，两分量不可分；独立仪器增加独立方程、多单元使 Ψ 变化、外部标定固定真值，均消除零空间。∎

**引理 101（对偶评测-控制的安全性与信息增益）** 任何满足 ζ∈A(I_β(C)) 的探测块保持安全概率≥1−δ；期望信息增益非负；在持续激励（PE）与有界噪声下，z_hd 的后验协方差有界且 TTC 宽度收敛到噪声地板；PE 失败时宽度可能不收缩，但证书保持保守（无假安全）。证明：安全由引理 96/97；信息增益非负由互信息性质；PE 下可观测性给出协方差界；无 PE 时 ACI 只增不减，保守性保持。∎

**引理 102（评测过拟合与选择偏差界）** 若从 M 个配置中用各 n 个样本的含噪真机测试挑最大，选中效应的向上偏差以高概率不超过 σ√(2 log M/n)；若预注册单一主终点或使用样本分裂，verified 的假阳性率≤α。证明：对 M 个高斯的极大值用 union bound；预注册消除选择自由度，回到标准假设检验。故"真机评测"必须先冻结主终点，否则 EC 无效。∎

**引理 103（中立元退化等价 v10）** 注入定义 567 的中立元后，TTL 使 β=0、I_β=id；GFE/DECP 使规划退回 v10 NCP；ECE/CML 不影响控制。故 v11 的可行集与评分逐项退化为 v10，再由 v10 引理 93 继续退回 v9/v8/v7。∎

**引理 104（预算守恒）** TTL 滤波 O(n_z²·d_o) 在 100Hz 下≤0.2ms；TTC 区间与 ACI≤0.1ms；膨胀≤0.1ms；DECP 信息增益在 5Hz 下≤0.3ms；GFE/ECE 离线。总决策 p99 仍≤20ms，50Hz 保持。证明：逐项代入复杂度表并做静态 EDF 校验 ΣŴ_m≤B_dec。∎

**引理 105（安全继承与无绕过）** 执行管线为"v10 证书→I_β 膨胀→DECP 规划→50Hz 守卫"。I_β 只收紧（引理 97），DECP 的探测受膨胀后证书约束（引理 101），ECE/CML 不进入执行路径。故不存在绕过 v10 适用证书的执行路径；β=0 时逐位等价 v10，v10 引理 95 的安全继承继续成立。∎

**引理 106（包络越界的安全失败）** 若 z_hd∉E，则 TTC 无效且不产生任何新的 verified 声明；系统只能执行包络内的保守块或安全停止/询问。因此热/磨损外推不会在无告警的情况下使安全保证失效。证明：定义 556 要求 env_ok，定义 566 强制重标定或保守回退；执行侧只接受 TTC 有效块，故越界后不存在"仍按旧界执行"的路径。∎

## 8. 已知风险与失效模式

1. **谐波模型误设**：Bouc–Wen/Preisach 无法覆盖装配差异、润滑状态与非线性柔度；缓解：残差由 ACI 吸收、包络限制、E589 多温度/负载辨识、必要时非参数残差模型。
2. **缺少关节力矩传感器**：仅靠电流估计会被摩擦与温度偏差污染，I1 失效；缓解：依赖多单元 I2 与外部标定 I3，id_status=joint-only 时只用和界。
3. **磨损/热非平稳破坏可交换性**：保形预测的有限样本保证依赖层内可交换；缓解：ACI 长程覆盖、包络越界即失效、周期性重标定、E593/E594。
4. **评测样本少、功效不足**：真机昂贵导致 verified 门槛达不到；缓解：配对/switchback 降方差、VOI 选测、把结论降级为 bounded 而不是硬凑显著。
5. **自证与 Goodhart**：同一台机器既执行又评测，指标可被选择/泄漏/单元调换游戏；缓解：预注册单一主终点、样本分裂、单元级留出、CML 多重性控制、E608 对抗测试。
6. **间隙不可识别**：G_trans 与 G_eval 在单仪器单单元下混在一起，分开认证会系统性偏乐观；缓解：强制和界 S、报告 id_status、优先增独立仪器/多单元，而不是增模型复杂度。
7. **过度保守导致僵局**：β_hd 过大时可行集为空，机器人不敢动；缓解：包络内安全 hold/询问、VOI 标定、限制 K、按任务分层设 δ；但**不得**为恢复活性而缩小 β 到不覆盖真值。
8. **跨本体迁移失败**：谐波参数随减速比、装配、润滑变化，源域 TTC 不可直接搬；缓解：per-joint 少量标定、not-transferable 判定、回退 v10，负迁移≤5% 作为硬门槛。
9. **声明账本复杂度**：多重性控制可能把真实效应也判为不显著；缓解：预注册分层主/次终点、FDR 分组、把探索性分析显式隔离为 simulation-only/exploratory。
10. **在线预算**：滤波与区间传播可能挤占实时预算；缓解：低维潜状态、低频更新、离线 GFE/ECE、静态 EDF 校验（引理 104）。

## 9. 本轮最大风险

**一句话**：在会发热、会磨损的真实谐波关节上，传动误差与评测误差共享同一台机器与同一批少量试验；一旦二者不可识别而系统仍分别给出"已认证的传动界"和"已认证的评测界"，它就会用同源误差互相作证，产生高置信度的**自证清白式假安全**。
