# 第 1 轮（灵感循环 v2：「位姿估计」×「迁移学习」）—— 承接 UIP-01~10：从「在线语义验证」升级为「位姿中介的跨任务迁移」

> **承接关系**：research.md 既有区块是「迭代验证 / 排行榜 / 常识推理」驱动的 UIP-01~10，旗舰为 RHPV-V（在线 VLM 核验子目标 + 滚动重试）。本轮**不推翻其目标**——在成功率可能 <30% 时同时抢「成功率」与「步骤分」；本轮替换其**实现基座**：把「在线语义验证」换成**几何位姿中介**，把「32 个任务各自适配」换成**共享位姿空间上的迁移**。编号续 UIP-11~18。

## 0. 承接诊断：为什么恰好是这两个词

| 既有设计的痛点 | 位姿估计能补什么 | 迁移学习能补什么 |
|---|---|---|
| UIP-01 用在线 VLM 判子目标：每步数百 ms，直接进入 §6 的**延迟方差**；误判触发 `max_retry`，反而耗尽 episode 预算 | 把「子目标是否达成」变成**可测量的相对位姿误差**，毫秒级小头即可判 | 进度先验可从 33k 条成功演示中**离线摊销**，推理时不必每次重新「看懂」 |
| 像素→动作策略容易记住背景/位置；AV1 低分辨率下更甚 | 对象坐标系**消去**全局平移/背景，保留操作几何 | 同一套位姿表示可跨任务、跨背景复用，减少对每任务样本的依赖 |
| 32 任务差异大（倒药/插网线/叠纸杯/折毛巾），单模型易「平均化」 | 任务被统一为「对象间相对位姿目标序列」，差异落在**目标位姿**而非像素分布 | 共享技能库 + 轻量适配器，实现「单模型、多任务」的正迁移 |
| 数据集相机键与在线相机键不同，N 台机器安装也可能不同 | 位姿在中立几何空间，可配合**在线手眼自标定**消除相机外参差异 | 数据集上学的几何先验可迁移到线上，只要坐标系对齐 |

**硬约束（沿用既有事实，不重复编造）**：接口只暴露 4 路图像 + 双臂关节/EE 位姿 + 夹爪 + `observation.language`；`control_space` 提交时固定为 joint 或 ee；N 台真机随机顺序、每步延迟与动作统计规律性计入可信度；数据集是**成功演示语料**，没有 success/reward 标签，也没有对象 CAD/真值位姿。**因此位姿必须自监督地估计/自标注，不能用「假设已知物体 CAD」的方案冒充可落地。**

## 1. 两个灵感词的直觉解释

### 1.1 位姿估计：把「看起来像」换成「几何上在哪里」

**直觉**：让一个模型在陌生背景里找「那个杯子」，比让它记住「杯子在画面左下角」更难；但一旦知道杯口相对于夹爪的**六自由度位姿**，背景、光照、相机小幅移动都变成了无关变量。位姿是一个**低维、物理可解释、可组合**的中间语言：抓取=夹爪位姿对齐抓取位姿；插入=插头轴线与插座轴线对齐；叠放=两个物体坐标系的相对变换趋近目标变换。

**关键取舍**：不追求「绝对物体位姿 + CAD 模型」，而追求**相对位姿**（EE↔物体、物体↔物体、当前帧↔演示关键帧）。原因有三：① 无 CAD、未见物体多；② 绝对位姿依赖精确外参，N 台机器上不稳；③ 操作本身只依赖相对几何。相对位姿还天然给出**进度**与**成功判据**。

### 1.2 迁移学习：不是「多训几个模型」，而是「换坐标系后共享技能」

**直觉**：32 个任务看似千差万别，底层技能高度重叠：接近、对准、闭合夹爪、抬升、放置、倾倒也。如果把它们放在**对象中心坐标系**里，很多任务的轨迹会长得很像；差异只是「目标相对位姿」和「语言指定哪个对象」。迁移就不是复制网络权重，而是**复用同一套位姿条件下的技能**，再用少量适配把新任务/新物体映射进这个共享空间。

**三层迁移**，按样本效率从高到低：
1. **表示迁移**：跨任务共享视觉-几何编码器（可用 Unitree 已开源的 UnifoLM 系列或通用 VLM/检测/深度基础模型初始化）。
2. **技能迁移**：从演示中发现可复用的位姿空间原语（reach/grasp/align/insert/place/pour/fold），组成技能库。
3. **目标迁移**：新任务只需给定「对象—关系—目标位姿」序列（由语言+首帧解析），即可零样本/少样本组合已有技能。

## 2. 严谨定义

**定义 1（位姿与相对位姿）** 记 \(T=(R,t)\in SE(3)\)，\(R\in SO(3),t\in\mathbb R^3\)。物体 \(o\) 在相机/世界系 \(c\) 中的位姿为 \(T_{co}\)，末端在相机系中为 \(T_{ce}\)；**EE 在物体系中的相对位姿**为
\[
X \;=\; T_{co}^{-1}T_{ce}\in SE(3).
\]
李代数 \(\xi=\log(T)\in\mathbb R^6\)，加权范数 \(\|T\|_\Sigma=\|\log(T)\|_\Sigma\)（平移/旋转分块加权）。

**定义 2（位姿规范化 / Pose Canonicalization）** 给定任务相关对象集合 \(O=\{o_i\}\) 与参考对象 \(o_\*\)（由语言 grounding 选出），把观测与动作都表达到 \(o_\*\) 的局部系：
\[
C(o_t,a_t)=(X_t,\ \{\,T_{o_\*o_i}(t)\}_{i},\ a_t^{\text{obj}}),
\]
其中 \(a_t^{\text{obj}}\) 是把末端动作增量用 \(T_{co_\*}\) 旋转到对象系的表示。\(C\) **消去**全局位置、相机平移、部分背景纹理，只保留任务几何。

**定义 3（位姿目标与几何进度）** 一个任务被表示成有序目标 \(g_{1:K}\)，每个目标是一个关系三元组
\[
g_k=(o_i,o_j,\ \text{rel}),\qquad T^{\*}_{o_io_j}\in SE(3),
\]
例如「杯口在瓶口上方 5cm 且轴线对齐」。定义几何进度
\[
\rho_k(t)=\exp\!\Big(-\frac{1}{2\sigma^2}\big\|\log\big(T_{o_io_j}(t)^{-1}T^{\*}_{o_io_j}\big)\big\|_\Sigma^2\Big)\in(0,1],
\]
并令任务总进度 \(\Phi(t)=\frac{1}{K}\sum_k w_k\,\max_{s\le t}\rho_k(s)\)（取 running max 保证单调）。**这就是 UIP-01 中 VLM 验证器的几何替代**：当 \(\rho_k\ge\tau_{\text{done}}\) 且不确定性低时判「子目标达成」；当进度长期不增且误差超阈值时判「失败」。

**定义 4（位姿中介迁移）** 给定源任务集 \(S\)、目标任务集 \(T\)、共享编码器 \(f_\theta\)、位姿条件策略 \(\pi_\psi(a\mid X,g,l)\)，迁移目标是
\[
\min_{\theta,\psi}\ \sum_{\tau\in S}\mathbb E_{D_\tau}\big[\ell_\tau(\pi_\psi(f_\theta(C(o)),g_\tau),a)\big]
+\lambda\sum_{\tau\in T}\mathbb E_{D_\tau}\big[\ell_\tau(\cdot)\big]
+\mu\,R(\psi),\quad R(\psi)=\|\psi-\psi_0\|_{\text{low-rank}},
\]
即：共享表示 + **低秩适配**（LoRA/Adapter），目标域只动很小的子空间。与「每任务一个模型」相比，它满足单模型约束；与「一个模型硬扛 32 任务」相比，它保留了任务特化容量。

**定义 5（不确定性门控）** 位姿估计器输出 \((\hat X,\Sigma_X)\)。可信度 \(c=\exp(-\tfrac12\|\log(\hat X^{-1}X_{\text{prior}})\|^2_{\Sigma_X})\)。仅当 \(c\ge c_{\min}\) 时才让位姿特征进入策略，否则退回 RGB 策略；这是防止「一个几何错误污染所有任务」的安全阀。

## 3. 瓶颈假设（可证伪）

- **H1（几何消噪）**：在「背景/位置」泛化轴上，位姿规范化能消去大部分 nuisance 方差；预测 held-out 背景上的成功率下降显著小于纯 RGB 基线。若 H1 不成立，则位姿带来的收益仅限精度任务。
- **H2（技能共享）**：32 任务可被少数位姿空间技能原语覆盖；在留出任务上，技能库组合的少样本迁移优于从头微调。若技能聚类数≈任务数，则 H2 伪。
- **H3（几何验证更省）**：几何进度验证的每步延迟与方差显著低于在线 VLM，且误判率不更高。若位姿估计本身比 VLM 更慢/更不稳，则应保留 VLM 做低频兜底。
- **H4（标定是前提）**：数据集与 N 台真机之间的相机外参差异，是位姿迁移失败的主因之一；在线手眼/运动学自标定能显著缩小该差距。若外参几乎一致，则 H4 不成立，可省掉这部分工程。

## 4. 候选创新点（UIP-11~18）

围绕两个词发散后收敛为 8 个，按与「赛制 + 权限」的贴合度排序：

1. **UIP-11（旗舰）PMT · 位姿中介迁移**：对象中心相对位姿 + 共享技能库 + 低秩适配，一次性同时服务「位置/背景/未见物品」三条泛化轴与 32 任务。
2. **UIP-12 RPE · 相对位姿自监督**：用立体/腕部多视图一致性与「当前帧↔演示关键帧」匹配构造位姿监督，解决无真值位姿。
3. **UIP-13 HEC · 在线手眼自标定迁移**：用机器人运动学 + 头部立体相机反解外参，对齐数据集与 N 台真机。
4. **UIP-14 PSL · 位姿技能库**：在位姿空间做变点分割与聚类，发现可复用原语并做语言/位姿双条件路由。
5. **UIP-15 PGD · 位姿目标分解**：把语言指令解析成对象—关系—目标位姿序列，提供**密集步骤分信号**。
6. **UIP-16 CAT · 类别级位姿迁移**：给未见物体学类别规范坐标系（NOCS 式），把新实例映射进共享位姿空间。
7. **UIP-17 PGA · 位姿一致的泛化增广**：在保持相对位姿标签不变的前提下做背景替换/遮挡/光照合成，直接针对 5 条泛化轴。
8. **UIP-18 UPT · 不确定性门控的位姿迁移**：位姿不可信时早退到 RGB 策略，防止表征级错误级联，同时压低平均延迟。

## 5. 本轮押注

**押注 UIP-11 + UIP-12 + UIP-13 的最小闭环**：先用**自监督位姿标签工厂（UIP-12）**把 33k 成功演示变成带相对位姿的语料；再用**在线自标定（UIP-13）**把数据集与真机坐标系对齐；最后用**位姿中介技能迁移（UIP-11）**在一个共享模型里覆盖 32 任务。理由：这三者构成「数据→坐标系→策略」的完整因果链，且全部落在选手 API 权限内，不依赖尚未公开的计分点细则。

**本轮最大风险（一句话）**：位姿估计在未见物体与遮挡下的误差是**系统性、跨任务相关**的，一旦把它当作共享瓶颈，单个表征层的失败会经由迁移同时污染几乎所有任务，而离线代理指标又难以完全暴露这种真实分布偏移。

### 1.1 在线策略伪代码

```python
class PMTPolicy:
    def __init__(self, pose, skills, parser, ik, k=6,
                 conf_thr=0.6, unc_thr=0.15, max_retry=2):
        self.pose, self.skills, self.parser = pose, skills, parser
        self.ik, self.k = ik, k
        self.conf_thr, self.unc_thr, self.max_retry = conf_thr, unc_thr, max_retry

    def reset(self, obs):
        self.T_cw = self.pose.online_calibrate(obs, self.k)   # UIP-13
        self.goals = self.parser(obs.language, obs)           # UIP-15: [g_1..g_K]
        self.g = 0; self.retry = 0; self.buf = []
        self.phi_hist = []

    def get_action(self, obs):
        if not self.buf:
            # 1) 几何层：对象位姿 + 协方差
            O, Sigma, unc = self.pose(obs, self.T_cw)         # O={T_co}
            # 2) 门控：不可信就退回 RGB 路径（UIP-18）
            if unc > self.unc_thr:
                self.buf = list(self.skills.rgb_act(obs)[: self.k]); return self.buf.pop(0)

            # 3) 几何进度 / 成功判据（替代在线 VLM）
            prog = self.progress(O, self.goals[self.g])
            self.phi_hist.append(prog.rho)
            if prog.rho >= self.conf_thr:
                self.g = min(self.g + 1, len(self.goals) - 1); self.retry = 0
            elif self.stalled() and self.retry < self.max_retry:
                self.retry += 1                              # 有界重试，保留三重护栏

            # 4) 规范化 + 技能选择 + 位姿条件动作
            X = canonicalize(O, obs.ee_pose)                  # UIP-11 定义 2
            a_chunk = self.skills.act(X, self.goals[self.g], obs.language)
            self.buf = list(a_chunk[: self.k])                # 只承诺 k 步
        return self.buf.pop(0)

    def stalled(self):
        return len(self.phi_hist) >= 8 and \
               max(self.phi_hist[-8:]) - min(self.phi_hist[-8:]) < 1e-3
```

**护栏继承**：`k` 步承诺限制盲走；`conf_thr` 限制误判；`max_retry` 限制发散；新增 `unc_thr` 限制「几何错误」进入策略。四者都是 API 内部变量，不触碰执行层。

### 1.2 数学形式（训练目标）

对任务 \(\tau\)，令 \(C(o_t)\) 为位姿规范化观测，\(g_{1:K}^{(\tau)}\) 为目标位姿序列，共享编码器 \(f_\theta\)、技能策略 \(\pi_\psi\)：
\[
\mathcal L_\tau=\sum_t \underbrace{\|a_t-\pi_\psi(f_\theta(C(o_t)),g_{\kappa(t)}^{(\tau)})\|^2}_{\text{动作回归}}
+\alpha\underbrace{\big(-\log\rho_{\kappa(t)}(t)\big)}_{\text{进度排序}}
+\beta\underbrace{\|\log(\hat X_t^{-1}X_t)\|^2_{\Sigma_t}}_{\text{位姿辅助}}
+\gamma\underbrace{\|a_t-a_{t-1}\|^2}_{\text{动作平滑（可信度）}}.
\]
及低秩约束 \(\psi=\psi_0+BA,\ \operatorname{rank}(BA)\le r\)。总目标为 \(\sum_{\tau\in S}\mathcal L_\tau+\lambda\sum_{\tau\in T}\mathcal L_\tau\)。

> 进度项 \(\rho\) 来自「目标位姿已达成程度」，因此**步骤分与成功率共享同一几何信号**：失败任务中只要到达了靠前的目标位姿，就自然锁定部分步骤分。

### 1.3 与既有 UIP-01 的关系

| 维度 | UIP-01 RHPV-V | UIP-11 PMT |
|---|---|---|
| 验证信号 | 在线 VLM 语义判断 | 相对位姿几何误差 + 不确定性 |
| 每步延迟 | 数百 ms，方差大 | 小头毫秒级；位姿可降频/缓存 |
| 泛化机制 | 语言常识条件 | 对象坐标系规范化 + 技能迁移 |
| 部分得分 | 靠 VLM 判子目标 | 靠目标位姿序列的连续进度 |
| 失败模式 | 语义误判 + 超时 | 几何系统性偏差 + 遮挡 |
| 关系 | —— | **保留其目标与护栏，替换验证基座；VLM 降为低频兜底** |

## 2. UIP-12 · 相对位姿自监督标签工厂

**动机**：没有对象真值位姿，必须从成功演示中自动构造监督，否则整个方案不可落地。

**核心方程**：机器人基座 \(w\)、相机 \(c\)、末端 \(e\)、对象 \(o\)。
1. **机器人-相机外参**（离线，一次）：末端上取若干已知运动学点 \(p_k^{e}\)，投影应与图像观测 \(u_{k,t}\) 一致：
\[
T_{cw}^{\*}=\arg\min_{T\in SE(3)}\sum_{t,k}\big\|\pi\big(T\,T_{we}(t)\,p_k^{e}\big)-u_{k,t}\big\|^2 .
\]
标准的机器人-相机标定，运动充分时可解，给出 \(T_{cw}\)。
2. **对象三维跟踪**：头部双目给出度量深度，语言 grounding（SAM2/GroundingDINO 或 VLM）给出对象掩码，得到对象点云 \(P_t^c\)；变换到世界系 \(P_t^w=T_{cw}P_t^c\)。
3. **相对位姿**：以演示起始/关键帧为参考，用 Umeyama/SVD 求
\[
T_{o_\*o_t}=\arg\min_{T\in SE(3)}\sum_j\|T\,p_j^{ref}-p_j^{t}\|^2 ,
\]
得到对象间相对轨迹；抓取闭合期间再用「手眼一致性」平滑：
\[
T_{eo}=\operatorname{robust\_avg}_t\big(T_{we}(t)^{-1}T_{wo}(t)\big).
\]
4. **伪标签置信度**：以重投影残差、点云覆盖度、双目视差有效性估计 \(\Sigma_t\)，低置信帧不参与训练。

**自监督闭环**：当前帧 ↔ 演示关键帧的匹配（DINOv2/MASt3R 特征 + 关键点求解）提供跨 episode 的相对位姿监督；双目左右一致性、腕部/头部视图循环一致性构成无标签损失。这样位姿估计器与策略可以在同一批演示上迭代，而不需要人工标注。

**可证伪检查**：在已知 CAD 的少量对象上，与 FoundationPose 式实例位姿对比；若相对位姿角误差 > 10° 或平移误差 > 2cm，则先修标签工厂，不进入策略训练。

## 3. UIP-13 · 在线手眼自标定（跨机器迁移的前提）

- **问题**：数据集相机键与在线接口键不同；N 台真机安装/分辨率也可能不同。绝对位姿迁移会因外参漂移整体失效。
- **做法**：在线前若干帧，让机器人做一小段已知运动（或利用评测开始时的自然运动），用 §2 的同一标定方程反解 \(T_{cw}\)；与数据集先验做鲁棒融合（Huber / 卡尔曼），得到 per-port 标定。
- **为什么算「迁移学习」**：它把「在一个标定下学到的几何先验」**显式搬运**到另一个标定，属于坐标系层面的 domain adaptation，而不是让网络重新学像素统计。
- **失败保护**：标定残差高时，位姿门控自动降级到 RGB 策略（UIP-18），避免把错误外参灌进所有任务。

## 4. UIP-14 · 位姿技能库（迁移的载体）

**构造**：
1. 用位姿轨迹 \(z(t)=[\log X(t),\ \text{gripper},\ \|v\|,\ \text{contact proxy}]\) 做带惩罚变点检测/最优分段：
\[
\min_{0=t_0<\cdots<t_K}\sum_k\sum_{t\in(t_{k-1},t_k]}\|z(t)-\mu_k\|^2+\lambda K .
\]
2. 对分段后的片段做 DTW 对齐 + 相位不变特征聚类，得到 \(M\) 个候选原语（reach / grasp / align / insert / place / pour / fold / retract）。
3. 每个原语学习一个位姿条件的动作头；任务策略 = 原语序列 + 目标位姿。

**为什么能迁移**：原语在**对象局部系**中定义，去掉全局位置与背景；新任务只需指定「哪个对象、什么关系、什么目标位姿」。若聚类数远小于 32（H2 成立），共享带来的样本效率就是净收益。

**可证伪检查**：留出 8 个任务做 zero-shot / 5-shot 迁移；若技能库组合不优于单任务微调，则 H2 伪，退回任务适配器方案。

---

## 5. UIP-15/16/17/18 · 支撑模块

- **UIP-15 PGD（位姿目标分解）**：把 `observation.language` 解析为 `(对象, 关系, 目标位姿)` 序列。对「叠杯/插网线/放相框/倒药」等任务，目标是可几何化的（轴线对齐、平面贴合、杯口相对高度）。解析不确定时保留 2~3 个候选目标，由进展最快的候选胜出（软目标，不硬判）。这正是「步骤分」的密集信号来源。
- **UIP-16 CAT（类别级位姿迁移）**：对未见物体，学习类别规范坐标系（NOCS 式）或「以抓取点/主轴定义的自定义规范系」，把实例映射到共享位姿空间；无法归类时退化为「相对关键帧位姿」。
- **UIP-17 PGA（位姿一致增广）**：在**保持相对位姿标签不变**的前提下，合成背景替换、干扰物、光照、轻微遮挡；与普通图像增广的区别是「几何标签必须同步变换或保持不变」。直接对冲位置/背景/干扰物三条泛化轴。
- **UIP-18 UPT（不确定性门控）**：以重投影残差 + 集成方差 + 视差有效性给出 \(c\)；低置信时早退到 RGB 策略或低频 VLM 核验。它同时保护成功率（不被错误几何带偏）与可信度（不产生异常动作/延迟尖峰）。

## 6. 实验设计（全部先做离线代理）

| 编号 | 对照 | 数据/设置 | 指标 | 通过标准（go） |
|---|---|---|---|---|
| E101 | RGB 策略 vs 位姿条件策略 | 同任务、held-out 背景/位置 | 成功率代理、进度 AUC | 位姿版在背景轴上下降 < 基线一半 |
| E102 | 单任务微调 vs 技能库迁移 | 留出 8 任务，5-shot | 成功率、达到首个目标位姿的步数 | 迁移版 ≥ 单任务版，且样本量需求降 ≥5× |
| E103 | 标签工厂 vs CAD 真值（少量已知物体） | FoundationPose 对照 | 角误差/平移误差/重投影 | 角 <10°、平移 <2cm |
| E104 | 无标定 vs 在线自标定 | 人为扰动外参 ±2cm/±5° | 成功率代理、位姿误差 | 自标定恢复 ≥70% 性能 |
| E105 | 无门控 vs 不确定性门控 | 注入遮挡/错误深度 | 失败率、异常动作率 | 失败率降 ≥30%，延迟不增 |
| E106 | 在线 VLM 验证 vs 几何验证 | 同任务回放 | 每步延迟均值/方差 | 延迟方差降 ≥50% |
| E107 | 端到端 PMT vs RHPV-V | 32 任务代理集 | 成功率 + 步骤分代理 | 综合显著优于，且动作平滑达标 |

**代理指标定义**（无真机/无计分点正文时的替代）：
- **成功率代理**：在留出演示上，最终相对位姿误差低于任务阈值且夹爪状态正确的比例。
- **步骤分代理**：\(\frac{1}{K}\sum_k \mathbb 1[\max_t \rho_k(t)\ge\tau_k]\)，即到达了多少个目标位姿里程碑。
- **可信度代理**：每步延迟的均值/95 分位/方差、动作 jerk、动作分布与演示的 MMD。

> 所有结论在正式提测前必须标注为**代理**；E107 的「优于」不得写成真机结论。

## 7. 消融与失败分析（必须做）

1. **位姿来源消融**：真值位姿（上限）→ 标签工厂位姿 → 在线估计位姿，量化每一级的性能衰减。
2. **规范化消融**：全局坐标系 vs 对象坐标系；证明收益来自几何而非更多参数。
3. **技能数 \(M\)**：扫 4/8/16/32，画「迁移收益—共享损失」曲线，验证 H2。
4. **误差相关性分析**：按对象类别/遮挡程度分组，检查位姿误差是否**跨任务相关**（这是本方案最大风险的直接检验）。
5. **门控阈值敏感性**：\(c_{\min}\)、`unc_thr` 的代价曲线（漏检 vs 误退）。

## 8. 资源与时间线（粗排）

- 第 1–2 周：标签工厂 + 机器人-相机标定；在少量已知物体上校准 E103。
- 第 3–4 周：位姿估计器蒸馏/轻量化 + 在线自标定；E104/E106。
- 第 5–7 周：技能库发现 + 位姿条件策略训练；E101/E102。
- 第 8–9 周：不确定性门控 + 增广；E105/E107，离线代理门禁。
- 第 10 周起：预约真机提测，用真实数据校准代理与阈值。

**算力/数据**：优先复用 Unitree 已开源模型与通用基础模型做初始化；位姿标签工厂主要吃 CPU/GPU 离线批处理；在线只需一个轻量位姿头 + 一个策略，符合单模型约束。

## 9. 本轮最大风险（承接想法区）

**一句话**：位姿误差在未见物体与遮挡下是系统性且跨任务相关的，一旦它成为共享瓶颈，单个表征层的偏差会经迁移同时污染几乎所有任务，而离线代理无法完全暴露真实分布偏移——因此必须先用**真值位姿上限实验 + 分组误差相关性分析 + 不确定性门控**证明「几何瓶颈」可控，再投入技能库与大规模迁移训练。
