### 第 5 轮灵感驱动研究记录

**灵感词**：在线学习、多机协作

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点之上追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3·η_val·η_bal；执行集跨版本单调收缩 Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。本轮不推翻 v4，而是补两个结构性缺口：**时间维**（部署后世界漂移时证书是否仍有效）与**社会维**（多个各自安全的证书能否组合出团队安全）。据此形成 CADVS-v5（IP-493~496），九硬门，并首次引入「学习-认证分离」原则与「安全包络包含」定理。执行集语义升级为时变：∀t, Exec_CADVS-v5(t) ⊆ Exec_CADVS-v4，且版本内随 re-forge 单调不减。

**直觉与动机**：

1. **在线学习：把「部署前快照」升级为「漂移下仍然有效、且可安全探索」的活证书**。
   - *直觉*：v4 的证书是静态快照——模型离线训练、规则准入时一次性评估。可机器人一旦上岗，物性（质量/摩擦）、传感器增益、任务分布都会漂移；昨天的证书今天可能已悄悄失配。但「在线学习」天然要求探索未知动作，而 fail-closed 硬门恰恰禁止未知——这是本轮的**根本冲突**。化解之道不是放松硬门，而是**把学习与认证在时间上解耦**：连续学习只更新软层（先验、价值权重 λ、conformal 分位数 q_t）；硬门参数在一个「证书 epoch」内冻结，只有 re-forge 事件才重新证明。探索动作必须先通过 v4 七硬门屏蔽（shield），于是**在线学习不可能做出 v4 不允许的动作**，安全包络不被突破。
   - *严谨定义*：引入在线证书学习核 OCLK。以非一致性分数 s(x,y;θ) 构造预测集 C_t={y:s≤q_t}，用**自适应 conformal 更新** q_{t+1}=q_t+γ(1{y_t∉C_t}−α)，在**任意（含对抗）漂移序列**下保证长期误覆盖 →α；用 Page-Hinkley/CUSUM 统计量 g_t 检测突变，告警即令 kc_temporal=⊥（fail-closed）并触发 re-forge；认证探索集 S_t={a : LCB_safety(a)=ŝ(a)−q_t ≥ 0}，以信息增益 I(a) 为目标、以安全边际预算 B_t 为约束，且执行前再过一遍 v4 七硬门。

2. **多机协作：把「站点间联邦」升级为「同场实时团队证书」**。
   - *直觉*：v4 的 FFA 是离线、跨组织、以服务器 FedAvg 为中心的星形联邦；它不处理同处一个工作空间的实时团队。危险在于：每台机器人都持有「我安全」的局部证书，但局部安全**不蕴含联合安全**——两两轨迹可能在时空上交叠（碰撞）、可能互相等待（死锁）、可能争抢同一资源。必须把「关系」本身铸成证书，并在无中心、有拜占庭、会分区的条件下达成**分布式证书共识**。
   - *严谨定义*：引入多机协作证书核 MCCK。两两关系证书 RC_ij=(d_ij, d_safe, ε_sep, comm_delay_ij, τ_comm)，kc_rel_ij=(d_ij>d_safe+√ε_sep)∧(comm_delay_ij<τ_comm)，其中分区安全膨胀项 ε_sep=(v_max·τ_max)²；团队门 kc_team=∧_i kc_i ∧ ∧_{i<j} kc_rel_ij ∧ kc_resource。共识采用 BFT 交叉验证：以同伴**相对观测**复核自报，quorum=2f+1，自报与 ≥f+1 同伴观测冲突即撤销证书（CERT_REVOKED）；分区时各连通分量按 ε_sep 膨胀边际并维持分离控制屏障 h_ij=d_ij²−d_safe²≥ε_sep。经验共享由信任加权 P2P 学习承担：τ_ij←(1−η)τ_ij+η·agree，更新须过本地 holdout 证书校验，抵御投毒。

3. **学习-认证分离：把「安全」与「进化」解耦，解决版本内扩张与跨版本收缩的矛盾**。
   - *直觉*：v4 的单调收缩定理说 Exec_{v(k+1)}⊆Exec_{v(k)}，这是**跨版本**性质；但在线学习希望同一版本内执行集随证据增长而**变大**（学会更多安全动作）。二者看似矛盾，实则可用「包络」调和：v5 的探索被 v4 七硬门屏蔽，且新增 kc_temporal/kc_team 两道门，故任一时刻 Exec_v5(t)⊆Exec_v4；而版本内每次 re-forge 都重证全部门，只可能把**已在 v4 包络内、且新证据支持**的规则纳入，故 Exec_v5 在 re-forge 间单调不减、上有界于 Exec_v4。
   - *严谨定义*：epoch 内硬门函数冻结 ⇒ Exec_v5(t) 为常量；软层更新不改变任何硬门判定。re-forge 时对候选规则重跑九门。得**安全包络包含定理**：∀t, Exec_v5(t)⊆Exec_v4；且对 re-forge 序列 t_1<t_2<…，Exec_v5(t_k) 单调不减且 ⊆Exec_v4。于是「跨版本只缩不涨」与「版本内自适应扩张」同时成立，安全不再依赖单调收缩，而依赖「扩张必经重证 + 恒被 v4 包络约束」。

**关键洞见**：v4 七锚点覆盖「空间→物理→人因→末点→记忆→价值→平衡」的**单机单时刻**证据链；v5 追加时间锚（OCLK：漂移鲁棒覆盖 + 认证探索）与社会锚（MCCK：关系证书 + 分布式共识 + 信任 P2P），把证据链补成「单机—时间—团队」三维。核心范式转变是**学习-认证分离**：连续学习只动软层，硬门只在 re-forge 时重证；安全由「包络包含 + 扩张必经重证」保证，而非由「执行集只缩不涨」保证。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_temporal ∧ kc_team，fail-closed；软评分 ECS_v5 = ECS_v4 · η_online · η_team。

**形式化目标（增量）**：
1. 定义自适应 conformal 证书 ACert=(q_t, α, γ, cover_hat_t)，更新 q_{t+1}=q_t+γ(err_t−α)；证明任意漂移下 |(1/T)Σerr_t−α| ≤ (q_max−q_min+γ)/(γT)。
2. 定义漂移检测器 CUSUM(g_t,h,k) 与 kc_temporal = (¬alarm) ∧ (q_t≤q_max) ∧ (cover_hat_t ≥ 1−α−ε)，fail-closed。
3. 定义认证探索：S_t={a:ŝ(a)−q_t≥0}，a_t=argmax_{a∈S_t} I(a) s.t. Δm(a)≤B_t；执行前经 v4 shield；给出遗憾-安全权衡界。
4. 定义关系证书 RC_ij、kc_rel_ij、kc_team 与分区分离不变量 ε_sep=(v_max·τ_max)²。
5. 定义分布式证书共识 DCC：quorum=2f+1、交叉验证、撤销规则；f<N/3 下的安全性与活性。
6. 定义信任加权 P2P 学习：τ_ij 更新、holdout 校验、gossip 传播。
7. 定义九硬门 EFA-v5 与 ECS_v5=ECS_v4·η_online·η_team。
8. 证明学习-认证分离定理与安全包络包含定理：∀t, Exec_v5(t)⊆Exec_v4；re-forge 间 Exec_v5 单调不减。

**本轮最大风险**：**在线学习的探索诉求与 fail-closed 认证在「漂移突发窗口」内存在根本性时间错配**——自适应 conformal 只保证**长期边际**覆盖，CUSUM 检测存在延迟，因此在突变被检出之前，证书可能仍显示「安全」而模型已失配，形成隐性违例；叠加多机分布式共识的通信延迟与分区，各机可能对团队证书产生分歧，使协同动作在通信盲区中失去互保。

## 2. 关键算法骨架

### IP-493 OCLK：在线证书学习核（控制/决策环内 O(1)）

```python
@dataclass
class OnlineCertificateLearningKernel:
    """OCLK：自适应 conformal + 漂移检测 + 认证探索；kc_temporal 硬门。
    设计原则（学习-认证分离）：update() 只动软层 q_t 与先验；硬门参数由 epoch 冻结。"""
    alpha: float = 0.10          # 目标误覆盖
    gamma: float = 0.01          # conformal 步长
    q: float = 0.0
    q_max: float = 1.0
    cusum_g: float = 0.0
    cusum_h: float = 8.0
    cusum_k: float = 0.5
    budget: float = 1.0          # 安全边际预算 B_t
    drift_alarm: bool = False
    cover_window: deque = field(default_factory=lambda: deque(maxlen=512))

    def update(self, x, y, theta) -> None:
        # 1) 非一致性分数与是否覆盖
        s = self._score(x, y, theta)
        covered = (s <= self.q)
        self.cover_window.append(1.0 if covered else 0.0)
        # 2) 自适应 conformal：对任意（含对抗）漂移序列保持长期覆盖 -> 1-alpha
        self.q = self.q + self.gamma * ((0.0 if covered else 1.0) - self.alpha)
        self.q = float(np.clip(self.q, 0.0, self.q_max))
        # 3) CUSUM 漂移检测（Page-Hinkley 变体）
        e = abs(y - self._predict(x, theta))
        self.cusum_g = max(0.0, self.cusum_g + (e - self._ref - self.cusum_k))
        if self.cusum_g > self.cusum_h:
            self.drift_alarm = True
            self.q = self.q_max          # 立即膨胀，等价于「拒绝一切未证动作」
        # 4) 预算补充：安全成功且无告警时恢复探索能力
        if covered and not self.drift_alarm:
            self.budget = min(1.0, self.budget + self._replenish)

    def kc_temporal(self) -> bool:
        """fail-closed：任一条件不满足即拒绝。O(1)（滑动窗口均值 O(1) 摊还）。"""
        cover_hat = sum(self.cover_window) / max(len(self.cover_window), 1)
        return (not self.drift_alarm) and (self.q <= self.q_max) \
            and (cover_hat >= 1.0 - self.alpha - self._eps)

    def explore(self, candidates, theta):
        """认证探索：仅在 LCB 安全的候选集内、且边际预算允许时选信息增益最大者。
        调用方在执行前必须再过 v4 七硬门（shield）。"""
        feasible = [a for a in candidates
                    if self._lcb_safety(a, theta) >= 0.0
                    and self._margin_cost(a) <= self.budget]
        if not feasible:
            return None
        a_star = max(feasible, key=self._info_gain)
        self.budget -= self._margin_cost(a_star)
        return a_star

    def reforge_trigger(self) -> bool:
        """漂移恢复且覆盖回升 -> 允许进入 re-forge（重证九门）"""
        return self.drift_alarm and self._recent_safe_run() >= self._reforge_len

    def _lcb_safety(self, a, theta) -> float: ...   # ŝ(a) - q_t（保守安全下界）
    def _margin_cost(self, a) -> float: ...
    def _info_gain(self, a) -> float: ...           # 集成方差/互信息
    def _score(self, x, y, theta) -> float: ...
    def _predict(self, x, theta) -> float: ...
```

### IP-494 MCCK：多机协作证书核（协作环 10–50 Hz）

```python
@dataclass
class MultiRobotCollaborativeCertificateKernel:
    """MCCK：关系证书 + BFT 分布式共识 + 信任加权 P2P 学习；kc_team 硬门"""
    N: int
    f: int                       # 需满足 3f+1 <= N
    d_safe: float = 0.30
    tau_comm: float = 0.020
    tau_max: float = 1.0         # 最大可容忍分区时长
    v_max: float = 1.5
    trust: dict = field(default_factory=dict)   # trust[(i,j)] in [0,1]
    tau_min: float = 0.60
    eta_trust: float = 0.10

    # ---------- 关系证书 ----------
    def relational_certificate(self, i, j, si, sj, comm_delay) -> RC:
        d = float(np.linalg.norm(si.p - sj.p))
        eps_sep = (self.v_max * self.tau_max) ** 2
        return RC(d_ij=d, d_safe=self.d_safe, eps_sep=eps_sep,
                  comm_delay=comm_delay, tau_comm=self.tau_comm)

    def kc_rel(self, rc: RC) -> bool:
        return (rc.d_ij > rc.d_safe + math.sqrt(rc.eps_sep)) \
            and (rc.comm_delay < rc.tau_comm)

    def kc_team(self, local_certs, rel_certs, resource_ok) -> bool:
        return all(local_certs) and all(self.kc_rel(rc) for rc in rel_certs) \
            and resource_ok

    # ---------- 分布式证书共识（BFT） ----------
    def consensus(self, self_report, peer_obs):
        """以同伴相对观测复核自报；quorum=2f+1 才能认证；冲突超 f+1 即撤销。"""
        quorum = 2 * self.f + 1
        votes = sum(1 for o in peer_obs if self._agree(self_report, o))
        if votes < quorum:
            return False, 'CERT_REVOKED'
        return True, 'CONSENSUS_OK'

    # ---------- 信任加权 P2P 学习（抗投毒） ----------
    def peer_update(self, j, update, holdout) -> bool:
        if self.trust.get(j, 0.0) < self.tau_min:
            return False
        if not self._passes_holdout(update, holdout):   # 证书级校验
            self.trust[j] = max(0.0, self.trust[j] - self.eta_trust)
            return False
        self.trust[j] = min(1.0, self.trust[j] + self.eta_trust)
        self._merge(update)                              # 软层合并，不动硬门
        return True

    def separation_barrier(self, i, j, si, sj) -> float:
        """分区期间维持 h_ij = d_ij^2 - d_safe^2 >= eps_sep 的 CBF"""
        return float(np.linalg.norm(si.p - sj.p) ** 2) - self.d_safe ** 2 \
            - (self.v_max * self.tau_max) ** 2

    def _agree(self, a, b) -> bool: ...
    def _passes_holdout(self, u, holdout) -> bool: ...
    def _merge(self, u) -> None: ...
```

### IP-495 CERTCALC-v5：证书演算与核心定理（离线理论）

```python
class CertCalcV5:
    """在 v4 证书格上加入时序算子与分布式模态，并给出 v5 两大定理。"""
    TOP, BOT = "⊤", "⊥"
    meet = staticmethod(lambda a, b: f"({a} ∧ {b})")   # 合取
    join = staticmethod(lambda a, b: f"({a} ∨ {b})")   # 析取
    neg  = staticmethod(lambda a: f"¬{a}")
    always = staticmethod(lambda a, T: f"□_[0,{T}]{a}")  # 时窗内恒真
    eventually = staticmethod(lambda a, T: f"◇_[0,{T}]{a}")
    until = staticmethod(lambda a, b: f"({a} U {b})")
    consensus = staticmethod(lambda a, Q: f"⊞_{Q}{a}")  # 在 quorum Q 中为真

# 定理 5（学习-认证分离）：epoch 内硬门冻结 => Exec_v5(t) 为常量，软层更新不改硬门判定；
#   re-forge 是唯一改变硬门参数的时刻，且必须重证九门。
```

### IP-496 EFA-v5：九硬门 + 软评分

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；ECS_v5 = ECS_v4 · η_online · η_team"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    ock: OnlineCertificateLearningKernel
    mcck: MultiRobotCollaborativeCertificateKernel
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec, bcc,
                  object_class, geo_sig, theta_domain_fp, traj, context,
                  local_certs, rel_certs, resource_ok):
        # 优先级：HIC veto 最高；其余八门并行评估，任一失败即拒（fail-closed）
        if self.hic.veto_active(hic):              return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):     return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):                return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc):               return False, 'BALANCE_UNSTABLE'
        if not self.ltem.query(object_class, geo_sig, theta_domain_fp, rule_id)[0]:
            return False, 'MEMORY_REJECT'
        if not self.vack.kc_val(self.vack.evaluate(traj, context, t_now)):
            return False, 'VALUE_MISALIGNED'
        if not self.ock.kc_temporal():             return False, 'TEMPORAL_INVALID'   # 新增
        if not self.mcck.kc_team(local_certs, rel_certs, resource_ok):
            return False, 'TEAM_UNSAFE'                                                  # 新增
        return True, 'FORGED_V5'

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5, eta_online=1.0, eta_team=1.0) -> float:
        base = (self.scf.gamma3d(x, t_now) ** self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0) ** self.w[1]
                * (1 + self.w[2] * A_att))
        return base * eta_mem * eta_val * eta_bal * eta_online * eta_team
```

## 4. 正确性论证（增量更新）

### 引理 43（ACert 漂移鲁棒覆盖）

**陈述**：对任意序列 (x_t,y_t)（不要求可交换/独立同分布），自适应 conformal 以步长 γ 更新 q_{t+1}=q_t+γ(err_t−α)，q_t∈[q_min,q_max]，则
|(1/T)Σ_{t=1}^T err_t − α| ≤ (q_max − q_min + γ)/(γT)。

**证明**：由 q_{T+1}−q_1 = γΣ_t(err_t−α) 望远镜求和，取绝对值并用 q_t 有界：|Σ_t(err_t−α)| ≤ (q_max−q_min)/γ，两边除 T。∎

**工程含义**：长期误覆盖 →α，对任意漂移成立；但这是**边际**保证，瞬时突发须靠引理 44 的检测器兜底。

### 引理 44（漂移检测的暴露界）

**陈述**：若漂移使残差均值偏移 Δμ，CUSUM（参考量 k<Δμ，阈值 h）的期望检测时延 ≤ h/(Δμ−k)；检测前平均额外误覆盖 ≤ α + Δμ·h/(Δμ−k)。

**证明**：CUSUM 漂移下统计量线性增长，越过 h 的期望步数为 h/(Δμ−k)（标准 Page-Hinkley 结论）；期间误覆盖近似为漂移后覆盖率。∎

**工程含义**：单次突变的总暴露为 O(h/(Δμ−k))，可通过调小 h 降暴露、以误报率换取。

### 定理 45（认证探索的遗憾-安全权衡）

**陈述**：探索动作先经 v4 七硬门 shield、再受 LCB 安全集 S_t 与预算 B_t 约束。则在 conformal 误接受率 ≤α 下，探索引入的**额外**安全违例期望 ≤ α·T_explore；且相对最优安全策略的遗憾 ≤ O(√(T·γ_T))（γ_T 为最大信息增益，GP-UCB 型界）。

**证明**：shield 保证任何执行动作已通过 v4 全部硬门，故不引入 v4 之外的新物理违例；LCB 用 ŝ−q_t，q_t 的 conformal 覆盖使误接受 ≤α；遗憾由标准安全贝叶斯优化界给出。∎

**工程含义**：在线学习**不可能比 v4 更不安全**——这是本轮最重要的安全论证。

### 定理 46（团队证书组合与分布式共识）

**陈述**：设 f<N/3 拜占庭、通信时延 ≤τ、关系模型完备、初始分离 d_ij≥2√ε_sep。则 DCC 共识（quorum=2f+1 + 交叉验证）只认证团队安全动作（安全性），且最终认证所有安全动作（活性）；分区期间各分量按 ε_sep 膨胀并维持 CBF h_ij≥ε_sep，保证跨分量无碰撞。

**证明**：quorum=2f+1>N/3 保证任两法定集合交集含 ≥1 诚实机（共识安全）；交叉验证以相对观测覆盖自报，拜占庭自报无法通过 ≥f+1 诚实机复核；分区时 d_ij≥2√ε_sep 且相对位移 ≤v_max·τ_max=√ε_sep，故 d_ij 始终 ≥√ε_sep>0（分离 CBF 保证）。∎

**工程含义**：局部安全 + 关系证书 + 共识 = 团队安全的**充分条件**（保守但可证）。

### 定理 47（学习-认证分离与安全包络包含）

**陈述**：(i) epoch 内硬门冻结 ⇒ Exec_v5(t) 为常量，软层更新不改变任何硬门判定。(ii) ∀t, Exec_v5(t) ⊆ Exec_v4。(iii) 对 re-forge 序列 t_1<t_2<…，Exec_v5(t_k) 单调不减且 ⊆ Exec_v4。

**证明**：(i) 硬门是冻结参数与冻结模型的确定性函数，软层不进入硬门。(ii) v5 = v4 ∧ kc_temporal ∧ kc_team，且探索被 v4 shield 屏蔽，故任一时刻多两道合取门只会收缩执行集。(iii) re-forge 只在重证九门通过时纳入新规则，故不删已证规则（单调不减），且新规则仍须过 v4 门（⊆Exec_v4）。∎

**诚实声明**：定理 46 的「关系模型完备」与「时延上界」在真实无线网络中是强假设；分区膨胀 ε_sep 依赖 v_max、τ_max 的可靠估计，估计偏低会低估分离需求。定理 45 的遗憾界依赖信息增益有界，非平稳环境下 γ_T 可能随漂移反复增长。

## 7. 本轮最大风险（最终确认）

**一句话**：**在线学习的探索诉求与 fail-closed 认证在「漂移突发窗口」内存在根本性时间错配**——自适应 conformal 只保证长期边际覆盖、CUSUM 检测存在延迟，故在突变被检出之前证书可能仍显示「安全」而模型已失配，形成隐性违例；叠加多机分布式共识的通信延迟与分区，各机可能对团队证书产生分歧，使协同动作在通信盲区中失去互保。
