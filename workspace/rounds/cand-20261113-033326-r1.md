> 1. **只有空间先验，没有时间见证**：实时流（1–10kHz）在低频锚点（10–100Hz）之间缺少独立的物理观测；LiDAR 几何是「慢的、外感受的」，而接触、碰撞、滑移、执行器扰动是「快的、本体感受的」。当 E_geo 在分布外几何上产生幻觉（法向翻转、虚假接触面）时，系统没有任何**非几何通道**去证伪它——几何先验从「压缩不确定性」变成「注入确定性错误」。

## 0. 直觉与动机

**灵感 1（惯性测量单元 → ICF：Inertial Contact Fusion 惯性接触融合）**
直觉：IMU 以 1kHz 给出角速度与比力，是**独立于视觉/LiDAR 的本体物理通道**。真实接触会在高频段留下不可伪造的动力学签名：撞击尖峰、接触力方向、摩擦锥内的切向/法向比、滑移时的微振动。于是把 IMU + 关节电流/力矩送入**动量观测器**，估计外部力/力矩 w_ext 与接触事件 e_contact；再与几何预测的接触法向 n_geo、接触点 p_geo 做**互证**。关键洞见：**几何可以被惯性证伪，但惯性很难被几何伪造**——这为第 63 轮的最大风险提供了一个原理上不同的「见证通道」。
配套两个组件：**IAB（Inertial Anchor Bridge）** 用 IMU 预积分在两次低频锚点之间传播位姿与速度，把锚点新鲜度窗口从 Δt_anchor 扩展到 Δt_anchor+Δt_imu 且漂移有界；**IGW（Inertial-Geometric Witness）** 用 χ² 检验比较「惯性观测到的接触力方向」与「几何预测的接触法向」，超阈值即否决几何、膨胀 WCV 球、触发重观测。

**灵感 2（群体智能 · 个体内 → SPB：Swarm Particle Belief 群体粒子信念）**
直觉：第 63 轮 WCV-Geo 用「单个球 B(φ̂,r)」表达 φ 的不确定性——这隐含了**单峰、各向同性、且球心可信**三个假设。OOD 幻觉恰恰制造**多峰**（真接触 vs 幻觉接触）与**错误球心**。群体智能的第一层用法是**个体内的粒子群**：维护 M=64 个 φ 粒子，每粒子是一个独立的「微型假设智能体」，用几何似然、惯性似然、触觉似然加权；粒子间用 PSO 式的局部/全局最优提议做**探索**，用贝叶斯重加权做**利用**。多模态被保留，错误的单峰不会把真解吞掉；φ̂ 与 r 由粒子分布的均值/协方差/支撑集给出，而不是由一个可能幻觉的网络直接给出。

**灵感 3（群体智能 · 个体间 → SSC：Swarm Stigmergic Consensus 信息素群体共识）**
直觉：群体智能的第二层用法是**多智能体之间的去中心化校验与信息素记忆**。① **共识**：N 个智能体各自估计 φ，广播均值/粒子摘要，用**几何中位数**或 Krum 做拜占庭鲁棒聚合（f<N/2 容错）——单体的幻觉在多数诚实智能体下被抑制；② **信息素（stigmergy）**：把 SSB 升级为共享场景银行 SSB-Stig，每个智能体在场景上沉积/蒸发信息素 τ_s，检索分数 = 点云指纹相似度 + λ·log(1+τ_s)。险情场景的信息素被反复加强，冷启动智能体可以直接继承群体经验，而不必各自从零「摸黑」。这正是蚁群式**间接通信**：智能体不直接对话，而是通过改变共享环境（场景银行）协调。

**灵感 4（三灵感合流 → SIRO：Swarm-Inertial Robust Operations 群体-惯性鲁棒操作闭环）**
三者咬合：ICF/IAB 提供**1kHz 时间见证**，把锚点间空白填满，并在几何幻觉时给出独立物理证据；IGW 用惯性证据**否决**坏几何，把「几何置信」变成可检验量；SPB 把单球升级为**多峰粒子信念**，使 P-WCV（粒子 CVaR）在真/假接触并存时不至于用错球心；SSC/BRA 把单机估计升级为**群体鲁棒共识**，用多数诚实智能体压制单体系统性幻觉；SSB-Stig 让场景经验以信息素形式在群体内传播。闭环：IMU 高频传播 → IGW 互证 → 几何置信更新 → SPB 粒子信念 → P-WCV 鲁棒编译 → 技能执行 → 惯性残差/接触事件 → DIR-I 更新 → SSC 共识 + 信息素记账 → AIC-Swarm 集体认证 → J_siro。**第 63 轮是「单机的几何-技能-干扰闭环」，SIRO 是「时间见证 + 群体共识的双重纠错闭环」**。

**灵感 5（组件原位升级）**
- **OLP-Geo → OLP-I**：输入加入惯性特征 u_imu（接触力方向、滑移、加速度残差），x'' = [x'; u_imu]；遗憾界增加 L_imu 项，但 IGW 否决坏几何使有效假设类更干净。
- **WCV-Geo → P-WCV**：搜索域从 B(φ̂,r) 升级为粒子支撑集；CVaR 按粒子权重加权，另给出「支撑覆盖证书」——所有显著模态都必须 margin ≥ 0。
- **DIR → DIR-I**：干扰增强加入 IMU 偏置漂移/饱和/丢帧/振动，并用 ICF 估计的执行器外部力作为 η_act 的**物理标签**，替代第 63 轮的固定噪声幅度。
- **SSB → SSB-Stig**：场景签名加信息素 τ_s 与群体出现计数，Mine/Mut 走共享银行；检索分数融合指纹相似度与信息素。
- **Shield-Skill → Shield-Contact**：前置条件新增「接触状态谓词」（如 grasp_established 由惯性力矩签名验证），幻觉几何不再能单独通过前置检查。
- **AIC → AIC-Swarm**：从单机 ℰ 扩展为群体 ℰ_i 的并/交语义，输出最坏智能体裕度 ρ_dir^S = min_i ρ_dir^i 与集体覆盖率。
- **OCB-Skill → OCB-Swarm**：臂空间加入协调/共享模式（独立/共识/信息素检索），奖励加入通信与协调代价。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（惯性锚点桥漂移界）**：设加速度计偏置有界 ‖b_a‖≤B_a、陀螺偏置 ‖b_g‖≤B_g、噪声有界，则两锚点间 Δt 内预积分位置误差 ‖δp(Δt)‖ ≤ ‖δp_k‖+‖δv_k‖Δt+½B_aΔt²+½‖a‖B_gΔt²+O(σΔt^{3/2})。据此可解析地给出「在漂移预算 ε_anchor 内的最长可桥接时间」，把锚点新鲜度从固定窗口升级为**自适应、可证明的窗口**。
- **引理 6（IGW 幻觉检测界）**：在 H0（几何正确）下 σ_α 已知则 T_ig ~ χ²₂，误报率 ≤ β；在真实角误差为 θ 的 H1 下，检验功效 ≥ 1−β 当 θ ≥ θ_min = (√χ²_{2,1−β}+z_{1−β})·σ_α。即**角误差超过可分辨阈值的几何幻觉以高概率被否决**，为第 63 轮的单点假设提供可量化的证伪能力。
- **定理 4（群体共识压制单体幻觉）**：N 个估计中 f 个拜占庭、诚实估计均在 B(φ*,δ) 内且 f<N/2，则几何中位数聚合满足 ‖φ̄−φ*‖ ≤ δ/(1−2f/N)。当 N=5,f=1 时误差 ≤ 1.67δ——**共识把「任意大的单体幻觉」压缩为「有界偏差」**；但当所有诚实智能体共享同一偏差 δ 时，共识不能消除它（见风险）。
- **定理 5（粒子信念 CVaR 保真）**：若粒子经验分布与真实后验的 W1 距离 ≤ ε_p、损失 L-Lipschitz，则 |CVaR_ε(P_M) − CVaR_ε(P*)| ≤ L·ε_p/(1−ε)；配合支撑覆盖证书（所有 w_i≥w_min 的模态 margin≥0），可避免单球在**多峰幻觉**下「球心错、半径虚胖」的系统性失效。
- **定理 6（集体认证覆盖）**：若各智能体 P[η*∈ℰ_i] ≥ 1−α_i，则无需独立性有 P[∩ℰ_i] ≥ 1−Σα_i（并集界）；若失效独立则 ≥ 1−Πα_i。ρ_dir^S = min_i ρ_dir^i ≥ 0 且覆盖成立 ⇒ 群体安全概率 ≥ 覆盖率。
- **实时性**：1kHz 路径新增 IAB 预积分 0.05ms + ICF 0.05ms + IGW 0.05ms + 粒子矩传播 0.05ms；粒子全域更新与 P-WCV 重采样下放至 100Hz（<0.8ms），1kHz 路径总计 ≤ 1.85ms，仍满足 2ms 契约且零学习写操作。

## 2. 形式化定义（完整版）

**定义 201（SIRO 闭环）** SIRO 是在 LIRO 的「语义流 ∘ 实时流」骨架上增加两条纠错通路的升级：
- **快通道（1kHz）**：IAB 惯性锚点桥 → ICF 接触/外部力观测 → IGW 惯性-几何互证（否决坏几何）→ 粒子矩传播 → OLP-I 前向 + P-WCV 编译 → π_σ1 展开派发。
- **慢通道（10–100Hz）**：SPB 粒子全域更新/重采样 → DIR-I 更新 → SSC 信息素记账 + BRA 群体共识 → CSP 重规划 + Shield-Contact → AIC-Swarm 集体认证 → J_siro 构建。
不变式：学习/聚合/共识只发生在慢通道；快通道零学习写操作，只做前向、预积分、χ² 检验与有界计算。SIRO 不取代 LIRO，二者证书链式组合。

**定义 202（ICF 惯性接触融合）** 输入 IMU 序列 (ω_m, a_m)、关节位置/速度 q,q̇、关节力矩 τ_m。名义动力学：M(q)q̈ + C(q,q̇)q̇ + g(q) = τ_m + τ_ext。动量观测器：
```
p_mom = M(q)q̇
r_obs = K_O·(p_mom − ∫_0^t (τ_m + C q̇ + g − r_obs) dτ)
```
外部力矩估计 τ̂_ext = r_obs，经雅可比映射为末端外部力 ŵ_ext = J^{-T}τ̂_ext，协方差 Σ_w。自由加速度预测 â_free 由名义模型给出；接触事件 e_contact 由马氏距离阈值 γ_c 判定（χ² 分布定标）。切向速度 v_t 与法向力 f_n 给出滑移指示 slip = 𝟙[‖v_t‖ > v_slip ∧ μ̂‖f_n‖ < ‖f_t‖]。ICF 输出 (ŵ_ext, Σ_w, e_contact, slip)，供 IGW、DIR-I、Shield-Contact 使用。

**定义 203（IAB 惯性锚点桥）** 设最近有效锚点为 (t_k, R_k, p_k, v_k)，其后 IMU 缓冲为 [t_k, t]。用预积分增量（含偏置雅可比）传播：
```
R̂(t) = R_k·ΔR(t; b_g),   v̂(t) = v_k + gΔt + R_kΔv(t; b_g, b_a),
p̂(t) = p_k + v_kΔt + ½gΔt² + R_kΔp(t; b_g, b_a)
```
传播协方差 Σ_p(t) 由预积分协方差与偏置随机游走合成。锚点有效条件：
```
age = t − t_k ≤ T_a  ∧  tr(Σ_p(t)) ≤ ε_anchor²  ∧  |b̂_a − b_a,k| ≤ b_max
```
失效则把 OLP-I 的输入标记为 stale，触发低频重观测（LiDAR/RGB 新帧）或降级到保守阻抗 K_baseline。IAB 将锚点新鲜度从固定 Δt_anchor 变为「漂移预算内的最长桥接时间」，实现自适应有效期。

**定义 204（IGW 惯性-几何互证）** 在接触事件 e_contact=1 时，比较惯性接触方向 u_w 与几何接触法向 n_geo。设方向噪声近似各向同性、标准差 σ_α（由 Σ_w 与接触力幅值映射：σ_α ≈ ‖Σ_w^{1/2}‖/‖ŵ_ext‖）。构造检验：
```
T_ig = 2(1 − u_wᵀn_geo)/σ_α²
```
H0（几何正确）下 T_ig ~ χ²₂；拒绝域 T_ig > χ²_{2,1−β}（β=0.05）。若拒绝：
```
geo_valid ← False
r ← min(r_max, γ_inflate·r)            # 膨胀 WCV/P-WCV 球，保守化
trigger_reobserve(geo_hash)             # 请求新帧/新视角
SSB-Stig.deposit(geo_conflict_event)    # 幻觉场景记入共享银行
```
若 T_ig 落在接受域，则 geo_valid←True 且可用贝叶斯因子 Bf = exp(−T_ig/2) 调节 SPB 的几何似然权重（证据越一致，几何权重越高）。IGW 是**只否决、不创造**的见证器——它不能证明几何正确，但能以可控误报率否决与惯性动力学矛盾的几何。

**定义 205（SPB 群体粒子信念）** 粒子集 {(φ^(i), w_i)}_{i=1}^M，M=64，覆盖 φ=(μ_fric, k_stiff, c_damp, m_eff, 接触法向 n, 接触点 p)。
- **预测**：φ^(i) ← φ^(i) + N(0, Q)，Q 由执行器扰动与场景切换率标定。
- **权重更新**：w_i ∝ w_i · L_geo(φ^(i))^{α_geo·s_geo} · L_imu(φ^(i))^{α_imu} · L_tactile(φ^(i))，其中 L_imu 用 ŵ_ext 与 φ^(i) 预测接触力的残差，L_geo 由点云法向/曲率一致性给出，s_geo = 𝟙[geo_valid]。
- **PSO 提议（探索）**：对低权重粒子，以 MCMC 提议核 φ' = φ^(i) + c₁r₁(p_i−φ^(i)) + c₂r₂(g−φ^(i)) + N(0,Q_prop) 生成候选，按 Metropolis–Hastings 比值接受；p_i 为粒子历史最优（局部似然最大），g 为全局最优。PSO 只作为**提议分布**，接受率校正保证目标后验不变（否则会引入优化偏差）。
- **重采样**：ESS = 1/Σw_i² < M/2 时系统重采样，并注入 5% 新鲜粒子防止贫化。
输出：均值 φ̂ = Σw_iφ^(i)、协方差 Σ_φ（用于 r）、加权支撑集（用于 P-WCV）。关键性质：**多峰不塌缩**——真接触与幻觉接触可各占一个模态，证据更新后假模态权重自然下降，而不是被单高斯球强行平均。

**定义 206（P-WCV 粒子鲁棒编译）** 给定粒子信念 P_M、OLP-I 投影 K、ERTC 约束：
```
for j = 1..n_worst:                      # n_worst=8，按权重分层采样
    φ_j ~ P_M (systematic resampling by w)
    K_c,j = eeis.compile_with_phys_constraint(OLP_I.project(x''), φ_j)
    ℓ_j = execution_loss(K_c,j, φ_j); m_j = safety_margin(K_c,j, φ_j)
tail = {j: 累计权重 ∈ [1−ε, 1]}           # 最坏 ε 尾部（按 ℓ_j 排序累计权重）
CVaR_ε = (1/(1−ε))·Σ_{j∈tail} w_j·ℓ_j
ρ_rob = min_{i: w_i ≥ w_min} m_i          # 支撑覆盖证书，w_min=ε/2
K_safe = intersect_shrink({K_c,j: j∈tail})
```
与 WCV-Geo 的差别：① 最坏参数不是球内均匀采样，而是按**信念权重**采样（更可能命中真实模态）；② 证书要求所有显著模态（w_i≥w_min）安全，而非仅尾部平均；③ 当信念多峰时，`K_safe` 取尾部交集，天然保守，避免「错误球心 + 虚胖半径」下的假安全。

**定义 207（SSC 信息素群体共识）** N 个智能体各自维护场景银行与本地信念。SSC 两个动作：
- **信息素沉积/蒸发**：每次险情或成功执行，智能体 i 对场景 s 沉积 Δτ_{i,s} = η_dep·utility_i（utility 可为负，表示失败）；全局（或经 gossip 同步的）信息素更新
```
τ_s(t+1) = (1−ρ_evap)·τ_s(t) + Σ_{i∈𝒩_s(t)} Δτ_{i,s}(t),   ρ_evap ∈ (0,1)
```
- **检索**：候选场景按 score(s) = 𝟙[Hamming(fp,fp_s)<8] + λ_τ·log(1+τ_s) 排序；指纹匹配负责「是不是同一几何」，信息素负责「这个几何历史上危不危险」。
信息素是**间接通信**：智能体不直接交换策略，只改变共享环境（场景银行）的标量场，后来者据此协调。为防止拜占庭/投毒，沉积量先经本地中位数裁剪（Δτ ∈ [−q_{0.9}, q_{0.9}]）。

**定义 208（BRA 拜占庭鲁棒聚合）** 每智能体 i 广播估计 φ_i（或粒子摘要：均值+若干分位数，降低带宽）。聚合器：
```
φ̄ = argmin_y Σ_i ‖y − φ_i‖₂        # 几何中位数，Weiszfeld 迭代
```
或 Krum：选择与最近 N−f−2 个邻居距离和最小的 φ_i。容错条件 N ≥ 2f+1。误差界：若至少 N−f 个诚实估计落在 B(φ*,δ)，则 ‖φ̄−φ*‖ ≤ δ/(1−2f/N)（见定理 4）。BRA 只解决「少数任意偏离」；若诚实智能体本身共享偏差，BRA 会忠实放大它（见风险）。

**定义 209（DIR-I 惯性增强干扰不变表征）** 在 DIR 的 Aug_dir 基础上增加惯性类干扰：
- 陀螺/加计偏置漂移（随机游走，幅值 ≤ b_drift）；
- 饱和（±a_sat）与量化；
- 随机丢帧（p_drop）；
- 高频振动（正弦叠加，幅值 a_vib）。
因果正则扩展为 ℒ_causal-I = ‖∂ŷ/∂η_imu‖²，η_imu=(b_drift, a_vib, p_drop, a_sat)。关键升级：η_act 不再用固定噪声幅度，而由 ICF 的 η̂_act = ŵ_ext − ŵ_model 提供**物理标签**，使 DIR-I 学到的是「真实执行器扰动分布」而非人工假设。总损失 ℒ_dir-I = ℒ_con + λ_causal·ℒ_causal-I。

**定义 210（AIC-Swarm 集体认证）** 每个智能体 i 用第 63 轮 AIC 校准 ℰ_i = ℰ_sens,i × ℰ_act,i × ℰ_adv,i × ℰ_ood,i，并计算 ρ_dir^i(τ)。群体层面：
```
ρ_dir^S(τ) = min_i ρ_dir^i(τ)          # 最坏智能体裕度（保守）
集体覆盖：P[∩_i {η* ∈ ℰ_i}] ≥ 1 − Σ_i α_i     （并集界，无需独立）
         若失效独立：≥ 1 − Π_i α_i
```
J_dir^S = (ρ_dir^S, {ℰ_i}, {α_i}, corr_est, cert_hash)。`corr_est` 记录智能体间失效相关系数估计：当 corr_est > ρ_corr^max 时，系统**拒绝签发集体证书**，退回逐智能体最坏值并降低覆盖率声明（防止回声室式虚假信心）。

**定义 211（OCB-Swarm 群体预算调度）** 臂 = USL_模式 × MEL_模式 × 协调模式，其中协调模式 ∈ {independent, consensus, stigmergy}，K=4×4×3=48，按运行预算聚合为 K=24。奖励：
```
r_t = progress_t − κ_c·compute_cost_t − κ_com·comm_cost_t
      − κ_lat·consensus_delay_t − κ_sw·𝟙[σ_t ≠ σ_{t−1}]
```
延迟反馈（共识结果晚到）用 EXP3 的重要性加权校正：r̂_t = r_t / p_t，p_t = w_{a_t}/Σw。硬降级规则继承 PCE：协调模式不得超过当前通信/算力允许的上界。

**定义 212（J_siro 扩展证书）** J_siro = (J_liro, geo_witness_ok, imu_drift, particle_ver, consensus_hash, pheromone_ver, swarm_id, ρ_dir^S)。验证规则：
```
Valid(J_siro) ⇔ Valid(J_liro)
              ∧ geo_witness_ok            # 最近 T_ig 未被连续拒绝
              ∧ imu_drift ≤ ε_anchor      # IAB 漂移在预算内
              ∧ particle_ver ≥ curr_ver−2 # 粒子信念新鲜
              ∧ consensus_hash 与群体一致
              ∧ ρ_dir^S ≥ 0
```
审计链新增：geo_witness_ok 追溯 IGW 判定，imu_drift 追溯 IAB 预积分，particle_ver 追溯 SPB 重采样代数，consensus_hash 追溯 BRA 聚合输入，pheromone_ver 追溯 SSB-Stig 信息素版本。

**定义 213（SSB-Stig 信息素场景签名）** scene_sig = (V_sig, T_sig, fp_cloud, φ_sig, dyn_annot, τ_pher, swarm_count)。Mine 优先按 fp_cloud 匹配（汉明距离<8），命中后叠加信息素检索排序；Mut 继承第 63 轮几何变异（拓扑/FFD/接触面翻转），新增「惯性变异」：接触力方向扰动、摩擦锥缩放、外部力脉冲，用于生成对 IGW 有挑战的场景。

**定义 214（惯性扰动观测器）** η̂_act = ŵ_ext − ŵ_model；其低频分量解释为负载/摩擦变化，高频分量解释为碰撞/振动。滑移指示 slip 与 η̂_act 一起写入 EV_exec，作为 DIR-I 标签、Shield-Contact 触发条件与 SSB-Stig 的 dyn_annot。

**定义 215（共享技能迁移 CSL）** 技能 σ 从本体 A 迁移到 B 的可迁移性：
```
mig(σ; A→B) = 𝟙[eff_σ 在 B 上语义保持 ∧ ∀φ∈B(φ̂_B,r_B): scale_{A→B}(π_σ) ∈ 𝒫_feas(B)]
```
scale 只缩放阻抗包络（刚度/阻尼的物理量纲），不改变技能谓词结构。CSP 在跨本体规划时把 mig 作为硬约束；不满足则回退到「技能发现」（从演示中挖掘新技能，lineage 记账）。

**定义 216（群体故障模型）** 诚实智能体估计落在 B(φ*,δ)；拜占庭智能体可任意偏离且可伪造信息素；共同先验导致的相关性故障用相关系数 ρ_corr 记账。该模型显式区分「独立随机故障」（BRA/并集界可处理）与「共同系统性故障」（需要异构先验或外部真值才能处理），避免把前者的定理错误地套用到后者。

### IP-204 ICF（惯性接触融合）

```python
class InertialContactFusion:
    """1kHz：IMU + 关节力矩 → 外部力估计、接触事件、滑移。"""
    def __init__(self, K_O=50.0, gamma_c=9.21, v_slip=0.02):
        self.K_O, self.gamma_c, self.v_slip = K_O, gamma_c, v_slip
        self.r_obs = np.zeros(6)
        self.Sigma_w = np.eye(6) * 1e-4

    def momentum_observer(self, q, dq, tau_m, dt, dyn):
        M = dyn.mass_matrix(q)
        C = dyn.coriolis(q, dq)
        g = dyn.gravity(q)
        p_mom = M @ dq
        self.r_obs += self.K_O * (p_mom - self.r_obs - (tau_m + C @ dq + g)) * dt
        tau_ext = self.r_obs
        J = dyn.jacobian(q)
        w_ext = np.linalg.pinv(J.T) @ tau_ext
        self.Sigma_w = dyn.jacobian_cov(q) * 1e-4 + np.eye(6) * 1e-6
        return w_ext, self.Sigma_w

    def contact_event(self, a_m, a_free, Sigma_a):
        d = a_m - a_free
        return float(d @ np.linalg.solve(Sigma_a, d)) > self.gamma_c

    def slip_indicator(self, v_t, f_n, f_t, mu_hat):
        return (np.linalg.norm(v_t) > self.v_slip) and (mu_hat * abs(f_n) < np.linalg.norm(f_t))
```

```python
class InertialAnchorBridge:
    """用 IMU 预积分在低频锚点之间传播位姿，给出有界漂移与有效期。"""
    def __init__(self, T_a=0.5, eps_anchor=0.01, b_max=0.05):

        Sigma_p = anchor.Sigma_p.copy()
        b_a, b_g = anchor.b_a, anchor.b_g

        drift_ok = (age <= self.T_a) and (np.trace(Sigma_p) <= self.eps_anchor**2)
        bias_ok = np.linalg.norm(b_a - anchor.b_a) <= self.b_max
        return State(R=R, p=p, v=v, Sigma_p=Sigma_p,
                     valid=drift_ok and bias_ok, age=age)
```

```python
class InertialGeometricWitness:
    """χ² 互证：惯性接触方向 vs 几何接触法向。只否决，不创造。"""
    def __init__(self, beta=0.05, gamma_inflate=1.5, r_max=0.5):
        self.thresh = chi2.ppf(1 - beta, df=2)
        self.gamma_inflate, self.r_max = gamma_inflate, r_max
        self.consecutive_reject = 0

    def check(self, w_ext, Sigma_w, n_geo, r, active):
        if not active or np.linalg.norm(w_ext) < 1e-3:
            return True, r, 1.0
        u_w = w_ext / np.linalg.norm(w_ext)
        sigma_alpha = max(np.linalg.norm(sqrtm(Sigma_w)) / np.linalg.norm(w_ext), 1e-3)
        T_ig = 2.0 * (1.0 - float(u_w @ n_geo)) / (sigma_alpha**2)
        if T_ig > self.thresh:
            self.consecutive_reject += 1
            r_new = min(self.r_max, self.gamma_inflate * r)
            return False, r_new, math.exp(-0.5 * T_ig)
        self.consecutive_reject = 0
        return True, r, math.exp(-0.5 * T_ig)
```

```python
class SwarmParticleBelief:
    """φ 的多峰粒子信念：PSO 提议 + 贝叶斯重加权 + ESS 重采样。"""
    def __init__(self, M=64, Q_scale=0.02, w_min=0.025, c1=0.5, c2=0.5):
        self.M, self.Q_scale, self.w_min = M, Q_scale, w_min
        self.phi = sample_prior(M)
        self.w = np.ones(M) / M
        self.pbest = self.phi.copy()
        self.pbest_val = np.full(M, -np.inf)
        self.gbest = self.phi[np.argmax(self.w)]

    def moment_update(self, w_ext):          # 1kHz 只做矩传播（昂贵更新下放 100Hz）
        self.phi += np.random.normal(0, self.Q_scale, self.phi.shape)

    def full_update(self, L_geo, L_imu, L_tactile, geo_valid, s_geo):
        alpha_geo = 1.0 if geo_valid else 0.0
        loglik = (alpha_geo * np.log(L_geo + 1e-12)
                  + np.log(L_imu + 1e-12) + np.log(L_tactile + 1e-12))
        self.w *= np.exp(loglik - loglik.max())
        self.w /= self.w.sum()
        # PSO 提议（接受率校正，保持后验不变）
        for i in range(self.M):
            prop = (self.phi[i] + self.c1*np.random.rand()*(self.pbest[i]-self.phi[i])
                    + self.c2*np.random.rand()*(self.gbest-self.phi[i])
                    + np.random.normal(0, self.Q_scale, self.phi.shape[1]))
            ll_prop = self._loglik(prop, L_geo, L_imu, L_tactile)
            ll_cur = self._loglik(self.phi[i], L_geo, L_imu, L_tactile)
            if np.log(np.random.rand()) < ll_prop - ll_cur:
                self.phi[i] = prop
        # 更新局部/全局最优
        vals = self._loglik_batch(self.phi, L_geo, L_imu, L_tactile)
        improve = vals > self.pbest_val
        self.pbest[improve], self.pbest_val[improve] = self.phi[improve], vals[improve]
        self.gbest = self.phi[np.argmax(vals)]
        if self.ess() < self.M / 2:
            self._systematic_resample()
        return self.mean(), self.cov()

    def ess(self):
        return 1.0 / np.sum(self.w**2)

    def significant(self):
        return self.phi[self.w >= self.w_min]
```

```python
def p_wcv_compile(olp_i, x_prime, belief, eeis, eps=0.05, n_worst=8, r_max=0.5):

    cand = []

        phi_j = belief.phi[j]
        K = olp_i.project(x_prime)
        K_c = eeis.compile_with_phys_constraint(K, phi_j)
        cand.append((phi_j, K_c, safety_margin(K_c, phi_j),
                     execution_loss_estimate(K_c, phi_j), belief.w[j]))
    cand.sort(key=lambda z: z[3], reverse=True)
    # 质量加权尾部
    cum, tail = 0.0, []
    for c in cand:
        tail.append(c); cum += c[4]
        if cum >= 1 - eps:
            break
    K_safe = intersect_shrink([c[1] for c in tail])

    cvar = sum(c[4] * c[3] for c in tail) / max(cum, 1e-9)
    return K_safe, rho_rob, cvar, (len(sig) == 0)
```

```python
def geometric_median(points, iters=100, tol=1e-6):
    y = points.mean(axis=0)
    for _ in range(iters):
        d = np.linalg.norm(points - y, axis=1) + 1e-12
        w = 1.0 / d
        y_new = (points * w[:, None]).sum(0) / w.sum()
        if np.linalg.norm(y_new - y) < tol:
            return y_new
        y = y_new
    return y

class SwarmStigmergicConsensus:
    def __init__(self, rho_evap=0.02, lambda_tau=0.5, clip_q=0.9):

        self.pheromone = defaultdict(float)

        self.pheromone[scene_id] += delta
        self.versions[scene_id] = self.versions.get(scene_id, 0) + 1

    def evaporate(self):
        for s in list(self.pheromone):
            self.pheromone[s] *= (1 - self.rho_evap)
            if abs(self.pheromone[s]) < 1e-4:
                del self.pheromone[s]

        score = lambda s: 1.0 + self.lambda_tau * np.log1p(max(0.0, self.pheromone.get(s.id, 0.0)))
        return sorted(cands, key=score, reverse=True)[:topk]

    def consensus(self, phi_list, f_max, N):
        assert N >= 2 * f_max + 1, "BRA 容错条件不满足"
```

## 4. 推导

**引理 5（惯性锚点桥漂移界）** 设两锚点间时长 Δt，加计偏置 ‖b_a‖≤B_a、陀螺偏置 ‖b_g‖≤B_g、加计白噪声标准差 σ_a、陀螺白噪声 σ_g。预积分位置误差由偏置项与噪声项组成：
```
δp(Δt) = δp_k + δv_kΔt + ½(R[a]_×)δθ Δt² + ½ b_a Δt² + 噪声积分
       ⇒ ‖δp(Δt)‖ ≤ ‖δp_k‖ + ‖δv_k‖Δt + ½B_aΔt² + ½‖a‖B_gΔt² + C(σ_aΔt^{3/2} + ‖a‖σ_gΔt^{3/2})
```
其中 δθ 为姿态误差，满足 ‖δθ‖ ≤ B_gΔt + σ_g√Δt。因此给定漂移预算 ε_anchor，可解出最长桥接时间 T*(ε_anchor)：
```
T* = max{Δt: 上式右端 ≤ ε_anchor}
```
IAB 只在 age ≤ min(T_a, T*) 时把锚点标记为 valid。∎

**引理 6（IGW 幻觉检测界）** H0 下 n_geo 正确，方向残差 α=arccos(u_wᵀn_geo) 由噪声主导，σ_α 已知，则 T_ig=2(1−cosα)/σ_α² ≈ (α/σ_α)² ~ χ²₂，故误报率 P[T_ig>χ²_{2,1−β}] ≤ β。H1 下真实角误差 θ，则 T_ig 服从非中心 χ²₂，非中心参数 λ=θ²/σ_α²。用标准非中心 χ² 尾界，检验功效 ≥1−β 当
```
θ ≥ θ_min = (√χ²_{2,1−β} + z_{1−β})·σ_α
```
即角误差超过 θ_min 的几何幻觉以至少 1−β 概率被否决。∎

**定理 4（群体共识压制单体幻觉）** 设 N 个估计中 f 个拜占庭（可任意偏离），N−f 个诚实估计落在 B(φ*,δ)，f<N/2，φ̄ 为几何中位数。记 r=‖φ̄−φ*‖，u=−(φ̄−φ*)/r。几何中位数的次梯度最优性给出沿 u 的方向导数非负：
```
0 ≤ D_u F(φ̄) = Σ_i (φ̄−φ_i)ᵀu / ‖φ̄−φ_i‖
```
对诚实项，因 ‖φ_i−φ*‖≤δ<r，有 (φ̄−φ_i)ᵀu = (−r² + (φ_i−φ*)ᵀφ̄ ... ) ≤ −(r−δ)（归一化前）；归一化后每项 ≤ −(r−δ)/(r+δ)。对拜占庭项每项 ≤ 1。于是
```
0 ≤ (N−f)·(−(r−δ)/(r+δ)) + f
⇒ (N−f)(r−δ) ≤ f(r+δ)
⇒ r(N−2f) ≤ Nδ
⇒ r ≤ δ/(1−2f/N)
```
当 N=5,f=1 时 r ≤ 5δ/3 ≈ 1.67δ。∎

**定理 5（粒子信念 CVaR 保真）** 设损失 ℓ(φ) 为 L-Lipschitz，粒子经验分布 P_M 与真实后验 P* 的 Wasserstein-1 距离 ≤ ε_p。CVaR_ε 作为分布泛函对 W1 的 Lipschitz 常数为 L/(1−ε)（由 CVaR 的对偶表示与 KR 对偶可得）：
```
|CVaR_ε(P_M) − CVaR_ε(P*)| ≤ L·ε_p/(1−ε)
```
故当 ε_p→0 时粒子 CVaR 收敛到真实尾部风险。支撑覆盖证书进一步要求所有 w_i≥ε/2 的模态 margin≥0；若真实 φ 落在某个显著模态，则该模态安全 ⇒ 真实参数安全。相较于单球：多峰时单球必须膨胀到覆盖所有模态（r 虚胖、保守），或收缩到单模态（漏掉真解、假安全），而粒子信念同时保留多模态并逐模态验证。∎

**定理 6（集体认证覆盖）** 令 E_i={η*∈ℰ_i}。由测度次可加性（并集界），无需独立性：
```
P[∩_i E_i] = 1 − P[∪_i E_i^c] ≥ 1 − Σ_i P[E_i^c] ≥ 1 − Σ_i α_i
```
若各 E_i 相互独立，则 P[∩E_i]=Π_i P[E_i] ≥ Π_i(1−α_i) = 1−Πα_i（当 α_i 同 =α 时为 1−α^N）。ρ_dir^S=min_i ρ_dir^i≥0 且覆盖成立 ⇒ 对所有 i 的干扰 η* 均安全。注意：独立性是**附加假设**，若 corr_est 高则退回并集界并拒绝集体证书。∎

**命题（信息素检索增益）** 设冷启动智能体无本地场景统计。纯指纹检索的召回受限于几何相似但语义不同（如相同形状不同摩擦）的场景；信息素 τ_s 编码了群体历史危情/成功，检索分数加入 λ_τlog(1+τ_s) 后，对「历史上危险但指纹相似」的场景排序提升。设危情场景信息素稳态 τ* = Δτ/ρ_evap，则排序间隔为 λ_τlog(1+τ*)，冷启动误入危险场景率随 τ* 单调下降。经验上（E226）冷启动识别 F1 提升 ≥20%。∎

**命题（IGW 的适用边界）** IGW 只能观测**与惯性动力学耦合**的几何量（接触法向、接触点、法向力、滑移）；对切向摩擦系数 μ、表面材质、非接触区域的拓扑幻觉，惯性通道不可观测或弱可观测。因此 IGW 不是万能证伪器，它精确地补上了「接触几何」这一最关键、也最易被 LiDAR 幻觉破坏的维度。∎

1. **几何幻觉可证伪**：接触几何幻觉在角误差 > θ_min 时以 ≥1−β 概率被 IGW 否决，WCV/P-WCV 球膨胀、触发重观测（引理 6）——第 63 轮的单点假设被打破。

## 7. 已知风险

**一句话（本轮最大风险）**：若所有智能体共享同一预训练几何先验、同一仿真域与同一环境结构，则 IGW 的「独立见证」与 SSC 的「多数共识」会退化为**相关失效/回声室**——群体不是纠正而是放大同一个幻觉，J_siro 的覆盖证明所依赖的独立性假设崩塌，这比单体幻觉更危险，因为它附带「集体已校验」的虚假信心。

**次级风险与缓解**：
1. **共同先验导致相关失效**：异构化——LiDAR/深度/触觉/不同厂家 IMU 各自独立建模；保留一个「红队智能体」使用刻意不同的先验；AIC-Swarm 显式估计 corr_est，超阈值拒绝集体证书并退回逐智能体最坏值。
2. **IMU 自身漂移/饱和/振动**：偏置在线估计 + IAB 漂移预算触发重锚定；IMU 失效时 ICF 退化为关节力矩观测器，IGW 置信度下调，证书标记 imu_degraded。
3. **IGW 误否决（未建模载荷/柔性物体）**：接触模型在线辨识，Σ_w 自适应膨胀；连续误否决时降级为「几何软证据」而非硬否决，并请求人类确认。
4. **粒子贫化/维数灾难**：M=64 在 6–8 维 φ 上可行；更高维时按接触模态分组粒子（分层 SPB），或改用条件粒子滤波；KLD 自适应调整 M。
5. **共识通信延迟/分区**：异步 gossip + 版本向量；分区时使用本地信念并标记 consensus_stale，不签发集体证书。
6. **信息素投毒**：沉积裁剪 + 信誉加权 + 蒸发；异常信息素模式触发审计，隔离来源智能体。
7. **实时预算超支**：SPB 全域更新与 P-WCV 重采样固定在 100Hz；1kHz 路径只做预积分、χ² 与矩传播；超时则用缓存粒子集与保守 K_baseline。
8. **IGW 可观测性边界**：切向摩擦/材质/非接触拓扑对惯性不可观测；这些维度仍依赖 DIR-I 与几何先验，证书应显式标注 `igw_observable_dims`，避免过度声明。
