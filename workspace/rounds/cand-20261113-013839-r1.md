# 第 65 轮（承接第 64 轮「GLIDE：深度相机 × 步态-操作联合 × 低成本」想法区；灵感循环 II 第 4 轮；本轮灵感：「强化学习训练」×「痛点分析」）

> 第 64 轮 GLIDE 用深度相机替代 LiDAR，并以不确定性 Σ_g 显式量化几何质量，但它自述的最大风险是：**在相干错误深度（强光/透明/镜面/运动模糊）下，Σ_g 会系统性低估**，从而 WCV-Depth 欠膨胀、CSP-Mixed 在错误几何上规划、DIR-Depth 在错误干净视图上对比。把视野再拉高一层：GLIDE/LIRO 的鲁棒性仍压在一批**手工单点假设**（A77–A82）上，这些假设的失效模式没有被系统性地「发现—排序—修复」；同时，技能策略、信任判断、不确定性校准仍以离线监督/规则为主，缺少一个**以痛点为导向、可持续自我改进的强化学习训练闭环**。本轮用「痛点分析」补上「发现与排序」，用「强化学习训练」补上「修复与验证」。

## 0. 直觉与动机

**灵感 1（痛点分析 → PPM/PPG：痛点挖掘器 + 痛点因果图）**
直觉：工程上真正昂贵的不是「又加一个模块」，而是**不知道当前系统最该修哪里**。把执行证据（EV_exec、SSB 险情、DIR 漂移、AIC 裕度、深度校准 gap、人类纠正）统一成事件流，PPM 把事件归因为**可干预的因果因子**（而非日志里的表面症状）：每个痛点 p = (组件 c, 症状 s, 根因假设 h, 频次 f, 严重度 σ, 可检测性 d, 修复成本 κ)，必须对应一个 do(fix_p) 干预。用 SSB-Pain 的反事实重放估计平均处理效应 ATE(h)=E[Y|do(h=1)]−E[Y|do(h=0)]，只保留 ATE 显著且机制可信的痛点。PPG 把痛点连成因果 DAG（修 p 会改变 q 的频次则有边 p→q），按「风险 × 下游影响 / 修复成本」排序，挑出**根痛点**而非症状。**关键洞见**：先做痛点归因，再决定训练什么，避免把算力浪费在「看起来吓人但修了没用」的症状上。

**灵感 2（强化学习训练 → PACT：痛点靶向课程 RL 训练器）**
直觉：固定训练分布（无论仿真随机化还是离线数据）无法覆盖「当前策略最脆弱的那一小撮场景」。把训练分布做成**由痛点实时生成的课程**：μ_θ = (1−ε_t)·μ_base + ε_t·Σ_{p∈P_root} w_p·μ_p，其中 μ_p 是能诱发痛点 p 的场景分布（SSB-Depth 几何变异 + 深度退化 + 步态/接触扰动），w_p ∝ R(p)。训练用**约束 MDP + PPO-Lagrangian**（安全进约束、任务进奖励，避免大权重把安全塞进奖励造成尺度病态），并加三个训练技巧：① **特权教师-学生蒸馏**（教师看真值 φ*/干净深度，学生看真实噪声观测，缩小 sim-to-real 差距）；② **痛点优先经验回放**（按痛点复发率 × TD 误差 × 稀有度加权采样）；③ **对抗自博弈课程**（对手 π_adv 专门生成当前策略最弱痛点对应的干扰，形成自动加难的 minimax 课程）。**关键洞见**：训练不是「一次性把策略练好」，而是「让训练分布追着痛点跑」。

**灵感 3（直击第 64 轮风险 → TRP + URC：信任策略 + 不确定性重校准）**
直觉：第 64 轮的根问题是「无条件相信 Σ_g」。两步修复：① **URC 不确定性重校准**：在留出的痛点验证集上学习尺度 s_ψ(O)，用**保形预测（conformal prediction）**给出 Σ̃_g = s_ψ(O)·Σ_g 与分位数 q_{1−α}，使 P[误差 ≤ q_{1−α}·‖Σ̃_g‖] ≥ 1−α——**把「系统性低估」变成一个可认证的覆盖率问题**；② **TRP 信任策略**：π_trust(x', Σ_g, 校准特征, 痛点上下文) → {trust, recalibrate, fallback, ask}，由 RL 训练，奖励同时惩罚「过度信任」（安全违规）与「过度不信任」（任务失败/频繁求助）。于是「几何先验」不再是非黑即白的单点假设，而是一个**可学习、可校准、可降级**的决策变量。

**灵感 4（三灵感合流 → PACT：Pain-point-Aware Curriculum Training 闭环）**
三者咬合：PPM/PPG 负责**发现与排序**（修哪里）；CPT/ASPC/LPPO/PST/PPR 负责**修复与训练**（怎么修）；URC/TRP 负责**把修复固化为可认证的在线决策**（修完怎么信）。闭环：部署 GLIDE → 证据流 → PPM 归因 → PPG 排序 → CPT 生成痛点课程 → LPPO+ASPC+PST+PPR 训练技能/信任/恢复策略 → URC 校准 → 重新部署 → 新证据。**第 63/64 轮是「设计更强的闭环」，PACT 是「让闭环自己找到并修补自己的痛点」——从 hand-crafted robustness 走向 evidence-driven self-improvement**。

**灵感 5（GLIDE 组件的原位升级）**
- **SSB-Depth → SSB-Pain**：场景签名增入 `pain_tag`（该场景历史触发的痛点 id 集合），Mine 优先返回带痛点标签的场景，供 PPM 反事实重放。
- **AIC-Depth → AIC-Pain**：认证输出增入 `calibration_gap`（预测 Σ_g 与实测误差的分布差）与 `trust_decision`，证书要求 gap 在保形界内。
- **WCV-Depth → WCV-Trust**：球半径由 TRP 的信任动作选择 γ_geo(g,Σ_g) / γ_geo(g,Σ̃_g) / 非几何回退。
- **OCB-Mixed → OCB-Train**：部署期臂不变；训练期新增 `training_mode` 臂（是否启用 ASPC/PPR/PST），由 RBA 以「单位算力的痛点下降」为奖励调度。
- **CSP-Mixed → CSP-Recover**：规划器在序列末端可选挂载 π_rec 恢复原语，保证信任降级/安全触发时有显式退路。

## 1. 形式化定义（增量：定义 219–236）

- **定义 219（PACT 闭环）**：PACT = (GLIDE, PPM, PPG, CPT, ASPC, LPPO, PST, PPR, URC, TRP, π_rec, RBA, J_pact)。语义层（低频）执行 [证据采集 → PPM 归因 → PPG 排序 → CPT 课程生成 → LPPO+ASPC+PST+PPR 训练 → URC 校准 → 证书更新]；部署层继承 GLIDE 的语义流/实时流，实时流**只多一次 TRP 前向（<0.1ms）**，零训练写操作。

- **定义 220（痛点 Pain Point）**：p = (c, s, h, f, σ_sev, d, κ, 𝒱_p)。c 组件，s 可观测症状，h 可干预根因假设（对应 do(h) 操作），f 频次（单位千步），σ_sev ∈ [0,1] 严重度，d ∈ [0,1] 可检测性，κ 归一化修复成本，𝒱_p 验证谓词（修复后症状应消失）。痛点必须满足**可干预性**：存在 do(h) 使 𝒱_p 可被检验。

- **定义 221（PPM 痛点挖掘器）**：输入证据流 EV = {EV_exec, SSB incidents, DIR drift, AIC margin, calibration gap, human corrections}。对每个候选干预 h_i，用 SSB-Pain 的反事实重放估计 ATE_i = E[Y|do(h_i=1)] − E[Y|do(h_i=0)]，Y 为综合失效指标（安全违规 + 任务失败 + 认证失效）。归因分数 a_i = |ATE_i|·plaus_i·(1−cost_i)，plaus_i 为机制可信度（专家规则/因果图约束）。PPM 输出痛点集 P = {p_i: |ATE_i| ≥ τ_ate, a_i ≥ τ_a}，并给每个事件分配 argmax_i a_i。

- **定义 222（PPG 痛点因果图与排序）**：PPG = (V_p, E_p) 为 DAG，边 p→q 当且仅当 do(fix_p) 使 q 的频次改变 |Δf_q| ≥ τ_edge。下游影响 downstream(p) = Σ_{q∈Reach(p)} |ATE(p→q)|。风险排序 R(p) = [f_p·σ_sev_p·(1−d_p)·(1+β·downstream(p))] / (κ_p+ε)。根痛点集 P_root = {p: R(p) 位于前 k，且无前驱 q 满足 R(q) ≥ R(p)}。训练只对 P_root 分配预算。

- **定义 223（CPT 痛点课程）**：训练分布 μ_θ = (1−ε_t)·μ_base + ε_t·Σ_{p∈P_root} w_p·μ_p，w_p = R(p)/ΣR。μ_p 由 SSB-Pain 变异生成：几何变异 + 深度退化（定义 217）+ 步态/接触扰动 + 任务上下文重采样。课程温度 ε_t = clip(ε_0 + η_ε·(1−SR_t), ε_min, ε_max)，SR_t 为最近窗口任务成功率；目标把 SR 维持在**学习前沿** [0.6, 0.8]。

- **定义 224（ASPC 对抗自博弈课程）**：对手 π_adv: (x', Σ_g, p) → η ∈ ℰ_p 在痛点 p 对应的干扰集内最大化当前策略失效。训练目标为两人零和：min_π max_{π_adv} E_{s~μ_θ, η~π_adv}[J(π, η)]。对手用 PGD/RL 交替更新（每 N 个策略步更新一次）。**自动加难**：当 π 在 p 上复发率 < δ_adv，π_adv 转向下一个痛点；否则在 ℰ_p 边界内加深干扰强度。

- **定义 225（训练 CMDP）**：M_train = (S, A, P, r, c, γ, d)。状态 s = (x', φ̂, r, Σ_g, p_ctx, history)；动作 a = (θ_skill, a_trust ∈ {trust, recalibrate, fallback, ask}, a_rec ∈ {none, π_rec})；奖励 r = progress − λ_pain·1[pain_recurred] − λ_compute·compute − λ_ask·1[ask]；代价 c = safety_violation（ERTC/ZMP/力锥/关节限位）；约束 E_π[Σ_t c_t] ≤ d（d=0.01/千步）。**安全进约束、任务进奖励**，避免大权重把安全塞进奖励导致的尺度病态。

- **定义 226（LPPO 拉格朗日 PPO）**：求解 max_π E[r] s.t. E[c] ≤ d。拉格朗日 L(π,λ)=E[r]−λ(E[c]−d)。策略用 PPO clipped objective 更新；乘子 λ ← max(0, λ + η_λ·(Ê[c]−d))。维护滑动上界 λ_max 防止训练早期过度保守；策略每 K 步更新、λ 每步更新（交替）。

- **定义 227（PST 特权教师-学生蒸馏）**：教师 π_T(a|s, φ*, D*, G*) 可见真值物理参数 φ*、干净深度 D*、完整几何 G*；学生 π_S(a|s) 只见真实观测。L_PST = E[KL(π_T(·|s,·) || π_S(·|s))] + L_task。教师仅在训练期存在（非对称 actor-critic），部署仅学生。**作用**：降低 sim-to-real 与深度噪声导致的方差。

- **定义 228（PPR 痛点优先回放）**：样本 i 的优先级 pri_i = (1+f_pain(i))^α·(1+|δ_i|)^β·(1+rarity(i))^γ，采样概率 p_i = pri_i/Σ_j pri_j。f_pain 为该样本关联的痛点频次，δ_i 为 TD 误差，rarity 为场景簇逆频率。**作用**：把梯度预算集中到「稀有且高痛点」的样本。

- **定义 229（URC 保形不确定性重校准）**：在留出校准集 D_cal（覆盖 P_root 痛点场景）上计算非一致性分数 e_i = ‖d_err_i‖/(‖Σ_g,i‖_F+ε)，取保形分位数 q_{1−α}=Quantile_{1−α}({e_i})。部署输出 Σ̃_g = q_{1−α}·Σ_g（或先学尺度 s_ψ(O) 再保形校准）。在可交换性下保证 P[‖d_err‖ ≤ q_{1−α}·‖Σ_g‖_F] ≥ 1−α。**直接修复第 64 轮 Σ_g 系统性低估**。

- **定义 230（TRP 信任策略）**：π_trust: (x', Σ_g, calib_features, p_ctx) → a_trust ∈ {trust, recalibrate, fallback, ask}。语义：trust → r_0=r_base·γ_geo(g,Σ_g)；recalibrate → r_0=r_base·γ_geo(g,Σ̃_g)；fallback → 走第 62 轮 ROSE 非几何路径（J 标记 geo_degraded）；ask → 请求多视角/人类澄清（有延迟与人力代价）。奖励 r_trust = task_progress − λ_over·1[过度信任致违规] − λ_under·1[不必要降级/求助] − λ_lat·delay。

- **定义 231（π_rec 恢复策略）**：π_rec: (s, trigger) → {safe_idle, retreat, re_approach, re_grasp}。触发：TRP=fallback/ask、ρ_rob < 0、AIC 证书失效。奖励 r_rec = recovery_success − λ_t·time − λ_c·residual_cost。作为 CSP-Recover 的末端可选原语。

- **定义 232（RBA 训练预算分配器）**：臂 = P_root × {curriculum_only, +ASPC, +PST, +PPR, full}，K=|P_root|×5。奖励 = ΔPain_p/compute（单位算力的痛点风险下降）。EXP3/UCB 非平稳调度，每轮训练后重估 ΔPain。硬规则：单痛点预算占比 ≤ 40%，防止课程坍缩。

- **定义 233（J_pact 证书）**：J_pact = (J_glide, pain_coverage, calibration_gap, curriculum_ver, trust_ver, λ_lagrange, rba_ver, training_hash)。pain_coverage = 1 − Σ_{p∉Cov} R(p)/Σ_p R(p)（Cov = 被课程覆盖或被显式监控的痛点）；calibration_gap = |empirical_coverage − (1−α)|。Valid ⇔ Valid(J_glide) ∧ pain_coverage ≥ 1−δ_pain ∧ calibration_gap ≤ δ_cal ∧ λ_lagrange ≤ λ_max ∧ training_hash 与部署策略一致。

- **定义 234（痛点复发率与训练目标）**：recurrence_t = Σ_{p∈P_root} w_p·f_p(t)/Σw_p。PACT 的训练目标不是「单轮奖励最大」，而是**跨轮痛点复发率的单调下降**：min_π E_round[recurrence_{t+1}] s.t. E[c] ≤ d ∧ calibration_gap ≤ δ_cal。

- **定义 235（痛点覆盖率下界）**：若 top-k 痛点的风险质量占总量 ≥ 1−δ_tail，且课程对每个 p∈top-k 的覆盖概率 ≥ 1−δ_p，则总痛点风险的未覆盖质量 ≤ δ_tail + (1−δ_tail)·δ_p。

- **定义 236（Goodhart 审计指标）**：为检测奖励黑客，定义 held-out 痛点集 P_hold（不参与训练、只监控），审计 gap = recurrence(P_hold) − recurrence(P_root)。若 gap 随时间上升，判定为「指标被游戏」。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# PPM：反事实归因，输出可干预痛点
P = mine_pain_points(evidence, ssb_pain)      # ATE + plausibility

P_root = rank_pain_points(P, edges, k=5)       # R(p) 排序 + 去前驱
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 8（痛点排序的贪心近似）**：若痛点修复的风险下降函数 F(S) 在痛点集合上单调次模，则按边际收益贪心选择 top-k 给出 (1−1/e) 近似；R(p) 是一阶边际收益，PPG 的下游项修正重复计数。
- **引理 9（保形重校准修复 Σ_g 低估）**：在可交换性下，split conformal 给出 P[误差 ≤ q_{1−α}·‖Σ_g‖] ≥ 1−α；以 Σ̃_g=q·Σ_g 驱动 WCV-Trust，球半径不再系统性欠膨胀。
- **定理 6（约束 RL 的可行性）**：在标准 CMDP 假设（Slater 条件、有界梯度）下，LPPO 收敛到 E[c] ≤ d + O(1/√T)，且奖励与约束最优相差 O(1/√T)。
- **定理 7（自博弈课程的最坏情况界）**：若 ASPC 为零和凸凹博弈且双方采用 no-regret 更新，平均迭代收敛到博弈值 v*，故 π 的最坏痛点复发率 ≤ v* + O(1/√T)。
- **定理 8（PACT 跨轮改进）**：在痛点覆盖（定义 235）+ 保形校准（引理 9）+ 约束训练（定理 6）下，若每个根痛点修复的 ATE>0 且被课程覆盖，则 E[rec_{t+1}] ≤ (1−η_p)·E[rec_t] + δ_tail + noise，复发率收敛到 δ_tail 邻域。
- **命题（PPR 样本效率）**：优先采样把有效样本量 N_eff=1/Σp_i² 集中到痛点相关子空间，稀有痛点的梯度方差显著下降。
- **命题（Goodhart 可检测性）**：若 P_hold 与 P_root 可交换且审计 gap > δ_audit，则「测得下降但真实未降」以高概率被标记。

## 5. 本轮最大风险

**一句话**：痛点指标一旦成为训练目标，系统可能通过「让痛点不被检测到」而非「让痛点不发生」来降低它（Goodhart/奖励黑客）——例如 TRP 退化为永远 fallback、PPM 漏报、或课程只覆盖已命名痛点；此时训练指标漂亮但真实长尾鲁棒性未升反降。

**定义 219（PACT 闭环）** PACT = (GLIDE, PPM, PPG, CPT, ASPC, LPPO, PST, PPR, URC, TRP, π_rec, RBA, J_pact)。语义层（低频）执行 [证据采集 → PPM 归因 → PPG 排序 → CPT 课程生成 → LPPO+ASPC+PST+PPR 训练 → URC 校准 → 证书更新]；部署层继承 GLIDE 的语义流/实时流，实时流**只多一次 TRP 前向（<0.1ms）**，零训练写操作。不变式：**训练只发生在离线/低频线程；在线实时路径不更新任何策略参数**。

**定义 220（痛点 Pain Point）** p = (c, s, h, f, σ_sev, d, κ, 𝒱_p)。其中 c ∈ 组件集（DGF/USL-Mixed/CSP-Mixed/DIR-Depth/AIC-Depth/WCV-Depth/TRP…），s 为可观测症状（如「透明物体处深度洞导致抓取失败」），h 为可干预根因假设（如「提高透明材质深度补全阈值」），f 为频次（单位千步），σ_sev ∈ [0,1] 为严重度，d ∈ [0,1] 为可检测性（越高越容易被现有监控发现），κ 为归一化修复成本，𝒱_p 为验证谓词（修复后症状应消失）。**可干预性要求**：存在 do(h) 使 𝒱_p 可被检验，否则只是症状描述，不能进入 P_root。

**定义 221（PPM 痛点挖掘器）** 输入证据流 EV = {EV_exec, SSB incidents, DIR drift, AIC margin, calibration gap, human corrections}。对每个候选干预 h_i，用 SSB-Pain 的反事实重放估计 ATE_i = E[Y|do(h_i=1)] − E[Y|do(h_i=0)]，Y 为综合失效指标（安全违规 + 任务失败 + 认证失效的加权和）。归因分数 a_i = |ATE_i|·plaus_i·(1−cost_i)，plaus_i ∈ [0,1] 为机制可信度（专家规则 + 因果图约束）。PPM 输出 P = {p_i: |ATE_i| ≥ τ_ate, a_i ≥ τ_a}，并把每个事件分配给 argmax_i a_i。**要点**：没有反事实重放的归因只能算相关性，不能作为训练目标。

**定义 222（PPG 痛点因果图与排序）** PPG = (V_p, E_p) 为 DAG，边 p→q 当且仅当 do(fix_p) 使 q 的频次改变 |Δf_q| ≥ τ_edge。下游影响 downstream(p) = Σ_{q∈Reach(p)} |ATE(p→q)|。风险排序：
R(p) = [f_p·σ_sev_p·(1−d_p)·(1+β·downstream(p))] / (κ_p+ε)，β=0.5，ε=1e-6。
根痛点集 P_root = {p: R(p) 位于前 k，且不存在前驱 q 满足 R(q) ≥ R(p)}。训练预算只分配给 P_root，避免「修症状」。

**定义 223（CPT 痛点课程）** 训练分布 μ_θ = (1−ε_t)·μ_base + ε_t·Σ_{p∈P_root} w_p·μ_p，w_p = R(p)/ΣR。μ_p 由 SSB-Pain 变异生成：几何变异（拓扑/FFD/接触面翻转）+ 深度退化（定义 217 的 6 类）+ 步态/接触扰动 + 任务上下文重采样。课程温度 ε_t = clip(ε_0 + η_ε·(1−SR_t), ε_min, ε_max)，SR_t 为最近窗口任务成功率；目标把 SR 维持在**学习前沿** [0.6, 0.8]。**依据**：过高 SR 说明课程太易、痛点没被训练；过低 SR 说明课程过难、梯度噪声大。

**定义 224（ASPC 对抗自博弈课程）** 对手 π_adv: (x', Σ_g, p) → η ∈ ℰ_p 在痛点 p 对应的干扰集内最大化当前策略失效。训练目标为两人零和：
min_π max_{π_adv} E_{s~μ_θ, η~π_adv}[J(π, η)]。
对手用 PGD/RL 交替更新（每 N 个策略步更新一次）。**自动加难**：当 π 在 p 上复发率 < δ_adv，π_adv 转向下一个痛点；否则在 ℰ_p 边界内加深干扰强度。对手只生成**物理可实现**的干扰（深度噪声、遮挡、运动模糊、摩擦突变），不生成无界对抗样本。

**定义 225（训练 CMDP）** M_train = (S, A, P, r, c, γ, d)：
- 状态 s = (x', φ̂, r, Σ_g, p_ctx, history)；
- 动作 a = (θ_skill, a_trust ∈ {trust, recalibrate, fallback, ask}, a_rec ∈ {none, π_rec})；
- 奖励 r = progress − λ_pain·1[pain_recurred] − λ_compute·compute − λ_ask·1[ask]；
- 代价 c = safety_violation（ERTC/ZMP/力锥/关节限位，连续裕度或 0/1）；
- 约束 E_π[Σ_t c_t] ≤ d（d=0.01/千步）。
**关键设计**：安全进约束、任务进奖励，避免「用大权重把安全塞进奖励」导致的奖励尺度病态与安全-任务跷跷板。

**定义 226（LPPO 拉格朗日 PPO）** 求解 max_π E[r] s.t. E[c] ≤ d。拉格朗日 L(π,λ)=E[r]−λ(E[c]−d)。策略用 PPO clipped objective 更新；乘子 λ ← max(0, λ + η_λ·(Ê[c]−d))。维护滑动上界 λ_max 防止训练早期过度保守；策略每 K 步更新、λ 每步更新（交替）。**收敛性**：标准 CMDP 假设下，策略与乘子的交替更新收敛到约束最优的 O(1/√T) 邻域。

**定义 227（PST 特权教师-学生蒸馏）** 教师 π_T(a|s, φ*, D*, G*) 可见真值物理参数 φ*、干净深度 D*、完整几何 G*；学生 π_S(a|s) 只见真实观测。L_PST = E[KL(π_T(·|s,·) || π_S(·|s))] + L_task。教师仅在训练期存在（非对称 actor-critic），部署仅学生。**作用**：降低 sim-to-real 与深度噪声导致的策略梯度方差，同时把教师的「真值直觉」蒸馏给学生。

**定义 228（PPR 痛点优先回放）** 回放池样本 i 的优先级 pri_i = (1+f_pain(i))^α·(1+|δ_i|)^β·(1+rarity(i))^γ，采样概率 p_i = pri_i/Σ_j pri_j，α=β=γ=1。f_pain 为该样本关联的痛点频次，δ_i 为 TD 误差，rarity 为场景簇逆频率。**作用**：把梯度预算集中到「稀有且高痛点」的样本，提升样本效率并缓解长尾遗忘。

**定义 229（URC 保形不确定性重校准）** 在留出校准集 D_cal（覆盖 P_root 痛点场景）上计算非一致性分数 e_i = ‖d_err_i‖/(‖Σ_g,i‖_F+ε)，取保形分位数 q_{1−α}=Quantile_{1−α}({e_i})。部署输出 Σ̃_g = q_{1−α}·Σ_g（或先学尺度 s_ψ(O) 再保形校准）。在可交换性下保证 P[‖d_err‖ ≤ q_{1−α}·‖Σ_g‖_F] ≥ 1−α。**这直接修复第 64 轮 Σ_g 系统性低估**：不再假设 Σ_g 可信，而是用实测误差分布把它「撑大」到可认证覆盖率。

**定义 230（TRP 信任策略）** π_trust: (x', Σ_g, calib_features, p_ctx) → a_trust ∈ {trust, recalibrate, fallback, ask}。动作语义：
- trust：r_0 = r_base·γ_geo(g, Σ_g)；
- recalibrate：r_0 = r_base·γ_geo(g, Σ̃_g)（保形膨胀）；
- fallback：走第 62 轮 ROSE 非几何路径，J 标记 geo_degraded=True；
- ask：请求多视角/人类澄清（有延迟与人力代价）。
奖励 r_trust = task_progress − λ_over·1[过度信任致违规] − λ_under·1[不必要降级/求助] − λ_lat·delay。**关键**：把「信不信几何」变成可学习决策，而非硬编码的二元开关。

**定义 231（π_rec 恢复策略）** π_rec: (s, trigger) → {safe_idle, retreat, re_approach, re_grasp}。触发条件：TRP=fallback/ask、ρ_rob < 0、AIC 证书失效。奖励 r_rec = recovery_success − λ_t·time − λ_c·residual_cost。作为 CSP-Recover 的末端可选原语，保证降级时有显式退路而非裸奔。

**定义 232（RBA 训练预算分配器）** 臂 = P_root × {curriculum_only, +ASPC, +PST, +PPR, full}，K=|P_root|×5。奖励 = ΔPain_p/compute（单位算力带来的痛点风险下降）。EXP3/UCB 非平稳调度；每轮训练后重估 ΔPain。硬规则：单痛点预算占比 ≤ 40%，防止课程坍缩到单一痛点。

**定义 233（J_pact 证书）** J_pact = (J_glide, pain_coverage, calibration_gap, curriculum_ver, trust_ver, λ_lagrange, rba_ver, training_hash)。pain_coverage = 1 − Σ_{p∉Cov} R(p)/Σ_p R(p)（Cov = 被课程覆盖或被显式监控的痛点）；calibration_gap = |empirical_coverage − (1−α)|。Valid ⇔ Valid(J_glide) ∧ pain_coverage ≥ 1−δ_pain ∧ calibration_gap ≤ δ_cal ∧ λ_lagrange ≤ λ_max ∧ training_hash 与部署策略一致。

**定义 234（痛点复发率与训练目标）** recurrence_t = Σ_{p∈P_root} w_p·f_p(t)/Σw_p。PACT 的训练目标不是「单轮奖励最大」，而是**跨轮痛点复发率的单调下降**：
min_π E_round[recurrence_{t+1}] s.t. E[c] ≤ d ∧ calibration_gap ≤ δ_cal。
该目标把「训练」与「部署验证」绑定：训练是否有效，由下一轮部署的痛点复发率裁决。

**定义 235（痛点覆盖率下界）** 若 top-k 痛点的风险质量占总量 ≥ 1−δ_tail，且课程对每个 p∈top-k 的覆盖概率 ≥ 1−δ_p，则总痛点风险的未覆盖质量 ≤ δ_tail + (1−δ_tail)·δ_p。**推论**：增大 k 或提高单痛点覆盖概率都能压低未覆盖风险，但受训练预算约束，需 RBA 折中。

**定义 236（Goodhart 审计指标）** 为检测奖励黑客，定义 held-out 痛点集 P_hold（不参与训练、只监控），审计 gap = recurrence(P_hold) − recurrence(P_root)。若 gap 随时间上升，判定为「指标被游戏」，触发 PPM 重新归因与课程重置。

### IP-203 PPM（痛点挖掘器）

```python
class PainPointMiner:
    """从证据流做反事实 ATE 归因，输出可干预痛点。"""
    def __init__(self, ssb_pain, tau_ate=0.05, tau_a=0.1):
        self.ssb = ssb_pain; self.tau_ate = tau_ate; self.tau_a = tau_a

    def mine(self, evidence, candidate_interventions):
        pains = []
        for h in candidate_interventions:          # h = (component, failure_mode, fix)
            y1 = self.ssb.counterfactual_replay(h, do=1)   # 修复后的失效指标
            y0 = self.ssb.counterfactual_replay(h, do=0)   # 原始失效指标
            ate = mean(y1) - mean(y0)
            plaus = self.mechanism_score(h)                # 专家规则/因果图约束
            cost = self.normalized_cost(h)
            a = abs(ate) * plaus * (1.0 - cost)
            if abs(ate) >= self.tau_ate and a >= self.tau_a:
                pains.append(PainPoint(component=h.component, symptom=h.symptom,
                                       h=h, freq=self.freq(evidence, h),
                                       sev=self.severity(evidence, h),
                                       detect=self.detectability(h),
                                       cost=cost, verify=h.verify_predicate))
        self._assign_events(pains, evidence)       # 每个事件 → argmax 归因
        return pains
```

### IP-204 PPG（痛点因果图与排序）

```python
class PainPointGraph:
    def __init__(self, pains, edge_threshold=0.02, beta=0.5):
        self.pains = {p.id: p for p in pains}
        self.beta = beta
        self.G = self._build_dag(pains, edge_threshold)   # do(fix_p) 改变 f_q 则有边

    def _build_dag(self, pains, thr):
        G = nx.DiGraph(); G.add_nodes_from(self.pains)
        for p in pains:
            for q in pains:
                if p.id == q.id: continue
                delta_f = self._intervene_freq(p, q)     # SSB 反事实：修 p 后 q 频次变化
                if abs(delta_f) >= thr:
                    G.add_edge(p.id, q.id, ate=abs(delta_f))
        return G

    def risk_score(self, p):
        downstream = sum(self.G[p.id][q].get('ate', 0.0)
                         for q in nx.descendants(self.G, p.id))
        return (p.freq * p.sev * (1 - p.detect) * (1 + self.beta * downstream)
                / (p.cost + 1e-6))

    def root_pains(self, k=5):
        ranked = sorted(self.pains.values(), key=self.risk_score, reverse=True)
        roots = []
        for p in ranked:
            if any(self.risk_score(self.pains[q]) >= self.risk_score(p)
                   for q in self.G.predecessors(p.id)):
                continue
            roots.append(p)
            if len(roots) >= k: break
        return roots
```

### IP-206 ASPC（对抗自博弈课程）

```python
class AdversarialSelfPlayCurriculum:
    """对手专攻当前最弱痛点，自动加难。"""
    def __init__(self, root_pains, adv_policy, delta_adv=0.05):
        self.root = root_pains; self.adv = adv_policy; self.delta = delta_adv
        self.active = root_pains[0]

    def generate(self, state, policy):
        eta = self.adv.perturb(state, pain=self.active)      # η ∈ ℰ_active
        return eta

    def update(self, policy, recurrence):
        # 当前痛点已足够鲁棒 → 转向下一个
        if recurrence[self.active.id] < self.delta:
            idx = self.root.index(self.active)
            self.active = self.root[(idx + 1) % len(self.root)]
        # 否则在 ℰ_p 边界内加深强度
        else:
            self.adv.escalate(self.active, factor=1.1)
```

### IP-207 LPPO（拉格朗日 PPO）

```python
class LagrangianPPO:
    def __init__(self, policy, value, cost_value, d=0.01,
                 eta_lambda=0.05, lambda_max=10.0, K=4):
        self.pi, self.v, self.vc = policy, value, cost_value
        self.d, self.eta_lambda, self.lambda_max = d, eta_lambda, lambda_max
        self.lam = 0.0; self.K = K; self.step_count = 0

    def update(self, batch, optimizer):
        adv = gae(batch, self.v)
        adv_c = gae(batch, self.vc, reward=batch.cost)
        pi_loss = ppo_clip(self.pi, batch, adv)
        cost_loss = ppo_clip(self.pi, batch, adv_c)
        loss = -pi_loss + self.lam * cost_loss
        optimizer.zero_grad(); loss.backward(); optimizer.step()
        # 每步更新乘子（策略每 K 步更新）
        self.lam = max(0.0, self.lam + self.eta_lambda * (batch.cost.mean() - self.d))
        self.lam = min(self.lam, self.lambda_max)
        return self.lam
```

### IP-208 PST（特权教师-学生蒸馏）

```python
class PrivilegedDistiller:
    """教师看真值 φ*/D*/G*，学生看真实观测；仅训练期存在教师。"""
    def __init__(self, teacher, student, beta_kl=0.5):
        self.teacher, self.student, self.beta = teacher, student, beta_kl

    def loss(self, s_student, s_privileged, action, reward):
        with torch.no_grad():
            pi_T = self.teacher(s_privileged)
        pi_S = self.student(s_student)
        kl = torch.distributions.kl_divergence(pi_T, pi_S).mean()
        task = -log_prob(pi_S, action) * reward
        return task + self.beta * kl
```

### IP-209 PPR（痛点优先回放）

```python
class PainPrioritizedReplay:
    def __init__(self, capacity, alpha=1.0, beta=1.0, gamma=1.0):
        self.buf, self.cap = [], capacity
        self.a, self.b, self.g = alpha, beta, gamma

    def priority(self, sample):
        return ((1 + sample.pain_freq) ** self.a
                * (1 + abs(sample.td_error)) ** self.b
                * (1 + sample.rarity) ** self.g)

    def sample(self, n):
        pri = np.array([self.priority(s) for s in self.buf])
        p = pri / pri.sum()
        idx = np.random.choice(len(self.buf), size=n, p=p)
        return [self.buf[i] for i in idx]
```

### IP-210 URC（保形不确定性重校准）

```python
class UncertaintyRecalibrator:
    """split conformal：把 Σ_g 撑大到可认证覆盖率。"""
    def __init__(self, alpha=0.05, eps=1e-6):
        self.alpha, self.eps = alpha, eps; self.q = None

    def calibrate(self, calib_loader, depth_model):
        scores = []
        for O, depth_gt in calib_loader:
            mu, sigma = depth_model(O)                  # 预测深度均值/不确定度
            err = torch.abs(mu - depth_gt)
            scores.append((err / (sigma + self.eps)).flatten())
        scores = torch.cat(scores)
        self.q = torch.quantile(scores, 1 - self.alpha).item()
        return self.q

    def recalibrate(self, sigma):
        return self.q * sigma if self.q is not None else sigma
```

### IP-211 TRP（信任策略）

```python
class TrustPolicy:
    """π_trust: 选择 trust / recalibrate / fallback / ask。"""
    ACTIONS = ['trust', 'recalibrate', 'fallback', 'ask']

    def __init__(self, net, urc, lambda_over=1.0, lambda_under=0.5, lambda_lat=0.1):
        self.net, self.urc = net, urc
        self.lo, self.lu, self.ll = lambda_over, lambda_under, lambda_lat

    def act(self, x_prime, Sigma_g, calib_feats, pain_ctx):
        logits = self.net(torch.cat([x_prime, calib_feats, pain_ctx]))
        return self.ACTIONS[int(logits.argmax())]

    def reward(self, progress, over_trust_violation, unnecessary_degrade, delay):
        return (progress - self.lo * over_trust_violation
                - self.lu * unnecessary_degrade - self.ll * delay)

    def radius(self, action, g, Sigma_g, r_base, gamma_geo):
        if action == 'trust':
            return r_base * gamma_geo(g, Sigma_g)
        if action == 'recalibrate':
            return r_base * gamma_geo(g, self.urc.recalibrate(Sigma_g))
        return None   # fallback → 走 ROSE 非几何路径
```

```python
class RecoveryPolicy:
    """信任降级/证书失效时的显式恢复原语。"""
    def __init__(self, net, lambda_t=0.1, lambda_c=1.0):
        self.net, self.lt, self.lc = net, lambda_t, lambda_c

    def act(self, state, trigger):
        return self.net(state, trigger)   # safe_idle/retreat/re_approach/re_grasp

    def reward(self, success, time_cost, residual_cost):
        return success - self.lt * time_cost - self.lc * residual_cost
```

### IP-213 RBA（训练预算分配器）

```python
class RLBudgetAllocator:
    """以单位算力痛点下降为奖励，EXP3 调度训练预算。"""
    def __init__(self, root_pains, modes, eta=0.2):
        self.arms = [(p, m) for p in root_pains for m in modes]
        self.K = len(self.arms); self.w = np.ones(self.K) / self.K; self.eta = eta
        self.prev_pain = {p.id: p.risk for p in root_pains}

    def choose(self):
        return np.random.choice(self.K, p=self.w)

    def update(self, idx, pain_now, compute):
        p = self.arms[idx][0]
        delta = max(0.0, self.prev_pain[p.id] - pain_now) / max(compute, 1e-6)
        reward = np.clip(delta, 0, 1)
        r_hat = reward / max(self.w[idx], 1e-6) / self.K
        self.w[idx] *= np.exp(self.eta * r_hat / self.K)
        self.w /= self.w.sum()
        self.prev_pain[p.id] = pain_now
        # 硬规则：单痛点预算 ≤ 40%
        self._cap_per_pain(0.4)
```

## 4. 推导

**引理 8（痛点排序的贪心近似）** 设痛点集合 S 的修复收益 F(S) 为单调次模函数（每修一个痛点带来的边际风险下降随已修集合增大而递减）。按边际收益贪心选择 top-k 得到 F(S_greedy) ≥ (1−1/e)·F(S*)。R(p) 是 p 的一阶边际收益；PPG 的 downstream(p) 项修正「修 p 会顺带降低 q」的重复计数，使排序更接近真实边际收益。**前提**：修复收益次模（现实中的确通常递减：先修最大痛点收益最高）。∎

**引理 9（保形重校准修复 Σ_g 低估）** 设校准样本与测试样本可交换。定义非一致性分数 e=‖d_err‖/(‖Σ_g‖+ε)，取 q_{1−α} 为校准集 e 的 ⌈(n+1)(1−α)⌉/n 分位数。则对新的测试样本，P[‖d_err‖ ≤ q_{1−α}·‖Σ_g‖] ≥ 1−α（split conformal 标准结论）。以 Σ̃_g=q_{1−α}·Σ_g 驱动 WCV-Trust 的半径 γ_geo(g,Σ̃_g)，球半径不再系统性欠膨胀。**注意**：若深度分布发生漂移，可交换性破坏，需滑动窗口重校准（见风险 3）。∎

**定理 6（约束 RL 的可行性）** 在标准 CMDP 假设下（Slater 条件存在严格可行策略、奖励与代价有界、策略梯度有界），LPPO 的交替更新等价于在拉格朗日对偶域上做随机原始-对偶优化。由对偶间隙 O(1/√T) 与乘子有界性，收敛点满足 E[c] ≤ d + O(1/√T)，且 E[r] ≥ E[r*] − O(1/√T)。**实践含义**：训练步数越多，安全违规越接近约束边界 d，而非「越训越保守」。∎

**定理 7（自博弈课程的最坏情况界）** 若 ASPC 构成两人零和博弈，支付 J(π,η) 对 π 凹、对 η 凸，且双方采用 no-regret 算法（如 EXP3/PGD），则平均迭代 (π̄_T, η̄_T) 收敛到鞍点，对偶间隙 ≤ O(1/√T)。于是 π̄_T 的最坏痛点复发率 max_η recurrence(π̄_T,η) ≤ v* + O(1/√T)，其中 v* 为博弈值。**前提**：干扰集 ℰ_p 有界且支付连续；否则只能得到局部鞍点。∎

**定理 8（PACT 跨轮改进）** 假设：(i) top-k 痛点风险质量 ≥ 1−δ_tail（定义 235）；(ii) 每个根痛点被课程覆盖概率 ≥ 1−δ_p；(iii) 每个根痛点修复的 ATE>0；(iv) URC 保形校准使球半径不欠膨胀（引理 9）；(v) LPPO 使 E[c] ≤ d+O(1/√T)（定理 6）。则单轮训练后，被覆盖痛点的期望复发率至少按 (1−η_p) 收缩；未被覆盖部分贡献 ≤ δ_tail。故
E[rec_{t+1}] ≤ (1−η_p)·E[rec_t] + δ_tail + O(1/√T)。
当 t→∞，rec 收敛到 δ_tail + O(1/√T) 的邻域。**关键**：改进速度由课程覆盖 η_p 决定，改进下限由长尾 δ_tail 决定——所以 PPM 必须持续发现新痛点，否则会在 δ_tail 处停滞。∎

**命题（PPR 样本效率）** 优先采样下，梯度估计的有效样本量 N_eff = 1/Σ_i p_i²。若痛点相关样本占比为 ρ 且优先级使其采样概率提升到 ρ'≫ρ，则 N_eff 在痛点相关子空间上提升约 ρ'/ρ 倍；代价是非痛点样本的梯度方差上升，需用重要性采样权重 w_i=(1/N)/p_i 做偏差校正。∎

**命题（Goodhart 可检测性）** 设 P_hold 与 P_root 来自同一痛点总体且修复对所有痛点同向有效。若观测到 recurrence(P_root) 显著下降而 recurrence(P_hold) 未降（审计 gap > δ_audit），则由「同向有效」假设的逆否，下降不可能来自真实修复，只能来自测量/检测层的变化（漏报、降级坍缩、课程过拟合）。因此审计 gap 可作为奖励黑客的一阶告警。∎

## 7. 已知风险

**一句话**：痛点指标一旦成为训练目标，系统可能通过「让痛点不被检测到」而非「让痛点不发生」来降低它（Goodhart/奖励黑客）——例如 TRP 退化为永远 fallback、PPM 漏报、或课程只覆盖已命名痛点；此时训练指标漂亮但真实长尾鲁棒性未升反降。

**次级风险与缓解**：
1. **PPM 归因错误（相关≠因果）**：反事实重放依赖 SSB 仿真保真度；仿真偏差会给出错误 ATE → 用真实部署的 A/B 干预做周期性校准（每 N 轮），并对 ATE 给置信区间而非点估计。
2. **保形可交换性破坏**：深度分布漂移使覆盖率保证失效 → 滑动窗口重校准 + 分布漂移检测（MMD/KS），漂移超阈值时把 calibration_gap 写入 J_pact 并降级信任。
3. **约束过保守**：λ 过大导致任务成功率崩塌 → λ_max 滑动上界 + 课程难度与 λ 联合调度；若任务成功率连续下降则临时冻结 λ 更新。
4. **自博弈不稳定**：对手过强导致策略梯度爆炸 → 对手强度上限（ℰ_p 半径）+ 周期性冻结对手 + 梯度裁剪。
5. **课程坍缩**：RBA 把预算全押单一痛点 → 单痛点预算占比硬上限 40% + 周期性强制探索。
6. **长尾盲区**：P_root 只覆盖已发现痛点，未知痛点导致定理 8 的 δ_tail 停滞 → 主动探索（novelty bonus）+ P_hold 审计 + 人类纠正注入。
7. **训练成本**：ASPC+PST+PPR 叠加使训练算力上升 → RBA 按「单位算力痛点下降」调度，只在边际收益高时启用重训练技巧。
