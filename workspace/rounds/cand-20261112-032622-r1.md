# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「力矩控制」×「开源软件」）

> 第 57 轮把风险从"模型置信"推到"元先验质量"，并用共形带、EV-xmodal 限 L1、授权单向有界三道护栏兜底。但它仍默认了两个未被审查的前提：**(a)** 只要证据门在检查点放行，一个"承诺"就会在物理层被忠实执行——可证据门以检查点为节拍、以信念为输入，而力矩以 kHz 为节拍、以执行器饱和/热/间隙/扰动为输入；证书证明的是"该不该踩"，从未证明"踩下去的那一脚最多有多大力"。**(b)** 证据是私有的、可被无条件信任的——没人问它"能否被另一个体复现"、"出错时归咎于哪一条证据"、"撤下这条证据后全舰队有多少承诺要一起回滚"。**力矩控制**补前者：把每个承诺编译成可执行、可审计、belief-independent 的**力矩包络**，并交给一个小可信实时内核执行；**开源软件**补后者：把证据变成带签名、provenance、复现回执、blame 与 revert 的**证据公地**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"证据可复现、承诺可执行、归责可回滚的力限公地说可信"**。

核心矛盾：
- **H29（承诺–执行鸿沟）**：J_p 在检查点证明"承诺安全"，但真实安全由 τ(t) 在毫秒尺度决定；执行器饱和、热降额、间隙与模型误差可在两个检查点之间把已认证的承诺变成实际越界。包络太紧则能力崩塌、操作者绕过；太松则安全证明与物理现实脱钩。
- **H30（证据不可复现）**：跨个体、跨载荷、跨控制器的"同一次探针"并不产生同一个观测；没有力矩轨迹与本体描述的"证据"只是证词。可复现性又要依赖容差 ε_rc 与验证器——谁来校准容差、谁来验证验证器？复现把信任问题从"证据本身"转移到"复现预言机"。
- **H31（证据公地治理）**：共享地图让全舰队免费搭便车，也让一条错误或恶意证据沿依赖图扩散；"many eyes"在所有人共用同一个有缺陷传感器/仿真器时退化为"同一个错误被看很多遍"。blame 的最小归因可能不唯一，revert 的扇出可能吞掉大量正常承诺。

## 0. 直觉与动机

**灵感 1（力矩控制 → 承诺必须被编译成力）**
直觉：第 57 轮的证据门像"出车前的安检"，但真正决定事故的是"上路后每一脚油门/刹车"。力矩控制提供了一个连续、可测量、可硬性截断的安全面：无论上层信念多自信，执行器力矩都必须落在由结构强度、热、摩擦锥、支撑多边形共同定义的**硬包络**内。于是安全被拆成两层：**认知层**决定"值不值得冒险"，**物理层**决定"最多能冒多大险"。即使地图全错，物理层也只让承诺以它被认证时的最大力执行；物理层不依赖信念，因而不可被坏先验污染。关键设计是把 J_p 通过编译器 Γ **编译**为每条承诺的力矩包络与能量预算，并让一个极小的实时内核独立执行"投影 + 违约预测 + 保守回退"。

**灵感 2（力矩控制 → 探针即受控力矩脉冲）**
直觉：探针不必是"戳一下看看"，而可以是一次能量受限的主动阻抗辨识：小幅力矩 chirp/阶跃，测响应，估计接触刚度与摩擦。这样"探针成本"第一次有了物理单位（N·m、J），探询预算从抽象的 θ_voi 变成 **VOI/焦耳** 的性价比排序；同时 `F_abs/E_abs` 上限让"探询"本身成为非破坏性动作，而不是把安全赌在"这次应该不会坏"上。

**灵感 3（开源软件 → 证据即代码：commit / review / reproducible build）**
直觉：可信的代码不是"作者说它对"，而是"有源码、可复现构建、可审查、可回滚"。把每条证据当成一次 commit：附带力矩轨迹（源码）、本体描述与控制器的 hash（构建环境）、标定状态、复现回执（review/reproduce）、依赖 lockfile。**不可复现的证据降级为证词（testimony），不再是证据**。这让第 57 轮缺失的"条件独立"第一次有了现实含义：独立不是同一台机器换两个模态，而是**不同本体/不同验证器的独立复现**。

**灵感 4（开源软件 → 小可信基与签名供应链）**
直觉：开源安全的核心不是"所有人都能改"，而是"所有人都能审计一个足够小的核"。整套系统的最终安全裁判应当是一个**小可信基（TCB）**：可形式化、可复现构建、可签名、可多版本异构冗余的实时内核；元模型权重、证据地图、云端更新都像依赖包一样带 SBOM、固定版本与签名。云端可以发布新元模型，但必须先在影子模式通过复现与校准回归，边端才允许将其并入 lockfile。

**灵感 5（两灵感合流 → 证据门从"单证书"到"双证书 + 分级复现"）**
直觉：第 57 轮的 J_p 是"认知证书"；本轮为它配一张"物理证书"E_σ，并要求证据带复现等级 T0~T3。不可逆承诺必须同时满足：认知证书 ∧ 物理包络可行 ∧ 证据等级达标 ∧ 区域非 disputed/revoked。击穿安全需要：坏证据 ∧ 坏先验 ∧ 包络编译错误 ∧ 内核失效 ∧ 复现预言机共谋 ∧ 归责失败——纵深从五层扩到七层，且其中两层（硬包络、实时内核）与信念完全解耦。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（力矩包络台账 TEL）** 对承诺 σ 与信念 𝓜，编译器 Γ:(σ,𝓜)↦E_σ(t)=(τ⁻,τ⁺,Δτ_max,P_max,E_max,f_n^min,μ_c,ρ_cop) 给出整条承诺上的逐关节力矩上下界、力矩变化率、功率/能量、法向力下限、摩擦锥与压力中心裕度；可行性由全身动力学 QP 判定。系统维护**硬包络** H（执行器/结构/热，belief-independent）与**软包络** E_σ（belief-dependent，随风险加严）。承诺可执行 ⇔ E_σ∩H 非空 ∧ 能量预算 B_act 可预留（沿路线按次可加合成）。两条不变量：(I1) ∀t, τ(t)∈H；(I2) 若环境落在认证信念集内，任务力矩以裕度落在 E_σ 内，否则内核触发保守回退。

**定义 140（可复现接触 RC 与证据等级）** 证据 e=(τ 轨迹,q,q̇,y 响应, χ 本体描述, h_ctl 控制器 hash, κ 标定状态, z 上下文, ε_rc, α_rc)。验证器 V 以同一 τ 轨迹在 V 的本体（或按本体标定的仿真器）上重放，若 d_rc(y,y′) 落在覆盖 ≥1−α_rc 的共形容差区间内则记一次成功复现。证据等级：**T0 证词**（无轨迹）/ **T1 有迹**（有轨迹，无独立复现）/ **T2 单方复现**（≥1 个独立验证器）/ **T3 多方复现**（验证器多样性 ν(e)≥2，即不同本体族或不同仿真器族）。独立性按 ν 计而非按次数计——同一仿真器跑十遍仍是一个"眼睛"。

**定义 141（证据公地 ECR：provenance / merge / blame / revert）** 地图升级为有向无环证据图 𝒢=(commits, deps)。每条 commit c=(id,parent,deps-lockfile,payload,sig,provenance,repro receipts,tier,status)，status∈{released,disputed,revoked,testimony}。合并规则：兼容 ⇒ released；同区域矛盾 ⇒ **disputed**（保留双方、区域禁承诺、触发判别性探针），禁止 fast-forward 静默覆盖；签名无效或等级不足 ⇒ 拒绝。失败时 **blame**：求最小反事实归因集 Cul(f)=最小的 S 使得移除 S 会改变原承诺决策；取依赖闭包 Dep*(S)；签发撤销证书 R，全舰队在 T_rev 内使 Dep*(S) 失效并灰度回滚。爆炸半径 b(c)=|Dep*(c)|，b 越大要求越高的复现等级与审查数。

**定义 142（实时力矩内核 RTK）** 一个小可信基：输入 τ_nom、状态 x、软包络 E_σ 与硬包络 H，输出 τ=Proj_{E_σ∩H}(τ_nom)；若在预测时域内将违反包络则执行回退 φ∈{降刚度, 被动顺从, 支撑相保持, 安全停}（按能力损失最小选择）。保证：∀t,τ(t)∈H；违约响应时延 ≤T_fb；任何上层 API 不可拓宽 H；固件可复现构建、签名、可证明（形式化规格），建议 N 版本异构冗余。

**定义 143（力矩–复现–公地证据门 TEG）** 升级第 57 轮 FSE。各证据类新增条件：EV-probe\* 须 tier≥T2（L1）/T3（L2）∧ E_σ 可行 ∧ 非 disputed/revoked；EV-visit/EV-margin 须轨迹完整 tier≥T1，L2 须 T2；EV-xmodal 仍限 L1 且须 tier≥T1；EV-human 默认 T0 证词，只有被第二操作者/会话独立复现后才升 T2。不可逆接触必要证据集 = **(EV-probe\*∨EV-margin) ∧ E_σ 可行 ∧ disputed=∅ ∧ revoked=∅**，不含 EV-xmodal。证书 J_t = J_p ∪ (E_σ, 预算预留, 复现回执, provenance/lockfile, tier, dispute, revocation, SBOM, 内核 attestation)。

**定义 144（探-诺-演++ 算子 PCE++）** 每检查点：①元推断与跨模态对账（继承第 57 轮）；②**力矩感知探询**：候选探针按 EVOI/(N·m·s+J) 排序，受 F_abs/E_abs 与 k_rc 复现预算约束；③对账后为探针生成 RC 回执，必要时请求独立复现；④提交前编译 E_σ、校验预算、过 TEG；不可行则探询→降档→绕行→协商/安全停；⑤提交后把包络与依赖写回证据图；⑥收到撤销或失败 ⇒ blame→revert→重探。

## 2. 关键算法伪代码（完整版见产物区）

```python
def compile_envelope(sigma, M, H, budget):          # IP-139
    tau_nom = whole_body_qp(sigma, M, H)            # 名义任务力矩
    E = tighten(tau_nom, margin_from(M.risk))       # 信念相关软包络
    E = meet(E, H)                                   # 永不拓宽硬包络
    if not feasible(E) or not budget.reserve(E.energy):
        return None                                  # 承诺不可执行
    return E

def torque_kernel(tau_nom, x, E, H):                # IP-142: 小 TCB
    tau = project(tau_nom, E & H)
    if predict_violation(x, tau, horizon=T_fb):
        return fallback(x, loss='min_capability')    # 降刚/顺从/安全停
    return tau, attest(H)

def reproduce(e, verifiers, alpha_rc):              # IP-140
    if e.trace is None: return T0
    ok = sum(v.replay_ok(e, alpha_rc) for v in verifiers)
    return tier(ok, diversity=nu(verifiers))        # ν≥2 才可 T3

def blame_revert(failure, G):                       # IP-141
    S = minimal_counterfactual(failure, G)          # 最小归因集
    D = transitive_dependents(S, G)
    R = revoke(S, D, ttl=T_rev); canary(R)          # 全舰队灰度回滚
    return R
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TEL | O(QP)/承诺；路线 O(\|CP\|) 合成 | O(\|CP\|·n_τ) | E_σ∩H 可行、预算守恒 |
| RTK | O(n_τ)/控制拍 | O(1) | 硬包络不变式、回退时延 ≤T_fb |
| RC | O(ν·T_replay)/证据 | O(ν) 验证器 | 容差覆盖 ≥1−α_rc、等级诚实 |
| ECR | blame O(\|𝒢\|·\|Dep\*\|) 最坏 | O(\|𝒢\|) | 签名/溯源、T_rev 内遏制 |
| TEG | O(\|σ\|) | O(\|σ\|) | 双证书、disputed/revoked 硬拒 |
| PCE++ | 继承 PCE+ 加 O(k_rc) | O(\|V\|+\|σ\|+\|𝒢\|) | 力矩预算单调、有限终止 |

**正确性定理（Torque-Reproducible Commons Soundness, TRCS 概要）**：在 A37–A40 上加 **(A41)** 内核执行与硬限：∀t,τ∈H、回退时延 ≤T_fb、TCB 经形式化验证或异构冗余；**(A42)** 复现诚实：tier 声明真实、容差覆盖 ≥1−α_rc、假接受率 ≤δ_rc；**(A43)** 公地完整性：签名不可伪造、撤销在 T_rev 内传播完备、disputed 区永不自动合并；**(A44)** 包络充分性：ID 且落在认证信念集内 ⇒ E_σ 可行且有裕度，OOD ⇒ 退保守包络 E_safe。则：
(i) **物理健全性与信念解耦**：P(τ∉H)≤δ_kernel+δ_fb；即使 𝓜/q_φ 全错，实际伤害被 H 与回退截断，承诺失效不再等价于物理事故；
(ii) **认知健全性**：只有 tier≥req ∧ 非 disputed ∧ 非 revoked 的证据能进入不可逆承诺；T0 仅以 w_test 进入 P_fail；
(iii) **公地遏制**：一次事后失败后，Cul 与 Dep\* 在 T_rev 内全舰队失效，残余风险 ≤ 未复现证词比例 × 爆炸半径；
(iv) **交互单调性**：力矩预算与包络只会使动作更保守，复现只可能降权（除非独立复现成功），个性化/对账/元推断仍只能经"信念更准或动作更保守"两条通道作用；
(v) PCE++ 在 k_probes+k_cons+k_rc 内终止于 {承诺, 绕行, 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把安全的最终裁定权下沉到一个实时力矩内核与一个"可复现"验证器网络——若这两者本身共享同一缺陷或被同一供应链污染（全舰队用同一个内核、同一个仿真器判定复现成功），所有机器人会以高度一致且自信的方式同时通过全部检查；必须以异构冗余内核、硬件硬限、独立验证器多样性、按爆炸半径分级审查与灰度回滚，确保"验证者自己也要被验证"。

### IP-139 TEL（力矩包络台账与编译）

```python
def compile_envelope(sigma, M, H, budget):
    tau_nom = whole_body_qp(sigma, M, H)              # 名义任务力矩
    E = tighten(tau_nom, margin_from(M.risk))         # 风险越大，软包络越紧
    E = meet(E, H)                                     # 软 ∩ 硬；永远不会拓宽 H
    if not feasible(E):                                # QP 不可行
        return None                                    # 承诺不可执行
    if not budget.reserve(E.energy):                   # 能量台账不足
        return None
    return E

def compile_route(route, M, H, budget):
    ledger = []
    for sigma in route.commitments:                    # 顺序合成
        E = compile_envelope(sigma, M, H, budget)
        if E is None: return None, ledger               # 交回 PCE++ 降档/绕行
        ledger.append((sigma, E))
    return ledger, budget

def tighten(tau_nom, margin):
    return Envelope(lo=tau_nom.lo - margin.lo,
                    hi=tau_nom.hi + margin.hi,
                    dtau=margin.dtau, power=margin.power,
                    energy=margin.energy, fn=margin.fn,
                    mu=margin.mu, cop=margin.cop)
```

def reproduce(e, verifiers, alpha_rc):
    if e.trace is None:
        return T0                                       # 无轨迹，仅证词
    ok = 0
    for v in distinct_families(verifiers):              # 按本体/仿真器"族"去重
        y2 = v.replay(e.trace, e.embodiment, e.h_ctl, e.kappa)
        if conformal_accept(y2, e.y, eps=e.eps_rc, alpha=alpha_rc):
            ok += 1
    nu = len(distinct_families(verifiers))
    if ok >= 2 and nu >= 2: return T3                   # 多方独立复现
    if ok >= 1:            return T2                    # 单方独立复现
    return T1                                           # 仅自身有迹

def tier_req(level, blast):
    if level == 'L2' or blast > B_HIGH: return T3        # 不可逆/大爆炸半径
    if level == 'L1' or blast > B_MID:  return T2
    return T1

def probe_commit_evolve_pp(x0, M, task, budget, consent, personas, G):

        lv = contact_level(cp)
        E = compile_envelope(commitment(sigma, g), M, H, budget)

            return negotiate_or_stop(cp, M, sigma, R, consent,

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TEL | O(QP)/承诺；路线 O(\|CP\|) 合成 | O(\|CP\|·n_τ) | E_σ∩H 可行、能量预算守恒（A41/A44） |
| RC | O(ν·T_replay)/证据 | O(ν) 验证器 | 容差覆盖 ≥1−α_rc、等级诚实（A42） |
| ECR | blame O(\|𝒢\|·\|Dep\*\|) 最坏 | O(\|𝒢\|) | 签名/溯源、T_rev 内遏制（A43） |
| RTK | O(n_τ)/控制拍 | O(1) | 硬包络不变式、回退时延 ≤T_fb（A41） |
| TEG | O(\|σ\|) | O(\|σ\|) | 双证书、disputed/revoked 硬拒 |
| PCE++ | O(\|CP\|·((k_p+k_c+k_rc)·C_EVOI+\|𝒢\|)) | O(\|V\|+\|σ\|+\|𝒢\|) | 力矩预算单调、有限终止、四态完备 |

**正确性定理（Torque-Reproducible Commons Soundness, TRCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 力矩内核执行与硬限：∀t,τ(t)∈H，回退时延 ≤T_fb，TCB 经形式化规格验证或 N 版本异构冗余，上层不可拓宽 H；**(A42)** 复现诚实：证据 tier 声明真实，容差区间覆盖 ≥1−α_rc，假接受率 ≤δ_rc；**(A43)** 公地完整性：签名不可伪造、provenance 与 lockfile 完整、撤销在 T_rev 内传播完备、disputed 区域永不自动合并；**(A44)** 包络充分性：ID 且落在认证信念集内 ⇒ E_σ 可行且有裕度，OOD ⇒ 退保守包络 E_safe。则：

1. **物理健全性与信念解耦**：P(τ∉H) ≤ δ_kernel + δ_fb。即使 𝓜 与 q_φ 全部错误，实际接触力仍被 H 截断并由回退降级，"承诺失效"不再等于"物理事故"。
2. **认知健全性**：任何不可逆承诺满足 (EV-probe\*∨EV-margin) ∧ E_σ 可行 ∧ tier≥tier_req ∧ 区域非 disputed ∧ 证据非 revoked；T0 证词只能以 w_test 进入 P_fail，不能单独授权。
3. **公地遏制**：一次失败被观测后，Cul(f) 与 Dep\*(Cul) 在 T_rev 内于全舰队失效；残余风险 ≤ (未复现证词比例) × b(c) / |𝒢|，且 disputed 区在判别探针前不产生承诺。
4. **交互单调性扩展**：力矩预算与包络只会使动作更保守（E 变紧、步态降档、绕行、安全停）；复现只可能降权（未复现 ⇒ 降为证词），独立复现成功最多恢复其应有等级，不提供"更敢赌"的通道；第 57 轮三个机制仍只经"信念更准或动作更保守"两条安全通道作用。
5. **终止性**：每检查点共识探针 ≤k_cons、复现预算 ≤k_rc，PCE++ 在 k_probes+k_cons+k_rc 内终止于 {承诺, 绕行, L2 协商, 安全停}。

**部署界**（对检查点与证据图取联合界）：

```
P_safe ≥ 1 − Σ_cp [ δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1] ]
             − δ_kernel − δ_fb − δ_rc·|T0 证据占比|
             − P(blame 归属错误) − P(撤销未在 T_rev 内传播) − P(内核 attestation 伪造)
```

关键：**认知证书给"该不该踩"，物理包络给"最多多大力"，两者解耦**——坏先验只能让承诺更频繁地失败在物理层，而不能让物理层放大伤害；**可复现把"证据"与"证词"分开**——不可复现的观测不再享有证据权重；**公地治理把"一次错误"限制在依赖闭包内**——blame + revert 让坏证据的寿命从"永久"变成"T_rev"。

## 6. 本轮最大风险

**一句话**：本轮把安全的最终裁定权下沉到一个实时力矩内核与一个"可复现"验证器网络——若这两者本身共享同一缺陷或被同一供应链污染（全舰队用同一个内核、同一个仿真器判定复现成功），所有机器人会以高度一致且自信的方式同时通过全部检查；必须以异构冗余内核、硬件硬限、独立验证器多样性、按爆炸半径分级审查与灰度回滚，确保"验证者自己也要被验证"。
