> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v23+IP-431–439（其上承 v22 分层 PGEV/机械臂/深度感知、v21 语义-规范层 SDC/CAC/DCL/GIC、v20 联邦感知证书、v19 证书体系 DCM/OGCC/CCV/DRS/OGC、v17 感知链 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**证书不是离线证明，而是带运行时前提的契约；执行不是单步动作，而是可中断的动作块**。不推倒 v23：HDL/ACSC/DCSC/HPC-E/CESC/FSVC/IPAM/HPC-E+ 全部保留。本轮只做一件事：**把 v23 的"离线可证"证书体系落地为"部署期可持续监控"的契约，并把执行原子单位从单步动作升级为带可中断性证明的动作块，同时封堵 v23 的最大风险（版本一致性与统计覆盖在协同故障下的共振崩塌）**。

## 0. 直觉与动机

**灵感 1（场景落地 → 证书是带前提的契约，落地是前提的持续监控）**
直觉：v23 的所有证书——conformal 覆盖、κ_c 召回下界、FewShotValid、CloudEdgeSync——都是**离线分布假设下的证明**。但"落地"意味着机器人离开标定集，进入真实场地：光照变了、地面摩擦变了、人的行为变了、网络抖了、维护人员换了。此时证书的形式仍然成立，其经验前提却已悄悄失效。场景落地教给我们的核心不是"再加一个模块"，而是**给每张证书显式挂上它的操作设计域（Operational Design Domain, ODD）前提，并把"落地"重新定义为"前提的持续监控与分级放行"**。核心创新：**操作设计域证书（Operational Design Domain Certificate, ODDC）+ 部署分级门（Deployment Graduation Gate, DGG）+ 现场覆盖监控（Field Coverage Monitor, FCM）**。关键反直觉点：**部署不是一个二元事件（部署/未部署），而是一条证书许可的偏序链——影子→监督→域内自主→域扩展，每一级的晋升都由现场证据门控，任一级证据退化立即降级**。这把"落地"从一次性工程变成可审计、可回滚的证书状态机。副产品：ODD 条件化 conformal（按 ODD 分层做 Mondrian conformal）直接封堵 v23 的最大风险——分布漂移导致覆盖跌破而无人察觉。

**灵感 2（动作分块 → 执行原子单位是可中断的动作块）**
直觉：v23（乃至所有前序版本）默认"每一步动作单独认证、单独执行"。但现代机器人学习（ACT、Diffusion Policy）普遍采用**动作分块（action chunking）**：一次预测未来 H 步动作，开环执行一段，以降低复合误差、保留人类演示的多模态性、提升时序平滑。分块对安全性是**双刃剑**：它提升任务成功率与平滑度，却**牺牲反应性**——机器人"承诺"了一段动作，期间世界可能已经变了（有人闯入）。核心创新：**时序分块证书（Temporal Chunk Certificate, TCC）+ 安全分块聚合器（Safe Chunk Aggregator, SCA）+ 反应断点监控器（Reactive Breakpoint Monitor, RBM）**。关键反直觉点（本轮最漂亮的数学）：**"可中断性"不需要逐点验证，只需整条动作块的可达管（reachable tube）落在"安全停机不变集" I 内**——由控制不变集理论，`Tube_δ(π) ⊆ I` 自动蕴含"块内任意前缀都能安全中止"。于是动作分块的承诺与安全框架的反应性不再矛盾，而是统一为**"在不变集内承诺，在不变集外中断"**。

**两者如何统一**
场景落地回答"证书在什么前提下才算数、谁来监控前提"，动作分块回答"执行的原子单位是什么、如何保证块内可中断"。统一为 **v23 之上的"部署-执行"层**：ODDC 给所有证书挂 ODD 前提，FCM 在运行时监控前提，DGG 按证据分级放行；TCC 把执行单位升级为带不变集证明的动作块，SCA 保证重叠块聚合不越界，RBM 在开环执行期做反应断点。共享状态 `ζ_ce` 扩展为 **`ζ_dep = ζ_ce ∪ (o_t, ODD_cert, stage, field_cov, π_chunk, I_v23, Tube_δ(π), abort_set, dossier_root)`**。统一准入门：**HPC-D = (HPC-E+, TCC, ODDC, DGG) 四证一体**——只有"v23 全证 ∧ 动作块可中断（TCC）∧ 处于认证 ODD 内（ODDC）∧ 当前部署级别允许自主（DGG）"才进入执行；任一缺失按固定偏序保守退化，再退 v23/v22/…/v18。

## 2. 设计原则（在 P34–P42 基础上新增 P43–P45）

**P43 分块可中断律（Chunk Interruptibility Law）**
动作块 `π_{t:t+H}` 可执行当且仅当其**带不确定性的可达管**落在 v23 的安全停机不变集内：
`TCC(π) ≜ Tube_δ(π, x_t) ⊆ I_v23`，其中 `I_v23` 是受控不变集（从其中任意点都存在长度 ≤ B 的已认证安全中止序列 `β`）。由不变集性质，`Tube ⊆ I` 自动蕴含块内**任意前缀**都能安全中止（anytime interruptibility），无需逐点验证。故 `Exec_v24 = Exec_v23 ∩ Fil_chunk ⊆ Exec_v23`。**承诺的边界就是不变集的边界**。

**P44 聚合保守律（Aggregation Conservatism Law）**
时序集成必须保持 `I` 的成员性：只在凸内近似 `I_cert ⊆ I_v23` 内做加权平均；当重叠块聚合点越出 `Tube_cert` 时，改用**交集/最保守选择**（取安全裕度最大者），绝不跨越不变集边界做平均；若各块可容许集的交为空 → RBM 立即中止。故聚合永不把两条安全轨迹"平均"成一条不安全轨迹。

**P45 场景前提律（ODD Precondition Law）**
每张证书 `C` 携带前提 `o_t ∈ ODD_C` 且 `field_cov_C(t) ≥ 1-α`（分层覆盖）。证书有效 ⟺ 前提成立且覆盖维持；ODD 退出或覆盖跌破 ⇒ 证书作废 ⇒ 确定性回退（缩短块长 / ODD-generic 保守模式 / 影子模式 / 安全停机）。部署级别构成偏序链 `SHADOW ⊑ SUPERVISED ⊑ AUTONOMOUS ⊑ EXPANDED`，晋升由 DGG 谓词 + 滞回门控，降级即时生效。故任意失效都向更保守方向退化，`Exec_v24 ⊆ Exec_v23`。

## 3. 与基线的接口（如何退化）

- **TCC 失效**（可达管模型不可信 / δ 无法标定）⇒ 退回单步认证（H=1），等价 v23（更保守）；
- **SCA 失效**（聚合不可证）⇒ 不做时序集成，仅执行最新块首步，等价 v23；
- **RBM 失效**（断点监控不可用）⇒ 强制 H=1 并提高控制频率，比 v23 更保守；
- **ODDC/FCM 失效**（ODD 不可判定）⇒ 视作 ODD 外，进入 ODD-generic 保守模式（全局限速 + 人距上限）⇒ 子集；
- **DGG 失效**（分级状态不可信）⇒ 回落到 SHADOW（只建议不执行）⇒ 执行集为空，子集；
- **HPC-D 任一证缺失** ⇒ 取交集，向 v23 退化 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`（引理 8）。
- **安全继承**：TCC 只做可达管包含检查（子集）、SCA 只在凸不变集内聚合（不扩张）、RBM 只提前中止（不延长）、ODDC/FCM 只作废证书（不新增自由空间）、DGG 只限制自主级别（不放宽）；任意失效都向更保守方向退化。

## 4. 预期贡献

1. **部署即契约**：首次把 ODD 前提 + 现场覆盖监控 + 分级放行形式化为证书的运行时契约，使"落地"成为可审计、可回滚的证书状态机；

## 5. 本轮最大风险

**一句话**：动作块的"可中断性"证明依赖可达管模型（sim-to-real 动力学误差界 δ）的准确性，若 δ 被低估，TCC 会形式成立而物理上不可中止，机器人在"可审计地承诺"一段它来不及中断的动作块——即"可中断性幻觉"；叠加 ODD 监控自身的漏检，落地场景会把这一幻觉放大为真实碰撞。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Temporal Chunk Certificate (TCC) — 分块可中断证书
# ============================================================
@dataclass
class ChunkCertificate:
    chunk_id: str
    H: int
    tube: "Tube"            # Tube_δ(π, x_t) 外近似
    invariant: "InvariantSet"  # I_v23
    delta: float            # sim-to-real 动力学误差界（标定）
    abort_budget: int       # B
    margin: float           # min_{k} dist(Tube_k, ∂I_v23)

    def admits(self) -> bool:
        # 1) 可达管整体落在不变集内
        if not self.tube.subset_of(self.invariant):
            return False
        # 2) 每个前缀都存在长度 ≤ B 的安全中止序列（不变集性质保证）
        for k in range(self.H + 1):
            if not self.invariant.has_safe_abort(self.tube.at(k), self.abort_budget):
                return False
        # 3) 反应窗口须覆盖承诺窗口：τ_react ≤ τ_commit（否则开环期不可救）
        return self.margin >= 0.0


class TemporalChunkCertificate:
    def __init__(self, invariant: "InvariantSet", delta: float,
                 B: int = 10, dt: float = 0.02):
        self.invariant = invariant
        self.delta = delta
        self.B = B
        self.dt = dt

    def reachable_tube(self, x0, chunk, dynamics_hat, delta) -> "Tube":
        """对学习动力学 dynamics_hat 做 δ-膨胀的可达管外近似。
        采用区间/椭球传播：Tube_{k+1} = f_hat(Tube_k, a_k) ⊕ Ball(delta)。
        外近似保证：真实轨迹必落在 Tube 内（δ 有效时）。"""
        tube = Tube.from_point(x0)
        for a in chunk:
            tube = dynamics_hat.propagate(tube, a).minkowski_sum(delta)
        return tube

    def certify(self, x0, chunk) -> ChunkCertificate:
        tube = self.reachable_tube(x0, chunk, self.dynamics_hat, self.delta)
        margin = self.invariant.distance_to_boundary(tube)
        return ChunkCertificate(
            chunk_id=chunk.id, H=len(chunk), tube=tube,
            invariant=self.invariant, delta=self.delta,
            abort_budget=self.B, margin=margin)

    def choose_horizon(self, x0, model_sampler, perf_fn, safety_fn, H_max=32):
        """在安全约束下最大化任务性能的块长：
        H* = argmax_H perf_fn(H)  s.t.  safety_fn(H) ∧ τ_react(H) ≤ τ_commit(H)。
        单调性：H 越大 Tube 越可能越界 → 存在安全上界 H_safe。"""
        best, best_score = 1, -float("inf")
        for H in range(1, H_max + 1):
            chunk = model_sampler(x0, H)
            cert = self.certify(x0, chunk)
            if cert.admits():
                score = perf_fn(H)
                if score > best_score:
                    best, best_score = H, score
        return best


# ============================================================
# IP-441 Safe Chunk Aggregator (SCA) — 安全时序聚合
# ============================================================
class SafeChunkAggregator:
    def __init__(self, invariant: "InvariantSet", convex_inner: "InvariantSet"):
        self.I = invariant
        self.I_cert = convex_inner      # 凸内近似，保证平均封闭

    def aggregate(self, overlapping_chunks, weights=None):
        """重叠块时序集成。默认加权平均，但仅在 I_cert 内合法。"""
        actions = [c.action_at_current_time() for c in overlapping_chunks]
        weights = weights or [1.0 / len(actions)] * len(actions)
        avg = sum(w * a for w, a in zip(weights, actions))

        # 若平均点仍在凸不变集内 → 安全（凸性 + 不变性）
        if self.I_cert.contains(avg) and all(self.I_cert.contains(a) for a in actions):
            return avg

        # 越界：改用交集/最保守选择——取安全裕度最大者
        candidates = [a for a in actions if self.I_cert.contains(a)]
        if not candidates:
            raise AbortSignal("aggregation_empty_intersection")
        return max(candidates, key=lambda a: self.I.distance_to_boundary(a))

    def aggregate_with_guard(self, chunks):
        try:
            return self.aggregate(chunks)
        except AbortSignal:
            # 交集为空 → 交由 RBM 触发安全停机
            return None


# ============================================================
# IP-442 Reactive Breakpoint Monitor (RBM) — 反应断点监控
# ============================================================
class ReactiveBreakpointMonitor:
    def __init__(self, tcc: TemporalChunkCertificate, oddc: "ODDCertificate",
                 heartbeat_timeout: float = 0.1):
        self.tcc = tcc
        self.oddc = oddc
        self.heartbeat_timeout = heartbeat_timeout

    def watch(self, state, executing_chunk, last_heartbeat, now):
        """开环执行期逐 tick 调用；返回 True 表示必须提前中止。"""
        # 1) 实际状态越出认证可达管 → 模型失配，立即中止
        if not executing_chunk.tube.contains(state):
            return True, "tube_breach"
        # 2) 心跳超时（感知/证书链断流）
        if now - last_heartbeat > self.heartbeat_timeout:
            return True, "heartbeat_lost"
        # 3) ODD 退出 → 证书作废
        if not self.oddc.contains(state.odd_features):
            return True, "odd_exit"
        # 4) 反应预算耗尽：剩余承诺窗口 < 反应窗口
        remaining = executing_chunk.remaining_time(now)
        if remaining < self.tcc.reaction_window():
            return True, "reaction_budget_exhausted"
        return False, "ok"

    def abort(self, state):
        """执行已认证的安全中止序列 β（长度 ≤ B），而非硬急停。"""
        return self.tcc.invariant.safe_abort(state, self.tcc.B)


# ============================================================
# IP-443 Operational Design Domain Certificate (ODDC)
# ============================================================
class ODDCertificate:
    def __init__(self, domain: "ODDDomain", alpha: float = 0.01,
                 margin: float = 0.0):
        self.domain = domain            # ODD_C：认证覆盖的域
        self.alpha = alpha
        self.margin = margin

    def contains(self, o) -> bool:
        """ρ_odd(o) ≤ margin 即在域内（O(1) 判定：查表/凸包/核密度）。"""
        return self.domain.membership_margin(o) <= self.margin

    def conditional_conformal(self, o, scores_by_stratum):
        """ODD 条件化（Mondrian）分位数：按分层取 (1-α) 分位数，
        保证每个 ODD 层内覆盖，而非仅边缘覆盖。"""
        stratum = self.domain.stratum(o)
        return scores_by_stratum[stratum].quantile(1 - self.alpha)


# ============================================================
# IP-444 Deployment Graduation Gate (DGG) — 部署分级门
# ============================================================
class DeploymentGraduationGate:
    STAGES = ["SHADOW", "SUPERVISED", "AUTONOMOUS", "EXPANDED"]

    def __init__(self, fcm: "FieldCoverageMonitor", alpha=0.01,
                 min_samples=1000, max_intervention=0.02, max_violations=0,
                 hysteresis=0.1):
        self.fcm = fcm
        self.alpha = alpha
        self.min_samples = min_samples
        self.max_intervention = max_intervention
        self.max_violations = max_violations
        self.hysteresis = hysteresis
        self.stage_idx = 0

    def may_execute(self) -> bool:
        """仅 AUTONOMOUS 及以上允许机器人自主执行。"""
        return self.stage_idx >= self.STAGES.index("AUTONOMOUS")

    def evaluate(self, cov, interv, viol, n) -> int:
        """晋升/降级谓词。降级即时，晋升带滞回。"""
        # 降级条件（任一）
        if viol > self.max_violations or cov < (1 - self.alpha):
            self.stage_idx = max(0, self.stage_idx - 1)
            return self.stage_idx
        if interv > self.max_intervention:
            self.stage_idx = max(0, self.stage_idx - 1)
            return self.stage_idx
        # 晋升条件（全部满足 + 滞回）
        if (n >= self.min_samples and cov >= (1 - self.alpha + self.hysteresis)
                and interv <= self.max_intervention and viol == 0):
            self.stage_idx = min(len(self.STAGES) - 1, self.stage_idx + 1)
        return self.stage_idx


# ============================================================
# IP-445 Field Coverage Monitor (FCM) — 现场分层覆盖
# ============================================================
class FieldCoverageMonitor:
    def __init__(self, oddc: ODDCertificate, alpha=0.01, window=5000):
        self.oddc = oddc
        self.alpha = alpha
        self.window = window
        self.buffers = defaultdict(lambda: deque(maxlen=window))  # stratum -> (score, err)

    def update(self, o, score, err):
        stratum = self.oddc.domain.stratum(o)
        self.buffers[stratum].append((score, err))

    def coverage(self, o) -> float:
        """该 ODD 分层的现场经验覆盖（Hoeffding 下界）。"""
        stratum = self.oddc.domain.stratum(o)
        buf = self.buffers[stratum]
        n = len(buf)
        if n < 30:
            return 0.0
        q = self.oddc.conditional_conformal(o, self._quantiles())
        emp = sum(1 for s, e in buf if e <= q) / n
        return emp - math.sqrt(math.log(1 / 1e-3) / (2 * n))

    def maintain(self, o) -> bool:
        """返回 False 表示覆盖跌破 → 触发重校准/降级。"""
        return self.coverage(o) >= 1 - self.alpha


# ============================================================
# IP-446 Compliance Dossier Compiler (CDC) — 合规卷宗编译
# ============================================================
class ComplianceDossierCompiler:
    CLAUSES = {
        "ISO 10218-1": ["risk_assessment", "safety_functions", "stop_functions"],
        "ISO/TS 15066": ["power_force_limits", "speed_separation", "hand_guiding"],
        "ISO 3691-4": ["operational_zone", "speed_limits", "manual_override"],
        "EU AI Act Art.14": ["human_oversight", "intervention_log", "traceability"],
    }

    def compile(self, cert_chain: list) -> dict:
        evidence = defaultdict(list)
        for cert in cert_chain:
            for std, feats in self.CLAUSES.items():
                for f in feats:
                    if cert.satisfies(f):
                        evidence[std].append((cert.id, f, cert.proof_hash))
        root = merkle_root([h for ev in evidence.values() for _, _, h in ev])
        return {"evidence": evidence, "dossier_root": root,
                "signed": sign(root, key=COMPLIANCE_KEY)}


# ============================================================
# IP-447 HPC-D 统一四证准入门
# ============================================================
@dataclass
class HPCD:
    hpc_e_plus: "HPCEPlus"
    tcc: TemporalChunkCertificate
    oddc: ODDCertificate
    dgg: DeploymentGraduationGate
    fcm: FieldCoverageMonitor

    def admits(self, x0, chunk, o, modules) -> bool:
        # 1) v23 全证（物理/规范/负信息/能量/云边/少样本/IP）
        if not self.hpc_e_plus.admits_chunk(chunk, modules):
            return False
        # 2) 分块可中断
        if not self.tcc.certify(x0, chunk).admits():
            return False
        # 3) ODD 前提 + 现场分层覆盖
        if not self.oddc.contains(o):
            return False
        if not self.fcm.maintain(o):
            return False
        # 4) 部署级别允许自主
        if not self.dgg.may_execute():
            return False
        return True


# ============================================================
# 端到端：部署-执行流水线（在 v23 流水线上扩展）
# ============================================================
class DeploymentExecutionPipeline(PerceptionComplianceEnergyPipeline):
    def __init__(self, config):
        super().__init__(config)
        self.oddc = ODDCertificate(config["odd_domain"], alpha=config["alpha"])
        self.fcm = FieldCoverageMonitor(self.oddc, alpha=config["alpha"])
        self.dgg = DeploymentGraduationGate(self.fcm)
        self.tcc = TemporalChunkCertificate(
            invariant=config["invariant"], delta=config["delta"])
        self.sca = SafeChunkAggregator(config["invariant"], config["invariant_convex"])
        self.rbm = ReactiveBreakpointMonitor(self.tcc, self.oddc)
        self.hpcd = HPCD(self.hpc_e_plus, self.tcc, self.oddc, self.dgg, self.fcm)
        self.cdc = ComplianceDossierCompiler()

    def step(self, sensor_data, chunk_candidates, cloud_update=None):
        o = sensor_data["odd_features"]
        # 1) 现场覆盖更新
        for s, e in sensor_data["field_errors"]:
            self.fcm.update(o, s, e)
        # 2) 安全聚合（重叠块）
        chunk = self.sca.aggregate_with_guard(chunk_candidates)
        if chunk is None:
            return False, {"reason": "aggregation_abort"}
        # 3) HPC-D 四证准入
        if not self.hpcd.admits(sensor_data["x"], chunk, o,
                                self._modules_in_plan(chunk)):
            return False, {"reason": "hpcd_denied"}
        # 4) 开环执行 + RBM 逐 tick 监控
        for k in range(len(chunk)):
            state = self.execute_one(chunk.action[k])
            abort, why = self.rbm.watch(
                state, self.tcc.certify(sensor_data["x"], chunk),
                sensor_data["heartbeat"], state.t)
            if abort:
                return False, {"reason": why, "abort": self.rbm.abort(state)}
        # 5) 部署分级评估（后台低频）
        self.dgg.evaluate(self.fcm.coverage(o), sensor_data["intervention_rate"],
                          sensor_data["violations"], sensor_data["n_field"])
        # 6) 合规卷宗（每块一次，异步）
        self.cdc.compile(self.certificate_chain())
        return True, {"stage": self.dgg.stage_idx, "coverage": self.fcm.coverage(o)}
```

## 3. 正确性论证

### 引理 5（可达管⊆不变集 ⇒ 任意时刻可中断）
**陈述**：若 `Tube_δ(π, x_t) ⊆ I_v23` 且 `I_v23` 是受控不变集（∀x∈I，∃长度≤B 的安全中止序列 β 使后继始终在安全集内并终止于停机），则对块内任意前缀 k∈[0,H]，存在长度≤B 的安全中止序列。

**证明**：
1. 可达管定义为真实轨迹的外近似：δ 有效时，`x_{t+k} ∈ Tube_k`。
2. `Tube_k ⊆ Tube ⊆ I_v23`，故 `x_{t+k} ∈ I_v23`。
3. 由 `I_v23` 的受控不变性，从 `x_{t+k}` 存在已认证中止序列 β_k（长度≤B）保持安全并停机。
4. 对任意 k 成立 ⇒ anytime interruptibility。∎

### 引理 6（安全聚合保持不变集成员性）
**陈述**：若 `I_cert ⊆ I_v23` 为凸集，且各重叠块当前动作 `a_i ∈ I_cert`，则加权平均 `ā = Σ w_i a_i ∈ I_cert`；当 `ā ∉ I_cert` 时 SCA 取最保守候选 `a* ∈ I_cert`，故聚合输出始终在 `I_cert ⊆ I_v23` 内。

**证明**：
1. 凸集对凸组合封闭 ⇒ `ā ∈ I_cert`（当所有 `a_i ∈ I_cert`）。
2. 若存在 `a_i ∉ I_cert`，SCA 不取平均，改取 `argmax_{a∈I_cert} dist(a, ∂I)`，其仍在 `I_cert`。
3. 若 `{a_i} ∩ I_cert = ∅`，抛 AbortSignal，RBM 安全停机，不输出任何越界动作。
4. 因此任何路径下输出 ∈ `I_cert ⊆ I_v23`，不会"平均出危险"。∎

### 引理 7（ODD 前提 + 分层覆盖 ⇒ 部署期覆盖）
**陈述**：若对每个 ODD 分层 s 有 `field_cov_s ≥ 1-α`（Hoeffding 下界），且 `o_t ∈ ODD_C`，则部署期证书覆盖满足 `P(err ≤ ε̂ | o_t) ≥ 1-α`。

**证明**：
1. Mondrian conformal 在每个分层 s 上独立校准，分位数 `q̂_α(s)` 满足层内覆盖 ≥1-α（标准分层 conformal）。
2. FCM 用 Hoeffding 下界估计层内经验覆盖，扣除统计波动后仍 ≥1-α 才判 `maintain=True`。
3. `o_t ∈ ODD_C` 确保 `o_t` 所属分层在认证域内，分位数有效；ODD 退出即作废，不回退到域外外推。
4. 故部署期覆盖在每个 ODD 层内成立。∎

### 引理 8（部署-执行单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：
- TCC 失效 ⇒ H=1，退化为 v23 单步认证 ⇒ 子集。
- SCA 失效 ⇒ 仅取最新块首步，等价 v23 ⇒ 子集。
- RBM 失效 ⇒ 强制 H=1 + 提高频率 ⇒ 更保守。
- ODDC/FCM 失效 ⇒ ODD 外保守模式（限速+人距）⇒ 子集。
- DGG 失效 ⇒ SHADOW（不执行）⇒ 执行集为空。
- 组合失效取交集，单调性保持。∎

### 定理（HPC-D 四证门的安全-可部署-可审计完备性）
**陈述**：对任意动作块 π，`HPCD.admits(π)=True` ⟺ π 同时满足：
(1) v23 全证（物理/规范/负信息/能量/云边/少样本/IP）；
(2) 分块可中断（`Tube_δ ⊆ I_v23`）；
(3) 处于认证 ODD 内且现场分层覆盖 ≥1-α；
(4) 当前部署级别允许自主执行。

**证明**：直接由 `HPCD.admits` 的四个连言条件与引理 5–8 可得。必要性：任一缺失即拒证，对应一类未被缓解的风险。充分性：四条件全满足，由引理 5 保证块内可中断、引理 6 保证聚合不越界、引理 7 保证部署覆盖、引理 8 保证单调退化链，构成完整闭环。∎
