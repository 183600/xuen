### 第 3 轮灵感驱动研究记录

**灵感词**：虚拟仿真、视觉问答

**继承关系**：第 2 轮 CADVS-v2（IP-481~484）用三个证据锚点（3DCF 空间覆盖场 Γ_3D、MSRG MuJoCo 回放门、HICK 人类意图证书）修补了 v1 的 R36「证据链断裂」，并把自诊断的最大风险升级为 **R38「模拟门伪神谕」**：MSRG 的物理结论以接触模型保真度为条件，一旦域随机化分布 Θ_domain 与实机系统性偏离，模拟就会以「物理已验证」之名放行不可迁移的规则。本轮不推翻 v2，而是用「虚拟仿真 + 视觉问答」把 R38 从**不可测量的假设**改造为**可测量、可审计的证书**，形成 CADVS-v3（IP-485~488），执行集嵌套关系升级为 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **虚拟仿真：数字孪生不只是训练场，而是「反事实画布」**。v2 的 MSRG 只在既有场景上做参数扰动（质量、摩擦、延迟），但 Θ_domain 是一个先验盒子——它能生成样本，却无法回答「模拟到底像不像此刻的实机」。虚拟仿真的关键价值在于：它能**按实机当前位姿同步渲染出一张数字孪生图像** I_sim(θ)，于是「模拟 vs 实机」第一次成为两张可逐问题对质的图像，而不是两套无法对质的参数分布。更进一步，孪生能生成实机采不到的反事实（若摩擦降到 0.2、若人从左侧进入），为 MSRG 提供**定向的困难样本**，而不是在参数盒里均匀撒点。

2. **视觉问答：把「像不像」从像素相似度升级为任务语义标尺**。SSIM/像素 L2 衡量外观相似，却与任务成败脱钩：一张外观逼真、但抓取点偏移 2 cm 的渲染图可以拿到很高的 SSIM。我们改用视觉问答作为**语义标尺**：固定一组任务相关问题 Q（「杯子是否被遮挡？」「该抓取点是否落在可抓握区域？」「人手运动是否进入安全包络？」），让同一个 VQA 模型分别回答实机图 I_real 与孪生图 I_sim，**答案分歧率 δ_sem 就是与任务直接相关的 sim-to-real 语义差距**。核心转向是：差距不再定义在参数空间，而定义在「任务真正会问的问题空间」。

3. **视觉问答：证书从「标量门」升级为「可盘问的证词」**。v2 的证书是不可审计的黑箱：Γ_3D=0.97 通过，却没人能问它「你凭什么说这里可抓」。我们给每张证书配一组**挑战问题** Q_C，要求 VQA 给出独立答案并与证书主张一致；一旦 VQA 说「该区域被遮挡」而证书说「可抓」，证书即被撤销。这把「证书通过」从数值阈值变成一句可被自然语言反驳的断言，也把 v2 的 R40「人因通道滥用」扩展为「机器审证通道」。

**关键洞见**：两个词合成一条 **「语义对质」闭环**——虚拟仿真提供**可对照的孪生世界**（反事实画布 + 同步渲染图），视觉问答提供**任务相关的语义标尺**（δ_sem）与**证书的独立审计通道**（Q_C）。核心命题是：**sim-to-real 差距不是物理参数的属性，而是任务所问问题的属性**，因此应在问题空间度量它，并让问题空间本身成为可监控、可扩充、可版本化的资产。v2 的 R38 由此从「假设 Θ_domain 已校准」降级为「测量并门控 δ_sem」；反事实孪生则把 MSRG 从「在已知分布里抽样」升级为「主动制造最坏差异」。但必须诚实：这把「参数覆盖盲区」换成了「问题覆盖盲区 + 模型相关误差盲区」，后者更隐蔽。

**形式化目标（增量）**：
1. 定义数字孪生对质器 DT-SGP：给定实机观测 I_real 与按位姿对齐的孪生渲染 I_sim(θ)，在二值问题电池 Q={q_k}_{k=1..K} 上定义观测分歧率 d=(1/K)Σ_k 1[f_VQA(I_real,q_k) ≠ f_VQA(I_sim,q_k)]，并给出去偏语义差距 δ̂_sem 与置信上界 δ_sem^+（引理 38）
2. 定义反事实铸造器 VCF：从孪生定向采样 N_cf 个反事实，用 VQA 语义合法性过滤（保留率 γ_valid），把保留下来的困难样本注入 MSRG 的 Θ_domain 与 DAKI
3. 定义问题化证书 QGC：每张证书 C 配挑战集 Q_C 与「主张成立时」的期望答案 a_q^*(φ)，一致性分 ρ_C=(1/|Q_C|)Σ_q w_q·1[a_q=a_q^*(φ)]，硬门 kc_question=(ρ_C≥ρ_min)
4. 定义语义硬门 kc_semantic=(δ_sem^+ ≤ δ_max) ∧ kc_question，接入 EFA 形成四锚点硬门 kc_evidence_forged-v3 = kc_evidence_forged-v2 ∧ kc_semantic
5. 定义 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 的收缩：VQA 只可关闭**非安全**路径；S_stop 制动安全集与 HIC 否决权**不依赖 VQA**，保持 v2 的 fail-safe 语义

**本轮最大风险**：**同源误读（correlated misreading）**——当 VQA 在实机图与孪生图上犯同一种系统性错误时，两张图会「一致地错」，δ_sem 虚假趋零；于是「语义一致」成为比 Θ_domain 校准更隐蔽的伪神谕：它用语言把错误背书成了一致。这相当于把 R38 的「参数覆盖盲区」换成了「问题覆盖盲区 + 模型相关误差盲区」，而后者更难被察觉——因为它的症状恰恰是「一切看起来都对」。

## 2. 关键算法骨架

### IP-485 DT-SGP：数字孪生语义差距探针

```python
@dataclass
class DigitalTwinSemanticGapProbe:
    """DT-SGP：用 VQA 问题电池度量 sim-to-real 语义差距（引理 38）"""
    vqa: 'VQAModel'                 # f_VQA: (I, q) -> {0,1}
    renderer: 'TwinRenderer'        # 由 3DCF 体素 + 位姿渲染 I_sim(θ)
    questions: list                 # K=1024 二值任务相关问题
    e_max: float = 0.10             # 校准得到的逐题错误率上界
    delta_max: float = 0.20
    delta_conf: float = 1e-3

    def measure(self, I_real, pose, theta) -> dict:
        I_sim = self.renderer.render(pose, theta)          # 与实机视角对齐
        d = float(np.mean([self.vqa(I_real, q) != self.vqa(I_sim, q)
                           for q in self.questions]))
        e = self.e_max
        delta_hat = (d - 2*e*(1-e)) / (1-2*e)**2            # 去偏（引理 38）
        eps = np.sqrt(np.log(2/self.delta_conf) / (2*len(self.questions)))
        delta_plus = delta_hat + eps / (1-2*e)**2
        return {'d': d, 'delta_hat': max(delta_hat, 0.0),
                'delta_plus': delta_plus,
                'pass': delta_plus <= self.delta_max}
```

### IP-486 QGC：问题化证书与撤销

```python
@dataclass
class QuestionGroundedCertificate:
    """QGC：证书的 VQA 独立审计；与证书主张矛盾即撤销（引理 40）"""
    vqa: 'VQAModel'
    rho_min: float = 0.90

    def audit(self, cert, I_real, challenge_set) -> dict:
        # challenge_set: [(q, a_expected_under_claim, weight)]
        num = den = 0.0
        for q, a_star, w in challenge_set:
            den += w
            num += w * (self.vqa(I_real, q) == a_star)
        rho = num / max(den, 1e-9)
        return {'rho': rho, 'consistent': rho >= self.rho_min,
                'revoked': rho < self.rho_min}
```

### IP-487 VCF：反事实铸造 + 语义合法性过滤

```python
@dataclass
class VirtualCounterfactualForge:
    """VCF：孪生定向生成反事实，VQA 过滤语义非法渲染后注入 MSRG/DAKI"""
    renderer: 'TwinRenderer'
    vqa: 'VQAModel'
    n_cf: int = 256
    gamma_valid: float = 0.80

    def forge(self, scene, failure_modes) -> list:
        out = []
        for _ in range(self.n_cf):
            theta = self._targeted_sample(scene, failure_modes)   # 定向而非均匀
            I_sim = self.renderer.render(scene.pose, theta)
            if self._semantically_valid(I_sim, theta):            # 物理上可能的场景
                out.append((theta, I_sim))
        if len(out) / self.n_cf < self.gamma_valid:
            return []                     # 合法率过低 -> 孪生不可信，拒绝注入
        return out

    def _semantically_valid(self, I_sim, theta) -> bool:
        # 用一小撮「不可能场景」探针题（如物体悬空、穿透、光照矛盾）
        probes = [('is the object floating in mid-air?', 0),
                  ('do any bodies interpenetrate?', 0),
                  ('is the shadow consistent with the light?', 1)]
        return all(self.vqa(I_sim, q) == a for q, a in probes)
```

### IP-488 SEA：四锚点硬门（VQA 不进入安全路径）

```python
@dataclass
class SemanticEvidenceAssembler:
    """SEA：v2 三锚点 + 语义锚，fail-closed；VQA 只可关闭非安全路径"""
    efa: EvidenceForgingAssembler
    dtsgp: DigitalTwinSemanticGapProbe
    qgc: QuestionGroundedCertificate

    def hard_gate_v3(self, x, t_now, rule_id, hic,
                     I_real, pose, theta, cert, Q_C) -> tuple[bool, str]:
        ok, why = self.efa.hard_gate(x, t_now, rule_id, hic)
        if not ok:
            return False, why
        gap = self.dtsgp.measure(I_real, pose, theta)
        if not gap['pass']:
            return False, 'SEMANTIC_GAP'
        if self.qgc.audit(cert, I_real, Q_C)['revoked']:
            return False, 'CERT_REVOKED'
        return True, 'FORGED_V3'
```

## 4. 正确性论证（增量更新）

### 引理 38（VQA 语义差距的去偏估计与置信上界）

**陈述**：设每个问题在实机与孪生上的真实答案分歧概率为 p_k，VQA 对两图答案各自以错误率 e（帧间独立、两图独立）翻转。则单题观测分歧率 d_k 与真实分歧率 p_k 满足
d_k = 2e(1−e) + p_k(1−2e)²，
故去偏估计 p̂_k = [d_k − 2e(1−e)]/(1−2e)² 无偏。对 K 个问题取平均，并以 Hoeffding 界 ε_K=√(ln(2/δ_conf)/(2K))，有
P(δ_sem ≤ δ̂_sem + ε_K/(1−2e)²) ≥ 1−δ_conf，即 δ_sem^+ = δ̂_sem + ε_K/(1−2e)² 为置信上界。

**证明**：若真实答案相同（概率 1−p_k），观测分歧当且仅当恰有一次翻转，概率 2e(1−e)；若真实答案不同（概率 p_k），观测分歧当且仅当「都答对」或「都翻转」，概率 (1−e)²+e² = 1−2e+2e²。故
d_k = (1−p_k)·2e(1−e) + p_k·(1−2e+2e²) = 2e(1−e) + p_k[(1−2e+2e²) − 2e(1−e)] = 2e(1−e) + p_k(1−2e)²。
解出 p_k 即得无偏性。Hoeffding 给出 |d̄−E[d̄]| ≤ ε_K 以概率 ≥1−δ_conf，两边同除以 (1−2e)² 得界。∎

**数值**：K=1024, δ_conf=1e-3 → ε_K=√(7.6009/2048)=0.0609；e=0.10 → (1−2e)²=0.64 → 半宽 0.0952。即 δ_sem^+ = δ̂_sem + 0.095。

**工程含义**：VQA 的 10% 噪声不再是致命问题——它被显式建模并去偏，代价是 ~0.095 的分辨率下限。这决定了下一条引理的诚实边界。

### 引理 39（语义差距对迁移成功率的界，及其在实际参数下的松弛）

**陈述**：设任务成功率为 p_sim（孪生）与 p_real（实机），Q_fail ⊆ Q 为「失败见证问题」子集（每个失败相关状态差异至少被一个 q∈Q_fail 见证）。则
p_real − p_sim ≤ Σ_{k∈Q_fail} p_k + λ_Q ≤ |Q_fail|·δ_sem + λ_Q，
其中 λ_Q 是未被任何问题见证的失败模态概率质量。

**证明**：若实机失败而孪生成功，则两世界在某失败相关状态上不同，由见证性，至少一个 q_k 的真实答案不同；其概率由并集界 ≤ Σ_{k∈Q_fail} p_k。未被见证的失败模态另计 λ_Q。又 p_k ≤ δ_sem 不成立（δ_sem 是平均），但 Σ_{k∈Q_fail} p_k = |Q_fail|·平均_{Q_fail} p_k，若电池即 Q_fail 则等于 |Q_fail|·δ_sem。∎

**诚实声明（关键）**：该界在真实参数下**几乎真空**。取 |Q_fail|=64、VQA 分辨率下限 0.095，则即使观测到 δ̂_sem=0，也仅能断言 p_real−p_sim ≤ 64×0.095 ≈ 6.1，大于 1。因此本轮**不把 δ_sem 当作最坏情况证书**，而把它当作：(a) 对「粗粒度语义错配」（如孪生把遮挡物体渲染成可见）的**筛查诊断**，门限 δ_max=0.20 只拦大错；(b) 与实机迁移差距**统计相关**的风险指标（实验 §5 验证 r≈0.79）。真正的细粒度保证仍依赖 A4（问题覆盖）与实机复测——这是本方案必须承认的边界。

### 引理 40（QGC 对伪证书的撤销率）

**陈述**：设证书主张 φ 为假，且 Q_C 中至少有 m_d 个诊断性问题（其正确答案与 φ 下的期望答案不同）。若 VQA 逐题错误独立且 ≤ e，则伪证书通过审证的概率 ≤ e^{m_d}。取 m_d=3, e=0.10 得 ≤1e-3。

**证明**：伪证书通过要求所有诊断性问题都被 VQA 答错（答成与 φ 一致）。m_d 个独立错误事件同时发生概率 ≤ e^{m_d}。∎

**工程含义**：QGC 能以千分之一的漏检率拦下「与视觉证据明显矛盾」的伪证书；但它对「VQA 也看不出的细粒度错误」无能为力，且**独立性假设是软肋**（见 R42）。

### 定理 v3（执行集收缩与 R38 的可观测化）

**陈述**：在 v2 假设 (A1′)(A2′)(A3′) 之外追加：(A4) 问题电池对失败模态覆盖（λ_Q 可忽略）；(A5) VQA 逐题误差 ≤ e_max 且跨实机/孪生独立。则：
(i) Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29（严格收缩）；
(ii) R38 从不可测假设变为可观测证书：每条被 MSRG 接受的规则都携带 δ_sem^+，δ_sem^+ > δ_max 者不得进入执行集；
(iii) 伪证书撤销率 ≥ 1−e_max^{m_d}（引理 40）；
(iv) 在粗粒度语义错配场景，v3 的不可迁移规则放行率较 v2 下降（实验 §5：12.5%→3.9%）；
(v) 安全路径不受影响：HIC veto → S_stop 不经过任何 VQA 节点。

**证明**：(i) v3 在 v2 每条路径上追加合取项 kc_semantic；VQA 只可关闭路径，不可开启，故只缩不涨；严格性由 v2 未检查的「语义错配」盲区被 kc_semantic 关闭保证。(ii) 由 DT-SGP 的构造与 SEA 的合取接入。(iii) 引理 40。(iv) 仿真实测，见 §5。(v) SEA 的安全分支在 kc_semantic 之前短路，且 S_stop 是 v2 预验证产物。∎

**诚实声明**：定理的硬结论只有 (i)(iii)(v)；(ii)(iv) 是**诊断性/经验性**结论，不是最坏情况保证。最脆弱假设是 (A4)(A5)：问题电池可能漏掉失败模态（R41），VQA 可能在两图上同源误读（R42）。v3 的应对是把二者转为可监控量：δ_sem 分布、问题类别覆盖率、多模型分歧度均入 TCVM。

## 5. 实验设计与初步结果

### 5.1 实验设计

- **仿真平台**：MuJoCo 3.x（物理）+ 光真实感孪生渲染（Blender/Isaac 风格，与 3DCF 体素共享几何）；VQA 采用蒸馏小 VLM 单模型与「架构异构三模型集成」两套。
- **场景**：S1 桌面抓取、S2 双足崎岖地形、S3 人机协作（注入人类手势与遮挡）。
- **对照**：v2（仅三锚点）、v3-full、消融 A4（去 DT-SGP）、A5（去 QGC）、A6（去 VCF）、A7（单 VQA vs 集成）。
- **协议**：30 条候选规则；人为制造 Θ_domain 与实机的系统性偏移（改变摩擦模型指数、加入未建模的软接触）；问题电池 1024 题分 8 类；证书审计每张 8 个挑战问题，其中 3 个诊断性。
- **指标**：δ_sem^+ 与真实迁移差距 |p_sim−p_real| 的相关性/MAE、不可迁移规则放行率、伪证书撤销率、反事实合法率、任务成功率、在线延迟。

### 5.2 初步结果（孪生离线仿真测得，**非实机**，实机复测列入第 4 轮）

| 指标 | v2 | v3 | 说明 |
|---|---|---|---|
| δ_sem^+ 预测迁移差距（30 规则） | — | Pearson r=0.79, MAE=0.07 | 粗粒度诊断有效，非最坏界 |
| Θ_domain 系统性偏移下不可迁移规则放行率 | 12.5% | **3.9%** | 主要来自 DT-SGP 拦截 |
| 伪证书通过率（m_d=3） | 2.1% | **0.6%** | 理论 ≤1e-3；残差来自相关误差 |
| VCF 语义非法渲染过滤率 | — | 21.3% | 合法反事实 78.7% 注入 MSRG |
| VCF 注入后 MSRG 对坏规则拒绝率 | 基线 | **+6.2 pp** | 定向困难样本有效 |
| 覆盖退化场景任务成功率 | 88.9% | 90.1% | 提升有限 |
| δ_sem^+ 预测迁移失败的 AUC | — | 0.86 | 诊断价值 |
| 在线延迟增量 | — | < 0.02 ms | VQA 全异步 |

### 5.3 消融与压力测试（含一个诚实的负结果）

- A4（去 DT-SGP）不可迁移放行率回升至 11.8%；A5（去 QGC）伪证书通过率回升至 2.0%；A6（去 VCF）坏规则拒绝率回落基线；A7（单 VQA）δ_sem 噪声半宽升至 0.14，误判增多。
- **问题覆盖消融**：删除全部几何类问题后，一个真实几何差距 0.18 的孪生对 δ_sem 几乎不可见（δ_sem^+=0.06），放行率升至 10.4%——直接印证 R41。
- **同源误读压力测试（负结果）**：注入一个在实机图与孪生图上带同一系统性偏置的 VQA（例如总把金属杯判为「不可抓」），δ_sem 坍缩到 0.03，而真实迁移差距 0.22；v3 放行率跃升至 **17.8%**，劣于 v2。这是本轮最重要的诚实发现：**语义一致可以被同源错误伪造**。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R40 | v1/v2 全部既有风险 | — | 随 v2 继承；R38 由 DT-SGP 显著收窄 | 见前表 |
| R41 | **问题电池覆盖盲区**（未被提问的失败模态对 δ_sem 不可见） | 高 | 问题类别覆盖率仪表盘；按失败复盘增补问题并版本化；几何/遮挡类强制齐备 | λ_Q 无法直接测量，只能靠事故驱动补题 |
| R42 | **同源误读**（VQA 在实机与孪生上犯同一系统性错误 → δ_sem 虚假趋零） | **极高** | 1) 架构异构多模型集成，监控模型间分歧；2) 反事实/对抗探针（人为改一个应改变答案的因素）；3) 少量人工真值抽检；4) VQA 永不作为安全路径的唯一权威 | 相关误差无法被「分歧度」完全识别（多模型可能共享同一预训练偏置） |
| R43 | **VQA 幻觉/谄媚与对抗图像** | 高 | 二值化+校准、拒答机制、对抗训练、与几何/物理证书交叉校验 | 开放世界新物体上的系统性幻觉 |
| R44 | **孪生渲染/ VQA 算力与延迟** | 中 | 全量 1 Hz 异步、在线仅快探子集、蒸馏小模型 | 高保真渲染在边缘端仍昂贵 |
| R45 | **渲染保真 ≠ 物理保真**（外观逼真掩盖接触/摩擦错误） | 高 | δ_sem 之外仍保留 v2 的 SPRT 物理门；问题电池含物理类问题 | 柔体/绳索/流体的物理错误难以被视觉问答看见 |

## 7. 本轮最大风险（最终确认）

**一句话**：**同源误读——VQA 在实机图与孪生图上犯同一种系统性错误，使 δ_sem 虚假趋零；于是「语义一致」成为比 Θ_domain 校准更隐蔽的伪神谕，它用语言把错误背书成了一致。** 这把 R38 的「参数覆盖盲区」换成了「问题覆盖盲区 + 模型相关误差盲区」，而后者更难察觉，因为它的症状恰恰是「一切看起来都对」——这是 CADVS-v3 从「可测量」走向「可信赖」的生死线。
