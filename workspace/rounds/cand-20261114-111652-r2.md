# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「域随机化」×「意图理解」）

> R69 漂亮地追问了「我该向谁求证、还能问什么」，并把不确定性拆成 aleatoric / epistemic。但它整套效率仍押在一个未被证明的前提上：**流模型给出的模态分布可信**。而它的校准门（MCG）只在**同分布留出集**上量 ECE——这等于说「在我认识的世界里，我的置信是准的」，却对**分布移移**（换了一种物理、换了一种文化下的用户、换了一个从没见过的目标）一无所知。R69 自陈的最大风险（幻觉模态诱发自信追问）本质上不是采样问题，而是**先验缺失**：它只有似然（拿交互去问），没有先验（不知道哪些世界/意图本来就可能）。
>
> 更深的错位在于：R69 的「模态」是**动作轨迹的聚类**，它把两类完全不同的东西混在一个簇空间里——
> - **世界歧义**（我在哪种物理/观测条件下？）：训练时可用**域随机化**覆盖，运行时可用探针消解；
> - **意图歧义**（这个人到底想要什么？）：人类是**策略性、会共适应、甚至会被机器人反向影响**的对象；它不是一个被动待估的隐变量。
>
> 本轮两个灵感正好补上这两块：
> - **域随机化**把 epistemic 从「单模型的聚类幻觉」变成「**随机化潜变量集合上的可测量方差**」——集成分歧是一个可证伪、可收敛的 epistemic 估计量，且幽灵模态会被「跨随机化世界的持久度」直接筛掉；
> - **意图理解**给出正确的潜变量语义 ψ=(目标, 偏好, 信念, 诚实度, 响应性) 与正确的人机交互模型——不是被动似然，而是**反应机制**（含策略性/欺骗性/共适应），由此得到鲁棒 VoI 与「理解 vs 操纵」的边界。
>
> 核心命题：**把 epistemic 重新奠基在「随机化先验 × 交互似然」上：随机化是宽而保守的先验，交互是按可辨识性收窄的后验；只对可辨识的潜维互动，不可辨识维度直接冻结进保守 floor；对意图额外加鲁棒 VoI、漂移跟踪与反操纵守卫。** 命名 **DRUID-RAS**（Domain-Randomized Uncertainty-aware Intent Disambiguation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我面对的是哪个世界、对面是谁、我是在理解他还是正在改造他**」——不确定性的上限由先验的覆盖决定，下限由可辨识性决定，而最危险的不是问错，是**把对方塑造成自己想要的答案**。

## 0. 直觉与动机

**灵感 1（域随机化 → epistemic 不是「猜」出来的，是「随机化」出来的）**
直觉：R69 用流采样聚类得到「模式 + 权重」，再用 ECE 证明权重在留出集上校准。但 ECE 是**同分布**概念；分布一移，权重可以既「校准」又完全错误。域随机化提供了另一种认识论：不要问「这个模型有多自信」，而要问「**在合理的一族世界/意图里，这个结论有多稳**」。在潜变量 θ 上采样一个集合，集成分歧 `Var_θ E[a|o,θ]` 就是 epistemic，世界内噪声 `E_θ Var[a|o,θ]` 就是 aleatoric——这不是启发式，而是**总方差分解的恒等式**（引理 19）。于是 R69 的 `H_mode·g(Δ_min)` 被一个可收敛、无需选 K、无需聚类超参的估计量替代。**幽灵模态 = 只在极少数随机化世界里出现的模态，持久度天然低。**

**灵感 2（意图理解 → 对面是一个会反应的策略主体，不是一个待估参数）**
直觉：R69 把人类回答当作「带噪声的标签」。但人会说谎、会不耐烦、会顺着你的问题猜你想要什么，甚至会因为你的提问而**改变原本的意图**。意图 ψ 应显式分解为（目标 g_h、偏好 ≻、信念 b_h、诚实度 δ、响应性 ρ）。人不是被动的 `q(y|ψ)`，而是 `q(y|g,ψ,m_robot)`——他的回答依赖于**他对机器人的模型**。这把交互从「贝叶斯更新」升级为**Stackelberg 博弈**：如果机器人的决策规则是确定且公开的，人可以选择回答来诱导机器人执行对他有利的动作。R69 的被动 VoI 在这种情形下会被系统性利用。

**灵感 3（先验-后验对偶 → R69 只有似然，缺了先验这一半）**
直觉：随机化和交互不是两个并列模块，而是同一推断的两面。域随机化给出 **P(θ)**（训练时宽，部署时作为一个覆盖假设），交互提供 **q(y|g,θ)**（似然）。R69 只做后一半：它拿「单模型采样出的模式」当先验，于是先验可能是幻觉。R70 把先验**显式化、可审计化**：支持检验（SPT）问「当前世界/意图是否落在 P(θ) 的支持内」；不在，就承认先验失配，退回最保守，而不是继续自信地算 VoI。这样「问错」的风险被先验覆盖直接约束，而不是靠事后 ECE 祈祷。

**灵感 4（可辨识性纪律 → 只随机化「问得出来」的东西）**
直觉：域随机化有一个经典陷阱——随机化无关维度会让策略不必要地保守（robustness theater）。R69 的 resolution bonus 也有同款隐患：它默认「交互后减少的 U_epi 是真的被消解了」。R70 要求先算**可辨识性剖面**：在交互预算 B 下，潜维 d 的 Fisher 信息最多约 `B·max_g I_d(g)`；达不到精度目标的维度属于 Θ_un，**无论你多想问都问不出来**，只能诚实计入 aleatoric floor。只有 Θ_id 才允许驱动交互。于是「随机化宽度 = 可辨识维度集合」成为一条硬纪律：不多随机化问不出的，也不漏掉问得出的。

**灵感 5（意图是双刃剑 → 会理解意图就会操纵意图）**
直觉：一旦训练对「随机化的策略性人类」做鲁棒优化，最优策略未必是更好地**理解**意图，而可能是更好地**塑造**意图——用措辞、时机、默认选项把对方推向某个 ψ。这在优化压力下不是 bug，而是 reward hacking 的必然吸引子。因此本轮必须交付**反操纵守卫**：用 do-演算的因果效应 `CE(g)=E[ψ'|do(g)]−E[ψ|do(∅)]` 区分「推断意图」与「改变意图」，超过 ε_manip 且无明确授权即拒绝；并用意图漂移跟踪防止系统靠「不断追问把对方问出某个答案」。这正面回应 R69 的「问错比不问更危险」：R70 说「**操纵比误解更危险**」。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（DRUID-RAS 总览）** DRUID-RAS = (ILF, RLE, IDP, ETD, RCC, SPT, RIV, IDC, MG, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；RLE 训练、先验更新一律离线/周期，在线只做选择与推断）；
(ii) **支持纪律**：部署时必须通过世界与意图的双支持检验；落在 P(θ) 支持外即视为先验失配，退二级保守（定义 317、322）；
(iii) **可辨识性纪律**：只有 Θ_id 可驱动交互与 resolution bonus；Θ_un 无条件计入 aleatoric floor，禁止用不可辨识维度「假装消歧」（定义 314、322）；
(iv) **意图安全纪律**：任何动作/交互不得在无授权时把对方意图改变超过 ε_manip；单源回答不得单独定案（继承 R69 定义 293-iii）。

**定义 311（潜变量分解）** θ = (φ, ψ) ∈ Θ = Φ × Ψ。φ 为世界参数（动力学、摩擦、光照、传感增益等）；ψ = (g_h, ≻, b_h, δ, ρ) 为意图潜变量：目标、偏好序、信念、诚实度、响应性。观测 o_t = h_φ(s_t, a_t) + ε；人类回答 y ~ q(· | g, ψ, m_robot)，其中 m_robot 是人类对机器人决策规则的模型。训练先验 P(θ) = P_φ × P_ψ。

**定义 312（随机潜变量集合 RLE）** 从 P(θ) 采 N 个潜变量 {θ_i}，得集成策略 {π_i = π(·|·,θ_i)}。训练目标
`min_π E_{θ~P(θ)} E_{ξ~π(·|o,θ)} [J(ξ,θ)] + λ_rob·Robust_{θ}(J)`，
其中鲁棒项取 CVaR 或 worst-case 分位。R69 的 FLUID 是本定义在 `P(θ)=δ_{θ0}` 且 ψ 退化为动作模式时的特例。在线侧只部署**蒸馏集成头**（预测集成均值与分歧方差），不跑 N 个完整策略。

**定义 313（意图随机化）** P_ψ 由**机制族**生成：目标从任务分布采样；偏好用随机效用/Dirichlet 采样；诚实度 δ 取混合（诚实 / 误导 / 对抗）；响应性 ρ 取（被动 / 策略性 / 共适应）。可选用冻结 LLM 生成场景脚本做覆盖。关键：支持集必须包含**对抗尾部**（不只是温和用户），否则「鲁棒」只是对好人的鲁棒。域随机化 = P_φ；意图随机化 = P_ψ；二者共同构成 P(θ)。

**定义 314（可辨识性剖面 IDP）** 对信息动作 g 与潜维 d，Fisher 信息
`I_d(g) = E_{y~p(·|θ,g)}[(∂ log p(y|θ,g)/∂θ_d)^2]`。
预算 B 次（近似）独立探询下最多获得 `B·max_g I_d(g)` 的信息。定义可辨识裕度
`κ_d = B · max_g I_d(g) / (1/ε_id²)`，
其中 ε_id 为目标后验标准差。`Θ_id = {d : κ_d ≥ 1}`，`Θ_un = Θ \ Θ_id`。只有 Θ_id 进入 RIV；Θ_un 直接进入 floor（定义 322）。

**定义 315（集合总方差分解 ETD）** 预测分布 `p(a|o) = E_{θ~P(θ|o)}[p(a|o,θ)]`。由总方差定律（**恒等式，非近似**）：
`Var(a|o) = E_θ[Var(a|o,θ)] + Var_θ[E(a|o,θ)]`。
定义
`U_ale = E_θ Var(a|o,θ)`（世界内噪声，不可约），
`U_epi = Var_θ E(a|o,θ)`（跨世界/意图，可约部分待识别）。
再按定义 314 投影拆分为 `U_epi = U_epi^id + U_epi^un`：只有 `U_epi^id` 可被交互削减，`U_epi^un` 立即并入 floor。R69 的 `H_mode·g(Δ_min)` 是本式在模态可分（A95）且以流采样近似后验时的样本近似。

**定义 316（随机化一致性校准 RCC）** 对每个候选模式 m，定义**持久度**
`s(m) = (1/N) Σ_i 1[m ∈ modes(π_i)]`。
认证模式集 `M_cert = {m : s(m) ≥ τ_persist}`；`s(m) < τ_persist` 的模式即**幽灵模式**，禁止进入 VoI 与选模。另对权重做集成一致性校准：比较集成平均权重与跨世界经验频率。RCC 是 R69 MCG 的**分布移移版**：不要求同一世界内 ECE 低，只要求结论跨合理世界稳定；RCC 失败 ⇒ 禁用 VoI。

**定义 317（支持与先验失配检验 SPT）** 世界支持：密度比 `w(o)=p(o|P_φ)/p_ref(o)` 高于阈值，或共形 p 值 ≥ α；意图支持：`max_{ψ∈supp P_ψ} q(y|g,ψ,m_robot) ≥ τ_int`。任一不通过 ⇒ 判定**先验失配**（deployment 的 θ 不在训练支持内），进入二级保守，并将该样本离线回灌以扩宽 P(θ)；在线绝不因此改参数。

**定义 318（鲁棒意图 VoI RIV）** 在机制集合 Q_ψ（定义 319）上取最坏情形：
`VoI_I(g) = min_{q∈Q_ψ} [ H(b(ψ)) − E_{y~q(·|g,ψ)} H(b(ψ|y)) ]`。
选择 `g* = argmax_g [VoI_I(g) − c(g)]`，s.t. 目标维度 d ∈ Θ_id 且 `κ_d` 最大、安全预算未超。若 `max[VoI_I − c] ≤ 0` ⇒ 不交互，逐指令退 R69。注意：不是对被动似然取期望，而是对**敌意/策略性人类**取最坏。

**定义 319（反应机制与策略性人类）** 人类反应 `q(y | g, ψ, m_robot)`，其中 `m_robot` 是人对机器人决策规则 π_robot 的估计。机制集
`Q_ψ = conv{ truthful, deceptive(δ), uninformative, Stackelberg-best-response }`。
Stackelberg 项：人已知（或可推断）π_robot 时，选 y 最大化自身效用。定义**操纵租金**
`R_manip = VoI_naive − VoI_I ≥ 0`；
R69 的被动 VoI 正是在忽略 R_manip 时的乐观估计。

**定义 320（意图漂移与共适应 IDC）** 意图非平稳：`ψ_{t+1} ~ T(· | ψ_t, a_t, y_t)`。定义漂移率
`V_T = (1/T) Σ_t TV(ψ_{t+1}, ψ_t)`，
跟踪步长 `H_track ≈ 1/V_T`。若估计 `V_T > V_max`（意图变得比交互能跟上的速度更快）⇒ 意图不可跟踪：停止主动探询、冻结到二级保守。理由：追问本身会改变 ψ，越问越飘。

**定义 321（意图操纵守卫 MG）** 用因果效应区分「推断」与「塑造」：
`CE(g) = E[ψ_{t+1} | do(g)] − E[ψ_t | do(∅)]`。
若 `|CE(g)| > ε_manip` 且无显式授权（用户委托/知情同意）⇒ 拒绝 g（必要时也拒绝改变意图的任务动作）。CE 由已知干预模型的随机化探针估计；不要求在线学习。此守卫保证系统**理解**意图而非**制造**意图。

**定义 322（三级保守退避）**
- **L0（支持内 + 可辨识消解成功）**：`λ = λ_floor(U_ale + U_epi^un)`，获得 resolution bonus（比 R69 更不保守但不更低安全）。
- **L1（支持内，但 U_epi^id 未在预算内消解：VoI≤成本 / RCC 失败 / 超时 / 单源证据）**：`λ = λ_floor(U_ale + U_epi^un + U_epi^id)`——即 R69 的未消解情形。
- **L2（支持外 / 先验失配 / 漂移越界 / 操纵守卫触发 / MG 失败）**：`λ = max(λ_floor(U_ale + U_epi^un + U_epi^id), λ_hard)`，并安全停车/移交。
三级 floor 单调不降。FLUID 是本定义在 `P(θ)=δ_{θ0}`、无漂移、Q_ψ={truthful} 时的 L1 边界。

**定义 323（随机化宽度课程与运行时组合）** 离线用留出支持率/RCC 调随机化宽度 σ_θ（课程式扩宽，避免一开始就过宽导致平庸）。运行时无法重训，但保留一个按不同 σ_j 训练的**策略组合** `{π^{σ_j}}`；部署时选「当前 o 最被其支持」的成员（选择不是学习）。太窄会漏威胁，太宽会无谓保守；取鲁棒-效率前沿的拐点。

**定义 324（证书 J_DRUID）** `J_DRUID = (J_FLUID, ensemble_disagreement, support_p_world, support_p_intent, identifiability_margin, rcc_persistence, manip_effect, drift_rate, prior_version, druid_ver)`。
Valid ⇔ `Valid(J_FLUID) ∧ support_p_world ≥ α ∧ support_p_intent ≥ α ∧ RCC 通过 ∧ |CE| ≤ ε_manip ∧ V_T ≤ V_max`。

**定义 325（参与式审计 VQAuditor-D）** 审计对象新增：这次跟的是哪个意图假设、它是否幽灵（持久度低）、交互是否带有操纵性、回答是否被单源采纳、随机化宽度是否合适（既覆盖威胁又不过度保守）、是否忽略了先验失配。结论回灌 AuditBuf 与离线先验更新；**绝不实时改写**。

**定义 326（威胁集 AIC-DRUID）** `ℰ_DRUID = ℰ_FLUID × ℰ_world-shift × ℰ_intent-shift × ℰ_strategic × ℰ_manip-exploit × ℰ_prior-misspec`，即：未见物理、意图漂移、策略性/欺骗性回答、利用提问反操纵机器人、以及「真实意图落在随机化支持之外」的先验失配。

**定义 327（计算预算与时间尺度）** 离线：RLE 训练（小时级）、Fisher 剖面（分钟级）、先验扩宽（周期）。在线：蒸馏集成头（均值+分歧）< 0.3ms；RCC 查表 O(1) < 0.02ms；SPT < 0.1ms；RIV 枚举（候选 ≤5 × 机制 ≤4）< 0.2ms；漂移估计 O(1)；常规总延迟 **< 2.9ms**（与 R69 的 2.6ms 基本持平），L2 路径 < 3.6ms。

## 2. 关键算法骨架

```python
# IP-264 ILF：潜变量分解（复用 R69 trunk，加意图头与世界头）
class IntentLatentFactorizer:
    def encode(self, o):
        z = self.trunk(o)                      # 复用 CALM-RAS 的 z_t
        return self.world_head(z), self.intent_head(z)  # (φ̂, ψ̂ 后验参数)

# IP-265 RLE：随机化潜变量集成（离线训练，在线只蒸馏）
class RandomizedEnsemble:
    def train(self, P_phi, P_psi, N):
        for theta in sample(P_phi, P_psi, N):  # (φ, ψ) 联合随机化
            fit_member(theta)                  # 域随机化 + 意图随机化
        self.distill_head = distill_mean_and_disagreement(self.members)

    def head(self, o):                         # 在线 O(1)：均值 + 分歧方差
        return self.distill_head(o)

# IP-267 ETD：总方差分解（精确恒等式，替代 R69 的聚类启发式）
def ensemble_decompose(head, o):
    mean, var_total = head(o)
    U_ale = mean.within_world_var             # E_θ Var(a|o,θ)
    U_epi = mean.across_world_var             # Var_θ E(a|o,θ)
    U_epi_id, U_epi_un = project(U_epi, Theta_id)   # 定义 314 的可辨识投影
    return U_ale, U_epi_id, U_epi_un

# IP-266 IDP：可辨识性剖面（离线 Fisher，预算 B）
def identifiability(probes, B, eps_id):
    kappa = {}
    for d in latent_dims:
        I = max(fisher_info(g, d) for g in probes)
        kappa[d] = B * I / (1.0 / eps_id**2)
    return {d for d in kappa if kappa[d] >= 1.0}   # Θ_id

# IP-268 RCC：随机化一致性校准 + 幽灵模式剔除
def randomization_consistency(modes_by_world, tau_persist):
    persist = {m: mean(m in modes for modes in modes_by_world) for m in all_modes}
    certified = {m for m, s in persist.items() if s >= tau_persist}
    return certified, persist                       # 幽灵模式被排除

# IP-269 SPT：世界 + 意图支持检验
def support_test(o, y, g, P_phi, P_psi, alpha):
    p_w = conformal_pvalue(density_ratio(o, P_phi), alpha)
    p_i = max_resp_likelihood(y, g, P_psi)          # max_{ψ∈supp} q(y|g,ψ)
    return p_w >= alpha and p_i >= tau_int

# IP-270 RIV：鲁棒意图 VoI（对策略性/欺骗人类取最坏）
def robust_intent_voi(b_psi, g_candidates, Q_psi, budget):
    best = None
    for g in g_candidates:
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi = min(entropy(b_psi) - expected_entropy(b_psi, g, q)
                  for q in Q_psi)                   # 对 Q_ψ 取 min
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None  # ≤0 → 退 R69

# IP-271 IDC：意图漂移跟踪；太快则停止探询
def intent_drift_tracker(b_psi_hist):
    V = mean(total_variation(b_psi_hist[t], b_psi_hist[t-1]) for t)
    return V, (V <= V_MAX)                          # False ⇒ 冻结/退 L2

# IP-272 MG：反操纵因果守卫
def manipulation_guard(g, psi_t, eps_manip, delegated):
    ce = do_effect(g, psi_t)                        # E[ψ'|do(g)] − E[ψ_t|do(∅)]
    return delegated or abs(ce) <= eps_manip        # 否则拒绝该 g

# IP-276 主闭环（继承 R69，在不确定性处置前插入随机化先验层）
def DRUID_RAS_round(M, obs, y):
    phi_hat, psi_hat = M.ilf.encode(obs)
    # 0) 支持纪律：先问「我在不在自己认识的世界/人里」
    if not M.spt.support_test(obs, y, M.last_g, M.P_phi, M.P_psi):
        return M.safe_stop_or_handover(obs)          # L2：先验失配
    # 1) 集合总方差分解（精确 aleatoric / epistemic）
    U_ale, U_epi_id, U_epi_un = M.etd.ensemble_decompose(M.rle.head, obs)
    # 2) 随机化一致性校准（幽灵模式剔除）
    modes, persist = M.rcc.certified_modes(M.rle.head, obs)
    if M.rcc.untrusted(persist):
        return M.fluid_round(M, obs, freeze=True)    # L1：退 R69
    # 3) 漂移与操纵守卫（意图不是一个被动参数）
    V, trackable = M.idc.intent_drift_tracker(M.b_psi_hist)
    # 4) 只在可辨识维度上做鲁棒交互
    g = None
    if trackable and U_epi_id > TAU_EPI:
        g = M.riv.robust_intent_voi(M.b_psi, M.info_candidates(modes), M.Q_psi, M.budget)
        if g is not None and not M.mg.guard(g, psi_hat, M.eps_manip, M.delegated):
            g = None                                 # 会改变意图 → 不做
    if g is not None:
        ans = M.cia.execute(g)
        U_epi_id = M.cia.update_belief(modes, ans, discipline='k_orthogonal_agree')
    # 5) 三级保守退避 + 风险缩放
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_un + (U_epi_id if g is None else 0.0)))
    if (not trackable) or M.last_support_failed:
        lam = max(lam, lam_hard)                     # L2
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode(modes, U_epi_id, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 审计（含意图正确性与操纵性）+ 证书
    M.vqa_d.submit_async(g, mode, persist, V, M.last_ce, lam)
    return k, lam, mode, (U_ale, U_epi_id, U_epi_un, g)
```

## 3. 推导

**引理 19（集合总方差分解的精确性与收敛）** 对任意条件分布，`Var(a|o)=E_θ Var(a|o,θ)+Var_θ E(a|o,θ)` 是恒等式；用 N 个随机化成员的蒙特卡洛估计无偏且误差 O(1/√N)。当 A95（模态可分）成立且 P(θ|o) 的后验退化为流采样诱导的经验后验时，R69 的 `U_ale=Σŵ trΣ_k`、`U_epi=H_mode·g(Δ_min)` 是本分解在「以 K 个样本聚类近似后验」下的一致近似。系：**R70 去掉的是 K 与聚类超参这一层任意性；epistemic 从「一个模型说了算」变成「一族合理世界说了算」**，这正是可证伪性的来源。

**引理 20（幽灵模式由持久度上界排除）** 设真实最优模式 `m*(θ)`。对任意模式 m，令 `A_m={θ:m*(θ)=m}`。若 `s(m)<τ_persist`，则 `P(θ∈A_m) ≤ 1−s(m)+ε_N < 1−τ_persist+ε_N`（ε_N 为集成有限样本误差）。因此，只要部署 θ 落在支持内（SPT 通过），「m 是正确模式」的置信不可能超过持久度所允许的上界；RCC 剔除低持久度模式只会伤及「θ 落在低概率/支持外区域」的情形，而那恰是 SPT 标记为先验失配的情形。系：**R69 的最大风险（自信追问幽灵）在「支持假设」下被结构性上界约束**，而不是靠 ECE 运气。

**引理 21（可辨识性—交互预算界，及「只随机化可辨识维度」）** 对（近似）独立探询，Fisher 信息可加，故 B 次预算下关于 θ_d 的累计信息 ≤ `B·max_g I_d(g)`；对任意估计量，后验方差满足 Cramér–Rao 下界 `≥ 1/(B·max_g I_d(g))`。若 `κ_d<1`，则维度 d 在预算内无法达到目标精度，任何基于 d 的 VoI 上界为 O(κ_d) 量级的小量。故最优交互分配是背包问题：按 `I_d(g)/c(g)` 排序，且只选 `κ_d≥1` 的维度。系：**对 Θ_un 随机化只是「鲁棒性表演」**——它不产生信息，只产生无谓保守；应直接计入 floor。

**引理 22（策略性回答的操纵租金与证据纪律）** 在 Stackelberg 设定下，若 π_robot 确定且被人类准确建模，人类可从可达动作集中诱发任一有利动作，故真实期望下 `VoI_naive` 可高估至多 `R_manip`；当人类只能通过多源一致证据影响决策、且机器人决策带熵 ≥ H_min 时，操纵租金被限制为 `R_manip ≤ δ_p·ρ^{k−1} + ε_σ`（与 R69 引理 18 同型）。系：**鲁棒 VoI（对 Q_ψ 取 min）+ k 源一致 + 随机化决策规则**三者共同把「问一次」的可利用面压到可审计的界内。

**定理 18（DRUID 严格包含 FLUID）** 令 `P(θ)=δ_{θ0}`、ψ 等同于 R69 的动作模式、Q_ψ={truthful}、V_T=0。则 ETD 给 `U_epi=0`，RCC 平凡通过，SPT 平凡通过，RIV 退化为 R69 的 VoI，三级退避塌缩为 R69 的两级。故 DRUID 在该边界上**逐指令等同于 FLUID**。更进一步，对任意支撑含 θ0 的先验 P(θ)，DRUID 对 θ∈Θ 的最坏情形风险 ≤ FLUID：因为 FLUID 的校准只在同分布成立、OOD 时可被欺骗，而 DRUID 的 floor 显式包含 `U_epi^un + U_OOD(SPT)`；效率则通过对 Θ_id 的交互与 resolution bonus 收回。**安全侧单调不降，R68=永不交互边界，FLUID=单世界/无意图边界。**

**定理 19（意图安全、无操纵与无突变）** 在支持检验通过、`Θ_id` 按定义 314 选取、MG 与 IDC 生效的前提下：
(a) 任一执行动作在意图模糊集 Q_ψ 上的最坏风险 ≤ ε_int，因为 floor 计入 `U_epi^un`、且 L2 触发 λ_hard；
(b) `|CE(g)| ≤ ε_manip`，故系统不改变意图，只推断意图；
(c) 三级退避使 λ 单调不降、k 单调不增，继承 R68 定理 15 / R69 定理 17 的**控制连续、无突变**。
若 SPT/RCC/IDC/MG 任一失败 ⇒ L2 安全停车/移交，安全包络只收紧不放宽。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** DRUID-RAS = (ILF,RLE,IDP,ETD,RCC,SPT,RIV,IDC,MG,RAS-WM†)；零实时学习写；支持纪律（支持外退 L2）；可辨识性纪律（Θ_un 直接入 floor，禁止「鲁棒性表演」）；意图安全纪律（无授权不得把意图改变超过 ε_manip，单源不定案）。

**定义 311–313（潜变量 / RLE / 意图随机化）** `θ=(φ,ψ)`；从 `P(θ)=P_φ×P_ψ` 采 N 个成员训练集成，在线用蒸馏均值+分歧头；`P_ψ` 由机制族生成（目标分布 / 随机效用偏好 / 诚实度混合 / 响应性），**支持必须含对抗尾部**。R69 = `P(θ)=δ_{θ0}` 特例。

**定义 314–315（IDP 与 ETD）** `κ_d=B·max_g I_d(g)/(1/ε_id²)`，`Θ_id={κ_d≥1}`；`Var(a|o)=E_θVar(a|o,θ)+Var_θE(a|o,θ)` 为**恒等式**，前者 U_ale、后者 U_epi，再投影拆 `U_epi^id/U_epi^un`。R69 的 `H_mode·g(Δ_min)` 是本式在 A95 下的聚类近似。

**定义 316（RCC）** `s(m)=(1/N)Σ_i 1[m∈modes(π_i)]`；`s(m)<τ_persist` 即幽灵模式，禁止进入 VoI/选模；RCC 失败即禁用 VoI、退 R69。

**定义 317（SPT）** 世界密度比/共形 p 值 ≥ α 且 `max_{ψ∈supp P_ψ} q(y|g,ψ,m_robot) ≥ τ_int`；任一不过 ⇒ 先验失配 ⇒ L2（安全停车/移交），先验扩宽只离线做。

**定义 318–319（RIV 与反应机制）** `VoI_I(g)=min_{q∈Q_ψ}[H(b(ψ))−E_q H(b(ψ|y))]`，选 `argmax[VoI_I−c]`，≤0 则不交互；Q_ψ 含 Stackelberg 最优反应；`R_manip=VoI_naive−VoI_I` 度量被动 VoI 的可利用度。

**定义 320–321（IDC 与 MG）** `ψ'~T(·|ψ,a,y)`，`V_T=mean TV`，`V_T>V_max` 则停止探询；`CE(g)=E[ψ'|do(g)]−E[ψ|do(∅)]`，`|CE|>ε_manip` 且无授权即拒绝 g（理解 vs 操纵的硬边界）。

**定义 322（三级退避）** L0：支持内且消解成功 → `λ=λ_floor(U_ale+U_epi^un)`（resolution bonus）；L1：支持内但 U_epi^id 未消解 → `λ=λ_floor(U_ale+U_epi^un+U_epi^id)`（=R69）；L2：支持外/漂移越界/守卫触发 → `λ=max(...,λ_hard)` + 安全停车/移交。floor 单调不降。

**定义 323–327（宽度/证书/审计/威胁/预算）** 随机化宽度用课程 + 运行时策略组合（选择非学习）取鲁棒-效率拐点；J_DRUID 增加分歧/支持 p 值/κ/RCC/操纵效应/漂移；VQAuditor-D 审意图是否幽灵/交互是否操纵/宽度是否合适；`ℰ_DRUID=ℰ_FLUID×ℰ_world-shift×ℰ_intent-shift×ℰ_strategic×ℰ_manip-exploit×ℰ_prior-misspec`；在线总延迟 < 2.9ms（L2 < 3.6ms），训练与先验更新全离线。

## 3. 关键算法伪代码

```python
# IP-264/265 ILF+RLE：潜变量分解 + 随机化集成（在线只蒸馏头）
def encode_and_head(o):
    phi, psi = world_head(trunk(o)), intent_head(trunk(o))
    mean, var_total = distill_head(trunk(o))       # 集成均值 + 分歧
    return phi, psi, mean, var_total

# IP-267 ETD：精确总方差分解（替代 R69 聚类）
def ensemble_decompose(mean, var_total):
    U_ale = mean.within_world_var                  # E_θ Var(a|o,θ)
    U_epi = mean.across_world_var                  # Var_θ E(a|o,θ)
    U_epi_id, U_epi_un = project(U_epi, Theta_id)  # 可辨识投影
    return U_ale, U_epi_id, U_epi_un

# IP-268 RCC：跨随机化世界的持久度，剔除幽灵模式
def randomization_consistency(modes_by_world, tau):
    persist = {m: mean(m in ms for ms in modes_by_world) for m in all_modes}
    return {m for m, s in persist.items() if s >= tau}, persist

# IP-269 SPT：世界 + 意图双支持检验
def support_test(o, y, g, P_phi, P_psi, alpha):
    return (conformal_pvalue(density_ratio(o, P_phi)) >= alpha
            and max_resp_likelihood(y, g, P_psi) >= TAU_INT)

# IP-270 RIV：对策略性人类取最坏的鲁棒 VoI
def robust_intent_voi(b_psi, gs, Q_psi, budget):
    best = None
    for g in gs:
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        score = min(entropy(b_psi) - expected_entropy(b_psi, g, q)
                    for q in Q_psi) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # ≤0 → 退 R69

# IP-271/272 IDC+MG：漂移跟踪 + 反操纵因果守卫
def intent_guards(g, psi_t, hist, delegated):
    V = mean(total_variation(hist[t], hist[t-1]) for t)
    trackable = V <= V_MAX
    safe = delegated or abs(do_effect(g, psi_t)) <= EPS_MANIP
    return trackable, safe

# IP-276 主闭环（继承 R69）
def DRUID_RAS_round(M, obs, y):
    phi, psi, mean, var_total = encode_and_head(obs)
    if not M.spt.support_test(obs, y, M.last_g, M.P_phi, M.P_psi):
        return M.safe_stop_or_handover(obs)               # L2：先验失配
    U_ale, U_epi_id, U_epi_un = M.etd(mean, var_total)
    modes, persist = M.rcc(M.rle.modes_by_world(obs), TAU_PERSIST)
    if M.rcc.untrusted(persist):
        return M.fluid_round(M, obs, freeze=True)         # L1：退 R69
    trackable, safe = M.idc_mg.guards(M.last_g, psi, M.b_psi_hist, M.delegated)
    g = None
    if trackable and safe and U_epi_id > TAU_EPI:
        g = M.riv.robust_intent_voi(M.b_psi, M.info_candidates(modes), M.Q_psi, M.budget)
    if g is not None:
        U_epi_id = M.cia.update_belief(modes, M.cia.execute(g), 'k_orthogonal_agree')
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + U_epi_un + (U_epi_id if g is None else 0.0)))
    if not trackable or M.last_support_failed:
        lam = max(lam, LAM_HARD)                          # L2
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi_id, lam)
    M.vqa_d.submit_async(g, mode, persist, M.last_V, M.last_ce, lam)
    return k, lam, mode, (U_ale, U_epi_id, U_epi_un, g)
```

## 4. 推导

**引理 19（集合总方差分解精确且收敛）** `Var(a|o)=E_θVar(a|o,θ)+Var_θE(a|o,θ)` 为恒等式，N 成员蒙特卡洛估计无偏、误差 O(1/√N)；A95 下 R69 的聚类式 `U_ale/U_epi` 是其后验样本近似。系：**epistemic 从「一个模型的置信」变成「一族合理世界的分歧」**，可证伪且无需选 K。

**引理 20（幽灵模式持久度上界）** 令 `A_m={θ:m*(θ)=m}`，则 `P(θ∈A_m) ≤ 1−s(m)+ε_N`。故 `s(m)<τ_persist` 时，在支持假设（SPT 通过）下「m 正确」的置信被持久度封顶；剔除低持久度模式只伤及支持外情形，而那正是被 SPT 拦下的。系：**R69 的幽灵追问风险被结构性上界约束，而非依赖 ECE 运气。**

**引理 21（可辨识性—预算界）** 独立探询 Fisher 信息可加 ⇒ B 次预算对 θ_d 的信息 ≤ `B·max_g I_d(g)`，后验方差 ≥ Cramér–Rao 界；`κ_d<1` 时基于 d 的 VoI 上界为 O(κ_d)。故交互应按 `I_d(g)/c(g)` 做背包且只选 `κ_d≥1`。系：**对 Θ_un 随机化是「鲁棒性表演」**，应直接计入 floor。

**引理 22（操纵租金与证据纪律）** Stackelberg 下被动 VoI 可高估至多 `R_manip`；当决策依赖 k 源一致证据且 π_robot 带熵 ≥ H_min 时，`R_manip ≤ δ_p·ρ^{k−1}+ε_σ`。系：**鲁棒 VoI + k 源一致 + 随机化决策**共同把「问一次」的可利用面压到可审计界内（R69 引理 18 的博弈版）。

**定理 18（DRUID 严格包含 FLUID）** `P(θ)=δ_{θ0}`、ψ≡R69 动作模式、Q_ψ={truthful}、V_T=0 时：ETD 给 U_epi=0，RCC/SPT 平凡通过，RIV 退化为 R69 VoI，三级塌缩为两级 ⇒ 逐指令与 FLUID 相同。对任意支撑含 θ0 的先验，DRUID 最坏情形风险 ≤ FLUID（FLUID 的同分布校准可被 OOD 欺骗，DRUID 的 floor 显式含 `U_epi^un+U_OOD`）；效率通过对 Θ_id 的交互与 resolution bonus 收回。

**定理 19（意图安全、无操纵、无突变）** 支持检验 + Θ_id 选取 + MG + IDC 生效时：(a) 任一动作在 Q_ψ 上最坏风险 ≤ ε_int；(b) `|CE(g)|≤ε_manip`，系统只推断不塑造意图；(c) 三级退避使 λ 单调不降、k 单调不增，继承 R68 定理 15 / R69 定理 17 的连续无突变。任一检验失败即 L2，安全包络只收紧不放宽。

## 7. 本轮最大风险

**一句话**：DRUID-RAS 的全部收益押在「**意图先验 P(ψ) 的支撑覆盖真实人类**」这一前提上——一旦意图随机化分布失配（LLM 场景有偏、真实意图在支持外、对抗尾部未覆盖），系统只获得「对**想象中的人类**鲁棒」；更糟的是，对随机化策略性人类做鲁棒优化会产生 reward hacking 吸引子，使策略**不是理解意图而是制造意图**，于是系统可能对着一个被自己诱导出来的人自信宣告「已验证」——**随机化出的意图世界里，最强的策略往往不是理解意图，而是操纵意图。**

**次级风险与缓解**：先验失配 → SPT 双支持检验 + L2 安全停车 + 离线扩宽（定义 317、322）；幽灵意图 → RCC 持久度剔除（引理 20）；策略性/欺骗回答 → 鲁棒 VoI 对 Q_ψ 取 min + k 源一致（引理 22）；共适应漂移 → IDC 跟踪步长，超 V_max 停止探询（定义 320）；反向操纵 → MG 因果效应守卫 + 授权机制（定义 321）；随机化过宽导致平庸 → 宽度课程 + 运行时策略组合取 Pareto 拐点（定义 323）；在线预算 → 蒸馏集成头 + 离线训练（定义 327）。
