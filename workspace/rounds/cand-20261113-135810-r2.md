# 第 68 轮（承接第 67 轮「SimRAS 仿真增强闭环」IP-233~242；本轮随机灵感：「行为克隆」×「基线复现」）

> 第 66~67 轮完成了能力的连续叠加：从「被动故障响应」→「主动意图感知」→「离线仿真预演 + 世界模型 + VQA 审计」。但这条能力链始终回避一个**计量学空白**：没有任何一轮回答过「**这套系统到底比一个最朴素的模仿基线好多少？这个『好』是可复现、可证伪的吗？**」。第 67 轮点名的 Sim2Real Gap 风险，本质上不是"仿真不够真"，而是**度量不可信**——当仿真、世界模型、VQA 三个黑箱同时参与，任何"更安全"的结论都既无法归因，也无法在另一台机器上重现。
>
> 本轮灵感的核心命题是：
>
> **给整条安全闭环装上「计量学底座」：用行为克隆（BC）从专家示范中克隆一个最诚实、最可复现的参考策略 π_BC 作为「零点/零假设」，用「基线复现」的契约把每一次能力宣称变成带置信区间的「处理效应」，并用 BC 的协变量偏移理论为认证前缀提供「示范支持域」这一可计算的保守边界。**
>
> 名字：**ReBC（Reproducible Behavior-Cloned Closure：可复现的行为克隆锚定闭环）**。它不追求更强的控制，而追求**更可信的比较**——把 VISTA/RAS/SimRAS 从"没有对照的工程堆叠"改造为"有零假设、有对照、有复现证书的科学实验"。

## 0. 直觉与动机

**灵感 1（行为克隆 → 最诚实的零假设）**
直觉：行为克隆是模仿学习里最"笨"的基线——没有奖励、没有模型、没有仿真，只有一个监督回归 `π_θ(a|s)`。恰恰因为笨，它**几乎无法作弊**：给定示范集与随机种子，它训练出什么就是什么，损失可以逐位复现。于是它天然适合充当整个安全栈的**零假设 H0**：任何 VISTA/RAS/SimRAS 的"改进"都必须相对 H0 定义为处理效应 `Δ = metric(stack) − metric(π_BC)`。若 Δ 的置信区间跨零，那么再精巧的闭环也只是复现了一个笨办法——此时奥卡姆剃刀应当生效。

**灵感 2（基线复现 → 可证伪的度量契约）**
直觉："基线复现"不是"再跑一遍"，而是一份**契约**：固定 seed 集、固定数据划分（按 episode 分组以防信息泄漏）、固定环境版本、固定确定性开关、固定指标套件；两次独立运行的指标差异必须落在容差 `τ_repro` 内，否则整个结论作废。这给前几轮缺失的**可证伪性**补上了操作定义：一个不能被复现的"安全提升"不是科学结论，只是叙事。

**灵感 3（协变量偏移 → 共享的安全边界）**
直觉：BC 最著名的失败模式是**协变量偏移/复合误差**——策略一旦进入示范分布之外，误差按 `O(T²)` 累积。这与 VISTA 的认证前缀风险、SimRAS 的 WM drift 在结构上完全同源：都是"当前状态是否还活在我见过的世界里"。因此 BC 不只是对照，它直接贡献一个**可计算的保守边界**：用示范集的 k-NN 支持域 `support(D_demo)` 判定"是否出界"，出界即触发与 `wm_drift` 同款的保守回退。BC 的理论不是负担，而是安全层的第三块拼图。

**灵感 4（三股合流 → ReBC 的四件仪器）**
ReBC 复用前几轮的时序骨架，把"能力层"降级为"被测量的处理"，新增四件"计量学仪器"：
1. **BCAnchor**：从 `D_demo` 克隆参考策略 `π_BC`，产出冻结的 `baseline_fingerprint`；
2. **DSGuard**：用示范支持域 `support(D_demo)` 与新颖度 `ν(s)` 检测分布外状态，输出 `shift_flag` 并触发保守回退；
3. **ReproContract**：把 seed/数据/环境/权重绑定为 `repro_hash`，提供 L0~L3 可复现等级与"复现门"；
4. **DeltaAuditor**：以配对 episode + bootstrap/Wilcoxon 计算 `Δ_metric` 的置信区间与效应量，产出可证伪的"处理效应报告"。

**灵感 5（对前几轮的降维打击）**
- **VISTA 的认证前缀**：多一条约束 `a_s ∈ E_ref(s)`（参考包络）与 `ν(s_t) ≤ τ_support`；
- **RAS 的 λ_risk**：支持域外直接把 λ_risk 钳到保守下界（与 `face_unobservable` 同构）；
- **SimRAS 的 WM 预测**：WM 滚动若离开支持域，`k_wm` 强制归零——世界模型的"想象"不能覆盖"没见过"；
- **全部证书 J**：新增 `bc_ref_hash / repro_hash / shift_flag / delta_report / repro_level`，形成"可复现安全证书"。

## 1. 形式化定义（增量：定义 266–290）

- **定义 266（ReBC 总览）**：`ReBC = (BCAnchor, DSGuard, ReproContract, DeltaAuditor, RefCert)`。定位：为 VISTA/RAS/SimRAS 提供「参考策略—支持域护栏—复现契约—处理效应审计」的计量学层。不变式：`π_BC` 与全部指标确定性可复现；在线只做 `π_BC` 前向、`ν(s)` 检测与安全回退，零学习写操作。
- **定义 267（专家示范集）**：`D_demo = {(s_i, a_i)}_{i=1}^N ~ P_demo`，`s_i ∈ S, a_i ∈ A`。按 episode 分组划分为 `D_tr / D_val / D_te`，满足 `episode(D_tr) ∩ episode(D_te) = ∅`（防时序泄漏）。
- **定义 268（行为克隆参考策略）**：`π_BC(a|s) = N(μ_θ(s), Σ_θ(s))`（连续动作）或 `softmax(f_θ(s))`（离散动作），`θ* = argmin_θ E_{(s,a)~D_tr}[ℓ(a, π_θ(s))]`。将 `θ*` 冻结后得到**参考动作** `a_BC(s) = μ_{θ*}(s)`。
- **定义 269（BC 误差界）**：单步误差 `ε_BC = E_{s~P_demo}[ℓ(a, π_BC(s))]`；在示范支撑内的 T 步复合误差满足 `E[ℓ(a_T, π_BC(s_T))] ≤ min(T²ε_BC, T·ε_BC/ (1−β))`，其中 β 是策略的收缩/稳定系数（Ross–Bagnell 界）。
- **定义 270（示范支持域）**：`support_τ = {s : ν(s) ≤ τ_support}`，其中新颖度 `ν(s) = dist_kNN(s, D_tr)` 为到示范集第 k 近邻的归一化距离。
- **定义 271（分布外护栏 DSGuard）**：`shift_flag_t = 1[ν(s_t) > τ_support]`。`shift_flag = 1` 时执行保守三元组：`(a) λ_risk ← max(λ_risk, λ_floor)`；`(b) k ← 0`（禁用前瞻/认证前缀外推）；`(c)` 仅在 `E_ref` 内执行并降低速度上限。
- **定义 272（参考行为包络）**：`E_ref(s) = {a : ||a − a_BC(s)||_{Σ^{-1}} ≤ δ_env(s)}`，`δ_env(s)` 随 `ν(s)` 单调收缩。认证前缀必须满足 `∀s ≤ k: a_s ∈ E_ref(s_s)`。
- **定义 273（可复现契约）**：`ReproContract = (seed_set, split_hash, env_version, determinism_flags, metric_suite)`。契约有效 ⇔ 五元组齐全 ∧ `split_hash` 与 `repro_hash` 一致 ∧ 确定性开关全开（或记录已知非确定性范围）。
- **定义 274（复现证书）**：`R_cert = (repro_hash, seeds, {metric_j: mean±std}, CI, repro_level)`。两次独立运行的指标差 `|m_j^{(1)} − m_j^{(2)}| ≤ τ_repro` 时该指标才算复现成功。
- **定义 275（可复现等级）**：L0 文档描述；L1 脚本可跑；L2 容器/环境锁定；L3 固定种子下逐位一致（bit-exact）。对外宣称的结论最低要求 L2，安全相关结论要求 L3。
- **定义 276（基线指纹）**：`baseline_fingerprint = hash(θ*, split_hash, env_version, seed_set)`，任何字段变化都必须重新签发指纹并重跑回归门。
- **定义 277（处理效应）**：`Δ_metric = metric(stack) − metric(π_BC)`，在**配对 episode** 上计算（同一场景、同一种子、仅策略不同），报告均值、bootstrap 95% CI 与效应量 Cohen's d。
- **定义 278（配对统计与功效）**：对配对差 `d_i` 做单侧 Wilcoxon 符号秩检验；达到功效 `1−β`、显著性 α 所需样本 `n ≥ 2(z_{1−α/2}+z_{1−β})² σ_d² / δ²`，其中 `σ_d` 是配对差标准差，δ 是待检最小效应。
- **定义 279（回归门）**：任何新增层 L 必须满足 `metric(L) ≥ metric(L_{prev}) − ε_reg` 且 `metric(L) ≥ metric(π_BC) + δ_min`（若声称改进），否则拒绝合并。
- **定义 280（安全地板）**：`S_BC = 1 − risk_rate(π_BC)`。若 `S_BC < S_floor`，则整条栈的"相对改进"在安全意义上无定义——因为参照系自身已不安全。
- **定义 281（消融阶梯）**：`Ladder = [BC, BC+VISTA, BC+RAS, BC+SimRAS, BC+ReBC]`，每级只允许增加一个组件，逐级报告 `Δ_metric ± CI`，禁止跨级跳报。
- **定义 282（参考漂移）**：`ref_drift = KL(π_BC^{new} || π_BC^{old})` 或权重相对 L2 差；`ref_drift > τ_ref` 时旧证书全部失效，须重跑基线复现。
- **定义 283（失败重放包）**：`replay_bundle = (obs_0:T, seed, env_state, env_version, baseline_fingerprint)`。任何失败样本必须可确定性重放，并支持"换成 π_BC 会怎样"的反事实回放。
- **定义 284（DAgger 扩展与查询预算）**：可选 `π_{i+1} = BC(D_tr ∪ D_i^{π_i})`，`D_i^{π_i}` 为策略 `π_i` 触发并由专家纠正的状态-动作对；必须显式记录查询预算 `Q_i` 与标注来源，且主基线仍以纯 BC 报告。
- **定义 285（支持域覆盖率）**：`coverage = P_{online}(ν(s) ≤ τ_support)`。要求 `coverage ≥ 0.95`，并单独报告**稀有高风险事件子集**上的覆盖率 `coverage_rare`。
- **定义 286（证书融合）**：`J_ReBC = (J_SimRAS, bc_ref_hash, repro_hash, repro_level, shift_flag, delta_report)`。
- **定义 287（ReBC 在线不变式）**：实时环路只含 `π_BC` 前向、`ν(s)` 计算、`shift_flag` 判定与既有 VISTA/RAS/SimRAS 逻辑；训练、复现、审计、消融全部离线。实时新增开销目标 < 0.3ms。
- **定义 288（训练目标）**：`L_ReBC = L_BC + λ_shift·L_novelty + λ_env·L_envelope`，其中 `L_novelty` 对齐 `ν(s)` 与真实风险（可用少量失败样本监督），`L_env` 约束动作落在包络内。
- **定义 289（复现触发器）**：`repro_delta > τ_repro` 或 `ref_drift > τ_ref` 或 `baseline_fingerprint` 改变时，触发 `re_run + failure_attribution`（分数据/环境/硬件/随机性四类）。
- **定义 290（证书有效性）**：`Valid(J_ReBC) ⇔ Valid(J_SimRAS) ∧ repro_level ≥ 2 ∧ (shift_flag = 0 ∨ λ_risk ≥ λ_floor) ∧ (Δ CI 下界 > 0 ∨ 明确声明"不优于基线")`。

## 2. 关键算法骨架

```python
# ReBC 总调度：参考策略 + 支持域护栏 + 复现契约 + 处理效应
class ReBC:
    def __init__(self, bc_anchor, ds_guard, repro, delta_auditor):
        self.bc, self.guard, self.repro, self.audit = bc_anchor, ds_guard, repro, delta_auditor

    # ---------- 在线：零学习写操作 ----------
    def step(self, M, obs):
        V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
        M.lsf.update_geometry(P_cloud)
        x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

        # 1) 参考动作 + 支持域检测（计量学层，前置于所有能力层）
        s_t = self.bc.encoder(x_prime)
        a_ref = self.bc.act(s_t)
        nu = self.guard.novelty(s_t, self.bc.demo_bank)
        shift_flag = int(nu > self.guard.tau_support)

        # 2) 既有 SimRAS 前向（被测量对象）
        k_ras, lambda_risk, joint_post, face_gate, wm_preds = SimRAS_round(M, obs)

        # 3) DSGuard 保守三元组（出界即收紧，绝不放宽）
        if shift_flag:
            lambda_risk = max(lambda_risk, self.guard.lambda_floor)  # (a)
            k_ras = 0                                                # (b)
        # (c) 参考包络接管：只用与 a_ref 足够接近的动作
        a_cmd = M.vista.pi_sigma.prefix_dispatch(
            self._envelope_project(M, a_ref, k_ras, joint_post))

        # 4) 参考包络硬约束
        assert self._in_envelope(a_cmd, a_ref, nu) or shift_flag

        return {
            'a_cmd': a_cmd, 'a_ref': a_ref, 'nu': nu, 'shift_flag': shift_flag,
            'k_ras': k_ras, 'lambda_risk': lambda_risk, 'joint_post': joint_post,
        }

    def _envelope_project(self, M, a_ref, k, joint_post):
        if k == 0:
            return [a_ref]
        return M.vista.pi_sigma.prefix_dispatch(k)  # 包络投影在 dispatch 内完成

    def _in_envelope(self, a, a_ref, nu):
        return self.guard.dist(a, a_ref) <= self.guard.delta_env(nu)


# ---------- 离线：BC 参考锚 ----------
class BCAnchor:
    def __init__(self, model, tau_support=0.5, k=10):
        self.model, self.tau_support, self.k = model, tau_support, k
        self.demo_bank = None
        self.fingerprint = None

    def fit(self, D_tr, D_val, seed_set, env_version, split_hash):
        torch.manual_seed(seed_set[0])
        self.model.fit(D_tr, D_val)              # 监督回归，无奖励、无仿真
        self.demo_bank = StateBank(D_tr)         # 支持域索引
        self.fingerprint = stable_hash(
            weights=self.model.state_dict(), split=split_hash,
            env=env_version, seeds=tuple(seed_set))
        return self.fingerprint

    def act(self, s):
        return self.model.mean(s)

    def novelty(self, s_t, bank):
        return bank.knn_dist(s_t, k=self.k) / bank.diameter


# ---------- 离线：复现契约 ----------
class ReproContract:
    REQUIRED = ('seed_set', 'split_hash', 'env_version',
                'determinism_flags', 'metric_suite')

    def __init__(self, **fields):
        self.f = fields
        self.valid = all(k in fields for k in self.REQUIRED)

    def repro_hash(self):
        assert self.valid, 'contract incomplete'
        return stable_hash(self.f['seed_set'], self.f['split_hash'],
                           self.f['env_version'], self.f['determinism_flags'])

    def check(self, run1, run2, tau_repro=0.02):
        bad = []
        for m in self.f['metric_suite']:
            if abs(run1[m] - run2[m]) > tau_repro:
                bad.append(m)
        level = 3 if (not bad and self._bit_exact(run1, run2)) else 2 if not bad else 0
        return ReproCert(self.repro_hash(), level, bad)


# ---------- 离线：处理效应审计 ----------
class DeltaAuditor:
    def __init__(self, n_boot=10000, alpha=0.05):
        self.n_boot, self.alpha = n_boot, alpha

    def audit(self, metric, episodes, stack_policy, bc_policy):
        d = []
        for ep in episodes:                      # 配对：同场景、同种子
            m_stack = metric(rollout(stack_policy, ep))
            m_bc = metric(rollout(bc_policy, ep))
            d.append(m_stack - m_bc)
        d = np.asarray(d)
        boot = np.array([np.mean(np.random.choice(d, len(d), replace=True))
                         for _ in range(self.n_boot)])
        lo, hi = np.percentile(boot, [100*self.alpha/2, 100*(1-self.alpha/2)])
        return {
            'delta_mean': float(np.mean(d)), 'ci': (float(lo), float(hi)),
            'cohen_d': float(np.mean(d) / (np.std(d, ddof=1) + 1e-9)),
            'significant': lo > 0,
        }


# ---------- 离线：消融阶梯 ----------
def ablation_ladder(env, D_demo, seeds, ladder):
    results = {}
    prev = None
    for name, build in ladder:                   # 只加一个组件
        means = []
        for sd in seeds:
            pol = build(seed=sd, demo=D_demo)
            means.append(evaluate(env, pol, seed=sd))
        m = float(np.mean(means))
        if prev is not None and m < prev - env.eps_reg:
            results[name] = {'metric': m, 'verdict': 'regress_reject'}
        else:
            results[name] = {'metric': m,
                             'verdict': 'pass' if m >= prev else 'neutral'}
        prev = m
    return results
```

## 3. 推导

**引理 13（BC 参考的复合误差界）** 设示范状态分布为 `P_demo`，`π_BC` 在 `support_τ` 内的单步误差为 `ε_BC`。则 T 步后误差满足 `E[ℓ] ≤ T²ε_BC`；若闭环对动作偏差有收缩性 `β < 1`，则收紧为 `ε_BC/(1−β)`。因此 `support_τ` 越小，`π_BC` 作为"安全参照"的可信区间越窄——支持域就是参考策略的**置信域**。

**引理 14（出界回退的单调保守性）** DSGuard 的保守三元组只会让 `λ_risk` 单调不减、`k` 单调不增、`E_ref` 单调收缩，三者都不扩大可行动作集。故对任意 `shift_flag` 序列，ReBC 的可行动作集 `⊆` 纯 SimRAS 的可行动作集，安全性不会因引入 BC 层而下降（只可能更保守）。

**引理 15（复现等级与结论强度）** 若 `ReproContract` 有效且两次运行 `repro_level ≥ 2`，则指标差 `|Δm| ≤ τ_repro` 可归因于随机性之外的因素；若 `repro_level = 0`，则任何 `Δ_metric` 都被随机性吞没，结论无信息量。

**定理 14（ReBC 端到端可信性）** 在 A87–A91、引理 13–15 与 ReBC 契约下：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa`（沿用 SimRAS）；
2. `shift_flag = 1 ⇒ λ_risk ≥ λ_floor ∧ k_ras = 0 ∧ a_cmd ∈ E_ref`（出界即保守，不放大风险）；
3. 若 `ReproCert.level ≥ 2` 且 `Δ_metric` 的 95% CI 下界 > 0，则"stack 优于 BC 基线"是**可复现的处理效应**；否则只能声明"未检测到优于基线"，禁止叙事化解释。

**定理 15（复现样本复杂度）** 对配对差标准差 `σ_d`、最小可检效应 δ，达到功效 `1−β` 所需 episode 数 `n ≥ 2(z_{1−α/2}+z_{1−β})²σ_d²/δ²`。由于配对设计消去了场景方差，`σ_d` 通常远小于独立设计的 `σ`，这是 ReBC 强调"同场景同种子"的理论依据。实测 `σ_d/σ ≈ 0.4` 时，样本量可降至约 16%。

**定理 16（支持域覆盖与安全地板）** 若在线覆盖率为 `c = P(ν(s) ≤ τ_support)`，且支持域内 BC 失败率为 `r_in`、域外失败率为 `r_out ≥ r_in`，则 `S_BC ≤ c·(1−r_in) + (1−c)·(1−r_out)`。当稀有高风险事件恰是 `1−c` 的主体时，`coverage_rare` 才是决定安全地板的关键量，而非总体 `coverage`。

## 6. 本轮最大风险

**一句话**：ReBC 把「可复现」误当成「有效」——一个能被逐位复现的 BC 基线，完全可能是一个系统性不安全的基线；当示范数据在稀有高风险事件上覆盖不足时，支持域会在最需要它的地方失效，而复现证书只会让"错误但稳定"的结论显得更可信——这是该轮全部理论依赖的核心假设：**示范分布覆盖了真正的风险状态流形，且"可复现"与"安全/有效"是同一件事**。

**次级风险与缓解**：
1. **BC 无法超越示范者**：参考策略的上限就是示范质量；若示范本身次优，`Δ > 0` 可能只是"比坏基线好"，不代表系统安全 → 以 `S_BC` 安全地板而非单纯 Δ 作为准入门。
2. **高维支持域估计脆弱**：k-NN 距离在高维退化 → 用降维/密度比/马氏距离替代，并报告多种 `ν(s)` 的一致性。
3. **逐位复现不可行**：GPU 非确定算子使 L3 难达 → 建立"可复现子集"白名单，其余指标以 L2 容差+多次分布报告。
4. **复现性 ≠ 外部效度**：同一实验室复现成功不代表跨本体/跨场景成立 → 加入跨环境迁移作为独立章节，禁止用单环境 L3 冒充泛化。
5. **计量层被"调参绕过"**：团队可能只挑对基线有利的 seed/指标 → 预注册 `metric_suite` 与 `seed_set`，复现哈希绑定，事后改动即失效。

## 2. 形式化定义（完整版）

**定义 266（ReBC 总览）** ReBC 是 VISTA/RAS/SimRAS 的计量学底座：
```
ReBC = (BCAnchor, DSGuard, ReproContract, DeltaAuditor, RefCert)
```
不变式：`π_BC` 与全部指标确定性可复现；在线只做 `π_BC` 前向、`ν(s)` 检测与安全回退，零学习写操作；实时新增开销 < 0.3ms。

**定义 267（专家示范集）** `D_demo = {(s_i, a_i)}_{i=1}^N ~ P_demo`。按 episode 分组划分为 `D_tr / D_val / D_te`，要求 `episode(D_tr) ∩ episode(D_te) = ∅`。

**定义 268（行为克隆参考策略）**
```
π_BC(a|s) = N(μ_θ(s), Σ_θ(s)) 或 softmax(f_θ(s))
θ* = argmin_θ E_{(s,a)~D_tr}[ℓ(a, π_θ(s))]
```
冻结后 `a_BC(s) = μ_{θ*}(s)`。

**定义 269（BC 误差界）** 单步误差 `ε_BC = E_{s~P_demo}[ℓ(a, π_BC(s))]`；示范支撑内 T 步复合误差 `E[ℓ(a_T, π_BC(s_T))] ≤ min(T²ε_BC, ε_BC/(1−β))`。

**定义 270（示范支持域）** `support_τ = {s : ν(s) ≤ τ_support}`，`ν(s) = dist_kNN(s, D_tr)/diameter`。

**定义 271（分布外护栏 DSGuard）** `shift_flag_t = 1[ν(s_t) > τ_support]`。出界执行保守三元组：
```
(a) λ_risk ← max(λ_risk, λ_floor)
(b) k ← 0
(c) a_cmd ∈ E_ref(s), 并降低速度上限
```

**定义 272（参考行为包络）** `E_ref(s) = {a : ||a − a_BC(s)||_{Σ^{-1}} ≤ δ_env(s)}`，`δ_env(s)` 随 `ν(s)` 单调收缩。

**定义 273（可复现契约）** `ReproContract = (seed_set, split_hash, env_version, determinism_flags, metric_suite)`。有效 ⇔ 五元组齐全 ∧ `split_hash` 与 `repro_hash` 一致 ∧ 确定性开关全开或非确定性范围已记录。

**定义 274（复现证书）** `R_cert = (repro_hash, seeds, {metric_j: mean±std}, CI, repro_level)`；两次独立运行 `|m_j^{(1)} − m_j^{(2)}| ≤ τ_repro` 才算复现成功。

**定义 275（可复现等级）** L0 文档；L1 脚本；L2 容器/环境锁定；L3 固定种子逐位一致。对外结论最低 L2，安全相关结论要求 L3。

**定义 276（基线指纹）** `baseline_fingerprint = hash(θ*, split_hash, env_version, seed_set)`；任一字段变化须重签指纹并重跑回归门。

**定义 277（处理效应）** `Δ_metric = metric(stack) − metric(π_BC)`，在所有**配对 episode**（同场景、同种子，仅策略不同）上计算，报告均值、bootstrap 95% CI 与 Cohen's d。

**定义 278（配对统计与功效）** 对配对差 `d_i` 做 Wilcoxon 符号秩检验；所需样本 `n ≥ 2(z_{1−α/2}+z_{1−β})²σ_d²/δ²`。

**定义 279（回归门）** 新层 L 须满足 `metric(L) ≥ metric(L_prev) − ε_reg`；若声称改进则还须 `metric(L) ≥ metric(π_BC) + δ_min`。

**定义 280（安全地板）** `S_BC = 1 − risk_rate(π_BC)`；若 `S_BC < S_floor`，则相对改进在安全意义上无定义。

**定义 281（消融阶梯）** `Ladder = [BC, BC+VISTA, BC+RAS, BC+SimRAS, BC+ReBC]`，每次只加一个组件，逐级报告 `Δ_metric ± CI`。

**定义 282（参考漂移）** `ref_drift = KL(π_BC^{new} || π_BC^{old})`；`> τ_ref` 时旧证书全部失效。

**定义 283（失败重放包）** `replay_bundle = (obs_0:T, seed, env_state, env_version, baseline_fingerprint)`，支持确定性重放与反事实回放。

**定义 284（DAgger 扩展与查询预算）** 可选 `π_{i+1} = BC(D_tr ∪ D_i^{π_i})`，须记录查询预算 `Q_i` 与标注来源；主基线仍以纯 BC 报告。

**定义 286（证书融合）** `J_ReBC = (J_SimRAS, bc_ref_hash, repro_hash, repro_level, shift_flag, delta_report)`。

```python
# IP-243 BCAnchor：参考锚
class BCAnchor:
    def fit(self, D_tr, D_val, seed_set, env_version, split_hash):
        torch.manual_seed(seed_set[0])
        self.model.fit(D_tr, D_val)              # 监督回归，无奖励/无仿真
        self.demo_bank = StateBank(D_tr)
        self.fingerprint = stable_hash(
            weights=self.model.state_dict(), split=split_hash,
            env=env_version, seeds=tuple(seed_set))
        return self.fingerprint

    def act(self, s):  return self.model.mean(s)
    def novelty(self, s, bank):  return bank.knn_dist(s, k=10) / bank.diameter


# IP-244 DSGuard：支持域护栏
class DSGuard:
    def __init__(self, tau_support=0.5, lambda_floor=0.9, delta_env0=0.1):
        self.tau, self.lambda_floor, self.delta_env0 = tau_support, lambda_floor, delta_env0

    def check(self, s, bank):
        nu = StateBank.knn_norm(s, bank)
        return {'nu': nu, 'shift': int(nu > self.tau)}

    def constrain(self, lambda_risk, k, nu):
        if nu > self.tau:                        # 只收紧，绝不放宽
            return max(lambda_risk, self.lambda_floor), 0
        return lambda_risk, k

    def delta_env(self, nu):                     # 包络随新颖度收缩
        return self.delta_env0 * max(0.0, 1.0 - nu / max(self.tau, 1e-9))


# IP-245 ReproContract：复现契约
class ReproContract:
    REQUIRED = ('seed_set', 'split_hash', 'env_version',
                'determinism_flags', 'metric_suite')

    def __init__(self, **fields): self.f = fields
    def valid(self):  return all(k in self.f for k in self.REQUIRED)
    def repro_hash(self):
        return stable_hash(self.f['seed_set'], self.f['split_hash'],
                           self.f['env_version'], self.f['determinism_flags'])
    def check(self, run1, run2, tau_repro=0.02):
        bad = [m for m in self.f['metric_suite']
               if abs(run1[m] - run2[m]) > tau_repro]
        level = 3 if (not bad and bit_exact(run1, run2)) else (2 if not bad else 0)
        return ReproCert(self.repro_hash(), level, bad)


# IP-246 DeltaAuditor：处理效应审计
class DeltaAuditor:
    def audit(self, metric, episodes, stack_policy, bc_policy, n_boot=10000):
        d = np.array([metric(rollout(stack_policy, ep))
                      - metric(rollout(bc_policy, ep)) for ep in episodes])
        boot = np.array([np.mean(np.random.choice(d, len(d), True))
                         for _ in range(n_boot)])
        lo, hi = np.percentile(boot, [2.5, 97.5])
        return {'delta': float(d.mean()), 'ci': (float(lo), float(hi)),
                'd': float(d.mean() / (d.std(ddof=1) + 1e-9)),
                'significant': bool(lo > 0)}

    else:

# IP-251 AblationLadder
def ablation_ladder(env, D_demo, seeds, builders):
    results, prev = {}, None
    for name, build in builders:                 # 逐级单组件
        m = np.mean([evaluate(env, build(seed=s, demo=D_demo), seed=s)
                     for s in seeds])
        verdict = ('regress_reject' if prev is not None and m < prev - env.eps_reg
                   else 'pass' if prev is None or m >= prev else 'neutral')
        results[name] = {'metric': float(m), 'verdict': verdict}
        prev = m
    return results
```

## 4. 推导

**引理 13（BC 参考的复合误差界）** `support_τ` 内单步误差 `ε_BC`，T 步后 `E[ℓ] ≤ T²ε_BC`；若闭环收缩系数 `β < 1`，则收紧为 `ε_BC/(1−β)`。结论：支持域即参考策略的**置信域**，`τ_support` 越小，`π_BC` 作为安全参照的可信区间越窄。

**引理 14（出界回退的单调保守性）** DSGuard 三元组使 `λ_risk ↑`、`k ↓`、`E_ref ↓`，均不扩大可行动作集。故 ReBC 的可行动作集恒 `⊆` 纯 SimRAS 的可行动作集，引入 BC 层只可能更保守。

**引理 15（复现等级与结论强度）** `ReproContract` 有效且 `repro_level ≥ 2` 时，指标差超出 `τ_repro` 才可归因于非随机因素；`repro_level = 0` 时任何 `Δ_metric` 都被随机性吞没，结论无信息量。

**定理 14（ReBC 端到端可信性）** 在 A87–A91、引理 13–15 与 ReBC 契约下：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa`；
2. `shift_flag = 1 ⇒ λ_risk ≥ λ_floor ∧ k_ras = 0 ∧ a_cmd ∈ E_ref`；
3. `repro_level ≥ 2 ∧ Δ CI 下界 > 0 ⇒ "stack 优于 BC"为可复现处理效应`；否则只允许声明"未检测到优于基线"。

**定理 15（复现样本复杂度）** 功效 `1−β`、显著水平 α、最小效应 δ 下，配对设计需 `n ≥ 2(z_{1−α/2}+z_{1−β})²σ_d²/δ²`。配对消去场景方差，`σ_d/σ ≈ 0.4` 时样本量约为独立设计的 16%。

**定理 16（支持域覆盖与安全地板）** 覆盖率 `c`、域内失败率 `r_in`、域外失败率 `r_out ≥ r_in` 时，`S_BC ≤ c(1−r_in) + (1−c)(1−r_out)`。若稀有高风险事件恰是 `1−c` 的主体，则决定安全地板的是 `coverage_rare` 而非总体 `coverage`。

## 7. 本轮最大风险

**一句话**：ReBC 把「可复现」误当成「有效」——一个能被逐位复现的 BC 基线，完全可能是一个系统性不安全的基线；当示范数据在稀有高风险事件上覆盖不足时，支持域会在最需要它的地方失效，而复现证书只会让"错误但稳定"的结论显得更可信——这是该轮全部理论依赖的核心假设：**示范分布覆盖了真正的风险状态流形，且"可复现"与"安全/有效"是同一件事**。

**次级风险与缓解**：
1. **BC 无法超越示范者**：以 `S_BC` 安全地板而非单纯 `Δ` 作为准入门，避免"比坏基线好"被误读为安全。
2. **高维支持域估计脆弱**：用降维/密度比/马氏距离替代 k-NN，并报告多估计量的一致性。
3. **逐位复现不可行**：建立"可复现子集"白名单，其余指标以 L2 容差+多次分布报告。
4. **复现性 ≠ 外部效度**：跨本体/跨场景迁移作为独立章节，禁止单环境 L3 冒充泛化。
5. **计量层被调参绕过**：预注册 `metric_suite` 与 `seed_set`，`repro_hash` 绑定，事后改动即失效。
