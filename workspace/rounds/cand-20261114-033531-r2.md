# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计层」IP-264~274；本轮灵感：「柔顺控制」×「排行榜」）

> R70 把不确定性推到「显式世界信念」`b_t(s)`，让 `H[b_t]` 成为 epistemic 的真身，交互升级为贝叶斯实验设计，并配了基线协议与原型验收。但它仍把安全押在两个从未被检验的东西上：
> 1. **安全 = 把动作收小（λ_floor）**。这条通道只在「位置/速度」域工作：把速度压到 0，对一个僵硬的力控任务并不更安全——持续顶住一个未知表面，能量照样注入，接触力照样可能超限。「慢」不等于「软」。
> 2. **「最好的策略」只有一个**。R70 用后验选一个模态、一个控制器、一个风险缩放。可真实部署里没有任何单一阻抗/缩放对所有相位都最优；而「谁最好」本身是一个随场景漂移、还会被评测方式污染的**统计问题**，不是一次离线基线能定死的。
>
> 本轮两个灵感正好补上：
> - **柔顺控制**把安全从「速度域」搬到「能量域」：不确定时不是刹车，而是**让路**（降低刚度、提高阻尼、最终被动），并用无源性给出一个**不依赖世界模型正确**的能量证书；
> - **排行榜**把「押注单一最优策略」换成「维护一个已认证的候选组合，按统计有效的证据排名、择优上场，排不出来就退被动」。
>
> 核心命题：**把「不确定 → 减速」升级为「不确定 → 让路」，把「选一个策略」升级为「在已认证条目里排名并选择」；安全由无源性能量门（硬约束）保证，效率由排行榜（软比较）争取；排行榜可以排错，但不能排出一个不安全的动作。** 命名 **YIELD-RAS**（Yielding Impedance Energy-tank Leaderboard Decision）。
>
> 一句话定位：R68 问「测量还准吗」，R69 问「该问谁」，R70 问「我相信什么」，R71 问「**当我既不能确信、也不能停住时，我该如何让路，并让谁上场？**」

## 0. 直觉与动机

**灵感 1（柔顺控制 → 安全不是一个标量，而是一条力-位妥协曲线）**
直觉：R68–R70 的安全动作是「把 λ 压小」——在固定的刚性控制器上缩放速度。这在自由空间有效，在接触任务里却是错觉：一个刚度 `K_d` 很大的位置控制器，只要持续顶着一个不确定表面，位置误差就会变成力（`F≈K_d·e`），把速度降到再低也只是「慢慢地顶」。真正的安全旋钮是**机械阻抗**：降低 `K_d`，机器人「让」；提高 `B_d`，把冲击动能耗散掉；极端情况把 `K_d→0`、只留阻尼，机器人变成一堵「软墙」。于是不确定性不再只映射到一个标量 λ，而是映射到一条**力-位折中曲线**：越不确定，越往「顺从而精确度低」的一端走。这把「安全」从「别撞上」扩展为「撞上了也不会造成不可逆的伤害」。

**灵感 2（无源性 → 一张不依赖信念正确性的安全证书）**
直觉：R70 最大的隐患是「后验自信地错」：`H[b_t]` 变小，安全却变差。柔顺控制给出一条完全不同的保证——**无源性/能量守恒**。如果控制器相对于环境是无源的（不凭空产生能量），那么无论环境是什么、无论我对环境的模型错得多离谱，闭环的能量都不会发散；用「能量罐」显式记账（注入扣、回收打折），只要罐子不为负，安全就有下界。这个保证**不需要 `b_t` 正确**，只需要能量会计保守。这正是 R70 缺的那块：一条独立于「信念」的安全底座。它的代价是更保守、更依赖物理假设——但这恰好可以被计量、被检验、被审计。

**灵感 3（柔顺即探询 → 让路也是一种测量）**
直觉：R69 的信息动作是「看/问/触」。但「触」其实不是一次性的，而是**用受控的柔顺去读取环境**：表面多硬、摩擦多大、有没有卡住，都是在你「让」的时候才显形。刚度可调的探针（admittance probe）能在力受限的前提下估计接触参数——这是把「柔顺」同时当作安全与感知。更妙的是，探询要消耗能量，而能量罐是硬预算，于是 R69 的「VoI − 社会成本」自然升级为「**VoI / 能量**」的信息密度问题：不是「值不值得问」，而是「在安全能量预算里，哪一问最划算」。这让「边做边问」第一次有了物理账本。

**灵感 4（排行榜 → 不押注单一策略，维护一个已认证的组合）**
直觉：真实系统里，「最该用的阻抗/缩放」随任务相位、载荷、地面、人的意图而变。与其训练一个在所有情形都最优的控制器，不如维护一个**候选条目池**：不同刚度档 × 不同风险缩放 × 不同探询策略，每条都带自己的证书；在成对、同分布的 episode 上做比较，用 Bradley–Terry / 置信序列给每条打一个「强度」的后验，选**下置信界最高且过硬门**的那条。这不是「多模型集成」的加权平均，而是**带证上岗的择优**：先认证，再排名，后上场。排行榜的哲学是「让证据决定谁上，而不是让一次训练决定一切」。

**灵感 5（排行榜是双刃剑 → Goodhart、榜单污染、刷分，以及一条分离原则）**
直觉：排行榜会诱发「优化指标而非目标」：刷公开集、挑种子、奖励黑客、把「看起来安全」做成「真的安全」的代理。更危险的是，系统自己也可能学会「赢榜」而不是「变安全」。所以本轮必须同时交付：**密封隐藏集 + 任意时刻有效的置信序列 + 榜单污染检测 + 公开/密封排名落差告警 + 预注册哈希**。但最锋利的不是这些补丁，而是一条**分离原则**：**排行榜只决定「效率与偏好」，安全由「准入 + 能量门」硬性保证；因此排行榜可以被攻破、被排错，却无法单独让系统变得不安全。** 除非——准入所依赖的无源性能量会计本身是错的。这把最大的攻击面精确地逼到「物理假设」上，也是本轮最大风险的来源。

## 1. 形式化定义（增量：定义 331–346）

**定义 331（YIELD-RAS 总览）** YIELD-RAS = (CIC, PET, CAP, EAR, SVS, PSC, ECG, GAD, VQA-IV, AIC-YIELD, J_YIELD, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R70 定义 310-i）；
(ii) **能量硬约束**：能量罐 `E_tank ≥ 0` 恒成立；任何条目须通过无源准入；探询与交互的能量之和 ≤ `E_budget`；
(iii) **排名纪律**：只有准入条目可被排名；排名主张须由任意时刻有效的置信序列支撑；公开/密封排名落差低于阈值；
(iv) **严格包含**：当阻抗集退化为单一高刚度、无探询、单条目（无排名）、禁用让路时，YIELD 逐指令退化为 BELIEF。

**定义 332（柔顺参数化动作）** 动作 `u_t = (a_t, g_t, θ_t^c)`。任务动作 `a_t` 给出期望轨迹 `(x_d, ẋ_d, ẍ_d)`；信息动作 `g_t` 同 R70；柔顺参数 `θ^c = (M_d, B_d, K_d) ∈ Θ_c`，`M_d ≻ 0`，`K_d ∈ [0, K_max]`，`B_d ∈ [B_min, B_max]`。执行用阻抗控制
`τ = J^T[M_d(ẍ_d−ẍ) + B_d(ẋ_d−ẋ) + K_d(x_d−x)] + ĝ(q) + τ_f`，
或其对偶导纳形式。于是「风险缩放」有两个正交旋钮：`λ`（速度/激进度）与 `θ^c`（机械阻抗）。R68–R70 只用了前者。

**定义 333（端口哈密顿闭环与无源性）** 机器人与环境构成端口哈密顿系统，能量 `H(x) ≥ 0`，端口变量 `(u, y)`，`u` 为控制力/力矩，`y` 为共轭速度。功率平衡 `Ḣ = u^T y − d(x) + P_ext`，`d(x) ≥ 0` 为耗散。控制器端口在 `[0,T]` 上无源 ⇔ `∫_0^T u^T y dt ≥ −E_tank(0)`（不从系统净取能）。

**定义 334（无源能量罐 PET）** 虚拟罐 `E_tank ≥ 0`，按保守会计更新：
若 `p = u^T y ≥ 0`（向环境注能）：`Ė_tank = −p − ε_d`；
若 `p < 0`（环境向机器人做功）：`Ė_tank = η(−p) − ε_d`，`0 < η ≤ 1`（回收打折）。
若下一步会使 `E_tank < 0`，则把 `u` 投影到无源动作集（降 `K_d`、升 `B_d`、或冻结），使罐永不为负。条目 `e` 的**无源准入**：在最坏环境功率（威胁集内）下，`P(E_tank(t) ≥ 0, ∀t) ≥ 1 − δ_pet`。

**定义 335（柔顺探询 CAP）** 探询 `g_probe = (n ∈ S², F(t) ≤ F_max, θ^c_probe)` 产生接触观测 `y_contact`，扩展观测模型的状态为 `s_contact = (k_e, μ, geometry)`。其能量成本 `E_probe = ∫ F·ẋ dt` 必须**执行前**从 PET 预扣。信息密度定义为 `ρ(g) = (H[s_contact|b_t] − E_y[H[s_contact|b_t,y]]) / E_probe`。候选探询必须落在 VoI-能量 Pareto 前沿上。

**定义 336（认证条目与组合）** 条目 `e = (π_e, θ_e^c, λ_e, g_e, J_e)`，其中 `J_e` 为本条目的证书（可含 R70 的 `J_BELIEF` 子证）。准入集 `A_t = {e : Valid(J_e) ∧ PET-admissible(e) ∧ 排名置信已建立}`。组合是一个动态集合，可增删隔离。

**定义 337（风险调整效用与成对比较）** 在同分布 episode `ω` 上（共享初始状态与随机数）：
`U_e(ω) = 1{成功} − β_v·1{违规} − β_e·E_e − β_t·T_e − β_s·H_2nd,e`。
成对结局 `o_{ij}(ω) = sign(U_i(ω) − U_j(ω))`。Bradley–Terry：`P(e_i ≻ e_j) = σ(θ_i − θ_j)`。维护每个 `θ_e` 的高斯（或在线逻辑）后验。

**定义 338（统计有效排行榜 SVS）** 仅当任意时刻有效下置信界分离时，才把 `i` 排在 `j` 之上：`LCB_{1−α}(θ_i − θ_j) > 0`（置信序列对可选停止与多重比较有效；用 Holm/e-value 控制族错误率）。选择 `e* = argmax_{e∈A_t} LCB(θ_e)`。这把「排行榜第几名」从一段噪声点估计升级为一个**带误差条的排序**。

**定义 339（Goodhart/榜单污染检测 GAD）** 公开集 `D_pub` 与密封集 `D_seal`（隐藏部署代理）。检测五类污染：(a) 训练/评测近重复与成员推断（污染分）；(b) 特征分布两样本散度（MMD/能量距离）；(c) 公开排名与密封排名的 Kendall τ 落差；(d) 种子挑选（种子间方差/一致性）；(e) 代理黑客（效用上升但违规率/能量消耗/二次伤害同步恶化）。任一越界 ⇒ 相关条目隔离，并触发 Goodhart 告警。

**定义 340（选择与让路）** 若存在 `e*` 使 `LCB(θ_{e*}) ≥ U_floor` 且能量余量 `≥ ε_res`，则选 `e*`；否则进入**纯让路模式**：`K_d → 0`、`B_d → B_damp`、`λ → λ_floor`，仅保留被动/阻尼控制。让路是柔顺版 `λ_floor`，也是最后的安全动作——它不保证完成任务，但保证不在不确定环境里继续注能。

**定义 341（能量-柔顺门 ECG）** 给定不确定性 `U = U_ale + α·H[b_t]`（继承 R70），定义可接受阻抗集
`Θ_c(U) = {θ^c : F_peak(θ^c, U) ≤ F_safe ∧ E_tank − E_probe ≥ ε_res}`。
`U` 增大时，门单调收缩 `K_d`、抬升 `B_d`。`λ_floor` 是它在「固定高刚度、只缩速度」上的截面；即 ECG 严格泛化 `λ_floor`。

**定义 342（无源切换 PSC）** 条目切换 `e→e′` 必须无源保持：仅当 `E_tank ≥ ΔE_switch(e→e′)`（切换瞬态能量上界，含 bump-less 转移）才允许切换；否则先耗散/等待。切换带滞回阈值 `Δ_rank`，避免排行榜噪声导致控制器抖振。

**定义 343（排行榜即审计 VQA-IV）** 审计：排名是否只在准入集上做、置信序列是否被尊重、Goodhart 告警是否被忽略、能量会计是否独立复核、让路是否被滥用为「逃避任务」。审计结论回灌为条目成本先验，并可否决条目。

**定义 344（干扰集 AIC-YIELD）** `ℰ_YIELD = ℰ_BELIEF × ℰ_passivity（非无源环境 / 执行器延迟 / 摩擦齿隙 / 能量会计故障）× ℰ_leaderboard（评测污染 / 排名投毒 / 指标黑客 / 种子挑选 / 非平稳）× ℰ_probe（探针损伤 / 对抗性柔顺）`。

**定义 345（证书 J_YIELD）** `J_YIELD = (J_BELIEF, energy_used, passivity_violations, min_tank_margin, entries_ranked, rank_confidence, sealed_rank_τ, goodhart_flags, yield_ratio, yield_ver)`。Valid ⇔ `J_BELIEF` valid ∧ 无源性违规 = 0 ∧ 排名纪律满足 ∧ 无未解释的 Goodhart 标记。

**定义 346（对 R70 的包含关系）** 当 `Θ_c = {K_max 刚性}`、无探询、组合只有单条目、且禁用让路时，YIELD 的每一指令与 BELIEF 相同。故 R70 是 YIELD 在「刚性 / 不探询 / 不排名」边界上的退化。

```python
# IP-275 CIC：柔顺参数化动作与阻抗执行
class ComplianceAction:
    def __init__(self, M_d, B_d, K_d):
        self.M_d, self.B_d, self.K_d = M_d, B_d, K_d
    def torque(self, q, dq, x_des, dx_des, ddx_des):
        x, dx = forward_kin(q, dq)
        e, de = x_des - x, dx_des - dx
        return (J(q).T @ (self.M_d @ ddx_des + self.B_d @ de + self.K_d @ e)
                + gravity(q) + friction_comp(dq))

# IP-276 PET：无源能量罐（模型无关安全会计）
class PassivityTank:
    def __init__(self, E0, eta=0.9, eps_d=1e-4, reserve=0.1):
        self.E, self.eta, self.eps_d, self.reserve = E0, eta, eps_d, reserve
    def step(self, u, y, dt):
        p = float(u @ y)                     # 正=向环境注能
        if p >= 0: self.E -= (p + self.eps_d) * dt
        else:      self.E += (self.eta * (-p) - self.eps_d) * dt
        return self.E >= 0.0
    def clamp(self, u, y):                   # 将透支则投影到无源动作
        if self.E - self.reserve <= 0: return passive_projection(u, y)
        return u

# IP-277 CAP：柔顺探询（信息密度 = VoI / 能量）
def plan_probe(b_t, tank, budget):
    best = None
    for g in probe_candidates(b_t):          # (n, F(t), theta_c)
        if g.F_max > F_safe: continue
        if g.energy > tank.E - tank.reserve: continue
        voi = entropy(b_t.contact) - expected_entropy(b_t.contact, g)
        score = voi / max(g.energy, 1e-6)
        if best is None or score > best.score: best = (g, score, voi)
    return best if best and best.score > RHO_MIN else None

# IP-278/279 EAR + SVS：带误差条的排行榜
class LeaderboardArena:
    def __init__(self, alpha=0.01):
        self.post, self.alpha = {}, alpha
    def compare(self, ei, ej, episode):      # 成对、共享 episode
        o = 1.0 if utility(ei, episode) > utility(ej, episode) else 0.0
        bt_update(self.post, ei, ej, o)      # 逻辑似然 -> 高斯后验
    def lcb(self, e):
        return anytime_valid_lcb(self.post[e], self.alpha)
    def select(self, Admissible, tank, u_floor):
        cand = [e for e in Admissible if tank.can_afford(e)]
        if not cand: return None             # -> 纯让路
        e_star = max(cand, key=self.lcb)
        return e_star if self.lcb(e_star) >= u_floor else None

# IP-280 GAD：榜单污染 / Goodhart 检测（异步）
def goodhart_check(arena, D_pub, D_seal, train):
    contam = contamination_score(D_pub, train)
    div    = two_sample_divergence(feats(D_pub), feats(D_seal))
    tau    = kendall_tau(rank_on(arena, D_pub), rank_on(arena, D_seal))
    hack   = any(e.utility_up and e.violation_up for e in arena.entries)
    flags  = dict(contamination=contam, divergence=div, rank_gap=tau, proxy_hack=hack)
    return flags, (contam < C0 and div < D0 and tau > T0 and not hack)

    lam = max(M.efs.risk_scale(...), lam_floor(U))

    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(e_star.policy.a[:k]) * lam
    tau = M.tank.clamp(tau, y_actual)
    if not M.tank.step(tau, y_actual, dt):
        e_star = M.ecg.pure_yield()          # 账见底 -> 让路
    # 6) 审计 + 榜单完整性 + 证书
    flags, clean = M.gad.check(...)
    if not clean:
        M.arena.quarantine(flags.entries); M.vqa_iv.alert(flags)
    M.vqa_iv.submit_async(e_star, g, U, M.tank.E, flags)
    M.b_prev = b_t
    return k, lam, tau, e_star
```

## 3. 推导

**引理 27（无源性证书不依赖信念正确性）** 设闭环满足功率平衡 `Ḣ = u^T y − d + P_ext`，PET 强制 `E_tank ≥ 0`。则对任意环境供能上界 `E_ext` 与任意（可任意错误的）信念 `b_t`，都有 `H(x(t)) ≤ H(x(0)) + E_tank(0) + E_ext`。证明：对功率平衡积分，注入项被罐与耗散吸收，罐非负给出能量上界；`b_t` 只进入 `u` 的选取，不进入该不等式。系：**即使 R70 的后验「自信地错」，只要 PET 与耗散假设成立，系统能量仍有界**——这比「把速度压小」强，因为它约束的是能量而不是指令幅度。

**引理 28（柔顺单调性）** 对线性阻抗的接触，在位置误差 `‖e‖ ≤ ē`、法向速度 `‖ė‖ ≤ v̄` 的有界假设与欠阻尼区间内，峰值接触力的一个保守上界 `F_peak(K_d, B_d)` 满足 `∂F_peak/∂K_d > 0`、`∂F_peak/∂B_d < 0`。故 ECG 的「降 `K_d`、升 `B_d`」在力域上单调降低最坏接触力；而 `λ_floor` 只在速度域缩放、对稳态 `K_d·e` 项无能为力。系：**接触任务里，柔顺是比减速更对的保守方向**。

**引理 29（柔顺探询的信息-能量前沿）** 在高斯接触观测模型下，探询的 Fisher 信息随探针力幅 `F` 单调增，而能量成本 `∝ F²`；故单位能量信息密度在最优点 `F* ∝ 1/√(观测噪声)`，且存在一个中间刚度使信息-能量比最大。于是 CAP 的候选应取 `(VoI, E_probe)` 的 Pareto 前沿；R69 的纯 VoI 选择会把能量当免费，在能量受限时会选到「昂贵而低效」的探询。系：**问得起不等于问得值；探询要把安全预算算进收益**。

**引理 30（排行榜的统计有效性与 Goodhart 界）** 使用任意时刻有效置信序列 + Holm 校正时，任意时刻「把 `i` 错排于 `j` 之上」的族错误率 ≤ α；在公开-密封分布 TV 距离 ≤ ε 时，排名反转概率的一个上界随 ε 线性增长；GAD 对污染/散度/排名落差超过阈值的替代假设有检验功效 ≥ 1−β。系：**排行榜可以「一直看、随时停」而不虚高显著性**——这正是在线榜单区别于一次性基线的关键。

**定理 23（YIELD 严格包含 BELIEF 严格包含 R68）** 在 A99–A101（R70）与 A106–A109（无源会计保守、`F_peak` 单调、探询可辨识、排名置信有效）下，对任意状态的期望风险 `R(YIELD) ≤ R(BELIEF) ≤ R(R68)`；且在「刚性 / 不探询 / 单条目」边界上逐指令相同。安全侧（能量/力上界）不弱于 R70，并在模型错误时获得 R70 没有的独立保证；效率侧通过更高刚度条目与更好选择获得 resolution bonus。

**定理 24（排行榜选错的代价 ≠ 不安全）** 若准入门（无源性、`J` 有效、能量）与执行时的 PET/clamp 均生效，则无论排行榜怎样被噪声、污染或投毒影响，系统执行的每一条目都满足能量与力安全约束；排名错误只影响任务效率（regret），不影响安全。即 **safety 由硬门保证、performance 由软排名争取**。推论：对排行榜的攻击面被压缩为「效率攻击」；只有当无源性假设本身失效时，排名攻击才可能转化为安全事件（见第 6 节）。

**定理 25（选择后悔与切换稳定性）** 在平稳准入集与次高斯效用下，SVS 选择相对最优准入条目的 regret 为 `O(√(K log T / T))`；加入滞回 `Δ_rank` 与 PSC 后，条目切换次数为 `O(K log T / Δ_min²)`，故无「榜单噪声导致的控制抖振」。非平稳时用滑窗置信序列可得有界跟踪后悔。

## 6. 本轮最大风险

**一句话**：YIELD-RAS 把安全从「信念正确」搬到「能量非负」，而无源性只是**条件**保证——它要求环境/执行器无源（或有界供能）、且能量会计本身可信；一旦环境是主动的（人、储能弹性、另一台机器人）、或执行器延迟/摩擦/齿隙让能量会计漏账，PET 就会开出一张**看起来模型无关、实则建立在错误物理假设上**的安全证书，排行榜再准也无法补救，因为「只让合格者上榜」里的「合格」本身是假的。

**次级风险与缓解**：
1. **非无源/主动环境**（人推、弹性储能、多机）→ 用有界功率界替代严格无源，配合力/位传感器独立计量，并在威胁集内做最坏情形准入；公开标注适用域。
2. **能量罐在长时间接触任务中被耗尽** → 能量回收打折入账 + 任务做功回充 + `reserve` 管理；耗尽即让路，绝不透支。
3. **排行榜非平稳与抖振** → 任意时刻有效置信序列 + 滞回 `Δ_rank` + PSC 无源切换；滑窗跟踪。
4. **Goodhart / 刷榜** → 密封集、污染检测、预注册、公开/密封落差告警、代理黑客检测；但这些只能降低而不能消除「优化代理」的倾向，需把安全与效率的分离原则写进协议。
5. **柔顺牺牲精度/任务失败** → 力-位 Pareto 与任务相位自适应；让路的失败要作为显式代价记录，而不是被安全指标掩盖。
6. **分离原则失效**（准入门本身被攻破）→ VQA-IV 独立复核能量账、证书哈希可追溯、任何准入依赖的物理假设必须可测并在 Proto-Val 中显式验收。

## 3. 关键算法伪代码（落地版）

```python
# IP-275 CIC：阻抗执行
def impedance_torque(q, dq, x_des, dx_des, ddx_des, M_d, B_d, K_d):
    x, dx = forward_kin(q, dq)
    e, de = x_des - x, dx_des - dx
    return (J(q).T @ (M_d @ ddx_des + B_d @ de + K_d @ e)
            + gravity(q) + friction_comp(dq))

# IP-276 PET：无源能量罐 + 透支投影
class PassivityTank:
    def __init__(self, E0, eta=0.9, eps_d=1e-4, reserve=0.1):
        self.E, self.eta, self.eps_d, self.reserve = E0, eta, eps_d, reserve
    def step(self, u, y, dt):
        p = float(u @ y)
        if p >= 0: self.E -= (p + self.eps_d) * dt
        else:      self.E += (self.eta * (-p) - self.eps_d) * dt
        return self.E >= 0.0
    def clamp(self, u, y):
        return passive_projection(u, y) if self.E - self.reserve <= 0 else u
    def admissible(self, e):
        return self.E >= e.worst_case_energy + self.reserve

# IP-277 CAP：信息密度选址
def plan_probe(b_t, tank, budget):
    cands = []
    for g in probe_candidates(b_t):
        if g.F_max > F_safe or g.energy > tank.E - tank.reserve: continue
        voi = entropy(b_t.contact) - expected_entropy(b_t.contact, g)
        cands.append((g, voi / max(g.energy, 1e-6), voi))
    if not cands: return None
    g, score, voi = max(cands, key=lambda t: t[1])
    return (g, voi) if score > RHO_MIN else None

# IP-278/279 EAR + SVS：带误差条的排行榜
class LeaderboardArena:
    def __init__(self, alpha=0.01, delta_rank=0.1):
        self.post, self.alpha, self.delta_rank = {}, alpha, delta_rank
    def register(self, e): self.post[e.id] = gaussian_prior()
    def compare(self, ei, ej, episode):
        o = 1.0 if utility(ei, episode) > utility(ej, episode) else 0.0
        bt_update(self.post, ei.id, ej.id, o)
    def lcb(self, e): return anytime_valid_lcb(self.post[e.id], self.alpha)
    def select(self, Admissible, tank, u_floor):
        cand = [e for e in Admissible if tank.admissible(e)]
        if not cand: return None
        e_star = max(cand, key=self.lcb)
        return e_star if self.lcb(e_star) >= u_floor else None

# IP-280 GAD：榜单完整性（异步）
def goodhart_check(arena, D_pub, D_seal, train):
    flags = dict(
        contamination = contamination_score(D_pub, train),
        divergence    = two_sample_divergence(feats(D_pub), feats(D_seal)),
        rank_gap      = kendall_tau(rank_on(arena, D_pub), rank_on(arena, D_seal)),
        proxy_hack    = any(e.utility_up and e.violation_up for e in arena.entries),
    )
    clean = (flags["contamination"] < C0 and flags["divergence"] < D0
             and flags["rank_gap"] > T0 and not flags["proxy_hack"])
    return flags, clean
```

## 4. 推导（工程可测版）

**引理 27（无源性证书不依赖信念）** 功率平衡积分 + `E_tank ≥ 0` 得 `H(x(t)) ≤ H(x(0)) + E_tank(0) + E_ext`，与 `b_t` 无关。**可测**：E322 直接量测能量账与实测功之差；E323 注入错误信念后测力/能量上界。

**引理 28（柔顺单调性）** 在有界误差/速度与欠阻尼区间内，`F_peak` 随 `K_d` 增、随 `B_d` 减。**可测**：E321 扫 `(K_d,B_d)` 网格画力-位 Pareto；E336 与 R70 比力超限率。

**引理 29（探询信息-能量前沿）** 高斯模型下 Fisher 信息 ∝ `F²`、能量 ∝ `F²`，最优 `F* ∝ 1/√噪声`；中间刚度信息-能量比最大。**可测**：E324 画 `VoI/能量` 前沿；E325 验证力/位包络。

**引理 30（排行榜统计有效性 + Goodhart 界）** 任意时刻有效置信序列 + Holm ⇒ 族错误率 ≤ α；公开-密封 TV 距离 ≤ ε 时排名反转随 ε 线性上界。**可测**：E326 用合成榜单注入噪声量测假排名率；E328/E329 注入污染与分布漂移。

**定理 23（严格包含）** `R(YIELD) ≤ R(BELIEF) ≤ R(R68)`；「刚性 / 不探询 / 单条目」边界逐指令相同。**可测**：E332 在退化配置下测行为差 = 0；E339 做四组件消融。

**定理 24（选错 ≠ 不安全）** 准入 + PET/clamp 生效时，任何排行榜输出都只能改变效率，不能改变能量/力上界。**可测**：E327 故意让排行榜选「差条目」，验证安全指标不变、仅效用下降；E338 做对抗性柔顺攻击。

**定理 25（后悔与切换稳定）** 平稳次高斯效用下 SVS regret `O(√(K log T / T))`；滞回 + PSC 后切换次数 `O(K log T / Δ_min²)`。**可测**：E333 统计切换次数；E334 非平稳滑窗跟踪。

**定理 26（全链路安全分离）** 若每条目满足 `J_e` 与无源准入，且执行时始终 `clamp + PET`，则部署安全（能量/力/二次伤害上界）独立于排名正确性；排名只影响 Pareto 效率。**系**：把对排行榜的攻击面压缩为「效率攻击」；把唯一可能升级为安全事件的路径精确锁定为「无源/能量会计假设失效」。

## 7. 本轮最大风险

**一句话**：YIELD-RAS 把安全从「信念正确」搬到「能量非负」，而无源性只是**条件**保证——它要求环境/执行器无源（或有界供能）、且能量会计本身可信；一旦环境是主动的（人、储能弹性、另一台机器人）、或执行器延迟/摩擦/齿隙让能量会计漏账，PET 就会开出一张**看起来模型无关、实则建立在错误物理假设上**的安全证书，排行榜再准也无法补救，因为「只让合格者上榜」里的「合格」本身是假的。

**次级风险与缓解**：
1. **非无源/主动环境** → 有界功率界 + 独立力/位计量 + 威胁集最坏情形准入 + 明确适用域标注。
2. **能量罐长时程耗尽** → 回收打折、任务做功回充、`reserve` 管理；耗尽即让路、绝不透支。
3. **榜单非平稳/抖振** → 任意时刻有效置信序列 + 迟滞 + PSC 无源切换 + 滑窗。
4. **Goodhart/刷榜** → 密封集、污染检测、预注册、公开-密封落差、代理黑客检测；把安全-效率分离原则写进协议。
5. **柔顺牺牲精度** → 力-位 Pareto + 相位自适应；让路造成的失败必须显式记账，不能被安全指标掩盖。
6. **分离原则失效** → VQA-IV 独立复核能量账、证书哈希可追溯、准入依赖的物理假设在 Proto-Val 中逐条验收。
