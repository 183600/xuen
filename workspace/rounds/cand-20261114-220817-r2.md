> **基线继承**：上一条标注为「第 2 轮」的 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），

E 层（Edge，≤1 ms）只保留 50 Hz 安全壳与 D-Box/Pose-Box 检测；
N 层（Near，≤50 ms）承担中等代价探测；
C 层（Cloud，≤2 s）承担 VLA 假设、MP-Φ 摊销校准与全局位姿图优化。
云校正被拆成 **gauge 分量**（全局坐标系/规范自由度，可追溯应用且不改变任何相对几何与控制）与
**shape 分量**（真实相对几何，只作用于因果前沿之后）。
姿态估计同时提供第 2 轮最缺的东西：**空间/时间/物理原理都不同的独立回执**（回环闭合），
使 V 阶段不再依赖「同场景互检」的伪独立证据。

**不变式保持声明**：

- **组合单调性**：分层只改变证据到达时机，不改变证据代数；C 层离线时系统按投影退化为 ToolGauge；
- **反作用通道完备**：云校正只能经由 CHS 注入，且 shape 分量永不逆改已消费节点；
- **主张绑定**：语言主张除引用回执外，还必须标注其坐标系与 gauge 假设（定义 444）；
- **严格退化链延长**：StrataGauge（C+N+E）⇒ 云不可用/超期 ⇒ ToolGauge（E+N）⇒ 边缘过载 ⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

### 0.1 云端协同：重先验上云，但「迟到」是新的第一性问题

ToolGauge 把 VLA 假设、MP-Φ 预训练先验、AP-Cal 摊销校准都放在同一个实时系统里，
这在工程上不成立：VLA 前向 0.2–0.8 s，云端全局位姿图优化可到秒级，而 50 Hz 控制周期只有 20 ms。
云端协同的直觉是**按时间尺度分层**：
- E 层是**安全壳**：D-Box/Pose-Box 扫描、回执签名与时钟校验、风险门、力矩硬限，永不等待网络；
- N 层是**近端增强**：主动光照、敲击、跨模态互检，几十毫秒内可完成；
- C 层是**经验与全局一致性**：VLA 提假设、MP-Φ 给摊销先验、全局位姿图做回环与形状校正。

但分层引入一个比「延迟」更根本的问题：**云端返回的校正，能不能修改已经发生过的状态？**
朴素做法是「等云端回来再热替换」，于是要么阻塞控制，要么回滚历史——两者都破坏实时因果性。
第 2 轮引理 44 只证明了「子图数值等价」，它默认替换发生在同一个计算快照内，**没有时间箭头**。
本轮必须补上时间箭头：把校正拆成「可以追溯的规范分量」与「只能向前的形状分量」。

### 0.2 姿态估计：盲区不是标量，而是流形上的多模信念

D-Box 的格子 (d,m,i) 只说「这一格没验证」，σ_conf 是一个标量。姿态估计告诉我们这远远不够：
- **对称物体**（圆柱、杯子、椅子）：存在离散或连续的对称群 G_sym，位姿后验在 SE(3)/G_sym 上是**多模**的。
  把两个等价模式压成一个高斯，会得到一个「既不在模式 A 也不在模式 B」的均值，误差反而更大；
- **镜面/透明**：深度出现空洞与多路径反射，位姿后验在深度方向上出现**重尾/多模**；
- **形变/柔性物体**：刚体假设失效，残差不是噪声而是**模型偏差**，需要非刚体自由度或局部形状变量。

因此把盲区重定义为「**位姿信念在某个自由度上的声明不足**」：
不仅包括协方差被低估（第 2 轮已有），还包括**模式数被低估**（歧义亏缺）与**刚体假设被违反**（形状自由度）。
这直接改变风险门：不能只看单个高斯的 σ_pred − σ_decl，必须在**最坏模式**上取风险，并把模式熵作为独立的盲区信号。

### 0.3 合成直觉：规范校正可追溯，形状校正必须因果

设想边缘维护一个局部位姿图 X_E，云端做全局优化后得到 X_C。两者之差 Δ = X_C X_E^{-1} 包含两种完全不同的成分：
1. **规范分量 Δ_g**：只是「世界坐标系原点/朝向/（在无尺度锚时的）尺度」的选择不同。
   对任意节点 i 做 X_i' = Δ_g X_i，所有相对位姿 X_i^{-1}X_j 与所有机体坐标系观测量**逐位不变**。
   因此把 Δ_g 追溯地乘到全部历史上，**不改变任何已执行的控制**——它是物理不可观测的；
2. **形状分量 Δ_s**：真实的相对几何被修正（回环把漂移拉回、把两个物体间距离改正）。
   如果把它追溯地写进历史，就等于宣称「过去执行的控制其实作用在另一个几何世界上」——这违反因果性。

于是得到一个干净的分工：**gauge 可以追溯，shape 只能向前**。
这把「云端协同」与「姿态估计」缝成一个可证明的机制，而不是两个并列的工程模块。

## 1. 形式化定义（增量：定义 432–446）

**定义 432（分层计量架构 Tiered Metrology）** 层级 τ ∈ {E,N,C}，时延上界 ℓ_E ≤ 1 ms（嵌在 50 Hz 内）、
ℓ_N ≤ 50 ms、ℓ_C ≤ 2 s（异步）。工具库按层指派：T_E = {stereo.baseline, ir.probe, imu.preint, therm.drift}、
T_N = {illum.sweep, tap.percuss, cross.modal, local.pgo}、T_C = {vla.hypothesize, mp_phi.calibrate, global.pgo}。
每个探测带硬截止期 d_t；预算向量 **B** = (B_E, B_N, B_C, B_tot)，任一维度耗尽即触发对应层降级。

**定义 433（SE(3) 位姿回执 PR）** r = (o, ξ, Σ_ξ, G_sym, F_ref, κ, t, sig)，其中
o 为物体/关键帧 id，ξ = log(T) ∈ se(3) 为切空间位姿，Σ_ξ ∈ S⁶₊ 为切空间协方差，
G_sym ⊆ SE(3) 为声明的对称群，F_ref ∈ {world, body, anchor} 为参考系，κ 为因果纪元（定义 442），
t 为时间戳。**valid(r)** ⇔ Schema_r ∧ Pre_r ∧ Verify(sig) ∧ 时钟一致 ∧ Σ_ξ ≽ κ_phys·I。
无效回执作废且永不进入校准集（继承定义 417，并把标量 σ 换成流形协方差）。

**定义 434（位姿信念混合 PBM 与对称商）** 位姿信念
b(ξ) = Σ_{k=1}^{K} w_k · N_{SE(3)}(ξ; μ_k, Σ_k)，定义在商流形 SE(3)/G_sym 上；
连续对称（圆柱、旋转体）用 Haar 测度把求和换成积分。模式集 M(b) = {μ_k : w_k ≥ w_min}，
模式熵 H(b) = −Σ w_k log w_k，最大模式权重 w_max。对观测 z 的似然在对称轨道上取等权平均：
p(z | [T]) = (1/|G_sym|) Σ_{g∈G_sym} p(z | gT)（连续群用积分）。弯折/形变情形允许附加形状变量 u_shape。

**定义 435（位姿盲区与自由度掩码）** 位姿盲区 s = (o, M_dof ∈ {0,1}⁶, cause, M(b))：
M_dof 标记被声明不足的自由度（平移/旋转各 3 维），cause ∈ {specular, transparent, deformable, symmetric, occlusion, calibration}。
两个失配量：
- **协方差亏缺** λ_cov(s) = max_k max_{j∈M_dof} (σ_pred,k,j − σ_decl,j)；
- **歧义亏缺** λ_amb(s) = H(b) − H_decl（离散对称可用 1 − w_max 代替）。
盲区判定：λ_cov ≥ γ 或 λ_amb ≥ γ_amb；风险门按**最坏模式**取，而不是按混合均值取。

**定义 436（规范子群与规范-形状分解 GSD）** 设物理锚 A = {重力方向, 度量尺度（若已知）, 固定地图地标}。
规范子群 G_gauge = Stab(A) = {G ∈ SE(3) : G·A = A}；在只有重力锚时 G_gauge 含平移与绕重力旋转，
在无尺度锚时再含尺度（用 Sim(3) 处理）。对校正 Δ = T_C T_E^{-1} ∈ SE(3) 做
Δ = Δ_g · Δ_s，其中 Δ_g = proj_{Lie(G_gauge)}(Δ)，Δ_s = Δ_g^{-1}Δ。
称 Δ_g 为**规范分量**、Δ_s 为**形状分量**。定义可观测量 O(X) = {X_i^{-1}X_j}_{(i,j)∈E} ∪ 机体系测量；
由构造，对任意 G ∈ G_gauge，O(G·X) = O(X)。**规范-形状可辨识性条件 A119**：
锚集合 A 正确且完整——漏掉一个锚会把真实形状变化误判为 gauge（本轮最大风险，见 §6）。

**定义 437（因果前沿与因果热替换 CHS）** 在墙钟 T，因果前沿 F(T) = max{κ : epoch ≤ κ 的全部回执已校验且已消费}。
CHS 规则：
1. **gauge 分量追溯应用**：X_i ← Δ_g X_i 对所有节点（含 epoch < F(T)）立即生效；
2. **shape 分量前向应用**：X_i ← Δ_s X_i 仅对 epoch ≥ F(T) 的节点生效，并作为后续节点先验；
3. 未消费节点不构成历史，可自由合并。
**假设 A120（控制器规范等变）**：控制器只依赖机体坐标系量与相对位姿，或对世界系设定点同步施加同一 Δ_g。
A120 成立时，gauge 追溯应用对控制输出逐位不变。

**定义 438（延迟共形校准 DCC）** 校准样本带年龄 a = t_now − t_sample；权重 w(a) = exp(−λ_age·a)。
非一致性分数与加权分位数给出模式覆盖 P(∃k: d(ξ*, μ_k) ≤ q_k) ≥ 1−α。
设校准-部署分布随年龄的 TV 漂移满足 η(a) ≤ η_0 + κ·a（κ 为漂移率上界），则
覆盖率 ≥ 1 − α − 2(η_0 + κ·a) − (1 − e^{−λ_age·a})。
定义最大可用年龄 a_max 使右端 ≥ 0.8；a > a_max 的云回执降级为 **hint**，不得作为校准证据或热替换依据。

**定义 439（回环回执与独立性证书 LIC）** 回环回执 ℓ = (i, j, ξ_ij, Σ_ij, sep)，
其中 sep = (Δt, modality, Δphysical, Δspatial) 记录时间间隔、传感器模态、物理原理与空间间隔。
**certified-independent(ℓ)** ⇔ Δt ≥ T_sep ∧ modality 不同 ∧ 物理原理不同 ∧ Δspatial ≥ d_sep ∧
ℓ 与拟合集不在同一校准块。V 阶段只接受带 LIC 的回执，且要求 n_indep ≥ 2；
同一回执在不同重试间复用 ⇒ 计入污染计数（修复第 2 轮缺陷 1）。
回环同时给出**形状分量的可证伪证据**：若 Δ_s 预测的回环残差与实测 LIC 回执矛盾，则拒绝 Δ_s。

**定义 440（联邦计量聚合 FMA）** n 个机器人各自上传本地后验 (μ_j, Σ_j) 的 DP 噪声充分统计量
（机制满足 ε_dp-DP），服务器做坐标级 trimmed mean（截尾比例 f）或 median-of-means。
**拜占庭假设 A121**：恶意/故障节点数 f < n/2。聚合误差
E‖μ̂ − μ*‖ ≤ ε_hetero + σ·√(2 log(1/δ)/(n−2f)) + O(σ_dp·√d/(ε_dp·√n))，
其中 ε_hetero 为机器人间环境异质性，DP 项给出隐私-精度 Pareto。f ≥ n/2 时 FMA 关闭，退回单机先验。

**定义 441（云信任等级与证伪预算）** 云回执分三级：signed（可验签）、reproducible（可复算哈希）、
cross-checked（已被至少一条 LIC 回环确认）。**证伪预算 F_bud**：每个纪元内每条 shape 校正必须在
horizon H_f 内被至少一条独立 LIC 回执证伪检查；未检查的 shape 校正标记为 **provisional**，
其影响半径（可修改节点数）按 F_bud 线性限制。云投毒因此不能一次性改写全局几何。

**定义 442（全局逻辑时钟与跨层回执序）** 每个回执携带 (κ, t, seq, robot_id)：
κ 为 Lamport 因果纪元，t 为带偏斜上界 δ_clock 的墙钟，seq 为单工具单调序号。
跨层合并时按 κ 排序，t 仅用于年龄与漂移计算；|t_i − t_j| > δ_clock 且 κ 不可比 ⇒ 回执 quarantined。
把第 2 轮「单工具 seq 单调」升级为跨层因果序（修复缺陷 6）。

**定义 443（分层退化链）** 定义投影 π_C（令 T_C=∅、Δ=0）得 ToolGauge；π_E（令 T_N=T_C=∅、Pose-Box→标量 D-Box）
得 LeanGauge；π_M（全部增强关闭）得 MODGAUGE。退化链：
StrataGauge --C 超期/断网--> ToolGauge --E 过载--> LeanGauge --失效--> MODGAUGE。
每一级都用同一套回执接口，降级不改变 50 Hz 路径契约。

**定义 444（规范等价契约 GEC）** EC 新增字段 frame = (F_ref, G_gauge, anchors, κ)；
热替换必须携带证书：O(X) 在替换前后逐项相等（容差 ε_num），且 claims 中每个数值标注其坐标系。
语言主张若未标注 frame 或引用了已过期 epoch 的回执，在序列化时剥离（扩展定义 423）。

**定义 445（全局预算与公平调度）** 总预算 B_tot 由所有盲区共享；调度器用 deficit round-robin：
每个盲区按权重获得配额，单轮最多提前消费 1 个配额单位。
**无饥饿条件**：若盲区集合有限且 B_tot > 0，任一盲区等待轮数 ≤ ⌈|S|/w_min⌉。
这修复第 2 轮「每盲区预算独立、全局可被少数盲区吃光」的缺陷（缺陷 5）。

**定义 446（继承与编号约定）** 未被本轮重定义的第 2 轮记号（r, Π_s, λ, β, MP-Φ, H_s, SNC, P-Quarantine 等）
沿用定义 416–431；所有增量以 ToolGauge 为退化特例：
令 T_C=∅、G_gauge=SE(3)、PBM 退化为单高斯、回环回执退化为 cross.modal ⇒ StrataGauge ≡ ToolGauge。

# IP-322 Pose-Box：SE(3) 多模信念 + 对称商 + 自由度掩码
@dataclass
class PoseReceipt:
    obj: str; xi: np.ndarray; Sigma: np.ndarray      # xi=log(T)∈se(3), Sigma∈S⁶₊
    G_sym: "SymmetryGroup"; ref: str; epoch: int; t: float; sig: bytes

class PoseBox:
    def detect(self, cell):
        b = self.se3_filter(cell.stereo, cell.imu, cell.depth)      # 混合信念
        b = quotient_symmetry(b, cell.symmetry_prior)               # SE(3)/G_sym
        modes = [m for m in b.modes if m.w >= W_MIN]
        lambda_cov = max(m.gap(mask) for m in modes for mask in DOF_MASKS)
        lambda_amb = entropy(b) - self.declared_entropy
        if max(lambda_cov) >= GAMMA or lambda_amb >= GAMMA_AMB:
            return BlindSpot(cell.obj, argmax_mask(modes), cause(b), modes)
        return None

# IP-323 GSD：规范-形状分解
class GaugeDecomposer:
    def decompose(self, T_edge, T_cloud, anchors):
        G   = stabilizer(anchors)                 # 定义 436
        D   = T_cloud @ inv(T_edge)
        Dg  = project_lie(D, lie_algebra(G))      # 规范分量
        Ds  = inv(Dg) @ D                         # 形状分量
        return Dg, Ds

# IP-324 CHS：因果热替换（gauge 追溯，shape 前向）
class CausalHotSwap:
    def apply(self, Dg, Ds, frontier):
        self.global_frame = Dg @ self.global_frame          # 允许追溯；A120 下控制不变
        for node in self.graph.nodes:
            if node.epoch >= frontier:                      # 只动未消费节点
                node.pose = Ds @ node.pose
        self.graph.reanchor(self.global_frame)

# IP-321 TierSched：分层指派 + 全局公平预算
class TierScheduler:
    TIERS = {"E": (T_E, 1e-3), "N": (T_N, 50e-3), "C": (T_C, 2.0)}
    def assign(self, probe, B):
        for tier in ("E", "N", "C"):
            if probe.tool in self.TIERS[tier][0] and probe.deadline >= self.TIERS[tier][1]:
                if B[tier] >= probe.cost: return tier
        return None
    def schedule(self, probes):                      # deficit round-robin（定义 445）
        return round_robin_by_blind_spot(probes, self.quotas)

# IP-325 DCC + FMA：延迟共形 + 联邦鲁棒聚合
class DelayedConformal:
    def quantile(self, cal, alpha, now):
        w = np.exp(-LAMBDA_AGE * (now - cal.t))
        a = now - cal.t
        if a.max() > A_MAX: return None              # 降级为 hint
        return weighted_quantile(cal.scores, w, 1 - alpha)

def federated_aggregate(local, f, eps_dp):
    if f >= len(local) / 2: return None              # A121 失效 ⇒ 单机
    stats = [dp_noise(p.mu, p.Sigma, eps_dp) for p in local]
    return trimmed_mean(stats, trim=f)               # 定义 440

# IP-326 主闭环：云校正只经 CHS 注入
def stratagauge_round(M, obs, audio, tac, depth, det):
    for s in M.posebox.detect(M.dbox.R):
        if s not in M.inflight:
            tier = M.sched.assign(probe_of(s), M.B)
            if tier is None: M.degrade(s); continue
            M.inflight.add(s)
            submit_async(solve_blind_spot, M, s, tier)      # E/N/C 各自时限
    for (Dg, Ds, lic) in M.cloud.drain_ready():

            M.cloud.demote(Dg, Ds); continue
        if not M.gsd.verify_shape(Ds, lic):                 # shape 可证伪
            M.cloud.quarantine(); continue
        M.chs.apply(Dg, Ds, M.frontier())                    # gauge 追溯 / shape 前向
        M.pquar.extend_cross_tier(Ds)                        # 定义 428 的跨层扩展
    if M.cloud.stale() or M.net.down():
        M.degrade_to_toolgauge()                             # 定义 443
    return MODGAUGE_round(M, obs, audio, tac, depth, det)     # 50 Hz 主控不变

## 3. 推导

**引理 51（分层时延与全局预算保持）** E 层只含 O(1) 回执校验、D-Box/Pose-Box 扫描与风险门，
单周期增量 < 0.2 ms；N/C 层探测全部异步于 50 Hz 路径。若每层预算按定义 432/445 硬顶，
则 50 Hz 硬实时（引理 45）保持；单盲区修复时延 ≤ ℓ_N·L_N + ℓ_C + τ_V（若需云形状校正），
且 C 层超期即由定义 443 降级，不阻塞控制。

**引理 52（规范校正的追溯无害性）** 设 A120 成立。对 G ∈ G_gauge，O(G·X) = O(X)（定义 436 构造）；
控制器只依赖 O，故对任意节点子集（含全部历史）施加 G 不改变任何已执行控制输出。证毕。
**系 52.1**：若控制器使用世界系绝对设定点，则这些设定点必须作为锚加入 A，使 G_gauge 缩小；
若 A 使 G_gauge 退化为平凡群，则不存在可追溯校正，所有云校正都按 shape 处理（保守但安全）。

**引理 53（形状校正的因果非预测性）** shape 分量 Δ_s 只作用于 epoch ≥ F(T) 的节点。
对任意 t ≤ T，作用于 t 时刻控制的节点均满足 epoch < F(T)，其位姿在 Δ_s 应用前后逐位相同；
故系统在 [0,T] 上的控制轨迹与未接收云校正时逐位相同。定义「F-因果轨迹等价」即由此成立。
（注意：这不保证未来轨迹相同——形状校正本来就要改变未来。）

**引理 54（延迟共形的覆盖下界）** 在定义 438 的漂移模型 η(a) ≤ η_0 + κa 下，
加权共形覆盖率 ≥ 1 − α − 2(η_0 + κ·a) − (1 − e^{−λ_age·a})。
证明：标准加权共形给出 1−α−(1−e^{−λ_age a}) 的权重质量损失项；漂移以 TV 的 2 倍进入覆盖损失。
**系 54.1**：给定 SLA 0.8，可反解 a_max；云回执超过 a_max 只能作 hint。这补上第 2 轮未建模的「回执年龄」。

**引理 55（对称歧义下风险门的保守性）** 若位姿真值分布在模式集 M(b) 上，
则单模风险门最多只能覆盖权重 w_max 的质量；按最坏模式取 λ_cov 并以模式熵触发 λ_amb，
可使「真实误差超过声明」的漏检概率 ≤ α + (1 − w_max)。
已知 G_sym 时，商化把等价模式合并，漏检回到 1−α；未知 G_sym 时禁止热替换（只能探测）。
**系 55.1**：把未知对称物体误当单模，是姿态估计给本方案引入的新失效模式，必须由 E442 专项验证。

**引理 56（联邦拜占庭 + DP 聚合误差）** 在 A121（f < n/2）下，坐标级 trimmed mean 的崩溃点为 f/n；
对亚高斯本地后验，聚合误差 ≤ ε_hetero + σ√(2 log(1/δ)/(n−2f)) + O(σ_dp√d/(ε_dp√n))。
DP 项随 ε_dp 减小而增大，给出「隐私预算 ↑ ⇒ 校准精度 ↓」的显式 Pareto；ε_dp 进入 TB-Contract 的预算向量。

**引理 57（分层退化等价）** 令 T_C=∅ 且 Δ=0，则 StrataGauge 的 H→C→E→C→V→U 与 ToolGauge 的 6C 逐条同构；
再令 T_N=∅ 且 Pose-Box 退化为标量 D-Box，则与 LeanGauge 同构。因此新增层是**增强项而非依赖项**，
严格退化链（定义 443）在代数上成立，而非仅是工程口号。

# IP-321 Pose-Box
class PoseBox:
    def detect(self, cell):
        b = quotient_symmetry(self.se3_filter(cell.stereo, cell.imu, cell.depth),
                              cell.symmetry_prior)
        modes = [m for m in b.modes if m.w >= W_MIN]
        lam_cov = max(m.gap(mask) for m in modes for mask in DOF_MASKS)
        lam_amb = entropy(b) - self.declared_entropy
        return BlindSpot(cell.obj, argmax_mask(modes), cause(b), modes) \
               if max(lam_cov) >= GAMMA or lam_amb >= GAMMA_AMB else None

# IP-322 TierSched：分层 + 公平预算
class TierScheduler:
    TIERS = {"E": (T_E, 1e-3), "N": (T_N, 50e-3), "C": (T_C, 2.0)}
    def assign(self, probe, B):
        for tier, (tools, lat) in self.TIERS.items():
            if probe.tool in tools and probe.deadline >= lat and B[tier] >= probe.cost:
                return tier
        return None
    def schedule(self, probes): return round_robin_by_blind_spot(probes, self.quotas)

# IP-323 GSD
class GaugeDecomposer:
    def decompose(self, T_edge, T_cloud, anchors):
        G  = stabilizer(anchors)
        D  = T_cloud @ inv(T_edge)
        Dg = project_lie(D, lie_algebra(G))
        return Dg, inv(Dg) @ D
    def verify_shape(self, Ds, lic):        # shape 必须被独立回环证伪
        return all(predicted_loop_residual(Ds, l) <= eps_loop for l in lic)

# IP-324 CHS
class CausalHotSwap:
    def apply(self, Dg, Ds, frontier):
        self.global_frame = Dg @ self.global_frame
        for node in self.graph.nodes:
            if node.epoch >= frontier:
                node.pose = Ds @ node.pose
        self.graph.reanchor(self.global_frame)

# IP-325 DCC + FMA
class DelayedConformal:
    def quantile(self, cal, alpha, now):
        if (now - cal.t).max() > A_MAX: return None
        w = np.exp(-LAMBDA_AGE * (now - cal.t))
        return weighted_quantile(cal.scores, w, 1 - alpha)

def federated_aggregate(local, f, eps_dp):
    if f >= len(local) / 2: return None
    return trimmed_mean([dp_noise(p.mu, p.Sigma, eps_dp) for p in local], trim=f)

# IP-326 主闭环
def stratagauge_round(M, obs, audio, tac, depth, det):
    for s in M.posebox.detect(M.dbox.R):
        if s not in M.inflight:
            tier = M.sched.assign(probe_of(s), M.B)
            if tier is None: M.degrade(s); continue
            M.inflight.add(s); submit_async(solve_blind_spot, M, s, tier)
    for (Dg, Ds, lic) in M.cloud.drain_ready():
        if not certify_independent(lic, n_min=2): M.cloud.demote(Dg, Ds); continue
        if not M.gsd.verify_shape(Ds, lic):       M.cloud.quarantine(); continue
        M.chs.apply(Dg, Ds, M.frontier())
        M.pquar.extend_cross_tier(Ds)
    if M.cloud.stale() or M.net.down(): M.degrade_to_toolgauge()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 51（分层时延/预算保持）** E 层仅 O(1) 校验与扫描，单周期增量 <0.2 ms；N/C 全异步。
按定义 432/445 硬顶预算，50 Hz 硬实时保持；C 超期由定义 443 降级，不阻塞控制。

**引理 52（规范校正追溯无害性）** A120 下，对 G∈G_gauge 有 O(G·X)=O(X)，控制器只依赖 O，
故对全部历史施加 G 不改变任何已执行控制输出。**系 52.1**：绝对世界系设定点必须作为锚，否则 G_gauge 缩小；
G_gauge 平凡时不存在可追溯校正，全部按 shape 处理。

**引理 53（形状校正因果非预测性）** shape 只作用于 epoch≥F(T) 的节点；t≤T 的控制节点 epoch<F(T)，
位姿前后逐位相同 ⇒ [0,T] 控制轨迹与未收云校正一致（F-因果轨迹等价）；未来轨迹允许改变。

**引理 54（延迟共形覆盖）** 权重损失 + TV 漂移：覆盖 ≥ 1−α−2(η_0+κa)−(1−e^{−λ_age a})；
**系 54.1**：给定 SLA 0.8 反解 a_max，超龄回执只能作 hint。

**引理 55（对称歧义风险门保守性）** 单模风险门最多覆盖 w_max 质量；最坏模式 + 模式熵触发使漏检 ≤ α+(1−w_max)；
已知 G_sym 时商化恢复到 1−α；未知对称禁止热替换。**系 55.1**：未知对称误当单模是本方案的新失效模式（E442）。

**引理 56（FMA 拜占庭+DP 误差）** A121 下 trimmed-mean 崩溃点 f/n；误差
≤ ε_hetero + σ√(2log(1/δ)/(n−2f)) + O(σ_dp√d/(ε_dp√n))；ε_dp 进入预算向量。

**引理 57（分层退化等价）** T_C=∅ 且 Δ=0 ⇒ 6C 与 ToolGauge 逐条同构；再 T_N=∅ 且 Pose-Box→标量 D-Box ⇒ LeanGauge。
故新增层是增强项，退化链在代数上成立。

## 8. 本轮最大风险

**一句话**：GSD 依赖**规范子群被正确识别**——若真实形状误差（尺度漂移、未建模连续对称、云端投毒偏置）被误判为 gauge，
系统会把错误当作「物理不可观测的换系」**追溯写入全部历史节点**，使真实几何错误看起来无害且已被证明，
而局部残差与 LIC 回环可能因同一误判同时失去检验力；这是一次**坐标系的自我欺骗**，会污染所有下游控制与语言证书，
以 E443/E449/E453/E454 证伪，以 A119 锚可辨识性检查、未知对称禁热替换、证伪预算 F_bud 与 FMA 拜占庭界四重兜底。
