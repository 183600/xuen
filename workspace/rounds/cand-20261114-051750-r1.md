# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「灵巧操作」×「需求洞察」）

> R69 问出了「我该向谁求证、还能问什么」，但它的整个式子里藏着一个未言明的前提：**要消解的那个 M 是世界的属性**——接触模式、动作模态、传感器是否可信。它把「向人提问」当成一条可靠的观测通道，仿佛只要问得对，答案就会揭示一个**固定不变的隐藏真值**。然而「需求洞察」恰恰相反：用户自己也常常不知道自己要什么，**需求是在看到选项、摸到实物、试过一次之后才被建构出来的**。于是 R69 最优雅的那一步（VoI = 问完之后熵会降多少）在最关键的地方失效：答案不是被「读出」的，而是被机器人的动作**诱发**的。
>
> 「灵巧操作」补上的正是这个缺口：手不只是执行器，也是**提问器官**。把物体以不同方式托起、旋转、递出、做出一个半成品的示范——这些接触丰富的动作是**可以被人直接读懂、且可逆的物理问题**；人的接受、抗拒、纠正、迟疑，是比口头回答带宽更高、社会成本更低的**显示性偏好信号**。一句「你想要哪个」可能得到礼貌的谎话；一只稳稳递到面前、随时可以推回的手，得到一个更诚实的答案。
>
> 核心命题：**把 R69 的 epistemic 再拆成 world-epistemic（世界的隐藏事实）与 demand-epistemic（目标函数/成功判据的隐藏参数）；前者靠接触探询，后者靠「灵巧操作作为物理提问」的因果识别；而安全约束对需求完全不变——需求只决定在可行集里选哪一点，绝不决定可行集本身。** 命名 **CRAFT-RAS**（Contact-Rich Adaptive Feedback for Task-specification）：需求不是被「问出来」的，而是被**共同 craft（做）出来**的。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**你真正要的到底是什么，而且它会不会因为我这样问而改变**」。

## 0. 直觉与动机

**灵感 1（需求不是隐藏常量，而是被动作诱发的变量）**
直觉：经典偏好推断假设「用户心里有一个固定的排序，问得越多估得越准」。但真实场景里存在菜单依赖与建构效应：同一个杯子，被「递到你右手边、杯柄朝外」和「放在桌上、让你自己够」两种方式呈现，用户会给出不同的偏好表达，甚至改变后续期望。若把 R69 的 M 换成需求 θ*，那么 `π = Π(θ*, offer, context)` 里的 offer 正是机器人自己选的——**自变量的选择依赖因变量的估计目标**，这是内生性，不是噪声。所以「需求洞察」的第一性原理不是「多问」，而是「**制造与需求无关的外生变异**」（随机化呈现方式），把 θ* 从「呈现效应」里分离出来。

**灵感 2（灵巧操作 = 物理提问：可读、可逆、接触接地）**
直觉：语言提问有两个毛病——社会期许偏差（人会说你想听的）与语义错位（词不达意）。而一只托着物体、掌心朝上、随时可退回的手，是一个**低承诺、高可读**的物理命题：「我猜你想这样拿，对吗？」。它的优点来自操作本身：a) **可读性**（动作的语义对人类直接可理解，不需要读心）；b) **可逆性**（可以 undo，未承诺）；c) **接触接地**（把抽象的「要」落到具体的力、姿态、温度上）。于是「灵巧操作」在本轮不是任务本体，而是**测量仪器**。

**灵感 3（双 latent 与双用途探针）**
直觉：一次接触动作同时在探测两样东西——物性（多重、摩擦、接触模式，world-epistemic）与人的接受度（demand-epistemic）。R69 的探针只算前者；而一个「先掂一掂再递给你」的动作把两者压进同一次物理交互，单位成本信息增益因此超加。这给出本轮的效率论证：**接触是需求的传感器，也是世界的传感器**。

**灵感 4（安全不变性：需求只排序，不扩集）**
直觉：最容易犯的错，是让「洞察到的需求」反过来改写安全约束——用户说「快点、别管洒」，系统就放松力限、放大速度。本轮立一条铁律：**硬约束集合 F 与 θ* 无关**；需求只在 F 内改变软目标的排序。这样「需求估计错」最多让任务做得不合心意，绝不会让物理安全变差。这是把 R68/R69 的保守主义继续往下继承的正确姿势。

**灵感 5（洞察的黑暗面：系统可以反向制造需求）**
直觉：一旦机器人能设计 offer，它也能用 offer 去「锚定」人、用便利的选项把人的表达偏好推向对自己容易的角落。这与 R69 的「交互投毒」是镜像：R69 怕外部骗系统，R70 怕**系统骗人**。所以「需求洞察」必须同时是「需求审计」：操纵势 μ(o) 要上界化、要可审计、要能一键关闭。

**灵感 6（双时间尺度：内环不动，外环做洞察）**
直觉：需求洞察天然是慢过程（秒~分钟级），不该挤进 1kHz 安全内环。因此 CRAFT-RAS 明确分两层：**内环完全等于 R69**（实时安全不妥协），**外环 ~1Hz** 做后验更新、物理提问、因果识别。这既守住了 P99 实时预算，也让「洞察」可以承担更贵的计算（随机化、多次接触、审计）。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（CRAFT-RAS 总览）** CRAFT-RAS = (DIL, CRF, DEX, CDI, VoSI, RIG, DCG, RAS-WM‡)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；内环逐指令等于 R69 FLUID-RAS）；
(ii) **硬约束不变性**：安全可行集 F = {a | C(a) ≤ 0} 与需求 θ* 独立，需求只能在 F 内改变排序；
(iii) **可逆探询**：洞察阶段的物理提问必须可 undo（定义 318），不可逆承诺动作必须过承诺门；
(iv) **反操纵与证据纪律**：操纵势 μ(o) ≤ μ_max，单次响应不得单独定案，且禁止 sycophancy（以表达偏好覆盖硬约束或高置信潜在需求）。

**定义 311（双 latent 与结构化响应模型）** 世界状态 w_t（接触模式 σ、质量、摩擦、物体位姿）；潜在需求 θ* ∈ Θ ⊂ ℝ^{d_θ}（目标函数 J_{θ}、成功判据、偏好权重）；上下文/指令 c。机器人选择物理提问 o^{offer} ∈ O_offer（参数 ψ = 呈现方式/候选变体）。表达偏好 π = Π(θ*, ψ, c, ν)（ν 为情境噪声，Π 含**菜单/呈现效应**）；响应 r ~ R(·|π, θ*, ψ, c)（隐式：接受/抗拒/纠正/迟疑；显式：语言）。观测 o =（传感器流，人类信号）。

**定义 312（需求后验与可识别性）** 需求后验 p(θ*|h_t) 由 DIL 维护。设外生随机化：以概率 ε 把 ψ 替换为与 θ* 独立的 q(ψ)。若 (a) ε > 0，(b) 呈现效应 Π 对 ψ 的参数化与 θ* 可分离（秩条件），则 θ* 可由去混杂 MLE 一致估计；否则估计偏差由引理 20 界定。θ* 的**因果**信息增益记 I_c(θ*; r | do(ψ))。

**定义 313（灵巧提问空间与可逆阶梯）** o^{offer} ∈ O_offer ⊂ 𝒜_+，须过接触约束（力/位/时序包络）。可逆等级 ℓ(a) ∈ {0,1,2}：0 = 可完全 undo（恢复态误差 ≤ δ_undo、时间 ≤ τ_undo）；1 = 条件可逆（需重规划）；2 = 不可逆/承诺。洞察阶段只允许 ℓ=0；ℓ=2 仅在承诺门（定义 318）打开后执行。

**定义 314（接触丰富流策略 CRF）** 在 R69 FMP 基础上，状态增广接触时序 σ_{t:t+H} ∈ {0,1}^{n_c×H}（各接触点是否闭合/滑动/滚动）。混合流：先由 mode_head 采样 K 个接触时序 {σ^{(j)}}，再在每个 σ 内做 rectified flow 采样 `x_s=(1−s)x_0+s x_1`，速度场 v_θ(x_s,s|z,σ)。接触模式的多峰性（捏/握/滚/滑）即 U_w 的显式形状；掩码损失只在接触区间回传力/位置梯度。采样后 `decode(x,σ)` 得到 `ξ=(a,g)` 及 offer 片段。

**定义 315（双 epistemic 分解）** 沿用 R69 的 U_ale；把 U_epi 细分为：
- `U_w = H(σ|o) · κ_w`（接触模式熵 × 后果敏感度，可约，靠接触探询）；
- `U_d = H(θ*|h)`（需求后验熵）与其**期望后悔** `R_d = E_{θ∼p(θ*|h)}[J_{θ}(a*) − J_{θ}(a)]`（可约，靠物理提问 + 因果识别）。
两者分通道：U_w 走 CRF/DEX 的接触探询；U_d 走 DEX/CDI 的偏好识别；仅在都消解不了时才回 R69 兜底。

**定义 316（传感运动洞察价值 VoSI）** 对候选提问 o，`VoSI(o) = [I_c(θ*; r | do(ψ_o)) + λ_w·I(w; y_c | o)] / (c_phys(o) + c_social(o) + c_undo(o))`。约束：`o ∈ F`、`ℓ(o)=0`、`μ(o) ≤ μ_max`、预算未超。选 `o* = argmax VoSI`；若 `VoSI(o*) ≤ 0`，不提问，退化为 R69 的 VoI 决策。λ_w 是双用途权重（接触同时降低 U_w）。

**定义 317（因果提问随机化 CDI）** 为避免「自己所选 offer 造成的内生偏差」，每次洞察以概率 ε 使用外生菜单 `ψ ~ q(·)`（与当前信念无关），以概率 1−ε 使用 VoSI 最优菜单。去混杂估计：对呈现效应 Π 建参数模型，用随机化样本作工具变量，联合估计 (θ*, Π)。ε 是**识别性—效率**折中：ε↓ 效率高但偏差大，ε↑ 无偏但信息少（引理 20 给出最优 ε*）。

**定义 318（可逆阶梯与承诺门 RIG）** 洞察阶段的提问必须满足 ℓ=0 且 undo 见证（可恢复到 δ_undo 内）。承诺动作（ℓ=2）仅在 `tail_risk(a; p(θ*|h)) ≤ ε_commit` 且（显式确认∨需求后验校准置信）时放行；否则继续可逆探询或回退安全默认动作。承诺门的物理风险与 R69 定理 17 的 ε_int 兼容。

**定义 319（需求校准门 DCG）** 需求后验须校准（可靠图 + ECE）。`ECE_d > τ_ece` ⇒ 禁用自适应 offer 与承诺，退回「R69 + 最小假设默认需求」，即不让一个不可信的需求分布驱动物理提问或任务选择（R69 表征坍缩门的「需求版」）。

**定义 320（反操纵与反谄媚）** 操纵势 `μ(o) = E[D_KL(Π(θ*,ψ_o,c) ‖ Π(θ*,∅,c))] − fit(o)`，其中 fit 为与真实拟合度相关的、可被正当化的部分。约束 `μ(o) ≤ μ_max`。反谄媚：若表达偏好 π 与高置信潜在需求 θ* 冲突、或 π 要求突破硬约束，则拒绝执行并触发审计（不得因「用户说了」而解除安全）。

**定义 321（参与式需求审计 VQAuditor-D）** 审计对象新增洞察决策：是否锚定/诱导、offer 是否单源定案、是否从一次响应过度泛化、是否存在 sycophancy、操纵势是否越界、洞察结论的证据溯源性（provenance）。结论回灌 AuditBuf，成为下一轮 VoSI 的成本与 μ_max 先验。

**定义 322（需求对抗集 ℰ_DEMAND）** 欺骗性反馈、对抗性偏好注入（恶意用户）、多人需求冲突、分布外需求（OOD need）、需求漂移（preference drift）。并入 AIC：`ℰ_CRAFT = ℰ_FLUID × ℰ_DEMAND`。

**定义 323（证书 J_CRAFT）** `J_CRAFT = (J_FLUID, demand_posterior_ece, identifiability_strength, reversibility_witness, manipulation_potential, hard_constraint_invariance, insight_provenance_hash, craft_ver)`。Valid ⇔ Valid(J_FLUID) ∧ ECE_d ≤ τ_ece ∧ ∀o ℓ=0（或承诺门通过）∧ μ ≤ μ_max ∧ 硬约束不变性证明存在。

**定义 324（洞察预算与停止准则）** 边际 VoSI 递减、时间压力上升。停止条件：`VoSI(o*) < c_stop` 或后验稳定（`ΔH(θ*) < δ_h` 连续 m 轮）或预算耗尽；停止后按当前后验选最优可行动作，并标记「洞察未收敛」进入证书。

**定义 325（对 R69 的严格包含）** 令 U_d=0 且关闭 offer（ε=1、O_offer=∅），则 VoSI→VoI、CRF→FMP、DEX/CDI 空操作，CRAFT-RAS 与 FLUID-RAS **逐指令相同**。故 R69 是 CRAFT 在「需求已知且不作物理提问」边界上的退化。

## 2. 关键算法骨架

```python
# IP-264 DIL：双 latent 后验（世界 w × 需求 θ*）
class DualLatentBelief:
    def __init__(self, theta_prior, world_prior):
        self.p_theta = theta_prior          # p(θ*|h)：低维（<64d），可参数化
        self.p_world = world_prior          # 接触模式/质量/摩擦
    def update(self, r, offer, h):
        # 结构化响应模型 π = Π(θ*, offer, c)，显式建模呈现效应
        self.p_theta = bayes_update(self.p_theta, r,
                                     model=response_model(offer.psi))
        return self.p_theta

# IP-266 CRF：接触丰富流策略（扩展 R69 FMP；零重复 trunk）
class ContactRichFlow:
    def sample(self, o, K, N_step=2):
        z = self.trunk(o)
        sigmas = self.mode_head(z).sample(K)          # 捏/握/滚/滑 接触时序
        out = []
        for sigma in sigmas:
            xs = randn(D)
            for i in range(N_step):
                xs = xs + (1.0/N_step) * self.v(xs, i/N_step, z, sigma)
            out.append(self.decode(xs, sigma))        # ξ=(a,g[,offer])
        return out

# IP-265 DEX：可逆、可读的物理提问库
class DexterousElicitor:
    def offers(self, theta_posterior, n_max=6):
        # 每个 offer = 一个候选需求的可逆物理示范（ℓ=0）
        return reversible_menu(theta_posterior, n_max=n_max,
                               legibility=self.legibility_model)

# IP-267 CDI：随机化去混杂，识别 θ*
def identify_need(belief, r, offer, rng, eps=0.3):
    psi = rng.choice(exogenous_menu()) if rng.random() < eps else offer.psi
    return deconfounded_update(belief.p_theta, r, psi,
                               menu_effect_model=Pi_param)

# IP-268 VoSI：因果信息增益 + 接触双用途，受可逆/操纵/安全约束
def choose_elicitation(belief, offers, budget, guards):
    best = None
    for o in offers:
        if not guards.in_safe_set(o):        continue   # 硬约束与 θ 无关
        if not guards.reversible(o):         continue   # ℓ=0 + undo 见证
        if guards.manipulation(o) > guards.mu_max: continue
        ig = (causal_info_gain(belief.p_theta, o)       # 需求：do(ψ)
              + guards.lam_w * world_info_gain(belief.p_world, o))  # 接触双用途
        score = ig / (cost(o) + guards.undo_cost(o))
        if best is None or score > best[1]: best = (o, score)
    return best[0] if best and best[1] > 0 else None     # 无利可图 → R69

# IP-269 RIG：硬约束不变性 + 可逆阶梯 + 承诺门
class ReversibilityInvariantGuard:
    def in_safe_set(self, o): return hard_constraints(self.state, o) <= 0  # 与 θ 无关
    def reversible(self, o):  return o.ell == 0 and undo_within(o, self.delta_undo)
    def may_commit(self, belief, a):
        return (belief.tail_risk(a) <= self.eps_commit
                and (explicit_confirm(a) or belief.calibrated_confident(a)))

# IP-274 CRAFT-RAS 主闭环（内环 1kHz = R69；外环 ~1Hz 洞察）
def CRAFT_round(M, obs, phase):
    if phase == 'inner':
        return M.fluid.fluent_round(obs)              # 安全内环：逐指令等于 R69
    belief = M.dil.update(M.last_r, M.last_offer, obs.history)
    if not M.dcg.trusted(belief):                     # ECE 越界 → 默认需求 + R69
        return M.fluid.fluent_round(obs)
    offers = M.dex.offers(belief.p_theta)
    o = M.vosi.choose_elicitation(belief, offers, M.budget, M.rig)
    if o is not None:
        r = M.hardware.enact(o)                       # 可逆物理提问
        belief.update(r, o, obs.history)
        M.vqa_d.submit(o, r, belief)                  # 审：锚定/诱导/操纵/sycophancy
    elif M.rig.may_commit(belief, M.candidate):
        return M.commit(M.candidate)                  # 高置信才承诺
    return M.fluid.fluent_round(obs)                  # 否则保守执行（R69）
```

## 3. 推导

**引理 19（硬约束不变性 ⇒ 需求误差不进安全）** 设 F={a|C(a)≤0} 与 θ* 独立，CRAFT 对任意后验 p(θ*|h) 都只在 F 内选动作。则对任意需求估计误差，`sup_a risk_hard(a) ≤ ε_safe` 与 θ̂ 无关；需求误差只影响软目标 J_θ 的排序。系：**「用户说要快」不能解除力/位/社交硬约束**——这堵死了把偏好泄漏进安全约束的最坏路径。

**引理 20（表演性偏差界）** 设 offer 由当前信念选择，呈现效应灵敏度 `L_Π = sup‖∂Π/∂ψ‖`，则 `|E[θ̂] − θ*| ≤ L_Π·E‖ψ − ψ_⊥‖ + σ/√N`（ψ_⊥ 为与 θ 独立的外生菜单）。以概率 ε 随机化时 `bias ≤ (1−ε)·L_Π·ψ_max + C/√(εN)`，存在最优 `ε* = argmin` 该折中。系：**洞察必须主动做一部分「非最优」的提问**，用外生变异换可识别性；纯贪心 VoSI 的 offer 会系统性高估「容易被呈现出来的需求」。

**引理 21（接触探询的双用途超加性）** 设接触观测 y_c 把世界 nuisance 方差由 σ_w² 降为 σ_w²(1−ρ_c)，响应噪声近似高斯。则 `I(θ*; r | do(ψ), y_c) − I(θ*; r | do(ψ)) ≥ ½log(1/(1−ρ_c))`。故当 ρ_c>0 时，**接触接地的物理提问在同等成本下严格优于纯语言提问**；ρ_c→1（世界几乎被接触确定）时优势最大。这是「灵巧操作作为需求传感器」的定量理由。

**定理 18（CRAFT 严格包含 R69）** 在 A95–A99、DCG 可信、可识别（定义 312）下，CRAFT 的期望软目标 `E[J_{θ*}] ≥ E[J_{θ*}]_{R69}`，且硬约束风险 `≤ R69`。证明要点：U_d=0 且 O_offer=∅ 时逐指令等于 R69（定义 325）；U_d>0 时所有探询在 F 内且 ℓ=0，安全不劣；VoI/VoSI 的期望信息增益非负，故后验更优、best-response 不减。因此 R69 = 「不洞察、不物理提问」边界，安全不让步、效率获 insight bonus。

**定理 19（可逆探询的无承诺伤害）** 在可逆阶梯（ℓ=0）与承诺门（定义 318）下，洞察阶段任何物理伤害被限定在 offer 包络 `≤ ε_offer`；错误承诺概率 `≤ P(tail_risk > ε_commit) ≤ δ_commit`；undo 在 `(δ_undo, τ_undo)` 内恢复。故洞察可在任意时刻中止且后悔有界，且继承 R69 无突变（定理 17）。

**定理 20（反操纵上界）** 若对每个 offer 施加 `μ(o) ≤ μ_max`，则 `D_KL(Π(θ*,ψ_o,c) ‖ Π(θ*,∅,c)) ≤ μ_max`（减去可正当化的 fit 项）。即机器人通过 offer 设计对表达偏好的**总推移不超过 μ_max nat**，从而给「制造共识」一个可审计的上界；审计估计 μ 越界即关闭 offer。

## 6. 本轮最大风险

**一句话**：CRAFT-RAS 最大的风险是**内生性/表演性**——机器人自己设计的物理提问会**建构**它随后「洞察」到的需求（呈现效应 + 确认偏误 + 系统性高估易展示的偏好），使「需求洞察」退化为**制造共识**：系统可能极其自信地服务一个它亲手诱导出来的伪需求；一旦这条偏差再经「需求驱动目标函数」渗进约束或长期策略，安全与伦理会同时失守。

**次级风险与缓解**：
1. **需求估计偏差被误当真相** → 外生随机化（定义 317）+ 引理 20 偏差界 + E305；
2. **硬约束被「用户偏好」侵蚀** → 硬约束不变性（引理 19）+ 反谄媚（定义 320）+ E307/E309；
3. **物理提问不安全/不可逆** → ℓ=0 + undo 见证 + 承诺门（定义 318、定理 19）；
4. **系统反向操纵人** → 操纵势上界 μ_max + VQAuditor-D（定义 320–321）+ E308；
5. **洞察挤占实时预算** → 双时间尺度，内环逐指令等于 R69，洞察仅在 ~1Hz 外环（定义 324、定理 18）。

def choose_elicitation(belief, offers, guards):

    for o in offers:
        if not guards.in_safe_set(o) or not guards.reversible(o): continue

## 4. 推导

**引理 19（硬约束不变性）** F={a|C(a)≤0} 与 θ* 独立，CRAFT 对任意后验只从 F 选动作 ⇒ `sup risk_hard ≤ ε_safe` 与需求估计误差无关。系：需求误差只损害软目标，不能解除力/位/社交硬约束。

**引理 20（表演性偏差界）** `|E[θ̂]−θ*| ≤ L_Π·E‖ψ−ψ_⊥‖ + σ/√N`；以概率 ε 随机化时 `bias ≤ (1−ε)L_Πψ_max + C/√(εN)`，存在 ε* 折中。系：洞察必须刻意做一部分「非最优」提问，用外生变异换可识别性；纯贪心 VoSI 会高估「容易被展示的需求」。

**引理 21（接触双用途超加性）** 接触观测把 nuisance 方差由 σ_w² 降到 σ_w²(1−ρ_c)，则 `I(θ*;r|do(ψ),y_c)−I(θ*;r|do(ψ)) ≥ ½log(1/(1−ρ_c))`。故 ρ_c>0 时，接触接地的物理提问在等成本下严格优于纯语言提问；ρ_c→1 时优势最大。

**定理 18（CRAFT 严格包含 R69）** A95–A99、DCG 可信、可识别下：`E[J_{θ*}]_CRAFT ≥ E[J_{θ*}]_R69` 且硬约束风险 `≤ R69`。U_d=0 ∧ O_offer=∅ 时逐指令相同（定义 325）；U_d>0 时探询全在 F 内且 ℓ=0，安全不劣；VoSI 期望信息增益非负 ⇒ 后验更优。R69 = 「不洞察、不物理提问」边界。

**定理 19（可逆探询无承诺伤害）** ℓ=0 + 承诺门下：洞察阶段物理伤害 ≤ ε_offer；错误承诺概率 ≤ δ_commit；undo 在 (δ_undo, τ_undo) 内恢复。洞察可任意中止且后悔有界，继承 R69 无突变。

**定理 20（反操纵上界）** 若每个 offer 满足 `μ(o)≤μ_max`，则 `D_KL(Π(θ*,ψ_o,c)‖Π(θ*,∅,c)) ≤ μ_max`。即 offer 设计对表达偏好的总推移 ≤ μ_max nat，给「制造共识」一个可审计上界；μ 越界即关闭 offer。

## 7. 本轮最大风险

**一句话**：CRAFT-RAS 最大的风险是**内生性/表演性**——机器人自己设计的物理提问会**建构**它随后「洞察」到的需求（呈现效应 + 确认偏误 + 系统性高估易展示的偏好），使「需求洞察」退化为**制造共识**：系统可能极其自信地服务一个它亲手诱导出来的伪需求；一旦这条偏差经「需求驱动目标函数」渗进约束或长期策略，安全与伦理会同时失守。

**次级风险与缓解**：需求偏差被误当真相（外生随机化 + 引理 20 + E305）；硬约束被偏好侵蚀（引理 19 + 反谄媚 + E307/E309）；物理提问不安全（ℓ=0 + undo 见证 + 承诺门，定理 19）；系统反向操纵人（μ≤μ_max + VQAuditor-D，定理 20/E308）；洞察挤占实时预算（双时间尺度，内环逐指令 = R69）。
