# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「目标检测」×「伦理审查」）

> 第 54 轮把技能组合从“能力匹配”推进为“动作空间-鲁棒性双证书”，并给出云边协同闭环。本轮引入两个看似方法论迥异的词：**目标检测**（感知层的置信度、漏检与分布漂移）与**伦理审查**（治理层的责任、非对称风险与人类监督）。核心矛盾：H22：目标检测的置信度不是可部署承诺，用 mAP/置信度直接支撑伦理决策，会把“统计似然”误当“可验证保证”；H23：伦理审查若只是一次性人工过会，就无法覆盖第 54 轮那种运行时动态组合出的新动作空间与新伦理暴露。

## 0. 直觉与动机

**灵感 1（目标检测的双重语义 → 任务目标与伦理敏感目标的类型化检测）**
直觉：同一个“人”既可能是操作目标（把杯子递给某人），也可能是必须保护的敏感实体（面部、隐私、未成年人）。所以检测器不应只输出类别与框，而应输出 **带角色的检测** `role ∈ {target, sensitive, dual}`。任务检测 `D_task` 为动作落地提供 grounding，伦理检测 `D_eth` 为治理提供触发源；二者共享主干、分离头，且“dual”类必须同时满足动作证书与伦理证书。这把“目标检测”从纯精度问题，变成 **精度 × 角色 × 义务** 的三元问题。

**灵感 2（伦理审查即检测条件证书 → 从清单打勾变为可失效的运行时门控）**
直觉：传统伦理审查是“上线前过会、上线后遗忘”。若把它改写成 **Detection-Conditioned Ethical Certificate（检测条件伦理证书）**，则伦理结论会随“检测器版本、校准集、覆盖类、漏检上界、审查人、有效期”而变化。关键不是“检测准确率多高”，而是用 **保形风险控制（conformal risk control）** 把检测统计量转成“漏检率 `FNR_e ≤ α_e` 以概率 `≥1-δ_e` 成立”的可审计承诺。伦理审查因此成为一个可计算、可失效、可追责的门控函数，而不是一次性人工意见。

**灵感 3（非对称风险 + 弃权优先 + 选择性审查）**
直觉：伦理风险天然非对称——漏掉一个高危敏感类 (`λ_FN ≫ λ_FP`) 远比误报严重。有限的人类审查预算 `B` 应优先投向“高风险 + 高不确定 + 本体外类别”的样本；检测器应被允许 **弃权（abstain）**，弃权不是检测失败，而是把责任显式交还人类。于是审查不再是“全检”，而是 **风险排序的选择性审查**：自动放行低风险、集中人力捕获尾部高危、预算耗尽时宁可延迟动作也不放行。

**灵感 4（组合的伦理暴露闭包 → 云边分工下的新增暴露）**
直觉：第 54 轮的技能组合会**创造新的伦理暴露**：`S1` 操作杯子、`S2` 把杯子递给人，单看都不敏感，组合后却出现“人与物的接触暴露”。因此需要 **伦理暴露闭包** `EthExpose(P)`，对技能动作剖面、转换段、云边映射 `γ_ce` 一并求闭包。云边分工天然对应：云端跑重模型与全局伦理本体、边端跑轻量检测并升级疑难样本；特别要审计 `Δ_expose^{ce} = EthExpose(γ_ce(A_c)) \ EthExpose(A_c)`——**云端看不见、边端映射后才出现的暴露**，这是云边伦理契约最容易被漏掉的黑洞。

**灵感 5（可审计回放 + 新鲜度 + 责任锚点）**
直觉：伦理证书必须像药品批号一样有 **有效期与召回机制**。检测器漂移、场景换季、本体扩展都应使证书失效；每次放行要有 **可回放审计日志**（版本、证据哈希、审查人、弃权理由）。最重要的是：**证书必须写明具名的人类责任主体**，禁止“系统自动通过”成为责任真空。这把第 53–54 轮的 Explain/证书体系延伸到“伦理可追溯”，形成 **检测—审查—门控—回放—失效** 的闭环。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（双通道类型化目标检测）**
检测器 `D = (D_task, D_eth)`。`D_task: X → 2^{O×[0,1]×B}` 输出任务目标框与分数；`D_eth: X → 2^{E×[0,1]×B}` 输出伦理敏感类 `E`（如 person / face / protected-attribute-proxy / private-object / minor）的框与分数。每个检测附角色 `role(o) ∈ {target, sensitive, dual}`。`D_eth` 允许输出空集或 **弃权标记 ⊥**。

**定义 122（伦理暴露集与组合闭包）**
给定技能 `S` 的动作剖面 `α_S`（第 54 轮定义 115）与观测算子 `obs(a)`：
```
EthExpose(S) = { e∈E | ∃a∈A, x∈obs(a): α_S(a) ≥ θ_cov ∧ D_eth(x) 检出 e 且分数 ≥ θ_e }
```
对组合计划 `P = S_1⊗…⊗S_k` 定义闭包
```
EthExpose(P) = ⋃_{i} EthExpose(S_i) ∪ EthExpose(Δ(P))
```
其中 `Δ(P)` 为技能转换段与接触/上下文事件。云边新增暴露
```
Δ_expose^{ce}(P) = EthExpose(γ_ce(A_c)) \ EthExpose(A_c)
```
刻画“云端粗动作不可见、经边端细映射后才出现的伦理暴露”。

**定义 123（非对称检测风险）**
对敏感类 `e`，令 `FNR_e, FPR_e` 为漏检率与误报率，`λ_FN(e) ≫ λ_FP(e)`：
```
R_e(D_eth) = λ_FN(e)·FNR_e(D_eth) + λ_FP(e)·FPR_e(D_eth)
```
伦理风险预算要求 `R_e(D_eth) ≤ β_e`，或等价的 **漏检上界** `P(FNR_e ≤ α_e) ≥ 1-δ_e`。注意：mAP/置信度**不是**此量，不能替代。

**定义 124（检测条件伦理审查证书）**
```
E_cert = (D_eth, h(calib), {α_e, δ_e}, O, reviewer, issued_at, ttl, audit_log)
```
其中 `h(calib)` 为校准集哈希，`O = Ω(EthExpose(P))` 为义务集（同意/脱敏/人在环/禁止部署），`reviewer` 为具名人类责任主体。`E_cert` 对类 `e` **sound** 当且仅当：`e` 在覆盖类内、`P(FNR_e ≤ α_e) ≥ 1-δ_e` 成立、`O(e)` 可执行、证书未过期、审计可回放。

**定义 125（选择性审查与弃权）**
弃权集 `Abs = { x | U(x) > θ_u ∨ e ∉ E_ontology ∨ 检测冲突 }`，其中 `U` 为检测不确定性。人类审查预算 `B`，审查负载 `L = E[|Abs|]`。选择性审查规则要求 `L ≤ B`，并在预算内按 `risk_rank(x) = h(e)·U(x)·novelty(x)` 降序分配；预算耗尽时输出 `defer`（延迟动作）而非放行。

**定义 126（伦理门控函数）**
```
Gate_eth(P, t) = 1  iff  ∀ e ∈ EthExpose(P):
    e ∈ E_cert.covered
  ∧ Fresh(E_cert, t)
  ∧ obligation_satisfied(e, P)
  ∧ FNR_upper_e ≤ α_e
  ∧ Δ_expose^{ce}(P) ⊆ E_cert.covered
```
`Gate_eth = 0` 时，第 54 轮的动作-鲁棒性联合证书 `J` **不得**被签发为可部署；伦理门控是 `J` 的上游强制门。

**定义 127（证书新鲜度与漂移失效）**
```
Fresh(E_cert, t) = 1  iff  (t - issued_at ≤ ttl) ∧ (Δ_drift(t) ≤ κ)
```
其中漂移统计量 `Δ_drift(t) = |FNR̂_shadow(t) - FNR_calib|` 由影子集在线估计。`Fresh=0` 则证书立即失效并要求重审；这是对保形保证“可交换性假设”被分布漂移破坏的显式补偿。

## 2. 关键算法 伪代码

### IP-121 EPD（Ethical Perception with Detection + conformal risk calibration）

```python
def calibrate_fnr(detector, calib_set, classes, alpha, delta):
    stats = {e: [] for e in classes}
    for x, gt in calib_set:
        preds = detector(x)
        for e in classes:
            miss = 0.0 if matched(preds, gt, e) else 1.0
            stats[e].append(miss)
    thr = {}
    for e in classes:
        # conformal risk control: 选阈值使 FNR 上界 <= alpha (置信 1-delta)
        thr[e] = conformal_threshold(sorted(stats[e], reverse=True), alpha, delta)
    return thr

def detect_typed(x, detector, thr):
    out = []
    for det in detector(x):
        role = 'dual' if det.cls in SENSITIVE and det.is_task_target else (
               'sensitive' if det.cls in SENSITIVE else 'target')
        if det.cls in SENSITIVE and det.score < thr[det.cls]:
            out.append(('abstain', det))
        else:
            out.append((role, det))
    return out
```

### IP-122 ROG（Review Obligation Generator）

```python
def obligations(exposure, context, ontology):
    O = {}
    for e in exposure:
        O[e] = ontology.obligation(e, context)   # consent / mask / human_in_loop / forbid
    return O
```

### IP-123 SRB（Selective Review Budgeting）

```python
def selective_review(detections, B, theta_risk):
    ranked = sorted(detections, key=risk_rank, reverse=True)
    reviewed, auto = [], []
    for d in ranked:
        if d.abstain or d.risk >= theta_risk:
            if len(reviewed) < B:
                reviewed.append(d)
            else:
                return ('defer', auto, reviewed)   # 预算耗尽：延迟而非放行
        else:
            auto.append(d)
    return ('auto', auto, reviewed)
```

### IP-124 EGC（Ethical Gate Certificate）

```python
def ethical_gate(plan, E_cert, t, exposure):
    if not fresh(E_cert, t):
        return ('reject', 'stale_certificate')
    for e in exposure:
        if e not in E_cert.covered:
            return ('reject', 'exposure_uncovered', e)
        if not obligation_satisfied(e, plan):
            return ('reject', 'obligation', e)
        if E_cert.fnr_upper[e] > E_cert.alpha[e]:
            return ('reject', 'risk_budget', e)
    return ('ok', issue_certificate(E_cert, plan, t))
```

### IP-125 EPX（Ethical Exposure Propagation）

```python
def eth_expose_composition(skill_seq, alpha, D_eth, gamma_ce):
    E_c = union(eth_expose(s, alpha[s], D_eth) for s in skill_seq)
    E_e = union(eth_expose(s, alpha[s], D_eth, space='edge') for s in skill_seq)
    E_e |= eth_expose(gamma_ce(A_c), D_eth, space='edge')
    delta_ce = E_e - E_c          # 云边映射创造的暴露
    E_trans = eth_expose_transitions(skill_seq)
    return E_c | E_e | E_trans, delta_ce
```

### IP-126 AER（Auditable Ethical Replay）

```python
def audit_replay(log, E_cert):
    for rec in log:
        if rec.detector_version != E_cert.detector_version:
            return ('fail', 'version_mismatch', rec.id)
        if not verify_hash(rec.evidence, rec.evidence_hash):
            return ('fail', 'tamper', rec.id)
        if rec.reviewer is None and rec.risk >= rec.high_risk_threshold:
            return ('fail', 'no_accountable_human', rec.id)
    return ('pass', coverage_ratio(log, E_cert.ttl))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EPD | O(\|X_cal\|·\|E\| + \|E\| log\|X_cal\|) | O(\|X_cal\|·\|E\|) | 校准集可交换、阈值单调 |
| ROG | O(\|EthExpose\|·\|O\|) | O(\|E\|·\|O\|) | 义务本体封闭 |
| SRB | O(n log n) | O(n) | 风险排序单调、预算不超发 |
| EGC | O(\|EthExpose\|·\|O\|) | O(\|EthExpose\|) | 证书 sound、门控前置 |
| EPX | O(\|S\|·\|A\|·\|E\|) | O(\|E\|) | 闭包完整、转换段不漏 |
| AER | O(\|log\|·\|E\|) | O(\|log\|) | 日志防篡改、版本一致 |

**正确性定理（Detection-Conditioned Ethical Soundness, DCES）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** 校准集与部署分布可交换，或漂移监控 `Δ_drift ≤ κ` 持续成立；**(A30)** 伦理本体封闭：`e ∉ E_ontology` 必弃权而非放行；**(A31)** 义务可执行且对子计划单调；**(A32)** 审计日志防篡改且完整。
则对任意通过 `Gate_eth` 的计划 `P`，以概率 `≥ 1-δ`：
```
P(部署期伦理违规) ≤ Σ_{e∈EthExpose(P)} β_e + P(Fresh=0) + P(弃权样本被人工误判)
```
关键：伦理结论是 **条件性保证**（依赖交换性、本体封闭、义务可执行），**不是**由检测器精度直接蕴含的绝对结论。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 分布漂移破坏 FNR 保证 | 高 | 影子集监控 + 短 TTL + 漂移即失效 |

## 6. 本轮最大风险

**一句话**：把伦理审查转写为“检测 + 保形漏检上界 + 证书门控”的最大风险是**责任洗白**——保形保证只在可交换性/本体封闭成立时有效，一旦分布漂移造成系统性伦理盲区，一张看似严谨的证书反而会给未审查的伤害披上合法性；因此必须以 **弃权优先 + 漂移即失效 + 具名人类责任锚点** 三重护栏，宁可延迟部署，也绝不把“检测通过”当作“伦理通过”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+++ → EthiDet-Trust（EPD×ROG×SRB×EGC×EPX×AER）

> 承接第 54 轮产物 v31。本轮把“目标检测”与“伦理审查”耦合为 **检测条件伦理治理层**，让伦理审查从一次性人工过会，升级为随检测覆盖、风险预算、分布漂移与组合动作空间动态失效的运行时证书门控：
> - **EPD（Ethical Perception Detection）**：任务/伦理双通道类型化检测 + 保形 FNR 校准；
> - **ROG（Review Obligation Generator）**：把伦理暴露映射为可执行义务集；
> - **SRB（Selective Review Budgeting）**：非对称风险排序 + 弃权优先 + 有限预算选择性审查；
> - **EGC（Ethical Gate Certificate）**：检测条件伦理证书，作为第 54 轮联合证书 `J` 的上游强制门；
> - **EPX（Ethical Exposure Propagation）**：组合与云边映射的伦理暴露闭包，显式建模 `Δ_expose^{ce}`；
> - **AER（Auditable Ethical Replay）**：版本/证据/审查人/弃权理由的可回放审计与新鲜度失效。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115（动作剖面纳入伦理暴露）与 IP-120（联合迁移证书增加伦理前置门）。

### IP-121 EPD

def calibrate_fnr(detector, calib_set, classes, alpha, delta):
    stats = {e: [] for e in classes}
    for x, gt in calib_set:
        preds = detector(x)
        for e in classes:

### IP-123 SRB

```python
def selective_review(detections, B, theta_risk):
    ranked = sorted(detections, key=risk_rank, reverse=True)
    reviewed, auto = [], []
    for d in ranked:
        if d.abstain or d.risk >= theta_risk:
            if len(reviewed) >= B:
                return ('defer', auto, reviewed)   # 预算耗尽：延迟而非放行
            reviewed.append(d)
        else:
            auto.append(d)
    return ('auto', auto, reviewed)
```

### IP-124 EGC

```python
def ethical_gate(plan, E_cert, t, exposure):
    if not fresh(E_cert, t):
        return ('reject', 'stale_certificate')
    for e in exposure:
        if e not in E_cert.covered:      return ('reject', 'exposure_uncovered', e)
        if not obligation_satisfied(e, plan): return ('reject', 'obligation', e)
        if E_cert.fnr_upper[e] > E_cert.alpha[e]: return ('reject', 'risk_budget', e)
    return ('ok', issue_certificate(E_cert, plan, t))
```

def eth_expose_composition(skill_seq, alpha, D_eth, gamma_ce):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EPD | O(\|X_cal\|·\|E\| + \|E\| log\|X_cal\|) | O(\|X_cal\|·\|E\|) | 校准集可交换，阈值单调 |
| ROG | O(\|EthExpose\|·\|O\|) | O(\|E\|·\|O\|) | 义务本体封闭 |
| SRB | O(n log n) | O(n) | 风险排序单调、预算不超发 |
| EGC | O(\|EthExpose\|·\|O\|) | O(\|EthExpose\|) | 证书 sound、门控前置 |
| EPX | O(\|S\|·\|A\|·\|E\|) | O(\|E\|) | 闭包完整、转换段不漏 |
| AER | O(\|log\|·\|E\|) | O(\|log\|) | 防篡改、版本一致、责任锚定 |

**正确性定理（Detection-Conditioned Ethical Soundness, DCES）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 校准集与部署分布可交换，或漂移监控 `Δ_drift ≤ κ` 持续成立；**(A30)** 伦理本体封闭且本体外必弃权；**(A31)** 义务可执行且对子计划单调；**(A32)** 审计日志防篡改且完整。
则对通过 `Gate_eth` 的计划 `P`，以概率 `≥ 1-δ`：
```
P(部署期伦理违规) ≤ Σ_{e∈EthExpose(P)} β_e + P(Fresh=0) + P(弃权样本被人工误判)
```
要点：伦理结论是 **条件性保证**，依赖交换性、本体封闭与义务可执行；检测精度本身不能替代审查，`Gate_eth` 必须强制位于联合证书 `J` 之前。

## 5. 本轮最大风险

**一句话**：把伦理审查转写为“检测 + 保形漏检上界 + 证书门控”的最大风险是**责任洗白**——保形保证只在可交换性/本体封闭成立时有效，一旦分布漂移造成系统性伦理盲区，一张看似严谨的证书反而会给未审查的伤害披上合法性；因此必须以 **弃权优先 + 漂移即失效 + 具名人类责任锚点** 三重护栏，宁可延迟部署，也绝不把“检测通过”当作“伦理通过”。
