# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「热管理」×「传感器融合」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**热-信息联合治理**。两个灵感分别治理 v9 尚未形式化的两种"隐藏状态"：热状态 θ（决定真实算力上限与执行器能力，却不在六层指标中）与多模态传感的冗余/温度耦合（决定感知证书的真实可信度，却被当作固定噪声）。必须保持 v9 的**中立元退化 + 严格退化链**纪律：任一新增环节失效即注入恒等元，逐级退回 v9 → v8 → …，绝不行为漂移。

## 0. 直觉与动机

**灵感 1（热管理 → 热是算力与执行器的物理调速器）**
直觉：v9 的整条安全论证（引理 82、86）都条件于"决策预算恒为 20ms、WCET 上界 Ŵ_m 固定"。但热才是算力的物理上限：SoC 持续满载会降频，电机持续大扭矩会降额，电池高温会限流。更关键的是——v9 自己指出的最大风险是"在最需要安全时证书最不可靠"，而那一刻恰恰是机器人最卖力、发热最快的时刻。热管理把这个"隐藏状态"变成可观测、且演化很慢的前馈信号：热不是噪声，而是**提前量**。核心创新：**热感知契约治理器（ThermalContractGovernor, TCG）**：契约升级为温度相关 (D_m(θ), Ŵ_m(θ))；集总 RC 热观测器预测"距降额时间"；预冷/算力储备维持 EDF 可行；热应力下的降级遵循一条**礼貌降级晶格**（定义 546），且它是 v9 中立元退化格的加细，不引入新状态。

**灵感 2（传感器融合 → 感知是带温度相关协方差的证据合成）**
直觉：v9 已有 Calib-FI/SPR，但把各传感器当成噪声固定的独立管线，既没利用跨模态冗余，也没建模"热会改变传感器噪声"这一物理事实：IMU 零偏随温漂、相机暗电流随温升、LiDAR 回波随自热变化、电机电流传感与热耦合。传感器融合把感知重述为**温度条件化的证据合成**：每模态带 R_i(θ)，用鲁棒协方差交叉融合，并输出 Fisher 信息融合证书，与 v9 的块证书 Ĉ_t 并列进入安全触发。核心创新：**温度耦合融合证书器（ThermalAwareFusionCertifier, TAFC）**。

**灵感 1×2 的耦合洞见（热-信息对偶，Thermal–Information Duality）**
直觉：热与信息争用同一份物理预算——热余量 H 约束可持续算力 P_c 与传感占空比 P_s；反过来，更多/更好的融合提高热状态 θ 的可观测性、降低其不确定度。于是存在良性环（热估得准 → 预算排得好 → 被迫降级少 → 算力留给融合）与恶性环（发热 → 降频 → 融合模态被削减 → θ 估计变差 → 更晚才发现过热）。核心创新：**热-信息联合预算（TIJB）**：用"热储备不变量 H(t) ≥ H_res"切断恶性环，并把 v9 的"证书在最需要时最不可靠"改为由热前馈提前规避。

## 1. 研究问题（轮次升级版）

- **Q1（热可观测与预警）**：在自热耦合、测量有界噪声与 RC 参数误差下，"距降额时间" T_warn 的估计误差如何界定？热前馈能否在 Δ_dom 跳变之前给出正提前量，而不是事后追认？
- **Q2（温度耦合融合的证书可信度）**：当真实噪声协方差随温度漂移、且模型误差有 PSD 界 δ 时，融合证书 F_t 需要多大保守裕度才能保证真实协方差满足 Fisher 要求？
- **Q3（热-信息预算守恒与退化安全）**：θ 相关 WCET 下如何同时保持 EDF 可行与 50Hz？热应力降级如何被证明是 v9 退化格的**加细**而非新不安全态？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 热感知契约律（Thermal-Aware Contract, TAC）**
契约升级为 κ_m^θ=(In,Out,D_m^θ,Ŵ_m^θ,v_m^⊥,π_m,φ_m^elig)，Ŵ_m^θ=ρ(θ)Ŵ_m^0、D_m^θ=ρ(θ)D_m^0，ρ≥1 为温度/DVFS 慢化因子（对 T_soc 单调不减，由离线频率-温度映射标定）。每个热模式部署期校验 Σ_m Ŵ_m^θ + O_sched ≤ B_dec，运行期仅在热模式变更时复验；不可行 ⇒ 沿礼貌降级晶格卸载，禁止用"超时"替代"卸载"。

**P14 热-信息预算守恒律（TIJB）**
分配约束 P_c+P_s ≤ P̄_design − P_res，维持热储备不变量 H(t) ≥ H_res。当预测 min_i T_warn,i < T_lead 触发预冷：只削 φ^elig 模块与非认证模态的占空比，**绝不以安全关键集换取热余量**。

**P15 温度耦合融合证书律（TAFC）**
每模态噪声 R_i(θ) 对温度单调（PSD 序），融合用协方差交叉；证书阈值按热噪声模型误差 δ 放大 (1+δ)，使"模型保守性"成为可证条件（引理 89）而非调参运气。

## 3. 与基线的接口（如何退化）

- TSF 失效 ⇒ θ̂ ← 保守常值 θ_safe（最热先验），等价 v9 固定预算；
- TAFC 失效 ⇒ 各模态回退 v9 固定 R_i、去掉融合证书 F_t，δ_trigger 退化为 v9 五条件；
- TCG 失效 ⇒ Ŵ_m^θ ← Ŵ_m^0、关闭预冷与热模式，退化为 v9 MW；
- TAC² 失效 ⇒ 块证书去掉热项 Θ̂_max、K_eff ← K_eff^{v9}，等价 v9 AC；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再退回 v8 / v7 / v6。

## 4. 预期贡献

1. **热-信息对偶框架**：把热作为"慢可观测前馈"，为 v9 的"证书在最需要时最不可靠"提供可工程化证明的提前量；
2. **温度耦合融合证书**：感知可信度首次以 PSD 序 + 有界热噪声模型误差的形式可证；
3. **热感知契约与礼貌降级晶格**：θ 相关 WCET 下的 EDF 可行性与退化安全，并证明它是 v9 退化格的加细；
4. **热-分块证书**：动作块同时携带间隙/力/抓取/热四项最坏界，热中止点并入停车不变式（P_t^θ ⊆ P_t）；
5. **实验 E571–E590**：覆盖热观测精度、预警时界、融合证书覆盖率、热退化等价、预算守恒、预冷有效性与"热前馈缩小证书失效窗口"的端到端检验。

## 5. 本轮最大风险

**一句话**：热管理所依赖的温度/功率传感器本身会被自热与热漂移污染，而热观测器又用这些读数去估计"热"——在最热、最卖力、域也最新的时刻，系统可能把"自身传感器的热退化"误判为域偏移或热越限，从而在热估计最不可信时触发礼貌降级、反而削弱感知，形成"热管理污染其自身观测"的闭环非可辨识风险。

> 本轮灵感：「热管理」×「传感器融合」

**新增定义 540（热状态与热余量 ThermalState）** 热状态 θ_t=(T_soc,T_batt,T_amb,T_mot)∈Θ⊆ℝ^{n_m+3}，每组件 i 设 T_i^nom<T_i^warn<T_i^der<T_i^off。热余量 h_i(t)=T_i^der−T_i(t)，系统余量 H(t)=min_i h_i(t)。集总 RC 演化：
```
T_i(t+Δ) = T_i(t) + (Δ/C_i)·[ P_i(t) − (T_i(t)−T_amb)/R_i ]
P_i(t) = P_i^comp + P_i^act + P_i^sens + P_i^amb
```
热观测以 5Hz 运行（Δ=0.2s）；50Hz 控制环只读取缓存 θ̂，不在快环内积分热模型。θ 作为**加性第七层** M_therm 接入六层指标，不改变 M₀–M_SLAM 语义。

**新增定义 541（热状态融合估计 ThermalStateFuser, TSF）** 观测量 y_t=(T̃_soc,T̃_batt,T̃_amb,{T̃_mot},P_comp,P_act)，测量模型 y_t=Cθ_t+ε_t，ε_t 有界、E[εεᵀ]=Q(θ_t)；先验由定义 540 前推得 (θ_t⁻,Σ_t⁻)，UKF 更新得 (θ̂_t,Σ_θ(t))。健康位 g_th(t)=1{trΣ_θ≤σ_θ² ∧ ∀i: T̂_i∈[T_min,T_i^off)}。距降额时间：
```
T_warn,i = inf{ τ≥0 : T̂_i(t+τ) ≥ T_i^der | P_i≡P̄_i }
T_warn   = min_i T_warn,i
```
TSF 每 5Hz 输出 (θ̂,Σ_θ,T_warn,g_th)。g_th=0 ⇒ θ̂←θ_safe（操作包络内最热先验），并令 ρ←ρ_max，等价"按最坏热况跑 v9"。

**新增定义 542（温度耦合噪声与融合证书 ThermalAwareFusionCertifier, TAFC）** 模态集 M={RGB-D, LiDAR, IMU, F/T, motor-current, audio, …}，z_i=h_i(x)+ε_i，ε_i~(0,R_i(θ))，R_i:Θ→S_{++} 连续且对每个分量温度单调不减（PSD 序：T⪯T′ ⇒ R_i(T)⪯R_i(T′)）。线性化 S_i(θ)=R_i(θ)+J_iΣ_xJ_iᵀ。等权协方差交叉：
```
Σ_f⁻¹(θ) = (1/|V|)·Σ_{i∈V} S_i(θ)⁻¹
F_t = ( λ_min=λ_min(Σ_f⁻¹),  tr_f=tr(Σ_f),  V_t )
```
以热噪声模型误差 δ（PSD 界 R_i^true⪯(1+δ)R_i^model）校正后：
```
F_t 有效 ⇔ λ_min/(1+δ) ≥ λ_min^req  ∧  tr_f ≤ σ_max²  ∧  M_min ⊆ V_t
```
F_t 进入 v9 的 δ_trigger，与 Ĉ_t 并列；M_min 为不可裁剪的认证最小融合集（如 RGB-D + IMU），即使礼貌降级也不得低于此集。

**新增定义 543（热感知契约 ThermalAwareContract, TAC）** 契约升级为
```
κ_m^θ = (In_m, Out_m, D_m^θ, Ŵ_m^θ, v_m^⊥, π_m, φ_m^elig)
Ŵ_m^θ = ρ(θ)·Ŵ_m^0,   D_m^θ = ρ(θ)·D_m^0
```
ρ:Θ→[1,ρ_max] 连续、对 T_soc 单调不减（DVFS/降额慢化因子，离线频率-温度映射标定）。热模式 s_θ 由带迟滞阈值对 (T^warn↑, T^recover↓) 定义。部署期对每个模式校验 EDF 可行性
```
Σ_m Ŵ_m^θ + O_sched ≤ B_dec
```
运行期仅在 s_θ 变更时复验；不可行 ⇒ 沿定义 546 卸载，**禁止以超时替代卸载**（超时是故障，卸载是设计）。

**新增定义 544（热-信息联合预算 ThermalInformationBudget, TIJB）** 稳态散热能力 P̄_design=(T^der−T_amb)/R_th。分配约束
```
P_c + P_s ≤ P̄_design − P_res,   P_res > 0
热储备不变量：H(t) ≥ H_res
```
预冷谓词 pre-cool ⇔ min_i T_warn,i < T_lead。触发时只削减 φ^elig 模块与非认证模态占空比（P13/P14 安全优先）；热账本 L_θ(t)=∫(P_c+P_s)dτ，结余即 H(t)。预冷持续性要求"视界平均功率需求 ≤ P̄_design−P_res"（可达性见引理 91）。

**新增定义 545（热-分块证书 Thermal-Aware Action Chunk, TAC²）** v9 块证书升级：
```
Ĉ_t^θ = (ĝ_min, ê_max, γ̂_grasp, Θ̂_max)
Θ̂_max = max_{i,k≤K} [ T̂_i(t+k) + m_i − T_i^der ]   （越阈量，越大越坏）
```
有效 ⇔ v9 四条件 ∧ Θ̂_max ≤ 0 ∧ P_t^θ ≠ ∅。热中止点集
```
P_t^θ = { p ∈ P_t : rollout(θ̂, P_{1:p} ∪ {P_safe}_{p+1:K}) 各组件 ≤ T_i^der − m_i }
```
因 P_t^θ ⊆ P_t（v9 停车中止点集），热中止**不破坏空间安全**。有效块长再受热门控：
```
K_eff^θ(t) = min( K_eff^{v9}(t), max(1, ⌊K_max·clip(H(t)/H_ref, 0, 1)⌋) )
           = 1  若 g_th=0 ∨ H(t) < H_min
```
热越紧块越短，最终 K=1 完全退回 v9 逐步模式。

**新增定义 546（礼貌降级晶格 PoliteDegradationLattice）** 偏序
```
L0 NOMINAL
 ⊑ L1  shed ID-eligible（v9 dormant）
 ⊑ L2  K_eff^{v9}↓ / AC→K=1
 ⊑ L3  裁剪非认证融合模态（保留 M_min）
 ⊑ L4  安全停驻
```
每一步语义等于 v9 的一个中立元注入或 K_eff←1。安全关键集
```
S* = (M₀ 硬检查, SpatialCert, FaultCert, M_min, TCG 自身, 热中止检查)
```
在任何 Lk 下不可剪除。热应力只允许沿链**单向升级（降级）**；恢复需连续 H≥H_res+δ_h 且带迟滞（定义 543）。

# IP-357 ThermalStateFuser：热状态融合估计器
class ThermalStateFuser:
    def __init__(self, rc_model, n_motors, dt=0.2):
        self.rc = rc_model                 # C_i, R_i, T_amb_hat, rho_map, T_der
        self.dt = dt                       # 5Hz 热观测
        self.theta = self.rc.nominal()
        self.Sigma = self.rc.init_cov()

    def predict(self, P_comp, P_act):
        self.theta = self.rc.propagate(self.theta, P_comp + P_act, self.dt)
        self.Sigma = self.rc.F @ self.Sigma @ self.rc.F.T + self.rc.Q
        return self.theta

    def update(self, y):
        self.theta, self.Sigma = ukf_update(
            self.theta, self.Sigma, y, self.rc.H, self.rc.R(self.theta))
        return self.theta, self.Sigma

    def time_to_derate(self, P_hat):
        return self.rc.solve_hitting_time(   # 定义 541
            self.theta, P_hat, self.rc.T_der, self.rc.T_amb_hat)

    def headroom(self):
        return float(np.min(self.rc.T_der - self.theta))     # H(t)

    def health(self):
        return int(np.trace(self.Sigma) <= self.rc.sigma2
                   and np.all((self.theta > self.rc.T_min)
                              & (self.theta < self.rc.T_off)))


# IP-358 ThermalAwareFusionCertifier：温度耦合融合证书器
class ThermalAwareFusionCertifier:
    def __init__(self, modalities, lam_req, delta=0.15, min_set=("rgbd", "imu")):
        self.mods = modalities
        self.lam_req, self.delta, self.min_set = lam_req, delta, set(min_set)

    def fuse(self, z, x_prior, theta_hat, health):
        infos, used = [], []
        for m in self.mods:
            if not health[m.name] and m.name not in self.min_set:
                continue                    # 可裁剪模态（礼貌降级）
            S = m.R(theta_hat) + m.jacobian(x_prior) @ x_prior.cov @ m.jacobian(x_prior).T
            infos.append(np.linalg.inv(S)); used.append(m.name)
        info_f = sum(infos) / len(infos)    # 等权协方差交叉（定义 542）
        Sigma_f = np.linalg.inv(info_f)
        cert = FusionCert(
            lam_min=float(np.linalg.eigvalsh(info_f).min()),
            trace=float(np.trace(Sigma_f)), used=used, margin=self.delta)
        cert.valid = (cert.lam_min / (1.0 + self.delta) >= self.lam_req
                      and cert.trace <= self.sigma_max
                      and self.min_set.issubset(set(used)))
        return fuse_state(Sigma_f, z, used), cert


# IP-359 ThermalContractGovernor：热感知契约治理器
class ThermalContractGovernor:
    def __init__(self, mw, tsf, B_dec_ms=20.0,
                 P_design=18.0, P_res=3.0, T_lead=5.0, H_res=3.0):
        self.mw, self.tsf = mw, tsf
        self.B, self.P_design, self.P_res = B_dec_ms, P_design, P_res
        self.T_lead, self.H_res = T_lead, H_res
        self.mode = 'NOMINAL'

    def slowdown(self, theta):
        return self.tsf.rc.rho(theta)        # ρ(θ) ≥ 1（定义 543）

    def budget_ok(self, theta):
        return sum(c.wcet_ms * self.slowdown(theta)
                   for c in self.mw.contracts.values()) <= self.B

    def step(self, P_req_comp, P_req_sens):
        theta, H = self.tsf.theta, self.tsf.headroom()
        T_warn = self.tsf.time_to_derate(P_req_comp + P_req_sens)
        self.mode = self._mode_with_hysteresis(theta)      # 定义 543
        if min(T_warn) < self.T_lead and self.mode == 'NOMINAL':
            self.mw.shed_polite(level=1)                   # 预冷：先休眠 ID 模块
        if not self.budget_ok(theta):                      # EDF 不可行
            self.mw.shed_polite(level=self._required_level(theta))
        self.mw.rebind(wcet_scale=self.slowdown(theta),    # 定义 543
                       deadline_scale=self.slowdown(theta))
        assert H >= self.H_res - 1e-9                      # 热储备不变量（定义 544）
        return self.mode


# IP-354↑ TAC²：在 v9 AC 上增加热证书项与热中止点
def thermal_chunk_certificate(self, state, cand, pred, tsf):
    g_min = pred.min_clearance - self.beta
    e_max = pred.max_effort + self.beta
    T_pred = tsf.rc.rollout(state.theta, pred.power_trace)       # 逐组件温度轨迹
    Theta_max = float(np.max(T_pred + tsf.rc.margin - tsf.rc.T_der))
    P_safe = tsf.rc.P_safe
    pts_theta = []
    for p in self._abort_points(state, cand, pred):              # v9 停车中止点
        P_after = pred.power_trace[:p] + [P_safe] * (len(pred.power_trace) - p)
        if np.max(tsf.rc.rollout(state.theta, P_after)
                  + tsf.rc.margin - tsf.rc.T_der) <= 0.0:
            pts_theta.append(p)
    ok = (g_min >= self.d_safe and e_max <= state.tau_eff
          and Theta_max <= 0.0 and len(pts_theta) > 0)
    return ok, Cert(g_min, e_max, Theta_max), pts_theta

## 4. 推导

**引理 87（热可观测性与预警时界误差界）** 设 (A1) 测量噪声有界 ‖ε‖∞≤ε_y；(A2) 集总参数与稳态温度误差合成为 ε_T；(A3) 功率上界 P_i≤P_max。则在操作包络内距降额时间满足
```
|T_warn^true − T_warn^est| ≤ L_T·(ε_y + ε_T),
L_T = RC · max{ 1/|T_ss−T_0|, 1/|T_ss−T_der| }
```
其中 T_ss=T_amb+P R 为稳态温度。推论：若 T_warn^est ≥ L_T(ε_y+ε_T) + T_lead，则存在至少 T_lead 的正提前量，热前馈可用。
证明：RC 解 T(τ)=T_ss+(T_0−T_ss)e^{−τ/(RC)}，命中时间 τ*=RC·ln[(T_ss−T_0)/(T_ss−T_der)]。对 T_0、T_ss 求偏导并取绝对值上界得 Lipschitz 常数 L_T；测量与参数误差经 RC 传播有界，故误差界成立。∎

**引理 88（热感知契约退化为 v9 中立元格）** 在 NOMINAL 且 g_th=1、θ̂ 低于所有预警阈时，ρ(θ)=1 ⇒ Ŵ^θ=Ŵ^0、D^θ=D^0，TCG 不卸载，TAC 与 v9 MW 逐位一致（引理 83）。沿礼貌晶格每一次降级 Lk→Lk+1 的作用等价于 v9 的某个中立元注入或 K_eff←1；热模式与契约退化级可交换（二者都是幂等的输出替换：先降级再升模式 = 先升模式再降级）。故可达行为集合 ⊆ v9 退化格，安全性由 v9 引理 84/86 传递。∎

**引理 89（温度耦合融合证书的保守性）** 若 ∀i∈M、∀θ∈Θ_op：R_i^true(θ)⪯(1+δ)R_i^model(θ)（PSD 序），则等权 CI 下
```
Σ_f^true(θ) ⪯ (1+δ)·Σ_f^model(θ)
⇒ λ_min(Σ_f^true⁻¹) ≥ (1+δ)⁻¹·λ_min(Σ_f^model⁻¹)
```
取证书阈值 λ_min^req，若 λ_min^model/(1+δ) ≥ λ_min^req，则真实融合协方差满足 Fisher 要求。
证明：S_i^true⪯(1+δ)S_i^model ⇒ S_i^true⁻¹⪰(1+δ)⁻¹S_i^model⁻¹。CI 对加权和与求逆保 PSD 序 ⇒ Σ_f^true⁻¹⪰(1+δ)⁻¹Σ_f^model⁻¹ ⇒ Σ_f^true⪯(1+δ)Σ_f^model；λ_min 对 PSD 序单调，结论成立。∎

**引理 90（热-分块联合安全）** 设 v9 引理 82 的间隙/停车条件成立。若热证书 Θ̂_max≤0 且 P_t^θ≠∅，则执行块（必要时中块切到 p*∈P_t^θ）后，所有组件温度 ≤ T_i^der−m_i 且空间安全不变式保持。
证明：热证书给出全块预测上界；中块守卫用实时 θ̂ 复算，若越阈则切 p*。由定义 545，p* 之后降功率至 P_safe 使预测温度不越阈；RC 对输入单调，故真实温度不超预测上界（有界误差由引理 87 吸收进余量 m_i）。因 P_t^θ⊆P_t，p* 同时满足 v9 停车不变式，空间安全由引理 82 保持；若 P_t^θ=∅ 则候选被拒、退回 K=1（等价 v9 逐步）。∎

**引理 91（热-信息预算守恒与 EDF 可行性）** 在 P_c+P_s≤P̄_design−P_res 与 RC 模型下，若 H(0)≥H_res，则 ∀t 有 H(t)≥H_res；且每当 s_θ 变更，TCG 沿 546 卸载使 ΣŴ_m^θ≤B_dec，故 50Hz 与 EDF 可行性保持。预冷规划可行 ⇔ 视界平均功率需求 ≤ P̄_design−P_res。
证明：RC 对输入单调；有界输入下温度有界，稳态 T_ss=T_amb+P R ≤ T^der−H_res 当 P≤P̄_design−P_res，故不变式由归纳成立。EDF 由离散卸载序列的单调性（Lk 逐级只减负载）保证；可行性条件由稳态功率平衡直接得到。∎

**引理 92（热模式无抖振 / 无 Zeno）** 预警/恢复阈值带迟滞（T^recover<T^warn）且热时间常数 RC≫控制周期；每次模式迁移后驻留 ≥τ_dwell（由 RC 与阈值间隔决定），故相邻迁移间隔有正下界，有限时间内迁移次数有限，无 Zeno；热循环次数受限。∎

| 竞赛（E590） | ≥ v9 + 10% | 综合调参、分析热瓶颈 |

## 8. 本轮最大风险

**一句话**：热管理所依赖的温度/功率传感器本身会被自热与热漂移污染，而热观测器又用这些读数去估计"热"——在最热、最卖力、域也最新的时刻，系统可能把"自身传感器的热退化"误判为域偏移或热越限，从而在热估计最不可信时触发礼貌降级、反而削弱感知，形成"热管理污染其自身观测"的闭环非可辨识风险。
