# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多模态大模型」×「推理延迟」）

> R69 让系统学会「问」，但它的提问建立在一个未言明的假想世界上：**答案会及时到，且答案说的是此刻**。它把「语言问句」交给冻结 LLM 在解码侧廉价生成，把真正的语义理解留在了环路之外；信息动作的收益 VoI 是一个没有时间维度的标量；MINT 默认交互在决策期限内完成。可一旦把真正的**多模态大模型**放进环路，这个假想世界立刻破裂：
> - 它给出开放词表的语义（这是什么、人在指什么、这是不是同一个任务），但单次推理是 10²–10³ ms，重尾、且**输入越难越慢**；
> - 它的答案永远指向前一个时刻的世界；在 1–3 ms 的控制节拍里，这是一份**关于过去的证词**；
> - 它会幻觉，而且幻觉的置信度往往不低；延迟与幻觉叠加，会把「诚实的不知道」变成「一份盖了时间戳的错误」。
>
> R69 问「我该向谁求证」；R70 必须接着问：**这份证词说的是哪个时刻？它来得及在仍然为真之前到达吗？在它到达之前，我的身体该按什么行动？**
>
> 核心命题：**把多模态大模型从实时环路中的同步 oracle，降格为一条异步、带时间戳、会过期的「语义证据总线」；把推理延迟从需要减掉的工程常数，升格为观测通道的一部分——用世界模型把旧语义前向重引用到当下，用尾延迟上界而非均值做决策，用「猜测—验证」把等待变成可回滚的并行，用「语义不变安全集」保证语义通道掉线时仍然安全。** 命名 **TEMPO-RAS**（Temporally-Expiring Multimodal Predictive Observations for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我得到的答案还新鲜吗？如果它迟到，我凭什么先动**」。

## 0. 直觉与动机

**灵感 1（多模态大模型 → 语义是慢变量，身体是快变量）**
直觉：控制环是毫秒级的，多模态大模型的语义推理是百毫秒到秒级的。把慢模型硬塞进快环，要么拖垮实时性，要么为了准时而砍掉它真正的能力。更合理的类比是「司令部与前线」：司令部给的是**带有发出时刻的判断**，前线不会停下来等下一封电报，而是按「这封信到现在已经过了多久、敌人可能移动多远」来决定怎么用。于是语义不该是一个返回值，而应是一条**消息**：有签发时间、有有效期、有来源证明、可以被后续消息作废。

**灵感 2（推理延迟 → 延迟不是开销，是观测的传输时延）**
直觉：经典做法把延迟当成「减掉一个 τ」。但延迟真正改变的是**证据所关于的世界时刻**。语义模型在 t−τ 时刻看到的世界，到 t 时刻已经变了。正确的用法不是把旧标签直接贴到当前帧，而是先问「从 t−τ 到 t，世界可能变成什么」，把旧语义**前向搬运**成一个关于当下的分布，并老老实实把搬运过程新增的漂移计入不确定性。这样，语义证据的价值天然随年龄衰减——不是人为加一个折扣，而是信息论上就该衰减。

**灵感 3（重尾延迟 → 决定安全的是 P99，不是均值）**
直觉：多模态大模型的延迟高度依赖输入：图更大、遮挡更多、问题更开放、分布越奇怪，它越慢——**恰好在场景最难、最需要它的时候最慢**。均值延迟会给出「来得及」的假象，而少数几次超时正好落在最危险的状态上。因此任何「是否值得问」的判断都必须使用延迟的**上置信界**，而不是期望；P99 超过期限的查询，其决策价值应按 0 计，哪怕平均只有 300 ms。

**灵感 4（幻觉 → 校准必须条件在「年龄」上）**
直觉：R69 的 ECE 只回答「这个模型平时准不准」。但对一份迟到 800 ms 的语义证词，真正该问的是「**在它这么老的时候**还准不准」。同一模型的 ECE 会随年龄上升：30 ms 时语义标签几乎不变，2 s 后物体可能被移动、人可能换了意图。于是校准对象从一维的 (confidence, correct) 变成二维的 (confidence, age, correct)；一旦某个年龄段的 ECE 超界，就把有效期截短，而不是继续相信。

**灵感 5（猜测—验证 → 把「等」变成可回滚的并行）**
直觉：既然慢模型一定会迟到，就不要让身体空等。用一个亚毫秒的快 draft 先猜「慢模型大概会说什么」，在**可逆、且在承诺视界内**的动作上先执行；慢答案到达后若与草稿不一致，再平滑纠正或重规划。这和投机解码同构，但风险对象从「token 正确性」变成「物理回滚代价」：只有当回滚成本被预算吸收时，猜测才被允许。猜测永远不被认证为「正确」，只被认证为「可恢复」。

**灵感 6（延迟攻击 → 新的攻击面是「时间」）**
直觉：R69 的威胁模型担心「问错」。R70 还要担心「被拖慢」与「被旧答案骗」：对手可以用超高分辨率图、超长提示、病态输入诱发尾延迟，让系统在关键时刻失去语义；可以重放一份格式完全合法、但描述的是三秒前世界的语义包；也可以给出「查询时刻正确、现在已错误」的滞后投毒。时间戳、内容哈希、来源证明、单调版本号和场景变化失效器，必须成为新的证据卫生。

**灵感 7（与 R69 的关系 → 慢语义只能是增强，不能是安全底座）**
直觉：R69 的安全性建立在「快感知 + 几何/动力学证书」上，语义只是消歧的额外证据。R70 必须守住这条线：**语义通道可以增加任务能力，但绝不能被允许成为安全认证的唯一来源**。这样，即使大模型彻底掉线、被骗或说胡话，系统也不过是退回到 R69 的「快而保守」，而不是退回到「慢而自信」。这是本轮的理论姿态：新层是旧层的增强，不是替代。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TEMPO-RAS 总览）** TEMPO-RAS = (SEB, FRR, LAT, ASB, TVoI, ASO, SVR, SCG, TCC, SIS, AIC-TEMPO, VQAuditor-T, J_TEMPO)。继承 R69 定义 293 的实时零学习写操作、交互预算与证据纪律；新增四条不变式：
(i) **语义非阻塞**：任何控制 tick 不得等待慢 oracle，快环硬截止与 R69 相同；
(ii) **新鲜度**：进入决策的语义证据必须携带时间戳，年龄 ≤ A_max(z_t)，并经 FRR 前向重引用；超龄即视同缺失；
(iii) **陈旧不单独认证**：安全关键动作的认证至少需一个当前时刻的快感知/几何通道佐证，或动作本身属于语义不变安全集 SIS；
(iv) **可回滚的猜测**：任何基于推测语义提前执行的动作必须可逆，且回滚能在承诺视界 h_c 内完成。

**定义 311（语义证据包 SEB）** e = (y, t_q, t_r, h, c, v)。y 为语义内容（物体类别/指代/任务意图/关系），t_q 为查询发出时刻，t_r 为返回时刻，h 为内容哈希与来源证明，c 为校准版本，v 为模型版本。**年龄按内容所关于的世界时刻计**：a(e,t) = t − t_q（不是 t − t_r）。包有效 ⇔ a ≤ A_max ∧ h 通过 ∧ (c,v) 在信任清单 ∧ 未被场景失效器作废。

**定义 312（前向重引用 FRR）** 设语义后验 p(s_{t_q} | e, o_{≤t_q})。用世界模型 P(s_t | s_{t_q}, a_{t_q:t}) 前向传播：
p_t^{sem}(s) = ∫ P(s_t | s_{t_q}) p(s_{t_q} | e) ds_{t_q}。
定义**语义漂移** D_sem(e,t) = W₂(p_t^{sem}, p_t^{fast})，其中 p_t^{fast} 为只用当前快观测的后验。FRR 的误差由世界模型的预测误差界与条件 Lipschitz 常数控制（A99）。若 D_sem 无法可靠估计，则用保守上界（由引理 19）。

**定义 313（延迟模型与 LUCB）** 延迟 τ(q,x) ~ p(τ | q, scene)，重尾且依赖输入。用分位数回归 + conformal 维护上界 τ⁺_α(q) = Q̂_{1−α}(τ | q) + δ_conf，α 为尾风险预算。**发不发**查询看 τ⁺_α(q) ≤ D_t − τ_margin；在 TEMPO 中查询永远异步，该判据决定「是否值得发」，而不是「是否等待」。

**定义 314（时效预算）** A_max(z_t) = sup{ a : E_{e, age=a}[D_sem(e,t)] ≤ ε_stale }，由快信念的局部可预测性/收缩率估计。同时受校准年龄 A_cal（定义 318）约束：A_max := min(A_stale, A_cal)。超龄包由总线丢弃。

**定义 315（时效折现 VoI）** TVoI(q) = E[ΔH(M; y) · 1{τ(q) ≤ D_t} · 1{D_sem(e,t) ≤ ε_stale}] − c_comp(q) − c_stale(q)，其中 c_stale = κ_s·E[D_sem]。等价的指数折现写法为 TVoI ≈ γ^{τ⁺}·VoI_0 − c_comp。若 max TVoI ≤ 0 或尾风险超限 ⇒ 不查询，走快环/推测。R69 的 VoI 是 τ≡0、D_sem≡0 的特例。

**定义 316（异步语义总线 ASB）** 由三部分组成：在途查询 future 表、有效证据包缓存、场景失效器。快环以 lock-free 快照读取最新有效包；失效触发条件为：(a) 快感知变化量 > δ_scene；(b) 包年龄超过 A_max；(c) 收到更高版本或矛盾的包；(d) 制度切换（碰撞/跌倒/急停，见 R69 认证联动）。场景变化后，在途查询被标记「到达即过期」，其结果不得进入决策。

**定义 317（推测—验证 SVR）** 快 draft 模型 D_ψ 在 τ_d ≪ τ 内给出语义草稿 y_d 与置信。若 y_d 与快感知自洽、动作可逆且在承诺视界 h_c 内，可先执行；慢 oracle 到达后若与草稿分歧超过 δ_sem，触发 (a) 平滑纠正、(b) 重新规划、或 (c) 进入保守制度。承诺视界之外的动作不得建立在草稿上。猜测只被认证为「可恢复」，不被认证为「正确」。

**定义 318（时效条件校准 TCC）** 在人工老化的验证集上（真实时序回放或世界模型前向）测 ECE(a)，要求 ∀a ≤ A_max：ECE(a) ≤ τ_ece，且可靠性图随年龄单调不增。定义 A_cal = sup{ a : ECE(a) ≤ τ_ece }。这把「模型准不准」升级为「模型在多老的时候还准」；A_max 由 min(A_stale, A_cal) 决定。

**定义 319（语义-快感知一致性门 SCG）** 一致性分 κ_t = log[p(y | o_t) / p(y | p_t^{fast})]，或用互信息。若 κ_t < κ_min 且没有第二个正交证据，则语义包降级为「先验提示」，不得参与安全认证。**关键约束**：SCG 至少需要一个几何/接触通道独立佐证；只比较快慢两路是否同源会被共享先验骗过（这一点扩展了 R69 引理 18 的正交性要求）。

**定义 320（计算预算编排 ASO）** 全局预算 B（算力/功耗/带宽），候选查询集 Q。选择 S ⊆ Q 最大化 Σ_{q∈S} TVoI(q)，s.t. Σ c_comp(q) ≤ B，且每个 q 的 τ⁺ 满足各自期限。这是带期限的背包/调度问题；在线用 TVoI/c_comp 贪心加期限可行性检查近似。停止准则是 value-of-computation：继续推理的边际收益 ≤ 边际延迟成本。

**定义 321（随时推理级联）** oracle 提供级联级别 l=0..L（早退/小模型/大模型），每级有 (τ_l, ECE_l, coverage_l)。在线选最小 l，使 P(correct | level l, deadline) ≥ 1−δ_req 且 τ⁺_l ≤ D_t。级联把「一个慢 oracle」变成「一族速度—精度可调的语义证据源」。

**定义 322（语义不变安全集 SIS）** S_sem-safe = { (x,a) : 安全认证只依赖几何/动力学/接触，不依赖语义标签 }。当语义通道 down/stale/uncalibrated/disagree 时，把任务限制到 S_sem-safe（例如只做避碰与保持，不做「按语义抓取」），直到证据恢复。这是在 R69 两级退避之外新增的**第三级：语义级退避**。

**定义 323（时序威胁模型 ℰ_TEMPO）** ℰ_lat（延迟洪泛：大分辨率/长提示/病态输入诱发尾延迟）、ℰ_replay（重放旧的但格式合法的语义包）、ℰ_lag（滞后投毒：查询时刻正确、当下已错误的答案）、ℰ_ver（版本回滚/伪造来源）。并入 AIC：ℰ_TEMPO = ℰ_FLUID × ℰ_lat × ℰ_replay × ℰ_lag。

**定义 324（VQAuditor-T）** 审计对象新增：是否「明知来不及仍发」查询、陈旧包是否被使用、推测是否越出承诺视界、SCG 的独立性是否满足、延迟是否被对手放大、TCC 是否在年龄维度被绕过。结论回灌为 ASO 的成本先验与 A_max 的保守偏移。

**定义 325（证书 J_TEMPO）** J_TEMPO = (J_FLUID, tau_p99, stale_age_p99, ece_age_curve_hash, scg_auc, spec_rollback_rate, compute_budget_used, sem_hash_chain, tempo_ver)。Valid ⇔ Valid(J_FLUID) ∧ τ⁺_α ≤ SLO ∧ A_max > 0 ∧ ∀a≤A_max ECE(a) ≤ τ_ece ∧ SCG 独立性通过 ∧ 预算未越界。

**定义 326（三级时序退避与 R69 包含）** 若语义包新鲜、校准且与快感知一致：扩展 R69 的 resolution bonus，λ = λ_floor(U_ale)，并允许语义消歧带来的 U_epi 下降；若语义通道超时/过期/未校准/不一致：λ = λ_floor(U_ale + U_epi + U_sem)，并把任务限制到 SIS，其中 U_sem := D_sem + (1−conf)·H(M) 为「陈旧 + 不确定」的等效不确定度。当 τ≡0、A_max=∞、oracle 完美且 SCG 恒真时，定义 326 退化为 R69 定义 307，且逐指令一致。

# IP-264/265 SEB + FRR：时间戳证据包与快照前向重引用
class SemPacket:
    y: Tensor; t_q: float; t_r: float; h: str; cal_ver: int; model_ver: int

class SemanticBus:
    def submit(self, q, t_q):                 # 非阻塞，立即返回 future
        self.inflight[q.id] = self.oracle(q, t_q)
    def poll(self, t, fast_belief):           # 快环 lock-free 读取
        e = self.latest_valid()
        if e is None or t - e.t_q > self.max_age(fast_belief):
            return None                       # 超龄即缺失，不"凑合用"
        p_sem = self.wm.forward_belief(e, t)  # FRR：把旧语义搬运到现在
        return e, p_sem
    def invalidate(self, delta_scene):
        if delta_scene > TAU_SCENE:           # 场景已变，在途答案到达即过期
            self.inflight.clear(); self.latest_valid = None

# IP-267/320 TVoI + ASO：用尾延迟而非均值编排查询
def schedule_queries(Q, budget, deadline, latency_model):
    scored = []
    for q in Q:
        tau_ub = latency_model.ucb(q, alpha=0.05)          # LUCB
        if tau_ub > deadline - TAU_MARGIN:
            continue                                        # 明知来不及，不发
        tv = temporal_voi(q, tau_ub)                        # 时效折现
        if tv > 0: scored.append((tv / max(q.cost, 1e-6), q, tv))
    picked, used = [], 0.0
    for ratio, q, tv in sorted(scored, reverse=True):
        if used + q.cost > budget: continue
        picked.append(q); used += q.cost
    return picked

# IP-269 SVR：推测语义 + 到达后验证（可回滚）
def speculate_or_act(fast, bus, action, h_c):
    draft = fast.semantic_draft()             # 亚毫秒
    if not within_commitment(action, h_c) or not fast.semantic_safe(action):
        return None                           # 不可回滚，禁止推测
    act(action, hint=draft)
    e = bus.wait_async()                      # 下一 tick 检查，不阻塞主环
    if e and disagree(e.y, draft) > DELTA_SEM:
        return rollback_or_replan(e)          # 平滑纠正 / 重规划 / 保守
    return None

# IP-276 TEMPO-RAS 主闭环（继承 R69，语义路径异步化）
def TEMPO_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)  # R69 快环
    snap = M.bus.poll(t, z)                   # 有新包才做 FRR
    if snap is not None:
        e, p_sem = snap
        kappa = M.scg.agreement(p_sem, z, o)  # 需独立几何/接触佐证
        if kappa < KAPPA_MIN or not M.tcc.valid(e):
            p_sem = None; U_sem = M.u_sem(e, z)   # 降级为先验提示
        else:
            U_sem = M.frr.drift(e, z)
    else:
        p_sem, U_sem = None, 0.0
    # R69 的 aleatoric/epistemic 二分；语义只作为额外证据/先验
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K, prior=p_sem)    # 条件先验，不阻塞
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 时效折现的交互：异步发出，立即返回
    if U_epi > TAU_EPI and not M.slow_fault:
        qs = M.aso.schedule(M.mint.candidates(modes), M.budget, M.deadline(z))
        for q in qs: M.bus.submit(q, t)
    # 有新鲜语义则消歧；否则语义级退避
    if p_sem is not None:
        U_epi = M.cia.update_belief_posterior(modes, p_sem)
        U_floor = U_ale
    else:
        U_floor = U_ale + U_epi + U_sem
        M.sis.restrict(M.task)                # 语义不变安全集
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(...)
    mode = M.svr.select_and_maybe_speculate(modes, lam, M.sis)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(snap, qs, U_sem, lam, M.svr.stats())
    return k, lam, mode, (U_ale, U_epi, U_sem)

## 3. 推导

**引理 19（陈旧可容许界）** 设快信念的模态分离裕度沿用 R69 的 Δ_min，语义漂移随年龄最多以两种方式增长：可预测场景下 D_sem(e,t) ≤ D_0 + L_f·a；不稳定场景下 D_sem(e,t) ≤ D_0·e^{λ_L·a}（λ_L 为局部 Lyapunov 指数）。语义证据仍能唯一决定模态（决策等价）的充分条件是 D_sem < Δ_min/2。于是可容许年龄
A_max ≤ (Δ_min/2 − D_0)/L_f（Lipschitz 型），或 A_max ≤ (1/λ_L)·ln(Δ_min/(2D_0))（指数型）。
系：**模态分得越开、世界越可预测，旧语义越"耐放"**；高动态场景会急剧压缩 A_max——这正是「延迟必须进入不确定性」的定量含义。

**引理 20（尾延迟支配与均值延迟的乐观偏差）** 设单次语义增益有界 0 ≤ ΔH ≤ H_max，查询期限 D_t。精确的期望增益为 E[ΔH·1{τ≤D_t}] ≤ H_max·P(τ≤D_t)。若用均值 τ̄ 代替分布，只要 τ̄ ≤ D_t 就判为「值得问」，但当重尾使 P(τ>D_t)=p 时，真实增益至多为 (1−p)H_max。因此当 p > c/H_max（c 为查询与延迟成本）时，基于均值的决策会**系统性地把不值得的查询判成值得**。系：任何 P99 超过期限的查询，其决策价值应按 0 计，无论均值多漂亮。这直接给出 LUCB 的必要性。

**引理 21（推测语义的安全回滚界）** 设 draft 的错误概率为 p_d，单次回滚代价为 c_r，承诺视界 h_c 内成功回滚的概率为 1−δ_r，最坏物理伤害为 s_max。若推测只在可逆动作集上、且回滚在 h_c 内完成，则期望伤害 ≤ p_d·c_r + δ_r·s_max。故当 p_d·c_r + δ_r·s_max ≤ ε_spec 时，推测可被安全地允许。系：**猜测只扩大"可恢复动作"的集合，不扩大"被认证为正确"的集合**；不可逆动作必须等真答案。

**引理 22（时效校准的 Lipschitz 界）** 若 ECE(a) 关于年龄是 L_cal-Lipschitz，且 ECE(0) ≤ τ_0，则 ECE(a) ≤ τ_0 + L_cal·a。于是校准允许的最大年龄 A_cal ≤ (τ_ece − τ_0)/L_cal。系：**校准时时钟由语义分布的漂移速度决定**；世界模型越准、语义越稳定，L_cal 越小，A_max 越长。这也说明 TCC 不是额外负担，而是把 R69 的 ECE 门自然延拓到时间轴。

**定理 18（TEMPO 严格包含 R69）** 当 τ≡0、A_max=∞、oracle 与 R69 等价、SCG 恒真、ASO 预算无限且关闭 SVR 时，定义 310–326 全部退化，TEMPO 的决策与 FLUID-RAS 逐指令相同。当 τ>0 时，对任意状态：(a) 若语义新鲜有效，额外证据只会降低后验熵，且动作仍受 R69 的 C-RAS-WM 认证，故风险不高于 R69 使用同等证据时的风险；(b) 若语义陈旧/缺失，λ 使用 U_floor = U_ale + U_epi + U_sem ≥ R69 的 U_ale + U_epi，并把任务限制到 SIS，认证安全包络不大于 R69，故期望风险 ≤ R69。等号在「永不使用语义通道」边界取得。**安全侧不做任何让步，效率侧获得「时效消歧」的 resolution bonus。**

**定理 19（非阻塞实时界）** ASB 的 submit/poll/invalidate 均为 O(1)，且不持有控制环锁；有新包时 FRR ≤ 0.2 ms、SCG ≤ 0.05 ms、SVR draft ≤ 0.4 ms，否则走缓存命中路径 ≤ 0.02 ms。故快环节拍 P99 在 K=1 时 ≤ 3.0 ms、K=4 时 ≤ 3.8 ms，与 R69 的 2.6/3.4 ms 相比仅增加亚毫秒级开销；慢 oracle 的 P99（目标 ≤ 800 ms，级联路径 ≤ 300 ms）完全在环外，由独立的语义 SLO 约束，不进入控制截止。

**定理 20（语义掉线安全 / rely-guarantee 契约）** 若 SIS 在快控制器下受控不变（即 R69 的快感知—几何证书单独成立），且任意任务可在 h_c 内安全悬挂到 SIS，则语义通道的丢失、超时、被投毒都不改变快环的安全证书；慢语义只提供任务能力增益，不承担安全底座。故延迟尖峰与延迟攻击最多导致任务能力下降，不会导致安全回退。这条定理是 R70 对第 323 类攻击的结构性回答。

## 6. 本轮最大风险

## 4. 推导

**引理 19（陈旧可容许界）** 在 R69 的模态分离裕度 Δ_min 下，若漂移按 `D_sem ≤ D_0 + L_f·a`（可预测）或 `D_sem ≤ D_0·e^{λ_L·a}`（不稳定）增长，则决策等价的充分条件为 `D_sem < Δ_min/2`，故 `A_max ≤ (Δ_min/2−D_0)/L_f` 或 `A_max ≤ (1/λ_L)·ln(Δ_min/(2D_0))`。系：模态越可分、世界越可预测，旧语义越「耐放」；高动态场景急剧压缩有效期。

**引理 20（尾延迟支配）** `E[ΔH·1{τ≤D_t}] ≤ H_max·P(τ≤D_t)`。用均值 `τ̄≤D_t` 判「值得问」时，若 `P(τ>D_t)=p`，真实增益至多 `(1−p)H_max`；当 `p > c/H_max` 时均值决策系统性高估。系：P99 超期的查询按价值 0 处理，LUCB 是必要的。

**引理 21（推测安全回滚界）** 若仅在可逆集上、且 `h_c` 内以概率 `1−δ_r` 成功回滚，则期望伤害 `≤ p_d·c_r + δ_r·s_max`；该值 `≤ ε_spec` 时推测可允许。系：猜测只扩大「可恢复动作」，不扩大「被认证正确」。

**引理 22（时效校准 Lipschitz 界）** `ECE(a) ≤ ECE(0) + L_cal·a`，故 `A_cal ≤ (τ_ece−τ_0)/L_cal`；语义漂移越慢，有效期越长。

**定理 18（TEMPO 严格包含 R69）** τ≡0、A_max=∞、oracle 等价、SCG 恒真、关闭 SVR 时，定义 310–326 退化为 FLUID-RAS，逐指令相同。τ>0 时：新鲜语义路径只增加证据、仍过 C-RAS-WM；陈旧/缺失路径用 `U_floor ≥ U_ale+U_epi` 并限制到 SIS，故期望风险 ≤ R69；等号在「永不使用语义」边界取得。安全不让步，效率获时效 resolution bonus。

**定理 19（非阻塞实时界）** 总线操作 O(1) 且不持锁；有新包时 FRR ≤ 0.2 ms、SCG ≤ 0.05 ms、SVR draft ≤ 0.4 ms，缓存命中 ≤ 0.02 ms。K=1 快环 P99 ≤ 3.0 ms，K=4 ≤ 3.8 ms；慢 oracle P99 目标 ≤ 800 ms（级联 ≤ 300 ms）全在环外，独立 SLO。

**定理 20（语义掉线安全）** 若 SIS 在快控制器下受控不变、任务可在 `h_c` 内安全悬挂到 SIS，则语义通道的丢失/超时/投毒都不改变快环安全证书；慢语义只提供能力增益，不承担安全底座。故延迟尖峰与延迟攻击最多降低任务能力，不导致安全回退。

## 7. 本轮最大风险

**一句话**：TEMPO-RAS 把安全与能力都押在「世界模型能把旧语义前向搬运到当下」上——**若世界模型在分布外或高动态场景下漂移，前向重引用会生成一个看似新鲜、实则是模型自己想象出的「当下」；而 SCG 若只比较快慢两路、缺少独立几何佐证，共享同一错误先验时会对幻觉齐声说「一致」，把错误盖成共识。**
