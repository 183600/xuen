# 第 1 轮 · 灵感：自监督学习 × 流匹配策略

## 一、直觉先行（先不严谨地说人话）

v23 的整条证书链解决的是「**我凭什么相信这个计划是安全的**」：语义证书、缺席证书、能量证书、云边版本、少样本覆盖、专利边界。它默认了策略 π 是一个**给定的、可被逐点检查的确定性映射**。但真实机器人策略正在换代：从「回归一个动作向量」变成「**从噪声生成一整条动作轨迹**」。

**流匹配策略（flow matching policy）** 的直觉是：不去直接拟合 `o → a`，而是学一个速度场 `v_θ(a_t, t | o)`，把高斯噪声沿 ODE 搬运成动作分布。好处是它能表达**多模态、平滑、时序连贯**的动作（这对灵巧操作极其关键）；代价是——动作不再是函数值，而是**积分的结果**。于是安全证书必须回答一个新问题：*积分误差会不会把「安全动作」搬出安全集？* 这就是 v23 完全没有覆盖的缺口。

**自监督学习（SSL）** 的直觉是：在没有标签的连续视频流里，学一个对「无关变换（光照、裁剪、噪声）不变」的表征 φ。它正好补 v23 的两个软肋：其一，conformal 校准和原型少样本都建立在 φ 上，φ 是否稳定决定了覆盖承诺是否可信；其二，分布漂移检测可以靠 φ 空间而非原始像素（也符合隐私）。但 SSL 有一个危险的副作用：**「不变」和「失明」在数学上是同一个操作**——如果你把行人当作「光照噪声」一样augment 掉，表征会非常一致地忽略他。

**把两个词焊在一起的直觉命题**：
> 用 SSL 表征 φ 去条件化一个流匹配策略 v_θ，再用「表征证书 + 流证书 + 屏障证书」把这条「表征→ODE→动作」的复合管线整体夹住。

一句话：v23 证明「**动作是安全的**」，v24 要证明「**生成动作的那条连续流是安全的，且喂给它的表征没有失明**」。

## 二、两个灵感词各自补哪个缺口

| 缺口（v23 遗留） | SSL 能补什么 | 流匹配能补什么 |
|---|---|---|
| 策略是多模态的，单点证书只覆盖一个动作 | — | 生成整族动作，可对分布整体取证 |
| 动作平滑性/时序一致性无证书 | — | ODE 天然产生连续轨迹，误差可界 |
| φ 的可靠性只是「经验假设」 | 不变性/信息量/Lipschitz 可量化成证书 | — |
| 分布漂移检测依赖像素 | 在 φ 空间做漂移与聚类条件覆盖 | — |
| 少样本原型易受 nuisance 干扰 | 一致性正则收缩 nuisance 方向 | 条件化在稳健 φ 上 |
| 生成过程的数值误差无人负责 | — | Euler/RK 离散误差可解析界（Grönwall） |

## 三、焊在一起后冒出的新命题（本轮真正的“想法”）

1. **复合 Lipschitz 链**：动作对观测的敏感度 = `L_D · e^{L_v} · L_φ`（解码器 × 流映射 × 编码器）。这条链把三个原本独立的模块的鲁棒性**乘**在一起——任何一环爆炸，整体安全证书失效。这是 v23 里不存在的「乘性耦合」。

2. **流上的屏障，而不是终点上的屏障**：只检查终点 `a_1 ∈ A_safe` 不够，因为积分中途可能穿过禁区再回来（对真实动力学是致命的）。要在 ODE 轨迹上放**控制屏障函数 B**，用 `∇B·v_θ ≤ -α(B)` 保证前向不变，再用 ε_ode 做鲁棒膨胀。

3. **SSL 的“不变性”必须配一个“危险性”对偶**：既然不变性会抹掉特征，就必须显式要求对**危险扰动**敏感（HazardProbe）。也就是把 SSL 目标从「单目标不变」升级成「**不变 + 敏感**」的双目标。这是本轮最关键的洞察——它直接把 SSL 从“可能致盲”变成“可审计”。

4. **簇条件 conformal**：用 φ 聚类做 Mondrian conformal，把 v23 的**边际覆盖**升级为**簇条件覆盖**，缓解多模态策略下“平均达标、局部失效”。

5. **证书感知的联合训练**：流匹配损失 + 不变性 + 危险性 + Lipschitz 惩罚 + 屏障惩罚，联合优化，使训练出的策略天生更容易通过证书（而不是训完再硬卡）。

## 四、候选方向与取舍

- 方向 A：只把流匹配当“更好的回归器”，沿用 v23 逐点证书。→ 太保守，浪费了 ODE 可解析取证的独特优势。
- 方向 B：只做 SSL 表征证书，策略仍是回归。→ 保守，但可作为退路。
- 方向 C（**选定**）：SSL 表征证书 ⊕ 流匹配策略证书 ⊕ 流上屏障 ⊕ 簇条件 conformal ⊕ 联合训练，五证一体，`Exec_v24 ⊆ Exec_v23`。
- 方向 D：把流匹配本身当 SSL 目标（用 flow 做表征学习）。→ 新颖但离安全取证太远，留作后续轮。

选 C：它既吃满两个灵感词，又严格保持 v23 的单调退化链。

## 五、本轮选定方向的一句话概括

**用「可审计的不变性 + 危险敏感性」给 SSL 表征发证，用「Grönwall 离散误差界 + 流上屏障」给流匹配策略发证，再用簇条件 conformal 兜住多模态覆盖，五证交集得到 `Exec_v24`。**

## 六、一句话最大风险

**SSL 的不变性目标可能把安全关键的低频特征当作 nuisance 一并丢弃，而流匹配会在这条“可证明一致、却可证明失明”的表征上生成平滑而自信的危险动作——证书链验证的是表征的一致性与流的数值正确性，而不是表征的语义完备性。**

```python
# ============================================================
# IP-440 Self-Supervised Representation Certificate (SSRC)
# ============================================================
class RepresentationCertificate:
    def __init__(self, encoder, G_safe, H_hazard,
                 eps_inv=0.05, delta_h=0.3, eps_probe=0.15,
                 lambda_min=1e-3, L_phi_max=5.0):
        self.phi = encoder            # SSL 编码器 E_ψ
        self.G_safe = G_safe          # 经审计的安全保持增强集合
        self.H_hazard = H_hazard      # 危险扰动集合
        self.eps_inv, self.delta_h = eps_inv, delta_h
        self.eps_probe, self.lambda_min = eps_probe, lambda_min
        self.L_phi_max = L_phi_max

    def invariance(self, unlabeled_stream) -> float:
        """RepInv：对 G_safe 内增强的不变性损失"""
        losses = []
        for x in islice(unlabeled_stream, 200):
            for g in self.G_safe.sample(4):
                losses.append(F.mse_loss(self.phi(x), self.phi(g(x))))
        return torch.stack(losses).mean().item()

    def hazard_probe(self, hazard_pairs) -> float:
        """HazardProbe：危险扰动必须显著改变表征，返回最小分离度"""
        seps = []
        for x, h in hazard_pairs:      # h(x) 是危险扰动后的同一场景
            seps.append(torch.norm(self.phi(x) - self.phi(h(x))).item())
        return min(seps) if seps else 0.0

    def information(self, probe_data) -> tuple[float, float]:
        """RepInfo：线性探针风险 + 协方差最小特征值（防坍缩）"""
        X = torch.stack([self.phi(x) for x, _ in probe_data])
        y = torch.tensor([y for _, y in probe_data])
        risk = linear_probe_risk(X, y)          # 闭式 ridge 解
        Sigma = torch.cov(X.T)
        lam_min = torch.linalg.eigvalsh(Sigma).min().item()
        return risk, lam_min

    def lipschitz_estimate(self, batch, n_pairs=256) -> float:
        """L_φ：随机对谱范数估计（幂迭代近似 Jacobian）"""
        return estimate_lipschitz(self.phi, batch, n_pairs)

    def certify(self, unlabeled_stream, hazard_pairs, probe_data, batch) -> bool:
        # 0. 增强群合法性：G 必须是 G_safe 的子集（审计门槛）
        if not self.G_safe.covers(self.phi.augmentation_group):
            return False
        # 1. 不变性
        if self.invariance(unlabeled_stream) > self.eps_inv:
            return False
        # 2. 危险敏感性（防“可证明失明”）
        if self.hazard_probe(hazard_pairs) < self.delta_h:
            return False
        # 3. 信息量 + 防坍缩
        risk, lam_min = self.information(probe_data)
        if risk > self.eps_probe or lam_min < self.lambda_min:
            return False
        # 4. Lipschitz
        if self.lipschitz_estimate(batch) > self.L_phi_max:
            return False
        return True

# IP-441 Flow Matching Policy Certificate (FMPC)
# ============================================================
class FlowMatchingCertificate:
    def __init__(self, v_theta, decoder, N=10,
                 L_v_max=8.0, M_v_max=50.0, eps_ode_max=0.02,
                 L_pi_max=50.0):
        self.v = v_theta
        self.D = decoder              # latent->action 解码器（可为恒等）
        self.N = N
        self.L_v_max, self.M_v_max = L_v_max, M_v_max
        self.eps_ode_max, self.L_pi_max = eps_ode_max, L_pi_max

    def euler_flow(self, a0, z):
        """N 步 Euler 积分：a_{k+1} = a_k + h v(a_k, t_k | z)"""
        h = 1.0 / self.N
        a = a0
        for k in range(self.N):
            a = a + h * self.v(a, k * h, z)
        return a

    def ode_error_bound(self, L_v, M_v) -> float:
        """Grönwall：全局离散误差 ε_ode = (h/2) M (e^L - 1)/L"""
        h = 1.0 / self.N
        if L_v < 1e-9:
            return 0.5 * h * M_v
        return 0.5 * h * M_v * (math.exp(L_v) - 1.0) / L_v

    def estimate_constants(self, batch, z_batch) -> tuple[float, float]:
        """离线估计 L_v 与 M_v（谱范数 + 沿流加速度）"""
        L_v = estimate_lipschitz(self.v, batch, cond=z_batch)
        M_v = 0.0
        for a0, z in zip(batch, z_batch):
            a, t = a0, 0.0
            for _ in range(self.N):
                v = self.v(a, t, z)
                dv_dt = jvp_time(self.v, a, t, z, v)     # ∂_t v + J_v v
                M_v = max(M_v, dv_dt.norm().item())
                a, t = a + v / self.N, t + 1.0 / self.N
        return L_v, M_v

    def composite_sensitivity(self, L_v, L_phi, L_D) -> float:
        """L_π = L_D · e^{L_v} · L_φ（乘性链）"""
        return L_D * math.exp(L_v) * L_phi

    def certify(self, batch, z_batch, L_phi, L_D) -> tuple[bool, float]:
        L_v, M_v = self.estimate_constants(batch, z_batch)
        eps_ode = self.ode_error_bound(L_v, M_v)
        L_pi = self.composite_sensitivity(L_v, L_phi, L_D)
        ok = (L_v <= self.L_v_max and M_v <= self.M_v_max
              and eps_ode <= self.eps_ode_max and L_pi <= self.L_pi_max)
        return ok, eps_ode

# IP-442 Certified Flow Safety Barrier (CFSB)
# ============================================================
class FlowSafetyBarrier:
    def __init__(self, barrier_fn, alpha_fn, L_B,
                 M_seeds=256, alpha_conf=0.01, delta=1e-3):
        self.B = barrier_fn          # B(a) <= 0 为安全
        self.alpha_fn = alpha_fn     # 扩展 K∞ 函数
        self.L_B = L_B
        self.M = M_seeds
        self.alpha_conf = alpha_conf
        self.delta = delta

    def barrier_derivative(self, a, t, z, v) -> float:
        """沿流的屏障导数：dB/dt = ∇B · v_θ(a,t|z)"""
        grad = torch.autograd.grad(self.B(a).sum(), a)[0]
        return (grad * v).sum().item()

    def trajectory_invariance(self, a0, z, v, eps_ode, N=10):
        """逐步检查 ∇B·v ≤ -α(B) 的离散鲁棒版本"""
        h = 1.0 / N
        a, t = a0, 0.0
        for _ in range(N):
            b = self.B(a).item()
            dB = self.barrier_derivative(a, t, z, v(a, t, z))
            # 离散鲁棒条件：dB/dt ≤ -α(B) - (L_B·M_v·h/2)
            if dB > -self.alpha_fn(b) - self.L_B * eps_ode * h:
                return False
            a, t = a + h * v(a, t, z), t + h
        return True

    def seed_safety(self, flow_fn, z, eps_ode) -> tuple[bool, float]:
        """种子采样 + conformal 分位数的概率屏障谓词"""
        vals = []
        for i in range(self.M):
            a0 = torch.randn_like(z)      # 先验 N(0,I)
            a1 = flow_fn(a0, z)
            vals.append(self.B(a1).item())
        vals = sorted(vals)
        k = math.ceil((self.M + 1) * (1 - self.alpha_conf)) - 1
        q = vals[min(k, self.M - 1)]
        eps_tube = self.L_B * eps_ode
        return (q + eps_tube <= 0.0), q + eps_tube

    def certify(self, flow_fn, z, eps_ode) -> bool:
        ok, _ = self.seed_safety(flow_fn, z, eps_ode)
        return ok

# IP-443 SSL-Clustered Conformal Calibration (SCC)
# ============================================================
class ClusteredConformal:
    def __init__(self, phi, clusterer, alpha=0.01, n_min=30, delta=1e-3):
        self.phi = phi
        self.clusterer = clusterer
        self.alpha = alpha
        self.n_min = n_min
        self.delta = delta
        self.calib = defaultdict(list)     # cluster -> [(score, err)]
        self.quantiles = {}                # cluster -> q_hat

    def score(self, x, y, prototypes, covs) -> float:
        z = self.phi(x)
        c = self.clusterer(z)
        mu = prototypes[y]
        return torch.sqrt((z - mu) @ torch.linalg.solve(covs[c], z - mu)).item()

    def fit(self, calib_pairs):
        for x, y in calib_pairs:
            z = self.phi(x)
            c = self.clusterer(z)
            self.calib[c].append((self.score(x, y, self._proto, self._covs), y))
        for c, rows in self.calib.items():
            if len(rows) < self.n_min:
                self.quantiles[c] = None      # 簇样本不足 → 弃权
                continue
            errs = sorted(e for _, e in rows)
            k = math.ceil((len(errs) + 1) * (1 - self.alpha)) - 1
            self.quantiles[c] = errs[min(k, len(errs) - 1)]

    def certify(self) -> bool:
        """SCC：每簇经验覆盖扣除 Hoeffding 波动后仍 ≥1-α"""
        for c, rows in self.calib.items():
            n = len(rows)
            if n < self.n_min:
                return False                  # 存在覆盖不足簇 → 拒证
            q = self.quantiles.get(c)
            emp = sum(1 for s, e in rows if e <= q) / n
            if emp - math.sqrt(math.log(1 / self.delta) / (2 * n)) < 1 - self.alpha:
                return False
        return True


# ============================================================
# IP-444 Self-supervised Flow Co-Training (SFCT)
# ============================================================
def sfct_train_step(phi, v, D, B, batch, opt, cfg):
    """证书感知联合训练：一次梯度步"""
    o, a1_gt = batch['obs'], batch['action']
    z = phi(o)
    a0 = torch.randn_like(a1_gt)
    t = torch.rand(a1_gt.shape[0], 1)
    a_t = (1 - t) * a0 + t * a1_gt
    # 1) 条件流匹配损失
    L_cfm = F.mse_loss(v(a_t, t.squeeze(-1), z), a1_gt - a0)
    # 2) 不变性（对 G_safe）
    L_inv = F.mse_loss(phi(o), phi(cfg.G_safe.random_aug(o)))
    # 3) 危险敏感性（负号：最大化分离度，低于 δ_h 才罚）
    sep = torch.norm(phi(o) - phi(cfg.H_hazard.random_hazard(o)), dim=-1)
    L_haz = F.relu(cfg.delta_h - sep).mean()
    # 4) Lipschitz 惩罚（谱范数上界）
    L_lip = (F.relu(estimate_lipschitz(v, a_t, cond=z) - cfg.L_v_max)
             + F.relu(estimate_lipschitz(phi, o) - cfg.L_phi_max))
    # 5) 屏障惩罚（在采样轨迹终点）
    a_end = euler_flow(v, a0, z, cfg.N)
    L_bar = F.relu(B(a_end) + cfg.eps_tube).mean()
    L = (L_cfm + cfg.lam_inv * L_inv + cfg.lam_haz * L_haz
         + cfg.lam_lip * L_lip + cfg.lam_bar * L_bar)
    opt.zero_grad(); L.backward(); opt.step()
    return L.item()


# ============================================================
# IP-445 HPC-E++ 统一五证准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'                 # v23 四证（HPC-E ∪ CESC ∪ FSVC ∪ IPAttest）
    ssrc: RepresentationCertificate
    fmpc: FlowMatchingCertificate
    cfsb: FlowSafetyBarrier
    scc: ClusteredConformal

    def admits(self, plan, obs, flow_fn, z, L_phi, L_D, cert_ctx) -> bool:
        # 1. v23 四证
        if not self.hpc_e_plus.admits(
                plan, obs['x'], obs['v'], obs['z'], obs['E_res'],
                obs['margin_req'], obs['modules']):
            return False
        # 2. 表征四证
        if not self.ssrc.certify(cert_ctx['unlabeled'], cert_ctx['hazard'],
                                 cert_ctx['probe'], cert_ctx['batch']):
            return False
        # 3. 流匹配策略证书
        ok, eps_ode = self.fmpc.certify(cert_ctx['batch'], z, L_phi, L_D)
        if not ok:
            return False
        # 4. 流安全屏障（用 ε_ode 做鲁棒膨胀）
        if not self.cfsb.certify(flow_fn, z, eps_ode):
            return False
        # 5. 簇条件覆盖
        if not self.scc.certify():
            return False
        return True


# ============================================================
# 端到端：从 SSL 表征到流生成动作的证书化管线
# ============================================================
class SSLFlowCertifiedPipeline:
    def __init__(self, cfg):
        self.phi = cfg['encoder']
        self.v = cfg['flow']
        self.decoder = cfg['decoder']
        self.ssrc = RepresentationCertificate(self.phi, cfg['G_safe'], cfg['H_hazard'])
        self.fmpc = FlowMatchingCertificate(self.v, self.decoder, N=cfg['N'])
        self.cfsb = FlowSafetyBarrier(cfg['barrier'], cfg['alpha_fn'], cfg['L_B'])
        self.scc = ClusteredConformal(self.phi, cfg['clusterer'])
        self.gate = HPCEPlusPlus(cfg['hpc_e_plus'], self.ssrc,
                                 self.fmpc, self.cfsb, self.scc)

    def act(self, obs, cert_ctx):
        z = self.phi(obs)
        a0 = torch.randn(obs.shape[0], self.v.action_dim, device=obs.device)
        # 只在通过五证后才真正积分生成动作
        admitted = self.gate.admits(self._plan(obs), obs, 
                                    lambda a, t, zz: self.v(a, t, zz),
                                    z, cert_ctx['L_phi'], cert_ctx['L_D'], cert_ctx)
        if not admitted:
            return self._safe_fallback(obs)      # 回退到保守控制器
        return self.fmpc.euler_flow(a0, z)
```

## 3. 正确性论证

### 引理 1（Euler 离散误差的 Grönwall 界）
**陈述**：若 v_θ 关于 (a,t) 是 L_v-Lipschitz 且沿流加速度有界 M_v，则对 h=1/N 的显式 Euler，
`‖Φ_1^{exact}(a_0) - Φ_1^{N}(a_0)‖ ≤ ε_ode = (h/2)·M_v·(e^{L_v}-1)/L_v`。

**证明**：
1. 单步局部截断误差：由 Taylor 展开，`a(t+h) - [a(t) + h v] = (h²/2) a''(ξ)`，且 `a'' = d/dt v = ∂_t v + J_v v`，故局部误差 ≤ (h²/2) M_v。
2. 全局误差递推：`e_{k+1} ≤ e_k + h L_v e_k + (h²/2) M_v`（Lipschitz 放大 + 局部误差）。
3. 离散 Grönwall 不等式：`e_N ≤ (h/2) M_v · ((1+hL_v)^N - 1)/L_v`，又 `(1+hL_v)^N ≤ e^{hL_v N} = e^{L_v}`。
4. 取 h=1/N，即得 ε_ode。∎

### 引理 2（复合 Lipschitz 链与表征-流敏感度）
**陈述**：策略 `π(o) = D(Φ_1^{exact}(a_0; φ(o)))` 对观测的敏感度满足
`‖π(o) - π(o')‖ ≤ L_D · e^{L_v} · L_φ · ‖o - o'‖`。

**证明**：
1. 流映射的 Lipschitz：对任意 z,z'，`‖Φ_1(a_0;z) - Φ_1(a_0;z')‖ ≤ e^{L_v}‖z-z'‖`（对变分方程 `δ̇ = J_v δ` 用 Grönwall；这里把 z 视为参数，L_v 含对 z 的依赖）。
2. 编码器：`‖z-z'‖ ≤ L_φ‖o-o'‖`。
3. 解码器：`‖D(u)-D(u')‖ ≤ L_D‖u-u'‖`。
4. 链式相乘即得。∎

**推论**：`L_π ≤ L_π,max` 的证书保证「观测的微小变化不会导致动作跳变」；三项任一超标都使证书失效，故必须**同时**约束编码器、速度场、解码器。

### 引理 3（流上屏障的鲁棒前向不变性）
**陈述**：若 (i) 屏障 B 满足 `∀a∈∂A_safe: ∇B·v_θ(a,t|z) ≤ -α(B(a))`（连续时间前向不变性），(ii) B 是 L_B-Lipschitz，(iii) 数值解满足引理 1 的 ε_ode，则 `B(Φ_1^{N}(a_0;z)) ≤ B(Φ_1^{exact}(a_0;z)) + L_B ε_ode`；若精确轨迹满足 `B(Φ_1^{exact}) ≤ -L_B ε_ode`，则数值终点必在 A_safe 内。

**证明**：
1. 由 Nagumo/屏障定理，条件 (i) 保证精确流不离开 `{B≤0}`。
2. Lipschitz：`|B(x)-B(y)| ≤ L_B‖x-y‖`，故 `B(x_N) ≤ B(x_exact) + L_B‖x_N - x_exact‖ ≤ B(x_exact) + L_B ε_ode`（引理 1）。
3. 若 `B(x_exact) ≤ -L_B ε_ode`，则 `B(x_N) ≤ 0`，即终点安全。∎
**注**：`SeedSafety` 用 conformal 分位数把「对所有 a_0 成立」弱化为「以概率 ≥1-α 成立」，用 M 个先验种子估计 `Q_{1-α}(B(Φ_1^N))`；有限样本修正见引理 4。

### 引理 4（簇条件覆盖）
**陈述**：若每簇 `n_c ≥ n_min` 且 `emp_cov_c - √(ln(1/δ)/2n_c) ≥ 1-α`，则对每簇 c 有 `P(err ≤ q̂_α^c | cluster=c) ≥ 1-α - δ`。

**证明**：
1. 簇内 Mondrian conformal 的有限样本覆盖保证：`P(覆盖 | c) ≥ 1-α`（簇内可交换性成立时）。
2. 经验覆盖的 Hoeffding 下界：以概率 ≥1-δ，`|emp_cov_c - P(覆盖|c)| ≤ √(ln(1/δ)/2n_c)`。
3. 故 `P(覆盖|c) ≥ emp_cov_c - √(...) ≥ 1-α`。∎
**关键前提**：簇内样本可交换。SSL 表征若在簇内发生漂移，可交换性被破坏——这正是 SCC 必须与 SSRC 的 HazardProbe 联动的原因。

### 定理（HPC-E++ 五证准入门的安全-表达-覆盖完备性）
**陈述**：对任意策略 π，`HPCEPlusPlus.admits(π) = True` ⟹ π 同时满足：
(1) v23 的物理接地/云边/少样本/IP 四证；
(2) 表征对 nuisance 不变、对危险敏感、信息量充足且 Lipschitz 有界（SSRC）；
(3) 流匹配生成的动作满足离散误差界与复合敏感度界（FMPC）；
(4) 数值轨迹终点以概率 ≥1-α 落在安全动作集内（CFSB）；
(5) 每个 SSL 簇的条件覆盖 ≥1-α-δ（SCC）。

**证明**：由 `admits` 的五个连言分支、引理 1–4 直接得到。必要性由各过滤器定义；充分性由五证合取保证。∎

### 引理 5（v24 单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ …` 恒成立。

**证明**：
- SSRC 失败（表征坍缩或危险失明）→ 拒证 → 退回 `Exec_v23`。
- FMPC 失败（L_v/M_v/ε_ode/L_π 超界）→ 拒证 → 退回 `Exec_v23`（可用 v23 的逐点策略）。
- CFSB 失败（种子屏障越界）→ 拒证 → 回退保守控制器。
- SCC 失败（某簇样本不足或覆盖不足）→ 拒证 → 退回 v23 的边际覆盖。
- 组合失效取交集，单调性保持。∎
