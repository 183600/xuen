# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233 与第 65 轮「VISTA 故障可归因」IP-214~223；灵感循环第 4 轮；本轮灵感：「创新点提炼」×「论文创新点」）

> 前 66 轮一直在做加法：每轮新增约 10 个 IP，累计到 IP-233。加法带来两个副作用：(i) **创新通胀**——每个组件都自称“创新”，但真正能写进论文的贡献是 O(1)；(ii) **证据稀释**——实验从 E1 排到 E260，审稿人却只记得住 3 个数字。本轮不再加系统，而是做一次「贡献收敛」：把 GRIP→VISTA→RAS 主线（IP-204~233）压成一个 **4 点论文贡献集**，并让每个贡献满足三个硬约束——**可反事实消融、可主张-证据对齐、可与 SOTA 拉开新颖性距离**。
>
> 核心命题：**创新点不是“我做了什么”，而是“没有它，哪条结论会塌；有它，哪个旧假设被替换”。** 更狠的一条：**提炼本身也必须可证伪**，否则所谓创新点只是事后合理化。

## 0. 直觉与动机

**灵感 1（创新点提炼 → 贡献原子）**
直觉：一个创新点 = 一次“假设替换”。GRIP 把“几何先验为真”换成“几何先验可证伪”；VISTA 把“异常即故障”换成“故障可归因”；RAS 把“控制输入不含人”换成“意图可接入”。判断一个 IP 是否够格当创新点，只问三件事：
1. 它替换了哪个旧假设？（position）
2. 去掉它，哪个头条指标或定理会坏？（ablation）
3. 哪个审稿人会因为它被说服？（audience）
三问缺一，它就只是 feature，不是 contribution。直觉上，**贡献原子 = 一句可证伪主张 + 一个最小机制改动 + 一个反事实效应 + 一个新颖性见证**。

**灵感 2（论文创新点 → 带宽受限的压缩）**
直觉：论文是一个带宽受限信道（页数、图数、实验预算固定）。创新点提炼 = 信源编码：在“主张保真度”约束下最小化“贡献数 × 证据成本”。因此正确目标不是“列全所有 IP”，而是求一个 **最小充分贡献集（MSCS）**：用最少的贡献覆盖所有头条主张。
一个反直觉推论：**删掉一个贡献后论文变好，说明它本来就不该在论文里**——它可能是实现细节、工程胶水，或与另一贡献共享同一份证据（冗余）。

**灵感 3（主线只取 64–66 轮）**
直觉：233 个 IP 横跨几何、接触、语义、规划、情绪，硬塞进一篇论文必然变成“大杂烩”。严谨做法是**显式缩范围**：本论文只主张 IP-204~233 的 GRIP→VISTA→RAS 主线；其余 IP 明确降级为附录、系统实现或未来工作。**不主张，才是最强的可辩护性。**

**灵感 4（提炼算子 PIE：Position∘Verify∘Compress∘Cluster）**
直觉：四步流水线——
- **Cluster**：按机制签名把 IP 聚类，而不是按名字聚类；
- **Compress**：证据 Jaccard 重叠 ≥ θ 的 IP 合并成一个贡献原子；
- **Verify**：做反事实消融（删掉它，哪个指标坏）与主张-证据对齐（每条主张至少两条独立证据）；
- **Position**：对 prior art 计算新颖性距离，并写出一条“对方推不出的性质”作为见证。
输出不是长清单，而是“**4 根柱子 + 一张对齐矩阵 + 一张攻击面表**”。

**灵感 5（从 233 个 IP 里冒出四根柱子）**
直觉：做完聚类后，主线的机制其实只剩四类替换：
- **CP-1 阶段化故障可归因**（替换“异常=故障”：用动作块三阶段创造可辨识性，只膨胀该膨胀的球）；
- **CP-2 长预测、短执行的可组合证书**（替换“每步独立安全”：把块承诺的风险压回单步）；
- **CP-3 意图可接入的风险自适应**（替换“人不在回路”：把情绪/意图作为新的故障维度 E，但设安全下界）；
- **CP-4 运行时证书链**（替换“离线证明”：把 J_grip→J_vista→J_RAS 做成可组合、可回放、可机器校验的运行时对象）。
问题重定义本身（“谁坏了、谁该控制、控制多少”）只作为 framing（CP-0），**不单列为创新**——否则会白送审稿人一个“novelty 注水”的把柄。

**灵感 6（自指检验：提炼结果也要被消融）**
直觉：如果换一次聚类阈值、换一个提取者，贡献集就变了，那它不可信。故引入**提炼稳定性**与**自指消融**：对提炼结果再跑一遍 PIE，若收敛到同一固定点，且删除任一贡献后至少一条头条主张不再被覆盖，则提炼通过；否则本轮产物应被判定为“叙事包装”，而不是科学贡献。

## 1. 形式化定义（增量：定义 251–264）

- **定义 251（贡献原子 CA）**：`CA = (c, m, Δ, a, w)`。`c` 是一句可判定真假的主张；`m` 是被替换旧假设的**最小结构改动**（机制签名）；`Δ` 是反事实消融效应向量；`a` 是证据锚点集合（定理/实验编号）；`w` 是新颖性见证（最近 prior art 及一条对方推不出的性质）。`CA` 可入论文 ⇔ `c` 可证伪 ∧ `∃i: |Δ_i| ≥ δ_abl` ∧ `w ≠ ∅`。
- **定义 252（机制签名与冗余度）**：`sig(ip) = (输入, 被替换的假设, 输出保证, 主要失效模式)`。冗余度 `red(ip_i, ip_j) = |E_i ∩ E_j| / |E_i ∪ E_j|`（证据集 Jaccard）；`red ≥ θ_red` 判为同一贡献，合并时保留更强的那个主张。
- **定义 253（反事实消融效应）**：`Δ_c = (M_{¬c} − M_{with}) / M_{with}`，逐头条指标计算（成功率、误降级率、违规率、审计时间）。贡献可辩护 ⇔ 至少一个头条指标 `|Δ| ≥ δ_abl`，且方向与该贡献的主张一致；若所有 `Δ≈0`，该贡献的**影子价格为零**，必须删除。
- **定义 254（新颖性距离与见证）**：在 `(problem, mechanism, guarantee)` 三维空间取语义嵌入 `φ(·)`，`d_novel(CA) = min_{p∈P} ‖φ(CA) − φ(p)‖`。要求 `d_novel > τ_novel`，且必须存在“差异见证”：明确指出 prior art **不能推出**的那条性质（通常是保证类型，如“归因定向膨胀”“意图噪声不放大风险”“证书可组合”）。
- **定义 255（主张-证据对齐矩阵）**：`A ∈ {0,1}^{|Q|×|E|}`，`A_{q,e}=1` 表示证据 `e` 支持主张 `q`。覆盖度 `cov(q) = Σ_e A_{q,e}`；**独立证据类型数** `ind(q)`（定理 / 仿真 / 真机 / 消融）须 `≥ 2`，否则标记为**脆弱主张**，不得写进 abstract 的强断言。
- **定义 256（最小充分贡献集 MSCS）**：给定候选贡献集 `C`、头条主张集 `Q`、证据预算 `B`：
  `S* = argmin_{S⊆C} |S|  s.t.  ∀q∈Q: cov(q,S)≥1  ∧  cost(S) ≤ B`。
  若允许“最大化覆盖”，该问题是最大覆盖（子模），贪心近似 `1−1/e`；若要求精确覆盖，退化为集合覆盖，贪心近似 `ln|Q|+1`。
- **定义 257（贡献影子价格）**：`σ_c = ∂(headline)/∂c`，即固定其余贡献时 `c` 的边际增益。**`σ_c ≈ 0` 的贡献应被删除**——这是“IP 通胀”的定量判据。
- **定义 258（提炼算子 PIE）**：`PIE = Position ∘ Verify ∘ Compress ∘ Cluster`，作用在 `(IP 集, 定理集, 实验集, prior art 集, 头条主张集 Q, 预算 B)` 上，输出 `(S, A, attack_map, stability)`。
- **定义 259（提炼保真度）**：`Fid(S) = (1/|Q|) Σ_q cover(q,S) · min(1, ind(q)/ind_target)`；要求 `Fid ≥ 1 − ε_fid`。注意：只覆盖不复现（例如只有仿真没有真机）会被 `ind` 项惩罚。
- **定义 260（提炼稳定性与固定点）**：对 `PIE` 输出 `S` 再跑 `PIE`，若 `PIE(S) = S`（等价类意义下）则称固定点；稳定性 `stab = E_perturb[ Jaccard(S, S_perturb) ]`，扰动包括聚类阈值、消融噪声、证据子采样。要求 `stab ≥ θ_stab`。
- **定义 261（审稿人攻击面）**：`A_attack(CA) = {(o_k, r_k)}`，`o_k` 是审稿人最可能提出的反对（如“conformal 交换性失效”“情绪识别不可靠”“证书组合会重复计风险”），`r_k` 是对应反驳或补充实验。每个贡献至少覆盖 **top-2 攻击**，否则视为“未准备好投稿”。
- **定义 262（论文贡献金字塔）**：`L0 问题重定义`（framing，不计创新）→ `L1 机制`（CP-1、CP-2）→ `L2 保证`（CP-3、CP-4）→ `L3 证据`（定理/实验/消融）。好的贡献集应每层都有柱子，避免“只有机制没有保证”或“只有保证没有证据”。
- **定义 263（范围界 Scope）**：`Scope = {IP-204,…,IP-233}`；显式列出**不属于本论文**的 IP 集合。任何主张不得引用 `Scope` 之外的证据，任何实验不得用 `Scope` 外组件“偷偷加分”。
- **定义 264（提炼证书 J_pie）**：`J_pie = (S, A, attack_map, stability, scope, novelty_witness, pid)`。`Valid(J_pie) ⇔ Fid(S) ≥ 1−ε_fid ∧ stab ≥ θ_stab ∧ (∀c∈S: |Δ_c|≥δ_abl ∧ d_novel≥τ_novel) ∧ attack_map 覆盖每根柱子的 top-2 攻击`。
  **重要边界**：`J_pie` 是**元证书**，它保证“论文主张可辩护”，**不保证系统安全**；系统安全仍由 `J_grip/J_vista/J_RAS` 负责。二者不可混用。

## 2. 关键算法骨架

```python
@dataclass
class ContributionAtom:
    claim: str                 # 可证伪的一句话主张
    mechanism: tuple           # (输入, 被替换假设, 输出保证, 失效模式)
    ablation: dict             # metric -> normalized delta
    evidence: set              # 定理/实验 id
    novelty_witness: str       # 最近 prior art + 对方推不出的性质

def mechanism_cluster(ips):
    # 按机制签名聚类，而不是按组件名聚类
    return cluster_by(ips, key=lambda ip: ip.signature)

def merge_redundant(cluster, theta_red=0.6):
    # 证据 Jaccard >= theta_red 的 IP 合并，保留更强主张与更全证据
    groups = union_find(cluster, lambda a, b: jaccard(a.evidence, b.evidence) >= theta_red)
    return [strongest_representative(g) for g in groups]

def counterfactual_ablation(atom, experiments):
    # 删掉机制后重跑每个头条指标，返回归一化效应
    return {m: (run_without(atom, m) - run_with(atom, m)) / run_with(atom, m)
            for m in HEADLINE_METRICS}

def align_claims(atom, theorems, experiments):
    # 主张 -> 证据矩阵；要求至少 2 类独立证据（定理/真机/消融）
    return {q: {e for e in theorems | experiments if supports(e, q)}
            for q in atom.claims}

def novelty_distance(atom, prior_art, tau_novel):
    p = nearest(atom, prior_art)
    d = embed_distance(atom, p)
    witness = diff_property(atom, p)       # 对方推不出的那条性质
    return d, p, witness

def greedy_min_sufficient(atoms, Q, budget):
    S, covered = [], set()
    while not covered.issuperset(Q):
        best = max(atoms, key=lambda a: marginal_coverage(a, covered) / a.cost)
        if best.cost + sum(a.cost for a in S) > budget:
            raise Infeasible("证据预算不足以覆盖全部头条主张")
        S.append(best); covered |= best.covers
    return S

def certify_pie(S, Q, n_perturb=32):
    stab = mean(jaccard_set(S, PIE_perturb(seed=i)) for i in range(n_perturb))
    # 自指消融：删任一柱子后是否仍覆盖全部主张
    for c in S:
        assert not covers_all(Q, S - {c}), "该柱子可删，非最小充分集"
    return J_pie(S, stab=stab, ...)

def PIE(ips, theorems, experiments, prior_art, Q, budget):
    clusters = mechanism_cluster(ips)
    atoms = [merge_redundant(c) for c in clusters]
    for a in atoms:
        a.ablation = counterfactual_ablation(a, experiments)
        a.evidence = align_claims(a, theorems, experiments)
        a.novelty = novelty_distance(a, prior_art, TAU_NOVEL)
    S = greedy_min_sufficient(atoms, Q, budget)
    return S, certify_pie(S, Q)
```

## 3. 推导

**引理 11（非冗余判据）** 若 `CA` 的消融效应 `|Δ_c| < δ_abl`，则删除它不改变任何头条指标，由 MSCS 的最小性，`CA ∉ S*`。等价地：**可入论文的贡献必有正影子价格**。这条引理把“创新点”从主观命名变成可测的量。

**引理 12（四根柱子的必要性）** 设 `Q = {Q1 归因正确, Q2 前缀安全, Q3 意图不越界, Q4 证书可审计}`。若 `S ⊂ {CP-1..CP-4}`，则至少存在一个 `Q_i` 不被覆盖（`Fid(S) < 1`）。故在不引入新证据的前提下，**删除任一柱子都必然损失一条头条主张**——四根柱子是当前证据预算下的最小充分集，而非“想讲四个故事”。

**定理 11（MSCS 的近似最优性）** 覆盖函数 `cover(·,·)` 单调子模，故预算约束下的贪心选择达到最优覆盖的 `(1−1/e)`；若要求精确覆盖，集合覆盖贪心达到 `ln|Q|+1`。因此 PIE 输出的四点贡献集在理论上**接近最小可辩护集**，而不是随意膨胀的 feature 清单。

**定理 12（主张-证据对齐的可靠性）** 若每条头条主张有 `k` 条独立证据通道，单通道失效概率 `≤ p_e`，则 `P(主张无支撑却通过评审) ≤ p_e^k`。取 `k=2, p_e=0.2`，上界约 `4%`。这解释了为何本论文要求“每条强主张 = 一条定理 + 一台真机/消融”，而弱主张只能放 limitations。

**定理 13（提炼稳定性 ⇒ 可复现贡献集）** 若在聚类阈值/消融噪声/证据子采样的扰动下 `stab ≥ θ_stab`，且对 `S` 的任一真子集都存在至少一条主张不被覆盖，则 `S` 是一个稳定的最小充分贡献集；此时换一位提取者重跑 PIE，仍会收敛到同一等价类。**稳定性是提炼可证伪性的操作化定义。**

## 4. 复杂度分析

| 阶段 | 时间 | 空间 | 说明 |
|---|---|---|---|
| 机制聚类 | `O(|IP|·d)` | `O(|IP|·d)` | `|IP|=233`，`d` 为签名维数，可忽略 |
| 冗余合并 | `O(|C|²·|E|)` | `O(|C|²)` | 候选贡献 `|C|≤12` |
| 反事实消融 | `O(|C|·|M|·T_exp)` | `O(|C|·|M|)` | **真正昂贵的是 T_exp（重跑实验）**，不是算法 |
| 新颖性定位 | `O(|C|·|P|)` | `O(|P|)` | 可用向量检索 |
| MSCS 贪心 | `O(|C|²·|Q|)` | `O(|C|)` | `|Q|≤6`，精确枚举 `2^12` 也可 |
| 稳定性复核 | `O(n_perturb·|C|²)` | `O(|C|)` | `n_perturb=32` |

**结论**：提炼的算法成本可忽略，**真正的预算是重跑消融实验的证据成本**。因此 PIE 的瓶颈不在算力，而在“你愿不愿意为每根柱子做一次单点消融”。

## 5. 实验设计 E251–E260（元实验 / 方法论实验）

| 实验 | 核心问题 | 关键目标 |
|---|---|---|
| E251 机制聚类稳定性 | 按签名聚类是否比按名字更稳 | 跨 3 位标注者 Jaccard ≥ 0.85 |
| E252 反事实消融显著性 | 每根柱子是否真有正效应 | 至少 1 个头条指标 \|Δ\| ≥ 0.15 |
| E253 冗余合并准确率 | 合并是否误伤独立贡献 | 误合并率 ≤ 5%，漏合并率 ≤ 10% |
| E254 MSCS 覆盖-成本曲线 | 4 根是否最小充分 | 删任一柱覆盖 < 100%，加第 5 柱边际 < 2% |
| E255 新颖性定位 | `d_novel` 是否与人类评审一致 | 与 5 位领域评审排序 Spearman ≥ 0.7 |
| E256 主张-证据独立通道 | 每条强主张是否有 ≥2 类证据 | 脆弱主张 = 0（否则降级措辞） |
| E257 审稿人攻击面覆盖 | top-2 攻击是否都有反驳 | 覆盖率 100%，反驳有实验/定理支撑 |
| E258 提炼稳定性 | 32 次扰动下贡献集是否稳定 | `stab ≥ 0.9` |
| E259 清单 vs 柱子（模拟评审） | 全 IP 清单与 4 点贡献谁更易过 | 4 点方案 novelty/clarity 评分 ≥ 全清单 |
| E260 自指消融 | 删一柱后核心主张是否塌 | 4/4 柱子删除后均至少 1 主张失覆盖 |

**推演结果（非真实实验，仅结构化推演）**：在 `|IP|=233, |C|=12, |Q|=6` 的设定下，PIE 预计输出 `S={CP-1,CP-2,CP-3,CP-4}`；冗余合并会把“多模态不确定性校准”“主动判别探针 AFA”“共因故障建模”分别并入 CP-1/CP-2/CP-3；影子价格预计 CP-1≈0.34、CP-2≈0.29、CP-3≈0.22、CP-4≈0.15。**CP-3 影子价格最低，是本论文最脆弱的一根柱子**（见第 6 节）。

## 6. 本轮最大风险

**一句话**：PIE 可能沦为“事后合理化”——把 233 个 IP 压成 4 根柱子，如果这些柱子在反事实消融下并不独立（删掉任一柱，其余三根仍能拼出同样结论，或四根共享同一批实验），那么“创新点”只是工程集成的包装，论文会在审稿人要求“逐点单点消融”时整篇崩塌；更尖锐地说，**本轮最大的风险不是提炼得不够多，而是提炼出的四根柱子可能只是同一个贡献的四种说法**。

# 第 67 轮产物 · 论文创新点清单 v4：从「IP 通胀」到「贡献收敛」——GRIP→VISTA→RAS 的四点论文贡献集（CP-1~CP-4）

> 本轮**不再新增系统 IP**（IP 编号封版于 IP-233；此后新增必须证明其影子价格 `σ>0`）。产物不是又一张功能清单，而是一篇论文的**最小充分贡献集**：4 根柱子、1 张主张-证据矩阵、1 张新颖性定位表、1 张审稿人攻击面表、1 份范围声明、1 份“明确不主张”的边界清单。

> 元命题：**论文的承载力是 O(1)，IP 的产出是 O(n)。创新点提炼 = 在保真度约束下把 O(n) 压回 O(1)，并让每一根柱子都能被单点消融。**

## 0. 论文元信息

- **工作标题**：《可归因、可协商、可审计：人机协作机器人的运行时安全证书链》
- **English**：*Attributable, Negotiable, Auditable: A Runtime Safety Certificate Chain for Human–Robot Collaboration*
- **一句话主张**：把机器人安全从“离线证明 / 在线检测”升级为“运行时可归因、可协商、可审计的证书对象”。
- **范围 `Scope`**：仅 IP-204~233（GRIP→VISTA→RAS 主线）。其余 200+ IP（语义、规划、多机、强化学习等）显式降级为附录、系统实现或未来工作，**不得作为本文证据**。
- **贡献金字塔**：`L0` 问题重定义（CP-0，不计创新）→ `L1` 机制（CP-1、CP-2）→ `L2` 保证（CP-3、CP-4）→ `L3` 证据（定理 7–13 / E231–E260 / 单点消融）。

## 2. 四根柱子的展开

### CP-1 阶段化故障可归因（Staged Fault Attribution, SFA）

- **主张**：在零力接近 / 轻触 / 承载三阶段上采集残差签名，可把“几何幻觉 / 力偏置 / 接触模型错”从“一个不可辨识的大残差”分离为近似正交的故障列；归因后只膨胀对应球，而非总膨胀几何球。
- **最小机制**：`ρ = [ρ_approach, ρ_touch, ρ_load] ∈ ℝ^{15}`；`P(H|ρ) ∝ p(ρ|H)P(H)`；可辨识裕度 `κ_fi = λ_min(SᵀΣ⁻¹S)/λ_max(SᵀΣ⁻¹S)`。
- **与 SOTA 的差异见证**：经典 FDI 用单时刻残差，CBF/安全滤波把所有不确定性塞进一个球，conformal 只给上界不做归因。**它们都推不出“只膨胀被归因的那个球”这条性质**。
- **证据**：引理 7（三阶段可辨识性）、定理 7（端到端归因-安全）、E232/E233/E238。
- **审稿人最可能攻击**：①“阶段划分只是特征工程”→ 回应：给出 `S` 的条件数下降 ≥5× 的消融；②“故障注入是合成的”→ 回应：真实标定 + 未知故障召回率。

### CP-2 长预测、短执行的可组合证书（Long-Horizon, Short-Prefix Certificate, LSC）

- **主张**：把预测视界 `H` 与执行前缀 `k` 解耦，用块级 conformal 选 `k* ≤ m`（不可逆视界），则单块越界概率 `≤ α_chunk + δ_fi (+ α_emotion)`；块承诺不引入超出单步安全的新风险。
- **最小机制**：`k* = csc.certified_prefix(A, post, m, α_chunk)`；执行 `k*` 步即强制重规划与再归因。
- **与 SOTA 的差异见证**：ACT/扩散策略优化任务成功率而不给安全预算；逐点安全滤波不推理“块承诺”。**它们推不出“长视界只用于前瞻、短前缀用于安全承诺”的近最优性**。
- **证据**：引理 8（认证前缀执行安全）、定理 8（`H/k` 解耦近最优性）、E236/E237。
- **审稿人最可能攻击**：①“conformal 的交换性在分布漂移下失效”→ 回应：按阶段分层 conformal + AIC 最坏包络；②“`m` 怎么定”→ 回应：给出基于执行器/环境的不可逆视界标定流程。

### CP-3 意图可接入的风险自适应（Intent-Admissible Risk-Adaptive Closure, IRAC）

- **主张**：把人类情绪/意图作为新的**可观测故障维度** `E={E0..E3}` 接入联合后验，并用带下界的 `λ_risk` 缩放控制；意图观测噪声只能**收紧**容差，不能把真实故障“放开”到不安全。
- **最小机制**：`λ_risk = 1 − α·R_emotion − β·H_face`，`λ_risk ≥ 0.6`；`face_unobservable ⇒ HIGH_RISK` 且不降极处置；`C-RAS` 前缀同时满足 VISTA 与情绪容差。
- **与 SOTA 的差异见证**：情感计算只做情绪识别、不接认证控制；共享自治把人类输入当命令、而非带故障模式的噪声假设。**它们推不出“意图噪声不放大端到端风险”这条安全性质**。
- **证据**：定理 9（RAS 端到端风险一致性）、定理 10（联合可分离性）、E244/E247/E250。
- **审稿人最可能攻击**：①“情绪识别不可靠，凭什么接安全回路”→ 回应：它是附加证据通道，不是唯一权威；不可观测即保守；可一键 opt-out；②“伦理上不能用表情替代用户同意”→ 回应：明确写入 limitations，只用于风险**收紧**，不用于授权动作。

### CP-4 运行时证书链（Runtime Certificate Chain, RCC）

- **主张**：把 GRIP→VISTA→RAS 的安全条件统一为可组合的运行时证书对象 `J = (J_grip, J_vista, J_RAS)`，给出组合规则与机器可校验的 `Valid(·)` 谓词，使安全**可审计、可回放、可事后归因**。
- **最小机制**：证书哈希链 `J_RAS = (J_vista, λ_risk, fault_emotion_posterior, face_quality, expression_hash, aic_ras_ver)`；`Valid(J_RAS) ⇔ Valid(J_vista) ∧ λ_risk≥0.6 ∧ …`；组合时按不相交预算做并集界。
- **与 SOTA 的差异见证**：运行时验证（RV）检查性质但不携带归因信息；离线安全证明不可在线回放。**它们推不出“证书既承载安全条件、又承载故障归因、还可组合”这条性质**。
- **证据**：定理 7/9 的组合、定理 12（证据对齐可靠性）、E247/E250 + 证书回放审计。
- **审稿人最可能攻击**：①“证书组合会重复计或漏计风险”→ 回应：显式不相交预算 + 并集界 + 独立证据假设；②“工程系统如何保证哈希链不丢帧”→ 回应：语义流低频写入 + 实时流零学习写操作。

## 3. 新颖性定位表（vs SOTA）

| 对照方法族 | 他们能做到 | 他们做不到（我们的差异见证） |
|---|---|---|
| CBF / 安全滤波 | 单步硬约束、可证明前向不变性 | 不做故障归因；不确定性只能塞进一个球，导致全膨胀；不推理块承诺 |
| Conformal Prediction | 分布无关的覆盖率上界 | 只给“多少”，不给“哪里坏了”；不把覆盖预算分配到多假设归因 |
| 经典 FDI / 故障诊断 | 检测+隔离已知故障 | 依赖单时刻残差，几何/力/模型常不可辨识；不做“定向膨胀”与安全前缀联动 |
| 动作分块（ACT / 扩散策略） | 长视界、低方差、任务成功率高 | 无安全前缀的概念；块承诺越界风险未被认证 |
| 情感计算 / 共享自治 | 情绪识别、意图推断、人机协商 | 情绪不接认证控制；人类输入被当命令而非带故障模式的噪声假设；无安全下界 |
| 运行时验证（RV） | 在线检查时序性质、报警 | 证书不含归因；不可组合；不可回放审计；不闭环到控制降级 |

## 4. 主张-证据对齐矩阵（`A`）

头条主张 `Q`：
- `Q1` 故障可被分离归因（而非只检出）
- `Q2` 块承诺不引入超出单步的新风险
- `Q3` 意图噪声不放大端到端风险
- `Q4` 安全证书可组合、可审计、可回放
- `Q5` 三阶段确实提供可辨识性（机制层）

## 5. 最小充分贡献集（MSCS）推导

**候选池**（PIE 聚类 + 合并后，`|C|=12` 压到 6）：
1. CP-1 阶段化故障可归因
2. CP-2 长预测短执行证书
3. CP-3 意图可接入风险自适应
4. CP-4 运行时证书链
5. `C5` 多模态不确定性校准（证据 Jaccard 与 CP-1/CP-3 均 ≥0.6，**合并**）
6. `C6` 主动判别探针 AFA（主要服务 CP-1 的归因与 CP-2 的早停，**合并**）

**贪心选择结果**：`S* = {CP-1, CP-2, CP-3, CP-4}`，覆盖 `Q1–Q6`。

**删柱检验（引理 12 实例化）**：
- 删 CP-1：`Q1、Q5` 失覆盖（无法说明“为什么只膨胀对的球”）。
- 删 CP-2：`Q2` 失覆盖（块承诺风险无界）。
- 删 CP-3：`Q3` 失覆盖（意图维度缺席）。
- 删 CP-4：`Q4` 失覆盖（证书不可组合/不可审计）。

**加第 5 柱的边际**：预计新增覆盖 <2%，但会增加 1 组真机实验与 2 页篇幅 ⇒ 不满足预算，故拒绝。**这正是用 MSCS 抵抗“再加一个模块”的诱惑。**

**影子价格（推演）**：`σ(CP-1)≈0.34`、`σ(CP-2)≈0.29`、`σ(CP-3)≈0.22`、`σ(CP-4)≈0.15`。四者均 `>0`，故全部保留；但 CP-3 的措辞强度应与其影子价格成比例。

## 8. 明确不主张的内容（Scope discipline）

为提高可辩护性，本文**主动放弃**以下主张：
1. 不主张情绪识别精度 SOTA（只把它当成噪声可建模的观测通道）。
2. 不主张覆盖全部 233 个 IP；只主张 IP-204~233 主线。
3. 不主张开放世界中任意未知复合故障都安全（只主张有限假设集 + ambiguous 时保守降级）。
4. 不主张情绪/意图可以替代用户知情同意或成为动作授权的唯一依据。
5. 不主张在所有嵌入式硬件上满足实时性（只给出 `≤2.5ms` 的目标与平台约束）。
6. 不主张“归因永远正确”（只主张归因错误时系统仍安全降级，即 Q6）。

## 10. 本轮最大风险

**一句话**：PIE 可能沦为“事后合理化”——把 233 个 IP 压成 4 根柱子，如果这些柱子在反事实消融下并不独立（删掉任一柱，其余三根仍能拼出同样结论，或四根共享同一批实验），那么“创新点”只是工程集成的包装，论文会在审稿人要求“逐点单点消融”时整篇崩塌；更尖锐地说，**本轮最大的风险不是提炼得不够多，而是提炼出的四根柱子可能只是同一个贡献的四种说法**。
