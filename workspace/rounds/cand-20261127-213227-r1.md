### 第 4 轮（新灵感循环第 1 轮；本轮灵感：「双臂协调」×「联邦学习」）

**继承关系**：第 3 轮 CADVS-v3（IP-485~488）在 v2 三锚点（3DCF/MSRG/HICK）上追加末端保真锚 EEK（EEC/kc_ee）与长期记忆锚 LTEM（kc_mem），并用联邦证书聚合器 FFA 做舰队级校准，形成五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem，执行集 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。v3 的最大风险是联邦聚合成为跨站伪神谕（非IID 坍塌 + 站点毒化）。本轮不推翻 v3，而是把「单臂末端锚」升级为「双臂耦合锚」、把「平均式 FFA」升级为「鲁棒、个性化、本地可否决的联邦协调先验 FCP」，形成 CADVS-v4（IP-489~492），执行集嵌套升级为 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **双臂协调：从「每只手都合格」到「这一对作为整体是否合格」**。v3 的 kc_ee 是逐末端的合取：左臂在容差内、右臂在容差内，就认为末点证据成立。但双臂操作是一个闭链/耦合系统：两臂绝对位姿都在容差内，相对位姿却可能已经把物体撕开；两臂力控各自稳定，闭链内力却低于摩擦锥所需，物体正在缓慢滑移；两臂各自时间戳都“新鲜”，但相差 20 ms，在高速段相对位姿已经漂出安全包络。逐臂证书的合取不等于整体证书，因为双臂的失败模式是相关的、相对的、由闭链约束产生的。引入双臂耦合证书 DCC：相对位姿误差 ξ_rel、抓取矩阵 G 的内力分解 λ、摩擦锥余量 m_fric、双臂同步偏差 Δt，以及单臂失效时的耦合安全回退。把 kc_ee 升级为 kc_ee^pair = kc_ee^L ∧ kc_ee^R ∧ kc_relpose ∧ kc_force ∧ kc_internal ∧ kc_sync。

2. **联邦学习：从「平均一个全局先验」到「鲁棒个性化 + 本地终审」**。v3 的 FFA 用 FedAvg 求一个全局先验 Φ_global，其最大风险正是非IID 坍塌与站点毒化。双臂协调让这个问题更尖锐：不同机器人型号、夹爪、物体类别所需的相对位姿容差、内力上下界、同步预算本质不同，平均会得到「对谁都不成立」的先验；更糟的是，双臂的耦合统计（相对位姿误差协方差、内力—摩擦余量联合分布、左右臂失败相关性）一旦被逐臂独立平均，就会被抹平成边际分布，恰好丢掉最该保留的尾部相关风险。本轮把 FFA 升级为联邦协调先验 FCP：(a) 只传耦合充分统计量（协方差/分位数/失败签名/同步偏差直方图），不传原始位姿、力序列或图像；(b) 分层个性化——全局只学「包络形状与归一化分位」，每站保留本地仿射头 θ_i；(c) Byzantine 鲁棒聚合（坐标截尾均值/几何中位数）限制毒化；(d) 本地否决权——全局先验只是提案，必须在站点留出校准集上通过本地一致性/安全校验 kc_fed_local^i 才被采纳，否则回退 v3 单机先验。核心原则：**联邦只提供先验，不提供终审权**。

3. **两者结合：耦合证据的联邦校准，而不是把耦合拆开平均**。双臂失败是相关失效：左右臂误差同向、物体几何导致的内力偏差、同步漂移、单臂打滑后另一臂继续拉拽。若联邦把左右臂当独立样本，就会系统性低估相关尾部风险；若把不同域站点强行平均，就会用「平均证书」覆盖「局部不安全」。FCP 因此聚合的是协方差/分位/失败签名等耦合统计，并用配对上下文指纹做域聚类，只在可比域内聚合；配对记忆 LTEM 也升级为 pair-level（PEM），记录「哪一臂是主因、失败模式、恢复策略」，并通过 DP 草图跨站预警，但本地记忆仍有终审权。

**关键洞见**：v3 把安全从「证据在哪」推进到「末点接触是否真实」；v4 指出「两个都真实的末点仍可能组成一个不真实的整体」。双臂协调要求证书从逐臂合取升级为闭链耦合；联邦学习则从「平均一个全局神谕」升级为「鲁棒、个性化、可本地否决的耦合先验」。五硬门结构保持不变，但 kc_ee 与 kc_mem 升级为 pair 版本，FFA 升级为 FCP；Exec_v4 ⊆ Exec_v3。

**形式化目标（增量）**：
1. 定义双臂耦合证书 DCC = (T_L, T_R, T_des, ξ_rel, G, w_L, w_R, λ, m_fric, Δt, slip_pair, t)，及耦合门 kc_dual = kc_relpose ∧ kc_force ∧ kc_internal ∧ kc_sync。
2. 定义 kc_ee^pair = kc_ee^L ∧ kc_ee^R ∧ kc_dual；配对记忆 kc_mem^pair = kc_mem ∧ kc_pairmem（kc_mem 为 v3 记忆门）。
3. 定义联邦协调先验 FCP：本地耦合充分统计 Δ_i^pair → 归一化/裁剪 → (ε,δ)-DP + 安全聚合 → Byzantine 鲁棒聚合 → 分层个性化 (Φ_g, θ_i)；本地一致性门 kc_fed_local^i 决定是否采纳 Φ_g，否则回退 v3 先验。
4. 定义 v4 五硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee^pair ∧ kc_mem^pair；软评分 ECS_v4 = ECS_v3 · η_pair，η_pair ∈ [0,1] 为配对历史置信度。
5. 定义 Exec_CADVS-v4 ⊆ Exec_CADVS-v3：kc_ee^pair ⇒ kc_ee^L ∧ kc_ee^R，kc_mem^pair ⇒ kc_mem，且 kc_fed_local 失败时回退而非放宽。

**本轮最大风险**：**双臂耦合证书与联邦协调先验都把安全押在「跨臂相关统计」上**——一旦相对位姿/内力/同步的耦合统计被错误的域聚类、非IID 偏差或毒化污染，系统会以「两臂各自合格、全局先验也通过」的双重表象，执行一个整体上撕裂/压碎物体的决定；这是比 v3 单臂伪神谕更隐蔽的相关性失效。

### IP-489 DCCK：双臂耦合证书（控制环内，O(1)）

```python
@dataclass
class DualArmCouplingKernel:
    """DCCK：双臂闭链耦合校验；kc_dual 硬门，每控制周期 O(1)"""
    delta_rel: float = 0.010       # m（归一化 twist），相对位姿容忍（FCP 先验给初值，本地校准覆盖）
    lambda_min: float = 8.0        # N，内力下界（防滑）
    lambda_max: float = 30.0       # N，内力上界（防压碎）
    mu_fric: float = 0.5           # 摩擦系数（物体类先验）
    m_fric_min: float = 0.5        # N，摩擦锥最小余量
    dt_max: float = 0.002          # s，双臂同步偏差上界
    v_rel_max: float = 0.5         # m/s，相对速度上界
    f_max_contact: float = 40.0    # N，单接触法向力上限
    sigma_rel: np.ndarray = None   # 6x6，FCP 提供的相对位姿误差协方差

    def observe(self, T_L, T_R, T_des, w_L, w_R, G,
                t_L, t_R, t_L_cmd, t_R_cmd, t_now) -> DCC:
        xi_rel = log_se3(inv(T_des) @ inv(T_L) @ T_R)
        w = np.concatenate([w_L, w_R])
        G_pinv = np.linalg.pinv(G)
        w_int = (np.eye(12) - G_pinv @ G) @ w
        B_int = null_space(G)                 # 12 x d_int，离线按抓取构型缓存
        lam = B_int.T @ w_int
        m_fric = min(mu_fric * fn - np.linalg.norm(ft)
                     for fn, ft in contact_forces(w_L, w_R))
        dt = max(abs(t_L - t_R), abs(t_L_cmd - t_R_cmd))
        slip_pair = int(any_contact_slip(w_L, w_R, mu_fric))
        return DCC(T_L, T_R, T_des, xi_rel, G, w_L, w_R, lam,
                   m_fric, dt, slip_pair, t_now)

    def kc_relpose(self, dcc) -> bool:
        delta_eff = self.delta_rel - self.v_rel_max * self.dt_max
        if delta_eff <= 0:
            return False                       # 同步预算吃光几何预算：fail-closed
        return np.linalg.norm(dcc.xi_rel) <= delta_eff

    def kc_force(self, dcc) -> bool:
        return dcc.m_fric >= self.m_fric_min and all_contact_normal_below(dcc, self.f_max_contact)

    def kc_internal(self, dcc) -> bool:
        return np.all(dcc.lam >= self.lambda_min) and np.all(dcc.lam <= self.lambda_max)

    def kc_sync(self, dcc) -> bool:
        return dcc.dt <= self.dt_max

    def kc_dual(self, dcc) -> bool:
        return (self.kc_relpose(dcc) and self.kc_force(dcc)
                and self.kc_internal(dcc) and self.kc_sync(dcc))

    def coupled_fallback(self, dcc, failed_arm: str) -> FallbackPlan:
        """单臂失效：健康臂保持/微调力，失效臂转柔顺保持或受控释放；
        返回带 kc_fallback 证书的计划（对象加速度、内力衰减率、扫掠体积、力矩上限）"""

### IP-491 FCP：联邦协调先验（异步、慢时域，不在控制环）

    def local_conformance(self, phi_i: dict, calib: CalibrationSet) -> tuple[bool, str]:

        ...

        """返回各站最终先验：kc_fed_local 通过则采纳 Phi_i，否则回退 v3 本地先验并记异常"""
        ...
```

### IP-492 EFA-v4：五硬门（pair 升级）+ 软评分 + 证据铸造流水线 v4

```python
@dataclass
class EvidenceForgingAssemblerV4:
    """EFA-v4：五硬门 fail-closed；kc_ee 与 kc_mem 升级为 pair 版本"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    dcck: DualArmCouplingKernel
    pem: PairEpisodicMemory
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec_L, eec_R, dcc, ctx_pair):
        if self.hic.veto_active(hic):                 return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):        return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not (self.eek.kc_ee(eec_L) and self.eek.kc_ee(eec_R)):
            return False, 'EE_UNPROVEN'
        if not self.dcck.kc_dual(dcc):
            return False, 'DUAL_UNPROVEN'
        pass_mem, eta_pair, novelty, forced = self.pem.query(ctx_pair, t_now)
        if not pass_mem:                              return False, 'PAIR_MEMORY_REJECT'
        if forced is not None:                        return True, 'FORGED|FORCE_' + forced
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v4(self, x, t_now, rule_id, A_att=0.0, eta_pair=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        return base * eta_pair
```

## 4. 正确性论证（增量更新）

### 引理 41（相对位姿与同步的耦合保真界）

**陈述**：设左/右臂各自绝对位姿误差满足 d_SE3(T_a^m, T_a^d) ≤ δ_abs，测量相对变换 T_rel^m = (T_L^m)^{-1} T_R^m，期望 T_des，ξ_rel = log(T_des^{-1} T_rel^m)。若 d_SE3(T_des, T_rel^m) ≤ δ_rel，则两接触点在物体坐标系下的配准误差 ≤ δ_abs^L + δ_abs^R + δ_rel（左不变度量下的三角不等式）。进一步，若真实滑移/撕裂使两接触点间距变化 s > δ_rel + δ_abs^L + δ_abs^R，则 kc_relpose 必失败或至少一个 kc_ee^a 失败；因此 kc_ee^pair 不会放行该事件。若两臂时钟偏差 Δt、相对速度上界 v_rel_max，则同一物理时刻的相对位姿漂移 ≤ v_rel_max·Δt + O(Δt²)；kc_sync 要求 Δt ≤ Δt_max，且 kc_relpose 使用 δ_rel^eff = δ_rel − v_rel_max·Δt_max，从而把同步误差计入预算而不破坏上述界。

**证明**：在 SE(3) 左不变度量下对 T_L^{-1}T_R = (T_L^{-1}T_L^d)(T_L^d)^{-1}T_R^d(T_R^d)^{-1}T_R 逐项三角不等式；log 映射在 δ 邻域内 Lipschitz；两接触点配准误差由两臂绝对误差与相对误差线性控制；同步项由相对运动学积分给出。∎

**工程含义**：逐臂绝对门看不见「两臂各自合格但相对关系已坏」的失效；相对门与同步预算把这类相关失效纳入硬门。

### 引理 42（内力/摩擦锥的闭链保持界）

**陈述**：设抓取矩阵 G 行满秩，接触 wrench w = G^+ w_o + B_int λ，B_int 为 N(G) 的正交基。若摩擦锥余量 m_fric ≥ m_fric_min > 0，且 λ ∈ [λ_min, λ_max]，则对任意满足 ‖w_ext‖ ≤ w_max 的外部 wrench，存在接触力修正 δw 使 G(w+δw) = w_o + w_ext、δw 落在摩擦锥内且执行器力矩不超限；物体法向应力 ≤ σ_max(λ_max)。反之，若 λ < λ_min，则存在由重力/惯性产生的外部 wrench 使接触点滑移；若 λ > λ_max，则可能超过物体压碎阈值。

**证明**：摩擦锥是凸锥，力闭合条件保证存在锥内解；内力位于 G 的零空间，只改变法向/挤压分量而不改变净物体 wrench，因此可在不破坏 w_o 的前提下把接触力推入锥内并留出余量；λ 的上下界分别由最坏外部 wrench 与材料强度反解得到。∎

**工程含义**：v3 只检查「末端接触是否真实」，v4 进一步检查「这对接触是否形成可承受外扰的闭链」，把「没打滑」升级为「有足够内力且不压碎」。

### 引理 43（联邦协调先验的鲁棒性、个性化与本地否决）

**陈述**：设 n 个站点，其中至多 q 个 Byzantine，鲁棒聚合器的 breakdown point > q/n，DP 噪声 σ，站点本地一致性检验在留出校准集上的假接受率 ≤ α_c（以置信度 1−β_c）。则：
(a) 全局先验误差满足 ‖Φ_g − Φ*‖ ≤ B_robust(q, n, σ) + B_bias(cluster)，其中 B_robust 随 q/n 与 σ 增大，B_bias 随域聚类纯度提高而减小；
(b) 任一诚实站点采纳 Φ_g 后，在留出集上的假接受率 ≤ α_c；对同分布新样本，以概率 ≥ 1−β_c 假接受率 ≤ α_c + ε_cal(n_cal)（DKW/Hoeffding 集中项）；
(c) 若 Φ_g 被毒化为对抗先验，诚实站点以概率 ≥ 1−α_c 拒绝它，因而不会在本地安全包络之外执行；
(d) 个性化先验误差 ≤ α‖Φ_g − θ*‖ + (1−α)‖θ_i − θ*‖，α 由本地留出集选择。

**证明**：(a) 鲁棒统计的 breakdown point 与 DP 高斯机制标准界；(b) 留出集上的经验风险集中；(c) 本地一致性门是采纳的必要条件，故对抗先验只能以 ≤ α_c 的概率通过；(d) 凸组合的三角不等式。∎

**工程含义**：v3 的 FedAvg 把「全局先验」当成终审；v4 把全局先验降级为提案，本地一致性门保留终审权。即使联邦被毒化，诚实站点也不会被强制放宽本地安全包络。

### 引理 44（配对记忆的重复失败界与归因）

**陈述**：设配对上下文 ctx_pair 的真实成功率为 p_s，失败模式 m 的条件概率为 p_m。PEM 在 n 次观测后，若配对失败率 > 1−γ_pair 则拒绝；若某失败模式占比 > 1−γ_mode 则强制对应恢复策略。则 (a) 真实 p_s < γ_pair 的上下文以指数概率被拒绝；(b) 冷启动放行 + novelty，进入教师观察；(c) 通过反事实单臂回放，主因臂归因错误率 ≤ ε_attr（由单臂混淆矩阵决定）；(d) 带时效衰减 τ_pair 与 s2rc_fp 失效的条目不会无限期污染。

**证明**：经验失败率对真实失败率的 Hoeffding 集中；归因由单臂回放的混淆矩阵控制；指数衰减使过时证据的权重随时间下降；s2rc_fp 变化即失效旧条目。∎

**工程含义**：配对记忆不只记「失败过」，还记「哪种失败、哪一臂主因、该用哪种恢复」，把 v3 的单臂重复失败界升级为配对相关失败界。

### 定理 v4（执行集收缩、双臂耦合补全与联邦本地终审）

**陈述**：在以下假设下：(B1) 末端/相对位姿/力/触觉传感器噪声模型成立；(B2) PEM 忠实反映配对历史；(B3) FCP 的本地一致性检验有足够代表性与功效；(B4) 鲁棒聚合的 Byzantine 比例低于 breakdown point；(B5) 继承 v3 的 (A1′)~(A3′)。则：
(i) Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29（严格收缩，当 kc_dual 拒绝 v3 逐臂门放行的耦合失效时）；
(ii) 相对滑移/撕裂误放行由引理 41 界；
(iii) 低/高内力误放行由引理 42 界；
(iv) 配对重复失败由引理 44 指数衰减；
(v) 联邦先验不能放宽本地安全包络：诚实站点即使收到毒化 Φ_g，本地假接受率仍受 kc_fed_local 的 α_c 约束（引理 43）；
(vi) 五硬门 fail-closed；任一失败路由到配对安全回退 S_stop^pair 或教师，而非继续执行。

**证明**：(i) 由 kc_ee^pair ⇒ kc_ee^L ∧ kc_ee^R 与 kc_mem^pair ⇒ kc_mem，v4 在 v3 每条路径上只追加约束；严格性由 v3 未检查的相对位姿/内力/同步失效处关闭路径保证。(ii)~(v) 分由引理 41、42、43、44。(vi) 由 EFA-v4 hard_gate 的合取结构与失败路由表。∎

**诚实声明**：(B3) 是本轮最脆弱假设——本地一致性检验依赖一个有代表性的留出校准集；若该集合本身有偏、被污染或与部署分布漂移，本地否决权会被「合法地」骗过。其次，相对位姿在接触/遮挡下估计困难，G 的在线辨识误差会传播到内力分解。缓解：多模态相对位姿（视觉 + 本体 + 触觉）、G 的在线辨识与保守余量、校准集漂移检测、高风险规则保留人审。

| R49 | **联邦域聚类错误/非IID 坍塌**（把不可比站点聚在一起，或聚类过细导致样本不足） | **极高** | 配对上下文指纹聚类 + 聚类置信度；个性化头；聚类不确定时退回本地先验；定期实机回灌 | 聚类边界模糊时全局先验质量下降 |
| R50 | **毒化 + 鲁棒聚合失效**（Byzantine 比例超过 breakdown point，或毒化模仿正常分布） | **极高** | 截尾/几何中位数；DP 限制单站影响；本地一致性否决；高风险规则保留 HICK 人审 | 过半毒化或隐蔽毒化仍可能污染全局提案 |
| R51 | **本地校准集污染/漂移**（本地否决权被有偏/被污染的留出集“合法”骗过） | **极高** | 校准集来源审计；漂移检测；多来源交叉校验；安全下界不依赖单一校准集；高风险规则人审 | 校准集与部署分布共同漂移时，本地终审也可能失效 |
| R52 | **耦合回退本身不安全**（健康臂单独承力超限、脆弱物体被捏碎、释放路径有碰撞） | 高 | 预计算 kc_fallback 证书；力速率限制；扫掠体积检查；投放区确认；HIC veto | 极端构型下无可行回退，只能急停 |
| R53 | **隐私—效用权衡**（DP 噪声淹没小量程耦合统计） | 中 | 物理量程归一化后再 DP；自适应 ε；安全聚合；本地保留高精度先验 | ε 过小效用差，ε 过大隐私弱 |

## 7. 本轮最大风险（最终确认）

**一句话**：**双臂耦合证书与联邦协调先验都把安全押在「跨臂相关统计」上**——一旦相对位姿/内力/同步的耦合统计被错误的域聚类、非IID 偏差或毒化污染，系统会以「两臂各自合格、全局先验也通过」的双重表象，执行一个整体上撕裂/压碎物体的决定；这是比 v3 单臂伪神谕更隐蔽的相关性失效。
