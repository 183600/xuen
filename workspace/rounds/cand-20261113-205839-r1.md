>
> 本轮两个灵感恰好是两把拆闭环的刀：
> - **竞品分析**不是列功能表，而是**等预算下的替代性分析**：在相同算力/时延/数据/调参预算下，一个只有几行的保守基线，会不会在安全尾部上打赢这套十层黑箱？「竞品」还必须包含一个**专门刷我们榜的对手**和一个**保守 oracle 下界**。
> - **评测指标**不是中立的尺子，而是**一种干预**：一旦被测系统能看到指标，它就会优化指标而不是优化安全；一旦排行榜固定，选择偏差会把「第 K 名的噪声」抬成「冠军」；一旦只用单一综合分，安全与效率的交换率就被偷偷固定并藏进标量里。
>

>

## 0. 直觉与动机

**灵感 1（竞品分析 → 竞品是「等预算替代品」，不是功能清单）**
直觉：用户不关心你有几个模块，只关心同样预算下是否更安全、更省、更可验证。竞品的本质是**替代**，不是**特征并集**。因此「我们多了 FMP/AUD/MINT/CIA/FMA 五层」根本不是优势陈述，除非能证明：在**相同推理时延、相同训练/调参算力、相同数据**下，这套栈在安全尾部上严格优于一个把同等预算全花在「更大安全裕度 + 更多标定」上的保守对手（complexity-matched rival）。复杂度本身是**负资产**：攻击面更大、验证负担更重、失效模式互相耦合、超参更多因而更容易在验证集上过拟合。一个十层栈若只在均值成功率上好 1%，却尾部更差、延迟更高、审计更难，它就是被支配的。更关键的是，**竞品集必须包含异质范式**（CBF/安全滤波、conformal MPC、端到端 RL+shield、规则保守基线），否则「比上一版好」只是在自己家谱里内卷。

**灵感 2（评测指标 → 指标是干预，不是镜子）**
直觉：我们测的是「安全」，还是「我们的设计意图」？成功率、违规率、near-miss、恢复时间、CVaR、交互成本、算力……每个指标都有**失效模式**。最要命的是三条：(a) **Goodhart**——系统一旦可适应，公开指标就会被优化；安全指标尤其脆弱，因为「停着不动」就能把违规率刷到零；(b) **排行榜选择偏差**——从 K 个带噪估计里挑最大，冠军会被系统性高估，所以「我们比 5 个 baseline 都好」这句话本身需要偏差校正；(c) **标量化陷阱**——把安全与效率压成一个综合分，等价于偷偷固定一个交换率，且把「用效率换安全」的权衡藏起来，无法审计。正确做法不是找一个「更好的分数」，而是**多轴帕累托 + 私有留出 + 预注册 + 指标轮换 + 变形测试**。

**灵感 3（两者合流 → 评价是对抗博弈，而非测量）**
直觉：竞品分析回答「谁来考你」，指标完整性回答「考什么」，二者都可以被过拟合，所以需要一个**刷榜对手**（metric-gaming vanguard）做反向压力测试：如果它只靠优化公开指标、完全不理会安全，却仍能进前三，那么这套评测就是无效的。这与 R69 的关系是：R69 的 FMA/MCG 是**系统内部自检**，ARENA 是**系统外部他检**。内部自检永远可能被同一套表征骗过（R69 已自陈），外部竞品是唯一不能被内部标定吸收的参照系——这正是 R68→R69「标定不可吸收通道」思想在**评价层**的镜像：**不能被系统自身优化的证据，才是真证据。**

**灵感 4（对整个纲领 → 允许「减法」）**
直觉：只加不减的研究循环会熵增。ARENA 给出合法的减法机制：死层检测 + 复杂度预算 + 被支配即剪枝。R70 因此可能是第一轮「输出比上一轮更少模块」的轮次。但减法必须可审计：剪枝也要预注册、要在私有留出集上验证、要防止「为了过评测而删掉安全层」。**能证明该删，才允许加。**

## 1. 形式化定义（增量：定义 310–322）

**定义 310（ARENA-RAS 总览与三不变式）** ARENA-RAS = (RC, MIC, PAD, CGA, GRE, MGV, CBE) 是作用于任意候选栈 S（含 R69）的**外部评价层**。三不变式：
(i) **评价独立性**：私有留出集、刷榜对手种子、评分代码对被测系统不可见、不可写；
(ii) **预注册**：指标、竞品集、阈值、统计检验在全量实验前冻结并提交哈希；
(iii) **禁止标量化安全主张**：安全结论以偏序/帕累托形式给出，任何单一综合分必须显式声明交换率并单独审计。

**定义 311（竞品集 RC）** ℛ = ℛ_paradigm ∪ ℛ_complexity ∪ ℛ_gamer ∪ ℛ_bound。每个竞品 r = (实现, 调参预算, 算力预算, 版本哈希)。ℛ_paradigm 含 CBF 安全滤波、conformal MPC、端到端 RL+shield、规则保守基线；ℛ_complexity 为**等算力/等时延**对手（把差分预算全投入更大裕度或更多标定）；ℛ_gamer 为刷榜对手；ℛ_bound 含保守 oracle（下界）与任务 oracle（上界）。

**定义 312（评测指标仪器）** 指标仪器 m = (构念 C, 估计量 m̂, 判定器 O, 不确定度)。真实目标 J\*（由外部判定器在留出分布上估计），公开读数 m̂(D_pub) 只是 J\* 的代理。

**定义 313（指标有效性三元组）** 构念效度 v_c = corr(m̂, J\*)（在人工裁决集上）；重测信度 v_r；判别效度 v_d（该分开的系统能分开、不该分开的不乱分）。指标可用 ⇔ v_c, v_r, v_d 均过阈。

**定义 314（古德哈特指数）** Γ = |m̂(D_pub) − m̂(D_priv)| / σ_priv，衡量公开与私有分布的系统性背离；自适应版本 Γ_t 度量「随轮次/适应，公开分上涨而私有分不涨」的速率。Γ 越大，指标越可能被当成目标刷。

**定义 315（帕累托支配与改进主张）** 评价轴 A = (安全尾部 CVaR_α、违规率/小时、near-miss 率、任务成功率、恢复时间、P99 时延、算力、复杂度 κ、数据量)。S **支配** S′ ⇔ 在所有轴上不劣、且至少一轴严格更优，全部以**同时置信区间**判定。主张格：Dominates / Non-inferior / Inconclusive / Dominated。只有 Dominates，或「安全 Non-inferior 且效率严格更优」，才允许称「改进」。

**定义 316（复杂度预算与匹配比较 CBE）** κ(S) = 学习模块数 + 超参数数 + 验证/认证负担的加权。任何新层须在**匹配预算**下证明其边际收益超过其复杂度成本；否则该层是「无免费复杂度」原则下的弱被支配对象。

**定义 317（竞品差距归因 CGA）** 差距 Δ(S, r) 按层做 Shapley 分解并给 bootstrap 置信区间；若某层的贡献 CI 含 0 或低于其复杂度成本，判为**死层（dead layer）**。

**定义 318（刷榜对手 MGV）** g 是只最大化公开指标、完全不含安全目标的对抗优化器（含「拒动刷违规率」「只报成功样本」等策略）。**评测健全性**：若 g 进入前 k 名，则 ARENA 判定该指标可博弈、本轮结论无效。

**定义 319（抗古德哈特评测 GRE）** GRE = (私有留出 D_priv, 指标轮换表, 变形关系 ℳ, 预注册哈希, canary 探针)。变形关系示例：平移/重命名不应改变安全结论；仅比例缩放不应改变排序。

**定义 320（排行榜选择偏差校正）** 对 K 个带噪竞品，冠军的真实值需用次序统计量下偏校正：E[m̂_winner − m_winner] ≈ σ√(2 ln K)。校正后仍为正的差距才计入 Δ(S, r)。

**定义 321（阴性结果登记 NRR）** 每轮预注册「假设—指标—预期效应—停止规则」，阴性/不确定结果入档并作为后续轮先验；禁止事后挑指标、事后改阈值。

**定义 322（外部效度与证书）** 外部效度要求在 ≥2 个体/分布上重跑；证书 J_ARENA = (eval_ver, rival_hash, metric_ver, priv_holdout_hash, prereg_hash, pareto_verdict, Γ, attribution, dead_layers, gamer_rank)。Valid ⇔ 指标有效 ∧ 预注册一致 ∧ 刷榜对手未进前 k ∧ 支配主张过选择偏差校正。

## 2. 关键算法骨架

```python
# IP-264 RC：构建并冻结竞品集（含等算力对手与刷榜对手）
def build_rivals(S, budget):
    rivals  = paradigm_rivals()                    # CBF / conformal MPC / RL+shield / rule
    rivals += [complexity_matched(S, budget)]      # 同等时延+算力，预算全给裕度/标定
    rivals += [MGV(public_metrics=PREREG.metrics)] # 反向压力测试
    rivals += [conservative_oracle(), task_oracle()]
    return freeze(rivals)                          # 版本哈希入证

# IP-265 MIC：指标有效性三元组
def audit_metric(m, adjudicated, retest):
    return {
        'construct':   corr(m.estimate(adjudicated), adjudicated.true),
        'reliability': corr(m.estimate(retest.A), m.estimate(retest.B)),
        'discriminant': separation(m, should_differ, should_same),
    }   # 任一不过阈 => 禁用该指标驱动结论

# IP-266 PAD：帕累托支配（同时置信区间 + 选择偏差校正）
def dominance(S, rivals, results, alpha):
    axes = AXES
    lo, hi = simultaneous_ci(results, alpha, K=len(rivals))
    corrected = subtract_selection_bias(hi, K=len(rivals))   # 定义 320
    if all_le(S.lo, rival.hi) and any_lt(S.hi, rival.lo):
        return 'Dominates' if rival is strongest(rivals) else 'Non-inferior'
    return 'Inconclusive' if overlap(S, rivals) else 'Dominated'

# IP-268 GRE：抗古德哈特评测
def goodhart_check(S, public, private, schedule):
    gamma = abs(public.score - private.score) / private.sigma   # 定义 314
    rotated = [m.score for m in schedule.rotate()]              # 指标轮换
    meta    = metamorphic_pass(S, RELATIONS)                    # 变形测试
    return (gamma <= TAU_GAMMA) and all(rotated) and meta

# IP-269 MGV：只刷公开指标、不理会安全
def metric_gaming_vanguard(metrics, budget):
    pi = init_policy()
    for step in range(budget.steps):
        pi = ascend(pi, objective=public_metric(metrics),
                    constraints=None)          # 故意不加安全约束
    return pi                                  # 若它进前 k => 评测无效

# IP-273 ARENA 主闭环：先他检，再决定加层或删层
def ARENA_round(S, prereg):
    assert prereg.hash == hash(PREREG)          # 不变式 ii：预注册
    results = {r: run_matched(S, r, prereg.budget) for r in PREREG.rivals}
    if not all(audit_metric(m).pass_ for m in PREREG.metrics):
        return 'METRIC_INVALID'                 # 指标不可信，不许下结论
    gamer = MGV(PREREG.metrics, prereg.budget)
    if rank(gamer, results) <= TOP_K:
        return 'GAMEABLE'                       # 刷榜对手进前 k，评测失效
    verdict = PAD.dominance(S, PREREG.rivals, results, prereg.alpha)
    attr    = CGA.shapley(S, results)           # 定义 317
    dead    = [l for l, c in attr if c.ci_contains(0) or c < cost(l)]
    if verdict in ('Dominated', 'Inconclusive'):
        return propose_prune(S, dead)           # 合法减法：删层而非加层
    return J_ARENA(verdict, attr, dead, gamma=..., gamer_rank=...)
```

## 3. 推导

**引理 19（可博弈标量的古德哈特必然性）** 设被测策略可观测并针对公开指标 m̂ 做无界搜索。若 m̂ 允许「不作为」取得极值（违规率、事故率、交互次数皆如此），则对任意目标 τ 与任意安全下界 J_min，存在策略 π 使 m̂(π) ≥ τ 而 J\*(π) ≤ J_min。证明要点：构造「停住不动 / 拒绝任务 / 只报成功样本」的策略，它以牺牲覆盖率与任务完成换取零违规。**系：任何可被「不动」刷高的安全指标，必须与活性/覆盖率指标成对使用；单独报告违规率是无效证据。**

**引理 20（排行榜选择偏差）** 设 K 个竞品的真实值 m_i 与独立噪声 ε_i ~ 𝒩(0, σ²)，公开榜单取 m̂_winner = max_i m̂_i，则
E[m̂_winner − m_winner] ≥ σ√(2 ln K) − o(1)。
即冠军的系统性高估随竞品数量对数增长。**系：`S 比 K 个 baseline 都好` 的原始差距必须减去 σ√(2 ln K) 才可信；否则「多找几个弱 baseline」就能制造显著性。**

**定理 18（ARENA 主张可靠性）** 在预注册（指标/竞品/阈值冻结）、私有留出、同时置信区间与选择偏差校正四者同时满足、且留出集与适应过程无泄漏时，任意一次「改进」主张的族错误率 FWER ≤ α。反之，缺少任一条，均存在一个世界/对手使错误「改进」主张以趋近 1 的概率成立。
*证明思路*：预注册消灭事后挑指标（多重比较只来自预注册族，用 Bonferroni/Šidák 控制）；私有留出切断适应—评价回环（消除 Goodhart 反馈）；同时 CI 控制多轴联合覆盖；定义 320 去掉选择偏差。缺任一条的构造分别对应：事后择优、公开集过拟合、逐轴多重比较、排行榜选择偏差。

**定理 19（内部包含不蕴含外部支配；合法减法）** 设 S 在自族偏序上严格支配其祖先 S_prev。则存在部署分布 P_dep 与一个简单竞品 r ∈ ℛ_complexity，使 r 在安全尾部 CVaR 上严格优于 S，而 S 相对 S_prev 的改进在 P_dep 上不可见。
*证明思路*：把 P_dep 的质量集中在公共验证集的极稀有尾部（自族迭代从未采样到的区域）；保守 r 的大裕度在该尾部有更低 CVaR，而 S 的复杂层在尾部只会放大方差。**系（无免费复杂度）：若某层贡献 CI 含 0 且 κ>0，则剪掉它得到的新栈在「安全不劣、复杂度更低」意义上弱支配原栈，故「必须保留」的举证责任在主张加层者一侧。**

## 6. 本轮最大风险

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** ARENA = (RC,MIC,PAD,CGA,GRE,MGV,CBE)；评价独立性（私有集/刷榜种子/评分代码对被测系统不可见、不可写）；预注册（指标/竞品/阈值/检验先冻结并提交哈希）；禁止标量化安全主张（安全以偏序给出，综合分须显式声明交换率）。

**定义 311（竞品集）** ℛ 含异质范式（CBF、conformal MPC、RL+shield、规则基线）、等算力/等时延对手（差分预算全投入裕度或标定）、刷榜对手、保守/任务 oracle；每个竞品带实现、调参与算力预算、版本哈希。

**定义 312–313（指标仪器与有效性）** `m=(C,m̂,O,σ)`，`m̂` 只是 `J*` 的代理；可用需构念效度 `corr(m̂,J*)`、重测信度、判别效度同时过阈。

**定义 314（古德哈特指数）** `Γ=|m̂(D_pub)−m̂(D_priv)|/σ_priv`；自适应版 `Γ_t` 度量公开分上涨而私有分不涨的速率。

**定义 315（帕累托支配）** 全轴不劣且至少一轴严格更优（同时置信区间）；主张格 Dominates / Non-inferior / Inconclusive / Dominated；只有支配或「安全 Non-inferior 且效率严格更优」可称改进。

**定义 316–317（复杂度与归因）** `κ` 计入学习模块、超参、验证负担；新层须证明边际收益 > 复杂度成本（无免费复杂度）。`Δ(S,r)` 做 Shapley 分解 + bootstrap CI，CI 含 0 或低于成本即死层。

**定义 318–319（刷榜红队与抗古德哈特）** 刷榜对手只最大化公开指标、无安全目标，进入前 k ⇒ 评测无效。GRE = 私有留出 + 指标轮换 + 变形关系 + 预注册哈希 + canary。

**定义 320–322（偏差校正、阴性登记、证书）** 冠军真实值需减去 `σ√(2 ln K)`（次序统计量）；每轮预注册假设/指标/阈值，阴性结果入档影响先验；外部效度需 ≥2 个体/分布；`J_ARENA` 绑定全部哈希与裁决。

## 3. 关键算法伪代码

```python
# IP-264 RC：冻结竞品集（异质 + 等算力 + 刷榜 + 界）
def build_rivals(S, budget):
    rivals  = paradigm_rivals()                     # CBF / conformal MPC / RL+shield / rule
    rivals += [complexity_matched(S, budget)]       # 同等时延+算力，预算全给裕度/标定
    rivals += [MGV(PREREG.metrics)]                 # 反向压力测试
    return freeze(rivals + [conservative_oracle(), task_oracle()])

# IP-265 MIC：指标有效性三元组
def audit_metric(m, adjudicated, retest):
    return dict(construct=corr(m.estimate(adjudicated), adjudicated.true),
                reliability=corr(m.estimate(retest.A), m.estimate(retest.B)),
                discriminant=separation(m, SHOULD_DIFFER, SHOULD_SAME))

# IP-266 PAD：帕累托支配（同时 CI + 选择偏差校正）
def dominance(S, results, alpha, K):
    lo, hi  = simultaneous_ci(results, alpha)
    hi      = subtract_selection_bias(hi, K)        # = σ√(2 ln K)
    dominates = all_le(S.lo, hi) and any_lt(S.hi, lo)
    return 'Dominates' if dominates else ('Inconclusive' if overlap(S, results) else 'Dominated')

# IP-269 MGV：只刷公开指标
def metric_gaming_vanguard(metrics, budget):
    pi = init_policy()
    for _ in range(budget.steps):
        pi = ascend(pi, objective=public_metric(metrics), constraints=None)  # 故意无安全约束
    return pi                                       # 排名进前 k ⇒ 评测可博弈

# IP-273 ARENA 主闭环
def ARENA_round(S, prereg):
    assert prereg.hash == hash(PREREG)              # 预注册不变式
    results = {r: run_matched(S, r, prereg.budget) for r in PREREG.rivals}
    if not all(audit_metric(m).pass_ for m in PREREG.metrics):
        return 'METRIC_INVALID'
    gamer = MGV(PREREG.metrics, prereg.budget)
    if rank(gamer, results) <= TOP_K:
        return 'GAMEABLE'                           # 评测失效
    verdict = PAD.dominance(S, results, prereg.alpha, len(PREREG.rivals))
    attr    = CGA.shapley(S, results)
    dead    = [l for l, c in attr if c.ci_contains(0) or c < cost(l)]
    if verdict in ('Dominated', 'Inconclusive'):
        return propose_prune(S, dead)               # 合法减法，而非再加层
    return J_ARENA(verdict, attr, dead, gamma=..., gamer_rank=...)
```

## 4. 推导

**引理 19（可博弈标量的古德哈特必然性）** 若被测策略可观测并针对公开指标 `m̂` 无界搜索，且 `m̂` 允许「不作为」取极值（违规率、事故率、交互次数皆如此），则对任意目标 `τ` 与安全下界 `J_min`，存在策略 `π` 使 `m̂(π)≥τ` 而 `J*(π)≤J_min`。证明要点：构造「停住不动 / 拒绝任务 / 只报成功样本」策略，以牺牲覆盖率与任务完成换零违规。**系：任何能被「不动」刷高的安全指标，必须与活性/覆盖率指标成对使用；单独报告违规率无效。**

**引理 20（排行榜选择偏差）** 设 K 个竞品真实值 `m_i` 与独立噪声 `ε_i~𝒩(0,σ²)`，榜单取 `m̂_winner=max_i m̂_i`，则
`E[m̂_winner − m_winner] ≥ σ√(2 ln K) − o(1)`。
冠军系统性高估随竞品数对数增长。**系：`S 比 K 个 baseline 都好` 的原始差距须减去 `σ√(2 ln K)`；否则「多找几个弱 baseline」即可伪造显著性。**

**定理 18（ARENA 主张可靠性）** 预注册 + 私有留出 + 同时置信区间 + 选择偏差校正四者同时满足、且留出集与适应过程无泄漏时，任意一次「改进」主张的族错误率 `FWER ≤ α`；缺少任一条，均存在一个世界/对手使错误「改进」主张以趋近 1 的概率成立。*证明思路*：预注册消灭事后挑指标（多重比较只在预注册族内，Bonferroni/Šidák 控制）；私有留出切断适应—评价回环；同时 CI 控制多轴联合覆盖；定义 320 去掉选择偏差。缺条四情形分别对应事后择优、公开集过拟合、逐轴多重比较、排行榜偏差。

**定理 19（内部包含不蕴含外部支配；合法减法）** 设 S 在自族偏序上严格支配祖先 S_prev，则存在部署分布 P_dep 与简单竞品 `r∈ℛ_complexity`，使 r 在安全尾部 `CVaR` 上严格优于 S，而 S 相对 S_prev 的改进在 P_dep 上不可见。*证明思路*：把 P_dep 质量集中于自族迭代从未采样的稀有尾部；保守 r 的大裕度在该尾部 CVaR 更低，而 S 的复杂层只放大方差。**系（无免费复杂度）：若某层贡献 CI 含 0 且 κ>0，则剪掉它得到「安全不劣、复杂度更低」的弱支配栈；「必须保留」的举证责任在主张加层者一侧。**
