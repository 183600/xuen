# 第 44 轮（新循环第 4 轮） · Bench-Cert × Grasp-Cert：把「评测基准」与「机械臂抓取」变成证书闭环的「镜子」与「压力舱」（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约空集」，但它仍压着两个更深的未言明假设：**(H1) 证书的「好」不需要外部真值**——E87–E94 的「0 违例」全靠自建仿真 oracle，没有抗污染、抗 Goodhart 的评测基准，因此「0 违例」可能只是「0 覆盖」；**(H2) 证书的平滑性假设在接触处成立**——定义 41 的租约衰减 λ=L_m·v_max 依赖 margin 对状态的 Lipschitz 性，而机械臂抓取的接触/冲击使 margin 在时间上不连续，抓取阶段会静默误用陈旧裕度。本轮灵感词「评测基准」「机械臂抓取」精确命中这两个假设：**评测基准**把「证书是否真的在测正确的东西」变成一等公民，用基准项证书 + 证书回执 + 认证缺口 Γ 防污染防 Goodhart；**机械臂抓取**把「接触」从普通场景提升为证书模型的压力舱，用鲁棒力闭合证书 + 接触感知混合租约 + 事件触发重认证替代失效的时间衰减。二者耦合处（基准 × 接触）是本轮真正的新问题：基准的接触真值 oracle 与证书的接触模型可能**共模失效**，使 Γ 检测不到真实差距。

## 0. 直觉与动机

**灵感 1（评测基准 → 「基准即契约」：没有回执的成功不算成功）**：过去 43 轮把「证书」越做越厚，却始终缺一面镜子——我们不知道这些证书是在测「安全」还是在测「自己」。一个抓取策略在公开基准上 95% 成功，可能是它记住了测试物体（污染），可能是基准只采样了简单位姿（分层缺失），更可能是它「成功」的判定本身没有安全含义（把撞飞物体也算成功）。因此把基准项升级为**契约**：每个测试项自带可行性证书 φ、污染见证 κ、分层标签 s、真值守卫 g；任何 leaderboard 提交必须附**机器可检验的证书回执** ρ，成功 ≜ ρ sound ∧ 真值一致。这样「运气成功」与「静默不安全成功」都被回执挡住，而**认证缺口** Γ = benchmark_success − certified_success 直接暴露基准被游戏或证书空泛。

**灵感 2（机械臂抓取 → 「接触是证书的断点」：时间衰减在冲击处不 sound）**：抓取是证书框架的天然压力舱。自由空间里 margin 对状态 Lipschitz，所以定义 41 用 m − λ(t−τ) 保守外推是 sound 的；但一旦接触，法向力、摩擦锥、物体惯量在毫秒级跳变，margin 的时间导数无界，时间衰减会**高估**裕度。于是把租约拆成**混合租约**：自由模式沿用时间衰减；接触模式只在事件窗口 δ_event 内有效，且 δ_event 由冲量界 I_imp 与扰动速率 W_imp 闭式给出；跨越接触模式切换（free→impact→stable-grasp→slip）必须**事件触发重认证**。同时把「抓得住」形式化为**鲁棒力闭合证书**：在感知不确定集 U（位姿/质量/摩擦）上最小化力闭合缩放因子 t(u)，用 LP/SOCP 对偶给下界——对偶可行解就是可审计的证书，对偶间隙就是保守性。

**灵感 3（耦合 → 「基准-证书共演化」与共模失效）**：把基准做成**主动对手**：从证书的认证域 D_C 边界采样反例（CEGIS），既找「证书说安全但真值违例」的可靠性缺陷，也找「真值成功但证书判不可行」的保守缺陷，迭代出**认证前沿** F=(coverage, certified_success, latency)。但这里埋着本轮最大的陷阱：如果基准的真值 oracle 与证书共用同一套接触模型 M，那么模型偏差 e_M 会让二者**一起错**，Γ 恒小却与现实脱节——这正是「共模失效」。所以基准必须持有多套**独立** oracle（不同摩擦模型、实机 holdout、第三方密封集），并把 e_M 作为显式不确定项注入。

**耦合升级**：CB（可验证基准）把每个测试项编译成带证书回执的契约；GCE（抓取证书引擎）把接触/抓取纳入混合租约与鲁棒力闭合；CAE（基准-证书共演化器）做边界反例生成、认证缺口监控与 Goodhart 警报。四层架构由此从 v8 的「人格 + 并发」升级为 v9 的「人格 + 并发 + 接触 + 基准镜」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（可验证基准项与基准 soundness）**：基准项 B_i=(ξ_i, s_i, φ_i, κ_i, g_i)：ξ_i 为场景/任务（物体、位姿、夹爪、初始状态），s_i∈S 为分层标签（接触模式 free/impact/stable/slip、物体类别、杂乱度、本体），φ_i 为可行性证书（物理可解性与最优代价 gap），κ_i 为污染见证（provenance hash、检索排除集、生成种子），g_i 为真值守卫（仿真 oracle + 实机校验协议）。**基准 soundness**：(a) 每个 φ_i 自身持证；(b) κ_i 证明 ξ_i 不在任何训练/检索可见集内；(c) 报告按 s_i 分层而非池化。**回执准入**：提交 (action, success) 必须附证书回执 ρ，成功 ≜ ρ sound ∧ g_i 一致。

**定义 45（抓取证书与鲁棒力闭合裕度）**：抓取状态 g=(q,o,μ)，接触集 C，摩擦锥 FC_c(μ_c,n_c)，抓取矩阵 G_c，外扰 w_d。不确定集 U=U_pose×U_obj×U_fric（有界）。定义**力闭合缩放因子** t(u)=max{t : t·w_d ∈ ⊕_{c∈C} G_c FC_c(μ_c(u))}。**鲁棒抓取证书** G=(C, m_G, slip, u_cert)，其中 m_G = min_{u∈U} t(u) − 1（m_G≥0 即鲁棒力闭合）。**soundness 命题**：m_G 由每个 u 的 LP/SOCP 对偶可行解给出，则 m_G 是真实鲁棒裕度的**下界**（保守但 sound）；对偶间隙即可审计的保守量。**滑移界**：若 m_G>0，则 ||w_ext|| ≤ m_G·κ_G 内无滑移。

**定义 46（接触感知混合租约）**：自由租约 ℓ_free=(m,τ,λ,κ)；接触租约 ℓ_ct=(m_c,t_c,δ_event,δ_detect,κ,mode)。自由模式判据沿用定义 41；接触模式 m_c 仅在 [t_c, t_c+δ_event] 有效。**推导**：设接触期扰动满足 ||w(t)−w(t_c)|| ≤ W_imp(t−t_c)+I_imp·1[impact]，检测延迟 δ_detect，则安全事件窗
δ_event = (m_c(t_c) − I_imp − θ)/W_imp − δ_detect。
**命题（跨接触 sound）**：若 δ_event≥0 且每次 mode 切换都重认证，则接触租约绝不误用陈旧接触裕度。**推论**：定义 41 的时间衰减在 free→impact 切换点不 sound，抓取阶段必须事件触发，否则会静默放行。

**定义 47（基准-证书共演化 / CEGIS 闭环）**：认证域 D_C={x: margin_C(x)≥θ}。生成器 A 在 ∂D_C 及其 ε-外邻域采样反例 ξ'，两类反馈：证书 sound 但 g 违例 → **可靠性缺陷**；g 成功但 C 判不可行 → **保守缺陷**。迭代得到认证前沿 F=Pareto{(coverage, certified_success, latency)}。**命题（ε-网近似完备）**：若 ∂D_C 可被有限 ε-网覆盖，则任何宽度 >ε 的证书缺陷必被采到。

**定义 48（跨本体抓取证书迁移）**：本体态射 ψ:H_A→H_B（接触点映射 + 自由度嵌入）。若 ψ 保持摩擦锥与运动学约束，且 margin_B(ψ(g)) ≥ margin_A(g) − Δ_m，则 G_A 迁移为 G_B；Δ_m 为迁移证书裕度损耗，由接触点数、可达性、关节刚度差异界出。**迁移 soundness**：迁移后证书仍 sound 当且仅当 Δ_m 被本体差异界覆盖。

**定义 49（污染与 Goodhart 防御 / 认证缺口）**：同一分层上**认证缺口** Γ_s = E_s[success_bench] − E_s[certified_success]。Γ_s 显著 >0 说明基准被游戏或证书空泛。**污染检测**：CKB 检索排除集 + 指纹碰撞；若 sealed holdout 成功率显著高于公开集，判污染。**报告准则**：只报分层 Γ 与认证前沿，不报单一平均成功率。**共模失效判据**：若 oracle 与证书共用接触模型 M，则 Γ ≤ e_M，Γ 对模型偏差 e_M 盲——必须用独立 oracle 交叉验证。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERT-BENCH（可验证基准 CB）
1. **基准项编译器**：场景 → (s_i, φ_i, κ_i, g_i)，可行性证书用规划/可达性离线证。
2. **证书回执 leaderboard**：提交必须带机器可检验回执 ρ，成功 = ρ sound ∧ 真值一致。
3. **分层报告 + 认证前沿 + 认证缺口 Γ**：按接触模式/物体/本体分层，报前沿不报均值。
4. **密封 holdout + 污染检测**：指纹碰撞 + 检索排除集。

### 2.2 IP-61 GRASP-CERT-ENGINE（抓取证书引擎 GCE）
1. **鲁棒力闭合裕度**：SOCP/LP 对偶证书；不确定集顶点/椭球保守化。
2. **接触感知混合租约**：事件触发 + 冲量界 + δ_event 闭式。
3. **slip/impact 检测与重认证**：触觉/力/视觉三源事件，最高关键级抢占。
4. **跨本体迁移**：ψ + Δ_m 证书损耗账本。

### 2.3 IP-62 CERT-ADVERSARY / CO-EVOLUTION（基准-证书共演化 CAE）
1. **边界采样反例生成**（CEGIS）：bisection 找 ∂D_C，采样 ε-外邻域。
2. **认证缺口监控 + Goodhart 警报**：Γ_s 漂移、公开/密封差。
3. **反例回灌** CKB/SCV/课程：可靠性缺陷进 CKB 黑名单，保守缺陷进课程。
4. **认证前沿追踪**：coverage/certified_success/latency Pareto。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

回退：E95/E96 不达标 → 关闭回执 leaderboard，退回纯离线评测；E97 对偶 gap 过大 → 用顶点枚举精确化，牺牲算力换 sound；E98 事件窗为负 → 强制每次接触重认证（不用窗口外推）；E99 无前沿提升 → 退回随机采样；E100 迁移不 sound → 禁用跨本体，逐本体重证；E101 Γ 异常 → 冻结 leaderboard 做污染审计；任何红线失败 → 熔断回退 v20。

## 5. 本轮最大风险

**一句话**：基准的真值 oracle 与抓取证书共用同一套接触/摩擦模型时会发生**共模失效**——二者一起错、认证缺口 Γ 恒小却与现实脱节，因此 E97（实机滑移）与 E101（独立密封集 Γ）必须用**不同物理模型 + 实机 holdout** 做红线，否则整个「可验证」闭环只是自洽的幻觉。

### IP-60 CB：基准项编译、回执准入与分层报告
```
def compile_bench_item(scene, stratum, goal):
    phi = feasibility_certificate(scene, goal)   # 规划/可达性离线证
    assert phi.holds()                            # 可行性证书自身持证
    kappa = provenance_witness(scene)             # hash + 检索排除集 + 种子
    g = TruthGuard(sim_oracles=[O1, O2], real_protocol=REAL_HOLDOUT)
    return BenchItem(scene, stratum, phi, kappa, g)

def admit_submission(item, action, success, receipt):
    if not receipt.verifiable():                 return Reject("no-receipt")
    if not receipt.sound():                      return Reject("unsound-cert")
    if not item.g.agrees(action, success):       return Reject("truth-mismatch")
    if item.kappa.contaminated():                return Reject("contamination")
    return Accept

def stratified_report(results):
    per = group_by_stratum(results)
    Gamma = {s: success_bench[s] - certified_success[s] for s in per}
    frontier = pareto(per, keys=('coverage', 'certified_success', 'latency'))
    return Report(per_stratum=per, gamma=Gamma, frontier=frontier)  # 不报均值
```

### IP-61 GCE：鲁棒力闭合、混合租约与跨本体迁移
```
def robust_force_closure(G_contacts, w_d, U):
    m = +inf
    for u in conservative_cover(U):              # 顶点枚举 / 椭球保守化
        # max t  s.t.  sum_c G_c f_c = t*w_d,  f_c in FC_c(mu_c(u))
        t, dual = solve_socp_force_closure(G_contacts, w_d, u)
        m = min(m, t - 1.0)                      # 对偶可行解即证书下界
    return GraspCert(m_G=m, u_cert=U, dual=dual)

def contact_lease(m_c, t_c, theta, W_imp, I_imp, delta_detect):
    delta_event = (m_c - I_imp - theta) / W_imp - delta_detect
    if delta_event < 0:
        return None                              # 窗口为负 => 立即重认证
    return ContactLease(m_c=m_c, t_c=t_c, delta_event=delta_event)

def contact_guard(lease, mode, t):
    if mode == FREE:
        return lease.m - lease.lam * (t - lease.tau) >= lease.theta   # 定义41
    if mode in (IMPACT, STABLE, SLIP):
        within = (t - lease.t_c) <= lease.delta_event
        return within and (lease.m_c - W_imp*(t-lease.t_c) - I_imp) >= lease.theta
    return False                                 # 未知模式 => 拒绝

def transfer_cert(cert_A, psi, delta_m_bound):
    m_B = cert_A.m_G - delta_m_bound             # 保守扣除迁移损耗
    return GraspCert(m_G=m_B, u_cert=psi.push(cert_A.u_cert))
```

### IP-62 CAE：边界 CEGIS、认证缺口与 Goodhart 警报
```
def cegis_loop(C, bench, budget):
    for _ in range(budget):
        x0 = sample_in(certified_domain(C))      # 内点
        x1 = sample_out(certified_domain(C))     # 外点
        xb = bisect_boundary(C, x0, x1)          # 逼近 ∂D_C
        for x in epsilon_neighborhood(xb):       # ε-外邻域
            truth = bench.truth(x)               # 多 oracle 交叉
            cert  = C.certify(x)
            if cert.sound and not truth.ok:
                bench.add_reliable_counterexample(x)       # 可靠性缺陷
            elif truth.ok and cert.infeasible:
                bench.add_conservative_counterexample(x)   # 保守缺陷
        if goodhart_alert(bench, C):
            freeze_and_audit(bench)              # 冻结榜单做污染审计
    return certification_frontier(C, bench)

def goodhart_alert(bench, C):
    return (bench.gamma_public_sealed > 0.05 or
            bench.stratified_vs_pooled_gap > 0.03)
```

def car_transition_guard(e, x, cert_obj, persona, lease, mode, t):

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 共模失效：真值 oracle 与抓取证书共用接触/摩擦模型，Γ 检测不到真实差距 | 极高 | E97/E101 红线；多套独立 oracle（不同摩擦模型）+ 实机 holdout + 第三方密封集；e_M 显式注入 |
| 鲁棒力闭合 SOCP 过保守，抓取可用性崩塌 | 高 | 对偶 gap 监控；顶点枚举精确化；分层报告可用性曲线 |
| 接触检测延迟超预算，事件窗为负 | 高 | 三源融合；最高关键级抢占；δ_event<0 强制重认证 |
| 基准污染：CKB/训练集泄漏测试项 | 高 | 指纹排除集 + provenance hash；sealed holdout；污染注入测试 |
| Goodhart：只优化公开集，均值掩盖长尾 | 高 | 分层 Γ；公开/密封差；只报认证前沿 |
| 跨本体 Δ_m 低估，迁移后不 sound | 中-高 | 本体差异界（接触点/可达性/刚度）；逐本体重证兜底 |
| 回执检验开销拖慢 leaderboard | 中 | 离线批量检验 + 回执缓存 + 抽样复核 |
| 多 oracle 真值冲突 | 中 | 冲突项隔离、人工仲裁、置信加权 |

## 6. 本轮最大风险

**一句话**：基准的真值 oracle 与抓取证书共用同一套接触/摩擦模型时会发生**共模失效**——二者一起错、认证缺口 Γ 恒小却与现实脱节，因此 E97（实机滑移）与 E101（独立密封集 Γ）必须用**不同物理模型 + 实机 holdout** 做红线，否则整个「可验证」闭环只是自洽的幻觉。
