研究循环·迁移第 1 轮；本轮灵感：「迁移学习」×「虚实迁移」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（其上承 v21 的 SDC/CAC/DCL/GIC/HPC+/CFC+，v20 的联邦感知证书 PCA/CTS/CFC/HPC/CFCtrl，及 v19/v17 各模块全保留）。
> 本轮纪律：**迁移不是"复制结论"，而是"复制带契约的信念"；虚实差距不是标量，而是随轨迹变化、可被多通道独立上界的"差距场"；负迁移是必须熔断的故障，而非可容忍的误差**。不推倒 v22：HDL/ACSC/DCSC/HPC-E/CFC++ 全部保留。本轮只做一件事：**在 v22 的层级物理-能量证书之上加一层"可迁移性"层，使证书/先验跨机器人、跨环境、从仿真迁移到现实时始终携带"出处-位移预算-到期"契约，并用差距场与负迁移熔断守住安全继承**。

## 0. 直觉与动机

**灵感 1（迁移学习 → 证书是带位移预算的"信念"，不是可随便复制的"事实"）**
直觉：v22 的证书几乎都是"就地标定"的——每台机器人、每个环境、每个用户都重新算 conformal 分位、重新标定能量模型、重新学类先验。这既昂贵又浪费：同厂商机器人、同类抓取任务、同一套规则库，本应可以"带着经验走"。迁移学习的直觉正是：**源域 S 上标定好的先验/证书，若能证明目标域 T 与 S 的分布位移足够小，就能以剩余覆盖 1-α-ε_shift 的代价搬过来用**。但安全证书不像分类精度，不能"大概好用"：一条迁移来的先验必须随身携带一张**迁移契约 (Transfer Contract)**——出处、位移预算 ε_shift、适用域、到期时间。核心创新：**迁移证书 (Transfer Certificate, T-Cert) + 出处账本 (Provenance Ledger, PL)**。关键反直觉点：**"迁移成功"不是"目标域表现好"，而是"可证明地退化到就地标定"——迁移的全部价值在于它失效时能否无损退回保守基线**。

**灵感 2（虚实迁移 → 现实差距是场，不是标量，且必须被多条独立通道同时上界）**
直觉：v22 的 RGC 用一个标量 d_gap 概括"仿真与现实差多少"，这在安全上是危险的过度简化：差距在平坦地面可能极小，在湿滑/玻璃/反光/重载下却可能爆炸。虚实迁移给出正确对象：**差距是定义在状态-轨迹空间上的场 d_gap(x, π)**，可从三条彼此独立的通道被上界——(a) **域随机化覆盖**：若 DR 参数集以 ≥1-β 覆盖真实参数，则最坏仿真裕度给出真实裕度下界；(b) **系统辨识后验**：参数后验半径 + 模型 Lipschitz 常数传播出差距上界；(c) **真实残差 conformal**：少量真实 rollout 残差给出分位上界。关键技巧与反直觉点：**取三者上界的 min 仍然安全**——每个通道给出的是"≥真值"的上界，只要同时成立（union bound 1-Σδ_i），min 仍 ≥ 真值，却比任何单通道都紧；这正是对 v22「配空间能量过度保守导致活性坍缩」的解药。支撑域之外一律 d_gap = +∞。

**灵感 3（负迁移 → 必须熔断，且熔断只能向保守方向坍缩）**
直觉：迁移学习最阴险的失败不是"没迁成"，而是**负迁移**：源域先验在目标域系统性错误，且错误方向恰好更乐观（把不该释放的自由空间释放了、把能量需求低估了）。更糟的是，这种错误会伪装成"迁移很成功"——因为监控器本身也由同源数据校准。核心创新：**负迁移熔断器 (Negative Transfer Circuit-Breaker, NTCB)**：持续对照一个"就地从头标定"的影子基线 β_0（可取得极保守），用序贯检验（CUSUM/SPRT）检测迁移预测相对 β_0 的系统性劣化或概念漂移；一旦触发，**撤销全部迁移先验、退回非迁移保守补全**。关键反直觉点：**影子基线越保守，熔断越安全**——熔断的代价只是活性，而不熔断的代价是安全。撤销必须可传递：账本记录每条证书依赖了哪些迁移先验，撤销沿依赖图闭包生效。

**三者如何统一**
在 v22 之上加 **可迁移性层 (Transferability Layer, TL)**：T-Cert/PL 回答"这条经验凭什么能搬到这里、还能用多久"，RGF 回答"仿真结论在现实里还剩多少余量"，NTCB 回答"搬错了怎么止血"。共享状态扩展为 **ζ_xfer = ζ_pgev ∪ (L_prov, τ_transfer, ε_shift, d_gap(·), nt_monitor)**。统一准入门升级为 **HPC-EX = (HPC-E, ValidTransf, GapOK)**：几何∧规范∧负信息∧能量（v22）之后，再要求 **迁移契约在当前域成立（ValidTransf）且轨迹条件差距在信用预算内（d_gap(π) ≤ credit）**。任一不满足退回 v22 的就地保守模式。故 **Exec_v23 = Exec_v22 ∩ Fil_transfer ⊆ Exec_v22**，与 v22 的「层级边界模糊」风险互补：迁移收紧保守性，熔断守住安全性。

## 2. 设计原则（在 P41–P42 基础上新增 P43–P45）

**P43 迁移契约律（Transfer Contract Law）**
每条被迁移复用的先验/证书 ξ 必须携带契约 `K_ξ = (src, ε_shift, D_transfer, t_expire, deps)`。仅当当前状态 `x_t ∈ D_transfer ∧ t ≤ t_expire ∧ ε_shift ≤ ε_budget` 且 deps 全部有效时，才允许 ξ 参与证书计算；否则 ξ 视为不存在，退回就地标定。`Exec_v23` 中所有结论都可追溯到一组契约有效的 ξ，或显式声明"未用迁移"。**推论**：契约失效只会移除乐观先验 ⇒ 执行域单调收缩至 v22。

**P44 差距场界定律（Reality Gap Field Bound Law）**
`d_gap(π) := min{ d_DR(π), d_sysID(π), d_real(π) }`，其中每个 `d_i(π)=max_{x∈traj(π)} d_i(x)` 均为在置信 1-δ_i 下 ≥ 真实差距的轨迹级上界；故 union bound 下 `d_gap(π) ≥ 真实差距` 以 ≥1-Σδ_i 成立。仿真裕度须满足 `M_sim(π) - d_gap(π) ≥ margin_req` 才授予仿真信用；`x ∉ support` 时 `d_gap = +∞`。差距按轨迹条件化（逐点取上界、轨迹取最坏点），禁止用全局平均掩盖局部尖峰。

**P45 负迁移熔断律（Negative Transfer Circuit-Breaker Law）**
维护影子基线 β_0（就地、非迁移、可取最保守）。监控序贯统计量 `Λ_t`（迁移相对 β_0 的"乐观劣化"或漂移证据），超过阈值 γ_revoke 即触发撤销 `revoke(ξ)`，沿 PL 依赖图取传递闭包。撤销仅移除迁移先验、保留 v22 全部本地证书，故 `Exec_v23^{after} ⊆ Exec_v23^{before} ⊆ Exec_v22`。熔断状态带滞回 h，避免抖动反复解锁。

## 3. 与基线的接口（如何退化）

- T-Cert 失效（位移超预算 / 契约到期 / 域外）⇒ 不用迁移先验，就地重新标定 ⇒ 比 v22 更保守 ⇒ 子集；

- **与 v22 层级过滤协同**：迁移只能"填回"被 v22 过度保守裁掉、且有契约担保的域，撤销只能"收回"这些填回 ⇒ `Fil_strategic ⊇ Fil_tactical ⊇ Fil_operational` 在每次迁移/撤销后仍保持。

## 5. 本轮最大风险

**一句话**：**差距场与可迁移性估计本身来自同一个仿真/源域家族**——DR 参数范围、sysID 数据集、漂移监控器的参考分布都与被检验的先验同源，于是"契约有效 ∧ 差距在预算内"可以**自指地自洽**，却在真实但未见的条件（湿滑地面、反光玻璃、负载突变、非典型人体）下同时落在 DR 支撑之外、又逃过同源校准的监控器——形成 union bound 也覆盖不到的**相关盲区**，机器人会"自信地、可审计地"执行一张只在它自己仿真镜像里成立的证书，即**虚实差距的自我确认幻觉**。

## 1. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
# IP-436 开放世界语义证书：集合值 conformal + 显式弃权
class OpenWorldSemanticCertificate:
    def __init__(self, detector, calibrator, alpha_ow=0.01,
                 n_min=200, unknown_class="U"):
        self.detector = detector
        self.calib = calibrator          # split / weighted conformal
        self.alpha_ow = alpha_ow
        self.n_min = n_min
        self.U = unknown_class

    def predict_set(self, proposal, weights=None):
        # 分数越小越一致；prediction set = {c : s(x,c) <= q_hat}
        scores = {c: self.detector.score(proposal.x, c)
                  for c in self.detector.classes}
        if weights is None:
            q_hat = self.calib.quantile(self.alpha_ow)      # 同分布
        else:
            n_eff = weights.sum() ** 2 / (weights ** 2).sum()
            if n_eff < self.n_min:
                return {self.U}                              # 退化：U 优先
            q_hat = self.calib.weighted_quantile(self.alpha_ow, weights)
        gamma = {c for c, s in scores.items() if s <= q_hat}
        # 弃权：含糊或空集都并入 U；U 一旦出现，永不剥除
        if len(gamma) == 0 or len(gamma) > 1 or self.detector.novelty(proposal) > self.calib.novelty_q:
            gamma.add(self.U)
        return gamma

    def cert_box(self, proposal):
        gamma = self.predict_set(proposal)
        if self.U in gamma:
            # 未知类：物理上界，禁用类先验与 CTS 收教
            return CertBox_U(box=inflate(proposal.box, eps_max(proposal)),
                             mass_bound=MASS_MAX, speed_bound=SPEED_MAX,
                             provenance="unknown")
        # 唯一已知类：可用该类校准的定位误差 + 类条件先验
        c = next(iter(gamma))
        return CertBox(cls=c, box=inflate(proposal.box, self.calib.eps_loc(c)),
                       prior=self.priors[c], provenance="known")

class UnexplainedEvidenceCertificate:
    def __init__(self, mass_fn, residual_calibrator, tau_alpha):
        self.mass = mass_fn              # 点/强度/占据的统一质量
        self.calib = residual_calibrator
        self.tau = tau_alpha

    def residual(self, raw_returns, obstacles):
        m_raw = self.mass(raw_returns)
        if m_raw <= 0:
            return 1.0                   # 无返回 ⇒ 不可信 ⇒ 全域保守
        m_exp = sum(self.mass.integrate(o) for o in obstacles)
        return max(0.0, min(1.0, (m_raw - m_exp) / m_raw))

    def augment(self, obstacles, raw_returns):
        r = self.residual(raw_returns, obstacles)
        if r <= self.tau:
            return obstacles, r
        # 残差连通分量 → 未知障碍（不命名、不设先验）
        comps = connected_components(self.mass.residual_voxels(raw_returns, obstacles))
        for comp in comps:
            obstacles = obstacles + [CertBox_U(box=comp.bounds,
                                               mass_bound=MASS_MAX,
                                               speed_bound=SPEED_MAX,
                                               provenance="residual")]
        return union_monotone(obstacles), r     # 快照内只增不减


# IP-438 孪生保真度证书：在线差距包络
class TwinFidelityCertificate:
    def __init__(self, twin, delta_g=0.01, ttl=0.5, window=200):
        self.twin = twin
        self.delta_g = delta_g
        self.ttl = ttl
        self.window = deque(maxlen=window)

    def update(self, real_state, real_sensor, t):
        twin_pred = self.twin.predict(real_state)
        self.window.append(norm(real_sensor - twin_pred))
        age = t - self.twin.last_sync
        if age > self.ttl:
            return None, age            # 失效：关闭 Fil_twin
        # 时间衰减加权分位，给出 >=1-delta_g 的差距包络
        w = np.exp(-np.array([t - ti for ti in self.twin.stamps]))
        d_twin = weighted_quantile(self.window, 1 - self.delta_g, w)
        return d_twin, age

    def envelope(self, d_twin):
        if d_twin is None:
            return set()                # 空包络 ⇒ 无孪生证据
        return {u for u in UNKNOWN_HYPOTHESES if u.divergence <= d_twin}


# IP-439 孪生接地反事实证伪器：只会否定，不会删除证据
class TwinGroundedCounterfactualFalsifier:
    def __init__(self, twin, tfc, margin_req):
        self.twin = twin
        self.tfc = tfc
        self.margin_req = margin_req

    def witnesses(self, plan, t, budget):
        d_twin, age = self.tfc.update(plan.state, plan.sensor, t)
        if d_twin is None:
            return [], "TWIN_STALE"     # 回落 v22，不加速也不放松
        env = self.tfc.envelope(d_twin)
        W = []
        for u in sample_hypotheses(env, H_t_active, budget):
            m = self.twin.rollout(plan, u)      # 反事实：含 U 类最坏质量/速度
            if m < self.margin_req:             # 只在包络内采信
                W.append(Witness(u=u, margin=m, d=d_twin))
        return W, "OK"                      # W 只进入否定条件


# IP-440 HPC-OT 统一准入门
@dataclass
class HPCOT:
    hpc_e: HPCE
    owsc: OpenWorldSemanticCertificate
    uec: UnexplainedEvidenceCertificate
    tfc: TwinFidelityCertificate
    tgcf: TwinGroundedCounterfactualFalsifier

    def admits(self, plan, raw_returns, obstacles, t, twin_budget):
        # 1) 开放世界：未知候选一律最大障碍（已在 cert_box 内体现）
        obs, _ = self.uec.augment(obstacles, raw_returns)
        ow_ok = all(o.provenance != "known" or o.in_owsc_set for o in obs)
        # 2) 残差必须被解释
        r = self.uec.residual(raw_returns, obs)
        uec_ok = r <= self.uec.tau or any(o.provenance == "residual" for o in obs)
        # 3) 孪生保真（陈旧则视为不可用，但只关闭加速，不放松）
        d_twin, age = self.tfc.update(plan.state, plan.sensor, t)
        tfc_ok = d_twin is not None or age > self.tfc.ttl  # 陈旧仍可继续，但无孪生证据
        # 4) 孪生反例：只否决
        W, status = self.tgcf.witnesses(plan, t, twin_budget)
        twin_ok = (len(W) == 0)
        # 5) v22 能量/几何/规范门原样保留
        base = self.hpc_e.admits(plan, plan.x, plan.v, plan.z,
                                 plan.E_res, margin_req=MARGIN)
        return base and ow_ok and uec_ok and tfc_ok and twin_ok, {
            "residual": r, "d_twin": d_twin, "twin_status": status,
            "witnesses": W}


# IP-441 漂移加权 + 孪生合成的开放世界校准（受 P46 信用封顶）
class ShiftWeightedTwinGroundedConformal:
    def __init__(self, calib, tfc, alpha_ow=0.01):
        self.calib = calib
        self.tfc = tfc
        self.alpha_ow = alpha_ow

    def recalibrate(self, real_scores, synthetic_scores, d_twin, credit):
        # 孪生合成只能回收被 d_twin 证明可用的那部分
        if d_twin is None or credit <= 0:
            return self.calib.quantile(self.alpha_ow)   # 零信用 ⇒ 不用合成
        # 密度比由孪生合成分布与校准分布估计；n_eff 不足则退化为 U 优先
        weights = density_ratio(synthetic_scores, real_scores)
        n_eff = weights.sum() ** 2 / (weights ** 2).sum()
        q_syn = self.calib.weighted_quantile(self.alpha_ow, weights)
        q_real = self.calib.quantile(self.alpha_ow)
        # P46：松弛量不得超过信用；无信用时取两界的最严者
        relax = min(max(0.0, q_real - q_syn), credit)
        return q_real - relax
```

## 2. 形式推导

**引理 163（v23 的安全继承）**
若 (i) OWSC 对任一候选输出的 CertBox 是其已知类 CertBox 的超集或 `B_max`；(ii) UEC 的更新算子为并集 `∪`；(iii) TGCF 仅在准入谓词中以 `W_twin = ∅` 的合取项出现（且 `W_twin` 只加不减）；则对任意状态与计划 `π`：
`π ∈ Exec_v23 ⇒ π ∈ Exec_v22`，即 `Exec_v23 ⊆ Exec_v22`。
证明：准入是各层谓词的合取，增加合取项只会缩小集合；OWSC/UEC 只扩大障碍集合 `Obs_t`，而 v22 的几何证书在更大障碍集上单调更保守；TGCF 只把计划从可行集中剔除、从不加入；TFC 陈旧时删除的是"孪生加速"而非"v22 约束"。∎

**命题 164（开放世界风险分解）**
设某物理实体 o 在时刻 t 真实存在，且准入计划与 o 发生碰撞。定义三个互斥归因事件：
- `C1`：o 产生了候选但真类别 `Y ∉ Γ_k`（语义覆盖失败）；
- `C2`：o 没有存活候选且残差未触发 `r_t ≤ τ_α`（静默丢弃 + 残差漏检）；
- `C3`：o 被正确覆盖，但 C3 的碰撞裕度在实际差距下小于证书值（v22 差距项未被孪生收紧）。
则
`P(unsafe) ≤ P(C1) + P(C2) + P(C3) ≤ α_ow + (1 - β_res) + ρ_gap(d_twin)`，
其中 `ρ_gap(d_twin)` 是 v22 原差距项经 TFC 包络收紧后的残余。孪生**只能**降低第三项，对第二项无贡献；OWSC **只能**降低第一项。
**关键警告（相关失效）**：`C1` 与 `C2` 并非独立——真正 OOD 的物体既可能得到高 novelty 分数（进 U，安全）也可能被错误地高置信匹配到某个已知类（`Γ_k` 不含 U，危险），且其残差可能低于 `τ_α`（材质透射/遮挡）。令 `γ_corr = P(C1 ∧ C2) / (P(C1) P(C2))`，则实际上界应写为
`P(unsafe) ≤ α_ow + (1 - β_res) - γ_corr·α_ow·(1-β_res) + ρ_gap`。
当 `γ_corr → 1` 时，"双网"退化为单网；本方案的任务不是假设 `γ_corr = 0`，而是**在线估计并报告**它（见实验 E4）。

**命题 165（P46 的不可越界性）**
若松弛量满足 `Δmargin ≤ credit(t)` 且 `φ(∞) = 0`，则当孪生-现实差距无界（`d_twin = ∞`）时 `credit = 0`，任何 `Δmargin > 0` 不可行，于是 v23 的证书不可能比 v22 更宽。故"用孪生补零样本数据"只能在 v22 已承认的保守冗余内回收活性。∎

## 3. 实验设计（预注册）

**E1 开放世界弃权（合成 + 真机）**
在训练类别表外构造 held-out 类别族（儿童/轮椅/服务犬/滑板车/输液架/气球）。指标：`Γ ∪ {U}` 对 held-out 真类别的覆盖率、U 触发率、误弃权（已知类被推入 U）率、活性保留率。零假设：分布内 α_ow=0.01 下覆盖 ≥ 0.99；held-out 覆盖率不承诺 1-α（不可实现），只要求"未被覆盖的样本 100% 落入 U 或残差"。

**E2 残差兜底（静默丢弃压力测试）**
强制检测器丢弃注入物体（模拟 OOD 完全无候选），扫材质（漫反射/镜面/玻璃/织物）、距离、遮挡、天气。指标：`β_res`、残差误报率（空场景）、定位误差。目标：刚性不透明物体 `β_res ≥ 0.95`；透明/镜面单独报告，不达标即触发最大保守模式。

**E3 孪生保真度与漂移**
注入受控模型误差（质量 ±30%、摩擦 ±40%、延迟 0–200ms、执行器滞后）。指标：`d_twin` 对真实残差的覆盖（≥ 1-δ_g=0.99）、活性、TTL 超时率、热更新期间保真度是否被"自我背书"（用更新前后的独立探针集检验）。

**E4 相关盲区对抗套件**
构造"同时逃避语义与孪生"的物体/场景：气球（轻、形变、训练外）、雾/雨（传感器域漂移）、镜面（虚假回波 + 残差阈值失效）、宠物（非人但会动）。指标：联合失效频率、在线估计的 `γ_corr`、UEC 是否仍能捕获（模型无关通道）、三重失效样本占比。这是判定"三网是否等于一网"的关键实验。

**E5 时延与代价**
孪生 rollout 预算扫描（每帧 0/8/32/128 个假设）。指标：50Hz 控制环 p99 延迟、准入率、活性、witness 命中率。目标：p99 < 20ms（控制路径 O(1)，rollout 在 10Hz 事件线程异步完成）。

**E6 消融（安全单调性验证）**
变体：v22 / +OWSC / +UEC / +TFC / +TGCF / full v23。指标：安全违规数（应满足 v23 ≤ v22 逐场景）、活性、准入率、计算开销。

| 变体 | 安全违规（期望） | 活性（期望） | 关键观察 |
|---|---|---|---|
| v22 | 基线 | 100% | 语义盲区导致 OOD 碰撞 |
| +OWSC | ↓ | ↓ | 弃权防误分类，但静默丢弃仍在 |
| +UEC | ↓↓ | ↓↓ | 模型无关兜底，透明/镜面失效 |
| +TFC | ↓↓ | ↓↓↓ | 孪生收紧差距项，但依赖同步 |
| +TGCF | ↓↓ | ↓ | 反事实增加反例，活性略降 |
| full v23 | 预期最低 | 预期 60–75% | 需 E4 验证三网相关性 |

**预注册假设（待验证，非真实测量）**
- H1：full v23 在 E1–E4 的任一场景中，准入碰撞次数不高于 v22（安全单调性）；
- H2：E2 的刚性物体 `β_res ≥ 0.95`，但透明/镜面 < 0.6，必须由最大保守模式兜底；
- H3：E4 中 `γ_corr` 显著大于 0（否则命题 164 会高估安全），且 UEC 是唯一在雾/镜面下仍部分有效的通道；
- H4：E5 的 50Hz 控制路径与孪生 rollout 完全解耦，p99 抖动主要来自同步事件而非 rollout。

## 4. 产物小结

本轮的产物是把 v22 的**闭世界证书**升级为 **v23 的开放世界-孪生证伪层**：`Exec_v23 = Exec_v22 ∩ Fil_owsc ∩ Fil_uec ∩ Fil_twin`。新增六个可机械复核的构件（OWSC/UEC/TFC/TGCF/HPC-OT/SWTGC），三条形式命题（安全继承、风险分解、信用不可越界），以及一个明确把"相关盲区"作为一等公民测量的实验 E4。方案不追求"零样本识别正确"，而是把"未知"变成**无法被打折的障碍**，并把数字孪生降格为**只会增加反例的攻击者**。

**本轮最大风险**：语义弃权与孪生物理都被"模型支撑之外"同一定义所界定，真正的新奇物体可能同时逃过两者，而唯一模型无关的解释残差又依赖传感器噪声分布的交换性——雨雾/强反光/透明材质正是同时破坏三者的三重域漂移，使 `γ_corr → 1`、三网退化为单网。
