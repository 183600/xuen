# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因」IP-214~223；灵感循环第 1 轮；本轮灵感：「机器人操作系统」×「VLA」）

> 第 65 轮用视觉与动作分块把「几何可证伪」升级为「故障可归因」，其自述最大风险一针见血：**归因依赖闭集故障假设与视觉/几何失效独立性；未知复合故障会被强行塞进最近假设、只膨胀错误的球，系统反而因为「已经归因」而更自信。** 本轮不再扩展故障假设集，而是换一个更根本的提问：**我们为什么非要在模型内部归因？** 如果 VLA 是一个开放词表、非确定、可能幻觉、无法枚举失效的语义编译器，那么正确姿态不是「相信它并诊断它」，而是**不信任它，但给它一个必须遵守的接口**。ROS 与 VLA 恰好提供了这个转向的两个支点：
>
> **ROS 把「制度」变成可执行件（QoS、executor、lifecycle、authority、replay）；VLA 把「语义」变成一个不可信的编译前端。**
>
> 本轮核心命题是：
>
> **把「故障可归因」升级为「接口可问责」：语义保持开放，接口必须封闭；VLA 只产生带证书的提议，ROS 2 运行时只执行通过准入的契约；归因单位从「哪个原因」换成「哪条边第一个违约」；而当没有任何契约被违反却仍然出错时，系统必须诚实报告「规格缺口」，而不是编造一个归因。**

## 0. 直觉与动机

**灵感 1（机器人操作系统 → 不是消息总线，而是可执行的制度）**
直觉：大家把 ROS 当"胶水/消息总线"，但真正稀缺的是它把工程制度写进了运行时：QoS 让"按时、够新、可靠、不丢"成为可检查的谓词；executor 让期限、优先级、回调组变成可调度对象；lifecycle node 让"配置/激活/停用/清理"有明确状态；component container 与 intra-process 让隔离与开销可以权衡；SROS2 让每个节点只能发它被授权发的命令；rosbag2 让事后可重放。严格地说，ROS 2 提供的是一个**分布式、强类型、带时间语义、可观测的执行基质**：它不保证语义正确，但它能把"语义正确性"降解为"接口契约是否被满足"——而后者是有限、可检查、可归因的。

**灵感 2（VLA → 不可信的语义编译前端）**
直觉：VLA 把语言 + 视觉直接映射为动作，强在开放语义与组合泛化，弱在不可解释、采样不确定、推理延迟大（数 Hz 到亚 Hz）、会幻觉、难以形式验证。严格地说，VLA 是一个**从自然语言/图像到动作 token 的编译器前端**，它的错误空间是开放的（开放物体、开放场景、开放指令、开放组合），不可能用有限故障假设覆盖。关键转向来自编译器与 proof-carrying code 的老经验：**不要验证编译器，验证它输出的中间表示（IR）**。VLA 可以错，但它必须把"我打算做什么、基于什么指代、在什么时限和包络内做"写成一份可被独立检查的提议；检查器在 TCB 内，VLA 在 TCB 外。

**灵感 3（合流 → PACT：Policy–Action Contract Transpiler，策略-动作契约转译与接口级问责闭环）**
直觉：在 VLA 与物理世界之间插入一层"可验证 IR"。闭环：VLA 产出**语义提议图 SPA**（实体、指代、技能、理由、置信，不含直接执行）→ **语义-契约编译器 SCC** 把它编译为**动作契约图 CAG**（类型/前置后置/期限/资源/权限/物理包络/中止条件）→ **实时准入 RTA** 检查期限链、WCET、资源与包络并决定接受/降级/拒绝 → **隔离监督 ISO** 在 ROS 2 的 lifecycle/container/QoS/SROS2 上执行 → **契约归因 CAD** 按 happens-before 找"第一条违约边" → **执行审计 EAR** 用 rosbag2 做反事实重放 → **开集语义升级 OSE** 处理无法落地、指代歧义与规格缺口 → **AIC-P** 对抗认证。VISTA 没有被抛弃，而是被"降格"为契约内部的物理故障归因器：它依旧回答"这个节点里几何/力/模型哪层坏了"，但不再承担"开放世界终局判断"的重任。

**灵感 4（三个反直觉的换轴）**
(a) **归因单位：原因 → 违约边。** 不再问"哪个物理原因导致异常"，而问"数据流图里哪条边/哪个节点第一个违反了哪条契约"。这与分布式系统的故障定位一致：你无法知道远端进程为何出错，但你能知道哪个接口先违约。
(b) **闭集：故障假设 → 违约模式。** 原因可以是开放集，但**可观测的违约表现是构造性有限的**：类型/模式错、指代/接地错、时序错、资源错、权限错、QoS 错、物理包络错、语义一致性错、活性错。开放世界被挡在接口之外，接口之内是可枚举的。
(c) **模糊性：后验熵阈值 → 因果前沿反链。** VISTA 用 `max_H P(H|ρ) < 1−δ` 判 ambiguous，依赖似然校准；PACT 的歧义是**结构性的**：偏序下"第一违约"可能是一个反链，`|frontier|>1` 即歧义，不需要相信任何后验概率。

**灵感 5（两把钥匙与信任边界）**
直觉：物理动作需要两把钥匙同时转动：**语义钥匙**（指代被真实观测接地、计划在多模型/多视角下一致、置信足够）与**物理钥匙**（VISTA 证书、准入裕度、力/速度/工作空间包络都通过）。严格地说，这把"模型可信度"从执行前提降为**证据之一**；TCB（可信计算基）只包含 SCC/证书检查器/ROS 2 实时运行时/物理模型，VLA 明确在 TCB 之外。安全论证不再需要"VLA 足够准"，只需要"检查器正确 + 契约语言足够表达"。

**灵感 6（VISTA 组件的原位升级/重定位）**
- **FIR → CAD-Phys**：VISTA 归因只在某个契约内部、且接口证据已锁定该节点时启用；不再用它给整个开放世界做裁决。
- **CSC → RTA**：承诺单位从"块前缀 k 步"升级为"契约图 + 期限链 + 准入前缀"；不可逆视界 `m` 变成每个物理契约的属性。
- **APP/AFA/SCP → OSE**：探针目标从"故障假设互信息/能力区域信息"改为"**先澄清语义指代与规格，再决定是否值得物理探测**"；多数幻觉应在语义层被拒绝，而不是用物理试探去验真。
- **RSC-V → RSC-P**：不确定球增加 `r_spec`（契约/规格外）与 `r_intent`（意图歧义）；接口违约只膨胀对应分量，规格缺口只膨胀 `r_spec`，不误伤几何/力。
- **WCV-V → WCV-P**：搜索域增加"契约可行域"与"QoS 可满足域"。
- **CSP-V → CAG/TSL-P**：计划单位从"技能/块"提升为"契约子图"，每条边必须带契约且可准入。
- **AIC-V → AIC-P**：干扰集从视觉/时序扩到语义（提示注入、指代替换、幻觉）、OS（节点崩溃、资源饥饿、lifecycle 竞态）、网络（DDS 分区、乱序、重复、QoS 不匹配）、时钟（skew）。
- **J_vista → J_pact**：证书增 `contract_hash`、`violation_frontier`、`deadline_slack`、`qos_profile`、`authority_scope`、`spec_gap_alarm`、`replay_id`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（PACT 闭环）**：PACT = (GRIP, VISTA, SPA, SCC, CAG, CAD, RTA, QCL, ISO, OSE, EAR, AIC-P, J_pact)。定位：VISTA 的"接口化 + 分布式问责"升级。不变式：**语义提议、契约编译、规格校准、反事实重放只在语义流/低频线程；实时流只做 QoS/期限检查、两把钥匙判定、准入前缀执行、隔离监督与早停，零学习写操作。VLA 永远不直接写执行器。**
- **定义 234（语义提议图 SPA）**：VLA 输出 P_t = (E, R, S, Π, u)，E 为候选实体/区域，R 为指代关系（语言指代 → 观测/帧/物体 id），S 为技能/子任务序列，Π 为自然语言理由与前提，u 为逐项置信/多模型一致性。SPA 只是**提议**，无执行语义；任何未被接地的实体只能出现在"待澄清"集合，不得进入契约。
- **定义 235（动作契约）**：一个动作契约 c = (Pre, Post, T, Res, Auth, Φ, Abort, m)：
  - Pre/Post 为带类型的状态谓词（含 TF 帧、物体 id、模式、夹持状态）；
  - T = (period, deadline, jitter, freshness) 为时间契约；
  - Res = (cpu, mem, dds_bw, energy) 为资源契约；
  - Auth ⊆ 2^{命令类} 为权限/作用域（SROS2）；
  - Φ 为物理包络（力/力矩/速度/工作空间/形变/碰撞距离）；
  - Abort 为实时中止谓词；m 为不可逆视界。
  契约是**可检查的承诺**，不是代码：检查器只依赖类型、时间戳、资源账本与物理模型。
- **定义 236（契约代数与契约图 CAG）**：串行 `c1∘c2` 要求 `Post1 ⇒ Pre2`（或存在显式适配器），期限为 `d1+d2+d_handoff`，资源按序累加，权限取交，物理包络需保持不变式；并行 `c1∥c2` 要求资源和不超配额、权限不冲突、包络互不侵入，期限取 max。契约图 CAG=(V_c,E_c) 是 DAG，每条路径有累计期限/资源/包络预算；**可准入（admissible）** 当且仅当所有路径预算不超上限且物理包络不变式可满足。
- **定义 237（契约精化与跨体可移植性）**：`c' ⊑ c`（c' 精化 c）当且仅当 `Pre' ⇒ Pre`、`Post' ⇒ Post`、`T'` 更紧、`Res'` 更小、`Auth' ⊆ Auth`、`Φ' ⊆ Φ`。同一 VLA 的语义提议可跨机器人复用，但物理契约必须按本体/执行器重新实例化；**语义可移植 ≠ 物理可移植**，负面迁移由两把钥匙拦截。
- **定义 238（语义-契约编译 SCC 与接地）**：编译函数 `SCC: SPA × O × K → CAG ∪ {reject, clarify}`，O 为本体/场景图，K 为契约库。接地 `γ: E → 观测实体`（TF 帧、分割 id、物体记忆），只有 `γ` 有唯一且新鲜的支撑时才生成物理契约；否则输出 `clarify`/`reject`，**绝不"猜一个最近的物体"**。编译器对每条契约附来源指针（提议节点 → 本体条目 → 传感器观测），构成可审计证据链。
- **定义 239（接口违约模式与表现闭集）**：违约模式集
  `V = {V_type, V_referent, V_grounding, V_temporal, V_resource, V_authority, V_qos, V_physical, V_consistency, V_liveness}`。
  它们是接口可观测的、构造性有限的。**表现闭集命题**：任何通过 ROS 图影响物理世界的偏差，若违反声明规格，则必在某个接口上产生 V 中某类违约；否则即为**规格缺口**（定义 246）。注意这不是"原因闭集"，而是"表现闭集"。
- **定义 240（因果归因与违约前沿 CAD）**：执行轨迹 τ 带每事件的分布式逻辑时钟/时间戳。定义 happens-before `≺`；违约事件集 `F(τ)={e: e 违反某契约}`。**第一违约前沿** `F* = {e ∈ F : ¬∃e' ∈ F, e' ≺ e}`。若 `F*` 为单点则唯一归因到该节点/边；若 `F*` 为反链且 `|F*|>1` 则输出 **blame frontier** 与 `ambiguous=True`（结构性歧义）；若 `F=∅` 但规格被违反，则输出 `spec_gap`。归因不依赖任何故障假设后验。
- **定义 241（实时准入 RTA）**：对 CAG 做响应时间分析：对每条路径 `π`，`R_π = Σ_{c∈π} WCET_c + Σ jitter + handoff`，要求 `R_π ≤ deadline_π`；WCET 用按契约分层的 split-conformal 上界 `q_cpu(α_time, c)`，VLA 推理用 anytime 机制（超时即回退到缓存/保守提议）。资源账本 `Σ Res ≤ cap`；物理包络需在路径上保持不变式。准入输出 `admitted_prefix(CAG*)` 与每步 `slack`；`slack<0` 即拒绝或降级，而不是"先跑跑看"。
- **定义 242（QoS 契约层 QCL）**：每条边绑定 QoS 配置 `q=(reliability, durability, history, depth, deadline, lifespan, liveliness)`。定义兼容关系 `q_prod ⊒ q_cons`；不兼容、deadline 超期、lifespan 过期（陈旧 TF/传感器）、liveliness 丢失分别映射到 `V_qos / V_temporal / V_liveness`。**"数据到了"不再是默认真值，"数据在契约时限内且新鲜"才是。**
- **定义 243（隔离与生命周期监督 ISO）**：每个契约子图运行在被监督的 component container / lifecycle node 中，带 CPU/内存/DDS 配额与 SROS2 权限作用域；lifecycle 状态机 `configure→activate→deactivate→cleanup→finalized` 与契约状态绑定。节点崩溃、资源饥饿、状态竞态在**进程/容器边界**被捕获并映射为 `V_liveness/V_resource`，不污染物理归因。
- **定义 244（两把钥匙执行准则）**：物理动作 `a` 仅当
  `K_sem(a) = grounded(a) ∧ consistent(a) ∧ (u(a) ≥ u_min) ∧ ¬ambiguous_intent(a)`
  与
  `K_phys(a) = Valid(J_vista) ∧ admitted(a) ∧ envelope_ok(a)`
  同时为真才执行；任一为假则进入回退阶梯。语义钥匙与物理钥匙的证据来源、失效模式、更新频率被显式分离。
- **定义 245（开集语义升级 OSE）**：当 `SCC` 输出 `clarify/reject`、SPA 指代不唯一、或 `spec_gap` 触发时，按阶梯升级：重新观测/换视角 → 语言澄清 → 请求人类确认 → 安全空闲/遥操作；**物理探针是最后手段**，且必须先通过语义钥匙的"值得探"判定。幻觉不应用物理接触来"验真"。
- **定义 246（契约校准与规格缺口 CCM）**：用执行/裁判/人工反馈校准每条契约的违约率与 WCET 分位数（版本化 `ver`）；定义**规格缺口告警**：若发生安全相关或意图相关事件而 `F=∅`，记一次 spec gap，要求新增/收紧契约或本体。证书报告 `spec_gap_rate`，未覆盖区域标 `unverified`。**一个从未被违约检验过的契约，和一张从未被执行的证书一样，是空洞的。**
- **定义 247（AIC-P 语义/时序/OS/网络对抗认证）**：干扰集
  `ℰ_P = ℰ_V × ℰ_sem × ℰ_time × ℰ_os × ℰ_net`。
  `ℰ_sem` 含提示注入（场景文字/指令注入）、指代替换、幻觉物体、开放词表漂移；`ℰ_time` 含 VLA 延迟尖峰、抖动、陈旧数据、时钟偏移；`ℰ_os` 含节点崩溃、资源饥饿、lifecycle 竞态、权限误配；`ℰ_net` 含 DDS 分区、乱序、重复、QoS 不匹配。认证对象从"物理安全"扩为"**接口问责是否仍成立**"：在最坏干扰下要求 first-violation 仍可定位或显式 `ambiguous/spec_gap`。
- **定义 248（J_pact 证书与闭环算子）**：J_pact = (J_vista, contract_hash, cag_version, violation_frontier, deadline_slack, qos_profile, authority_scope, grounding_hash, spec_gap_alarm, replay_id, aic_p_ver)。Valid ⇔ Valid(J_vista) ∧ 所有物理动作两把钥匙通过 ∧ (first-violation 唯一 ∨ 显式 ambiguous) ∧ (F=∅ 时显式检查 spec gap) ∧ 审计可重放。语义流：[VLA→SPA→SCC→CAG→RTA→OSE/CCM→AIC-P]；实时流：[QoS/期限检查→两把钥匙→准入前缀执行→ISO 监督→CAD 采集→J_pact]。

## 2. 关键算法骨架

```python
# SCC：把「提议」编译成「可检查的契约」，接不上就拒绝/澄清
prop = vla.propose(instruction, img, depth, scene_graph)      # SPA
cag, why = scc.compile(prop, ontology, contract_lib)
if cag is None:                                               # ungrounded/ambiguous
    return ose.escalate(prop, why)                             # 先澄清，不动手

# RTA：先问「来不来得及、包络够不够」，再允许执行
adm = rta.admit(cag, wcet=q_cpu(alpha_time), qos=qcl.check(cag.edges))
if not adm.ok:
    cag = rta.downgrade(cag)                                  # 缩短/分解/回退
    if cag is None:
        return ose.escalate(prop, 'infeasible_deadline')

# 两把钥匙 + 执行 + 接口归因
for c in adm.prefix:
    if not (semantic_key(c, prop) and physical_key(c, vista_cert, qcl)):
        return fallback_ladder(c)
    dispatch_isolated(c)                                      # ISO/SROS2/QoS
    if rta.monitor(c).deadline_miss or qcl.stale(c):
        break

# CAD：找第一条违约边；找不到违约但规格被违反 -> 规格缺口
frontier, status = cad.attribute(trace, contracts=cag)
if status == 'ambiguous':
    ose.clarify_or_idle(frontier)
elif status == 'spec_gap':
    ccm.record_gap(trace); ose.escalate(trace, 'spec_gap')
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（表现闭集的相对完备性）**：若契约集 C 对声明规格 S 是**可靠的**（凡满足全部契约的物理轨迹都满足 S），则任何违反 S 的物理偏差要么在某个接口上产生 V 中违约，要么是 S 未被 C 表达的**规格缺口**。故"接口问责"相对声明规格是完备的，且不完备性被显式命名为 spec gap，而不是伪装成归因。证明只需逆否：无违约且违反 S ⇒ C 不可靠 ⇒ 规格缺口。
- **引理 10（违约前沿的结构唯一性）**：在带 happens-before 的因果图上，第一违约前沿 `F*` 是一个反链；若执行轨迹存在全序时间戳且违约判定确定，则 `|F*|=1`，归因唯一；歧义当且仅当 `|F*|>1`。因此 ambiguous 是**结构性可检测**的，不依赖后验校准（对比 VISTA 的 `δ_fi` 阈值）。
- **定理 12（准入的执行安全）**：若 (a) WCET 上界以 conformal 覆盖 ≥1−α_time，(b) CAG 在固定优先级/EDF 下响应时间 ≤ 期限，(c) 物理包络与 VISTA 证书在支持集上成立，则被执行前缀满足实时期限与物理安全，失败概率 ≤ α_time + α_phys + α_qos；VLA 延迟尖峰被 anytime 回退吸收，不阻塞控制环。
- **定理 13（两把钥匙的故障域上界）**：设语义钥匙失效概率 p_s、物理钥匙 p_p、共因耦合 ρ。若两把钥匙的失效机制可分离，则不安全执行概率 ≤ p_s·p_p + ρ。关键不在乘积，而在 ρ：**若两把钥匙共享同一相机/同一 VLM，则 ρ 主导，独立性论证失效**；故物理钥匙必须包含至少一个非视觉通道（本体感觉/电流/保险杠），否则两把钥匙退化为一把。
- **定理 14（契约精化下的跨体安全迁移）**：若目标机器人的契约 `c'_j ⊑ c_j` 对所有物理契约成立，且语义提议图不变，则同一 VLA 在目标本体上的执行安全由目标物理钥匙保证；反之，未经精化的直接迁移可能通过语义钥匙但违反 `Φ'`，被准入拒绝。这给出"语义可复用、物理必须重校准"的形式理由。
- **实时性**：VLA/SPA/SCC/CAG/RTA 规划/OSE/CCM/AIC-P 全在语义流；实时流只做 QoS/新鲜度检查（<0.05ms）、两把钥匙查表（<0.02ms）、期限/资源监视（<0.03ms）、CAD 事件采集（<0.02ms）与 VISTA 实时层（≈2.5ms），目标 ≤3ms。

## 2. 形式化定义（完整版）

**定义 233（PACT 闭环）** PACT 是 VISTA 的「接口化 + 分布式问责」升级：在 VISTA 的语义流/实时流骨架前挂载 SPA/SCC/CAG，横切 RTA/QCL/ISO/CAD/OSE/CCM/EAR，并原位升级 FIR→CAD-Phys、CSC→RTA、APP/AFA→OSE、RSC-V→RSC-P、WCV-V→WCV-P、CSP-V→CAG、AIC-V→AIC-P、J_vista→J_pact。不变式：
1. **VLA 不直接写执行器**：只有通过 SCC 编译、RTA 准入、两把钥匙判定后的契约才能派发；
2. **语义提议、契约编译、规格校准、反事实重放只在语义流/低频线程**；
3. **实时流只做 QoS/期限检查、两把钥匙查表、准入前缀执行、隔离监督、早停与违约事件采集，零学习写操作**；
4. **任何未接地或规格外的事件必须显式标 `clarify / ambiguous / spec_gap`，不得静默执行或强行归因**。

**定义 234（语义提议图 SPA）** VLA 输出
`P_t = (E, R, S, Π, u)`，
其中 E 为候选实体/区域（开放词表），R 为语言指代到观测的候选关系 `r=(mention, candidate, score)`，S 为技能/子任务序列（含自然语言前提与效果），Π 为理由/计划文本，u 为逐项置信与多模型/多视角一致性。SPA 的语义是「提议」：
- 不产生话题、不写 action goal、不改变 TF；
- 每个实体带 `grounded / ambiguous / ungrounded` 三态；
- 每个技能带 `pre/post` 的自然语言版本，等待 SCC 将其类型化。
SPA 是**可审计的证据**而非命令：它使 VLA 的错误停留在语义层，而不是变成电机电流。

**定义 235（动作契约）** 一个物理动作契约
`c = (Pre, Post, T, Res, Auth, Φ, Abort, m)`：
- `Pre, Post`：带类型的状态谓词，状态变量取自 `(TF 帧, 物体 id, 夹持状态, 模式, 场景图节点)`；类型系统保证不可把「杯子」接到「夹具闭合」谓词上；
- `T = (period, deadline, jitter, freshness)`：周期、相对/绝对期限、允许抖动、数据最大年龄；
- `Res = (cpu, mem, dds_bw, energy)`：资源账本；
- `Auth ⊆ 2^{命令类}`：该契约被允许发出的命令类（速度/力矩/夹爪/导航目标），与 SROS2 权限一致；
- `Φ`：物理包络，含力/力矩/速度/工作空间/形变/最小碰撞距离；
- `Abort`：实时中止谓词（超力、滑移、超时、越界、QoS 失效）；
- `m`：不可逆视界（越过该视界后故障不可恢复）。
**良构性**：`Pre`/`Post` 类型可检查、`Φ` 可在机载物理模型下求值、`Abort` 只依赖实时可读信号、`m` 有限且由停止距离/力限反解。

**定义 236（契约代数与契约图 CAG）** 组合规则：
- **串行** `c1∘c2`：定义当且仅当 `Post1 ⇒ Pre2` 或存在显式适配器 `A: Post1→Pre2`；`T_12 = (period, d1+d2+d_handoff, jitter1+jitter2, min(freshness1,freshness2))`；`Res_12 = Res1+Res2`（按保守上界）；`Auth_12 = Auth1∩Auth2`；`Φ_12` 需路径不变式（例如搬运时夹持力下界）。
- **并行** `c1∥c2`：定义当且仅当 `Res1+Res2 ≤ cap`、`Auth1∩Auth2=∅` 或命令类不冲突、`Φ1` 与 `Φ2` 的可行域交非空且不发生碰撞；期限取 `max(d1,d2)`。
- **选择** `c1⊕c2`：语义流中二选一，准入时分别计算，运行时不得同时激活。
契约图 `CAG=(V_c,E_c)` 是 DAG；对每条源到汇路径 π，定义期限预算 `D_π`、资源账本 `R_π`、包络不变式 `I_π`。**可准入**：
`admissible(CAG) ⇔ ∀π: R_π ≤ D_π ∧ Res_π ≤ cap ∧ I_π 可满足 ∧ Auth_π 合法`。
CAG 是 PACT 的「安全 IR」：VLA 可以生成任意提议，但只有能编译成 admissible CAG 的提议才有资格接近物理世界。

**定义 237（契约精化与跨体可移植性）** 定义 `c' ⊑ c` 当且仅当
`Pre' ⇒ Pre`，`Post ⇒ Post'`，`T'` 各项更紧（更短期限、更小抖动、更严新鲜度），`Res' ≤ Res`，`Auth' ⊆ Auth`，`Φ' ⊆ Φ`，`m' ≤ m`。
精化是偏序。语义提议图 `P_t` 与本体无关，可跨机器人复用；但物理契约依赖 URDF、执行器、力限与标定。若目标机器人上的契约 `c'_j ⊑ c_j` 对所有 j 成立，则同一语义提议在目标本体上的安全由目标物理钥匙保证（定理 14）；若只有语义相同而 `Φ' ⊄ Φ`，准入必须拒绝——**语义可移植不等于物理可移植**。

**定义 238（语义-契约编译 SCC 与接地）** 编译器
`SCC: (P_t, O, K) → CAG ∪ {reject(r), clarify(q)}`，
O 为版本化本体/场景图，K 为契约库。对每个提议实体 e，接地 `γ(e)` 必须满足：
1. **存在性**：γ(e) 对应一个当前被传感器/记忆支撑的实体 id；
2. **唯一性**：在容差内只有一个候选，或歧义被显式标注；
3. **新鲜性**：支撑观测年龄 ≤ freshness；
4. **类型一致**：本体类型与契约 `Pre` 的类型匹配。
任一不满足则不生成物理契约：无支撑→`reject(V_referent/V_grounding)`；多候选/指令歧义→`clarify(V_consistency)`。**绝不使用"最近邻猜测"把未接地实体硬接到某个物体**。每条契约保留证据链 `(提议节点 → 本体条目 → 观测 id → 时间戳)`，写入 `grounding_hash`，供 EAR 重放与 CAD 问责。

**定义 239（接口违约模式与表现闭集）** 违约模式集
`V = {V_type, V_referent, V_grounding, V_temporal, V_resource, V_authority, V_qos, V_physical, V_consistency, V_liveness}`。
| 模式 | 接口可观测量 | 典型 ROS 2 信号 |
|---|---|---|
| `V_type` | 消息/参数/谓词类型不匹配 | 话题类型、action schema、参数类型 |
| `V_referent` | 指代对象不存在/已消失 | 场景图 id、分割掩码、物体记忆 |
| `V_grounding` | 存在但不唯一/不新鲜/坐标错帧 | TF2 查询、时间戳、frame_id |
| `V_temporal` | 超过 deadline/jitter/freshness | executor 统计、header.stamp、lifespan |
| `V_resource` | CPU/内存/DDS 带宽/能量超配额 | 容器 cgroup、DDS 统计、电量 |
| `V_authority` | 未授权命令类/越权节点 | SROS2 权限、节点身份 |
| `V_qos` | QoS 不兼容/可靠性/持久性不符 | QoS 兼容性检查、丢包/重复计数 |
| `V_physical` | 力/速度/工作空间/形变越界 | F/T、关节限位、电流、碰撞距离 |
| `V_consistency` | 计划/多模型/多视角不一致 | 多 VLA 采样、跨视角几何、语义冲突 |
| `V_liveness` | 节点失活/心跳丢失/生命周期竞态 | lifecycle 状态、liveliness、心跳 |
**表现闭集命题（非原因闭集）**：任何通过 ROS 图影响物理世界的偏差，若违反声明规格 S，则必在某个接口产生 V 中某类违约；否则即为规格缺口。V 的有限性来自接口类型的构造，而非对世界失效方式的穷举。

**定义 240（因果归因与违约前沿 CAD）** 执行轨迹 τ 是带时间戳与向量时钟的事件序列。定义 happens-before `≺`（同节点程序序 + 消息发送→接收 + 显式同步）。违约事件
`F(τ) = {e : e 违反某契约 c ∈ CAG}`。
**第一违约前沿**
`F* = {e ∈ F : ¬∃e' ∈ F, e' ≺ e}`。
归因规则：
- `|F*|=1`：唯一归因到该事件所在的节点/边；
- `|F*|>1` 且构成反链：输出 `blame_frontier` 与 `ambiguous=True`，进入 OSE 澄清/安全空闲；
- `F=∅` 但规格被违反：输出 `spec_gap`，进入 CCM 记录与契约扩充。
CAD 不使用 `P(H|ρ)`，因此不依赖似然校准；它把"谁坏了"变成"哪条边先违约"，把"未知原因"变成"结构性歧义或规格缺口"。

**定义 241（实时准入 RTA）** 对 CAG 的每条路径 π，用响应时间分析：
`R_π = Σ_{c∈π} WCET_c + Σ_{c∈π} jitter_c + Σ handoff`，
要求 `R_π ≤ deadline_π`。`WCET_c` 用按契约类型/输入规模分层的 split-conformal 上界 `q_cpu(α_time,c)`，不假设高斯。VLA 推理采用 anytime：
- 在 `T_vla_max` 内返回当前最佳 SPA；
- 超时则回退到缓存提议或保守子图；
- 语义流可以慢，但**实时路径永远不等 VLA**。
准入输出 `admitted_prefix(CAG*)`、每步 `slack` 与 `qos_profile`；`slack<0` 或资源/包络不可满足即拒绝或降级到更短子图。粗粒度资源+期限联合优化在小图上用 ILP，大图上用保守 sufficient condition（EDF/固定优先级 + 资源账本）。

**定义 242（QoS 契约层 QCL）** 每条边绑定
`q = (reliability, durability, history, depth, deadline, lifespan, liveliness)`。
定义生产者/消费者兼容 `q_prod ⊒ q_cons`（至少一样可靠、一样持久、history 足够、deadline 不更松、lifespan 不更短、liveliness 不更弱）。检查：
- 不兼容 → `V_qos`；
- `header.stamp` 年龄 > lifespan/freshness → `V_temporal`；
- liveliness 丢失/心跳超时 → `V_liveness`；
- TF 链缺失/外推 → `V_grounding`。
**数据"到了"不是真值，"在契约时限内且新鲜"才是。**

**定义 243（隔离与生命周期监督 ISO）** 每个契约子图部署在被监督的 component container / lifecycle node 中：
- **状态机**：`configure → activate → deactivate → cleanup → finalized`，契约的 `Pre` 包含所需节点的状态；
- **配额**：cgroup CPU/内存、DDS 带宽/队列、能量预算；
- **权限**：SROS2 只授予契约 `Auth` 中的命令类与话题；
- **隔离不变式**：语义容器（VLA/规划）没有任何执行器话题的写权限；只有实时容器中的契约执行器能写 `cmd_*`。
节点崩溃、资源饥饿、状态竞态在进程/容器边界被捕获，映射为 `V_liveness/V_resource`，**不污染物理归因**。

**定义 244（两把钥匙执行准则）** 物理动作 a 仅当
`K_sem(a) = grounded(a) ∧ consistent(a) ∧ (u(a) ≥ u_min) ∧ ¬ambiguous_intent(a)`
且
`K_phys(a) = Valid(J_vista) ∧ admitted(a) ∧ envelope_ok(a)`
同时为真才执行。两把钥匙的**证据来源、更新频率、失效模式显式分离**：
- 语义钥匙来自 VLA 提议、多模型/多视角一致性、本体接地；
- 物理钥匙来自 VISTA 证书、RTA 准入、QCL、现场 F/T/本体感觉。
失败即走回退阶梯：`重观测 → 语言澄清 → 降级契约 → 安全空闲 → 求助人/遥操作`。两把钥匙不是两个独立传感器时，独立性论证失效（定理 13）。

**定义 245（开集语义升级 OSE）** 触发条件：`SCC` 返回 `reject/clarify`、指代不唯一、`V_consistency`、或 `spec_gap`。阶梯：
1. **重观测/换视角**（零接触，优先）；
2. **语言澄清**（问"你指的是左边的杯子还是右边？"）；
3. **请求人类确认**（高风险/低置信）；
4. **安全空闲/遥操作**；
5. **物理探针**（仅当语义钥匙判定"这个探测能区分两个真实假设"且 VISTA/包络允许；易损物体禁用接触探针）。
**幻觉不应用物理接触来验真**：用电机去验证语言模型的错误，是把语义错误升级为物理伤害。

**定义 246（契约校准与规格缺口 CCM）** 用执行日志、裁判（若存在）、人工反馈校准：
- 每条契约的违约率、WCET 分位数、QoS 超期率，版本化 `ver_c`；
- 外部校准误差 `ECE_c = |预测违约率 − 实测违约率|`；
- 未达 `n_min` 的契约标 `unverified`。
**规格缺口告警**：若发生安全相关或意图相关事件而 `F=∅`（没有契约被违反），记一次 `spec_gap`，要求新增/收紧契约、本体或 `Pre/Post`；`J_pact` 报告 `spec_gap_rate`。
**一个从未被违约检验过的契约，和一张从未被执行的证书一样，是空洞的。**

**定义 247（AIC-P 语义/时序/OS/网络对抗认证）** 干扰集
`ℰ_P = ℰ_V × ℰ_sem × ℰ_time × ℰ_os × ℰ_net`：
- `ℰ_sem`：场景文字/指令提示注入、指代替换（把"杯子"接到"玻璃瓶"）、幻觉物体、开放词表漂移、意图反转；
- `ℰ_time`：VLA 延迟尖峰、executor 抖动、陈旧 TF/图像、时钟偏移；
- `ℰ_os`：节点崩溃、内存/CPU 饥饿、lifecycle 竞态、SROS2 权限误配；
- `ℰ_net`：DDS 分区、乱序、重复、QoS 不匹配、带宽挤压。
认证对象从"物理安全"扩为"**接口问责是否仍成立**"：在最坏干扰下要求 (i) first-violation 仍可定位，或 (ii) 显式 `ambiguous/spec_gap` 并安全降级。`ρ_dir` 在 `ℰ_P` 上重算，`n_cert` 由 128 增至 176（其中 48 给语义/OS/网络/时钟）。**共因故障下不要求归因正确，只要求不冒充归因、能安全降级。**

**定义 248（J_pact 证书与 PACT 闭环算子）**
`J_pact = (J_vista, contract_hash, cag_version, violation_frontier, deadline_slack, qos_profile, authority_scope, grounding_hash, spec_gap_alarm, replay_id, aic_p_ver)`。
`Valid(J_pact) ⇔`
1. `Valid(J_vista)`（物理层）；
2. 所有被执行的物理动作满足 `K_sem ∧ K_phys`；
3. `|F*|=1` 或显式 `ambiguous=True` 并已进入 OSE；
4. 若 `F=∅`，已执行 spec gap 检查且 `spec_gap_alarm` 被正确置位/清零；
5. 契约、QoS、权限、接地证据链版本一致，且 `replay_id` 可由 rosbag2 复现；
6. `aic_p_ver` 为当前版本。
语义流：[VLA→SPA→SCC→CAG→RTA→OSE/CCM→AIC-P]；实时流：[QoS/期限检查→两把钥匙→准入前缀执行→ISO 监督→CAD 事件采集→J_pact]。

class ContractCompiler:
    def compile(self, prop, ontology, contract_lib):
        evidence, contracts = [], []
        for e in prop.E:
            g, why = self.ground(e, ontology)          # γ: 存在/唯一/新鲜/类型
            if g.status == 'absent':
                return None, ('reject', 'V_referent', why)
            if g.status == 'ambiguous':
                return None, ('clarify', 'V_consistency', why)
            if not g.fresh:
                return None, ('clarify', 'V_grounding', why)
            evidence.append((e, g.id, g.stamp))
        for s in prop.S:
            c = contract_lib.instantiate(s, evidence, prop.u)
            if c is None:
                return None, ('reject', 'V_type', 'no well-typed contract')
            contracts.append(c)
        cag = ContractGraph.compose(contracts, prop.R)  # Pre/Post 适配 + 路径预算
        if not cag.well_formed:
            return None, ('reject', 'V_type', cag.why)
        return cag.with_evidence(evidence), ('ok', None, None)

    def ground(self, e, ontology):
        cands = ontology.match(e, tol=TAU_MATCH, max_age=FRESH)
        if not cands:
            return Grounding('absent'), 'no observed referent'
        if len(cands) > 1 and margin(cands) < TAU_UNIQUE:
            return Grounding('ambiguous', cands), 'multiple referents'
        return Grounding('ok', cands[0].id, cands[0].stamp,
                         fresh=(now() - cands[0].stamp) <= FRESH), ''
```

### IP-226/228/229 CAG + RTA + QCL（能不能做、来不来得及）

class ContractGraph:
    def path_budgets(self):
        # DAG：累计 WCET/jitter/资源，检查包络不变式
        for pi in self.source_to_sink_paths():
            yield pi, sum_wcet(pi), sum_jitter(pi), sum_res(pi), envelope_inv(pi)

    def well_formed(self):
        return all(post_implies(pre) for pre, post in self.adjacent_predicates())


def admit(cag, q_cpu, caps, alpha_time):
    for pi, wcet_ub, jitter, res, env in cag.path_budgets():
        R_pi = wcet_ub + jitter + HANDOFF
        if R_pi > pi.deadline:            return Admission(False, 'V_temporal', slack=R_pi - pi.deadline)
        if not res <= caps:               return Admission(False, 'V_resource', slack=0)
        if not env.satisfiable:           return Admission(False, 'V_physical', slack=0)
    for edge in cag.edges:
        if not qos_compatible(edge.q_prod, edge.q_cons):
            return Admission(False, 'V_qos', slack=0)
    return Admission(True, None, slack=min_deadline_slack(cag))


class QoSContractLayer:
    def check_edge(self, edge, last_stamp, now):
        if not compatible(edge.q_prod, edge.q_cons):
            return 'V_qos'
        if now - last_stamp > edge.q.lifespan:
            return 'V_temporal'            # 数据在但已过期
        if not edge.liveliness_ok(now):
            return 'V_liveness'
        return None
```

## 4. 推导

**引理 9（表现闭集的相对完备性）** 设契约集 C 对声明规格 S 可靠：凡满足 C 全部契约的物理轨迹都满足 S。则任何违反 S 的物理轨迹 τ，要么存在 `e∈F(τ)`（某契约被违反），要么 S 未被 C 表达（规格缺口）。
**证明**：反设 τ 违反 S 且 F(τ)=∅。由 F=∅，τ 满足 C 中每条契约；由 C 对 S 可靠，τ 满足 S，矛盾。故若 τ 违反 S 而 F=∅，只能是"可靠"前提不成立，即存在 S 要求但 C 未表达的行为——按定义即规格缺口。∎
**推论**：接口问责相对**声明规格**是完备的；它不能相对"真实意图"完备，因为意图不是契约语言中的符号。这一不完备性被 `spec_gap` 显式暴露，而不是被归因掩盖。

**引理 10（违约前沿的结构唯一性）** 在带 happens-before 的因果图上，`F*` 是反链；若轨迹存在与 `≺` 一致的全序且违约判定确定，则 `|F*|=1`，归因唯一；歧义当且仅当 `|F*|>1`。
**证明**：若 e1,e2∈F* 且 e1≺e2，则 e2 不满足"无前驱违约"，矛盾，故 F* 中任意两点不可比，即反链。若全序，反链至多一个元素；F 非空故恰一个。若 |F*|>1，则存在不可比的两个第一违约，无法在偏序下判定谁先，故歧义。∎
**与 VISTA 的对比**：VISTA 的 ambiguous 依赖 `max_H P(H|ρ)<1−δ_fi`，需要似然 `p(ρ|H)` 校准正确；PACT 的 ambiguous 只依赖违约谓词与 happens-before，**不依赖故障假设后验**。代价是它只能定位"哪个接口先坏"，不能告诉你"为什么坏"——后者交给契约内部的 VISTA 与 EAR 反事实重放。

**定理 12（准入的执行安全）** 若 (a) 每个契约的 WCET 上界 `q_cpu(α_time,c)` 以 ≥1−α_time 覆盖真实执行时间；(b) CAG 在给定调度下所有路径响应时间 `R_π≤deadline_π`；(c) 物理包络 `Φ` 与 VISTA 支持集证书成立（覆盖 ≥1−α_phys）；(d) QoS 新鲜性/兼容性以 ≥1−α_qos 成立，则执行准入前缀期间控制环 deadline miss 与物理越界概率 ≤ α_time+α_phys+α_qos。
**证明**：在 (a)(b) 下，实时调度可行性由响应时间分析保证（标准结果：若所有任务的最坏响应时间不超过期限，则固定优先级/EDF 调度可行）；(c)(d) 分别保证物理包络与数据新鲜性。三类保证各自可能失效，按联合界相加即得。VLA 延迟不在实时路径上：anytime 机制在 `T_vla_max` 超时后回退，故不进入该界的计算。∎
**注意**：该定理不保证"语义正确"，只保证"被准入的执行在时间与物理包络上安全"；语义正确性由两把钥匙的语义侧与 spec gap 机制处理，且**不可被形式保证**（命题 11）。

**定理 13（两把钥匙的故障域上界）** 设语义钥匙失效概率 `p_s`、物理钥匙失效概率 `p_p`、共因耦合项 `ρ = P(K_sem 与 K_phys 同时失效 | 共用证据源)`。则不安全执行概率
`P_unsafe ≤ p_s·p_p + ρ`。
当两把钥匙共享同一相机或同一 VLM 时，`ρ` 不可忽略，独立性论证失效；此时必须有至少一个非视觉物理通道（关节电流/本体感觉/保险杠/力矩突变）进入 `K_phys`，否则两把钥匙退化为一把。
**证明**：由全概率公式，`P_unsafe = P(K_sem fail ∧ K_phys fail)`；在条件独立下为 `p_s p_p`，一般情形加上共因项 `ρ`。共享证据源使两次失效强相关，`ρ` 可接近 `min(p_s,p_p)`，乘积界失效。∎
**实践含义**：PACT 不宣称"VLA 与控制器独立"，而是把独立性作为**可检验的工程假设**：若 E245 显示共因主导，则必须引入非视觉通道或降级为单钥匙 + 更保守包络。

**定理 14（契约精化下的跨体安全迁移）** 若目标本体上每条物理契约 `c'_j ⊑ c_j`，且语义提议图不变，则源本体上成立的物理安全在目标本体上由目标 `K_phys` 保证；若仅语义相同而 `Φ' ⊄ Φ`，则准入必拒绝该动作。
**证明**：由精化定义，`Pre'⇒Pre`、`Φ'⊆Φ`、`T'` 更紧、`Res'≤Res`、`Auth'⊆Auth`。源本体的安全前提在目标上被更强的前置/更小的包络/更紧的期限所蕴含；准入检查 `admitted` 与 `envelope_ok` 直接使用 `Φ'`，若 `Φ'⊄Φ`，则存在允许的力/速度超出源包络，准入拒绝。∎
**推论**：VLA 的语义可跨体复用，物理契约必须按本体重新实例化与校准；这为"通用操作 = 语义复用 + 物理重校准"提供了形式边界。

**命题 11（意图不可由接口完全表达）** 对任何有限契约语言 L 与开放语义的意图规格 S_intent，存在一个语义相关的偏差 τ，它满足 L 中所有可表达契约，却违反 S_intent；因此接口问责不能替代意图对齐，只能把意图错误显式命名为 spec gap。
**证明要点**：L 的符号集有限，而自然语言/开放场景的意图区分（例如"拿杯子"是指"喝水"还是"递给别人"）可构造任意细分的等价类；取一个 L 无法区分的等价类中的两个意图，构造在两者下接口行为相同、但仅其一流行的轨迹。该轨迹不违反任何 L-契约，却违反 S_intent。∎
**这不是缺陷，而是边界**：PACT 的价值在于**不把这种错误伪装成"几何故障"或"力偏置"**，而是让 `spec_gap` 成为一等公民，推动契约/本体/澄清机制的迭代。

**命题 12（结构性歧义与统计歧义的差异）** CAD 的 `ambiguous` 由 `|F*|>1` 决定，不随先验/似然/阈值变化；VISTA 的 `ambiguous` 由后验集中度决定，可因错误的似然校准而"自信地错误归因"。因此 PACT 把"歧义检测"的可靠性从模型校准转移到图结构与违约谓词上。
**证明要点**：`F*` 只依赖事件偏序与契约谓词的布尔结果；后验 `P(H|ρ)` 依赖 `p(ρ|H)` 的离线拟合与 `δ_fi`。前者是组合/序结构，后者是统计估计。故在 `p(ρ|H)` 错配时 VISTA 可给出高置信错误归因，而 CAD 的歧义判定不受影响。∎
**代价**：CAD 只能给出 blame frontier，不能给出"根因解释"；解释需结合 EAR 反事实重放与契约内部 VISTA。**问责与解释被有意分离。**

**正确性定理（PACT-Complete）** 见引理 9–10、定理 12–14、命题 11–12。核心是：
1. **接口问责相对声明规格完备**（引理 9），不 complete 的部分被命名为 spec gap；
2. **歧义结构性可检测**（引理 10），不依赖后验校准；
3. **准入保证时间/物理安全**（定理 12），但明确不保证语义；
4. **两把钥匙的独立性是可检验假设**（定理 13），不是宣称；
5. **语义可移植、物理须精化**（定理 14），否定"一个 VLA 直接驱动所有机器人"的朴素通用性。

## 8. 已知风险

**一句话**：PACT 的全部安全性都落在"契约语言能表达所有会伤人的语义要求"这一隐含前提上——ROS 只能强制执行被写成契约的东西，VLA 却可以在**类型正确、按时、力限合规、指代也确实存在**的情况下自信地做错事（拿错那个"合法存在"的物体、执行一个语法正确但意图相反的步骤），此时两把钥匙同时通过、归因会精确地 blame 一个完全健康的节点，系统得到的是"**接口完美、意图错误**"的证书剧场；这是本轮表现闭集、准入与两把钥匙论证共同依赖的隐藏假设（A94），也是"语义开放"必须付出的真正代价。

**次级风险与缓解**：
1. **规格语言表达力不足（头号）**：意图/语用/社会规范难以类型化；缓解：`spec_gap` 一等公民 + 版本化契约/本体 + 人工澄清 + 用失败案例驱动契约扩充；永不宣称"意图安全"，只宣称"接口问责 + 显式缺口"。
2. **两把钥匙共因失效**：共享相机/VLM 使语义与物理同错；缓解：`K_phys` 强制含非视觉通道（电流/本体感觉/保险杠）；AIC-P 显式建共因；共因下只要求安全降级与 `ambiguous`。
3. **接地错误仍可能"合法"**：本体把玻璃瓶误标为杯子，契约类型全通过；缓解：多视角/多模型一致性、物体记忆版本、人工抽检、把本体条目也纳入 ECE/spec gap 审计。
4. **WCET 上界与 VLA anytime 失准**：conformal 在分布漂移下覆盖下降；缓解：分层/分视界校准、在线漂移检测、超时回退、把 VLA 完全移出实时环。
5. **QoS/executor 语义在真实 DDS 实现中不完整**：不同中间件行为差异；缓解：在目标中间件上做一致性测试，把 QoS 不匹配当一等故障，保留保守超时。
6. **lifecycle/容器隔离有性能与状态机开销**：切换延迟、资源配额过紧；缓解：预配置热备节点、配额自适应、把语义容器与实时容器放到不同 CPU 核。
7. **反事实重放并非完全确定**：多线程 executor、DDS 乱序、时钟偏移；缓解：记录向量时钟与调度日志、必要时单线程回放、把重放一致性作为指标而非假设。
8. **契约图/准入组合爆炸**：多路径 × 多契约 × 资源约束；缓解：DAG 剪枝、只准入 top-k 子图、保守 sufficient condition、离线预编译常用子图。
9. **提示注入/场景文字攻击**：VLA 把环境文字当指令；缓解：指令来源白名单（SROS2/签名）、语言输入与场景文字分离、OSE 澄清、AIC-P 语义对抗集。
10. **组织/工程风险**：把安全责任过度外包给"检查器"；缓解：TCB 明确列出（SCC/checker/ROS 2 实时运行时/物理模型），VLA 明确在 TCB 外，审计链保留 `grounding_hash` 与 `contract_hash`，禁止用未校准契约做高风险动作。
