# 第 3 轮（灵感循环第 3 轮；接续状态文件中的第 2 轮；本轮灵感：「真实世界泛化」×「手眼标定」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），其下承
> 第 1 轮 **LeanGauge** 与 **MODGAUGE**。本轮纪律：**继续在前人基础上改进，而不是推倒重来**——
> 不改 MODGAUGE 五不变式、ToolGauge 的 6C 骨架、TB-Contract 与 50Hz 硬实时路径；

> 本轮把它**分解**为「可辨识的世界帧误差」与「局部的内容偏移」，并审计修复第 2 轮遗留的 9 处缺陷（§5）。

## 双灵感映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 手眼标定 | MP-Φ / AP-Cal：把整个环境偏移都塞进摊销后验 | **F-Box + HE-Cal + LCG**：把契约参数分解为共享帧 X∈G 与局部位 v_s，用 AX=XB 回路闭合在线辨识 X | 「手」与「眼」的未知相对位姿对所有盲区施加**同一个**偏差；不显式建模它，逐盲区数据再多也消不掉相关性 |
| 真实世界泛化 | 引理 47：TV(𝒟_dep,𝒟_env)≤η，η「不可消除」 | **帧-内容泛化分解**：η = η_frame(ε_F) ⊕ η_content(δ)；前者可辨识可归零，后者局部可摊销 | 真正不可消除的只有内容偏移；帧误差是低维、共享、可由主动运动辨识的结构化偏移，把它当噪声处理是把可解问题当不可解 |

**核心命题**：把 ToolGauge 的「语义假设 → 契约工具 → 摊销校准 → 交叉验证热替换」升级为
「**世界帧分解 → 修复即标定（AX=XB）→ 帧条件化等变校准 → 回路闭合无标签监控**」：
每个盲区修复事件同时是一次手眼标定事件；跨盲区共享的偏差被显式估计并从内容后验中剥离；
于是「局部修复、误差局部化」不再依赖「预训练分布 ≈ 部署分布」的强假设，而依赖一个
**可测量、可告警、可退化**的帧误差 ε_F。真实世界泛化因此从"更多域随机化"变成三件可审计的事：
ε_F（帧误差）、δ_s（内容偏移）、N_update（在线适应次数）。

**不变式保持声明**：
- MODGAUGE 五不变式、ToolGauge 的 6C 与退化链、TB-Contract 全部保留；
- 新增**内容局部性不变式 CLI**（定义 440）：帧校正后任意两盲区的后验相关性受 diam(G_F)·ε_F 上界约束；
- **退化链再延长**：FrameGauge 失效（帧不可辨识 μ_exc<μ_0 / SG-Monitor 判为内容漂移 / 帧更新越出信赖域 /
  CLI 违反）⇒ 退回 ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。**帧标定是增强项，不是依赖项**。

## 0. 直觉与动机

**灵感 1（手眼标定 → 把「共享偏差」从内容后验里拎出来）**
直觉：机器人里眼睛和手各说各话，二者之间的刚体变换 X 未知。你在每个任务上单独调参，X 的误差会在
每个任务上重复出现——而且**方向一致**。这正是第 2 轮最大风险（AP-Cal 跨盲区强相关系统性偏差）的
几何原型。手眼标定的解法不是"每个任务多采点"，而是**制造一对相关运动并强制 AX=XB**：让手和眼同时动，
用回路闭合把共享的 X 逼出来。映射到计量：盲区修复本来就要进入 PROBING 状态去探测（第 2 轮定义 430），
这些探测运动天然提供了 (A_i, B_i) 对。于是我们把"修复"改造成"**修复即标定**"（RAC）：
每个盲区顺带贡献若干手眼约束，跨盲区拼成帧图，用回路闭合在线辨识 X。修复不再是纯成本，而是标定数据源。

**灵感 2（真实世界泛化 → 偏移的结构化分解，而非一个标量 η）**
直觉：域随机化把"真实世界"当成一个巨大而扁平的分布，于是 sim2real 只能靠"覆盖更多"。但真实部署中的
主要偏移是**低维且结构化**的：相机外参漂移、机械臂零点误差、温漂引起的几何变化、光度增益漂移——
它们都属于一个低维李群 G，并且对所有盲区施加**同一个群作用**。真正的"内容"偏移（没见过的材质、
光照、杂物）才是高维局部的。引入手眼标定后，泛化界从
「2η + 元项」（η 在高维下≈1，界空谈）变成
「L·L_F·ε_F + L·δ_v + 元项」：第一项由回路闭合压到可测的 ε_F，第二项逐盲区局部摊销，第三项由第 2 轮
引理 47 管。**框架把"不可消除的 η"拆成"可消除的帧项 + 可局部化的内容项"**，这是本轮最实质的理论推进。
把它读成因果语言：帧 X 是** nuisance**，内容 v_s 是**不变机制**；好的泛化 = 对 nuisance 等变、对机制不变。

**灵感 3（泛化 = 等变 + 自适应，而不是更多预训练）**
若工具契约与校准对 G 等变（定义 441），则在规范帧学到的先验可被 X̂ **搬运**到任意新位姿，无需为每个
位姿重训；这就是"用对称性买泛化"（引理 55）。在时间维度上，把内容先验存于规范帧 + 在线帧滤波
（定义 444），使温漂/长期漂移更新帧时不发生灾难性遗忘。真实世界泛化因此不再是一次性的训练问题，
而是一个**持续辨识 nuisance、持续局部适应机制**的控制问题——这也让"退化链"第一次有了明确的物理含义：
当帧不可辨识时，系统诚实地退回一个不假设帧结构的保守模型。

## 1. 形式化定义（增量：定义 432–446）

**定义 432（世界帧分解 WFD）** 设 G 为低维李群（主情形 G=SE(3)；可含光度子群 (ℝ⁺,×)），
X∈G 为「手（探测/执行）」与「眼（感知/验证）」之间的共享帧潜变量。契约参数分解为
`u_s = Φ_X(z_s) ⊕ v_s`，`Φ_X(z) := X·z`，
其中 z_s 为盲区 s 的名义几何/光度坐标，Φ_X 为 G 在参数空间上的作用，v_s∈ℝ^{d_v} 为局部内容残差；
X 的先验 `X_0 ~ 𝒩_G(X_factory, Σ_X)`。约束：`E[v_s]=0`（消除帧-内容之间的规范自由度，否则
u_s = Φ_X(z_s)+v_s 与 Φ_{Xg}(z_s)+(v_s−δ) 不可辨识）。v_s 的先验取 MP-Φ 在规范帧下的输出（定义 436）。

**定义 433（手眼约束对与残差）** 第 i 次探测产生 `(A_i,B_i)∈G×G`：A_i 为「手」的相对运动
（动作日志/proprioception 给出），B_i 为「眼」的相对运动（多视配准/视觉里程计给出）。
手眼方程 `A_i X = X B_i`。李代数残差
`r_i(X) = Log(A_i X B_i^{-1} X^{-1}) ∈ 𝔤`。
（等价写法 `Log(X^{-1} A_i^{-1} X B_i)`，二者相差内自同构，范数等价，可任选。）
鲁棒代价 `J(X)=Σ_i ρ(‖r_i(X)‖_{Σ_i})`，ρ 为 Tukey。**有效性前置**：只有通过第 2 轮定义 417 校验的
回执所对应的运动对才可进入标定集；无效回执产生的 (A_i,B_i) 一律剔除（否则一次伪造回执可污染全局帧）。

**定义 434（激励度与可辨识性）** 令 R_i 为 A_i 的旋转部分（省略平移对旋转子问题的一阶影响）。
激励矩阵 `H_exc = Σ_i (I − R_i) ∈ ℝ^{3×3}`，`μ_exc := σ_min(H_exc)`。
**可辨识判定**：`μ_exc ≥ μ_0` **且** 至少两轴的旋转方向不平行（等价于 rank(H_exc)=3）。
（a）纯平移、平行轴、零旋转、旋转角≈π 的退化配置 ⇒ X 在某些方向上不可观测；
（b）退化时**不得**用求解结果覆盖 X_prior，只能以先验运行并打标 `frame_unidentifiable`（退化链入口）；
（c）μ_exc 与 ε_F 的关系见引理 52——小 μ_exc 下的"回路自洽"并不等于帧正确。

**定义 435（帧图 LCG 与回路闭合）** 帧图 `G_F=(V,E)`：V = 盲区节点 ∪ 外部锚点
（出厂标定 / IMU / 轮式里程计）；边 e=(s,s') 表示两盲区共享工具在同一规范坐标下的相对帧估计，
边权为 Σ_e。对每个独立回路 c，闭合残差
`ρ_c(X)=‖⊕_{e∈c} Log(Δ_e(X))‖`，`ρ_loop(X)=max_c ρ_c(X)`。
全局帧估计
`X̂ = argmin_X Σ_e ρ(‖r_e(X)‖) + ‖Log(X_0^{-1}X)‖²_{Σ_X^{-1}}`，
用增量式位姿图优化（iSAM/流形 Gauss–Newton）在线维护。
关键性质：ρ_loop **无需真值**即可计算 ⇒ 它是定义 437 的漂移信号，修复了第 2 轮引理 48
「覆盖率 SLA 无法在线测量」的可观测性缺陷。锚点数量必须 ≥1，否则帧图只在相差一个全局 g 的意义下可辨识
（**规范自由度**；由 X_0 先验打破）。

**定义 436（帧条件化摊销先验 FAP / GE-Cal）** 在规范帧中做摊销：
`q_θ(v_s | ctx) = MP-Φ_θ( featurize( Φ_{X̂}^{-1} ∘ receipts, h, z_s ) )`，
再搬运回部署帧：`q̂ = Φ_{X̂}# q_θ`（均值按群作用搬运，协方差按 Adjoint 作用 `Ad_{X̂} Σ Ad_{X̂}ᵀ` 搬运）。
**等变约束**：对任意 g∈G，`q_{gθ}(g·v) = g·q_θ(v)`，允许近似误差 ε_eq 进入认证。
训练目标 = 第 2 轮定义 420 的元目标 + `λ_eq·E[dist(q_{gθ}(g·v), g·q_θ(v))]` + 规范帧重建损失。
输出仍做保守性夹紧 `Σ ≽ κ_phys·I`（第 2 轮定义 420），且搬运后重新夹紧，防止 Adjoint 放大后过度自信。

**定义 437（无标签漂移监控 SG-Monitor）** 对每次帧更新构造无标签非一致性向量
`s_t = ( ρ_loop(X̂_t), max_s ‖r_s(X̂_t)‖, receipt_disagreement_t, ‖Log(X̂_t^{-1}X̂_{t-1})‖ )`。
在预注册标定流上经验化其秩，用基于秩的 e-value 乘积 `E_t=Π_{τ≤t} e_τ` 做顺序检验
（Ville 不等式控制误报，见引理 54）。`E_t ≥ 1/α_SG` ⇒ 判为分布漂移，并按主导分量分诊：
（a）ρ_loop 主导 ⇒ **帧漂移** ⇒ 触发 HE-Cal 重估；
（b）receipt_disagreement 主导而 ρ_loop 低 ⇒ **内容漂移** ⇒ 转 ToolGauge/BP-Cal 局部路径或标 stub；
（c）其余 ⇒ **工具故障** ⇒ TCV 维护与工具隔离。
全部分量均不需要真值 h*，因此可作为运行期 SLA，替代第 2 轮引理 48 的 coverage SLA。

**定义 438（修复即标定 RAC）** 每个进入 PROBING（第 2 轮定义 430）的修复事件，除产出计量回执外，
还记录运动对 (A_i,B_i) 写入标定缓冲。若当前 μ_exc<μ_0，允许在 TB-Contract（第 2 轮定义 424）预算内
**追加**激励运动（旋转基线运动 / 多视环拍）以提高 μ_exc；追加动作同样受 TCV 四查（第 2 轮定义 418）
与力矩硬限约束。若预算不足 ⇒ 接受较低激励度、扩大 Σ_X、降低帧路径能力等级（**不阻塞修复**）。
定理化的收益：单次修复的边际成本不变，但每次修复额外产出 O(1) 个手眼约束 ⇒ 标定数据随修复免费累积。

**定义 439（失效归因 FA）** V 阶段（第 2 轮定义 421.5）失败时按 `(μ_exc, ρ_loop, receipt 有效率)` 归因：
- **FRAME**（ρ_loop 高且 μ_exc 充分）⇒ 重估 X 后重试一次；
- **CONTENT**（ρ_loop 低但逐盲区残差高）⇒ 回退 BP-Cal 局部校准，不触碰 X；
- **TOOL**（回执有效率低/前置失败）⇒ TCV 维护与工具隔离。
归因写入 RGL（定义 443）；三类各有独立恢复动作，取代第 2 轮"一律 stub+RED"的粗糙处置。

**定义 440（内容局部性不变式 CLI）** 记帧校正后的内容后验为 `p(v_s|·)`。要求对任意 s≠s'，
由标定流程引入的后验相关满足
`|corr(v_s, v_s')| ≤ c_0 · ε_F · dist_{G_F}(s,s')`，
其中 dist 为帧图最短路长。CLI 是本轮对第 2 轮"局部修复、误差局部化"的**可检验版本**；
违反 ⇒ 视为帧吸收了内容（frame aliasing，见 §6）⇒ 强制 P-Quarantine（第 2 轮定义 428）并拒绝本次热替换。

**定义 441（G-等变工具契约）** 工具库 T₀（第 2 轮定义 416）中每个工具须满足：对任意 g∈G，
`t.invoke(g·args, g·snapshot) = g·t.invoke(args, snapshot)` 且 `Post(g·r)=g·Post(r)`。
注册时用性质测试（随机 g 采样 + 边界位姿）审计；不满足等变的工具标 `neq`，禁止跨位姿搬运其预训练模型。
注：把等变性从"假设"降为"可测试契约"，是对第 2 轮"物理先验足够好不可审计"批评的延续——
现在连"对称性"也必须先通过注册测试才能进入数值通道。

**定义 442（退化链更新）** 能力链 `FrameGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE`：
帧不可辨识 / 帧更新越出信赖域 / CLI 违反 / SG-Monitor 判内容漂移 ⇒ 关闭 F-Box/HE-Cal/GE-Cal，
按第 2 轮 ToolGauge 原样运行（使用 X_prior 或纯数值）；ToolGauge 再失效 ⇒ LeanGauge；再失效 ⇒ MODGAUGE。
每一级只减少能力，不改变 50Hz 主路径与五不变式。退化链的每一级都对应一个**明确被放弃的假设**：
FrameGauge 放弃"帧可辨识"，ToolGauge 放弃"语义假设可用"，LeanGauge 放弃"主动探测可用"——这让
退化从工程兜底变成可解释的假设松弛。

**定义 443（真实世界泛化账本 RGL）** 每次修复追加
`RGL_s = (ε_F, μ_exc, diam(G_F), ρ_loop, δ̂_s, N_update, attr∈{FRAME,CONTENT,TOOL,NONE})`。
热替换证书（第 2 轮定义 427）仅在 RGL 条目均落在预注册阈值内时有效；否则证书降级为"实验性"，
不进入安全论证。RGL 使"泛化"从口号变为逐事件可审计的账，并给 E444/E445 提供直接观测量。

**定义 444（在线帧更新与抗遗忘）** 帧滤波：`X_t = X_{t-1}·Exp(w_t)`，`w_t∼𝒩(0,Σ_w)`
（温漂/磨损的过程噪声），观测为手眼残差；用流形卡尔曼 / 不变 EKF 更新，信赖域
`‖Log(X_t^{-1}X̂)‖ ≤ δ_trust`（越界 ⇒ 不更新并告警，防止一次异常标定把全局帧带偏）。
**抗遗忘**：内容先验与回放缓存一律存于**规范帧**（Φ_{X}^{-1} 坐标）。帧更新只改变搬运映射，
不改规范内容 ⇒ 不会因为换位姿而遗忘内容；重放时按 X̂ 重新搬运。这把"持续学习"简化为
"一个变化的坐标变换 + 一个不动的规范先验"，避免了参数漂移式灾难遗忘。

**定义 445（评测分布族）** 真实世界泛化测试分布
`𝒟_test = { g·(content stratum) : g∼G_test, stratum∈{seen/unseen material, lighting, clutter} }`
× 实施扰动 `{外参偏移, 关节零点, 温度}`。指标族：
(i) 分层超额风险；(ii) 跨盲区残差相关矩阵（对照 CLI）；(iii) 帧误差-风险散点（验证引理 51 的 L_F）；
(iv) RGL 越界率；(v) 无标签监控 AUROC / 检测延迟。评测**必须报告"帧项 vs 内容项"的分解**，
而非单一平均误差——否则又会把两类完全不同的失败混成一个数字。

**定义 446（继承与行为退化）** 未重定义的符号沿用定义 398–431。令 G={e}、X=id、LCG 为空、
SG-Monitor=P-Quarantine，则 FrameGauge 在**行为上**退化为 ToolGauge（不声称逐指令等价；
仅要求安全相关输出与退化链一致）。它与第 2 轮定义 431 的"≡"不同：本轮只要求行为等价，
因为回执中多了运动日志字段，逐指令等价已不成立。

## 2. 关键算法骨架

```python
# IP-321 F-Box：世界帧分解 u_s = Φ_X(z_s) ⊕ v_s
class FBox:
    def decompose(self, u_s, z_s):
        nom = apply_frame(self.X_hat, z_s)          # Φ_X̂(z_s)
        return nom, residual(u_s, nom)              # 返回名义项与局部位 v_s

# IP-322 HE-Cal：手眼标定（AX=XB），鲁棒 + 可辨识性 + 信赖域
class HECal:
    def add_pair(self, A, B):                       # 仅接受有效回执对应的运动对
        self.pairs.append((A, B))
        self.H = sum((I - rot(A_i)) for A_i, _ in self.pairs)
    def excitation(self):
        return smin(self.H)                         # μ_exc（定义 434）
    def identifiable(self):
        return self.excitation() >= MU_0 and rank(self.H) == 3
    def solve(self):
        if not self.identifiable():
            return self.X_prior, "degenerate", inf    # 不可辨识：只许用先验
        X = self.robust_ax_xb(self.pairs)             # Tukey IRLS
        X = self.trust_region(self.X_prior, X)        # ‖Log(X_prior⁻¹X)‖ ≤ δ_trust
        rho = max(norm(log(A @ X @ inv(B) @ inv(X)))
                  for A, B in self.pairs)             # 单边残差上界
        return X, "ok", rho

# IP-323 LCG：跨盲区帧图 + 回路闭合（无真值漂移信号）
class LCG:
    def add_node(self, s, X_s): self.nodes[s] = X_s
    def add_edge(self, s, s2, dX, Sigma): self.edges[(s, s2)] = (dX, Sigma)
    def closure(self):                               # max over independent cycles
        return max(norm(compose_cycle(c)) for c in self.independent_cycles())

# IP-324 GE-Cal：帧条件化摊销先验（等变 + 搬运 + 夹紧）
class GECal(APCal):
    def calibrate(self, receipts, H, s, X_hat):
        rc = canonicalize(receipts, X_hat)           # 拉回规范帧
        mu_v, Sig_v = self.mp_phi(featurize_ctx(rc, H, s))
        mu = transport_mean(X_hat, mu_v)             # Φ_X̂#μ
        Sig = transport_cov(X_hat, Sig_v)            # Ad_X̂ Σ Ad_X̂ᵀ
        return mu, clamp_min(Sig, KAPPA_PHYS)        # 搬运后重新夹紧

# IP-325 SG-Monitor：无标签漂移（秩 e-value / conformal martingale）
class SGMonitor:
    def score(self, X_hat, obs, prev):
        return vector(self.lcg.closure(), receipt_disagreement(obs),
                      max_receipt_residual(obs), dist(X_hat, prev))
    def update(self, x):                             # 顺序检验；无需真值
        self.e *= self.bet(self.rank_of(x))
        return self.e >= 1.0 / ALPHA_SG

# IP-326 FrameGauge 6C′：在 ToolGauge 6C 上插入「帧估计 + 标定」两段
def framegauge_6c_prime(M, s):
    H    = M.lbox.hypothesize(s, M.dbox.R[s])                       # H（第 2 轮）
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))       # C（第 2 轮）
    receipts, pairs = M.tcv.execute_with_motion_log(prog, M.env)     # E：附 (A_i,B_i)
    for A, B in pairs:
        M.hecal.add_pair(A, B)                                      # 修复即标定（定义 438）
    rho = M.lcg.closure()

    if st != "ok":                                                  # 帧不可辨识 ⇒ 退化
        X_hat = M.hecal.X_prior                                     # 只许用先验

    if not M.gecal.cross_validate_frame(mu, Sig, M.lcg.holdout_cycle()):
        kind = attribute_failure(M.hecal.excitation(), rho, receipts)   # 定义 439
        return recover_by_kind(M, s, kind)                          # FRAME/CONTENT/TOOL
    if not contract_regression(M.gecal.build(M.dpe, mu, Sig, s)):
        return stub_and_red(s, "regression")
    new_ec = M.gecal.build(M.dpe, mu, Sig, s)
    if violates_cli(M.gecal, s, new_ec):                            # 定义 440
        M.pquar.trigger(); return stub_and_red(s, "frame_aliasing")
    M.mreg.hot_replace(M.dpe, new_ec)                               # U
    M.lcg.add_node(s, X_hat)                                        # 帧图增量
    M.rgl.record(s, dist(X_hat, M.hecal.X_prior), M.hecal.excitation(),
                 rho, M.gecal.last_gain)                            # 定义 443
    if M.sgmon.update(M.sgmon.score(X_hat, receipts, M.hecal.last_X)):
        M.route_shift(M.sgmon.dominant_component())                 # 定义 437 分诊
    return True

# IP-326 主闭环：50Hz 不变；帧路径不可用时严格退化到第 2 轮
```

## 3. 推导

**引理 51（帧-内容泛化分解界）** 设风险 ℓ 关于契约参数 u 为 L-Lipschitz，帧作用 Φ 关于 X 为
L_F-Lipschitz（`‖Φ_X(z)−Φ_{X'}(z)‖ ≤ L_F·dist_G(X,X')`），X̂ 为部署帧估计，`ε_F=dist_G(X̂,X*)`：
```
ExcessRisk ≤ L·L_F·ε_F + L·δ_v + MetaTerm(M,N_bl) + L·ε_eq,
```
δ_v 为逐盲区内容后验误差（由第 2 轮引理 47 在**规范帧**给出），ε_eq 为等变近似误差。
证明：`‖û_s−u*_s‖ ≤ ‖Φ_{X̂}(z_s)−Φ_{X*}(z_s)‖ + ‖v̂_s−v*_s‖`，逐项用 Lipschitz 与三角不等式再对 s 取上确界。
**与第 2 轮引理 47 的对比**：η 被替换为结构化的、可估计的 ε_F 与局部的 δ_v；当 ε_F→0，
跨盲区相关项消失，只剩局部项。这正是对「预训练→部署偏移不可消除」的修正。

**引理 52（手眼可辨识性与帧误差界）** 在定义 434 的 μ_exc≥μ_0 下，鲁棒 AX=XB 解的一阶扰动满足
```
ε_F ≤ C_he · (ρ_loop + ε_obs) / μ_exc,
```
C_he 为旋转-向量化映射的条件数相关常数，ε_obs 为 B_i 的观测噪声。
证明思路：AX=XB 线性化后得到关于 `δξ∈𝔤` 的线性系统 `M(X)δξ = r`，其最小奇异值由 H_exc 控制；
对 r 用鲁棒界即得。**推论 52.1**：μ_exc 越小，同样的回路残差可对应越大的帧误差——
**回路闭合"看起来一致"不等于帧正确（自洽错误）**。这直接导出 §6 的最大风险。

**引理 53（内容局部性保持）** 在引理 51–52 下，任意两盲区 s,s' 由标定引入的后验相关满足
```
|corr(v_s, v_s')| ≤ c_0·ε_F·dist_{G_F}(s,s') ≤ c_1·(ρ_loop+ε_obs)·dist_{G_F}(s,s') / μ_exc。
```
即：帧误差是唯一的跨盲区相关源，其影响随帧图距离与激励度可控；激励充分（μ_exc 大）时，
相关随 ε_F 一起可控地趋零。CLI（定义 440）是该界的运行时断言，也是第 2 轮"局部误差局部化"的定量版。

**引理 54（无标签监控的统计效力）** 在可交换性下，SG-Monitor 的秩 e-value 满足
`P(∃t: E_t ≥ 1/α_SG) ≤ α_SG`（Ville）；在替代分布下，检测延迟期望
`E[τ] ≤ log(1/α_SG) / KL(s_shift ‖ s_0)`，其中 s 为定义 437 的非一致性向量。
系：这是第 2 轮引理 48 的**可观测替代**——不需要 h* 真值即可给出误报控制与延迟上界。
注意：e-value 的有效性依赖"标定流与部署流在无漂移时同分布"，而帧校正正是让这一假设更接近成立的手段，
因此监控与帧估计是相互支撑的，而不是两个独立补丁。

**引理 55（等变先验的样本效率）** 若工具/契约族对紧致群 G 精确等变，则规范帧假设类的覆盖数满足
```
N(ε; ℋ_G) ≤ N(ε/L_G; ℋ_canon) · P_G(ε),
```
其中 P_G(ε) 为 G 上 ε-网的规模（∼(d_G/ε)^{d_G}，d_G=dim G）。
因此帧分量不再需要域随机化覆盖整个 G，只需规范帧数据 + 在线辨识 d_G 个参数；
样本复杂度对帧维度的依赖由"覆盖 G"降为"每盲区辨识 d_G 维"。
系：这解释了为什么"手眼标定 + 等变"能用远少于域随机化的数据达到同样的位姿泛化——
对称性把 d_G 维的覆盖问题变成了 d_G 维的**参数估计**问题，而后者有可辨识性条件与收敛率（引理 52）。

**引理 56（时序与退化链保持）** HE-Cal/LCG/SG-Monitor 均在异步修复路径内；50Hz 内联新增仅为
RGL 追加、回执运动字段检查与（建议的）对称 MAC 校验，合计 O(1) < 0.05ms/周期。
帧路径关闭时严格退化到第 2 轮引理 50 的时序结论 ⇒ 硬实时与预算不变式保持。
**系**：若沿用第 2 轮的非对称签名验证（RSA/ECDSA，~0.1–1ms），0.2ms 预算会被击穿（见 §5 缺陷 7）；
本轮明确改为对称 MAC 或异步校验。

## 6. 本轮最大风险（一句话）

**一句话**：当部署运动**激励不足或退化**（μ_exc<μ_0：纯平移、平行轴、固定云台）时，HE-Cal 会把真实的
内容偏移**吸收**成一个自洽但错误的帧变换（**frame aliasing / 标定过拟合**）——回路闭合全部通过、
RGL 与证书看起来更可信，但错误重新变成全局共享，且比第 2 轮的先验偏差更隐蔽，因为它在几何上"说得通"。

**次级风险与缓解**：
1. **帧吸收内容（aliasing）** → 激励度门槛 μ_exc≥μ_0 + 留一回路 hold-out + CLI 运行时断言 + 信赖域；
   不可辨识时只许用 X_prior 并打标 `frame_unidentifiable`（定义 434/440，E448/E455）；
2. **回路自洽但错误** → 引理 52 的 μ_exc 分母 + 外部锚点（IMU/里程计/出厂标定）交叉验证；
   禁止用闭环残差单独作为"帧正确"的充分证据（E442/E455）；
3. **共模噪声** → 手眼对中的 A_i 与 B_i 若共享同一时钟/同一故障，AX=XB 会吸收共模误差；
   强制使用独立时基与至少一条跨模态边，并报告共模置信（E443）；
4. **等变假设不成立**（非刚性形变、非线性光度） → 定义 441 注册期性质测试 + ε_eq 进入引理 51 的界；
   不满足等变的工具标 `neq` 不参与跨位姿搬运（E447）；
5. **在线帧更新漂移/被单次异常带偏** → 信赖域 δ_trust + 流形 EKF + 规范帧存储（定义 444，E450）；
6. **规范帧抗遗忘仍有残余**（规范帧本身随 X 变化） → 定期全量重锚 + 规范帧快照版本化（E450）；
7. **RGL/证书的审计成本** → 只对安全相关子图要求完整 RGL，其余降级为实验性证书（定义 443，E452）。

# 第 3 轮产物 · 创新点清单 v3：**FrameGauge**（Frame-Decomposed, Hand-Eye-Calibrated Metrology for Real-World Generalization）

> 背景：第 2 轮 ToolGauge（IP-315–320）把 LeanGauge 的盲区修复升级为「语义假设 → 契约化工具调用 →
> 摊销校准 → 交叉验证热替换」，并用元泛化界（引理 47）把先验质量变成可测量量。但它留下一个结构性弱点：
> **把 sim→real 偏移建模成一个标量 TV 距离 η**，于是 (a) 高维下 η≈1，界空谈；(b) "η 不可消除"导致
> 跨盲区强相关偏差只能靠断路器（P-Quarantine）事后补救，无法事前消除。
>
> 本轮以「真实世界泛化 × 手眼标定」为灵感，在 ToolGauge 之上加入一层**世界帧分解**：
> 把契约参数拆成「共享帧 X∈G」与「局部位 v_s」，用修复过程中顺带采集的 AX=XB 约束在线辨识 X，
> 用帧图回路闭合做**无真值**漂移监控，用等变先验把规范帧学到的知识搬运到任意新位姿。
> 关键结论：**可消除的帧误差与不可消除的内容偏移被分开**，跨盲区相关性第一次有了可计算的界与运行时断言。
>

> 理论姿态：不改五不变式与 50Hz 骨架，新增「帧分解层」「内容局部性不变式 CLI」「无标签漂移监控」。

| `(A_i,B_i)` 缓冲 | 修复即标定 RAC 的运动对缓冲（定义 438） |
| `FRAME / CONTENT / TOOL` | V 失败的三类归因与差异化恢复（定义 439） |

## 2. 形式化定义（要点）

**定义 432（WFD）** `u_s = Φ_X(z_s) ⊕ v_s`，X∈G 为共享帧，v_s 为局部位内容；`E[v_s]=0` 消除规范自由度；
X 有出厂先验 `X_0∼𝒩_G(X_factory,Σ_X)`。这是把第 2 轮"整个 u_s 都是内容"的错误建模改正过来。
**定义 433（手眼对）** `A_i X = X B_i`，残差 `r_i(X)=Log(A_i X B_i^{-1}X^{-1})`；仅有效回执（第 2 轮 417）
对应的运动对可入标定集。
**定义 434（可辨识性）** `μ_exc=σ_min(Σ(I−R_i))`；`μ_exc≥μ_0` 且 rank=3 才可辨识；退化时只许用 X_prior，
不得用求解值覆盖（防止"自洽错误"污染全局）。
**定义 435（LCG）** 帧图 + 独立回路；`ρ_loop=max_c‖⊕ Log Δ_e‖`；增量位姿图优化；至少一个外部锚点打破全局规范自由度。
**定义 436（GE-Cal）** 规范帧摊销 `q_θ(v_s|ctx)`，按 `Φ_{X̂}#` 搬运均值/协方差（协方差用 Adjoint），
搬运后重新做 `Σ≽κ_phys·I` 夹紧；训练加等变惩罚 λ_eq。
**定义 437（SG-Monitor）** 无标签非一致性向量 = (ρ_loop, max 单边残差, receipt 不一致, 帧步长)；
秩 e-value 顺序检验；按主导分量分诊 FRAME/CONTENT/TOOL。
**定义 438（RAC）** 修复即标定：PROBING 期间顺带记录运动对；预算内可追加激励运动；预算不足则扩 Σ_X、降级而非阻塞。
**定义 439（FA）** V 失败归因 FRAME/CONTENT/TOOL，差异化恢复；取代第 2 轮"一律 stub+RED"。
**定义 440（CLI）** `|corr(v_s,v_s')| ≤ c_0·ε_F·dist_{G_F}(s,s')`；违反 ⇒ P-Quarantine + 拒绝热替换。
**定义 441（等变契约）** 工具注册须通过 `t.invoke(g·args,g·snapshot)=g·t.invoke(args,snapshot)` 性质测试；
不通过标 `neq`，禁止跨位姿搬运。
**定义 442（退化链）** FrameGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE；每级只减能力，不改主路径。
**定义 443（RGL）** 逐修复记录 `(ε_F,μ_exc,diam(G_F),ρ_loop,δ̂_s,N_update,attr)`；证书仅在阈值内有效。
**定义 444（在线帧 + 抗遗忘）** 流形 EKF + 信赖域；内容先验/回放存于规范帧，帧更新只改搬运映射。
**定义 445（评测）** SE(3) 位姿 × 内容分层 × 实施扰动；必须报告帧项/内容项分解，不报单一均值。
**定义 446（行为退化）** G={e}、X=id、LCG 空、SG-Monitor=P-Quarantine ⇒ 行为上退化为 ToolGauge（非逐指令等价）。

## 3. 关键算法骨架

```python
# IP-322 HE-Cal：可辨识性优先，鲁棒求解，信赖域兜底
class HECal:
    def add_pair(self, A, B): self.pairs.append((A, B))
    def excitation(self): return smin(sum(I - rot(A) for A, _ in self.pairs))
    def identifiable(self): return self.excitation() >= MU_0 and rank(self.H) == 3
    def solve(self):
        if not self.identifiable():
            return self.X_prior, "degenerate", inf      # 只许用先验（定义 434）
        X = self.trust_region(self.X_prior, self.robust_ax_xb(self.pairs))
        return X, "ok", max(norm(log(A @ X @ inv(B) @ inv(X))) for A, B in self.pairs)

# IP-323 LCG：无真值回路闭合
class LCG:
    def closure(self): return max(norm(compose_cycle(c)) for c in self.independent_cycles())

# IP-324 GE-Cal：规范帧摊销 + 等变搬运 + 夹紧
class GECal(APCal):
    def calibrate(self, receipts, H, s, X_hat):
        mu_v, Sig_v = self.mp_phi(featurize_ctx(canonicalize(receipts, X_hat), H, s))
        return (transport_mean(X_hat, mu_v),
                clamp_min(transport_cov(X_hat, Sig_v), KAPPA_PHYS))

# IP-325 SG-Monitor：秩 e-value（无需 label）
class SGMonitor:
    def update(self, x):
        self.e *= self.bet(self.rank_of(x))
        return self.e >= 1.0 / ALPHA_SG

# IP-326 FrameGauge 6C′
def framegauge_6c_prime(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                        # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))      # C
    receipts, pairs = M.tcv.execute_with_motion_log(prog, M.env)   # E + 手眼对
    for A, B in pairs: M.hecal.add_pair(A, B)                      # RAC（定义 438）
    X_hat, st, rho = M.hecal.solve()
    if st != "ok": X_hat = M.hecal.X_prior                         # 退化：用先验
    mu, Sig = M.gecal.calibrate(receipts, H, s, X_hat)             # 帧条件化
    if not M.gecal.cross_validate_frame(mu, Sig, M.lcg.holdout_cycle()):
        return recover_by_kind(M, s,
            attribute_failure(M.hecal.excitation(), rho, receipts)) # FRAME/CONTENT/TOOL
    new_ec = M.gecal.build(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    if violates_cli(M.gecal, s, new_ec):                           # 定义 440
        M.pquar.trigger(); return stub_and_red(s, "frame_aliasing")
    M.mreg.hot_replace(M.dpe, new_ec)                              # U
    M.lcg.add_node(s, X_hat)
    M.rgl.record(s, dist(X_hat, M.hecal.X_prior), M.hecal.excitation(),
                 rho, M.gecal.last_gain)                           # 定义 443
    if M.sgmon.update(M.sgmon.score(X_hat, receipts, M.hecal.last_X)):
        M.route_shift(M.sgmon.dominant_component())                # 定义 437
    return True

def FrameGauge_round(M, *obs):
    for s in M.dbox.detect_blind_spot():
        if s in M.inflight: continue
        M.inflight.add(s)
        submit_async(framegauge_6c_prime if M.hecal.identifiable() and M.gecal.available()
                     else toolgauge_6c, M, s)                      # 严格退化
    return MODGAUGE_round(M, *obs)
```

## 4. 推导

**引理 51（帧-内容泛化分解界）** `ExcessRisk ≤ L·L_F·ε_F + L·δ_v + MetaTerm(M,N_bl) + L·ε_eq`。
η 被拆成可估计的帧项与局部内容项；ε_F→0 时跨盲区相关项消失。这是对第 2 轮引理 47 悲观结论的修正。

**引理 52（手眼可辨识性与帧误差界）** `ε_F ≤ C_he·(ρ_loop+ε_obs)/μ_exc`。
推论 52.1：小 μ_exc 下回路自洽 ≠ 帧正确（自洽错误），这是本轮最大风险的数学根源。

**引理 53（内容局部性保持）** `|corr(v_s,v_s')| ≤ c_1·(ρ_loop+ε_obs)·dist_{G_F}/μ_exc`。
帧误差是唯一跨盲区相关源，且影响随帧图距离与激励度可控；CLI 为该界的运行时断言。

**引理 54（无标签监控效力）** 可交换下 `P(∃t:E_t≥1/α_SG)≤α_SG`（Ville）；
替代分布下检测延迟 `E[τ]≤log(1/α_SG)/KL(s_shift‖s_0)`。这是第 2 轮不可测 coverage SLA 的可观测替代。

**引理 55（等变先验样本效率）** `N(ε;ℋ_G) ≤ N(ε/L_G;ℋ_canon)·P_G(ε)`，`P_G(ε)∼(d_G/ε)^{d_G}`。
帧维度从"覆盖整个 G"降为"每盲区辨识 d_G 维"，且有可辨识性条件与收敛率（引理 52）。

**引理 56（时序与退化链保持）** 帧/标定全异步；50Hz 新增 ≤0.05ms（对称 MAC）；帧路径关闭 ⇒ 第 2 轮引理 50 时序。
系：非对称签名（0.1–1ms）会击穿第 2 轮 0.2ms 预算，故本轮改用 MAC 或异步验签。

## 8. 本轮最大风险

**一句话**：部署运动**激励不足或退化**时，HE-Cal 会把真实的内容偏移吸收成自洽而错误的帧变换
（**frame aliasing / 标定过拟合**）——回路闭合全部通过、证书更可信，错误却重新全局共享，
且比第 2 轮的先验偏差更隐蔽，因为它在几何上"说得通"。
**三重兜底**：μ_exc≥μ_0 才允许帧路径（定义 434）+ 留一回路 hold-out 与外部锚点交叉验证（定义 435）+
CLI 运行时断言与信赖域（定义 440/444）；以 E443/E448/E455 证伪，以 RGL（定义 443）审计。
