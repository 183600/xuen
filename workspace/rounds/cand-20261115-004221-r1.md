# 第 3 轮（灵感循环第 1 轮；本轮灵感：「可重构机构」×「决策规划」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439）。
> 其下继承 LeanGauge（IP-310–314）与 MODGAUGE 五不变式。
> 本轮纪律：**只加一层「构型—规划」层，不改数值真值通道**——RM-Box 只改变观测几何，
> P-Plan 只在有限动作集上做序列决策，两者都不直接写契约数值；热替换与交叉验证仍由 ToolGauge 把关。
> 所有旧模块、五不变式与退化链保留；ToolGauge 是新系统的**退化特例**（构型集合 `C={c₀}` 退化为固定夹具）。

## 0. 直觉与动机

**灵感 1（可重构机构 → 把「传感器布置」从常量变成决策变量）**

直觉：ToolGauge 的 `T₀` 工具库与安装几何是写死的。它隐含假设「盲区 = 样本不足」，
但大量盲区其实是「当前几何下不可观测」：短基线下远距离深度方向几乎零信息；单视点无法区分
镜面与漫反射（二者都能拟合同一 RGB 残差）；遮挡使某方向 Fisher 信息矩阵秩亏。
这类盲区**再采样也不会收敛**——你只是把同一个不可观测方向重复测量了 n 次。
可重构机构的启示是：把相机基线、云台、滑轨、伸缩臂、可部署标靶、可换末端都视为**机构的自由参数**，
让 `F(c)` 随构型 `c` 改变。信息来自几何，而不只来自样本数。

**灵感 2（决策规划 → 构型选择是有顺序、有代价、有风险的序列决策）**

直觉：即使有了可重构能力，「每一步选信息增益最大的构型」也是错的：
(a) 重配置有代价（时间、磨损、能耗）与风险（扰动现场、碰撞、丢标定）；
(b) 动作**不可交换**：先拉基线再标定 ≠ 先标定再拉基线；
(c) 重配置会引入新的 nuisance（新基线/新安装位自身需要标定），
把「看得见」误判成「测得准」是最大的陷阱；
(d) 一次重配置可能让**已有的**契约证据失效。
因此正确的对象是有限时域、带约束的序列决策：动作 =（重配置到 `c`，执行探测程序 `Π`），
目标 = 期望信息增益 − 重配置代价 − 风险，硬约束 = 安全包络 / 预算 / 时延 / 证据单调性。
这正是决策规划（约束 MDP / POMDP、 anytime 搜索、证书）的标准战场。

**为什么两者必须合起来（融合命题）**

单独的可重构机构 = 一个更灵活但更危险的夹具，会为了看得见而毁掉标定；
单独的决策规划 = 在一个固定且可能秩亏的几何上做最优采样，天花板被物理锁死。
只有把「构型改变信息矩阵」与「规划权衡信息/代价/证据生命周期」合在一起，
才能回答 ToolGauge 回答不了的问题：**这个盲区在当前机构下是否可修？要换到哪个构型？
换构型的代价与它摧毁的旧证据相比值不值？换完之后谁来证明新的标定本身是对的？**

**与上一轮的边界**：ToolGauge 的 VLA 只做「提假设 / 选工具 / 写主张」；本轮 VLA 多一个**提案**角色
（提议候选构型与候选计划），但**证书由数值层签发**：FIM 计算、风险上界、证据失效判定全部在计量层。
语言依旧不进入数值通道。重配置是增强项：规划器不可用 / 证书失败 / 安全包络不满足 / 预算耗尽
⇒ 退回固定构型 ToolGauge ⇒ 再退 LeanGauge ⇒ 再退 MODGAUGE。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- **新增第六不变式（证据单调性）**：一次重配置若使某已认证字段 `f` 失效，则计划中必须已包含

- **退化链延长**：ReGauge 失效 ⇒ ToolGauge 固定构型 ⇒ LeanGauge 纯数值 ⇒ MODGAUGE；
- 主张绑定语言扩展保持：计划证书与语言修复证书都必须引用有效回执。

## 2. 形式化定义（增量：定义 432–447）

**定义 432（可重构计量机构 RMM）** 计量机构 `ℛ = (C, Φ, g, H, cost, τ, risk, rev)`：
- `C`：离散构型模式集（如 `{单目, 双目短基线, 双目长基线, 侧视, 顶视, 可部署标靶}`），`|C|` 有限；
- `Φ`：连续关节/滑轨空间，`g_c: Φ → SE(3)^{m(c)}` 给出构型 `c` 下各传感器位姿；
- `H = {h_j(c, q, x, ξ)}`：构型条件下的观测模型，`x` 为场景/目标参数，`ξ` 为噪声；
- `cost(c→c')`、`τ(c→c')`、`risk(c→c')`：归一化代价、最坏时延、物理风险；
- `rev(c→c')`：可逆性与恢复动作（不可逆构型必须显式标记并单独审批）。
`c₀` 为默认固定构型；`C={c₀}` 时 `ℛ` 退化为 ToolGauge 的固定夹具。

**定义 433（构型条件可观测性与 Fisher 映射 FIMap）** 对目标参数 `u_s`，构型 `c` 下的
Fisher 信息矩阵 `F(c) = Σ_{j=1}^{m(c)} J_j(c)ᵀ Σ_j⁻¹ J_j(c)`，`J_j = ∂h_j/∂u_s`。
方向 `v` 在 `c` 下**不可观测** ⇔ `vᵀF(c)v = 0`（在给定线性化点与噪声模型下）。
`FIMap: C × u_s ↦ {F(c)}` 预计算并缓存；非线性强时附局部有效性半径 `ρ_lin(c)`。

**定义 434（联合参数与构型 nuisance）** 参数拆为 `u = (u_s, b_r)`：
`u_s` 为盲区目标参数，`b_r` 为重配置引入的 nuisance（新基线/新外参/新安装位）。
联合 FIM 为分块矩阵 `F_c = [[F_ss, F_sb],[F_bs, F_bb]]`；
**条件信息增益**用 Schur 补 `F_{s|b}(c) = F_ss − F_sb F_bb⁻¹ F_bs`。
若 `b_r` 未标定（`F_bb` 近奇异），则 `F_{s|b}` 必须按保守值计算，**禁止**使用边缘 `F_ss` 冒充可获信息。
这把「换个没标定的构型」从「信息增加」纠正为「信息可能为零甚至为负」。

**定义 435（重配置宏动作与计划）** 宏动作 `a = (c, Π)`：先重配置到 `c`，再执行 ToolGauge 探测程序 `Π`。
计划 `π = (a₁,…,a_H)`，`H ≤ H_max = 4`；动作可带依赖（后一动作的参数可引用前序回执）。
计划必须满足：几何可达、无碰撞、安全包络、预算 `Σ cost ≤ B_reconfig + B_tools`。

**定义 436（信息增益与贝叶斯下界）** 高斯线性化下构型 `c` 的期望信息增益
`IG(c) = ½ log det(I + Σ_0 F_{s|b}(c))`（nats）；
执行计划后的后验协方差满足 `Σ_post(π) ≽ (Σ_0⁻¹ + Σ_k F_{s|b}(c_k))⁻¹`（Bayesian CRLB，正则条件下）。
证书中的 `IG` 与 `σ` 均取该下界的**保守侧**。

**定义 437（计划证书 PlanCert）** `PlanCert(π) = (Ĵ_IG, Û_risk, Û_cost, Û_invalid, δ)`：
在置信度 `1−δ` 下保证
`realized IG ≥ Ĵ_IG − ε_IG`、`realized risk ≤ Û_risk`、`cost ≤ Û_cost`、`invalidated ⊆ Û_invalid`。
证书由数值层签发；任一界不可计算 ⇒ 该计划不可执行（不是「乐观执行」）。
VLA 只能提候选计划，不能填证书字段。

**定义 438（标定溯源台账 Cal-DAG）** 有向图 `G_cal = (V, E)`：节点 `v=(field, context)` 是契约字段及其
获取时的物理上下文（构型、位姿、温度、时间）；边 `(r → v)` 表示回执 `r` 支持字段 `v`。
重配置 `c→c'` 诱导失效集 `Inv(c→c') = {v : v 的支撑回执引用了被改动的几何/位姿/外参}`。
**保留集** `Keep = V \ Inv` 中的字段在热替换后必须逐位数值等价（引理 53）。

**定义 439（证据单调性不变式 EMI）** 任何被采纳的重配置 `c→c'` 必须满足：
`Inv(c→c')` 中的每个字段，计划内都存在一个在 `τ_recal` 内完成、且其证书成立的恢复子计划；
否则规划器必须返回 `REJECT`。EMI 把「毁掉旧证据」变成**必须先买单的动作**。

**定义 440（重配置规划目标）** 在信念 `b`（盲区假设后验 + 未认证字段集）上求解
`max_π E[ Σ_{k=0}^{H-1} γ^k ( IG(a_k) − λ_c·cost(a_k) − λ_r·risk(a_k) ) ]`
s.t. `risk(a_k) ≤ ρ`、`Σ cost ≤ B`、EMI 成立、`PlanCert(π,δ)` 成立。
这是有限时域约束 MDP；观测随机时按 POMDP 处理，用信念节点上的 AO*/MCTS 求解。

**定义 441（非交换性与顺序敏感度）** 对两个宏动作 `a,b`，
`Ω(a,b) = |IG(a∘b) − IG(b∘a)| / max(IG(a∘b), IG(b∘a), ε)`。
`Ω > Ω_th` 时规划器禁止使用交换律剪枝；贪心/交换排序在该情形下无最优性保证（引理 54）。

**定义 442（RECONFIGURING 显式状态）** 重配置期间系统进入显式 `RECONFIGURING` 态：
速度/力矩/工作空间硬限、禁止接触、日志全录、可随时中止并回退到 `c₀`；
不可逆构型需要额外的二次确认与人工可见性。它是定义 430 `PROBING` 的机构级推广。

**定义 443（重配置回执与有效性）** `r_c = (c', g 实测, b_r 估计, sig, ts, seq)`；
`valid(r_c) ⇔ 几何实测与指令构型一致（在容差内）∧ 外参可行 ∧ 签名有效 ∧ seq 单调`。
无效的重配置回执 ⇒ 该构型下所有后续观测作废，计划回退。

**定义 444（联合校准 AP-Cal(c)）** 在 ToolGauge AP-Cal 的上下文里显式加入构型与 nuisance：
`q_θ(u_s,b_r | c, receipts)`；先验锚 `p_phys` 与夹紧 `Σ ≽ κ_phys I` 保留。
预训练分布中必须包含「构型切换 + 标定恢复」的 episode，否则先验在 `C>1` 时不可信（P-Quarantine 扩展）。

**定义 445（计划缓存与重用）** 以盲区类 `class(s)` + 构型上下文为键缓存计划；命中缓存仍需重跑
`PlanCert` 的失效检查与 EMI 检查。缓存只省搜索，不省验证。

**定义 446（ReGauge 八段闭环 8C）** `H → P → R → C → E → C → V → U`：
H（L-Box 共形假设）→ P（P-Plan 生成并证书化计划）→ R（重配置 + 回执校验）→ C（TCV 编译探测程序）
→ E（执行，PROBING/RECONFIGURING 显式态）→ C（AP-Cal(c) 联合校准）→ V（独立回执交叉验证 + 契约回归 + EMI 复核）
→ U（Cal-DAG 更新 + 局部热替换 + 证书绑定）。V 或 EMI 失败 ⇒ 回退 `c₀` 重试 1 次 ⇒ 再失败 stub + RED。

**定义 447（继承与退化）** 未重定义的记号沿用定义 398–431。令 `C={c₀}`、`P-Plan=单步 β 闸门`、
`AP-Cal(c)=AP-Cal` ⇒ ReGauge ≡ ToolGauge。所有新增量都是**可关闭的增强层**。

# IP-321 RM-Box：可重构计量机构与构型条件可观测性
class RMBox:
    def __init__(self, modes, g, obs_models, cost, tau, risk, rev):
        self.C, self.g, self.H = modes, g, obs_models
        self.cost, self.tau, self.risk, self.rev = cost, tau, risk, rev
        self.fimap = {}                          # (c, cell) -> F(c) 缓存

    def fisher(self, c, u_s, b_r=None):
        F = sum(J(c).T @ inv(Sigma) @ J(c) for J in self.H.jacobians(c, u_s))
        if b_r is not None:                      # 定义 434：Schur 补，禁止用边缘 F_ss 冒充
            F = schur_complement(F, b_r)         # F_{ss} - F_{sb} F_{bb}^{-1} F_{bs}
        return F

    def unobservable_dirs(self, c, u_s, tol=1e-9):
        w, V = eigh(self.fisher(c, u_s))
        return V[:, w <= tol]                    # 定义 433：秩亏方向

# IP-322 P-Plan：证书化的序列规划（anytime AO* + 约束）
class PPlan:
    def plan(self, b, s, budget, deadline):
        root = PlanNode(b= b, c=self.current_c, t=0, inval=set())
        best = None
        while not self.expired(deadline):
            a = self.best_first_expand(root, h=self.admissible_ig_upper)   # 放松 FIM 上界
            if a is None: break
            for macro in self.macro_actions(a, s, budget):                 # (c', Π)
                cert = self.certify(macro, a)          # 定义 437：IG/风险/代价/失效集
                if not cert.ok: continue               # 证书不可算 => 不可执行
                if not self.emi_ok(a, macro, cert):    # 定义 439：必须自带恢复子计划
                    continue
                self.push(a.child(macro, cert))
            best = self.best_certified_leaf(root) or best
        return best or self.fallback_fixed_config()    # 退化到 ToolGauge

    def certify(self, macro, parent):
        c, prog = macro
        F = self.rm.fisher(c, parent.u_s, b_r=parent.b_r_hat)
        ig = 0.5 * logdet(I + parent.Sigma @ F)        # 定义 436
        return PlanCert(ig_lo=ig - eps_model,
                        risk_hi=risk_bound(c, prog),
                        cost_hi=self.rm.cost(self.current_c, c) + tcv_cost(prog),
                        invalid=self.caldag.invalidation(self.current_c, c),
                        delta=self.delta)

# IP-323 证据台账 + 单调性
class CalDAG:
    def invalidation(self, c, c_new):
        changed = geometry_delta(c, c_new)             # 被改动的基线/外参/位姿
        return {v for v in self.nodes if self.depends(v, changed)}

    def emi_ok(self, plan, macro, cert):
        # 每个失效字段都必须有计划内的恢复动作（定义 439）
        return all(plan.has_restore(f, within=TAU_RECAL) for f in cert.invalid)

# IP-324 ReGauge-8C
def regauge_8c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                     # H
    plan = M.pplan.plan(M.belief(s), s, M.budget_left(s), M.deadline)  # P + 证书
    if plan is None or not plan.is_certified():                # 退化链第 1 级
        return toolgauge_6c_fixed(M, s)
    for macro in plan.macros:
        if not M.rm.safe(macro.c): return toolgauge_6c_fixed(M, s)
        r_c = M.rm.reconfigure(macro.c)                        # R（RECONFIGURING 态）
        if not valid_reconfig(r_c): return rollback_and_fallback(M, s)
        receipts = M.tcv.execute(macro.prog, M.env)            # C + E
        mu, Sig = M.apcal_calibrate(mu_prev, Sig_prev, receipts, c=macro.c, b_r=r_c.b_r)  # C
        if not M.cross_validate(mu, Sig, M.cross_receipt(s, macro.c)):  # V
            continue
        if not M.caldag.emi_ok(plan, macro, macro.cert):       # U 前复核
            return rollback_and_fallback(M, s)
        new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s, c=macro.c)
        if not contract_regression(new_ec): return stub_and_red(s, "regression")
        M.mreg.hot_replace(M.dpe, new_ec)                      # U
        M.caldag.rebind(s, receipts, c=macro.c)
        bind_claims(new_ec, H, plan, receipts)
        if M.caldag.certifies(s): break
    return M.caldag.certifies(s)

# IP-325 主闭环
def ReGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(regauge_8c, M, s)
    if M.pquar.triggered(): M.apcal.pause(); M.use_bpcal_fallback = True
    return MODGAUGE_round(M, obs, audio, tac, depth, det)      # 主控不变

## 4. 推导

**引理 51（构型信息占优与秩修复）** 若构型 `c'` 的观测集包含 `c` 的观测集且新增观测在给定 `u`
下条件独立，则 `F(c') ≽ F(c)`（Loewner 序），从而 `(Σ_0⁻¹+F(c'))⁻¹ ≼ (Σ_0⁻¹+F(c))⁻¹`，
后验协方差在任一方向不劣。若 `c` 下方向 `v` 秩亏而 `c'` 下 `vᵀF(c')v>0`，则称 `c'` **修复该方向**。
系：ToolGauge 在 `C={c₀}` 上无法降低的秩亏方向，ReGauge 可能通过换构型修复——这是「换几何优于加样本」的形式化。

**引理 52（计划证书可靠性）** 在模型误差有界（`‖ĥ−h‖≤ε_m`）、噪声亚高斯、线性化半径 `ρ_lin` 内，
定义 437 的证书以概率 `≥1−δ` 成立；证明用 FIM 的 Lipschitz 扰动界 + 对 `H` 步的 union bound。
系：证书不可算或超界 ⇒ 计划拒绝 ⇒ **不存在「未认证却执行」的路径**（与 ToolGauge 的零副作用下界对齐）。

**引理 53（重配置下的证据保持）** 若字段 `v` 的支撑回执不引用 `c→c'` 改动的几何/位姿/外参，
则热替换后 `v` 的数值逐位不变；即 `Keep` 上的子图与替换前数值等价（推广第 2 轮引理 49）。
证明：`v` 的数值仅由其支撑回执与构型上下文决定，二者均未变 ⇒ 同一条计算路径 ⇒ 等价。

**引理 54（贪心的次优性与顺序敏感）** 存在构型集合与代价结构，使逐动作贪心（每步取最大 `IG`）
的累计净收益 `≤ OPT/(1+Ω_max·H)`；因此必须做序列规划。系：`Ω` 小且代价满足拟阵条件时可安全交换剪枝，
否则禁用交换剪枝（定义 441）。

**引理 55（证据单调性 ⇒ 无活锁）** 在 EMI 成立、预算有限且每个恢复子计划严格减少「未认证字段数」
（或严格消耗正预算）的条件下，`8C` 闭环不可能无限次重配置；执行必然在 `H·H_max` 步内终止于
`certified` 或 `stub+RED`。证明：取良基测度 `(未认证字段数, 剩余预算)` 的字典序，每次被采纳的重配置都使其严格下降。

**引理 56（时序与实时性保持）** 规划与重配置全部位于 50Hz 计量路径之外；50Hz 路径新增仅为
构型状态检查 `O(1)`。重配置最坏时延 `τ_reconfig`、规划最坏时延 `τ_plan` 由 RM-Budget 界定；
超时按退化链回退 ⇒ 硬实时与预算不变式保持（继承引理 50）。

## 7. 本轮最大风险（一句话）

**一句话**：重配置会同时改变「可观测性」和「标定基准」，规划器可能为了看见盲区而摧毁
证明该盲区已被看见的标定——**证书自指失效（self-undermining certificate）**，
在极端情况下导致构型震荡或活锁，并让所有被重标定的字段同时偏移。

**次级风险与缓解**：
1. **构型 nuisance 漂移**（换了基线却没标定准）→ Schur 补条件信息（定义 434）+ 联合校准 + 强制恢复子计划；
2. **状态爆炸/规划超时** → anytime + 可采纳 FIM 上界 + 计划缓存 + 超时退化（引理 56）；
3. **物理磨损与场景扰动** → 代价/风险项 + RECONFIGURING 包络 + 不可逆构型审批；
4. **线性化失效**（FIM 只在局部有效）→ 局部有效性半径 + 证书模型误差项 + 实测校验（E442）；
5. **证据账本不一致** → Cal-DAG 失效判定 + 引理 53 的逐位等价回归（E444）；
6. **活锁/震荡** → 证据单调性 EMI + 良基测度终止性（引理 55，E445）；
7. **VLA 提案污染** → VLA 只提案、不签证书；输入白名单（定义 429）保持；E449 消融。

## 2. 形式化定义（要点）

**定义 432（RMM）** 可重构机构 = 离散构型集 + 连续关节空间 + 构型相关正运动学 `g_c` + 观测模型族 `H` + 代价/时延/风险/可逆性。构型是一等决策变量，不是实现细节。

**定义 433（FIMap）** `F(c) = Σ_j J_j(c)ᵀΣ_j⁻¹J_j(c)`；`v` 在 `c` 下不可观测 ⇔ `vᵀF(c)v=0`。`FIMap` 预计算并附线性化有效性半径。

**定义 434（联合参数与 nuisance）** `u=(u_s,b_r)`；`F_c = [[F_ss,F_sb],[F_bs,F_bb]]`，条件信息 `F_{s|b}=F_ss−F_sbF_bb⁻¹F_bs`。`b_r` 未标定时按保守侧计算，**禁止**用 `F_ss` 冒充可获信息。

**定义 435（宏动作与计划）** `a=(c,Π)`；`π=(a₁,…,a_H)`，`H≤4`；满足几何可达、无碰撞、安全包络与预算。

**定义 436（信息增益与贝叶斯下界）** `IG(c)=½logdet(I+Σ₀F_{s|b}(c))`；`Σ_post(π) ≽ (Σ₀⁻¹+Σ_kF_{s|b}(c_k))⁻¹`（Bayesian CRLB，正则条件下）。

**定义 437（计划证书）** 在 `1−δ` 下保证实现的 `IG` 不低于 `Ĵ_IG−ε_IG`、风险不高于 `Û_risk`、代价不高于 `Û_cost`、失效集被 `Û_invalid` 覆盖。证书由数值层签发；不可算 ⇒ 不执行。

**定义 438（Cal-DAG）** 节点 `(field, context)`，边 `receipt → field`；`Inv(c→c') = {v : v 的支撑回执引用被改动的几何/位姿/外参}`；保留集 `Keep` 必须逐位数值等价（引理 53）。

**定义 439（EMI）** 被采纳的 `c→c'` 必须让 `Inv` 中每个字段在计划内都有 `τ_recal` 内可完成的恢复子计划；否则 `REJECT`。

**定义 440（规划目标）** `max_π E[Σ γ^k(IG−λ_c·cost−λ_r·risk)]`，约束 `risk≤ρ`、`Σcost≤B`、EMI、`PlanCert`。

**定义 441（顺序敏感度）** `Ω(a,b)=|IG(a∘b)−IG(b∘a)|/max(...)`；`Ω>Ω_th` 时禁用交换律剪枝。

**定义 442/443（RECONFIGURING 与重配置回执）** 速度/力矩/工作空间硬限、禁接触、可中止回退；回执含几何实测 `g` 与 nuisance 估计 `b_r`，无效则后续观测全部作废。

**定义 444（AP-Cal(c)）** `q_θ(u_s,b_r | c, receipts)`；预训练 episode 必须覆盖构型切换与标定恢复，否则先验在 `C>1` 不可信。

**定义 445（计划缓存）** 按 `class(s)` + 构型上下文缓存；命中仍须重验 `PlanCert` 与 EMI。

**定义 446（8C）** `H→P→R→C→E→C→V→U`；V/EMI 失败回退 `c₀` 重试 1 次 ⇒ 再失败 stub+RED。

**定义 447（继承与退化）** 未重定义记号沿用 398–431；关闭重配置与序列规划 ⇒ ReGauge ≡ ToolGauge。

# IP-321/322 RM-Box + FIMap：构型条件可观测性
class RMBox:
    def fisher(self, c, u_s, b_r=None):
        F = sum(J(c).T @ inv(Sigma) @ J(c) for J in self.H.jacobians(c, u_s))
        return schur_complement(F, b_r) if b_r is not None else F   # 定义 434

    def unobservable_dirs(self, c, u_s, tol=1e-9):
        w, V = eigh(self.fisher(c, u_s))
        return V[:, w <= tol]                                      # 定义 433

# IP-323 P-Plan：证书化 anytime 序列规划
class PPlan:
    def plan(self, s, belief, budget, deadline):
        root = PlanNode(belief, c=self.current_c, inval=set())
        best = None
        while not self.expired(deadline):
            node = self.best_first_expand(root, h=self.admissible_ig_upper)  # FIM 放松上界
            if node is None: break
            for (c, prog) in self.macro_actions(node, s, budget):
                cert = self.certify(node, c, prog)          # IG/风险/代价/失效集
                if not cert.ok: continue                    # 证书不可算 => 不执行
                if not self.caldag.emi_ok(node.plan, c, cert): continue
                self.push(node.child(c, prog, cert))
            best = self.best_certified_leaf(root) or best
        return best or self.fallback_fixed_config()         # 退化到 ToolGauge

    def certify(self, node, c, prog):
        F = self.rm.fisher(c, node.u_s, node.b_r_hat)
        ig = 0.5 * logdet(I + node.Sigma @ F)               # 定义 436
        return PlanCert(ig_lo=ig - EPS_MODEL,
                        risk_hi=risk_bound(c, prog),
                        cost_hi=self.rm.cost(self.current_c, c) + tcv_cost(prog),
                        invalid=self.caldag.invalidation(self.current_c, c),
                        delta=self.delta)

# IP-324 Cal-DAG：失效判定 + EMI 复核
class CalDAG:
    def invalidation(self, c, c_new):
        return {v for v in self.nodes if self.depends(v, geometry_delta(c, c_new))}
    def emi_ok(self, plan, c, cert):
        return all(plan.has_restore(f, within=TAU_RECAL) for f in cert.invalid)

# IP-325 ReGauge-8C
def regauge_8c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                          # H
    plan = M.pplan.plan(s, M.belief(s), M.budget_left(s), M.deadline)  # P
    if plan is None or not plan.is_certified(): return toolgauge_6c_fixed(M, s)
    for macro in plan.macros:
        if not M.rm.safe(macro.c): return toolgauge_6c_fixed(M, s)
        r_c = M.rm.reconfigure(macro.c)                             # R
        if not valid_reconfig(r_c): return rollback_and_fallback(M, s)
        receipts = M.tcv.execute(macro.prog, M.env)                 # C + E
        mu, Sig = M.apcal_joint(M.mu_prev, M.Sig_prev, receipts,
                                c=macro.c, b_r=r_c.b_r)             # C（联合校准）
        if not M.cross_validate(mu, Sig, M.cross_receipt(s, macro.c)):  # V
            continue
        if not M.caldag.emi_ok(plan, macro.c, macro.cert):          # U 前复核
            return rollback_and_fallback(M, s)
        new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s, c=macro.c)
        if not contract_regression(new_ec): return stub_and_red(s, "regression")
        M.mreg.hot_replace(M.dpe, new_ec)                           # U
        M.caldag.rebind(s, receipts, c=macro.c)
        bind_claims(new_ec, H, plan, receipts)
        if M.caldag.certifies(s): break
    return M.caldag.certifies(s)

## 4. 推导

**引理 51（构型信息占优与秩修复）** 若 `c'` 观测集 ⊇ `c` 且新增观测条件独立，则 `F(c') ≽ F(c)`，
后验协方差 `(Σ₀⁻¹+F(c'))⁻¹ ≼ (Σ₀⁻¹+F(c))⁻¹`；若 `c` 下 `vᵀF(c)v=0` 而 `c'` 下 `>0`，则 `c'` 修复该方向。
系：固定夹具无法降低的秩亏方向，可重构机构可能修复——「换几何优于加样本」的形式化。

**引理 52（计划证书可靠性）** 模型误差有界 `‖ĥ−h‖≤ε_m`、亚高斯噪声、线性化半径内，
`PlanCert` 以 `≥1−δ` 成立（FIM Lipschitz 扰动 + 对 `H` 步 union bound）。
系：证书不可算/超界 ⇒ 拒绝 ⇒ 无「未认证却执行」路径。

**引理 53（重配置下的证据保持）** 若字段 `v` 的支撑回执不引用 `c→c'` 改动的几何/位姿/外参，
则热替换后 `v` 逐位不变；`Keep` 上子图数值等价（推广第 2 轮引理 49）。

**引理 54（贪心次优与顺序敏感）** 存在构型集合与代价结构，使逐动作贪心累计净收益 `≤ OPT/(1+Ω_max·H)`。
系：`Ω` 小且代价满足拟阵条件时可安全交换剪枝，否则禁用（定义 441）。

**引理 55（EMI ⇒ 无活锁）** EMI 成立、预算有限、每个恢复子计划严格减少未认证字段数（或严格消耗正预算）时，
`8C` 必在 `H·H_max` 步内终止于 `certified` 或 `stub+RED`。证明：字典序良基测度 `(未认证字段数, 剩余预算)` 严格下降。

**引理 56（时序与实时性保持）** 规划/重配置全在 50Hz 路径外；50Hz 新增仅 `O(1)` 构型状态检查；
`τ_reconfig/τ_plan` 由 RM-Budget 界定，超时退化 ⇒ 硬实时与预算不变式保持（继承引理 50）。

## 8. 本轮最大风险

**一句话**：重配置会同时改变「可观测性」与「标定基准」，规划器可能为了看见盲区而摧毁
证明该盲区已被看见的标定——**证书自指失效**，导致构型震荡/活锁，并让所有被重标定的字段同时偏移。

**三重兜底**：Schur 补条件信息（定义 434）拒绝「假信息」、EMI（定义 439）+ 良基测度（引理 55）拒绝
「先毁后想」与活锁、Cal-DAG 逐位等价回归（引理 53/E444）保证未受影响子图不被污染；
任一失效 ⇒ 固定构型 ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。
