### 第 1 轮灵感驱动研究记录

**灵感词**：可用性评估、深度学习

**直觉与动机**：

先给直觉。前几轮我们把证书从「布尔有效性」推进到「时空有效域 + 抓取动力学 + 数据挖掘」，但所有门控仍由人手设定阈值：κ < 50、λ_max < 0.02、γ_data > 0.3……这些阈值回答的是「证书在理想模型下是否有效」，却没有回答一个更朴素的问题：**此刻这个证书，对这台机器人、这个任务，到底还能不能用？** 可用性评估（usability / availability assessment）正是这个缺口：它不问证书「对不对」，而问证书「用不用得上、用了会不会出事」。

深度学习则提供两种互补能力：(1) 从高维、多模态的上下文（图像、点云、本体感知、证书历史、环境嵌入）中**学习**可用性的条件分布，替代脆弱的手工阈值；(2) 从任务成功/失败、证书互相矛盾等弱信号中**回溯标注**，让「可用性」成为可训练、可校准的量。直觉上，这相当于给证书系统请一位经验丰富的老师傅：他未必写得出解析式，但一眼能判断「这个定位在隧道里不能信」「这帧纹理太少，视觉伺服该降级」。

但必须警惕：深度学习擅长给出「看起来合理」的答案。若把它的输出直接当真理，就会把原来的「布尔虚假安全感」升级为「校准过的虚假安全感」——后者更危险，因为它带着漂亮的置信区间。

**严谨定义（增量）**：

1. **证书可用性评分（CAU）**：对证书 c 与上下文 x_t，定义 a_c(x_t) = Pr(support(c, x_t) | evidence)，其中 support 表示「消费 c 后、于任务视界 H 内不产生违反或矛盾」。a_c ∈ [0,1]，区别于二值 valid。核心约定：valid ⇒ a_c > 0，但 a_c 高**不**蕴含 valid——可用性是有效性的必要条件而非充分条件。
2. **深度可用性评估器（DCAA）**：a_t = f_θ(x_t)，x_t = (o_t, q_t, h_t, e_t)，θ 由时序多模态网络参数化；M 个深度集成成员给出认知不确定度 σ_epi 与偶然不确定度 σ_alea。
3. **保形可用性证书（CUC）**：UC_c = (a_c, a_c^lo, a_c^hi, 1−α, hash(θ), ood_c)，[a^lo, a^hi] 为分裂保形预测区间，在可交换性假设下保证边缘覆盖 ≥ 1−α。
4. **可用性门控 KC 规则**：kc_usable(c) = c.valid ∧ (a_c^lo ≥ τ_use)。硬证书仍是必要条件，可用性只做进一步收缩，从而保证执行集单调收缩（Exec_v2 ⊆ Exec_v1）。
5. **风险预算聚合**：R(x_t) = Σ_c w_c · (1 − a_c^lo) · cost_c；当 R > B 或任一关键证书 a^lo < τ_use 时触发分级回退。
6. **神经-符号蒸馏**：把 DCAA 蒸馏为可解释规则集 R_KC，供 CertChecker 在无 GPU / 低算力时兜底，并保留人类可审计性。
7. **元可用性评估**：评估「评估器本身」的 ECE、保形覆盖、FUR（false-usable rate）、漂移鲁棒性与自一致性。

**关键洞见**：可用性评估把「证书是否有效」从**存在性判断**转变为**支撑度估计**；深度学习把「支撑度」从**手工先验**转变为**可校准的经验分布**。二者的结合点不是「用神经网络替换证书」，而是「用学习到的可用性去约束证书的消费」——证书仍是安全契约，深度学习只是给契约加上可信度注解。这既保住了 CADVS「证书驱动」的安全内核，又补上了「阈值脆弱」与「证据链断裂」两个旧缺口。

**形式化目标（增量）**：

1. 定义 CAU 与二值 valid 的合取关系，证明 Exec_v2 ⊆ Exec_v1 ⊆ Exec_v29。
2. 定义 DCAA 的时序多模态编码与不确定度分解（σ_epi / σ_alea）。
3. 定义 CUC 的分裂保形校准流程与覆盖保证，并显式标注可交换性失效条件。
4. 定义 AACA 的风险预算聚合与分级回退（NONE / DEGRADE / FORCE_TEACHER）。
5. 定义 NSKD 的蒸馏保真度指标与规则提取，给出「保真度不足即拒绝蒸馏」的守门。
6. 定义 RUL 的回溯弱标注流程，及 UME 对「自证循环」的监控指标。
7. 定义 CADVS-v2 = CADVS-v1 ∪ {DCAA, CUC, AACA, DSUM, NSKD, RUL, UME, AUQ}，且 Exec_CADVS-v2 ⊆ Exec_CADVS-v1。

**本轮最大风险**：**自证循环的「可用性幻觉」**——DCAA 的训练标签来自证书系统自身的事后矛盾/成功信号，若证书系统存在系统性盲区，DCAA 会把盲区学成「高可用」，而保形校准又会给它一个看似可靠的置信区间；于是系统在最需要报警的分布尾部反而最自信。

## 2. 关键算法骨架

### IP-481 Deep Certificate Availability Assessor (DCAA)

```python
@dataclass
class DeepCertificateAvailabilityAssessor:
    """DCAA：时序多模态深度可用性评估器（深度集成）"""
    cert_ids: list = field(default_factory=lambda: [
        'kc_loc_valid', 'kc_vs_active', 'kc_spatiotemporal_valid',
        'kc_grab_stable', 'kc_balance', 'kc_student_trust'])
    window: int = 64          # 证书历史窗口
    d_model: int = 256
    n_heads: int = 8
    ensemble_size: int = 5
    tau_use: float = 0.6

    def __post_init__(self):
        self.encoders = [MultiModalEncoder(d_model=self.d_model,
                                           n_heads=self.n_heads)
                         for _ in range(self.ensemble_size)]
        self.heads = [nn.Linear(self.d_model, len(self.cert_ids))
                      for _ in range(self.ensemble_size)]

    def encode(self, ctx: Context, m: int) -> torch.Tensor:
        # o_t: 图像/点云 CNN/PointNet；q_t: 本体 MLP；
        # h_t: 证书历史 Transformer；e_t: 环境嵌入（地形/光照/几何先验）
        return self.encoders[m](
            image=ctx.o_t, proprio=ctx.q_t,
            cert_hist=ctx.h_t[-self.window:], env=ctx.e_t)

    def predict(self, ctx: Context) -> AvailabilityPrediction:
        logits = torch.stack([head(self.encode(ctx, m))
                              for m, head in enumerate(self.heads)])  # (M,K)
        probs = torch.sigmoid(logits)                                 # (M,K)
        a = probs.mean(dim=0)
        sigma_epi = probs.std(dim=0)                                  # 认知
        sigma_alea = torch.sqrt((probs * (1 - probs)).mean(dim=0))    # 偶然
        return AvailabilityPrediction(a=a, sigma_epi=sigma_epi,
                                      sigma_alea=sigma_alea)

    def loss(self, pred, y, lam_cal: float = 0.1, lam_ood: float = 0.05):
        # 1) 主任务：可用性回归/分类（弱标签 y ∈ {0,0.5,1}）
        bce = F.binary_cross_entropy(pred.a.clamp(1e-6, 1-1e-6), y)
        # 2) 校准项：成员均值与经验频率对齐（Brier）
        brier = ((pred.a - y) ** 2).mean()
        # 3) 集成多样性项：惩罚成员过度一致，保留认知不确定度
        diversity = -pred.sigma_epi.mean()
        return bce + lam_cal * brier + lam_ood * diversity
```

### IP-482 Conformal Usability Certificate (CUC)

```python
@dataclass
class ConformalUsabilityCertificate:
    """CUC：分裂保形校准，把 DCAA 输出包装为带覆盖保证的可用性证书"""
    alpha: float = 0.1
    tau_use: float = 0.6
    ood_max: float = 0.5

    def __post_init__(self):
        self.q_hat = None
        self.model_hash = None

    def calibrate(self, cal_loader, dcaa, model_hash: str):
        """在留出校准集上计算残差分位数；校准集必须与训练集不相交"""
        scores = []
        for ctx, y_true in cal_loader:
            pred = dcaa.predict(ctx)
            scores.append(float(np.abs(pred.a - y_true)))
        n = len(scores)
        # 有限样本修正：ceil((n+1)(1-alpha))/n 分位
        self.q_hat = float(np.quantile(scores,
                                       min(1.0, (1 - self.alpha) * (1 + 1 / n))))
        self.model_hash = model_hash

    def build(self, pred, ood_score: float) -> UsabilityCert:
        assert self.q_hat is not None, 'CUC 未校准，禁止签发'
        lo = np.clip(pred.a - self.q_hat, 0.0, 1.0)
        hi = np.clip(pred.a + self.q_hat, 0.0, 1.0)
        # 硬门控：下界达标且不在分布外
        usable = bool(np.all(lo >= self.tau_use)) and ood_score < self.ood_max
        return UsabilityCert(a=pred.a, a_lo=lo, a_hi=hi,
                             coverage=1 - self.alpha, model_hash=self.model_hash,
                             ood=ood_score, usable=usable)

    def cert_payload(self, uc: UsabilityCert, cert_id: str) -> dict:
        return {
            'cert_id': f'kc_usable:{cert_id}',
            'payload': {'a': uc.a.tolist(), 'a_lo': uc.a_lo.tolist(),
                        'a_hi': uc.a_hi.tolist(), 'ood': uc.ood,
                        'usable': uc.usable},
            't_stamp': time.time(),
            'validity_window': 0.05,      # 50ms，可用性变化快
            'src_node': 'dcaa',
            'model_hash': uc.model_hash,
        }
```

### IP-483 Availability-Aware Certificate Aggregation (AACA)

```python
@dataclass
class AvailabilityAwareCertAggregator:
    """AACA：硬证书合取 + 风险预算 + 分级回退"""
    tau_use: float = 0.6
    budget_B: float = 0.2
    costs: dict = field(default_factory=lambda: {
        'kc_loc_valid': 5.0, 'kc_vs_active': 2.0,
        'kc_grab_stable': 4.0, 'kc_balance': 5.0})

    def aggregate(self, hard_certs: dict, cus: dict) -> AggregationResult:
        # 1) 硬证书必须全部通过——原样继承 CADVS-v1，保证执行集单调收缩
        if not all(hard_certs.values()):
            return AggregationResult(action=Fallback.FORCE_TEACHER,
                                     risk=float('inf'), reason='hard_cert_fail')
        # 2) 风险预算：可用性下界越低、误用代价越高，风险越大
        risk = 0.0
        for cid, uc in cus.items():
            risk += self.costs.get(cid, 1.0) * (1.0 - float(np.min(uc.a_lo)))
        # 3) 关键证书可用性门控
        critical_ok = all(float(np.min(cus[c].a_lo)) >= self.tau_use
                          for c in self.costs if c in cus)
        if risk > self.budget_B or not critical_ok:
            return AggregationResult(action=Fallback.DEGRADE,
                                     risk=risk, reason='usability_budget')
        return AggregationResult(action=Fallback.NONE, risk=risk,
                                 reason='ok')

    def apply(self, result: AggregationResult) -> ControlMode:
        return {Fallback.NONE: ControlMode.STUDENT_VS,
                Fallback.DEGRADE: ControlMode.STUDENT_ONLY,
                Fallback.FORCE_TEACHER: ControlMode.TEACHER}[result.action]
```

### IP-484 Distribution Shift Usability Monitor (DSUM)

```python
@dataclass
class DistributionShiftUsabilityMonitor:
    """DSUM：能量 + 马氏距离双通道 OOD，漂移时下压可用性"""
    ood_max: float = 0.5
    drift_max: float = 3.0
    ema: float = 0.99
    ref_stats: dict = field(default_factory=dict)

    def energy(self, logits: np.ndarray) -> float:
        return float(-logsumexp(logits, axis=-1))

    def mahalanobis(self, z: np.ndarray) -> float:
        d = z - self.ref_stats['mu']
        return float(np.sqrt(max(0.0, d @ self.ref_stats['prec'] @ d)))

    def update(self, z: np.ndarray, logits: np.ndarray) -> ShiftReport:
        e = self.energy(logits)
        m = self.mahalanobis(z)
        ood = (e > self.ood_max) or (m > self.drift_max)
        # 漂移惩罚：越界越多，下压越狠（上限 1.0）
        penalty = 0.0 if not ood else float(
            min(1.0, 0.5 * (m - self.drift_max) + 0.5 * max(0.0, e - self.ood_max)))
        self.ref_stats['mu'] = (self.ema * self.ref_stats['mu']
                                + (1 - self.ema) * z) if 'mu' in self.ref_stats else z
        return ShiftReport(ood=ood, energy=e, mahalanobis=m, penalty=penalty)

    def tighten(self, uc: UsabilityCert, shift: ShiftReport) -> UsabilityCert:
        if not shift.ood:
            return uc
        uc.a_lo = np.clip(uc.a_lo - shift.penalty, 0.0, 1.0)
        uc.usable = bool(np.all(uc.a_lo >= 0.6))
        return uc
```

### IP-485 Neural-Symbolic KC Distiller (NSKD)

```python
@dataclass
class NeuralSymbolicKCDistiller:
    """NSKD：把 DCAA 蒸馏为可解释规则；保真度不足即拒绝"""
    max_depth: int = 4
    min_agreement: float = 0.95
    tau_use: float = 0.6

    def _symbolic_features(self, ctx: Context) -> np.ndarray:
        # 只允许可解释、可在线计算的物理量
        return np.array([
            ctx.kappa_jacobian, ctx.track_conf, ctx.depth_var,
            ctx.lambda_loc, ctx.t_since_loc, ctx.cog_offset,
            ctx.force_ratio, ctx.ood_energy, ctx.cert_age,
            ctx.spatial_dist / ctx.R_cec])

    def distill(self, dcaa, data_loader) -> DistillResult:
        X, Y = [], []
        for ctx, _ in data_loader:
            pred = dcaa.predict(ctx)
            X.append(self._symbolic_features(ctx))
            Y.append(int(np.all(pred.a >= self.tau_use)))
        X, Y = np.asarray(X), np.asarray(Y)
        tree = DecisionTreeClassifier(max_depth=self.max_depth).fit(X, Y)
        agreement = float(tree.score(X, Y))
        if agreement < self.min_agreement:
            return DistillResult(rules=[], agreement=agreement, accepted=False)
        rules = self._extract_rules(tree)          # 转成 KC 谓词
        return DistillResult(rules=rules, agreement=agreement, accepted=True)
```

### IP-486 Retrospective Usability Labeler (RUL)

```python
@dataclass
class RetrospectiveUsabilityLabeler:
    """RUL：从证书矛盾与任务结果回溯生成弱标签"""
    horizon: int = 50
    contradiction_window: int = 5

    def _contradicts(self, cert: CertMsg, future: CertMsg) -> bool:
        # 例：定位证书声称 valid，但后续相对位姿与之矛盾超过 γ_consist
        if cert.cid == 'kc_loc_valid' and future.cid == 'kc_pose_consistency':
            return future.payload['err'] > 0.05
        if cert.cid == 'kc_vs_active' and future.cid == 'kc_vs_lost':
            return True
        return False

    def label(self, episode: Episode) -> list:
        labels = []
        for t, cert in enumerate(episode.certs):
            future = episode.certs[t + 1:t + 1 + self.horizon]
            contradicted = any(self._contradicts(cert, f) for f in future)
            window_ok = bool(episode.success[t:t + self.horizon].all()) \
                if t + self.horizon <= len(episode.success) else False
            if contradicted:
                y = 0.0
            elif window_ok:
                y = 1.0
            else:
                y = 0.5                       # 不确定，训练时降权
            labels.append(UsabilityLabel(cid=cert.cid, t=t, y=y,
                                         source='retrospective'))
        return labels

    def label_weight(self, y: float) -> float:
        return {0.0: 1.0, 1.0: 1.0, 0.5: 0.25}[y]   # 不确定样本降权
```

### IP-487 Usability Meta-Evaluator (UME)

```python
@dataclass
class UsabilityMetaEvaluator:
    """UME：评估评估器本身（校准 / 覆盖 / FUR / 自一致性）"""
    alpha: float = 0.1
    ece_bins: int = 15
    fur_max: float = 0.02

    def _ece(self, preds, labels) -> float:
        bins = np.linspace(0, 1, self.ece_bins + 1)
        ece = 0.0
        for lo, hi in zip(bins[:-1], bins[1:]):
            mask = (preds >= lo) & (preds < hi)
            if mask.sum() == 0:
                continue
            conf = preds[mask].mean()
            acc = labels[mask].mean()
            ece += mask.mean() * abs(conf - acc)
        return float(ece)

    def evaluate(self, preds, labels, intervals) -> MetaReport:
        ece = self._ece(preds, labels)
        coverage = float(np.mean([(lo <= y <= hi)
                                  for (lo, hi), y in zip(intervals, labels)]))
        fur = float(np.mean([(a >= 0.6) and (y == 0)
                             for a, y in zip(preds, labels)]))
        return MetaReport(
            ece=ece, coverage=coverage, fur=fur,
            coverage_ok=coverage >= 1 - self.alpha - 0.03,
            fur_ok=fur <= self.fur_max,
            # 自一致性：同一上下文多次前向的方差不应过大
            self_consistent=bool(np.mean([hi - lo for lo, hi in intervals])
                                 < 0.3))
```

### IP-488 Active Usability Query (AUQ)

```python
@dataclass
class ActiveUsabilityQuery:
    """AUQ：主动选择最有价值样本请教师/人工标注"""
    budget: int = 20
    strategy: str = 'bald'          # 'bald' | 'epistemic' | 'random'

    def _bald(self, dcaa, ctx) -> float:
        # 互信息近似：成员预测熵 − 平均成员熵
        probs = dcaa.member_probs(ctx)              # (M,K)
        mean_p = probs.mean(axis=0)
        h_mean = -(mean_p * np.log(mean_p + 1e-8)
                   + (1 - mean_p) * np.log(1 - mean_p + 1e-8)).sum()
        h_each = -(probs * np.log(probs + 1e-8)
                   + (1 - probs) * np.log(1 - probs + 1e-8)).sum(axis=1).mean()
        return float(h_mean - h_each)

    def select(self, pool, dcaa) -> list:
        if self.strategy == 'random':
            idx = np.random.choice(len(pool), size=self.budget, replace=False)
            return [pool[i] for i in idx]
        scores = [self._bald(dcaa, ctx) if self.strategy == 'bald'
                  else float(dcaa.predict(ctx).sigma_epi.mean())
                  for ctx in pool]
        return [pool[i] for i in np.argsort(scores)[-self.budget:]]
```

## 4. 正确性论证（增量更新）

### 引理 35（保形可用性证书的覆盖保证）

**陈述**：设校准样本与测试样本 (x_i, y_i) 可交换，残差分数 s_i = |a(x_i) − y_i|，q̂ 为 ⌈(n+1)(1−α)⌉/n 分位数。则由 CUC 签发的区间 [a−q̂, a+q̂] 满足 P(y ∈ [a−q̂, a+q̂]) ≥ 1−α。

**证明**：由分裂保形的有限样本覆盖定理，可交换性下 P(s_{n+1} ≤ q̂) ≥ 1−α。因 s_{n+1} = |a(x_{n+1}) − y_{n+1}|，故 |y − a| ≤ q̂ 的概率 ≥ 1−α，即 y 落入区间。∎

**诚实声明**：可交换性在部署中**不成立**——环境漂移、传感器老化、任务切换都会破坏它。因此 CUC 的覆盖保证只是「名义保证」，必须配合 DSUM 在检测到漂移时主动下压 a_lo，否则会出现「名义 90% 覆盖、实际远低」的校准幻觉。这正是本轮最大风险的数学根源。

### 引理 36（可用性门控的风险上界）

**陈述**：若 CUC 覆盖成立（引理 35），且 AACA 要求关键证书 a_lo ≥ τ_use，则单证书的期望违反概率满足 E[1{support=0}] ≤ (1−τ_use) + α。

**证明**：以概率 ≥ 1−α 有 y ≥ a_lo（因 y ∈ [a−q̂, a+q̂] 且 a_lo = a−q̂）。在该事件上 a_lo ≥ τ_use ⇒ y ≥ τ_use，即违反概率 ≤ 1−τ_use。以概率 ≤ α 覆盖失效，此时违反概率至多 1。合并得 E[1{support=0}] ≤ (1−α)(1−τ_use) + α ≤ (1−τ_use) + α。∎

**工程含义**：τ_use 与 α 是两个可直接调节的「安全旋钮」。缺省 τ_use=0.6、α=0.1 时，单证书名义违反率上界约 0.5；对代价高的证书应提高 τ_use 至 0.8–0.9。

### 引理 37（神经-符号蒸馏的保真度—风险界）

**陈述**：设蒸馏规则 R_KC 在分布 𝒟 上与 DCAA 的判定一致率为 1−ε_fid，安全损失函数 ℓ 关于可用性判定为 L-Lipschitz。则在 𝒟 上 R_KC 相对 DCAA 的额外期望安全损失 ≤ L·ε_fid。

**证明**：以指示变量表示判定差异，E[ℓ(R_KC) − ℓ(DCAA)] ≤ L·P(R_KC ≠ DCAA) = L·ε_fid。∎

**诚实声明**：一致率只在训练分布 𝒟 上估计，分布外一致率可能骤降。故 NSKD 设 min_agreement=0.95 的硬守门，且蒸馏规则仅作**无 GPU 兜底**，绝不替代 DCAA 作为主裁决；一旦 UME 检测到规则与 DCAA 分歧率上升，立即停用 R_KC。

### 定理（CADVS-v2 执行集收缩与假可用率下降）

**陈述**：在以下假设下：
- (B1) CUC 在部署分布上覆盖成立（或 DSUM 已检测并下压）；
- (B2) AACA 保留 v1 全部硬证书合取；
- (B3) RUL 标签相对证书系统盲区无系统性污染（即标注独立于盲区）；
- (B4) UME 的 FUR 监控有效，FUR > FUR_max 时冻结 DCAA 并回退 v1；

有 Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29，且对满足 (B1)–(B4) 的轨迹段，假可用率 FUR_v2 ≤ FUR_v1 − Δ，其中 Δ > 0 随 τ_use 与覆盖质量单调增加。

**证明**：
- **执行集收缩**：v2 单步逻辑 = v1 硬证书合取 ∧ (a_lo ≥ τ_use) ∧ (R ≤ B) ∧ (¬ood)。这是 v1 条件与额外合取项的合取，故 Exec_v2 ⊆ Exec_v1。又 Exec_v1 ⊆ Exec_v29（v1 定理），传递得证。
- **FUR 下降**：v1 中「硬证书通过但实际不可用」即假可用。v2 在此之上要求 a_lo ≥ τ_use；由引理 36，该条件将假可用概率压低至少 (1−τ_use) 的相对比例；DSUM 在漂移时进一步下压 a_lo；UME 在 FUR 超标时直接回退 v1。三重合取只会移除「v1 会接受但 v2 拒绝」的危险样本，不会新增假可用，故 FUR_v2 ≤ FUR_v1 − Δ。∎

**诚实声明**：假设 (B3) 是整个定理最脆弱的一环，且**无法被数据本身验证**——因为标签正是从被评估的系统里产生的。若盲区是系统性的，RUL 会把盲区标成「成功」，DCAA 学到「盲区=高可用」，定理的 Δ > 0 便不再成立。这不是工程 bug，而是方法论层面的自指困难，只能靠外部独立证据（人工审计、独立传感器、物理模型反证）打破。

## 7. 本轮最大风险（最终确认）

**一句话**：**自证循环的「可用性幻觉」**——DCAA 的标签来自证书系统自身的事后矛盾/成功信号，若系统存在系统性盲区，DCAA 会把盲区学成「高可用」，而保形校准再给它一个看似可靠的置信区间，使系统在最需要报警的分布尾部反而最自信；这是比「证据链断裂」更隐蔽的方法论级风险，因为它在数据、校准、监控三层都「看起来正确」，只能靠独立于证书系统的外部证据来打破。
