# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「传感器标定」×「位姿估计」）

> R69 把不确定性一分为二，让系统学会「问」：aleatoric 收紧，epistemic 去交互消解。但它默认了一件从未验证的事——**「歧义一旦可分，就问得出来」**。这条默认藏着两个漏洞：
> 1. R69 的 `U_ale = tr(Σ)` 与 `λ_floor` 都是**标量**。而真实不确定性（尤其姿态与标定）是**有方向的**：走廊里前后极差、侧向很好；某个标定自由度根本没有被激励过，它的不确定性是「整条轴都盲」。标量化既浪费预算，又会在真正致盲的方向上给出**虚假的乐观**。
> 2. R69 的交互（看/问/触）都是**在当前位姿上取证**。若判别性证据落在当前配置的**不可观测子空间**里，问一百次也问不出来——不是「不值得问」，而是「问了也看不见」。此时唯一的信息动作不是「看」，而是「**动**」：走到一个让该自由度变得可观测的位姿。
>
> 本轮两个灵感正好统一了这两点：
> - **传感器标定**告诉我们：标定不是查表，是**估计**；参数只有在被充分激励（persistent excitation）时才可观测，标定问题的本质是「用运动换取信息」（D-最优实验设计）。
> - **位姿估计**告诉我们：标定与位姿是**同一件事**——外参是一段传感器间位姿，位姿是一段传感器-世界位姿，二者都在 SE(3) 上，误差都在李代数 se(3) 上呈**各向异性的协方差**，而判别性还来自**回环/全局一致性**。
>
> 核心命题：**把「不确定性」从标量升级为「流形上的方向性协方差 + 可观测性谱」；只有落在可观测子空间的 epistemic 才值得交互，落在盲子空间的必须靠「主动激励」把证据搬进可观测区，搬不动就沿盲方向做方向性保守膨胀；并用回环几何债务作为第三条不可被局部标定吸收的故障通道。** 命名 **PRISM-RAS**（Pose-observability, Riemannian Information, Sensor-calibration Manifold）。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**从我这个位置，这个问题到底看不看得见；看不见，我该怎么动**」——不确定性不只是刹车、不只是提问，也可以是**一次为了看清而做的机动**。

## 0. 直觉与动机

**灵感 1（标定即位姿 → 不确定性本来就住在流形上）**
直觉：R68 把标定当成一组可以「调掉」的标量偏置，R69 把不确定性当成动作空间里的一个标量散布。但外参本身就是一段 SE(3) 位姿，位姿估计与外参标定是同一个估计问题，只是参考系不同。因此「标定残差」与「位姿误差」不该分两套账：它们共用同一个李群状态、同一个协方差、同一张因子图。一旦承认这一点，冗余的传感器标定就变成**多段位姿之间的约束**，而回环闭合就变成一个全局的、无法被单帧标定吸收的一致性检验。

**灵感 2（可观测性 → 有些不确定性是「看不见」，不是「太模糊」）**
直觉：位姿估计里最要命的不是噪声大，而是**退化（degeneracy）**：对着白墙、沿长走廊直行、在平面上运动、静止时标定——某些自由度根本没有信息。此时协方差在该方向上是「一条没有尽头的轴」，而 R69 的标量 `tr(Σ)` 会把这条轴和别的方向糊在一起。一个成熟的做法不是把整体拉大，而是**沿这条轴拉大、沿其它轴保持**。这要求把不确定性保留成**方向性协方差**，并显式算出可观测子空间 O 与盲子空间 B。

**灵感 3（激励 → 消除歧义的动作不止「问」，还有「动」）**
直觉：R69 的信息动作是在当前位姿上「看/问/触」。但经典标定理论说：不可观测的参数不会因为你看得更仔细就变得可观测，它需要**激励**——你必须运动出足够的姿态变化，让回归量满秩。把这一条接进闭环，就得到：当歧义落在盲子空间时，正确的 VoI 动作不是静止的注视或提问，而是一条**故意为可观测性设计的小幅机动**（D-最优实验设计：最大化 `log det F(ζ)`）。这既是「主动感知」，也是「主动标定」，与 R69 的 MINT 共用同一个 VoI−成本骨架，只是动作空间从 `g` 扩到了机动轨迹 `ζ`。

**灵感 4（回环 → 一条局部标定吸收不了的几何通道）**
直觉：R69 已经用「动作似然」给传感器残差做了第二意见，但行为似然也可能被同一份有偏数据带偏。位姿估计给出第三条更硬的通道：**回环几何债务**。局部标定偏差 `b` 会被拟合吸收（`r_res≈0`），但只要你走一个回环、展开一段基线，回环残差就正比于 `b·L` 累积起来，无法被逐帧标定吞掉。`D_geo` 因此是三条通道里最难被欺骗的：它不依赖学习到的策略密度，只依赖几何自洽。

**灵感 5（棱镜 → 沿可观测方向把不确定性拆开，并保证严格包含）**
直觉：一块棱镜把一束白光按方向拆成光谱；PRISM 把一团标量不确定性按可观测性拆成「看得见的部分」与「看不见的部分」。可观测部分交给交互/激励去消解，盲部分只能做方向性保守膨胀。关键的理论姿态仍是前几轮的老规矩：**新层必须严格包含旧层**。当协方差各向同性、盲子空间为空、无回环时，方向性膨胀退化为标量 `λ_floor`，主动激励退化为 R69 的 MINT，PRISM 逐指令等于 FLUID；再叠加 `VoI≤成本` 等于 CALM。安全侧永不让步，只在「方向」上把 R68/R69 白白扔掉的效率捡回来。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PRISM-RAS 总览）** PRISM-RAS = (LGE, OBS, AED, EXC, GCM, LCX, DRS, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **激励预算硬约束**：单位时间激励能量 ≤ ε_exc、时长 ≤ T_exc、位移 ≤ ε_g，且激励轨迹必须与任务动作一样通过 C-RAS-WM 认证，且不得使任务先验失败；
(iii) **可观测性纪律**：只有落在可观测子空间 O 的 epistemic 才允许被「消解」；落在盲子空间 B 的分量不得被任何静态交互宣称已解决，只能靠激励搬进 O，或沿 B 做方向性保守膨胀。

**定义 311（标定-位姿统一状态 LGE）** 联合状态 χ = (T₀,…,T_n; c₁,…,c_m) ∈ SE(3)^{n+m+1}，其中 T_i 为机体/传感器在世界系的位姿，c_j 为传感器间外参（也是一段位姿）。右扰动误差：χ = χ̂·exp(δχ)，δχ ∈ se(3)^{n+m+1} ≅ ℝ^{6(n+m+1)}。协方差 Σ_χ 为块稀疏对称正定矩阵。**标定与外参不再单列，统一为同一条因子图上的位姿变量。**

**定义 312（Fisher 信息与可观测谱 OBS）** 设残差雅可比 J、量测噪声协方差 Λ，则信息矩阵 `F = JᵀΛ⁻¹J`（等价于 Gauss-Newton Hessian）。特征分解 `F = U diag(f₁,…,f_D) Uᵀ`（f₁≤…≤f_D，D=6(n+m+1)）。定义可观测子空间 `O = span{u_i : f_i ≥ f_thr}`、盲子空间 `B = span{u_i : f_i < f_thr}`、条件数 `κ_F = f_max/f_min⁺`。CRLB 在观测子空间上为 `Σ_CR = F⁺`（伪逆，B 上取 ∞）。

**定义 313（方向性不确定度 AED）** 对任意单位方向 u，`σ(u) = √(uᵀ Σ_χ u)`；张量型不确定度 = 整条谱 `{σ(u)}`，而非标量 `tr(Σ)`。定义各向异性比 `κ_σ = σ_max/σ_iso`，其中 `σ_iso = √(tr Σ / D)`。**R69 的 `U = tr Σ` 只保留了 σ_iso，丢掉了方向。**

**定义 314（可观测/盲 epistemic 分解）** 记 R69 的模态间散布为 `Σ_epi`，投影得 `U_O = tr(P_O Σ_epi P_O)`（可观测、可由交互/激励消解）与 `U_B = tr(P_B Σ_epi P_B)`（盲、当前配置静态不可解），`P_O/P_B` 为到 O/B 的投影。规定：`U_epi = U_O + U_B` 但**分通道处置**——`U_O` 可换 resolution bonus，`U_B` 只能换方向性膨胀或激励。

**定义 315（SE(3) 黎曼流匹配 RMP）** 把 R69 的 FMP 从 ℝ^D 提升到流形：x₀ 在切空间 se(3) 上采各向同性噪声，测地线路径 `x_s = exp_{x̂}(s·log_{x̂}(x₁))`（或李代数上的线性插值再 exp），速度场 `v_θ(x_s,s|o) ∈ T_{x_s}SE(3)`，回归目标为 `log_{x_s}(x₁)`（重投影到切空间）。采样用流形上的 Heun `N_step=2`。这保证生成的位姿/标定块不越出群结构（R69 的欧氏高斯噪声会在 SE(3) 外撒点，产生不可执行、也不可微的「伪位姿」）。

**定义 316（主动激励 EXC / D-最优实验设计）** 候选激励轨迹 `ζ ∈ 𝒵`（小幅转向、基线展开、受控往复等）。预期信息增益 `IG(ζ) = H(χ|o) − E_{y~p(·|ζ,o)}[H(χ|o,y)] ≈ ½ log det(I + F(ζ)Σ_χ⁻¹)`（D-最优等价式）。选择 `ζ* = argmax_ζ [IG(ζ) − c_exc(ζ)]`，s.t. 激励预算、C-RAS-WM 认证、任务先验不失败。若 `max[IG − c] ≤ 0`，不激励。

**定义 317（激励安全与任务先验）** 激励轨迹整体过 C-RAS-WM 前缀认证；定义任务先验约束 `task_prior.violates(ζ)`：激励不得把任务推进到不可恢复区、不得使时间窗过期、不得越过自由空间。任一不满足 ⇒ ζ 作废，`U_B` 视为未消解并走方向性膨胀。

**定义 318（Cramér-Rao 可辨识模态门 GCM）** 两个模态原型沿判别方向 u 的间距若非统计学上可分，即 `‖Δ‖ < γ·√(uᵀ Σ_CR u)`（Σ_CR = F⁺），则它们在当前数据下**不可辨识**，判为幻影模态：合并或剪枝，不进入 VoI 决策。这是对 R69「流模型幻觉出模态」的正面封堵。

**定义 319（回环几何债务 LCX）** 对位姿图窗口内的回环 `(i,j,T_ij)`，残差 `r_ij = log_SE3(χ_i⁻¹ T_ij χ_j)`，几何债务 `D_geo = Σ_loops ‖W r_ij‖ / √(baseline_ij)`。标定偏差 b 下局部 `r_res→0`，但 `D_geo ≈ b·L` 随回环尺度 L 线性增长。**这是第三条不可被局部标定吸收的故障通道。**

**定义 320（三通道联合故障判据）** 证据三元组 `(r_res, Δa, D_geo)`。判别规则：`r_res` 低但 `Δa` 高或 `D_geo` 增长 ⇒ 疑似缓变标定故障；三者联合分布分离「真漂移 / 缓变故障 / 正常」。R69 只用前两通道，R70 补上几何通道。

**定义 321（方向性风险缩放 DRS / 不确定管）** 对候选动作的扫掠体积 `S(a)`，认证时取其与不确定椭球 `E_Σ = {δ : δᵀΣ_χ⁻¹δ ≤ c²}` 的 Minkowski 和 `S(a) ⊕ E_Σ`（沿盲方向自动膨胀）。数学上等价于沿特征方向 `u_i` 膨胀 `c·σ(u_i)`。R69 的标量 `λ_floor` 是本定义在 `Σ = σ²I` 时的退化。

**定义 322（几何 resolution bonus）** 若 `U_O` 在预算内被交互或激励消解，则只在被消解的方向释放膨胀，其余方向保持；盲方向的膨胀不因任何静态交互而释放。安全侧单调不降。

**定义 323（严格包含链与退化边界）** 当 `κ_σ=1`（各向同性）、`B=∅`（全可观测）、且无回环（`D_geo=0`）时，PRISM 逐指令等于 FLUID；再叠加 `VoI(g*)≤c(g*)`、`ECE>τ_ece` 或 `slow_fault_suspect` 时逐指令等于 CALM。即 `R_CALM ⊇ R_FLUID ⊇ R_PRISM`（风险集），安全不让步，效率单调改进。

**定义 324（参与式审计 VQAuditor-P 与证书 J_PRISM）** 审计新增：可观测谱是否被正确估计、激励是否真正提升可观测性、盲方向是否被误标为已解决、回环债务是否被忽略。证书 `J_PRISM = (J_FLUID, spec_f_min, κ_F, κ_σ, excitation_log_hash, D_geo, CRLB_margin, prism_ver)`，Valid ⇔ `Valid(J_FLUID)` ∧ 可观测性纪律满足 ∧ 激励预算未越界。

**定义 325（干扰集 ℰ_PRISM）** 在 `ℰ_FLUID` 上增加：**退化攻击**（人为构造白墙/长走廊/平面场景，让某自由度不可观测，诱使系统信任错误标定）、**激励疲劳**（反复激励耗尽预算）、**回环伪造**（假回环把 `D_geo` 抹平）。`ℰ_PRISM = ℰ_FLUID × ℰ_degen × ℰ_exc`。

**定义 326（持续激励时序与自适应调度）** 维护一个滑窗激励回归量矩阵 `R(t)=∫φφᵀ`；当 `λ_min(R(t)) < ρ_pe`（持续激励条件将失效）或可观测余量 `f_min` 低于阈值时，才调度激励。常规路径不激励，保持实时；激励为一次性预算事件。

```python
# IP-264 LGE：标定-位姿统一李群估计（复用 R68 COF 残差，输出协方差而非标量）
class LieGroupEstimator:
    def __init__(self, iekf, noise_model):
        self.iekf, self.R = iekf, noise_model         # IEKF 在 SE(3)^N 上
    def update(self, obs):
        chi, Sigma = self.iekf.predict()
        chi, Sigma, r_res = self.iekf.update(obs)     # r_res 沿用 R68
        return chi, Sigma, r_res                      # Sigma: 6N×6N 块稀疏

# IP-265 OBS：可观测性谱分解（不给标量，给方向）
def observability(J, Lambda):
    F = J.T @ solve(Lambda, J)                        # Fisher / GN Hessian
    f, U = eigh(F)                                    # 升序
    O = U[:, f >= F_THR]; B = U[:, f < F_THR]         # 可观测 / 盲子空间
    return F, f, U, O, B

def directional_sigma(Sigma, dirs):
    return {u: sqrt(u.T @ Sigma @ u) for u in dirs}   # 方向性 σ(u)，取代 tr(Σ)

# IP-266 AED：可观测 epistemic 分解（盲歧义不可被静态交互解决）
def split_epistemic(Sigma_epi, O, B):
    P_O = O @ O.T; P_B = B @ B.T
    return trace(P_O @ Sigma_epi @ P_O), trace(P_B @ Sigma_epi @ P_B)  # U_O, U_B

# IP-267 EXC：从「问」到「动」——D-最优主动激励
def choose_excitation(chi, F, budget, task_prior):
    best = None
    for zeta in excitation_candidates(chi):           # 转向 / 基线展开 / 受控往复
        if not budget.allow(zeta):                          continue
        if not c_ras_wm.certify_excitation(zeta, chi):      continue
        if task_prior.violates(zeta):                       continue
        F_z = predicted_fisher(chi, zeta)
        ig  = 0.5 * logdet(I + F_z @ inv(F + EPS*I))        # D-最优增益
        score = ig - excitation_cost(zeta)
        if best is None or score > best.score: best = (zeta, score)
    return best if best and best.score > 0 else None

# IP-268 GCM：Cramér-Rao 可辨识模态门（杀幻影模态）
def crlb_gate(modes, F):
    Sigma_cr = pinv(F)                                 # 观测子空间 CRLB，B 上取 ∞
    keep = []
    for (i, j) in pairs(modes):
        delta = frechet(modes[i].proto, modes[j].proto); u = unit(delta)
        if norm(delta) >= GAMMA * sqrt(u.T @ Sigma_cr @ u):
            keep.append((i, j))                        # 统计学上可分
        # 否则：两模态在当前数据下不可辨识 → 合并/剪枝（幻影）
    return keep

# IP-269 LCX：回环几何债务（局部标定吸收不了的第三条通道）
def geometric_debt(pose_graph, chi, window):
    D = 0.0
    for (i, j, T_ij) in pose_graph.loops(window):
        r = log_SE3(inv(chi[i]) @ T_ij @ chi[j])
        D += norm(whiten(r)) / sqrt(loop_baseline(i, j))
    return D                                           # 标定偏差 b ⇒ D ~ b·L 增长

# IP-276 主闭环（继承 R69，插入可观测性/激励/几何债务）
def PRISM_RAS_round(M, obs):
    chi, Sigma, r_res = M.lge.update(obs)              # 1) 李群估计，得协方差
    z = M.mtm.encode(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(obs, K, manifold=True)      # 2) SE(3) 黎曼流匹配
    U_ale, U_epi, modes = M.aud.decompose(samples, Sigma)
    F, f, U, O, B = M.obs.observability(M.last_J, M.last_Lambda)
    U_O, U_B = M.aed.split_epistemic(U_epi, O, B)      # 看得见 / 看不见
    pairs = M.gcm.crlb_gate(modes, F)                  # 3) 先剪掉幻影模态
    # 4) 三条故障通道：残差 / 行为似然 / 回环几何债务
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs, M.obs.calibrated)
    D_geo = M.lcx.geometric_debt(M.pose_graph, chi, M.window)
    suspect = (r_res < TAU_RES) and (a_hat > TAU_FMA or D_geo > TAU_GEO)
    # 5) 看得见的歧义 → 交互；看不见的 → 激励（动）把它搬进可观测区
    act = None
    if not suspect:
        if U_O > TAU_EPI:
            act = M.mint.choose_interaction(modes, obs, M.budget)       # 看/问/触
        elif U_B > TAU_EPI:
            act = M.exc.choose_excitation(chi, F, M.budget, M.task_prior)  # 动
    if act is not None:
        y = M.exec(act); chi, Sigma, _ = M.lge.fuse(chi, Sigma, y)
        M.aed.apply_resolution_bonus(U_O, U_B, act)                     # 只释解可观测方向
    # 6) 方向性风险缩放：沿盲方向椭球膨胀，而不是全局减速
    lam_dir = M.drs.directional_scale(Sigma, B, U_B)
    A = M.ach.propose(chi, M.vista.H)
```

## 3. 推导

**引理 19（标量风险的各向异性欠覆盖）** 设误差协方差 Σ 在 D 维误差空间，特征值 `σ₁²≤…≤σ_D²`，`σ_iso=√(trΣ/D)`，`σ_max=σ_D`。R69 的标量 `U=trΣ` 对应各向同性膨胀半径 `σ_iso`，但最坏方向需要 `σ_max`。若按标量 U 膨胀，最坏方向的覆盖率被低估 `κ_σ=σ_max/σ_iso` 倍；要覆盖最坏方向，标量法必须整体放大到 `σ_max`，平均多付 `σ_max/σ_iso` 的代价。故**方向性膨胀在最坏方向同等安全时平均代价严格更低**。系：R69 的 `λ_floor` 是 `κ_σ=1` 的退化；沿盲方向，标量法系统性欠覆盖（欠覆盖比可达 `√D`）。

**引理 20（盲子空间中的静态交互零增益）** 若判别性证据方向 `u* ∈ B`（`f(u*) < f_thr`），则对任意不改变配置的静态信息动作 g，真实信息增益上界 `IG(g) ≤ ε_B = O(f_thr⁻¹)`。R69 的 VoI 用策略观测模型估计增益，若不显式编码可观测性，会在盲方向高估；Fisher 给出真实上界，故静态交互无法消解盲歧义——**这不是「不值得问」，而是「问了也看不见」**。

**引理 21（激励把证据搬进可观测区）** 持续激励下 `log det F(ζ)` 随激励能量单调增；存在 `ζ` 使 `uᵀF(ζ)u ≥ 1/σ_target²`，从而 `uᵀΣ_CR u ≤ σ_target²`。因此原先 `‖Δ‖<γ·√(uᵀΣ_CR u)` 的不可辨识模态对，在激励后可变得可辨识。系：`U_B` 的存在本身就是一个「该动」的信号。

**引理 22（几何债务的不可吸收性）** 标定偏差 b 下，局部残差 `r_res≈0`（被拟合吸收），动作似然 `Δa` 也可能因训练数据同偏置而失效；但回环残差 `r_ij ≈ b·L`，`D_geo≈b·L/√L = b√L` 随回环尺度增长。故 `b≠0 ⇒ D_geo>0` 不可被逐帧标定吸收，是三通道中最难被欺骗的几何证据。

**定理 18（PRISM 严格包含 FLUID）** 在 A99–A101（李群线性化有效、F 与 CRLB 有界、激励安全性成立）下，PRISM 任意状态期望风险 ≤ FLUID；当 `κ_σ=1`、`B=∅`、`D_geo=0` 时逐指令相同。叠加 R69 的退化条件后 PRISM ≡ CALM。故风险链 `R_CALM ⊇ R_FLUID ⊇ R_PRISM`：安全侧不让步，效率侧获方向性 resolution bonus。

**定理 19（激励安全与无突变）** 激励经 C-RAS-WM 认证（定义 317）后物理风险 ≤ ε_exc；任务先验约束保证不把任务做坏；激励失败/超时/退化时 `λ_dir` 单调不降地退化为 R69/R68 的保守膨胀；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

**定理 20（幻影模态有界）** 经 CRLB 门（定义 318）后，被采纳模态对均满足 `‖Δ‖ ≥ γ·√(uᵀΣ_CR u)`；真实不可分但被流模型分开的幻影，被剪枝的概率 ≥ 1−α（α 为 F 估计的置信失败率）。由此 R69「追问幻影」的错误率下降因子随 γ 增大，直接对冲 R69 自陈的最大风险。

## 6. 本轮最大风险

**一句话**：PRISM 把安全性押在「可观测性谱 F 估得对」上，而 F 恰恰是用它要检验的那套标定/位姿估计出来的——**一旦退化发生在非线性层面（线性化失效、噪声模型错、盲区随运动变化），或场景被人为构造成「看起来可观测、实则致盲」，系统就会用一把歪尺子量出「我没问题」，并沿真正致盲的方向给出方向性放行**；可观测性自证（self-confirming observability）比 R69 的单通道失效更隐蔽，因为它同时污染了「该不该信」与「该往哪动」两个判断。

**次级风险与缓解**：
1. **线性化/协方差失真**（F 只在大信号附近可信）→ 多假设 IEKF + 蒙特卡洛一致性校验（E302）+ 保守协方差下界；
2. **激励本身危险或拖垮任务** → 定义 317 任务先验 + C-RAS-WM 认证 + 定理 19 无突变 + 激励预算硬约束；
3. **退化攻击/假回环** → ℰ_degen/ℰ_exc 对抗训练 + `D_geo` 与局部残差的联合检验 + E312；
4. **计算预算被 6N×6N 特征分解与激励枚举击穿** → 块稀疏/低频重算 + 候选 ≤8 + 一次性激励预算；
5. **方向性膨胀被误当成「更安全」而绕开 R68 兜底** → 定理 18 严格包含 + 退化边界逐指令一致性测试（E309）作为回归门。

```python
def lge_update(iekf, obs):
    chi, Sigma = iekf.predict()
    chi, Sigma, r_res = iekf.update(obs)          # Sigma: 6N×6N 块稀疏
    return chi, Sigma, r_res

def observability(J, Lambda):
    F = J.T @ solve(Lambda, J); f, U = eigh(F)
    return F, f, U, U[:, f >= F_THR], U[:, f < F_THR]   # F,f,U,O,B

def split_epistemic(Sigma_epi, O, B):
    P_O, P_B = O @ O.T, B @ B.T
    return trace(P_O @ Sigma_epi @ P_O), trace(P_B @ Sigma_epi @ P_B)  # U_O,U_B

def choose_excitation(chi, F, budget, task_prior):

        score = ig - excitation_cost(zeta)
        if best is None or score > best.score: best = (zeta, score)
    return best if best and best.score > 0 else None

    chi, Sigma, r_res = M.lge.update(obs)
    K = 1 if M.fmp.mode_head(M.mtm.encode(obs)) < TAU_MODE else 4
    samples = M.fmp.sample(obs, K, manifold=True)                 # SE(3) 黎曼流匹配
    U_ale, U_epi, modes = M.aud.decompose(samples, Sigma)
    F, f, U, O, B = M.obs.observability(M.last_J, M.last_Lambda)
    U_O, U_B = M.aed.split_epistemic(U_epi, O, B)
    pairs = M.gcm.crlb_gate(modes, F)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs, M.obs.calibrated)
    D_geo = M.lcx.geometric_debt(M.pose_graph, chi, M.window)
    suspect = (r_res < TAU_RES) and (a_hat > TAU_FMA or D_geo > TAU_GEO)
    act = None
    if not suspect:
        if U_O > TAU_EPI:   act = M.mint.choose_interaction(modes, obs, M.budget)
        elif U_B > TAU_EPI: act = M.exc.choose_excitation(chi, F, M.budget, M.task_prior)
    if act is not None:
        chi, Sigma, _ = M.lge.fuse(chi, Sigma, M.exec(act))
        M.aed.apply_resolution_bonus(U_O, U_B, act)               # 只释可观测方向
    lam_dir = M.drs.directional_scale(Sigma, B, U_B)
    A = M.ach.propose(chi, M.vista.H)
    k = M.c_ras_wm.certified_prefix_dir(A, Sigma, M.free_space)   # 胶囊 ⊕ 不确定椭球
    if suspect: lam_dir = M.drs.conservative_dir(Sigma, B); k = min(k, M.c_ras_wm.cal_shrink(chi))
    mode = select_mode(modes, pairs, lam_dir)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam_dir
    M.vqa_p.submit_async(act, r_res, a_hat, D_geo, f, U_O, U_B)
    return k, lam_dir, mode, (U_ale, U_O, U_B)
```

## 4. 推导

**引理 19（标量风险的各向异性欠覆盖）** 特征值 `σ₁²≤…≤σ_D²`，`σ_iso=√(trΣ/D)`、`σ_max=σ_D`。标量 `U=trΣ` 对应各向同性膨胀 `σ_iso`，但最坏方向需 `σ_max`，欠覆盖比 `κ_σ=σ_max/σ_iso`（可达 `√D`）；要覆盖最坏方向标量法须整体放大到 `σ_max`，平均多付同倍代价。故方向性膨胀在最坏方向同等安全时平均代价严格更低；`λ_floor` 是 `κ_σ=1` 的退化。

**引理 20（盲子空间静态交互零增益）** 若判别方向 `u*∈B`（`f(u*)<f_thr`），任意不改变配置的静态交互真实增益上界 `IG(g)≤ε_B=O(f_thr⁻¹)`；R69 不编码可观测性的 VoI 会高估——「问了也看不见」，需激励（引理 21）。

**引理 21（激励搬证据）** 持续激励下 `logdet F(ζ)` 单调增；存在 ζ 使 `uᵀF(ζ)u ≥ 1/σ_target²`，从而 `uᵀΣ_CR u ≤ σ_target²`，原不可辨识模态对变可辨识。系：`U_B` 存在本身就是「该动」的信号。

**引理 22（几何债务不可吸收）** 标定偏差 b 下 `r_res≈0`、`Δa` 也可能失效，但回环残差 `≈b·L`，`D_geo≈b√L`，不可被逐帧标定吸收，是三通道最硬的几何证据。

**定理 18（PRISM 严格包含 FLUID）** A99–A101 下 PRISM 风险 ≤ FLUID；`κ_σ=1 ∧ B=∅ ∧ D_geo=0` 时逐指令相同；叠加 R69 退化条件 ≡ CALM。风险链 `R_CALM ⊇ R_FLUID ⊇ R_PRISM`：安全不让步，效率获方向性 bonus。

**定理 19（激励安全与无突变）** 激励经 C-RAS-WM 认证 + 任务先验 ⇒ 物理风险 ≤ ε_exc 且不把任务做坏；失败/超时/退化时 `λ_dir` 单调不降地退化到 R69/R68；提交/换装不变式保持 ⇒ 控制连续、无突变。

**定理 20（幻影模态有界）** CRLB 门后被采纳模态对满足 `‖Δ‖≥γ√(uᵀΣ_CR u)`；真实不可分而流模型误分的幻影被剪枝概率 ≥ 1−α，R69「追问幻影」错误率随 γ 增大而下降。

## 7. 本轮最大风险

**一句话**：PRISM 把安全性押在「可观测性谱 F 估得对」上，而 F 恰恰是用它要检验的那套标定/位姿估计出来的——**若退化发生在非线性层面（线性化失效、噪声模型错、盲区随运动变化），或场景被人为构造成「看起来可观测、实则致盲」，系统就会用一把歪尺子量出「我没问题」，并沿真正致盲的方向给出方向性放行**；可观测性自证比 R69 的单通道失效更隐蔽，因为它同时污染了「该不该信」与「该往哪动」两个判断。

**次级风险与缓解**：线性化/协方差失真（多假设 IEKF + 蒙特卡洛一致性校验 E302 + 保守协方差下界）；激励危险或拖垮任务（定义 317 任务先验 + C-RAS-WM 认证 + 定理 19 + 硬预算）；退化攻击/假回环（ℰ_degen/ℰ_exc 对抗训练 + `D_geo` 与局部残差联合检验 + E312）；计算预算被 6N×6N 特征分解与激励枚举击穿（块稀疏/低频重算 + 候选 ≤8 + 一次性激励）；方向性膨胀被误当「更安全」绕开 R68 兜底（定理 18 严格包含 + E309 逐指令一致性回归门）。
