# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉-语言-动作模型」×「续航能力」）

> R69 教会闭环去「问」：不确定性一分为二，流匹配给出有形状的歧义，注视/探针/问句主动消解。但它有两个从未被检验的默认。
>
> **默认一：理解是免费的。** R69 只把冻结 LLM 用来解码问句，真正的「看懂场景」被当成一个随时可调、不耗能的黑箱。现实里看懂场景的正是 **VLA（视觉-语言-动作模型）**——它是整条链上最耗电、最慢、也最容易被幻觉污染的一环；而且每次「问完」，你都要重新「看懂」回答。于是「问」不是一次孤立事件，它后面拖着一次昂贵的**再理解**。
>
> **默认二：预算是松的。** R69 的交互预算是一组互不相干的计数（≤1 次/单位时间、位移 ≤ ε_g、成本 ≤ c_max），仿佛信息、算力、能量是三本账。真实续航受限的具身体只有一块电池：多采 K=4 条流轨迹、跑一次 FMA 回放、让 VLA 多想 200 ms、探一次、问一句，全部从同一块正在减少的电里扣。R69 的 VoI 还是**短视（myopic）**的——只问「这一步问了值不值」，不问「把电花在思考上，还够不够走完剩下的路、还回不回得去」。
>
> 本轮两个灵感正好补上：
> - **视觉-语言-动作模型（VLA）**给出一条**可细分的计算旋钮**：不是「开/关」，而是从反射策略到完整 VLA 的计算阶梯（早退层数、token 预算、输入分辨率、扩散步数）。「多想一点」第一次成为可建模、可定价、可审计的动作。
> - **续航能力**把能量变成一等状态：不仅动作耗能，**思考也耗能**；并且存在「续航悬崖」——当剩余能量逼近安全返航储备，继续思考本身就是失能风险。
>
> 核心命题：**把「思考」写成与「移动 / 看 / 问」并列的、按焦耳计价的认知动作；用能量影子价格 μ_t 给算力定价；用「跨计算档一致性」而非 VLA 自报置信度判定「再想还有没有用」；用「计划保质期 / 语义缓存」把计算当成会过期的易腐品，按 μ_t 排程刷新。能量充裕时 VITAL 逐指令退化为 R69（μ=0、c=c_min），能量逼近储备时逐级退避到反射返航（RHA）。** 命名 **VITAL-RAS**（Vision-language-action Inference-Time Allocation for Longevity）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还能想多久，这一点确定性值不值得用回程的电来换**」——不确定性有两条预算线：信息的预算线是社交成本，思考的预算线是续航。

## 0. 直觉与动机

**灵感 1（VLA → 理解是一条计算阶梯，不是一个开关）**
直觉：今天的 VLA 常被当成「一次前向」：输入图像+指令，输出动作。但一次前向的算力其实可调——浅层早退给出粗糙但快的判断，深层 + 长推理链给出更细的接地；分辨率、token 数、扩散步数都能连续缩放。这正好对应经典「anytime 算法」：先给可用解，再花更多算力把它变好。于是「想多久」不是部署超参，而是**决策变量**：在岔路口、在人脸模糊、在接触前一刻，多花 20 ms 算力可能比问一句更便宜。R69 的动作空间里没有这个维度，所以它只能在「做/看/问」之间选，不能在「想」和「问」之间选。

**灵感 2（续航 → 思考也要吃饭，且和返航抢同一块电）**
直觉：多算 200 ms 不是免费的信息，它和「多走 3 米」「多探一次」「多说一句」从同一块电池里扣。更本质的是能量**不可逆**：信息会过时、可以作废，花掉的电回不来。所以「现在多想一会儿」的真实代价，是「未来某个时刻本可以用这份电避免一次碰撞或完成一次返航」的**期权价值**。这个期权价值就是能量约束的拉格朗日乘子 μ_t，即**电的影子价格**。μ_t 随剩余能量下降而单调上升；μ=0 恰是「电无限」的幻觉，也就是 R69。

**灵感 3（提取差 × 信息差 → 「再想」与「去问」是两种本质上不同的操作）**
直觉：很多人把「多想」和「多问」都叫「消除不确定性」，但它们在信息论上根本不同。**再想**是对已有观测 o 做更好的推断；**去问**是获取新观测 o′。数据处理器不等式（DPI）说得很清楚：任何对 o 的计算都不能增加 o 里已含的关于模态 M 的信息，`I(M; q_c(o)) ≤ I(M; o)`。所以计算只能逼近「从当前数据本可提取的极限」，永远无法越过它；要越过，只能靠交互拿到新数据。这把 R69 的 U_epi 一刀切成两半：
- **提取差**（extraction gap）：信息已经在 o 里，只是当前算力没估好——**能靠想解决**；
- **信息差**（information gap）：信息根本不在 o 里——**只能靠看/问**。

这条区分让「想 vs 问」的取舍第一次有了硬边界：提取差耗尽后，再多算力都是纯浪费；信息差为正时，再想也不会更确定。R69 把两者混成一个 U_epi，正是它「越问越贵、越贵越不敢问」的根源。

**灵感 4（计算一致性 → 不靠模型自报置信度的停机判据）**
直觉：R69 最大的教训之一是「模型会撒谎」——它自报的置信度不能信。可停机判据天然需要「我还差多少」。解法是**不向内问，而向外比**：把同一个 VLA 在两个计算档 c 与 c+Δ 各跑一次，看两次输出有多一致。若粗档和细档已经收敛到同一个动作分布，继续加算力的边际收益很小；若两者分歧大，说明这个场景「对计算敏感」，多想也许有用。这本质上是数值分析里的**残差收敛判据**搬到了策略空间：不需要真值，只需要看「加密一格，答案是否还在动」。它比自报置信度可靠，因为它要求模型在两次不同计算下相互印证，而不是一次性自评。但它也有死穴（见风险）：若两档共享同一个盲区，它们会一致地错。

**灵感 5（计划保质期 → 计算是易腐品，语义缓存有半衰期）**
直觉：「续航能力」在这里有第二层含义——不只是电池续航，也是**计划续航**：一个 VLA 计划所依赖的世界理解能保鲜多久。场景在变，缓存的动作计划会随时间变旧；越久不刷新，陈旧代价越大。于是 VLA 的输出不该被当成一次性结论，而应被当成一条**带保质期的语义缓存**。刷新太勤费电，刷新太懒危险——这正是运筹里的库存/补货问题：最优刷新间隔满足「边际陈旧代价 = 边际刷新代价」，在二次陈旧代价 + 随机漂移下给出**平方根律** `T* ∝ √(μ·e_refresh / 漂移率)`。电量低（μ 大）时，系统会「省着看」，把计划保质期拉长；但有一条安全上限，超过它陈旧就进入不安全集。

**灵感 6（对抗性歧义 → 让机器人「想到没电」）**
直觉：一旦「想」要耗电，就出现一种全新的攻击：**不直接攻击感知，而是制造一个永远想不明白的场景**，诱导系统无限延长思考、烧干电池。这可以是对抗性歧义（两个模态权重永远 50/50、粗档细档永远不收敛），也可以是提示注入让 VLA 生成超长推理链，或者干脆伪造燃料计读数让你「以为自己还有电」。R69 的威胁模型只覆盖「问错」，R70 必须覆盖「想到没电」与「想错还以为想对了」。防御不是让系统更聪明，而是给它装**硬上限 + 储备 + 反射**：单步算力封顶、连续未收敛思考步数封顶、返航能量不可挪用、燃料计取保守下界。

**灵感 7（严格包含 → 能量充裕时，VITAL 就是 R69）**
直觉：任何新层若不能退化回旧层，就多了一个要独立信任的黑箱。VITAL 的所有新机制在边界上都应恒等：μ=0（电无限）⇒ E-VoI 退化为 R69 的 VoI；c=c_min（只跑反射/蒸馏策略）⇒ 计算维度消失；计划新鲜、不触发刷新 ⇒ 缓存命中，行为不变；无交互 ⇒ 走 R69 保守。只有能量紧、或计划旧、或提取差未耗尽时，新机制才介入，且**只会更保守，不会更激进**。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（VITAL-RAS 总览与四不变式）** VITAL-RAS = (AVA, EPC, XGE, PES, ESG, RHA, EIL, ECL, VQAuditor-E, RAS-WM§)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）：VLA、μ 评论家、刷新策略均在部署期冻结，学习只发生在离线；
(ii) **能量账本闭合**：运动/感知/认知/通信四类能耗记入同一 ECL，`E_{t+1} = E_t − Σe`，`E_t` 单调不增；安全判断使用保守下界 `E_lo,t`，硬约束 `E_lo,t ≥ E_res(s_t) + m`（RHA 接管时除外，RHA 由 E_res 供能）；
(iii) **认知上限硬约束**：单步计算档 `c ≤ c_max`、单位时间认知能耗 `≤ e_max`、连续未收敛思考步数 `≤ N_think`；对抗性歧义不得无限榨取算力；
(iv) **单调退化**：`μ=0、c=c_min、计划新鲜、无交互` ⇒ 逐指令等于 R69；`E_lo ≤ E_res + m_hard` ⇒ 只执行 RHA；安全侧永不弱于 R69。

**定义 311（含认知动作的增广动作空间）** 任务动作 `a ∈ 𝒜_task`；信息动作 `g = (g_gaze, g_probe, g_ask) ∈ 𝒜_info`（继承定义 294）；认知动作 `c ∈ 𝒞 = {0,1,…,L}` 为计算档，由预算向量 `b(c) = (n_layer, n_token, res, diff_step)` 决定。增广动作 `ξ = (a, g, c) ∈ 𝒜_+^V`。`c=0` 表示非 VLA 的反射/蒸馏策略；R69 的动作空间是 `c ≡ c_min` 的截面。

**定义 312（Anytime VLA，AVA）** 计算条件策略 `π_θ(·|o,c)`，共享主干、带早退头。性能画像 `P(c) = (E[task-loss at c], e_think(c), τ(c))`。假设 **A-endur（单调精化）**：`c′ ≥ c ⇒ E[loss(c′)] ≤ E[loss(c)]`，且 `e_think, τ` 严格递增（只保证期望意义下的单调，不保证逐样本）。`c_min = 0` 不加载大模型。AVA 是**异步后台认知作业**：它把结果写入语义缓存，实时控制环只读缓存，绝不阻塞于大模型。

**定义 313（能量状态、账本与储备）** `E_{t+1} = E_t − e_move(a_t) − e_sense(o_t) − e_think(c_t) − e_comm(g_t) − e_idle`。燃料计读数 `Ê_t` 不可信，取保守下界 `E_lo,t`（库仑计数、电压、热模型三路交叉取最小）。储备 `E_res(s) = e_return(s) + e_emergency(s) + m`。能量可行域 `𝔽_t = { ξ : E_lo,t − Δe(ξ) ≥ E_res(s_{t+1}) }`。

**定义 314（能量影子价格 μ_t）** `μ_t = ∂V*(s, E_lo) / ∂E_lo`，即能量约束的对偶变量 / 剩余电量的期权价值。性质：`μ_t ≥ 0`；`E_lo ↓ ⇒ μ_t` 单调不减；`E_lo → E_res ⇒ μ_t → ∞`。在线由冻结小评论家 `μ_φ(s, E_lo)` 给出（O(1)），部署期冻结；离线用约束 MDP 的对偶上升标定。

**定义 315（能量修正信息价值 E-VoI）** 对联合认知-信息动作 `(c,g)`：
`E-VoI(c,g) = VoI(g,c) − μ_t·Δe(c,g) − c_social(g) − c_phys(g)`，
其中 `VoI(g,c)` 为在计算档 c 下的后验熵降。选择 `(c*,g*) = argmax E-VoI`，s.t. `ξ ∈ 𝔽_t`、认证通过、硬上限未越。若最大值 `≤ 0`：不思考、不交互，走 R69 兜底。`μ=0` 且去掉 c 时逐项等于 R69 定义 298。

**定义 316（epistemic 的二分：提取差 vs 信息差）** 设模态 `M`、观测 `o`。计算档 c 的估计器为 `q_c(M|o)`，其贝叶斯最优极限为 `q∞(M|o)`。定义
`U_epi^ext(c) = H(q_c(M|o)) − H(q∞(M|o)) ≥ 0`（**提取差**，可被计算消解），
`U_epi^irr(c) = H(q∞(M|o))`（**信息差**，只能被新观测消解）。
于是 `U_epi(c) = U_epi^ext(c) + U_epi^irr(c)`。由 DPI：`I(M; q_c(o)) ≤ I(M; o)`，故 `U_epi^ext ≥ 0`，计算无法越过 `H(q∞)`。U_ale 仍为模态内不可约方差（继承定义 297）。这是对 R69 定义 297 的严格细化。

**定义 317（XGE 计算一致性估计与停机律）** 在 c 与 c+Δ 两档取 `κ(c) = 1 − D_JS(q_c, q_{c+Δ})`，收敛残差 `ρ(c) = D_JS(q_c, q_{c+Δ})`。升级律：
`c ← c+Δ` 当且仅当 `ρ(c) − ρ(c+Δ) > μ_t·(e_think(c+Δ) − e_think(c))/w`（w 为每 nat 的任务效用），且未越硬上限。
若 `ρ(c) ≤ ε_conv`，判为「已收敛」，记 `Û_epi^ext(c) ≤ δ(ε_conv)`。**该判据只读跨档一致性，绝不读 VLA 自报置信度**；且必须通过物理锚点门（R69 的 FMA 流似然 / 不变量未告警）才可被采信，否则视为「共同盲区疑」。

**定义 318（计划保质期与语义缓存）** 缓存条目 `K = (π, t_π, σ_drift, validity, k, lam, mode)`；`π` 为 VLA 计划，`σ_drift` 为观测漂移率（由 FMA 似然衰减、事件率、流模态位移估计）。陈旧误差方差模型 `Var[err](Δ) = σ_drift²·Δ`。计划是**易腐品**，其剩余语义续航定义为陈旧风险低于安全阈值的时间。

**定义 319（PES 刷新排程与平方根律）** 设陈旧代价率 `c_s·err²`，刷新代价 `e_refresh`（能量，按 μ 计价）加风险。最小化每单位时间代价 `C(T) = μ e_refresh / T + (1/2)c_s σ_drift² T`，得
`T* = clamp( sqrt(2 μ_t e_refresh / (c_s σ_drift²)), T_min, min(T_max(s), T_safe) )`。
刷新条件：`age ≥ T*` 或 `σ_drift` 突增（变化检测）。低电量 ⇒ T* 增大（少想），但 `T_safe` 为硬安全上限，陈旧不得进入不安全集。

**定义 320（EIL 能量感知交互阶梯）** 候选消歧算子按**总定价成本**排序：
`cache / reuse < think(c↑) < look(g_gaze) < probe(g_probe) < ask(g_ask)`。
每个算子带代价向量 `(Δe, c_social, c_phys, τ, poison-exposure)`；统一由 E-VoI 选择。R69 是「去掉 think 且 μ=0」的阶梯特例。

**定义 321（ESG 储备治理与 RHA）** 设软/硬两条储备线 `m_soft > m_hard`。`E_lo − E_res ≤ m_soft`：冻结非关键认知与交互、μ 取高值；`≤ m_hard`：移交 **RHA**（认证反射返航策略：反应式避障 + 最短安全返回 + 零 VLA）。两线间用滞回带，避免抖振；μ 变化率限幅。

**定义 322（ECL 认知看门狗 / 抗榨取）** 硬上限：`c ≤ c_max`、窗口认知能耗 `≤ e_max`、连续未收敛步数 `≤ N_think`。越界即中止思考、置 U_epi 未消解、退 R69 保守或 RHA，并记 ECL。最坏认知能耗被 `c_max · N_think · T_horizon` 封顶。

**定义 323（威胁模型 AIC-VITAL）** `ℰ_VITAL = ℰ_FLUID × ℰ_cog × ℰ_energy`。
- `ℰ_cog`：对抗性歧义（强制不收敛的**计算耗尽攻击 / denial-of-cognition**）、超长推理链注入、跨档**共同盲区**伪造一致性、语义缓存投毒、早退头后门。
- `ℰ_energy`：燃料计欺骗/有偏、热致容量骤降、储备侧信道推断、诱导高功耗。
攻击成功定义：因能量误算或过度思考导致任务中止、储备违约或执行不安全动作。

**定义 324（证书 J_VITAL）** `J_VITAL = (J_FLUID, energy_ledger_hash, compute_ledger_hash, E_lo_final, reserve_margin, μ_trace, TTL_log, xge_residual_trace, starvation_flag, vital_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 能量账本闭合 ∧ 每步 `E_lo ≥ E_res + m` ∧ 硬上限未越 ∧ XGE 仅在锚点有效时被采信。

**定义 325（参与式审计 VQAuditor-E）** 审计：过度思考（无 VoI 增益的算力支出）、能量透支、刷新风暴、缓存投毒采纳、燃料计漂移、饥饿中止；结论回灌 μ 评论家与 TTL 先验。

**定义 326（价值-焦耳账本）** 认知效率 `η_c = −ΔU_epi^ext / Δe_think`（nat/J），交互效率 `η_i = VoI / Δe_info`。审计设下限 `η_floor`：若 `η_c < η_floor` 仍在支出算力 ⇒ 报警。「想得值不值」由此有了统一度量。

**定义 327（四区运行包络）** R-rich：`E_lo ≫ E_res + m_soft`、`μ≈0` ⇒ 等价 R69（可选升 c）；R-tight：能量中等、`μ>0` ⇒ E-VoI + 拉长 TTL；R-reserve：`E_lo ≤ E_res + m_soft` ⇒ 冻结认知，RHA 待命；R-stranded：`E_lo ≤ E_res + m_hard` ⇒ 仅 RHA、零 VLA。区间转移带滞回。

class AnytimeVLA:
    def __init__(self, trunk, exit_heads, reflex, budget_map):
        self.trunk, self.heads, self.reflex = trunk, exit_heads, reflex
        self.budget_map = budget_map          # c -> (layers, tokens, res, diff_steps)

    def infer(self, o, c):
        if c == 0:
            return self.reflex(o)             # 零 VLA，能耗最低
        b = self.budget_map[c]
        f = self.trunk(o, n_layer=b.layers, n_token=b.tokens, res=b.res)
        return self.heads[c](f), energy_table[c]

# IP-265/266/320 EPC+XGE+EIL：认知定价、提取差停机、交互阶梯
def choose_action(o, E_lo, modes, budget, mu):

    for c, g in EIL.candidates(modes, o):     # cache < think < look < probe < ask
        if not (budget.allow(c, g) and ECL.caps_ok(c, g)):      continue
        if not c_ras_wm.certify(g, o):                          continue

        voi   = info_gain(modes, q_c, g)
        score = (voi - u_ext) - mu * dE - social(g) - phys(g)   # E-VoI
        if best is None or score > best.score: best = (c, g, q_c, score)
    return best if best and best.score > 0 else None            # 退化 R69

# IP-267 PES：计划保质期（带安全上限的平方根律）
def plan_ttl(mu, e_refresh, drift, safety_cap):
    T = sqrt(2.0 * mu * e_refresh / (C_STALE * drift**2 + 1e-9))
    return clamp(T, T_MIN, min(T_MAX, safety_cap))

# IP-268/269 ESG+RHA：影子价格与储备返航（滞回、限幅，无抖振）
def shadow_price(E_lo, s):
    return clamp(MU_K / max(E_lo - reserve(s), 1e-6), 0.0, MU_MAX)

def guard_energy(M, a, c, g, o):
    dE = M.ecl.move(a) + M.ecl.sense(o) + M.ecl.think(c) + M.ecl.comm(g)
    if M.E_lo - dE <= M.esg.reserve(M.s_next) + M.esg.M_HARD:
        return M.rha.act(M.s_next), 'homing'   # 只返航，零 VLA

## 3. 推导

**引理 19（提取差下界与 DPI 停机）** 对任意由 o 计算的估计器 `q_c`，因 `M → o → q_c` 构成马尔可夫链，数据处理器不等式给出 `I(M; q_c) ≤ I(M; o)`，故 `H(q_c(M|o)) ≥ H(q∞(M|o))`，即 `U_epi^ext(c) ≥ 0`，且任何算力都无法把熵压到 `H(q∞)` 以下。在 A-endur 下，沿 c 的最优残余收敛到 `H(q∞)`；若跨档残差 `ρ(c)` 是 `U_epi^ext(c)` 的单调代理（假设 A100：无共同盲区），则 `ρ(c) → 0 ⇒ U_epi^ext(c) → 0`，算力的边际 VoI 随之趋零。停机律按构造只支付「边际提取增益 ≥ μ·边际能耗」的算力，故不会为不足以抵电费的确定性买单。系：只有交互能抬高 `I(M;o)`、压低 `U_epi^irr`；纯计算策略存在不可逾越的熵地板。

**引理 20（影子价格与交互的单调性）** 对资源约束问题，值函数 `V*(s,E_lo)` 关于 `E_lo` 单调不减且凹（可行集随电量扩大）；由包络定理 `μ = ∂V*/∂E_lo` 随 `E_lo` 下降而单调不减。于是任意 `Δe>0` 的动作的 E-VoI 关于 `μ` 单调不增，被接受的认知/交互集合随电量下降单调收缩。系：不存在「电量越低越乱花」的非单调病理；定义 321 的滞回只是把这一单调性做成可用工程。

**引理 21（计划保质期平方根律）** 在二次陈旧代价与常数漂移方差下，每单位时间总代价 `C(T) = μ e_refresh / T + (1/2)c_s σ_drift² T`；令 `dC/dT = 0` 得 `T* = sqrt(2 μ e_refresh / (c_s σ_drift²))`，且二阶导为正（极小）。故 `T* ∝ √μ`：电量越低（μ 越大），刷新越稀疏；`T_safe` 与 μ 无关，是安全侧硬上限。系：把「省电」从「少看」翻译成「拉长计划保质期」，可用实测刷新间隔对 √μ 的斜率检验（E306）。

**定理 18（VITAL 严格包含 R69）** 在 A-endur、A99（信息与能量可折算到同一效用）、A100（跨档一致性无共同盲区）、A102（RHA 在 `E_lo ≥ E_res` 下必达安全终态）下：当 `μ=0、c=c_min、plan.age<T*、无交互触发、E_lo > E_res+m_soft` 时，E-VoI 逐项退化为 R69 的 `VoI−c`，候选集与决策规则相同 ⇒ 与 R69 逐指令一致。对一般电量，VITAL 只在 `𝔽_t ⊆` R69 可行集内行动，且不在证据纪律之外授予 resolution bonus，故期望风险 ≤ R69；当 `E_lo ≤ E_res+m_hard` 时 RHA 保证不搁浅。因此 R69 是 VITAL 在「电无限、思考免费、计划永鲜」边界上的退化，安全侧零让步。

**定理 19（能量安全与无抖振切换）** 设 `E_lo,0 ≥ E_res(s_0)+m`，且 RHA 满足 A102。归纳：若名义步，guard 要求 `E_lo − Δe ≥ E_res(s_{next})+m_hard` 才执行，故不变式保持；否则移交 RHA，由 A102 用不超过 `E_res` 的能量到达安全终态。软/硬两线间的滞回带与 μ 变化率限幅排除在边界上的频繁切换，控制连续。系：只要燃料计下界 `E_lo` 不高于真实电量，系统不会因思考而跌破返航储备。

**引理 22（计算耗尽攻击上界）** 在定义 322 的硬上限下，任一决策 epoch 的认知能耗 ≤ `c_max·N_think`，全时程 ≤ `c_max·N_think·T_horizon`；储备由定理 19 保护。故对抗性歧义最多把任务「想到超时/中止」，不能造成储备违约或物理不安全动作。系：计算耗尽是一种**可用性**攻击，不是**安全性**攻击（前提 A102 成立）。

**定理 20（共同盲区下的诚实边界）** 若 `π_c` 与 `π_{c+Δ}` 共享盲区 B（同一错误内部表征导致同错），则对 `o∈B` 有 `q_c=q_{c+Δ}`、`ρ(c)=0`，XGE 会判「已收敛」，而真实 `U_epi^ext(c)` 可以很大。故 XGE 的「收敛」只有在存在**与 VLA 盲区独立的物理锚点**时才可信（R69 的 FMA 流似然、刚体/运动学不变量、事件变更）。若锚点同处盲区，则任何只用模型自身的判据都无法证伪；VITAL 必须退化为 R69 纯保守。这条定理把「计算一致性」的适用范围画死，也是本轮最大风险的来源。

## 6. 本轮最大风险

**一句话**：VITAL 的全部安全论证押在两个前提上——**燃料计（E_lo）可信**、**跨计算档一致性不会被共同盲区同时骗过**。若电量估计本身被缓变故障污染（R68 最脆弱的洞恰好可以钻进燃料计），μ_t 就算错；若 VLA 在所有计算档共享同一个幻觉，ρ 就会假收敛、XGE 就会盖章。于是系统要么「以为自己还有电」而烧掉回程，要么「以为自己想明白了」而带着高能量代价执行错误动作——**把 R69 的「问错」升级为「想到没电 / 想错还以为想对了」**。

1. **效用不可公度**（A99：信息与焦耳如何折算）→ 保守 μ、显式敏感度分析、安全优先的字典序；

3. **TTL 安全上限学不好** → 用几何/运动学硬包络给出 `T_safe`，不交给学习；
4. **共同盲区** → 独立物理锚点（FMA/不变量/事件）+ 硬上限 + 直接退化 R69；
5. **燃料计漂移** → 库仑/电压/热三路交叉取最小 + 漂移审计 + 储备留余量。

**定义 310（总览与四不变式）** VITAL-RAS = (AVA, EPC, XGE, PES, ESG, RHA, EIL, ECL, VQAuditor-E, RAS-WM§)。四不变式：零学习写操作；能量账本闭合 + 保守下界 `E_lo≥E_res+m`；认知硬上限（`c_max/e_max/N_think`）；单调退化（μ=0、c=c_min、计划新鲜 ⇒ 逐指令 = R69；`E_lo≤E_res+m_hard` ⇒ 仅 RHA）。

**定义 311–312（认知动作与 anytime VLA）** `ξ=(a,g,c)`；`c` 由预算向量决定；`π_θ(·|o,c)` 共享主干、带早退头，A-endur 单调精化；AVA 异步运行，控制环只读语义缓存，绝不阻塞。

**定义 313–314（能量账本与影子价格）** `E_{t+1}=E_t−Σe`；`E_lo` 取库仑/电压/热模型三路最小；`E_res=e_return+e_emergency+m`；`μ_t=∂V*/∂E_lo≥0` 随电量下降单调上升，在线由冻结评论家给出。

**定义 315（E-VoI）** `E-VoI=VoI−μΔe−c_social−c_phys`；`argmax` 受能量可行域、认证、硬上限约束；`≤0` 则不思考不交互、退 R69；`μ=0` 即 R69。

**定义 316（提取差 vs 信息差）** `U_epi^ext=H(q_c)−H(q∞)≥0`（计算可解）；`U_epi^irr=H(q∞)`（只能靠新观测）；DPI 保证计算不能越过 `H(q∞)`。这是对 R69 定义 297 的严格细化。

**定义 317（XGE 停机律）** `ρ(c)=D_JS(q_c,q_{c+Δ})`；当且仅当 `ρ(c)−ρ(c+Δ) > μΔe/w` 才升档；`ρ≤ε_conv` 判收敛，但须过物理锚点门（FMA/不变量未告警），否则记「共同盲区疑」。

**定义 318–319（计划保质期与平方根律）** 缓存 `(π,t_π,σ_drift,k,lam,mode)`；陈旧方差 `σ_drift²Δ`；最优 TTL `T*=clamp(sqrt(2μ e_refresh/(c_sσ_drift²)),T_min,min(T_max,T_safe))`；低电量拉长 TTL，但不得越过安全上限。

**定义 320–321（交互阶梯与储备治理）** 排序 `cache<think<look<probe<ask`，统一 E-VoI；`E_lo−E_res≤m_soft` 冻结非关键认知，`≤m_hard` 移交 RHA（零 VLA）；两线滞回、μ 限幅。

**定义 322–323（看门狗与威胁模型）** 认知硬上限 `c_max/e_max/N_think`；`ℰ_VITAL=ℰ_FLUID×ℰ_cog×ℰ_energy`：计算耗尽、共同盲区、缓存投毒、超长推理注入、燃料计欺骗、热致容量骤降。

**定义 324–327（证书/审计/价值-焦耳/四区）** `J_VITAL` 覆盖能量与计算账本、储备裕度、μ 轨迹、TTL、XGE 残差、饥饿标志；VQAuditor-E 审过度思考与透支；`η_c` 度量 nat/J；四区 R-rich/R-tight/R-reserve/R-stranded 带滞回切换。

## 3. 关键算法伪代码

```python
# IP-264 AVA：anytime VLA（共享主干 + 早退头；c=0 反射，不加载大模型；异步）
class AnytimeVLA:
    def infer(self, o, c):
        if c == 0: return self.reflex(o), 0.0
        b = self.budget_map[c]
        f = self.trunk(o, n_layer=b.layers, n_token=b.tokens, res=b.res)
        return self.heads[c](f), self.energy_table[c]

# IP-265/266/320 EPC+XGE+EIL：认知定价 + 提取差停机 + 交互阶梯
def choose_action(o, E_lo, modes, budget, mu):
    best = None
    for c, g in EIL.candidates(modes, o):        # cache<think<look<probe<ask
        if not (budget.allow(c, g) and ECL.caps_ok(c, g)): continue
        if not c_ras_wm.certify(g, o): continue
        if E_lo - energy(c, g) < ESG.reserve(s) + MARGIN: continue
        q_c  = AVA.infer(o, c)
        rho  = XGE.residual(q_c, AVA.infer(o, c + DELTA))
        u_ext = 0.0 if rho <= EPS_CONV else XGE.proxy_gap(rho)
        score = (info_gain(modes, q_c, g) - u_ext) \
                - mu * energy(c, g) - social(g) - phys(g)          # E-VoI
        if best is None or score > best.score: best = (c, g, q_c, score)
    return best if best and best.score > 0 else None              # 退化 R69

# IP-267 PES：计划保质期（带安全上限的平方根律）
def plan_ttl(mu, e_refresh, drift, safety_cap):
    T = sqrt(2.0 * mu * e_refresh / (C_STALE * drift**2 + 1e-9))
    return clamp(T, T_MIN, min(T_MAX, safety_cap))

# IP-268/269 ESG+RHA：影子价格与储备返航（滞回、限幅，无抖振）
def shadow_price(E_lo, s):
    return clamp(MU_K / max(E_lo - reserve(s), 1e-6), 0.0, MU_MAX)

def guard_energy(M, a, c, g, o):
    dE = M.ecl.move(a) + M.ecl.sense(o) + M.ecl.think(c) + M.ecl.comm(g)
    if M.E_lo - dE <= M.esg.reserve(M.s_next) + M.esg.M_HARD:
        return M.rha.act(M.s_next), 'homing'       # 只返航，零 VLA
    return None, 'nominal'

# IP-275 主闭环（继承 R69；仅在不触发新机制时逐指令等于 R69）
def VITAL_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    M.E_lo = M.ecl.robust_estimate()                # 库仑/电压/热三路取最小
    mu = M.esg.shadow_price(M.E_lo, M.s)
    choice = choose_action(o, M.E_lo, M.modes, M.budget, mu)
    if choice is None:                              # 退化路径 = R69
        u_ale, u_epi, modes, _ = M.aud.decompose(
            M.fmp.sample(o, K=1), z, M.fmp.mode_head)
        lam = max(M.efs.risk_scale(...), lam_floor(u_ale + u_epi))
        k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
        return k, lam, select_mode(modes, u_epi, lam), (u_ale, u_epi)
    c, g, q_c, score = choice
    plan = M.pes.get(o)                             # 语义缓存（异步作业写入）
    if plan is None or plan.age >= plan_ttl(mu, M.e_refresh, plan.drift, M.T_SAFE):
        plan = M.pes.refresh_async(o, q_c)          # 启动后台思考，不阻塞控制环
    M.ecl.record(M.E_lo, c, g, plan)
    guard, mode = guard_energy(M, plan.a0, c, g, o)
    if guard is not None: return M.rha.prefix(guard), 'homing'
    M.vqa_e.submit_async(c, g, score, mu, plan.ttl)
    return plan.k, plan.lam, plan.mode, (plan.u_ale, plan.u_epi)
```

## 4. 推导

**引理 19（提取差下界与 DPI 停机）** `M→o→q_c` 为马尔可夫链，故 `I(M;q_c)≤I(M;o)`、`H(q_c)≥H(q∞)`、`U_epi^ext≥0`；任何算力都无法越过 `H(q∞)`。A-endur 下最优残余收敛；若跨档残差 ρ 是 `U_epi^ext` 的单调代理（A100：无共同盲区），则 `ρ→0 ⇒ U_epi^ext→0`，边际算力 VoI 趋零。停机律只支付「边际提取增益 ≥ μ·边际能耗」的算力。系：只有交互能压低 `U_epi^irr`。

**引理 20（影子价格单调性）** `V*(s,E_lo)` 关于 `E_lo` 单调不减且凹，由包络定理 `μ=∂V*/∂E_lo` 随电量下降单调不减；故任意 `Δe>0` 动作的 E-VoI 关于 μ 单调不增，被接受的认知/交互集合随电量下降单调收缩——不存在「越低电越乱花」的病理。

**引理 21（计划保质期平方根律）** `C(T)=μ e_refresh/T+(1/2)c_sσ_drift²T`，令导数为零得 `T*=sqrt(2μ e_refresh/(c_sσ_drift²))`，二阶导正。故 `T*∝√μ`：低电量刷新更稀疏；`T_safe` 与 μ 无关，是安全硬上限。

**定理 18（VITAL 严格包含 R69）** 在 A-endur、A99（信息/能量可折算同一效用）、A100、A102（RHA 必达安全终态）下：`μ=0、c=c_min、计划新鲜、无交互` 时 E-VoI 逐项退化为 R69 的 `VoI−c`，候选集与规则相同 ⇒ 逐指令一致。一般电量下只在 R69 可行集内行动、不在证据纪律外授予 resolution bonus，故期望风险 ≤ R69；`E_lo≤E_res+m_hard` 时 RHA 保证不搁浅。R69 是「电无限、思考免费、计划永鲜」边界。

**定理 19（能量安全与无抖振切换）** 归纳可证：名义步要求 `E_lo−Δe≥E_res(s_next)+m_hard` 才执行；否则移交 RHA，由 A102 用不超过 `E_res` 的能量到达安全终态。两线滞回 + μ 限幅排除边界抖动，控制连续。系：只要 `E_lo` 不高于真实电量，就不会因思考跌破返航储备。

**引理 22（计算耗尽攻击上界）** 硬上限使单 epoch 认知能耗 ≤ `c_max·N_think`，全时程 ≤ `c_max·N_think·T_horizon`；储备由定理 19 保护。故对抗性歧义最多导致任务超时/中止，不能造成储备违约或物理不安全动作——计算耗尽首先是**可用性**攻击。

**定理 20（共同盲区下的诚实边界）** 若 `π_c` 与 `π_{c+Δ}` 共享盲区 B，则 `o∈B` 时 `q_c=q_{c+Δ}`、`ρ=0`，XGE 假收敛而真实 `U_epi^ext` 可很大。故 XGE 的「收敛」只有在**与 VLA 盲区独立的物理锚点**（FMA 流似然、刚体/运动学不变量、事件变更）有效时才可信；锚点同处盲区时任何只用模型自身的判据都无法证伪，VITAL 必须退化 R69 纯保守。

## 7. 本轮最大风险

**一句话**：VITAL 的全部安全论证押在两个前提上——**燃料计（E_lo）可信**、**跨计算档一致性不会被共同盲区同时骗过**。若电量估计被缓变故障污染（R68 最脆弱的洞恰好可以钻进燃料计），μ_t 就算错；若 VLA 在所有计算档共享同一个幻觉，ρ 就会假收敛、XGE 就会盖章。系统要么「以为自己还有电」而烧掉回程，要么「以为自己想明白了」而带着高能量代价执行错误动作——**把 R69 的「问错」升级为「想到没电 / 想错还以为想对了」**。

**次级风险与缓解**：效用不可公度（保守 μ + 敏感度分析 + 安全字典序）；anytime VLA 非单调（离线性能画像 + 上包络 + 退回 c_min）；TTL 安全上限学不好（几何/运动学硬包络）；共同盲区（独立物理锚点 + 硬上限 + 退化 R69）；燃料计漂移（三路交叉取最小 + 漂移审计 + 储备余量）。
