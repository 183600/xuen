# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 4 轮；本轮灵感：「数据采集」×「分布外泛化」）

> R73 把「系统可信吗」重构为「证据计量能否成为可组合契约」，并把证明负担压到**契约表达力**上。但 R73 的证书里有一个从未被写进类型的自变量：
> - **分布前提被隐藏**：所有 cert（深度六分量校准、材质后验、conformal 一致性审计、χ_v 的 Lipschitz 常数）都是在某个校准分布 P_cal 上得到的。J_MOD 实际上证明的是「P_deploy 与 P_cal 可交换 / 同支撑」。部署分布一漂移，证书哈希不变、结论失效——这是 R73 最大风险的正式形态：**分布外泛化不是风险清单里的一条，而是契约缺失的一个字段。**
> - **数据采集是未计量的动作**：SEAL 集、材质训练集、conformal 校准集、自标定基准——每一张证书的上游都是一次「摆标定板 / 换材质 / 走一圈 / 换光照」的采集动作。但采集没有契约、没有预算、没有谱系、没有进入反作用层。R73 把动作效应分为 ψ/z/c/v 四层，唯独漏掉**为了获得证据而做的动作**（L5 认知反作用）。
> - **OOD 检测悖论**：检测器本身要用 ID 数据校准，却在 OOD 下失效；更糟的是，任何有限灵敏度的**全局**检测器都能被足够慢、足够局部的漂移规避——大漂移可测、慢漂移不可测、局部稀疏漂移（罕见但安全关键的分层）尤其不可测，而这三者恰好是真实部署（传感器老化、季节光照、地板磨损、罕见材质）的常态。
>
> 本轮灵感补两块，并逼出第三块：
> - **数据采集 → AMS（Acquisition Metrology System）**：采集是一等证据动作。采集契约 AC =（观测类型，五分量采集不确定度，认知反作用通道 χ_E，采集有效域，谱系链，预算，fit/audit 分离）；五分量 u_acq =（u_sampling 覆盖不足，u_label 基准真值误差，u_provenance 来源混叠/泄漏，u_manip 投毒/选择性采集，u_staleness 老化）。与 DPEM 六分量、DMEM 四分量严格同构——**证据计量递归到数据层**。
> - **分布外泛化 → DEC（Distributional Evidence Contract）**：EC† =（EC，分布域 𝒫_cert，覆盖下界 1−α_cov，漂移检验组，降级策略）。证书从「一个风险数」升级为「一个函数 P ↦ 风险上界」。组合时分布域取交（与有效域 D 取交完全同构）；**组合只能收窄分布域，只有采集能扩张它**——数据是分布域的唯一货币。
> - **交叉 → CDA（Coverage-Driven Acquisition）+ e-GAUGE + PBA**：主动采集是扩张 𝒫_cert 的唯一手段，但按覆盖目标挑数据会对证书做 Goodhart（coverage hacking）。解法是 fit/audit 谱系分离（PBA）+ anytime-valid e-process（e-GAUGE）+ 采集策略不得触碰审计集。这是「采集的采集」——元层审计。
>
> 核心命题：**证书不是关于模型的，而是关于「模型 × 采集过程 × 部署分布」三元组的。不问「模型能否 OOD 泛化」，而问「这张证书的分布域有多大、漂移多快后失效、失效前能否安全降级」。** 把 R73 的 MODGAUGE-RAS 扩展为 **SHIFTGAUGE-RAS**（SHift-aware, acquisition-grounded evidence metrology with GAUGE audits）——**分布域计量**。

## 0. 直觉与动机

**灵感 1（数据采集 → 数据不是天上掉的，采集本身有不确定度）**
直觉：每一条校准样本都是某次动作的产物：把标定板摆到第 7 个位姿、把镜面/透明/黑体样品依次放上转台、在三种光照下走一圈、把相机预热 40 分钟。采集动作有成本、有偏置、可被攻击（数据投毒）、可被滥用（为了证书好看而挑数据）。既然接触证据有四分量、深度证据有六分量，**采集证据没有理由没有分解**。更关键：采集不是被动记录，而是**动作**——机器人可以选择「去哪里采、采多少、采什么材质」，这会改变证据质量本身，和 R73 的 χ_v 视角反作用是同一类结构。故采集需要一个认知反作用通道 χ_E（L5）：采集动作 → 覆盖/不确定度变化 → 证书强度变化 → 采集动作。

**灵感 2（分布外泛化 → 泛化不是一个能力，是证书的适用范围）**
直觉：conformal 覆盖率 1−α 只在可交换性下成立；协变量偏移下边际覆盖率可以任意崩，**最坏分层覆盖率**崩得更快（罕见但致命的透明杯、反光金属、暗色地毯）。所以正确的问法不是「模型能否 OOD 泛化」，而是「这张证书的分布域有多大、在域外多远仍保守、漂移多快后会失效」。把分布域 𝒫_cert 写成契约字段，组合时取交（与 R73 的 D 取交完全同构），就得到：**安全证书不是一个数，而是一个函数 P ↦ 风险上界**。R73 的定理 28 变成「P ∈ 𝒫_cert ⇒ 风险 ≤ ε_mod(P)」，R73 的最大风险从一个 open problem 变成一个可审计的契约字段是否为空的问题。

**灵感 3（交叉 → 主动采集的两难：扩张域 vs 污染证）**
直觉：主动采集能扩张 𝒫_cert，但只要你按「最大化覆盖证书」挑数据，证书就会过拟合你的挑法（coverage hacking，与 p-hacking 同型）。而且如果 fit 集和 audit 集来自同一采集过程，覆盖率估计是自证循环。解法不是「不要主动采集」，而是**把采集的采集做出来**：fit/audit 在谱系层分离（不同动作、不同时间、不同操作者），audit 集封存或只经 e-process 消费（anytime-valid，允许边采边测而不违反 I 类错误）。这样主动采集的收益可以被合法兑现，而审计不可被采集策略污染。

**灵感 4（慢漂移 → 检测不是保证，维护才是）**
直觉：任何有限灵敏度的检测器都有盲区；漂移速度 v → 0 时，检测时延 τ ~ δ_min/v → ∞，但检测时刻的累计漂移恒等于 δ_min——也就是说**检测决定的是「何时停」，不是「漂移了多少」**。真正安全的东西不是更灵敏的检测器，而是**与检测无关的强制再采集（TTL / 漂移预算）**：无论检测器说什么，证书到期即降级或重采。这把「OOD 检测」从一道防线降级为一道**加速器**，把「证书老化」升级为一条契约义务。

**灵感 5（分布域组合 → 与 R73 域交的同构，以及「数据是唯一货币」）**
直觉：R73 已经证明组合下不确定度只能增、有效域只能收（引理 34）。分布域是同一件事在高一层：A on 𝒫_A，B on 𝒫_B ⇒ 组合只在 𝒫_A ∩ 𝒫_B 上有证书。串联/并联/否决都不扩张分布域。**任何「组合后泛化更好」的主张都是违法的**——除非引入了新数据。这条「无免费泛化」引理，正好把 R73 的「组合不产生认知免费午餐」提升到分布层，也顺手解释了为什么迁移学习/领域自适应的收益必须记在「采集」账上，而不能记在「组合」账上。

**灵感 6（为什么必须是 e-process，而不是再加一个 conformal 校准）**
直觉：R73 用固定 conformal 集做一致性审计，那是「一次性、固定样本量」的推断。但本轮的系统是**在线、自适应采集**的：采哪些数据取决于已看到的漂移，看多少取决于预算，随时可能停。固定 conformal 在可选停时（optional stopping）下覆盖率失效。e-value / e-process 天生 anytime-valid（Ville 不等式），可以在「边采边测边停」下保持 I 类错误。这不是工程选择，是**主动采集在统计上唯一合法的证书形态**。

## 1. 形式化定义（增量：定义 383–399）

**定义 383（SHIFTGAUGE-RAS 总览）** SHIFTGAUGE-RAS = (MODGAUGE-RAS†, AMS, DEC, SENTINEL, CDA, e-GAUGE, PBA, S-DEG)。在 R73 五不变式上增加第六条：
(vi) **分布域完备性**：每个证据模块的证书必须携带分布域 𝒫_cert 与覆盖下界 1−α_cov；部署时由 SENTINEL 判定当前分布是否在域内；判定不确定或检测器自身失效 ⇒ **fail-closed**（按域外处理）。无 𝒫_cert 的 cert 不可入图，等价于 R73「无契约不入图」在数据层的推广。

**定义 384（采集契约 AC）** AC = (T_obs, 𝒰_acq, χ_E, D_acq, prov, B_acq, split, seal_ref)：
- T_obs：采集产出的观测/基准类型；
- 𝒰_acq：五分量采集不确定度（定义 385）；
- χ_E: 𝒢_acq × X → Θ_cert × D_acq′：**认知反作用通道**——采集动作如何调制证书强度（覆盖下界、有效域、u_acq）与采集有效域；平凡恒等 χ_E ≡ id 表示「采集与证书无关」（极少成立，仅用于 stub/静态数据集）；
- D_acq：采集有效域（操作者资质、环境条件、标定物可用性、时间窗）；
- prov：谱系节点（采集动作、设备、时间、操作者、原始数据哈希）；
- B_acq：采集预算（时间/能耗/人工/风险暴露）；
- split: {FIT, AUDIT, HELD}：该数据在证书中的角色，**角色由谱系预注册，不得事后更改**；
- seal_ref：SEAL-ACQ / SEAL-SHIFT 审计集引用。

**定义 385（采集五分量不确定度 AMS）**
u_acq² = u_sampling² + u_label² + u_provenance² + u_manip² + u_staleness²。
- u_sampling：覆盖/抽样不足（分布域的体积、分层样本数、协变量支撑）；
- u_label：基准真值误差（标定板加工公差、人手标注、外部基准本身的误差）；
- u_provenance：来源混叠与泄漏（fit 与 audit 是否同源、是否重复样本、是否跨轮复用）；
- u_manip：投毒/选择性采集（采集策略对数据分布的有意或无意塑形，Goodhart 的可观测代理）；
- u_staleness：老化（采集时刻到部署时刻的环境/硬件漂移，由定义 393 的漂移预算给出）。
五分量各有独立谱系链 τ_acq,i，合并为 τ_acq。

**定义 386（采集动作与 AMS 算子）** 采集动作 a_acq = (probe, target, expected_gain, cost) ∈ 𝒢_acq：probe 是物理/虚拟探针（移动相机、换样品、请求人类示范、合成扰动），target 是待扩张的分布域子集或待压低的不确定度分量，expected_gain 是该动作对覆盖下界的期望增量，cost 是 B_acq 消耗。AMS 输出 AcquisitionEvidence = (u_acq 五分量, χ_E, τ_acq, split, valid)。**采集动作与任务动作共用动作空间的一部分**（走近 = 采集 + 视角改变），故 χ_E 与 R73 的 χ_v 在同一预算下合算（定义 390）。

**定义 387（分布证据契约 DEC = EC†）** EC† = (EC, 𝒫_cert, α_cov, 𝒯_shift, degrade_policy)：
- 𝒫_cert：**认证分布族**——一个由校准过程显式给出的分布集合（如「相对 P_cal 的 f-散度 ≤ ρ」「似然比 ≤ W」「分层支撑覆盖 ≥ 1−β」的并/交）；
- α_cov：覆盖下界 1−α_cov（分层意义下，定义 396）；
- 𝒯_shift：SENTINEL 检验组（定义 389），每个检验自带 e-process 与阈值；
- degrade_policy：域外时的降级等级映射（定义 394）。
证书语义：**Cert_i(P) 给出对任意 P ∈ 𝒫_cert^i 成立的风险上界；P ∉ 𝒫_cert^i 时证书不提供保证，必须降级。**

**定义 388（条件证书与分布域有效性）** 记 ε_mod(P) 为 R73 定理 28 的风险界在分布 P 下的取值。定义
Valid(J_MOD | P) ⇔ (∀i: P ∈ 𝒫_cert^i) ∧ (∀T ∈ ∪𝒯_shift: T 未越阈) ∧ MReg 组合校验通过。
Valid(J_MOD | P) ⇒ 物理执行风险 ≤ ε_mod(P)。**这是 R73 定理 28 的分布参数化版本；R73 是其 P = P_cal 的特例。**

**定义 389（SENTINEL 漂移哨兵）** SENTINEL = ({T_j}, 状态机 {ID, WARN, OOD}, fail-closed 策略)：
- 每个 T_j 是一个**分层**双样本/序贯检验（全局 + 安全关键分层 + 罕见事件分层），输出 e-process E_j(t)；
- 状态机：任一 E_j ≥ 1/α_j ⇒ WARN（禁用 PAR 缩窄）；任一 E_j ≥ 1/α_j′（α_j′ < α_j）或 WARN 持续超过 τ_w ⇒ OOD（按定义 394 降级）；
- **检测器自身的证书**：SENTINEL 的有效性在 SEAL-SHIFT（已知漂移族）上校准；若检测器自身的 u_acq 超预算或其校准域外 ⇒ 视为 OOD（fail-closed，打破「检测器在 OOD 下失效」的悖论）；
- **局部/稀疏检测**：除全局均值/MMD 外，必须含「最坏分层」检验；否则稀有但致命的漂移不可见（引理 41）。

**定义 390（e-GAUGE：anytime-valid 证书）** 用 e-process 替代固定样本 conformal：对零假设 H_0（「当前分布 ∈ 𝒫_cert 且证书覆盖成立」），构造非负上鞅 (E_t)，E_0 = 1，满足 E[E_t | ℱ_{t−1}] ≤ E_{t−1}。由 Ville 不等式，对任意**可选停时** τ（包括由自适应采集决定的停时）有 P(E_τ ≥ 1/α) ≤ α。故「边采集边检验边停止」下 I 类错误仍受控。固定 conformal 集 C_α 被 e-GAUGE 集 E_α 替代；PAR 缩窄的合法性从「conformal 覆盖」升级为「e-GAUGE 未拒」。**这是主动采集在统计上合法的前提，不是可选项。**

**定义 391（覆盖驱动采集 CDA）** 采集策略 π_acq: 历史 → a_acq。目标：
a_acq* = argmax_{a ∈ 𝒢_acq} [ ΔCoverage_lb(a) − λ_acq·cost(a) − Σ_i c_reflex^i(a) ]，
s.t. B_acq 未超；a 不得选择或触碰 AUDIT/HELD 集（谱系约束）；D_acq 满足；REG 时序契约。
其中 ΔCoverage_lb(a) = 覆盖下界在 𝒫_cert 上的期望增量（由 χ_E 解析/半解析给出，类比 PVOP 的解析 χ_v）。**与 PVOP 联合**：走近兼作采集动作时，一次动作同时贡献任务进展、视角证据、域覆盖。

**定义 392（谱系绑定审计 PBA）** 谱系图 G_prov = (V_data, E_prov)：节点 = 原始样本（哈希），边 = 派生/清洗/合并。PBA 校验：
(i) **fit/audit 分离**：任何用作 AUDIT 的样本，其谱系上游不得与 FIT 集共享采集动作或重复样本（哈希判重 + 近重复检测）；
(ii) **角色预注册**：split 在采集时写入，事后不可改；
(iii) **审计集封存**：AUDIT 只被 e-GAUGE 以预注册方式消费，采集策略不可见（避免选择性审计）；
(iv) **元证书** MetaCert = （AC, G_prov, e-process 轨迹）——**证书之证书**，进入 J_MOD 的乘法项。
PBA 失败 ⇒ 该 cert 无效（不是降级，是撤销）。

**定义 393（证书老化与再采集调度 TTL）** 每个 cert 携带 TTL = τ_cert 与漂移预算 δ_D：在 τ_cert 内，若累计环境漂移 ≤ δ_D，则证书仍视为有效（保守）；超过 τ_cert **无论 SENTINEL 是否报警**，强制进入「重采集或降级」二选一。调度：
τ_cert* = argmax_τ [ 有效工作时长 − 重采成本·(1/τ) ]，s.t. L_shift·δ_D(τ) ≤ ε_budget。
**TTL 是与检测无关的兜底**（引理 41 的直接推论）：检测器可以坏，时钟不会。

**定义 394（漂移感知降级 S-DEG）** 四级单调降级：
- **L0（ID）**：正常；PAR 允许缩窄（需 e-GAUGE 未拒）；
- **L1（WARN）**：禁用 PAR 缩窄与 χ_v 解析式近场外推，保留观测（保守取 max），记录反事实日志；
- **L2（OOD-局部）**：受影响**分层/模态**置 stub（R73 定义 381），其余模态保留；分布域收缩到未受影响分层；
- **L3（OOD-全局 / 检测器失效 / TTL 到期且无法重采）**：整机退 R68（唯一系统级降级，继承 R72）。
降级单调：Lk 的保守性 ≥ L(k−1)，且**禁止升级跳过**（L3→L0 必须经过重采集并重新校准，不能靠检测器「恢复正常」直接跳回）。

**定义 395（分布域组合与单调性）** 对组合算子 ⊛ ∈ {SER, PAR, VETO}：
- 𝒫_comp = 𝒫_A ∩ 𝒫_B（**只能收窄**）；
- 覆盖下界取 min（分层取逐层 min）；
- PAR 缩窄的合法性要求联合 e-GAUGE 在**交集**上未拒；交集为空 ⇒ 组合非法（类比 R73 有效域交集为空）；
- χ_E,comp = χ_E,B ∘ χ_E,A（采集通道串联）；
- PBA 合并：G_prov,comp = G_prov,A ⊎ G_prov,B，并要求 fit/audit 分离在合并后仍成立。
**分布域组合引理（引理 39）**：任何 ⊛ 路径的 𝒫_comp ⊆ min_i 𝒫_i；无新采集 ⇒ 组合不扩张认证分布族。

**定义 396（分层覆盖与最坏层保证）** 设分层划分 𝒮 = {S_1,…,S_m}（由安全分析预注册，不得事后按数据选层）。marginal coverage = Σ_s π_s·cov_s。DEC 要求**逐层** cov_s ≥ 1−α_cov（Bonferroni 或 e-process 联合控制），而非仅边际。原因：边际 1−α 可以在一个安全关键层 cov=0 的情况下仍成立（只要该层占比小）。**R73 的 conformal 审计只保证边际，这是它在 OOD 下最隐蔽的失效点。**

**定义 397（漂移风险界与检测滞后）** 若 P_deploy ∈ 𝒫_cert，风险 ≤ ε_mod。若 P ∉ 𝒫_cert 且 SENTINEL 在滞后 τ 内检出，则风险 ≤ ε_mod + L_shift·ρ_drift·τ + ε_detect，其中 L_shift 是风险对分布位移的 Lipschitz 常数，ρ_drift 是漂移速率，ε_detect 是检测漏报项。**若漏报（未检出），则由定义 393 的 TTL 与定义 396 的分层检验兜底：风险保证降级为「在 τ_cert 内成立或强制 L3」。** 三者合起来才是完整保证（定理 31）。

**定义 398（证书过拟合 / 覆盖黑客 C-overfit）** 对手/自利采集策略选择数据以最大化报告的覆盖下界。定义 C-overfit gap = 报告覆盖 − 真实审计覆盖。若采集策略可见并可选择 AUDIT 集，gap 无上界（可把审计集挑成全是易样本）；PBA 分离 + 封存 + e-GAUGE 后，gap 以 1−α 概率 ≤ 0（定理 32）。这是 C4 的可证伪核心。

**定义 399（主张 C4 与 CPB v2）** 新增第四条可证伪主张：
- **C4（采集感知的分布外认证）**：把分布域与采集谱系写成契约字段、用 e-GAUGE 做 anytime-valid 审计、用 CDA 扩张域，比「被动校准 + 事后 OOD 检测」在**漂移下覆盖保持率、最坏分层覆盖、安全降级率、风险界违例率**上显著更优。
绑定表 v2：
- C1 ← (DPEM, DMEM†) ← MB1 ← AB1 ← (ECE, coverage, collision_rate, grasp_err)；
- C2 ← (ΣREFLEX, ERVOI†, PVOP) ← MB2 ← AB2 ← (n_interactions, human_cost, stop_var)；
- C3 ← (MMS, CCA, J_MOD) ← MB3 ← AB3 ← (instr_equiv, cert_cost_ratio, transfer_loc)；
- **C4 ← (AMS, DEC, SENTINEL, CDA, e-GAUGE, PBA) ← MB4（漂移）× MB5（采集）← AB4（DEC+CDA vs 被动 vs 仅检测器）← (coverage_retention, worst_stratum_cov, safe_degrade_rate, risk_bound_violation, c_overfit_gap)**。
**CertCost v2** = 采集成本 + fit 成本 + audit 成本（e-GAUGE 消费）+ 组合校验。C4 的收益必须扣除采集成本后再比较（否则「多采数据当然更好」是废话）。

```python
# IP-303 AMS：采集契约与五分量采集计量
@dataclass(frozen=True)
class AcquisitionContract:
    t_obs: type
    u_fields: Tuple[str, ...]                 # ("sampling","label","provenance","manip","staleness")
    chi_E: Callable[[AcqAction], CertMod]     # 认知反作用通道（L5）
    domain: Predicate                         # 采集有效域 D_acq
    prov: ProvenanceNode                      # 谱系
    budget: AcqBudget                         # B_acq
    split: str                                # {"FIT","AUDIT","HELD"} 预注册，不可改

class AcquisitionMetrology:                   # 感知/离线域
    def update(self, acq_action, raw, env, prev):
        u_s   = self.coverage.deficit(acq_action.target, raw)       # 覆盖不足
        u_l   = self.groundtruth.label_unc(raw, acq_action.probe)   # 基准真值
        u_p   = self.prov.leakage(prev, raw, self.fit_set)          # 同源/重复/泄漏
        u_m   = self.manip.detect(acq_action, raw)                  # 选择性/投毒
        u_st   = self.age.track(acq_action.time, env)               # 老化（接定义 393）
        valid = self.domain_ok(acq_action, env) and u_p < TAU_PROV
        return AcqEvidence(u=sqrt(u_s**2+u_l**2+u_p**2+u_m**2+u_st**2),
                           breakdown=(u_s,u_l,u_p,u_m,u_st),
                           chi_E=chi_epistemic(acq_action),
                           prov=self.prov.extend(acq_action, raw),
                           split=acq_action.split, valid=valid)

# IP-304 DEC / EC†：证书携带分布域
@dataclass(frozen=True)
class DistributionalContract:
    ec: EvidenceContract                      # R73 定义 367
    P_cert: DistributionFamily                # 认证分布族（散度球/似然比/分层支撑）
    alpha_cov: float                          # 逐层覆盖下界 1-alpha
    shift_tests: Tuple[ShiftTest, ...]        # SENTINEL 检验组
    degrade_policy: Callable[[float], int]    # 漂移量 -> 降级等级 L0..L3

def cert_valid(dc: DistributionalContract, P_hat, sentinel_state, mreg_ok):
    if not mreg_ok: return False
    if sentinel_state == "OOD": return False
    if not dc.P_cert.contains(P_hat): return False
    return True                               # fail-closed: 无法判定 => False

# IP-305 SENTINEL：分层 e-process 漂移哨兵（fail-closed）
class Sentinel:
    def __init__(self, tests, alpha, strata):
        self.tests = tests; self.alpha = alpha; self.strata = strata
        self.state = "ID"; self.warn_since = None
    def step(self, batch, t):
        # 全局 + 每个安全关键分层都要检验；只看全局会被稀疏漂移绕过
        for T in self.tests:
            self.e[T.name] *= T.e_value(batch)          # e-process 更新
        self.e_worst = max(self.e[T.name] for T in self.tests
                           if T.stratum in self.strata)  # 最坏分层
        if self.e_worst >= 1/self.alpha:
            self.state = "WARN"
            if self.e_worst >= 1/self.alpha_ood or self.warn_too_long(t):
                self.state = "OOD"
        # 检测器自身失效也要 fail-closed
        if not self.self_cert_valid(): self.state = "OOD"
        return self.state

# IP-306 CDA：覆盖驱动采集（与 PVOP 共用动作预算）
def coverage_driven_acquisition(P_cert, chi_E, budget, state):
    def J(a):
        gain   = chi_E(a).coverage_lb_gain(state)    # 解析/半解析，类比 chi_v
        cost   = a.cost + sum(m.reflex_cost_estimate(state[m], m.ec.chi_R(a))
                              for m in modules)
        return gain - LAMBDA_ACQ * cost
    a = argmax_under_budget(J, budget, forbid_touching={"AUDIT", "HELD"})
    return a if a is not None else None              # 采不起 -> L3 或降级

# IP-307 e-GAUGE + PBA：anytime-valid 审计 + 谱系绑定
def e_gauge_audit(e_process, alpha, meta_cert, prov_graph):
    if not pba_check(prov_graph):                    # fit/audit 分离、角色预注册
        return "REVOKE"                              # 证书撤销，不是降级
    return "REJECT" if e_process.value >= 1/alpha else "ACCEPT"
    # Ville: 对任意由采集策略决定的停时，P(REJECT | H0) <= alpha

# IP-308 S-DEG：漂移感知单调降级
def shift_degrage(state, level, affected_strata):
    if state == "ID":   return level                 # L0
    if state == "WARN": return max(level, 1)         # L1: 禁 PAR 缩窄
    if state == "OOD":
        if affected_strata: return max(level, 2)     # L2: 分层/模态 stub
        return 3                                     # L3: 整机 R68
    if ttl_expired() and not reacquired(): return 3  # 时钟兜底

# IP-309 SHIFTGAUGE 主闭环（在 MODGAUGE 上插入采集/哨兵/降级）
def SHIFTGAUGE_round(S, obs, audio, tac_frame, depth_img):
    # === 采集域（事件触发 / 离线批次）===
    acq_ev = S.ams.update(S.pending_acq, raw=S.raw_buf, env=S.env, prev=S.prev_acq)
    if acq_ev.valid: S.cert_store.attach(acq_ev)     # 谱系写入
    else:            S.cert_store.invalidate(acq_ev) # 采集不可信 => 证书不可信

    # === 感知域（继承 R73）===
    d_ev = S.dpe.update(depth_img, rgb, S.cam_state, S.motion, S.peers)
    if not d_ev.valid: d_ev = stub(S.dpe)
    t_ev = S.dmem.update(tac_frame, S.last_action)

    # === 计量域 ===
    if S.clock.due_metric():
        s = S.sentinel.step(batch=S.recent, t=S.clock.t)        # IP-305
        b_t, z_dist, ece_z = S.bse_irl.step(d_ev, t_ev, obs, audio)
        a_acq = coverage_driven_acquisition(S.P_cert, S.chi_E, S.budget, S.state)  # IP-306
        g = S.ervoi.choose(b_t, z_dist, t_ev.c_dist, S.budget, S.fmp, S.bse)
        if g:
            s2, cost = sigmareflex_step(S.mods, g, S.state, S.budget)   # R73 + chi_E 合算
            if s2 is not None: S.last_g, S.state = g, s2
        if a_acq: S.pending_acq = a_acq
        level = shift_degrage(s, S.level, S.affected_strata)    # IP-308
        if level >= 2: S.mods = stub_affected(S.mods, S.affected_strata)
        S.snapshot.write(b_t, z_dist, d_ev, t_ev, S.state, level, s)
        S.mreg.audit()

    # === 控制域（继承 R73，只读快照）===
    snap = S.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u),
                              snap.level, S.risk_params)   # 降到 L1+ 即抬高 lambda
    k = S.c_ras_wm.certified_prefix(S.ach.propose_ctrl(..., pvop_bias=snap.pvop), lam)
    S.ctrl_out.publish(k, lam)
    return k, lam, J_MOD_v2(S.mreg, S.cert_store)             # 含 MetaCert 的乘法项
```

## 3. 推导

**引理 38（采集五分量条件正交性）** 给定（采集动作，环境，操作者，时间窗）条件下，五分量由独立机制产生（覆盖几何、基准加工/标注、谱系管理、策略选择、时间老化），条件近似不相关；遗漏任一分量 ⇒ 系统性高估证书强度（与引理 33 同型，条件集扩大到采集过程）。系：**AMS 不是「给数据加个质量分」，而是把 R73 的「证据计量」递归到证据的来源。**

**引理 39（分布域组合的单调收缩 / 无免费泛化）** 对任意 ⊛：𝒫_comp = 𝒫_A ∩ 𝒫_B ⊆ 𝒫_A, 𝒫_B；逐层覆盖取 min；故组合路径的认证分布族不可能严格大于任何输入。要扩张 𝒫_cert，唯一合法途径是增加新的、与既有数据谱系可分离的采集（定义 384/392）。系：**「组合不产生认知免费午餐」（R73 引理 34）在分布层的严格推广；领域自适应的收益必须记在采集账上，不能记在组合账上。**

**引理 40（e-process 在自适应采集下的 anytime 有效性）** 若 (E_t) 在 H_0 下为非负上鞅，且采集策略 π_acq 只依赖 ℱ_{t−1}（因果、不窥探未来），则任意由 (E_t, π_acq) 决定的可选停时 τ 满足 P(E_τ ≥ 1/α | H_0) ≤ α（Ville）。故「边采边测边停」不违反 I 类错误；固定 conformal 的固定样本量假设被解除。系：**e-GAUGE 是 CDA 的统计许可证。**

**引理 41（慢漂移与稀疏漂移的可检测性下界）** 设检测器对累计位移的最小可检量为 δ_min，漂移速率 ρ_drift，则检测时延 τ ≥ δ_min/ρ_drift，且检测时刻的累计位移 → δ_min（ρ→0）。更糟：若漂移仅作用于占比 π_s → 0 的安全关键分层，全局检验的功效 → α（不可检），而该层风险可达最大。⇒ **仅靠检测无法给出与漂移速度/稀疏度无关的保证；必须叠加与检测无关的 TTL（定义 393）与逐层检验（定义 396）。** 系：**检测是加速器，不是保证；保证来自维护。**

**引理 42（S-DEG 的安全单调）** 对任意状态，Lk 的保守性（PAR 禁用、stub、R68）使风险上界单调不减，且任何降级都不减少其他模态的证据（stub 只影响本分层/本模态，定义 381/394）。禁止 L3→L0 直跳（定义 394）⇒ 不存在「检测器恢复即宣称安全」的路径。系：**降级链与 R73 退化链同构，安全侧只增不减。**

**引理 43（证书过拟合的不可避免性与 PBA 的必要性）** 若采集策略可选择或影响 AUDIT 集，则对任意目标覆盖 γ，存在策略使报告覆盖 ≥ γ 而真实覆盖任意低（挑易样本/近重复样本）；故 C-overfit gap 无上界。PBA（谱系分离 + 角色预注册 + 审计封存）切断策略对审计的影响；再叠加 e-GAUGE，gap 以 1−α 概率 ≤ 0。系：**「主动采集」若不同时做「采集的采集」，必然退化为自我认证。**

**引理 44（分层覆盖与边际覆盖的差距界）** 边际覆盖 = Σ_s π_s·cov_s。若某安全关键层 S_k 的 π_k 可以很小，则边际 ≥ 1−α 完全不约束 cov_k（可低至 1−(1−α)/π_k 的下界，且随 π_k→0 趋于 0）。故 DEC 必须逐层（定义 396），否则最危险的分层恰好最不受约束。系：**R73 的「conformal 覆盖率 ≥ 1−α」在 OOD 下是一个边际幻象。**

**定理 30（SHIFTGAUGE 严格包含 R73）** 取 𝒫_cert = {P_cal}（单点分布族）、SENTINEL ≡ ID（恒不报警）、AC 平凡（split=HELD、u_acq=0）、TTL=∞，则 SHIFTGAUGE 逐指令等于 MODGAUGE（R73），再退化等于 R72/R71/R68。**安全单调不减；新增能力仅在 P ∈ 𝒫_cert 且采集合法时兑现。**

**定理 31（OOD 安全条件）** 设 A114–A117 成立。则对任意部署分布 P：
(i) P ∈ 𝒫_cert 且 MReg 合法 ⇒ 风险 ≤ ε_mod(P)；
(ii) P ∉ 𝒫_cert 且 SENTINEL 在 τ 内检出 ⇒ 风险 ≤ ε_mod(P) + L_shift·ρ_drift·τ + ε_detect，并在 L1–L3 后进一步收紧；
(iii) 未检出（慢/稀疏漂移）时 ⇒ 风险保证降级为「在 τ_cert 内成立或强制 L3」：超过 TTL 且无法重采即整机 R68。
**故保证不是一个数，而是三元组（域内界，检测滞后界，TTL 界）的并。** 证明用定义 388/397 + 引理 41/42。

**定理 32（采集-审计分离的证书有效性 / C4 隔离定理）** 在 PBA 合法（引理 43 条件）且 e-GAUGE 为零假设上鞅（引理 40 条件）下：无论采集策略如何自适应，报告覆盖下界以概率 ≥ 1−α_cov 不高于真实逐层覆盖；故 C-overfit gap ≤ 0。若无 PBA（策略可选审计集），存在策略使 gap 无上界。**这条定理给出 C4 的隔离消融：DEC+CDA+e-GAUGE+PBA vs 仅 OOD 检测 vs 被动校准，差异可被 MB4/MB5 直接测量。**

**A114–A117（新增条件）** A114：采集五分量模型在 D_acq 内可表达真实采集误差；A115：𝒫_cert 可被 SENTINEL 检验组保守判定（不能判定 ⇒ fail-closed）；A116：H_0 下 e-process 上鞅性成立；A117：分层划分在安全分析阶段预注册，不依赖部署数据。**定理 31/32 的证明重量落在 A115/A116：分布域的「可判定性」与 e-process 的「上鞅性」是新的两个脆弱假设。**

## 6. 本轮最大风险

**一句话**：SHIFTGAUGE 把安全从「分布内」扩展到「分布域」，但它的最终保证依赖 SENTINEL 能在证书失效前检出漂移——而 OOD 检测存在**不可消除的慢漂移与稀疏分层盲区**（任何有限灵敏度的全局检验都能被足够慢、足够局部的漂移规避，而最危险的分层往往占比最小、最不可检），再叠加「采集会按覆盖目标选数据」对审计集的潜在污染，系统可能在**证书已失效、哨兵未报警、审计日志仍显示 coverage ≥ 1−α** 的空窗期里运行；最大的风险不是检测不到大漂移，而是**慢/稀疏漂移下「安全」与「证书有效」之间的空窗期被系统性低估，而 TTL 与逐层检验这两个兜底恰好是最容易被工程上「为了可用性」而放宽的两个参数**。

次级风险与缓解：
1. **𝒫_cert 不可判定（A115）** → 只声明可被检验组保守判定的分布族（散度球 + 分层支撑 + 似然比界），无法判定即 fail-closed；SEAL-SHIFT 做域族校准。
2. **e-process 上鞅性失效（A116，模型误设）** → 用非参数 e-value + 对模型误设做稳健化（betting e-process）；H_0 复合零假设需显式覆盖 𝒫_cert 的并。
3. **分层 p-hacking（A117）** → 分层在安全分析阶段预注册并哈希锁定；禁止部署后加层；E400 做对抗性分层审计。
4. **TTL 被工程放宽** → TTL 与漂移预算写入契约且进入 J_MOD v2，放宽即证书失效；E412 量化可用性代价。
5. **采集成本被低估 / C4 净收益为负** → CertCost v2 强制计入采集；E409 只认扣除采集后的净收益。
6. **谱系近重复检测漏检** → 哈希 + 嵌入近重复 + 采集动作元数据三重判重；漏检进入 u_provenance 并由 PBA 撤销。
7. **χ_E 解析失真** → 与 χ_v 同法：有效域硬边界 + 近场/极端禁用解析 + 在线查表；E413 验证。
8. **「域外保守」导致可用性塌缩** → L1/L2 分层降级而非全局 stub；域外只禁用缩窄、保留观测；E405/E408 量化。
9. **分布域组合爆炸** → 只允许可判定的分布族表示（散度球 + 分层箱），交集仍是同族；|𝒮| ≤ 8、|𝒯_shift| ≤ 16 作为可审计图性质。

## 2. 形式化定义（要点版）

**定义 383（SHIFTGAUGE 总览与六不变式）** R73 五不变式 + (vi) 分布域完备性：每张 cert 携带 𝒫_cert 与逐层覆盖下界；部署时经 SENTINEL 判定；不可判定或检测器自身失效 ⇒ **fail-closed**。无 𝒫_cert 的 cert 不入图（「无契约不入图」的数据层推广）。

**定义 384–386（AMS：采集契约、五分量、采集动作）** AC 见符号表；采集动作 a_acq=(probe,target,expected_gain,cost)，与任务动作共用动作空间（走近=采集+视角改变）；AMS 输出（五分量, χ_E, τ_acq, split, valid）。split ∈ {FIT,AUDIT,HELD} 由谱系预注册，事后不可改。

**定义 387–388（DEC 与条件证书）** 证书语义从「标量风险」变为「函数 Cert_i(P)」：对任意 P ∈ 𝒫_cert^i 给风险上界；P ∉ 𝒫_cert^i ⇒ 不提供保证、必须降级。Valid(J_MOD|P) ⇔ 全部 P ∈ 各自分布域 ∧ 检验未越阈 ∧ 组合校验通过 ∧ 谱系合法 ⇒ 风险 ≤ ε_mod(P)。**R73 定理 28 是 P = P_cal 的特例。**

**定义 389（SENTINEL）** 分层 e-process 检验组；ID→WARN（禁 PAR 缩窄）→OOD（降级）；全局 + 最坏分层 + 罕见事件层；检测器自身在 SEAL-SHIFT 上校准，自身域外或不确定 ⇒ fail-closed。**只看全局会被稀疏漂移绕过（引理 41）。**

**定义 390（e-GAUGE）** 用非负上鞅 e-process 与 Ville 不等式替代固定 conformal；对任意由自适应采集决定的可选停时，I 类错误 ≤ α。**这是主动采集在统计上合法的前提，不是工程选项。**

**定义 391（CDA）** a_acq* = argmax ΔCoverage_lb(a) − λ_acq·cost(a) − Σ c_reflex^i(a)，s.t. B_acq、D_acq、REG 时序、禁触 AUDIT/HELD；ΔCoverage_lb 由 χ_E 解析/半解析给出（类比 PVOP 的解析 χ_v）。

**定义 392（PBA）** 谱系图 G_prov；校验 (i) fit/audit 谱系分离（无共享采集动作/重复样本），(ii) 角色预注册，(iii) 审计封存（采集策略不可见），(iv) 元证书 MetaCert=(AC,G_prov,e-process 轨迹) 进入 J_MOD。PBA 失败 ⇒ **撤销证书**（不是降级）。

**定义 393（TTL 与再采集调度）** 每 cert 携带 τ_cert 与漂移预算 δ_D；超 τ_cert 无论 SENTINEL 是否报警，强制「重采集或降级」；τ_cert* 权衡有效工作时长与重采成本，约束 L_shift·δ_D(τ) ≤ ε_budget。**时钟不会坏，检测器会坏。**

**定义 394（S-DEG）** L0 正常 / L1 禁 PAR 缩窄与近场 χ_v 外推 / L2 受影响分层或模态 stub / L3 整机 R68；保守性单调、禁止 L3→L0 直跳（须重采集+重校准）。stub 语义继承 R73 定义 381。

**定义 395（分布域组合）** 𝒫_comp=𝒫_A∩𝒫_B；覆盖取逐层 min；PAR 缩窄须联合 e-GAUGE 在交集上未拒；交集空 ⇒ 组合非法；χ_E 串联；谱系合并后仍须 fit/audit 分离。**无新采集 ⇒ 组合不扩张认证分布族（引理 39）。**

**定义 396（分层覆盖）** 分层 𝒮 由安全分析预注册；要求逐层 cov_s ≥ 1−α_cov（联合控制），而非仅边际。**边际覆盖可在最危险层 cov=0 时仍成立（引理 44）。**

**定义 397（漂移风险界）** 域内 ε_mod；域外且检出滞后 τ ⇒ ε_mod + L_shift·ρ_drift·τ + ε_detect；未检出 ⇒ 退化为「τ_cert 内成立或强制 L3」。

**定义 398（覆盖黑客）** 若策略可选/影响 AUDIT 集，C-overfit gap 无上界；PBA 分离 + 封存 + e-GAUGE 后 gap 以 1−α 概率 ≤0。

**定义 399（C4 与 CPB v2）** C4 绑定见符号表；隔离消融 AB4：DEC+CDA+e-GAUGE+PBA vs 被动校准 vs 仅 OOD 检测；预注册指标 (coverage_retention, worst_stratum_cov, safe_degrade_rate, risk_bound_violation, c_overfit_gap)，收益须扣除 CertCost v2 中的采集成本。

```python
# IP-305 SENTINEL：分层 e-process 漂移哨兵（fail-closed）
class Sentinel:
    def __init__(self, tests, alpha, strata):
        self.tests = tests; self.alpha = alpha; self.strata = strata
        self.state = "ID"; self.warn_since = None
    def step(self, batch, t):
        # 全局 + 每个安全关键分层都要检验；只看全局会被稀疏漂移绕过
        for T in self.tests:
            self.e[T.name] *= T.e_value(batch)          # e-process 更新
        self.e_worst = max(self.e[T.name] for T in self.tests
                           if T.stratum in self.strata)  # 最坏分层
        if self.e_worst >= 1/self.alpha:
            self.state = "WARN"
            if self.e_worst >= 1/self.alpha_ood or self.warn_too_long(t):
                self.state = "OOD"
        # 检测器自身失效也要 fail-closed
        if not self.self_cert_valid(): self.state = "OOD"
        return self.state

    if state == "WARN": return max(level, 1)         # L1: 禁 PAR 缩窄
    if state == "OOD":
        if affected_strata: return max(level, 2)     # L2: 分层/模态 stub
        return 3                                     # L3: 整机 R68
    if ttl_expired() and not reacquired(): return 3  # 时钟兜底

# IP-309 SHIFTGAUGE 主闭环（在 MODGAUGE 上插入采集/哨兵/降级）
def SHIFTGAUGE_round(S, obs, audio, tac_frame, depth_img):
    # === 采集域（事件触发 / 离线批次）===
    acq_ev = S.ams.update(S.pending_acq, raw=S.raw_buf, env=S.env, prev=S.prev_acq)
    if acq_ev.valid: S.cert_store.attach(acq_ev)     # 谱系写入
    else:            S.cert_store.invalidate(acq_ev) # 采集不可信 => 证书不可信

    # === 感知域（继承 R73）===
    d_ev = S.dpe.update(depth_img, rgb, S.cam_state, S.motion, S.peers)
    if not d_ev.valid: d_ev = stub(S.dpe)
    t_ev = S.dmem.update(tac_frame, S.last_action)

    # === 计量域 ===
    if S.clock.due_metric():
        s = S.sentinel.step(batch=S.recent, t=S.clock.t)        # IP-305
        b_t, z_dist, ece_z = S.bse_irl.step(d_ev, t_ev, obs, audio)
        a_acq = coverage_driven_acquisition(S.P_cert, S.chi_E, S.budget, S.state)  # IP-306
        g = S.ervoi.choose(b_t, z_dist, t_ev.c_dist, S.budget, S.fmp, S.bse)
        if g:
            s2, cost = sigmareflex_step(S.mods, g, S.state, S.budget)   # R73 + chi_E 合算
            if s2 is not None: S.last_g, S.state = g, s2
        if a_acq: S.pending_acq = a_acq
        level = shift_degrage(s, S.level, S.affected_strata)    # IP-308
        if level >= 2: S.mods = stub_affected(S.mods, S.affected_strata)
        S.snapshot.write(b_t, z_dist, d_ev, t_ev, S.state, level, s)
        S.mreg.audit()

    # === 控制域（继承 R73，只读快照）===
    snap = S.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u),
                              snap.level, S.risk_params)   # 降到 L1+ 即抬高 lambda
    k = S.c_ras_wm.certified_prefix(S.ach.propose_ctrl(..., pvop_bias=snap.pvop), lam)
    S.ctrl_out.publish(k, lam)
    return k, lam, J_MOD_v2(S.mreg, S.cert_store)             # 含 MetaCert 的乘法项
```

## 4. 推导

**引理 38（采集五分量条件正交性）** 给定（采集动作，环境，操作者，时间窗）条件下，五分量由独立机制产生（覆盖几何、基准加工/标注、谱系管理、策略选择、时间老化），条件近似不相关；遗漏任一分量 ⇒ 系统性高估证书强度（与 R73 引理 33 同型，条件集扩大到采集过程）。系：**AMS 把「证据计量」递归到证据的来源。**

**引理 39（无免费泛化）** 任意 ⊛ 下 𝒫_comp = 𝒫_A∩𝒫_B ⊆ 各输入；逐层覆盖取 min；组合路径的认证分布族不可能严格大于输入。扩张 𝒫_cert 的唯一合法途径是新增可谱系分离的采集。系：**R73「组合不产生认知免费午餐」在分布层的严格推广；领域自适应收益必须记在采集账上。**

**引理 40（e-GAUGE anytime 有效性）** 若 (E_t) 在 H_0 下非负上鞅，采集策略只依赖 ℱ_{t−1}，则任意由 (E_t, π_acq) 决定的可选停时 τ 满足 P(E_τ ≥ 1/α | H_0) ≤ α（Ville）。固定 conformal 的固定样本量假设被解除。系：**e-GAUGE 是 CDA 的统计许可证。**

**引理 41（慢/稀疏漂移下界）** 设最小可检累计位移 δ_min、漂移速率 ρ_drift，则检测时延 τ ≥ δ_min/ρ_drift，检测时刻累计位移 → δ_min（ρ→0）；若漂移仅作用于占比 π_s→0 的安全关键层，全局检验功效 → α（不可检），而该层风险最大。⇒ 仅靠检测无法给出与速度/稀疏度无关的保证；必须叠加 TTL（定义 393）与逐层检验（定义 396）。系：**检测是加速器，保证来自维护。**

**引理 42（S-DEG 安全单调）** L0→L3 保守性单调不减；stub 只影响本分层/本模态；禁止 L3→L0 直跳 ⇒ 无「检测器恢复即宣称安全」路径。系：**降级链与 R73 退化链同构，安全侧只增不减。**

**引理 43（证书过拟合与 PBA 必要性）** 若策略可选/影响 AUDIT 集，则对任意目标覆盖 γ 存在策略使报告覆盖 ≥ γ 而真实覆盖任意低，C-overfit gap 无上界；PBA 切断策略对审计的影响，叠加 e-GAUGE 后 gap 以 1−α 概率 ≤0。系：**主动采集若不做「采集的采集」，必然退化为自我认证。**

**引理 44（分层覆盖 vs 边际覆盖）** 边际覆盖 = Σ_s π_s·cov_s；若安全关键层 π_k 很小，边际 ≥1−α 完全不约束 cov_k（可随 π_k→0 趋于 0）。故 DEC 必须逐层。系：**R73 的「覆盖率 ≥1−α」在 OOD 下是边际幻象。**

**定理 30（严格包含 R73）** 取 𝒫_cert={P_cal}、SENTINEL≡ID、AC 平凡、TTL=∞，则 SHIFTGAUGE 逐指令等于 MODGAUGE，再退化等于 R72/R71/R68。安全单调不减，新能力仅在 P∈𝒫_cert 且采集合法时兑现。

**定理 31（OOD 安全条件）** 设 A114–A117：(i) P∈𝒫_cert 且 MReg 合法 ⇒ 风险 ≤ ε_mod(P)；(ii) P∉𝒫_cert 且 τ 内检出 ⇒ 风险 ≤ ε_mod(P)+L_shift·ρ_drift·τ+ε_detect，L1–L3 后进一步收紧；(iii) 未检出 ⇒ 保证降级为「τ_cert 内成立或强制 L3」。**保证是三元组（域内界，检测滞后界，TTL 界）的并。**

**定理 32（采集-审计分离的证书有效性 / C4 隔离定理）** 在 PBA 合法且 e-GAUGE 为上鞅（A116）下：无论采集策略如何自适应，报告逐层覆盖下界以概率 ≥1−α_cov 不高于真实覆盖，C-overfit gap ≤0；无 PBA 时 gap 无上界。**直接给出 C4 的隔离消融。**

## 7. 本轮最大风险

**一句话**：SHIFTGAUGE 把安全从「分布内」扩展到「分布域」，但最终保证依赖 SENTINEL 能在证书失效前检出漂移——而 OOD 检测存在**不可消除的慢漂移与稀疏分层盲区**（任何有限灵敏度全局检验都能被足够慢、足够局部的漂移规避，最危险的分层往往占比最小、最不可检），叠加「采集按覆盖目标选数据」对审计集的潜在污染，系统可能在**证书已失效、哨兵未报警、审计日志仍显示 coverage ≥1−α** 的空窗期运行；最大的风险不是检测不到大漂移，而是**慢/稀疏漂移下「安全」与「证书有效」之间的空窗期被系统性低估，而 TTL 与逐层检验这两个兜底恰好是最容易被工程上「为了可用性」而放宽的两个参数**。

次级风险与缓解：
1. **𝒫_cert 不可判定（A115）** → 只声明可被检验组保守判定的分布族（散度球+分层支撑+似然比界），不可判定即 fail-closed；SEAL-SHIFT 做域族校准。
2. **e-process 上鞅性失效（A116，模型误设）** → 非参数 e-value + betting e-process 稳健化；复合零假设显式覆盖 𝒫_cert 的并。
3. **分层 p-hacking（A117）** → 分层在安全分析阶段预注册并哈希锁定；禁止部署后加层；E400 做对抗性分层审计。
4. **TTL 被工程放宽** → TTL 与漂移预算写入契约并进入 J_MOD v2，放宽即证书失效；E412 量化可用性代价。
5. **采集成本被低估 / C4 净收益为负** → CertCost v2 强制计入采集；E409 只认扣除采集后的净收益。
6. **谱系近重复检测漏检** → 哈希+嵌入近重复+采集动作元数据三重判重；漏检进入 u_provenance 并由 PBA 撤销。
7. **χ_E 解析失真** → 与 χ_v 同法：有效域硬边界+近场/极端禁用解析+在线查表；E413 验证。
8. **「域外保守」导致可用性塌缩** → L1/L2 分层降级而非全局 stub；域外只禁缩窄、保留观测；E405/E408 量化。
9. **分布域组合爆炸** → 只允许可判定分布族表示（散度球+分层箱），交集仍同族；|𝒮|≤8、|𝒯_shift|≤16 作为可审计图性质。
