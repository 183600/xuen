# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「泛化能力」×「社会规范理解」）

> R69 给了系统一张「嘴」——它会展露歧义（流匹配多模态）、会看、会问、会触。但 R69 悄悄押了两个前提，都没有被检验：
> 1. **它的模态分布在当前输入上仍然有意义**。流策略在训练分布外采样出的 K 条轨迹，未必是「可能的未来」，而可能是「幻觉」。VoI 建立在错误信念上——这正是 R69 自陈的最大风险。
> 2. **它的交互在社交上可被接受**。R69 把交互编码为一个标量成本 c(g)，仿佛规范是一张价签，付得起就能越界。但规范不是价格，是红绿灯：有些动作在这里根本不被允许，无论信息增益多大（隐私、尊严、角色、在场者）；而且「这里」依赖你只能部分观测的语境，只能从稀疏示范与语言先验中习得——这本身就是一个泛化问题。
>
> 本轮两个灵感正好各堵一个洞：
> - **泛化能力**不是模型的形容词，而是一句**可被检验、也可被拒绝的覆盖声明**。conformal prediction 给分布无关覆盖率 1−α，代价是全押在**可交换性（exchangeability）**上；而泛化失败恰恰是可交换性破裂。于是系统可以「知道自己什么时候失去了保证」。
> - **社会规范理解**把规范从「成本」升级为「deontic 约束 + 可估计的可信集」：规范是隐性的、多元的、时变的；不确定性越高，许可动作集越小。
>
> 核心命题：**把「我能不能做」拆成两问——competence（泛化，physis）与 permission（规范，nomos）；前者用 conformal 覆盖 + 可交换性检验守门，后者用规范后验的可信集 + 鲁棒许可守门；两问在「陌生处」合流为同一条因果链：越 novelty → 覆盖越不可信、可信集越宽 → 鲁棒许可集越窄 → 越保守。** 命名 **NOMOS-RAS**（Norms, OOD, Meta-normative, Oversight Safeguards；亦取希腊语 νόμος「习俗/法」与 physis/nomos 之辩：可泛化的是自然，可被允许的是习俗）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在这里，我有没有资格问、问了合不合规矩**」——不确定性不只是刹车踏板，也不只是一句提问；它是**一句必须本身也合规矩、且只在你看懂了这个房间时才配问出口的提问**。

## 0. 直觉与动机

**灵感 1（泛化能力 → 模态分布有「适用域」）**
直觉：R69 问「我在哪个模态」，却没问「我知不知道这里到底有哪些模态」。流策略在 p_train 支撑集外采样出的 K 条轨迹，不是「可能的未来」，而是「模型编出来的未来」。跨学科桥：conformal prediction 给出分布无关覆盖 ≥ 1−α，但它的全部效力系于可交换性；而「泛化失败」在统计上就是可交换性被打破。所以别把泛化当成一个不可测的形容词，把它做成一个**可拒绝的原假设**：系统同时输出「覆盖率声明（1−α）」和「该声明当前的失效证据（T_ex）」。这样 R69 的 VoI 就有了前置门槛——信念不可信时，别在上面算信息增益。

**灵感 2（社会规范理解 → 规范不是价格，是红绿灯）**
直觉：R69 的 c(g) 是价签，可以「付钱越界」；规范是 deontic 的——有些动作在这里根本不允许，无论信息增益多大。而且「这里」依赖只能部分观测的语境（关系、角色、紧急度、在场者、文化）。规范大多隐性，只从稀疏纠正反馈和语言先验习得，因此**规范模型必须带不确定性，且不确定性本身要被纳入决策**，而不是用一个点估计的 ν 假装知道礼貌。

**灵感 3（两者在陌生处合流 → 双重失能，一条因果链）**
直觉：真正危险的地方恰是泛化差的地方——陌生的社会场景里，你既不懂当地「物理怎么运作」，也不懂当地「规矩怎么算」。二者共变。所以别做成两个并列模块相加：让 novelty 同时（a）削弱覆盖声明、（b）扩大规范可信集；由于鲁棒许可在可信集越宽时越收缩，「越不确定越保守」就成了一条**单调性**，而不是一条需要额外拍脑袋的安全规则。

**灵感 4（规范鲁棒 → 文化多元不是 Bug，是约束）**
直觉：若只维护单条规范 ν，就把一个文化普遍化了——这是规范僭越。改为维护规范后验的**可信集 N_ρ**，要求信息动作在 N_ρ 内「处处许可」（robust permission），并对信息增益取最坏情形。收益自动打折，越不确定越不行动，且系统在构造上永不宣称某文化规范普适。

**灵感 5（问「能不能问」也是问 → 自指安全）**
直觉：系统一旦用「问」来消除规范不确定，就出现自指——「我可以凑近看吗」本身也是社交动作，也可能不合规矩。别无限递归：找一个**不动点**——若连元问题都不在鲁棒许可集内，则不交互，只做最保守的任务动作（观察/等待）。这把「问」的安全边界封在有限深度。

**灵感 6（规范可学，但只能离线；并带来三个新威胁）**
直觉：规范从纠正反馈/不适信号中学习，但必须离线批更新（继承实时零写）。新攻击面：**规范投毒**（有人故意教错规矩）、**规范漂移**（社会随时间变）、**规范盲区**（训练与标定里根本没有的规矩）。盲区最致命：可信集给出虚假的合规感。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（NOMOS-RAS 总览）** NOMOS-RAS = (GEN, NOM, NCRS, META, RDI, NCG, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 276-i）；
(ii) **deontic floor（道义底线）**：任何信息动作若在可信规范集内某规范下被禁止，则不可执行；VoI 不得覆盖——deontic 约束是硬约束而非成本；
(iii) **competence gating（能力门）**：仅当可交换性检验未被拒绝时，VoI 才信任模态分布，否则退化。

**定义 311（泛化证书 GEN / competence 区域）** 标定集上非一致性分数 s(o, ξ)；conformal 给出模态集 C_α，在可交换性下覆盖 ≥ 1−α。可交换性检验统计量 T_ex（如非一致性分数分布的两样本 KS / 秩检验）。competence c_G = σ(−T_ex) ∈ [0,1]；拒绝可交换性则 c_G → 0。**关键**：系统输出「覆盖率声明 + 该声明此刻的失效证据」，而不是裸置信度。

**定义 312（规范系统 NOM）** 规范系统 ν : (q, action) → (d, a)，其中 deontic 状态 d ∈ {F（禁止）, P（允许）, O（应当）}，软适宜度 a ∈ ℝ。语境算子 q = Ψ(o)（关系 / 角色 / 在场者 / 紧急度 / 文化线索）。ν 是**潜在**的：维护后验 p(ν | D_norm)，不取点估计。

**定义 313（规范可信集 NCRS 与鲁棒许可）** N_ρ = {ν : 后验可信质量 ≥ 1−α_norm}（或 Wasserstein 半径 ρ 的 DRO 球）。**鲁棒许可**：g 在 N_ρ 下「处处许可」⇔ ∀ν ∈ N_ρ，d_ν(g) ≠ F。

**定义 314（规范鲁棒信息价值 META）** VoI_robust(g) = min_{ν∈N_ρ} [VoI(g) − c_ν(g)]，s.t. ∀ν∈N_ρ 许可、通过 R69 预算与 C-RAS-WM 认证。选 g* = argmax_g VoI_robust(g)。若不存在鲁棒许可候选，或 max VoI_robust ≤ 0 ⇒ 不交互，走 R69 → R68 兜底。

**定义 315（元规范询问 MNQ）** 当任务消歧被规范不确定阻断，可发 g_norm ∈ 𝒜_info（如「我可以靠近看看吗」）。g_norm 亦须鲁棒许可，否则不交互。**有限深度**：最多一层元询问（防自指无限递归）。

**定义 316（离线规范学习 NDL）** 稀疏规范反馈（纠正 / 拒绝 / 不适信号）→ 批更新规范后验。实时零写；更新须过规范校准（定义 318）。

**定义 317（联合 competence–规范 OOD）** novelty n(o) 由生成模型密度得。n 高 ⇒ 同时（a）c_G 降、（b）N_ρ 半径 ρ 增。由定义 313，鲁棒许可随 ρ 单调收缩 ⇒ 单调保守（定理 18）。二者不是并列模块，而是一条因果链。

**定义 318（规范校准门 NCG）** 规范后验 ECE > τ_norm，或 OOD 拒真 ⇒ 禁用规范相关交互，退化 R69（R69 再退化 R68）。

**定义 319（RDI 鲁棒道义交互）** 信息动作须同时通过：R69 的 C-RAS-WM 认证 × 定义 313 鲁棒许可 × R69 证据纪律（定义 293-iii）。任一不过 ⇒ 作废，视为 U_epi 未消解。

**定义 320（证书 J_NOMOS）** J_NOMOS = (J_FLUID, coverage_emp, ex_p, norm_ECE, deontic_violations=0, rho, meta_norm_ratio, norm_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖声明未失效（ex_p 未越界）∧ norm_ECE ≤ τ_norm ∧ deontic_violations = 0。

**定义 321（规范盲区风险）** 真规范 ν* ∉ N_ρ 的情形。此时鲁棒许可给出**虚假保证**。内部证据无法自证（引理 22），必须靠结构性兜底与外部审计。

**定义 322（不可交互默认通道 SafeDefault）** 永远保留一条不依赖规范推理的「只做安全任务动作 / 观察 / 等待（并转人工）」路径。任何「OOD 拒真 ∧ 拟交互」时强制走此通道。它既防「盲区下自信违规」，也防「可信集过宽导致瘫痪」——因为观察/等待通常是 deontic 上最安全的一档。

**定义 323（规范漂移跟踪）** 规范的时序非平稳性；用变化点检测跟踪 ρ 与 ν 后验；检测到漂移 ⇒ ρ 增大 ⇒ 更保守（接定义 317 的单调链）。

**定义 324（规范投毒与干扰集 AIC-NOMOS）** 恶意规范反馈、共谋「大家都说可以」、以纠正为名的操纵。并入 AIC：ℰ_NOMOS = ℰ_FLUID × ℰ_norm_poison × ℰ_norm_drift × ℰ_norm_blindspot。

**定义 325（参与式规范审计 VQAuditor-N）** 审计：规范后验是否被单源反馈绑架、鲁棒许可是否被绕过、元询问是否诱导、是否文化僭越。结论回灌 AuditBuf，作为下一轮 ρ 的先验。

**定义 326（两级退化链）** 若 c_G 高 ∧ 规范可信集为单点且该动作许可 ⇒ 逐指令 = R69；若规范不确定但存在鲁棒许可 ⇒ 对 VoI 折价（保守化）；若 OOD 拒真 / NCG 越界 / 无鲁棒许可 / 疑似盲区 ⇒ 退化 R69，再退 R68。安全侧永不弱于 R69。

## 2. 关键算法骨架

```python
# IP-264 GEN：泛化证书（conformal 覆盖 + 可交换性检验）
def competence(o, xi_candidates, calib):
    scores = [nonconformity(o, xi) for xi in xi_candidates]
    C_alpha = conformal_set(scores, calib.qhat)          # 覆盖 >= 1-alpha
    T_ex    = exchangeability_test(scores, calib.scores) # 漂移/秩检验
    c_G     = sigmoid(-T_ex)
    return C_alpha, c_G, T_ex

# IP-265/266 NOM + NCRS：规范后验与可信集
def norm_credible_set(norm_post, alpha_norm):
    return {nu for nu, mass in norm_post.items() if mass >= 1 - alpha_norm}

def robust_permitted(g, N_rho):
    return all(deontic(nu, g) != 'F' for nu in N_rho)   # 处处许可

# IP-267/268 META + RDI：规范鲁棒 VoI 与道义交互
def choose_interaction_nomos(modes, o, budget, N_rho, c_G):
    if c_G < TAU_CG:                       # 泛化不可信 -> 不算 VoI
        return None                        # 走 R69/R68 兜底
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g):                     continue
        if not c_ras_wm.certify_info(g, o):         continue   # R69 认证
        if not robust_permitted(g, N_rho):          continue   # 道义底线
        worst = min(voi(g, nu, o) - cost(nu, g) for nu in N_rho)
        if best is None or worst > best.score: best = (g, worst)
    return best if best and best.score > 0 else None  # 无利可图/无许可 -> 不交互

# IP-269 MNQ：元规范询问（有限深度，自指不动点）
def maybe_meta_question(blocked_by_norm, N_rho, depth=0):
    if depth > 0: return None            # 只问一层
    g = propose_norm_question()          # "我可以靠近看看吗"
    return g if robust_permitted(g, N_rho) else None

# IP-275 主闭环（继承 R69，在交互门前插 competence + norm 两道门）
def NOMOS_round(M, obs):
    z, o = M.mtm.forward(...); M.cof.step(...)              # R68 标定
    C_alpha, c_G, T_ex = M.gen.competence(o, M.candidates, M.calib)
    n_o   = M.gen.novelty(o)
    N_rho = M.ncrs.credible(radius=lambda: expand(rho0, n_o))# novelty -> rho 增大
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, M.k(o)), z)
    slow  = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    g = None
    if c_G >= TAU_CG and M.ncg.ok() and U_epi > TAU_EPI and not slow:
        g = M.meta.choose(modes, o, M.budget, N_rho, c_G)
        if g is None:
            g = M.mnq.maybe_meta_question(blocked=True, N_rho=N_rho)
    if g is not None:
        ans = M.cia.execute(g)                              # 看/问/触 + 证据纪律
        U_epi = M.cia.update_belief(modes, ans)
    else:
        g = M.safe_default if (n_o > TAU_OOD or c_G < TAU_CG) else None  # 定义 322
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    if g is M.safe_default or slow: lam = max(lam, 0.8)     # 结构性兜底
    M.vqa_n.submit_async(g, N_rho, c_G, U_epi)              # 审计
    return k, lam, (U_ale, U_epi), (c_G, len(N_rho))
```

## 3. 推导

**引理 19（泛化保证的失效是可检测的）** 可交换性下 conformal 覆盖 ≥ 1−α；当 T_ex 越界，经验覆盖下降，且该下降由 T_ex 可检出。故「有保证」与「保证已失效」可被区分——泛化能力由此从形容词变成一个可拒绝的原假设，成为 VoI 的合法前置门。

**引理 20（鲁棒许可 ⇒ 规范违规上界）** 若 g 在 N_ρ 内处处许可，且 P(ν* ∈ N_ρ) ≥ 1−α_norm，则 P(g 实际违规) ≤ α_norm。这是规范侧的「安全证书」，其全部效力系于——可信集是否真的包含真规范（见引理 22）。

**引理 21（元询问的自指安全）** 若 g_norm 不在鲁棒许可集，则「询问」本身即构成一次可能违规的社交动作，其期望违规 ≥ 某一正下界。故安全不动点是：不可鲁棒许可则不询问、只观察。有限深度保证该递归终止。

**定理 18（NOMOS 严格包含 R69，且不确定性 ⇒ 更保守）** 在边界（c_G 高、规范可信集为单点、动作许可）下 NOMOS 与 R69 逐指令相同；任意状态下控制侧风险 ≤ R69，规范违规由引理 20 以 α_norm 界定。且 ρ ↑ ⇒ 鲁棒许可集 ↓（单调），故由定义 317，novelty ↑ ⇒ 更保守，无需额外安全规则。R69 = 「泛化可信且规范已知」边界，R68 = 「永不交互」再退一步。

**定理 19（无规范僭越 / 多元稳健）** 按定义 314 的鲁棒目标选动作，其相对可信集 N_ρ 内任一规范的遗憾 ≤ 与 ρ 相关的上界；且由于决策在规范集合上分布鲁棒，系统在构造上不把任一文化的规范宣称为普适。

**引理 22（规范盲区不可内证）** 若真规范 ν* ∉ N_ρ，则仅凭系统内部证据无法自证其缺失——否则由定义 313 它早已在可信集内。**推论**：盲区只能靠结构性兜底（定义 322）与外部审计（定义 325）处理，不能靠「更聪明的规范推理」消除。这条引理是本轮最重要的诚实：不要假装内部能解决 unknown unknowns。

## 6. 本轮最大风险

**一句话**：NOMOS-RAS 的全部保证都压在「可信规范集 N_ρ 真的包含真规范」这一前提上——一旦进入训练与规范标定都没覆盖的**规范盲区**（OOD 叠加一条隐性规矩），鲁棒许可会给出**虚假的合规感**：系统会礼貌、自信、且系统性地违反一条它根本没有表征到的规矩；这比 R69「问错」更隐蔽，因为它**看起来完全合规**——最危险的不是不知道，而是不知道自己不知道哪些规矩。

**次级风险与缓解**：
1. **可信集过宽 → 瘫痪 / 永不交互** → SafeDefault 默认通道 + 观察/等待的 deontic 最安全档 + Pareto 预算（E299 思路）；
2. **规范投毒 / 共谋「大家都说可以」** → ℰ_norm_poison + 单源不采 + VQAuditor-N；
3. **规范漂移** → 变化点检测 + ρ 自适应（定义 323）；
4. **元询问自指** → 有限深度 + 不动点（引理 21）；
5. **文化僭越** → 多元可信集 + 鲁棒目标（定理 19），并显式承认盲区只能靠外部审计（引理 22）。

# IP-264 GEN：泛化证书
def competence(o, xi_candidates, calib):
    scores = [nonconformity(o, xi) for xi in xi_candidates]
    C_alpha = conformal_set(scores, calib.qhat)          # 覆盖 >= 1-alpha
    T_ex    = exchangeability_test(scores, calib.scores)
    return C_alpha, sigmoid(-T_ex), T_ex

# IP-265/266 NOM + NCRS
def robust_permitted(g, N_rho):
    return all(deontic(nu, g) != 'F' for nu in N_rho)    # 处处许可

# IP-267/268 META + RDI：规范鲁棒 VoI
def choose_interaction_nomos(modes, o, budget, N_rho, c_G):
    if c_G < TAU_CG: return None                          # 泛化不可信 -> 不算 VoI
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g):               continue
        if not c_ras_wm.certify_info(g, o):   continue    # R69 认证
        if not robust_permitted(g, N_rho):    continue    # 道义底线
        worst = min(voi(g, nu, o) - cost(nu, g) for nu in N_rho)
        if best is None or worst > best.score: best = (g, worst)
    return best if best and best.score > 0 else None      # 无利可图 -> 不交互

# IP-269 MNQ：元询问（自指不动点，深度 <= 1）
def maybe_meta_question(N_rho, depth=0):
    if depth > 0: return None
    g = propose_norm_question()                           # "我可以靠近看看吗"
    return g if robust_permitted(g, N_rho) else None

# IP-275 主闭环（继承 R69，插 competence + norm 两道门 + SafeDefault）
def NOMOS_round(M, obs):
    z, o = M.mtm.forward(...); M.cof.step(...)            # R68 标定
    C_alpha, c_G, T_ex = M.gen.competence(o, M.candidates, M.calib)
    n_o   = M.gen.novelty(o)
    N_rho = M.ncrs.credible(radius=lambda: expand(rho0, n_o))   # novelty -> rho↑
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, M.k(o)), z)
    slow  = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    g = None
    if c_G >= TAU_CG and M.ncg.ok() and U_epi > TAU_EPI and not slow:
        g = M.meta.choose(modes, o, M.budget, N_rho, c_G)
        if g is None:
            g = M.mnq.maybe_meta_question(N_rho=N_rho)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))  # 看/问/触 + 证据纪律
    else:
        g = M.safe_default if (n_o > TAU_OOD or c_G < TAU_CG) else None
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    if g is M.safe_default or slow: lam = max(lam, 0.8)   # 结构性兜底
    M.vqa_n.submit_async(g, N_rho, c_G, U_epi)
    return k, lam, (U_ale, U_epi), (c_G, len(N_rho))

## 4. 推导

**引理 19（泛化保证可检测）** 可交换下 conformal 覆盖 ≥ 1−α；T_ex 越界意味着经验覆盖下降且可检出。故「有保证」与「保证失效」可区分，泛化成为 VoI 的合法前置门。

**引理 20（鲁棒许可 ⇒ 违规上界）** `∀ν∈N_ρ` 许可 g 且 `P(ν*∈N_ρ) ≥ 1−α_norm` ⇒ `P(g 实际违规) ≤ α_norm`。规范侧安全证书；效力系于可信集是否真含真规范。

**引理 21（元询问自指安全）** g_norm 不在鲁棒许可集时，询问本身即可能违规；安全不动点是「不鲁棒许可则不询问、只观察」，有限深度保证终止。

**定理 18（严格包含 R69，且不确定 ⇒ 更保守）** 边界（c_G 高、规范单点、动作许可）下逐指令 = R69；任意状态控制风险 ≤ R69（规范违规由引理 20 界定）。且 `ρ↑ ⇒ 鲁棒许可集↓`，由定义 317 novelty↑ ⇒ 更保守。两级退化：R69 = 「泛化可信 + 规范已知」，R68 = 「永不交互」。

**定理 19（无规范僭越 / 多元稳健）** 按定义 314 鲁棒目标选动作，相对 N_ρ 内任一规范的遗憾 ≤ 与 ρ 相关上界；决策在规范集合上分布鲁棒，故构造上不把任一文化规范宣称为普适。

**引理 22（规范盲区不可内证）** 若 ν* ∉ N_ρ，则内部证据无法自证其缺失（否则由定义 313 已在集内）。盲区只能由 SafeDefault（定义 322）与外部审计（定义 325）处理，不能靠更强的规范推理消除。
