# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「论文创新点」×「机械臂抓取」）

> R69 把不确定性一分为二（aleatoric / epistemic），并让系统学会「问」——看、触、问句。但它有一个没有被点破的缺口：**证据只被用来降低熵，却没有被绑定到一个可能失败的命题上**。系统问到了东西，不等于它证明了东西；J_FLUID 是一张安全证书，不是一张真理证书。更尖锐地说，R69 的最大风险是「模态分布可能不可信」，而它对此的补救仍然是**在同一套可能错误的世界模型里继续求证**——求证（VoI）天生偏向确认，不擅长拆台。
>
> 本轮两个灵感正好从两侧夹住这个缺口：
> - **论文创新点**提示：一个创新点不是名词清单，而是一个**可被实验杀死的命题**。没有证伪器的「我们提出了 X」不应获得任何信用；未结算的主张应当记成**债务**，而不是成绩。
> - **机械臂抓取**提示：抓取是物理世界最诚实的证伪器。抓得稳不稳不靠声明，靠**鲁棒力封闭**在扰动集下是否成立；物体一滑，命题立刻被物理反驳。而 LP 对偶天然给出二选一：要么是稳定性见证，要么是一个具体的反例扳手。
>
> 核心命题：**把「创新点」与「抓取」统一成同一类对象——带证书的可证伪主张；用接触模式流策略生成抓取，用鲁棒力封闭半径做见证，用主动证伪（VoF）而不是主动求证（VoI）去拆台，用哈希证据账本结算「主张—证据—债务」；只有在主张被结算为 discharged 时才允许放宽到 R69 的效率档，否则逐级退避且安全侧永不弱于 FLUID-RAS。** 命名 **GRAIL**（Grasp Risk-aware Assertion & Innovation Ledger，「抓取即证明」）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底证明了什么，以及这个证明能不能被现实推翻**」——**论文的创新点，应当像抓取一样，由物理/实验来结算，而不是由作者来申报。**

## 0. 直觉与动机

**灵感 1（论文创新点 → 创新点是一个可证伪契约）**
直觉：多数论文的创新点写成「我们提出了 A，结合了 B，提升了 C」。这是一份**库存清单**，不是贡献。真正的贡献必须回答：哪个实验会让它失败？失败长什么样？需要多大预算才能找到反例？把这些写清楚，创新点才从一个形容词变成一个可结算的对象。形式化后，一个创新点是一个契约 ICC =（主张 c，见证 W，证伪器族 ℱ，预算 b，依赖 Dep）。没有 ℱ 的条目直接拒编译；未结算的条目信用为 0 并记为债务。更进一步，**证据本身也会通胀**：同一仿真器的多个 seed、同一相机的多个视角、同一力传感器的多次读数，如果彼此相关，就不该被当成多个独立证据。所以还要定义**有效独立证据数 k_eff**。

**灵感 2（机械臂抓取 → 抓稳本身就是一条可证伪命题）**
直觉：抓取是「接触、摩擦、力封闭、模式切换」的混合系统。说「这个抓取是稳的」，等价于说：在一个明确的扰动集 𝒲 和一组摩擦系数范围 Θ_α 内，总存在落在摩擦锥里的接触力，使物体不被推走。这不是口号，是一个 LP 可行性问题。把它的解写成**鲁棒力封闭半径 ρ**：ρ 越大，抓取越稳。**LP 对偶给出一个漂亮的性质**——原始可行时，对偶变量是稳定性见证；原始不可行时，对偶给出一个分离扳手 w*，那是一个具体的、可施加的反例。于是「抓稳」永远不可能是一句不可检验的形容词：它要么带见证，要么带反例。

**灵感 3（二者同构 → 抓取即证明；论文创新点即抓取）**
直觉：论文创新点和机械臂抓取在结构上是同一件事——都是「在对抗集下能不能抓住」。
- 抓取抓住的是物体，对抗集是扰动 wrench、摩擦误差、质心偏移；
- 创新点抓住的是科学主张，对抗集是消融、红队、分布外、安全压力测试、以及「换成一个诚实但普通的基线」。
因此可以共用一套协议：主张登记 → 生成见证 → 主动找反例 → 账本结算 → 未结算则退避。**「论文创新点」不再是写作阶段的修辞，而是运行时可结算的系统输出。**

**灵感 4（R69 的升级 → 从 VoI 的「求证」到 VoF 的「拆台」）**
直觉：R69 的 MINT 用 VoI 选择信息动作，目标是让后验熵最小。这在模型正确时是对的；但在模型可能错、回答可能被投毒时，VoI 会稳定地把系统推向**自己最想相信的假设**——它优化的是「确定性」，不是「正确性」。R70 增加**证伪价值 VoF**：选一个动作，使「如果当前主张是假的，这次实验能把它打掉」的概率最大。抓取里的对应动作不是「轻轻抬一下确认抓到了」，而是「侧向轻推、单指卸载、短距离滑动、换抓点」——主动去拆自己的台。两者不互相替代：VoI 负责消歧，VoF 负责防止**自信地错**。

**灵感 5（风险 → 账本可以被选择性设计）**
直觉：一旦「创新点」可以被账本结算，就出现了新的攻击面：**把红队设计得弱一点、把扰动集设得小一点、把证伪器选得偏一点，任何模块都能还清债务并拿到漂亮证书**。抓取证书同理：如果 𝒲 只包含很小的扰动，ρ 当然漂亮，但真实世界的最坏扰动根本不在集合里。于是最大的危险不是「主张不成立」，而是**用一份自洽但封闭的账本，证明了错误的东西，并盖上「已结算」的章**。所以本轮必须同时交付：证伪器覆盖度、预注册、外部红队、k_eff 独立性、以及「框架自身也是一个 ICC」的自审计。

## 1. 形式化定义（增量：定义 310–330）

**定义 310（GRAIL 总览）** GRAIL = (ICC, NDA, CMD, CMFP, RGC, GEM, VoF, RTF, CSG, SAL, RAS-WM‡)。四不变式：
(i) **实时控制流零学习写操作**（继承 R68 定义 276-i）；
(ii) **无证据不主张**：任何 IP / 创新点必须先登记为 ICC，未结算的 ICC 一律计入债务，不得进入「已贡献」；
(iii) **证伪不对称**：见证弱于证伪器；默认先跑证伪器；claim 的信用被证伪器覆盖度封顶；
(iv) **安全继承**：所有新动作（含探索性抓取 / 证伪动作）必须通过 C-RAS-WM 与 R69 的交互预算；在无接触模式、无证伪预算时，GRAIL 逐指令退化为 FLUID-RAS。

**定义 311（创新点契约 ICC）** ICC_i = (c_i, W_i, ℱ_i, b_i, Dep_i)。c_i 是可判定的命题（有真值、可观测）；W_i 是见证谓词（在证据账本上可检验）；ℱ_i = {f_j} 是证伪器族，每个 f_j 是可执行实验，输出「拒绝 / 不拒绝 c_i」；b_i 是证伪预算（时间 / 物理试验次数 / 成本）；Dep_i ⊆ {ICC} 是依赖。三值结算：
Discharged_i ⇔ (∃ 证据满足 W_i) ∧ (∀ f_j ∈ ℱ_i 在 b_i 内均未拒绝 c_i)；
Refuted_i ⇔ ∃ f_j 在 b_i 内拒绝 c_i；
其余为 Unresolved_i。**Unresolved ≠ Discharged**，且 Unresolved 是合法且诚实的输出。

**定义 312（新颖性债务与净创新）** 对 ICC_i：
- 信用 credit_i = v_i · min(1, cov_i / cov*) · 1[Discharged_i]，v_i 为声明的价值权重，cov_i 为其证伪器覆盖度；
- 债务 debt_i = b_i · 1[¬Discharged_i]（预算已花但未结算仍记债务）；
- 净创新 N_net = Σ_i credit_i − λ_d Σ_i debt_i − λ_p Σ_{(i,j)∈Dep} w_ij · debt_j。
**未结算的上游依赖会把债务传播到下游。** 「新增一个未证明的模块」至多增加声明的 v_i，但立刻增加 debt_i，且 credit_i = 0，所以 N_net 不增（定理 20）。

**定义 313（证伪力与覆盖度）** 对证伪器 f 与主张 c，证伪力 Pf(f, c) = D_KL(P(·|c) ‖ P(·|¬c))（实际用可分性/分类器 AUC 作可计算代理）。对失败模式集合 ℳ，覆盖度 cov(ℱ) = Σ_{m∈ℳ} p_m · 1[∃f ∈ ℱ covers m] / Σ_{m∈ℳ} p_m。**Pf = 0 的命题信用恒为 0**。这条定义把「论文创新点」从修辞变成可计算量：能不能被证伪，以及被多强地证伪。

**定义 314（接触模式空间）** 抓取是混合系统，接触模式 m_t ∈ ℳ_c = {approach, make, squeeze, lift, transport, slip, drop, regrasp}；模式转移由 guard 谓词 g_{m→m'}(x) 控制。接触模式序列 μ = (m_0, …, m_H) 称为**可行**，若相邻 guard 在参数置信集 Θ_α 内可满足。

**定义 315（接触模式流策略 CMFP）** 连续动作块 x_1 = ξ_{t:t+H}，模式序列 μ 是离散 token。速度场 v_θ(x_s, s | o, μ)，模式先验 p_φ(μ | o)。采样：μ ~ p_φ，再由 v_θ(·|μ) 生成连续轨迹；模式转移处用 guard 投影到非穿透 / 摩擦锥。目标 L_CMFP = L_FM + λ_mode·CE(p_φ(μ|o), μ*) + λ_guard·L_guard。这是 R69 定义 295 在混合接触系统上的扩展。

**定义 316（接触不确定性三分）** U_ale = Σ_μ p(μ) tr Σ_μ（模式内连续噪声，不可约）；U_mode = H(p(μ|o))（离散模式身份歧义，可被消歧）；U_par = H(p(θ_par | 𝒟))（摩擦 / CoM / 刚度等连续物理参数的后验熵，可被辨识但可能不可辨识）。三者分通道：U_ale → 保守；U_mode → R69 的 VoI 主动消歧；U_par → 主动证伪 + 鲁棒膨胀。**不做简单加和。**

**定义 317（鲁棒抓取证书 RGC / 抓取见证）** 接触点 p_i、法向 n_i、摩擦系数 μ_i ∈ [μ_i^lo, μ_i^hi]，外部扰动 wrench 集 𝒲。**鲁棒力封闭半径**
ρ = max{ r : ∀w, ‖w‖ ≤ r, ∃f_i ∈ FC(μ_i) s.t. Σ G_i f_i = −w，且接触力 / 力矩余量 ≥ ε }。
若 ρ ≥ ρ_req，则抓取被 ε-认证。见证 W = (ρ, μ, Θ_α, 对偶变量 λ)。**证书—反例对偶**：LP 原始可行 ⇒ 对偶给出 margin 见证；原始不可行 ⇒ 对偶给出分离扳手 w*（反例）。因此每次「抓稳」主张要么带稳定性见证，要么带物理反例，不存在不可检验的第三种状态。

**定义 318（抓取主张）** 一个抓取主张 c 是「在 Θ_α 与 𝒲_req 下，接触模式序列 μ 的鲁棒力封闭半径 ρ ≥ ρ_req」。其 ICC 的 W 即 RGC；ℱ 包括：增大摩擦扰动、偏移 CoM、接触几何误差、注入传感器偏置、横向轻推、单指卸载、抓取中途扰动、真实 / 仿真差。

**定义 319（证据台账 GEM）** 只追加、哈希链式账本 L = {(e_k, hash_{k−1}, source, calib, indep_tag, ts)}。每条证据携带 provenance（sim / real / human / tactile / vision / F-T）与校准状态。ICC 的 W 只能引用账本中的证据，**禁止口头 witness**。

**定义 320（证据独立性与有效证据数）** 设证据源相关矩阵 R，有效独立证据数 k_eff = 1ᵀR⁻¹1（或 1/平均相关系数）。一个 claim 需 k_eff ≥ k_req 才可结算。**同一仿真器的多个 seed、同一相机的多个视角、同一 F-T 传感器的多次读数，若相关 ρ > ρ_0，均不得计为独立源。** 这防止「证据通胀」，与定义 312 的「创新点通胀」是同一枚硬币的两面。

**定义 321（证伪价值 VoF）** 对候选证伪动作 g：
VoF(g) = P(falsify(c) | g, o) · L_false(c) − c_safety(g) − c_time(g) − λ_ind·(1 − Δk_eff(g)/k_req)。
选 g* = argmax VoF(g)，s.t. CSG(g) 与预算。总目标 = VoI（消歧）+ λ_F·VoF（拆台）。**若 max VoF ≤ 0：不证伪，但也绝不得把 claim 记为 Discharged；只能记为 Unresolved 并走保守。**

**定义 322（证伪动作空间）** 在 R69 的 (g_gaze, g_probe, g_ask) 上新增 g_test ∈ 𝒜_test：小幅抬升、侧向轻推、旋转、单指卸载、轻拍、表面滑动、换抓点、短暂松力。𝒜_test 的每个动作都必须通过 CSG 与 R69 交互预算；**证伪动作不得以「为了测试」为由越过安全包络**。

**定义 323（序贯证书获取与停止规则）** 用 SPRT 式检验：每步更新对数似然比 Λ_k = Σ_t log[P(y_t | c) / P(y_t | ¬c)]。接受边界 A(α, β) 与拒绝边界 B(α, β) 由错误结算率 α 与漏证伪率 β 给定；|Λ_k| 未越界且预算耗尽 ⇒ Unresolved。**任何单次证伪动作不得单独结案**（继承 R69 证据纪律），需 k_eff ≥ k_req 或 Λ 越界。

**定义 324（红队证伪器族 RTF）** ℱ_red = {摩擦锥扰动, 质量 / CoM 偏移, 接触几何误差, 传感偏置, 执行器延迟, 触觉欺骗, 抓取中途扰动, 分布外物体}。每个 f 带一个「最坏扰动生成器」，目标是让 RGC 失效。覆盖度按定义 313 计算；未覆盖的模式记为**开放失败模式**，并按比例冻结 claim 的信用。

**定义 325（接触安全治理 CSG）** 继承 R69 定义 302 与 C-RAS-WM：接触力 ≤ f_max、法向速度非穿透、关节力矩 / 速度限、自碰撞、抓取中的物体不得越出安全包络；模式切换必须满足 guard 且不产生超过 ε_jump 的指令突变。证伪动作若不能同时满足 CSG，一律作废。

**定义 326（证书 J_GRAIL）** J_GRAIL = (J_FLUID, ICC_discharge_vector, ρ_vector, Θ_α, cov(ℱ), k_eff_vector, debt_ledger_hash, redteam_log_hash, sal_ver, grail_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有进入执行的抓取主张已 Discharged ∨ 显式 Unresolved 且已走保守退避 ∧ CSG 全程成立 ∧ 债务账本哈希一致。

**定义 327（仿真到现实的见证迁移）** 一个在 sim 中 Discharged 的 ICC，若要在 real 中复用，必须满足**见证迁移条件 WT**：ρ_real ≥ ρ_req − Δ_transfer(Θ_α, gap)，且 Θ_α 在 real 证据下重新校准；否则该 claim 在 real 中仍为 Unresolved。**仿真通过不是通行证，只是先验。**

**定义 328（三级退避与 R69 严格继承）**
- **L1（Discharged 且证伪器全过）**：λ = λ_floor(U_ale)（R69 的 resolution bonus）；
- **L2（Unresolved / 预算不足 / 证据独立性不足）**：λ = λ_floor(U_ale + U_mode + robust_inflate(U_par, Θ_α))；
- **L3（Refuted / 红队成功 / CSG 失败 / 账本被篡改）**：λ = λ_floor(U_ale + U_mode + U_par + drift_bound)，并缩回 R68 最保守，禁止执行该抓取主张。
λ 单调不降，安全侧永不弱于 R69。

**定义 329（债务传播 DAG）** Dep 构成有向无环图。若 ICC_j 依赖 ICC_i 且 i 未结算，则 j 的最大可结算信用 ≤ (1 − δ_prop)·credit_j，且 j 继承 i 的债务哈希。拓扑排序后可线性结算总债务。**「下游创新点靠上游未证结论支撑」会显式反映为净创新下降。**

**定义 330（自审计 SAL / 本框架自身是一个 ICC）** GRAIL 自身的主主张 c_G =「在 E301–E316 的证伪器覆盖下，GRAIL 的净创新 > 强基线，且安全违规不比 FLUID-RAS 多」。其 W 是 E301–E316 的可复现实验账本；ℱ_G 包含消融、红队、分布外、安全压力测试，以及「把 GRAIL 的组件替换成一个诚实但普通的抓取基线」。**论文的创新点由账本结算，而不是由作者申报**；若自审计失败，框架应在证书中把自己标为 Unresolved。

# IP-264 ICC Compiler：把每个创新点编译成可证伪契约
@dataclass
class ICC:
    c: Claim; W: WitnessPred; F: list[Falsifier]
    b: Budget; Dep: list[str]; v: float

def compile_icc(claim, witness, falsifiers, budget, deps, value):
    assert falsifiers and all(f.executable for f in falsifiers)  # 不可证伪 => 拒编译
    return ICC(claim, witness, falsifiers, budget, deps, value)

# IP-265 NDA：净创新结算（未结算债务沿依赖 DAG 传播）
def settle(ledger, iccs):
    credit = {i: iccs[i].v * min(1, ledger.cov(i)/COV_STAR)   # 覆盖度封顶
                 * (1.0 if ledger.discharged(i) else 0.0) for i in iccs}
    debt   = {i: iccs[i].b if not ledger.discharged(i) else 0.0 for i in iccs}
    for i in topo(iccs):                       # 上游先结算
        for j in iccs[i].Dep:
            if not ledger.discharged(j):
                credit[i] *= (1 - PROP); debt[i] += PROP * debt[j]
    return sum(credit.values()) - LAM_D * sum(debt.values())

# IP-267 CMFP：接触模式流策略（模式 token + 连续速度场）
class ContactModeFlowPolicy:
    def sample(self, o, K):
        mu = sample_modes(self.mode_head(o), K)              # 模式先验 + 聚类
        xs = randn(K, D)
        for i in range(self.N_step):
            xs = xs + (1.0/self.N_step) * self.v(xs, i/self.N_step, o, mu)
        return [self.guard_project(self.decode(x), m) for x, m in zip(xs, mu)]

def grasp_certificate(contacts, Theta_alpha, W_req):

    for _ in range(BISECT):
        r = 0.5*(lo+hi)
        ok, dual = lp_robust_closure(contacts, Theta_alpha, ball(r))
        lo, hi = (r, hi) if ok else (lo, r)
    ok, dual = lp_robust_closure(contacts, Theta_alpha, ball(lo))
    if ok and lo >= RHO_REQ:
        return lo, "witness", dual            # 对偶 = 稳定性见证
    return lo, "counterexample", dual         # 对偶 = 分离扳手 w*

# IP-270 VoF：主动寻找能拆掉当前主张的实验
def choose_falsifier(c, o, budget, ledger):
    best = None
    for g in falsifier_candidates(c, o):      # 抬升/轻推/卸载/滑动/换抓点
        if not csg.certify(g, o) or not budget.allow(g): continue
        p_f = falsify_prob(c, g, o)
        score = p_f * c.loss - cost(g) - LAM_I*(1 - ledger.dk_eff(g)/K_REQ)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 无利可图 -> 不测 -> unresolved

# IP-276 GRAIL 主闭环（继承 R69，仅在「主张结算」处插入 GRAIL 层）

## 3. 推导

**引理 19（不可证伪即零信用）** 若 ICC 的证伪器族为空或所有 Pf(f, c) = 0，则由定义 311/313，cov = 0 且 Discharged 不可达，故 credit = 0、debt = b > 0。系：**论文创新点清单里凡无对应证伪器的条目，净贡献为 0；「我们提出了 X」不构成创新点。**

**引理 20（抓取证书的可靠性）** 设 Θ_α 为摩擦 / CoM 的 (1−α) 置信集，RGC 在 Θ_α × 𝒲_req 上鲁棒可行。则真实参数落在 Θ_α 外、或抓取在 𝒲_req 内失效的概率 ≤ α + ε_num + ε_model。证明：以置信集覆盖事件为条件，力封闭可行性由 LP 对偶保证；失效只能来自覆盖失败（≤ α）或数值 / 未建模项。系：**证书的保守性就是 Θ_α 的大小**；辨识越充分 ρ 越接近真实，但永远不会把 α 变成 0。

**引理 21（VoF 在模型误设下优于 VoI）** 设模型误设使 P_model(c) 与 P_true(c) 的 KL 为 δ。纯 VoI 选择后验熵最小的实验，在 δ > 0 时可能把证据引向错误假设；VoF 选择使「若 c 假则拒绝概率」最大的实验。二元假设下，E[false-accept | VoF] ≤ E[false-accept | VoI] − c·δ + O(δ²)。直观：**VoI 优化确定性，VoF 优化可错性**；前者在错误模型上把自信越推越高，后者把反驳机会当作目标。系：R69 的最大风险（模态分布不可信 → 自信地问错）被 VoF 部分对冲，但**不能被完全消除**——因为证伪器也来自同一个可能错的模型。

**引理 22（债务传播与净创新的单调性）** 若 Dep 为 DAG，且 ICC_j 依赖未结算的 ICC_i，则 j 的可结算信用 ≤ (1−δ_prop)·credit_j，总债务按拓扑序可加；因此**新增一个未结算 ICC 不可能提高 N_net**（其 credit = 0，debt > 0，且可能通过 Dep 抬高下游债务）。证明：代入定义 312/329，各项非负。系：这是「论文创新点通胀」的数学刹车——**堆模块不能刷分**。

**定理 18（GRAIL 严格继承 FLUID-RAS）** 在无接触模式（ℳ_c 单点）、无证伪预算（b_i = 0）、无新证据时，GRAIL 退化为 FLUID-RAS：定义 328 的 L1/L2 与 R69 定义 307 逐指令一致；安全侧 λ 单调不降。故 R69、进而 R68，均为 GRAIL 的边界特例。

**定理 19（抓取安全与模式切换无突变）** 若接触模式序列 μ 的每个 guard 在 Θ_α 上可满足，且 CSG 认证通过，则模式切换产生的指令跳变 ≤ ε_jump，接触力 / 速度不越包络；证伪动作同理。证明：guard 投影 + C-RAS-WM 前缀认证 + 力 / 速限的单调性。系：**探索性抓取不会把「为了测试」变成「为了违规」**。

**定理 20（无免费创新 / No Free Novelty）** 对任意 ICC 集合 S 与未结算模块 i，N_net(S ∪ {i}) ≤ N_net(S)；仅当 i 已 Discharged 且 cov_i ≥ cov* 时 N_net 才可增。证明：引理 22。系：**论文的每个创新点必须带着它的证伪实验一起来；否则它只是债务。**

## 6. 本轮最大风险

**一句话**：GRAIL 把「创新点」变成可结算的债务账本，但**证伪器覆盖度本身是一个可以被作者 / 系统选择性设计的自由参数**——把红队设弱一点、把扰动集设小一点、把证伪器选偏一点，任何模块都能「还清债务」并拿到漂亮证书；于是最大的风险不是创新点不成立，而是**用一份自洽但封闭的账本，证明了错误的东西，并盖上「已结算」的章**。

**次级风险与缓解**：
1. **真空证书**（𝒲 / Θ_α 太小，ρ 漂亮但无意义）→ 外部红队 + 覆盖度上界 + E305/E309；
2. **证伪器 gaming / 选择性报告**→ 预注册证伪器 + 哈希链不可改 + 第三方重放 + E302/E316；
3. **接触模式爆炸与实时性** → 模式抽象 + K 门控 + 定理 19 + E312；
4. **主动证伪动作本身危险** → CSG + 定理 19 + R69 交互预算 + E315；
5. **自审计循环（GRAIL 证明 GRAIL）** → 外部基线 + 预注册 + 第三方重放 + 定义 330；
6. **仿真证据被当成通行证** → 定义 327 见证迁移 + E310；仿真只作先验，不作结算。

**本轮结论一句话**：**可审计的假象，比不可审计的诚实更危险——如果证伪器覆盖度不被独立审计，GRAIL 越自洽，它就越可能自信地证明一个错误的世界。**

**定义 319–320（GEM / k_eff）** 证据账本 = 只追加哈希链 + provenance + 校准状态 + 独立性标签；有效独立证据数 k_eff = 1ᵀR⁻¹1，相关证据（同仿真器多 seed、同相机多视角、同 F-T 多次读数）不得计为独立源；k_eff ≥ k_req 才可结算。

**定义 321–323（VoF / 证伪动作 / SPRT）** VoF(g) = P(falsify(c)|g,o)·L_false − c_safety − c_time − λ_ind(1−Δk_eff/k_req)；𝒜_test = {抬升, 轻推, 旋转, 单指卸载, 轻拍, 滑动, 换抓点, 松力}，全部过 CSG；SPRT 对数似然比 Λ_k 越界才结案，预算耗尽 ⇒ Unresolved，单次证伪不得单独结案。

**定义 324–326（RTF / CSG / J_GRAIL）** ℱ_red 含摩擦锥扰动、CoM 偏移、几何误差、传感偏置、执行器延迟、触觉欺骗、中途扰动、OOD 物体，未覆盖模式登记为开放失败模式并冻结信用；CSG 约束接触力 / 非穿透 / 力矩 / 自碰撞 / 模式切换跳变 ≤ ε_jump；J_GRAIL 并入 ICC 结算向量、ρ、Θ_α、覆盖度、k_eff、债务哈希。

**定义 327–330（见证迁移 / 三级退避 / 债务 DAG / 自审计）** sim 证据只是先验，real 需满足 ρ_real ≥ ρ_req − Δ_transfer 且重校 Θ_α；L1（Discharged）λ = λ_floor(U_ale)，L2（Unresolved）λ = λ_floor(U_ale + U_mode + robust_inflate(U_par, Θ_α))，L3（Refuted / 红队成功 / 账本篡改）λ = λ_floor(U_ale + U_mode + U_par + drift_bound) 且缩回 R68；Dep 为 DAG，未结算依赖按 δ_prop 传播；GRAIL 自身是 ICC，自审计失败即自标 Unresolved。

# IP-264 ICC Compiler
def compile_icc(claim, witness, falsifiers, budget, deps, value):
    assert falsifiers and all(f.executable for f in falsifiers)   # 不可证伪 => 拒编译
    return ICC(claim, witness, falsifiers, budget, deps, value)

# IP-265 NDA：净创新结算（债务沿 DAG 传播）
def settle(ledger, iccs):
    credit = {i: iccs[i].v * min(1, ledger.cov(i)/COV_STAR)
                 * (1.0 if ledger.discharged(i) else 0.0) for i in iccs}
    debt   = {i: iccs[i].b if not ledger.discharged(i) else 0.0 for i in iccs}
    for i in topo(iccs):
        for j in iccs[i].Dep:
            if not ledger.discharged(j):
                credit[i] *= (1 - PROP); debt[i] += PROP * debt[j]
    return sum(credit.values()) - LAM_D * sum(debt.values())

# IP-267 CMFP：接触模式流策略
def cmfp_sample(policy, o, K):
    mu = sample_modes(policy.mode_head(o), K)
    xs = randn(K, D)
    for i in range(policy.N_step):
        xs = xs + (1.0/policy.N_step) * policy.v(xs, i/policy.N_step, o, mu)
    return [policy.guard_project(policy.decode(x), m) for x, m in zip(xs, mu)]

# IP-268 RGC：鲁棒力封闭半径 + LP 对偶（见证 或 反例）
def grasp_certificate(contacts, Theta_alpha):
    lo, hi = 0.0, RHO_MAX
    for _ in range(BISECT):
        r = 0.5*(lo+hi)
        ok, _ = lp_robust_closure(contacts, Theta_alpha, ball(r))
        lo, hi = (r, hi) if ok else (lo, r)
    ok, dual = lp_robust_closure(contacts, Theta_alpha, ball(lo))
    return (lo, "witness", dual) if ok and lo >= RHO_REQ else (lo, "counterexample", dual)

# IP-270 VoF：主动寻找能拆掉当前主张的实验
def choose_falsifier(c, o, budget, ledger):
    best = None
    for g in falsifier_candidates(c, o):
        if not csg.certify(g, o) or not budget.allow(g): continue
        score = falsify_prob(c, g, o)*c.loss - cost(g) - LAM_I*(1 - ledger.dk_eff(g)/K_REQ)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None    # 无利可图 -> 不测 -> unresolved

# IP-276 GRAIL 主闭环（继承 R69）
def GRAIL_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    U_ale, U_mode, U_par, modes = M.cmd.decompose(cmfp_sample(M.cmfp, o, K))
    icc = M.gem.active_grasp_claim(o)
    g_info = M.mint.choose_interaction(modes, o, M.budget) if U_mode > TAU_MODE else None
    g_test = M.vof.choose_falsifier(icc, o, M.budget, M.gem)      # 新增：拆台
    if g_test is not None:
        M.gem.append(M.execute_safe(g_test), source='real', indep_tag=g_test.tag)
    state = M.gem.settle(icc)                                     # discharged/refuted/unresolved
    if state == 'discharged':   U_floor = U_ale
    elif state == 'unresolved': U_floor = U_ale + U_mode + robust_inflate(U_par, Theta_alpha)
    else:                       U_floor = U_ale + U_mode + U_par + DRIFT_BOUND
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if state != 'discharged':
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam

    return k, lam, state, (U_ale, U_mode, U_par)

## 4. 推导

**引理 19（不可证伪即零信用）** ℱ 为空或所有 Pf = 0 ⇒ cov = 0 且 Discharged 不可达 ⇒ credit = 0、debt = b > 0。系：**无证伪器的创新点净贡献为 0；「我们提出了 X」不是创新点。**

**引理 20（抓取证书可靠性）** 若 RGC 在 Θ_α × 𝒲_req 上鲁棒可行，则真实参数越出 Θ_α 或抓取在 𝒲_req 内失效的概率 ≤ α + ε_num + ε_model。证明：以置信集覆盖为条件，力封闭可行性由 LP 对偶保证；失效只来自覆盖失败或数值 / 未建模项。系：**证书的保守性就是 Θ_α 的大小；辨识不能把 α 变成 0。**

**引理 21（VoF 在误设下优于 VoI）** 模型误设 KL 为 δ 时，纯 VoI 可能把证据引向错误假设；VoF 选择「若 c 假则拒绝概率最大」的实验。二元假设下 E[false-accept | VoF] ≤ E[false-accept | VoI] − c·δ + O(δ²)。系：VoF 部分对冲 R69 的最大风险，但证伪器也来自同一可能错的模型，故不能完全消除。

**引理 22（债务传播与净创新单调性）** Dep 为 DAG 时，依赖未结算上游的 ICC 信用按 (1−δ_prop) 折减、债务按拓扑序可加；故新增未结算 ICC 不可能提高 N_net。系：**堆模块不能刷分。**

**定理 18（GRAIL 严格继承 FLUID-RAS）** 无接触模式、无证伪预算、无新证据时，GRAIL 的 L1/L2 与 R69 定义 307 逐指令一致，λ 单调不降；R69、R68 均为其边界特例。

**定理 19（抓取安全与模式切换无突变）** 每个 guard 在 Θ_α 可满足 + CSG 通过 ⇒ 模式切换指令跳变 ≤ ε_jump、接触力 / 速度不越包络；证伪动作同理。

**定理 20（无免费创新）** 对任意 ICC 集合 S 与未结算模块 i，N_net(S∪{i}) ≤ N_net(S)；仅当 i 已 Discharged 且 cov_i ≥ cov* 时 N_net 才可增。系：**每个创新点必须带着它的证伪实验一起来，否则它只是债务。**

## 8. 本轮最大风险

**一句话**：GRAIL 把「创新点」变成可结算的债务账本，但**证伪器覆盖度本身是一个可以被作者 / 系统选择性设计的自由参数**——把红队设弱一点、把扰动集设小一点、把证伪器选偏一点，任何模块都能「还清债务」并拿到漂亮证书；于是最大的风险不是创新点不成立，而是**用一份自洽但封闭的账本，证明了错误的东西，并盖上「已结算」的章**。

**次级风险与缓解**：真空证书（外部红队 + 覆盖度上界 + E305/E309）；证伪器 gaming（预注册 + 哈希链 + 第三方重放）；接触模式爆炸（模式抽象 + K 门控 + E312）；主动证伪动作越界（CSG + 定理 19 + E315）；自审计循环（外部基线 + 预注册 + 第三方重放）；仿真证据被当通行证（定义 327 + E310）。

**本轮结论一句话**：**可审计的假象，比不可审计的诚实更危险——如果证伪器覆盖度不被独立审计，GRAIL 越自洽，它就越可能自信地证明一个错误的世界。**
