# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「热管理」×「谐波减速器」）

> R69 把不确定性一分为二：**aleatoric 只收紧，epistemic 去「看/问/触」**。这套二分法默认了一件事——不确定性的来源在**外部世界或观测**，而执行动作的**身体本身是透明、时不变的**：指令到了关节，关节就忠实地执行；只有「世界是什么」需要求证，「我的身体能不能做到」不需要。对一台真正的人形机器人，这是最脆弱的一个隐含假设。
>
> 本轮两个灵感正好从身体内部拆掉它：
> - **谐波减速器**（以及任何高减速比传动）把「指令位置」和「输出位置」之间塞进一个**有记忆的迟滞算子**：回差、柔度、摩擦都依赖载荷历史。同样的指令，正向和反向行程的输出不同；这不是随机噪声，而是**机械的 epistemic 状态**——可辨识、可预载、可被证书约束，但不能被瞬时清空。
> - **热管理**把这个迟滞算子和一个**自加热的慢变量**耦合起来：迟滞环的面积就是每个循环耗散的热；温度又反过来改变润滑黏度、预紧、电阻与力矩常数。机器人**用自己的动作把自己加热**，从而改变自己未来动作的含义。热不是外部扰动，而是**由行动写出的隐状态**；更残酷的是，热有硬上限，超过就降额、退磁、停机——**能力本身是一种会被消耗、也会恢复的预算**。
>
> 核心命题：**把 R69 的两分法升级为三分法——aleatoric（摩擦/传感噪声，收紧）、epistemic（热-迟滞隐状态，用内部探询消解）、irreversible（磨损/热损伤，不可消解，只能不产生）。** 行为不再只问「世界是什么」，还要问「**我的身体现在是什么状态、这次动作会不可逆地花掉多少未来能力、我该不该先花时间把身体准备好**」。命名 **HEAT-RAS**（Hysteresis-Energy-Aware Thermal Risk-adaptive System：迟滞-能量感知的热风险自适应系统）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的身体还剩下多少、这一次动作会不会把它花掉、我该先把自己预热 / 预载 / 冷却到能可靠完成它的状态吗**」——不确定性不只在世界那边，也在关节里面；它既是一句提问，也可以是一次预载、一段冷却、一次有意的热身。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 传动是有记忆的，不是噪声）**
直觉：谐波减速器用波发生器把柔轮压成椭圆，靠齿的错位获得极高减速比，代价是柔轮弹性、齿面摩擦、以及不可避免的微小回差。它的输入-输出关系不是一条直线，而是一个**滞回环**：加载和卸载走不同的路径，换向时先要走完一段 lost motion。关键在于：**同样的指令，其含义取决于你之前对它做过什么**。这不是 aleatoric 噪声（不能靠平均消掉），而是一个**有记忆的隐状态**。好消息是，这个状态是**可观测的**：G1 这类关节有双编码器，输入侧和输出侧的差就是传动误差；不需要额外力矩传感器，也能从「指令位置-输出位置」的循环里重构出滞回环、回差宽度与柔度。R69 的外部交互（看/问/触）问不到这件事——只能由机器人**对自己**做一次受控的探询。

**灵感 2（热管理 → 热是自加热的慢变量，也是能力预算）**
直觉：关节的热来自三处：铜损 `i²R`、摩擦 `τ_f·ω`、以及滞回环面积 `∮τ dθ`。温度升高又反过来改变润滑黏度（摩擦与回差）、热膨胀（零位偏置）、磁钢强度（力矩常数）、以及绕组电阻（更高温度 → 更大铜损 → 更多热，正反馈）。于是热不是一个外部扰动，而是一个**由自己的动作写出的隐状态**：你越用力，越热；越热，越容易继续变热，同时能出的力越小。工业上「峰值力矩 / 连续力矩」往往差 2.5–3 倍；这个差额不是免费的午餐，而是**从热容里借来的贷款**。因此「能力」应当被当作一种**荷电状态（thermal state of charge）**：有上限、有充放电速率、有不可逆的过放损伤。

**灵感 3（三分法 → R68/R69 的 λ_floor 对第三类失效）**
直觉：R68/R69 的保守铁律只处理两类东西：不可约噪声（收紧）与可约歧义（去交互）。它们都默认不确定性是**已经存在、等待被发现**的。热-滞回引入第三类：**由自己的动作不可逆地产生、且无法通过任何观测消除**的东西——磨损、润滑氧化、磁钢退磁、柔轮疲劳。对它，「收紧」没有意义（已经发生了），「交互」也没有意义（问不回来）。唯一的处置是**预算与禁令**：在动作发生之前，估计它会花掉多少寿命，若超过剩余预算就拒绝，或要求人类授权。这是 R70 新增的一条安全轴：**机器人有权拒绝一个会把自己花掉的任务**。

**灵感 4（内部信息动作 → 探询自己，但探询要花热）**
直觉：R69 的信息动作 `g=(g_gaze,g_probe,g_ask)` 都是对外部的。HEAT-RAS 增加一组**内部信息动作**：`g_preload`（沿已知方向轻推、吃掉回差，把迟滞状态置到已知边界）、`g_chirp`（小幅多频激励，提升参数可辨识性）、`g_dwell`（零力矩等待，让热状态向已知环境松弛，同时降低热不确定性）、`g_warm`（低幅往复预热，避开冷启动标定失配）。它们与任务动作拼进同一个增广动作空间，用同一个安全前缀认证。这里有一个反直觉的张力：**探询自己会产生热，而热正是你要管理的东西**。所以内部探询不是免费的：它有一个由热惯性决定的时间窗——太早，信息会被后续状态漂移冲掉；太晚，探询产生的热来不及散掉就进入精密动作。**最便宜的信息源，可能是热上最贵的。**

**灵感 5（热-机械指纹 → 正面回应 R68/R69 的「标定吸收」风险）**
直觉：R68 最大的弱点是慢变故障可以被标定「解释掉」，R69 用动作似然做第二意见。但在身体内部，热膨胀看起来和一个慢变零偏几乎一样：标定层会把它吸收，残差 `r_res≈0`，系统以为自己很准。HEAT-RAS 的回应是**热-机械指纹**：`z0`（零位偏置）、`A_h`（滞回环面积）、`∂A_h/∂T`（环面积的温度斜率）、`ΔE_bal`（电功率 − 机械功 − 热增量的能量平衡残差）。一个**常数**传感器偏置不改变速度，也不改变机械功，因此 `z0` 变而能量账平；热膨胀是**时变**的，被位置标定吸收后会在能量账上留下 `τ·ḃ` 的残差；磨损让 `A_h` 单调变大；润滑退化让 `A_h` 和 `∂A_h/∂T` 同时变大。**能量平衡是位置标定吸收不了的一条独立通道**——这是 R69 FMA 在「身体内部」的镜像。

**灵感 6（严格包含 → 新层必须是旧层的边界退化）**
直觉：每加一层，就多一个需要独立信任的黑箱。HEAT-RAS 的理论姿态必须是：**R69 是它在「热恒定、迟滞已知、无磨损」边界上的逐指令退化**。热安全盾只会收缩可行集，磨损记账只会删除动作，内部探询只会改善估计、绝不扩大已认证的安全集。因此安全侧永不弱于 R69，效率侧只在「身体状态被证书化」时获得 resolution bonus。否则本轮就不是进步，而是给 R69 的保守主义装了一个会把自己烧坏的执行器。

**灵感 7（与 UniBot / G1 的落地约束）**
直觉：这条线不是抽象玩具。公开拆解对 G1 关节传动的说法并不完全一致：多数拆解称肩/肘/膝为「电机 + 两级行星减速 + 双编码器 + 驱动」的四合一模块，减速比约 15–20.58:1，QDD 方案效率高但**更容易过热**；也有论文按「BLDC + 谐波减速器」建模。因此本方案**不绑定具体传动类型**，而抽象为「高减速比传动 + 双编码器 + 局部风冷 + 热降额」。可核实的事实是：G1 为 23–43 自由度、约 35kg、关节双编码器、局部风冷，膝部峰值 90/120 N·m；拆解报告称高负载关节超过安全阈值会触发 **thermal derating / 限流**，膝部用 VC 均热板 + 铜带被动散热，腰部有主动风扇，主控 SoC 与 BMS 有 NTC；宇树 IM6014 关节电机规格写明驱动板 >90°C、绕组 >130°C 报过热关机，且其自研热管理模型以 400Hz 监测温度。更关键的是，UniBot-V1 的公开提交接口只发送 `observation.state.*` 的位置/末端位姿/夹爪开度、图像与语言，**没有电流、力矩、温度、深度**；动作是位置目标，且 `action_chunk_size` 步内开环执行。这意味着热状态和迟滞状态必须从「动作历史 + 指令-响应增益 + 位置残差」中估计，而不能假设有完美的力矩/温度传感器。具体替换是：`i` → 由逆动力学/观测器估出的 `τ̂`；`P_elec` → `P̂ = τ̂·ω + Q̂` 代理；`T_sensor` → 不可用，`T̂_h` 纯模型外推、UCB 更宽；降额还可由**指令-响应增益的下降**独立检出（同样的位置增量，输出速度/幅度变小）。这把「热不可观」从缺陷变成了一个新的观测量，也把严格退避（定理 18）从「理论洁癖」变成「部署必需」。（来源见产物区「落地与来源」，检索日期 2026-11-14。）

## 1. 形式化定义（增量：定义 310–324）

**定义 310（HEAT-RAS 总览）** HEAT-RAS = (THM, TUD, TSO, DER, IIP, UIV, TMF, HSC, WAC, AIC-HEAT, J-HEAT, RAS-WM†)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）与 R69 的交互预算（定义 293-ii）；
(ii) **热安全包络**：以热点温度的上置信界 `T̂_h^ucb` 计费，任何时刻 `T̂_h^ucb ≤ T_max − δ_T`；
(iii) **迟滞因果性**：任何精密动作不得依赖未被证书约束的迟滞状态；要么估计误差有界，要么先做预载/微激励；
(iv) **热-功守恒记账**：每个动作的产热与散热必须进账，不得凭空获得持续力矩；峰值力矩是从热容借来的贷款；
(v) **证据纪律**：热/迟滞结论需 ≥2 个正交证据源（双编码器、温度、电流/功率、能量平衡）一致，单源不定案。

**定义 311（热-迟滞关节模型 THM）** 关节输入角 `θ_m`、输出角 `θ_j`、减速比 `N`。传动误差 `e = θ_m/N − θ_j`。迟滞算子 `H` 带内部记忆 `h`：
`τ_t = N·[k(φ_T)·H(e; h) + b(φ_T)·ė] + τ_f(φ_T, ω) + τ_ext`
其中 `φ_T = (η_grease(T), preload(T), K_t(T), R(T))` 为温度依赖参数。产热
`Q̇ = τ_f·ω + (∮τ dθ)/T_cycle + i²R(T)`
（第一项为摩擦，第二项为滞回耗散）。热网络用多节点 RC：
`C_th Ṫ = Q̇ − (T − T_amb)/R_th`，
节点含绕组、齿面/柔轮、壳体；热点 `T_h` 通常不可直接测，只能由壳体温度、电流与热模型外推。

**定义 312（隐状态与可观测性）** 隐状态 `s = (h, T_h, w, φ_T)`（`w` 为磨损）。观测 `y = (θ_m, θ_j, T_sensor, i 或 P_elec)`；在只有位置接口的部署里，`i/P_elec` 退化为估计量 `(τ̂, P̂)`，另加两个纯位置观测量：**指令-响应增益** `g_r = Δθ_out/Δθ_cmd`（降额/饱和时下降）与**跟踪残差** `r_t = θ_cmd − θ_out`（迟滞/负载/接触的混合）。迟滞记忆 `h` 的可观测性依赖**持续激励**：近窗回归矩阵 `F_t = Σ_k φ_k φ_kᵀ`，参数估计误差下界 `≥ √(σ²·tr(F_t^{-1}))`。若近窗运动单向、慢速、无换向，`F_t` 近奇异，`h` 不可观，`U_epi^th` 增大。这条定义直接解释了「越慢越准」为何是错觉，也是内部探询的动机。

**定义 313（三元不确定性分解 TUD）**
- `U_ale^th`：摩擦、传感、未建模快动力学的不可约噪声 → 交给 `λ_floor` 收紧；
- `U_epi^th`：`(h, T_h, φ_T)` 的后验熵/协方差，可由内部信息动作或冷却/时间降低；
- `U_irr^th = D(w, T, cycles)`：已累积的磨损/润滑退化/热损伤，**单调不减**，不可由任何观测降低；只能通过「不产生」来保持。剩余预算 `B_dmg = D_max − U_irr^th`。
三者**语义不同、量纲不同、通道不同，不做简单加和**：`U_ale` 进 λ，`U_epi` 进探询，`U_irr` 进硬预算。

**定义 314（热荷电状态与热预算 TSoC）** `TSoC = clip((T_max − T̂_h^ucb)/(T_max − T_amb), 0, 1)`。动作 `ξ` 的预测产热 `Q(ξ)`。热成本
`c_th(ξ) = β·Q(ξ) + γ·1[predicted T_h > T_max] + ΔTVR(TSoC_loss(ξ))`，
其中 `TVR(ΔTSoC)` 为**热储备价值**：在给定任务分布下，保留 `ΔTSoC` 所能增加的期望未来任务价值。这把热从「约束」变成「价格」：不是不能热，而是要把未来的能力折现进来。

**定义 315（温度依赖降额与热安全包络 DER）** 以 I²R 为主的近似降额：
`τ_max(T) = τ_peak·√(clip((T_max − T)/(T_max − T_amb), 0, 1))`；
更精确时直接用厂商 derating 曲线。连续力矩 `τ_cont(T)` 由热平衡 `Q(τ) = (T − T_amb)/R_th` 解出。安全包络要求 `τ_cmd ≤ τ_max(T̂_h^ucb)`。降额是单调的：`T` 升 → 可行力矩集收缩。

**定义 316（内部信息动作 IIP）** `g_int ∈ 𝒜_int`，至少四类：
- `g_preload`：沿已知方向轻推、吃掉回差，把 `h` 置到已知边界（带力矩上限与位移上限）；
- `g_chirp`：小幅多频激励，提升 `F_t` 的秩，辨识迟滞/摩擦参数；
- `g_dwell`：零力矩等待，让 `T` 向已知环境松弛（同时降低 `U_epi^th`、提升 `TSoC`）；
- `g_warm`：低幅往复预热，把关节带到稳定温度桶，避免冷启动标定失配。
每个 `g_int` 有热成本、时间成本，并且必须通过与任务动作相同的 C-RAS-WM 前缀认证。增广动作 `ξ = (a, g_ext, g_int)`。

**定义 317（统一信息价值 UIV）** 对外部信息动作 `g_ext`（R69 的看/问/触）与内部信息动作 `g_int` 用同一种货币比较：
`VoI_total(g) = E[L(s, m) − L(s', m')] − c_time(g) − c_th(g) − c_social(g)`
其中 `L` 为任务损失，`s'` 为执行 `g` 后的状态估计。选择 `g* = argmax VoI_total`，受安全、交互预算与热预算约束。**R69 的 VoI 是 `c_th ≡ 0` 且 `𝒜_int = ∅` 的特例。** 由此得到一个反直觉结论：冷的时候应优先探询/预热（热成本低、信息价值高），热的时候应少探询、多计算、甚至先冷却——**信息策略必须随热状态切换**。

**定义 318（热-机械指纹 TMF）** 特征向量
`z = (z0, A_h, ∂A_h/∂T, ΔE_bal)`，
其中 `z0` 为双编码器零位偏置，`A_h = ∮τ dθ` 为滞回环面积（由双编码器与力矩估计 `τ̂` 重构），`∂A_h/∂T` 为环面积温度斜率，`ΔE_bal = P̂ − P_mech − Q̂ − dU/dt` 为**能量平衡代理残差**（有电功率/电流时用实测，只有位置接口时用 `τ̂·ω` 与热模型代理；误差界相应放宽）。判决规则（≥2 特征一致才定案）：
- 标定吸收的**常数**传感器偏置 ⇒ `z0` 变，`A_h` 不变，`ΔE_bal≈0`（常数偏移不影响速度/机械功）；
- 热膨胀（**时变**零偏）⇒ `z0` 随 `T` 变，`A_h` 不变，`ΔE_bal` 因 `τ·ḃ` 项而升高；
- 磨损 ⇒ `A_h` 单调增大、`z0` 慢漂；
- 润滑退化 ⇒ `A_h` 与 `∂A_h/∂T` 同时增大；
- **缓变故障被位置标定吸收 ⇒ `z0` 被抹平而 `ΔE_bal` 保留**。
这是 R69 FMA（动作似然）在身体内部的物理镜像，且比似然更硬：能量不会说谎。

**定义 319（热安全盾 HSC）** 给定计划 `ξ`，预测热点上界 `T̂_h^ucb(t)`。HSC 把计划投影到**最大热可行前缀**：
`∀t: T̂_h^ucb(t) ≤ T_max − δ_T` 且 `τ(t) ≤ τ_max(T̂_h^ucb(t))`。
若前缀为空：执行 `g_dwell` 冷却，或安全停。HSC 的自由力矩集随 `U_epi^th` 增大而单调收缩（使用 UCB 的保守端）。

**定义 320（不可逆损伤记账 WAC）** 损伤按 Miner 规则 + Arrhenius 温度加速累积：
`Ḋ = Σ_i 1/L_i(τ_i, T_i)`，
其中 `L_i` 为对应失效模式（柔轮疲劳、齿面磨损、润滑氧化、磁钢退磁）的寿命。剩余预算 `B_dmg = D_max − D`。任何动作若 `E[ΔD] > B_dmg` 被硬禁止；接近上限时要求人类授权或任务重规划。WAC 是 R70 新增的**不可逆安全轴**：宁可拒绝任务，也不把身体花掉。

**定义 321（冷启动与热校准调度）** 冷机参数 `φ_T(25°C)` 与热机 `φ_T(80°C)` 不同；标定必须在热状态索引下进行。为每个温度桶 `T_bucket` 维护一份参数证书 `J_cal(T_bucket)`；跨桶使用需插值，并把插值误差计入 `U_epi^th`。冷启动后先执行 `g_warm` 到稳定桶，再执行精密任务。**「冷标定热使用」被禁止**，除非误差界覆盖温漂。

**定义 322（热-迟滞证书 J_HEAT）** `J_HEAT = (J_FLUID, TSoC, T̂_h^ucb, h_err_bound, A_h, ∂A_h/∂T, ΔE_bal, B_dmg_left, g_int_log_hash, derate_status, heat_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ HSC 通过 ∧ WAC 预算未越界 ∧ 热/迟滞结论满足 ≥2 正交证据 ∧ 冷/热校准桶匹配。

**定义 323（热-机械威胁模型 ℰ_thermal）** 环境热（阳光、暖风、冷库）、传感器热滞后与安装误差、负载诱导的假温升、**主动热攻击**（在关键任务前强迫高负载，耗尽热预算——thermal denial of service）、**迟滞历史投毒**（从特定方向接近使回差最大）、以及**标定吸收型缓变故障**（把热膨胀/磨损误当零偏）。`ℰ_HEAT = ℰ_FLUID × ℰ_thermal`。

**定义 324（两级退避与严格包含）** 若热-迟滞不确定性在预算内被消解（`U_epi^th < τ_epi` 且 TMF 通过）：使用证书化的 `λ` 与 `τ`（resolution bonus，比纯保守更不保守但不低于 R69 安全）；若未消解/超时/被投毒/WAC 越界/TMF 冲突：退化为 R69 的纯保守（外部交互 + `λ_floor`），并叠加 HSC 的最坏热包络与 WAC 禁令。⇒ 当 `T` 恒定、`h` 已知、无磨损时，HEAT-RAS 逐指令等于 R69；安全侧只收紧（可行集单调收缩），效率侧只在「身体状态被认证」时放松。

class ThermoHystereticModel:
    def step(self, y, u, dt):
        self.h = self.hyst.update(y.theta_in, y.theta_out)      # 有记忆的迟滞
        q = copper_loss(u.i, self.T) + friction_loss(u.tau, y.omega) \
            + self.hyst.loop_dissipation()                      # 环面积=耗散热
        self.T = self.thermal_rc.step(q, dt)                    # 热点外推
        self.wear = self.wear_model.step(u.tau, self.T, dt)
        return self.h, self.T, self.wear

# IP-265 TUD：三分不确定性
def decompose_th(model, fisher):
    U_ale = model.ale_floor
    U_epi = trace(model.posterior_cov) * fisher_rank_factor(fisher)
    U_irr = model.accumulated_damage
    return U_ale, U_epi, U_irr, model.D_max - U_irr

# IP-266/267 TSO+DER：热点 UCB 与降额包络
def thermal_envelope(model, delta_T=4.0):
    T_ucb = model.T_mean + 3.0 * model.T_std
    frac  = clip((T_MAX - delta_T - T_ucb) / (T_MAX - T_AMB), 0.0, 1.0)
    return T_ucb, TAU_PEAK * sqrt(frac)

# IP-268/269 IIP+UIV：内部探询与统一信息价值
def choose_internal_action(modes, model, budget):
    best = None
    for g in [preload(), chirp(), dwell(), warm()]:
        if not budget.allow(g) or not c_ras_wm.certify(g): continue
        voi = expected_loss_drop(g) - time_cost(g) - thermal_cost(g, model)
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None   # 无利可图 → 不探询

# IP-270 TMF：热-机械指纹（位置标定吸收不了能量账）
def fingerprint(enc_in, enc_out, tau_hat, T, P_elec):
    z0    = mean(enc_in / N - enc_out)
    A_h   = loop_area(enc_in / N, enc_out, tau_hat)
    dA_dT = slope(A_h, T)
    dE    = energy_balance_residual(P_elec, tau_hat, enc_out, T)
    return z0, A_h, dA_dT, dE

# IP-274 主闭环（继承 R69，在不确定性处置与执行层插入 HEAT）
def HEAT_RAS_round(M, obs):

    U_ale, U_epi, U_irr, B_dmg = M.tud.decompose_th(M.thm, M.fisher)
    T_ucb, tau_max = M.der.thermal_envelope(M.thm)
    # 0) 不可逆安全轴先于一切
    if B_dmg < B_MIN: return M.safe_stop(reason="damage_budget")
    # 1) R69 外部闭环：看/问/触 + λ_floor
    k, lam, mode = M.fluid.step(obs)
    # 2) 只有精密动作才值得内部探询；且要算热价格
    if needs_precision(mode) and U_epi > TAU_EPI:
        g_int = M.uiv.choose_internal_action(mode, M.thm, M.budget)
        if g_int is not None: M.execute_certified(g_int)
    # 3) 热安全盾：只收缩前缀，绝不扩张
    k = M.hsc.project_prefix(k, T_ucb, tau_max)
    if k == 0: return M.cool_or_stop()
    # 4) 证书 + 参与式审计
    J = M.jheat.build(U_ale, U_epi, U_irr, B_dmg, M.tmf.last_fingerprint)
    M.vqa_t.submit_async(g_int, J)
    return k, lam, mode, J

## 3. 推导

**引理 19（迟滞环面积 = 耗散热：估计即热管理）** 对率无关迟滞算子，一个完整循环的净功 `A_h = ∮τ dθ = ∮H(e;h) de ≥ 0`，正好等于该循环的滞回耗散；加上摩擦与铜损即总产热。
系：**辨识迟滞不需要额外传感器**——双编码器给出的环面积同时进入传动误差模型与热模型；反过来，能量不平衡可反推迟滞/摩擦异常。这是本轮最重要的「一测两用」：估计与热管理共享同一个可观测量。

**引理 20（持续激励下的迟滞可观测性）** 在定义 312 的回归模型下，参数估计误差满足 `E‖φ̂−φ‖² ≥ σ²·tr(F_t^{-1})`。单向、慢速、无换向的运动使 `F_t` 近奇异；一次 `g_chirp` 或 `g_preload` 可把最小特征值抬到 `λ_min`，使误差界收紧到 `σ²·d/λ_min`。
系：**精密动作之前必须保证近窗激励的秩**；「越慢越稳」在迟滞存在时是错觉，慢而单向恰恰让回差状态最不可观。

**引理 21（热预算守恒 / 无免费持续力矩）** 对任意周期任务，稳态时平均产热必须等于平均散热：
`(1/T)∮Q dt = (T_ss − T_amb)/R_th`。
故持续平均力矩 `τ_avg ≤ τ_cont(T_max − δ_T)`；任何策略若想超过它，只能（a）超过 `T_max`，或（b）花掉不可逆损伤预算。峰值与连续力矩之比（常见 2.5–3:1）不是性能余量，而是**从热容借来的贷款**。
系：R68/R69 的 `λ` 只管「做多快/多保守」，HEAT 的 `τ_max(T)` 与 `B_dmg` 管「还能不能做」——两套刹车，缺一不可。

**引理 22（冷标定热使用的误差下界）** 若在温度 `T0` 标定、在 `T` 使用，零位/回差误差满足
`|δφ| ≥ L_φ·|φ_T(T) − φ_T(T0)| − ε_est`。
对热膨胀主导的参数，`|φ_T(T)−φ_T(T0)| ∝ ΔT`。故证书必须携带温度桶；跨桶不重辨识即违约。这是定义 321 的定量依据，也是「冷机调好的增益热机不稳」的正式版本。

**定理 18（HEAT 严格包含 R69）** 当 `U_epi^th = U_irr = 0`、`φ_T` 常数、`T_max → ∞` 时：HSC 与 WAC 为空操作，IIP 无候选，UIV 退化为 R69 的 VoI，TMF 只读不判——HEAT-RAS 与 R69 **逐指令相同**。一般情况下，HSC 只收缩可行前缀，WAC 只删除动作，内部探询只改善估计而**不扩张已认证安全集**，因此任意状态下的期望风险 `≤ R69`；效率收益仅来自「身体状态已认证」时的 resolution bonus。
⇒ R69 是 HEAT 在「身体透明、热无限」边界上的退化；安全侧不做任何让步。

**定理 19（内部探询的热-时序窗）** 设精密承诺在 `t_c`，探询耗时 `t_p`、冷却/整定耗时 `t_s`，探询后的不确定度下降为 `Δσ²(t)`，且状态漂移使信息以速率 `κ` 衰减。探询价值
`V(t) = c·Δσ²(t)·e^{−κ(t_c − t)} − c_th·Q_p·e^{−λ_th(t_c − t)} − c_time`。
`V(t)` 在 `[t_c − (t_p + t_s), t_c − t_s]` 内为正、窗外可能为负：**太早信息会漂掉，太晚热来不及散**。故内部探询既不是越早越好，也不是越多越好，而是有一个由热惯性 `R_th C_th` 与状态漂移率共同决定的时间窗。
系：`g_warm` 应放在长时程任务的冷启动阶段，`g_preload` 应紧贴精密承诺之前，`g_chirp` 应放在有热余量的空闲段。

**定理 20（能量平衡对时变标定吸收的不可吸收性）** 设位置标定从观测中减去慢变偏置 `b(t)`，使残差 `r_res≈0`。若 `b` 为**常数**（传感器偏置），它不改变速度与机械功，能量账平；若 `b` 为**时变**（热膨胀/磨损漂移），校正后的机械功率少算 `τ·ḃ`，于是
`|ΔE_bal| = |P_elec − P_mech^cal − Q − dU/dt| = |τ·ḃ + ε| ≥ τ_min·|ḃ| − ε`。
因此 `(r_res↓, ΔE_bal↑)` 是「时变故障被标定吸收」的判别性联合模式，补 R68 最脆弱处；而 `(r_res↓, ΔE_bal≈0, z0↑)` 则更像无害的常数偏置。**位置标定可以抹掉残差，但抹不掉能量账。**

## 6. 本轮最大风险

**一句话**：HEAT-RAS 的全部安全与效率收益都押在「热-迟滞隐状态可以从位置序列中被可靠辨识」这一前提上——**若辨识有偏（热点不可观、迟滞非平稳、chunk 开环把微运动藏掉），内部探询就会在错误的信念上加热关节，把一个错误的“已认证”章盖在不可逆的磨损上：机器人用自己的身体做探针，错一次就是永久损伤**。

**次级风险与缓解**：
1. **热点不可观 / 温度滞后** → UCB 保守端 + 能量平衡第二意见 + 外壳 NTC 兜底；
2. **热攻击 / 迟滞投毒** → ℰ_thermal 对抗训练 + WAC 硬预算 + 关键任务前的热预留；
3. **冷标定热使用** → 温度桶证书 + `g_warm` + 跨桶误差上界；
4. **内部探询自己产热** → 定理 19 的时间窗 + 热成本计入 VoI，无利可图即不探；
5. **chunk 开环掩盖微运动** → 把 TMF 与探询放在块边界/低频层，绝不假设逐帧反馈；
6. **磨损模型不准** → WAC 用保守寿命下界 + 人类授权门，宁可拒绝也不赌。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 继承零学习写与交互预算；**热安全包络**以 `T̂_h^ucb` 计费；**迟滞因果性**要求精密动作依赖有界估计或先预载；**热-功守恒记账**禁止凭空获得持续力矩；热/迟滞结论需 ≥2 正交证据。

**定义 311（THM）** 传动误差 `e=θ_m/N−θ_j`；`τ_t=N[k(φ_T)H(e;h)+b(φ_T)ė]+τ_f+τ_ext`；产热 `Q̇=τ_fω+(∮τdθ)/T_cycle+i²R(T)`；多节点 RC `C_thṪ=Q̇−(T−T_amb)/R_th`；热点不可直接测。

**定义 312（可观测性）** `s=(h,T_h,w,φ_T)`；只有位置接口时用 `(τ̂,P̂,g_r,r_t)` 替代 `(i,P_elec,T)`；迟滞可观测性由激励矩阵 `F_t=Σφφᵀ` 的秩决定，误差下界 `√(σ²tr(F_t^{-1}))`；单向慢速运动使 `h` 不可观。

**定义 313（三分 TUD）** `U_ale`（噪声→λ）、`U_epi^th`（可约→探询/冷却）、`U_irr^th=D(w,T,cycles)`（单调→硬预算）。三者不做简单加和，分通道处置。

**定义 314–315（TSoC 与降额）** `TSoC=clip((T_max−T̂_h^ucb)/(T_max−T_amb),0,1)`；热成本含产热、越温惩罚与热储备价值 `TVR`；`τ_max(T)=τ_peak√(clip((T_max−T)/(T_max−T_amb),0,1))`，连续力矩由热平衡解出。

**定义 316–317（IIP 与统一 VoI）** 四类内部信息动作，均有热/时间成本并过安全认证；`VoI_total=E[ΔL]−c_time−c_th−c_social`，外部与内部探询同台竞价；R69 是 `c_th≡0, 𝒜_int=∅` 的特例。冷时优先探/预热，热时少探多算。

**定义 318（TMF）** `z=(z0,A_h,∂A_h/∂T,ΔE_bal)`；常数偏置 `z0↑, A_h` 不变、能量平；热膨胀 `z0` 随 T 变、`ΔE_bal↑`；磨损 `A_h↑`；润滑退化 `A_h↑` 且 `∂A_h/∂T↑`；**标定吸收 ⇒ `z0` 被抹平而 `ΔE_bal` 保留**。≥2 特征一致才定案。

**定义 319–320（HSC 与 WAC）** HSC 投影到满足 `T̂_h^ucb≤T_max−δ_T`、`τ≤τ_max` 的最大前缀，空则 `g_dwell`/安全停。WAC 用 Miner+Arrhenius 累积损伤，`E[ΔD]>B_dmg` 的动作硬禁止；接近上限要求人类授权。

**定义 321–322（冷启动与证书）** 标定按温度桶维护 `J_cal(T_bucket)`，跨桶插值误差计入 `U_epi^th`；冷启动先 `g_warm`。`J_HEAT` 并入热状态、损伤预算、指纹与探询日志。

**定义 323–324（威胁与退避）** `ℰ_thermal`：环境热、假温升、热 DoS、迟滞投毒、标定吸收。预算内消解则用证书化 λ/τ（resolution bonus）；否则退 R69 纯保守 + HSC 最坏包络 + WAC 禁令。R69 逐指令退化为「热恒定、迟滞已知、无磨损」边界。

## 3. 关键算法伪代码

```python
# IP-264 THM：热-迟滞状态观测器
class ThermoHystereticModel:
    def step(self, y, u, dt):
        self.h = self.hyst.update(y.theta_in, y.theta_out)        # 有记忆的迟滞
        q = copper_loss(u.i_or_tau, self.T) + friction_loss(u.tau, y.omega) \
            + self.hyst.loop_dissipation()                          # 环面积 = 耗散热
        self.T = self.thermal_rc.step(q, dt)                        # 热点外推
        self.wear = self.wear_model.step(u.tau, self.T, dt)
        return self.h, self.T, self.wear

# IP-265 TUD：三分不确定性
def decompose_th(model, fisher):
    U_ale = model.ale_floor
    U_epi = trace(model.posterior_cov) * fisher_rank_factor(fisher)
    U_irr = model.accumulated_damage
    return U_ale, U_epi, U_irr, model.D_max - U_irr

# IP-266/267 TSO+DER：热点 UCB 与降额包络
def thermal_envelope(model, delta_T=4.0):
    T_ucb = model.T_mean + 3.0 * model.T_std
    frac  = clip((T_MAX - delta_T - T_ucb) / (T_MAX - T_AMB), 0.0, 1.0)
    return T_ucb, TAU_PEAK * sqrt(frac)

# IP-268/269 IIP+UIV：内部探询与统一信息价值
def choose_internal_action(modes, model, budget):
    best = None
    for g in [preload(), chirp(), dwell(), warm()]:
        if not budget.allow(g) or not c_ras_wm.certify(g): continue
        voi = expected_loss_drop(g) - time_cost(g) - thermal_cost(g, model)
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None   # 无利可图 → 不探询

# IP-270 TMF：热-机械指纹（位置标定吸收不了能量账）
def fingerprint(enc_in, enc_out, tau_hat, T, P_hat):
    z0    = mean(enc_in / N - enc_out)
    A_h   = loop_area(enc_in / N, enc_out, tau_hat)
    dA_dT = slope(A_h, T)
    dE    = energy_balance_residual(P_hat, tau_hat, enc_out, T)
    return z0, A_h, dA_dT, dE

# IP-274 主闭环（继承 R69，在执行层插入 HEAT）
def HEAT_RAS_round(M, obs):
    M.thm.step(obs, M.last_cmd, M.dt)
    U_ale, U_epi, U_irr, B_dmg = M.tud.decompose_th(M.thm, M.fisher)
    T_ucb, tau_max = M.der.thermal_envelope(M.thm)
    if B_dmg < B_MIN: return M.safe_stop(reason="damage_budget")   # 不可逆轴最先
    k, lam, mode = M.fluid.step(obs)                                # R69 外部闭环
    if needs_precision(mode) and U_epi > TAU_EPI:
        g_int = M.uiv.choose_internal_action(mode, M.thm, M.budget)
        if g_int is not None: M.execute_certified(g_int)
    k = M.hsc.project_prefix(k, T_ucb, tau_max)                     # 只收缩，不扩张
    if k == 0: return M.cool_or_stop()
    J = M.jheat.build(U_ale, U_epi, U_irr, B_dmg, M.tmf.last_fingerprint)
    M.vqa_t.submit_async(g_int, J)
    return k, lam, mode, J
```

## 4. 推导

**引理 19（环面积 = 耗散热：估计即热管理）** 对率无关迟滞，`A_h=∮τdθ=∮H(e;h)de≥0`，正好是该循环的滞回耗散；加摩擦与铜损即总产热。系：辨识迟滞不需要额外传感器，双编码器的环面积同时进入传动模型与热模型；能量不平衡可反推迟滞/摩擦异常。**一测两用**。

**引理 20（持续激励下的可观测性）** `E‖φ̂−φ‖² ≥ σ²tr(F_t^{-1})`；单向慢速使 `F_t` 近奇异，一次 `g_chirp`/`g_preload` 可把最小特征值抬到 `λ_min`，误差收紧到 `σ²d/λ_min`。系：精密动作前必须保证激励秩；「越慢越稳」在迟滞存在时是错觉。

**引理 21（热预算守恒 / 无免费持续力矩）** 稳态 `(1/T)∮Qdt=(T_ss−T_amb)/R_th`，故 `τ_avg≤τ_cont(T_max−δ_T)`；想超过只能越温或花损伤。峰值:连续常见 2.5–3:1，是**从热容借来的贷款**。系：λ 管「做多快」，`τ_max(T)`/`B_dmg` 管「还能不能做」——两套刹车。

**引理 22（冷标定热使用误差下界）** `|δφ| ≥ L_φ|φ_T(T)−φ_T(T0)| − ε_est`；热膨胀主导时 `∝ΔT`。故证书必须携带温度桶，跨桶不重辨识即违约。

**定理 18（HEAT 严格包含 R69）** 当 `U_epi^th=U_irr=0`、`φ_T` 常数、`T_max→∞` 时，HSC/WAC 为空操作、IIP 无候选、UIV 退化为 R69 VoI，两者逐指令相同。一般情况下，HSC 只收缩前缀、WAC 只删动作、内部探询只改善估计不扩张认证集 ⇒ 期望风险 `≤R69`；效率收益仅来自已认证状态的 resolution bonus。

**定理 19（内部探询的热-时序窗）** `V(t)=cΔσ²(t)e^{−κ(t_c−t)}−c_thQ_pe^{−λ_th(t_c−t)}−c_time`；正值集中在 `[t_c−(t_p+t_s), t_c−t_s]`。太早信息漂掉，太晚热来不及散。系：`g_warm` 放冷启动，`g_preload` 紧贴精密承诺，`g_chirp` 放有热余量的空闲段。

**定理 20（能量账对时变标定吸收的不可吸收性）** 位置标定减去慢变 `b(t)` 使 `r_res≈0`：若 `b` 为常数，不改变速度/机械功，能量平；若 `b` 时变（热膨胀/磨损），校正后机械功率少算 `τ·ḃ`，故 `|ΔE_bal|≈|τ·ḃ+ε|`。于是 `(r_res↓, ΔE_bal↑)` 判别「时变故障被标定吸收」，而 `(r_res↓, ΔE_bal≈0, z0↑)` 更像无害常数偏置。**位置标定抹得掉残差，抹不掉能量账。**

## 7. 本轮仿真结果（synthetic mechanism check，非榜单证据）

代码：`exp/heat_sim.py`；结果：`exp/heat_results.json`；seed `20261114`。四个独立玩具模型，仅验证机制方向与量级，不代表真机性能。

**A. 热预算调度（80 个任务的有限任务）**

| 策略 | 完成时间 | 峰值温度 | 超温时长 | 结论 |
|---|---|---|---|---|
| naive 峰值力矩 30 N·m | 28.0 s | 102.0°C | 11.0 s | 最快但越界，不可接受 |
| 静态连续降额 23.57 N·m | 34.6 s | 73.9°C | 0 | 安全但过保守 |
| **HEAT 热预算调度** | **29.6 s** | **88.6°C** | **0** | **比静态快 14.4%，且不越温** |

HEAT 用 4 s 滚动热预测选择当前最热可行力矩：冷时接近 30 N·m，热时自动降额；平均力矩 28.23 N·m，最后一段降到 26.0 N·m。naive 仅比 HEAT 快 5.4%，代价是 11 s 超温与 102°C 峰值——**「峰值性能」是贷款，不是免费午餐**（引理 21）。

**B. 冷标定热使用（回差宽度随温度变化）**

真实回差全宽从 25°C 的 20.0 mrad 降到 75°C 的 16.0 mrad。冷机标定直接热机使用时，误差随温差线性增长，75°C 达 **2.0 mrad**；带温度估计（观测误差 σ=2°C）的热感知补偿 p95 误差仅 **0.123 mrad**。这验证定义 321 与引理 22：**证书必须带温度桶**。

**C. 内部探询（精密插入前的预载/take-up）**

4000 个 episode，初始回差侧未知、宽度 `U[0.5,1.5]×20 mrad`、基础噪声 0.5 mrad：

| 指标 | 不探询 | 探询（预载） |
|---|---|---|
| p95 误差 | 28.1 mrad | **3.0 mrad** |
| 平均误差 | 10.3 mrad | **1.2 mrad** |
| p95 降幅 | — | **89.3%** |
| 成本 | — | 0.15 s / 1.94 J |

期望平方误差收益 217.5 mrad²，远高于成本阈值 0.97 ⇒ UIV 选择探询。这正是定理 19 的「贴近精密承诺的窗口」：探询只花 0.15 s，却把回差不确定性压低一个数量级。

**D. 热-机械指纹（四类故障）**

特征 `(z0, A_h, ∂A_h/∂T)`，标准化后最近质心分类，噪声 σ=0.30，每类 600 样本：

| 类别 | 精确率（对角/该类） |
|---|---|
| 传感器常数偏置 | 555/600 = 92.5% |
| 热膨胀 | 490/600 = 81.7% |
| 磨损 | 548/600 = 91.3% |
| 润滑退化 | 490/600 = 81.7% |

总体准确率 **86.8%**；主要混淆在「热膨胀 ↔ 润滑退化」（81 例），说明仅靠三个特征还不够，需要 `ΔE_bal` 作为第四特征（E307 的动机）。这不是失败，而是诚实的边界：**指纹是判决的必要条件，不是充分条件**。

**E. 严格包含自检** 由构造保证：当 `T` 恒定、`h` 已知、`WAC` 关闭时，`thermal_envelope` 返回 `τ_peak`，`choose_internal_action` 返回空（`U_epi=0`），HSC 前缀不变 ⇒ 与 R69 逐指令一致。E309 将把它做成回归测试。

## 8. 落地与来源（UniBot-V1 / Unitree G1）

**接口约束（决定了本方案必须「从位置推状态」）**
- UniBot-V1 提交接口的 observation 只有四路 RGB、左右臂各 7 维关节位置、左右 EE pose + gripper、左右夹爪开度、lower_body 15 维与语言；**没有电流、力矩、温度、深度**。动作是 joint 或 ee 的位置目标，`action_chunk_size` 步内开环执行，再次调用前无逐帧反馈。
- 因此 HEAT-RAS 在评测中必须用 `τ̂`（逆动力学/扰动观测器）、`P̂=τ̂ω+Q̂`、指令-响应增益 `g_r` 与跟踪残差 `r_t` 替代 `i/P_elec/T`；`T_h` 只用 UCB 外推，宁宽勿窄。这不是降级，而是把「热不可观」变成第 4 个观测量：**降额会让同样的位置指令产生更小的响应**。
- 来源：`github.com/unitreerobotics/unibot_submission` README（observation/action 目录与 chunk 约定），检索日期 2026-11-14。

**G1 硬件事实（用于设定量级，不绑定具体传动）**
- G1：23–43 自由度、约 35kg、关节双编码器、局部风冷、膝部峰值 90/120 N·m（`unitree.com/g1`）。
- 多数拆解：关节为「电机 + 两级行星减速 + 双编码器 + 驱动」四合一，减速比约 15–20.58:1；QDD 低成本高效率但**更容易过热**（`global.eefocus.com` 2026-07-27；`humanoid.guide` 2026-09-13）。
- 也有论文按「BLDC + 谐波减速器」建模 G1 手臂（`arxiv.org/html/2606.15915v1`）。**两类说法冲突，故本方案只依赖「高减速比 + 回差/迟滞/热」这一同构抽象。**
- 热管理：高负载关节超阈值触发 thermal derating/限流；膝部 VC 均热板 + 铜带被动散热，腰部主动风扇，主控 SoC/BMS 有 NTC；高负载连续运行约 1–2h 后需停机降温（`en.eeworld.com.cn` 2026-07-27；中邮证券 G1 拆解报告）。
- 宇树 IM6014 关节电机：驱动板 >90°C、绕组 >130°C 报过热关机；自研热管理模型以 400Hz 监测温度（`unitree.com/IM6014`）。
- 峰值:连续力矩在空冷人形执行器上常见 2.5–3:1；绕组绝缘约 130–150°C 失效，铜电阻约 +0.4%/°C（`humanoid.guide` 2026-09-02）。这些数字直接支撑 `τ_max(T)` 与「热是预算」的设计。

## 9. 本轮最大风险

**一句话**：HEAT-RAS 的全部安全与效率收益都押在「热-迟滞隐状态可以从位置序列中被可靠辨识」这一前提上——**若辨识有偏（热点不可观、迟滞非平稳、chunk 开环把微运动藏掉），内部探询就会在错误的信念上加热关节，把一个错误的“已认证”章盖在不可逆的磨损上：机器人用自己的身体做探针，错一次就是永久损伤。**

**次级风险与缓解**：热点不可观 → UCB 保守端 + 能量账第二意见 + NTC 兜底；热攻击/迟滞投毒 → `ℰ_thermal` 对抗训练 + WAC 硬预算 + 关键任务前热预留；冷标定热使用 → 温度桶证书 + `g_warm` + 跨桶误差上界；内部探询自己产热 → 定理 19 时间窗 + 热成本计入 VoI；chunk 开环掩盖微运动 → TMF/探询放在块边界与低频层；磨损模型不准 → 保守寿命下界 + 人类授权门。
