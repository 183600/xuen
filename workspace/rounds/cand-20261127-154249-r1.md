## 1. 直觉与动机（两个灵感的碰撞）

**灵感 A（多模态大模型 → 我们一直把它当「更大的策略」，但它其实是「更好的老师」）**
直觉：机器人竞赛里大家的本能是「上更大的 VLA」，但部署预算（单模型、p99<40ms）直接封死这条路。反过来看官方架构：ER-1 已经会检测物体、点出抓取点、预测 2D 轨迹、判断空间关系（F22），可基线把它冻住只读隐状态（F21）。这等于请了一位会看图会讲理的老师，却只让她站在旁边当背景板。正确用法是：**让 MLLM 在训练期把每条示教「讲一遍」——这段在接近、这段在抓、这一分拿到了——再把讲解蒸馏进小模型。** 推理期只有小 VLA，老师下课。核心反直觉点：**多模态大模型的价值不在推理时算得更多，而在训练时把「示教 + 评分细则」翻译成可监督的中间结构。**

**灵感 B（示教学习 → 我们一直在模仿动作，却没模仿「动作的理由」）**
直觉：行为克隆只监督 a_t，等于逼模型从像素直接猜电机指令；而人类学徒学的不只是手怎么动，还有「为什么现在抓、抓哪里、什么时候算完成」。示教里其实藏着这些理由，只是没被标注出来。MLLM 恰好能把它们显式化：子目标切分（temporal subgoal）、可供性（抓取点 / 接近方向 / 间隙）、进度曲线（对齐官方 100 分得分点）、失败归因（扰动后哪一步崩了）。把这些作为**辅助监督**（privileged information）蒸馏进动作专家，动作头的隐表示就被迫编码任务结构，而不是死记轨迹。核心反直觉点：**示教学习的下一步不是更多示教，而是给现有示教补上「理由标签」——而理由标签可以由 MLLM 以远低于真机的成本生成。**

**统一**：A 回答「老师从哪来」（官方 ER-1 / 更强的离线 VLM），B 回答「老师教什么」（子目标 / 可供性 / 进度 / 失败归因，对齐评分细则）。二者合起来就是本轮主创新 I10「示教编译器」。它同时给 I2（孪生语义核验）、I5（得分点里程碑）、I9（可供性先验）、I1（增广物理可行性）供能，并把 I7（外部世界模型前瞻）降级——因为官方主干已内置未来动态区域预测（F23）。

## 0. 形式化定义（先立符号，再谈方案）

**任务与示教。** 任务 $k\in\{1..32\}$，指令 $\ell_k$。一条示教 episode $e=(o_{1:T},a_{1:T},\ell_k)$，其中 $o_t=(I_t^{L},I_t^{R},I_t^{W},s_t)$（多视角图像 + 本体状态 $s_t\in\mathbb{R}^{60}$），$a_t\in\mathbb{R}^{54}$（Dex1 二指夹爪子空间，F20）。

**评分细则。** 每任务细则
$$R_k=\{(g_j,w_j,\phi_j)\}_{j=1}^{M_k},$$
$g_j$ 为得分点的自然语言判据，$w_j>0$ 为分值且 $\sum_j w_j=100$，$\phi_j:\text{observation}\to\{0,1\}$ 为可视判据（F17）。时刻 $t$ 的步骤分为
$$S_k(e_{1:t})=\sum_{j=1}^{M_k} w_j\cdot \mathbb{1}\big[\phi_j\ \text{在}\ t\ \text{前已满足}\big].$$
目标不是最大化 $t=T$ 的终态，而是最大化整条轨迹的 $S_k$（超时仍计步骤分）。

**特权标注。** 冻结 MLLM 标注器 $\mathcal{A}$（官方 ER-1 或更强的离线 Qwen3-VL）：
$$\mathcal{A}\big(\text{keyframes}(e),\ \ell_k,\ R_k\big)=z=(\sigma,\beta,p,\psi),$$
- $\sigma=\{(b_j,e_j,g_{\pi(j)})\}$：子目标时段及与细则点的对齐 $\pi$；
- $\beta=\{(u_j,d_j,c_j)\}$：抓取点 $u_j\in\mathbb{R}^2$（图像坐标）、接近方向 $d_j\in S^2$、所需间隙 $c_j$；
- $p:[1,T]\to[0,1]$ 单调，且 $p(t)\approx S_k(e_{1:t})/100$（进度即步骤分）；
- $\psi$：对扰动轨迹的失败归因（哪个 $\phi_j$ 先崩）。

**蒸馏（Learning Using Privileged Information）。** 学生策略
$$\pi_\theta(a_{t:t+H}\mid o_{t-h:t},\ell),\quad H=30,$$
共享主干 + 三个小辅助头 $h_{\text{prog}},h_{\text{sub}},h_{\text{aff}}$。训练目标
$$\mathcal{L}=\mathcal{L}_{\text{flow}}(a)+\lambda_p\|h_{\text{prog}}-p\|^2+\lambda_s\,\mathrm{CE}(h_{\text{sub}},\sigma)+\lambda_a\,\mathcal{L}_{\text{aff}}(h_{\text{aff}},\beta)+\lambda_r\|\theta\|^2.$$
关键性质：$z$ 只在训练期存在（privileged），推理期不需要 $\mathcal{A}$；辅助头是**同一网络内的子头**，不是第二个模型——PR2/PR6 同时满足。动作专家→VLM 保持 stop-gradient（F20 的 Knowledge Insulation），辅助头梯度也只回传动作专家，不动冻结 VLM。

**孪生双判据。** 迁移权重
$$w(i\to j)=\begin{cases}W_{\max}\cdot M_{\text{sem}}(i,j)\cdot M_{\text{dyn}}(i,j), & M_{\text{dyn}}\ge D_{\min}\\ 0, & \text{否则（动态方向相反，如 ZipUp/Unzip）}\end{cases}$$
$M_{\text{sem}}$ 由 MLLM 读任务描述 + 示教视频给出语义相似度；$M_{\text{dyn}}$ 由 MLLM「方向是否相反」判断 + 末端位移场相关性联合给出。语义高但动态低 → 否决，直接攻击 v1.1 的最大风险（负迁移）。

## 1. 创新点清单（每点：动机 / 差异 / 可行性 / 资源 / 落地 / 风险）

### I10 示教编译器：MLLM 特权信息蒸馏（新） ★★★★★
- **动机**：官方基线把具身 MLLM 冻结为被动特征提取器（F21/F22），浪费了它本就会产出的点 / 框 / 轨迹 / 空间判断；行为克隆只监督动作，不监督「动作的理由」；评分是逐点步骤分，却缺少稠密的步骤级监督（F17）。

### 2.3 蒸馏与辅助头（训练期；推理期可丢弃辅助头）
```python
class DistilledVLA(nn.Module):
    def forward(self, obs, lang):
        h = self.frozen_er(obs, lang)             # F21: 冻结 VLM
        h = stop_grad(h)                          # Knowledge Insulation (F20)
        a = self.dit_flow(h, obs.state)           # 主头：54-D, horizon 30
        return a, self.h_prog(h), self.h_sub(h), self.h_aff(h)

def train_step(batch):
    a_hat, prog, sub, aff = model(batch.obs, batch.lang)
    L = flow_loss(a_hat, batch.a) \
      + lam_p * huber(prog, batch.z.p) \
      + lam_s * ce(sub, batch.z.sigma) \
      + lam_a * affordance_loss(aff, batch.z.beta) \
      + lam_r * reg
    # lam_*: warmup（主 flow 稳定后再开辅助）; 辅助头梯度只到动作专家
    return L
```

## 3. 实验设计（L0 前置闸 + 分级消融）

| 阶段 | 问题 | 方法 | 通过判据（放量闸） |
|---|---|---|---|
| **L0-a 标签保真** | Q9 | 5% 人工审计；per-point F1、子目标 temporal IoU、进度 MAE、进度-真机步骤分 Spearman | F1 ≥ 0.8 且 temporal IoU ≥ 0.6 才允许进 L1 |
| L0-b 蒸馏不伤 | Q10 | 留出集：baseline vs +prog / +sub / +aff / +all；λ 与注入层扫描 | 动作重建不退化（Δ<2%），辅助指标升 |
| L0-c 孪生 | Q11 | 名字 vs 语义 vs 语义×动态；ZipUp/Unzip、Plug/Disconnect 对照 | 动态判据把负迁移家族退步消除 |
| L0-d 增广批评 | I1 | MLLM 可行性过滤 on/off | 不可行动作占比 < 5% |
| L1 因子 | 组合 | $2^{k-p}$ 部分析因，主效应优先 | 显著组合 ≤3 个进 L2 |
| L2 真机 | 确认 | top 2–3，≥2 任务 × 各 2 次 | 真机增益 ≥ 离线预测的 50% |
| 门禁 | 部署 | run_client 全流程 + p99 + 动作健康度 | 0 拒绝动作、p99 < 40ms |

**首批 L2 排队**：①I10 标签保真 + 蒸馏试点（3 任务）→ ②I2 v3 双判据孪生（ZipUp/Unzip 对照）→ ③I5 v3 失败合成 → ④I1 批评器 → ⑤I9 v2 可供性头未见轴抽测。
