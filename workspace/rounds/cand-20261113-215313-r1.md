# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「位姿估计」×「关节驱动」）

> 第 68 轮把「标定」升级为一等公民在线潜变量，用自监督与单模型多任务把测量可信度纳入闭环，但其自陈最大风险是一句判词：**标定能力越强，落在标定带宽内的缓变故障越隐形**。根源在于 R68 的验证是「静观」——静态段自标定只能辨识**无记忆**的偏移/增益，而真实关节的缓变退化（间隙、摩擦、传动增益、编码器滑移）是**历史依赖的迟滞**，根本不在标定模型的可吸收子空间里，却被 COF 用「时间上够慢」这一条判据放行。
>
> 本轮灵感恰好给出两把钥匙：
> **位姿估计**让「关节指令 → 末端位姿」成为一条可闭合的运动学回路（command-to-motion 的物理承诺）；
> **关节驱动**让系统可以**主动动一下**去激发并读回传动特性，把「被动观测」升级为「主动辨识」。
>
> 核心命题：**以运动学互易性为锚、以安全激发为探针，把「不可吸收性」从带宽假设升级为结构定理——ARTIC-RAS（Articulation-grounded Reciprocity-Tested Integrated Calibration RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我的动作和我的观测还自洽吗**」——静观其变不够，动察其变才能分辨「世界变了 / 传感器歪了 / 关节坏了」。

## 0. 直觉与动机

**灵感 1（位姿估计 → 位姿不是又一路传感器，而是一条闭环的「关节」）**
直觉：R68 把视觉、触觉、力、世界模型都当成「可标定的观测」，于是它们两两一致时系统就相信；但若它们**一起缓慢漂移**，内部一致性依然完美——这是自证循环。位姿估计提供了一条不同的东西：刚体运动学约束。末端位姿既可以由视觉/深度估计（T̂_ee^vis），也可以由关节编码器经正运动学算出（FK(q_enc)）。二者之差 r_recip = FK(q_enc) ⊖ T̂_ee^vis 不是「两个可标定传感器的差」，而是「**我对关节下的命令，与关节实际把世界带到的位置**」之间的物理对账。刚体闭合是物理定律，不是可学习参数；把它立为外部锚，标定就无法再独自解释一切。

**灵感 2（关节驱动 → 静观其变，不如动察其变）**
直觉：R68 的静态段自标定很聪明——静止时跨模态分歧就是标定误差。但**静止永远看不见间隙**：反向间隙、静/动摩擦、传动增益的方向不对称，全都只在**运动换向与加载**时显形。一个只做静态自标定的系统，能标定「零点偏了多少」，却对「关节松了多少」结构性失明。于是本轮引入**主动激发探针（AEP）**：在认证安全的状态下，主动做小幅、可控、富含换向的辨识动作，把关节的传动特性「问」出来。观测是被动的，辨识是主动的——只有动一下，β 才可辨识。

**灵感 3（迟滞不可吸收 → 不可吸收性从「频率」升级为「结构」）**
直觉：R68 的反吸收（引理 13）依赖一个带宽不等式：故障要快于 ω_cal 才不被吸收。但缓变故障（磨损、渐进松动）恰恰慢于 ω_cal，于是被「合法」吸收。本轮的洞察是：**标定是记忆less的常数/慢潜变量，迟滞是历史依赖的算子**。对一条闭合的激发回路，任何常数标定 c 的回路积分 ℒ(r_cal(c)) = ∮ r_cal·dq 恒为 0（路径无关），而间隙/摩擦的回路积分 A_loop = ∮ r_recip·dq > 0。于是「标定吸收慢故障」在**回路功能**上被结构性地否证——这不是同一把尺子上的带宽之争，而是两个正交的函数空间。**慢，不再是隐形的理由。**

**灵感 4（主动感知的代价 → 激发必须被风险预算约束）**
直觉：动察不是免费的——探针本身是动作，可能扰动场景、加剧磨损、甚至在错误状态下触发失稳。若为了辨识而无条件激发，等于把「被动防御」改成「主动扰动源」。因此激发必须：(i) 只在认证安全包络 𝒜_safe 内执行（k*RAS 已收缩、λ_risk 抬高、无接触危险）；(ii) 有显式风险预算 ε_probe；(iii) 收益（Fisher 信息）必须超过风险。激发的**信息收益–安全代价**是一个可优化的权衡，而不是一张空白支票。

**灵感 5（与 R68 融合 → ARTIC-RAS 六组件）**
1. **PKF Pose–Kinematics Fusion**：位姿估计与关节驱动进同一因子图，输出 (T̂_ee, q̂, r_recip, Σ)；
2. **AEP Active Excitation Probe**：安全包络内的最优辨识动作，最大化关于 β 的 Fisher 信息；
3. **HOD Hysteresis/Observability Detector**：提取回路面积、死区宽度、方向增益不对称、摩擦曲线等**结构指纹**；
4. **CKR Calibration–Kinematics Reciprocity**：把残差分解到可吸收子空间 𝒮_cal 与其正交补，新增 H_act 假设（升级 R68 的 CFA）；
5. **CAC† Certified Adapter Commit**：在 R68 五关之上新增「激发溯源门」与「慢故障 canary」（回放带宽 ≪ ω_cal 的间隙坡道）；
6. **RAS† 继承核**：R68 的 COF/SSG/MTM 全部保留，标定潜变量 c 旁新增传动潜变量 β 与双滤波器 DKF，阈值由 (U_cal, U_kin) 联合重参数化。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（ARTIC-RAS 总览）** ARTIC-RAS = (PKF, AEP, HOD, CKR, CAC†, RAS†)。三条不变式：
(i) **静动分离**：静观段只辨识无记忆标定量 c（R68 的 COF），动察段专门辨识历史依赖传动量 β；两者参数空间结构正交（定义 297），互不吞并；
(ii) **激发安全包络**：任何激发动作 q_ex ∈ 𝒜_safe（定义 304），且期望风险 ≤ ε_probe；激发只在 k*RAS 已收缩、λ_risk 已抬高的时段执行；
(iii) **双锚裁决**：慢变量可信度由「标定不确定 U_cal」与「运动学互易不确定 U_kin」共同裁决，任一超阈即收缩——**不允许任一路单独把不确定解释掉**。

**定义 294（PKF 位姿–运动学因子图）** 变量 X = (T_ee, q, c, β)。因子：
- 位姿先验因子 f_vis: ‖T_ee − T̂_ee^vis‖²_{Σ_vis}（视觉/深度/时序位姿估计）；
- 运动学因子 f_fk: ‖T_ee − FK(q; c_ext, β)‖²_{Σ_fk}（关节驱动经传动与正运动学）；
- 编码器因子 f_enc: ‖q − q_enc‖²_{Σ_enc}；力矩/电流因子 f_τ；
- 平滑因子 f_smooth（运动连续性与接触一致性）。
MAP 求解得 (T̂_ee, q̂, Σ_T, Σ_q)，并输出**互易残差** r_recip = FK(q_enc; c_ext, β̂) ⊖ T̂_ee。位姿估计因此获得运动学先验（抗遮挡、抗单目尺度漂移），关节驱动因此获得外部位姿对账（抗编码器滑移）。

**定义 295（关节传动模型与 β 潜变量）** 单关节指令 q_cmd 经传动得到真实关节量 q_true = G_β(q_cmd, d_t, load_t)，其中方向状态 d_t = sign(q̇_t)，β = (b ∈ ℝⁿ 反向间隙, f_v, f_c 黏/库仑摩擦, k_g 传动增益, s_enc 编码器滑移, τ_d 死区)。
β 慢变：β_{t+1} = β_t + w_t, w ~ 𝒩(0, Q_act)，但**依赖方向状态 d_t**——这一条使其不可被任何时不变 c 吸收。

**定义 296（运动学互易残差）** r_recip(t) = FK(q_enc(t); c_ext) ⊖ T̂_ee(t)。在纯外参标定误差下，r_recip 是**常值刚体变换**（可被 c_ext 吸收）；在传动退化下，r_recip 依赖 d_t 与 load_t，并随换向勾出**迟滞环**。

**定义 297（可吸收子空间与结构正交）** 定义标定可吸收子空间
𝒮_cal = span{∂r/∂c}（时不变、无记忆），其 Q-正交补为 𝒮_cal^⊥。
对任意闭合激发回路 Γ，定义回路功能 ℒ_Γ(r) = ∮_Γ r · dq。
命题（结构正交）：∀c，ℒ_Γ(r_cal(c)) = 0（标定残差是保守场/路径无关）；而理想反向间隙算子 H_b 满足 ℒ_Γ(H_b) = A_loop(b, A_exc) > 0（b > 0 且激发幅度 A_exc > b）。故 H_b 在回路功能意义下位于 𝒮_cal^⊥，**任何时不变标定都无法将其吸收**。

**定义 298（迟滞/摩擦算子族）** 反向间隙用 play 算子 H_b（死区宽 2b）；摩擦用 Stribeck 曲线 f(v) = f_c·sgn(v) + f_v·v + (f_s − f_c)e^{−(v/v_s)²}·sgn(v)；增益与滑移为方向相关线性项。定义回路面积 A_loop = ℒ_Γ(H_b)，死区宽度 δ_db，方向增益不对称 Δg = g_+ − g_-。

**定义 299（主动激发策略 AEP）** 在安全包络与风险预算下选择激发轨迹 q_ex：
q_ex* = argmax_{q_ex ∈ 𝒜_safe, Risk(q_ex|state) ≤ ε_probe} I(β; r_recip | q_ex)，
I 为 Fisher 信息。持续激发条件：一条激发回路内**至少 2 次换向**、幅度 A_exc ≥ b_min、频带覆盖摩擦动态；仅恒速/静止段对 b 的 Fisher 信息为 0（定义 307）。

**定义 300（HOD 结构指纹）** φ_act = (A_loop, δ_db, Δg, f̂(v) 曲线, k̂_g, ŝ_enc, r_recip 与 load 的偏相关)。检测统计量 T_act = w^T φ_act，阈值 τ_act 由 U_kin 重参数化。

**定义 301（CKR 标定–运动学互易归因，升级 CFA）** 将残差分解 r = r_cal + r_perp，r_cal = P_{𝒮_cal} r，r_perp = r − r_cal。四假设：
- H_cal：r_perp ≈ 0 且 r_cal 可被 ĉ 解释（漂移）；
- H_act：r_perp 具有回路结构（A_loop > τ_act 或 Δg ≠ 0）——**传动退化**；
- H_sensor^trans：r_perp 非回路、非标定可解释（真实传感故障）；
- H_real：残差与动作/负载无关、与场景变化相关（世界真变了）。
后验 P(H | r, β̂, ĉ, U) ∝ p(r | H, β̂, ĉ)·P(H)，并按 R68 纪律：U_cal 或 U_kin 超阈 ⇒ 最坏情况归因 + λ 下限抬升。

**定义 302（双滤波器 DKF）** c 用 R68 的 COF（带宽 ω_cal）；β 用 UKF/EKF，且**激发门控更新**：仅当 Fisher 信息 I(β) ≥ I_min 才允许 β 更新，否则保持预测——杜绝无信息时把噪声当参数学。联合不确定 U = (U_cal, U_kin)=(tr Σ_c, tr Σ_β)。

**定义 303（CAC† 六关）** R68 五关（金标回归 / 审计回放 / TV 界 / 风险界 / canary 不可修复）+ 第六关 **激发溯源门**：
6. 慢故障 canary（间隙按 0.01 mm/min 坡道注入，带宽 ≪ ω_cal）必须在激发回放中产生可检 A_loop；且「指令 q_cmd 与实际位姿变化」必须一致（激发确实执行、未被探针欺骗伪造）。任一不过即拒。

**定义 304（激发安全包络）** 𝒜_safe = {q_ex: |q̈| ≤ a_max, |ΔT_ee| ≤ δ_safe, 接触力 ≤ F_safe, 工作空间余量 ≥ m_safe, 且当前 λ_risk ≥ λ_probe}。风险预算 ε_probe ≤ 10⁻³/小时，违反即全局降级。

**定义 305（J_ARTIC 证书）** J_ARTIC = (J_CALM, kin_state_hash, β̂, U_kin, excitation_log_hash, act_verdict, artic_ver)。Valid ⇔ Valid(J_CALM) ∧ U_kin < τ_kin^hard ∧ act_verdict = PASS ∧ 激发包络未越界。

**定义 306（管线）** 离线：R68 自监督预训练 → 加入运动学/传动自监督头（FK 一致性、互易残差）→ 有标签微调 → 首次静观标定 + 首次动察辨识 → CAC† 提交。在线：静观段跑 COF 标定 c；安全窗口插入 AEP 激发、HOD 提取 φ_act、DKF 更新 β；CKR 归因；60 s 影子提交经六关。

**定义 307（持续激发可辨识性）** 对反向间隙 b，若激发轨迹在死区内无换向（静止或恒速），则 ∂r_recip/∂b ≡ 0，Fisher 信息 I(b)=0，b 不可辨识；若回路含 ≥ 2 次换向且 A_exc > b，则 I(b) ≥ I_min > 0。推论：**R68 的静态自标定对 b 结构性失明，不是精度不够，而是不可辨识。**

**定义 308（激发收益不等式）** 一次激发的净收益 ΔJ = ΔI(β)·V_β − c_R·Risk(q_ex) − c_W·Wear(q_ex)。仅当 ΔJ > 0 才执行激发；V_β 为 β 不确定所对应的下游风险价值。

**定义 309（联合规范自由度，A95）** 若所有位姿源与编码器共享同一缓变刚体偏移，则 r_recip 对该共模偏移不变，β 与其不可分——这是运动学互易的**规范自由度**。打破它只能靠外部计量（出厂溯源）、重力/接触约束或独立模态。此自由度内的问题不可被本框架解决，必须显式声明。

```python
# IP-253 PKF：位姿估计 × 关节驱动的因子图，输出互易残差
class PoseKinematicsFusion:
    def estimate(self, pose_obs, q_enc, tau, c, beta, prior):
        X = factor_graph.solve(
            variables=('T_ee', 'q', 'c', 'beta'),
            factors=[vis_prior(pose_obs), fk_factor(q_enc, c, beta),
                     enc_factor(q_enc), torque_factor(tau), smooth_factor(prior)])
        r_recip = se3_log(fk(X.q, X.c, X.beta) @ inv_pose(X.T_ee))
        return X, r_recip, cov(X)


# IP-254 AEP：安全包络内的最优激发（动察）
class ActiveExcitationProbe:
    def __init__(self, eps_probe=1e-3, A_safe=None):
        self.eps_probe, self.A_safe = eps_probe, A_safe

    def plan(self, state, beta_hat, Sigma_beta):
        if state.lam_risk < LAMBDA_PROBE or not state.safe: return None
        best = None
        for q_ex in design_dithers(reversals=2, amps=np.linspace(B_MIN, A_SAFE, 6)):

        return best                                  # None ⇒ 本轮不激发

def hysteresis_signatures(q, r_recip):
    loop_area = abs(np.trapz(r_recip, q))            # ℒ_Γ(r)=∮r·dq
    db        = estimate_deadband(q, r_recip)

    return {'A_loop': loop_area, 'deadband': db,
            'delta_g': g_plus - g_minus, 'friction': fit_stribeck(q, r_recip)}

def act_statistic(phi, U_kin):
    w = ACT_WEIGHTS
    return w @ phi, TAU_ACT0 * (1 + K_ACT * U_kin)   # 不确定 → 更敏感而非更迟钝


# IP-256 CKR：标定–运动学互易归因（升级 R68 的 CFA）
def calibration_kinematics_reciprocity(r, c, beta, U):
    J_cal  = jacobian_cal(r, c)
    r_cal  = J_cal @ np.linalg.pinv(J_cal) @ r      # 投影到 𝒮_cal
    r_perp = r - r_cal                              # 正交补：结构不可吸收
    phi    = hysteresis_signatures(*r_perp)         # 回路指纹
    H_act  = act_statistic(phi, U.kin) > tau_act(U.kin)
    if np.linalg.norm(r_perp) < eps and U.cal < TAU_CAL:
        return 'H_cal'
    if H_act:
        return 'H_act'                              # 先判结构，再判幅值
    return attribute_transient_sensor(r_perp, U)   # H_sensor^trans / H_real

    # 4) CKR：先判结构（迟滞）再判幅值，最后才归因
    H = M.ckr.calibration_kinematics_reciprocity(
            r_recip, c, beta, Uncertainty(U_cal, U_kin))

    # 5) 阈值联合重参数化 + 风险缩放（继承 R68，新增 U_kin）
    thr = reparam(thr, U_cal, U_kin)                  # 不确定 → 收紧总闸
    lam = max(M.efs.risk_scale(H), thr['lam_floor'],
              0.8 if (H == 'H_act' or U_kin > TAU_KIN) else 0.6)
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(X.T_ee), H, M.m_ras)
    if U_kin > TAU_KIN: k = min(k, k_kin_shrink(U_kin))   # 传动不确定 → 前缀收缩

    # 6) 控制（R68 ERS-WM 保留），激发动作与任务动作按安全优先级仲裁
    tau_cmd = M.pi_sigma.prefix_dispatch(M.actions[:k]) * lam
    tau_cmd = M.aep.arbitrate(tau_cmd, probe)          # 激发让位于安全
    M.vqa_k.submit_async((r_recip, phi, H), {'beta': beta, 'U': (U_cal, U_kin)})
    M.cac_artic.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, H, (c, beta, U_cal, U_kin)
```

## 3. 推导

**引理 16（迟滞结构不可吸收——反吸收从带宽升级为结构）** 对任意时不变标定 c，r_cal(c) 是保守场，故任意闭合回路 Γ 上 ℒ_Γ(r_cal(c)) = ∮ r_cal·dq = 0。对理想反向间隙 H_b（死区 2b），当激发幅度 A_exc > b 时回路面积 A_loop = 4b(A_exc − b) > 0，且单调于 b 与 A_exc。于是 min_c |ℒ_Γ(r_recip − r_cal(c))| = A_loop > 0：**无论 c 如何优化，都无法把回路功能消为零**。系：R68 的「慢故障被标定吸收」在传动故障上被结构性阻断——吸收的是路径无关的偏移，吸收不了路径依赖的迟滞。

**引理 17（持续激发可辨识性——为什么必须动）** 静止或恒速段 q̇ 不换向，死区从未被穿越，∂r_recip/∂b ≡ 0，Fisher 信息 I(b) = 0；b 不可辨识。含 ≥ 2 次换向、A_exc > b 的激发回路给出 I(b) ≥ I_min(A_exc − b)²/σ² > 0。故 **R68 静态自标定对间隙不是「精度不足」而是「原理不可辨识」**，只能靠主动激发补齐。

**引理 18（激发–安全折衷）** 检测 SNR(A_exc) ≈ A_loop(A_exc)/σ = 4b(A_exc − b)/σ，随 A_exc 单调增；激发风险 Risk(A_exc) ≈ c_R·A_exc² + c_W·Wear(A_exc)。故最优幅度 A* = min(A_safe, argmax_A [SNR(A) − c_R·Risk(A)])，且仅当净收益 > 0（定义 308）才激发。系：**不是越大越好，而是在安全包络内取信息–风险最优点**。

**定理 16（ARTIC-RAS 端到端风险一致性）** 在 A87–A95 下，输出 τ_cmd 满足：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_act**，其中 α_act 由引理 16–17 的迟滞可辨识与 CKR 结构判别限制；
2. (U_cal > τ_cal) ∨ (U_kin > τ_kin) ⇒ λ_risk ≥ 0.8 ∧ 前缀收缩——**任一路测量/传动不确定都只导向收紧**；
3. 激发动作满足 Risk ≤ ε_probe 且仅在 𝒜_safe 内，激发引入的额外风险 ≤ ε_probe（定义 304）；
4. canary 慢故障（带宽 ≪ ω_cal）检出率 ≥ 0.95（定理 17），CAC† 有害适配器上线概率 ≤ 0.05·p_h。

**定理 17（慢故障不再隐形——对 R68 最大风险的正面关闭）** 对任何传动退化，只要其反向间隙 b ≥ b_min 且激发回路含 ≥ 2 次换向、A_exc > b，则检测所需样本数 N ≤ C·σ²/(A_loop(A_exc)²)，检测时延 T_detect = N·Δt **与故障变化率 ω_f 无关**——即使 ω_f ≪ ω_cal，迟滞回路面积仍然出现。因此 R68「落在标定带宽内的缓变故障被吸收」的最大风险，在**传动侧被结构性关闭**。边界：若故障是纯无记忆慢偏移（而非迟滞），仍落入 𝒮_cal，需靠 R68 的反吸收界与定义 309 的规范自由度显式承认；若所有模态共享同一刚体慢漂移，则不可辨识（A95），必须外接计量锚。

## 6. 本轮最大风险

**一句话**：ARTIC-RAS 的安全性押在「主动激发」这一新动作上——**探针本身可能加速关节磨损、在边界状态触发失稳，或被对手识别后「只在探测时表演正常」（probe-aware spoofing），从而把 R68 的「静观盲区」转移成 R69 的「动察表演窗口」；激发的信息收益越高，系统对探针真实性的依赖越致命。**

**次级风险与缓解**：
1. **激发安全**：任何激发必须过 𝒜_safe 与 ε_probe 双重门，越界即全局降级（k=0）；
2. **探针欺骗**：激发溯源门校验「指令 vs 实际位姿变化」一致性 + 随机化激发波形，防重放/预测；
3. **β 过拟合噪声**：激发门控（I ≥ I_min 才更新）+ 先验收缩，无信息不学习；
4. **规范自由度**：共模刚体漂移不可辨识，J_ARTIC 显式报告并强制外接计量锚（A95）；
5. **激发与任务冲突**：激发与任务动作仲裁，安全优先级最高，占空比受限（< 3%）。

**定义 308（激发收益不等式）** ΔJ = ΔI(β)·V_β − c_R·Risk(q_ex) − c_W·Wear(q_ex)；仅 ΔJ > 0 才激发。

**定义 309（联合规范自由度，A95）** 所有模态共享同一缓变刚体偏移时 r_recip 不变、β 不可分；只能靠外部计量/重力/接触约束或独立模态打破——此自由度内不可解，必须显式声明。

```python
class ActiveExcitationProbe:
    def plan(self, state, beta_hat, Sigma_beta):
        if state.lam_risk < LAMBDA_PROBE or not state.safe: return None
        best = None
        for q_ex in design_dithers(reversals=2, amps=np.linspace(B_MIN, A_SAFE, 6)):

            if gain > 0 and (best is None or info > best.info):
                best = Probe(q_ex, info, gain)
        return best                                        # None ⇒ 不激发

# IP-255 HOD：不可吸收的结构指纹
def hysteresis_signatures(q, r_recip):
    return {'A_loop': abs(np.trapz(r_recip, q)),          # ℒ_Γ(r)=∮r·dq
            'deadband': estimate_deadband(q, r_recip),

    return attribute_transient_sensor(r_perp, U)          # H_sensor^trans / H_real
```

## 4. 推导

**引理 16（迟滞结构不可吸收——反吸收从带宽升级为结构）** 时不变标定 c 的残差 r_cal(c) 是保守场，任意闭合回路 ℒ_Γ(r_cal(c)) = ∮ r_cal·dq = 0。理想间隙 H_b 在 A_exc > b 时 A_loop = 4b(A_exc − b) > 0，单调于 b 与 A_exc。故 min_c |ℒ_Γ(r_recip − r_cal(c))| = A_loop > 0：**任何标定都无法把回路功能消为零**。系：R68「慢故障被标定吸收」在传动故障上被结构性阻断——吸收得了路径无关偏移，吸收不了路径依赖迟滞。

**引理 17（持续激发可辨识性——为什么必须动）** 静止/恒速段不换向，死区从未穿越，∂r_recip/∂b ≡ 0，I(b)=0，b 不可辨识；含 ≥2 次换向且 A_exc>b 的回路给出 I(b) ≥ I_min(A_exc−b)²/σ² > 0。**R68 静态自标定对间隙不是精度不足，而是原理不可辨识。**

**引理 18（激发–安全折衷）** SNR(A_exc) ≈ 4b(A_exc−b)/σ 随幅度单调增；Risk(A_exc) ≈ c_R A_exc² + c_W Wear(A_exc)。最优 A* = min(A_safe, argmax[SNR−Risk])，且仅当净收益 > 0 才激发。**不是越大越好，而是在安全包络内取信息–风险最优点。**

**定理 16（ARTIC-RAS 端到端风险一致性）** A87–A95 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_act`（α_act 受引理 16–17 限制）；
2. `(U_cal>τ_cal) ∨ (U_kin>τ_kin) ⇒ λ_risk ≥ 0.8 ∧ 前缀收缩`——任一路不确定只导向收紧；
3. 激发满足 Risk ≤ ε_probe 且仅在 𝒜_safe 内，引入额外风险 ≤ ε_probe；
4. canary 慢故障检出 ≥ 0.95，CAC† 有害适配器上线 ≤ 0.05·p_h。

**定理 17（慢故障不再隐形——正面关闭 R68 最大风险）** 传动退化只要 b ≥ b_min 且激发含 ≥2 次换向、A_exc > b，则 N ≤ Cσ²/(A_loop(A_exc)²)，T_detect = N·Δt **与故障变化率 ω_f 无关**——即使 ω_f ≪ ω_cal，迟滞回路面积仍然出现。故 R68「缓变故障落入标定带宽被吸收」的最大风险在**传动侧被结构性关闭**。边界：纯无记忆慢偏移仍属 𝒮_cal，靠 R68 反吸收界；全模态共模刚体漂移不可辨识（A95），需外接计量锚。

## 7. 本轮最大风险

**一句话**：ARTIC-RAS 的安全性押在「主动激发」这一新动作上——**探针本身可能加速关节磨损、在边界状态触发失稳，或被对手识别后「只在探测时表演正常」（probe-aware spoofing），从而把 R68 的「静观盲区」转移成 R69 的「动察表演窗口」；激发的信息收益越高，系统对探针真实性的依赖越致命。**

**次级风险与缓解**：激发安全（𝒜_safe + ε_probe 双门，越界即 k=0）；探针欺骗（激发溯源门校验「指令 vs 实际位姿变化」+ 随机化波形防重放）；β 过拟合噪声（I ≥ I_min 才更新 + 先验收缩）；规范自由度（共模刚体漂移显式报告，强制外接计量锚）；激发与任务冲突（安全优先级仲裁，占空比 < 3%）。
