# 第 43 轮（新循环第 3 轮） · 鲁棒创新挖掘机（RIM）：把创新点炼成带鲁棒半径的可证伪 Claim 证书（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。v19 的飞轮已经能「仿真验证 → 知识沉淀 → 边缘部署 → 偏移回流」，但它有两个未解的隐病：其一，**鲁棒性仍是平均意义**——域随机化测的是期望，W_1 迁移界给的是分布级而非逐状态级的保证，面对 UniBot 的五类泛化场景（位置/干扰物/背景/未见物品/人为干扰）仍可能在「没采样到的角落」静默失效；其二，**创新点是手写的**——清单靠人拍脑袋，缺少「可证伪、可复现、可排序」的机制，容易把「仿真里好看」误当成「隐藏测试里有效」。本轮灵感词「鲁棒性」「创新点挖掘」恰好互补：鲁棒性为创新提供**最坏情况证据**，创新点挖掘把鲁棒性漏洞变成**可排序的研究资产**。本轮核心命题：**每一个鲁棒性洞都是一个创新点，而每一个创新点都必须携带自己的鲁棒半径与证伪记录。**

## 0. 直觉与动机

**灵感 1（鲁棒性 → 从「平均安全」到「半径安全」）**：第 42 轮的 SCV 用域随机化跑万级轨迹，本质是在估计 E_{ξ∼D_sim}[m_ξ(x)] 与它的低分位。但安全是**最坏情况**问题：只要存在一个 ε-球内的扰动 δ 使边际跌破阈值，证书就在真实世界里失效，而这个 δ 可能概率极低、采样永远采不到。直觉的修正有三层：**（a）半径而非布尔**——不再只输出 safe/unsafe，而是输出「离失效还有多远」的鲁棒半径 ρ(x)，机器人可据此做「保守但可解释」的退让；**（b）最坏情况而非期望**——用对抗搜索直接最大化违约量，把「没采到」变成「主动去找」；**（c）分布鲁棒而非点分布**——用 Wasserstein 球代替单一 D_sim，把 W_1 迁移界从「事后修正系数 α_e」升级为「带有限样本置信的 DRO 边际下界」，从根上消除 α_e 靠手调的经验性。

**灵感 2（创新点挖掘 → 把失败证书当矿，把 Claim 当矿产品）**：现有创新点清单（v1–v19）是**人类先验的线性堆叠**，没有「挖掘算子」。直觉是：把研究产物建成一张**产物-假设图**（节点 = 模块/假设/Claim，边 = 依赖/矛盾/未验证），把反例集 Ξ、迁移界失效、误触发、可用性跌落当作「矿脉」；每个失败都定位到某条被违反的证书边与某个未被覆盖的假设，再从**变异库**（加传感器、换不变量、改损失权重、加数据增广、换表征、改课程相位）里生成候选修改 Δ，构成一条创新 Claim。关键不是「多提点子」，而是**证伪优先**：Claim 必须先通过预注册的证伪测试与鲁棒增益下界，才能进入「已认证」账本。这样创新点清单就从「散文」变成「可审计的资产表」。

**灵感 3（两者耦合 → 鲁棒性是创新的裁判，创新是鲁棒性的出口）**：鲁棒半径场给出**逐状态的证伪 oracle**：一个 Claim 声称「加了某模块后更安全」，就必须证明它在对抗扰动集下仍带来**正的鲁棒增益下界**，而不是平均值涨了、最坏情况掉了。反过来，鲁棒性分析会持续暴露「半径收缩区」，这些区域就是下一轮创新挖掘的输入。于是形成 **失败 → 挖矿 → 认证 → 部署 → 新失败** 的第二重飞轮，且这一重飞轮直接以「隐藏测试上的最坏情况」为目标函数，而不是以「论文好看」为目标函数。

**与 UniBot 赛题的对应**：五类泛化场景天然就是扰动集的五个轴 Δ_UniBot = Δ_pos ⊗ Δ_distract ⊗ Δ_bg ⊗ Δ_unseen ⊗ Δ_human；榜首成功率不足 30% 说明平均意义下的泛化已很难，**最坏情况**更是空白。鲁棒半径能告诉系统「在哪个场景轴上先崩」，创新挖掘则把「哪个轴最值得投入」按鲁棒增益/成本排序。这比继续堆 VLA 参数量更接近赛题的评分结构（平均成功率 + 步骤分，且隐藏测试就是一次分布偏移）。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（鲁棒半径场 RRF）**：对守卫边 e 的边际函数 m_e 与阈值 θ_e，定义逐状态鲁棒半径
ρ_e(x) = sup{ r ≥ 0 : ∀δ ∈ B_r(x) ∩ X_valid, m_e(x+δ) ≥ θ_e }，
其中 B_r 为证书相关特征空间（位置、速度、接触力、语义摘要）上的 r-球。若 m_e 为 L_m-Lipschitz，则 ρ_e(x) ≥ (m_e(x) − θ_e)/L_m。**鲁棒安全集** S_ρ = {x : ∀e, ρ_e(x) ≥ ρ_min}，把二值安全集升级为带裕度的分层安全集。ρ_e 由对抗搜索给出经验下界、由 Lipschitz 给出解析下界，取二者较小者保持 sound。

**定义 39（Wasserstein-DRO 鲁棒边际与有限样本半径）**：对证书敏感特征做 1D 投影 π，令经验分布为 D̂_N，取模糊集 P_ε = {Q : W_1(π_#Q, π_#D̂_N) ≤ ε}，定义
m_DRO(x) = inf_{Q∈P_ε} E_Q[m_ξ(x)] ≥ m̂_N(x) − L_m·ε （Kantorovich–Rubinstein 对偶）。
有限样本半径取 ε_N(δ) = C·sqrt(log(1/δ)/N)（1D 投影，DKW/分位过程），高维时退化为 O(N^{−1/d})。由此把 v19 的经验系数重写为**可计算**的
α_e = 1 + L_m·ε_N(δ)/θ_e，且该式给出「以概率 ≥ 1−δ 成立」的迁移保证，而非拍脑袋夹在 [1,3]。

**定义 40（对抗证书压力测试 ACST）**：给定扰动生成器 G_ψ 与允许集 Δ，求解
δ*_e(x) = argmax_{δ∈Δ} (θ_e − m_e(x+δ))，
用投影梯度/CMA-ES 在守卫面 g_e≈0 附近搜索，收集对抗反例集 Ξ_adv = {(x, δ*) : m_e(x+δ*) < θ_e}。定义**对抗覆盖率缺口** Ĝ_e = |Ξ_adv|/N_adv 与**鲁棒边际分位** m_rob,e = Quantile_{0.01}{m_e(x+δ*)}。ACST 与 v19 的随机域随机化是**互补**的：随机测广度，对抗测深度。

**定义 41（保形检索门 CRG）**：设校准集给出检索正确性非一致性分数 s_i(q)，取 q̂ = ⌈(n+1)(1−α)⌉/n 分位，构造预测集
C_α(q) = { template i : s_i(q) ≤ q̂ }。
在可交换性下 P(correct ∈ C_α(q)) ≥ 1−α。**门控规则**：仅当 |C_α(q)| ≤ k_max 且集合内模板对守卫方向「一致」（合取后不产生相反约束）时接受检索；否则弃权（abstain），退回 v19 的冷启动 CEGAR。这把「检索幻觉」从不可控风险降为**有覆盖保证的弃权**。

**定义 42（创新 Claim 与 Claim 证书 ICC）**：一条创新 Claim
c = (Δ, φ, ψ, G, Θ_exp, F_test, ρ_c)，
其中 Δ 为对方法/产物的修改，φ/ψ 为任务/环境指纹，G 为增益指标（成功率、步骤分、鲁棒半径、成本），Θ_exp 为实验扰动集（随机种子、数据划分、超参、仿真参数），F_test 为预注册证伪测试，ρ_c 为「增益对 Θ_exp 的鲁棒半径」。**Claim 证书** CC(c) = (E, S, LCB(G_rob), ρ_c, F_record)，其中
G_rob = inf_{θ∈Θ_exp} G(θ)，LCB(G_rob) = Ĝ_rob − sqrt(log(1/δ)/(2n))·Range(G)。
c **被认证**当且仅当 LCB(G_rob) > 0、ρ_c ≥ ρ_min、F_test 在留出的对抗划分上通过、且多重比较校正后 FDR ≤ 0.1。

**定义 43（创新挖掘算子与鲁棒创新账本）**：挖掘算子
M(KB, FailSet) → {c_i}，
流程为：**(a) 挖矿**——对每个失败/反例，定位被违反的证书边与假设，从变异库生成候选 Δ；**(b) 新颖性过滤**——对 KB 与文献嵌入做近邻去重 + Claim 图冲突检测，剔除已知项；**(c) 鲁棒评分**——RIS(c) = LCB(G_rob)·Novelty(c)·Feasibility(c) / Cost(c)；**(d) 组合选择**——在预算与多样性约束下用子模贪心最大化 Σ RIS。账本 L = {(c, CC, status)}，status ∈ {proposed, certified, falsified, retired}；认证采用**预注册证伪协议**（先锁种子/划分/指标，再跑；跨 Claim 用 Benjamini–Hochberg 控 FDR），防止「挖得越多、假阳性越多」的 p-hacking。

## 2. 四大产出设计（增量 IP-57/58/59/60 + 升级 IP-49/51/52/53/54/55/45/47）

### 2.1 IP-57 ROBUST-CERT-FIELD（鲁棒证书场 RCF）
1. **半径场构建**：对 L0 证书表的每个叶节点存 ρ_e 的解析下界；对高风险区（ρ 小、梯度大）用 ACST 做局部加密，得到「解析 + 经验」双下界。
2. **DRO 边际**：按定义 39 在证书敏感投影上估 ε_N，输出 m_DRO 与置信标签（置信度、样本量、投影维度）。
3. **分层安全集**：按 ρ 分档（Green/Yellow/Red），Yellow 触发「保守但仍执行」，Red 才降级，直接缓解 v19 的「可用性崩塌」。
4. **鲁棒半径热力图**：把 ρ 在 UniBot 五轴上分解，输出「哪个泛化轴最先崩」的可视化，供创新挖掘选靶。

### 2.2 IP-58 ADVERSARIAL-CERT-STRESS（对抗证书压力测试 ACS）
1. **对抗搜索器**：在守卫面附近用投影梯度 + CMA-ES 混合搜索；对离散语义扰动（背景/干扰物）用检索式替换 + 渲染回灌。
2. **反例去重与归因**：按「违反边 + 扰动轴 + 语义标签」聚类，保留最小反例（最接近守卫面者），入 KB Ξ_adv。
3. **鲁棒覆盖报告**：输出每边 Ĝ_e、m_rob,e、ρ 分布，作为 Claim 认证的证伪 oracle。
4. **攻击-防御共演化**：防御侧（加不变式/加传感器）上线后重跑 ACST，若旧反例被修复且新反例减少，记一次「鲁棒性增量」。

### 2.3 IP-59 INNOVATION-MINER（鲁棒创新挖掘机 RIM）
1. **产物-假设图**：从 KB、实验记录、失败集自动构图，边标依赖/矛盾/未验证。
2. **变异库**：结构化变异算子（表征、损失、数据、课程、守卫、组合），每个算子带「预期影响的证书边」。
3. **证伪优先认证**：Claim 进入账本前必须过预注册 F_test + 鲁棒增益下界 + BH-FDR；未过者标 falsified，保留为负知识。
4. **组合与修剪**：子模贪心选 Top-k 组合；每轮把低 RIS/被证伪项 retired，保持清单是「活账本」而非只增不减。

### 2.4 IP-60 CONFORMAL-RAG-GATE（保形检索门 CRG）
1. **保形校准**：用历史检索-正确性对训练非一致性分数，按 α 取分位；支持任务/环境分层的 Mondrian 保形。
2. **门控与弃权**：预测集过大或守卫方向冲突即弃权；弃权率作为一等指标上报。
3. **与 IP-55 集成**：检索结果附覆盖保证标签；KB 记录「适用域 + 校准集版本」，防止跨分布误用。
4. **偏移联动**：可交换性被破坏时（S_t 超阈值）自动重校准，避免「覆盖保证过期」。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| E94 鲁棒-成本 Pareto | 正鲁棒增益 Claim 数 vs COT；相对 v19 成本 | ≥ 8 条正增益；成本 ≤ 1.2x |

回退：E87 半径低估 → 提高 Lipschitz 保守度、扩大对抗搜索预算，或退回 v19 二值安全集；E88 DRO 界过松 → 降维投影/分层 DRO，否则退回经验 α_e；E89 覆盖不达标 → 弃权阈值收紧、只信高置信模板；E90 对抗无增量 → 保留随机 DR，ACST 仅做离线审计；E91/E92 挖掘质量差 → 关闭自动挖掘，改人类提案 + 自动证伪；E93 飞轮不收敛 → 锁定证书版本、人工选靶。

## 5. 本轮最大风险

**一句话**：RIM 把「鲁棒性证据」与「创新挖掘」耦合后，最大的风险是**自证循环（robustness theater）**——对抗扰动集 Θ_exp 与认证测试若都由同一套仿真/同一批种子生成，Claim 会在「自己出的题」上满分、在 UniBot 隐藏测试上归零，且账本的 FDR 控制只对「已建模的扰动」有效；因此 E90（对抗发现的独立失效）与 E92（跨种子/跨扰动存活）必须作为红线，任何一项不达标即停止自动认证、退回人工证伪。

# 第 43 轮产物 · 创新点清单 v20：鲁棒创新挖掘机（RIM）× 对抗证书场 × 保形检索门（四层架构 v8）

> 承接第 42 轮产物 v19。本轮**增量插入** IP-57/58/59/60，并升级 IP-49/51/52/53/54/55/45/47；不推倒任何既有层级。核心是把 v19 的「平均安全 + 手写创新」升级为「半径安全 + 可证伪创新」：鲁棒性提供逐状态的最坏情况证据，创新挖掘把鲁棒性洞变成带鲁棒半径与证伪记录的 Claim 资产。

### IP-57 RCF：鲁棒半径场与 DRO 边际
```
def robust_radius_field(cert_table, L_m, X_probe, theta):
    R = {}
    for leaf in cert_table.leaves:
        x = leaf.center
        # 解析下界（sound）：m 为 L_m-Lipschitz
        rho_analytic = max(0.0, (leaf.m_lo - theta) / max(1e-6, L_m))
        # 对抗经验下界（更紧）：沿证书敏感方向做半径二分
        rho_adv = adversarial_radius_search(x, leaf.margin_fn, theta,
                                            directions=sensitive_dirs(x),
                                            budget=64)
        R[leaf.key] = min(rho_analytic, rho_adv)  # 取小保 sound
    return R

def adversarial_radius_search(x, margin_fn, theta, directions, budget):
    # 对每个方向 u，二分找最大 r 使 m(x + r·u) >= theta；取最小者
    best = float('inf')
    for u in directions[:budget]:
        lo, hi = 0.0, R_MAX
        if margin_fn(x + hi * u) >= theta:
            best = min(best, hi); continue
        for _ in range(20):                    # ~1e-6 精度
            mid = 0.5 * (lo + hi)
            if margin_fn(x + mid * u) >= theta: lo = mid
            else: hi = mid
        best = min(best, lo)
    return best

def dro_margin(samples_proj, L_m, delta=1e-3):
    # 证书敏感特征的 1D 投影样本
    n = len(samples_proj)
    eps_N = C_DKW * math.sqrt(math.log(1.0 / delta) / n)
    m_hat = empirical_mean(samples_proj)
    return m_hat - L_m * eps_N, eps_N          # (m_DRO, 置信半径)

def robustness_tier(rho, rho_min):
    if rho >= 2 * rho_min: return 'Green'
    if rho >= rho_min:     return 'Yellow'
    return 'Red'
```

### IP-58 ACS：对抗证书压力测试
```
def adversarial_stress(H, D_sim, N_adv=2000, delta_budget=0.1):
    results = {}
    for e in H.E:
        # 初始点：守卫面附近 + 随机域随机化
        X0 = near_guard_samples(H, e, N_adv // 2)
        X0 += domain_random_sample(D_sim, N_adv // 2)
        adv = []
        for x in X0:
            # 连续扰动：PGD 最大化违约量；离散语义：检索式替换后渲染回灌
            d_cont = pgd_maximize(x, lambda z: H.theta[e] - H.margin(e, z),
                                  eps=delta_budget, steps=30)
            d_sem = semantic_swap(x, H.env)     # 背景/干扰物/纹理替换
            for d in (d_cont, d_sem):
                z = x + d
                if H.margin(e, z) < H.theta[e]:
                    adv.append((x, d, H.margin(e, z)))
        adv = min_counterexamples(adv)          # 保留最接近守卫面者并去重
        results[e] = {
            'Xi_adv': adv,
            'G_hat': len(adv) / N_adv,
            'm_rob': quantile([m for _, _, m in adv], 0.01) if adv else H.margin(e, X0),
            'robust_radius': min(adversarial_radius_search(x, H.margin_fn(e), H.theta[e], sensitive_dirs(x)) for x in X0),
        }
    return results
```

### IP-59 RIM：鲁棒创新挖掘与证伪认证
```
def mine_innovations(KB, FailSet, budget, seed_set):
    # (a) 挖矿：失败 -> 被违反的证书边/假设 -> 候选修改
    graph = build_artifact_hypothesis_graph(KB, FailSet)
    candidates = []
    for f in FailSet:
        edge = localize_violated_edge(graph, f)
        for delta in mutation_library(edge):          # 表征/损失/数据/课程/守卫/组合
            candidates.append(Claim(delta=delta, phi=f.phi, psi=f.psi,
                                    target_edge=edge, expected_gain=estimate_gain(delta, f)))
    # (b) 新颖性过滤
    candidates = [c for c in candidates
                  if novelty(c, KB, graph) >= 0.5 and not conflicts_known(c, graph)]
    # (c) 预注册证伪 + 鲁棒评分
    certified = []
    for c in candidates:
        c.F_test = pre_register_falsification(c)       # 先锁种子/划分/指标
        G_rob, rho_c = robust_gain(c, c.F_test, seed_set)   # inf over Theta_exp
        c.CC = ClaimCertificate(
            LCB=lower_confidence_bound(G_rob, n=c.F_test.n, delta=1e-3),
            rho=rho_c,
            F_record=run_falsification(c.F_test))
        c.RIS = c.CC.LCB * novelty(c, KB, graph) * feasibility(c) / cost(c)
        if c.CC.LCB > 0 and c.CC.rho >= RHO_MIN and c.CC.F_record.passed:
            certified.append(c)
    # (d) 组合选择（预算 + 多样性，子模贪心）+ BH-FDR
    selected = submodular_greedy(certified, budget=budget, diversity=claim_diversity)
    selected = benjamini_hochberg(selected, q=0.1)
    ledger_update(KB, proposed=candidates, certified=selected)
    return selected

def robust_gain(claim, F_test, seed_set):
    gains, rhos = [], []
    for theta in experiment_perturbations(F_test):      # 种子/划分/超参/仿真参数
        g = evaluate_gain(claim.delta, theta)
        gains.append(g)
        rhos.append(gain_radius(claim.delta, theta))    # 增益符号保持的半径
    return min(gains), min(rhos)                        # 最坏情况，而非平均

def pre_register_falsification(claim):
    return FalsificationTest(
        seeds=lock([0, 1, 2]),
        splits=lock(['train', 'val', 'adversarial_holdout']),
        metrics=lock(['success_rate', 'step_score', 'robust_radius', 'COT']),
        pass_condition=lambda r: r.robust_gain_lcb > 0 and r.radius >= RHO_MIN)
```

### IP-60 CRG：保形检索门

```
def conformal_gate(query, KB, calib_scores, alpha=0.1, k_max=3):
    n = len(calib_scores)
    q_hat = quantile(calib_scores, math.ceil((n + 1) * (1 - alpha)) / n)
    # 取非一致性分数 <= q_hat 的模板集合
    C_alpha = [t for t in KB.retrieve(query, k=n)
               if nonconformity(query, t) <= q_hat]
    if len(C_alpha) > k_max:
        return None, 'abstain_set_too_large'
    if guards_conflict([t.guard for t in C_alpha]):
        return None, 'abstain_guard_conflict'
    return merge_templates(C_alpha), 'accept'

def recalibrate_on_drift(calib_set, S_t, tau_drift):
    if S_t > tau_drift:                 # 可交换性可能被破坏
        return collect_new_calibration(calib_set)   # 偏移后重校准，防覆盖过期
    return calib_set
```

## 6. 本轮最大风险

**一句话**：RIM 把「鲁棒性证据」与「创新挖掘」耦合后，最大的风险是**自证循环（robustness theater）**——对抗扰动集 Θ_exp 与认证测试若都由同一套仿真/同一批种子生成，Claim 会在「自己出的题」上满分、在 UniBot 隐藏测试上归零，且账本的 FDR 控制只对「已建模的扰动」有效；因此 E90（对抗发现的独立失效）与 E92（跨种子/跨扰动存活）必须作为红线，任何一项不达标即停止自动认证、退回人工证伪。
