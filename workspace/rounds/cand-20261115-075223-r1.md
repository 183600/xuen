# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；本轮灵感：「论文发表」×「位姿估计」）

> R69 把不确定性拆成 aleatoric / epistemic，并给 epistemic 配了嘴：看、问、触。但它有一个未言明的前提：**模态权重与 VoI 是由同一个可能失准的模型自报的**。它自陈的最大风险正是「模态分布不可信 → 自信地追问一个幻影 / 把一个误导性回答盖上『已验证』的章」。缺的不是又一个大模型，而是一套**判定「一个信念何时配得上被行动」的程序**——也就是科学共同体用了两百年的证据纪律。
>
> 本轮两个灵感正好给出实例与制度：
> - **位姿估计**提供可测的规范实例：对称、无纹理、遮挡会让位姿在 SE(3) 上真正多峰；更关键的是，其中一部分多峰是**规范（gauge）**——由物体对称性产生、任何观测都不可分、也不影响任务，把它当 epistemic 去「问」是纯粹浪费；
> - **论文发表**提供制度：预注册、独立同行评审、复现、文件抽屉校正、FDR、撤稿、元评审——以及它自身的病理（发表偏倚、HARKing、评审共谋、范式俘获）。
>
> 核心命题：**把每个位姿假设当成一篇稿件；只有通过「预注册 + 独立评审 + 复现 + FDR 控制」的稿件才可「发表」（写入记忆、驱动不可逆动作）；用任务对称商把不可观测且不相关的歧义从 epistemic 中剔除；用文件抽屉校正抵消记忆的发表偏倚；并保留撤稿通道。** 命名 **PEER-RAS**（Pre-registered Epistemic Evidence Review：预注册证据评审的位姿假设闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我这个信念，够格被发表吗**」——不确定性不仅决定动作，也决定一个结论配不配进入记忆与行动。

## 0. 直觉与动机

**灵感 1（位姿估计 → 歧义有精确几何，且对称不等于不确定）**
直觉：R69 的「模态」是抽象的聚类结果；在位姿估计里它是可写的：圆柱绕轴连续对称、方盒有 90° 旋转对称、无纹理物体有前后翻转、遮挡会产生离散分支。两个位姿若只差一个**保持任务不变的对称变换**（例如抓取圆柱时绕轴旋转），它们在物理上不可区分、任务上等价——这是**规范自由度**，不是不确定性。若把这种分支计入 U_epi，系统会花预算去「看」一个永远看不出、且看了也没用的差别。位姿估计因此给 R69 的二分补上第三刀：**gauge（忽略）/ 可分辨 epistemic（值得问）/ 不可分辨 epistemic（只能保守或换模态）**。

**灵感 2（论文发表 → 信念需要证据纪律，而不是更大的模型）**
直觉：科学不是「谁模型大谁对」，而是一套**限制自我欺骗**的程序：先注册假设再看数据（反 HARKing），让独立的人来挑错（反确认偏误），换条件重做（反过拟合），连失败一起记录（反发表偏倚），批量发表时控制假发现率。机器人恰好需要同一套东西：它的位姿信念会进入记忆、训练集和不可逆动作，一旦「发表」就很难收回。把发表制度搬进闭环，等于给 R69 的「问」装上一个**编辑部**：不是问完就信，而是问完还要过审。

**灵感 3（预注册 → 把 VoI 变成可证伪的预测）**
直觉：R69 的 VoI 是模型自己算的期望信息增益，没有任何东西检验它算得准不准。预注册改变这一点：在做出信息动作之前，先把「每个假设下我预期会看到什么」写进只追加的哈希账本；动作完成后，用预注册的对数评分检验预测。**若实际增益系统性低于预注册值，说明模型的「好奇心」过度自信**，应缩减交互预算并重校准。这把「问得值不值」从一个自报指标变成一个可被数据打脸的预测——也是反 HARKing 的机制：不能看完结果再挑一个「我早就想验证」的解释。

**灵感 4（同行评审 → 独立性比人数重要，Reviewer 2 是最强反假设）**
直觉：R69 要求「k 个正交证据源一致」，但没定义「正交」。若五个评审都用同一个主干网络、同一份训练集、同一个 CAD 模型，他们的错误高度相关，k 个等于一个。正确的量是**有效评审人数 k_eff**（由评审间错误相关系数折减）。而「Reviewer 2」的制度价值在于：它被要求构造**最强的替代假设**并计算 Bayes 因子——对对称物体，这个替代假设就是对称等价的另一个位姿。若最强反假设无法被证据压过，稿件只能「大修」，不能发表。

**灵感 5（发表偏倚与文件抽屉 → 记忆会系统性乐观）**
直觉：如果系统只把「验证成功」的位姿写进记忆与训练集，被拒的、矛盾的、没下文的假设全被丢掉，那么它学到的世界分布是**经过选择**的：越容易被验证的位姿越常出现，难验证的（恰是最需要学的）被系统性删除。这就是发表偏倚 / 文件抽屉问题。后果不是一次错，而是**校准随时间的单调乐观漂移**。因此必须保留「拒稿档案」，用逆倾向重加权或 trim-and-fill 式补回缺失模态，并检测提交分布与发表分布的漏斗不对称。

**灵感 6（FDR 与撤稿 → 批量发表要控假发现，发表不是终审）**
直觉：一个场景里同时评估几十个物体/分支，逐个用 p<0.05 发表，假发现会累积。Benjamini–Hochberg 把「已发表位姿中假货的期望比例」压到 q 以下——这给出一个**不依赖模态权重是否校准**的错误发表率上界，正好绕开 R69 最脆弱的前提。同时，发表不是终审：任何后续矛盾都应触发**撤稿**，并从记忆与训练缓冲中传播删除；否则错误会被复利。

**灵感 7（双刃剑 → 评审制度本身是攻击面）**
直觉：会评审的系统也会被评审俘获：提交方可「切香肠」拆成多篇低质量稿件刷发表量；评审方可共谋放水；对手可污染基准让所有评审一起错；甚至可以伪造一个「审稿人意见」诱导系统撤掉正确位姿（DoS）。所以 ℰ_PEER 必须把学术不端当成一等威胁，而不是隐喻。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PEER-RAS 总览）** PEER-RAS = (SYMQ, PREG, EDTR, REV2, REP, FDX, FDRP, NBVS, RRG, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **发表门**：任何驱动不可逆动作（抓取闭合、插入、越障承诺）的位姿断言必须是 published 状态；preprint 只能驱动可逆动作（看、悬停、慢速接近）；
(iii) **不可单独定案**：published 需 k_eff ≥ 2 的独立证据 + 复现率达标 + FDR 通过；单源只能 preprint；
(iv) **可撤稿**：任何后续矛盾必须能回溯到已发表断言并将其降级、传播删除。

**定义 311（任务对称商与歧义三分）** 位姿空间 𝒫 = SE(3)。物体对称群 G_obj ≤ SE(3)；任务相关对称子群 G_task = {g ∈ G_obj : 任务函数 J(g·T) = J(T)}。商空间 𝒫/G_task 的元素是**可区分位姿类**。对假设对 (T_i, T_j)，令 g = T_j T_i^{-1}：
- g ∈ G_task：**gauge 歧义**，不可观测且任务等价，U_gauge 不计入任何通道；
- g ∈ G_obj \ G_task 且 ∃ 可用模态 o 使 p(o|T_i) ≠ p(o|T_j)：**可分辨 epistemic**，进 U_epi^res，可被信息动作消解；
- g ∈ G_obj \ G_task 但对当前可用动作集 𝒜_info 不可观测：**不可分辨 epistemic**，进 U_epi^unres，只能保守或等待新模态（触觉可把 unres 转 res）。
故 U = U_ale + U_epi^res + U_epi^unres + U_gauge，四者分通道处置，不做标量加和。

**定义 312（位姿稿件）** 每个估计器/假设提交稿件 M_k = (T_k, Σ_k, 方法 id, 证据集 E_k, 局限 L_k, 预注册哈希 h_k, 对称类 [T_k])。稿件不是结论，而是**待审主张**。

**定义 313（预注册账本 PREG）** 在执行信息动作 g 之前，对每个存活假设 k 提交预测分布 p_k(·|g) 与其哈希，写入只追加账本 ℒ_pre。执行后观测 y，计算预注册对数评分 S(y) = −log Σ_k w_k p_k(y|g)。**动作后不得修改 p_k**。

**定义 314（预注册后悔与好奇心校准）** 预测增益 Ĝ = H(w) − E_{y~Σ_k w_k p_k}[H(w|y)]；实现增益 G = H(w) − H(w|y)。预注册后悔 R_pre = |Ĝ − G|。在滑动窗口上若 E[R_pre] > τ_pre 或符号系统性偏正（高估），则缩小交互预算、重校准 VoI 头；这与 R69 MCG 的模态校准门并列，但校准的是**好奇心本身**。

**定义 315（独立性审计与有效评审人数）** 评审源 i,j 的历史错误相关 ρ_ij（在同一标定集上的残差相关）。设计效应 k_eff = k / (1 + (k−1) ρ̄)，ρ̄ 为平均相关。RRG 要求 k_eff ≥ 2，而不是 k ≥ 2。共享主干/训练集/CAD 的源必须显式声明相关性，不得当作独立评审。

**定义 316（对抗评审 REV2 与 Bayes 因子）** 给定领先假设 h*，REV2 在存活假设中求最强替代 h† = argmax_{h≠h*} p(h|E)。证据 Bayes 因子 BF = p(E|h*)/p(E|h†)。若 BF < τ_BF ⇒ 稿件「大修」：不得 published，转 preprint 或触发对称破除动作。对对称物体，h† 通常是对称等价位姿。

**定义 317（复现协议 REP）** 扰动族 𝒟_nuis = {视角抖动、光照、传感器丢帧、时间偏移、触觉重探}。复现成功：d_SE3(T,T') ≤ κ·σ 且分支身份不变。复现率 ρ_rep = 成功扰动数 / 总扰动数。published 要求 ρ_rep ≥ ρ_min；复现失败是「结果不稳健」，不是「再算一次取平均」。

**定义 318（文件抽屉校正 FDX）** 设发表倾向 p_pub(h)（假设被提交/保留的概率）。观测记忆权重 w_obs ∝ w_true·p_pub。逆倾向校正 ŵ_true ∝ w_obs / p_pub。p_pub 未知时给出偏差界并据此**膨胀 U_epi**（宁可承认「我的记忆是选择性的」）。被拒/矛盾假设进入拒稿档案 ℱ_rej，不得删除。

**定义 319（发表偏倚检测 PBD）** 比较提交集与发表集在「效应量」（如位姿置信 vs 实际误差、分支支持度）上的分布；用漏斗图不对称 / 选择模型检验是否存在系统性缺失。检测到偏倚 ⇒ 触发 FDX 补回 + U_epi 膨胀 + 审计告警。

**定义 320（FDR 控制发表 FDR-P）** 一批 N 个位姿主张，每个有零假设「该位姿与观测一致」的 p 值（共形/置换检验）。用 Benjamini–Hochberg 在水平 q 下决定哪些可 published。则已发表集合中假发现的期望比例 ≤ q（在独立性/PRDS 下）。q 是**安全参数**，不是统计装饰。

**定义 321（对称破除主动获取 NBV-Sym）** 升级 R69 MINT：候选信息动作 g 的价值 = 在商空间 𝒫/G_task 上对**可分辨 epistemic** 的期望熵减，减去成本；gauge 方向上的信息增益恒记为 0。优先选择能打破 G_obj \ G_task 的视角/触觉探针。若没有任何动作能提高可分辨性（unres 全为不可分辨），VoI = 0，直接走保守。

**定义 322（断言生命周期与注册报告门 RRG）** 状态 ∈ {submitted, preprint, published, retracted, rejected}。RRG：published ⇔ k_eff ≥ 2 ∧ ρ_rep ≥ ρ_min ∧ BF ≥ τ_BF ∧ FDR 通过 ∧ 预注册完整。preprint 只能驱动可逆动作；retracted 触发记忆与训练缓冲的传播删除；rejected 回退到几何安全集（R69 保守）。

**定义 323（证书 J_PEER）** J_PEER = (J_FLUID, symmetry_class, k_eff, BF, ρ_rep, R_pre, fdr_q, fdx_bias, claim_state, retraction_epoch, peer_ver)。Valid ⇔ Valid(J_FLUID) ∧ 发表门满足。

**定义 324（威胁模型 ℰ_PEER）** ℰ_PEER = ℰ_FLUID × ℰ_academic，其中 ℰ_academic = {HARKing / 事后选假设、p-hacking、评审共谋（相关错误）、基准污染（所有评审共享同一错先验）、香肠切片（拆分低质稿件刷量）、伪造审稿意见诱导撤稿（DoS）、CAD/对称模型版本漂移}。

**定义 325（元评审与评审校准）** 对编辑部本身做校准：评审间信度（Krippendorff α）、编辑后验 ECE、发表偏倚强度、撤稿率、评审延迟。元评审结论回灌 RRG 阈值与 k_eff 估计；评审过程不可信时，RRG 自动收紧到「只 preprint」。

**定义 326（两级退避与实时 SLA）** 评审不得阻塞控制：给定 SLA τ_sla，超时默认降级为 preprint（可逆动作）而非等待。若 claim_state ∈ {preprint, retracted, rejected} 或评审不可信：λ = λ_floor(U_ale + U_epi^res + U_epi^unres)（等同 R69 兜底）；若 published：λ = λ_floor(U_ale)，获得 resolution bonus。安全侧永不弱于 R69。

## 2. 关键算法骨架

```python
# IP-264 SYM-Q：任务对称商 + 歧义三分（gauge / epi_res / epi_unres）
def quotient_and_classify(hyps, task, G_obj, A_info):
    cls = {}
    for i, h in enumerate(hyps):
        g = h.T @ hyps[0].T.inverse()
        if in_group(g, G_obj):
            if task_invariant(g, task):     cls[i] = 'gauge'
            elif observable(g, A_info):     cls[i] = 'epi_res'
            else:                           cls[i] = 'epi_unres'
        else:
            cls[i] = 'epi_res'
    return cls

# IP-265 PREG：动作前预注册预测，动作后只评分、不回改
def commit_and_execute(g, obs, modes):
    pre = {k: predict_obs(modes[k], g) for k in modes}
    ledger.append(hash(pre))                      # 只追加账本
    y   = execute_info_action(g, obs)
    S   = -logsumexp([log(w[k]) + pre[k].logp(y) for k in modes])
    return S, realized_gain(modes, y)             # 实现增益用于好奇心校准

# IP-266 EDTR：编辑部聚合（按独立性折减，不按人数）
def effective_reviewers(sources):
    rho = estimate_error_correlation(sources)     # 历史残差相关
    k, rbar = len(sources), mean_offdiag(rho)
    return k / (1 + (k - 1) * rbar)               # k_eff

# IP-267 REV2：最强反假设的 Bayes 因子
def rev2(hyps, evidence):
    h_star = max(hyps, key=posterior)
    h_dag  = max((h for h in hyps if h is not h_star), key=posterior)
    return bayes_factor(evidence, h_star, h_dag)

# IP-268 REP：扰动静默复现（不是重复取平均）
def replicate(estimator, T, n=8):
    ok = 0
    for pert in nuisance_family(n):
        T2 = estimator(pert)
        ok += (pose_dist(T, T2) <= KAPPA * sigma(T)) and same_branch(T, T2)
    return ok / n

# IP-270 FDR-P：批量发表用 BH 控假发现
def fdr_publish(claims, q=0.05):
    p = sorted(c.p for c in claims); m = len(p)
    k = max([i for i in range(1, m + 1) if p[i-1] <= i / m * q], default=0)
    return {c for c in claims if c.p <= p[k-1]} if k else set()

# IP-269 FDX：逆倾向补回被文件抽屉删掉的模态
def fdx_correct(w_obs, p_pub):
    return normalize({k: w_obs[k] / max(p_pub[k], EPS) for k in w_obs})

# IP-276 主闭环（评审不阻塞控制；超时默认 preprint）
def PEER_RAS_round(M, obs):
    hyps = M.fmp.sample(...)                      # R69 多模态位姿/动作假设
    cls  = quotient_and_classify(hyps, M.task, M.G_obj, M.A_info)
    U_ale, U_res, U_unres = split_uncertainty(hyps, cls)
    # 1) 只对可分辨 epistemic 预注册并交互；gauge 的 VoI 恒为 0
    g = M.nbvs.choose(hyps, cls, M.budget) if U_res > TAU else None
    if g is not None:
        S, G = M.preg.commit_and_execute(g, obs, hyps)
        M.meta.update_curiosity_regret(S, G)
    # 2) 编辑部：有效评审人数 + 对抗评审 + 复现
    ms    = [M.edtr.manuscript(h, obs) for h in hyps]
    k_eff = effective_reviewers(M.edtr.sources)
    bf    = rev2(hyps, obs)
    rrep  = replicate(M.estimator, best(hyps))
    # 3) FDR 批量门 + 发表偏倚校正
    pub   = fdr_publish(ms, q=M.fdr_q)
    w     = fdx_correct(mode_weights(hyps), M.p_pub)
    state = M.rrg.decide(k_eff, bf, rrep, pub, M.preg.complete)
    if M.sla.timeout(): state = 'preprint'        # 评审不得阻塞控制
    # 4) 生命周期 → 风险缩放（安全侧不弱于 R69）
    lam = lam_floor(U_ale + (0.0 if state == 'published' else U_res + U_unres))
    A = M.ach.propose(...); k = M.c_ras_wm.certified_prefix(A, ...)
    M.vqa_p.submit_async(ms, k_eff, bf, rrep, state)
    return k, lam, state, (U_ale, U_res, U_unres)
```

## 3. 推导

**引理 19（任务对称商下无免费信息）** 设 g ∈ G_task。则对任意可用模态 o 有 p(o|T) = p(o|gT)，且 J(gT) = J(T)。故任何信息动作在 g 方向上的期望信息增益恒为 0：VoI_gauge ≡ 0。若把 gauge 熵 H_gauge 计入 U_epi，则 R69 的交互预算至少被浪费 H_gauge / H_mode 的比例，且不会带来任何任务收益。系：**先商化，再问；不可观测且不相关的歧义应被删除，而不是被消解。**

**引理 20（预注册抑制 HARKing 膨胀）** 若动作后允许在 m 个候选解释中挑选一个最吻合者，则表观证据/增益最多可被抬高 log m（次高斯情形约 √(2 log m)）；预注册把可选集合固定为 m=1，故 R_pre 是「模型好奇心误差」的无偏估计。系：**没有预注册的 VoI 不是信息增益，而是事后叙事。**

**引理 21（FDR 控制不依赖模态校准）** 在独立性或 PRDS 下，BH 程序在水平 q 给出的 FDR ≤ q，与模态权重 w_k、ECE 是否准确无关。故「已发表位姿中错误者的期望比例」≤ q，即使 R69 的模态分布完全失准。系：**用多重检验的分布无关保证，替换掉「模态权重可信」这一脆弱前提**——这是对 R69 最大风险的正面回应。

**引理 22（文件抽屉偏差界）** 若发表倾向有下界 p_pub(h) ≥ p_min > 0，则观测记忆分布与真实分布的全变差 ≤ 1 − p_min；逆倾向重加权 ŵ ∝ w_obs / p_pub 无偏。p_pub 未知时，以该上界膨胀 U_epi，可保证退避方向仍是保守的。系：**记忆的选择性必须被显式建模，否则校准会随「只记成功」单调乐观。**

**定理 18（PEER 严格包含 R69）** 在 A95–A99 下：(a) 当所有断言处于 {preprint, rejected, retracted} 或评审不可信时，λ = λ_floor(U_ale + U_epi^res + U_epi^unres)，与 R69 在去掉 gauge 后的兜底逐指令一致；(b) gauge 方向任务敏感度为零（引理 19），故删除 gauge 不增加任务风险；(c) published 时 λ = λ_floor(U_ale) ≤ R69 的 λ，获得 resolution bonus 而安全侧不弱化。故 PEER 的期望任务风险 ≤ R69，且 R69 是「全部拒稿」边界。

**定理 19（评审俘获上界）** 设 k 个评审的两两错误相关为 ρ̄，则 k_eff = k / (1 + (k−1)ρ̄) ≤ 1/ρ̄。当 ρ̄ → 1 时 k_eff → 1，无论增加多少同范式评审都无法满足 RRG；此时唯一出路是引入**机械正交**的通道（不同物理量、不同先验来源）或范式留出集。故：**增加评审人数不能治愈共同盲点，只有改变评审的物理基础才行。**

## 6. 本轮最大风险

**一句话**：PEER-RAS 的全部证据纪律都假设「评审之间至少存在一个机械正交的通道」——**若所有通道共享同一个范式错误（同一份错 CAD、同一个被污染的基准、同一个对称模型版本），则 k_eff → 1，预注册、复现、FDR 会一起通过，系统会把错误位姿以一张完整证书「发表」；同行评审不能治愈范式错误，只会把它制度化为共识**。

**次级风险与缓解**：
1. **评审共谋/共享主干** → k_eff 独立性折减 + 机械正交通道（触觉/力觉）强制入审 + E304/E311；
2. **发表偏倚导致记忆乐观** → 拒稿档案 + 逆倾向校正 + 漏斗检测 + U_epi 膨胀（引理 22）；
3. **预注册流于形式（预测太宽）** → 预测必须可检验（对数评分/区间覆盖）+ 好奇心校准门；
4. **评审阻塞实时控制** → SLA + 超时默认 preprint + 不可逆动作前的异步评审；
5. **撤稿传播不彻底** → retraction_epoch 版本化 + 训练缓冲反向索引 + E310；
6. **学术不端刷量/DoS** → 香肠切片检测（相似稿件聚类）+ 伪造审稿签名校验 + 元评审。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** PEER-RAS 由九组件构成；实时流零学习写操作继承 R68；**发表门**（不可逆动作只认 published，preprint 只能可逆动作）；**不可单独定案**（k_eff ≥ 2 + 复现 + FDR）；**可撤稿**（矛盾可回溯降级并传播删除）。

**定义 311（任务对称商与歧义三分）** `G_task = {g ∈ G_obj : J(gT)=J(T)}`；对位姿对令 `g=T_jT_i^{-1}`：`g∈G_task` 为 gauge（忽略）；`g∈G_obj\G_task` 且可用模态可分辨为 `U_epi^res`（值得问）；同集合但当前动作集不可观测为 `U_epi^unres`（保守/换模态，触觉可转 res）。四类分通道，不做标量加和。

**定义 312–313（稿件与预注册）** 每个估计器提交稿件 `M_k`；信息动作前把 `p_k(·|g)` 哈希写入只追加账本，动作后只评分 `S(y) = −log Σ_k w_k p_k(y|g)`，不得回改。

**定义 314（好奇心校准）** `R_pre = abs(Ĝ − G)`；窗口内系统性高估 ⇒ 缩小交互预算、重校准 VoI 头（与 R69 MCG 并列，但校准对象是好奇心）。

**定义 315（独立性与 k_eff）** `k_eff = k/(1+(k−1)ρ̄)`；RRG 要求 `k_eff ≥ 2`。共享主干/训练集/CAD 的源必须声明相关，不得冒充独立评审。

**定义 316（REV2）** `h† = argmax_{h≠h*} p(h|E)`，`BF = p(E|h*)/p(E|h†)`；`BF < τ_BF` ⇒ 大修，不得发表；对称物体的 `h†` 即对称等价位姿。

**定义 317（复现）** 扰动族 `𝒟_nuis`；成功 ⇔ `d_SE3 ≤ κσ` 且分支不变；`ρ_rep ≥ ρ_min` 才可发表。复现失败是「不稳健」，不是「再算一次取平均」。

**定义 318–319（文件抽屉与偏倚检测）** `w_obs ∝ w_true·p_pub`；逆倾向 `ŵ ∝ w_obs/p_pub`；未知时按偏差界膨胀 `U_epi`。比较提交集/发表集效应量分布的漏斗不对称，检出即补回并告警。

**定义 320（FDR-P）** 对 N 个「位姿与观测一致」的 p 值做 BH(q)；已发表集合期望假发现比例 ≤ q（独立性/PRDS 下）。q 为安全参数。

**定义 321（NBV-Sym）** 信息动作价值 = 商空间上可分辨 epistemic 的期望熵减 − 成本；gauge 方向增益恒 0；无可分辨增益则 VoI=0，直接保守。

**定义 322–323（生命周期与证书）** published ⇔ `k_eff≥2 ∧ ρ_rep≥ρ_min ∧ BF≥τ_BF ∧ FDR 通过 ∧ 预注册完整`；preprint 只驱动可逆动作；retracted 传播删除；J_PEER 并入对称类、k_eff、BF、ρ_rep、R_pre、fdr_q、fdx_bias、claim_state。

**定义 324–325（威胁与元评审）** `ℰ_PEER = ℰ_FLUID × ℰ_academic`；元评审校准评审信度 α、编辑后验 ECE、发表偏倚、撤稿率、延迟，不可信时 RRG 收紧到「只 preprint」。

**定义 326（退避与 SLA）** 评审不阻塞控制；超时默认 preprint。非 published ⇒ `λ=λ_floor(U_ale+U_epi^res+U_epi^unres)`（R69 兜底）；published ⇒ `λ=λ_floor(U_ale)`（resolution bonus）。

```python
# IP-264 SYMQ：任务对称商 + 歧义三分
def quotient_and_classify(hyps, task, G_obj, A_info):
    cls = {}
    for i, h in enumerate(hyps):
        g = h.T @ hyps[0].T.inverse()
        if in_group(g, G_obj):
            if task_invariant(g, task): cls[i] = 'gauge'
            elif observable(g, A_info): cls[i] = 'epi_res'
            else:                       cls[i] = 'epi_unres'
        else:                           cls[i] = 'epi_res'
    return cls

# IP-265 PREG：动作前预注册，动作后只评分
def commit_and_execute(g, obs, modes):
    pre = {k: predict_obs(modes[k], g) for k in modes}
    ledger.append(hash(pre))                    # 只追加，不回改
    y = execute_info_action(g, obs)
    S = -logsumexp([log(w[k]) + pre[k].logp(y) for k in modes])
    return S, realized_gain(modes, y)

# IP-266 EDTR：按独立性折减的有效评审人数
def effective_reviewers(sources):
    rho = estimate_error_correlation(sources)
    k, rbar = len(sources), mean_offdiag(rho)
    return k / (1 + (k - 1) * rbar)

# IP-267 REV2：最强反假设
def rev2(hyps, evidence):
    h_star = max(hyps, key=posterior)
    h_dag  = max((h for h in hyps if h is not h_star), key=posterior)
    return bayes_factor(evidence, h_star, h_dag)

# IP-268 REP：扰动复现
def replicate(estimator, T, n=8):
    ok = 0
    for pert in nuisance_family(n):
        T2 = estimator(pert)
        ok += (pose_dist(T, T2) <= KAPPA * sigma(T)) and same_branch(T, T2)
    return ok / n

# IP-270 FDRP：BH 批量发表
def fdr_publish(claims, q=0.05):
    p = sorted(c.p for c in claims); m = len(p)
    k = max([i for i in range(1, m+1) if p[i-1] <= i/m*q], default=0)
    return {c for c in claims if c.p <= p[k-1]} if k else set()

# IP-269 FDX：逆倾向补回缺失模态
def fdx_correct(w_obs, p_pub):
    return normalize({k: w_obs[k] / max(p_pub[k], EPS) for k in w_obs})

    A = M.ach.propose(...); k = M.c_ras_wm.certified_prefix(A, ...)

```

## 4. 推导

**引理 19（任务对称商下无免费信息）** 对 `g ∈ G_task`，`p(o|T)=p(o|gT)` 且 `J(gT)=J(T)`，故 `VoI_gauge ≡ 0`；把 gauge 熵计入 U_epi 只会浪费交互预算且无任务收益。系：**先商化再问；不可观测且不相关的歧义应删除，而非消解。**

**引理 20（预注册抑制 HARKing 膨胀）** 动作后在 m 个解释中择优可抬高表观增益至多 `log m`（次高斯约 `√(2 log m)`）；预注册固定 m=1，`R_pre` 成为好奇心误差的无偏估计。系：**无预注册的 VoI 是事后叙事，不是信息增益。**

**引理 21（FDR 控制不依赖模态校准）** 独立性/PRDS 下 BH(q) 保证 FDR ≤ q，与 `w_k`、ECE 无关。故「已发表位姿中错误者的期望比例」≤ q，即使 R69 模态分布完全失准。系：**用分布无关的多重检验保证替换「模态权重可信」这一脆弱前提。**

**引理 22（文件抽屉偏差界）** 若 `p_pub ≥ p_min > 0`，则 `TV(w_obs, w_true) ≤ 1 − p_min`；逆倾向重加权无偏；`p_pub` 未知时按该界膨胀 U_epi，退避仍保守。系：**记忆的选择性必须显式建模，否则校准随时间单调乐观。**

**定理 18（PEER 严格包含 R69）** (a) 全部断言处于 preprint/rejected/retracted 或评审不可信时，`λ=λ_floor(U_ale+U_epi^res+U_epi^unres)`，与 R69 去 gauge 后的兜底逐指令一致；(b) gauge 方向任务敏感度为零，删除不增风险；(c) published 时 `λ=λ_floor(U_ale) ≤ R69`。故期望任务风险 ≤ R69，R69 为「全部拒稿」边界。

**定理 19（评审俘获上界）** `k_eff = k/(1+(k−1)ρ̄) ≤ 1/ρ̄`；`ρ̄→1` 时 `k_eff→1`，增加同范式评审无法满足 RRG。唯一出路是**机械正交**通道（不同物理量/不同先验来源）或范式留出集。故：**评审人数治不了共同盲点，只有换物理基础才行。**

## 7. 本轮最大风险

**一句话**：PEER-RAS 的全部证据纪律都假设「评审之间至少存在一个机械正交的通道」——**若所有通道共享同一个范式错误（同一份错 CAD、同一个被污染的基准、同一个对称模型版本），则 k_eff→1，预注册、复现、FDR 会一起通过，系统会把错误位姿以一张完整证书「发表」；同行评审不能治愈范式错误，只会把它制度化为共识**。

**次级风险与缓解**：评审共谋/共享主干（k_eff 折减 + 触觉/力觉机械正交强制入审 + E304/E311）；发表偏倚致记忆乐观（拒稿档案 + 逆倾向 + 漏斗检测 + U_epi 膨胀）；预注册流于形式（可检验预测 + 好奇心校准门）；评审阻塞实时控制（SLA + 超时 preprint + 异步评审）；撤稿传播不彻底（retraction_epoch 版本化 + 训练缓冲反向索引 + E310）；学术不端刷量/DoS（香肠切片检测 + 审稿签名校验 + 元评审）。
