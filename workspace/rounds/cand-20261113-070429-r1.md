# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「动作空间」×「数据采集」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险是：VISTA 依赖"故障属于有限假设集、且视觉与几何失效相互独立"；未知复合故障会被强行归入最近假设、只膨胀错误的球，系统因"已经归因"而更自信。**但在这个风险之上还有一层更上游、也更致命的隐藏假设（记为 A94）：区分这些故障所需的数据真的存在，且能被当前的动作分布激励出来。** VISTA 的引理 7 默认三阶段被激励、签名矩阵 S 已知且列近正交；可"是否真的出现过零力窗、是否真的加载到足以分离 H_model"完全由**执行与采集时的动作分布**决定。若机器人从不进入零力窗、从不施加足够的载荷，S 的列会坍缩，哪怕 FIR 再完美也会退化成第 64 轮的不可辨识二分。于是本轮不问"谁坏了"，而问：
>
> **我们手上的数据，足以证明"能分清谁坏"吗？如果不足，怎样用受安全预算约束的动作去采集它，并在采不到时诚实地承认"不可辨识"而不是硬归因？**
>
> 核心命题：**把动作空间从"控制接口"升级为"实验设计空间"，把数据采集从"喂模型"升级为"以安全证书的决策价值为目标、受风险预算约束、且与认证数据严格分离的主动实验"；当已知假设解释不了数据时，先拒绝归因，再受控地扩展假设集与认证动作空间。**

## 0. 直觉与动机

**灵感 1（动作空间 → 实验设计空间）**
直觉：第 65 轮把动作看作"要被认证的对象"，但每个动作同时是一次**实验条件**：接近段（零力窗）测的是 F/T 的 DC 偏置，轻触段测的是接触几何落点，加载段才让接触模型误差显形。选哪些动作，就等于选了签名矩阵 S 的哪些行；S 是否满秩、条件数多大，是**设计属性**，不是估计器的属性。于是可辨识性不该是"假设它成立"，而应是"由动作分布主动建立、用数据证书证明"。进一步地，动作空间本身可以降维：存在一个低维**诊断动作子空间 DAS**，沿它的方向采样，单位数据对"分辨故障"的信息量最大；任务执行走完整动作空间，数据采集只走诊断子空间。

**灵感 2（数据采集 → 证书的决策价值，而非样本量）**
直觉：多采数据并不天然更好。真正有价值的是**能改变安全决策的数据**——能决定"这个球要不要膨胀、这个前缀能不能执行、这个动作层能不能扩张"的数据。因此采集目标应从"参数估计的 Fisher 信息"升级为**证书决策的期望价值 EVOI**；而且采集动作本身就消耗安全预算、本身就是一次有风险的动作，必须被同一套证书约束。数据采集不是免费的信息来源，而是一个**受限资源分配问题**。

**灵感 3（开放世界 → 先拒绝归因，再扩展假设集）**
直觉：第 65 轮最大的病是"必须从 6 个假设里挑一个"。开放世界的正确姿态是：先用**conformal 新颖性检验**判断"当前签名是否还能被已知假设族解释"，不能解释就置 `H_unknown`、拒绝归因、保守联合膨胀；只有当未知签名成簇、可分离、且有标注探针时，才把它固化为新假设 `H_new` 并升版假设库。**承认"不知道"是一种可认证的状态，而不是失败。**

**灵感 4（数据采集破坏可交换性 → 自适应认证 + 数据角色分离）**
直觉：主动采集会改变状态-动作分布，conformal 赖以成立的**可交换性被自己破坏**；越主动，校准越可能失准（分布漂移、选择偏差）。于是需要自适应 conformal（ACI）或动作密度重加权（IPW），并把有效样本量 n_eff 记进证书。更关键的是**数据角色分离**：用于"选择采什么"的设计集与用于"签安全证书"的审计集必须独立（样本分裂/交叉拟合），否则系统会用自己挑的数据证明自己安全——这正是本轮要正面处理的自证风险。

**灵感 5（动作空间的嵌套安全分层 → 数据门控增长）**
直觉：把可达动作空间分层：`A_0` 自由空间零接触 → `A_1` 轻触 → `A_2` 承载 → …。只有当审计数据在某一层给出"可辨识性下界达标 + 激励覆盖达标 + 无未知签名 + 安全谓词成立"时，才允许向下一层扩张；任何一项失败就回退到上一个有效层，`A_0` 也失效则 `safe_idle`。动作空间的增长因此是**数据门控、可回退、单调有界**的，而不是工程师拍脑袋的开关。

**灵感 6（证书-数据-动作回环 CDA）**
直觉：以上合起来暴露一个结构性事实——**证书门控动作，动作产生数据，数据又估计证书**，这是一个自指回环 `cert* = C(D(π(cert*)))`。它既可能让系统自我改进（主动学习），也可能自我确认（只采支持自己的数据）。SCOPE 的全部严谨性，本质上是在这个回环上装三道保险：审计集独立、随机化探索、开放世界新颖性检验。

**灵感 7（VISTA 组件的原位升级）**
- **FIR → FIR-OW**：增 `H_unknown` 与拒绝归因状态；未知签名不再被硬塞进最近假设。
- **AFA → DCC**：探针目标从"当前故障假设互信息"升级为"证书决策的期望价值 EVOI"，并纳入风险预算与停止规则。
- **CSC → CSC-D**：认证前缀同时覆盖数据采集动作，并按 `calibration_mode`（split/ACI/IPW）调整越界预算。
- **RSC-V → RSC-D**：除 r_geo/r_force/r_model 外增 `r_data`（数据支持不足导致的膨胀），由 n_eff 与 n_eff 缺口驱动。
- **WCV-V → DAW**：搜索域增"动作条件支持约束"，只在与参考分布可比、n_eff 足够的动作上认证。
- **CSP-V → CSP-D**：增元技能 `collect_data` / `audit` / `expand_space` / `retreat`；块边需数据支持证书。
- **AIC-V → AIC-D**：干扰集增数据投毒、自证采集、自适应采集漂移、静默未知故障。
- **J_vista → J_scope**：证书增 identifiability_lcb、excitation_cov、novelty_pvalue、unknown_flag、action_stratum、n_eff、calibration_mode、hypothesis_lib_ver、data_support_hash。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（SCOPE 闭环）**：SCOPE = (VISTA, ASF, ECI/DAS, DCC, OGN, HX, ACI, ASG, DAW, J_scope)。定位：VISTA 的"可辨识性数据认证 + 开放世界 + 动作空间数据门控扩张"升级。不变式：**数据采集控制器、假设扩展、校准与证书只在语义流；实时流只执行认证前缀、记录激励覆盖与新颖性分数、维护风险预算表，零学习写操作；设计集与审计集严格不相交。**
- **定义 234（动作空间分层 ASF）**：把可达动作空间划分为不相交层 `A_reach = ⊔_{j=0..J} A_j`，`A_0` 为零接触自由空间、`A_1` 轻触、`A_2` 承载……每层携带数据支持证书 `d_j=(n_eff,j, c_j, ρ_j, g_j)`（有效样本量、激励覆盖、最坏安全裕度、增长门）。动作记为 `a=(u, σ_probe, τ_stage)`：任务动作 u、探针标志 σ_probe、阶段模板 τ_stage。
- **定义 235（激励覆盖与数据条件可辨识性 ECI + DAS）**：对动作 a，签名敏感度 `S(a)=∂E[ρ(a)]/∂θ ∈ ℝ^{15×d_H}`。设计测度 ξ 下的 Fisher 信息 `J_fi(ξ)=Σ_a ξ(a) S(a)ᵀ Σ_ρ⁻¹ S(a)`；其数据估计 `Ĵ_fi=n⁻¹ Σ_i S(a_i)ᵀ Σ̂_ρ⁻¹ S(a_i)`。激励覆盖 `c_p=#{i: 阶段 p 出现}/n`（p∈{approach,touch,load}）。由矩阵 Bernstein，`P[‖Ĵ_fi−J_fi‖≥ε_MB(n,δ)]≤δ`，故可辨识性下界 `κ̂_fi=λ_min(Ĵ_fi)−ε_MB`。**诊断动作子空间** `Π*∈ℝ^{d_a×r}` 解 `max_{ΠᵀΠ=I} λ_min(Π J_fi(ξ) Πᵀ)`。可辨识性证书 `I_cert=(κ̂_fi, {c_p}, rank(Ĵ_fi), Π*)`。
- **定义 236（安全决策与证书价值）**：安全决策 `d∈D={accept, demote_geo, recalibrate_force, compliant, expand, retreat, refuse}`，效用 `U(d,θ)`，`EU(d|D)=E_{θ|D}[U(d,θ)]`。证书价值 `V(D)=max_d EU(d|D)`；数据价值是它相对后验的增量。
- **定义 237（决策相关数据采集 DCC）**：给定数据 D，采集动作 a 的期望价值
  `VOI_DC(a|D)=E_{ρ|a,D}[ max_d E[U(d,θ)|D∪{(a,ρ)}] ] − max_d E[U(d,θ)|D]`。
  选 `a*=argmax_a VOI_DC(a|D)/(r(a)+λ_n)`，s.t. `r(a)≤R_DC`（剩余风险预算）、`a∈A_j`（当前认证层）、阶段模板可执行。当 `max VOI_DC<δ_VOI` 或预算耗尽即停止——**采集是决策相关的、带预算的、可停的**。
- **定义 238（开放世界新颖性 OGN）**：非一致性分数 `s(ρ)=−log max_{H∈ℋ} p(ρ|H)`（或到已知签名流行距离）；在独立已知故障校准集上取 `s_i`，conformal p 值 `p(ρ)=(1+#{i:s_i≥s(ρ)})/(n+1)`。若 `p(ρ)≤α_novel` 判 `H_unknown`，置 `unknown_flag`，**禁止归因与动作空间扩张**；否则认为仍在已知族内。
- **定义 239（假设集扩展 HX）**：未知签名进入缓冲区并聚类；对簇 C，质量 `m_C`、可分离度 `T_C`（能量距离/轮廓系数/两样本检验）。若 `m_C≥m_min ∧ T_C≥τ_sep` 且存在可用标注探针，则固化 `H_new`、拟合 `p(ρ|H_new)`、`hypothesis_lib_ver←ver+1`；否则把 `H_unknown` 当 nuisance 保留，走保守联合膨胀，不新增假设。
- **定义 240（自适应 conformal ACI）**：采集自适应会破坏可交换性，故用 `q_{t+1}=q_t+γ(α−err_t)`（`err_t=1[e_t>q_t]`）给长程覆盖 `≥1−α−ε_ACI`；或用密度比 `w(a)=π_ref(a)/π_collect(a)` 做 IPW，`n_eff=(Σw)²/Σw²`。证书记录 `calibration_mode∈{split,ACI,IPW}`，且**只允许在审计集 `D_audit` 上签发**；设计集 `D_design` 仅用于选采集动作。
- **定义 241（动作空间增长门 ASG）**：`Growth(A_j→A_{j+1})` 当且仅当在 `D_audit` 上：(i) `κ̂_fi≥κ_min`；(ii) `min_p c_p≥c_min`；(iii) 近期无未知签名（`p_novel>α_novel`）；(iv) 新层安全谓词在支持集上成立且裕度 `≥ρ_min`；(v) `n_eff≥n_min`。任一失败则 `Retreat` 到上一个有效层；`A_0` 也失败则 `safe_idle`。
- **定义 242（数据感知 WCV DAW）**：在 WCV-V 的搜索域上增动作条件支持约束 `𝒮={a: n_eff(a)≥n_min ∧ w(a) 有界}`；CVaR 尾部按动作密度重加权；支持不足时膨胀 `r_data` 或收紧定义域；交集为空则回退 `B(φ̂,r)` 并置 `data_support_conflict=True`。
- **定义 243（采集课程与预算 CBD）**：总预算 `(R_DC,N_DC)`，在层与假设间分配以最大化累计 VOI；VOI 在自适应子模条件下用贪心，得 `(1−1/e)` 近似；每步扣减风险预算并记账；预算耗尽即冻结扩张、只允许执行已认证前缀。
- **定义 244（SCOPE 证书 J_scope）**：`J_scope=(J_vista, κ̂_fi, {c_p}, p_novel, unknown_flag, action_stratum, n_eff, calibration_mode, hypothesis_lib_ver, data_support_hash, voI_log, aic_d_ver)`。`Valid(J_scope) ⇔ Valid(J_vista) ∧ κ̂_fi≥κ_min ∧ min_p c_p≥c_min ∧ (unknown_flag ⇒ 未归因未扩张) ∧ calibration_mode 有覆盖证明 ∧ n_eff≥n_min ∧ 动作层与执行前缀一致 ∧ 审计集未参与设计`。
- **定义 245（SCOPE 闭环算子）**：语义流 [VISTA 归因→ECI 可辨识性证书→OGN 新颖性→(未知? HX/保守)→ACI 重校准→DCC 选采集或停止→ASG 增长/回退→DAW→CSP-D→CSC-D]；实时流 [执行认证前缀→记录激励覆盖→滑动新颖性分数→风险预算表→早停]。
- **定义 246（CDA 回环与自证偏差）**：`cert_{t+1}=C(D(π(cert_t)))`。若 `D_design∩D_audit≠∅` 或二者分布差异 `TV(ξ_design,ξ_audit)=τ_self>0`，则证书覆盖是被自身选择抬高的，定义**自证偏差** `b_self≤τ_self·L/(1−τ_self)`（L 为似然比界）。SCOPE 用样本分裂使 `τ_self=0`（有限样本下近似）。
- **定义 247（开放世界证书语义）**：`Valid(J_scope)` 的含义是三种可接受结局之一：(a) 已知故障且数据认证可辨识→定向处置；(b) `unknown_flag=True`→拒绝归因、保守膨胀、只执行 `A_0/A_1` 安全前缀；(c) 动作空间扩张且扩张门在审计集上通过。**绝不包含"强行归因到最近假设"。**
- **定义 248（退化关系）**：若 ℋ 封闭、动作空间静态、数据无限，则 SCOPE 退化为 VISTA；若 `α_novel=1`（永不判未知）且跳过 ECI，则退化为第 65 轮的强制归因，即本轮要修的病。

    # 采不动：拒绝扩张，退到 A_0/A_1

# ASG：数据门控扩张 / 回退

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（设计-可辨识性对偶）**：`J_fi(ξ)=Σ_a ξ(a)S(a)ᵀΣ_ρ⁻¹S(a)`；其秩与 `κ_fi` 完全由 ξ 在三阶段上的支撑决定。缺零力窗 ⇒ H_force 列缺失、H_geo/H_force 不可分；缺加载 ⇒ H_model 列缺失。数据侧用矩阵 Bernstein 给 `κ̂_fi` 的一致下界，故"能否分清"第一次成为**可测量、可签发证书**的性质，而非默认假设。诊断子空间 Π* 最大化单位样本的可辨识信息。
- **引理 10（开放世界与自适应采集的覆盖控制）**：可交换性下 conformal p 值使已知故障被误判未知的概率 ≤α_novel；自适应采集中 ACI 给长程覆盖 `≥1−α−ε_ACI`（单步 `err_t` 修正幅度 O(γ)），IPW 在密度比有界时给逐动作覆盖；`n_eff` 量化重加权后的真实信息量。
- **引理 11（数据门控扩张的安全性）**：若 ASG 五条件在审计集上成立，则新层内单步越界概率 ≤ `α_chunk+δ_fi+α_vis+α_novel+α_cal+α_audit`；回退保证任何时刻都停留在"上一次被审计通过"的层，故扩张不引入超出审计预算的风险。
- **定理 9（SCOPE 端到端：可辨识-开放世界-安全）**：在 A94–A98 下，SCOPE 的每次决策落在定义 247 的三类可接受结局之一；不存在"数据不足却强行归因"的路径；动作空间增长单调、有界、可回退；`Valid(J_scope)` ⇒ VISTA 有效 ∧ 可辨识性由审计数据认证 ∧ 未知状态被显式标注 ∧ 执行前缀落在已审计动作层内。
- **定理 10（数据-风险-可辨识性三重权衡）**：总风险 `R_total=R_exec+R_DC+λ_U·U_epist`，预算约束下三者不可同时最小；VOI 采集在自适应子模下设下 `(1−1/e)` 近似，最优停止条件为边际 VOI ≤ 边际风险代价，给出采集量的闭式阈值。
- **命题（自证偏差上界）**：若设计/审计不独立，表观覆盖可被抬高至任意；`b_self≤τ_self·L/(1−τ_self)`，故样本分裂（`τ_self=0`）不是工程洁癖，而是证书有效性的前提。
- **实时性**：ECI/OGN/HX/ACI/DCC/ASG 全在语义流；实时流只增激励覆盖计数（<0.03ms）、滑动新颖性分数（<0.05ms）、预算与阶段判定（<0.02ms），目标仍 ≤2.5ms（A93 继承，A98 修订）。

## 5. 本轮最大风险

**一句话**：SCOPE 的根基是"用数据证明可辨识、再用可辨识决定动作空间扩张"，但采什么数据本身由当前证书决定——一旦设计集与审计集被分布漂移或实现细节重新耦合，系统就会**只采集能证明自己安全的数据**，把"未被证伪"误当成"已被认证"，让数据覆盖替代真实覆盖，安全证书沦为自我实现的预言；而静默的未知故障恰恰最难触发新颖性检验，会被更自信地执行。

## 2. 形式化定义（完整版）

**定义 233（SCOPE 闭环）** SCOPE 是 VISTA 的"可辨识性数据认证 + 开放世界 + 动作空间数据门控扩张"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 ASF（动作空间分层）、ECI/DAS（可辨识性证书与诊断子空间）、DCC（决策相关采集）、OGN（开放世界新颖性）、HX（假设扩展）、ACI（自适应校准）、ASG（增长门）、DAW（数据感知 WCV），并原位升级 FIR→FIR-OW、AFA→DCC、CSC→CSC-D、RSC-V→RSC-D、WCV-V→DAW、CSP-V→CSP-D、AIC-V→AIC-D、J_vista→J_scope。不变式：
1. **数据角色分离**：`D_design ∩ D_audit = ∅`；设计集只用于选采集动作，证书只在审计集签发。
2. **流分离**：ECI/OGN/HX/ACI/DCC/ASG/DAW 只在语义流；实时流只执行认证前缀、记录激励覆盖、维护新颖性分数与风险预算表。
3. **零学习写操作**：实时路径不写任何模型、假设库或校准状态。

**定义 234（动作空间分层 ASF）** 把可达动作空间划分为层 `A_reach=⊔_{j=0..J}A_j`，按接触状态与法向力阈值分层：`A_0: f_n≈0`（零力窗/自由空间），`A_1: 0<f_n≤f_light`（轻触），`A_2: f_n>f_light`（承载），更高层按载荷/形变细分为 `A_3…`。每层维护数据支持证书 `d_j=(n_eff,j, c_j=min_p c_p, ρ_j, g_j)`。动作 `a=(u,σ_probe,τ_stage)`，其中 `σ_probe=1` 表示该动作同时是采集动作。层间序关系 `A_j ≺ A_{j+1}` 只在增长门通过时成立；否则保持独立并禁止跨越。

**定义 235（激励覆盖与数据条件可辨识性 ECI + DAS）** 对动作 a，阶段签名 `ρ(a)` 对故障幅度 θ 的一阶敏感度 `S(a)=∂E[ρ(a)]/∂θ∈ℝ^{15×d_H}`。设计测度 ξ 作用在动作空间上，Fisher 信息
`J_fi(ξ)=Σ_{a∈A} ξ(a) S(a)ᵀ Σ_ρ⁻¹ S(a)`。
给定审计数据 `D_audit={(a_i,ρ_i)}`，经验估计
`Ĵ_fi = n⁻¹ Σ_{i=1}^{n} S(a_i)ᵀ Σ̂_ρ⁻¹ S(a_i)`。
由于 `S(a_i)ᵀΣ̂⁻¹S(a_i)` 是独立同分布（在固定设计下）且有界对称矩阵，矩阵 Bernstein 给：以概率 ≥1−δ，
`‖Ĵ_fi−J_fi‖₂ ≤ ε_MB(n,δ) = √(2σ²log(2d/δ)/n)+R log(2d/δ)/(3n)`，
因此 `λ_min(J_fi) ≥ λ_min(Ĵ_fi)−ε_MB`。定义**可辨识性下界** `κ̂_fi=λ_min(Ĵ_fi)−ε_MB`。激励覆盖 `c_p=#{i: phase p present in ρ_i}/n`。**可辨识性证书**
`I_cert=(κ̂_fi, {c_p}_{p∈P}, rank(Ĵ_fi), Π*)`，其中诊断动作子空间
`Π* = argmax_{ΠᵀΠ=I_r} λ_min(Π J_fi(ξ) Πᵀ)`
（用半定松弛/特征子空间近似求解）。语义：**`κ̂_fi≥κ_min` 且 `min_p c_p≥c_min` 才允许调用 FIR 并签发归因类证书**；否则只能进入 DCC 采集或拒绝。

**定义 236（安全决策与证书价值）** 安全决策集
`D={accept, demote_geo, recalibrate_force, compliant, expand, retreat, refuse}`。
给定数据 D，`EU(d|D)=E_{θ|D}[U(d,θ)]`，证书价值 `V(D)=max_{d∈D} EU(d|D)`。`θ` 包含故障幅度、偏置、模型误差与数据支持缺口；效用编码任务收益、越界/损伤惩罚与保守代价。VISTA 的定向膨胀、CSC 前缀与 RSC 更新都是 `d` 的特例；SCOPE 只是把它们放进一个可比较的决策空间。

**定义 237（决策相关数据采集 DCC）** 采集动作 a 的期望价值
`VOI_DC(a|D)=E_{ρ|a,D}[ V(D∪{(a,ρ)}) ] − V(D)`。
选择
`a* = argmax_{a∈A_j} VOI_DC(a|D) / (r(a)+λ_n)`，
s.t. `r(a)≤R_DC`（剩余风险预算）、阶段模板可执行、`a` 在当前认证层内、若对象易损则禁用接触类探针。停止规则：`max_a VOI_DC(a|D)<δ_VOI`、或 `R_DC`/`N_DC` 耗尽、或无处可采（支持不足）。与第 65 轮 AFA 的区别：AFA 最大化**当前故障假设的互信息**；DCC 最大化**安全证书决策的期望价值**，并把采集动作本身当作消耗风险预算的动作。互信息是 EVOI 在特定效用下的特例。

**定义 238（开放世界新颖性 OGN）** 非一致性分数
`s(ρ) = −log max_{H∈ℋ_known} p(ρ|H)`（或 `min_H d(ρ, M_H)`，`M_H` 为假设 H 的签名流形）。在独立已知故障校准集 `{s_i}_{i=1..n}` 上，conformal p 值
`p(ρ) = (1 + #{i: s_i ≥ s(ρ)}) / (n+1)`。
若 `p(ρ)≤α_novel` 判 `H_unknown`，置 `unknown_flag=True`，**禁止 FIR 定向处置与 ASG 扩张**。可交换性下，已知故障被误判为未知的概率 ≤α_novel。注意这是**边际**保证，且对自适应采集失效——故必须配合定义 240。

**定义 239（假设集扩展 HX）** 未知签名进入缓冲区 `U`。对 `U` 聚类得簇 C，计算质量 `m_C=|C|/|U|` 与可分离度 `T_C`（两样本能量距离 / 轮廓系数 / 置换检验统计量）。若 `m_C≥m_min`、`T_C≥τ_sep`、且存在可用标注探针（能低成本地产生该簇的可解释签名），则固化为 `H_new`：拟合 `p(ρ|H_new)`（高斯混合/归一化流）、更新先验、`hypothesis_lib_ver←ver+1`。否则保留 `H_unknown` 作为 nuisance，只做保守联合膨胀，**不新增假设**（避免把噪声固化成"新故障"）。

**定义 240（自适应 conformal ACI + 数据角色分离）** 主动采集使 `ξ` 随证书变化，破坏可交换性。两条修正路径：
1. **ACI**：`q_{t+1}=q_t+γ(α−err_t)`，`err_t=1[e_t>q_t]`；长程平均覆盖 `≥1−α−ε_ACI`，单步偏差 O(γ)。
2. **IPW**：`w(a)=π_ref(a)/π_collect(a)`，用 `w` 重加权校准样本；密度比有界时给逐动作覆盖；`n_eff=(Σw)²/Σw²`。
证书记录 `calibration_mode∈{split,ACI,IPW}` 与 `n_eff`。**审计约束**：所有证书只在 `D_audit` 上签发，`D_audit` 从不由 DCC 选择动作时读取；设计/审计样本分裂（或交叉拟合）保证 `τ_self=0`（有限样本近似）。

**定义 241（动作空间增长门 ASG）** `Growth(A_j→A_{j+1})` 为真当且仅当在 `D_audit` 上同时满足：
- (i) 可辨识性：`κ̂_fi≥κ_min`；
- (ii) 激励覆盖：`min_p c_p≥c_min`；
- (iii) 开放世界：近期样本 `p_novel>α_novel`（无未知签名）；
- (iv) 安全：新层安全谓词在支持集上成立，最坏裕度 `ρ_j≥ρ_min`；
- (v) 数据支持：`n_eff≥n_min`，且动作条件支持覆盖新层入口。
任一失败则 `Retreat(A_j→A_{j-1})`；若 `A_0` 亦失败则 `safe_idle`。扩张与回退都写审计日志。

**定义 242（数据感知 WCV DAW）** 在 WCV-V 的搜索域上增动作条件支持约束
`𝒮={a: n_eff(a)≥n_min ∧ w(a)≤w_max}`，
搜索域变为 `B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ 𝒮`。
CVaR 尾部按 `w(a)` 做重要性加权，`n_worst` 从 8 增到 12（含支持不足等价类）。若某方向 `n_eff<n_min`，膨胀 `r_data`（与 n_eff 缺口单调），或收紧定义域；交集为空则回退 `B(φ̂,r)` 并置 `data_support_conflict=True`。融合半径
`r=√(r_geo²+r_force²+r_model²+r_data²)`。
相比第 65 轮，DAW 第一次让"这些数据不足以支持这个动作上的认证"成为一个显式、可拒签的理由。

**定义 243（采集课程与预算 CBD）** 总预算 `(R_DC,N_DC)`。在层 `{A_j}` 与假设 `{H}` 上分配采集动作以最大化累计 VOI：
`max_{π_collect} E[Σ_t VOI_DC(a_t|D_t)]  s.t.  Σ_t r(a_t)≤R_DC, |{a_t}|≤N_DC`。
在自适应子模条件下（Golovin–Krause），贪心给 `(1−1/e)` 近似；每步扣减风险预算并记账。预算耗尽即冻结扩张、只允许执行已认证前缀。可选优先级：先补覆盖缺口 `c_p<c_min`（可辨识性最脆弱处），再降低决策相关熵。

**定义 244（SCOPE 证书 J_scope）**
`J_scope=(J_vista, κ̂_fi, {c_p}, p_novel, unknown_flag, action_stratum, n_eff, calibration_mode, hypothesis_lib_ver, data_support_hash, voI_log, aic_d_ver)`。
验证规则：
`Valid(J_scope) ⇔ Valid(J_vista)`
`∧ κ̂_fi≥κ_min ∧ min_p c_p≥c_min`
`∧ (unknown_flag ⇒ (未做定向归因 ∧ 未扩张动作空间 ∧ 只执行安全前缀))`
`∧ calibration_mode 有对应覆盖保证（split/ACI/IPW）`
`∧ n_eff≥n_min ∧ 动作层与执行前缀一致`
`∧ D_design∩D_audit=∅`。
审计链新增：**凭什么说能分清（κ̂_fi, c_p）、凭什么是新的（p_novel, hypothesis_lib_ver）、凭什么敢扩张（ASG 五条件）、数据够不够（n_eff, data_support_hash）**。

**定义 245（SCOPE 闭环算子）** 语义流：
`[LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→VCV→FIR-OW→ECI 证书→OGN 新颖性→(未知? HX/保守)→ACI 校准→DCC 采集或停止→ASG 增长/回退→DAW→CSP-D/TSL→CSC-D→Shield→执行 k*→EV_exec→RSC-D→OLP/DIR/SSB→AIC-D]`；
实时流：
`[锚点读→激励覆盖计数→滑动新颖性分数→阶段判定→CSC-D 早停→DAW 编译→π_σ 前缀派发→风险预算表→J_scope 构建]`。

**定义 246（CDA 回环与自证偏差）** 证书-数据-动作回环
`cert_{t+1}=C(D(π(cert_t)))`。
若设计集与审计集不独立，或 `TV(ξ_design,ξ_audit)=τ_self>0`，则表观覆盖被自身选择抬高。定义**自证偏差**
`b_self ≤ τ_self·L/(1−τ_self)`，
其中 `L` 为设计/审计分布间的似然比上界。样本分裂使 `τ_self=0`；分布漂移或实现把审计数据回流到设计器则 `τ_self>0`，证书必须显式打折（在 `J_scope` 记 `self_confirmation_bound`）。这是 SCOPE 区别于"普通主动学习"的关键：**它把自证偏差当作一等安全量，而不是训练技巧**。

**定义 247（开放世界证书语义）** `Valid(J_scope)` 恰好对应三类可接受结局之一：
(a) **已知且可辨识**：`unknown_flag=False ∧ κ̂_fi≥κ_min ∧ min_p c_p≥c_min` ⇒ 允许 FIR 定向处置与认证前缀；
(b) **未知但诚实**：`unknown_flag=True` ⇒ 拒绝归因、保守联合膨胀、只执行 `A_0/A_1` 安全前缀，等待 HX 或人工；
(c) **已认证扩张**：ASG 五条件在审计集通过 ⇒ 允许进入新动作层。
**Valid 绝不包含"数据不足却强行归因到最近假设"**——这正是对第 65 轮最大风险的正面否定。

**定义 248（退化关系）** 若 ℋ 封闭、动作空间静态 `A_reach=A_0`、且数据无限（`κ̂_fi→κ_fi`、`c_p→1`），则 SCOPE 退化为 VISTA；若进一步 `α_novel=1`（永不判未知）并跳过 ECI，则退化为第 65 轮的强制归因，即本轮要修的病。反过来，`α_novel→0` 会把一切都判未知、退化为 `safe_idle`。因此 SCOPE 的有效性落在 `α_novel、κ_min、c_min、R_DC` 的可调折衷带内。

### IP-225 ECI/DAS（可辨识性证书）

```python
class IdentifiabilityCertificate:
    """审计集上估计 J_fi 并给 λ_min 的有限样本下界；设计集不参与签发。"""
    def __init__(self, kappa_min=1e-2, c_min=0.1, delta=1e-3):
        self.kappa_min, self.c_min, self.delta = kappa_min, c_min, delta

    def certify(self, audit_D, Sigma_rho):
        S, phases, acts = [], [], []
        for (a, rho) in audit_D:
            S.append(sensitivity(a, rho))                 # 15×d_H
            phases.append(phase_presence(rho))            # {approach,touch,load}
            acts.append(a)
        n = len(S)
        J_hat = sum(Si.T @ np.linalg.inv(Sigma_rho) @ Si for Si in S) / n
        eps = matrix_bernstein_radius(S, Sigma_rho, n, self.delta)
        kappa_lcb = np.linalg.eigvalsh(J_hat)[0] - eps
        cov = {p: np.mean([ph[p] for ph in phases]) for p in PHASES}
        return {'kappa_lcb': kappa_lcb, 'J_hat': J_hat, 'cov': cov,
                'identifiable': kappa_lcb >= self.kappa_min
                                and min(cov.values()) >= self.c_min,
                'n_eff': self.effective_n(acts)}

    def diagnostic_subspace(self, J_hat, r):
        # max_{Pi^T Pi = I} lambda_min(Pi J_hat Pi^T) 的 SDP 松弛；工程退化用
        # 最大特征子空间近似，并在证书里记录近似方式与差距
        w, V = np.linalg.eigh(J_hat)
        return V[:, -r:]

    def effective_n(self, acts):
        # IPW 后的有效样本量；无权重时退化为 n
        if not self.weights:
            return len(acts)
        w = np.array([self.weights(a) for a in acts])
        return w.sum() ** 2 / (w @ w)
```

### IP-227 OGN + IP-228 HX（开放世界与假设扩展）

```python
class OpenWorldAttributor:
    def __init__(self, known_lik, calib_scores, alpha_novel=0.05,
                 m_min=0.1, tau_sep=0.7):
        self.known_lik, self.calib = known_lik, np.sort(calib_scores)
        self.alpha_novel, self.m_min, self.tau_sep = alpha_novel, m_min, tau_sep
        self.unknown_buffer = []

    def novelty(self, rho):
        s = -max(np.log(self.known_lik[h](rho) + 1e-12) for h in self.known_lik)
        p = (1 + np.sum(self.calib >= s)) / (len(self.calib) + 1)
        return float(p), bool(p <= self.alpha_novel)

    def maybe_expand(self, lib):
        for C in cluster_signatures(self.unknown_buffer):
            if len(C) / max(len(self.unknown_buffer), 1) < self.m_min:
                continue
            if separability(C) < self.tau_sep:
                continue
            if not labeling_probe_available(C):
                continue
            lib.add(fit_likelihood(C)); lib.version += 1
            self.unknown_buffer.clear()
            return True
        return False
```

### IP-229 ACI（自适应校准）

```python
class AdaptiveConformal:
    def __init__(self, alpha, gamma=0.01, mode='aci', q0=0.0):
        self.alpha, self.gamma, self.mode, self.q = alpha, gamma, mode, q0

    def update(self, e_t):
        err = 1.0 if e_t > self.q else 0.0
        self.q = self.q + self.gamma * (self.alpha - err)
        self.q = max(0.0, self.q)
        return self.q

    def coverage_bound(self):
        return {'split': 1 - self.alpha,
                'aci': 1 - self.alpha - 1e-3,       # ε_ACI 由 γ 与漂移界给出
                'ipw': 1 - self.alpha}[self.mode]
```

```python
class ScopeController:
    def choose_data_action(self, post, I_cert, budget, stratum):
        best, best_score = None, 0.0
        for a in candidate_probes(stratum):
            if risk(a) > budget.remaining or not stage_template_ok(a):
                continue
            voi = expected_certificate_voi(a, post, I_cert)
            score = voi / (risk(a) + LAMBDA_N)
            if score > best_score:
                best, best_score = a, score
        return best if best_score >= DELTA_VOI else None   # None = 停止采集

    def growth_gate(self, cert, p_novel, stratum, audit):
        return (cert['kappa_lcb'] >= KAPPA_MIN
                and min(cert['cov'].values()) >= C_MIN
                and p_novel > ALPHA_NOVEL
                and safety_valid_on_support(stratum, audit, rho_min=RHO_MIN)
                and cert['n_eff'] >= N_MIN
                and not self.audit_leaked_into_design)

    def step(self, stratum, cert, p_novel, audit):
        if self.growth_gate(cert, p_novel, stratum, audit):
            return advance(stratum), 'grow'
        return retreat(stratum), 'retreat'                # A_0 失败 -> safe_idle
```

## 4. 推导

**引理 9（设计-可辨识性对偶）** 设故障幅度 θ，`E[ρ(a)|θ]=S(a)θ`，`ρ(a)∼N(S(a)θ,Σ_ρ)`。对动作设计测度 ξ，样本的 Fisher 信息可加：
`J_fi(ξ)=Σ_a ξ(a) S(a)ᵀΣ_ρ⁻¹S(a)`。
由阶段结构（第 65 轮定义 222），`S(a)` 仅在动作激励了相应阶段时含非零列：
- 缺 `approach`（零力窗）⇒ `H_force` 的 DC 偏置列缺席，`H_force` 与 `H_geo` 在观测上不可分，`J_fi` 奇异；
- 缺 `touch` ⇒ `H_geo` 的落点列衰减，`H_geo` 与 `H_model` 相关性上升；
- 缺 `load` ⇒ `H_model` 列缺席，模型误差无法与健康区分。
故 `rank(J_fi)` 与 `κ_fi` 是设计测度的函数，而非估计器的函数。数据侧，`Ĵ_fi` 是独立有界对称矩阵之和，矩阵 Bernstein 给 `‖Ĵ_fi−J_fi‖₂≤ε_MB(n,δ)`；由 Weyl 不等式 `λ_min(J_fi)≥λ_min(Ĵ_fi)−ε_MB=κ̂_fi`。因此 `κ̂_fi≥κ_min` 是**可签发**的可辨识性证书。DAS 解 `max_{ΠᵀΠ=I}λ_min(ΠJ_fiΠᵀ)`，其最优值不小于 `κ_fi` 在 r 维主子空间上的投影，故沿 Π* 采集的单位样本信息量最大。∎

**引理 10（开放世界与自适应采集的覆盖控制）**
(1) **可交换性下**：校准分数 `{s_i}` 与测试分数 `s(ρ)` 可交换时，`p(ρ)=(1+#{s_i≥s})/(n+1)` 是有效 p 值，`P[p≤α_novel]≤α_novel`；故已知故障被误判未知的概率受控。
(2) **ACI**：按 `q_{t+1}=q_t+γ(α−err_t)`，若 `e_t` 有界，则长程平均覆盖 `T⁻¹Σ_t err_t ≤ α+O(1/(γT))+O(γ)`；即自适应采集下覆盖不会被无限抬高，但需付出 `ε_ACI` 的折扣。
(3) **IPW**：若 `π_collect(a)>0`、`π_ref(a)/π_collect(a)≤w_max`，则重加权样本对参考分布无偏，逐动作覆盖成立；`n_eff=(Σw)²/Σw²` 度量重加权后的有效信息量，`n_eff` 越小，conformal 分位数的方差越大。∎

**引理 11（数据门控扩张的安全性）** 设 ASG 五条件在审计集成立。则对 `A_{j+1}` 内任一动作：(i) `κ̂_fi≥κ_min` 与 `c_p≥c_min` 保证故障可辨识，故 VISTA 的归因错误率受引理 7 控制；(ii) `p_novel>α_novel` 保证无未知签名（误判率 ≤α_novel）；(iii) 安全谓词在支持集上成立，且 DAW 只在 `n_eff≥n_min` 的动作上认证。由联合界，新层单步越界概率
`P[越界] ≤ α_chunk+δ_fi+α_vis+α_novel+α_cal+α_audit`。
回退规则保证任何时刻停留在"上一次审计通过"的层，故扩张不引入超出审计预算的风险。∎

**定理 9（SCOPE 端到端：可辨识-开放世界-安全）** 在 A94–A98 下：
1. **可辨识优先**：FIR 仅在 `κ̂_fi≥κ_min ∧ min_p c_p≥c_min` 时被调用；否则进入 DCC 采集或退层。故不存在"数据不足却强行归因"的路径。
2. **开放世界诚实**：`unknown_flag=True` ⇒ 拒绝定向处置、保守膨胀、只执行安全前缀；HX 只在成簇+可分离+可标注时固化新假设，避免把噪声当故障。
3. **动作空间安全增长**：ASG 单调、有界、可回退；扩张安全性由引理 11 给出。
4. **数据角色分离**：证书只在审计集签发，`D_design∩D_audit=∅`，自证偏差 `b_self=0`（有限样本近似，记入 `J_scope`）。
5. **证书语义**：`Valid(J_scope)` 等价于定义 247 的三类可接受结局之一，且包含 VISTA 的全部安全性。
6. **优雅降级**：未知→safe 前缀；采不动→退层→safe_idle；数据漂移→ACI 折扣+保守膨胀；假设爆炸→nuisance 化。
∎

**定理 10（数据-风险-可辨识性三重权衡）** 定义总风险
`R_total = R_exec + R_DC + λ_U·U_epist`，
其中 `R_exec` 为执行风险、`R_DC` 为采集消耗的风险预算、`U_epist` 为可辨识性/覆盖不足带来的认知不确定度惩罚（`U_epist∝max(0,κ_min−κ̂_fi)+Σ_p max(0,c_min−c_p)`）。采集降低 `U_epist` 但抬高 `R_DC`；不采集则相反。在自适应子模假设下，VOI 贪心给 `(1−1/e)` 近似最优；最优停止在边际 `VOI_DC(a*)/(r(a*)+λ_n) < δ_VOI` 时触发。因此**不存在同时最小化三者的策略**，只有一条 Pareto 前沿；SCOPE 选择的是"先保证 `R_exec` 的硬约束，再在预算内最小化 `U_epist`"。∎

**命题（自证偏差上界）** 设设计分布与审计分布的总变差距离为 `τ_self`，设计/审计似然比上界为 L。则用设计数据自我验证得到的表观覆盖与实际覆盖之差
`b_self ≤ τ_self·L/(1−τ_self)`。
当 `τ_self→0`（样本分裂）时 `b_self→0`；当审计数据被回流进设计器（`τ_self` 不受控），`b_self` 可任意大。故样本分裂不是工程洁癖，而是 `J_scope` 有效性的前提。∎

**推论（"未被证伪"≠"已被认证"）** 若 `κ̂_fi<κ_min` 或 `c_p<c_min`，则 `Valid(J_scope)` 不成立；此时即使所有已观测数据都"看起来安全"，也只是"未被证伪"，不得升级为"已认证"。

## 7. 已知风险

**一句话**：SCOPE 的根基是"用数据证明可辨识、再用可辨识决定动作空间扩张"，但采什么数据本身由当前证书决定——一旦设计集与审计集被分布漂移或实现细节重新耦合，系统就会**只采集能证明自己安全的数据**，把"未被证伪"误当成"已被认证"，让数据覆盖替代真实覆盖，安全证书沦为自我实现的预言；而静默的未知故障恰恰最难触发新颖性检验，会被更自信地执行。

**次级风险与缓解**：
1. **自证偏差（头号）**：设计/审计不独立时表观覆盖可任意抬高；缓解：样本分裂、交叉拟合、审计集访问审计、`self_confirmation_bound` 入证书；发现回流即作废相关证书。
2. **静默未知故障**：与已知签名统计不可分，OGN 的边际检验必然漏检；缓解：不把 OGN 当万能，保留保守膨胀与 safe_idle，引入物理独立通道（本体感觉/IMU）作为未来工作，并用扰动测试估计"最坏静默故障"下界。
3. **数据采集本身是未认证动作**：风险预算 `R_DC` 若低估，采集会越过不可逆点；缓解：采集动作同样走 CSC-D 前缀与不可逆视界 m，易损物体禁用接触探针，预算耗尽即冻结。
4. **ACI/IPW 在剧烈漂移下失准**：`ε_ACI` 名不副实；缓解：漂移检测（覆盖误差 CUSUM）、分动作分视界校准、必要时丢弃旧校准集。
5. **动作空间扩张不可逆**：进入新层后若支持崩塌；缓解：ASG 可回退 + 每层独立审计 + 定期重认证；禁止跨层跳级。
6. **HX 假设爆炸与标注成本**：未知簇过多导致假设库爆炸、拟合过拟合；缓解：质量/可分离双阈值、最小描述长度惩罚、定期剪枝与版本回滚。
7. **VOI 依赖模型**：`VOI_DC` 用 `p(ρ|H)` 与效用模型计算，模型错则采集方向错；缓解：对模型做鲁棒化（CVaR）、保留随机化探索比例、用无模型基线兜底。
8. **DAS 投影丢失任务相关信息**：低维子空间可能漏掉只在非诊断方向显形的故障；缓解：Π* 仅用于**采集**，执行仍用完整动作空间；定期用完整空间审计校验子空间。
9. **实时预算**：新颖性打分、覆盖计数与 DAW 逼近 3ms；缓解：ROI 降采样、事件触发、与 LSF 共享编码、全部学习/统计留在语义流。
10. **审计集耗尽/污染**：长期运行后审计数据与新分布脱节；缓解：滚动审计、留出比例下限、投毒检测（E250）、审计数据哈希链。
