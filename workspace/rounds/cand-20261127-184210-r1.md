### 第 4 轮灵感驱动研究记录

**灵感词**：模型量化、机器人

**直觉与动机**：

先给一个直觉画面：前几轮我们把 KEMPC/CADVS 做成了一条「证书链」，从感知、定位、视觉伺服一路签发到学生策略准入。但这条链默认了一个隐藏前提——**被证书认证的函数，就是机器人实际执行的函数**。一旦为了在 Jetson/MCU 上跑到 500Hz 而把学生策略量化成 INT8/INT4，这个前提就断了：证书仍然签发在浮点参考模型 f_θ 上，机器人执行的却是另一个函数 f_θ^q。量化不是「压缩」，而是**一次有界的函数替换**。证书链因此出现了一个此前没有的缺口：*certificate–reference mismatch*（证书-参考失配）。

1. **量化对证书是威胁**：均匀量化的逐元素误差 |Q_Δ(x)−x| ≤ Δ/2 看似很小，但经过深层网络的 Lipschitz 累积，输出端误差可能放大到不可忽略；更危险的是它**状态相关**——在标定域内很小，在 OOD 输入上可能爆炸。若证书仍用浮点模型判定「通过」，就是拿旧证书给新函数背书。

2. **证书反过来可以指导量化**：安全证书本来就定义了控制器的「误差预算」——鲁棒不变集留了多大裕度、KC 规则留了多少余量。量化误差本质上是在花这笔预算。于是可以把「每层分配多少 bit」变成一个**受证书约束的误差预算分配问题**，而不是按经验统一 INT8。

3. **一个被忽视的不对称**：证书本身（值网络、集成方差、条件数、守卫比较）也在量化硬件上计算。**守卫若比被守卫对象更粗，就会把 reject 翻成 accept**。因此需要「证书精度支配」：证书的计算精度必须严格高于它所守护的决策裕度。这比控制量化更关键，因为它守护的是安全判据本身。

4. **机器人特有的取舍**：量化换来的不只是显存，还有推理延迟——更低的延迟允许更高的控制频率，从而更好地抑制扰动；但更低的 bit 又带来更大的单步误差。于是存在一个**频率-量化联合最优**，而不是单调地「越精确越好」。

**关键洞见**：把量化视为一个**有界、状态相关的误差源**，它消耗证书所定义的**安全裕度预算**。整条链应满足「量化误差 ≤ 安全裕度」且「守卫误差 < 守卫裕度」。前者给出混合精度分配，后者给出证书最低精度，两者共同把「浮点证书」升级为「部署函数证书」。

**形式化目标（增量）**：
1. 定义量化误差证书 QEC：ε_q(x; b) = Σ_l (Π_{k>l} L_k) ε_l(x; b_l)，其中 ε_l 为第 l 层局部量化误差，L_k 为层 Lipschitz 常数。
2. 定义证书引导混合精度：min_b Σ c_l b_l s.t. ε_q(x;b) ≤ m_safe ∀x∈X_cert，用拉格朗日松弛 + 灵敏度贪心求解。
3. 定义证书精度支配：ε_c(b_c) < γ_c，得到每张证书的最低 bit 数 b_c^min。
4. 定义量化准入 KC 规则：q_admit = q_valid(x) ∧ (ε_q(x;b) ≤ m_safe) ∧ student_admitted。
5. 定义频率-量化联合代价 J(b) = w_ε·ε_q(b)² + w_T·(L_d·T(b))²，给出最优工作点。
6. 证明 Exec_v31 ⊆ Exec_v30，并给出闭环跟踪误差上界 ‖e_ss‖ ≤ (m_safe + L_d·T)/λ_cl。

**本轮最大风险**：**QEC 的有效域与部署分布失配**——误差上界只在标定域 X_cert 内严格成立，机器人一旦进入 OOD（打滑、载荷突变、传感器退化），真实量化误差可能远超证书上界，而证书链仍显示「通过」，形成比全精度更隐蔽的虚假安全。

## 2. 关键算法骨架

### IP-478 Quantization Error Certificate (QEC)

```python
@dataclass
class QuantizationErrorCertificate:
    """QEC：逐层量化误差 + Lipschitz 传播，输出状态相关的误差上界"""
    bits: dict[str, int]                        # 层名 -> bit 宽
    weight_range: dict[str, tuple[float, float]]
    act_range: dict[str, tuple[float, float]]   # 标定域内的激活范围
    lipschitz: dict[str, float]                 # 层名 -> L_l（谱范数上界）
    shape: dict[str, tuple[int, int]]           # 层名 -> (n_in, n_out)
    order: list[str] = field(default_factory=list)
    acc_bits: int = 16                          # 累加器位宽

    def _dW(self, l: str) -> float:
        lo, hi = self.weight_range[l]
        return (hi - lo) / (2 ** self.bits[l] - 1)

    def _dx(self, l: str) -> float:
        lo, hi = self.act_range[l]
        return (hi - lo) / (2 ** self.bits[l] - 1)

    def local_error(self, l: str, abs_x: float) -> float:
        """仿射层 y = W x + b 的局部量化误差：权重扰动 + 输入扰动 + 交叉项 + 累加舍入"""
        dW, dx = self._dW(l), self._dx(l)
        n_in, n_out = self.shape[l]
        W = self.lipschitz[l]
        lo, hi = self.act_range[l]
        return (np.sqrt(n_in * n_out) * dW / 2.0) * abs_x \
             + W * (np.sqrt(n_in) * dx / 2.0) \
             + (np.sqrt(n_in * n_out) * dW / 2.0) * (np.sqrt(n_in) * dx / 2.0) \
             + np.sqrt(n_out) * (hi - lo) / (2 ** self.acc_bits)

    def bound(self, x: np.ndarray, region=None) -> float:
        """区间前向估计各层输入幅值，再反向累积误差"""
        abs_x = self._interval_abs(x, region)   # dict: 层 -> 输入 |x| 上界
        err, tail = 0.0, 1.0
        for l in reversed(self.order):
            err += tail * self.local_error(l, abs_x[l])
            tail *= self.lipschitz[l]
        return err

    def bound_region(self, X_cert, bits: dict[str, int]) -> float:
        """对整块证书域取上确界（用于离线分配与准入）"""
        self.bits = dict(bits)
        return max(self.bound(x) for x in X_cert.samples)

    def cert_payload(self, x: np.ndarray) -> dict:
        return {
            'cert_id': 'qec_valid',
            'payload': {'eps_q': float(self.bound(x)), 'bits': dict(self.bits)},
            't_stamp': time.time(),
            'validity_window': 0.02,
            'src_node': 'qec',
        }
```

### IP-479 Certificate-Guided Mixed-Precision Allocator (CGMPA)

```python
@dataclass
class CertificateGuidedMixedPrecisionAllocator:
    """CGMPA：把 m_safe 当作误差预算，逐 bit 分配给「性价比」最高的层"""
    b_min: int = 4
    b_max: int = 16
    cost: dict[str, float] = field(default_factory=dict)   # 层 MACs，用作成本

    def allocate(self, qec: QuantizationErrorCertificate,
                 m_safe: float, X_cert) -> dict[str, int]:
        b = {l: self.b_min for l in qec.order}
        while qec.bound_region(X_cert, b) > m_safe:
            base = qec.bound_region(X_cert, b)
            best_l, best_gain = None, -1.0
            for l in qec.order:
                if b[l] >= self.b_max:
                    continue
                b[l] += 1
                gain = (base - qec.bound_region(X_cert, b)) / self.cost.get(l, 1.0)
                b[l] -= 1
                if gain > best_gain:
                    best_l, best_gain = l, gain
            if best_l is None:
                raise InfeasibleBudget(m_safe)   # 触发降频/教师兜底
            b[best_l] += 1
        return b

    # 拉格朗日松弛（连续近似）：min_b Σ c_l b_l + μ·(ε_q(b) − m_safe)
    # 对 b_l 求次梯度并按 μ 二分，可给出贪心的下界与最优性间隙估计。
```

### IP-480 Certificate Precision Dominance Guard (CPDG)

```python
@dataclass
class CertificatePrecisionDominanceGuard:
    """CPDG：守卫计算误差必须严格小于其决策裕度，否则量化会翻案"""
    margin: dict[str, float] = field(default_factory=dict)   # cert_id -> γ_c

    def required_bits(self, cert_id: str, err_fn) -> int:
        for b in range(2, 17):
            if err_fn(cert_id, b) < self.margin[cert_id]:
                return b
        return 16

    def admits(self, cert_id: str, err_fn, b_used: int) -> bool:
        return err_fn(cert_id, b_used) < self.margin[cert_id]

    def check_all(self, err_fn, bits: dict[str, int]) -> tuple[bool, list[str]]:
        bad = [c for c, g in self.margin.items()
               if not self.admits(c, err_fn, bits.get(c, 16))]
        return len(bad) == 0, bad
```

### IP-481 Quantization-Aware Admission Kernel (QAAK)

```python
@dataclass
class QuantizationAwareAdmissionKernel:
    """QAAK：量化学生准入 KC 规则 q_admit"""
    m_safe: float

    def admit(self, x, student, qec: QuantizationErrorCertificate,
              qvm: 'QuantizationValidityMonitor', bits) -> 'Admission':
        if not qvm.in_domain(x):
            return Admission(False, 'qec_domain_invalid')       # QEC 失效
        if qec.bound(x) > self.m_safe:
            return Admission(False, 'quant_error_exceeds_margin')
        if not student.admitted:
            return Admission(False, 'student_rejected')
        return Admission(True, 'q_admitted')
```

### IP-482 Frequency-Quantization Co-Designer (FQCD)

```python
@dataclass
class FrequencyQuantizationCoDesigner:
    """FQCD：低 bit 换低延迟/高控制频率，但抬高单步误差，求联合最优"""
    macs: dict[str, float] = field(default_factory=dict)
    throughput: dict[int, float] = field(default_factory=dict)   # bit -> MACs/s
    overhead: float = 0.5e-3
    w_eps: float = 1.0
    w_T: float = 1.0
    dist_scale: float = 1.0                                       # L_d

    def latency(self, b: dict[str, int]) -> float:
        return sum(self.macs[l] / self.throughput[b[l]] for l in b) + self.overhead

    def cost(self, qec: QuantizationErrorCertificate, X_cert, b) -> float:
        eps = qec.bound_region(X_cert, b)
        T = self.latency(b)
        return self.w_eps * eps ** 2 + self.w_T * (self.dist_scale * T) ** 2

    def optimize(self, qec, X_cert, candidates) -> tuple[dict[str, int], float]:
        best = min(candidates, key=lambda b: self.cost(qec, X_cert, b))
        return best, self.cost(qec, X_cert, best)
```

### IP-483 Quantization Validity Monitor (QVM)

```python
@dataclass
class QuantizationValidityMonitor:
    """QVM：标定域内马氏距离 + split-conformal p 值；越域即宣告 QEC 失效"""
    mean: np.ndarray
    cov_inv: np.ndarray
    thr: float                       # 由标定集分位数/覆盖率校准

    def in_domain(self, x: np.ndarray) -> bool:
        d = (x - self.mean) @ self.cov_inv @ (x - self.mean)
        return d <= self.thr

    # 备选：split-conformal p 值 p(x) = (#{d_i >= d(x)} + 1)/(n+1)
    # 标定分布内保证覆盖率 >= 1-alpha；分布漂移时该保证失效，需叠加漂移检测
```

### QCADVS 统一执行流（单步）

```python
def qcadvs_step(robot_state, sensor_data, qec, qvm, cpdg, qaak) -> ControlOutput:
    """v31：在 v30 证书链上叠加 QEC/QVM/CPDG 的量化准入"""
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)
    if cert_agg is None or not cert_agg.all_passed:
        return fallback_to_teacher(robot_state, sensor_data, reason='cert_agg_fail')

    # 0) 守卫精度支配：量化证书本身不得翻案
    ok, bad = cpdg.check_all(cert_err_fn, qec.bits)
    if not ok:
        return fallback_to_teacher(robot_state, sensor_data, reason=f'cpdg:{bad}')

    # 1) 量化学生路径（QEC 有效 ∧ 误差在裕度内）
    student = wait_for_topic('/ctrl/student', timeout=0.001)
    adm = qaak.admit(robot_state.x, student, qec, qvm, qec.bits) if student else None
    if adm and adm.admitted:
        vs = wait_for_topic('/ctrl/vservo', timeout=0.002)
        if vs and vs.kc_active:
            u = blend_student_vservo(student.u, vs.u, alpha=0.3)
            return ControlOutput(u, path='quant_student+vservo', certs=cert_agg)
        return ControlOutput(student.u, path='quant_student', certs=cert_agg)

    # 2) 全精度学生兜底（QEC 失效但全精度仍可）
    fp_student = wait_for_topic('/ctrl/student_fp32', timeout=0.002)
    if fp_student and fp_student.admitted:
        return ControlOutput(fp_student.u, path='fp_student', certs=cert_agg)

    # 3) 教师路径
    teacher = wait_for_topic('/ctrl/teacher', timeout=0.020)
    if teacher and teacher.admitted:
        return ControlOutput(teacher.u, path='teacher', certs=cert_agg)

    return ControlOutput(np.zeros(6), path='emergency_stop', certs=None)
```

## 4. 正确性论证（增量更新）

### 引理 32（逐层量化误差的 Lipschitz 传播上界）

**陈述**：设网络 f = f_L ∘ … ∘ f_1，第 l 层 Lipschitz 常数为 L_l，量化在第 l 层输出注入误差 δ_l 且 ‖δ_l‖ ≤ ε_l。则
‖f_q(x) − f(x)‖ ≤ Σ_{l=1}^{L} (Π_{k=l+1}^{L} L_k) ε_l。

**证明**：令 δ_l = f_q^{1:l}(x) − f^{1:l}(x)，其中 f^{1:l} 为前 l 层复合。有
‖δ_l‖ = ‖f_l(f_q^{1:l−1}(x)) − f_l(f^{1:l−1}(x)) + η_l‖ ≤ L_l‖δ_{l−1}‖ + ε_l。
递推展开得 ‖δ_L‖ ≤ Σ_l (Π_{k=l+1}^{L} L_k) ε_l。∎

**工程含义**：深层/大 Lipschitz 的层会把早期量化误差指数级放大，因此 bit 不能均匀分配——这正是 CGMPA 存在的理由。

### 引理 33（证书精度支配）

**陈述**：设某证书的精确判据为 g(x)，量化计算为 ĝ(x)，|ĝ(x) − g(x)| ≤ ε_c，且 |g(x)| ≥ γ_c > ε_c。则 sign(ĝ(x)) = sign(g(x))，即量化不会翻转该证书的通过/拒绝判定。

**证明**：若 g(x) ≥ γ_c > ε_c，则 ĝ(x) ≥ g(x) − ε_c > 0；若 g(x) ≤ −γ_c < −ε_c，则 ĝ(x) ≤ g(x) + ε_c < 0。∎

**工程含义**：守卫的量化误差必须小于其决策裕度，否则会出现「reject 被翻成 accept」的静默失效。CPDG 因此为每张证书独立求 b_c^min。

### 引理 34（QEC 的有效域）

**陈述**：QEC 的局部误差项 ε_l 依赖标定域内的激活范围 [a_l^min, a_l^max]。若 x ∉ X_cert 使真实激活越界，则区间界不再包含真实激活，QEC 上界失效（且通常是乐观失效）。

**证明**：区间算术的包含性前提是真实取值落在给定区间内；越界后该前提不成立，局部误差估计不再覆盖真实误差。∎

**工程含义**：QEC 必须与 QVM 绑定使用；QVM 判定越域时，QEC 的数值上界一律作废，不得作为准入依据。

### 定理（量化部署的执行集不扩张与误差有界）

**陈述**：在以下假设下：
(B1) x ∈ X_cert（QEC 有效，引理 34）；
(B2) ε_q(x; b) ≤ m_safe（量化误差在安全裕度内）；
(B3) 对全部安全证书 ε_c(b_c) < γ_c（精度支配，引理 33）；
(B4) v30 的鲁棒不变集对半径 m_safe 的输入扰动前向不变（tube-MPC 假设）；
则 Exec_v31 ⊆ Exec_v30，且闭环稳态误差满足 ‖e_ss‖ ≤ (m_safe + L_d·T)/λ_cl。

**证明**：
- 执行集包含性：设 x 被 v31 准入，则实际执行 u_q = f_q(x) = f(x) + δ，‖δ‖ ≤ ε_q(x;b) ≤ m_safe。由 (B4)，轨迹仍留在 v30 的鲁棒不变集内，即 v30 在该状态也允许执行；故 v31 不引入 v30 之外的执行，Exec_v31 ⊆ Exec_v30。
- 守卫不翻案：(B3) + 引理 33 保证量化证书与精确证书同号，不存在「量化守卫误放行」的新执行。
- 误差界：单步输入扰动 δ（≤ m_safe）与采样零阶保持误差（≤ L_d·T）经闭环收缩率 λ_cl 放大，稳态误差上界为 (m_safe + L_d·T)/λ_cl。∎

**诚实声明**：(B4) 的 m_safe 需离线计算鲁棒正不变集；若 L_l 的谱范数界过松，QEC 会过度保守，导致 m_safe 预算不可行、频繁回退教师。此外 (B1) 在真实分布漂移下不恒成立，必须依赖 QVM 的在线监控，而非静态假设。

### 频率-量化联合最优（命题）

**陈述**：设 ε_q(b) 随 b 单调下降、延迟 τ(b) 随 b 单调上升，联合代价 J(b) = w_ε·ε_q(b)² + w_T·(L_d·τ(b))²。则当 b 连续可微且两端导数非零时，最优 b* 满足
w_ε·ε_q·(dε_q/db) + w_T·L_d²·τ·(dτ/db) = 0，
即「误差边际收益 = 延迟边际成本」，一般为内点解。

**证明**：对 J 求一阶条件即得；由 dε_q/db < 0、dτ/db > 0，两项异号，存在平衡点。∎

**工程含义**：不存在「越精确越好」或「越低 bit 越快越好」的单向结论；FQCD 在候选位宽/频率组合上直接搜索该平衡点。

## 6. 本轮最大风险（最终确认）

**一句话**：**QEC 的「标定域有效性」与机器人真实部署分布的失配**——量化误差上界只在 X_cert 内严格成立，而 OOD（打滑、载荷突变、传感器退化、光照骤变）会让真实量化误差悄然越过上界，证书链却仍显示「通过」，从而制造出比全精度更隐蔽的**虚假安全**；这是整个量化-证书框架从实验室走向现场部署的生死线。
