# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因」IP-214~223；灵感循环第 1 轮；本轮灵感：「嵌入式系统」×「实时推理」）

> 第 65 轮把不可辨识的“几何 vs 传感器 vs 模型”升级成三阶段故障归因，并自述最大风险：**归因依赖有限假设集与视觉/几何失效独立；未知复合故障会被强行归入最近假设、只膨胀错误的球，而系统因“已经归因”更自信地继续执行。** 本轮不推翻 VISTA，而是追问一个被 VISTA 当成“架构常量”的东西：**“语义流慢而聪明、实时流快而固定”这条分界线本身，在真实嵌入式平台上并不免费。** 世界模型推断、归因、conformal、认证都要花时间、占内存、受温度/功耗/共运行任务影响；一个在论文里 50ms 能算完的证书，在 30Hz 控制回路里可能根本来不及出。于是本轮核心命题是：
>
> **把时间从“预算数字”升级为“第一类证据与第一类证明义务”：让时序签名成为独立于几何/视觉/力的第四条故障通道，让每份安全证书都是一份可调度、可中断、可退化的证明义务。**

## 0. 直觉与动机

**灵感 1（嵌入式系统 → 时间是被忽略的第四条可错通道）**
直觉：VISTA 担心透明/镜面/对抗 patch 让视觉与几何共享同一个 OOD 源，于是“归因”整体失真。但在嵌入式平台上，每一次推理、每一次中断、每一次 DMA 都天然带时间戳：WCET 超了、抖动变大、队列积压、频率被热降、传感器与执行器时间戳错位——这些量**不需要新增传感器**，且与几何、视觉、力在物理上几乎不共享失效源。第 65 轮把“第三个物理独立通道（IMU/本体感觉）”列为未来工作；本轮指出：**时序就是已经付过钱的第四通道**。但必须诚实：时延会被“任务难”污染（难场景推理更久），所以不能直接拿时延当故障证据，必须先用一个**固定微基准 canary** 把“机器慢”与“任务难”分开。

**灵感 2（实时推理 → 推理要 anytime，证书要 time-uniform）**
直觉：VISTA 的语义流默认“算完再执行”。实时系统里没有“算完”，只有截止期。把归因与证书做成 anytime：任何时刻被打断，都给出一个**当时仍然有效**的（更粗的）结论；时间越多结论越紧，但绝不出现“算到一半所以没有安全结论”。这要求置信陈述**对任意停止时刻一致有效**（不是固定样本量下的有效），于是用 e-process / always-valid confidence sequence，而不是 softmax + 固定阈值。截止期是数据依赖的停时——普通置信区间在这里是错的。

**灵感 3（嵌入式系统 → 安全 = 控制安全 × 时间安全）**
直觉：第 65 轮的“长预测、短执行”只约束了**距离**不可逆视界 k≤m；真正决定伤害的是**时间**：从故障发生到“检出 + 重规划 + 停住”要多久，这段反应时间必须短于抵达不可逆点的时间。WCET 与抖动一进来，k* 就不再是纯控制量，而是**可调度性**方程的解：
k*_RT = max k s.t. kΔ + t_detect^WCET + t_plan^WCET + t_stop^WCET + J ≤ m_time。

**灵感 4（资源受限 → 认证降级阶梯，而不是临场拍脑袋）**
直觉：算力一紧，VISTA 会怎么办？真实系统常常是“临时关掉一些东西”，这既不认证也不可审计。本轮预先把能力排成阶梯 R0..R5（完整 VISTA → 缩短 H → 减集成/n_worst → 降视觉 ROI → 常速预测 + 力护栏 → 安全停），每一档都有**离线证明的安全不变式**与可界定的切换代价；运行时只做“选满足截止期的最低代价档”，且**永不跌破安全地板**。

**灵感 5（合流 → TEMPO：Timing-Embedded Multi-tier Proof Obligations）**
- **VISTA 骨架不变**：几何/力/视觉/归因仍是主体；TEMPO 只负责“时间层”。
- **TEP / TWC**：时序证据平面 + 固定 canary，产生与任务难度解耦的资源签名。
- **FIR/AFA → ATA**：anytime 故障归因，用 running-max e-process 得到**对任意停时有效且嵌套**的认证支持集。
- **CSC → SPR**：把认证前缀从“距离约束”升级为“反应时间可调度约束”。
- **RSC → CDL**：认证降级阶梯，每档预证明、切换有界、地板不可越。
- **新增 DSI**：截止期感知的分割推理（远端语义 + 本地 anytime 回退），网络延迟成为显式故障假设。
- **新增 QSC**：量化感知安全裕度（INT8/定点下的 conformal 与区间算术）。
- **新增 CR**：认证运行时（核隔离、锁缓存、锁频、看门狗、可抢占检查点）。
- **CSP-V → CSP-T**：块边携带 (WCET, deadline, 安全不变式)，时间作为规划资源。
- **AIC-V → AIC-T**：干扰集增截止期错过、抖动、WCET 超限、热降频、时钟漂移、网络延迟/丢包，以及“难场景同时拉长推理并诱发策略 OOD”的共因。
- **J_vista → J_tempo**：证书增 τ_signature、pWCET_ver、slack_min、k*_RT、rung、canary_ver、quant_ver、deadline_miss、offload_delay。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（TEMPO 闭环）**：TEMPO = (VISTA, TEP, TWC, ATA, SPR, CDL, DSI, QSC, CR, CSP-T, AIC-T, J_tempo)。定位：VISTA 的“时间层”升级。不变式：(i) **anytime**——每个调度时刻都存在有效证书或安全地板；(ii) **timing-bound**——实时路径每个操作都有静态/测量的 WCET 上界，且认证只在该上界下成立；(iii) **isolation**——认证运行时的隔离不变式可监控；(iv) 学习写操作仍只在语义流/离线流。
- **定义 234（时序证据平面 TEP 与 canary 条件化残差）**：每个控制周期并行运行固定微基准 canary，得 canary slack c_t；采集任务 slack s_t、抖动 j_t（p99）、队列深度 q_t、频率/温度 h_t、传感器-执行器时间戳偏差 δ_t、重试次数 n_t。定义块级时序签名
  ρ_time = [c̄, s̄−ĝ(c̄,w), j_p99, q_max, h_min, δ_drift]ᵀ ∈ ℝ⁶，
  其中 ĝ 是由离线 workload→slack 模型给出的“在资源状态 c 与任务量 w 下应有的任务 slack”。ĝ 的作用是把“机器慢”从“任务难”里减掉。扩展签名 ρ̃ = [ρ_phy(15), ρ_time(6)]ᵀ ∈ ℝ²¹。
- **定义 235（时序故障假设 ℋ_T）**：ℋ_T = ℋ ∪ {H_compute, H_sync, H_net}。H_compute：资源争用/热降频/WCET 超限；H_sync：时钟漂移、传感器-执行器时间错位；H_net：卸载链路延迟/丢包。**截止期错过是观测量，不是假设**（它可由多种原因产生）。似然 p(ρ̃|H) 由离线注入（co-runner 负载、锁频/降频、网络损伤、时钟偏移）拟合。
- **定义 236（时序可辨识性：第四通道）**：把第 65 轮线性化扩为 E[ρ̃|θ]=S̃θ、ρ̃∼N(S̃θ,Σ̃_ρ)。**canary 可分性**要求：(a) ∂c/∂θ_compute ≥ γ > 0（canary 对资源敏感）；(b) ∂c/∂θ_geo = ∂c/∂θ_vis = ∂c/∂θ_model = 0（canary 对感知难度与几何不敏感，可实验检验）。在 (a)(b) 下，S̃ 的时序行对 θ_phy 近零、对 θ_compute 非零，故 S̃ᵀΣ̃⁻¹S̃ 在 (θ_phy, θ_compute) 上近分块对角，κ_t = λ_min/λ_max 由 canary 信噪比控制。**注意：可辨识性 ≠ WCET 可靠性；后者由定义 242 单独处理。**
- **定义 237（anytime 故障归因 ATA）**：对每个 H 维护 e-process E_H(t)（非负、适应、在 H 下 E[E_H]≤1），并用 running max Ê_H(t)=max_{s≤t}E_H(s) 保证**拒绝集单调**。认证支持集
  Ŝ_δ(t) = {H ∈ ℋ_T : Ê_H(t) < 1/δ}。
  由 Ville 不等式，对**任意停时** τ（含“截止期到了就停”）有 P[H* ∉ Ŝ_δ(τ)] ≤ δ；running max 使 Ŝ_δ(t) 随 t 嵌套不增。点估计 Ĥ(t) 由按安全相关性排序的 refine 队列逐步精化（先算高先验/高风险的假设）。归因输出为 (Ĥ(τ), Ŝ_δ(τ))：|Ŝ_δ|=1 才定向处置，否则 ambiguous → CDL。
- **定义 238（可调度认证前缀 SPR）**：设控制周期 Δ，反应时间
  T_react(k) = kΔ + T_det^ub + T_plan^ub + T_stop^ub + J，
  其中上标 ub 为 WCET 上界，J 为抖动上界（p99.9）。不可逆时间预算 m_time 由第 65 轮距离不可逆视界 m 与当前速度反解。可调度认证前缀
  k*_RT = max{k ≤ H : T_react(k) ≤ m_time ∧ (∀H∈Ŝ_δ: ρ_safe(k,H) ≥ 0) ∧ kΔ ≥ T_det^ub}。
  最后一项保证“检测窗口不短于一步执行”，否则 k*=0 → 地板档。
- **定义 239（认证降级阶梯 CDL）**：能力档 R0..R5：R0 完整 VISTA；R1 缩短 H；R2 减集成 M 与 n_worst；R3 降视觉 ROI/分辨率；R4 常速预测 + 力护栏；R5 安全停（地板）。每档 r 绑定 (算力预算 C_r, WCET 上界 T_r^ub, 安全不变式 I_r, 切换代价 σ_{r→r'})，I_r 离线证明。运行时选
  r* = min{cost(r) : I_r 成立 ∧ T_r^ub ≤ 剩余 slack ∧ 当前块允许切到 r}。
  切换只允许在**检查点**（定义 244）发生，且 σ 计入 T_plan^ub。**R5 永远可调度**，故阶梯不会无解。
- **定义 240（截止期感知分割推理 DSI）**：语义推理可卸载到边缘/服务器。请求带截止期 d_req；本地保留 anytime 回退。若响应在 d_req 后到达则丢弃并记 H_net 证据；实时路径**绝不阻塞等待远程**，只轮询已完成结果。网络延迟用分位数上界 D_net^ub，时钟用 PTP/硬件时间戳对齐；D_net 超界即进入 CDL 相应档。
- **定义 241（量化感知安全裕度 QSC）**：标定与推理使用**同一量化域**（INT8/定点）与同一舍入模式。非一致性分数在量化域计算，split-conformal 在可交换量化样本上仍给 ≥1−α 覆盖。安全裕度用区间算术计算，并扣除量化误差上界 δ_q 与溢出保护：
  ρ_safe^q = ρ_safe − δ_q，要求 ρ_safe^q ≥ 0。定点累加器设饱和/异常标志，任何溢出即判证书无效。
- **定义 242（有效 WCET 与 pWCET）**：有效 WCET 是运行包络的函数
  WCET_ub = max_{(f,h,co)∈ℰ_os} WCET(f,h,co) + A_anom，
  ℰ_os 为频率/热状态/共运行任务包络，A_anom 为时序异常（缓存、加速器、预取）保守余量。对软实时语义流，用 MBPTA 的 pWCET 尾分位给概率保证（α_T）。**若无法排除时序异常，则不允许多段 WCET 组合，必须整体测量/隔离。**
- **定义 243（认证运行时 CR）**：核隔离（实时核独占）、缓存锁定/预取限制、关键段锁频（禁 DVFS）、内存分区、看门狗、每周期 TWC。运行时监控隔离不变式（例如 canary slack 方差、频率是否被外部改写）；违反即判 H_compute 并降档。CR 把定义 242 的“测量有效”变成“运行时可验证有效”。
- **定义 244（可抢占检查点）**：定义可安全快照的状态集 X = (φ̂, r_geo/r_force/r_model, Ŝ_δ, k*_RT, rung, 残差缓冲)。检查点是能在一个控制周期内完成快照/恢复且证书可复现的时刻。抢占只允许在检查点或块边界；快照/恢复的 WCET 计入 T_react 的 slack。**不允许在“归因写到一半”时被抢占后继续使用半成品**。
- **定义 245（CSP-T 时间资源规划）**：块边携带 (T^ub, d, I_r)；规划变为资源受限最短路，时间为资源。TSL 技能绑定时序包络；实际块耗时超出包络即 OOD。可插入 `timing_calib` 元技能（在 null_test 里跑 TWC 标定）。
- **定义 246（AIC-T 时序对抗认证）**：ℰ_T 增截止期错过、抖动、WCET 超限、热降频、时钟漂移、网络延迟/丢包，以及共因“难场景同时拉长推理并诱发策略 OOD”。n_cert 128→160。ρ_dir 在 worst-case timing 下取最坏；J_tempo 增 pWCET_ver、canary_ver、quant_ver。
- **定义 247（TEMPO 证书 J_tempo）**：J_tempo = (J_vista, τ_signature, pWCET_ver, slack_min, k*_RT, rung, canary_ver, quant_ver, deadline_miss, offload_delay, cr_ver)。Valid ⇔ Valid(J_vista) ∧ T_react(k*_RT) ≤ m_time（在 WCET_ub 下）∧ k*_RT≥1 ∧ rung ≥ 地板 ∧ 认证支持集在停时有效 ∧ 量化裕度非负 ∧ CR 隔离不变式成立。
- **定义 248（TEMPO 闭环算子）**：语义/离线流 [TEP 标定→TWC 基线→ATA 归因→SPR→CDL 选档→CSP-T 块规划→AIC-T→QSC→证书]; 实时流 [TWC→TEP 采集→SPR 快校验→CDL 档检查→SIGINT/DMA 时间戳对齐→认证前缀派发→检查点抢占→力/视觉/时序早停→地板]。

## 2. 关键算法骨架

```python
# TEP + TWC：把“机器慢”从“任务难”里分离（实时）
c = canary.run_fixed_workload()                 # 资源状态
r_time = [c, task_slack - g_hat(c, workload), jitter_p99(),
          queue_max, freq_min, skew_drift()]
rho_tilde = concat(phase_signature, r_time)     # 21 维

# ATA：anytime 归因，running-max e-process（语义流/任意可中断点）
for H in frontier_order(prior, risk):
    E[H].update(evidence_slice())               # e-value, H 下 E[E] <= 1
    Ehat[H] = max(Ehat[H], E[H])
    if deadline_reached: break
support = {H: Ehat[H] < 1/delta}                # time-uniform, 嵌套
h_star = argmax(refined_loglik) if len(support) == 1 else None

# SPR + CDL：可调度前缀与认证降级（语义流，快校验在实时）
rung = min_rung_satisfying(deadline_budget, support)     # 预证明的档
k_star = max_k(lambda k: react_time(k) <= m_time
               and safety_margin(k, support, rung) >= 0)
if k_star == 0: rung = R5; k_star = 0                     # 安全停

# 实时派发 + 检查点抢占
for a in A[:k_star]:
    dispatch(a, deadline=next_checkpoint())
    if at_checkpoint() and should_preempt():
        snapshot(X); break
    if monitor.abort(): rung = downgrade(rung); break
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（canary 条件化后的时序可辨识性）**：若 canary 满足定义 236 的 (a)(b)，则扩展 Fisher 矩阵在 θ_phy 与 θ_compute 上近分块对角，H_compute 可由 canary 行单独识别；H_sync 由 δ_drift、H_net 由 offload 延迟分位识别。合因项（难场景同时拉长任务耗时）被 ĝ(c,w) 吸收后不进入 H_compute 列。
- **引理 10（可调度前缀的安全性）**：若 k*_RT 满足定义 238 且 WCET_ub 为真上界（A94），则在前缀内任意一步发生的故障，其检出/重规划/停住都在 m_time 之前完成；单块越界概率 ≤ α_T + α_chunk + δ_fi + α_vis。**前提是 WCET 不被低估——这正是本轮风险的落点。**
- **定理 9（TEMPO 端到端时间-安全）**：在 A88–A97 下，Valid(J_tempo) ⇒ 第 65 轮控制安全 ∧ 时间可调度安全（引理 10）∧ anytime 可用性（定理 10）∧ 降级可审计（CDL 每档不变式）∧ 隔离成立（CR）。证书链从“几何-技能-干扰-接触-归因”扩到“……-归因-时间”。
- **定理 10（anytime 归因的有效性与单调性）**：running-max e-process 使 Ŝ_δ(t) 随 t 嵌套不增，且对任意停时（含数据依赖的截止期停时）满足 P[H*∉Ŝ_δ(τ)]≤δ（Ville）。因此“截止期到了就停”不破坏有效性；若 deadline < τ_min（连最粗安全集都算不出），直接落到 R5 地板。
- **命题（阶梯避免两种坏结局）**：无 CDL 时，资源紧张要么“硬算完”导致截止期错过（时间不安全），要么“临时关模块”导致未证明降级（控制不安全）；CDL 把选择限制在预证明档内，故任一时刻都满足 I_r，且 r* 存在（R5 恒可调度）。
- **实时性**：新增 TWC 0.1ms、TEP 采集 0.02ms、SPR 快校验 0.2ms、CDL 查表 0.05ms、CR 监控 0.1ms，合计约 0.5ms；与第 65 轮 2.5ms 合并目标 ≤3.0ms（30Hz 下预算 33ms，占 9%），且以 WCET 而非均值报账。

## 5. 本轮最大风险

**一句话**：TEMPO 把安全押在 WCET/pWCET 的可信上；在带缓存/加速器/DVFS 的 COTS SoC 上，时序异常、共运行干扰、热降频和测量者效应都可能让上界偏乐观，而系统恰恰是**用时间来证明时间安全**——一旦 WCET 被低估，“可调度证书”会变成一张看似严格、实则把执行推过不可逆点的通行证。

## 2. 形式化定义（完整版）

**定义 233（TEMPO 闭环）** TEMPO 是 VISTA 的“时间层”升级：保留第 65 轮“语义流 ∘ 实时流”的主体，挂载 TEP（时序证据）、TWC（canary）、ATA（anytime 归因）、SPR（可调度前缀）、CDL（降级阶梯）、DSI（分割推理）、QSC（量化证书）、CR（认证运行时），并原位升级 CSP-V→CSP-T、AIC-V→AIC-T、J_vista→J_tempo。不变式：
1. **anytime**：每个调度时刻存在有效证书或安全地板；
2. **timing-bound**：实时路径每个操作有 WCET 上界，认证只在该上界下成立；
3. **isolation**：认证运行时的隔离不变式可监控、可证伪；
4. 学习写操作仍只在语义流/离线流，实时流零学习写。
与第 65 轮的区别：VISTA 把时间当“预算数字”，TEMPO 把时间当**证据与证明义务**。

**定义 234（时序证据平面 TEP）** 每个控制周期并行运行固定微基准 canary，得到 canary slack c_t；同时采集任务 slack s_t、抖动 j_t（p99）、队列深度 q_t、频率/温度 h_t、传感器-执行器时间戳偏差 δ_t、重试次数 n_t。定义块级时序签名
ρ_time(t) = [c̄_t, s̄_t − ĝ(c̄_t, w_t), j_p99, q_max, h_min, δ_drift]ᵀ ∈ ℝ⁶，
其中 ĝ 是离线拟合的 workload→slack 模型，w_t 为当前任务量估计。s̄−ĝ 是**资源条件化后的任务时延残差**，用于吸收“难场景推理更久”的合因。扩展签名 ρ̃ = [ρ_phy(15), ρ_time(6)]ᵀ ∈ ℝ²¹，其中 ρ_phy 沿用第 65 轮定义 220。

**定义 235（时序故障假设 ℋ_T）** ℋ_T = ℋ ∪ {H_compute, H_sync, H_net}：
- H_compute：资源争用、热降频、WCET 超限、缓存/加速器干扰；
- H_sync：时钟漂移、传感器-执行器时间戳错位；
- H_net：卸载链路延迟、丢包、远端排队。
**截止期错过是观测量而不是假设**，因为它可由 H_compute/H_net/H_policy 共同导致。似然 p(ρ̃|H) 由离线注入拟合：co-runner 负载、锁频/降频、网络损伤、时钟偏移、以及“难场景”数据集。先验按平台部署与历史故障率设定。

**定义 236（时序可辨识性：第四通道）** 线性化 E[ρ̃|θ]=S̃θ、ρ̃∼N(S̃θ,Σ̃_ρ)。canary 可分性条件：
(a) ∂c/∂θ_compute ≥ γ > 0（canary 对资源敏感）；
(b) ∂c/∂θ_geo = ∂c/∂θ_vis = ∂c/∂θ_model = ∂c/∂θ_policy = 0（canary 对感知/几何/策略难度不敏感）。
(b) 是可实验检验的强假设（见 E242），不是先验真理。在 (a)(b) 下，S̃ 的时序行对 θ_phy 近零、对 θ_compute 非零，S̃ᵀΣ̃⁻¹S̃ 在 (θ_phy, θ_compute) 上近分块对角，
κ_t = λ_min(S̃ᵀΣ̃⁻¹S̃)/λ_max(S̃ᵀΣ̃⁻¹S̃)
由 canary 信噪比与 δ_drift/网络分位共同控制。**可辨识性不等于 WCET 可靠性**：前者说“能分辨谁慢”，后者说“慢多少的上界对不对”，由定义 242/243 单独处理。

**定义 237（anytime 故障归因 ATA）** 对每个 H 维护非负适应 e-process E_H(t)，在 H 下满足 E[E_H(τ)] ≤ 1（任意停时 τ）。用 running max
Ê_H(t) = max_{s≤t} E_H(s)
保证拒绝集单调。认证支持集
Ŝ_δ(t) = {H ∈ ℋ_T : Ê_H(t) < 1/δ}。
Ville 不等式给出：对任意停时 τ（**包括数据依赖的“截止期到了就停”**），P[H* ∉ Ŝ_δ(τ)] ≤ δ。点估计 Ĥ(t) 由按 (先验 × 风险 × 安全相关性) 排序的 refine 队列逐步精化：先算最可能且最危险的假设，每步输出一个可用的粗结论。归因输出 (Ĥ(τ), Ŝ_δ(τ))：|Ŝ_δ|=1 才定向处置；否则 ambiguous → CDL。**这取代第 65 轮“softmax + 固定阈值”的非停时有效做法。**

**定义 238（可调度认证前缀 SPR）** 设控制周期 Δ，反应时间
T_react(k) = kΔ + T_det^ub + T_plan^ub + T_stop^ub + J，
其中上标 ub 为 WCET 上界，J 为抖动上界（p99.9）。不可逆时间预算 m_time 由第 65 轮距离不可逆视界 m 与当前末端速度 v 反解（m_time≈m/v 的保守下界）。可调度认证前缀
k*_RT = max{ k ≤ H : T_react(k) ≤ m_time
             ∧ (∀H∈Ŝ_δ: ρ_safe(k,H) ≥ 0)
             ∧ kΔ ≥ T_det^ub }。
最后一项保证检测窗口不短于一步执行；若不存在这样的 k，则 k*_RT=0 并切 R5。T_plan^ub 含 CDL 切换代价 σ。与第 65 轮 CSC 相比：约束从“距离 k≤m”变成“时间 T_react(k)≤m_time”，WCET/抖动直接进入 k* 的取值。

**定义 239（认证降级阶梯 CDL）** 能力档：
- R0 完整 VISTA（全部 ATA + WCV-V + CSP-T）；
- R1 缩短 H（H←max(H_min,H/2)）；
- R2 减集成 M 与 n_worst（8→4）；
- R3 降视觉 ROI/分辨率/帧率；
- R4 常速预测 + 力护栏（跳过世界模型）；
- R5 安全停（地板）。
每档 r 绑定 (C_r, T_r^ub, I_r, σ_{r→r'})，I_r 离线证明（例如 R4 的 I 是“力限 + 滑移护栏仍生效”，R5 的 I 是“停止距离 < 剩余自由空间”）。运行时
r* = min{ cost(r) : I_r 成立 ∧ T_r^ub ≤ 剩余 slack ∧ 允许切到 r }。
切换只在检查点（定义 244）发生，σ 计入 T_plan^ub。R5 恒可调度，故阶梯不会无解。**CDL 把“临时关模块”的未证明降级变成“预证明档选择”。**

**定义 240（截止期感知分割推理 DSI）** 语义推理可卸载至边缘/服务器。请求携带截止期 d_req；本地保留 anytime 回退（至少 R4/R5）。若响应在 d_req 之后到达则丢弃，并把“迟到量”作为 H_net 证据。实时路径只轮询已完成结果，**绝不阻塞等待远程**。网络延迟用分位上界 D_net^ub，时钟用 PTP/硬件时间戳对齐；D_net 超界即降档。远端返回的证书必须带 τ_signature 与 pWCET_ver，否则本地不采信。

**定义 241（量化感知安全裕度 QSC）** 标定与推理使用同一量化域（INT8/定点）与同一舍入模式。非一致性分数在量化域计算；split-conformal 在可交换量化样本上仍给 ≥1−α 覆盖（覆盖性只依赖可交换性，不依赖连续性）。安全裕度用区间算术计算并扣除量化误差上界 δ_q：
ρ_safe^q = ρ_safe − δ_q，要求 ρ_safe^q ≥ 0。
定点累加器设饱和与异常标志，任何溢出即判证书无效（不允许“溢出后回绕仍继续”）。

**定义 242（有效 WCET 与 pWCET）** 有效 WCET 是运行包络的函数
WCET_ub = max_{(f,h,co)∈ℰ_os} WCET(f,h,co) + A_anom，
ℰ_os 为频率 f、热状态 h、共运行任务 co 的包络，A_anom 为时序异常（缓存、加速器、预取、分支预测）保守余量。对软实时语义流用 MBPTA 的 pWCET 尾分位给概率保证 α_T；对硬实时实时流只用确定上界。**若无法排除时序异常，则不允许多段 WCET 组合，必须整体测量或强制隔离。**

**定义 243（认证运行时 CR）** 核隔离（实时核独占）、缓存锁定/预取限制、关键段锁频（禁 DVFS）、内存分区、看门狗、每周期 TWC。运行时监控隔离不变式：canary slack 方差、频率是否被外部改写、缓存锁定是否生效、内存带宽是否超预算。违反即判 H_compute 并降档。CR 把定义 242 的“测量时有效”变成“运行时可验证有效”。

**定义 244（可抢占检查点）** 可安全快照的状态集 X = (φ̂, r_geo/r_force/r_model, Ŝ_δ, k*_RT, rung, 残差缓冲)。检查点是能在一个控制周期内完成快照/恢复、且恢复后证书可复现的时刻。抢占只允许在检查点或块边界；快照/恢复 WCET 计入 T_react 的 slack。**禁止在“归因写到一半”被抢占后继续使用半成品状态**——否则 anytim 归因的一致性会被破坏。

**定义 245（CSP-T 时间资源规划）** 在 CSP-V 的块级 A* 上，每条块边携带 (T^ub, d, I_r)；规划变为资源受限最短路，时间为资源。TSL 技能绑定时序包络；实际块耗时超出包络即判 OOD、不入图。可插入 `timing_calib` 元技能（在 null_test 中跑 TWC 标定与 canary 基线更新）。

**定义 246（AIC-T 时序对抗认证）** 干扰集
ℰ_T = ℰ_V × ℰ_time，
ℰ_time 含截止期错过、抖动、WCET 超限、热降频、时钟漂移、网络延迟/丢包；并含共因“难场景同时拉长推理并诱发策略 OOD”。n_cert 128→160。ρ_dir 在 worst-case timing 下取最坏；ρ_force 在最坏时序下重算（力环路的延迟会放大冲击）。J_tempo 增 pWCET_ver、canary_ver、quant_ver、cr_ver。**时序共因下不要求归因正确，只要求判 ambiguous 并落地板。**

**定义 247（TEMPO 证书 J_tempo）** J_tempo = (J_vista, τ_signature, pWCET_ver, slack_min, k*_RT, rung, canary_ver, quant_ver, deadline_miss, offload_delay, cr_ver)。验证规则：
Valid(J_tempo) ⇔ Valid(J_vista)
∧ T_react(k*_RT) ≤ m_time（在 WCET_ub 下）
∧ k*_RT ≥ 1
∧ rung ≥ R_floor（默认 R4，易损/未知故障时 R5）
∧ 认证支持集 Ŝ_δ 在停时有效（running-max）
∧ ρ_safe^q ≥ 0（量化裕度非负）
∧ CR 隔离不变式成立
∧ aic_t_ver / canary_ver / quant_ver 为当前版本。
审计链在 VISTA 基础上新增：为何只执行 k*_RT 步（SPR，含 WCET/抖动）、当前哪一档及为何（CDL）、时序是否可信（canary/CR）、量化是否吃掉裕度（QSC）。

**定义 248（TEMPO 闭环算子）**
- 语义/离线流：[TEP 标定→TWC 基线→ATA 归因→SPR 计算→CDL 选档→CSP-T 块规划→AIC-T 认证→QSC→J_tempo]；
- 实时流：[TWC→TEP 采集→SIGINT/DMA 时间戳对齐→SPR 快校验→CDL 档检查→认证前缀派发→检查点/抢占→力/视觉/时序早停→地板]。

## 3. 关键算法伪代码

### IP-224 / IP-225 TEP + TWC（把资源与难度分开）

```python
class TimingEvidencePlane:
    def __init__(self, g_hat):
        self.g_hat = g_hat                 # workload+resource -> expected slack

    def sample(self, task_slack, workload, hw):
        c = run_canary()                   # fixed micro-benchmark, no perception input
        r = [c.mean,
             task_slack.mean - self.g_hat(c.mean, workload),
             task_slack.p99, hw.queue_max,
             hw.freq_min, hw.skew_drift]
        return np.asarray(r)

    def signature(self, phases, r_time):
        return np.concatenate([self._phy(phases), r_time])   # 21-dim


class TimingCanary:
```

### IP-226 ATA（anytime 归因 + 对停时有效）

```python
class AnytimeAttribution:
    def __init__(self, prior, delta=0.05):
        self.prior, self.delta = prior, delta
        self.E = {h: 1.0 for h in HYP_T}
        self.Ehat = {h: 1.0 for h in HYP_T}

    def update(self, h, log_e_increment):
        self.E[h] *= np.exp(log_e_increment)
        self.Ehat[h] = max(self.Ehat[h], self.E[h])

    def run(self, evidence_stream, deadline):
        for h in self._frontier():              # 按 先验×风险×安全相关性 排序
            if hw.now() >= deadline:
                break                           # 停时是数据依赖的，仍然有效
            self.update(h, evidence_stream.log_e(h))
        support = {h for h in HYP_T if self.Ehat[h] < 1.0 / self.delta}
        h_star = max(support, key=lambda h: evidence_stream.loglik[h]) \
                 if len(support) == 1 else None
        return h_star, support, hw.now()

    def _frontier(self):
        # 高先验、高危险（如 H_geo/H_force）先算，保证早停时最有用的结论已出
        return sorted(HYP_T, key=lambda h: -(self.prior[h] * risk(h)))
```

```python
def schedulable_prefix(A, support, m_time, rung, delta, jitter_ub):
    if rung == R5:
        return 0
    budget = m_time - t_detect_ub() - t_plan_ub(rung) - t_stop_ub() - jitter_ub
    if budget < DELTA:
        return 0
    k_max = int(np.floor(budget / DELTA))
    for k in range(min(len(A), k_max), 0, -1):
        if all(safety_margin(A[i], h, rung) >= 0
               for i in range(k) for h in support):
            return k
    return 0


def select_rung(support, deadline_budget, checkpoint_ok):
    for r in (R0, R1, R2, R3, R4):
        if (invariant_holds(r, support)
                and wcet_ub(r) <= deadline_budget
                and (checkpoint_ok or r == current_rung)):
            return r
    return R5                                  # 地板，恒可调度
```

```python
def split_inference(request, obs, d_req, local_fallback):
    future = offload.submit(request, obs, deadline=d_req)
    while hw.now() < d_req:
        a = local_fallback.poll()              # 本地 anytime，不阻塞
        if a is not None:
            return a, 'local'
        if future.done():
            resp = future.result()
            if hw.now() <= d_req and resp.ver == CURRENT:
                return resp, 'remote'
        spin_until(next_tick())
    future.cancel()                            # 迟到即弃，记 H_net 证据
    return local_fallback.floor(), 'floor'
```

## 4. 推导

**引理 9（canary 条件化后的时序可辨识性）** 设 E[ρ̃|θ]=S̃θ、ρ̃∼N(S̃θ,Σ̃_ρ)。由定义 236 的条件 (a)(b)，canary 行在 θ_phy 上为零、在 θ_compute 上非零；任务 slack 残差经 ĝ 条件化后，其对 θ_policy/θ_vis 的合因（“难场景更久”）被 ĝ(c,w) 吸收，因此 S̃ 的时序行只对 θ_compute/θ_sync/θ_net 敏感。于是 S̃ᵀΣ̃⁻¹S̃ 在 θ_phy 与 θ_time 之间近分块对角，κ_t 由 canary 信噪比与 δ_drift/网络分位控制；只要 κ_t>0，H_compute 与 H_geo/H_force/H_model 可分离。∎

**引理 10（可调度前缀的安全性）** 设 k*_RT 满足定义 238，且 WCET_ub 为真上界（A94）。前缀内任一步 s≤k*_RT 发生故障时，其最坏反应时间 T_react(k*_RT) ≤ m_time，因此检出、重规划与停住均在抵达不可逆点之前完成。由第 65 轮引理 8 的联合界，单块越界概率
P[越界] ≤ α_T + α_chunk + δ_fi + α_vis，
其中 α_T 为 WCET/pWCET 尾概率。若 k*_RT=0，则切 R5，无执行承诺。∎

**定理 9（TEMPO 端到端时间-安全）** 在 A88–A97 下：
1. **时间可归因**：引理 9 给出 H_compute/H_sync/H_net 的可辨识性；canary 使时序证据不被 workload 污染。
2. **控制安全不回退**：归因正确时沿用 VISTA 定理 7 的定向膨胀；归因 ambiguous 时由 CDL 选预证明档，不临时拍脑袋。
3. **时间安全**：引理 10 保证前缀在 WCET 上界下可停止；k*_RT 含检测窗口约束，避免“来不及反应”。
4. **anytime 可用**：定理 10 保证截止期截断不破坏归因有效性。
5. **优雅降级**：视觉失效→R3；算力紧张→R1/R2；网络迟到→DSI 本地回退；未知/共因→ambiguous→R4/R5。任一时刻都满足某档不变式。
6. **证书六层链**：Valid(J_tempo) ⇔ 控制安全 ∧ 归因有效 ∧ 可调度 ∧ 档位合法 ∧ 量化裕度非负 ∧ 隔离成立。∎

**定理 10（anytime 归因的有效性与单调性）** running-max e-process Ê_H(t)=max_{s≤t}E_H(s) 在 H 下仍满足 E[Ê_H(τ)]≤1（可选停时定理的保守形式）。由 Ville 不等式，对任意停时 τ（含数据依赖的截止期停时），P[∃t: Ê_{H*}(t) ≥ 1/δ] ≤ δ，故 true H* 以 ≥1−δ 概率始终留在 Ŝ_δ(t) 中。Ê 单调不减 ⇒ Ŝ_δ(t) 嵌套不增 ⇒ 任意早停给出的支持集是后续支持集的超集，归因结论不会因“多算了”而被推翻。若 deadline < τ_min（连最粗安全集都算不出），直接 R5。∎

**命题（CDL 避免两种坏结局）** 无 CDL 时资源紧张只有两条路：硬算完→截止期错过（时间不安全），或临时关模块→未证明降级（控制不安全）。CDL 把运行时选择限制在预证明档内：任一档满足 I_r；R5 恒可调度，故 r* 存在。切换代价 σ 计入 T_plan^ub，且只在检查点发生，避免切换本身制造新的时间违规。∎

## 7. 已知风险

**一句话**：TEMPO 把安全押在 WCET/pWCET 的可信上；在带缓存/加速器/DVFS 的 COTS SoC 上，时序异常、共运行干扰、热降频和测量者效应都可能让上界偏乐观，而系统恰恰是**用时间来证明时间安全**——一旦 WCET 被低估，“可调度证书”会变成一张看似严格、实则把执行推过不可逆点的通行证。

**次级风险与缓解**：
1. **COTS 上 WCET 不可靠**：缓存/加速器带来时序异常，分段 WCET 不可组合；缓解：核隔离 + 锁缓存 + 锁频，MBPTA 尾分位，A_anom 保守余量，E249 红队专测；无法排除异常时只用整体测量上界。
2. **测量者效应**：采集本身扰动时序；缓解：硬件计数器/PMU，canary 与任务解耦，采样降频，测量开销计入 WCET。
3. **canary 条件 (b) 不成立**：共享缓存/内存带宽让难场景也拖慢 canary；缓解：E242 显式检验，多 canary + 随机化，必要时用“固定输入子任务”替代纯微基准。
4. **anytime 在截止期给出过粗结论**：支持集仍大；缓解：按风险排序的 refine 队列、离线 warm start、预先算好各档的安全集。
5. **热/DVFS 非平稳**：WCET 包络随温度漂移；缓解：关键段锁频、热感知包络、降额与降档联动。
6. **卸载链路不可控**：网络延迟/安全边界；缓解：本地 anytime 回退、迟到即弃、证书校验，绝不阻塞实时。
7. **量化吃掉安全裕度**：δ_q 大于裕度导致恒无效；缓解：区间算术、保守舍入、必要时升精度或提高裕度。
8. **新增假设再次落入有限假设集陷阱**（第 65 轮风险的延续）：时序只提供新证据轴，不解决未知复合故障；缓解：时序只作为证据而非标签，高熵即 ambiguous，CDL 地板兜底。
