# 第 71 轮（承接第 70 轮「HYDRA-RAS」IP-264~274；灵感循环新循环第 4 轮；本轮灵感：「姿态估计」×「位姿估计」）

> R66–R70 一路补上了控制权、未来、测量、求证、身体状态，但它们共享一个从未被点破的底座：**系统始终知道「东西在哪」**。R70 的迟滞包络把 θ_out 约束在 θ_in 的邻域内，前提是 θ_in、关节零位、世界系、手眼变换都已给定；R68 的标定修的是**单个传感器的内参**；R69 的交互是「向另一个模态求证」。可真实系统里，参照系本身是**估出来的、相对的、会漂的**，而物体位姿常常**因对称而多解**。
>
> 本轮两个灵感是同一件事的两个尺度：
> - **姿态估计（attitude / posture on SO(3)）**提醒我们：方向是流形上的量，用欧拉角/标量方差去描述会在奇点处崩溃，且身体姿态与相机姿态必须放在同一套等变语言里；
> - **位姿估计（6D pose on SE(3)）**给出真正的痛点：位姿是相对的（帧图）、由对应关系解出（PnP/RANSAC 有平面二义）、且**对称物体会产生观测别名**——同一个观测对应一整个对称轨道，不是「噪声大」，而是**原理上分不开**。
>
> 核心命题：**在 R68（内参可信吗）、R69（该向谁求证）、R70（身体在哪个状态）之外，补上「我在哪个参照系、这个参照系本身可信吗、这个物体的姿态是否存在对称多解」；把位姿表示成 SE(3) 上带可信集的分布，把对称诱导的歧义升格为第三类不确定性 U_sym，用轨道不变安全包络约束执行，用主动换视角（next-best-view）打破对称，用回路残差 r_loop 作为「标定吸收不掉」的关系性证据通道。** 命名 **ARGUS-RAS**（Active Reference-frame Graph, Uncertainty & Symmetry-aware Risk-Adaptive Safety：百眼巨人——用多视角与帧图一致性看住参照系）。
>
> 一句话定位：R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「我的身体在哪个状态」，R71 问「**我在哪个坐标系里、这个坐标系可信吗、这个姿态是不是还有另一个同样合理的解**」——不确定性不只在数值里，也在参照系的选择与对称群的商空间里。

## 0. 直觉与动机

**灵感 1（姿态/位姿是流形上的量 → 不确定性必须有形状与坐标无关性）**
直觉：把位姿当成 6 维欧拉向量加对角高斯，是机器人里最常见也最危险的偷懒。SO(3) 有奇点、SE(3) 不是向量空间；两个位姿之间的「差」是测地距离，不是分量相减。位姿估计的工程实践（矩阵 Fisher / 集中高斯 / 流形粒子、Lie 群上的不变 EKF）早已说明：**可信集必须是流形上的集合，覆盖率必须按测地距离度量**。R68 的 ECE 是标量校准，R70 的 HSE 是标量区间；到了位姿层，必须升级为**流形校准**：报告的是 C_δ ⊂ SE(3) 以及它是否真的以 δ 的概率包住真值。否则一个「标量上校准良好」的位姿滤波器，可能在旋转方向上系统性偏 30° 而 ECE 看不出来。

**灵感 2（对称 → 观测别名 → 第三类不确定性）**
直觉：一个圆柱、一个方盒、一个棋盘格标定板、一个 180° 对称的夹爪——它们的观测在某个对称群 G_sym 下**完全不变**。这意味着「这个物体转 90°」和「没转」给出同一张图。于是位姿后验不是单峰高斯，而是**一整个对称轨道上的等价类**。这与 R69 的 epistemic 有本质区别：R69 的歧义可以靠「多看一眼、多问一句」消解；对称歧义**在同一视角下再怎么看、再高的分辨率、再准的标定都消解不了**，因为信息在观测模型里就被群作用抹掉了。它也不是 aleatoric（不是随机噪声，是可精确刻画的等价类）。我们把它命名为 **U_sym（对称诱导的结构性不确定性）**：**不可约于「更准」，只可约于「换一个打破对称的视角/动作」**。

**灵感 3（参照系是相对的 → 帧图、回路闭合、关系性漂移）**
直觉：位姿估计从来不是绝对测量，而是一张**帧图**：世界→基座→相机→物体→工具→末端，每条边是一个带不确定性的 SE(3) 相对变换；多个视角/多次观测形成**回路**，回路上的变换复合应当回到单位阵。R68 标定的是单传感器**内参**；但一条边慢慢漂移（外参、装配、热变形、IMU 偏置）时，内参标定可以把它的**一部分**重新解释成传感器偏置而吸收掉——r_res 依旧接近 0，可整张帧图已经不自洽。**回路残差 r_loop 是规范不变的（gauge-invariant）**：它只依赖相对变换的相容性，不看你在哪个原点。于是 (r_res↓, r_loop↑) 成为「帧漂移被标定吸收」的判别签名——这正是 R69 的 (r_res↓, Δa↑)、R70 的 (r_res↓, play 残差↑) 在**关系侧**的镜像。三条正交残差通道（内参/传动/帧图）终于凑齐。

**灵感 4（主动位姿估计 = next-best-view → R69 信息动作的位姿特化）**
直觉：打破对称的唯一办法是**移动**。R69 的信息动作是看/问/触；到这一步，「换个视角」成为一个新的、代价更高、风险更大的信息动作：它可能需要底盘运动、机械臂重定位、等待遮挡解除。关键洞察是：**不是所有移动都能打破对称**——沿圆柱轴看，绕轴的偏航永远看不见；必须移到偏离对称轴的位置。所以 NSV 的目标不是「信息量最大」，而是「**残余稳定子（stabilizer）最小**」。这把 R69 的 VoI 从「模态熵」推广到「对称轨道熵」，并且与 R70 的物理包络强耦合：换视角本身必须过 C-RAS-WM 与传动降额。

**灵感 5（等变性 → 与任务对称对齐的位姿歧义是无害的）**
直觉：如果抓取一个圆柱用顶抓，那么绕轴任意偏航都抓到同一个东西——任务动作对 U(1) 对称。于是「偏航不可辨识」这件事**根本不影响安全**，因为它落在任务的不变子群 G_task 里。真正危险的是**商空间里**的那部分：SE(3)/G_eff，其中 G_eff = G_amb ∩ G_task。这条洞察把 U_sym 从「一律保守」变成「**只在任务不不变的子群上保守**」，并解释了为什么等变策略（π(g·o)=g·π(o)）能把「不可辨识」翻译成「可忽略」：对称保护（symmetry protection）。R69 的 resolution bonus 在这里有了位姿层的对应物：**轨道商化奖励（quotient bonus）**。

**灵感 6（对旧层的严格包含 → 安全约束是交集，不是并列黑箱）**
直觉：ARGUS 若只是再叠一个位姿模块，就又多一个要独立信任的东西。正确姿态仍是 R69/R70 的：**ARGUS 的安全约束 = R70 约束 ∩ 轨道不变包络 ∩ 帧不一致膨胀**。当对称群退化到平凡（G_amb={e}）、位姿可信集收缩为点、帧图自洽（r_loop→0）时，交集逐项退回 R70。这样新层只可能更保守，不可能更激进；R70、R69、R68 都是 ARGUS 在不同边界上的严格退化。

**灵感 7（新风险：对称遮蔽与伪回路 → 自信的错误位姿）**
直觉：把对称当朋友，前提是**你估的对称群不小于真实对称群**（引理 23）。一旦发生**对称遮蔽（symmetry masking）**——遮挡、纹理、部分视角让一个本对称的物体看起来不对称——系统就会「合法地」跳过轨道安全，直接提交一个自洽但错误的位姿代表；同理，**伪回路闭合**（感知别名把两个不同地点认成同一个）会让一张正在漂移的帧图看起来高度一致，从而把漂移**藏起来**。这两种故障都不会触发任何告警，因为它们让系统**更自信**。故本轮必须同时交付：对称群的保守超集、伪回路检测、流形可信集校准、以及「单通道不足以认证帧」的证据纪律。

## 1. 形式化定义（增量：定义 327–343）

**定义 327（ARGUS-RAS 总览）** ARGUS-RAS = (PFG, MPE, SGI, OSE, NSV, FCR, MCG-3D, RAS-WM†)。五不变式：
(i) **实时流零学习写操作**（继承 R70/R69 定义 276-i）；
(ii) **规范不变性（gauge invariance）**：任何安全判定与证书必须对全局参照系的任意选择不变——把整个世界平移/旋转后，Valid 与安全裕度逐位相同；
(iii) **轨道安全**：存在对称歧义时，只允许提交对**整个可行轨道**安全的动作，禁止提交「某个对称代表」上的点安全动作；
(iv) **关系性证据纪律**：帧一致性须由 ≥2 条正交残差通道（r_res / r_play / r_loop）一致确认，单通道不得认证参照系（继承 R69 定义 293-iii、R70 定义 310-iv）；
(v) **主动视角认证**：任何用于消歧的视角/运动必须过 C-RAS-WM 前缀认证，并同时满足 R70 的传动包络与降额。

**定义 328（位姿流形与流形分布）** 位姿 p ∈ SE(3) = SO(3) ⋉ ℝ³；姿态 R ∈ SO(3)，平移 t ∈ ℝ³。位姿信念是 SE(3) 上的分布 b(p)（矩阵 Fisher / 集中高斯 / 流形粒子），以测地距离 d_SE3(p,q)=‖log(p⁻¹q)‖_∨ 定义可信集 C_δ = {p : d_SE3(p, p̂) ≤ ρ_δ} 与覆盖率 cov(δ)=P(p* ∈ C_δ)。**禁止**用 ℝ⁶ 上的欧拉向量高斯替代（奇点、非唯一参数化会破坏规范不变性）。

**定义 329（参照系图 PFG）** 帧图 G = (V, E, L)：V = {world, base, cam, obj, tool, ee}，边 e=(i,j) 携带相对变换 T_ij ∈ SE(3) 与流形协方差 Σ_ij；L 为回路边集合。位姿由流形位姿图优化给出：p̂ = argmin_p Σ_e ‖log(T̂_ij⁻¹ T_i⁻¹ T_j)‖²_{Σ_e}。**只有相对位姿可观测**：全局规范 g ∈ SE(3) 作用 p_i → g p_i 不改变任何残差，证书必须对此不变（定义 341）。

**定义 330（对称诱导的位姿歧义 U_sym）** 设物体/任务在群 G_sym ≤ SE(3) 下观测不变：对任意 g ∈ G_sym，p(y | g·p) = p(y | p)。则完整位姿 p 不可辨识，只有轨道 [p] ∈ SE(3)/G_sym 可辨识。定义**歧义子群** G_amb = G_sym / Stab(p̂)（Stab 为固定 p̂ 的稳定子），以及轨道后验熵 H_orbit = −∫_{G_amb} b([g·p̂]) log b dg（离散对称取求和）。例：绕轴旋转对称的瓶/圆柱 → G_amb ⊇ S¹（连续偏航）；方盒/棋盘 → 4 或 8 重离散歧义；平面 PnP 的 IPPE 二义 → 2 重；180° 对称夹爪 → ℤ₂。

**定义 331（五类不确定性，分通道处置）**
- U_ale（R69 模态内噪声）→ λ_floor；
- U_epi（R69 决策歧义）→ MINT；
- P_plant（R70 迟滞/模式/退化）→ 确定性包络；
- **U_sym（本轮：对称轨道歧义）**→ 轨道不变包络 OSE + 主动 NSV；
- **U_frame（本轮：帧图不一致/漂移）**→ FCR 检测 + 保守膨胀。
五者语义不同，**不做标量加和**；安全约束是五条通道约束的**交集**（定义 342）。

**定义 332（流形校准门 MCG-3D）** 对位姿信念报告三项：测地覆盖率 cov(δ) 与目标 δ 的偏差、测地 ECE、以及**轨道校准**（把概率质量正确分配到对称轨道上的比例）。若 cov(δ) < δ − τ_cov，或轨道校准误差 > τ_orb，则判定位姿层不可信：禁用一切位姿条件决策，退回 R70 的**与位姿无关**的保守行为。这是 R69 MCG 与 R70 HSE 在位姿层的严格推广。

**定义 333（轨道不变安全包络 OSE）** 给定可行位姿集 𝒫 = C_δ（定义 328）与歧义子群 G_amb（定义 330），动作 a 轨道安全当且仅当
∀p ∈ 𝒫, ∀g ∈ G_amb: risk(a, g·p) ≤ ε ∧ a 对 G_eff 等变，
其中 G_eff = G_amb ∩ G_task（与任务不变子群相交，见引理 25）。工程上用商空间参数化：只在 SE(3)/G_eff 上做风险最大化；连续子群用区间/李代数范数松弛，离散子群（|G_amb| ≤ 8）直接枚举最坏代表。**R70 的「最坏模式包络」是本定义在离散点轨道上的特例**。

**定义 334（主动视角选择 NSV）** 候选视角/运动 v ∈ 𝒱（相机重定位、底盘移动、等待遮挡解除）。信息增益定义在**轨道商**上：
VoI_view(v) = H_orbit(G_eff | o) − E_{y~p(·|v,o)}[H_orbit(G_eff | o, y)]，
选择 v* = argmax_v [VoI_view(v) − c(v)]，s.t. 认证前缀安全、R70 包络保持、预算未超。与 R69 的 MINT 区别：目标不是模态熵而是**残余稳定子大小**；且 v 改写的是「观测者」而非「被观测者」，代价与风险通常更高。VoI_view ≤ 0 或 G_eff 已平凡 ⇒ 不移动。

**定义 335（对称破缺判据 SBG）** 视角变化 ΔT 能打破 g ∈ G_amb，当且仅当沿 ΔT 的观测分布可分：D(p(y|ΔT,p) ‖ p(y|ΔT,g·p)) > τ_sep。记可破缺集 B(ΔT) = {g ∈ G_amb : g 被 ΔT 打破}。若 B(ΔT)=G_amb 称**完全消歧视角**；否则残余歧义为 G_amb \ B(ΔT)，OSE 必须用这个更大的残余群。**含连续稳定子且该稳定子固定视角轴的对称（如沿圆柱轴观察的偏航）对任何单一视角都不可破缺**，必须移动视线离开对称轴。

**定义 336（帧一致性残差 FCR）** 三类正交残差：
r_loop(c) = ‖log(T_{e1} T_{e2} … T_{em})‖ 对回路 c ∈ L（规范不变）；
r_ep = d_SE3(p̂_proprio, p̂_extero)（本体感觉 R70 的 θ_out 与外部视觉位姿之差）；
r_fresh = 位姿信念的新鲜度（距上次全量更新时长）。
帧漂移判据：**(r_res↓, r_loop↑) 或 (r_play↓, r_ep↑)** = 被局部标定/传动模型吸收、但关系层已不自洽。与 R69 Δa、R70 play 残差构成三条互不吸收的通道。

**定义 337（位姿证书 J_ARGUS）** J_ARGUS = (J_HYDRA, frame_graph_hash, sym_group_id, G_amb_hash, orbit_coverage, r_loop_p95, r_ep_p95, nsv_log_hash, gauge_invariance_ok, pose_age, argus_ver)。Valid ⇔ Valid(J_HYDRA) ∧ MCG-3D 通过 ∧ OSE 满足 ∧ gauge_invariance_ok ∧ 帧图自洽（或已记录保守回退）∧ pose_age ≤ τ_age。

**定义 338（威胁模型 ℰ_ARGUS）** ℰ_ARGUS = ℰ_HYDRA × ℰ_pose，ℰ_pose 含：
对称遮蔽（遮挡/纹理/局部视角使真对称看起来不对称）→ 跳过轨道安全；
伪对称注入（对抗纹理使非对称物体看似对称）→ 过保守/任务不可行；
伪回路闭合（感知别名让漂移帧图显得一致）→ 隐藏漂移；
帧边投毒（伪造某条 T_ij）→ 选错参照系；
视角拒绝（遮挡/无法移动）→ 无法消歧却被迫决策；
PnP 二义利用（平面弱透视二解被选错）。

**定义 339（等变策略与帧误差传播）** 策略 π 对 G_eff 等变：π(g·o)=g·π(o)。在策略对位姿 Lipschitz（常数 L_π）下，动作误差 ≤ L_π·d_SE3(p̂,p*)。若 π 恰好 G_eff-等变，则位姿误差中**落在 G_eff 李代数方向上的分量产生零动作误差**（对称保护），有效误差只在商空间 SE(3)/G_eff 上计。等变性违背检测：比较 π(o) 与 g⁻¹π(g·o)；显著差异是规范依赖的告警信号。

**定义 340（对称群辨识 SGI：保守超集）** 由几何/外观/任务先验给出**可信对称群集合** 𝒢 = {G₁, G₂, …}，并取**上闭包** G_safe = 包含 𝒢 的最小闭子群（即最大可行对称）。安全性一律按 G_safe 计算（引理 23/定理 23）。若某个候选 G 被强证据否定，不得据此**缩小**安全用的 G_safe，只能缩小**能力**用的 G_task；缩小安全群需要外部登记（换装/维修/新标定）并留审计。

**定义 341（规范不变证书 GIC）** 对任意全局规范 g ∈ SE(3)，用 p_i ← g p_i 重算 J_ARGUS，要求 Valid、安全裕度、r_loop、orbits 全部逐位相同。任何只在特定原点下成立的证书视为无效。这防止「改一个原点把不安全证书变成安全」。

**定义 342（嵌套回退链）** 安全约束嵌套：
𝒞_ARGUS = 𝒞_HYDRA ∩ 𝒞_OSE ∩ 𝒞_frame，其中 𝒞_frame 为由 U_frame 诱导的保守膨胀。
回退：位姿层 invalid → 退回 HYDRA（位姿无关）；HYDRA invalid → FLUID；FLUID invalid → CALM；CALM 再退 λ_floor。**回退只允许沿链单调加保守，禁止用更细层的较小 U 去抵消更粗层的确定性/轨道界。**

**定义 343（位姿预算与新鲜度）** 每拍只做廉价位姿传播（R70 运动学 + IMU 航位推算 + 协方差传播，<0.05ms）；全量帧图优化、对称群辨识、NSV 仅在触发时异步执行（r_loop 越界、U_sym 高、计划主动视角、或 pose_age 超限）。位姿信念带时间戳：过期即标记 stale，按定义 332 退回位姿无关保守分支，绝不拿旧位姿当新位姿用。

## 2. 关键算法骨架

## 3. 推导

**引理 23（对称保守超集的可靠性）** 设真实对称群 G*，观测不变性成立；若安全用的估计群 G_est ⊇ G*，则对真位姿 p* ∈ orbit_{G_est}(p̂) 有 safe_{G_est}(a) ⇒ safe(a, p*)。故**高估对称群是可靠的（只会更保守）**；反之若 G_est ⊉ G*（对称遮蔽），存在 p* 与 a 使系统报告 Valid 却在真位姿处不安全。系：SGI 必须取可信群集合的上闭包（定义 340），这是定理 23 的前件，不是可调启发式。

**引理 24（对称破缺视角的可辨识性）** 视角 ΔT 完全消歧 G_amb 当且仅当 B(ΔT)=G_amb（定义 335）。若 G_amb 含一个固定视角轴的连续稳定子 H（如沿物体对称轴观察），则对任意仅绕该轴的观察变化有 B 不含 H，即**单视角不可破缺，必须移动视线离开对称轴**。系：NSV 的选点目标是最大化 |B(v)|（或残留稳定子的李代数维数下降），而非单纯最大化熵减；沿对称轴移动是**零信息**的伪动作。

**引理 25（等变导致的有效不确定性商化）** 若 π 精确 G_eff-等变且对位姿 Lipschitz 常数 L_π，则动作误差 ≤ L_π·‖proj_{SE(3)/G_eff}(p̂⁻¹p*)‖，即落在 G_eff 李代数方向的位姿误差产生零动作误差。证：g·p 与 p 在等变策略下给出 g·a，而任务只依赖轨道代表，差为零。系：**只有当位姿歧义落在任务不不变的子群 G_amb\G_task 上时才危险**；圆柱顶抓的偏航歧义是「免费」的（quotient bonus），这解释了 R69 resolution bonus 的位姿版本。

**引理 26（帧漂移的标定不可吸收性）** 单传感器内参标定 r_res 只约束内参；帧图回路残差 r_loop 是**相对变换的外参函数且规范不变**。若某条外参边发生慢变漂移，则任何仅调整内参/单边偏置的重标定都不能使所有回路同时闭合；因此存在非规范（non-gauge）漂移使 r_res→0 而 r_loop>0。纯全局规范变化使 r_loop=0，但那是不可观测且无害的。故 **(r_res↓, r_loop↑) 是帧漂移的判别签名**，补 R68 内参与 R70 传动的盲区。

**引理 27（位姿可信集的必要非充分校准）** 标量 ECE 与测地覆盖率不互为函数：存在位姿滤波器其平移分量 ECE 良好但旋转分量在 SO(3) 上系统性偏置，使 cov(δ) 显著低于 δ。故位姿层的证书必须报告**测地覆盖率与轨道校准**（定义 332），不能用 R68 的标量 ECE 代替。

**定理 21（ARGUS 严格包含 HYDRA/FLUID/CALM）** 当 G_amb={e}（G_eff 平凡）、可信集收缩为点（ρ_δ→0）、帧图自洽（r_loop,r_ep→0）时，OSE 退化为 R70 的单模包络、NSV 不触发、FCR 不膨胀，ARGUS 与 HYDRA 逐指令相同。一般情形 𝒞_ARGUS = 𝒞_HYDRA ∩ 𝒞_OSE ∩ 𝒞_frame ⊆ 𝒞_HYDRA，故期望风险 ≤ R70。回退链（定义 342）保证安全侧单调只增。

**定理 22（主动视角消歧的收敛与安全）** 设每次成功 NSV 使轨道熵至少下降 δ_H（除非残余稳定子已平凡），且每个视角过 C-RAS-WM 与 R70 包络（累积风险 ≤ ε_view）。则贪心 NSV 在 O(log(1/ε)/δ_H) 个视角内使 H_orbit ≤ ε；若预算耗尽仍有 H_orbit > ε（如残余连续稳定子不可破缺），OSE 保持轨道安全、**永不提交点安全**。证：熵单调下降 + 破缺正增益 + 安全认证的归纳；不可破缺时由引理 24 与定义 333 直接得保守性。

**定理 23（等变-安全分离与 SGI 保守性的必要性）** 若策略与安全检查器均 G_eff-等变、且证书在商空间上计算，则安全判定与真实对称代表无关，对称歧义本身不能导致不安全提交——**前提是 G_est ⊇ G***。若 G_est ⊉ G*，由引理 23 存在报告 Valid 却不安全的轨迹。故「SGI 只增不减的保守超集」是安全的必要条件，也是对称遮蔽成为本轮头号威胁的根源。

## 6. 本轮最大风险

**一句话**：ARGUS 的全部安全论证押在「**估计的对称群不小于真实对称群**」与「**帧图回路残差可信**」这两条前提上——一旦发生**对称遮蔽**（遮挡/纹理/局部视角让对称物体看起来不对称），轨道安全被合法地跳过，系统会自信地提交一个自洽却错误的位姿代表；一旦发生**伪回路闭合**（感知别名让漂移帧图显得一致），漂移被藏起来，证书依旧 Valid。这两种故障都不报警，因为它们让系统**更自信**——**一个被证实的错误位姿，比一个诚实的「我不知道朝向」危险得多**。

**次级风险与缓解**：
1. **对称遮蔽（头号）** → SGI 取可信群上闭包 + 遮蔽对抗集 + E325 专项 + 任何缩小安全群的证据都需外部登记；
2. **伪回路 / 帧边投毒** → 回路一致性 RANSAC、r_ep 交叉验证、≥2 正交通道纪律、ℰ_pose 对抗训练；
3. **流形校准失真** → MCG-3D 同时报测地覆盖率与轨道校准，越界即退回位姿无关 R70（引理 27）；
4. **主动视角本身不安全** → 视角动作过 C-RAS-WM + R70 包络/降额，累积风险 ≤ ε_view（定理 22）；
5. **规范依赖的假证书** → 随机规范重算 GIC + 审计（定义 341）；
6. **位姿计算击穿实时** → 廉价航位推算 + 触发式异步优化 + pose_age 过期即保守（定义 343）。

## 2. 形式化定义（要点版）

**定义 327（总览与五不变式）** 零学习写操作；**规范不变性**（换原点证书逐位不变）；**轨道安全**（只提交对整个可行轨道安全的动作）；关系性证据纪律（≥2 正交通道才认证帧）；主动视角必须过 C-RAS-WM 与 R70 包络。

**定义 328–329（流形位姿与帧图）** 位姿是 SE(3) 上的分布 + 测地可信集；帧图边为相对变换，只有相对位姿可观测（全局规范不可观测），回路残差规范不变。

**定义 330（U_sym）** 观测在 G_sym 下不变 ⇒ 仅轨道 `[p]∈SE(3)/G_sym` 可辨识；`G_amb=G_sym/Stab`，`H_orbit` 为其后验熵。例：回转体→S¹、方盒/棋盘→4/8 重、平面 PnP→2 重、180° 夹爪→ℤ₂。

**定义 331–332（五类不确定性与 MCG-3D）** U_ale/U_epi/P_plant/U_sym/U_frame 分通道、不标量加和；MCG-3D 报测地覆盖率 + 轨道校准，越界即退回位姿无关 R70。

**定义 333（OSE 轨道安全）** `∀p∈C_δ, ∀g∈G_amb: risk(a,g·p)≤ε` 且 `a` 对 `G_eff` 等变；离散群枚举最坏代表，连续群用商空间/李代数松弛。

**定义 334–335（NSV 与对称破缺）** `v*=argmax[VoI_view−c]`（轨道商上的熵减，约束安全/预算）；`B(ΔT)={g 被视角打破}`；完全消歧需 `B(ΔT)=G_amb`；固定对称轴的连续稳定子对单视角不可破缺。

**定义 336（FCR）** `r_loop`、`r_ep`、`r_fresh`；`(r_res↓, r_loop↑)` 或 `(r_play↓, r_ep↑)` = 被局部标定吸收但关系层不自洽 = 帧漂移。

**定义 337–338（证书 / 威胁）** J_ARGUS 并入住帧图/对称/测地覆盖/NSV/规范检查/新鲜度；ℰ_pose 含对称遮蔽、伪对称注入、伪回路、帧边投毒、视角拒绝、PnP 二义。

**定义 339–340（等变与 SGI）** 等变策略使 `G_eff` 方向位姿误差零传播；SGI 取可信对称群**上闭包**，安全一律用 G_safe，缩小安全群需外部登记。

**定义 341–343（规范不变证书 / 嵌套回退 / 预算）** 任意全局规范下证书逐位一致；`𝒞_ARGUS=𝒞_HYDRA∩𝒞_OSE∩𝒞_frame` 且回退单调加保守；每拍只做廉价航位推算，全量优化/辨识/NSV 触发式异步，位姿过期即退保守。

# IP-275 PFG：帧图、规范不变回路残差
class PoseFrameGraph:
    def propagate(self, p, u, dt):
        return lie_propagate(p, u, dt), lie_cov_propagate(self.Sigma, u, dt)
    def loop_residual(self, cycle):
        T = eye(4)
        for e in cycle: T = T @ self.T[e]
        return norm(log_se3(T))                      # 规范不变
    def optimize(self, edges, loops):                 # 仅触发时异步
        return manifold_pose_graph_opt(edges, loops)

# IP-276 MPE：流形可信集（禁止欧拉向量高斯）
def credible_set(belief, delta):
    return {p: geodesic_dist(p, belief.center) <= belief.radius(delta)}

# IP-277 SGI：对称群保守超集
def identify_symmetry(geom, appearance, task):
    G_safe = upper_closure(detect_symmetry_candidates(geom, appearance))  # 只增不减
    G_task = task_invariance(task)
    return G_safe, G_task, intersect(G_safe, G_task)   # G_eff

# IP-278 OSE：对轨道（非点）做风险最大化
def orbit_safe(a, belief, G_eff, eps):
    reps = ([g @ p for g in G_eff.elements() for p in belief.samples()]
            if is_discrete(G_eff) else belief.samples())
    return all(risk(a, p) <= eps for p in reps)

# IP-279 NSV：最大残余稳定子缩减
def choose_view(belief, G_eff, budget, c_ras_wm):
    if is_trivial(G_eff): return None
    best = None
    for v in viewpoint_candidates(belief):
        if not budget.allow(v) or not c_ras_wm.certify_info(v, belief): continue
        B = breakable(v, G_eff)                      # 定义 335
        if not B: continue                           # 沿对称轴看 = 零信息
        score = (orbit_entropy(G_eff) -
                 expected_orbit_entropy(residual(G_eff, B))) - cost(v)
        if best is None or score > best.score: best = (v, B, score)
    return best if best and best.score > 0 else None

# IP-280 FCR：关系性帧漂移（标定吸收不掉）
def frame_consistency(pfg, p_prop, p_ex, r_res, r_play):
    r_loop = max(pfg.loop_residual(c) for c in pfg.L)
    r_ep   = geodesic_dist(p_prop, p_ex)
    drift  = (r_loop > TAU_LOOP and r_res < TAU_RES) or \
             (r_ep   > TAU_EP  and r_play < TAU_PLAY)
    return drift, r_loop, r_ep

# IP-285 主闭环（继承 R70）
def ARGUS_RAS_round(M, obs, cmd):
    k0, tau0, q_safe, hydra = M.hydra.step(...)          # R70 层不变
    p_hat, Sigma = M.pfg.propagate(M.p_prev, cmd.u, cmd.dt)
    fresh = M.pose_age < TAU_AGE
    if M.trigger(p_hat, Sigma, obs):
        p_hat, Sigma = M.pfg.optimize(M.edges, M.loops); M.pose_age = 0
    G_safe, G_task, G_eff = M.sgi.identify(obs)
    orb_ok = M.mcg3d.check(M.pose_hist)
    drift, r_loop, r_ep = M.fcr.frame_consistency(
        M.pfg, p_hat, p_extero, M.last_r_res, M.last_r_play)
    if orb_ok and fresh and not drift:
        safe_mask = [M.ose.orbit_safe(a, (p_hat, Sigma), G_eff, EPS_RISK)
                     for a in M.candidates(k0, tau0)]
    else:
        safe_mask = None                                 # 退回 R70 位姿无关
    v = (M.nsv.choose_view((p_hat, Sigma), G_eff, M.budget, M.c_ras_wm)
         if orb_ok and fresh and not drift and not is_trivial(G_eff) else None)
    eq_ok = M.eqp.check(M.policy, o, obs, G_eff)
    a = (M.select_orbit_robust(M.candidates(k0, tau0), safe_mask, G_eff)
         if safe_mask is not None and eq_ok else None)
    cert = M.gic.certify(a, p_hat, G_eff, r_loop, r_ep, drift, orb_ok, fresh)
    M.vqa_i.submit(p_hat, G_safe, G_eff, r_loop, r_ep, v, cert)
    return a, k0, tau0, (p_hat, G_eff, cert)

## 4. 推导

**引理 23（对称保守超集的可靠性）** 真实对称群 G*；若安全用群 `G_est ⊇ G*`，则 `safe_{G_est}(a) ⇒ safe(a,p*)`（高估对称只更保守）。若 `G_est ⊉ G*`（对称遮蔽），存在 p*、a 使系统报 Valid 却在真位姿不安全。系：SGI 必须取可信群上闭包，这是定理 23 的前件而非启发式。

**引理 24（对称破缺的可辨识性）** 视角 ΔT 完全消歧当且仅当 `B(ΔT)=G_amb`；若 G_amb 含固定视角轴的连续稳定子（沿对称轴观察），单视角不可破缺，必须移动视线离开对称轴。系：NSV 目标是最大化可破缺集/最小化残余稳定子，沿对称轴移动是零信息伪动作。

**引理 25（等变导致的有效不确定性商化）** π 精确 G_eff-等变且 Lipschitz L_π ⇒ 动作误差 `≤ L_π‖proj_{SE(3)/G_eff}(p̂⁻¹p*)‖`；落在 G_eff 李代数方向的位姿误差产生**零**动作误差。系：只有 `G_amb\G_task` 上的歧义危险；圆柱顶抓的偏航歧义是 quotient bonus（R69 resolution bonus 的位姿版）。

**引理 26（帧漂移的标定不可吸收性）** 内参标定只约束 r_res；`r_loop` 是相对外参的规范不变函数。外参慢漂移无法靠仅调整内参/单边偏置使所有回路同时闭合，故存在非规范漂移使 `r_res→0` 而 `r_loop>0`。纯全局规范变化使 r_loop=0，但不可观测且无害。系：`(r_res↓,r_loop↑)` 是帧漂移判别签名。

**引理 27（测地覆盖不由标量 ECE 决定）** 存在位姿滤波器平移 ECE 良好、旋转在 SO(3) 上系统性偏置，使 `cov(δ) < δ`。故位姿证书必须报测地覆盖率与轨道校准，不能用标量 ECE 替代。

**定理 21（ARGUS 严格包含 HYDRA/FLUID/CALM）** `G_amb={e}`、`ρ_δ→0`、`r_loop,r_ep→0` 时 OSE 退化为 R70 单模包络、NSV 不触发、FCR 不膨胀，与 HYDRA 逐指令相同；一般 `𝒞_ARGUS ⊆ 𝒞_HYDRA`，风险 ≤ R70，回退链安全侧单调只增。

**定理 22（主动视角消歧的收敛与安全）** 每次成功 NSV 使轨道熵至少降 `δ_H`（除非残余稳定子平凡），且视角过认证、累积风险 ≤ ε_view ⇒ `O(log(1/ε)/δ_H)` 步内 `H_orbit ≤ ε`；预算耗尽仍有歧义时 OSE 保持轨道安全、永不提交点安全。

**定理 23（等变-安全分离与 SGI 保守性的必要性）** 策略与安全检查器均 G_eff-等变且证书在商空间计算 ⇒ 安全判定与真实对称代表无关，对称歧义本身不致不安全提交，**前提 `G_est ⊇ G*`**；否则由引理 23 存在报 Valid 却不安全的轨迹。故保守超集是对称安全必要条件，也是对称遮蔽成为头号威胁的根源。

## 7. 本轮最大风险

**一句话**：ARGUS 的全部安全论证押在「**估计的对称群不小于真实对称群**」与「**帧图回路残差可信**」两条前提上——**对称遮蔽**（遮挡/纹理/局部视角让对称物体看似不对称）会让轨道安全被合法跳过，系统自信提交一个自洽却错误的位姿代表；**伪回路闭合**（感知别名）会让漂移帧图显得一致、把漂移藏起来，证书依旧 Valid。二者都不报警，因为它们让系统**更自信**——**一个被证实的错误位姿，比诚实的「我不知道朝向」危险得多**。

**次级风险与缓解**：对称遮蔽（SGI 上闭包 + 遮蔽对抗集 + E325，缩小安全群需外部登记）；伪回路/帧边投毒（回路 RANSAC + r_ep 交叉验证 + ≥2 正交通道 + ℰ_pose 对抗训练）；流形校准失真（MCG-3D 报测地覆盖率与轨道校准，越界退回 R70，引理 27）；主动视角越界（C-RAS-WM + R70 包络/降额，累积风险 ≤ ε_view，定理 22）；规范依赖假证书（随机规范重算 GIC）；实时击穿（廉价航位推算 + 触发式异步 + pose_age 过期即保守）。
