（灵感驱动研究循环·新灵感第 2 轮；本轮灵感：「开源软件」×「故障诊断」）

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（上承 v22 分层 PGEV/机械臂/深度感知、v21 语义-规范层、v20 联邦感知证书、v19/v17 证书与感知链）。
> 本轮纪律：**信任不是单把密钥、故障不是二元真假、退化不是全局停机**。不推倒 v23：CESC/FSVC/IPAM/HPCE+/CFC+++ 全部保留，v22/v21/v20 全部保留。本轮只做一件事：**在 v23 的“四证一体”之外再套一层“来源可复现 + 独立审计 + 故障可诊断”的开放可信层**，把 v23 的最大风险（云边版本与统计覆盖在协同故障下共振崩塌）从“一检测到就全局保守”升级为“可复现地信任、按最小割隔离、有时限地恢复”，并用**集合-时间双单调律**严格封住“诊断会不会偷偷放宽执行集”这个致命口子。

## 0. 直觉与动机

**灵感 1（开源软件 → 信任从单点密钥转移到可复现的群体重建）**
直觉：v23 的信任锚是“云端私钥签名 + 版本三元组一致”。但开源世界用 xz 后门这类事件反复证明：**签名可以来自被收买的维护者，版本可以完全一致，攻击可以从上游依赖悄悄进入**。开源给出的答案不是“更强的密钥”，而是四件套：**可复现构建（reproducible build）、软件物料清单（SBOM）、独立重建审计（“many eyes”形式化为审计法定人数）、透明日志（transparency log）**。核心创新：**可复现来源证书 (Reproducible Provenance Certificate, RPC) + 独立审计法定人数证书 (Audit Quorum Certificate, AQC)**。关键反直觉点：**可复现性不是“更安全的哈希”，而是把信任从“一个签名者”重新分配到“一群互相独立的重建者”——它防的恰恰是 v23 CESC 的结构性盲区：“签名正确但内容被投毒”。** 同时把 v21 的义务逻辑延伸到开源许可证：copyleft 传染闭包必须被显式声明并可审计，否则 RPC 直接不通过（许可证合规 = 一类可判定的义务）。
但可复现性有致命边界：**若所有审计者共享同一被污染的编译器或同一份被投毒的源码镜像，则“可复现的恶意”照样通过全部法定人数**——这把“独立”从一个形容词变成了必须形式化验证的假设。

**灵感 2（故障诊断 → 从二元 pass/fail 到“坏在哪、隔离多少、多久回来”）**
直觉：v23 把每张证书的有效性当二元的（pass/fail），任一失效就整体保守。故障诊断（尤其基于模型的一致性诊断，MBD）告诉我们，真正该问的是三个问题：**哪个部件坏了（诊断）、影响面多大（最小割）、能否以及多快恢复（可恢复性）**。用 Reiter 的经典框架：系统描述 SD + 观测 OBS 的**冲突集**（最小不一致子集）的**最小碰集**就是**最小诊断** Δ。核心创新：**故障签名与诊断引擎 (Fault Signature & Diagnosis Engine, FSDE) + 最小割证书 (Minimal Cut Certificate, MCC) + 主动诊断与恢复证书 (Active Diagnosis & Recovery Certificate, ADRC)**。关键反直觉点（本轮最重要的一条）：**诊断直觉上应该“恢复活性”，但在严格安全单调链下，任何基于诊断的“放宽”都会把 Exec 撑破 v23——因此诊断的正确角色不是扩大瞬时许可集，而是“按最小割精确隔离 + 在时限内自动恢复到同一许可集的子集”，提升的是时间可用性而非瞬时许可集。** 集合单调（`Exec_v24 ⊆ Exec_v23`）与时间可用性单调是两件必须分开证明的事（P46）。另一条工程约束：诊断是“事后”的，`T_diag` 窗口内必须仍按 v23 最保守策略运行，诊断只决定“窗口结束后退到哪”。

**两者（两层）如何统一**
统一为 **v23 之上的“开放可信 + 可诊断”层**：RPC/AQC/SHCK 回答“**我凭什么信这套证书的生成者**”；FSDE/MCC/ADRC 回答“**坏在哪、隔离多少、多久能回来**”。二者把 v23 的“签名 + 版本”升级为“**来源可复现 + 审计法定人数 + 故障最小割**”。统一准入门：**HPC-E++ = HPC-E+ ∧ Repro ∧ AuditQuorum ∧ (DiagnosisConsistent ∨ ScopedDegradation)**。**自举**是关键（SHCK）：证书验证器本身也必须可复现、被独立审计，否则“谁来验证验证者”会无限回退；用“最小可信内核 + 透明日志锚点”截断回退。故障树视角把这一切串起来：安全准入是 AND 门（HPC∧CC∧AbsCert∧Energy…），“错误准入”是 OR 门，**最小割集 = 能导致安全失效的最小同时故障组合**，冗余度直接决定最小割的大小（与 CFC+++ 的模态数 ≥2 天然衔接）。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 可复现来源律（Reproducible Provenance）**
进入准入门的一切工件（模型/校准/规则/原型/验证器二进制）必须携带 `P = (src, sbom, build_env, artifact)`，且 `Repro(P) ≜ H(rebuild(src, sbom, build_env)) = H(artifact)` 成立、`SBOM_complete(P)` 依赖闭包成立、`Lic_ok(P)` 许可证传染闭包已声明。任一不成立即视为**不透明工件**，不激活、不信任、向“冻结最后已复现版本”退化。来源沿依赖 DAG 传递：父件可复现要求其全部子件可复现。

**P44 独立审计法定人数律（Independent Audit Quorum）**
版本被信任当且仅当 `AuditQuorum(P,q) ≜ |{a ∈ Auditors : indep(a) ∧ Repro_a(P) ∧ Trace_a(P) ≡ Trace_ref(P)}| ≥ q`，其中 `indep(a)` 机械要求审计者构建环境哈希互异、维护者集合不交、源码镜像不同源。**单一云端签名不再是充分条件**（CESC 的 `verify_sig` 退化为必要条件）。法定人数不达 ⇒ 冻结 `V_last_audited`，绝不静默激活。审计结果写入透明日志（append-only Merkle），供第三方公开复核。

**P45 诊断优先与最小割隔离律（Diagnosis-First Minimal-Cut Isolation）**
任一证书失效，先产出最小诊断 `Δ`（冲突集的最小碰集），再做隔离：`D_v24(Δ) = D_v23 ∩ Restrict(Δ)`，其中 `Restrict(Δ)` 只收紧被诊断为故障的最小割内模块，**绝不放宽任何模块**。`Δ` 不唯一时取**所有一致诊断的安全闭包之交**（保守）。`T_diag` 窗口内仍按 `D_v23` 运行；`T_diag` 超时仍未唯一隔离 ⇒ 保持 v23 SafeStop 闩锁（不得猜测）。

**P46 集合-时间双单调律（Set–Temporal Dual Monotonicity）**
必须区分两种“单调”：**(i) 瞬时许可集单调不增**：`Exec_v24 = Exec_v23 ∩ Fil_repro ∩ Fil_audit ∩ Fil_diag ⊆ Exec_v23`，恒成立，与是否有诊断无关；**(ii) 时间可用性**：v24 可在 `T_diag + T_recover` 内自动恢复到 `D_v24(Δ) ⊆ D_v23` 的认证工作点，避免 v23 的永久闩锁，但**永不恢复到 v23 之外的集合**。任何真正的集合扩张只能通过**显式重新认证纪元 (re-certification epoch)** 完成：重新走 RPC + AQC + 全量证书，且写入透明日志；纪元切换是新基线，**不计入** `Exec_v24 ⊆ Exec_v23` 单调链，也禁止用于掩盖一次未解释的故障。

## 3. 与基线的接口（如何退化）

- RPC 不可复现/来源不明 ⇒ 视为不透明工件，冻结最后已复现版本，不激活新版本（比 v23 更保守）；
- AQC 达不到法定人数 ⇒ 冻结 `V_last_audited`，不激活；已有版本继续按 v23 证书运行（等价 v23，方向不变）；
- FSDE 失效（诊断引擎崩溃）⇒ 退回 v23 的全局保守回退 `D_v23`（等价 v23）；
- MCC 无法计算最小割 ⇒ 取最悲观单点割（`k_min=1`），等价全局保守；
- ADRC 失效 ⇒ 不自动恢复，保持 v23 SafeStop 闩锁（等价 v23）；
- SHCK 自举失败 ⇒ 不签发新证书，回退最后已审计内核；
- 诊断不唯一/超时 ⇒ 取保守闭包交，仍 ⊆ `D_v23`；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

## 4. 预期贡献

1. **可复现来源证书**：把“签名可信”升级为“内容可复现、依赖闭包完整、许可证合规”，首次将 SBOM/copyleft 义务与 v23 版本五元组对齐，并沿依赖 DAG 传递；
2. **独立审计法定人数**：把“many eyes”形式化为可机械检查的 `indep(a)` + 法定人数 `q`，用透明日志提供第三方可复核的信任锚，直接封堵 v23 单签信任的 xz 式盲区；
3. **自举证书内核**：用最小可信内核 + 透明日志锚点解决“谁来验证验证者”的无限回退；
4. **一致性故障诊断**：用 Reiter 冲突集/最小碰集给出可解释、最小化的故障诊断，替代 v23 的二元 pass/fail；
5. **最小割证书**：把安全 AND-tree 的冗余度证书化（最小割大小 ≥ k），与 CFC+++ 模态仲裁天然衔接；
6. **集合-时间双单调**：严格证明“诊断只提高时间可用性、绝不扩大瞬时许可集”，并给出重新认证纪元的解耦规则，防止诊断被滥用为放宽安全的后门；
7. **统一准入门 HPC-E++**：`Exec_v24 ⊆ Exec_v23 ⊆ …` 闭环。

## 5. 本轮最大风险

**一句话**：RPC/AQC 的“独立”是经验假设——若所有审计者共享同一被投毒的编译器或同一份被投毒的源码镜像，“可复现的恶意”会**逐比特复现**并骗过全部法定人数，而同一供应链里的 FSDE 还会把它诊断为“健康”，于是系统会**经审计、可复现、被诊断为准入地**执行一个后门——“可复现的投毒 + 被诊断的健康”。

## 1. 关键算法骨架（在 IP-431–439 骨架上扩展）

```python
# ============================================================
# IP-440 Reproducible Provenance Certificate (RPC)
# ============================================================
@dataclass(frozen=True)
class ProvenanceRecord:
    src_hash: bytes
    sbom_hash: bytes
    build_env_hash: bytes
    artifact_hash: bytes
    deps: tuple[str, ...]
    license_closure: frozenset[str]

class ReproducibleProvenanceCertificate:
    def __init__(self, rebuild_fn, license_policy):
        self.rebuild_fn = rebuild_fn
        self.license_policy = license_policy

    def repro(self, P: ProvenanceRecord) -> bool:
        rebuilt = self.rebuild_fn(P.src_hash, P.sbom_hash, P.build_env_hash)
        return hashlib.sha256(rebuilt).digest() == P.artifact_hash

    def sbom_closed(self, P, dep_records: dict[str, ProvenanceRecord]) -> bool:
        # 沿依赖 DAG 递归：父件可复现要求全部子件可复现（有向无环 + 记忆化）
        seen, stack = set(), list(P.deps)
        while stack:
            d = stack.pop()
            if d in seen:
                continue
            seen.add(d)
            rec = dep_records.get(d)
            if rec is None or not self.repro(rec):
                return False
            stack.extend(rec.deps)
        return True

    def license_ok(self, P: ProvenanceRecord) -> bool:
        # copyleft 传染闭包必须被显式声明，且与策略兼容
        return P.license_closure <= self.license_policy.allowed_closure

    def check(self, P, dep_records) -> bool:
        return (self.repro(P)
                and self.sbom_closed(P, dep_records)
                and self.license_ok(P))


# ============================================================
# IP-441 Audit Quorum Certificate (AQC) + Transparency Log
# ============================================================
class TransparencyLog:
    def __init__(self):
        self.leaves: list[bytes] = []

    def append(self, entry: dict) -> bytes:
        leaf = hashlib.sha256(json.dumps(entry, sort_keys=True).encode()).digest()
        self.leaves.append(leaf)
        return self.root()

    def root(self) -> bytes:
        # append-only Merkle 根（简化：逐层哈希）
        level = self.leaves[:]
        while len(level) > 1:
            level = [hashlib.sha256(level[i] + level[i + 1]).digest()
                     for i in range(0, len(level) - 1, 2)] + (
                     [level[-1]] if len(level) % 2 else [])
        return level[0] if level else b"\x00" * 32

class AuditQuorumCertificate:
    def __init__(self, auditors, q: int, log: TransparencyLog):
        self.auditors = auditors
        self.q = q
        self.log = log

    @staticmethod
    def independent(a, chosen) -> bool:
        # 独立性必须机械可查：构建环境哈希互异、维护者不交、镜像不同源
        return (all(a.env_hash != o.env_hash for o in chosen)
                and all(a.maintainers.isdisjoint(o.maintainers) for o in chosen)
                and all(a.mirror != o.mirror for o in chosen))

    def quorum(self, P: ProvenanceRecord, ref_trace: bytes) -> bool:
        chosen = []
        for a in self.auditors:
            if not self.independent(a, chosen):
                continue
            if a.reproduce(P) and a.behavior_trace(P) == ref_trace:
                chosen.append(a)
        ok = len(chosen) >= self.q
        self.log.append({"artifact": P.artifact_hash.hex(),
                         "valid": [a.id for a in chosen], "ok": ok})
        return ok

class FaultDiagnosisEngine:
    def __init__(self, SD):
        self.SD = SD
        self._cache: dict[bytes, list[frozenset]] = {}

    def diagnose(self, OBS) -> list[frozenset] | None:
        # 返回全部最小诊断；None 表示 SD 自身不可用（引擎故障）
        conflicts = minimal_conflicts(self.SD, OBS)
        if not conflicts:
            return [frozenset()]            # 空集 = 无故障
        return minimal_hitting_sets(conflicts)

    def k_diagnosable(self, k: int) -> bool:
        # 对任意 |fault| ≤ k 的注入，最小诊断唯一
        for fault in all_subsets(self.SD.components, upto=k):
            OBS = self.SD.simulate(fault)
            if len(self.diagnose(OBS)) != 1:
                return False
        return True


# ============================================================
# IP-443 Minimal Cut Certificate (MCC) — 故障树最小割
# ============================================================
def minimal_cut_sets(ft) -> list[frozenset]:
    """AND 门：子割集取并；OR 门：子割集笛卡尔积后极小化。"""
    if ft.kind == "leaf":
        return [frozenset({ft.name})]
    if ft.kind == "and":                 # 全部子事件发生才发生 → 任一子割即割
        cuts = [c for child in ft.children for c in minimal_cut_sets(child)]
    else:                                # or：各子割需同时成立
        cuts = [frozenset().union(*combo)
                for combo in itertools.product(*[minimal_cut_sets(c)
                                                 for c in ft.children])]
    return minimalize(cuts)              # 去掉被包含的超集

class MinimalCutCertificate:
    def __init__(self, k_min: int):
        self.k_min = k_min

    def certify(self, safety_tree) -> tuple[list[frozenset], bool]:
        mcs = minimal_cut_sets(safety_tree)
        return mcs, all(len(c) >= self.k_min for c in mcs)

        # 只收紧、绝不放开：与 v23 回退集取交
        D = self.D_v23 & restrict(Delta)
        assert D <= self.D_v23          # 集合-时间双单调的机械检查
        return D

    def probe(self, ambiguous: list[frozenset]):
        # 探针本身必须落在 v23 已认证的安全包络内，不扩大危险
        action = self._design_probe(ambiguous)
        assert action in self.D_v23
        return action

    def admit_degraded(self, plan, diags: list[frozenset]) -> bool:
        # 诊断不唯一 → 取所有一致诊断的安全闭包之交（保守）
        return all(plan in self.degraded_set(d) for d in diags)

class SelfHostingKernel:

# IP-446 HPC-E++ 统一准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'
    rpc: ReproducibleProvenanceCertificate
    aqc: AuditQuorumCertificate
    fsde: FaultDiagnosisEngine
    mcc: MinimalCutCertificate
    adrc: ActiveDiagnosisRecovery
    shck: SelfHostingKernel

    def admits(self, plan, artifacts, obs, ref_trace,
               x, v, z, E_res, margin_req, modules) -> bool:
        # (1) v23 四证（HPC-E ∪ CESC ∪ FSVC ∪ IPAttest）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # (2) 来源可复现（含 SBOM 依赖闭包 + copyleft 义务）
        if not all(self.rpc.check(P, artifacts.dep_records)
                   for P in artifacts.provenance):
            return False
        # (3) 独立审计法定人数
        if not self.aqc.quorum(artifacts.bundle, ref_trace):
            return False
        # (4) 自举内核已复现且被审计
        if not self.shck.attested():
            return False
        # (5) 诊断门：无故障直过；有故障只能按最小割收紧
        diags = self.fsde.diagnose(obs)
        if diags is None:
            return False                     # 引擎不可用 → 保守拒绝
        if diags == [frozenset()]:
            return True                      # 无故障
        return self.adrc.admit_degraded(plan, diags)

# 端到端：在 v23 流水线上叠加开放可信 + 诊断
# ============================================================
class OpenTrustworthyPipeline(PerceptionComplianceEnergyPipeline):
    def __init__(self, config):
        super().__init__(config)
        self.rpc = ReproducibleProvenanceCertificate(config['rebuild_fn'],
                                                     config['license_policy'])
        self.aqc = AuditQuorumCertificate(config['auditors'], config['q'],
                                          TransparencyLog())
        self.fsde = FaultDiagnosisEngine(config['SD'])
        self.mcc = MinimalCutCertificate(config['k_min'])
        self.adrc = ActiveDiagnosisRecovery(config['D_v23'], 0.5, 1.0)
        self.shck = SelfHostingKernel(config['kernel_prov'], self.rpc, self.aqc,
                                      config['log_root'])
        self.gate = HPCEPlusPlus(self.hpc_e_plus, self.rpc, self.aqc,
                                 self.fsde, self.mcc, self.adrc, self.shck)

    def step(self, sensor_data, cloud_update=None):
        admitted, info = super().step(sensor_data, cloud_update)
        # 故障树与最小割每纪元离线计算一次，热路径只查表
        mcs, cut_ok = self.mcc.certify(self.gate_safety_tree)
        diags = self.fsde.diagnose(sensor_data['symptoms'])
        admitted = admitted and self.gate.admits(
            info['plan'], sensor_data['artifacts'], sensor_data['symptoms'],
            sensor_data['ref_trace'], sensor_data['x'], sensor_data['v'],
            sensor_data['z'], sensor_data['E_res'], sensor_data['margin_req'],
            info['modules'])
        info.update({'diagnosis': diags, 'min_cut_ok': cut_ok,
                     'epoch': self.epoch, 'set_subset_v23': admitted <= info.get('v23', set())})
        return admitted, info
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| RPC 可复现检查 | O(1) 哈希比对 + O(\|deps\|) 闭包遍历 | O(\|deps\|) | 依赖 DAG 记忆化 |
| AQC 法定人数 | O(n·(repro+trace)) | O(n + \|Log\|) | n 审计者, q = ⌊n/2⌋+1 |

| FSDE 诊断（增量） | O(\|Conflicts\|·HS-tree) 最坏指数 / 热路径 O(1) 查表 | O(\|SD\| + \|cache\|) | 冲突集通常 <10 |
| MCC 最小割 | O(2^b) 离线一次（b=分支因子） | O(\|MCS\|) | 热路径查表 O(1) |

| HPC-E++ 准入 | O(\|modules\| + \|deps\| + \|diags\|·\|modules\|) | O(1) 增量 | 无阻塞 I/O |

**实时性保证**：热路径只做查表与哈希比对（RPC 预计算、FSDE 诊断结果缓存、MCC 每纪元离线一次），云端/审计/复现全部异步；`T_diag` 窗口内按 `D_v23` 保守运行，不等待诊断结果。

## 3. 正确性论证

### 引理 5（可复现-审计可靠性及其共模边界）
**陈述**：在假设 (A1) 至少 q 个审计者彼此独立（`build_env` 互异、维护者不交、镜像不同源）、(A2) 参考行为轨迹 `Trace_ref` 未被污染下，`Repro_a(P) ∧ Trace_a(P)=Trace_ref` 对 q 个独立审计者成立 ⇒ 工件与声明源码在功能上等价。当 (A1) 被违反（共享工具链/镜像）时结论失效，存在“可复现的投毒”。

**证明**：
1. 逐审计者 `Repro_a` 得到相同 `artifact_hash`，说明 artifact 是 `(src,sbom,build_env)` 的确定函数；
2. q 个独立环境排除单点环境后门（同一后门无法同时出现在互异环境中而不被发现）；
3. `Trace` 相等排除“同比特不同语义”（如未定义行为导致的隐蔽分支）；
4. 若共享环境/镜像，则同一后门对所有审计者同时可见，A1 失效，构造反例（xz 式上游投毒）。∎

### 引理 6（Reiter 最小碰集诊断正确性）
**陈述**：若 SD 一致、OBS 为真实观测，则 `Diag(OBS) = MHS(Conflicts(SD,OBS))` 恰为全部最小诊断；系统 k-可诊断当且仅当任意 `|Δ*| ≤ k` 的注入都产生唯一最小碰集。

**证明**：Reiter (1987) 定理的直接引用：诊断 `Δ` 一致 ⟺ `Δ` 与每个冲突集相交；最小诊断 ⟺ 最小碰集。唯一性 = 最小碰集唯一，逐故障枚举即得 k-可诊断判定。∎

### 引理 7（最小割与冗余度）
**陈述**：若安全准入是证书 AND 门、错误准入是 OR 门，且第 i 张证书由 `r_i` 条独立路径多数表决产生，则 `U_i` 的最小割大小为 `⌈(r_i+1)/2⌉`，全局最小割 = 各 `U_i` 割集并之极小化。MCC 认证 `k_min` 后，任何 `< k_min` 重同时故障至少保留一条有效证书路径。

**证明**：AND→OR 对偶（错误准入需某张证书被错误判真）；多数表决失效需过半独立路径同时故障；`minimalize` 去掉被包含的超集，故最小割集精确。∎

### 引理 8（集合-时间双单调）
**陈述**：任意诊断 Δ 与恢复动作下 `Exec_v24 = Exec_v23 ∩ Fil_repro ∩ Fil_audit ∩ Fil_diag ⊆ Exec_v23`；自动恢复集 `D_v24(Δ)=D_v23 ∩ Restrict(Δ) ⊆ D_v23`；重新认证纪元切换不改变历史纪元的单调链。

**证明**：
1. 交集定义直接给出 `Exec_v24 ⊆ Exec_v23`，与诊断是否发生无关；
2. `Restrict(Δ)` 只收缩，故 `D_v23 ∩ Restrict(Δ) ⊆ D_v23`；
3. `T_diag` 内运行 `D_v23`，超时保持闩锁，均不越过 v23；
4. 纪元 `Epoch_{k+1}` 是新证明义务（重走 RPC/AQC/全量证书），与 `Epoch_k` 的单调链并列而非包含，故不“洗白”未解释故障。∎

### 定理（HPC-E++ 的健全性、可诊断性与双单调）
**陈述**：`HPCEPlusPlus.admits(π) = True` ⇒ π 同时满足：(1) v23 四证（物理/规范/负信息/能量/差距 + 云边同步 + 少样本覆盖 + IP 认证）；(2) 来源可复现且依赖闭包完整、许可证合规；(3) 独立审计法定人数；(4) 自举内核可信；(5) 诊断一致（无故障，或仅按最小割收紧）。且 `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

**证明**：由 `admits` 的五个连言与引理 5–8 直接可得。必要性：任一条件缺失即拒证，对应一类未缓解风险（供应链/审计/诊断/自举）。充分性：五条件全满足时，执行集为 v23 的交集子集，且故障路径被最小割隔离而非全局放宽，构成安全-可复现-可诊断闭环。∎

## 6. 本轮最大风险（最终确认）

**一句话**：RPC/AQC 的“独立”是经验假设——若所有审计者共享同一被投毒的编译器或同一份被投毒的源码镜像，“可复现的恶意”会**逐比特复现**并骗过全部法定人数，而同一供应链里的 FSDE 还会把它诊断为“健康”，于是系统会**经审计、可复现、被诊断为准入地**执行一个后门——“可复现的投毒 + 被诊断的健康”。
