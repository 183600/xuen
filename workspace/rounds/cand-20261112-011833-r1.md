# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「末端位姿」×「常识推理」）

> 第 57 轮把"证据承诺"做成少样本可校准、跨模态可对账、个性化有界的判定体系；但它所有证据都停在**区域（region）**这一抽象粒度，且先验全部来自**同一部署语料**。这留下两个结构性问题：**(a) 生态谬误**——区域平均安全不等于选定位姿安全；探针在 p₁ 点、脚落在 p₂ 点，证据跨位姿迁移无声明，而不可逆接触恰恰由**具体末端位姿**而非区域平均值决定；**(b) 语料闭环**——元先验、OOD 门、共形带都只能对"训练里见过/没见过"作反应，无法命名"训练里没有的世界"，更无法生成针对它的探针；第 57 轮自陈的"坏先验普遍"风险正源于此。本轮两个灵感各补一刀：**末端位姿**把证书从区域边际下沉到位姿条件，引入位姿条件证据、位姿鲁棒管、位姿响应真值（EV-pose）与位姿实现缺口；**常识推理**引入一个与部署语料**异源**的定性物理先验，但严格限制其权限——**常识只能否决、不能授权**，其真正价值是把开放集 OOD 变成有限假设判别，从而为语料盲区生成探针。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"位姿可落地、常识可否决、证据可回溯的接地承诺"**。

核心矛盾：
- **H29（区域安全 ≠ 位姿安全）**：区域边际信念 b_r 无法回答"脚落在 p 这个具体位姿是否安全"；探针与承诺的位姿相关性若不声明，证据迁移就是未经验证的假设——区域越异构，生态谬误越大。
- **H30（常识有用但不可信）**：常识能廉价地指出"水/冰/格栅/雪壳"等语料外类别，但它的感知输入与数据证据共享同一批传感器，会一起被骗；一旦让常识"授权"，它就从护栏变成新的单点故障。
- **H31（接地 vs 可执行）**：证书若绑定计划位姿而执行位姿偏离（软地沉降、滑移、控制误差），"安全证书"描述的是一双从未落地的脚；把证书绑到实现位姿又会因跟踪误差而频繁失效——安全与活性在接地处对撞。

## 0. 直觉与动机

**灵感 1（末端位姿 → 从区域边际到"这只脚、这个位姿"）**
直觉：所有证据最终要兑现成一个 SE(3) 位姿上的接触。区域说"这块地大概率硬"，但脚掌的接触斑可能正好压在一道裂缝上——平均值安全，选点位不安全，这是典型的生态谬误。末端位姿把问题问对：**不要问"这个区域安全吗"，要问"存在一个可实现的位姿 p，使 p 及其跟踪误差邻域都安全吗"**。于是三件事被显式化：(i) **位姿条件证据**——探针在 p 邻域内才对该位姿有效，超出相关长度 ℓ_corr 就必须重探，否则要声明迁移算子及其误差；(ii) **位姿鲁棒管**——证书不认证单点 p\*，而认证球 B(p\*, ε_pose) 内全部位姿，ε_pose 是跟踪误差的 δ_pose 分位；(iii) **位姿响应真值**——轻触时实测的位姿轨迹与接触力旋量是"现实"最接近接地的读数（EV-pose），它可反过来证伪元先验与常识，是整条证据链唯一真正接地的一环（自身仍有传感器误差模型）。

**灵感 2（常识推理 → 异源先验、否决权、假设发生器）**
直觉：部署语料是一个闭环——模型只能对"像不像训练集"反应，说不出"这可能是水/冰/格栅/雪壳"。常识是一个**异源**的定性物理先验：廉价、可迁移、能命名语料外类别。但它不可信：它的感知输入与视觉证据同源，透明冰面能同时骗过两者。所以给它的权限必须**非对称**：**常识说危险 ⇒ 红灯（可否决）；常识说安全 ⇒ 不作为授权依据**。因为误否决只损失效率（活性），误授权直接损失安全——非对称把常识的错误方向限定在安全的一侧。常识真正的建设性用途不是"下结论"，而是**生成假设与探针**：把开放集"这是不是 OOD"变成有限假设集 ℋ_cg={水,冰,格栅,雪壳,…} 的判别，再挑一个**判别性最强且非破坏**的探针去问现实——这把第 57 轮"语料里没有的世界只能退回宽区间"变成"语料里没有的世界可以被命名并主动检验"。

**灵感 3（两灵感合流 → 位姿接地 + 常识对质 = 接地承诺）**
直觉：把常识推理放在**位姿**上做——不是对区域做常识，而是对"这只脚要落的这个位姿"做常识（支撑、摩擦、滑移、塌陷、可通行性）。对质算子把两路异源判断摆在一起：一致只给有界佐证（且仅 L1），**静默冲突（数据说安全、常识说危险）触发红灯 + 定向反事实探针**，数据说危险则常识说安全也无效（非对称硬约束）。承诺门因此从"证据门"扩为"证据门 ∧ 位姿门 ∧ 无红灯 ∧ 位姿实现吻合"，证书 J_g 把安全绑定到**实际实现的末端位姿**而非计划位姿。三条新机制全部只经"去掉承诺"或"增加安全探针"起作用——安全单调性得以保持。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（位姿条件信念与证据迁移 EPR）** 末端位姿 p∈SE(3)（足端接触坐标系），区域边际 b_r(θ)。位姿条件失效率 P_fail(p)=∫P_fail(p|θ)b_r(θ)dθ。可采纳位姿集 𝒫_adm(r;b_r)={p: Reach(p) ∧ F_cone(p,μ̂_p) ∧ Clear(p) ∧ m_p≥K}，m_p=min_c slack_c(p)。**位姿下界** LB_pose(r)=inf_{p∈𝒫_adm} P_safe(p)（连续集用离散化+裕度 Lipschitz 界保守估计）。承诺要求 LB_pose(r)≥1−δ_f（而非 E_θ 边际）。探针证据只在相关长度 ℓ_corr 内迁移：若 ‖p_probe−p_commit‖>ℓ_corr，证据对该位姿无效，须重探或声明迁移算子 T(p_probe→p_commit) 及其误差界。位姿响应证据 EV-pose=(p̃, w̃, ṗ̃)（实现位姿、接触力旋量、位姿速度）为接地真值，可证伪任何先验，自身带传感器误差模型。

**定义 140（常识接地推理 CGR）** 定性物理规则库 𝒦（条件→(预期类别 ℓ, 预期危险 h, 强度 κ)），属性 a(r,p)（外观/几何/支撑拓扑/坡度/材质）。对位姿 p 输出 CG(p)=(ℓ̂_cg,ĥ_cg,κ_cg,Deriv)，Deriv 为可审计推导（触发规则+属性+属性置信度）。**非对称权限**：(V) ĥ_cg=hazard ∧ κ_cg≥θ_cg ⇒ 位姿红灯，未经位姿级实证不得承诺；(A) ℓ̂_cg=safe **永不**单独授权，仅可在数据已允许且仅 L1 时作有界佐证 EV-cg（权重≤w_max^cg，误差 δ_cg 入界）。属性置信度低于 θ_attr 时常识必须弃权。常识可靠性 ρ_cg 按事后证伪回溯、按证实有界恢复，规则库版本化。

**定义 141（常识-数据对质 CDC）** 对质算子 Conf(b_r,CG(p))∈{agree, silent_conflict, data_hazard, both_unsure}：(C1) agree（均安全）⇒ 可加 EV-cg（仅 L1，D(r)≤θ_D，且位姿级数据亦同意），不得进入不可逆接触必要证据集；(C2) silent_conflict（数据安全 ∧ 常识危险）⇒ **红灯**，禁止承诺，先发 CSC 判别探针，未决则绕行/降档/保守停；(C3) data_hazard ⇒ 常识安全不得翻案（非对称硬约束）；(C4) both_unsure ⇒ 走数据路径并加宽信念。**单调性**：忽略有界 L1 佐证，Commit_new ⊆ Commit_data。

**定义 142（位姿接地证书 PGC / J_g）** J_g=(J_p, 𝒫_adm, LB_pose, ε_pose, p\*, p̃, pose_track_log, cg_log, deriv_log, confrontation_log, veto_log)。有效性：①LB_pose(p\*)≥1−δ_f；②B(p\*,ε_pose)⊆安全域（鲁棒管）；③实现位姿 ‖p̃−p\*‖≤ε_pose 且持续监控；④无未决红灯。任一失效 ⇒ 证书即刻作废 ⇒ 安全停/重探，不允许"带着过期证书继续"。

**定义 143（常识反事实探询 CSC）** 常识假设集 ℋ_cg(p)（如 {水,冰,格栅,雪壳,沙}），每 h 给观测模型 p(o|h,π,p)。判别性价值 VOI_cg(π)=E[H(ℋ_cg)−H(ℋ_cg|o_π)]−cost(π)，候选探针须继承 A34 非破坏性且**在承诺位姿邻域内执行**。silent_conflict 时优先选 argmax VOI_cg。常识因此把开放集 OOD 转为有限假设判别，为语料盲区生成探针；若真实类别∉ℋ_cg，则判别失败必须显式弃权而非硬猜。

**定义 144（探-诺-演++ / 位姿接地承诺 GCP）** 每检查点：①算 𝒫_adm 与 LB_pose；②元推断（第 57 轮）；③对每个候选位姿做 CGR；④CDC 对质，silent_conflict ⇒ CSC 探针（预算 k_cg）；⑤承诺 ⇔ 位姿门 ∧ 证据门（第 57 轮 FSE）∧ 无红灯 ∧ 实现位姿吻合；否则重定位姿/绕行/降档/L2 协商/安全停。位姿重采样允许在 𝒫_adm 内重选 p 以恢复承诺，但不得放宽 LB_pose 门槛。

## 2. 关键算法伪代码（完整版见产物区）

```python
def pose_gate(r, M, p_star, eps_pose):
    Padm = admissible_poses(r, M)                 # Reach/F_cone/Clear/m_p>=K
    if not Padm: return Gate(False, 'empty_pose_set')
    LB = min(pose_safety(p, M) for p in Padm)     # 位姿下界，非边际
    tube_ok = all(safe(q, M) for q in ball(p_star, eps_pose))
    return Gate(LB >= 1 - delta_f and tube_ok, LB)

def commonsense_veto(r, p, K_cg):
    cg = K_cg.infer(attrs(r, p))                  # (label, hazard, conf, derivation)
    if cg.attr_conf < theta_attr: return False, cg   # 属性不可信 → 弃权
    return (cg.hazard == 'hazard' and cg.conf >= theta_cg), cg

def confront(b_r, cg, level):
    if cg.hazard and cg.conf >= theta_cg:
        return 'silent_conflict' if data_safe(b_r) else 'data_hazard'
    if data_safe(b_r) and cg.label == 'safe': return 'agree'
    return 'both_unsure'

def grounded_commit(cp, M, persona, K_cg):
    p_star = argmax(admissible_poses(cp.region, M), key=lambda p: pose_margin(p, M))
    gate = pose_gate(cp.region, M, p_star, eps_pose=track_error_q(0.95))
    if not gate.ok: return reroute_or_stop(cp)
    inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
    veto = False
    for _ in range(k_cg):
        veto, cg = commonsense_veto(cp.region, p_star, K_cg)
        rel = confront(M.b[cp.region], cg, cp.level)
        if rel == 'data_hazard': return reroute_or_stop(cp)
        if rel != 'silent_conflict': break
        pi = argmax(csc_candidates(cp, p_star), key=voi_cg)   # 位姿邻域内非破坏探针
        M = execute_and_fuse(M, cp.region, pi)
    if veto: return reroute_or_stop(cp)                        # 红灯未解 → 不承诺
    if few_shot_evidence_gate(core_contact(cp), M, persona, ood_reg)[0] != 'ok':
        return reroute_or_stop(cp)
    return commit(cp, p_star, Jg(M, cp, p_star, gate, cg))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| EPR | O(\|𝒫_adm\|·C_pose)/检查点 | O(\|𝒫_adm\|) | LB_pose 为真下界、ℓ_corr 迁移声明 |
| CGR | O(\|𝒦\|)/位姿 | O(\|𝒦\|) | 非对称权限、推导可审计、版本化 |
| CDC | O(1) | O(1) | 常识安全不翻数据危险、红灯不可绕过 |
| PGC | O(1)+监控 | O(\|J_g\|) | 绑定实现位姿、失效即作废 |
| CSC | O(\|ℋ_cg\|·k_cg) | O(\|ℋ_cg\|) | 探针非破坏且位姿邻域内、预算有界 |
| GCP | O(\|CP\|·(\|𝒫_adm\|+k_p+k_c+k_cg)) | O(\|V\|+\|σ\|) | 位姿门先行、红灯优先、终止性 |

**正确性定理（Grounded Commonsense Pose Soundness, GCPS 概要）**：在 A33–A40 上加 (A41) 位姿接地：LB_pose 为 𝒫_adm 上真下界、ε_pose 跟踪误差诚实且实现位姿被监控；(A42) 常识审计：否决精度≥1−ε_veto、ρ_cg 回溯诚实、规则库版本化、属性置信度可弃权；(A43) 对质非对称：常识安全永不覆盖数据危险、红灯不可被证据绕过、EV-cg 仅 L1 有界；(A44) CSC 探针非破坏且在承诺位姿邻域内、假设空间声明。则：(i) **位姿健全性** P(fail|commit)≤δ_f+δ_pose+δ_probe+ε_h；(ii) **安全单调性** 忽略有界 L1 佐证，Commit_new⊆Commit_data——位姿门与红灯只会删除承诺，CSC 只会增加安全探针；(iii) **语料盲区可判别**：silent_conflict 场景下，若真实类别∈ℋ_cg，则 ≤k_cg 次判别探针后或承诺或安全停，不再只能退回宽区间；(iv) **终止性** 每检查点 CSC≤k_cg，GCP 终止于{承诺,绕行,L2,安全停}。

## 6. 本轮最大风险

**一句话**：本轮把安全证书下沉到"这只脚的这个位姿"、又引入一个异源但不可信的常识先验；最大的风险不是常识会错，而是**任何一条代码路径让常识"授权"而非"否决"，或让 LB_pose 在一个脚从未真正占据的位姿集上计算**——那一刻，接地反而制造了虚假的安全感；整轮成立的前提是非对称权限（常识只否决不授权）与证书绑定**实现位姿**而非计划位姿。

## 2. 关键算法伪代码

### IP-139 EPR（位姿条件信念、位姿下界与证据迁移）

```python
def pose_safety(p, M):
    b = pose_conditioned_belief(p, M)             # b_{r,p}，非区域边际 b_r
    return credible_lower(b, delta_f)             # 可信集下界，非期望

def admissible_poses(r, M):
    out = []
    for p in sample_poses(r, M):
        if (reachable(p) and force_cone_ok(p, M)
            and clearance_ok(p, M) and pose_margin(p, M) >= K):
            out.append(p)
    return out

def pose_gate(r, M, p_star, eps_pose):
    Padm = admissible_poses(r, M)
    if not Padm:
        return Gate(False, 'empty_pose_set')      # 无安全位姿 ≠ 无位姿，走重规划
    LB = min(pose_safety(p, M) for p in Padm)     # 保守下界（离散化+Lipschitz）
    tube_ok = all(safe(q, M) for q in ball(p_star, eps_pose))
    return Gate(LB >= 1 - delta_f and tube_ok, LB)

def transfer_valid(p_probe, p_commit, ell_corr):
    if dist(p_probe, p_commit) <= ell_corr:
        return True, 0.0
    return False, transfer_operator_error(p_probe, p_commit)  # 超界须显式声明误差

def pose_response_evidence(p_tilde, w_tilde, pdot_tilde):
    return EVpose(pose=p_tilde, wrench=w_tilde, vel=pdot_tilde)  # 可证伪先验
```

### IP-140 CGR（常识接地推理，非对称权限）

```python
def cg_infer(r, p, K_cg):
    attrs = perceive_attributes(r, p)             # 外观/几何/支撑/坡度/材质
    if min(a.conf for a in attrs.values()) < theta_attr:
        return CG(label=None, hazard=None, conf=0.0,
                  derivation=Deriv(abstain=True))  # 属性不可信 → 弃权
    fired = K_cg.forward_chain(attrs)             # 定性规则前向链
    label, hazard, conf = K_cg.aggregate(fired)
    return CG(label, hazard, conf, Deriv(fired, attrs))   # 可审计推导

def cg_authority(cg):
    # 非对称：只有 hazard 有权限；safe 永不授权
    if cg.hazard == 'hazard' and cg.conf >= theta_cg:
        return 'VETO'
    if cg.label == 'safe':
        return 'CORROBORATE_ONLY'                 # 仅 L1 有界佐证
    return 'ABSTAIN'
```

### IP-141 CDC（常识-数据对质）

```python
def confront(b_r, cg, level):
    d_safe = credible_lower(b_r, delta_f) >= 1 - delta_f
    if cg_authority(cg) == 'VETO':
        return 'silent_conflict' if d_safe else 'data_hazard'  # 数据危险则常识无效
    if d_safe and cg.label == 'safe':
        return 'agree'                            # 仅可作 EV-cg，且限 L1
    return 'both_unsure'

def cg_evidence(rel, level, D, rho_cg):
    if rel == 'agree' and level == 'L1' and D <= theta_D and rho_cg >= rho_0_cg:
        return 'EV-cg'                            # 有界佐证，不入不可逆必要集
    return None
```

### IP-143 CSC（常识反事实探询）

```python
def csc_candidates(cp, p_star):
    H = K_cg.hypotheses(cp.region, p_star)        # {水,冰,格栅,雪壳,沙,...}
    cands = []
    for pi in non_destructive_probes(cp, p_star): # 继承 A34，限位姿邻域
        if in_ball(pi.pose, p_star, ell_corr):
            cands.append(pi)
    return cands

def voi_cg(pi, H, p_star):
    H0 = entropy(H)
    H1 = sum(prob(h) * entropy(posterior(H, o)) for o in predict(pi, H, p_star))
    return H0 - H1 - cost(pi)

def csc_probe(cp, p_star, H):
    pi = argmax(csc_candidates(cp, p_star), key=lambda q: voi_cg(q, H, p_star))
    o = execute_probe(pi, cap=F_abs)              # 力上限，非破坏
    return fuse_hypotheses(H, o), pi
```

### IP-144 GCP（探-诺-演++：位姿门 × 常识对质 × 反事实探询）

```python
def grounded_commit_planner(x0, M, task, budget, consent, personas, K_cg):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        p_star = argmax(admissible_poses(cp.region, M),
                        key=lambda p: pose_margin(p, M))
        gate = pose_gate(cp.region, M, p_star, eps_pose=track_error_q(0.95))
        if not gate.ok:
            alt = reroute(M, cp, risk_model)
            if alt: route = alt; continue
            return negotiate_or_stop(cp, M, None, None, consent,
                                     tau_int=tau_int(personas.active.auth))
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        veto, cg = False, None
        for _ in range(k_cg):                      # CSC 预算有界
            veto, cg = commonsense_veto(cp.region, p_star, K_cg)
            rel = confront(M.b[cp.region], cg, cp.level)
            cp.confront_log.append(rel)
            if rel == 'data_hazard': veto = True; break
            if rel != 'silent_conflict': break
            H, _ = csc_probe(cp, p_star, K_cg.hypotheses(cp.region, p_star))
            M = refit_from_hypotheses(M, cp.region, H)
        if veto:                                   # 红灯未解 → 不承诺
            cp.veto_log.open = True
            alt = reroute(M, cp, risk_model)
            if alt and pose_gate(alt.region, M, alt.p_star, gate.eps).ok:
                route = alt; continue
            return negotiate_or_stop(cp, M, None, None, consent,
                                     tau_int=tau_int(personas.active.auth))
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        g = select_gait(R)
        ev = tag_evidence_p(sigma, M, contact_level(cp))
        if g != 'halt' and few_shot_evidence_gate(
                core_contact(cp), M, personas, ood_reg)[0] == 'ok':
            J = Jg(M, cp, p_star, gate, cg, cp.track_log, cp.confront_log)
            sched.append(commit(sigma, g, p_star, J)); log.append(ev); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EPR | O(\|𝒫_adm\|·C_pose)/检查点 | O(\|𝒫_adm\|) | LB_pose 真下界、ℓ_corr 迁移声明（A41） |
| CGR | O(\|𝒦\|)/位姿 | O(\|𝒦\|) | 非对称权限、推导可审计、版本化（A42） |
| CDC | O(1) | O(1) | 常识安全不翻数据危险、红灯不可绕过（A43） |
| PGC | O(1)+监控 | O(\|J_g\|) | 绑定实现位姿、失效即作废 |
| CSC | O(\|ℋ_cg\|·k_cg) | O(\|ℋ_cg\|) | 探针非破坏且位姿邻域内、预算有界（A44） |
| GCP | O(\|CP\|·(\|𝒫_adm\|+k_p+k_c+k_cg)) | O(\|V\|+\|σ\|) | 位姿门先行、红灯优先、终止性 |

**正确性定理（Grounded Commonsense Pose Soundness, GCPS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 位姿接地：LB_pose 为 𝒫_adm 上的真下界（离散化+Lipschitz 保守界），ε_pose 为跟踪误差诚实分位，实现位姿 p̃ 被持续监控；**(A42)** 常识审计：否决精度 ≥1−ε_veto，ρ_cg 回溯诚实，规则库版本化，属性置信度不足时弃权；**(A43)** 对质非对称：常识安全永不覆盖数据危险，红灯不可被任何证据绕过，EV-cg 仅限 L1 且有界；**(A44)** CSC 探针继承 A34 非破坏性、在承诺位姿邻域内执行、假设空间已声明。则：

1. **位姿健全性**：P(fail | commit at p\*) ≤ δ_f + δ_pose + δ_probe + ε_h(w_max)。区域边际不再直接充当位姿证书；生态谬误被 LB_pose 的下界性质消除。
2. **安全单调性**：忽略有界 L1 佐证 EV-cg，`Commit_new ⊆ Commit_data`——位姿门与常识红灯只会删除承诺，CSC 只会增加非破坏探针；不存在由常识引入的升险路径。
3. **语料盲区可判别**：若 silent_conflict 且真实类别 ∈ ℋ_cg，则 ≤k_cg 次判别探针后系统或承诺或安全停；若真实类别 ∉ ℋ_cg，常识必须弃权并退回第 57 轮 OOD 保守路径（不硬猜）。
4. **终止性**：每检查点 CSC ≤k_cg，GCP 在 k_probes+k_cons+k_cg 内终止于 {承诺, 绕行, L2 协商, 安全停}。

**安全部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + δ_pose + δ_probe + ε_h + δ_ood·α_conf
                   + δ_xm·1[L1] + δ_cg·1[L1])
             − P(位姿监控失效) − P(𝓜 陈旧未检出) − P(护盾回退失败)
```

**活性界**（与安全分开，防止用安全掩盖死锁）：

```
P(progress) ≥ 1 − Σ_cp (ε_veto + P(𝒫_adm 因过保守而空且重规划失败))
```

关键：**位姿给接地、常识给否决**——LB_pose 把"区域平均安全"换成"最坏可采纳位姿安全"，常识把开放集 OOD 换成有限假设判别但只保留否决权；**非对称是整轮的支点**（误否决只损活性、误授权才损安全）；**证书绑定实现位姿**（p̃ 而非 p\*）使"接地"名副其实。

## 6. 本轮最大风险

**一句话**：本轮把安全证书下沉到"这只脚的这个位姿"、又引入一个异源但不可信的常识先验；最大的风险不是常识会错，而是**任何一条代码路径让常识"授权"而非"否决"，或让 LB_pose 在一个脚从未真正占据的位姿集上计算**——那一刻，接地反而制造了虚假的安全感；整轮成立的前提是非对称权限（常识只否决不授权）与证书绑定**实现位姿**而非计划位姿。
