# 第 44 轮（新循环第 4 轮） · Cert-Diagnosis × Gap-Map：把「故障诊断」与「研究空白」纳入证书闭环——从「安全停机」到「可诊断、可恢复、可自省」（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约求交为空」，但两者都指向同一个更深、未被言明的单点假设：**(H3) 证书只需要回答「能不能做」，不需要回答「为什么不能做」**。于是任何 guard 失败都被折叠成同一个动作——安全停机。这在 soundness 上无懈可击，却是**诊断学上的空白**：真实系统里「m<θ」可能是环境真变危险、模型/地图过期、传感器漂移、租约陈旧、人格识别错、或单纯的「我们走进了从未认证的空白区」。把六种根因折叠成一个停机，正是 v20「可用性崩塌」的根源之一。本轮灵感词「故障诊断」把证书从**判决器**升级为**诊断仪**；「研究空白」则要求把「没被认证的空间 / 没被验证的假设」变成一等公民，而不是当作不存在。二者耦合处——**空白的诊断**（这是故障，还是我们只是不知道？）——是本轮真正的新问题。

## 0. 直觉与动机

**灵感 1（故障诊断 → guard 失败是症状，不是结论）**：温度计报警不等于发烧；`m<θ` 也不等于「环境危险」。直觉上应保留失败时的**残差指纹**（margin 余量、租约余量、epoch 冲突、共形非一致性分数、persona 失配、几何不一致、跟踪误差），用签名匹配把症状归因到故障类，再选择**故障特异恢复**（重校准 / 重规划 / 重启子系统 / 撤销 persona / 回滚租约），恢复后必须**再认证**。这样「安全停机」从唯一出口降级为兜底出口，可用性在保持 soundness 的前提下被诊断救回来。

**灵感 2（研究空白 → 未认证空间与未验证假设都是对象）**：传统证书库只存「正例」：哪些状态被证明安全。但系统真正的风险常在**负空间**：从未尝试认证的区域（G_never）、预算内判不定的区域（G_undecided）、已被反证的区域（G_invalid）。直觉上三者完全不同：G_invalid 该绕开，G_undecided 值得探测，G_never 需要主动学习。把它们统一成「未知」是文献的结构性空白。于是引入**证书空白集 G** 与三态认知 κ∈{CERT, GAP, BAD}；进入 GAP 是**认知故障**而非物理故障，应触发主动诊断/探测而非直接停机。

**灵感 3（耦合 → 诊断必须区分「真故障」与「只是空白」）**：若系统把 GAP 误判为物理故障，会做无谓恢复甚至破坏系统；若把物理故障误判为 GAP，会去「探测」一个已经坏掉的系统。诊断的第一问不是「修什么」，而是**「这是故障还是无知」**。同时，主动诊断的探测动作本身必须**在证书内**（探测不能成为新的不安全来源）；恢复动作可能把系统带进 GAP，因此恢复必须携带「再认证证书」。一句话：**诊断可以花钱，但不能越界；恢复可以恢复可用性，但不能恢复许可上限**。

**耦合升级**：CFD（证书故障诊断器）把残差变成假设集与恢复策略；GME（空白图谱引擎）把负空间与开放假设变成可查询、可预测、可课程化的对象；FDV（诊断验证器）用故障注入验证诊断混淆矩阵与恢复再认证。四层架构由 v8 的「人格 + 并发」升级为 v9 的「人格 + 并发 + 诊断/空白平面」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（证书空白集与三态认知）**：设状态空间 S，已认证域 C = ∪_i dom(c_i)。**空白集** G = S \ C 分层为：G_never（无任何认证证据）、G_undecided（预算/理论内不可判定）、G_invalid（已被反证，已知坏）。三态认知 κ(x)=CERT if x∈C；GAP if x∈G_never∪G_undecided；BAD if x∈G_invalid。**命题（负空间不可省）**：sound 系统只能在 CERT 内执行；GAP 必须触发主动诊断或单调收缩，绝不能默认安全；BAD 必须硬拒绝。**推论**：把 GAP 与 BAD 混同，会把「可探索」误当「危险」而牺牲可用性；把 GAP 与 CERT 混同，则产生静默失效。

**定义 45（故障模型、残差与签名）**：故障类 F = F_alea（真实环境漂移）∪ F_epis（模型/地图过期、空白、校准漂移）∪ F_comp（传感器/执行器/运行时）∪ F_adv（人格误识别/投毒/置信度攻击）∪ F_conc（陈旧读、撕裂读、租约过期、模式切换丢失）。**残差向量** r(t) = (m−θ, 租约余量 m−λΔ−θ, epoch 冲突计数, 共形非一致性分数, persona 失配度, 几何不一致度, 动作跟踪误差)。**故障签名** Σ(f)=P(r|f)（或鲁棒区间包络）。**诊断** Ĥ_f = {f : r 与 Σ(f) 相容} ⊆ F。

**定义 46（可诊断性与保守交集）**：故障对 (f,f') 关于残差映射 φ 是 (ε,δ)-可分的，若两签名的支撑集间隔 ≥ ε 且在该间隔上的误分概率 ≤ δ。f 可诊断当且仅当对所有 f'≠f，(f,f') (ε,δ)-可分。**定理（非唯一诊断的保守恢复）**：若 |Ĥ_f|>1，则允许执行的恢复动作集合为 R*(Ĥ_f)=∩_{f∈Ĥ_f} R(f)（对所有候选故障都成立的恢复交集）；若 R* 为空，必须安全停机，禁止猜测性恢复。**推论**：误诊的风险被限制在「恢复交集」内，而不是被诊断置信度直接放大。

**定义 47（认证主动诊断）**：探测动作 a_p ∈ A_diag ⊆ A，须满足 (i) 探测轨迹全程保持在 CERT（探测自带证书）；(ii) 最大化期望信息增益 IG(a_p)=H(Ĥ_f)−E[H(Ĥ_f|r')]；(iii) 探测代价（时间 / 扰动量 / 打扰用户次数）≤ 预算 B_diag。**定理（探测不降 soundness）**：若每个 a_p 被证书 guard 许可且探测有限终止，则主动诊断保持 soundness，且期望假设熵单调不增。

**定义 48（故障特异恢复与再认证）**：恢复策略 π_f: F→动作序列（F_alea→重规划；F_epis→重校准/重采样/回退空白安全包络；F_comp→重启子系统/切换冗余；F_adv→撤销 persona/降权；F_conc→回滚 epoch/重取租约）。恢复可执行当且仅当 (i) 恢复轨迹每步在 CERT ∪ 受控小 GAP 预算内，(ii) 恢复后**重新认证**通过。**单调恢复命题**：恢复不得放松任何阈值 θ 或人格契约 Π_u；恢复只能恢复可用性，不能提高许可上限。

**定义 49（开放空白账本 OGL 与信息增益优先级）**：每个跨轮遗留假设 a_k=(claim_k, evidence_k∈{supported,refuted,open}, residual_test_k, impact_k)。**研究空白** = {a_k : evidence_k=open}。下一轮实验按期望诊断信息增益/成本优先：e* = argmax_e IG(e|OGL)/cost(e)。**命题（研究过程的自诊断）**：若每轮至少把一个 open 假设转为 supported/refuted，或改写为可测 residual_test，则开放空白集单调收缩；否则该假设必须升级为红线风险。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERT-FAULT-DIAGNOSTICIAN（证书故障诊断器 CFD）
1. **残差提取**：从 IP-51 / CCR / 几何 / 共形 / 租约导出标准化 r(t)，与判决解耦（判决仍只由 guard 给）。
2. **签名库与诊断**：每故障类维护 Σ(f)，在线做集合覆盖 / 贝叶斯更新得 Ĥ_f；非唯一时走定义 46 保守交集。
3. **可诊断性检查**：离线计算故障对可分图，标注不可诊断对；不可诊断对默认保守。
4. **诊断状态机**：CERT →(guard false)→ DIAGNOSE →(unique)→ RECOVER(π_f) → RECERT → CERT；非唯一 → CERTIFIED_PROBE 或 SAFE_STOP。

### 2.2 IP-61 GAP-MAP-ENGINE（空白图谱引擎 GME）
1. **空白集构建与索引**：C 的并集求补得 G，三分 G_never/G_undecided/G_invalid；空间哈希支持 O(1) 查询。
2. **认知故障预测**：对候选轨迹预测是否进入 GAP，提前触发探测 / 收缩 / 课程采样。
3. **负面知识库**：IP-55 CKB 新增 negative certificate（已知坏）/ undecidable（判不定）/ boundary（临界）；指纹增 gap 维度。
4. **OGL 与信息增益课程**：把每轮 residual risk 登记为 open 假设 + residual_test，驱动 gap-directed curriculum 与下一轮实验选择。

### 2.3 IP-62 FAULT-DIAGNOSIS-VALIDATOR（故障诊断验证器 FDV）
1. **故障注入矩阵**：按 F 类注入（传感器噪声 / 漂移、执行器卡死、地图过期、租约抖动、撕裂读、persona 投毒、分布漂移）。
2. **诊断混淆矩阵**：根因 top-1/top-k、误隔离率、不可诊断对检出率、误诊后不安全动作（必须 0）。
3. **恢复再认证审计**：恢复后 sound 率、可用性恢复率、恢复是否越权放松阈值。
4. **空白实验**：gap 检测前置率、gap-directed vs 随机采样的信息增益比。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 故障归因 | 根因 top-1/top-3；误隔离率 | ≥90%/≥98%；<5% |
| E96 可诊断性 | 可分故障对比例；不可诊断对正确标记率 | ≥85%；100% |
| E97 认证主动诊断 | 探测违例；平均信息增益；诊断时延 | 0；≥1.0 bit/探测；<200ms |
| E98 恢复再认证 | 恢复后违例；可用性恢复率 vs 一刀切停机；越权放松 | 0；≥80%；0 |
| E99 空白图谱 | GAP 提前检出率；假空白率；三态误分类 | ≥95%；<10%；0 |
| E100 空白课程 | gap-directed 信息增益/仿真小时 vs 随机；gap 覆盖率 | ≥2x；≥90% |
| E101 并发/人格故障注入 | 陈旧/撕裂读检出；persona 投毒检出；误恢复 | 100%；≥95%；0 |
| E102 长时程诊断 | 100h 误诊致不安全动作；诊断漂移；OGL 关闭率 | 0；<5%；≥1 假设/轮 |

回退：E95/E96 不达标 → 取消自动恢复，退回「诊断仅解释、恢复人工」；E97 探测违例 → 关闭主动探测，仅被动诊断；E98 恢复越权 → 强制恢复仅做单步且必再认证；E99 假空白率高 → GAP 一律按 BAD 保守处理；E100 无收益 → 课程退回随机；E101 漏检 → 并发故障一律走 HI 安全停机；任何红线失败 → 回退 v20。

## 5. 本轮最大风险

**一句话**：不同根因可能共享同一残差签名（签名碰撞），尤其人格投毒可被伪装成环境漂移，使诊断高置信地误归因并执行「看起来合理」的恢复，从而把一个新的攻击面引入闭环——因此 E95（误隔离）与 E98（恢复再认证）必须设为红线，且默认策略是「非唯一诊断只允许执行保守恢复交集，空交集则安全停机」。

| Σ(f)=P(r\|f) | 故障签名 | 故障类到残差分布的映射（或区间包络） |
| Ĥ_f ⊆ F | 诊断假设集 | 与当前残差相容的故障类集合 |
| (ε,δ)-可分 | 可诊断性 | 签名支撑集间隔 ≥ ε 且误分 ≤ δ |
| R*(Ĥ_f)=∩_{f∈Ĥ_f} R(f) | 保守恢复交集 | 非唯一诊断时允许执行的恢复集合 |
| A_diag | 探测动作集 | 自身满足证书的主动诊断动作 |
| IG(a_p) | 信息增益 | H(Ĥ_f)−E[H(Ĥ_f\|r')] |
| π_f | 故障特异恢复 | F→动作序列 |
| B_diag | 诊断预算 | 探测时间/扰动/打扰上限 |
| a_k=(claim,evidence,residual_test,impact) | OGL 假设 | 开放空白账本条目 |
| e* = argmax IG(e\|OGL)/cost(e) | 实验优先级 | 按信息增益/成本选择下一实验 |

## 2. 关键算法（伪代码）

### IP-60 CFD：三态分类、残差、诊断与保守恢复
```
def classify_cognition(x, cert_index, bad_index):
    if x in bad_index:  return BAD      # 已知坏：硬拒绝
    if x in cert_index: return CERT     # 已认证：允许
    return GAP                          # 未知：诊断/探测/收缩

def extract_residuals(x, guard, lease, epoch, conf, persona, geom, tracker, t):
    return Residual(
        guard_margin      = guard.m - guard.theta,
        lease_margin      = lease.m - lease.lam*(t-lease.tau) - guard.theta,
        epoch_conflict    = epoch.conflicts,
        conformal_score   = conf.nonconformity(x),
        persona_mismatch  = persona.mismatch(x),
        geom_inconsistency= geom.residual(x),
        tracking_error    = tracker.err(x))

def diagnose(r, signatures, delta):
    H = {f for f, S in signatures.items() if compatible(r, S, delta)}
    if not H:
        return {F_epis}                 # 无签名相容 => 模型/空白导致的认知故障
    return H                            # 可能多元素 => 非唯一

def safe_recovery(H, pi, cert):
    if len(H) == 1:
        seq = pi[next(iter(H))]
    else:
        seq = intersect_recoveries([pi[f] for f in H])   # 定义 46 保守交集
        if not seq:
            return SAFE_STOP            # 空交集：禁止猜测性恢复
    for a in seq:
        if not cert.allows(a):          # 恢复不得越证书/放松阈值
            return SAFE_STOP
        a.execute()
    return RECERT                       # 恢复后必须再认证
```

### IP-60/47：认证主动诊断与故障传播
```
def certified_probe(H, A_diag, cert, budget):
    best = None
    for a_p in A_diag:
        if not cert.allows_trajectory(a_p):   # 探测轨迹必须全程在 CERT
            continue
        ig = entropy(H) - expected_entropy(H, a_p)
        if cost(a_p) <= budget and ig/cost(a_p) > (best.score if best else -inf):
            best = Probe(a_p, ig, ig/cost(a_p))
    return best.action if best else PASSIVE_DIAGNOSE   # 无安全探测则被动观察

def compose_fault_signatures(subsystem_sigs, topology):
    # 组合子系统的故障签名；接口处只保留可观测投影，避免无关维度爆炸
    return project(convolve(subsystem_sigs), topology.observable_vars)
```

### IP-61 GME：空白图谱、轨迹预测与 OGL 优先级
```
def build_gap_map(cert_domains, bad_domains, undecided_domains, index):
    C = union(cert_domains)
    for cell in index.cells():
        if cell in bad_domains:      index.set(cell, BAD)
        elif cell in C:              index.set(cell, CERT)
        elif cell in undecided_domains: index.set(cell, GAP_UNDECIDED)
        else:                        index.set(cell, GAP_NEVER)

def predict_gap_entry(trajectory, gap_index):
    return any(gap_index.classify(z) in (GAP_NEVER, GAP_UNDECIDED, BAD)
               for z in trajectory)

def gap_directed_curriculum(gap_index, sampler, budget):
    cells = [c for c in gap_index.cells() if gap_index.classify(c) != CERT]
    cells.sort(key=lambda c: gap_index.uncertainty(c), reverse=True)  # 高不确定优先
    return [sampler.sample(c) for c in cells[:budget]]

def ogl_prioritize(ogl, candidate_experiments):
    open_claims = [a for a in ogl if a.evidence == OPEN]
    return max(candidate_experiments,
               key=lambda e: expected_info_gain(e, open_claims) / cost(e))
```

### IP-51/58 升级：诊断感知的守卫与租约
```
def car_transition_guard_v2(e, x, cert_obj, persona, lease, t):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m = min(cert_obj.lookup(x).m_lo[e],
            lease.m - lease.lam*(t-lease.tau),
            persona_cap[e](persona))
    if m >= theta and lease_valid(lease, theta, t):
        return ALLOW
    # 不再直接停机：携带残差进入诊断状态机
    return DIAGNOSE(extract_residuals(x, Guard(m, theta), lease,
                                      epoch_of(cert_obj), cert_obj.conf,
                                      persona, cert_obj.geom, cert_obj.tracker, t))

def concurrency_fault_residual(lease, epoch, read_log, t):
    return Residual(
        lease_margin   = lease.m - lease.lam*(t-lease.tau) - lease.theta,
        epoch_conflict = epoch.conflicts,
        stale_reads    = sum(1 for r in read_log if r.epoch != epoch.current),
        torn_reads     = sum(1 for r in read_log if r.start_epoch != r.end_epoch))
```

## 6. 本轮最大风险

**一句话**：不同根因可能共享同一残差签名（签名碰撞），尤其人格投毒可被伪装成环境漂移，使诊断高置信地误归因并执行「看起来合理」的恢复，从而把一个新的攻击面引入闭环——因此 E95（误隔离）与 E98（恢复再认证）必须设为红线，且默认策略是「非唯一诊断只允许执行保守恢复交集，空交集则安全停机」。
