# 第 44 轮（新循环第 4 轮） · LiDAR-Health × Fault-Diagnosis：把「传感器健康」与「故障诊断」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖 + 多用户契约空集」，但它仍压着一个更底层的假设：**(H3) 几何证书的观测源（LiDAR）是对世界的忠实采样**——C_ms、m_lo、I_u^α、租约衰减全部默认点云可信。真实 LiDAR 会在雨雾/玻璃/金属反射、运动畸变、标定漂移、通道失效、对抗注入下**静默失真**：它不是报错，而是给出一个「看起来正常」的点云，让证书产生**自信的错误**。本轮灵感词「激光雷达」「故障诊断」精确命中 H3：**激光雷达**迫使我们把传感器从「可信前端」降级为「可故障、需诊断的组件」；**故障诊断**迫使我们把健康从「报警/急停」升级为**证书的 soundness 参数**。二者耦合出的新问题是：**诊断本身也会错，且故障表不完整**——因此必须做集合值健康估计，并对「未知」给出可证明的保守证书。

## 0. 直觉与动机

**灵感 1（故障不是报警，是证书的保守化算子）**：现状三选一都很差——报警（交人，延迟不可证）、急停（可用性崩塌）、无视（静默不 sound）。直觉上应把故障看成对几何证书的一次**有界扰动**：每种故障模式 f 在其认证运行包络 E_f 内，最多让「观测净空」高估真实净空 δ_f。于是证书只需**腐蚀** δ_f：C_ms(h)=C_ms ⊖ δ_h，守卫用 m_obs−δ_h≥θ。健康越差，证书越小，安全免费、可用性付费——这把故障容错从二值开关变成**连续、可审计的单调降级**，并与 v20 的人格收缩天然可交：C=C_global∩Π_u∩C_h。

**灵感 2（诊断是集合，不是单点标签）**：单标签故障分类器是新的单点故障：它一旦判错，证书就静默错。改用**共形故障集合** Ĥ：按故障类分层校准非一致性分数，保证 P(f*∈Ĥ)≥1−β；证书对 Ĥ 的最坏情况做保守化，δ_Ĥ=max_{f∈Ĥ}δ_f。关键反转：**诊断质量成为可用性杠杆**——Ĥ 越小，δ 越小，证书越大；而覆盖率 1−β 越大，Ĥ 越大，证书越小。这把 v20「收缩免费、扩张持证」原封不动搬到**故障标签空间**，形成显式的「可诊断性 vs 可用性」Pareto。

**灵感 3（证书反过来诊断传感器，但要破循环）**：慢标定漂移、微小外参偏差在原始点云统计里几乎不可见，却会在**证书残差**（预测边际−实测边际）上留下系统性偏移。因此证书层本身就是一个故障传感器；而「无金标准」下的诊断之所以可能，是因为证书不变式（时序连续性、运动一致性、跨模态一致性、地图先验）不依赖任何单一传感器健康。但双向闭环有**循环性风险**：能同时欺骗观测与残差模型的故障可自洽而不被发现。必须用**独立锚点**（IMU/相机/地图/已知路标/轮速）的多样性破环，并规定：**任何无法证明可检测的故障一律归入 unknown 并触发最大收缩**。

**耦合升级**：健康层与 v20 的人格/并发层耦合出真正的难点：人格收缩与健康收缩叠加可能直接为空集；健康诊断必须在并发过载时保持最高关键级与硬预算；健康租约与证书租约必须原子刷新，否则会读到「证书新、健康旧」的撕裂状态。四层架构因此从 v8 的「仿真-检索-边缘 + 人格 + 并发」升级为 v9 的「+ 健康-故障闭环层」，并新增 IP-60/61/62。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（LiDAR 故障模式与几何失真界）**：故障模式集 F={f_rain, f_fog, f_glass, f_range, f_distort, f_calib, f_dropout, f_spoof, …}，每类 f 有认证运行包络 E_f（天气/材质/距离/动态/温度）。**几何失真界** δ_f≥0：在 E_f 内，对任意真实世界 W 与故障下点云 P，观测净空对真实净空的单侧高估满足 sdf_W(x) ≥ sdf_P(x) − δ_f，∀x∈证书域。取 δ_nominal=δ_0（测量噪声），δ_unknown=δ_max（包络内最坏界；若无界则证书域置空）。**单调性**：F'⊆F'' ⇒ δ_{F'}≤δ_{F''}。**注**：δ_f 是经验认证量而非解析证明，其自身不确定度必须计入（见风险）。

**定义 45（健康条件化几何证书 LHCC 及其 sound 性）**：C_ms(h)=C_ms(P) ⊖ δ_h，即可行动作集 A_h={a: m_obs(a)−δ_h≥θ}。**定理（健康条件 sound）**：若真实故障 f*∈Ĥ，则 C_ms(Ĥ) 放行的任意 a 满足真实边际 m_true≥θ。证：m_true ≥ m_obs−δ_{f*} ≥ m_obs−δ_Ĥ ≥ θ（δ_Ĥ=max_{f∈Ĥ}δ_f 且 δ 对集合单调）。**推论**：健康收缩对 soundness 免费（δ↑⇒C↓）；降低 δ（恢复/扩张）必须持诊断证据。**组合**：C=C_global∩Π_u∩C_ms(Ĥ)；三层收缩中，安全与健康层**不可协商**，只有人格层可协商放松。

**定义 46（共形故障集合、可诊断性与开放集）**：健康监测器由多源残差产生非一致性分数 s(x_t,f)，按故障类分层校准；Ĥ_t={f: s(x_t,f)≤q_f(1−β)}，在可交换性下 P(f*∈Ĥ_t)≥1−β。**可诊断性**：f 为 (ε,γ)-可诊断，若故障下残差分布与 nominal 分离 ≥ε 且漏检 ≤γ；仅在**证书残差空间**可分离者称**证书级可诊断**（如标定漂移）。**开放集规则**：unknown 默认属于 Ĥ，除非通过**认证新颖性检验**显式排除；排除失败或检验未通过则 Ĥ=F∪{unknown}、δ=δ_max。**推论**：不可证明可检测的故障被自动纳入最坏情况，从而 soundness 不依赖诊断完备性，只依赖 δ_max 有界。

**定义 47（健康租约、检测时延与预腐化）**：健康结论携带租约 (h,τ,T_h,κ)，有效当 t−τ≤T_h；取 T_h≤min_{f∈F_crit} τ_det(f)，τ_det 为认证检测时延。租约过期、监测预算被饿死或诊断失效 ⇒ Ĥ:=F∪{unknown}、δ:=δ_max（最大收缩）。**检测时延暴露窗**：故障从 onset 到被检出存在 [onset, onset+τ_det] 窗口；用**预腐化** δ_pre=max{δ_f: f 可在 τ_det 内 onset 且未被检出} 覆盖该窗口，最终腐蚀 δ=max(δ_Ĥ,δ_pre)。**命题**：若健康监测以最高关键级运行且 WCET 有界，则 T_h≤τ_det 下证书永不使用过期 nominal 诊断。

**定义 48（单调降级格与恢复闸门）**：健康状态构成格 (H,≼_h)：nominal≼_h degraded(f)≼_h …≼_h unknown（≼_h 表示「至少同样健康」）。运行期只允许**自由向更保守**移动；向更健康移动（恢复）必须过**恢复闸门**：独立锚点一致 ∧ 连续健康计数≥N_rec ∧ 驻留时间≥T_dwell ∧ 重颁健康租约。**定理（恢复 sound）**：若恢复仅在「f*∉F_recovered 且驻留超过故障瞬态」时开启，则恢复不重新引入不 sound；滞回+驻留消除模式抖动。**注**：闸门是可用性与安全之间的显式、可审计契约。

**定义 49（双向闭环与循环性破除）**：证书残差 r_t=m_pred(t)−m_obs(t) 同时喂给诊断（诊断←证书）与证书（证书←诊断）。**不可检测条件**：若故障 f 的残差签名在所有独立锚点 A_ind={IMU,相机,地图先验,已知路标,轮速} 的 nominal 噪声内，则 f 不可检测，必须归入 unknown 并由 δ_max 覆盖。**锚点多样性条件**：∩_{a∈A_ind} Influence(a)=∅，或故障须同时污染 ≥k 个独立模态才可能不被察觉。**契约**：诊断可缩小 Ĥ 的前提是「至少一个不受该故障影响的独立锚点 + 证书级可诊断证据」；否则不得排除 unknown。**推论**：闭环 soundness = 健康集合覆盖（定义 46）+ 腐蚀界有界（定义 44）+ 不可检测故障默认 unknown（本定义），三者缺一不可。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 LIDAR-HEALTH-CERTIFIER（激光雷达健康证书器 LHC）
1. **故障模式库与失真界认证**：每类故障在认证包络 E_f 内标定 δ_f；按距离/天气/材质分段，δ_f 取包络上界并叠加不确定度。
2. **多源健康特征**：原始点云统计（环/距/强度/回波缺失）、scan-to-map 残差、LiDAR-IMU 残差、LiDAR-相机跨模态、证书残差。
3. **共形健康集合**：按故障类分层校准，输出 Ĥ（含开放集 unknown）；δ_Ĥ=max δ_f。
4. **健康条件化证书**：C_ms ⊖ δ_Ĥ，并叠加检测时延预腐化 δ_pre；签发健康租约 (h,τ,T_h,κ_safety)。

### 2.2 IP-61 FAULT-DIAGNOSIS-LOOP（故障诊断闭环 FDL）
1. **残差生成库**：多模态残差并行计算，输出可解释故障特征。
2. **故障隔离**：共形集合 + 签名匹配；证书级可诊断故障（标定漂移等）走证书残差通道。
3. **单调降级与恢复闸门**：降级格 + 滞回/驻留/独立锚点证据；恢复必须重颁健康租约。
4. **降级策略**：未知→最大收缩或安全停机/切备用传感器；可恢复故障→按 δ 收缩并协商人格；**永不放松安全与健康层**。
5. **健康租约与预算**：健康监测固定最高关键级，硬隔离预算，与证书租约原子刷新。

### 2.3 IP-62 DEGRADATION-VALIDATOR（退化验证器 DV）
1. **故障注入等价类**：按「证书退化签名」而非物理现象分类，保证每类至少一个代表被覆盖；定义**证书故障覆盖率 CFC**。
2. **LiDAR 退化仿真**：雨/雾/雪、玻璃/水面/金属、运动畸变、标定漂移、通道失效、对抗点注入/中继欺骗。
3. **开放集评估**：未见故障 AUROC、unknown 触发率、漏检致 unsound 计数。
4. **故障×人格×并发矩阵**：在 v20 的交错/多用户压力测试上叠加故障注入。
5. **长时程健康租约/恢复抖动/MTTD/MTTR**。

## 5. 本轮最大风险

**一句话**：开放集故障 + δ_f 的经验性——故障表不完整、失真界 δ_f 又只是有限注入数据上的估计，未知故障可能骗过诊断得到一个「小而错」的 Ĥ，从而在证书层制造自信的错误；因此必须默认「unknown∈Ĥ」、把 E95/E101 设为红线，并对任何无法证明可检测的故障一律按 unknown 最大收缩，宁可牺牲可用性也不静默不 sound。

## 2. 关键算法（伪代码）

### IP-60 LHC：多源健康特征、共形健康集与健康条件化证书
```
def health_features(P, imu, cam, map_prior, cert_prev):
    return {
      'raw':    point_stats(P),                   # 环/距/强度/回波缺失率
      's2m':    scan_to_map_residual(P, map_prior),
      'lio':    lidar_imu_residual(P, imu),
      'xmodal': lidar_camera_consistency(P, cam), # 深度/语义一致性
      'cert':   cert_prev.m_pred - measure_margin(P),
    }

def conformal_health_set(feats, beta, calib):
    H = {f for f in FAULTS if score(feats, f) <= quantile(calib[f], 1 - beta)}
    if not certified_novelty_reject(feats):       # 开放集：无证据排除
        H.add(UNKNOWN)                             # unknown 默认在内
    return H

def delta_bound(H):
    return DELTA_MAX if UNKNOWN in H else max(DELTA[f] for f in H)

def preemptive_erosion(H):
    # 覆盖检测时延窗内可能 onset 且尚未检出的故障
    return max((DELTA[f] for f in ONSET_WINDOW if f not in H), default=0.0)

def health_conditioned_cert(P, H, theta):
    d = max(delta_bound(H), preemptive_erosion(H))
    A = {a for a in actions(P) if margin_obs(P, a) - d >= theta}
    return Cert(admissible=A, delta=d, health=H)   # d 即证书携带的健康证明

def issue_health_lease(H, tau_det):
    return HealthLease(h=H, tau=monotonic_now(), T=min(tau_det), kappa=K_SAFETY)
```

### IP-61 FDL：诊断、单调降级格与恢复闸门
```
def diagnose(feats, beta, calib, anchors):
    H = conformal_health_set(feats, beta, calib)
    for f in CERT_DIAGNOSABLE:                     # 证书残差通道
        if signature_match(feats['cert'], SIGN[f]): H.add(f)
    if not anchor_diversity(anchors, H):           # 破循环：锚点不足则不可排除
        H.add(UNKNOWN)
    return H

def degradation_step(H_prev, H_new, anchors):
    if more_healthy(H_new, H_prev):                # 向健康方向：需恢复闸门
        return H_new if recovery_gate(H_new, anchors) else H_prev
    return H_new                                   # 向保守方向：自由移动

def recovery_gate(H_new, anchors):
    return (anchor_diversity(anchors, H_new) and
            consecutive_healthy() >= N_REC and
            dwell_time() >= T_DWELL and
            fresh_health_lease(H_new))

def degrade_policy(H, C_persona):
    if UNKNOWN in H:
        return safestop_or_fallback(C_persona)     # 最大收缩，绝不静默放行
    if H & FALLBACK_FAULTS:
        return switch_sensor(C_persona, H)         # 相机/雷达备用 + 重新腐蚀
    return contract_by_delta(C_persona, delta_bound(H))

def health_cert_margin(x, health):
    return measure_margin(x) - max(delta_bound(health.H),
                                   preemptive_erosion(health.H))
```

def car_guard(e, x, cert_obj, persona, lease, health, t):

def monitor_step_health(x, health):

### IP-62 DV：按证书退化签名构造注入等价类与开放集评估

def build_injection_classes(F):
    classes = {}
    for f in F:
        sig = (DELTA[f], frozenset(AFFECTED_ANCHORS[f]), ONSET_RATE[f])
        classes.setdefault(sig, []).append(f)      # 按证书退化签名分组

def certificate_fault_coverage(classes, tested):

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 健康特征 | O(|P|+log N) | O(|P|) | 多源残差；分层共形覆盖 ≥1−β |
| IP-60 δ/腐蚀 | O(|F|) | O(|F|) | δ 对集合单调 ⇒ 健康收缩 sound |
| IP-60 预腐化 | O(|F_onset|) | O(1) | 覆盖检测时延窗，T_h≤τ_det |
| IP-60 证书腐蚀 | O(|A|) | O(|A|) | m_obs−δ≥θ ⇒ m_true≥θ |
| IP-61 隔离 | O(|F|·d) | O(|F|) | 可诊断性+锚点多样性 ⇒ Ĥ 覆盖 |
| IP-61 降级格 | O(1) | O(1) | 单调向保守+恢复闸门 ⇒ 无抖动、无错误恢复 |
| IP-61 策略 | O(|H|) | O(1) | unknown→最大收缩 ⇒ 不静默放行 |
| IP-51 守卫 | O(|E|) | 同 L0+双租约 | min 四源+双租约有效 ⇒ 无陈旧/无失真放行 |
| IP-56 监控 | O(1) INT8 | O(1) | 量化+健康失真取 max ⇒ 保守 |
| IP-62 注入类 | O(|F|) | O(|F|) | 按退化签名分组 ⇒ CFC 可度量 |
| IP-62 开放集 | O(N log N) | O(N) | 未见故障 AUROC 可评估 |

**正确性证明要点（增量）**：

- **命题 1（健康条件 sound）**：若 f*∈Ĥ，则 ∀a∈A_h：m_true(a) ≥ m_obs(a)−δ_{f*} ≥ m_obs(a)−δ_Ĥ ≥ θ。∎
- **命题 2（预腐化覆盖时延）**：设故障在 [t0,t0+τ_det] 未被检出，则期间 f*∈ONSET_WINDOW，δ_pre≥δ_{f*}，故 m_true ≥ m_obs−δ_pre ≥ θ。∎
- **命题 3（不可检测故障）**：若 f* 对所有独立锚点不可检测，则由定义 49 不允许将其排除出 unknown，Ĥ∋unknown ⇒ δ=δ_max≥δ_{f*} ⇒ sound（或证书域空 ⇒ 停机）。∎
- **命题 4（三层收缩组合）**：C=C_global∩Π_u∩C_h ⊆ C_h，C_h sound ⇒ C sound；收缩不新增违例，只可能使可行集为空 ⇒ 必须协商/停机，绝不静默放行。∎
- **协商顺序**：三层收缩为空时，先放松人格层 Π_u（安全/健康不可协商）；若仍空（源于健康），切备用传感器或安全停机。

## 6. 本轮最大风险

**一句话**：开放集故障 + δ_f 的经验性——故障表不完整、失真界 δ_f 又只是有限注入数据上的估计，未知故障可能骗过诊断得到一个「小而错」的 Ĥ，从而在证书层制造自信的错误；因此必须默认「unknown∈Ĥ」、把 E95/E101 设为红线，并对任何无法证明可检测的故障一律按 unknown 最大收缩，宁可牺牲可用性也不静默不 sound。
