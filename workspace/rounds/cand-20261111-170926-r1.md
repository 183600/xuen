# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「视觉感知」×「目标检测」）

> 第 54 轮把技能组合提升为「动作-鲁棒性」双证书，但仍默认了一个从未受检的前提：**α_S 与 ρ 都假设“被操作的那个对象”已经被正确感知、正确指认**。本轮把视觉感知与目标检测纳入证书体系。核心矛盾：H22：检测置信度被下游当作真值使用，而数据集级 mAP 与“本任务关键指称对象的实例级可靠性”根本不是一回事；H23：组合失败常常不是动作不兼容，而是**指称不一致**——同一物理对象在两个技能里被检测/跟踪成不同实例，视觉接地断裂，动作层却毫无察觉。

## 0. 直觉与动机

**灵感 1（视觉感知 → 感知是带不确定性的测量，不是真值）**
直觉：技能 `grasp(cup)` 真正执行的是 `grasp(被指认为 cup 的那个实例 r)`。检测器给出的不是“杯子的位置”，而是“关于杯子位置的一次带漏检概率、定位误差与置信偏置的测量”。因此动作剖面应写成 **感知条件化** 的形式 `α_S(a | g)`，其中 `g` 是视觉接地（referent → instance）。当 `g=⊥` 或低置信时，动作剖面本身就被污染；再精确的动作证书也救不回来。

**灵感 2（目标检测 → 实例级检测证书，而非数据集级 mAP）**
直觉：mAP 是数据集平均，部署时真正关心的是“本任务依赖的那几个指称对象”是否被稳定检出。于是把检测从单一分数拆成**四维实例证书** `D_cert(o) = (recall_o, IoU_q, ECE_o, stab_o)`：漏检、定位分位、置信校准、时序稳定。它直接接入第 53 轮鲁棒性谱 `ρ`，成为感知维度 `d_perc`，而不是一个新的、与 `ρ` 平行的黑箱分数。

**灵感 3（指称接地 → 身份才是隐藏的耦合变量）**
直觉：两个技能引用同一物体，但跟踪器在遮挡后发生 ID switch，或“那个”在视角变化后指错，组合就在语义上断裂了——可动作空间交集 `compat` 仍然很高。建立 **接地图 `G_g`**：节点是持久轨迹 track，边是“技能-指称-track”的分配。组合除了动作兼容，还要 **指称一致性**：同一 track、可见性重叠在预算内、ID 漂移风险低于阈值。这样“组合失败”可以被下移到感知层定位，而不是笼统归因于鲁棒性。

**灵感 4（云边感知不对称 → 感知对齐证书）**
直觉：云端大检测器（高召回、可慢），边端小检测器（实时、低功耗）。已有 `γ_ce` 映射动作，却没有映射**检测**。云端说“目标在 B”，边端漏检，边端计划就是“盲执行”。引入感知映射 `γ_ce^perc : I_c → I_e` 与感知对齐误差 `δ_p`、分歧集 `Dis = {o | D_cert_e(o) 不通过而 D_cert_c(o) 通过}`。分歧未经边端重查消解，就否决部署。

**灵感 5（主动感知 → 感知本身就是一种动作）**
直觉：当关键区域检测证书低于阈值，机器人可以执行“靠近、换视角、拨开遮挡”等信息获取动作 `π_probe`。动作空间因此扩为 `A ∪ A_probe`。组合规划可在证书不足处**插入探测动作**，用期望信息增益与成本之比决定是否探测。这把感知与动作统一为一条可调度的“信息-物理动作序列”，也让第 54 轮的 `A_cert` 与 `D_cert` 通过 `π_probe` 相互转化。

**灵感 6（金字塔向下补一层）**
直觉：第 53/54 轮的金字塔是 `𝕃`（鲁棒性）叠在 `𝔸`（动作协同）上。其实 `𝔸` 之下还缺一层 `ℙ`（感知接地）：`ℙ_0` 传感器物理极限，`ℙ_1` 检测，`ℙ_2` 接地与身份，`ℙ_3` 任务指称。证书必须沿 `ℙ → 𝔸 → 𝕃` 逐层传递，任一层断裂则整条链不可部署。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（观测与视觉接地）**
观测 `O = (I, P)`。检测器 `D` 输出实例集合 `I = {i = (b_i, c_i, s_i, t_i)}`，分别为框、类别、分数、轨迹号。技能指称集合 `R`，接地函数 `g : R → I ∪ {⊥}`。接地置信 `g_conf(r) = s_{g(r)} · calib(c_{g(r)}, s_{g(r)})`，`g(r)=⊥` 表示未接地。

**定义 122（感知条件化动作剖面）**
`α_S(a | g) = α_S(a) · μ_S(g)`，其中 `μ_S(g) ∈ [0,1]` 是接地门控。默认 `μ_S(g)=1` 当且仅当 `∀ r ∈ Pre(S): g(r) ≠ ⊥ ∧ g_conf(r) ≥ θ_g`；否则按未接地指称的比例衰减。

**定义 123（实例级检测证书）**
对指称对象 `o`（由持久 track `t` 承载）：
```
D_cert(o) = (recall_o, IoU_q, ECE_o, stab_o)
```
`recall_o` 为分层工况（遮挡/距离/光照/尺度/视角）下的检出率；`IoU_q` 为 IoU 的 q 分位；`ECE_o` 为置信校准误差；`stab_o` 为跨帧 ID 一致率与框抖动。通过条件：
```
recall_o ≥ θ_r ∧ IoU_q ≥ θ_iou ∧ ECE_o ≤ θ_ece ∧ stab_o ≥ θ_stab
```

**定义 124（感知前置与感知兼容）**
`Pre(S) = {(r, class_r, θ_g)}`。技能对感知兼容 `pcompat(S_i,S_j)=1` 当且仅当对所有共享指称 `r`：接地到同一 track、可见性重叠 `vis_overlap(r) ≥ θ_vis`、且 `D_cert(r)` 通过。组合可判定条件在第 54 轮定义 116 上追加 `pcompat(S_i,S_j)=1`。

**定义 125（接地图与指称一致性风险）**
接地图 `G_g = (T, E_g)`，`T` 为持久轨迹，`E_g ⊆ Skill × R × T` 为分配。指称一致性风险：
```
risk_id(S_i,S_j) = P(IDswitch within H) + P(occlusion > τ_occ)
```
风险超预算时，必须插入探测动作或拒绝组合。

**定义 126（云边感知对齐）**
感知映射 `γ_ce^perc : I_c → I_e`，感知对齐误差 `δ_p = 1 - |matched(R_critical)| / |R_critical|`，分歧集 `Dis = {o ∈ R_critical | D_cert_e(o) 不通过 ∧ D_cert_c(o) 通过}`。契约要求 `δ_p ≤ Θ_p` 且 `Dis` 经边端重查后为空。

**定义 127（感知-动作-鲁棒性联合证书）**
```
J⁺ = (ρ, A_cert, D_cert, γ_ce, γ_ce^perc, δ_a, δ_p, evidence)
```
部署条件：
```
dom_{J⁺}(T)=in ∧ δ_a<Θ_a ∧ δ_p<Θ_p
∧ ∀ o∈Pre(T), D_cert(o) 通过
∧ adversarial_tripwire = trust
∧ evidence 含感知反例与云边分歧记录
```

## 2. 关键算法 伪代码

### IP-121 PGC（Perceptual Grounding Certificate）

```python
def detection_certificate(detector, track, strata, q=0.05):
    recall = sum(s.w * detector.hit(track, s) for s in strata)
    iou_q  = quantile([detector.iou(track, s) for s in strata], q)
    ece    = expected_calibration_error(detector, track, strata)
    stab   = track.id_consistency(H) * (1 - track.occlusion_gap_ratio)
    return DCert(track, recall, iou_q, ece, stab,
                 ok=(recall >= theta_r and iou_q >= theta_iou
                     and ece <= theta_ece and stab >= theta_stab))
```

### IP-122 PCSC（Perception-Conditioned Skill Composition）

```python
def build_perception_graph(skills, det_certs, theta_a, theta_vis):
    G = nx.DiGraph()
    for i, s1 in skills:
        for j, s2 in skills:
            if i == j or not action_compat(s1, s2, theta_a):
                continue
            ok = True
            for r in s1.refs & s2.refs:
                if not same_track(r, s1, s2):            ok = False; break
                if visibility_overlap(r, s1, s2) < theta_vis: ok = False; break
                if not det_certs[r].ok:                  ok = False; break
            if ok:
                G.add_edge(i, j, pcompat=1,
                           D_cert={r: det_certs[r] for r in s1.refs | s2.refs})
    return G
```

### IP-123 PACE（Perception-Aware Cloud-Edge）

```python
def perception_align(I_c, I_e, critical_refs, theta_p):
    match  = hungarian_match(I_c, I_e, cost=iou_cost)
    delta_p = 1 - len(match) / len(critical_refs)
    Dis = [o for o in critical_refs
           if det_cert(I_c, o).ok and not det_cert(I_e, o).ok]
    if delta_p > theta_p:
        return ('reject', 'perception_misalign', delta_p, Dis)
    for o in Dis:
        if not edge_requery(o).ok:
            return ('reject', 'edge_blind', o)
    return ('ok', match, delta_p)
```

### IP-124 APX（Active Perception eXecution）

```python
def schedule_probes(P_c, det_certs, probes, budget, lambda_gain):
    plan = []
    for step in P_c:
        need = [r for r in step.refs if not det_certs[r].ok]
        if need:
            best = max(probes, key=lambda p: EIG(p, need) / p.cost)
            if EIG(best, need) / best.cost >= lambda_gain and budget.can(best):
                plan.append(best); budget.spend(best)
                det_certs = update_certs(det_certs, best)
                if any(not det_certs[r].ok for r in need):
                    return ('need_more_perception', plan)
        plan.append(step)
    return ('ok', plan)
```

### IP-125 GID（Grounding Identity Disambiguator）

```python
def disambiguate(refs, tracks, motion, appearance, tau_id):
    S = {(r, t): w_m * motion.loglik(r, t) + w_a * appearance.sim(r, t)
         for r in refs for t in tracks}
    assign = hungarian_max(S)
    ambiguous = [r for (r, t) in assign if S[(r, t)] < tau_id]
    if ambiguous:
        return ('ambiguous', ambiguous)
    return ('ok', assign)
```

### IP-126 DAT（Detection Adversarial Tripwire）

```python
def adversarial_tripwire(detector, frames, ref_certs):
    feat  = detector.penultimate(frames)
    ood   = mahalanobis(feat, detector.train_stats) > tau_ood
    patch = saliency_temporal_inconsistency(frames) > tau_patch
    drop  = ref_certs.ece - online_ece(frames) > tau_cal
    if ood or patch or drop:
        return ('quarantine', (ood, patch, drop))
    return ('trust', None)
```

### IP-127 PAC（Perception-Action Joint Certificate）

```python
def joint_certificate_plus(P, gamma_ce, gamma_ce_p, budgets):
    A_cert  = action_cert(P)
    D_cert  = {r: detection_certificate(P.detector, P.track[r], P.strata)
               for r in P.refs}
    delta_a = max_alignment_error(gamma_ce, A_cert.A_core)
    delta_p = perception_alignment_error(gamma_ce_p, P.refs)
    if delta_a > budgets.a: return ('reject', 'action_misalign', delta_a)
    if delta_p > budgets.p: return ('reject', 'perception_misalign', delta_p)
    if not all(c.ok for c in D_cert.values()):
        return ('reject', 'perception_unreliable', D_cert)
    if adversarial_tripwire(P.detector, P.frames, D_cert)[0] != 'trust':
        return ('reject', 'quarantine')
    return ('ok', JointCertPlus(D_cert, A_cert, gamma_ce, gamma_ce_p,
                                delta_a, delta_p))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PGC | O(|strata|·|T|) | O(|T|) | 分层采样覆盖长尾、校准无偏 |
| PCSC | O(|S|²·|R| + |S|²·|A|) | O(|S|²+|E|) | 指称一致性 sound、track 稳定 |
| PACE | O(|I|³ + |R_crit|) | O(|I|²) | 匹配唯一、重查闭环 |
| APX | O(|P|·|Probe|·log|need|) | O(|P|) | EIG 估计无偏、预算闭合 |
| GID | O(|R|·|T|)（匈牙利） | O(|R|·|T|) | 代价矩阵可辨识、歧义显式 |
| DAT | O(|frames|·d) | O(d) | 阈值由干净集标定 |
| PAC | O(|P|·|A| + |R|·|strata|) | O(|A|+|R|) | 各子证书独立可验 |

**正确性定理（Perception-Grounded Composition Soundness）**
在承接第 53/54 轮 (A22)–(A28) 的基础上追加：**(A29)** `D_cert` 在部署分布的分层采样上校准，`ECE ≤ θ_ece`；**(A30)** 指称身份在任务时域 `H` 内稳定（`risk_id ≤ θ_id`）；**(A31)** 感知对齐 `δ_p ≤ Θ_p` 且 `Dis=∅`；**(A32)** 对抗绊线在干净分布上误报率 `≤ β_A`。
则由联合事件的并集界：
```
P_success ≥ 1 - Σ_d (1-ρ_min(d)) - Σ_{o∈Pre(T)} (1-recall_o)
            - β_E - P(δ_a>Θ_a) - P(δ_p>Θ_p) - P(risk_id>θ_id) - β_A
```
关键：**感知证书是必要条件而非充分条件**；动作成功要求“感知接地正确 ∧ 动作可执行 ∧ 鲁棒性达标”三者同时成立。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 实例证书在长尾/新实例上失准 | 高 | 分层+主动采样、conformal 校准、置信下界 |
| 遮挡后 ID switch 导致静默指错 | 高 | 运动+外观+时序融合、歧义显式化、探测优先 |
| 云边检测器分布不一致 | 高 | 共享类别本体、边端重查、分歧否决 |
| 主动感知引入延迟与新失败 | 中 | 探测预算、失败回退、hysteresis |
| 检测对抗/分布外样本 | 高 | 对抗绊线、OOD 检测、隔离而非硬判 |
| 证书间相关性破坏并集界 | 中 | 经验联合标定、保守阈值、copula 敏感性分析 |

## 6. 本轮最大风险

**一句话**：把视觉感知与目标检测纳入证书体系，确实补上了 `ℙ → 𝔸 → 𝕃` 缺失的感知底座，但整个 `J⁺` 的 soundness **依赖实例级检测证书在部署分布上校准、指称身份在遮挡后仍稳定、且云边检测分布一致**；一旦证书在分层样本上“看起来校准”而部署时出现相关的分布外失败（对抗 patch、新实例、长时遮挡后 ID switch），`J⁺` 会一边宣称“已感知接地”一边让机器人操作错误对象——这是一种比可见动作失败更危险的静默感知-动作错配，故必须以 **conformal 校准 + 对抗绊线 + 指称漂移绊线** 三重护栏，证书不足时宁可探测或弃权，绝不把检测置信度当作真值。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（PGC×PCSC×PACE×APX×GID×DAT×PAC）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书」之下补上缺失的 **感知接地层 `ℙ`**，新增七个算子：
> - **PGC（Perceptual Grounding Certificate）**：实例级检测证书 `D_cert=(recall,IoU_q,ECE,stab)`，把“检测置信度”升级为“可验证的指称可靠性”；

> - **GID（Grounding Identity Disambiguator）**：运动+外观+时序的指称消歧，显式输出歧义；
> - **DAT（Detection Adversarial Tripwire）**：OOD/对抗 patch/校准骤降的绊线与隔离；

```python
def build_perception_graph(skills, det_certs, theta_a, theta_vis):
    G = nx.DiGraph()
    for i, s1 in skills:
        for j, s2 in skills:
            if i == j or not action_compat(s1, s2, theta_a):
                continue
            ok = True
            for r in s1.refs & s2.refs:
                if not same_track(r, s1, s2):                ok = False; break
                if visibility_overlap(r, s1, s2) < theta_vis: ok = False; break
                if not det_certs[r].ok:                      ok = False; break
            if ok:
                G.add_edge(i, j, pcompat=1,
                           D_cert={r: det_certs[r] for r in s1.refs | s2.refs})
    return G
```

### IP-123 PACE

```python
def perception_align(I_c, I_e, critical_refs, theta_p):
    match   = hungarian_match(I_c, I_e, cost=iou_cost)
    delta_p = 1 - len(match) / len(critical_refs)
    Dis = [o for o in critical_refs
           if det_cert(I_c, o).ok and not det_cert(I_e, o).ok]
    if delta_p > theta_p:
        return ('reject', 'perception_misalign', delta_p, Dis)
    for o in Dis:
        if not edge_requery(o).ok:
            return ('reject', 'edge_blind', o)
    return ('ok', match, delta_p)
```

### IP-124 APX

```python
def schedule_probes(P_c, det_certs, probes, budget, lambda_gain):
    plan = []
    for step in P_c:
        need = [r for r in step.refs if not det_certs[r].ok]
        if need:
            best = max(probes, key=lambda p: EIG(p, need) / p.cost)
            if EIG(best, need) / best.cost >= lambda_gain and budget.can(best):
                plan.append(best); budget.spend(best)
                det_certs = update_certs(det_certs, best)
                if any(not det_certs[r].ok for r in need):
                    return ('need_more_perception', plan)
        plan.append(step)
    return ('ok', plan)
```

### IP-125 GID

```python
def disambiguate(refs, tracks, motion, appearance, tau_id):
    S = {(r, t): w_m * motion.loglik(r, t) + w_a * appearance.sim(r, t)
         for r in refs for t in tracks}
    assign = hungarian_max(S)
    ambiguous = [r for (r, t) in assign if S[(r, t)] < tau_id]
    if ambiguous:
        return ('ambiguous', ambiguous)
    return ('ok', assign)
```

```python
def adversarial_tripwire(detector, frames, ref_certs):
    feat  = detector.penultimate(frames)
    ood   = mahalanobis(feat, detector.train_stats) > tau_ood
    patch = saliency_temporal_inconsistency(frames) > tau_patch
    drop  = ref_certs.ece - online_ece(frames) > tau_cal
```

```python
def joint_certificate_plus(P, gamma_ce, gamma_ce_p, budgets):
    A_cert  = action_cert(P)
    D_cert  = {r: detection_certificate(P.detector, P.track[r], P.strata)
               for r in P.refs}
    delta_a = max_alignment_error(gamma_ce, A_cert.A_core)
    delta_p = perception_alignment_error(gamma_ce_p, P.refs)
    if delta_a > budgets.a: return ('reject', 'action_misalign', delta_a)

    if adversarial_tripwire(P.detector, P.frames, D_cert)[0] != 'trust':
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PGC | O(|strata|·|T|) | O(|T|) | 分层采样覆盖长尾、校准无偏 |
| PCSC | O(|S|²·(|R|+|A|)) | O(|S|²+|E|) | `pcompat` sound、track 稳定 |
| PACE | O(|I|³+|R_crit|) | O(|I|²) | 匹配唯一、重查闭环 |
| APX | O(|P|·|Probe|·log|need|) | O(|P|) | EIG 无偏、预算闭合 |
| GID | O(|R|·|T|) | O(|R|·|T|) | 歧义显式、代价可辨识 |
| DAT | O(|frames|·d) | O(d) | 阈值由干净集标定 |
| PAC | O(|P|·|A|+|R|·|strata|) | O(|A|+|R|) | 子证书独立可验 |

**正确性定理（Perception-Grounded Composition Soundness）**
承接 (A22)–(A28)，追加：**(A29)** `D_cert` 在部署分布分层采样上校准 `ECE ≤ θ_ece`；**(A30)** 身份在任务时域 `H` 内稳定 `risk_id ≤ θ_id`；**(A31)** `δ_p ≤ Θ_p` 且 `Dis=∅`；**(A32)** 对抗绊线干净分布误报 `≤ β_A`。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - Σ_{o∈Pre(T)}(1-recall_o)
            - β_E - P(δ_a>Θ_a) - P(δ_p>Θ_p) - P(risk_id>θ_id) - β_A
```
关键在于：**感知证书是部署的必要条件，不是充分条件**；成功要求“接地正确 ∧ 动作可执行 ∧ 鲁棒达标”三者同时成立。

## 6. 本轮最大风险

**一句话**：把视觉感知与目标检测纳入证书体系，确实补上了 `ℙ → 𝔸 → 𝕃` 缺失的感知底座，但整个 `J⁺` 的 soundness **依赖实例级检测证书在部署分布上校准、指称身份在遮挡后仍稳定、且云边检测分布一致**；一旦证书在分层样本上“看起来校准”而部署时出现相关的分布外失败（对抗 patch、新实例、长时遮挡后 ID switch），`J⁺` 会一边宣称“已感知接地”一边让机器人操作错误对象——这是一种比可见动作失败更危险的静默感知-动作错配，故必须以 **conformal 校准 + 对抗绊线 + 指称漂移绊线** 三重护栏，证书不足时宁可探测或弃权，绝不把检测置信度当作真值。
