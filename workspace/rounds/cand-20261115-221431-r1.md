# 第 10 轮（本轮灵感：「基准测试」×「可用性评估」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**先注册、后测量；以人为证；双盲防污染**。两个灵感分别治理 v9 的两种债：**自证债**（E551–E570 全部是自设模拟器上的自证，缺隐藏集、缺多重比较校正、缺外部复现）与**人因债**（系统有语音、情感与 claims，却从未严格评估操作员可用性；操作员在环却不在模型里）。本轮把「评估层」与「执行层」显式解耦：评估组件失效只允许**撤回结论**、绝不允许改变机器人行为，严格退回 v9 的报告与交互方式（引理 92）。

## 0. 直觉与动机

**灵感 1（基准测试 → 把「评估」本身做成可退化契约）**
直觉：v9 的 MW 已经把运行时模块接线变成了契约表，但**评估**仍是手写脚本——指标自选、数据集自建、显著性随手报，而且我们既当运动员又当裁判。基准测试给的正解不是「再多跑几个实验」，而是让每条结论都成为带预注册、隐藏集、访问预算和适用范围声明的**证据契约**。核心创新：**基准契约引擎（Benchmark Contract Engine, BCE）**。每条 claim c=(θ, θ̂, C_{1−α}, S_scope, ρ) 必须同时满足四道闸——预注册哈希 ρ、统计功效 ≥1−β、多重比较校正、隐藏集访问预算未耗尽——才被授予最高证据级 E0；隐藏集不可用只能发 E2（仅开发集、范围收窄），**证据等级只降不升**。这与 v9 的中立元退化同构：退化的是「我们敢声称什么」，而不是「机器人做什么」。

**灵感 2（可用性评估 → 把操作员信任做成在线可校准状态）**
直觉：v9 会说话、会表达情感、会输出 claims，但没有任何一个量回答「人到底信不信、信得对不对」。严谨的可用性评估不是发问卷，而是把**信任校准**当状态估计：潜在信任 x_t、客观系统可靠度 r_t、校准误差 e_t=|x_t−r_t|；过信 x_t≫r_t 与欠信 x_t≪r_t 都要被检测并纠正。难点在于不能一直用探针打断任务，于是用行为通道（干预率、响应时延、覆盖接受率、重述率）做隐式估计，用稀疏校准探针（SAGAT/信任量表）做锚定。核心创新：**运行时可可用性证书（Operational Usability Certificate, OUC）**＋**解释预算（Explanation Budget）**：解释是有限的注意力资源，纳入 MW 契约表按 EDF 调度，只在对校准误差边际收益最大的区间花费。这把「可用性」从离线问卷变成与 50Hz 闭环同频的一等约束。

**灵感 3（两者耦合 → 防「测什么就优化什么」的古德哈特闸）**
直觉：基准分一旦进入优化回路就会被优化（Goodhart）；信任估计一旦反馈给自主策略就会被操纵。两个灵感单独用都会制造新的自证陷阱，必须成对使用。核心创新：**影子评测与分歧检测（Blind Shadow Evaluation, BSE）**：保留一个从不用于调参、只用于验收的隐藏任务族＋人因面板；用 CUSUM 序贯检测「基准改善而影子可用性恶化」的分歧；基准复用 k 次后冻结；再以**覆盖证书**要求任务族覆盖六层指标与五级运行时退化链，否则记为「覆盖缺口」而非「通过」。

## 1. 研究问题

- **Q1（评估有效性与抗污染）**：在「自设模拟器＋有限隐藏集访问」条件下，如何使每条 claim 的证据等级可审计、可复现，并对多重比较与自适应窥探稳健？证据等级退化是否与 v9 的中立元退化同构（即失效只降级、不漂移）？
- **Q2（信任校准的可辨识性）**：仅用行为通道＋稀疏探针，潜在信任 x_t 与客观可靠度 r_t 是否可辨识？当解释本身反馈进信任回路时，「测量信任」是否退化为「生产信任」？随机扣留解释能否恢复可辨识性？
- **Q3（双系统分歧）**：基准分与人因可用性何时会系统性背离？CUSUM 分歧检测的误报/漏报与基准冻结策略，能否在有限访问预算下给出可陈述的保证？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 证据等级退化律（Evidence-Level Degradation, BCE）**
每条评估结论携带证据等级 E0–E4；等级由证据集合的交（预注册 ∧ 隐藏集 ∧ 影子集 ∧ 覆盖）决定，移除任一证据只能降级、不能升级。隐藏集访问是有限预算，且每次访问必须携带预注册令牌；未注册访问一律拒绝。任何跨系统比较（「≥ v8 + 10%」）只在 E0 下允许，否则自动收窄为基准内或描述性结论。

**P14 信任校准证书律（Calibrated-Trust Certificate, OUC）**
自主等级与解释预算由校准误差 e_t 门控：过信 ⇒ 提高解释频次并降低自主；欠信 ⇒ 展示证据并保持/恢复自主但不滥用解释；e_t 在带内 ⇒ 冻结解释预算以节省注意力。为保可辨识性，必须保留比例 ρ_hold 的**随机扣留解释**交互（该次交互不解释），否则闭环不可辨识（引理 90）。解释预算与自主门控均受 MW 契约约束，且不得绕过 M₀ 硬检查与 AC 证书。

**P15 影子评测与冻结律（Blind Shadow & Freeze, BSE）**
影子集与人工面板永不被优化器读取；分歧统计量越阈 ⇒ 立即暂停对外 claim 并触发审计；隐藏集/影子集总访问次数受预算约束，耗尽后冻结（frozen）。任何「改进」必须在冻结解除后由新预注册复测；基准复用 k 次后的分数不得再作为 E0 证据。

## 3. 与基线的接口（如何退化）

- BCE 失效（无预注册 / 隐藏集为空 / 预算耗尽）⇒ 结论降为 E2 描述性统计，等价 v9 的实验报告方式（自设模拟器、无证据等级标签）；
- OUC/BTC 失效（行为通道不可用 / 探针不可达）⇒ 关闭信任闭环，解释预算置 0，交互退回 v9 的 ER/claims 默认策略；
- BSE 失效（影子集或人因面板不可用）⇒ 禁止跨系统比较与对外 claim，仅保留基准内 E1 结论，等价 v9；
- 覆盖证书失败 ⇒ 在报告中显式标注未覆盖的指标层/退化级，不得声称全任务族结论；
- **全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9 的评估与交互方式；运行时安全链不受任何影响（引理 92）。**

## 4. 预期贡献

1. **评估的证据契约与等级退化**：把「可复现」从口号变成带预注册哈希、访问预算、多重比较校正与范围声明的可审计结构，并证明其退化与 v9 中立元退化同构（引理 87–88）；
2. **运行时可可用性证书**：首次把信任校准作为与 50Hz 闭环同频的状态估计与门控；给出行为通道下的可辨识条件与有界误差（引理 89），并证明解释闭环会破坏可辨识性、必须靠随机扣留修复（引理 90）；
3. **古德哈特闸与影子评测**：用 CUSUM＋冻结＋覆盖证书约束「自证陷阱」，给出误报率与访问预算的可陈述界（引理 91）；
4. **评估-执行层解耦**：证明全部评估组件失效不改变任何执行动作，v9 的引理 82–86 原样成立（引理 92）——把「评估不可靠」的风险限制在认识论层，不外溢到安全层；
5. **实验 E571–E590**：从污染防火墙、外部复现、覆盖矩阵，到信任校准、观察者效应、人因量表与盲审复现，形成可被第三方重跑的评估套件。

## 5. 本轮最大风险

**一句话**：把可用性做成在线证书并闭环调控之后，「测量信任」会变成「生产信任」——解释预算可能被优化去操纵操作员的信任读数而非提升真实可靠性，使可用性证书在最需要独立性的地方与系统共谋（古德哈特定律的人因版本）。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-CUBE**（Certified Usability & Benchmark Evaluation）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「基准测试」×「可用性评估」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v9 的 AC/MW/ID 三模块原样继承并向评估层开放**只读**观测端口。新组件一律位于**评估层（evaluation plane）**，与执行层（execution plane）数据流隔离：评估组件失效只撤回结论，不改变任何执行动作（引理 92）。

**退化链声明（评估层证据级 E0–E4，与运行时五级链正交）：**
- **E0**：预注册 ∧ 隐藏集（预算内）∧ 影子集 ∧ 覆盖证书全部成立 ⇒ 允许跨系统比较与对外 claim；
- **E1**：缺影子集或缺覆盖证书 ⇒ 仅基准内结论，禁止跨系统比较；
- **E2**：缺隐藏集或访问预算耗尽 ⇒ 仅开发集描述性统计，无显著性结论；
- **E3**：缺预注册 ⇒ 仅探索性假设，不得作为结论；
- **E4**：评估层整体失效 ⇒ 退回 v9 手写实验报告方式（无证据等级标签）。
> 注：运行时五级退化（AC→MW→ID→DA/SPR/Cal→v7→v6）**完全不变**；评估层的 E 级与运行时 Level 级互不替代。

## 1. 符号体系增量（定义 540–548）

| 符号 | 含义 |
|---|---|
| β = (T, M, Π, S, ρ) | 基准契约单元：任务族、指标映射、协议、数据划分、预注册哈希 |
| S = (S_dev, S_hidden, S_shadow) | 开发集 / 密封隐藏集 / 影子验收集 |
| c = (θ, θ̂, C_{1−α}, S_scope, ρ) | 一条评估 claim：估计量、估计器、置信集、适用范围、预注册哈希 |
| L(c) ∈ {E0,…,E4} | 证据等级（格序 E0 ≻ E1 ≻ E2 ≻ E3 ≻ E4） |
| B_h, b_t | 隐藏集访问预算与已用计数 |

| B_exp, c_e, Δe | 单位时间解释预算、单条解释成本、解释带来的校准误差下降 |
| ρ_hold | 随机扣留解释比例（可辨识性的工具变量） |
| D_t, C_t | 基准-影子分歧量与 CUSUM 统计量 |
| cov(i, ℓ) | 指标层 i ∈ {M₀…M_SLAM} 在运行时退化级 ℓ 上的任务计数 |

**新增定义 540（基准契约单元 BenchmarkUnit）** 一次评估的最小可复现单元 β=(T,M,Π,S,ρ)：T 为任务族采样分布；M 为指标映射（六层指标 + 可用性指标）；Π 为协议（配对随机种子、每任务 N 回合、固定停止规则、预设分析计划）；S 为三分数据划分；ρ=H(fields) 为预注册内容的密码学哈希，写入后不可变。

**新增定义 541（证据等级 EvidenceLevel）** 设 claim c 的证据集合 Ev(c)⊆{P,H,S,C}（预注册、隐藏集、影子集、覆盖证书）。等级由下表确定，且满足单调性 Ev(c′)⊆Ev(c) ⇒ L(c′)⪯L(c)：

| Ev(c) 含 | L(c) | 允许的结论 |
|---|---|---|
| P,H,S,C | E0 | 跨系统比较、对外 claim |
| P,H（S 或 C 缺） | E1 | 基准内结论，禁止跨系统比较 |
| P（H 缺或预算耗尽） | E2 | 开发集描述统计，无显著性 claim |
| 无 P | E3 | 探索性假设 |
| 评估层失效 | E4 | 退回 v9 报告（无等级） |

**新增定义 542（访问预算与污染防火墙 AccessBudget）** 隐藏集访问计数器 b_t；每次访问必须携带有效预注册令牌，否则抛 `UnregisteredAccess`；b_t ≤ B_h，耗尽后隐藏集**冻结**。访问日志 append-only 并逐条哈希，形成可审计链。禁止在观察到隐藏集结果后新增假设（阻断 optional stopping 与 p-hacking）。

**新增定义 543（信任校准状态 TrustCalibration）** 潜在信任 x_t∈[0,1]，客观可靠度 r_t 为最近窗口内系统实际成功率的滑动估计，校准误差 e_t=|x_t−r_t|。定义过信带 x_t−r_t>ε_o、欠信带 r_t−x_t>ε_u、校准带 e_t≤min(ε_o,ε_u)。注意：r_t 由系统自身日志估计，不由操作员自评给出。

**新增定义 544（行为信任观测 BehavioralTrustObservation）** y_t=(ν_int, τ_resp, α_over, ρ_rep) ∈ ℝ⁴，观测模型 y_t = h(x_t, d_t) + w_t，其中 d_t 为任务难度协变量，h 对 x_t 逐通道单调（信任越高，干预越少、响应越快、覆盖接受率越高、重述越少），w_t 为零均值有界噪声。

**新增定义 545（校准探针 CalibrationProbe）** 稀疏探针 π_t ∈ {SAGAT 情境意识查询, Jian 信任量表条目, 强制依赖选择}，读数 z_t = x_t + ν_t，E[ν_t]=0、|ν_t|≤ν_max；探针频率 λ_p ≤ λ_max，保证打断成本有界。

**新增定义 546（解释预算 ExplanationBudget）** 每分钟预算 B_exp；解释条目 e 有成本 c_e（时间＋注意力）与收益 Δe(e)（对 e_t 的期望下降）。分配问题为 max Σ_e Δe(e)·u_e s.t. Σ_e c_e·u_e ≤ B_exp，u_e∈{0,1}；由 MW 契约表按 EDF 调度，且每次交互以概率 ρ_hold 强制不解释（工具变量）。

**新增定义 547（影子评测与分歧 BlindShadow）** 影子集 S_shadow 与人工面板对优化器不可见（访问需独立审计密钥）。分歧 D_t=|z(score_bench)−z(score_usab)|（z 为预注册标准化），CUSUM：C_t=max(0, C_{t−1}+D_t−k)；C_t>h 触发告警、暂停对外 claim 并冻结基准。

**新增定义 548（覆盖证书 CoverageCertificate）** 覆盖矩阵 cov(i,ℓ) 统计指标层 i（六层）在运行时退化级 ℓ（Level-1..5）上的合格任务数；覆盖完整 ⇔ 每格 ≥ m_min 且每层总任务 ≥ m_layer。缺口集合 G={ (i,ℓ) | cov(i,ℓ)<m_min } 必须在报告中显式列出。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 521（DA-OTL）** 继承 v9 不变。
**升级定义 496（软证书，v10）** 运行时 δ_trigger 五条件**不变**；评估层仅在日志上追加 `{claim_id, L(c), Ev(c)}` 注释，注释不回写控制路径。
**升级定义 531（软硬约束衔接）** 运行时判据不变；新增规定：任何对外 claim 必须引用其证据等级 L(c)，且 L(c)=E0 才可写「优于」类比较句。
**新增定义 549（评估层只读不变式 ReadOnly Evaluation）** 评估层的输入仅为执行层日志、传感器回放与人工面板记录；输出仅为报告与 claim，不存在指向 `execute()`、`M0_check()`、`SpatialCert`、`AC.midchunk_guard()` 的写通道。该不变式由静态数据流分析＋运行时审计双重检查（E576）。

## 3. 关键算法骨架

```python
    scope: str                # 预注册的范围声明
    prereg_hash: str
    evidence: frozenset       # {'P','H','S','C'} 的子集

def evidence_level(ev: frozenset) -> str:
    if {"P", "H", "S", "C"} <= ev:
        return "E0"
    if "P" in ev and "H" in ev:
        return "E1"
    if "P" in ev:
        return "E2"
    return "E3" if ev else "E4"

class BenchmarkContractEngine:
    def __init__(self, registry, hidden, budget_h, alpha=0.05, family_m=None):
        self.registry = registry          # 预注册哈希表（只读）
        self.hidden = hidden              # 密封隐藏集
        self.B_h, self.b_used = budget_h, 0
        self.alpha, self.family_m = alpha, family_m
        self.audit = []                   # append-only, 逐条哈希

    def access_hidden(self, token, purpose):
        if not self.registry.valid(token):          # 无预注册令牌
            raise UnregisteredAccess(token)
        if self.b_used >= self.B_h:                 # 预算耗尽 → 冻结
            raise BudgetExhausted(self.B_h)
        self.b_used += 1
        self.audit.append(hash((token, purpose, self.b_used, time())))
        return self.hidden.evaluate(purpose)

    def report(self, claims, pvalues):
        # Holm–Bonferroni：固定族、任意相关下控制 FWER
        reject = holm_bonferroni(pvalues, self.alpha)   # bool 数组
        out = []
        for c, p, r in zip(claims, pvalues, reject):
            ev = set(c.evidence)
            if c.prereg_hash not in self.registry:      # 无预注册
                ev.discard("P")
            lvl = evidence_level(frozenset(ev))
            c = replace(c, evidence=frozenset(ev), scope=shrink(c.scope, lvl))
            out.append(ReportItem(c, p, sig=(r and lvl in ("E0", "E1")), level=lvl))
        return out
```

```python
# IP-358 OperationalUsabilityCertifier：信任校准 + 解释预算
class BehavioralTrustCalibrator:
    """x_t 的线性高斯滤波；行为通道连续更新，探针稀疏锚定。"""
    def __init__(self, A, C, Q, R, x0=0.5):
        self.A, self.C, self.Q, self.R = A, C, Q, R
        self.x, self.P = x0, 1.0

    def predict(self):
        self.x = self.A * self.x
        self.P = self.A * self.P * self.A + self.Q

    def update(self, y, R=None):
        R = self.R if R is None else R
        K = self.P * self.C / (self.C * self.P * self.C + R)
        self.x += K * (y - self.C * self.x)
        self.P = (1 - K * self.C) * self.P

class ExplanationBudget:
    def __init__(self, B_exp, items):
        self.B_exp, self.items = B_exp, items   # items: (cost, dE)

    def allocate(self, budget):
        # 校准误差越大解释收益越可能为正；按收益/成本贪心
        ranked = sorted(self.items, key=lambda it: it.dE / it.cost, reverse=True)
        picked, spent = [], 0.0
        for it in ranked:
            if it.dE > 0 and spent + it.cost <= budget:
                picked.append(it); spent += it.cost
        return picked

class OperationalUsabilityCertifier:
    def __init__(self, btc, explainer, eps_o=0.15, eps_u=0.15,
                 rho_hold=0.1, rng=None):
        self.btc, self.explainer = btc, explainer
        self.eps_o, self.eps_u, self.rho_hold = eps_o, eps_u, rho_hold
        self.rng = rng or random.Random(0)
        self.autonomy = 1.0

    def step(self, y, r_t, probe_due, probe_fn):
        self.btc.predict()
        self.btc.update(y)                      # 行为通道
        if probe_due and self.rng.random() >= self.rho_hold:
            z, var = probe_fn()                 # 随机扣留：ρ_hold 比例不探针
            self.btc.update(z, var)
        x = self.btc.x
        e = abs(x - r_t)
        if e <= min(self.eps_o, self.eps_u):
            state, budget = "calibrated", 0.0   # 带内冻结解释
        elif x > r_t:
            state = "overtrust"
            self.autonomy = clamp(self.autonomy - k_o * (e - self.eps_o), 0, 1)
            budget = self.explainer.B_exp * min(1.0, e / self.eps_o)
        else:
            state = "undertrust"
            budget = 0.0
            self.explainer.show_evidence()      # 欠信靠证据而非更多解释
        plan = self.explainer.allocate(budget)
        return UsabilityCert(state, e, self.autonomy, plan)
```

```python
# IP-359 BlindShadowEvaluator：影子评测与古德哈特闸
class BlindShadowEvaluator:
    def __init__(self, shadow_key, k=0.5, h=5.0, max_reuse=3):
        self.shadow_key, self.k, self.h = shadow_key, k, h
        self.C, self.reuse = 0.0, 0
        self.frozen = False

    def observe(self, bench_score, shadow_usability):
        if self.frozen:
            return "frozen"
        self.reuse += 1
        d = abs(zscore(bench_score) - zscore(shadow_usability))
        self.C = max(0.0, self.C + d - self.k)          # CUSUM
        if self.C > self.h:
            self.freeze()                                # 暂停 claim + 冻结
            return "divergence"
        if self.reuse >= self.max_reuse:
            self.freeze()
        return "ok"

    def freeze(self):
        self.frozen = True
        claim_gate.suspend_external()                    # 只撤回结论
```

## 4. 推导

**引理 87（证据等级单调性与退化同构）** 若 Ev(c′)⊆Ev(c)，则 L(c′)⪯L(c)。设 v9 的评估组件集合为 ∅（v9 无证据等级），则评估层全失效时 BCE 输出的报告字段与 v9 报告逐项一致（仅缺 L 标签）。证明：由定义 541 的等级表直接验证单调性；E4 分支显式调用 `v9_report` 并只删除等级字段，故逐项一致。∎

**引理 88（访问预算与多重比较下的 FWER 控制）** 设分析计划在任何隐藏集访问前固定，假设族大小 m 固定，隐藏集访问次数 ≤ B_h，显著性经 Holm–Bonferroni 校正。则族错误率 P(任一错误拒绝) ≤ α。且由于每次隐藏集访问必须携带预注册令牌，观察到数据后新增假设的通道被阻断，optional stopping 不可用。证明：Holm–Bonferroni 对任意相关结构控制 FWER ≤ α；访问令牌机制把可用假设族限制为预注册族，故有效族大小不超过 m。∎

**引理 89（信任估计的有界误差，条件性）** 假设 (i) 一致可观测性（探针频率 λ_p≥λ_min 且各行为通道充分激励），(ii) 探针噪声 |ν|≤ν_max、行为噪声 ‖w‖≤w_max，(iii) 观测映射 h 逐通道单调且 L_h-Lipschitz。则滤波估计 x̂_t 的误差满足 sup_t E|x̂_t−x_t| ≤ κ(ν_max + w_max + L_h·δ_d)，其中 δ_d 为难度协变量失配，κ 只依赖 (A,C,Q,R)。证明要点：一致可观测性给出预测误差协方差的一致上界，增益有界；有界噪声经线性滤波传播为有界误差；h 的单调性保证 e_t 的符号可辨。∎（这是条件性命题，E577 将以探针真值检验其常数。）

**引理 90（解释闭环的可辨识性极限与随机扣留修复）** 若每次交互都依据 x̂_t 决定是否解释（解释输入 u_t 是 x̂_t 的确定性函数），则自然信任 x_t^nat 不可从 (y_t, z_t) 辨识：存在两条不同自然信任轨迹产生完全相同的观测。若以概率 ρ_hold>0 强制不解释，使 u_t 具有外生变异，则在一致可观测性下 x_t^nat 可辨识。证明：无扣留时 u_t 由 x̂_t 决定，观测方程闭环，x^nat 与解释效应不可分离（混淆）；扣留集合 W 中 u_t=0 与 x_t 独立，构成工具变量，打破混淆；再由引理 89 的一致可观测性得到可辨识。∎

**引理 91（CUSUM 分歧检测与冻结界）** 设冻结前分歧序列独立同分布，均值 μ₀，方差 σ²；漂移参数 k>0。则 ARL0(h) 随 h 单调增，长度 T 内期望误报数 ≤ T/ARL0(h)；一旦 C_t>h 触发冻结，隐藏集与影子集总访问次数被硬上限 B_h+B_s 截断，与告警次数无关。证明：CUSUM 的 ARL0 单调性为标准结论；冻结把访问计数器置于不可逆状态，故总访问量受预算约束。∎

**引理 92（评估层与执行层解耦）** 评估组件对执行层无写通道（定义 549）。因此任意评估失效组合下，执行层动作序列与 v9 逐周期相同，v9 引理 82–86 原样成立。证明：由数据流隔离，`metricvoicegauge_round_10` 的执行返回值与直接调用 v9 逐位相同；解释预算只改变人机交互文本，其诱发的操作员指令仍需通过 v9 的 M₀/SpatialCert/AC 全部安全门，故不扩张可达安全集。∎
