> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v24（承 v23 的 CESC/FSVC/IPAM/HPC-E+/CFC+++，v22 的 PGEV/ACSC/DCSC，v21 的 SDC/CAC/DCL/GIC，v20 的 PCA/CTS/CFC/HPC，v19/v17 全部保留）。
> 本轮纪律：**仿真只许证伪、不许授权；接触只许在无源能量界内兑现**。不推倒 v23。本轮只做一件事：在 v23 的"语义-规范-能量-云边"证书体系上，加一层**"仿真证据 + 接触语义"层**，把"永不接触的几何安全"升级为"可认证的接触安全"，并用对抗场景挖掘封堵 v21 的缺席幻觉与 v23 的共振崩塌。

## 0. 直觉与动机

**灵感 1（仿真训练 → 稀有事件的证据放大器，但必须先证明它没在说谎）**
直觉：v23 的所有证书都是在有限真实数据上校准的；而最致命的事件——儿童/轮椅/蹲姿漏检、接触瞬态伤害——恰恰是样本最少、最需要统计保证的事件。仿真能廉价地放大稀有事件：它有成对真值标签、可注入对抗场景、可枚举接触动力学。但仿真会撒谎：在仿真里成立的证书，只有先界住 sim-to-real 差距、并且**永远不让仿真数据污染现实锚**，才能迁移到真实。核心创新：**场景证伪引擎 (Scenario Falsification Engine, SFE) + 仿真到真实迁移证书 (Sim2Real Transfer Certificate, SRTC) + 不可变现实锚集 (Reality Anchor Set, RAS)**。关键反直觉点：仿真的作用不是"把模型训得更好"，而是**"证伪证书 + 提供分布无关界所需的样本量"**；它必须与一个不可被优化器"作弊"的现实锚配对，否则只是自洽的虚构。SFE 用场景优化给出概率鲁棒界；SRTC 用加权 conformal + 概念漂移裕度把仿真覆盖换算成真实覆盖下界；RAS 是只读、签名、永不参与训练的真实校准快照。

**灵感 2（柔顺控制 → 把"避碰"这一单一安全语义，换成"能量受限接触"这一更强语义）**
直觉：v20–v23 的安全语义是"永不接触"——距离 ≥ 0。但交接、助老、擦拭、开门本质上需要有意接触；刚性位置控制加安全裕度做不了。柔顺控制（阻抗/导纳）把位置刚性换成力/能量调节，于是安全语义从"距离 ≥ 0"变成"接触力 ∈ [F_min,F_max] ∧ 注入人体能量 ≤ E_safe ∧ 闭环无源稳定"。核心创新：**认证柔顺策略 (Certified Compliant Policy, CCP) + 能量罐调速器 (Energy Tank Governor, ETG) + 阻抗包络证书 (Impedance Envelope Certificate, IEC) + 接触契约证书 (Contact Contract Certificate, CCC) + 接触反射回撤 (Contact Reflex & Retraction, CRR)**。关键反直觉点：**无源性/能量罐给出的是一个可组合的证书——无论阻抗如何切换，注入人体的能量都被罐容 + 吸收能量上界住，因此可以在不建模"人"的前提下认证接触**。而且接触不是对几何安全的削弱，而是**模式切换**：接触被禁用时，执行集精确回落到 v23。

**两者如何统一**
统一为 **v23 之上的"仿真证据 + 接触语义"层**：SFE/SRTC/RAS 回答"凭什么相信仿真里的证据"，CCP/ETG/IEC/CCC/CRR 回答"凭什么允许接触、接触时凭什么说安全"。共享状态 `ζ_v24 = ζ_v23 ∪ (D_real, gap_bound, θ_scen, T_tank, C_contact, mode)`。统一准入门 **HPC-C = HPC-E+ ∧ SRTC ∧ CCC ∧ IEC**，且**模式条件化**：避碰模式下 SRTC 只影响接触解锁、不影响几何准入；接触模式下缺任一证书即退回避碰。理论上最要紧的一步：**全局 `Exec_v24 ⊆ Exec_v23` 必须被诚实地放宽为"模式条件继承"**——因为接触是有意离开避碰集，声称全局子集就是在撒谎。正确表述是：在非接触计划子空间上 `Exec_v24|_{Π_0} = Exec_v23|_{Π_0}`，在接触子空间上由独立的无源证书认证，且两个子空间的认证风险上界都不超过 δ。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P47）

**P43 仿真证伪律（Simulation-as-Falsifier）**
仿真只能收紧执行集，不能直接授权。任何仿真派生证书必须 (i) 通过 RAS 上的现实校验，(ii) 报告 `n_eff` 与 `Δ_gap`；仿真数据永不写入 RAS。故 `Exec_sim ⊆ Exec_v23`，且仿真证据只能"否决"、不能"放行"。

**P44 现实锚定律（Reality Anchor）**
所有统计保证都以只读、签名、版本化的 `D_real` 为条件。锚过期/被污染/样本不足 → SRTC 失效 → 接触禁用并退回 v23。禁止用仿真数据"补"锚的样本量。

**P45 场景概率鲁棒律（Scenario Probabilistic Robustness）**
对不确定动力学 `θ ~ P_θ`，`N` 个**独立**场景全部满足约束 ⇒ 以置信 `1-β` 有 `P_θ(违反) ≤ ε`，前提 `N` 满足场景界且独立同分布成立；`P_θ` 由 RAS 锚定。种子相关/非独立即界失效。

**P46 无源接触律（Passive Contact）**
一切接触动作必须从能量罐 `T(t) ≥ 0` 支取：`∫P_inj dt ≤ T(0) + ∫P_abs dt`；罐只能由耗散运动或认证外部做功充电。接触期间 `K ∈ [K_min,K_max]`、`D ≥ D_min`、`F ∈ [F_min,F_max]`。能量罐与 PGEV 统一记账，`E_contact` 优先于任何非安全运动预算。

**P47 模式条件继承律（Mode-Conditional Inheritance）**
计划空间划分为非接触 `Π_0` 与接触 `Π_c`。`Exec_v24|_{Π_0} = Exec_v23|_{Π_0}`；`Exec_v24|_{Π_c} = {π : CCC ∧ IEC ∧ SRTC ∧ CRR_armed}`；两子空间风险上界均 ≤ δ。禁用接触精确恢复 v23。模式切换带滞回，禁止颤振。

## 3. 与基线的接口（如何退化）

- SRTC 失效（锚过期 / `Δ_gap` 超限 / `n_eff` 不足）⇒ 仿真证据全部作废、接触禁用 ⇒ 精确 v23；
- SFE 失效 ⇒ 无对抗挖掘，证书退回 v23 校准 ⇒ 子集；
- ETG 失效（罐空 / 力传感器故障）⇒ 接触终止 + 反射回撤 ⇒ 避碰模式 ⊆ v23；
- CCC 失效 ⇒ 避碰模式；
- IEC 失效（力/阻抗越界或标定漂移）⇒ 接触禁用；
- CRR 未武装（反射超时/驱动异常）⇒ 禁止接触；
- 全失效 ⇒ v23。
- **安全继承（诚实版）**：不是全局 `Exec_v24 ⊆ Exec_v23`，而是**模式条件继承**——非接触子空间精确不变，接触子空间由独立无源证书认证且风险上界不增；任意失效都把接触子空间收缩为空，精确回退 v23。这比一句"子集"更弱、但更真：**我们放弃了一个漂亮的全局包含关系，换来了一个不撒谎的接触安全证明。**

## 4. 预期贡献

1. **仿真作为证伪器而非授权器**：给出"仿真只收紧、现实锚只读"的证据纪律，把仿真从"训练数据源"提升为"分布无关证书的样本量来源 + 对抗场景挖掘器"；
2. **迁移证书**：加权 conformal + 概念漂移裕度 + 有效样本量，把仿真覆盖换算成带显式 gap 的真实覆盖下界，并给出锚过拟合的检测条件；
3. **无源接触证书**：能量罐把"注入人体能量"变成可组合、可审计、与 PGEV 统一记账的界，首次在不建模人的前提下认证接触；
4. **接触契约**：在场/意图/传感器/能量/包络/反射六元合取，缺一即反射回撤，使接触成为"可撤销的临时授权"而非永久权限；
5. **模式条件安全继承的形式化**：诚实地把全局单调链放宽为按模式分区的继承 + 风险不增，禁用接触精确恢复 v23，避免"边接触边声称子集"的逻辑谎言；
6. **封堵仿真相关共振**：场景独立性去重 + 模式一致性共识，使"同一仿真故障的一致票"在结构上不构成共识。

## 5. 本轮最大风险

**一句话**：本轮最大风险是"仿真可信"与"准静态力限"两条外推链在真实接触瞬态上同时失效——能量有界、力限合规、统计覆盖达标的证书，仍可能无法证明人未受瞬态伤害。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Scenario Falsification Engine (SFE) — 对抗场景证伪
# ============================================================
@dataclass
class ScenarioCertificate:
    N: int
    eps: float
    beta: float
    d: int
    violations: int
    independent_seeds: bool
    convex: bool

class ScenarioFalsificationEngine:
    def __init__(self, eps=1e-3, beta=1e-6, d_theta=8,
                 convex=True, seed_pool=None):
        self.eps = eps
        self.beta = beta
        self.d = d_theta
        self.convex = convex
        self.seed_pool = seed_pool      # 独立种子池，禁止复用
        self.seen_seeds: set[int] = set()

    def required_N(self) -> int:
        """凸场景界；非凸黑箱用 VC 型界。种子必须独立。"""
        if self.convex:
            return math.ceil((2.0 / self.eps) *
                             (math.log(1.0 / self.beta) + self.d))
        # VC 型充分条件（保守）
        N = 1
        while N < (1.0 / self.eps) * (math.log(1.0 / self.beta)
                                      + self.d * math.log(2.0 * math.e * N / self.d)):
            N *= 2
        return N

    def certify(self, constraint_fn, theta_sampler) -> ScenarioCertificate:
        N = self.required_N()
        seeds = self.seed_pool.sample_independent(N, exclude=self.seen_seeds)
        self.seen_seeds.update(seeds)
        thetas = [theta_sampler(s) for s in seeds]
        violations = sum(0 if constraint_fn(th) else 1 for th in thetas)
        indep = len(set(seeds)) == N
        return ScenarioCertificate(N, self.eps, self.beta, self.d,
                                   violations, indep, self.convex)

    def admissible(self, cert: ScenarioCertificate) -> bool:
        """零违反 + 独立种子才可引用概率界；否则只收紧，不放行。"""
        return cert.independent_seeds and cert.violations == 0


# ============================================================
# IP-441 Sim2Real Transfer Certificate (SRTC) — 仿真到真实迁移
# ============================================================
class Sim2RealTransferCertificate:
    def __init__(self, alpha=0.01, delta=1e-3, W_max=20.0,
                 n_min=200.0, gap_max=0.02):
        self.alpha = alpha
        self.delta = delta
        self.W_max = W_max
        self.n_min = n_min
        self.gap_max = gap_max
        self.w = None
        self.n_eff = 0.0
        self.q_hat = None
        self.gap = 1.0

    def fit(self, sim_scores, real_scores, raw_weights):
        w = np.clip(np.asarray(raw_weights, float), 0.0, self.W_max)
        if w.sum() <= 0:
            return False
        self.w = w
        self.n_eff = (w.sum() ** 2) / (np.square(w).sum() + 1e-12)
        self.q_hat = weighted_quantile(sim_scores, w, 1.0 - self.alpha)
        self.gap = estimate_conditional_discrepancy(sim_scores, real_scores)
        return True

    def verify(self, anchor_fresh: bool, anchor_untampered: bool,
               real_scores) -> bool:
        # P44：锚失效 → 仿真证据全部作废
        if not (anchor_fresh and anchor_untampered):
            return False
        if self.q_hat is None:
            return False
        if self.n_eff < self.n_min:
            return False
        if self.gap > self.gap_max:
            return False
        # 真实覆盖须扣除概念漂移与 Hoeffding 波动
        n = len(real_scores)
        if n < 30:
            return False
        emp_cov = float(np.mean(np.asarray(real_scores) <= self.q_hat))
        hoeff = math.sqrt(math.log(1.0 / self.delta) / (2.0 * n))
        return emp_cov - hoeff >= 1.0 - self.alpha - self.gap

    def effective_alpha(self) -> float:
        return self.alpha + self.gap

# IP-442 Reality Anchor Set (RAS) — 只读现实锚
# ============================================================
class RealityAnchorSet:
    def __init__(self, path: Path, pk_cloud: PublicKey):
        self.path = path
        self.pk_cloud = pk_cloud
        self.snapshot = None
        self.version = -1

    def load(self) -> bool:
        raw = self.path.read_bytes()
        meta, payload = split_signed_blob(raw)
        if not verify_signature(self.pk_cloud, sha256(payload), meta.sig):
            return False
        self.snapshot = decode(payload)
        self.version = meta.version
        return True

    def is_fresh(self, now: float, ttl: float) -> bool:
        return self.snapshot is not None and (now - self.snapshot.ts) <= ttl

    def is_untampered(self) -> bool:
        return self.snapshot is not None and self.snapshot.hash == \
               sha256(self.snapshot.payload)

    def write_guard(self, incoming):
        """仿真/训练数据写入一律拒绝：RAS 只由带外签名流程更新。"""
        raise PermissionError("RAS is read-only inside the control loop")

# IP-444 Energy Tank Governor (ETG) — 无源能量罐
# ============================================================
class EnergyTankGovernor:
    def __init__(self, E_cap: float, E_min: float, dt: float):
        self.E_cap = E_cap
        self.E_min = E_min
        self.T = E_cap
        self.dt = dt

    def step(self, p_human_to_robot: float, p_cmd_to_human: float) -> float:
        """p_human_to_robot>0 表示人向机器人做功（可充电）；
        p_cmd_to_human>0 表示机器人拟向人注入。返回实际注入功率。"""
        # 仅吸收功率可充电，且不超过容量
        self.T += max(p_human_to_robot, 0.0) * self.dt
        self.T = min(self.T, self.E_cap)
        # 注入功率受当前罐存量硬约束
        p_inj = min(max(p_cmd_to_human, 0.0), self.T / self.dt)
        self.T -= p_inj * self.dt
        self.T = max(self.T, 0.0)
        return p_inj

    def can_contact(self) -> bool:
        return self.T >= self.E_min

    def charge_from_dissipation(self, p_diss: float):
        """耗散运动可回收充电（保守折算系数 eta<=1）。"""
        self.T = min(self.E_cap, self.T + max(p_diss, 0.0) * self.dt)

            return False

        return True

            return False

            return False
        if not s.crr_armed:
            return False

# IP-449 Mode-Conditional Consensus (MCC) — 模式一致性 + 场景去重
# ============================================================
class ModeConditionalConsensus(CertificateFederatedConsensusPlusPlusHierarchical):
    def consensus_round(self, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            # (a) 模式一致性：避碰票与接触票不得混算
            modes = {v.mode for v in votes.values()}
            if len(modes) > 1:
                results[key] = "CI"          # 模式冲突即保守
                continue
            # (b) 场景独立性去重：同一随机种子的多票只算一张
            independent = dedup_by_scenario_seed(votes)
            count_ok = len(independent) >= self.N - self.F
            modalities = {v.modality for v in independent.values()}
            modality_ok = len(modalities) >= self.M_MIN_MODALITIES
            layer_ok = self._check_layer_consistency(independent)
            ce_ok = len({v.ce_version for v in independent.values()}) == 1
            fs_ok = all(v.few_shot_valid for v in independent.values())
            ip_ok = all(v.ip_attested for v in independent.values())
            if all([count_ok, modality_ok, layer_ok, ce_ok, fs_ok, ip_ok]):
                results[key] = self._majority_with_outlier_filter(independent)
            else:
                results[key] = "CI"
        return results
```

## 3. 正确性论证

### 引理 1（场景概率鲁棒界）
**陈述**：设 `θ_1..θ_N` 为 `P_θ` 的独立同分布样本，约束函数 `g(θ) ≤ 0`。若 `N ≥ (2/ε)(ln(1/β)+d_θ)`（凸、非退化场景）且全部场景满足，则以概率 ≥ 1-β 有 `P_θ(g(θ)>0) ≤ ε`。非凸黑箱改用 VC 型界 `N ≥ (1/ε)(ln(1/β)+d_θ ln(2eN/d_θ))`。

**证明要点**：标准场景优化定理（Campi & Garatti）。凸性与非退化保证支撑集上界；独立性是概率测度可乘的前提。若场景共享随机种子（同一仿真故障被复制 N 份），独立性破坏，界不成立——故 SFE 强制 `independent_seeds` 检查，且 `admissible` 在种子重复时拒绝引用概率界，只允许"收紧"。
∎

### 引理 2（能量罐的无源注入界）
**陈述**：对任意功率序列，ETG 满足 `T(t) ≥ 0`，且累计注入能量 `∫_0^t P_inj dτ ≤ E_cap + ∫_0^t max(P_abs,0) dτ`。

**证明**：对离散递推归纳。每步先 `T ← min(E_cap, T + max(P_abs,0)dt)`，再取 `P_inj ≤ T/dt`，故更新后 `T ≥ 0`。将每步注入求和：`Σ P_inj dt ≤ E_cap - T(t) + Σ max(P_abs,0)dt ≤ E_cap + Σ max(P_abs,0)dt`。罐只能由吸收/耗散充电（`charge_from_dissipation` 的 `eta ≤ 1`），不存在凭空注入能量的路径。
∎

### 引理 3（SRTC 的真实覆盖下界）
**陈述**：若 `SRTC.verify = True`，则对真实分布上的新样本，`P_real(err ≤ q̂^w_α) ≥ 1 - α - Δ_gap - δ_hoeffding`，其中 `δ_hoeffding = sqrt(ln(1/δ)/(2n))`。

**证明**：
1. 协变量漂移下，加权 conformal（权重 `w=dP_real/dP_sim`）给出 `P_real` 覆盖 ≥ 1-α（Tibshirani et al. 2019），前提是条件分布不变；
2. 概念漂移使该下界再损失至多 `Δ_gap`（条件 TV 差异），故 `1-α-Δ_gap`；
3. 现实锚上的经验覆盖存在有限样本波动，Hoeffding 扣除 `δ_hoeffding`；
4. `verify` 要求 `emp_cov - δ_hoeffding ≥ 1-α-Δ_gap`，且 `n_eff ≥ n_min`、`Δ_gap ≤ Δ_max`、锚新鲜且未篡改。故结论成立。
∎

### 引理 4（模式条件继承与风险不增）
**陈述**：`Exec_v24|_{Π_0} = Exec_v23|_{Π_0}`；且存在 `δ` 使 `sup_{π∈Exec_v24} Risk(π) ≤ δ`，只要接触子空间仅接纳满足 CCC∧IEC∧SRTC∧CRR_armed 的计划。禁用接触时 `Exec_v24 = Exec_v23`。

**证明**：
- 非接触子空间：HPC-C 的 `avoid` 分支在 `HPC-E+` 通过后直接放行，未附加任何新约束，故与 v23 逐点相同；
- 接触子空间：由引理 2 注入能量有界、IEC 力/冲量有界、CCC 六元合取与 CRR 反射时限保证越界即回撤，故接触风险被独立证书界住；
- 禁用接触（`sim_ok=False` 或 `mode='avoid'`）时接触分支不可达，执行集精确收缩为 v23；
- 因此不存在"全局子集"，但存在**按模式分区的继承**：非接触精确不变，接触风险独立有界。声称全局 `Exec_v24 ⊆ Exec_v23` 会与"允许接触"矛盾，故本方案显式放弃该全局命题。
∎

### 引理 5（反射时限）
**陈述**：若 `CRR.armed` 且 `control_latency_p99 ≤ τ_reflex`，则任一触发（力尖峰/罐空/证书失效）在 `τ_reflex` 内进入 `RETRACT`；且 CCC 在 `CRR` 未武装时拒绝接触。

**证明**：`armed` 将 `control_latency_p99` 与 `τ_reflex` 直接比较；`step` 为 O(1) 无阻塞判定；CCC 的合取项含 `crr_armed`，故未武装时接触不可达。触发到执行的端到端延迟由 `control_latency_p99` 上界保证。
∎

### 定理（HPC-C 的模式条件可靠性）
**陈述**：`HPCC.admits(π,s) = True` 当且仅当：
(1) v23 的 HPC-E+ 全条件成立；
(2) 若为接触计划，则 SRTC 有效且 CCC∧IEC∧CRR_armed 成立；
(3) 若 SRTC 失效或模式为避碰，则计划仅在 v23 避碰语义下被接纳。
并且 `Exec_v24|_{Π_0} = Exec_v23|_{Π_0}`，接触子空间风险由引理 2–5 独立界住。

**证明**：直接由 `admits` 的分支结构与引理 1–5 组合可得。必要性：任一合取项失败即拒证或降级为避碰；充分性：全条件成立时，接触计划的能量、力、反射、迁移覆盖均有显式界。
∎
