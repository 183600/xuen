# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；本轮灵感：「成本控制」×「通用机器人平台」）

> R73 把安全证明从「全系统审计」降到「证据契约的组合代数」（MMS/DPEM/CCA/ΣREFLEX/CPB/J_MOD），并给出热替换定理与零级联降级。它回答的是「**信任如何组合**」，却默认了三个经济学上不成立的前提：
> - **认证是免费的**：每个模块的 SEAL 校准、conformal 校准、RTA 片段、证书维护被当成「只要做就能做」，证书强度 α 没有价格。真实世界里 `n ~ O(1/α)`，认证是随强度发散变贵的稀缺资源；R73 的 `CertCost` 只是一个度量，从未进入决策。
> - **平台是单体的**：R73 的模块图服务于「一台机器人」。而「通用机器人平台」的经济本质是**同一套认证资产被多任务、多形态复用**。R73 的热替换定理只证明了「同契约复用是安全的」，没有回答「**复用是否划算、复用到什么程度、标准化到什么半径**」。
> - **安全与成本可分离**：R73 把运行风险 λ 与认证成本分置两处，从不交易。但平台运营者真实面对的是**一条安全-成本前沿**：多花一元认证费换回多少期望损失？R73 的 λ 只度量「运行时的风险厌恶」，缺少其对偶——「认证的影子价格」。
>
> 本轮的直觉一句话：**R73 造出了可组合的「证据资本」，却没造出资本市场。** 成本控制不是工程优化，而是给这套代数补上**对偶的价格维度**；通用机器人平台不是「支持很多机器人」，而是「**让同一份证据资本尽可能多地摊销**」。两者合起来把 R73 从「计量契约代数」推进为「**认证经济学**」。

## 0. 直觉与动机

**灵感 1（成本控制 → 认证是一条会发散的成本曲线，不是布尔量）**
直觉：给一个模块做认证，不是「做了/没做」的开关，而是「做到多强」的连续旋钮。conformal 要覆盖 1−α，样本量约 `n ∝ 1/α`；SEAL 校准要在受控矩阵上覆盖更多材质/距离区间；RTA 要为更紧的时序包络重新证明。于是模块 i 的认证成本有确定形状：`C_i(α) = a_i + b_i/α`（固定成本 + 与强度成反比的边际成本），对更强证书（更小 α）**单调递增且凸**。一旦承认这一点，R73 的整个组合代数就自动诱导出一套**成本代数**：串联（单点失效、union bound）与并联（冗余、product）不仅在不确定度上不同，在「要花多少钱才能买到这个不确定度」上也不同。**安全不是一个数，而是一条价格曲线。**

**灵感 2（通用机器人平台 → 通用性的本质是标准化带来的摊销，而摊销有半径）**
直觉：一台定制机器人要为自己的每个模块付全额认证费；一个通用平台把同一份契约认证摊到 N 台本体、M 个任务上，单机成本骤降——这就是「通用」的经济来源。但标准化不是免费的：一份标准契约要同时服务一群异构本体，其有效域只能取交集 `D_std ⊆ ∩_j D_j`，不确定度只能取最坏 `u_std ≥ max_j u_j`；**越通用 ⇒ 公共有效域越小、越保守 ⇒ 运行时越畏手畏脚（运行成本 Δc_op 上升）**。于是存在一个可计算的**标准化半径**与**规模阈值 N***：低于 N*，定制更便宜；高于 N*，平台更便宜；若本体异质性太大导致保守性代价超过认证节省，则 `N*→∞`，平台永远不划算。**「通用」不是一个能力形容词，而是一个有盈亏平衡点的经济量。**

**灵感 3（成本-安全对偶 → 认证预算与运行风险是同一条前沿的两个坐标）**
直觉：R72 的 λ 说「我愿意为降低单位风险付出多少运行代价」；成本控制说的是「我愿意为买到单位证书强度付出多少认证费」。二者在最优处必须相等：**认证的影子价格 λ_cert = 运行损失的边际减少**。这把 R73 硬编码的「认证等级」变成内生的运营点：灾难性风险必须满足不可削减的安全下限（字典序、非补偿，继承 R71）；非灾难性风险则在预算内按边际收益水填。**平台不该过度认证，也绝不允许用成本理由削掉灾难性认证。** 这是本轮的伦理/安全锚点，也是「成本控制」不堕落为「偷工减料」的唯一结构保证。

**核心命题**：不再问「这套证据契约可不可信」，而问「**在总认证预算下，如何把有限的校准/审计资源分配到使平台级风险最小、并在多本体多任务上最大化证书复用？**」 把 MODGAUGE-RAS 推进为 **ECONGAUGE-RAS**（ECONomic, Cost-aware evidence metrology with GAUGE audits for RAS）——**认证经济学闭环**。

## 1. 形式化定义（增量：定义 383–396）

**定义 383（成本感知证据契约 EC-COST）** 在 R73 的 EC 上追加经济字段：
`EC_cost = (EC, C_i, α_min,i, δ_i, γ_i, L_class,i)`
- `C_i: (0,1] → ℝ_{≥0}`：认证成本函数，`C_i(α)=a_i + b_i/α`，对证书强度（`1−α`）单调递增、凸；`a_i` 固定成本，`b_i` 单位强度成本；
- `α_min,i`：**安全下限**——灾难性失效模式的误覆盖预算上界（证书至少这么强），属于不可交易约束；
- `δ_i`：证书漂移/折旧率（标定漂移、分布漂移、器件磨损）；
- `γ_i = ∂c_op/∂u_i ≥ 0`：该模块不确定度对运行时操作成本（保守动作、通过率）的敏感度；
- `L_class,i ∈ {bounded, catastrophic}`：失效后果等级，决定是否进入字典序约束。
**与 χ_R 同构**：R73 让模块声明「动作如何调制我的噪声」，本轮让模块声明「**把证书做多强要花多少钱、我的不确定度多值钱**」——成本成为契约字段，而不是外部参数。

**定义 384（认证预算代数 CBA，Cost Budget Algebra）** 每个组合算子 `⊛ ∈ {SER, PAR, VETO}` 对偶出一个成本算子：
- **SER / VETO（单点失效，union bound）**：`α_sys ≤ Σ_i α_i`，`C_sys(α_sys) = Σ_i C_i(α_i)`；
- **PAR（冗余，独立失效，product）**：`α_sys ≤ Π_i α_i`（相关性未审计时退化为 `Σ α_i`），`C_sys` 为对应和。
证书强度在组合下**只能变贵，不能变便宜**（见引理 38）——这是 R73「组合不产生认知免费午餐」的**经济版本**。

**定义 385（认证影子价格 λ_cert）** `λ_cert(α_sys) := −∂C*_sys(α_sys)/∂α_sys ≥ 0`。它度量「把系统级风险预算再收紧一单位，需要多付多少认证费」，是 R72 运行风险 λ 的**对偶价格**。

**定义 386（安全下限与字典序优化）** 认证预算分配是**字典序**问题：
1. 先满足所有灾难性模块的 `α_i ≤ α_min,i`（不可补偿、不可用成本理由削减）；
2. 在剩余预算内最小化非灾难性模块的总成本（或最大化其安全）。
若预算不足以满足全部下限，则**拒绝部署**（继承 R71 非补偿否决）。**成本控制只在「可安全削减」的集合内生效。**

**定义 387（证书资产 CAL，Certificate Asset Ledger）** 证书不是一次性报告，而是**资产** `A = (EC_cost, cert, D, t_0, drift_model)`：带有效域、签发时间、漂移模型、复用次数。资产可被多实例共享，按折旧规则减值。

**定义 388（证书折旧与漂移检测）** 模块不确定度随部署时间漂移：`u_i(t) = u_i(0)·(1+δ_i t)`（封顶后触发重认证）。漂移由**顺序 conformal 漂移检验**监控：当经验误覆盖超出 `α_i + 置信带宽` 时，证书从「有效」降为「待复核」并触发重认证。折旧不是隐喻，是可测的失效概率上界。

**定义 389（证书复用规则）** 把证书 `A` 用于实例 `j` 合法，当且仅当：
(i) `EC_cost` 逐字段匹配（R73 热替换条件）；(ii) `D_j ⊆ D`（在有效域内）；(iii) 漂移在认证带宽内；(iv) 若 `L_class=catastrophic`，则**禁止跨实例复用**，必须对 `j` 重新认证（下限优先于摊销）。
四条合取 ⇒ 复用安全（引理 42）；其中 (iv) 是成本控制的安全闸门。

**定义 390（标准化契约与标准化半径）** 对本体/任务簇 `G`，标准契约 `EC_std(G)` 必须**支配**每个成员：`D_std ⊆ ∩_{j∈G} D_j`、`u_std ≥ max_{j∈G} u_j`。标准化半径 `r(G)=|G|`。半径越大，认证固定成本摊得越薄，但公共域越小、越保守。

**定义 391（平台总拥有成本 TCO）** 对地平线 `H` 个任务/本体：
`TCO_platform = C_std + Σ_j [C_adapt,j + H·c_op(u_{g(j)})] + E[tail loss]`；
`TCO_bespoke = Σ_j [C_cert,j + H·c_op(u_j)] + E[tail loss]`。
`c_op(u)=c_0+γ u`（保守性线性代价），`E[tail loss]` 由 R72 风险模型给出。

**定义 392（规模阈值 N\*）** 在单一标准化组内，平台严格优于定制的规模阈值：
`N* = C_std / (C_bespoke − C_adapt − H·Δc_op)`，`Δc_op = c_op(u_std) − avg_j c_op(u_j) ≥ 0`。
分母 `≤0` ⇒ `N* = ∞`（标准化永不划算）。`N*` 是通用平台经济性的**相变点**。

**定义 393（异质性阻力）** 设组内不确定度分布跨度为 `spread = u_max − u_min`。由于 `u_std=u_max`，`Δc_op ≈ γ·(u_max − avg u)`，故 `∂N*/∂spread > 0`：**本体/任务越多样，摊销越难，越难跨过盈亏平衡**。这把「通用」量化成一个随异质性单调恶化的经济量。

**定义 394（成本-安全对偶前沿）** 设接受系统风险 `ε` 的期望运行损失为 `L(ε)`（`L'≥0`），保证 `ε` 的认证成本为 `C*(ε)`。联合运营点：
`min_ε L(ε) + C*(ε) + B_other`，一阶条件 `−L'(ε*) = C*'(ε*) = λ_cert(ε*)`。
**认证影子价格 = 运行损失的边际减少**。对 SER 线性损失 `L=ℓε`、成本 `C*=(Σ√b_i)²/ε`，闭式解 `ε* = Σ√b_i / √ℓ`，最小总安全成本 `= 2√(ℓ·(Σ√b_i)²)`。

**定义 395（成本攻击面与防护）** 成本控制引入新失效面：`ℰ_econ = {成本驱动欠校准、伪造低价证书、超期复用、审计套利（挑选宽松审计方）、以平均成本掩盖尾部成本}`。防线：安全下限（定义 386）+ 独立抽样审计 + 漂移监控 + 审计方轮换 + 尾部事件单独定价（不并入平均预算）。

**定义 396（ECON-MBench / MB4）** 经济基准：测量 `C_i(α)` 曲线、标度律、复用率、`N*`、`TCO` 与安全下限行为；预注册、固定种子、密封保持集 SEAL-MB4，各 ≤3h 单卡。

## 2. 关键算法骨架

```python
# IP-303 CBA：认证预算代数（成本对偶）
@dataclass(frozen=True)
class CostContract:
    a: float; b: float                      # C(alpha) = a + b/alpha
    alpha_min: float                        # 安全下限（catastrophic）
    delta: float; gamma: float              # 漂移率；运行成本敏感度
    cost_class: str                         # 'bounded' | 'catastrophic'
    def cost(self, alpha): return self.a + self.b / alpha

def cost_compose(children, op, alpha_sys):
    # SER/VETO: alpha_sys <= sum(alpha_i);  PAR: alpha_sys <= prod(alpha_i)
    # 返回满足系统预算的最优分配与总成本（IP-304 OCA）
    if op in ('SER', 'VETO'):
        return oca_union([c.b for c in children], alpha_sys)
    return oca_product([c.b for c in children], alpha_sys)

# IP-304 OCA：最优认证分配（水填；含安全下限与预算拒绝）
def oca_union(b, alpha_sys, floors=None):
    # 解析：alpha_i* = alpha_sys * sqrt(b_i) / sum(sqrt(b_j))
    # C* = (sum sqrt(b_i))**2 / alpha_sys；lambda = (sum sqrt(b_i))**2 / alpha_sys**2
    s = sum(math.sqrt(x) for x in b)
    alphas = [alpha_sys * math.sqrt(x) / s for x in b]
    if floors and any(a > f for a, f in zip(alphas, floors)):
        return project_with_floors(b, alpha_sys, floors)   # KKT 投影
    return alphas, s * s / alpha_sys

def oca_product(b, alpha_sys):
    # 解析：alpha_i* = alpha_sys**(1/k) * b_i / prod(b)**(1/k)
    # C* = k * (prod(b)/alpha_sys)**(1/k)
    k = len(b); pb = math.prod(b)
    alphas = [alpha_sys ** (1/k) * x / pb ** (1/k) for x in b]
    return alphas, k * (pb / alpha_sys) ** (1/k)

def lexicographic_allocate(modules, B_cert, alpha_sys):
    # 字典序：先满足 catastrophic 下限，再在剩余预算上做 OCA
    floors = {i: m.alpha_min for i, m in modules.items() if m.cost_class == 'catastrophic'}
    cost_floor = sum(modules[i].cost(f) for i, f in floors.items())
    if cost_floor > B_cert:
        return None                                     # 预算不足以安全部署 ⇒ 拒绝
    rest = {i: m for i, m in modules.items() if i not in floors}
    return oca_with_budget(rest, B_cert - cost_floor, alpha_sys)

# IP-305 CAL：证书资产账本（折旧 + 复用决策）
class CertLedger:
    def usable(self, asset, inst):
        return (asset.ec == inst.ec and inst.domain <= asset.domain
                and asset.drift_ok(inst.t) and asset.cost_class != 'catastrophic')
    def should_recert(self, asset, inst):
        tail = inst.p_fail * inst.L_catastrophic
        return (asset.cost_class == 'catastrophic'
                or tail >= asset.recert_cost
                or not asset.drift_ok(inst.t))          # 尾部风险优先，非平均

# IP-306 SCP：标准化分组（层次合并，合并增益 > 0 才合）
def merge_gain(g, h, members, H, gamma, cost_std):
    u_merged = max(members[j].u for j in g + h)
    extra = sum(H * gamma * (u_merged - members[j].u) for j in g + h)
    saved = cost_std                                # 少了一套标准契约固定成本
    return saved - extra

def standardize(members, H, gamma, cost_std):
    groups = [[j] for j in members]
    while True:
        best = max(((merge_gain(g, h, members, H, gamma, cost_std), i, j)
                    for i, g in enumerate(groups) for j, h in enumerate(groups) if i < j),
                   default=(0, -1, -1))
        if best[0] <= 0: break
        _, i, j = best; groups[i] += groups[j]; groups.pop(j)
    return groups                                   # 标准化半径由经济性内生决定

# IP-307 CSD：成本-安全对偶运营点
def optimal_assurance(b_vec, loss_per_risk, eps_max):
    s = sum(math.sqrt(x) for x in b_vec)
    eps_star = s / math.sqrt(loss_per_risk)         # 定义 394 闭式
    eps = min(eps_star, eps_max)                    # 安全下限/法规上限裁剪
    cert_cost = s * s / eps
    total = loss_per_risk * eps + cert_cost
    return eps, cert_cost, total, (s * s / eps ** 2)  # 返回 lambda_cert

# IP-308 ECON 主闭环：成本只进「部署/运营域」，不进硬实时控制域
def ECONGAUGE_round(M, obs, audio, tac_frame, depth_img):
    # 运行域（继承 R73，逐指令不变；成本不进入 1kHz 控制路径）
    k, lam, J = M.modgauge_round(obs, audio, tac_frame, depth_img)
    # 运营域（异步，秒级/任务级）：预算分配、复用、重认证
    if M.ops.due():
        alloc = lexicographic_allocate(M.modules, M.B_cert, M.alpha_sys)
        if alloc is None:
            M.safety.publish_refusal('CERT_BUDGET_INSUFFICIENT')   # 非补偿
            return k, lam, J
        for j, inst in M.new_instances():
            if M.ledger.usable(M.cert_for(inst), inst):
                M.ledger.reuse(inst)                                # 摊销
            else:
                M.ledger.schedule_recert(inst)                      # 部分/全量重认证
        M.ledger.check_drift(M.drift_tests)                         # 顺序 conformal
        M.scp.update(M.fleet)                                       # 标准化分组
        M.econ.log(alloc, M.ledger.tco(), M.shadow_price())
    return k, lam, J
```

## 3. 推导

**引理 38（成本组合单调性）** `C_i(α)=a_i+b_i/α` 在 `α>0` 上递减且凸。SER 下 `C_sys=ΣC_i`，对每个 `α_i` 单调；收紧系统风险（减小 `α_sys`）要求至少一个 `α_i` 减小，故 `C_sys` 不减。PAR 同理。⇒ **组合只会让证书变贵，不会让「安全」变便宜；成本与不确定度一样，无免费午餐。** 系：R73 引理 34 的严格经济对偶。

**引理 39（水填最优性）** 因 `C_i` 凸、约束线性/对数线性，KKT 一阶条件给出唯一最优：
SER（约束 `Σα_i=α_sys`）：`−b_i/α_i² + μ = 0 ⇒ α_i ∝ √b_i`，`α_i*=α_sys√b_i/Σ√b_j`，`C*=(Σ√b_i)²/α_sys`。
PAR（约束 `Π α_i = α_sys`）：`−b_i/α_i² + μ/α_i = 0 ⇒ α_i ∝ b_i`，`α_i*=α_sys^{1/k} b_i/(Πb_j)^{1/k}`，`C*=k(Πb_i/α_sys)^{1/k}`。
系：**贵模块（大 b）拿到更宽的 α（更弱的证书）**——不是因为它更安全，而是因为提升它太贵；这是成本的边际均衡，不是安全偏好。

**引理 40（影子价格单调性）** SER 的 `λ_cert=(Σ√b_i)²/α_sys²`：对 `α_sys` 递减（风险预算越松，边际认证越便宜），对 `b_i` 递增（认证越贵，影子价格越高）。⇒ 平台在风险预算宽松时应少认证，在认证昂贵时应更愿意接受风险——但仅在非灾难性集合内。

**引理 41（安全下限的字典序可靠性）** 设 `α_min,i` 为灾难性下限。字典序解先满足所有下限，再做 OCA。则任意预算决策下，灾难性模块的误覆盖 `≤α_min,i` 恒成立；若不可行则拒绝。⇒ **成本优化不可能侵蚀灾难性安全**，与 R71 非补偿否决同构。

**引理 42（证书复用可靠性）** 若 `EC_cost` 匹配、`D_j⊆D`、漂移在认证带宽内且非灾难性，则复用证书的有效性由 R73 引理 35（同契约实现保持系统性质）与 conformal 覆盖保证共同给出：`P(risk_j > ε) ≤ α + α_drift`。灾难性模式禁止复用 ⇒ 下限不被摊销绕过。系：**复用是安全的，但仅在可安全复用的集合上安全。**

**引理 43（标准化支配的安全性）** 若 `D_std ⊆ ∩D_j` 且 `u_std ≥ max u_j`，则标准契约给每个成员的有效域与不确定度都是保守的，成员在其上的风险不高于用各自最优契约时的风险。⇒ **标准化以保守性换复用，安全侧只增不减，代价是 `Δc_op`。**

**引理 44（分组合并的单调性与贪心）** 合并增益 `gain(g,h)=C_std−Σ_j Hγ(u_{g∪h}−u_{g(j)})`。若 `c_op` 凸、`u` 对集合运算单调，则合并增益满足子模性近似，层次贪心在 `O(N²logN)` 内收敛到局部最优；`K*` 通常呈 U 形（`K→1` 保守代价大，`K→N` 固定成本大）。⇒ **标准化半径可由数据内生确定，而非拍脑袋。**

**定理 30（认证成本标度律）** 在 `C_i(α)=a_i+b_i/α`、独立/单点失效模型下：
SER/VETO：`C*_sys = Σa_i + (Σ√b_i)²/α_sys`，`λ_cert=(Σ√b_i)²/α_sys²`；
PAR：`C*_sys = Σa_i + k(Πb_i/α_sys)^{1/k}`，`λ_cert=(Πb_i)^{1/k}α_sys^{−(1+1/k)}`。
**解读**：串联安全成本随「单位成本平方根之和」二次增长、随风险预算反比增长；冗余安全成本取几何平均、随冗余度 `k` 线性增长。这是「安全要花多少钱」的闭式答案，直接可证伪（E397）。

**定理 31（平台规模阈值与异质性阻力）** 单一标准组下平台优于定制当且仅当 `N > N* = C_std/(C_bespoke−C_adapt−HΔc_op)`，且 `N*` 对组内异质性（`spread`）单调递增、对任务地平线 `H` 单调递减。⇒ **存在通用平台的经济相变；多样化机队天然更难标准化。** 可证伪：扫 N 与 spread 测 TCO 交叉点（E401/E402）。

**定理 32（成本-安全对偶最优性）** 在 `L` 凸增、`C*` 凸减（对 ε）下，联合运营点由 `−L'(ε*)=C*'(ε*)=λ_cert` 唯一刻画；对 SER 线性损失，`ε*=Σ√b_i/√ℓ`，最小总安全成本 `=2√(ℓ·(Σ√b_i)²)`。⇒ **认证等级是内生的：既不该过度认证，也不能用成本理由突破安全下限（引理 41 约束该最优）。** 可证伪：扰动预算/损失率，检验影子价格对边际价值的预测（E399）。

**定理 33（ECONGAUGE 严格包含）** 令所有 `b_i→0`（认证免费）且 `α_min=0`、`C_std=∞`（不标准化），则字典序优化退化为恒等、TCO 退化为 R73 的 `CertCost`、复用规则退化为 R73 热替换。由引理 38–44 与 R73 定理 27–29，ECONGAUGE 逐指令等于 MODGAUGE，再退化为 R72/R71/R68。**安全单调不减，经济性只在「可安全削减」的集合内获益。**

## 6. 本轮最大风险

**一句话**：成本优化会系统性地奖励「**可被便宜地度量**的安全」，而惩罚「**昂贵但真实**的尾部风险」——`C_i(α)=a_i+b_i/α` 只对可观测、可校准的平均失效定价，对罕见灾难性事件要么定价高到无人问津、要么被字典序下限挡在优化之外而缺少持续投入；于是平台可能在一套**所有证书都有效、所有预算都闭合、所有影子价格都相等**的经济学最优解上，**恰好对最该害怕的那些低概率高后果失效保险不足**，而账本会证明「每一分钱都花在了边际收益最高的地方」。

次级风险与缓解：
1. **安全下限被架空（历史最危险）** → 下限由独立于成本优化的认证方设定，定期外部复审；`α_min` 变更需安全委员会签署；E404 专项对抗。
2. **成本曲线误设（平均掩盖尾部）** → 尾部分布单独建模，灾难性事件不并入平均预算（定义 395）；用极值理论校准 `L` 的尾部而非均值。
3. **复用漂移的隐性失效** → 顺序 conformal 漂移监控 + 硬到期强制重认证 + 域外一律拒绝（E400/E406）。
4. **标准化过度保守导致平台不可用** → 内生 `K*` 分组 + 离群体单独成组（E403/E410），避免「为了摊销牺牲性能」。
5. **审计套利/伪证** → 审计方轮换 + 独立抽样 + 证书签名与追溯链（继承 R73 τ_merge）+ 伪证经济惩罚模型。
6. **度量成本本身被低估（元成本）** → 把「测量 `C_i` 与 `L` 的成本」计入 `a_i`，否则成本模型自欺（元认证预算）。
7. **N\* 估计对任务混合分布敏感** → TCO 按任务混合加权，报告置信区间而非点估计；换任务分布时重估。

**定义 384（CBA 认证预算代数）** SER/VETO：`α_sys≤Σα_i`，`C_sys=ΣC_i`；PAR：`α_sys≤Πα_i`（独立性未审计则退化为 Σ）。证书强度组合下只能变贵（引理 38）——不确定度组合单调性的经济对偶。

## 3. 关键算法伪代码

```python
# IP-303 CBA：成本对偶代数
@dataclass(frozen=True)
class CostContract:
    a: float; b: float                      # C(alpha) = a + b/alpha
    alpha_min: float                        # 灾难性下限
    delta: float; gamma: float              # 漂移率；运行成本敏感度
    cost_class: str                         # 'bounded' | 'catastrophic'
    def cost(self, alpha): return self.a + self.b / alpha

# IP-304 OCA：最优认证分配（水填闭式 + 下限投影 + 预算拒绝）
def oca_union(b, alpha_sys, floors=None):
    s = sum(math.sqrt(x) for x in b)
    alphas = [alpha_sys * math.sqrt(x) / s for x in b]
    if floors and any(a > f for a, f in zip(alphas, floors)):
        return project_with_floors(b, alpha_sys, floors)      # KKT 投影
    return alphas, s * s / alpha_sys                          # C* = (sum sqrt b)^2 / alpha

def oca_product(b, alpha_sys):
    k = len(b); pb = math.prod(b)
    alphas = [alpha_sys ** (1/k) * x / pb ** (1/k) for x in b]
    return alphas, k * (pb / alpha_sys) ** (1/k)             # C* = k (prod b / alpha)^(1/k)

def lexicographic_allocate(modules, B_cert, alpha_sys):
    floors = {i: m.alpha_min for i, m in modules.items() if m.cost_class == 'catastrophic'}
    cost_floor = sum(modules[i].cost(f) for i, f in floors.items())
    if cost_floor > B_cert:
        return None                                          # 预算不足以安全部署 ⇒ 拒绝
    rest = {i: m for i, m in modules.items() if i not in floors}
    return oca_with_budget(rest, B_cert - cost_floor, alpha_sys)

# IP-305 CAL：证书资产账本
class CertLedger:
    def usable(self, asset, inst):
        return (asset.ec == inst.ec and inst.domain <= asset.domain
                and asset.drift_ok(inst.t) and asset.cost_class != 'catastrophic')
    def should_recert(self, asset, inst):
        tail = inst.p_fail * inst.L_catastrophic
        return (asset.cost_class == 'catastrophic' or tail >= asset.recert_cost
                or not asset.drift_ok(inst.t))               # 尾部优先于平均

# IP-306 SCP：标准化分组（合并增益 > 0 才合，标准化半径内生）
def merge_gain(g, h, members, H, gamma, cost_std):
    u_merged = max(members[j].u for j in g + h)
    extra = sum(H * gamma * (u_merged - members[j].u) for j in g + h)
    return cost_std - extra

def standardize(members, H, gamma, cost_std):
    groups = [[j] for j in members]
    while True:
        best = max(((merge_gain(g, h, members, H, gamma, cost_std), i, j)
                    for i, g in enumerate(groups) for j, h in enumerate(groups) if i < j),
                   default=(0, -1, -1))
        if best[0] <= 0: break
        _, i, j = best; groups[i] += groups[j]; groups.pop(j)
    return groups

# IP-307 CSD：成本-安全对偶运营点
def optimal_assurance(b_vec, loss_per_risk, eps_max):
    s = sum(math.sqrt(x) for x in b_vec)
    eps_star = s / math.sqrt(loss_per_risk)                  # 定义 394
    eps = min(eps_star, eps_max)                             # 法规/安全上限裁剪
    return eps, s * s / eps, loss_per_risk * eps + s * s / eps, s * s / eps ** 2

# IP-308 ECON 主闭环：成本只进部署/运营域，硬实时控制域零改动
def ECONGAUGE_round(M, obs, audio, tac_frame, depth_img):
    k, lam, J = M.modgauge_round(obs, audio, tac_frame, depth_img)   # R73 逐指令不变
    if M.ops.due():
        alloc = lexicographic_allocate(M.modules, M.B_cert, M.alpha_sys)
        if alloc is None:
            M.safety.publish_refusal('CERT_BUDGET_INSUFFICIENT')     # 非补偿
            return k, lam, J
        for j, inst in M.new_instances():
            if M.ledger.usable(M.cert_for(inst), inst):
                M.ledger.reuse(inst)                                 # 摊销
            else:
                M.ledger.schedule_recert(inst)                       # 部分/全量重认证
        M.ledger.check_drift(M.drift_tests)                          # 顺序 conformal
        M.scp.update(M.fleet)                                        # 标准化分组
        M.econ.log(alloc, M.ledger.tco(), M.shadow_price())
    return k, lam, J
```

## 4. 推导

**引理 38（成本组合单调性）** `C_i=a_i+b_i/α` 递减凸；SER/PAR 的 `C_sys` 对强度单调不减。⇒ 组合不会让安全变便宜——R73 引理 34 的严格经济对偶。

**引理 39（水填最优性）** SER：`α_i*=α_sys√b_i/Σ√b_j`，`C*=(Σ√b_i)²/α_sys`；PAR：`α_i*=α_sys^{1/k}b_i/(Πb_j)^{1/k}`，`C*=k(Πb_i/α_sys)^{1/k}`。系：贵模块获更宽 α（更弱证书）——成本的边际均衡，而非安全偏好。

**引理 40（影子价格单调性）** `λ_cert` 对 `α_sys` 递减、对 `b_i` 递增。⇒ 风险预算宽松时少认证；认证昂贵时更愿接受风险（仅非灾难性集合内）。

**引理 41（安全下限字典序可靠性）** 先满足全部 `α_i≤α_min,i` 再做 OCA ⇒ 任意预算决策下灾难性误覆盖恒 `≤α_min`；不可行则拒绝。⇒ 成本优化无法侵蚀灾难性安全（与 R71 非补偿同构）。

**引理 42（复用可靠性）** EC 匹配 ∧ `D_j⊆D` ∧ 漂移在带内 ∧ 非灾难性 ⇒ `P(risk_j>ε)≤α+α_drift`（R73 引理 35 + conformal 覆盖）。灾难性禁复用 ⇒ 下限不被摊销绕过。

**引理 43（标准化支配安全性）** `D_std⊆∩D_j`、`u_std≥max u_j` ⇒ 成员风险不高于各自最优契约，安全只增不减，代价是 `Δc_op`。

**引理 44（分组合并）** 合并增益 `gain=C_std−Σ_j Hγ(u_{g∪h}−u_{g(j)})`；凸 `c_op` 下层次贪心 `O(N²logN)` 收敛到局部最优，`K*` 常呈 U 形。

**定理 30（认证成本标度律）** SER `C*=Σa+(Σ√b)²/α_sys`；PAR `C*=Σa+k(Πb/α_sys)^{1/k}`。安全成本：串联随「单位成本平方根之和」二次增长、随风险预算反比；冗余取几何平均、随 k 线性。直接可证伪（E397）。

**定理 31（平台规模阈值与异质性阻力）** 平台优于定制 ⇔ `N>N*=C_std/(C_bespoke−C_adapt−HΔc_op)`；`N*` 对 spread 递增、对 H 递减。⇒ 通用平台存在经济相变；多样化机队更难标准化（E401/E402）。

**定理 32（成本-安全对偶最优性）** `−L'(ε*)=C*'(ε*)=λ_cert` 唯一刻画联合运营点；SER 线性损失下 `ε*=Σ√b/√ℓ`，最小总成本 `2√(ℓ(Σ√b)²)`。⇒ 认证等级内生，但受引理 41 下限约束（E399）。

**定理 33（ECONGAUGE 严格包含）** 令 `b_i→0`、`α_min=0`、`C_std=∞`：字典序退化为恒等、TCO 退化为 R73 `CertCost`、复用退化为热替换。由引理 38–44 与 R73 定理 27–29 ⇒ 逐指令等于 MODGAUGE ⇒ R72/R71/R68。**安全单调不减，经济性仅在可安全削减集合内获益。**

## 7. 本轮最大风险

**一句话**：成本优化会系统性奖励「可被便宜地度量」的安全、惩罚「昂贵但真实」的尾部风险——`C_i(α)=a_i+b_i/α` 只对可观测的平均失效定价，对罕见灾难性事件要么定价高到无人问津、要么被字典序下限挡在优化之外而缺少持续投入；于是平台可能在**所有证书都有效、所有预算都闭合、所有影子价格都相等**的经济学最优解上，**恰好对最该害怕的低概率高后果失效保险不足**，而账本会证明「每一分钱都花在了边际收益最高的地方」。

次级风险与缓解：
1. **安全下限被架空（最危险）** → 下限由独立于成本优化的认证方设定并定期外部复审；变更需安全委员会签署；E404 专项对抗。
2. **成本曲线误设（平均掩盖尾部）** → 尾部分布单独建模，灾难性不并入平均预算；极值理论校准 `L` 的尾部。
3. **复用漂移隐性失效** → 顺序 conformal 监控 + 硬到期强制重认证 + 域外一律拒绝（E400/E406）。
4. **标准化过度保守使平台不可用** → 内生 `K*` 分组 + 离群体单独成组（E403/E410）。
5. **审计套利/伪证** → 审计方轮换 + 独立抽样 + 证书签名与追溯链（R73 τ_merge）+ 伪证经济惩罚。
6. **度量成本被低估（元成本）** → 把「测量 `C_i` 与 `L` 的成本」计入 `a_i`（元认证预算）。
7. **N\* 对任务混合分布敏感** → TCO 按任务混合加权，报告置信区间；换分布重估。
