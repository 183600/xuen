# 第 44 轮（新循环第 4 轮） · Sim-as-Falsifier × Dual-Sim-Validity：把「MuJoCo 虚拟仿真」从神谕降级为可审计的双向证书器官（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖 + 多用户契约空集」，但它仍压着一个更底层、从未被检视的单点假设：**(H3) 仿真器是 sound 神谕**——v19/v20 的 Sim-Cert-RAG 飞轮默认「仿真里没违例 ≈ 真实安全」「仿真里找到的反例 ≈ 真实反例」。本轮灵感词「MuJoCo」「虚拟仿真」精确命中它：MuJoCo 是接触丰富、软接触、摩擦锥正则化的真实物理引擎，它既不是真实的过近似、也不是欠近似，只是一个参数化点估计；接触瞬间的模型误差会让「仿真安全」无法转移、「仿真反例」无法落地。于是本轮把仿真器拆成**两个方向相反的证书器官**：S^⊕（证明定向、过近似，只有它的「安全」结论可下发）与 S^⊖（反驳定向、欠近似，只有它的「不安全」见证可采信）。核心命题：**同一标称仿真器不能同时证明安全与反驳不安全**；MuJoCo 的正确角色是可微分反驳器（MJX）与课程生成器，而不是真理来源。

## 0. 直觉与动机

**灵感 1（仿真是不对称器官：证明要过近似，反驳要欠近似）**：直觉上，仿真说「安全」只能说明「在我这个模型里安全」，真实系统可能因为接触刚度、摩擦、延迟不同而更危险；反过来，仿真里跑出一条撞车轨迹，也不能保证真机一定撞——除非仿真可达集**包含于**真实可达集。这两个方向要求相反的建模偏差：证明安全需要仿真**比真实更大**（保守过近似，Reach_R ⊆ Reach_S⊕），反驳不安全需要仿真**比真实更小**（乐观欠近似，Reach_S⊖ ⊆ Reach_R）。一个标称 MuJoCo 参数点是「中间点」，两个方向都不满足。这就是 v19/v20 飞轮最深的漏洞：它把「点估计」当成了「双向保证」。

**灵感 2（接触丰富 → 误差管爆炸，证书必须膨胀而非掩盖）**：MuJoCo 的软接触（solref/solimp）、摩擦锥正则化、有限迭代求解器，在**接触发生的瞬间**产生非光滑、非 Lipschitz 的误差跳变。任何用单一 Lipschitz 常数做的管半径 ρ(t) 会在接触时刻爆炸。正确做法不是假装它光滑，而是**承认管半径并让证书 margin 去吸收它**：只在 m > ρ^⊕(t) 的时段下发证书，否则进入接触专用保守模式（低刚度、低速、软接触参数上界）。这给出了一个可审计的「接触契约」。

**灵感 3（可微物理 → 梯度反驳器与用反例收紧管）**：MuJoCo 的 MJX 后端提供可微物理。与其用仿真去「证明」，不如用它去「找反例」：对初始条件、接触参数、控制器做梯度上升，最大化证书违反度；找到的轨迹在 S^⊖ 语义下是可反驳见证，回灌后可**收紧 ρ^⊕**（因为上包络必须覆盖这些真实失败模式）。仿真由此成为证书的「对抗训练数据源」，而非真理来源。

**耦合升级**：SVC（仿真有效性证书）把「仿真-现实误差」变成带覆盖保证的双向管；DSF（可微反驳器）用 MJX 生成反例证书；S2R-CT（仿真到现实证书转移）给出 m > ρ 的可下发判据。四层架构由 v8 的「人格契约 + 并发证书」升级为 v9 的「双向仿真器官 + 证书转移 + 人格/并发」，即 **仿真只负责反驳与课程，证明责任回到带管膨胀的证书层**。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（双向包含与仿真器的双重角色）**：记 S_θ 在任务分布 D、时域 T 上的可达集为 Reach_S(θ)，真实可达集为 Reach_R。定义
- **证明定向仿真器 S^⊕**：要求 Reach_R ⊆ Reach_S⊕（过近似）。若 Reach_S⊕ ∩ Unsafe = ∅，则真实安全。
- **反驳定向仿真器 S^⊖**：要求 Reach_S⊖ ⊆ Reach_R（欠近似）。若 Reach_S⊖ ∩ Unsafe ≠ ∅，则真实存在违例。

**不可兼得命题**：对同一标称 S_θ，一般不存在 θ 同时满足两向包含（接触非光滑下尤甚）。因此必须维护参数区间 [θ^⊖, θ^⊕] 与两套证书，且**按方向路由**：安全结论只信 S^⊕，不安全见证只信 S^⊖。

**定义 45（仿真有效性证书 SVC）**：对任务分布 D 与时间 t∈[0,T]，SVC V=(ρ^⊕, ρ^⊖, α, N) 声称：以 ≥1−α 概率（对 D 的真机采样与校准样本），∀t 有
dist(x_R(t), Reach_S⊕(t)) ≤ ρ^⊕(t) 且 dist(x_S⊖(t), Reach_R(t)) ≤ ρ^⊖(t)。
ρ 由接触模型参数区间、系统辨识残差、以及**真机-仿真轨迹对的经验分位数**（轨迹级共形 / scenario optimization）共同标定；N 为校准轨迹数，给出有限样本覆盖保证。SVC 不是一次性结论，带租约（定义 49）。

**定义 46（仿真到现实的证书转移定理 S2R-CT）**：设 S^⊕ 上证书不变集 I 满足：∀x∈I，dist(x, Unsafe) ≥ m（margin）；且上包络半径满足 ρ^⊕(t) < m 在 [0,T] 内成立。则真实轨迹在 I 的 ρ^⊕-膨胀集 I⊕ 内保持安全。**证明直觉**：真实轨迹被限制在仿真轨迹的 ρ^⊕ 球内，球心到不安全集距离 ≥ m，球半径 < m，故球与不安全集不交。**对偶**：若 S^⊖ 上存在反例轨迹且其 ρ^⊖-邻域仍落入不安全集（witness 余量），则该反例是真实的。**推论**：安全转移的唯一代价是「margin 必须大于上包络」，接触-rich 任务的痛点正是 ρ^⊕ 在接触瞬间爆炸 → 必须显式建模，不能掩盖。

**定义 47（可微分仿真反驳器 DSF）**：用 MJX 可微物理求
x* = argmax_{θ∈[θ^⊖,θ^⊕], x0∈X0, u(·)} Violation(S, x0, u, θ)，
在接触非光滑处用 randomized smoothing / 次梯度包络近似梯度。产出反例证书 c^- = (x0, u(·), θ, 轨迹, 违反谓词)。**命题**：在 S^⊖ 语义与 witness 余量下，c^- 是可反驳见证；回灌后用于收紧 ρ^⊕（上包络必须覆盖已知失败模式）与更新课程。

**定义 48（虚拟仿真证书训练场 / 证书课程）**：以 MuJoCo 场景族构成 certificate gym。每个场景带三元难度 (接触频率 f_c、接触刚度 k_c、误差管需求 ρ_req)。课程按「先低 f_c 低 k_c、后接触突变」排序；样本用于 (a) 校准 SVC，(b) 训练/蒸馏证书网络，(c) 压力测试。定义课程效率 = 单位真机样本带来的 ρ^⊕ 收缩量。

**定义 49（仿真保真度租约 Fidelity Lease）**：数字孪生随磨损、负载、温度漂移，SVC 非永久。给 SVC 配租约 ℓ_f=(ρ^⊕, ρ^⊖, τ, λ_fid, κ_fid)；在线用真机残差 r(t)=x_R(t)−x_S(t) 检验是否越过 ρ^⊕(t)+λ_fid(t−τ)。越界即判定租约过期：触发重标定（系统辨识）或降级到**纯真机保守策略**（去掉所有仿真派生证书）。**注**：这是把第 43 轮证书租约（定义 41）从「推理结论」推广到「仿真器本身」，二者可组合：最终下发 margin = min(推理租约衰减, 保真度管膨胀)。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 SIM-VALIDITY-CERTIFICATE（仿真有效性证书 SVC）
1. **双向区间仿真**：参数区间 [θ^⊖, θ^⊕]（接触刚度/阻尼/摩擦/延迟），分别构建 S^⊕ 与 S^⊖；内置「接触契约」（接触时刻自动降速/软化）。
2. **管半径标定**：真机-仿真轨迹对 + 轨迹级共形 / scenario optimization，给出 (ρ^⊕, ρ^⊖) 的有限样本覆盖证书。
3. **保真度租约**：在线残差监测、漂移检测、过期降级到纯真机策略。
4. **按方向路由**：安全结论只走 S^⊕；反例只走 S^⊖；路由表与证书一起审计。

### 2.2 IP-61 DIFF-SIM-FALSIFIER（可微仿真反驳器 DSF）
1. **MJX 可微反驳**：对 x0、接触参数、控制器做梯度/自然梯度搜索最大化违反度。
2. **非光滑处理**：接触处 randomized smoothing，给出违反度的下界包络，避免假反例。
3. **反例证书化**：反例存为 (x0,u,θ,轨迹,违反谓词)，可在真机/高保真回放验证。
4. **回灌闭环**：反例 → 收紧 ρ^⊕ → 更新 CKB/课程 → 重训证书。

### 2.3 IP-62 SIM-TO-REAL-CERT-TRANSFER（证书转移 S2R-CT）
1. **转移判据**：强制检查 m(x) > ρ^⊕(t) 才允许下发仿真派生证书；否则膨胀或降级。
2. **证书膨胀算子**：I⊕ = dilate(I, ρ^⊕)，与几何证书、CBF 约束求交。
3. **双模型一致性检查**：S^⊕ 安全但 S^⊖ 有反例时，标记为「争议区」，交真机/高保真升级验证。
4. **审计**：每条下发证书记录其方向、ρ、margin、租约。

## 5. 本轮最大风险

**一句话**：仿真-现实误差管 ρ 的估计依赖与模型同源的有限真机数据，而接触突变的非 Lipschitz 性会让 ρ^⊕ 爆炸到使 m > ρ^⊕ 恒不成立——「证书转移」要么空洞（ρ→∞ 永不下发）要么循环（用仿真验证仿真），整个 v21 可能退化为只能反驳、不能证明的反例机器。

| ℓ_f=(ρ^⊕,ρ^⊖,τ,λ_fid,κ_fid) | 保真度租约 | 仿真器自身的时效契约 |
| I⊕ = dilate(I, ρ^⊕) | 证书膨胀 | 与几何/CBF 约束求交后下发 |
| m > ρ^⊕ | 转移判据 | margin 吸收模型误差才可下发 |

### IP-60 SVC：双向区间、共形管与保真度租约
```
def build_interval_sim(theta_nom, bounds):
    # 方向由 E95 实测定标；不默认为真：先验证单调性再定上/下界
    theta_plus  = upper_bound(theta_nom, bounds)
    theta_minus = lower_bound(theta_nom, bounds)
    return Sim(theta_plus, role=PROOF), Sim(theta_minus, role=FALSIFY)

def conformal_tube(residual_trajs, alpha, contact_flags):
    # 分层共形：接触 / 非接触各一条管，避免接触突变污染全局分位
    q = {}
    for layer in (False, True):
        rs = [max_t r[t] for r, cf in zip(residual_trajs, contact_flags)
              for t in T if cf[t] == layer]
        n = len(rs)
        k = ceil((n + 1) * (1 - alpha))
        q[layer] = sorted(rs)[min(k, n) - 1]      # 秩统计阈值
    return Tube(q[False], q[True])

def calibrate_svc(traj_pairs, alpha):
    # traj_pairs: [(x_R(t), x_S(t), contact_flag(t))]
    r_plus  = [max_t ||x_R(t) - x_S_plus(t)|| for ...]   # 上包络残差
    r_minus = [max_t ||x_S_minus(t) - x_R(t)|| for ...]  # 下包络残差
    return SVC(conformal_tube(r_plus, alpha, cf),
               conformal_tube(r_minus, alpha, cf), alpha, N=len(traj_pairs))

def fidelity_lease_check(svc, x_real, x_sim, t):
    r = norm(x_real - x_sim)
    rho_t = svc.rho_plus(t) + svc.lam_fid * (t - svc.tau)
    if r > rho_t:
        svc.status = RECALIBRATE_OR_DEGRADE       # 过期 => 纯真机保守
        return False
    return True
```

### IP-61 DSF：MJX 梯度反驳与反例证书
```
def dsx_falsify(sim_minus, x0_dist, theta_box, horizon, steps, restarts):
    for _ in range(restarts):
        x, th = sample(x0_dist), sample(theta_box)
        for _ in range(steps):
            loss = violation(sim_minus, x, th, horizon)   # MJX 可微
            g = smooth_grad(loss)                          # 接触处 randomized smoothing
            x, th = ascend(x, th, g)                       # 次梯度包络上升
        if witness_margin(sim_minus, x, th) > 0:
            traj = rollout(sim_minus, x, th)
            return CounterexampleCert(x, th, traj, violated_at(traj))
    return None

def close_loop_from_counterexample(svc, cex):
    # 已知失败模式必须被上包络覆盖 => 反例收紧 ρ^⊕
    svc.rho_plus = max(svc.rho_plus, tube_needed_to_cover(cex))
    svc.rho_minus = min(svc.rho_minus, ...) if cex.confirms_under_approx else svc.rho_minus
    stage_to(svc.ckb, cex)                             # 写入 CKB / 课程
    return svc
```

### IP-62 S2R-CT：转移判据、膨胀与争议区
```
def s2r_transfer(cert, svc, t):
    if not svc.lease_valid(t):
        return downgrade_to_real_only()               # 仿真证书整体失效
    m, rho = cert.margin, svc.rho_plus(t)
    if m > rho * SAFETY_FACTOR:                        # 严格 m > ρ
        return cert.dilate(rho)                        # 膨胀后下发（仍是证书）
    return escalate_to_disputed(cert)                  # 争议区：真机/高保真升级

def route_by_direction(claim, sim_plus, sim_minus):
    if claim.kind == 'SAFE':
        return sim_plus.verify(claim)                  # 只信过近似
    if claim.kind == 'UNSAFE':
        return sim_minus.witness(claim)                # 只信欠近似
    raise ValueError('未声明方向的证书拒绝下发')

def disputed_zone(cert_plus, cex_minus):
    # ⊕ 认为安全、⊖ 找到反例 => 争议区，禁止静默选边
    if cert_plus.safe and cex_minus.exists:
        return Disputed(cert_plus, cex_minus, action=REAL_OR_HIFI_TEST)
    return None
```

def car_transition_guard_v9(e, x, cert, persona, lease, svc, t):

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |

## 6. 本轮最大风险

**一句话**：仿真-现实误差管 ρ 的估计依赖与模型同源的有限真机数据，而接触突变的非 Lipschitz 性会让 ρ^⊕ 爆炸到使 m > ρ^⊕ 恒不成立——「证书转移」要么空洞（ρ→∞ 永不下发）要么循环（用仿真验证仿真），整个 v21 可能退化为只能反驳、不能证明的反例机器。
