# 第 47 轮（承接第 46 轮产物 v23；本轮灵感：视觉伺服 × 轨迹优化） · Servo-Traj-Cert：视觉伺服可观测性证书驱动的轨迹优化与轨迹级证书管（五层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice 与第 45 轮 v10 Energy-Context-Depth。v10 把感知可信性升级为能量-上下文-深度联合调度下的逐帧姿态证书 P_t，v23 把交互安全性升级为记忆-语音-绑定闭环，但二者共享两个隐含假设：**H5：姿态证书是“点时刻”的，逐帧有效即可推出整条轨迹有效**；**H6：控制是在证书签发之后独立执行的，运动不会反过来改变可观测性**。在 UniBot 的真实 pick-and-place 与接近-对准任务里，这两条都不成立：视觉伺服直接以图像特征闭环，特征可能在中途出视野、被遮挡、因运动模糊失去纹理，交互矩阵可能因深度误差而病态；而轨迹优化若只看端点代价，就会主动选择“端点姿态证书很窄、但中途特征不可跟踪”的捷径。两个灵感词精确命中 H5/H6：**视觉伺服**把证书从位姿空间推进到图像特征空间，要求沿轨迹维持可观测性与收缩性；**轨迹优化**则提供了主动塑造可观测性的手段，也带来“证书必须对整段时间一致有效”的新约束。二者耦合出的核心问题是：**如何把逐帧姿态证书提升为对整条轨迹一致有效的证书管，并在能量租约与特征可观测性约束下联合优化轨迹、特征集与深度门控；当轨迹中段的可观测性静默退化时，如何保证视觉伺服不会在证书已失效的情况下继续执行。**

## 0. 直觉与动机

**灵感 1（视觉伺服 → 图像空间的可观测性证书）**
直觉：视觉伺服不是“先估位姿再动”，而是盯着图像特征动。它能不能收敛，不取决于当前位姿估得多准，而取决于三件事：特征还在不在画面里（可见性）、交互矩阵 L(s,Z) 是否病态（条件数）、深度误差与延迟是否让 ė=−λL̂⁺e 的收缩被噪声压过。因此“感知可信”必须新增一维：伺服证书 C^vs=(F, χ, κ(L̂), σ_Z, δ_lat, ρ, ε_ss, ℓ_vs)。
定义化（见定义 59–60）：若特征全可见、κ≤κ_max、δ_L≤δ_L,max、且 ρ^H‖e_0‖+ε_ss≤ε_s，则称伺服证书在时域 H 上 sound；它给出的不是“位姿对不对”，而是“图像误差能否在 H 内进入容差”。

**灵感 2（轨迹优化 → 把可观测性当成可优化的约束）**
直觉：既然特征可见性和交互矩阵条件数取决于相机与目标的相对运动，那么轨迹本身就能“买”可观测性：绕到正面、保持特征居中、避免贴近透明/镜面/弱纹理表面、控制速度以抑制运动模糊。反过来，轨迹优化也能“卖”掉可观测性换取更短时间——这正是危险所在。于是轨迹优化不应只优化任务代价与能耗，而应把伺服证书作为整条轨迹上的约束。
定义化（见定义 62）：OATO 在状态/控制轨迹 ξ、特征集 F、模态（深度开关）m(τ) 与伺服增益 λ 上联合优化
min w_T·T(ξ)+w_c·∫r_tube(τ)dτ+w_e·∫P_{m(τ)}dτ，
s.t. 动力学/关节限位、特征全程在视场、C^vs 在每个配点 sound、r_tube≤r_max、能量积分 B_t−∫P_m≥E_min。

**灵感 3（耦合 → 点证书到轨迹管的严格提升）**
直觉：逐帧证书无法直接拼接。两个相邻配点各自 P_k sound，并不意味着它们之间 sound：机械臂在两点之间可能瞬时加速、遮挡或模糊。必须用速度/加速度 Lipschitz 界把点证书“膨胀”成一段管，并用并集界把逐节点覆盖预算分配到整条轨迹。
定义化（见定义 61）：取配点 t_k=t+kδ，点证书半径 r_k，运动界 ‖ẋ‖≤v_max、‖ẍ‖≤a_max，则中间时刻
r_tube(τ)=r_k+v_max|τ−t_k|+½a_max(τ−t_k)²，τ∈[t_k,t_{k+1}]。
若每个节点覆盖≥1−α_p，则整条轨迹在 N=H/δ 个节点上的并集覆盖≥1−Nα_p；取 α_p=α_trj/N 即得轨迹级保证。

**耦合升级（v10/v23 → v11 五层）**：新增 **L5 伺服-轨迹证书层**。根信任层加入伺服租约 ℓ_vs 与轨迹证书；L1 几何层由 PSE 输出“点证书 + 运动膨胀管”；L2 上下文层为 OATO 提供特征/退化层先验与深度增益；L3 CAR 守卫改为“轨迹管前向不变 + 伺服门控”；L4 DCL 采集轨迹级失败（特征丢失、节点间违例、条件数塌缩）；ECPS 的能量租约升级为沿轨迹的积分预算。MVR/VAD/SAB 分别以特征配置、目标特征集、轨迹级绑定接入。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（图像伺服模型与交互矩阵不确定性）**
设图像特征 s∈R^{2k}，目标 s*，误差 e=s−s*。连续时间模型
ṡ=L(s,Z)v_c+η，L∈R^{2k×6}，
IBVS 控制 v_c=−λL̂(s,Ẑ)⁺e，η 为特征提取/标定/延迟噪声。
深度区间 Z_i∈[Z_i^−,Z_i^+]，L̂ 在名义深度 Ẑ 处求值。定义相对模型误差
δ_L=sup‖L−L̂‖/‖L‖，
任务子空间条件数 κ(L̂)=σ_max(L̂)/σ_min(L̂)（限制到 6 维任务子空间），特征可见性 χ_i∈{0,1}，控制延迟 δ_lat。
**关键**：深度越准，δ_L 与 κ 越小；这给了 v10 的深度门控一个全新的、可量化的收益通道。

**定义 60（伺服证书 C^vs 与收缩保证）**
C^vs_t=(F_t,χ_t,κ_t,δ_{L,t},σ_{Z,t},δ_{lat,t},ρ_t,ε_{ss,t},ℓ_vs)。
给定 δ_L≤δ_L,max、特征全可见，则对任意 e_0，
‖e(t+H)‖≤ρ^H‖e(t)‖+ε_ss，
其中 ρ=exp(−λ(1−δ_L)δ_t/2)，ε_ss=η/(√2·λ(1−δ_L))。
**伺服 soundness**：C^vs_t sound ⇔ χ=1 ∧ κ≤κ_max ∧ δ_L≤δ_L,max ∧ δ_lat≤δ_lat,max ∧ ρ^H‖e_t‖+ε_ss≤ε_s ∧ ℓ_vs 有效。ℓ_vs 绑定特征集版本、目标图像 s*、深度模型与标定版本；任一变更即失效。

**定义 61（轨迹级证书管 P^trj）**
轨迹 ξ 在 [t,t+H] 上以 δ 采样，N=H/δ。节点 k 有点证书 P_k=B(x̂_k,r_k) 与租约 ℓ_{p,k}。设运动界 ‖ẋ‖≤v_max、‖ẍ‖≤a_max。定义
P^trj(τ)=B(x̂_k, r_k+v_max|τ−t_k|+½a_max(τ−t_k)²)，τ∈[t_k,t_{k+1})。
**轨迹 soundness**：若 ∀k 节点覆盖≥1−α_p 且运动界成立，则
P(∀τ∈[t,t+H], X_τ∈P^trj(τ))≥1−Nα_p。
取 α_p=α_trj/N，即得以 α_trj 保证整条轨迹。**要点**：节点间不是靠“采样足够密”口头保证，而是靠运动界显式膨胀；实测速度/加速度越界必须立即判管失效。

**定义 62（伺服可观测性约束的轨迹优化 OATO）**
决策变量：轨迹 ξ（控制点/配点）、特征集 F、模态调度 m(τ)（是否开深度）、伺服增益 λ。
min_{ξ,F,m,λ} J=w_T·T(ξ)+w_c∫_t^{t+H} r_tube(τ)dτ+w_e∫_t^{t+H} P_{m(τ)}dτ+w_ab·N_abort
s.t. 动力学与关节限位；∀k: C^vs_{t_k}(ξ,F,m) sound；∀τ: s_i(ξ(τ))∈FOV；r_tube(τ)≤r_max；B_t−∫P_{m(τ)}dτ≥E_min；碰撞/安全谓词成立；并集覆盖预算 α_trj 满足。
F 与 m 是离散变量，用分支（枚举候选特征集/模态）外层 + SQP/SCP 内层求解；不可行时允许带罚松弛，但松弛解不得进入执行，只用于生成回退诊断。

**定义 63（证书保持的重规划与回退阶梯）**
定义监督裕度
M_t=min{κ_max−κ_t, δ_L,max−δ_{L,t}, σ_Z,max−σ_{Z,t}, r_max−r_tube(t), E(t)−E_min, min_i χ_i·m_vis,i}。
回退阶梯 a^(0..5)：
a^(0) 名义 OATO 轨迹；a^(1) 降速（γ=0.7，收窄管、抑制模糊）；a^(2) 开深度/再观测（降 σ_Z、δ_L、κ）；a^(3) 特征重选（换高纹理/更居中特征）；a^(4) 轨迹重规划（恢复视场/条件数）；a^(5) 安全停住/fail-closed。
**选择规则**：选满足所有证书与能量约束的最低档；若 M_t<2ε_trig 则提前触发重规划，若切换延迟 < ε_trig/L_M，则闭环过程中 M_t 不会跌破 0；否则直接 a^(5)。

## 2. 新增产出与既有 IP 升级

**IP-69 SERVO-CERT（图像伺服可观测性证书）**
- 特征可见性/纹理熵/运动模糊监控，FOV 与遮挡判定
- 交互矩阵条件数 κ(L̂) 与相对误差 δ_L 的深度区间估计
- 收缩因子 ρ、稳态误差 ε_ss、延迟补偿（Smith 预测）与 ℓ_vs 租约签发
- 特征重选：在候选特征子集上最大化“可观测性裕度/计算量”

**IP-70 TRJ-CERT（轨迹级证书管）**
- 点证书→轨迹管：速度/加速度膨胀 + 并集覆盖预算分配
- 节点间区间监控：实测 v、a 越界即判管失效
- 轨迹证书签发/续租/级联失效，绑定 τ_traj 与 α_trj
- 与 PSE 的点证书、CAR 的安全谓词联动

**IP-71 OATO（可观测性感知轨迹优化器）**
- 直接配点/SCP + 伺服证书约束 + FOV 约束 + 能量积分约束
- 外层分支特征集与深度模态，内层连续轨迹与增益
- 证书管目标（∫r_tube）与任务时间/能耗的 Pareto 前沿
- 不可行时生成回退阶梯诊断，而非直接执行松弛解

**既有 IP 升级**
IP-63 ECPS：效用改为“沿 H 的轨迹管收窄/能量积分”，深度开启的价值 = Δκ+Δδ_L+Δσ_Z 带来的可执行性提升
IP-60 PSE：输出点证书 + 运动膨胀管；半径随速度/加速度条件化
IP-61 DCL：采集轨迹级失败（特征丢失、节点间违例、条件数塌缩）、深度/特征上下文
IP-62 CCA：新增运动模糊、特征遮挡、对抗纹理、交互矩阵奇异、延迟与标定漂移红队
IP-51 CAR：守卫升级为“轨迹管前向不变 + C^vs sound + 能量积分可行”，任一失败→回退阶梯或 fail-closed
IP-66 MVR：记忆键加入特征配置/条件数/轨迹段，复用前须整段 C^vs sound
IP-67 VAD：语音目标→目标特征集 s*/关注区域，需求分布落到特征空间
IP-68 SAB：绑定检查从端点扩展到整条轨迹管，避免“端点安全、中途失效”
IP-45 总线：新增 servo-cert / traj-cert / feature-set / tube-violation / replan-trigger 话题

## 3. 算法骨架

每控制周期（OATO 低频重规划 + 监控高频执行）：
1. 由语音/任务得到目标特征 s*，由上下文层给出退化先验与深度增益预测
2. 枚举候选特征集 F 与深度模态 m，warm-start 轨迹 ξ0
3. 内层 SCP 求 (ξ,λ)，逐配点检查 C^vs、逐区间检查 r_tube、积分检查能量
4. 选最低代价可行解，用 α_p=α_trj/N 签发轨迹管 P^trj
5. 执行中每周期跑 tube_monitor：位置是否在管、实测 v/a 是否越界
6. 若 M_t<2ε_trig 或监控违例 → 按回退阶梯选最低可行档；无档可退 → safe-abort/fail-closed
7. 轨迹级失败回灌 DCL；κ/深度/能耗变更广播使旧证书级联失效

## 4. 本轮最大风险

**一句话**：轨迹管依赖 v_max、a_max 与交互矩阵条件数，而这些量恰恰由被认证的感知与执行系统估计；一旦高速段、透明/弱纹理表面或延迟突变使真实速度/深度误差超出保守界，节点处证书仍 sound、节点之间却已失效，视觉伺服会在“证书看似有效”的情况下丢特征并发散；因此必须用独立于认证器的保守运动界、节点间区间监控和不可退则 fail-closed 三重防线，绝不允许靠加密采样代替连续时间保证。

**定义 59（伺服模型）** ṡ=L(s,Z)v_c+η，v_c=−λL̂⁺e；δ_L=sup‖L−L̂‖/‖L‖，κ=cond(task-proj(L̂))，深度区间 Z∈[Z^−,Z^+]。

**定义 60（伺服证书与收缩）** C^vs=(F,χ,κ,δ_L,σ_Z,δ_lat,ρ,ε_ss,ℓ_vs)；ρ=exp(−λ(1−δ_L)δ_t/2)，ε_ss=η/(√2λ(1−δ_L))；sound ⇔ χ=1 ∧ κ≤κ_max ∧ δ_L≤δ_{L,max} ∧ δ_lat≤δ_{lat,max} ∧ ρ^H‖e‖+ε_ss≤ε_s ∧ ℓ_vs 有效。

**定义 61（轨迹管）** r_tube(τ)=r_k+v_max|τ−t_k|+½a_max(τ−t_k)²；P^trj(τ)=B(x̂_k,r_tube(τ))；若每节点覆盖≥1−α_p，则整轨迹覆盖≥1−Nα_p，取 α_p=α_trj/N。

**定义 62（OATO）** min_{ξ,F,m,λ} w_T·T(ξ)+w_c∫r_tube+w_e∫P_m+w_ab·N_abort，s.t. 动力学/关节/碰撞、∀k C^vs sound、特征全程 FOV、r_tube≤r_max、B_t−∫P_m≥E_min、并集预算 α_trj。

**定义 63（证书保持重规划）** M_t=min{κ裕度, δ_L裕度, σ_Z裕度, r_max−r_tube, E−E_min, 可见性裕度}；M_t<2ε_trig 触发重规划，按回退阶梯选最低可行档；无可行档→fail-closed。

## 2. 关键算法 伪代码

### IP-69 SVC（伺服证书）
```
def servo_certify(s, s_star, depth, F, calib, lam, H):
    chi = feature_visibility(s, F, calib.fov)
    if not all(chi):
        return None                       # 特征出视野/被遮挡

    Z_lo, Z_hi = depth_interval(F, depth, calib.sigma_z)
    L_hat = interaction_matrix(s, (Z_lo + Z_hi) / 2)
    L_lo  = interaction_matrix(s, Z_lo)
    L_hi  = interaction_matrix(s, Z_hi)
    delta_L = max(norm(L_hi - L_hat), norm(L_hat - L_lo)) \
              / max(norm(L_hat), EPS)
    kappa = cond(task_projection(L_hat))
    if kappa > calib.kappa_max or delta_L > calib.delta_L_max:
        return None                       # 交互矩阵病态/深度不确定过大

    alpha = lam * (1 - delta_L) / 2
    rho = exp(-alpha * calib.dt)
    eps_ss = calib.eta / sqrt(2 * lam * (1 - delta_L))
    n = int(H / calib.dt)
    if rho**n * norm(s - s_star) + eps_ss > calib.eps_s:
        return None                       # 时域内进不了容差

    lease = calib.lease.bind(F, s_star, depth.version)
    return ServoCert(F, chi, kappa, delta_L, eps_ss, rho, lease)
```

### IP-70 TRT（轨迹级证书管）
```
def trajectory_tube(nodes, calib, H, delta, alpha_trj):
    N = max(1, int(H / delta))
    alpha_p = alpha_trj / N               # 并集界预算分配
    segs = []
    for nd in nodes:
        Pk = pose_certify(nd.x_hat, nd.obs, alpha_p)
        if Pk is None or not Pk.lease.valid(nd.t + delta):
            return None
        r_end = Pk.radius + calib.v_max * delta \
                + 0.5 * calib.a_max * delta**2
        if r_end > calib.r_max:
            return None                   # 运动膨胀后超任务容差
        segs.append(TubeSegment(nd.t, nd.t + delta,
                                nd.x_hat, Pk.radius, Pk.lease))
    return TrajectoryCert(segs, alpha_trj, calib)

def tube_radius(seg, tau, calib):
    d = tau - seg.t0
    return seg.r0 + calib.v_max*d + 0.5*calib.a_max*d*d

def tube_monitor(x_meas, v_meas, a_meas, cert, calib, t):
    seg = cert.segment_at(t)
    if seg is None:
        return 'expired'
    if norm(x_meas - seg.center) > tube_radius(seg, t, calib):
        return 'position_violation'
    if norm(v_meas) > calib.v_max or norm(a_meas) > calib.a_max:
        return 'motion_bound_exceeded'    # 节点间连续界被破坏
    return 'ok'
```

### IP-71 OTO（可观测性感知轨迹优化）
```
def oato(c_t, B_t, s_star, F0, calib, H):
    best = None
    for F in feature_candidates(c_t, F0):          # 外层：离散特征集
        for m in modality_candidates(c_t, B_t):    # 外层：深度开/关等
            xi, lam = solve_scp(
                warm_start(c_t, s_star, F, m),
                constraints=[
                    dynamics(), joint_limits(), collision(),
                    fov(F), servo_sound(F, m),
                    tube_le_r_max(m),
                    energy_integral(B_t, m, calib.E_min),
                    alpha_budget(calib.alpha_trj)],
                cost=lambda x, l: (
                    calib.w_T * T(x)
                    + calib.w_c * integral(
                        tube_radius_pred(x, m), t, t + H)
                    + calib.w_e * integral(calib.P[m], t, t + H)))
            if xi is None:
                continue
            J = (calib.w_T * T(xi)
                 + calib.w_c * J_tube(xi, m)
                 + calib.w_e * J_energy(m))
            if best is None or J < best.J:
                best = Candidate(xi, lam, F, m, J)
    return best                                    # None => 无可行轨迹
```

### 证书保持执行与回退阶梯
```
def cert_preserving_execute(c_t, B_t, s_star, F0, calib):
    plan = None
    for level in range(6):
        if level == 0:
            plan = oato(c_t, B_t, s_star, F0, calib, calib.H)
        elif level == 1:
            plan = retime(plan, gamma=0.7) if plan else None
        elif level == 2:
            plan = oato(c_t, B_t, s_star, F0,
                        calib.with_depth(), calib.H)
        elif level == 3:
            F1 = reselect_features(c_t, s_star, calib)
            plan = oato(c_t, B_t, s_star, F1, calib, calib.H)
        elif level == 4:
            plan = oato(c_t, B_t, s_star, F0,
                        calib.with_new_horizon(), calib.H)
        else:
            return 'fail-closed', 'no_certified_trajectory'

        if plan is None:
            continue
        cert = trajectory_tube(plan.nodes, calib, calib.H,
                               calib.delta, calib.alpha_trj)
        if cert is None:
            continue
        if all(servo_certify(nd.s, s_star, nd.depth, plan.F,
                             calib, plan.lam, calib.H)
               for nd in plan.nodes):
            return (plan, cert, level)
    return 'fail-closed', 'no_certified_trajectory'

def run_closed_loop(c_t, B_t, s_star, F0, calib):
    plan, cert, level = cert_preserving_execute(
        c_t, B_t, s_star, F0, calib)
    if cert is None:
        return 'fail-closed'

    while executing(plan):
        st = tube_monitor(measure_x(), measure_v(), measure_a(),
                          cert, calib, now())
        if st != 'ok' or margin(cert, now()) < 2 * calib.eps_trig:
            broadcast_invalidate(cert)      # 旧轨迹管级联失效
            plan, cert, level = cert_preserving_execute(
                c_t, B_t, s_star, plan.F, calib)
            if cert is None:
                return 'safe-abort'
        dcl_ingest(trajectory_outcome(plan, st))
        execute_servo(plan, now())
    return 'ok'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IP-69 SVC | O(k^3)（2k×6 的 SVD/条件数）+ O(k) | O(k) | κ、δ_L、ρ、ε_ss 满足界 ⇒ 图像误差在 H 内进容差 |
| IP-70 TRT | O(N) 建管；O(1) 每次监控 | O(N) | 运动界成立 + 并集界 ⇒ 整轨迹覆盖≥1−α_trj |
| IP-71 OTO | O(|F|·|M|·S·C_inner) | O(|F|·N) | 约束满足 ⇒ 轨迹、特征、深度、能量联合可行 |
| 回退执行 | 最坏 O(6·OTO) | O(N) | 每档都重签证书；无档可退 ⇒ fail-closed |
| 全局闭环 | 由低频 OTO 主导 | O(N+|M|) | 监控违例/裕度不足必触发重签或停住 |

**命题 1（轨迹管 soundness / 并集界）**
设每个配点姿态证书覆盖 Pr(X_{t_k}∈P_k)≥1−α_p，且真实运动满足 ‖ẋ‖≤v_max、‖ẍ‖≤a_max。则对 τ∈[t_k,t_{k+1}]，
‖X_τ−x̂_k‖≤‖X_τ−X_{t_k}‖+‖X_{t_k}−x̂_k‖≤v_maxδ+½a_maxδ²+r_k。
因此事件 {X_τ∉P^trj(τ)} ⊆ ∪_k {X_{t_k}∉P_k}。由并集界（无需独立性）得
Pr(∀τ, X_τ∈P^trj(τ))≥1−Nα_p。
令 α_p=α_trj/N 即得证。**代价**：Boole 界对 N 线性保守，故需在“配点更少”与“单点更紧”之间权衡；可用自适应 α 分配或任意时刻 e-process 收紧紧度，但不得取消连续界。

**命题 2（有界交互矩阵误差下的伺服收缩）**
设特征可见，L(s,Z) 在任务子空间满列秩，且 ‖L−L̂‖/‖L‖≤δ_L，则在任务子空间 L L̂⁺⪰(1−δ_L)I。取 V=½‖e‖²，有
V̇=eᵀ(−λL L̂⁺e+η)≤−λ(1−δ_L)‖e‖²+‖e‖‖η‖
≤−(λ(1−δ_L)/2)‖e‖²+η²/(2λ(1−δ_L))。
故 ‖e(t)‖≤e^{−λ(1−δ_L)t/2}‖e(0)‖+η/(√2λ(1−δ_L))，即定义 60 的 ρ、ε_ss 成立。注意：若 κ 超界或特征接近奇异，满列秩与下界假设失效，故 κ、δ_L 必须作为证书显式检查，而不能只检查“特征数够不够”。

**命题 3（证书保持重规划的前向不变性）**
设裕度 M_t 关于时间 Lipschitz 常数 L_M，监督器在 M_t≤2ε_trig 时触发重规划，且从触发到新轨迹生效的延迟 ≤ε_trig/L_M，新轨迹在起点满足 M≥2ε_trig。则在切换期间 M_t 最多下降 ε_trig，仍 ≥ε_trig>0；切换后恢复到 ≥2ε_trig。因此安全集 {M_t≥0} 在监督切换下前向不变。若 OATO/回退阶梯找不到满足条件的轨迹，则必须进入 a^(5) fail-closed，而不是执行带罚松弛解。该命题依赖“延迟有界”和“切换可原子化”，异步总线需 epoch/generation 校验，否则前向不变性不成立。

**命题 4（能量积分可行性）**
若每个模态的实测功率不超过标定上界 P_m，且 ∫_t^{t+H}P_{m(τ)}dτ≤B_t−E_min，则对任意 τ∈[t,t+H]，E(τ)≥E_min，沿轨迹不发生能量租约级联失效；若实测功率超上界，监控器立即判该轨迹管失效并按定义 63 重规划。该命题把 v10 的瞬时能量判据升级为轨迹级积分预算。

## 6. 本轮最大风险

**一句话**：轨迹管依赖 v_max、a_max 与交互矩阵条件数，而这些量恰恰由被认证的感知与执行系统估计；一旦高速段、透明/弱纹理表面或延迟突变使真实速度/深度误差超出保守界，节点处证书仍 sound、节点之间却已失效，视觉伺服会在“证书看似有效”的情况下丢特征并发散；因此必须用独立于认证器的保守运动界、节点间区间监控和不可退则 fail-closed 三重防线，绝不允许靠加密采样代替连续时间保证。
