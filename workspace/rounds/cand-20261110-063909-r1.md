# 第 42 轮（新循环第 2 轮） · 激光雷达 × UniBot：给证书补上「感知地基」与「跨具身可移植性」（四层架构 v7）

> 承接第 41 轮 v18（运行时证书自动机 CAR × 轻量分层认证 LCS × 证书监控编译器 CMC）。第 41 轮把证书从静态文档变成了可执行的转移守卫，但它仍默认了两个未言明的前提：**(A) 几何证据是真的**（地图、位姿、自由空间可信），**(B) 证书只对当前这台本体成立**。本轮灵感词「激光雷达」「UniBot」恰好各拆掉一个前提：激光雷达逼我们为感知本身发证书，UniBot 逼我们回答「一套统一栈凭什么在异构本体上仍然可认证」。这轮不是再加一层功能，而是给 v18 的证书体系补上**证据来源**与**迁移语义**。

## 0. 直觉与动机

**灵感 1（激光雷达 → 证书不能建在「真值地图」的沙地上）**：v18 的 `ValidRegion`、几何边际、漂移界 B_t 全部把点云当成可靠标尺。但激光雷达最危险的失效不是「坏点」，而是**各向异性退化**：长走廊、隧道、玻璃幕墙、雨雾烟尘、大片动态遮挡会让点-面配准的 Hessian 在某个方向上特征值趋近 0——此时位姿在那个方向几乎不可观测，地图会「看起来连续」却整体缓慢滑移。更隐蔽的是**未知空间**：障碍物背后没有回波，不代表那里是自由空间；把未知当自由，是比把自由当障碍更致命的方向性错误。因此直觉是：证书要向下追一层，增加 **LiDAR 可观测性证书（哪些方向可信、误差椭球多大）** 与 **已知自由空间证书（哪里真的看过、看过几次、入射角多大、多久没看）**；几何边际在进入守卫前必须先按位姿误差和未知空间打折。感知不再是被信任的输入，而是**被认证的证据**。

**灵感 2（UniBot → 「统一」不等于「同一张证书」）**：UniBot 代表的统一机器人/跨具身平台，最有价值的承诺是一套技能与安全栈可跨形态复用。但数值证书不可直接搬运：同一参考轨迹，轮式、四足、人形、机械臂的跟踪误差、包络半径、可达集都不同。直觉上正确的抽象是**证书模式（schema）而非证书数值**：把安全核心写在所有本体共享的任务帧 Z 中（世界系下的带符号距离、相对物体位姿），每个本体只贡献一个**适配器**——跟踪误差界 δ_b 与包络参数——以及「参考轨迹在 Z 中留出 δ_b 余量 ⇒ 真实本体安全」的证明。跨本体复用因此变成一个可检验的 **ε-仿真**问题：结构相同、守卫余量差 ε、不变式按 ε 平移；ε 超过余量就必须重认证，而不是假装统一。

**耦合（激光雷达是跨具身共同的尺子，也是共同的单点故障）**：UniBot 的跨本体迁移需要一个共同坐标系，激光雷达建出的共享度量语义图 C_ms 正好提供这个锚点；于是 δ_b 里自然包含本体位姿误差与地图漂移。反过来，LiDAR 一旦退化，e_loc 与 B_t 同时变大，ε-仿真的余量被吃掉，跨本体复用必须被**主动关闭**并回退到单本体局部证书。两条灵感由此咬合：激光雷达让证书有地基，UniBot 让地基必须可迁移；任何一个失效都通过感知条件守卫转化为可观测的降级，而不是无声的不安全。

## 1. 形式化定义

**定义 32（LiDAR 可观测性证书 LOC）**：设 t 时刻扫描 S_t 与地图 M_t 的对应点残差 r_i=n_iᵀ(Rp_i+t−q_i)，堆叠雅可比 J_i=[(p_i×n_i)ᵀ, n_iᵀ]∈R^{1×6}，加权 Hessian H_t=Σ_i w_iJ_iᵀJ_i。特征分解 H_t=Σ_k λ_k u_ku_kᵀ。在残差噪声尺度 σ_t 与模型偏差 β_t（离散化、动态物体、反射）下，位姿误差 ξ_t 沿方向 u_k 的置信 1−δ 界为 e_k=χ_{6,1−δ}(σ_t/√λ_k)+β_t，且 ξ_t 以概率 1−δ 落在椭球 E_t={ξ:Σ_k(u_kᵀξ)²/e_k²≤1}。**LOC 证书** D_t=({λ_k,u_k,e_k}ₖ, ρ_t, β_t, t₀, δ)，ρ_t 为内点率。只有当守卫所需的位移/力方向在**可观测方向集** K_ε={k:λ_k≥λ_min} 上分量足够时，D_t 才被称为「对该守卫充分」。

**定义 33（已知自由空间证书 FSC）**：把空间分为已知自由 F_t、占据 O_t、未知 U_t。F_t={v:h(v)≥h_min, α(v)≤α_max, age(v)≤τ_age}，其中 h(v) 为穿过 v 的独立回波数、α(v) 为最大入射角、age(v) 为最近观测龄期；O_t 由占据证据给出；其余为 U_t。**FSC 的单边可靠性**：在传感器模型下，F_t 中不存在面积超过 A_min 的未观测障碍面；U_t 一律按保守占据处理。轨迹管道 T_{r_b}(π)（r_b 为本体膨胀半径）合法当且仅当 T_{r_b}(π)⊆F_t 且 T_{r_b}(π)∩O_t^{infl}=∅；**只看「不撞 O_t」是不够的，必须证明整条管道都在 F_t 内**。

**定义 34（感知条件守卫 PCG）**：原守卫 g_e(x)=m_e(x)−θ_e 升级为
g_e^{perc}(x,D_t,F_t)=m_e(x)−L_e(e_pose(D_t)+B_t)−L_f·dist(T_{r_b}(π),U_t)−θ_e，
其中 L_e 是边际对几何误差的 Lipschitz 常数，L_f 是边际对未知空间距离的敏感度，e_pose(D_t)=max_k e_k（或按方向投影）。**单调保守性强化**：若 D_t 过期、K_ε 不覆盖所需方向、或 F_t 在管道上不完整，则 g_e^{perc} 视为未定义/为负，转移只能指向 Degraded/SafeStop，绝不指向 Nominal。

**定义 35（跨具身证书模式 CCS 与适配器）**：设共享任务帧 Z，本体 b 的特征映射 ψ_b:X_b→Z。核心证书 C_core=(m_core,L_core,θ,T_hold) 定义在 Z 上（如世界系带符号距离、相对物体位姿）。适配器 A_b=(δ_b,E_b) 证明：对本体可达包络 E_b 内的任意参考 z_ref 与执行，真实状态满足 |ψ_b(x_b)−z_ref|≤δ_b，且 δ_b 可分解为 δ_b=δ_track,b+e_loc,b+B_t（跟踪 + 定位 + 地图漂移）。于是若 m_core(z_ref)≥θ+L_coreδ_b，则本体 b 实际安全。**跨本体传输 b→b′**：同一 z_ref 的证书可复用时需 m_core(z_ref)≥θ+L_core·max(δ_b,δ_{b′})；若只移植为 b 标定的余量，则传输缺陷 ε_{b→b′}=L_core|δ_b−δ_{b′}| 必须从余量中扣除。**「统一」= 一个 schema + 一组被认证的适配器，而不是一个共享的数值界。**

**定义 36（ε-仿真自动机与迁移可靠性）**：H_b⊑_ε H_{b′} 当且仅当存在关系 R 使 (x,x′)∈R ⇒ |m_b(x)−m_{b′}(x′)|≤ε，且 H_b 的每条转移都能被 H_{b′} 在守卫松弛 ε、不变式按 ε 平移后匹配。**命题**：若 H_b⊑_ε H_{b′} 且 H_b 的不变式 I_b 含余量 ε，则 I_b 平移后是 H_{b′} 的归纳不变式；若余量小于 ε，迁移不安全，必须重认证或降低制度。LiDAR 锚定把 ε 具体化为 ε_{b→b′}≤L_core(δ_b+δ_{b′})，并随 D_t 全域退化而增大。

## 2. 三大产出设计

### 2.1 IP-54 LIDAR-INTEGRITY-CERT（激光雷达完整性证书 LIC）
1. 逐帧点-面配准 Hessian 与特征分解，输出可观测方向、逐方向误差界 e_k、内点率 ρ_t、模型偏差 β_t；退化方向（λ_k<λ_min）显式标红。
2. 稳健噪声/偏差估计：MAD 残差尺度、动态物体剔除、玻璃/高反射的入射角与强度一致性检验；用分段标定给出 β_t 上界。
3. 已知自由空间证书：射线穿越计数、入射角、龄期、独立回波数，产出 F_t/O_t/U_t；未知一律保守占据。
4. 证据融合：LOC/FSC 同时喂给 ValidRegion、B_t 与 L_m；管道级自由空间检查替代点级避障。
5. 单边可靠性：LOC/FSC 只给保守下界，任何不确定都映射为「更保守方向」，与 IP-53 看门狗共用区间算术。

### 2.2 IP-55 CROSS-EMBODIMENT-CERT-TRANSPORT（跨具身证书传输 CECT）
1. 定义共享任务帧 Z 与本体特征映射 ψ_b；核心证书 m_core 与 θ 放在 Z，本体的形态差异全部进入适配器 A_b。
2. 适配器证书：跟踪误差 δ_track,b（接 IP-48 流策略跟踪界）、定位误差 e_loc,b（接 IP-54）、地图漂移 B_t；给出 δ_b 的合成上界与有效期。
3. ε-仿真检查：对技能组合的乘积自动机做守卫松弛与不变式平移检查；给出可复用/需重认证/禁止复用三值判定。
4. 跨本体预算：只有 max(δ_b,δ_b′) 留出余量时才复用同一 z_ref；否则按 δ 差值收紧参考（缩放速度/加大 clearance）或触发 RCA 重颁。
5. UniBot 实例化：一个 schema、N 个适配器；新增本体只补 A_b 与仿真检查，不改核心栈；LiDAR 共享图作为公共锚点，退化时自动退化为单本体局部证书。

### 2.3 IP-56 PERCEPTION-CONDITIONED-GUARD（感知条件守卫 PCG）
1. 把 LOC/FSC 编译进守卫：几何边际先扣除 L_e(e_pose+B_t) 与未知空间折扣 L_f·dist(·,U_t)，再做阈值比较。
2. 方向性门控：只允许沿可观测方向做 Nominal 转移；退化方向上的转移强制经 Watch/Degraded 并以低速/短保持时间试探。
3. 与 CAR/LCS 融合：感知证书作为一条新的守卫维度参与决策等价精化；U≠∅ 时优先精化「感知敏感」守卫。
4. 与 CMC 融合：把 LOC/FSC 检查编译为定点看门狗，WCET 与内存纳入 E77；trip 直接 SafeStop。
5. 可检查推导链：每个感知折扣都附带 Hessian 特征值、残差尺度、自由空间计数与置信参数，便于离线复核。

## 4. 实验设计（E79–E84 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E79 LiDAR 可观测性证书 | 退化检测 AUC；误差椭球覆盖率；误判 safe 次数 | AUC≥0.95；覆盖率≥99%；误 safe=0 |
| E80 已知自由空间证书 | 未知空间违规次数；安全相关管道覆盖率；虚警率 | 0 违规；覆盖≥95%；虚警<1% |

回退路径：E79 不通过（椭球不覆盖真误差）→ 增大 β_t/χ² 并只用保守方向，必要时退回纯避障而非几何证书；E80 不通过（未知空间仍被穿越）→ 只允许 O_t 外的已验证管道，速度上限减半；E81 不通过（跨本体迁移不 sound）→ 禁用 ε-仿真复用，UniBot 退化为逐本体独立认证；E84 退化超阈 → 关闭跨站点迁移，先保安全再谈统一。

## 5. 本轮最大风险

**一句话**：最大的风险是「统一性幻觉」——把共享 schema 当成共享证书、把 LiDAR 建出的地图当成共同真值，于是在 LiDAR 退化或新本体动力学超出适配器包络时，得到一张看似可认证、实则在未验证区域悄悄失效的安全网；因此必须让感知折扣与 ε-仿真余量在守卫处显式相减，余量不足即拒绝迁移。

## 1. 符号体系（承接定义 32–36）

## 2. 关键算法（伪代码）

### IP-54 LIC：可观测性证书与自由空间证书
```
def lidar_cert(scan, map):
    C = correspondences(scan, map)
    C, rho = robust_reject(C)                    # 动态物体/MAD 残差
    H = sum(w_i * outer(J_i, J_i) for i in C)
    lam, U = eigh(H)                             # lam 升序
    sigma = mad_scale(residuals(C))
    beta = model_bias_bound(scan, map)           # 反射/玻璃/离散化
    e = [chi2(6, 1-delta) * sigma / sqrt(l) + beta for l in lam]
    D = LocCert(lam, U, e, rho, beta, t0=now, delta=delta)
    F, O, Uu = raycast_space(scan, map,
                             h_min, alpha_max, tau_age)
    return D, SpaceCert(F, O, Uu)                # Uu 一律保守占据

def guard_observable(D, g):
    need = required_directions(g)
    return all(k in D.K_eps for k in need) and not expired(D)
```

### IP-55 CECT：跨具身适配器与 ε-仿真
```
def transport(core, b, b2, z_ref, D, B):
    delta_b  = track_bound(b) + loc_bound(D, b) + B
    delta_b2 = track_bound(b2) + loc_bound(D, b2) + B
    need = core.theta + core.L_core * max(delta_b, delta_b2)
    if core.m_core(z_ref) < need:
        return REJECT                        # 余量不足，禁止复用
    eps = core.L_core * abs(delta_b - delta_b2)
    if eps > core.m_core(z_ref) - need:
        return RECERTIFY                     # 可尝试收紧参考后重认证
    return REUSE, eps

def eps_simulation(Hb, Hb2, eps):            # 守卫松弛 + 不变式平移
    return all(match(e, e2, eps) for e in Hb.E for e2 in Hb2.E)
```

### IP-56 PCG：感知折扣守卫与看门狗
```
def guard_perc(x, D, S, e_guard):
    e_pose = max(D.e) if guard_observable(D, e_guard) else INF
    discount = e_guard.L_e * (e_pose + e_guard.B_t)
    unknown  = e_guard.L_f * dist(tube(x), S.U)
    return e_guard.m(x) - discount - unknown - e_guard.theta

def compile_perc_guard(e_guard):
    circuit = interval_arith(e_guard.discount, fixed)   # 含舍入
    return Monitor(circuit,
                   trip_if = lower(circuit) < e_guard.theta,
                   wcet    = bound_wcet(circuit),
                   mem     = bound_mem(circuit))
```

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 统一性幻觉：schema 被误当共享证书 | 高 | 核心/适配器分离；ε-仿真三值判定；余量不足即拒绝复用；E81 以 soundness 守门 |
| LiDAR 退化误判或椭球不覆盖真误差 | 高 | 稳健残差 + 模型偏差 β_t + χ² 置信；退化方向强制降级；E79 设误 safe=0 |
| 未知空间被当自由（方向性致命错误） | 高 | F_t 单边可靠性；管道级 T⊆F_t；U_t 保守占据；E80 零违规 |
| δ_b 过松 → 长期 Degraded/可用性下降 | 中 | 分段/局部跟踪界；自适应 N*；Degraded 中间档；E82/E83 联合作守门 |
| ε 在边界附近抖动导致反复迁移 | 中 | 滞回 + τ_min；把边界拍计入 Watch；迁移预算限频 |
| Hessian 特征分解与看门狗算力 | 中 | 采样/增量 eigh；L0 采样档；定点区间算术；超预算下放 |
| 动态物体造成配准污染 | 中 | 稳健剔除 + 多帧一致性；动态区域标为 U_t 而非 F_t |
| 多本体参数标定成本 | 中 | 适配器模板 + 少量真机标定；仿真先验 + 在线更新 |

## 6. 本轮最大风险

**一句话**：最大的风险是「统一性幻觉」——共享 schema 不等于共享证书，LiDAR 地图也不等于共同真值；一旦在感知退化区或适配器包络外静默复用，系统会在「看起来可认证」的地方失效。因此必须让感知折扣与 ε 余量在守卫处显式相减，余量不足即拒绝迁移。
