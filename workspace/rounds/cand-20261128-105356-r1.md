### 第 8 轮灵感驱动研究记录（新循环第 1 轮，继承 CADVS-v7）

**灵感词**：视觉语言模型、语义分割

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）把系统从「指令响应」推进到「需求意图推导」，用 DIM/DRC/DAC 在软因子层补上了「用户到底想要什么」。但它留下一个结构性缺口：ρ_demand 与推理链都停留在**语言-向量层**——系统知道「要拿杯子、要稳妥」，却不知道「当前画面里哪一块像素是杯子、哪一条边界不能碰」。本轮（新循环第 1 轮）以「视觉语言模型」「语义分割」为灵感，提出「**视觉-语义接地桥**」(Visual-Semantic Grounding Bridge)：让 VLM 负责**开放词表提议**，让语义分割负责**像素级裁决**，二者的一致性被编译进既有 GGC 几何硬门，而**不新增任何硬门**。核心口号：**VLM 提议、分割裁决、硬门处置**。

**直觉与动机**：

1. **视觉语言模型 → 从「文本意图」到「开放词表接地」**。v7 的 ρ_demand 是抽象向量，无法回答「红色杯子在画面哪里」。VLM 能以指令为条件输出区域提议（box/mask）与接地嵌入 g_vlm，支持「像鱼一样的东西」这类开放词表指代。关键洞见是：**VLM 只能当『提议者』，不能当『裁决者』**——它幻觉丰富、校准差，若直接驱动执行会破坏 fail-closed。故 VLM 输出必须被分割与几何硬门复核。

2. **语义分割 → 从「稀疏框」到「稠密裁决」**。语义/部件分割给出逐像素、几何对齐的标签，天然可验证：它能把目标切成 handle/rim/body，把「人手、易碎物、液体」划为 keep-out 区。关键洞见是：**分割是 VLM 的『几何裁判』**——VLM 说「那是杯子」，分割说「这些像素属于杯子、那些属于桌面与人手」；二者 IoU 就是可审计的接地证书。分割同时把 GGC 的接触点约束从「物体级」细化到「部件级」，把碰撞约束从「几何碰撞」升级为「语义禁入」。

3. **从「一致性评分」到「证据编译」**。v7 的教训是：每轮加一个软因子、再加一个新硬门，会把证书边界越堆越脆（R59 接口漂移）。本轮主张**零新增硬门**：把「VLM-分割一致性」与「接触合法 / 禁入不相交」作为**合取项编译进既有 GGC 谓词**，得到 GGC_v8 = GGC_v7 ∧ kc_ground ∧ contact⊆A_contact ∧ swept∩Ω_keepout=∅。硬门数量仍是 7，但几何门被像素级证据强化。

**关键洞见**：v6 回答「物理/空间/意图可行」，v7 回答「用户真正想要什么」，v8 回答「**当前画面里，凭什么像素证据相信这个行为是对的**」。七硬门 kc_evidence_forged_v5 记号原样复用；本轮新增的只有：
- IP-505 VLMG（视觉语言接地器），
- IP-506 PSM（部件级语义掩码器），
- IP-507 GAB（接地可供性桥，含歧义再查询），
- IP-508 EFA-v8（软因子链扩至 η_ground、η_seg，接地证书编译进 GGC）

**形式化目标（增量）**：

1. **VLMG（Vision-Language Model Grounder）**：<br>
   - VLM: (I, L, ρ_demand) ⟼ G = {(m̂_i, ℓ_i, s_i)} ∪ {g_vlm}，仅保留 s_i ≥ τ_vlm；<br>
   - 接地一致性 IoU_i = |m̂_i ∩ M_target| / |m̂_i ∪ M_target|；<br>
   - 软因子 η_ground = 1 + ε_g·clip((IoU* − τ_ground)/(1 − τ_ground), 0, 1) ∈ [1, 1+ε_g]。

2. **PSM（Part-aware Semantic Masker）**：<br>
   - S: I ⟼ {M_part}，导出目标掩码 M_target、可抓取接触区 A_contact、语义禁入区 Ω_keepout；<br>
   - 掩码置信 conf_seg = mean_{p∈M_target} max_c p_c(p)；<br>
   - 软因子 η_seg = 1 + ε_s·clip((conf_seg − τ_seg)/(1 − τ_seg), 0, 1) ∈ [1, 1+ε_s]。

3. **GAB（Grounded Affordance Bridge）**：<br>
   - g_ga = Fuse(g_vlm, E_part(M_target), ρ_demand)；<br>
   - 若 IoU* < τ_ground：以 M_target 作分割提示触发**一次**再查询；仍失败则回退 v7 需求路径，不改任何硬门。

4. **接地证书编译（零新增硬门）**：<br>
   - kc_ground := ∃i [IoU_i ≥ τ_ground ∧ ℓ_i 与 M_target 标签一致 ∧ s_i ≥ τ_vlm]；<br>
   - GGC_v8(x) := GGC_v7(x) ∧ kc_ground ∧ contact(x) ⊆ A_contact ∧ swept(x) ∩ Ω_keepout = ∅。

5. **EFA-v8**：<br>
   - ECS_v8 = ECS_v7 · η_ground · η_seg；<br>
   - τ_i^v8 = γ_i·τ_i^v7·Π_factor_i，Π_factor_i = ∏_j η_j ∈ [1, 1.3]；<br>
   - 硬门数 |G_v8| = |G_v7| = 7（kc_ground 是 GGC 的内部合取项，不是新的顶层门）。

**本轮最大风险**：**相关失效下的『共识幻觉』**：VLM 与语义分割共享视觉骨干与训练分布，在 OOD（新物体、遮挡、逆光）下可能**一起错**——两者把桌面误判为目标、IoU 反而很高，于是 kc_ground 给出「虚假接地证书」，而七硬门越严反而越像「已严格验证」。这种相关失效在结构上无法靠一致性检验捕获。

## 2. 关键算法骨架

### IP-505 VLMG：视觉语言接地器

```python
@dataclass
class VLMBasedGrounder:
    """VLMG：以指令 + 需求为条件，输出开放词表区域提议与接地嵌入。
    只做『提议』，不做『裁决』；裁决交给 PSM 与 GGC_v8。"""
    vlm: VisionLanguageModel
    tau_vlm: float = 0.5
    tau_ground: float = 0.75
    eps_g: float = 0.1

    def ground(self, image, L: str, rho_demand: torch.Tensor):
        prompt = self.build_prompt(L, rho_demand)      # 需求条件化，抑制过度泛化
        out = self.vlm.ground(image, prompt)           # {proposals, embedding}
        props = [p for p in out.proposals if p.score >= self.tau_vlm]
        props.sort(key=lambda p: p.score, reverse=True)
        return props, out.embedding                    # g_vlm

    def grounding_factor(self, best_iou: float) -> float:
        """η_ground ∈ [1, 1+ε_g]；未达阈值时返回 1.0（由硬门拦截）。"""
        if best_iou < self.tau_ground:
            return 1.0
        u = (best_iou - self.tau_ground) / (1.0 - self.tau_ground)
        return 1.0 + self.eps_g * min(1.0, max(0.0, u))
```

### IP-506 PSM：部件级语义掩码器

```python
@dataclass
class PartSemanticMasker:
    """PSM：逐像素语义/部件分割，导出目标掩码、接触合法区、语义禁入区。
    分割是 VLM 的『几何裁判』，同时把 GGC 约束细化到部件级。"""
    seg: SegmentationModel
    graspable_parts: set[str] = field(default_factory=lambda: {"handle", "rim", "body"})
    keepout_labels: set[str] = field(default_factory=lambda: {"human_hand", "fragile", "liquid"})
    tau_seg: float = 0.7
    eps_s: float = 0.1

    def segment(self, image, depth) -> "SegmentEvidence":
        logits = self.seg(image, depth)                # [C, H, W]
        prob = torch.softmax(logits, dim=0)
        masks = self._parts_from_logits(prob)          # {label: bool mask}
        M_target = self._union(masks, self.graspable_parts) | self._union(masks, {"target"})
        A_contact = self._union(masks, self.graspable_parts) & M_target
        Omega_keepout = self._union(masks, self.keepout_labels)
        conf_seg = prob.max(dim=0).values[M_target].mean().item() if M_target.any() else 0.0
        eta_seg = self._factor(conf_seg)
        return SegmentEvidence(M_target, A_contact, Omega_keepout,
                               masks, conf_seg, eta_seg)

    def _factor(self, conf: float) -> float:
        if conf < self.tau_seg:
            return 1.0
        u = (conf - self.tau_seg) / (1.0 - self.tau_seg)
        return 1.0 + self.eps_s * min(1.0, max(0.0, u))
```

### IP-507 GAB：接地可供性桥

```python
@dataclass
class GroundedAffordanceBridge:
    """GAB：融合 VLM 提议与分割证据，检测歧义并做一次再查询。"""
    vlm_grounder: VLMBasedGrounder
    masker: PartSemanticMasker
    fusion: nn.Module
    tau_ground: float = 0.75

    def fuse(self, image, depth, L: str, rho_demand) -> "GroundedContext":
        props, g_vlm = self.vlm_grounder.ground(image, L, rho_demand)
        seg = self.masker.segment(image, depth)

        best, best_iou = self._best_match(props, seg.M_target)
        grounded = best is not None and best_iou >= self.tau_ground

        if not grounded:
            # 一次再查询：把分割掩码作为视觉提示回灌 VLM（不新增硬门）
            props2, g_vlm2 = self.vlm_grounder.ground(
                image, L + " [mask-hint]", rho_demand)
            best, best_iou = self._best_match(props2, seg.M_target)
            grounded = best is not None and best_iou >= self.tau_ground
            if grounded:
                g_vlm = g_vlm2

        eta_ground = self.vlm_grounder.grounding_factor(best_iou)
        if not grounded:
            # 接地失败：交由 EFA-v8 回退 v7 需求路径，绝不进入 GGC_v8
            return GroundedContext(g_vlm, seg, eta_ground, grounded=False, best=None)

        g_ga = self.fusion(g_vlm, self._encode_parts(seg), rho_demand)
        return GroundedContext(g_ga, seg, eta_ground, grounded=True, best=best)

    @staticmethod
    def _best_match(props, M_target):
        best, best_iou = None, -1.0
        for p in props:
            inter = (p.mask & M_target).sum().item()
            union = (p.mask | M_target).sum().item()
            iou = inter / max(union, 1)
            if iou > best_iou:
                best, best_iou = p, iou
        return best, best_iou
```

### IP-508 EFA-v8：七硬门（强化 GGC）+ 八软因子链

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：硬门数不变（7）；kc_ground 编译进 GGC 谓词。
    软因子链：η_g·η_topo·η_interp·η_cmd·η_demand·η_affect·η_ground·η_seg。"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    ggc: GraspGeometryCutter
    mctm: MobileChassisTopologyMap
    stm: SemanticTrajectoryMapper
    dim: DemandIntentModel
    drc: DemandReasoningChain
    dac: DemandAffectCapture
    gab: GroundedAffordanceBridge
    v7: EvidenceForgingAssemblerV7       # 复用七硬门与需求路径
    tau_ground: float = 0.75

    def select(self, L: str | None, t_now, context):
        # 0. v7 需求路径先算，作为接地失败时的安全回退（不改 v7 语义）
        rho_demand, eta_demand = self.dim.forward(
            history=self.lmem.get_history(), context=context.__dict__,
            env=getattr(context, "env", {}), L=L)
        affect = self.dac.observe(context.face) if hasattr(context, "face") else 0.0
        eta_affect = self.dac.get_affect_factor(affect)

        if L is None or eta_demand < self.v7.tau_demand:
            return self.v7.select(L, t_now, context)   # 原样回退，不引入新风险

        # 1. 视觉-语义接地
        gc = self.gab.fuse(context.image, context.depth, L, rho_demand)
        if not gc.grounded:
            return self.v7.select(L, t_now, context)   # 接地失败 → v7 需求路径
        eta_ground, eta_seg = gc.eta_ground, gc.seg.eta_seg

        # 2. 软因子（v7 链 + 接地链）
        q_L = self.stm.forward(L, grounded=gc.g_ga)
        eta_cmd = 1.0 - 0.1 * self.stm.information_entropy(q_L, self.lmem.all_embeddings())
        eta_interp = sigmoid(-self._semantic_traj_distance(q_L) / self.stm.temp)
        eta_topo = self.mctm.query(context.pose)

        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)
        m_topk = self.lmem.retrieve_by_semantic(q_L, k=4)
        t_topo = self.mctm.token(context.pose)
        c = build_ctx(context, s_emo, m_topk, t_topo, q_L, gc.g_ga)
        cands = self.fmpp.propose(c, K=self.fmpp.K)

        # 3. 强化 GGC 谓词：kc_ground 已由 gc.grounded 保证，另加接触/禁入约束
        def ggc_v8(x) -> bool:
            if not self.ggc.filter(x):
                return False
            if not self._contact_legal(x, gc.seg.A_contact):
                return False
            if not self._swept_disjoint(x, gc.seg.Omega_keepout):
                return False
            return True

        surv = []
        for x in cands:
            if not ggc_v8(x):
                continue
            eta_g = self.ggc.quality_factor(x)
            eta_total = (eta_g * eta_topo * eta_interp * eta_cmd
                         * eta_demand * eta_affect * eta_ground * eta_seg)
            if self._cheap_gates(x, gamma, eta_total):
                surv.append((x, eta_total))
        if not surv:
            return self.v7.select(L, t_now, context)

        # 4. 级联筛选（VACK → BCK），与 v7 完全一致
        surv.sort(key=lambda xe: xe[1], reverse=True)
        finals = []
        for x, _ in surv[:3]:
            vac = self.v7.v6.vack.evaluate(x, context_with(s_emo), t_now)
            if self.v7.v6.vack.kc_val(vac, tau=gamma["val"] * TAU_VAL5):
                if self.v7.v6._bck_preview(x, gamma):
                    finals.append(x)
        if not finals:
            return self.v7.select(L, t_now, context)

        best = max(finals, key=lambda x: self._margin(x))
        return True, best, "FORGED_CGE_V8"

    def ecs_v8(self, x, n_flow, s_emo, eta_factors) -> float:
        return (self.v7.ecs_v7(x, n_flow, s_emo, eta_factors)
                * eta_factors["ground"] * eta_factors["seg"])
```

### 集成流水线（v7 → v8，双层时延架构）

```
慢时域（感知关键帧，5~10 Hz）：
  PSM.segment(I, depth) ──▶ M_target / A_contact / Ω_keepout / η_seg
  VLMG.ground(I, L, ρ_demand) ──▶ 提议 + g_vlm
  GAB.fuse(...) ──▶ g_ga + η_ground + grounded（失败则一次再查询）
  结果写入「接地缓存」：{g_ga, A_contact, Ω_keepout, η_ground, η_seg, t_ground}

快时域（在线控制环，< 0.8 ms）：
  读取接地缓存（若 t_now − t_ground > T_stale 则降低权重/回退）
  EFA-v8 消费 η_ground、η_seg、A_contact、Ω_keepout，七硬门链路不变
  GGC_v8 执行接触合法 + 禁入不相交 + kc_ground（编译项）

离线/慢时域：
  VLM 接地提示模板与校准（小时级）；PSM 部件词表与 keep-out 标签（小时级）
  联邦下发：VLM 适配器、PSM 权重、τ_ground / τ_seg（站内签名）
```

|---|---|---|---|---|
| PSM.segment | O(H·W·C) | O(H·W·C) | H·W=640×480, C=32 | 8~20 ms（GPU） |
| VLMG.ground | O(T_vlm) | O(d_vlm) | T_vlm=视觉 token 数 | 30~120 ms（可批/缓存） |
| GAB.fuse | O(H·W + d) | O(H·W) | d=512 | 2~5 ms |
| kc_ground 判定 | O(H·W) | O(1) | 掩码 IoU | < 0.1 ms（缓存） |
| contact / swept 检查 | O(N_c·N_v) | O(N_c) | N_c 接触点, N_v 扫掠采样 | 0.05~0.2 ms |
| 软因子链（8 项） | O(1) | O(1) | — | < 0.05 ms |

**结论**：VLM 与分割**不能**进入 0.8 ms 控制环；它们运行在 5~10 Hz 的感知关键帧上，控制环只消费缓存证据。接地缓存过期（`t_now − t_ground > T_stale`）时 η_ground 强制置 1 并回退 v7 需求路径，避免「用旧像素证据给新场景背书」。

## 4. 正确性论证（增量更新）

### 定理 13（零新增硬门 + 单调收紧）

**陈述**：设 v8 的七硬门与 v7 相同，仅将 GGC 谓词强化为 GGC_v8 = GGC_v7 ∧ kc_ground ∧ contact⊆A_contact ∧ swept∩Ω_keepout=∅，且软因子 η_ground, η_seg ∈ [1, 1+ε]。则：
- Exec_CADVS-v8 ⊆ Exec_CADVS-v7（执行集只收缩）；
- 硬门数量 |G_v8| = |G_v7| = 7，kc_ground 不是新的顶层门。

**证明**：GGC_v8 ⇒ GGC_v7（合取引入），其余六门谓词不变；软阈值 τ_i^v8 = γ_i·τ_i^v7·Π_factor_i，因 η_j ≥ 1 得 Π_factor_i ≥ 1，故 τ_i^v8 ≥ τ_i^v7，判定 1[s_i ≥ τ_i^v8] ≤ 1[s_i ≥ τ_i^v7]。逐项取交即得执行集子集。kc_ground 仅作为 GGC 的内部合取项，不改变顶层门的计数。∎

### 定理 14（分割裁判下的接地污染上界）

**陈述**：设分割掩码 M_s 相对真值 M* 满足 |M_s Δ M*| ≤ ε_s|M*|，VLM 提议 m̂ 满足 IoU(m̂, M_s) ≥ τ。则 m̂ 相对真值的假阳性面积占比满足
$$\frac{|m̂ \setminus M^*|}{|m̂|} \le (1-\tau) + \varepsilon_s\frac{|M^*|}{|m̂|}.$$

**证明**：|m̂\M*| ≤ |m̂\M_s| + |M_s\M*|。由 IoU ≥ τ 得 |m̂∩M_s| ≥ τ|m̂∪M_s| ≥ τ|m̂|，故 |m̂\M_s| = |m̂| − |m̂∩M_s| ≤ (1−τ)|m̂|；又 |M_s\M*| ≤ ε_s|M*|。两边除以 |m̂| 即得。∎

**推论**：当 |M*| ≤ |m̂|（VLM 不过度收缩）时，假阳性占比 ≤ (1−τ) + ε_s。取 τ=0.75、ε_s=0.1 时上界仍达 0.35——这说明**一致性证书只是必要不充分条件**，τ_ground 必须取高值，且需要独立的几何/语义门叠加（这正是 GGC_v8 保留 contact/keepout 合取项的理由）。

### 定理 15（再查询与回退的安全性）

**陈述**：GAB 的一次再查询只改变 VLM 提议与 g_vlm，不改变任何硬门语义；若再查询后仍不满足 kc_ground，则 EFA-v8 回退到 v7 需求路径，其执行集 ⊆ Exec_CADVS-v7。

**证明**：再查询分支仅替换 `props/g_vlm`，GGC_v8 的谓词定义不变；未通过时直接调用 `v7.select`，由定理 13 知该路径执行集 ⊆ Exec_v7。故 v8 不会因再查询引入新的不安全执行。∎

### 诚实声明

- **相关失效**：VLM 与分割可能共享骨干/预训练分布，OOD 下同向出错，IoU 高但都错——定理 14 无法覆盖这种相关性；
- **标签体系不匹配**：VLM 的开放词表标签 ℓ_i 未必落在分割的闭集词表中，「ℓ_i 与 M_target 标签一致」会因词表缺口产生**假拒绝**（可回退，但降低可用性）；
- **分割边界噪声**：深度缺失、反光、透明物会让 M_target 边界抖动，A_contact 可能被侵蚀，导致可抓取区域过窄；
- **缓存过期**：接地证据按关键帧刷新，快速移动的人手可能已进入 Ω_keepout 但缓存尚未更新；T_stale 是安全与实时性的硬权衡；
- **谓词膨胀**：零新增硬门换来的是 GGC 谓词变长，可解释性与单元测试成本上升（R72）。

## 5. 实验设计与验证计划（仿真 → 实机）

### 5.1 实验设计（MuJoCo 3.x + MJX + 真实 RGB-D）

- **平台**：UR10e（6DOF）+ 移动底盘（2DOF）+ RGB-D 相机 + 语音指令合成器
- **感知模型**：
  - VLM：开源 VLM（如 LLaVA-1.6 / Qwen-VL）做零样本接地，另训一个轻量适配器；
  - 分割：Mask2Former / SAM 系部件分割，叠加 keep-out 类别（human_hand / fragile / liquid）；
  - 真值：仿真渲染语义/部件标签；真实场景用少量人工标注校验。
- **数据集**：
  - 接地集：2k 条「指令-目标区域」配对，覆盖 120 类开放词表物体；
  - 部件集：800 个物体的 handle/rim/body 部件标注；
  - keep-out 集：500 段人手进入工作空间的视频，标注禁入掩码。
- **对照**：v7-full、v8-full、A21（无 VLMG，仅分割）、A22（无 PSM，仅 VLM 框）、A23（η_ground 恒为 1）、A24（无再查询）、A25（关闭 keep-out 合取）、A26（关闭 contact 合取）。
- **场景**：
  - (a) 开放词表指代：「把那个像鱼一样的东西拿起来」→ VLM 提议 + 分割裁决；
  - (b) 部件级抓取：马克杯仅允许抓 handle，抓 body 会被 A_contact 拒绝；
  - (c) 语义禁入：人手快速伸入，Ω_keepout 使扫掠体判失败并回退；
  - (d) VLM 幻觉：VLM 指向不存在的物体 → IoU≈0 → kc_ground 失败 → 回退 v7，且不执行；
  - (e) 相关失效压力测试：逆光/透明物体/遮挡，统计 VLM 与分割**同向错误**率。
- **指标**：接地精确率/召回率、幻觉拒绝率、接触合法率、禁入违规率、任务成功率、回退触发率、控制环 P99、接地缓存过期率、跨词表假拒绝率。

## 7. 本轮最大风险（最终确认）

**一句话**：**相关失效下的『共识幻觉』**：VLM 与语义分割共享视觉骨干与训练分布，在 OOD（新物体、遮挡、逆光）下可能**一起错**——两者把桌面误判为目标、IoU 反而很高，于是 kc_ground 给出「虚假接地证书」，而七硬门越严反而越像「已严格验证」；这种相关失效在结构上无法靠一致性检验捕获。
