# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「云端协同」×「材料选型」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**云边安全分离 + 材料保守选型 + 租约退化**。v9 把算力债压到边缘 50Hz，但 5Hz 块生成仍吃 12ms、64 候选前向 rollout 与全因子消融在单机上难以为继；本轮把「重生成」外移到云端，把「裁决权」留在边缘，并用材料选型把证书从「模型误差」扩展到「物理参数误差」。铁律：**云端只能提议（propose），边缘必须裁决（dispose）**；任何未通过本地验证、或租约/材料卡过期的云端产物只能注入中立元，严格等价退回 v9。

## 0. 直觉与动机

**灵感 1（云端协同 → 提议/裁决分离）**
直觉：v9 的 5Hz 块生成、64 候选前向 rollout、每 500 周期一轮的消融归因，都是「离线可做、在线很贵」的计算；云端有更强前向模型、多机共享地图与算力，理应承担这些。但云端在实时安全边界之外：延迟抖动、断连、重放、甚至被攻陷都可能。因此不能把云端当「远程协处理器」，而要当「不可信提议者」。核心创新：**云端块委派器（CloudChunkDelegator, CCD）** 发送的不是「可执行块」，而是 (proposal, claim, witness, lease) 四元组；边缘用**边缘委派验证器（EdgeDelegationVerifier, EDV）** 以当前实测状态独立做一次 O(K) 保守区间 rollout，只有本地验证通过且租约新鲜才执行。安全责任从「信任云端模型」变成「验证一个提案」，云端误差只降低性能、不改变安全——**P13 云边安全分离律**。

**灵感 2（材料选型 → 物理参数也是证书的一部分）**
直觉：v9 的块证书假设「前向模型误差 ≤ β」，却把执行器材料当作无关背景。真实抓取/接触中，摩擦系数、柔顺性、夹持力上限、热限与磨损率直接决定滑移与损坏；同一动作在软指尖上安全，在硬指尖上可能打滑。核心创新：**材料感知证书器（MaterialAwareCertifier, MAC）** 为每个可换材料建**材料卡** μ_j，把块证书升级为材料条件证书 Ĉ^μ=(ĝ_min, ê_max, ŝ_slip, ŵ_wear, θ̂_temp)；材料选型 m_t 只在**可行材料集** M_t^feas 内优化，并用摩擦下界与力/热上界的悲观值评分。材料卡由云端**材料属性账本（MaterialPropertyLedger, MPL）** 聚合全机队经验，但边缘保留**材料观测器（EMO）** 由接触力与微滑移得到的经验下界，认证时取二者更保守者——**P14 材料保守选型律**。

**灵感 3（两词合流 → 租约化退化）**
直觉：云边协同与材料选型共享同一个脆弱点——**新鲜度**。云证书会过期，材料卡会因磨损而过期。把两者统一为「租约失效 ⇒ 注入中立元」：过期云证书 ⇒ 丢弃提案、退回边缘 v9 块；不可用材料账本 ⇒ 退回基线材料 μ₀ 与 v9 证书；断云 ⇒ 边缘自治 v9。核心创新：**租约退化律 P15**，使 v10 的退化链成为 v9 契约表的又一层数据实例（引理 91 证明逐位等价）。材料磨损另有**磨损状态机**：retired 为吸收态，云端无权解冻，确保「边缘对物理安全拥有最终否决权」。

## 1. 研究问题（轮次升级版）

- **Q1（云边安全分离）**：怎样设计 (proposal, claim, witness, lease) 与 O(K) 本地验证器，使云端任意错误（过期、重放、投毒、断连、错误模型）都不导致安全不变式违背，而只导致性能退化？
- **Q2（材料感知证书）**：在摩擦/刚度/力限/热限/磨损参数带区间不确定性时，如何给出接触安全（无滑移、无力损、无热超限）的可验证条件？边缘经验下界与云端账本如何合成而不引入新的乐观偏差？
- **Q3（租约与磨损的组合退化）**：租约过期与材料退化的组合状态空间是否仍满足「任意状态 ∈ v9 退化格点」？磨损状态机的吸收态能否保证不出现「云端把已退役材料重新上线」？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 云边安全分离律（Safety-Delegation Separation, CCD/EDV）**
云端输出 δ=(p,c,w,ℓ,j) 只是提案；边缘验证器 V(s,δ,μ) 用当前实测状态、局部动力学区间与材料置信盒独立做 O(K) 保守 rollout，唯一决定是否执行。云端模型误差、延迟、断连、投毒只影响提案被接受的概率，不进入安全证明；云端永不直接写执行器。

**P14 材料保守选型律（Material-Conservative Selection, MAC/MPL）**
材料卡 μ_j 的每个参数带区间与置信；证书一律使用摩擦下界、力/热上界；可行材料集随不确定性单调收缩；选型用悲观分数（乐观只在离线规划中允许）；云端账本只有在通过来源/置信校验后才扩大候选，且认证取 min(云端摩擦下界, 边缘经验下界)。无可行材料时进入**无接触中立模式 m^⊥**（张开/后退），只损失任务、不损失安全。

**P15 租约退化律（Lease Degradation, EDV）**
云证书与材料卡共享「新鲜度」语义：租约 ℓ 以本地接收时刻锚定（不信任云端时钟），epoch+nonce 防重放；过期/版本不符/验签失败 ⇒ 丢弃云端产物并退回 v9。材料卡 retired 为吸收态，只有离线复检可解冻。任一退化层的组合仍落在 v9 退化格点内（引理 91）。

## 3. 与基线的接口（如何退化）

- 云断连 / 租约过期 / 重放 / 验签失败 / EDV 拒绝 ⇒ 丢弃 δ，边缘 AC 本地生成，等价 v9（K_eff 门控不变）；
- EDV 自检失败 ⇒ 不执行任何云端提案，直接 v9 AC（安全默认）；
- MPL 或 EMO 或 MAC 失效 ⇒ 固定基线材料 μ₀，材料证书项取 v9 常数，等价 v9 证书；
- 无材料可行（含 μ₀ 不可用）⇒ 无接触中立模式 m^⊥（张开/后退），不执行接触动作；
- 全失效 ⇒ v9 → v8 → v7 → v6 严格链；
- ID 的消融归因可由云端批量算，但边缘只接受租约内、且能用本地日志复算的结果；否则按 v9 本地 ID 运行。

## 4. 预期贡献

1. **云边安全分离**框架：提议/裁决分离 + 本地可验证证书 + 接收时刻锚定租约，把云端移出安全 TCB，云端错误只降性能；
2. **材料感知证书与保守选型**：把物理参数不确定性纳入块证书，证明风险随不确定性单调（引理 90），并给出无接触中立元；
3. **租约化组合退化**：云证书与材料卡的过期统一为中立元，v10 任一新增模块失效均严格退回 v9（引理 91）；
4. **边缘材料观测**：以接触力/微滑移维护摩擦经验下界，与云端账本取 min，消除单源乐观偏差；
5. **E571–E590**：延迟/断连/重放/投毒、材料标定/磨损/退役、组合退化等价、跨机队共享与端到端任务。

## 5. 本轮最大风险

**一句话**：安全被完全下放给边缘验证器，而验证器的保守性又依赖材料卡——一旦材料磨损使真实摩擦下界低于账本值，EDV 会以「本地已验证」的姿态放行一个已经打滑的抓取，即云边协同把 v9 的模型误差风险置换成了材料账本的新鲜度风险。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-CEMC**（Metric Voice Gauge with Cloud-Edge Material Certificates）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「云端协同」×「材料选型」
> **继承纪律**：v9 的 AC/MW/ID 与 v8 的 DA-ML/SPR/Cal 原样继承，v9 引理 82–86 继续成立。新组件一律为**可选增强**：CCD、EDV、MPL、MAC、EMO 任一不可用 ⇒ 注入中立元（无提案 / 全拒绝 / 基线材料 μ₀ / v9 证书 / 基线材料），严格等价退回 v9（引理 91），而非行为漂移。云端永不进入边缘 50Hz 关键路径。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 MetricVoiceGauge-ACMD v9） |
|---|---|---|---|
| IP-340–356 | v9 全部模块 | 继承 | 语义不变；ID 的消融归因可由云端批量预计算，但边缘只接受租约内且可复算的结果 |
| IP-346 | MetricVoiceGauge 主闭环 | 集成升级 | 边缘关键路径不引入网络等待；云提案异步 5Hz，50Hz 守卫与 v9 完全一致 |
| IP-357 | CloudChunkDelegator（CCD） | 新增核心模块 | 云端异步生成 (proposal, claim, witness, lease, material_id)；256 候选大模型 rollout；只提议、不裁决 |
| IP-358 | MaterialPropertyLedger（MPL） | 新增核心模块 | 全机队材料卡聚合：摩擦、刚度、力/热限、磨损率、来源、置信、单调版本；边缘缓存 |
| IP-359 | MaterialAwareCertifier（MAC） | 新增核心模块 | 材料条件块证书 Ĉ^μ；材料可行集与悲观选型；磨损状态机；基线材料 μ₀ 与无接触中立元 m^⊥ |
| IP-360 | EdgeDelegationVerifier（EDV） | 新增核心模块 | O(K) 保守区间 rollout；租约/epoch/nonce/哈希校验；唯一安全裁决者；边缘 ≤0.4ms |
| IP-361 | EdgeMaterialObserver（EMO） | 新增（小） | 由 F/T 与微滑移事件维护摩擦经验下界 σ̂_s^-，认证取 min(云端下界, 本地下界) |

**退化链声明（v10 契约化六级）：**
- Level-0：全云边材料模式（CCD+MPL+MAC+EDV+EMO 健康）；
- Level-1：委派被拒（租约过期 / epoch 或 nonce 不符 / 哈希不符 / 云断连 / EDV 拒绝）⇒ 丢弃 δ，边缘 AC 本地生成，等价 v9；
- Level-2：MPL 或 EMO 不可用 ⇒ 基线材料 μ₀，材料证书项取 v9 常数，等价 v9；
- Level-3：MAC 不可用 ⇒ μ₀ + v9 证书，等价 v9；
- Level-4：EDV 不可用 / 自检失败 ⇒ 拒绝一切云端提案，直接 v9 AC，等价 v9；
- Level-5：全失效 ⇒ 完整退回 v9 → v8 → v7 → v6。

## 1. 符号体系增量（定义 540–548）

| 符号 | 含义 |

| δ_t = (p_t, c_t, w_t, ℓ_t, j_t) | 云边委派单元：提案动作、证书声明、证据、租约、材料编号 |
| ℓ = (id, epoch, t_recv, T_lease, nonce, h) | 证书租约；t_recv 为边缘本地单调时钟接收时刻 |
| φ_fresh(t) | 新鲜度谓词：t−t_recv ≤ T_lease ∧ epoch=当前 ∧ nonce 匹配 ∧ h=H(p,c,w) |
| μ_j = (σ_s^-, σ_s^+, k_c, F_n^max, T^max, r_w, prov, ts, n_val, conf, st) | 材料卡（带上/下界、来源、置信、磨损状态） |
| B(μ_j, δ) | 材料置信盒：各参数按不确定半径 δ 的悲观角点 |
| Ĉ_t^μ = (ĝ_min, ê_max, ŝ_slip, ŵ_wear, θ̂_temp) | 材料条件块证书 |

| m^⊥, μ₀ | 无接触中立元（张开/后退）与 v9 基线材料（固定默认夹爪） |
| V(s, δ, μ) | 边缘委派验证器，输出 ACCEPT / REJECT / DEGRADE |
| D0–D5 | 云边退化格点 |

**新增定义 540（云边委派单元 CloudDelegationUnit）**
一次云端提议的完整凭证：δ_t=(p_t, c_t, w_t, ℓ_t, j_t)。其中 p_t={a^{1:K}} 为候选动作序列，c_t=(ĝ_min, ê_max, ŝ_slip, ŵ_wear, θ̂_temp) 为材料条件声明，w_t=(model_hash, param_version, nominal_rollout, provenance) 为可审计证据，ℓ_t 为租约，j_t 为材料编号。δ_t **不携带执行权限**：只有 EDV 返回 ACCEPT 后，p_t 才被转成 v9 的 Chunk 结构交给 50Hz 守卫。

**新增定义 541（证书租约与新鲜度 CertificateLease/Freshness）**
ℓ=(id, epoch, t_recv, T_lease, nonce, h)，t_recv 由边缘在**接收时**用本地单调时钟打戳（不信任云端时钟，避免时钟偏移/回拨攻击）。新鲜度：
```
φ_fresh(t) = (t − t_recv ≤ T_lease) ∧ (epoch = E_current)
             ∧ (nonce = N_session) ∧ (h = H(p_t, c_t, w_t))
```
默认 T_lease=250ms（≥ 最大 RTT 200ms + 一个 5Hz 周期留量）。任一项失败即视为无提案，按 Level-1 退回 v9。epoch 随材料账本或会话单调递增，旧 epoch 的重放被一次性拒绝。

**新增定义 542（材料卡 MaterialCard）**
μ_j=(σ_s^-, σ_s^+, k_c, F_n^max, T^max, r_w, prov, ts, n_val, conf, st)，分别表示静/动摩擦下界与上界、接触刚度、法向力上限、温度上限、磨损率、来源证明、时间戳、独立验证次数、置信度、磨损状态（fresh/worn/retired）。不确定半径 δ_μ=(δ_σ, δ_k, δ_F, δ_T, δ_r)，置信盒的**认证角点**为：
```
σ_min = σ_s^- − δ_σ,  F_max = F_n^max + δ_F,
T_cert = T^max − δ_T,  r_max = r_w + δ_r,  k_c ∈ [k_c^-, k_c^+]
```
任一角点缺失或 prov 无效或 conf<κ_conf ⇒ 该材料不可选。

**新增定义 543（材料条件块证书 MaterialAwareCertificate）**
对材料 μ、块 ζ 与预测接触力轨迹 (F_n^k, F_t^k)、温度 θ̂_k：
```
ĝ_min = min_k F̂_clear(s,a^k) − β(μ) − δ_g(μ)
ê_max = max_k F̂_effort + β(μ) + δ_e
ŝ_slip = min_k (σ_min·F_n^k − F_t^k − ε_slip)
ŵ_wear = N_r − N_used − ⌈r_max·K/Δ_use⌉
θ̂_temp = max_k θ̂_k + δ_T
```
证书有效 ⇔ ĝ_min ≥ d_safe ∧ ê_max ≤ τ_eff ∧ ŝ_slip ≥ 0 ∧ ŵ_wear ≥ K ∧ θ̂_temp ≤ T_cert ∧ γ̂_grasp=valid。β(μ) 对柔顺材料更大（接触模型误差随刚度降低而升高），由 E575 标定。相对 v9，新增的是**物理参数项** ŝ_slip、ŵ_wear、θ̂_temp。

**新增定义 544（边缘委派验证器 EdgeDelegationVerifier）**
确定性函数 V(s_t, δ_t, μ_j, t)→{ACCEPT, REJECT, DEGRADE}，依次执行：
1. 租约检查 φ_fresh(t) 与 payload 哈希；
2. 材料检查 st≠retired、conf≥κ_conf、prov 有效、epoch 一致；
3. 以当前实测状态为初值，用**局部区间动力学** f̂ 与材料置信盒 B(μ,δ) 做 O(K) 保守 rollout，得到可达集 S_k 的过近似；
4. 用区间几何给出间隙下界 inf_k dist(S_k,O)，区间接触模型给出力/滑移/热的上/下界；
5. 全部满足定义 543 的不变式才 ACCEPT；否则 REJECT（退回 v9）。
V **不信任 c_t**：c_t 只用于审计与提前剪枝；所有边界由第 3–4 步本地重算。假设 A1：局部区间模型在材料盒与扰动界内过近似真实被控对象（与 v9 的 β 假设同级）。

**新增定义 545（材料可行集与保守选型 MaterialFeasibleSet/Selection）**
```
M_t^feas = { μ_j : conf_j ≥ κ_conf ∧ prov_j valid ∧ st_j ≠ retired
             ∧ ∃ 候选块使 Ĉ^μ 有效（角点取悲观值） }
m_t = argmax_{μ∈M_t^feas} J^μ,   J^μ = J_task(μ; σ_min, F_max, T_cert)
                                  − λ_s·max(0, −ŝ_slip) − λ_w·(N_used/N_r)
                                  − λ_T·max(0, θ̂_temp − T_cert)
```
若 M_t^feas=∅ ⇒ m_t=m^⊥（无接触：张开/后退）。m^⊥ 是聚合算子的恒等元（不施加接触作用），恒可行；μ₀ 是 v9 基线材料，用于所有退化层以复现 v9 行为。

**新增定义 546（材料磨损状态机 MaterialWearFSM）**
st: fresh → worn（N_used>N_w 或 σ_min 相对初始下降 >γ_w）→ retired（N_used>N_r 或 ŝ_slip<s_retire 或观测到滑移事件）。retired 为**吸收态**；只有离线物理复检并 epoch+1 才可解冻。云端可**建议**退役（安全方向），但**无权**解冻或把 retired 改回 fresh；退役判定最终由边缘账本写入。

**新增定义 547（云边退化格 CloudEdgeDegradationLattice）**
D0 → D1 → D2 → D3 → D4 → D5 的偏序与中立元映射：
| 层级 | 触发 | 中立元 | 等价 |
|---|---|---|---|
| D0 | 全健康 | — | v10 |
| D1 | 委派被拒/云断连 | 无提案 | v9 AC |
| D2 | MPL/EMO 失效 | μ₀ | v9 证书 |
| D3 | MAC 失效 | μ₀ + v9 Ĉ | v9 |
| D4 | EDV 失效 | 拒绝一切云提案 | v9 AC |
| D5 | 全失效 | 全中立元 | v9→v8→v7→v6 |
组合规则：任一维度取最保守层；中立元与 v9 对应退化分支在可观测端口逐位一致（引理 91）。

**新增定义 548（边缘材料观测 EdgeMaterialObservation）**
由力/力矩与微滑移检测维护每个材料的经验摩擦下界 σ̂_s^-(t)（滑动前后切向/法向力比的置信下界，Wilson 下界）。认证一律使用
```
σ_s^cert = min( σ_s^- − δ_σ , σ̂_s^-(t) )
```
故云端账本再乐观也不能把认证摩擦抬高到本地观测之上。EMO 失效时按 P15 退回 μ₀，不退回云端单源值。

        if tube.inf_slip      < 0.0:                    return REJECT, 'slip'
        if tube.sup_temp      > box.T_cert:             return REJECT, 'thermal'
        return ACCEPT, tube                              # 本地独立认证


# IP-358/359/361：材料账本、材料证书与边缘观测
class MaterialAwareCertifier:
    def feasible(self, task, ledger, emo):
        out = []
        for mu in ledger.cached():
            if mu.st == 'retired' or mu.conf < K_CONF or not mu.prov.valid:
                continue
            box = mu.confidence_box()
            box.sigma_min = min(box.sigma_min, emo.sigma_lower(mu.id))
            if self.exists_cert(task, box):              # 定义 543
                out.append((mu, box))
        return out

    def select(self, task, ledger, emo):
        feas = self.feasible(task, ledger, emo)
        if not feas:
            return M_NEUTRAL                              # 无接触中立元 m^⊥
        return max(feas, key=lambda mb: pessimistic_score(*mb))

    def update_wear(self, mu, uses, slip_margin, ledger):
        if mu.st == 'retired': return
        if uses > N_R or slip_margin < S_RETIRE:
            mu.st = 'retired'; ledger.retire(mu.id)       # 边缘最终权威
        elif uses > N_W or slip_margin < S_WORN:
            mu.st = 'worn'

## 4. 推导

**引理 87（租约新鲜性与抗重放）** 若 V 接受 δ，则 φ_fresh 成立：t−t_recv ≤ T_lease，epoch=E_current，nonce=N_session，且 h=H(p,c,w)。上一会话/旧 epoch 的消息因 epoch 与 nonce 不匹配而被拒；中途篡改任一字段使哈希不匹配而被拒。t_recv 由边缘本地单调时钟打戳，云端时钟偏移或回拨不影响判定，故不存在「旧提案因时钟回拨而被续命」。∎

**引理 88（边缘验证器可靠性）** 在假设 A1（局部区间模型在材料置信盒与扰动界内过近似真实对象）下，若 V 返回 ACCEPT，则对执行前缀真实间隙 ≥ d_safe、作用力 ≤ τ_eff、滑移裕度 ≥0、温度 ≤T_cert。证明：区间 rollout 的可达集 S_k 包含真实状态；区间几何的间隙下界 inf C_k ≤ 真实间隙，故 inf C_k ≥ d_safe ⇒ 真实间隙 ≥ d_safe；接触力/滑移/温度为同一区间过近似的上下界。云端声明 c_t 未参与任何边界判定，故其误差、延迟或伪造不改变结论。∎

**引理 89（材料感知接触安全）** 若认证摩擦 σ_min ≤ 真实摩擦 σ_s，且真实切向力 F_t ≤ F_t^max、法向力 F_n ≥ F_n^min，则 ŝ_slip ≥ 0 ⇒ F_t^max ≤ σ_min F_n^min ≤ σ_s F_n，接触不滑移；ê_max≤τ_eff 与 θ̂_temp≤T_cert 分别排除过力与过热。EMO 的经验下界使 σ_s^cert ≤ σ_s 以高概率成立；EMO 不可用则按 P15 退回 μ₀。证明：摩擦锥的充分条件 + 置信盒角点单调性。注：若只用云端单源材料卡，结论条件于账本正确性——这正是认证必须取 min 的原因。∎

**引理 90（保守选型单调性）** 记不确定半径 δ，若 δ'≥δ（逐分量），则置信盒更宽、角点更悲观，故 M_feas(δ')⊆M_feas(δ)，且对每个 μ 有 J^μ(δ')≤J^μ(δ)。于是「不确定性增加 ⇒ 可行集不扩张、悲观得分不上升」，系统不会因为对材料更不确定而选得更激进。选取的材料其最坏情形安全裕度随 δ 单调不降。∎

**引理 91（云边退化等价）** 对 D1–D5 逐层注入中立元：D1/D4 无提案 ⇒ 走 v9 AC；D2/D3 μ₀+v9 Ĉ ⇒ 走 v9 证书；D5 全中立元 ⇒ v9→v8→v7→v6。CCD/MPL/MAC/EDV/EMO 只改变「候选提案从哪来」与「材料参数取谁」，从不绕过 v9 的 AC 守卫、SpatialCert、FaultCert 与 M₀ 硬检查；故各层可观测端口读数与 v9 对应分支逐位一致（映射表见定义 547，与 v9 引理 83 复合）。∎

**引理 92（云边预算守恒）** 边缘关键路径 = 租约检查 O(1) + EDV O(K) + v9 中块守卫 + v9 继承路径；云端 RTT 与模型推理不进入该路径，因为提案异步到达、缺失或过期只触发本地回退。故 Σ 边缘 WCET 典型 ≤8ms、p99 ≤20ms，与 v9 持平；网络抖动映射为 D1 层的接受率下降，而非 50Hz 丢拍。∎

**引理 93（磨损退役安全）** retired 为吸收态且 EDV 对 st=retired 直接 REJECT；云端无权解冻，故不存在「云端把已退役材料重新上线」。当 ŝ_slip 降到 s_retire 以下时状态机在当周期退役，后续块只能选其他材料或 m^⊥，因此材料磨损不会把认证摩擦拖到退役阈值之下仍继续使用。∎

## 8. 本轮最大风险

**一句话**：安全被完全下放给边缘验证器，而验证器的保守性又依赖材料卡——一旦材料磨损使真实摩擦下界低于账本值，EDV 会以「本地已验证」的姿态放行一个已经打滑的抓取，即云边协同把 v9 的模型误差风险置换成了材料账本的新鲜度风险。
