# 第 2 轮（新灵感循环第 2 轮；本轮灵感：「数据集」×「行为树」）

> **基线**：第 1 轮产出 MetricVoiceGauge-NCD-HUTDH-v20+IP-420–424（v20 完整方案）。
> 本轮纪律：**证书是数据集，不是单点证明；安全是行为树契约传播的不动点，不是单动作属性**。不推倒 v20：v20 的 PCA/CTS/CFC/HPC/CFCtrl 与 v19 的 DCM/OGCC/CCV/DRS/OGC、v17 的 CLP/S2C/HCG/PSV/APS/AMC 全部保留。本轮只做一件事：**把 v20 的“单次碰撞证书”升级为“数据集支撑 + 行为树契约组合”的证书语料体系 v21**。

## 0. 直觉与动机

**灵感 1（数据集 → 证书的可信度是支撑集，不是证明长度）**
直觉：传统碰撞证书像一条定理，证明一次就处处成立；但真实证书来自有限采样，只在**采样覆盖到的参数域**上有效。出了支撑集，证书不是“错”，而是“空”（vacuous）。数据集的价值不在样本多，而在**数据表（datasheet）**诚实标注了来源、覆盖、标签噪声与版本。核心创新：**证书语料与数据表（Certificate Corpus & Datasheet, CCD）**——把每次 v20 验证的 `(状态, 动作, 判决, 证明, 几何上下文, 机器人, 时间戳)` 存成带 provenance / coverage / label-noise / split / version 的语料 `C`；证书 = 语料在参数域上的 **ε-支撑集 `Supp_ε(C)`**，出支撑集即失效。关键反直觉点：**“安全”不是被证明出来的，而是被数据集的覆盖边界圈出来的；数据集的空洞必须像 v20 的感知盲区一样显式携带，而不能被“证明完整”的假象掩盖**。

**灵感 2（数据集 → 覆盖保证应分布无关，而非经验平均）**
直觉：经验成功率 99% 不等于安全 99%，换个光照或物体分布就可能崩。保形预测（conformal prediction）给出分布无关的有限样本覆盖保证：只要校准集与测试点可交换，预测集以 ≥ 1−α 的概率包含真值。核心创新：**保形覆盖门（Conformal Coverage Gate, CCG）**——用**独立校准语料**构造碰撞判决的保形集 `C_α(θ)`，再用**保形风险控制**把**假安全率**（判 SAFE 但真碰撞）控制在 α 以内。关键反直觉点：**证书的置信度不该由模型打分给出，而应由“交换性成立时错误被排除的集合”给出**——安全证书第一次有了有限样本、分布无关的统计语义。

**灵感 3（行为树 → 安全是契约沿树拓扑传播的不动点）**
直觉：行为树用 Sequence / Selector / Parallel / Decorator 把原子动作组合成任务，其 tick 语义天然层次化、可组合、可回退；传统碰撞证书只看单个原语，无法回答“整棵任务树是否安全”。核心创新：**契约行为树（Contracted Behavior Tree, CBT）**——每个节点携带契约 `φ_v = (Pre_v, Post_v, Inv_v)`，叶子契约由语料支撑背书，内部节点按组合规则传播契约；整棵树安全 ⇔ 契约在根节点被**消解（discharged）**。关键反直觉点：**安全不是“所有叶子都安全”的合取，而是契约传播的最小不动点；一个 Selector 的 fallback 分支可能因覆盖不足让整棵树从 SAFE 变 UNSAFE——组合不单调，回退不免费**。

**灵感 4（数据集 × 行为树 → 树告诉你缺什么数据，数据告诉你树能证什么）**
直觉：这是本轮真正的化学反应。行为树的契约证明义务精确指出**哪片参数域缺覆盖**（某叶子 `α_v` 未达标），数据集提供**主动采集**的靶点。核心创新：**覆盖引导采集规划器（Coverage-Guided Acquisition Planner, CGAP）**——把“契约未消解”的缺口转成采集任务，按覆盖增益/代价排序；采集后重校准，证书集合向 v20 上界逼近但永不越过。关键反直觉点：**数据不是越多越好，而是“证明义务指向的那一点”最值钱**——行为树是数据集的“需求编译器”，数据集是行为树的“能力边界”。

**四者如何统一**
统一为 **v20 之上的证书语料层（Certificate Corpus Layer）**：v20 回答“给定几何与感知，θ 是否零碰撞”；v21 回答“在什么数据支撑、什么组合契约下，这个零碰撞结论可被有限样本地信任”。CCD 是语料侧（数据集与数据表），CCG 是统计侧（保形覆盖），CBT 是组合侧（行为树契约），CGAP 是闭环侧（覆盖缺口→采集）。共享状态 `ζ_corpus = (C, D, C_α, φ, {α_v}, w, mode_corpus)`。统一接口：**当且仅当 CCD 支撑成立、CCG 覆盖达标、CBT 契约在根消解三者同时满足，计划才进入 `Exec_v21`；否则逐级回退到 v20 的 HPC 或 v19 的 CCV**。

## 1. 研究问题（轮次升级版）

- **Q1（语料支撑与数据表）**：如何定义 `Supp_ε(C)`，使其既覆盖真实安全域、又不过度外推？数据表如何量化 provenance / coverage / label-noise / split，使“出支撑集即失效”可机械判定？语料版本演化时，旧证书如何增量失效、如何继承仍有效的部分？

- **Q2（保形覆盖与组合稀释）**：在碰撞判决的非对称代价下，如何用保形风险控制给出“假安全率 ≤ α”的有限样本界？当行为树有 `L` 个叶子时，覆盖预算 `{α_v}` 如何分配（Bonferroni / e-value 融合 / 按关键度加权），使全局覆盖不随树深线性退化？交换性被破坏时如何检测并降级？

- **Q3（契约行为树的组合语义）**：Sequence / Selector / Parallel / Decorator 的 `(Pre, Post, Inv)` 组合规则如何定义，使契约传播既 sound（不放过不安全轨迹）又不过度保守？覆盖感知 Selector 如何在“分支覆盖不足”时拒绝路由？契约如何与 v20 的 HPC 证书、v19 的 CCV `cert_phase` 对接？

- **Q4（覆盖引导采集与漂移）**：如何把“契约未消解”的缺口转成采集目标，并保证采集本身不破坏交换性（避免分布偏置）？语料 / 环境漂移（光照、物体磨损、传感器标定）如何用密度比与两样本检验触发重校准？采集与执行的时间预算如何与 APS 新鲜度阶梯协调？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 语料支撑律（Corpus Support Law）**
证书仅在 `Supp_ε(C)` 内有效，定义为
`Supp_ε(C) = { θ : r_{m_min}(θ) ≤ ε 且 局部语料密度 ≥ m_min }`，
其中 `r_{m_min}(θ)` 是 θ 到第 `m_min` 个近邻的半径。出支撑集一律 `ABSTAIN`，退回 v20。语料只记录 v20 已判定过的 `(θ, verdict)`，**不生成新 verdict**，故 `Exec_v21 ⊆ Exec_v20`。

**P35 覆盖预算组合律（Coverage Budget Composition Law）**
设根覆盖水平 `1−α`，行为树叶子集合 `L(T)`。全局误覆盖满足
`P(任一叶子误覆盖) ≤ Σ_{v∈L(T)} α_v`。
采用 Bonferroni 分配 `α_v = α/|L(T)|`，或按关键度加权 `α_v = α·w_v / Σ_u w_u`。每个叶子必须达到实测覆盖 `Ĉ_v ≥ 1−α_v` 才可消解；否则 `ABSTAIN` 并交给 CGAP。**禁止不分配预算的朴素合取**，因为其全局误覆盖上界退化为 `|L(T)|·α`。

**P36 契约传播律（Contract Propagation Law）**
定义组合算子 `⊗`：
- **Sequence**：`Post(c_i) ⇒ Pre(c_{i+1})`，且 `Inv = ⋀_i Inv(c_i)`；
- **Selector**：`Pre = ⋁_i Pre(c_i)`，且只在**覆盖达标**的分支中路由，选中分支的 `Inv` 成立；
- **Parallel**：全部子节点有效且满足非干扰 `NI`，`Inv = ⋀_i Inv(c_i)`；
- **Decorator（Retry / Timeout）**：`Inv` 跨 tick 保持，并与 v20 CFCtrl 的 TTL 对齐。

整树安全 = 契约在根的**最小不动点**，且所有叶子覆盖达标；未消解的树一律不进入 `Exec_v21`。

## 3. 与基线的接口（如何退化）

- CCD 失效（语料缺失 / 损坏 / 版本不可追溯）⇒ 无支撑 ⇒ 回退 v20 的 HPC ⇒ `Exec_v21 = Exec_v20`；
- CCG 失效（校准集不足 / 交换性被拒）⇒ 只用经验证书并放大 `margin_col_fed` ⇒ 等价 v20（更保守）；
- CBT 失效（契约规格缺失 / 树结构非法）⇒ 逐原语证书 ⇒ 等价 v20；
- CGAP 失效（采集预算为零）⇒ 只执行已有支撑，活性下降，安全不变；
- CFSM 漂移（TTL 超期 / 两样本拒绝 / 密度比越界）⇒ 重校准或回退 v20；
- 全失效 ⇒ 完全回退 v19 的 CCV；
- **安全继承**：CCD 只收窄支撑、CCG 只加统计门、CBT 只消解已有叶子契约、CGAP 只采集不授权、CFSM 只降级；五者叠加只产生子集，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18` 由引理 164 保证。

## 4. 预期贡献

1. **证书语料与数据表**：首次把“碰撞证书”数据集化，给出支撑集、数据表、标签噪声与版本演化的机械语义，使证书的“有效范围”第一次成为一等公民；
2. **保形安全证书**：首次把分布无关、有限样本的覆盖保证引入碰撞证书，并揭示“行为树组合会稀释覆盖保证”这一结构性现象，给出覆盖预算分配方案；
3. **契约行为树**：首次把行为树 tick 语义升级为契约传播，证明组合 soundness 与覆盖感知 Selector 的安全性，使“整棵任务树的安全”可组合验证；
4. **覆盖引导采集闭环**：把“证明义务”编译成数据需求，实现“安全缺口 → 定向采集 → 重校准”的主动闭环，让数据集从被动资产变为主动安全工具；

## 5. 本轮最大风险

**一句话**：**自证数据集 × 行为树组合放大**——若覆盖标注由同一条 v20 证书管线自产（循环论证），而 CBT 只要各叶子“自证覆盖达标”就把整树判 SAFE，则一个被系统性漏覆盖的叶子会被组合放大为树级“已认证”计划，即“数据集自证 + 契约合取 = 组合式伪安全”。

# IP-425 Certificate Corpus & Datasheet
@dataclass
class Datasheet:
    provenance: list      # (robot_id, sensor, timestamp, calib_id)
    coverage: dict        # theta-cell -> certified density
    label_noise: float    # verdict 误标上界
    splits: dict          # build / calibrate / test
    version: str
    support_eps: float

class CertificateCorpus:
    def __init__(self, eps=0.01, m_min=8):
        self.records = []
        self.eps = eps
        self.m_min = m_min
        self.datasheet = None
        self._kd = None
        self._split_ids = set()

    def add(self, state, action, verdict, proof, geom_ctx, meta, split):
        assert split in ("build", "calibrate", "test")
        rid = self._record_id(state, action)
        # 防泄漏：同一条 trace 不得跨 split 复用（见失效模式 5）
        if (rid, split) in self._split_ids and split != "build":
            return None
        if any(rid == r for r, s in self._split_ids if s != split):
            return None
        self._split_ids.add((rid, split))
        rec = CorpusRecord(state, action, verdict, proof, geom_ctx, meta, split)
        self.records.append(rec)
        self._kd = None
        return rec

    def _rebuild(self):
        self._kd = KDTree([r.state for r in self.records if r.split != "test"])

    def kth_radius(self, theta):
        if self._kd is None:
            self._rebuild()
        dists, _ = self._kd.query(theta, k=self.m_min + 1)
        return dists[-1]

    def in_support(self, theta):
        return self.kth_radius(theta) <= self.eps

    def build_datasheet(self):
        prov = [(r.meta.robot_id, r.meta.sensor, r.meta.ts, r.meta.calib_id)
                for r in self.records]
        self.datasheet = Datasheet(
            provenance=prov,
            coverage=self._coverage_map(),
            label_noise=self._label_noise_bound(),
            splits=self._split_stats(),
            version=self._version(),
            support_eps=self.eps,
        )
        return self.datasheet


# IP-426 Conformal Coverage Gate
class ConformalCoverageGate:
    def __init__(self, alpha=0.1):
        self.alpha = alpha
        self.qhat = None

    def nonconformity(self, rec):
        # 越大越危险：证书 margin 的违背度
        return max(0.0, rec.margin_col - rec.signed_distance)

    def calibrate(self, corpus):
        scores = sorted(self.nonconformity(r)
                        for r in corpus.records if r.split == "calibrate")
        n = len(scores)
        if n == 0:
            raise ValueError("NO_CALIBRATION_DATA")
        k = math.ceil((n + 1) * (1 - self.alpha))
        self.qhat = scores[min(k, n) - 1]
        return self.qhat

    def certify(self, theta, verdict, score, corpus):
        if not corpus.in_support(theta):
            return "ABSTAIN"                 # 出支撑集
        if verdict == "UNSAFE":
            return "UNSAFE"
        return "SAFE" if score <= self.qhat else "ABSTAIN"

    def risk_bound(self):
        return self.alpha


# IP-427 Contracted Behavior Tree
@dataclass
class Contract:
    pre: Callable
    post: Callable
    inv: Callable
    criticality: float = 1.0

class ContractedBehaviorTree:
    def __init__(self, root, alpha_root=0.1, kappa=0.95):
        self.root = root
        self.alpha_root = alpha_root
        self.kappa = kappa

    def leaves(self, node=None):
        node = node or self.root
        if node.kind == "leaf":
            return [node]
        out = []
        for c in node.children:
            out.extend(self.leaves(c))
        return out

    def allocate_budget(self):
        leaves = self.leaves()
        wsum = sum(l.contract.criticality for l in leaves)
        for l in leaves:
            l.alpha_v = self.alpha_root * l.contract.criticality / wsum
        return {id(l): l.alpha_v for l in leaves}


# IP-428 Compositional Certificate Propagator
class CompositionalCertificatePropagator:
    def __init__(self, corpus, ccg, cbt):
        self.corpus = corpus
        self.ccg = ccg
        self.cbt = cbt

    def certify_leaf(self, leaf, theta, trace):
        if not self.corpus.in_support(theta):
            return "ABSTAIN"
        rec = self.corpus.query(theta)
        verdict = self.ccg.certify(
            theta, rec.verdict, self.ccg.nonconformity(rec), self.corpus)
        if verdict != "SAFE":
            return verdict
        if not leaf.contract.pre(trace) or not leaf.contract.inv(trace):
            return "ABSTAIN"
        if self.realized_coverage(leaf) < 1.0 - leaf.alpha_v:
            return "ABSTAIN"                 # 覆盖预算未达标
        return "SAFE"

    def certify(self, node, ctx):
        k = node.kind
        if k == "leaf":
            return self.certify_leaf(node, ctx.theta, ctx.trace)
        if k == "sequence":
            for c in node.children:
                if self.certify(c, ctx) != "SAFE":
                    return "UNSAFE"
            for a, b in zip(node.children, node.children[1:]):
                if not implies(a.contract.post, b.contract.pre, ctx):
                    return "ABSTAIN"
            return "SAFE"
        if k == "selector":
            for c in node.children:
                if self.realized_coverage(c) < self.cbt.kappa:
                    continue                 # 覆盖感知路由：跳过欠覆盖分支
                if self.certify(c, ctx) == "SAFE":
                    return "SAFE"
            return "ABSTAIN"
        if k == "parallel":
            if any(self.certify(c, ctx) != "SAFE" for c in node.children):
                return "UNSAFE"
            return "SAFE" if non_interfering(node.children, ctx) else "ABSTAIN"
        if k == "decorator":
            if not across_ticks_invariant(node, ctx):
                return "ABSTAIN"
            return self.certify(node.children[0], ctx)
        return "ABSTAIN"

    def realized_coverage(self, node):
        return node.stats.empirical_coverage if node.stats.n > 0 else 0.0


# IP-429 Coverage-Guided Acquisition Planner
class CoverageGuidedAcquisitionPlanner:
    def __init__(self, corpus, cbt):
        self.corpus = corpus
        self.cbt = cbt

    def find_gaps(self):
        gaps = []
        for leaf in self.cbt.leaves():
            target = 1.0 - leaf.alpha_v
            deficit = max(0.0, target - leaf.stats.empirical_coverage)
            if deficit <= 0:
                continue
            for h in self.corpus.low_density_regions(leaf.domain, eps=self.corpus.eps):
                gaps.append(Gap(
                    leaf=leaf, theta=h, deficit=deficit,
                    gain=deficit * leaf.contract.criticality,
                    cost=self.estimate_cost(h),
                ))
        return sorted(gaps, key=lambda g: g.gain / g.cost, reverse=True)

    def propose(self, budget):
        picked, spent = [], 0.0
        for g in self.find_gaps():
            if spent + g.cost > budget:
                break
            picked.append(g)
            spent += g.cost
        return picked


# IP-430 Corpus Freshness & Shift Monitor
class CorpusFreshnessShiftMonitor:
    def __init__(self, aps, ttl_corpus=30.0, beta=0.1):
        self.aps = aps
        self.ttl_corpus = ttl_corpus
        self.beta = beta

    def density_ratio(self, theta, corpus, live):
        return density_live(theta) / max(1e-9, density_corpus(theta, corpus))

    def exchangeability_test(self, corpus, live_window):
        return mmd_test(corpus.recent(), live_window)

    def check(self, corpus, live_window, now):
        if now - corpus.timestamp > self.ttl_corpus:
            return "STALE_RECALIBRATE"
        if self.exchangeability_test(corpus, live_window) > self.beta:
            return "SHIFT_RECALIBRATE"
        if any(self.density_ratio(t, corpus, live_window) > 1.0 / self.beta
               for t in live_window):
            return "OOD_ABSTAIN"
        return "OK"

    def gate(self, plan, corpus, live_window):
        mode = self.check(corpus, live_window, time.time())
        if mode != "OK":
            return self.aps.activate_freshness_ladder(plan, force_mode="V20")
        return self.aps.update_plan_risk(plan, mode_corpus="V21")

## 2. 推导

**引理 157（语料支撑保守性）** `Supp_ε(C)` 由 kNN 半径与局部密度定义；CCP 对 `θ ∉ Supp_ε(C)` 返回 `ABSTAIN`，且 `C` 中所有 verdict 均来自 v20 已认证记录。故 v21 认证轨迹上的每个 θ 都落在 v20 可认证域内，`Exec_v21 ⊆ Exec_v20`。∎

**引理 158（保形覆盖的有限样本保证）** 若校准语料与测试轨迹可交换，非一致性分数 `s` 的保形分位数 `q̂ = s_{⌈(n+1)(1−α)⌉}` 满足 `P(s_test ≤ q̂) ≥ 1−α`。以 `L = 1[SAFE ∧ collision]` 为损失、取 `q̂` 作风险控制阈值，则 `E[L] ≤ α`（保形风险控制）。∎

**引理 159（行为树组合的覆盖稀释）** 设 `L(T)` 为叶子集合，`E_v` 为叶子误覆盖事件。由联合界 `P(∪_v E_v) ≤ Σ_v α_v`。若统一取 `α_v = α`（不分配预算），全局上界为 `|L(T)|·α`，随树规模线性退化；Bonferroni 取 `α_v = α/|L(T)|` 则恢复 `≤ α`。∎

**引理 160（契约传播可靠性）** 对 BT 结构归纳。叶子：`Cert` 有效 ⇒ 轨迹满足 `Inv_v`。Sequence：子节点有效 + `Post(c_i) ⇒ Pre(c_{i+1})` ⇒ 拼接轨迹满足各 `Inv` 与转移约束。Selector：被选中分支有效 ⇒ 满足其 `Inv` 且 `Pre` 成立。Parallel：全部有效 + `NI` ⇒ 并发轨迹满足合取不变式。Decorator：跨 tick 保持 `Inv`。故 `⟦T⟧` 中每条轨迹满足 `Inv(root)`。∎

**引理 161（覆盖感知 Selector 安全性）** Selector 仅当分支实测覆盖 `Ĉ_c ≥ κ` 且 `Cert(c) = SAFE` 时才选择该分支；欠覆盖分支被跳过，故不会路由到语料未支撑区域，不产生新的假安全轨迹。∎

**引理 162（采集闭环的安全单调性）** CGAP 只增加样本并触发重校准，不直接产生 `SAFE`；认证仍须通过支撑、覆盖、契约三道门。故采集不会使 `Exec_v21` 越过 `Exec_v20`；随样本增加，`Ĉ_v` 依 DKW / 集中不等式收敛到真实覆盖，认证集合单调逼近 v20 上界。∎

**引理 163（漂移门的安全性）** 若 `now − t_corpus > TTL`、或两样本检验统计量 `> β`、或密度比 `> 1/β`，CFSM 返回非 `OK` 并回退 v20；故漂移下 `Exec_v21 = Exec_v20`。∎

**引理 164（v21 整体安全继承）** 在固定语料、几何与机器人集合下，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。证明：CCD 只收窄支撑、CCG 只加统计门、CBT 只消解已有叶子契约、CGAP 只采集不授权、CFSM 只降级；五者叠加只产生子集。∎

## 6. 已知风险与失效模式

1. **自证数据集（循环覆盖）**：覆盖标注若由同一条 v20 证书管线自产，则 `Supp_ε(C)` 只是“管线自认为覆盖”的地方，而非真实安全域。缓解：独立校准通道、异构传感器交叉验证、留出集强制隔离。

2. **交换性被破坏**：保形保证依赖校准集与部署轨迹可交换；真实部署的物体、光照、磨损会漂移。缓解：CFSM 两样本检验 + 密度比 + 滑窗重校准；漂移即回退。

3. **覆盖预算错配**：Bonferroni 过保守会大幅损失活性；按关键度加权若权重估计失真，则全局覆盖不再受控。缓解：e-value 融合、分层 α 分配、在线校准权重。

4. **契约规格错误**：组合 soundness 依赖 `Pre/Post/Inv` 写对；规格本身漏掉约束（如未建模的碰撞耦合）时，形式证明会放大错误。缓解：契约单元测试、运行时监视器、与 v20 HPC 交叉校验。

5. **数据泄漏**：同一轨迹同时进入 build 与 calibrate，会使保形覆盖虚高（经典数据泄漏）。缓解：哈希去重、split 隔离、泄漏检测器（E790）。

6. **Selector 非确定性 / 竞态路由**：若分支覆盖与前置条件在 tick 间变化，Selector 可能瞬时路由到未支撑分支。缓解：tick 内快照、路由决策单调化、覆盖缓存加锁。

7. **主动采集引入分布偏置**：CGAP 专挑“缺口”采样，会改变语料分布，反过来破坏交换性。缓解：采集与校准分池、重要性加权、采集后重新做交换性检验。

8. **语料版本与增量失效**：物体几何、标定、传感器版本变化后，旧语料仍被引用，证书静默过期。缓解：语料版本号 + 依赖闭包 + 失效传播（借鉴 v17 的 CPM）。

## 7. 本轮最大风险

**一句话**：**自证数据集 × 行为树组合放大**——若覆盖标注由同一条 v20 证书管线自产（循环论证），而 CBT 只要各叶子“自证覆盖达标”就把整树判 SAFE，则一个被系统性漏覆盖的叶子会被组合放大为树级“已认证”计划，即“数据集自证 + 契约合取 = 组合式伪安全”。
