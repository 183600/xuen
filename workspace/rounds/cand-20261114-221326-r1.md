# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互消歧」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「跨物体泛化」×「场景落地」）

> R69 把不确定性拆成 aleatoric 与 epistemic，用流匹配给出「有形状的歧义」，用看/问/触去消解。但它悄悄依赖一个前提：**策略吐出的那几个模态里，一定有一个是对的**——系统只是不知道选哪个。跨物体泛化正好击穿这个前提：面对新物体（质量、摩擦、柔性、关节约束、质心都变了），策略往往不是「犹豫」，而是**自信地做错**。流模型的速度场是 Lipschitz 的，分布外条件会被光滑外推到某个训练模态上，于是 H_mode 低、U_ale 低、FMA 的动作似然甚至更高——**R69 的三盏灯全绿，系统却在一个它从未理解的对象上全速前进**。真实场景里最致命的从来不是高方差抖动，而是低方差的错误（confident wrongness）。
>
> 本轮两个灵感各补一刀：
> - **跨物体泛化**逼我们承认不确定性的第三维：不是「哪一个已知模态」（epistemic），而是「这些模态到底适不适用于这个对象」（novelty，模型类之外）。它要求把潜状态显式拆成物体无关的任务语义 z_task 与物体特有的物理参数 θ_obj，并让 θ_obj 可估计、可探测、可拒绝迁移。
> - **场景落地**逼我们承认：证书不是全局布尔值，而是**带作用域的契约**。真实部署的价值不在于「在验证集上很强」，而在于「知道自己在哪里不成立，并在边界上安全退化」。每个对象需要一本护照，每个场景需要一次准入判定，每次能力升级需要统计证据。
>
> 核心命题：**把不确定性升级为三分——aleatoric（收紧）、epistemic（交互消解）、novelty（对象/场景级的不适用）——并给三者三条不同的响应通道：λ 缩放、信息动作、物理辨识/域外退化。跨物体泛化 = 用「对象护照」做可计算的组合泛化与负迁移保护；场景落地 = 用「带 ODD 的证书 + 分级放行」把「能跑」变成「可审计地知道自己何时不能跑」。** 命名 **PASSPORT-RAS**（Physical-Aware Scoped Safety via Probing, Object Registration & Transfer）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我对眼前这个对象、这个场景，还有资格自信吗**」——泛化不是更聪明地推理，而是知道自己的执照在哪失效。

## 0. 直觉与动机

**灵感 1（跨物体泛化 → 尖锐外推：低熵的错误）**
直觉：R69 的歧义是「support 之内选哪个模态」；跨物体失败是「support 之外根本没有正确模态」。更糟的是，流/扩散模型的速度场被训练成光滑回归器：给一个分布外条件，它不会像高斯过程那样把方差撑大，而是沿最近的训练流形**平滑外推**出一个尖锐、低熵、看似可信的轨迹。于是所有「看内部不确定性」的仪表（模态熵 H_mode、模态内方差 U_ale、动作似然 a_score）在这个最危险的时刻**同时读数偏低**。这不是阈值没调好，而是**仪表测错了物理量**：它们测的是「在假定模型类正确的前提下有多犹豫」，而不是「模型类本身是否适用」。跨物体泛化的第一步，是承认「更不确定」不会自动出现，必须另设一条能看见「预测不了」的通道。

**灵感 2（物体不是一个类别标签，而是一组物理参数）**
直觉：把「新物体」当成一个新的类别标签（object id = 47）是无用的——它不告诉你该怎么迁移。真正决定动作的是可测的物理量：质量与质心、接触摩擦、柔性/刚度、关节自由度与限位、可抓取面几何、热/磨损状态。把潜状态拆成 **z_task（物体无关的任务语义：这是「把杯子放上架子」）** 与 **θ_obj（物体特有的物理参数）**，跨物体泛化就从一个「网络容量/数据量」问题变成两个可检验的问题：(a) z_task 是否真的跨物体不变；(b) θ_obj 是否可从本体感知/短程激励中辨识。前者是表征学习命题，后者是系统辨识命题——都可被实验否证。新物体的正确姿态不是「祈祷策略泛化」，而是**给它做一次短程「体检」，发一本记录 θ_obj 与适用域的护照**。

**灵感 3（novelty 不能靠「更不确定」发现，只能靠「预测不了」发现）**
直觉：R69 的 FMA 用动作轨迹在策略密度下的似然做第二意见，但它与策略**共享同一个错误的对象假设**：策略以为物体是 A，于是自信地生成「A 的动作」，观测到的也确实是这个动作，似然很高，残差也很低——自洽不等于正确。唯一能看见 θ 错的是**结果**：执行动作后，真实下一状态 s_{t+1} 与对象条件动力学 f_{θ̂}(s_t,a_t) 的偏差。这是「物理预测误差」，与传感器残差、动作似然都正交。它也有代价：某些参数方向在小信号下不可辨识（质量与摩擦在匀速段混淆），所以必须**主动激励**才能让 ∂f/∂θ 显形——这把 R69 的「问」升级为「探（exciting probe）」：不是问人「这杯子重吗」，而是做一次受控的小动作，让物理自己回答。

**灵感 4（负迁移：迁移是一笔有风险的贷款）**
直觉：跨物体泛化最诱人的捷径是「邻居能用，我也能用」。但 R68 的铁律「不确定 → 只收紧」在这里必须升级为「**迁移距离越远，初始包络越收缩**」：从相似对象借来的护照只能当先验，不能当结论，且必须按对象距离支付「迁移保证金」。距离足够远时，正确做法是**拒绝迁移、从零做安全的小信号体检**，而不是用邻居的自信去覆盖自己的无知。错误的自信比诚实的无能更危险——后者会停下，前者会撞墙。

**灵感 5（场景落地 = 带作用域的证书 + 分级放行）**
直觉：实验室里的「一次成功」和现场里的「可交付」是两回事。落地意味着：有操作员、有验收标准、有维护周期、有监管责任、有长尾、有对象磨损。一个诚实的系统必须能回答三个问题：**我此刻是否在已验证的域内（ODD）？这本护照是否还在有效期？我的能力是否已被统计证据批准到这个自主等级？** 因此证书要从「布尔」变成「带 Ω 的契约」：Ω 内有效，Ω 外**显式作废**并进入最小风险态/交接，绝不静默失败。分级放行（shadow → guarded → supervised → autonomous）必须用**随时有效（anytime-valid）的风险置信序列**门控，而不是「跑三天没出事」。

**灵感 6（严格包含：新层必须是旧层的退化）**
直觉：R70 不能推翻 R68/R69，否则每加一层就多一个需要独立信任的黑箱。当「对象适用（U_nov=0）、场景全域（Ω=𝒮）、拒绝迁移」时，PASSPORT 必须逐指令退化为 FLUID；再加「永不交互」则退化为 R68。安全侧永不弱于旧层，效率侧才允许获得新收益。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PASSPORT-RAS 总览）** PASSPORT-RAS = (OCB, OPS, NED, NDT, CPR, OTM, ODM, SJC, DLR, CDL, FGH, FWF, RAS-WM‡)。四不变式：
(i) **实时零学习写操作**（继承 R68 定义 276-i）：实时环只改条件变量与包络，不写网络权重；
(ii) **交互/探测预算硬约束**（继承 R69 定义 293-ii，并区分社交信息动作与物理激励动作）；
(iii) **作用域原则**：任何安全声明必须携带作用域 Ω 与对象护照版本；Ω 外声明自动失效，不得静默沿用；
(iv) **证据纪律 + 迁移纪律**：单源证据不得定案（继承 R69）；跨对象迁移必须显式支付迁移保证金 λ_tr(d)，且 d > d_max 时**拒绝迁移**。

**定义 311（对象条件化生成模型）** 观测 o 由物体无关的任务语义 z_task 与物体特有物理参数 θ_obj 联合生成。策略
p(ξ|o) = ∫ p(ξ | z_task, θ_obj) p(θ_obj | o) dθ_obj。
OCB 双头输出 (z_task, θ̂_obj, Σ_θ)。**跨物体泛化的可检验假设**：(a) z_task 在物体间近似不变（不变性误差 ≤ δ_inv）；(b) θ_obj 在给定激励下局部可辨识（A102）。若 (a) 不成立，迁移无意义；若 (b) 不成立，任何护照都不可信——必须先补传感或缩域。

**定义 312（对象护照）** 每个具体对象实例（不是类别）持有一本护照
𝒫 = (oid, θ̂_obj, Σ_θ, E_norm, Ω_admit, d_prov, t_issue, t_exp, debt, transfer_chain, prov_hash)。
其中 E_norm 为认证包络（参数空间 × 动作空间 × 任务空间的联合可信域）；Ω_admit 为已准入的场景集合；d_prov 为数据来源与责任人；t_exp 为有效期（物理参数随磨损/温漂漂移，护照会过期）；debt 为覆盖负债（定义 320）；transfer_chain 记录迁移谱系用于追溯负迁移；prov_hash 为审计哈希链。**护照不是「证明能用」，而是「证明在何处、凭何证据、由谁负责地能用」。**

**定义 313（不确定性三分 NDT）** 沿用 R69：U_ale = Σ_k ŵ_k tr(Σ_k)（模态内、不可约）；U_epi = H_mode·g(Δ_min)（模态间、可在 support 内消解）；新增
U_nov = 1 − p_t（模型类之外、对象/场景级不适用），p_t 由定义 314 给出。
三者语义不同，**不做加权求和**，分别进入三条响应通道（定义 318、321、322）。关键：U_nov 不能被 U_epi 或 U_ale 上界，因为流模型在 support 外可以任意尖锐（引理 19）。

**定义 314（新颖性证据检测 NED）** 令对象条件动力学一步预测残差
e_t = ‖s_{t+1} − f_{θ̂}(s_t, a_t)‖²_{Σ_f^{-1}}。
在校准集（同 Ω、同护照版本的留出残差）上做 split-conformal：p_t = (1 + #{e_cal ≥ e_t}) / (n + 1)，U_nov = 1 − p_t。当 p_t < α_nov 触发新颖性告警。conformal 的交换性假设只在 Ω 内成立；跨域交换性由 ODM（定义 317）显式拒绝，而不是假装成立。残差通道与 R68 的传感器残差 r_res、R69 的动作似然 a_score 正交：前者测「模型是否描述了这个对象」，后两者测「传感器/行为是否自洽」。

**定义 315（Commissioning 协议 CPR）** 主动物理辨识：选择激励序列 u_{1:m}（小信号、能量/位移/时长有界），
u* = argmax_u [ VoI_phys(u) − c_phys(u) ]，s.t. risk(u) ≤ ε_comm，budget 未超，
其中 VoI_phys(u) = H(θ_obj|o) − E_y[H(θ_obj|o,u,y)]。当 H(θ_obj|o) ≤ τ_θ 或预算耗尽即停，得到 (θ̂′, Σ_θ′) 并认证包络 E_norm′。**这是 R69 MINT 的物理镜像：不是问人，而是让物理回答；且激励本身必须过 C-RAS-WM 认证（引理 20 说明为何必须主动激励）。**

**定义 316（对象距离与迁移保证金 OTM）** 对象距离
d_obj(𝒫_i, 𝒫_j) = W_2(θ̂_i, θ̂_j; Σ) + λ_Ω · d_H(Ω_i, Ω_j)。
迁移先验 θ̂_0 取最近邻护照的加权组合；保证金 λ_tr(d) = min(1, L_θ·d/ε_0)；初始包络 E_init = E_neighbor ⊖ λ_tr（按比例收缩）。**准入条件**：d ≤ d_max 且 E_init 非空；否则拒绝迁移，走从零 CPR。这把「泛化」变成一笔有明确定价的贷款（引理 21）。

**定义 317（ODD 与域监测 ODM）** Ω = (对象类别, 负载, 表面/摩擦, 光照, 人机距离, 任务)。域监测输出 d_ctx(o) 与 in_Ω(o)；域外即证书作废。ODM 还监测**交换性漂移**（残差分布的时间漂移），一旦漂移超阈，即使仍在名义 Ω 内也降级——因为 conformal 的 p 值不再有效。这是 R68 缓变故障监测在部署域的对应物。

**定义 318（作用域证书 SJC）** J_PASSPORT = (J_FLUID, passport_hash, Ω_hash, θ̂_obj, U_nov, p_t, d_ctx, envelope_coverage, debt, ladder_state, field_ver)。
Valid ⇔ Valid(J_FLUID) ∧ in_Ω(o) ∧ p_t ≥ α_nov ∧ debt ≤ b_max ∧ ¬expired(𝒫) ∧ ladder_state ≥ required。
**Valid 是「条件于 Ω 与护照」的声明**：Ω 外不是「False」，而是「void」——二者的区别是，False 会被误读成「检查过且不行」，void 明确表示「此证书无权对此情形发言」。

**定义 319（分级放行 DLR）** 自主等级 D0 shadow（只推理不执行）、D1 guarded（监督者可否决）、D2 supervised（人在场可接管）、D3 autonomous（Ω 内全自主）。升级 D_k → D_{k+1} 需在**预注册**的样本量与验收指标下，风险的经验上界（e-process / 置信序列）低于 ε_k；任一红事件即刻**单向降级**。预注册防止「跑够了就说安全」的事后挑选。

**定义 320（覆盖负债 CDL）** 在 E_norm 之外但 Ω 之内的每次操作记负债 δ（按距包络边界的距离与任务风险加权）；负债通过 CPR 扩张包络或离线重训偿还；debt > b_max ⇒ 禁止升级并强制降额。**这是把「先上线再补证据」的隐性技术债显式化成可审计账本。**

**定义 321（退化阶梯与交接 FGH）** 回退策略 π_fb 与阶梯：继续 → 降额 → 物理体检 → 问人 → 最小风险态 → 交接。选择在「成功概率 ≥ p_min」约束下最小化期望风险，且每一级必须自身通过 C-RAS-WM 认证并可到达。**落地系统的安全性由最坏分支决定，而不是由平均成功率决定。**

**定义 322（离线飞轮 FWF）** 现场数据 → 离线重训 → **回归门**：新版本在每个既有 Ω 上的风险上界不得高于旧版本；通过后版本号递增并重签受影响护照。实时环永不写权重（不变式 310-i），因此「现场适应」与「实时安全」解耦：适应只改条件与包络，权重只在离线换装（继承 R68 换装不变式）。

**定义 323（威胁模型 ℰ_FIELD）** 在 R69 的 ℰ_FLUID 之外新增：**对象伪装**（外观/语义相似但物理参数不同的物体）、**包络博弈**（操作员为推动产能把系统推出 Ω）、**证书重放**（把旧护照/旧证书套到新对象）、**飞轮投毒**（有偏现场数据污染 θ 先验与 conformal 校准集）、**负迁移**、**域监测规避**。

**定义 324（部署审计 VQAuditor-D）** 审计护照签发（θ̂ 是否由合规激励得到）、novelty 告警与复核、升级证据是否预注册且随时有效、交接是否及时、负债是否被偿还。结论回灌 ODM 的漂移先验与 CPR 的激励成本先验。

**定义 325（时序与预算）** 常规路径：OCB 双头 + NED + 护照查表 + ODM < 2.8ms（与 R69 的 2.6ms 同量级）；CPR 为**偶发**进程（每对象 ≤ 30s，≤ 1 次/N 分钟），不进入毫秒级实时环；DLR 门控离线计算。

**定义 326（严格包含）** 令 U_nov ≡ 0、Ω = 𝒮、且拒绝一切迁移（每对象独立 CPR），则 PASSPORT 的决策与 FLUID 逐指令相同；再令永不交互（VoI ≤ c），则与 R68 逐指令相同。⇒ R70 是 R69 在「对象适用 + 场景全域」边界上的退化，安全侧不做让步。

## 2. 关键算法骨架

```python
# IP-264 OCB：对象条件化双头（任务语义 / 物理参数解耦）
class ObjectConditionedBackbone:
    def forward(self, o):
        z_task, mu, logvar = self.trunk(o)      # 复用 R68 MTM trunk
        return z_task, mu, torch.exp(0.5 * logvar)

# IP-266 NED：用「结果残差」看 novelty（conformal，Ω 内交换）
class NoveltyEvidenceDetector:
    def __init__(self, dynamics, calib_residuals, alpha=0.01):
        self.f, self.calib, self.alpha = dynamics, calib_residuals, alpha

    def score(self, s, a, s_next, theta_hat):
        e = mahalanobis(s_next, self.f(s, a, theta_hat), self.Sigma_f)
        p = (1 + (self.calib >= e).sum()) / (len(self.calib) + 1)
        return 1.0 - p, p                    # (U_nov, p_t)

# IP-265/270 OPS+OTM：护照查表 + 负迁移保护的迁移
def resolve_object(obs, ledger, L_theta, d_max):
    P = ledger.get(instance_id(obs))          # O(1)
    if P is not None and not P.expired:
        return P, 0.0
    nn, d = ledger.nearest(obs)
    if nn is None or d > d_max:
        return None, d                        # 拒绝迁移 → 从零体检
    lam = min(1.0, L_theta * d / EPS0)
    return reissue_with_shrink(nn, lam), d    # 借来的护照必须收缩包络

# IP-268 CPR：主动物理辨识（小信号、可认证）
def commission(obs, budget, c_ras_wm, eps_comm):
    post = prior_from_uniform_or_transfer(obs)
    while budget.left and entropy(post) > TAU_THETA:
        u = argmax_u(voi_phys(post, u) - c_phys(u))
        if not c_ras_wm.certify_probe(u):  continue
        y = execute_probe(u)                  # 能量/位移/时长有界
        post = bayes_update(post, u, y)
    return post, certify_envelope(post)       # (θ̂, E_norm)

# IP-267 NDT：三分（ale / epi / nov），不加权求和
def trichotomy(policy, obs, z_task, theta_hat, ned):
    K = 1 if policy.mode_head(z_task, theta_hat) < TAU_MODE else 4
    samples = policy.sample(obs, K, cond=(z_task, theta_hat))
    U_ale, U_epi, modes = decompose(samples)  # 继承 R69
    U_nov, p_t = ned.score(obs.s, obs.a, obs.s_next, theta_hat)
    return U_ale, U_epi, U_nov, p_t, modes

# IP-272 DLR：任何时候有效的升级门 + 单向降级
def ladder_gate(eprocess, eps_k, red_event):
    if red_event:        return "demote_now"
    return "promote" if eprocess.upper() < eps_k else "hold"

# IP-278 主闭环（继承 R69，先问「有没有资格」再问「选哪个」）
def PASSPORT_RAS_round(M, obs):
    z_task, theta_hat, Sig = M.ocb(obs)
    # 1) 作用域先于一切：证书是带域契约，不是全局布尔
    in_odd, d_ctx = M.odm.check(obs, M.scene)
    P, d_obj = M.resolve_object(obs)
    if not in_odd or P is None or P.expired:
        return M.fgh.degrade(M.state, reason="out_of_scope_or_no_passport")
    # 2) 三分不确定性
    U_ale, U_epi, U_nov, p_t, modes = M.ndt.trichotomy(M.fmp, obs, z_task, theta_hat, M.ned)
    # 3) novelty 优先：对象都可能不对，先别讨论「选哪个模态」
    if U_nov > TAU_NOV or p_t < ALPHA_NOV:
        if M.cpr.budget_ok():
            theta_hat, E = M.cpr.commission(obs, M.cpr.budget, M.c_ras_wm, EPS_COMM)
            P = M.ops.reissue(P, theta_hat, E)
            U_nov, p_t = M.ned.recalibrate_and_score(P, obs)   # 用新护照复核
        if U_nov > TAU_NOV:                    # 体检也没救回来
            return M.fgh.degrade(M.state, reason="novelty")
    # 4) epistemic 消解（仅在对象适用之后）
    g = (M.mint.choose_interaction(modes, obs, M.budget)
         if U_epi > TAU_EPI else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 5) 风险缩放：novelty 未消解 ⇒ 不可用 resolution bonus，直接保守/退化
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    mode = select_mode(modes, U_epi, lam)
    # 6) 作用域证书 + 负债 + 分级放行
    debt = M.cdl.log(P, mode, d_ctx)
    J = M.sjc.build(M, P, U_nov, p_t, d_ctx, debt)
    if not M.dlr.allows(M.scene, J):
        return M.fgh.degrade(mode, reason="ladder_gate")
    tau = M.pi_sigma.prefix_dispatch(mode.a[:M.c_ras_wm.certified_prefix(mode.a)]) * lam
    M.vqa_d.submit_async(P, J, U_nov, p_t, d_obj, debt)
    return tau, lam, mode, (U_ale, U_epi, U_nov)
```

## 3. 推导

**引理 19（尖锐外推：内部不确定性不是 novelty 检测器）** 设速度场 v_θ(·,·|o) 关于 (x,s) 满足 L-Lipschitz（A101），rectified flow 的流映射 Φ_o: x_0 ↦ x_1 可逆且 Lipschitz 常数 ≤ e^L，其 Jacobian 行列式因此有正下界。于是条件 o 远离训练 support 时，Φ_o 既不会把噪声「放大成高熵」，也不会让模态分裂；输出分布的熵由流映射的局部伸缩决定，而非由 o 到训练集的距离决定。可构造对角速度场使 H_mode(o_nov) = 0 < H_mode(o_in)。**故 H_mode、U_ale、a_score 在 support 外可同时偏低；把「更不确定」当作 novelty 信号在原理上不成立**——R69 的三盏灯对跨物体失败是盲的。

**引理 20（novelty 只从结果残差可见，且必须主动激励）** 设真实动力学 f_{θ*}，估计 f_{θ̂}。若沿激励方向 u 有 ‖∂f/∂θ‖ ≥ c_u > 0，则一步残差 e = ‖s_{t+1} − f_{θ̂}(s_t,a_t)‖ ≥ c_u‖θ* − θ̂‖ − σ。反之，策略的条件分布可以完全以 θ̂ 自洽（它「以为」对象是 θ̂ 并生成对应动作），因此动作似然与传感器残差都可保持很低。**⇒ (r_res↓, a_score 低) 与 novelty 不矛盾；唯一判别量是对象条件动力学的预测残差 e，且其灵敏度 c_u 只在激励方向 u 上非零——这解释了为什么 CPR 必须主动、且必须小信号有界**（A102 给了可辨识性前提）。

**引理 21（负迁移上界与拒绝迁移判据）** 从距离 d 的邻居护照迁移，若真参数满足 ‖θ* − θ_nn‖ ≤ d + ν，则真实风险膨胀
ΔR ≤ L_R·(d + ν) + ε_est，
其中 L_R 为风险对物理参数的 Lipschitz 常数，ε_est 为先验估计误差。故所需包络收缩保证金 λ_tr ≥ L_R·d/ε_0；当 d > d_max ≜ (ε_0 − L_Rν − ε_est)/L_R 时，任何正的安全包络都无法由该邻居保证，**必须拒绝迁移**，走从零 CPR。系：迁移可视为一笔利率随 d 增长的贷款；负迁移不是偶发 bug，而是可以被距离界显式定价和拒绝的风险。

**定理 18（三分可分离性与响应不支配）** 在 A100（模态可分）、A101（Lipschitz 流）、A102（局部可辨识）、A103（Ω 内 conformal 可交换）下，三类不确定性的观测签名在给定上下文条件独立：U_ale 由模态内协方差可测、U_epi 由模态熵与间距可测、U_nov 由结果残差 p_t 可测。且**没有任何单一响应同时降低三者**：λ 缩放不改变错误的 support（对 U_nov 无效）；社交交互不改变物理参数（对 U_nov 无效，甚至可能因错误前提被放大）；物理辨识不降低模态内噪声（对 U_ale 无效）。⇒ 必须三分三通道；把三者塞进一个标量会必然在某一维上系统性失明。

**定理 19（分级放行的 anytime-valid 安全性）** 用 e-process / 置信序列对每个自主等级的「风险 ≤ ε_k」做检验，α 花费满足可加性。由 Ville 不等式，P(存在某次错误的升级) ≤ α（任意停时、任意样本量下成立）。单向即时降级保证降级路径不依赖未来证据。⇒ 「落地」的升级决策有可审计的统计保证，而不是「跑够了没出事」的事后叙事；预注册进一步排除事后挑选。

**定理 20（作用域证书的健全性与无静默失效）** 若 in_Ω(o) ∧ Valid(𝒫) ∧ p_t ≥ α_nov，则（在 A100–A104 与校准覆盖下）实际风险 ≤ ε_within；若 o ∉ Ω 或护照失效或 p_t < α_nov，则 J_PASSPORT 为 **void**，主环在选动作前即进入 π_fb，其风险 ≤ ε_fb。由于作用域检查先于任何动作执行，**不存在「证书已作废但系统仍在跑」的静默失效路径**。⇒ 场景落地的安全命题不是「永不失败」，而是「失败发生在被声明的位置，且被声明为失败」。

**定理 21（严格包含 R68/R69）** 取 U_nov ≡ 0、Ω = 𝒮、拒绝迁移并令每对象独立 CPR，则 SJC 退化为 J_FLUID、NDT 退化为 R69 的二分、主环逐指令等价于 FLUID；再令 VoI ≤ c（永不交互），逐指令等价于 R68。故 PASSPORT 在「对象适用 + 场景全域」边界上严格包含 R69，安全侧不做任何让步，效率侧的收益（跨对象迁移、分级放行）是可选择的增量。

## 6. 本轮最大风险

**一句话**：PASSPORT 的全部安全性押在「护照与 novelty 检验能诚实地说『我没见过这个对象』」这一前提上——**一旦 θ_obj 在可用传感下不可辨识（质量/摩擦/柔性混淆），或 conformal 校准集本身有偏（只覆盖了「像训练集的新物体」），NED 会系统性低报 novelty，系统就会带着一本合法、可审计的护照，在一个它从未理解的对象上自信运行；此时 R69 的「问错」被升级为 R70 的「合法地签错」——错误不再是一次失误，而是一份被制度背书的证书**。

**定义 311–312（对象条件化与护照）** `p(ξ|o)=∫p(ξ|z_task,θ_obj)p(θ_obj|o)dθ`；护照记录 `θ̂,Σ_θ,E_norm,Ω_admit,t_exp,debt,transfer_chain,prov_hash`，是「在何处、凭何证据、由谁负责地能用」的契约，而非「能用」的证明。

**定义 313–314（三分与 NED）** 三分 `(U_ale,U_epi,U_nov)`，不求和；`U_nov=1−p_t`，`p_t` 由对象条件动力学残差 `e_t` 的 split-conformal 得到；Ω 内交换性由 ODM 守护，Ω 外显式拒绝交换性假设。

**定义 315–316（体检与迁移）** CPR 最大化 `VoI_phys−c`，小信号激励辨识 θ，`H(θ)≤τ_θ` 即停；OTM 以 `d_obj` 定价迁移保证金 `λ_tr`，`d>d_max` 拒绝迁移、从零体检。

**定义 317–318（ODD 与证书）** `Ω` 六元组；SJC 仅在 `in_Ω ∧ Valid(J_FLUID) ∧ p_t≥α_nov ∧ debt≤b_max ∧ ¬expired ∧ ladder≥required` 时 Valid；Ω 外为 **void**（无权对此情形发言），不是 False。

**定义 319–321（放行、负债、退化）** DLR 用预注册 + e-process 置信序列门控升级，任一红事件单向降级；CDL 记录包络外负债，超债禁升级；FGH 退化阶梯每级须自身可认证、可到达，安全性由最坏分支决定。

**定义 322–326（飞轮、威胁、审计、时序、包含）** FWF 离线重训 + 回归门 + 护照重签，实时不写权重；ℰ_FIELD 增对象伪装/包络博弈/证书重放/飞轮投毒/负迁移/域监测规避；VQAuditor-D 审护照与升级证据；常规实时 < 2.8ms，体检在环外；`U_nov=0 ∧ Ω=𝒮 ∧ 拒绝迁移` 时退化为 FLUID，再 `VoI≤c` 退化为 R68。

## 3. 关键算法伪代码

```python
# IP-264 OCB：任务语义 / 物理参数解耦
class ObjectConditionedBackbone:
    def forward(self, o):
        z_task, mu, logvar = self.trunk(o)          # 复用 R68 MTM trunk
        return z_task, mu, torch.exp(0.5 * logvar)

# IP-266 NED：结果残差 + split-conformal（Ω 内交换）
class NoveltyEvidenceDetector:
    def score(self, s, a, s_next, theta_hat):
        e = mahalanobis(s_next, self.f(s, a, theta_hat), self.Sigma_f)
        p = (1 + (self.calib >= e).sum()) / (len(self.calib) + 1)
        return 1.0 - p, p                           # (U_nov, p_t)

# IP-265/269 OPS+OTM：护照查表 + 负迁移保护的迁移
def resolve_object(obs, ledger, L_theta, d_max):
    P = ledger.get(instance_id(obs))
    if P is not None and not P.expired: return P, 0.0
    nn, d = ledger.nearest(obs)
    if nn is None or d > d_max: return None, d      # 拒绝迁移
    return reissue_with_shrink(nn, min(1.0, L_theta * d / EPS0)), d

# IP-268 CPR：主动物理辨识（小信号、可认证）
def commission(obs, budget, c_ras_wm, eps_comm):
    post = prior_from_uniform_or_transfer(obs)
    while budget.left and entropy(post) > TAU_THETA:
        u = argmax_u(voi_phys(post, u) - c_phys(u))
        if not c_ras_wm.certify_probe(u): continue
        post = bayes_update(post, u, execute_probe(u))
    return post, certify_envelope(post)             # (θ̂, E_norm)

# IP-267 NDT：三分，不加权求和
def trichotomy(policy, obs, z_task, theta_hat, ned):
    K = 1 if policy.mode_head(z_task, theta_hat) < TAU_MODE else 4
    U_ale, U_epi, modes = decompose(policy.sample(obs, K, cond=(z_task, theta_hat)))
    U_nov, p_t = ned.score(obs.s, obs.a, obs.s_next, theta_hat)
    return U_ale, U_epi, U_nov, p_t, modes

# IP-278 主闭环：先问「有没有资格」，再问「选哪个」
def PASSPORT_RAS_round(M, obs):
    z_task, theta_hat, Sig = M.ocb(obs)
    in_odd, d_ctx = M.odm.check(obs, M.scene)
    P, d_obj = M.resolve_object(obs)
    if not in_odd or P is None or P.expired:
        return M.fgh.degrade(M.state, reason="out_of_scope_or_no_passport")
    U_ale, U_epi, U_nov, p_t, modes = M.ndt.trichotomy(M.fmp, obs, z_task, theta_hat, M.ned)
    if U_nov > TAU_NOV or p_t < ALPHA_NOV:          # novelty 优先于 epistemic
        if M.cpr.budget_ok():
            theta_hat, E = M.cpr.commission(obs, M.cpr.budget, M.c_ras_wm, EPS_COMM)
            P = M.ops.reissue(P, theta_hat, E)
            U_nov, p_t = M.ned.recalibrate_and_score(P, obs)
        if U_nov > TAU_NOV:
            return M.fgh.degrade(M.state, reason="novelty")
    g = (M.mint.choose_interaction(modes, obs, M.budget) if U_epi > TAU_EPI else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    mode = select_mode(modes, U_epi, lam)
    debt = M.cdl.log(P, mode, d_ctx)
    J = M.sjc.build(M, P, U_nov, p_t, d_ctx, debt)
    if not M.dlr.allows(M.scene, J):
        return M.fgh.degrade(mode, reason="ladder_gate")
    k = M.c_ras_wm.certified_prefix(mode.a)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(P, J, U_nov, p_t, d_obj, debt)
    return tau, lam, mode, (U_ale, U_epi, U_nov)
```

## 4. 推导

**引理 19（尖锐外推）** A101 下 rectified flow 的流映射可逆且 Lipschitz 常数 ≤ e^L，Jacobian 行列式有正下界；support 外条件不会把输出「撑成高熵」，可构造对角速度场使 `H_mode(o_nov)=0 < H_mode(o_in)`。⇒ `H_mode / U_ale / a_score` 同时偏低不能证明对象适用，内部不确定性不是 novelty 检测器。

**引理 20（novelty 只从结果残差可见，且须主动激励）** 沿激励 u 有 `‖∂f/∂θ‖≥c_u` 时，`e ≥ c_u‖θ*−θ̂‖−σ`；而策略可以完全以 θ̂ 自洽，使动作似然与传感器残差都偏低。⇒ 唯一判别量是对象条件动力学的预测残差，且其灵敏度只在激励方向上非零——CPR 必须主动且小信号有界。

**引理 21（负迁移上界）** 距离 d 的邻居迁移，真实风险膨胀 `ΔR ≤ L_R(d+ν)+ε_est`；故 `λ_tr ≥ L_R d/ε_0`，且 `d > d_max ≜ (ε_0−L_Rν−ε_est)/L_R` 时拒绝迁移、从零体检。

**定理 18（三分可分离、响应不支配）** A100–A103 下三类签名条件独立；λ 缩放不改错误 support（对 U_nov 无效），社交交互不改物理参数（对 U_nov 无效），物理辨识不降模态内噪声（对 U_ale 无效）。⇒ 必须三分三通道，任何单一标量都会在某一维系统性失明。

**定理 19（分级放行 anytime-valid）** e-process + α 可加花费，Ville 不等式给出 `P(∃错误升级) ≤ α`，任意停时/样本量成立；单向即时降级不依赖未来证据。⇒ 落地升级有可审计统计保证。

**定理 20（作用域证书健全、无静默失效）** 域内 + 护照有效 + `p_t≥α_nov` ⇒ 风险 ≤ ε_within；域外/失效/告警 ⇒ 证书 void，主环在选动作前进入 π_fb，风险 ≤ ε_fb。作用域检查先于执行 ⇒ 不存在「证书作废但仍在跑」的静默路径。

**定理 21（严格包含 R68/R69）** `U_nov≡0, Ω=𝒮, 拒绝迁移` ⇒ 退化为 FLUID；再 `VoI≤c` ⇒ 退化为 R68。安全侧不让步，效率侧收益（迁移、分级放行）为可选增量。

## 7. 本轮最大风险

**一句话**：PASSPORT 的安全性押在「护照与 novelty 检验能诚实地说『我没见过这个对象』」这一前提上——**一旦 θ_obj 在可用传感下不可辨识（质量/摩擦/柔性混淆），或 conformal 校准集本身有偏（只覆盖「像训练集的新物体」），NED 会系统性低报 novelty，系统就带着一本合法、可审计的护照，在从未理解的对象上自信运行；此时 R69 的「问错」被升级为 R70 的「合法地签错」——错误不再是一次失误，而是一份被制度背书的证书**。

**次级风险与缓解**：负迁移（定义 316 距离定价 + 引理 21 拒绝迁界 + E306）；校准集有偏/交换性破裂（ODM 漂移 + Ω 外 void + split-conformal + E307/E311）；体检不安全（小信号硬约束 + C-RAS-WM + 定理 20 作用域前置）；证书重放/对象伪装（哈希链 + 实例 oid + ℰ_FIELD + E313）；指标游戏（预注册 + e-process + 单向降级 + 定理 19）；飞轮遗忘/投毒（回归门 + 来源审计 + 护照重签 + E312/E313）。
