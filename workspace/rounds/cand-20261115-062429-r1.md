# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「手眼标定」×「示教学习」）

> R69 把不确定性一分为二，并让系统学会「问」。但它默认了一个从未被检验的前提：**观测与动作处在同一个、已知的坐标系里**。手眼标定恰好是这个前提的名字——相机看到的运动 B 与机械臂执行的运动 A 之间差一个未知的 SE(3) 变换 X，且必须满足 **A X = X B**。示教学习则把这个缺口放大成系统性风险：示教给出的从来不是「动作本身」，而是**在教师/相机坐标系里被观测到的动作**；策略要复现的是教师意图，中间必须穿过同一个 X。
>
> 于是 R70 要指出 R69 的盲点：**R68 看传感器残差，R69 看动作似然，但两者都在「假定坐标系」内部自洽。若策略与标定共享同一个错误的 X，残差与似然会同时归零——不是因为没有错误，而是因为错误被一致地编码进了策略。** 这既不是噪声，也不是可以问出来的歧义，而是一个**规范（gauge）偏差**：它不会随平均而消失，也不会随提问而减少，只能通过「换一个位姿去动一下」来暴露。
>
> 核心命题：**给不确定性补上第三根轴 U_gauge（SE(3) 规范不确定性）。三轴各有唯一对应的获取算子：aleatoric → 重复平均，epistemic → 交互询问，gauge → 主动激励。示教学习不是策略数据的同义词，它同时是规范测量（A X = X B）；但正因如此，「教」与「标」共享同一份数据会让 X 与 π 不可分（规范-策略混淆）。R70 的职责是：先辨识规范是否可观测，再决定激励、示教修正或保守。** 命名 **GAUGE-RAS**（Gauge-Aware Uncertainty from hand-eye calibration and demonstration GEneralization）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们说的是不是同一个坐标系**」——在你能问「哪个模态」之前，先得确认自己没有站在错误的参照系里。

## 0. 直觉与动机

**灵感 1（手眼标定 → 偏差不是方差，尺子只能靠另一把尺子量）**
直觉：R68/R69 的整套不确定性语言都是「围绕一个均值的方差」——再多看几眼、再问一句，方差就小一点。但手眼标定错误不是这样：如果相机与末端之间差了 1cm，那么**每一次**抓取都会偏 1cm，而且平均一百次仍然偏 1cm。它是一个**持续的坐标系偏置**，不是零均值噪声。更麻烦的是它的可观测性有结构：你无法在「同一个位姿」上把尺子校准，必须**换位姿去动**，让同一段物理运动在两个坐标系里留下不同的投影，才能解出 X。数学上这就是 A X = X B，即 A 与 B **共轭**：X 是那个把「看到的运动」变成「执行的去找运动」的 conjugator。规范误差不是「看得不准」，而是「看与做被同一个错误的旋转平移同时扭了一下」。

**灵感 2（示教学习 → 示教本身就是一次规范测量，也是一次规范污染）**
直觉：示教通常被当成「策略数据」：教师示范轨迹 → 策略模仿。但换个角度看，示教同时给出了 (B, A) 的对应：B 是教师在相机/观察者坐标系里的运动，A 是期望机器人在自身坐标系里复现的运动。二者正是手眼方程的两边。**所以示教学习天然是一个带策略副产物的手眼标定问题**；而手眼标定也天然是示教的前置条件。危险由此而来：如果策略拟合得好，它会把那个错误的 X 一起拟合进去——**越像老师，越忠实地继承老师的坐标系错误**。R69 的 FMA 之所以看不见它，是因为动作似然是在同一个错误 X 下算的，观测与动作一起被共轭，似然完全不变。

**灵感 3（两项灵感相撞 → 规范-策略混淆与「自洽的谎言」）**
直觉：给定一条示教，究竟「X 错了」还是「策略本来就是另一个动作」？在示教流形上这两种解释**产生完全相同的观测**。形式化地说，X 只能被确定到它的**中心化子（centralizer）**为止：任何与所有示教运动都可交换的 C，都能把 X 换成 X C 而不改变任何 A X = X B 的等式，同时把策略整体共轭一下。于是 R68 的残差、R69 的模态与似然、甚至 ECE，全都保持一致。系统会得到一个**内部处处自洽、外部系统性错误**的证书——这不是「诚实的不知道」，而是「被自己证实的错误」。唯一能打破它的，是一个**不在这份示教流形里的运动**（held-out excitation），或一个**来自独立坐标系的修正**（teach-back / 跨本体示教）。

**灵感 4（三轴分类 → 不确定性的「获取算子」比「大小」更本质）**
直觉：过去我们按「可不可约」分 aleatoric / epistemic；R70 提出更本质的切法——按**你拿什么动作去降它**来分：
- 重复同一观测可以降的，是 **aleatoric**（方差，~1/N）；
- 换一个条件观测/问一句可以降的，是 **epistemic**（歧义，按 VoI）；
- **只有改变相对位姿才能降的，是 gauge**（偏差，按 Fisher 信息秩）。
这三类不能互相替代：重复不会增加标定信息矩阵的秩，提问若没有改变相对位姿对 X 的 Fisher 信息就是零，而激励也永远消不掉传感器噪声。把「获取算子」写成不确定性的一等公民，才能解释为什么 R68/R69 的两种通道在规范错误面前同时失效。

**灵感 5（示教的双重用途 → 既省数据，又制造循环论证）**
直觉：动觉示教（kinesthetic teaching）最诱人之处是「一份数据两用」：人握着机械臂走一遍，既得到策略示范 A，又得到与视觉观测 B 的对应，于是**示教 = 免费的手眼标定数据**。但这也正是循环论证的入口：同一份数据既用来拟合 X 又用来证明 X，残差当然为零。可辨识性要求示教运动生成的运动群具有**平凡中心化子**；若示教全是绕同一轴的旋转、或准静态不动的接触操作，中心化子非平凡，某些规范方向**永远不可观测**。此时无论采多少条示教，都只是在同一个不可观测子空间里打转——「多教几遍」不等于「标定得更好」。

**灵感 6（第三条通道是双刃剑 → 激励是主动的、危险的和可被伪造的）**
直觉：主动激励（转一转、抬一抬、走一段标定轨迹）在实验室里很便宜，在人身旁、在接触任务中、在高节拍产线上却可能最昂贵甚至不被允许。并且它引入了新的攻击面：伪造激励（回放旧动作）、退化激励（只在单轴转）、示教投毒（用错误坐标系示范）、跨本体冒充（教师手与机器人夹爪的对应被恶意错配）。更隐蔽的是**证书自指**：系统因为「我的示教残差很小」而给自己签发标定合格证；若错误本来就被示教吸收，这个证书会稳定地签发一个错误结论。激励不是万能药，它必须被认证、被预算、被审计，且不能由被它校准的同一份数据来背书。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GAUGE-RAS 总览）** GAUGE-RAS = (GEM, GID, CXE, DGC, TBL, GCR, GAS, RAS-WM‡)。三不变式：
(i) **规范优先判读（gauge-first triage）**：任何 epistemic 分解之前，先做规范可辨识性检查；因为 R69 的模态/权重不是规范不变的，错误的 X 会把整个模态结构一起共轭掉；
(ii) **激励安全与预算**：激励动作 g_cal ∈ 𝒜_cal 必须通过与任务动作相同的 C-RAS-WM 前缀认证，且与 R69 的交互预算共享同一硬约束（单位时间信息/激励动作 ≤ 1 次、位移 ≤ ε_g、接触力 ≤ f_max）；
(iii) **非循环证据**：标定证书不得仅由「用于拟合策略的同一份示教集」签署，必须至少有一条 held-out 激励或一个独立坐标系的修正作为外部证据。

**定义 311（规范变量与共轭作用）** 规范 X ∈ SE(3)，其李代数坐标 ξ = log(X) ∈ se(3) ≅ ℝ⁶。观测与动作在规范下共变：o = X·w ⊕ n，a = Ad_X b，其中 Ad_X 为伴随作用。手眼约束 A_i X = X B_i ⇔ **A_i = Ad_X B_i**。规范误差的作用是把整条「看—做」映射共轭一次，而非给某个动作加零均值扰动。

**定义 312（规范不确定性 U_gauge）** U_gauge = (b_g, Σ_g, N_g)：偏差 b_g ∈ ℝ⁶（非零均值，必须显式建模）、协方差 Σ_g ∈ ℝ^{6×6}、不可观测子空间 N_g = null(Λ_X) ⊆ se(3)。三者的语义不同：b_g 是「系统性偏」，Σ_g 是「已辨识方向上的残余不确定」，N_g 是「再怎么采同一类数据也测不出的方向」。只报 Σ_g 而隐去 b_g 与 N_g，等于用方差掩盖偏差。

**定义 313（三轴分解与获取算子）** U = (U_ale, U_epi, U_gauge)，分别对应获取算子 𝒪_rep（同条件重复）、𝒪_int（条件观测/询问）、𝒪_exc（改变相对位姿的激励）。三者在概率上未必独立（同一物理过程可同时产生噪声与歧义），但在**可操作性**上分离：定义算子-不可约关系 U_gauge ⊥ 𝒪_rep、U_gauge ⊥ 𝒪_int（即前两者对 gauge 的信息增益恒为 0），使每类不确定性有唯一的「该做什么」答案。这是 R70 对 R69 二分法的严格细化：R69 是 U_gauge ≡ 0 的特例。

**定义 314（示教即规范测量）** 示教集 D = {(B_i, A_i*)}，B_i 为观察坐标系中的示范运动，A_i* 为期望在机器人/任务坐标系中复现的运动，满足 A_i* = Ad_{X_T} B_i，其中复合规范 X_T = X_emb ∘ X_he（本体对应 × 手眼）。策略拟合与规范估计共享这组等式，故「示教」在语义上同时是策略数据与规范测量；定义 D_fit 与 D_exc 的不交划分，后者不得参与策略拟合。

**定义 315（可辨识性与中心化子）** 令 G = ⟨B_i⟩ 为示教运动生成的李子群，C(G) = {C ∈ SE(3) : C B = B C, ∀B ∈ G} 为其中心化子。手眼方程的解集是 **X·C(G)**；因此 X 可辨识 ⇔ C(G) = {e}。等价地，信息矩阵 Λ_X = Σ_i J_iᵀ Σ_i^{-1} J_i ∈ ℝ^{6×6} 的秩为 6 − dim C(G)。示教若只含绕同一轴的旋转（或纯平移共线），C(G) 非平凡，对应方向上的规范**不可观测**。

**定义 316（激励动作与规范 VoI）** 𝒜_cal 为有界 twist 序列组成的激励动作空间。候选 g 的信息增益 VoI_cal(g) = H(X | prior) − E_{y~p(·|g)}[H(X | prior, y)]，在 Laplace/高斯近似下等价于 D-最优准则 g* = argmax_g log det(Λ_X(prior) + Λ_X(g))。选择 g* = argmax_g [VoI_cal(g) − c_cal(g)]，s.t. risk(g) ≤ ε_cal 且预算未超；若 max[VoI_cal − c_cal] ≤ 0，则不激励，规范保持未辨识并走保守退避。

**定义 317（规范等变策略 GEM）** 策略满足等变性 π_θ(Ad_X s) = Ad_X π_θ(s)（表示层面记为 ρ）；等变残差 ε_eq = E_s‖π_θ(Ad_X s) − Ad_X π_θ(s)‖ 作为训练正则与部署监控。关键推论：等变策略把规范误差保留为**可后置修正的显式量**，而不是把它烘焙进权重；因此规范错误不再伪装成「策略风格」，而是一个可以对账的坐标差。

**定义 318（示教回授与李代数滤波 TBL）** 回授/纠正给出规范残差 r_tb = log(X̂^{-1} A_tb X̂ B_tb^{-1}) ∈ se(3)（即 AX=XB 的违背量）。用李代数卡尔曼/鲁棒滤波融合：b_g ← b_g + K r_tb，Σ_g ← (I−K)Σ_g，并对 r_tb 做门控（Mahalanobis 阈值）以拒绝投毒纠正。来自**独立坐标系**的回授（人从外部纠正、另一台相机、接触约束）才计入非循环证据。

**定义 319（示教-规范联合估计 DGC）** 联合估计 (X, π)：交替进行「给定 X̂ 拟合 π」与「给定 π 在 D_exc 上重估 X̂」。**仅当 D_exc 使 C(G) 平凡时联合解可辨识**；若 D_fit = D_exc（同一份数据既教又标），则 (X, π) 只确定到 X·C(G) 与 π∘Ad_{C^{-1}}，估计器会收敛到一个自洽但可能错误的不动点。

**定义 320（规范共谋残差 GCR）** 三通道证据元组 (r_res, Δa, r_gauge, κ)，其中 κ = λ_min(Λ_X)/λ_max(Λ_X) 为规范条件数。判定「共谋」：当 r_res < τ_res 且 Δa < τ_FMA 但 **κ < κ_min 或 held-out 外推误差大** 时，不得签发标定合格；这对应「残差与似然都被同一错误 X 吸收」的可疑自洽态。GCR 的职责不是证明错，而是拒绝在不可伪证的证据上盖章。

**定义 321（规范感知风险缩放 GAS）** 任务对规范的敏感度（杠杆）L_X = ∂e/∂ξ ∈ ℝ^{m×6}。规范风险 risk_gauge = ‖L_X b_g‖ + ‖L_X Σ_g^{1/2}‖_F，并投影到「会改变接触/奇异/碰撞裕度」的方向上（方向性：只有这些分量才真正危险）。风险缩放 λ = max(risk_scale, λ_floor(U_ale + 未消解 U_epi + c_g·risk_gauge))，c_g 由任务类型给出，保证安全侧不弱于 R69。

**定义 322（规范优先判读流程）** 顺序固定为：(1) 由 D_exc 估 κ、N_g、b_g、Σ_g；(2) 若 risk_gauge > ε_g 且 N_g ≠ {0} 且激励可行 → 执行经认证的 g_cal 并重估；(3) 激励不可行 → 冻结规范声明、降低权限、走保守；(4) 规范可信后才运行 R69 的 epistemic 分解与交互；(5) 残余一律汇入 R68 兜底。理由：epistemic 分解在错误规范下会被整体共轭，先问「哪个模态」可能问错问题。

**定义 323（证书 J_GAUGE）** J_GAUGE = (J_FLUID, b_g, Σ_g, rank(Λ_X), N_g, κ, excitation_log_hash, D_fit/D_exc 划分哈希, gauge_ver)。Valid ⇔ Valid(J_FLUID) ∧ Λ_X 在任务敏感子空间上满秩 ∧ 非循环证据满足 ∧ 激励未越安全/预算界。

**定义 324（参与式规范审计 VQAuditor-G）** 审计四件事：是否用同一份示教既拟合又认证（循环度）；激励是否为真实新运动而非回放；纠正是否来自独立坐标系的源；证书是否在不可观测子空间上给出了过度声明。结论回灌 AuditBuf，成为下一轮激励预算与规范先验。

**定义 325（对抗与故障模型 AIC-GAUGE）** ℰ_GAUGE = ℰ_FLUID × ℰ_demo_poison × ℰ_gauge_deception × ℰ_excitation_hijack。含：错误坐标系的示教投毒、跨本体冒充（人手/夹爪对应被错配）、激励回放/退化（伪称已激励但只在单轴微动）、示教与观测共谋（两者同时偏移使残差归零）。

**定义 326（与 R69 的边界与退化）** 若任务对规范不敏感（L_X 在规范方向上为零，如纯力控/纯接触）或规范已满秩辨识且 b_g=0，则 GAUGE 逐指令退化为 FLUID，再在「永不交互」边界退化为 R68。若规范敏感但不可观测且激励被禁止，则进入**规范冻结**：保留 R69 的语义但不签发任何「已标定」声明，权限与速度按 risk_gauge 收紧。退化链 GAUGE ⊃ FLUID ⊃ CALM 必须逐指令一致。

## 2. 关键算法骨架

```python
# IP-264 GEM：SE(3) 等变策略（复用 R69 FMP trunk，仅把条件编码与动作头改为 ρ-等变）
class GaugeEquivariantPolicy:
    def __init__(self, trunk, action_head, rho):
        self.trunk, self.head, self.rho = trunk, action_head, rho
    def act(self, s):
        return self.head(self.trunk(s))
    def equivariance_residual(self, s, X):
        return norm(self.act(adj(X, s)) - adj(X, self.act(s)))

# IP-265 GID：规范可辨识性诊断（中心化子 + 信息矩阵秩）
def gauge_identifiability(demos):
    Bs  = [d.B for d in demos]
    C   = centralizer(generate_group(Bs))        # 与所有 B_i 可交换的子群
    N_g = null_lie_algebra(C)                    # 不可观测方向
    Lam = information_matrix(Bs)                 # 6x6 Fisher 信息
    return N_g, rank(Lam), cond(Lam)             # κ 小 => 规范不可信

# IP-266 CXE：D-最优激励规划（与 R69 交互预算共享）
def plan_excitation(Lam, leverage, budget):
    best = None
    for g in safe_excitation_library():          # 有界 twist 序列，≤8 个候选
        if not budget.allow(g) or not c_ras_wm.certify(g): continue
        score = logdet(Lam + information_matrix(g)) - cal_cost(g) - leverage_penalty(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 无利可图 -> 规范冻结

# IP-267/268 DGC + TBL：分开拟合，避免「教—标」循环
def joint_fit(demos_fit, demos_exc):
    X, pi = handeye(demos_fit), fit_policy(demos_fit, X)
    for _ in range(iters):
        pi = fit_policy(demos_fit, X)
        X  = fit_gauge(demos_exc, pi)            # held-out 才允许打破混淆
    return X, pi

def teach_back_update(b_g, S_g, r_tb):
    if mahalanobis(r_tb, S_g) > TAU_TB: return b_g, S_g   # 拒绝投毒纠正
    K = S_g @ inv(S_g + R_tb)

# IP-269 GCR：三通道共谋检测（低残差 + 低似然差 + 低 κ = 自洽但不可证）
def gauge_conspiracy(r_res, da, kappa, heldout_err):
    return (r_res < TAU_RES and da < TAU_FMA) and (kappa < KAPPA_MIN or heldout_err > TAU_EXT)

# IP-274 主闭环：规范优先，随后才是 R69 的 epistemic 交互
```

## 3. 推导

**引理 19（规范-策略混淆定理）** 设示教数据满足 A_i = Ad_X B_i。对任意 C ∈ C(G)，令 X′ = X C、π′ = π ∘ Ad_{C^{-1}}，则 (X′, π′) 产生与 (X, π) 完全相同的示教配对，且在示教流形上的闭环轨迹相同。证明：Ad_{XC} B_i = Ad_X Ad_C B_i = Ad_X B_i（C 中心化所有 B_i），故数据不变；策略经共轭后输出同一动作。**系**：仅凭示教，规范与策略只能联合辨识到中心化子商空间；「模仿得越完美」越可能把错误规范一并学会（gauge conspiracy）。

**引理 20（FMA 的规范盲区）** 若 π 规范等变，则动作似然差 Δa 对任意 X → X C（C ∈ SE(3)）不变，即 ∂Δa/∂X ≡ 0：观测与动作同步共轭，密度在共轭下同变。若 π 不等变但以同一 X̂ 拟合示教，则最优拟合会把 X̂ 的偏差吸收进权重，使 Δa 同样趋近于零。两种情形下 **R69 的 FMA 对规范误差的敏感度都为零**。故规范必须有一条独立通道（Λ_X 的秩/κ 与 held-out 外推），不能被 FMA 替代。

**引理 21（激励可辨识性与 D-最优）** 若激励运动群 G_exc 的中心化子平凡（经典充分条件：含至少两个不平行旋转轴，且平移不退化），则 Λ_X 满秩，Σ_g ≻ 0 且有限；D-最优激励使 log det Λ_X 最大，从而使规范误差椭球体积最小。证明要点：中心化子非平凡 ⇔ Λ_X 存在零特征方向（该方向的无穷小运动不改变任何 B_i，因而不产生信息）；两个不平行转轴排除绕单轴的旋转/平移中心化子，秩补满 6。

**引理 22（示教投毒的规范杠杆）** 若示教规范被污染 δ ∈ se(3)，且策略忠实拟合，则闭环任务误差满足 ‖e‖ ≤ ‖L_X‖·‖δ‖ + O(‖δ‖²)，其中 L_X 为任务杠杆。来自独立坐标系的回授在 Mahalanobis 门控下把 ‖δ‖ 缩减为 ‖(I−K)δ‖；若纠正源与污染源共享同一规范（ρ→1），则无缩减——这正是「非循环证据」不可省的原因。

**定理 18（三轴操作完备性）** 对任一系统误差，按其可被降低的获取算子分类，恰有一类算子有效：(a) 同条件重复使 aleatoric 协方差以 1/N 下降，但不改变 Λ_X 的秩，故对 b_g/Σ_g 无信息；(b) 任何不改变相对位姿、不引入独立坐标系的交互，对 X 的 Fisher 信息为零，故对规范无效；(c) 只有提高 rank(Λ_X) 的激励能降低规范不确定。反过来，激励无法消除传感器噪声，询问无法消除规范偏差。**故 aleatoric / epistemic / gauge 三条通道在获取算子上不可互相替代**——这解释了为何 R68 与 R69 会在规范错误前同时失灵，也给出了新增第三通道的必要性。

**定理 19（GAUGE 对 R69 的严格包含）** 在引理 19–21 的假设下，若任务规范不敏感（L_X 在规范方向为零）或规范已满秩辨识且 b_g=0，则 GAUGE 的每一步与 FLUID 逐指令相同；而在规范敏感且未辨识时，GAUGE 的 λ_floor 不低于 R69，且拒绝签发「已标定」声明。故期望风险 ≤ R69，安全侧不做让步；R69 是 GAUGE 在 U_gauge ≡ 0 边界上的退化。

**定理 20（自证不可能性 / 非循环证据的必要性）** 若证书只使用 D_fit（既拟合又验证），则存在一对 (π′, X′) 使全部残差 r_res、Δa、示范拟合误差都任意小，但在 D_exc 上外推误差任意大。证明：由引理 19，沿中心化子方向移动 (X, π) 不改变 D_fit 上的任何可观测统计量，却改变流形外行为。**系**：任何仅由被校准数据背书的标定证书都是不可伪证的；必须引入 held-out 激励或独立坐标系修正，否则「标定合格」只是自指的修辞。

## 6. 本轮最大风险

**一句话**：GAUGE-RAS 的命门是**可辨识性本身**——若示教/任务恰好落在标定的不可观测子空间（单轴旋转、准静态、或接触让规范不敏感），系统就只能用同一份示教去自证同一个错误的 X，证书是自指的、错误是不可伪证的；而此时唯一能救它的主动激励，又恰恰可能是人身旁或接触场景中最不能做的那一次动作。

**次级风险与缓解**：
1. **激励本身不安全/扰民** → 定义 310-ii 认证 + 定义 316 预算 + E310，激励只在任务间隙、安全包络内执行；

3. **等变假设不成立**（真实机器人非理想、夹持工件破坏对称）→ 监控 ε_eq，越界即降级为非等变并收紧 c_g；
4. **规范漂移**（相机碰撞、温漂）→ 持续 κ/残差监控 + 定期 held-out 微激励 + E313；
5. **证书自指/循环论证** → 强制 D_fit/D_exc 分离 + 定理 20 + VQAuditor-G 审计 + E315；

**定义 313（三轴与获取算子）** `U=(U_ale, U_epi, U_gauge)` 对应 `𝒪_rep, 𝒪_int, 𝒪_exc`；`U_gauge ⊥ 𝒪_rep, U_gauge ⊥ 𝒪_int`（前两者对 gauge 信息增益恒 0）。R69 是 `U_gauge ≡ 0` 的特例。

**定义 314–315（示教即规范测量；可辨识性）** `D={(B_i,A_i*)}`，`A_i*=Ad_{X_T}B_i`，`X_T = X_emb ∘ X_he`。解集 `X·C(G)`；可辨识 ⇔ `C(G)={e}` ⇔ `rank Λ_X = 6 − dim C(G)`。单轴旋转/共线平移 ⇒ 非平凡中心化子 ⇒ 规范方向不可观测。

**定义 316（激励与 VoI_cal）** `g* = argmax_g [VoI_cal(g) − c_cal(g)]`，s.t. `risk(g) ≤ ε_cal` 与预算；高斯近似即 D-最优 `max log det(Λ_X + Λ_X(g))`；无利可图则不激励、规范冻结。

**定义 317（等变策略 GEM）** `π_θ(Ad_X s) = Ad_X π_θ(s)`；等变残差 `ε_eq` 作训练正则与部署监控。规范误差因而是**可后置修正的坐标差**，不再伪装成策略风格。

**定义 318（示教回授 TBL）** `r_tb = log(X̂⁻¹ A X̂ B⁻¹)`，李代数滤波更新 `(b_g, Σ_g)`；Mahalanobis 门控拒绝投毒；只有**独立坐标系**的回授计入非循环证据。

**定义 319–320（联合估计与共谋残差）** DGC 交替拟合 (X, π)，仅当 `D_exc` 使 `C(G)` 平凡时可辨识；`D_fit=D_exc` 会收敛到自洽但可能错误的不动点。GCR：`r_res<τ ∧ Δa<τ ∧ (κ<κ_min ∨ heldout_err>τ)` ⇒ 拒绝签发标定合格。

**定义 321–322（方向性风险与规范优先）** `risk_gauge = ‖L_X b_g‖ + ‖L_X Σ_g^{1/2}‖_F`，只投影到碰撞/接触/奇异敏感方向；`λ = max(risk_scale, λ_floor(U_ale + 未消解 U_epi + c_g·risk_gauge))`。流程固定为：先规范、再 epistemic、最后 R68 兜底。

**定义 323–326（证书/审计/对抗/退化）** `J_GAUGE` 并入规范量并要求非循环证据；VQAuditor-G 审循环度与激励真实性；`ℰ_GAUGE = ℰ_FLUID × ℰ_demo_poison × ℰ_gauge_deception × ℰ_excitation_hijack`；退化链 `GAUGE ⊃ FLUID ⊃ CALM` 逐指令一致，规范敏感但不可观测且禁激励 ⇒ 规范冻结、降低权限。

## 3. 关键算法伪代码

```python
# IP-264 GEM：SE(3) 等变策略（复用 R69 trunk）
class GaugeEquivariantPolicy:
    def act(self, s): return self.head(self.trunk(s))
    def equivariance_residual(self, s, X):
        return norm(self.act(adj(X, s)) - adj(X, self.act(s)))

# IP-265 GID：中心化子 + 信息矩阵秩
def gauge_identifiability(demos):
    C   = centralizer(generate_group([d.B for d in demos]))
    N_g = null_lie_algebra(C)
    Lam = information_matrix([d.B for d in demos])
    return N_g, rank(Lam), cond(Lam)          # κ 小 => 规范不可信

# IP-266 CXE：D-最优激励（与 R69 交互共享预算）
def plan_excitation(Lam, leverage, budget):
    best = None
    for g in safe_excitation_library():
        if not budget.allow(g) or not c_ras_wm.certify(g): continue
        score = logdet(Lam + information_matrix(g)) - cal_cost(g) - leverage_penalty(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None    # 无利可图 -> 规范冻结

# IP-267/268 DGC + TBL：分开拟合，避免「教—标」循环
def joint_fit(demos_fit, demos_exc):
    X, pi = handeye(demos_fit), fit_policy(demos_fit, X)
    for _ in range(iters):
        pi = fit_policy(demos_fit, X)
        X  = fit_gauge(demos_exc, pi)           # held-out 才能打破混淆
    return X, pi

def teach_back_update(b_g, S_g, r_tb):
    if mahalanobis(r_tb, S_g) > TAU_TB: return b_g, S_g
    K = S_g @ inv(S_g + R_tb)
    return b_g + K @ r_tb, (eye(6) - K) @ S_g

# IP-269 GCR：低残差 + 低似然差 + 低 κ = 自洽但不可证
def gauge_conspiracy(r_res, da, kappa, heldout_err):
    return (r_res < TAU_RES and da < TAU_FMA) and (kappa < KAPPA_MIN or heldout_err > TAU_EXT)

# IP-274 主闭环：规范优先，随后才是 R69 epistemic 交互
def GAUGE_RAS_round(M, obs, demos):
    N_g, r, kappa = M.gid.gauge_identifiability(demos)
    risk_g = M.gas.gauge_risk(N_g, M.bias, M.cov, task_leverage=obs.L)
    if risk_g > EPS_G:                                # 1) 先确认参照系
        if kappa < KAPPA_MIN and N_g and M.budget.allow_exc():
            g = M.cxe.plan_excitation(M.gid.Lam, obs.L, M.budget)
            if g is not None:
                M.cxe.execute_certified(g)            # 过 C-RAS-WM
                M.bias, M.cov = M.tbl.reestimate(g)
        else:
            return M.degrade_gauge_freeze(obs, risk_g) # 不签发标定声明
    o_fixed = M.gem.apply_gauge_correction(obs, M.bias, M.cov)   # 2) 再谈模态
    K = 1 if M.fmp.mode_head(o_fixed) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o_fixed, K), o_fixed)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs.o, o_fixed)
    consp = M.gcr.gauge_conspiracy(M.last_r_res, a_hat, kappa, M.last_heldout_err)
    g_int = (M.mint.choose_interaction(modes, o_fixed, M.budget)
             if (U_epi > TAU_EPI and not consp) else None)
    if g_int is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g_int))
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (U_epi if g_int is None else 0.0),
                        c_g=1.0, risk_gauge=risk_g))
    if consp: lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_g.submit_async(g_int, g_cal, M.bias, kappa, consp)
    return k, lam, mode, (U_ale, U_epi, risk_g)
```

## 4. 推导

**引理 19（规范-策略混淆）** 对任意 `C ∈ C(G)`，取 `X′=XC`、`π′=π∘Ad_{C^{-1}}`，则 `Ad_{X′}B_i = Ad_X Ad_C B_i = Ad_X B_i`，示教配对与流形上闭环轨迹完全不变。故仅凭示教，(X, π) 只能辨识到中心化子商空间；模仿越完美，越可能把错误规范一并学会。

**引理 20（FMA 的规范盲区）** 若 π 规范等变，观测与动作同步共轭，动作似然差 `Δa` 对 `X→XC` 不变，`∂Δa/∂X≡0`；若 π 不等变但以同一 `X̂` 拟合示教，偏差被吸收进权重，`Δa` 同样趋零。两种情形下 R69 的 FMA 对规范误差敏感度皆为零，必须另设通道。

**引理 21（激励可辨识性）** 若激励群中心化子平凡（经典充分条件：≥2 个不平行转轴且平移不退化），则 `Λ_X` 满秩、`Σ_g≻0` 有限；D-最优激励使 `log det Λ_X` 最大、规范误差椭球体积最小。

**引理 22（示教投毒杠杆）** 污染 `δ∈se(3)` 且策略忠实拟合时，闭环误差 `‖e‖ ≤ ‖L_X‖‖δ‖ + O(‖δ‖²)`；独立坐标系回授在门控下把 `δ` 缩减为 `(I−K)δ`，若纠正源与污染源共享规范（ρ→1）则无缩减。

**定理 18（三轴操作完备性）** 同条件重复使 aleatoric 以 1/N 下降但不改变 `rank Λ_X`，对 gauge 无信息；不改变相对位姿/不引入独立坐标系的交互对 X 的 Fisher 信息为零；只有提高 `rank Λ_X` 的激励能降规范不确定。反向亦然。故三通道在获取算子上不可互相替代——这解释了 R68/R69 在规范错误前同时失灵。

**定理 19（严格包含 R69）** 规范不敏感（`L_X` 在规范方向为零）或规范已满秩辨识且 `b_g=0` 时，GAUGE 与 FLUID 逐指令相同；规范敏感且未辨识时 `λ_floor` 不低于 R69 且拒绝签发标定声明。故 `GAUGE ⊃ FLUID ⊃ CALM`，安全不让步，R69 是 `U_gauge≡0` 边界。

**定理 20（自证不可能性）** 若证书只用 `D_fit`，则存在 `(π′,X′)` 使 `r_res`、`Δa`、示范拟合误差任意小，但 `D_exc` 上外推误差任意大（沿中心化子移动不改变 `D_fit` 上任何可观测统计量）。故仅由被校准数据背书的证书不可伪证；必须引入 held-out 激励或独立坐标系修正。

## 7. 本轮最大风险

**一句话**：GAUGE-RAS 的命门是**可辨识性本身**——若示教/任务恰好落在标定的不可观测子空间（单轴旋转、准静态、或接触让规范不敏感），系统就只能用同一份示教去自证同一个错误的 X，证书是自指的、错误是不可伪证的；而此时唯一能救它的主动激励，又恰恰可能是人身旁或接触场景中最不能做的那一次动作。

**次级风险与缓解**：激励越界/扰民（C-RAS-WM 认证 + 共享预算 + E310）；示教投毒与跨本体冒充（独立源回授 + Mahalanobis 门控 + ℰ_GAUGE）；等变假设不成立（监控 ε_eq，越界降级并收紧 c_g）；规范漂移（持续 κ/残差监控 + 间歇微激励 + E313）；证书自指（强制 D_fit/D_exc 分离 + 定理 20 + VQAuditor-G）；实时预算（6×6 小矩阵 + 激励离线/间隙执行）。
