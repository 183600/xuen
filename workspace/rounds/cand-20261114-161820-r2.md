# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环第 3 轮；本轮灵感：「关节空间控制」×「步态规划」）

> R69 的成就是把「不确定性」一分为二：aleatoric 收紧、epistemic 去问。但它整轮的**测量、生成、决策**都发生在同一个抽象动作空间里——流匹配采样 task/semantic 动作块，聚类出模态，VoI 在那里算，λ 也在那里乘。两个隐含假设从未被质疑：
> 1. **动作模态是连续的、可在同一空间里线性插值的**；
> 2. **风险在「生成动作的那个空间」里实现**。
>
> 本轮两个灵感正好各击穿一个假设：
> - **步态规划**表明真实具身动作里有大量**离散接触/拓扑**选择（先迈哪只脚、何时换支撑、落点在哪）——它是混合自动机，不是连续流形。rectified flow 对两个轨迹做线性插值，一旦跨过两个接触层（homotopy class），**插值路径会穿过不可行状态**：两条可行步态的「平均」是一条会摔的步态。
> - **关节空间控制**表明同一个 task 层指令对应一整条**关节实现纤维**（冗余/零空间），不同实现的关节限位、力矩、奇异、摩擦锥裕度天差地别——**风险住在关节与接触里，不在任务里**；同时零空间自运动是一个**零社交成本**的探针。
>
> 核心命题：**R69 的连续多模态流只覆盖了不确定性的「连续层」；它下面还有两个物理层——离散接触层与连续关节层。R70 把不确定性升级为三分（U_ale、U_epi^cont、U_epi^disc），把策略升级为「分层流（离散接触头 + 层内连续流）」，把保守退避升级为「层内收缩 λ、离散层安全吸引子 DSA」，并把物理可行性作为第三条不可校准、不可幻觉的正交通道，赋予其一票否决权。** 命名 **STRIDE-RAS**（Stratified Topological Realizability-aware Interactive Disambiguation & Embodiment）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量准吗」，R69 问「该向谁求证」，R70 问「**这个答案，我的身体做得到、且不会摔吗**」——身体是最后一个不会被谎言和模型幻觉直接收买的裁判。

## 0. 直觉与动机

**灵感 1（关节空间控制 → 风险住在关节里，不在任务里）**
直觉：R69 在任务/语义空间采样并聚类模态，然后按模态风险做 λ 缩放。但同一句「把杯子放到桌上」对应无穷多关节实现（冗余）：肘高一点还是低一点、腰转不转、腕补不补——它们在任务空间几乎无差别，在关节空间里却可能是「远离限位、力矩裕度 40%」与「贴着奇异、力矩裕度 3%」的差别。反过来，两个看似不同的任务模态，下投影到关节后可能几乎重合，根本不值得为它们去问人。所以**在任务层测到的歧义，不等于执行层的风险**。
严谨版：风险是定义在关节/接触实现上的泛函；任务命令 a 的实现纤维 Π^{-1}(a) 上裕度非单值（引理 20）。R69 的 U 必须经该纤维**传输**（取选定实现的裕度或最坏实现），否则既可能低估（危险）也可能高估（无谓交互）。冗余同时给了我们一个礼物：零空间自运动 JΔq=0 不改任务位姿，却改变接触负载与内部状态——这是一个**零社交成本的本体探针**（引理 22）。

**灵感 2（步态规划 → 有一类歧义是流模型根本表示不了的）**
直觉：步态不是一段连续轨迹，而是一个**混合自动机**：`{双支撑} → {左脚摆动} → {单支撑} → {右脚摆动} → …`，每一步还带落点与时序。R69 用连续轨迹聚类得模态，隐含假设「模态之间可以连续过渡」。可「先迈左脚还是先迈右脚」不是两个可插值的连续模态，而是两个**拓扑不同的接触层**。对它们做 rectified 线性插值，脚会同时出现在两个落点上——非穿透直接崩掉。
严谨版：接触约束集 Ξ(c) 随离散接触模式 c 变化，不同 c 的可行集在状态空间中不相交；跨层线性插值一般落在两者之外（引理 19）。故 R70 用**分层流**：离散头 q_φ(c|o) 采样接触层，层内再用条件连续流 v_θ(x_s,s|c,o) 积分；U 增加第三分量 U_epi^disc；并有**同伦禁插值门 HNG**（定义 318）硬性禁止跨层平均。

**灵感 3（离散歧义不能塞进 λ → 单调收紧在离散层是错的）**
直觉：R68/R69 的铁律「任何不确定 → 收紧 λ」在连续层是成立的：慢一点通常更稳。但到接触层就**反了**：一条放慢到 0.5 倍的摆动腿不是更稳，而是更不稳（单支撑时间被拉长、动量管理失效）；停在一半的跨步姿态是纯不可行。**离散层不存在「安全的中点」。**
严谨版：λ 是对连续动作的标量收缩；跨层收缩无定义（引理 19 系）。离散层的正确保守退避不是「更慢的意图动作」，而是**换一个动作**：转入一个静态/动态稳定、支撑最大、CoM 居中的**安全吸引子 DSA**（双足着地、最宽支撑、关节远离限位）；若在时限内不可达，则力矩安全停。这把 R68/R69 精确地**收编为「接触层固定」时的特例**——层内仍用 λ_floor，离散层用 DSA。

**灵感 4（身体是最后裁判 → 第三条不可校准、不可幻觉的正交通道）**
直觉：R68 信传感器残差 r_res，但它能被标定层吸收；R69 信动作似然 Δa，但它能被流模型的幻觉伪造。两者都是**模型/测量**通道，都可能撒谎。但关节力矩、接触力、摩擦锥、关节限位是**在执行器处实测**且由硬约束定义的：一个「语义合理、似然很高」的模态，若需要三倍力矩或让脚滑出摩擦锥，身体会直接否决它。这正是 R69 最大风险（「问错比不问更危险」）的正面解药——即使流模型幻觉出模态、即使人给了误导答案，**物理可行性能一票否决**。
严谨版：e_phys = τ_meas − ID(ξ_j,c) 不属于 R68 的标定参数、也不由 R69 的生成样本决定（引理 21）；它在 A99（执行器/力传感器故障有界）下误放行率 ≤ ε_phys。故三通道 (r_res, Δa, e_phys) 共模失效更低；物理给**否决权**，其余只投票（定义 325）。

**灵感 5（冗余是免费探针，也是新的欺骗面）**
直觉：既然任务到关节是多对一，攻击者就能把「危险关节配置」藏在一个「看起来安全的任务命令」后面；而一次自运动探针虽不产生任务位移，却也可能把系统推离稳定域。更微妙的是：探针改变了接触，等于**用身体去问地面**——如果地面/接触模型被测错，探针会把错误写进信念。
严谨版：RAP（定义 319）在实现纤维内取最大裕度并限制关节跳变，堵住「安全任务、危险实现」这一欺骗面；PRB（定义 316）必须过 JRC 且满足任务位移 ≤ ε_null；ℰ_embody（定义 323）显式纳入接触/视觉协同欺骗与力传感器伪造。**物理是裁判，但裁判也可能被收买——所以裁判要带证书，且不能单独定案。**

## 1. 形式化定义（增量：定义 310–327）

**定义 310（STRIDE-RAS 总览与四不变式）** STRIDE-RAS = (SFM, HUD, JRC, DSA, PRB, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **分层完整性（stratum integrity）**：任何采样/执行都不得跨接触层做线性插值（HNG，定义 318）；每个被分发的指令必须属于一个被承认的接触层；
(iii) **可实现性硬门**：任何任务命令必须先在关节空间通过 JRC（定义 314），不可行者**拒绝**，而不是降速；
(iv) **证据纪律与预算继承**（R69 定义 293-ii/iii），且物理否决（定义 325）不得被任何「已验证」的语义回答覆盖。

**定义 311（分层/混合动作与 stratum）** 接触模式 c ∈ 𝒞 为离散集合（哪些足/手在接触、摆动相 ID）。关节轨迹 ξ_j ∈ Ξ(c) ⊂ ℝ^{n_q×H}，任务命令 a = Π_c(ξ_j)。增广混合动作 ζ = (c, ξ_j, g)，其中 g 为信息动作（定义 321）。称 Ξ(c) 的连通分支为一个 **stratum** S_c；不同 S_c 之间不可连续过渡（homotopy class）。

**定义 312（分层流匹配 SFM）** 联合建模离散 c 与连续 x_1=ξ_j：
- 离散头：q_φ(c|o_t)，可带 CTMC 式跳转 / 接触时序；
- 连续头：rectified flow v_θ(x_s,s|c,o_t)，x_s=(1−s)x_0+s x_1，条件于 c；
- 损失 L_SFM = CE(c) + E_{s,x_0,x_1,c}‖v_θ(x_s,s|c,o_t) − (x_1−x_0)‖²。
采样**先 c 后层内积分**；top-m 个 c 各自独立积分，绝不混合。

**定义 313（三分不确定性 HUD）** 对采样集合与接触后验 q(c)：
- U_ale = Σ_c q(c)·E[tr Σ_c]（层内不可约噪声）；
- U_epi^cont = E_c[H(M|o,c)]（层内连续模态歧义，R69 的 H_mode 条件于 c）；
- U_epi^disc = H(c|o)（离散接触/时序歧义）。
三者语义不同，**不做加和**，分别进入定义 326 的三条通道。

**定义 314（关节可实现性证书 JRC）** 对 (ξ_j,c)，定义归一化裕度
m(ξ_j,c) = min{ limit(q,q̇,τ), sing(J(q))−σ_0, coll(q)−d_0, fric(ξ_j,c), support(ξ_j,c) }，
其中 fric 为摩擦锥裕度 |f_t|≤μ f_n，support 为 CoP∈支撑多边形（或 capture-point 条件）。可行 ⇔ m ≥ 0。证书携带 margin、活动约束、以及沿轨迹的最小值分位。JRC 是**硬门**。

**定义 315（离散安全吸引子 DSA）** 当 U_epi^disc 未消解：不映射为 λ 收缩，而选
a_stop = argmin_{ξ_j∈Ξ(c_safe)} τ_transition(ξ_j, c_now)
s.t. m(ξ_j,c_safe) ≥ m_0 > 0，c_safe ∈ 𝒞_safe(o)（静态/动态稳定、支撑最宽、CoM 居中），且可达。若无 c_safe 或超时 ⇒ 力矩安全停（阻尼/零力模式）。DSA 是**离散刹车**：换动作，不是放慢动作。

**定义 316（零空间本体探针 PRB）** 冗余机构 J(q)Δq=0，故自运动不改变任务位姿。探针
Δq* = argmax_{Δq} VoI_PR(Δq) s.t. ‖Δq‖ ≤ ε_null，m(ξ_j+Δq,c) ≥ 0，
VoI_PR = I(hidden_contact; y | Δq) − c(Δq)，c≈0（无社交成本）。用于消解「哪只脚承重/接触点在哪/是否滑移」这类隐藏本体状态。

**定义 317（具身一致性对偶 ECD / 物理通道）** e_phys = τ_meas − ID(ξ_j,c)（或接触力残差）。定义第三通道 a_phys = ‖e_phys‖ 与可疑判据。它**不依赖**标定参数 r_cal，也**不由**生成样本决定：标定不能吸收它（执行器/接触建模项），流幻觉不能伪造它（实测）。

**定义 318（同伦禁插值门 HNG）** rectified 插值 x_s=(1−s)x_0+s x_1 被允许 ⇔ (a) x_0,x_1 属同一 stratum；(b) ∀s∈[0,1]，m(x_s,c) ≥ 0。不满足则拒绝采样、重采样，或改用层内测地线。HNG 是分层完整性的执行机构。

**定义 319（冗余感知投影 RAP）** 给定 a 与上一实现 ξ_prev：
ξ_j* = argmax_{ξ_j∈Π^{-1}(a)} m(ξ_j,c) s.t. ‖ξ_j−ξ_prev‖ ≤ Δq_max（连续性）。
在实现纤维内**免费**换取安全裕度，并阻止「安全任务、危险实现」。

**定义 320（接触计划后验 CSP）** 接触计划 c_{t:t+H} 是混合自动机路径（接触 onset/offset 序列 + 落点）。后验 q(c|o) 由 SFM 离散头给出；转移只允许物理可达的接触切换（脚不能在未抬起时瞬移落点）。

**定义 321（交互动作扩展 MINT-E）** 信息动作 g ∈ {g_gaze, g_probe, g_ask, g_self, g_step}：新增 g_self=PRB 零空间探针（零社交成本）、g_step=一次受认证的探路/换支撑步（同时是信息动作与物理动作）。VoI 含接触模式信息；成本含探针步的稳定风险（须 JRC 认证）。

**定义 322（参与式审计 VQAuditor-E）** 审计对象扩展：是否发生跨层插值、是否有指令未经 JRC 就分发、DSA 是否真达 m_0、PRB 是否越出 ε_null、是否忽略物理否决。结论回灌 AuditBuf，成为下一轮成本/阈值先验。

**定义 323（干扰集 AIC-STRIDE）** ℰ_STRIDE = ℰ_FLUID × ℰ_embody，其中 ℰ_embody = {关节限位越界, 奇异穿越, 执行器饱和, 摩擦锥违反/滑移, 力传感器伪造, 接触-视觉协同欺骗}。

**定义 324（证书 J_STRIDE）** J_STRIDE = (J_FLUID, jrc_margin_p05, stratum_id, n_cross_stratum_reject, dsa_settle_time, e_phys_p95, null_probe_dev, stride_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有分发指令 m ≥ 0 ∧ 无跨层插值 ∧ (离散未消解时 DSA 达 m_0 或被安全停)。

**定义 325（三通道仲裁）** 硬性优先级：物理否决 e_phys / JRC **高于** 标定残差 r_res **高于** 动作似然 Δa **高于** 语义先验。物理只有否决权（硬约束）、无生成权；语义证据再「已验证」也不能覆盖物理不可行。

**定义 326（三级保守退避）**
- 连续已消解且层固定：λ = λ_floor(U_ale)（R69 resolution bonus）；
- 连续未消解、层固定：λ = λ_floor(U_ale + U_epi^cont)（R69 兜底）；
- **离散未消解**：不使用 λ，执行 DSA（硬裕度 m_0）；不可达 ⇒ 力矩安全停。
边界：无接触切换 ⇒ 退化为 R69；不交互 ⇒ 退化为 R68。安全侧永不弱于二者。

**定义 327（分层自适应计算）** 默认连续头 N_step=2、离散头 top-1；仅当 q_φ 报离散歧义、或 JRC 接近边界、或 e_phys 异常时，升 top-m=2、全量 JRC、启动 PRB。保证 P99 实时预算。

```python
# IP-264 SFM：分层流匹配（离散接触头 + 层内连续流）
class StratifiedFlowPolicy:
    def __init__(self, trunk, c_head, v_net, N_step=2):
        self.trunk, self.q_c, self.v = trunk, c_head, v_net    # q_c(c|z), v(x_s,s,c,z)

    def sample_joint(self, o_t, top_m=2):
        z  = self.trunk(o_t)
        cs = self.q_c(z).topk(top_m)                          # 离散接触层 c
        out = []
        for c, pc in cs:
            x = randn(D_joint)
            for i in range(self.N_step):                      # 只在层内积分，绝不跨层
                x = x + (1.0 / self.N_step) * self.v(x, i / self.N_step, c, z)
            out.append((c, pc, self.decode_joint(x)))
        return out                                            # [(c, p_c, ξ_j)]

# IP-265 HUD：三分不确定性
def decompose3(modes, q_c):
    U_ale      = sum(p * trace(cov_within(m)) for _, p, m in modes)
    U_epi_cont = conditional_mode_entropy(modes)              # R69 H_mode | c
    U_epi_disc = entropy(q_c)                                 # 接触层离散歧义
    return U_ale, U_epi_cont, U_epi_disc

# IP-266 JRC：关节可实现性证书（硬约束 + 裕度）
def jrc(xi_j, c):
    m = {
        'limit':  clearance(xi_j.q, QMIN, QMAX, VMAX, TAUMAX),
        'sing':   min_singular_value(J(xi_j.q)) - SIG0,
        'coll':   clearance_collision(xi_j.q) - D0,
        'fric':   friction_cone_margin(xi_j, c),              # |f_t| <= μ f_n
        'support':support_margin(xi_j, c),                    # CoP ∈ 支撑多边形 / CP
    }
    return min(m.values()), argmin(m)                         # margin, 活动约束

# IP-267 DSA：离散安全吸引子（不是 λ 收缩！）
def discrete_safe_attractor(o_t, c_now, lib):
    best = None
    for a in lib:
        if not reachable(a, c_now, o_t):        continue
        if jrc(a.xi_j, a.c)[0] < M_SAFE:        continue     # 双足着地/最宽支撑/CoM 居中
        t = transition_time(a, c_now)
        if best is None or t < best[1]: best = (a, t)
    return best                                               # None ⇒ 力矩安全停

# IP-268 PRB：零空间本体探针（零社交成本）
def null_space_probe(xi_j, J_task, amb):
    N  = null_space(J_task)                                   # J·Δq = 0 ⇒ 任务位移 = 0
    dq = argmax_dq VoI_contact(amb, dq) \
         s.t. norm(dq) <= EPS_NULL and jrc(xi_j + dq, c)[0] >= 0
    return dq

# IP-269 RAP：冗余感知投影（实现纤维内选最安全）
def redundancy_aware_project(a_task, xi_prev, c):
    return argmax_{xi_j in fiber(a_task)}
           jrc(xi_j, c)[0] s.t. norm(xi_j - xi_prev) <= DQ_MAX

# IP-272 HNG：同伦禁插值门
def admit_interp(x0, x1, c):

           min(jrc(((1-s)*x0 + s*x1), c)[0] for s in grid) >= 0

def STRIDE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c_cal, U_cal, thr = M.cof.step(...)
    # 1) 分层采样（离散头廉价门控）
    modes = M.sfm.sample_joint(o, top_m=M.sfm.topm(z))

    # 2) 物理第三通道（关节力矩/接触力实测）
    e_phys = M.ecd.physics_residual(M.last_cmd, M.tau_meas, M.f_meas)
    # 3) 离散层优先：先探/先问；不可消解则 DSA（不碰 λ）
    if U_epi_d > TAU_DISC:
        g = M.mint_e.choose(modes, o, M.budget)               # 含 g_self / g_step / g_ask
        if g is not None and M.jrc.cert_info(g, o)[0] >= 0:
            U_epi_d = M.cia.update_contact_belief(M.cia.execute(g))
    # 4) 连续层：R69 的 VoI 交互
    if U_epi_d <= TAU_DISC and U_epi_c > TAU_CONT and not M.ecd.suspect(e_phys):
        g = M.mint_e.choose_continuous(modes, o, M.budget)
        if g is not None:
            U_epi_c = M.cia.update(modes, M.cia.execute(g))
    # 5) 选 stratum 与关节实现
    if U_epi_d > TAU_DISC:                                    # 离散未消解 ⇒ DSA，无 λ
        dsa = M.dsa.pick(o, M.last_c, M.dsa_lib)
        if dsa is None:            return M.safe_stop()
        c_sel, xi, lam = dsa.c, dsa.xi_j, 1.0
    else:
        lam = (lam_floor(U_ale) if U_epi_c < TAU_CONT
               else lam_floor(U_ale + U_epi_c))               # 层内 λ（R69 边界）
        c_sel = sample_stratum(modes, U_epi_c, lam)
        xi    = M.rap.project(modes[c_sel], M.last_xi, c_sel)  # 纤维内选最安全实现
    # 6) 硬门：可实现性先于一切
    margin, active = M.jrc.cert(xi, c_sel)
    if margin < 0:                                            # 不可行 ⇒ 拒绝，不降速
        xi, c_sel = M.dsa.backup(c_sel) or M.safe_stop()
        margin, active = M.jrc.cert(xi, c_sel)
    if M.ecd.suspect(e_phys) and margin < M_PHYS:             # 物理否决
        return M.safe_stop()
    # 7) 分发：层内认证前缀 + 关节空间阻抗/力矩控制
    k   = M.c_ras_wm.certified_prefix(xi.task[:H], ..., wm_preds)
    tau = M.wbc.dispatch(xi.joint[:k], c_sel) * lam
    M.vqa_e.submit_async(c_sel, margin, e_phys, U_epi_d, g)
    return k, tau, c_sel, (U_ale, U_epi_c, U_epi_d)
```

## 3. 推导

**引理 19（跨层插值不可行性 / 「两条步态的平均会摔」）** 设 ξ^{(1)}∈Ξ(c_1)、ξ^{(2)}∈Ξ(c_2)，c_1、c_2 属不同 stratum。线性插值 ξ_s=(1−s)ξ^{(1)}+sξ^{(2)}。因接触约束集合 Ξ(c) 对每个 c 非凸，且不同 c 的接触/落点拓扑互斥，一般存在正测度 s∈(0,1) 使 ξ_s∉Ξ(c_1)∪Ξ(c_2)：脚同时压向两个落点（非穿透破坏），或 CoP 落在两支撑多边形之外（支撑破坏）。系：**对跨层样本做 rectified 线性积分等价于生成不可行轨迹；标量 λ 收缩对切换动作无定义**——不存在「以 0.5 的速度同时迈两只脚」。

**引理 20（实现纤维上的风险传输）** 任务命令 a 的实现纤维 Π^{-1}(a) 上，JRC 裕度 m(ξ_j) 一般非单值。存在 ξ_j∈Π^{-1}(a) 使真实风险 > 仅基于任务层的估计 R_task(a)（低估，危险），也存在使其 < R_task(a)（高估，无谓保守/交互）。RAP 取 ξ_j*=argmax m。故 U 必须经纤维传输：U_transport(a)=m(ξ_j*)^{-1} 或最坏实现裕度。系：**任务层歧义 ≠ 执行层风险；冗余既可能稀释也可能放大安全裕度**。

**引理 21（物理通道的不可校准性与不可幻觉性）** e_phys = τ_meas − ID(ξ_j,c;model)。它依赖执行器测量与关节限位硬约束，不依赖标定参数 r_cal，也不由生成样本决定。故标定层无法将其归零（它含执行器/接触建模失配项），流模型无法凭空生成可行的 e_phys（它实测而非生成）。在 A99（执行器与力传感器故障有界，误差 ≤ ε_phys）下，物理否决的误放行率 ≤ ε_phys。系：三通道共模失效概率低于任意两通道；物理适合作否决权而非投票权。

**引理 22（零空间探针的零任务代价与正信息）** 冗余机构 J(q)Δq=0 ⇒ 任务位姿不变，任务误差变化为 0。若接触阻抗对方向敏感（∂f/∂p 满秩，A100 接触可观测），则探针观测 y 满足 I(hidden_contact; y | Δq) > 0；其社交成本 ≈0、任务位移 =0。故当歧义关于隐藏本体状态（承重脚、接触点、滑移）时，PRB 严格优于 g_ask（成本更低、无谎言投毒面）。系：MINT-E 的动作集必须含 g_self，且其 VoI 按零社交成本计算。

**定理 18（STRIDE 在固定层边界严格包含 FLUID / R68）** 当接触层固定（U_epi^disc=0）且所有命令 JRC 可行时，SFM 退化为 R69 的条件连续流；DSA 不触发、PRB 可关闭，闭环逐指令等价于 FLUID-RAS；再若 VoI≤成本，逐指令等于 R68。反之在离散层，STRIDE 拒绝一切跨层插值（引理 19）并强制 JRC（引理 20–21），其可行域 ⊆ FLUID 的可行域，安全侧严格更紧；效率侧（零空间探针、冗余选实现、层内 resolution bonus）只增不减。⇒ **R69 = 「接触固定、不利用冗余」边界**。

**定理 19（DSA 的单调安全性与无突变）** 若存在 DSA 且 m ≥ m_0 > 0，则转入后的稳定裕度 ≥ 部分消解的任意意图步态（由 DSA 定义：稳定集内、支撑最大、CoM 居中）；若不存在 DSA，则力矩安全停是允许集上的最大保守。交互/探针动作经 JRC 认证 ⇒ 物理风险 ≤ ε_int；只改变 stratum 选择与实现，不改变安全壳；失败/超时/投毒时单调退化为 DSA/安全停（层内连续性由 R69 定理 17 保证）⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：STRIDE-RAS 把最终裁判权交给了「物理可实现性」，于是整个安全叙事押在 **JRC/接触动力学模型（逆动力学、摩擦锥、接触点、支撑判据）是准的** 这一前提上——一旦接触模型或力传感器失真，物理就不再是诚实的裁判：它可能**放行一个真正危险的步态**（假阴性），也可能**否决掉所有可行动作而陷入冻结**（假阳性）；而因为我们给了物理**一票否决权**，一个建模误差会从「软降速」直接升级为「硬失败」。**身体是最后裁判，但裁判只和它的接触模型一样诚实。**

**次级风险与缓解**：
1. **动态步态下 DSA 不存在**（奔跑/跳跃时「安全停下」本身很难）→ 预计算动态安全吸引子库 + 捕获点判据 + 最坏情形安全停；运动学约束内退化为静态 DSA；
2. **接触/力传感器被伪造**（ℰ_embody）→ 多源交叉（关节电流 vs 力矩传感器 vs IMU）+ 引理 21 的有界假设 + E307；
3. **HNG 过严导致采样被大量拒绝**（尤其近接触切换）→ 层内测地线/热启动 + top-m 重采样 + 缓存；
4. **JRC 实时开销**（QP 在 P99 放大）→ hot-start、缓存、仅近边界全量（定义 327）；
5. **冗余探针把误差写进接触信念** → PRB 过 JRC、ε_null 硬限、探针证据只作「一条证据源」，仍需 R69 的 k 源一致纪律。

**定义 317（ECD）** `e_phys=τ_meas−ID(ξ_j,c)`；不依赖标定参数、不由生成样本决定 ⇒ 不可校准、不可幻觉；可疑判据 `a_phys=‖e_phys‖`。

**定义 318（HNG）** 允许插值 ⇔ 同 stratum 且 `∀s m(x_s,c)≥0`；否则拒绝/重采样/层内测地线。

**定义 319（RAP）** `ξ_j*=argmax_{Π^{-1}(a)} m` s.t. `‖ξ_j−ξ_prev‖≤Δq_max`。

**定义 320（CSP）** 接触计划 `c_{t:t+H}` 混合自动机路径；后验 q(c|o)；仅允许物理可达切换。

**定义 321–322（MINT-E / VQAuditor-E）** 信息动作 + `g_self`（PRB）/`g_step`（认证探路步）；审计跨层插值、无 JRC 分发、DSA 裕度、探针越界、物理否决被忽略。

**定义 323–324（AIC/J_STRIDE）** `ℰ_STRIDE=ℰ_FLUID×ℰ_embody`；证书增 `jrc_margin_p05, stratum_id, n_cross_reject, dsa_settle, e_phys_p95, null_probe_dev`。

**定义 325（三通道仲裁）** 物理否决(JRC/e_phys) **>** 标定残差 r_res **>** 动作似然 Δa **>** 语义先验；物理只有否决权，语义「已验证」不能覆盖物理不可行。

**定义 326（三级退避）** 层固定+连续消解 → `λ_floor(U_ale)`；层固定+连续未消解 → `λ_floor(U_ale+U_epi^cont)`；**离散未消解 → DSA**（无 λ，不可达则安全停）。边界：无接触切换 ⇒ R69；不交互 ⇒ R68。

**定义 327（分层自适应计算）** 默认 N_step=2、top-1；离散歧义/JRC 近边界/e_phys 异常才升 top-m=2、全量 JRC、启 PRB。

## 3. 关键算法伪代码

```python
# IP-264 SFM：分层流匹配（离散接触头 + 层内连续流）
class StratifiedFlowPolicy:
    def sample_joint(self, o_t, top_m=2):
        z  = self.trunk(o_t)
        cs = self.q_c(z).topk(top_m)                          # 离散接触层 c
        out = []
        for c, pc in cs:
            x = randn(D_joint)
            for i in range(self.N_step):                      # 只在层内积分，绝不跨层
                x = x + (1.0/self.N_step) * self.v(x, i/self.N_step, c, z)
            out.append((c, pc, self.decode_joint(x)))
        return out

# IP-265 HUD：三分不确定性
def decompose3(modes, q_c):
    return (sum(p*trace(cov_within(m)) for _,p,m in modes),
            conditional_mode_entropy(modes), entropy(q_c))    # U_ale, U_epi_cont, U_epi_disc

# IP-266 JRC：关节可实现性证书（硬约束 + 裕度）
def jrc(xi_j, c):
    m = {'limit': clearance(xi_j.q, QMIN, QMAX, VMAX, TAUMAX),
         'sing':  min_singular_value(J(xi_j.q)) - SIG0,
         'coll':  clearance_collision(xi_j.q) - D0,
         'fric':  friction_cone_margin(xi_j, c),
         'support': support_margin(xi_j, c)}
    return min(m.values()), argmin(m)                         # margin, 活动约束

# IP-267 DSA：离散安全吸引子（不是 λ 收缩！）
def discrete_safe_attractor(o_t, c_now, lib):
    best = None
    for a in lib:
        if not reachable(a, c_now, o_t) or jrc(a.xi_j, a.c)[0] < M_SAFE: continue
        t = transition_time(a, c_now)
        if best is None or t < best[1]: best = (a, t)
    return best                                               # None ⇒ 力矩安全停

# IP-268 PRB：零空间本体探针（零社交成本）
def null_space_probe(xi_j, J_task, amb, c):
    dq = argmax_dq VoI_contact(amb, dq) \
         s.t. norm(dq) <= EPS_NULL and jrc(xi_j + dq, c)[0] >= 0
    return dq                                                 # J·Δq=0 ⇒ 任务位移=0

# IP-269 RAP：冗余感知投影（实现纤维内选最安全）
def redundancy_aware_project(a_task, xi_prev, c):
    return argmax_{xi_j in fiber(a_task)} jrc(xi_j, c)[0] \
           with_constraint norm(xi_j - xi_prev) <= DQ_MAX

# IP-272 HNG：同伦禁插值门
def admit_interp(x0, x1, c):
    return same_stratum(x0, x1, c) and \
           min(jrc((1-s)*x0 + s*x1, c)[0] for s in grid) >= 0

# IP-277 主闭环（继承 R69 FLUID_RAS_round）
def STRIDE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c_cal, U_cal, thr = M.cof.step(...)
    modes = M.sfm.sample_joint(o, top_m=M.sfm.topm(z))
    U_ale, U_epi_c, U_epi_d = M.hud.decompose3(modes, M.sfm.q_c(z))
    e_phys = M.ecd.physics_residual(M.last_cmd, M.tau_meas, M.f_meas)
    if U_epi_d > TAU_DISC:                                    # 离散层优先
        g = M.mint_e.choose(modes, o, M.budget)               # g_self/g_step/g_ask
        if g is not None and M.jrc.cert_info(g, o)[0] >= 0:
            U_epi_d = M.cia.update_contact_belief(M.cia.execute(g))
    if U_epi_d <= TAU_DISC and U_epi_c > TAU_CONT and not M.ecd.suspect(e_phys):
        g = M.mint_e.choose_continuous(modes, o, M.budget)
        if g is not None: U_epi_c = M.cia.update(modes, M.cia.execute(g))
    if U_epi_d > TAU_DISC:                                    # 离散未消解 ⇒ DSA，无 λ
        dsa = M.dsa.pick(o, M.last_c, M.dsa_lib)
        if dsa is None: return M.safe_stop()
        c_sel, xi, lam = dsa.c, dsa.xi_j, 1.0
    else:
        lam = (lam_floor(U_ale) if U_epi_c < TAU_CONT
               else lam_floor(U_ale + U_epi_c))               # 层内 λ（R69 边界）
        c_sel = sample_stratum(modes, U_epi_c, lam)
        xi    = M.rap.project(modes[c_sel], M.last_xi, c_sel)
    margin, active = M.jrc.cert(xi, c_sel)
    if margin < 0:                                            # 不可行 ⇒ 拒绝，不降速
        xi, c_sel = M.dsa.backup(c_sel) or M.safe_stop()
        margin, active = M.jrc.cert(xi, c_sel)
    if M.ecd.suspect(e_phys) and margin < M_PHYS: return M.safe_stop()   # 物理否决
    k   = M.c_ras_wm.certified_prefix(xi.task[:H], ..., wm_preds)
    tau = M.wbc.dispatch(xi.joint[:k], c_sel) * lam           # 关节空间阻抗/力矩控制
    M.vqa_e.submit_async(c_sel, margin, e_phys, U_epi_d, g)
    return k, tau, c_sel, (U_ale, U_epi_c, U_epi_d)
```

## 4. 推导

**引理 19（跨层插值不可行性 / 「两条步态的平均会摔」）** 不同接触层 c_1、c_2 的约束集非凸且接触/落点拓扑互斥，线性插值 `ξ_s=(1−s)ξ^(1)+sξ^(2)` 一般存在正测度 s 落在两者之外（非穿透破坏 / CoP 出支撑多边形）。系：跨层 rectified 积分生成不可行轨迹；**标量 λ 收缩对切换动作无定义**。

**引理 20（实现纤维上的风险传输）** 纤维 `Π^{-1}(a)` 上 JRC 裕度非单值，存在实现使真实风险高于/低于任务层估计。RAP 取 `argmax m`。故 U 须经纤维传输（取选定或最坏实现裕度）。系：**任务层歧义 ≠ 执行层风险**。

**引理 21（物理通道不可校准/不可幻觉）** `e_phys=τ_meas−ID(ξ_j,c)` 依赖执行器测量与关节硬限，不依赖标定参数、不由生成样本决定。标定不能归零它、流模型不能伪造它；A99 下误放行率 ≤ ε_phys。系：三通道共模失效更低，物理宜作否决权。

**引理 22（零空间探针零任务代价与正信息）** `JΔq=0` ⇒ 任务误差变化为 0；若接触阻抗对方向敏感（A100 接触可观测），`I(hidden_contact;y|Δq)>0`，成本≈0 ⇒ 对隐藏本体状态，PRB 严格优于 g_ask。系：MINT-E 必须含 g_self。

**定理 18（固定层边界严格包含 FLUID/R68）** `U_epi^disc=0` 且全命令 JRC 可行时，SFM 退化为 R69 条件连续流、DSA 不触发，逐指令等价 FLUID-RAS；再若 VoI≤成本，等同于 R68。离散层则拒绝跨层插值并强制 JRC，可行域 ⊆ FLUID，安全更紧、效率只增。⇒ **R69 = 「接触固定、不利用冗余」边界**。

**定理 19（DSA 单调安全与无突变）** 存在 `m≥m_0` 的 DSA 时，转入后稳定裕度 ≥ 部分消解的任意意图步态；不存在则安全停为最大保守。交互/探针经 JRC 认证 ⇒ 风险 ≤ ε_int；只改 stratum/实现，不改安全壳；失败/超时/投毒单调退化 ⇒ 无突变。

## 7. 本轮最大风险

**一句话**：STRIDE-RAS 把最终裁判权交给「物理可实现性」，于是整个安全叙事押在 **JRC/接触动力学模型（逆动力学、摩擦锥、接触点、支撑判据）是准的** 这一前提上——一旦接触模型或力传感器失真，物理就不再诚实：它可能**放行一个真正危险的步态**，也可能**否决所有可行动作而陷入冻结**；而我们给了物理一票否决权，建模误差会从「软降速」升级为「硬失败」。**身体是最后裁判，但裁判只和它的接触模型一样诚实。**

**次级风险与缓解**：动态步态下 DSA 可能不存在（预计算动态安全吸引子库 + 捕获点判据 + 最坏情形安全停）；力/接触传感器被伪造（关节电流 vs 力矩 vs IMU 多源交叉 + 引理 21 有界假设 + E307）；HNG 过严致采样拒绝率升高（层内测地线/热启动/top-m 重采样/缓存）；JRC 实时开销（hot-start、缓存、仅近边界全量）；冗余探针把误差写进接触信念（PRB 过 JRC、ε_null 硬限、探针只作一条证据源，仍需 k 源一致纪律）。
