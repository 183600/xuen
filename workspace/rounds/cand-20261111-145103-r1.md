# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「腕部相机」×「开源硬件」）

> 第 54 轮把「技能组合」与「云边部署」建立在动作空间剖面 α_S 与联合证书 J 上，但隐含了两个强假设：**感知是外生的**（动作不改变可观测性），**硬件是单例的**（证书绑定一台机器）。腕部相机把传感器装到执行器上，使「动作决定看见什么」；开源硬件让同一设计在多台异构构建上复现，使「证书必须跨构建可迁移」。本轮的核心矛盾：H22：存在任务动作覆盖高、但腕部相机看不见的动作（自遮挡、运动模糊、反光），第 54 轮的证书在其上无效；H23：开源硬件的装配公差、相机内参/手眼外参、USB 延迟因构建而异，单构建证书直接复制到另一台机器会产生静默失效。于是提出 **可观测性-构建条件化证书**：证书不再是 J，而是 `J|_{ω≥θ_obs, b∈𝔅}`。

## 0. 直觉与动机

**灵感 1（腕部相机让感知成为动作的函数）**
直觉：外置相机像“上帝视角”，动作只改变世界；腕部相机是“第一人称”，动作同时改变世界与视野。技能 S 除了动作剖面 α_S(a)，还必须带 **可观测性剖面** `ω_{S,b}(a)`：执行 a 时腕部图像 Z 对任务相关状态 X_T 的信息量。一个动作可能“做得对但看不见”，这类动作不能进入证书域。关键转变：**可观测性不是附加指标，而是与 α、ρ 并列的第一性可行性维度**。

**灵感 2（主动感知动作：用动作换信息）**
直觉：看不清时，人会转手腕、拉远、侧视、晃一晃制造视差。把这类 **认知动作** `A_epi` 显式纳入动作空间，它们任务收益低但信息增益高。技能组合因此不只要“动作接得上”，还要“视野接得上”：在技能转移处必须存在一条 **视域状态机** 上的路径，使 ω 始终 ≥ θ_obs。组合图从 `G_S` 升级为 **`G_S × V`**（技能 × 视域模式）的乘积图，可判定性从“动作兼容”扩展为“动作-视域双兼容”。

**灵感 3（开源硬件把单例证书变成构建分布上的证书）**
直觉：开源硬件的价值不只是便宜，而是**可被独立复现**。但每台构建 b 的镜头、支架刚度、手眼外参、USB 延迟都不同，J 只在 b 上被验证过。于是需要 **构建溯源** `P_b` 与 **证书可移植算子** `T_{b→b'}`：只有当参数距离在标定包络内、且少量验证样本通过时，才能把 `J_b` 迁移为 `J_{b'}`，并把迁移残差 `ε_xfer` 显式写进证书。开源硬件的“同款”只是 BOM 同款，不是证书同款。

**灵感 4（腕部相机同时是校准仪器：手指上的 fiducial）**
直觉：腕部相机天然能看见夹爪与手指。在指尖/夹爪贴 AprilTag，就得到一个“始终在视野内的标定靶”：手眼外参、支架受力形变、镜头脏污都能被在线监测。这把 **校准从一次性出厂步骤变成持续可观测状态**，并为开源硬件的跨构建标定迁移提供低成本抓手。硬件设计应主动“为可认证而设计”：刚性安装、视野内 fiducial、全局快门、与机械臂触发同步。

**灵感 5（可复现性即证据：k-of-n 独立构建证书）**
直觉：单台机器上 100% 成功不是可复现性。开源硬件让我们可以要求 **n 台独立构建中至少 k 台通过**，并用 Clopper-Pearson 下界给出置信声明。这把“开源”从社区叙事变成 **统计证据装置**：构建分布 𝔅、独立复现次数 n、通过次数 k，共同构成可审计的复现证书 RRC。反过来，若构建方差过大导致 k-of-n 无法通过，结论应是“该证书不可移植”，而不是“再调调参”。

**灵感 6（证书亲和设计：把可认证性写进开源硬件规格）**
直觉：开源硬件的设计目标通常是最低成本/最易制造，但证书可迁移性取决于 `∂ω/∂b` 与标定可观性。于是提出 **证书亲和设计 (certificate-affine design)**：选全局快门（抑制腕部快速运动模糊）、加视野内 fiducial、用 kinematic 定位特征保证装配重复性、暴露触发同步与温度/延迟遥测。它把“能不能被证明”前移到硬件设计阶段，而不是事后补证书。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（可观测性剖面）**
设任务相关隐状态 `X_T`（物体相对夹爪位姿、接触模式、滑移指示），腕部观测 `Z`，构建参数 `b`。技能 S 在动作 a 上的可观测性剖面
```
ω_{S,b}(a) = I_b(X_T ; Z | do(a)) / H_b(X_T) ∈ [0,1]
```
其中 `I_b` 为互信息，`do(a)` 表示干预执行 a。若 `H_b(X_T)=0` 则约定 `ω=1`。动作覆盖与可观测性共同定义 **可认证域**
```
A^cert_{S,b} = { a ∈ A_S : α_{S,b}(a) ≥ θ_cov ∧ ω_{S,b}(a) ≥ θ_obs ∧ U_{cal,b}(a) ≤ δ_cal }
```
`U_{cal,b}(a)` 为标定不确定度传播到 X_T 的误差上界。`A_S \ A^cert` 中 α 高而 ω 低者称为 **感知盲区 (perceptual blind spot)**。

**定义 122（视域状态机与可观测性闭合）**
离散视域模式 `V = {v_0,...,v_m}`（如 approach / side / top / in-hand / retract），技能 S 的可视域集合 `dom_obs(S) ⊆ V`，即 `ω_{S,b}(a) ≥ θ_obs` 的模式。视域转移 `E_V ⊆ V×V` 带时延 `τ_v`。技能序列 `π = (S_1,...,S_k)` 的 **视域路径** 为 `v_0...v_k`，要求 `v_i ∈ dom_obs(S_i)` 且 `(v_{i-1},v_i)∈E_V`。定义
```
obs_gap(π) = Σ_i max(0, θ_obs − max_{v∈dom_obs(S_i), reachable} ω_{S_i,b}(a_i,v))
```
若 `obs_gap=0` 且 `Σ τ_v ≤ τ_loop`，称 π **可观测性闭合**。否则必须插入认知动作 `A_epi` 或拒绝组合。

**定义 123（主动感知动作与信息预算）**
认知动作 `e ∈ A_epi`（转腕、回撤、侧视、微动制造视差）有任务收益 `r_task(e)≈0` 与信息增益 `ΔH(e)`。规划目标在任务收益外增加信息项：
```
π* = argmax_π E[ Σ_t r_task(a_t) + λ_info · I(X_T; Z_{t+1} | a_t, b) ]
     s.t. obs_gap(π)=0 ∧ 总时延 ≤ τ_loop ∧ 每步 ω ≥ θ_obs
```
`λ_info` 是“看清”的机会成本；它把主动感知从启发式变成可调、可审计的规划项。

**定义 124（构建溯源与证书可移植性）**
构建 `b = (BOM_hash, CAD_rev, K_intr, T_wc, τ_cam, κ_mount, lens_id)`。溯源 `P_b` 为上述字段的哈希承诺。证书 `J_b` 只在 b 上 sound。定义参数距离 `d(b,b')`（内参/外参/延迟/刚度加权）。**可移植算子**
```
T_{b→b'} : J_b ↦ J_{b'} ,  仅当 d(b,b') ≤ δ_cal 且 b' 上验证集通过
```
迁移残差 `ε_xfer(b,b')` 由 b' 上少量真机样本的 conformal 分位数给出；`J_{b'}` 必须携带 `(P_b, ε_xfer, evidence)`。`d>δ_cal` 时唯一合法动作是重新标定，而不是“相信同款”。

**定义 125（校准状态与校准债）**
手眼标定 + 指尖 fiducial 监测给出 `T_wc(t)`、重投影残差 `r_reproj(t)`、支架形变代理 `κ_mount(t)`。定义 **校准债**
```
D_cal(t) = ∫_0^t u_cal(τ) · 1[ r_reproj(τ) > δ_r ∨ κ_mount(τ) > δ_κ ] dτ
```
`u_cal` 为未检测漂移的暴露权重。当 `D_cal > D_cal^max` 或即时 `U_cal > δ_cal` 时，所有依赖视觉的证书自动降级为 `conditional`，禁止部署。校准不是一次性动作，而是持续、可计息的负债。

**定义 126（k-of-n 复现证书）**
构建分布 𝔅（由声明 BOM/CAD 公差定义），独立构建 `b_1..b_n ~ 𝔅`。同一证书在 n 台上通过 k 台，定义复现证书
```
RRC = (P_b, J, n, k, p_L, α, build_manifest)
p_L = Beta^{-1}(α; k, n−k+1)          # Clopper-Pearson 下界
```
若 `p_L ≥ p_min` 且构建清单覆盖声明的公差范围，则称证书在 `1−α` 置信下可复现。`RRC` 的对象是 **构建分布**，不是单台机器；这是开源硬件语境下“证据”的正确单位。

## 2. 关键算法 伪代码

### IP-121 OBS（Observability Profiling）

```python
def observability_profile(skill, A, build, estimator, theta_obs, theta_cov, delta_cal):
    omega, cert = {}, {}
    for a in A:
        if skill.action_profile(a, build) < theta_cov:
            continue
        zs, xs = estimator.rollout(skill, a, build)        # 采样状态-观测对
        omega[a] = estimator.mutual_info(xs, zs) / estimator.entropy(xs)
        U = estimator.calibration_uncertainty(a, build)
        cert[a] = (omega[a] >= theta_obs and U <= delta_cal)
    return omega, cert
```

### IP-122 VMC（View-mode Closure）

```python
def view_closure(plan, view_automaton, omega, theta_obs, tau_loop):
    path, latency = [], 0
    v = view_automaton.start
    for S, a in plan:
        v_next = argmax_{v in dom_obs(S)} omega[S, a, v]
        if omega[S, a, v_next] < theta_obs:
            gap = theta_obs - omega[S, a, v_next]
            return ('reject', 'obs_gap', S, gap)          # 感知盲区
        edge = view_automaton.transition(v, v_next)
        if edge is None:
            return ('reject', 'view_unreachable', S)
        latency += edge.tau
        path.append((S, a, v_next))
        v = v_next
    if latency > tau_loop:
        return ('reject', 'view_latency', latency)         # 破坏云边契约
    return ('ok', path, latency)
```

### IP-123 APC（Active Perception Composition）

```python
def active_perception_plan(G_S, V, task, belief, lam_info, theta_obs, tau_loop):
    # 状态 = (技能节点, 视域模式)；边权 = 动作成本 − λ_info·信息增益
    h = lambda n: admissible_heuristic(n, task)
    path = a_star(product_graph(G_S, V), start=(root, V.start),
                  goal=task, heuristic=h,
                  edge_cost=lambda u, v: c_task(u, v) - lam_info * info_gain(u, v),
                  constraint=lambda p: view_closure(p, V, omega, theta_obs, tau_loop)[0] == 'ok')
    if path is None:
        return ('reject', 'no_observable_path')
    return insert_epistemic_actions(path, A_epi, theta_obs)
```

### IP-124 BPC（Build Provenance Certificate）

```python
def build_certificate(J_source, build_src, build_dst, validation_fn,
                      validation_set, delta_cal, alpha):
    d = build_distance(build_src, build_dst)
    if d > delta_cal:
        return ('reject', 'outside_build_envelope', d)
    residuals = [validation_fn(build_dst, case) for case in validation_set]
    eps_xfer = conformal_quantile(residuals, 1 - alpha)
    if eps_xfer > eps_xfer_max:
        return ('reject', 'transfer_residual', eps_xfer)
    return ('ok', PortableCert(J_source, provenance(build_dst),
                               eps_xfer, build_manifest(build_dst)))
```

### IP-125 CAL（Continuous Calibration Ledger）

```python
def calibration_ledger(build, wrist_frames, fingertip_fiducial, budget):
    T_wc, r_reproj = hand_eye_solve(wrist_frames, fingertip_fiducial)
    kappa = mount_flex_estimate(wrist_frames)
    debt = integrate(drift_exposure(r_reproj, kappa))
    if debt > budget or r_reproj > delta_r or kappa > delta_k:
        invalidate_visual_certificates(build)   # 全部视觉证书降级
        return ('conditional', debt, request_recalibration())
    return ('ok', T_wc, debt, calibration_hash(T_wc, kappa))
```

### IP-126 RRC（k-of-n Replication Certificate）

```python
def replication_certificate(J, build_manifest, n, k, alpha, p_min):
    builds = sample_independent_builds(build_manifest, n)   # 真实独立构建
    results = [validate_on_build(J, b) for b in builds]
    k_obs = sum(results)
    p_L = clopper_pearson_lower(k_obs, n, alpha)
    if p_L < p_min or not covers_declared_tolerance(build_manifest):
        return ('reject', 'not_reproducible', p_L, build_manifest)
    return ('ok', RRC(provenance(J), J, n, k_obs, p_L, alpha, build_manifest))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OBS | O(|A|·(N_state+N_obs+|V|)) | O(|A|) | 互信息估计无偏、覆盖标定包络 |
| VMC | O(|π|·|V|) | O(|π|+|V|) | 视域模式完备、时延可信 |
| APC | O(|V|·(|V|+|E|) log(|V|²)) | O(|V|²) | 乘积图完备、信息增益可估 |
| BPC | O(|val|·c_val) | O(|val|) | 构建包络声明、conformal 覆盖 |
| CAL | O(K·(pose_iter+tag_detect)) | O(K) | 标定可观测、漂移可检 |
| RRC | O(n·c_val) | O(n) | 独立构建、置信下界正确 |

**定理（Perception- and Build-Conditioned Composition Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** 在声明的光照/遮挡包络内，`ω̂` 的一致误差 ≤ ε_ω；**(A30)** 校准不确定度 `U_cal` 与迁移残差 `ε_xfer` 均由 conformal 方法以 `1−α` 覆盖；**(A31)** 构建 `b_1..b_n` 独立采样自声明构建分布 𝔅；**(A32)** 视域状态机 V 对任务转移完备，认知动作时延 ≤ τ_epi。
则对任一 `(σ,a) ∈ A^cert_{S,b}`：
```
P_success ≥ 1 − Σ_d (1−ρ_min(d)) − β_E − P(ω̂<θ_obs | 包络内) − P(U_cal>δ_cal)
```
跨构建 `b' ~ 𝔅`：
```
P_success(b') ≥ p_L − ε_xfer − ε_ω            （置信 1−α）
```
若 `obs_gap(π)>0`，则存在任务扰动下正测度路径，使证书在无法观测的状态上被误用，故上述界需再减去 `P(obs_gap>0)`。**关键**：公式中的每一项都对应一个可测量的拒绝/降级条件——不能测得 ω 就拒绝，不在构建包络内就重新标定，复现下界不达标就不宣称可复现。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| ω̂ 在 OOD 光照/透明物体上过度自信 | 高 | conformal 校准 + 不确定即弃权 + 主动探测 |
| 主动感知的“自遮挡反馈陷阱”（为看清而移动反而更看不清） | 高 | 视域前瞻 + 安全认知动作集 + 回撤兜底 |
| 手眼外参/支架形变静默漂移 | 高 | 指尖 fiducial 在线监测 + 校准债硬门 + 定期重标 |
| 开源构建方差过大导致证书不可移植 | 中 | 声明构建包络 + 证书亲和设计 + 验收测试 |
| 视觉闭环时延破坏云边契约 | 中 | 边端本地感知 + 全局快门 + 触发同步 |
| 供应链/镜头 revision 漂移 | 中 | BOM 哈希 + revision 锁定 + 入厂验收 |

## 6. 本轮最大风险

**一句话**：腕部相机与开源硬件把证书从“动作-鲁棒性”推进为“可观测性-构建”双重条件化，但 soundness 现在压在**可观测性估计器在 OOD 光照/遮挡下不过度自信、手眼与支架标定不发生静默漂移、以及构建分布被真实独立复现**这三根柱子上；一旦 ω̂ 把看不见的状态判成看得见，或同款开源硬件的手眼迁移悄悄失准，系统就会在“看起来已认证”的动作上系统性失明，而 k-of-n 还会把这种失明包装成可复现的假象——必须以 **conformal 弃权 + 指尖 fiducial 持续校准 + 构建包络硬门** 三重护栏，宁可拒绝部署，也不把“同款硬件 + 高置信预测”当成真实可观测。

> - **RRC（k-of-n Replication Certificate）**：开源硬件独立复现的统计证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入可观测性与构建维度。核心转向：**从「动作-鲁棒性双证书」改为「可观测性-构建条件化证书 + 可复现证据」**。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |
|---|---|---|---|
| IP-121 | OBS Observability Profiling | 新增 | `ω_{S,b}(a)=I(X_T;Z|do(a))/H(X_T)`，感知盲区识别 |
| IP-122 | VMC View-mode Closure | 新增 | 视域状态机 V，`obs_gap` 硬约束，时延入证书 |
| IP-123 | APC Active Perception Composition | 新增 | `G_S × V` 乘积图 + 信息增益项 `λ_info` |
| IP-124 | BPC Build Provenance Certificate | 新增 | 构建溯源 `P_b`、可移植算子、`ε_xfer` |
| IP-125 | CAL Continuous Calibration Ledger | 新增 | 指尖 fiducial 持续监测、校准债 `D_cal` |
| IP-126 | RRC k-of-n Replication Certificate | 新增 | Clopper-Pearson 下界 `p_L`，构建分布证据 |

**升级既有 IP**
- **IP-115 ACS**：动作剖面从 `α_S` 扩为 `(α_S, ω_{S,b})` 双剖面；
- **IP-116 SCOM**：组合图 `G_S` 扩为 `G_S × V`，边权加入视域转移时延与信息增益；
- **IP-118 AEC**：联合证书 `J` 增加 `ω`、`P_b`、`ε_xfer` 三个条件字段；
- **IP-120 JTC**：跨域迁移目标域同时受 `d(b,b')≤δ_cal` 与 `p_L≥p_min` 约束。

## 2. 关键算法 伪代码

### IP-121 OBS

```python
def observability_profile(skill, A, build, estimator, theta_obs, theta_cov, delta_cal):
    omega, cert = {}, {}
    for a in A:
        if skill.action_profile(a, build) < theta_cov:
            continue
        zs, xs = estimator.rollout(skill, a, build)
        omega[a] = estimator.mutual_info(xs, zs) / estimator.entropy(xs)
        U = estimator.calibration_uncertainty(a, build)
        cert[a] = (omega[a] >= theta_obs and U <= delta_cal)
    return omega, cert
```

### IP-122 VMC

```python
def view_closure(plan, view_automaton, omega, theta_obs, tau_loop):
    path, latency = [], 0
    v = view_automaton.start
    for S, a in plan:
        v_next = argmax_{v in dom_obs(S)} omega[S, a, v]
        if omega[S, a, v_next] < theta_obs:
            return ('reject', 'obs_gap', S, theta_obs - omega[S, a, v_next])
        edge = view_automaton.transition(v, v_next)
        if edge is None:
            return ('reject', 'view_unreachable', S)
        latency += edge.tau
        path.append((S, a, v_next))
        v = v_next
    if latency > tau_loop:
        return ('reject', 'view_latency', latency)
    return ('ok', path, latency)
```

### IP-123 APC

```python
def active_perception_plan(G_S, V, task, belief, lam_info, theta_obs, tau_loop):
    h = lambda n: admissible_heuristic(n, task)
    path = a_star(product_graph(G_S, V), start=(root, V.start),
                  goal=task, heuristic=h,
                  edge_cost=lambda u, v: c_task(u, v) - lam_info * info_gain(u, v),
                  constraint=lambda p: view_closure(p, V, omega, theta_obs, tau_loop)[0] == 'ok')
    if path is None:
        return ('reject', 'no_observable_path')
    return insert_epistemic_actions(path, A_epi, theta_obs)
```

### IP-124 BPC

```python
def build_certificate(J_source, build_src, build_dst, validation_fn,
                      validation_set, delta_cal, alpha):
    d = build_distance(build_src, build_dst)
    if d > delta_cal:
        return ('reject', 'outside_build_envelope', d)
    residuals = [validation_fn(build_dst, case) for case in validation_set]
    eps_xfer = conformal_quantile(residuals, 1 - alpha)
    if eps_xfer > eps_xfer_max:
        return ('reject', 'transfer_residual', eps_xfer)
    return ('ok', PortableCert(J_source, provenance(build_dst),
                               eps_xfer, build_manifest(build_dst)))
```

### IP-125 CAL

```python
def calibration_ledger(build, wrist_frames, fingertip_fiducial, budget):
    T_wc, r_reproj = hand_eye_solve(wrist_frames, fingertip_fiducial)
    kappa = mount_flex_estimate(wrist_frames)
    debt = integrate(drift_exposure(r_reproj, kappa))
    if debt > budget or r_reproj > delta_r or kappa > delta_k:
        invalidate_visual_certificates(build)
        return ('conditional', debt, request_recalibration())
    return ('ok', T_wc, debt, calibration_hash(T_wc, kappa))
```

### IP-126 RRC

```python
def replication_certificate(J, build_manifest, n, k, alpha, p_min):
    builds = sample_independent_builds(build_manifest, n)
    results = [validate_on_build(J, b) for b in builds]
    k_obs = sum(results)
    p_L = clopper_pearson_lower(k_obs, n, alpha)
    if p_L < p_min or not covers_declared_tolerance(build_manifest):
        return ('reject', 'not_reproducible', p_L, build_manifest)
    return ('ok', RRC(provenance(J), J, n, k_obs, p_L, alpha, build_manifest))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OBS | O(|A|·(N_state+N_obs+|V|)) | O(|A|) | 互信息估计无偏、覆盖标定包络 |
| VMC | O(|π|·|V|) | O(|π|+|V|) | 视域模式完备、时延可信 |
| APC | O(|V|·(|V|+|E|) log(|V|²)) | O(|V|²) | 乘积图完备、信息增益可估 |
| BPC | O(|val|·c_val) | O(|val|) | 构建包络声明、conformal 覆盖 |
| CAL | O(K·(pose_iter+tag_detect)) | O(K) | 标定可观测、漂移可检 |
| RRC | O(n·c_val) | O(n) | 独立构建、置信下界正确 |

**定理（Perception- and Build-Conditioned Composition Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** 在声明光照/遮挡包络内 `ω̂` 一致误差 ≤ ε_ω；**(A30)** `U_cal` 与 `ε_xfer` 由 conformal 以 `1−α` 覆盖；**(A31)** `b_1..b_n` 独立采样自声明构建分布 𝔅；**(A32)** 视域状态机完备，认知动作时延 ≤ τ_epi。则
```
∀(σ,a)∈A^cert_{S,b}: P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − P(ω̂<θ_obs) − P(U_cal>δ_cal)
∀b'~𝔅:              P_success(b') ≥ p_L − ε_xfer − ε_ω        (置信 1−α)
若 obs_gap(π)>0:     P_success 再减 P(obs_gap>0)
```
**关键**：每一项都是一个可执行的拒绝/降级条件；证书只声明“在可观测域与构建包络内、且经 k-of-n 复现”的部分。

```
根信任 + 能力格
│
├─ L0 分布式底座与执行边 (GPC/SEN/TBC)

├─ L0.5+ 鲁棒性层 (TRO,RXC,RCO,REX,RTA,TRC,RUR) ← v53
├─ L0.5++ 动作-协同层 (ACS,SCOM,CEC,AEC,JTC) ← v54
├─ L0.5+++ 可观测-构建层 (OBS,VMC,APC,BPC,CAL,RRC) ← v55 新增
├─ L1 几何感知
├─ L2 任务/上下文/记忆/语音
...
└─ L6 原型证伪/XFER/LFF/IXD
```

JCPS 输出扩展为：
`(v,a,m,q,ι,κ,g,λ,τ,σ,ρ,Explain,RUR_state,α_S,A_cert,γ_ce,δ_a,ω_{S,b},V_path,P_b,ε_xfer,D_cal,RRC)`

其中新增：
- `ω_{S,b}` 可观测性剖面与感知盲区；
- `V_path` 视域状态机路径与 `obs_gap`；
- `P_b` 构建溯源（BOM/CAD/镜头/标定哈希）；
- `ε_xfer` 跨构建证书迁移残差；
- `D_cal` 校准债；
- `RRC=(n,k,p_L,α)` 独立复现证书。

**与既有 IP 的接口**
- IP-115 ACS 的 `α_S` 与 IP-121 的 `ω` 共同定义 `A^cert`；只有二者同时达标的动作才进入 IP-116 的组合图。
- IP-118 AEC 的联合证书升级为 `J_b`，多一个“构建条件”与“可观测条件”的合取项。
- IP-117 CEC 的边端校验新增 `view_closure`；视域时延超 `τ_loop` 直接否决，防止云边契约被视觉回路悄悄破坏。
- IP-120 JTC 的跨域迁移改为“先 BPC 迁移证书、再 JTC 迁移任务”，顺序不可交换。

## 6. UniBot 参赛叙事与差异化

| 维度 | 常见做法 | 本轮方案 |
|---|---|---|
| 腕部相机 | 当作额外输入通道，固定外参 | **可观测性剖面 + 视域状态机**，主动感知进入技能组合 |
| 开源硬件 | 低成本 BOM + 复现视频 | **构建溯源 + 证书可移植 + k-of-n 统计复现** |
| 失败分析 | 汇总成功率 | **区分感知盲区、视域缺口、校准漂移、构建迁移失败**，每类有拒绝条件 |
| 证书 | 单机、单次、全局 | **范围化、构建条件化、可审计**，不达标即拒绝 |

**三个可主张的创新点**
1. 首次把腕部相机的**可观测性**提升为技能组合的第一性约束，并给出 `G_S × V` 可判定规划与 `obs_gap` 硬门；
2. 首次把开源硬件纳入证书体系：**构建溯源 `P_b` + 可移植算子 `T_{b→b'}` + k-of-n 复现下界 `p_L`**，使“开源”成为证据而非叙事；
3. 给出低成本、可复制的 **OpenWrist** 硬件与“证书亲和设计”原则，使上述理论在 UniBot 平台上可落地、可被第三方独立复验。

## 7. 本轮最大风险

**一句话**：腕部相机与开源硬件把证书从“动作-鲁棒性”推进为“可观测性-构建”双重条件化，但 soundness 现在压在**可观测性估计器在 OOD 光照/遮挡下不过度自信、手眼与支架标定不发生静默漂移、以及构建分布被真实独立复现**这三根柱子上；一旦 ω̂ 把看不见的状态判成看得见，或同款开源硬件的手眼迁移悄悄失准，系统就会在“看起来已认证”的动作上系统性失明，而 k-of-n 还会把这种失明包装成可复现的假象——必须以 **conformal 弃权 + 指尖 fiducial 持续校准 + 构建包络硬门** 三重护栏，宁可拒绝部署，也不把“同款硬件 + 高置信预测”当成真实可观测。
