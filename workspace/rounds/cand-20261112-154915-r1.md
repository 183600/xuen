# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环新篇；本轮灵感：「强化学习训练」×「抗干扰」）

> 第 60 轮把「执行层→证据层」闭环升级为「认知驱动的场景-执行闭环」：SSM 场景-阻抗先验、CIEC 意图→约束锁定、EPIR 消息因果隔离、SERC 闭环、PCE++++ 四维认知预算、SIC 三元校验、CESC 联合决策。但仍有三处**未被触及的根问题**：
> 1. **认知是「手工先验」，不是「学出来的」**：π_scene(K|z)、SIC 的记忆系数 β、CIEC 的意图→约束映射都是人工设定的常量或查表。真实接触经验没有被用来改进它们；换个用户、换种说法（「再温柔一点」）映射表就失效，场景先验也无法从数据中自适应。
> 2. **抗干扰停在执行层，认知层完全裸奔**：EPIR 只对「消息丢失」这一种干扰做恢复，SIC 只对「置信度低」做回退；但**场景误判、意图误解析、观测对抗扰动**会让错误的 K_safe^scene「合法地」通过 EEIS 编译——安全证书依然成立，因为它证明的是「在错误前提下仍安全」。这是比执行噪声更危险的**语义级干扰**。
> 3. **训练是新的攻击面，也是被浪费的数据源**：在线 RL 的探索动作会直接破坏执行安全；而 EPIR 影子副本里积累的 EV-exec 证据链，本可作为**离线强化学习**的高质量数据，却只被用来做对账。

## 0. 直觉与动机

**灵感 1（强化学习训练 → 抗干扰对抗训练 RAL）**
直觉：不要只在「标称场景」上训练阻抗策略，而要让**对手**同时扰动四个通道：物理力/摩擦、场景观测、意图措辞、ROS 消息。策略学到的不是一个「最优阻抗点」，而是一个**抗干扰阻抗流形**（robust impedance manifold）——在扰动集合 Δ 内任意一点都仍然可行。关键洞见：把「抗干扰」从**事后滤波**变成**训练时的 minimax 目标**：π* = argmax_π min_{δ∈Δ} J(π, δ)。

**灵感 2（抗干扰 → 训练-执行解耦护盾 TED）**
直觉：RL 训练慢、探索危险；执行快、必须绝对安全。让两者**物理隔离**：学习器只能在「提案面」输出阻抗分布 q_θ(K|s)，真正的执行参数必须经过 EEIS/ERTC 的**安全面**求交后才下发。学习器永远没有直接执行权（no actuation authority），相当于给 RL 套一个**不可学习的硬护盾**。关键洞见：**性能可以学，安全不能学**——护盾是确定性的，策略才是可训练的。

**灵感 3（强化学习训练 → 干扰课程控制器 DCC）**
直觉：一上来就训练最强的对抗扰动会让策略崩溃；应当像课程学习一样，从「轻微推力」逐步升级到「湿滑 + 误判 + 丢包」的复合干扰。用成功率做门控：成功率高于 τ_up 就升温（加大扰动），低于 τ_down 就降温。关键洞见：**干扰强度本身是一个可调的「训练温度」T_dist**，且必须受训练预算 B_train 约束。

**灵感 4（强化学习训练 → 证据影子回放 OSR）**
直觉：EPIR 的影子副本 S_shadow 其实就是一条**带时间戳与哈希的执行轨迹**，天然是离线 RL 的 replay buffer。用保守离线 RL（CQL/IQL）在这条证据链上训练，可以在**不与环境交互**的情况下改进策略，规避在线探索的安全风险。关键洞见：**证据链即数据集**——第 60 轮为「可追溯」存下的数据，本轮变成「可学习」的资产。

**灵感 5（抗干扰 → 反事实影子晋升 CSP + 鲁棒性证书 RRC）**
直觉：学好的新策略不能「热更新」到真机；先让它在**反事实世界模型**里对当前真实状态做「影子推演」，只有当它相对现策略的**反事实增益 G_cf** 足够大、且**鲁棒性证书 ρ_θ(s)** 在扰动集 Δ 下仍然达标、并通过 10⁴ 次随机扰动的护盾测试，才允许晋升。关键洞见：**晋升是一次受控实验，不是一次部署**。

**灵感 6（合流 → 抗干扰训练-执行闭环 RTE，PCE+++++ 五维预算）**
直觉：RAL 学出抗干扰流形 → TED 把它约束进安全面 → DCC 控制训练难度 → OSR 用证据链离线训练 → CSP/RRC 决定能否晋升 → 执行时 RCA 依据 ρ 在「学习策略 / 场景先验 / 保守策略」之间仲裁。预算从四维扩展为五维：新增 **B_train = (B_rollout, B_adv, B_sim2real, B_compute)**；任一维度耗尽都有确定的降级路径，绝不允许「无限训练」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（结构化扰动集 Δ 与抗干扰策略）** Δ = Δ_phys × Δ_scene × Δ_intent × Δ_comm，其中：
- **物理扰动**：Δ_phys = {δ_f : ‖δ_f‖_∞ ≤ ε_f} ∪ {δ_μ : |μ−μ₀| ≤ ε_μ}（外力、负载、摩擦系数）
- **语义扰动**：Δ_scene = {δ_o : ‖δ_o‖₂ ≤ ε_o}，且允许至多 k_o 个场景标签翻转
- **意图扰动**：Δ_intent = {δ_I : d_sem(I, I′) ≤ ε_I}（同义、歧义、口语化指令的语义邻域）
- **通信扰动**：Δ_comm = {δ_m : 丢包率 ≤ p_loss, 时延 ≤ d_max, 乱序 ≤ r_max}
- **抗干扰策略**：π* = argmax_π min_{δ∈Δ} E_{τ~π_δ}[R(τ)]，约束 K_t ∈ K_safe(t) 几乎必然成立
- **抗干扰阻抗流形**：M_rob(α) = {K : min_{δ∈Δ} Feasible(K, δ) ≥ 1−α}

**定义 162（训练-执行解耦护盾 TED）** 三平面：训练面 P_train（仿真/离线，无执行权）→ 提案面 P_prop（q_θ(K|s)）→ 安全面 P_safe（EEIS + ERTC 确定性编译）。下发规则：
```
K_dispatch = argmin_{K ∈ supp(q_θ) ∩ K_safe^scene ∩ C_intent} Ĵ(K)
若交集为空：K_dispatch = Proj_{K_safe}(K_θ)，且 veto_flag = 1
```
**护盾不变式**：∀θ，P(K_dispatch ∈ K_safe) = 1——训练过程无论多「野」，都不可能把非法参数送上执行层。

**定义 163（干扰课程控制器 DCC）** 课程状态 c_t = (ε_f, ε_μ, ε_o, ε_I, p_loss, d_max)。升温/降温：
```
ε_{t+1} = Clip(ε_t · (1 + η·1[SR_t ≥ τ_up] − η·1[SR_t < τ_down]), ε_min, ε_max)
```
其中 SR_t 为最近 W 个 episode 的成功率，η 为课程步长；硬样本占比 ≤ 1−η，课程受 B_train 约束。

**定义 164（证据影子回放 OSR）** 离线数据集 D_off = S_shadow（EPIR 影子副本）∪ 历史 EV-exec。保守离线目标：
```
L(θ) = −E_{D_off}[Q_θ(s,a)]
     + α·E_s[ log Σ_a exp Q_θ(s,a) − Q_θ(s,a_data) ]      # CQL 保守项
     + β·E_s[ D_KL(π_θ(·|s) ‖ π_β(·|s)) ]                  # 行为约束
     + λ_s·E[ max(0, ĥ(s,a)) ]                             # 安全屏障惩罚
```
CQL 项惩罚 OOD 动作的 Q 高估，使离线策略不因「没见过」而盲目乐观。

**定义 165（反事实影子晋升 CSP）** 影子策略 π_sh 只在真实状态 s_t 上做反事实推演（无执行权）：
```
G_cf(s_t) = E_{τ~π_sh}[R | s_t] − E_{τ~π_cur}[R | s_t]   # 世界模型/重要性采样估计
晋升条件：G_cf ≥ g_min ∧ ρ_{π_sh}(s_t) ≥ τ_ρ ∧ ShieldTest(π_sh, Δ, N=10⁴)=pass ∧ 人工授权
```
四者同时满足才执行 π_cur ← π_sh，否则 π_sh 继续影子运行。

**定义 166（鲁棒性证书 RRC）** 给定状态 s 与扰动集 Δ，证书 ρ_θ(s) 是任务成功/约束满足的下界：
```
ρ_θ(s) = 1 − CVaR_α[Cost(τ) | δ~Δ]           # 分布鲁棒视角
     或 ρ_θ(s) = min_{δ∈Δ} min_t h(s_t)     # 屏障视角（IBP / Lipschitz 下界）
```
在线门控：仅当 ρ_θ(s) ≥ τ_ρ 才允许下发学习策略，否则回退保守策略。**可靠性**：若 ρ 由可验证下界（区间传播 / Lipschitz）计算，则真实抗干扰裕度 ≥ ρ。

**定义 167（五维训练预算 B_train 与 PCE+++++）** B_train = (B_rollout, B_adv, B_sim2real, B_compute)。合并第 60 轮认知预算：
```
B_total = B_cog ⊕ B_train = (B_scene, B_intent, B_ros, B_exec, B_train)
voi_train(π) = VOI_meta(π) − cost_cog(π) − cost_exec(π) − cost_train(π)
cost_train = λ_roll·Rollouts + λ_adv·AdvQueries + λ_s2r·Sim2RealGap + λ_comp·GPU
```
**耗尽降级**：B_rollout 耗尽→冻结 θ、沿用最后通过证书的策略；B_adv 耗尽→收缩 Δ 幅度；B_sim2real 耗尽→加大安全裕度 λ_s；B_compute 耗尽→关闭影子训练（仅保留在线执行）。

**定义 168（抗干扰仲裁 RCA）** 候选集 C = {K_θ（学习）, K_scene（SSM 先验）, K_cons（保守编译）}。评分与硬否决：
```
S(K) = (1−λ)·Ê[R|K] + λ·ρ(K) − μ·Cost(K)
ρ(K_θ) < τ_ρ ⇒ S(K_θ) = −∞            # 学习策略必须先过证书，才配参与仲裁
K* = argmax_{K ∈ C ∩ K_safe} S(K)，同分取 ρ 更大者
```
RCA 是「学习性能」与「可验证安全」的最终仲裁器。

## 2. 关键算法伪代码

### IP-161 RAL（抗干扰对抗训练）

```python
def robust_adversarial_train(policy, env, delta, budget, dcc):
    for episode in range(budget.B_rollout):
        s = env.reset()
        dist_sample = delta.sample(course=dcc.state())   # DCC 提供当前干扰温度
        traj = []
        while not env.done:
            qK = policy.propose(s)                        # 阻抗候选分布
            K_safe = env.eeis.certified_set(s)            # TED 安全面
            K_exec = project_to_intersection(qK, K_safe)  # 永不下发非法参数
            s2, r, info = env.step(K_exec, dist_sample)
            traj.append((s, K_exec, r, s2))
            s = s2
        delta.ascend(traj, steps=budget.B_adv)            # 内层对手上升
        policy.update(traj, robust="cvar", alpha=DELTA)   # 最小化 CVaR 代价
        dcc.update(info.rolling_success_rate)             # 课程门控
    return policy
```

### IP-162 TED（训练-执行解耦护盾）

```python
def shield_dispatch(policy_q, s, eeis, ertc, intent):
    support = policy_q.top_k(s, k=8)                      # 学习器只提案
    K_safe = eeis.compile(s) & ertc.locked_set(intent)    # 确定性安全面
    feasible = [K for K in support if K in K_safe]
    if not feasible:
        K = eeis.project(K_safe, policy_q.mean(s))        # 投影回安全面
        return K, {"veto": True, "reason": "learned-policy-veto"}
    K = min(feasible, key=lambda k: policy_q.cost(s, k))
    return K, {"veto": False}
```

### IP-164 OSR（证据影子回放）

```python
def offline_shadow_update(policy, q, D_off, steps):
    for _ in range(steps):
        s, a, r, s2 = D_off.sample()
        q_target = r + GAMMA * q.target(s2, policy.act(s2))
        td = (q(s, a) - q_target) ** 2
        cql = torch.logsumexp(q(s, all_actions), dim=-1) - q(s, a)
        bc = (policy.logprob(a, s) - behavior_logprob(a, s)) ** 2
        safety = torch.relu(barrier(s, a))
        loss = td + ALPHA * cql.mean() + BETA * bc.mean() + LAMBDA * safety.mean()
        loss.backward(); opt.step()
```

### IP-165/166 CSP + RRC（影子晋升与证书）

```python
def counterfactual_promotion(shadow, current, world_model, s, Delta):
    G_cf = estimate_return(world_model, shadow, s) - estimate_return(world_model, current, s)
    rho = robustness_certificate(shadow, s, Delta)       # CVaR / IBP 下界
    shield_pass = randomized_shield_test(shadow, Delta, n=10_000)
    ok = (G_cf >= G_MIN and rho >= TAU_RHO and shield_pass and authorized())
    return (shadow if ok else current), {"promoted": ok, "G_cf": G_cf, "rho": rho}
```

### IP-168 RCA（抗干扰仲裁）

```python
def robust_arbitrate(candidates, s, Delta, ertc):
    best, best_score = None, -float("inf")
    for name, K in candidates.items():
        if not ertc.admissible(K, s):
            continue
        rho = robustness_of(K, s, Delta)
        if name == "learned" and rho < TAU_RHO:
            continue                                      # 硬否决：未过证书不得参与
        score = (1 - LAM) * expected_reward(K, s) + LAM * rho - MU * cost(K)
        if best is None or score > best_score or (
                score == best_score and rho > robustness_of(best, s, Delta)):
            best, best_score = K, score
    return best
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RAL | O(E·T·|Δ|) | O(D_off) | 扰动集 Δ 内成功率下界可估 |
| TED | O(k·|K_safe|) | O(k) | 下发必在 K_safe（概率 1） |
| DCC | O(1)/周期 | O(W) | 课程单调有界，不越 ε_min/ε_max |
| OSR | O(steps·B) | O(D_off) | CQL 保守性：OOD 动作不被高估 |
| CSP | O(N_test) 仅晋升时 | O(1) | 四条件齐备才晋升 |
| RRC | O(|Δ|·T) | O(T) | ρ 为可验证下界 |
| RCA | O(|C|·|Δ|) | O(|C|) | 硬否决保证不低于保守策略 |

**正确性定理（RTEC）**：假设 A66–A70 成立：
**(A66)** RAL：Δ 紧致，minimax 目标存在鞍点，CVaR 估计一致；**(A67)** TED：EEIS 的 K_safe 非空且可投影（承接第 59 轮）；**(A68)** OSR：D_off 覆盖执行分布 supp(π_β)，CQL 保守项 ≥ 0；**(A69)** CSP/RRC：ρ 为可验证下界（IBP/Lipschitz），ShieldTest 覆盖 Δ 的 ε-网；**(A70)** RCA：至少一个候选 ∈ K_safe（保守编译保底）。则：
1. **安全不变性**：∀θ、∀t，K_dispatch(t) ∈ K_safe(t)（TED 护盾 ∩ RCA 硬否决，概率 1）。
2. **抗干扰下界**：若 ρ_θ(s) ≥ τ_ρ，则对真实扰动 δ∈Δ 有 J(π_θ, δ) ≥ J_min − Δ(τ_ρ)。
3. **晋升可信性**：CSP 四条件满足 ⇒ 晋升策略在 Δ 上以 G_cf 与 ρ 为界不劣于现策略。
4. **预算安全性**：任一 B_train 维度耗尽 ⇒ 触发冻结/收缩/加裕度/关影子策略，训练有界终止。

## 5. 本轮最大风险

**一句话**：对抗训练可能把策略练成「只会应付 Δ 内见过的扰动」，一旦真实干扰落在 Δ 之外（OOD 扰动），鲁棒性证书 ρ 仍会给出乐观下界，导致「证书看似达标、实机却崩溃」的**证书-现实错位**；必须以「OOD 判别器 + 证书置信折扣 + RCA 保守策略保底」确保 Δ 外自动降级，而不是盲目信任学习策略。

### IP-161 RAL（抗干扰对抗训练）

```python
def robust_adversarial_train(policy, env, delta, budget, dcc):
    for episode in range(budget.B_rollout):
        s = env.reset()
        dist_sample = delta.sample(course=dcc.state())
        traj = []
        while not env.done:
            qK = policy.propose(s)
            K_safe = env.eeis.certified_set(s)           # TED 护盾
            K_exec = project_to_intersection(qK, K_safe)
            s2, r, info = env.step(K_exec, dist_sample)
            traj.append((s, K_exec, r, s2)); s = s2
        delta.ascend(traj, steps=budget.B_adv)           # 内层对手
        policy.update(traj, robust="cvar", alpha=DELTA)  # 抗最坏分位
        dcc.update(info.rolling_success_rate)
    return policy
```

### IP-162 TED（训练-执行解耦护盾）

```python
def shield_dispatch(policy_q, s, eeis, ertc, intent):
    support = policy_q.top_k(s, k=8)
    K_safe = eeis.compile(s) & ertc.locked_set(intent)
    feasible = [K for K in support if K in K_safe]
    if not feasible:
        K = eeis.project(K_safe, policy_q.mean(s))
        return K, {"veto": True, "reason": "learned-policy-veto"}
    return min(feasible, key=lambda k: policy_q.cost(s, k)), {"veto": False}
```

### IP-163 DCC（干扰课程控制器）

```python
class DisturbanceCurriculum:
    def __init__(self, eta=0.1, tau_up=0.85, tau_down=0.6, eps_min=0.05, eps_max=1.0):
        self.c = dict(eps_f=eps_min, eps_mu=eps_min, eps_o=eps_min,
                      eps_I=eps_min, p_loss=0.0, d_max=0.01)
        self.eta, self.tau_up, self.tau_down = eta, tau_up, tau_down
        self.eps_min, self.eps_max = eps_min, eps_max
        self.window = deque(maxlen=20)

    def update(self, success_rate):
        self.window.append(success_rate)
        sr = sum(self.window) / len(self.window)
        for k in self.c:
            if k == "p_loss":
                self.c[k] = clip(self.c[k] + self.eta * (1 if sr >= self.tau_up else -1 if sr < self.tau_down else 0), 0.0, 0.3)
            else:
                up = self.eta if sr >= self.tau_up else -self.eta if sr < self.tau_down else 0.0
                self.c[k] = clip(self.c[k] * (1 + up), self.eps_min, self.eps_max)

    def state(self):
        return self.c
```

### IP-164 OSR（证据影子回放）

```python
def offline_shadow_update(policy, q, D_off, steps):
    for _ in range(steps):
        s, a, r, s2 = D_off.sample()
        q_target = r + GAMMA * q.target(s2, policy.act(s2))
        td = (q(s, a) - q_target) ** 2
        cql = torch.logsumexp(q(s, all_actions), dim=-1) - q(s, a)
        bc = (policy.logprob(a, s) - behavior_logprob(a, s)) ** 2
        safety = torch.relu(barrier(s, a))
        loss = td + ALPHA * cql.mean() + BETA * bc.mean() + LAMBDA * safety.mean()
        loss.backward(); opt.step()
```

### IP-165/166 CSP + RRC（影子晋升与鲁棒性证书）

```python
def robustness_certificate(policy, s, Delta):
    costs = [rollout_cost(policy, s, delta.sample()) for delta in Delta.net(eps=DELTA_EPS)]
    return 1.0 - cvar(costs, alpha=ALPHA_CVAR)          # 可验证下界

def counterfactual_promotion(shadow, current, world_model, s, Delta):
    G_cf = estimate_return(world_model, shadow, s) - estimate_return(world_model, current, s)
    rho = robustness_certificate(shadow, s, Delta)
    shield_pass = randomized_shield_test(shadow, Delta, n=10_000)
    ok = (G_cf >= G_MIN and rho >= TAU_RHO and shield_pass and authorized())
    return (shadow if ok else current), {"promoted": ok, "G_cf": G_cf, "rho": rho}
```

### IP-167 PCE+++++（五维预算耦合）

```python
class TrainBudget:
    def __init__(self, rollout=10_000, adv=2_000, sim2real=50, compute=100):
        self.B_rollout, self.B_adv = rollout, adv
        self.B_sim2real, self.B_compute = sim2real, compute
        self.used = dict(rollout=0, adv=0, sim2real=0, compute=0)

    def degrade(self):
        if self.used["rollout"] >= self.B_rollout:   return "freeze_policy"
        if self.used["adv"] >= self.B_adv:           return "shrink_delta"
        if self.used["sim2real"] >= self.B_sim2real: return "raise_safety_margin"
        if self.used["compute"] >= self.B_compute:   return "shadow_off"
        return "normal"
```

### IP-168 RCA（抗干扰仲裁）

```python
def robust_arbitrate(candidates, s, Delta, ertc):
    best, best_score = None, -float("inf")
    for name, K in candidates.items():
        if not ertc.admissible(K, s):
            continue
        rho = robustness_of(K, s, Delta)
        if name == "learned" and rho < TAU_RHO:
            continue                                    # 硬否决
        score = (1 - LAM) * expected_reward(K, s) + LAM * rho - MU * cost(K)
        if best is None or score > best_score or (
                score == best_score and rho > robustness_of(best, s, Delta)):
            best, best_score = K, score
    return best
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| RAL | O(E·T·|Δ|) | O(D_off) | Δ 内成功率下界可估 |
| TED | O(k·|K_safe|) | O(k) | P(K_dispatch∈K_safe)=1 |
| DCC | O(1)/周期 | O(W) | 课程单调有界 |
| OSR | O(steps·B) | O(D_off) | CQL 保守性成立 |
| CSP | O(N_test) 仅晋升时 | O(1) | 四条件齐备才晋升 |
| RRC | O(|Δ|·T) | O(T) | ρ 为可验证下界 |
| RCA | O(|C|·|Δ|) | O(|C|) | 不低于保守策略保底 |

**正确性定理（RTEC）**：若 A66–A70 成立，则：
1. **安全不变性**：∀θ、t，K_dispatch(t) ∈ K_safe(t)（TED 求交 ∩ RCA 硬否决）。
2. **抗干扰下界**：ρ_θ(s) ≥ τ_ρ ⇒ 对 δ∈Δ 有 J(π_θ,δ) ≥ J_min − Δ(τ_ρ)。
3. **晋升可信性**：CSP 四条件满足 ⇒ 晋升后策略在 Δ 上以 G_cf、ρ 为界不劣于现策略。
4. **预算安全性**：任一 B_train 维度耗尽 ⇒ 冻结/收缩/加裕度/关影子，训练有界终止。

| 实验 | 指标 | 目标 |

| E192 RAL | Δ 下成功率、标称退化 | ≥ 80%；≤ 5% |

| E195 TED+RRC | 安全违反率、证书覆盖率 | 违反率 0；覆盖 ≥ 95% |

**消融矩阵**：去掉 TED ⇒ 预期出现「学习策略越强、安全违反越多」的反向相关；去掉 RRC ⇒ 证书覆盖率与实机成功率脱钩；去掉 DCC ⇒ 样本效率显著下降；去掉 OSR ⇒ 训练成本上升、且失去离线安全改进。该矩阵用于证明四个组件各自的不可替代性。

## 5. 本轮最大风险

**一句话**：对抗训练可能把策略练成「只会应付 Δ 内见过的扰动」，一旦真实干扰落在 Δ 之外（OOD 扰动），鲁棒性证书 ρ 仍会给出乐观下界，导致「证书看似达标、实机却崩溃」的**证书-现实错位**；必须以「OOD 判别器 + 证书置信折扣 + RCA 保守策略保底」确保 Δ 外自动降级，而不是盲目信任学习策略。
