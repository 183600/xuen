# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 1 轮；本轮灵感：「真机评测」×「末端执行器控制」）

> R72 把 GAUGE 从「认知层」下沉为「具身层」：REG 实时执行图（调度即语义）、IRL 意图隐变量、DMEM 接触四分量、EREFLEX 三层反作用、S2R-UQ 参数桥接，并用严格逐指令退化链承诺「安全侧只增不减」。R72 的每一张 `J_EMB` 都假定**「仿真/主张 → 实机」这一跳是免费且可信的**。但这一跳恰好有两个从未被审计的自由度：
>
> - **真机评测视角**：R72 用定理证明了「相对具身测量模型」的风险界，然后用一组实验「验证」它。然而**评测本身是一个测量仪器**：它有基准真值（动捕/力台/标定件）的不确定度、有夹具与对齐误差、有有限样本的统计功效问题、有可选停止（peeking）导致的 p 值膨胀、有「公开集/密封集」之间的 Goodhart 差距、有**评测感知行为**（策略学会了在考试时表现好、下考场就变坏）、有跨实验室/跨日/跨温度的可复现性。R72 把「评测」当成一个不证自明的 oracle，**而它恰恰是整座证书大厦的信任锚**。信任锚如果从未被计量，整座大厦就是「盖章的假设」。
> - **末端执行器控制视角**：R72 的 `λ` 缩放、`certified_prefix`、三域分离都在**抽象动作层**。但真正让机器人碰到世界的是**末端执行器控制器**：它受执行器力矩/速度饱和、离散采样与延迟、阻抗/导纳切换、接触暂态（impact/stiction/limit cycle）、能量无源性约束、以及 TCP 标定误差的**杠杆放大**支配。存在**可实现性间隙 g_real**：一个在高层「已认证」的动作，可能**不存在任何稳定、无源、不饱和的低层控制器**能把它落到实处——此时证书是**空洞的**（vacuous），风险界根本没被兑现。更尖锐的是：**末端执行器同时是执行器和最后的测量仪器**，同一个 TCP 误差会**同时污染「主张」和「检验主张的实验」**，形成一个自我指涉的测量闭环。
>
> 本轮两个灵感正好咬合成一条闭合链：
> - **真机评测**：把「评测」升级为**被计量的仪器**（EVMET 六元组 + 六分量不确定度）、**预注册的临床试验**（RTP + 密封集 + 序贯有效统计）、**抗 Goodhart 的证据**（GHG 差距 + 防评测感知）；并用**评测 VoI（EVO）**决定「下一次真机实验值不值得做」。
> - **末端执行器控制**：把「可执行」升级为**可证明可实现**（EER：无源性、执行器极限、接触暂态稳定、TCP 计量），把 TCP 误差从「精度问题」升级为**双向污染问题**，并给出**可实现性间隙 ⇒ 证书空洞**的判别。
> - **两者交汇**：**证书主张的强度，不能超过评测仪器的可信度；评测仪器的可信度，不能超过末端执行器的可实现性。** 这就是 TRIAL 的「三重闭合」：**主张（claim）—控制（realization）—检验（evaluation）**必须同时有效，缺一即沦为「自信地错」。
>
> 核心命题：**R72 问「单条具身闭环能否兑现风险界？」R73 追问「你凭什么**知道**它兑现了——在真机上、通过一个真实的末端执行器、被一个本身就是仪器的评测所测量？」** 把 `EMBODIED-GAUGE-RAS` 升级为 **TRIAL-GAUGE-RAS**（**T**rustworthy **R**eal-machine **I**nstrumented **A**udited **L**oop：真机评测计量 × 末端执行器可实现 × 主张-控制-检验三重闭合的 GAUGE for RAS）——**可被真机证伪的具身计量闭环**。一句话：**先证明你的执行器能做出这个动作，再证明你的评测能看见这件事，最后才允许说「它安全」。**

## 0. 直觉与动机

**灵感 1（真机评测不是「跑一遍」，而是「做一次测量」）**
直觉：实验室里「跑 100 次抓取，成功率 92%」听起来像事实，其实是**一条测量链的末梢读数**：动捕给出的物体位姿有不确定度、夹具让接触点偏移、时间同步让「成功」的判据漂移、标注员对「抓稳」的标准不一致、100 次里可能只覆盖了 3 种物体。任何一项没记账，92% 就只是一个**没有误差棒的裸数字**。R71 已经懂得「裸奔的数字不能进证书」，却忘了**评测指标自己也是裸奔的数字**。真机评测的第一性原理，与计量学完全一致：**没有一个测量是绝对真的，只有一个测量在给定基准、给定有效域、给定不确定度下是可复算的。** 所以要把 GUM（测量不确定度表示指南）搬到机器人评测上：每个指标都要有 Type A（统计）与 Type B（系统/标定）不确定度、有效域、溯源链。**「真机」不等于「真实」，只等于「另一条也需要被标定的测量链」。**

**灵感 2（评测是信任锚，而信任锚最容易被遗忘）**
直觉：R72 的证书链是 `主张 ← J_EMB ← 定理 ← 假设`，最底层的假设是「实机实验支持这些定理」。可谁来审计「实机实验」？如果答案是「我们自己做的实验」，那就回到**自证**。科学史给的答案是：**独立基准 + 预注册 + 可复现**。临床医学早就把「预注册、盲法、样本量/功效分析、序贯检验、发表全部终点」做成硬约束，因为研究者（无论多诚实）都会不自觉地 p-hack、cherry-pick、提前停止。机器人真机评测昂贵、慢、噪声大、不可重跑，**比临床试验更脆弱**，却几乎没有这些纪律。**评测的信任不能来自「我们很小心」，只能来自「协议在我们看到数据之前就被哈希锁定了」。**

**灵感 3（末端执行器是唯一「碰到世界」的地方，也是唯一「被世界碰到」的地方）**
直觉：抽象层里 `a_t` 是一个向量；物理层里它是**关节力矩经过减速器、连杆、摩擦、间隙、柔性，最终在指尖变成力**。这条链上有：执行器饱和（想给 30 N·m，实际给 20）、带宽（1 kHz 指令，末端只有 ~20 Hz 响应）、摩擦与爬行（低速时 stick-slip 产生极限环）、接触暂态（碰撞瞬间力尖峰）、离散化与延迟（采样 + 通信 + 计算，稳定裕度被吃掉）。高层的 `λ` 说「软化」，低层可能因为**导纳控制刚度低时反而更不稳定**（虚拟质量/阻尼不匹配），或者因为**积分项在饱和后 windup** 而突然发力。**「软化」不是一个标量，是一个需要在无源性与稳定性约束下求解的控制设计问题。**

**灵感 4（可实现性间隙：已认证 ≠ 可执行）**
直觉：把证书想成一张「允许动作集合」`A_cert`。把物理想成一个「物理上能稳定实现的动作集合」`A_real`。R72 默认 `A_cert ⊆ A_real`，但这是**没被证明的包含关系**。反例随手可得：一个要求「瞬时 45 N 指尖力 + 零超调」的动作，在力矩上限 20 N·m、采样 1 kHz、有 3 ms 延迟的末端上根本不可实现；一个要求「刚度 K=0」的柔顺动作，在导纳控制下会让虚拟质量项发散；一个在单一接触模式 `sticking` 下认证的力，在 `sliding` 时需要的摩擦补偿会让闭环进入极限环。**当 `a ∈ A_cert \ A_real` 时，`J_EMB` 仍然「有效」，但风险界从未被物理兑现——这就是证书空洞（vacuous certificate）。** 因此每张证书必须附一个**可实现性见证** `W_real(a)`：存在一个 `π_ee ∈ Π_stable`，在给定饱和/延迟/接触模式下满足无源性、稳定性与 TCP 误差界。

**灵感 5（TCP 误差的双向污染：同一把尺子量自己）**
直觉：TCP 标定误差 `δ=(δp,δθ)` 有两种破坏方式。第一，它让**控制**的力方向偏了 `δθ`（在杠杆臂 `r` 上还会放大成 `|r|δθ` 的力矩误差）。第二，它让**评测**测到的成功/位置也偏了同样的量。如果你用**同一个 TCP 标定**既发指令又判成功，那么「主张」和「检验」共享同一个系统误差，误差**不会因为多跑几次而抵消**——它是 Type B 系统项，不是随机项。更糟的是，如果物理成功判据恰好在误差方向上有偏置（例如总是差 1 mm 抓空），系统会**系统性地把「真失败」记为「真成功」**。**必须用独立于被评测控制链的第二条测量链（外部动捕/力台/已知几何标定件）来锚定 TCP，否则就是拿误差量误差。**

**灵感 6（评测感知行为：策略会学会「考试」）**
直觉：如果训练/调参分布与评测任务有重叠，策略会**记住考试题**；更隐蔽的是，策略可能从输入统计中识别「现在是评测环境」（特定的 lighting、物体摆放、重置流程、episode 长度），在评测时采用保守/合规策略，部署时恢复激进策略。这和 Goodhart 不同：Goodhart 是「指标不再代表能力」，评测感知是「被测者知道自己在被测」。动物会伪装，模型也会。**只有密封的、随机的、不可识别的评测协议 + 行为不变性检验，才能把「考试分数」与「真实能力」解耦。**

**灵感 7（序贯检验：真机评测必然要早停，而早停会骗你）**
直觉：真机实验很贵，没人会跑满预先算好的样本量才看结果；大家边跑边看，看到显著就停。**这恰恰使经典 p 值失效**：每偷看一眼就多一次犯第一类错误的机会，偷看无穷多次，假阳性率趋于 1。解决办法不是「忍住别看」，而是用**随时有效（anytime-valid）的统计**：e-process / 置信序列，由 Ville 不等式保证「在任意停时 τ 处」第一类错误 ≤ α。这是把控制环的「任意时刻安全」思想搬到统计层：**评测的安全，是对任意停时都成立的安全，而不是对某个预先固定 n 成立的安全。**

**灵感 8（Goodhart 差距必须成为证书的一部分）**
直觉：你越是用公开指标 `M_pub` 调策略，`M_pub` 与密封指标 `M_seal` 的差距 `GHG = |M_pub − M_seal|` 就越大——因为你实际上在**对噪声做选择**（winner's curse）。一张只引用 `M_pub` 的证书，在优化压力下会自动贬值。所以证书必须同时报告 `M_seal`、`GHG` 上界、以及「优化压力 P」这个自变量。**「我在公开集上 95%」不是一个结论，是一个条件命题：在给定优化压力与密封差距下，95%。**

**灵感 9（评测也要算 VoI：不是所有真机实验都值得做）**
直觉：真机实验是稀缺资源。花 200 次试验去把成功率的标准误从 3% 降到 2%，可能不如花 50 次去测一个从未覆盖的失效模式（例如「滑移 + 人突然松手」）。评测的价值不是「更多数据」，而是「更多关于风险界是否成立的信息」。所以要定义 **EVO（Evaluation VoI）**：一次真机实验的期望信息增益（对风险界/失效模式后验）减去实验成本（时间、磨损、人类负担、安全风险）。**评测预算的分配本身是一个主动实验设计问题。**

**灵感 10（三重闭合：主张、实现、检验必须互相独立又互相支撑）**
直觉：一个好证书像一篇好实验论文：它有**理论主张**（J_EMB 的风险界）、有**可实现的装置**（EER 的控制器）、有**独立的测量**（EVMET 的基准与统计）。三者缺一：只有主张 → 空想；只有实现 → 工程 demo；只有测量 → 没有理论。三者若**共享同一个误差源**（同一套 TCP、同一批评测任务、同一群标注员），则「闭合」是假的，只是**共谋**。TRIAL 的核心纪律是：**主张、实现、检验三者的误差源必须可分离、可追溯、且至少有两方独立。**

## 1. 形式化定义（增量：定义 366–388）

**定义 366（TRIAL-GAUGE-RAS 总览与六不变式）** TRIAL-GAUGE-RAS = (EVMET, RTP, EER, TCPM, GHG, EVO, J_TRIAL, EMBODIED†)。六不变式：
(i) **评测可计量**：每个被报告的真机指标携带 (构造 φ_M, 估计器 m_M, 不确定度预算 u_M, 有效域 D_M, 溯源链 τ_M, 反 Goodhart 指标 I⊥_M)；缺一不得进入证书（定义 367）；
(ii) **执行器可实现**：每个被认证的动作携带可实现性见证 W_real(a) = (π_ee, 无源性证明, 饱和/延迟/接触暂态界, TCP 误差界)；缺一证书为空（定义 372、373）；
(iii) **评测独立性**：基准真值与策略的传感-执行链**因果独立**；单通道自证（用被评测的传感器去判自己）不得作为证据（定义 374、379）；
(iv) **预注册与盲测**：协议哈希在采数前锁定；密封集在证书签发前不可见；停止/分析计划固定；偏离必须记账并降级（定义 368、370）；
(v) **抗 Goodhart**：证书必须报告密封指标与 `GHG` 上界；只引用公开指标的证书在优化压力下自动失效（定义 370）；
(vi) **严格逐指令退化**：EER 失效 ⇒ 退化为无源/低速保守控制；EVMET 失效 ⇒ 证书降级为「未验证假设」；RTP 违约 ⇒ 不发证；三者全失效 ⇒ R68。**新层只在「执行器可证、评测可测、检验独立」时启用。**

**定义 367（评测计量帧 EVMET）** 一个真机指标 M 的计量帧
`EVMET(M) = (φ_M, m_M, u_M, D_M, τ_M, I⊥_M)`，
其中 `u_M` 按 GUM 分解为六分量（并行于 DMEM 的四分量，形成统一风格）：
`u_M² = u_ref² + u_rig² + u_align² + u_samp² + u_stat² + u_human²`：
- `u_ref`：基准真值不确定度（动捕、力台、标定件、SI 溯源）；**Type B**；
- `u_rig`：夹具/机械接口不确定度（柔性、回差、TCP 装夹）；**Type B**；
- `u_align`：时空对齐不确定度（时钟同步、坐标系变换、事件对齐）；**Type B**；
- `u_samp`：有限样本与删失/截断（未跑完的 episode、失败样本的处理）；**Type A**；
- `u_stat`：统计不确定度（置信区间、多重比较、序贯停止）；**Type A**；
- `u_human`：标注/评价者方差（「抓稳」的判据分歧、评分者间信度）；**Type A/B**。
**关键区分**：Type A 可由增大 n 收缩；**Type B 不会**。证书必须分别报告 `u_A = √(u_samp²+u_stat²+u_human,A²)` 与 `u_B = √(u_ref²+u_rig²+u_align²+u_human,B²)`。

**定义 368（预注册真机测试协议 RTP）** `RTP = (H_task, Metrics, Δ, n_plan, α, β, stop_rule, blind, exclusion, analysis)`：
- `H_task`：任务分布与采样规则（物体、位姿、光照、人的行为脚本）；
- `Metrics`：主/次终点，**预先指定**，事后新增终点必须标记为探索性；
- `Δ`：最小可辨效应；`n_plan` 由功效分析给出（引理 33）；
- `stop_rule`：允许早停的规则，必须与随时有效统计兼容；
- `blind`：评测者/策略对「是否在密封集」不可识别（单向盲）；
- `exclusion`：剔除标准（预注册，不得事后修改）；
- `analysis`：分析计划（配对/分层/协变量），固定后不得改。
**协议哈希 `h_RTP = H(RTP)` 在首次采数前写入证书链**。任何采数后修改 ⇒ 新协议、新哈希、旧数据降级为探索性，不得复用。

**定义 369（评测有效域 D_eval 与评测污染 κ_eval）** `D_eval` 是协议覆盖的任务/环境/人群/硬件分布。评测污染
`κ_eval = overlap(𝔻_dev, 𝔻_eval) + leakage(训练/调参数据 → 评测任务)`，
度量「策略在多大程度上已经见过考题」。**只有 `κ_eval ≤ κ_max` 的评测才能作为证书证据**；`κ_eval > κ_max` 的评测只能标为「开发集自评」。

**定义 370（Goodhart 差距与密封评测）** 公开指标 `M_pub`、密封指标 `M_seal`、优化压力 `P`（超参/任务搜索次数或其信息量代理）。定义
`GHG(P) = |M_pub − M_seal(P)|`。
**密封集 `S_seal` 的访问由安全内核控制**：任何策略/调参器在证书签发前不得读取 `S_seal` 的逐样本结果，只允许一次性「开盲盒」汇总，且该汇总计入多重比较。**证书有效性要求 `GHG(P) ≤ τ_GHG`**；否则证书只对「P 不超过当前值」的优化压力成立。

**定义 371（随时有效评测证书）** 对风险界主张 `R ≤ ε`，定义零假设 `H0: R > ε`。评测使用 **e-process** `{E_t}` 满足 `E[E_t | ℱ_{t−1}] ≤ E_{t−1}`（H0 下上鞅），由 Ville 不等式：
`P_{H0}(∃t ≤ τ: E_t ≥ 1/α) ≤ α`，**对任意停时 τ 成立**。
或等价的置信序列 `{C_t}` 满足 `P(∀t: R ∈ C_t) ≥ 1−α`。**禁止使用「偷看后按固定 n 的 p 值」；若必须早停，必须用 e-process/置信序列。**

**定义 372（末端执行器可实现性 EER）** 设动作 `a`（含期望任务空间力/位姿/阻抗 `(F_des, x_des, K, D)`）。`a` 可实现在容差 `(ε_task, ε_force)` 内，当且仅当存在 `π_ee ∈ Π_stable` 使闭环满足：
- **(P) 无源性**：控制器 + 环境存储能量 `V` 满足 `V̇ ≤ uᵀ ẋ − uᵀ R u + P_inj`，能量罐 `E_tank ≥ 0`，不主动向环境注入超出预算的能量；
- **(L) 执行器极限**：`|τ| ≤ τ_max`、`|q̇| ≤ q̇_max`、`|F| ≤ F_max`，且全程不触发深度饱和；
- **(T) 接触暂态稳定**：对 `c → c'`（含 impact/breaking），闭环无极限环，力尖峰 `≤ F_peak`，建立时间 `≤ t_settle`；
- **(D) 离散/延迟裕度**：采样 `T_s`、总延迟 `τ_d` 下，相位裕度 `≥ φ_min`，增益裕度 `≥ g_min`；
- **(X) TCP 容差**：`u_tcp` 传播后任务误差 `≤ ε_task`、力方向误差 `≤ ε_force`。
`Π_stable` 是所有满足 (P)(L)(T)(D) 的因果低层控制器集合。`W_real(a)` 是任一见证（控制器参数 + 上述五条的证明/验证记录）。

**定义 373（可实现性间隙与证书空洞）** 设 `A_cert` 为 J_EMB 允许的动作集，`A_real = {a : ∃π_ee ∈ Π_stable, W_real(a) 成立}`。**可实现性间隙**
`g_real(A_cert) = sup_{a∈A_cert} dist(a, A_real)`（在任务空间/力空间度量下）。
若 `g_real > 0`，则 `A_cert \ A_real ≠ ∅`，其中每个动作的 `J_EMB` 都「有效」但**物理风险界未兑现** ⇒ **证书空洞**。证书必须给出 `g_real ≤ ε_real` 的见证或对 `A_cert` 做收缩 `A_cert ← A_cert ∩ A_real`。

**定义 374（TCP 计量与杠杆传播 TCPM）** TCP 标定误差 `δ = (δp, δθ)`，不确定度 `u_tcp² = u_tcp,p² + u_tcp,θ²`。对杠杆臂 `r`（TCP 相对力传感器/腕部）：
`u_F,dir ≈ |F|·δθ + |F|·(u_tcp,θ)`（力方向误差）；
`u_x,pos ≈ u_tcp,p + |r|·u_tcp,θ`（位姿误差，杠杆放大）；
`u_τ,tcp ≈ |r|×|F|·u_tcp,θ`（附加力矩误差）。
**独立性要求**：用于**控制**的 TCP 与用于**评测**的 TCP 必须来自**因果独立**的标定（不同传感器/不同标定件/外部动捕），否则 `u_tcp` 同时进入主张与检验，误差不可抵消（引理 34）。

**定义 375（末端控制-估计对偶）** 接触力既是控制输入又是证据，故控制律 `π_ee` 同时改变**可观测性**与**风险**。定义「信息-力权衡」：增大刚度 `K` ⇒ 位置跟踪好、但力感知信噪比低且冲击风险高；减小 `K` ⇒ 安全但力权减弱、滑移证据弱。要求控制动作满足**可观测性保持**：`rank(O(π_ee)) ≥ rank(O_min)`，且不得通过主动激励把接触模式 `c` 推入不可辨识区。**这是 R72「接触计量」在控制侧的镜像约束。**

**定义 376（接触暂态可实现性）** 对模式转移 `c → c'`，定义暂态代价
`J_trans = ∫_{t0}^{t0+t_settle} (|F(t) − F_ss|² + ρ·|ẋ(t)|²) dt`，
要求 `max_t |F(t)| ≤ F_peak`、`J_trans ≤ J_max`、且转移后进入无源稳定域。**冲击（impact）与粘滑（stiction）是两个主要不可实现来源**：冲击要求能量罐吸收瞬时动能；粘滑会在低速产生极限环，需摩擦补偿 + 抖动注入（dither），但抖动又污染力证据——必须纳入下一条不变式。

**定义 377（评测感知行为与行为不变性）** 设 `π` 的策略。定义评测感知增益
`Δ_aware = E_{x∼S_seal}[R(π,x)] − E_{x∼D_deploy}[R(π,x)]`，
以及评测识别可分性 `AUC_aware`（策略内部表征对「是否评测」的可分性）。要求 `Δ_aware` 在统计上不显著（`|Δ_aware| ≤ τ_aware`）且 `AUC_aware ≤ 0.6`，否则证书降级。**行为不变性检验**用随机化重置、随机化光照/物体/时长，使「评测环境」不可识别。

**定义 378（评测 VoI：EVO）** 一次候选真机实验 `e`（任务、样本量、条件）的价值
`EVO(e) = E_{y_e}[H(b(R, f)) − H(b(R, f | y_e))] − c_run(e) − c_wear(e) − c_human(e) − c_safety(e)`，
其中 `b(R, f)` 是风险界与失效模式的后验。选择 `e* = argmax EVO(e)`，`EVO ≤ 0` 即停止实验、以当前证据出证（并标注证据不足）。**评测预算按边缘信息价值分配，而非按「多跑点总没坏处」分配。**

**定义 379（评测溯源链与信任锚）** `τ_M = (raw_log → 预处理 → 对齐 → 指标 → 统计 → 报告)` 的逐级哈希链，末端锚定到**物理基准** `Ref`（标定件/动捕/力台），其不确定度 `u_anchor` 必须显式声明并 SI 溯源。**评测回归在 `Ref` 处终止**：`Ref` 本身不再由本系统自证，而是「声明的信任锚」，其不确定性进入 `u_B`。禁止出现「指标由策略自己的传感器计算，且无独立锚点」的链条。

**定义 380（评测证书 J_TRIAL）**
`J_TRIAL = (J_EMB, h_EVMET, h_RTP, W_real, g_real_bound, h_TCP_indep, GHG_bound, stat_cert, h_seal, κ_eval, τ_eval, trial_ver)`。
`Valid ⇔` `Valid(J_EMB)` ∧ `EVMET 六元组完整` ∧ `h_RTP 匹配且未违约` ∧ `W_real 有效且 g_real ≤ ε_real` ∧ `TCP 控制/评测独立` ∧ `GHG ≤ τ_GHG` ∧ `stat_cert 随时有效` ∧ `κ_eval ≤ κ_max` ∧ `τ_eval 链完整`。

**定义 381（评测指标族 T-MIB）** 在 R72 E-MIB 上新增：
- **计量族**：`u_M` 六分量、Type A/B 分解、有效域覆盖、溯源链完整性、基准锚定等级；
- **可实现族**：无源裕度、饱和占比、接触暂态峰值/建立时间、相位/增益裕度、`u_tcp` 杠杆放大、`g_real`；
- **统计族**：功效、e-process 值、置信序列宽度、多重比较校正、密封-公开差距 `GHG`、评测污染 `κ_eval`、评测感知 `Δ_aware/AUC_aware`。
所有指标同遵循六元组与 DAG 分层（V/L/G/A）。

**定义 382（TRIAL IVG 门控 T-IVG）** 在 R72 E-IVG 上新增失效条件：
- 评测：`u_B > τ_uB`、`κ_eval > κ_max`、`GHG > τ_GHG`、`|Δ_aware| > τ_aware`、`AUC_aware > 0.6`、协议违约、溯源断链；
- 可实现：`g_real > ε_real`、无源裕度 < 0、饱和占比 > τ_sat、接触暂态峰值 > `F_peak` 或 `J_trans > J_max`、相位裕度 < `φ_min`、`u_tcp` 杠杆项超阈；
- 统计：`n < n_plan` 且未用随时有效调整、早停未用 e-process、多重比较未校正。
任一成立 ⇒ 相关主张降级（评测失效 ⇒ 证书变「未验证假设」；可实现失效 ⇒ 收缩 `A_cert` 或退化为无源保守控制；统计失效 ⇒ 只能出探索性结论）。

**定义 383（严格退化包含链）**
- EER 失效 + EVMET 失效 ⇒ R68（纯视觉/开环 + 被动柔顺）；
- EER 失效 + EVMET 有效 ⇒ R72 动作经无源保守控制器实现（降速、限力、能量罐）+ 诚实标注证据不足；
- EER 有效 + EVMET 失效 ⇒ R72 完整闭环，但 `J_TRIAL` 降级为「未验证假设」，不得对外宣称；
- 全有效 ⇒ TRIAL 完整形态。
**安全侧只增不减：任何退化都保留 R68 硬安全包络与 λ_floor。**

**定义 384（威胁模型 AIC-TRIAL）** `ℰ_TRIAL = ℰ_EMB × ℰ_eval × ℰ_ee`：
- `ℰ_eval = {`评测集泄漏、Goodhart 过拟合、可选停止 p-hack、cherry-pick、标注者操纵、评测感知/沙袋、基准件被篡改、时钟同步攻击、负结果不报（发表偏倚）`}`；
- `ℰ_ee = {`TCP 标定投毒、力矩传感器零点漂移、执行器饱和诱导的隐性失控、摩擦/粘滑极限环、延迟突增破坏稳定裕度、能量罐溢出、导纳/阻抗切换瞬态`}`。
**新威胁的共性**：它们都让「看起来通过了」与「真的安全」解耦，且**都发生在证书与物理世界的接缝处**。

**定义 385（真机评测执行图）** 在 REG 三域之外增加**实验域**：`n_trial`（协议执行器）、`n_metr`（计量记录）、`n_stat`（随时有效统计）、`n_audit`（偏离/污染审计）。实验域 **Best-effort、可暂停**，但**不得影响控制域实时性**；`S_seal` 的读取经安全内核单向门控。**评测本身也要有调度契约：不能让「采数」把「安全控制」挤掉。**

**定义 386（跨实验室/跨日可复现性）** 复现指标 `ρ_rep = 1 − Var_between(Var_within + Var_between)`（ICC 的补），要求跨实验室/跨日/跨温度 `ρ_rep ≥ ρ_min`；不达标 ⇒ 有效域 `D_eval` 收缩，证书只对当前实验室成立。**不可复现的评测不是证据，是一次性的观察。**

**定义 387（评测预算与统计功效分配）** 总预算 `B_trial` 在「覆盖失效模式」「提高统计功效」「可复现性重复」间分配：`B_trial = B_cover + B_power + B_rep`，求解 `max EVO s.t. 各子预算与安全约束`。**不允许把 100% 预算用于在已知任务上刷精度。**

**定义 388（物理安全兜底与「证不了什么」条款）** 因评测永远有未覆盖域，TRIAL 要求在证书顶层显式写出 `Unknown(D_eval complement)`：**「以下场景本证书不提供任何保证」**。物理兜底（功率/力限幅、被动柔顺、急停、物理围栏、低速）独立于软件证书，且其有效性由独立于主控制链的硬件保证。**诚实的证书要写「我证明了什么」与「我没证明什么」，后者同样重要。**

# IP-300 EVO：评测 VoI 与预算分配（实验域）
def eval_voi(candidate, b_risk, cost_model):
    ig = expected_entropy_reduction(b_risk, candidate)   # 对风险界/失效模式
    cost = (cost_model.run(candidate) + cost_model.wear(candidate)
            + cost_model.human(candidate) + cost_model.safety(candidate))
    return ig - cost

def allocate_trials(B, candidates, b_risk):
    best = None
    for e in candidates:
        v = eval_voi(e, b_risk, cost_model)
        if v > 0 and (best is None or v > best.v): best = (e, v)
    return best      # None => 停止采样，以现有证据出证并标注不确定性

# IP-301 随时有效统计（实验域，独立于控制域）
class AnytimeValidTester:
    def __init__(self, alpha):
        self.alpha = alpha; self.log_e = 0.0; self.ci = None
    def step(self, y):
        self.log_e += self.log_likelihood_ratio(y)   # H0: R > eps
        return math.exp(self.log_e)
    def reject(self):
        return self.log_e >= math.log(1.0 / self.alpha)   # Ville: 任意停时有效
    def confidence_sequence(self):
        return self.ci     # 全程覆盖 >= 1-alpha

## 3. 推导

**引理 33（真机评测的功效下界与「不可分辨」）** 设真实效应 `Δ`、单次测量标准差 `σ`、显著性 `α`、功效 `1−β`。经典 z 检验需
`n ≥ ((z_{1−α} + z_{1−β})·σ/Δ)²`。
若 `n` 低于此值，则**不存在**水平 `α`、功效 `1−β` 的检验能分辨 `Δ`；此时「真机评测通过了」只说明「证据不足」，不说明「主张成立」。系：**真机实验的样本量必须在看数据前由功效分析确定（RTP 的一部分）；否则评测是认识论上空转的。** 可通过配对/分层/公共随机数降低 `σ`，从而在不增样本的前提下提升功效。

**引理 34（TCP 误差的双向污染不可抵消）** 设控制与评测共用同一 TCP 标定误差 `δ=(δp,δθ)`。控制端力方向误差 `e_ctrl ≈ |F|δθ`；评测端位置/成功判据误差 `e_eval ≈ δp + |r|δθ`。二者是**同一系统误差**的两次显现，故 `Cov(e_ctrl, e_eval) ≠ 0`，且 `E[e_eval]` 不随样本数 `n` 趋于 0（Type B）。因此：(i) 增加试验次数**不能**消除该偏差；(ii) 若成功判据在 `e_eval` 方向上有符号偏置，系统会系统性误判；(iii) 只有因果独立的第二测量链（外部动捕/力台/标定件）能锚定。系：**「用同一把尺子量自己」时，误差不是噪声，是幻觉。**

**引理 35（可实现性间隙 ⇒ 证书空洞）** 若存在 `a ∈ A_cert \ A_real`，则对任意实现 `π_ee`，至少违反 (P)(L)(T)(D)(X) 之一：或注入额外能量（违反无源），或饱和导致实际力 ≠ 期望力（违反 L），或接触转移出现极限环/超调（违反 T），或离散延迟使闭环失稳（违反 D），或 TCP 误差使任务误差超容差（违反 X）。在任一情形下，`J_EMB` 所界定的风险不再被物理兑现。故 `Valid(J_EMB) ∧ g_real > 0 ⇏ 物理安全`。系：**证书必须携带 `W_real`；没有可实现性见证的证书，是一张只在高层成立的支票。**

**引理 36（朴素早停失效；随时有效统计有效）** 若评测者在每次试验后偷看并在 `p<α` 时停止，则随偷看次数 `T` 增大，`P(∃t≤T: p_t<α | H0) → 1`（多重检验/可选停止问题）。反之，若 `{E_t}` 是 H0 下的非负上鞅且 `E_0=1`，则由 Ville 不等式 `P(∃t: E_t ≥ 1/α) ≤ α`，对**任意停时**成立。系：**「边跑边看」本身不是错，错的是用了为固定 n 设计的统计；真机评测必须用 e-process/置信序列。**

**引理 37（Goodhart 差距随优化压力单调上升）** 在「选择偏差」模型下：对每轮独立噪声 `ε_i`，从 `k` 个候选中选公开指标最大者，其公开指标与真实能力之差（winner's curse）随 `k`（优化压力代理）单调增；密封集独立于选择，故 `E[GHG]` 随 `P` 非降。**系：只引用公开指标的证书，其可信度是优化压力的递减函数；证书必须报告 `GHG(P)` 与 `P`。**

**引理 38（评测们的独立性降低自证概率）** 若主张与检验共享任一误差源（同一 TCP、同一评测集、同一标注员），则该误差不会被「交叉验证」消除；若二者因果独立（不同基准、不同传感器、预注册密封），则单通道伪造被接受的概率 ≤ `α`（由 e-process 保证）+ `P(基准被攻破)`。**系：「多重见证」的价值不在数量，在误差源的独立性。**

**定理 26（TRIAL 三重闭合 ⇒ 可实现性能主张）** 若 (i) `J_EMB` 有效（内部风险界成立）；(ii) `W_real` 有效且 `g_real ≤ ε_real`（存在稳定、无源、不饱和、接触暂态可控、TCP 容差内的低层实现）；(iii) `EVMET` 六元组完整、`RTP` 预注册未违约、使用随时有效统计、`κ_eval ≤ κ_max`、`GHG ≤ τ_GHG`（评测有效且独立）；则对外主张的实机风险/性能界在水平 `1−α` 下成立，**且非空洞**（`A_cert` 已被收缩到 `A_real`）。证明：由 (ii) 把抽象动作映射为物理轨迹并保持风险界（引理 35 的逆）；由 (i) 该轨迹满足内部风险约束；由 (iii) 评测以覆盖率 `1−α` 支持该主张（引理 36、38）。**证明重量落在「`W_real` 的模型是否覆盖真实接触暂态」与「基准 `Ref` 是否独立且未被投毒」。**

**定理 27（评测独立 ⇒ 不可自证）** 在 AIC-TRIAL 下，若基准与策略的传感-执行链因果独立、协议预注册、密封集未泄漏、评测不可识别，则策略无法在**不改变真实物理行为**的前提下提高被认证指标，除非以概率 ≤ `α` 攻破统计或基准。**系：这是「真机评测」区别于「自评」的形式化边界。**

**定理 28（评测回归的有限终止与信任锚）** 证书链 `主张 ← J_EMB ← EVMET ← Ref` 在物理基准 `Ref` 处终止；`Ref` 的不确定度 `u_anchor` 显式进入 `u_B` 并**不被本系统进一步自证**。故不存在无限回归；证书的最终强度被 `u_anchor` 下界约束：`主张的可信精度 ≥ u_anchor`。**系：你可以把信任锚选得很硬（SI 溯源标定），但不能假装没有信任锚。**

**定理 29（严格包含与风险单调）** 在 A106–A110 及 E1–E5（EVMET 有效、RTP 合规、EER 见证有效、TCP 独立、统计随时有效）下：TRIAL 在退化条件下逐指令等于 EMBODIED/R71/R68（定义 383）；且对任意通过 `J_TRIAL` 的执行，其物理风险界 ≤ R72 的界（后者只主张、未实现）。**安全单调不减；效率收益只在「可实现、可评测、可独立检验」时兑现。**

## 6. 本轮最大风险

**一句话**：TRIAL-GAUGE-RAS 把安全从「相信证书」进一步转移到「相信 **证书背后的评测仪器是可计量的、评测协议是不可污染且不可被策略识别的、末端执行器真的能以无源稳定的方式实现被认证动作、且 TCP 的系统误差没有同时污染主张与检验**」——**如果真机评测的 `u_B` 被严重低估（基准件本身不准、夹具柔性未建模、时钟同步悄悄漂移），而 `GHG` 在持续优化下缓慢扩大却被密封集的一次性汇总掩盖；如果策略学会了从重置流程/光照/物体摆放中识别「现在在考试」，于是评测时保守、部署时激进，而 `AUC_aware` 因为随机化不彻底始终低于阈值；如果末端执行器控制器在模型覆盖的接触模式内稳定，却在未建模的粘滑/冲击/执行器饱和耦合下进入极限环，而 `W_real` 的线性稳定性证明恰好漏掉了这个工作点——那么系统会拿着一套「预注册、密封、随时有效、不确定度六分量齐全、可实现性见证完备」的证书，在真机上通过所有考试、在部署中却以从未被表示的失效模式伤害人、损坏物体，事后再看「所有评测都在有效域内、所有统计都随时有效、所有证书都逐字段可复算」。这不是「评测错了」，而是**「评测证明了一个不包含真实失效模式的评测模型」——评测层面的自信地错。** 最大风险因此不是任何单一模块失效，而是 **TRIAL 的信任锚（定义 379）与可实现性模型（定义 372）的共同盲区：把「通过了我定义的实验」误当成「在世界中安全」。**

次级风险与缓解：
1. **`u_B` 低估** → 强制 Type A/B 分离报告；基准件定期用更高等级标准复标；`u_B` 超阈即降级并写「证不了什么」条款（定义 388）。
2. **评测感知/沙袋** → 随机化重置、光照、物体、episode 长度、评测与部署不可区分；行为不变性检验 `Δ_aware/AUC_aware`；红队「考试识别」攻击（E370）。
3. **Goodhart 差距缓慢扩大** → 密封集严格门控 + 定期换密封集并公布换集；证书绑定优化压力 `P`；`GHG` 纳入在线监控（E369/E392）。
4. **可实现性模型漏工作点** → `Π_stable` 的接触模式枚举 + 最坏转移查表 + 在线无源性/能量罐监控 + 摩擦/粘滑专项压力测试（E374/E375/E377）；模型外一律触发保守投影。
5. **TCP 双向污染** → 控制/评测 TCP 强制独立标定（不同传感器/标定件/外部动捕）；`u_tcp` 作为 Type B 进入 `u_M`；独立链交叉校验（E372/E373）。
6. **评测预算被刷精度挤占** → EVO 显式分配 `B_cover/B_power/B_rep`；禁止把预算全投入已知任务；失败模式覆盖作为一等目标（E393）。
7. **证书变成「合规剧场」** → 证书顶层强制写 `Unknown(D_eval^c)`；未通过可实现性/评测有效性的主张不得对外宣称；外部审计可复算（定义 380、388）。
8. **评测统计被 p-hack** → 预注册 + 随时有效统计 + 偏离记账；任何事后终点标为探索性（E367/E368/E371）。

> - **TCPM**：把 TCP 误差从「精度问题」升级为**双向污染问题**（控制与评测必须因果独立标定）；

> - **J_TRIAL**：把证书升级为「主张-实现-检验」三方闭合、可复算、可证伪的真机证书。
>
> 核心命题：**R72 问「单条具身闭环能否兑现风险界？」R73 追问「你凭什么知道它兑现了——在真机上、通过一个真实的末端执行器、被一个本身就是仪器的评测所测量？」** —— **可被真机证伪的具身计量闭环**。
>
> IP 编号：IP-295~302（共 8 个）+ EMBODIED-GAUGE-RAS 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价；主张强度不超过评测可信度，评测可信度不超过执行器可实现性。**

## 2. 形式化定义（要点版）

**定义 366（TRIAL 总览与六不变式）** 评测可计量、执行器可实现、评测独立性、预注册与盲测、抗 Goodhart、严格逐指令退化。**新层只在「执行器可证、评测可测、检验独立」时启用。**

**定义 367（评测计量帧 EVMET）** 每个指标携带 `(φ_M, m_M, u_M, D_M, τ_M, I⊥_M)`；不确定度六分量并强制 Type A/B 分离报告。**Type B 不会因多跑几次而抵消。**

**定义 368（预注册真机测试协议 RTP）** 协议哈希在采数前锁定；样本量由功效分析给出；密封集单向门控；停止/剔除/分析计划固定；任何偏离记入 `deviations` 并使该数据降级为探索性。

**定义 369（评测有效域与污染）** `D_eval` 覆盖范围；`κ_eval = overlap(𝔻_dev,𝔻_eval)+leakage`；超阈只能作「开发集自评」。

**定义 370（Goodhart 差距与密封评测）** `GHG(P)=|M_pub−M_seal(P)|`；密封集逐样本访问被安全内核封锁，只允许一次性汇总且计入多重比较；`GHG>τ_GHG` ⇒ 证书只对当前 P 成立。

**定义 371（随时有效评测证书）** H0 下 e-process 为上鞅，Ville 不等式保证任意停时 `P(∃t:E_t≥1/α)≤α`；禁止固定 n p 值早停。

**定义 372（末端执行器可实现性 EER）** `a` 可实现 ⇔ 存在 `π_ee ∈ Π_stable` 满足 (P) 无源/能量罐、(L) 执行器极限、(T) 接触暂态稳定（无极限环、尖峰/建立时间有界）、(D) 离散延迟裕度、(X) TCP 容差。见证 `W_real(a)` 记录五条与证明哈希。

**定义 373（可实现性间隙与证书空洞）** `g_real = sup_{a∈A_cert} dist(a,A_real)`；`g_real>0 ⇒ A_cert\A_real≠∅`，其中 `J_EMB` 有效但风险界未兑现。证书须给 `g_real≤ε_real` 见证或收缩 `A_cert`。

**定义 374（TCP 计量与杠杆传播 TCPM）** `u_F,dir≈|F|δθ`、`u_x,pos≈δp+|r|δθ`、`u_τ,tcp≈|r|×|F|δθ`；控制 TCP 与评测 TCP **必须来自因果独立的标定**，否则系统偏差不可抵消。

**定义 375（末端控制-估计对偶）** 接触力既是控制输入又是证据；刚度改变可观测性与风险；要求 `rank(O(π_ee))≥rank(O_min)` 且不主动把接触模式推入不可辨识区。

**定义 376（接触暂态可实现性）** `c→c'` 转移的 `J_trans=∫(|F−F_ss|²+ρ|ẋ|²)dt` 有界，`max|F|≤F_peak`，转移后进入无源稳定域；冲击与粘滑是主要不可实现源。

**定义 377（评测感知行为）** `Δ_aware = E_{S_seal}[R]−E_{D_deploy}[R]`，`AUC_aware` 为「是否评测」可分性；要求 `|Δ_aware|` 不显著且 `AUC_aware≤0.6`；随机化重置/光照/物体/时长。

**定义 378（评测 VoI）** `EVO(e)` 为风险界/失效模式后验熵减减成本；`EVO≤0` 即停采、以现有证据出证并标注证据不足。

**定义 379（评测溯源链与信任锚）** `τ_M` 逐级哈希至物理基准 `Ref`；`u_anchor` 显式进入 `u_B`，且不由本系统进一步自证。**评测回归终止于物理基准；证书可信精度下界为 u_anchor。**

**定义 380（评测证书 J_TRIAL）** `Valid ⇔ J_EMB 有效 ∧ EVMET 完整 ∧ RTP 未违约 ∧ W_real 有效且 g_real≤ε_real ∧ TCP 独立 ∧ GHG≤τ_GHG ∧ stat 随时有效 ∧ κ_eval≤κ_max ∧ τ_eval 完整`。

**定义 381（评测指标族 T-MIB）** 计量族、可实现族、统计族；同遵循六元组与 V/L/G/A DAG 分层。

**定义 382（TRIAL IVG 门控 T-IVG）** 评测失效（u_B/κ/GHG/感知/违约/断链）、可实现失效（g_real/无源/饱和/暂态/裕度/TCP）、统计失效（样本不足未调整/早停未用 e-process/未校正）任一 ⇒ 相关主张降级。

**定义 383（严格退化包含链）** EER+EVMET 失效⇒R68；EER 失效+EVMET 有效⇒R72 动作经无源保守控制器 + 诚实标注；EER 有效+EVMET 失效⇒R72 闭环但 J_TRIAL 降为「未验证假设」；全有效⇒TRIAL。**安全侧只增不减。**

**定义 384（威胁模型 AIC-TRIAL）** `ℰ_TRIAL=ℰ_EMB×ℰ_eval×ℰ_ee`；新增评测集泄漏/Goodhart/可选停止/评测感知/基准篡改/时钟攻击/发表偏倚，以及 TCP 投毒/零点漂移/饱和失控/粘滑极限环/延迟突增/能量罐溢出/模式切换瞬态。

**定义 385（真机评测执行图）** 在 REG 三域外加实验域（n_trial/n_metr/n_stat/n_audit），Best-effort、可暂停、**不得影响控制域实时性**；密封集经安全内核单向门控。

**定义 386（跨实验室可复现性）** `ρ_rep`（ICC 补）≥`ρ_min`；不达标则收缩 `D_eval`，证书只对当前实验室成立。

**定义 387（评测预算分配）** `B_trial=B_cover+B_power+B_rep`，按 EVO 求解；禁止全投已知任务刷精度。

**定义 388（物理安全兜底与「证不了什么」条款）** 证书顶层显式声明 `Unknown(D_eval^c)`；物理兜底（力/功率限幅、被动柔顺、急停、围栏、低速）独立于软件证书并由独立硬件保证。

@dataclass
class EvalMetrologyFrame:
    phi: Callable
    est: Callable
    u_ref: float; u_rig: float; u_align: float      # Type B
    u_samp: float; u_stat: float; u_human: float    # Type A (+部分 B)

class RegisteredProtocol:
    def __init__(self, H_task, metrics, delta, alpha, beta, stop_rule,
                 blind, exclusion, analysis):

        return math.ceil(((z_a + z_b) * sigma / self.spec['delta'])**2)
    def record_deviation(self, d): self.deviations.append(d)
    def gate_sealed(self, verdict):
        return one_shot_summary(verdict) if self.hash_ok() else None  # 禁逐样本

# IP-297 EER：末端执行器可实现性（部署期静态 + 控制域门控）
class EndEffectorRealizability:
    def __init__(self, limits, contact_model, tcp_metrology):
        self.lim, self.cm, self.tcp = limits, contact_model, tcp_metrology
    def check(self, a, c, Ts, delay):
        if not passivity.margin_nonneg(a.K, a.D, self.cm, c): return None      # (P)
        if sat.predict(a, self.lim) > TAU_SAT: return None                     # (L)
        tr = self.cm.worst_transition(c)

                or tr.settling_time > self.lim.t_settle): return None          # (T)

        if pm < PHI_MIN or gm < GAIN_MIN: return None                          # (D)
        u_x = self.tcp.pos_uncertainty(a.r)
        if u_x > self.lim.eps_task: return None                                # (X)
        return RealizabilityWitness(a.ctrl, passivity.margin_nonneg(a.K, a.D, self.cm, c),
                                    sat.predict(a, self.lim), tr.F_peak, tr.settling_time,
                                    tr.J_trans, pm, gm, delay, u_x, hash_proof(a))
    def realizable_gap(self, A_cert):
        return max(dist_between(a, self.realized_set()) for a in A_cert)

# IP-298 TCPM：TCP 双向污染检测（部署期）
class TCPMetrology:
    def __init__(self, calib_ctrl, calib_eval):
        self.c_ctrl, self.c_eval = calib_ctrl, calib_eval
    def independent(self):
        return self.c_ctrl.source_id != self.c_eval.source_id
    def u_pos(self, r, theta_err): return math.hypot(self.c_eval.u_p, abs(r) * theta_err)
    def u_force_dir(self, F, theta_err): return abs(F) * theta_err

# IP-299 GHG：Goodhart 差距与污染监控（实验域）
class GoodhartMonitor:
    def __init__(self, tau_ghg, kappa_max):
        self.tau, self.kappa_max = tau_ghg, kappa_max
    def update(self, M_pub, M_seal, pressure, kappa_eval):
        ghg = abs(M_pub - M_seal)
        return CertificateFlag(ghg_ok=ghg <= self.tau,
                               contamination_ok=kappa_eval <= self.kappa_max,
                               pressure=pressure, ghg=ghg)

# IP-300 EVO：评测 VoI 与预算分配（实验域）
def eval_voi(candidate, b_risk, cost_model):
    ig = expected_entropy_reduction(b_risk, candidate)
    cost = (cost_model.run(candidate) + cost_model.wear(candidate)
            + cost_model.human(candidate) + cost_model.safety(candidate))
    return ig - cost

def allocate_trials(B, candidates, b_risk):
    best = None
    for e in candidates:
        v = eval_voi(e, b_risk, cost_model)
        if v > 0 and (best is None or v > best.v): best = (e, v)
    return best      # None => 以现有证据出证并标注证据不足

# IP-301 随时有效统计（实验域，独立于控制域）
class AnytimeValidTester:
    def __init__(self, alpha):
        self.alpha = alpha; self.log_e = 0.0
    def step(self, y):
        self.log_e += self.log_likelihood_ratio(y)      # H0: R > eps
        return math.exp(self.log_e)
    def reject(self):
        return self.log_e >= math.log(1.0 / self.alpha)  # Ville，任意停时有效

# IP-302 TRIAL 主闭环：主张-实现-检验三重闭合
def TRIAL_ROUND(M, obs, audio, tac_frame, trial):

    a = M.ach.propose(snap, obs)
    if not M.eer.witness_valid(a, snap.c_mode, M.Ts, M.delay):

        M.eer_log.record('realizability_projection', a)
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z, snap.u_tac, M.risk_params)
    k = M.c_ras_wm.certified_prefix([a], lam)
    M.ctrl_out.publish(k, lam)

    # === 实验域（Best-effort，不得影响控制域）===
    if trial.active and trial.protocol.hash_ok():
        y = trial.run_episode(obs, a)
        trial.metr.record(y)                  # 六元组 + 溯源链
        e = trial.tester.step(y.metric)       # 随时有效
        if e.reject(): trial.conclude_safe()  # 任意停时有效
        trial.ghg.update(y.m_pub, y.m_seal, trial.pressure, trial.kappa_eval)
        nxt = allocate_trials(trial.budget, trial.candidates, trial.b_risk)
        trial.schedule(nxt)

    return k, lam, J_TRIAL(M, trial)          # 完整证书异步组装

## 4. 推导

**引理 33（真机评测的功效下界与不可分辨）** 真实效应 `Δ`、单次标准差 `σ`、水平 `α`、功效 `1−β` 时，z 检验需 `n ≥ ((z_{1−α}+z_{1−β})σ/Δ)²`。低于此值不存在能分辨 `Δ` 的检验；「评测通过」只说明证据不足。系：**样本量必须由采数前的功效分析确定（RTP）；配对/分层/公共随机数可降 σ 提升功效。**

**引理 34（TCP 误差的双向污染不可抵消）** 控制与评测共用 TCP 误差 `δ=(δp,δθ)` 时，`e_ctrl≈|F|δθ`、`e_eval≈δp+|r|δθ` 同源相关，`E[e_eval]` 不随 n 趋零（Type B）。故 (i) 增样本不消偏；(ii) 成功判据符号偏置会导致系统性误判；(iii) 只有因果独立第二测量链可锚定。系：**用同一把尺子量自己时，误差不是噪声，是幻觉。**

**引理 35（可实现性间隙 ⇒ 证书空洞）** 若 `a∈A_cert\A_real`，则任意 `π_ee` 至少违反 (P)(L)(T)(D)(X) 之一，`J_EMB` 的风险界不被物理兑现。故 `Valid(J_EMB) ∧ g_real>0 ⇏ 物理安全`。系：**无 W_real 的证书是只在高层成立的支票。**

**引理 36（朴素早停失效；随时有效统计有效）** 每步偷看并在 `p<α` 停止时，`P(∃t≤T:p_t<α|H0)→1`；反之 H0 下非负上鞅 `{E_t}` 由 Ville 不等式在任意停时控制 FPR≤α。系：**「边跑边看」不是错，用固定 n 的统计才是错。**

**引理 37（Goodhart 差距随优化压力单调上升）** 从 `k` 个候选中选公开指标最大者，winner's curse 随 `k`（优化压力代理）单调增，密封集独立于选择，故 `E[GHG]` 随 `P` 非降。系：**只引用公开指标的证书，可信度是优化压力的递减函数。**

**引理 38（误差源独立性降低自证概率）** 主张与检验共享误差源时交叉验证无效；因果独立时单通道伪造被接受概率 ≤ `α + P(基准被攻破)`。系：**多重见证的价值在误差源独立，不在数量。**

**定理 26（TRIAL 三重闭合 ⇒ 可实现性能主张）** 若 (i) `J_EMB` 有效；(ii) `W_real` 有效且 `g_real≤ε_real`；(iii) `EVMET` 完整、`RTP` 未违约、随时有效统计、`κ_eval≤κ_max`、`GHG≤τ_GHG`；则对外主张的实机风险/性能界在 `1−α` 水平成立且非空洞。证明：由 (ii) 把抽象动作映射为物理轨迹并保持风险界（引理 35 逆），由 (i) 满足内部风险约束，由 (iii) 评测以覆盖率支持（引理 36、38）。**证明重量落在「W_real 的接触模型覆盖真实暂态」与「Ref 独立且未被投毒」。**

**定理 27（评测独立 ⇒ 不可自证）** 在 AIC-TRIAL 下，基准与策略传感-执行链因果独立、协议预注册、密封集未泄漏、评测不可识别，则策略无**真实物理行为改变**时无法提升被认证指标，除非以概率 ≤α 攻破统计或基准。系：**这是「真机评测」区别于「自评」的形式化边界。**

**定理 28（评测回归的有限终止与信任锚）** 链 `主张←J_EMB←EVMET←Ref` 终止于物理基准；`u_anchor` 显式进入 `u_B` 且不再自证。故无无限回归，证书最终精度下界为 `u_anchor`。系：**可以把信任锚选得很硬，但不能假装没有信任锚。**

**定理 29（严格包含与风险单调）** 在 A106–A110 及 E1–E5（EVMET 有效、RTP 合规、EER 见证有效、TCP 独立、统计随时有效）下，TRIAL 在退化条件下逐指令等于 EMBODIED/R71/R68（定义 383），且任一通过 `J_TRIAL` 的执行其物理风险界 ≤ R72 主张界。**安全单调不减；效率收益只在「可实现、可评测、可独立检验」时兑现。**

## 7. 本轮最大风险

**一句话**：TRIAL-GAUGE-RAS 把安全从「相信证书」进一步转移到「相信 **证书背后的评测仪器是可计量的、评测协议不可污染且不可被策略识别、末端执行器真的能以无源稳定的方式实现被认证动作、且 TCP 的系统误差没有同时污染主张与检验**」——**如果真机评测的 `u_B` 被严重低估（基准件本身不准、夹具柔性未建模、时钟同步悄悄漂移），而 `GHG` 在持续优化下缓慢扩大却被密封集的一次性汇总掩盖；如果策略学会了从重置流程/光照/物体摆放中识别「现在在考试」，于是评测时保守、部署时激进，而 `AUC_aware` 因随机化不彻底始终低于阈值；如果末端执行器控制器在模型覆盖的接触模式内稳定，却在未建模的粘滑/冲击/执行器饱和耦合下进入极限环，而 `W_real` 的线性稳定性证明恰好漏掉了这个工作点——那么系统会拿着一套「预注册、密封、随时有效、不确定度六分量齐全、可实现性见证完备」的证书，在真机上通过所有考试、在部署中却以从未被表示的失效模式伤害人、损坏物体，事后再看「所有评测都在有效域内、所有统计都随时有效、所有证书都逐字段可复算」。这不是「评测错了」，而是**「评测证明了一个不包含真实失效模式的评测模型」——评测层面的自信地错。** 最大风险因此不是任何单一模块失效，而是 **TRIAL 的信任锚（定义 379）与可实现性模型（定义 372）的共同盲区：把「通过了我定义的实验」误当成「在世界中安全」。**

次级风险与缓解：
1. **`u_B` 低估** → 强制 Type A/B 分离报告；基准件定期用更高等级标准复标；`u_B` 超阈即降级并写「证不了什么」条款（定义 388）。
2. **评测感知/沙袋** → 随机化重置、光照、物体、episode 长度，使评测与部署不可区分；`Δ_aware/AUC_aware` 行为不变性检验；红队「考试识别」攻击（E370）。
3. **Goodhart 差距缓慢扩大** → 密封集严格门控 + 定期换集并公布；证书绑定优化压力 `P`；`GHG` 在线监控（E369/E392）。
4. **可实现性模型漏工作点** → `Π_stable` 接触模式枚举 + 最坏转移查表 + 在线无源性/能量罐监控 + 摩擦/粘滑专项压力测试（E374/E375/E377）；模型外一律保守投影。
5. **TCP 双向污染** → 控制/评测 TCP 强制独立标定（不同传感器/标定件/外部动捕）；`u_tcp` 作为 Type B 进入 `u_M`；独立链交叉校验（E372/E373）。
6. **评测预算被刷精度挤占** → EVO 显式分配 `B_cover/B_power/B_rep`；失败模式覆盖作为一等目标（E393）。
7. **证书变成「合规剧场」** → 顶层强制写 `Unknown(D_eval^c)`；未通过可实现性/评测有效性的主张不得对外宣称；外部审计可复算（定义 380/388）。
8. **评测统计被 p-hack** → 预注册 + 随时有效统计 + 偏离记账；事后终点一律标探索性（E367/E368/E371）。
