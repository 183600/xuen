### 第 3 轮灵感驱动研究记录（承接第 2 轮）

**灵感词**：机械臂、动态避障

**直觉与动机**：
机械臂动态避障的难点不在「看见障碍」，而在「障碍会动、且未来不可完全预知」。1) 预测不确定性：人、移动平台或另一台机械臂的未来轨迹只能以分布或可达集给出，任何把障碍当成确定性轨迹的方法都在赌预测正确；2) 高维构型：7-DOF 以上关节空间里，末端笛卡尔空间的一条「绕开」轨迹可能对应关节空间的大幅重构，甚至穿越自碰撞区；3) 安全-活性张力：过度保守的避障会让机械臂在人机共存/多机场景中「冻结」（deadlock），而激进避障又牺牲安全；4) 实时性：动态障碍要求 50–100Hz 级别重规划，完整非线性 MPC 往往来不及。

传统方法各缺一角：速度障碍（VO）只处理瞬时速度锥、不考虑关节与自碰撞约束；DMP/CHOMP/STOMP 在动态场景重规划代价高且缺乏形式保证；确定性 MPC 把预测轨迹当真理，预测一偏即失守。前两轮建立了「证书驱动」的准入范式（KEMPC / KACG，Exec_v27），本轮把该范式从「静态常识」推进到「时空预测」。

**关键洞见**：把动态障碍的「未来」显式建模为**带不确定度的可达管（Reachable Tube）**，用**时空分离证书（STSC）**要求机械臂扫掠体在整个预测时域内与可达管保持含不确定度膨胀的安全间距；用**可撤销安全走廊（RSC）**保证预测更新时可行域只单调收缩、不突然失效；用**速度障碍证书（VOC）**提供短时快速反应层；用**无死锁证书（DEC）**保证安全约束不会把系统永久锁死。四者并入证书准入证书门，得到 Exec_v28 ⊆ Exec_v27。其精髓是把「预测—证书—准入」做成带**租期（lease）**的可失效链：观测漂移超阈值即吊销旧证书并重签，而不是沿用一条已经过时的安全保证。

**形式化目标**：
1. 定义动态障碍可达管 R_i(t) = { y : (y-μ_i(t))ᵀΣ_i(t)⁻¹(y-μ_i(t)) ≤ χ²_{3,1-δ} } ⊕ Ball(ε_i(t))，其中 μ_i、Σ_i、ε_i 由意图感知预测器给出并带在线标定；
2. 定义机械臂扫掠体 SV(q(t))（胶囊体近似），以及时变最小间距 d_i(t) = dist(SV(q(t)), R_i(t))；
3. 定义时空分离证书 STSC：∀t∈[0,H], d_i(t) ≥ ε_safe + γ·σ_i(t)，并附带租期 lease，观测漂移超过 δ_lease 即吊销；
4. 定义广义速度障碍证书 VOC：候选关节速度 q̇ 在 τ_max 内不进入任一障碍的广义速度障碍集；
5. 定义可撤销安全走廊 RSC：C_k = {q : ‖q-q_ref,k‖²_W ≤ r_k²}，满足 r_{k+1} ≤ r_k，预测更新量 Δ 触发 r ← r - ηΔ；
6. 定义无死锁证书 DEC：滑动窗口 W 内要么任务进度 ≥ δ_prog，要么在 T_stop 内被认证为安全停机，禁止无限冻结；
7. 定义 CADA-MPC：在关节空间 MPC 中把 STSC、VOC、RSC 作为（软/硬）约束，输出控制量并同步签发四类证书；
8. 定义反应式证书门 RCG：Exec_v28 = Exec_v27 ∩ Fil_spacetime ∩ Fil_intention ⊆ Exec_v27，并证明预测失准、超时、死锁三类退化路径。

**本轮最大风险**：可达管低估导致的「虚假安全」——当障碍出现分布漂移或对抗性运动（人突然加速/变向）而预测器仍给出过窄的可达管时，STSC 会为实际会碰撞的轨迹签发通过证书，这种「证书背书的事故」比无证书的保守避障更危险，也更难在线发现。

## 2. 关键算法骨架

### IP-465 Intention-Aware Trajectory Predictor (IATP)

```python
@dataclass
class ReachableTube:
    """可达管：均值轨迹 + 标定协方差 + 误差上界，向外膨胀成安全区域"""
    mu: Tensor                    # (H+1, 3) 位置均值
    sigma: Tensor                 # (H+1,) 各时刻不确定度标量
    eps: Tensor                   # (H+1,) 残差误差上界
    radius0: float = 0.05         # 障碍自身几何半径

    def at(self, t: float) -> 'EllipsoidRegion':
        i = self._nearest(t)
        r = self.radius0 + self.eps[i] + 3.0 * self.sigma[i]
        return EllipsoidRegion(center=self.mu[i], radius=r)

    def sigma_at(self, t: float) -> float:
        i = self._nearest(t)
        return self.sigma[i] + self.eps[i]

    def _nearest(self, t: float) -> int:
        return min(len(self.mu) - 1, max(0, int(t / self.dt)))


class IntentionAwarePredictor:
    """三类意图先验 + 残差校准，输出可达管而非单轨迹"""
    PRIORS = ("human", "robot_arm", "mobile_base")

    def __init__(self, model, residual_calibrator, horizon: int = 30):
        self.model = model
        self.calibrator = residual_calibrator
        self.horizon = horizon

    def predict(self, obs_history: Tensor, kind: str) -> ReachableTube:
        mu, raw_sigma = self.model(obs_history, kind)          # 均值 + 原始方差
        eps = self.calibrator.residual_bound(kind, obs_history) # 在线残差上界
        sigma = self.calibrator.calibrate(raw_sigma, eps)       # 保形校准
        return ReachableTube(mu=mu, sigma=sigma, eps=eps)
```

### IP-466 Spatio-Temporal Separation Certificate (STSC)

```python
@dataclass
class SpatioTemporalSeparationCertificate:
    """STSC：全时域扫掠体-可达管分离，含不确定度膨胀与租期"""
    name: str
    horizon: float
    eps_safe: float = 0.05
    gamma: float = 1.5
    lease: float = 0.10
    margin_curve: list = field(default_factory=list)

    def verify(self, swept_volume_fn, tubes: list['ReachableTube'],
               q_traj: Tensor, t_grid: Tensor) -> bool:
        self.margin_curve = []
        for t in t_grid:
            sv = swept_volume_fn(q_traj, float(t))            # 胶囊体并集
            d_min = min(gjk_distance(sv, tube.at(float(t))) for tube in tubes)
            required = self.eps_safe + self.gamma * max(
                tube.sigma_at(float(t)) for tube in tubes)
            margin = d_min - required
            self.margin_curve.append(margin)
            if margin < 0.0:
                return False
        return True

    def revoke_if_drifted(self, delta_obs: float) -> bool:
        """观测漂移超过阈值则吊销证书，必须重签"""
        return delta_obs > self.lease * 10.0
```

### IP-467 Velocity Obstacle Certificate (VOC)

```python
@dataclass
class VelocityObstacleCertificate:
    """短时反应层：候选关节速度不得进入任一障碍的广义速度障碍集"""
    tau_max: float = 0.5
    n_tau: int = 16

    def verify(self, q: Tensor, qdot: Tensor,
               tubes: list['ReachableTube'], fk,
               q_min: Tensor, q_max: Tensor) -> bool:
        taus = torch.linspace(0.0, self.tau_max, self.n_tau)
        for tau in taus:
            q_pred = q + qdot * tau
            if torch.any(q_pred < q_min) or torch.any(q_pred > q_max):
                return False                                   # 关节限位
            p = fk(q_pred)
            for tube in tubes:
                if tube.at(float(tau)).contains(p):
                    return False                               # 进入 GVO_i
        return True
```

### IP-468 Revocable Safety Corridor (RSC)

```python
@dataclass
class RevocableSafetyCorridor:
    """可撤销走廊：半径单调收缩，保证递归可行而非突变失效"""
    center: Tensor
    radius: float
    W: Tensor                       # 关节权重矩阵（对角）
    min_radius: float = 1e-3

    def contains(self, q: Tensor) -> bool:
        delta = q - self.center
        return float(delta @ self.W @ delta) <= self.radius ** 2

    def contract(self, delta_pred: float, eta: float = 0.5) -> bool:
        self.radius = max(self.min_radius, self.radius - eta * delta_pred)
        return self.radius > self.min_radius

    def recenter(self, q_ref: Tensor) -> None:
        """重规划成功后才允许重设中心；半径只减不增"""
        self.center = q_ref.clone()
```

### IP-469 Certificate-Aware Dynamic Avoidance MPC (CADA-MPC)

```python
@dataclass
class CADADynamicAvoidanceMPC:
    dynamics: Callable
    horizon: int = 15
    dt: float = 0.02
    weights: dict = field(default_factory=dict)
    stsc: SpatioTemporalSeparationCertificate = None
    voc: VelocityObstacleCertificate = None
    rsc: RevocableSafetyCorridor = None

    def solve(self, q0: Tensor, q_goal: Tensor, tubes: list['ReachableTube']):
        import cvxpy as cp
        N, nq = self.horizon, len(q0)
        Q = cp.Variable((N + 1, nq))
        V = cp.Variable((N, nq))
        s = cp.Variable(N, nonneg=True)          # STSC 软约束松弛
        cost, cons = 0.0, [Q[0] == q0]

        for k in range(N):
            cons += [Q[k + 1] == self.dynamics.step(Q[k], V[k], self.dt)]
            # 关节/速度/加速度约束
            cons += [V[k] >= self.dynamics.v_min, V[k] <= self.dynamics.v_max]
            # RSC 终端约束（凸近似）
            cons += [cp.quad_form(Q[k + 1] - self.rsc.center, self.rsc.W)
                     <= self.rsc.radius ** 2]
            # STSC 线性化分离平面：a_kᵀ q ≥ b_k - s_k
            for a, b in self._separating_planes(k, tubes):
                cons += [a @ Q[k + 1] >= b - s[k]]
            cost += self.weights.get("slack", 1e3) * s[k]
            cost += self.weights.get("control", 0.05) * cp.sum_squares(V[k])
            cost += self.weights.get("task", 1.0) * cp.sum_squares(Q[k + 1] - q_goal)

        prob = cp.Problem(cp.Minimize(cost), cons)
        try:
            prob.solve(solver="OSQP", warm_start=True)
            if prob.status not in ("optimal", "optimal_inaccurate"):
                return self._safe_stop(q0)
            q_traj = Q.value
            if not self._issue_certificates(q_traj, tubes):
                return self._safe_stop(q0)
            return V.value[0], q_traj
        except Exception:
            return self._safe_stop(q0)

    def _separating_planes(self, k, tubes):
        """由可达管生成时变分离超平面（凸包/GJK 支撑点）"""
        return self.stsc.separating_planes_at(k * self.dt, tubes)

    def _issue_certificates(self, q_traj, tubes) -> bool:
        ok_stsc = self.stsc.verify(self.dynamics.swept_volume, tubes,
                                   q_traj, torch.arange(0, self.horizon + 1) * self.dt)
        ok_voc = self.voc.verify(q_traj[0], (q_traj[1] - q_traj[0]) / self.dt,
                                 tubes, self.dynamics.fk,
                                 self.dynamics.q_min, self.dynamics.q_max)
        ok_rsc = all(self.rsc.contains(q) for q in q_traj)
        return ok_stsc and ok_voc and ok_rsc

    def _safe_stop(self, q0: Tensor):
        """认证安全停机：零速保持并签发保守证书"""
        return torch.zeros_like(q0), q0.unsqueeze(0)
```

### IP-470 Deadlock Escape Certificate (DEC)

```python
@dataclass
class DeadlockEscapeCertificate:
    """活性：窗口内要么有进度，要么认证安全停机，禁止无限冻结"""
    window: int = 20
    delta_prog: float = 0.01
    T_stop: float = 0.5
    history: list = field(default_factory=list)

    def update(self, task_cost: float, is_safe_stop: bool) -> str:
        self.history.append((task_cost, is_safe_stop))
        if len(self.history) > self.window:
            self.history.pop(0)
        if len(self.history) < self.window:
            return "warming"
        progress = self.history[0][0] - self.history[-1][0]
        if progress >= self.delta_prog:
            return "progressing"
        if all(s for _, s in self.history[-int(self.T_stop / 0.02):]):
            return "certified_stop"
        return "deadlock"          # 触发绕行/换手/让行策略
```

### IP-471 Dynamic Obstacle Knowledge Base (DOKB)

```python
class DynamicObstacleKnowledgeBase:
    """动态障碍常识库：给预测器/证书提供先验与自适应参数"""
    def __init__(self):
        self.rules = [
            # 人类靠近时放大不确定度，宁可保守
            ("human_proximity_inflate", lambda d: d < 1.0, {"gamma": 2.0}),
            # 人类不会主动穿越机械臂本体，但可能伸手
            ("human_no_cross_body", lambda kind: kind == "human", {"bias": 0.15}),
            # 另一台机械臂共享工作空间时，互避让优先于任务
            ("dual_arm_yield", lambda kind: kind == "robot_arm", {"yield": True}),
            # 负载摆动：末端速度高时放大扫掠体
            ("payload_swing", lambda v: v > 0.5, {"swept_inflate": 0.08}),
        ]

    def adapt(self, obs: dict) -> dict:
        params = {"gamma": 1.5, "bias": 0.0, "yield": False, "swept_inflate": 0.0}
        for _, cond, delta in self.rules:
            if cond(obs.get("x", 0.0)) or cond(obs.get("kind", "")):
                params.update({k: delta.get(k, v) for k, v in params.items()
                               if k in delta})
        return params
```

### IP-472 Reactive Certification Gate (RCG)

```python
@dataclass
class ReactiveCertificationGate:
    """v28 准入门：KACG ∪ STSC ∪ VOC ∪ RSC ∪ DEC ∪ DOKB"""
    kacg: 'KnowledgeAwareCertificationGate'
    predictor: IntentionAwarePredictor
    cada_mpc: CADADynamicAvoidanceMPC
    stsc: SpatioTemporalSeparationCertificate
    voc: VelocityObstacleCertificate
    rsc: RevocableSafetyCorridor
    dec: DeadlockEscapeCertificate
    dokb: DynamicObstacleKnowledgeBase

    def admits(self, plan: 'RobotPlan', sensor_data: dict) -> bool:
        # 1. 继承 v27 的八证准入
        if not self.kacg.admits(plan, sensor_data):
            return False
        # 2. 意图感知预测 -> 可达管
        tubes = [self.predictor.predict(h, k) for h, k in
                 zip(sensor_data["obstacle_hist"], sensor_data["obstacle_kind"])]
        params = self.dokb.adapt(sensor_data)
        self.stsc.gamma = params["gamma"]
        # 3. CADA-MPC 求解并签发证书
        u, q_traj = self.cada_mpc.solve(plan.q0, plan.q_goal, tubes)
        if not self.stsc.verify(self.cada_mpc.dynamics.swept_volume, tubes,
                                q_traj, plan.t_grid):
            return False
        if not self.voc.verify(q_traj[0], u, tubes, self.cada_mpc.dynamics.fk,
                               self.cada_mpc.dynamics.q_min, self.cada_mpc.dynamics.q_max):
            return False
        if not all(self.rsc.contains(q) for q in q_traj):
            return False
        # 4. 活性：禁止无限冻结
        if self.dec.update(plan.task_cost, plan.is_safe_stop) == "deadlock":
            return False
        # 5. 观测漂移吊销旧证书
        if self.stsc.revoke_if_drifted(sensor_data.get("obs_drift", 0.0)):
            return False
        return True
```

## 3. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |

## 4. 正确性论证（增量）

### 假设 A1（可达管过近似）
预测器输出的 R_i(t) 以概率 ≥ 1-δ 覆盖真实障碍占据集 O_i(t)，即 O_i(t) ⊆ R_i(t)。

### 引理 23（STSC 的连续时间可靠性）
**陈述**：若 STSC 在采样网格上满足 d_i(t_k) ≥ ε_safe + γσ_i(t_k)，且间距函数关于时间 Lipschitz 常数为 L，网格步长 Δt ≤ ε_safe / L，则在连续时域 [0,H] 内无碰撞。

**证明**：由 Lipschitz 性，任意 t∈[t_k,t_{k+1}] 有 d_i(t) ≥ d_i(t_k) - L|t-t_k| ≥ ε_safe + γσ_i(t_k) - LΔt ≥ γσ_i(t_k) ≥ 0。再由 A1，真实障碍 ⊆ R_i，故扫掠体与真实障碍不交。∎

### 引理 24（RSC 递归可行性）
**陈述**：若 q_k ∈ C_k 且 r_{k+1} ≤ r_k、center 仅在重规划成功后重设，则只要重规划成功，q_{k+1} ∈ C_{k+1}；若重规划失败则触发认证安全停机，不产生不可行控制。

**证明**：CADA-MPC 将终端 Q[k+1] 约束在 C_k 内，收缩后 C_{k+1} ⊆ C_k，故解仍可行；预测更新只减少半径，不会引入未验证的新区域。失败分支返回零速保持。∎

### 引理 25（VOC 与 STSC 的互补性）
**陈述**：在 τ_max 内，VOC 通过 ⟹ 不存在以当前 q̇ 恒速外推的碰撞；STSC 覆盖 τ_max 之外的预测时域。二者合取严格强于任一单独证书。

**证明**：VOC 对每个 τ∈(0,τ_max] 检查 FK(q+q̇τ) ∉ R_i(τ)，即恒速外推轨迹在反应时域内分离；STSC 对全 [0,H] 检查扫掠体分离。前者是后者在「恒速子集」上的短时特化，故合取更强。∎

### 引理 26（DEC 的活性）
**陈述**：若 DEC 输出 progressing 或 certified_stop，则系统不会无限冻结；若输出 deadlock，则触发绕行/让行，保证有限时间内离开局部极小。

**证明**：窗口 W 内进度不足且未认证停机即判 deadlock，状态机强制切换策略；认证停机本身是 STSC 保持下的合法终端状态。∎

### 定理（Exec_v28 的可靠性与单调性）
**陈述**：对任意计划 Π，RCG.admits(Π)=True ⟹ Π 在 A1 下无碰撞、满足关节/自碰撞约束、且非死锁；并且 Exec_v28 = Exec_v27 ∩ Fil_spacetime ∩ Fil_intention ⊆ Exec_v27。

**证明**：RCG 首先调用 KACG（继承 v27 全部约束），再合取 STSC（引理 23）、VOC（引理 25）、RSC（引理 24）、DEC（引理 26）。合取只缩小可行集，故单调性成立；各证书均以 A1 为前提，故结论在预测覆盖成立时可靠。∎

## 5. 实验设计

| 场景 | 动态障碍 | 基线 | 指标 |
|---|---|---|---|
| S1 人机共享工作台 | 人手线性/正弦伸取 | VO、确定性 MPC、CHOMP、CADA-MPC | 碰撞率、最小间距、成功率、单步耗时 |
| S2 双臂协同 | 另一 7-DOF 臂变向 | 独立规划、集中式 MPC、RCG | 死锁率、让行次数、任务完成时间 |
| S3 对抗性运动 | 障碍突然加速/折返 | 固定 σ、放大 σ、在线标定 σ | 虚假安全率、保守度（路径长度开销） |
| S4 预测分布漂移 | 训练/测试意图不同 | 无租期、带租期吊销 | 事故率、证书吊销及时性 |

**消融**：逐一移除 STSC / VOC / RSC / DEC；扫描 γ∈{1.0,1.5,2.0}、τ_max∈{0.3,0.5,0.8}、lease∈{0.05,0.1,0.2}。

**预期**（示意）：RCG 相对确定性 MPC 碰撞率下降 >80%，相对固定 σ 的虚假安全率下降 >50%，死锁率 <2%；代价是路径长度增加 8–15%，单步耗时增加 3–6ms。S3 中在线标定 σ 是抑制虚假安全的关键；S4 中租期吊销把事故率从「隐性累积」变为「可检测的证书失效」。

## 7. 本轮最大风险（最终确认）

**一句话**：**动态障碍预测的可达管一旦被低估（分布漂移或对抗性运动），STSC 会为实际会碰撞的轨迹签发「虚假安全」证书，这种被证书背书的事故比无证书的保守避障更危险、更难在线发现，是当前方案最大的安全隐患。**
