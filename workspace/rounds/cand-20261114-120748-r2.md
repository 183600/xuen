# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分」IP-253~263；灵感循环新循环第 2 轮；本轮灵感：「数据配比」×「技术路线图」）

> R69 让系统学会了在**测试时提问**：把不确定性拆成 aleatoric 与 epistemic，后者用「流匹配多模态策略 + 主动多模态交互」去消解。但 R69 有一个从未被审计的前提——**它赖以计算 VoI 的模态分布，不是模型天生的，而是数据配比"制造"出来的**。如果某个真实模式的数据层质量低于可辨识阈值，流模型不会"把权重算错"，而是**根本学不出这个模式**；此时 ECE 仍然漂亮，因为校准的考题与答案来自同一份配比。R69 自陈的最大风险（模态权重不可信 → 追问幻影 / 给误导性回答盖章），本质上不是模型问题，而是**数据构成问题**。
>
> 本轮的第二个灵感「技术路线图」补上时间维度：R69 的证书是一个**点**（对固定配比 w0 与固定分布 q0 有效），但真实部署会换场地、换物体、换数据源，配比与分布都会漂移。可信不应是一次性结论，而应是**分阶段扩张的有效域 + 预注册证据门 + 可回退**。路线图不是幻灯片上的甘特图，而是"证书有效域"的扩张协议。
>
> 核心命题：**把数据配比提升为一等状态变量，把证书从"点"升级为"配比×部署空间中的区域"，用技术路线图作为区域的分阶段扩张协议；同时把 R69 的 VoI 复制到数据空间，形成双时间尺度信息经济学——动作空间的 VoI 决定"现在问不问"，数据空间的 DVoI 决定"以后买不买这块数据"。** 命名 **MIXROAD-RAS**（Data-**Mix**-conditioned, **Road**map-gated Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么相信我的信念？这份信任在哪种数据配比下成立、能维持多久、下一块数据该买什么？**」——不确定性不只是一脚刹车或一句提问，它还是一份**数据预算**和一张**路线图**。

## 0. 直觉与动机

**灵感 1（数据配比是模式先验的制造者，不是超参数）**
直觉：配比像食谱里的材料比例——它决定的不是"这道菜咸一点还是淡一点"，而是"这道菜里到底有没有这种味道"。若真实模式 k 的有效质量 n_k 低于可辨识阈值，流模型对它的表示不是"低置信"，而是**不存在**；此时 R69 采样得到 K 个模态、算出的 H_mode 很低、U_epi 很小，系统于是**既自信又错误**。更糟的是，R69 的 MCG 用同一配比下的留出集测 ECE——考题和答案都由这份配比生成，坍缩的模式不会出现在任何一方，校准门对此完全失明。**校准必须有一个"外部锚点"：一段不参与训练、且刻意覆盖稀有层的探针数据。** 同时，把稀有层权重抬高并非免费：它同时放大了该层的投毒杠杆与幻影稳定性（灵感 2）。

**灵感 2（配比本身就是攻击面：比例投毒）**
直觉：对手不必篡改任何一条样本的内容，**只改比例**就够了。往正确的层里多掺一点"看起来合理"的数据，就能把某个模式的先验抬高、或让一个幻影模式显得"有支撑"。更阴险的是阈值效应：当估计的模态权重本来就靠近 VoI 决策边界时，只需很小的比例扰动就能让系统"该问而不问"或"不该问而乱问"。这是 R69 的 ℰ_poison 没有覆盖的维度——**内容投毒 vs 比例投毒**。防御不能只靠"清洗内容"，必须靠多源鲁棒聚合（破坏点）、归因集中度检测、配比指纹与外部锚点。

**灵感 3（双时间尺度 VoI：现在问，还是以后买数据）**
直觉：R69 用 VoI 决定是否发起一次交互——本质是"这个信息能不能改变我现在的动作"。R70 把同一条经济学原则搬到训练时间：**这块数据能不能改变我下一版模型的决策**。二者只差一个时间尺度与成本模型：
- 动作空间：VoI_act(g) = H(M|o) − E[H(M|o,y)]，成本是物理/社交成本；
- 数据空间：DVoI(δw) = 决策相关校准增益 × 下游决策敏感度 − 数据成本。
于是"多买数据"和"多问一句"受同一个约束：**信息只在能改变决策时才值钱**。这天然给出"别什么都采"的纪律，也把 R69 的交互日志变成 R70 的数据需求信号——但注意，这个信号是内生的，必须被外生锚点校正（灵感 5）。

**灵感 4（技术路线图 = 证书有效域的分阶段扩张协议）**
直觉：R69 的证书是一张"点证书"：只对训练配比 w0 和标定分布 q0 成立。换一个场地、换一批物体、换一个采集源，配比和分布都变了，证书其实已经悄悄失效，但系统仍在用。R70 把证书改成**区域证书**：一条 claim + 一组证据 + 一个在 (配比, 部署) 空间中的有效域 + 一条数据血统。技术路线图就是扩张这个有效域的协议：每个阶段提出一个能力主张和一个目标有效域，晋升必须过预注册的证据门，越界必须降级。**预注册（先锁阈值再看结果）是对抗"证书剧场"的关键**——否则路线图会退化成"先开枪再画靶"。

**灵感 5（自证飞轮：越不确定越买这块数据，可能是在追逐幻影）**
直觉：主动配比会闭合成一个环——模型在配比 w_t 上训练，报告哪些模式不确定；控制器去买这些模式的数据，w_{t+1} 抬高它们；模型于是对这些模式更自信——无论它们是真实还是幻影。没有外部锚点与探索下限时，这个环可以收敛到一个**幻影吸引子**：系统越来越自信地追问一个不存在的东西，并把人类一个误导性回答盖上"已验证"的章。这正是 R69 最大风险的动态放大版。所以数据 VoI 必须在外生留出探针上计算，配比更新必须保留锚点比例与覆盖下限。**配错数据，比不配更危险。**

## 1. 形式化定义（增量：定义 310–324）

**定义 310（数据配比与有效模式质量）** 数据层划分为 M 个层（stratum）𝒮 = {1,…,M}（模态 / 任务 / 场地 / 物体 / 采集源）。配比 w ∈ Δ^{M−1}，∑_s w_s = 1；训练集 D(w) 中层 s 的样本数 n_s = w_s N。模式 k 的**有效质量** n_k(w) = ∑_s w_s N κ_{k,s}，其中 κ_{k,s} 为层 s 的样本落入模式 k 的比例（模式—层混淆矩阵，由聚类/归因估计）。模式支持集 supp(w) = {k : n_k(w) ≥ n_min}。模式—层集中度 H_k = ∑_s (w_s κ_{k,s} / n_k)^2（Herfindahl）。

**定义 311（配比条件化校准曲面）** 对配比 w 训练（或重标定）的模型，在部署分布 q 上的模态权重校准误差记为 C(w, q)。R69 的 MCG 检查的只是 C(w0, q0) ≤ τ_ece 的**一个点**；本轮把证书定义为校准曲面上区域 ℛ = {(w,q) : C(w,q) ≤ τ_ece} 的一个内近似，部署只在 ℛ 内被认证。

**定义 312（配比迁移界与有效半径）** 假设 A99（校准曲面正则性）：C 对 w 满足 L_w-Lipschitz（TV 距离）、对 q 满足 L_q-Lipschitz（W1 距离）。则
|C(w′,q′) − C(w,q)| ≤ L_w·D_TV(w′‖w) + L_q·W1(q′,q)。
给定已测点 C(w0,q0)，有效半径 r_cal(w0) = sup{r : C(w0,q0) + L_w r + L_q r ≤ τ_ece}。R69 的 MCG 是 r = 0 的特例。**推论**：部署落在 r_cal 之外时，即使在线代理指标看起来正常，ECE 保证也不再成立；而真实 ECE 需要模式标签，部署时不可得，因此只能依赖区域证书，不能依赖"现场看一眼指标"。

**定义 313（模式可辨识性与四类模式）** 在分离度 Δ_min、模态内尺度 σ_in、有效维 d 下，模式 k 可辨识当且仅当
n_k ≥ n_min := C_d·(σ_in/Δ_min)^d·log(1/β)，且存在留出探针使检验功效 ≥ 1−β。
按可辨识性与稳定性把模式分为四类：**已证（verified）**——可辨识、稳定、多源佐证；**坍缩（collapsed）**——真实但 n_k < n_min，模型里根本不存在，ECE 看不见；**幻影（phantom）**——模型里有，但重采样不稳定或归因高度集中；**欠采样歧义（latent-ambiguous）**——可辨识但样本不足，权重可信度低。R69 的 ECE 只对"模型里已存在的模式"有定义，故坍缩与幻影都是其盲区。

**定义 314（模式稳定性与归因集中度）** 对每个模式 k：MSS_k = 在 B 次分层自助/重采样下，以 Fréchet 距离 δ 匹配重现的频率（mode stability score）；ACI_k = 数据源上归因（TracIn / 影响函数 / Shapley 近似）的 Herfindahl 指数（attribution concentration index）。已证要求 MSS_k ≥ θ_s 且 ACI_k ≤ θ_c。幻影判据：MSS 低**或** ACI 高；坍缩判据：外部探针上存在高密度簇，但策略无对应模态。

**定义 315（双时间尺度 VoI 与数据 VoI）** R69 的测试时 VoI：VoI_act(g) = H(M|o) − E_{y∼p(·|g,o)}[H(M|o,y)]。本轮的数据 VoI：对候选配比调整 δw（或新增数据批次），
DVoI(δw) = E_{probe∼𝒫_ext}[ CE(w,q) − CE(w+δw,q) ] · S_dec − c(δw)，
其中 CE 为按决策边界加权的校准误差，S_dec = |∂risk/∂p(mode)| 为下游决策敏感度（例如 VoI 决策翻转的概率），c 为采集/标注/训练成本。选择 δw* = argmax DVoI，s.t. 覆盖下限、锚点比例、投毒预算与总算力约束。**DVoI 的期望必须在外部锚点/留出探针 𝒫_ext 上计算，不能用部署自身的不确定性（见定理 19）。**

**定义 316（主动配比控制器与鲁棒目标）** w_{t+1} = (1−η)w_t + η·Π_𝒲(w*)，其中
w* = argmin_{w∈𝒲} max_{q∈𝒬_stress} C(w,q) + ρ·PoisonRisk(w)，
s.t. w_s ≥ w_min（覆盖/探索下限），w_anchor ≥ α（固定外部锚点比例），∑_s w_s = 1，cost(w) ≤ B。
𝒬_stress 是**预先注册**的配比/部署扰动族（不是当前部署分布），Π_𝒲 为投影到带上下限的单纯形。PoisonRisk(w) 由定义 314 的 ACI 与定义 317 的阈值估计。

**定义 317（配比投毒模型与破坏点）** 对手控制总质量比例 ε 的数据（每条内容可以看似合理），使实际配比 w′ 满足 D_TV(w′‖w) ≤ ε。定义决策翻转阈值 ε*(m,τ) = min{ε : |ŵ_m(w′) − ŵ_m(w)| ≥ |ŵ_m(w) − τ|}，τ 为 VoI 决策阈值。多源鲁棒聚合器（分层中位数 / 截尾均值）的破坏点为 β_b：只要 ε < β_b，模式权重偏差有界；但**模式存在性**（幻影 / 坍缩）的破坏点更低——只要 ε 足以让一个簇跨过密度阈值，幻影即可出现。防御组合：多源鲁棒聚合 + ACI 集中度检测 + 外部锚点 + 配比指纹。

**定义 318（技术路线图结构）** 路线图 ℛ = {S_0, …, S_T}，每个阶段 S_t = (C_t, w_t, 𝒬_t, E_t, θ_t, π⁻_t)：能力主张 C_t、目标配比 w_t、认证部署域 𝒬_t、证据集 E_t、出口阈值 θ_t、回退策略 π⁻_t。要求能力与认证域单调扩张：C_t ⊇ C_{t−1}，𝒬_t ⊇ 𝒬_{t−1}（否则只算 fork，不算晋升）。阶段之间的边是**证据门**，不是日历。

**定义 319（能力就绪等级 CRL）** 7 级，以可核验证据定义（防"PPT 路线图"）：CRL0 离线基准可复现；CRL1 留出配比上模式覆盖/召回达标；CRL2 名义配比上 ECE ≤ τ；CRL3 跨配比扰动族校准迁移达标；CRL4 R69 交互安全与证据纪律达标；CRL5 24h 闭环零交互诱发违规 + 独立审计；CRL6 车队级上线，配比指纹 / 血统 / 回退演练完备。每级有强制证据，不可跳级。

**定义 320（路线图门与降级）** 晋升门 G_t：仅当 E_t 全过、J_MIXROAD 有效、且预注册未改时，允许从 S_t 到 S_{t+1}；否则停在 S_t。运行时监控若发现配比指纹不匹配、部署越出 𝒬_t、或 MIM 报坍缩/幻影，则**降级**到 S_{t−1} 的保守策略 π⁻_{t−1}（其安全侧不弱于 R68/R69 兜底）。安全不变式：任一时刻部署的策略都在某个已认证区域内。

**定义 321（配比指纹与证书血统）** h(w) = H(数据集 ID 与版本, 分层计数, 去重/归因摘要, 代码版本, 校准头版本)。证书绑定 (h(w), ℛ_region, 证据哈希)。任何配比变化 ⇒ 指纹不匹配 ⇒ 证书失效 ⇒ 自动触发迁移测试或降级。血统是有向无环图：数据批次 → 模型版本 → 证书版本，支持"这个证书是哪批数据、哪次实验挣来的"的可追溯回答。

**定义 322（预注册与"球门锁定"）** 在阶段实验开始前，把 (指标定义, 阈值, 压力族, 分析计划) 的哈希提交到外部只追加日志（独立托管）。任何阈值修改产生新版本并触发重新审计；未重新审计不得晋升。用于阻止"看到结果再调阈值"的证书剧场（certificate theater）。

**定义 323（证书 J_MIXROAD）** J_MIXROAD = (J_FLUID, h(w), ℛ_region, crl_level, DVoI_log, MIM_summary(MSS, ACI, n_k), stress_suite_hash, prereg_hash, audit_hash, mixroad_ver)。Valid ⇔ R69 的 J_FLUID 有效 ∧ 指纹匹配 ∧ 整个 ℛ_region 内校准带达标 ∧ 无坍缩/幻影标记 ∧ 预注册哈希一致 ∧ 独立审计通过。

**定义 324（MIXROAD-RAS 双环）** 实时环 = R69 原样（保持 < 2.6ms）；元环（训练/运维节律）：部署日志 → MIM 模式四分类 → DVoI 选数据 → 鲁棒主动配比 → 重标定/重训 → 压力测试族 → 路线图门 → 颁发区域证书；运行时监控持续校验指纹与区域，越界即降级。**R69 是元环关闭、配比固定、单阶段（T = 0）的退化情形。**

# IP-264 MCS：配比条件化校准曲面（离线/周期；在线只查表 + 区域判定）
class MixCalibrationSurface:
    def __init__(self, policy_factory, stress_mixes, stress_qs):
        self.policy_factory, self.grid = policy_factory, []

    def fit(self, w0, q0, margin):
        c0 = self.ece(w0, q0)
        Lw, Lq = self.estimate_lipschitz()            # 在压力族上拟合
        r = self.solve_radius(c0, Lw, Lq, margin)     # 定义 312
        self.grid.append((w0, q0, c0, r))
        return r

    def certified(self, w, q):
        return any(D_tv(w, w0) + W1(q, q0) <= r
                   for (w0, q0, c0, r) in self.grid)

# IP-265/266 MIM+MSA：模式四分类（坍缩 / 幻影 / 欠采样 / 已证）
def classify_modes(policy, D, probes, B=20):
    modes, out = policy.modes(D), {}
    for k in modes:
        nk  = effective_mass(k, D)                    # 定义 310
        mss = bootstrap_persistence(k, D, B)          # 定义 314
        aci = attribution_concentration(k, D)         # TracIn/Shapley 近似
        if nk < n_min(k):                       out[k] = 'collapsed'
        elif mss < THETA_S or aci > THETA_C:    out[k] = 'phantom'
        elif nk < N_COMFORT:                    out[k] = 'latent_ambiguous'
        else:                                   out[k] = 'verified'
    for k in external_probe_modes(probes):            # 坍缩只能从外部看
        if not matched_by_policy(k, modes):     out[k] = 'collapsed'
    return out

# IP-267/268 DVoI + 鲁棒主动配比（元环，离线）
def data_voi(w, delta_candidates, probes, sensitivity, cost):
    best = None
    for dw in delta_candidates:
        gain  = expected_calibration_gain(probes, w, dw) * sensitivity
        score = gain - cost(dw)
        if best is None or score > best.score: best = (dw, score)
    return best if best and best.score > 0 else None   # 不划算就不买

def active_mix_step(w, stress_family, poison_risk, budget):
    w_star = argmin_robust(stress_family, poison_risk, budget)   # 定义 316
    return simplex_project((1 - ETA) * w + ETA * w_star,
                           lower=W_MIN, anchor=ALPHA)            # 下限 + 锚点

# IP-271/272/273 路线图门 + 预注册 + 运行时降级
def roadmap_gate(stage, J, prereg, audit):
    ok = (J.compact_valid() and J.mixroad_valid()
          and J.prereg_hash == prereg.hash
          and audit.passed and all(e.passed for e in stage.evidence))
    return advance(stage) if ok else stay(stage)

def runtime_monitor(policy, obs, deployed):
    if not fingerprint_match(policy, deployed.h_w):    return demote(deployed)
    if not deployed.region.contains(obs.mix_estimate): return demote(deployed)
    if MIM.flags_collapse_or_phantom(policy, obs):     return demote(deployed)
    return deployed

# IP-275 双环主流程
def MIXROAD_round(real_time_loop, meta_state):
    k, lam, mode, U = real_time_loop.step()            # 实时环完全复用 R69
    if meta_state.due():                               # 元环，不在实时路径
        classes = MIM.classify(meta_state.policy, meta_state.data,
                               meta_state.external_probes)
        if any(c in ('collapsed', 'phantom') for c in classes.values()):
            meta_state.freeze_and_audit(classes)       # 先冻住，别追幻影
        else:
            dw = DVoI.best(meta_state.w, meta_state.candidates,
                           meta_state.external_probes,
                           meta_state.sensitivity, meta_state.cost)
            if dw is not None:
                w_next = AMC.step(meta_state.w, meta_state.stress_family,
                                  meta_state.poison_risk, meta_state.budget)
                meta_state = retrain_and_recalibrate(w_next)
        J = issue_certificate(meta_state)
        roadmap_gate(meta_state.stage, J, meta_state.prereg, meta_state.audit)
    return runtime_monitor(meta_state, real_time_loop.last_obs(),
                           meta_state.deployed)
```

## 3. 推导

**引理 19（校准曲面的区域有效性）** 在 A99 下，R69 的点证书只保证 |C(w′,q′) − C(w0,q0)| ≤ L_w·TV + L_q·W1。故存在有效半径 r_cal（定义 312）：球内证书成立，球外 ECE 保证失效。系：**"部署时在线 ECE 看起来正常"不能替代区域证书**，因为真 ECE 需要模式标签，部署时不可得；R69 的 MCG 是 r = 0 的点测量。

**引理 20（可辨识阈值与配比的两难）** 在分离度 Δ_min、模态内尺度 σ_in、有效维 d 下，区分真模式与噪声需 n_k = Ω((σ_in/Δ_min)^d log(1/β))（非参数簇分离率）。故 w_k 过小 ⇒ 坍缩概率不可忽略；但把稀有层权重抬得过高，等价于放大该层的投毒杠杆与幻影稳定性（定义 317）。于是总风险 R(w) = P_collapse(w) + γ·P_phantom(w) 不是任何单个 w_k 的单调函数，存在内点最优。**这解释了为什么"多买稀有数据"并不总是更安全**，主动配比必须是带预算与投毒约束的鲁棒优化，而不是简单的"缺什么补什么"。

**引理 21（配比投毒的决策翻转阈值）** 若对手只改比例、总变差为 ε，则由引理 19 的 Lipschitz 性，要让 VoI 决策翻转（跨越 |ŵ_m − τ|）至少需要 ε ≥ |ŵ_m − τ| / L_w。但模式**存在性**的阈值更低：只要污染质量足以让一个簇跨过密度阈值，幻影即可出现，且 ACI 会随单源占比升高而升高。因此"可检测的投毒"与"能改变决策的投毒"之间存在一条**审计前沿**；多源鲁棒聚合把权重偏差的破坏点抬到 β_b，但不能自动修复存在性，必须叠加 ACI + 外部锚点。

**定理 18（路线图无回退 / 严格包含 R69）** 在 A99–A100 下，若 (i) 每阶段只在已认证区域 ℛ_t 内运行；(ii) 晋升要求全证据门 + 预注册一致；(iii) 运行时越界即降级到 S_{t−1} 的保守策略；(iv) 各阶段保守策略的安全侧不弱于 R68/R69；则任意部署轨迹都不会在未认证区域运行。且当元环关闭、w 固定、T = 0、锚点 = 当前配比时，MIXROAD 逐指令退化为 FLUID-RAS。故 R69 是本轮"单阶段、固定配比、无主动采数"的特例，安全侧不做任何让步。

**定理 19（自证飞轮与幻影吸引子）** 设 w_{t+1} = F(U(w_t))，且 F 把质量推向部署不确定性高的模式。若 U 完全内生（无外部锚点），则存在非空吸引域，使一个幻影模式获得正质量并自我维持：模型对它不确定 → 买它的数据 → 它在训练集中占比升高 → 模型对它更自信，而真实标签缺失时无法证伪。加入固定锚点比例 α 与探索下限 w_min 后，内生映射在 α ≥ α*（由 F 的 Lipschitz 常数决定）时收缩，幻影吸引子消失。系：**数据 VoI 必须在外生留出探针上计算，配比更新必须保留锚点与覆盖下限；纯部署不确定性驱动的主动配比不安全。**

**定理 20（区域扩张的样本复杂度下界）** 在 d_mix 维配比空间把认证半径从 r 扩到 r + Δr，需覆盖 𝒪((r/Δr)^{d_mix}) 个配比格点；每点估计校准误差需 𝒪(ε^{−2} log(1/δ)) 个带标签探针。故"路线图免费扩张有效域"不可能；每个阶段的认证域大小受数据预算硬约束。这为技术路线图给出可计算的成本下界，也解释了为何必须分阶段，而不能一次宣称全域可信。

## 6. 本轮最大风险

**一句话**：MIXROAD-RAS 把"可信"押在"配比可控 + 路线图可审计"上，但配比由部署不确定性驱动、部署不确定性又由旧配比训练的模型度量——**一旦外部锚点被同化、预注册被绕过、或压力族被过拟合，系统就会把"数据越配越自信"误读成"能力越来越强"，在错误的配比上逐级晋升出一张完美却与现实脱钩的证书；此时它比 R69 更危险，因为它不再只是"问错"，而是用一整套流程把错误制度化。**

**次级风险与缓解**：
1. **锚点被污染 / 被同化** → 锚点数据独立托管、定期轮换、指纹分离，且锚点不参与任何梯度更新；
2. **证书剧场（先开枪后画靶）** → 定义 322 预注册哈希 + 外部审计 + 阈值修改强制重审；
3. **压力族过拟合** → 压力族预注册且对参赛者不可见，定期注入未公开 held-out mix；
4. **可辨识阈值估计偏差** → n_min 用多重自助置信区间给出区间而非点，保守取上界；
5. **元环成本被低估** → 元环与实时环彻底解耦，任何预算超支只降级不占用实时路径；
6. **路线图僵化**（现实变化快于阶段） → 允许 fork 但禁止静默扩域，fork 必须重新预注册。

# IP-264 MCS：配比条件化校准曲面
class MixCalibrationSurface:
    def fit(self, w0, q0, margin):
        c0 = self.ece(w0, q0)
        Lw, Lq = self.estimate_lipschitz()          # 压力族上拟合，定义 312
        r = self.solve_radius(c0, Lw, Lq, margin)
        self.grid.append((w0, q0, c0, r)); return r
    def certified(self, w, q):
        return any(D_tv(w, w0) + W1(q, q0) <= r
                   for (w0, q0, c0, r) in self.grid)

# IP-265/266 MIM+MSA：模式四分类
def classify_modes(policy, D, probes, B=20):
    modes, out = policy.modes(D), {}
    for k in modes:
        nk  = effective_mass(k, D)
        mss = bootstrap_persistence(k, D, B)
        aci = attribution_concentration(k, D)
        if nk < n_min(k):                    out[k] = 'collapsed'
        elif mss < THETA_S or aci > THETA_C: out[k] = 'phantom'
        elif nk < N_COMFORT:                 out[k] = 'latent_ambiguous'
        else:                                out[k] = 'verified'
    for k in external_probe_modes(probes):       # 坍缩只能从外部看见
        if not matched_by_policy(k, modes):  out[k] = 'collapsed'
    return out

# IP-267/268 DVoI + 鲁棒主动配比（元环）
def data_voi(w, candidates, probes, sensitivity, cost):
    best = None
    for dw in candidates:
        score = expected_calibration_gain(probes, w, dw) * sensitivity - cost(dw)
        if best is None or score > best.score: best = (dw, score)
    return best if best and best.score > 0 else None    # 不划算就不买

def active_mix_step(w, stress_family, poison_risk, budget):
    w_star = argmin_robust(stress_family, poison_risk, budget)
    return simplex_project((1-ETA)*w + ETA*w_star,
                           lower=W_MIN, anchor=ALPHA)    # 覆盖下限 + 锚点

# IP-273 运行时监控与降级
def runtime_monitor(policy, obs, deployed):
    if not fingerprint_match(policy, deployed.h_w):    return demote(deployed)
    if not deployed.region.contains(obs.mix_estimate): return demote(deployed)
    if MIM.flags_collapse_or_phantom(policy, obs):     return demote(deployed)
    return deployed

# IP-275 双环主流程
def MIXROAD_round(real_time_loop, meta_state):
    k, lam, mode, U = real_time_loop.step()             # R69 实时环不动
    if meta_state.due():

                               meta_state.external_probes)
        if any(c in ('collapsed','phantom') for c in classes.values()):
            meta_state.freeze_and_audit(classes)        # 先冻住，别追幻影
        else:
            dw = DVoI.best(meta_state.w, meta_state.candidates,
                           meta_state.external_probes,
                           meta_state.sensitivity, meta_state.cost)

                w_next = AMC.step(meta_state.w, meta_state.stress_family,
                                  meta_state.poison_risk, meta_state.budget)
                meta_state = retrain_and_recalibrate(w_next)
        J = issue_certificate(meta_state)
        roadmap_gate(meta_state.stage, J, meta_state.prereg, meta_state.audit)
    return runtime_monitor(meta_state, real_time_loop.last_obs(), meta_state.deployed)
```

## 4. 推导

**引理 19（区域有效性）** A99 下 R69 点证书只保证 `|C(w′,q′)−C(w0,q0)| ≤ L_w·TV + L_q·W1`；故存在 `r_cal`。球外 ECE 保证失效。系："在线指标正常"不能替代区域证书，因为真 ECE 需模式标签，部署时不可得。

**引理 20（可辨识与配比两难）** 区分真模式需 `n_k = Ω((σ_in/Δ_min)^d log(1/β))`。w_k 过小 ⇒ 坍缩；抬得过高 ⇒ 放大投毒杠杆与幻影稳定性。`R(w)=P_collapse(w)+γP_phantom(w)` 存在内点最优；"多买稀有数据"不总是更安全。

**引理 21（比例投毒阈值）** 改比例 ε 使 VoI 决策翻转至少需 `ε ≥ |ŵ_m−τ|/L_w`；但模式存在性阈值更低，且 ACI 随单源占比升高。"可检测"与"能改变决策"之间存在审计前沿；鲁棒聚合抬升权重破坏点，但修不了存在性，必须叠加 ACI + 外部锚点。

**定理 18（严格包含 R69）** 每阶段只在认证区域运行、晋升需全证据 + 预注册、越界即降级、各阶段保守策略不弱于 R68/R69 ⇒ 任意轨迹不越界；元环关闭 / 配比固定 / T=0 时逐指令退化为 FLUID-RAS。R69 = 单阶段固定配比特例。

**定理 19（自证飞轮 / 幻影吸引子）** 若 `w_{t+1}=F(U(w_t))` 且 U 完全内生，则存在非空吸引域使幻影模式自我维持；加入锚点 α 与覆盖下限后，α ≥ α* 时内生映射收缩，幻影吸引子消失。系：**DVoI 必须外生，主动配比必须带锚点与下限。**

**定理 20（区域扩张样本复杂度下界）** 认证半径 r→r+Δr 需覆盖 `𝒪((r/Δr)^{d_mix})` 个格点，每点需 `𝒪(ε^{−2}log(1/δ))` 个带标签探针。故路线图不能免费扩域，认证域受数据预算硬约束。

## 7. 本轮最大风险

**一句话**：MIXROAD-RAS 把"可信"押在"配比可控 + 路线图可审计"上，但配比由部署不确定性驱动、部署不确定性又由旧配比训练的模型度量——**一旦外部锚点被同化、预注册被绕过、或压力族被过拟合，系统会把"数据越配越自信"误读成"能力越来越强"，在错误的配比上逐级晋升出一张完美却与现实脱钩的证书；它比 R69 更危险，因为它不再只是"问错"，而是用一整套流程把错误制度化。**

**次级风险与缓解**：锚点污染 → 独立托管 + 定期轮换 + 不参与梯度；证书剧场 → 预注册哈希 + 外部审计；压力族过拟合 → 预注册且对参赛者不可见 + 未公开 held-out mix；阈值估计偏差 → 自助置信区间保守取上界；元环成本 → 与实时环彻底解耦，超支只降级；路线图僵化 → 允许 fork 但禁止静默扩域，fork 必须重新预注册。
