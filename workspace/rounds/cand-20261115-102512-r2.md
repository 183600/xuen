# 第 5 轮（灵感循环第 2 轮；本轮灵感：「可用性评估」×「分层规划」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。第 3 轮 InstructGauge、第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。可用性与分层各只升级一条轴；可用性只影响「自主级别、解释粒度、块长预算」，**绝不改变物理可行域**；分层只提供「抽象—细化」结构，任一细化证书失效即压平回 v4。

## 0. 直觉与动机

**灵感 1（可用性评估 → 从「事后问卷」变成「可执行的机会约束」）**
直觉：v4 一直在优化「机器执行是否正确」，却没有回答「人是否用得起」。一个 100% 安全但每次都要求操作者接管、解释延迟三秒、事后说不清为什么的修复系统，在真实工位上会被弃用。可用性不是主观好感，而是一组**可观测的闭环量**：恢复时间 TTR、干预率 IR、认知负荷 CL、信任校准 TC、解释质量 EQ、态势感知 SA。关键洞察是：**可用性与自主级别并不单调**——全自主让人无法建立信任、也来不及接管；全手动又慢又累。二者之间存在一条 Pareto 前沿，系统应当**在线选择工作点**，而不是固定一个自主级别。更关键的是，可用性指标会被 Goodhart：减少解释可以降低打断率，却损害信任校准。所以必须用**预注册复合指标 + 独立审计队列 + 反事实扰动检验**，而不是把可用性压成一个可被优化的标量奖励。

严谨化的方向：把可用性写成向量 `u(π)` 与预算 `U*`，策略需满足机会约束 `P(L_u(π) ≤ U*) ≥ 1-δ`；用分层共形预测给出 TTR / 干预概率的区间，样本不足则退回保守固定级别。可用性只作为**门控与排序**，安全仍由 v4 的硬约束与不可逆屏障负责。

**灵感 2（分层规划 → 抽象降低决策开销，但细化处最容易漏安全）**
直觉：v4 的分块是「平铺」的：所有动作在同一层，块长只由一个漂移界决定。真实的盲区修复天然分层：mission（修好这个工位）→ subtask（先定位、再清洁、再复核）→ chunk（一段探测轨迹）→ primitive（单个关节/工具指令）。分层带来两个直接收益：抽象层搜索空间小，决策开销可摊薄；解释与干预有了自然粒度——对经理讲 mission，对工程师讲 subtask，对执行器讲 primitive。但分层也是**安全最容易泄漏的地方**：抽象规划器认为「清洁可达」，细化到原语层可能发现关节限位或碰撞。若直接把抽象计划当承诺，就会把错误藏进整棵分解树。

严谨化的方向：定义保守抽象 `α/γ` 与**细化证书 RefCert**，要求每个方法（method）的抽象后置条件在其所有原语细化下成立；RefCert 验证失败、样本不足或跨不可逆动作时，**整棵子树压平**为 v4 的逐步执行。分层只增加结构，不增加能力。

**灵感 3（耦合 → 可用性决定「人在哪一层介入」，分层决定「介入是否来得及」）**
直觉：可用性回答「人应不应该管、管多少」，分层回答「人在哪一层管、以什么粒度管」。最危险的耦合是：系统选择高自主级别 + 长块 + 高层解释，而操作者的反应时域根本覆盖不了当前块——形式上有人类否决点，实质上接管永远慢半拍。解法是三根结构支柱：**细化可靠**（RefCert 不通过就压平）、**可用性门控**（自主级别由带审计的机会约束选择，且有滞回）、**干预时域一致**（每层块时长必须落在所选自主级别的操作者反应时域内），再叠加**分层共形校准**与**解释忠实性证书**。这样分层提升可用性，但不会以细化漏洞为代价。

## 1. 研究问题（本轮要回答什么）

- **Q1（可用性是否可执行）**：可用性能否从离线问卷变成在线、可校准、可审计的门控信号，而不是新的 Goodhart 入口？
- **Q2（分层是否有净收益）**：分层规划在什么条件下既降低决策开销、又保持与平铺执行的安全等价？RefCert 的验证成本是否值得？
- **Q3（耦合是否放大误差）**：当可用性信号错误时，它是否会选错自主级别/层级，并沿分解树系统性放大？能否用审计、滞回与压平把它压回有界？

## 2. 三条设计原则（雏形，正式化见产物区定义 468–478）

**P1 细化可靠（Refinement Soundness）**
任何抽象计划 `P̄` 只有在携带有效 `RefCert` 时才可提交；`RefCert` 必须证明：对抽象状态的所有具体实现、以及该方法的全部原语细化，抽象前后置条件仍被满足。验证失败 ⇒ 该子树压平为 v4 的逐 chunk/逐步执行。这是「分层不改变能力」的类型级保证。

**P2 可用性作为门控而非奖励（Usability as Gate, not Reward）**
可用性向量 `u` 只用于**选择自主级别与解释粒度**，不进入动作奖励，不扩大可行域；门控必须使用预注册的复合损失、独立审计队列与反事实扰动检验。任何单项指标改善而审计指标不改善，一律判定为潜在投机并降级。

**P3 干预时域一致（Intervention-Horizon Consistency）**
设操作者反应时域的 p95 为 `H_ℓ`（自主级别 ℓ 下），层级 l 的块时长 `Δ_{l,K}` 必须满足 `Δ_{l,K} ≤ H_ℓ`，且块内检查点间隔不超过 `H_ℓ`。否则人类否决点在物理上来不及生效，等同于没有否决点；不可逆动作在该条件下强制 K=1。

## 3. 与基线的接口（如何退化）

- 可用性表不可用 / 样本不足 / 审计冲突 ⇒ 固定保守自主级别 L2，块长按 v4；
- 分层规划不可用 / RefCert 验证失败 / 跨不可逆屏障 ⇒ 整棵子树压平为 v4 的 WRC-ROS-7C；
- 解释证书缺失 ⇒ 只输出原始 CVC / SpatialCert，不生成自然语言理由；
- 分层共形样本不足 ⇒ 回退全局共形阈值；
- InstructGauge-WR 失效 ⇒ InstructGauge v3；InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge / MODGAUGE。

## 4. 预期贡献

1. 一个**可执行的可用性口径**：向量指标 + 机会约束 + 审计，把「好用」从主观评价变成可校准、可证伪的门控；
2. 一个**带细化证书的分层规划器**，证明抽象层安全可承载到原语层，失败时可一键压平；
3. 一个**可用性门控的混合主动控制**，在线选择自主级别与解释粒度，并给出干预时域约束；
4. 一条完整可证伪路径：E473–E490 覆盖可用性信度、细化可靠性、解释忠实性、信任校准、干预时域、Goodhart 审计、分层退化和 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：可用性指标只在小规模操作者队列上校准且天然可被投机，门控可能优化出一个「看起来好用、实际欠信任或漏安全」的工作点；一旦这个错误信号又决定了分层中的自主级别与块长，误差会沿整棵分解树系统性放大，而不是像单步错误那样可被下一条回执局部纠正。

## 2. 形式化定义（要点）

**定义 468（可用性向量与预算）** 对执行策略 `π`、任务 `x`、操作者 `o`，可用性向量
```
u(π;x,o) = (u_TTR, u_IR, u_CL, u_TC, u_EQ, u_SA) ∈ [0,1]^6
```
各分量归一化为越大越好。预注册复合损失为
```
L_u(π;x,o) = Σ_i w_i · max(0, u*_i − u_i(π;x,o)) + λ·1[SA < s_0 ∨ TC_over > c_0]
```
其中 `w_i, u*_i, s_0, c_0` 在实验前冻结；后两项是不可被加权抵消的硬地板。`U*` 为可用性预算。

**定义 469（ε-可用策略）** 给定任务分布 `D_x` 与操作者队列 `O`，
```
Usable_{ε,δ}(π) ⇔ P_{x~D_x, o~O}[ L_u(π;x,o) ≤ U* ] ≥ 1 − δ
```
注意这是**队列级**机会约束，不是对单个操作者的保证；个体差异由分层校准与自主级别吸收。

**定义 470（分层任务网络）** `H = (T, M, A, ≺)`，其中方法
```
m = (head(m), pre(m), subtasks(m), post(m), cons(m)) ∈ M
```
把任务 `head(m)` 分解为 `subtasks(m)`。分解树 `D` 的叶子是 `A` 中的原语；`frontier(D)` 为尚未展开的可执行计划。

**定义 471（保守抽象与细化证书）** 设抽象状态 `s̄ = α(s)`，`γ(s̄) = {s : α(s)=s̄}`。对抽象动作 `ā`，`ρ(ā)` 是其所有原语细化序列。细化证书
```
RefCert(ā) = (α, γ, ρ, Φ, κ, N, ε_s)
```
可靠当且仅当：
```
∀ s ∈ γ(s̄), ∀ a_{1:K} ∈ ρ(ā):
  pre(ā) ∧ Φ(s) ⇒ post(ā) 在 a_K 后成立 ∧ 轨迹始终留在 γ 内
```
`Φ` 为不变量集合，`κ` 为层级一致性条件（块时长、检查点间隔、不可逆屏障），`N, ε_s` 为统计验证的样本数与置信松弛。任一条件不成立即 `RefCert = ⊥`。

**定义 472（分层块与前缀封闭）** 层级 `l` 的块
```
C^(l) = (x_1 … x_{K_l}),  x_j ∈ frontier_{l−1}(D) ∪ A
```
要求 `∀ j ≤ K_l, C^(l)_{1:j}` 是合法前沿；且父子层级满足 `κ`：子块的所有前缀仍是父块对应步骤的合法细化。这样任意层级都能安全截断。

**定义 473（干预时域与可干预块）** 设操作者反应时域 `R_o`，`H_ℓ = p95(R_o | ℓ)`。块 `C` 在级别 `ℓ` 下**可干预**当且仅当
```
duration(C) ≤ H_ℓ  ∧  max_checkpoint_gap(C) ≤ H_ℓ
```
不可逆动作额外要求 `K=1` 且独立回执交叉验证。不可干预的块，其人类否决点在物理上无法及时生效。

**定义 474（可用性门控的自主级别）** 带滞回带宽 `h` 的门控为
```
ℓ_t = max { ℓ ∈ {L0,L1,L2,L3} :
            r̂(s_t, ℓ) ≤ ρ*  ∧  û_L(ℓ) ≤ U*  ∧
            RefCert(frontier) ≠ ⊥  ∧  C 在 ℓ 下可干预 }
```
若集合为空，强制 `ℓ = L2` 并把块长压到 `K=1`。切换需越过 `h` 才生效，避免在边界来回抖动。

**定义 475（解释忠实性证书）** 
```
HRC(C) = (why, what, how, evidence, confidence)
```
其中 `why` 对应 mission 级目标与约束，`what` 对应 subtask 级方法选择与替代方案，`how` 对应 primitive 级动作与证书。每个自然语言断言 `c` 必须携带证据链接 `λ(c)` 指向 `CVC`、`SpatialCert`、`RefCert` 或可用性区间的具体字段。**忠实性**要求 `λ(c) ≠ ⊥` 且 `c` 由该字段蕴含；无证据时输出「未知/不解释」，而不是补全理由。

**定义 476（分层共形校准）** 对每个 stratum `(l, ℓ, cohort)`，用 split conformal 给出 TTR 与干预概率的区间 `Ĉ_{1−α_l}`，要求
```
P( y ∈ Ĉ_{1−α_l} ) ≥ 1 − α_l
```
当该层样本数 `< n_min` 时，回退到全局阈值，并把该层标记为 `calibration=borrowed`。

**定义 477（Goodhart 审计散度）** 设独立审计向量 `v(π)`（不参与门控优化），扰动集合 `Π`（如隐藏解释、缩短解释、改变提示顺序）。定义
```
A(π) = max_{π'∈Π} ‖ norm(u(π)) − norm(v(π')) ‖_1
```
若复合目标改善而审计指标未同向改善（秩相关 `< ρ_min`），判定为潜在投机，门控强制降一级自主并记录审计事件。

**定义 478（v5→v4 压平算子）** 
```
D_{5→4}(D, ℓ, HRC) = (flatten(D), ℓ_0, ⊥)
```
即：把分解树按深度优先展开为平铺 chunk 序列，自主级别重置为 v4 默认，丢弃解释层。要求 `D_{5→4}` 与 v4 的 `instructgauge_wr` 在相同随机种子下产生**相同物理动作序列**。

## 3. 关键算法骨架

# IP-334 可用性计量器
class UsabilityMeter:
    def __init__(self, cohort, alpha=0.1):
        self.cohort = cohort
        self.alpha = alpha
        self.events = []

    def observe(self, ev):
        self.events.append(ev)                    # 干预/接管/解释请求/确认延迟
        return self.vector()

    def vector(self):
        ttr = estimate_ttr(self.events)
        ir = intervention_rate(self.events)
        cl = workload_proxy(self.events)          # 次级任务 + 接管次数
        tc = trust_calibration(self.events)       # 过信任/欠信任
        eq = explanation_quality(self.events)
        sa = situation_awareness_proxy(self.events)
        return normalize((ttr, ir, cl, tc, eq, sa))

    def loss(self, u):
        return composite_loss(u, self.cohort.weights, self.cohort.floors)

    def conformal_interval(self, key, y):
        return self.calibrator[key].interval(y, alpha=self.alpha)

# IP-335 / IP-336 分层规划与细化证书
class HTNPlanner:
    def plan(self, mission, state):
        tasks = self.decompose(mission, state)    # 抽象层搜索
        tree = DecompositionTree(root=mission)
        for t in tasks:
            m = self.select_method(t, state)
            tree.expand(t, m)
        return tree

    def select_method(self, task, state):
        for m in self.methods[task]:
            if not holds(m.pre, state):
                continue
            cert = RefCertChecker.verify(m, state, budget=self.cert_budget)
            if cert is not None:
                return m, cert
        return None

class RefCertChecker:
    @staticmethod
    def verify(method, state, budget):
        for s in sample_concretizations(alpha(state), N=budget.N):
            for seq in refinements(method, max_len=budget.K):
                if not simulate_contract(seq, s, method.post, method.cons):
                    return None
                if not level_consistent(seq, method.cons):
                    return None
        return RefCert(method, budget.N, budget.eps_s)

# IP-337 可用性门控
class UsabilityGate:
    def __init__(self, levels=("L0", "L1", "L2", "L3"), hysteresis=0.05):
        self.levels = levels
        self.h = hysteresis
        self.current = "L2"

    def select(self, state, planned, cert, u_hat, risk_hat):
        feasible = []
        for lv in self.levels:
            if risk_hat[lv] > self.rho_star:
                continue
            if u_hat[lv] > self.U_star:
                continue
            if cert is None or not intervenable(planned, lv):
                continue
            feasible.append(lv)
        if not feasible:
            return "L2", force_single_step(planned)
        best = feasible[-1]
        if abs(rank(best) - rank(self.current)) < self.h:
            best = self.current
        self.current = best
        return best, planned

# IP-338 解释证书
def build_hrc(tree, cvc, spatial_cert, ref_cert, usability_ci):
    why = link_claims(tree.root, cvc.post_conditions, "mission")
    what = link_claims(tree.frontier, ref_cert.invariants, "method")
    how = link_claims(tree.leaves, spatial_cert.violations, "primitive")
    claims = why + what + how
    for c in claims:
        if c.evidence is None:
            c.text = "unknown"                    # 无证据不解释
    return HRC(why, what, how, [c.evidence for c in claims],
               min_confidence(usability_ci))

# IP-340 HUG-8C 主闭环
def instructgauge_hu(M, s, ell=None):
    iota = M.nlib.ground(ell, M.scene, M.ontology) if ell else M.default_iota

    # 1. 分层规划（可选增强）
    tree = M.htn.plan(mission(s, iota), M.env.state())
    if tree is None or not M.refcert.all_valid(tree):
        return M.instructgauge_wr(s, ell)          # 压平回 v4

    # 2. 可用性预测与门控
    u_hat = M.usability.predict(tree, M.cohort)
    risk_hat = M.risk.predict(tree)
    level, plan = M.gate.select(M.env.state(), tree.frontier, tree.cert,
                                u_hat, risk_hat)

    # 3. 逐层执行：每个边界重新验证，不信任旧证书
    receipts = []
    for node in plan.levels(level):
        C = node.to_chunk()
        if level in ("L1", "L2") and not intervenable(C, level):
            C = C.truncate_to_horizon(M.H[level])
        if not M.refcert.recheck(node, M.env.state()):
            return M.instructgauge_wr(s, ell)      # 边界失效即压平
        C, sc, claims = M.wrc.execute(C, iota)     # v4 的 WRC-ROS-7C
        receipts += claims
        M.usability.observe(interaction_event(level, C, sc))
        if M.usability.loss(M.usability.vector()) > M.U_star:
            level, C = M.gate.demote(level)        # 可用性超预算：降级
    M.audit.record(M.usability.vector(), M.usability.audit_vector())

    hrc = build_hrc(tree, receipts, M.wrc.last_spatial_cert,
                    tree.cert, M.usability.last_ci)
    return tree, hrc, receipts

def InstructGauge_HU_round(M, obs, audio, tac, depth, det, ell=None):

## 4. 推导

**引理 63（细化可靠性沿分解树组合）** 若分解树 `D` 的每个内部节点都携带有效 `RefCert`，且每个原语执行满足其契约，则根任务的后置条件成立，且整条具体轨迹留在根抽象的逆像内。
证明：对树高归纳。叶子由原语契约直接给出；内部节点由 `RefCert` 的定义 471，把子节点的后置条件提升为父方法的后置条件，并保持 `γ` 包含关系。归纳假设给出子树轨迹在各自 `γ` 内，`Φ` 在边界处闭合，故父节点成立。关键前提是 `RefCert` 必须对**全部** `ρ(ā)` 成立而非采样平均；这由定义 471 的全称量词保证。

**引理 64（门控的建模风险单调性）** 在风险预测 `r̂` 对动作集单调、且低自主级别使用可行动作子集并增加强制否决点的假设下，`ℓ` 降低不会提高建模风险：`rank(ℓ') ≤ rank(ℓ) ⇒ r̂(s,ℓ') ≤ r̂(s,ℓ)`。
证明：低级别策略集是高级别的子集（只减少可选动作），并额外插入检查点（只增加否决机会）；`r̂` 对集合包含单调。注意这是**建模风险**，不包含人类操作失误；人类失误由 `TC` 与自主级别分层校准单独度量。

**引理 65（干预时域的必要性）** 若 `duration(C) > H_ℓ`，则操作者的否决在块完成后才可能到达；在 p95 意义下该块的人类干预有效权威为零。
证明：否决最早在 `t_start + R_o` 生效，块在 `t_start + duration(C)` 完成。若 `duration(C) > p95(R_o)`，则至少 95% 的否决晚于完成。因此对 L1/L2，长块提供的「人在环」只是形式上的；对不可逆动作，这种形式主义直接等价于无否决。

**引理 66（层级有效块长）** 在漂移界 `K_drift`、反应时域 `H_ℓ`、证书预算 `K_cert` 与不可逆屏障下，
```
K*_l = min( K_drift, ⌊H_ℓ / Δt_l⌋, K_cert, K_irr )
```
且 `K*_{l+1} ≤ K*_l`（更粗层级不放大单位时间动作数）。
证明：四项分别来自漂移、干预时域、细化证书与不可逆性；取最小即同时满足。层级越粗，`Δt_l` 越大，但 `H_ℓ` 与 `K_cert` 不随层级放松，故单调性成立。

**引理 67（解释忠实性）** 由定义 475 构造的 `HRC` 中，每个非「未知」断言都由某个证书字段蕴含；因此不会出现无证据的因果归因。
证明：构造时逐条检查 `λ(c)`，缺失即替换为「未知」；蕴含关系由证书的语义定义给出。注意这是**可靠性**而非完备性：证书未覆盖的真实原因可能不被解释。

**引理 68（退化等价性）** 关闭分层 / 细化证书 / 可用性门控 / 分层共形，分别逐字回到：v4 平铺 chunk、v4 的 `plan_chunk`、固定自主级别、全局共形阈值；因此
```
v5 ⇒ v4 ⇒ v3 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE
```
且 `D_{5→4}` 在相同种子下与 v4 产生相同物理动作序列。
证明：各关闭开关后，剩余调用图与 v4 的 `instructgauge_wr` 同构；压平算子只改变计划表示，不改变动作顺序与证书内容。

## 5. 复杂度分析

| 组件 | 域 | 时间 | 空间 | 正确性锚 |
|---|---|---|---|---|
| Usability-Meter | 交互 | O(1)/事件 + O(n) 区间更新 | O(n_events) | 定义 468–469 |
| HTN-Planner | 规划 | O(|T|·|M| + 抽象搜索) | O(|D|) | 定义 470 |

`RefCert` 的验证在最坏情况下对细化集合是指数的；因此实现中限制 `N, K, |ρ|`，并对超预算方法直接返回 `⊥`（压平），把「验证不起」显式变成「不用分层」，而不是静默跳过。

## 8. 本轮最大风险

**一句话**：可用性只在有限操作者队列上校准且指标可被投机，分层又让同一个错误信号同时决定自主级别、块长与解释粒度；一旦门控选中了错误的工作点，误差会沿整棵分解树系统性放大，而压平回 v4 只能止损、不能纠正已经建立的错误信任与错误抽象。
