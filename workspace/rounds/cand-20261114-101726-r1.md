# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「位姿估计」×「嵌入式系统」）

> R69 把不确定性一分为二，并让系统学会「问」：aleatoric 收紧、epistemic 去交互消解，还把流似然当成一条标定吸收不了的第二意见。但 R69 仍踩在一个未经审视的假设上——**它讨论的不确定性是统计意义上的，而它运行的计算基底是理想化的**。两个盲点：
> - **位姿**：真实机器人的大量不确定性既不是「噪声」也不是「两个意图」，而是**几何上根本没看清**（白墙、共线特征、正对平面靶标、运动模糊）。这类不确定性再问、再平均都不会消失，只有**换个视角/激励**才消失；更阴险的是，位姿病态会**污染** R69 赖以判断「歧义大不大」的模态间距估计，使系统把「看不清」误判成「不歧义」，从而自信地做错。
> - **嵌入式**：R68/R69 的所有证书（U、λ、ECE、流似然、P99 延迟）都默认了 GPU、float64、无穷时间。放到 MCU 上，**证书本身也是一段要赶在截止期前跑完、且要能比特级复现的程序**；一旦为了守时把昂贵检查跳过却仍宣称「已认证」，安全层就成了掩盖故障的帮凶——这与 R68 标定吸收、R69 模态未校准是同一类错误的第三次化身。
>
> 核心命题：**不确定性还有第三根轴——几何可观测性 U_geo；且所有层的不确定性处置都必须「在地认证」：证书必须在被认证的同一基底上、以确定性数值与可界定的最坏执行时间算出，跑不完就必须诚实地把对应不确定度当作未消解，退回更保守的旧层。** 命名 **PLUMB-RAS**（Pose-grounded, Latency-certified, Uncertainty-split, Manifold-aware, Budget-honest Risk-Adaptive System；plumb = 铅垂线/测深，既是「真值基准」也是「探一探」）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我真的看清了吗，而且我还有时间和算力把这件事算完吗**」——不确定性既可以是刹车、是提问，也可以是一次挪动视角、一个「本次未检查」的诚实标记。

## 0. 直觉与动机

**灵感 1（位姿估计 → 第三类不确定性：几何可观测性）**
直觉：R69 的 U_ale 是「同一件事重复看会抖」，U_epi 是「两件事都说得通」。但在白墙前、正对平面靶标、特征点全共线、或相机运动模糊时，位姿的解不是抖、也不是两可，而是**沿某个方向根本没被约束**——你手里有一个数值、一个协方差，甚至一个「置信度」，但对那条近零空间方向，再多帧、再高分辨率、再多次询问都毫无帮助。人不会站在原地反复问「这是不是墙」，人会**挪一步、换个角度**。所以这必须成为第三类：**结构性/几何不确定性 U_geo**，它的解药不是平均也不是提问，而是**激励（excitation / next-best-view）**。
严格地说，位姿估计是 SE(3) 上的非线性最小二乘，残差雅可比 J∈ℝ^{m×6} 给出 Fisher 信息 I=JᵀWJ；其特征值谱直接暴露可观测性。病态（κ=λ_max/λ_min 大）或近奇异（λ_min→0）不是噪声大小问题，而是**信息矩阵的形状问题**。

**灵感 2（位姿病态会污染 R69 的「歧义判断」——本轮最锋利的失败机制）**
直觉：R69 用模态间距 Δ_min 判断「歧义是否可分」，从而决定去不去交互。但「模态间距」是在某个坐标系里量出来的；坐标系本身若病态，两条本可分的动作轨迹可能在观测里**被压到一起**（假「不歧义」），也可能被**拉开**（假歧义）。前者致命：系统认为「没有歧义」→ 不交互 → 直接用错误位姿下选出的单一模态。也就是说，**几何上的看不清，会伪装成意图上的很确定**。
严格地说，帧的不确定性对轨迹簇的作用近似一个随机刚体变换；Wasserstein 距离的扰动被该变换幅度界住，因而 Δ̂ = Δ ± O(√tr Σ_T)。当 √tr Σ_T 与 Δ 同量级，Δ_min 的符号/量级都不可信，U_epi 必须置为「未解上界」而不是「很小」。

**灵感 3（嵌入式系统 → 证书本身也是一段要被认证的实时程序）**
直觉：R69 里 λ_floor、ECE、流似然、mode_head 都是「算出来的数」，仿佛算它们不要钱。可部署到 Cortex-M7/RTOS 上：控制环 1 kHz、预算 1 ms，流匹配的 K=4 采样根本排不进；更要命的是——**为了赶上截止期而悄悄跳过昂贵检查、却仍然输出一份「合格」证书**，这正是 R68（标定吸收慢变故障）、R69（模态未校准）之外的第三种「安全层说谎」。解法只有一条：把流水线劈成**硬实时内核**（位姿残差、帧闭合、U_ale、λ_floor、认证前缀、确定性哈希，WCET 可界）与**软实时增值件**（流采样、聚类、VoI、Hutchinson），并给每个软件一个**证据位**；没跑就把该位清 0，并把对应不确定度取**上界**。于是「没时间查」在数学上等价于「当作没查过、因此更保守」——**预算诚实（budget-honest）**。

**灵感 4（数值基底会制造「假 aleatoric」与「不可回放的证书」）**
直觉：定点量化的舍入误差看起来像噪声，但它是**确定性的、可标定的**；真 aleatoric 才是不可约的。把量化误差当噪声会平白抬高 λ（保守但低效），把真噪声当量化而扣掉则会削弱裕度（危险）。同时，浮点归约不满足结合律、DVFS/中断会让同一输入算出不同比特——一份不能**逐比特复现**的证书，审计时根本无法回放，等于没有证据。所以数值层必须显式区分：量化底噪 σ_q（已知、可测）、真噪声、以及**值确定性/时序确定性**这两个独立维度。

**灵感 5（坐标系 → 「被认证的错误」；帧-时对偶）**
直觉：位姿永远是「相对某个坐标系」的。一个自信的位姿加上一个错的坐标系，是所有状态里最可怕的一种：数值自洽、统计检验全过，但整个世界被转了一下/翻了一下（x/y 轴互换、四元数符号翻转，都是嵌入式固件里最经典的 bug）。R66–R69 从未把坐标系形式化。同理，时间戳错位（钟漂）会让位姿误差正比于运动速度。妙处在于：**空间帧错是随速度不变的常数项，时间错是随速度增长的斜率项**——于是「帧闭合残差 vs 速度」的截距/斜率，正好把两类故障分开。这是 R69 的 (r_res, Δa) 对偶判据在几何-时间维度的镜像。
并且，只有**闭合**才能验证：任何坐标变换环（world→base→cam→target→world）在精确算术下必须复合为单位阵，闭合残差就是一颗常开的几何完整性心脏监护仪。

**灵感 6（包含关系 → 新层必须是旧层的严格泛化）**
直觉：R69 是「U_geo=0、算力无限、算术精确、坐标系完美」的边界情形；R68 再是其中「永不交互」的边界。PLUMB 不允许在任何边界上比旧层更激进：所有新增通道只能**增加**证据、只能**收紧** λ 或提供**有证书的** resolution bonus；缺证据一律回退。这是本轮的纪律：**每加一根不确定性轴，必须附赠一个可证明的退化路径**，否则就是在安全栈上再叠一个需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（PLUMB-RAS 总览）** PLUMB-RAS = (PGL, GEO, MDA†, EAX, MINT†, SCE, EBL, NCP, DTA, FTA, FTD, SCS, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 276-i）；
(ii) **在地认证**：安全关键证据只能由运行在同一目标基底上的确定性内核产生，离岸（离线/异基）证书仅作建议，不得置位安全关键证据位；
(iii) **预算诚实**：任何软检查未执行 ⇒ 对应证据位清 0 ⇒ 对应不确定度取上界，λ 单调不降；
(iv) **帧闭合常开**：任意变换环的闭合残差若越界，立即判坐标/时间故障，进入最保守层。

**定义 311（位姿与坐标系代数）** 位姿 T=(R,t)∈SE(3)，但一律写作带类型的 `T_{A←B}`（把 B 系坐标映到 A 系），附 `(t_stamp, provenance, basis_id)`。姿态信念用流形上的集中分布（如 se(3) 局部坐标高斯）表示，均值取 Karcher/Fréchet 均值而非算术平均。复合 `∘` 做运行时帧类型校验；环 `T_{A←B}∘T_{B←C}∘T_{C←A}` 应≈I。

**定义 312（几何可观测性 U_geo）** 位姿估计的残差雅可比 J 与权 W，Fisher 信息 I=JᵀWJ∈ℝ^{6×6}，特征对 (λ_i,u_i) 降序。条件数 κ=λ_1/λ_6；退化方向集 D={u_i:λ_i<λ_*}（λ_* 由可容忍位姿误差与噪声水平定）。定义 `U_geo = log κ + ρ·|D|`（严格模式下 |D|>0 即 U_geo=∞）。**关键性质：U_geo 不随同几何下的帧数增加而下降**，只随激励（改变几何）下降。

**定义 313（三分解与门控层级）** U_ale 同 R69（模态内不可约）；U_epi 同 R69（模态间可约）；新增 U_geo（结构不可观测）。处置顺序**必须**是：先算 U_geo，再由它**门控** U_epi。若 `√tr Σ_T > τ_pose` 或 `κ>κ_*`：令 U_epi := U_epi^ub（未解上界），禁止用观测到的 Δ_min 做「不歧义」推断；否则按 R69 正常分解。理由见引理 19：病态位姿会**压低** Δ̂ 从而**低估** U_epi。

**定义 314（激励动作与几何 VoI）** 增广信息动作扩展为 `g=(g_gaze,g_probe,g_ask,g_ex)`，其中 g_ex∈SE(3) 为小位移/换视角。几何收益 `GeoGain(g_ex)=E[tr Σ_T − tr Σ_T(g_ex)]`（或 D-最优：max E[det I(g_ex)]）。综合选择 `g* = argmax_g [VoI_intent(g) + w_geo·GeoGain(g) − c(g)]`，s.t. g 通过 C-RAS-WM 认证、位移 ≤ ε_g、时间窗未过。**激励本身可能是危险动作**（挪动会撞、会失稳），故认证优先级高于收益：认证不过则 g_ex 作废，U_geo 维持未解。

**定义 315（硬核/软核实时劈分与 WCET）** 硬实时内核 `K_hard={位姿残差, 帧闭合, U_ale 更新, λ_floor, 认证前缀, 确定性哈希}`，其 WCET 界为 W_hard；软增值件 `S={流采样, 模态聚类, VoI 枚举, Hutchinson}`，各自 WCET 为 W_s，控制截止期 D。可调度性约束：`W_hard + Σ_{s∈S_act} W_s + blocking ≤ D`。超预算时在 S 上解 0/1 背包：最大化证据价值、满足时限；未选中的检查**显式清位**。

**定义 316（证据位格与预算诚实）** 证据位向量 B∈{0,1}^{|S|}。保守不确定度泛函
`Ū(B) = U_ale + [b_geo]·U_geo + [b_epi]·U_epi^{obs} + [¬b_epi]·U_epi^{ub} + ...`，
缺位一律取**上界**。性质：`B₁⊆B₂ ⇒ Ū(B₁) ≥ Ū(B₂)`（引理 20）。故任何只清位的降级都安全；反之，清掉计算却不清位的证书是**伪造**（定义 325 拒绝该证书）。

**定义 317（在地认证与值/时序确定性）** 证书由目标基底上的确定性内核产生，须同时满足跨界面的两个维度：
(a) **值确定性**：同输入比特 ⇒ 同输出比特（用整数/定点内核或固定归约树，禁 FMA 收缩、禁依赖 DVFS 的路径）；
(b) **时序确定性**：存在有效 WCET 界并留出 slack。
证书记录 `(substrate_id, clock_hz, precision_mode, per_bit_provenance)`；离岸计算的证据位只能取 0（建议位）。

**定义 318（数值底噪与量化分解）** 定点步长 q 的单通道舍入标准差 `σ_q=q/√12`，经链路传播得数值底噪 `U_num`。观测噪声 `σ_obs² = σ_ale² + q²/12`（近似独立）。**纪律：不做减法**；仅当 `U_num ≤ α·U_ale`（如 α=0.2）才认为 aleatoric 估计可信，否则标记 **resolution-limited**（瓶颈在硬件分辨率而非统计），走保守层，并建议换传感器而不是加算力。

**定义 319（确定性审计与回放哈希）** 证书字节的哈希 `H(C)`。同一输入在两次运行（可选跨核/跨电源态）必须 `H` 相同；不同 ⇒ 证书无效（相关位清 0，回退）。证书落盘用**哈希链**（前一轮 H 进入下一轮），使流式审计可回放、可追责。

**定义 320（坐标系闭合残差）** 对任一变换环 C=(T_{A←B}∘…∘T_{·←A})，令 `E=∏T`，`ε=log_SE3(E)∈ℝ⁶`，`r_frame=‖ε‖`。常开监测。精确算术下 r_frame=0；越 `τ_frame` 即坐标/标定/时间异常。

**定义 321（帧-时对偶判别）** 在窗口内收集 `(运动幅度 v_k, r_frame,k)`，拟合 `r_frame ≈ a + b·v`。**b>0 且显著 ⇒ 时间同步/钟漂故障**（平移误差 ≈ v·τ）；**a>0 且显著 ⇒ 空间坐标系/约定故障**（轴交换、符号翻转，约与速度无关）。据此分流：时间故障→重标时间偏移、加宽时间戳不确定度；空间故障→拒绝该位姿、重锚定坐标系。这是 R69 (r_res,Δa) 的几何-时域镜像。

**定义 322（流式证书摘要）** 内存上界 M_max 下，仅维持 O(d²)/O(1) 充分统计：定点 Welford 均值/协方差、WCET 直方图与分位、模态权重的 count-min sketch、哈希链。禁止缓冲全历史；证书体积恒定，适配 MCU SRAM。

**定义 323（姿态门控的流形模态分解）** 采样轨迹 ξ 按流形结构聚类：动作部件在 SE(3)×ℝ^{d} 上取 Fréchet/Karcher 原型；Δ_min 在**位姿归一化帧**内测量；先过定义 313 门控。若门控判未解，则不输出模态权重（避免下游误用），只输出 `U_epi^ub`。

**定义 324（三级预算诚实退避）**
- L1（全部证据、κ≤κ_*、确定性通过）：`λ=λ_floor(U_ale)`，得 resolution bonus（R69 最优路径）；
- L2（U_epi 未解 / U_geo 中等 / 部分软位缺）：`λ=λ_floor(U_ale + U_epi^ub + U_geo)`；
- L3（U_geo 退化 / 帧闭合越界 / 确定性或时序失守）：`λ=max(λ_floor, λ_slow)`（R68 缓变故障路径），必要时 hold/safe-stop。
层级随证据缺失**单调不降**。R68 ≡ 恒 L3；R69 ≡ 无 U_geo 的 L1/L2。

**定义 325（证书 J_PLUMB）** `J_PLUMB = (J_FLUID, κ_pose, U_geo, bitset, substrate_id, value_hash, wcet_slack, frame_closure_p95, numeric_floor_ratio, frame_time_slope, plumb_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 时序达标 ∧ 值哈希复现 ∧ 帧闭合达标 ∧ 证据位与 Ū 一致`。凡「计算的位=0 却据此宣称低不确定度」⇒ 伪造，置 Invalid。

**定义 326（干扰集 ℰ_PLUMB）** `ℰ_PLUMB = ℰ_FLUID × ℰ_geo × ℰ_frame × ℰ_time × ℰ_substrate`：
- ℰ_geo：退化几何攻击（白墙、共线特征、正对平面靶、强运动模糊）诱导假确定；
- ℰ_frame：坐标系投毒（轴交换、四元数符号、隐藏平移偏置）；
- ℰ_time：钟漂 / 时间戳错位 / 传感器不同步；
- ℰ_substrate：DVFS/热节流致超时、定点溢出、位翻转、静默数值漂移。

**定义 327（严格包含映射 Φ）** `Φ: PLUMB→FLUID` 在「U_geo=0、全证据位=1、值比特确定、帧完美、算力无限」时逐指令等价；`Φ: FLUID→CALM` 在「永不交互」时等价。故 `Risk(PLUMB) ≤ Risk(FLUID) ≤ Risk(CALM)`（定理 18），且安全侧永不更激进。

## 2. 关键算法骨架

```python
# IP-264 PGL：SE(3) 位姿信念（带坐标系 provenance；硬核）
class PoseBelief:
    def update(self, obs):
        T, J, W = self.gauss_newton(obs)              # W 为测量权
        S = frozenset((self.frame, obs.frame))        # 帧类型
        return TypedPose(T, S, obs.t_stamp, prov=obs.src), J, W

# IP-265 GEO：可观测性分析（6x6 特征分解；硬核）
def geometric_observability(J, W, lam_star, rho=1.0):
    I      = J.T @ W @ J
    lam, U = eigh_sym(I)                              # 升序
    kappa  = lam.max() / max(lam.min(), 1e-12)
    degen  = [U[:, i] for i in range(6) if lam[i] < lam_star]
    U_geo  = log(kappa) + rho * len(degen)
    return U_geo, kappa, degen

# IP-266 MDA†：位姿门控的模态分解（软核；门控通过才可调用）
def decompose_pose_gated(samples, pose, Sigma_T, tau_pose, tau_geo, U_geo):
    if sqrt_trace(Sigma_T) > tau_pose or U_geo > tau_geo:
        return None, U_epi_upper_bound(samples)       # 禁止用 Δ̂ 推「不歧义」
    modes = manifold_cluster(samples)                 # SE(3)×R^d Fréchet 原型
    w     = mode_weights(modes)
    U_ale = sum(w[k] * trace(cov(modes[k])) for k in modes)
    U_epi = entropy(w) * sep_factor(modes)            # 位姿归一化帧内测距
    return (U_ale, U_epi, modes), None

# IP-267/268 EAX + MINT†：含「激励」的 VoI 选择（软核）
def choose_info_action(modes, pose, Sigma_T, budget):
    best = None
    for g in candidates(modes):                       # gaze / probe / ask / excite
        if not budget.allow(g):                      continue
        if not c_ras_wm.certify_info(g, pose):       continue   # 激励也过安全认证
        voi  = entropy(modes) - expected_entropy(modes, g)
        geo  = geo_gain(Sigma_T, g)                   # 期望 trΣ 下降 / D-最优
        cost = social_cost(g) + physical_cost(g)
        s    = voi + W_GEO * geo - cost
        if best is None or s > best.s: best = (g, s)
    return best if best and best.s > 0 else None       # 无利可图 → 不开销

# IP-269 SCE：硬/软劈分与截止期调度（硬核决策）
def schedule(hard, soft, D, W):
    if W[hard] + W.blocking > D:                       # 连安全核都排不进
        return KERNEL_ONLY, bits_all_zero()            # 强制 L3
    bits, t = ones(), W[hard] + W.blocking
    for s in sorted(soft, key=evidence_value, reverse=True):  # 价值密度背包
        if t + W[s] <= D: bits[s], t = 1, t + W[s]
        else:             bits[s] = 0                  # 未跑 ⇒ 清位
    return bits, t

# IP-270 EBL：预算诚实的保守不确定度（缺位取上界；硬核）
def conservative_uncertainty(bits, U):
    U_bar = U.ale
    U_bar += U.geo if bits.geo else U.geo_ub
    U_bar += U.epi if bits.epi else U.epi_ub
    U_bar += U.num if bits.num  else U.num_ub
    return U_bar                                        # 单调：少证据只会更大

# IP-271/272 NCP + DTA：数值底噪与确定性/时序审计（硬核）
def numeric_floor(q, chain, alpha, U_ale):
    U_num = propagate(q / sqrt(12), chain)
    resolution_limited = U_num > alpha * U_ale           # 不做减法，只判可信度
    return U_num, resolution_limited

def deterministic_certificate(build):
    h1 = sha256(build())                                 # 定点 + 固定归约树
    h2 = sha256(build())
    return h1 if h1 == h2 else None                      # None ⇒ 证书无效

# IP-273/274 FTA + FTD：帧闭合与帧-时判别（硬核）
def frame_closure(cycle):                                # cycle: [T_{A←B}, ...]
    E = compose_all(cycle)                               # 应 ≈ I
    return norm(log_se3(E))                              # r_frame

def frame_time_signature(window):                        # [(v_k, r_frame,k)]
    a, b = lstsq([v for v, _ in window], [r for _, r in window])
    if b > tau_b and a <= tau_a: return "TIME_SYNC"      # 误差 ∝ 速度
    if a > tau_a and b <= tau_b: return "FRAME_SPATIAL"  # 误差与速度无关
    if a > tau_a and b > tau_b: return "BOTH"
    return "OK"

# IP-276 主闭环：硬核先跑，软件按证据位可选，缺位即退回
def PLUMB_round(M, obs, D):
    # --- 硬实时内核（必须完成） ---
    T, J, W        = M.pgl.update(obs)
    r_frame        = M.fta.closure(M.cycles)
    U_geo, kappa, Dg = M.geo.analyze(J, W, M.lam_star)
    U_num, res_lim = M.ncp.floor(M.q, M.chain, M.alpha, M.U_ale_prev)
    if r_frame > M.tau_frame:
        return M.safe_hold(J_PLUMB(L3, frame=r_frame))    # 帧故障：立即最保守
    # --- 调度软件，得到证据位 ---
    bits, t_used   = M.sce.schedule(M.hard, M.soft, D, M.W)
    # --- 软件（可能被裁；未跑则位=0） ---
    if bits.epi and kappa <= M.kappa_star:
        (U_ale, U_epi, modes), ub = M.mda.decompose(obs, T, M.Sigma_T)
    else:
        U_ale, U_epi, modes, ub = M.U_ale_prev, 0.0, None, M.epi_ub
    g = (M.mint.choose(modes, T, M.Sigma_T, M.budget)
         if (bits.voi and U_epi > M.tau_epi) else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # --- 预算诚实的保守不确定度与分级 ---
    level  = pick_level(bits, kappa, res_lim, r_frame)
    U_bar  = M.ebl.conservative_uncertainty(bits, U)
    lam    = level_lambda(level, U_bar, M.lam_floor, M.lam_slow)
    k      = M.c_ras_wm.certified_prefix(M.ach.propose(T, M.vista.H), ...)
    mode   = M.select_mode(modes, U_epi, lam)
    # --- 证书：值确定性 + 时序 + 阴影审计 ---
    cert   = J_PLUMB(M.fluid_cert, kappa, U_geo, bits, M.substrate,
                     M.dta.hash(), D - t_used, r_frame, U_num, M.fts.slope)
    return k, lam, mode, cert
```

## 3. 推导

**引理 19（几何门控：病态位姿会压低模态间距）** 设真实模态原型间距为 Δ，位姿信念协方差 Σ_T（`s=√tr Σ_T`）。轨迹簇经一个由 Σ_T 诱导的随机刚体变换后，其 Wasserstein 距离满足 `|Δ̂−Δ| ≤ c·s`（c 由簇直径与帧条件数界住）。因 R69 中 `U_epi=H_mode·g(Δ_min)` 且 g 对 Δ 单调增，当 Δ̂ 被向下偏置时 U_epi 被**低估**；极端情形（退化方向与模态分离方向对齐）两簇可被**合并**，产生「假不歧义」。故需 `s ≤ τ_pose` 才允许用 Δ̂ 推断，否则 U_epi:=上界。系：**几何看不清会伪装成意图很确定**——这是 R69 未覆盖、也最危险的一类误判。

**引理 20（证据位单调性与预算诚实）** 由定义 316，B₁⊆B₂ ⇒ Ū(B₁)≥Ū(B₂)。λ_floor 对自变量单调不减 ⇒ 同一状态下清位只会让 λ 增大、认证前缀只会缩短。故任何「只清位、不隐位」的截止期降级都不降低安全性。逆命题：若某检查未执行却仍置位（或据此宣称低 U），则 Ū 小于真实上界，该状态的安全性不再被定理 18 覆盖——这正是「证书伪造」的形式定义（定义 325 判 Invalid）。

**引理 21（量化可辨识性与确定性审计必要性）** (a) 设 `σ_obs²=σ_ale²+q²/12`，则 σ_ale 可辨识当且仅当 `q²/12 ≤ α·σ_obs²`；估计误差量级 `O(q²/(σ_obs²√N))`，q 主导时不可分，只能标记 resolution-limited。(b) 浮点归约/动态电压频率使「同输入不同输出」成为可能，故可回放审计的证书必须走确定性整数内核；否则同一物理事件可对应两份不同判决，审计失效。

**定理 18（PLUMB 严格包含 FLUID 与 CALM）** 在 A100–A105（策略 Lipschitz、U_geo 有界、WCET 界有效、帧闭合在 r>τ_frame 时可检、量化底噪可界定）下，对任意状态 `Risk(PLUMB) ≤ Risk(FLUID) ≤ Risk(CALM)`；当 `U_geo=0`、全部证据位置 1、值比特确定、帧完美、算力无限时，PLUMB 与 FLUID **逐指令相同**。证明要点：PLUMB 与 FLUID 用同一策略；其 λ 的自变量为 Ū ≥ R69 的 U；激励动作是可选的且须过 C-RAS-WM 认证，只在有证据时提供受引理 16 约束的 resolution bonus；其余新增通道只增不减保守度。边界条件使 Ū 退化为 R69 的 U，逐指令相同。

**定理 19（帧-时可分性）** 设 `r_frame ≈ ‖a + b·v + ξ‖`，空间约定误差贡献常数项 a（轴交换/符号/平移偏置，约与速度无关；随空间尺度变化），时间同步误差贡献 `b·v`（平移 ≈ v·τ、旋转 ≈ ω·τ）。在激励使速度跨越足够范围时，最小二乘的 (a,b) 可辨识；检测功效随速度方差增大。故 (a,b) 的截距/斜率把「坐标系错」与「钟漂」分开，二者需要完全不同的修复动作（重锚定 vs 重对时）。

**定理 20（硬核可调度与无突变）** 若 W_hard（含中断阻塞与内存抖动的有效 WCET 界）满足 `W_hard+blocking ≤ D`，且硬核算术确定，则安全内核必在截止期前完成；由于降级只清位、λ 单调不降、认证前缀与 R68 定理 15 的换装不变式保持，控制量随证据丢失**连续**，无行为突变。系：把「来不及」变成「更保守」，而不是「悄悄跳过」。

## 6. 本轮最大风险

**一句话**：PLUMB 把安全押在「我们能给出**可信的 WCET 界与确定性保证**」上——但在带缓存、中断、DVFS、热节流的真实 MCU 上，WCET 分析极易给出**过于乐观的界**，值确定性也可能被未建模的浮点/加速器路径破坏；一旦界是错的，系统就会**带着满分证书超时运行或用另一套数值算出另一个判决**，安全层于是从「诚实地不知道」升级为「**以全副信心说谎**」——认证的谎言，比未认证的无知危险得多。

**次级风险与缓解**：
1. **U_geo 过度保守导致瘫痪**（纹理稀少环境不敢动）→ 把「不动」也纳入 C-RAS-WM 认证，并允许有界激励；瘫痪是安全失败，可接受但需 E302/E303 标定。
2. **激励动作本身不安全**（挪动会撞/失稳）→ 激励必须过认证，且优先于收益；认证失败即维持未解（定义 314）。
3. **量化底噪主导被误当噪声** → 不做减法，只判 resolution-limited，并触发硬件升级建议（定义 318）。
4. **帧闭合监测被共谋标定吸收**（所有帧一起偏）→ 闭合只能抓「环内不自洽」，若整环同偏需外部基准（重力/已知标定物）；以 ℰ_frame 对抗训练 + E313 验证。
5. **证据位被错误置位 / 证书伪造** → 定义 325 强制「位=0 ⇒ 不得宣称低 U」，哈希链回放 + E305/E306 双跑校验。

| `J_PLUMB = (J_FLUID, κ, U_geo, bitset, substrate, value_hash, wcet_slack, r_frame, U_num, b_slope, ver)` | 证书 |

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** PLUMB-RAS；继承零学习写操作；在地认证（安全关键证据只能由同基底确定性内核置位）；预算诚实（未跑⇒清位⇒上界）；帧闭合常开。

**定义 311–313（位姿 / U_geo / 三分解门控）** 带类型 SE(3) 信念；`I=JᵀWJ`，`U_geo=logκ+ρ|D|`；处置顺序**先 U_geo 门控 U_epi**：病态（`√trΣ_T>τ_pose ∨ κ>κ_*`）时 U_epi 取上界，禁用「不歧义」推断（引理 19）。

**定义 314–315（激励 / 硬软劈分）** `g=(g_gaze,g_probe,g_ask,g_ex)`；`g*=argmax[VoI+w_geo·GeoGain−c]`，激励须过 C-RAS-WM；`K_hard` WCET W_hard，约束 `W_hard+ΣW_s+blocking≤D`，超预算则在软件上解 0/1 背包。

**定义 316–317（证据位 / 在地认证）** `Ū(B)` 缺位取上界，`B₁⊆B₂⇒Ū(B₁)≥Ū(B₂)`；证书须同时满足值确定性（比特复现）与时序确定性（WCET），记录每证据位基底 provenance；离岸证书只能作建议位。

**定义 318–319（量化底噪 / 确定性审计）** `σ_obs²=σ_ale²+q²/12`；不做减法，仅当 `U_num≤α·U_ale` 才信 aleatoric，否则 resolution-limited；证书双跑哈希必须一致，否则判无效并回退。

**定义 320–321（帧闭合 / 帧-时判别）** `r_frame=‖log_SE3(∏T)‖` 常开；拟合 `r_frame≈a+b·v`：斜率显著⇒钟漂，截距显著⇒空间帧错，双显著⇒两者都有。分别对应「重对时」与「重锚定」。

**定义 322–323（流式摘要 / 流形分解）** O(d²) 充分统计 + 哈希链，恒定证书体积；SE(3)×ℝ^d 上 Fréchet 原型、位姿归一化帧内测 Δ_min，先过门控再输出。

**定义 324–325（三级退避 / 证书）** L1 `λ=λ_floor(U_ale)`；L2 `λ=λ_floor(U_ale+U_epi^ub+U_geo)`；L3 `λ=max(λ_floor,λ_slow)`（必要时 hold）。层级随证据缺失单调不降。`J_PLUMB` 扩展 J_FLUID；凡「位=0 却宣称低 U」⇒ 伪造，Invalid。

**定义 326–327（干扰集 / 包含映射）** `ℰ_PLUMB=ℰ_FLUID×ℰ_geo×ℰ_frame×ℰ_time×ℰ_substrate`；`Φ:PLUMB→FLUID→CALM` 在边界逐指令一致，风险序 `PLUMB≤FLUID≤CALM`。

## 3. 关键算法伪代码

```python
# IP-264/265 PGL+GEO（硬核）
def pose_and_geo(obs, lam_star):
    T, J, W = gauss_newton_se3(obs)                  # 帧类型/时间戳/provenance 自带
    I = J.T @ W @ J
    lam, U = eigh_sym(I)                             # 升序
    kappa  = lam.max() / max(lam.min(), 1e-12)
    degen  = [U[:, i] for i in range(6) if lam[i] < lam_star]
    return T, J, W, log(kappa) + len(degen), kappa   # U_geo, κ

# IP-266 MDA†（软核，门控后）
def decompose_pose_gated(samples, Sigma_T, U_geo, tau_pose, tau_geo):
    if sqrt_trace(Sigma_T) > tau_pose or U_geo > tau_geo:
        return None, upper_bound_U_epi(samples)      # 禁用 Δ̂ 推「不歧义」
    modes = manifold_cluster(samples)                # SE(3)×R^d Fréchet 原型
    w = mode_weights(modes)
    return (sum(w[k]*trace(cov(modes[k])) for k in modes),
            entropy(w)*sep_factor(modes), modes), None

# IP-267/268 EAX+MINT†（软核）
def choose_info_action(modes, Sigma_T, budget):
    best = None
    for g in candidates(modes):                      # gaze/probe/ask/excite
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        s = (entropy(modes) - expected_entropy(modes, g)
             + W_GEO*(trace(Sigma_T) - expected_trace(Sigma_T, g)) - cost(g))
        if best is None or s > best.s: best = (g, s)
    return best if best and best.s > 0 else None     # 无利可图 → 不开销

# IP-269/270 SCE+EBL（硬核）
def schedule_and_bound(hard, soft, D, W, U):
    if W[hard] + W.blocking > D:
        return zero_bits(), U.ale + U.geo_ub + U.epi_ub + U.num_ub   # 强制 L3
    bits, t = ones(), W[hard] + W.blocking
    for s in sorted(soft, key=value_density, reverse=True):
        if t + W[s] <= D: bits[s], t = 1, t + W[s]
        else:             bits[s] = 0                # 未跑 ⇒ 清位
    U_bar = (U.ale
             + (U.geo if bits.geo else U.geo_ub)
             + (U.epi if bits.epi else U.epi_ub)
             + (U.num if bits.num else U.num_ub))
    return bits, U_bar                                # 单调：少证据只会更大

# IP-272/273/274 DTA+FTA+FTD（硬核）
def frame_closure(cycles):
    return norm(log_se3(compose_all(cycles)))         # 应≈0；越界即故障

def frame_time_signature(window):                     # [(v_k, r_frame,k)]
    a, b = lstsq([v for v, _ in window], [r for _, r in window])
    return ("TIME_SYNC" if b > tau_b and a <= tau_a else
            "FRAME_SPATIAL" if a > tau_a and b <= tau_b else
            "BOTH" if a > tau_a and b > tau_b else "OK")

# IP-276 主闭环
def PLUMB_round(M, obs, D):
    T, J, W, U_geo, kappa = pose_and_geo(obs, M.lam_star)     # 硬核
    r_frame = frame_closure(M.cycles)                         # 硬核
    U_num, res_lim = M.ncp.floor(M.q, M.chain, M.alpha, M.U_ale)  # 硬核
    if r_frame > M.tau_frame:
        return M.safe_hold(J_PLUMB(L3, frame=r_frame))        # 帧故障→最保守
    bits, U_bar = schedule_and_bound(M.hard, M.soft, D, M.W, M.U)
    if bits.epi and kappa <= M.kappa_star:
        (U_ale, U_epi, modes), ub = decompose_pose_gated(obs, M.Sigma_T,
                                                          U_geo, M.tau_pose, M.tau_geo)
    else:
        U_ale, U_epi, modes, ub = M.U_ale, 0.0, None, M.epi_ub
    g = (M.mint.choose_info_action(modes, M.Sigma_T, M.budget)
         if (bits.voi and U_epi > M.tau_epi) else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    level = pick_level(bits, kappa, res_lim, r_frame)
    lam   = level_lambda(level, U_bar, M.lam_floor, M.lam_slow)
    k     = M.c_ras_wm.certified_prefix(M.ach.propose(T, M.vista.H), ...)
    mode  = M.select_mode(modes, U_epi, lam)
    cert  = J_PLUMB(M.fluid_cert, kappa, U_geo, bits, M.substrate,
                    M.dta.hash(), D - M.sce.t_used, r_frame, U_num, M.fts.slope)
    return k, lam, mode, cert
```

## 4. 推导

**引理 19（几何门控）** 位姿协方差 Σ_T（`s=√trΣ_T`）使轨迹簇经历随机刚体变换，`|Δ̂−Δ|≤c·s`。R69 的 `U_epi=H·g(Δ_min)` 对 Δ 单调增，故 Δ̂ 向下偏置会**低估** U_epi；退化方向与模态分离方向对齐时两簇可合并，产生「假不歧义」。故须 `s≤τ_pose` 才信 Δ̂，否则 U_epi 取上界。**系：几何看不清会伪装成意图很确定。**

**引理 20（证据位单调 / 预算诚实）** `B₁⊆B₂⇒Ū(B₁)≥Ū(B₂)`，λ_floor 单调 ⇒ 清位只增 λ、只缩认证前缀。故「只清位、不隐位」的截止期降级不降安全性；未执行却置位即「证书伪造」（定义 325 判 Invalid）。

**引理 21（量化可辨识 / 确定性审计）** `σ_obs²=σ_ale²+q²/12`，σ_ale 可辨识当且仅当 `q²/12≤α·σ_obs²`；q 主导时不可分，只能标记 resolution-limited。浮点归约/DVFS 可致同输入异输出，故可回放证书须走确定性整数内核。

**定理 18（PLUMB 严格包含 FLUID/CALM）** A100–A105 下 `Risk(PLUMB)≤Risk(FLUID)≤Risk(CALM)`；当 `U_geo=0`、全证据位=1、值比特确定、帧完美、算力无限时逐指令相同。证明要点：同策略；λ 自变量 `Ū≥U`；激励可选且须过认证，收益受引理 16 约束；其余通道只增不减保守度。

**定理 19（帧-时可分）** `r_frame≈‖a+b·v+ξ‖`：空间约定误差贡献常数 a，时间同步误差贡献 `b·v`（平移 v·τ、旋转 ω·τ）。速度跨足够范围时 (a,b) 可辨识，检测功效随速度方差增大。二者修复动作不同：重锚定 vs 重对时。

**定理 20（硬核可调度 / 无突变）** 若 `W_hard+blocking≤D` 且硬核算术确定，则安全内核必在截止期前完成；降级只清位、λ 单调不降、认证前缀与换装不变式保持 ⇒ 控制量随证据丢失连续、无行为突变。**系：把「来不及」变成「更保守」，而非「悄悄跳过」。**

## 7. 本轮最大风险

**一句话**：PLUMB 把安全押在「能给出可信 WCET 界与确定性保证」上——但在带缓存、中断、DVFS、热节流的真实 MCU 上，WCET 分析极易给出**过于乐观的界**，值确定性也可能被未建模的浮点/加速器路径破坏；一旦界是错的，系统会**带着满分证书超时运行、或用另一套数值算出另一个判决**，安全层从「诚实地不知道」升级为「**以全副信心说谎**」——认证的谎言比未认证的无知危险得多。

**次级风险与缓解**：U_geo 过度保守致瘫痪（把「不动」也纳入认证，允许有界激励；E302/E303）；激励动作本身不安全（激励须过 C-RAS-WM，认证优先于收益）；量化底噪主导被误当噪声（不做减法，只判 resolution-limited，触发硬件升级建议）；帧闭合被共谋标定吸收（整环同偏需外部基准——重力/已知标定物；ℰ_frame 对抗训练 + E313）；证据位错误置位/证书伪造（定义 325 强制「位=0 ⇒ 不得宣称低 U」，哈希链回放 + E305/E306 双跑）。
