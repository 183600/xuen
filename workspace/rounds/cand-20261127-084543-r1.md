### 第 2 轮灵感驱动研究记录（在 v25 SRC-USC 基础上推进）

**灵感词**：续航能力、边缘计算

**直觉与动机**：
v25 已把结构-力控-轻量、语义、重构、多机协同统一为 SRC-USC 七证准入门，但能量维度仍停留在「瞬时余量」E_res ≥ margin_req，没有回答两个时间尺度的问题：其一，长时任务的续航——电池老化（SoH）、热降额、充电/换电物流如何被形式化保证；其二，证书验证本身的算力、时延与电量开销——边缘-云协同并不是免费算力。受「续航能力」启发：**续航不是剩余电量，而是证书链在时间轴上可持续发放的最长视界**；受「边缘计算」启发：**边缘卸载不是白得算力，而是用通信能量、尾部时延与信任风险去置换机载计算能量**。核心洞见：**续航与边缘是一对对偶预算——边缘卸载节省的机载能量必须扣除通信/排队/证明代价；任何续航证书都必须把「验证证书」的能量与时限计入自身开销，否则证书会耗尽它所承诺的续航。**

**形式化目标**：
1. 定义续航-电池健康证书（EBHC）：以 (SoC_t, SoH_t, T_t) 为状态，建立能量、退化、热三动力学，输出可证续航下界 T_end(π, σ) ≥ T_task + Δ_safe，并把证书自检能量作为固定开销。
2. 定义边缘计算卸载证书（ECOC）：卸载决策 o_v ∈ {0,1}，端到端时延 D_up + D_q + D_comp + D_down ≤ D_deadline；边缘队列稳定 λ_j < μ_j 且 P99 排队时延有界；净机载能量收益 ΔE(o) ≥ ΔE_min。
3. 定义分割验证-信任证书（SVTC）：验证谓词划分 V = V_loc ⊔ V_edge，边缘证明需签名、输入绑定、新鲜度 τ_fresh 与可组合性（局部证明 ∧ 边缘证明 ⇒ 整体证明）。
4. 构建续航-边缘统一准入门（EEUC）：EEUC = SRC-USC ∪ EBHC ∪ ECOC ∪ SVTC，Exec_v26 ⊆ Exec_v25。
5. 证明电池退化/热降额、卸载超时/队列溢出、边缘失信/证明过期三条新退化路径下，单调退化链保持。
6. 给出续航-边缘联合调度：MINLP → 凸松弛 + 截止期感知舍入 + 证书复核，滚动时域执行。

**本轮的严谨化切口**：把「能量」从标量预算升级为带时间索引的区间可达集，把「边缘」从通信链路升级为带排队论界与证明可信度的验证资源；两者在证书层面首次以「验证开销」耦合，而不是事后相加。

```python
# ============================================================
# IP-448 Endurance & Battery-Health Certificate (EBHC)
# ============================================================
@dataclass
class EnduranceBatteryHealthCertificate:
    """电池三动力学 + 区间能量可达集 + 可证续航下界"""
    soc: float; soh: float; temp: float
    Q_nom: float; E_nom: float
    soc_min: float = 0.15; soh_min: float = 0.80; temp_max: float = 45.0
    dt: float = 0.1
    max_horizon: int = 10_000
    delta_safe: float = 60.0            # 续航安全裕度 (s)
    power: 'PowerEnvelope' = None       # 每相位的 [P_lo, P_hi]
    degradation: 'DegradationEnvelope' = None
    thermal: 'ThermalEnvelope' = None
    recharge: Optional['RechargeSchedule'] = None
    cert_overhead_w: float = 0.0        # 证书自检/证明传输平均功率

    def _reserve(self) -> float:
        return self.soc_min * self.E_nom * self.soh_min

    def _energy_interval(self, plan, t: int, temp: float) -> tuple[float, float]:
        p_lo, p_hi = self.power.interval(plan, t, temp)
        return p_lo + self.cert_overhead_w, p_hi + self.cert_overhead_w

    def verify_energy(self, plan, horizon: Optional[int] = None) -> bool:
        """区间前向传播：实际能量 ∈ [e_lo, e_hi]；只要 e_lo 不破备即安全。"""
        H = horizon or len(plan)
        e_lo = e_hi = self.soc * self.E_nom * self.soh
        cap = self.E_nom * self.soh
        for t in range(H):
            p_lo, p_hi = self._energy_interval(plan, t, self.temp)
            e_lo -= self.dt * p_hi
            e_hi -= self.dt * p_lo
            if self.recharge is not None:
                e_lo += self.dt * self.recharge.min_power(t)   # 保守：少充
                e_hi += self.dt * self.recharge.max_power(t)   # 保守：多充
            e_hi = min(e_hi, cap)
            e_lo = max(e_lo, 0.0)
            # 热降额后允许功率还必须覆盖后续需求（见 verify_thermal）
            if e_lo < self._reserve():
                return False
        return True

    def verify_degradation(self, plan) -> bool:
        """保守退化上界：SoH_end ≥ SoH_0 - f_deg^max(cycles, T, H)"""
        cycles = self._rainflow_cycles(plan)
        d_soh = self.degradation.max_degradation(
            cycles=cycles, temp=self.temp, duration=len(plan) * self.dt)
        return self.soh - d_soh >= self.soh_min

    def verify_thermal(self, plan) -> bool:
        temp = self.temp
        for t in range(len(plan)):
            _, p_hi = self._energy_interval(plan, t, temp)
            temp = self.thermal.max_next_temp(temp, p_hi, self.dt)
            if temp > self.temp_max:
                return False
            # 热降额：后续可用功率必须被计划能量需求包住
            if t + 1 < len(plan):
                _, need_lo = self._energy_interval(plan, t + 1, temp)
                if self.thermal.p_allow(temp) < need_lo:
                    return False
        return True

    def _feasible_prefix(self, plan, H: int) -> bool:
        return (self.verify_energy(plan, H) and
                self.verify_degradation(plan[:H]) and
                self.verify_thermal(plan[:H]))

    def certified_endurance(self, plan) -> int:
        """对单调可行性做二分；不可行前缀之外一律不承诺。"""
        lo, hi = 0, min(self.max_horizon, len(plan))
        while lo < hi:
            mid = (lo + hi + 1) // 2
            lo, hi = (mid, hi) if self._feasible_prefix(plan, mid) else (lo, mid - 1)
        return lo

    def verify_horizon(self, plan, T_task: float) -> bool:
        return self.certified_endurance(plan) * self.dt >= T_task + self.delta_safe

    def verify_recharge_logistics(self, plan) -> bool:
        if self.recharge is None:
            return True
        # 充电点可达性 + 排队等待上界 + 换电库存下界
        return (self.recharge.all_reachable(plan) and
                self.recharge.queue_bound() <= self.recharge.wait_max and
                self.recharge.inventory_lower_bound() >= self.recharge.inv_min)

    def verify_all(self, plan, T_task: float) -> bool:
        return (self.verify_horizon(plan, T_task) and
                self.verify_degradation(plan) and
                self.verify_thermal(plan) and
                self.verify_recharge_logistics(plan))

# IP-449 Edge Computation Offloading Certificate (ECOC)
# ============================================================
@dataclass
class EdgeComputationOffloadingCertificate:
    """任务 DAG 部分卸载：截止期 + 队列稳定 + 净能量收益"""
    dag: 'TaskDAG'
    offload: dict[str, bool]
    edge_map: dict[str, int]
    net: 'NetworkEnvelope'                 # R_up/R_down/编码/解码时延
    edges: list['EdgeProfile']             # f_j, μ_j, 当前负载, delay_max
    deadline_slack: float = 0.0
    delta_E_min: float = 0.0               # 要求的最小净机载能量收益 (J)
    p_local: float = 0.0; p_tx: float = 0.0
    p_rx: float = 0.0; p_sleep: float = 0.0
    cert_overhead_j: float = 0.0           # 验证/证明本身的能量开销

    def _edge_latency(self, v: str, t0: float) -> float:
        j = self.edge_map[v]
        e = self.edges[j]
        d_up = self.net.b_v(v) / self.net.r_up + self.net.t_enc
        d_q = e.delay_bound(self.net.arrival(v))      # 网络演算：σ/(μ-ρ)+τ
        d_comp = self.dag.w_v(v) / e.effective_flops(self.net.arrival(v))
        d_down = self.net.out_v(v) / self.net.r_down + self.net.t_dec
        return d_up + d_q + d_comp + d_down

    def _local_latency(self, v: str) -> float:
        return self.dag.w_v(v) / self.dag.f_loc

    def verify_deadline(self) -> bool:
        finish: dict[str, float] = {}
        for v in self.dag.topological_order():
            est = max((finish[u] for u in self.dag.pred(v)), default=0.0)
            lat = self._edge_latency(v, est) if self.offload[v] else self._local_latency(v)
            finish[v] = est + lat
            if finish[v] > self.dag.deadline(v) - self.deadline_slack:
                return False
        return True

    def verify_queue_stability(self) -> bool:
        for j, e in enumerate(self.edges):
            rho = sum(self.net.arrival_rate(v) for v in self.dag.V
                      if self.offload[v] and self.edge_map[v] == j)
            if rho >= e.mu_j:                       # 队列不稳定
                return False
            for v in self.dag.V:
                if self.offload[v] and self.edge_map[v] == j:
                    if e.delay_bound(self.net.arrival(v)) > e.delay_max:
                        return False
        return True

    def verify_energy_benefit(self) -> bool:
        saved = -self.cert_overhead_j
        for v in self.dag.V:
            if not self.offload[v]:
                continue
            j = self.edge_map[v]; e = self.edges[j]
            d_up = self.net.b_v(v) / self.net.r_up + self.net.t_enc
            d_down = self.net.out_v(v) / self.net.r_down + self.net.t_dec
            d_edge = (e.delay_bound(self.net.arrival(v)) +
                      self.dag.w_v(v) / e.effective_flops(self.net.arrival(v)))
            e_off = self.p_tx * d_up + self.p_rx * d_down + self.p_sleep * d_edge
            saved += self.p_local * self._local_latency(v) - e_off
        return saved >= self.delta_E_min

    def verify_all(self) -> bool:
        return (self.verify_deadline() and
                self.verify_queue_stability() and
                self.verify_energy_benefit())

# IP-450 Split Verification & Trust Certificate (SVTC)
# ============================================================
@dataclass
class SplitVerificationTrustCertificate:
    """验证分割 + 边缘证明的签名/绑定/新鲜度/可组合性"""
    partition: dict[str, str]                 # predicate -> 'local' | 'edge'
    attestations: dict[str, 'Attestation']    # 边缘谓词 -> 证明
    trusted_roots: set[str]
    tau_fresh: float = 0.5                    # s
    delta_edge: float = 1e-9                  # 允许的声音性误差
    critical: set[str] = field(default_factory=set)

    def verify_local(self, certs: dict, ctx: dict) -> bool:
        return all(certs[p].verify(ctx) for p, side in self.partition.items()
                   if side == 'local')

    def verify_edge(self, ctx: dict, now: float) -> bool:
        for p, side in self.partition.items():
            if side != 'edge':
                continue
            att = self.attestations.get(p)
            if att is None:
                return False
            if not att.verify_signature(self.trusted_roots):
                return False
            if now - att.ts > self.tau_fresh:          # 新鲜度
                return False
            if att.h_in != stable_hash(ctx, p):        # 输入绑定，防 TOCTOU
                return False
            if att.ctr < self._last_ctr(p):            # 单调计数器，防重放
                return False
            if p in self.critical:
                # 关键谓词不接受"信任"，只接受可验证计算或 TEE 证明
                if not (att.tee_quote.verify() or att.vc_proof.verify()):
                    return False
            if not att.result:
                return False
        return True

    def verify_composition(self, certs: dict, ctx: dict, now: float) -> bool:
        """(V_loc ∧ V_edge) ⇒ V；任一失败即整体拒证并回退本地。"""
        return self.verify_local(certs, ctx) and self.verify_edge(ctx, now)

    def committed_soundness_error(self) -> float:
        """边缘证明只允许贡献 δ_edge；超出预算则降级为整证本地复核。"""
        edge_cnt = sum(1 for s in self.partition.values() if s == 'edge')
        return edge_cnt * self.delta_edge

# 续航-边缘联合调度：MINLP → 凸松弛 → 截止期感知舍入 → 证书复核
# ============================================================
class EnduranceAwareOffloadingMPC:
    def __init__(self, ebhc, ecoc, svtc, horizon: int, dt: float):
        self.ebhc, self.ecoc, self.svtc = ebhc, ecoc, svtc
        self.horizon, self.dt = horizon, dt

    def plan(self, ctx: dict) -> tuple[dict, bool]:
        # 1) 松弛 o∈[0,1]，固定 σ 与轨迹，凸化能量/时延约束，ADMM 分解到边缘节点
        o_relaxed = self._convex_relaxation(ctx)
        # 2) 截止期感知舍入：按"能量收益/时延占用"比排序，贪心取 0/1
        o = self._deadline_aware_rounding(o_relaxed, ctx)
        # 3) 只有通过证书复核的卸载方案才允许下发（证书是门，不是事后检查）
        if not self._rebuild_ecoc(o, ctx).verify_all():
            return self._all_local(ctx), False
        # 4) 若边缘证明过期/失信，退回本地验证，必要时收缩任务视界
        if not self.svtc.verify_edge(ctx, ctx['now']):
            return self._all_local(ctx), False
        return o, True

# 端到端流水线增量：在 SRC-USC 之后追加续航-边缘闭环
# ============================================================
class EnduranceEdgePipeline:
    def __init__(self, config: dict):
        self.src_pipeline = config['src_pipeline']
        self.eeuc = EnduranceEdgeUnifiedCertificate(
            src_usc=config['src_usc'],
            ebhc=config['ebhc'],
            ecoc=config['ecoc'],
            svtc=config['svtc'])
        self.mpc = EnduranceAwareOffloadingMPC(
            config['ebhc'], config['ecoc'], config['svtc'],
            config['horizon'], config['dt'])
        self.ipam.register_module("ebhc", ["IP-448"],
            ["battery_health", "endurance_lower_bound", "certificate_self_energy"])
        self.ipam.register_module("ecoc", ["IP-449"],
            ["partial_offload", "network_calculus_deadline", "net_energy_benefit"])
        self.ipam.register_module("svtc", ["IP-450"],
            ["split_verification", "attestation_freshness", "verifiable_composition"])
        self.ipam.register_module("eeuc", ["IP-451"],
            ["endurance_edge_gate", "triple_degradation_chain"])

    def step(self, sensor: dict, ctx: dict, T_task: float) -> tuple[bool, dict]:
        # 1) SRC-USC 七证
        ok, info = self.src_pipeline.step(sensor)
        if not ok:
            return False, {'stage': 'src_usc', 'info': info}
        # 2) 续航预检：不满足则收缩任务/请求换电，而不是硬跑
        if not self.eeuc.ebhc.verify_all(info['plan'], T_task):
            return False, {'stage': 'endurance', 'reason': 'EBHC_reject',
                           'action': 'shrink_task_or_recharge'}
        # 3) 边缘卸载滚动规划（证书门控）
        offload, offload_ok = self.mpc.plan(ctx)
        # 4) 统一准入
        admitted = self.eeuc.admits(
            self._attach_offload(info['plan'], offload), ctx, T_task, ctx['now'])
        return admitted, {
            'stage': 'eeuc', 'offload': offload, 'offload_certified': offload_ok,
            'endurance_horizon_s': self.eeuc.ebhc.certified_endurance(info['plan']) * self.eeuc.ebhc.dt,
            'cert_overhead_w': self.eeuc.ebhc.cert_overhead_w,
            'edge_soundness_budget': self.eeuc.svtc.committed_soundness_error()}
```

**实时性论证**：续航证书不在控制频率上重算——它按「事件 + 低频率」触发（换电、SoH 更新、任务切换），滚动视界 H 仅在规划层更新；控制层只做 O(1) 的剩余续航/热余量查表。边缘卸载证书随任务 DAG 更新，DAG 频率远低于 50Hz 控制环。关键路径新增的是 SVTC 的证明校验（只对 ≤5 个关键谓词），可预计算并缓存，P99 增量控制在 5ms 内。

## 3. 正确性论证（增量）

### 引理 13（EBHC 的区间-退化-热三重声音性）
**陈述**：若 EBHC 的功率区间包络满足 P_actual(t) ∈ [P_lo(t), P_hi(t)]，退化包络满足 ΔSoH_actual ≤ f_deg^max，热包络满足 T_next ≤ T_next^max，则 `verify_all(π,T_task)=True` ⇒ 对 ∀t ≤ T_task：SoC_t ≥ SoC_min，SoH_t ≥ SoH_min，T_t ≤ T_max，且 T_end(π,σ) ≥ T_task + Δ_safe。

**证明**：
1. 能量：归纳。e_lo(0)=实际 E(0)；若 e_lo(t) ≤ E_actual(t)，则 e_lo(t+1)=e_lo(t)-Δt·P_hi+Δt·min_power ≤ E_actual(t)-Δt·P_actual+Δt·charge = E_actual(t+1)，故 e_lo 是下界。`verify_energy` 保证 e_lo ≥ reserve，故实际 SoC 不破下限。
2. 退化：雨流计数给出循环数上界，f_deg^max 对温度与倍率取保守包络，故实际容量保持率不低于证书下界。
3. 热：`verify_thermal` 用最大功率推进温度，并用 p_allow(T) 覆盖后续需求，故实际温度与降额均不越界。
4. 续航：`certified_endurance` 通过二分找最大可行前缀，可行性对前缀单调（同一计划截短只会减少能量/退化/热需求），故返回值是真实可行视界的下界；加上 Δ_safe 得证。∎

### 引理 14（ECOC 的截止期-队列-能量三重声音性）
**陈述**：若网络演算的到达曲线 (σ_j,ρ_j) 与实际流量一致、服务曲线下界为 μ_j(t-τ)^+、功率上界被能量模型包住，则 `ECOC.verify_all()=True` ⇒ 每个任务在 d_v 前完成、每个边缘队列稳定且 P99 时延 ≤ delay_max、净机载能量收益 ≥ ΔE_min。

**证明**：
1. 时延：网络演算定理给出 backlog/delay 上界；当 ρ_j<μ_j 时，排队时延 ≤ σ_j/(μ_j-ρ_j)+τ。`verify_deadline` 用该上界与有效算力做 DAG 列表调度，若每任务 finish≤d_v，则实际完成时间（≤模型上界）也满足截止期。
2. 队列：ρ_j<μ_j 是队列稳定性的充分条件；delay_bound≤delay_max 直接约束 P99。
3. 能量：`verify_energy_benefit` 逐任务计算「本地计算能耗 − (上行+下行+待机+证明) 能耗」，并扣除 cert_overhead_j；若总和 ≥ ΔE_min，则由功率上界知实际收益不低于证书值。∎

### 引理 15（SVTC 的分割-绑定-新鲜-可组合性）
**陈述**：若 (i) 本地谓词在本地执行且可信；(ii) 边缘证明签名可验证、输入哈希绑定当前上下文、时间戳满足 τ_fresh、计数器单调；(iii) 关键谓词使用 TEE 或可验证计算；(iv) 边缘至多贡献 δ_edge 的声音性误差，则 `verify_composition=True` ⇒ 整体证书以误差 ≤ δ_edge 成立。

**证明**：
1. 输入哈希绑定排除 TOCTOU：证明针对 h_in 而非旧输入，上下文改变即失效。
2. 新鲜度与单调计数器排除重放：过期证明与旧计数器证明被拒。
3. 签名/TEE/VC 排除伪造：非可信边缘无法构造通过校验的证明。
4. 组合性：整体谓词 V = ⋀_{p∈V_loc} p ∧ ⋀_{p∈V_edge} p；本地全真、边缘全真且误差预算 ≤δ_edge，故整体以该误差成立。若任一假设破裂，`verify_edge=False`，系统退回 V_loc ∪ 本地复核，不产生「错误通过」。∎

### 引理 16（续航-边缘单调退化链）
**陈述**：`Exec_v26 ⊆ Exec_v25`，且在电池退化/热降额、卸载超时/队列溢出、边缘失信/证明过期及其组合下，系统均退化到 v25 的保守可执行集而不越界。

**证明**：EEUC 的准入是 SRC-USC 与三个新过滤器的合取，故 Exec_v26 ⊆ Exec_v25。
- SoH 跌破 / 热降额 → EBHC 拒证 → 收缩任务视界或请求换电；若无可行收缩，回退到 v25 的短视界计划（v25 不承诺长时续航，故其执行仍在 Exec_v25 内）。
- 边缘队列溢出 / 截止期不可达 → ECOC 拒证 → `all_local` 卸载方案，机载算力执行；该方案若满足 SRC-USC 则属于 Exec_v25。
- 证明过期 / 签名失败 / 计数器回退 → SVTC 拒证 → 关键谓词本地复核；复核通过的计划属于 v25 语义，失败则停机。
- 组合失效取交集；每个回退分支的目标集合均被 Exec_v25 包含，故单调性保持。∎

### 定理（EEUC 的物理-语义-协同-续航-边缘完备性）
**陈述**：对任意计划 π（含可选卸载 o_π），`EEUC.admits(π)=True` ⇔ π 同时满足：
(1)–(10) SRC-USC 的十项条件（物理接地安全、云边版本一致、少样本覆盖、专利保护、结构、力控、轻量化、语义、重构、多机协同）；
(11) 续航：T_end(π,σ) ≥ T_task+Δ_safe 且 SoC/SoH/T 全程在界内；
(12) 卸载：端到端截止期、边缘队列稳定、净机载能量收益达标；
(13) 分割验证：本地谓词为真、边缘证明签名/绑定/新鲜/可组合且误差 ≤δ_edge。

**证明**：充分性由 `admits` 的合取结构与引理 1–16 直接得到；必要性由任一条件缺失即触发对应过滤器拒证（SRC-USC 拒证、EBHC 拒证、ECOC 拒证或 SVTC 拒证）得到。特别地，证书自检功率 P_cert 被显式计入 EBHC 能量传播，故不存在「验证耗尽续航」的自指漏洞。∎
