# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「基线复现」×「通用操作」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险是**闭世界 + 共因 + 过度自信**：故障必须落在有限假设集 ℋ 内，且视觉与几何的失效相互独立；未知复合故障会被强行归入最近假设、只膨胀错误的球，而系统还会因为「已经归因」而更自信地继续执行。本轮不再增加故障类或传感器，而是换一个更根本的问题：第 65 轮问「**谁坏了**」，REPRO 问「**这个安全结论本身可复现吗？它凭什么迁移到没见过的物体/任务？把两个已验证的技能拼起来，安全还在吗？**」
>
> 本轮核心命题：
>
> **把「故障可归因」升级为「安全结论可复现、可迁移、可组合」：用基线复现（对照实验）为每条安全主张建立方差基线与零假设，用蜕变关系群把单点证书扩展为通用操作的泛化包络，用技能契约组合让新任务的安全从已验证组件继承，而不是每次重新标定。**

## 0. 直觉与动机

**灵感 1（基线复现 → 科学对照实验，而不是又一次标定）**
直觉：第 64/65 轮的所有安全结论都是「相对」的——残差对 conformal 界、力对 f_lim、几何对先验。但**这些界本身是否可复现，从未被检验**。科学上，一个结果只有在独立重复下仍成立才可信；机器人上最小的重复单元是：同一初始状态、同一物体、同一指令、同一控制器，在受控扰动下重复 N 次。若行为离散度已经吃掉安全裕度，那么这个证书描述的不是机器人的能力，而是噪声——它是**不可复现的**，不得用于放行。基线复现因此是**负对照（negative control）**：它把「真本事」与「运气好的一次」分开。证书必须显式携带复现方差 σ_rep 与**复现裕度**（安全裕度减去若干倍 σ_rep），就像计量学里任何测量都要报不确定度。

**灵感 2（基线复现 → 影子基线：用保守策略当参照系）**
直觉：通用操作里无法枚举学习策略的所有失效模式。但总可以运行一个**慢、保守、已知安全**的基线（guarded move / 低增益 / 先接触后加载），把它放在**影子模式**（只预测、不执行），要求通用策略的预测轨迹要么落在基线的**安全管**内，要么显式声明「偏离需要理由」。基线不是竞争对手，而是**参照系**：没有基线，偏离没有意义；有了基线，「新方法更好」和「新方法只是没被测出来」才能被区分。这正是机器学习里「先复现 baseline 再谈提升」的机器人版本。

**灵感 3（通用操作 → 泛化不是任务更多，而是证书的变换不变性）**
直觉：通用操作常被表述为「在更多任务上训练、迁移到新任务」。但从安全角度，新任务之所以安全，只可能是因为它与某个已验证任务之间差了一个**保持任务语义的变换**（物体与目标整体 SE(3) 平移、指令改写、同类物体替换、视角变化），而该变换不改变相关物理与安全裕度。于是定义**任务保持变换群 G**（由蜕变关系 metamorphic relations 验证），并要求证书在**泛化包络**内对 G 近似不变（裕度对变换距离 Lipschitz）。包络外的任务不是「一定不安全」，而是「**未认证**」——必须先跑复现探针重新建立基线。**通用性 = 可被证书覆盖的变换半径，而不是任务数量。**

**灵感 4（通用操作 → 组合式复用：假设-保证契约）**
直觉：通用操作是长程技能组合。组合的安全**不是**各部分安全的乘积：接口、前后置条件、力/能量预算、不确定性半径都会耦合。若每个技能暴露一份**接口契约**（pre/post/不变式/资源预算/不确定半径/有效包络），则两个证书可组合当且仅当契约相容、且组合不确定度被保守合成（共因时不能当独立）。这就是 assume-guarantee / rely-guarantee 推理。它让新任务的安全**从已验证组件继承**，而不必从头认证——前提是接口的基线复现成立。

**灵感 5（三灵感合流 → REPRO：Reproducibility-Enforced Policy for Robust Operations，可复现性执照的通用操作闭环）**
闭环：基线复现电池 BRB → 影子基线安全管 SBR → 蜕变关系群/泛化包络 MRG → 复现增广归因 FIR-R（把 H_rep 噪声与 H_transfer 越界提为一等假设）→ 复现探针 RPP → 可复现证书包络 RCE → 技能契约组合 SCC → 复现感知前缀 CSC-R → 归因定向球 RSC-R/WCV-R → 块级组合规划 CSP-R → 不变性对抗认证 AIC-R → J_repro。第 65 轮是「几何-技能-干扰-接触-归因」五层；REPRO 不新增模态，而是在整条证书链上再加一个**元层**：**证书本身必须可复现、可迁移、可组合**。它问的不是「哪一层坏了」，而是「**我们凭什么相信这份证书在新的、没见过的、拼起来的场景里还成立**」。

**灵感 6（VISTA 组件原位升级）**
- **FIR → FIR-R**：假设集增 H_rep（不可复现噪声）、H_transfer（包络外迁移）、H_contract（组合接口错）；用重复间的**方差 vs 偏差**分解，先判「这是噪声还是真故障」。
- **AFA/APP → RPP**：探针目标从「故障假设互信息」升级为「单位风险下的复现信息/包络扩张」；优先零接触、可重复的基线重放。
- **RSC-V → RSC-R**：增 r_rep / r_transfer / r_contract；H_rep 时**靠重复降方差**而不是靠保守膨胀——用重复换裕度。
- **WCV-V → WCV-R**：搜索域增包络约束 E_ε 与契约可行性；越界时回退到影子基线安全管。
- **CSC → CSC-R**：认证前缀须同时满足 k·Δt≤m 与复现裕度 ρ_rep≥0；块内离散度超基线即早停重基线。
- **CSP-V/TSL → CSP-R/SCC**：块边需契约相容；技能绑定有效包络与复现签名；插入 `repro_probe` 元技能。
- **OLP → OLP-R**：在线学习只在包络内写；包络外先复现再学习。
- **AIC-V → AIC-R**：干扰集拆成「应当不变的变换（完备性）」与「必须拒绝的变换（可靠性）」；并增契约/共因故障。
- **J_vista → J_repro**：证书增 rep_variance、rep_margin、baseline_id、envelope_id、transfer_distance、metamorphic_pass、contract_hash、composition_graph_hash、repro_probe_log。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（REPRO 闭环）**：REPRO = (VISTA, BRB, SBR, MRG, FIR-R, RPP, RCE, SCC, RSC-R/WCV-R, CSC-R, CSP-R, AIC-R, J_repro)。定位：VISTA 的「可复现性 + 泛化包络 + 契约组合」元层升级。不变式：**基线复现、包络估计、契约组合、证书更新只在语义流；实时流只做影子基线比较、复现残差采集、复现裕度早停与前缀执行，零学习写操作。**
- **定义 234（基线复现电池 BRB 与重复分解）**：对上下文 c 重复执行基线块 N 次，得签名 ρ_i。分解 ρ_i=μ_c+b(θ)+ε_i，ε_i∼(0,Σ_rep)。样本均值 ρ̄、样本协方差 S_rep、偏差 b̂=ρ̄−μ_c。Σ_rep 是上下文 c 的**可复现性**；b̂ 才是第 65 轮意义上的系统性故障证据。BRB 是负对照：它先回答「这份数据里有没有超出噪声的东西」。
- **定义 235（方差-偏差检验与复现裕度）**：在 H0（无系统故障）下 T²=N b̂ᵀS_rep⁻¹b̂ 近似 Hotelling T²；T²≤τ_T² 判 `H_rep/H0`（噪声主导），否则把 b̂ 与协方差 Σ_rep/N 交给 FIR-R。对安全标量裕度 m，定义复现裕度 m_rep=m−q_rep(α)，q_rep 为 σ_rep 的 conformal/正态分位；只有 m_rep≥0 才可放行。
- **定义 236（影子基线参照 SBR）**：维护保守基线 π_base 及其预测安全管 𝒯_base={x: d(x,τ_base)≤r_base}。通用策略块 A 的影子预测 τ_A 必须满足 τ_A⊆𝒯_base（或在偏离处给出契约级理由），否则置 `baseline_divergence` 并降级/重规划。π_base 只在影子运行，不消耗执行预算。
- **定义 237（任务保持变换群与蜕变关系）**：G={g} 作用于任务上下文 (s,object,instruction,scene)，满足蜕变关系 MR_g：若 τ 是 g 下的有效解，则 g·τ 是 g·s 下的有效解，且安全裕度协变。G 的经验版本 Ĝ 由 MR 通过率定义；MR 失败即证伪该变换「保持语义」，必须收缩 G。
- **定义 238（泛化包络与迁移界）**：任务度量 d_G，证书在 c_0 有裕度 m_0。若 m 对 d_G 满足 Lipschitz 常数 L_m，则包络 E_ε={c:d_G(c,c_0)≤ε} 内 m(c)≥m_0−L_m ε−q_rep(α)。可认证半径 ε_max=(m_0−q_rep)/L_m。c∉E_ε ⇒ `uncertified`，必须跑 RPP。
- **定义 239（可复现证书包络 RCE）**：RCE=(baseline_id, rep_variance, rep_margin, envelope_id, ε_max, L_m, MR_pass, context_hash)。RCE 是技能/块的可迁移安全断言；它显式声明「在哪个变换半径内、以多大不确定度、凭什么基线」。
- **定义 240（技能接口契约）**：技能 σ 的契约 C_σ=(Pre_σ,Post_σ,Inv_σ,R_σ,U_σ,E_σ)：前后置条件、不变式、资源/力预算、不确定半径（含 r_rep/r_transfer/r_contract）、有效包络。契约是技能对外的「假设-保证」摘要。
- **定义 241（契约组合与共因合成）**：σ1;σ2 可组合 ⇔ Post_{σ1}⇒Pre_{σ2}（容差内）∧ Inv 相容 ∧ R_{12}=R_1⊕R_2≤R_budget ∧ E_{12}=E_1∩E_2≠∅ ∧ U_{12}=U_1⊕_cc U_2。共因依赖图 𝒟 给相关技能对；相关时用最坏和/联合球而非独立平方和，避免低估不确定度。
- **定义 242（复现探针 RPP）**：越界或契约不匹配时，选择最小风险重放 a*=argmax_a I(σ_rep,L_m,MR;Z_a)/risk(a)，s.t. 预测力/形变≤安全限、优先零接触、可早停；执行后更新 BRB、ε_max 与 MR_pass。RPP 的目标是**扩张可认证包络或降低复现方差**，而非单纯判别故障。
- **定义 243（FIR-R 复现增广归因）**：ℋ_R=ℋ_VISTA∪{H_rep,H_transfer,H_contract}。判定顺序：(1) T² 检验先分 H_rep；(2) MR 失败或 d_G>ε_max 判 H_transfer；(3) 组合期前置条件/预算违约判 H_contract（符号检查，不等残差）；(4) 余下才用第 65 轮阶段化签名归因。
- **定义 244（RSC-R 定向校准与用重复换裕度）**：维护 r_geo,r_force,r_model,r_vis,r_rep,r_transfer,r_contract。H_rep→增大重复数 N 使 r_rep=σ_rep/√N 下降（而非膨胀物理球）；H_transfer→收缩 ε 或跑 RPP，r_transfer=L_m·d_G；H_contract→拒绝组合、重规划接口。融合半径按依赖图选择独立平方和或共因最坏和。
- **定义 245（WCV-R 复现-包络联合压缩）**：搜索域 B(φ̂,r)∩𝒢(g)∩K(μ̂)∩ℱ(f_lim)∩𝒱∩E_ε∩C_feasible；越界或交集为空时回退 SBR 安全管并置 `envelope_conflict=True`；CVaR 尾部按后验与复现分布加权。
- **定义 246（CSC-R 复现感知认证前缀）**：k*=max{k: ∀s≤k, m_rep(s)≥0 ∧ k·Δt≤m ∧ c∈E_ε}；若块内跨重复/时序集成离散度>κ_rep·σ_rep，实时早停并触发重基线与重归因。块内越界概率 ≤ α_chunk+δ_fi+α_vis+α_rep。
- **定义 247（CSP-R 组合式块规划）**：块边需 Valid(J_repro) ∧ 契约相容 ∧ k*≥1；技能绑定 (E_σ, 𝒟_σ, RCE)；可插入 `repro_probe`、`null_test`、`baseline_replay` 元技能；软约束增 λ_rep·(r_rep+r_transfer) 与 λ_cc·共因惩罚。
- **定义 248（AIC-R 与 J_repro）**：ℰ_R=ℰ_V×ℰ_inv×ℰ_adv×ℰ_contract。ℰ_inv 是「应当不变」的变换（光照/视角/同类物体/指令改写），用于**完备性**（该迁移的必须迁移）；ℰ_adv 是「必须拒绝」的变换（质量/摩擦/刚性→柔性/隐藏障碍），用于**可靠性**（不该迁移的必须拒绝）；ℰ_contract 含接口缺失、预算耗尽、共因。J_repro=(J_vista, rep_variance, rep_margin, baseline_id, envelope_id, ε_max, transfer_distance, metamorphic_pass, contract_hash, composition_graph_hash, repro_probe_log, aic_r_ver)。Valid ⇔ Valid(J_vista) ∧ (c∈E_ε ∨ 已跑 RPP) ∧ m_rep≥0 ∧ MR 在包络边界样本通过 ∧ 契约可组合 ∧ 复现方差≤预算。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（方差-偏差可分与复现裕度）**：重复分解下，T² 检验以 N 与 Σ_rep 决定的功效把「零均值噪声」与「系统性偏差」分开；单次运行的「看起来安全」不能控制真实均值裕度，而复现裕度 m_rep=m−q_rep(α) 才能。故第 65 轮把噪声误归因为物理故障的概率可由 BRB 显式压低。
- **引理 10（包络内迁移界）**：裕度 L_m-Lipschitz + 复现残差 conformal ⇒ 对 c∈E_ε，m(c)≥m_0−L_m ε−q_rep(α)。由此得可认证半径 ε_max 与「通用性=变换半径」的量化定义。
- **引理 11（契约组合可靠性）**：若各契约 sound、接口匹配、且共因用最坏和合成，则组合 sound；把相关技能当独立会把 r 低估至多 √n 倍，导致不安全——故组合必须读依赖图。
- **定理 9（REPRO 端到端）**：在 A94–A98 下，Valid(J_repro) ⇒ 包络内安全裕度≥0（概率≥1−α）∧ 包络外未认证不迁移 ∧ 组合安全 ∧ 优雅降级（H_rep→重复/减速；H_transfer→收缩/探针；H_contract→拒绝/重规划）。
- **定理 10（复现-复用成本优势）**：从头认证任务成本 O(n_cert·|T|)；REPRO 复用成本 O(|σ|·接口检查+N·n_rep)，在包络覆盖的任务数增长时摊销成本下降，且由引理 11 保持 sound。
- **命题（可复现 ≠ 正确）**：常数系统偏差 b 的 σ_rep=0、完美可复现，却系统性错误；故 REPRO 必须同时用 SBR 交叉参照与 MR 证伪，否则「稳定复现的错误基线」会产生既紧又自信的错证书。
- **实时性**：影子基线比较、复现残差采集、离散度早停都在实时流（目标 ≤0.3ms 增量）；BRB/MRG/RPP/契约组合/AIC-R 全在语义流，目标总实时预算 ≤2.8ms（A99）。

| E250 压力测试 | 漂移/契约错/延迟 | 优雅降级，恢复 ≤2s |

## 5. 本轮最大风险

**一句话**：REPRO 把「可复现」当成「正确」的代理——一个稳定复现但系统性错误的基线、一个漏掉关键变换（质量分布/摩擦/刚性→柔性）的任务保持群、或一份不完整（漏掉热/磨损/共因）的接口契约，都会产生一个**又紧又自信却在通用操作上系统性错误**的证书；组合契约还会把这个单点错误沿长程任务放大，而系统会因为「已复现、已组合」而更加相信它。这是本轮全部迁移界与组合论证共同依赖的隐藏假设（A94）。

## 2. 形式化定义（完整版）

**定义 233（REPRO 闭环）** REPRO 是 VISTA 的「可复现性 + 泛化包络 + 契约组合」元层升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 BRB（基线复现电池）、SBR（影子基线）、MRG（蜕变关系/包络）、RPP（复现探针），并原位升级 FIR→FIR-R、RSC-V→RSC-R、WCV-V→WCV-R、CSC→CSC-R、CSP-V→CSP-R/SCC、AIC-V→AIC-R、J_vista→J_repro。不变式：**基线复现、包络估计、契约组合、证书构建只发生在语义流与低频线程；实时路径只做影子基线比较、复现残差采集、离散度早停、前缀执行与派发，零学习写操作。** REPRO 不替代 VISTA，而是给 VISTA 的每个结论加一个「这份结论在重复/迁移/组合下是否仍成立」的元检查。

**定义 234（基线复现电池 BRB 与重复分解）** 给定上下文 c（物体、位姿、指令、场景、本体），对同一基线块重复执行 N 次，得到签名序列 ρ_1,…,ρ_N∈ℝ^{15}。假设可加分解
ρ_i = μ_c + b(θ) + ε_i，  ε_i ∼ (0, Σ_rep)， E[ε_i]=0，
其中 μ_c 是上下文的名义签名（由 BRB 在无故障条件下估计），b(θ) 是第 65 轮意义上的系统性故障偏差（θ 为故障幅度），ε_i 是运行间不可约噪声。样本统计量
ρ̄ = (1/N)Σ_i ρ_i， S_rep = (1/(N−1))Σ_i (ρ_i−ρ̄)(ρ_i−ρ̄)ᵀ， b̂ = ρ̄ − μ_c。
**Σ_rep 刻画上下文 c 的可复现性；只有 b̂ 才是「真故障」的候选证据。** BRB 是负对照：它先回答「数据里有没有超出运行间噪声的东西」，再谈归因。对 N=1（第 65 轮的默认），S_rep 不可估，FIR 只能把噪声与故障混为一谈——这是第 65 轮过度归因的统计根源。

**定义 235（方差-偏差检验与复现裕度）** 在零假设 H0: b=0（无系统故障）下，若 ε_i 近似高斯，则
T² = N b̂ᵀ S_rep⁻¹ b̂ ∼ Hotelling T²(p, N−1)， p=15。
当 T² ≤ τ_{T²}（按显著性水平 α_T 取分位）时判 `H_rep/H0`（噪声主导），**不膨胀任何物理不确定球**，而是增大 N 或减速；否则把 b̂ 连同协方差 Σ_rep/N 交给 FIR-R 做第 65 轮归因。对安全标量裕度 m（如力限/滑移/几何裕度），定义复现裕度
m_rep = m − q_rep(α)， q_rep(α) 为 σ_rep/√N 的正态或 split-conformal 分位。
只有 m_rep≥0 才允许放行。直觉：单次「看起来安全」只说明这一次的噪声实现没越界，不说明真实均值安全；复现裕度把「重复带来的均值不确定度」显式扣掉，等价于计量学里的测量不确定度。

**定义 236（影子基线参照 SBR）** 维护一个保守、慢速、已知安全的基线策略 π_base（例如 guarded move + 低增益阻抗 + 先接触后加载），及其在上下文 c 下的预测轨迹 τ_base 与安全管
𝒯_base = { x : d(x, τ_base) ≤ r_base(c) }。
对通用块策略给出的 A_t，SBR 计算影子预测 τ_A（只预测、不执行）并检查 τ_A ⊆ 𝒯_base。若存在偏离点，则置 `baseline_divergence=True`，并要求偏离由契约级理由（新的 pre/post 或包络扩张）解释；否则降级到 π_base 或重规划。π_base 不消耗执行预算，只提供**参照系**：它使「通用策略的偏离」成为可检验事件，而不是无法解释的自由度。SBR 与 BRB 互补：BRB 回答「重复是否一致」，SBR 回答「一致的行为是否至少和保守基线一样安全」。

**定义 237（任务保持变换群与蜕变关系 MRG）** 令上下文 c=(s, object, instruction, scene, embodiment)，任务解为轨迹 τ。定义变换群 G={g} 作用于上下文与轨迹。对每个 g 定义蜕变关系
MR_g：若 τ 在 c 下有效且安全，则 g·τ 在 g·c 下有效且安全，且安全裕度按已知方式协变。
G 的候选生成元包括：物体+目标+机器人整体 SE(3) 平移/旋转、指令改写（保持意图）、同类物体实例替换（几何/质量在类内）、相机视角/光照变化、执行速度在安全范围内缩放。**MR 是无需 oracle 的检验**：通用操作里往往不知道「正确动作」，但知道「这个变换下动作应当协变」。经验版本 Ĝ 由 MR 通过率定义；若某 g 的 MR 失败，则该 g 不保持语义，必须从 G 中剔除或收缩其有效范围。这一步是对**包络本身**的证伪，和 VISTA 对几何先验的证伪同构。

**定义 238（泛化包络与迁移界）** 在任务空间上取与 G 相容的度量 d_G（例如 SE(3) 位移、指令嵌入距离、物体参数距离的加权和）。设已验证上下文 c_0 的安全裕度为 m_0，且 m 对 d_G 满足 Lipschitz
|m(c) − m(c_0)| ≤ L_m · d_G(c, c_0) + e_rep，
其中 e_rep 是复现残差（由 BRB 的 q_rep(α) 给出）。则对任意 c∈E_ε={c: d_G(c,c_0)≤ε}，
m(c) ≥ m_0 − L_m·ε − q_rep(α)。
令右端≥0 得可认证半径 ε_max=(m_0−q_rep(α))/L_m。于是「通用操作的安全」被量化为**包络半径**：c∈E_ε 时证书可继承；c∉E_ε 时输出 `uncertified`，必须跑 RPP（定义 242）。L_m 由 MRG 在 G 的样本上估计（例如对 g 的一维子群做扰动，拟合裕度对 d_G 的斜率上界）。

**定义 239（可复现证书包络 RCE）** RCE 是技能/块级证书的可迁移断言：
RCE = (baseline_id, rep_variance, rep_margin, envelope_id, ε_max, L_m, MR_pass, context_hash)。
- baseline_id 指向产生 μ_c 与 Σ_rep 的 BRB 批次；
- rep_variance/rep_margin 是定义 234/235 的统计量；
- envelope_id/ε_max/L_m 是定义 238 的可认证区域；
- MR_pass 记录该包络用到的蜕变关系及其通过率；
- context_hash 绑定上下文，防止包络被错误套用。
RCE 的意义：**证书不再是一个点上的布尔值，而是「带半径与不确定度的区域断言」**。VISTA 的 J_vista 只在该点上有效；RCE 说明它能被继承到多远。

**定义 240（技能接口契约）** 技能 σ 的契约
C_σ = (Pre_σ, Post_σ, Inv_σ, R_σ, U_σ, E_σ)，
其中 Pre/Post 是任务状态上的前置/后置条件（符号谓词 + 几何容差），Inv 是执行期间必须保持的不变式（无碰撞、力≤f_lim、物体在夹爪内、温度/电流在界内），R_σ 是资源预算（时间、能量、力冲量 ∫f dt、接触次数），U_σ 是退出时的不确定半径（含 r_geo/r_force/r_model/r_vis/r_rep/r_transfer/r_contract），E_σ 是有效包络。契约是技能对外的**假设-保证摘要**：只要调用方满足 Pre 并遵守 R_σ，技能保证 Post 与 Inv，且不确定度不超过 U_σ。

**定义 241（契约组合与共因合成）** 对技能序列 σ1;σ2，定义可组合
Comp(C_σ1,C_σ2) ⇔ Post_{σ1} ⇒ Pre_{σ2}（容差内）
∧ Inv_{σ1} 与 Inv_{σ2} 相容
∧ R_{12}=R_1⊕R_2 ≤ R_budget
∧ E_{12}=E_1∩E_2 ≠ ∅
∧ U_{12}=U_1⊕_cc U_2。
不确定度合成 `⊕_cc` 读共因依赖图 𝒟：若两技能共享标定、物体、传感器或同一 OOD 源（𝒟 中有边），则按最坏和相关合成
U_{12}² = U_1² + U_2² + 2ρ_cc U_1 U_2， ρ_cc→1 时退化为 (U_1+U_2)²；
若独立则 U_{12}²=U_1²+U_2²。资源预算对力冲量/能量取和（不可交换的物理量），时间取和。组合的不变式取并集，包络取交集。**注意 E 取交集意味着组合会缩小可认证区域**——这正是「拼起来更不安全」的形式化来源。

**定义 242（复现探针 RPP）** 当 c∉E_ε 或契约不匹配时，RPP 选择一个最小风险的重放/探测动作
a* = argmax_{a∈A_probe} I(σ_rep, L_m, MR ; Z_a | 历史) / risk(a)，
s.t. 预测 f_n ≤ f_safe、预测形变 ≤ ε_strain、优先零接触（null_test / baseline_replay）、支持早停、且人类/环境预算未耗尽。
A_probe = {baseline_replay, null_test, visual_probe, slow_replay, micro_press, MR_probe}。执行后用观测更新 μ_c、Σ_rep、L_m、MR_pass 与 ε_max。与第 65 轮 AFA 的区别：AFA 最大化「故障假设互信息」以分清谁坏了；RPP 最大化「复现/包络信息」以决定**这份证书能否被继承或必须收缩**。前者是诊断，后者是**认证域的扩张/收缩**。

**定义 243（FIR-R 复现增广归因）** 故障假设集
ℋ_R = ℋ_VISTA ∪ {H_rep, H_transfer, H_contract}
= {H0, H_geo, H_force, H_model, H_vis, H_policy, H_rep, H_transfer, H_contract}。
判定按**成本从低到高、从统计到物理**的顺序：
1. **H_rep**：T² ≤ τ_{T²}（定义 235）→ 噪声主导，不归因物理故障，增大 N/减速；若 T² 高但 b̂ 方向在各重复间不稳定（bootstrap 方向一致性低），仍判 H_rep。
2. **H_transfer**：MR 失败，或 d_G(c,c_0)>ε_max，或 SBR 出现系统性偏离而局部残差正常 → 包络/迁移问题。
3. **H_contract**：组合期前置条件不满足、资源预算耗尽、包络交集为空、共因依赖未计入 → 符号检查，不依赖残差。
4. 余下才用第 65 轮阶段化签名 + 6 假设 FIR 归因（用 b̂ 与 Σ_rep/N，而非单次 ρ）。
这个顺序的关键：**先用方差排除噪声，再用包络排除迁移，再用符号排除接口，最后才做昂贵的物理归因**，避免第 65 轮把统计涨落误诊为传感器/几何故障。

**定义 244（RSC-R 定向校准与「用重复换裕度」）** 维护半径
r_geo, r_force, r_model, r_vis, r_rep, r_transfer, r_contract。
定向处置：
- **H_rep**：不膨胀物理球；令 N←min(N_max, 2N)，r_rep←σ_rep/√N；若 r_rep 仍超预算，判该上下文 `uncertifiable`，降速或请求更稳的执行条件。**这是与第 64/65 轮最本质的不同：不确定性可以通过重复被「挣回来」，而不是只能通过保守被「买回来」。**
- **H_transfer**：收缩 ε（ε←ε/2）或跑 RPP；r_transfer←L_m·d_G。
- **H_contract**：拒绝组合、重规划接口，不膨胀物理球。
- 其他 H 沿用 VISTA 的定向处置。
融合半径按 𝒟：独立时 r=√(Σ r_i²)，共因时 r=Σ r_i（最坏和），或对相关子集用联合球。

**定义 245（WCV-R 复现-包络联合压缩）** 搜索域
B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ E_ε ∩ C_feasible，
其中 E_ε 是泛化包络（上下文约束），C_feasible 是当前技能契约的可行域（资源/不变式）。CVaR 尾部 n_worst=8，尾部样本按归因后验与复现分布（σ_rep/√N）加权；归因模糊时做后验边缘化尾部。若交集为空或 c∉E_ε，则回退到 SBR 的 𝒯_base，并置 `envelope_conflict=True` 写入证书。

**定义 246（CSC-R 复现感知认证前缀）** 对块 A_t 与执行前缀 k，
k* = max{ k : ∀s≤k, m_rep(s)≥0 ∧ k·Δt≤m ∧ c∈E_ε }，
其中 m 为不可逆视界，m_rep(s) 用定义 235 的复现裕度逐通道计算。块内实时监控：若跨重复（并行/时间集成副本）或时序集成的签名离散度
disp_now = ‖ρ_now − ρ̄_rep‖_{Σ_rep⁻¹} > κ_rep
（κ_rep 由 α_rep 定），立即早停、触发重基线与重归因。块内越界概率界
P[越界] ≤ α_chunk + δ_fi + α_vis + α_rep。
k* 同时受包络约束：若块轨迹离开 E_ε，即使单步裕度为正也必须截断。

**定义 247（CSP-R 组合式块规划）** 在 CSP 的层级 A* 上以**块**为边，边 (σ_i→σ_j) 合法需
Valid(J_repro) ∧ Comp(C_{σ_i},C_{σ_j}) ∧ k*≥1。
技能 σ 绑定 (E_σ, 𝒟_σ, RCE_σ)，其中 𝒟_σ 是典型复现签名分布，RCE_σ 是其可迁移断言。实际块签名到 𝒟_σ 的 Mahalanobis 距离 > τ_chunk 或上下文离开 E_σ 即判 OOD，该边不入图。规划器可插入元技能：`repro_probe`（RPP）、`null_test`（零力窗重标定）、`baseline_replay`（SBR 重放）、`mr_check`（蜕变关系检验）。软约束代价增
λ_rep·(r_rep+r_transfer) + λ_cc·1[𝒟 有共因边] + λ_k·Σ hinge(k*−k_req)。

**定义 248（AIC-R 与 J_repro）** 干扰集
ℰ_R = ℰ_V × ℰ_inv × ℰ_adv × ℰ_contract，
其中
- ℰ_inv（**应当不变**）：光照、视角、同类物体实例、指令改写、整体 SE(3) —— 用于**完备性**：该迁移的必须迁移，证书漂移必须 ≤ L_m·d_G+q_rep；若漂移超界，说明包络/L_m 估错，必须收缩。
- ℰ_adv（**必须拒绝**）：质量分布、摩擦、刚性→柔性、隐藏障碍、超出类别的物体 —— 用于**可靠性**：不该迁移的必须被拒（输出 `uncertified` 或跑 RPP），若错误迁移即认证失败。
- ℰ_contract：接口缺失、预算耗尽、包络交集为空、共因未计入。
ρ_dir 在 ℰ_R 上重算（n_cert 128→144，其中 16 给 ℰ_inv 的完备性、16 给 ℰ_adv 的可靠性、16 给 ℰ_contract）；ρ_force 在最坏摩擦/质量与最坏视觉遮挡下取最坏。J_dir 增 envelope_ver、contract_ver、mr_ver、repro_ver。
J_repro = (J_vista, rep_variance, rep_margin, baseline_id, envelope_id, ε_max, transfer_distance, metamorphic_pass, contract_hash, composition_graph_hash, repro_probe_log, aic_r_ver)。
Valid(J_repro) ⇔
Valid(J_vista)
∧ (c∈E_ε ∨ 已执行 RPP 并更新包络)
∧ m_rep≥0
∧ MR 在包络边界样本上通过（metamorphic_pass）
∧ 当前技能契约可组合（contract_hash 与 composition_graph_hash 一致）
∧ 复现方差 ≤ 预算（σ_rep≤σ_budget）
∧ aic_r_ver 为当前版本。
审计链新增：凭什么基线（baseline_id）、证书覆盖多远（envelope_id/ε_max）、迁移了多远（transfer_distance）、噪声多大（rep_variance/rep_margin）、拼起来是否相容（contract_hash/composition_graph_hash）。

### IP-224 BRB（基线复现电池）

```python
class BaselineReproductionBattery:
    """负对照：先分噪声，再谈故障。实时只采集签名，统计在语义流。"""
    def __init__(self, N=8, alpha_T=0.01, alpha_rep=0.05):
        self.N, self.alpha_T, self.alpha_rep = N, alpha_T, alpha_rep
        self.mu_c, self.S_rep, self.n = {}, {}, {}

    def measure(self, context, run_block):
        rho = np.stack([run_block(context) for _ in range(self.N)])
        mu = rho.mean(0)
        S = np.cov(rho, rowvar=False)
        self.mu_c[context.id], self.S_rep[context.id] = mu, S
        self.n[context.id] = self.N
        return mu, S

    def variance_bias_test(self, context, rho_new):
        mu0, S = self.mu_c[context.id], self.S_rep[context.id]
        b_hat = rho_new - mu0
        S_reg = S + 1e-6 * np.eye(S.shape[0])      # 防止奇异
        T2 = self.N * b_hat @ np.linalg.pinv(S_reg) @ b_hat
        tau = hotelling_quantile(p=len(b_hat), n=self.N - 1,
                                 alpha=self.alpha_T)
        return T2, tau, b_hat, S / self.N

    def repro_margin(self, m, sigma_rep):
        q = normal_quantile(1 - self.alpha_rep) * sigma_rep / np.sqrt(self.N)
        return m - q, q

    def increase_repeats(self, context, cap=64):
        self.N = min(cap, 2 * self.N)
```

### IP-226 MRG（蜕变关系与泛化包络）

```python
class MetamorphicEnvelope:
    """用蜕变关系验证任务保持变换，估计 Lipschitz 裕度与可认证半径。"""
    def __init__(self, group_generators, alpha=0.05):
        self.G, self.alpha = group_generators, alpha
        self.mr_pass, self.L_m = {}, None

    def validate(self, context0, tau0, m0, rollout_fn):
        xs, ys = [], []
        for g in self.G:
            c_g = apply_transform(g, context0)
            tau_g = rollout_fn(c_g)
            ok = check_metamorphic_relation(g, tau0, tau_g)
            self.mr_pass[g.name] = ok
            if not ok:
                continue                                   # 证伪该变换
            m_g = safety_margin(tau_g)
            xs.append(d_G(c_g, context0)); ys.append(abs(m_g - m0))
        if len(xs) >= 2:
            self.L_m = max(np.array(ys) / (np.array(xs) + 1e-9))  # 斜率上界
        return self.mr_pass, self.L_m

    def certified_radius(self, m0, q_rep, L_m):
        return max(0.0, (m0 - q_rep) / max(L_m, 1e-9))

    def inside(self, c, c0, eps):
        return d_G(c, c0) <= eps
```

### IP-229 SCC（技能契约组合）

```python
class ContractComposer:
    def __init__(self, dep_graph):
        self.dep = dep_graph                                # 共因依赖图

    def compatible(self, C1, C2):
        return (implies(C1.post, C2.pre, tol=TOL)
                and invariants_compatible(C1.inv, C2.inv)
                and budget_le(add_budget(C1.R, C2.R), R_BUDGET)
                and intersects(C1.E, C2.E))

    def compose_uncertainty(self, U1, U2, s1, s2):
        if self.dep.has_edge(s1, s2):                      # 共因：最坏和相关
            return U1 + U2
        return math.sqrt(U1**2 + U2**2)                    # 独立

    def compose(self, plan):
        for s1, s2 in plan.edges:
            if not self.compatible(plan.C[s1], plan.C[s2]):
                return None, 'contract_incompatible'
        U = plan.C[plan.start].U
        for s1, s2 in plan.edges:
            U = self.compose_uncertainty(U, plan.C[s2].U, s1, s2)
        return U, 'ok'
```

def directed_demote_repro(h, balls, N, eps, dG, L_m, sigma_rep):

def REPRO_round(M, obs, delta_f_req):

## 4. 推导

**引理 9（方差-偏差可分与复现裕度）** 在定义 234 的可加分解与高斯 ε_i 下，b̂∼N(b, Σ_rep/N)。零假设 b=0 时 T²=N b̂ᵀS_rep⁻¹b̂ 服从 Hotelling T²(p,N−1)；对立假设下 T² 服从非中心 T²，非中心参数 λ=N bᵀΣ_rep⁻¹b，故检验功效随 N 与故障信噪比 bᵀΣ_rep⁻¹b 单调增。于是「零均值噪声」与「系统性偏差」在 N 足够时以任意高的功效被分开。
对安全标量裕度，设真实均值裕度 m*<0（实际不安全），单次观测 m_obs=m*+ε，ε∼N(0,σ_rep²)。单次证书的假安全概率为
P_false^(1) = P(ε > −m*) = Φ(m*/σ_rep)。
用 N 次重复并要求复现裕度 m̄−z_{1−α}σ_rep/√N ≥ 0 时，
P_false^(N) = P( ε̄ ≥ −m* + z_{1−α}σ_rep/√N )
= 1 − Φ( √N·(−m*)/σ_rep + z_{1−α} )，
随 N 单调下降。故 BRB 把第 65 轮「把噪声误归因为物理故障、并据此放行」的概率显式压低；代价是重复的执行/仿真预算。∎

**引理 10（包络内迁移界）** 由定义 238 的 Lipschitz 性与复现残差的 conformal 覆盖 P[e_rep≤q_rep(α)]≥1−α，对 c∈E_ε，
m(c) ≥ m(c_0) − L_m·d_G(c,c_0) − e_rep ≥ m_0 − L_m·ε − q_rep(α)。
令右端≥0 即得 ε_max=(m_0−q_rep)/L_m。于是只要 d_G(c,c_0)≤ε_max，迁移后的证书仍然有效；这给出「通用性 = 可认证变换半径」的严格含义，且半径随基线裕度增大、随 L_m 与复现噪声减小而增大。∎

**引理 11（契约组合可靠性）** 设每个技能契约 sound：从任意满足 Pre_i 的状态出发、在资源 ≤R_i 内执行 σ_i，则 Inv_i 始终成立且 Post_i 成立，退出不确定度 ≤U_i。若 Post_1⇒Pre_2、Inv 相容、R_12≤R_budget、E_12≠∅，则 σ_1;σ_2 的每一步都满足对应前置与不变式，故组合 sound。对不确定度：若误差独立，U_12²=U_1²+U_2²；若共因相关系数 ρ_cc>0，真实 U_12²=U_1²+U_2²+2ρ_ccU_1U_2。把相关误当独立会把 U_12 低估至多
(U_1+U_2)/√(U_1²+U_2²) ≤ √2（两个技能），n 个相关技能时最坏低估 √n 倍。因此共因依赖图 𝒟 不是优化项，而是 soundness 的必要条件。∎

**定理 9（REPRO 端到端）** 在假设 A94–A99 下：
1. **噪声不冒充故障**：BRB 的 T² 检验把零均值噪声判为 H_rep（引理 9），此时不膨胀物理球、只增加重复或减速；第 65 轮的单次归因被降级为「有重复支撑才成立」。
2. **迁移受包络约束**：c∈E_ε 时 m(c)≥0（引理 10）；c∉E_ε 时证书输出 `uncertified`，必须先跑 RPP，禁止静默迁移。
3. **组合 sound**：契约相容 + 共因感知合成 ⇒ 组合安全（引理 11）；包络取交集显式表达「拼起来更不安全」。
4. **可复现 ≠ 正确被显式标注**：RCE 记录 baseline_id 与 MR_pass；SBR 提供独立参照，防止「稳定复现的错误基线」被当成真值（命题 1）。
5. **优雅降级**：H_rep→重复/减速；H_transfer→收缩包络/探针；H_contract→拒绝组合/重规划；视觉或力失效→退回 VISTA/GRIP 的对应降级。
6. **证书元层**：Valid(J_repro) 同时要求 J_vista 有效、包络或 RPP、m_rep≥0、MR 通过、契约可组合、复现方差有界。
∎

**定理 10（复现-复用成本优势）** 从头认证一个任务需要 n_cert 次最坏扰动评估，成本 O(n_cert·|T|)（|T| 为任务/块数）。REPRO 在包络内复用一个已验证技能只需：N 次基线复现（估计 σ_rep）+ 常数次接口检查 + RCE 查表，成本 O(N·n_rep + |σ|·c_iface)。当同一技能被 m 个包络内任务复用时，摊销认证成本
C_amort(m) = (N·n_rep + |σ|·c_iface)/m + c_repro，
随 m 增大而下降；而从头认证成本恒为 O(n_cert·|T|)。由引理 11，复用保持 sound，故在包络覆盖良好的通用操作分布上，REPRO 以更低成本获得同等安全。∎

**命题 1（可复现 ≠ 正确）** 设基线存在常数系统偏差 b≠0，即 ρ_i=μ_c+b 对所有 i 成立。则 S_rep=0，T²=0，BRB 判 `H_rep/H0`（完美可复现），但真实安全裕度已偏移 b。故可复现性只约束**方差**，不约束**偏差**；REPRO 必须同时用 (i) SBR 的独立保守参照与 (ii) MRG 的蜕变关系证伪，才能发现「稳定地错」。这也说明 BRB 不能被单独当作正确性证据——它只回答「这次结果是否只是运气」。∎

**假设 A94–A99**：
- **A94（基线复现有效性）**：BRB 能在上下文内估计 Σ_rep，且基线偏差可由 SBR/MR 发现（否则见命题 1）。
- **A95（包络 Lipschitz）**：安全裕度对 d_G 满足 L_m-Lipschitz，且 L_m 可由 MRG 样本给出上界。
- **A96（MR 覆盖）**：G 覆盖任务分布中与安全相关的变换；MR 失败可被检测。
- **A97（契约完备）**：契约包含全部安全相关不变式与资源预算；共因依赖图 𝒟 覆盖共享标定/物体/传感器/OOD 源。
- **A98（复现方差有界）**：σ_rep≤σ_budget，否则上下文判 `uncertifiable`。
- **A99（实时契约）**：实时路径 ≤2.8ms，零学习写操作；BRB/MRG/RPP/契约组合/AIC-R 全在语义流。

## 7. 已知风险

**一句话**：REPRO 把「可复现」当成「正确」的代理——一个稳定复现但系统性错误的基线、一个漏掉关键变换（质量分布/摩擦/刚性→柔性）的任务保持群、或一份不完整（漏掉热/磨损/共因）的接口契约，都会产生一个**又紧又自信却在通用操作上系统性错误**的证书；组合契约还会把这个单点错误沿长程任务放大，而系统会因为「已复现、已组合」而更加相信它。这是本轮全部迁移界与组合论证共同依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **可复现但系统性错误（命题 1）**：BRB 只约束方差，不约束偏差；缓解：SBR 独立参照 + MRG 证伪 + 定期用外部标定/人类抽检做绝对锚定；RCE 显式记录 baseline_id，禁止跨基线复用。
2. **任务保持群选错/漏项**：G 是人工/数据驱动的，漏掉质量、摩擦、柔性等「物理语义」变换会错误迁移；缓解：ℰ_adv 专门测试「必须拒绝」的变换；MR 失败即收缩 G；把物理参数变化显式纳入 d_G 或拒绝迁移。
3. **Lipschitz 常数低估**：L_m 由有限样本估上界，可能在裕度非单调区失效；缓解：取分位数上界而非均值、对 d_G 做分片、包络边界用 MR 复核、保守乘以安全系数。
4. **契约不完备**：漏掉热/磨损/疲劳/共因会让组合 sound 论证失效；缓解：契约模板强制覆盖力/能量/时间/不变式；依赖图 𝒟 由标定与传感器共享关系自动生成；未知依赖默认按共因（最坏和）处理。
5. **重复成本与实时性**：N 增大带来执行/仿真开销，实时流逼近 2.8ms；缓解：仿真/数字孪生做 BRB、只在关键上下文真机重复、并行副本、按需自适应 N。
6. **包络交集快速收缩**：组合使 E 取交集，长程任务可能几乎没有可认证区域；缓解：契约设计时显式对齐包络、插入 repro_probe 元技能、允许在线扩张包络（带安全约束）。
7. **共因依赖图不准**：漏边会把相关当独立、低估 √n；缓解：默认保守（未知即相关）、标定/传感器/OOD 源显式建边、AIC-R 的 ℰ_contract 专测。
8. **MR 的 oracle 假设**：蜕变关系本身可能错（例如速度缩放并非安全协变）；缓解：MR 需可证伪、按任务族验证、把 MR 版本写入证书并可回滚。
