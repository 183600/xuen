# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC，IP-153~160；灵感循环第 7 轮；本轮灵感：「深度相机」×「关节空间控制」）

> 第 60 轮把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭合成 SERC，并用 SSM 的场景-阻抗先验提前收窄 K_safe、CIEC 锁定意图约束、EPIR 保障 ROS 证据链、PCE++++ 管理认知预算。但整个闭环仍站在两个**未接地的假设**上：
> 1. **场景是「接触之后的标签」，不是「接触之前的几何」**：SSM 的观测输入是力/位遥测，只有碰到东西之后才能更新场景后验。深度相机本可把识别前移到接触前，但深度是**视角依赖、遮挡敏感、透明/反光失效、噪声随距离平方增长**的；“点云看起来像桌面”与“这里的接触法向和有效刚度是什么”之间存在一条**几何-阻抗接地鸿沟**。把点云当真相，等于把视觉幻觉直接注入安全先验。
> 2. **阻抗在任务空间编译，却在关节空间实现**：EEIS/CIEC/CESC 的 K_safe 全部定义在笛卡尔任务空间 (K_x, F)，而真实执行量是关节量 (q, q̇, τ)。任务空间里一个温和的 K_x，经 K_q = JᵀK_xJ 映到关节后，可能在奇异附近病态、在关节限位附近不可达、在力矩饱和下不可维持。第 60 轮默认「任务空间安全 ⇒ 关节空间可实现」，这从未被证书化。
> 本轮的核心论点是：**阻抗必须做「双向接地」**——深度相机把环境几何接地为「需求阻抗 + 接触法向」，关节空间把任务阻抗接地为「可实现阻抗集 + 力矩/奇异/限位裕度」；两者交集为空时，正确动作是**改变姿态/视角/抓取**，而不是把安全阻抗“静默投影”成一个更小但方向错误的阻抗。

## 0. 直觉与动机

**灵感 1（深度相机 → 接触前几何先验接地 DGPG）**
直觉：人伸手前会先“看”一眼：这块表面是平的还是弧的？是硬木还是软垫？离手还有多远？大概沿哪个法向碰上去？深度相机给出的稠密点云正是这些问题的原料。关键洞见：不要把点云直接映射成“场景类别”，而要映射成**局部接触几何描述子** g = (n̂, κ, d_c, σ_n, ρ_vis)：n̂ 是法向（决定往哪使力），κ 是曲率（决定法向刚度 K_n 与切向刚度 K_t 的比例），d_c 是净空（决定接近速度 v_app），σ_n 是法向不确定度，ρ_vis 是可见率。再由 ρ_geo: g → (K_x^req, F_n^req, v_app) 得到**接触前的阻抗需求先验**。这样场景语义就退化成几何描述子的一个粗粒度投影，而不是唯一的中间表示。

**灵感 2（关节空间控制 → 可实现性证书 JSR）**
直觉：任务空间的“软”不等于关节空间的“做得到”。当机械臂接近奇异位形时，J 的最小奇异值趋零，任务空间某个方向上的刚度几乎无法由关节力矩维持；当接近关节限位时，某些方向根本无法继续运动；当力矩接近饱和时，K_x 再大也只是“纸面刚度”。关键洞见：**可实现的不是任意 K_x，而是由 (q, τ_max, 限位, 奇异裕度) 诱导的一个集合 K_adm(q)**。真正的安全是 K_safe^x ∩ K_adm(q) 非空，而不是 K_safe^x 单独非空。沿接触法向的最大可施加力有闭式表达：F_n^max(q, n̂) = Σ_j τ_j^max |(J⁻¹n̂)_j|（支撑函数），它把“力够不够”变成一个可精确计算的量，而不是采样估计。

**灵感 3（合流 → 几何-运动学一致性门 GKG）**
直觉：几何说“沿 n̂ 压下去”，关节说“我最擅长沿 f* 方向出力”。如果 n̂ 落在力可行多面体的“瘦”方向，强行沿 n̂ 施力会先让某几个关节饱和，接触力跟踪立刻失真，甚至激发振荡。关键洞见：光有 JSR 还不够，必须再加一道**法向一致性门**：若几何法向 n̂ 与关节最优出力方向偏离超过 θ_max，或运动学法向增益 ‖J⁻¹n̂‖ 过大（法向微动需要巨大关节运动），就**不要降低力硬顶**，而应通过冗余零空间/底座/换抓取**重定向**，让 n̂ 重新落进“好出力”的方向。

**灵感 4（双空间阻抗编译 DAI + 接触前闭环 PCGL）**
直觉：正确流程不是“先在任务空间算完 K_safe，再在关节空间硬截断”，而是**同时在两个空间里求解**：任务空间给出安全语义（来自场景几何与意图），关节空间给出可实现语义（来自当前位形），二者的交集才可下发。若交集为空，有三种诚实的选择：调姿态（冗余/底座）、换视角（主动重观测）、或安全降级；**绝不允许**“把 K_safe 投影成某个看起来可行、但改变了接触法向的 K_q”混过去。这样 SERC 的“接触后闭环”就被前移成“接触前几何-运动学闭环” PCGL：深度→几何→任务需求→关节可实现→一致性→执行→接触事件回灌几何（在线校正手眼与深度尺度）→场景更新。

**灵感 5（不确定度预算 DUB + 在线手眼校正 HEC）**
直觉：深度不是免费的。帧率、点密度、有效掩膜、标定新鲜度都消耗预算；关节可实现性 QP 也有算力预算。它们应像第 60 轮的认知预算一样显式管理：B_depth 耗尽就退回接触探测（第 60 轮 SERC），B_kin 耗尽就下发保守固定关节阻抗并慢速接近。同时，接触事件是几何的“真值锚点”：视觉法向与力觉法向的残差可在线估计手眼外参漂移 ΔT 与深度尺度偏差 δz，让“看过”与“摸过”互相校正。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（深度几何先验接地 DGPG）** 给定深度帧、相机内参与手眼外参，反投影点云 P_t 与有效掩膜 V_t。对接触候选点 p 取 k 近邻，做局部 PCA：
- **局部几何描述子** g(p) = (n̂(p), κ(p), d_c(p), σ_n(p), ρ_vis(p))，其中
  - n̂(p) 为最小特征值 λ₀ 对应的特征向量（表面法向）；
  - κ(p) = λ₀ / (λ₀+λ₁+λ₂) ∈ [0, 1/3] 为表面曲率；
  - d_c(p) 为沿 n̂ 的净空（最近障碍距离）；
  - σ_n(p) ≈ σ_d(z) / r，σ_d(z) = a·z² + b·z + c 为深度噪声模型，r 为邻域半径；
  - ρ_vis(p) = |{有效点}| / k 为局部可见率。
- **几何→阻抗需求映射** ρ_geo: g → (K_x^req, F_n^req, v_app)：
  - 法向刚度 K_n 随曲率 κ 增大而降低（平面硬、弧面软），切向刚度 K_t ≈ 0.1·K_n；
  - 法向需求力 F_n^req 由 g 的先验表给出（平坦刚性面小力快触，软/未知面小力慢触）；
  - 接近速度 v_app ∝ γ_geo 并随 d_c 收缩。
- **几何置信度** γ_geo(p) = ρ_vis(p) · exp(−σ_n(p)/σ_n⁰) · γ_cal，其中 γ_cal 为手眼标定置信（见定义 167）。
- **门控**：仅当 γ_geo(p) ≥ τ_geo 才允许用该先验；否则该区域视为“未知 ≠ 自由”，回退第 60 轮接触探测，禁止把遮挡区当可触面。
- **几何先验**：π_geo(K_x | g) = N(K_x; μ_geo(g), Σ_geo(g))，Σ_geo 随 γ_geo 反比放大。

**定义 162（关节空间可实现性 JSR）** 给定位形 q、关节速度 q̇、任务阻抗 K_x ⪰ 0、阻尼 D_x ⪰ 0、法向 n̂ 与需求力 F_n^req。设 J = J(q) ∈ R^{6×n}，奇异值 σ_i。
- **空间映射**：K_q = JᵀK_xJ，D_q = JᵀD_xJ（同余变换保半正定）。
- **力矩**：τ = Jᵀ(K_xΔx + D_xΔẋ + F_ff) + g(q) + C(q,q̇)q̇。
- **可实现集** K_adm(q) = { K_x ⪰ 0 : ∃ 力矩分配满足下列全部约束 }：
  1. |τ_j| ≤ τ_j^max(q̇, T_j)（含速度/热降额）；
  2. q_min+δ ≤ q ≤ q_max−δ，且 |q̇| ≤ q̇_max；
  3. σ_min(J) ≥ σ_min^req（等价 κ(J)=σ_max/σ_min ≤ κ_max，远离奇异）；
  4. 法向力可行：F_n^max(q, n̂) ≥ F_n^req。
- **法向力支撑函数（闭式）**：当 J 为满秩方阵时
  F_n^max(q, n̂) = Σ_j τ_j^max · |(J⁻¹n̂)_j|。
  证明：F = J⁻ᵀτ ⇒ n̂ᵀF = (J⁻¹n̂)ᵀτ，在盒约束 |τ_j|≤τ_j^max 上最大化线性泛函，逐坐标取边界并按系数符号定向。冗余臂用 J 的加权伪逆 + QP 求同一支撑函数。
- **证书**：Cert_jsr = (K_q, τ_margin = min_j (τ_j^max−|τ_j^req|)/τ_j^max, σ_min, κ, μ(q)=√det(JJᵀ), F_n^max/F_n^req, q_margin)。

**定义 163（几何-运动学一致性门 GKG）** 设 f*(q, n̂) 为力可行多面体在方向 n̂ 上的支撑点。
- **法向偏差**：θ(q, n̂) = arccos( n̂ · f*/‖f*‖ )；
- **运动学法向增益**：g_n(q, n̂) = ‖J⁻¹n̂‖（单位法向力所需关节力矩范数的代理；也是法向微动的关节放大率）；
- **一致性分数**：C_gk(q, n̂) = min( F_n^max/F_n^req, g_n^max/g_n, cos θ / cos θ_max, 1 )。
- **门控规则**：C_gk ≥ 1 才允许沿 n̂ 直接接触；否则进入**重定向**（零空间腕部旋转、底座微移、换抓取点），而**禁止**用“降低 F_n 硬顶”或“投影改变法向”来伪造通过。

**定义 164（双空间阻抗编译 DAI）** 设任务空间安全集 K_safe^x（第 60 轮 EEIS+SSM，含场景先验 π_geo）与关节可实现集 K_adm(q)。
- **双空间可行集**：K_dual(q) = K_safe^x ∩ K_adm(q)。
- **选取**：K* = argmin_{K∈K_dual} [ J_task(K) + λ‖K−K_x^req‖²_F ]，再下发 K_q* = JᵀK*J。
- **空集处理**：若 K_dual = ∅，返回 `ADJUST_POSTURE`（冗余/底座/抓取）或 `RE_OBSERVE`（主动视角），**不得**返回投影后的 K_q。理由：投影会改变安全语义与接触法向，使证书“数值可行、物理错误”。
- **安全降级**：姿态调整不可达且预算不足时，返回 `DEGRADE_EXEC`（慢速接触探测或请求人类），并显式记录失败原因。

**定义 165（接触前几何-运动学闭环 PCGL）** 算子 PCGL(M, intent, δ_f^req)：
```
① Depth:      (P_t, V_t) ← capture_depth()
② DGPG:       g, γ_geo ← local_geometry(P_t)
③ Gate:       if γ_geo < τ_geo: return contact_probe_fallback(M)   # 第 60 轮 SERC
④ Prior:      (K_x^req, F_n^req, v_app) ← ρ_geo(g)
⑤ Intent:     K_safe^x ← EEIS.compile_with_prior(K_x^req, π_geo, δ_f^req)
              K_safe^x ← CIEC.constrain(K_safe^x, intent)
⑥ JSR:        Cert_jsr ← evaluate(q, q̇, K_safe^x, n̂, F_n^req)
⑦ GKG:        C_gk ← consistency(q, n̂); if C_gk < 1: return reorient(...)
⑧ DAI:        K* ← dual_space_compile(K_safe^x, K_adm(q))
              if K* = ∅: return ADJUST_POSTURE / RE_OBSERVE / DEGRADE_EXEC
⑨ Dispatch:   K_q* ← JᵀK*J; τ_cmd ← Jᵀ(K*Δx+D*Δẋ+F_ff)+g+Cq̇
⑩ Execute:    telemetry ← contact_execute(τ_cmd, v_app)
⑪ HEC:        ΔT, δz ← hand_eye_correct(g, telemetry)             # 定义 167
⑫ Certify:    Cert_gk ← build_cert(g, Cert_jsr, C_gk, γ_cal)      # 定义 168
⑬ Evidence:   EPIR.append(Cert_gk); scene_model.update(telemetry)  # 第 60 轮
⑭ Return:     (K*, Cert_gk, telemetry, g)
```

**定义 166（深度-关节不确定度预算 DUB）** B_dk = (B_depth, B_kin, B_cal)：
- B_depth = (frame_rate, point_density, valid_ratio, view_budget)；
- B_kin = (QP_ops, singular_eval_rate, torque_margin_floor)；
- B_cal = (calib_age, residual_threshold)；
- **主动视角**：v* = argmax_v E[IG(γ_geo) | v] / cost(v)，只在 B_depth 有余额时执行；
- **降级**：B_depth 耗尽 ⇒ `contact_probe_only`；B_kin 耗尽 ⇒ 下发保守固定 K_q⁰（慢速、低刚度）；B_cal 过期 ⇒ 强制 τ_geo 上调（更不信视觉）。

**定义 167（手眼-深度在线校正 HEC）** 接触事件同时给出力觉接触点/法向 (p_f, n̂_f) 与几何预测 (p_d, n̂_d)。
- 残差 r = [p_f − p_d; n̂_f − n̂_d]；
- 增量模型 r ≈ J_h·[ΔT(6); δz(1)]，用鲁棒递推最小二乘（Huber 降权）估计 x = [ΔT; δz]；
- 置信 γ_cal = 1/(1+trace(P))，随观测次数上升、随长时间无接触缓慢衰减；
- **防污染**：仅当 |r| 在鲁棒阈值内且接触被证书判定为合规时才更新，避免把一次撞错当成标定真值。

**定义 168（几何-运动学联合证书 GKC）** Cert_gk = (γ_geo, γ_cal, n̂, σ_n, K_x^req, F_n^req, K_q*, τ_margin, σ_min, κ, F_n^max/F_n^req, C_gk, valid, hash)。
- **有效性**：valid = (γ_geo ≥ τ_geo) ∧ (γ_cal ≥ τ_cal) ∧ (Cert_jsr 全约束满足) ∧ (C_gk ≥ 1) ∧ (|Δn̂_投影| ≤ θ_max)。
- **合成**：Cert_gk = Cert_eeis ∧ Cert_jsr ∧ Cert_gkg；任一子证书失效则整体失效，执行不得穿越。
- **上链**：Cert_gk 写入第 60 轮 EPIR 的影子副本，作为 EV-exec 的几何-运动学附件，供云端因果校验与复盘。

### IP-161 DGPG（深度几何先验接地）

```python
class DepthGeometricPrior:
    def __init__(self, K_intr, T_ee_cam, tau_geo=0.6, k_nn=20):
        self.K = K_intr
        self.T = T_ee_cam
        self.tau_geo = tau_geo
        self.k = k_nn
        self.calib_conf = 1.0

    def update_cloud(self, depth, valid=None):
        P, V = self._backproject(depth, valid)     # X = z K^{-1}[u,v,1]
        self.P = self._voxel_downsample(P, 0.005)
        self.normals, self.curv, self.sigma_n = self._estimate_normals(self.P)
        self.valid_ratio = V.mean()
        return self

    def _estimate_normals(self, P):
        normals, curv, sig = [], [], []
        for i, p in enumerate(P):
            nb = self._knn(P, p, self.k)
            C = np.cov((nb - nb.mean(0)).T)
            w, U = np.linalg.eigh(C)
            w = np.clip(w, 1e-12, None)
            n = U[:, 0]; n *= np.sign(n[2] + 1e-9)
            normals.append(n)
            curv.append(w[0] / w.sum())
            sig.append(np.sqrt(w[0] / self.k))       # 法向不确定度代理
        return np.array(normals), np.array(curv), np.array(sig)

    def local_geometry(self, idx):
        rho_vis = self._visibility_ratio(idx)
        d_c = self._clearance(idx)
        gamma = rho_vis * np.exp(-self.sigma_n[idx] / 0.05) * self.calib_conf
        return dict(p=self.P[idx], n=self.normals[idx], kappa=self.curv[idx],
                    d_c=d_c, sigma_n=self.sigma_n[idx],
                    rho_vis=rho_vis, gamma=float(gamma))

    def geometry_to_impedance(self, g):
        K_n = np.interp(g['kappa'], [0.0, 0.2], [800.0, 150.0])
        K_t = np.interp(g['kappa'], [0.0, 0.2], [80.0, 40.0])
        K_x = np.diag([K_t, K_t, K_n])              # 以 n 为局部 z 轴
        F_n_req = 5.0 + 10.0 * g['d_c']
        v_app = np.clip(0.05 * g['gamma'], 0.005, 0.05)
        return K_x, F_n_req, v_app

    def prior(self, g):
        K_x, F_n_req, v_app = self.geometry_to_impedance(g)
        Sigma = np.diag([1 / (g['gamma'] + 1e-6)] * 6) * 0.01
        return dict(K_x=K_x, Sigma=Sigma, F_n_req=F_n_req, v_app=v_app)
```

### IP-162 JSR（关节空间可实现性）

```python
class JointSpaceRealizability:
    def __init__(self, robot, sigma_min_req=0.02, kappa_max=50.0):
        self.robot = robot
        self.sigma_min_req = sigma_min_req
        self.kappa_max = kappa_max

    def evaluate(self, q, qd, K_x, n_hat, F_n_req):
        J = self.robot.jacobian(q)
        U, s, Vt = np.linalg.svd(J)
        sigma_min, kappa = s[-1], s[0] / max(s[-1], 1e-9)
        K_q = J.T @ K_x @ J
        J_pinv = np.linalg.pinv(J)
        Jinv_n = J_pinv @ n_hat[:3]
        tau_max = self.robot.torque_limit(q, qd)
        F_n_max = float(np.sum(tau_max * np.abs(Jinv_n)))
        tau_req = J_pinv.T @ (n_hat[:3] * F_n_req)
        tau_margin = float(np.min((tau_max - np.abs(tau_req)) / tau_max))
        q_margin = float(np.min(np.minimum(q - self.robot.q_lo,
                                           self.robot.q_hi - q)))
        feasible = (sigma_min >= self.sigma_min_req and kappa <= self.kappa_max
                    and F_n_max >= F_n_req and tau_margin >= 0 and q_margin >= 0)
        return dict(K_q=K_q, sigma_min=sigma_min, kappa=kappa,
                    F_n_max=F_n_max, tau_margin=tau_margin,
                    q_margin=q_margin, feasible=bool(feasible))
```

### IP-163 GKG（几何-运动学一致性门）

```python
class GeometryKinematicsGate:
    def __init__(self, theta_max=np.deg2rad(20), gain_max=5.0):
        self.theta_max = theta_max
        self.gain_max = gain_max

    def check(self, q, n_hat, F_n_req, jsr):
        J = self.robot.jacobian(q)
        Jinv_n = np.linalg.pinv(J) @ n_hat[:3]
        g_n = float(np.linalg.norm(Jinv_n))
        C = min(jsr['F_n_max'] / max(F_n_req, 1e-9),
                self.gain_max / max(g_n, 1e-9), 1.0)
        return dict(C_gk=float(C), g_n=g_n, ok=bool(C >= 1.0 - 1e-6))

    def reorient(self, q, n_hat):
        J = self.robot.jacobian(q)
        N = null_space(J)                            # 冗余零空间
        best = None
        for alpha in np.linspace(-0.3, 0.3, 13):
            q_try = q + N @ (alpha * np.ones(N.shape[1]))
            if self.robot.within_limits(q_try):
                score = self.robot.force_gain(q_try, n_hat)
                if best is None or score > best[0]:
                    best = (score, q_try)
        return best[1] if best else None
```

### IP-166 DUB（深度-关节预算）

```python
class DepthKinematicBudget:
    def __init__(self, depth_hz=15, qp_ops=200):
        self.B_depth, self.B_kin = depth_hz, qp_ops
        self.used_depth = self.used_kin = 0

    def has_depth(self):
        return self.used_depth < self.B_depth

    def next_best_view(self, candidates, info_gain, cost):
        if not self.has_depth():
            return None
        util = [info_gain[c] / max(cost[c], 1e-6) for c in candidates]
        c = candidates[int(np.argmax(util))]
        self.used_depth += cost[c]
        return c

    def mode(self):
        if self.used_kin >= self.B_kin:
            return 'conservative_joint_impedance'
        if self.used_depth >= self.B_depth:
            return 'contact_probe_only'
        return 'normal'
```

### IP-167 HEC（手眼-深度在线校正）

```python
class HandEyeCorrector:
    def __init__(self, dim=7, huber=0.01):
        self.x = np.zeros(dim)        # [ΔT(6), δz(1)]
        self.P = np.eye(dim)
        self.huber = huber

    def update(self, g, telemetry):
        p_d, n_d = g['p'], g['n']
        p_f, n_f = telemetry.contact_point, telemetry.contact_normal
        r = np.concatenate([p_f - p_d, n_f - n_d])
        J_h = self._residual_jacobian(g, telemetry)
        w = np.linalg.norm(r)
        rho = 1.0 if w <= self.huber else self.huber / w      # Huber 降权
        S = J_h @ self.P @ J_h.T + 1e-6 * np.eye(len(r))
        K = self.P @ J_h.T @ np.linalg.inv(S)
        self.x += rho * K @ (r - J_h @ self.x)
        self.P = (np.eye(len(self.x)) - rho * K @ J_h) @ self.P
        return self.x

    def confidence(self):
        return float(1.0 / (1.0 + np.trace(self.P)))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DGPG | O(N_p·k) 法向估计（KD-tree 可降至 O(N_p log N_p)） | O(N_p) | γ_geo 门控下法向误差 ≤ δ_n；遮挡区不被当作可触面 |
| JSR | O(n³) SVD/求逆 + O(n) 支撑函数；n=6~7 | O(n²) | 证书有效 ⇒ 力矩/限位/奇异裕度全满足 |
| GKG | O(n²) | O(n²) | C_gk ≥ 1 ⇒ 法向力可行且法向增益有界 |
| DAI | O(QP) + O(n³) | O(n²) | 空集不投影；三选一诚实降级 |
| PCGL | 每周期 O(深度 + QP)，多速率解耦 | 复用 | 接触前闭环；接触事件回灌校正 |
| HEC | O(dim³) / 接触事件 | O(dim²) | Huber 鲁棒，γ_cal 单调可信 |
| GKC | O(1) 组装 | O(1) | 子证书任一失效则整体失效 |

**多速率分层**：深度几何 15~30 Hz；JSR/GKG/DAI 100~1000 Hz（q 变化快、K_x^req 变化慢，缓存几何先验）；力矩环 1 kHz。这样“看得慢、算得快、控得更快”，避免把深度帧率拖进实时环路。

**引理 1（支撑函数）** 满秩方阵 J、盒约束 |τ_j| ≤ τ_j^max 下，沿单位方向 n̂ 的最大可施加力为 F_n^max = Σ_j τ_j^max |(J⁻¹n̂)_j|。
*证明*：F = J⁻ᵀτ ⇒ n̂ᵀF = (J⁻¹n̂)ᵀτ。在盒约束上最大化线性泛函，逐坐标取 τ_j = τ_j^max·sign((J⁻¹n̂)_j)。∎

**引理 2（刚度同余）** K_x ⪰ 0 ⇒ K_q = JᵀK_xJ ⪰ 0。*证明*：∀q̇，q̇ᵀK_q q̇ = (Jq̇)ᵀK_x(Jq̇) ≥ 0。∎

**正确性定理（DGKG）** 假设 A66–A70 成立：
- **(A66)** 深度噪声模型与 σ_n 估计是有效上界；γ_geo 是几何误差概率的上界代理。
- **(A67)** J(q) 在允许工作空间内满秩，τ_max 与限位已知且保守。
- **(A68)** 实际接触发生在被观测且 C_gk 通过的局部表面上。
- **(A69)** 手眼偏差缓慢变化，HEC 在有限接触事件内收敛到有界残差。
- **(A70)** B_depth/B_kin/B_cal 单调消耗，降级策略覆盖所有耗尽组合。

则：
1. **几何接地正确性**：γ_geo ≥ τ_geo ∧ A66 ⇒ 接触法向误差 ≤ δ_n，ρ_geo 给出的 K_x^req 落在真值需求的 1−α 置信集内。
2. **关节可实现性**：Cert_jsr 有效 ⇒ 执行 K_q* 的 τ 不饱和、q 不越限、σ_min ≥ σ_min^req；由引理 2，K_q* 半正定，阻尼环路耗散。
3. **一致性安全**：C_gk ≥ 1 ⇒ F_n^max ≥ F_n^req 且 g_n ≤ g_n^max，法向力可跟踪、法向微动不放大。
4. **双空间诚实性**：K_dual = ∅ ⇒ 系统返回姿态调整/重观测/降级，绝不返回改变法向超过 θ_max 的投影；因此“证书可行但物理错误”的静默失败不可达。
5. **校正收敛性**：A69 ∧ Huber 下界 ⇒ HEC 残差有界，γ_cal 不因单次错误接触而崩塌；γ_geo 随 γ_cal 更新。
6. **预算安全**：任一 B_dk 耗尽 ⇒ 对应降级（接触探测/保守关节阻抗/提高视觉门限），不进入不可实现执行。

### IP-161 DGPG（深度几何先验接地）

```python
class DepthGeometricPrior:
    def __init__(self, K_intr, T_ee_cam, tau_geo=0.6, k_nn=20):
        self.K, self.T, self.tau_geo, self.k = K_intr, T_ee_cam, tau_geo, k_nn
        self.calib_conf = 1.0

    def update_cloud(self, depth, valid=None):
        P, V = self._backproject(depth, valid)          # X = z K^{-1}[u,v,1]
        self.P = self._voxel_downsample(P, 0.005)
        self.normals, self.curv, self.sigma_n = self._estimate_normals(self.P)
        return self

    def _estimate_normals(self, P):
        normals, curv, sig = [], [], []
        for p in P:
            nb = self._knn(P, p, self.k)
            C = np.cov((nb - nb.mean(0)).T)
            w, U = np.linalg.eigh(C); w = np.clip(w, 1e-12, None)
            n = U[:, 0]; n *= np.sign(n[2] + 1e-9)
            normals.append(n); curv.append(w[0] / w.sum())
            sig.append(np.sqrt(w[0] / self.k))
        return np.array(normals), np.array(curv), np.array(sig)

    def local_geometry(self, idx):
        rho_vis = self._visibility_ratio(idx); d_c = self._clearance(idx)
        gamma = rho_vis * np.exp(-self.sigma_n[idx] / 0.05) * self.calib_conf
        return dict(p=self.P[idx], n=self.normals[idx], kappa=self.curv[idx],
                    d_c=d_c, sigma_n=self.sigma_n[idx], rho_vis=rho_vis,
                    gamma=float(gamma))

    def geometry_to_impedance(self, g):
        K_n = np.interp(g['kappa'], [0.0, 0.2], [800.0, 150.0])
        K_t = np.interp(g['kappa'], [0.0, 0.2], [80.0, 40.0])
        F_n_req = 5.0 + 10.0 * g['d_c']
        v_app = np.clip(0.05 * g['gamma'], 0.005, 0.05)
        return np.diag([K_t, K_t, K_n]), F_n_req, v_app

    def prior(self, g):
        K_x, F_n_req, v_app = self.geometry_to_impedance(g)
        Sigma = np.diag([1 / (g['gamma'] + 1e-6)] * 6) * 0.01
        return dict(K_x=K_x, Sigma=Sigma, F_n_req=F_n_req, v_app=v_app)
```

### IP-162 JSR（关节空间可实现性）

```python
class JointSpaceRealizability:
    def __init__(self, robot, sigma_min_req=0.02, kappa_max=50.0):
        self.robot, self.sigma_min_req, self.kappa_max = robot, sigma_min_req, kappa_max

    def evaluate(self, q, qd, K_x, n_hat, F_n_req):
        J = self.robot.jacobian(q)
        _, s, _ = np.linalg.svd(J)
        sigma_min, kappa = s[-1], s[0] / max(s[-1], 1e-9)
        K_q = J.T @ K_x @ J
        J_pinv = np.linalg.pinv(J); Jinv_n = J_pinv @ n_hat[:3]
        tau_max = self.robot.torque_limit(q, qd)
        F_n_max = float(np.sum(tau_max * np.abs(Jinv_n)))          # 引理 1
        tau_req = J_pinv.T @ (n_hat[:3] * F_n_req)
        tau_margin = float(np.min((tau_max - np.abs(tau_req)) / tau_max))
        q_margin = float(np.min(np.minimum(q - self.robot.q_lo,
                                           self.robot.q_hi - q)))
        feasible = (sigma_min >= self.sigma_min_req and kappa <= self.kappa_max
                    and F_n_max >= F_n_req and tau_margin >= 0 and q_margin >= 0)
        return dict(K_q=K_q, sigma_min=sigma_min, kappa=kappa, F_n_max=F_n_max,
                    tau_margin=tau_margin, q_margin=q_margin, feasible=bool(feasible))
```

```python
class GeometryKinematicsGate:
    def __init__(self, theta_max=np.deg2rad(20), gain_max=5.0):
        self.theta_max, self.gain_max = theta_max, gain_max

    def check(self, q, n_hat, F_n_req, jsr):
        Jinv_n = np.linalg.pinv(self.robot.jacobian(q)) @ n_hat[:3]
        g_n = float(np.linalg.norm(Jinv_n))
        C = min(jsr['F_n_max'] / max(F_n_req, 1e-9),
                self.gain_max / max(g_n, 1e-9), 1.0)
        return dict(C_gk=float(C), g_n=g_n, ok=bool(C >= 1.0 - 1e-6))

    def reorient(self, q, n_hat):
        N = null_space(self.robot.jacobian(q))
        best = None
        for alpha in np.linspace(-0.3, 0.3, 13):
            q_try = q + N @ (alpha * np.ones(N.shape[1]))
            if self.robot.within_limits(q_try):
                score = self.robot.force_gain(q_try, n_hat)
                if best is None or score > best[0]:
                    best = (score, q_try)
        return best[1] if best else None
```

### IP-164 DAI（双空间阻抗编译）

```python
def dual_space_compile(K_safe_x, q, n_hat, F_n_req, robot, budget):
    jsr = JointSpaceRealizability(robot).evaluate(q, robot.qd, K_safe_x, n_hat, F_n_req)

        return ('ADJUST_POSTURE', q_new, jsr)
```

### IP-166 DUB（深度-关节预算）

```python
class DepthKinematicBudget:
    def __init__(self, depth_hz=15, qp_ops=200):
        self.B_depth, self.B_kin = depth_hz, qp_ops
        self.used_depth = self.used_kin = 0

    def has_depth(self):
        return self.used_depth < self.B_depth

    def next_best_view(self, candidates, info_gain, cost):
        if not self.has_depth():
            return None
        util = [info_gain[c] / max(cost[c], 1e-6) for c in candidates]
        c = candidates[int(np.argmax(util))]
        self.used_depth += cost[c]
        return c

    def mode(self):
        if self.used_kin >= self.B_kin:
            return 'conservative_joint_impedance'
        if self.used_depth >= self.B_depth:
            return 'contact_probe_only'
        return 'normal'
```

### IP-167 HEC（手眼-深度在线校正）

```python
class HandEyeCorrector:
    def __init__(self, dim=7, huber=0.01):
        self.x, self.P, self.huber = np.zeros(dim), np.eye(dim), huber

    def update(self, g, telemetry):
        r = np.concatenate([telemetry.contact_point - g['p'],
                            telemetry.contact_normal - g['n']])
        J_h = self._residual_jacobian(g, telemetry)
        w = np.linalg.norm(r)
        rho = 1.0 if w <= self.huber else self.huber / w       # Huber 降权
        S = J_h @ self.P @ J_h.T + 1e-6 * np.eye(len(r))
        K = self.P @ J_h.T @ np.linalg.inv(S)
        self.x += rho * K @ (r - J_h @ self.x)
        self.P = (np.eye(len(self.x)) - rho * K @ J_h) @ self.P
        return self.x

    def confidence(self):
        return float(1.0 / (1.0 + np.trace(self.P)))
```

```python
    return c
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| DGPG | O(N_p·k)（KD-tree 可 O(N_p log N_p)） | O(N_p) | γ_geo 门控下法向误差 ≤ δ_n |
| JSR | O(n³)+O(n)，n=6~7 | O(n²) | 证书有效 ⇒ 力矩/限位/奇异裕度全满足 |
| GKG | O(n²) | O(n²) | C_gk ≥ 1 ⇒ 法向力可行且增益有界 |
| DAI | O(QP)+O(n³) | O(n²) | 空集不投影，三选一诚实降级 |
| PCGL | 每周期 O(深度+QP)，多速率解耦 | 复用 | 接触前闭环，接触事件回灌 |
| HEC | O(dim³)/接触事件 | O(dim²) | Huber 鲁棒，γ_cal 可信 |
| GKC | O(1) 组装 | O(1) | 子证书任一失效则整体失效 |

**正确性定理（DGKG）**：若 A66–A70 成立（深度噪声模型有效、J 满秩且限位/力矩已知、接触发生在已观测表面、手眼偏差慢变且 HEC 收敛、预算单调且降级完备），则：
1. **几何接地**：γ_geo ≥ τ_geo ⇒ 法向误差 ≤ δ_n，K_x^req 落在真值需求的 1−α 置信集内。
2. **关节可实现**：Cert_jsr 有效 ⇒ 执行 K_q* 时 τ 不饱和、q 不越限、σ_min ≥ σ_min^req，且 K_q* ⪰ 0（引理 2）。
3. **一致性安全**：C_gk ≥ 1 ⇒ F_n^max ≥ F_n^req 且 g_n ≤ g_n^max，法向力可跟踪、法向微动不放大。
4. **双空间诚实**：K_dual = ∅ ⇒ 返回姿态调整/重观测/降级；不存在“改变法向 > θ_max 的静默投影”路径，故命题 1 的伪安全不可达。
5. **校正收敛**：A69 + Huber 下界 ⇒ HEC 残差有界，γ_cal 不被单次错误接触污染。
6. **预算安全**：任一 B_dk 耗尽 ⇒ 接触探测 / 保守关节阻抗 / 提高视觉门限，不进入不可实现执行。

## 6. 本轮最大风险

**一句话**：若深度几何把“看似可触”误判为“真实接触面”（透明/反光/遮挡），而关节空间又把不可实现的 K_x 静默投影成一个方向已变、数值却“可行”的 K_q，两个空间各自都通过了证书，合起来却指向错误法向——形成“双重接地、联合错误”的共模失效；必须以 γ_geo 门控、C_gk 法向一致性门、接触事件在线校正、以及“投影不得改变法向超过 θ_max”的硬约束四重封堵。
