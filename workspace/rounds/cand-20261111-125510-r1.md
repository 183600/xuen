# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「安全交互」×「灵巧手」）

> 第 54 轮已把技能组合从“能力匹配”推进为“动作-鲁棒性双证书”。本轮灵感「安全交互」「灵巧手」迫使我们承认一个此前被 ρ 与 α_S 掩盖的事实：**可行 ≠ 可做 ≠ 可安全地做**。核心矛盾：H22：动作空间剖面 α_S 只描述“够得着/覆盖”，不描述“接触时是否安全”，而高灵巧动作恰恰贴着力/压强/奇异位形边界；H23：灵巧手的接触模式转移是离散-连续混合过程，云端证据在边端毫秒级触觉反射的时间尺度上失效。

## 0. 直觉与动机

**灵感 1（安全不是成功率的维度，而是可行域的硬约束）**
直觉：安全交互（不压伤人、不捏碎物体、不越力/压强/能量上限）本质是“不得越过”的约束，不能用 reward 加权与成功率做折中。第 54 轮的 ρ 是“扰动下仍成功的概率”，它天然可以被成功率稀释；安全必须独立成**约束层**。把安全从优化目标降级为可行域，意味着：一个技能即使成功率 99%，只要接触安全剖面越界，就应直接判不可部署。这就是**安全优先于能力**的第一性排序。

**灵感 2（灵巧手 = 接触模式切换能力，而非自由度数）**
直觉：灵巧不等于 DoF 多。真正的灵巧是“在保持力闭合的前提下，能在接触模式图里切换多少种模式、切换多平滑”。于是灵巧度 `Dex(S)` 应由三件事决定：可达的力闭合接触模式比例、模式间连续可迁移性、以及切换时的力/位形代价。安全交互会压缩可达模式集合，二者形成**安全-灵巧 Pareto 前沿**，而不是一个标量“灵巧分”。

**灵感 3（触觉反射必须下沉到边端，云端只定契约）**
直觉：滑移、过力、碰撞的物理时间常数在毫秒级，云端 50ms 的规划环回传根本来不及。安全交互因此必须是两级结构：**云端承诺安全契约**（力上限 `w_max`、人距下限 `d_min`、安全阈值 `θ_safe`、预算 `W_budget`），**边端执行反射**（CBF 安全屏蔽 + 触觉事件触发的 QP 投影）。云端证书若不能落到边端反射的时间粒度，就只是纸面安全。

**灵感 4（安全感知的技能组合：接触模式可迁移 + 力预算可加）**
直觉：组合两个技能时，即使动作空间 `compat` 很高，也可能在“接触模式切换”处产生瞬态力尖峰，或组合后最小安全剖面跌破阈值。所以第 54 轮的组合边条件要加三条：`min(β) ≥ θ_safe`、接触模式 `m_i → m_j` 存在且保持力闭合裕度 `κ ≥ η`、组合力预算 `W_chain ≤ W_budget`。组合从“路径搜索”变成**带安全硬约束的路径搜索**。

**灵感 5（人的安全是外部不可建模约束）**
直觉：共享工作空间里，人是分布外扰动源，不能被当成普通障碍物。必须引入速度-分离监控（SSM）与人的短时轨迹预测，把 `human_clearance` 写进证书，并在边端以最高优先级触发减速/退让。人安全不能被“平均成功率”代表，只能被**最坏情形距离下界**代表。

**灵感 6（金字塔再叠加安全-灵巧层）**
直觉：在第 54 轮 `𝕃`（鲁棒性）与 `𝔸`（动作协同）之上叠加 **安全-灵巧层 `𝕊`**：`𝕊_0` 物理安全边界（力/压强/能量/人距），`𝕊_1` 技能接触安全剖面，`𝕊_2` 边端反射屏蔽，`𝕊_3` 任务级人机契约。跨层迁移证书必须同时携带 `(ρ, A_cert, S_cert)`，构成 **动作-鲁棒-安全三证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（接触交互空间）**
灵巧手位形 `q ∈ Q ⊂ ℝⁿ`（n 个驱动自由度），接触集 `C = {(i, p_i, n_i)}`（第 i 指在 `p_i`、法向 `n_i` 接触）。单接触力旋量 `w_i = (f_i, τ_i) ∈ ℝ⁶`，聚合接触旋量 `W = ⊕_{i} w_i`。交互状态 `x = (q, q̇, o, C)`，其中 `o` 为物体位姿。接触交互空间 `𝒲 = ∪_C (ℝ⁶)^{|C|}`，其力闭合子集记为 `𝒲_fc`。

**定义 122（接触安全剖面）**
给定安全约束族 `g_j(x, W) ≤ 0, j = 1..m`（力上限、接触压强、物体应力、人距、能量），定义安全边际与**接触安全剖面**：
```
h(x,W) = -max_j g_j(x,W)
β_S(x,W) = clip( h(x,W) / h_ref , 0, 1 )
```
`β_S = 1` 表示深处于安全域内部，`β_S = 0` 表示已到安全边界。技能 S **安全可执行**当且仅当 `β_S(x,W) ≥ θ_safe`。注意：`α_S`（覆盖/可达）与 `β_S`（安全）是正交的两个剖面，**可达但不可安全执行**是灵巧手的常态。

**定义 123（灵巧度与接触模式图）**
接触模式 `m ∈ M` 为“哪些指以何种接触类型接触”的离散组合。抓取矩阵 `G_m`，力闭合裕度 `κ(m) = λ_min(G_m G_mᵀ)`（最小奇异值）。接触模式图 `H_S = (M, E_M)`，边 `(m,m') ∈ E_M` 当且仅当存在连续准静态转移且全程 `κ ≥ η`。**灵巧度**定义为可达力闭合模式的加权比例：
```
Dex(S) = (1/|M|) · |{ m' ∈ M_fc : m' 与某 m∈M_fc 在 H_S 中同连通分量 }| · exp(-L̄_trans)
```
其中 `L̄_trans` 为模式间平均迁移代价。`Dex` 度量的是**在安全前提下能切换的接触模式丰富度**，而非自由度数量。

**定义 124（安全交互契约）**
云边安全契约 `C_safe = (w_max, d_min, θ_safe, W_budget, τ_tac, π_shield)`：
- `w_max` 力/力矩上限向量；`d_min` 人机最小距离；
- `θ_safe` 接触安全剖面阈值；`W_budget` 组合力预算；
- `τ_tac` 触觉反射最大允许延迟；
- `π_shield : (u_nom, x) → u_safe` 为安全屏蔽，由 CBF-QP 实现：
```
u_safe = argmin_{u∈U} ||u - u_nom||²
         s.t.  L_f h(x) + L_g h(x) u + α(h(x)) ≥ 0
```
安全屏蔽的语义是：**最小干预地**把名义动作投影进前向不变安全集；若 `u_nom` 本身安全，则 `u_safe = u_nom`。

**定义 125（接触安全证书与安全保持组合）**
技能链 `S_1 ⊗ … ⊗ S_k` 的联合证书 `S_cert = (β_min, W_used, κ_min, τ_tac^p95, human_clearance, evidence)`。称组合为**安全保持组合** `SafeComp(S_1..S_k)`，当且仅当：
```
min_i β_{S_i} ≥ θ_safe
∧ ∀i, (m_i, m_{i+1}) ∈ E_{M} 且 κ_min ≥ η
∧ W_chain = Σ_i W_i + Σ_i W_trans,i ≤ W_budget
∧ max_i τ_tac,i ≤ τ_tac
∧ human_clearance ≥ d_min
```
其中 `W_trans,i` 为模式迁移瞬态力尖峰。关键：力预算**不可只看稳态**，瞬态尖峰才是安全违规主因。

**定义 126（安全-灵巧前沿）**
对技能 S 与安全阈值 `θ_safe`，定义**安全可达灵巧度**：
```
Dex_safe(S, θ_safe) = max { Dex(S') : S' ⊆ S, β_min(S') ≥ θ_safe }
```
安全-灵巧前沿 `F_S = { (Dex_safe(S,θ), β_min(S,θ)) : θ 变化 }`。任务 T 可行当且仅当存在 S 使 `Dex_safe(S,θ_safe) ≥ Dex_req(T)` 且 `β_min ≥ θ_safe`。**安全不是降低灵巧度上限，而是重定义其可行边界**。

## 2. 关键算法 伪代码

### IP-121 CSP（Contact Safety Profiling）

```python
def contact_safety_profile(skill, X, W_grid, constraints, tactile_sim, n_samples):
    beta = {}
    for x in sample_state_space(X, n_samples):
        for W in W_grid:
            trace = tactile_sim.rollout(skill, x, W)
            margins = [c.margin(trace) for c in constraints]   # g_j <= 0; margin>0 安全
            beta[(x, W)] = clip(max(margins) / H_REF, 0.0, 1.0)
    # 共形校准给出 β 的保守下界，避免乐观估计导致假安全
    return conformal_lower_bound(beta, alpha=0.05)
```

### IP-122 SDG（Safe-Dex Composition Graph）

```python
def safe_dex_graph(skills, theta_a, theta_safe, eta, W_budget, tau_tac):
    G = nx.DiGraph()
    for i, s in enumerate(skills):
        for j, t in enumerate(skills):
            if i == j:
                continue
            if jaccard(s.alpha, t.alpha) < theta_a:
                continue                      # 动作不可覆盖
            if min(s.beta_min, t.beta_min) < theta_safe:
                continue                      # 接触安全越界
            trans = contact_mode_transition(s.modes, t.modes, eta)
            if trans is None:
                continue                      # 无保力闭合的连续迁移
            W_chain = s.W_used + t.W_used + trans.W_spike
            if W_chain > W_budget:
                continue                      # 力预算超支
            if max(s.tau_tac, t.tau_tac) > tau_tac:
                continue                      # 反射太慢
            G.add_edge(i, j, compat=jaccard(s.alpha, t.alpha),
                       W_used=W_chain, trans=trans,
                       beta_min=min(s.beta_min, t.beta_min))
    return G
```

### IP-123 CBF-TR（Tactile Reflex Shield）

```python
def tactile_reflex_loop(skill, u_nom, x, w_max, alpha_cbf, tau_tac):
    ev = tactile.read()                        # 滑移/碰撞/过力事件
    if ev.slip or (ev.wrench > w_max).any():
        u_safe = solve_cbf_qp(u_nom, x, alpha_cbf)   # 最小干预投影
        return u_safe, SafetyEvent(ev, latency=measured_latency())
    return u_nom, None

def solve_cbf_qp(u_nom, x, alpha):
    # min ||u-u_nom||^2 s.t. Lf h + Lg h u + alpha(h) >= 0, u in U
    return qp_solver(u_nom, cbf_constraint(x, alpha), bounds=U)
```

### IP-124 SSC（Safe Skill Certificate）

```python
def safe_skill_certificate(chain, theta_safe, W_budget, tau_tac_max, d_min):
    beta_min = min(s.beta_lb for s in chain)
    if beta_min < theta_safe:
        return ('reject', 'safety_margin', beta_min)
    W_used = compose_wrench_budget(chain)          # 稳态 + 瞬态尖峰
    if W_used > W_budget:
        return ('reject', 'wrench_budget', W_used)
    if max(s.tau_tac for s in chain) > tau_tac_max:
        return ('reject', 'reflex_latency')
    if not contact_modes_connected(chain, eta=ETA):
        return ('reject', 'mode_gap')
    if min_human_clearance(chain) < d_min:
        return ('reject', 'human_distance')
    return ('ok', S_cert(beta_min, W_used, kappa_min(chain),
                         tau_tac_max, min_human_clearance(chain), evidence=chain))
```

### IP-125 DSR（Dexterity-Safety Router）

```python
def dexterity_safety_router(task, skills, theta_safe):
    Dex_req = task.dexterity_requirement
    cand = []
    for s in skills:
        Dex_safe = max_dexterity_under_safety(s, theta_safe)
        if Dex_safe >= Dex_req and s.beta_min >= theta_safe:
            cand.append((Dex_safe, s.beta_min, s))
    # 返回安全-灵巧 Pareto 前沿，交由上层按人距/节拍偏好选择
    return pareto_front(cand, maximize=(0, 1))
```

### IP-126 HSC（Human Safety Contract）

```python
def human_safety_contract(human_traj, robot_state, v_max, d_min, a_max, H):
    d_pred = min_distance_prediction(human_traj, robot_state, horizon=H)
    v_ssm = sqrt(2 * a_max * max(d_pred - d_min, 0.0))   # 速度-分离监控
    zone = 'stop' if d_pred <= d_min else ('slow' if v_ssm < v_max else 'free')
    return Contract(v_max=min(v_max, v_ssm), d_min=d_min, zone=zone,
                    evidence=(human_traj, robot_state, d_pred))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CSP | O(N_x·|𝒲|·τ_rollout) | O(N_x·|𝒲|) | 共形下界、约束覆盖 |
| SDG | O(|S|²·(|α|+|M|²)) | O(|S|²+|E|) | 安全边际 sound、力预算单调 |
| CBF-TR | O(d³) / QP | O(d²) | CBF 前向不变、最小干预 |
| SSC | O(|chain|·(|𝒲|+|M|)) | O(|𝒲|) | 瞬态尖峰计入、三证书一致 |
| DSR | O(|S|·|M|·|E_M|) | O(|M|) | Dex_safe 单调、前沿完整 |
| HSC | O(H·|human|) | O(H) | 预测保守、最坏距离下界 |

**正确性定理（Contact-Safe Dexterous Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增假设：
**(A29)** 接触安全剖面经共形校准，`P(β < β̂_lb) ≤ δ_β` 且采样覆盖 ≥ 1-δ_c；
**(A30)** CBF 安全屏蔽在安全集 `𝒮` 上前向不变，干预延迟 ≤ τ_cbf，且名义动作安全时不改动；
**(A31)** 触觉事件检测延迟 ≤ τ_tac，漏检率 ≤ γ_tac；
**(A32)** 组合力预算满足 `W_chain ≤ Σ W_i + W_trans`，`W_trans` 由迁移证书上界约束。

把安全与任务成功拆成两条：
```
P(safe) ≥ 1 - δ_β - δ_c - γ_tac - P(W_chain > W_budget) - P(d < d_min)
P(success ∧ safe) ≥ P(safe) · [ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a) ]
```
即 **安全是乘性门槛，不是加性惩罚**：安全概率为 0 时，再高的鲁棒性谱也不能挽救部署。关键：`β̂_lb` 用保守下界、`W_trans` 显式建模、`π_shield` 保证前向不变。

## 6. 本轮最大风险

**一句话**：安全交互与灵巧手的引入把体系从“动作-鲁棒双证书”升级为“安全硬约束下的灵巧部署”，但其 soundness **同时押注于接触安全剖面 β 的 sim-to-real 保真、CBF 屏蔽的前向不变性、以及触觉反射的毫秒级不遗漏**；一旦 β 乐观或屏蔽晚到，证书会把“未观测到的力尖峰/模式切换失败”误判为安全，故必须以 **共形保守下界 β̂_lb + 数据驱动 CBF 不变集 + 触觉冗余与硬回退** 三重护栏，宁可牺牲灵巧度，也绝不把“仿真里的安全边际”当成真机上的安全保证。

### IP-121 CSP

```python
def contact_safety_profile(skill, X, W_grid, constraints, tactile_sim, n_samples):
    beta = {}
    for x in sample_state_space(X, n_samples):
        for W in W_grid:
            trace = tactile_sim.rollout(skill, x, W)
            margins = [c.margin(trace) for c in constraints]   # margin > 0 表示安全
            beta[(x, W)] = clip(max(margins) / H_REF, 0.0, 1.0)
    return conformal_lower_bound(beta, alpha=0.05)             # β̂_lb 保守下界
```

### IP-122 SDG

```python
def safe_dex_graph(skills, theta_a, theta_safe, eta, W_budget, tau_tac):
    G = nx.DiGraph()
    for i, s in enumerate(skills):
        for j, t in enumerate(skills):
            if i == j or jaccard(s.alpha, t.alpha) < theta_a:
                continue
            if min(s.beta_min, t.beta_min) < theta_safe:
                continue
            trans = contact_mode_transition(s.modes, t.modes, eta)
            if trans is None:
                continue
            W_chain = s.W_used + t.W_used + trans.W_spike
            if W_chain > W_budget or max(s.tau_tac, t.tau_tac) > tau_tac:
                continue
            G.add_edge(i, j, compat=jaccard(s.alpha, t.alpha),
                       trans=trans, W_used=W_chain,
                       beta_min=min(s.beta_min, t.beta_min))
    return G

def contact_mode_transition(modes_a, modes_b, eta):
    for m in modes_a:
        for m2 in modes_b:
            path = shortest_force_closed_path(m, m2)   # 全程 κ >= eta
            if path is not None:
                return Transition(m, m2, path, W_spike=path.max_wrench_spike())
    return None
```

def tactile_reflex_loop(skill, u_nom, x, w_max, alpha_cbf, tau_tac):

### IP-124 SSC

```python
def safe_skill_certificate(chain, theta_safe, W_budget, tau_tac_max, d_min):
    beta_min = min(s.beta_lb for s in chain)
    if beta_min < theta_safe:
        return ('reject', 'safety_margin', beta_min)
    W_used = compose_wrench_budget(chain)              # 稳态 + Σ 瞬态尖峰
    if W_used > W_budget:
        return ('reject', 'wrench_budget', W_used)
    if max(s.tau_tac for s in chain) > tau_tac_max:
        return ('reject', 'reflex_latency')
    if not contact_modes_connected(chain, eta=ETA):
        return ('reject', 'mode_gap')
    if min_human_clearance(chain) < d_min:
        return ('reject', 'human_distance')
    return ('ok', S_cert(beta_min, W_used, kappa_min(chain),
                         tau_tac_max, min_human_clearance(chain), evidence=chain))
```

### IP-125 DSR

```python
def dexterity_safety_router(task, skills, theta_safe):
    Dex_req = task.dexterity_requirement
    cand = []
    for s in skills:
        Dex_safe = max_dexterity_under_safety(s, theta_safe)
        if Dex_safe >= Dex_req and s.beta_min >= theta_safe:
            cand.append((Dex_safe, s.beta_min, s))
    return pareto_front(cand, maximize=(0, 1))         # 安全-灵巧 Pareto 前沿

def max_dexterity_under_safety(skill, theta_safe):
    best = 0.0
    for subset in mode_subsets(skill, ordered_by_force_closure=True):
        if subset.beta_min >= theta_safe:
            best = max(best, Dex(subset))
    return best
```

def human_safety_contract(human_traj, robot_state, v_max, d_min, a_max, H):
    d_pred = min_distance_prediction(human_traj, robot_state, horizon=H)
    v_ssm = sqrt(2 * a_max * max(d_pred - d_min, 0.0))
    zone = 'stop' if d_pred <= d_min else ('slow' if v_ssm < v_max else 'free')

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CSP | O(N_x·|𝒲|·τ_rollout) | O(N_x·|𝒲|) | 共形下界覆盖 ≥ 1-δ_c |
| SDG | O(|S|²·(|α|+|M|²)) | O(|S|²+|E|) | 安全边际 sound，力预算单调 |
| CBF-TR | O(d³)/QP，控制频率执行 | O(d²) | CBF 前向不变、最小干预 |
| SSC | O(|chain|·(|𝒲|+|M|)) | O(|𝒲|) | 瞬态尖峰计入，三证书一致 |
| DSR | O(|S|·|M|·|E_M|) | O(|M|) | `Dex_safe` 单调，前沿完整 |
| HSC | O(H·|human|) | O(H) | 预测保守，最坏距离下界 |

**正确性定理（Contact-Safe Dexterous Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增：
**(A29)** `β̂_lb` 为共形保守下界：`P(β < β̂_lb) ≤ δ_β`，采样覆盖 ≥ 1-δ_c；
**(A30)** CBF 安全屏蔽在安全集 `𝒮` 上前向不变，干预延迟 ≤ τ_cbf，名义安全时不改动；
**(A31)** 触觉事件检测延迟 ≤ τ_tac，漏检率 ≤ γ_tac；
**(A32)** 组合力预算 `W_chain ≤ Σ W_i + W_trans`，`W_trans` 由迁移证书上界约束。

安全与任务成功**分离证明**：
```
P(safe) ≥ 1 - δ_β - δ_c - γ_tac - P(W_chain > W_budget) - P(d < d_min)          (S1)
P(success ∧ safe) ≥ P(safe) · [1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)]        (S2)
```
**关键**：安全是**乘性门槛**而非加性惩罚；`P(safe)=0` 时任何鲁棒性谱都无法挽救部署。`β̂_lb` 保守化、`W_trans` 显式上界、`π_shield` 前向不变共同保证 (S1)；第 54 轮动作-鲁棒条件保证 (S2)。
