# 第 42 轮（新循环第 2 轮） · 移动操作 × 场景泛化：把「泛化」重写为「可证搬运」——场景相对证书层（SRC × WBCF × SGC）（四层架构 v8）

> 承接第 41 轮 v18（CAR × LCS × CMC）与第 42 轮产物 v19（SCV × CKB × ECR）。v19 的飞轮解决了「证书生产太贵」，却默认了两个前提：证书的**适用域**是场景无关的（ValidRegion 写在世界坐标/固定语义图上），技能是**固定基座**的（守卫不区分底盘在哪、看不看得见、够不够得着）。移动操作与场景泛化正好拆掉这两个前提：前者让「机器人在哪、以什么姿态观察与施力」成为证书的一部分；后者让「换一个房间、换一个同类物体、换一种摆放」不再等于重新认证。本轮核心主张：**泛化不是统计相似，而是可证搬运——只要存在一个低畸变的场景态射，把已认证的交互基元搬到新场景，证书就可以带着可计算的裕度折损被搬运过去；搬不动、搬不准或搬错了，必须显式降级。** 证书由此从「一张世界坐标下的大表」升级为「一层局部证书 + 搬运映射」。

## 0. 直觉与动机

**先区分两种泛化**：统计泛化问「平均来看，新场景的失败率有多低」；证书泛化问「对**这一个**新场景，我能否给出可信的界，或者明确拒绝」。第 41 轮的 ValidRegion、v19 的 C_sim 都偏向后者，但它们的「场景」仍被隐式固定：语义图不变、物体角色不变、基座不动。移动操作把矛盾推到极致——机器人一边走一边改变自己的观测、可达集与施力方向，证书若写在世界坐标里，底盘动 20 cm 就可能失效；场景泛化则要求同一技能在换房间、换同类物体、换摆放后仍成立。于是问题变成：*证书的哪些部分是场景的「规范选择」，哪些才是真正决定安全的「不变量」？*

**灵感 1（场景泛化 → 证书应写在「交互基元」的局部框架里，而非世界坐标里）**：一次移动操作真正依赖的几何，通常不是「桌子的绝对位姿」，而是「手柄轴与接近方向的关系、肘部到桌沿的净空、支撑多边形相对重心的位置、目标容器开口是否在可达锥内」。这些关系在一个**交互基元**（task-relevant motif）的局部框架中表达，天然对全局 SE(3) 变换等变：把整个房间平移旋转，证书一字不改仍然成立。这是「免费的泛化」——对称群轨道内的泛化。但真实场景泛化不止于刚体变换：同类物体尺寸不同、抽屉换成柜门、桌上多了一把椅子。这些是**态射**而不是群作用。直觉的解法是：把泛化写成「从已认证基元到新场景的角色保持态射」，并用几何/属性/拓扑畸变 δ 给证书裕度打折；δ 小则搬，δ 大则就地重证，找不到态射则拒绝。这样「泛化能力」从一个网络属性变成一个**可检查的搬运证书**。

**灵感 2（移动操作 → 证书不是单点断言，而是基座图册上的纤维截面）**：移动操作的核心冗余是：同一个末端位姿 ξ 可以由许多组 (基座位姿, 臂构型) 实现，即 π⁻¹(ξ) 是一条纤维。只在一个 IK 解上认证是危险的：换一个基座位置，肘部可能撞桌、相机可能被遮挡、力椭圆可能退化。因此证书必须覆盖**整条纤维**（或其连通分支），至少给出一个由纤维直径与 Lipschitz 常数推出的保守下界。更麻烦的是，基座移动会让「可用的纤维」本身变化：某些任务点只有靠近才可达，某些只有退后才能看清。于是把任务空间划成**基座图册**：每张图给出一个基座区域、一个截面（选定基座策略）与该图上的纤维裕度；图与图的重叠处需要转移映射。绕一圈基座运动回到同一任务点，证书可能回不到原值——这就是**和乐（holonomy）**，它把「移动操作中的路径依赖」变成一个可测量的安全漂移。

**灵感 3（耦合 → 证书层与下降条件：局部证书何时能粘成全局证书）**：SRC 处理连续几何的搬运，WBCF 处理基座/全身体冗余的搬运，SGC 处理离散组合（新物体、新支撑关系、新子场景）的搬运。三者统一在同一张数学图景里：把场景分成若干**站点**（交互基元、基座图、文法产生式），每个站点携带局部证书，站点重叠处携带搬运/限制映射；只有当所有重叠上的映射满足**上闭链条件（cocycle/descent）**时，局部证书才能粘成一张全局证书。粘不上，不是「模型不够强」，而是一个可观测的矛盾：两张图对同一物理量的保守界互相冲突，或文法推导在接口处净空为负。此时自动机应进入 Watch/Degraded，而不是继续自信执行。**这把「泛化失败」从静默的性能下降，变成运行时可检测的证书下降失败。**

**与 v19 飞轮的关系**：v19 解决「证书从哪里来、怎么便宜地跑」；本轮解决「证书凭什么能用在没见过的场景/基座上」。飞轮仍然是生产者，SRC/WBCF/SGC 是**搬运与粘贴层**，CAR 是消费与守门层。新增的纪律是：**没有搬运映射的复用不算认证**；统计相似只能产生候选，不能产生安全结论。

## 1. 形式化定义

**定义 38（交互基元 Interaction Motif）**：场景图 S=(V,E,A,τ)，其中 τ:V→SE(3) 为几何实现，A 为物体属性（类别、可供性、质量、摩擦、关节轴等）。给定任务 φ，交互基元 M=(V_M,E_M,ρ,F_M) 是满足以下条件的连通子图：V_M⊆V 只保留对 φ 的可行性有因果作用的节点（删除任一节点会改变可行性谓词），ρ:V_M→Roles 为角色分配（目标物、支撑面、容器、障碍、工具、关节），F_M∈SE(3) 为由至少两个正交锚定特征（如手柄轴、支撑面法向、开口朝向）构造的**规范框架**。局部坐标 z=T_{F_M}^{-1}x。M 的实例化记为 S⊨M。

**定义 39（场景相对证书 SRC）**：C_M=(G_M,I_M,m_M,θ_M,L_M,ε_M)，其中 G_M 为局部坐标下的守卫族（可达性、净空、支撑/接触稳定、可见性），I_M 为局部不变式，m_M(z) 为证书边际（取各守卫裕度的最小值），θ_M 为阈值，L_M 为 m_M 对局部状态与框架扰动的 Lipschitz 常数，ε_M 为标定置信。**证书语义**：对任意 S⊨M 与任意满足 I_M 的局部状态，若 m_M≥θ_M，则对应安全谓词成立。**等变性**：对任意 T∈SE(3) 作用于世界，m_{T·S}(Tz)=m_S(z)，因此轨道内泛化不需要新证书。

**定义 40（证书搬运与泛化半径）**：场景态射 f:M→M′ 由角色保持的图同态、属性匹配与框架对齐 A_f∈SE(3) 组成。其**畸变**定义为
δ_f = max_{v∈V_M} d_SE3(A_f T_v, T′_{f(v)})/ℓ + λ_a·d_attr + λ_t·d_topo，
其中 ℓ 为特征长度（消除尺度），d_attr 为角色相关属性差（尺寸、摩擦、关节行程），d_topo 为拓扑编辑代价（多/少一个支撑、遮挡关系改变）。若 f 还满足接触一致性（法向、摩擦锥、可达方向不被翻转），则拉回证书 f*C_M 满足
m_{M′}(z) ≥ m_M(z) − L_M·δ_f。
定义**泛化半径** R_M=(m_M−θ_M)/L_M。若 δ_f≤R_M，则搬运后的证书 sound；若 δ_f>R_M，必须就地重证（CEGAR/采样）或拒绝。场景 S′ 到基元库的**泛化距离**为 d_gen(S′)=min_{M,f} δ_f。**命题（搬运可靠性）**：在 δ_f 为真上界、L_M 为真 Lipschitz 界的前提下，δ_f≤R_M 蕴含搬运证书在 S′ 上 sound。证明由 Lipschitz 定义直接得到；风险全部集中在「δ_f 是否被低估」与「接触一致性是否被漏检」。

**定义 41（基座图册与纤维证书 WBCF）**：全身体构型 q=(q_b,q_a)∈Q=Q_b×Q_a，任务映射 π:Q→Ξ（末端位姿+接触旋量）。纤维 F_ξ=π⁻¹(ξ)。一个**基座图** U_i=(Ξ_i,B_i,σ_i,m_i) 包含：任务点开集 Ξ_i、可行基座区域 B_i⊆Q_b（使 π⁻¹(ξ)∩(B_i×Q_a) 非空且无碰）、截面 σ_i:Ξ_i→Q（选定的基座策略与 IK 分支）、纤维裕度
m_i(ξ)=min_{q∈π⁻¹(ξ)∩(B_i×Q_a)∩Q_adm} m(q)。
若纤维非凸/不连通，则用「纤维直径 + Lipschitz」给保守下界，或对每个连通分支单独认证。重叠 Ξ_i∩Ξ_j 上的转移映射 φ_ij 把图 i 的证书搬到图 j；**上闭链条件**为 φ_jk∘φ_ij=φ_ik（容差 ε_glue）。绕基座闭环 γ 的和乐 Hol_γ=φ_γγ−Id，裕度漂移满足 |Δm|≤L_M‖Hol_γ‖。任务点 ξ 称为**移动操作可认证**，当且仅当存在图 i 使 ξ∈Ξ_i 且 m_i(ξ)≥θ。

**定义 42（场景文法与组合证书 SGC）**：属性图文法 G=(N,T,P,S,A)，产生式 p:L_p→R_p 带接口 I_p=L_p∩R_p、嵌入关系与证书模板 C_p。推导 τ:S_0⇒…⇒S 的累计退化
Δ(τ)=Σ_{p∈τ}(Δ_p^geom+λ_t Δ_p^topo)。
**粘合条件**：在每个接口上，父/子证书经转移后的守卫差 ≤ε_glue 且合取不变式非空。若 S∈L(G) 且所有接口满足粘合，则
m(S) ≥ m_0 − Δ(τ) − L_glue·ε_glue。
若解析失败，则 S∉L(G)，判为 OOD；文法可用反例场景做 CEGAR 扩展。**覆盖**用保形预测给出 P(S∈L(G)) 的下置信界，作为泛化证书的概率部分。

**定义 43（证书层与下降条件）**：把上述站点（基元、基座图、文法产生式）视为层 X 的开覆盖 {U_i}，局部证书为截面 s_i∈C_M(U_i)，重叠上的搬运/限制映射为 ρ_ij。全局证书存在当且仅当**下降条件**成立：ρ_jk∘ρ_ij=ρ_ik（上闭链）且各局部守卫在重叠上符号一致。下降失败给出一个可定位的矛盾见证（witness），可直接转成 CAR 的降级事件或 CEGAR 的精化目标。**设计约束（可证搬运原则）**：任何跨场景/跨基座复用必须附带显式搬运映射 (f,δ_f) 或文法推导 τ；无映射的复用视为未认证；δ 无法上界时按 +∞ 处理，只能指向 Degraded/SafeStop，绝不能指向 Nominal。**覆盖优先于紧致**：当 δ 接近 R 时，宁可局部重证或进 Watch，也不要用一张濒临失效的搬运证书换取更高的 Nominal 占比。

## 2. 三大产出设计

### 2.1 IP-57 SCENE-RELATIVE-CERT（场景相对证书 SRC）
1. **基元抽取**：从 TRI-FUSE/LIO 的场景图出发，按任务 φ 与开放词汇可供性打分抽取角色子图；用两个正交锚定特征构造 F_M，并检查框架可辨识性（特征近共线、单点支撑等退化情形直接拒绝）。
2. **局部证书**：在 F_M 下计算四类边际——可达性（臂长/关节限位/自碰）、净空（多分辨率 ESDF）、支撑/接触稳定（支撑多边形、摩擦锥、ZMP/力椭圆）、可见性（相机视锥与遮挡）。取最小者为 m_M，并用解析/采样混合估计 L_M。
3. **搬运搜索**：角色约束的图匹配 + SE(3) 对齐 + 属性/拓扑畸变计算；接触一致性检查（法向、摩擦锥、接近方向）作为硬过滤。若 δ≤R 则拉回并扣裕度；否则在差异区域跑局部 CEGAR/采样补证，补证失败则拒绝。
4. **基元库与泛化距离图**：把 (motif 指纹, 证书, 适用域, δ 上界) 存入 IP-55 CKB；运行时先查最近基元，输出 d_gen 与建议动作（搬运/重证/降级）。
5. **与 CAR 接口**：搬运守卫写成 m′≥θ+λ·δ_upper（λ>1 为安全余量）；δ 接近 R 时自动进 Watch；无态射时进 Degraded 并触发局部重证。

### 2.2 IP-58 WHOLE-BODY-CERT-FIBRATION（全身体纤维证书 WBCF）
1. **基座图册构建**：在任务空间采样，求每个任务点的可行基座集合 B(ξ) 与 IK 分支；把连通、证书裕度达标的区域合并成图；图边界保留足够重叠，保证转移有余量。
2. **纤维认证**：对每个图，用区间/ Lipschitz 界覆盖整条纤维；对非凸或断裂纤维按连通分支分别处理；用 IP-54 SCV 做基座轨迹压力测试，找出「基座一动就失效」的窄纤维。
3. **转移与和乐**：在重叠区定义基座路径与证书转移；运行时监控上闭链残差与绕圈和乐；残差超 ε_glue 即重证或切换图。
4. **基座—臂联合规划**：IP-39 规划器以 m_i(ξ)−L·dist 为启发式选择图与基座策略，优先选择「裕度大、转移短、重叠厚」的图，而不是几何最短路径。
5. **执行期守卫**：全身体控制器在每个控制拍检查当前 q 是否仍在图的可行基座区与纤维内；一旦越界，走 CAR 的 Degraded 而非硬停。

### 2.3 IP-59 SCENE-GRAMMAR-CERT（场景文法证书 SGC）
1. **文法库**：产生式覆盖「放置/堆叠/插入/开门/收纳/多物拥挤」等组合模式；每个产生式带接口、局部证书模板、几何/拓扑退化 Δ_p；接口显式记录支撑面、开口、抓取点等共享变量。
2. **解析与认证**：新场景先解析成推导树（typed grammar + 深度/时间上界），计算 Δ(τ) 与粘合残差；若 m(S)≥θ 则签发组合证书，否则在失败接口处局部重证。
3. **OOD 与 CEGAR**：解析失败或粘合失败即 OOD；把反例场景归因为「缺产生式/Δ 过松/接口定义错」，分别触发文法扩展、模板收紧或接口重定义；用保形预测维护文法覆盖率。
4. **文法级场景采样**：IP-54 的域随机化从「像素/物理参数扰动」升级为「文法级编辑」——替换物体类别、增删支撑、改变关节行程、制造遮挡与拥挤；这样压力测试直接覆盖组合泛化面。
5. **与 SRC/WBCF 的耦合**：文法给出基元与接口，SRC 给局部证书，WBCF 给每个基元的基座图；三者通过定义 43 的下降条件粘成全局证书。

### IP-57 SRC：基元抽取、证书搬运与泛化半径

```
def extract_motif(S, task, role_scorer):
    M = task_relevant_subgraph(S, task, role_scorer)   # 删除会改变可行性谓词
    anchors = select_anchors(M)                        # 至少两个正交几何特征
    if not frame_identifiable(anchors): return None     # 近共线/单点支撑退化
    F = canonical_frame(anchors)
    return Motif(M, F, localize(S, M, F))

def transport_certificate(C_src, M_new, R_src=None):
    R = R_src if R_src is not None else (C_src.m - C_src.theta) / C_src.L
    best = None
    for f in role_preserving_morphisms(C_src.motif, M_new):
        if not contact_consistent(f):                  # 法向/摩擦锥/接近方向
            continue
        delta = distortion_se3(f) + lam_a * distortion_attr(f) + lam_t * distortion_topo(f)
        margin = C_src.m - C_src.L * delta
        if margin >= C_src.theta:
            best = max(best, (margin, f, delta), key=lambda t: t[0])
    if best is None:
        return None, "NO_CERTIFIED_TRANSPORT"          # 拒绝，而非猜
    margin, f, delta = best
    slack = lam_s * delta                              # 安全余量，λ_s>1
    guard = lambda z: margin - slack >= C_src.theta
    return PulledBackCert(C_src, f, margin, delta, guard), "OK"

def generalization_radius(C):
    return (C.m - C.theta) / C.L

def decide_reuse(C, M_new):
    cert, status = transport_certificate(C, M_new)
    if status != "OK": return "RECERTIFY_LOCAL"
    if cert.delta > 0.8 * generalization_radius(C):
        return "WATCH_THEN_RECERTIFY"                  # 覆盖优先于紧致
    return "ACCEPT"
```

```
    for loop in fundamental_loops(path_gamma):

        for (i, j) in edges_along(loop, atlas):
            g = compose(g, atlas.transition(i, j))
        drift = max(drift, norm(g - identity_transition()))
```

### IP-59 SGC：场景文法解析、粘合与 OOD

```
def parse_and_certify(S, G, cert_lib, max_depth=12, budget_ms=8):
    trees = G.parse(S, max_depth=max_depth, budget=budget_ms)  # typed + memoized
    if not trees:
        return None, "OOD_UNPARSED"
    best = None
    for tau in trees:
        delta = sum(G.delta[p] for p in tau.productions)
        if not interfaces_consistent(tau, eps_glue):
            continue
        margin = G.m0 - delta - L_glue * eps_glue
        if margin >= theta:
            best = max(best, (margin, tau), key=lambda t: t[0])
    if best is None:
        return None, "GLUING_FAIL"                       # 可定位的下降失败
    return ComposedCert(best[1], best[0]), "OK"

def interfaces_consistent(tau, eps):
    for (p, iface) in tau.interfaces():
        m_parent = transport_margin(p.parent_cert, iface)
        m_child = transport_margin(p.child_cert, iface)
        if abs(m_parent - m_child) > eps: return False
        if empty_intersection(p.parent_inv, p.child_inv, iface): return False
    return True

def cegar_grammar(S_fail, G, cause):
    if cause == "MISSING_PRODUCTION": return add_production(G, minimal_scene_motif(S_fail))
    if cause == "LOOSE_DELTA":        return tighten_delta(G, S_fail)
    if cause == "BAD_INTERFACE":      return redefine_interface(G, S_fail)
    return G
```

**关键正确性说明**：
1. **搬运可靠性**依赖 δ_f 的上界。SE(3) 项可由标定/区间给出；属性项（尺寸、摩擦）可由传感器区间给出；拓扑项由文法解析给出。任一项不可上界，δ=+∞。
2. **纤维下界**是保守的：m(q) 对 q 的 Lipschitz 常数 L_state 与纤维直径 diam 相乘；若纤维断裂，必须逐分支认证，否则下界无效。
3. **文法粘合**是充分条件：局部证书不能自动保证组合安全，接口处的净空、支撑与接触必须显式检查；粘合失败是可定位的下降见证。
4. **CAR 守卫**是合取：任一搬运/图册/文法守卫不确定，就按单调保守性指向 Degraded/SafeStop，不会指向 Nominal。
