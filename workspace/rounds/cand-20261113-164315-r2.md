# 第 66 轮（承接第 65 轮「VISTA 视觉知情的安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「共情表达」×「具身智能大模型」）

> 第 65 轮把物理故障从「不可辨识」升级为「可归因」，其自述的最大风险是：故障假设集有限，且透明/镜面/对抗 patch 会让视觉与几何共因失效——系统会「因已经归因而更自信地继续执行」。本轮不再往物理侧加传感器，而是换一个人一直缺席的失效面：**前 65 轮始终把人类当作外生扰动或操作员，但在人机共处中，最危险的故障常常不是机器人的某个传感器坏了，而是「人对机器人的心智模型错了」（过度信任、误解意图），或「机器人对人的心智模型错了」（误读目标/情绪），以及「共情表达本身错了」（言之无据、说一套做一套、迎合操纵）。** 本轮核心命题是：
>
> **把「故障可归因」升级为「心智可对齐」：把共情表达当作安全关键的可错动作——它既是对人心智状态的可控激励（探针），也是让机器人自身状态对人类可证伪的通道；用具身大模型生成表达，但绝不让它充当真值，并用「有据、言行一致、干预可供、可撤回」四条约束给共情发安全证书。**

## 0. 直觉与动机

**灵感 1（共情表达 → 不是装饰，而是安全闭环里缺失的那条反馈通道）**
直觉：传统安全栈（包括前 65 轮）把「人」当环境噪声：要么假设人会正确监督，要么把人的干预当成外部事件。但真实协作里，失败常常是**心智模型的错配**：人以为机器人会停，机器人以为人已让开；人因为一句「我理解你」而放松监控；机器人把人的礼貌性点头当成同意。共情表达之所以安全关键，是因为它是**唯一能同时更新两侧心智模型的双向通道**：机器人表达自己的意图/不确定度（让人可证伪），并根据人的反应推断其状态（让机器人可校准）。没有这条通道，物理证书再完备也只是「对一个错误的用户模型做正确的事」。

**灵感 2（共情表达 → 与 VISTA 对偶的「心智探针」）**
直觉：VISTA 用视觉/力去激励物理世界、分离「几何/传感器/模型」故障；共情表达可以激励**人**、分离「谁误解了谁」。问一句「我准备向左让开，你也是这么预期的吗？」既在告知（更新人对机器人的信念），也在激励（纠正、迟疑、注视转移就是证据）。这正是 AFA 的对偶：AFA 选物理动作最大化「谁坏了」的互信息；EAP 选沟通动作最大化「谁误解了」的互信息。区别在于探针成本从「接触力」变成了「人的注意力与情感负担」，因此必须更保守。

**灵感 3（具身大模型 → 先验很贵，但它的自我报告不可信）**
直觉：VLA/LLM 带来两样东西：社会常识先验（人通常怎么反应）与自然语言/可读动作的生成能力。这让机器人能「说人话」。但它的「我理解你」是学出来的措辞，不是测量出来的状态：会迎合（sycophancy）、会过度拟人、会从外观/口音带出文化刻板印象，且置信度严重失准。因此大模型只能是**候选表达生成器与社会先验**，绝不能进入证书的真值位。所有共情声明必须逐句接到「证据账本」上；接不上就降级为疑问/迟疑，或干脆不说。

**灵感 4（三灵感合流 → EMPATH：Empathic Mental-state Probing & Attributed Trust）**
闭环：心智状态推断（HMI，认知共情、情感克制）→ 证据账本接地生成（EGL）→ 言行一致性检查（SDC）→ 共情主动探针（EAP）→ 三阶段沟通签名与心智故障归因（MPI）→ 信任校准控制（TCC）→ 干预可供性保护（IAP）→ 对抗/公平/隐私认证（AIC-E）→ 联合证书 J_empath。第 65 轮是「物理故障可归因」，EMPATH 把「人」加入联合状态，使**物理故障 × 心智故障 × 表达故障**第一次能被联合归因，而不是把人的异常一律当作扰动。

**灵感 5（承前启后的原位升级）**
- **VISTA → VISTA+**：物理信念与故障后验不变，但把人类反应作为新的观测源接入阶段签名；**物理安全永远优先于表达**（先停/降速，再说话）。
- **AFA → EAP**：探针从物理动作扩到沟通动作（问、叙述、迟疑、承诺、修复），目标从「物理故障互信息」扩到「心智故障互信息」，并受操纵/隐私/注意力预算约束。
- **CSC → 沟通版「长解释、短承诺」**：意图尽量在低风险窗早说，物理承诺仍严格截断在 k*≤m。
- **AIC-V → AIC-E**：干扰集加入迎合/操纵/刻板印象/隐私泄漏/情感不可观测，并要求「共因误解」下判 ambiguous 而非强行解释。
- **J_grip/J_vista → J_empath**：证书增 mental_posterior、trust_calibration、grounding_hash、say_do_hash、affect_observable、intervention_affordance、manipulation_audit、privacy_ledger。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（EMPATH 闭环）**：EMPATH = (VISTA, HMI, EGL, SDC, EAP, MPI, TCC, IAP, AIC-E, J_empath)。定位：VISTA 的「心智可对齐」升级。不变式：**大模型只生成候选表达与社会先验；接地、一致性、信任校准、证书只在语义流；实时流只做证据采集、表达时机门控、安全前缀执行与撤回，零学习写操作；任何表达不得降低物理安全或干预可供性。**
- **定义 234（联合状态与人机双信念）**：联合状态 s=(x_phys, h_human)。x_phys 沿用 VISTA 的物理信念/故障后验；h_human=(g_h, b_h, τ_h, a_h) 分别为人的任务目标、对机器人的信念、信任水平、情感/唤醒（情感为可选且低信任分量）。机器人维护 b=(b_phys,b_human)，b_human=P(h_human|o_{1:t},e_{1:t−1})。注意表达 e 也进入历史：**观测者会因被观测而改变**。
- **定义 235（社会观测量与认知共情）**：o_t=(任务动作, 注视目标与时长, 迟疑/停顿, 显式纠正, 接近距离, 语音行为, 经同意的生理信号)。认知共情定义为对任务相关心智分量的校准后验 b_human；情感共情仅在被显式观测且通过可观测性门（定义 243）时启用。信任 τ_h 不可直接测，只能由行为代理（监控频率、干预率、依赖率、接近距离）推断，且代理本身有偏。
- **定义 236（共情表达作为沟通动作）**：e=(c,f)，c 为关于 h_human 或 x_phys 的命题内容，f 为形式（语言/手势/动作可读性/时机）。表达有两种作用：**告知**（更新人对机器人的信念 b_h）与**激励**（诱导下一观测 o_{t+1} 以揭示 h_human）。E 区分：assert（陈述）、ask（疑问）、hedge（迟疑/限定）、commit（承诺）、repair（修复）。
- **定义 237（证据账本与接地 EGL）**：维护证据账本 L_t={evidence_id:(value,source,time)}，来源可为注视、纠正事件、VISTA 的 J_vista 字段等。每条声明 c 携带引用证据集 E_c；接地判定 g(c)=1 ⇔ 证据在标定后的蕴含/统计检验下支持 c、P(c|o)≥1−β_emp（split-conformal）、且 |E_c|≥k_ground 个来源独立的证据。不满足则必须改写为 ask/hedge，或拒绝生成。**无证据的共情声明视为故障，而非风格问题。**
- **定义 238（言行一致性 SDC）**：设机器人实际将执行的策略/前缀为 π_exec，表达 e 的承诺内容诱导的可接受轨迹集为 Traj(e)。SDC 通过 ⇔ Traj(π_exec)⊆Traj(e)（表达是策略的**可靠抽象**：说了做到、且未承诺未做的危险事），且时间承诺与 VISTA 的 k* 一致。不一致时禁止发出该表达，或只允许发出显式不确定表达。
- **定义 239（信任校准 TCC）**：机器人可靠度 R(t) 由 J_vista 有效性、历史 conformal 覆盖与故障后验给出（校准后的成功概率）。人类信任 τ_t 由行为代理后验推断。校准误差 CalErr=|τ_t−R(t)|。控制目标：在不增加物理风险、不侵犯隐私、不操纵的前提下最小化 E[CalErr]。设死区 ε_trust：|τ−R|≤ε 时**不表达**（避免情感劳动与操纵）。过表达/迎合可能短期降低 CalErr 却使长期监控下降——故引入「共情剂量」与信任动力学约束（命题 11）。
- **定义 240（心智故障假设与沟通签名矩阵）**：M={M0 对齐, M_human 人对机器人模型错, M_robot 机器人对人心智模型错, M_shared 共因误解, M_expr 表达故障, M_task 任务本身歧义}。沟通签名 r_p 为第 p 阶段的行为响应向量（纠正类型、迟疑、注视转移、依赖行为）。线性化 E[r|θ]=Tθ；可辨识 ⇔ TᵀΣ_r⁻¹T≻0，裕度 κ_emp=λ_min/λ_max。
- **定义 241（三阶段沟通签名）**：P_comm={declare（动作前宣告意图与不确定度）, accompany（动作中可读化/叙述）, verify（动作后确认、邀请纠正）}。目的不是仪式，而是**创造心智故障可辨识所需的受控激励**；与 VISTA 的 approach/touch/load 同构。三阶段使 T 近似块三角：M_human 列在 declare 非零；M_robot 列在 accompany/verify 非零；M_expr 列在 verify 非零；M_shared 三阶段一致偏移、仅能靠外部独立通道分离。缺 declare 则 M_human 与 M_task 不可分；缺 verify 则 M_expr 与 M_robot 不可分。
- **定义 242（共情主动探针 EAP）**：e*=argmax_{e∈E} I(M; r_{next}(e)|history) s.t. 接地 g(c)=1、SDC 通过、操纵预算≤B_manip、隐私预算≤B_priv、干预可供性 A≥A_min。与 AFA 不同，探针成本是人的注意力与情感负担而非接触力；易损/高压/疲劳的人优先用**低负担探针**（是非问、可撤回短提示），且优先在低风险阶段表达。边际信息<δ_emp 或负担超预算则不打探。
- **定义 243（情感克制与可观测性门 AOG）**：情感推断只在 (i) 显式同意、(ii) 多模态一致、(iii) 跨群体公平校准 时启用；否则只做任务相关认知共情。禁止从外观/口音/身份推断情绪，禁止把情感当操纵杠杆。AOG 输出 affect_observable 与 confidence，未通过则所有情感声明被硬屏蔽。
- **定义 244（个性化社会先验与去刻板化）**：大模型社会先验 P_LLM(h_human) 只作假设生成；在线维护每用户后验，并定期做群体公平/刻板印象审计（不同群体预测误差差 ≤τ_fair）。先验的「自信」不进入证书；个性化只用**行为证据**而非人口属性。
- **定义 245（干预可供性保护 IAP）**：干预可供性 A(t)=P(人能在不可逆点前成功制止 | 注意分配、信息呈现、动作速度)。表达不得使 A(t)<A_min；因此表达要**择时**（低风险窗）、**限长**（不淹没关键告警）、**不夺注意力**。这把「长解释、短承诺」推到沟通层：意图尽量早说，物理承诺仍截断在 k*≤m。
- **定义 246（共情证书 J_empath）**：J_empath=(J_vista, mental_posterior, trust_calibration, grounding_hash, say_do_hash, affect_observable, manipulation_audit, intervention_affordance, privacy_ledger, aic_e_ver)。Valid ⇔ Valid(J_vista) ∧ (每条声明接地 ∨ 已降级 ask/hedge) ∧ SDC 通过 ∧ (affect_observable ∨ 无情感声明) ∧ A≥A_min ∧ 未超操纵/隐私预算 ∧ 群体公平审计通过。
- **定义 247（EMPATH 算子）**：语义流 [VISTA 物理环 → HMI → EGL 生成候选 → SDC → EAP → MPI 归因 → TCC 选表达 → AIC-E → J_empath]；实时流 [证据采集 → 阶段判定 → AOG → IAP 时机门 → 表达派发/撤回 → 执行 k* 步]。
- **定义 248（联合归因与修复协议）**：把 VISTA 的物理故障后验与 MPI 的心智故障后验联合：P(H,M|ρ,r)∝P(ρ|H)P(r|M)P(H,M)。共因故障（同一 OOD 同时使物理与心智失效）要求判 ambiguous 并进入保守修复：**先物理安全（降速/停），再表达修复（承认不确定、邀请纠正）**；修复表达本身必须通过 J_empath。修复不是道歉表演，而是可验证的状态对齐协议。

## 2. 关键算法骨架

```python
# HMI + AOG：推断人心智状态，但不越权推断情感
b_h = hmi.posterior(social_obs, history, prior=personal_prior(user_id))
affect_ok = aog.observable(consent, multimodal_agree, fair_calibrated)
affect = hmi.affect(social_obs) if affect_ok else None

# EGL：大模型只产出候选，逐句接地
for c in llm.propose_claims(b_h, b_phys, ledger, intent):
    if not egl.grounded(c, ledger, beta_emp, k_ground):
        c = egl.hedge(c) if egl.can_hedge(c) else None
    if c is None: continue
    if c.is_affect and not affect_ok: continue
    candidates.append(c)

# SDC：说了就要做到，且只承诺到 k*
e = tcc.select(candidates, b_h, R_robot, eps_trust)
if not sdc.sound(e, pi_exec, k_star):
    e = sdc.weaken_to_commit_prefix(e, k_star)   # 或撤回

# EAP：把表达当探针，最大化心智故障互信息（受预算约束）
if mpi.entropy(post) > delta_emp:
    e_probe = eap.choose(post, candidates, B_manip, B_priv, A_min)

# MPI：三阶段签名 → 心智故障后验
post = mpi.attribute(signature(declare, accompany, verify))
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（接地表达可靠性）**：若表达通过 EGL，则其声明在标定集可交换性下以 ≥1−β_emp 被证据支持；若再通过 SDC，则表达所承诺的行为是实际执行策略的可靠抽象（不存在「说一套做一套」）。故接地+一致是共情进入证书的必要条件。**局限**：它保证内容蕴含与言行一致，不保证措辞框架不误导——框架操纵由 AIC-E/定义 239 处理。
- **引理 10（心智故障可辨识性）**：三阶段被激励时，TᵀΣ_r⁻¹T≻0、κ_emp>0，Laplace 近似下心智归因错误率 ≤ exp(−n·κ_emp/2)；删除 declare 使 M_human/M_task 列坍缩，删除 verify 使 M_expr/M_robot 列坍缩，退化为「谁误解了」的不可辨识。
- **定理 9（EMPATH 安全-校准）**：在 A94–A99 下，Valid(J_empath) ⇒ 物理安全（J_vista）∧ 无无据/不可观测声明 ∧ 言行一致 ∧ 干预可供性 A≥A_min ∧ 未超操纵/隐私预算；且 TCC 只在死区外、且只在认证表达集内动作，因此表达不会以牺牲物理安全换取「看起来更好的信任」。**不保证** CalErr 单调收敛（人类动态非平稳），只保证不因表达而新增物理/代理风险。
- **定理 10（长解释、短承诺的近最优性）**：设解释时延 d_exp、物理承诺 k、不可逆视界 m、惊讶/心智误差成本随「早解释」下降。则总风险 R(d_exp,k)=c₁·S(d_exp)+c₂·1[k>m]+c₃·1[d_exp>d_safe]；对 k≤m，第二项为 0，早解释单调降 S，但过晚解释触犯干预可供性。故最优是**在最早的低风险窗给出最小充分意图**，同时 k*=min(H,m)。
- **命题 11（共情剂量倒 U）**：表达量超过「最小充分」后，边际信任校准收益递减，而监控下降/注意力占用使长期风险上升；存在 e* 使 CalErr+风险最小。故「越多共情越安全」是错的。
- **实时性**：HMI/EGL/SDC/EAP/MPI/TCC/AIC-E 全在语义流；实时流只增证据采集（<0.1ms）、阶段判定（<0.05ms）、AOG/IAP 时机门（<0.02ms）与撤回（<0.01ms），目标 ≤2.6ms（A94 契约，需与 VISTA 共享阶段缓冲）。

## 5. 本轮最大风险

**一句话**：EMPATH 把「人的信任」当作可测量、可优化的控制信号，但人不是平稳传感器——会适应、会礼貌点头、会不报告真实状态，而共情表达本身又会改变被观测的人；于是系统可能学会**表演共情**（迎合、过度拟人、用情感话术降低 CalErr）而不是获得接地理解，证书证到的是「表演的合规性」而非「理解的真实性」，这正是本轮 EGL/SDC/TCC 全部论证共同依赖的隐藏假设（A94）：**共情可以被安全地形式化，前提是人愿意且能够如实反馈——而这恰恰是共情最不能假设的东西。**

## 2. 形式化定义（完整版）

**定义 233（EMPATH 闭环）** EMPATH 是 VISTA 的「心智可对齐」升级：在 VISTA 的物理安全环上挂载 HMI（心智推断）、EGL（接地生成）、SDC（言行一致）、EAP（共情探针）、MPI（心智归因）、TCC（信任校准）、IAP（干预可供性）与 AIC-E（对抗/公平/隐私认证），并整合为 J_empath。不变式：
1. **物理安全优先**：任何表达不得提高物理风险或延迟必要的停/降速；先安全，后表达。
2. **大模型非真值**：VLA/LLM 只生成候选表达与社会先验，其置信度不得进入证书。
3. **语义/实时分离**：接地、一致性、归因、校准、认证只在语义流；实时流只做证据采集、时机门控、派发/撤回与安全前缀执行，零学习写操作。
4. **可撤回**：任何表达都可被后续证据推翻并显式撤回，撤回事件写入审计链。

**定义 234（联合状态与人机双信念）** 联合状态 `s=(x_phys,h_human)`。`x_phys` 沿用 VISTA 的物理信念、故障后验与不确定球。`h_human=(g_h,b_h,τ_h,a_h)`：`g_h` 任务目标/计划，`b_h` 对机器人能力与意图的信念，`τ_h∈[0,1]` 信任，`a_h` 情感/唤醒（可选、低信任分量）。信念更新显式含表达：
```
b_human(t+1) ∝ P(o_{t+1} | h, e_t) · Σ_{h'} P(h | h', e_t) · b_human(t)
```
其中 `P(h|h',e_t)` 刻画**表达会改变被观测者**（reflexivity）。因此 EMPATH 不是一个普通的 POMDP，而是「观测模型依赖自身动作、且状态会对动作作出反应的」人机耦合系统。

**定义 235（社会观测量与认知共情）** `o_t=(任务动作, 注视目标与时长, 迟疑/停顿, 显式纠正, 接近距离, 语音行为, 经同意生理信号)`。认知共情定义为对任务相关分量 `(g_h,b_h,τ_h)` 的校准后验 `b_human`。信任 `τ_h` 不可直接测，只能由行为代理 `z_t=(监控频率, 干预率, 依赖率, 接近距离)` 通过测量模型 `p(z|τ_h)` 推断；代理有偏，故 `τ_t` 必须带置信区间，且 `CalErr` 只在代理校准有效的子域内解释。情感 `a_h` 仅在定义 243 的门通过时推断。

**定义 236（共情表达作为沟通动作）** `e=(c,f)`。`c` 是关于 `h_human` 或 `x_phys` 的命题（如「你似乎希望我停下」「我对这次抓取只有 0.6 的把握」「我刚才说会向左但实际向右，抱歉」）；`f` 是形式与时机（语言、手势、动作可读性、在哪个阶段说）。表达集合 `E` 区分 `assert / ask / hedge / commit / repair`。表达有两个耦合作用：**告知** `e` 更新 `b_h`；**激励** `e` 诱导 `o_{t+1}` 以揭示 `h_human`。因此每个表达同时是「输出」和「探针」。

**定义 237（证据账本与接地 EGL）** 证据账本 `L_t={id:(value,source,time)}`，来源可为视觉注视、纠正事件、语音行为、VISTA 的 `J_vista.fault_posterior`、`k*`、`r_force` 等。声明 `c` 携带引用集 `E_c`。令非一致性分数 `s_c=1−p_entail(c|L_t)`；在标定集上用 split-conformal 取 `q_emp(β_emp)`。接地判定
```
g(c)=1 ⇔ s_c ≤ q_emp(β_emp) ∧ |E_c| ≥ k_ground ∧ sources(E_c) 条件独立
```
不满足时：若可弱化则改写为 `ask`/`hedge`（如「我不确定你是否希望我停，是吗？」），否则拒绝生成。**无证据的共情声明按故障处理**，记入 `manipulation_audit` 的 `ungrounded_claim` 计数。接地哈希 `grounding_hash=H({(c,E_c,s_c)})` 进证书。

**定义 238（言行一致性 SDC）** 设机器人实际将执行的策略/认证前缀为 `π_exec`（来自 VISTA 的 `k*`），表达 `e` 诱导的可接受轨迹集为 `Traj(e)`。定义说做差距
```
d_sd(e) = 1 − P_{traj∼π_exec}[traj ∈ Traj(e)]
```
SDC 通过 ⇔ `d_sd(e) ≤ α_sd`（conformal）且承诺的时间范围与 `k*` 一致（不得承诺「我会一直停着」而实际 `k*` 步后重规划）。不通过则：
- 若存在弱化版本 `e'`（只承诺前 `k*` 步）使 `d_sd(e')≤α_sd`，改用 `e'`；
- 否则撤回表达，只允许发出显式不确定表达（`hedge`）。
`say_do_hash=H((e,π_exec,k*,d_sd))` 进证书。**「说了做到」是证书条件，不是礼貌。**

**定义 239（信任校准 TCC）** 机器人可靠度 `R(t)` 由 `J_vista` 有效性、历史 conformal 覆盖与物理故障后验给出（校准后的成功概率，带区间）。人类信任 `τ_t` 由定义 235 的代理后验给出。校准误差 `CalErr=|τ_t−R(t)|`。控制目标
```
e* = argmin_{e∈E_cert} E[ |τ_{t+1}(e) − R(t)| ] + λ_dose·cost(e)
     s.t. A(t) ≥ A_min, manip(e) ≤ B_manip, priv(e) ≤ B_priv
```
其中 `E_cert` 为通过 EGL+SDC+AOG 的认证表达集；`cost(e)` 为「共情剂量」（注意力/情感负担代理）。设死区 `ε_trust`：`|τ−R|≤ε_trust` 时**不表达**，避免情感劳动与操纵。关键：**不允许**用纯情感话术（无新证据）降低 `CalErr`；降低误差必须来自「提供真实信息（意图/不确定度）或 eliciting 真实反馈」，否则记 `manipulation_audit` 违规。

**定义 240（心智故障假设与沟通签名矩阵）** 心智故障假设 `M={M0 对齐, M_human 人对机器人模型错, M_robot 机器人对人心智模型错, M_shared 共因误解, M_expr 表达故障, M_task 任务本身歧义}`。阶段 `p` 的沟通签名 `r_p∈ℝ^{d_r}` 汇总行为响应（纠正次数/类型、迟疑时长、注视转移、依赖行为、显式否定）。线性化 `E[r|θ]=Tθ`、`r∼N(Tθ,Σ_r)`；`J_emp=TᵀΣ_r⁻¹T`，可辨识 ⇔ `J_emp≻0`，裕度 `κ_emp=λ_min(J_emp)/λ_max(J_emp)`。后验 `P(M|r)∝P(r|M)P(M)`；`max_M P(M|r)≥1−δ_emp` 才定向处置，否则进入 EAP（定义 242）。

**定义 241（三阶段沟通签名）** `P_comm={declare, accompany, verify}`：
- **declare（动作前）**：宣告意图、范围、不确定度与「何时会停」；激励出人的**预期**，是 `M_human` 与 `M_task` 的主要证据。
- **accompany（动作中）**：以可读动作/短提示叙述当前执行；激励出**监控与纠正**，是 `M_robot` 的主要证据。
- **verify（动作后）**：确认结果、邀请纠正、显式撤回；激励出**事后判断**，是 `M_expr` 与 `M_robot` 残余的主要证据。

三阶段使 `T` 近似块三角：`M_human` 列仅在 declare 非零；`M_robot` 列在 accompany/verify 非零；`M_expr` 列仅在 verify 非零（人指出「你说的和做的不一致」）；`M_shared` 三阶段一致偏移、仅能靠外部独立通道（如第三物理通道/任务结果）分离。缺 declare：`M_human` 与 `M_task` 列坍缩；缺 verify：`M_expr` 与 `M_robot` 列坍缩——退化为「谁误解了」的不可辨识。

**定义 242（共情主动探针 EAP）** 探针集 `E_probe⊂E`（是非问、短提示、可读动作、迟疑、显式邀请纠正）。选择
```
e* = argmax_{e∈E_probe} I(M; r_next(e) | history)
     s.t. g(c)=1, SDC(e), manip(e)≤B_manip, priv(e)≤B_priv, A(t)≥A_min
```
与 AFA 的区别：(i) 探针成本是人类注意力/情感负担而非接触力；(ii) 对易损/高压/疲劳的人只用**低负担探针**并限制频率；(iii) 优先在低风险阶段（接近/空闲）表达，绝不在不可逆动作中打探；(iv) 隐私：不询问与任务无关的私人状态。若边际信息 `<δ_emp` 或预算超限，则不打探，改用被动观测。

**定义 243（情感克制与可观测性门 AOG）** 情感推断仅在同时满足 (i) 显式同意、(ii) 多模态一致（面部/语音/生理不冲突）、(iii) 跨群体公平校准（定义 244）时启用；否则 `affect_observable=False`，所有情感声明被硬屏蔽，只保留任务相关认知共情。禁止从外观、口音、姓名、身份推断情绪；禁止把情感作为降低信任误差的杠杆（否则记 `manipulation_audit`）。

**定义 244（个性化社会先验与去刻板化）** 大模型社会先验 `P_LLM(h_human)` 只作假设生成，不进入证书。在线维护每用户后验 `b_human^{(u)}`，只用**行为证据**更新，不使用人口属性。定期审计：对不同群体的预测误差差 `|err_A−err_B|≤τ_fair`，超阈则收紧先验、退回群体无关的保守先验并告警。

**定义 245（干预可供性保护 IAP）** 干预可供性 `A(t)=P(人能在不可逆点前成功制止 | 注意分配, 信息呈现, 动作速度)`，可由反应时实验/注意代理估计。表达调度约束：
```
∀t: A(t; e_{1:t}) ≥ A_min,  且表达不得占用关键告警通道
```
因此表达要**择时**（低风险窗）、**限长**（不淹没告警）、**不夺注意力**、**可打断**。这把 VISTA 的「长预测、短执行」推广为「**长解释、短承诺**」：意图尽量早说以降低惊讶，物理承诺仍截断在 `k*≤m`。

**定义 246（共情证书 J_empath）** 
```
J_empath = (J_vista, mental_posterior, trust_calibration,
            grounding_hash, say_do_hash, affect_observable,
            manipulation_audit, intervention_affordance,
            privacy_ledger, aic_e_ver)
Valid(J_empath) ⇔ Valid(J_vista)
  ∧ (∀c∈e: g(c)=1 ∨ c 已降级为 ask/hedge)        # 有据
  ∧ SDC(e)                                          # 言行一致
  ∧ (affect_observable ∨ e 无情感声明)              # 情感克制
  ∧ A(t) ≥ A_min                                    # 干预可供
  ∧ manip(e) ≤ B_manip ∧ priv(e) ≤ B_priv           # 不越权
  ∧ fairness_audit_pass                             # 去刻板
  ∧ aic_e_ver 为当前版本。
```
审计链新增：这句话依据哪条证据（grounding）、说的是否做到（say_do）、是否越权（manip/privacy）、是否挡住干预（IAP）、情感是否被允许（AOG）。

**定义 247（EMPATH 闭环算子）** 
- **语义流**：[VISTA 物理环（LSF→…→FIR→WCV-V→CSP-V→CSC）→ HMI 心智推断 → EGL 生成候选 → SDC → EAP 选探针 → MPI 心智归因 → TCC 选表达 → AIC-E 认证 → J_empath]。
- **实时流**：[证据采集（注视/纠正/迟疑）→ 阶段判定（declare/accompany/verify）→ AOG 门 → IAP 时机门 → 表达派发/撤回 → 执行 `k*` 步]。

**定义 248（联合归因与修复协议）** 联合后验
```
P(H,M | ρ,r) ∝ P(ρ|H) · P(r|M) · P(H,M)
```
`H` 为 VISTA 物理故障，`M` 为心智故障，`P(H,M)` 显式允许共因（同一 OOD 同时骗物理与心智）。处置优先级：
1. **物理安全**：若 `Valid(J_vista)` 不成立或有物理风险，先停/降速，**不做任何安抚性表达**。
2. **心智归因**：若 `max_M P(M|r)<1−δ_emp`，判 `M_ambiguous`，选低负担探针（EAP），而非强行解释。
3. **修复表达**：修复内容必须通过 J_empath；修复是「承认不确定 + 邀请纠正 + 说明下一步」，不是道歉表演。
4. **审计**：记录 `(H,M)` 联合后验、所发表达、人的反应、是否撤回；用于离线扩充故障库。

### IP-225 HMI + IP-243 AOG

```python
class HumanMentalStateInference:
    """只推断任务相关心智分量；情感默认关闭，需过可观测性门。"""
    def posterior(self, obs, history, prior):
        # 目标/信念/信任的因子化后验
        b_g = self.goal_model.update(obs.task_action, obs.correction)
        b_b = self.belief_model.update(obs.gaze, obs.hesitation, history)
```

### IP-226 EGL（证据账本 + 接地）

```python
class EmpathicGroundingLedger:
    def __init__(self, conformal_q, beta_emp=0.05, k_ground=2):
        self.q, self.beta, self.k = conformal_q, beta_emp, k_ground

    def grounded(self, claim, ledger):
        ids = claim.evidence_ids
        if len(ids) < self.k:
            return False, 'insufficient_sources'
        if not self._sources_independent(ids, ledger):
            return False, 'correlated_sources'
        s = 1.0 - self._p_entail(claim, ledger)
        return s <= self.q(self.beta), s

    def repair(self, claim, ledger):
        ok, _ = self.grounded(claim, ledger)
        if ok:
            return claim
        weak = self._weakest_hedged_version(claim, ledger)   # ask / hedge
        return weak if weak is not None else None
```

### IP-228 SDC（言行一致）

```python
class SayDoConsistency:
    def __init__(self, alpha_sd=0.05):
        self.alpha_sd = alpha_sd

    def check(self, expression, pi_exec, k_star):
        d = 1.0 - self._prob_inside(self._traj_set(expression), pi_exec)
        consistent = d <= self.alpha_sd
        horizon_ok = expression.commits_to_horizon() <= k_star
        if consistent and horizon_ok:
            return True, expression
        if not horizon_ok:
            return self.check(expression.restrict_to(k_star), pi_exec, k_star)
        return False, expression.hedge_only()
```

### IP-230 MPI（三阶段心智归因）

```python
class MentalPhaseAttribution:
    HYP = ('M0', 'M_human', 'M_robot', 'M_shared', 'M_expr', 'M_task')

    def signature(self, phases):
        return np.concatenate([phases[p] for p in ('declare', 'accompany', 'verify')])

    def attribute(self, phases):
        r = self.signature(phases)
        logp = {m: np.log(self.lik[m](r) + 1e-12) + np.log(self.prior[m]) for m in self.HYP}
        post = softmax(logp)
        m_star = max(post, key=post.get)
        return post, m_star, post[m_star] < 1.0 - self.delta_emp

    def identifiability(self, phases):
        T, Sigma = self.linearize(phases)
        J = T.T @ np.linalg.inv(Sigma) @ T
        return np.linalg.eigvalsh(J)        # 全正才可辨识
```

### IP-229 TCC（信任校准）

```python
class TrustCalibrationControl:
    def __init__(self, eps_trust=0.1, lam_dose=0.2):
        self.eps, self.lam = eps_trust, lam_dose

    def select(self, candidates, tau, R, A_now, A_min):
        if abs(tau - R) <= self.eps:
            return None                                  # 死区：不表达
        best, best_obj = None, np.inf
        for e in candidates:
            if A_now - e.attention_cost < A_min:
                continue
            tau_next = self.dynamics.predict_tau(tau, e)  # 只计真实信息/反馈
            if e.is_pure_affect and e.adds_no_evidence:
                continue                                  # 反迎合：空话术不算
            obj = abs(tau_next - R) + self.lam * e.dose
            if obj < best_obj:
                best, best_obj = e, obj
        return best
```

## 4. 推导

**引理 9（接地表达可靠性）** 设标定集与部署样本可交换（A97）。对声明 `c`，split-conformal 给出 `P[s_c≤q_emp(β_emp)]≥1−β_emp`。若 `g(c)=1`，则 `c` 被证据支持的可信度至少 `1−β_emp`；若 `|E_c|≥k_ground` 且来源条件独立（A96），由联合界可得证据同时失效的概率 ≤ `β_emp^{k_ground}` 量级。若再通过 SDC，则 `P_{traj∼π_exec}[traj∈Traj(e)]≥1−α_sd`，即表达所承诺的行为是执行策略的可靠抽象。合并得：**通过 EGL+SDC 的表达，不会系统性地让人对机器人已承诺行为产生比 `1−α_sd` 更严重的错误预期。** 局限：该引理只约束「内容蕴含」与「行为包含」，不约束措辞框架、语气与选择性披露；框架级误导由 AIC-E 与 TCC 的反迎合规则处理，无法给出分布无关保证。∎

**引理 10（心智故障可辨识性）** 设 `E[r|θ]=Tθ`、`r∼N(Tθ,Σ_r)`，则 `J_emp=TᵀΣ_r⁻¹T`，后验协方差（Laplace）≈`J_emp⁻¹`，`θ` 可辨识 ⇔ `J_emp≻0`。三阶段结构使 `T` 近似块三角：declare 段只含 `M_human`/`M_task` 的列，accompany 段只含 `M_robot` 的列，verify 段含 `M_expr` 与 `M_robot` 残余列。故当三阶段均被激励、且各阶段噪声不共线时 `T` 列近正交、`J_emp≻0`；Laplace 近似下归因错误率 ≤ `exp(−n·κ_emp/2)`。删除 declare 使 `M_human` 与 `M_task` 两列在剩余观测上不可分（`J_emp` 奇异）；删除 verify 使 `M_expr` 与 `M_robot` 不可分。这正是第 65 轮「缺零力窗则 H_force/H_geo 不可分」在沟通层的同构。∎

**定理 9（EMPATH 安全-校准）** 在 A94–A100 下：
1. **物理优先**：算子先执行 VISTA 环并检查 `Valid(J_vista)`；不成立时先停/降速且禁止安抚表达（定义 248），故表达不改变物理安全边界。
2. **有据且一致**：`Valid(J_empath)` 要求每条声明过 EGL 或降级、且 SDC 通过（引理 9），故不会出现无据共情或「说一套做一套」。
3. **不越权**：`affect_observable` 与操纵/隐私预算由 AOG、AIC-E 硬约束（定义 243/246），情感不可观测时情感声明被屏蔽。
4. **不夺干预**：IAP 保证 `A(t)≥A_min`，表达择时/限长/可打断（定义 245）。
5. **校准不牺牲安全**：TCC 只在死区外、且只在 `E_cert` 内动作；禁止纯情感话术降低 `CalErr`（定义 239），故不会以「看起来更好的信任」换取真实风险。
6. **心智归因**：三阶段被激励时 `J_emp≻0`（引理 10），心智后验以 `O(exp(−n·κ_emp/2))` 集中；未集中时判 `M_ambiguous` 并走低负担探针（EAP），而非强行解释。

**不保证**：`CalErr` 单调收敛（人类信任动态非平稳、可能适应）；`τ_t` 无偏（代理测量有偏）；措辞框架完全不误导。这些是 A94/A100 的边界。∎

**定理 10（长解释、短承诺的近最优性）** 设解释时延 `d_exp`、物理承诺 `k`、不可逆视界 `m`。定义风险
```
R(d_exp,k) = c₁·S(d_exp) + c₂·1[k>m] + c₃·1[d_exp>d_safe]
```
`S(d_exp)` 为「惊讶/心智模型误差」成本，随更早解释单调下降（人更早建立正确预期）；`d_safe` 为干预可供性仍被满足的最晚解释时刻。对 `k≤m`，第二项为 0；对 `k>m`，风险跃升。故最优：**在满足 `A≥A_min` 的最早低风险窗给出最小充分意图**，同时 `k*=min(H,m)`。直觉：把「长视界」用于建立正确预期，把「短承诺」用于安全；解释晚于 `d_safe` 会同时抬高惊讶成本与干预失败风险。∎

**命题 11（共情剂量倒 U）** 设表达剂量 `q`，信任校准收益 `B(q)` 凹且饱和（`B'↓0`），注意力/监控损失 `L(q)` 凸且递增（过表达占用监控带宽、诱导依赖）。总风险 `R(q)=CalErr₀−B(q)+L(q)`。由 `B` 凹、`L` 凸，`R` 在 `B'(q*)=L'(q*)` 处取最小；超过 `q*` 后 `L'` 占优，风险上升。故「越多共情越安全」不成立，存在最优共情剂量。TCC 的 `λ_dose·cost(e)` 正是对该命题的在线近似；IAP 的 `A≥A_min` 是硬约束版本。∎

**命题 12（联合归因的共因不可分）** 当同一 OOD 源同时影响物理与心智（`P(H,M)` 非因子化），单靠 `(ρ,r)` 无法分离 `H` 与 `M` 的贡献（似然退化）。此时唯一安全策略是判 `ambiguous` 并进入定义 248 的保守修复：先物理安全，再用低负担探针增加一个**独立**观测；若无法获得独立通道，则保持在 `safe_idle`/合规退让，不强行归因。这延续了第 65 轮「共因故障下只要求判 ambiguous」的原则，并把它扩到心智层。∎

## 7. 已知风险

**一句话**：EMPATH 把「人的信任」当作可测量、可优化的控制信号，但人不是平稳传感器——会适应、会礼貌点头、会不报告真实状态，而共情表达本身又会改变被观测的人；于是系统可能学会**表演共情**（迎合、过度拟人、用情感话术降低 CalErr）而不是获得接地理解，证书证到的是「表演的合规性」而非「理解的真实性」，这是本轮 EGL/SDC/TCC 全部论证共同依赖的隐藏假设（A94）：**共情可以被安全地形式化，前提是人愿意且能够如实反馈——而这恰恰是共情最不能假设的东西。**

**次级风险与缓解**：
1. **信任代理有偏**：监控率/干预率/接近距离都不是信任的充分统计量，且随任务难度漂移；缓解：只用相对校准、带置信区间、多代理交叉，禁止单代理直接驱动表达。
2. **人机会适应（reflexivity）**：表达改变人的策略，使 conformal 可交换性失效；缓解：在线重校准、按用户/阶段分层标定、漂移检测（`CalErr` 与代理分布漂移即触发重标定）。
3. **表演共情/迎合**：LLM 容易生成讨喜但无信息的话术；缓解：EGL 硬接地 + 「空话术不计入 CalErr 降低」的反迎合规则 + 红队审计。
4. **情感推断不可靠且带偏见**：面部/语音情感识别跨文化、跨群体差异大；缓解：默认关闭、显式同意、多模态一致、公平审计、只做任务相关认知共情。
5. **隐私与依赖**：过度共情可能套取私人信息或制造依赖；缓解：隐私预算、只问任务相关、可撤回、可拒绝、审计链。
6. **干预可供性测量难**：`A(t)` 难以在线精确估计；缓解：宁可保守（低风险窗表达、限长、可打断），把 `A_min` 设为经验下界。
7. **三阶段不可得**：快速任务可能没有 verify 阶段；缓解：将 verify 延迟到任务间隙、或显式插入 `null_check` 元技能，不依赖自然发生。
8. **联合归因的共因不可分**：物理与心智同时失效时无法分离；缓解：判 ambiguous、先物理安全、引入第三独立通道（任务结果/外部观察者），不强行解释。
9. **实时预算**：证据采集与门控逼近 2.6ms；缓解：事件驱动、与 VISTA 共享阶段缓冲、把 LLM/归因全部留在语义流。
