# 第 1 轮 · SAFE-DATASET-INNOVATION ZEST：从「数据集构建」「安全性」「创新点提炼」出发，构建安全可证的自进化数据-创新循环

## 0. 先给直觉与动机

CG-ZEST 解决了物体实例盲区与零样本泛化，但它隐含三个脆弱假设：
1. **数据集是给定的**：SIM-DISTILL-2 的程序化生成依赖手工设计的物体先验，缺乏可证的安全性与覆盖度保证；
2. **安全是启发式的**：置信调制、动作包络是经验阈值，无法给出形式化不违反约束的保证；
3. **创新是隐形的**：系统能采集数据，却从未显式提炼「这次失败说明了什么新原理」，科研迭代靠人工解读。

灵感词的对应：
- **数据集构建 → 可证构造**：把数据生成从“采样”升级为“受约束的程序合成”，用可满足性求解器保证每条样本满足物理可行、安全可达、信息增益三目标；
- **安全性 → 形式化屏障**：在 CG-ZEST 的 γ_adjusted 上叠加控制屏障函数 CBF 和风险上界，使每一步动作都有数学上不可违反的安全保证；
- **创新点提炼 → 失败到假设**：把失败轨迹映射到故障嵌入流形，通过稀疏聚类与因果差异检测自动提炼出可验证的创新点假设 H_i。

一句话押注：
> 让数据生成可证安全，让决策可证保守，让失败自动升华为可证伪的创新假设。

## 1. 形式化定义

### 符号
- $\mathcal{O}$ 物体动力声纹空间，$e_{obj}\in\mathbb{R}^{64}$
- $\mathcal{D}$ 数据集，样本 $d=(o,a,r,\theta_{phys},s)$，$s\in\{0,1\}$ 安全标签
- $\mathcal{C}_{safe}=\{x\mid h(x)\ge0\}$ 安全集，$h$ 为可微屏障
- $\Pi_{probe}$ 探测原语集合
- $\mathcal{F}$ 失败嵌入，$f=\Phi(o_{hist},a_{hist},r)$
- $U_{acq}(p)$ 采集效用

### 数据集构造器 DATASET-FABRICATOR
约束合成问题：
$$
\begin{aligned}
\min_{u\in\mathcal{U}} \quad & -\;U_{acq}(G_\psi(u)) \\
\text{s.t.} \quad & h_{phys}(G_\psi(u))\ge0 \\
& h_{safe}(G_\psi(u))\ge0 \\
& I_{info}(G_\psi(u))\ge \tau_{info}
\end{aligned}
$$
其中 $G_\psi$ 为程序化物体生成器，$h_{phys}$ 物理可行，$h_{safe}$ 经验碰撞/力矩安全，$I_{info}$ 为声纹覆盖信息增益。

### 安全屏障 SAFEGUARD
在动作投影层加入 CBF：
$$
a_{safe}= \arg\min_{a}\|a-a_{synth}\|^2 \quad\text{s.t.}\quad \dot h(x,a)\ge -\alpha(h(x))
$$
结合不确定性：
$$
\dot h \ge -\alpha(h) - \kappa\;u_{total}
$$
若不可行则强制回退快策略 $a_{fast}$。

### 创新点提炼 INNOV-EXTRACT
失败嵌入聚类：
$$
\mathcal{C}=\text{HDBSCAN}(\{f_i\mid r_i<0\}),\quad
\text{score}(c_j)=\lambda_1\frac{|c_j|}{N}+\lambda_2\text{novelty}(c_j)-\lambda_3\text{redundancy}(c_j)
$$
对高分簇生成假设模板：
$$
H_j: \exists e_{obj}\in\mathcal{R}_j\ \text{s.t.}\ \mathbb{E}[\gamma\mid e_{obj}]<\gamma_{thr}\ \land\ \nu(e_{obj})>\nu_{thr}
$$
假设可被后续主动探测证伪/证实，形成科研闭环。

## 2. 算法步骤

1. **初始化**：继承 CG-ZEST 权重，初始化声纹库 $B$、安全屏障参数、创新簇库。
2. **可证数据生成**：在空闲时段求解约束合成问题产生一批仿真物体，自动标注 $\theta_{phys}$ 与安全标签，注入 SIM-DISTILL-2。
3. **安全感知决策**：每步执行 CG-ZEST $\rightarrow$ CBF 投影 $\rightarrow$ 三重降级，记录安全裕度 $h(x)$。
4. **失败回滚与提炼**：任务失败后提取 $f$，更新聚类，生成创新点 $H_j$ 并写入研究日志。
5. **主动闭环**：以 $H_j$ 为先验更新 $U_{acq}$，优先探测能证伪假设的物体。

## 3. 复杂度分析

- DATASET-FABRICATOR：约束求解 $O(K\cdot |\mathcal{U}|)$，$K$ 为 CMA-ES 迭代，离线运行。
- SAFEGUARD：CBF 投影为二次规划，Horizon=1 时闭式解 $O(d_a^2)$，$d_a=18$，约 $0.02$ ms。
- INNOV-EXTRACT：HDBSCAN $O(N\log N)$，仅在失败批处理触发，控制环外。

总控制环延迟增加 $<0.05$ ms，内存 $+2$ MB。

## 4. 正确性论证

**引理1 安全不变性**：若初始 $h(x_0)\ge0$ 且每步选择满足 $\dot h\ge -\alpha(h)-\kappa u_{total}$，则 $\mathcal{C}_{safe}$ 不变。
证明：标准 CBF 递推 + 不确定性保守项。

**命题1 数据可证覆盖**：约束合成保证生成样本满足 $h_{phys},h_{safe},I_{info}$，因此不会引入物理不可行或明显不安全样本。

**命题2 创新点完备性**：若失败流形存在密度 $\rho>\rho_{min}$ 的连通分支，则 HDBSCAN 以概率 $1-\delta$ 检测到对应簇。

## 5. 已知风险

- 约束求解器可能过保守导致数据多样性下降；
- CBF 与高频控制环耦合可能引入相位滞后；
- 创新点提炼依赖嵌入质量，误聚类会产生虚假假设。

## 6. 本轮最大的风险

**安全屏障的保守性与数据多样性的冲突：CBF 在高不确定性下过度收缩动作空间，可能导致系统在陌生物体上陷入“安全死锁”，既不学习也不失败，创新点提炼枯竭且实际事故率不变。**

### 2.2 SAFEGUARD
```python
def cbf_project(x, a_synth, h_func, alpha, kappa, u_total):
    # 二次规划：min ||a - a_synth||^2 s.t. dh/dx * f(x,a) >= -alpha(h) - kappa*u_total
    # 1步 horizon 闭式解
    J = dh_dx(x) @ da_dx
    b = -alpha(h_func(x)) - kappa*u_total - dh_dx(x)@f(x)
    if J @ a_synth >= b:
        return a_synth
    a_safe = a_synth + max(0, (b - J@a_synth)/ (J@J.T + 1e-6)) * J
    return np.clip(a_safe, a_min, a_max)
```

## 3. Python 核心实现骨架

```python
class SDIZestPolicy:
    def __init__(self, base_cgzest, cbf, fabricator, innov_extractor):
        self.base = base_cgzest
        self.cbf = cbf
        self.fabricator = fabricator
        self.innov = innov_extractor
        self.fail_buffer = []

    def get_action(self, obs):
        a_fast = self.base.select_fast(obs)
        e_obj = self.base.e_obj
        if e_obj is None:
            return a_fast
        a_synth = self.base.synth.sample(obs)
        u_total = np.hypot(self.base.u_obj, self.base.u_act)
        a_safe = self.cbf.project(obs, a_synth, u_total)
        alpha = self.base.compute_alpha()
        a_blend = (1-alpha)*a_fast + alpha*a_safe
        return a_blend

    def on_failure(self, obs, action, reward):
        f = self.encode_failure(obs, action, reward)
        self.fail_buffer.append(f)
        if len(self.fail_buffer)%50==0:
            innovs = self.innov.extract(self.fail_buffer)
            self.log_innovations(innovs)

    def on_idle(self):
        batch = self.fabricator.fabricate_batch(32)
        self.base.train_on_batch(batch)
```

## 4. 复杂度

- FABRICATOR 离线：$O(N_{cand}\cdot C_{solver})$，不入控制环
- CBF 投影：$O(d_a^2)=324$ FLOPs
- INNOV-EXTRACT：每 50 失败一次 HDBSCAN，$O(M\log M)$

## 5. 正确性

安全不变性由 CBF 标准证法保证；数据可证覆盖由约束求解器保证；创新点检测概率由 HDBSCAN 理论下界保证。

## 6. 实验设计

- 基线：CG-ZEST
- 指标：安全违规率、安全裕度均值、创新点发现数、未见物体成功率
