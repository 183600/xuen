# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「抓取位姿估计」×「单模型多任务」）

> R69 把不确定性拆成 aleatoric / epistemic，并用「看/问/触」的 VoI 主动消解 epistemic。但它偷偷假设了三件从未被检验的事：(a) **歧义都是缺陷**——多峰就是「我不知道」，值得花预算查清；(b) **答案是一个点或一组真正互不相同的点**——没有等价结构，任意两个模态都算「不同」；(c) **证据相互独立**——所以「k 个正交证据源一致」可以压住欺骗。
>
> 两个灵感恰好击穿这三条：
> - **抓取位姿估计**：答案是 SE(3)×夹爪空间上的**流形**，而流形上天然带**对称/规范（gauge）结构**。绕圆柱轴转 90° 的抓取是同一个抓取；可行抓取本来就是一片流形而非单点。把这种「规范冗余」当成 epistemic 去追问，是**花预算消解一个不影响任务的自由度**；更糟的是，用它校准模态权重，会把 ECE 建立在被对称性膨胀的模态数上。而真正该关心的不是位姿 RMSE，而是**位姿误差中会改变力闭合/成功率的那一个分量**。
> - **单模型多任务**：一个共享 trunk 同时服务位姿估计、抓取、导航、对话。于是「k 个正交证据源」可能只是同一 trunk 的 k 个分身——**误差同源（common-mode）**；同一观测还可能同时兼容多个任务，即**任务别名（task aliasing）**——这不是「该抓哪里」的世界歧义，而是「你到底要我干什么」的目标歧义，几何探针问不出来；最后，为任务 A 采集的信息会改写共享信念 z，**外溢到任务 B**，可能帮倒忙。
>
> 核心命题：**不确定性要三分再加一——U_ale（噪声，收紧）、U_epi（世界歧义，交互消解）、U_gauge（任务相关规范冗余，商掉而不是问掉）、U_task（目标别名，问目标而不是问世界）；并把跨任务信息外溢与共享证据的有效独立性列为硬约束。** 命名 **GAUGE-RAS**（Gauge-Aware Uncertainty GEometry for single-model multi-task Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个差别真的重要吗？我是不是在问一个不该问的自由度，而把真正该区分的当成了等价的**」。

## 0. 直觉与动机

**灵感 1（抓取位姿估计 → 答案是一片带对称性的流形，不是一组离散候选）**
直觉：给杯子抓取位姿，绕杯子轴旋转的任意角度都同样好；给方块，90° 旋转等价；平行夹爪绕接近轴的某些小角度也可能都能闭合。人不会在「转 0° 还是转 90°」之间纠结，因为这两个动作对任务**可交换**。R69 的流策略会采样出这些「模态」，聚类得 H_mode，再把它们当成 epistemic 去算 VoI——系统于是花一次注视/探针去区分两个对结果完全等价的抓取。这不仅是浪费，还会**污染校准**：8 重对称的物体被定义成 8 个独立模态时，ECE 可能在错误的标签空间上「看起来不错」。正确做法是先按任务相关对称群做**商（quotient）**，再谈不确定性；对称方向上的散布不是「不知道」，而是「知道它们一样」。

**灵感 2（单模型多任务 → 共享表示让证据与信念都不再独立）**
直觉：一个 trunk 出多个 head，训练共享梯度，推理共享 z。R69 定义 300/引理 18 的「k 个正交证据源」在这里可能根本不正交：所有 head 都喝同一个 z，遇到共同盲点会**一起错**。此时投票越多越自信，却不会更对——共同模式的错误率就是下界，k 再大也压不下去。第二个后果更微妙：同一观测可能既像「把杯子递给我」又像「把杯子放桌上」，这两个任务的抓取位姿、速度、安全包络都不同。这是**目标**的别名，不是世界几何的歧义；拿探针戳杯子不会告诉你对方想要哪个，必须问目标（或选一个对所有候选任务都安全的行为）。第三个后果是**信息外溢**：为任务 A 选的注视点会改写共享 z，从而改变任务 B 的信念——可能降低也可能升高；R69 的单任务 VoI 没算这笔跨任务账。

**灵感 3（三分+一 → 每个桶走不同通道，且 R69 是退化情形）**
直觉：把表观多峰方差沿**群轨道**做正交分解：垂直（轨道内、纯规范）分量 = U_gauge；水平（商空间内、真正不同）分量再分 U_ale 与 U_epi。U_gauge 既不该收紧也不该追问，应**商掉**；执行时再把「同类中选哪个代表」按成本/舒适度做 **gauge-fixing**（商用于信念，gauge-fixing 用于执行）。U_task 走「目标查询 / 任务安全交集」，不是几何探针。只有证明对称群估计正确（规范一致性证书）时才能商；证书不过，就把 U_gauge 降级回 U_epi 走 R69——**宁可多问，不可错并**。当对称群平凡、任务唯一、证据独立时，GAUGE-RAS 逐指令退化为 FLUID-RAS。

**灵感 4（位姿估计的提示 → 只估计「会影响抓取成功」的那部分位姿）**
直觉：抓取位姿评测常报平移/旋转 RMSE，但 2cm 的切向误差可能毫无影响，3° 的接近角误差却可能让摩擦锥失效。任务真正关心的是力闭合裕度 m(ξ) 的分布，而非位姿本身的分布。因此主动感知应最大化「m 的方差下降」，即沿 ∇m 方向的 Fisher 信息；对称方向天然满足 ∇m⊥轨道（m 是规范不变量），所以「不要问对称方向」与「只问影响成功的方向」是同一件事。这把 R69 的 g_gaze/g_probe 从「降低位姿熵」升级为「降低任务相关位姿熵」。

**灵感 5（单模型多任务的威胁模型）**
直觉：共享 trunk 带来三种新攻击面：(i) **对称伪装**——把真实差异（夹爪开合方向、物体正反面）伪装成规范等价，诱导系统商掉它；(ii) **任务混淆**——构造观测让任务后验指向错误任务，系统若取 argmax 就会为错任务自信抓取；(iii) **共同模式投毒**——污染少数共享特征，所有 head 一起偏。因此证书必须包含：规范一致性、任务别名检测、有效独立性、跨任务干扰计数。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GAUGE-RAS 总览）** GAUGE-RAS = (GQ, GMD, GPI, TAI, GQG, XVoI, EIG, BIC, GEC, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **先商后问（quotient-before-query）**：任何信息动作不得用于区分在任务相关规范群 G_T^rel 下轨道相同的点；
(iii) **有效独立性纪律**：k 个证据源须满足由 EIG 实测的有效独立性 ≥ ρ_min，否则只计外源证据；
(iv) **跨任务信念干扰硬约束**：信息动作对任一安全关键任务信念子空间造成的 KL 漂移 ≤ ε_x，越界即否决（硬约束，非软惩罚）；
(v) **严格包含**：G 平凡 ∧ 单任务 ∧ 证据独立 ⇒ 逐指令退化为 FLUID-RAS（定义 326）。

**定义 311（任务-观测-动作空间）** 任务 T ∈ 𝒯，上下文 c，观测 o；共享 trunk z = Φ_θ(o)，任务头 h_T。动作 ξ = (a, g) ∈ 𝒜_+（继承定义 294），抓取实例的 a 含位姿 p ∈ SE(3)、夹爪开度 w ∈ ℝ_+ 与预抓取轨迹。策略 π_θ(ξ | o, c, T) 由同一流匹配速度场生成，任务条件经 (c, T) 注入。

**定义 312（任务相关规范群 G_T^rel）** 设任务结果向量 F_T(ξ) = (success_T, cost_T, risk_T, constraints_T)。对作用在 𝒜_+ 上的群 G_T：
G_T^rel = { h ∈ G_T : F_T(h·ξ) = F_T(ξ), ∀ξ ∈ 𝒜_+ }。
关键：**规范是任务与风险相对的，不是纯几何的**。若某自由度改变成本/碰撞/安全，它就不在 G_T^rel 里，必须保留为待决策维度。绕轴旋转 ∈ G_T^rel；但若绕轴会碰到旁边的人，则该自由度被安全约束破缺，**不得商掉**。

**定义 313（轨道与商度量）** 轨道 [ξ] = {h·ξ : h ∈ G_T^rel}。在 SE(3) 上取双不变度量 d（SO(3) 迹度量 × ℝ³ 欧氏）。商度量 d_G([ξ],[ξ']) = min_{h,h'∈G} d(h·ξ, h'·ξ')。切空间按该度量正交分解为垂直（轨道）分量 V 与水平（商）分量 H。

**定义 314（规范感知模态分解 GMD）** K 个流样本 {ξ^(j)}，在商空间用商度量聚类得 K̂ 个轨道模态 {[m_k]}、权重 ŵ_k、原型 ξ̄_k、商内协方差 Σ_k^H 与轨道内协方差 Σ_k^V。定义
U_gauge = Σ_k ŵ_k tr(Σ_k^V)（轨道内、纯规范、任务无关）；
U_ale = Σ_k ŵ_k tr(Σ_k^{H,ale})（商内、模态内、不可约）；
U_epi = H([M]) · g(Δ_min^G)，其中 Δ_min^G 用商度量计算，H([M]) 是**商模态**熵。
R69 的 H_mode 与 U_epi 会把同一轨道的副本当成不同模态；GMD 与它的差就是 U_gauge。

**定义 315（任务相关位姿信息 GPI）** 抓取成功率/力闭合裕度 m(ξ)（规范不变量：m(h·ξ)=m(ξ)）。位姿协方差 Σ_p 在任务相关方向的标量化：
U_pose^task = ∇_ξ m^T Σ_ξ ∇_ξ m（delta 法，见引理 20）。
主动感知选 g_gaze/g_probe 最大化 E_y[U_pose^task(before) − U_pose^task(after)]，而非 tr Σ_p。对称方向因 ∇m⊥V 自动不进入目标。

**定义 316（任务别名 TAI）** 任务后验 p(T | o, c)；别名集 A(o) = {T : p(T|o,c) ≥ τ_alias}。行为可区分度 D_TT' = W_2(π(·|T), π(·|T')) + λ_s‖safety_T − safety_T'‖。加权任务熵
U_task = H(T|o,c) · g_task(min_{T≠T'∈A} D_TT')。
只有「会改变行为/安全」的别名才算 U_task；纯语义不确定可忽略。

**定义 317（目标查询与任务安全默认）** 目标查询 g_goal ∈ 𝒜_info^goal（语言/上下文动作，复用 g_ask 通道）。若 U_task > τ_task ∧ XVoI(g_goal) > c(g_goal) ∧ 过 BIC，则问目标；否则执行**任务安全默认**：
a_default = argmin_a max_{T∈A(o)} Risk_T(a)，s.t. a ∈ ∩_{T∈A(o)} SafeSet_T（交集为空则去掉该约束）。
**绝不取 argmax_T p(T|o,c)**——那是「自信地做错任务」的根源。

**定义 318（跨任务信息价值 XVoI）** 共享信念 b(z)。信息动作 g 产生 y。对每个任务 j：ΔH_j(g) = H(T_j 结果信念 | b) − E_y H(T_j 结果信念 | b_y)。为 i 选 g 时对 j 的外溢即 ΔH_j(g)。选
g* = argmax_g [ Σ_j w_j ΔH_j(g) − λ_x Σ_{j≠i} max(0, −ΔH_j(g)) − c(g) ]，
s.t. BIC(g) ∧ 预算。R69 的 VoI 是 |𝒯|=1、w=1、无外溢项的退化。

**定义 319（信念干扰约束 BIC）** 对安全关键任务集 𝒯_safe 与其相关子空间 S_j = E_j（定义 324），要求
D_KL( proj_{S_j} b(·|y) ‖ proj_{S_j} b(·) ) ≤ ε_x, ∀ j ∈ 𝒯_safe。
越界 ⇒ g 否决，U_epi/U_task 视为未消解并走退避。BIC 是硬约束，不能被更高的 VoI 抵消。

**定义 320（有效独立性 EIG）** 证据源 e_i（残差通道/任务头/外源）。给定共享 z 与任务 T 的条件相关
ρ_eff(i,j) = max_cal |corr(e_i − E[e_i|z,T], e_j − E[e_j|z,T])|（或用条件互信息 / Jacobian 的 CKA，取可测版本）。
有效证据数 k_eff = (Σ_i 1)² / (Σ_{i,j} ρ_eff(i,j))（有效样本量口径），外源计数 k_ext。证据纪律升级为：接受证据集 S 需 max_{i≠j∈S} ρ_eff(i,j) ≤ ρ_max 且 k_eff ≥ k_min；否则必须 k_ext ≥ 1（至少一个不经过共享 trunk 的外源）。R69 的「k 个正交源」是 ρ_eff≡0 的特例（引理 22 说明为何必须改）。

**定义 321（规范一致性证书 GEC）** 抽样 h ∈ G_T（或从估计的对称群采样），
E_G = E_{h,o}[ d_G( [π_θ(·|o)], [π_θ(·|h^{-1}·o)] ) ]（等变误差），
以及商标签上的模态校准 ECE_G。Valid(GEC) ⇔ E_G ≤ τ_G ∧ ECE_G ≤ τ_ece。GEC 不过 ⇒ 禁止商（U_gauge 并入 U_epi），提升 λ；若任务安全关键，直接回 R69 最保守。**商不是假设，而是一张必须年检的证。**

**定义 322（四通道处置与两级退避）** 依据定义 314/316/321：
- **U_gauge**：GEC Valid 则商掉，既不追问也不收紧；执行侧 gauge-fixing 选轨道内成本最低代表。GEC 不过则并入 U_epi（保守侧）。
- **U_epi**：走 R69 MINT/CIA 交互消解。
- **U_task**：走 GQG 目标查询或任务安全默认。
- **残余**：λ = λ_floor(U_ale + 未消解 U_epi + 未消解 U_task)；消解成功 ⇒ λ = λ_floor(U_ale)（resolution bonus）。
安全侧恒不弱于 R69：所有不确定/证书失败/预算超限/被投毒 → 单调退化为 R69。

**定义 323（审计、干扰集与证书）** VQAuditor-G 审：商的正确性、任务别名、跨任务干扰、相关证据、对称伪装。ℰ_GAUGE = ℰ_FLUID × ℰ_sym × ℰ_alias × ℰ_corr（对称伪装 / 任务混淆 / 共同模式投毒）。J_GAUGE = (J_FLUID, gauge_consistency E_G, quotient_ECE, U_gauge, U_task_before/after, k_eff, k_ext, cross_task_interference, safety_veto_count, gauge_ver)。

**定义 324（共享表示的最小暴露面）** 单模型多任务共享 z，定义任务 j 的暴露子空间 E_j = span(∂h_j/∂z)。信息动作对另一任务的影响只在 E_j 上计；BIC 的 S_j 取 E_j。定义共享表示对任务 j 的干扰增益 Γ_j = tr(Σ_{E_j})/tr(Σ_z)，把「共享」从口号变成可审计的数。

**定义 325（自适应 K 与时序）** 默认 K=1、N_step=2（继承定义 308）。当 mode_head 报歧义、TAI 报别名、或 FMA 报异常时升 K=4；GEC 只在采样到的对称群上做廉价一致性检查（≤ 8 个 h）；商聚类只在 K>1 时触发。GEC/ECE_G 低频（每 N 帧）更新，G_T^rel 可按任务-场景表缓存。

**定义 326（严格包含 FLUID-RAS）** 当 G_T^rel = {e}（无规范对称）、|𝒯|=1（单任务）、ρ_eff≡0 且不触发 BIC 时，U_gauge=0、U_task=0、EIG 纪律退化为 R69 的 k-一致，GAUGE-RAS 每一步决策与 FLUID-RAS 逐指令相同。故 R70 是 R69 的严格泛化；商与别名检测只在**证明安全**（GEC / 安全默认）时改变行为。

# IP-264/265 GMD+GQ：先在任务相关规范群下做商，再分解不确定性
def gauge_decompose(samples, task, o, model):
    G = task.relative_gauge_group(o)          # 仅保留保持 F_T 不变的 h
    cert = model.gec.check(G, o)              # IP-272 一致性证书
    xs = samples if not cert.ok else [quotient(x, G) for x in samples]
    modes = cluster_quotient(xs, metric=d_G)  # 商度量聚类
    w = mode_weights(modes)
    U_gauge = 0.0 if not cert.ok else orbit_variance(samples, G, modes)
    U_ale = sum(w[k] * trace(horizontal_cov(modes[k], G)) for k in modes)
    U_epi = entropy(w) * sep_factor(modes, d_G)
    if not cert.ok:                            # 宁可多问，不可错并
        U_epi += U_gauge; U_gauge = 0.0
    return U_ale, U_epi, U_gauge, modes, cert

# IP-266 GPI：主动视角/探针只降低"会影响抓取成功"的位姿方差
def choose_view_gpi(modes, task, o, budget):
    best = None
    for g in view_candidates(modes, o):
        dU = expected_reduction(lambda_pose: grad_m(modes).T @ lambda_pose @ grad_m(modes), g)
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        score = dU - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-267/268 TAI + GQG：目标歧义问目标，不问世界；问不到就选任务安全默认
def resolve_task_alias(o, c, tasks, budget):
    A = [T for T in tasks if task_posterior(T, o, c) >= TAU_ALIAS]
    if len(A) <= 1: return (A[0] if A else None), 0.0
    U_task = task_entropy(A) * behavior_separation(A)
    g = best_goal_query(A, o, c, budget)       # 过 BIC 与预算
    if U_task > TAU_TASK and g is not None:
        return infer_task(action=g), U_task
    return safe_default(A), U_task             # argmin_a max_T Risk_T(a)

# IP-269/271 XVoI + BIC：单次信息动作要算跨任务外溢，安全任务一票否决
def xvoi_select(cands, beliefs, safe_tasks, budget):
    best = None
    for g in cands:
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        if not bic_ok(g, beliefs, safe_tasks, eps_x):              continue  # 硬约束
        gain = sum(w[j] * dH(j, g) for j in tasks)
        harm = sum(max(0.0, -dH(j, g)) for j in tasks if j not in safe_tasks)
        score = gain - LAMBDA_X * harm - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-270 EIG：把"正交证据"从口号变成实测量
def effective_evidence(sources, z, task):
    rho = pairwise_conditional_corr(sources, z, task)
    k_eff = effective_sample_size(rho)
    k_ext = count_exogenous(sources)           # 不经过共享 trunk 的源
    return (k_eff >= K_MIN and max_offdiag(rho) <= RHO_MAX) or k_ext >= 1

# IP-276 主闭环（继承 R69，在不确定性处置处插入 GAUGE 层）
def GAUGE_RAS_round(M, obs, c):
    z, o = M.trunk(obs), obs
    _, U_cal, _ = M.cof.step(...)              # R68 标定
    # 1) 任务别名：先判断"在做什么任务"
    task, U_task = resolve_task_alias(o, c, M.tasks, M.budget)
    # 2) 规范商 + 不确定性三分（证书不过则不减商）
    K = 1 if M.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K, cond=task)
    U_ale, U_epi, U_gauge, modes, gcert = gauge_decompose(samples, task, o, M)
    # 3) 主动感知只买"任务相关"的位姿精度；跨任务外溢过 BIC
    g = None
    if U_epi > TAU_EPI:
        g = xvoi_select(M.view_candidates(modes) + M.probe_candidates(modes),
                        M.belief, M.safe_tasks, M.budget)
    if g is not None:
        y = M.cia.execute(g, cert=gcert)
        if effective_evidence(M.evidence(y), z, task):
            U_epi = M.cia.update_belief(modes, y)
    # 4) 执行侧 gauge-fixing：商用于信念，代表选择用于成本
    rep = gauge_fix(modes, task, cost=M.cost)  # min 轨道内成本/舒适度
    # 5) 两级退避：残余 epistemic / task 视同 aleatoric
    U_floor = U_ale + (U_epi if g is None else 0.0) + U_task
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(rep.a, M.vista.H), ...)
    if not gcert.ok: lam = max(lam, 0.8)        # 证书失败，回 R69 最保守
    M.vqa_g.submit_async(g, gcert, U_task, k_eff, ...)
    return k, lam, rep, (U_ale, U_epi, U_gauge, U_task)
```

## 3. 推导

**引理 19（规范方差正交分解）** 设 G_T^rel 紧、作用等距、度量双不变，则样本协方差分解为 Σ = Σ_V ⊕ Σ_H，U_gauge = tr Σ_V 恰是商运算去除的部分；商模态熵 H([M]) ≤ H(M)，差值由轨道熵界住。故 R69 在对称物体上**高估 U_epi** 并可能超买 VoI。量化：在「把同一轨道副本误判为独立模态」的假设下，多花的交互预算 ≤ c·(H(M) − H([M])) / ΔH_per_query，且该上界随对称阶数增长。文明：**对称性越强，R69 的 VoI 越保守得离谱**。

**引理 20（任务相关位姿精度）** 由 delta 法，Var(m(ξ)) ≈ ∇m^T Σ ∇m；对抓取，m 只依赖位姿中影响摩擦锥/碰撞的分量。若 h ∈ G_T^rel，则 ∇m(h·ξ) 与轨道切向正交（m 规范不变），故对称方向对 Var(m) 零贡献。⇒ 最优主动视角最大化 E[Δ(∇m^T Σ ∇m)]，与「商掉对称方向」一致。推论：位姿 RMSE 不是好的主动感知目标——存在 RMSE 更小而成功率方差更大的视角。

**引理 21（任务安全默认的风险上界）** 设别名集 A 与先验 p。后验贪心 a* = argmax_a Σ_T p(T) success_T(a) 若落在某个 T_min 的安全包络外，则 violation ≥ p(T_min)。而 a_def = argmin_a max_{T∈A} Risk_T(a) 由 minimax 定义满足 max_T Risk_T(a_def) ≤ max_T Risk_T(a) 对所有可行 a，特别地 ≤ 后验贪心的最坏任务风险。故当 max_T Risk_T(a_def) 可接受时，安全默认的灾难率严格更低；代价是平均成功率下降，量级由 D_TT' 界住。⇒ 别名未消解时**不要 argmax 任务**。

**引理 22（共同模式下证据融合的地板）** 若所有证据源共享 z，则存在共同模式项：以概率 δ_cm 所有源同时翻转到同一错误。对任意加权/多数融合，错误率 ≥ δ_cm（共同模式下独立衰减项失效）。R69 引理 18 的 δ_p ρ^{k−1} 只在 ρ<1 且无共同模式时成立；引入 k_eff 后，独立部分随 k_eff 衰减，但该地板不衰减。⇒ 必须 k_ext ≥ 1（至少一个外源）才能把错误率压到 δ_cm 以下。这是「单模型多任务」对 R69 最直接的理论修正。

**定理 18（GAUGE-RAS 严格包含 FLUID-RAS）** 在 A99（G_T^rel 正确且 GEC 有效）、A100（任务唯一，或别名已由安全默认处理）、A101（证据有效独立性满足）下：任意状态期望任务风险 ≤ FLUID-RAS；且在 G={e}、单任务、ρ_eff=0 时逐指令相同。证明要点：GEC 有效时商只移除 F_T 不变方向（定义 312），任务结果分布不变（风险侧恒等），而交互预算不被浪费（效率侧改善）；证书失效或别名未解则落入定义 322 的 R69 退化路径。

**定理 19（跨任务安全与无突变）** BIC 为硬约束 ⇒ 任意允许的信息动作对 𝒯_safe 信念子空间的漂移 ≤ ε_x；XVoI 的负外溢只影响效率不影响安全；退避时 λ 单调不降，继承 R69 定理 17 的提交/换装不变式 ⇒ 控制连续、无突变。共享表示不引入新的安全假设，只可能因 BIC 否决而更保守。

# IP-264/265 GMD+GQ
def gauge_decompose(samples, task, o, model):
    G = task.relative_gauge_group(o); cert = model.gec.check(G, o)
    xs = samples if not cert.ok else [quotient(x, G) for x in samples]
    modes = cluster_quotient(xs, metric=d_G); w = mode_weights(modes)
    U_gauge = 0.0 if not cert.ok else orbit_variance(samples, G, modes)
    U_ale = sum(w[k]*trace(horizontal_cov(modes[k], G)) for k in modes)
    U_epi = entropy(w) * sep_factor(modes, d_G)
    if not cert.ok: U_epi += U_gauge; U_gauge = 0.0     # 宁可多问，不可错并
    return U_ale, U_epi, U_gauge, modes, cert

    for g in view_candidates(modes, o):
        dU = expected_reduction(lambda S: grad_m(modes).T @ S @ grad_m(modes), g)
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        score = dU - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-267/268 TAI+GQG
def resolve_task_alias(o, c, tasks, budget):
    A = [T for T in tasks if task_posterior(T, o, c) >= TAU_ALIAS]
    if len(A) <= 1: return (A[0] if A else None), 0.0
    U_task = task_entropy(A) * behavior_separation(A)
    g = best_goal_query(A, o, c, budget)
    if U_task > TAU_TASK and g is not None: return infer_task(action=g), U_task
    return safe_default(A), U_task              # argmin_a max_T Risk_T(a)

# IP-269/271 XVoI+BIC
def xvoi_select(cands, beliefs, safe_tasks, budget):
    best = None
    for g in cands:
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        if not bic_ok(g, beliefs, safe_tasks, eps_x): continue   # 硬约束
        gain = sum(w[j]*dH(j, g) for j in tasks)
        harm = sum(max(0.0, -dH(j, g)) for j in tasks if j not in safe_tasks)
        score = gain - LAMBDA_X*harm - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-270 EIG
def effective_evidence(sources, z, task):
    rho = pairwise_conditional_corr(sources, z, task)
    k_eff, k_ext = effective_sample_size(rho), count_exogenous(sources)
    return (k_eff >= K_MIN and max_offdiag(rho) <= RHO_MAX) or k_ext >= 1

# IP-276 主闭环
def GAUGE_RAS_round(M, obs, c):
    z = M.trunk(obs); _, U_cal, _ = M.cof.step(...)
    task, U_task = resolve_task_alias(obs, c, M.tasks, M.budget)
    K = 1 if M.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(obs, K, cond=task)
    U_ale, U_epi, U_gauge, modes, gcert = gauge_decompose(samples, task, obs, M)
    g = (xvoi_select(M.view_candidates(modes) + M.probe_candidates(modes),
                     M.belief, M.safe_tasks, M.budget)
         if U_epi > TAU_EPI else None)
    if g is not None:
        y = M.cia.execute(g, cert=gcert)
        if effective_evidence(M.evidence(y), z, task):
            U_epi = M.cia.update_belief(modes, y)
    rep = gauge_fix(modes, task, cost=M.cost)          # 商用于信念，代表用于成本
    U_floor = U_ale + (U_epi if g is None else 0.0) + U_task
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(rep.a, M.vista.H), ...)
    if not gcert.ok: lam = max(lam, 0.8)
    M.vqa_g.submit_async(g, gcert, U_task, k_eff)
    return k, lam, rep, (U_ale, U_epi, U_gauge, U_task)
```

## 4. 推导

**引理 19（规范方差正交分解）** 紧群、等距作用、双不变度量下 `Σ=Σ_V⊕Σ_H`，`U_gauge=tr Σ_V` 恰为商去除部分；`H([M])≤H(M)`，差值由轨道熵界住。R69 在对称物体上高估 U_epi、超买 VoI，多花预算上界 `≤ c·(H(M)−H([M]))/ΔH_per_query`，随对称阶数增长。系：**对称越强，R69 越过度保守**。

**引理 20（任务相关位姿精度）** delta 法 `Var(m)≈∇mᵀΣ∇m`；`m` 规范不变 ⇒ ∇m⊥轨道切向 ⇒ 对称方向零贡献。最优主动视角最大化 `E[Δ(∇mᵀΣ∇m)]`。推论：位姿 RMSE 会误导主动感知，存在 RMSE 更小而成功率方差更大的视角。

**引理 21（任务安全默认的风险上界）** 后验贪心若落在某任务 `T_min` 安全包络外，violation≥p(T_min)；而 minimax 安全默认 `a_def=argmin_a max_T Risk_T(a)` 满足 `max_T Risk_T(a_def)≤max_T Risk_T(a)` 对所有可行 a，故灾难率严格更低；平均成功率损失由 `D_TT'` 界住。⇒ 别名未消解时不要 argmax 任务。

**引理 22（共同模式地板）** 共享 z 下存在共同模式项 δ_cm（所有源同时翻错），任意融合错误率 ≥ δ_cm；R69 的 `δ_p ρ^{k−1}` 无共同模式时才成立。k_eff 只加速独立部分衰减，地板不动。⇒ 必须 `k_ext≥1`（外源）才能压到 δ_cm 以下。

**定理 18（GAUGE-RAS 严格包含 FLUID-RAS）** A99（G^rel 正确且 GEC 有效）、A100（任务唯一或别名已由安全默认处理）、A101（证据有效独立性满足）下，任意状态期望任务风险 ≤ FLUID-RAS；`G={e}∧单任务∧ρ_eff=0` 时逐指令相同。证明：商只移除 F_T 不变方向 ⇒ 任务结果分布不变（安全恒等），交互预算不浪费（效率改善）；证书失效/别名未解则走定义 322 的 R69 退化路径。

**定理 19（跨任务安全与无突变）** BIC 硬约束 ⇒ 允许的信息动作对安全任务信念子空间漂移 ≤ ε_x；XVoI 负外溢只损效率不损安全；退避 λ 单调不降，继承 R69 定理 17 的提交/换装不变式 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：GAUGE-RAS 的全部效率收益押在「任务相关规范群 G_T^rel 估计正确」这一前提上——**若对称性判断错了，系统会把两个对任务/安全并不等价的抓取或任务并成一个轨道，然后以「这没差别」的确定性执行错的那一个；这种错误对熵、VoI、ECE 全不可见，因为系统已先验认定差别不存在**。R69 错在「把等价的当不同的，多问几句」；R70 错在「把不同的当等价的，直接做错」——**错并，比多问更危险**。

**次级风险与缓解**：共享 trunk 共同模式误差（EIG + 强制外源 + 引理 22 地板）；安全默认过度保守（D_TT' 门控 + E305/E309 标定）；GEC 假通过（ℰ_sym 对抗集 + E302）；BIC 否决饿死交互（预算/优先级调度 + E306）；商群缓存漂移（低频重估 + E313）。
