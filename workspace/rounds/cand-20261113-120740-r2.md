>
> 本轮的核心命题：
>
> **把「安全证书」升级为「能量注解证书」，把「安全闭环设计」升级为「能量约束下的快速原型搜索」：PACE（Prototype-Accelerated Certified Energy-closure，原型加速的能量认证闭环）。**
>
> PACE 问的不是「系统安不安全」，也不是「系统省不省电」，而是：**为了达到给定安全置信度，最少需要花多少焦耳——并且这些焦耳该花在运行时的感知/计算上，还是花在设计期的原型实验上？**

## 0. 直觉与动机

**灵感 1（快速原型 → 最小可证伪闭环 MFC）**
直觉：传统安全栈是「先造完整系统、再做全面验证」，迭代周期以周/月计，失败一次代价巨大。快速原型的精髓恰恰相反：**先用最小、最便宜、但可以被立刻证伪的闭环跑起来**，让失败尽早、尽量便宜地发生，然后按「信息收益/焦耳」逐层长大。这与 VISTA/RAS 的「故障可归因」天然同构：故障归因要的是「哪一个假设能被当前观测区分」，快速原型要的是「哪一个原型能被当前实验证伪」——两者都是**主动信息获取**。
于是定义 **MFC（Minimal Falsifiable Closure）**：`(单通道感知, 单故障假设, 单证书谓词, 单证伪测试 ψ)`。MFC 不是「简化版系统」，而是一个**可被实验判死的科学命题**。PACE 的闭环从 MFC 开始生长，而不是从完整 RAS 开始裁剪。

**灵感 2（能耗优化 → 能量是设计期与运行期的统一货币）**
直觉：能耗优化通常被当作部署后的推理加速（量化、剪枝、事件相机）。但对闭环安全系统而言，能量有四种完全不同的去向：
1. **感知能耗** `E_sense`：面部 ROI、深度、触觉的采样与传输；
2. **计算能耗** `E_comp`：联合后验、认证前缀、Grad-CAM/注意力；
3. **执行能耗** `E_act`：力限越保守，任务越慢，维持时间越长，执行能耗反而上升；
4. **原型能耗** `E_proto`：仿真 rollout、数字孪生、真实试探、标定实验。
关键洞察是：**安全不是免费的，也不总与能耗同向**。过度保守的力限会增加任务时长从而增加 `E_act`；而更准的感知/归因可以用更小的保守裕度达成同等安全。因此存在一个**内点最优**：不是「越安全越好」，也不是「越省电越好」，而是沿着「安全-能耗 Pareto 前沿」选点。
更关键的是，**原型实验本身要耗能**（仿真机时、真机试跑、人因测试）。若把快速原型看成「用能量购买关于证书有效性的信息」，那么设计期与运行期的能量就被同一个预算 B 统一了：**PACE = 在总能量预算 B 下，最大化最终证书置信度的资源分配问题**。

**灵感 3（两灵感合流 → 能量-信息-安全三角）**
直觉：把「每焦耳换来的安全增量」记作能效 `η = ΔS/ΔE`。快速原型提供的是**设计期能效**：花少量原型能量，排除大量错误闭环；能耗优化提供的是**运行期能效**：花少量感知/计算能量，维持高证书置信度。二者共享一个结构：
- 设计期：`E_proto` → 信息增益 `IG(certificate)` → 缩小候选闭环空间；
- 运行期：`E_sense + E_comp` → 后验集中度 → 放宽 `λ_risk` 从而省 `E_act`。
因此 PACE 的核心不是又一个控制器，而是**一个跨设计期/运行期的能量-信息-安全调度器**。它把 RAS 的 `λ_risk` 从「风险缩放」推广为「能量-风险联合缩放」，把 VISTA 的「故障可归因」推广为「原型可证伪、证书可迁移、能量可核算」。

**灵感 4（快速原型 × 能耗优化 → 原型保真阶梯 PFL）**
直觉：快速原型最大的诱惑也是最大的陷阱——**低保真仿真里过了，真实系统里炸**。解决办法不是「一律用高保真」（太贵），而是像能耗优化里的「多保真度优化」一样，建一条**保真阶梯** `T_1 ≺ T_2 ≺ … ≺ T_L`：低层便宜、筛掉明显坏的候选；高层昂贵、只用于存活候选。每一层的证书都带一个**迁移误差上界** `|S_real - S_T| ≤ L_T·(1-φ_T)`。于是一个原型该不该升保真度，就变成一个可计算的问题：**升保真带来的证书方差下降，是否值得它多花的焦耳？**

**灵感 5（PACE 与 VISTA/RAS 的接口）**
PACE 不推翻 VISTA/RAS，而是把它们当作**闭环库**：VISTA 提供技术故障归因，RAS 提供情绪-风险闭环，PACE 提供「为当前任务/本体/电池预算挑选并证明最小充分子集」的元层。`J_PACE` 在 `J_RAS` 之上增加 `E_vec, η, prototype_id, fidelity, falsification_log, budget_remaining`。当预算 B → ∞ 时，PACE 退化为完整 RAS（安全优先）；当 B 极紧时，PACE 退化为 MFC 的保守降级（能量优先）。这条**退化链**是本轮理论的核心：它让「安全」和「省电」成为连续谱上的两个端点，而不是两个对立口号。

## 1. 形式化定义（增量：定义 245–260）

- **定义 245（PACE 总览）** `PACE = (MFC, EPU, PFL, PCC, EAC, EIGS, ESR, PGN)`：分别是最小可证伪闭环、能量核算单元、原型保真阶梯、原型证书编译器、能量注解证书、EIG/焦耳原型调度器、能量塑形精化、运行期能量治理器。不变式：证书构建与原型搜索只在语义流；实时流只做能耗采样、`λ_risk` 缩放与早停，零学习写操作。
- **定义 246（能耗向量与总预算）** 对闭环 `C` 与地平线 `H`：
  `E(C) = (E_sense, E_comp, E_act, E_proto) ∈ ℝ^4_+`，
  `E_total(C) = E_proto(C) + ∫_0^H [P_sense(t) + P_comp(t) + P_act(t)] dt ≤ B`。
  其中 `E_proto(C) = Σ_j n_j·(c_fidelity(T_j) + c_rollout(T_j))` 为多保真原型实验能量。
- **定义 247（安全度量与能效）** `S(C) = 1 - P(violation | C)`（或证书有效概率）；`η(C) = ΔS/ΔE` 为边际安全-能量效率。PACE 目标是 `max_C S(C) s.t. E_total(C) ≤ B`。
- **定义 248（安全-能耗 Pareto 支配）** `C_1 ≻ C_2 ⇔ S(C_1) ≥ S(C_2) ∧ E_total(C_1) ≤ E_total(C_2)`，且至少一者严格。前沿 `F = {C : ¬∃C', C' ≻ C}`。
- **定义 249（最小可证伪闭环 MFC）** `MFC = (ch, H_0, φ_cert, ψ)`，其中 `ch` 为单感知通道，`H_0 ∈ ℋ_RAS` 为单故障假设，`φ_cert` 为单证书谓词，`ψ` 为能在预算 `ε_proto` 内以功效 `1-β` 拒绝 `H_0` 的证伪测试。MFC 必满足：`P(ψ 接受 | C 不安全) ≥ 1-β`。
- **定义 250（生长算子 G）** `G(MFC, L) = MFC ⊕ ℓ`，仅当新增层 `ℓ` 满足 `η(ℓ) = ΔS(ℓ)/ΔE(ℓ) ≥ η_min` 且 `E_total ≤ B`；否则不生长。每一层生长必须附带一个新的可证伪测试 `ψ_ℓ`。
- **定义 251（原型保真阶梯 PFL）** 序列 `T_1 ≺ T_2 ≺ … ≺ T_L`，保真度 `φ_1 < … < φ_L ≤ 1`，单位 rollout 成本 `c_1 < … < c_L`，且满足证书迁移界：
  `|S_real(C) - S_{T_j}(C)| ≤ Λ_j := L_S·(1-φ_j) + ε_sim`，
  其中 `L_S` 为安全度量对模型误差的 Lipschitz 常数，`ε_sim` 为仿真器系统偏差。
- **定义 252（原型证书编译器 PCC）** `PCC: (task_spec, library L, budget B) → (C*, J_PACE)`。编译器先在 `L` 上做**反合一（anti-unification）**，把新任务归约到最相近的已有闭环模板，再只对差异部分生成原型测试，从而把「从零设计」变为「模板修补」。
- **定义 253（能量注解证书 EAC）** `J_PACE = (J_RAS, E_vec, η, prototype_id, φ, falsification_log, B_remaining, pace_ver)`。`Valid(J_PACE) ⇔ Valid(J_RAS) ∧ E_total ≤ B ∧ φ ≥ φ_min ∧ falsification_log 非空且未被证伪`。
- **定义 254（EIG/焦耳原型调度）** 对候选测试 `x`，`EIGS(x) = I(Valid(J_PACE); y_x) / E_cost(x)`。每次选择 `x* = argmax_x EIGS(x)`，其中 `y_x` 为测试结果。当 `EIG` 关于测试集合单调次模时，贪心达到 `(1-1/e)` 近似。
- **定义 255（能量-风险联合缩放）** 将 RAS 的 `λ_risk` 扩展为 `λ_ER(t) = λ_risk(t) · g(E_rem(t)/B)`，`g` 单调递增、`g(0)=g_min`、`g(1)=1`；能量越紧，容差越保守（`λ_ER` 越小）。该缩放必须与 C-RAS 认证前缀**联合认证**，不得先算前缀再乘缩放。
- **定义 256（原型保真升级判据）** 在 `T_j` 上存活且证书区间 `[S-Λ_j, S+Λ_j]` 仍跨越决策阈值 `τ_S` 时，必须升级到 `T_{j+1}`；升级的期望收益 `EIG(升保真)/ΔE_proto ≥ η_min` 才允许。这排除了「低保真误放行」。
- **定义 257（PACE 运行期治理器 PGN）** 维护滚动能量预算 `E_rem`，在每个认证前缀周期输出 `(k_PACE, λ_ER, spend_plan)`，其中 `spend_plan` 决定本轮把剩余能量分配给感知/计算/原型探针的哪一栏。
- **定义 258（能耗最优分配）** 设各层安全-能量曲线 `S_i(E_i)` 可分离且凹，则 `max Σ_i S_i(E_i) s.t. Σ_i E_i ≤ B` 的最优解由等边际条件 `∂S_i/∂E_i = μ` 给出；离散情形用贪心 `argmax_i ΔS_i/ΔE_i` 即得最优。
- **定义 259（原型覆盖度）** 库 `L` 对前沿 `F` 的 `(ε_S, ε_E)`-覆盖度：`∀C∈F, ∃C'∈L, S(C') ≥ S(C)-ε_S ∧ E(C') ≤ E(C)+ε_E`。PACE 的最优性间隙由覆盖度与迁移界共同决定。
- **定义 260（退化链）** `B→∞ ⇒ PACE ≡ RAS`；`B→0 ⇒ PACE ≡ MFC(最保守降级)`。PACE 是连接两者的一族单调插值：预算增加时安全性单调不减、能量单调不减。

## 2. 关键算法骨架

```python
# PACE 总循环：能量约束下的快速原型 -> 证书 -> 运行
def PACE_round(M, task, obs, B, H):
    # 0) 能量账本
    epu = EnergyParetoUnit(budget=B, horizon=H)
    # 1) 模板检索 + 反合一：从库中找最近闭环
    template, diff = M.pcc.anti_unify(task, M.library)
    # 2) 最小可证伪闭环：先跑最便宜、最可能失败的测试
    C = M.mfc.build(template, diff)          # (ch, H0, φ_cert, ψ)
    log = []
    while True:
        # 3) EIG/焦耳原型调度：挑单位能量信息增益最高的测试
        test = M.eigs.choose(C, M.pfl, epu.remaining())
        if test is None or not epu.can_afford(test):
            break
        y = M.pfl.run(test)                   # 可能是低保真仿真
        log.append((test, y))
        # 4) 保真升级判据：证书区间是否跨越阈值
        if M.pfl.crosses_threshold(C, y) and epu.can_afford_upgrade(C):
            M.pfl.escalate(C)
        # 5) 生长算子：只在 η >= η_min 时加层
        if M.mfc.can_grow(C, y, eta_min=M.eta_min):
            C = M.mfc.grow(C, M.mfc.best_layer(C))
        else:
            break
    # 6) 证书编译与校验
    J = M.pcc.compile_certificate(C, log, epu)
    if not Valid(J):
        return M.mfc.fallback(C), J        # 退化为 MFC 保守闭环
    # 7) 运行期：能量-风险联合缩放 + 认证前缀
    k, lam, plan = M.pgn.step(M, obs, J, epu)
    return (k, lam, plan, J), log


# 运行期能量治理器（与 C-RAS 联合认证，不后乘）
class PrototypeEnergyGovernor:
    def step(self, M, obs, J, epu):
        face_gate = M.er.recognize(obs.img)
        rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
        joint, _ = M.efs.synthesize(rho, face_gate)
        # 能量-风险联合缩放
        lam_r = M.efs.risk_scale(joint)              # RAS 原 λ_risk
        lam_e = epu.g(epu.remaining() / epu.B)       # 能量紧 -> 保守
        lam = max(0.5, min(1.2, lam_r * lam_e))
        # 认证前缀必须用 λ_ER 重新认证，而不是事后缩放
        A = M.vista.ach.propose(M.lsf.fuse(obs), H=M.vista.H)
        k = M.csc_ras.certified_prefix_ras(
                A, joint, min(M.vista.m, M.er.max_m_emotion), M.alpha_chunk,
                risk_scale=lam)
        spend = self.allocate(epu, M.layers)         # 贪心 ΔS/ΔE
        return k, lam, spend


# 能量最优层分配（定义 258）
def allocate_energy(epu, layers, B):
    remaining, plan = B, {}
    while remaining > 0:
        cands = []
        for l in layers:
            e = epu.next_quantum(l)
            if e <= remaining:
                cands.append((epu.delta_s(l, e) / e, l, e))
        if not cands:
            break
        _, l, e = max(cands)
        plan[l] = plan.get(l, 0) + e
        remaining -= e
    return plan
```

## 3. 推导

**引理 11（可分离凹曲线的贪心最优性）** 若各层安全产出 `S_i(E_i)` 可分离、凹且单调，则按 `ΔS_i/ΔE_i` 从大到小的贪心分配在离散预算下达到最优。证明用交换论证：若最优解给某层多分配而边际效率较低，则交换一个量子严格不劣。推论：PACE 的层选择不需要全局搜索，只需维护每层的边际效率堆。

**引理 12（保真阶梯的证书迁移收敛）** 沿 `PFL` 升保真，若每层 `φ_j ↑ 1`，则迁移误差上界 `Λ_j = L_S(1-φ_j)+ε_sim` 单调下降；跨层组合误差由三角不等式与望远镜求和界为 `Σ_j Λ_j·1{在 T_j 被跳过}`。故「低层粗筛、高层精验证」的总误差不劣于「只在最高层验证」的误差，但期望能量显著更低——这是快速原型与能耗优化共同的理论根据。

**定理 11（PACE 的 ε-最优性）** 设库 `L` 对 Pareto 前沿 `F` 具有 `(ε_S, ε_E)`-覆盖度，`PFL` 最高层保真度 `φ_L` 满足 `Λ_L ≤ ε_T`，且原型证伪测试功效 `≥ 1-β`。则对任意预算 `B`，PACE 返回的 `C_PACE` 满足：
1. `E_total(C_PACE) ≤ B`（硬约束，账本不超支）；
2. `S(C_PACE) ≥ S*_B - ε_S - ε_T`，其中 `S*_B = max_{E≤B} S`；
3. 失败概率 `≤ δ + β·|L_tested|`（δ 为迁移置信度，`|L_tested|` 为被证伪测试数）。
当 `B→∞` 且 `L` 覆盖完整 `F` 时，`ε_S→0`，PACE 退化为 RAS 的最优证书。

**定理 12（EIG/焦耳调度近似最优）** 若原型测试的期望信息增益 `I` 关于已选测试集单调次模，则贪心 `EIG/焦耳` 调度达到最优期望信息增益的 `(1-1/e)`，且在单位成本相等时进一步还原为标准 EIG 贪心。推论：**原型预算应优先买「能区分最多候选闭环」的测试，而不是买「最贵最真」的测试**——这解释了为什么低保真、高吞吐的快速原型常优于单次高保真验证。

**定理 13（能量-安全连续谱）** 在 `g` 单调、`λ_risk` 收敛（引理 9）且 C-RAS 用 `λ_ER` 重新认证的前提下，PACE 的 `(E_total, S)` 轨迹在 `B∈(0,∞)` 上构成一条单调 Pareto 曲线：预算增加时 `S` 不减、`E` 不减；`B→∞` 恢复 RAS，`B→0` 收敛到 MFC 的最小安全闭环。证明由 `g` 的单调性与引理 11 的等边际条件直接得到。

## 4. 复杂度与能量分析

| 组件 | 时间 | 空间 | 能量 | 正确性保证 |
|---|---|---|---|---|
| MFC 构建 + 证伪测试 | <1s（模板命中）/ 分钟级（冷启动） | O(1) 模板差量 | `ε_proto` 可控 | 定义 249：功效 ≥ 1-β |
| PCC 反合一编译 | O(|L|·d) | O(|L|) | 可忽略 | 定理 11：覆盖度间隙 |
| EIG/焦耳调度 | O(n_test²)（小规模） | O(n_test) | 计入 `E_proto` | 定理 12：(1-1/e) |
| PFL 多保真 rollout | 低层 <1s，高层分钟级 | 按仿真器 | 主要设计期开销 | 引理 12：迁移界 |

## 4. 推导

**引理 11（可分离凹曲线的贪心最优性）** 若各层 `S_i(E_i)` 可分离、凹、单调，则按 `ΔS_i/ΔE_i` 降序的贪心分配在离散预算下最优。交换论证：设最优解给边际效率较低的层多分配一个量子，则与高效率层交换后总安全不降、预算不变，矛盾。

**引理 12（保真阶梯迁移收敛）** 沿 `PFL` 升保真时 `Λ_j=L_S(1-φ_j)+ε_sim` 单调下降；跳过层的误差由三角不等式与望远镜求和界定。故「低层粗筛、高层精验」的误差不劣于仅最高层验证，但期望能量更低。

**定理 11（PACE 的 ε-最优性）** 设库 `L` 对前沿 `F` 具 `(ε_S, ε_E)`-覆盖度，`φ_L` 使 `Λ_L ≤ ε_T`，证伪功效 `≥1-β`。则对任意 `B`：
1. `E_total(C_PACE) ≤ B`（硬约束）；
2. `S(C_PACE) ≥ S*_B - ε_S - ε_T`；
3. 失败概率 `≤ δ + β·|L_tested|`。
`B→∞` 且覆盖完整时 `ε_S→0`，PACE 退化为 RAS 最优证书。

**定理 12（EIG/焦耳近似最优）** 若 `I` 关于测试集单调次模，贪心 `EIG/焦耳` 达到最优期望信息增益的 `(1-1/e)`；单位成本相等时退化为标准 EIG 贪心。推论：**原型预算应买「能区分最多候选闭环」的测试，而非「最贵最真」的测试**。

**定理 13（能量-安全连续谱）** 在 `g` 单调、`λ_risk` 收敛（引理 9）、C-RAS 用 `λ_ER` 联合认证的前提下，PACE 的 `(E_total, S)` 轨迹在 `B∈(0,∞)` 上单调：预算增则 `S`、`E` 均不减；`B→∞` 恢复 RAS，`B→0` 收敛到 MFC 最小安全闭环。

**推论 11（安全-能耗不可能三角）** 对固定任务与固定原型保真度，`(S, 响应时延, E_total)` 三者不可同时任意优化；PACE 的贡献不是打破三角，而是把「在哪条边上取点」变成显式、可认证、可预算的决策。
