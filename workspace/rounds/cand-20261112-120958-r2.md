# 第 58 轮（承接第 57 轮 IP-133~138「少样本×跨模态×个性化证据承诺」；本轮灵感：「运动规划」×「自适应控制」）

> 第 57 轮把安全感从"证据质量"再往前推了一步：元先验摊销、跨模态对账、个性化有界信任，使单点坏证据/坏先验不再直接变成坏承诺。但它同时留下三个更深的控制论漏洞：**(a)** 证据与承诺都是"逐检查点"的局部判断，而一次落足会改变后续可落足集——局部证据安全不等于轨迹安全，逐点风险的算术和也不是整条路线的失效概率；**(b)** "多探针=更多证据"被默认成立，但若探针激励不足（同一模态、同一方向重复），被辨识的参数根本不可辨识，后验变窄只是幻觉（自适应控制称之为缺乏持续激励 PE）；**(c)** 信念/信任的自适应被当作"越更新越准"，但高增益自适应遇到证据时延会震荡失稳，地形非平稳时旧证据既"过期"又"目标已移动"。本轮两个灵感各补一条腿并互相咬合：**运动规划**把承诺从"点"提升到"带证据的轨迹前缀/同伦类"（证据管、证据支持生存核、滚动时域、同伦感知重规划）；**自适应控制**把"探询"严格化为"激励"、把"信任更新"严格化为"带投影/死区/泄漏的鲁棒自适应"，并给出证据闭环的稳定性证书。核心命题升级为 **"轨迹可联合承诺、激励可辨识、自适应可稳定的证据说可信"**。

核心矛盾：
- **H29（逐点证据 vs 轨迹耦合）**：检查点证据独立、承诺也独立，但一次早段落足会缩窄后续可行集；"每点局部安全"可被串成"全局走进死角"。反向地，在不确定证据图上做全局轨迹优化又容易过度乐观，因为它默认了证据相关结构已知。
- **H30（激励 vs 可辨识 vs 安全）**：更多探针未必更多信息；缺乏持续激励时参数不可辨识，窄后验是假象。而要获得激励就必须扰动/试探，扰动本身消耗安全裕度——可辨识性与安全可能直接冲突，某些参数的正确安全答案是"承认不可辨识、按鲁棒未知处理"而非"探到能辨识"。
- **H31（自适应增益 vs 时延/非平稳）**：证据链有延迟（探针→后验→策略），高增益自适应加延迟会震荡；地形非平稳使旧证据既陈旧又指向已移动的目标。稳定追踪与快速响应不可兼得，需要 Lyapunov/收缩证书、增益-时延上界、死区与泄漏。

## 0. 直觉与动机

**灵感 1（运动规划 → 轨迹证据管 + 生存核 + 滚动时域 + 同伦类）**
直觉：落足不是独立事件。第一脚决定后面还能落在哪儿；一串"每点都还行"的检查点可能把你送进没有退路的死角。因此承诺不该是"这个接触点有证据"，而应是"**这条轨迹前缀的整条证据管有证据，且它的终点落在证据支持的生存核里**"——即便事后发现判断有偏，仍存在一条证据支持的恢复轨迹把你带回安全集，才允许不可逆接触。规划层面用滚动时域：只承诺近端 h_c 步，尾部保留为可重规划的暂定段，证据随"年龄"指数陈旧。绕行用同伦类：同一条走廊里的近邻路线共享同一个物理欺骗/失效模式，真正的替代必须跨同伦类、带来近似独立的证据。

**灵感 2（自适应控制 → 持续激励 + 鲁棒自适应 + 稳定性证书）**
直觉：探针像自适应控制里的回归向量，探得再多，若方向几乎共线，参数空间仍有一整个方向没被激发——后验在那一维的"窄"完全是幻觉。于是证据质量从"样本数"换成"**激励矩阵 G_k 的最小特征值/条件数**"：达不到 λ_min≥λ* 的探针不计入 EV-probe*，必须按 Fisher/CRLB 沿最坏方向把后验撑开；实在不能安全激发，就按"鲁棒未知"给它一个保守界，而不是硬探。自适应更新沿用成熟护栏：投影 Π 把参数/信任锁在安全集（= 单向有界的连续版）、死区 dz 不被噪声带节奏、泄漏 σ 忘掉过自信的旧适应、增益必须满足 Γ≤Γ_max(τ_d) 以规避时延诱发的震荡。

**灵感 3（两灵感咬合 → 探询预算即激励预算，承诺即轨迹前缀）**
直觉：VOI 的"值"现在要乘上"这一次探针能把最坏方向的可辨识性提高多少"；承诺的门槛从接触级证据门升级为轨迹级证据门；重规划不仅要换代价，还要换同伦类以换取证据独立性。运动规划负责"证据如何在时空上耦合传播"，自适应控制负责"激励如何让参数可辨识、闭环如何稳定"——一个管结构，一个管增益。

**灵感 4（证据门从接触级到轨迹级，从五类到带证书）**
直觉：第 57 轮 EV-probe*/visit/margin/xmodal/human 五类证据仍是局部量。本轮对每一段轨迹段附加：激励证书（λ_min）、自适应稳定证书（Γ/时延/死区）、轨迹陈旧权重（age）、同伦类身份。不可逆接触的必要证据集改为**轨迹级**：{EV-probe*∧激励证书 ∨ EV-margin} ∪ 生存核可行 ∪ 佐证，EV-xmodal 仍限 L1。

**灵感 5（EMP：把探询预算、承诺长度、尾部可重规划性一起优化）**
直觉：滚动时域把"承诺"变成一个可调长度 h_c 的动作：h_c 越大越快但也越难反悔。把探针代价、承诺前缀长度、终端生存核约束一起放进证据-MPC 的代价里，近端执行、尾部重规划、证据陈旧衰减；这给"快"和"可反悔"一个可证明的折中，而不是拍脑袋的固定检查点。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（轨迹证据管与生存核 TEC）** 规划轨迹 ξ={x_t}_{t=0}^{T}，证据管 𝒯(ξ)=∪_t B_ε(x_t) 为每段挂证据支持集的时空管。轨迹联合证据支持 C_ev(ξ)=⋂_{t≤H} Sup(b_{x_t})，其中 Sup 为证据支持集（后验/共形带/生存核约束的交）。**证据支持生存核** V_ev={x : ∃ξ' 从 x 出发，ξ' 全段落在 C_ev 内且终态∈X_safe}。承诺规则：接触 c 仅在 x_c∈V_ev ∧ C_ev(ξ_{≤h_c}) 一致时允许；联合失效界用相关感知联合界 P_fail(ξ)≤JointBound({P_fail(t)},{Σ_ε})，Σ_ε 为段间证据相关阵（不假设独立）。

**定义 140（激励矩阵与可辨识证书 PEX）** 探针特征回归向量 φ_i∈R^d（法向力/切向/滑移率/接触斑/声谱等），激励矩阵 G_k=(1/k)Σ_{i=1}^k φ_iφ_i^T，Fisher 信息 F_k=Σ_i φ_iφ_i^T/σ²。可辨识证书 κ_k=(λ_min(G_k), λ_max(G_k)/λ_min(G_k))；EV-probe*/EV-margin 仅在 λ_min(G_k)≥λ*(w*) ∧ κ_k≤κ_max 时成立。否则沿 F_k^{-1} 最坏方向以 CRLB 撑开后验：width_worst≥sqrt((F_k^{-1})_{vv})；若安全激发不可得（需超预算扰动），标 unidentifiable 并按鲁棒界 [θ_lo,θ_hi] 进入 P_fail，禁止以窄后验承诺。VOI 改为激励加权：VOI_ex(π)=VOI(π)·Δλ_min(π|G_k)⁻，即"能把最坏方向可辨识性抬多少"。

**定义 141（鲁棒自适应承诺 RAC）** 误差 e=y−ŷ（实测 vs 参考安全模型），参数/信任更新 θ̇=Proj_Θ(Γφe)−σ(θ−θ_safe)，含投影 Π、死区 dz（|e|≤d 不更新）、泄漏 σ、有界增益 Γ≤Γ_max(τ_d)（τ_d 为证据时延）。稳定性证书：存在 V(θ,e) 使 V̇≤−cV+b（ISS），则证据闭环对时延/非平稳输入稳定；增益超界或无 PE 时冻结自适应（保持保守先验）。承诺激进度（步态/速度/δ_f）为被增益调度的对象，但全程受硬界 Θ_safe 投影。

**定义 142（证据滚动时域规划 EMP）** 时域 H、承诺前缀 h_c≤H。代价 J(ξ)=Σ_{t<H}[risk(x_t,u_t|b_t)+λ_p·probe_cost]+Φ_term(V_ev,evidence_gate)；证据陈旧权 age: w(age)=e^{−λ_age·age}。规则：优化 ξ*；仅执行前 h_c 段并承诺，尾部保留；每步重规划；若终端生存核空或证据门不过，则延长 h_c 前先探针（受激励约束），否则缩短 h_c/绕行/降档/协商。

**定义 143（同伦感知重规划 HRP）** 轨迹同伦类 [ξ]（不穿越禁行/失效区的连续形变等价类）。类证据 e([ξ])、类间证据相关阵 Σ_{[ξ][ξ']}。规则：(R1) 类内绕行视为同一证据源，不重复计为独立佐证；(R2) 重规划优先跨类，选择使 e([ξ']) 与已证伪证据相关最小者；(R3) 若所有可达类共享同一可疑模态（Σ 下界高），视为"无独立替代"，只能降档/停/协商。EV-xmodal 与轨迹证据均不得跨类自动继承。

**定义 144（轨迹证据门 TEG 与证书 J_t）** 轨迹级证据门：不可逆接触必要证据集={EV-probe*∧激励证书 ∨ EV-margin}∪佐证∪(x_c∈V_ev)，EV-xmodal 仅 L1 且不得单独满足不可逆段；每段附 (λ_min,Γ/τ_d/dz,age,[ξ])。J_t=(ξ,h_c,C_ev,V_ev,[ξ],seg_evidence,excitation_log,adapt_log,staleness,probe_log,consent_log,xmodal_log,auth_log,J_p)，继承 J_p 全检并新增轨迹级检查。

## 2. 关键算法伪代码（完整版见产物区）

```python
def excitation_ok(G, lam_star, kappa_max):            # IP-140: 可辨识证书
    lam = eigvalsh(G)
    return lam[0] >= lam_star and lam[-1]/max(lam[0],1e-12) <= kappa_max

def trajectory_commit(route, M, meta, ctrl, budgets):  # IP-139/142 合流
    for H in growing_horizons(route):
        xi = evidence_mpc(route, H, M)                 # 近端有证据、尾部暂定
        Cev = intersect_support(M, xi[:H])
        Vev = evidence_viability_kernel(Cev, X_safe)   # 证据支持生存核
        if xi[0].state in Vev and joint_bound(route, xi) <= delta_f:
            return commit_prefix(xi, h_c=min(H, len(xi))), Vev
    return probe_or_replan(route, M, budgets)          # 探针/跨同伦类绕行

def robust_adapt(theta, e, phi, G, tau_d):             # IP-141: 投影/死区/泄漏
    if abs(e) <= dz or not excitation_ok(G, lam_star, kappa_max):
        return theta                                   # 死区/无激励→冻结
    g = min(Gamma, Gamma_max(tau_d))                   # 增益-时延稳定界
    d = projection(theta + g * outer(phi, e), Theta_safe)
    return d - sigma * (d - theta_safe)                # 泄漏回保守先验

def homotopy_replan(route, M, falsified):              # IP-143: 跨类换证据
    classes = reachable_homotopy(route, M)
    return min(classes, key=lambda c: evidence_corr(c, falsified) + risk(c, M))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TEC | O(H·\|V\|) 规划 + O(\|ξ\|) 联合界 | O(\|V\|·H) | 生存核非空、联合界相关感知（A41） |
| PEX | O(d²·k)/窗口（增量特征值） | O(d²) | λ_min≥λ*、无激励不计证据、CRLB 撑开（A42） |
| RAC | O(d²)/更新 | O(d²) | 投影/死区/泄漏、Γ≤Γ_max(τ_d)、ISS（A43） |
| EMP | O(H²·\|A\|·\|V\|) | O(H·\|V\|) | 端点生存核约束、前缀可重规划 |
| HRP | O(\|classes\|·\|V\|) | O(\|classes\|) | 跨类独立性声明诚实（A44） |
| TEG | O(\|ξ\|) | O(\|ξ\|) | 轨迹级证据齐、不可逆段禁 xmodal |

**正确性定理（Motion-Adaptive Evidence Soundness, MAES）**：在 A33–A40 上加 (A41) 轨迹联合界相关感知且生存核保守；(A42) EV-probe*/margin 仅在激励证书成立时计入，否则按 CRLB/鲁棒界撑开；(A43) 自适应满足投影/死区/泄漏且 Γ≤Γ_max(τ_d)，闭环 ISS；(A44) 同伦类独立性声明诚实、类间证据相关阵保守。则：(i) 轨迹级承诺失效率 ≤ δ_f + ε_meta + δ_probe + ε_h + δ_joint + δ_pe + δ_adapt；(ii) 交互单调性强化：激励、自适应、同伦重规划只能经"信念更准（含撑开）/动作更保守（h_c↓、降档、跨类绕行、冻结自适应）"影响系统；(iii) EMP 在 H 步内、探针受 λ* 与预算约束下终止于 {前缀承诺, 绕行, 降档, 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|

## 6. 本轮最大风险

**一句话**：本轮为了让"证据更可信"引入了激励与自适应，却可能把系统推入一个危险的自我强化循环——为了证明参数可辨识而持续扰动、为了让证据快速生效而提高自适应增益，二者都在悄悄透支安全裕度；最大的风险不是证据不够，而是系统"为了获得证据/保持灵敏"而主动把自己探到失稳边缘，因此必须以激励预算硬上限、仅非不可逆层扰动、Γ≤Γ_max(τ_d) 的 ISS 证书和不可辨识即鲁棒未知四道护栏，宁可慢、宁可宽、宁可冻结自适应，也不拿安全换可辨识。

# 第 58 轮产物 · 创新点清单 v34：MotionAdapt-Evidence（运动规划×自适应控制×证据承诺，TEC×PEX×RAC×EMP×HRP×TEG）

### IP-139 TEC（轨迹证据管 + 证据支持生存核）

```python
def evidence_tube(M, xi, H):
    Cev = support(M.b[xi[0].region])                  # 初始证据支持集
    for t in range(1, H + 1):
        Cev = intersect(Cev, support(M.b[xi[t].region]))  # 联合证据支持
    return Cev

def evidence_viability_kernel(Cev, X_safe, M):
    # 反向可达：从 X_safe 前推/后推，只保留全程落在 Cev 内的状态
    K = X_safe
    for t in reversed(range(H)):
        K = {x : transition(x, M) & Cev[t] != empty and successor(x) in K}
    return K                                          # 空集 ⇒ 无证据支持的退路

def joint_bound(route, xi, Sigma):
    # 相关感知：不假设段独立，用相关阵/最坏 copula 给出上界
    ps = [segment_fail_prob(s, M) for s in xi]
    return worst_copula_sum(ps, Sigma)                # ≥ Σps，保守
```

### IP-140 PEX（激励矩阵与可辨识证书）

```python
def excitation_matrix(phis, decay=1.0):
    G = zeros(d, d)
    for i, phi in enumerate(phis):
        G += (decay ** (len(phis) - i)) * outer(phi, phi)
    return G / max(len(phis), 1)

def identifiability_certificate(G, lam_star, kappa_max):
    lam = eigvalsh(G)
    lmin, lmax = lam[0], lam[-1]
    return dict(lmin=lmin, cond=lmax / max(lmin, 1e-12),
                ok=(lmin >= lam_star and lmax / max(lmin, 1e-12) <= kappa_max))

def probe_as_evidence(phi_seq, Fk, lam_star, kappa_max):
    cert = identifiability_certificate(excitation_matrix(phi_seq), lam_star, kappa_max)
    if cert['ok']:
        return ('EV-probe*', cert)
    # 不可辨识：沿 Fisher 最坏方向用 CRLB 撑开，或标 unidentifiable 走鲁棒界
    v = worst_eigvec(Fk)
    width = sqrt(max(inv(Fk)[v][v], 0.0))
    return ('unidentifiable', dict(belt_width=width, robust=[theta_lo, theta_hi]))

def voi_ex(probe, M, inf, G):
    return voi(probe, M, inf) * max(0.0, delta_lmin_after(G, probe))
```

### IP-141 RAC（鲁棒自适应承诺控制）

```python
def robust_adapt(theta, e, phi, G, tau_d, cfg):
    if abs(e) <= cfg.dz:
        return theta                                   # 死区：不被噪声带节奏
    if not cfg.excitation_ok(G):
        return theta                                   # 无 PE：冻结自适应
    gamma = min(cfg.Gamma, cfg.Gamma_max(tau_d))       # 增益-时延稳定界
    theta_new = projection(theta + gamma * outer(phi, e), cfg.Theta_safe)
    theta_new = theta_new - cfg.sigma * (theta_new - cfg.theta_safe)  # 泄漏
    return theta_new

def iss_certificate(theta_hist, e_hist, tau_d):
    # Lyapunov 候选 V=e^T P e + ||θ-θ_safe||^2/Γ
    # 要求沿轨迹 V_{k+1} <= (1-c) V_k + b，且 Γ<=Γ_max(τ_d)
    return (contraction_rate(theta_hist, e_hist) <= -(cfg.c) and
            gain_bound_ok(theta_hist, tau_d))
```

def evidence_mpc(route, H, M, budgets):

def probe_commit_evolve_motion(x0, M, task, budget, consent, personas, ctrl):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        H = initial_horizon(cp)
        while budget.probes_left > 0:

            Cev = evidence_tube(M, xi, H)
            Vev = evidence_viability_kernel(Cev, X_safe, M)

                shrink_horizon_or_detour(); continue

                if voi_ex(p, M, inf, G) < theta_voi: break

    return sched, log, M

def homotopy_replan(route, M, falsified):
    classes = reachable_homotopy_classes(route.goal, M)
    if not classes:
        return None
    scored = sorted(classes, key=lambda c: (evidence_corr(c, falsified),
                                            risk(c, M)))
    best = scored[0]
    if evidence_corr(best, falsified) >= corr_max:      # 所有类共享可疑证据
        return None                                     # 视为无独立替代
    return plan_in_class(best, M)

def inherit_evidence_across(xi_new, xi_old):
    if same_homotopy(xi_new, xi_old):
        return carry_support(xi_new, xi_old)            # 类内：同一证据源
    return fresh_evidence_required(xi_new)               # 跨类：禁止自动继承

def trajectory_gate(seg, M, personas, ood_reg):
    for s in seg.segments:
        if s.irreversible:
            need = (s.ev == 'EV-probe*' and s.excitation_ok) or \
                   (s.ev == 'EV-margin')
            if not need: return Reject('irreversible_needs_identified_evidence')
            if s.ev == 'EV-xmodal': return Reject('xmodal_on_irreversible')
            if not s.state_in_survival_kernel: return Reject('no_evidence_escape')

            return Reject('segment_evidence')

    if seg.age_weighted_support < theta_support: return Reject('stale_evidence')
    return Ok

def map_evidence_certificate_t(sched, M, log, consent_log, auth_log, ood_reg):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TEC | O(H·\|V\|) + O(\|ξ\|) 联合界 | O(H·\|V\|) | 生存核非空、联合界相关感知（A41） |
| PEX | O(d²·k)/窗口（增量特征值） | O(d²) | λ_min≥λ*、无激励不计证据、CRLB 撑开（A42） |
| RAC | O(d²)/更新 | O(d²) | 投影/死区/泄漏、Γ≤Γ_max(τ_d)、ISS（A43） |
| EMP | O(H²·\|A\|·\|V\|) | O(H·\|V\|) | 端点生存核约束、前缀可重规划、H 步终止 |
| HRP | O(\|classes\|·\|V\|) | O(\|classes\|) | 跨类独立性声明诚实、类内不重复计证（A44） |
| TEG | O(\|ξ\|) | O(\|ξ\|) | 轨迹证据齐、不可逆段禁 xmodal、生存核必检 |

**正确性定理（Motion-Adaptive Evidence Soundness, MAES）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 轨迹证据管保守、联合失效界为相关感知上界（不假设段独立），生存核由保守反向可达计算；**(A42)** 可辨识证书诚实：EV-probe*/EV-margin 仅当 λ_min(G_k)≥λ* ∧ κ_k≤κ_max，否则按 CRLB/鲁棒界撑开，unidentifiable 不得以窄后验承诺；**(A43)** 自适应满足投影/死区/泄漏且 Γ≤Γ_max(τ_d)，证据闭环输入-状态稳定（V̇≤−cV+b）；**(A44)** 同伦类独立性与类间证据相关阵声明保守、类内证据不重复计为独立佐证。则：

1. **轨迹承诺健全性**：任一轨迹前缀承诺的失效率 ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_joint + δ_pe + δ_adapt，其中 δ_joint 来自相关感知联合界，δ_pe 来自可辨识证书漏检（无 PE 却计证据），δ_adapt 来自自适应失稳（A43 下应为 0）。
2. **交互单调性强化**：激励约束、鲁棒自适应、同伦重规划只能经 (a) 校准信念更新（含 CRLB 撑开/鲁棒界）或 (b) 更保守动作（h_c↓、降档、冻结自适应、跨类绕行、安全停）影响系统，不存在升险路径；证据越不激励/自适应越不稳定，系统越保守。
3. **终止性**：EMP 在 H 步内、探针受 λ* 与预算约束；HRP 每轮至少切换到更独立的同伦类或返回协商，跨类数有限 ⇒ 终止于 {前缀承诺, 绕行, 降档, 协商, 安全停}。
4. **部署界**（对承诺前缀取联合界）：

```
P_safe ≥ 1 − Σ_prefix (δ_f + ε_meta(k) + δ_probe + ε_h + δ_joint + δ_pe + δ_adapt)
             − P(𝓜 陈旧未检出) − P(生存核计算失保守) − P(同伦独立性被证伪失败)
             − P(自适应冻结/护盾回退失败)
```

关键：**承诺绑在轨迹与生存核上**（可恢复性成为承诺前提，逐点安全不再能串成全局危险）；**证据绑在激励证书上**（没有持续激励就没有可辨识，窄后验不许冒充证据）；**自适应绑在稳定性证书上**（投影/死区/泄漏/增益-时延界把"快速响应"隔离在稳定裕度内）；三个新机制全部经"信念更准或动作更保守"两个安全通道起作用，且都只能在非不可逆层换取效率。

## 6. 本轮最大风险

**一句话**：本轮为了让"证据更可信"引入了激励与自适应，却可能把系统推入危险的自我强化循环——为了证明参数可辨识而持续扰动、为了让证据快速生效而提高自适应增益，二者都在悄悄透支安全裕度；最大的风险不是证据不够，而是系统"为了获得证据/保持灵敏"而主动把自己探到失稳边缘，因此必须以激励预算硬上限、仅非不可逆层扰动、Γ≤Γ_max(τ_d) 的 ISS 证书、不可辨识即按鲁棒未知处理四道护栏，宁可慢、宁可宽、宁可冻结自适应，也不拿安全换可辨识。
