# 第 44 轮（新循环第 1 轮） · Bimanual-Cert × Certified-Distill：把「双臂协作」与「模型蒸馏」统一为「去中心化残差证书」闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约空集」，但它仍压着两个未言明的单点假设：**(H1) 系统是单体的**——所有证书被默认为一个“单臂、单身体”的联合体，多臂协作要么靠“安全隔离带”粗暴回避，要么假设单臂证书可免费笛卡尔积；**(H2) 蒸馏是无损工程步骤**——IP-44 被当作“压模型、提速度”的部署技巧，学生被默认为自动继承教师的 soundness，从未给出迁移证明。本轮灵感词「双臂协作」「模型蒸馏」精确命中这两个假设：**双臂协作**迫使我们承认证书**不可复合**（两臂各自安全 ≠ 联合安全，且引入死锁这类“安全但无活性”的新失败态）；**模型蒸馏**迫使我们把“容量削减”视为一次**证书迁移**，学生的每个动作都欠教师一笔可量化的“蒸馏税”。二者在架构上并非并列，而是**同构**：一个把集中式联合控制器拆成两条物理臂，一个把大模型拆成两个小模型，都是“去中心化”；于是本轮真正的新问题是——**能否用一个统一的“去中心化残差证书”同时约束物理拆分与神经压缩，并让双臂的冗余反过来为蒸馏误差买单**。

## 0. 直觉与动机

**灵感 1（双臂协作 → 证书不可复合，且安全之外还有活性）**：直觉上，“左臂不撞墙、右臂不撞墙”根本不保证“两臂不互撞”，更不保证协同搬箱子时闭链约束不被撕开。因此单臂证书的笛卡尔积存在一个**复合缺口 Γ**，它只能在**相对空间**（相对位姿、相对速度、扫掠体）与**共享物体接口**（闭链约束残差、内力/摩擦锥）上显式认证。更进一步，双臂引入了 v20 完全没有的维度——**活性**：一个只满足安全不变式的系统可能“双臂互相等待让出”而死锁。死锁不是不安全，而是“安全地停摆”，属于 reach-avoid 框架之外的失败。故双臂证书必须是**安全(H) ∧ 活性(R)** 的对偶证书，R 为严格下降的 ranking function。

**灵感 2（模型蒸馏 → 蒸馏是“借证书”，不是“得证书”）**：直觉上，学生模型再准也可能在长尾处偏离教师一个 δ，而这个 δ 会被闭环动力学放大成状态漂移。因此正确姿势不是“学生继承教师证书”，而是**证书迁移**：教师证书按误差传播界**收缩**后再借给学生，收缩量就是“**蒸馏税** T_D”。由于 T_D 随 horizon T 指数增长，学生天然只适合短时程反应式层，长程规划必须回退教师或查表——这把 v20 的 L0/L1/L2 分层赋予了新的理论依据（每一层允许的蒸馏税不同）。

**灵感 3（耦合 → 去中心化残差证书 DRC，双臂冗余为蒸馏买单）**：把“物理拆分”和“神经拆分”统一为因子化 F: π_mono → ∏_i π_i，每个 F 携带残差 r_F，联合证书 C_F = C_mono ⊖ B(r_F)。关键收益：**交叉臂互验**提供了独立第二视图，能退还一部分保守性（验证红利 V_X）；于是存在一条可优化的**压缩—信任前沿**：τ_net = τ_0 − T_D(压缩比) + V_X(臂间多样性) ≥ 0。压缩越狠，税越高；臂间越异构，红利越大。这把两个灵感词焊成一个标量约束，也解释了为什么“双臂”不只是多一个执行器，而是一种**可验证性的冗余来源**。

**耦合升级**：BCC（双臂协同证书）负责在相对空间/共享物体/交接时序上封闭 Γ 并提供 (H,R)；CDE（持证蒸馏引擎）负责把教师证书按蒸馏税迁移给学生并做 OOD 门控与教师回退；XCV（交叉臂一致性验证器）负责用互验红利与共同模式残差把“去中心化”拉回可信。四层架构由 v8 的「仿真-检索-边缘飞轮 + 人格契约 + 并发证书」升级为 v9 的「**+ 双臂协同层 + 持证蒸馏层 + 去中心化残差闭环**」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（双臂联合证书与非复合性）**：单臂状态 x_i∈X_i，联合状态 z=(x_1,x_2,x_o)∈Z（x_o 为共享物体）。单臂证书 C_i⊆X_i 仅保证本臂动力学可行与静态避障。双臂联合安全谓词至少含三类：**(a) 自碰撞** d(x_1,x_2)≥d_safe（含连杆扫掠体）；**(b) 闭链约束** g(x_1,x_2,x_o)=0（协同搬运时两臂与物体构成闭链）；**(c) 内力可行** f_int∈ℱ_int（摩擦锥与物体刚性）。联合证书 C_12={z∈Z : 满足 (a)(b)(c) 且存在联合策略}。**非复合性命题**：一般地 C_1×C_2 ⊄ C_12，即单臂各自 sound 不蕴含联合 sound；复合缺口 Γ=(C_1×C_2)\C_12 只能通过相对空间与共享物体力旋量上的**接口证书** I_12 封闭。**推论**：双臂 soundness 不能由单臂证书的笛卡尔积免费得到，Γ 的大小正是双臂协调保守性的来源，也是必须被显式认证、不能默认的量。

**定义 45（交接证书与安全-活性对偶）**：交接是时间参数化的抓取权转移。窗口 [t_s,t_e] 内的**交接不变式** H：至少一只手抓取力 f_g≥f_safe，物体位姿不确定度 σ_o≤σ_max，两臂相对速度受限。仅 H 不足以保证完成，需**活性**：存在 ranking function R(z)（剩余交接步数/势能），使每步 R 严格下降且永不进入死锁集 D。**安全-活性对偶命题**：满足 H 的实现仍可能死锁（双臂互相等待让出），故双臂证书必须是二元组 (H,R)；**死锁是安全的活性失败**，v20 的纯 reach-avoid 框架无法表达，必须外挂协调自动机与 ranking 检查。**推论**：任何“只报告 unsafe=0”的双臂评测都会系统性漏掉死锁，E96 因此专设活性红线。

**定义 46（持证蒸馏与蒸馏税）**：教师 π_T:Z→A 为集中式双臂策略（高容量、慢、权威），学生 π_S=(π_S^1,π_S^2) 为去中心化单臂策略（快、仅本地观测 o_i）。在认证域 D 上定义动作偏差 δ_D=sup_{z∈D}‖π_T(z)−(π_S^1(o_1),π_S^2(o_2))‖。设闭环动力学为 L-Lipschitz，则 horizon T 内状态偏差满足 ε_state(T)≤((e^{LT}−1)/L)·δ_D。**证书迁移引理**：教师边际 m_T 可迁移为学生边际 m_S(x)=m_T(x)−L_m·ε_state(T)；仅当 m_S≥θ 处允许学生单独接管。**蒸馏税** T_D=L_m·ε_state(T)。**注**：T_D 随 T 指数增长 ⟹ 学生只适合短 horizon 反应式层；长程规划仍须教师/查表。这是“学生不是继承证书，而是按税借证书”的形式化。

**定义 47（共形蒸馏界与支持域门控）**：δ_D 依赖分布，无法在全体 D 上一致估计。用（状态簇 × 任务）分层共形（Mondrian）校准动作偏差，得 δ_α 使 P(‖π_T−π_S‖≤δ_α)≥1−α。**支持域门控**：学生仅在共形校准覆盖的区域内被信任；以 OOD 分数 s_oood(z) 门控，s_oood>η 时强制教师回退。**引理**：若门控无假阴性（OOD 必被检出）且区域条件覆盖有效，则支持域内满足定义 46 的证书迁移；否则迁移失效。**风险**：共形仍只保边际覆盖（与 v20 同源），必须按状态簇分层并在线检测漂移，否则 δ_α 会被尾部样本系统性低估。

**定义 48（交叉臂互验与验证红利）**：两臂对同一联合谓词 φ（相对位姿/碰撞间隙/物体力旋量）独立估计 φ̂_1,φ̂_2，分歧 d_x=‖φ̂_1−φ̂_2‖。若 d_x≤η_x 则互证通过，可**退还**一部分证书保守性（验证红利 V_X）；若 d_x>η_x 判故障并回退。**故障容错定理**：若 (i) 至少一臂的计算 sound（1-of-2 冗余），(ii) 分歧检测器无假阴性，(iii) 两臂故障独立，则系统整体 sound，即使另一臂的蒸馏模型任意错误。**共同模式命题**：若故障相关（共享传感器/训练数据/网络权重），检测器可能同时沉默，前提 (iii) 失效——故必须认证**臂间多样性**（不同模态、不同蒸馏种子/架构），并把共同模式残差 r_cm 直接并入证书收缩。**注**：这条既给出双臂的“验证红利”，也划出它的失效边界：红利只对独立故障兑付。

**定义 49（去中心化证书一致性与延迟租约）**：两臂各自运行学生与本地守卫，经总线交换**空间责任区** claim 与租约。臂 i 声明责任区 S_i(t)，其 guarantee G_i：「在租约有效期内不进入 S_j\S_i」。通信延迟上界 Δ_comm。**一致性定理**：若 (a) 每条消息携带单调时钟与租约；(b) 延迟>Δ_comm 时接收方立即收缩到本地保守集（不信任旧 claim）；(c) 声明区以 seqlock/epoch 前后一致，则任意交错下联合不变式保持。**推论**：去中心化无需全局锁，只需「责任区 + 延迟租约」这一可静态审计的局部契约；它与 v20 定义 40/41 的 rely-guarantee + 租约同构，只是从“任务维度”扩到“空间 + 跨臂时钟维度”。

**定义 50（去中心化残差证书 DRC，统一物理与神经拆分）**：将“物理去中心化”（单臂拆分）与“神经去中心化”（蒸馏压缩）统一为因子化 F:π_mono→∏_i π_i，每个因子化携带残差 r_F。联合证书 C_F=C_mono ⊖ B(r_F)，B 为由 Lipschitz/通信延迟/共形界诱导的收缩球。**可靠性命题**：若每个因子在其责任域内保持 rely-guarantee，且残差界 r_F sound，则 C_F 在任意交错下 sound。**统一权衡**：压缩比 ρ↑ ⟹ 蒸馏残差↑（税 T_D）；臂间多样性↑ ⟹ 可容忍残差↑（红利 V_X）；可行部署的充要约束为 τ_net = τ_0 − T_D(ρ) + V_X(diversity) ≥ 0 且 (H,R) 可满足。**这条把本轮两个灵感词焊接为一个可优化标量约束，也是 v9 的理论内核。**

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 BIMANUAL-COORDINATION-CERTIFICATE（双臂协同证书引擎 BCC）
1. **联合/相对证书**：显式认证自碰撞、闭链残差、内力可行域，输出复合缺口 Γ，绝不默认 C_1×C_2 安全。
2. **交接 (H,R) 证书**：交接不变式 + 严格下降 ranking function，死锁集 D 进红线。
3. **角色契约**：领导/跟随、交接方向、让步优先级编译为守卫谓词（复用 IP-57 契约与最小让步协商）。
4. **协调自动机**：approach→grasp→transfer→release 的状态机，与 IP-47 组合代数对接，状态迁移带 Γ/活性检查。

### 2.2 IP-61 CERTIFIED-DISTILLATION-ENGINE（持证蒸馏引擎 CDE）
1. **证书迁移**：按定义 46 计算蒸馏税 T_D 并收缩教师证书，只在 m_S≥θ 区域放行学生。
2. **共形蒸馏界**：Mondrian 分层校准 δ_α，输出按状态簇的误差界并做在线漂移检测。
3. **支持域门控与教师回退**：OOD 分数门控，长 horizon/通信超界/分歧/漂移一律回退权威教师。
4. **压缩—信任前沿优化**：在 τ_net≥0 约束下最大化压缩比，输出 (ρ*, 预期税/红利) 供部署决策。

### 2.3 IP-62 CROSS-ARM-CONSISTENCY-VALIDATOR（交叉臂一致性验证器 XCV）
1. **交叉臂互验**：同一谓词双估计、分歧阈值、验证红利结算，并做红利封顶（不得超过教师边际的 β 倍，防“互验放大保守性”）。
2. **共同模式审计**：量化臂间多样性（传感器模态/蒸馏种子/架构/数据切片），估计 r_cm 并并入证书收缩。
3. **通信-延迟 fuzz**：注入延迟/丢包/时钟漂移，验证定义 49 的收缩回退与线性一致性。
4. **故障注入**：单臂学生投毒/传感器偏移，检验 1-of-2 容错定理的边界（独立 vs 相关故障）。

### IP-61 CDE：证书迁移、蒸馏税与支持域门控

def distillation_tax(delta_D, L, T, L_m):
    eps_state = ((exp(L*T) - 1) / L) * delta_D       # Grönwall 型传播界
    return L_m * eps_state                           # 随 horizon T 指数增长

def certified_distill(teacher, student, D, alpha):
    delta_alpha = conformal_action_gap(teacher, student, D, alpha)  # Mondrian 分层
    tax  = distillation_tax(delta_alpha, L, T, L_m)
    C_S  = shrink(teacher.certificate, tax)          # 证书迁移引理：借而非继承
    gate = ood_gate(student.support)                 # 支持域门控

def student_takeover(x, C_S, gate, theta):
    if not gate.in_support(x):        return TeacherFallback()   # OOD 回退
    if C_S.margin(x) < theta:         return TeacherFallback()   # 税后不可行
    return StudentAction(student.policy(x))          # 仅短 horizon 反应式层

### IP-62 XCV：交叉臂互验、共同模式与延迟租约

def cross_arm_verify(phi1_hat, phi2_hat, eta_x, teacher_margin, beta):
    d = norm(phi1_hat - phi2_hat)
    if d <= eta_x:
        V = min(beta * teacher_margin, dividend(d))   # 红利封顶，防放大保守性
        return Verified(V)
    return Fault(d)                                   # 分歧 → 回退教师/停机

def common_mode_residual(arms):
    # 多样性：传感器模态、蒸馏种子、架构、训练数据切片
    div = diversity_score(arms)                       # 越低越危险
    return r_cm(div)                                  # 直接并入证书收缩

def decentralized_claim(arm_i, t, lease, Delta_comm):
    if lease.expired(t) or lease.delay > Delta_comm:
        return local_conservative_set(arm_i)          # 超界即收缩，不信旧 claim
    return arm_i.claim                                # 责任区 + 单调时钟租约

def car_transition_guard_v9(e, x1, x2, xo, teacher_cert, student_cert,
