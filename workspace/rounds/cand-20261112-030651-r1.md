# 第 58 轮（承接第 57 轮「元少样本×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 4 轮；本轮灵感：「模型蒸馏」×「世界模型」）

> 第 57 轮把安全的赌注从"手工先验"换到"跨区域摊销的元先验 + 共形保底"，并让证据按模态分账、让人从常量变成单向信任状态机；它自陈的最大风险是"坏先验普遍"——元模型在语料盲区里高度自信。但第 57 轮的整套论证还隐含了一个更强、更危险的前提：**决策所依据的模型与证据，始终是"本地、当前、原始"的那一份**。真实部署几乎从不如此：边缘端跑的是从云端大模型**蒸馏**下来的小模型，规划用的是**世界模型**想象出来的未来，而不是每次都用真实探针去问世界。蒸馏和世界模型是让机器人"跑得动、算得起"的两根支柱，却恰恰是第 57 轮安全论证没有覆盖的两条**证据压缩通道**：蒸馏压缩"模型"，世界模型压缩"经验"。二者都把一个已经被取证的大家伙，替换成一个更便宜、更快、但分布更窄的替身，然后默认"证书会跟着一起搬过去"。本轮的核心判断是：**证书不是模型的属性，而是（模型 × 输入管线 × 部署分布 × 校准集）的属性；一旦压缩，证书即失效，必须再取证**。于是把命题从"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"压缩不失证、想象不入证、蒸馏可再证的证据说可信"**。

核心矛盾：
- **H29（蒸馏 vs 校准/能力）**：蒸馏保的是"老师在这些题上的答案"，不是"老师不会做哪些题"；软标签里的暗知识不含"我不知道"。学生可以在教师高熵/OOD 处给出低熵输出，比教师更自信；教师的 OOD 门与共形覆盖不随权重迁移。压缩越狠，抄来的证书越假。
- **H30（世界模型 vs 模型利用）**：规划器越强，越会往世界模型误差的缝里钻——想象里最优的轨迹，常常正是现实中最危险的轨迹。误差随 horizon 复合，且用自身想象再训练会让尾部逐代消失（想象自噬/model collapse）；"想象中成功"与"现实中安全"之间没有必然通道。
- **H31（再取证 vs 部署经济）**：每蒸馏一次、每换一版世界模型都要重新取证，成本可能吃掉压缩的收益；于是工程上最诱人的捷径是"把老师的证书贴到学生身上"——**证书洗白**。而"再取证"本身也是一个由人/脚本执行的判定器，谁来验证它诚实？

## 0. 直觉与动机

**灵感 1（模型蒸馏 → 压缩的是函数，不是"我知道/我不知道"）**
直觉：把一个在云端被反复验证过的大模型压成边缘小模型，看起来像"把已验证的能力装进口袋"。但蒸馏的监督信号是教师的**输出**，不是教师的**证据与犹豫**：教师对某个新材质其实也没把握，只是它的 softmax 被温度抹平后看起来"有分布"；学生学到的是被抹平后的自信，甚至因为容量小而把"高熵"硬压成"某一类"。安全最需要的不是"老师答过什么"，而是"老师在哪儿会拒答"——这恰好是蒸馏损失里最容易被优化掉的部分。故本轮把蒸馏降级为**提案/加速通道**：学生必须重新声明自己的校准、OOD 召回与拒答边界（能力边界损失），证书不随权重迁移；不能自带证书的学生，至多 L0。

**灵感 2（世界模型 → 想象是提案，不是证据）**
直觉：世界模型让机器人"先在脑子里走一遍"，省下大量真实探针。但基于模型的规划有一个反直觉的恶性循环：**模型越好用，规划器越会利用模型的系统性偏差**——它找到的不是"现实中最好的路"，而是"模型误差最大的缝里、恰好显得最好的路"。就像奖励黑客，只不过被黑的是世界模型本身。故本轮引入**悲观想象**（集成/分位数下的最坏值）与**计划级乐观差** OG：若一条计划在想象中远好于最近的任何真实经历，它不是"新发现"，而是"模型外推"，必须降级为探针或绕行。世界模型只能回答"先试哪个"，永远不能回答"可以承诺"——**想象不入证（INE）**。

**灵感 3（想象自噬 → 世界模型吃自己的梦会失尾）**
直觉：世界模型最省钱的训练方式，是拿自己的想象当数据再训练（自举）。这会形成回声室：模型只在自己会生成的分布上越来越准，真实世界里罕见但致命的尾部（薄冰、松动的碎石、异常反光）被一代代"梦"抹平。模型不是变笨，而是变**窄**——置信越来越高、覆盖越来越小。蒸馏会放大同一问题：学生只见到教师采样出的分布。故本轮给出**真实锚点配额**与**自噬界**：每代再训练必须混入 α≥α_min 的真实探针，尾部覆盖 c_tail≥c_min；否则判"回声室"，冻结自训练并按代衰减其证据权重。

**灵感 4（证书绑定 → 证书不可免费传递）**
直觉：工业界把"在 A 上验证通过"当成"在 B 上也成立"是常态，但统计证书的成立条件比签名苛刻得多：它绑定的是具体权重、具体输入管线、具体部署分布、具体校准集。换任何一个，旧的 ECE/共形覆盖都可能瞬间失真。于是本轮把证书做成**四元绑定** bind=(weights,input_pipeline,𝒟_cal,σ_S)，蒸馏/量化/换传感器即刻吊销；再取证门 DRC 要求在本地探针流上以影子模式重跑 ECE、OOD 召回、共形覆盖，且只允许学生"更保守"（拒答集合是教师的超集）。任何"证书迁移"声明都必须附再取证日志，否则视为洗白。

**灵感 5（双灵感合流 + PCE-WM → 用想象选探针，而不是用想象免探针）**
直觉：世界模型的正确用法不是"替代真实探针"，而是"**决定下一个真实探针打在哪**"——在悲观模型下计算哪个探针最能消解当前决策的不确定性，然后**真的去打它**。蒸馏的正确用法不是"继承证据特权"，而是"更快地给出提案、更省算力地跑影子模式"。二者都只走效率通道：世界模型经"选探针/选绕行"降低探询成本，蒸馏经"降算力/降时延"降低提案成本；任何承诺仍必须过真实证据门与再取证门。这延续并再次收窄第 57 轮的交互单调性——**压缩与想象可以让系统更便宜，永远不能让系统更敢赌**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（证书保持蒸馏 CPD）** 教师 T 持证书 J_T=(ECE_T,OOD_recall_T,cov_T,supp_T)，学生 S=Distill(T;𝒟_dis)。蒸馏证书 J_dis=(ΔECE,ΔOOD,Δcov,supp_overlap,abstain_quality,α)。四条约束：(i) **特权不可继承**——S 不得复用 J_T 的任何证据资格，须在本地边端流上独立声明 ECE_S(k)≤ε_meta(k)、OOD_recall_S≥1−δ_ood、共形覆盖≥1−α_conf；(ii) **能力边界损失** L_boundary 惩罚"教师在 x 上熵高或 OOD 分高、而学生仍低熵输出"的情形，迫使学生学会拒答；(iii) **暗知识仅限支撑内**——软标签只在 supp_T 内有监督效力，支撑外视为无标签；(iv) J_dis 不过 ⇒ S 至多 L0/提案。

**定义 140（回声室与想象自噬守卫 EAG）** 蒸馏/自训练语料 𝒟=α·𝒟_real+(1−α)·𝒟_gen，真实锚点比例 α，尾部覆盖 c_tail。生成支撑差 G_supp=W_1(𝒟_real^{test},𝒟_gen)（或尾部覆盖亏损）。自噬界：反复以自身生成数据再训练 n 代，有效支撑 supp_n≤supp_0·(1−λ)^n，λ 由每代尾部丢失率估计。部署约束：每代 α≥α_min 且 c_tail≥c_min；否则判"回声室"，冻结自训练、按 (1−α)^n 衰减其证据权重并强制补真实探针。

**定义 141（悲观世界模型与模型利用防护 PWM）** 世界模型 M_w:(s,a)→(ŝ',r̂,σ_w)，σ_w 由集成 {M_w^i} 或分位数头给出。悲观值 Q_pess(s,a)=r̂−β·σ_w+γ·min_i V_i(ŝ_i')（或 CVaR_α）。计划级乐观差 OG(π)=Ŝ(π)−max_{e∈𝒩_real(π)} S_real(e)，𝒩_real(π) 为真实经历中与 π 最近的计划。规则：(R1) 只在悲观值下规划；(R2) OG(π)>θ_og ⇒ 计划级 OOD，禁止承诺，转探针/绕行；(R3) M_w 只能产生提案集，承诺谓词不得读取 M_w——**想象不入证 INE**。

**定义 142（想象-现实对账 IRE）** 每次真实执行 π 记录 (ŷ,y,σ_w,e=|y−ŷ|/scale)。若 e>θ_res 或违反预测约束 ⇒ 模型证伪事件，回溯降低该区域/该模式的模型信任 τ_M、放大 σ_w、写入 model_falsified 注册表；连续证实则有界恢复。EV-imagine 永不进入不可逆证据集；只有真实执行产生 EV-real。

**定义 143（蒸馏再取证门 DRC）** 证书绑定 bind(cert)=(hash(weights),hash(input_pipeline),𝒟_cal,σ_S)。蒸馏/量化/换管线/换场景 ⇒ 旧证书自动吊销。DRC 要求：①影子模式在本地流运行≥N_shadow；②ECE_S≤ε_meta(k) 且不劣于教师 δ_ece；③OOD 召回不降、共形覆盖≥1−α_conf；④**保守性**——学生拒答集合 ⊇ 教师拒答集合，或同等输入上学生动作更保守。防洗白：证书哈希绑定权重与数据指纹，复制/改写即校验失败；证书迁移声明须附再取证日志。

**定义 144（PCE-WM 算子）** 每检查点：①MFSL 元推断（ID→摊销后验/OOD→共形带）；②世界模型悲观规划并算 OG(π)；③若 OG>θ_og 或 σ_w 高，选"最能降低模型不确定性的**真实**探针"（VOI 用悲观模型估计，执行的是真探针，预算 k_wm）；④跨模态对账；⑤过真实证据门 FSE+/DRC；⑥承诺 ⇔ ∃g:R≤δ_f(g) ∧ 证据门过；否则绕行→降档→L2 协商或安全停。蒸馏只用于更快提案/更低算力，失败则回退云端教师或第 57 轮保守路径。

## 2. 关键算法伪代码（完整版见产物区）

```python
def distill_with_boundary(T, D_dis, local_stream):      # IP-139/143
    S = distill(T, D_dis, loss=task + lam * L_boundary(T, S))
    J = recertify(S, local_stream)                      # 独立再取证，不继承 J_T
    return S, J                                         # 无 J 则 S 仅可提案

def pessimistic_plan(Mw, s, real_nb):                   # IP-141
    pi = argmax_a [r_hat - beta * sigma_w + gamma * min_i V_i(s')]
    OG = S_hat(pi) - max(S_real(e) for e in real_nb(pi))
    return pi, ('plan_ood' if OG > theta_og else 'ok')

def reconcile(pi, y_hat, y, Mw, reg):                   # IP-142
    if abs(y - y_hat) / scale > theta_res:
        Mw.tau[pi.region] *= gamma_down; Mw.sigma[pi.region] *= gamma_up
        reg.flag(pi.region)                             # 模型证伪，回溯降权

def pce_wm(x0, M, task, budget, personas):              # IP-144
    for cp in route.checkpoints:
        inf = meta_infer(M, cp.region)
        pi, st = pessimistic_plan(Mw, cp, real_neighbors(cp))
        if st == 'plan_ood':                            # 想象外推 → 只许真探针
            p = argmax_probe(VOI_wm_pessimistic, M, inf)
            M, _, D = xmodal_fuse(M, cp.region, real_execute(p))
        if odd_gate(inf, M, D) or not recert_ok(S, DRC):
            continue_to_probe_or_reroute()
        if evidence_gate_real(M, cp) == 'ok':
            commit(); continue
        else:
            reroute_or_negotiate(cp, personas)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CPD | 训练 O(E·d_T)；推理 O(d_S) | O(\|S\|) | 能力边界拒答、特权不继承 |
| EAG | O(1) 记账；周期 O(N) | O(锚点集) | α≥α_min、c_tail≥c_min、自噬界 |
| PWM | 规划 O(H·\|A\|·K) | O(K·\|s\|) | 集合覆盖真模型、计划级 OOD |
| IRE | O(1)/执行 | O(\|V\|) | 残差诚实、回溯完整 |
| DRC | O(N_shadow·d_S) | O(\|𝒟_cal\|) | 四元绑定、保守性、防洗白 |
| PCE-WM | O(\|CP\|·(k_p+k_c+k_w)·(C_VOI+H·\|A\|·K)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 悲观 VOI、k_p+k_c+k_w 终止 |

**正确性定理（CPWS 概要）**：在 A33–A40 上加 (A41) 蒸馏证书诚实且经 DRC 独立重建（ECE/OOD/覆盖达标、保守性成立）；(A42) 悲观覆盖——真模型以 ≥1−β 概率落在集成/分位数集合内，且计划级 OOD 漏检 ≤δ_og；(A43) 真实锚点配额 α≥α_min、尾部覆盖 c_tail≥c_min（自噬界可控）；(A44) IRE 残差与模型证伪记录诚实。则：
(i) 部署失效率 P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_dis·1[用蒸馏学生]+δ_wm·1[用世界模型]+δ_og；
(ii) 交互单调性再次收窄：蒸馏只减权限（拒答集合只增），世界模型只提案（承诺谓词不读 M_w），想象只用于选真实探针、永不入证；三个新机制不存在升险路径；
(iii) 终止性：每检查点真实探针 ≤k_probes+k_cons+k_wm，PCE-WM 终止于 {承诺, 绕行, L2 协商, 安全停}；
(iv) 自噬界：α≥α_min 时 supp_n≤supp_0·(1−λ)^n，λ 有上界；回声室一旦检出即冻结自训练。

## 6. 本轮最大风险

**一句话**：本轮把"效率"交给两条有损压缩通道——蒸馏压缩模型、世界模型压缩经验——而压缩最危险之处在于**它让系统同时更便宜、更自信、更窄**：一旦再取证被跳过或真实锚点配额被侵蚀，学生会与教师共享盲区却显得校准良好，悲观规划也仍在同一个模型误差盆地内寻优，于是系统在它不再探的尾部上"又省又准又瞎"；必须以四元证书绑定、真实锚点配额与"想象永不入证"三重护栏，宁可退回又慢又贵的云端教师/真实探针，绝不让压缩后的替身继承它没有挣来的证书。

### IP-139 CPD（证书保持蒸馏，含能力边界）

```python
def certificate_preserving_distill(T, D_dis, local_stream, cfg):
    def boundary_loss(student, x):
        with torch.no_grad():
            pT, uT = teacher_probs(T, x), teacher_uncertainty(T, x)
        uncertain = (uT > cfg.theta_ent) | (teacher_ood_score(T, x) > cfg.theta_ood_T)
        # 教师不确定处，学生若仍低熵输出则惩罚；鼓励学会 abstain
        return cfg.lam * masked_kl(student, pT, mask=~uncertain) \
             + cfg.lam_b * masked_conf_penalty(student, uncertain)
    S = train_student(D_dis, loss=task_loss + boundary_loss)
    # 暗知识只在教师支撑内有监督效力
    S = reject_out_of_support_softlabels(S, T.support)
    J_dis = recertify(S, local_stream, teacher=T)   # IP-143，绝不复制 J_T
    return S, J_dis

def usable_for_commit(S, J_dis):
    return J_dis.passed                       # 否则仅 L0 / 提案
```

### IP-140 EAG（回声室与想象自噬守卫）

```python
def echo_autophagy_guard(D_real, D_gen, gen, cfg, audit):
    alpha = share_real(D_real, D_gen)
    c_tail = tail_coverage(D_real.test_tails, D_gen)
    G_supp = wasserstein(D_real.test, D_gen)
    supp_bound = cfg.supp0 * (1 - cfg.lam_gen) ** gen
    if alpha < cfg.alpha_min or c_tail < cfg.c_tail_min or G_supp > cfg.theta_supp:
        audit.flag('echo_chamber', gen, alpha, c_tail, G_supp)
        return Guard(freeze_selftrain=True,
                     evidence_weight=(1 - alpha) ** gen)   # 只减不增
    require_real_anchor(D_real, quota=cfg.alpha_min)          # 强制补真实探针
    return Guard(freeze_selftrain=False, evidence_weight=1.0,
                 supp_bound=supp_bound)
```

### IP-141 PWM（悲观世界模型与模型利用防护）

```python
def pessimistic_plan(Mw, s0, real_nb, cfg):
    best, best_q = None, -inf
    for a in admissible_actions(s0):
        for Mwi in Mw.ensemble:
            shat, rhat, sig = Mwi.rollout(s0, a, H=cfg.H)
            q = rhat - cfg.beta * sig + cfg.gamma * min_i(Mw.value_i(shat))
        if q > best_q:
            best, best_q = a, q
    OG = S_hat(best) - max(S_real(e) for e in real_nb(best))
    if OG > cfg.theta_og:
        return best, 'plan_ood', OG      # 想象外推：只许真实探针/绕行
    return best, 'ok', OG

def commitment_may_read_world_model():
    return False                          # INE：承诺谓词禁止读取 M_w
```

### IP-142 IRE（想象-现实对账）

```python
def imagination_reality_reconcile(pi, y_hat, y, Mw, reg, cfg):
    e = abs(y - y_hat) / cfg.scale
    if e > cfg.theta_res or violates_predicted_constraint(pi, y):
        Mw.tau[pi.region] = max(cfg.tau_min, Mw.tau[pi.region] * cfg.gamma_down)
        Mw.sigma[pi.region] = min(cfg.sigma_max, Mw.sigma[pi.region] * cfg.gamma_up)
        reg.flag(pi.region, 'model_falsified', e)
        reg.retro_deweight(pi.region, source='imagination')
    else:
        Mw.tau[pi.region] = min(1.0, Mw.tau[pi.region] + cfg.gamma_up_tau)
    # 记录 EV-real；EV-imagine 永远不进入证据集
    return 'EV-real'
```

### IP-143 DRC（蒸馏再取证门，含防洗白）

```python
def recertify(S, local_stream, teacher, cfg):
    run_shadow(S, local_stream, steps=cfg.N_shadow)
    ece = local_ece(S, local_stream)
    ood = local_ood_recall(S, local_stream)
    cov = local_conformal_coverage(S, local_stream)
    conservative = abstain_set(S).issuperset(abstain_set(teacher)) or \
                   all(action_conservatism(S, x) >= 0 for x in local_stream)
    if ece > cfg.eps_meta or ece - teacher.ece > cfg.delta_ece:  return Fail('ece')
    if ood < 1 - cfg.delta_ood or cov < 1 - cfg.alpha_conf:      return Fail('coverage')
    if not conservative:                                         return Fail('not_conservative')
    return Cert(bind=(hash(S.W), hash(S.pipe), local_stream.cal_ids, S.sigma_S),
                ece=ece, ood=ood, cov=cov, shadow_log=cfg.shadow_log)

def verify_bind(cert, S, pipeline, D_cal, sigma_S):
    # 四元绑定任一不符 ⇒ 证书失效；复制教师证书/改哈希即校验失败
    return cert.bind == (hash(S.W), hash(pipeline), D_cal, sigma_S)
```

### IP-144 PCE-WM（想象选探针，真实门承诺）

```python
def pce_wm(x0, M, task, budget, personas, S, J_dis, DRC):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)   # IP-133
        pi, st, OG = pessimistic_plan(Mw, cp.state, real_neighbors(M, cp), cfg)
        if st == 'plan_ood' and budget.wm_left > 0:
            p = argmax(admissible_probes(cp, M),
                       key=lambda q: voi_wm_pessimistic(q, M, inf, pi) - cost(q))
            if voi_wm_pessimistic(p, M, inf, pi) >= theta_voi:
                obs = real_execute(p)                      # 真的去打，不用想象替代
                M, _, D = xmodal_fuse(M, cp.region, obs)
                imagination_reality_reconcile(pi, pi.y_hat, obs.y, Mw, reg, cfg)
                budget.spend_wm(p)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)        # A34 继承：非破坏性
            if not cands: break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, real_execute(p))
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        g = select_gait(R); lv = contact_level(cp)
        # 承诺必须过：真实证据门 ∧ 蒸馏再取证 ∧ 非计划级 OOD
        if g != 'halt' and st != 'plan_ood' and usable_for_commit(S, J_dis) \
           and few_shot_evidence_gate(core_contact(cp), M, personas, ood_reg)[0] == 'ok' \
           and DRC.verify_bind(J_dis.cert, S, S.pipe, M.cal_ids, M.sigma_S):
            sched.append(commit(sigma, g)); log.append(tag_evidence_real(sigma, M, lv)); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M

def tag_evidence_real(sigma, M, lv):
    # EV-imagine 永不入证；只有 real_execute 产生的观测可记 EV-probe*/EV-xmodal/EV-margin
    return evidence_from_real_observations(sigma, M, lv)
```

### IP-137→FSE-C（证据门纳入蒸馏证书与想象禁入）

```python
def few_shot_evidence_gate_c(c, M, persona, ood_reg, J_dis, DRC):
    if c.ev == 'EV-imagine':
        return ('reject', 'imagination_not_evidence', c)      # 硬禁令（INE）
    if c.ev == 'EV-distill':
        ok = J_dis.passed and DRC.verify_bind(J_dis.cert, c.S, c.pipe, M.cal_ids, M.sigma_S)
        if not ok: return ('reject', 'distill_cert_invalid', c)
    base = few_shot_evidence_gate(c, M, persona, ood_reg)     # 第 57 轮五类判定
    if base[0] != 'ok': return base
    if c.irreversible and c.ev in ('EV-xmodal', 'EV-distill'):
        return ('reject', 'compressed_evidence_on_irreversible', c)  # 硬禁令
    return base
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPD | 训练 O(E·d_T)；推理 O(d_S) | O(\|S\|) | 能力边界拒答、特权不继承（A41） |
| EAG | O(1) 记账；周期 O(N) | O(锚点集) | α≥α_min、c_tail≥c_min、自噬界（A43） |
| PWM | 规划 O(H·\|A\|·K) | O(K·\|s\|) | 悲观覆盖、计划级 OOD（A42） |
| IRE | O(1)/执行 | O(\|V\|) | 残差诚实、回溯完整（A44） |
| DRC | O(N_shadow·d_S) | O(\|𝒟_cal\|) | 四元绑定、保守性、防洗白（A41） |
| PCE-WM | O(\|CP\|·(k_p+k_c+k_w)·(C_VOI+H·\|A\|·K)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 悲观 VOI、有限探针终止 |

**正确性定理（CPWS: Certificate-Preserving World-model Soundness）**
假设 A22–A40（第 53–57 轮）成立；**(A41)** 蒸馏证书诚实且经 DRC 独立重建：ECE_S≤ε_meta(k)、OOD 召回与共形覆盖达标、保守性成立（学生拒答集 ⊇ 教师拒答集），且证书四元绑定不可伪造；**(A42)** 悲观覆盖：真模型以 ≥1−β 概率落在集成/分位数集合内，计划级 OOD 漏检率 ≤δ_og；**(A43)** 真实锚点配额：每代 α≥α_min、c_tail≥c_min，自噬界 supp_n≤supp_0(1−λ)^n 且 λ 有上界；**(A44)** IRE 残差与模型证伪记录诚实。则：

1. **压缩后承诺健全性**：部署失效率
   `P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_dis·1[用S] + δ_wm·1[用M_w] + δ_og`
   其中 δ_dis 只在 J_dis 通过后计入，δ_wm 只在世界模型参与提案时计入；EV-imagine 贡献恒为 0（不入证）。
2. **交互单调性再次收窄**：蒸馏只经"减少证据特权 / 增大拒答集 / 更保守动作"影响系统；世界模型只经"选择真实探针 / 选择绕行"降低探询成本；承诺谓词禁止读取 M_w。三个新机制**不存在升险路径**——压缩与想象只能让系统更便宜，不能让它更敢赌。
3. **终止性**：每检查点真实探针 ≤k_probes+k_cons+k_wm，PCE-WM 必终止于 {承诺, 绕行, L2 协商, 安全停}。
4. **自噬可控性**：α≥α_min 时有效支撑衰减有界，回声室一旦被 EAG 检出即冻结自训练并把证据权重按 (1−α)^n 衰减。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                   + δ_dis·1[S] + δ_wm·1[M_w] + δ_og)
             − P(证书洗白未检出) − P(回声室未检出) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**证书绑定而非传递**（压缩即吊销，DRC 再取证）；**世界模型只提案**（想象选探针，绝不入证）；**自举必须有真实锚点**（否则冻结并降权）。三者把第 57 轮"效率与安全解耦"从"元先验/共形"推广到"压缩/想象"。

## 6. 本轮最大风险

**一句话**：本轮把效率交给两条有损压缩通道——蒸馏压缩模型、世界模型压缩经验——压缩最危险之处在于它让系统同时更便宜、更自信、更窄：若再取证被跳过或真实锚点配额被侵蚀，学生会与教师共享盲区却显得校准良好，悲观规划仍在同一模型误差盆地内寻优，系统便在它不再探的尾部上"又省又准又瞎"；必须以四元证书绑定、真实锚点配额与"想象永不入证"三重护栏，宁可退回又慢又贵的云端教师/真实探针，绝不让压缩后的替身继承它没有挣来的证书。
