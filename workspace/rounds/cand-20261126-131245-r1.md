研究循环·新灵感三元组第 1 轮；本轮灵感：「抗干扰」×「可用性评估」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23（IP-431–439：HDL/ACSC/DCSC/HPC-E/CFC++/CESC/FSVC/IPAM/HPC-E+；其上承 v22 分层义务与能量、v21 语义-规范层、v20 联邦感知证书、v19 DCM/OGCC/CCV/DRS/OGC 与 v17 感知链 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**干扰不是噪声而是状态；可用性是目标而不是约束；安全永远不可被可用性交换**。不推倒 v23：HPC-E+/CESC/FSVC/IPAM/CFC+++/HDL/ACSC/DCSC 全部保留。本轮只做一件事：**给 v23 的证书链补上它一直默认成立、却会在现实中同时被打破的两个前提——模态/样本的"独立性"，以及"安全即可用"——即加一层"共模干扰状态层 + 非侵入可用性评估层"，并顺手封堵 v23 最大风险（版本-覆盖共振崩塌）的物理成因**。

## 0. 直觉与动机

**灵感 1（抗干扰 → 共模干扰击穿的是"独立性"，不是"精度"）**
直觉：v23 的证书链有三处隐形的"独立/可交换"假设：CFC+++ 的模态配额假设各模态独立投票；conformal 与 FSVC 的覆盖保证假设校准样本与测试样本可交换；Hoeffding 界假设样本独立。现实中的干扰恰恰是**共模 (common-mode)** 的：同一束阳光、同一场雨雾、同一段电磁噪声、同频段通信拥塞、甚至同一片遮挡，会**同时**打击多个模态、多台机器人。共模干扰不会让票数变多，反而制造"假独立的一致票"：三台被同一束激光致盲的相机，会一致地报告"覆盖区内无人"。这正是 v23 最大风险（版本-覆盖共振崩塌）的物理化身——不是每个通道各自坏，而是它们**一起错**。
严谨化：引入干扰状态 `ι_t ∈ I = {clear, glare, rain, emi, occlusion, comm_jam}`；模态干扰相关矩阵 `R(ι) = [ρ_ij(ι)]`；**有效独立模态数** `M_eff = (Σ_i λ_i)² / Σ_i λ_i²`（相关矩阵特征值的参与率，`1 ≤ M_eff ≤ M`），工程近似 `M_eff ≈ 1 + (M−1)(1−ρ̄)`。配额从 `M ≥ 2` 升级为 `M_eff ≥ 2 ∧ M ≥ 2`；CertBox 在体制 ι 下膨胀 `ε_loc(ι) = ε_loc · (1+γ(ι))`；conformal 按体制分组校准，保证 `P(err ≤ ε̂ | ι) ≥ 1−α`；用 online e-value / martingale 检验可交换性，一旦拒绝即强制重校准或回落最保守体制。
关键反直觉点：**干扰不该被"平均"掉，而应被"条件化"**——平均会稀释共模信号，只有条件化才保得住覆盖。第二个反直觉点：**在共模干扰下"多装同质传感器"是假朋友**——M 增大而 M_eff 不增，冗余票仍然是同一张票；真正有效的是**异质物理原理**（雷达 / 相机 / 超声 / 事件相机），即降低 ρ 而非增加 M。

**灵感 2（可用性评估 → 安全是约束，可用性是目标，二者不可对调）**
直觉：前几轮一路加约束，单调链 `Exec_v24 ⊆ Exec_v23 ⊆ …` 保证了"绝不更危险"，却可能把可用性压到零——过度保守 = 安全但没用。可用性评估就是给这条链装一个"仪表盘"：在安全集合**内部**，还剩多少可执行计划？操作员要多久看懂一张证书？干扰下停机多久？关键纪律：**可用性是目标 (objective)，安全是约束 (constraint)；绝不能用可用性去放宽安全**。安全-可用性是一条 Pareto 前沿，不是一条可以互相折抵的标量。
严谨化：可用性向量 `U = (A_avail, R_task, R_interv, T_audit, L_cog)`：可执行时间比例 / 任务成功率 / 人工接管率 / 证书可解释时间 / 认知负荷（问卷 + 信息熵代理）。`Exec_v24 = Exec_v23 ∩ Fil_int` 是硬约束集；`π* = argmax_{π∈Exec_v24} U(π)`，在安全等价类内做 Pareto 选择。评估必须**非侵入 (non-invasive)**：在影子通道 / 数字孪生中评估，不进入 50Hz 安全路径，不改变任何证书；UC 记录协议、样本量、置信区间，以及"评估本身是否干扰了系统"。
关键反直觉点：**可用性最高的方案既不是最安全的，也未必是最保守的**——在安全等价类内 `argmax U`，比"一律最严"能显著恢复活性且零安全损失。第二个反直觉点：**可解释性 `T_audit` 本身就是可用性维度**——一张形式正确却没人看得懂的证书，事故后等效于不存在；"可审计"必须包含"人类可审计"。

**三者如何统一**
统一为 **v23 之上的"干扰-可用性"层**：ISL（Interference State Layer）回答"现在的独立性假设还成立吗"，UEL（Usability Evaluation Layer）回答"在仍然安全的计划里，哪个最好用、多好用"。共享状态扩展为 `ζ_v24 = ζ_v23 ∪ (ι_t, R, M_eff, e_value, U_vec, pareto_front, uc_proof)`。准入门升级为 **HPC-E++ = (HPC-E+, InterferenceValid, UsabilityEvaluated)**：InterferenceValid 是硬约束（收缩执行集），UsabilityEvaluated 是软目标（只在执行集内选 argmax，绝不扩张）。于是 `Exec_v24 = Exec_v23 ∩ Fil_int ⊆ Exec_v23`，而可用性只决定"在子集里挑哪个"，不决定"子集有多大"。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P45）

**P43 干扰即状态律（Interference-as-State）**
干扰不被平均，而被条件化。定义 `ι_t`、`R(ι)`、`M_eff`；CertBox 膨胀 `ε_loc(ι) = ε_loc · (1+γ(ι))`；conformal 与 FSVC 的覆盖按体制分组（`P(err ≤ ε̂ | ι) ≥ 1−α`）；配额以 `M_eff` 计。任何干扰状态**不确定**时，取最保守体制 `ι* = argmax_ι γ(ι)`；`e_value` 拒绝可交换性即触发重校准，重校准未完成期间一律按最保守体制。故 `Fil_int` 只会收缩执行集。

**P44 异质冗余优于同质堆叠律（Heterogeneous Redundancy）**
有效独立度 `M_eff = (Σ_i λ_i)² / Σ_i λ_i²`，配额要求 `M_eff ≥ 2 ∧ M ≥ 2`。增加同质传感器不提升 `M_eff`；仲裁必须证明模态的**物理异质性**（不同物理原理、不同失效模式、不同供电/时钟域）。同质堆叠只可作为"可用性冗余"，不可作为"抗干扰冗余"计入配额。共模干扰下 `ρ̄ → 1 ⇒ M_eff → 1`，配额自动拒绝假共识。

**P45 安全约束-可用性目标分离律（Safety-Constraint / Usability-Objective Separation）**
可用性只在安全集合内优化，永不放宽安全：`Exec_v24 = Exec_v23 ∩ Fil_int`；`π* = argmax_{π∈Exec_v24} U(π)`（字典序：安全 ≻ 可用性）。可用性评估非侵入、可审计、带不确定度；`U` 的置信下界不达标或样本不足时，回退到最保守等价类而非外推。可用性评估的失败（评估器崩溃 / 样本污染）只会导致"选择更保守"，不会导致"选择更激进"。故 `Exec_v24 ⊆ Exec_v23` 在任意可用性行为下恒成立。

## 3. 与基线的接口（如何退化）

- CMIC 失效（干扰状态不可辨识）⇒ 取最保守体制 `ι*`（最大膨胀 + 单模态配额 + 全组重校准）⇒ 比 v23 更保守，方向不变；
- CFC-IR 无法证明异质性（`M_eff < 2`）⇒ 退回 v23 的 CFC+++ 模态配额，再退回 v22 的 CFC++，最后退回单模态保守仲裁；
- ICCC 失效（分组校准不可信）⇒ 全局使用最保守分位数（最大 `ε̂`），覆盖保证退化为 v23 的全局 conformal；
- UC 失效（可用性评估器崩溃 / 样本不足）⇒ 不做 argmax，默认选择安全集中最保守的等价类 ⇒ 可用性下降但安全不变；
- PDC 失效（Pareto 选择器崩溃）⇒ 一律取最严计划 ⇒ 与 v23 行为等价（只是活性更低）；
- 四者全失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 166）。
- **安全继承**：ISL 只条件化/膨胀/收缩，UEL 只在集合内选择、失败向保守；干扰与可用性的任何失效都向更保守方向退化。ISL/UEL 以事件方式（10Hz 注入 + TTL）接入 v17 APS 新鲜度阶梯，控制路径仅做 O(1) 状态查询。

## 4. 预期贡献

1. **共模干扰证书 CMIC**：把"干扰"从噪声提升为一等状态 `ι_t`，给出相关矩阵、有效独立模态数 `M_eff` 与在线可交换性 e-value 的可审计形式化；
2. **有效独立配额 CFC-IR**：把"多传感器冗余"从计数问题纠正为"相关结构"问题，证明共模干扰下 `M_eff → 1`，从结构上拒绝"假独立的一致票"，直接封堵 v23 共振崩塌的物理成因；
3. **干扰条件化 conformal（ICCC）**：按体制分组校准 + e-value 监控，在体制切换与稀疏样本下给出可计算的覆盖下界与重校准收敛界；
4. **非侵入可用性证书 UC**：把 `(A_avail, R_task, R_interv, T_audit, L_cog)` 变成可测量、可审计、带置信区间的向量，首次把"安全但没用"纳入可评估范畴；
5. **安全约束/可用性目标分离的 Pareto 退化控制器 PDC**：在不损失任何安全的前提下恢复活性，给出"安全等价类内 argmax U"的单调性证明；
6. **HPC-E++ 统一准入门**：`HPC-E+ ∧ InterferenceValid ∧ UsabilityEvaluated`，`Exec_v24 ⊆ Exec_v23` 闭环，且可用性永不扩张执行集。

## 5. 本轮最大风险

**一句话**：干扰检测器与安全证书共享同一个被干扰的感知前端——若共模干扰同时欺骗"干扰状态估计"与"几何/语义证书"，系统会把**被污染的安全集**误认为真安全集，并在其中按可用性 `argmax` 选出最激进的计划，即"干扰诱导的可用性乐观"（interference-induced usability optimism）；它比单纯保守更危险，因为它在形式上仍然通过了所有证书，而"干扰状态"这一层恰好成了绕过安全检查的共谋。

class InterferenceRobustConsensus(CertificateFederatedConsensusPlusPlusHierarchical):
    """在 CFC+++ 上增加有效独立配额与异质性证明。"""

    def __init__(self, N: int, F: int, m_min: int = 2,
                 homogeneity_map: dict[str, str] = None):
        super().__init__(N, F)
        self.M_MIN = m_min
        self.homogeneity_map = homogeneity_map or {}  # modality -> 物理原理族

    def consensus_round(self, icert: InterferenceCertificate, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            count_ok = len(votes) >= self.N - self.F
            modalities = {v.modality for v in votes.values()}
            # 异质性证明：同物理原理族只算 1 个有效模态
            families = {self.homogeneity_map.get(m, m) for m in modalities}
            heterogeneous_ok = len(families) >= 2
            # 有效独立配额（共模下 M_eff → 1，自动拒绝假共识）
            m_eff_ok = icert.m_eff >= self.M_MIN
            # 体制一致：票据必须与当前干扰体制一致，旧体制票据降权
            regime_ok = all(getattr(v, "regime", icert.regime) == icert.regime
                            for v in votes.values())
            layer_ok = self._check_layer_consistency(votes)
            ce_ok = all(v.ce_version == next(iter(votes.values())).ce_version
                        for v in votes.values())
            fs_ok = all(v.few_shot_valid for v in votes.values())
            ip_ok = all(v.ip_attested for v in votes.values())

            if all([count_ok, heterogeneous_ok, m_eff_ok,
                    regime_ok, layer_ok, ce_ok, fs_ok, ip_ok]):
                results[key] = self._majority_with_outlier_filter(votes)
            else:
                results[key] = "CI"   # 证据不足 → 保守
        return results

# IP-442 Interference-Conditioned Conformal (ICCC)
# ============================================================
class InterferenceConditionedConformal:
    def __init__(self, alpha: float = 0.01, min_group: int = 30):
        self.alpha = alpha
        self.min_group = min_group
        self.D = {r: [] for r in CommonModeInterferenceEstimator.REGIMES}

    def update(self, regime: str, score: float, err: float):
        self.D[regime].append((score, err))
        if len(self.D[regime]) > 5000:
            self.D[regime].pop(0)

    def quantile(self, regime: str, score: float) -> float:
        data = self.D[regime]
        if len(data) < self.min_group:
            # 组内样本不足 ⇒ 合并近邻体制 + 最保守膨胀
            data = self._pool_neighbors(regime)
        if not data:
            return float("inf")          # 无数据 ⇒ 最大误差界
        errs = sorted(e for s, e in data)
        k = min(len(errs) - 1,
                int(np.ceil((1 - self.alpha) * (len(errs) + 1))) - 1)
        return errs[max(k, 0)]

    def _pool_neighbors(self, regime: str):
        # 实现略：按体制相似度加权合并，并乘 (1+γ) 保守因子
        return []

    def coverage_lower_bound(self, regime: str, delta: float = 1e-3) -> float:
        data = self.D[regime]
        n = len(data)
        if n == 0:
            return 0.0
        q = self.quantile(regime, 0.0)
        emp = sum(1 for s, e in data if e <= q) / n
        return emp - math.sqrt(math.log(1 / delta) / (2 * n))

## 3. 正确性论证

### 引理 5（有效独立模态数单调性与假共识拒绝）
**陈述**：对任意相关矩阵 `R(ι)`（对称半正定、对角为 1），有 `1 ≤ M_eff ≤ M`；当所有模态完全共模（`R = 11ᵀ`）时 `M_eff = 1`。因此配额 `M_eff ≥ 2` 在完全共模下必然拒绝共识。

**证明**：
1. 设特征值 `λ_1 ≥ … ≥ λ_M ≥ 0`，因 `tr(R) = M`，故 `Σλ_i = M`。
2. `M_eff = (Σλ)² / Σλ² = M² / Σλ²`。由 Cauchy–Schwarz，`Σλ² ≥ (Σλ)²/M = M`，故 `M_eff ≤ M`；又 `Σλ² ≤ (Σλ)²`（因 `λ_i ≥ 0` 且交叉项非负），故 `M_eff ≥ 1`。
3. 完全共模时 `R` 秩为 1，`λ = (M,0,…,0)`，`Σλ² = M²`，故 `M_eff = 1`。
4. 因此 `M_eff ≥ 2` 蕴含 `R` 至少有 2 个非平凡特征方向，共模一致票无法满足配额。∎

### 引理 6（干扰条件化覆盖与体制切换界）
**陈述**：若在体制 `ι` 内校准样本与测试样本可交换，则 `P(err ≤ ε̂_ι | ι) ≥ 1−α`。体制切换瞬间，对有限体制集 `I`，全局覆盖满足 `P(err ≤ ε̂_{ι}) ≥ 1−α−Σ_{ι'≠ι} w_{ι'}`（并集界），其中 `w` 为切换权重；`e_value ≥ 1/δ` 时回退最保守体制 `ι*`，覆盖不降。

**证明**：
1. 组内可交换 ⇒ 标准 split-conformal 有限样本覆盖 `≥ 1−α`。
2. 体制切换时测试点可能落入校准不足的组；按并集界，错误概率至多加上跨组权重质量。
3. `e_value` 检验（Ville 不等式）在可交换性成立时 `P(sup_t e_t ≥ 1/δ) ≤ δ`；拒绝后取 `ι*`（最大 `γ`、最大 `ε̂`），误差界只增不减，故覆盖不降。∎

### 引理 7（安全-可用性分离与执行集单调）
**陈述**：对任意可用性评估结果与任意 PDC 行为，`Exec_v24 = Exec_v23 ∩ Fil_int ⊆ Exec_v23`；`π* = argmax_{π∈Exec_v24} U(π) ∈ Exec_v24`，故可用性选择不扩张执行集。

**证明**：
1. `Fil_int` 仅由 `ε_loc(ι)` 膨胀、`M_eff` 配额、体制回落构成，均为收缩算子（引理 5、6）。
2. `Exec_v24` 定义为 `Exec_v23` 与 `Fil_int` 的交，交集必为子集。
3. PDC 的 `select` 输入域为 `Exec_v24`，输出 `π*` 必在域内（`_safety_dominates` 防御性复核）。
4. 可用性评估器失败 / 样本不足 / Hawthorne 标记触发时，`select` 返回 `Exec_v24` 内最保守元素，仍在集合内。∎

### 引理 8（v24 单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18` 恒成立。

**证明**：
- CMIC 失效 ⇒ 取 `ι*`（最大膨胀 + 单模态配额）⇒ `Fil_int` 更严 ⇒ 子集。
- CFC-IR 异质性无法证明 ⇒ 退回 CFC+++ 配额 ⇒ `Exec_v24` 收缩至 v23 行为 ⇒ 子集。
- ICCC 失效 ⇒ 全局最大分位数 ⇒ `ε̂` 只增 ⇒ 子集。
- UC/PDC 失效 ⇒ 最保守选择 ⇒ 计划集不变或更小 ⇒ 子集。
- 组合失效取交集，单调性保持；全失效完全回退 v23。∎

### 定理（HPC-E++ 的安全-抗干扰-可用性三性完备性）
**陈述**：对任意计划 π，`HPCEPlusPlus.admits(π)=True` ⟺ π 同时满足：
(1) v23 全部四证条件（物理接地、云边同步、少样本覆盖、IP 保护）；
(2) 干扰有效性：`M_eff ≥ 2`、体制置信 `≥ 0.5`、`e_value < 1/δ`、误差界按 `ι` 膨胀；
(3) 可用性已非侵入评估且协议合规。
且 (2) 只收缩执行集，(3) 只做集合内选择，故 `Exec_v24 ⊆ Exec_v23`。

**证明**：由 `HPCEPlusPlus.admits` 三连言条件直接得必要性；充分性由引理 5–8 的覆盖、配额、分离与单调性保证。可用性条件不进入 `Fil_int` 的收缩算子，仅作为 `select` 的排序依据，故不扩张。∎

## 6. 本轮最大风险（最终确认）

**一句话**：干扰检测器与安全证书共享同一个被干扰的感知前端——若共模干扰同时欺骗"干扰状态估计"与"几何/语义证书"，系统会把**被污染的安全集**误认为真安全集，并在其中按可用性 `argmax` 选出最激进的计划，即"干扰诱导的可用性乐观"（interference-induced usability optimism）；它比单纯保守更危险，因为它在形式上仍然通过了所有证书，而"干扰状态"这一层恰好成了绕过安全检查的共谋。
