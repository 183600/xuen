# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；新一轮灵感循环第 1 轮；本轮灵感：「意图识别」×「位姿估计」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因能力依赖「故障属于有限假设集、且视觉与几何的失效相互独立」；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——第 65 轮的单点故障由此升级为「归因错误的复合故障」，而且系统会因为「已经归因」而更自信地继续执行。** 本轮不靠「多加一个假设」续命，而是换一个更根本的问法：第 65 轮问「**到底谁坏了**」，PIVOT 问「**即使不知道谁坏了，当前意图下还安不安全；哪些位姿/故障差异根本不影响任务**」。本轮核心命题是：
>
> **把「故障可归因」升级为「意图条件下的故障相关性」：用意图识别给出任务相关的投影与开放世界意图信念，用多假设位姿估计给出对称商空间上的可认证位姿集；只在意图相关子空间里判断故障是否重要，对无关模糊性显式「商掉」，对相关模糊性按「先问、再看、最后才碰」消歧。归因不是目的，包络覆盖才是。**

## 0. 直觉与动机

**灵感 1（意图识别 → 故障是否重要，取决于任务想干什么）**
直觉：一个几何误差、一个 F/T 偏置、一个接触模型错，本身没有「危险」这个属性；危险是 **误差 × 任务 × 意图** 的联合谓词。绕圆柱对称轴多转 90° 对「抓起来」毫无影响，对「把标签转到指定朝向」却是致命错误；插入轴方向偏 2mm 对「自由放置」无所谓，对「轴孔装配」就是碰撞。第 65 轮把所有残差挤进同一个 `‖e‖`，于是**把与任务无关的误差也当成故障来膨胀球**；反过来，又可能把与任务强相关的误差当成「小残差」放过。意图识别恰好提供了那个缺失的投影算子：**先确定「为了什么」，才能确定「错在哪里才算错」**。但必须诚实：意图本身是分层的（任务/接触/柔顺）、时变的、开放世界的，还会被误读和欺骗，因此它不是新的真值，而是一个**带未知质量与可信集的概率信念**。

**灵感 2（位姿估计 → 几何不是点，是带对称商的多模态信念）**
直觉：6D 位姿估计界早就承认两件事。其一，**对称性**：圆柱、球、对称盒子、平行夹爪换指、绕接近轴自旋，在物理任务上完全等价，naive ADD 位姿误差却会爆炸，所以才有 MSSD/MSPD/VSD 这类对称感知指标。其二，**多模态**：单目/少视角位姿天然有翻转解、镜像解、遮挡歧义，正确做法不是强行选一个点，而是维护多个位姿假设及其权重。第 65 轮的 `e_vis` 正是 ADD 式的绝对残差，`φ̂` 正是单点估计——于是它会对着一个「物理上完全等价的抓取」大喊几何幻觉，也会因为选错位姿模式而把整条技能判 OOD。PIVOT 把几何升级为：**意图条件化商空间上的多假设位姿集合**，并由 conformal 给出可认证覆盖。

**灵感 3（意图识别 → 第三条证据通道，但要防「自证」循环）**
直觉：第 65 轮的独立性假设在透明/镜面/对抗物体上崩了——视觉与几何共享同一个分布外原因。人的意图线索（语言、注视、指向手势、示范、任务上下文）是**外生**的，原则上能打破这个共因僵局：人指着杯柄说「拿这个」，比任何视觉残差都更能决定哪里可碰。但危险在于：意图也常从机器人自己的运动/力历史里推断（「它往那边压，大概想推」），这就与故障共享同一个因果源，形成 **自证循环**——视觉错了 → 机器人动作偏了 → 从动作推断出的意图也偏了 → 用这个意图把几何错误「商掉」→ 系统更自信。因此必须显式区分**外生意图证据**（可用于归因/安全方向判定）与**内生意图证据**（只可用于跟踪），并用循环指数监控。更进一步，意图可被对抗欺骗（假语音、假手势、伪造注视），所以它是**可错证据**，不是新的真值。

**灵感 4（合流 → 从「诊断标签」到「效应包络 + 诊断商」）**
直觉：第 65 轮最大的隐藏假设是「必须先知道是谁坏了，才能安全」。这其实不必要。对安全而言，真正需要知道的是：**在意图相关子空间里，故障会把位姿/力/接触推多远，安全动作集会不会因此改变**。于是定义**效应包络** ℰ（不依赖故障标签，只依赖可界定的物理扰动范围）与**诊断商**：两个故障假设若在当前意图下诱导相同的任务相关效应包络，它们在安全意义上就是同一个类，不必区分。未知复合故障不再被强行塞进最近标签——只要它的效应落在包络内，就按包络认证；包络若不被覆盖，就触发消歧或安全停机。这把「归因正确」从**安全的前置条件**降级为**可选的效率优化**。消歧手段也按风险排序：**先问人（ask）→ 再看一眼（look, next-best-view/主动视觉）→ 最后才碰（touch, AFA 物理探针）**，把第 65 轮「主动探测可能压坏易损物体」的风险进一步压低。

**灵感 5（PIVOT 组件原位升级）**
- **新增 INB（Intent Belief）**：分层开放世界意图信念；外生/内生证据分离 + 循环指数；未知意图质量 `b(⊥)` 一等公民。
- **新增 TPQ（Task–Pose Quotient）**：`π_I: SE(3)→𝒬_I`，把物体对称、换指对称、接近轴自旋以及任务无关方向显式商掉；只在 `ker π_I` 之外的坐标上计残差。
- **新增 MHP（Multi-Hypothesis Pose）**：维护位姿模式集合与权重，对称等价模式合并，非等价多解保留；per-mode conformal 认证集。
- **FIR → IFR**：从「最大后验故障标签」改为「意图条件故障相关性 + 效应包络 + 诊断商」；无行动差异的模糊性直接标 `benign_ambiguity`。
- **AFA → AID**：探针选择从「故障互信息」升级为「在风险预算下最大化**可操作相关性下降**」，动作集含 `ask/look/touch/wait`，物理探针是最后手段。
- **CSC → CSC-Q**：认证对象从「后验支持集上的标签最坏」改为「位姿认证集 × 故障效应包络 × 意图可信集」的三重覆盖，不再需要标签。
- **RSC-V → RSC-I**：不确定半径分为 `r_pose^I / r_intent / r_force / r_model`，只沿意图相关方向膨胀；物理硬约束（力限、碰撞）永不被商掉。
- **WCV-V → WCV-Q**：搜索域在商空间 `𝒬_I` 上编译，避免对称等价的重复覆盖。
- **CSP-V → CSP-I**：意图模式作为规划图节点；跨意图模式共享的块边需要包络证书；`ask/look` 作为零接触元技能。
- **AIC-V → AIC-I**：干扰集增意图欺骗、位姿对称攻击、模式注入、意图漂移与共因；证书增 `intent_integrity_ver`。
- **J_vista → J_pivot**：证书增加 intent_posterior、pose_mode_set、task_quotient_id、relevance_partition、envelope_coverage。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（PIVOT 闭环）**：PIVOT=(GRIP,VISTA,INB,TPQ,MHP,IFR,AID,ECC,CSC-Q,RSC-I,WCV-Q,CSP-I,AIC-I,J_pivot)。定位：VISTA 的「意图条件化 + 诊断去标签化」升级。不变式：**意图信念、位姿模式、相关性划分、包络证书只在语义流；实时流只做意图条件投影、包络成员检查、认证前缀执行与早停，零学习写操作。** 附加不变式：**内生意图证据不得用于故障归因或商掉安全方向，只能用于意图跟踪。**
- **定义 234（分层意图信念）**：`I=(g,c,κ)∈ℐ=𝒢×𝒞×𝒦`，g 为任务目标（拿什么/放到哪），c 为接触意图（接触点/接近方向/夹持方式），κ 为柔顺意图（力/阻抗偏好）。维护信念 `b_t(I)` 与开放世界质量 `b_t(⊥)`。外生证据 `E_t`（语言、注视、手势、示范、任务上下文）与内生证据 `Z_t`（机器人自身位姿/力历史）分别更新；只有 `E_t` 可进入归因与商投影的可信计算。
- **定义 235（意图证据图与循环指数）**：有向图节点含 `{E,Z,robot action,fault,I}` 及共享混杂。定义循环指数 `χ_int = max_{path Z→I 且与 ρ 共享 fault 源} confounding_strength`。若 `χ_int>χ_max`，标 `intent_endogenous=True`：意图后验降温，TPQ 只保留任务不变量，不执行意图特定商。
- **定义 236（任务-位姿商）**：给定意图 I，任务泛函 `ψ_I(T)` 取接触点集、接近轴、插入轴、夹爪闭合平面、任务相关物体坐标系等。定义等价 `T ~_I T' ⇔ ψ_I(T)=ψ_I(T')`，商映射 `π_I: SE(3)→𝒬_I=SE(3)/~_I`。物体对称群、换指对称、绕接近轴自旋满足 `G_sym(I) ⊆ ker π_I`；而纹理朝向、按键方向、线缆走向等任务相关方向必须保留在商之外。
- **定义 237（对称感知任务残差）**：`e_pose^I(T,T') = d_{𝒬_I}(π_I T, π_I T')²`。对位姿模式 `T̂_m`，非一致性分数 `s_m(T)=e_pose^I(T,T̂_m)/σ_m²`。该残差只惩罚任务可见差异，不对规范等价（canonical symmetry）误报。
- **定义 238（多假设位姿信念与认证集）**：维护 `{(T̂_m,w_m)}_{m=1..M}`，由 MHP 滤波器（预测、鲁棒更新、GNC 外点抑制、模式新生/消亡）产出。per-mode conformal 阈值 `q_m(α/M)`，认证集 `𝒯_α = ⋃_m {T: s_m(T) ≤ q_m(α/M)}`，在可交换性下 `P[T_true∈𝒯_α] ≥ 1−α`。
- **定义 239（位姿模式商合并）**：若 `d_{𝒬_I}(π_I T̂_m, π_I T̂_n) ≤ ε_q`，两模式合并、权重相加；若在任务相关投影上不同，则即使 3D 位姿很近也保留为不同模式（例如对称物体上差一个任务关键朝向）。
- **定义 240（意图条件故障相关性）**：对故障假设 H（含未知类 `H_?`），效应包络 `ℰ(H)` 为可能的位姿/接触/力扰动集；意图条件投影 `ℰ_I(H)={π_I^{eff}(e):e∈ℰ(H)}`。定义意图条件下安全动作集 `A_safe(H,I)={a: margin_{H,I}(a)≥0}`，相关性 `Rel_I(H)=D(A_safe(H,I),A_safe(H0,I))`（可取最大后悔或集合散度）。`Rel_I(H)>ε_rel` 才是**可操作故障**。
- **定义 241（诊断商）**：`H ~_I H' ⇔ d(ℰ_I(H),ℰ_I(H'))≤ε_rel`。商集 `ℋ/~_I` 是意图相关故障类。归因只需分辨这个商集，而非原始标签；未知复合故障若落入已有包络类，则安全上视为同类，无需强行命名。
- **定义 242（意图条件安全动作包络）**：`S_I = ⋂_{[H]∈cover(ℋ/~_I)} A_safe([H],I) ∩ A_safe(H_?,I)`。`S_I≠∅` 表示当前意图下存在可认证动作；为空则触发 AID 或安全停机。物理硬约束（力限、碰撞、不可逆视界）在所有投影中保持不变。
- **定义 243（主动意图消歧 AID）**：动作集 `{ask, look, touch, wait}`，风险序 `r_ask≤r_look≤r_touch`。选择 `a* = argmax_a ΔRel_I(a)/cost(a)`，s.t. `cost(a)≤risk_budget`；`touch` 仅当 `ask/look` 无法把可操作模糊降到阈值以下、且物体不脆弱时允许。`ask` 用于人类意图，`look` 用于位姿模式（next-best-view/主动视觉），`wait` 用于意图时变。
- **定义 244（包络覆盖证书 ECC）**：给定位姿认证集 `𝒯_α`、故障效应覆盖 `ℰ_β`、意图可信集 `ℐ_γ`，证书要求 `∀I∈ℐ_γ, ∀T∈𝒯_α, ∀e∈ℰ_β, ∀s≤k: margin_{I,T,e}(a_s)≥0`。覆盖概率下界 `1−α−β−γ`。证书**不依赖故障标签**，只依赖效应包络。
- **定义 245（意图条件认证前缀 CSC-Q）**：`k* = max{k≤m: ECC 在 A[:k] 上成立}`，m 为不可逆视界。执行中若意图信念相对块首的 KL 散度 `D_KL(b_t(I)‖b_0(I))>δ_int`，或位姿模式集合哈希变化且新模式的 `ℰ_I` 改变包络，立即早停并重规划。
- **定义 246（RSC-I 与 WCV-Q）**：不确定半径分为 `r_pose^I`（任务投影位姿）、`r_intent`、`r_force`、`r_model`。只沿 `𝒬_I` 中任务相关方向膨胀；与意图无关的方向保持标称误差，不因「看见一个大残差」而过度保守。WCV-Q 在商空间 `B_Q(π_I φ̂, r_pose^I) ∩ 𝒢 ∩ K ∩ ℱ ∩ 𝒱` 中编译。
- **定义 247（AIC-I 意图/位姿对抗认证）**：`ℰ_I = ℰ_vis×ℰ_pose×ℰ_intent×ℰ_time×ℰ_common`；`ℰ_intent` 含假语音/假手势/伪造注视/意图漂移，`ℰ_pose` 含对称攻击（与真值对称等价但任务相关投影不同）、模式注入/重放、位姿跳变。共因下**不要求意图正确**，只要求包络覆盖或 `safe_idle`。
- **定义 248（PIVOT 证书 J_pivot）**：`J_pivot=(J_vista,intent_posterior,intent_entropy,intent_evidence_mask,pose_mode_set_hash,task_quotient_id,relevance_partition,envelope_coverage,disambiguation_action,intent_integrity_ver)`。Valid ⇔ `Valid(J_vista)` ∧ 包络覆盖达标 ∧ （可操作模糊已消解 ∨ 已进入 `safe_idle`） ∧ 归因只使用外生意图证据 ∧ 位姿认证集被完全覆盖 ∧ 物理硬约束未被商掉。

## 2. 关键算法骨架

```python
# INB：分层意图信念 + 外生/内生证据隔离（语义流）
b_I = inb.update(exo_cues, endo_cues, dt)
if inb.circularity(b_I) > CHI_MAX:
    b_I = inb.temper(b_I, tau=TAU_TEMP)     # 内生成分降温，禁止用于商掉安全方向
I_cred = inb.credible_set(b_I, gamma)       # 含 unknown 类

# MHP + TPQ：多假设位姿 → 意图相关商空间
modes = mhp.track(rgbd, prev_modes)         # 预测/鲁棒更新/GNC/模式新生消亡
modes = tpq.merge_symmetric(modes, b_I)     # 合并 ker(pi_I) 内的等价模式
T_alpha = mhp.conformal_set(modes, I_cred, alpha)   # 联合认证集

# IFR：不是归因标签，而是“是否改变意图相关安全包络”
env = {H: effect_envelope(H, b_I) for H in HYP + ('H_unknown',)}
classes = diagnosis_quotient(env, eps_rel)  # H~H' iff 任务相关效应相同
if actionable_ambiguity(classes):
    a = aid.choose(b_I, classes, risk_budget, fragile=M.fragile)
    if a in ('ask', 'look', 'wait'):
        return NONCONTACT_ACTION(a)         # 先问/再看/等待，不接触物体
    # touch 仅在非接触失败且不脆弱时

# ECC + CSC-Q：在包络上认证，而非在标签上认证
k_star = ecc.certify_prefix(A, T_alpha, env_cover(classes), I_cred, m, alpha)
for a in A[:k_star]:
    dispatch(a)
    if ecc.monitor(a, b_I, modes).abort:    # 意图漂移/新模式改变包络
        break
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（任务-位姿商的无过罚性）**：若任务损失对 `G_sym(I)` 不变且在商度量下 L-Lipschitz，则用 `e_pose^I` 替代绝对残差不会漏掉任务后果，且消除了高达轨道直径的对称误报。于是「对称物体上的几何幻觉」不再被误判为 H_geo。
- **引理 10（包络覆盖免诊断）**：只要真实故障效应落在 `ℰ_β`、真位姿落在 `𝒯_α`、真意图落在 `ℐ_γ`，且三者的笛卡尔积内所有边距非负，则执行前缀安全概率 ≥`1−α−β−γ`，**无需知道故障标签**。这把 VISTA 的有限假设集依赖替换为「效应有界」这一弱得多的假设；未知复合故障只要效应在包络内即可安全。
- **定理 9（PIVOT 端到端）**：在 A94–A99 下，`Valid(J_pivot)` ⇒ 意图相关安全 ∧ 归因只在可操作处发生 ∧ 未知复合故障被包络覆盖或触发消歧/安全停机 ∧ 物理硬约束从未被商掉。证书链从「几何-技能-干扰-接触-归因」扩到「…-归因-意图相关性-包络覆盖」。
- **定理 10（ask–look–touch 的风险序最优性）**：在风险单调、信息增益递减、非接触动作可达阈值的假设下，风险约束下最优消歧策略是先选择能达到 `ΔRel≥δ` 的最低风险动作；若 `ask/look` 足够，`touch` 严格次优。故物理探针仅作为最后手段，易损物体时风险为无穷、永不接触。
- **命题（商降低保守性）**：设任务相关子空间维数 `d_rel`、完整位姿维数 d，则把不确定球投到商空间后体积比约 `r^{d−d_rel}`；对称/任务无关方向上的过度膨胀被消除，同时诊断商把「无行动差异」的假设合并，减少无谓消歧。
- **实时性**：INB、MHP、TPQ 校准、IFR、AID、ECC 全在语义流；实时流只增任务投影（<0.1ms）、包络成员检查（<0.05ms）、意图漂移早停（<0.02ms），目标 ≤2.5ms（A99，需与 LSF/视觉 ROI 共享编码）。

## 2. 形式化定义（完整版）

**定义 233（PIVOT 闭环）** PIVOT 是 VISTA 的「意图条件化 + 诊断去标签化」升级：在 GRIP/VISTA 的「语义流 ∘ 实时流」骨架上挂载 INB（意图信念）、TPQ（任务-位姿商）、MHP（多假设位姿）、IFR（意图条件故障相关性）、AID（主动意图消歧）、ECC/CSC-Q（包络覆盖与认证前缀），并原位升级 RSC-V→RSC-I、WCV-V→WCV-Q、CSP-V→CSP-I、AIC-V→AIC-I、J_vista→J_pivot。不变式：

1. **全部意图推断、位姿模式维护、相关性划分、包络证书只在语义流/低频线程；实时流只做意图条件投影、包络成员检查、认证前缀执行与早停，零学习写操作。**
2. **内生意图证据不得用于故障归因或商掉安全方向，只能用于意图跟踪。**
3. **物理硬约束（力限、碰撞、不可逆视界、传感器物理量程）在一切商投影下保持不变，永不被商掉。**

**定义 234（分层意图信念）** 意图 `I=(g,c,κ)∈ℐ=𝒢×𝒞×𝒦`：g 为任务目标（拿哪个物体、放到哪、执行什么操作），c 为接触意图（允许/期望的接触点集、接近方向、夹持方式），κ 为柔顺意图（期望力/阻抗/速度上限）。维护信念 `b_t(I)` 与开放世界质量 `b_t(⊥)`（表示「当前意图不在已知集合内」）。外生证据 `E_t`（语言指令、注视、指向手势、示范、任务上下文、场景中的人类行为）与内生证据 `Z_t`（机器人自身位姿/力/动作历史）分别进入更新：

```
b_t ∝ b_{t−1} · p(E_t|I) · p(Z_t|I)^{τ_endo} ,  τ_endo ≤ 1
b_t(⊥) ← b_t(⊥) + novelty(E_t,Z_t)
```

`τ_endo` 对内生证据降温；只有外生证据允许进入 IFR 的相关性判定与 TPQ 的意图特定商。

**定义 235（意图证据图与循环指数）** 构建有向图，节点 `{E,Z,robot action,fault,I}`，边表示因果/条件依赖；允许显式混杂节点（例如「同一物体外观」同时影响视觉、手势识别与几何）。循环指数

```
χ_int = max_{path Z→I 且该路径与 ρ 共享 fault 源} confounding_strength(path)
```

若 `χ_int>χ_max`，置 `intent_endogenous=True`：意图后验按温度 `τ_temp` 降温；TPQ 只保留与意图无关的任务不变量（如抓取接近轴、夹持宽度），不执行特定意图的商；J_pivot 中记录 `intent_evidence_mask`，审计可复现「这次凭什么商掉了方向」。

**定义 236（任务-位姿商）** 给定意图 I，任务泛函

```
ψ_I(T) = (C_I(T), n_I(T), a_I(T), p_I(T), …)
```

其中 `C_I` 为任务相关接触点/区域，`n_I` 为接近/插入轴，`a_I` 为夹爪闭合平面/开合方向，`p_I` 为任务相关物体坐标系（例如标签朝向、按键法向、插头键槽方向）。定义等价关系

```
T ~_I T'  ⇔  ψ_I(T)=ψ_I(T')
```

商映射 `π_I:SE(3)→𝒬_I=SE(3)/~_I`。物体几何对称群、平行夹爪换指对称、绕接近轴自旋均满足 `G_sym(I)⊆ker π_I`；**但纹理朝向、按键方向、线缆走向、插头键槽等任务相关方向必须保留在商之外**。商由意图 I 参数化，因此对意图信念是「商丛」：`𝒬 = ⊔_{I∈ℐ} 𝒬_I`。

**定义 237（对称感知任务残差）** 对位姿 T 与参考 `T'`：

```
e_pose^I(T,T') = d_{𝒬_I}(π_I T, π_I T')²
```

`d_{𝒬_I}` 可取商空间上的测地距离（先在纤维内对齐规范代表元，再计 SE(3) 距离）。对模式 m 的非一致性分数 `s_m(T)=e_pose^I(T,T̂_m)/σ_m²`。与 ADD/MSPD 的关系：`e_pose^I` 正是把 ADD 式绝对残差投影到任务相关子空间、并对 `G_sym(I)` 商掉后的版本；它**只惩罚任务可见差异**。

**定义 238（多假设位姿信念与认证集）** 维护位姿模式集合 `{(T̂_m,w_m)}_{m=1..M}`，由 MHP 滤波器产生：

1. **预测**：按末端/物体运动模型传播各模式与协方差；
2. **鲁棒更新**：对每个模式做观测似然更新，GNC 抑制外点；
3. **模式新生**：当观测残差在多处形成新峰（翻转解、镜像解、遮挡后新解）时新增模式；
4. **模式消亡**：权重低于阈值或长期无观测支持则删除；
5. **认证**：per-mode split-conformal 阈值 `q_m(α/M)`，认证集 `𝒯_α=⋃_m{T:s_m(T)≤q_m(α/M)}`，在模式内可交换性下 `P[T_true∈𝒯_α]≥1−α`。

**定义 239（位姿模式商合并）** 若 `d_{𝒬_I}(π_I T̂_m, π_I T̂_n)≤ε_q`，合并两模式（权重相加、协方差按高斯混合压缩）；若两模式在 3D 上很接近但 `π_I` 投影不同（例如对称物体上仅差一个任务关键朝向、或换指前后），则**不得合并**。合并后重新做 per-mode 校准，保持覆盖。

**定义 240（意图条件故障相关性）** 对故障假设 H（含未知类 `H_?`），效应包络 `ℰ(H)` 为故障可能造成的位姿/接触/力扰动集合（由物理界、故障注入或在线辨识给出）。其任务相关投影

```
ℰ_I(H) = { π_I^{eff}(e) : e ∈ ℰ(H) }
```

其中 `π_I^{eff}` 把位姿扰动投到 `𝒬_I`、保留力/接触相关分量（力永远不商掉）。意图条件下安全动作集

```
A_safe(H,I) = { a : margin_{H,I}(a) ≥ 0 }
```

相关性 `Rel_I(H)=D(A_safe(H,I),A_safe(H0,I))`，D 可取最大后悔 `sup_{a∈A_safe(H0,I)} regret(a;H,I)` 或集合散度。只有 `Rel_I(H)>ε_rel` 才是**可操作故障**；否则标 `benign_ambiguity`，不膨胀球、不触发探针。

**定义 241（诊断商）** 定义故障等价

```
H ~_I H'  ⇔  d(ℰ_I(H), ℰ_I(H')) ≤ ε_rel
```

商集 `ℋ/~_I` 为意图相关故障类。IFR 只需输出「当前属于哪个商类、这些商类是否改变安全包络」，而不必恢复原始 H 标签。未知复合故障若其效应落入已有商类包络，则安全上视为同类；若落在所有已知包络之外，则使用 `H_?` 的保守效应包络（在线单调扩张、审计）或触发 AID。**这正面拆除了第 65 轮「有限假设集」这一风险：安全不再要求归因到 H。**

**定义 242（意图条件安全动作包络）** 给定商类覆盖 `cover(ℋ/~_I)`：

```
S_I = ⋂_{[H]∈cover(ℋ/~_I)} A_safe([H],I) ∩ A_safe(H_?,I)
```

`S_I≠∅` 表示当前意图下存在可认证动作；为空则触发 AID（找信息）或 `safe_idle`/柔顺撤退。物理硬约束（力限、碰撞、不可逆视界）作为所有 `A_safe` 的公共约束，不参与商。

**定义 243（主动意图消歧 AID）** 动作集 `{ask, look, touch, wait}`：

- `ask`：向人请求澄清/确认（语言/界面），风险最低，但依赖人；
- `look`：next-best-view / 主动视觉 / 改变视角重估位姿，零接触；
- `touch`：AFA 物理探针，仅当非接触手段无法把可操作模糊降到阈值以下、且物体不脆弱；
- `wait`：意图可能时变，等待新外生证据。

选择

```
a* = argmax_{a∈A} ΔRel_I(a) / cost(a)
s.t. cost(a) ≤ risk_budget,
     touch: ΔRel_I(touch)>δ_rel 且 ΔRel_I(ask)≤δ_rel 且 ΔRel_I(look)≤δ_rel 且 ¬fragile,
     fragile ⇒ touch 的风险为 +∞。
```

`ΔRel_I(a)` 为执行 a 后预期可操作相关性/包络歧义的下降，按当前意图信念与故障商类做期望。

**定义 244（包络覆盖证书 ECC）** 给定三个覆盖参数：位姿认证集 `𝒯_α`（覆盖 ≥1−α）、故障效应覆盖 `ℰ_β`（真效应 ∈ℰ_β 概率 ≥1−β）、意图可信集 `ℐ_γ`（真意图 ∈ℐ_γ 概率 ≥1−γ）。证书要求

```
∀I∈ℐ_γ, ∀T∈𝒯_α, ∀e∈ℰ_β, ∀s≤k:  margin_{I,T,e}(a_s) ≥ 0。
```

由联合界，执行安全概率 ≥`1−α−β−γ`。证书**不依赖故障标签**，也不要求归因正确；它只要求「位姿在集合内、效应在包络内、意图在可信集内」。输出 `envelope_coverage`、`certified_on_envelope=True`、以及各约束的最小裕度。

**定义 245（意图条件认证前缀 CSC-Q）** 对动作块 A 与不可逆视界 m：

```
k* = max{ k ≤ min(|A|,m) : ECC(A[:k], 𝒯_α, ℰ_β, ℐ_γ) 成立 }。
```

执行器只执行 `k*` 步即强制重规划与重新认证。执行中触发早停的条件：

1. 意图信念相对块首 KL 散度 `D_KL(b_t(I)‖b_0(I))>δ_int`；
2. 位姿模式集合哈希变化，且新模式使 `ℰ_I` 包络扩大或安全包络缩小；
3. 实测残差越出包络（`e∉ℰ_β`）；
4. 物理裕度低于实时安全阈值。

**定义 246（RSC-I 与 WCV-Q）** 不确定半径拆为：`r_pose^I`（任务投影位姿不确定度）、`r_intent`（意图可信集直径/熵映射）、`r_force`、`r_model`。RSC-I 只沿 `𝒬_I` 的任务相关方向膨胀 `r_pose^I`；对 `ker π_I` 中的方向保持标称误差，不因绝对残差大而过度保守。融合半径在商空间计算：

```
r_Q = √( (r_pose^I)² + r_intent² + r_force² + r_model² )
```

WCV-Q 在 `B_Q(π_I φ̂,r_Q) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱` 上编译；`𝒢,K,ℱ` 的硬约束原样保留，`𝒱` 为视觉可观测性约束。交集为空则 `attribution_conflict=True` 并回退 `safe_idle`。

**定义 247（AIC-I 意图/位姿对抗认证）** 干扰集

```
ℰ_I = ℰ_vis × ℰ_pose × ℰ_intent × ℰ_time × ℰ_common
```

`ℰ_intent` 含假语音/假手势/伪造注视/社交工程式误导/意图快速漂移；`ℰ_pose` 含对称攻击（构造一个与真值在 `G_sym` 下等价、但任务相关投影不同的位姿）、模式注入/重放、位姿跳变与遮挡；`ℰ_time` 含延迟与块重放；`ℰ_common` 含同一 OOD 物体同时骗过视觉与几何。认证时在商空间与包络上取最坏；`J_dir` 增 `intent_integrity_ver`、`pose_mode_hash`、`quotient_ver`。**共因或意图被欺骗时，不要求意图正确，只要求包络覆盖或 `safe_idle`。**

**定义 248（PIVOT 证书 J_pivot）**

```
J_pivot = (J_vista,
           intent_posterior, intent_entropy, intent_evidence_mask,
           pose_mode_set_hash, task_quotient_id,
           relevance_partition, envelope_coverage,
           disambiguation_action, intent_integrity_ver)
```

验证规则：

```
Valid(J_pivot) ⇔ Valid(J_vista)
  ∧ envelope_coverage ≥ 1−α−β−γ
  ∧ (可操作模糊已消解 ∨ disambiguation_action='safe_idle')
  ∧ 归因只使用外生意图证据（intent_evidence_mask 通过审计）
  ∧ 𝒯_α 被完全覆盖
  ∧ 物理硬约束未进入 ker π_I（未被商掉）
  ∧ intent_integrity_ver 为当前版本。
```

审计链新增：为何认为某故障「不重要」（`relevance_partition`）、为何某位姿方向可商（`task_quotient_id`）、意图证据是否自证（`intent_evidence_mask`/`χ_int`）、包络是否覆盖未知（`envelope_coverage`）。

### IP-224 INB（分层意图信念 + 循环防护）

```python
class IntentBelief:
    """分层开放世界意图信念。外生证据可归因，内生证据只跟踪。"""
    def update(self, b, E, Z, dt):
        b = self.predict(b, dt)
        b = self.bayes(b, E, weight=1.0)                 # 外生：语言/注视/手势/示范
        b = self.bayes(b, Z, weight=TAU_ENDO)            # 内生：仅跟踪，tau<=1
        b['unknown'] += self.novelty(E, Z)               # 开放世界质量
        return self.normalize(b)

    def circularity(self, b, graph):
        # 内生路径 Z->I 若与 rho 共享 fault 源，则计混杂强度
        return graph.max_confounded_path_weight('Z', 'I', share_with='rho')

    def temper(self, b, tau):
        return self.normalize({k: v ** tau for k, v in b.items()})

    def credible_set(self, b, gamma):
        # 含 unknown；返回最小质量 >= 1-gamma 的意图集合
        items = sorted(b.items(), key=lambda kv: kv[1], reverse=True)
        out, mass = [], 0.0
        for k, v in items:
            out.append(k); mass += v
            if mass >= 1.0 - gamma:
                break
        return out
```

### IP-225/226 TPQ + MHP（任务-位姿商与多假设认证）

class TaskPoseQuotient:
    def project(self, T, I):
        psi = task_functionals(I)        # 接触点集/接近轴/插入轴/夹持平面/任务坐标系
        return psi(T)                    # 自动对 G_sym(I) 取规范代表元

    def residual(self, T, That, I):
        return d_quotient(self.project(T, I), self.project(That, I)) ** 2

    def merge_symmetric(self, modes, b_I):
        I = argmax(b_I, key=b_I.get)
        merged = []
        for m in modes:
            hit = next((n for n in merged
                        if self.residual(m.T, n.T, I) <= EPS_Q), None)
            if hit is None:
                merged.append(m)
            else:
                n = hit
                n.T, n.w = gaussian_mix(n.T, n.w, m.T, m.w)
        return merged


class MultiHypothesisPose:
    def track(self, obs, modes):
        modes = [self.predict(m) for m in modes]
        modes = [self.robust_update(m, obs) for m in modes]
        modes = self.gnc_reject_outliers(modes, obs)
        modes = self.spawn_from_residual_peaks(modes, obs)
        return self.prune_by_weight(modes)

### IP-227 IFR（意图条件故障相关性 + 诊断商）

```python
class IntentFaultRelevance:
    """不输出‘谁坏了’作为安全前置；输出‘哪些差异会改变意图相关安全包络’。"""
    def partition(self, b_I, effect_model):
        env = {}
        for H in HYP + ('H_unknown',):
            env[H] = effect_model.envelope(H, b_I)        # 已投到任务相关子空间
        classes = []
        for H, e in env.items():
            hit = next((c for c in classes if dist_env(c.e, e) <= EPS_REL), None)
            if hit is not None:
                hit.members.append(H)
            else:
                classes.append(EnvClass(e=e, members=[H]))
        return classes

    def actionable(self, classes, b_I):
        if len(classes) <= 1:
            return False
        # 只要各商类对安全动作包络的影响相同，就不可操作（benign ambiguity）
        return any(self._changes_safe_set(c, classes[0], b_I)
                   for c in classes[1:])

    def relevant_envelope(self, classes):
        # 证书使用的效应覆盖：所有商类包络的并（而非标签后验）
        return union_envelopes([c.e for c in classes])
```

### IP-228 AID（ask / look / touch 风险序消歧）

```python
class ActiveIntentDisambiguation:
    def choose(self, b_I, classes, risk_budget, fragile):
        cands = ['ask', 'look', 'wait']
        if not fragile:
            cands.append('touch')
        cands.sort(key=lambda a: RISK[a])                 # ask < look < wait < touch
        for a in cands:
            if RISK[a] > risk_budget:
                continue
            gain = self.expected_relevance_gain(a, b_I, classes)
            if gain >= DELTA_REL:
                if a == 'touch' and self._noncontact_sufficient(b_I, classes):
                    continue                              # 非接触已够，不碰
                return a, gain
        return 'safe_idle', 0.0

    def expected_relevance_gain(self, a, b_I, classes):
        if a == 'ask':
            return self._ask_information_value(b_I, classes)
        if a == 'look':
            return self._next_best_view_value(b_I, classes)
        if a == 'touch':
            return self._probe_information_value(b_I, classes)
        return 0.0                                        # wait
```

class EnvelopeCoverageCertificate:
    def certify_prefix(self, A, T_set, E_cover, I_cred, m, alpha, beta, gamma):
        k_best = 0
        for k in range(1, min(len(A), m) + 1):
            ok = True
            for I in I_cred:
                for T in sample_cover(T_set):
                    for e in sample_cover(E_cover):
                        if margin(A[k - 1], I, T, e) < 0:
                            ok = False
                            break
                    if not ok:
                        break
                if not ok:
                    break
            if not ok:
                break
            if alpha + beta + gamma <= ALPHA_MAX:          # 覆盖预算可行
                k_best = k
        return k_best

    def monitor(self, a, b_I, modes):
        drift = kl(b_I, self.b_I0) > DELTA_INT
        mode_changed = hash(modes) != self.mode_hash0 and self._envelope_widened(modes)
        out_of_envelope = self._residual_outside(a, self.E_cover)
        return AbortFlag(abort=drift or mode_changed or out_of_envelope)

## 4. 推导

**引理 9（任务-位姿商的无过罚性）** 设任务损失 `ℓ_task(T,a)` 满足：(i) 对 `G_sym(I)` 不变，`ℓ_task(gT,a)=ℓ_task(T,a)`；(ii) 在商度量下 L-Lipschitz，`|ℓ_task(T,a)−ℓ_task(T',a)|≤L·d_{𝒬_I}(π_I T,π_I T')`。则对任意 `T,T'`：

```
|ℓ_task(T,a)−ℓ_task(T',a)| ≤ L·e_pose^I(T,T')^{1/2}。
```

故用商残差替代绝对残差不会漏掉任何任务后果；同时，绝对残差 `d_SE3(T,T')` 在对称轨道上可高达轨道直径（旋转对称物体可达 π 量级），而 `e_pose^I` 在该方向恒为 0。于是「绕对称轴多转 90°」不再被误判为 H_geo，`r_pose^I` 也不会沿不可观测方向膨胀。证毕。∎

**引理 10（包络覆盖免诊断）** 设事件 `A_pose={T_true∈𝒯_α}`、`A_eff={e_true∈ℰ_β}`、`A_int={I_true∈ℐ_γ}` 分别以概率 `1−α,1−β,1−γ` 成立。若在 `𝒯_α×ℰ_β×ℐ_γ` 上所有 `margin≥0`，则三事件同时成立时执行安全。由联合界

```
P[安全] ≥ 1 − α − β − γ。
```

该结论**不引用任何故障标签**：真故障可以是未知类型、复合类型、甚至与视觉共因，只要其效应在 `ℰ_β` 内。因此 VISTA 的有限假设集依赖被替换为「效应有界 + 包络覆盖」这一更弱、更可检验的假设；代价是包络可能比单假设保守，由引理 9 的意图商与诊断商把保守性压回任务相关子空间。证毕。∎

**定理 9（PIVOT 端到端归因-安全）** 在 A94–A99（见 §5）下：

1. **对称不误报**：由引理 9，`e_pose^I` 对 `G_sym(I)` 不变，对称等价位姿不触发 H_geo；位姿模式商合并避免模式爆炸。
2. **归因可选**：由引理 10，安全只要求包络覆盖，不要求标签正确；IFR 仅在 `Rel_I>ε_rel`（安全动作集被改变）时输出可操作模糊并触发 AID。
3. **未知可包**：未知复合故障若效应落入 `ℰ_β`，证书照常通过；若不在，在线单调扩张 `H_?` 包络并触发消歧或 `safe_idle`，不强行归类。
4. **风险序消歧**：AID 先 `ask/look/wait`，`touch` 仅在非接触不足且非脆弱时使用（定理 10），把第 65 轮物理探针的伤害风险进一步压低。
5. **意图自证防护**：归因只使用外生证据；`χ_int>χ_max` 时降温并禁用意图特定商，避免「视觉错→动作偏→意图偏→商掉错误」的闭环。
6. **硬约束不商**：力限、碰撞、不可逆视界作为 `A_safe` 的公共约束，永不进入 `ker π_I`；即使意图完全错误，物理界仍生效。
7. **证书六层链**：`Valid(J_pivot)` ⇔ GRIP/VISTA 有效 ∧ 包络覆盖 ∧ 可操作模糊已消解或 `safe_idle` ∧ 外生证据审计 ∧ 位姿认证集覆盖 ∧ 硬约束未被商。
8. **优雅降级**：意图不可用→只保留任务不变量、放大 `ℐ_γ`；位姿多模→按并集认证；故障未知→用 `H_?` 包络；包络冲突→`safe_idle`。∎

**定理 10（ask–look–touch 的风险序最优性）** 设消歧动作的风险满足 `r_ask≤r_look≤r_wait≤r_touch`，且各动作对可操作相关性的期望下降满足递减收益；要求在风险预算 `budget` 内使 `ΔRel_I≥δ_rel`。若 `ask/look` 中存在一个动作可在预算内达到阈值，则任何包含 `touch` 的策略都可被替换为该动作而不增加风险、且仍满足信息约束，故 `touch` 严格次优。若 `ask/look` 均不能达到阈值，则在 `¬fragile` 时 `touch` 可能是最优；`fragile` 时 `r_touch=+∞`，只能 `safe_idle`。由交换论证即得。该定理解释了为什么 PIVOT 把第 65 轮 AFA 的物理探针从「首选」降为「最后手段」。∎

**命题（商降低保守性）** 设完整位姿不确定球半径 r、维数 d，任务相关子空间维数 `d_rel`。第 65 轮在完整空间膨胀，体积 `V_full∝r^d`；PIVOT 在商空间膨胀，体积 `V_Q∝r^{d_rel}`，体积比 `V_Q/V_full∝r^{−(d−d_rel)}`。对典型抓取，`d=6`，`d_rel∈{2,3,4}`（接近轴 + 夹持平面 + 任务朝向），故保守性可降一个数量级以上；诊断商进一步把无行动差异的假设合并，减少无谓 AID 触发。∎

## 7. 已知风险

**一句话**：PIVOT 把「诊断」降级为「包络覆盖」，其正确性完全押在「意图商没有商掉安全关键方向」上；一旦意图识别错误、被欺骗或在执行中漂移，系统就会用错误的任务投影把真正危险的位姿/故障方向判为「与意图无关」，并给出一个看似严格、实则投影掉了安全的证书——**上一轮是归因错，本轮是把安全本身投影掉了**。

**次级风险与缓解**：

1. **意图成为新的单点故障**：错误/对抗意图会把安全关键方向商掉。缓解：意图可信集 `ℐ_γ` 而非点估计；硬约束永不商；AIC-I 显式建模意图欺骗；`intent_integrity_ver`；不确定时退化为「只保留任务不变量」而非意图特定商。
2. **任务泛函漏掉隐藏约束**：`ψ_I` 可能漏掉标签朝向、线缆走向等任务关键方向。缓解：保守的任务泛函库 + 未知任务不商 + 人类确认（ask）；把「未建模的任务相关方向」纳入 `H_?` 包络。
3. **效应包络过松导致死锁/过度保守**：未知类 `H_?` 的包络可能很大。缓解：在线单调学习包络（只扩不缩并审计）；按意图商裁剪；包络冲突时 `safe_idle` 或 ask，而不是硬执行；AIC-I 认证包络本身。
4. **位姿模式漏检或模式爆炸**：漏一个模式会破坏覆盖；模式过多会拖慢认证。缓解：残差峰新生 + GNC + 权重剪枝 + 对称商合并；per-mode conformal 分摊 α；定期全量重初始化。
5. **conformal 在模式切换/分布漂移下失准**：per-mode 校准依赖模式内可交换性。缓解：分模式分视界校准、在线重校准、漂移检测（分位数漂移即重标定）；对模式切换用保守联合界。
6. **意图证据并不独立**：注视/手势与视觉共享场景原因，仍可能共因。缓解：循环指数 + 因果图显式混杂；优先使用语言/示范等更强外生证据；多源一致才提高置信。
7. **意图时变与实时滞后**：人随时改主意，MHP/INB 在语义流更新可能滞后。缓解：实时 KL 早停；`wait` 元技能；短认证前缀 `k*`；块首/块尾均做意图一致性检查。
8. **共因故障 + 意图欺骗叠加**：同一 OOD 物体同时骗视觉、几何与人的判断（例如伪装成常见物体并配以误导手势）。缓解：AIC-I 共因认证；不要求归因/意图正确，只要求包络覆盖或 `safe_idle`；引入第三个物理独立通道（IMU/本体感觉/触觉阵列）作为未来工作。
