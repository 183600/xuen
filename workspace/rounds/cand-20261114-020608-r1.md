# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「最优控制」×「人形机器人」）

> R69 问出了「该向谁求证、还能问什么」，把不确定性一分为二，用 VoI 决定看/问/触。但它对「值不值得问」的度量是**信息熵**——一种纯信息论、与任务代价无关的量。这留下两个洞：其一，熵减不等于收益，减掉一个与代价无关的模态可能毫无价值，而减掉一个能把机器人从摔倒边缘拉回来的模态价值连城；其二，R69 自陈的最大风险（流模型幻觉出幻影模态 → 自信地追问幻影 → 把「诚实的不知道」升级为「被证实的错误」）在熵框架下无解，因为幻觉模态和真模态在信息论上一样"干净"。
>
> 本轮两个灵感恰好补上：
> - **最优控制**给出一个比熵更对的 VoI 客体——**值函数 / 代价-to-go**。问的价值不是"熵降了多少"，而是"最优代价降了多少"；这正是 1960 年代 Feldbaum 的**对偶控制**：最优控制器天生就同时"控制"和"学习"。R69 的 MINT 只是对偶控制的一个熵启发式代理。
> - **人形机器人**给出两个具体化：多模态流里的"模态"就是**接触模式**（左脚/右脚/双手/推/撑/抓）；epistemic 不确定性的主要来源就是**接触/摩擦/负载/地形**；而"摔倒"是一个**吸收态**，所以 VoI 必须用风险敏感（CVaR）代价来量，且任何"为了知道而做的动作"都必须先证明自己不会把机器人弄倒。
>
> 核心命题：**把 R69 的信息论 VoI 换成控制论 VoI（值函数差），用最优控制的对偶性统一"做"与"问"；用可行性核/控制屏障把"幻觉模态"在物理层先剪掉（这条通道独立于流模型，不会和流模型一起幻觉）；再用风险敏感值函数把"摔倒吸收态"纳入代价，使"求证"必须自证安全。** 命名 **COVE-RAS**（Control-optimal Value of Epistemic information；同时取 cove「安全的港湾」= 可行性核）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**求证本身值多少、以及求证会不会先把我摔倒**」——知道的价值由代价-to-go 定价，知道的权利由可行性核担保。

## 0. 直觉与动机

**灵感 1（最优控制 → VoI 的正确客体是值函数，不是熵）**
直觉：R69 的 MINT 在比"哪个信息动作让模态熵降得最多"。但一个在悬崖边的人形机器人不会为了"降低对地面材质的熵"去低头看——它会先算：看清之后我能省下多少代价-to-go，而低头这个动作又让我多接近摔倒多少。熵是一个与任务无关的标量，值函数才是任务相关的裁判。最优控制早已把"信息"内化进 Bellman 方程：POMDP 的值函数 V(b)=max_a E[r+γV(b′)] 里，b′ 是贝叶斯更新后的信念；把"先观测再动作"与"直接动作"相减，差就是**信息的价值**。所以 VoI 不需要另造一个熵启发式，它就是值函数在信念上的差。更妙的是 Feldbaum 的**对偶控制**：最优控制器的控制量天然有两重作用——驱动状态（控制）与激励系统（学习）。R69 把这两者拼成一个增广动作空间，是一种"工程拼接"；对偶控制说它们本来就是同一个 Bellman 最优解的两个面。于是本轮的理论姿态是：**COVE 的 DCMPC 是 R69 MINT 的严格上游——当值函数退化为"熵代理"时，COVE 逐指令退化为 FLUID。**

**灵感 2（人形机器人 → 模态就是接触模式，epistemic 就是接触参数）**
直觉：R69 的流匹配策略在抽象动作空间里聚类出"模态"，但没说什么叫模态。对人形机器人，这个"模态"有明确的物理身份：**接触调度**——单脚支撑/双脚/腾空、左手抓/右手推/双手撑、脚掌全接触/脚尖。流模型采样出的几条差异很大的轨迹，本质是几种接触模式。对应地，epistemic 不确定性的头号来源不是"人类的表情"，而是**摩擦系数、负载质量、地形高度、接触刚度**——这些参数决定哪条接触模式可行。于是 R69 的"模态权重"在人形机器人上变成"接触模式后验"，"交互"变成"轻踏一脚测地面/推一下测负载/摸一下测刚度"。这不再是隐喻，而是可建模的 Bayes-adaptive 动力学。

**灵感 3（可行性 → 幻觉模态在物理层就被剪掉，而不是靠统计校准）**
直觉：R69 的 MCG 用 ECE 校准模态权重，但校准的前提是"真值可观测"；当流模型幻觉出一个根本不可行的模态时，校准层用的是同一类数据、可能一起被骗。人形机器人给了一条**完全独立**的通道：一条接触模式是否可行，是**动力学/接触几何**的事，与流模型是否幻觉无关。给定模式 σ，只要问"存在一条控制律，使系统在进入下一决策时刻前始终留在可行性核内吗？"——不存在就剪掉，不管流模型给它多高的权重。于是 R69 的"最大风险"有了一个不会被同源幻觉污染的答案：**先物理剪枝，再统计校准**。这也重新定义了 epistemic 消解：不是"让后验更尖"，而是"让可行域更明"。

**灵感 4（摔倒 = 吸收态 → 风险敏感代价，求证必须自证安全）**
直觉：熵对"灾难"和"小事"一视同仁。但人形机器人有一个吸收态：摔倒。一旦倒下，后续所有代价都失效，讨论"信息价值"毫无意义。所以 VoI 必须用**风险敏感**（CVaR/最坏情形）的代价-to-go 来量，而不是期望值；更关键的是，信息动作本身（俯身看、抬脚探、伸手摸）会改变可行性裕度。一个"高 VoI 但高摔倒风险"的探询是负资产。因此本轮铁律从 R69 的"VoI > 成本才问"升级为"**VoI > 成本、且探询动作本身在可行性核内、且其风险敏感增量 ≤ 0 ⟹ 才问**"。知道的权利，必须由安全来担保。

**灵感 5（包含关系与循环性 → 新层泛化旧层，但证书本身有自指风险）**
直觉：当值函数可由熵近似（信息单调、风险中性）时，COVE 的 V-VoI 退化为 FLUID 的熵 VoI；当没有可行的信息动作时，退化为 R69/R68 的纯保守。所以安全侧仍不让步。但本轮必须诚实地指出一个新洞：**可行性证书本身依赖模型，而"接触参数未知"正是我们要消解的 epistemic**——用一个"我们还不确定的模型"去证明"这次求证是安全的"，是一个自指循环。本轮必须把这条循环性摆到明面上（定义 326 与最大风险），并用"基线控制器 + 运行时监护"（Simplex/责任分离）把这个循环截断：探索只允许发生在"基线控制器总能兜住"的状态里。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（COVE-RAS 总览）** COVE-RAS = (FMP, AUD, VCOST, DCMPC, CMG, VCERT, CIP, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **可行性优先**：任何被执行的动作（任务或信息）必须位于某一认证可行性核 K_cert 内并保留裕度 ≥ m_min；摔倒为吸收态，禁止进入；
(iii) **值单调交互**：仅当风险敏感 V-VoI(g) > c(g) 且探询动作自身通过 CBF + 可行性核认证时才允许信息动作，否则逐指令退化到 R69/R68。

**定义 311（信念增广状态）** 状态 s = (x, σ, θ)：x ∈ ℝ^{n_x} 为浮动基 + 关节构型/速度；σ ∈ Σ 为接触模式（足/手接触指示）；θ ∈ Θ 为接触-动力学参数（摩擦 μ、负载 m、地形高度 h、接触刚度 k），带后验 p(θ)（高斯/粒子/集合）。决策在信念 b(s) 上进行，构成 Bayes-adaptive MDP（BAMDP）。

**定义 312（风险敏感代价-to-go）** 给定信念 b、策略 π：G^π(b) = Σ_t γ^t c(s_t,u_t) + c_fall·1[fall]。风险敏感值 V_ρ(b) = CVaR_α(G^π(b))（或 ρ-熵风险度量），V*_ρ(b) = min_π V_ρ(b)；ρ=1 记作普通期望值。摔倒代价 c_fall 取支配常数（吸收态，远超任何有限时域收益）。

**定义 313（控制论 VoI / V-VoI）** 对信息动作 g 与候选观测 y：
V-VoI(g) = V*_ρ(b) − E_{y|g,b}[ V*_ρ(b_g^y) ]，其中 b_g^y 为执行 g（含其物理位移）并观测到 y 后的后验。**ρ=1 时 V-VoI ≥ 0**（POMDP Bellman 的鞅性）；**ρ<1（CVaR/风险敏感）时 V-VoI 可能为负**——"多知道一点"因放大尾部风险反而更糟，此时控制器应主动**拒绝**该探询（定义 321）。这与 R69 的熵 VoI（条件熵恒 ≥ 0）有本质区别。

**定义 314（接触模式流与物理模态）** 流策略采样轨迹经聚类得模态 {m_k}；每个模态映射到接触调度 σ_k = ContactClassifier(m_k)（由足/手接触力阈值或接触几何判定）。模态权重 ŵ_k 在 CMG 之后重新归一化为**可行模态后验**。无合法接触调度的簇记为"幽灵模态"。

**定义 315（可行性核）** 对模型集合 ℳ（由 θ 后验诱导）与模式 σ，K_σ = {s : ∃π_σ, ∀t≥0, s_t ∈ 𝒮_safe}（控制不变集），可用 HJ 可达性、CBF 或采样验证近似；裕度 m(s) = min_t h(s_t)。**鲁棒核** K^rob_σ = ∩_{M∈ℳ} K_σ(M)。

**定义 316（可行性闸门 CMG）** 模态 σ_k 可采纳 ⇔ K^rob_{σ_k} 非空 且 当前 s ∈ K^rob_{σ_k} 且 m(s) ≥ m_min。CMG 只依赖动力学/几何，**不依赖 FMP 的概率输出**，因此与流模型幻觉不同源。输出可行模态集 ℱ 与可行比例 φ = Σ_{k∈ℱ} ŵ_k。

**定义 317（认证信息动作 CIP）** 信息动作 g 认证 ⇔ (a) g 的控制指令过 C-RAS-WM 前缀认证；(b) g 执行全程保持在 K^rob_{σ(g)} 内（CBF：ḣ + αh ≥ 0）；(c) 风险敏感增量 ΔV_ρ(g) = V_ρ(b | g) − V*_ρ(b) ≤ ε_probe。任一不满足 ⇒ g 作废，V-VoI 不采纳。

**定义 318（接触参数后验更新）** 探询 g 产生接触观测 y（足底力/触觉/音频/本体），似然 p(y|θ,g)（接触模型 + 摩擦锥）；后验 b′ ∝ p(y|θ,g)·b(θ)。用 Fisher 信息阵 J(θ) 衡量可辨识性。

**定义 319（对偶-MPC 目标）** 在时域 H 上求解
min_{u_{0:H}} E[Σ_t γ^t c(s_t,u_t)] + c_fall·P(fall) − β·V-VoI(u_info)
s.t. 动力学/接触互补约束、CBF（定义 317）、可行性核约束（定义 315）。β 为对偶增益；β=0 退化为纯最优控制（R69 保守边界），信息激励作为决策变量与任务控制联合求解（真正的对偶控制）。

**定义 320（值敏感 Fisher / 探针方向）** 探针方向 d 最大化**值相关**信息：J_V(d) = (∂V_ρ/∂θ)ᵀ J_θ(d) (∂V_ρ/∂θ)。只探"能改变代价-to-go"的方向（近摔倒边界探摩擦、搬重物探负载），不探与代价无关的方向。这是对 R69 VoI 的"任务相关性"修正。

**定义 321（风险敏感 VoI 的负号）** 若 V-VoI(g) < 0（"知道更糟"，尾部风险被放大）则禁止 g，即使其熵增益很大；U_epi 保持未消解，走 R69 兜底。专门对付"探询收益被 CVaR 反转"的病态情形。

**定义 322（值敏感模态选择）** 执行模态 σ* = argmin_{σ∈ℱ} V_ρ(b, σ)（在可行集内最小化风险敏感代价），平局由 V-VoI 与后验权重打破。R69 的 select_mode 是 ρ=1、ℱ=全部时的特例。

**定义 323（退化边界）** 当 (a) 风险中性 ρ=1，(b) V* 可由模态熵代理（值对模态呈对数/线性单调），(c) ℱ=全部模态（CMG 不过滤）时，V-VoI ≡ FLUID VoI，DCMPC ≡ MINT，COVE 逐指令退化为 FLUID。当 ℱ=∅ 或无合法 CIP 时退化为 R69/R68 纯保守。

**定义 324（自适应时域与预算）** 时域 H 与 DDP 迭代由值间隙 ΔV = V*_ρ − V_ρ(次优) 与可行裕度 m 自适应：裕度小 ⇒ 短时域、高频重规划（保护性）；裕度大且 V-VoI 高 ⇒ 允许探询时域。P99 预算由热启动 iLQR/DDP 保证。

**定义 325（证书 J_COVE）** J_COVE = (J_FLUID, viability_margin_p5, cvar_post, robust_mode_fraction φ, delta_theta_fisher, vvoi_before/after, certificate_model_set_hash, cove_ver)。Valid ⇔ Valid(J_FLUID) ∧ φ ≥ φ_min ∧ viability_margin_p5 ≥ m_min ∧ ΔV_ρ(g*) ≤ ε_probe。

**定义 326（运行时监护与自指截断）** 因可行性证书依赖模型集合 ℳ，而 ℳ 本身的正确性是 epistemic，定义"基线安全控制器 π_base"（独立验证的保护性停/蹲/抓扶）与运行时监护 σ_monitor：仅当 π_base 从当前 s 出发可兜住（s ∈ K_base，K_base 用最保守模型/解析近似得到）时才允许探索性 CIP；否则只用 π_base。这把"用不确定模型证明安全"的自指循环截断在"已独立验证的兜底集"内。

## 2. 关键算法骨架

```python
# IP-265 VCOST：风险敏感值函数（CVaR-DDP，热启动）
class RiskSensitiveValue:
    def value(self, b, sigma, H):
        # b=(x, theta posterior)；CVaR-DDP 求 V_rho(b)
        return cvar_ddp(self.dyn, self.cost, b, sigma, H, alpha=self.alpha)

    def value_gap(self, b, g, H):                       # 控制论 VoI
        v0 = self.value(b, b.sigma, H)
        return v0 - self.expected_value_after(b, g, H)  # E_y[V_rho(b_g^y)]

# IP-268 CMG：接触模式 + 可行性核闸门（独立于流模型）
def contact_mode_gate(modes, s, model_set):
    feasible = {}
    for k, m in modes.items():
        sigma = contact_classifier(m)                   # 轨迹 -> 接触调度
        K = robust_viability_kernel(sigma, model_set)   # ∩_{M in model_set}
        if K and s in K and margin(K, s) >= M_MIN:
            feasible[k] = sigma
    phi = sum(modes.w[k] for k in feasible)
    return feasible, phi                                # 幽灵模态在此被物理剪枝

# IP-267 DCMPC：对偶 MPC（任务控制 + 价值敏感的激励）
def dual_mpc(s, b, feasible, budget):
    def objective(u):
        J = expected_cost(s, u, b)
        if u.info is not None:
            J -= BETA * value.value_gap(b, u.info, H=budget.H)
        return J
    cons = [dynamics(s, u), contact_complementarity(u),
            cbf_constraint(s, u), viability_constraint(s, u, feasible)]
    return solve_ocp(objective, cons, warm_start=last_solution)  # iLQR/DDP

# IP-270 CIP：认证信息动作（CBF + 可行性核 + 风险敏感预算）
def certify_info(g, s, b):
    if not c_ras_wm.certify_prefix(g, s):     return False
    if not stays_in_viability(g, s, K_rob):   return False
    if not cbf_ok(g, s):                      return False
    if risk_delta(b, g) > EPS_PROBE:          return False
    return True

# IP-276 COVE 主闭环（继承 R69）
def COVE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) 物理剪枝：幽灵模态先过可行性核（独立通道）
    feasible, phi = M.cmg.contact_mode_gate(modes, s, M.model_set)
    if phi < PHI_MIN:
        return M.fallback_rcs(M, U_ale + U_epi)          # 退化 R69/R68
    # 2) 风险敏感值函数 + 控制论 VoI
    b = M.bstate.update(s, o)                            # 接触参数后验
    vvoi = M.vcost.value_gap(b, g_candidates, H=M.budget.H)
    # 3) 仅当值单调 + 探询自证安全才交互（对偶控制）
    g = M.dcmpc.choose_excitation(feasible, b, vvoi) if U_epi > TAU_EPI else None
    if g is not None and not M.cip.certify_info(g, s, b): g = None
    if g is not None and vvoi[g] <= 0:                   g = None  # 负 VoI 拒绝
    if g is not None:
        y = M.cip.execute(g); b = M.bstate.post_update(b, y, g)
        U_epi_after = M.bstate.residual_epi(b)
    else:
        U_epi_after = U_epi
    # 4) 风险缩放（继承 R68/R69）
    U_floor = U_ale + (U_epi_after if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 5) 执行：在可行模态内最小化风险敏感值
    sigma = select_mode_value_sensitive(feasible, M.vcost, b, lam)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(sigma, M.vista.H), ...)
    tau = M.pi_sigma.prefix_dispatch(sigma, k) * lam
    # 6) 参与式审计 + 证书（含模型集哈希，便于事后追责自指循环）
    M.vqa_d.submit_async(g, phi, vvoi, cert_hash=M.model_set.hash)
    return k, lam, sigma, (U_ale, U_epi_after), phi
```

## 3. 推导

**引理 19（风险中性 V-VoI 非负，风险敏感可负）** 对 ρ=1，POMDP Bellman 给出 V*(b)=max_a E[r+γV*(b′)]，"先观测后动作"的策略类包含"直接动作"的策略类，故 V-VoI ≥ 0。对 ρ<1（CVaR），价值不满足对观测的条件期望鞅性，存在 V-VoI < 0 的构造（尾部风险被信息"揭示"而非"消除"）。系：熵 VoI 恒 ≥ 0，故 R69 无法表达"知道更糟"；COVE 可以，因此更安全——它允许理性地**拒绝**一个高熵增益的探询。

**引理 20（可行性核剪枝的幻觉免疫）** 设流模型幻觉模态集 ℋ、真可行模态集 ℱ_true。CMG 只用动力学/几何（与 FMP 独立），故 P(σ∈ℋ 被执行) ≤ P(σ 被 CMG 误判为可行)，该概率与 FMP 的校准误差**独立**；即便 MCG 的 ECE 完全失效，只要 K^rob 计算可靠，幽灵模态仍被剪掉。系：这是对 R69「模态幻觉 → 自信追问」风险的**正交**防线——两条通道的失效模式不同源。

**引理 21（值敏感探针的信息效率）** 在局部线性-高斯/一阶接触模型下，探针方向 d 使后验协方差沿 ∂V_ρ/∂θ 方向收缩最多；单位能耗带来的代价-to-go 降幅 ≥ (∂V_ρ/∂θ)ᵀ J_θ(d) (∂V_ρ/∂θ) / E_energy(d)。系：只探值相关方向，杜绝"为知道而知道"；这与 R69 的熵 VoI 形成"任务相关 vs 任务无关"的对照。

**定理 18（COVE 严格包含 FLUID/R68）** 在 A99–A101（ρ=1、值-熵可比、ℱ=全部、模型集覆盖真值）下，COVE 的期望风险 ≤ FLUID；且满足定义 323 时两者逐指令相同。故 FLUID 是 COVE 在「熵代理值函数 + 物理不过滤」边界上的退化；安全侧因 CMG/CBF 只会更强。

**定理 19（求证安全与无突变）** 若 (a) g 通过 CIP 认证，(b) 真实模型属于模型集 ℳ，(c) 运行时监护生效，则执行 g 期间进入摔倒吸收态的概率为 0（在证书模型类内），且交互失败/超时/负 VoI 时 λ 单调不降地退化为 R69/R68；换装不变式（R68 定理 15）继承 ⇒ 控制连续、无突变。**注意前提 (b) 正是本轮最大风险所在。**

## 6. 本轮最大风险

**一句话**：COVE 的安全性全部押在**可行性核证书所假设的模型类 ℳ 覆盖了真实接触动力学**这一前提上——但"接触参数未知"恰恰是本轮要消解的 epistemic，于是我们用**一个还不确定的模型去证明"这次求证是安全的"**，构成自指循环；一旦真实模型滑出 ℳ（未建模的接触、突变摩擦、软地形），证书会在最需要它的时刻（机器人主动探询时）给出错误的"安全"背书——**求证越主动，越可能用自己的不确定性为灾难签字**。

**次级风险与缓解**：
1. **证书自指**（模型失配）→ 定义 326 运行时监护 + 独立验证的 π_base + 最保守 K_base；E308 专测失配；
2. **可行性核过保守**导致"永远不敢探" → 用可达性/采样近似 + 自适应裕度；E303 监控保守率；
3. **V-VoI 计算昂贵击穿实时** → 降频 + 热启动 + 增量估计 + 值网络摊销；
4. **风险敏感 VoI 的方差**导致错误拒绝 → 置信区间 + E315；
5. **接触模式分类错误** → 力/几何双阈值 + 与流模态交叉校验。

> **本轮结论一句话**：COVE-RAS 把「该不该问」从信息论问题升级为对偶最优控制问题——用代价-to-go 给知道定价、用可行性核给求证担保，并用一条不依赖流模型的物理通道正面回应 R69 的幽灵模态风险；但它的命门是**用不确定的接触模型去认证求证的安全性**这一自指循环。

```python
class RiskSensitiveValue:

# IP-268 CMG：接触模式可行性核闸门（独立于流模型）
def contact_mode_gate(modes, s, model_set):

        K = robust_viability_kernel(sigma, model_set)       # ∩_{M in model_set}
```

## 4. 推导

**引理 19（风险中性 V-VoI 非负，风险敏感可负）** ρ=1 时 POMDP Bellman 的鞅性给出 V-VoI ≥ 0；ρ<1（CVaR）时价值不满足对观测的条件期望鞅性，存在 V-VoI<0。系：熵 VoI 恒 ≥0，R69 无法表达"知道更糟"，COVE 可理性拒绝高熵增益的探询。

**引理 20（可行性核剪枝的幻觉免疫）** CMG 只用动力学/几何（与 FMP 独立），`P(幽灵模态被执行) ≤ P(CMG 误判)`，与 FMP 校准误差独立；即便 ECE 失效，只要 K^rob 可靠，幽灵模态仍被剪掉。系：对 R69「模态幻觉→自信追问」的**正交**防线。

**引理 21（值敏感探针效率）** 一阶接触模型下，探针方向使后验沿 ∂V_ρ/∂θ 收缩最多；单位能耗代价降幅 ≥ `(∂V/∂θ)ᵀ J_θ(d)(∂V/∂θ)/E_energy`。系：只探值相关方向，杜绝"为知道而知道"。

**定理 18（COVE 严格包含 FLUID/R68）** A99–A101（ρ=1、值-熵可比、ℱ=全部、模型集覆盖真值）下期望风险 ≤ FLUID；满足定义 323 时逐指令相同。FLUID = COVE 的「熵代理 + 物理不过滤」边界；安全因 CMG/CBF 只强不弱。

**定理 19（求证安全与无突变）** 若 g 过 CIP 认证、真实模型 ∈ ℳ、监护生效，则执行 g 期间进入摔倒吸收态概率为 0（证书模型类内）；失败/超时/负 VoI 时 λ 单调不降退化 R69/R68；换装不变式（R68 定理 15）保持 ⇒ 控制连续。**前提"真实模型 ∈ ℳ"正是本轮最大风险。**

## 7. 本轮最大风险

**一句话**：COVE 的安全性全部押在「可行性证书所假设的模型类 ℳ 覆盖了真实接触动力学」上——但"接触参数未知"恰恰是本轮要消解的 epistemic，于是我们用**一个还不确定的模型去证明"这次求证是安全的"**，构成自指循环；一旦真实模型滑出 ℳ（未建模接触、突变摩擦、软地形），证书会在最需要它的时刻给出错误的"安全"背书——**求证越主动，越可能用自己的不确定性为灾难签字**。

**次级风险与缓解**：证书自指（定义 326 运行时监护 + π_base + K_base；E308 专测模型失配）；核过保守导致"不敢探"（可达性/采样近似 + 自适应裕度；E303）；V-VoI 计算昂贵（降频 + 热启动 + 增量 + 值网络摊销；E312）；风险敏感 VoI 方差导致误拒（置信区间；E315）；接触模式分类错误（力/几何双阈值 + 与流模态交叉校验；E301–E302）。
