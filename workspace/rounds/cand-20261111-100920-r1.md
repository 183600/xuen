# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「双臂协调」×「真实世界泛化」）

> 第 54 轮已把技能组合提升为动作空间剖面 `α_S` + 云边协同 `γ_ce` + 动作-鲁棒性联合证书 `J`。本轮换一个视角：**从单臂/单技能的“绝对能力”转向双臂的“相对约束”，并把相对约束当作真实世界泛化的结构性先验**。核心矛盾：H22：双臂协调不是两个单臂技能相加，共享物体/相对位姿把系统约束到低维流形，单臂动作剖面在流形外失效；H23：真实世界泛化失败主要源于对绝对坐标/外观/相机外参等 nuisance「绝对量」的过拟合，而协调信号（相对位姿、互力、相位）天然是这些变换的不变量，但过度不变会抹除任务相关绝对信息。

## 0. 直觉与动机

**灵感 1（双臂协调 = 约束流形，而非动作空间的笛卡尔积）**
直觉：两只手单独都能到达的点，双手同时到达时未必可行——一旦共同持物或保持相对位姿，两臂就被锁成一个闭环运动链。可行配置不是 `A_L × A_R` 的全空间，而是被相对位姿约束 `h(q_L,q_R)=0` 切出的低维流形 `M_coord`。技能的动作剖面必须投影到这个流形上才有意义：单臂问的是“可达性”，双臂问的是“同时可达性 + 相对一致性”。

**灵感 2（协调兼容性：从动作重叠升级为相对连续）**
直觉：第 54 轮的 `compat` 只看两个技能动作集合的 Jaccard 重叠，对单臂够用；但双臂技能切换的失败点往往不在“动作是否重叠”，而在切换瞬间相对位姿是否连续、两臂相位是否同步、夹持力是否保持闭合。于是兼容性应升级为四元组：动作重叠、相对位姿 Lipschitz、相位同步、力闭合裕度，任一维塌陷都会让“看似兼容”的组合在执行时撕裂。

**灵感 3（相对不变量 → 泛化商空间）**
直觉：真实世界泛化差，常常是因为策略把“物体在世界坐标的绝对位置”“相机绝对外参”记成了特征。双臂协调恰恰提供了一组对全局 SE(3)、光照、相机位置近似不变的量：两臂相对位姿、互力、相位差。把这些量作为表征，等于把策略放到一个商空间里学习，泛化间隙应显著变小。但这是有代价的：若任务本身依赖绝对量（如把物体放到绝对目标点），商掉它就会发生“不变性坍塌”。

**灵感 4（泛化包络：不承诺无限泛化，只承诺有界域）**
直觉：真实世界泛化不可能无条件成立。工程上更靠谱的是给出一个“泛化包络”：在标定分布附近一个可检测的漂移半径内，风险上界可证明地不超过预算；一旦探针检测到漂移越界，就降级或重标定。这样泛化从一句口号变成一张可部署、可失效、可回滚的证书。

**灵感 5（协调-泛化对偶：协调刚度的双刃）**
直觉：协调约束越强（相对位姿锁得越死），有效自由度越低，样本复杂度越低、泛化界越紧；但约束过强会牺牲任务所需灵活性，带来偏差。于是存在一个最优协调刚度 `λ*`：**“协调到刚好够用”**。这把“要不要协调、协调多紧”从工程直觉变成可优化目标。

**灵感 6（协调探针：用双臂不一致做无标签的分布漂移检测）**
直觉：真实世界发生漂移时（物体变重、摩擦变化、相机偏了），双臂对同一共享物体的估计/执行会先出现不一致。这个不一致是对称性给出的“免费”误差信号，不需要标签。用共享物体上两臂位姿差 `p_t = ||T_L - T_R||` 或互力失配作为 test-time 漂移探针，可在任务失败之前提前报警。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（协调约束流形）**
双臂配置空间 `Q = Q_L × Q_R`，协调约束 `h: Q → ℝ^k`（相对位姿、闭链、共享物体抓取）。协调流形 `M_coord = { q ∈ Q | ‖h(q)‖_C ≤ ε_h }`，其中 `‖·‖_C` 为由柔顺/摩擦锥诱导的加权范数。双臂技能 S 的协调剖面 `α^⊗_S : M_coord → [0,1]`，`α^⊗_S(q) = α_S(q)·1[q∈M_coord]`。协调覆盖 `cover_⊗(S,Q_T)=1 ⟺ ∀q∈Q_T, α^⊗_S(q) ≥ θ_cov`。

**定义 122（协调兼容性与协调证书）**
协调兼容性四元组
```
compat_⊗(S_i,S_j) = ( o_ij, ℓ_ij, φ_ij, f_ij )
```
其中 `o_ij` 为流形共享片上的动作重叠，`ℓ_ij = exp(−Lip(h∘τ_ij))` 为切换轨迹 `τ_ij` 上相对位姿连续性，`φ_ij` 为相位同步度，`f_ij` 为力闭合裕度。协调边成立当且仅当 `min(o,ℓ,φ,f) ≥ θ_⊗`。协调证书 `C_coord = (o,ℓ,φ,f, M_ij, evidence)`，`M_ij = M_i ∩ M_j` 为共享协调流形片。

**定义 123（相对不变商空间与不变性债务）**
设 nuisance 群 `G_n`（全局 SE(3)、光照、相机外参、背景）作用于真实世界状态。表征 `φ: state → Z` 在 `G_n` 上不变：`φ(g·s)=φ(s), ∀g∈G_n`。技能在协调商空间 `Q_⊗ = Q / G_n` 上学习。若任务相关映射 `y` 不是 `G_n`-不变的，则不变性债务 `D_inv = E[‖(y∘φ^{-1})(φ(s)) − y(s)‖]`；部署要求 `D_inv ≤ Θ_inv`。

**定义 124（泛化包络与泛化债）**
泛化包络 `E_env = (D_cal, ε_shift, n_eff, δ_gen)`：标定域、漂移半径上界、有效样本量、允许泛化间隙。经验风险 `R_emp`，泛化债 `D_gen = R_test − R_emp − complexity_term`。若实测漂移 `d(D_test,D_cal) > ε_shift` 或 `D_gen > δ_gen`，则包络失效并触发重标定。部署判据：`d ≤ ε_shift ∧ D_gen ≤ δ_gen ∧ D_inv ≤ Θ_inv`。

**定义 125（协调刚度与有效维数）**
协调刚度 `λ ≥ 0`，软约束 `h_λ(q)=h(q)+λ^{-1}ξ`。有效维数 `d_eff(λ)=dim(M_coord)+r(λ)`，`r(λ)` 为剩余柔顺自由度，`∂d_eff/∂λ ≤ 0`。泛化界 `B(λ)=sqrt((d_eff(λ) log n + log(1/δ))/(2n)) + bias(λ)`，最优刚度 `λ* = argmin_λ B(λ)`。

**定义 126（协调-泛化联合证书）**
`K = (J, C_coord, Q_⊗, E_env, λ*, p_t)`：
- `J` 为第 54 轮动作-鲁棒性联合证书；
- `C_coord` 为协调证书；
- `Q_⊗` 为相对不变商空间表征；
- `E_env` 为泛化包络；
- `λ*` 为协调刚度；
- `p_t` 为协调探针统计量。
若 `J` 可部署、`cover_⊗` 成立、`E_env` 有效且 `D_inv ≤ Θ_inv`，则 `K` 判定「协调-泛化可部署」。

## 2. 关键算法 伪代码

### IP-121 CMM（Coordination Manifold Modeling）

```python
def coordination_manifold(skills, h, eps_h, sampler):
    M = {}
    for s in skills:
        pts = sampler.sample(s.action_set)
        M[s.id] = [q for q in pts if norm_C(h(q)) <= eps_h]
    return M

def coordination_profile(skill, M, theta_cov=0.8):
    return {q: skill.alpha.get(q, 0.0)
            for q in M if skill.alpha.get(q, 0.0) >= theta_cov}

def cover_tensor(skill, Q_T, theta_cov=0.8):
    return all(skill.alpha_tensor.get(q, 0.0) >= theta_cov for q in Q_T)
```

### IP-122 BCC（Bimanual Coordination Certificate）

```python
def coordination_compat(si, sj, tau_ij, force_model, theta_tensor):
    M_ij = si.M & sj.M
    o = jaccard_on_manifold(si.alpha, sj.alpha, M_ij)
    l = exp(-lipschitz(h, tau_ij))
    phi = phase_sync(si.phase, sj.phase)
    f = force_closure_margin(force_model, si, sj)
    ok = min(o, l, phi, f) >= theta_tensor
    return ok, C_coord(o, l, phi, f, M_ij, evidence=[tau_ij])
```

### IP-123 RIQ（Relative Invariant Quotient）

```python
def relative_invariant_representation(state, G_n, task_label):
    z = extract_relative(state)   # relative pose, mutual force, phase
    assert all(invariant(z, g, state) for g in G_n)
    D_inv = estimate_invariance_debt(z, task_label, G_n)
    return z, D_inv
```

### IP-124 GEC（Generalization Envelope Certificate）

```python
def generalization_envelope(calib, test_stream, n_eff, delta):
    d = distribution_distance(test_stream, calib.D)
    D_gen = estimate_test_risk(test_stream) - empirical_risk(calib)
    valid = (d <= calib.eps_shift) and (D_gen <= calib.delta_gen)
    return valid, E_env(calib.D, calib.eps_shift, n_eff, delta), D_gen
```

### IP-125 CGD（Coordination-Generalization Duality）

```python
def optimal_coordination_stiffness(n, delta, bias_fn, dim_fn, grid):
    best_B, best_lam = float('inf'), None
    for lam in grid:
        d_eff = dim_fn(lam)
        B = sqrt((d_eff*log(n) + log(1/delta)) / (2*n)) + bias_fn(lam)
        if B < best_B:
            best_B, best_lam = B, lam
    return best_lam, best_B
```

### IP-126 CPP（Coordination Probe Protocol）

```python
def coordination_probe(T_L, T_R, F_L, F_R, eps_shift, scale, F_scale):
    p = norm(T_L - T_R) / scale + norm(F_L - F_R) / F_scale
    if p > eps_shift:
        return 'shift_detected', p
    return 'nominal', p
```

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |

| CPP | O(1) | O(1) | 探针功效 ≥ 1−β_p |

**正确性定理（Coordination-Invariant Generalization Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `G_n` 作用良定义，`φ` 在 `G_n` 上不变且任务信息损失以 `D_inv` 有界；**(A30)** 协调约束估计误差 `‖ĥ−h‖ ≤ ε_h`；**(A31)** 协调探针对漂移 `d ≥ ε_shift` 的检测功效 `≥ 1−β_p`。
则对任意 `π ∈ Π`，以概率 `≥ 1−δ`：
```
R_test(π) ≤ R_emp(π) + sqrt((d_eff(λ)·log n + log(1/δ))/(2n))
            + bias(λ) + L_h·ε_h + D_inv + ε_shift·1[漏检]
```
当右端 `≤ R_budget` 且 `E_env` 有效时，`K` 判定部署 sound。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 相对表示抹除任务绝对信息（不变性坍塌） | 高 | 任务相关信息保留检验 + 绝对残差通道 |

## 6. 本轮最大风险

**一句话**：把双臂协调的相对不变量当作真实世界泛化的“免费午餐”，是本轮最大的诱惑也是最大的风险——一旦 nuisance 群里混入任务相关的绝对信息，商空间就会发生不变性坍塌（越协调越不泛化），而协调约束的估计误差又会沿闭链放大；因此必须以 **任务相关信息保留检验 + ε_h 入证书 + λ* 自适应 + 协调探针哨兵** 四重护栏，宁可保留一条绝对残差通道，也不把“相对化”当作泛化的充分条件。

| BCC | O(\|S\|²·\|M\|) | O(\|S\|²+\|E\|) | 四元阈值全维 sound，无误兼容 |
| RIQ | O(\|Z\|+\|G_n\|·\|Z\|) | O(\|Z\|) | 不变性可验证，D_inv 可估 |
| GEC | O(n_eff) | O(\|D_cal\|) | 漂移度量与风险界一致 |
| CGD | O(\|Λ\|·log n) | O(\|Λ\|) | d_eff 单调、bias 可估、λ* 最优 |
| CPP | O(1) | O(1) | 探针功效 ≥ 1−β_p |

**正确性定理（Coordination-Invariant Generalization Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `G_n` 作用良定义，`φ` 在 `G_n` 上不变且任务信息损失以 `D_inv` 有界；**(A30)** 协调约束估计误差 `‖ĥ−h‖ ≤ ε_h`；**(A31)** 协调探针对漂移 `d ≥ ε_shift` 的检测功效 `≥ 1−β_p`。
则对任意策略 `π ∈ Π`，以概率 `≥ 1−δ`：
```
R_test(π) ≤ R_emp(π) + sqrt((d_eff(λ)·log n + log(1/δ))/(2n))
            + bias(λ) + L_h·ε_h + D_inv + ε_shift·1[漏检]
```
关键：**协调先验降低有效维数**，**相对表征缩小 nuisance 依赖**，**泛化包络与协调探针把“未知漂移”变成可检测、可降级的失效模式**。

## 5. 本轮最大风险

**一句话**：把双臂协调的相对不变量当作真实世界泛化的“免费午餐”，是本轮最大的诱惑也是最大的风险——一旦 nuisance 群里混入任务相关的绝对信息，商空间就会发生不变性坍塌（越协调越不泛化），而协调约束的估计误差又会沿闭链放大；因此必须以 **任务相关信息保留检验 + ε_h 入证书 + λ* 自适应 + 协调探针哨兵** 四重护栏，宁可保留一条绝对残差通道，也不把“相对化”当作泛化的充分条件。
