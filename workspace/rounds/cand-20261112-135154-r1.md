# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮（新周期）；本轮灵感：「课程学习」×「安全对齐」）

> 第 57 轮把承诺的资格证做成了"少样本可校准、跨模态可对账、个性化有界"，并诚实地把最大风险写成"坏先验普遍"：语料没见过的世界，元模型会自信地错。但第 57 轮仍把每个承诺当成**孤立的考试**来判——它只问"这一次证据够不够"，不问两个更上位的问题：**(a) 系统凭什么先遇到这个区域？** 没有课程的系统可能把最难的不可逆接触排在第一天，也可能永远在自己擅长的简单地形里刷证据，把"坏先验盲区"越养越大；**(b) 就算证据充分，系统凭什么保证行为仍符合人类声明的约束与偏好？** 证据门是"允许下注"的局部许可，不是"行为对齐"的全局保证——它无法阻止规格博弈（specification gaming）、奖励黑客（reward hacking）与"对齐到一个写错的宪法"。本轮两个灵感各补一层：**课程学习**把"先学什么、何时进阶、如何考试"变成可审计的进阶结构——难度是前置关系、进阶靠掌握证书、分布外先当"旁听课"（仅 L1）而不是直接承诺；**安全对齐**把"不许做什么"写成不参与学习的硬宪法、把偏好模型关在硬约束之内、把"拒止/绕行/降档/上课"升格为一等动作，并给拒止加单调性与"预算饥饿不降标"（no-starvation）。核心命题由"证据承诺"升级为 **"课程可进阶、宪法不可越、拒止可举证的安全承诺"**。

核心矛盾：
- **H29（课程 vs 覆盖）**：课程把证据集中到可达的、较易的区域，越学越深，却可能把最难、最分布外的区域永远排除在课程之外——进阶曲线越漂亮，盲区越危险；单调进步很容易退化成"安全剧场"。
- **H30（对齐 vs 规范）**：对齐只能对齐到一份**写下来的人类宪法**；宪法本身不完备、会漂移，偏好模型在新分布上会 OOD，优化器会绕过偏好模型去刷奖励——对齐到错误的目标比不对齐更危险，因为它自带合法性。
- **H31（拒止 vs 可用）**：安全拒止与可用性是一对反向成本；拒止门槛若与剩余预算耦合，系统会在快没时间时自己降标；若过度保守，则"什么都不做"本身成为失败模式。
- **H32（自定进度 vs 考试完整性）**：自定进度学习进度可被刷简单题伪造，掌握考试可被"应试"（teaching to the test）污染；一旦考试与晋级同源，课程就在自己证明自己。

## 0. 直觉与动机

**灵感 1（课程学习 → 部署课程与能力前沿）**
直觉：没有人第一天就去滑黑道。课程学习说三件事：**先易后难、掌握再进阶、难度有前置关系**。机器人部署本身就是一门课程：把区域/任务按难度与风险排成前置 DAG，维护一条"能力前沿"；未掌握的高难区域只能"上课"——以 L1 非不可逆探针/影子模式见识它，而不是直接拿不可逆接触去赌。进阶需要**掌握证书**（成功率下置信界过线 ∧ 本地证据门通过 ∧ 一场密封考试），失败要**连坐降级**（该区域及其所有后继一起回炉）。这把第 57 轮"坏先验盲区"从"某天突然踩到"改造成"被安排在某节课里先见识、先校准"。

**灵感 2（课程学习 → 自定进度，但防刷题）**
直觉：课程不能写死，因为系统不知道自己哪里不会。自定进度按**学习进度** LP（单位风险成本换来的不确定性下降）选下一课；但"自选"天然可博弈——反复刷简单课也能让 LP 好看。因此 LP 必须在**留出集**上估计、对重复课做边际递减、并强制前置覆盖。自定进度是探索，不是刷分。

**灵感 3（安全对齐 → 宪法式硬约束与受限偏好）**
直觉：对齐不是"把人类偏好拟合进奖励函数就完事"——奖励函数一定会被 hack。安全对齐最硬的教训是：**硬约束不参与学习**。把"不许做什么"写成声明式宪法 H，由独立监视器逐动作检查，带版本与红队；偏好模型 p_ψ 只允许在 H-可行集内排序，且自己有校准与 OOD 门——偏好模型一旦 OOD，就退回保守序并更倾向拒止。宪法是笼子，偏好是笼子里的排序，优化器永远碰不到笼子。

**灵感 4（安全对齐 → 拒止是一等动作，且不因预算饿死而降标）**
直觉：对齐系统最重要的动作常常是"不做"。把拒止（安全停/绕行/降档/L1 上课）升格为一等动作，并强制两条性质：**单调性**（更不确定/更高风险只会更拒止，不会更放行）与**预算饥饿不降标**（剩余预算只决定"还探不探"，绝不决定"证据够不够"）。否则时间一紧，系统就会悄悄把门槛调低——这是最像人的、也最致命的对齐失败。拒止也要双向校准：既不漏拒（假承诺），也不滥拒（假拒止把可用性杀光）。

**灵感 5（合流 → 课程-对齐证据门 CAG 与 PCA 算子）**
直觉：证据门新增两类证据——**EV-exam**（外部密封留出考试）与 **EV-align**（宪法通过 + 偏好遗憾有界）；并加两道与证据**正交**的闸：课程准入闸（没到前沿就是不能 L2）与宪法闸（H 不过就一票否决，无论证据多充分）。承诺 = 证据 ∧ 课程 ∧ 对齐，三者缺一即拒；拒止只经"更保守"通道起作用，延续第 56 轮的交互单调性。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（部署课程 DCL）** 课程图 G=(R,E,d̂,μ_req)，E⊆R×R 为前置 DAG，d̂(r)∈[0,1] 为元先验难度（含认知不确定性），μ_req(r) 为区域要求成功率。已掌握集 M⊆R，前沿难度 D(M)=max_{r∈M}d̂(r)。准入谓词 Adm_Δ(r)=[∀r'≺r:r'∈M] ∧ [d̂(r)≤D(M)+Δ_step]。掌握证书 m(r)=1 ⇔ LCB_δ(μ(r))≥μ_req(r) ∧ FSE_57(r)=ok ∧ Exam(r)=pass。**课程规则**：未掌握但准入的区域仅可进入"上课模式"（L1 探针/影子，禁不可逆）；不可逆接触 L2 要求 r∈M ∨ (Adm_Δ(r) ∧ 本地 FSE_57 通过)；考试/承诺失败 ⇒ M←M∖(desc(r)∪{r})（连坐降级）。

**定义 140（自定进度课程 SPC）** 学习进度 LP(r)=[H(b_r)−E H(b_r|lesson)]/(cost(r)+λ_R·Risk(r))，其中 H 为区域信念熵；重复课乘边际递减 γ^{n_r}（n_r 为已上课次数），LP 一律在**留出集**估计。选课 r\*=argmax_{r∈Adm_Δ∪∂M} LP(r)−λ_r Risk(r)，受覆盖约束（每类前置至少覆盖一次）与第 57 轮全部安全约束。**防刷题**：γ<1、留出估计、覆盖下界三者同时生效。

**定义 141（宪法式安全对齐 CAF）** 宪法 𝒞=(H,≺_p,Ref,ver)：H 为有限条硬安全不变量（禁无证据 L2、力上界、τ_int、预算饥饿不改阈等）；≺_p 为人类反馈学到的偏好前序；Ref 为拒止规则。行为策略 π、轨迹 τ，对齐集 Π_𝒞={π:∀τ~π,τ⊨H ∧ π 在 H-可行集内取 ≺_p 极大 ∧ 未定义时默认拒止}。对齐缺口 A(π)=P_τ(τ⊭H)+Regret_{≺_p}(π)。偏好模型 p_ψ 带校准 ECE≤ε_p 与 OOD 门 n_ψ>θ_ψ；OOD ⇒ 切保守序 + 触发拒止。**硬约束由独立监视器 M_H 检查，不参与学习、不可被 p_ψ 覆盖、带版本与红队。**

**定义 142（拒止对齐 RAL）** 拒止动作集 Act_ref={safe_stop,reroute,degrade,L1_lesson}。拒止集 Ref(s) 由证据不足、未缓解 OOD、对齐风险、课程未准入共同决定。**单调性**：若 s' 在不确定/风险上占优于 s，则 Ref(s)⊆Ref(s')。**预算饥饿不降标（no-starvation）**：承诺谓词 C(s) 不依赖剩余预算 B 与课程进度，B 只进入探询调度。**拒止校准**：P(refuse|应承诺)≤ε_fr（滥拒），P(commit|应拒止)≤ε_cr（漏拒）。

**定义 143（课程-对齐证据门 CAG）** 证据类扩充为 EV-probe\*/EV-visit/EV-margin/EV-xmodal(限 L1)/EV-human/EV-exam/EV-align。过门 ⇔ (第 57 轮 FSE 全部条件) ∧ 课程准入 ∧ 对齐证书有效；不可逆接触额外要求 M_H 通过且不含 EV-xmodal。EV-exam 必须来自**外部密封留出集**（随机抽题、仅用一次、与晋级判定不同源）；EV-align 由 J_a=(H 审计通过、偏好遗憾≤ε_p、p_ψ 非 OOD) 构成。证书 J_ca=(J_p,J_c,J_a)，J_c 为课程掌握证书。

**定义 144（探-课-诺-演+ 算子 PCA / PCE++）** 每检查点：①元推断（ID→摊销后验/OOD→共形带）；②跨模态对账（D>θ_D 先发共识探针）；③课程检查：未准入 ⇒ 只许 L1 上课并记 lesson 证据，禁 L2；④宪法检查：M_H 不过或 p_ψ OOD ⇒ 直接拒止/降档；⑤承诺 ⇔ 证据门 ∧ 课程准入 ∧ 对齐有效；否则按 VOI_元悲观 + LP 选下一动作（探针/上课）；⑥探尽→绕行→降档→L2 协商（τ_int(auth)）→安全停；⑦周期抽取密封考试，失败则连坐降级。

## 2. 关键算法伪代码（完整版见产物区）

```python
def curriculum_gate(r, M, exam):                     # IP-139
    if not all(p in M.mastered for p in G.preds(r)): return 'reject', 'prereq'
    if G.d(r) > G.frontier(M) + Delta_step:          return 'reject', 'above_frontier'
    if r in M.mastered:                              return 'ok', 'mastered'
    return 'lesson_only', 'admitted_not_mastered'    # 只能 L1 上课

def align_gate(trace, C, p_psi, monitor):            # IP-141
    if not monitor.H_ok(trace):                      return 'reject', 'constitution'
    if p_psi.ood(trace):                             return 'reject', 'pref_ood'
    if p_psi.regret(trace) > eps_p:                  return 'reject', 'pref_regret'
    return 'ok', 'aligned'

def refuse_gate(s, evidence, budget):                # IP-142: 预算不参与判定
    if not evidence.ok:                 return 'refuse', 'evidence'
    if s.ood_unmitigated:               return 'refuse', 'ood'
    if s.curriculum != 'ok':            return 'refuse', 'curriculum'
    if s.alignment != 'ok':             return 'refuse', 'alignment'
    return 'commit', 'ok'                            # budget 不出现在此函数
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DCL | O(\|E\|) 前置检查 | O(\|R\|+\|E\|) | 前置 DAG 无环、掌握用 LCB、连坐降级 |
| SPC | O(\|R\|·\|H\|)/选课 | O(\|R\|) | LP 留出估计、边际递减、覆盖下界 |
| CAF | O(\|H\|·\|τ\|) 审计 | O(\|H\|+d_ψ) | H 不学习、监视器独立、p_ψ 校准+OOD |
| RAL | O(1) | O(\|Ref\|) | 单调、no-starvation、双向校准 |
| CAG | O(\|σ\|) | O(\|σ\|) | 双正交闸、EV-exam 密封、EV-align 可审计 |
| PCA | O(\|CP\|·(k_p+k_c+k_l)·C_VOI+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|R\|) | 四态完备（承诺/上课/绕行/拒止）、终止 |

**正确性定理（CSS：Curriculum-Aligned Safe Soundness）概要**：在 A33–A40（第 56–57 轮）上增加 (A41) 课程健全：前置 DAG 覆盖真实依赖、难度估计有界误差、考试来自外部密封留出集且与晋级不同源；(A42) 对齐诚实：H 版本固定且监视器漏检 ≤δ_H、偏好模型 ECE≤ε_p 且 OOD 漏检 ≤δ_ψ；(A43) 拒止性质：单调且 C(s) 与预算无关；(A44) 反博弈：LP 留出估计、重复课递减、覆盖下界。则：(i) 本地承诺健全性继承 CCPS，并叠加课程错误贡献 δ_cur（越级/误晋级）；(ii) 课程健全性：若 r∈M 则真实成功率 ≥μ_req(r)（w.p.≥1−δ_m），前提是 A41 的考试无偏；(iii) 对齐健全性：宪法违反率 ≤δ_H+δ_ψ，偏好遗憾 ≤ε_p；(iv) 预算饥饿不降标：降低 B 不改变承诺谓词，故不产生新的升险路径；(v) 课程 DAG 有限 + 每检查点步数有限 ⇒ PCA 终止于 {承诺,上课,绕行,降档,拒止}。

## 6. 本轮最大风险

**一句话**：课程与对齐若共用同一套自证逻辑，就会形成"自己出题、自己判卷"的闭环——系统只在它自选的难度顺序上看起来安全，却永远不被最难、最分布外的区域证伪；一旦难度估计或宪法本身有盲点，越漂亮的进阶曲线越是安全剧场，必须以外部密封对抗考试、宪法版本化红队、拒止双向校准三重外部性打破闭环。

### IP-139 DCL（部署课程与连坐降级）

```python
def curriculum_gate(r, M, G, Delta_step):
    if any(p not in M.mastered for p in G.preds(r)):
        return ('reject', 'prereq')
    if G.d(r) > G.frontier(M) + Delta_step:
        return ('reject', 'above_frontier')
    if r in M.mastered:
        return ('ok', 'mastered')                     # 可 L2（仍需证据门）
    return ('lesson_only', 'admitted_not_mastered')   # 只许 L1 上课

def promote_or_demote(M, r, exam, fse_ok, tau_delta):
    lcb = M.lcb(r, delta=tau_delta)
    if lcb >= G.mu_req(r) and fse_ok and exam.pass_:
        M.mastered.add(r)                            # 掌握证书
    else:
        M.mastered -= ({r} | G.descendants(r))       # 连坐降级
        M.lessons[r] += 1                            # 回炉
    return M
```

### IP-140 SPC（自定进度 + 反刷题）

```python
def next_lesson(M, G, heldout):
    best, arg = -inf, None
    for r in G.admitted(M) | G.frontier_set(M):
        lp = (heldout.H(r) - heldout.H_after_lesson(r)) / (cost(r) + lam_R*risk(r))
        lp *= (gamma ** M.lessons[r])                # 边际递减，防刷简单课
        score = lp - lam_r * risk(r)
        if score > best and coverage_ok(r, M):        # 前置类覆盖下界
            best, arg = score, r
    return arg
```

```python
def align_gate(trace, C, p_psi, monitor):
    if not monitor.H_ok(trace):                      # 硬约束：不可学习/不可覆盖
```

```python
def refuse_gate(s, evidence, budget):
    # 注意：budget 仅为签名对齐，绝不出现在任何阈值/判定中（no-starvation）
    if not evidence.ok:      return ('refuse', 'safe_stop', 'evidence')
    if s.ood_unmitigated:    return ('refuse', 'L1_lesson', 'ood')
    if s.curriculum != 'ok': return ('refuse', 'L1_lesson', 'curriculum')
    if s.alignment != 'ok':  return ('refuse', 'reroute', 'alignment')
    return ('commit', 'ok', None)

def refusal_calibrate(history):
    fr = P(refuse | should_commit, history)
    cr = P(commit | should_refuse, history)
    return fr <= eps_fr and cr <= eps_cr                # 双向校准
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DCL | O(\|E\|) 前置检查；降级 O(\|desc\|) | O(\|R\|+\|E\|) | DAG 无环、LCB 掌握、连坐降级（A41） |
| SPC | O(\|R\|·\|H\|)/选课 | O(\|R\|) | LP 留出估计、边际递减、覆盖下界（A44） |
| CAF | O(\|H\|·\|τ\|)/审计 | O(\|H\|+d_ψ) | H 不学习、监视器漏检≤δ_H（A42） |
| RAL | O(1) | O(\|Ref\|) | 单调、C(s)⊥B、双向校准（A43） |
| CAG | O(\|σ\|) | O(\|σ\|) | 课程闸+宪法闸正交、EV-exam 密封 |
| PCA | O(\|CP\|·(k_p+k_c+k_l)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|R\|) | 五态完备、k_p+k_c+k_l 终止 |

**正确性定理（Curriculum-Aligned Safe Soundness, CSS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 课程健全：前置 DAG 覆盖真实依赖、难度估计误差有界、考试取自外部密封留出集且与晋级判定不同源；**(A42)** 对齐诚实：宪法版本固定且独立监视器漏检 ≤δ_H，偏好模型 ECE≤ε_p 且 OOD 漏检 ≤δ_ψ；**(A43)** 拒止性质：Ref 单调且承诺谓词 C(s) 与预算 B 无关；**(A44)** 反博弈：LP 在留出集估计、重复课边际递减、覆盖下界生效。则：

1. **本地承诺健全性**：继承第 57 轮 CCPS，额外叠加课程错误贡献 δ_cur（误晋级/越级），即 P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+δ_cur。
2. **课程健全性**：若 r∈M，则真实成功率 ≥μ_req(r)（w.p.≥1−δ_m），**其有效性完全取决于 A41 的考试无偏**；否则证书只是自我安慰。
3. **对齐健全性**：宪法违反率 ≤δ_H+δ_ψ；偏好遗憾 ≤ε_p；规格博弈被 H 闸隔离在偏好层之外。
4. **预算饥饿不降标**：因 C(s) 不含 B，减小 B 只减少探询次数、不改变承诺阈值，故不产生新的升险路径。
5. **终止性**：课程 DAG 有限、每检查点 k_p+k_c+k_l 有限 ⇒ PCA 终止于 {承诺,上课,绕行,降档,拒止}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1] + δ_cur + δ_H + δ_ψ)
             − P(考试完整性失效) − P(宪法版本漂移未检出) − P(护盾回退失败)
```

关键：**课程给顺序、考试给外部性**（关键不是"学了多久"，而是"被谁考过"）；**宪法给笼子、偏好给笼内排序**（优化器碰不到笼子）；**拒止给默认安全、no-starvation 给抗压力**（时间压力不得改变证据标准）。

## 6. 本轮最大风险

**一句话**：课程与对齐若共用同一套自证逻辑，就会形成"自己出题、自己判卷"的闭环——系统只在它自选的难度顺序上看起来安全，却永远不被最难、最分布外的区域证伪；一旦难度估计或宪法本身有盲点，越漂亮的进阶曲线越是安全剧场，必须以外部密封对抗考试、宪法版本化红队、拒止双向校准三重外部性打破闭环。
