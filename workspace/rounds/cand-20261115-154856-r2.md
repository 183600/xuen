# 第 8 轮（灵感循环第 2 轮；本轮灵感：「大语言模型」×「多视角视觉」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER v7（定义 493–529；引理 73–76；实验 E513–E525）。
> **本轮纪律**：LLM 只编译契约、不产生动作；多视角只提供几何证据、只能收紧；两者共同门控 v7 的在线适应（OTL/ER）。任一组件失效，必须**单跳退回 v7**，不允许级联。
> **与 v7 的差别**：v7 用在线学习与情感权重直接改“判据/价值”，适应本身缺少独立的可信度证据；本轮引入**语言契约**（要做什么的正式规格）与**多视角共识**（看到的几何是否支持它）作为两道外部证据，只有证据足够时才允许 v7 的适应通道开门。

## 0. 直觉与动机

**灵感 1（大语言模型 → 会写工单的工程师，而不是直接操机的人）**
直觉：让人用自然语言说“把桌上那只红色杯子拿给我，别碰倒旁边的碗”，LLM 最擅长的不是输出关节力矩，而是把这句话整理成一张**可检查的工单**：目标物体、属性、空间关系、禁忌、完成判据。工单可以盖章（schema 校验）、可以复核（安全细化检查）、可以退回重写。只要规定“LLM 的输出类型里根本没有动作字段，只有契约字段”，那么 LLM 的幻觉最坏也只是写出一张**不合规或过紧的工单**，被校验器拒掉，而不是让机器人做出危险动作。核心创新：**语言契约编译（Language Contract Compiler, LCC）**。

**灵感 2（多视角视觉 → 多个证人交叉作证）**
直觉：单目视觉像一个证人，可能把反光、透明、遮挡看错；多目视觉像多个证人，关键不是“谁更清楚”，而是“他们的证词是否在三维空间中对得上”。把每个视角的检测反投影到同一个三维假设，重投影残差、双视角可见覆盖率、遮挡一致性就构成一张**几何共识证书**。共识高不代表一定对，但共识低一定意味着“现在不该激进”。核心创新：**多视角共识证书（Multi-View Consensus, MVC）**。

**交叉直觉（语言先验 × 几何验证 = 互相作保）**
LLM 能凭语言先验消歧（“红色那只”“碗后面的”），但会幻觉出一个不存在的物体；多视角几何能确认“那里确实有一个三维物体、尺寸可抓、没有遮挡”，但不知道用户到底指哪一只。把两者做成**双向蕴含**：LLM 契约里的每个指称与假设，必须被多视角场景图支持；多视角给出的候选物体，必须能被契约类型系统接纳。两边都对上，才把 v7 的适应门打开；任一边对不上，就退回 v7 的保守行为或向用户澄清。这样把 v7 最大风险“过度适应导致退化频率不稳”，改写成“**证据门控的适应**”。

## 1. 研究问题（轮次升级版）

- **Q1（契约编译的可靠性）**：如何把自然语言指令编译成带类型的任务契约 `C = (g, Φ, A, τ_spec, u_L, π, TTL)`，使其只可能**收紧**而不能放松 v7 的 `M₀/M₁`，并在有时限的慢层内完成？
- **Q2（多视角共识的可校准性）**：如何定义带覆盖率、遮挡惩罚与协方差传播的共识分数 `a_mv`，并用校准集给出误接受率上界；相机丢失或视角不足时如何保守退化？
- **Q3（跨模态蕴含与澄清）**：如何形式化“多视角场景图 `S_mv` 支持契约假设 `A`”的支持度 `ρ`，并设计接受/澄清/退化三态门，使错误指称的接受概率有界？
- **Q4（证据门控与组合退化）**：如何用 `(u_L, a_mv, ρ)` 乘性门控 v7 的 OTL/ER 适应强度，并证明 LCC/MVC/VEG 任一失效时系统在**一个控制周期内**等价于 v7？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P14）

**P10 契约编译（Language Contract Compiler, LCC）**
LLM 的输出被限制为结构化契约，且契约必须通过 schema 与安全细化检查：
```
C_raw = LLM(prompt(ℓ_voice, obs_summary))     # 只允许返回契约 JSON
C     = Project(C_raw, C_v7)                  # 类型检查 + 单调收紧投影
Valid(C) ⇔ SchemaOK(C) ∧ SafeRefine(C, C_v7)  # 失败则 C ← C_v7
```
契约中没有 `action`/`torque`/`velocity` 字段；`Project` 对阈值只做 `max(τ_raw, τ_v7)`（按“越大越保守”统一符号），对未接地目标一律替换为 `g₀`。

**P11 多视角共识证书（Multi-View Consensus Certificate, MVC）**
每个视角给出检测与掩码，反投影到统一世界坐标，做协方差交叉与鲁棒三角化：
```
Cert_mv = (x̂, Σ̂, a_mv, cov₂, V_used, t, hash)
a_mv = exp(−mean_v r_vᵀ Σ_v⁻¹ r_v) · cov₂ · (1 − occ)
```
其中 `r_v` 为重投影残差，`cov₂` 为“至少两视角可见”的目标表面比例，`occ` 为遮挡不一致惩罚。证书只用于**收紧**：`a_mv` 低时冻结适应，而不是生成新动作。

**P12 视觉蕴含门（Visual Entailment Gate, VEG）**
从多视角融合结果构造三维场景图 `S_mv`，逐条核对契约假设 `A`：
```
ρ(S_mv, A) = min_{a_j ∈ A} P(attr(o_j)=val_j | S_mv, evidence)
```
三态决策：`ρ ≥ 1−δ_fa` 接受；`δ_clar ≤ ρ < 1−δ_fa` 要求澄清或重写契约；`ρ < δ_clar` 退化到 `C_v7` 或 `ι₀`。

**P13 证据门控适应（Evidence-Gated Adaptation, EGA）**
适应强度由一个乘性门控制，门只能减小、不能放大 v7 原有的适应量：
```
α_ad(t) = clip( w_u·(1−u_L) + w_a·a_mv + w_ρ·ρ − c, 0, 1 )
θ_OTL(t) ← α_ad(t) · θ_OTL(t)        # OTL 增量被门控
β_ER(t)  ← α_ad(t) · β₀             # 情感影响被门控
```
`α_ad = 0` 时 `τ(t) = τ(0)`、`β = 0`，逐项等价于 v7 名义状态。

**P14 单跳退化路由（One-Hop Degradation Router, DR）**
固定优先级：`LCC 不可用/超时/非法 ⇒ C = C_v7`；`MVC 视角不足 ⇒ a_mv = a_single`（协方差膨胀、阈值提高）；`VEG 弃权 ⇒ 本周期不改契约且 α_ad = 0`；全部失效 ⇒ 精确 v7。禁止“LLM 用语言解释去绕过几何证据”，也禁止“几何自信去改写语义目标”。

## 3. 与基线的接口（如何退化）

- LCC 失效（模型不可达、超时、schema/安全校验失败）⇒ 契约取模板 `C_v7`，等价于 v7 的语音类型化指令；
- MVC 失效（相机少于 2 路、标定过期、共识低于阈值）⇒ 退化为单视角 + 膨胀不确定度，`α_ad` 上限压到 `α_single`，最终等价于 v7 的保守适应；
- VEG 失效（场景图不可用、支持度落在弃权带）⇒ 不修改契约、关闭本周期适应，等价于 v7 冻结态；
- EGA 失效（门控计算异常）⇒ 强制 `α_ad = 0`，仍等价于 v7；所有退化均为**单跳**，不经过中间不稳定态。

## 4. 预期贡献

1. **语言契约编译**：把 LLM 从“动作生成器”改造为“可校验的规格编译器”，从类型层面阻断幻觉改写安全约束。
2. **多视角共识证书**：给出带覆盖率、遮挡惩罚与误接受率上界的几何证据，可作为在线适应之外的独立“证人”。
3. **视觉蕴含三态门**：把“用户到底指哪只”从隐式假设变成可接受/可澄清/可退化的显式决策。
4. **证据门控适应**：为 v7 的 OTL/ER 增加可信度刹车，目标是把“过度适应导致的退化频率”降下来，同时不牺牲正常场景的适应收益。
5. 完整实验 E526–E542：契约注入攻击、视角丢失、相关失效、澄清率、端到端竞赛与组合退化等价性。

## 5. 本轮最大风险

**一句话**：最大风险是“相关失效伪装成共识”——同一块反光/透明表面可同时骗过所有相机，而 LLM 的语言先验又会为这个错误指称编出一套自洽的契约，于是 `a_mv` 与 `ρ` 同时偏高、门控在最需要保守的新场景反而打开。

# 第 8 轮产物 · 创新点清单 v8：**MetricVoiceGauge-LCC-MVC**（Language Contract Compiler + Multi-View Consensus）

> **背景**：第 7 轮 MetricVoiceGauge-OTL-GC-ER v7（定义 493–529；引理 73–76；实验 E513–E525）。
> **本轮灵感**：「大语言模型」×「多视角视觉」。
> **继承纪律**：v7 六不变式（CVC-闭环、SpatialCert、RT-CVC 任务模型、FaultCert 闭环、PrimitiveGraph 接地、严格退化链）与 OTL/GCT/ER 三增强全部保留。本轮新增组件一律为**可选证据层**：LCC 只写契约，MVC/VEG 只给证据，EGA 只做乘性门控；任一环节不可用 ⇒ 单跳退回 v7。

- `LCC/CSV` 失败 ⇒ `C ← C_v7`，语音类型化与指标层级仍按 v7 运行；
- `MVC/AVS` 失败 ⇒ `a_mv ← a_single`（协方差膨胀、阈值提高），`α_ad ≤ α_single`；
- `VEG` 弃权 ⇒ 本周期不修改契约且 `α_ad ← 0`，v7 参数保持名义值；
- `EGA` 异常 ⇒ 强制 `α_ad ← 0`；
- 四项全失效 ⇒ **精确等价** v7（`τ=τ(0)`、`β=0`、`C=C_v7`）。

**定义 530（任务契约 TaskContract）** 契约是六元组加时效：
```
C = (g, Φ, A, τ_spec, u_L, π, t_c, TTL)
```
其中 `g ∈ G` 为 PrimitiveGraph 上可接地的目标；`Φ` 为可判定片段内的时序/几何约束（STL/MTL + 线性不等式）；`A = {a_j = (o_j, attr_j, val_j)}` 为指称与属性假设；`τ_spec` 仅允许给出 `M₁,M₂,M₃` 的收紧阈值；`u_L ∈ [0,1]` 为经校准的 LLM 不确定度；`π = (model_id, prompt_hash, seed)`；`TTL` 为有效期。契约**良构**当且仅当 `SchemaOK(C) ∧ g ∈ G ∧ Φ` 可判定。

**定义 531（安全细化偏序 SafeRefinement）** 设阈值统一按“越大越保守”编码，则
```
C ⪯_safe C_v7  ⇔
  (i)   g ∈ G(C_v7)
  (ii)  τ_0(C) = τ_0(C_v7)
  (iii) ∀ i ∈ {1,2,3}: τ_i(C) ≥ τ_i(C_v7)   （逐分量）
  (iv)  Φ(C) ∧ M₀ ⇒ Φ(C_v7)
  (v)   Allowed(C) ⊆ Allowed(C_v7)
```
`Project(C_raw, C_v7)` 只执行以下四类操作：补默认字段、拒绝未知字段、把 `τ_i` 替换为 `max(τ_i^raw, τ_i^v7)`、把未接地 `g` 替换为 `g₀(C_v7)`。因此 `Project` 的输出若通过良构检查，必然满足 `(i)–(iii)`；`(iv)(v)` 由校验器显式检查。

**定义 532（语言契约编译器 LCC）** 编译器是带超时的映射
```
LCC: (ℓ_voice, o_summary) ↦ (C, ok, log)
C_raw = LLM(prompt(ℓ_voice, o_summary); schema)
C     = Project(C_raw, C_v7)
ok    = SchemaOK(C) ∧ C ⪯_safe C_v7 ∧ (now − t_c ≤ TTL)
```
若超时、解析失败或 `ok = False`，输出 `(C_v7, False, reason)`；LLM 在任何路径上都不返回动作。

**定义 533（多视角几何观测 MultiViewObservation）** 对视角集合 `V`，每路给出检测 `d_v`，把掩码像素按 `T_v,K_v` 反投影为射线族 `{r_{v,p}}`。对视角对 `(v,v')` 做鲁棒三角化得到 `x_{vv'}` 与协方差 `Σ_{vv'}`，再用协方差交叉融合：
```
Σ̂⁻¹ = Σ_v ω_v Σ_v⁻¹,   x̂ = Σ̂ (Σ_v ω_v Σ_v⁻¹ x_v)
```
其中 `ω_v` 按视角覆盖与检测置信度归一化。

**定义 534（多视角共识证书 ConsensusCertificate）**
```
r_v = π(T_v x̂) − b_v
a_mv = exp( − (1/|V|) Σ_v r_vᵀ Σ_v⁻¹ r_v ) · cov₂ · (1 − occ)
Cert_mv = (x̂, Σ̂, a_mv, cov₂, V_used, t, H(o))
```
`cov₂` 为目标所需表面中至少两视角可见的比例；`occ` 为不同视角对同一像素给出互斥深度/类别的比例。阈值 `a*` 在独立校准集上按分裂保形预测选取，使得在“三维假设错误”条件下 `P(a_mv ≥ a*) ≤ δ_mv`。

**定义 535（视角覆盖与主动选视 ActiveViewSelector）** 设候选视角集合 `V_all`、可选上限 `k`、单视角延迟 `τ_v`、预算 `B_view`。覆盖函数
```
f(V') = E[ 可见目标表面中至少两视角覆盖的比例 ]
```
`f` 单调子模；选视问题为 `max_{V'⊆V_all, |V'|≤k, Σ τ_v ≤ B_view} f(V')`，用贪心得到 `(1−1/e)` 近似。

**定义 536（视觉蕴含支持度 VisualSupport）** 三维场景图 `S_mv = (O, R, P_attr)`，其中 `P_attr(o, attr, val)` 为校准后的属性概率。契约假设集 `A` 的支持度
```
ρ(S_mv, A) = min_{a_j ∈ A} P_attr(o_j, attr_j, val_j | S_mv, Cert_mv)
```
若 `A` 中某物体在 `S_mv` 中不存在，则该项支持度定义为 0。

**定义 537（证据门控适应 EvidenceGatedAdaptation）** 设校准阈值 `u*`、`a*`、`δ_clar`，定义
```
α_ad(t) = clip( w_u·(1 − u_L) + w_a·a_mv + w_ρ·ρ − c, 0, 1 ),  Σ w = 1
θ_OTL^gated(t) = α_ad(t) · θ_OTL(t)
β_ER^gated(t)  = α_ad(t) · β₀
```
门控是**乘性**的：`α_ad ≤ 1`，所以任何时刻的适应量都不超过 v7 未门控时的适应量；`α_ad = 0` 时输出 v7 名义参数。

**定义 538（复合证书 CompositeCertificate）**
```
Cert_LM = (C, Cert_mv, ρ, α_ad, π, t_c, TTL)
```
只有当 `C ⪯_safe C_v7`、`a_mv ≥ a*`、`ρ ≥ 1−δ_fa` 且 `t − t_c ≤ TTL` 时，`Cert_LM` 才标记为 `certified`；否则标记 `degraded` 并记录失败原因。

**定义 539（单跳退化路由 DegradationRouter）** 路由按固定优先级执行：
```
D(state) =
  C_v7,                    if LCC timeout / SchemaOK=false / ¬SafeRefine
  (C, a_single, α_single), if |V_used| < 2 ∨ calibration_expired
  (C, a_mv, 0),            if VEG = CLARIFY / ABSTAIN
  (C, a_mv, α_ad),         otherwise
```
任一路径都在一个控制周期内完成，不保留中间“半适应”状态。

**定义 540（契约-几何闭环标识）**
```
Φ_LCC-MVC = { C ⪯_safe C_v7,  a_mv ≥ a*,  ρ ≥ 1−δ_fa,  α_ad > 0 }
Φ_v7     = { C = C_v7,       a_mv = ⊥,     ρ = ⊥,         α_ad = 0 }
```

**定义 541（时效与新鲜度 Freshness）** 契约与共识证书均带 `TTL`；若 `now − t > TTL`，视为证据过期，`D` 路由到 `C_v7` 且 `α_ad = 0`。这防止慢层 LLM 在场景已变化后仍以旧契约开门。

## 2. 形式化定义（要点复述）

**定义 530′（契约合法性）** `Valid(C) ⇔ SchemaOK(C) ∧ C ⪯_safe C_v7`。注意：`Valid` 不要求 LLM “说得对”，只要求它“说得不更危险”；语义正确性由 VEG 另门校验。

**定义 534′（共识的保守性）** `a_mv` 对视角数单调不降（视角增加至多降低平均残差、提高 `cov₂`），对遮挡与重投影残差单调不增；因此 `a_mv` 是“证据变多则不应更悲观”的一致统计量。

**定义 537′（门控的零化性质）** 当 `u_L ≥ u*` 或 `a_mv < a*` 或 `ρ < δ_clar` 之一成立时，强制 `α_ad = 0`；这是硬零化，不依赖线性组合的数值巧合。

```python
# IP-351/352 LanguageContractCompiler + ContractSchemaValidator
class ContractCompiler:
    def __init__(self, llm, schema, baseline_contract, timeout_ms=120):
        self.llm = llm
        self.schema = schema
        self.C0 = baseline_contract          # C_v7
        self.timeout_ms = timeout_ms

    def compile(self, utterance, obs_summary):
        t0 = now_ms()
        try:
            raw = self.llm.complete(
                build_prompt(utterance, obs_summary),
                schema=self.schema, timeout_ms=self.timeout_ms)
        except TimeoutError:
            return self.C0, False, "llm_timeout"
        if not self.schema.validate(raw):
            return self.C0, False, "schema_fail"
        C = self.project(raw, self.C0)
        if not (self.schema.validate(C) and safe_refine(C, self.C0)):
            return self.C0, False, "not_safe_refinement"
        C["t_c"] = now_ms()
        return C, True, "ok"

    def project(self, raw, C0):
        """只补默认、拒未知、收紧阈值、替换未接地目标"""
        C = {}
        C["g"] = raw.get("g") if raw.get("g") in C0["G"] else C0["g"]
        C["A"] = [a for a in raw.get("A", []) if self.schema.is_assumption(a)]
        C["Phi"] = C0["Phi"] | self.schema.decidable_subset(raw.get("Phi", []))
        C["tau_spec"] = {
            i: max(raw.get("tau_spec", {}).get(i, C0["tau_spec"][i]),
                   C0["tau_spec"][i]) for i in (1, 2, 3)
        }
        C["tau_spec"][0] = C0["tau_spec"][0]      # M0 永不被 LLM 改写
        C["u_L"] = calibrate_uncertainty(raw)
        C["pi"] = provenance(raw)
        C["TTL"] = C0["TTL"]
        return C


def safe_refine(C, C0):
    if C["g"] not in C0["G"]:
        return False
    if C["tau_spec"][0] != C0["tau_spec"][0]:
        return False
    if any(C["tau_spec"][i] < C0["tau_spec"][i] for i in (1, 2, 3)):
        return False
    if not implies(C["Phi"] and M0, C0["Phi"]):
        return False
    return allowed_set(C) <= allowed_set(C0)


# IP-353/354 MultiViewConsensus + ActiveViewSelector
class MultiViewConsensus:
    def __init__(self, calibrator, k_views=3, latency_budget_ms=3.0):
        self.calibrator = calibrator
        self.k = k_views
        self.budget = latency_budget_ms

    def select_views(self, candidates, target_surface):
        # 覆盖率函数单调子模；预算内贪心
        chosen, spent = [], 0.0
        for v in sorted(candidates, key=lambda v: v.expected_gain, reverse=True):
            if len(chosen) >= self.k or spent + v.latency > self.budget:
                continue
            if self._marginal_gain(chosen + [v], target_surface) <= 1e-3:
                continue
            chosen.append(v)
            spent += v.latency
        return chosen

    def certify(self, views, target):
        if len(views) < 2:
            return self._single_view(views[0] if views else None, target)
        obs = [detect_and_backproject(v) for v in views]
        x_hat, Sigma_hat = robust_fuse(obs)
        resid = mean_reprojection_residual(obs, x_hat)
        cov2 = two_view_visible_fraction(obs, target)
        occ = occlusion_inconsistency(obs)
        a_raw = exp(-resid) * cov2 * (1.0 - occ)
        a = self.calibrator.lower_confidence(a_raw)
        return Cert_mv(x_hat, Sigma_hat, a, cov2, views, now_ms())

    def _single_view(self, view, target):
        cert = single_view_estimate(view, target)
        cert.Sigma_hat *= 4.0           # 协方差膨胀
        cert.a_mv = self.calibrator.single_view_lower(cert)
        return cert


# IP-355 VisualEntailmentGate
class VisualEntailmentGate:
    def __init__(self, delta_fa=0.01, delta_clar=0.30):
        self.delta_fa = delta_fa
        self.delta_clar = delta_clar

    def decide(self, scene_graph, contract):
        rho = min(support(scene_graph, a) for a in contract["A"]) \
              if contract["A"] else 1.0
        if rho >= 1.0 - self.delta_fa:
            return "ACCEPT", rho
        if rho >= self.delta_clar:
            return "CLARIFY", rho
        return "DEGRADE", rho


# IP-356 EvidenceGatedAdapter
class EvidenceGatedAdapter:
    def __init__(self, w_u=0.3, w_a=0.4, w_rho=0.3, c=0.15,
                 u_star=0.2, a_star=0.7):
        self.w_u, self.w_a, self.w_rho, self.c = w_u, w_a, w_rho, c
        self.u_star, self.a_star = u_star, a_star

    def gate(self, u_L, a_mv, rho):
        if u_L >= self.u_star or a_mv < self.a_star:
            return 0.0                       # 硬零化
        alpha = (self.w_u * (1.0 - u_L) + self.w_a * a_mv
                 + self.w_rho * rho - self.c)
        return clip(alpha, 0.0, 1.0)

    def apply(self, otl, er, alpha):
        otl_delta = alpha * otl.pending_delta()
        er_beta = alpha * er.beta0
        return otl_delta, er_beta


# IP-357/358 主闭环集成（关键片段）
def metricvoicegauge_round_8(M, s, obs, audio_stream=None, ell=None,
                             lcc=None, mvc=None, veg=None, ega=None):
    # 0) 慢层：契约编译（不阻塞 50Hz 快层）
    if lcc is not None:
        C, ok, log = lcc.compile(ell or "", summarize(obs))
    else:
        C, ok, log = M.C_v7, False, "lcc_off"

    # 1) 快层：多视角共识（50Hz 内完成，<=3ms）
    if mvc is not None:
        views = mvc.select_views(obs.cameras, obs.target_surface)
        cert_mv = mvc.certify(views, obs.target_surface)
    else:
        cert_mv = M.cert_single_conservative(obs)   # a_single
    a_mv = cert_mv.a_mv

    # 2) 视觉蕴含门
    if veg is not None:
        decision, rho = veg.decide(M.scene_graph, C)
    else:
        decision, rho = "DEGRADE", 0.0

    # 3) 证据门控 + 单跳退化
    if ega is not None and ok and decision == "ACCEPT":
        alpha = ega.gate(C["u_L"], a_mv, rho)
        otl_delta, er_beta = ega.apply(M.otl, M.er, alpha)
    else:
        C, alpha, otl_delta, er_beta = M.C_v7, 0.0, 0.0, 0.0

    if decision == "CLARIFY":
        M.request_clarification(C, rho)            # 不冒险执行新契约
        C, alpha, otl_delta, er_beta = M.C_v7, 0.0, 0.0, 0.0

    # 4) 继承 v7：使用 C、门控后的 tau/beta 跑指标层级与软证书
    return M.run_v7(C, s, obs,
                    tau_override=M.otl.apply(otl_delta),
                    beta_override=er_beta,
                    evidence=(cert_mv, rho, alpha, C))
```

## 4. 推导

**引理 77（契约编译安全性）** 若 `LCC` 返回 `ok = True`，则 `Allowed(C) ⊆ Allowed(C_v7)` 且 `M₀` 判据与 v7 完全一致；因此 LLM 的任何幻觉都不能放松硬安全约束。证明：`ok` 要求 `SchemaOK ∧ SafeRefine`；`Project` 将 `τ₀` 固定为 `τ₀(C_v7)`，并对 `τ₁–τ₃` 取逐分量 `max`；`Allowed` 的单调性由定义 531(v) 保证。最坏情况是输出被拒并退回 `C_v7`。

**引理 78（共识误接受上界）** 在场景与校准样本可交换、校准集独立于测试集的假设下，按定义 534 的分裂保形阈值 `a*` 满足
```
P( a_mv ≥ a*  ∧  三维假设错误 ) ≤ δ_mv + O(1/√n_cal)
```
证明：保形预测给出错误假设分数的边际覆盖率上界；`a_mv` 是分数 `−log a_mv` 的单调变换；有限样本修正项来自分裂保形的经验分位数。

**引理 79（视觉蕴含三态风险）** 若 `P_attr` 经校准且 `δ_fa < δ_clar`，则 VEG 的 `ACCEPT` 分支错误接受指称的概率不超过 `δ_fa`，`DEGRADE` 分支不会执行未经几何支持的契约；`CLARIFY` 分支的最坏后果是一个控制周期的任务延迟。证明：由 `ρ = min_j P_attr` 与并集界，任一假设错误时被接受要求所有假设同时过阈值；`ACCEPT` 条件 `ρ ≥ 1−δ_fa` 直接给出单假设错误概率上界，取最小值的并集界再乘 `|A|`，故实现中取 `δ_fa ← δ_fa/|A|`。

**引理 80（门控非扩张性）** 由于 `α_ad ∈ [0,1]` 且门控只乘在 v7 的适应增量上，任意时刻 `|θ_OTL^gated| ≤ |θ_OTL|`、`|β_ER^gated| ≤ β₀`。因此 v7 的不变安全集不被门控破坏，且到达硬退化边界所需步数不少于 v7。证明：OTL 更新是增量式，`θ^gated(t) = α(t)·θ(t)`；当 `α=0` 时参数停在 `τ(0), β₀`，即 v7 名义点。

**引理 81（主动选视近似比）** 定义 535 的覆盖函数 `f` 是单调子模的，预算约束下的贪心选视满足 `f(V_greedy) ≥ (1−1/e)·OPT`。证明：双视角可见覆盖是集合覆盖函数的期望，集合覆盖单调子模；带预算的贪心对子模最大化有经典 `(1−1/e)` 保证；延迟约束按单位价值/延迟排序后保持同一近似界。

**引理 82（单跳退化等价性）** 若 LCC、MVC、VEG、EGA 中任一组件不可用，定义 539 的路由在至多一个控制周期内把状态置为 v7 的对应名义模式；当全部不可用时，系统轨迹与 v7 **逐状态等价**。证明：逐项检查路由的四个分支，每个分支显式设置 `C=C_v7`、门控为零或单视角保守证书；分支之间互斥且无中间状态，故不产生级联退化。

**引理 83（慢快分离的实时性）** 若 `latency(LCC) ≤ 120ms` 且 `latency(MVC) + latency(VEG) + latency(EGA) ≤ 4ms`，则 50Hz 快层 WCET 由 v7 的 22ms 增至至多 26ms，满足 20ms 周期约束需要将 LCC 放在独立慢线程并以双缓冲读取 `C`。证明：快层只读已发布契约，MVC 的选视与融合在 `k ≤ 3` 时为常数级；LCC 不在快层关键路径。

## 8. 本轮最大风险

**一句话**：最大风险是“相关失效伪装成共识”——同一块反光/透明表面可同时骗过所有相机，而 LLM 的语言先验又会为这个错误指称编出一套自洽的契约，于是 `a_mv` 与 `ρ` 同时偏高、门控在最需要保守的新场景反而打开；因此下一轮必须把“跨模态证据的条件独立性检验”作为一等公民，而不是假设语言与几何天然独立。
