# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「协同控制」×「基准测试」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC 把「认知驱动的场景落地」做成闭环：场景先验提前收敛阻抗、意图即时锁定约束、ROS 证据防丢包。但**三个更深的局限**被暴露：
> 1. **单智能体假设**：SSM/CIEC/SERC 全部默认「一个机器人、一条执行流、一个 K_safe」。真实协作场景（双臂搬运、交接、人机共融）中，两台机器人**各自局部安全**的阻抗组合起来可能**联合超力、共振、互相激励失稳**——安全不是逐点的，而是**联合可行域**的性质。
> 2. **缺乏可证伪的共同标尺**：E187–E191 的阈值是自定的、场景是自选的、报告只给均值。没有外部对照、没有置信区间、没有留出/对抗集，任何「提升」都可能只是**基准过拟合**。一个不能被基准判别的创新点，本质上不可验证。
> 3. **证据的跨流因果缺口**：EPIR 只保证**单流 seq 连续**；但协同执行中 A 的推挤导致 B 的滑移，两条 EV-exec 流之间存在 **happens-before** 依赖。若只校验各自 seq，云端会看到「两条都连续、但因果对不上」的假完整证据链。
> 4. **协同与评估的耦合陷阱**：一旦把「基准失败场景」回流为训练场景，就会形成自我强化的闭环——分数上升，但泛化与判别力下降。**基准必须能审计基准自己。**

## 0. 直觉与动机

**灵感 1（协同控制 → 分布式阻抗共识 DIC）**
直觉：单机 K_safe 是「我的安全」，协同安全是「我们的安全」。两台机械臂在共享工作空间里各自选了一个「局部最优」的阻抗，但共享接触力预算 F_shared 是耦合的、刚度矩阵的特征模态是耦合的——局部最优叠加可能是全局危险。协同控制的本质是：**在只有局部信息的条件下，用有限轮次通信达成联合可行的一致决策**。做法是把每个 agent 的可行阻抗集 K_i 当作凸约束，把共享力预算当作耦合线性约束，用 ADMM/一致性平均逼近交集 ∩K_i 中的共识解 K*；并显式保留**共识残差 ρ_cons** 与**联合安全裕度 CSM**，残差大或裕度为负就说明「我们其实没有达成共识」。

**灵感 2（协同控制 → 协同控制契约 CCC）**
直觉：协同不是简单平均，而是**角色与责任的显式契约**。主从、对等、人机共融三类协同的力分配、时延容忍、失效接管完全不同。把第 59 轮的 ERTC 单方实时契约升级为**多方契约**：每个 agent 声明 (角色, 阻抗能力, 力预算, 时基偏差, 失效策略)，系统做契约一致性检查，用**互斥令牌**防止多个 leader 同时改写共享约束，用 **wait-for 图**做死锁检测。契约违约不是异常，而是**一等公民**——必须有确定性的接管路径。

**灵感 3（协同安全裕度 CSM）**
直觉：「每台都安全」不等于「整体安全」。协同安全至少需要三件事同时成立：总接触力不超共享预算、每个 agent 的局部安全裕度不为负、联合刚度矩阵不出现**危险的低频共振模态**。因此 CSM 不是标量加权，而是**三个约束的联合最小松弛量**；任一为负，DIC 的共识解就必须被否决，而不是被平均掉。

**灵感 4（协同控制 + 证据 → 协同证据因果图 CECG）**
直觉：协同执行产生的证据天然是**偏序**，不是全序。A 的「推」在 B 的「滑」之前发生（happens-before），这层因果不能靠各自的时间戳猜。用**向量时钟 + 因果父指针 + 哈希**把 EPIR 的「单流连续」升级为「跨流因果一致」：每条 EV-exec 携带 causal_parent 与 vector clock；云端检验的不是 seq 加一，而是**向量时钟支配关系**与因果图可达性。这样「两条流都完整但因果断裂」就会被显式检出。

**灵感 5（基准测试 → 协同执行基准 CEB）**
直觉：没有基准，协同创新无法证伪。但基准不是「跑几个任务报个分」，而是**一套可复现、可判别、可对抗的实验协议**：任务电池（协作搬运/交接/共同装配/人机共融/故障接管）× 场景库（训练/验证/留出/对抗四分离）× 扰动注入（延迟、丢包、摩擦突变、刚度漂移、意图噪声）× 统计协议（配对检验、Bootstrap 置信区间、效应量、功效分析）× 可复现清单（代码哈希、种子、ROS bag、硬件画像）。基准的最终产物不是排行榜，而是**可审计的证据包**。

**灵感 6（基准测试 → 元基准与反事实回放）**
直觉：基准本身要被检验。若所有方案都能拿高分，说明基准**没有判别力**；若对无关扰动也剧烈波动，说明**不稳定**；若只看测试集，说明可能**过拟合**。元基准用判别力 D、敏感性 S、稳定性 St、过拟合指数 BOF 四个量给基准「打分」。反事实回放 CXB 则把历轮（第 58–60 轮）的证据包在新版本上重放，做**时间维度的 A/B**，捕捉「新能力牺牲旧能力」的隐性回归。

**灵感 7（合流 → 协同基准闭环 CBL，但装三把闸门）**
直觉：协同控制产生协同证据 → 基准暴露协同失效模式 → 失效模式回流为新压力场景 → 协同策略改进。这个闭环很自然，但极其危险：它会把「基准」变成「训练集」，分数上升而真实能力不升。因此必须加三道闸门：**(i) 留出/对抗集必须同步提升**；**(ii) 元基准判别力 D 不得下降、BOF 不得越界**；**(iii) 反事实回放不得出现显著回归**。三闸全过，才允许把新场景纳入训练。核心原则：**协同可以妥协，安全不能平均；基准可以进化，判别力不能自噬。**

## 1. 形式化定义（增量：定义 161–168）

**定义 161（分布式阻抗共识 DIC）** 设 N 个 agent，各自局部可行阻抗集
K_i = {K | SIC_valid_i(K) ∧ ||F_i(K)|| ≤ F_i^max}，
共享接触力预算约束 Σ_i F_i(K_i) ≤ F_shared。共识问题为
```
min_{K_1..K_N}  Σ_i ||K_i − K_i^local||²_{W_i}
s.t.  K_i ∈ K_i,  Σ_i F_i(K_i) ≤ F_shared
```
用 ADMM 求解：
```
K_i^{t+1} = Π_{K_i}(K_i^local + u_i^t − z^t)
z^{t+1}   = Π_{∩K_i ∧ F_shared}( (1/N)·Σ_i K_i^{t+1} )
u_i^{t+1} = u_i^t + K_i^{t+1} − z^{t+1}
ρ_cons    = ||z^{t+1} − z^t|| / (||z^t|| + ε)
```
当 ρ_cons ≤ ε_cons 或 t ≥ T_cons 终止。称 z 为共识阻抗，ρ_cons 为共识残差。**注意：DIC 的输出只有在 CSM ≥ 0 时才被接受**，否则返回 JOINT_INFEASIBLE，而不是把危险解「平均」出来。

**定义 162（协同控制契约 CCC）** 契约元组 C_op = (A, Roles, Φ_share, T_sync, Ξ_fail, Token)。其中：
- **A** = {a_1, …, a_N}，**Roles** ∈ {leader, follower, peer, human}
- **共享力分配**：F_i = Φ_share(role_i, capacity_i)，且 Σ_i F_i ≤ F_shared
- **时基同步**：要求 ∀i,j |clock_i − clock_j| ≤ δ_t（δ_t 默认 5 ms）
- **失效策略**：Ξ_fail ∈ {transfer, degrade, safe_stop}，违约时按角色优先级确定性接管
- **令牌**：同一时刻至多一个 leader 持有写共享约束的 Token；用 wait-for 图 G_wait 检测环路，检测到即 `_break_cycle()` 并触发 Ξ_fail
- **一致性检查**：`compatible = (单 leader) ∧ (clock_skew ≤ δ_t) ∧ (Σ F_budget ≤ F_shared)`；不兼容时回退到「最保守公共子集」K_conservative = ∩_i K_i^{min}。

**定义 163（协同安全裕度 CSM）** 给定 K = (K_1,…,K_N)：
```
CSM(K) = min{ (F_shared − Σ_i F_i) / F_shared,
              min_i margin_i(K_i) / margin_i^nom,
              λ_gap(K) }
```
其中 λ_gap 为联合刚度矩阵 J = Σ_i K_i 的最小特征值间隔（用于排除低频共振模态，λ_gap < λ_min 判为危险）。**联合可行域** J = {K | ∀i K_i ∈ K_i, Σ F_i ≤ F_shared, CSM(K) ≥ 0, ρ_cons ≤ ε_cons}。只有当共识解落在 J 内，才允许下发执行。

**定义 164（协同证据因果图 CECG）** CECG = (V, E_hb, E_cf)。其中：
- **V**：EV-exec 事件节点 (agent_id, seq_id, timestamp, vclock, causal_parent, hash)
- **E_hb**：happens-before 边，由向量时钟支配关系判定：e₁ →hb e₂ ⇔ vclock(e₁) < vclock(e₂)（逐分量 ≤ 且至少一个 <）
- **E_cf**：反事实依赖边，「若无 e₁ 则 e₂ 不会发生」，用于协同归因
- **跨流缺口**：若收到 e 但 vclock(e) 不支配其声明的 vclock(parent)+δ，判为 CAUSAL_GAP
- **协同证据完整率**：η_ev = |可重建的 E_hb| / |真实 E_hb|。

**定义 165（协同执行基准 CEB）** CEB = (T, S, P, M, Σ_stat, R)。其中：
- **任务电池 T** = {协作搬运, 交接, 共同装配, 人机共融, 故障接管}
- **场景划分 S** = S_train ∪ S_val ∪ S_test ∪ S_adv，且四者两两不交，S_adv 为对抗生成分布
- **扰动协议 P** = {通信延迟, 丢包, 摩擦突变, 刚度漂移, 意图噪声}
- **指标向量 M** = {cooperation_success, CSM_min, consensus_time, η_ev, recovery_rate, tail_latency_p99}
- **统计协议 Σ_stat**：配对 Wilcoxon 检验、Bootstrap 95% CI、Cohen's d、功效 ≥ 0.8；**禁止只报均值**
- **可复现清单 R** = {git_hash, seeds, ROS bag, 硬件画像, 参数快照, 随机源}

**定义 166（元基准判别力 BDC 与过拟合指数 BOF）** 给定一组能力已知的方案 P：
```
D    = P(score(A) > score(B) | A 真优于 B)          # 判别力（AUC 形式）
S    = ∂score / ∂capability                          # 敏感性斜率
St   = Var(score | 无关扰动)                         # 稳定性
BOF  = (score_train − score_test) / (score_train + ε) # 过拟合指数
```
**元基准门** Gate_meta = (D ≥ τ_D) ∧ (S ≥ τ_S) ∧ (St ≤ τ_St) ∧ (BOF ≤ θ_BOF)。只有通过 Gate_meta 的基准才允许用于模型选择；否则其结论降级为「参考」。

**定义 167（反事实回放审计 CXB）** 给定历轮证据包集合 E_hist，新版本 v_new：
```
CXB(v_new, E_hist) = { (pkg, metric, Δ) | Δ = v_new[pkg.scenario][metric] − pkg.metrics[metric],
                        Δ < −δ_reg 且 Δ 的 95% CI 不含 0 }
audit_score = 1 − |回归项| / |全部可比指标项|
```
回放必须在**固定种子、固定硬件画像、固定 ROS bag** 下进行，否则不构成反事实对照。CXB 用于检测「新协同能力以旧能力为代价」的隐性回归。

**定义 168（协同基准闭环 CBL）** 算子 CBL(M, C_op, CEB, E_hist)：
```
① DIC: (K*, ρ_cons) ← distributed_impedance_consensus(A, F_shared)
② CSM: 若 CSM(K*) < 0 → JOINT_INFEASIBLE，回退 K_conservative
③ CCC: 若契约不兼容 → 按 Ξ_fail 接管，禁止继续
④ 执行: EV-exec* ← execute_cooperative(K*, C_op)；CECG.update(EV-exec*)
⑤ 评估: report ← CEB.evaluate(M, splits=(S_test, S_adv))
⑥ 元基准: mb ← BDC(CEB, M, baseline)
⑦ 回放: cxb ← CXB(M.version, E_hist)
⑧ 准入: accept = (report.heldout_gain > 0) ∧ mb.gate ∧ (cxb.audit_score ≥ 0.95)
⑨ 回流: if accept ∧ 有新失效模式 → CEB.register(scenario, split=S_train)
⑩ return (K*, report, mb, cxb, accept)
```
**防自噬原则**：回流只允许进入 S_train，**永不进入 S_test/S_adv**；且回流后必须重算 BOF 与 D。

## 2. 关键算法伪代码（要点版，完整版见产物区）

```python
def distributed_impedance_consensus(agents, F_shared, rho=1.0, T_cons=20, eps_cons=1e-3):
    z = np.mean([a.K_local for a in agents], axis=0)
    u = [np.zeros_like(a.K_local) for a in agents]
    for t in range(T_cons):
        K = [project_feasible(a.K_local + u[i] - z, a.K_safe, a.F_budget)
             for i, a in enumerate(agents)]
        for i in range(len(agents)): u[i] += K[i] - z
        z_new = project_joint_feasible(np.mean(K, axis=0), agents, F_shared)
        rho_cons = np.linalg.norm(z_new - z) / (np.linalg.norm(z) + 1e-9)
        z = z_new
        if rho_cons <= eps_cons: break
    csm = cooperative_safety_margin(K, agents, F_shared)
    return (z, {'rho_cons': rho_cons, 'iters': t+1, 'csm': csm}) if csm >= 0 \
           else (None, {'status': 'JOINT_INFEASIBLE', 'csm': csm})

def benchmark_discriminative_capacity(policies, ceb, capability):
    scores = {p: ceb.eval(p) for p in policies}
    D  = roc_auc(scores, capability)
    S  = sensitivity_slope(scores, capability)
    St = stability_variance(ceb, irrelevant_perturbations=True)
    BOF = (mean_train_score(ceb) - mean_test_score(ceb)) / (mean_train_score(ceb) + 1e-9)
    return {'D': D, 'S': S, 'St': St, 'BOF': BOF,
            'gate': D >= TAU_D and S >= TAU_S and St <= TAU_ST and BOF <= THETA_BOF}
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DIC | O(T_cons·N·d) | O(N·d) | 凸约束下 ADMM 收敛；ρ_cons ≤ ε_cons |
| CCC | O(N+E) wait-for 环检测 | O(N²) 契约矩阵 | 无多 leader 死锁；失效接管确定性 |
| CSM | O(N·d + d³) 特征分解 | O(d²) | CSM < 0 时否决联合解 |
| CECG | O(1) 追加 / O(N·d) 合并 | O(N·d) | 向量时钟支配校验跨流因果 |
| CEB | O(|T|·|S|·seeds) 回放 | O(|report|) | 配对检验 α 控制、功效 ≥ 0.8 |
| BDC | O(P·|benchmark|) | O(P) | Gate_meta 过滤无判别力/过拟合基准 |
| CXB | O(|E_hist|) | O(|E_hist|) | 固定种子/硬件下检测显著回归 |
| CBL | O(一次闭环 + 评估) | 复用 | 三闸门联合准入 |

**正确性定理（CBC）**：假设 A66–A73 成立：
- **(A66)** DIC 的 K_i 与 F_shared 约束凸，ADMM 有界收敛；
- **(A67)** CCC 的 Token + wait-for 图保证无多重 leader、无死锁；
- **(A68)** CSM ≥ 0 蕴含联合接触力与共振模态安全；
- **(A69)** CECG 的向量时钟与哈希保证跨流因果可重建；
- **(A70)** CEB 的划分独立、配对检验满足分布假设；
- **(A71)** 元基准对真实能力变化有判别力；
- **(A72)** CXB 回放保真（种子/硬件/场景可复现）；
- **(A73)** CBL 的回流只进 S_train 且重算 BOF/D。

则：
1. **协同安全**：CSM(K*) ≥ 0 且 ρ_cons ≤ ε_cons ⇒ 联合接触力不超 F_shared，且危险共振模态被排除；否则拒绝下发。
2. **协同无死锁**：CCC 一致性检查与 Token 机制 ⇒ 不存在两个 leader 并发写共享约束；违约按 Ξ_fail 确定性接管。
3. **跨流证据完整**：CECG 的 vclock 支配校验 ⇒ η_ev ≥ τ_ev；「双流连续但因果断裂」被显式标记为 CAUSAL_GAP。
4. **可证伪性**：CEB 的留出/对抗划分 + 配对检验 ⇒ 在 α 水平上拒绝「无提升」原假设；报告必须带 CI 与失败案例。
5. **基准可信**：Gate_meta 与 BOF ⇒ 只有具备判别力且未过拟合的基准可参与模型选择。
6. **闭环安全**：CBL 三闸门 ⇒ 任何回流更新都必须同时满足留出集提升、元基准不降、无显著回归；否则仅记录、不训练。

## 5. 本轮最大风险

**一句话**：协同共识可能「以平均掩盖危险」——两机阻抗平均后各自看着安全、联合却力叠加或低频共振；而基准闭环又可能把「测试集」悄悄变成「训练集」，使高分只反映记忆而非能力。必须用 CSM 联合裕度一票否决、CCC 确定性接管、CECG 跨流因果校验，以及「留出 + 对抗 + 元基准 + 反事实回放」四重闸门，确保**协同不稀释安全、基准不替代真实**。

# 第 61 轮产物 · 创新点清单 v1：CBC（协同基准控制：分布式阻抗共识×协同契约×协同因果证据×协同执行基准，DIC×CCC×CSM×CECG×CEB×BDC×CXB×CBL）

## 2. 关键算法伪代码

### IP-161 DIC（分布式阻抗共识）

```python
def distributed_impedance_consensus(agents, F_shared,
                                    rho=1.0, T_cons=20, eps_cons=1e-3):
    z = np.mean([a.K_local for a in agents], axis=0)
    u = [np.zeros_like(a.K_local) for a in agents]
    history = []
    for t in range(T_cons):
        K = []
        for i, a in enumerate(agents):
            K_target = a.K_local + u[i] - z
            K_i = project_feasible(K_target, a.K_safe, a.F_budget)
            K.append(K_i)
            u[i] = u[i] + K_i - z
        z_new = project_joint_feasible(np.mean(K, axis=0), agents, F_shared)
        rho_cons = np.linalg.norm(z_new - z) / (np.linalg.norm(z) + 1e-9)
        history.append(rho_cons)
        z = z_new
        if rho_cons <= eps_cons:
            break
    csm = cooperative_safety_margin(K, agents, F_shared)
    if csm < 0:
        return None, {'status': 'JOINT_INFEASIBLE', 'csm': csm,
                      'rho_cons': rho_cons, 'history': history}
    return z, {'status': 'OK', 'K': K, 'csm': csm,
               'rho_cons': rho_cons, 'iters': t + 1, 'history': history}
```

### IP-162 CCC（协同控制契约）

```python
from dataclasses import dataclass

@dataclass
class Contract:
    agent_id: str
    role: str          # leader / follower / peer / human
    capacity: float
    F_budget: float
    clock: float
    fail_policy: str   # transfer / degrade / safe_stop

class CooperativeContract:
    def __init__(self, contracts, F_shared, delta_t=5e-3):
        self.contracts = {c.agent_id: c for c in contracts}
        self.F_shared = F_shared
        self.delta_t = delta_t
        self.token_holder = None
        self.wait_for = {}          # agent_id -> waiting agent_id

    def check_compatibility(self):
        leaders = [c for c in self.contracts.values() if c.role == 'leader']
        if len(leaders) > 1:
            return False, 'MULTI_LEADER'
        clocks = [c.clock for c in self.contracts.values()]
        if clocks and (max(clocks) - min(clocks)) > self.delta_t:
            return False, 'CLOCK_SKEW'
        if sum(c.F_budget for c in self.contracts.values()) > self.F_shared:
            return False, 'FORCE_OVERCOMMIT'
        return True, 'OK'

    def acquire_token(self, agent_id):
        if self.token_holder in (None, agent_id) or not self._alive(self.token_holder):
            self.token_holder = agent_id
            return True
        if self._would_deadlock(agent_id):
            self._break_cycle()     # 按角色优先级中断低优先级等待
        return False

    def _would_deadlock(self, agent_id):
        # 沿 wait_for 边走，若回到 agent_id 则成环
        seen, cur = set(), agent_id
        while cur in self.wait_for:
            if cur in seen:
                return True
            seen.add(cur)
            cur = self.wait_for[cur]
        return cur == agent_id

    def failover(self, failed_agent):
        c = self.contracts[failed_agent]
        if c.fail_policy == 'transfer':
            return self._transfer_responsibility(failed_agent)
        if c.fail_policy == 'degrade':
            return conservative_joint_impedance(self.contracts, self.F_shared)
        return SAFE_STOP
```

### IP-163 CSM（协同安全裕度）

```python
def cooperative_safety_margin(K_list, agents, F_shared, lambda_min=0.05):
    F_total = sum(a.contact_force(K) for a, K in zip(agents, K_list))
    force_margin = (F_shared - F_total) / F_shared
    local_margin = min(a.margin(K) / a.margin_nom
                       for a, K in zip(agents, K_list))
    J = sum(K_list)
    eig = np.linalg.eigvalsh(symmetrize(J))
    gap = (eig[1] - eig[0]) if len(eig) > 1 else 0.0
    resonance_margin = (gap - lambda_min) / lambda_min
    return min(force_margin, local_margin, resonance_margin)

def joint_feasible(K_list, agents, F_shared, rho_cons, eps_cons=1e-3):
    return (cooperative_safety_margin(K_list, agents, F_shared) >= 0
            and rho_cons <= eps_cons)
```

### IP-164 CECG（协同证据因果图）

```python
class CooperativeEvidenceGraph:
    def __init__(self, n_agents, agent_ids):
        self.n = n_agents
        self.agent_index = {aid: i for i, aid in enumerate(agent_ids)}
        self.clock = {aid: np.zeros(n_agents, dtype=np.int64) for aid in agent_ids}
        self.nodes = {}
        self.E_hb = set()
        self.E_cf = set()

    def emit(self, agent_id, ev, causal_parents=()):
        self.clock[agent_id][self.agent_index[agent_id]] += 1
        vclock = self.clock[agent_id].copy()
        node = {
            'agent': agent_id, 'seq': int(vclock[self.agent_index[agent_id]]),
            'vclock': vclock, 'causal_parents': tuple(causal_parents),
            'timestamp': time.time(),
            'hash': hashlib.sha256(json.dumps(ev, sort_keys=True).encode()).hexdigest()[:16],
            'content': ev,
        }
        nid = (agent_id, node['seq'])
        self.nodes[nid] = node
        for p in causal_parents:
            if p not in self.nodes:
                return nid, 'CAUSAL_GAP'      # 父事件未到
            self.E_hb.add((p, nid))
            self.clock[agent_id] = np.maximum(self.clock[agent_id],
                                              self.nodes[p]['vclock'])
        return nid, 'OK'

    def merge(self, incoming):
        nid = (incoming['agent'], incoming['seq'])
        if nid in self.nodes:
            return 'DUPLICATE'
        for p in incoming['causal_parents']:
            if p not in self.nodes:
                return 'CAUSAL_GAP'
        if self.nodes and not any(dominates(incoming['vclock'], n['vclock'])
                                  for n in self.nodes.values()):
            # 检查是否与任何已收节点不可比且时间戳倒流
            if any(incoming['timestamp'] < n['timestamp']
                   for n in self.nodes.values()):
                return 'CAUSAL_GAP'
        self.nodes[nid] = incoming
        return 'OK'

    def completeness(self, true_edges):
        reconstructable = {(a, b) for (a, b) in self.E_hb
                           if a in self.nodes and b in self.nodes}
        return len(reconstructable & true_edges) / (len(true_edges) + 1e-9)
```

### IP-165 CEB（协同执行基准）

```python
TASKS = ['coop_transport', 'handover', 'joint_assembly',
         'human_robot', 'failover']
SPLITS = ['train', 'val', 'test', 'adv']
PERTURBATIONS = ['comm_delay', 'packet_loss', 'friction_shift',
                 'stiffness_drift', 'intent_noise']
METRICS = ['cooperation_success', 'csm_min', 'consensus_time',
           'eta_ev', 'recovery_rate', 'tail_latency_p99']

class CooperativeExecutionBenchmark:
    def __init__(self, scenes, seeds=range(30)):
        self.scenes = scenes          # {split: [scene,...]}, 四分离
        self.seeds = list(seeds)

    def evaluate(self, policy, splits=('test', 'adv')):
        rows = []
        for split in splits:
            for task in TASKS:
                for scene in self.scenes[split]:
                    for pert in PERTURBATIONS:
                        for seed in self.seeds:
                            trace = rollout(policy, task, scene, pert, seed)
                            rows.append(metrics(trace, METRICS))
        return {
            'per_metric': {m: bootstrap_ci([r[m] for r in rows]) for m in METRICS},
            'failures': collect_failures(rows),
            'manifest': self.manifest(policy),
        }

    def paired_test(self, policy, baseline, metric):
        a = self._raw(policy, metric)
        b = self._raw(baseline, metric)
        stat, p = wilcoxon(a, b)
        return {'p': p, 'effect': cohens_d(a, b), 'power': power(a, b),
                'ci': bootstrap_ci([x - y for x, y in zip(a, b)])}

    def manifest(self, policy):
        return {'git': git_hash(), 'seeds': self.seeds,
                'rosbag': self.rosbag_ids, 'hardware': hardware_profile(),
                'params': policy.snapshot()}
```

### IP-166 BDC/BOF（元基准判别力）

```python
def benchmark_discriminative_capacity(policies, ceb, capability,
                                      TAU_D=0.85, TAU_S=0.1,
                                      TAU_ST=0.05, THETA_BOF=0.10):
    scores  = {p.id: ceb.eval(p) for p in policies}
    D  = roc_auc(scores, capability)                # 判别力
    S  = sensitivity_slope(scores, capability)      # 敏感性
    St = stability_variance(ceb, irrelevant_perturbations=True)
    BOF = (mean_train_score(ceb) - mean_test_score(ceb)) / \
          (abs(mean_train_score(ceb)) + 1e-9)
    gate = (D >= TAU_D and S >= TAU_S and St <= TAU_ST and BOF <= THETA_BOF)
    return {'D': D, 'S': S, 'St': St, 'BOF': BOF, 'gate': gate,
            'verdict': 'SELECTABLE' if gate else 'REFERENCE_ONLY'}
```

### IP-167 CXB（反事实回放审计）

```python
def counterfactual_replay(new_version, history, delta_reg=0.05, n_boot=1000):
    regressions, total = [], 0
    for pkg in history:
        with replay_context(seed=pkg.seed,
                            hardware=pkg.hardware,
                            rosbag=pkg.rosbag):
            new = new_version.evaluate(pkg.scenario)
        for metric, old_val in pkg.metrics.items():
            if metric not in new:
                continue
            total += 1
            diffs = bootstrap_paired_diff(new[metric], old_val, n_boot)
            delta = diffs['mean']
            if delta < -delta_reg and diffs['ci_high'] < 0:
                regressions.append({'pkg': pkg.id, 'metric': metric,
                                    'delta': delta, 'ci': diffs})
    audit = 1.0 - len(regressions) / (total + 1e-9)
    return {'regressions': regressions, 'audit_score': audit,
            'pass': audit >= 0.95}
```

### IP-168 CBL（协同基准闭环）

```python
def cooperative_benchmark_loop(M, contract, ceb, history):
    # ① 分布式阻抗共识
    K_star, dic = distributed_impedance_consensus(M.agents, contract.F_shared)
    if K_star is None:
        return M, {'status': 'JOINT_INFEASIBLE', 'dic': dic}, False

    # ② 契约一致性
    ok, reason = contract.check_compatibility()
    if not ok:
        K_star = conservative_joint_impedance(contract.contracts, contract.F_shared)
        contract.failover(reason)

    # ③ 执行 + 因果证据
    M, ev_nodes = execute_cooperative(M, K_star, contract)
    for nid, node in ev_nodes.items():
        status = M.cecg.merge(node)
        if status == 'CAUSAL_GAP':
            M.cecg.request_retransmit(node['causal_parents'])

    # ④ 基准评估（留出 + 对抗）
    report = ceb.evaluate(M.policy, splits=('test', 'adv'))

    # ⑤ 元基准门
    meta = benchmark_discriminative_capacity(
        [M.policy, M.baseline], ceb, capability=M.true_rank)

    # ⑥ 反事实回放
    cxb = counterfactual_replay(M.version, history)

    # ⑦ 三闸门准入
    accept = (report.heldout_gain > 0
              and meta['gate']
              and cxb['pass'])
    if accept and report.novel_failures:
        ceb.register(report.novel_failures, split='train')  # 永不写 test/adv
        meta_after = benchmark_discriminative_capacity(
            [M.policy, M.baseline], ceb, capability=M.true_rank)
        accept = accept and meta_after['gate']              # 回流后重算
    return M, {'report': report, 'meta': meta, 'cxb': cxb,
               'dic': dic, 'status': 'OK'}, accept
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| DIC | O(T_cons·N·d) | O(N·d) | 凸约束 ADMM 收敛；ρ_cons ≤ ε_cons |
| CCC | O(N+E) 环检测 | O(N²) 契约矩阵 | 无多 leader 死锁；接管确定 |
| CSM | O(N·d + d³) | O(d²) | CSM ≥ 0 才允许下发 |
| CECG | O(1) 追加 / O(N·d) 合并 | O(N·d) | 向量时钟支配校验；η_ev ≥ 99.5% |
| CEB | O(|T|·|S|·|P|·seeds) | O(|report|) | 配对检验 α 控制；功效 ≥ 0.8 |
| BDC | O(P·|benchmark|) | O(P) | Gate_meta 过滤无判别力/过拟合 |
| CXB | O(|E_hist|·n_boot) | O(|E_hist|) | 固定种子/硬件下检测显著回归 |
| CBL | O(一次闭环 + 评估) | 复用 | 三闸门联合准入 |

**正确性定理（CBC / Cooperative Benchmark Control）**：假设 A66–A73 成立，则：
1. **协同安全**：若 CSM(K*) ≥ 0 且 ρ_cons ≤ ε_cons，则联合接触力 ΣF_i ≤ F_shared，联合刚度最小模态间隔 ≥ λ_min；否则 CBL 返回 JOINT_INFEASIBLE 并回退保守解。
2. **协同无死锁**：Token 保证至多一个 leader 写共享约束，wait-for 图无环；违约时 Ξ_fail 在 O(N) 内确定性接管。
3. **跨流因果完整**：CECG 的 vclock 支配 + causal_parent + hash 三重校验，使任意 happens-before 边可重建；不可达父事件被判 CAUSAL_GAP 并触发重传，η_ev ≥ τ_ev。
4. **可证伪性**：CEB 的 S_test/S_adv 与训练集两两不交，配对 Wilcoxon 控制 I 类错误 ≤ α，功效 ≥ 1−β；报告强制包含 95% CI 与失败案例，不允许只报均值。
5. **基准可信**：Gate_meta 与 BOF 阈值保证只有具备判别力、敏感性与稳定性的基准可用于模型选择。
6. **闭环安全（防自噬）**：CBL 仅当「留出提升 ∧ 元基准门通过 ∧ 无显著回归」三闸全过才接受更新；回流只写 S_train 并立即重算 BOF/D，故 `score_test` 不含被回流场景的记忆。

## 5. 本轮最大风险

**一句话**：协同共识可能「以平均掩盖危险」——两机阻抗平均后各自看着安全、联合却力叠加或低频共振；而基准闭环又可能把「测试集」悄悄变成「训练集」，使高分只反映记忆而非能力。必须以 CSM 联合裕度一票否决、CCC 确定性接管、CECG 跨流因果校验，以及「留出 + 对抗 + 元基准 + 反事实回放」四重闸门，确保**协同不稀释安全、基准不替代真实**。
