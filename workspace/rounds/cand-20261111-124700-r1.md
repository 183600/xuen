# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「奖励设计」×「语音识别」）

> 第 54 轮已把技能组合提升为动作-鲁棒性双证书，但命令入口仍被当作「已解析的干净文本」。本轮把 **语音识别的不确定性** 与 **奖励设计的目标对齐** 引入，形成 **奖励感知的语义解码**。核心矛盾：H22：ASR 的 N-best/lattice 被压成单一文本后，同音误识与语义别名会把错误意图送入组合器，动作-鲁棒性证书只能证明「这条计划在其意图下可行」，却无法证明「意图本身是对的」；H23：为组合器设计的奖励/代价容易被代理指标劫持，出现「奖励高、任务失败」的 reward hacking。

## 0. 直觉与动机

**灵感 1（命令不是字符串，而是后验）**
直觉：用户说「把杯子放到左边」，ASR 真正给出的不是一句话，而是一个 lattice，`左边 / 杯边 / 被边` 同音候选并存。传统管线取 1-best，把这份不确定性一次性丢掉。更合理的做法是把 lattice 折叠为 **意图后验 `q(i|audio)`**，直接传给技能组合器做期望奖励解码。这正是 ASR 中 **MBR（最小贝叶斯风险）解码** 在机器人上的对偶：ASR 最小化期望词错，我们最大化期望任务效用。

**灵感 2（奖励设计是证书的目标函数，不是补丁）**
直觉：第 54 轮的 `cost_align` 只衡量动作对齐，不衡量「是否完成用户真正想要的事」。把奖励 `R(i,π,o)` 作为组合图 `G_S` 的边权，路径搜索就从「最小对齐成本」升级为「最大期望任务效用 − 鲁棒性风险」。但奖励模型一旦被下游优化器利用，就会偏离真实目标，因此 **奖励也需要一张证书**，而不是一个标量。

**灵感 3（语音识别的校准工具 → 奖励的分布无关误差界）**
直觉：ASR 用温度缩放做置信度校准、用 conformal prediction 给出「覆盖有保证」的候选集。同样的工具可给奖励模型加一层分布无关护栏：只在 **保形意图集 `C_α`** 上求期望奖励，避免对单一 1-best 或单一奖励标量过拟合。这把「语音置信度」变成了「语义决策的可行域」。

**灵感 4（用语义保持改写审计奖励 → paraphrase-invariant reward）**
直觉：语义等价的改写（同义句、口音、语序）应当产生相同的奖励排序。若奖励模型对这类保持标签的扰动敏感，说明它抓的是表面伪相关，是 reward hacking 的强信号。语音识别的数据增强因此变成 **奖励鲁棒性审计器**，而不是只用来提升 WER。

**灵感 5（歧义时「问」也是一等动作）**
直觉：当意图后验熵高、或候选意图的最优路径奖励 margin 很小时，盲目执行比「请求澄清」更危险。把 `clarify` 纳入动作空间，与 `execute / abort` 一起做期望效用比较。这与 ASR 的 reject option（拒识）同构：**不确定时不猜，而是买信息**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（意图后验与保形意图集）**
ASR 输出 lattice `L` 与词串后验 `p(w|audio)`。意图 `i = parse(w)`，意图后验
```
q(i|audio) = Σ_{w∈L : parse(w)=i} p(w|audio)
```
保形意图集 `C_α(L)` 由非一致性分数 `s(L,i)` 的 `⌈(n+1)(1-α)⌉/n` 分位数 `q̂` 构造：
```
C_α(L) = { i ∈ intents(L) : s(L,i) ≤ q̂ }
```
满足边际覆盖 `P(i* ∈ C_α(L)) ≥ 1-α`，`i*` 为真实用户意图。

**定义 122（奖励泛函）**
```
R(i,π,o) = R_task(i,o) − λ_r·Risk(π) − λ_a·Amb(π) − λ_c·c_clar
```
其中 `R_task` 为任务完成度，`Risk(π)` 复用第 54 轮 `ρ` 与 `δ_a`，`Amb(π)` 为同一路径在不同候选意图间效用排序的不一致度，`c_clar` 为澄清成本。强调 `R` 是 **决策效用**，不是纯任务分数。

**定义 123（奖励条件解码）**
```
π* = argmax_{π∈Π(G_S)}  E_{i~q(·|audio)} [ R(i,π,o) ]
     s.t.  ρ_π(d) ≥ ρ_min ∀d  ∧  δ_a ≤ Θ_a  ∧  A_T ⊆ A_core
```
第 54 轮的可行域原样保留，只把目标函数从「最小对齐成本」换成「最大期望奖励」。这样奖励设计 **不放松** 任何已有的动作-鲁棒性约束。

**定义 124（奖励证书）**
```
R_cert = (R̂, ECE, PV, HS, cov)
```
- `R̂`：校准后的奖励估计（温度缩放 / isotonic）；
- `ECE`：期望校准误差；
- `PV`：语义保持改写下的奖励排序方差（paraphrase variance）；
- `HS`：hack 分数，即代理奖励与留出真值结果的秩相关背离 `1 − mean Spearman`；
- `cov`：`C_α` 的经验覆盖率。

**定义 125（歧义门控策略）**
动作空间 `{execute, clarify, abort}`，效用：
```
U_exec  = E_{i~q}[R(i,π̂,o)]
U_clar  = −c_clar + E_{i~q}[ max_π R(i,π,o) | 澄清后 ]
U_abort = 0
```
执行当且仅当 `U_exec − max(U_clar,U_abort) ≥ Δ_u` 且最优意图的效用 margin `≥ m`；否则优先 `clarify`，`U_clar<0` 时 `abort`。

**定义 126（奖励-语义联合证书）**
```
J_R = (J, R_cert, C_α, d*),  d* ∈ {execute, clarify, abort}
```
可部署当且仅当第 54 轮 `J` 可部署，且
```
cov ≥ 1−α−ε_cov  ∧  ECE ≤ ε_ece  ∧  PV ≤ v_max  ∧  HS ≤ h_max  ∧  d* = execute
```

## 2. 关键算法 伪代码

### IP-121 RCD（Reward-Conditioned Decoding）

```python
def reward_conditioned_decode(L, G, q, R_task, constraints, k=16, beam=32):
    candidates = []
    for intent, prob in topk(q, k):
        frontier = [([start_node], start_node, 0.0)]
        while frontier:
            path, node, acc = frontier.pop()
            if is_goal(node, intent):
                candidates.append((acc, path, intent, prob))
                continue
            for nxt, edge in G.successors(node):
                # 复用第 54 轮动作-鲁棒性可行域
                if not constraints.allow(edge, intent):
                    continue
                step = expected_reward(intent, path + [nxt], edge, R_task)
                frontier.append((path + [nxt], nxt, acc + step))
                frontier = prune_beam(frontier, beam, key=lambda b: b[2])
    # MBR 式：按意图后验对候选加权，而非只取 1-best
    return max(candidates, key=lambda c: c[3] * c[0])

def expected_reward(intent, path, edge, R_task):
    risk = sum(1.0 - edge.rho[d] for d in edge.rho) + edge.delta_a
    return R_task(intent, path) - LAMBDA_R * risk - LAMBDA_A * path_ambiguity(path)
```

### IP-122 SRC（Semantic-Reward Calibration）

```python
def fit_conformal(calib_set, alpha):
    scores = [nonconformity(L, i_true) for L, i_true in calib_set]
    return quantile(scores, 1.0 - alpha, interpolation='higher')

def intent_set(L, qhat):
    return [i for i in intents(L) if nonconformity(L, i) <= qhat]

def calibrate_reward(R_raw, holdout):
    T = fit_temperature(R_raw, holdout)          # 温度缩放
    R_hat = lambda i, p, o: R_raw(i, p, o) / T
    ece = expected_calibration_error(R_hat, holdout)
    return R_hat, ece
```

### IP-123 PRA（Paraphrase Reward Audit）

```python
def paraphrase_audit(R_hat, pairs, paraphrases):
    violations, rank_orders = [], []
    for (audio, i_star, o_star) in pairs:
        base = rank_of(R_hat, i_star, o_star)
        for w in paraphrases(audio, i_star):
            r = rank_of(R_hat, parse(w), o_star)
            if r != base:
                violations.append((audio, w, base, r))
        rank_orders.append(spearman(R_hat.scores, true_scores))
    PV = variance(rank_orders)
    HS = 1.0 - mean(rank_orders)                 # 与留出真值的秩相关背离
    return R_cert(PV=PV, HS=HS, n_violations=len(violations))
```

### IP-124 AGC（Ambiguity-Gated Commitment）

```python
def ambiguity_gate(q, C_alpha, plans, c_clar, Delta_u, margin):
    best = max(((expected_utility(i, p), i, p)
                for i in C_alpha for p in plans[i]), key=lambda t: t[0])
    U_exec = best[0]
    U_clar = -c_clar + expected_value_after_clarification(q)
    if U_exec - max(U_clar, 0.0) >= Delta_u and utility_margin(C_alpha, plans) >= margin:
        return ('execute', best[2])
    if U_clar > 0:
        return ('clarify', clarifying_question(C_alpha))
    return ('abort', None)
```

### IP-125 RSC（Reward-Semantic Certificate）

```python
def reward_semantic_certify(J, R_cert, C_alpha, alpha, eps_cov, eps_ece, v_max, h_max):
    cov = empirical_coverage(C_alpha)
    if cov < 1.0 - alpha - eps_cov:  return ('reject', 'coverage_fail', cov)
    if R_cert.ECE > eps_ece:         return ('reject', 'miscalibrated', R_cert.ECE)
    if R_cert.PV > v_max:            return ('reject', 'paraphrase_unstable', R_cert.PV)
    if R_cert.HS > h_max:            return ('reject', 'reward_hack', R_cert.HS)
    d = ambiguity_gate(q, C_alpha, plans, c_clar, Delta_u, margin)
    if d[0] != 'execute':            return ('defer', d[0], d[1])
    return ('ok', JointRewardCert(J, R_cert, C_alpha, d))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RCD | O(k·|E|·beam) | O(beam·|V|) | 可行域复用、期望奖励无偏 |
| SRC | O(n log n) 离线 + O(|L|) 在线 | O(n) | 可交换性、覆盖率单调 |
| PRA | O(n·|paraphrase|·|L|) | O(n) | 改写保持语义、留出真值独立 |
| AGC | O(|C_α|·|Π|) | O(|C_α|) | 效用可比、澄清收益可估 |
| RSC | O(1) 校验 | O(1) | 四个护栏正交、否决先于执行 |

**正确性定理（Reward-Semantic Decoding Regret）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `C_α` 满足覆盖 `P(i*∈C_α)≥1−α`；**(A30)** 奖励估计 `|R̂−R|≤ε_R` 以概率 `1−δ` 成立；**(A31)** 语义保持改写下的排序方差 `≤ v`（蕴含局部泛化）。则对 `π̂ = RCD(L,G,q,R̂)`：
```
E[ R(i*,π*) − R(i*,π̂) ] ≤ 2·R_max·α + 2·ε_R + λ_a·v + λ_r·P(δ_a>Θ_a)
```
直觉：第一项是「真实意图不在保形集」的代价（由覆盖保证控制），第二项是奖励估计误差，第三项是改写不稳定带来的语义漂移，第四项是继承自第 54 轮的动作对齐风险。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 意图后验校准偏差 | 高 | 温度缩放 + 分层 conformal + 域内重校准 |
| 奖励模型被 hacking | 高 | 语义改写审计 + 留出真值 + 秩相关监控 |
| 澄清打断用户体验 | 中 | 澄清预算 + 效用阈值 + 主动学习挑问题 |
| lattice × 组合图搜索爆炸 | 中 | beam + 意图剪枝 + 路径缓存 |
| 「语义等价」定义不严 | 高 | 形式化 paraphrases 算子 + 人工双盲审计 |

## 6. 本轮最大风险

**一句话**：本轮把语音不确定性折叠成保形意图集、把奖励设计提升为决策效用，但 **保形覆盖只约束「真实意图是否在候选集内」，并不约束「奖励模型在候选集内的排序是否正确」**；一旦把 `cov ≥ 1−α` 误读为奖励正确性的保证，系统就会在「意图没漏、但排序被代理奖励劫持」时自信地执行错误技能，因此必须以 **留出真值秩相关 + 语义改写审计 + 歧义门控** 三重复核，任何一项不达标都宁可澄清，绝不把统计覆盖当作目标对齐。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-RewardDecode（RCD×SRC×PRA×AGC×RSC）

> 承接第 54 轮产物 v31（动作-鲁棒性双证书）。本轮在 L0.5++ 动作-协同层之上，新增 **奖励-语义解码层**，把命令入口从「1-best 文本」升级为「意图后验 + 奖励证书」：

|---|---|---|---|
| RCD | O(k·|E|·beam) | O(beam·|V|) | 可行域复用、期望奖励无偏 |
| SRC | O(n log n) 离线 + O(|L|) 在线 | O(n) | 可交换性、覆盖率单调 |
| PRA | O(n·|paraphrase|·|L|) | O(n) | 改写保持语义、留出真值独立 |
| AGC | O(|C_α|·|Π|) | O(|C_α|) | 效用可比、澄清收益可估 |
| RSC | O(1) | O(1) | 四护栏正交、否决先于执行 |

**正确性定理（Reward-Semantic Decoding Regret）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `P(i*∈C_α)≥1−α`；**(A30)** `|R̂−R|≤ε_R` 以概率 `1−δ`；**(A31)** 语义保持改写下排序方差 `≤v`。则
```
E[ R(i*,π*) − R(i*,π̂) ] ≤ 2·R_max·α + 2·ε_R + λ_a·v + λ_r·P(δ_a>Θ_a)
```
其中 `π*` 为真实意图下的最优计划，`π̂` 为 RCD 输出。四项分别对应：保形集漏检、奖励估计误差、语义漂移、继承的动作对齐风险。**关键：覆盖保证与奖励正确性是两条独立条件，定理不会用前者替代后者。**

## 6. 本轮最大风险

**一句话**：本轮把语音不确定性折叠成保形意图集、把奖励设计提升为决策效用，但 **保形覆盖只约束「真实意图是否在候选集内」，并不约束「奖励模型在候选集内的排序是否正确」**；一旦把 `cov ≥ 1−α` 误读为奖励正确性的保证，系统就会在「意图没漏、但排序被代理奖励劫持」时自信地执行错误技能，因此必须以 **留出真值秩相关 + 语义改写审计 + 歧义门控** 三重复核，任何一项不达标都宁可澄清，绝不把统计覆盖当作目标对齐。
