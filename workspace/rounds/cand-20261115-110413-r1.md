# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「机器人操作系统」×「本体感知」）

> R69 把不确定性一分为二，并为 epistemic 配上了「提问」的能力。但它自陈的最大风险恰恰是**信任的地基问题**：整套效率收益押在「流模型的模态分布可信」上，而模态校准、交互投毒、幻影模态这些威胁，没有一个能被同一层内部签发的证书真正证伪——**证书由被怀疑的模型自己出具**。这就是「谁认证认证者」的循环。
>
> 更一般地看，R66→R69 是一条**不断加层**的路：控制、世界模型、计量、交互。每加一层，就多一个需要独立信任的黑箱；而层与层之间的契约（谁消费谁、何时失效、证据多新鲜、资源多少）全靠口头约定。R69 的 VoI 交互甚至把「提问」本身变成了新的攻击面。
>
> 本轮两个灵感把问题换了一个维度：
> - **机器人操作系统**不证明每个应用正确，而是提供**隔离、资源记账、最小可信内核与契约**，让任意一个坏模块都无法腐蚀整个系统；
> - **本体感知**提供唯一一个「不由外感受学习栈签发」的参照系——**身体实际做了什么**（efference copy + 关节/力矩/接触/IMU）。它把「信任」从全局假设变成**每轮可测的局部残差**。
>
> 核心命题：**把 R69 的「认证一个输出」升级为「认证一个组合」——用类 OS 的微内核垄断派发与安全包络，用本体感知作为信任的物理锚点，用版本化自图（body schema）做失效传播，用信任账本把模块的自我声明变成可证伪的契约。** 命名 **SOMA-RAS**（Self-model Operating-system Mediated Agency，身体自模型中介的自主性）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**凭什么相信『我』这个系统本身**」——信任不该是一个假设，而应是一个由身体每轮签字、可被隔离、可被降级的资源。

## 0. 直觉与动机

**灵感 1（机器人操作系统 → 从「模型层」下沉到「系统层」）**
直觉：R69 想用一个更好的模型（流匹配）去解决信任问题，但模型越好，越难被同层证伪。真实机器人不是靠「一个完美模型」活下来的，而是靠操作系统：进程隔离、资源配额、最小内核、类型化接口、生命周期管理、日志与内省。ROS 2 的这些机制并不保证节点正确，却保证**一个节点崩溃不会拖垮整车**。本轮的核心转向因此是：不再往栈顶加一个更聪明的模型，而是在栈下垫一个**可证伪的契约执行器**——把「信任」从每个模型的自我声明，改成内核可核对的证据。

**灵感 2（本体感知 → 唯一不经过外感受学习栈的锚点，打破 R69 的自指）**
直觉：R69 的 FMA 用动作似然 `p_θ(ξ|o)` 做「第二意见」，但 `p_θ` 就是被怀疑的那个流策略——这是**自指**：一个说谎的模型可以同时伪造它的自信和它的似然。本体感知不同：它来自编码器、力矩计、接触、IMU，且**efference copy 由内核签发**，模块无法伪造「我到底发了什么指令」。于是「身体实际响应 vs 指令预期响应」的残差，提供了一个不经过外感受学习栈的独立通道。它不能告诉你世界是什么，但能告诉你**世界和你声称的动作是否自洽**。本体感知因此从「一个传感器模态」升级为**信任的物理根**。

**灵感 3（body schema ↔ TF 树 + 失效传播）**
直觉：ROS 里 TF 树是所有节点共享的、版本化的坐标变换；谁改了标定或装配，旧的变换立刻作废，依赖它的节点必须重算。人体对应物是**体模（body schema）**：一个随负载、工具、磨损缓慢更新的自我模型。R69 的证书没有「版本」概念——换了工具、加了负载、关节磨损之后，旧证书仍在被信任。本轮把自图 `G_self` 做成版本化对象：任何几何/负载/执行器健康的变化，都使声明依赖它的模块**失效**，其证书作废并强制重认证。这把「环境变了而模型不知道」从隐性风险变成显式、可传播的事件。

**灵感 4（信任是可管理资源 → 账本 + 交互经济）**
直觉：操作系统管理的从来不是「正确性」，而是「资源」：内存、CPU、带宽、能量。本轮把**信任**也当作一种内核管理的资源：每个模块有信任余额 `T_i`，由契约履约、身体残差一致性和证据新鲜度更新，且**自我声明不计入**。R69 的交互预算随之升级为**信任门控的交互经济**：低信任模块不得驱动高成本交互——这正好堵住 R69「自信地追问一个幻影」的路。信任还能被「花费」（一次高成本问询），花费后需要重新赚回，从而避免交互疲劳与信任通胀。

**灵感 5（自我信任是新的根风险 → 最小 TCB 与递归上限）**
直觉：把信任锚在「我」身上是一件危险而诚实的事——**当『我』可以说谎时，以『我』为锚的一切认证都会一致地骗过自己**。操作系统给出的答案是「最小可信计算基（TCB）+ 硬件根 + 递归深度上限」：不追求证明一切，而是把必须无条件相信的东西压到最小、可度量、可形式化验证。本轮据此定义「信任深度」与「本体自证禁令」，并给出组合风险上界与内核停机条件。这是对 R69「新增一层就多一个黑箱」的正面回答：**新层不引入需要信任的模型，而是把 n 个黑箱压成 1 个最小内核 + 1 个硬件根。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SOMA-RAS 总览）** SOMA-RAS = (KRN, SGM, PRP, TLD, IOE, QRN, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **内核垄断派发**：任何改变安全包络的指令必须由 KRN 派发并留下签名的 efference copy，模块只能「提议」不能「执行」；
(iii) **契约可证伪**：模块的自我声明（不确定性/健康/资源）必须能对照日志与身体残差被核验，不得自证；
(iv) **证据有时效**：任何证据/证书只在 QoS deadline 内有效，过期视同缺失。

**定义 311（模块契约）** 模块 `m_i` 的契约 `C_i = (I_i, O_i, U_i, R_i, D_i, F_i)`：输入/输出类型与 QoS（deadline, reliability, liveliness, durability）、不确定性声明 `U_i`、资源预算 `R_i`（算力/内存/能量/带宽）、依赖 `D_i ⊆ 𝒢_self ∪ {m_j}`、失败模式 `F_i`。契约是**可执行**的：内核在运行时逐条核对，而非文档约定。

**定义 312（本体感知流与 efference copy）** 本体流 `p_t = (q, q̇, τ, contact, IMU) ∈ ℝ^{d_p}`；efference copy `e_t` 为 KRN **实际派发**的指令（非模块「声称」派发的指令），由内核签名。定义 `E_t = σ(e_t)` 为其完整历史摘要，模块不可伪造。

**定义 313（自图 G_self）** `G_self(t) = (kinematic tree, 标定参数 ĉ, 执行器健康 h_act, 负载/工具参数, 版本 v(t), 协方差 Σ_g)`。类比 ROS 的 TF 树：所有模块读同一份、版本化的「自我描述」。自图不是静态配置，而是带协方差的在线估计。

**定义 314（身体前向模型与残差）** `F_body: (p_t, e_t, G_self) → p̂_{t+1}`；`ρ_t = p_{t+1} − p̂_{t+1}`。归一化身体残差 `r_body = ρ_tᵀ Σ_ρ^{-1} ρ_t`。`F_body` 只依赖本体与自图，不依赖外感受学习栈。

**定义 315（能动性归因与歧义度）** 将 `ρ_t` 投影到三个子空间：`span(J_e)`（可由自身指令解释）、`span(J_ext)`（需外部扰动解释）、其余（无法归因）。得 `(r_self, r_ext, r_decep)`。歧义度 `A = 1 − max(r_self, r_ext, r_decep) / (r_self + r_ext + r_decep + ε)`。`r_decep` 高而 `r_self` 低，是「某外感受模块在撒谎或本体在漂移」的判别信号。

**定义 316（信任账本 TLD）** 每模块信任 `T_i(t) ∈ [0,1]`，按
`T_i ← clip(T_i + α(contract_i − T_i) − β·violation_i − γ·stale_i, 0, 1)`
更新。关键：`contract_i` 由**身体残差与交叉证据**计算，**自我声明不进更新式**（打破自证）。信任是 OS 管理的可消耗资源。

**定义 317（信任门控的交互经济 TBE）** R69 的交互预算由固定值升级为 `B_int(t) = B_0 · min_{i∈驱动者} T_i`；且 `T_i < τ_trust` 的模块不得发起高成本信息动作。一次交互消耗信任与预算，需在后续窗口内用履约赚回，防止「交互疲劳」与「信任通胀」。

**定义 318（非干涉与安全包络所有权）** 安全包络 `𝒮` 由 KRN 独占持有。模块输出经「提议 → 内核认证 → 派发」。非干涉：对任意模块子集 `M'`，若把其中所有输出替换为任意值，`𝒮` 不变。任何违约不得扩展 `𝒮`。

**定义 319（组合证书 J_SOMA）** `J_SOMA = (J_FLUID, r_body_p95, agency_ambiguity, trust_ledger_hash, self_graph_version, contract_violations, qos_deadline_margin, tcb_hash, soma_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ r_body ≤ τ_body ∧ A ≤ τ_A ∧ ∀i: T_i ≥ τ_trust ∧ 无过期证据 ∧ tcb_hash 匹配`。

**定义 320（隔离与降级格）** 模块状态 `∈ {nominal, suspect, quarantined, re-attesting}`；系统整体沿格单调下降：`nominal ⊒ 个别模块隔离 ⊒ R69 退化 ⊒ R68 纯保守 ⊒ 硬件安全停机`。**任何转换只允许沿格向下；恢复必须经 re-attestation（自证 + 交叉验证），不得瞬时跳回。**

**定义 321（自图变更检测与失效传播）** 若 `v(t) ≠ v_used` 或自图某项（负载/工具/标定/执行器健康）变化超阈值，则所有 `D_i` 声明依赖该项的模块被**失效**，其旧证书作废，必须重认证。类比 ROS 中 TF 更新使旧变换失效。

**定义 322（时效语义与 deadline 证书）** 证据/证书携带 deadline `δ`；在 `t` 时刻有效当且仅当 `age ≤ δ` 且 liveliness 未断。过期证据不参与融合，并计入 `stale` 惩罚（定义 316 的 γ 项）。

**定义 323（本体根信任 BRD 与本体自证禁令）** 因为本体感知是信任的根，给它最小攻击面：硬件签名传感器、电流-力矩/能量守恒/热约束等物理不变量交叉校验、冗余本体模态。**本体自证禁令**：任何单一本体源不得单独为自己或为整个栈背书，至少需要一路物理不变量或独立冗余源 corroborate。

**定义 324（继承栈的封装）** R69 的 FLUID-RAS 作为 KRN 之上的一个「受信进程」：其 `J_FLUID` 成为 `J_SOMA` 的子证书；R68/R67/R66 依次为更深的退化。新层不重写旧层，只在其外包一层可证伪的契约。

**定义 325（双时间尺度体模可塑性）** 自图更新分两通道：**快通道**检测突变（负载骤变、碰撞、卡死）→ 立即隔离并冻结依赖模块；**慢通道**更新长期参数（磨损、工具、标定漂移）→ 需稳态证据 + 回滚点 + 版本递增。快慢分离防止「把故障当漂移吸收」（这正是 R68 的最大风险在自图上的版本）。

**定义 326（递归信任深度与组合风险上界）** 信任链最多递归到硬件根，深度上限 `d_max`；无法在 `d_max` 内锚定的声明按 `T=0` 处理。组合风险保守上界：
`P(unsafe) ≤ Σ_i (1 − T_i)·p_fail,i + ε_kernel`，
其中 `ε_kernel` 只由最小 TCB 决定，与模块数 `n` 无关。这给出「加层不加黑箱」的定量含义。

## 2. 关键算法骨架

```python
# IP-264 KRN：最小可信内核（唯一能派发改变安全包络的指令）
class CertifiedKernel:
    def __init__(self, acl, envelope, tcb_attest):
        self.acl, self.S, self.attest = acl, envelope, tcb_attest
        self.efference = deque(maxlen=T)              # 已签名派发历史 e_t
    def dispatch(self, proposal, module_id):
        if not self.acl.allows(module_id, proposal.kind): return REJECT
        if not cert_pipeline.valid(proposal, self.S):      return REJECT   # 只收紧
        e = sign(self.attest, proposal)                    # 模块无法伪造
        self.efference.append(e)
        return actuate(e)                                  # 安全包络唯一出口

# IP-266 PRP：本体残差 + 能动性归因（不经过外感受学习栈）
def proprioceptive_probe(krn, p_t, p_next, G_self):
    e_t   = krn.efference[-1]                              # 硬件签名的 efference copy
    p_hat = F_body(p_t, e_t, G_self)                       # 身体前向模型
    rho   = p_next - p_hat
    r_self, r_ext, r_decep = project(rho, J_e(e_t), J_ext, G_self)
    A = 1.0 - max(r_self, r_ext, r_decep) / (r_self + r_ext + r_decep + EPS)
    return rho, (r_self, r_ext, r_decep), A

# IP-267 TLD：信任账本（只吃可证伪证据，不吃自我声明）
def trust_update(T, i, contract_ok, violation, stale):
    T[i] = clip(T[i] + ALPHA*(contract_ok - T[i]) - BETA*violation - GAMMA*stale, 0, 1)
    return T

# IP-268 TBE：交互预算受信任约束（堵住 R69 的「自信追问幻影」）
def trust_budgeted_voi(T, driver_ids, base_budget):
    return base_budget * min(T[i] for i in driver_ids)    # 低信任不得驱动高成本交互

# IP-271 SGI：自图变更 → 失效传播（类比 TF 更新使旧变换失效）
def invalidate_on_selfgraph_change(G_used, G_now, modules):
    if version(G_now) == version(G_used): return []
    dirty = {m for m in modules if deps(m) & changed_fields(G_used, G_now)}
    for m in dirty: revoke_cert(m)                        # 旧证书作废，须 re-attest
    return dirty

# IP-275 主闭环：SOMA 包裹 R69（FLUID 成为受信进程）
def SOMA_round(M, obs):
    G = M.sgm.snapshot()                                  # 版本化自图
    rho, parts, A = M.prp.probe(M.krn, M.p_t, obs.p, G)   # 身体残差 + 归因
    T = M.tld.update(rho, parts, M.contracts)             # 信任账本
    quarantined = M.ioe.enforce(M.contracts, T)           # 隔离违约模块
    M.sgm.invalidate(M.last_G, G)                         # 失效传播
    if not M.qrn.fresh(M.last_evidence):                  # 时效：过期视同缺失
        M.last_evidence = None
    # R69 的 FLUID 只作为「提议者」，其交互预算被信任门控
    proposal = FLUID_RAS_round(M.fluid, obs)              # 继承 R69
    cert = compose_certificate(proposal, rho, A, T, G, M.qrn)
    if not cert.valid:                                    # 沿降级格回退
        return M.lattice.fallback(proposal, cert.reason)
    return M.krn.dispatch(proposal, module_id='fluid')    # 唯一出口
```

## 3. 推导

**引理 19（本体通道的非自指性与欺骗检测下界）** R69 的 FMA 用 `p_θ(ξ|o)` 作第二意见，而 `p_θ` 即被怀疑的策略，构成自指。本体残差 `ρ_t = p_{t+1} − F_body(p_t, e_t, G_self)` 由硬件派发 `e_t` 与本体感知 `p_t` 计算，不经过外感受学习栈。在 A99（本体通道与外感受通道条件独立、本体传感器未被攻破）下，`ρ_t` 对「外感受模块的声称偏差 Δ」是充分统计量：`E[r_body] ≥ c‖Δ‖ − √(tr Σ_ρ)`。故 **欺骗检测不再自指**，且检测能力不随流模型被投毒而降级。系：R69 的「第二意见」升级为「第三意见」，且这条意见不与被审对象共享参数。

**引理 20（信任账本无膨胀）** 更新式对 `contract_i` 是指数为遗忘的压缩（增益 α<1），且惩罚项单向非负；由于自我声明不进入 `contract_i`，模块无法通过「自我表扬」抬高 `T_i`。在诚实模块上 `T_i` 有界且不虚高；在攻击者上，所需伪造的 `contract_i` 必须同时骗过身体残差与交叉证据，代价随 `r_decep` 单调上升。违约检测延迟上界为 QoS deadline `δ`（定义 322）。

**引理 21（自图失配误差不累积）** 若自图失配量为 `ε_g` 且**未**做失效传播，则依赖模块的模型误差随运行时间线性累积（旧几何/旧负载被持续误用）。加入定义 321 的失效传播后，任何 `ε_g` 变化都会在 `δ` 内触发 `revoke + re-attest`，误差被钉在 `O(ε_g)` 而非 `O(ε_g·t)`。这从机制上解释了「体模必须版本化」。

**定理 18（SOMA 严格包含 FLUID ⊃ R68）** 当所有契约通过、自图稳定、`T_i ≥ τ_trust` 且证据新鲜时，SOMA 与 FLUID 逐指令相同；任意违约只沿定义 320 的降级格向下移动，不会向上跳回。因此 SOMA 在任意状态上的期望风险 ≤ R69 ≤ R68，且 R69/R68 恰为「信任无损/永不交互」的边界。**安全侧不做任何让步，新增层只增加可证伪性与恢复纪律。**

**定理 19（非干涉与最小 TCB）** 在定义 318 的微内核派发下，任意（包括被攻破的）模块子集无法改变安全包络 `𝒮`；组合证书的 soundness 归结为「内核 + 本体硬件根」这一最小 TCB，其规模与模块数 `n` 无关。结合定义 326，`P(unsafe)` 的上界只含 `O(1)` 的内核项与各模块的 `(1−T_i)` 加权项。这是对「每加一层多一个黑箱」的构造性回答：**把 n 个需要信任的模型压成 1 个可验证内核 + 1 个物理根。**

**定理 20（组合证书的 soundness 与时效）** 若 `J_SOMA` 有效，则在 `[t, t+δ]` 内（a）安全包络未被越权扩展，（b）所有参与决策的模块信任不低于阈值，（c）身体残差与归因歧义在界内；任一条件在 `δ` 内失效，证书自动作废并触发降级。证书不是「永久正确」的断言，而是「在此时窗内可辩护」的断言——这正是把 R69 的静态证据纪律升级为**时间有界的可辩护性**。

## 6. 本轮最大风险

**一句话**：SOMA-RAS 把信任的根交给了本体感知——**若本体通道本身被攻破或被系统性偏置（传感器伪造、前向身体模型失配、机械故障伪装成正常本体反馈），那么「以身体为锚」的认证会让整个栈一致地骗过自己：坏模块显得健康、诚实模块显得有罪，而内核因为信任这根锚反而会批准它**；这比 R69 更危险，因为它把单点故障放在了信任拓扑的**根**上。

**次级风险与缓解**：
1. **本体自证退化**（用本体残差证明本体健康）→ 定义 323「本体自证禁令」+ 物理不变量（能量/动量/热/电流-力矩）交叉校验 + 冗余本体模态；
2. **内核自身被攻破**（TCB 扩大、供应链）→ 最小化内核、形式化验证、签名启动、E312 覆盖审计；
3. **信任更新被慢速投毒**（长期低幅违约被 α 吸收，即 R68 风险的信任版）→ 快慢双通道（定义 325）+ 回滚点 + E304/E310；
4. **失效传播过度**（一次自图更新雪崩式作废全栈）→ 依赖粒度化 + 影响集限幅 + 分级重认证；
5. **实时预算被新增层击穿** → PRP/SGM 脏集 O(1) 快路径 + 仅违约时重认证。

class CertifiedKernel:
    def dispatch(self, proposal, module_id):
        if not self.acl.allows(module_id, proposal.kind): return REJECT
        if not cert_pipeline.valid(proposal, self.S):      return REJECT   # 只收紧
        e = sign(self.attest, proposal)                    # 模块无法伪造
        self.efference.append(e)
        return actuate(e)                                  # 安全包络唯一出口

# IP-266 PRP：本体残差 + 能动性归因（不经过外感受学习栈，打破自指）
def proprioceptive_probe(krn, p_t, p_next, G_self):
    e_t   = krn.efference[-1]
    p_hat = F_body(p_t, e_t, G_self)
    rho   = p_next - p_hat
    r_self, r_ext, r_decep = project(rho, J_e(e_t), J_ext, G_self)
    A = 1.0 - max(r_self, r_ext, r_decep) / (r_self + r_ext + r_decep + EPS)
    return rho, (r_self, r_ext, r_decep), A

# IP-267 TLD：信任账本（只吃可证伪证据）
def trust_update(T, i, contract_ok, violation, stale):
    T[i] = clip(T[i] + ALPHA*(contract_ok - T[i]) - BETA*violation - GAMMA*stale, 0, 1)
    return T

# IP-268 TBE：信任门控的交互预算（堵住「自信追问幻影」）
def trust_budgeted_voi(T, driver_ids, base_budget):
    return base_budget * min(T[i] for i in driver_ids)

# IP-271 SGI：自图变更 → 失效传播（类 TF 更新）
def invalidate_on_selfgraph_change(G_used, G_now, modules):

## 4. 推导

**引理 19（本体通道的非自指性与欺骗检测下界）** R69 的 FMA 以 `p_θ(ξ|o)` 为第二意见，而 `p_θ` 即被怀疑对象，构成自指。本体残差 `ρ_t` 由硬件派发 `e_t` 与本体 `p_t` 计算，不经外感受学习栈。A99（两通道条件独立、本体未破）下，`ρ_t` 对「外感受声称偏差 Δ」是充分统计量：`E[r_body] ≥ c‖Δ‖−√(trΣ_ρ)`。⇒ 欺骗检测不随流模型投毒而失效。

**引理 20（信任账本无膨胀）** 更新式对 `contract_i` 为指数遗忘压缩（α<1），惩罚项单向非负，且自我声明不入式。⇒ 模块无法自我抬升信任；攻击者须同时骗过身体残差与交叉证据，代价随 `r_decep` 上升；违约检测延迟 ≤ QoS deadline `δ`。

**引理 21（自图失配误差不累积）** 若无失效传播，自图失配 `ε_g` 使依赖模块误差随运行时间线性累积；加入定义 321 后，任何 `ε_g` 变化在 `δ` 内触发 `revoke + re-attest`，误差被钉在 `O(ε_g)` 而非 `O(ε_g·t)`。

**定理 18（SOMA 严格包含 FLUID ⊃ R68）** 契约全通过、自图稳定、信任达标且证据新鲜时，SOMA 与 FLUID 逐指令相同；任意违约只沿降级格向下。⇒ 期望风险 ≤ R69 ≤ R68；R69/R68 为「信任无损/永不交互」边界。安全不让步，新增层只加可证伪性与恢复纪律。

**定理 19（非干涉与最小 TCB）** 微内核派发下，任意（含被攻破）模块子集无法改变 `𝒮`；组合证书 soundness 归结为「内核 + 本体硬件根」这一最小 TCB，规模与模块数无关。结合定义 326，`P(unsafe)` 上界只含 `O(1)` 内核项与各模块 `(1−T_i)` 加权项。⇒ 把 n 个待信模型压成 1 个可验证内核 + 1 个物理根。

**定理 20（证书 soundness 与时效）** `J_SOMA` 有效 ⇒ 在 `[t,t+δ]` 内：安全包络未被越权扩展、参与模块信任达标、残差与歧义在界；任一条件失效则证书作废并降级。证书不是「永久正确」，而是「此时窗内可辩护」——把 R69 的静态证据纪律升级为时间有界的可辩护性。

## 7. 本轮最大风险

**一句话**：SOMA-RAS 把信任的根交给了本体感知——**若本体通道本身被攻破或被系统性偏置（传感器伪造、前向身体模型失配、机械故障伪装成正常本体反馈），「以身体为锚」的认证会让整个栈一致地骗过自己：坏模块显得健康、诚实模块显得有罪，而内核因为信任这根锚反而会批准它**——这比 R69 更危险，因为它把单点故障放在了信任拓扑的根上。

**次级风险与缓解**：本体自证退化（定义 323 自证禁令 + 能量/动量/热/电流-力矩不变量交叉校验 + 冗余本体模态，E311）；内核被攻破（最小 TCB + 形式化验证 + 签名启动，E312）；信任慢速投毒（快慢双通道 + 回滚点，E304/E310）；失效传播雪崩（依赖粒度化 + 影响集限幅 + 分级重认证，E305/E308）；实时预算被新增层击穿（脏集 O(1) 快路径 + 仅违约时重认证，E314）。
