# 第 72 轮（承接第 71 轮「GAUGE-RAS 计量审计层」IP-275~286；灵感循环第 2 轮；本轮灵感：「行为克隆」×「场景落地」）

> R71 把信任从 H[b_t] 转移到「指标系统 + 情感通道」，但它默认了两件事：**（a）被认证的策略来自在线学习/流匹配，其误差主要表现为随机噪声与可被交互消解的 epistemic；（b）部署是一个逐指令的在线问题。** 行为克隆（BC）同时打破这两条。BC 的策略是**有限示范数据集的监督压缩**：它只在示范者走过的状态上有标签；在示范者没走过的状态上，**根本不存在正确答案**——不是「不确定」，而是「未定义」。R71 的 U_epi 可以靠看/问/触降低，但没有任何信息动作能凭空造出一个示范者从未给出的动作标签。更麻烦的是，BC 会连示范者的**盲区与坏习惯**一起继承：示范者在某类场景本来就不行，模仿得越像，错得越稳。
>
> 「场景落地」补上另一块。实验室里的 BC 用「平均动作误差」验收；真实部署用「在运营设计域（ODD）内的长尾场景里，能否连续数周不出事」验收。两者之间的鸿沟不只是「分布偏移」的工程注脚，而是**认证对象换了**：从「策略在一个采样分布上准不准」变成「这套人—机—场景系统，在一个被声明、被监控、可回滚的运营范围内安不安全」。落地失败最常见的原因不是算法不收敛，而是**范围被偷换**：把测不过的场景宣布为「域外」，把狭窄的 ODD 当成绩，把验收用例当成优化目标，把「demo 能跑」当成「部署可用」。
>
> 本轮两个灵感正好补两块认知缺口：
> - **行为克隆**：把「状态不确定」升级为「三种不确定性」。U_ale（噪声，不可约）、U_epi（有标签但未观测，可被 VoI 降低）、U_sup（**根本没有标签**，只能靠升级/退回/重新采集示范）。并引入「系绳」：BC 的闭环误差随时间复利增长，存在一个可计算的**可信任步数 T_exit**，部署必须按这个节律重新锚定。
> - **场景落地**：把 ODD 从一句免责声明升级为一等公民——场景语法、独立需求范围 R、成员估计、覆盖账本、密封对抗场景族、顺序检验发布门、回滚与接管。认证从「逐指令证书」升级为「**范围证书 + 发布状态机 + 再锚定节律**」。
>
> 核心命题：**不再只问「我的策略在这些状态上像不像专家」，而问四件事：专家在哪些场景真的可信；这些场景是否覆盖了必须覆盖的运营范围；在没有标签的地方我还能走多远；一旦越界，谁在 leash 的另一端接住我。** 命名 **TETHER-RAS**（Teacher-grounded, Envelope-bounded, Traceable, Human-escalating, Evidence-gated Risk-aware deployment）。策略被一根可测量的系绳拴在「示范支撑 × 专家能力 × 声明 ODD」上；部署不是一次盖章，而是一套带节律的重新锚定与发布门。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我该信哪个状态」，R71 问「我用来判断的尺子可信吗」，R72 问「**教我的人只教到这儿——我还能走多远，绳子断之前谁接住我**」——安全不再只是一个阈值，而是一条**有长度、有范围、有交接人的系绳**。

## 0. 直觉与动机

**灵感 1（行为克隆 → 第三种不确定性：没有标签，而不是标签难猜）**
直觉：R70 的 epistemic 是「有一个真实状态 s，我只是没看清」；R71 的计量审计是「我估 s 的尺子准不准」。BC 面对的是第三种情形：**示范者根本没在这个状态上做过动作，因而不存在「正确动作」这个待估量。** 这不是方差大，也不是后验宽，而是**条件分布没有定义**。把这个东西塞进 H[b_t] 会被误读成「再问一句就好」；可你问谁？问环境不会给你动作标签，问示范者也只是请他在一个新状态上**重新当一次老师**。所以 U_sup 与 U_epi 的操作后果完全相反：前者禁用 VoI，只允许升级、退回或离线补示范。这是本轮第一条硬边界。

**灵感 2（复合误差 → 安全是一个「节律」，不是一个「布尔值」）**
直觉：BC 在示范分布上每步只差一点点 ε，但闭环会把这个小误差喂回输入：稍微偏一点 → 看到的状态就偏离示范 → 动作更偏。若动力学是扩张的（Lipschitz 常数 L>1），偏差按 L^t 复利；若动力学是收缩的（L<1），偏差会被拉回一个有界球。于是存在一条**可计算的系绳长度 T_exit**：在没有新锚点的情况下，策略大约还能安全走多少步就会离开支撑。**「这策略安不安全」因此不是一个 yes/no，而是「每隔多少步必须重新接地」。** 这条结论直接改变落地形态：不是求一个永久证书，而是设计一个 re-anchor 节律（人工纠偏、回到已知状态、换用已验证策略、离线重训）。

**灵感 3（示范者不是神 → 嵌套信任：支撑 × 能力）**
直觉：数据是「专家做过的」，不等于「专家做对的」。R71 已经给「回答者可信度 c(ψ)」建了模；本轮把它从「这条回答值多少」升级为「这位老师在这类场景值多少」。可信域是二维的：**看过没有（支撑）× 做对没有（能力）**。最危险的不是「没看过还乱做」，而是「看过、但示范者本来就做得不好」——BC 会以极高置信度复制一个坏习惯，而且它的训练损失还很漂亮。因此「像专家」绝不能替代「是对的」。

| | 示范者在该场景有能力 c_E ≥ c_min | 示范者无能力 c_E < c_min |
|---|---|---|
| **在支撑内** s ∈ S_E^r | 可模仿：正常控制 + 可选 VoI | **最危险**：高置信复制坏习惯 → 必须降权/拒绝/换老师 |
| **在支撑外** s ∉ S_E^r | 可升级：请专家现场示范（产生新标签） | 拒绝/退回：没有老师，也没有正确答案 |

**灵感 4（场景落地 → ODD 是认证对象，不是免责声明）**
直觉：部署真正的问句不是「策略在哪准」，而是「**被认证的范围，是否覆盖了业务要求必须覆盖的范围**」。如果 ODD 由被认证方自己划，就永远可以通过把失败场景宣布为「域外」来通过——这叫 **ODD laundering**。所以需求范围 R 必须由发布门外的独立方密封给定，ODD 必须 **⊇ R**，而不是「ODD 内的都过了」。同时，固定的验收场景集会立刻变成优化目标（R71 的 Goodhart 在场景层的镜像），必须有同构念、异实现的密封/对抗场景族来测「场景 Goodhart 间隙」。最后，现场数据大多是**无动作标签、且被策略自己选择过**的：拿它闭环再训练会自我确认、越练越偏；只有人工纠正与专家示范才是真标签。

**灵感 5（严格包含 → 新层必须能整体关掉）**
直觉：当支撑覆盖 ODD、专家能力饱和、动力学收缩、无场景/因果偏移时，TETHER 应当**逐指令退化为 R71 GAUGE**，再退化为 BELIEF/FLUID/R68。新增的只是「范围、节律、发布门」这些**治理与审计层**，不是又一个必须被信任的黑箱。否则每加一层就多一个故障源——这是 R70/R71 反复自陈的教训。**本轮所有自动化程度的提升，都以「范围可证、节律可执行、越界可接管」为代价换取。**

## 1. 形式化定义（增量：定义 349–364）

**定义 349（TETHER-RAS 总览）** TETHER-RAS = (SCOPE, ODD-G, SUS, TETHER, CIP, COV, SCEN, RELEASE, HANDOFF, FIELD, J_TETHER, GAUGE-RAS†)。五不变式：
(i) **实时流零学习写操作**（继承 R71 定义 331-i）：现场数据只进离线发布门，绝不进在线策略；
(ii) **范围完整性**：任何部署证书必须同时声明 ODD 𝒪 与独立需求范围 R，且 𝒪 ⊇ R；
(iii) **支撑优先**：U_sup 未消解时**禁用 VoI 消歧**，只允许升级（定义 360）或退回（回退 R71）；
(iv) **系绳节律**：两次 re-anchor 的间隔 ≤ T_exit/κ_safe（定义 356）；
(v) **不可补偿**：SCOPE/支撑/能力/因果/安全任一门失败 ⇒ 证书失效，性能与覆盖率不得反向补偿（继承 R71 定义 334）。

**定义 350（示范数据与行为克隆策略）** 示范集 D = {(s_i, a_i, e_i, τ_i)}，e_i 为示范者/批次标识，τ_i 为追溯链。π_E 为示范策略；BC 目标 L_BC(θ) = E_D[−log π_θ(a|s)]（确定性专家可用 MSE）。**TETHER 不依赖策略类**：π_θ 可以是回归、流匹配或扩散；本轮补的是「标签从哪来、能信到哪」，不是「怎么拟合」。

**定义 351（策略状态分布与示范支撑集）** d_t^{π}(s) 为策略 π 第 t 步的状态访问分布；示范支撑集
S_E^r = { s : dist(s, supp d^{π_E}) ≤ r }，
即**示范者闭环可达流形**的 r-邻域。**关键：不是示范数据点的凸包。** 凸包会把两个示范者从未连续穿越过的区域也算成支撑，制造虚假的「我见过」。支撑必须来自闭环可达性（或可达性估计），否则 U_sup 会系统性低估。

**定义 352（支撑不确定性与三分解）** 若 s ∉ S_E（严格说：p(a_E | s) 在数据生成过程下未定义或密度为零），令 U_sup(s) = 1；一般化用 novelty 分数。总体分解为
U = U_ale + U_epi + U_sup，
三者语义不同、**不可简单相加进同一个 λ**：
- U_ale：不可约噪声 → R68 的 λ_floor；
- U_epi：有标签但未观测 → R71 的 VoI 可降低；
- U_sup：**没有标签可被观测** → VoI 恒为零收益，只能升级/退回/补示范。
**「问」对 U_sup 是沉默的，不是有帮助的。**

**定义 353（专家能力后验与 SCOPE 可信域）** c_E(θ) ∈ [0,1] 为示范者在场景参数 θ 上的能力/正确性后验，由结果标签、多示范者一致性、人工复核、干预试验估计。可信域
SCOPE = { (s, θ) : s ∈ S_E^r ∧ c_E(θ) ≥ c_min }。
**SCOPE 是「支撑 × 能力」的交集，不是任一单独条件。** 在演示数据上「像专家」只是必要条件，不是充分条件。

**定义 354（场景语法、ODD 与需求范围）** 场景参数 θ ∈ Θ，由场景语法生成（道路/光照/人流/地面摩擦/任务/交互者属性/传感退化…）。𝒪 ⊆ Θ 为声明的运营设计域；R ⊆ Θ 为**独立需求方密封给定**的必须运营范围。部署要求 𝒪 ⊇ R（并留 margin）。成员估计 m_𝒪(θ) ∈ [0,1] 带不确定度，只有 m_𝒪(θ) ≥ 1−α 才视为域内。**R 不得由被认证团队划定**——这是防止 ODD laundering 的制度性约束，不是技术细节。

**定义 355（因果不变性探针 CIP）** 设候选因果特征 C 与 nuisance N。要求 π_θ 对 do(N) 不变、对 do(C) 敏感。定义因果混淆间隙
I_cc = E_{c, n≠n'}[ TV( π_θ(·|c,n), π_θ(·|c,n') ) ]，
在**应当不变**的 n,n' 上计算。纯观测 BC 在一般情形下**不可识别**因果方向；因此 J_TETHER 必须携带「因果充分性假设成立」或「该 ODD 内相关性稳定」的证据，否则只能把认证限制在相关性稳定的子域。

**定义 356（系绳长度 TETHER）** 设闭环动力学 f 关于 (s,a) 联合 L-Lipschitz，支撑内 per-step 动作误差 ≤ ε，状态偏差 δ_t = ‖s_t^θ − s_t^E‖。则
δ_{t+1} ≤ L·δ_t + L·ε。
L<1 时 δ_t 收敛到 εL/(1−L)，系绳无限长；L>1 时
T_exit ≤ ⌈ log(1 + r(L−1)/(Lε)) / log L ⌉
是「偏差首次超过支撑半径 r」的步数上界。**部署规则：re-anchor 间隔 k ≤ T_exit/κ_safe（κ_safe>1 为安全系数）。**

**定义 357（覆盖与长尾账本 COV）** 场景覆盖 Cov_θ(𝒪) = P_{θ~p_req}(θ ∈ 已覆盖 ∧ m_𝒪≥1−α)，按**需求分布 p_req 加权**，不是「场景条数」。行为覆盖 Cov_b = 支撑内被示范覆盖的状态质量。长尾账本为每类稀有场景记录样本数、能力后验、失败案例与最近一次验证时间。**覆盖是一个分布量，不是一个计数。**

**定义 358（密封/对抗场景族 SCEN）** 每个验收场景族 A_j 配一个**同构念、异实现**的密封族 A_j⊥（不同生成器、隐藏参数、对抗生成）。场景 Goodhart 间隙 D_scen = |perf_A − perf_{A⊥}|。A⊥ 在线不可见（继承 R71 定义 336 SEAL），用于防止「验收用例调参」。

**定义 359（发布门 RELEASE）** 部署状态机：
OFFLINE → SHADOW（只记录不执行）→ CANARY（受限权限/受限 ODD）→ GUARDED（人可随时接管）→ SUPERVISED → AUTONOMOUS。
转移使用 **always-valid confidence sequence / e-value** 做顺序检验，控制「反复看结果再决定」导致的误认证；任一 veto（支撑/ODD/能力/因果/安全）失败 ⇒ **自动回滚**到上一状态。**发布门不是一次考试，而是一条有记忆、可回滚的状态机。**

**定义 360（升级与接管 HANDOFF）** U_sup 未消解且不能退回时，唯一合法动作是升级（求助现场人/远程操作员/切换到已验证策略）。接管有延迟预算 t_hand < t_crit（到临界的时间），且需定期演练以防自动化自满；升级动作本身要过安全认证（继承 R71 定义 343 证据纪律）。

**定义 361（现场数据与反确认 FIELD）** 现场数据分四类：专家示范（有 a 标签）、人工纠正（有 a 标签，最珍贵）、策略自执行（**无** a 标签）、影子运行（无执行）。发布训练必须带 provenance 与 intervention log；**禁止只用策略自执行数据做闭环再训练**（否则确认偏差/模型自噬）。密封集永不进训练。

**定义 362（威胁模型 AIC-TETHER）** ℰ_TETHER = ℰ_GAUGE × ℰ_scope × ℰ_deploy：
ℰ_scope = { ODD laundering（缩域免责）、支撑伪造（凸包注入）、专家能力高估、因果混淆/捷径学习、示范投毒 }；
ℰ_deploy = { 验收用例过拟合、顺序检验 peeking、现场数据自噬、接管延迟、自动化自满、回滚失败、版本漂移 }。

**定义 363（证书 J_TETHER）** J_TETHER = (J_GAUGE, scope_set, odd_margin, support_novelty_p95, competence_posterior, tether_length, causal_gap, coverage_ledger, scen_gap, release_state, handoff_budget, field_provenance, tether_ver)。
Valid ⇔ Valid(J_GAUGE) ∧ 𝒪 ⊇ R ∧ SCOPE 覆盖 𝒪 ∧ T_exit>0 且 re-anchor 节律满足 ∧ 因果/场景/覆盖门通过 ∧ 发布状态合法。

**定义 364（退化与包含）** 当 D 的支撑覆盖 𝒪=R、c_E≡1、L<1（或 T_exit > 部署时域）、无场景/因果偏移时，TETHER 逐指令等于 GAUGE；再按 R71 定义 348 退化为 BELIEF → FLUID → R68。**安全侧只增不减；自动化程度只在所有门通过时增加。**

## 2. 关键算法骨架

```python
# IP-287 SCOPE：示范支撑（闭环可达，而非凸包）+ 专家能力后验
class ScopeModel:
    def __init__(self, density, reach_est, competence_head):
        self.q, self.reach, self.comp = density, reach_est, competence_head
    def support(self, s, r):
        return self.q(s) > Q_MIN and self.reach.dist_to_expert_manifold(s) <= r
    def competence(self, theta):
        return self.comp.posterior(theta)          # c_E(theta) + uncertainty
    def in_scope(self, s, theta, r, c_min):
        return self.support(s, r) and self.competence(theta).mean >= c_min

# IP-288 ODD-G：场景成员 + 需求范围包含（R 独立密封）
def odd_gate(theta, m_odd, R_sealed, ODD, alpha):
    if not R_sealed.subset_of(ODD): return Gate(False, 'ODD_NOT_COVER_R')
    return Gate(m_odd(theta) >= 1 - alpha, reason='ODD_MEMBER')

# IP-289 SUS：三分解；U_sup 不可由 VoI 降低
def decompose_uncertainty(b_t, s, scope, r):
    u_ale = b_t.aleatoric()
    u_epi = b_t.epistemic()
    u_sup = 0.0 if scope.support(s, r) else 1.0
    return u_ale, u_epi, u_sup

# IP-290 TETHER：系绳长度与再锚定节律
def tether_length(L, eps, r, kappa_safe=2.0):
    if L < 1.0: return float('inf')
    if eps <= 0: return float('inf')
    t = math.ceil(math.log(1 + r*(L-1)/(L*eps)) / math.log(L))
    return max(1, int(t // kappa_safe))         # 两次 re-anchor 的最大步数

# IP-291 CIP：因果混淆探针（干预，而非观测）
def causal_gap(policy, env, causal_feats, nuisances, n_pairs=32):
    gaps = []
    for c in causal_feats:
        for n1, n2 in sample_nuisance_pairs(nuisances, n_pairs):
            p1 = policy(env.do({**c, **n1}))
            p2 = policy(env.do({**c, **n2}))
            gaps.append(total_variation(p1, p2))
    return max(gaps, default=0.0)              # I_cc > tau_cc -> 门失败

# IP-292 COV：需求加权覆盖 + 长尾账本
def coverage(ledger, p_req, m_odd, alpha):
    return sum(p_req(theta) for theta in ledger.covered
               if m_odd(theta) >= 1 - alpha)

# IP-293 SCEN：验收族 vs 密封对抗族的场景 Goodhart 间隙
def scenario_goodhart(accept_perf, sealed_perf):
    return abs(accept_perf - sealed_perf)       # D_scen > tau_scen -> 告警

# IP-294 RELEASE：顺序检验 + 自动回滚的状态机
STATES = ['OFFLINE','SHADOW','CANARY','GUARDED','SUPERVISED','AUTONOMOUS']
def release_step(state, evidence, gates, cs):
    if any(not g.pass_ for g in gates):
        return 'ROLLBACK', state                  # 不可补偿
    if not cs.cover(evidence, threshold=SAFE_RATE):
        return state, state                       # 继续当前状态收集证据
    return STATES[min(STATES.index(state)+1, len(STATES)-1)], state

# IP-295 HANDOFF：接管/升级（唯一合法的 U_sup 处理）
def handoff(scope, s, theta, t_crit, t_hand_est):
    if scope.in_scope(s, theta, R_SUP, C_MIN): return None
    if t_hand_est >= t_crit: return 'EMERGENCY_STOP'   # 来不及时先停
    return 'REQUEST_OPERATOR'                          # 否则升级

# IP-296 FIELD：现场数据 provenance 与反确认
def accept_for_training(record):
    return record.label_kind in ('expert_demo', 'human_correction') \
           and record.provenance.verify() \
           and not record.in_sealed_holdout

# IP-297 GATE：证书 J_TETHER 的门（任一失败即失效）
def tether_gate(J, scope, s, theta):
    checks = [J.gauge_valid, J.odd_covers_required,
              scope.in_scope(s, theta, R_SUP, C_MIN),
              J.tether_length > 0, J.causal_gap <= TAU_CC,
              J.scen_gap <= TAU_SCEN, J.coverage >= COV_MIN]
    return Gate(all(checks), reasons=[i for i,c in enumerate(checks) if not c])

# IP-298 TETHER 主闭环：四时标分离，慢环永不阻塞快环
def TETHER_round(M, obs, theta, audio):

    else:

        action = M.ach.propose(...)
    # --- 中频（100ms–1s）：支撑/ODD 监测 + 系绳计数器 ---
    if M.clock.due_scope():

            M.release.request('ROLLBACK_TO_GUARDED')
        M.tether.tick()                              # 超过节律 -> 强制 re-anchor

    return action, u_ale, u_epi, u_sup, J_TETHER(M)
```

## 3. 推导

**引理 28（U_sup 对 VoI 不可约）** 设专家动作的先验 p(a_E|s) 在示范支撑外未定义（数据生成过程下密度为零）。任何信息动作 g 的 VoI 定义为 H[p(a_E|s)] − E_y H[p(a_E|s,y)]，当 p(a_E|s) 无定义时两项均无定义；用极限/正则化定义时，条件互信息 I(a_E;Y|s∉S_E)=0（因为 a_E 与任何可观测量在同一零测事件上不联合可测）。故 VoI(g)≤0。**系：在支撑外，R71 的 MINT/RVOI 不是「算出来收益小」，而是「问错了对象」——只有升级（请人给出新标签）或退回才能改变 U_sup。**

**引理 29（系绳长度的收敛/发散二分）** 由定义 356 的递推 δ_{t+1}≤Lδ_t+Lε：L<1 时 δ_t→εL/(1−L)，永不出支撑（若该值<r）；L>1 时 δ_t 单调增，首次超过 r 的步数满足 T_exit ≤ log(1+r(L−1)/(Lε))/log L。**系：BC 的可部署性主要由场景动力学的 L 决定，而非仅由训练损失决定。收缩场景可以「原谅」BC 误差；扩张场景不能。这条把「选场景」从商业决策变成安全决策。**

**引理 30（纯观测 BC 的因果不可识别）** 若两个结构因果模型 M1、M2 在示范分布 D 上诱导相同的 p(s,a)，但在某个干预 do(N=n) 下给出不同的最优动作，则任何只依赖 p_D(s,a) 的 BC 算法都无法区分 M1、M2；在干预分布上其误差可无界。故证书必须：(i) 有干预/不变性证据把 I_cc 压到阈值下，或 (ii) 把部署限制在相关性结构稳定的子域。**系：CIP 不是可选的调试工具，而是 BC 证书的合法性前提。**

**引理 31（场景 Goodhart 间隙的可检测性）** 设验收性能 perf_A 与密封族性能 perf_A⊥ 共享构念 φ，但实现/混杂不同。对验收族做选择/调参使 ∂perf_A/∂θ>0 而 ∂perf_A⊥/∂θ≈0，则 D_scen=|perf_A−perf_A⊥| 的期望随调参上升，而真实 φ 可不变。K 个近似独立的密封族提升检测功效。**系：没有密封对抗场景族的「场景覆盖率」，等价于给「过拟合验收集」发合格证。**

**引理 32（顺序发布门的 anytime 有效性）** 用 always-valid confidence sequence（或 e-value 的 Ville 不等式）替代固定样本检验，则对任意停时 τ，P(在 τ 处错误认证 真实不安全率>δ) ≤ α，无需校正「看了多少次」。**系：分阶段 rollout 中反复看指标再决定不会像重复 p 检验那样膨胀误认证率；这让「边部署边观察」在统计上合法。**

**定理 23（TETHER 的风险界）** 在 A106–A110（支撑/ODD 可检、专家能力后验校准、c_E 与支撑条件独立于策略选择、动力学 Lipschitz、CIP 门有效）下，若一次部署通过 J_TETHER，则其期望风险 ≤ R71 的 ε_cert + 支撑外质量项 + 能力不足项 + 因果混淆项，且后三项被门控置零；任一 veto 失败则强制回退 R71 或拒绝部署。故 TETHER 的期望风险 ≤ R71。**全部重量落在「支撑与 ODD 的估计本身有效」上**——这正是本轮最大风险。

**定理 24（再锚定节律的稳定性）** 若每次 re-anchor 间隔 k ≤ T_exit/κ_safe，则闭环状态偏差始终有界（L<1 时 ≤εL/(1−L)，L>1 时 ≤r）；且 re-anchor 动作本身通过安全认证时，系统不进入「越界—纠偏—再越界」的振荡。**系：BC 的长时程安全可以分解为「短时程系绳 + 周期性接地」，而不是要求一个永不犯错的策略。**

**定理 25（严格包含链）** 在定义 364 的退化条件下，TETHER 逐指令等于 GAUGE；GAUGE ⊂ BELIEF ⊂ FLUID ⊂ R68（R71 定理 20）。故安全侧永不弱于 R71；自动化程度只在所有门通过时增加。**新层不是新黑箱，而是旧层之上的范围与节律治理。**

## 6. 本轮最大风险

**一句话**：TETHER-RAS 把信任从「策略本身」转移到「**示范支撑集 × 专家能力 × 声明 ODD**」——而这三者恰好都可以由希望它通过的人来划定和测量：把失败场景宣布为「域外」（ODD laundering），把支撑量在训练分布或凸包上（虚假支撑），把专家能力默认满分（把「像专家」当成「对」）。于是系统会用一张**自己签发、自己审计的范围证书**，在真实世界的长尾里运行；它不再「自信地错状态」，而是**「合规地错范围」——每一份日志都能证明它在证书允许的地方，而那份证书从未覆盖过它实际去的地方。**

**次级风险与缓解**：
1. **ODD 偷换** → 需求范围 R 由发布门外的独立方密封；𝒪⊇R 是硬约束；覆盖按 p_req 加权而非计数；E344 专测缩域攻击。
2. **支撑估计过宽/凸包伪造** → 用闭环可达流形而非数据凸包；OOD/新颖性分数与可达距离双通道；E342 对照凸包基线。
3. **专家能力被高估** → 多示范者一致性 + 结果标签 + 接管日志 + 干预试验联合估计；能力不足场景强制降权/换老师；E345。
4. **因果混淆** → CIP 干预证据或限制到相关性稳定子域；不可识别即拒绝认证；E346。
5. **场景过拟合** → 同构念异实现的密封/对抗族 + 场景 Goodhart 间隙；E347。
6. **现场数据自噬** → 只接受专家示范/人工纠正进训练；自执行数据只做监测；provenance + 密封 holdout；E351。
7. **接管来不及时/自动化自满** → t_hand < t_crit 硬约束，来不及时先急停；定期接管演练；E350。
8. **过度保守/无法落地** → veto 只覆盖支撑/ODD/能力/因果/安全；性能与成本在门内排序；E324/E357 量化代价。

| `SCOPE = {s∈S_E^r ∧ c_E(θ)≥c_min}` | 支撑 × 能力的可信域 |

| `J_TETHER = (J_GAUGE, scope, odd_margin, u_sup_p95, c_E, T_exit, I_cc, cov, D_scen, release, handoff, provenance, ver)` | 部署证书 |

## 2. 形式化定义（要点版）

**定义 349（总览与五不变式）** 继承 GAUGE 全部组件（† 升级），新增范围/节律/接管/发布层。五不变式：(i) 实时零学习写操作，现场数据只进离线发布门；(ii) 范围完整性 𝒪⊇R（R 独立密封）；(iii) 支撑优先：U_sup 未消解时禁用 VoI；(iv) 系绳节律 k≤T_exit/κ_safe；(v) veto 不可补偿。

**定义 350（示范与 BC 策略）** D={(s_i,a_i,e_i,τ_i)}；L_BC(θ)=E_D[−log π_θ(a|s)]。TETHER 不依赖策略类（回归/流匹配/扩散均可），补的是「标签来源与可信范围」。

**定义 351（示范支撑集）** S_E^r 为示范者闭环可达流形的 r-邻域，**不是数据点凸包**。凸包会把从未被连续穿越的区域算作支撑，系统性地低估 U_sup。

**定义 352（三分解）** U=U_ale+U_epi+U_sup。U_ale 进 R68 λ_floor；U_epi 走 R71 VoI；U_sup **无标签可观测**，VoI 收益恒为零，只能升级/退回/补示范。**「问」对 U_sup 是沉默的。**

**定义 353（SCOPE）** 专家能力后验 c_E(θ) 由结果标签、多示范者一致性、人工复核、干预试验估计；SCOPE = 支撑 ∧ 能力。**「像专家」只是必要非充分条件。**

**定义 354（场景语法与 ODD）** θ∈Θ 由场景语法生成；𝒪 为声明域，R 为独立需求方密封的必须域；要求 𝒪⊇R（含 margin）。成员 m_𝒪(θ)≥1−α 才算域内。**R 不由被认证团队划定——这是防 ODD laundering 的制度约束。**

**定义 355（CIP）** 要求 π 对 do(N) 不变、对 do(C) 敏感；I_cc 在应不变的 nuisance 对上计算。纯观测 BC 一般不可识别因果方向；证书须带「因果充分性」或「该域相关性稳定」证据，否则限制子域。

**定义 356（系绳）** 联合 L-Lipschitz 下 δ_{t+1}≤Lδ_t+Lε。L<1 收敛到 εL/(1−L)（系绳∞）；L>1 时 T_exit ≤ log(1+r(L−1)/(Lε))/log L。部署按 k≤T_exit/κ_safe 再锚定。

**定义 357（COV）** Cov_θ 按需求分布 p_req 加权；Cov_b 为支撑内状态质量；长尾账本记录稀有场景样本数/能力/失败/最近验证。**覆盖是分布量，不是场景条数。**

**定义 358（SCEN）** 每个验收族 A_j 配同构念异实现的密封族 A_j⊥；D_scen=|perf_A−perf_{A⊥}|。A⊥ 在线不可见（继承 SEAL），防验收用例调参。

**定义 359（RELEASE）** OFFLINE→SHADOW→CANARY→GUARDED→SUPERVISED→AUTONOMOUS；转移用 always-valid confidence sequence/e-value；任一 veto 失败自动回滚。**发布门是有记忆、可回滚的状态机，不是一次考试。**

**定义 360（HANDOFF）** U_sup 未消解且不能退回时，唯一合法动作是升级；t_hand<t_crit，来不及先急停；定期演练防自动化自满；升级动作本身过安全认证。

**定义 361（FIELD）** 现场数据四类：专家示范（有标签）、人工纠正（有标签，最珍贵）、自执行（无标签）、影子（无执行）。只允许前两类进训练；provenance + intervention log；密封集永不训练。

**定义 362（AIC-TETHER）** ℰ_TETHER=ℰ_GAUGE×ℰ_scope×ℰ_deploy。ℰ_scope={ODD laundering, 支撑伪造, 能力高估, 因果混淆, 示范投毒}；ℰ_deploy={验收过拟合, peeking, 数据自噬, 接管延迟, 自动化自满, 回滚失败, 版本漂移}。

**定义 363（J_TETHER）** Valid ⇔ Valid(J_GAUGE) ∧ 𝒪⊇R ∧ SCOPE 覆盖 𝒪 ∧ T_exit>0 且节律满足 ∧ 因果/场景/覆盖门通过 ∧ 发布状态合法。

**定义 364（严格包含）** 支撑覆盖 𝒪=R、c_E≡1、L<1（或 T_exit>时域）、无偏移 ⇒ 逐指令等于 GAUGE；再按 R71 定义 348 退化 BELIEF→FLUID→R68。

```python
# IP-287 SCOPE：闭环可达支撑 + 专家能力后验
class ScopeModel:
    def __init__(self, density, reach_est, competence_head):
        self.q, self.reach, self.comp = density, reach_est, competence_head
    def support(self, s, r):
        return self.q(s) > Q_MIN and self.reach.dist_to_expert_manifold(s) <= r
    def competence(self, theta):
        return self.comp.posterior(theta)          # c_E(theta) + uncertainty
    def in_scope(self, s, theta, r, c_min):
        return self.support(s, r) and self.competence(theta).mean >= c_min

# IP-288 ODD-G：成员估计 + 需求范围包含
def odd_gate(theta, m_odd, R_sealed, ODD, alpha):
    if not R_sealed.subset_of(ODD): return Gate(False, 'ODD_NOT_COVER_R')
    return Gate(m_odd(theta) >= 1 - alpha, reason='ODD_MEMBER')

# IP-289 SUS：三分解；U_sup 不可由 VoI 降低
def decompose_uncertainty(b_t, s, scope, r):
    u_ale = b_t.aleatoric(); u_epi = b_t.epistemic()
    u_sup = 0.0 if scope.support(s, r) else 1.0
    return u_ale, u_epi, u_sup

# IP-290 TETHER：系绳长度与再锚定节律
def tether_length(L, eps, r, kappa_safe=2.0):
    if L < 1.0 or eps <= 0: return float('inf')
    t = math.ceil(math.log(1 + r*(L-1)/(L*eps)) / math.log(L))
    return max(1, int(t // kappa_safe))

# IP-291 CIP：干预式因果混淆探针
def causal_gap(policy, env, causal_feats, nuisances, n_pairs=32):
    gaps = []
    for c in causal_feats:
        for n1, n2 in sample_nuisance_pairs(nuisances, n_pairs):
            p1 = policy(env.do({**c, **n1})); p2 = policy(env.do({**c, **n2}))
            gaps.append(total_variation(p1, p2))
    return max(gaps, default=0.0)              # I_cc > tau_cc -> 门失败

# IP-292 COV：需求加权覆盖
def coverage(ledger, p_req, m_odd, alpha):
    return sum(p_req(theta) for theta in ledger.covered
               if m_odd(theta) >= 1 - alpha)

# IP-293 SCEN：验收族 vs 密封对抗族
def scenario_goodhart(accept_perf, sealed_perf):
    return abs(accept_perf - sealed_perf)       # D_scen > tau_scen -> 告警

# IP-294 RELEASE：顺序检验 + 自动回滚
STATES = ['OFFLINE','SHADOW','CANARY','GUARDED','SUPERVISED','AUTONOMOUS']
def release_step(state, evidence, gates, cs):
    if any(not g.pass_ for g in gates): return 'ROLLBACK', state
    if not cs.cover(evidence, threshold=SAFE_RATE): return state, state
    return STATES[min(STATES.index(state)+1, len(STATES)-1)], state

# IP-295 HANDOFF：U_sup 的唯一合法出路
def handoff(scope, s, theta, t_crit, t_hand_est):
    if scope.in_scope(s, theta, R_SUP, C_MIN): return None
    if t_hand_est >= t_crit: return 'EMERGENCY_STOP'   # 来不及先停
    return 'REQUEST_OPERATOR'

# IP-296 FIELD：现场数据 provenance 与反确认
def accept_for_training(record):
    return record.label_kind in ('expert_demo', 'human_correction') \
           and record.provenance.verify() and not record.in_sealed_holdout

# IP-297 J_TETHER 门
def tether_gate(J, scope, s, theta):
    checks = [J.gauge_valid, J.odd_covers_required,
              scope.in_scope(s, theta, R_SUP, C_MIN),
              J.tether_length > 0, J.causal_gap <= TAU_CC,
              J.scen_gap <= TAU_SCEN, J.coverage >= COV_MIN]
    return Gate(all(checks), reasons=[i for i,c in enumerate(checks) if not c])

# IP-298 四时标主闭环：慢环永不阻塞快环
def TETHER_round(M, obs, theta, audio):
    b_t = M.bse.step(M.b_prev, obs, M.last_action, M.last_g, M.last_y)  # 高频
    u_ale, u_epi, u_sup = decompose_uncertainty(b_t, M.s, M.scope, M.r)
    if u_sup > 0:
        g = None                                     # 无标签：禁用 VoI
        action = M.handoff.route(M.scope, M.s, theta, M.t_crit)
    else:
        g = M.gauge.rvoi.choose(b_t, M.psi, M.budget, M.fmp, M.bse)
        action = M.ach.propose(...)
    if M.clock.due_scope():                          # 中频：支撑/ODD/系绳
        if not M.scope.support(M.s, M.r) or not M.odd_gate.member(theta):
            M.release.request('ROLLBACK_TO_GUARDED')
        M.tether.tick()
    if M.clock.due_drill():                          # 低频：接管演练
        M.handoff.drill(); M.scope.comp.update_readonly(M.intervention_log)
    if M.clock.due_release():                        # 超低频：发布门（离线）
        M.release.step(M.evidence, M.gates(), M.cs)
```

## 4. 推导

**引理 28（U_sup 对 VoI 不可约）** 支撑外 p(a_E|s) 未定义（密度零）。VoI=H[p(a_E|s)]−E_yH[p(a_E|s,y)] 两项均无定义；正则化后 I(a_E;Y|s∉S_E)=0。故 VoI≤0。**系：支撑外 MINT/RVOI 不是「收益小」，而是「问错对象」——只有升级或退回能改变 U_sup。**

**引理 29（系绳收敛/发散二分）** 由 δ_{t+1}≤Lδ_t+Lε：L<1 时收敛 εL/(1−L)；L>1 时 T_exit≤log(1+r(L−1)/(Lε))/log L。**系：BC 可部署性主要由场景动力学 L 决定，而非训练损失。收缩场景原谅误差，扩张场景不能——「选场景」是安全决策。**

**引理 30（纯观测 BC 的因果不可识别）** 若 M1、M2 在 D 上诱导相同 p(s,a) 但在某 do(N) 下最优动作不同，则任何只依赖 p_D(s,a) 的 BC 无法区分；干预分布上误差可无界。故证书需 (i) CIP 把 I_cc 压到阈值下，或 (ii) 限制到相关性稳定子域。**CIP 不是调试工具，而是 BC 证书的合法性前提。**

**引理 31（场景 Goodhart 可检测）** perf_A、perf_{A⊥} 共享构念但实现不同；调参使 ∂perf_A/∂θ>0、∂perf_{A⊥}/∂θ≈0，则 E[D_scen] 随调参上升而 φ 可不变。K 个近似独立密封族提升检测功效。**没有密封族的「覆盖率」等于给「过拟合验收集」发合格证。**

**引理 32（顺序门 anytime 有效）** 用 always-valid confidence sequence / e-value（Ville）替代固定样本检验，对任意停时 τ，P(错误认证 真实不安全率>δ)≤α，无需校正「看了多少次」。**分阶段 rollout 中反复看指标不会膨胀误认证率。**

**定理 23（TETHER 风险界）** 在 A106–A110（支撑/ODD 可检、c_E 校准且条件独立于策略选择、动力学 Lipschitz、CIP 有效）下，通过 J_TETHER ⇒ 期望风险 ≤ R71 的 ε_cert + 支撑外质量 + 能力不足 + 因果混淆，后三项被门控置零；任一 veto 失败强制回退 R71 或拒绝。故期望风险 ≤ R71。**全部重量落在「支撑与 ODD 估计本身有效」上。**

**定理 24（再锚定节律稳定性）** 若 k≤T_exit/κ_safe，则状态偏差始终有界（L<1 时 ≤εL/(1−L)，L>1 时 ≤r）；re-anchor 动作过安全认证时，系统不进入「越界—纠偏—再越界」振荡。**系：BC 长时程安全 = 短时程系绳 + 周期性接地，而非要求永不犯错的策略。**

**定理 25（严格包含链）** 定义 364 退化条件下 TETHER 逐指令等于 GAUGE；GAUGE⊂BELIEF⊂FLUID⊂R68（R71 定理 20）。安全侧不弱于 R71；自动化程度只在门全通过时增加。

## 7. 本轮最大风险

**一句话**：TETHER-RAS 把信任从「策略本身」转移到「示范支撑 × 专家能力 × 声明 ODD」，而这三者都可以由希望它通过的人来划定和测量——把失败场景宣布为「域外」（ODD laundering）、把支撑量在训练分布或凸包上（虚假支撑）、把专家能力默认满分（把「像专家」当成「对」）。于是系统会用一张**自己签发、自己审计的范围证书**在长尾里运行：它不再「自信地错状态」，而是**「合规地错范围」——每一份日志都能证明它在证书允许的地方，而那张证书从未覆盖过它实际去的地方。**

**次级风险与缓解**：
1. **ODD 偷换** → R 由发布门外独立方密封；𝒪⊇R 硬约束；覆盖按 p_req；E344 专测缩域攻击；
2. **支撑过宽/凸包伪造** → 闭环可达流形而非凸包；OOD + 可达距离双通道；E342；
3. **专家能力高估** → 多示范者一致性 + 结果标签 + 接管日志 + 干预试验；E345；
4. **因果混淆** → CIP 干预证据或限制相关性稳定子域；不可识别即拒绝；E346；
5. **场景过拟合** → 同构念异实现密封/对抗族 + D_scen；E347；
6. **现场数据自噬** → 只收专家示范/人工纠正；自执行仅监测；provenance + 密封 holdout；E351；
7. **接管不及时/自满** → t_hand<t_crit 硬约束，来不及先急停；定期演练；E350；
8. **过度保守难落地** → veto 只覆盖支撑/ODD/能力/因果/安全；门内排序；E324/E357 量化代价。
