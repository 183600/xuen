# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「伦理与合规」×「技能组合」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**规范治理 + 认证技能代数**。两个灵感各治 v9 的一种债：**正当性债**（系统能证明"安全"，却不能证明"被允许"——隐私、同意、不可逆、可解释在架构里没有形式位置）、**组合债**（PrimitiveGraph 有原子技能，但拼装靠人工；个体安全 ≠ 组合安全）。关键理论动作：v9 的 P11 只覆盖"增强类"模块（失效=中立元=退回基线）；伦理/合规属"约束类"，失效绝不能 fail-open。故提出**双类退化代数**，把 P11 从单类推广为两类——这是对 v9 纪律的**有意细化**而非破坏，须以引理 88 严格论证。

## 0. 直觉与动机

**灵感 1（伦理与合规 → 规范治理器与合规证书）**
直觉：v9 能给出空间/故障/块证书，证明"这样做不会撞、不会崩"，却无法回答"这样做是否被允许"。伦理与合规要求的不是又一个可加权的软指标，而是一条**不可交易的硬边界**：隐私区、录音同意、不可逆动作、人类否决权、情感不得用于操纵。核心创新：**规范治理器（NormativeGovernor, NG）**——机器可读规则库 R，按道义模态分为禁止/义务/许可；每个候选动作或动作块领取**合规证书** Ĉ^comp ∈ {compliant(w), violating(j), unknown(J)}；禁止类 unknown 一律 fail-closed 拒绝，义务类 unknown 升级人类介入。所有裁决写入**合规账本**（哈希链），使"为什么允许"可回放、可审计、防篡改。伦理不是事后解释，而是**决策过滤器的第一等约束**。

**灵感 2（技能组合 → 认证技能代数）**
直觉：PrimitiveGraph 给了原子技能，但"导航→抓取→搬运→放置"的拼装仍靠人工，且**个体安全不蕴含组合安全**：每一步都在安全间隙内，累计漂移却可能把机器人带进隐私区或死角。核心创新：**认证技能代数（CertifiedSkillAlgebra, CSA）**——技能 s=(Pre,Post,Inv,Eff,Cert,Norm) 是带契约的态射；顺序(;)、并行(∥)、选择(⊕)、迭代(*)四个算子各自推导组合契约；组合安全性由 Hoare/rely-guarantee 风格引理保证。对**叶技能无法覆盖的全局不变式 G**（如"全程不进隐私区"），在技能边界与 AC 中止点设**涌现违背检测器**。技能入生产库须过契约验证 + 组合测试 + 合规标注完备性；未认证技能只能在受限沙箱内探索。

**灵感 1×2 的交叉（本轮真正的创新点）**
合规与安全都能**组合**：若每个技能携带 Norm_s 且组合保持接口/非干涉前提，则组合技能自动继承合规（引理 89）。这把"合规"从"对最终轨迹的事后检查"升级为"对组合结构的构造性保证"，并让 AC 的中止点获得新语义——中止点不仅要停车安全，还要**契约兼容**（不把系统停进违反下一技能 Pre/Inv 的状态）。

## 1. 研究问题（轮次升级版）

- **Q1（规范形式化边界）**：如何把开放纹理的伦理规则压缩为可判定谓词，同时给出"近似过宽→合规剧场 / 过严→频繁 fail-closed"的量化边界？unknown 的 fail-closed 在什么条件下不牺牲可用性？
- **Q2（双类退化正确性）**：约束类模块失效注入受限模式后，如何严格证明其安全性是 v9 的安全**细化**（而非等价）？如何界定"NG 失效时不保证 NG 特有规则"这一可接受缺口？
- **Q3（组合合规性）**：技能代数在什么前提（接口兼容、非干涉、边界可观测）下，使组合合规与组合安全同时成立？涌现违背能否被局部检测点完备捕获？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15，并细化 P11）

**P11′ 双类退化律（Two-Sorted Degradation, TSD）**（细化 v9 P11）
模块分两类：**增强类** E（AC/MW/ID/DA/SPR/Cal）失效注入中立元 v^⊥，严格退回基线；**约束类** C（NG、M₀、SpatialCert、FaultCert、账本、同意守卫）失效注入**失效元 f^⊥ = 受限模式**（deny/restricted），绝不注入单位元 ⊤（allow-all）。约束类合取格的单位元（⊤）与失效元（f^⊥，⊥ 侧）**分离**——这是 P11 单类代数无法表达的安全关键区分。

**P13 规范不可交易律（Normative Non-Tradeoff, NG）**
决策按字典序：合规 ≻ 安全 ≻ 任务 ≻ 效率/情感适配。禁止类 hard 规则一旦 violating 即在过滤阶段移除，不进入任何打分；unknown 对禁止类 fail-closed。任何任务收益不能换取一次禁止违反（无奖励黑客）。

**P14 合规组合律（Compliance Compositionality, CSC）**
技能携带 Norm_s；组合算子保持 Norm 并集与接口前提；组合合规由构造继承。组合边界与中止点检查全局不变式 G；中止点须契约兼容。

**P15 技能准入律（Certified Admission, CSA）**
技能入生产库需契约形式验证、组合测试、合规标注完备；未认证技能限于受限沙箱，Eff 隔离、不可与生产技能组合。

## 3. 与基线的接口（如何退化）

- **NG 失效**（规则库缺失 / 验证超时 / 证书不可得）⇒ 注入 f^⊥ = 受限模式（降速、禁不可逆、K_eff=1、人类解除）；安全性是 v9 的细化（引理 88），**不保证 NG 特有规则**（明示缺口）；
- **合规账本失效** ⇒ 决策继续但标记 "unlogged"，并进入受限模式（审计不可得视为合规不可证）；
- **CSA 失效**（组合契约验证不可得）⇒ 退回 PrimitiveGraph 的 v9 原子技能执行，禁止多技能自动组合；
- **AC/MW/ID/DA/SPR/Cal 失效** ⇒ 沿用 v9 中立元退化，等价 v9；
- 全部失效 ⇒ 退回 v9，再退回 v8/v7/v6。

## 4. 预期贡献

1. **双类退化代数**：区分增强类的"中立元退化"与约束类的"失效元 fail-closed"，为安全/伦理约束给出可证明的组合正确性；
2. **规范治理器 + 合规证书 + 哈希账本**：把隐私、同意、不可逆、人类否决、反操纵从口号变成可判定、可审计的一等约束；
3. **认证技能代数**：契约化技能与四算子，使"个体安全 ⇒ 组合安全 ⇒ 组合合规"成为可证的构造链，并引入涌现违背检测与契约兼容中止点；
4. **合规-安全-任务字典序**：给出无奖励黑客的形式保证，以及受限模式的可用性/安全权衡曲线；E571–E590 覆盖规范可靠性、组合安全、隐私同意、可争议性、对抗合规与端到端。

## 5. 本轮最大风险

**一句话**：合规验证器的可靠性以「伦理规则可判定且场景可观测」为前提，而真实伦理规则含开放纹理谓词（"尊重""不伤害""不过度操纵"）——形式化必然压缩为可判定近似，近似过宽则合规证书沦为**合规剧场**（形式通过、实质违背），过严则系统频繁 fail-closed 而丧失可用性；更危险的是，受限模式在 NG 失效时**不再保证 NG 特有规则**，恰恰在最需要规范判断的边缘场景留下已知缺口。

**新增定义 540（运动学拉回度量 KinematicPullbackMetric）** 设机械臂构型 q∈Q⊆R^n，任务映射 x=f(q)∈R^m，雅可比 J(q)=∂f/∂q，任务度量 W∈S^m_{++}（块对角：W=diag(W_pose, W_voice)）。定义关节空间度量
```
g_q = J(q)ᵀ W J(q) + λ I_n,   λ>0
```
关节位移 δq 的 gauge 长度 ‖δq‖_{g_q}=√(‖Jδq‖_W² + λ‖δq‖²)。g_q≻0，λ_min(g_q)≥λ。条件数 κ_q=λ_max(g_q)/λ_min(g_q)。奇异值 σ_i(J) 降序，σ_min=σ_n；可操作度 w(q)=√det(JJᵀ)（m≤n）。**直觉**：g_q 把"关节动了多少"翻译成"任务上差了多少"，是 MetricVoiceGauge 的物理接地。

**新增定义 541（奇异感知块证书 SingularityAwareCertificate）** 在定义 533 基础上扩展块证书：
```
Ĉ_t = (ĝ_min, ê_max, γ̂_grasp, σ̂_min, μ̂_t, d̂_eff)
σ̂_min = min_{k≤K} σ_min(J(q_k)),  μ̂_t = max_{k≤K} κ_{q_k},  d̂_eff = min_{k≤K} d_eff(q_k)
```
前向模型 F̂ 须同时预测构型轨迹 q^{1:K}。证书有效 ⇔ 定义 533 原条件 ∧ σ̂_min≥σ_sing ∧ μ̂_t≤μ_max ∧ d̂_eff≥d_safe。即"任务空间够、关节空间也用得上、且不在奇异处"三条件同尺度。

**新增定义 542（度量一致安全裕度 Metric-Consistent Margin）**
```
d_eff(q) = min( d_task(q), σ_min(J(q))·Δq_avail(q) )
Δq_avail(q) = min_j ( 剩余关节行程_j, 到自碰的关节空间距离_j )
```
**直觉**：d_task 是"任务空间有没有空间"；σ_min·Δq_avail 是"用现有关节预算最多能抵掉多大的任务误差"。二者取小才是真实可纠正裕度。当 σ_min 为 O(1) 且 Δq_avail 充裕时 d_eff=d_task，退化回 v9。

**新增定义 543（零空间安全通道 NullSpaceSafetyChannel）** n>m 时定义阻尼加权伪逆与零空间投影
```
J⁺ = (JᵀWJ+λI)⁻¹JᵀW,   N(q) = I − J⁺J
a = a_task + N(q) u_safe
```
u_safe 由关节限位排斥、自碰排斥、奇异排斥（势场或 QP）产生。**性质**：J a = J a_task（任务一阶精确不变）。中性元 u_safe=0 ⇒ a=a_task，等价 v9。

**新增定义 544（零空间可行性与升级 NullSpaceFeasibility）** 设 P_safe(q,a) 为安全谓词（限位、自碰、间隙）。若 ∃a'∈a_task+null(J) 使 P_safe(q,a') 成立、a' 在关节限位内、且二阶误差 ≤β_N，则 NSC 可行；否则升级：(i) **降维图谱重规划**（丢弃退化任务方向、以缩减 W 重跑 AC，并显式声明能力损失 Δcap），或 (ii) 在最近中止点 p*（定义 534）安全停驻。

**新增定义 545（构型条件契约 EmbodimentConditionedContract）** 构型描述子 M_e=(n_e,m_e,连杆参数,关节限位,质量,J_e(·),额定负载)。契约提升
```
κ_m^e = lift(κ_m, M_e) = (In_m^e, Out_m^e, D_m^e, Ŵ_m^e, v_m^{⊥,e}, π_m^e, φ_m^{elig,e})
```
代入 n_e/限位/预算，v_m^{⊥,e} 为该构型的安全停驻，SpatialCert 等用 J_e 实例化。可移植谓词 π_m^port(M_e)∈{⊤,⊥}；π_m^port=⊥ 时模块在 e 上声明 φ_m^{elig,e}=⊥（仅该构型不消融，不全局删除）。

**新增定义 546（构型条件蒸馏与覆盖不变式 EmbodimentConditionedDistillation）** 贡献 c_m(t;e) 为按构型 e 的滑窗消融 EMA。构型 e 上置 m 为 dormant 当且仅当：
```
c_m(t;e') < τ_off  ∀e' ∈ cluster(e)      （同簇全体低贡献）
∧ φ_m^{elig,e} = ⊤
∧ ∀c∈C_req: |{m'∈active(e): capability(m')=c} \ {m}| ≥ 1   （覆盖不变式）
```
frozen 仍需离线证据解冻。**直觉**：全局蒸馏会删掉"只在少数构型关键"的模块；覆盖不变式把"删除"限制为"在能力类上仍有人值守"。

**新增定义 547（能力包络 CompetenceEnvelope）** 通用策略 π_θ 的能力包络 C_π。在线能力分
```
s_comp(t) = min( ensemble_disagreement_confidence, d_behav(obs, task; C_π) )
```
其中 d_behav 用 g_q 度量（与 KMG 同一 gauge，避免维护两套距离）。仅当 s_comp≥τ_comp 时执行 π_θ；否则触发定义 548。

**新增定义 548（保守技能回退 ConservativeSkillFallback）** 若 s_comp<τ_comp，则在中止点 p*（定义 534）切换到已认证保守技能 σ∈S_cert（停驻/后退/重抓取），由 AC 重新认证。切换是 abort 机制的特例，故不引入新的瞬态风险源。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v8 不变。
**定义 521（DA-OTL）** 继承 v8 不变；K_eff>1 时以块证书替代逐层逐步复核。
**升级定义 533（块证书，v10）** 见定义 541：新增 σ̂_min、μ̂_t、d̂_eff 三项，其余语义不变。
**升级定义 534（中止点，v10）** 停车不变式改用度量一致裕度：p∈P_t 当且仅当
```
d_brake(v_p) + d_safe ≤ d_eff(s_p) − |traj_{p:K}|
```

```python
# IP-357 KinematicMetricGauge：运动学度量计
class KinematicMetricGauge:
    def __init__(self, W, lam=1e-3, sigma_sing=0.05, mu_max=50.0):
        self.W, self.lam = W, lam
        self.sigma_sing, self.mu_max = sigma_sing, mu_max

    def metric(self, J):
        return J.T @ self.W @ J + self.lam * np.eye(J.shape[1])   # 定义 540

    def pullback_len(self, J, dq):
        g = self.metric(J)
        return float(np.sqrt(max(0.0, dq @ g @ dq)))

    def sigma_min(self, J):
        return float(np.linalg.svd(J, compute_uv=False)[-1])

    def effective_margin(self, J, d_task, dq_avail):
        s_min = self.sigma_min(J)
        return min(d_task, s_min * dq_avail), s_min      # 定义 542

    def certify(self, J, d_task, dq_avail, d_safe):
        d_eff, s_min = self.effective_margin(J, d_task, dq_avail)
        mu = float(np.linalg.cond(self.metric(J)))
        ok = (d_eff >= d_safe) and (s_min >= self.sigma_sing) and (mu <= self.mu_max)
        # 不通过 ⇒ 降维图谱（丢弃退化方向、缩减 W）或停驻，绝不放行
        return ok, dict(d_eff=d_eff, sigma_min=s_min, mu=mu,
                        reduce_chart=(s_min < self.sigma_sing or mu > self.mu_max))


# IP-358 NullSpaceSafetyChannel：零空间安全通道
class NullSpaceSafetyChannel:
    def __init__(self, W, lam=1e-3, beta_N=1e-3):
        self.W, self.lam, self.beta_N = W, lam, beta_N

    def pinv(self, J):
        return np.linalg.solve(J.T @ self.W @ J + self.lam * np.eye(J.shape[1]),
                               J.T @ self.W)                # 定义 543

    def project(self, J, u_safe):
        N = np.eye(J.shape[1]) - self.pinv(J) @ J
        return N @ u_safe

    def compose(self, J, a_task, u_safe, q, env, dt):
        u_N = self.project(J, u_safe)
        a = a_task + u_N
        if not env.joint_ok(a) or not env.safety_ok(q, a):
            return self.escalate(J, a_task, u_safe, env)     # 行空间修正需求（定义 544）
        e2 = 0.5 * env.hess_norm(q) * float(u_N @ u_N) * dt * dt
        if e2 > self.beta_N:                                 # 二阶界破 ⇒ 升级
            return self.escalate(J, a_task, u_safe, env)
        return ('ok', a, dict(e2=e2, u_N=u_N))

    def escalate(self, J, a_task, u_safe, env):
        # (i) 降维图谱重规划（声明 Δcap）；(ii) 中止点 p* 停驻
        return ('escalate', env.reduced_chart_replan(J, a_task, u_safe))


# IP-359 EmbodimentContractCompiler：构型条件契约 + 能力包络回退
class EmbodimentContractCompiler:
    def __init__(self, base_contracts, cluster_of, capability_of, required_caps):
        self.base, self.cluster_of = base_contracts, cluster_of
        self.capability_of, self.required_caps = capability_of, required_caps

    def lift(self, M_e):
        table = {}
        for name, c in self.base.items():
            if not c.portable_to(M_e):                       # π_m^port=⊥
                c = c.declare_ineligible(M_e)                # 仅该构型 φ^elig=⊥
            table[name] = c.instantiate(M_e)                 # 定义 545
        return table

    def coverage_ok(self, active, e, drop=None):
        caps = {self.capability_of[m] for m in active[e] if m != drop}
        return caps >= self.required_caps                    # 定义 546

    def distill(self, contrib, active, M_e):
        e = M_e.id
        for m, c in contrib[e].items():
            if not self.base[m].distill_eligible:
                continue
            if c >= TAU_OFF:
                continue
            same_cluster_low = all(contrib[e2][m] < TAU_OFF
                                   for e2 in self.cluster_of(e))
            if same_cluster_low and self.coverage_ok(active, e, drop=m):
                active[e].discard(m)                         # 构型条件休眠

    def competence_gate(self, policy, obs, task, skill_lib, chunker):
        s_comp = min(policy.ensemble_confidence(obs, task),
                     behavior_metric_distance(obs, task))     # 定义 547，用 g_q
        if s_comp >= TAU_COMP:
            return ('generalist', policy.act(obs, task), None)
        p_star = chunker.nearest_abort_point()                # 复用定义 534
        return ('conservative', skill_lib.certified(task), p_star)   # 定义 548
```

## 4. 推导

**引理 87（拉回度量正则性与奇异能力坍缩）** 对任意 q 与 λ>0，g_q=JᵀWJ+λI 正定，且
```
κ_q = κ(g_q) ≤ 1 + σ_max²(J)·‖W‖₂ / λ
```
即度量被 λ 正则、不发散。然而**可纠正能力**并非由 κ_q 表征，而由伪逆谱决定：沿第 i 奇异方向，单位任务误差所需关节运动为 1/σ_i(J)，用关节预算 Δq_avail 可纠正的任务误差半径仅为 σ_i(J)·Δq_avail。故当 σ_min(J)→0 时，能力椭球 {δ : ‖J⁺δ‖≤Δq_avail} 沿最小奇异方向的半轴 σ_min·Δq_avail→0：**度量没坏，能力没了**。证明：g_q 的谱为 {σ_i²λ_i(W)+λ}，κ_q≤(σ_max²λ_max(W)+λ)/λ；能力椭球是 J(B_{Δq_avail}) 的像，其半轴为 σ_iΔq_avail，最小半轴随 σ_min→0 而趋于 0。∎

**引理 88（度量一致裕度充分必要）** d_eff(q)≥d_safe 当且仅当任意满足 ‖δx‖≤d_safe 的任务扰动都可在关节预算 Δq_avail 内被抵消。证明：最坏情况需 ‖J⁺δx‖≤‖J⁺‖·‖δx‖=(1/σ_min)‖δx‖≤Δq_avail，即 d_safe≤σ_minΔq_avail；反之若 σ_minΔq_avail<d_safe，取 δx 沿最小奇异方向、模 d_safe，则 ‖J⁺δx‖=d_safe/σ_min>Δq_avail，不可抵消。故 d_eff 取 d_task 与 σ_minΔq_avail 之小是充要的。∎

**引理 89（零空间一阶不变与二阶界）** 对 a=a_task+N u_safe，有 J a=J a_task（一阶精确不变）。离散步 Δt 内端到端偏差为
```
e_2 = ½ (N u_safe)ᵀ H_J (N u_safe) Δt² + O(Δt³)
```
其中 H_J 为任务映射的 Hessian。故只要 ½‖H_J‖‖N u_safe‖²Δt²≤β_N，NSC 叠加不破坏 AC 任务证书（证书的 β 预算中扣除 β_N）。证明：对 x(q+(a_task+Nu)Δt) 在 q+a_taskΔt 处 Taylor 展开，一阶项 J(Nu)=0 因 N 是 J 的零空间投影而消去，余下二阶项即 e_2。∎

**引理 90（零空间可行性与升级）** 若所需安全修正 u_req 含行空间分量（即其零空间投影 N u_req 不满足安全谓词 P_safe），则在保持任务动作不变的动作集 a_task+null(J) 中不存在满足 P_safe 的动作；此时必须升级为降维图谱重规划或安全停驻。证明：a_task+null(J) 中每个动作的像 J a 都等于 J a_task，其行空间分量固定；若 P_safe 需要改变该行空间分量（例如必须把末端推离障碍），则任何保持任务不变的动作都无法满足，只能放弃部分任务（降维图谱）或停驻。∎

**引理 91（构型条件蒸馏安全，含中立元等价推广）** 在 ECC 下，模块 m 在构型 e 上可休眠仅当同簇全体贡献 <τ_off、φ_m^{elig,e}=⊤、且覆盖不变式成立。于是对每个 e，active(e) 对每个能力类仍至少含一个已认证模块；休眠注入 v_m^{⊥,e} 与 v9 对应退化级逐位等价（v9 引理 83 按构型实例化）。故任意蒸馏状态下的行为 ∈ v9 退化格点，跨构型安全性由 v9 引理 80–81 与 v9 引理 84 逐构型传递。证明：由定义 546 的构造与覆盖不变式，删除不减少任何能力类的值守；中立元等价按 v9 引理 83 的端口映射逐项代入 M_e。∎

**引理 92（能力包络回退安全）** 若 s_comp<τ_comp 并在中止点 p* 切换到保守技能 σ∈S_cert，则切换保持 v9 安全不变式。证明：p* 满足升级版定义 534 的停车不变式（d_brake+d_safe≤d_eff−剩余轨迹），故从 p* 出发可安全停驻；σ 已在 S_cert 中离线认证并由 AC 在线复核；切换时刻系统处于可停驻状态，等价于一次 abort，故不引入新的安全违背路径。∎

**推论（五级退化仍成立）** 令 KMG→λI、NSC→0、ECC→全局契约，则定义 540–548 分别退化为 v9 定义 533–539，v10 主闭环逐位退化为 v9 主闭环；再令 v9 模块失效即得 v9→v8→v7→v6 的完整链。∎
