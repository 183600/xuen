# 第 56 轮（承接第 55 轮想法区「语义-接触接地」与第 54 轮产物 v31；灵感循环第 2 轮；本轮灵感：「UniBot」×「推理延迟」）

> 第 55 轮把“感知标签”升级为“可执行的语义-接触约束”，并用生存核 `K(Σ)` + 护盾 + 证书 `J_s` 把“接触是否可信”写进部署判据。但整条证书链悄悄假设了一件事：**观测、推理、证书与执行发生在同一个时刻**。本轮引入「UniBot」与「推理延迟」，正是来拆这个假设：UniBot 式统一具身策略把分割、可供性、全身核、护盾 QP 串成一条端到端推理链，任何一环慢一点，动作就是用 `x_{t-Δ}` 算出来、在 `x_t` 上执行的；而“兜底的安全制动/避难所”本身也要花时间，它可能恰好在最需要时来不及。核心矛盾：**H24（证书的“同时刻”幻觉）**：语义图、生存核与护盾都是对某一时刻状态的有效断言，却没有携带有效期；延迟让“签发时成立”不等于“执行时成立”，无 TTL 的证书在时延下是 unsound 的；**H25（最脆弱的一环也有延迟）**：三层防御的最后一层是制动/避难所，但它依赖同一套陈旧状态与同一份时延预算，重尾延迟（p99 ≫ p50）下护盾可能在截止后才返回，使“最后一道防线”在尾部失效——时延不是性能指标，而是安全语义的一部分。

## 0. 直觉与动机

**灵感 1（UniBot → 统一推理是一条端到端时延链，而非若干模块的加速问题）**
直觉：UniBot 的价值在于“一个模型贯穿感知-推理-控制、一套策略跨构型”，代价是这些阶段共享同一条关键路径。把每个模块单独做快 10% 并不能保证端到端赶上控制周期，因为关键路径、排队与云端往返才是决定项。正确对象不是“某个网络的 FLOPs”，而是 **推理时延账本**：沿关键路径逐段标定时延分布，给端到端设概率预算与硬上界。于是“能不能部署”第一次同时包含“算得对”和“来得及”。

**灵感 2（推理延迟 → 证书必须有 TTL，而不是给正确性打补丁）**
直觉：一张证书 `J` 说的不是“永远安全”，而是“从 `x_0` 出发的一段安全窗口”。状态在无干预下会以由动力学决定的速度离开认证集 `S_J`，所以每张证书天然有一个 **时效** `τ(J)`（离开认证集的逃逸时间）。执行前必须核对 `t_apply - t_issue ≤ τ(J)`；过期的“正确证书”与错误证书同样危险。这把时延从工程噪声升格为证书的一个维度。

**灵感 3（推理延迟 → 生存核要在时延区间 Δ 上鲁棒，而不是在单点上可行）**
直觉：第 55 轮的 `K(Σ)` 回答“此刻能不能撑住”，但动作要到 `t+Δ` 才真正落地。若只要求 `x_t∈K`，则 `Δ` 秒后状态可能已经滑出 `K`。应把核升级为 **时延鲁棒生存核** `K_Δ`：从 `x_t` 出发存在策略让整个 `[0,Δ]` 都留在 `K` 内。`K_Δ ⊆ K` 且随 `Δ` 单调收缩——延迟越长，可行动集越小，这才是“慢”对安全的正确定价。

**灵感 4（任意时间算法 → 证书应可降级，而不是在截止时刻崩溃）**
直觉：与其“算不完就丢弃”，不如让生存核具备 **任意时间** 性质：`K_in^(1) ⊆ K_in^(2) ⊆ … ⊆ K`，算得越久内近似越紧，且任意时刻都 sound。截止时用当前最大的 `K_in^(k*)` 决策，并附带保守间隙 `g(k*)`；预算不足时是“更保守地动”，而不是“来不及就不动或乱动”。护盾同理：QP 必须在截止前给出结果，否则由看门狗切换到 **预计算避难所**，而不是让求解器继续跑。

**灵感 5（UniBot 跨构型 → 时延画像随本体迁移，避难所必须预计算且按时触发）**
直觉：同一套 UniBot 策略在不同本体、不同芯片上的控制周期与时延画像完全不同，因此在 A 本体上有效的 TTL 与预算不能直接搬到 B。部署前要把 **时延画像** 作为可迁移、可复验的对象；同时为每个构型预计算一条 **时延避难所** 轨迹（在硬上界 `T_max` 内可达的安全停靠段），由看门狗按时间触发。这样兜底不依赖在线最坏情形求解，而依赖离线已证过的动作序列。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（推理时延账本）**
设推理链模块集 `M`，模块 `m` 的时延为随机变量 `T_m`，经校准得到分布函数 `F_m`（含 p50/p99 与物理硬上界 `T_m^max`）。关键路径 `P ⊆ M`（第 55 轮链：分割 → `κ` 评估 → 核查询 → 护盾 QP → 云边通信）。端到端时延
`T_e2e = Σ_{m∈P} T_m`，控制周期 `T_c`，安全裕度 `T_sm`，预算 `B = T_c - T_sm`。
**时延可部署条件**：`P(T_e2e ≤ B) ≥ 1 - δ_lat` 且硬路径 `T_e2e^max = Σ_{m∈P} T_m^max ≤ B`。
时延画像 `L_M = {(m, F_m, p50, p99, T_m^max)}_{m∈M}` 作为证书的可迁移分量。

**定义 128（证书时效 TTL）**
证书 `J` 关联认证安全集 `S_J ⊆ 𝒳`（由 `K_margin` 与 `C^+(Σ)` 诱导）。给定扰动集 `W` 与不重认证的执行，证书时效
`τ(J) = sup{ Δ ≥ 0 | ∀ w(·)∈W, ∀t∈[0,Δ]: x(t)∈S_J }`，
即认证集的逃逸时间。执行时刻 `t_apply` 的**有效性判据**：
`t_apply - t_issue ≤ τ(J) - T_remaining`，其中 `T_remaining` 为动作落地前的剩余推理时间。
语义图另设语义时效 `τ_Σ`：若 `age(Σ) = t_apply - t_seg > τ_Σ`，接触集必须按陈旧度膨胀或拒绝使用。

**定义 129（时延鲁棒生存核）**
对时延区间 `Δ ≥ 0`，
`K_Δ(Σ) = { x | ∃ π: ∀t∈[0,Δ], x(t)∈K(Σ), supp Λ(t) ⊆ C^+(Σ), x(Δ)∈K(Σ) }`，
即 `K(Σ)` 的 `Δ` 步受控不变子集（后向可达管）。性质：`K_0 = K`，`K_Δ` 对 `Δ` 单调不增，`K_Δ ⊆ K`。
护盾的约束从 `x_{t+1}∈K` 升级为 `x_{t+Δ_exec}∈K_{Δ_rem}`（`Δ_rem` 为落地后仍需保证的时域）。

**定义 130（任意时间生存核）**
存在迭代序列给出内/外近似
`K_in^(1) ⊆ K_in^(2) ⊆ … ⊆ K(Σ) ⊆ … ⊆ K_out^(2) ⊆ K_out^(1)`，
且保守间隙 `g(k) = μ(K_out^(k) \ K_in^(k))` 单调下降。截止调度器在预算 `B` 内选最大完成迭代
`k*(B) = max{ k | cost(k) ≤ B }`，以 `K_in^(k*)` 决策。**任意时间 soundness**：对任意 `k`，`K_in^(k) ⊆ K(Σ)`；若 `g(k*) ≤ Θ_g` 才允许放行，否则降级。

**定义 131（时延鲁棒性谱）**
在第 55 轮谱 `ρ` 上增加时延维：
`ρ_lat(Δ) = inf_{T_e2e∈𝒯_Δ} inf_{w∈W} P( ∀t∈[0,Δ]: x(t)∈K(Σ_t^{age}), supp Λ(t)⊆C^+(Σ_t^{age}) )`，
其中 `𝒯_Δ` 为画像支持且不超过 `Δ` 的时延实现集，`Σ_t^{age}` 表按时延陈旧的语义图。全谱 `ρ_full = ρ ⊕ ρ_sem ⊕ ρ_lat`。

**定义 132（时延-安全联合证书）**
`J_t = (J_s, L_M, T_e2e^{p99}, T_e2e^{max}, τ(J_s), τ_Σ, K_Δ_margin, ρ_lat, s_dl, refuge, evidence)`，
其中 `s_dl = B - T_e2e^{p99}` 为截止松弛，`refuge` 为预计算避难所证书。
**时延-安全可部署** 当且仅当：
1. `J_s` 可部署（第 55 轮判据）；
2. `T_e2e^{max} ≤ B` 且 `P(T_e2e ≤ B) ≥ 1 - δ_lat`；
3. `τ(J_s) ≥ T_e2e^{p99} + T_sm` 且 `age(Σ) ≤ τ_Σ`；
4. `K_Δ_margin ≥ θ_Δ`，任意时间间隙 `g(k*) ≤ Θ_g`；
5. `refuge` 在 `T_e2e^{max}` 内可达且其自身 `τ(refuge) ≥ T_e2e^{max}`。
任一条不满足只允许拒证/降级/制动，不允许“用 p50 很快”替代“尾部来得及”。

## 2. 关键算法 伪代码

### IP-127 LAL（Latency Accounting Ledger）

```python
def latency_ledger(modules, traces, delta_lat):
    prof = {}
    for m in modules:
        s = traces.latency(m)
        F = conformal_cdf(s, alpha=delta_lat)      # distribution-free tail coverage
        prof[m] = LatencyProfile(F, p50=quantile(s,.5),
                                 p99=quantile(s,.99),
                                 t_max=evt_endpoint(s, physical_bound(m)))
    path = critical_path(modules)                  # seg -> kappa -> kernel -> shield -> comm
    return prof, path, lambda B: (P_e2e(prof, path) >= 1 - delta_lat
                                  and hard_sum(prof, path) <= B)
```

### IP-128 TVK（Temporal Viability Kernel）

```python
def temporal_viability_kernel(Sigma, C_plus, Delta, W, f):
    K = whole_body_viability_kernel(Sigma, C_plus)     # round 55, K_0
    K_Delta = K
    for t in range(Delta):                             # backward reachable tube
        K_Delta = controlled_preimage(K_Delta, f=f, contacts=C_plus, disturb=W)
    margin = min_dist_to_boundary(K_Delta) if K_Delta else 0.0
    return KernelTube(K_Delta, margin)

def stale_contacts(Sigma, age, tau_Sigma, v_max, kappa, theta_m):
    if age > tau_Sigma:
        return None, 'semantic_expired'
    return conservative_contacts(C, M - v_max*age, kappa, theta_m), 'ok'
```

### IP-129 ALB（Anytime Latency-Budgeted kernel）

```python
def anytime_kernel(Sigma, C_plus, deadline):
    K_in, K_out, k = empty_set(), whole_set(), 0
    while now() < deadline:
        k += 1
        K_in  = refine_inner(K_in, k)              # monotone increasing, sound
        K_out = refine_outer(K_out, k)             # monotone decreasing
        if gap(K_in, K_out) <= theta_g:
            break
    return AnytimeResult(K_in, K_out, gap(K_in, K_out), k, deadline_met=now() < deadline)
```

### IP-130 DAS（Deadline-Aware Shield）

```python
def deadline_aware_shield(u_nom, x, K_Delta, C_plus, deadline, refuge):
    t0 = now()
    u = qp_solve(H=W, g=-W @ u_nom,
                 constraints=[viability(x, u, K_Delta),
                              contact(u, C_plus),
                              friction_cone(u, mu),
                              joint_limit(u)],
                 time_limit=deadline - t0)          # interruptible solver
    if u is not None and now() - t0 <= deadline:
        return u, 'ok'
    seg = refuge.best_segment_from(x, remaining=deadline - t0)
    if seg is not None and seg.valid_for >= now() - t0:
        return seg.control(x), 'refuge'
    return hard_brake(x), 'hard_brake'
```

### IP-131 TRS（Temporal Robustness Spectrum）

```python
def temporal_robustness_spectrum(Sigma_hat, prof, Delta, sampler):
    worst = 1.0
    for T in prof.support_up_to(Delta):            # every latency realization
        Sigma_age = age_semantics(Sigma_hat, T)
        for w in sampler.worst_case_disturbance(T, Delta):
            p = empirical_safety(Sigma_age, T, w, sampler.states)
            worst = min(worst, p)
    return worst
```

### IP-132 TSC（Temporal-Safety Certificate）

```python
def temporal_safety_certificate(J_s, prof, K_Delta, refuge, budgets):
    t99, tmax = tail(prof, .99), hard_sum(prof)
    if tmax > budgets.B:
        return ('reject', 'hard_deadline_violation', tmax)
    if P_e2e(prof) < 1 - budgets.delta_lat:
        return ('reject', 'latency_probability')
    if J_s.ttl < t99 + budgets.T_sm or J_s.age_Sigma > budgets.tau_Sigma:
        return ('reject', 'certificate_expired', J_s.ttl, t99)
    if K_Delta.margin < budgets.theta_Delta or anytime_gap > budgets.Theta_g:
        return ('reject', 'temporal_kernel_too_thin')
    if not refuge.reachable_in(tmax) or refuge.ttl < tmax:
        return ('reject', 'no_valid_latency_refuge')
    return ('ok', TemporalCert(J_s, prof, t99, tmax, K_Delta, refuge, rho_lat))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| LAL | O(|M|·N_trace) 离线 | O(|M|) | 尾部校准覆盖、硬上界可信 |
| TVK | O(Δ·|X|·QP) | O(|X|) | 后向管 sound、扰动集完备 |
| ALB | O(k*·refine) | O(|X|) | 内近似单调且 ⊆ K、间隙估计 |
| DAS | O(QP) 截止截断 | O(|A_WB|) | 截断即避难所、看门狗按时触发 |
| TRS | O(|𝒯_Δ|·N_w·|X|) | O(|X|) | 时延实现覆盖、最坏可复现 |
| TSC | O(|M|+|𝒯_Δ|) | O(|M|) | 硬上界而非 p99、TTL 闭合 |

**正确性定理（Latency-Aware Temporal Soundness）**
假设第 54 轮 (A26)–(A28) 与第 55 轮 (A29)–(A32) 成立；本轮追加
**(A33)** 各模块时延尾部经 conformal/EVT 校准，`P(T_e2e ≤ B) ≥ 1-δ_lat` 且 `T_e2e^max ≤ B`；
**(A34)** `K_in^(k*) ⊆ K(Σ) ⊆ K_out^(k*)` 且 `K_Δ` 为真实 `Δ` 步不变子集的 sound 内近似；
**(A35)** `τ(J_s)` 为由 `W` 诱导的真实逃逸时间下界，`age(Σ) ≤ τ_Σ`；
**(A36)** 避难所 `refuge` 在 `T_e2e^max` 内可达且自身有效，看门狗切换不晚于截止；
**(A37)** 任意时间调度器在预算内至少完成 `k*` 且 `g(k*) ≤ Θ_g`。
则执行时刻单步安全概率：
```
P_safe(t_apply) ≥ 1 − P(T_e2e > B) − P(τ(J_s) < Δ_exec) − P(age(Σ) > τ_Σ)
                    − P(K_out\K_in ≠ ∅) − P(g(k*) > Θ_g) − P(refuge invalid)
```
关键：**时延进证书、证书带 TTL、核在 Δ 上鲁棒、护盾受截止约束、兜底离线预计算**；五者任一失守都只允许保守降级，绝不把“p99 内很快”当作“最坏情形也来得及”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 时延重尾导致硬上界被低估 | 高 | EVT + 物理界 + 在线尾部监控与降级 |
| TTL 按平均速度估计而低估逃逸 | 高 | 用最坏扰动上界推逃逸时间，TTL 打折 |
| 任意时间核饥饿、间隙过大 | 中 | 预算优先分配 + 热启动 + 间隙超限即降级 |
| 护盾 QP 截断后避难所仍从陈旧态算 | 高 | 避难所离线预计算 + 时间触发 + 可达性证书 |
| 跨构型画像迁移失效 | 高 | 每构型复验、画像版本化、留出集校准 |

## 6. 本轮最大风险

**一句话**：时延-安全证书把“算得对”与“来得及”绑成一条链，但它引入一个自指的 **时间悖论**——越想给出更紧的保证就需要更多计算，计算越久时延越大、可用时域越短，证书可能在签发时成立、在执行时已过期；一旦重尾延迟越过硬截止、或预计算避难所本身是按陈旧状态选的，护盾会在最需要兜底的尾部把控制权交给一条已不可达的停靠轨迹，造成“越保守越来不及”的跌倒——因此必须以 **硬上界（非 p99）+ 证书 TTL + 离线时间触发避难所 + 任意时间降级** 四重护栏，宁可提前冻结，也绝不把“平均很快”当作“尾部安全”。

```python
# IP-121 SCG
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)
    C = {(p, c) for p in grid(rgbd) for c in CONTACT_TYPES
         if confidence(Sigma[p]) >= theta_conf
         and kappa[argmax(Sigma[p])][c] >= theta_k}
    M = boundary_margin(Sigma)                      # m_s(p)
    return Sigma, C, M

# IP-122 WBV
def viability_kernel(Sigma, C_plus, x0, horizon, eps):
    K, margins = set(), []
    for x in sample_state_space(x0, horizon):
        feas, u, lam = solve_contact_dynamics(x, C_plus, friction_cone=mu)
        if feas:
            K.add(x); margins.append(distance_to_infeasible(x, C_plus))
    return KernelApprox(inner_hull(K), outer_hull(K, eps),
                        min(margins) if margins else 0.0)

# IP-123 SSF
def semantic_shield(u_nom, x, Kernel, C_plus, W):
    u = qp_solve(H=W, g=-W @ u_nom,
                 constraints=[viability_constraint(x, u, Kernel.K_in),
                              contact_constraint(u, C_plus),
                              friction_cone_constraint(u, mu),
                              joint_limit_constraint(u)])
    if u is None or projection_gap(u, u_nom) > Delta_u:
        return safe_brake(x), 'shield_infeasible'
    return u, 'ok'

# IP-124 SCC
def semantic_contact_certificate(traj, Sigma, kappa, rho_sem, budgets):
    Sigma_core = core_semantics(traj, Sigma)
    C_core = contacts_used(traj) & conservative_contacts(Sigma_core, M, kappa, theta_m)
    if not C_core:
        return ('reject', 'no_core_contact')
    K_margin = min(distance_to_boundary_K(x, Sigma) for x in traj)
    delta_s = semantic_perturbation(Sigma_core, calibrated_eps)
    if K_margin < budgets.theta_K or delta_s > budgets.Theta_s:
        return ('reject', 'semantic_budget_exceeded', K_margin, delta_s)
    if rho_sem(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_robustness_fail')
    return ('ok', SemanticCert(Sigma_core, C_core, K_margin, rho_sem, delta_s))

# IP-125 SRS
def semantic_robustness_spectrum(Sigma_hat, eps_s, sampler):
    worst = 1.0
    for Sigma_adv in sampler.ball(Sigma_hat, eps_s, worst_case=True):
        p = empirical_viability(renormalize(Sigma_adv), sampler.states)
        worst = min(worst, p)
    return worst

# IP-126 CEB
def cloud_edge_semantics(P_c, Sigma_c, kappa_c, edge):
    Sigma_e, C_e = edge.local_semantics()
    mismatch = boundary_disagreement(Sigma_c, Sigma_e)
    if mismatch.area > delta_A:
        return ('reprofile', region=mismatch.hotspots,
                evidence=edge.explain_contact_failure())
    C_shared = conservative_contacts(C_e, edge.margin, kappa_c, theta_m)
    return ('ok', C_shared, merge_uncertainty(Sigma_c, Sigma_e))
```

```python
# IP-127 LAL：时延账本
def latency_ledger(modules, traces, delta_lat):
    prof = {}
    for m in modules:
        s = traces.latency(m)
        F = conformal_cdf(s, alpha=delta_lat)       # distribution-free tail coverage
        prof[m] = LatencyProfile(F, p50=quantile(s, .5), p99=quantile(s, .99),
                                 t_max=evt_endpoint(s, physical_bound(m)))
    path = critical_path(modules)                   # seg -> kappa -> kernel -> shield -> comm
    return LatencyLedger(prof, path,
                         p_ok=lambda B: P_e2e(prof, path) >= 1 - delta_lat,
                         hard_ok=lambda B: hard_sum(prof, path) <= B)

# IP-128 TVK：时延鲁棒生存核
def temporal_viability_kernel(Sigma, C_plus, Delta, W, f):
    K = whole_body_viability_kernel(Sigma, C_plus)  # K_0，第 55 轮
    K_Delta = K
    for _ in range(Delta):                          # 后向可达管
        K_Delta = controlled_preimage(K_Delta, f=f, contacts=C_plus, disturb=W)
    return KernelTube(K_Delta, min_dist_to_boundary(K_Delta) if K_Delta else 0.0)

def stale_contacts(Sigma, age, tau_Sigma, v_max, kappa, theta_m):
    if age > tau_Sigma:
        return None, 'semantic_expired'
    return conservative_contacts(C, M - v_max * age, kappa, theta_m), 'ok'

# IP-129 ALB：任意时间预算核
def anytime_kernel(Sigma, C_plus, deadline):
    K_in, K_out, k = empty_set(), whole_set(), 0
    while now() < deadline:
        k += 1
        K_in  = refine_inner(K_in, k)               # 单调增、始终 ⊆ K
        K_out = refine_outer(K_out, k)              # 单调减
        if gap(K_in, K_out) <= theta_g:
            break
    return AnytimeResult(K_in, K_out, gap(K_in, K_out), k,
                         deadline_met=now() < deadline)

# IP-130 DAS：截止感知护盾
def deadline_aware_shield(u_nom, x, K_Delta, C_plus, deadline, refuge):
    t0 = now()
    u = qp_solve(H=W, g=-W @ u_nom,
                 constraints=[viability(x, u, K_Delta),
                              contact(u, C_plus),
                              friction_cone(u, mu),
                              joint_limit(u)],
                 time_limit=deadline - t0)          # 可中断求解
    if u is not None and now() - t0 <= deadline:
        return u, 'ok'
    seg = refuge.best_segment_from(x, remaining=deadline - t0)
    if seg is not None and seg.valid_for >= now() - t0:
        return seg.control(x), 'refuge'
    return hard_brake(x), 'hard_brake'

# IP-131 TRS：时延鲁棒谱
def temporal_robustness_spectrum(Sigma_hat, prof, Delta, sampler):
    worst = 1.0
    for T in prof.support_up_to(Delta):             # 覆盖所有时延实现
        Sigma_age = age_semantics(Sigma_hat, T)
        for w in sampler.worst_case_disturbance(T, Delta):
            worst = min(worst, empirical_safety(Sigma_age, T, w, sampler.states))
    return worst

# IP-132 TSC：时延-安全联合证书
def temporal_safety_certificate(J_s, prof, K_Delta, refuge, budgets):
    t99, tmax = tail(prof, .99), hard_sum(prof)
    if tmax > budgets.B:
        return ('reject', 'hard_deadline_violation', tmax)
    if P_e2e(prof) < 1 - budgets.delta_lat:
        return ('reject', 'latency_probability')
    if J_s.ttl < t99 + budgets.T_sm or J_s.age_Sigma > budgets.tau_Sigma:
        return ('reject', 'certificate_expired', J_s.ttl, t99)
    if K_Delta.margin < budgets.theta_Delta or anytime_gap > budgets.Theta_g:
        return ('reject', 'temporal_kernel_too_thin')
    if not refuge.reachable_in(tmax) or refuge.ttl < tmax:
        return ('reject', 'no_valid_latency_refuge')
    return ('ok', TemporalCert(J_s, prof, t99, tmax, K_Delta, refuge, rho_lat))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCG | O(|Ω|·(|L|+|C|)) | O(|Ω|·|L|) | 置信校准、可供性标定 |
| WBV | O(|X|·T·QP) | O(|X|) | 核外近似 sound、接触集完备 |
| SSF | O(QP)/步 | O(|A_WB|) | QP 可行或安全回退 |
| SCC | O(|轨迹|·|Ω|) | O(|Ω|) | δ_s 预算闭合、核心接触非空 |
| SRS | O(N_adv·|X|) | O(|X|) | 扰动球覆盖、最坏可复现 |
| CEB | O(|∂Ω|·|C|) | O(|∂Ω|) | 边界不一致检测、重分割收敛 |
| LAL | O(|M|·N_trace) 离线 | O(|M|) | 尾部校准覆盖、硬上界可信 |
| TVK | O(Δ·|X|·QP) | O(|X|) | 后向管 sound、扰动集完备 |
| ALB | O(k*·refine) | O(|X|) | 内近似单调且 ⊆ K、间隙可估 |
| DAS | O(QP) 截止截断 | O(|A_WB|) | 截断即避难所、看门狗按时 |
| TRS | O(|𝒯_Δ|·N_w·|X|) | O(|X|) | 时延实现覆盖、最坏可复现 |
| TSC | O(|M|+|𝒯_Δ|) | O(|M|) | 硬上界而非 p99、TTL 闭合 |

**正确性定理（GroundEdge v32 全链证据 Soundness）**
假设 v31 的 (A26)–(A28) 与 SCT 的 (A29)–(A32) 成立；TEMPO 追加
**(A33)** 各模块时延尾部经 conformal/EVT 校准，`P(T_e2e ≤ B) ≥ 1-δ_lat` 且 `T_e2e^max ≤ B`；
**(A34)** `K_in^(k*) ⊆ K(Σ) ⊆ K_out^(k*)` 且 `K_Δ` 是真实 `Δ` 步不变子集的 sound 内近似；
**(A35)** `τ(J_s)` 为由 `W` 诱导的真实逃逸时间下界，`age(Σ) ≤ τ_Σ`；
**(A36)** `refuge` 在 `T_e2e^max` 内可达、自身 `τ(refuge) ≥ T_e2e^max`，看门狗切换不晚于截止；
**(A37)** 任意时间调度器在预算内至少完成 `k*` 且 `g(k*) ≤ Θ_g`。
则端到端部署成功概率：
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − P(δ_a > Θ_a)                        # v31 动作-协同
            − P(‖Σ−Σ̂‖∞ > ε_s) − P(κ miscalibrated) − P(K_out\K_in ≠ ∅)        # SCT 语义-接触
            − P(T_e2e > B) − P(τ(J_s) < Δ_exec) − P(age(Σ) > τ_Σ)             # TEMPO 时延-TTL
            − P(g(k*) > Θ_g) − P(refuge invalid)                              # TEMPO 降级-兜底
```
关键：**动作对齐（v31）→ 接触可信（SCT）→ 证据在执行时刻仍有效（TEMPO）**；任一环失守都只允许拒证/降级/制动，不允许用“p99 内很快”或“仿真里成功”替代“硬截止内且证书未过期”。

## 5. 本轮最大风险

**一句话**：SCT 把“语义标签”变成接触约束，TEMPO 又给这份约束加上“必须按时成立”的时间条件，整条链因此暴露一个自指的时间悖论——**保证越紧需要算得越多，算得越久时延越大、可用时域越短，证书可能在签发时成立、在执行时已过期**；一旦重尾延迟越过硬截止，或预计算避难所本身是按陈旧状态选出的，护盾会在最需要兜底的尾部把控制权交给一条已不可达的停靠轨迹，使“越保守越来不及”。故必须以 **硬上界（非 p99）+ 证书 TTL + 离线时间触发避难所 + 任意时间降级** 四重护栏，宁可提前冻结，也绝不把“平均很快”当作“尾部安全”。
