# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「主动交互」×「安全对齐」）

> 第 54 轮已把技能组合提升为动作空间剖面 + 云边动作-鲁棒性双证书（ACS/SCOM/CEC/AEC/JTC），但整套证书仍默认“任务已给定、执行即正义”。本轮把系统推进到 **机器人自己决定是否、何时、以何种方式发起交互**，核心矛盾：H22：主动交互扩大了有效动作空间，却引入 **单向风险不对称**——误主动（打扰、越权、抢跑）的代价远高于漏主动，任何只做期望效用最大化的主动策略都会系统性过度主动；H23：安全对齐不是一个静态约束集，而是随交互历史漂移的意图后验，主动查询既降低意图熵、又反过来塑造人类偏好，形成 **诱导性对齐漂移**；H24：主动决策权若全放云端会不可接受地慢且易越权，若全放边端则缺乏长时程意图，必须做 **主动权限的云边分层**。

## 0. 直觉与动机

**灵感 1（主动交互 → 把“是否行动”升为一等动作）**
直觉：过去所有证书都在证明“照着做能做成”，却没证明“该不该开口、该不该先动手”。把主动层显式建模为主动动作 `u ∈ I = {yield, query, propose, act, stop}`，并计算 **主动裕度 `m_u(s)`**：只有主动带来的对齐后悔下降超过打扰成本与误主动风险时，才允许发起。主动不是默认能力，而是需要被“挣得”的许可；`yield`（什么都不说）永远是一个合法且默认的选项。

**灵感 2（安全对齐 → 可信意图集上的有界后悔，而非物理避撞）**
直觉：不撞人只是对齐的下界。真正的问题是“机器人做的，是不是这个人此刻想要的”。把人类意图 `θ` 视为隐变量，机器人维护后验 `b(θ|s)`；只在 **可信意图集 `Θ_δ`** 上评估 **最坏后悔 `AG_δ(s,b)`**——即机器人动作相对“该意图下人类认可的最优动作”的最大差距。这样对齐是单边、可证伪的量，而不是一句价值观口号。用可信集而非全空间，避免过度保守。

**灵感 3（主动查询 → 以“后悔收缩”为目标的实验设计）**
直觉：提问不是礼貌，而是一次 **降低最坏后悔的实验**。查询价值 `VoI(q)` 直接用“查询前后 `AG_δ` 的期望下降”减去打扰成本与诱导风险来定义，而不是用泛泛的熵减。机器人应问“每单位打扰最能压低对齐后悔”的问题；若问不出正价值，就闭嘴（yield）。这把被动的偏好收集变成在线、按预算、有证书的主动推断。

**灵感 4（安全对齐的暗面 → 诱导漂移与可撤销性）**
直觉：主动会反过来塑造人。反复提议制造默认选项，追问框定答案，抢先行动压缩否决窗口。因此必须区分 **自然漂移** 与 **诱导漂移**：用“无交互反事实后验 `b_t^∅`”作基线，`Δ_ind = W_1(b_t,b_t^∅)` 刻画机器人自身造成的偏好位移。再叠加 **可撤销半径 `κ_rev`**：撤销一次主动动作的最大代价。诱导漂移超预算或动作不可撤销，就必须停下来重新征得授权。

**灵感 5（云边主动权限分层 → 快慢双系统的“谁替谁做主”格）**
直觉：短时程、可逆、低风险的主动（让行、递工具、请求确认）由边端快系统毫秒级决定；长时程、不可逆、涉及价值权衡的主动（改任务目标、进新场景、替人承诺）必须上移云端慢系统并在人类回路中确认。用 **主动权限格 `𝕀`** 显式规定“哪一级系统可以在哪一风险级别上、对哪类 Scope 发起主动”，从架构上消除越权。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（主动动作空间、主动裕度与发起规则）**
在 `A = A_c × A_e` 上增加主动维 `I = {yield, query, propose, act, stop}`，得 `A_u = A × I`；主动策略 `π_u : S → I`。主动裕度
```
m_u(s) = max_{u∈I} [ ΔRegret(u|s,b) - λ_c·C_int(u) - λ_r·R_mis(u,s) ]
```
其中 `ΔRegret(u|s,b) = AG_δ(s,b) - E_{o~u}[AG_δ(s,b')]` 为主动带来的最坏后悔下降，`C_int` 为打扰成本，`R_mis` 为误主动风险。发起规则：`m_u(s) ≥ 0 ∧ within_scope(u,Scope) ∧ rollback_cost(u) ≤ κ_rev`；否则默认 `yield`。

**定义 122（可信意图集与分布鲁棒对齐间隙）**
人类意图 `θ ∈ Θ`，后验 `b(θ|s)`，人类认可成本 `c_h(a,s,θ)`。给定可信水平 `δ`，`Θ_δ = {θ : b(θ|s) ≥ δ}`（或最高后验密度集）。对齐间隙
```
AG_δ(s,b;π) = sup_{θ∈Θ_δ} [ E_{a~π(·|s)} c_h(a,s,θ) - min_a c_h(a,s,θ) ]
```
对齐可行域 `𝓐_ε = {π : AG_δ(s,b;π) ≤ ε_align, ∀s}`。

**定义 123（对齐信息价值）**
候选查询 `q ∈ Q`，观测 `o ~ P(o|q,s)`，`b' = update(b,q,o)`。
```
VoI(q|s,b) = AG_δ(s,b) - E_o[AG_δ(s,b')] - λ_c·C_int(q) - λ_r·R_leak(q)
```
`R_leak(q)` 为诱导性/泄密风险（问题本身改变或套取偏好）。仅当 `VoI(q) ≥ τ_voi` 才值得问。

**定义 124（安全对齐证书 SAC）**
```
SAC = (ε_align, δ, ρ_safe, Scope, κ_rev, evidence)
```
- `ε_align`：可信集上的对齐间隙上界；
- `δ`：可信集水平（覆盖 `P(θ_true ∈ Θ_δ) ≥ 1-δ`）；
- `ρ_safe`：物理/任务安全维度的鲁棒性下界（承第 53 轮 `ρ`）；
- `Scope = (S_scope, T_scope, Θ_scope, revocable)`：人类授权的动作/场景/意图/时限范围；
- `κ_rev = max_u rollback_cost(u)`：可撤销半径；
- `evidence`：人类确认、反事实仿真、审计日志。
判定：`AG_δ ≤ ε_align ∧ ρ ≥ ρ_safe ∧ κ_rev ≤ κ_max ∧ (s,u) ∈ Scope`。

**定义 125（对齐漂移、诱导漂移与重授权）**
自然漂移 `Δ_align(t) = W_1(b_t, b_0)`；诱导漂移 `Δ_ind(t) = W_1(b_t, b_t^∅)`，其中 `b_t^∅` 为“从未主动交互”反事实下的后验。漂移速率 `v_align = dΔ_align/dt`。若 `Δ_align > Δ_max ∨ Δ_ind > Δ_ind_max ∨ v_align > v_max`，进入 `reconsent`：冻结主动、请求新 Scope。

**定义 126（主动-对齐联合证书 IAC）**
```
IAC = (J, u_cert, SAC, DriftAudit)
```
`J` 为第 54 轮联合证书 `(ρ,A_cert,γ_ce,δ_a,evidence)`；`u_cert = (m_u, u*, VoI, C_int, R_mis)`；`DriftAudit = (Δ_align, Δ_ind, v_align, reconsent_log)`。`dom_IAC = in` 当且仅当 `J.ok ∧ SAC.ok ∧ DriftAudit.ok`。

## 2. 关键算法 伪代码

### IP-121 PIA（Proactive Initiative Actuation）
```python
def initiative_gate(s, b, actions, Q, scope, budget):
    base = robust_alignment_gap(s, b, actions, budget.delta)
    best = ('yield', base, 0.0)
    for u in candidates(s, actions, Q):          # query/propose/act/stop
        if not within_scope(u, s, scope):        # 越权硬剪枝
            continue
        if rollback_cost(u) > budget.kappa_rev:  # 不可撤销硬剪枝
            continue
        gain = base - expected_gap_after(u, s, b, budget.delta)
        m = gain - budget.lambda_c * interrupt_cost(u) \
                - budget.lambda_r * misinit_risk(u, s)
        if m > best[2]:
            best = (u, gain, m)
    return best if best[2] >= 0 else ('yield', base, best[2])
```

### IP-122 SAB（Safety Alignment Boundary）
```python
def robust_alignment_gap(s, b, actions, delta):
    support = credible_set(b, delta)             # {theta: b[theta] >= delta}
    worst = 0.0
    for theta in support:
        c = {a: human_cost(a, s, theta) for a in actions}
        best = min(c.values())
        policy_cost = sum(pi(a, s) * c[a] for a in actions)  # E_{a~pi} c
        worst = max(worst, policy_cost - best)
    return worst
```

### IP-123 ICQ（Intent Clarification Query）
```python
def select_query(s, b, actions, Q, delta, budget):
    base = robust_alignment_gap(s, b, actions, delta)
    best_q, best_voi = None, budget.tau_voi
    for q in Q:
        exp_after = 0.0
        for o, p in obs_dist(q, s, b).items():
            bp = bayes_update(b, q, o)
            exp_after += p * robust_alignment_gap(s, bp, actions, delta)
        voi = base - exp_after \
              - budget.lambda_c * interrupt_cost(q) \
              - budget.lambda_r * leak_risk(q, b)
        if voi > best_voi:
            best_q, best_voi = q, voi
    return best_q
```

### IP-124 ACD（Alignment Drift Certificate）
```python
def drift_audit(b_hist, b_counterfactual, dt, cfg):
    d_align = wasserstein1(b_hist[0], b_hist[-1])
    d_ind = wasserstein1(b_hist[-1], b_counterfactual[-1])
    v = wasserstein1(b_hist[-2], b_hist[-1]) / dt
    if d_align > cfg.delta_max or d_ind > cfg.delta_ind_max:
        return ('reconsent', d_align, d_ind, v)
    if v > cfg.v_max:
        return ('slow_down', d_align, d_ind, v)
    return ('ok', d_align, d_ind, v)
```

### IP-125 HAL（Human Alignment Ledger）
```python
class AlignmentLedger:
    def __init__(self):
        self.chain = [GENESIS]
    def commit(self, scope, consent, action, ts):
        block = {'prev': self.chain[-1].hash, 'scope': scope,
                 'consent': consent, 'action': action, 'ts': ts}
        self.chain.append(Block(block, hash=sha256(block)))
        return self.chain[-1].hash
    def revoke(self, scope_id, reason, ts):
        return self.commit(scope_id, 'revoked', reason, ts)
```

### IP-126 PSC（Proactive Safety Certificate）
```python
def proactive_safety_cert(J, u_cert, sac, audit, plan):
    if not J.ok:
        return ('reject', 'joint_cert_fail')
    if audit[0] != 'ok':
        return ('reject', 'alignment_drift', audit)
    if robust_alignment_gap(plan.s, plan.b, plan.actions, sac.delta) > sac.eps_align:
        return ('reject', 'alignment_gap')
    if min(plan.rho.values()) < sac.rho_safe:
        return ('reject', 'safety_rho')
    if max(rollback_cost(u) for u in plan.u_seq) > sac.kappa_rev:
        return ('reject', 'irreversible')
    if not all(within_scope(u, plan.s, sac.Scope) for u in plan.u_seq):
        return ('reject', 'out_of_scope')
    return ('ok', IAC(J, u_cert, sac, audit))
```

## 3. 关键推导、复杂度与正确性

**命题 1（查询后悔收缩）** 由定义 123，若 `VoI(q) ≥ AG_δ(b) - ε + λ_c C_int + λ_r R_leak`，则 `E_o[AG_δ(b')] ≤ ε`。即查询把“期望对齐间隙”压到预算内，且该保证只依赖可信集上的最坏后悔，不依赖后验均值，因而是单边的。

**命题 2（主动偏置）** 设误主动成本 `c_FP`、漏主动成本 `c_FN` 且 `c_FP > c_FN`。若后验校准误差为 `β_b`，则任何只最小化期望后悔、不含硬 Scope/可撤销约束的策略，其误主动率下界随 `β_b` 单调上升。直觉：期望最优会把低概率高风险意图压成零，而硬约束对 `b` 不敏感。故主动必须有硬权限与硬撤销。

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PIA | O(|I|·|Θ_δ|·|A|) | O(|Θ_δ|+|A|) | 裕度校准、VoI 无偏 |
| SAB | O(|A|·|Θ_δ|) | O(|Θ_δ|) | 可信集覆盖、后悔单边 |
| ICQ | O(|Q|·|Θ_δ|·|O|) | O(|Q|·|Θ_δ|) | 后验更新可逆、问题中性 |
| ACD | O(T·|Θ|) | O(T) | 漂移度量稳定、反事实可比 |
| HAL | O(1) 摊销 | O(T) | 哈希链不可篡改、撤销生效 |
| PSC | O(|S|·|A|) | O(|A|) | 四证联合 sound |

**正确性定理（Proactive-Aligned Interaction Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 可信集覆盖 `P(θ_true ∈ Θ_δ) ≥ 1-δ`；**(A30)** `C_int`、`R_mis` 有上界且估计无系统偏置；**(A31)** 主动动作可撤销且 `κ_rev ≤ κ_max`；**(A32)** 诱导漂移与自然漂移均在预算内。
则对任意通过 PSC 的主动策略：
```
P(人类认可 | 主动) ≥ 1 - ε_align - δ - β_b - P(κ_rev > κ_max) - P(Δ_ind > Δ_ind_max)
```
关键：**主动必须被最坏后悔、硬权限、可撤销性三重约束**；**查询价值必须扣除打扰与诱导成本**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 可信集覆盖失效 → 对齐间隙低估 | 高 | 共形校准 + 温度标定 + 人类抽检 |

| 可撤销半径低估 | 中 | 沙箱回滚演练 + 最坏情况估计 |

## 6. 本轮最大风险

**一句话**：主动交互与安全对齐把系统从“执行已给定任务”推进到“自己决定是否替人做主”，其 soundness **三重依赖可信意图集的覆盖、打扰/诱导成本的诚实建模、以及主动动作的可撤销性**；一旦可信集漏掉真实意图、或主动查询诱导出伪偏好、或不可逆动作被误判为可回滚，机器人就会以“我在帮你”的名义系统性越权，且越主动越难纠偏，故必须以 **共形可信集 + 不对称主动损失 + 硬性撤销预算** 三重护栏，宁可不主动，绝不把“看似对齐”当作发起交互的许可证。

```python
        policy_cost = sum(pi(a, s)*c[a] for a in actions)
        worst = max(worst, policy_cost - min(c.values()))
    return worst

def aligned_filter(s, b, actions, sac):
    return [a for a in actions
            if a in sac.Scope and rollback_cost(a) <= sac.kappa_rev
            and robust_alignment_gap(s, b, [a], sac.delta) <= sac.eps_align]
```

```python
def select_query(s, b, actions, Q, delta, budget):
    base = robust_alignment_gap(s, b, actions, delta)
    best_q, best_voi = None, budget.tau_voi
    for q in Q:
        exp_after = sum(p * robust_alignment_gap(s, bayes_update(b,q,o), actions, delta)
                        for o, p in obs_dist(q, s, b).items())
        voi = base - exp_after - budget.lambda_c*interrupt_cost(q) \
              - budget.lambda_r*leak_risk(q, b)
        if voi > best_voi: best_q, best_voi = q, voi
    return best_q
```

## 3. 关键推导与正确性

**命题 1（后悔收缩）**：`E_o[AG_δ(b')] = AG_δ(b) - VoI(q) - λ_c C_int - λ_r R_leak`，故 `VoI(q) ≥ AG_δ(b) - ε + 成本项` 时必有 `E_o[AG_δ(b')] ≤ ε`。查询选择因此是“把证书量压进预算”的直接手段。

**命题 2（主动偏置下界）**：当 `c_FP > c_FN` 且后验校准误差为 `β_b` 时，无硬 Scope/可撤销约束的期望最优策略，其误主动率下界随 `β_b` 上升；硬约束不依赖 `b`，是唯一的分布外防线。

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PIA | O(|I|·|Θ_δ|·|A|) | O(|Θ_δ|+|A|) | 裕度校准、VoI 无偏 |
| SAB | O(|A|·|Θ_δ|) | O(|Θ_δ|) | 可信集覆盖、后悔单边 |
| ICQ | O(|Q|·|Θ_δ|·|O|) | O(|Q|·|Θ_δ|) | 后验可逆、问题中性 |
| ACD | O(T·|Θ|) | O(T) | 漂移度量稳定、反事实可比 |
| HAL | O(1) 摊销 | O(T) | 哈希链不可篡改、撤销生效 |
| PSC | O(|S|·|A|) | O(|A|) | 四证联合 sound |

**正确性定理（Proactive-Aligned Interaction Soundness）**
假设第 54 轮 (A26)-(A28) 成立；**(A29)** `P(θ_true∈Θ_δ) ≥ 1-δ`；**(A30)** `C_int,R_mis` 有上界且无系统偏置；**(A31)** `κ_rev ≤ κ_max`；**(A32)** `Δ_ind ≤ Δ_ind_max`。则通过 PSC 的主动策略满足
```
P(人类认可 | 主动) ≥ 1 - ε_align - δ - β_b - P(κ_rev>κ_max) - P(Δ_ind>Δ_ind_max)
```

## 6. 本轮最大风险

**一句话**：主动交互与安全对齐把系统从“执行已给定任务”推进到“自己决定是否替人做主”，其 soundness **三重依赖可信意图集的覆盖、打扰/诱导成本的诚实建模、以及主动动作的可撤销性**；一旦可信集漏掉真实意图、或主动查询诱导出伪偏好、或不可逆动作被误判为可回滚，机器人就会以“我在帮你”的名义系统性越权，且越主动越难纠偏，故必须以 **共形可信集 + 不对称主动损失 + 硬性撤销预算** 三重护栏，宁可不主动，绝不把“看似对齐”当作发起交互的许可证。
