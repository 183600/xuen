# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「虚拟仿真」×「排行榜」）

> R69 给闭环装上了一张嘴：不确定性被一分为二，epistemic 的部分交给「看 / 问 / 触」去消解，并立下证据纪律——问来的答案不能单源定案。但 R69 有一个从未言明的前提：**消歧要么发生在现实里（直接选），要么发生在交互里（去问）**。它没有第三条通道——**在动真格之前，先在脑子里把未来演一遍**。而这恰是人类在「问不到、也等不起」时最常用的手段：拿不准就先「预演」。
>
> 本轮两个灵感正好补上这块：
> - **虚拟仿真**给出一个安全、廉价、可反复重放的沙盘——在不碰真实执行器的前提下，把每个候选模态各演一遍；
> - **排行榜**给出一个只需「两两比较」就能完成选角的结构——不需要绝对分数，只需要排序；而排序对「共模偏置」天生更稳健。
>
> 核心命题：**在 R69 的「直接做 / 去问」之外并联第三条通道「先预演」；但预演（仿真）只能证伪、不能证实，排行榜只在「可分且经排序校准」时才可定案，否则 ARENA 逐指令退化为 R69。** 命名 **ARENA-RAS**（Audited Robust ENsemble Arena：带审计的稳健集成竞技场）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我梦见的未来可信吗，预演出来的冠军真的会赢吗**」——想象也是一种证据，但它是最容易被自己偏见加冕的那一种证据。

## 0. 直觉与动机

**灵感 1（虚拟仿真 → 决策前的「沙盘推演」）**
直觉：R69 已经能一次吐出 K 个模态，但它只有两种处置——在现实里赌一个，或去现实里问一句。人还有第三种：先在脑子里过一遍。预演的价值有两层：**安全**（失败发生在沙盘里，代价为零）与**廉价**（可以演一百遍再动一次）。技术落点很自然：R67 的 VISTA 世界模型本来就是「预测未来」的，把它从「单条预测」升级为「带参数扰动的集成」，就得到一个可反复采样的仿真沙盘，无需新建昂贵的物理引擎。

**灵感 2（排行榜 → 只要排序，不要绝对分）**
直觉：选模态本质上只需要「谁第一」。而「谁第一」比「绝对得几分」更容易从仿真迁移到现实：若仿真的偏差是**共模**的（对所有模态施加同一个偏移或同一个单调扭曲），胜负关系不变。排行榜（成对对决 → Bradley-Terry / Elo）恰恰只消费胜负、不消费绝对值。更妙的是它可以「随时叫停」——一旦冠军与亚军在置信区间上分开就不必再演，这天然适配实时预算（best-arm identification）。

**灵感 3（合起来 → 想象是最容易自恋的证据）**
直觉：R69 对「问来的话」立了证据纪律；本轮必须对「演出来的未来」立同样的纪律，因为仿真比人更容易被讨好。仿真器是模型，模型可以被优化——一个模态只要学会利用仿真器的伪影（碰撞检测太松、奖励函数有洞、接触太滑），就能在排行榜上刷出冠军，而在现实里一败涂地。这就是排行榜的经典陷阱：**Goodhart——当度量变成目标，它就不再是好的度量**。所以本轮的姿态是四条铁律：(a) **仿真只能证伪、不能证实**（能淘汰坏模态，不能给好模态盖章）；(b) **只有可分且经过排序校准的排行榜才可定案**（领先幅度 > 仿真噪声底线，且历史 sim-real 排序相关达标）；(c) **留出（sealed）仿真器做盲测**，只在可见仿真器上赢的模态一律可疑；(d) **仿真不替代交互**，它最多给交互装准星。

**灵感 4（第三条通道 → 只在「问不到也等不起」时启用）**
直觉：预演很贵（算力 / 延迟），而且容易被骗，所以它只能是**稀疏的、按需的**：只在 R69 已报出 epistemic 歧义、且交互预算耗尽或交互不安全时才启用；否则直接走 R69。这样 ARENA 不改变常规路径的实时性，只在真拿不准时多花一次预算。这是对 R69「严格包含」姿态的延续：**新通道是旧闭环的并联旁路，不是替换**——新层必须是旧层的严格泛化，而不是并列替代，否则每加一层就多一个需要独立信任的黑箱。

**灵感 5（排行榜还能「瞄准」交互 → 仿真当望远镜）**
直觉：即使排行榜本身不可信，仿真仍有一个安全用途——在沙盘里算出「哪一次注视 / 哪一句问话最能分开前两名」，然后把 R69 的交互对准那里。**仿真不替代交互，而是给交互装准星。** 这把「预演」与「求证」接成一个闭环：想象告诉你该看哪里，看一眼回来再修正想象（SRC 更新）。于是「虚拟仿真」与「多模态交互」不再是两条平行技术，而是互为先验与校准的一对。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ARENA-RAS 总览）** ARENA-RAS = (VSA, DUE, LAD, FBR, SIG, SRC, RRA, SIP, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **仿真预算硬约束**：单次决策 rollout ≤ B_sim、墙钟 ≤ τ_sim，仿真永不写真实执行器；
(iii) **证伪单边纪律**：仿真可淘汰、可排序、可瞄准交互，但不得作为「确认」单一模态的唯一证据，不得替代 R69 定义 293-iii 的证据纪律；
(iv) **定案门槛**：仅当 Δ_rank > σ_sim ∧ ρ_rank ≥ τ_rank ∧ ¬exploit ∧ rank_stable ∧ 预算未越界 时排行榜方可定案；否则逐指令退化 R69。

**定义 311（虚拟仿真沙盘 VSA）** 仿真集成 𝒮 = {S_m}_{m=1..M}，以 R67 VISTA 为基座，第 m 个仿真器的动力学由参数扰动 θ_m ~ p(θ)（潜变量随机化 / 参数集成 / 物理 fuzz）生成。对模态 m_k 与仿真器 S_m：rollout 得 τ = S_m(x_t, ξ_k; θ_m)，产出 (r, c, φ, ρ)（回报、成本、可行性、终端风险）。**可见集 𝒮_vis 与留出集 𝒮_ho 分离**，排序器只见 𝒮_vis。

**定义 312（仿真噪声底线 σ_sim）** 同一模态重复 rollout 的结局差异标准差（test-retest 可靠性）：σ_sim = std_{a,b∈𝒮}[ Δ(r_a, r_b) | 同一 ξ ]。这是排行榜的分辨率极限：任何小于 σ_sim 的领先都「不可分」。

**定义 313（成对对决与 Bradley-Terry 排行榜 LAD）** 对 (i,j) 用 𝒮_vis 判胜负 y_ij ∈ {i≻j, j≻i, tie}；拟合 P(i≻j) = σ_BT(s_i − s_j)。排行榜 L = 按强度 s 排序，并给出 anytime 置信序列 CI_i(t)。**可分边缘** Δ_rank = (s_(1) − CI_(1)) − (s_(2) + CI_(2))。

**定义 314（自适应对决配额 DUE）** LUCB 式：每轮选「最接近且置信仍重叠」的一对 (a,b) 对决，把预算花在最难分的地方；一旦 Δ_rank > σ_sim 立即 early-exit。对决次数服从预算 B_sim 硬上限。

**定义 315（稳健排名聚合 RRA）** 当多个仿真器 / 裁判给出不一致排序：用 median-of-ranks 或 Kemeny 且对离群裁判降权；若裁判间排序分歧（Kendall τ 方差）超阈值，判为「排名不稳定」，不得定案。

**定义 316（证伪过滤器 FBR）** 令 𝒯_stress 为物理极值 / 对抗场景集。模态 m_k 被淘汰当且仅当 ∃ S_m∈𝒮 与 ∃ s∈𝒯_stress 使 φ=0 或 ρ>ρ_max。存活集 𝒜_surv 表示「未被证伪」，**不表示「被证实安全」**。

**定义 317（仿真诚信治理 SIG）** 对每个候选计算可见集与留出集的对决边缘差 Δ_exploit = margin(𝒮_vis) − margin(𝒮_ho)。Δ_exploit > τ_exploit ⇒ 判为「利用仿真伪影刷榜」，降权 / 隔离。留出集每轮轮换并对排序器不可见。

**定义 318（仿真-现实排序校准 SRC）** 历史已提交决策上，仿真的模态排序与现实的模态排序的 Spearman 相关 ρ_rank。ρ_rank < τ_rank ⇒ 排行榜不可信，禁用定案（对应 R69 MCG 的「排序版」）。

**定义 319（仿真引导探询 SIP）** 排行榜不可定案时，用 𝒮 估计各信息动作 g 的期望信息增益 I_sim(M; y|g)，选 g* = argmax_g I_sim − c(g)，交回 R69 的 MINT 执行。仿真只**瞄准**交互，不**替代**交互。

**定义 320（排行榜奖金与退化边界 ARB）** 定案成功：λ = λ_floor(U_ale) 且可对 U_epi 取 resolution bonus（比 R69 更不保守，但提交仍过 C-RAS-WM，故不低于安全包络）；不可分 / 未校准 / 被刷榜 / 超预算：逐指令退回 R69；R69 再退回 R68。⇒ R68 ⊂ R69 ⊂ ARENA 是严格能力包含、且安全侧逐步不让步。

**定义 321（排行榜投毒威胁 ℰ_rank）** 多智能体共享排行榜时的 Sybil 模态（伪造多个候选刷票）、裁判共谋（多个仿真器同时被偏置）、时间维 Goodhart（逐轮抬高「看起来在进步」的虚假冠军）、以及仿真伪影利用。并入 AIC：ℰ_ARENA = ℰ_FLUID × ℰ_sim（仿真欺骗）× ℰ_rank。

**定义 322（参与式审计 VQAuditor-S）** 审计仿真 / 排行决策：留出集是否真留出、Δ_exploit 是否被处理、SRC 是否被更新、排行榜是否被刷、定案是否越过 σ_sim。结论回灌 AuditBuf，成为下一轮 τ_exploit / τ_rank 的先验。

**定义 323（证书 J_ARENA）** J_ARENA = (J_FLUID, sim_ensemble_hash, σ_sim, Δ_rank, ρ_rank, exploit_flag, rank_stability, rollout_budget_used, arena_ver)。Valid ⇔ Valid(J_FLUID) ∧ Δ_rank > σ_sim ∧ ρ_rank ≥ τ_rank ∧ ¬exploit_flag ∧ rank_stable ∧ 预算未越界。

**定义 324（严格退化与逐指令一致）** 退化触发集 D = {U_epi ≤ τ_epi} ∪ {mode_head < τ_mode} ∪ {不可分} ∪ {ρ_rank < τ_rank} ∪ {exploit} ∪ {超预算}。在 D 上 ARENA 与 R69 逐指令相同。

**定义 325（时序与异步）** 常规路径不仿真（K=1，走 R69）；仅当 U_epi > τ_epi 且交互不可用 / 超预算时启动 VSA（默认 M=3, H=16，复用 VISTA）；SIG / SRC 异步摊销（读缓存），不阻塞实时环。

**定义 326（想象-求证对偶）** 仿真通道（imagined evidence）与交互通道（real evidence）构成对偶：仿真可在沙盘里「先验地」算信息增益并瞄准交互（SIP），交互回来的真实证据再修正仿真排序（SRC 更新）。二者互为对方的先验与校准，任一方单独都不可定案。

## 2. 关键算法骨架

```python
# IP-264 VSA：随机化 VISTA 仿真集成（复用 R67 世界模型，零新建物理引擎）
class SimArena:
    def __init__(self, vista, M=3, B_sim=8, tau_sim_ms=6.0, stress=STRESS_SET):
        self.base, self.M = vista, M
        self.thetas = [perturb(vista.params) for _ in range(M)]   # θ_m ~ p(θ)
        self.vis, self.ho = self.thetas[:M-1], self.thetas[M-1:]  # 可见/留出分离
        self.B, self.tau, self.stress = B_sim, tau_sim_ms, stress
    def rollout(self, xi, x_t, theta, stress=None):
        return self.base.rollout(x_t, xi, H, params=theta, inject=stress)

# IP-267 FBR：证伪（单边：能淘汰，不能确认）
def falsify(modes, arena, x_t):
    surv = []
    for m in modes:
        outs = [arena.rollout(m.xi, x_t, th) for th in arena.vis]
        bad  = any((not o.feasible) or o.risk > RHO_MAX for o in outs) \
               or any(not arena.rollout(m.xi, x_t, th, s).feasible
                      for th in arena.vis[:1] for s in arena.stress)
        if not bad: surv.append(m)              # 存活 ≠ 证实
    return surv

# IP-265/266 DUE+LAD：LUCB 配额 + Bradley-Terry anytime 排行榜
def arena_leaderboard(surv, arena, x_t, budget):
    if len(surv) <= 1: return surv, float('inf'), 0.0
    s  = {m.id: 0.0 for m in surv}; ci = {m.id: 1.0 for m in surv}
    while budget.left() > 0:
        a, b = most_confusable(s, ci)                 # 最接近且 CI 重叠
        y = duel(arena.vis, a, b, x_t)                # 成对胜负
        s, ci = bt_update(s, ci, a, b, y)             # 在线 BT + anytime CI
        if top1_margin(s, ci) > sigma_sim(arena): break
    order  = sorted(surv, key=lambda m: -s[m.id])
    return order, top1_margin(s, ci), sigma_sim(arena)

# IP-268 SIG：留出盲测，检测刷榜
def exploit_check(mode, arena, x_t):
    return duel_margin(mode, arena.vis, x_t) - duel_margin(mode, arena.ho, x_t)

# IP-269 SRC：仿真排序 vs 现实排序（异步读缓存）
def sim_real_rank_corr(hist):
    return spearman([h.sim_rank for h in hist], [h.real_rank for h in hist])

# IP-271 SIP：排行榜不决时，用仿真给交互装准星
def sim_informed_probe(top2, arena, x_t):
    return argmax(g, E_sim[H(M|o) - H(M|o, y_g)])

# IP-276 主闭环（继承 R69，仅在其模态选择处并联 ARENA 旁路）
def ARENA_RAS_round(M, obs):
    z, U_ale, U_epi, modes = M.r69_forward(obs)        # R69 一次前向
    if U_epi <= TAU_EPI or M.fmp.mode_head(z) < TAU_MODE:
        return M.fluid_round(obs)                      # 无歧义 → 逐指令 R69
    surv = M.fbr.falsify(modes, M.vsa, x_t)            # 1) 先淘汰（单边可靠）
    if len(surv) == 1:
        return M.commit(surv[0], bonus=True, why='falsification')
    order, margin, sig = M.arena.leaderboard(surv, M.vsa, x_t, M.budget)
    exploit = any(M.sig.exploit_check(m, M.vsa, x_t) > TAU_EXPL for m in surv)
    rho     = M.src.rank_corr()                        # 异步缓存
    rankable = (margin > sig) and (rho >= TAU_RANK) and (not exploit) \
               and M.rra.stable(surv)
    if rankable:
        return M.commit(order[0], bonus=True, why='leaderboard')   # 2) 可定案
    g = M.sip.probe(order[:2], M.vsa, x_t) if M.budget.allow_probe() else None
    return M.fluid_round(obs, restrict_to=surv, probe_hint=g)      # 3) 退化 R69（可瞄准）
```

## 3. 推导

**引理 19（共模偏置在成对比较中相消）** 设真实结局 u_k = f(o_k) + b_k，仿真判官对 u 单调。若 sim-real 偏置对所有模态共模，即 b_k ≡ b（或经同一单调扭曲 Ψ 作用于所有模态），则任意对的胜负 sign(u_i − u_j) 与 sign(Ψ(u_i) − Ψ(u_j)) 不变，故排行榜排序不变；只有模态相关偏置 b_i ≠ b_j 才能翻转排序。系：**排行榜应建立在「差」而非「绝对值」上；留出集的作用正是把模态相关偏置暴露出来**（Δ_exploit 度量其大小）。

**引理 20（证伪的单边可靠性）** 在 A99（𝒯_stress 中每个场景都是真实动力学的一个过近似 / 极端化，即若真实中对所有场景可行则必在某个 stress 场景可行）下，若模态 m 在某 stress 场景失败，则 m 在真实中不可能对所有场景都安全；故淘汰是**可靠**的（sound），P(真实失败 | 被淘汰) 高。但反之不成立：P(被淘汰 | 真实失败) 可低，存活不构成证实。系：**ARENA 只把仿真用于「减集」，绝不用于「盖章」**——这正是定义 310-iii。

**引理 21（排行榜的可辨识阈值）** 设前两名真实强度差 Δ，仿真每次对决的噪声方差 σ²。则正确识别冠军的概率 P_top1 随 Δ/σ 单调增，且当 Δ < c·σ_sim（c≈2，与 k、CI 宽度相关）时，任何排行榜的 top-1 与随机选择在 1−ε 置信下不可区分（标准 best-arm identification / LUCB 下界）。系：**低于仿真噪声底线的「冠军」是噪声的冠军**，故立「不可分不定案」（定义 310-iv）。

**引理 22（刷榜的可检测性）** 若模态优势来自仿真伪影（可见集有、留出集无），则 Δ_exploit 的期望等于该伪影贡献 α；用 m 个独立留出仿真器，检测统计量的信噪比 ∝ α√m，误报由 τ_exploit 控制。故**留出集 + 轮换**使「靠伪影赢」的优势可被系统性识别；系：**排行榜必须有一半裁判永远不给排序器看**。

**定理 18（ARENA 严格包含 R69）** 在 A99–A102 下，对任意状态 s，ARENA 的期望任务损失 ≤ R69（它只在 R69 的模态集上做「证伪减集 + 可分排序」，证伪可靠、排序可分则必优），且在退化集 D（定义 324）上与 R69 **逐指令相同**。故 R68 ⊂ R69 ⊂ ARENA 是能力严格包含、安全侧不让步：**错误的仿真只会让你少赚效率，不会让你越过安全包络**（提交仍过 C-RAS-WM，见定理 20）。

**定理 19（仿真引导探询不劣于盲探询）** 若仿真的信息增益估计校准（ρ_IG ≥ τ），则 SIP 选出的 g* 的期望真实 VoI ≥ 盲 MINT 的期望 VoI；且当仿真不可信（ρ_rank < τ_rank）时 SIP 被禁用、退回盲 MINT。系：**仿真可以当望远镜，但不能当眼睛**——它瞄准交互，证据仍须来自现实（定义 326）。

**定理 20（无新增物理风险）** VSA 只读世界模型、永不写执行器；ARB 的 resolution bonus 只作用于 U_epi 分量、不突破 λ_floor(U_ale)，且提交模态仍须过 C-RAS-WM 前缀认证。故 ARENA 的最坏情况是「选了一个次优但已认证的模态」（性能损失），而非「选了一个越界的模态」（安全损失）。⇒ 仿真的自恋只能让你输掉效率，不能让你撞墙。

## 6. 本轮最大风险

**一句话**：ARENA 的全部效率收益都押在「仿真里排出来的名次能迁移到现实」这一前提上——**一旦仿真的排序被模式相关偏置污染、被留出集之外的新伪影刷榜、或随轮次 Goodhart 化，系统就会以「已淘汰其余选项」的自信，为一个在现实中并不更优甚至更差的模态加冕；而排行榜是最善于把模型的偏见伪装成客观裁决的评价装置，所以这种失败是安静的——预演错，比不预演更危险，排行榜会把模型的自恋误认成现实的加冕。**

**次级风险与缓解**：仿真预算击穿实时（定义 314 自适应配额 + early-exit + 常规路径不仿真）；仿真伪影刷榜（定义 317 留出盲测 + ℰ_rank 对抗训练）；证伪不 sound（定义 316 的 𝒯_stress 过近似 + 引理 20 单边纪律）；rank 过时 / Goodhart（定义 318 SRC 门 + 留出轮换 + E311）；裁判分歧 / Condorcet 循环（定义 315 RRA + 保留 Pareto 前沿、以 maximin 决策）；多智能体投毒（定义 321 Sybil 抵抗 + E315）。

def arena_leaderboard(surv, arena, x_t, budget):

## 4. 推导

**引理 19（共模偏置相消）** 若 sim-real 偏置对所有模态共模（同一加性偏移或同一单调扭曲），则任意对的胜负符号不变，排行榜排序不变；只有模态相关偏置才能翻转排序。系：排行榜建立在「差」而非绝对值上，留出集专门暴露模态相关偏置。

**引理 20（证伪单边可靠）** A99（𝒯_stress 过近似真实动力学）下，被淘汰模态在真实中不可能对所有场景安全（sound）；但存活不构成证实（P(被淘汰|真实失败) 可低）。系：仿真只减集、不盖章。

**引理 21（可辨识阈值）** 正确识别冠军的概率随 `Δ/σ` 单调增；当 `Δ < c·σ_sim` 时 top-1 与随机不可区分（LUCB 下界）。系：低于噪声底线的冠军是噪声的冠军，故「不可分不定案」。

**引理 22（刷榜可检测）** 伪影优势 α 使 `E[Δ_exploit]=α`；m 个留出仿真器使检测信噪比 ∝ α√m，误报由 τ_exploit 控制。系：留出集必须轮换且对排序器不可见。

**定理 18（ARENA 严格包含 R69）** A99–A102 下，ARENA 期望任务损失 ≤ R69；在退化集 D 上与 R69 逐指令相同。故 R68 ⊂ R69 ⊂ ARENA 是能力严格包含、安全侧不让步。

**定理 19（SIP 不劣于盲探询）** 仿真 IG 校准（ρ_IG≥τ）时，SIP 的期望真实 VoI ≥ 盲 MINT；仿不可信时禁用 SIP。系：仿真当望远镜，不当眼睛。

**定理 20（无新增物理风险）** VSA 不写执行器；resolution bonus 只作用于 U_epi、不破 λ_floor(U_ale)，提交仍过 C-RAS-WM。最坏是「次优但已认证」的性能损失，不是「越界」的安全损失。

## 7. 本轮最大风险

**一句话**：ARENA 的全部效率收益都押在「仿真里排出来的名次能迁移到现实」这一前提上——**一旦仿真的排序被模式相关偏置污染、被留出集之外的新伪影刷榜、或随轮次 Goodhart 化，系统就会以「已淘汰其余选项」的自信，为一个在现实中并不更优甚至更差的模态加冕；排行榜是最善于把模型的偏见伪装成客观裁决的评价装置，所以这种失败是安静的——预演错，比不预演更危险。**

**次级风险与缓解**：仿真预算击穿实时（DUE 自适应配额 + early-exit + 常规不仿真）；仿真伪影刷榜（SIG 留出盲测 + ℰ_rank 对抗训练）；证伪不 sound（𝒯_stress 过近似 + 引理 20 单边纪律）；rank 过时 / Goodhart（SRC 门 + 留出轮换 + E311）；裁判分歧 / Condorcet 循环（RRA + 保留 Pareto 前沿、maximin 决策）；多智能体投毒（ℰ_rank Sybil 抵抗 + E315）。
