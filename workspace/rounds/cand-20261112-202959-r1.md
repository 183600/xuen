# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 8 轮；本轮灵感：「情感计算」×「避障控制」）

> 第 61 轮把「场景—意图—阻抗—证据」统一进 USR，用 MEL 做零样本物理推断、DMS 做多轮对话、SRT-Dual 解耦语义流/实时流。但**“人”这个维度仍然是扁平的**：
> 1. **USR 里没有“感受”**：`b_intent` 只刻画“想做什么”，不刻画“此刻多紧张、多信任、多舒适”。同一句“轻一点”，在恐惧与玩笑两种情绪下应导出不同的安全边界。
> 2. **避障只活在几何层**：EEIS/ERTC 的安全集是固定的距离/力限，**不知道人的主观安全区会随情绪、信任、注意力而伸缩**——对焦虑的人 0.8m 太近，对专注协作的人 1.2m 又太远。
> 3. **DMS 不会“解释/安抚”**：对话只围绕约束协商；执行中因避障产生的绕行、停顿、任务偏差**没有向人解释**，人容易把它读成“笨”或“危险”，反过来进一步降低信任。
> 4. **安全裕度是静态常数**：证书里的 `ε_safe` 不随人状态变化，无法表达“宁可我保守一点，也别吓到人”这种安全—情感耦合。
> 5. **情感推断本身是高风险传感器**：表情/语音/生理线索噪声大、可伪装、有隐私与操纵风险；若让不可靠的情感直接**放松**安全约束，会产生“笑着把人撞了”的灾难。

## 0. 直觉与动机

**灵感 1（情感计算 → 情感-语义统一表征 ASU）**
直觉：第 61 轮的 USR 是“物理交互的语义投影”，但交互的另一半是**人的内在状态**。关键洞见：在 USR 中开辟一个**情感子空间** ℝ^d_aff，把人的情感状态 `a_h = (v, r, τ, κ, ℓ)`（效价 valence、唤醒 arousal、信任 trust、舒适 comfort、认知负荷 load）与机器人自身的“谨慎状态” `a_r = (confidence, caution, urgency)` 一起编码为 `affect_emb`。于是 USR 从“场景-意图-阻抗-证据”升级为“场景-意图-**情感**-阻抗-证据”五元组，情感不再是外挂标签，而是能与场景/意图在同一空间做**一致性对齐**的第一等实体。

**灵感 2（避障控制 → 情感调制控制屏障函数 ACBF）**
直觉：经典避障用固定安全距离 `d_min` 或控制屏障函数（CBF）`h(x)=d(x)-d_min≥0`。关键洞见：**人感知到的“安全”不是欧氏距离，而是“距离减去主观安全半径”**。把人状态吃进屏障：`h_aff(x,a)=d(x,human)-d_min(a)`，其中 `d_min(a)` 随焦虑/低信任上升、随舒适/高信任下降。CBF-QP 仍在 1kHz 实时流求解，但安全集被**语义流的情感锚点**调制——这是第 61 轮 SRT-Dual 的自然延伸：情感锚点与语义锚点共用同一套 CAS/版本号协议。

**灵感 3（合流一 → 双层安全集与单调裕度 MSMP）**
直觉：让不可靠的情感去放松安全约束是危险的。关键洞见：把安全集拆成**硬层** `C_hard`（几何/力/速度硬限，情感永不可改）与**软层** `C_soft(d_min(a))`（情感可调）。并规定**非对称更新**：情感只能让裕度**立即收紧**，放松必须满足“新鲜锚点 + 低不确定性 + 慢斜率 + 人同意”。这样，即使情感推断完全错误，系统仍退化为“只会更保守”，不会更危险。

**灵感 4（避障控制 → 时空-社会风险场 STRisk）**
直觉：避障不只看“此刻离多远”，还要看“未来 1~2s 会不会撞上”，以及“从人的视角看是否冒犯”。关键洞见：用 MEL 的轨迹预测构造**时空风险场** `R(x,t)`，叠加动力学风险（TTC）、近体学风险（proxemics）、情感风险（对方恐惧/注意力分散）。风险场作为 EEIS 的**避障先验**，与阻抗先验并列进入编译。

**灵感 5（合流二 → 情感-避障闭环 EACL 与情感接地对话 A-DMS）**
直觉：情感影响避障，避障又反过来改变人的情感，这是一个闭环。关键洞见：建模**信任动力学** `τ_{t+1}=f(τ_t, 成功率, 违规, 解释有效性)`；当机器人为了避障而偏离任务时，DMS 必须主动**解释**（“我绕开一点，是为了不吓到您”），并允许人用语言**松绑软裕度**（“没关系，靠近点”），但硬层永不松绑。这让“情感计算”从“读心”变成“可协商、可审计的共情”。

**灵感 6（PCE → 情感/避障/隐私三预算）**
直觉：情感推断、CBF 求解、轨迹预测都要花预算，且情感数据有隐私与操纵风险。关键洞见：扩展 `B_aff = (估计频率, 模态预算, 不确定性阈值, 同意标志, 保留 TTL)`、`B_avoid = (CBF 迭代, 预测时域, QP 可行性预算)`，并新增**操纵护栏**：预算耗尽或未获同意时，情感信息只能用于“收紧安全”，不能用于“说服/引导/加速任务”。

## 1. 形式化定义（增量：定义 173–185）

**定义 173（情感-语义统一表征空间 ASU）** 在 USR 基础上扩展为 `U⁺ = (U, E_aff, d_aff, Π_aff, ℒ_aff)`：
- **情感嵌入**：`E_aff: (V, Voice, Physio, Dialogue, H_hist) → affect_emb ∈ ℝ^{d_aff}`，`d_aff=64`
- **人的情感状态**：`a_h = (v, r, τ, κ, ℓ) ∈ [-1,1]×[0,1]⁴`，分别为效价、唤醒、信任、舒适、认知负荷
- **机器人谨慎状态**：`a_r = (confidence, caution, urgency) ∈ [0,1]³`
- **情感投影头**：`Π_aff: ℝ^{d_aff} → (d_min, v_max, K_scale)`，把情感嵌入投影为**软安全裕度、速度上限、阻抗缩放**
- **情感对齐损失**：`ℒ_aff = ‖E_aff(a_h) - (w_s·scene_emb + w_i·intent_emb + w_e·evidence_emb)‖²`，避免情感表征与交互语境脱节
- **情感锚点**：`AffAnchor_t = (affect_emb, a_h, U_aff, consent, version, ts)`，与第 61 轮语义锚点同协议写入

**定义 174（多模态情感状态估计器 ASE）** `ASE = (Enc_face, Enc_voice, Enc_physio, Enc_text, Fuse, Head_dist, Head_unc)`：
- 输入：面部表情（可选）、语音韵律、生理信号（HRV/EDA，可选）、对话文本情感、交互历史
- 输出：`p(a_h | obs) = N(μ_a, Σ_a)`，**永远是分布而非单一标签**
- 不确定性分解：`U_aff = (U_ep, U_al)`，`U_ep` 由模态缺失/分布外触发，`U_al` 由传感器噪声触发
- **校准**：温度缩放 + conformal prediction，保证 `P(a_h ∈ C_α) ≥ 1-α`
- **缺失鲁棒**：任一模态缺失时，用其余模态 + 先验，且 `U_ep` 自动抬升

**定义 175（双层安全集与情感调制裕度）** 对第 `i` 个人/障碍物定义：
```
硬层（情感永不可改）：C_hard = { x : d_i(x) ≥ d_hard, |F| ≤ F_hard, |v| ≤ v_hard }
软层（情感可调）    ：C_soft = { x : d_i(x) ≥ d_min(a_h, U_aff) }
                    d_min = clip( d_base + w_v(1-v) + w_r·r + w_τ(1-τ) + w_ℓ·ℓ
                                  + γ·σ_aff,  d_hard,  d_max )
```
其中 `σ_aff` 为情感分布标准差，`γ>0`。**关键性质**：不确定性越高，裕度越大（保守），因此情感估错时只会“更保守”。`d_min ≥ d_hard` 恒成立。

**定义 176（情感调制控制屏障函数 ACBF）** 对角速度/加速度控制 `u` 定义：
```
h_i(x, a_h) = d_i(x) - d_min(a_h, U_aff)
ACBF 约束   ：ḣ_i + α(h_i) ≥ 0,   α 为 class-κ 函数
实时 QP     ：u* = argmin ‖u - u_nom‖²
              s.t. ḣ_i + α(h_i) ≥ 0,  ∀i
                   u ∈ U_hard,  x⁺ ∈ C_hard
```
多目标时取所有约束的交；动态障碍用预测位置 `d_i(x, t+Δ)` 的**鲁棒管（tube）**下界。

**定义 177（单调安全裕度协议 MSMP）** 约束情感裕度的时间演化：
```
收紧（增大 d_min）：立即生效，无需同意
放松（减小 d_min）：需同时满足
   ① 锚点新鲜：now - AffAnchor.ts < τ_aff_fresh
   ② 不确定性低：σ_aff ≤ σ_max 且 U_ep ≤ ε_ep
   ③ 斜率受限：d_min(t) - d_min(t-Δ) ≥ -ρ·Δ   （每周期最多放松 ρ）
   ④ 人同意：consent == True（或处于已授权的协作模式）
```
形式化保证：若 `d_min(t0) ≥ d_hard` 且 MSMP 成立，则 `∀t≥t0, d_min(t) ≥ d_hard`，且安全集的收缩是**单调可证**的。

**定义 178（时空-社会风险场 STRisk）** 在空间-时间格 `(x,t)` 上：
```
R(x,t) = w_kin·TTC(x,t)^{-1} + w_prox·φ((d(x,t)-d_min)/s) + w_aff·F_aff(a_h)
TTC(x,t) = min_i ‖x - p_i(t)‖ / max(ε, -(d/dt)‖x-p_i(t)‖)
F_aff = r·(1-τ) + ℓ·fear_indicator
```
风险场用于：(a) 生成 EEIS 的避障先验；(b) 在 CBF 不可行时选择“最小风险退让动作”（急停/后退/让行）。

**定义 179（情感-避障闭环算子 EACL 与信任动力学）** 
```
EACL: a_h → d_min, v_max, K_scale → (ACBF 避障) → 实际轨迹/交互 → 新观测 obs' → ASE → a_h'
信任更新：τ_{t+1} = clip( τ_t + α_s·success - β_v·violation - β_u·unexpected
                          + δ_e·explanation_effective , 0, 1 )
```
解释有效性 `explanation_effective` 由“解释后人的负向情感/干预行为是否下降”估计，仅在 `consent` 允许时启用。

**定义 180（情感接地对话策略 A-DMS）** 扩展第 61 轮 DMS：
- **状态增广**：`S⁺ = (H_diag, b_intent, C_exec, C_pending, U_mel, a_h, U_aff, τ_trust, turn_id)`
- **动作增广**：`A⁺ = A ∪ {explain(reason), reassure, request_consent, offer_distance_choice}`
- **触发规则**：
  ```
  if 避障导致任务偏差 > θ_dev and not 已解释:
      a = explain("为保持安全距离，我绕行/暂停了")
  elif a_h.fear > θ_fear:
      a = reassure + offer_distance_choice  # 让人选“近一点/远一点”
  elif 需用情感放松 d_min and not consent:
      a = request_consent("可以靠近一些吗？")
  elif a_h.urgency > θ_urg and 任务有时限:
      a = execute_with_minimal_explanation  # 先安全后解释
  ```
- **奖励增广**：`R⁺ = R - λ_fear·fear - λ_manip·manipulation_risk - λ_privacy·privacy_cost`
- **操纵风险**：`manipulation_risk = 利用 a_h 改变用户决策而非改善其安全的程度`（用“动作是否降低用户选项集”近似）

**定义 181（情感调制阻抗先验 AMP）** 在 MSPF 物理先验之上再乘情感调制：
```
K_p^aff = K_p^mel · (1 - η_v·(1-v)) · (1 - η_r·r)
K_d^aff = K_d^mel · (1 + ζ_r·r + ζ_τ·(1-τ))
v_max^aff = v_max · (1 - ν_r·r)
约束：K_p^aff ≥ K_p_min, K_d^aff ≤ K_d_max, v_max^aff ≥ v_min_safe
```
单调方向与直觉一致：恐惧/高唤醒→更软、更阻尼、更慢；且全部夹在硬限内。

**定义 182（情感-安全联合证书 J_aff）**
```
J_aff = ( J_sem_exec,
          a_h_posterior (μ_a, Σ_a), U_aff,
          d_hard, d_min_used, h_min = min_i h_i(x),
          CBF_feasible, risk_field_peak,
          τ_trust, consent_flag,
          explanation_id, msmp_version )
验证：Valid(J_aff) ⇔ Valid(J_sem_exec) ∧ h_min ≥ 0 ∧ CBF_feasible
        ∧ d_min_used ≥ d_hard ∧ (若放松则 consent ∧ U_aff ≤ ε)
        ∧ msmp_version 单调
```

**定义 183（情感/避障/隐私预算 PCE-aff）**
```
B_aff  = (freq_aff, modality_budget, σ_max, ε_ep, consent, retention_ttl)
B_avoid = (cbf_iters, pred_horizon, qp_feasibility_budget, risk_field_res)
```
- `B_aff` 耗尽 ⇒ 情感估计降级为“中性先验 + 最大不确定性” ⇒ `d_min` 自动取更保守值（`γ·σ_max`），**只收紧不放松**
- `B_avoid` 耗尽 ⇒ 降低预测时域/风险场分辨率；QP 不可行 ⇒ 走“最小风险退让”
- **隐私/伦理硬约束**：无 `consent` 不使用生理/面部模态；情感原始数据 TTL 到期即删；情感永不用于“说服用户接受更危险任务”

**定义 184（预测性社会避障 PSP）** 用 MEL 的轨迹预测 + 鲁棒管构造动态屏障：
```
p_i(t+Δ) ∈ Tube_i(Δ) = { p : ‖p - p̂_i(Δ)‖ ≤ β·σ_pred(Δ) + δ_model }
h_i^psp(x) = min_{p∈Tube_i(Δ)} ‖x - p‖ - d_min(a_h) - γ·σ_aff
```
在 `Δ ∈ [0, H_pred]` 上取最小值，保证对预测误差鲁棒；预测越不确定，管越粗、裕度越大。

**定义 185（情感漂移与重校准 ADR + 消融兜底）** 监测情感表征的协变量漂移：
```
D_aff = ‖μ_a - μ_a^ref‖_{Σ^{-1}} + |σ_aff - σ_aff^ref|
若 D_aff > τ_drift：触发重校准；若重校准失败或 U_aff 持续超阈：
    进入 affect-neutral 模式：忽略 a_h 的放松能力，仅保留“收紧”方向
```
这保证情感子系统失效时，系统**退化为第 61 轮的安全行为**（甚至更保守），而不是变得危险。

### IP-183 ASU（情感-语义统一表征空间，USR 扩展）

```python
class AffectiveSemanticUnification:
    def __init__(self, usr, d_aff=64):
        self.usr = usr
        self.d_aff = d_aff
        self.aff_encoder = AffectiveEncoder(d_aff)
        self.aff_projector = AffectiveProjector()  # -> (d_min, v_max, K_scale)
        self.ase = AffectiveStateEstimator()
        self.anchor = SharedMemoryAnchor(d_aff, name='aff_anchor')

    def update(self, V, voice, physio, dialogue, H_hist, consent):
        mu_a, Sigma_a, U_aff = self.ase.estimate(V, voice, physio, dialogue, H_hist)
        sigma_aff = float(np.sqrt(np.trace(Sigma_a)))
        aff_emb = self.aff_encoder(mu_a, U_aff)
        # 情感对齐：只做表征约束，不反向改变人的状态
        target = (0.4 * self.usr.scene_emb + 0.3 * self.usr.intent_emb
                  + 0.2 * self.usr.evidence_emb + 0.1 * aff_emb.detach())
        loss_aff = F.mse_loss(aff_emb, target.detach())
        d_min, v_max, K_scale = self.aff_projector(aff_emb, sigma_aff)
        # 安全投影：软裕度永远不小于硬下限
        d_min = max(d_min, self.hard_floor)
        anchor = AffAnchor(mu_a=mu_a, Sigma_a=Sigma_a, U_aff=U_aff,
                           affect_emb=aff_emb, d_min=float(d_min),
                           v_max=float(v_max), K_scale=float(K_scale),
                           consent=consent, version=self.anchor.next_version(),
                           ts=time.time())
        self.anchor.write_cas(anchor)
        return anchor, loss_aff
```

### IP-184 ASE（多模态情感估计）

```python
class AffectiveStateEstimator:
    def estimate(self, V, voice, physio, dialogue, H_hist):
        feats, avail = [], []
        if V is not None:      feats.append(self.enc_face(V));        avail.append('face')
        if voice is not None:  feats.append(self.enc_voice(voice));   avail.append('voice')
        if physio is not None and self.consent: feats.append(self.enc_physio(physio)); avail.append('physio')
        feats.append(self.enc_text(dialogue)); avail.append('text')
        z = self.fuse(feats)
        mu, logvar = self.head_dist(z)
        Sigma = torch.diag(torch.exp(logvar))
        U_al = float(logvar.mean())                       # 传感器噪声
        U_ep = self._epistemic(avail, z)                  # 模态缺失/分布外
        mu, Sigma = self._conformal_calibrate(mu, Sigma)  # 保证覆盖
        return mu, Sigma, (U_ep, U_al)
```

### IP-185 ACBF（情感调制控制屏障函数 QP）

```python
class AffectiveCBFController:
    def __init__(self, hard_floor=0.35, alpha=lambda h: 2.0 * h):
        self.hard_floor = hard_floor
        self.alpha = alpha

    def solve(self, x, u_nom, humans, aff_anchor, obstacles, dt):
        cons, h_min = [], np.inf
        for i, h in enumerate(humans):
            d = dist(x, h.pos)
            d_min = self._robust_margin(aff_anchor, i)          # 含 γ·σ_aff
            h_i = d - d_min
            h_min = min(h_min, h_i)
            # 动态障碍：预测位置下界
            if h.dynamic:
                d_pred = min(dist(x, p) for p in h.predicted_tube(dt))
                h_i = min(h_i, d_pred - d_min)
            # 硬层约束（与情感无关）
            h_hard = d - self.hard_floor
            cons.append(h_hard)
            cons.append(h_i + self.alpha(h_i) * dt)             # 离散 CBF
        u, feasible = solve_qp(u_nom, cons, u_min, u_max, dt)
        if not feasible:
            u = self.min_risk_retreat(x, humans, obstacles)     # 急停/后退/让行
        return u, dict(h_min=h_min, feasible=feasible,
                       d_min=self._robust_margin(aff_anchor, 0))

    def _robust_margin(self, aff_anchor, i):
        # 软裕度 + 不确定性膨胀；MSMP 保证放松受限
        return max(self.hard_floor, aff_anchor.d_min + 2.0 * aff_anchor.sigma_aff)
```

### IP-186 MSMP（单调安全裕度协议）

```python
class MonotoneSafetyMarginProtocol:
    def __init__(self, rho=0.02, tau_fresh=0.5, sigma_max=0.15):
        self.rho, self.tau_fresh, self.sigma_max = rho, tau_fresh, sigma_max
        self.prev_dmin = None
        self.last_ts = 0.0

    def admit(self, anchor, now):
        d_req = max(anchor.d_min, self.hard_floor)
        if self.prev_dmin is None:
            self.prev_dmin = d_req
            return d_req, 'init'
        dt = max(1e-3, now - self.last_ts)
        fresh = (now - anchor.ts) < self.tau_fresh
        confident = anchor.sigma_aff <= self.sigma_max and anchor.U_ep <= 0.3
        if d_req >= self.prev_dmin:
            # 收紧：立即生效，永不阻止
            self.prev_dmin = d_req; self.last_ts = now
            return d_req, 'tighten'
        # 放松：必须四条件同时成立，且斜率受限
        if fresh and confident and anchor.consent:
            d_new = max(d_req, self.prev_dmin - self.rho * dt)
            d_new = max(d_new, self.hard_floor)
            self.prev_dmin = d_new; self.last_ts = now
            return d_new, 'relax_admitted'
        # 不满足：保持原值（保守）
        self.prev_dmin = self.prev_dmin; self.last_ts = now
        return self.prev_dmin, 'relax_denied'
```

### IP-187 STRisk（时空-社会风险场）

```python
class SpatioTemporalRiskField:
    def __init__(self, w_kin=1.0, w_prox=0.5, w_aff=0.3, s=0.3):
        self.w_kin, self.w_prox, self.w_aff, self.s = w_kin, w_prox, w_aff, s

    def field(self, x, t, humans, d_min, aff):
        R = 0.0
        for h in humans:
            p = h.predict(t)
            v = h.velocity(t)
            rel = p - x
            d = np.linalg.norm(rel)
            closing = max(1e-3, -np.dot(v, rel) / max(d, 1e-6))
            ttc = d / closing
            R += self.w_kin / max(ttc, 1e-3)
            R += self.w_prox * np.exp(-((d - d_min) / self.s) ** 2)
        R += self.w_aff * (aff.r * (1 - aff.tau) + 0.5 * aff.load)
        return R

    def avoidance_prior(self, x, t, humans, d_min, aff):
        R = self.field(x, t, humans, d_min, aff)
        # 风险梯度作为 EEIS 避障先验方向
        grad = finite_difference(lambda y: self.field(y, t, humans, d_min, aff), x)
        return R, -grad / (np.linalg.norm(grad) + 1e-8)
```

```python
    def trust_update(self, success, violation, unexpected, explained):
```

```python
class AffectiveStateEstimator:
    def estimate(self, obs, dialogue, H_hist, consent):
        feats, avail = [self.enc_text(dialogue)], ['text']
        if obs.V is not None:                   feats.append(self.enc_face(obs.V)); avail.append('face')
        if obs.voice is not None:               feats.append(self.enc_voice(obs.voice)); avail.append('voice')
        if obs.physio is not None and consent:  feats.append(self.enc_physio(obs.physio)); avail.append('physio')
        z = self.fuse(feats)
        mu, logvar = self.head_dist(z)
        Sigma = torch.diag(torch.exp(logvar))
        U_al = float(logvar.mean())
        U_ep = self.epistemic(avail, z)         # 缺失模态/分布外
        mu, Sigma = self.conformal(mu, Sigma)   # 覆盖 >= 1-alpha
        return mu, Sigma, (U_ep, U_al)

    def neutral_prior(self):

        return mu, Sigma, (1.0, 1.0)            # 最大不确定 -> 最保守
```

```python
class AffectiveCBFController:
    def solve(self, x, u_nom, humans, obstacles, aff, dt, hard_floor=0.35):
        cons, h_min, d_min = [], np.inf, 0.0
        for h in humans:
            d = dist(x, h.pos)
            d_min = self.robust_margin(aff, hard_floor)       # 含 gamma*sigma_aff
            hi = d - d_min
            if h.dynamic:
                d_pred = min(dist(x, p) for p in h.tube(dt))
                hi = min(hi, d_pred - d_min)
            h_min = min(h_min, hi)
            cons += [d - hard_floor, hi + self.alpha(hi) * dt]  # 硬层 + 软层
        u, feasible = solve_qp(u_nom, cons, u_min, u_max, dt)
        if not feasible:

                       feasible=bool(feasible))
```

### IP-186 MSMP（单调安全裕度协议）

```python
class MonotoneSafetyMarginProtocol:
    def __init__(self, hard_floor=0.35, rho=0.02, tau_fresh=0.5, sigma_max=0.15):
        self.hard_floor, self.rho = hard_floor, rho
        self.tau_fresh, self.sigma_max = tau_fresh, sigma_max
        self.prev, self.last_ts = None, 0.0

    def admit(self, a, now):
        d_req = max(a.d_min, self.hard_floor)
        if self.prev is None:
            self.prev, self.last_ts = d_req, now
            return d_req, 'init'
        dt = max(1e-3, now - self.last_ts)
        if d_req >= self.prev:                          # 收紧：无条件
            self.prev, self.last_ts = d_req, now
            return d_req, 'tighten'
        fresh = (now - a.ts) < self.tau_fresh
        confident = a.sigma_aff <= self.sigma_max and a.U_aff[0] <= 0.3
        if fresh and confident and a.consent:           # 放松：四条件
            d_new = max(d_req, self.prev - self.rho * dt, self.hard_floor)
            self.prev, self.last_ts = d_new, now
            return d_new, 'relax_admitted'
        self.last_ts = now
        return self.prev, 'relax_denied'                # 保持保守
```

```python
            p, v = h.predict(t), h.velocity(t)
            rel, d = p - x, np.linalg.norm(p - x)
            closing = max(1e-3, -np.dot(v, rel) / max(d, 1e-6))
            R += self.w_kin / max(d / closing, 1e-3)
            R += self.w_prox * np.exp(-((d - d_min) / self.s) ** 2)
        R += self.w_aff * (a_h.r * (1 - a_h.tau) + 0.5 * a_h.load)
        return R

    def prior(self, x, t, humans, d_min, a_h):
        R = self.field(x, t, humans, d_min, a_h)
        g = finite_difference(lambda y: self.field(y, t, humans, d_min, a_h), x)
        return R, -g / (np.linalg.norm(g) + 1e-8)      # 风险下降方向
```

### IP-188 EACL（情感-避障闭环 + 信任动力学）

```python
class EmotionAwareAvoidanceLoop:
    def __init__(self, asu, acbf, msmp, dms, ertc, budget):
        self.asu, self.acbf, self.msmp = asu, acbf, msmp
        self.dms, self.ertc, self.budget = dms, ertc, budget
        self.trust = 0.5

    def semantic_step(self, obs, dialogue, H):
        a = self.asu.update(obs, dialogue, H, self.budget.consent, self.budget)
        d_min, why = self.msmp.admit(a, time.time())
        self.ertc.lock_soft_margin(d_min)              # 实时流只读
        if why == 'relax_denied' and a.consent:
            self.dms.request_consent(scope='soft_margin')
        return a, d_min, why

    def realtime_step(self, x, u_nom, humans, obstacles, a):
        u, info = self.acbf.solve(x, u_nom, humans, obstacles, a, dt=1e-3)
        self.ertc.dispatch(u)
        return u, info

    def trust_update(self, success, violation, unexpected, explained):
        self.trust = float(np.clip(
            self.trust + 0.1*success - 0.3*violation - 0.1*unexpected
            + 0.05*explained, 0.0, 1.0))
        return self.trust
```

```python
class AffectiveAvoidanceBudget:
    def __init__(self, freq=5, sigma_max=0.15, eps_ep=0.3,
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ASU | O(d_aff) | O(N_anchor·d_aff) | 软裕度 ≥ 硬下限；锚点 CAS 无撕裂 |
| ASE | ~10–50ms | ~200MB | conformal 覆盖 ≥ 1-α；缺模态抬升 U_ep |
| ACBF-QP | ~0.1–0.5ms（≤5 目标） | O(n_constraints) | 可行 ⇒ h_min ≥ 0；不可行 ⇒ 最小风险退让 |
| MSMP | O(1) | O(1) | 放松斜率受限；`d_min` 永不跌破 `d_hard` |
| STRisk | O(N_obs·H_pred) | O(N_obs·H_pred) | 预测越不确定 ⇒ 管越粗 ⇒ 裕度越大 |
| EACL | 语义流 10Hz / 实时流 1kHz | 共享内存 ~5MB | 情感失效 ⇒ 退化为第 61 轮安全行为 |
| PCE-aff | O(1) | O(1) | 预算耗尽只收紧；无同意禁用敏感模态 |

**正确性定理（Affective-Safety-Complete）**：
在 A61–A70 基础上新增：**(A71)** `C_hard` 由任务/法规固定，情感子系统无写权限；**(A72)** MSMP 四条件原子检查，且 `ρ·Δt < d_min - d_hard`；**(A73)** ACBF 的 class-κ 与离散化满足前向不变性，QP 不可行时最小风险退让有定义；**(A74)** ASE 的 conformal 校准在 ADR 覆盖下有效，`U_aff` 不低于真实误差的 `1-α` 分位；**(A75)** 情感锚点仅在 `consent=True` 时携带可用于放松的模态信息；**(A76)** STRisk 的预测管以概率 ≥ 1-β 覆盖真实轨迹。

则：
1. **情感安全不变性**：任意情感估计（含完全错误/对抗输入）下，`d_i ≥ d_hard` 与 `|F| ≤ F_hard` 恒成立；情感只能更保守。
2. **实时性隔离**：ACBF-QP 在实时流独立求解；情感锚点过期时 `d_min` 按 MSMP 只增不减，实时周期 ≤ 1ms。
3. **单调保守性**：`U_aff`↑ ⇒ `d_min`↑；模态缺失 ⇒ 更保守；情感子系统失效 ⇒ 等价第 61 轮安全行为。
4. **可协商共情**：用户可语言放松软裕度（受 MSMP+同意约束），但无法放松硬层；所有放松由 `J_aff` 审计。
5. **伦理可证**：无同意不用敏感模态；情感不得用于扩大风险或压缩用户选项集。
