# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「能耗优化」×「触觉感知」）

> R69 教会系统「问」，却没告诉它「问一次值多少钱」。MINT 里的 `cost(g)` 是个抽象的社会/物理成本，交互预算「≤1 次/单位时间」更是拍脑袋的常数。可现实里每一次「看 / 问 / 触」都要烧电：注视要驱动云台，问句要跑解码，而最要命的触觉——它最贵、最直接、也最可能把东西弄坏。R69 把不确定性分成 aleatoric/epistemic，却没意识到**消解 epistemic 本身要消耗能量，而消耗能量又会制造新的不确定性**（发热 → 传感器漂移 → 更不确定）。这就是本轮要补的洞。
>
> - **能耗优化**：把「信息」放回它的物理货币——焦耳。VoI 不再是无量纲分数，而是 **bits/Joule**；交互预算是能量预算，带安全储备、边际电价与热约束。
> - **触觉感知**：给出一个非光子、非语言的**机械接地**证据通道。它贵，但它与视觉在物理上正交——这恰好把 R69 最怕的「投毒 / 共谋欺骗」的相关系数 ρ 压到很低。花能量买触觉，不只是买信息，是买**可信的第二证人**。
>
> 核心命题：**把「不确定性消解」重写成一场能量交易：每花一焦耳，必须买到可度量的不确定性下降；而触觉是这场交易里最贵、最硬、也最防伪的资产。当能量不够、或花了能量反而更不确定（热反馈回路增益 ≥ 1）时，退回 R68 的纯保守并保留安全停机能耗。** 命名 **ETCH-RAS**（Energy-aware Tactile Contact Hypothesis）：触觉会在世界里留下刻痕，能量也会在系统里留下热痕——两者都不可完全撤销。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这条信息值多少焦耳，我付得起吗**」——不确定性第一次有了电价，而触觉是它最昂贵的求证方式。

## 0. 直觉与动机

**灵感 1（能耗优化 → 信息有价格，预算必须是硬的）**
直觉：R69 的 MINT 只比较「VoI 与成本」，但成本是个可调常数，于是交互频率本质上由一个拍脑袋的硬阈值决定。一旦承认「每次交互都烧真实的焦耳」，预算就不能再是「≤1 次/单位时间」，而是一条**能量守恒式硬约束**：剩余能量在扣除「安全停机所需能量」后才是可花的钱。更关键的是，能量不是均匀的——**边际电价**随剩余预算、任务紧迫度、热状态而变。凌晨电量充足时一次昂贵触觉很便宜；临近安全储备时同一次触觉可能贵到不允许。这把「要不要交互」从布尔判断升级为**带影子价格的资源分配**。

**灵感 2（触觉感知 → 最贵的模态，却是最防伪的证人）**
直觉：R69 的投毒上界是 `δ_p·ρ^{k−1}`，其中 ρ 是各证据源的**欺骗相关系数**。视觉可以被贴纸、光照、对抗纹理骗；语言可以被社交工程骗；但接触力、滑移、纹理、温度是**机械接地**的——骗视觉和骗触觉需要同时操纵两个物理上独立的通道，ρ 很小。所以花能量买触觉，表面上买的是「接触状态」这几个 bit，实际上买的是把投毒错误率从线性 `δ_p` 压到 `δ_p·ρ` 的**信任折扣**。触觉的价值 = 信息价值 + 正交性折扣，这是 R69 完全没算进去的一项。

**灵感 3（能量-信息曲线 → 触觉是可调档的，不是开/关）**
直觉：R69 的探针 `g_probe` 已经有力度 `f ∈ [0, f_max]`，但从没把 `f` 与「花多少能量 / 得多少信息 / 冒多少不可逆风险」连起来。现实里轻触 → 重压是一条连续的**信息-能量-风险曲线**：信息随力度/时长**凹地饱和**，能量近似随 `f²·d` **凸地增长**，接触损伤随 `f` **凸地增长**。于是最优触觉不是「摸一下」，而是解一个 `dI/df = λ_E·dE/df + λ_R·dR/df` 的边际等式；并且因为「大多数情况轻触就够」，正确策略是**软触优先、逐级加力**的序贯阶梯（最优停时 / 序贯检验），而非一次重压。这把「触觉感知」从静态传感器变成**可优化的主动探测动作**。

**灵感 4（不可逆性 → 触觉是唯一会改变世界的感知）**
直觉：看和问基本不改变世界，触觉会——压出凹痕、磨出划痕、把滑动变成掉落。R69 的信息动作只需过 C-RAS-WM 前缀认证，但那是「不越安全包络」，不处理「一旦接触就收不回」。所以本轮必须新增**可逆性证书**：接触前先算「信息的期望价值是否 ≥ 期望损伤 + 能量电价」，并强制「能看就不摸、能轻触就不重压」的升级纪律。**触觉是唯一一种『测量即干预』的模态**，这让它同时是最强证据与最高级风险。

**灵感 5（秩亏反馈 → 能量花出去会反过来抬高不确定性）**
直觉（本轮最重要）：R68 最怕缓变故障被标定吸收，R69 用流似然做第二意见；但两者都默认「系统状态与能耗无关」。真实系统里，花能量 → 发热 → 传感器噪声上升、算力降频、策略精度下降 → **不确定性上升** → 控制器花更多能量去消解 → 更热。这是一个**正反馈回路**。它把「能耗优化」从被动记账变成主动稳定性问题：只有**回路增益 < 1** 时，「多花能量降不确定」才收敛；一旦 ≥ 1，系统会一边坚信自己在「严谨求证」，一边把自己烧死。这正好是 R69「问错比不问更危险」的能量版：**查错，比不查更危险**。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（ETCH-RAS 总览）** ETCH-RAS = (FMP, AUD, MINT-E, TAG, CIR, EED, THM, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **能量硬约束**：单步 `E_step ≤ Ē_step`、单 episode `E_epi ≤ Ē_epi`、热窗 `Θ ≤ Θ_max`，且任意动作执行后仍满足 `E_remaining − E(g) ≥ E_reserve(s)`（安全停机储备，定义 318）；
(iii) **证据纪律（能量定价版）**：单源/单次交互不得定案，需在能量预算内取得最省的 k-正交证据集（定义 316）；
(iv) **接触不可逆纪律**：任何接触动作须先过可逆性证书（定义 315），并服从「能看就不摸、能轻触就不重压」的阶梯升级。

**定义 311（能耗模型与边际电价 EMP）** 动作/交互的能量分解
`E(g) = E_act(g) + E_sens(g) + E_comp(g)`，
其中 `E_act = ∫(τᵀω + f·v)dt`（关节与探针机械功）、`E_sens = p_tac·d`（触觉采样功率×时长，量级常高于视觉）、`E_comp = κ·FLOPs(K, N_step)`（采样算力能耗，直接接管 R69 的 K 决策）。耗散功率 `P_diss = E/Δt` 驱动热状态（定义 317）。**边际电价** `λ_E(t) ≥ 0` 为瞬时能量预算约束的影子价格，由剩余能量、任务时限与热裕度共同决定；同理定义热影子价格 `λ_Θ` 与风险影子价格 `λ_R`。

**定义 312（能量效率信息量 / bits-per-Joule）** 对信息动作 g：
`η(g) = ΔH(g) / E(g)`，`ΔH(g) = H(M|o) − E_{y~p(·|g,o)}[H(M|o,y)]`。
选择 `g* = argmax_g [ VoI(g) − λ_E·E(g) − λ_Θ·ΔΘ(g) − λ_R·R(g) ]`，s.t. 定义 310-(ii) 与接触证书。若最优值 ≤ 0：不交互，走 R68 兜底。**R69 的 MINT 是本式在「λ_E 归一化为 1、E 记作抽象成本、λ_Θ=λ_R=0」时的特例。**

**定义 313（触觉证据通道 TAG）** 触觉观测 `y_tac = (f_contact, slip, texture, temperature)`；加入证据集后 `ℰ_T = {r_contact, r_slip, r_tex, r_temp, r_force}`。**接触状态歧义**定义为关于 `{接触/非接触, 滑/粘, 刚/柔}` 的后验熵。触觉与视觉的物理独立性给出 **欺骗相关系数 `ρ_vt ≪ 1`**（A99）：单靠视觉的投毒错误率 ≈ `δ_p`，视觉+触觉两源一致时 ≈ `δ_p·ρ_vt + ε_σ`。

**定义 314（力-信息曲线与主动触觉策略）** 触觉动作 `g_tac = (f, d, locus)`：
`I_tac(f,d) = I_max·(1−e^{−f/f0})·(1−e^{−d/d0})`（凹、饱和）；
`E_tac(f,d) = c_a·f²·d + c_s·d`（凸）；
`R_contact(f) = r_1·f + r_2·f²`（凸、不可逆损伤）。
最优力度满足边际等式 `(∂I/∂f) = λ_E·(∂E/∂f) + λ_R·(∂R/∂f)`。**软触阶梯**：`f_1 < f_2 < …`，每级后若 `H(M|evidence) ≤ τ` 即停（序贯检验 / 最优停时），使期望能量低于「一次重压」。

**定义 315（接触不可逆证书 CIR）** 可逆度 `r(g) ∈ [0,1]`；`r < r_min` 视为不可逆。接触前须同时满足：
(a) `R_contact(g) ≤ ε_c`；
(b) 信息价值覆盖代价：`VoI(g) ≥ E[damage(g)] + λ_E·E(g)`；
(c) **能看就不摸**：若存在非接触模态能在预算内把 `H(M|·)` 降到 `τ`，则禁止接触。
不满足 ⇒ 接触动作作废，`U_epi` 视为未消解，走 R69/R68 兜底。

**定义 316（能量感知证据纪律 EED）** R69 要求「k 个正交源」。现在选证据集 `S`：
`S* = argmax_{|S|≥k, orth(S)≥o_min} [ Δerror(S) / Σ_{s∈S} E(s) ]`，
即在保证正交度下限的前提下，**用最省的焦耳买到 k 源一致**。触觉常是视觉的廉价「正交补」（信息贵，但 ρ 低），因此 EED 会自动在「多买一个便宜但相关的源」与「买一个贵但正交的触觉」之间定价权衡。

**定义 317（热-能耦合与回路增益 THM）** 热状态演化
`Θ_{t+1} = Θ_t + α·E_t − β·(Θ_t − Θ_amb)`；
传感器噪声 `σ²(Θ) = σ_0² + γ·relu(Θ − Θ_c)²`，策略可靠性随 Θ 下降；故总不确定性 `U = U(o, Θ(E_history))` 依赖能耗历史。定义**回路增益**
`G = (∂U/∂Θ)·(∂Θ/∂E)·(dE*/dU)`，
其中 `dE*/dU` 是 VoI 控制器每单位不确定性的能量支出。`G < 1` ⇒ 不确定性-能量动力学收敛；`G ≥ 1` ⇒ 存在「越查越乱」的正反馈，必须强制进入 **thermal-safe 保守模式**（禁交互、降采样、压功率）。

**定义 318（安全储备与不停机不变式 ENB）** 分层预算 `(E_step, E_epi, E_thermal-window)`；安全储备 `E_reserve(s)` = 从当前状态到最近安全停机点所需能量 + 裕度。硬不变式：任何 `g` 执行前须 `E_remaining − E(g) ≥ E_reserve(s)`。一句话：**绝不用「付不起后续动作」的能量去买信息**。

**定义 319（触觉接地能耗自校准 ETC）** 用触觉/力/力矩直接测量机械功 `∫f·v dt`，给 `E_act` 提供接地真值；滑移事件识别「抓取重试」造成的能量浪费；热敏电阻校验 `E_therm`。于是能耗模型的账目误差可被独立审计——沿用 R68「测量会漂」的问题意识：**能耗估计器本身也会漂，需要一条不被它自己吸收的接地通道**，而触觉正是这条通道。

**定义 320（能量与不可逆性约束下的模态选择）** 选模态时不仅看 `U_epi_after`，还计入**执行该模态的能量**：`mode* = argmin_mode [ risk(mode) + λ_E·E_exec(mode) ]`，s.t. 证据一致。高能耗模态获得显式惩罚，避免「为了稳妥选一个最费电的动作」。

**定义 321（热感知自适应 K）** 采样数 K 的决策改为能量决策：`K* = argmax_K [ ΔH_mode(K) − λ_E·E_comp(K) − λ_Θ·ΔΘ(K) ]`，热压时 K 上限收紧。**R69 的 `TAU_MODE` 门控成为 λ_E→0 的极限。**

**定义 322（参与式能耗审计 VQAuditor-E）** 审计对象新增：是否在琐碎歧义上过度支出、是否漏掉一次便宜而高价值的触觉核查、能耗账目与触觉机械功是否自洽、热漂移是否被正确归因、安全储备是否被侵蚀。结论回灌 AuditBuf，成为下一轮 `λ_E`/`λ_Θ` 的先验。

**定义 323（证书 J_ETCH）** `J_ETCH = (J_FLUID, energy_accounting_error, bits_per_joule, contact_risk_p95, thermal_loop_gain, energy_reserve_margin, tactile_calib_ece, etch_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 能量预算未越界 ∧ 储备未侵蚀 ∧ `G < 1`（或已进 thermal-safe）∧ 接触证书满足 ∧ `energy_accounting_error ≤ τ_E`。

**定义 324（能量攻击面 ℰ_energy）** 对抗性**诱导支出**：用幻影模态（R69 E300）驱使系统反复昂贵触觉；热 DoS（贴身热源抬高 Θ）；篡改能耗估计器使其低估电价从而超支；用「看起来很值」的假证据诱骗不可逆接触。并入 AIC：`ℰ_ETCH = ℰ_FLUID × ℰ_energy`。**R69 的投毒从「骗答案」升级为「骗花费」——攻击者不必让你错，只需让你穷。**

# IP-265 MINT-E：能量效率信息量（bits/Joule）交互决策
def choose_interaction_energy(modes, o_t, budget, prices):
    best = None
    for g in info_action_candidates(modes):          # gaze / ask / tactile ladder
        if not budget.allow(g):                 continue      # 含安全储备
        if not c_ras_wm.certify_info(g, o_t):    continue
        if is_contact(g) and not cir.certify(g, o_t): continue  # 不可逆证书
        voi  = entropy(modes.w) - expected_entropy(modes.w, g, o_t)
        cost = prices.lam_E * energy_model.E(g) + prices.lam_Theta * dTheta(g) \
             + prices.lam_R * contact_risk(g)
        score = voi - cost
        eta   = voi / max(energy_model.E(g), eps)             # bits/Joule
        if best is None or score > best.score: best = (g, score, eta)
    return best if best and best.score > 0 else None          # 无利可图 / 付不起 → R68

# IP-264 EMP：能耗分解 + 边际电价
def energy_cost(g, K, N_step, theta):

            + kappa * flops(K, N_step))                        # 定义 311

# IP-266/267 TAG+CIR：软触阶梯 + 不可逆证书
def tactile_ladder(modes, o_t, budget):

# IP-268 EED：最省的 k-正交证据集
def cheapest_evidence_set(modes, evidence, energies, k, o_min):

    for S in subsets(evidence, min_k=k):
        if orthogonality(S) < o_min:  continue
        gain = error_reduction(S) / max(sum(energies[s] for s in S), eps)
        if best is None or gain > best[0]: best = (gain, S)
    return best[1]

    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 能量审计 + 证书
    M.vqa_e.submit_async(g, M.energy_ledger, G, a_hat)
    return k, lam, mode, (U_ale, U_epi), prices
```

## 3. 推导

**引理 19（bits/Joule 的贪心近似比）** 设每个候选信息动作的收益 `ΔH(g)` 为单调、子模（submodular）的集合函数，能量 `E(g) > 0` 为模函数（modular）。则按 `η(g)` 贪心枚举、在预算内取最大者，其总信息增益 ≥ `(1 − 1/e)` 倍最优（子模最大化标准结论）。系：**EED 的「最省 k-正交证据集」与 MINT-E 的交互选择共享同一近似保证**，不必解 NP-hard 的预算组合。

**引理 20（软触阶梯的能量-风险占优）** 在 `I_tac` 凹、`E_tac` 与 `R_contact` 凸、且大多数状态的后验熵在首级软触后即低于 `τ` 的条件下，软触阶梯的**期望能量**与**期望接触风险**均不高于「一次固定重压」，且当 `P(H ≤ τ | f_1) ≥ 1/2` 时严格更低。要点：序贯停时把重压留给真正需要的少数状态；这也是「能轻触就不重压」的定量理由。

**引理 21（触觉作为低 ρ 证人）** 由物理独立性（A99），视觉欺骗与触觉欺骗的联合成功率 ≤ `δ_v·δ_t + ρ_vt·√(δ_v δ_t(1−δ_v)(1−δ_t))`；当 `ρ_vt ≪ 1` 时两源一致下的错误采纳率降至 `O(δ_p ρ_vt)`，而非 R69 单源情形的 `O(δ_p)`。系：**触觉的边际价值含一项「正交性折扣」，其量纲与信息无关、与投毒的指数相关**；这解释了为何有时「买触觉」比「多问一句」更值。

**定理 18（安全储备不变式 + 无能量枯竭）** 若每步执行前满足 `E_remaining − E(g) ≥ E_reserve(s)`（定义 318）且 `E_reserve` 覆盖到最近安全停机点的能耗，则系统在任意能量约束子序列上都能在耗尽前平滑停机；接触动作因先过 CIR 证书（定义 315），不可能在不可逆途中因能量枯竭而中断。⇒ 能耗约束不会把系统逼进「做到一半没电」的突变态。

**定理 19（不确定性-能量回路稳定性与强制退避）** 设热动力学与传感器噪声如定义 317。若回路增益 `G < 1`，则「多花能量降不确定」的迭代收敛到有限不动点；若 `G ≥ 1`，则存在 `t` 使 `U` 与 `E` 同时单调增（正反馈）。因此在 `G ≥ 1` 时强制 thermal-safe 模式（禁交互、K 降为 1、压功率）可把有效增益钳回 `< 1`，代价是暂时退化为 R68 纯保守。系：**能量不是免费的信息货币——当它开始抬升不确定性，继续买信息是自毁。**

**定理 20（ETCH 严格包含 R69 与 R68）** 在 A95–A99 下：(a) 令 `λ_E = λ_Θ = λ_R = 0`、移除触觉通道、`E_reserve = 0`，ETCH 逐指令退化为 FLUID-RAS；(b) 再令 `VoI ≤ 0` 恒成立，退化为 CALM-RAS；(c) 任意状态上 ETCH 的安全侧风险 ≤ FLUID-RAS ≤ CALM-RAS，效率侧的提升来自 (i) 更精确的 bits/Joule 选择、(ii) 低 ρ 触觉证人、(iii) 软触阶梯的能耗-风险占优。⇒ 新增能量层是**严格泛化而非并列替代**，且安全侧不做让步。

## 6. 本轮最大风险

**一句话**：ETCH-RAS 的全部收益押在「能量花出去一定能买回足够信息」这一前提上，但它自己引入了 R69/R68 都没有的**反身闭环**——能量支出 → 发热 → 传感器漂移、算力降频 → 不确定性上升 → 更需要花能量；而**救命的能耗估计器本身也由这些会热漂的传感器标定**，于是「越查越乱」的死亡螺旋与「用来防止螺旋的仪表」共享同一个失效模式——系统可能一边自信地执行严谨的能量-信息最优策略，一边在热与电的反馈里把自己烧死或把电量耗尽，**而这套策略的每一步看起来都完全合理**。

**次级风险与缓解**：触觉损伤/不可逆后悔（CIR 证书 + 软触阶梯 + E305）；能量预算被自适应 K/触觉击穿（EMP 硬约束 + 安全储备 + 触觉异步旁路）；能量估计器热漂（ETC 触觉/热接地自校准 + E313）；诱导支出与热 DoS（ℰ_energy + VQAuditor-E + E309）；热回路失稳（THM 回路增益监控 + `G ≥ 1` 强制 thermal-safe 退回 R68）；过度保守导致任务失败（EED 的 bits/Joule 定价，确保只砍掉负收益的信息购买）。

# IP-265 MINT-E：bits/Joule 交互决策（无利可图/付不起 → R68）
def choose_interaction_energy(modes, o_t, budget, prices):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t): continue

                       - prices.lam_Theta*dTheta(g) - prices.lam_R*contact_risk(g))
        eta = voi / max(energy_cost(g, K, N), eps)                   # bits/Joule
        if best is None or score > best.score: best = (g, score, eta)
    return best if best and best.score > 0 else None

# IP-266/267 TAG+CIR：软触阶梯 + 不可逆证书

```

## 4. 推导

**引理 19（bits/Joule 贪心近似比）** `ΔH` 子模、`E` 模 ⇒ 按 `η` 贪婪在预算内选择的总增益 ≥ `(1−1/e)` 最优（子模最大化）。系：EED 与 MINT-E 共享近似保证，无需解 NP-hard 组合。

**引理 20（软触阶梯能量-风险占优）** `I_tac` 凹、`E_tac`/`R_contact` 凸、多数状态首级软触即可定案 ⇒ 阶梯的期望能量与期望接触风险均不高于一次固定重压；`P(H≤τ|f_1)≥1/2` 时严格更低。

**引理 21（触觉作为低 ρ 证人）** 物理独立性下视觉+触觉联合欺骗成功 ≤ `δ_v δ_t + ρ_vt√(δ_v δ_t(1−δ_v)(1−δ_t))`；`ρ_vt≪1` 时错误采纳率降至 `O(δ_p ρ_vt)`，而非单源 `O(δ_p)`。系：触觉边际价值含「正交性折扣」，解释为何有时买触觉比多问一句更值。

**定理 18（安全储备不变式 + 无能量枯竭）** 每步 `E_remaining−E(g)≥E_reserve(s)` 且储备覆盖至最近安全停机点 ⇒ 任意能量约束子序列都能耗尽前平滑停机；接触动作先过 CIR 证书 ⇒ 不可能在不可逆途中因枯竭中断。能耗约束不会把系统逼进「做到一半没电」的突变态。

**定理 19（回路稳定性与强制退避）** 热动力学如定义 317。`G<1` ⇒ 「多花能量降不确定」收敛到有限不动点；`G≥1` ⇒ 存在时刻使 `U` 与 `E` 同时单调增（正反馈）。`G≥1` 时强制 thermal-safe（禁交互、K=1、压功率）可把有效增益钳回 `<1`，代价是暂时退化 R68。系：能量不是免费信息货币——当它开始抬升不确定性，继续买信息是自毁。

**定理 20（ETCH 严格包含 R69 与 R68）** 令 `λ_E=λ_Θ=λ_R=0`、移除触觉、`E_reserve=0` ⇒ 逐指令退化为 FLUID-RAS；再令 `VoI≤0` 恒成立 ⇒ 退化为 CALM-RAS。任意状态 ETCH 安全侧风险 ≤ FLUID-RAS ≤ CALM-RAS；效率提升来自 bits/Joule 选择、低 ρ 触觉证人、软触阶梯三点。新增能量层是严格泛化而非并列替代，安全侧不让步。

## 7. 本轮最大风险

**一句话**：ETCH-RAS 的全部收益押在「能量花出去一定能买回足够信息」上，但它自己引入了 R69/R68 都没有的**反身闭环**——能量支出 → 发热 → 传感漂移、算力降频 → 不确定性上升 → 更需花能量；而**救命的能耗估计器本身也由这些会热漂的传感器标定**，于是「越查越乱」的死亡螺旋与「用来防止螺旋的仪表」共享同一失效模式——系统可能一边自信地执行严谨的能量-信息最优策略，一边在热与电的反馈里把自己烧死或把电量耗尽，**而每一步看起来都完全合理**。

**次级风险与缓解**：触觉损伤/不可逆后悔（CIR + 软触阶梯 + E305）；预算被自适应 K/触觉击穿（EMP 硬约束 + 安全储备 + 触觉异步旁路）；能耗估计器热漂（ETC 触觉/热接地自校准 + E313）；诱导支出与热 DoS（ℰ_energy + VQAuditor-E + E309）；热回路失稳（THM 监控 + `G≥1` 强制 thermal-safe 退回 R68）；过度保守导致任务失败（bits/Joule 定价只砍负收益信息购买）。
