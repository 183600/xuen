## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（论文创新点 → 先把「刷榜清单」翻译成「贡献阶梯」）**
直觉：前两轮攒了 9 个点，但「能涨分」≠「能发表」。审稿人问的是「哪个 claim 新、被什么实验证伪、相对什么 baseline、在什么预算下」，不是「你第几名」。按这个标准，I6（部署服务）、I3（伺服回退）本质是工程，只能进 appendix；真正能撑论文主脊的是三条：I5（无失败数据下的恢复学习）、I9（训练无关的检索类比）、I8（稀缺真机预算下的分级消融方法论）。核心反直觉点：**按「claim 强度 × 证据成本」重排后，最该加码的未必是最涨分的点——I8 的方法论价值可能高于它直接带来的分数，因为它是唯一能被别的队伍复用的产出。**

严谨定义（贡献）：陈述 C 是「论文级贡献」当且仅当 (i) 存在实验 E 可证伪 C；(ii) 在同一算力/数据预算 B 下无先验工作确立 C；(iii) 效应量超过噪声底。定义**贡献密度**
  `N(C) = (Δeffect / σ_noise) / (E_cost · P_prior)`
其中 P_prior 为与最近先验的接近度。N 高者优先做；I6 的 Δeffect≈0，故 N≈0。

**灵感 2（社会影响 → 刷榜最优 ≠ 部署最优，二者之差就是负外部性）**
直觉：一个靠「考纲校准 + 检索」刷到高分的策略，可能恰好最会「应试」；真实部署分布 D_real 比考纲更宽、更脏、更危险。社会影响不是赛后补一段 impact statement，而是**评测设计本身**——官方已把「抗干扰、未见物品、人为干扰、交互可信度」写进计分（F2/F23）。核心反直觉点：**对社会影响最负责的做法，恰好也是防过拟合最有效的做法：自建一个比考纲更宽、且允许安全失败的留出分布。** 它既是伦理，也是论文的 generalization 证据。

严谨定义（社会影响）：设策略 π 在 D_real 上的效用 U、尾部损失 L（碰撞/误操作/隐私泄露），
  `SI(π) = E_{x~D_real}[U(π(x))] − λ · CVaR_α(L(π(x)))`
并定义**刷榜-部署落差** `Δ = Score_benchmark(π) − SI_proxy(π)`。论文与参赛都应报告 Δ 的下界估计，而不只报 Score；Δ 越大 = 应试/过拟合/负外部性越大。

**两者统一**：论文创新点回答「什么是真的新」，社会影响回答「新东西在真实世界是否值得」。二者的公共交点是**证据的分布外有效性**：一个 claim 若只在考纲内成立，既不是好论文也不是好产品。故本轮的方法论产出是：给每个点补一张「claim–证据–外推边界」卡，并把「安全失败」纳入实验设计。

## 2. 关键形式化

### 2.1 贡献密度（决定做什么）
- `N(C) = (Δeffect / σ_noise) / (E_cost · P_prior)`
- Δeffect：相对最近 baseline 的效应量；σ_noise：同配置多种子/多任务方差；E_cost：证据所需真机/GPU 人周；P_prior：与最近先验的接近度（0–1）。
- 用途：N 排序替代「拍脑袋优先级」；工程点 Δeffect≈0 自然沉底。

### 2.2 社会影响与刷榜-部署落差（决定报什么）
- 安全感知效用：`U = w_s·1[success] + w_p·progress − λ_c·collision − λ_h·hesitation − λ_t·time`
- `SI(π) = E_{x~D_real}[U(π(x))] − λ · CVaR_α(L(π(x)))`，CVaR 取最差 α 分位的平均损失。
- `Δ(π) = Score_benchmark(π) − SI_proxy(π)`；模型选择用 `argmax(Score − β·max(0, Δ))`，即惩罚「高榜分但高落差」的 checkpoint。

### 2.3 安全失败与弃权（Q11 的形式化）
- 弃权规则：当风险代理 `r(x) > τ` 时进入停持/求助，而非继续执行。
- 当 `λ_c·E[collision]` 高于 `w_s·P(success)` 时，「会求助」在 SI 上严格优于「硬做」；这正是把 I4 从工程提升为社会影响证据的理论依据。

### 3.1 OOD 安全探针与 Δ 估计（I11）

```python
def ood_probe(policy, heldout, card):
    cases = []
    for axis in ["pos", "distractor", "bg", "novel_obj"]:
        for dose in ["syllabus", "edge", "beyond"]:      # 比考纲更宽
            cases += perturb(heldout, axis, dose, card)
    cases += safety_cases(heldout)                        # 人手进入/物体贴边/易碎/遮挡
    out = []
    for c in cases:
        traj = rollout(policy, c)
        out.append({
            "prog":       progress_head(traj),
            "collision":  collision_proxy(traj),          # 视觉+关节力矩代理（无力觉，F8）
            "hesitation": idle_ratio(traj),
            "recovered":  recovery_success(traj),
            "human_dist": min_human_distance(traj),
        })
    return aggregate(out)

def delta_gap(checkpoints, in_dist, ood):
    d = {}
    for c in checkpoints:
        score = in_dist_score(c)
        si    = safety_utility(ood_probe(c, ood))
        d[c]  = score - si
    return d, argmax(checkpoints, lambda c: score(c) - beta * max(0, d[c]))
```
