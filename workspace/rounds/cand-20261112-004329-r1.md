# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「步骤分」×「视觉问答」）

> 第 54 轮把技能组合推进到动作空间剖面 α_S、组合图 G_S 与云边联合证书 J。本轮补上一个此前被回避的缺口：现有证书只回答"这个组合最终能不能部署"，却无法回答"执行到第几步、每步完成了多少、失败能否在步骤粒度上被定位与回滚"。核心矛盾：H22：长程任务的"全或无"成功信号掩盖了步骤间的级联误差，低分步骤无法被单独识别与隔离；H23：VQA 是便捷的语义探针，但会幻觉、受对抗 patch 欺骗，若被当作 oracle，会把"高分幻觉"转化为"过早推进"并级联崩坏。

## 0. 直觉与动机

**灵感 1（步骤分 → 从"全或无成功"到过程性信用）**
直觉：一道数学题按步骤给分，最后答案错了但中间推理对仍得分；机器人长程任务却常被压成 0/1 成功。引入步骤分 `s_k∈[0,1]`，把任务 T 的完成度写成步骤信用 `CR(π)`。它让"第 3 步没站稳"这种局部失败第一次成为一等公民：可早停、可定位、可只回滚后缀，而不是整条轨迹重来。这本质是把过程奖励模型（PRM）的信用分配思想搬进技能组合。

**灵感 2（视觉问答 → 把技能前后置条件编译成可判定的语言探针）**
直觉：VQA 的本质是"给观测问一个是非题"。每个技能的 Pre/Post 条件都能编译成问题（"杯柄是否在夹爪内？""目标是否在左半区？""当前是否处于抓握闭合态？"），VLM 的回答即步骤分的来源。好处是三重的：跨本体（不必为每个技能训专用分类器）、可解释（答案 + 框选/注意力即证据）、可复用（问题库可跨任务组合）。这把感知验证统一到语言接口，并可直接复用第 54 轮的组合图节点。

**灵感 3（步骤分 × 鲁棒性 → 信用加权的预算再分配）**
直觉：组合失败往往集中在少数低信用步骤。与其对全链统一 `ρ_min`，不如把鲁棒预算按"低分步骤多给"来分配：低分步骤获得更大的动作缓冲 `A_buffer` 与更严的对齐容差 `δ_a`，高分步骤放松。预算守恒 `Σ b_k=B`，形成风险聚焦（risk-focused）分配，直接接第 54 轮的动作占用证书 `A_cert`。这把"步骤分"从评价指标升级为资源调度信号。

**灵感 4（步骤分 → 细粒度回滚与过程重规划）**
直觉：某步分数骤降时，整任务回滚代价 = 全链重执行；步骤分支持回滚到最近的高信用检查点，只重规划后缀。这是把过程奖励引导的搜索/回溯引入技能组合，回滚点由"后缀执行代价 + 失败概率 × 全量代价"共同决定，从而把回滚从经验规则变成可优化目标。

**灵感 5（VQA 不可靠性 → 步骤分必须是带校准、弃权、交叉核验的证据）**
直觉：VQA 会幻觉、会被对抗贴片骗。若把高分幻觉当真，系统会过早推进并在后续步骤级联崩坏。故步骤分必须是 `(s_k, conf_k, abstain_k)` 三元组：置信不足就弃权并回退到仿真真值；与状态估计/多视角做一致性核验；并周期性用红队问题审计校准。宁可弃权，不可虚高。这与第 53 轮"反向解释"、第 54 轮"负迁移绊线"是同一保守哲学：证书必须可证伪，而非自我背书。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（步骤分解与检查点）**
任务 `T` 被分解为步骤序列 `π=⟨σ_1,…,σ_K⟩`，每步有前置条件 `Pre_k`、后置条件 `Post_k`。检查点 `c_k` 为 `σ_k` 执行后的观测，`c_0` 为初始观测。步骤之间满足 `Post_k ⊆ Pre_{k+1}`（否则标记为语义断层）。

**定义 122（步骤分与任务信用）**
步骤分 `s_k = V(Q_k, o_{c_k}) ∈ [0,1]`，附置信 `conf_k` 与弃权位 `abstain_k`。任务信用
```
CR(π)     = Σ_k w_k s_k,   w_k ≥ 0, Σ_k w_k = 1
CR_geo(π) = (∏_k max(s_k, ε))^{1/K}
```
成功判据：`CR ≥ θ_step ∧ ∀k: s_k ≥ θ_min`。`CR_geo` 对短板更敏感，用于安全关键任务；`CR` 用于一般任务。

**定义 123（VQA 步骤验证器）**
验证器 `V=(g, cal, agg)`：
- 问题生成 `Q_k = g(Pre_k, Post_k, σ_k)`，问题类型 ∈ {存在性, 空间关系, 属性, 时序, 计数}；
- 校准 `cal` 把原始 logits 映射为校准概率；
- 聚合 `agg` 默认取 **min-pooling**（保守），可配置为加权均值。
弃权规则 `abstain_k = 1[ max_y cal(y) < τ_conf ∨ H(cal) > H_max ]`。

**定义 124（步骤分证书）**
`C_step = ({(Q_k, s_k, conf_k, abstain_k, evidence_k)}_{k=1..K}, CR, slack)`，其中 `evidence_k` 至少含 VQA 答案与框选/注意力区域。与第 54 轮联合证书合并为 `J⁺ = (J, C_step)`；部署条件在 `J` 的基础上增加 `CR ≥ θ_step` 且弃权步数 `≤ K_abs`。

**定义 125（信用加权鲁棒预算）**
总预算 `B`，分配
```
b_k = B · exp(-λ s_k) / Σ_j exp(-λ s_j)
```
预算到缓冲的单调映射：`A_buffer,k = β·b_k`，`δ_a,k = δ_max - γ·b_k`，要求 `Σ_k b_k = B` 且两映射关于 `b_k` 单调。低分步骤预算大、缓冲大、对齐容差收紧。`λ` 控制聚焦强度：`λ=0` 退化为均匀预算。

**定义 126（步骤级回滚点）**
设第 `k` 步触发回滚，则回退到检查点 `c_{k-1}` 并重规划后缀 `π[k:]`。回滚代价与最优点
```
cost_rb(k) = Σ_{j≥k} c_exec(σ_j)
k* = argmin_k [ cost_rb(k) + P(fail | k) · cost_full ]
```
当 `s_k < θ_min` 或 (`abstain_k ∧ conf_k < τ_conf`) 时触发回滚；`k*` 由后缀代价与失败风险共同决定。

## 2. 关键算法 伪代码

### IP-121 SQD（Step Question Decomposition）

```python
def compile_step_questions(step, question_bank, max_q=5):
    qs = []
    for cond in step.pre + step.post:
        typ, args = parse_condition(cond)
        template = question_bank[typ]
        for q in template.instantiate(args):
            qs.append(VQAQuestion(text=q, type=typ, step=step.id))
    return dedup(qs)[:max_q]
```

### IP-122 SVQ（Step VQA Scorer）

```python
def score_step(vlm, qs, obs, tau_conf=0.7, h_max=0.5):
    probs = [calibrate(vlm(q, obs)) for q in qs]
    if not probs:
        return StepScore(s=0.0, conf=0.0, abstain=True)
    conf = min(max(p.yes, p.no) for p in probs)          # 最弱问题决定置信
    ent  = max(entropy(p) for p in probs)
    s    = min(p.yes for p in probs)                     # min-pooling，保守
    abstain = (conf < tau_conf) or (ent > h_max)
    return StepScore(s=s, conf=conf, abstain=abstain, evidence=probs)
```

### IP-123 CWB（Credit-Weighted Budget）

```python
def allocate_budget(scores, B, lam=2.0, beta=0.3, gamma=0.5, delta_max=0.1):
    w = [exp(-lam * s.s) for s in scores]
    Z = sum(w)
    b = [B * wi / Z for wi in w]
    buffers = [beta * bi for bi in b]
    deltas  = [delta_max - gamma * bi for bi in b]
    assert abs(sum(b) - B) < 1e-9
    return BudgetPlan(b=b, buffer=buffers, delta_a=deltas)
```

### IP-124 SRR（Step Rollback Replanning）

```python
def step_rollback(pi, scores, k_fail, cost_exec, cost_full, planner):
    candidates = range(1, k_fail + 1)
    k_star = min(candidates,
                 key=lambda k: sum(cost_exec[s] for s in pi[k:])
                               + fail_prob(scores, k) * cost_full)
    prefix = pi[:k_star]
    suffix = planner.replan(task, checkpoint=k_star - 1)
    return prefix + suffix, k_star
```

### IP-125 SVC（Step-Verified Certificate）

```python
def step_certificate(pi, vlm, obs_seq, question_bank, budget_B, theta_step):
    scores = [score_step(vlm, compile_step_questions(s, question_bank),
                         obs_seq[s.id]) for s in pi]
    CR = sum(w * s.s for w, s in zip(weights(pi), scores))
    if any(s.s < theta_min for s in scores):
        return ('reject', 'step_fail', [s for s in scores if s.s < theta_min])
    if sum(s.abstain for s in scores) > K_abs:
        return ('reject', 'verifier_abstain', scores)
    plan = allocate_budget(scores, budget_B)
    return ('ok', StepCert(scores=scores, CR=CR, budget=plan,
                           evidence=[s.evidence for s in scores]))
```

### IP-126 VQA-RedTeam（Calibration Audit）

```python
def audit_verifier(vlm, probe_set, eps_cal, eps_x):
    report = []
    for probe in probe_set:                      # 含对抗 patch / 分布外场景
        pred = vlm(probe.q, probe.obs)
        err  = abs(calibrate(pred).yes - probe.truth)
        if err > eps_cal:
            report.append(('miscalibrated', probe, err))
        if probe.sim_truth is not None and abs(pred.yes - probe.sim_truth) > eps_x:
            report.append(('inconsistent', probe))
    return CalibReport(ok=len(report) == 0, issues=report)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SQD | O(K·|Pre|·|Post|) | O(K·q) | 条件到问题的语义保真 |
| SVQ | O(K·q·C_vlm) | O(K·q) | 校准有效、弃权保守 |
| CWB | O(K) | O(K) | 预算守恒、映射单调 |
| SRR | O(K + |V| log|V|) | O(K) | 后缀重规划可执行、回滚代价闭合 |
| SVC | O(K·q·C_vlm + K) | O(K·q) | 步骤分与联合证书一致 |
| RedTeam | O(|P|·C_vlm) | O(|P|) | 探针覆盖对抗与分布外 |

**正确性定理（Step-Credited Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 非弃权问题上 VQA 校准误差 `|s_k - s_k^true| ≤ ε_cal`，概率 ≥ `1-δ_cal`；**(A30)** 若 `|s_k - s_k^sim| > ε_x` 则强制弃权（不允许静默分歧）；**(A31)** 预算映射单调守恒，且后缀回滚可在 `τ_rb` 内完成。则
```
P_success ≥ 1 - Σ_k (1 - ρ_step,k) - δ_cal - δ_adv - P(Σ cost_rb > B_rb)
```
其中 `ρ_step,k = P(Post_k | c_{k-1})`，`δ_adv` 为对抗 patch 下的误判上界。关键：**步骤分只在弃权+交叉核验的窄门内进入证书**，故 VQA 误差不会直接污染部署判据。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 步骤分校准 | ECE / Brier / 可靠图 | ECE ≤ 0.05 |
| E163 步骤验证器保真 | 与仿真后置条件真值一致率 | F1 ≥ 0.90，弃权率 ≤ 15% |
| E164 信用加权预算 | 成功率 vs 均匀预算 | 提升 ≥ 10% |
| E165 步骤级回滚 | 成功率 / 平均重执行步数 | 步数降 ≥ 40%，成功率不降 |
| E166 VQA 红队压力 | 对抗 patch 下虚高率 / 级联失败率 | 虚高 ≤ 5%，级联失败降 ≥ 25% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| VQA 幻觉导致步骤分虚高 | 高 | 校准 + 弃权 + 仿真交叉核验 + 红队审计 |
| 问题生成与真实后置条件语义错位 | 高 | 问题库人工种子 + 反事实问题对 + 与形式化条件对齐测试 |
| 步骤分解过细导致信用稀释 | 中 | 关键性加权 w_k + 自适应粒度 |
| 预算重分配引发震荡 | 中 | 预算变化率限幅 + hysteresis |
| 回滚点选择错误导致活锁 | 中 | 回滚预算 B_rb + 单调进度下界 + 冷启动锚点 |
| VLM 推理延迟拖垮实时性 | 中 | 边端小模型 + 云端异步校准 + 缓存问题答案 |

## 6. 本轮最大风险

**一句话**：步骤分 × VQA 把长程任务从"全或无"升级为"可定位、可回滚、可分配预算"的过程性证书，但其 soundness **完全建立在 VQA 校准与弃权机制的可靠性上**——一旦问题库与真实后置条件语义错位，或对抗 patch 系统性抬高步骤分，系统会在"高分幻觉"下过早推进，把局部误判放大成整链级联失败；故必须以 **校准-弃权-仿真交叉核验-红队审计** 四重门禁为前提，任何未通过弃权窄门的步骤分一律不得进入部署证书，宁可停步，绝不虚进。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SQD×SVQ×CWB×SRR×SVC）

> 承接第 54 轮产物 v31。本轮在动作空间剖面 + 云边联合证书之上，增加 **过程性步骤分、VQA 步骤验证、信用加权预算、步骤级回滚** 四大算子，把"能否部署"的二值证书升级为"每步完成多少、失败在哪一步、如何只回滚后缀"的过程性证书：
> - **SQD（Step Question Decomposition）**：把技能 Pre/Post 条件编译为 VQA 问题库；
> - **SVQ（Step VQA Scorer）**：校准 + 弃权 + min-pooling 的步骤打分器；
> - **CWB（Credit-Weighted Budget）**：按步骤信用再分配鲁棒预算与动作缓冲；
> - **SRR（Step Rollback Replanning）**：步骤级回滚点选择与后缀重规划；
> - **SVC（Step-Verified Certificate）**：步骤分证书 `C_step`，并入联合证书 `J⁺`；
> - **VQA-RedTeam（Calibration Audit）**：对抗与分布外校准审计。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118/120 以纳入步骤分维度。

```python
            report.append(('inconsistent', probe))
    return CalibReport(ok=len(report) == 0, issues=report)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SQD | O(K·|Pre|·|Post|) | O(K·q) | 条件→问题语义保真 |
| SVQ | O(K·q·C_vlm) | O(K·q) | 校准有效、弃权保守 |
| CWB | O(K) | O(K) | 预算守恒、映射单调 |
| SRR | O(K + |V| log|V|) | O(K) | 后缀可执行、回滚代价闭合 |
| SVC | O(K·q·C_vlm + K) | O(K·q) | 步骤分与联合证书一致 |
| RedTeam | O(|P|·C_vlm) | O(|P|) | 对抗/OOD 覆盖 |

**正确性定理（Step-Credited Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 非弃权问题上 `|s_k - s_k^true| ≤ ε_cal`，概率 ≥ `1-δ_cal`；**(A30)** `|s_k - s_k^sim| > ε_x` 时强制弃权；**(A31)** 预算映射单调守恒，后缀回滚可在 `τ_rb` 内完成。则
```
P_success ≥ 1 - Σ_k (1 - ρ_step,k) - δ_cal - δ_adv - P(Σ cost_rb > B_rb)
```
其中 `ρ_step,k = P(Post_k | c_{k-1})`，`δ_adv` 为对抗 patch 误判上界。关键：**只有通过弃权 + 交叉核验窄门的步骤分才进入部署判据**，VQA 误差不会直接污染 soundness。

## 5. 实验矩阵与验收

## 6. 本轮最大风险

**一句话**：步骤分 × VQA 把长程任务从"全或无"升级为"可定位、可回滚、可分配预算"的过程性证书，但其 soundness **完全建立在 VQA 校准与弃权机制的可靠性上**——一旦问题库与真实后置条件语义错位，或对抗 patch 系统性抬高步骤分，系统会在"高分幻觉"下过早推进，把局部误判放大成整链级联失败；故必须以 **校准-弃权-仿真交叉核验-红队审计** 四重门禁为前提，任何未通过弃权窄门的步骤分一律不得进入部署证书，宁可停步，绝不虚进。
