# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「鲁棒性」×「视觉-语言-动作模型」）

> R69 把不确定性一分为二（aleatoric / epistemic），并用「证据纪律」把「问」变成可审计的动作。但它有一个未言明的前提：**策略看到的世界，是它以为的那个世界**。VLA 的典型失败恰恰打破这个前提——机器人不是「不知道」，而是**自信地看错、自信地听错、自信地做错**：被背景里的高显著干扰物吸走（视觉捷径），把「不要拿红杯子」parse 成一袋词（语言捷径），在同一张图换光/换背景后行为崩溃（分布偏移）。这类错误在 R68 看来残差≈0、在 R69 看来模态≈单峰——**两套不确定性机制都测不到它**，甚至 R69 会拿一次「追问」为这个错信念盖章。
>
> 本轮两个灵感补上第三块：
> - **鲁棒性**给出判别准则——不是「模型有多确信」，而是「当语义不变时它是否不变、当语义改变时它是否改变」这个**双侧剖面**；
> - **视觉-语言-动作模型**给出变换的载体——视觉（光照/背景/视角/遮挡）、语言（复述/否定/组合）、动作（坐标系/本体）三通道各有明确的**语义保持群**与**语义改变群**。
>
> 核心命题：**不确定性有第三个来源——表征/捷径不确定性 U_rep；它既不能被「慢下来」（aleatoric）吸收，也不能被「问一句」（epistemic）消解，只能被「不变性/敏感性双侧检验 + 群边缘化重接地」处理。U_rep 不是与 R68/R69 并列，而是它们的前置门：鲁棒性未认证的信念，禁止交互。** 命名 **TRUSS-RAS**（Test-time Robustness Under Semantic Shifts）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看到的这件事，真的是这件事吗**」——在问别人之前，先确认自己有没有看错。

## 0. 直觉与动机

**灵感 1（鲁棒性 → 自信的错误是一种独立故障类）**
直觉：R68 的 λ_floor 与 R69 的 VoI 都建立在「不确定性可观测」上——残差高、模态散，系统才知道要小心。但捷径行为是**低不确定性的高置信错误**：图像背景里有一只显眼的手，模型就伸手；指令里出现「红」，模型就去抓最近的红物而不看动词。它的残差小、模态尖，因此 R68 不会收紧、R69 不会追问。这不是「噪声」也不是「歧义」，而是**表征把因果特征替换成了相关特征**。记为 U_rep（representational / shortcut uncertainty）。关键洞察：**U_rep 不能靠「观测更多同类数据」降低，只能靠「改变不该改变的东西，看它是否还不变」来暴露。**

**灵感 2（VLA → 鲁棒性是双侧剖面，不是单侧抗扰）**
直觉：抗扰研究常只测一侧——对抗鲁棒测「扰动下是否稳定」（不变性），泛化测「分布外是否还准」（敏感性的一种）。VLA 需要**同时**满足两个方向相反的要求：
- 对**语义保持**变换（换光、换背景、复述、换同义说法、相机微动）→ 必须**不变**；
- 对**语义改变**变换（换物体身份、改空间关系、加否定、改数量/颜色词）→ 必须**敏感且方向正确**。
只满足前者会得到「什么都不看」的退化策略（把所有指令都执行成同一动作，Inv 满分但 Sen=0）；只满足后者会得到「什么扰动都反应」的脆弱策略。**鲁棒 = 正确的等价类划分**，而不是「任何输入都一样」。这把鲁棒性从「抗扰指标」升级为「语义等价关系是否被模型正确实现」。

**灵感 3（双侧检验 → 无标签的可证伪信号）**
直觉：语义保持/改变本该人工标注，代价高且主观。但 VLA 有天然的对偶结构：**配对反事实**——同一场景两种光照（应不变）、同一场景两个指令（应改变）、同一指令两个物体（应改变）。这些配对可以**在测试时自监督生成**，无需任务标签。于是 Inv/Sen 成为一个和 R69 流似然同样「无标签的第二意见」，但测的是完全不同的东西：流似然测**行为自洽**，不变性测**语义接地是否成立**。两者正交，可交叉验证。

**灵感 4（前置门 → 正面堵住 R69 的最大风险）**
直觉：R69 自陈的最大风险是「问错比不问更危险」——主动交互会把「诚实的不知道」升级成「被证实的错误」。R70 的回答不是再加一个事后审计，而是**把鲁棒性检验放在交互之前**：若当前信念未通过不变性认证（U_rep 高），则 MINT 被禁用。因为此时间多少问题都没用——你问的是「该拿红杯子还是蓝杯子」，可你根本没看清哪个是红杯子；追问只会把错误前提固化。于是三层阶梯清晰起来：aleatoric→慢下来（R68）；epistemic→问（R69）；representational→**先别看错，重接地或失败安全（R70）**。

**灵感 5（认证的相对性 → 元鲁棒监视）**
直觉：不变性只能相对于一个**有限的变换群**去认证。人类选定的 𝒢 之外，永远有没想到的漂移（新材质、新口音、新组合）。所以「鲁棒证书」永远带一个**覆盖度**字段，并且需要一个**元鲁棒哨兵**：当测试输入的低层统计落在 𝒢 覆盖范围之外时，**主动给证书降级**，退到最保守层。承认「认证的边界就是想象的边界」，比假装全局鲁棒更诚实，也更安全。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（TRUSS-RAS 总览）** TRUSS-RAS = (SIG, CIT, RCG, UQ3, GRP, MRS, RAS-WM‡)。三不变式（继承 R68/R69 并新增一条）：
(i) 实时流零学习写操作（继承 R68 定义 276-i）；
(ii) 交互预算与证据纪律（继承 R69 定义 293-ii/iii）；
(iii) **鲁棒前置门**：任何交互或高风险动作前，当前决策必须通过不变性认证（U_rep ≤ τ_rep）；未通过 ⇒ 禁止交互，只能重接地或失败安全。

**定义 311（语义变换群与等价类）** 设任务语义等价关系 ~ 定义在观测-指令对 (o,ℓ) 上。变换群 𝒢 = 𝒢_sem ∪ 𝒢_alt：
- g ∈ 𝒢_sem ⇒ g·(o,ℓ) ~ (o,ℓ)（语义保持：视觉换光/换背景/视角微扰/中性纹理；语言复述/语序/礼貌化；动作坐标系重参数化）；
- g ∈ 𝒢_alt ⇒ g·(o,ℓ) ≁ (o,ℓ) 但 ‖g·(o,ℓ) − (o,ℓ)‖ 小（语义改变且分布接近：物体身份/空间关系/颜色数量/否定；视觉中遮挡目标/替换干扰物）。
𝒢 的**覆盖度** cov(𝒢) = P(测试漂移落在 span(𝒢) 内)，由定义 321 估计。

**定义 312（VLA 三通道鲁棒性）** 视觉通道 ρ_v、语言通道 ρ_l、动作/本体通道 ρ_a；每个通道各自有变换子群 𝒢^{(c)}。鲁棒性剖面 R_π(o,ℓ) = (Inv_π, Sen_π) ∈ [0,1]²，按通道给出三元组。

**定义 313（不变性/敏感性分数）** 
Inv_π(o,ℓ) = 1 − E_{g~𝒢_sem}[ d_a(π(·|g·(o,ℓ)), π(·|o,ℓ)) ]，
Sen_π(o,ℓ) = E_{g~𝒢_alt}[ d_a(π(·|g·(o,ℓ)), π(·|o,ℓ)) ]，
其中 d_a 是**任务效应距离**（动作导致的状态/后果距离，经 R67 的 VISTA 世界模型前推并归一化），不是原始动作 L2——因为语义不同的动作可能在参数空间很小、后果很大（否定一个词就反向了）。

**定义 314（表征/捷径不确定性 U_rep）** 
U_rep = max( 1 − Inv_π/τ_inv , 1 − Sen_π/τ_sen , RCE/τ_rce , 0 )，
两种失败模式：**脆弱型**（Inv 低：语义保持下行为漂移）、**退化/捷径型**（Sen 低：语义改变下行为不变，说明模型没在用该语义通道）。U_rep 不进入 λ_floor，也不进入 VoI（定义 315）。

**定义 315（三方不确定性诊断树）** 输入 (U_ale, U_epi, U_rep) 与证据纪律，按序判定：
1. U_rep > τ_rep → **REGROUND**（禁止交互，见定义 322）；
2. 否则 U_epi > τ_epi 且 A95 可分 → **INTERACT**（R69）；
3. 否则 → **CONSERVATIVE**（R68 的 λ_floor）。
该树是有序门控：前一层的否定短路后一层，保证错误信念不会流入交互。

**定义 316（反事实不变性检验 CIT）** 对当前决策采样 G_test ⊂ 𝒢_sem（m 个）、G_alt ⊂ 𝒢_alt（n 个），估计 Inv/Sen 并给出置信下界（Hoeffding / 自助法）：Inv_LB = Inv̂ − √(log(1/δ)/2m)，Sen_LB 同。同时做**理由不变性**检验：证据归因（R68 的 ℰ 五元组 Top-k 支撑、注意力图）在 𝒢_sem 下的一致率 Rat。任一置信下界低于阈值 ⇒ 未认证。

**定义 317（鲁棒性校准误差 RCE）** 在留出配对集上把 Inv/Sen 预测分箱，RCE = Σ_b (|B_b|/N)|acc_b − conf_b|（类比 ECE，但对象是「不变性类别」而非分类置信）。RCE > τ_rce ⇒ 证书降级（不是「稍微不鲁棒」，而是「连自己鲁不鲁棒都判不准」）。

**定义 318（群边缘化与最坏情况策略 GRP）**
- 性能侧：π_G(a|o,ℓ) = ∫_{𝒢_sem} π(a|g·(o,ℓ)) dμ(g)（测试时增强共识，群平均收缩到不变子空间）；
- 安全侧：π_wc 只在所有 g ∈ G_test 下都安全的动作集合中选，A_safe^rob = ⋂_{g} A_safe(g·o)。
REGROUND 用 π_G 提供候选、用 π_wc 兜底。

**定义 319（鲁棒安全认证 RAS-WM‡）** 把 R68/R69 的前缀认证从单点推广到群邻域：前缀 A[:k] 鲁棒认证 ⇔ 对所有 g ∈ G_test，C-RAS-WM 判定安全包络均不越界。给出**认证鲁棒半径** ρ = sup{ r : ∀‖δ‖ ≤ r（语义度量下）认证仍成立 }。

**定义 320（鲁棒证书 J_TRUSS）** J_TRUSS = (J_FLUID, Inv_LB, Sen_LB, Rat, RCE, cov(𝒢), ρ, n_test, reground_log_hash, truss_ver)。Valid ⇔ Valid(J_FLUID) ∧ (U_rep ≤ τ_rep ∨ REGROUND 成功) ∧ RCE ≤ τ_rce ∧ cov ≥ cov_min。

**定义 321（覆盖度与元鲁棒哨兵 MRS）** cov(𝒢) 用密度比/变换类型分类器估计：给定测试漂移方向，估计它是否落在 𝒢 的支撑内。若低层统计（光照、模糊、口音、词表外词）落在 span(𝒢)^c，MRS 触发**证书降级**：τ_rep 收紧、禁用 INTERACT、退 REGROUND/保守。

**定义 322（重接地 REGROUND）** U_rep 高时的动作集合（与 R69 的消歧交互不同，这里的动作是**修复表征**而非**消除世界歧义**）：
(a) **语言重解析**：对 ℓ 做受控复述/去否定/指代消解，看 Sen 是否恢复（区分「没听懂」与「没看到」）；
(b) **视觉重注视**：把注视强制移到指令所指实体（而非显著物），重算 Inv/Sen；
(c) **群边缘化共识**：用 π_G 得到不变动作；
(d) **失败安全停机**：以上都失败则停/求援。
REGROUND 成功的判据是**新的观测-指令对通过 CIT**，此时才允许回到 R69 的 INTERACT。

**定义 323（鲁棒-交互次序不变式）** U_rep > τ_rep ⇒ MINT.choose_interaction 返回 None 且不可绕过。这从机制上消除 R69 的「确认错误」事件——没有不变性认证，就没有追问资格。

**定义 324（捷径对抗集 ℰ_shortcut）** 指令消融（删掉关键动词，看行为是否不变 ⇒ 语言捷径）、干扰物注入（无关高显著物）、否定-复述对（「不要红」vs「要蓝」）、纹理-身份置换（把 A 的纹理贴到 B 上）、遮挡关键实体。并入 AIC：ℰ_TRUSS = ℰ_FLUID × ℰ_shortcut。

**定义 325（退化包含性）** U_rep ≡ 0（通过全部变换）时，诊断树只剩分支 2/3 ⇒ TRUSS 逐指令等于 FLUID（R69）；再令 VoI ≤ 成本 ⇒ 等于 CALM（R68）。故 R68 ⊂ R69 ⊂ R70 为严格阶梯，安全侧单调不减。

## 2. 关键算法骨架

```python
# IP-264 SIG：语义变换群采样器（视觉 / 语言 / 动作三通道）
class SemanticGroup:
    VIS_SEM  = [relight, background_swap, view_jitter, neutral_texture]
    VIS_ALT  = [object_swap, distractor_inject, occlude_target]
    LANG_SEM = [paraphrase, reorder, politeness]
    LANG_ALT = [negate, swap_object_word, change_number_color]

    def all_sem(self): return self.VIS_SEM + self.LANG_SEM
    def all_alt(self): return self.VIS_ALT + self.LANG_ALT

# IP-265 CIT：双侧不变性/敏感性检验（含置信下界与理由不变性）
def invariance_test(policy, o, l, G, m, n, delta):
    a0  = policy.act(o, l)
    inv = 1 - mean(effect_dist(a0, policy.act(*g), via='vista')
                   for g in G.sample_sem(o, l, m))
    sen = mean(effect_dist(a0, policy.act(*g), via='vista')
               for g in G.sample_alt(o, l, n))
    inv_lb = inv - sqrt(log(1/delta) / (2*m))
    sen_lb = sen - sqrt(log(1/delta) / (2*n))
    rat    = rationale_consistency(policy, o, l, G.sample_sem(o, l, m))
    return inv_lb, sen_lb, rat

# IP-266 RCG：鲁棒前置门（未认证即禁用交互）
def robustness_gate(policy, o, l, G, rce, cov, tau):
    inv_lb, sen_lb, rat = invariance_test(policy, o, l, G, tau.m, tau.n, tau.delta)
    U_rep = max(1 - inv_lb/tau.inv, 1 - sen_lb/tau.sen, rce/tau.rce, 0.0)
    if cov < tau.cov:  U_rep = max(U_rep, tau.rep)      # MRS 证书降级
    return U_rep, (inv_lb, sen_lb, rat)

# IP-268 GRP / IP-272 REGROUND：重接地（先修表征，再谈交互）
def regroup(policy, o, l, G, budget):
    for step in [reparse_language, reattend_referent, group_marginalize]:
        if not budget.allow(step): continue
        o2, l2 = step(o, l)
        if robustness_gate(policy, o2, l2, G, ...)[0] <= TAU_REP:
            return o2, l2, 'regrounded'
    return None, None, 'fail_safe'                      # π_wc 兜底 / 停机

# IP-274 主闭环：R68 + R69 + 前置鲁棒门
def TRUSS_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, r_res = M.cof.step(...)
    # 0) 廉价捷径哨兵：语言消融小头 + 归因熵，仅可疑时跑完整 CIT
    if M.sentry.suspicious(o, l, z):
        U_rep, (inv, sen, rat) = M.rcg.gate(M.policy, o, l, M.G, M.rce, M.mrs.cov(o))
    else:
        U_rep, (inv, sen, rat) = 0.0, (1.0, 1.0, 1.0)
    # 1) 三分歧诊断树：鲁棒未认证 → 重接地 / 失败安全
    if U_rep > TAU_REP:
        o, l, status = M.reground(M.policy, o, l, M.G, M.budget)
        if status != 'regrounded':
            return M.fail_safe(o, U_cal, r_res)         # 定义 322(d)
        U_rep, (inv, sen, rat) = M.rcg.gate(...)
    # 2) 通过鲁棒门后才允许 R69 的消歧交互
    samples = M.fmp.sample(o, 1 if M.fmp.mode_head(z) < TAU_MODE else 4)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_rep <= TAU_REP and U_epi > TAU_EPI) else None)   # 定义 323
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 3) 鲁棒前缀认证：群邻域内都安全（RAS-WM‡）
    A = M.ach.propose(x_prime, H=M.vista.H)
    k, rho = M.c_ras_wm.robust_certified_prefix(A, M.G.test_set(), wm_preds)
    # 4) 风险缩放：未消解 epistemic 走 R68 兜底
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 5) 参与式审计：新增鲁棒证据
    M.vqa.submit_async(g, U_rep, inv, sen, rat, rho)
    return k, lam, mode, (U_ale, U_epi, U_rep)
```

## 3. 推导

**引理 19（捷径静默性）** 设捷径决策 d_s 由非因果特征 f_sp 决定，其 aleatoric 与 epistemic 分数与正确决策不可区分（A99：残差与模态熵对因果/非因果特征不敏感）。则 R68 的 λ_floor 检出率 ≤ ε_ale，R69 的 VoI 触发率 ≤ ε_epi。故捷径误差对两套机制**统计不可见**，必须引入一条与行为分布正交的通道（不变性），否则漏检率下界不随样本量下降。系：**置信不是鲁棒性的证据，恰恰可能是捷径的伪装。**

**引理 20（群边缘化的不变性增益）** 设 π 在 𝒢_sem 下的不变性误差为 δ。群平均 π_G 的不变性误差 ≤ δ；当 𝒢_sem 为紧群、μ 为其 Haar 测度时 π_G 落在不变子空间，误差为 0（理想情形），有限采样 m 下误差 ≤ δ·√(1/m) + 采样项。系：REGROUND 的 group_marginalize 是**有方向的不变性修复**，不是盲目平滑。

**引理 21（认证差距）** 鲁棒证书只对 g ∈ span(𝒢_test) 成立；对 g* ∉ span(𝒢)，存在对抗输入使策略在该方向上失败而证书仍 Valid。形式化：任何仅基于有限群 𝒢 的证书，其保证集 ⊆ span(𝒢)，且 |保证集|/|漂移空间| ≤ cov(𝒢)。**认证的上界就是群的覆盖**，无法用更多样本突破，只能扩群或降级。

**定理 18（TRUSS 严格包含 FLUID 并封锁其最坏失败）** 在 A99–A101 下：
(i) 任意状态 (o,ℓ)，TRUSS 的期望风险 ≤ FLUID ≤ CALM；
(ii) U_rep ≡ 0 时 TRUSS 与 FLUID 逐指令相同（定义 325）；
(iii) 在捷径状态集 S_short 上，FLUID 的「确认错误」事件概率 ≥ p_confirm > 0，而 TRUSS 通过定义 323 使其概率 = 0（代价是 REGROUND 开销与可能的失败安全停机）。故 R70 不是 R69 的补充，而是它的**安全包络**。

**定理 19（鲁棒认证的安全与无突变）** 在群邻域内做前缀认证（定义 319），任一 g ∈ G_test 下动作均不越安全包络 ⇒ 实际执行风险 ≤ ε_int；REGROUND/失败安全切换若按 π_wc 的字典序保守选择（先安全后性能）并沿用 R68 提交不变式，则控制连续、无突变。

## 6. 本轮最大风险

**一句话**：TRUSS-RAS 的全部保证都相对于人手选定的语义变换群 𝒢 —— 若真实漂移发生在 𝒢 之外，或 𝒢 错误地把一次真语义改变当成「保持」，不变性认证就会给出**虚假的鲁棒**，系统带着盖了章的错信念继续执行或交互；**认证的边界就是想象的边界，想不到的漂移永远不会被拒**（引理 21）。

**次级风险与缓解**：
1. **语义等价关系本身有争议**（复述可能改意图、换纹理可能改身份）→ 𝒢 的标注走「配对反事实 + 人工仲裁」双轨，RCE 越界即降级；
2. **CIT 采样开销击穿实时性** → 廉价捷径哨兵门控 + 异步预认证 + m=n=4 的小样本置信下界；
3. **群边缘化把动作平滑成「都不像」** → 安全侧用 π_wc 交集而非平均，性能侧才用 π_G，且 Rat 不达标即拒；
4. **理由不变性被注意力伪影欺骗** → 归因需与行为双向一致（行为变但归因不变 ⇒ 仍判捷径）；
5. **重接地死循环/交互疲劳** → 重接地步数硬上限、失败即降级停机，绝不无限重试。

```python
class SemanticGroup:

    VIS_ALT  = [object_swap, distractor_inject, occlude_target]
    LANG_SEM = [paraphrase, reorder, politeness]

    def all_alt(self): return self.VIS_ALT + self.LANG_ALT

# IP-265 CIT：双侧检验 + 置信下界 + 理由不变性
def invariance_test(policy, o, l, G, m, n, delta):
    a0  = policy.act(o, l)
    inv = 1 - mean(effect_dist(a0, policy.act(*g), via='vista') for g in G.sem(o,l,m))
    sen = mean(effect_dist(a0, policy.act(*g), via='vista') for g in G.alt(o,l,n))
    inv_lb = inv - sqrt(log(1/delta)/(2*m)); sen_lb = sen - sqrt(log(1/delta)/(2*n))
    rat = rationale_consistency(policy, o, l, G.sem(o,l,m))
    return inv_lb, sen_lb, rat

# IP-266 RCG：鲁棒前置门
def robustness_gate(policy, o, l, G, rce, cov, tau):
    inv_lb, sen_lb, rat = invariance_test(policy, o, l, G, tau.m, tau.n, tau.delta)
    U_rep = max(1 - inv_lb/tau.inv, 1 - sen_lb/tau.sen, rce/tau.rce, 0.0)
    if cov < tau.cov: U_rep = max(U_rep, tau.rep)          # MRS 降级
    return U_rep, (inv_lb, sen_lb, rat)

# IP-272 REGROUND：先修表征，再谈交互
def reground(policy, o, l, G, budget):
    for step in [reparse_language, reattend_referent, group_marginalize]:
        if not budget.allow(step): continue
        o2, l2 = step(o, l)
        if robustness_gate(policy, o2, l2, G, ...)[0] <= TAU_REP:
            return o2, l2, 'regrounded'
    return None, None, 'fail_safe'
```

## 4. 推导

**引理 19（捷径静默性）** 捷径决策由非因果特征主导，其残差与模态熵与正确决策不可区分（A99）⇒ R68 的 λ_floor 检出率 ≤ ε_ale、R69 的 VoI 触发率 ≤ ε_epi。故捷径误差对两套机制统计不可见，必须引入正交的不变性通道；漏检下界不随样本量下降。系：**置信不是鲁棒性的证据，反而常是捷径的伪装。**

**引理 20（群边缘化不变性增益）** π 在 𝒢_sem 下误差为 δ，则 π_G 误差 ≤ δ；紧群 + Haar 测度下 π_G 落在不变子空间（误差 0）；有限采样 m 下误差 ≤ δ·√(1/m) + 采样项。系：group_marginalize 是有方向的不变性修复，不是盲目平滑。

**引理 21（认证差距）** 鲁棒证书只对 g ∈ span(𝒢_test) 成立；对 g* ∉ span(𝒢) 存在使策略失败而证书仍 Valid 的输入。且任何有限群证书保证集 ⊆ span(𝒢)，|保证集|/|漂移空间| ≤ cov(𝒢)——**认证上界就是群的覆盖**，加样本无法突破，只能扩群或降级。

**定理 18（TRUSS 严格包含 FLUID 并封锁其最坏失败）** A99–A101 下：
(i) 任意状态风险 TRUSS ≤ FLUID ≤ CALM；
(ii) `U_rep≡0` 时 TRUSS 与 FLUID 逐指令相同（定义 325）；
(iii) 在捷径状态集 S_short 上 FLUID 的「确认错误」概率 ≥ p_confirm > 0，而 TRUSS 经定义 323 使其 = 0（代价为重接地开销与可能停机）。故 R70 是 R69 的**安全包络**，不是并列补充。

**定理 19（鲁棒认证安全与无突变）** 群邻域前缀认证（定义 319）⇒ 任一 g∈G_test 下动作不越安全包络，风险 ≤ ε_int；REGROUND/失败安全按 π_wc 字典序（先安全后性能）切换并沿用 R68 提交不变式 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：TRUSS-RAS 的全部保证都相对于人手选定的语义变换群 𝒢 —— 若真实漂移发生在 𝒢 之外，或 𝒢 把一次真语义改变误标为「保持」，不变性认证会给出**虚假的鲁棒**，系统带着盖了章的错信念继续执行或交互；**认证的边界就是想象的边界，想不到的漂移永远不会被拒**（引理 21）。

**次级风险与缓解**：语义等价关系有争议（配对反事实 + 人工仲裁双轨，RCE 越界降级）；CIT 开销击穿实时（捷径哨兵门控 + 异步预认证 + 小样本置信下界）；群边缘化把动作平滑成「都不像」（安全侧 π_wc 交集、性能侧 π_G，Rat 不达标即拒）；理由不变性被注意力伪影欺骗（行为变而归因不变仍判捷径）；重接地死循环（步数硬上限，失败即失败安全停机）。
