# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「场景泛化」×「创新点」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把闭环从「执行层→证据层」推进到「认知驱动的场景-执行闭环」。但**三个更深的局限**在本轮灵感下暴露出来：
> 1. **闭集场景假设是硬伤**：SSM 的 Z_scene 是 10 个手工枚举场景，π_scene(K|z) 是每场景一张查表先验、ϕ_intent 五条规则也全人工写死。真实部署必然遇到**未枚举的属性组合**（湿滑大理石斜坡、粗糙织物+金属混合桌面）；闭集分类器会把新场景塞进最近邻类别并给出高置信度，导致 K_safe 提前收敛到错误值——这是比「意图误判」更隐蔽的失败：**模型在分布外安静而自信地错**。
> 2. **「泛化=更多场景」是组合爆炸的错觉**：靠加场景、做域随机化永远追不上物理属性组合数；更关键的是第 60 轮**没有任何「我的能力边界在哪」的度量**，无法回答「这个新场景我到底该不该相信自己的先验」。
> 3. **创新点没有被形式化**：第 60 轮是多个模块的增量堆叠，容易被审稿人判为「模块拼接」。本轮必须给出一个**单一、可证伪、可评测**的核心创新，而不是再增加一个闭环名字。

## 0. 直觉与动机

**灵感 1（场景泛化 → 场景不是类别，是物理属性的组合 CASF）**
直觉：场景标签是**枚举**的，物理属性是**可组合**的。一个「湿滑大理石斜坡」可能从未在训练集出现，但它的摩擦 μ、刚度 κ、粗糙度 ρ、坡度 θ 每一个都单独见过。色彩不需要枚举「所有颜色」，只需三个基色组合；场景泛化同理——把场景从 z∈{桌面, 楼梯, …} 改写为属性向量 φ=(μ, κ, ρ, θ, δ, ν)，阻抗是共享函数 K=g(φ) 而非每场景查表。关键洞见：**泛化的对象应是属性轴上的插值/外推，而不是场景身份上的最近邻**。

**灵感 2（场景泛化 → 可加阻抗映射 SCG：轴覆盖⇒组合覆盖）**
直觉：若真实阻抗近似可加 K=g₀+Σᵢgᵢ(φᵢ)，则「每个旋钮单独拧过」就足以预测「任意旋钮组合」。这不是更强的假设，而是**把场景泛化转化为属性轴覆盖问题**：用可加结构 GP 后验，未见组合的方差上界是各轴方差之和；只要每根轴都有证据，组合就有界。关键洞见：**组合泛化可以从单因子证据推出，而不需要组合级数据**。

**灵感 3（创新点 → 新颖性认证 NCG：把「会泛化」变成可证伪命题）**
直觉：不要说「我们的方法能泛化」，要说「对这个 φ，在 ≥1−α 覆盖、宽度 ≤w_max 的意义上能泛化，超出就弃权」。用**加权共形预测**（处理组合泛化带来的协变量偏移）+ 新颖性分数 η(φ) 做门控，输出的是**集合 C_α(φ)** 而不是点估计。关键洞见：**创新点不是模型结构，而是「泛化的证书」**——把经验主张转成有限样本、逐场景、可审计的保证。

**灵感 4（创新点 → 泛化感知主动探测 GAP）**
直觉：当场景落在认证域外时，最省钱的泛化方式是「问一个最值钱的问题」，而不是盲目执行再回退。探测动作（轻触、点动、微滑移）按**风险加权信息增益**排序：用 GP 方差收缩近似 IG，用违反安全不变量的概率做风险惩罚，优先探测低风险、高信息的方向。关键洞见：**泛化是探测出来的，不是祈祷出来的**。

**灵感 5（跨场景迁移 → 证据账本 XTL）**
直觉：证据不应随场景切换而丢弃或重学。在属性空间维护 append-only 账本，记录每个属性区域被哪些 EV-exec 证据覆盖、覆盖半径与证书；新场景用邻域证据做核加权后验。关键洞见：**泛化能力=可复用的证据覆盖，而不是可记忆的场景列表**。

**灵感 6（创新点 → 泛化能力证书 GCC）**
直觉：把「创新点」做成一个下游可直接查询的一等公民：GCC=(Φ_cert, α_eff, η_max, w_max, ttl, digest)。规划器可以问「这个场景在我的认证域内吗？」。关键洞见：**GCC 是一种新的评测/声明格式**——它让「泛化」从叙事变成可被第三方验证的凭证，也让弃权成为显式、可审计的行为。

**灵感 7（合流 → 泛化认证场景闭环 GENESIS）**
直觉：CASF 把场景变属性，SCG 给组合先验，NCG 划认证域，GAP 在域外补证据，XTL 复用证据，GCC 签发证书，NCP 分配泛化/认证预算。闭环为：**观测→属性后验→新颖性认证→(探测|编译)→意图锁→执行→EPIR 校验→账本更新→共形再校准→GCC 更新**。它与第 60 轮的关系是**替换而非叠加**：SERC 的第 ② 步 π_scene 被 SCG 取代，SIC 的 scene_conf 被 GCC 门控取代。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（组合属性场景分解 CASF）** 场景不再取离散标签，而取物理属性向量：
- **属性空间** Φ = ∏_{i=1}^{d} Φ_i ⊆ ℝ^d，d=6，Φ_i 分别为摩擦 μ、刚度 κ、粗糙度 ρ、坡度 θ、可变形性 δ、振动谱 ν。
- **属性编码器** E_φ: O_{1:t} → p(φ|O_{1:t})（对角高斯或因子化 normalizing flow）。
- **共享阻抗映射** g_ψ: Φ → K，跨场景共享；场景 z 只是 φ 的一个取值点。
- **解耦条件 (D)**：存在 p(φ|O)=∏ᵢ p(φᵢ|O)，且观测解码器在 φ 上单射（可辨识到置换/尺度意义）。这是「属性可独立操控」的数学表述。
- **场景泛化算子**：对未见场景 z*，φ*=E_φ(z*)，预测 π(K|φ*)=p(K|g(φ*))。
与第 60 轮的本质区别：π_scene(K|z) 是 per-scene 查表，定义域只有 |Z_scene| 个点；g_ψ 定义在整个 Φ 上，故**对未枚举的属性组合仍有定义**。

**定义 162（结构化组合泛化 SCG）** 采用可加结构高斯过程：
```
g(φ) = g₀ + Σᵢ gᵢ(φᵢ),   gᵢ ~ GP(0, kᵢ)
⇔ g ~ GP(m, k),           k(φ,φ') = Σᵢ kᵢ(φᵢ, φ'ᵢ)
```
给定证据 D={(φⱼ,Kⱼ)}，后验 μ*(φ*)=m(φ*)+k(φ*,Φ_D)ᵀ(K_DD+σ_n²I)⁻¹(K−m)，σ*²(φ*)=k(φ*,φ*)−k(φ*,Φ_D)ᵀ(·)⁻¹k(Φ_D,φ*)。
- **轴覆盖半径**：rᵢ = sup_{φ∈Φ_i} min_{j} |φ−φ_{j,i}|。
- **组合泛化界**：因核可加，σ*²(φ*) ≤ Σᵢ σᵢ²(φ*ᵢ)。故若每轴后验标准差 ≤ εᵢ，则任意未见组合满足误差 ≤ β·√(Σᵢ εᵢ²)（以 ≥1−δ 概率，β 为 GP 置信系数）。
- **模型失配项**：若真实 g 不可加，额外误差 ≤ 2·Lip(g−g_add)·maxᵢ rᵢ（用 Lipschitz 差界定，作为 NCG 的失配检测依据）。

**定义 163（新颖性认证泛化 NCG）** 设证据属性集 D_ev，校准集 D_cal={(φⱼ,Kⱼ)}：
- **新颖性分数** η(φ) = min_{φⱼ∈D_ev} ‖φ−φⱼ‖_{Σ⁻¹}（白化属性空间距离；可换 kNN/能量分数）。
- **密度比** r(φ) = p_ev(φ)/p_prior(φ)，用判别器估计（处理组合泛化诱导的协变量偏移）。
- **加权共形集**：非一致性分数 s(φ,K)=|K−μ*(φ)|/σ*(φ)；加权分位数
  Q(α)=inf{ q : Σ_{j: s_j≤q} wⱼ / Σⱼ wⱼ ≥ 1−α },  wⱼ=r(φⱼ)；
  C_α(φ)={ K : s(φ,K) ≤ Q(α) }。
- **覆盖保证**：加权可交换性下 P(K∈C_α(φ)) ≥ 1−α−ε_est。
- **认证域** G_α={ φ : η(φ)≤η_max ∧ width(C_α(φ))≤w_max }。
- **三态判定**：IN_CERT（直接用组合先验）/ PROBE（先探测）/ ABSTAIN（弃权、保守执行或请求人工）。

**定义 164（泛化感知主动探测 GAP）** 候选探测动作集 A（轻触、点动、微滑移、局部扫掠）：
- **信息增益** IG(a)=H[p(φ|D)]−E_{y|a}[H[p(φ|D∪{(a,y)})]] ≈ ½·log(σ²_before/σ²_after(a))。
- **风险** R(a)=P(违反当前活跃安全不变量 | a, K_safe)。
- **选择规则**：a* = argmax_{a∈A_safe} IG(a) / (c(a)·(1+R(a)/ρ))，A_safe 由 ERTC 契约给出，ρ 为风险厌恶尺度。
- **停止条件**：η(φ)≤η_max，或 B_gen 耗尽（耗尽即转 ABSTAIN）。

**定义 165（跨场景迁移账本 XTL）** append-only 账本 L={(t, R_k, n_k, r_k, cert_k, ev_hash_k)}：
- R_k⊆Φ 为属性区域，r_k 为覆盖半径，ev_hash_k 为支撑 EV-exec 的哈希（对接第 60 轮 EPIR）。
- **覆盖函数** cov(φ)=Σ_k w_k(φ)·𝟙[φ∈R_k]，w_k 为核权重。
- **迁移**：查询 φ 时取邻域条目做核加权后验，等价于带重要性权重的贝叶斯更新。
- **不变量**：任一条目必须可追溯到 EV-exec 哈希；只追加，删除只能留墓碑（保护长程证据链）。

**定义 166（组合泛化闭环 CGL）** 算子 CGL(M, O_t, intent, δ_f_req)：
```
① CASF:  p(φ|O_t) ← E_φ(O_t)
② NCG:   η(φ), C_α(φ), state ∈ {IN_CERT, PROBE, ABSTAIN}
③ 若 PROBE: a* ← GAP.select(...); y ← execute_probe(a*); 更新 p(φ|D); 回 ②
④ 若 IN_CERT: K_prior ← SCG.posterior(φ)
   若 ABSTAIN: K_prior ← None（走通用保守先验/求助）
⑤ EEIS: K_safe^gen ← compile_with_prior(K_prior, δ_f_req)
⑥ CIEC: C_intent ← ϕ(intent); ERTC.lock(C_intent)        # 第 60 轮
⑦ 执行，收集 EV-exec
⑧ EPIR.verify(EV-exec); XTL.update; NCG.recalibrate        # 第 60 轮 + 本轮
⑨ GCC.issue(); return (φ, K_safe^gen, C_α, GCC, L.status)
```

**定义 167（新颖性认证预算 NCP / PCE+++++）** B_cog⁺=(B_scene, B_intent, B_ros, B_exec, B_gen, B_cert)：
- B_gen = 探测次数/能量/时间；B_cert = 共形再校准与证书签发算力。
- **泛化 VOI**：voi_gen(π)=λ_cov·E[Δcoverage]−λ_probe·cost_probe−λ_cert·cost_cert；总价值 VOI=voi_cog+voi_gen。
- **降级表**：B_gen 耗尽 ⇒ 只允许 IN_CERT 区域执行，域外 ABSTAIN；B_cert 耗尽 ⇒ 复用缓存证书并加宽 α_eff；B_scene 耗尽 ⇒ 属性编码退化为保守先验；B_exec 耗尽 ⇒ 第 60 轮原有降级。

**定义 168（泛化能力证书 GCC）** GCC=(Φ_cert, α_eff, η_max, w_max, ttl, digest)：
- Φ_cert=∪ 认证 cell（属性空间中的凸/超矩形覆盖）。
- covered(φ) ⇔ φ∈Φ_cert ∧ η(φ)≤η_max ∧ width(C_α(φ))≤w_max ∧ 未过 ttl。
- **语义**：GCC 断言「在 Φ_cert 上以 ≥1−α_eff 覆盖、宽度 ≤w_max 泛化；域外显式弃权」。这是本轮创新点的可审计载体。

## 2. 关键算法伪代码（简版，完整版见产物区）

```python
class CompositionalAttributeSceneFactorization:   # IP-161
    def encode(self, obs):
        mu, logvar = self.encoder(obs)            # 因子化属性编码
        return Gaussian(mu, np.exp(logvar))
    def predict_K(self, phi):
        return self.impedance.posterior(phi)      # 共享 g_ψ

class AdditiveGPImpedance:                        # IP-162
    def k(self, p, q):                            # 可加核
        return sum(ki(p[i], q[i]) for i, ki in enumerate(self.kernels))
    def posterior(self, phi):
        k = self._cross(phi, self.X)
        mu = k @ cho_solve(self.L, self.Y)
        return mu, max(self.k(phi, phi) - k @ cho_solve(self.L, k), 1e-9)

class NoveltyCertifiedGeneralization:             # IP-163
    def certify(self, phi):
        eta = min(np.linalg.norm((phi - e) @ self.Whiten) for e in self.ev_phi)
        mu, var = self.scg.posterior(phi)
        scores = np.abs(self.K_grid - mu) / np.sqrt(var)
        q = weighted_quantile(scores, self.weights(), 1 - self.alpha)
        C = self.K_grid[scores <= q]
        state = ('IN_CERT' if (eta <= self.eta_max and width(C) <= self.w_max)
                 else 'PROBE' if self.budget.B_gen > 0 else 'ABSTAIN')
        return Cert(eta, C, state)

def select_probe(phi_post, probes, ertc, rho=0.1):  # IP-164
    base = phi_post.var()
    return max((a for a in probes if ertc.admissible(a)),
               key=lambda a: 0.5*np.log(base/phi_post.anticipate(a).var())
                             / (cost(a)*(1 + risk(a)/rho)))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CASF | O(d) 编码/步 | O(d²) | 属性可辨识（定义 161-D） |
| SCG | O(n²d) 查询 / O(n³) 拟合 | O(n²) | 轴覆盖⇒组合覆盖，误差 ≤ β√(Σεᵢ²) |
| NCG | O(n log n) 校准 | O(n) | 加权共形覆盖 ≥ 1−α−ε_est |
| GAP | O(|A|·d) | O(d) | 仅在 A_safe 内探测，风险有界 |
| XTL | O(log n) 查询 | O(n) | append-only 可追溯 |
| CGL | O(闭环) | 复用 | 域外必弃权，无静默错误 |

**正确性定理（GENESIS）** 设 A66–A71 成立：**(A66)** 属性解耦与可辨识（定义 161-D）；**(A67)** 真实阻抗映射在 Lipschitz 意义下可加近似，失配 ≤ ε_add；**(A68)** 各轴核满足 GP 平滑性，后验置信界成立；**(A69)** 校准集与测试场景满足加权可交换性（密度比可估）；**(A70)** GAP 仅在 ERTC 可行动作集内探测且单步风险 ≤ ρ；**(A71)** B_gen/B_cert 单调消耗。则：
1. **组合泛化正确性**：若每轴覆盖 εᵢ 且 ε_add 足够小，则任意未见组合 φ* 的阻抗误差 ≤ β√(Σεᵢ²)+2·Lip·maxᵢrᵢ。
2. **认证覆盖性**：φ∈Φ_cert 时，P(K_true∈C_α(φ)) ≥ 1−α−ε_est。
3. **安全弃权性**：当 η>η_max 且 C_α∩K_safe=∅ 时系统必 ABSTAIN，故「用错误先验执行」的概率 ≤ δ_abstain。
4. **预算安全性**：任一 B_cog⁺ 分量耗尽即触发定义 167 的降级策略。

## 5. 创新点提炼（本轮「创新点」落地）

1. **从闭集分类到属性组合泛化（CASF+SCG）**：把场景泛化重新表述为「属性轴覆盖」问题，给出「轴覆盖⇒组合覆盖」的可加 GP 定理，摆脱对场景枚举的依赖。
2. **从「声称泛化」到「认证泛化」（NCG）**：用加权共形 + 新颖性门控，把泛化变成有限样本覆盖保证；这是本轮最核心、最可证伪的创新点。
3. **从被动适应到泛化感知探测（GAP）**：以风险加权信息增益选择最小探测，把泛化成本显式化、最优化。
4. **从「每场景重学」到跨场景证据复用（XTL）**：属性空间账本与 EPIR 证据链对接，证据可审计、可迁移。
5. **从隐藏失败到能力感知弃权（GCC+NCP）**：GCC 作为新的评测/声明格式，使「不知道就弃权」成为一等公民。
6. **方法论创新**：把「创新点」本身形式化为可验证的 GCC 契约，而非模块堆叠叙事。

## 6. 本轮最大风险

**一句话**：最大的风险是「组合过度自信」——一旦属性解耦或可加性假设被违背，可加 GP 会在属性凸包内部自信地插值到错误的 K，而 η(φ) 在凸包内仍然很小、NCG 的新颖性门控根本发现不了这种**模型失配型错误**；因此必须把新颖性分数与后验预测检验/CUSUM 失配检测联合使用，并保留域内弃权能力，否则「认证泛化」会退化为「认证地犯错」。

### IP-161 CASF（组合属性场景分解）

```python
class CompositionalAttributeSceneFactorization:
    ATTRS = ['mu', 'kappa', 'rho', 'theta', 'delta', 'vib']

    def __init__(self, d=6):
        self.d = d
        self.encoder = FactorizedAttributeEncoder(d)   # output: mu, logvar (diagonal)
        self.impedance = AdditiveGPImpedance(d)

    def encode(self, obs):
        mu, logvar = self.encoder(obs)
        return Gaussian(mu, np.exp(logvar))            # p(phi | O)

    def predict_K(self, phi):
        mu, var = self.impedance.posterior(phi)
        return Gaussian(mu, var)

    def disentanglement_penalty(self, phi_batch):
        # enforcement of p(phi|O)=prod p(phi_i|O): off-diagonal corr penalty
        C = np.corrcoef(phi_batch.T)
        off = C - np.diag(np.diag(C))
        return (off ** 2).mean()
```

### IP-162 SCG（结构化组合泛化）

```python
class AdditiveGPImpedance:
    def __init__(self, d, lengthscales):
        self.d = d
        self.kernels = [RBF(lengthscale=ls) for ls in lengthscales]  # per-axis ARD

    def k(self, p, q):
        return sum(ki(p[i:i+1], q[i:i+1]) for i, ki in enumerate(self.kernels))

    def fit(self, X, Y, noise=1e-3):
        self.X, self.Y = np.asarray(X), np.asarray(Y)
        self.Kxx = self._gram(X) + noise * np.eye(len(X))
        self.L = np.linalg.cholesky(self.Kxx)

    def _gram(self, X):
        n = len(X)
        return np.array([[self.k(X[i], X[j]) for j in range(n)] for i in range(n)])

    def posterior(self, phi):
        k = np.array([self.k(phi, x) for x in self.X])
        mu = k @ cho_solve(self.L, self.Y)
        var = self.k(phi, phi) - k @ cho_solve(self.L, k)
        return mu, max(var, 1e-9)

    def axis_coverage_bound(self, phi):
        # sigma^2(phi) <= sum_i sigma_i^2(phi_i), per-axis marginal
        return sum(self._marginal_var(phi, i) for i in range(self.d))
```

### IP-163 NCG（新颖性认证泛化）

```python
class NoveltyCertifiedGeneralization:
    def __init__(self, scg, alpha=0.1, eta_max=0.5, w_max=0.2):
        self.scg = scg
        self.alpha, self.eta_max, self.w_max = alpha, eta_max, w_max
        self.ev_phi = []
        self.Sigma_inv_sqrt = np.eye(scg.d)
        self.weights_fn = lambda phi: 1.0

    def novelty(self, phi):
        return min(np.linalg.norm((phi - e) @ self.Sigma_inv_sqrt)
                   for e in self.ev_phi)

    def weighted_conformal(self, scores, weights):
        order = np.argsort(scores)
        s, w = scores[order], weights[order]
        cum = np.cumsum(w) / np.sum(w)
        idx = min(np.searchsorted(cum, 1 - self.alpha), len(s) - 1)
        return s[idx]

    def certify(self, phi, K_grid, budget):
        eta = self.novelty(phi)
        mu, var = self.scg.posterior(phi)
        scores = np.abs(K_grid - mu) / np.sqrt(var)
        weights = np.array([self.weights_fn(e) for e in self.ev_phi])
        if len(scores) == 0 or len(weights) == 0:
            return Cert(eta, np.array([]), 'ABSTAIN')
        q = self.weighted_conformal(scores, weights)
        C = K_grid[scores <= q]
        if eta <= self.eta_max and width(C) <= self.w_max:
            state = 'IN_CERT'
        elif budget.B_gen > 0:
            state = 'PROBE'
        else:
            state = 'ABSTAIN'
        return Cert(eta, C, state)

    def recalibrate(self, ev_exec, phi):
        self.ev_phi.append(phi)
        self._update_density_ratio(ev_exec)
```

### IP-164 GAP（泛化感知主动探测）

```python
PROBES = ['light_touch', 'micro_jog', 'micro_slip', 'local_sweep']

def estimate_violation_risk(a, K_safe, M):
    d = M.forward_kinematics_delta(a)
    return M.safety_margin_violation_prob(d, K_safe)

def select_probe(phi_post, M, rho=0.1):
    base_var = max(phi_post.var(), 1e-12)
    best, best_score = None, -np.inf
    for a in PROBES:
        if not M.ertc.admissible(a):          # A_safe: ERTC contract constraint
            continue
        var_after = phi_post.anticipate(a).var()
        ig = 0.5 * np.log(base_var / max(var_after, 1e-12))
        risk = estimate_violation_risk(a, M.K_safe, M)
        score = ig / (M.probe_cost(a) * (1 + risk / rho))
        if score > best_score:
            best, best_score = a, score
    return best

def generalization_probe_loop(M, phi_post, max_probes=3):
    for _ in range(max_probes):
        if M.ncg.novelty(phi_post.mean) <= M.ncg.eta_max:
            break
        if M.budget.B_gen <= 0:
            break
        a = select_probe(phi_post, M)
        if a is None:
            break
        y = M.execute_probe(a)
        phi_post = M.casf.update(phi_post, a, y)
        M.budget.B_gen -= 1
    return phi_post
```

### IP-165 XTL（跨场景迁移账本）

```python
class CrossSceneTransferLedger:
    def __init__(self):
        self.entries = []

    def update(self, region, radius, ev_hash, cert, n=1):
        # append-only; entries never mutated
        self.entries.append({
            't': time.time(), 'region': region, 'radius': radius,
            'n': n, 'cert': cert, 'ev_hash': ev_hash
        })

    def query(self, phi):
        neigh = [e for e in self.entries if phi in e['region']]
        if not neigh:
            return None
        w = np.array([np.exp(-np.linalg.norm(phi - e['region'].center) /
                             max(e['radius'], 1e-6)) for e in neigh])
        return np.average([e['n'] for e in neigh], weights=w)

    def coverage(self, phi):
        return max((e['radius'] for e in self.entries if phi in e['region']),
                   default=0.0)
```

### IP-166 CGL（组合泛化闭环）

```python
def compositional_generalization_loop(M, obs, intent, delta_f_req):
    # (1) attribute posterior
    phi_post = M.casf.encode(obs)

    # (2) novelty certification
    phi = phi_post.mean
    cert = M.ncg.certify(phi, M.K_grid, M.budget)

    # (3) probe if outside certified region
    if cert.state == 'PROBE':
        phi_post = generalization_probe_loop(M, phi_post)
        phi = phi_post.mean
        cert = M.ncg.certify(phi, M.K_grid, M.budget)

    # (4) prior or abstain
    if cert.state == 'IN_CERT':
        K_prior = M.scg.posterior(phi)
    else:                                     # ABSTAIN
        K_prior = None                        # fall back to general conservative prior

    # (5) compile + intent lock (round 60)
    K_safe_scene = (M.eeis.compile_with_prior(K_prior, delta_f_req)
                    if K_prior is not None else None)
    if intent:
        M.intent_ctrl.receive_intent(intent)

    # (6) execute
    M, fused, D_plus, EV_exec, eeis_cert = closed_loop_exec_probe(
        M, M.current_cp, delta_f_req, M.budget)
    if K_safe_scene is not None:
        dispatch_impedance_params(K_safe_scene.best, eeis_cert)

    # (7) evidence: EPIR verify -> ledger -> recalibrate
    msg = M.epir.append(EV_exec.__dict__)
    if not M.epir.verify(msg):
        return M, 'EVIDENCE_BROKEN'
    M.xtl.update(region=cell_of(phi), radius=cert.width,
                 ev_hash=msg.hash, cert=cert)
    M.ncg.recalibrate(EV_exec, phi)

    # (8) issue certificate
    gcc = M.gcc.issue(phi, cert)
    return M, (phi, K_safe_scene, cert, gcc, M.xtl.coverage(phi))
```

### IP-167 NCP（新颖性认证预算 / PCE+++++）

```python
class NoveltyCertifiedBudget:
    def __init__(self, scene_ops=100, intent_ops=50, ros_retry=3,
                 gen_probes=3, cert_ops=1000, exec_budget=None):
        self.B_scene_ops, self.B_intent_ops = scene_ops, intent_ops
        self.B_ros_retry = ros_retry
        self.B_gen, self.B_cert = gen_probes, cert_ops
        self.B_exec = exec_budget or ExecBudget()
        self.ops_scene = self.ops_intent = self.ops_cert = 0

    def policy(self, state):
        if state == 'PROBE' and self.B_gen <= 0:
            return 'ABSTAIN'
        if state == 'IN_CERT' and self.B_cert <= 0:
            return 'CACHED_CERT'      # reuse certificate, widen alpha_eff
        if self.ops_scene >= self.B_scene_ops:
            return 'GENERAL_PRIOR'
        if self.B_ros_retry <= 0:
            return 'LOCAL_LOOP_ONLY'
        return 'NORMAL'

def generalization_voi(action, coverage_gain, cost_probe, cost_cert,
                       lam_cov=1.0, lam_probe=0.2, lam_cert=0.1):
    return (lam_cov * coverage_gain - lam_probe * cost_probe
            - lam_cert * cost_cert)
```

### IP-168 GCC（泛化能力证书）

```python
@dataclass
class GeneralizationCompetenceCertificate:
    covered_cells: list          # list of attribute-space cells
    alpha_eff: float
    eta_max: float
    w_max: float
    ttl: float
    digest: str                  # sha256 over (cells, alpha_eff, ledger tip)

    def covers(self, phi):
        if time.time() > self.ttl:
            return False
        return any(cell.contains(phi) for cell in self.covered_cells)

class CertificateAuthority:
    def issue(self, phi, cert):
        cells = merge_cells(self.cells + [cell_of(phi)]) if cert.state == 'IN_CERT' \
                else self.cells
        digest = hashlib.sha256(repr((cells, cert.eta)).encode()).hexdigest()[:16]
        return GeneralizationCompetenceCertificate(
            cells, alpha_eff=self.alpha, eta_max=self.eta_max,
            w_max=self.w_max, ttl=time.time() + TTL, digest=digest)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| CASF | O(d) / 步 | O(d²) | 属性可辨识（定义 161-D） |
| SCG | O(n²d) 查询 / O(n³) 拟合 | O(n²) | 组合误差 ≤ β√(Σεᵢ²)+2Lip·r_max |
| NCG | O(n log n) 校准 | O(n) | 覆盖 ≥ 1−α−ε_est |
| GAP | O(|A|·d) | O(d) | 仅 A_safe 内探测，单步风险 ≤ ρ |
| XTL | O(log n) 查询 | O(n) | append-only、可追溯 |
| CGL | O(闭环) | 复用 | 域外必弃权 |

**正确性定理（GENESIS）**：若 A66–A71 成立，则：
1. **组合泛化**：每轴覆盖 εᵢ 且失配 ε_add 足够小 ⇒ 任意未见组合误差 ≤ β√(Σεᵢ²)+2Lip·maxᵢrᵢ。
2. **认证覆盖**：φ∈Φ_cert ⇒ P(K_true∈C_α(φ)) ≥ 1−α−ε_est。
3. **安全弃权**：η>η_max 且 C_α∩K_safe=∅ ⇒ 必 ABSTAIN，错误先验执行概率 ≤ δ_abstain。
4. **预算安全**：任一 B_cog⁺ 耗尽 ⇒ 触发定义 167 降级策略。
5. **证据一致**：XTL 条目均携带 EPIR 校验通过的 EV-exec 哈希；EPIR 失败则拒绝写入账本。

**与第 60 轮的兼容性**：IP-161/162 替换 SERC 的步骤 ②（π_scene→SCG 属性先验）；IP-163/168 替换 SIC 的 scene_conf 门控；IP-165 复用 EPIR 的 S_local 哈希；IP-167 扩展 PCE++++ 的预算向量。故 GENESIS 是 SGEC 的**升级路径**而非平行系统。

## 6. 本轮最大风险

**一句话**：最大的风险是「组合过度自信」——一旦属性解耦或可加性假设被违背，可加 GP 会在属性凸包内部自信地插值到错误的 K，而 η(φ) 在凸包内仍然很小、NCG 的新颖性门控根本发现不了这种**模型失配型错误**；因此必须把新颖性分数与后验预测检验/CUSUM 失配检测联合使用，并保留域内弃权能力，否则「认证泛化」会退化为「认证地犯错」。
