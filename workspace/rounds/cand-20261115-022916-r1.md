# 第 3 轮（研究线累计第 3 轮；任务书将本轮记为「灵感循环新阶段第 1 轮」；承接基线 **ToolGauge**；本轮灵感：「状态隔离」×「关节驱动」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439），
> 其下承第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45）与 **MODGAUGE**。
> **本轮纪律**：不推倒 6C 闭环、MTC/TCV 工具契约、双层下注、MP-Φ/AP-Cal、L-Box 共形假设、
> MODGAUGE 五不变式、严格退化链与 50Hz 硬实时约束；只正面攻击 ToolGauge 的两个**未言明假设**：
>
> 1. **「机器人是被动观测者，探测工具都在体外」**——ToolGauge 的工具库是 IR / 敲击 / 光照 / 双目 / 热漂移 / 跨模态，
>    唯独没有「移动机器人自己的关节」。但关节驱动是机器人**最便宜、最高带宽、也最危险**的计量仪器：
>    同一固定视角无法分离手眼外参与关节零偏，单向运动无法分离减速器回差与连杆柔度，静止观测无法激发热-力耦合。
> 2. **「隔离可以按盲区格子做」**——ToolGauge 用全局 AP-Cal 先验，污染一旦发生就是跨盲区强相关；
>    朴素的补救是「每个格子独立先验」，但这会**破坏可辨识性**：共享零偏、规范自由度与柔度耦合参数
>    在单格内根本不可分辨。隔离不是越细越好，正确边界是**可辨识边界**。
>
> **核心命题**：把 ToolGauge 的「盲区 → 契约探测 → 摊销校准 → 局部热替换」升级为
> 「**主动关节驱动取信息 → 按可辨识分量画隔离边界 → 分区摊销校准 → 隔离事务提交**」。
> 一句话：ToolGauge 问「证据可不可信」；**ArtiGauge 问「哪些参数必须一起估、该驱动哪些关节去估、其余状态如何隔离到不串味」**。

## 双灵感映射（不是加工具，而是改信息获取方式与安全边界）

| 灵感词 | ToolGauge 的隐含假设 | 升级为 | 一句话动机 |
|---|---|---|---|
| 状态隔离 | 一个全局 AP-Cal 先验 + 全局 P-Quarantine 急停；隔离 = 事后断路 | **S-Box 隔离事务 + 按 ICC 分区先验 + 交换门 + 两阶段提交** | 污染应在结构边界阻断；但边界必须按可辨识性切，不能按格子切 |

**不变式保持声明**：
- MODGAUGE 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）全部保留；
- 组合单调性获得**隔离版本**：任意已提交隔离事务前缀可串行化等价于某串行执行（引理 54）；
- 主张绑定获得**隔离证书扩展**：数值主张除引用回执外，还必须引用 `IsolationCert`（定义 446）；
- **严格退化链延长**：ArtiGauge 隔离设施失效 ⇒ 禁用关节驱动（物理副作用不可控）⇒ 退回 ToolGauge 被动探测
  ⇒ LeanGauge ⇒ MODGAUGE。关节驱动是增强项，不是正确性依赖（引理 56）。

## 0. 直觉与动机

### 0.1 关节驱动：从「被动看」到「主动动」

ToolGauge 的探测哲学是「在盲区旁边放一台仪器」：补一束 IR、敲一下、扫一圈光。它默认机器人本体不动。
这在一个关键场景里失效：**误差源本身是关节空间参数**。

- **手眼标定**：相机外参与关节编码器零偏在单一固定视角下是**乘积可辨识**的，只有让机械臂走过多个构型，
  残差随构型的变化才把两者分开；
- **减速器回差 / 连杆柔度**：只有做**双向、带载、反向**的关节激励，回差与柔度才从「总误差」里显形；
- **热-力耦合**：关节持续驱动会改变本体温度，热漂移系数只有在**主动热激励**下才可估；
- **遮挡与视差**：移动基座/机械臂能制造视差、绕开遮挡，这是任何外部传感器都买不到的几何信息。

直觉上，关节驱动把「观测设计」从「选哪个外部工具」升级为「**选哪条机器人自身轨迹**」。
它带来三类新东西：

1. **信息增益高**：一次自运动同时改变视角、光照、接触与动力学，等效于并行执行多个外部探测；
2. **可辨识性强**：它直接给计量雅可比 `J` 增加新的行，能把秩亏的固定构型变成满秩；
3. **危险**：运动会碰撞、磨损、发热、扰动场景，且**物理状态不能像内存一样回滚**。

所以关节驱动必须与「状态隔离」同时出现：前者负责**取信息**，后者负责**把取信息的副作用关进笼子**。

### 0.2 状态隔离：不是「切得越细越好」，而是「沿可辨识边界切」

第 2 轮已经点名最大风险：AP-Cal 的摊销先验在预训练→部署偏移下会产生**跨盲区强相关**的系统性偏差；
P-Quarantine 是「烟雾报警器 + 全楼断电」——等连续 3 次同向残差才触发，那时污染已提交，且一停全停。
状态隔离的第一层直觉很直接：**让每个修复成为事务**——读快照、写私有缓冲、提交时查冲突、失败原子回滚、
每个字段带溯源标签。这样「一次坏先验污染所有子图」在结构上被挡住。

但**第二层直觉更重要，也更反直觉**：隔离不能按盲区格子切。
设两个参数 `θ₁`（关节零偏）与 `θ₂`（连杆长度），它们对残差的雅可比列高度相关；
若把 `θ₁` 与 `θ₂` 放进两个互不通信的隔离单元，各自只用自己的数据估计，
则 `θ₁` 的规范自由度无法消除，信息矩阵 `ℐ₁` 降秩，方差发散——**隔离反而让估计不可辨识**。
反过来，若把所有参数放进一个全局单元，则一次先验错误会同时污染所有参数。

正确的切法是**可辨识边界**：

- **同一可辨识分量（ICC）内部**：参数必须**联合估计**（joint estimation），因为存在共享零偏、规范自由度或强柔度耦合；
- **不同 ICC 之间**：耦合弱，可以**状态隔离**，让误差局部化；
- **不确定时**：把边合并（更粗的隔离），而不是冒险切细——「未知 ⇒ 合并」是保守方向。

这就是本轮的核心洞察：**状态隔离的粒度 = 可辨识性的粒度**。
隔离不是免费的安全，而是一个**受可辨识性约束的图划分问题**。

### 0.3 合流：ArtiGauge = 主动关节计量 + 按 ICC 隔离的事务

把两条灵感接起来，得到一个自然的分工：

1. **先画边界**：用微激励主动辨识关节耦合图 `G_𝒥`（而不是假设它已知）；
2. **再取信息**：在 ICC 上做关节空间 D-最优激励，选一条既安全又 maximally informative 的轨迹；
3. **最后隔离提交**：每个 ICC 用私有先验头校准，跨 ICC 只经「交换门」通信；
   契约热替换走两阶段隔离提交，物理副作用走安全等价类回滚。

一句话：**ToolGauge 把机器人当「带工具的观察者」，ArtiGauge 把机器人当「会移动的计量仪器」，
并用数据库级的隔离事务保证「仪器动过的地方」不会污染「没动过的地方」。**

### 0.4 为什么这不是「换皮」

| 维度 | ToolGauge | ArtiGauge |
|---|---|---|
| 优化目标 | 单次探测的信息增益 `Ĝ_t − c_t` | 关节轨迹的 D-最优信息 `log det ℐ(ξ)` − 驱动/热/磨损代价 |
| 修复单元 | 单盲区格子 `s=(d,m,i)` | 可辨识分量 `c ⊆ 𝒥`（一个 ICC 可含多格、可跨格共享） |
| 探测动作 | 预注册外部工具调用 | 外部工具 ∪ **机器人自身关节轨迹**（受力矩/速度/热/碰撞包络） |
| 隔离方式 | 全局先验 + 事后 P-Quarantine | 按 ICC 分区先验 + 交换门 + 两阶段隔离提交 |
| 失效模式 | 一次坏先验污染全部子图 | 边界画错会「假装隔离」；因此用保守上界 + 未知即合并 |
| 安全论证 | 统计相关性 + 在线断路器 | 可串行化 + 原子提交 + 可辨识性约束 + 泄漏监测 |

## 1. 形式化定义（增量：定义 432–447）

**定义 432（计量状态与状态模式）** 系统状态 `x = (φ, p, e)`：
- `φ`：契约状态（EC / M_ver 的数值字段、χ_R、claims）；
- `p`：物理状态（关节角 q、关节力矩 τ、温度 T、物体位姿、光照、接触状态）；
- `e`：证据状态（回执库、分区后验、缓存、失败计数、版本号）。
状态模式 `Σ_x` 为每个字段声明类型、版本、可变性、快照代价与隔离级别。

**定义 433（状态足迹与快照）** 事务 `T` 的足迹 `F(T) = (R(T), W(T), P(T))`：
`R/W` 为逻辑字段读写集；`P` 为物理副作用集（关节轨迹包络、光照、接触、热注入）。
`snapshot(F)` 返回 `R(T)` 的版本化只读拷贝；`restore(F)` 恢复 `φ/e` 并执行物理归位/补偿。
物理状态只保证回到**安全等价类**，不保证逐位相同（见引理 54）。

**定义 434（隔离事务 STxn 与隔离级别）** `STxn = (id, s, F, snap, intent, post, receipts, status)`。
隔离级别：
- **I1 快照读**：读已提交版本，写私有缓冲；
- **I2 可串行化**：提交时做写冲突检测 + 全局不变式校验；
- **I3 物理隔离**：`P(T)` 与其他在飞事务的物理足迹不相交，或工作空间/光照/接触互斥。
修复事务默认 **I2 + I3**；仅读诊断可为 I1；任何会移动关节的事务必须 I3。

**定义 435（状态隔离不变式 SI）** 对任意并发事务交错：
- **SI1**：未提交写对其它事务不可见；
- **SI2**：已提交事务前缀可串行化；
- **SI3**：物理副作用限于 `P(T)`，事务结束（提交或回滚）后 `p` 回到预注册安全等价类；
- **SI4**：每个写入字段携带溯源标签 `(txn_id, prior_version, receipts, cert_id)`。

**定义 436（计量关节与关节化契约图）** 计量关节 `j ∈ 𝒥` 是**可驱动自由度**：
机械臂/基座关节、云台、夹爪开合、光照方向、接触点、视角。每个关节有：
可达构型集 `Q_j`、驱动包络 `E_j`（力矩/速度/加速度/加加速度/热/碰撞）、
以及它所影响的契约参数子集。关节化契约图 `G_𝒥 = (𝒥, E_𝒥, w)`：
边 `(j,k)` 表示两关节对残差存在耦合，权重 `w_jk` 取归一化互信息、`|ℐ_jk|` 或物理柔度，
并带置信区间 `[w⁻, w⁺]`（保守估计用上界 `w⁺`）。

**定义 437（关节空间残差模型与计量雅可比）** 在名义构型 `θ₀` 附近：
`r = y − h(θ) ≈ J δθ + b + ε`，`J = ∂h/∂θ`，`ε ~ N(0, Σ_obs)`。
Fisher 信息 `ℐ(θ) = Jᵀ Σ_obs⁻¹ J`。
非线性情形用 Gauss-Newton 迭代重线性化；每次线性化后做秩与条件数检验。

**定义 438（可辨识分量 ICC 与合法隔离分区）** 给定 `G_𝒥` 与阈值 `τ_J`，
`G_𝒥` 中边权上界 `w⁺ ≥ τ_J` 的连通分量称为**可辨识分量（ICC）**，记其分区为 `π_id`。
一个分区 `π` 是**合法隔离分区**，当且仅当：
1. **粗化性**：`π` 是 `π_id` 的粗化（每个隔离块是若干 ICC 的并；不拆 ICC）；
2. **可辨识性**：对每个块 `c ∈ π`，`rank(J_c) = dim(θ_c)` 且 `cond(ℐ_c) ≤ κ_max`；
3. **弱耦合性**：对任意 `c ≠ c'`，归一化跨块耦合 `λ_{c,c'} ≤ λ_iso`（定义见引理 51）。
若 (2) 失败，必须与相邻块**合并**；若 (3) 失败，也必须合并或拒绝隔离。
默认取**最细的合法分区**（最大隔离且不破坏可辨识性）。

**定义 439（关节驱动探测原语与驱动包络）** 原语 `ξ = (q(t), q̇(t), q̈(t), t∈[0,T])`，满足：
`τ_min ≤ τ(t) ≤ τ_max`，`|q̇| ≤ q̇_max`，`|q̈| ≤ q̈_max`，`T_joint ≤ T_max`，
轨迹位于安全工作空间 `W_safe`，无自碰撞/环境碰撞，且**场景扰动预算** `D(ξ)` 不超过预注册上界
（例如不允许把物体推离原位）。读出仍由 ToolGauge 的工具 `t ∈ T₀` 完成。
执行期间进入 **PROBING-I3** 状态：工作空间互斥、力矩硬限、全量日志、操作者可见。

**定义 440（关节空间信息与 D-最优目标）** 对轨迹集 `S = {ξ_i}`：
`ℐ(S) = ℐ₀ + Σ_{ξ∈S} Σ_t J(q_ξ(t))ᵀ Σ_obs⁻¹ J(q_ξ(t)) Δt`。
D-最优目标 `max_S log det ℐ(S)`（等价于最小化参数置信椭球体积）；
对特定任务方向可用 A-最优 `tr(W ℐ(S)⁻¹)` 或 E-最优 `λ_min(ℐ(S))`。

**定义 441（JDA 关节驱动分配器）** 在包络、驱动预算 `B_drive`、长度上限 `L_max` 与 ICC 分区约束下：
`max_{S⊆Ξ, |S|≤L_max, cost(S)≤B_drive} log det ℐ(S) − λ_E·cost(S)`
s.t. 每条 `ξ` 满足 `E_j` 与扰动预算；每个 ICC 至少获得足以满足 rank/cond 的激励。
`cost(ξ)` 为能量 + 热积累 + 磨损的归一化代价；`λ_E` 把物理代价折算为信息当量。

**定义 442（分区摊销先验 SIP-Cal）** 对每个 ICC `c`，维护私有先验头
`q_c(u_c | ψ, ctx_c) = N(μ_c, Σ_c)`；共享骨干 `ψ` 只编码跨 ICC 的物理超参数
（噪声尺度、材质族、热扩散系数等），且在事务期间**冻结只读**。
全局后验取块对角积 `q(u) = ∏_c q_c(u_c|ψ,ctx_c) · r(ψ)`；跨块协方差默认不建模，
只有交换门（定义 443）通过时才允许单向信息交换或合并。
元训练目标：
`min_ψ Σ_c E[−log q_c(u*_c|ψ,ctx_c)] + β_KL·KL(q_c‖p_phys,c) + λ_iso·LeakagePenalty(π)`。
**保守性夹紧仍在**：`Σ_c ≽ κ_phys,c·I`，禁止预训练先验过度自信。

**定义 443（交换门与泄漏检验）** 对 ICC 对 `(c,c')`，用**未参与拟合**的 witness 回执 `W_c`：
比较独立后验与联合后验的 held-out NLL：
`Δ = NLL_ind(W_c) − NLL_joint(W_c)`。
仅当 `Δ > δ_gate`、`rank/cond` 仍合法、且跨块残差相关 `|ρ̂_{c,c'}| ≤ ρ_max` 时，
才允许 `c' → c` 的单向交换（或合并）；否则保持隔离。
用 e-value / 序贯检验控制「错误共享」的假阳性；交换门的状态写入 `IsolationCert`。

**定义 444（两阶段隔离提交 2PIC）** 对提交组 `C ⊆ π`：
- **Prepare**：在私有缓冲计算每个 `c` 的 EC_c，跑局部 V 与契约回归；
- **Pre-commit**：检查全局不变式（契约完整性、组合单调性、反作用通道完备、claims 绑定）、
  写冲突（自快照以来无冲突写）、ICC 合法性（rank/cond/λ）与 `IsolationCert`；
- **Commit**：单写者原子热替换，发布证书，更新版本与溯源；
- **Abort**：回滚 `φ/e`，物理归位，记录 RED。
提交组内不允许部分提交；跨组用一致割（consistent cut），失败则整组回滚。

**定义 445（隔离粒度自适应与拆分/合并）** 维护耦合上界 `w⁺` 与泄漏统计：
- **拆分**：若 `λ̂ > λ_iso` 且拆后两侧仍满足 rank/cond，则拆；
- **合并**：若 rank 亏、`cond > κ_max`、`λ̂ > λ_iso` 或耦合不可检测（引理 57），则合并；
- **冻结**：事务进行中不改变分区；分区只在 epoch 边界变更并重新验证。
原则：**未知 ⇒ 合并；有证据支持弱耦合 ⇒ 拆分。**

**定义 446（隔离证书 IsolationCert）** `Cert = (txn_id, π, {rank_c, cond_c}, F(T), snapshot_hashes,
leakage_tests, drive_envelope_compliance, rollback_hash, receipts)`。
证书绑定进 `EC.claims`；数值主张必须同时引用回执与证书，否则在序列化时剥离（定义 423 的扩展）。

```python
@dataclass
class STxn:
    id: str; s: Any; footprint: Any
    snap: dict; write_buf: dict; phys_log: list; status: str = "open"

class SBox:
    def begin(self, s, footprint):
        return STxn(id=new_id(), s=s, footprint=footprint,
                    snap=self.snapshot(footprint.R), write_buf={}, phys_log=[])
    def snapshot(self, fields):
        return {f: (self.state[f].value, self.state[f].version) for f in fields}
    def commit(self, txn, ec_bundle, cert):

        if not cert.valid():                       return self.abort(txn, "isolation_cert")
        if self.write_conflict(txn):               return self.abort(txn, "conflict")
        if not self.global_invariants(ec_bundle):  return self.abort(txn, "invariant")
        self.apply_atomic(txn.write_buf, ec_bundle, cert)   # 单写者
        self.publish(cert); return True
    def abort(self, txn, why):
        self.restore(txn.snap)                     # φ/e 快照回滚
        self.physical_home(txn.phys_log)           # 回到安全等价类 + 补偿
        self.record_red(txn, why); return False

    def estimate_coupling(self, joints, envelope):

            r  = self.execute(xi)                  # 读出所有通道的残差响应

        return ArticulationGraph(W)

    def icc_partition(self, G, tau_J, kappa_max):

        return merge_until_identifiable(comps, kappa_max)

# IP-323 JDA：关节空间 D-最优激励
class JDA:
    def plan(self, partition, envelope, budget, L_max):

                if envelope.safe(xi) and xi.disturbance <= D_max]
        def f(S): return logdet(I0 + sum(A(xi) for xi in S))   # A=JᵀΣ⁻¹J

    def calibrate(self, receipts, partition, backbone):

            mu, Sig = self.head[c](backbone, ctx)          # 私有头；骨干冻结
            posts[c] = (mu, clamp_min(Sig, KAPPA_PHYS[c]))  # 保守性夹紧
        return posts

        return { (c, d): self.test_share(posts, witness, c, d)
                 for c in posts for d in posts if c != d }

# IP-325 ArtiGauge-8C：隔离 → 假设 → 关节规划 → 编译 → 执行 → 校准 → 验证 → 更新
def artigauge_8c(M, s):

    partition = M.iso_sup.current_partition(s)             # I：ICC 分区
    H = M.lbox.hypothesize(s, M.dbox.R[s])                 # H：共形假设

    if not M.sbox.commit(txn, ec_bundle, cert):            # U：两阶段隔离提交
        return False

    return True
```

## 3. 推导（引理 51–57）

**引理 51（隔离-污染分解界）** 设 `π` 为合法隔离分区，`ℐ` 为全 Fisher，`ℐ_π` 为块对角 Fisher。
定义块 `c` 的 Schur 耦合 `E_c = ℐ_{c,-c} ℐ_{-c,-c}⁻¹ ℐ_{-c,c}`，
归一化耦合 `λ_π = max_c ‖ℐ_cc^{-1/2} E_c ℐ_cc^{-1/2}‖^{1/2}`。
则：
(a) 真实边缘协方差 `(ℐ⁻¹)_cc = (ℐ_cc − E_c)⁻¹`，而块隔离给出 `ℐ_cc⁻¹`；
二者之差为负半定（隔离**低估**方差、过度自信），相对误差
`‖ℐ_cc⁻¹ − (ℐ⁻¹)_cc‖ / ‖(ℐ⁻¹)_cc‖ ≤ λ_π²/(1−λ_π²) = O(λ_π²)`。
(b) 若 ICC `c` 的先验被污染、其后验 TV 偏差为 `ε_c`，则经 `λ_π` 泄漏到 `c'` 的 TV 偏差
`≤ C·λ_π·ε_c/(1−λ_π²)`；因此全局污染质量 ≤ `Σ_c ε_c + C·λ_π·Σ_c ε_c`，
而不是 ToolGauge 的「一次污染全部」。
(c) 交换门关闭时，跨 ICC 的唯一全局通道是骨干 `ψ`。**骨干是单点故障**：
必须低维、事务期间冻结、可版本回滚；否则「隔离了头，没隔离骨干」。
系：若 `λ_π ≤ λ_iso`，任务风险差 ≤ `L_task·C₀·λ_iso·√d`（`L_task` 为任务代价对契约参数的 Lipschitz 常数）。

**引理 52（可辨识-隔离对偶）** 设 `θ = (θ_1,…,θ_k)`。
(a) 若块 `c` 被拆到 `rank(J_c) < dim(θ_c)`，则 `ℐ_c` 奇异，任何有限方差估计不存在；
因此 ICC 不可拆，这是隔离的**硬下界**。
(b) 若拆分合法（`rank` 满），忽略跨块项使 `ℐ_cc ≥ ℐ_cc − E_c`，故
`ℐ_cc⁻¹ ⪯ (ℐ⁻¹)_cc`——块隔离**系统性过度自信**，过度量由 `E_c` 控制。
(c) 合并独立块在统计上安全（不会过度自信），但会把污染从「局部」扩大为「块内」；
因此在所有合法分区中，**最细的合法分区**在保持可辨识性的同时最小化污染扩散。
**推论 52.1**：从 ICC 分区出发，把所有 `λ_{c,c'} > λ_iso` 的块对合并，迭代至不动点，
得到最细合法分区；该过程单调、有限步终止。

**引理 53（JDA 的次模近似与安全过滤）** 设 `A_ξ = J_ξᵀ Σ_obs⁻¹ J_ξ ⪰ 0`，
`f(S) = log det(ℐ₀ + Σ_{ξ∈S} A_ξ)`。`f` 单调且次模。
在 `|S| ≤ L_max` 的基数约束下，贪心达到 `≥ (1−1/e)·OPT`；
在预算约束下用 cost-benefit 贪心得 `≥ (1−1/e)/2`，或在 `L_max ≤ 6` 且候选集小时精确枚举。
驱动包络约束是**向下封闭**的（安全集的子集仍安全），因此先按包络过滤再贪心不破坏可行性。
系：先验信息 `ℐ₀` 天然提供方差下界，避免「为了信息而做危险动作」的退化。

**引理 54（2PIC 的原子性与不变式保持）** 在快照读 + 写冲突检测 + 单写者提交下，
任意并发事务执行可串行化（冲突图无环）；Abort 不留下 `φ/e` 痕迹，并把 `p` 恢复到安全等价类。
已提交事务保持 MODGAUGE 五不变式：
契约完整性（只提交通过回归的 EC）、组合单调性（热替换保持）、反作用通道完备（不改通道）、
主张绑定（证书 + 回执）、严格退化（失败 ⇒ stub + RED）。
**诚实边界**：磨损、热积累与塑性变形不可完全回滚；证书记录残余偏差并计入 `B_drive` 的代价，
因此 SI3 是「安全等价类」而非「逐位回滚」。

**引理 55（时序、驱动安全与预算）** 状态快照/提交 `O(|F| log |x|) < 5ms`（异步）；
JDA 规划 `O(L_max·M·d³) < 20ms`；耦合辨识离线/异步，可缓存。
50Hz 路径只做版本检查与脏标记 `O(1) < 0.1ms`；关节轨迹执行在异步物理域，
时长 `≤ B_drive`，进入 PROBING-I3，力矩/速度/热包络 + watchdog 硬限。
最坏修复时延 `≤ τ_repair`；预算耗尽由 2PIC Abort 强制降级 ⇒ 硬实时（引理 45）保持。

**引理 56（严格退化与等价）** 关闭关节驱动 + 单 ICC + 交换门全开 ⇒ ArtiGauge ≡ ToolGauge（逐指令等价）。
耦合图未知时取**完全图** ⇒ 单一 ICC ⇒ 全局 AP-Cal/ToolGauge 行为（安全但无隔离）；
这比「按格子瞎隔离」严格更安全。隔离设施失效 ⇒ 禁用关节驱动（因为 `P(T)` 不可控）⇒ 被动 ToolGauge；
SIP-Cal 失效 ⇒ AP-Cal；再失效 ⇒ LeanGauge ⇒ MODGAUGE。退化链严格、每级都保留正确性。

**引理 57（耦合辨识的可检测下界与保守合并）** 微激励幅度 `a`、噪声 `σ` 下，
边 `(j,k)` 的耦合 `w` 可检测当且仅当 `|w|·a/σ ≥ z_{1−δ/2}/√n`。
若置信区间包含 0（激励太弱、噪声太大或样本不足），则**必须合并**该边对应的块，
不得据「未检出」推断「无耦合」。这把「未知 ⇒ 合并」变成可计算的规则，
并给出隔离边界误判的概率上界 `≤ δ`（单边）。

## 6. 本轮最大风险（一句话）

**最大风险是耦合图/可辨识边界本身估错**：若漏掉一条隐藏的共同误差通道（典型如全机热漂移、共用电源纹波、同一批减速器回差），
隔离边界就会画在错误的位置，系统会带着「已隔离 + 已认证」的证书把相关污染放进每个块——
而状态隔离与隔离证书恰好会把这种错误包装成「已审计的安全」。
缓解是**保守上界 + 微激励主动辨识 + 未知即合并 + 交换门 + 泄漏监测**（引理 51/57、定义 443/445）。

## 2. 形式化定义（要点）

**定义 432/433（状态与足迹）** 状态 `x=(φ,p,e)` 分为契约、物理、证据三层；事务足迹 `F(T)=(R,W,P)`
显式声明读写字段与物理副作用（关节轨迹、光照、接触、热注入）。`snapshot(F)` 只读拷贝，`restore(F)` 回滚到安全等价类。

**定义 434/435（隔离事务与不变式）** 修复事务默认 I2+I3：提交时做写冲突检测与全局不变式校验，
会移动关节的事务必须工作空间互斥。SI1 未提交写不可见；SI2 已提交前缀可串行化；
SI3 物理副作用限于 `P(T)` 且事务结束回到安全等价类；SI4 每个写字段带 `(txn_id, prior_version, receipts, cert_id)`。

**定义 436/437（计量关节与关节空间）** 计量关节 `j∈𝒥` 是可驱动自由度（机械臂/基座/云台/夹爪/光照/接触/视角），
带可达构型集与驱动包络。残差线性化 `r ≈ Jδθ + b + ε`，`ℐ = JᵀΣ_obs⁻¹J`；
非线性用 Gauss-Newton 重线性化并做秩/条件数检验。

**定义 438（ICC 与合法隔离分区）** `G_𝒥` 中 `w⁺ ≥ τ_J` 的连通分量为 ICC，分区 `π_id`。
合法隔离分区 `π` 满足：(1) `π` 是 `π_id` 的粗化（不拆 ICC）；(2) 每块 `rank(J_c)=dim(θ_c)` 且 `cond(ℐ_c)≤κ_max`；
(3) 跨块归一化耦合 `λ_{c,c'}≤λ_iso`。不满足 (2)/(3) 就合并。默认取**最细合法分区**。

**定义 439/440/441（关节驱动、信息、JDA）** 驱动原语 `ξ` 受 `τ/ q̇ / q̈ / 热 / 碰撞 / 场景扰动` 包络约束，
执行时进入 **PROBING-I3**。轨迹集信息 `ℐ(S)=ℐ₀+Σ_ξ Σ_t JᵀΣ_obs⁻¹J Δt`；
JDA 解 `max_S log det ℐ(S) − λ_E·cost(S)`，s.t. 包络、`B_drive`、`L_max`、每 ICC 秩充分。
`log det` 单调次模；基数约束贪心 `≥(1−1/e)OPT`，预算约束用 cost-benefit 贪心或小规模精确枚举（引理 53）。

**定义 442（SIP-Cal）** 每个 ICC 维护私有头 `q_c(u_c|ψ,ctx_c)=N(μ_c,Σ_c)`；
共享骨干 `ψ` 只编码跨 ICC 物理超参数（噪声尺度、材质族、热扩散），事务期间**冻结只读**。
全局后验默认块对角；跨块协方差只经交换门（定义 443）开启。
元训练：`min_ψ Σ_c E[−log q_c] + β_KL KL(q_c‖p_phys,c) + λ_iso LeakagePenalty`；
保守性夹紧 `Σ_c ≽ κ_phys,c I`。

**定义 443（交换门）** 用未参与拟合的 witness 回执，比较独立与联合后验的 held-out NLL：
`Δ = NLL_ind − NLL_joint`。仅当 `Δ > δ_gate`、`rank/cond` 合法、`|ρ̂_{c,c'}|≤ρ_max` 时允许单向交换或合并；
否则隔离。用 e-value / 序贯检验控制错误共享。交换状态写入隔离证书。

**定义 444（2PIC）** Prepare（私有缓冲算 EC_c + 局部 V + 回归）→ Pre-commit（全局不变式 + 写冲突 + ICC 合法性 + 证书）
→ Commit（单写者原子热替换 + 发布证书 + 版本更新）→ Abort（回滚 `φ/e` + 物理归位 + RED）。
提交组不允许部分提交；跨组用一致割，失败整组回滚。物理磨损/热积累不可完全回滚，按安全等价类 + 补偿处理。

**定义 445（隔离粒度自适应）** 拆分：`λ̂>λ_iso` 且两侧仍 rank/cond 合法；合并：秩亏、`cond>κ_max`、`λ̂>λ_iso`
或耦合不可检测（引理 57）；事务进行中冻结分区，只在 epoch 边界变更并重验。原则：**未知 ⇒ 合并；有证据 ⇒ 拆分。**

**定义 446（隔离证书）** `Cert=(txn_id, π, {rank_c,cond_c}, F(T), snapshot_hashes, leakage_tests,
drive_envelope_compliance, rollback_hash, receipts)`。绑定进 `EC.claims`；数值主张必须同时引用回执与证书，
否则序列化时剥离（定义 423 扩展）。

**定义 447（继承与退化）** 沿用定义 398–431。关闭关节驱动 + 单 ICC + 交换门全开 ⇒ ArtiGauge ≡ ToolGauge。
隔离设施失效 ⇒ 禁用关节驱动 ⇒ 被动 ToolGauge；SIP-Cal 失效 ⇒ AP-Cal；再失效 ⇒ LeanGauge ⇒ MODGAUGE。

## 3. 关键算法骨架

```python
# IP-321 S-Box：状态隔离事务（快照 / 私有写 / 冲突检测 / 2PIC）
class SBox:
    def begin(self, s, fp):
        return STxn(new_id(), s, fp, snap=self.snapshot(fp.R), write_buf={}, phys_log=[])
    def commit(self, txn, ec_bundle, cert):
        if not cert.valid():                      return self.abort(txn, "isolation_cert")
        if self.write_conflict(txn):              return self.abort(txn, "conflict")
        if not self.global_invariants(ec_bundle): return self.abort(txn, "invariant")
        self.apply_atomic(txn.write_buf, ec_bundle, cert)   # 单写者
        self.publish(cert); return True
    def abort(self, txn, why):
        self.restore(txn.snap); self.physical_home(txn.phys_log)
        self.record_red(txn, why); return False

# IP-322 J-Box：微激励辨识耦合图 + ICC 分区
class JBox:
    def estimate_coupling(self, joints, envelope):
        W = {}
        for (j, k) in pairs(joints):
            r = self.execute(micro_excite(j, k, envelope))   # PROBING-I3
            W[(j, k)] = conservative_upper(self.response(r, j, k))
        return ArticulationGraph(W)
    def icc_partition(self, G, tau_J, kappa_max):
        comps = connected_components(G, weight_upper=tau_J)
        return merge_until_identifiable(comps, kappa_max)    # 只合并不拆分

# IP-323 JDA：关节空间 D-最优激励
class JDA:
    def plan(self, partition, envelope, budget, L_max):
        cand = [xi for xi in self.candidate_trajectories()
                if envelope.safe(xi) and xi.disturbance <= D_max]
        f = lambda S: logdet(I0 + sum(A(xi) for xi in S))
        return greedy_submodular(cand, f, cost=lambda xi: xi.cost,
                                 budget=budget, k=L_max, cover=partition)

# IP-324 SIP-Cal：分区摊销先验 + 交换门
class SIPCal:
    def calibrate(self, receipts, partition, backbone, freeze_exchange=False):
        posts = {}
        for c in partition:
            mu, Sig = self.head[c](backbone, select(receipts, c))  # 私有头；骨干冻结
            posts[c] = (mu, clamp_min(Sig, KAPPA_PHYS[c]))
        return posts
    def exchange_gate(self, posts, witness):
        return {(c, d): self.test_share(posts, witness, c, d)
                for c in posts for d in posts if c != d}

# IP-325 ArtiGauge-8C
def artigauge_8c(M, s):
    txn = M.sbox.begin(s, footprint(s))                         # I
    partition = M.iso_sup.current_partition(s)                  # I（ICC）
    H = M.lbox.hypothesize(s, M.dbox.R[s])                      # H
    drive = M.jda.plan(partition, M.envelope, M.budget_drive(s))# J
    prog = M.tbox.compile(H, drive)                             # C
    if not M.tcv.verify(prog, M.budget_tools(s)):               # C
        prog, drive = M.numeric_fallback(H), []
    receipts = M.tcv.execute(prog, M.env, isolation=txn)        # E（PROBING-I3）
    if effective_n(receipts) < n_min(s):                        # n_eff 门槛
        return M.sbox.abort(txn, "insufficient_evidence")
    posts = M.sipcal.calibrate(receipts, partition, M.backbone) # C
    if not M.sipcal.exchange_gate(posts, M.witness(s)):         # V
        posts = M.sipcal.calibrate(receipts, partition, M.backbone, freeze_exchange=True)
    ec_bundle = M.dpe.update_partitioned(posts, partition)      # U
    cert = IsolationCert(txn, partition, posts, receipts, M.sbox.snapshot_hash(txn))
    if not cert.valid() or not M.contract_regression(ec_bundle):
        return M.sbox.abort(txn, "verify_failed")               # 原子回滚
    if not M.sbox.commit(txn, ec_bundle, cert): return False    # 2PIC
    M.mreg.hot_replace_partitioned(ec_bundle)
    M.dbox.update_from_partitioned_posterior(posts)
    M.iso_sup.observe_leakage(posts, receipts)
    return True

# IP-326 主闭环
def ArtiGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(artigauge_8c, M, s)
    if not M.sbox.healthy() or not M.iso_sup.healthy():
        M.disable_joint_drive = True                            # 先禁物理驱动
        M.use_toolgauge_fallback = True                         # 再退回被动 ToolGauge
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导（引理 51–57）

**引理 51（隔离-污染分解界）** `π` 合法，`ℐ` 全 Fisher，`ℐ_π` 块对角，块 Schur 耦合
`E_c=ℐ_{c,-c}ℐ_{-c,-c}⁻¹ℐ_{-c,c}`，`λ_π=max_c‖ℐ_cc^{-1/2}E_cℐ_cc^{-1/2}‖^{1/2}`。则
(a) `(ℐ⁻¹)_cc=(ℐ_cc−E_c)⁻¹`，块隔离给 `ℐ_cc⁻¹`，二者之差负半定（隔离低估方差、过度自信），
相对误差 `≤λ_π²/(1−λ_π²)=O(λ_π²)`；
(b) 若块 `c` 先验污染 TV 偏差 `ε_c`，泄漏到 `c'` 的偏差 `≤Cλ_π ε_c/(1−λ_π²)`，全局污染质量
`≤Σ_c ε_c + Cλ_π Σ_c ε_c`，不再是「一次污染全部」；
(c) 交换门关闭时唯一全局通道是骨干 `ψ`，必须低维、冻结、可版本回滚——**否则隔离了头，没隔离骨干**。
系：`λ_π≤λ_iso` ⇒ 任务风险差 `≤L_task C₀ λ_iso √d`。

**引理 52（可辨识-隔离对偶）** (a) 若拆到 `rank(J_c)<dim(θ_c)`，`ℐ_c` 奇异，有限方差估计不存在 ⇒ ICC 不可拆（硬下界）；
(b) 合法拆分下忽略跨块项使 `ℐ_cc≥ℐ_cc−E_c`，故 `ℐ_cc⁻¹⪯(ℐ⁻¹)_cc`，块隔离系统性过度自信，过度量由 `E_c` 控制；
(c) 合并独立块统计上安全但把污染局部→块内扩大，故**最细合法分区**在保持可辨识性的同时最小化污染扩散。
推论 52.1：从 ICC 分区出发，合并所有 `λ_{c,c'}>λ_iso` 的块对，迭代至不动点，得最细合法分区；单调、有限步终止。

**引理 53（JDA 次模近似与安全过滤）** `f(S)=log det(ℐ₀+Σ_{ξ∈S}A_ξ)`，`A_ξ⪰0`，`f` 单调次模。
基数约束 `|S|≤L_max` 贪心 `≥(1−1/e)OPT`；预算约束用 cost-benefit 贪心 `≥(1−1/e)/2`，或 `L_max≤6` 小候选集精确枚举。
驱动包络向下封闭（安全集子集仍安全），先过滤再贪心不破坏可行性。先验信息 `ℐ₀` 提供方差下界，避免危险动作。

**引理 54（2PIC 原子性与不变式）** 快照读 + 写冲突检测 + 单写者提交 ⇒ 可串行化（冲突图无环）；
Abort 不留 `φ/e` 痕迹并把 `p` 恢复到安全等价类。已提交事务保持 MODGAUGE 五不变式：
契约完整性、组合单调性、反作用通道完备、主张绑定（证书+回执）、严格退化（stub+RED）。
诚实边界：磨损/热积累/塑性变形不可完全回滚，证书记录残余偏差并计入 `B_drive`，SI3 是安全等价类而非逐位回滚。

**引理 55（时序与驱动安全）** 快照/提交 `O(|F| log|x|)<5ms`（异步）；JDA `<20ms`；耦合辨识离线可缓存；
50Hz 路径仅版本检查 `O(1)<0.1ms`；关节执行异步、`≤B_drive`、PROBING-I3、力矩/速度/热包络 + watchdog；
最坏修复 `≤τ_repair`，预算耗尽由 Abort 强制降级 ⇒ 硬实时保持。

**引理 56（严格退化与等价）** 关闭关节驱动 + 单 ICC + 交换门全开 ⇒ ArtiGauge ≡ ToolGauge；
耦合图未知 ⇒ 完全图 ⇒ 单 ICC ⇒ 全局 AP-Cal/ToolGauge（安全但无隔离，严格优于「按格子瞎隔离」）；
隔离设施失效 ⇒ 禁用关节驱动 ⇒ 被动 ToolGauge；SIP-Cal 失效 ⇒ AP-Cal ⇒ LeanGauge ⇒ MODGAUGE。

**引理 57（耦合可检测下界与保守合并）** 微激励幅度 `a`、噪声 `σ` 下，耦合 `w` 可检测当且仅当
`|w|a/σ ≥ z_{1−δ/2}/√n`。若置信区间含 0，则**必须合并**该边对应块，不得据「未检出」推断「无耦合」。
这把「未知 ⇒ 合并」变成可计算规则，并给出隔离边界误判概率上界 `≤δ`（单边）。

## 8. 本轮最大风险

**一句话**：最大风险是**耦合图/可辨识边界本身估错**——漏掉一条隐藏的共同误差通道（全机热漂移、共用电源纹波、
同批减速器回差）会让隔离边界画在错误位置，系统带着「已隔离 + 已认证」的证书把相关污染放进每个块；
状态隔离与隔离证书反而放大这种虚假安全感。
缓解：保守上置信界、微激励主动辨识、**未知即合并**、交换门 held-out 检验、按 ICC 泄漏监测与两阶段回滚（引理 51/57、定义 443/445/446）。
