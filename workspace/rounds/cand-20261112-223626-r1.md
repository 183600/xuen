# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC / IP-173~182；灵感循环第 8 轮；本轮灵感：「热管理」×「深度学习」）

> 第 61 轮把固定基座的「场景→意图→约束→阻抗→证据」统一进 USR，用 MEL 做零样本物理属性推断、DMS 做多轮对话接地、SRT-Dual 解耦语义流与实时流。但那套闭环**隐含了一个从未被检验的热力学假设**：
> 1. **执行器无限热容假设**：EEIS 编译 `K_safe` 时只问「力矩是否超额定」，不问「线圈是否正在过热」。长时间高刚度接触、堵转、频繁启停会让铜损 `I²R` 累积，导致绝缘老化、磁体不可逆退磁、力矩常数漂移——而这些都以**分钟级**发生，完全落在 1 ms 实时控制的盲区。
> 2. **热-力解耦假设**：温度升高使可用力矩下降（`τ_max(T)` 降额），名义上可行的 `K_p` 在热学上可能不可行；同时连杆热膨胀会改变运动学零点与接触几何，使第 61 轮的几何/语义锚点悄悄失效。**热是唯一一个会同时改写「能力」与「几何」的慢变量。**
> 3. **语义缺少热通道**：RGB 与触觉无法区分外观相同、热物性迥异的材质（金属/塑料/陶瓷/复合材料）。热成像与「刚接触瞬间的温度瞬态」天然携带热扩散率/热积信息，是**零样本材料先验**，但第 61 轮的 `φ_phys=(μ,k,η,σ)` 没有热维度。
> 4. **算力热节流**：MEL 在边缘 SoC 上推理会升温→降频→时延非线性上升。`B_mel` 只计 token 与时延，不计「热成本」，于是「多推理」既烧算力预算也烧热预算，SRT-Dual 的语义流时效在长时间运行后会被热节流击穿。
> 5. **热债不可瞬时偿还**：与 token 预算不同，热不能「下一周期清零」。热债的偿还时间常数是分钟级，必须**前瞻预测 + 提前调度**，而不是事后告警。

## 0. 直觉与动机

**灵感 1（热管理 → 热-力可行域 TIFS：把降额曲线变成阻抗约束）**
直觉：电机的「温度-扭矩降额曲线」是一张现成的安全边界，但传统上只用于告警和粗暴限流。关键洞见：阻抗产生的末端力 `f=K_pΔx+K_dΔẋ` 经接触雅可比 `J_c^T` 映射为关节力矩，于是「每个关节不超过当前温度允许的力矩」可以写成**对 `K` 的概率约束**——给定扰动分布 `e∼N(0,Σ_e)`，`τ_j` 是高斯，约束 `P(|τ_j|≤ρ_j(T)τ_rated,j)≥1−α` 等价于一个方差上界。更锋利的一点：`K` 越小→铜损越小→温度越低→`ρ` 越大，存在**单调不动点**，可以从 `s=1` 开始只允许「更保守」地迭代，得到毫秒级可证明的热降额因子 `s_th`。

**灵感 2（深度学习 → 深度热世界模型 DHT-WM：分钟级可预测的热场）**
直觉：热是多物理场、跨连杆传导、边界对流依赖姿态与气流的强非线性过程，手写集总模型在真实机器人上必然漂移。关键洞见：用**图神经 ODE 建模运动链传导 + 傅里叶神经算子建模连杆表面温度场 + 潜状态空间模型做长时程滚动 + PINN 热方程残差约束**，学习 `(关节温度, 力矩历史, 姿态, 环境温度, 气流)→未来 30–300 s 温度场`。再用深度集成 + 保形预测给出**温度上置信界 `T_UCB`**，把「预测」变成可进证书的「带概率保证的约束」。热参数（热阻/热容/对流系数）用在线递推辨识持续校正，避免 sim2real 漂移。

**灵感 3（热惯性 × 接触热瞬态 → 热-语义材料推断 TSM）**
直觉：当手指刚接触物体时，界面温度瞬态由两侧热积 `e=√(λρc)` 决定：金属抽热快、塑料抽热慢、陶瓷介于其间。关键洞见：**用可微一维热仿真拟合接触瞬态**，从 `T_s(t)` 反演物体热积 `e_o` 与接触换热系数 `h_c`，把热物性作为新的语义通道注入 MEL；热成像再提供发射率与空间热场。对视觉同色同形的金属/塑料件，热通道是**决定性的零样本判别器**。

**灵感 4（多时间尺度 → 四时钟热-语义-实时架构 SRT-Thermal）**
直觉：热流（0.1–1 Hz）比语义流（10–100 Hz）慢两个数量级，比实时流（1–10 kHz）慢三到四个数量级。关键洞见：**绝不能让热预测进入实时关键路径**。热流每 1–2 s 计算一次 `s_th` 与冷却计划，写入热状态锚；实时流只做一次 O(d²) 的标量乘 `K_safe=s_th·K_prior`，并用硬件温控作为独立最后防线。热锚点有独立 TTL，过期即冻结降额、只允许更保守。

**灵感 5（任务协商 → 热感知对话管理 DMS-T）**
直觉：热约束会产生「机器人想休息但用户想继续」的真实冲突。关键洞见：把 `request_rest / propose_derate / reorder_tasks / cool_pose` 加入对话动作空间，用热债与剩余热余量做奖励项；用户可协商，但**安全层对用户意图拥有一票否决**——这是「对话接地」在物理约束下的正确边界。

**灵感 6（预算 → PCE++++++ 七维认知-热预算）**
直觉：热不是无限资源，也不能被瞬时重置。扩展为 `B_cog7=(B_scene,B_intent,B_ros,B_exec,B_mel,B_usr,B_therm)`，其中 `B_therm=(H_th,min, D_th,max, Cooling_ops, T_sensor_freq, WM_calls)`。VOI 加入**热机会成本**：现在多干一点，会让未来几分钟少干很多。

**本轮的核心科学问题（一句话）**：如何把「热」这一慢变、不可逆、全身耦合、部分可观测的物理量，变成跨时间尺度**可预测、可证明安全**的约束，并反过来作为材料/语义先验，使具身系统在热约束下**优雅降级而不牺牲安全**？

## 1. 形式化定义（增量：定义 173–184）

**定义 173（热状态锚 THA）** 在语义锚之上增加一层慢变量快照：
```
A_t^th = (version, T_joint ∈ R^n, \hat T_field, z_th, Σ_th,
          H_th, D_th, s_th, r_th, cooling_plan, ts)
```
- `T_joint`：各关节线圈/壳体温度测量（热电偶或绕组电阻估计）
- `\hat T_field`：DHT-WM 预测的连杆表面温度场；`z_th`：热模态嵌入
- `Σ_th`：热状态后验协方差；`r_th`：最近热模型残差（校准/漂移指标）
- `H_th = min_j (T_lim,j − \hat T_j^{UCB})`：热余量；`D_th = ∫Σ_j max(0,T_j−T_soft,j)dt`：热债
- `s_th ∈ [0,1]`：当前热降额因子；`cooling_plan`：未来一个热周期的冷却动作序列
- 关键：语义锚可以「新鲜」，而热锚可能「已进入不可恢复区」；两者**必须分开验证**。

**定义 174（关节-连杆热动力学 THD）** 集总关节模型 + 连杆场模型：
```
C_th,j · dT_j/dt = τ_j²/κ_j + Σ_k G_jk(T_k − T_j)
                   − h_j(pose, airflow)·(T_j − T_amb) − Q_contact,j
ρ_j(T) = clip((T_lim,j − T)/(T_lim,j − T_rated,j), 0, 1)
τ_max,j(T) = ρ_j(T) · τ_rated,j
连杆场: ρ_m c_p ∂T/∂t = ∇·(λ_m ∇T) + q_vol,
边界: −λ_m ∂T/∂n = h_conv(pose,airflow)(T − T_amb) + εσ_SB(T⁴ − T_env⁴)
```
其中 `τ_j²/κ_j` 是铜损发热（`κ_j` 为电机常数折算），`G` 为传导耦合矩阵，`h_j` 依赖位形与气流。`ρ_j` 是标准热降额曲线。

**定义 175（热-力阻抗可行域 TIFS）** 把降额曲线变成对 `K` 的概率约束：
```
TIFS(Σ_e, α, H) = { K : e ∼ N(0, Σ_e), f = K e, τ = J_c^T f,
   ∀j, ∀h ∈ [0,H]: P( |τ_j| ≤ ρ_j( \hat T_j^{UCB}(t+h) ) · τ_rated,j ) ≥ 1−α,
   K ⪰ 0, K_d ⪰ K_d,min ≻ 0 }
```
单侧概率约束等价于
```
z_{1−α/2} · sqrt( g_j^T K Σ_e K^T g_j ) ≤ ρ_j( \hat T_j^{UCB}(t+h) ) · τ_rated,j
```
其中 `g_j` 是 `J_c` 的第 `j` 行（`J_c` 为接触雅可比）。对 `K` 的齐次缩放 `s·K` 使左端线性，因此存在闭式保守降额（见产物区推导）。

**定义 176（深度热世界模型 DHT-WM）** 学习式长时程热预测器：
```
\hat T_{t+1} = F_θ(T_t, q_t, pose_t, a_t, T_amb)
             = T_t + Δt ⊙ C_th^{-1}( q_t − H(pose_t)(T_t − T_amb) + G T_t )
               + g_θ(z_t, pose_t)                       # 残差学习
z_t = LatentSSM(z_{t−1}, T_t, q_{t−K:t})                # 长时程潜状态
\hat T_field = FNO_θ(T_t, q_t, pose_t, boundary)        # 表面温度场
```
- `FNO_θ`：傅里叶神经算子，分辨率无关地学习 `(热源, 边界)→温度场`
- `g_θ`：运动链图神经网络（节点=关节/连杆，边=传导/对流耦合）
- 物理损失：`L = L_data + λ_pde·L_pde + λ_E·L_energy + λ_mono·L_mono`
- 不确定性：`M=5` 深度集成 + 保形校准，输出 `\hat T^{UCB} = \hat T + q_{1−α}(residual)`
- 在线辨识：用稀疏温度测点对 `(R_th, C_th, h(pose,airflow))` 做递推最小二乘/扩展卡尔曼更新

**定义 177（热-算力耦合模型 TCM）** 把 SoC 热节流纳入语义流预算：
```
C_soc · dT_soc/dt = P_comp(m, tokens, f) − h_soc(T_soc − T_amb)
f(T_soc) = f_max · clip( (T_soc,max − T_soc)/(T_soc,max − T_throttle), f_min/f_max, 1 )
L_mel(m, T_soc) = L_m(m) · f_max / f(T_soc)              # m ∈ {full, distill, cached, frozen}
```
热感知调度在预测时域上求解
```
m* = argmax_m  VOI_sem(m) − λ_L·L_mel(m,T_soc) − λ_T·ΔT_soc^+(m)
     s.t.  max_h T_soc(t+h) ≤ T_soc,lim,   L_mel ≤ τ_sem_max
```

**定义 178（热-语义材料推断 TSM）** 用接触热瞬态反演热物性：
```
物体: ∂T_o/∂t = α_o ∇²T_o,  α_o = λ_o/(ρ_o c_o),  e_o = sqrt(λ_o ρ_o c_o)
界面: q'' = h_c (T_o,s − T_s,s)
传感器: C_s dT_s/dt = q'' A − h_s(T_s − T_amb)
观测: T_s(t), t ∈ [0, t_contact]
反演: (e_o*, h_c*, T_o*) = argmin ∫ ||T_s^meas(t) − T_s^sim(t; e_o,h_c,T_o)||² dt
```
`e_o` 映射为材质/摩擦/脆性先验 `φ_th = (e_o, λ_o, α_o, ε_ir)`，与第 61 轮 `φ_phys` 拼接为
`φ_phys^+ = (μ, k, η, σ, e_o, λ_o, α_o, ε_ir)`；热成像嵌入 `z_th^ir = E_ir(V_ir)` 提供空间热场先验。

**定义 179（七维认知-热预算 PCE++++++）**
```
B_cog7 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_therm)
B_therm = (H_th,min, D_th,max, Cooling_ops, T_sensor_freq, WM_calls)
D_th(t) = ∫_0^t Σ_j max(0, T_j(s) − T_soft,j) ds
H_th(t) = min_j ( T_lim,j − \hat T_j^{UCB}(t) )
voi_7(a) = VOI_meta(a) − cost_mel(a) − cost_usr(a) − cost_exec(a)
           − λ_H·max(0, H_th,min − H_th^+(a))
           − λ_D·ΔD_th(a) − λ_E·E_cool(a)
```
级联降级（安全项永不降级）：
```
H_th < H_soft  ⇒ 降低 K_p、切换冷却位形、禁止高发热任务
H_th < H_warn  ⇒ DMS-T 请求休息/降速；THCS 切 distill/cached 模式
H_th < H_min   ⇒ 冻结高发热任务、最大冷却；仍不满足 ⇒ 安全停
```

**定义 180（热感知对话管理 DMS-T）**
```
A_T = A_DMS ∪ {request_rest(Δt), propose_derate(r), reorder_tasks(π),
               cool_pose(π_cool), report_thermal(T_UCB,H_th)}
R_T(s,a) = task_complete − λ_cog·load − λ_safe·risk
           − λ_th·D_th − λ_E·energy − λ_t·latency
硬约束: π_dms 只能输出 K ∈ TIFS 的约束提案；用户「继续」的意图不能越过安全停
```
`report_thermal` 把内部温度上界以自然语言/可视化反馈给用户，使「休息 20 s」的请求可解释、可协商。

**定义 181（热-语义-执行联合证书 J_thermal）**
```
J_thermal = ( J_sem_exec,
              \hat T^{UCB}_{t:t+H}, s_th, H_th, D_th, r_th,
              κ_cal, cooling_plan, dhtwm_version, anchor_version )
Valid(J_thermal) ⇔ Valid(J_sem_exec)
   ∧ ∀j, ∀h∈[0,H]: \hat T_j^{UCB}(t+h) ≤ T_lim,j
   ∧ s_th ≥ s_min
   ∧ r_th ≤ ε_th
   ∧ D_th ≤ D_th,max
   ∧ (s_th < 1 ⇒ 降额已实际作用于 K_safe)
```

**定义 182（热一致性跨模态对账 XMC-T）** 在 USR 对账中加入热残差：
```
D⁺_th = ‖T_meas − \hat T‖²_{Σ_th^{-1}}
        + ‖z_th^ir − E_ir(V_ir)‖²
        + |e_o^fit − e_o^prior| / σ_e
        + 1[ H_th < H_warn ]
if D⁺_th > τ_th: 触发 DHT-WM 在线辨识 / MEL 重推理 / 冷却动作重规划
```

**定义 183（热-具身语义进化闭环 THEEC）** 四时钟统一算子：
```
THEEC(M, V, V_ir, T, P, L, δ_f):
  # 热流（0.1–1 Hz）
  T_meas ← read_thermistors();  z_th ← E_ir(V_ir)
  \hat T, Σ_th ← DHT-WM.predict(T_meas, q_hist, pose_hist)
  H_th, D_th, s_th ← budget.update(\hat T^{UCB})
  A^th ← THA.commit(\hat T, z_th, H_th, D_th, s_th)
  # 语义流（10–100 Hz）
  φ^+, z_scene, π, U ← MEL.infer(V, T, P, L, z_th, A)
  a_diag ← DMS-T.step(U, H_th, D_th, EV_exec)
  A ← USR.commit(z_scene, E_intent(b_intent), φ^+, A^th)
  # 实时流（1–10 kHz，绝不等热流）
  A^th ← THA.read_latest()
  K_prior ← Π(A.scene_emb + A.intent_emb)
  K_safe ← TDIC.compile(K_prior, s_th, A^th)
  EV_exec ← ERTC.dispatch(K_safe)
  J_thermal ← certify(EV_exec, A^th, J_sem_exec)
  return M, K_safe, EV_exec, J_thermal
```

**定义 184（热可恢复性与 T_rec-韧性）** 判断「休息一会儿」是否真的够：
```
无热源冷却时 T_j(t) = T_amb + (T_j(0) − T_amb)·e^{−t/τ_th,j}
恢复至软限所需时间 τ_rec,j = τ_th,j · ln( (T_j(0)−T_amb)/(T_soft,j−T_amb) )
状态 x 是 T_rec-韧性的 ⇔ max_j τ_rec,j ≤ T_rec
否则必须升级为安全停 / 人工介入，而不是承诺一个做不到的休息时长
```
这一条把 DMS-T 的「请求休息 Δt」从语言承诺变成**可验证的物理可行性检查**。

## 2. 本轮最大风险（一句话）

**最大风险**：若 DHT-WM 在真实环境（气流突变、接触换热、长时间负载）下系统性低估最热关节，预测式降额会「太晚太小」，导致高价值任务进行到一半时不可逆退磁或热停；更危险的是，热漂移会同时污染温度测点与力矩证据，使模型用被污染的残差自我确认「还很安全」——形成**热盲区自证**；必须以保形上界、独立硬件热熔断、以及「预测永不下调安全阈值」三重护栏，确保安全不依赖学习模型。

## 2. 核心推导：热-力耦合、预测式降额与热可恢复性

### 2.1 从「温度-力矩降额」到「阻抗概率约束」

给定阻抗 `K=[K_p K_d]` 与扰动 `e=[Δx;Δẋ]∼N(0,Σ_e)`，末端力 `f=Ke`，接触雅可比 `J_c`（`n×6`），关节力矩 `τ=J_c^T f`。第 `j` 个关节的力矩为线性泛函
```
τ_j = g_j^T K e,     g_j = J_c[j,:]^T
Var(τ_j) = g_j^T K Σ_e K^T g_j ≜ σ_{τ,j}²
```
于是热-力概率约束
```
P(|τ_j| ≤ ρ_j(T)·τ_rated,j) ≥ 1−α
⇔ z_{1−α/2}·σ_{τ,j} ≤ ρ_j(T)·τ_rated,j
```
**关键性质（对齐次）**：令 `K←sK`，则 `τ_j←sτ_j`、`σ_{τ,j}←sσ_{τ,j}`，约束左端对 `s` 线性。因此对**给定温度**的瞬时最大安全缩放为
```
s_max(T) = min_j  ρ_j(T)·τ_rated,j / ( z_{1−α/2}·σ_{τ,j}(K_prior) )
s_th     = clip( min(1, s_max(T)), 0, 1 )
K_safe   = clip_impedance( s_th·K_prior, K_min, K_max )
```
这一步是 O(n·d²) 的矩阵-向量运算，微秒级可完成（热流频率下算一次，实时流只做标量乘）。

### 2.2 预测式降额的不动点：K↓ ⇒ 发热↓ ⇒ 温度↓ ⇒ 允许 K↑

温度本身依赖 `K`：铜损 `q_j=τ_j²/κ_j ∝ s²`。定义预测时域 `[0,H]` 上的保守映射
```
Φ(s) = min_j  ρ_j( \hat T_j^{UCB}(H; s) )·τ_rated,j / ( z·σ_{τ,j}(K_prior) )
```
其中 `\hat T^{UCB}(H;s)` 由 DHT-WM 在「保持 `sK_prior`」假设下滚动得到。

- `s↑ ⇒ q↑ ⇒ \hat T↑ ⇒ ρ↓ ⇒ Φ↓`，故 `Φ` 单调不增；
- 目标是不动点 `s* = min(1, Φ(s*))`；
- 取迭代 `s_0=1, s_{k+1}=min(s_k, Φ(s_k))`，序列单调不增且有下界 `≥0`，必收敛；
- 因每一步取 `min`，迭代值**永不低于**真实可行缩放，故是**保守（安全侧）**近似；实测 2–3 次即收敛（`|Δs|<1e-3`）。

**工程实现**：热流每 1–2 s 用 WM 滚动一次并解上述不动点，得到 `s_hold`；实时流只读 `s_hold`，绝不在 1 kHz 环内调用神经网络。热锚 `T_UCB` 过期时 `s_hold←min(s_hold, s_stale)`（只降不升），并触发保守扩展。

### 2.3 热债、热余量与「热 CBF」：把长期热管理变成每周期约束

定义热余量 `H_th(t)=min_j(T_lim,j−\hat T_j^{UCB}(t))` 与热债 `D_th(t)=∫Σ_j max(0,T_j−T_soft,j)dt`。对 `H_th` 用控制屏障函数（CBF）约束：
```
Ḣ_th ≥ −α_cbf·H_th,   α_cbf > 0
```
由于 `Ḣ_th ≈ −k·Σ_j τ_j²/κ_j + cooling`（发热项为二次），上述约束等价于对总发热功率的逐周期上界
```
Σ_j τ_j²/κ_j ≤ [ α_cbf·H_th + cooling ] / k ≜ q_max
```
再由 `τ_j² ∝ s²` 得功率降额 `s_q = sqrt(q_max / q_nominal)`，最终取
```
s_th = min(s_torque, s_q, 1)
```
这样「未来几分钟不过热」被压缩成「本周期发热不超 `q_max`」，既保留 CBF 的安全性，又让实时层只需一次标量比较。

### 2.4 热可恢复性：DMS-T 的「休息 20 秒」必须可证明

无热源时关节按 `T_j(t)=T_amb+(T_j(0)−T_amb)e^{−t/τ_th,j}` 冷却，恢复到软限 `T_soft,j` 所需时间
```
τ_rec,j = τ_th,j·ln( (T_j(0)−T_amb)/(T_soft,j−T_amb) )
```
若 `max_j τ_rec,j > Δt_requested`，DMS-T **不得**承诺该休息时长，必须改为更长休息、降低负载、或安全停。这把语言层的「等一会儿」与物理层的热时间常数对齐，避免「答应了却恢复不了」。

### IP-184 DHT-WM（深度热世界模型）

```python
class DeepThermalWorldModel(nn.Module):
    def __init__(self, n_joints, d_latent=64, horizon=120, n_ens=5):
        super().__init__()
        self.n_joints = n_joints
        self.horizon = horizon
        self.dt = 0.5  # s, 热流步长

        # 物理参数（在线辨识）
        self.theta = ThermalParams(n_joints)  # R_th, C_th, h(pose), G, kappa

        # 学习组件
        self.gnn = KinematicThermalGNN(d_node=32, n_layers=4)       # 运动链传导/对流
        self.fno = FourierNeuralOperator(in_ch=4, width=32, modes=12)  # 表面温度场
        self.ssm = LatentSSM(d_obs=2 * n_joints + 4, d_latent=d_latent)  # 长时程潜状态
        self.heads = nn.ModuleList([ThermalHead(d_latent) for _ in range(n_ens)])

        # 不确定性与校准
        self.calibrator = ConformalCalibrator(alpha=0.05)
        self.online_rls = RLSIdentifier(dim=3 * n_joints)  # R_th,C_th,h

    def physics_rhs(self, T, q, pose, T_amb, airflow):
        # C * dT/dt = q - h(pose,airflow)*(T-Tamb) + G @ T
        C = self.theta.C
        h = self.theta.convection(pose, airflow)   # 位形/气流相关
        G = self.theta.G
        return (q - h * (T - T_amb) + G @ T) / C

    def rollout(self, T0, q_hist, pose_seq, T_amb, airflow):
        z = self.ssm.encode(T_hist=T0, q_hist=q_hist[-20:])
        T = T0.clone()
        T_pred, field_pred = [], []
        for h in range(self.horizon):
            q = q_hist[-1]
            dT_phys = self.physics_rhs(T, q, pose_seq[h], T_amb, airflow)
            dT_res = self.gnn(z, pose_seq[h])          # 学习残差（未建模传热）
            T = T + self.dt * (dT_phys + dT_res)
            T_pred.append(T)
            field_pred.append(self.fno(T, q, pose_seq[h]))
            z = self.ssm.step(z, T, q)
        T_pred = torch.stack(T_pred)
        mem = torch.stack([head(z) for head in self.heads])  # [n_ens, H, n]
        mu = mem.mean(0)
        sigma = mem.std(0) + 1e-6
        return mu, sigma, torch.stack(field_pred)

    def upper_bound(self, T_pred, sigma):
        # 深度集成 + 保形残差分位数：无分布校准上界
        q = self.calibrator.quantile()                 # 离线校准，在线只读
        return T_pred + 1.96 * sigma + q

    def train_step(self, batch):
        T_pred, sigma, fields = self.rollout(batch.T0, batch.q, batch.pose,
                                             batch.T_amb, batch.airflow)
        L_data = gaussian_nll(T_pred, batch.T_future, sigma)
        L_pde = heat_equation_residual(fields, batch.q, batch.pose, self.theta)
        L_energy = energy_balance_residual(T_pred, batch.q, self.theta)
        L_mono = torch.relu(-(T_pred[:, 1:] - T_pred[:, :-1])).mean()  # 有热源时不应无故降温
        return L_data + 0.1 * L_pde + 0.1 * L_energy + 0.01 * L_mono

    def online_update(self, T_meas, q_meas, pose, T_amb, airflow):
        # 递推最小二乘更新 R_th/C_th/h；只在热流低频调用
        theta_new = self.online_rls.step(T_meas, q_meas, pose, T_amb, airflow)
        self.theta.blend_(theta_new, beta=0.1)
        self.calibrator.update_residual(T_meas - self.last_pred)
```

### IP-185/186 TIFS + TDIC（热-力可行域与热降额编译器）

```python
class ThermalDeratedImpedanceCompiler:
    def __init__(self, alpha=0.05, s_min=0.2):
        self.z = norm.ppf(1 - alpha / 2)
        self.s_min = s_min
        self.s_hold = 1.0
        self.version = -1

    def torque_std(self, K, Sigma_e, Jc):
        # K: [6,6]; Sigma_e: [12,12]; Jc: [n,6] 接触雅可比
        KS = K @ sqrt_psd(Sigma_e)          # [6,12]
        Tau = Jc @ KS                       # [n,12]
        return np.linalg.norm(Tau, axis=1)  # sigma_tau per joint

    def derate(self, K_prior, T_ucb, T_lim, T_rated, tau_rated, Sigma_e, Jc):
        rho = np.clip((T_lim - T_ucb) / np.maximum(T_lim - T_rated, 1e-6), 0.0, 1.0)
        sigma = self.torque_std(K_prior, Sigma_e, Jc) + 1e-9
        s_torque = float(np.min(rho * tau_rated / (self.z * sigma)))

        # 热-CBF 导出的发热功率降额（见 2.3）
        q_nom = np.sum(self.torque_std(K_prior) ** 2 / kappa)
        s_power = float(np.sqrt(max(q_allow, 0.0) / max(q_nom, 1e-9)))

        return float(np.clip(min(1.0, s_torque, s_power), 0.0, 1.0))

    def update_hold(self, K_prior, wm, T0, q_hist, pose_seq, T_amb, airflow):
        """热流调用：解预测式不动点，得到未来一个热周期的 s_hold。"""
        s = 1.0
        for _ in range(3):
            T_ucb = wm.rollout_under(K_prior * s, T0, q_hist, pose_seq,
                                     T_amb, airflow)   # 预测时域 H 上的 UCB
            s_new = self.derate(K_prior, T_ucb[-1], ...)
            if abs(s_new - s) < 1e-3:
                break
            s = min(s, s_new)          # 只允许更保守，保证单调安全
        self.s_hold = s
        return s

    def compile(self, K_prior, anchor_th):
        """实时流调用（1–10 kHz）：零神经网络，仅标量乘 + clip。"""
        if anchor_th is None or anchor_th.ts stale:
            self.s_hold = min(self.s_hold, self.stale_floor)
        if anchor_th is not None and anchor_th.version != self.version:
            self.s_hold = anchor_th.s_th          # 热流已算好，直接采用
            self.version = anchor_th.version
        K_safe = clip_impedance(self.s_hold * K_prior, K_min, K_max)
        return K_safe, self.s_hold
```

```python
class ThermalSemanticMaterialInference(nn.Module):
    def __init__(self, d_phys=8, d_latent=128):
        super().__init__()
        self.encoder = ThermalTransientEncoder(d_latent)  # 温度瞬态 + 接触力 + 热图像
        self.heat_solver = Differentiable1DHeatSolver()    # 可微热仿真
        self.head = nn.Sequential(
            nn.Linear(d_latent, 128), nn.GELU(),
            nn.Linear(128, 2 + 3)   # (e_o mean, log_std, h_c, T_o, log_sigma)
        )

    def forward(self, T_s_seq, F_contact, T_ir=None, T_s0=None):
        z = self.encoder(T_s_seq, F_contact, T_ir)
        e_mean, e_logstd, h_c, T_o, log_sig = self.head(z).split([1, 1, 1, 1, 1], dim=-1)
        e_o = F.softplus(e_mean) + 1e-3
        T_s_sim = self.heat_solver(e_o, F.softplus(h_c), T_o, T_s0, T_s_seq.shape[-1])
        aux = F.mse_loss(T_s_sim, T_s_seq)                 # 物理一致性自监督
        # 热积 -> 热物性与材质先验
        alpha_o = (e_o / (rho_o * c_o)) ** 1  # 由 e=sqrt(lambda rho c) 与先验密度反解
        phi_th = torch.cat([e_o, alpha_o, T_ir_feat(T_ir)], dim=-1)
        return phi_th, log_sig, aux

    def fuse_physical_prior(self, phi_phys, phi_th):
        # 金属/陶瓷/塑料的 e_o 先验用于校正摩擦与脆性估计
        return fuse_module(phi_phys, phi_th)  # -> phi_phys^+ = (mu,k,eta,sigma,e,lambda,alpha,eps)
```

```python
class FourClockThermalLoop:
    def __init__(self, mel, dms_t, usr, tha, tdic, wm, ertc, budget):
        self.mel, self.dms_t, self.usr = mel, dms_t, usr
        self.tha, self.tdic, self.wm = tha, tdic, wm
        self.ertc, self.budget = ertc, budget
        self.K_prior = None
        self.cached_anchor_version = -1

    def thermal_step(self):
        """热流 0.1–1 Hz：预测 + 辨识 + 提交热锚（永不进入实时环）"""
        T_meas = read_thermistors()
        T_ir = read_thermal_camera()
        mu, sigma, field = self.wm.rollout(T_meas, self.q_hist, self.pose_hist,
                                           self.T_amb, self.airflow)
        T_ucb = self.wm.upper_bound(mu, sigma)
        H_th, D_th = budget.update_thermal(T_ucb, T_meas)
        z_th = self.mel.thermal_embedding(T_ir, T_meas)
        s_th = self.tdic.update_hold(self.K_prior, self.wm, T_meas, self.q_hist,
                                     self.pose_hist, self.T_amb, self.airflow)
        anchor = self.tha.commit(T_ucb, field, z_th, H_th, D_th, s_th)
        return anchor

    def semantic_step(self):
        """语义流 10–100 Hz：热材料先验注入 MEL + 热协商"""
        anchor_th = self.tha.read_latest()
        phi_phys_plus, z_scene, pi, U = self.mel.infer(
            V, T, P, L, z_th=anchor_th.z_th, phi_prev=self.usr.phi_prev)
        a_diag = self.dms_t.step(U, anchor_th.H_th, anchor_th.D_th,
                                 self.usr.evidence_buffer, dt_request=20.0)
        self.usr.commit(z_scene, self.usr.encode_intent(a_diag.b_intent),
                        phi_phys_plus, anchor_th)

    def realtime_step(self, delta_f_req, fused, Sigma_e, Jc):
        """实时流 1–10 kHz：只读热锚的 s_th，不做任何网络推理"""
        anchor = self.tha.read_latest()
        if anchor is None:
            self.tdic.s_hold = 0.0            # 无热信息 ⇒ 最小风险
        scene_emb = self.usr.latest_anchor.scene_emb
        intent_emb = self.usr.latest_anchor.intent_emb
        self.K_prior = self.usr.project_to_impedance(scene_emb, intent_emb)
        K_safe, s_th = self.tdic.compile(self.K_prior, anchor)
        cert = self.ertc.dispatch(K_safe)
        EV_exec = wait_contact_and_build_evidence()
        # 硬件独立热熔断：优先级高于一切语义
        if max(read_thermistors()) > T_hard:
            self.ertc.safe_stop(reason="HARD_THERMAL")
        J_thermal = build_thermal_cert(EV_exec, anchor, self.usr.cert, self.wm)
        return K_safe, EV_exec, J_thermal
```

### IP-189 THCS（热-算力协同调度）

```python
class ThermalHealthComputeScheduler:
    MODES = ["full", "distill", "cached", "frozen"]

    def __init__(self, soc_model, latency_model, T_soc_lim, tau_sem_max):
        self.soc = soc_model                  # C_soc dT/dt = P(m) - h(T-Tamb)
        self.lat = latency_model              # L(m, T_soc)
        self.T_lim = T_soc_lim
        self.tau = tau_sem_max

    def schedule(self, T_soc, horizon_s=60):
        best = None
        for m in self.MODES:
            T_hat = self.soc.rollout(T_soc, m, horizon_s)
            L_hat = self.lat.predict(m, T_hat)       # 热节流后时延
            if max(T_hat) <= self.T_lim and max(L_hat) <= self.tau:
                score = self.voi_sem(m) - 0.1 * L_hat.mean() - 0.05 * max(T_hat)
                if best is None or score > best[0]:
                    best = (score, m)
        return best[1] if best else "frozen"

    def calibrate(self, m, measured_latency, measured_T):
        self.lat.add_sample(m, measured_latency, measured_T)
        self.lat.fit_piecewise_throttle()       # 学习 f(T) 降频拐点
```

```python
class CognitiveThermalBudget:
    def __init__(self, H_th_min=5.0, D_th_max=600.0, cooling_ops=20,
                 T_sensor_freq=2.0, wm_calls=1):
        self.H_th_min = H_th_min
        self.D_th_max = D_th_max
        self.cooling_ops = cooling_ops
        self.T_sensor_freq = T_sensor_freq
        self.wm_calls = wm_calls
        self.D_th = 0.0
        self.H_th = float("inf")
        self.lambda_H, self.lambda_D, self.lambda_E = 1.0, 0.01, 0.2

    def update_thermal(self, T_ucb, T_meas, T_lim, T_soft, dt):
        self.H_th = float(np.min(T_lim - T_ucb))
        self.D_th += float(np.sum(np.maximum(0.0, T_meas - T_soft)) * dt)
        return self.H_th, self.D_th

    def voi_7(self, action, base_voi, cost_exec):
        thermal_penalty = 0.0
        if action.delta_H < 0:
            thermal_penalty += self.lambda_H * (self.H_th_min - action.delta_H)
        thermal_penalty += self.lambda_D * max(0.0, action.delta_D)
        thermal_penalty += self.lambda_E * action.energy
        return base_voi - cost_exec - self.cost_mel(action) - self.cost_usr(action) - thermal_penalty

    def degrade_level(self):
        if self.H_th < 0 or self.D_th > self.D_th_max:
            return "safe_stop"
        if self.H_th < self.H_th_min:
            return "freeze_high_heat"
        if self.H_th < 2 * self.H_th_min:
            return "derate_and_rest"
        if self.H_th < 4 * self.H_th_min:
            return "cool_pose_distill"
        return "nominal"
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| THA | O(n+d_th) 读写 | O(n+d_th) | CAS 原子写、版本单调、独立 TTL |
| DHT-WM | 滚动 120 步 ~10–50 ms（热流 0.1–1 Hz） | ~50–200 MB | 保形上界覆盖率 ≥ 95%；在线辨识残差 ≤ ε_th |
| TIFS/TDIC | 热流解不动点 ~0.1–1 ms；实时 O(d²) ~µs | O(1) 热路径 | `s_th` 单调不增、只向安全侧近似 |
| TSM | 每次接触 ~10–30 ms | ~20 MB | 热积误差 < 20%；材质 AUC ≥ 0.9 |
| SRT-Thermal | 热 0.1–1 Hz / 语义 10–100 Hz / 实时 1–10 kHz | 共享内存 ~10 MB | 实时流零神经推理、零阻塞 |
| THCS | O(|M|·horizon) ~1 Hz | O(1) | 所选模式满足 `T_soc` 与时延双约束 |
| PCE++++++ | O(1) | O(1) | 降级单调更保守，安全项永不降级 |

**正确性定理（TH-ESEC-Complete）**：
在 A61–A70 及以下假设下：
- **(A71) 热模型校准**：DHT-WM 经保形校准，`P(T_j(t+h) ≤ \hat T_j^{UCB}(t+h)) ≥ 1−α`；在线辨识使分布漂移下残差 `r_th ≤ ε_th`。
- **(A72) 降额单调性**：`ρ_j` 对 `T` 单调不增；`q_j ∝ s²`；WM 滚动对 `q` 单调；`s_{k+1}=min(s_k,Φ(s_k))` 从 `s_0=1` 收敛到保守可行点。
- **(A73) 独立安全**：硬件热熔断与固件力矩限幅独立于学习模型与语义层。
- **(A74) 材料可辨识性**：接触过程中接触力/面积变化提供持续激励，使 `(e_o,h_c,T_o)` 可辨识。
- **(A75) 算力模型校准**：THCS 的 `L_mel(m,T_soc)` 经在线校准，所有模式满足实时契约。
- **(A76) 对话安全**：DMS-T 规则策略只输出 `K∈TIFS` 的提案，用户意图不能越过安全停。
- **(A77) 锚点一致性**：THA 的 CAS 写与 64 位版本号保证无撕裂读；热锚 TTL 与热时间常数匹配。

则：
1. **热-力安全**：若 `Valid(J_thermal)`，则在预测时域 `H` 内以概率 `≥1−α` 执行 `K_safe` 不会使任何关节超过 `T_lim`，且关节力矩不超过当前温度允许的 `τ_max,j(T)`。
2. **预测式优雅降级**：随温度上升，`s_th` 单调不增；任务性能先于安全边界下降，且不存在「越热越激进」的振荡。
3. **实时性隔离**：实时流周期不依赖 DHT-WM 与 MEL；热流最坏延迟只影响 `s_hold` 的更新频率，过期时只会更保守。
4. **热-语义增强**：对于视觉同色同形、热积差异显著的材质，TSM 的 `e_o` 后验使材质判别 AUC 显著高于纯 RGB/触觉（目标 ≥0.9），并降低摩擦/脆性估计误差。
5. **算力-热协同**：THCS 在满足 `T_soc ≤ T_soc,lim` 与 `L_mel ≤ τ_sem_max` 的前提下最大化语义 VOI，避免「大模型把 SoC 跑热后语义流崩塌」。
6. **热可恢复性**：若状态是 `T_rec`-韧性，则 DMS-T 可在 `T_rec` 内恢复热余量；否则系统升级为降载或安全停，不承诺不可行的休息时长。
7. **预算安全**：七维预算任一维耗尽触发单调降级，安全项（TIFS、硬件熔断、ERTC 契约）永不降级。

## 6. 本轮最大风险（一句话）

**最大风险**：若 DHT-WM 在气流/接触/长时负载漂移下系统性低估最热关节，预测式降额会「太晚太小」，造成不可逆退磁或任务中途热停；且热漂移会同时污染温度测点与力矩证据，使模型用被污染的残差自我确认安全，形成**热盲区自证**——必须以保形上界、独立硬件热熔断与「预测永不下调安全阈值」三重护栏兜底，安全绝不外包给学习模型。
