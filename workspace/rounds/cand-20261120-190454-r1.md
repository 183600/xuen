# 第 2 轮（UniBot 线 · LENS 子线；本轮灵感：「多语言支持」×「视觉编码器」）

> **基线与编号声明**：承接第 1 轮 **UniBot-SAGE**（抓握确认 / 技能路由 / 推理期适应 / chunk 缝合 / 代理评测）。本轮不推倒 SAGE，而是在其事实与组件之上新开 **LENS 子线**：把「语言」当作任务规格、把「视觉编码器」当作标定归一化的几何接口。SAGE 的 U/L/E 编号保留为历史引用；本轮启用新编号 **V1–V12（定义）、M1–M8（引理）、E701–E720（实验）**。数据事实除沿用 2026-11-17 的公开检索外，新增 **2026-11-20 本地数据审计**（32 个官方 `*_info.json` 与 teaser 榜单文件），出处见产物区 §11。

## 0. 本轮一句话

**上一轮把「抓没抓住」变成可观测量；本轮把「做没做对任务」和「量没量对尺度」变成可观测量**：用语言等价类与视觉绑定消除「同一任务的不同说法 / 不同别名」，用标定归一化的度量几何消除「不同机器人相机导致的尺度漂移」，再以「语义不变、几何等变、无法接地时诚实降级」的契约把两者统一到同一个策略服务里。

## 1. 直觉解释

### 灵感 1 ·「多语言支持」→ 不是翻译，是「同一规格的等价类 + 无法接地时的诚实降级」

**第一性原理**：在 VLA 里，语言不是装饰性输入，而是**任务规格（specification）**。规格有三个失效面：

1. **表层脆弱（surface brittleness）**：同一任务换一种说法——中英互译、同义词、语序、量词、否定、指代——若映射到不同的任务 token 或不同的动作分布，系统就会「正确地执行错误的规格」。这不是翻译问题，而是**语义等价类没有被显式建模**。
2. **别名歧义（alias ambiguity）**：同一物体 / 任务在不同来源里有不同名字。本轮本地审计发现：32 个官方数据集的名称与 teaser 榜单任务名中，**至少 8 个不是逐词一致，其中 4 个是硬别名**（`PourOutMedicine ↔ Open Pill Bottle`、`StoreCups ↔ Stack Cups`、`StorePaddle ↔ Store Racket`、`ArrangePlates ↔ Clear Plates`）。这意味着**即使评测只用英文、不换句式，纯字符串的任务路由也会在约 1/8–1/4 的任务上出错**。
3. **规格缺口（spec gap）**：指令可能模糊、指代不存在、或目标不可抓。最坏的失败不是「不会做」，而是**流畅、自信、平滑地做错**——上一轮已经指出，这类「静默规格错误」是任何几何 / 力觉证书都检测不到的。

**结论**：多语言支持的正解不是「多训几种语言」，而是三件事：

- **(a) 语言等价类**：把所有表层形式映射到同一个**语言规格图（LSG：verb / entities / attributes / relations / constraints）**；
- **(b) 组合式视觉绑定**：名词不是查 32 个任务 ID，而是绑定到当前画面中的实体；别名与未见物品靠视觉证据消解；
- **(c) 可校准的规格缺口分数 κ**：低置信时**降级 / 探索 / 视觉推断**，而不是硬猜。

一个类比：多语言支持不是给数据库写 32 套查询，而是定义**一套 schema**，让中文、英文、别名都成为同一 schema 的**受审计视图**。

### 灵感 2 ·「视觉编码器」→ 不是更大的 ViT，是「标定感知的几何接口 + 相机角色分工」

**第一性原理**：编码器决定策略**能知道什么**。桌面操作至少需要三类信息，它们的统计特性完全不同：

- **全局任务 / 场景**：头戴双目，约 97° 宽视场，低频；回答「这是什么任务、物体大概在哪」。
- **局部接触 / 对齐**：腕部相机，约 72.5° 视场，高频、高分辨率；回答「夹住了吗、对上了吗、滑了吗」。
- **度量三维**：双目 / 结构光；回答「差几毫米、该往哪个方向补」。

本轮对 32 个官方 `info.json` 的审计给出一组硬事实：

| 事实 | 数值 | 含义 |
|---|---|---|
| 32 个数据集全部提供 `camera_params` | 32/32 | 离线可用真实内参 / 基线做几何自监督 |
| 头部双目已校正（`rectified: true`），基线 | 46.42–63.24 mm（中位 58.25） | 可直接 SGBM / 立体匹配得到度量深度 |
| 32 个数据集至少来自 **11 组不同标定**；头部 `f·b` 最大值 / 最小值 | **1.8357×** | 标定盲的深度编码器在最坏情况下有 **−45.5%～+83.6%** 的尺度偏差 |
| 腕部 RGB-D 红外双目基线 | ≈18 mm | 近距接触几何的天然来源 |
| 头 / 腕水平视场 | ≈97° / ≈72.5° | 头看全局、腕看局部，角色不可互换 |

**结论**：视觉编码器的正解不是「换一个更大的 ViT」，而是：

- **(a) 标定归一化**：把内参 / 基线作为输入或显式归一化，输出**度量 / 相对点图**，并在无标定时用本体感觉（EE 位移）做在线尺度锚定；
- **(b) 角色分工**：头 / 腕共享主干 + 角色适配器，而不是把 4 路 token 等权拼接；
- **(c) 视点鲁棒**：训练期随机丢视角，评测期人手遮挡 / 相机失效时优雅退化；
- **(d) 焦距式 token 预算**：接触相位把 token 给腕部，搬运相位把 token 给头部，直接服务上一轮的延迟预算。

### 合成 · UniBot-LENS 的三因子契约

把两个灵感放在一起，核心不是「语言 + 视觉」，而是**同一个表征必须同时满足两类相反的要求**：

- **语义不变（invariant）**：换语言、换别名、换背景、换光照，任务语义 `s_task` 不变。
- **几何等变（equivariant）**：物体平移 / 旋转多少，动作就应当相应平移 / 旋转多少；相机标定变了，度量尺度要跟着归一化。
- **nuisance 隔离**：背景 / 纹理 / 光照只允许进入 `z_nui`，供上一轮 IP-04 的上下文调制使用，**不允许直接进入动作通路**。

因此 LENS 把表征显式拆成三个因子：

```text
o, K, ℓ  ──►  s_task   （语言规格，语义不变）
              z_geo    （度量几何，标定归一化 + 几何等变）
              z_nui    （外观 nuisance，只供上下文适配）
π(a | s_task, z_geo, K)     # 动作只看语义 + 几何，不看 nuisance
```

**为什么必须拆**：单一潜变量不可能同时「对背景颜色不变」又「对物体位移等变」——不是数学上绝对不可能，而是**在没有干预数据的条件下不可辨识**（见 M8）。不拆，编码器就会走捷径：要么把几何压掉换取 nuisance 不变，要么把 nuisance 漏进动作换取几何敏感。拆开并把「哪一维该变」用反事实配对钉住，才是可检验的工程。

## 3. 研究问题（本轮新增）

- **Q11（语言接口）**：在没有行级语言监督、每个任务只有一条规范指令的条件下，能否用「LLM 改写 + 反事实配对 + 视觉绑定」学到对表层形式不变、对语义差异敏感的 `s_task`？
- **Q12（别名接地）**：4 个硬别名 + 4 个形态差异，能否靠「视觉实体绑定 + 开放词表检测」而不是字符串匹配解决？误绑定的代价如何门控？
- **Q13（标定归一化）**：在 11 组标定、`f·b` 1.84× 的异质性下，能否用双目自监督 + 本体尺度锚定，把无标定评测的深度尺度误差压到可接受范围？无内参时的退化链是什么？
- **Q14（不变 / 等变分解）**：在只有增广配对、没有真实反事实视频的条件下，`s_task / z_geo / z_nui` 的分解能否被识别？若不能，代理审计会不会「全绿但真机失效」？
- **Q15（分数相关性）**：语言不变性、几何归一化、视点鲁棒这些表征性质，究竟和真机终态成功率相关多少？若相关性低，应该砍掉哪一部分？

## 4. 设计原则（在 SAGE P1–P6 上追加）

- **P7 语言是规格，不是标签**：任何表层形式都必须映射到同一 LSG；不能接地时允许弃权，不允许硬猜。
- **P8 几何先于外观**：动作条件化只用 `s_task + z_geo`；纹理 / 背景 / 光照进入 `z_nui`，只服务上下文适配。
- **P9 标定是一等输入**：有标定就用标定，没有标定就用双目 / 本体尺度锚定；绝不假设「训练和评测同一台相机」。
- **P10 不变与等变分开审计**：PC / AR（语言不变）、NI（nuisance 不变）、GE（几何等变）、VR（视点鲁棒）分别度量，不合成一个模糊总分。
- **P11 便宜探针先行**：语言审计、标定审计、冻结编码器线性探针是零真机成本的；先做这些，再决定是否训大模型。
- **P12 不做静默规格错误**：κ 低时优先降级 / 探索，而不是把错误任务执行到底。

## 5. 最小可提交闭环（MVP）与退化链

**MVP = SAGE 的 IP-06（代理评测） + 本轮 E701/E702（语言 / 标定审计） + IP-09（POLYGLOT 别名 / 改写接地） + IP-10（标定归一化几何） + 基线 VLA**。

**退化链（任一环节不可用 ⇒ 行为回退，不漂移）**：

- L0 语言编码器不可用 ⇒ 退回「数据集规范英文 + 视觉显著目标」；
- L1 κ 低 / 规格不可接地 ⇒ 退回视觉目标推断或广域探索，不执行高置信错误任务；
- L2 评测无标定 ⇒ 双目深度 → 本体尺度锚定 → 相对几何 → 2D token；
- L3 几何头失败 ⇒ SAGE IP-02 的 2D 腕部抓握确认；
- L4 整条新链路失效 ⇒ 纯 SAGE 基线（保留可跑通、可信度合规的安全网）。

## 6. 预期贡献（可验收）

1. **两份公开可复用的审计**：语言 / 别名审计（8/32 非一致、4/32 硬别名）与标定异质性审计（11 组、`f·b` 1.84×），把「多语言 / 多相机」从口号变成可量化缺口。
2. **POLYGLOT**：一个对表层形式不变、对语义差异敏感、带规格缺口校准的语言接地器，直接升级 SAGE IP-01 的任务路由。
3. **CALIB-VISION**：一个标定归一化、可用双目自监督、可用本体尺度锚定的多视角度量编码器，并给出无标定退化链。
4. **EQUI-AUDIT**：把「语义不变 / nuisance 不变 / 几何等变 / 视点鲁棒」拆成四个可测指标与逐 episode 证书。
5. **ENCODER-BENCH**：用冻结编码器线性探针回答「表征是不是瓶颈」，给出编码器选型准则，而不是盲目换大模型。

## 7. 本轮最大风险

**一句话**：官方训练集没有行级语言字段、每个任务只有一条规范指令，而评测是否改变语言 / 相机仍是未知；若语言与标定在评测中都是常量，本轮的两大直觉就只能兑现为「更稳的表征」而无法兑现为分数——更糟的是，缺少真实反事实配对时，语言不变性可被「记住 task_index」的捷径满足、几何等变可被「拟合增广」的捷径满足，代理审计全绿却在真机 OOD 上失效。

# 第 2 轮产物 · 创新点清单 v2（UniBot 线）：**UniBot-LENS**

> **LENS = Language-grounded, Equivariant, Normalized Spatial encoder**（语言接地 · 几何等变 · 标定归一化 · 空间编码）。
> **定位**：承接第 1 轮 **UniBot-SAGE**（抓握确认 / 技能路由 / 推理期适应 / chunk 缝合 / 代理评测）。本轮把「语言」升级为任务规格、把「视觉编码器」升级为标定归一化的几何接口，二者合成一个「语义不变 / 几何等变 / 无法接地时诚实降级」的表征契约。
> **编号**：SAGE 的 U/L/E 保留为历史；本轮启用 V1–V12、M1–M8、E701–E720。
> **数据纪律**：榜单数字仍来自 `unibot.unitree.com/leaderboard_data.json`（**teaser / 占位表**，非官方终稿）；本轮新增的 32 数据集审计来自本地缓存的官方 `*_info.json` 与 `meta` 统计，检索 / 审计日期 **2026-11-20**。

## 0. 本轮结论摘要

**一句话路线**：在 SAGE 的「抓握 / 技能 / 适应 / 工程」四层栈上，加一层**表征契约层**：语言侧把任意表层形式压成 `s_task`（语言规格图），视觉侧把 4 路异构相机压成 `z_geo`（标定归一化的度量几何）与 `z_nui`（外观 nuisance），动作只吃 `s_task + z_geo`；当 `s_task` 无法接地时，用校准过的 κ 诚实降级。

**为什么是这个组合（本轮本地审计的硬数字）**：

| 证据 | 数值 | 推出的设计 |
|---|---|---|
| 32 个数据集行级无 `observation.language`，每个 `total_tasks=1` | 语言监督只有「每任务一条规范指令」 | 必须用 LLM 改写 + 反事实配对补语言多样性；不能指望数据里自然出现多语言 |
| 数据集名 vs teaser 任务名：8/32 非逐词一致、4/32 硬别名 | 纯字符串路由在约 1/8–1/4 任务上已错 | **POLYGLOT**：LSG + 视觉实体绑定，别名不靠字符串 |
| 32 数据集来自 ≥11 组标定；头部 `f·b` 极差 1.8357× | 标定盲深度最坏有 −45.5%～+83.6% 尺度偏差 | **CALIB-VISION**：标定条件化 / 本体尺度锚定 |
| 头部双目 `rectified=true`、基线 46–63 mm；腕部 IR 基线 ≈18 mm | 度量深度可离线自监督 | 用双目生成深度标签，蒸馏到轻量点图头 |
| 头 / 腕视场 ≈97° / ≈72.5°，角色不同 | 等权拼接 4 路 token 浪费容量与延迟 | **ROLE-VISION**：角色适配器 + 焦距式 token 预算 |
| 5 类官方泛化场景不含「语言改写」与「标定漂移」 | 两个未列出的 OOD 轴 | **LANG-VISION CONTRACT**：新增 PC/AR/NI/GE/VR 代理轴 |

**合规红线（沿用 SAGE P5/P6）**：单 checkpoint、单 API；不读评测侧私有信息；不硬编码任务名 / 端口 / 场景；所有「语言 / 视觉」改动都发生在策略内部，不改变官方接口语义。

## 3. 创新点详述

### IP-09 · POLYGLOT：语言规格图 + 视觉绑定 + 规格缺口校准（P0）

- **动机**：F2（无行级语言、每任务一条规范指令）+ F5（8/32 非逐词一致、4/32 硬别名）+ 规格缺口（模糊 / 不存在 / 不可抓）。纯字符串 / 任务 ID 路由在评测换说法或换别名时会把「做错任务」伪装成「执行失败」。
- **与现有方案的差异**：SAGE IP-01 用 `z_task = argmax cos(E_L(ℓ), e_k)`（32 个任务原型）；这是**闭集分类**。POLYGLOT 改成**开集规格解析 + 视觉绑定**：
  1. `parse(ℓ) → LSG = (v, E, R, C)`：动词、实体、属性、关系、约束；
  2. `bind(LSG, o) → {(n_i, e_i, r_i)}`：名词绑定到当前画面的实体（开放词表检测 + VLM 属性核验 + 空间关系）；
  3. `s_task = encode(LSG, bindings)`：规格嵌入，不是任务 ID；
  4. `κ(ℓ,o)`：规格缺口分数，低时降级。
- **技术可行性**：高。
  - 改写集：32 任务 × 20 条（中 / 英 / 混合；同义、语序、量词、否定、指代），≈640 条，LLM 离线生成 + 人工抽检 10%。
  - 别名图：把 `PourOutMedicine↔Open Pill Bottle`、`StoreCups↔Stack Cups`、`StorePaddle↔Store Racket`、`ArrangePlates↔Clear Plates` 等写入本体；但**不靠图谱硬编码作为最终路径**，图谱只做弱先验，最终由视觉绑定决定。
  - 视觉绑定：GroundingDINO / OWLv2 给候选框，Qwen2.5-VL 做属性 / 关系核验；GPU 单卡可跑。
  - 一致性损失：同一任务的不同表层形式 `s_task` 对比学习（正样本 = 改写 / 别名；负样本 = 其他任务 + 难负样本，如「把杯子放左边」vs「把杯子放右边」）。
- **所需资源**：数据 = 官方 32 数据集（仅用帧 + 任务名，不需新机器人数据）；算力 = 1×A100 数天（文本编码器 + 绑定头 + 对比学习）；接口 = 无新增字段。
- **落地步骤**：
  1. 抽取 32 条规范指令 / 数据集名 / 榜单名，建立三列对照表（E701）；
  2. LLM 生成 20× 改写，人工抽检 10%，保留「语义等价但表面不同」与「表面相似但语义不同」两类；
  3. 训练 `s_task` 对比编码器（文本 + 视觉绑定特征），难负样本挖掘；
  4. 训练 κ 校准器（温度缩放 / isotonic），标签 = 该 episode 最终是否成功 + 人工规格正确性；
  5. 在 4 个硬别名 + 4 个形态差异上做专项路由测试（E705）；
  6. κ 低时接视觉目标推断 / 探索（L1 退化）。
- **风险**：
  1. **捷径学习**：模型记住 `task_index` / 训练集规范句，改写集上仍好，但换语言就崩 ⇒ 必须用「留出改写模板」「留出语言」「留出别名」三套测试，且训练时随机 dropout 任务 ID；
  2. **改写坍缩**：过度强调不变性会把「左 / 右」「开 / 关」等语义差异压掉 ⇒ 难负样本 + 最小可分间距 δ_p；
  3. **绑定错误**：开放词表检测在遮挡 / 未见物品上误绑 ⇒ κ 门控 + 多帧一致性 + 保守降级；
  4. **过度弃权**：κ 阈值太高导致大量 episode 不执行 ⇒ 用 M4 的成本比定阈值，并报告覆盖率。

### IP-10 · CALIB-VISION：标定归一化度量编码器（P0）

- **动机**：F3/F4——32 数据集来自 ≥11 组标定，头部 `f·b` 极差 1.8357×。标定盲的 2D 编码器无法区分「物体真的小」与「相机焦距不同」；深度尺度错会直接毁掉抓取点、插入深度与对齐。
- **与现有方案的差异**：通用 VLA 把 4 路 RGB 等权 token 化，深度只作为可选通道；我们让几何成为**一等输出**：
  1. 训练期用已校正头部双目（SGBM / RAFT-Stereo）生成度量深度 / 点图；
  2. 训练一个**内参条件化**的点图头 `X = f(I, K)`（`K` 含 fx/fy/cx/cy/baseline），用随机标定增广（在 11 组标定 + 抖动上采样）逼模型学会「焦距变了，尺度跟着变」；
  3. 评测期若无 `K`：先用双目匹配 → 若双目不可用 / 未校正，用**本体尺度锚定**（头戴相机中可见末端标记的运动 vs 本体 EE 位移做最小二乘）→ 再退相对几何 → 最后退 2D token；
  4. 输出 `z_geo`（尺度归一化点图特征）与 `z_nui`（外观残差）。
- **技术可行性**：中–高。离线深度生成可抽样（每 30 帧取 1 帧，约 60 万帧），不必全量；点图头可轻量（ViT-S + 深度解码头），目标在线 ≤20 ms。
- **所需资源**：数据 = 官方 32 数据集 + `camera_params`；算力 = 深度生成 4×A100 数天（可离线）+ 点图头训练 1–2×A100 两天；接口 = 不新增字段（标定从 `camera_params` / 首帧探测获得）。
- **落地步骤**：
  1. 验证 32 数据集的 `rectified` 与 `camera_params` 一致性（E702 已完成初版）；
  2. 抽样生成双目深度 / 点图，做噪声与遮挡过滤；
  3. 训练内参条件化点图头，标定留出（leave-one-calibration-out）；
  4. 实现本体尺度锚定（EE 位移最小二乘）；
  5. 接入 SAGE IP-02 的抓握确认与滑移检测（腕部 IR 双目）；
  6. 做无标定 / 错标定 / 跨机器人三组压力测试（E708）。
- **风险**：
  1. **评测不下发标定** ⇒ 依赖本体尺度锚定；锚定需要可见末端运动，静止抓取时退化 ⇒ 多窗口 + 相对几何兜底；
  2. **评测相机键 / 校正状态与数据集不一致**（F6）⇒ E703 首帧验证极线约束；不一致就关闭度量头，走相对几何；
  3. **深度噪声 / 反光 / 透明物体** ⇒ 置信度图 + 多帧融合 + 抓握确认门控；
  4. **延迟** ⇒ 点图头只在关键帧 / 接触相位跑，其他相位用缓存 + 轻量跟踪。

### IP-11 · ROLE-VISION：相机角色分工 + 焦距式 token 预算（P1）

- **动机**：4 路相机不是同质的：头部 97° 看全局，腕部 72.5° 看接触；插入 / 对齐阶段腕部像素的信息密度远高于背景。等权 token 化既浪费容量又拉高延迟。
- **与现有方案的差异**：
  1. 共享主干 + 角色适配器（head / wrist），而不是一个 ViT 拼 4 路 token；
  2. 跨视角物体槽（slot）一致性：同一物体在头 / 腕视角应落到同一槽（对比损失）；
  3. 视角 dropout：训练期随机丢 1–3 路，评测期人手遮挡 / 相机失效时优雅退化；
  4. 焦距式 token 预算：`B(head, wrist, phase)`，接触相位把 token 给腕部，搬运相位给头部；与 SAGE IP-03 的自适应 chunk 联动。
- **技术可行性**：中–高。角色适配器 / slot attention / dropout 都是成熟组件；关键是延迟预算与跨视角对应。
- **所需资源**：算力 = 比单塔略高（+20–30%）；数据 = 官方 4 路；接口 = 无。
- **落地步骤**：①角色适配器消融；②跨视角 slot 对比；③视角 dropout 曲线；④焦距预算的 Pareto；⑤与 IP-03 联合调 chunk。
- **风险**：①跨视角对应在遮挡 / 重复物体上错配 ⇒ 空间先验 + 置信度门控；②过度 dropout 降低训练信号 ⇒ 课程式 dropout；③焦距预算切换引入抖动 ⇒ 只在 chunk 边界切换（与 IP-03 一致）。

### IP-12 · EQUI-AUDIT：不变 / 等变三因子分解与证书（P1）

- **动机**：语义不变、nuisance 不变、几何等变是三类不同要求；单一潜变量无法同时满足（M8）。没有显式分解，代理指标会被捷径满足。
- **与现有方案的差异**：
  1. 三因子 `s_task / z_geo / z_nui`，动作只吃前两个；
  2. 用**反事实配对**（同一场景换背景 / 光照 / 纹理；同一场景刚体平移 / 旋转）钉住「哪一维该变」；
  3. 逐 episode 证书：NI（nuisance 漂移）、GE（几何等变误差）、VR（视角一致性）、XS（跨视角槽一致）；
  4. 与 IP-07 DualSpace 联动：几何等变在 EE 空间定义，joint 头只负责执行。
- **技术可行性**：中。反事实配对可在仿真 / 图像增广中生成；真实刚体变换可在少量真机 A/B 中做。
- **所需资源**：数据 = 官方数据 + 合成增广 + 小规模真机；算力 = 1–2×A100；接口 = 无。
- **落地步骤**：①构造配对生成器；②训练分解编码器（IB + 对抗 + 一致性）；③测 NI/GE/VR/XS；④逐 episode 证书；⑤E713 分解 vs 单体对照。
- **风险**：①**不可识别**：无真实干预时只能识别到可逆混合（M8）⇒ 配对增广 + 真机小样本；②代理指标好看但真机无效 ⇒ E719 相关性门槛；③几何变换在关节空间非线性 ⇒ 只在 EE 空间要求等变（M3）。

### IP-13 · ENCODER-BENCH：冻结编码器探针选型（P0，零真机成本）

- **动机**：在训大模型前，先回答「表征是不是瓶颈」。如果冻结编码器的几何探针已经能预测成功率，那么换 encoder / 加几何头比堆参数更划算。
- **与现有方案的差异**：不做「端到端训一个更大的 VLA 再看结果」，而是**先做表征诊断**：
  - 冻结 backbone：CLIP ViT-L/14、SigLIP-SO400M、DINOv2 ViT-L/14、MAE ViT-L/14；
  - 线性 / 轻量探针：任务身份（32 类）、物体类别（开放词表）、6-DoF 物体位姿、夹爪开合、接触 / 滑移、尺度不变深度；
  - 与 IP-06 代理成功率做 Spearman 相关；
  - 输出「编码器 × 任务簇」的选型矩阵。
- **技术可行性**：高。冻结特征 + 线性探针，单卡数小时。
- **所需资源**：数据 = 官方 32 数据集抽帧；算力 = 1×A100 数小时。
- **落地步骤**：①统一抽帧 / 标注；②冻结特征；③线性探针；④与代理成功率相关；⑤选型。
- **风险**：①线性探针低估非线性信息 ⇒ 加 MLP 探针；②探针标签噪声 ⇒ 双标注 / 人工抽检；③代理成功率本身不可信 ⇒ 与 E719 联动。

### IP-14 · LANG-VISION CONTRACT：新代理轴与逐 episode 证书（P1）

- **动机**：官方 5 类泛化场景不含「语言改写 / 别名」与「标定漂移」；这两条恰是本轮的主战场。没有新轴，LENS 的收益无法被代理评测看见。
- **指标定义**：
  - **PC（paraphrase consistency）**：同一 episode / 场景下，改写指令之间的动作分布距离（Hellinger / Wasserstein）；
  - **AR（alias robustness）**：别名任务名下的路由准确率；
  - **SG（spec-gap calibration）**：κ 的 ECE + 静默错误率（低 κ 仍执行错误任务的比例）；
  - **NI（nuisance invariance）**：`z_geo` 在背景 / 光照 / 纹理 OOD 下的漂移；
  - **GE（geometric equivariance）**：已知刚体变换下动作的等变误差；
  - **VR（view robustness）**：丢视角 / 遮挡下动作一致性；
  - **XS（cross-view slot consistency）**：跨视角同一物体的槽匹配率。
- **落地步骤**：①在 IP-06 的六因子之外加四轴 OOD（改写 / 别名 / 标定 / 视点）；②实现指标；③逐 episode 证书；④E719 相关真机。
- **风险**：①指标可被捷径满足 ⇒ 与真机 A/B 挂钩；②相关性低 ⇒ 按预注册砍轴。

## 4. 符号与定义（V1–V12）

| 符号 | 含义 |
|---|---|
| `ℓ` | 任意语言 / 任意表层形式的指令 |
| `o` | 观测：4 路图像 + 本体状态 + EE 位姿 |
| `K` | 相机标定：内参、基线、畸变、校正状态 |
| `s_task` | 语言规格嵌入：`(verb, entities, relations, constraints)` |
| `z_geo` | 标定归一化、几何等变的度量几何潜变量 |
| `z_nui` | 外观 nuisance 潜变量（背景 / 光照 / 纹理） |
| `κ` | 规格缺口分数：指令在 `o` 中可接地的校准置信度 |
| `σ` | 本体尺度锚定因子（把相对点图对齐到米制） |
| `ρ(g)` | 刚体变换 `g` 在几何潜空间中的表示 |
| `T_par, T_ali` | 语义保持的改写 / 别名变换 |
| `T_nui` | 外观 nuisance 变换（背景 / 光照 / 纹理） |
| `T_g` | 任务相关物体的刚体变换 |
| `S ⊆ {h_L,h_R,w_L,w_R}` | 可见视角子集 |
| `PC/AR/SG/NI/GE/VR/XS` | 见 IP-14 的审计指标 |

**定义 V1（语言等价类）** `ℓ ~ ℓ' ⇔ Spec(ℓ) = Spec(ℓ')`，其中 `Spec(ℓ) = (v, E, R, C)` 为动词、实体集合、关系集合、约束集合；`T_par` 与 `T_ali` 是保持 `Spec` 的变换。

**定义 V2（语言不变性 / 可分性）** 对任意 `ℓ ~ ℓ'`，`d(s_task(ℓ,o), s_task(ℓ',o)) ≤ ε_p`；对任意 `ℓ ≁ ℓ''`，`d(s_task(ℓ,o), s_task(ℓ'',o)) ≥ δ_p`。`d` 用余弦距离或动作分布 Wasserstein 距离。

**定义 V3（组合式视觉绑定）** `s_task = encode(v, {(n_i, e_i, r_i)})`，其中 `e_i = bind(n_i, o)` 是名词 `n_i` 在画面中的实体；同一指称的别名 `n_i'` 满足 `bind(n_i,o) = bind(n_i',o)`。

**定义 V4（规格缺口分数）** `κ(ℓ,o) = σ(w^T [1 - d(s_task, P), agree(paraphrases), bind_conf, visual_evidence])`，其中 `P` 为任务原型集合，`agree` 为多改写一致性；用温度缩放 / isotonic 校准，使 `P(correct | κ) = κ`。

**定义 V5（标定归一化点图）** `X(u,v) = Z(u,v) K^{-1} [u, v, 1]^T`，`Z` 来自双目匹配或点图头；`f_vis(o, K) → X` 在规范相机系输出，训练时对 `K` 做随机增广。

**定义 V6（本体尺度锚定）** `σ* = argmin_σ Σ_t || σ ΔX_t - R_cam^T Δp_EE,t ||^2`，`ΔX_t` 为头戴相机中可见末端标记的点图位移，`Δp_EE,t` 为本体 EE 位移（米制）；`R_cam` 为相机到基座的旋转（可估）。

**定义 V7（nuisance 不变性）** `d(z_geo(o), z_geo(T_nui o)) ≤ ε_n`。

**定义 V8（几何等变）** 对任务相关物体的刚体变换 `g`（相机固定）：`z_geo(T_g o) = ρ(g) z_geo(o)`，`π(a | T_g o) = g · π(a | o)`；`g` 限制在工作空间内、且动作在 EE 空间定义（M3）。

**定义 V9（视点鲁棒）** `E_{S⊆V} d(π(·|o), π(·|o_S)) ≤ ε_v(|S|)`，且 `ε_v(|S|)` 随 `|S|` 减小而单调增大。

**定义 V10（因子分解目标）** `min I(z_geo; z_nui) + β I(z_nui; a)`，约束 `I(z_geo; a) ≥ I_0`；`z_nui` 只允许进入 IP-04 的上下文调制，不直接进入动作头。

**定义 V11（联合损失）** `L = L_act + λ_p L_par + λ_a L_alias + λ_n L_nui + λ_g L_geo + λ_v L_view + λ_κ L_calib`。

**定义 V12（审计向量）** `Audit = (PC, AR, SG-ECE, NI, GE, VR, XS)`；每个 episode 导出一份，进入 IP-14 看板。

        a = self.pol.act(o, s_task, z_geo, budget)          # SAGE IP-01
        a = self.st.stitch(a, s.last_action)                # SAGE IP-03
        a = self.audit.clamp_and_log(a, o, t0, tau_budget_ms=self.tau_budget_ms)

        s.last_action = a[-1]
        self.audit.episode_metrics(PC=None, AR=None, NI=None, GE=None, VR=None)
        return pack(a, obs)

# ===== IP-09：语言规格图 + 视觉绑定 + κ =====
class PolyGlotGrounder:
    def parse(self, ell):
        # LLM / 规则：返回 verb, entities, relations, constraints
        return LSG(**self.llm.parse(ell))

    def bind(self, lsg, obs, X):
        boxes = self.detector(obs, lsg.entity_nouns)        # GroundingDINO / OWLv2
        boxes = self.vlm_verify(obs, boxes, lsg)            # 属性 / 关系核验
        return [self.to_slot(b, X) for b in boxes]

    def ground(self, ell, obs, X):
        lsg = self.parse(ell)
        bindings = self.bind(lsg, obs, X)
        s = self.encoder(lsg, bindings)
        kappa = self.kappa(s, obs, bindings)                # V4
        return s, kappa

    def visual_goal(self, obs, X):
        # 低 κ 退化：从场景显著物体 / 可操作关系推断目标
        cand = self.detector(obs, OPEN_VOCAB)
        return self.encoder.from_visual(cand, X)

# ===== IP-10：标定归一化度量编码器 =====
class CalibAwareMultiViewEncoder:
    def encode(self, obs, K):
        # 1) 头部双目：已校正则直接 SGBM / RAFT-Stereo
        if K and K.head.rectified:
            d = self.stereo(obs.head_L, obs.head_R)
            Z = K.head.f * K.head.b / (d + 1e-6)
            Xh = self.pointmap(Z, K.head)
        else:
            Xh, c = self.mono_pointmap(obs.head_L, K)       # 内参条件化
        # 2) 腕部 IR 双目：近距接触几何
        Xw = self.stereo_wrist(obs.wrist_L, obs.wrist_R, K)
        # 3) 角色融合 + 跨视角 slot
        z_geo = self.fuse_roles(Xh, Xw)
        # 4) nuisance 残差（只给 IP-04）
        z_nui = self.nuisance_head(obs)
        # 5) 本体尺度锚定
        sigma = self.scale_anchor(Xh, obs)
        return (Xh, Xw), z_geo, z_nui, sigma

    def scale_anchor(self, X, obs):
        # V6：用可见末端 / 腕部标记的位移对齐本体 EE 位移
        pairs = self.track_end_effector(X, obs)
        if len(pairs) < 3:
            return 1.0                       # 退相对几何
        return lstsq_scale(pairs)

def lens_loss(batch, model):
    o, o_nui, o_g, ell, ell_par, a = batch
    s, s_par = model.s_task(ell, o), model.s_task(ell_par, o)

    L_calib = kappa_nll(model.kappa, labels)         # V4

## 6. 推导（M1–M8）

**M1（别名 / 改写路由的 margin 界）** 设同一任务的所有表层形式在 `s_task` 空间的直径 ≤ ε_p，不同任务间最小距离 ≥ δ_p。若 `δ_p > 2ε_p`，最近原型 / 最近邻路由在等价类上一致；若 `δ_p ≤ 2ε_p`，存在至少一对任务不可分。对纯字符串匹配，本轮审计给出经验下界：8/32 非逐词一致、4/32 硬别名 ⇒ 在对抗性换名下有 **≥25%** 的路由错误面；视觉绑定把比较对象从「字符串」换成「实体 + 关系」，因此只要绑定正确，别名不再进入距离计算。∎

**M2（标定盲深度的尺度偏差）** 对已校正双目，`Z = f·b / d`。若编码器在 `(f_0,b_0)` 上训练、在 `(f,b)` 上推理，则 `Ẑ = f_0 b_0 / d = Z · (f_0 b_0)/(f b)`。本轮 32 数据集的 `f·b` 最小 10,201.8、最大 18,727.3，比值 **1.8357**，故 `Ẑ/Z ∈ [1/1.8357, 1.8357] = [0.545, 1.836]`，即 **−45.5%～+83.6%** 的尺度误差。这个误差会线性进入抓取点、插入深度与对齐残差，故「标定归一化」是几何等变的前提。∎

**M3（等变误差分解）** 动作管线可写成 `π ∘ f_vis ∘ IK`（EE 空间）。由三角不等式，`E_geo ≤ E_calib + E_enc + E_pol + E_kin`：标定误差、编码器等变误差、策略近似误差、关节空间 / IK 非线性误差。`E_kin` 在关节空间通常不可忽略，因此**几何等变应在 EE 空间定义与审计**，joint 头只负责执行；这也解释了 SAGE IP-07 双头的价值。∎

**M4（规格缺口的保守阈值）** 设 κ 已校准，`P(correct|κ)=κ`；执行错误任务的代价 `C_s`，降级 / 探索的代价 `C_f`，且 `C_s ≫ C_f`。阈值 τ 的期望代价
`R(τ) = ∫_0^τ C_f p(κ)dκ + ∫_τ^1 (1-κ) C_s p(κ)dκ`。
对 τ 求导：`R'(τ) = p(τ)[C_f - (1-τ)C_s]`，令其为零得 `τ* = 1 - C_f/C_s`。若 `C_s/C_f = 10`，`τ* = 0.9`；若 `C_s/C_f = 100`，`τ* = 0.99`。这给出「高精度、低召回」的介入准则，与 SAGE 的抓握介入同构。∎

**M5（视角 dropout 的证书）** 令 `A_S = π(·|o_S)` 为可见视角子集 S 下的动作。由全方差公式：
`Var(A) = E_S[Var(A|S)] + Var_S(E[A|S])`。
第二项 `Var_S(E[A|S])` 正是「不同视角子集给出的平均动作分歧」。若训练覆盖所有子集并施加一致性损失，该项可测且小；因此实测的 VR 曲线可作为遮挡 / 相机失效下的误差上界证书。∎

**M6（焦距式预算的近似最优）** 若每个 token 的信息增益函数 `G` 单调子模、预算为基数约束 B，则贪心分配满足 `G(A_greedy) ≥ (1-1/e) max_{|A|≤B} G(A)`。在桌面任务中，接触相位腕部 token 的边际信息增益远高于背景 token，故贪心会把预算推向腕部；若预算是时间 / 算力背包，则用边际增益 / 毫秒排序，得到近似解。∎

**M7（跨视角槽的样本复杂度）** 若给定物体状态时各视角条件独立，则 V 个视角对物体位姿的 Fisher 信息相加；在正则条件下，Cramér–Rao 下界使位姿估计方差按 `1/V` 下降，等价地，达到同一误差所需样本量按 `1/V` 下降。跨视角对比损失正是利用这 V 份免费监督。∎

**M8（三因子分解的可识别性）** 若无干预 / 辅助变量，非线性 ICA 仅可识别到可逆混合（Hyvärinen & Pajunen, 1999）；即使线性情形，nuisance 与几何的旋转混合也不可区分。因此 `s_task / z_geo / z_nui` 不能只靠重构损失学出来；必须用**反事实配对**（同一场景换背景 / 光照 / 纹理；同一场景刚体变换）作为辅助变量，把「哪一维该变」钉住。没有配对，代理审计可以被捷径满足：模型把 task_index 编进 `s_task`、把增广伪影编进 `z_geo`，指标仍可能好看。∎

## 12. 本轮最值得押注的创新点（一句话）

**押注 IP-09（POLYGLOT 别名 / 改写接地）：它是本轮唯一「零真机成本、零新数据、直接命中已量化缺口」的改动——32 个数据集里 8 个任务名与榜单不一致、4 个是硬别名，纯字符串路由在评测换名 / 换语言时会把「做错任务」伪装成「执行失败」；而它又能直接升级 SAGE 的 IP-01 任务路由，收益不需要等大模型训练。**

**本轮最大风险（一句话）**：官方训练集没有行级语言字段、每个任务只有一条规范指令，而评测是否改变语言 / 相机仍是未知；若语言与标定在评测中都是常量，LENS 就只能兑现为「更稳的表征」而无法兑现为分数，且缺少真实反事实配对时，不变性 / 等变性损失可被捷径满足，代理审计全绿却在真机 OOD 上失效。
