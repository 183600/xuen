# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「无刷电机」×「轻量化设计」）

> R69 把不确定性一分为二：aleatoric 交给 R68 的 λ_floor 收紧，epistemic 交给「流匹配多模态策略 + 主动多模态交互」去消解。但它有一个未经审视的前提：**策略选中的动作 ξ，就是身体真正执行的动作**。对真实的无刷电机驱动机械臂，这句话不成立——策略给出的只是一个「请求」，真正兑现的是扭矩，而扭矩受磁钢温度、磁饱和、死区、电流传感器偏置、母线电压与反电动势共同调制。R69 的 `U_ale`（噪声）与 `U_epi`（该选哪个模态）都住在「选择」里；本轮要补的是第三个、**串行**的通道：`U_act`（所选动作能否被身体兑现）。
>
> 本轮两个灵感正好给出这条缺失通道的两面：
> - **无刷电机**——FOC 下扭矩 ∝ ψ_f(T_m)·i_q，扭矩常数随磁钢温度漂移；但电机同时是一个**电气传感器**：d 轴高频注入、电压阶跃、主动短路反电动势测量，可以在**几乎不产生净扭矩、不移动机械臂**的条件下辨识 R_s、L_d/q、ψ_f、死区与传感器偏置。R69 的「信息动作」在这里第一次有了一个只花热、不花运动、也不骚扰人的版本。
> - **轻量化设计**——减重不是免费的：惯量 J↓ 让同样扭矩产生更大加速度（更敏捷），也让同样的扭矩误差放大成更大的加速度误差（更脆弱）；热容 C_th↓ 让同样损耗更快升温（热缓冲变薄）；结构刚度↓ 让一阶模态下移进控制带宽。轻量化是一次**不确定性预算的再分配**，而且它让「不确定就慢一点」这条从 R68 延续到 R69 的铁律第一次失效：低速保持扭矩会让焦耳热 ∝ 1/v 发散，**慢，可能比快更危险**。
>
> 核心命题：**把 R69 的「选择不确定性」接上一条「兑现不确定性」：用电气自辨识把 θ_a 的后验压下去，用双节点热观测把磁钢温度的不确定度显式化，用扭矩保真证书把 ε_τ 计入安全包络，用可实现性投影把流策略生成的轨迹拉回电流圆/电压椭圆/热降额的交集；再把「减速」从一个标量升级为一个热感知的安全动作集（减速 / 快速穿越 / 机械抱闸 / 停驻冷却 / 换低扭矩路径）。最后加一个设计时外层：质量、电机、减速比、冷却与刚度与策略共设计，优化「安全调整敏捷度」而不是裸速度。** 命名 **REAL-RAS**（Realizable Embodied Actuation & Lightweighting for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的指令兑现得了吗**」——不确定性不只是刹车踏板、不只是提问，它还是一笔**执行器可能还不起的物理债务**。

## 0. 直觉与动机

**灵感 1（无刷电机 → 指令不是扭矩；而电机本身是传感器）**
直觉：R69 的 `ξ=(a,g)` 是可微、连续、漂亮的轨迹；但电机只认电流。`τ = (3/2)p[ψ_f(T_m) i_q + (L_d−L_q)i_d i_q]`。`ψ_f` 随磁钢温度以约 −0.1%/°C 漂移，磁饱和让 `L_d,L_q` 随电流变化，逆变器死区与电流传感器偏置再叠一层系统性误差。于是「策略认为自己在执行 a」与「关节真正得到 τ」之间有一条**结构化、慢变、可辨识**的缝。它既不是 aleatoric 噪声（不是零均值抖动），也不是 R69 的 epistemic 歧义（不是「选左还是选右」）——它是**兑现误差**。更妙的是，这条缝可以被电机自己测量：d 轴注入（i_q≈0，SPM 无磁阻转矩）可以在静止状态下测 `R_s, L_d`；电压阶跃测死区；母线/相电流测偏置；受控自由旋转测 `ψ_f`。R69 要「问人」，R70 可以「问电机」——而且问电机不打扰任何人、不移动、只发热。

**灵感 2（轻量化设计 → 质量是共享资源，减重是在借债）**
直觉：轻量化的收益是 `J↓`：同样扭矩加速度更大、带宽更高、能耗更低。代价同时到达：`δa = δτ/J`，扭矩噪声被 `1/J` 放大；`C_th ∝ m`，同样铜损升温更快、热时间常数更短；结构变薄让一阶模态 `ω_1` 下移，可能进入控制带宽。于是「敏捷 / 脆弱 / 热缓冲 / 结构」四者共享同一个质量预算。R69 把「安全」当成运行时可以靠 λ 买到的量；轻量化说明**安全裕度有一部分是设计时用质量买来的，运行时买不到**。这要求第一次引入设计–控制共设计，而不是继续在运行时加一层缩放。

**灵感 3（轻量化 × 热 → 打破「不确定就慢」的单调铁律）**
直觉：这是本轮最重要的反直觉结论。R68/R69 的保守主义是一条单调铁律：不确定 ↑ ⇒ 速度 ↓。但对电机，低速往往意味着**更长时间的保持扭矩**（重力、摩擦、预紧），铜损 `∫ i²R dt` 随 `1/v` 发散；而高速受反电动势/铁损限制。因此热安全速度集合通常是一个区间 `[v_min, v_max]`，**不包含 0**。当不确定性升高时，正确动作可能是「快速穿越高扭矩区」「机械抱闸停驻」或「换一条低扭矩路径」，而不是「慢爬」。轻量化让 `C_th` 更小，这个非单调性更强——**身体越轻，越不能靠慢来兜底**。

**灵感 4（三层串行不确定性 → 严格包含 R69）**
直觉：R69 的两分法是「选择」内部的分解；本轮加的是「选择 → 兑现 → 结构」的串行链。安全论证必须逐级收紧：先选模态（R69），再证该模态的扭矩可实现（TFC/OPER），再证结构不被激励坏（SLC）。当驱动理想（ψ_f 已知、T_m 远低于 T_crit、电压/电流非绑定、结构刚性）时，投影是恒等、热窗是全速域，REAL-RAS **逐指令等于** FLUID-RAS。新层只做加法，不放松旧层的任何安全结论。

**灵感 5（辨识的自指性 → 问电机会改变电机；轻量化让它更脆弱）**
直觉：EID 注入本身产热、可能加速退磁；高温时信息价值高，但激励成本与风险也高。更严重的是「认证效应」：一旦一个偏置的 `ψ̂_f` 被写进证书，系统会带着错误的安全裕度全速运行，而辨识动作恰好把它推向那个错误极限。R69 说「问错比不问更危险」，本轮升级为「**认错扭矩比不认识扭矩更危险**」。轻量化把热缓冲削薄，正是让这种错误最难被吸收的设计选择。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（REAL-RAS 总览与三不变式）** REAL-RAS = (DFM, EID, THM, TFC, OPER, RPROJ, SLC, CDC, RAS-WM⁂)。三不变式：
(i) **实时流零学习写操作**（继承 R68/R69）；
(ii) **驱动证书**：每条指令必须携带扭矩保真裕度 `ε_τ` 与热余量 `h_T`，不满足者必须经 `Π_F` 投影、降额或换模态，不得直接执行；
(iii) **统一热-能量-寿命账户**：任务动作与信息动作共享同一热预算 `Q_max` 与损伤预算 `D_max`；「减速」也必须记账（保持扭矩不是免费的）。

**定义 311（PMSM-FOC 驱动模型 DFM）** 状态 `x_a=(i_d,i_q,ω,T_w,T_m)`，参数 `θ_a=(R_s,L_d,L_q,ψ_f(T_m),T_dead,δ_i,δ_v)`。电压方程 `v_d=R_s i_d+L_d i̇_d−ω_e L_q i_q`，`v_q=R_s i_q+L_q i̇_q+ω_e(L_d i_d+ψ_f)`；扭矩 `τ=(3/2)p[ψ_f i_q+(L_d−L_q)i_d i_q]+τ_cog+τ_f`。温度依赖 `R_s(T_w)=R_s0(1+α_cu ΔT_w)`、`ψ_f(T_m)=ψ_f0(1+α_m ΔT_m)`，`α_m<0`。

**定义 312（可实现性与可实现裕度 ρ）** 对规划块 `a_{t:t+H}`，可行集 `F(x_a)={i : i_d²+i_q²≤I_max², v_d²+v_q²≤V_max², h_T≥0, f_sw≤f_max}`。`ρ(a)=min_{t≤H} slack_F(a_t)`（归一化裕度）；可实现 ⇔ `ρ≥0`。不可实现时用修复算子 `Π_F`（缩放时间轴 / 降低 i_q / 换模态 / 插入抱闸）。

**定义 313（驱动不确定性三分 U_act）** `U_act=(U_param,U_thermal,U_struct)`：参数后验、磁钢温度不可观测、结构柔顺与未建模振动。它与 R69 的 `U_ale/U_epi` **串行**而非并列：R69 决定「选哪个动作」，R70 决定「这个动作能否兑现」。

**定义 314（电气自辨识 EID；电机即传感器）** 信息动作 `e` 不再是注视/探针/问句，而是 d 轴高频注入、电压阶跃、受控自由旋转反电动势测量、主动短路。对 SPM 取 `i_q≈0` 时净扭矩≈0。目标：估计 `R_s,L_d,L_q,ψ_f,T_dead,δ_i`。定义**信息-热效率** `η_EID(e)=I_θ(e)/Q_loss(e)`（Fisher 信息 / 焦耳热）。**可以在不动的条件下问电机。**

**定义 315（双节点热模型与降额 THM）** `C_w Ṫ_w=P_cu+P_iron−(T_w−T_m)/R_wm−(T_w−T_amb)/R_wa`，`C_m Ṫ_m=(T_w−T_m)/R_wm−(T_m−T_amb)/R_ma`，`P_cu=(3/2)(i_d²+i_q²)R_s(T_w)`。轻量化 ⇒ `C_w,C_m↓`。热余量 `h_T=T_crit−T̂_m−k_σ σ_T`；连续扭矩 `τ_cont(h_T,v)=min(τ_I,τ_V(v),τ_T(h_T))`。

**定义 316（速度–扭矩–热运行包络 OPER 与非单调安全窗）** `E_op(T_w,T_m,V_bus,v)` 不是盒子。定义热安全速度窗 `𝒱_safe={v : ∫ τ(v,t)²R_s/k_t² dt ≤ Q_max, h_T≥0}`。重力/摩擦下低速需长时间保持扭矩 ⇒ 焦耳热随 `1/v` 发散；高速受反电动势与铁损限制 ⇒ `𝒱_safe` 可为 `[v_min,v_max]`，**不含 0**。

**定义 317（扭矩保真证书 TFC）** 对指令 a 证明 `|τ_actual−τ_cmd|≤ε_τ`（高概率），`ε_τ=(3/2)p(ψ_f^max δi_q+i_q δψ_f)+ε_cog+ε_fric`，`δψ_f=|∂ψ_f/∂T|δT_m+δ_sat`。安全包络一律用 `τ_cmd+ε_τ` 计算；若不可证，改用最坏 `ψ_f(T_crit)`。

**定义 318（惯性–保真耦合与脆弱度）** `δa=δτ/J`；脆弱度 `Φ=σ_τ/J`。时间最优移动 `T∝√J` 时，位置噪声方差 `Var(x)∝σ_τ²T³/(3J²)∝σ_τ²/√J` ⇒ **越轻越抖**。定义 `J_min(σ_τ,e_max,T_task)` 为满足跟踪容差的最小惯量。

**定义 319（轻量化结构证书 SLC）** 质量预算 `m≤m_max`；一阶模态 `ω_1≥k_ω ω_c`；最坏负载下应力/柔度满足可靠度 `β`；疲劳寿命 `≥N_mission`。质量、刚度、热容、传动比强耦合，不能分别优化。

**定义 320（安全调整敏捷度与共设计 CDC）** `J_SA(d,π)=E[perf]−α·Risk−β·Age−γ·Φ`，设计变量 `d=(质量分布, 电机选型, 减速比, 冷却, 刚度)`，s.t. `m≤m_max`、SLC、TFC、热约束。设计–控制联合优化，而非「先设计后控制」。

**定义 321（热感知风险动作 TARA；打破速度单调性）** λ 不再是速度的单调递减函数。定义安全动作集 `𝒮_safe={减速, 保持, 快速穿越高扭矩区, 机械抱闸, 停驻冷却, 换低扭矩路径}`；选择 `s*=argmin_{s∈𝒮_safe} Risk(s)`。在热约束下，「加速穿越」或「抱闸驻停」可能严格优于「慢爬」。

**定义 322（寿命/损伤预算）** `D(t)=∫[A·e^{−E_a/(kT_m)}+C·(ΔT_cycle)^p+demag(i_d,i_q,T_m)]dt≤D_max`。轻量化降低 `C_th` ⇒ 温度循环幅度/频率上升 ⇒ 疲劳与退磁加速。

**定义 323（电气观测完整性 EOI 与攻击面）** 电流传感器偏置/增益欺骗、母线电压篡改、温度传感器故障、参数注入、以 EID 为名的过流诱导。`ℰ_elec`。若 EOI 不过，禁用基于辨识的降额，退回最坏 `ψ_f(T_crit)`。

**定义 324（耦合证书 J_REAL）** `J_REAL=(J_FLUID, torque_fidelity, thermal_headroom, demag_margin, structural_margin, fragility, age_budget, design_cert_hash, real_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ TFC ∧ h_T≥0 ∧ demag_margin≥0 ∧ SLC ∧ D≤D_max`。

**定义 325（两级包含与退化）** 运行时投影 `Π_F` + 设计时包络。若 `θ_a` 已知、`T_m<T_safe`、电压/电流非绑定、结构理想 ⇒ `Π_F=Id` 且 `𝒱_safe` 为全速域 ⇒ **REAL-RAS ≡ FLUID-RAS（逐指令）**。若 EOI/EID 不可信或磁钢温度不可观测 ⇒ 用 `ψ_f(T_crit)` 与 `τ_cont^worst` 全量降额 ⇒ 逐指令退回 R69，再退回 R68。安全侧只做加法。

**定义 326（辨识自指安全）** EID 注入本身产热、可能加速退磁；安全激励集 `E_safe={e : Q(e)≤Q_id, T̂_m+ΔT(e)<T_crit, i_d 不造成不可逆退磁}`。高温时信息价值高，但激励成本与风险也高；存在最优注入幅度（引理 21）。

```python
# IP-264 DFM：PMSM-FOC 驱动模型（扭矩、电压椭圆、双节点热）
class PMSMDrive:
    def torque(self, i_d, i_q, Tm):
        return 1.5*self.p*(self.psi_f(Tm)*i_q + (self.Ld(i_d,i_q)-self.Lq(i_d,i_q))*i_d*i_q)

    def feasible(self, i_d, i_q, w, Tw, Tm, Vbus):
        i_ok = i_d*i_d + i_q*i_q <= self.Imax**2
        v_ok = self.vd(i_d,i_q,w)**2 + self.vq(i_d,i_q,w,Tw,Tm)**2 <= (Vbus/1.732)**2
        t_ok = self.thermal_headroom(Tw,Tm) >= 0
        return i_ok and v_ok and t_ok

# IP-265 EID：电气自辨识（零净扭矩 / 低净扭矩）
def electrical_identify(drive, thermal, budget):
    e = choose_excitation(drive, thermal, budget)       # d 轴 HF 注入 / 阶跃 / 自由旋转
    if not in_E_safe(e, thermal): return None           # 辨识不能把自己烧坏
    y = drive.inject_and_measure(e)                     # i_d,i_q,v_d,v_q,w
    theta_hat, cov = rls_or_ekf(drive.model, e, y)      # Rs,Ld,Lq,psi_f,deadtime,offset
    return theta_hat, cov, fisher_info(e)/loss(e)       # eta_EID

# IP-266 THM：双节点热观测（绕组可直接测，磁钢只能估）
def thermal_observer(drive, theta_hat, i, w, dt):
    Tw = drive.update_winding(i, theta_hat, dt)         # Rs(T) 即温度计
    Tm, sig_Tm = drive.update_magnet(drive.Tm, Tw, dt)  # 不可观测部分显式保留
    return Tw, Tm, sig_Tm

# IP-267 TFC：扭矩保真界（把温度/偏置/死区折进 epsilon_tau）
def torque_fidelity(theta_hat, cov, i_q, Tm, sig_Tm):
    dpsi = abs(drive.dpsi_dT)*sig_Tm + drive.sat_bound(i_q)
    eps  = 1.5*drive.p*(drive.psi_max*drive.di_bound + i_q*dpsi) + drive.cog + drive.fric
    return eps

# IP-268/269 OPER + RPROJ：热窗 + 可实现性投影
def thermal_window(drive, Tw, Tm, Vbus, load):
    return [v for v in grid if drive.feasible(*profile(v, load), Tw, Tm, Vbus)]

def project_realizable(traj, drive, thermal, struct):
    if struct.violates(traj): return repair_structure(traj)
    v_ok = thermal.nearest_safe_speed(traj)
    i      = inverse_dynamics(traj, v_ok)
    i_proj = clip_to_current_circle_and_voltage_ellipse(i, drive)
    return trajectory_from(i_proj), real_margin(i_proj, drive)

# IP-272 TARA：热感知动作选择（可能加速/抱闸，而非一律减速）
def thermal_aware_action(cands, drive, thermal, r69_lam):
    best = None
    for s in (slow, hold, fast_cross, brake, park, low_torque_path):
        if not drive.feasible_action(s): continue
        r = risk(s, thermal) + r69_lam*uncertainty_penalty(s)
        best = min(best, (r, s), key=lambda z: z[0])
    return best[1]

        id_res = M.eid.identify(M.drive, M.thermal, M.budget)
        if id_res: M.theta_a, M.cov_a, _ = id_res
    Tw, Tm, sig_Tm = M.thm.update(M.drive, M.theta_a, M.last_i, M.dt)
    # 3) 扭矩保真 + 可实现性投影
    eps_tau = M.tfc.bound(M.theta_a, M.cov_a, mode.i_q, Tm, sig_Tm)
    traj    = M.tara.select(mode, M.drive, M.thm, M.lam_from_r69)
    traj, rho = M.rproj.project(traj, M.drive, M.thm, M.slc)
    if rho < 0 or M.slc.violates(traj):
        traj, rho = M.rproj.worst_case_fallback(traj, M.drive)   # 全量降额
    # 4) 安全包络用 τ_cmd + ε_τ 计算；λ 承接 R69
    lam = M.efs.risk_scale(traj, eps_tau, U_ale + U_epi_after)
    k   = M.c_ras_wm.certified_prefix(traj, ..., wm_preds_worst_case)
    # 5) 执行 + 记账 + 异步审计
    M.thermal.commit(traj); M.age.commit(traj)
    M.vqa_e.submit_async(M.theta_a, M.cov_a, eps_tau, rho, M.eid.last)
    M.vqa_i.submit_async(...)                                   # 继承 R69
    return k, lam, traj, (U_ale, U_epi_after, rho, eps_tau)
```

## 3. 推导

**引理 19（扭矩误差传播与温度敏感性）** 由 `τ=(3/2)p ψ_f i_q` 与 `ψ_f(T_m)` 的温度依赖，有
`δτ ≤ (3/2)p(ψ_f δi_q + i_q |α_m| ψ_f0 δT_m) + ε_cog + ε_fric`。
加速度误差 `δa=δτ/J`。系：**磁钢温度的不可观测度 `δT_m` 直接以 0.1%/°C 的量级进入安全包络**，且被轻量化的 `1/J` 放大到运动层；`R_s(T_w)` 可电气观测，但 `T_m` 只能通过热模型弱观测——这决定了本轮的最大风险所在。

**引理 20（热安全速度窗的非单调性）** 设移动距离 D、保持扭矩 `τ_h`（重力/摩擦）、速度 v。低速时 `T=D/v`，铜损 `Q_cu≈(τ_h/k_t)²R_s·D/v`，当 `v→0` 时 `Q_cu→∞`；高速时反电动势使可用 `i_q` 下降、铁损 `P_iron∝ω²` 上升。故总热负载 `Q(v)` 在 `(0,∞)` 上存在内点极小 `v*`，`𝒱_safe` 一般为 `[v_min,v_max]` 且 `0∉𝒱_safe`。系：**R68/R69 的「不确定 ⇒ 减速」在热约束下不再单调安全；轻量化（C_th↓）让该效应更强**。

**引理 21（EID 的信息-热效率上界与最优注入）** 高频注入下 Fisher 信息 `I_θ(e)` 随注入幅值平方增长，但焦耳热 `Q∝i²` 同阶增长，故 `η_EID` 受信噪比与采样率上界约束；磁饱和使 `∂ψ_f/∂i→0`，大电流不再带来成比例信息。因此存在最优注入幅值 `i*`，且高温时 `T_m` 接近 `T_crit` 使 `E_safe` 收缩、可用信息下降——**信息不是免费的，辨识会消耗它试图保护的热余量**。

**引理 22（轻量化的脆弱度放大）** 时间最优移动 `T∝√J`。对白噪声扭矩扰动 `σ_τ`，位置方差 `Var(x)=σ_a²T³/3=(σ_τ/J)²T³/3∝σ_τ²/√J`。故 `J↓` 使敏捷度 `∝1/√J` 提升、同时使位置抖动 `∝J^{−1/4}` 恶化；存在 `J_min` 使跟踪容差可满足。系：**轻量化不是单调收益，存在由执行器噪声决定的内点最优质量**。

**引理 23（共设计的内点最优）** 在「质量–惯量–热容–刚度」的一维参数化下，`J_SA(m)` 的收益项（时间、能耗）随 m 下降而上升，风险项（脆弱度 `∝1/√J`、热时间常数 `∝m`、模态 `ω_1∝√k/m`）随 m 下降而上升；在 A99（各项单调、光滑、端点发散）下 `J_SA` 存在内点极大，最优质量 `m*` 严格大于「纯性能最优」的质量。系：**顺序设计（先减重再调控制）会系统性过度轻量化**。

**定理 18（REAL-RAS 严格包含 FLUID-RAS）** 若 `θ_a` 已知、`T_m<T_safe`、电压/电流约束非绑定、结构刚性（`SLC` 自动满足），则 `Π_F=Id`、`𝒱_safe` 为全速域、`ε_τ=0`，REAL-RAS 与 FLUID-RAS 在任意状态上逐指令相同。一般情形下 REAL-RAS 只在 FLUID-RAS 的动作上追加可实现性/热/结构约束，认证安全侧不减。

**定理 19（热–退磁安全不变式）** 若每条执行指令满足瞬时 `h_T≥0`、累积 `Q≤Q_max` 与 `D≤D_max`，且 `ε_τ` 覆盖参数/温度不确定度，则在 A100（热模型耗散性、`T_crit` 边界）下 `T_m(t)<T_crit`、不可逆退磁概率 `≤δ`。证明用双节点热模型的耗散不变集 + 扭矩误差上界构成的屏障证书。

**定理 20（共设计支配顺序设计）** 在定义 320 的耦合目标下，若质量–热–刚度–控制耦合强（A101：交叉偏导非零），则联合优化的 Pareto 前沿严格支配「先设计后控制」的两阶段解；且存在质量预算 `m_max` 使顺序设计越过 `m*`、进入风险上升区。系：**R70 的 resolution bonus 有一部分必须在设计时兑现，运行时 λ 买不到**。

**定理 21（非单调保守性与安全动作集）** 在引理 20 的热窗下，对任意不确定性水平 `U`，存在负载/温升区间使 `Risk(slow)>Risk(fast_cross)` 或 `Risk(slow)>Risk(brake)`。因此单调减速策略在热约束下不是最优保守策略；TARA 在 `𝒮_safe` 上取最小风险，且当热约束不活跃时退化为 R69 的「不确定 ⇒ 减速」。

## 6. 本轮最大风险

**一句话**：REAL-RAS 把安全押在「电–热–力模型可信」这一前提上，而**轻量化恰好削薄了吸收模型误差的热/结构缓冲**——一旦磁钢温度不可观测（`T_m` 只能靠热模型外推）或电流传感器被偏置，系统会**用「指令扭矩」签发证书、却用「真实扭矩」还债**，更轻的身体没有热惯性来承受这笔债；认错扭矩，比不认识扭矩更危险。

**次级风险与缓解**：
1. **磁钢温度弱可观测** → `σ_Tm` 显式进入 `ε_τ` 与 `h_T`，用 `ψ_f(T_crit)` 做最坏兜底，绝不把点估计当证书；
2. **EID 自损（发热/退磁）** → `E_safe` 安全激励集 + `Q_id` 预算 + 引理 21 的最优注入，高温时优先冷却而非辨识；
3. **电气投毒/偏置** → EOI 多源一致性（相电流和 ≈ 0、母线功率守恒、反电动势交叉校验）+ `ℰ_elec` 对抗集；
4. **轻量化过度** → SLC + 引理 22 的 `J_min` + 共设计内点 `m*`，禁止越过结构/脆弱度边界；
5. **非单调保守性被误用** → TARA 只在 `𝒮_safe` 内取最小风险，热约束不活跃时严格退化为 R69 的「不确定 ⇒ 减速」。

**定义 315（THM 与降额）** 双节点热模型；`C_th∝m`（轻量化 ⇒ 热缓冲↓）；`τ_cont(h_T,v)=min(τ_I,τ_V,τ_T)`。

**定义 316（OPER 非单调安全窗）** 低速保持扭矩使 `Q_cu∝1/v` 发散，高速受反电动势/铁损限制；`𝒱_safe` 可为 `[v_min,v_max]` 且 `0∉𝒱_safe`。

**定义 317（TFC）** `ε_τ=(3/2)p(ψ_f^max δi_q+i_q δψ_f)+ε_cog+ε_fric`；`δψ_f=|∂ψ_f/∂T|δT_m+δ_sat`；安全包络用 `τ_cmd+ε_τ`；不可证用 `ψ_f(T_crit)`。

**定义 318（惯性–保真耦合）** `δa=δτ/J`；`Φ=σ_τ/J`；时间最优 `T∝√J` 下位置噪声 `Var∝σ_τ²/√J` ⇒ 越轻越抖；定义 `J_min`。

**定义 319–320（SLC 与 CDC）** 质量预算、模态、可靠度、疲劳；`J_SA(d,π)` 设计–控制联合优化，`d=(质量分布,电机,减速比,冷却,刚度)`。

**定义 321–322（TARA 与寿命）** `s*=argmin_{s∈𝒮_safe}Risk(s)`，允许加速穿越/抱闸；`D(t)` 含 Arrhenius、Coffin–Manson、退磁项。

**定义 323–324（EOI 与 J_REAL）** 电气观测完整性 + `ℰ_elec`；`J_REAL` 并入扭矩/热/退磁/结构/脆弱/寿命与设计证书哈希。

**定义 325–326（两级包含与辨识自指）** 理想驱动下 `REAL-RAS≡FLUID-RAS`；不可信时用 `ψ_f(T_crit)`/`τ_cont^worst` 全量降额，逐指令退回 R69→R68；`E_safe` 约束 EID 自身的热/退磁代价。

## 3. 关键算法伪代码

```python
# IP-264 DFM：扭矩与可行域
class PMSMDrive:
    def torque(self, i_d, i_q, Tm):
        return 1.5*self.p*(self.psi_f(Tm)*i_q + (self.Ld(i_d,i_q)-self.Lq(i_d,i_q))*i_d*i_q)
    def feasible(self, i_d, i_q, w, Tw, Tm, Vbus):
        return (i_d*i_d+i_q*i_q <= self.Imax**2
                and self.vd(i_d,i_q,w)**2 + self.vq(i_d,i_q,w,Tw,Tm)**2 <= (Vbus/1.732)**2
                and self.thermal_headroom(Tw,Tm) >= 0)

# IP-265 EID：零净扭矩电气辨识
def electrical_identify(drive, thermal, budget):
    e = choose_excitation(drive, thermal, budget)          # HF 注入 / 阶跃 / 自由旋转
    if not in_E_safe(e, thermal): return None              # 不许把电机烧坏/退磁
    theta_hat, cov = rls_or_ekf(drive.model, e, drive.inject_and_measure(e))
    return theta_hat, cov, fisher_info(e)/loss(e)          # eta_EID

# IP-266 THM：双节点热观测
def thermal_observer(drive, theta_hat, i, w, dt):
    Tw = drive.update_winding(i, theta_hat, dt)            # Rs(T) 本身就是温度计
    Tm, sig_Tm = drive.update_magnet(drive.Tm, Tw, dt)     # 不可观测度显式保留
    return Tw, Tm, sig_Tm

# IP-267 TFC：扭矩保真界
def torque_fidelity(drive, theta_hat, cov, i_q, sig_Tm):
    dpsi = abs(drive.dpsi_dT)*sig_Tm + drive.sat_bound(i_q)
    return 1.5*drive.p*(drive.psi_max*drive.di_bound + i_q*dpsi) + drive.cog + drive.fric

# IP-269 RPROJ：可实现性投影
def project_realizable(traj, drive, thermal, struct):
    if struct.violates(traj): traj = repair_structure(traj)
    traj = thermal.nearest_safe_speed(traj)                # 回到 V_safe
    i    = clip_to_current_circle_and_voltage_ellipse(inverse_dynamics(traj), drive)
    return trajectory_from(i), real_margin(i, drive)

# IP-272 TARA：热感知动作选择（允许加速/抱闸）
def thermal_aware_action(cands, drive, thermal, lam):
    opts = (slow, hold, fast_cross, brake, park, low_torque_path)
    ok   = [s for s in opts if drive.feasible_action(s)]
    return min(ok, key=lambda s: risk(s, thermal) + lam*uncertainty_penalty(s))

# IP-274 主闭环（继承 R69，仅在执行前插入 REAL 层）
def REAL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    U_epi = M.cia.update_belief(...) if U_epi > TAU_EPI else U_epi
    mode  = select_mode(modes, U_epi)
    if M.budget.info_electrical_ok() and M.eoi.trusted():
        r = M.eid.identify(M.drive, M.thm, M.budget)
        if r: M.theta_a, M.cov_a, _ = r
    Tw, Tm, sig_Tm = M.thm.update(M.drive, M.theta_a, M.last_i, M.dt)
    eps_tau = M.tfc.bound(M.theta_a, M.cov_a, mode.i_q, Tm, sig_Tm)
    traj    = M.tara.select(mode, M.drive, M.thm, M.lam_from_r69)
    traj, rho = M.rproj.project(traj, M.drive, M.thm, M.slc)
    if rho < 0 or M.slc.violates(traj):
        traj, rho = M.rproj.worst_case_fallback(traj, M.drive)
    lam = M.efs.risk_scale(traj, eps_tau, U_ale + U_epi)
    k   = M.c_ras_wm.certified_prefix(traj, ..., wm_preds_worst_case)
    M.thermal.commit(traj); M.age.commit(traj)
    M.vqa_e.submit_async(M.theta_a, M.cov_a, eps_tau, rho, M.eid.last)
    M.vqa_i.submit_async(...)
    return k, lam, traj, (U_ale, U_epi, rho, eps_tau)
```

## 4. 推导

**引理 19（扭矩误差传播）** `δτ ≤ (3/2)p(ψ_f δi_q + i_q|α_m|ψ_f0 δT_m)+ε_cog+ε_fric`，`δa=δτ/J`。系：磁钢温度不可观测度直接进安全包络，并被 `1/J` 放大。

**引理 20（热安全速度窗非单调）** 低速 `T=D/v`，`Q_cu≈(τ_h/k_t)²R_s D/v → ∞`；高速反电动势/铁损上升。故 `Q(v)` 有内点极小 `v*`，`𝒱_safe=[v_min,v_max]` 且 `0∉𝒱_safe`。系：不确定 ⇒ 减速在热约束下不再单调安全；轻量化增强该效应。

**引理 21（EID 信息-热效率上界）** `I_θ` 与 `Q_loss` 同阶随 `i²` 增长，`η_EID` 受 SNR/采样率上界；饱和使 `∂ψ_f/∂i→0`；存在最优注入 `i*`，高温时 `E_safe` 收缩。信息不是免费的。

**引理 22（轻量化脆弱度放大）** 时间最优 `T∝√J`，`Var(x)=σ_a²T³/3=(σ_τ/J)²T³/3∝σ_τ²/√J`。`J↓` 提升敏捷 `∝1/√J`、恶化抖动 `∝J^{−1/4}`；存在 `J_min`。

**引理 23（共设计内点最优）** 收益项随 m↓ 升、风险项（`1/√J`、`C_th∝m`、`ω_1∝√(k/m)`）随 m↓ 升，`J_SA(m)` 存在内点极大 `m*`，且 `m*>m_perf`。顺序设计系统性过度减重。

**定理 18（严格包含 FLUID-RAS）** 理想驱动（`θ_a` 已知、`T_m<T_safe`、电压/电流非绑定、结构刚性）下 `Π_F=Id`、`𝒱_safe` 全速域、`ε_τ=0` ⇒ 与 FLUID-RAS 逐指令相同；一般情形只追加约束，安全侧不减。

**定理 19（热–退磁安全不变式）** 若执行指令满足瞬时 `h_T≥0`、累积 `Q≤Q_max`、`D≤D_max` 且 `ε_τ` 覆盖参数/温度不确定度，则 `T_m<T_crit`、不可逆退磁概率 ≤ δ（双节点热模型耗散不变集 + 屏障证书）。

**定理 20（共设计支配顺序设计）** 质量–热–刚度–控制强耦合时，联合优化 Pareto 前沿严格支配「先设计后控制」；存在 `m_max` 使顺序设计越过 `m*` 进入风险上升区。系：resolution bonus 有一部分必须在设计时兑现。

**定理 21（非单调保守性与 TARA）** 存在负载/温升区间使 `Risk(slow)>Risk(fast_cross)` 或 `Risk(slow)>Risk(brake)`；TARA 在 `𝒮_safe` 上取最小风险，热约束不活跃时严格退化为 R69 的「不确定 ⇒ 减速」。

## 7. 本轮最大风险

**一句话**：REAL-RAS 把安全押在「电–热–力模型可信」上，而**轻量化恰好削薄了吸收模型误差的热/结构缓冲**——若磁钢温度不可观测或电流传感器被偏置，系统会**用「指令扭矩」签发证书、用「真实扭矩」还债**，更轻的身体没有热惯性承受这笔债；认错扭矩，比不认识扭矩更危险。

**次级风险与缓解**：磁钢温度弱可观测（`σ_Tm` 入 `ε_τ`/`h_T`，`ψ_f(T_crit)` 兜底）；EID 自损（`E_safe`+`Q_id`+引理 21 最优注入）；电气投毒（EOI 多源一致性 + `ℰ_elec`）；轻量化过度（SLC + `J_min` + 共设计 `m*`）；非单调保守性误用（TARA 仅在 `𝒮_safe` 内取最小风险，热约束不活跃时退化为 R69）。
