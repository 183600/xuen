# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「地形适应」×「通用机器人」）· TerrainCert-Gen：地形条件化证书 × 可审计通用性

> 第 54 轮把技能组合推进为动作-鲁棒性联合证书 `J=(ρ,A_cert,γ_ce,δ_a)`，但它仍压着一个从未进入证明的变量：**地形 `c`**。本轮两个灵感词正好从两侧击穿这一盲点：**地形适应**说明 `c` 不是离散标签，而是通过本体感知隐约可见、持续演化的隐状态；**通用机器人**说明“什么都会”不能被当作营销声明，而必须改写为“任务 × 地形乘积空间上的可审计覆盖 + 显式拒识”。核心矛盾：**H22（证书的地形影子失效）**——`α_S(a)`、`ρ_S(d)`、`compat(S_i,S_j)`、`J` 全部隐含条件于某个地形模型，一旦机器人从瓷砖走到碎石、从干地走到湿地，证书文本仍在、语义却已失效；**H23（通用性的不可审计性）**——通用机器人的能力按“任务”被宣称，却在“任务×地形”上被证伪，且没有机制区分“我不会”与“我假装会”。本轮命题：**证书不是静态断言，而是带地形有效域、时效与拒识义务的运行期契约；通用性不是平均成功率，而是风险-覆盖前沿上可审计的已证集合。**

## 0. 直觉与动机

**灵感 1（地形是隐状态，不是标签）**
直觉：传统“地形分类”把地形切成 `flat / gravel / grass / sand` 几个离散类，但真正决定动力学的是连续隐参数 `c = (μ, 坡度 α, 刚度 k, 粗糙度 r, 内聚力, 接触时序)`。机器人看不到 `c`，只能看到本体感知与视觉的投影 `z_t = φ(o_t,a_t)`——本文称 **地形指纹**。因此“这张证书在草地上有效”在工程上应写成“当后验 `b_t(c)` 的质量落在证书的有效域 `C_S` 内时，证书才 in-force”。没有 `C_S` 的证书是不可证伪的：它不是错误，而是根本没有 truth condition。更关键的是，地形指纹只需对证书判据充分，不必对地形完全充分——我们不需要识别“这是哪种土”，只需要判断“鲁棒性谱是否仍达标”。

**灵感 2（影子失效：证书会“看起来有效”）**
直觉：第 54 轮的 `J` 像一份合同，但合同有隐含前提（地形、载荷、接触模式）和有效期。地形漂移时，前提被悄悄违反，合同却没有自动作废——这就是 **shadow invalidation（影子失效）**：存储的证书 `valid=true`，实际 soundness 已为 0。解决方法不是“更频繁地重训”，而是把证书从布尔值升级为三元状态 `in-force / suspect / expired`，由后验支撑度与时效共同裁决。更进一步：地形变化有特征时间 `τ_c`，检测与重认证有延迟 `τ_det+τ_rec`；若 `τ_det+τ_rec ≥ τ_c`，则任何非退化证书都无法维持 in-force——此时唯一 sound 的策略是退到 **安全内核模式** 并显式拒识。这把“适应”从感知问题提升为控制带宽问题。

**灵感 3（地形适应是对偶控制：动作既执行任务又识别地形）**
直觉：自适应控制里的 **dual control** 告诉我们，动作同时承担“控制”和“辨识”两个角色。第 54 轮的动作剖面只问了“这个动作能否完成任务”，没问“这个动作会让我对地形更确定还是更不确定”。一次试探性落脚、一次轻微打滑测试、一次步态切换，既可能获得高信息增益，也可能把系统推出安全内核。因此地形适应不能是“先识别再行动”，也不能是无约束的主动探索，而应是 **证书感知的主动探测**：只在安全内核允许的动作集内选探针，用信息增益/风险比排序，并设置地形信息预算 `B_info`。这把探索-利用权衡写进了证书体系，而不是留给调参。

**灵感 4（通用性 = 可审计覆盖 + 显式拒识，而非平均成功率）**
直觉：一个“通用机器人”不是每项任务都做得很好的机器人，而是 **知道自己会什么、不会什么，并对不会的部分拒绝或转介** 的机器人。形式上拆成两层：**安全内核 `K`** 在全部允许地形 `C` 上一致 sound（注意：不是“与地形无关”，而是“有对 `C` 内任意地形的统一证明或鲁棒不变集”，因此必然保守）；**任务专门化 `S_τ`** 带地形有效域。通用性证书 `G=(K,S,Ω,∂Ω,π_ref)` 中，`Ω` 是已证的（任务×地形）集合，`∂Ω` 是覆盖前沿，`π_ref` 是拒识/询问/自适应探测策略。一个从不说“不”的通用机器人，要么不通用，要么不诚实。工程上应报告 **风险-覆盖前沿（risk-coverage frontier）**，而不是单点成功率。

**灵感 5（地形组合是路径依赖的，且云边地形先验会错位）**
直觉：第 54 轮把技能组合写成图搜索，默认 `compat` 可合并。但地形条件下，组合不仅要求各技能有效域相交，还要求 **转换地形**（`S_i` 末态到 `S_j` 初态之间的落脚/接触序列）也落在两者共同有效域内，并要求步态相位连续。于是组合算子 `⊗` 一般 **不满足结合律**：`(S_1⊗S_2)⊗S_3` 与 `S_1⊗(S_2⊗S_3)` 的地形包络可以不同，因为中间态接触相位不同。云端掌握全局地形图但粒度粗，边端掌握局部后验但视野窄；云端承诺“该路径在地形区域 `R` 上有效”，边端必须用 `z_e` 核对 `R` 并检查后验支撑，否则触发拒识与重规划。这把第 54 轮的 `γ_ce` 扩展为 **地形握手**，而不是只对齐动作。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（地形隐状态、指纹与后验）**
地形隐状态 `c ∈ C ⊆ ℝ^m`，`c_{t+1} ~ T(·|c_t,a_t)`。本体/视觉观测经指纹映射 `z_t = φ(o_t,a_t) ∈ Z ⊆ ℝ^k`。边端地形后验 `b_t(c) = P(c | z_{1:t}, a_{1:t})`。校准映射 `ψ : Z → 2^C` 满足覆盖保证 `P(c_t ∈ ψ(z_t)) ≥ 1-α_z`。称 `φ` 对证书泛函 `F∈{α_S,ρ_S}` **ε-充分**，若 `|F(c) - F(ψ^{-1}(z))| ≤ ε` 对所有 `c∈C` 成立。

**定义 122（地形条件化技能证书与有效域）**
技能 `S` 的动作剖面与鲁棒性谱在地形条件下为 `α_S(a|c)`、`ρ_S(d|c)`。其 **地形有效域**
```
C_S = { c∈C | ∀a∈A_T: α_S(a|c) ≥ θ_cov  ∧  ∀d∈𝔇_ρ: ρ_S(d|c) ≥ ρ_min }。
```
证书 `J_S^c = (α_S,ρ_S,A_cert,C_S,z_ref,τ_val)`。**in-force 判据**：
`P_{b_t}(C_S) ≥ 1-ε_sup` 且 `age(J_S^c) ≤ τ_val`；否则状态为 `suspect`（后验不支撑）或 `expired`（超时），二者统称 **shadow-invalid**。关键：证书是对 `c` 的集合值断言，不是对地形标签的断言。

**定义 123（地形条件化组合与路径依赖）**
组合图 `G_S(c)=(V,E)`，边 `(i,j)` 需同时满足动作相容、转换成本与 **转换地形相容**：
```
compat(S_i,S_j|c) ≥ θ_a ∧ c_trans(A_i,A_j|c) ≤ τ_e ∧ c ∈ C_trans(i,j)。
```
有序路径 `P=⟨S_1,…,S_k⟩` 的 **地形包络**
```
C_P = ⋂_i C_{S_i}  ∩  ⋂_{i=1}^{k-1} C_trans(S_i,S_{i+1})，
```
并要求步态相位连续性谓词 `Φ(P)` 成立。称 `P` **地形可组合**，当且仅当 `C_P ≠ ∅`、`P_{b_t}(C_P) ≥ 1-ε_sup` 且 `Φ(P)=⊤`。一般地 `C_{(S_1⊗S_2)⊗S_3} ≠ C_{S_1⊗(S_2⊗S_3)}`，故证书必须记录 **有序分解**，不能先做无序交集再搜索。

**定义 124（证书时效与可行适应带宽）**
地形变化特征时间 `τ_c`，检测延迟 `τ_det`，重认证延迟 `τ_rec`。若在某路线上 `τ_det + τ_rec ≥ τ_c`，则不存在能持续保持 in-force 的非退化证书，称为 **适应带宽不足**；此时唯一 sound 策略是进入 **kernel-only 模式**：只执行安全内核动作并显式声明能力退化。反之称该路线 **可维持认证**。

**定义 125（可审计通用性证书）**
通用性证书 `G = (K, S, Ω, ∂Ω, π_ref)`：
- `K` 为安全内核谓词，要求 **对全部 `c∈C` 一致 sound**（可用鲁棒不变集/统一控制屏障证明），而非与地形无关；
- `S={S_τ}` 为带地形有效域的任务专门化技能集；
- `Ω = { (τ,c) | ∃ 有序技能链 P 使 τ 达成、J_P^c in-force、且与 K 组合 sound }` 为已证覆盖；
- `∂Ω` 为覆盖前沿（可从内部用多面体/核密度估计）；
- `π_ref` 为拒识策略：`(τ,c) ∉ Ω` 或后验不支撑时返回 `reject / ask / probe / fallback-K`，并签发 **拒识证书**（记录拒识理由与证据）。
称 `G` **可审计**，当且仅当 `K` 的统一证明、`Ω` 的审计日志、`π_ref` 的 soundness 三者齐备；只宣称 `Ω` 而不披露 `∂Ω` 与拒识行为者视为无效声明。

**定义 126（地形探测准入与信息预算）**
探针动作 `p`，信息增益 `IG(p)=H(b_t)-𝔼[H(b_{t+1})]`，风险 `Risk(p)=P(p∉A_K(c))+λ_ρ·𝔼[Δρ^-]+λ_c·cost(p)`。称 `p` **可准入**，当且仅当
```
p ∈ A_K(c) ∧ Risk(p) ≤ R_b ∧ IG(p) ≥ g_min。
```
地形信息预算 `B_info(t)` 随时间/任务阶段递减；预算耗尽时必须停止探测并转入 `reject / fallback-K`，不得用“再试一次”无限续命。

### IP-121 TFP（Terrain Fingerprint Profiler）

```python
def terrain_fingerprint(o_hist, a_hist, phi, psi, b_prev):
    z = phi(o_hist, a_hist)                 # 地形指纹
    C_support = psi(z)                      # 校准的集合值逆映射
    b_t = bayes_update(b_prev, z, a_hist)   # 边端后验
    return z, C_support, b_t, entropy(b_t)

def calibrate_psi(Z_cal, C_cal, alpha_z=0.05):
    # split-conformal：为每个 z 构造覆盖 c 的集合
    scores = [dist(c, phi_inverse(z)) for z, c in zip(Z_cal, C_cal)]
    q = quantile(scores, 1 - alpha_z)
    return lambda z: {c for c in C_grid if dist(c, phi_inverse(z)) <= q}
```

### IP-122 TEC（Terrain Envelope Certificate）

```python
def terrain_envelope(skill, C_grid, A_T, rho_min, theta_cov, r_erode=1):
    C_S = []
    for c in C_grid:
        if cover(skill.alpha, A_T, c, theta_cov) and \
           min(skill.rho(c).values()) >= rho_min:
            C_S.append(c)
    # 单边保守：腐蚀边界，只保留邻域也被证实的格点，宁可漏证不可误证
    C_S = erode(set(C_S), C_grid, radius=r_erode)
    if not C_S:
        return Envelope(empty=True, reason='no_terrain_support')
    z_ref = fingerprint_of(center(C_S))
    return Envelope(C_S, z_ref=z_ref, tau_val=estimate_tau_val(skill, C_S))
```

### IP-123 TRC（Terrain-Robust Composition）

```python
def terrain_robust_composition(skills, task, b_t, C_grid, theta_a, tau_e, eps_sup):
    G = build_terrain_graph(skills, C_grid, theta_a, tau_e)
    best = None
    for P in k_shortest_paths(G, start='root', goal=task, K=32):
        C_P = intersect_envelopes(P, C_grid)          # 含转换地形
        if not C_P: continue
        if posterior_mass(b_t, C_P) < 1 - eps_sup: continue
        if not phase_continuous(P): continue           # 有序分解，不可交换
        score = worst_robustness(P, C_P) - cost_align(P, C_P)
        best = max(best, (score, P, C_P), key=lambda x: x[0])
    if best is None:
        return ('reject', refusal_cert('no_terrain_composable_path', b_t))
    return ('ok', TerrainPlan(best[1], best[2]))
```

### IP-124 GPA（General-Purpose Audit）

```python
def audit_generality(K, skills, tasks, C_grid, alpha_env=0.01):
    # 1) 内核必须对 C_grid 内每个地形一致 sound，否则直接判不可审计
    for c in C_grid:
        if not verify_kernel_uniform(K, c):
            return ('invalid', 'kernel_not_uniform', c)
    # 2) 只在保守包络内累计已证覆盖，避免用乐观估计灌水
    Omega = set()
    for tau in tasks:
        for c in C_grid:
            if exists_valid_chain(tau, c, skills, K, alpha_env):
                Omega.add((tau, c))
    frontier = estimate_frontier(Omega, C_grid)
    return ('ok', GeneralityCert(K, Omega, frontier,
                                 refine_policy=risk_coverage_policy(Omega, frontier)))
```

### IP-125 TAP（Terrain Active Probing）

```python
def admissible_probe(p, b_t, K, R_b, g_min):
    a_p = kernel_safe_action(p, b_t)
    if a_p is None:                      # 探针必须落在安全内核动作集内
        return None
    IG = expected_information_gain(b_t, p)
    risk = expected_kernel_risk(p, b_t) + lambda_rho * expected_rho_loss(p, b_t)
    if risk <= R_b and IG >= g_min:
        return Probe(p, a_p, IG, risk)
    return None

def adapt_loop(b_t, skill, C_valid, B_info):
    while not in_force(b_t, C_valid) and B_info > 0:
        probes = [q for q in generate_probes(skill)
                  if (q := admissible_probe(q, b_t, K, R_b, g_min))]
        if not probes:
            return ('fallback_K', refusal_cert('no_admissible_probe', b_t))
        p = max(probes, key=lambda q: q.IG / (q.risk + 1e-9))
        execute(p.a_p); B_info -= probe_cost(p); b_t = update(b_t, p)
    if not in_force(b_t, C_valid):
        return ('expired', refusal_cert('info_budget_exhausted', b_t))
    return ('recertified', b_t)
```

### IP-126 CTJ（Cloud-Edge Terrain Joint Certificate）

```python
def cloud_edge_terrain_handshake(P_c, R_cloud, z_e, Delta_z, b_e, eps_sup):
    # 云端承诺路径在地形区域 R_cloud 上有效；边端用局部指纹核对
    if not region_consistent(z_e, R_cloud, Delta_z):
        return ('reject', 'terrain_region_mismatch', z_e, R_cloud)
    C_local = psi(z_e)
    if posterior_mass(b_e, P_c.terrain_envelope) < 1 - eps_sup:
        return ('reject', 'envelope_not_supported_locally', b_e)

    return ('ok', J_ext)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TFP | O(T·k) 在线；校准 O(N log N) | O(|Z|+|C_grid|) | 校准覆盖 `1-α_z`、指纹 ε-充分 |
| TEC | O(|C_grid|·|A_T|·|𝔇_ρ|) | O(|C_grid|) | 单边腐蚀、包络保守 |
| TRC | O(|S|²·|C_grid| + K·|P|·|C_grid|) | O(|S|²+|C_grid|) | 有序分解、相位连续、后验支撑 |
| GPA | O(|T|·|C_grid|·|S|) | O(|Ω|+|C_grid|) | 内核统一 sound、覆盖审计 |
| TAP | O(|P_probe|·(|C_grid|+IG)) | O(|P_probe|) | 探针落在内核动作集、预算闭合 |
| CTJ | O(|P|·|C_grid|) | O(|C_grid|) | 区域一致、包络后验支撑 |

**正确性定理（Terrain-Conditioned Generalist Soundness）**
假设第 54 轮 (A26)–(A28) 成立；并新增：**(A29)** 指纹校准满足 `P(c_t∈ψ(z_t))≥1-α_z` 且 `φ` 对 `α_S,ρ_S` 为 `ε`-充分；**(A30)** 包络估计单边保守，`Ĉ_S ⊆ C_S` 以概率 `≥1-α_env`；**(A31)** 后验支撑检验的误接受率 `≤ε_sup`，检测延迟 `≤τ_det`；**(A32)** 安全内核 `K` 在 `C` 上一致 sound，且所有探针限制在 `A_K` 内。若系统只在证书 in-force 且 `(τ,c)∈Ω` 时执行，则
```
P(fail) ≤ α_z + α_env + ε_sup + β_E
          + P(τ_c < τ_det+τ_rec) + P(B_info 耗尽) + Σ_d(1-ρ_min(d))。
```
且由拒识策略的定义，**P(在 Ω 之外静默部署)=0**：系统可以“不会”，但不会“假装会”。

**命题 1（组合的地形路径依赖）**
`C_{(S_i⊗S_j)⊗S_k} ≠ C_{S_i⊗(S_j⊗S_k)}` 一般成立。构造：令 `S_j` 为坡面横移、`S_k` 为下坡落脚，前者末态接触相位决定后者可用坡度区间；交换结合顺序会改变中间接触相位，从而改变 `C_trans`。故路径证书必须按有序序列计算，不能先合并再搜索。

**命题 2（适应带宽的可行性上界）**
若 `τ_det+τ_rec ≥ τ_c`，任何非退化证书的 in-force 时间占比趋于 0；此时“持续通用”与“持续 sound”不可兼得，唯一可证策略是 kernel-only + 显式拒识。换言之，**通用性存在一个由地形变化率决定的速度上限**。

**命题 3（覆盖-拒识权衡）**
固定安全内核 `K` 时，扩大已证覆盖 `Ω`（例如削弱包络腐蚀或放宽 `ε_sup`）必然单调提高误纳入风险。因此“更通用”不是免费的，必须报告风险-覆盖前沿，而不是仅报告平均成功率。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|

| 风险 | 等级 | 缓解 |
|---|---|---|
| 地形指纹不足导致证书索引错位 | 高 | 反事实探针 + 集成指纹 + 证书判据直接监督（非全地形重建） |

## 6. 本轮最大风险

**一句话**：地形条件化证书把“适应”从感知模块变成运行期契约，但其 soundness 同时依赖 **地形指纹对证书判据的 ε-充分性、包络估计的单边保守性、以及安全内核在地形全集上的一致 sound**；只要其中任一环乐观，系统就会在“证书仍显示有效”的假象下跨越到未证地形并静默违反内核，故必须以 **单边包络 + 后验支撑拒识 + 内核动作约束的主动探测** 三重保守护栏，宁可频繁拒识与退化，也绝不把“地形指纹相似”误当作“鲁棒性仍然成立”。

```python
def terrain_fingerprint(o_hist, a_hist, phi, psi, b_prev):
    z = phi(o_hist, a_hist)
    C_support = psi(z)
    b_t = bayes_update(b_prev, z, a_hist)
    return z, C_support, b_t, entropy(b_t)

def calibrate_psi(Z_cal, C_cal, alpha_z=0.05):
    scores = [dist(c, phi_inverse(z)) for z, c in zip(Z_cal, C_cal)]
    q = quantile(scores, 1 - alpha_z)
    return lambda z: {c for c in C_grid if dist(c, phi_inverse(z)) <= q}
```

### IP-122 TEC

```python
def terrain_envelope(skill, C_grid, A_T, rho_min, theta_cov, r_erode=1):
    C_S = []
    for c in C_grid:
        if cover(skill.alpha, A_T, c, theta_cov) and \
           min(skill.rho(c).values()) >= rho_min:
            C_S.append(c)
    C_S = erode(set(C_S), C_grid, radius=r_erode)   # 单边保守，宁可漏证
    if not C_S:
        return Envelope(empty=True, reason='no_terrain_support')
    return Envelope(C_S, z_ref=fingerprint_of(center(C_S)),
                    tau_val=estimate_tau_val(skill, C_S))

def cert_state(J, b_t, now, eps_sup):
    if now - J.issued > J.tau_val:            return 'expired'
    if posterior_mass(b_t, J.C_S) < 1 - eps_sup: return 'suspect'
    return 'in-force'
```

### IP-123 TRC

```python
def terrain_robust_composition(skills, task, b_t, C_grid, theta_a, tau_e, eps_sup):
    G = build_terrain_graph(skills, C_grid, theta_a, tau_e)
    best = None
    for P in k_shortest_paths(G, start='root', goal=task, K=32):
        C_P = intersect_envelopes(P, C_grid)           # 含 C_trans
        if not C_P: continue
        if posterior_mass(b_t, C_P) < 1 - eps_sup: continue
        if not phase_continuous(P): continue            # 有序分解，不可交换
        score = worst_robustness(P, C_P) - cost_align(P, C_P)
        best = max(best, (score, P, C_P), key=lambda x: x[0])
    if best is None:
        return ('reject', refusal_cert('no_terrain_composable_path', b_t))
    return ('ok', TerrainPlan(best[1], best[2]))
```

```python
def audit_generality(K, skills, tasks, C_grid, alpha_env=0.01):
```

```python
def admissible_probe(p, b_t, K, R_b, g_min):
    a_p = kernel_safe_action(p, b_t)
    if a_p is None: return None                        # 探针必须限入 A_K

def adapt_loop(b_t, skill, C_valid, B_info):
    while cert_state_from(b_t, C_valid) != 'in-force' and B_info > 0:
        probes = [q for q in generate_probes(skill)
                  if (q := admissible_probe(q, b_t, K, R_b, g_min))]
        if not probes:
            return ('fallback_K', refusal_cert('no_admissible_probe', b_t))
        p = max(probes, key=lambda q: q.IG / (q.risk + 1e-9))
        execute(p.a_p); B_info -= probe_cost(p); b_t = update(b_t, p)
    if cert_state_from(b_t, C_valid) != 'in-force':
        return ('expired', refusal_cert('info_budget_exhausted', b_t))
    return ('recertified', b_t)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TFP | O(T·k) 在线；校准 O(N log N) | O(|Z|+|C_grid|) | 校准覆盖 `1-α_z`、`ε`-充分 |
| TEC | O(|C_grid|·|A_T|·|𝔇_ρ|) | O(|C_grid|) | 单边腐蚀、包络保守 |
| TRC | O(|S|²·|C_grid| + K·|P|·|C_grid|) | O(|S|²+|C_grid|) | 有序分解、相位连续、后验支撑 |
| GPA | O(|T|·|C_grid|·|S|) | O(|Ω|+|C_grid|) | 内核统一 sound、覆盖审计 |
| TAP | O(|P_probe|·(|C_grid|+IG)) | O(|P_probe|) | 探针限入 `A_K`、预算闭合 |
| CTJ | O(|P|·|C_grid|) | O(|C_grid|) | 区域一致、包络后验支撑 |

**正确性定理（Terrain-Conditioned Generalist Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `P(c_t∈ψ(z_t))≥1-α_z` 且 `φ` 对 `α_S,ρ_S` 为 `ε`-充分；**(A30)** 包络单边保守 `Ĉ_S⊆C_S` 以概率 `≥1-α_env`；**(A31)** 后验支撑误接受 `≤ε_sup`、检测延迟 `≤τ_det`；**(A32)** 安全内核 `K` 在 `C` 上一致 sound，探针限入 `A_K`。若只在证书 in-force 且 `(τ,c)∈Ω` 时执行：
```
P(fail) ≤ α_z + α_env + ε_sup + β_E
          + P(τ_c < τ_det+τ_rec) + P(B_info 耗尽) + Σ_d(1-ρ_min(d))
```
且 **P(在 Ω 之外静默部署)=0**：系统允许“不会”，但不允许“假装会”。

**命题 1（地形组合路径依赖）**：`C_{(S_i⊗S_j)⊗S_k} ≠ C_{S_i⊗(S_j⊗S_k)}` 一般成立；组合证书必须按有序序列计算，不能先无序合并。
**命题 2（适应带宽上界）**：若 `τ_det+τ_rec ≥ τ_c`，非退化证书的 in-force 时间占比趋于 0，唯一可证策略是 kernel-only + 显式拒识；通用性存在由地形变化率决定的速度上限。
**命题 3（覆盖-拒识权衡）**：固定 `K` 时扩大 `Ω`（削弱腐蚀或放宽 `ε_sup`）必然单调提高误纳入风险；应报告风险-覆盖前沿而非单点成功率。
