# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「无刷电机」×「机械臂抓取」）

> 第 60 轮的 SGEC 把「场景→意图→约束→阻抗→执行→证据」闭成了认知闭环，但它留下一个**被层层抽象掩盖的物理空洞**：所有「执行」最终都发生在无刷电机的定子电流里，而前 60 轮从未真正打开过这个「执行的发生地」。
> 1. **执行层的黑箱化**：EEIS 编译出的阻抗 K_safe、ERTC 锁定的约束，最终都要折算成 q 轴电流 i_q；但 K_safe 从未被「电气可实现性」检验。一个热到 120°C 的电机，其可持续转矩远低于冷态标称值——**纸面安全的阻抗，可能在电机里根本发不出来**。这是典型的「抽象泄漏」：证据层越自信，执行层越可能被物理规律一票否决。
> 2. **力感知的舍近求远**：抓取力/滑移感知几乎默认依赖指尖触觉或腕部六维力传感器；但无刷电机的相电流、反电动势、齿槽转矩纹波本身就是**带宽最高（电流环 kHz 级）、零附加成本、已在闭环内**的力/接触观测通道，却被当作「纯执行器」丢弃。**电机不是只能出力，它同时在"感受"力。**
> 3. **热-力耦合的失稳**：抓住物体需要持续电流，持续电流加热绕组；绕组升温使铜阻 R 上升、永磁体磁链 λ_m 下降；同一 i_q 产生的力随温度下降。控制器若不知情就会继续加电流——**热、力、电流形成正反馈**，这正是「抓得越紧越抓不住、最后滑落」的物理根因，也是本轮的切入点。

## 0. 直觉与动机

**灵感 1（无刷电机 → 电机即传感器：EMGO + CCF）**
直觉：对表贴式永磁同步电机（SPMSM），电磁转矩近似正比于 q 轴电流，`τ_e ≈ K_t·i_q`。因此**电流环本身就是一条 kHz 带宽的转矩观测链路**，比大多数触觉/力传感器快一个数量级。更进一步：齿槽转矩（cogging torque）是电角度 θ_e 的**确定性周期函数**，可以在空载时标定成一条「齿槽指纹曲线」。当机械臂抓住物体后，接触刚度会叠加到关节等效刚度上，使「转矩—角度」曲线发生**增益变化、相位偏移与迟滞环面积增大**。于是：**自由空间指纹 vs 接触后指纹之差 ΔC(θ) 就是接触状态的高带宽签名**——斜率编码接触刚度，迟滞面积编码能量耗散/滑移，谐波边带编码黏滑振动。关键洞见：**不需要新增传感器，只要把电机本来就在测的电流/角度"再读一遍"**。

**灵感 2（机械臂抓取 → 电流域抓取力控制：CGFC）**
直觉：抓取不是独立的「力环」，而是**在热、电、机械约束下的电流分配问题**。抓取力有下界（防滑）与上界（防损），而电机能持续输出的力还有第三个上界——**热上限**。把三者的可行窗口显式写出来：`F_slip(1+ε) ≤ F_g ≤ min(F_damage/(1+ε), F_thermal(T_w))`。当窗口为空，说明该物体在当前电机热状态下「电气不可持续抓取」，必须机械助锁或间歇换手，而不是硬加电流。关键洞见：**抓取安全不是一个点，而是一个随温度漂移的区间；控制器要做的是让区间永远非空。**

**灵感 3（热-电-力耦合 → 电机-抓取安全包络 MGSE）**
直觉：第 60 轮的 K_safe 只问「接触是否稳定」，不问「电机是否发得出、扛得住」。把电气可行性作为一层**投影算子**：`K_feas = Π_MGSE(K_safe)`。若 K_safe 落在包络外，不是拒绝执行，而是**投影到最近的可行阻抗并记录降级原因**；若投影后仍不满足防滑下界，则触发「电气不可行」而非「控制失败」。这把「执行失败」从玄学变成了可解释的物理边界。

**灵感 4（三灵感合流 → 电磁抓取闭环 EMGC）**
直觉：EMGO 从电流里"读"出接触力/刚度/滑移；CCF 用齿槽指纹提供高带宽接触签名；TRSS 从电流谐波里识别黏滑；CGFC 把抓取力目标折算成热感知的 i_q；MGSE 保证 K_safe 电气可实现；EFLG 在失磁/过流/过温时保抓或受控释放；EGEC 把整条链沉淀成可审计证书。形成闭环：**场景/意图 → K_safe → 电气可实现投影 → i_q → 接触 → 电流反演 → 证据**。关键洞见：**执行层与证据层在同一个物理量（i_q）上汇合，证据不再是对执行的"事后描述"，而是执行的"直接读数"。**

**灵感 5（PCE-E → 电-认知预算）**
直觉：第 60 轮的四维认知预算 B_scene/B_intent/B_ros/B_exec 缺少**物理预算**。本轮补充：B_elec（电流/电压裕度）、B_therm（温升裕度、热时间常数）、B_emg（电流采样率、观测器带宽、标定新鲜度）、B_exec（原有）。若 B_therm 耗尽 ⇒ 降低持续抓取力或转机械自锁；若 B_emg 耗尽（标定过期/采样掉帧）⇒ 观测器降权，回退到触觉/开环保守抓取；若 B_elec 耗尽 ⇒ 禁止瞬时大电流，限制加速度。**预算耗尽不是报错，而是把系统推向更保守但物理可行的模态。**

## 1. 形式化定义（增量：定义 161–170）

**定义 161（电机-抓取耦合模型 MGC）** 以 SPMSM 驱动二指/多指抓取，状态 `x = (i_d, i_q, ω_m, θ_m, T_w)`：
- **电气方程**（d-q 轴，`θ_e = p·θ_m`）：
  `v_d = R(T_w)·i_d + L_d·di_d/dt − p·ω_m·L_q·i_q`
  `v_q = R(T_w)·i_q + L_q·di_q/dt + p·ω_m·(L_d·i_d + λ_m(T_w))`
- **电磁转矩**：`τ_e = (3/2)·p·[λ_m(T_w)·i_q + (L_d − L_q)·i_d·i_q]`；SPMSM 下 `L_d≈L_q`，故 `τ_e = K_t(T_w)·i_q`，`K_t = (3/2)·p·λ_m`。
- **机械方程**（电机侧）：`J_m·θ̈_m = τ_e − τ_cog(θ_e) − τ_fric(ω_m) − τ_g(θ_m) − τ_c`
- **抓取负载**：`τ_c = r_g·F_g + τ_slip`，其中 `r_g` 为等效传动力臂，`F_g` 为实际抓取力，`τ_slip` 为滑移动力学产生的附加力矩。
- **温度模型**：`C_th·dT_w/dt = P_cu + P_fe − (T_w − T_amb)/R_th`，`P_cu = (3/2)(i_d²+i_q²)·R(T_w)`。
- 参数漂移：`R(T_w)=R_0[1+α(T_w−T_0)]`（铜，α≈3.93e−3/°C），`λ_m(T_w)=λ_m0[1−β(T_w−T_0)]`（钕铁硼，β≈1.0~1.5e−3/°C）。

**定义 162（电磁抓取观测器 EMGO）** 观测器 `O_emg = (DOB, K̂_c, v̂_s, T̂_w)`：
- **扰动观测**：`τ̂_c = Q(s)·[ τ_e − J_m·θ̈_m − B_m·θ̇_m − τ_cog(θ_e) − τ_g(θ_m) ]`，`Q(s)` 为带宽 `ω_o` 的低通；`θ̈_m, θ̇_m` 由编码器差分/速度观测器给出。
- **接触刚度辨识**：在抓取位附近施加小幅 dither `θ_probe(t)=A·sin(2πf_d t)`，用最小二乘拟合 `k̂_c = g_r²·∂τ̂_c/∂θ_m`。
- **滑移速度**：由摩擦-迟滞模型 `v̂_s = argmin_v ‖τ̂_c − f_fric(v)‖²`，或由迟滞环面积 `A_hys` 的斜率估计。
- **热补偿**：`R̂(T_w), K̂_t(T_w)` 进入 `τ_e` 折算与 `Q(s)` 增益调度；标定新鲜度进入 B_emg。

**定义 163（齿槽指纹 CCF / CogPrint）** 自由空间双向扫描得到
- `τ_up(θ) = τ_cog(θ) + τ_g(θ) + τ_f(v>0)`，`τ_down(θ) = τ_cog(θ) + τ_g(θ) + τ_f(v<0)`
- `τ_free(θ) = (τ_up+τ_down)/2 = τ_cog(θ)+τ_g(θ)`（扣除重力后得 `C_free(θ)`），摩擦半差用于标定。
- 接触后同法得 `C_contact(θ,F_g)`。定义指纹偏差
  `ΔC(θ) = C_contact(θ) − C_free(θ)`，其特征三元组
  `Φ_CCF = ( k̂_c = ∂ΔC/∂θ ,  A_hys = ∮ΔC dθ ,  d_harm = ‖H(C_contact)−H(C_free)‖ )`
  分别为刚度、耗散/滑移、谐波指纹距离；`H(·)` 为齿槽谐波系数向量。判定：`A_hys > τ_A` 或 `d_harm > τ_H` ⇒ 发生微滑/几何失配。

**定义 164（转矩纹波滑移谱 TRSS）** 对电流窗 `i_q[t−W:t]` 做 STFT，得 `P_q(f,t)`。定义滑移指数
`s_slip(t) = 1 − exp( −λ·Σ_{f∈[f_lo,f_hi]} P_q(f,t) / N_0(f) )`，
其中 `N_0(f)` 为空载噪声基线，`[f_lo,f_hi]` 覆盖黏滑特征频带（典型 50–500 Hz），并检测 dither 频率 `f_d` 的边带 `f_d ± k·f_ss`。判定阈值为 `τ_slip`。
- **检测时延**：`t_detect ≤ W + H`（W 窗长，H 帧移）；`W=10ms` 时频率分辨率 100 Hz，时延 ≤ 20–30 ms。

**定义 165（电流域抓取力控制 CGFC）** 抓取力到 q 轴电流的映射
`i_q* = F_g* / (c_g·K_t(T_w))`，其中 `c_g` 为「每安培转矩→抓取力」的几何/传动增益。
热感知电流上限（稳态）：
`I_cont(T_w) = sqrt( 2·(T_max − T_amb) / (3·R_th·R(T_max)) )`，
`F_max_thermal(T_w) = c_g·K_t(T_w)·I_cont(T_w)`。
控制律为带前馈的 PI + 观测器反馈：`i_q* = sat( i_q_ff + K_pF(F_g*−F̂_g) + K_iF∫e , ±I_cont )`，其中 `F̂_g = τ̂_c/r_g`，饱和即触发 MGSE 投影记录。

**定义 166（电机-抓取安全包络 MGSE）** 可行集
`S_MGSE = { (F_g, i_q, T_w, ω_m, s_slip) : F_slip(1+ε_s) ≤ F_g ≤ F_damage/(1+ε_d), |i_q| ≤ I_inst(T_w), |v_q| ≤ V_bus/√3, T_w ≤ T_max, s_slip ≤ τ_slip }`
其中 `F_slip = m_obj·(g+|a|)/(2μ)` 为二指防滑下界，`F_damage` 为物体损伤上界，`I_inst` 为短时电流上限（区分 `I_cont`）。
**投影算子** `Π_MGSE(K)`：若 `K∈K_feas` 直接返回；否则沿可行域边界求最近点 `K' = argmin_{K'∈K_feas} ‖K−K'‖_W`，并返回 `(K', reason)`。若 `F_slip(1+ε_s) > min(F_damage/(1+ε_d), F_max_thermal)`，则 `K_feas=∅`，返回 `DEGRADE_UNHOLDABLE`（电气不可持续抓取），而不是静默失败。

**定义 167（电气失效保抓 EFLG）** 状态机 `S_eflg ∈ {NORMAL, DEGRADED, LOCKDOWN, RELEASE}`，故障集
`Φ = {commutation_loss, overcurrent, overtemperature, encoder_dropout, bus_undervoltage}`。
- NORMAL→DEGRADED：任一故障软触发，降低 `F_g*`、提高 `K_d`、开启电流/温度裕度监控。
- DEGRADED→LOCKDOWN：故障持续 `>τ_hold` 或 `T_w>T_derate`；若机构自锁（蜗轮/抱闸/欠驱动自锁），切零电流保抓。
- DEGRADED/LOCKDOWN→RELEASE：确需释放时，以受控速度 `|v|≤v_release` 缓慢放下，并生成释放证据。
- 不可自锁机构在 LOCKDOWN 下退化为 `RELEASE`，但必须**显式证书标注"不可保抓"**，不得伪装成功。

**定义 168（电-认知预算 PCE-E）** `B_phys = (B_elec, B_therm, B_emg, B_exec)`：
- `B_elec = (I_margin, V_margin, Bus_ripple)`；`B_therm = (T_headroom, τ_thermal, R_th_conf)`；
- `B_emg = (f_sample, ω_o, Calib_age, CogMap_version)`；`B_exec` 沿用第 60 轮。
- **VOI-E**：`voi_phys(π) = VOI_cog(π) − cost_phys(π)`，
  `cost_phys = λ_T·max(0,T_w−T_soft) + λ_I·max(0,|i_q|−I_soft) + λ_C·Calib_age + λ_F·max(0, F_slip−F̂_g)`。
- 降级策略：B_therm 耗尽 ⇒ 降 `F_g*` 或转自锁；B_elec 耗尽 ⇒ 限制加速度/瞬时电流；B_emg 耗尽 ⇒ 观测器降权、回退触觉/保守开环；B_exec 耗尽 ⇒ 第 60 轮原有降级。

**定义 169（电磁抓取证据证书 EGEC）** `Cert_emg = (t, seq_id, hash, i_dq_summary, T_w, K_t_model_ver, τ̂_c, k̂_c, A_hys, s_slip, F_g_est, MGSE_margin, EFLG_state, J_emg)`。
验证谓词
`J_emg = 1 ⇔ [∀t: |i_q(t)| ≤ I_inst(T_w(t))] ∧ [T_w(t) ≤ T_max] ∧ [s_slip(t) ≤ τ_slip] ∧ [F_slip(1+ε_s) ≤ F_g ≤ F_damage/(1+ε_d)] ∧ [无未检出的 commutation_loss]`。
`Cert_emg` 作为第 60 轮 XMC++ 的一个新模态接入，与 `EV-exec` 对账。

**定义 170（电磁抓取闭环 EMGC）** 算子 `EMGC(M, K_safe, F_g*, intent, scene)`：
```
① 热/电状态: (T_w, R̂, K̂_t, Bus, Calib_age) ← read_drive_state()
② 包络投影: (K_feas, reason) ← Π_MGSE(K_safe, T_w, F_g*, object_class)
③ 若 K_feas = ∅: return (DEGRADE_UNHOLDABLE, Cert_emg(reason))
④ 电流前馈: i_q_ff ← F_g* / (c_g·K̂_t(T_w))
⑤ 电磁观测: τ̂_c, k̂_c, v̂_s ← EMGO(i_dq, θ_m, ω_m, T_w)
⑥ 指纹/谱: Φ_CCF ← CCF.update(τ̂_c, θ_m); s_slip ← TRSS(i_q)
⑦ 力闭环: i_q* ← CGFC(F_g*, F̂_g, I_cont(T_w))
⑧ 安全校验: if s_slip > τ_slip or |i_q| > I_inst: EFLG.trigger(); F_g* ← retract(F_g*)
⑨ 执行: apply_current(i_dq*); telemetry ← wait_contact()
⑩ 证据: Cert_emg ← build_emg_cert(...); EPIR.append(Cert_emg)
⑪ 回写: XMC++.fuse(M, Cert_emg); B_phys.consume(...)
⑫ return (K_feas, F̂_g, Φ_CCF, s_slip, Cert_emg, EFLG_state)
```

## 2. 关键算法伪代码

### IP-162 EMGO（电磁抓取观测器）
```python
class ElectroMagneticGraspObserver:
    def __init__(self, J_m, B_m, cog_map, thermal_model, omega_o=2*pi*300):
        self.J, self.B = J_m, B_m
        self.cog = cog_map            # 标定的齿槽+重力查表
        self.thermal = thermal_model
        self.Q = LowPass(omega_o)
        self.calib_age = 0.0

    def observe(self, i_dq, theta_m, omega_m, acc_m, T_w):
        R = self.thermal.R(T_w); Kt = self.thermal.Kt(T_w)
        tau_e = Kt * i_dq.q
        tau_cog = self.cog.cogging(theta_m * self.poles)
        tau_g = self.cog.gravity(theta_m)
        residual = tau_e - self.J*acc_m - self.B*omega_m - tau_cog - tau_g
        tau_c_hat = self.Q.filter(residual)
        return tau_c_hat

    def estimate_stiffness(self, tau_c_hist, theta_hist, g_r):
        # 局部窗口最小二乘: tau_c ≈ k_c/g_r^2 * theta + b
        A = np.vstack([theta_hist, np.ones_like(theta_hist)]).T
        k_motor, _ = np.linalg.lstsq(A, tau_c_hist, rcond=None)[0]
        return g_r**2 * k_motor
```

### IP-163 CCF（齿槽指纹）
```python
class CoggingFingerprint:
    def __init__(self, n_harm=8):
        self.C_free = None
        self.n_harm = n_harm

    def calibrate_free(self, theta, tau_up, tau_down, tau_gravity):
        tau_free = 0.5*(tau_up + tau_down) - tau_gravity
        self.C_free = Interpolator(theta, tau_free)

    def deviation(self, theta, tau_contact, tau_gravity):
        Cc = np.asarray(tau_contact) - np.asarray(tau_gravity)
        dC = Cc - self.C_free(theta)
        k_c = np.polyfit(theta, dC, 1)[0]
        A_hys = trapz(np.abs(np.diff(dC)), theta[:-1])  # 迟滞能量代理
        Hc = self._harmonics(Cc); Hf = self._harmonics(self.C_free(theta))
        return {'k_c': k_c, 'A_hys': A_hys, 'd_harm': np.linalg.norm(Hc-Hf)}
```

### IP-164 TRSS（转矩纹波滑移谱）
```python
class TorqueRippleSlipSpectroscopy:
    def __init__(self, fs=20000, win=0.010, hop=0.005, band=(50, 500)):
        self.fs, self.win, self.hop, self.band = fs, win, hop, band
        self.noise = None

    def fit_noise(self, iq_free):
        self.noise = welch(iq_free, fs=self.fs, nperseg=int(self.win*self.fs))[1]

    def slip_index(self, iq_window):
        f, P = welch(iq_window, fs=self.fs, nperseg=int(self.win*self.fs))
        m = (f >= self.band[0]) & (f <= self.band[1])
        ratio = np.sum(P[m]) / (np.sum(self.noise[m]) + 1e-12)
        return 1.0 - np.exp(-ratio)
```

### IP-166 MGSE（安全包络投影）
```python
def project_mgse(K, T_w, F_g_star, obj, drive, eps=0.1):
    F_slip = obj.mass*(9.81 + abs(obj.acc))/(2*obj.mu)
    F_dam  = obj.F_damage
    F_therm = drive.c_g*drive.Kt(T_w)*drive.I_cont(T_w)
    lo, hi = F_slip*(1+eps), min(F_dam/(1+eps), F_therm)
    if lo > hi:
        return None, 'DEGRADE_UNHOLDABLE'
    # K 映射到 F_g 后裁剪，再映回 K
    F_g = max(lo, min(hi, K_to_force(K, obj)))
    K_feas = force_to_K(F_g, obj)
    reason = 'ok' if np.allclose(K, K_feas) else 'projected'
```

**正确性定理（EMGC）**：设 A66–A72 成立：
- **(A66)** 电机参数与热模型在不确定度 `δ_T` 内有效；
- **(A67)** 齿槽/重力曲线可标定，重复误差 `≤ δ_cog`；
- **(A68)** 电流环带宽 `≥ 2 kHz`，观测器带宽 `ω_o` 满足采样定理；
- **(A69)** 编码器分辨率足以使 `θ̈` 差分误差 `≤ δ_ω̇`；
- **(A70)** dither 幅值足够小，接触可线性化；
- **(A71)** 发生黏滑时特征频带信噪比高于检测阈；
- **(A72)** 热时间常数远大于控制周期，`T_w` 可观。

则：
1. **观测误差有界**：`|τ_c − τ̂_c| ≤ ‖Q‖∞·(Jδ_ω̇ + Bδ_ω + δ_cog + δ_model) + (1−‖Q‖∞)·‖τ_c‖`。
2. **电气可实现性**：`K_feas = Π_MGSE(K_safe)` 满足 `F_slip(1+ε_s) ≤ F_g ≤ min(F_damage/(1+ε_d), F_max_thermal)`；若空集，返回 `DEGRADE_UNHOLDABLE`，绝不宣称可行。
3. **热安全**：只要 `i_q ≤ I_cont(T_w)` 且 `T_w ≤ T_max`，稳态温升不超过 `T_max`；控制器饱和前先降 `F_g*`，故不出现热失控。
4. **滑移可检**：若黏滑能量使 `s_slip > τ_slip`，则 `t_detect ≤ W+H` 内报警；漏检概率受 A71 信噪比约束。
5. **证据可信**：`J_emg=1` 的证书蕴含上述四条同时成立；EFLG 不可保抓时 `J_emg=0` 并显式标注，避免"伪造合规"。

```python
class ThermalModel:
    def __init__(self, R0, Kt0, alpha=3.93e-3, beta=1.3e-3, T0=25.0):
        self.R0, self.Kt0 = R0, Kt0
        self.alpha, self.beta, self.T0 = alpha, beta, T0
        self.R_th, self.C_th = None, None   # 由阶跃温升实验辨识

    def R(self, T):  return self.R0*(1 + self.alpha*(T-self.T0))
    def Kt(self, T): return self.Kt0*(1 - self.beta*(T-self.T0))
    def I_cont(self, T_max, T_amb):
        return np.sqrt(2*(T_max-T_amb)/(3*self.R_th*self.R(T_max)))


class ElectroMagneticGraspObserver:
    def __init__(self, poles, J_m, B_m, cog_map, thermal, omega_o=2*np.pi*300):
        self.p, self.J, self.B = poles, J_m, B_m
        self.cog, self.thermal = cog_map, thermal
        self.Q = FirstOrderLowPass(omega_o)
        self.model_age = 0.0

    def torque_estimate(self, iq, theta_m, omega_m, acc_m, T_w):
        Kt = self.thermal.Kt(T_w)
        tau_e = Kt * iq
        residual = (tau_e
                    - self.J*acc_m
                    - self.B*omega_m
                    - self.cog.cogging(self.p*theta_m)
                    - self.cog.gravity(theta_m))
        return self.Q.filter(residual)   # τ̂_c

    def contact_stiffness(self, tau_hist, theta_hist, g_r):
        A = np.vstack([theta_hist, np.ones_like(theta_hist)]).T
        k_motor = np.linalg.lstsq(A, tau_hist, rcond=None)[0][0]
        return g_r**2 * k_motor
```

### IP-163 CCF（齿槽指纹）
```python
class CoggingFingerprint:
    def __init__(self, n_harm=8, tau_A=0.02, tau_H=0.15):
        self.C_free = None
        self.n_harm, self.tau_A, self.tau_H = n_harm, tau_A, tau_H

    def _harm(self, y, theta):
        # 对 2π 周期做前 n_harm 阶傅里叶系数
        return np.array([np.trapz(y*np.exp(-1j*k*theta), theta)
                         for k in range(1, self.n_harm+1)])

    def calibrate(self, theta, tau_up, tau_down, tau_g):
        tau_free = 0.5*(np.asarray(tau_up)+np.asarray(tau_down)) - np.asarray(tau_g)
        self.C_free = LinearInterpolator(theta, tau_free)
        self.H_free = self._harm(tau_free, theta)

    def deviation(self, theta, tau_contact, tau_g):
        Cc = np.asarray(tau_contact) - np.asarray(tau_g)
        dC = Cc - self.C_free(theta)
        k_c = np.polyfit(theta, dC, 1)[0]
        A_hys = np.trapz(np.abs(np.diff(dC)), theta[:-1])
        d_harm = np.linalg.norm(self._harm(Cc, theta) - self.H_free)
        slip_flag = (A_hys > self.tau_A) or (d_harm > self.tau_H)
        return {'k_c': k_c, 'A_hys': A_hys,
                'd_harm': d_harm, 'slip_flag': slip_flag}
```

```python
class TorqueRippleSlipSpectroscopy:
    def __init__(self, fs=20000, win=0.010, hop=0.005,
                 band=(50, 500), tau_slip=0.6):
        self.fs, self.win, self.hop = fs, win, hop
        self.band, self.tau_slip = band, tau_slip
        self.noise_psd = None

    def fit_noise(self, iq_free):
        _, self.noise_psd = welch(iq_free, fs=self.fs,
                                  nperseg=int(self.win*self.fs))

    def slip_index(self, iq_win):
        f, P = welch(iq_win, fs=self.fs, nperseg=int(self.win*self.fs))
        m = (f >= self.band[0]) & (f <= self.band[1])
        ratio = np.sum(P[m]) / (np.sum(self.noise_psd[m]) + 1e-12)
        return 1.0 - np.exp(-ratio)

    def latency_bound(self):
        return self.win + self.hop      # ≤ 15 ms（win=10ms, hop=5ms）
```

```python
class CurrentDomainGraspController:
    def __init__(self, drive, thermal, kp=0.35, ki=2.0):
        self.drive, self.thermal = drive, thermal
        self.kp, self.ki = kp, ki
        self.integ = 0.0

    def step(self, F_star, F_hat, T_w, dt):
        Kt = self.thermal.Kt(T_w)
        iq_ff = F_star/(self.drive.c_g*Kt)
        e = F_star - F_hat
        self.integ += e*dt
        iq = iq_ff + self.kp*e + self.ki*self.integ
        return float(np.clip(iq, -self.drive.I_cont(T_w),
                             self.drive.I_cont(T_w)))


def project_mgse(K, T_w, obj, drive, thermal, eps=0.1):
    F_slip = obj.mass*(9.81+abs(obj.acc))/(2*obj.mu)
    F_dam  = obj.F_damage
    F_therm = drive.c_g*thermal.Kt(T_w)*thermal.I_cont(drive.T_max)
    lo, hi = F_slip*(1+eps), min(F_dam/(1+eps), F_therm)
    if lo > hi:
        return None, {'reason': 'DEGRADE_UNHOLDABLE',
                      'lo': lo, 'hi': hi, 'F_therm': F_therm}
    F_g = float(np.clip(force_of(K, obj), lo, hi))
    K_feas = impedance_of(F_g, obj)
    return K_feas, {'reason': 'ok' if np.allclose(K, K_feas) else 'projected',
                    'lo': lo, 'hi': hi, 'F_therm': F_therm}
```

## 3. 推导与命题

### 命题 1（热-力天花板）
设 `x=T_w−T_amb`，`K_t=K_t0(1−βx)`，`R=R_0(1+αx)`。稳态仅计铜损：
```
x = R_th·(3/2)·i_q²·R_0(1+αx)
⇒ i_q² = 2x / [3·R_th·R_0·(1+αx)]
⇒ F_g(x) = c_g·K_t0·(1−βx)·sqrt( 2x / [3·R_th·R_0·(1+αx)] )
```
令 `h(x)=x(1−βx)²/(1+αx)`，由 `d(ln h)/dx = 1/x − 2β/(1−βx) − α/(1+αx)=0` 得驻点
```
x* ≈ 1/(2β+α)     （小 x 展开）
```
取钕铁硼 `β≈1.3e−3`、铜 `α≈3.93e−3`，得 `x*≈153°C`。工程上 `T_max−T_amb≈75~105°C < x*`，故 `F_g(x)` 在允许温区内单调升，**热约束由绝缘等级 `T_max` 先绑定**：
```
F_max_thermal(T_w) = c_g·K_t(T_w)·I_cont,
I_cont = sqrt( 2(T_max−T_amb) / [3·R_th·R(T_max)] )
```
**推论（电气不可持续抓取）**：若 `F_slip(1+ε_s) > min(F_damage/(1+ε_d), F_max_thermal)`，则不存在任何控制律能长期同时满足防滑与热安全，必须机械自锁或间歇换手——这解释了「越热越加电流、越加电流越抓不住」的正反馈，并给出可判定的边界。

### 命题 2（观测器误差界）
若真实残差 `r = τ_c + e_m + n`（模型误差 `e_m`、量测噪声 `n`），且 `τ̂_c=Q(s)r`，则
```
|τ_c − τ̂_c| ≤ (1−‖Q‖∞)·‖τ_c‖∞ + ‖Q‖∞·(‖e_m‖∞ + ‖n‖∞)
```
`ω_o` 越高则 `‖Q‖∞→1`、跟踪越快，但对 `e_m,n` 越敏感；热补偿的目标正是压低 `e_m`，从而允许更高的 `ω_o`。这给出「带宽 vs 模型可信度」的显式折中。

### 命题 3（MGSE 投影安全性）
Π_MGSE 把 K 投影到一维力区间 `[lo,hi]`；若 `lo≤hi`，输出 `K_feas` 必满足五约束，且当 `K` 已在区间内时 `K_feas=K`（幂等）；若 `lo>hi`，返回空集标记而非任意可行解。故 **`J_emg=1` 的证书不会把不可行阻抗标为可行**（在 A66–A72 成立时）。

### 命题 4（滑移检测时延）
STFT 窗长 W、帧移 H，特征出现于 t 的最坏检出时延为 `W+H`；频率分辨率 `1/W`。取 `W=10ms, H=5ms`，时延 ≤15ms，分辨率 100Hz，足以覆盖 50–500Hz 黏滑带。若需更低时延，可并行短窗（W=5ms）+ 长窗确认，形成「快报慢确认」。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| EMGO | O(1)/周期；拟合 O(n) | O(n_win) | 转矩 RMSE ≤5% FS；带宽 ≥300 Hz |
| CCF | 标定 O(N_θ)；在线 O(n_harm) | O(N_θ) | k_c 误差 ≤15%；滑移 AUC ≥0.90 |
| TRSS | O(W log W)/窗 | O(W) | F1 ≥0.95；误报 ≤2%；时延 ≤30 ms |
| MGSE | O(1) | O(1) | 投影后 100% 满足五约束 |
| EFLG | O(1) | O(1) | 故障检出 ≤10 ms；证据完整 ≥99.9% |
| EMGC | O(闭环) | 复用 | 端到端掉落率 −60% |

**正确性定理（EMGC）**：若 A66–A72 成立，则：
1. 观测误差满足命题 2 的界；
2. `K_feas=Π_MGSE(K_safe)` 满足力/热/电/滑移五约束，空集显式返回 `DEGRADE_UNHOLDABLE`；
3. 只要 `i_q≤I_cont` 且 `T_w≤T_max`，稳态温升不超过 `T_max`，不出现热失控；
4. 黏滑能量超阈时 `t_detect≤W+H` 内报警；
5. `J_emg=1 ⇒` 上述四条同时成立；EFLG 不可保抓时 `J_emg=0` 且证书显式标注，避免「伪造合规」。

## 7. 本轮最大风险

**一句话**：EMGO/CCF/TRSS 全部建立在「电机参数（R(T)、K_t(T)、齿槽图）长期可信」这一模型假设上；一旦电机磨损、磁钢老化或温度模型失配，观测器会**用错误的模型自信地报出"抓取安全"**，形成比第 60 轮更隐蔽的「模型可信度泄漏」——因此必须用在线参数辨识、标定新鲜度预算 B_emg、与指尖触觉的交叉校验三重护栏，确保"电机说的安全"永远不等于"事实上的安全"。
