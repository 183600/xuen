# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「抓取」×「流匹配策略」）

> 第 57 轮把承诺的判定权下沉到"元推断 + 跨模态对账 + 信任状态机"，但它的最大风险自陈暴露了一个更底层的事实：**前 57 轮的一切承诺本质都是"路能不能走"的承诺，而机器人真正不可逆的失败往往发生在"接触抓不抓得住"**——足底打滑与手中掉物是同一类事件（接触力旋量契约被违反）；同时，策略仍被当作"点估计 + 安全壳"，生成式策略天然的多模态动作能力被浪费，而任何生成器的错误又无法靠"信任先验"兜住。本轮两个灵感各补一层：**抓取**把承诺的原子单位从"区域可通行"下沉到"接触可持稳"——足底抓地与手指抓物统一为力旋量契约，滑移成为比"走错路"更原生的证伪事件；**流匹配策略**把动作生成从"一个点"升级为"一族可审计的传输轨迹"——多模态提案、给定种子可复现、可用反向流做事后归因，但**生成器只提案、不裁决**，安全由"安全质量证书 + 单调引导 + 证据门"保证。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"接触可持稳、生成可担保、提案不裁决的接触-传输承诺"**。

核心矛盾：
- **H29（接触不确定性 vs 可逆性）**：摩擦系数、质心、形变都只能在"真正接触"时才被测准，但第一次接触常常就是不可逆的（掉物、跌落）——"先测后信"在接触域存在结构性悖论：想安全就得先摸，想先摸就已经承担了摸错的风险。
- **H30（生成多模态 vs 自指证书）**：流匹配策略能给出多种抓法/落足，但"安全质量"只能在策略自己采样的轨迹上估计——策略看不见的危险模式，证书也看不见；证书因此是自指的，`M_safe` 高只说明"提案里安全的多"，不说明"世界里的危险少"。
- **H31（引导 vs 多样性）**：约束引导把传输拉向安全集，能提高安全质量，却可能压掉少数但关键的模态（例如唯一能抓住薄壁/斜坡的抓法），使"更安全"的引导反而制造盲区——安全的操作可能亲手删掉唯一的生路。

## 0. 直觉与动机

**灵感 1（抓取 → 接触承诺：把"可走"下沉到"可持"）**
直觉：走路时脚掌抓住地面，抓物时手指抓住物体，本质是同一个动作——**用一个接触集去兑现一张力旋量支票**。区域地图回答"这块地值不值得踩"，接触承诺回答"踩上去这个力旋量能不能撑住 τ_req 而不滑"。于是接触假设 h=(接触面/物体, 接触集 C, 法向 n, 摩擦 μ, 需求力旋量 w_req, 持续 τ_req) 成为一等公民；滑移裕度 m_s 是"需求力旋量离力闭合边界还有多远"。最关键的是事件语义：**滑移是比"走错路"更原生的证伪事件**——它直接、局部、可测；一次滑移就回溯性地说明 μ̂ 或质心估计错了，于是按第 57 轮的 XMC 规则降权该"触觉/本体"模态、按 SMM 规则改区域与物体信念。不可逆接触（掉物、跌落、压坏）自动落入 L2，且**不能用任何生成式证据豁免**。

**灵感 2（流匹配策略 → 生成即提案，安全靠质量而非点）**
直觉：流匹配策略学的不是一个"最优动作"，而是一个把噪声传输成动作轨迹分布的速度场 v_θ(x,t|c)。这带来三个前 57 轮没有的东西：**(a) 多模态**——同一情境下它天然能吐出"正面抓/侧抓/托底"几种模式，而不是把多峰平均成一个必错的中间动作；**(b) 可复现**——给定潜变量 z 与初值，ODE 积分是确定性的，审计可以逐条重放；**(c) 可反演**——把一条失败轨迹沿速度场反向积分回潜空间，能问"是哪个条件/模式把它送进失败的"，这是比"事后打标签"更细的归因。但生成器天生会幻觉：它能生成"看起来像抓取"的轨迹，却不保证抓得住。因此本轮的纪律是 **提案器不裁决**——FMP 只能输出带 `proposal` 标签的动作候选，永远不能直接生成承诺；安全由下游"安全质量证书"独立测量。

**灵感 3（合流 → 安全质量证书 + 单调引导 + 接触-流证据门）**
直觉：既然不能信单条生成轨迹，就信**"这族提案里有多大质量落在已认证安全集里"**：在认证安全集 S_c（同时满足屏障约束与接触裕度）上估计 M_safe(c)=Pr_{z~p0}[Φ_θ(z|c)∈S_c]，并用 Beta/共形下界给一个保守的 LCB。这个量是"对生成器安全性的度量"，而非"对生成器的信任"。再用约束引导（CBF-QP 式投影）把速度场往安全集拉，但**只有当 LCB 单调不降且模式覆盖不降时才接受引导**（防止 H31）。最后用升级的证据门把两类新证据接进承诺：**EV-contact** 是接触承诺的必要证据，**EV-flow** 只作辅助、只在 L1 顶替一次探针，绝不进入不可逆接触的必要证据集。击穿安全需要：元先验错 ∧ OOD 漏检 ∧ 安全质量高估 ∧ 模式盲区 ∧ 接触证据缺失 ∧ 人也错——纵深从五层到六层，且新加的两层（流、接触）互相不背书。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（接触承诺模型 CCM）** 接触假设 h=(O, C, {n_i}, μ, w_req, τ_req)，接触集 C 上摩擦锥 FC_i={f:f_n≥0,‖f_t‖≤μ f_n}，可达力旋量集 W(C)={Σ_i G_i f_i : f_i∈FC_i}。滑移裕度 ρ_s(h)=sup{ρ≥0 : ρ w_req∈W(C)}，m_s(h)=ρ_s(h)−1。**接触证据类 EV-contact** = (实测法向/切向力、黏着比、微滑移事件、事后滑移标签)。滑移事件 σ_s∈{micro,macro} 为证伪事件：macro 滑移 ⇒ 对 μ̂ 与质心估计取回溯乘性降权，并按 XMC 对 tactile/proprio 模态 ρ 降级、按 SMM 改区域/物体信念。接触承诺 comm_c(h)=1 ⇔ m_s(h)≥θ_s ∧ EV-contact 存在 ∧（若 level=irreversible 则另有 L2 同意 ∧ 独立佐证≥corrob\*(auth)）。接触状态机 approach→preload→hold→release，每相位各自带裕度与证据要求。

**定义 140（流匹配策略提案器 FMP）** 速度场 v_θ(x,t|c):ℝ^d×[0,1]→ℝ^d，条件 c=(任务, 接触假设 h, 地图 𝓜, 元推断 Inf)，基分布 p0，流 Φ_θ^{t}(z|c) 解 dx/dt=v_θ(x,t|c), x(0)=z。策略分布 p_θ(a|c)=(Φ_θ^{1})_# p0。终端轨迹聚类得模式 {π_k,ρ_k}_{k≤K_modes}，ρ_k 为模式质量，覆盖度 cov=Σ_k ρ_k·1[π_k 非退化]。**提案契约**：FMP 的一切输出携带 `proposal` 标签与潜变量 z，不构成任何证据类，不可直接触发承诺；给定 z 的轨迹可由审计重放。条件 c 可含已知危险模式提示（危险模式注入只增加候选，不删除候选）。

**定义 141（流安全质量证书 FSC）** 认证安全集 S_c={动作轨迹 a : B(x_t)≥0, ∀t∈[0,τ]；接触相位 m_s≥θ_s；峰值力≤F_abs}（B 为屏障函数）。安全质量 M_safe(c)=Pr_{z~p0}[Φ_θ(z|c)∈S_c]，估计 M̂_safe=1/n·Σ 1[·]。**下置信界** M_safe^LCB=Beta^{-1}(α_conf; n_safe+1, n−n_safe)（Clopper–Pearson，或用分层共形带校准）；模型误差膨胀 ε_θ。**流风险界**：P(fail | 仅凭流的决策) ≤ 1−M_safe^LCB+ε_θ+P_blind(c)，其中 **盲区项** P_blind(c)=Pr[危险模式 ∈ support(p_θ) 之外] 明确**不可由证书估计**，只能由独立对抗采样与模式覆盖审计给上界。**反向流归因** z\*=Φ_θ^{-1,1}(a_fail|c)，把失败轨迹反演回潜空间并归因到条件/模式，写入审计。

**定义 142（约束引导传输 CGT）** 屏障 b(x)≥0，引导速度 v_g=v_θ−λΠ_{T S_c}∇b（切空间投影的 CBF 式引导），每积分步做安全投影 x←Π_{S_c}(x)（可行时保证 x_t∈S_c）。**单调接受契约**：仅当 M_safe^LCB(v_g)≥M_safe^LCB(v_θ) ∧ cov(v_g)≥cov(v_θ)−ε_cov 时接受引导；否则回退 v_θ。引导只允许"减少已认证的不安全质量"，不允许以多样性为代价换取账面安全。

**定义 143（接触-流证据门 CTG，升级 FSE）** 证据类 = EV-probe\*/EV-visit/EV-margin/EV-xmodal/EV-human/**EV-contact**/**EV-flow**。不可逆接触必要证据集 = {EV-contact} ∪ ({EV-probe\*∨EV-margin}) ∪ 佐证，**显式不含 EV-flow 与 EV-xmodal**；EV-flow 与 EV-xmodal 仅可在 L1 各顶替一次佐证，且两者不可叠加顶替同一承诺。流提案若未附 FSC 与模式覆盖审计则一律拒。证书 J_c=(𝓜_core,C_core,K_margin,ρ_sem,δ_s,probe_log,consent_log,evidence,meta_cal_log,xmodal_log,auth_log,ood_registry,**contact_log,slip_log,flow_audit,safe_mass_lcb,mode_coverage,blind_mode_audit**)，继承 J_p 全检。

**定义 144（接触-传输探-诺-演算子 PCE++）** 每检查点：①元推断（ID→摊销后验/OOD→共形带）；②流提案 K_modes 个模式，各自过 FSC；③接触预检（可及性、m_s 上界）；④在候选模式上按 VOI_元悲观 选探针，执行接触探针（预触/力斜坡/微滑移）预算 k_contact；⑤接触承诺 comm_c ∧ CTG 过门 ⇒ 提交；否则重抓/绕行/降档/L2 协商（τ_int(auth)）或安全停；⑥任一 macro 滑移 ⇒ 触发回溯降权并重新开放模式搜索。

## 2. 关键算法伪代码（完整版见产物区）

```python
def contact_commit(x, h, M, level):
    m_s = slip_margin(h, M)                       # ρ_s - 1
    if level == 'irreversible' and not has_ev_contact(h):
        return ('reject', 'contact_evidence_required')   # 硬规则
    if m_s < theta_s: return ('probe', 'contact_margin', m_s)
    return ('commit', m_s)

def flow_safe_cert(v, c, S_c, n, alpha):
    zs = sample_base(n); trajs = [Phi(v, z, c) for z in zs]
    safe = [in_safe(a, S_c) for a in trajs]
    lcb = beta_lcb(sum(safe), n, alpha)           # 单侧下界
    modes = cluster_modes(trajs)                  # 多模态提案
    return lcb, modes, audit_flow(trajs, zs)

def monotone_guide(v, c, S_c, lcb0, cov0):
    vg = project(getattr(v), S_c)                 # CBF 式引导+投影
    lcb1, _, _ = flow_safe_cert(vg, c, S_c, n, alpha)
    if lcb1 < lcb0 or coverage(vg) < cov0 - eps_cov:
        return v, 'guide_rejected'                # H31 护栏
    return vg, 'ok'

def reverse_flow(v, a_fail, c):
    z_star = integrate_backward(v, a_fail, c)     # 反演到潜空间
    return attribute(z_star, c), z_star
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CCM | O(\|C\|·d_f)/接触 | O(\|对象/区域\|) | 滑移裕度保守、macro 滑移不漏检 |
| FMP | O(K_ode·d_θ)/轨迹 | O(d_θ+K_modes) | 提案契约、种子可复现 |
| FSC | O(n·K_ode)/证书 | O(n) 采样 | 采样独立、LCB 覆盖、盲区单列 |
| CGT | O(K_ode·d)/步 | O(d) | 单调接受、投影可行 |
| CTG | O(\|σ\|) | O(\|σ\|) | 无接触证据不承诺、流限 L1 |
| PCE++ | O(\|CP\|·(K_modes·n·K_ode+k_contact·d)) | O(\|V\|+K_modes·n) | K_modes+k_contact 终止 |

**正确性定理（接触-传输担保健全性 CTWS 概要）**：在 A33–A40 上加 (A41) 接触模型诚实：m_s 为真实力闭合裕度的下界，macro 滑移检测漏检 ≤δ_slip；(A42) 流证书有效：FSC 采样 i.i.d. 于真实提案分布、LCB 覆盖 ≥1−α_conf，且盲区项 |P_blind|≤δ_blind 由独立对抗采样审计给出；(A43) 引导单调：仅当 LCB 不降且覆盖不降才接受，投影可行；(A44) 提案契约：FMP 输出不含证据类，不可逆接触禁 EV-flow/EV-xmodal。则：
(i) **接触健全性**：P(slip | 提交接触) ≤ δ_slip(θ_s)+ε_contact；
(ii) **流健全性**：L1 上使用 EV-flow 的 P(fail) ≤ (1−M_safe^LCB)+ε_θ+δ_blind；不可逆接触的界**不含流项、也不享受流收益**（EV-flow 被硬禁），故不受生成器误差影响；
(iii) **引导单调性**：接受 CGT 不增加已认证风险，也不减少覆盖超过 ε_cov；
(iv) **终止性**：每检查点模式数 ≤K_modes、接触探针 ≤k_contact，PCE++ 在 K_modes+k_contact 内终止于 {承诺, 重抓, 绕行, L2 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把"生成器有多安全"交给一个只在生成器自己采样上估计的安全质量证书，风险从"坏先验普遍"变成"**坏模式不可见**"——策略越是只吐出它熟悉的那几种抓法，`M_safe` 就越是漂亮，而真正能救命的少数模态（薄壁、湿滑、非刚体）恰恰可能落在分布之外；因此流证书只能做辅助、不可逆接触必须由独立接触证据裁决，并用对抗采样与覆盖度硬门持续追问"你没生成的模式里有没有危险"。

# 第 58 轮产物 · 创新点清单 v34：Contact-Transport（抓取式接触承诺×流匹配提案×安全质量证书，CCM×FMP×FSC×CGT×CTG×PCE++）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把承诺的原子单位从"区域可通行"下沉到"**接触可持稳**"，把动作生成从"点估计"升级为"**可审计的流传输提案**"：足底抓地与手指抓物统一为力旋量契约，滑移成为原生证伪事件；流匹配策略只提案、不裁决，安全由独立的安全质量证书、单调约束引导与升级证据门保证。第 57 轮"一切判定器（含元模型）走隔离"在本轮推广为"**一切生成器（含流策略）走提案隔离**"——生成器只进候选池，永不直接进证据类。

### IP-139 CCM（接触承诺与滑移证伪）

```python
def contact_margin(h, M):
    W = wrench_set(h.contact_set, mu=h.mu)        # 摩擦锥合成的力旋量集
    rho_s = sup_scale(lambda r: (r * h.w_req) in W)   # 需求旋量的可缩放上界
    return rho_s - 1.0                            # m_s: >0 即留有余量

def contact_update(M, e):
    if e.type == 'contact':
        M.contact[e.object] = bayes_update(M.contact[e.object], e.force_like)
    if e.type == 'slip':                          # 证伪事件：回溯降权
        scale = 0.5 if e.severity == 'macro' else 0.85
        M.mu[e.surface]  = max(MU_MIN, M.mu[e.surface] * scale)
        M.com[e.object]  = shrink_uncertainty(M.com[e.object], e.com_obs)
        M.rho['tactile'] = max(RHO_MIN, M.rho['tactile'] * scale)   # 接 XMC R3
        M.audit.flag(('slip', e.object, e.t))
        if e.severity == 'macro' and e.level == 'irreversible':
            M.consent.revoke(e.object)            # 不可逆滑移即冻结授权
    return M

def contact_commit(x, h, M, level, persona):
    m_s = contact_margin(h, M)
    if level == 'irreversible':
        if not has_ev_contact(h):                 # 硬规则：流/一致都不替代
            return ('reject', 'contact_evidence_required')
        if h.corrob < corrob_star(persona.auth):
            return ('reject', 'corroboration_required')
    if m_s < theta_s: return ('probe', 'contact_margin', m_s)
    return ('commit', m_s)
```

### IP-140 FMP（流匹配策略提案器，永不裁决）

```python
def flow_propose(v_theta, cond, K_modes, n):
    zs = sample_base(n)
    trajs = [integrate(v_theta, z, cond, steps=K_ode) for z in zs]
    modes = cluster_terminal(trajs, k=K_modes)    # 多模态：正面/侧抓/托底...
    out = []
    for pi in modes:
        out.append(Proposal(mode=pi, z=pi.rep_z, traj=pi.rep_traj,
                            tag='proposal',          # 契约：不是证据类
                            replay=(v_theta, cond, pi.rep_z)))
    return out, zs, trajs

def replay(p):                                    # 审计：给定种子逐条复现
    return integrate(p.replay[0], p.replay[2], p.replay[1])
```

### IP-141 FSC（流安全质量证书 + 反向流归因）

```python
def in_safe(a, S_c):
    return all(barrier(a.x[t]) >= 0 for t in a.t) \
       and all(a.m_s[t] >= theta_s for t in a.contact_phases) \
       and max(a.force) <= F_abs

def flow_safe_cert(v, cond, S_c, n, alpha):
    zs = sample_base(n)
    trajs = [integrate(v, z, cond) for z in zs]
    safe  = [in_safe(a, S_c) for a in trajs]
    lcb   = beta_lcb(sum(safe), n, alpha)         # Clopper-Pearson 下界
    modes = cluster_terminal(trajs)
    # 盲区项不在此估计：由独立对抗采样 + 模式覆盖审计给 δ_blind
    return Certificate(lcb=lcb, modes=modes,
                       blind_audit=adversarial_mode_audit(v, cond, modes))

def reverse_flow(v, a_fail, cond):
    z_star = integrate_backward(v, a_fail, cond)  # 失败轨迹反演
    return attribution(z_star, cond), z_star
```

### IP-142 CGT（约束引导传输，单调接受）

```python
def guided_transport(v, cond, S_c, lcb0, cov0, barrier):
    v_g = project_to_safe(v - lambda_g * grad(barrier), S_c)  # CBF 式引导
    lcb1, modes1, _ = flow_safe_cert(v_g, cond, S_c, n, alpha)
    cov1 = coverage(modes1)
    if lcb1 < lcb0 or cov1 < cov0 - eps_cov:      # H31 护栏：不许删生路
        return v, 'guide_rejected'
    return v_g, 'ok'

def integrate_guided(v_g, z, cond, S_c):
    x = z
    for t in linspace(0, 1, K_ode):
        x = x + dt * v_g(x, t, cond)
        if not feasible(S_c, x):
            x = project(x, S_c)                   # 每步安全投影
    return x
```

### IP-143 CTG（接触-流证据门 + 证书 J_c）

```python
def contact_transport_gate(c, M, persona, ood_reg):
    if c.ev == 'EV-contact':
        ok = c.m_s >= theta_s and has_ev_contact(c.h)
    elif c.ev == 'EV-flow':
        ok = c.level == 'L1' and c.cert.lcb >= theta_flow \
             and c.cert.blind_audit.covered and not c.irreversible
    elif c.ev == 'EV-probe*':
        ok = round57_probe_checks(c, M)           # 继承元校准/OOD
    elif c.ev == 'EV-margin':
        ok = c.K_margin >= theta_K
    elif c.ev in ('EV-visit', 'EV-xmodal', 'EV-human'):
        ok = round57_checks(c, M, persona)        # 继承第 57 轮
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-flow', 'EV-xmodal'):
        return ('reject', 'generative_on_irreversible', c)   # 硬禁令
    return ('ok', c)

def certificate_jc(sched, log, M, consent_log, auth_log, ood_reg):
    for c in contacts(sched):
        st = contact_transport_gate(c, M, persona_of(c), ood_reg)
        if st[0] != 'ok': return st
    if min(x.K_margin for x in sched) < theta_K:  return ('reject', 'K_margin')
    if any(x.slip_severity == 'macro' for x in log): return ('reject', 'slip_unresolved')
    if not all(l2.resolved for l2 in consent_log): return ('reject', 'consent_open')
    return ('ok', Jc(M.core, log.contact_log, log.slip_log,
                     log.flow_audit, log.safe_mass_lcb, log.mode_coverage,
                     log.blind_mode_audit, log.xmodal_log, log.auth_log, ood_reg))
```

### IP-144 PCE++（接触-传输探-诺-演）

```python
def probe_commit_evolve_contact(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        props, _, _ = flow_propose(v_theta, cond=(cp, M, inf), K_modes=budget.K_modes)
        props = [p for p in props if contact_margin(p.h, M) >= -theta_pre]
        while props and budget.contact_left > 0:
            props.sort(key=lambda p: voi_meta_pessimistic(p, M, inf) - cost(p))
            p = props[0]
            # 接触探针：预触 → 力斜坡 → 微滑移
            e = execute_contact_probe(p, cap=F_abs)
            M = contact_update(M, e); budget.spend_contact(e)
            log.append(e)
            if e.type == 'slip' and e.severity == 'macro':
                M = retroactive_downgrade(M, e)    # 回溯降权
                props, _, _ = flow_propose(v_theta, cond=(cp, M, inf),
                                           K_modes=budget.K_modes)  # 重开模式
                continue
            if e.type == 'contact' and contact_margin(p.h, M) >= theta_s:
                break
        lvl = contact_level(cp)                    # L0/L1/L2
        st  = contact_commit(x0, p.h, M, lvl, personas.active)
        if st[0] == 'commit' and contact_transport_gate(
                core_contact(p), M, personas, ood_reg)[0] == 'ok':
            sched.append(commit_contact(p)); continue
        alt = regrasp_or_reroute(M, cp, p)
        if alt and schedule_risk(alt, M) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, p, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CCM | O(\|C\|·d_f)/接触 | O(\|对象/区域\|) | 滑移裕度保守、macro 滑移不漏检（A41） |
| FMP | O(K_ode·d_θ)/轨迹 | O(d_θ+K_modes) | 提案契约、种子可复现（A44） |
| FSC | O(n·K_ode)/证书 | O(n) | 采样独立、LCB 覆盖、盲区单列（A42） |
| CGT | O(K_ode·d)/步 | O(d) | 单调接受、投影可行（A43） |
| CTG | O(\|σ\|) | O(\|σ\|) | 无接触证据不承诺、生成证据限 L1 |
| PCE++ | O(\|CP\|·(K_modes·n·K_ode+k_contact·d)) | O(\|V\|+K_modes·n) | K_modes+k_contact 终止 |

**正确性定理（Contact-Transport Warranted Soundness, CTWS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 接触模型诚实：m_s 为真实力闭合裕度下界，macro 滑移检测漏检 ≤δ_slip，μ/质心回溯更新为乘性降权且不增信；(A42)** 流证书有效：FSC 采样 i.i.d. 于真实提案分布，M_safe^LCB 覆盖 ≥1−α_conf，模型误差 ≤ε_θ，且盲区项 P_blind≤δ_blind 由独立对抗采样 + 覆盖审计给出（**不**由证书本身给出）；**(A43)** 引导单调：仅当 LCB 不降且覆盖降幅 ≤ε_cov 才接受，安全投影在可行时保证轨迹留在 S_c；**(A44)** 提案契约：FMP 输出不含证据类且可重放，不可逆接触禁用 EV-flow/EV-xmodal。则：

1. **接触承诺健全性**：P(slip | 提交) ≤ δ_slip(θ_s) + ε_contact；不可逆接触的滑移率由 θ_s 与佐证数共同约束。
2. **流辅助健全性**：L1 上以 EV-flow 顶替一次佐证的承诺失效率 ≤ (1−M_safe^LCB) + ε_θ + δ_blind；**不可逆接触的界不含流项、也不享受流收益**（硬禁），故生成器误差无法经此通道进入不可逆层。
3. **引导单调性**：接受 CGT 不增加已认证不安全质量，且模式覆盖下降 ≤ε_cov；被拒引导回退原速度场。
4. **提案隔离**：移除 FMP 不改变任何不可逆承诺的可达证据集，即生成器不是安全链上的必要环节（安全不依赖生成器正确）。
5. **终止性**：每检查点模式数 ≤K_modes、接触探针 ≤k_contact，PCE++ 在 K_modes+k_contact 内终止于 {承诺, 重抓, 绕行, L2 协商, 安全停}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                  + δ_contact + δ_slip + 1[L1]·((1−M_safe^LCB) + ε_θ + δ_blind) + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**接触证据裁决不可逆、流证据只做 L1 辅助**（两类新证据互不背书）；**安全质量证书度量的是"提案里安全的比例"，不是"世界的危险比例"**（盲区必须由独立审计另付）；**引导只许变安全、不许删生路**（LCB 与覆盖双单调）；**生成器可被整体移除而不破坏不可逆安全**（提案隔离）。

## 6. 本轮最大风险

**一句话**：本轮把"生成器有多安全"交给一个只在生成器自己采样上估计的安全质量证书，风险从"坏先验普遍"变为"**坏模式不可见**"——策略越只吐出熟悉的那几种抓法，`M_safe` 越漂亮，而真正救命的少数模态（薄壁、湿滑、非刚体）恰恰可能落在分布之外；因此流证据只能做 L1 辅助、不可逆接触必须由独立接触证据裁决，并用对抗采样与覆盖度硬门持续追问"你没生成的模式里有没有危险"。
