### 第 1 轮灵感驱动研究记录（承接 CADVS-v5 → v6）

**灵感词**：创新点挖掘、长程任务

**继承关系**：工作区既有状态为 CADVS-v5（IP-493~496，前序循环第 5 轮）：七硬门 fail-closed（覆盖/物理/人因/末点/记忆/价值/平衡）、证书演算与单调信任收缩、流匹配提议 FMPP、嵌入记忆固化 LMEM-v2、面部情感调制 FAMK、执行集嵌套 Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29；其最大未偿风险 R57 是「记忆固化自指回路」。本轮以「创新点挖掘」为方法论、以「长程任务」为问题域，把 v5 的**单次认证执行**推进到**长程认证执行**（Long-Horizon Certified Execution, LHCE），形成 CADVS-v6（IP-497~500）。本轮自律延续 v5：**不增硬门**，新增能力全部以「契约算子 / 信任账本 / 记忆分层 / 挖掘算子」实现，原子执行集仍只缩不涨。

**直觉与动机**：

1. **创新点挖掘不是头脑风暴，而是对设计空间的结构化搜索**。直觉：前几轮都在「补短板」，但补哪块最值一直靠灵感词撞。把设计空间显式化为 D = L × H（框架层 × 长程挑战），每格用（新颖度 N、安全杠杆 S、可行性 F、成本 C）打分，扣除既有轮次已覆盖的格，取 Pareto 前沿；再用「预注册预测 vs 实测增益」的 Spearman 相关检验挖掘器本身是否可信。这样「挖掘」从叙事变成可证伪算子。本轮挖出的三格是：(组合×门)→时序证书代数；(漂移×人因)→信任账本再锚定；(遗忘×记忆)→有界遗忘分层记忆。

2. **长程任务的本质是「认证的串联」，而串联会消耗边际**。直觉：v5 能认证单段轨迹，但长任务是一串技能首尾相接；每段执行都有跟踪误差，误差沿链条累积，吃掉下一段的可行域。引入**时序证书代数（TCA）**：每个技能携带 assume-guarantee 契约 K=(A,G)（假设集 A、保证边际 G、末态集 E），组合 K2∘K1 仅在「K1 的鲁棒末态集含于 K2 的假设集」时有定义；组合保证 G = min(G1, inf_{s∈E1^Δ} G2)。**定理 9（长程边际预算）**：在门边际 L-Lipschitz 假设下，可认证链条长度上界 L_max = 1 + ⌊(m0 − m_min)/(L_g·Δ)⌋——能走多远，精确地由初始边际、跟踪误差与门灵敏度决定。

3. **要突破边际预算，只能「再锚定」，而再锚定必须来自系统外部**。直觉：链条越长边际越薄，靠内部重算无法变厚；唯一出路是周期性引入外部真值（独立传感器/人类确认/物理测量）重置边际。引入**长程信任账本（HTL）**：维护边际预算 B_t，外部锚定按 α_t∈[0,1] 注资 B←α·m_fresh+(1−α)·B；**独立性红线**：若锚定证据由策略自身证书派生，则 α_t=0，不计注资。**定理 10（无自放大）**：α≡0 时 B_t 单调不增——策略无法自举信任。这正面对 R57 的自指回路：长程越久，越不能自我背书。

4. **长程记忆必须会遗忘，且遗忘本身是安全机制**。直觉：v5 固化把经验焊进策略，长程下旧自证模式会越焊越牢，加剧 R57。引入**有界遗忘分层记忆（HBFM）**：情节→语义→程序三层，升层需「铸证 ∧ 结局验证 ∧ 人工抽检 ∧ 反事实扰动一致」；容量有界，淘汰优先删除「移除后不改变已认证契约集」的条目（可证安全遗忘），失败模式条目钉住不删。遗忘让自证模式自然衰减，是对 R57 的结构性对冲，而非补丁。

**关键洞见**：v5 问「任意提议下证书边界是否不变」；v6 问「把认证执行沿时间串联时，边界如何随 horizon 收缩、又靠什么外部证据回补」。答案是一条守恒式：**认证长程 = 边际预算 + 外部锚定**。七硬门与 τ^5 原样冻结；新增的是契约组合算子 ∘、信任账本 B、分层遗忘 M、挖掘算子 Ω。原子执行集 Exec_v6 ⊆ Exec_v5（鲁棒 Δ 与 β_min 只紧），并新增链条层 ChainExec_v6 = Closure_∘(Exec_v6)。

**形式化目标（增量）**：
1. 契约：K_σ=(A_σ,G_σ,E_σ)，A_σ⊆S 假设集，G_σ:S→R≥0 保证边际，E_σ 末态集；鲁棒末态集 E_σ^Δ。
2. 组合：K2∘K1 有定义 ⇔ E_1^Δ(A_1) ⊆ A_2；G_{21}(s)=min(G_1(s), inf_{s'∈E_1^Δ(s)} G_2(s'))。
3. 定理 9 长程边际预算、定理 10 信任无自放大、定理 11 A/G 组合可靠性、定理 12 有界遗忘保持契约集、定理 13 Exec_v6 ⊆ Exec_v5 与链条闭包。
4. HTL：B_{t+1}=B_t·exp(−λ·d_t/Δ)，锚定 α_t 独立性审计，B<B_min 则停/再锚。
5. HBFM：升层谓词 Promote、钉住集 Pin、淘汰分数、容量 C_e/C_s/C_p。
6. IPM：D=L×H，打分 (N,S,F,C)，覆盖扣除，Pareto 选择，Spearman 校准。

**本轮最大风险**：**边际预算与锚定稀缺的耦合塌缩**——长程下鲁棒边际随 horizon 线性消耗，而外部锚（独立传感器/人类确认）在真实部署中稀疏且昂贵；系统要么在 B<B_min 时安全停机（安全但无用），要么被迫放宽 Δ 或降低 B_min（有用但不安全）。TCA/HTL 只是把这一权衡显式化，并未消除它。

## 2. 关键算法骨架

### IP-497 TCA：时序证书代数（规划/准入时域，离线或 10 Hz）

```python
@dataclass(frozen=True)
class Contract:
    """七硬门上的 assume-guarantee 契约。门集合不变，契约只是门的时域封装。
    红线：gates_sig 必须等于 v5 冻结的门签名，任何门改动使契约失效"""
    A: Region                       # 假设集：可接受的起始状态集合
    G: Callable[[State], float]     # 保证边际 G(s)=min_i inf m_i ≥ 0
    E: Callable[[State], Region]    # 末态集
    gates_sig: tuple                # 冻结门版本签名

def compose(k1: Contract, k2: Contract, delta: float) -> Contract | None:
    """K2 ∘ K1：守卫条件 E1^Δ(A1) ⊆ A2；不满足则拒绝组合（fail-closed）"""
    if k1.gates_sig != k2.gates_sig:
        return None
    if not subset(inflate(k1.E_of(k1.A), delta), k2.A):
        return None
    def G(s: State) -> float:
        return min(k1.G(s), inf_over(k2.G, inflate(k1.E_of(s), delta)))
    def E(s: State) -> Region:
        return union_over(k2.E_of, inflate(k1.E_of(s), delta))
    return Contract(A=k1.A, G=G, E=E, gates_sig=k1.gates_sig)

def certify_chain(skills: list[Skill], s0: State, delta: float,
                  m_min: float) -> ChainCertificate:
    """左折叠组合；任一组合无定义或边际 < m_min → fail-closed"""
    k = skills[0].contract
    if k.G(s0) < m_min:
        return ChainCertificate(ok=False, reason='SEED_MARGIN_FAIL')
    for sk in skills[1:]:
        k = compose(k, sk.contract, delta)
        if k is None:
            return ChainCertificate(ok=False, reason='CONTRACT_MISMATCH')
        if k.G(s0) < m_min:
            return ChainCertificate(ok=False, reason='MARGIN_EXHAUSTED')
    # 定理 9 的预算预测，供 HTL 规划再锚定时机
    L_max_h = 1 + floor((skills[0].contract.G(s0) - m_min) / (L_g * delta))
    return ChainCertificate(ok=True, margin=k.G(s0), horizon=len(skills),
                            l_max_h=L_max_h)
```

### IP-498 HTL：长程信任账本（在线，每步 O(1)）

```python
@dataclass
class HorizonTrustLedger:
    """HTL：边际预算账本。锚定必须外部独立，否则 α=0（定理 10 无自放大）"""
    lam: float = 1.0
    beta_min: float = 0.15
    m_min: float = 0.05

    def step(self, B: float, deviation: float, delta: float) -> float:
        # 无锚定时单调不增：exp(-λ·d/Δ) ≤ 1
        return B * exp(-self.lam * deviation / max(delta, 1e-9))

    def anchor(self, B: float, m_fresh: float, evidence: Evidence) -> float:
        # 自证证据（由策略自身证书派生）→ α=0，不注资
        alpha = 1.0 if audit_independent(evidence) else 0.0
        return alpha * m_fresh + (1.0 - alpha) * B

    def must_reanchor(self, B: float) -> bool:
        return B < self.beta_min * self.m_min

    def audit_independent(self, ev: Evidence) -> bool:
        # 独立性：证据源 ∈ E_ext 且与策略自身输出在审计下条件独立
        return ev.source in E_ext and ev.independence_audit_passed
```

### IP-499 HBFM：有界遗忘分层记忆（检索 O(log|M|)；淘汰离线/低频）

```python
@dataclass
class HierarchicalBoundedForgettingMemory:
    """情节→语义→程序三层；遗忘是安全机制，不是容量补丁"""
    C_e: int = 50_000; C_s: int = 5_000; C_p: int = 500
    pinned: set = field(default_factory=set)      # 失败模式条目，永不淘汰

    def promote(self, ep: Episode) -> bool:
        # 反事实一致：在假设集内扰动起点仍成功，削弱「只在自证样本上成立」
        return (ep.forged and ep.outcome_ok and ep.human_audit
                and counterfactual_consistent(ep, n_perturb=8))

    def evict(self, tier: str) -> list[Episode]:
        cap = {'episodic': self.C_e, 'semantic': self.C_s, 'procedural': self.C_p}[tier]
        items = self.tiers[tier]
        if len(items) <= cap:
            return []
        # 优先删「移除后不改变已认证契约集」的条目 → 可证安全遗忘（定理 12）
        safe = [e for e in items
                if e not in self.pinned and not contract_critical(e)]
        if len(items) - len(safe) <= cap:
            return drop_oldest(safe, n=len(items) - cap)
        # 安全条目不足时才按效用 + DP 噪声淘汰，并写审计日志
        return dp_evict(items, self.pinned, n=len(items) - cap)
```

### IP-500 IPM + EFA-v6：创新挖掘算子与装配（离线方法论 + 在线装配）

```python
@dataclass
class InnovationMiningOperator:
    """把「找创新点」做成可证伪算子：打分 → 扣覆盖 → Pareto → Spearman 校准"""
    layers = ('proposal', 'gate', 'memory', 'human', 'verify', 'compose', 'eval')
    challenges = ('accum', 'compose', 'drift', 'credit', 'forget', 'reanchor', 'scaling')

    def mine(self, coverage: dict[tuple, int], k: int = 3) -> list[Cell]:
        cells = []
        for l in self.layers:
            for h in self.challenges:
                if coverage.get((l, h), 0) >= 1:     # 既有轮次已覆盖
                    continue
                N, S, F, C = self.score(l, h)
                cells.append(Cell(l, h, value=N * S * F / (C + 1e-9)))
        return pareto_topk(cells, k)

    def calibrate(self, predicted: list[float], measured: list[float]) -> float:
        # 预注册 V 排名 vs 实测增益；ρ_s 低说明「挖掘」只是事后叙事
        return spearman(predicted, measured)


@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：原子七门不变 + 链条组合认证 + 再锚定判定"""
    v5: EvidenceForgingAssemblerV5
    tca: TemporalCertificateAlgebra
    htl: HorizonTrustLedger
    hbfm: HierarchicalBoundedForgettingMemory

    def select_chain(self, task, s0, delta):
        skills = self.v5.fmpp.propose_plan(task)          # 复用 v5 提议
        for sk in skills:                                  # 原子层：七门不变
            if not self.v5.gate_all(sk.traj, sk.start):
                return False, None, 'ATOMIC_GATE_REJECT'
        cert = self.tca.certify_chain(skills, s0, delta, m_min=self.htl.m_min)
        if not cert.ok:
            return False, None, cert.reason
        if self.htl.must_reanchor(cert.margin):            # 预算耗尽 → 先锚
            return True, cert, 'REANCHOR_REQUIRED'
        return True, cert, 'FORGED_LHCE'
```

### 集成流水线（v5 → v6）

```
离线/慢时域：
  IPM 挖掘（每轮一次）：D=L×H 打分 → 扣覆盖 → Pareto top-k → 预注册预测
  HBFM 固化（小时级）：Promote 过滤（含反事实一致）→ DP-SGD + KL 正则 → 回归门 + 红队
  契约编译：每个技能离线计算 (A,G,E) 与 Lipschitz 常数 L_g；门签名冻结

在线规划/准入（异步，秒级）：
  FMPP.propose_plan ──▶ 逐段七门 ──▶ TCA 守卫组合 ──▶ 定理 9 预算预测 L_max_h
        ├─ 组合失败/边际耗尽 ──▶ fail-closed 回退 v5 单段执行或拆分任务
        └─ 认证通过 ──▶ HTL 规划再锚点（B 低于阈值处插入外部测量）

在线控制环（1 kHz，不变）：
  每周期：EEK(kc_ee) + BCK（事件触发缓存证书）；消费 v5 冻结门与 τ^5
  HTL.step 每步 O(1) 更新 B；B<B_min 触发再锚请求（异步，不进环）

外部锚定（事件触发）：
  独立传感器/人类确认 ──▶ 独立性审计 ──▶ α=1 才注资 B ← m_fresh；否则 α=0
```

## 4. 正确性论证（增量更新）

### 引理 45（门边际的 Lipschitz 鲁棒性）

**陈述**：在假设 (B8) 下，每个门边际 m_i 对起始状态扰动满足 L_i-Lipschitz。则对 ‖δ‖≤Δ 有 m_i(x;s+δ) ≥ m_i(x;s) − L_i·Δ。**证明**：Lipschitz 定义直接展开。∎

**诚实边界**：(B8) 在接触建立/丢失/打滑等不连续处会失效，边际可能跳变；工程上用事件触发在拓扑变更处强制全量重算（复用 v5 BCK），并把跳变计入 Δ。

### 定理 11（A/G 组合可靠性）

**陈述**：若 K1、K2 对各自技能可靠（在 A 内执行确实达到 G 且末态落在 E），且守卫条件 E_1^Δ(A_1)⊆A_2 成立，则 K2∘K1 可靠，其执行通过七门且边际 ≥ G_{21}(s0)。**证明**：首段可靠 ⇒ 边际≥G1 且实际末态∈E1；由引理 45，任何实际末态 s'∈E_1^Δ(s0)⊆A_2；次段在 s' 可靠 ⇒ 边际≥G2(s')；对 s' 取下确界后与 G1 取 min。∎

### 定理 9（长程边际预算）

**陈述**：在 (B8) 下，长度 L、每步跟踪误差 ≤Δ 的链条，其鲁棒边际满足 m_chain ≥ m0 − (L−1)·L_g·Δ 且 m_chain ≤ m0（单调不增）。故可认证当且仅当 m0 − (L−1)·L_g·Δ ≥ m_min，即 L ≤ 1+⌊(m0−m_min)/(L_g·Δ)⌋ = L_max_h。**证明**：对每次组合应用引理 45，逐项望远镜求和；上界由组合取 min。∎

**工程含义**：这是可证伪的定量预测——认证 horizon 应与 Δ 成反比。实验可直接检验 L_max_h 与实测最长可认证链是否吻合（见 §5）。

### 定理 10（信任无自放大）

**陈述**：若所有锚定的 α_t=0（证据由策略自身证书派生），则 B_{t+1}=B_t·exp(−λ d_t/Δ) ≤ B_t，从而 B_t ≤ B_0。**证明**：衰减因子 ≤1 且锚定退化为恒等。∎ **推论**：自证不能提升信任；任何 B 的增长必须来自 α>0 的外部独立证据。这从结构上切断 R57 的「铸证→自证→更可信」回路。

### 定理 12（有界遗忘保持契约集）

**陈述**：设淘汰只移除不在 Pin 且非 ContractCritical 的条目。若 ContractCritical 判定可靠，则任意淘汰序列后，已认证契约集不变。**证明**：ContractCritical(e)=真 定义为「移除 e 后契约集改变」；只删其补集，故契约集不变；对淘汰序列归纳。∎ **诚实边界**：ContractCritical 的可靠判定本身是近似（需重跑认证），故定理在「判定器可靠」条件下成立。

### 定理 13（原子嵌套与链条闭包）

**陈述**：(i) 原子 Exec_v6 = {x : ∧_i kc_i(x;τ^5)=1 ∧ robust_margin(x)≥m_min ∧ B≥B_min} ⊆ Exec_v5；令 Δ=0,m_min=0,B_min=0 时精确退化 v5。(ii) ChainExec_v6=Closure_∘(Exec_v6) 在守卫组合下封闭（由定理 11）。(iii) 不增硬门、不改锚点集合（七门冻结）。**证明**：(i) 两个附加谓词只删不增；(ii) 定理 11 保证组合可靠，归纳得闭包；(iii) 构造上未引入新门。∎

**诚实声明**：(i) (B8) 在接触不连续处失效，鲁棒界可能乐观；(ii) ContractCritical 判定近似；(iii) 外部锚的可得性/成本未建模进定理，只由实验评估；(iv) IPM 的打分 (N,S,F,C) 含主观项，Spearman 校准只能证伪「完全无预测力」，不能证明最优；(v) HBFM 仍可能漏掉未钉住的罕见失败模式。

## 5. 实验设计与初步结果（仿真，单机；实机/舰队列入后续轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX；长程装配/厨房任务，技能库复用 v5 FMPP 提议；七门原样调用；外部锚用「oracle 状态测量（低成本）/ 人类确认（高成本）」两级模拟，按预算配额注入。
- **horizon 梯度**：L ∈ {1,3,5,10,20,50}。
- **对照**：v5-单段（整任务当一条轨迹）、flat-replan、naive-concat（无鲁棒守卫直接拼接）、TCA-only（无 HTL）、TCA+HTL（无 HBFM）、v6-full。
- **指标**：horizon 成功率、链条认证率、边际预算消耗曲线、再锚定频率、偏差检测 AUROC、自证博弈拦截率、内存规模与遗忘后性能、IPM 的 Spearman ρ_s、规划时延、控制环 P99。
- **消融**：关闭 Δ（设 0，预期边际界失效、违例上升）、关闭 Pin（预期罕见失败被遗忘）、随机选点 vs IPM 选点（验证挖掘器）。

| R60 | **边际预算与锚定稀缺耦合塌缩**（horizon↑ ⇒ B↓，锚贵 ⇒ 要么停机要么放松） | **极高** | 定理 9 显式预算 + 自适应 Δ + 任务拆分 + 锚定预算规划 | 权衡无法消除，只能管理 |

## 7. 本轮最大风险（最终确认）

**一句话**：**边际预算与锚定稀缺的耦合塌缩**——长程下鲁棒边际随 horizon 线性消耗，而外部独立锚（传感器/人类确认）稀疏且昂贵；系统要么在 B<B_min 时安全停机（安全但无用），要么被迫放宽 Δ 或降低 B_min（有用但不安全）。TCA/HTL 只是把这一权衡显式化，并未消除它。
