# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮（新周期）；本轮灵感：「低延迟推理」×「模仿学习」）

> 第 54 轮把技能组合提升为「动作空间 α_S + 鲁棒性谱 ρ + 云边映射 γ_ce」的双证书体系。本轮引入两组新的第一性约束：**低延迟推理**把计算变成受截止期支配的稀缺资源，**模仿学习**把「技能从哪来」变成演示分布下的协变量偏移问题。核心矛盾：H22：模仿学习的协变量偏移界默认「观测-动作同步」，低延迟推理使动作陈旧 Δ，有效策略 π^Δ 偏离演示分布，误差被延迟乘性放大；H23：第 54 轮的动作剖面 α_S 只有「质量」维度而没有「预算/时延」维度，同一技能在不同算力预算下覆盖不同，组合图的转换成本与时延耦合，导致路径在截止期上不可行。

## 0. 直觉与动机

**灵感 1（延迟是对策略算子的形变，不只是外部约束）**
直觉：低延迟推理不是给策略「加一个超时」，而是用一个延迟算子 Φ_Δ 把名义策略 π 变成「用 t-Δ 的观测产生 t 时刻动作」的等效策略 `π^Δ = Φ_Δ(π)`。模仿学习的经典界 `J(π_E) - J(π̂) ≤ C·ε_IL·T` 假设同步；延迟把这个界乘上一个与 Δ、状态速度、策略敏感度成正比的放大因子。于是「低延迟」是 **协变量偏移的乘性放大器**，而不是一个可以事后裁剪的指标——先降延迟再谈模仿精度，否则精度被陈旧观测系统性浪费。

**灵感 2（时延-容差对偶 → 第 54 轮的 A_buffer 恰好能「吸收」延迟）**
直觉：第 54 轮的动作证书带有容错带 A_buffer。若动作在 Δ 内变化足够慢，则陈旧动作仍落在 A_buffer 的「拉回域」内，系统可容忍。于是定义技能的最大可容忍延迟 `Δ_max(S) = sup{Δ : drift_Δ(A_core) ⊆ A_buffer}`。这把「低延迟」从绝对阈值变成 **相对技能动作带宽的性质**：动作越平滑、越块化，Δ_max 越大。这正是 action chunking 在低延迟场景有效的第一性解释，也把时延与第 54 轮的动作契约显式耦合。

**灵感 3（Any-time 动作剖面 → α_S 增加算力预算维度）**
直觉：同一技能在预算 b 下只能覆盖「粗动作核心」，预算升高才扩展到精细动作；覆盖随预算单调增、容差随预算单调减。定义 `α_S(a,b)` 与 **预算-覆盖曲线**，由此得到任务的最小可行预算 `b_min(S,A_T)`。这把第 54 轮的动作剖面从静态占用升级为 **随算力伸缩的 anytime 剖面**，为端侧「按需降级」提供可判定依据，而不是靠经验设一个固定超时。

**灵感 4（延迟感知组合与算力预算再分配）**
直觉：组合路径不仅要满足动作兼容与转换成本，还要在总截止期 `T_dl` 内完成 `Σ ℓ(S_i,b_i) + Σ ℓ_trans ≤ T_dl`。于是第 54 轮的最短路变成 **带截止期的资源约束最短路**。更进一步，总预算 `B_total` 在技能间可再分配：把算力给鲁棒性敏感度高的技能、压缩不敏感技能，能在同一截止期下最大化最差维度鲁棒性 `min_d ρ`。这形成 **算力-鲁棒性联合分配**，与第 54 轮的 `compat` 约束正交。

**灵感 5（延迟失配证书与延迟 DAgger）**
直觉：演示通常在「无延迟/离线」下采集，部署在低延迟但受限的端侧，二者存在 **演示-部署延迟失配**。把失配量 `ε_drift` 做成证书：超预算则拒绝，或触发 **延迟 DAgger**——在 Φ_Δ 诱导的状态分布上向专家查询校正，把插值误差拉回。这把模仿学习从一次性行为克隆变成 **带延迟锚点的在线校正闭环**，与第 54 轮的反向解释信道天然同构。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（推理延迟剖面）**
策略 π 的推理延迟 `ℓ_π(o) ~ D_π(o)`，以分位数 `ℓ_π^q(o)`（q ∈ {50,95,99}）刻画。对技能 S 记 `ℓ_S = ℓ_π`。截止期违约率 `miss_π(T_dl) = P_{o~ν}(ℓ_π(o) > T_dl)`。要求 `D_π` 在部署硬件上按次高斯尾部校准（见 A29）。

**定义 122（延迟等效策略与延迟条件协变量偏移系数）**
延迟算子 `Φ_Δ(π)(o_t) = π(o_{t-Δ})`。对平滑系统定义延迟条件协变量偏移系数
```
κ_Δ = sup_s ( ||∂π/∂s|| · ||ṡ|| · Δ ) / (1 + ||s||)
```
模仿差距界：`J(π_E) - J(Φ_Δ(π̂)) ≤ C · ε_IL · (1 + κ_Δ) · T`。直觉：延迟把单步误差的传播速率放大 `(1+κ_Δ)` 倍。

**定义 123（Any-time 动作剖面）**
`α_S : A × B → [0,1]`，B 为算力预算格（FLOPs/延迟档）。固定 b 时 `α_S(·,b)` 为预算 b 下的动作占用。要求预算单调：`b1 ≤ b2 ⇒ α_S(a,b1) ≤ α_S(a,b2)`，且容差反向单调 `buf_S(b1) ⊇ buf_S(b2)`。

**定义 124（预算-覆盖曲线、最小可行预算与时延-容差对偶）**
`cov_S(b) = |{a ∈ A_T : α_S(a,b) ≥ θ_cov}| / |A_T|`；`b_min(S,A_T) = min{b : cov_S(b) = 1}`。
时延-容差对偶：`Δ_max(S) = sup{Δ ≥ 0 : drift_Δ(A_core) ⊆ A_buffer}`，其中 `drift_Δ(A) = {a(t-Δ)⊕Δ·ȧ : a ∈ A}` 为延迟漂移域。

**定义 125（延迟感知技能组合）**
组合边 `e=(i,j)` 附三维权 `w_e = (c_trans, ℓ_trans, b_req)`。路径可行当且仅当
```
compat(S_i,S_j) ≥ θ_a
∧ Σ_e c_trans(e) ≤ C_max
∧ Σ_i ℓ(S_i,b_i) + Σ_e ℓ_trans(e) ≤ T_dl
∧ b_i ≥ b_min(S_i, A_T^i)   ∀i
```

**定义 126（算力-鲁棒性分配）**
预算分配 `β = {b_i}`，满足 `Σ_i b_i ≤ B_total`。最优分配
```
β* = argmax_β min_{d∈𝔇} ρ_comp(d; β)   s.t. 截止期约束与 b_min 约束
```
分配收益 `Δρ = min_d ρ(d; β*) - min_d ρ(d; β_uniform)`，用于度量「把算力用在刀刃上」的增益。

**定义 127（演示-部署延迟失配证书）**
`L_cert = (Δ_demo, Δ_deploy, ε_drift, κ_Δ)`，其中 `ε_drift = E_{s~ν_deploy}[ d(π_E(s), Φ_Δ(π̂)(s)) ]`。若 `ε_drift > ε_max` 或 `Δ_deploy > Δ_max(S)`，则拒绝部署或触发延迟 DAgger；否则证书随组合证书一同传递。

**定义 128（动作块策略与最优块长）**
块策略每 h 步推理一次：`ℓ_chunk(h) = h·τ_env + L_infer(h)`，协变量偏移随块长增长 `ε(h) = ε_IL·(1 + κ_{h·τ_env})`。最优块长
```
h* = argmin_h [ ε(h) + λ · max(0, ℓ_chunk(h) - T_dl) / T_dl ]
```
在「块太长导致反应迟钝/超时」与「块太短导致推理频率过高/延迟堆积」之间取平衡。

## 2. 关键算法 伪代码

### IP-121 LIP（Latency Imitation Profile）
```python
def latency_imitation_profile(policy, obs_dist, deltas, quantiles=(50,95,99)):
    lat = measure_latency(policy, obs_dist)          # 实测硬件延迟分布
    kappa = {}
    for delta in deltas:
        phi = delay_operator(policy, delta)          # Φ_Δ
        kappa[delta] = covariate_shift_coeff(phi, policy, obs_dist)
    return LatencyProfile({q: quantile(lat, q) for q in quantiles}, kappa)
```

### IP-122 ABP（Anytime Budget Profiler）
```python
def anytime_profile(skill, A_T, budgets, theta_cov):
    curve = {}
    for b in sorted(budgets):
        alpha = profile_at_budget(skill, b)          # α_S(·,b)
        curve[b] = coverage(alpha, A_T, theta_cov)
    b_min = next((b for b in sorted(budgets) if curve[b] >= 1.0), float('inf'))
    delta_max = max_delta_within_buffer(skill)       # drift_Δ(A_core) ⊆ A_buffer
    return AnytimeProfile(curve, b_min, delta_max)
```

### IP-123 LAC（Latency-Aware Composition）
```python
def latency_aware_path(G, T_dl, B_total, C_max):
    # 三维资源约束最短路：cost / latency / budget
    labels = resource_constrained_shortest_path(
        G, dims=['cost', 'latency', 'budget'],
        bounds={'cost': C_max, 'latency': T_dl, 'budget': B_total})
    return [p for p in labels if p.feasible]
```

### IP-124 LBRA（Latency-Budgeted Robustness Allocation）
```python
def allocate_budget(skill_seq, B_total, rho_min, step):
    beta = init_from_b_min(skill_seq)                # 先满足 b_min
    while sum(beta.values()) + step <= B_total:
        gains = {i: marginal_robustness_gain(skill_seq, beta, i) for i in beta}
        i = max(gains, key=gains.get)
        if gains[i] <= 0:
            break
        beta[i] += step                              # 贪心填空，可换 LP 松弛
    if min(composed_rho(skill_seq, beta).values()) < rho_min:
        return ('reject', 'robustness_infeasible', beta)
    return ('ok', beta)
```

### IP-125 LMC（Latency Mismatch Certificate）
```python
def latency_mismatch_cert(policy_hat, expert, nu_deploy, delta_deploy,
                          delta_max, eps_max):
    phi = delay_operator(policy_hat, delta_deploy)
    eps_drift = expectation(nu_deploy,
                            lambda s: dist(expert(s), phi(s)))
    if delta_deploy > delta_max or eps_drift > eps_max:
        return ('reject', L_cert(delta_deploy, eps_drift),
                'trigger_delay_dagger')
    return ('ok', L_cert(delta_deploy, eps_drift,
                         kappa_delta=covariate_shift_coeff(phi, expert, nu_deploy)))
```

### IP-126 ACB（Action Chunk Balancer）
```python
def optimal_chunk_len(h_grid, eps_IL, kappa_fn, tau_env, L_infer, T_dl, lam):
    def obj(h):
        cost = eps_IL * (1 + kappa_fn(h * tau_env))
        over = max(0.0, h * tau_env + L_infer(h) - T_dl) / T_dl
        return cost + lam * over
    return min(h_grid, key=obj)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| LIP | O(|O|·|Δ|·C_π) | O(|Δ|) | 延迟尾部校准、κ_Δ 有界 |
| ABP | O(|B|·|A|·|S|) | O(|B|·|A|) | 预算单调、覆盖可判定 |
| LAC | O(|E|·Π_d bound_d) | O(|V|·Π_d bound_d) | 标签支配剪枝 sound、截止期闭合 |
| LBRA | O(|S|·(B_total/step)·|𝔇|) | O(|S|) | 边际收益次模/近似最优 |
| LMC | O(|ν_deploy|·C_π) | O(1) | ε_drift 可估、Δ_max 可判定 |
| ACB | O(|h_grid|) | O(1) | 目标单峰、h* 存在 |

**正确性定理（Latency-Aware Imitation-Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `ℓ_π` 次高斯且尾部分位数已校准（P99 可由有限样本界定）；**(A30)** 演示与部署共享观测语义（无外生分布偏移）；**(A31)** `T_dl, τ_ctrl` 固定可测，`Δ_deploy ≤ τ_ctrl`；**(A32)** anytime 剖面在预算上单调、`Δ_max(S)` 可判定；**(A33)** 延迟 DAgger 查询预算足以使 `ε_drift` 收敛到 `ε_max` 以内。则
```
P_success ≥ 1 - [ Σ_d(1-ρ_min(d)) + β_E + P(δ_a > Θ_a) + P(compat < θ_a) ]
              - C · ε_IL · (1 + κ_{Δ_deploy})
              - P( Σ_i ℓ(S_i,b_i) + Σ_e ℓ_trans(e) > T_dl )
```
关键：**延迟只通过 κ_Δ 进入模仿误差界**，**截止期违约是独立可加项**，**b_min 与 Δ_max 把「算力」和「容差」变成可判定的部署前提**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 延迟分布重尾/非平稳（热降频、资源争用） | 高 | 在线分位数跟踪 + 冷启动保守上界 + 尾延迟红队测试 |

## 6. 本轮最大风险

**一句话**：把低延迟推理与模仿学习耦合为「延迟形变策略 + anytime 剖面 + 算力再分配 + 延迟失配证书」，理论上优雅，但其 soundness **同时依赖延迟尾部可校准、κ_Δ 界非空、以及 anytime 剖面的预算单调**；一旦真实端侧的延迟重尾且随热/负载漂移，κ_Δ 的实测界会瞬间失真，而按静止分布算出的 b_min 与 Δ_max 会把「离线可部署」误判为「在线可部署」，故必须以 **在线尾延迟跟踪 + 分段保守 κ_Δ + 硬截止期绊线** 三重护栏，宁可牺牲算力利用率，也不拿延迟分布的平稳性当部署前提。

## 2. 关键算法 伪代码

### IP-121 LIP
```python
def latency_imitation_profile(policy, obs_dist, deltas, quantiles=(50,95,99)):
    lat = measure_latency(policy, obs_dist)
    kappa = {d: covariate_shift_coeff(delay_operator(policy, d), policy, obs_dist)
             for d in deltas}
    return LatencyProfile({q: quantile(lat, q) for q in quantiles}, kappa)

def delay_operator(policy, delta):
    return lambda o_t: policy(o_t - delta)          # 观测时间戳平移

def covariate_shift_coeff(phi, policy, obs_dist):
    # κ_Δ = sup_s ||∂π/∂s||·||ṡ||·Δ / (1+||s||)
    return max(jacobian_norm(phi, s) * speed_norm(s) * delta / (1 + norm(s))
               for s, delta in sample_states(obs_dist))
```

```python
        curve[b] = coverage(alpha, A_T, theta_cov)
    b_min = next((b for b in sorted(budgets) if curve[b] >= 1.0), float('inf'))
    delta_max = max_delta_within_buffer(skill)
    return AnytimeProfile(curve, b_min, delta_max)

def max_delta_within_buffer(skill):
    lo, hi = 0.0, skill.max_delay_bound
    for _ in range(20):                              # 二分 drift_Δ ⊆ A_buffer
        mid = (lo + hi) / 2
        if drift_domain(skill.A_core, mid).issubset(skill.A_buffer):
            lo = mid
        else:
            hi = mid
    return lo
```

### IP-124 LBRA
```python
def allocate_budget(skill_seq, B_total, rho_min, step):
    beta = init_from_b_min(skill_seq)
    while sum(beta.values()) + step <= B_total:
        gains = {i: marginal_robustness_gain(skill_seq, beta, i) for i in beta}
        i = max(gains, key=gains.get)
        if gains[i] <= 0:
            break
        beta[i] += step
    if min(composed_rho(skill_seq, beta).values()) < rho_min:
        return ('reject', 'robustness_infeasible', beta)
    return ('ok', beta)
```

### IP-125 LMC
```python
def latency_mismatch_cert(policy_hat, expert, nu_deploy, delta_deploy,
                          delta_max, eps_max):
    phi = delay_operator(policy_hat, delta_deploy)
    eps_drift = expectation(nu_deploy, lambda s: dist(expert(s), phi(s)))
    if delta_deploy > delta_max or eps_drift > eps_max:
        return ('reject', L_cert(delta_deploy, eps_drift),
                'trigger_delay_dagger')
    return ('ok', L_cert(delta_deploy, eps_drift,
                         kappa_delta=covariate_shift_coeff(phi, expert, nu_deploy)))

def delay_dagger(policy_hat, expert, nu_deploy, delta, rounds):
    for _ in range(rounds):                          # 在 Φ_Δ 诱导分布上聚合
        phi = delay_operator(policy_hat, delta)
        D_new = [(s, expert(s)) for s in sample(nu_deploy)]
        policy_hat = fit_bc(policy_hat, D_new)
        nu_deploy = rollout_mixture(policy_hat, phi)
    return policy_hat
```

### IP-126 ACB
```python
def optimal_chunk_len(h_grid, eps_IL, kappa_fn, tau_env, L_infer, T_dl, lam):
    def obj(h):
        cost = eps_IL * (1 + kappa_fn(h * tau_env))
        over = max(0.0, h * tau_env + L_infer(h) - T_dl) / T_dl
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LIP | O(|O|·|Δ|·C_π) | O(|Δ|) | 延迟尾部校准；`κ_Δ` 有界且 Lipschitz |
| ABP | O(|B|·|A|·|S| + 20·|A_core|) | O(|B|·|A|) | 预算单调；`Δ_max` 二分收敛 |
| LAC | O(|E|·Π_d bound_d) | O(|V|·Π_d bound_d) | 标签支配 sound；截止期剪枝不丢最优 |
| LBRA | O(|S|·(B_total/step)·|𝔇|) | O(|S|) | 边际收益近似次模 → 常数近似 |
| LMC | O(|ν_deploy|·C_π) | O(1) | `ε_drift` 可估；拒绝规则 sound |
| ACB | O(|h_grid|) | O(1) | 目标单峰 → 全局 `h*` |

**正确性定理（Latency-Aware Imitation-Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `ℓ_π` 次高斯且尾部分位数由有限样本校准；**(A30)** 演示与部署共享观测语义；**(A31)** `T_dl, τ_ctrl` 固定可测且 `Δ_deploy ≤ τ_ctrl`；**(A32)** anytime 剖面预算单调、`Δ_max(S)` 可判定；**(A33)** 延迟 DAgger 查询预算使 `ε_drift` 收敛到 `ε_max` 以内。则
```
P_success ≥ 1 - [ Σ_d(1-ρ_min(d)) + β_E + P(δ_a > Θ_a) + P(compat < θ_a) ]
              - C · ε_IL · (1 + κ_{Δ_deploy})
              - P( Σ_i ℓ(S_i,b_i) + Σ_e ℓ_trans(e) > T_dl )
```
三项结构清晰：**鲁棒性缺口**（第 54 轮）、**延迟放大的模仿误差**（本轮 LIP/LMC）、**截止期违约**（本轮 LAC/ACB）。

## 6. 本轮最大风险

**一句话**：把低延迟推理与模仿学习耦合为「延迟形变策略 + anytime 剖面 + 算力再分配 + 延迟失配证书」，理论上优雅，但其 soundness **同时依赖延迟尾部可校准、κ_Δ 界非空、以及 anytime 剖面的预算单调**；一旦真实端侧的延迟重尾且随热/负载漂移，κ_Δ 的实测界会瞬间失真，而按静止分布算出的 b_min 与 Δ_max 会把「离线可部署」误判为「在线可部署」，故必须以 **在线尾延迟跟踪 + 分段保守 κ_Δ + 硬截止期绊线** 三重护栏，宁可牺牲算力利用率，也不拿延迟分布的平稳性当部署前提。
