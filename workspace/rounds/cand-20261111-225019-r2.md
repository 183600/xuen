# 第 57 轮（承接第 56 轮「MapProbe-Negotiate」IP-127~132；灵感循环第 2 轮；本轮灵感：「运动控制」×「通用机器人平台」）

> 第 56 轮把安全依据从"模型置信"升级为"证据承诺"：语义变成持久地图 𝓜，动作扩为运动×探询×沟通，护盾会协商。但它默认了两个未经检验的前提：(a) 证据是**外生**的——探针似然 `p(e|r,θ_true)` 与控制器无关；(b) 证据是**无条件**的——一条证据对所有身体、所有时刻都同权。本轮两个灵感正好各击穿一个：**运动控制**说明证据是在反馈回路里被"制造"出来的（控制器一边补偿滑移一边掩盖滑移，观测分布依赖策略而非仅依赖地形），并在 ms 级连续演化；**通用机器人平台**说明证据是**受身体约束**的（同一块地面的 μ 或许可移植，但 F_bear、接触刚度 k 取决于足端面积与压力，换一个本体就换了一个有效性域）。于是本轮命题从"证据说可信"收紧为 **"证据在其因果-条件包络内说可信"**：证据必须携带**干预类型**（do / obs）、**混杂折扣** γ、**有效域** D 与**移植误差** ε_T，地图对本体与时间条件化，生存核必须对整条**信念管**而非点估计成立。

核心矛盾：
- **H26（内生性）**：A34"探针似然诚实"在闭环运动控制下失效。控制器对滑移的补偿动作既是观测的原因又是观测的一部分；把 obs 当 do 融合，会在系统最自信的地方（控制器工作良好处）系统性制造假证据——**控制越成功，测量越失真**。
- **H27（身体绑定）**：通用平台上多本体共图。把四足的证据直接喂给人形/轮足，等于让"足端 2cm² 高压接触"的承载力结论去为"大面积低压接触"背书；朴素池化把第 56 轮的单机坏证据问题放大成**全机队系统性偏差**。
- **H28（时间尺度）**：证据/地图协商在秒级，全身控制/接触在毫秒级。两次证据刷新之间信念会漂移、地形会风化；用点估计生存核去跑快环，等于在一条不断变粗的信念管上取单点样本——分布式假设给不了快环的 soundness。

## 0. 直觉与动机

**灵感 1（运动控制 → 探针即控制，控制即探针）**
直觉：第 56 轮把探询当成检查点上的离散动作（view/tap/shift/revisit），代价高、频率低。但真正的四足/人形每走一步都在产生证据：足端力、关节力矩、腿部里程计滑移残差、IMU 冲击——**每一步都是一次无意识的实验**。若善加利用，探针不必"额外做"，而是"边控边测"。代价是：这些证据全部长在反馈回路里，控制器为稳定而抹平的那部分残差，恰是辨识最需要的信号。于是"探针非破坏"要升级为"**探针可辨识**"：不是不碰，而是碰的方式要能把自己与地形分开（干预、激励、工具变量）。

**灵感 2（运动控制 → 双控制：安全激励是连续版变速箱）**
直觉：想让闭环里的观测变成因果证据，就得有**持续激励（PE）**——输入要在参数敏感的方向上有足够能量。但激励会扰动任务、逼近约束。于是探询变成一个**双控制**问题：`u = u_task + u_exc`，激励项被限制在"仍满足鲁棒生存核 + 力帽 + 跟踪误差上界"的可行集里，最大化 Fisher 信息减去风险与跟踪代价。第 56 轮的"步态变速箱"是离散的（降档买裕度），这里是连续的（花一点跟踪误差买可辨识性）。

**灵感 3（通用机器人平台 → 证据有有效域，移植要付代价）**
直觉：通用平台的价值是"一套安全契约、多种身体"。但这要求把**什么是可移植的**说清楚：μ 更像地形内禀属性（可近似移植），k 与 F_bear 是接触几何/压力的函数（必须按接触力学缩放），而"表面状态/时间"决定证据是否过期。正确做法不是共享一张信念图，而是共享**拓扑×几何**、对**有效域**条件化信念、并用带误差界的**移植算子**在域间搬运。能力格把"这台机器能测什么、测得多准、在什么范围内算数"写成可检查的合同。

**灵感 4（时间尺度分离 → 信念鲁棒管，陈旧性变成管的命中时间）**
直觉：第 56 轮的陈旧半衰期是个启发式。更严谨的说法是：两个证据刷新点之间，参数在漂、估计在涨，可信集 `B(t)` 像管子一样变粗；只要整条管仍落在生存核内，快环就安全；一旦管半径撞到阈值，就必须重探。**陈旧不是"太旧"，而是"管子粗到容不下今天的风险"**。

**灵感 5（综合 → 因果-条件证据门：把第 56 轮最大风险从"长寿"改成"短命"）**
直觉：第 56 轮担心坏证据在地图里长寿并被多访放大。本轮给每条证据打上三重"保质期"：因果有效性（不是 do 或无激励就折价）、有效域（跨本体要过移植误差门）、时间管（漂移超界即失效）。坏证据不再能"诚实放行"，因为它连**被当作证据的资格**都随条件到期。

## 1. 形式化定义（增量：定义 133–140）

**定义 133（结构化证据与干预类型）** 证据记录 `e=(r,type,payload,t,src,φ,mode,D,ver)`，`mode∈{obs,do}`，φ 为本体；结构因果模型 `θ → e=f_φ(θ,u,ξ)`、`u=π_c(o_{≤t})`。干预似然 `L_do(e;θ)=P(e|do(u),θ,φ)`，观测似然 `L_obs(e;θ;π_c)=P(e|π_c,θ,φ)`。**混杂间隙** `γ(e;π_c)=sup_θ |log L_do(e;θ) − log L_obs(e;θ;π_c)|`。只有 `do` 证据、或满足可辨识条件的 `obs` 证据，才可按全权重进入因果结论。

**定义 134（闭环可辨识与持续激励）** 观测证据升格为因果证据需 `(i)` 窗内持续激励 `∃α>0,T: ∫_T ϕ(s)ϕ(s)ᵀ ds ⪰ αI`（ϕ 为对 θ 敏感的特征）；`(ii)` 噪声与回归量不相关，否则用工具变量/两阶段校正。可辨识裕度 `ι(e)`；证据权重 `w(e)=w_base·h(ι(e))·(1−γ(e))`，`h` 单调且 `h(0)=0`。

**定义 135（有效域与移植算子）** `D(e)=(φ, 表面状态 s, 压力/速度工况, 标定版本)`；兼容 `e⊑q ⇔ D(e)` 覆盖查询工况。参数级移植 `T_{φ→φ'}`：`μ'≈μ`（地形内禀，误差 `ε_μ`）；`F_bear'=F_bear·(A'/A)^{β_F}`、`k'=k·(A'/A)^{β_k}`（接触力学缩放），带误差界 `ε_T(e,φ')`。仅当 `ε_T≤ε_Tol` 允许移植，否则挂起并安排重探。

**定义 136（条件证据地图）** `𝓜^φ=(G,{b_{[D]}},prov,ver)`：拓扑/几何全局共享；信念按**有效域等价类** `[D]` 条件化；融合仅在同域/可移植证据间进行。第 56 轮 `𝓜` 是本定义在单一 `φ`、单一 `[D]` 下的特例。

**定义 137（信念鲁棒管与时间尺度证书）** 信念可达集 `B(t)={θ: d_H(θ,post) ≤ r_est(t)}`；漂移界 `|θ(t+Δ)−θ(t)| ≤ ρ_drift·Δ`（概率 `≥1−δ_drift`）；管膨胀 `r(t+Δ)=r(t)+ρ_drift·Δ+ε_est(Δ)`。**鲁棒可行** `viable_R(x,u) ⇔ ∀θ∈B(t): viable_b(x,u,θ)`；不变量 `𝒮_inv ⊆ ∩_{θ∈B(t)} K_B(θ)`。当 `r(t)>θ_tube` 触发重探——**陈旧性 = 管命中时间**。

**定义 138（安全激励 / 双控制）** `u=u_task ⊕ u_exc`，`u_exc∈U_exc(x)={u: viable_R(x,u) ∧ F≤F_abs ∧ ‖track_err‖≤e_max ∧ 窗内 PE}`；目标 `max_{u_exc} [ I(u)−λ_s·risk(u)−λ_t·track_err ]`，`I=½log det(Σ_prior Σ_post^{-1})`（或 Fisher 信息）。第 56 轮的 `δ_f(g)` 变速箱在此是"离散降档"，本定义是"连续花跟踪误差买可辨识性"。

**定义 139（平台能力格与一致性）** 本体 `φ=(DOF, 足端/接触几何, 接触模型参数界, 探针/动作集, 传感)`；能力格 `(Φ,⪯)`。证据契约 `Π(φ)=(可测量集, 有效域, 误差界, 可满足的安全契约)`。新平台上线须过**一致性测试**：关键参数存在 `T` 且 `ε_T≤ε_Tol`、可构造 `U_exc`、鲁棒生存核非空。

**定义 140（因果-条件证据证书 J_c）** `J_c=(𝓜_core,{e(mode,γ,ι,D,T-log)},tube_cert,exc_log,consent_log)`；每个承诺接触须满足：`mode=do` 或（`γ≤γ_max ∧ ι≥ι_min`），部署本体下 `D` 有效，跨本体 `ε_T≤ε_Tol`，且 `r(t)≤θ_tube`；否则拒绝。继承第 56 轮证据门四类（EV-probe/visit/margin/human），但"probe"细分为 `EV-do` 与 `EV-obs`。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 CVE（Causal-Validity Evidence）

```python
def causal_evidence_weight(e, phi, ctrl_model, window):
    if e.mode == 'do':
        gamma = 0.0
    else:
        gamma = confounding_gap(e, ctrl_model)       # obs 与 do 偏差上界
        if gamma > gamma_max: return 0.0             # 不可辨识，弃权
    iota = identifiability_margin(e, window)         # PE / 噪声独立性
    if iota < iota_min:
        e = iv_correct(e)                            # 工具变量/两阶段校正
        iota = identifiability_margin(e, window)
    return e.w_base * h(iota) * (1.0 - gamma)
```

### IP-134 ETL（Embodiment Transport Layer）

```python
def transport_evidence(e, phi_target, M):
    if domain_covers(e.D, phi_target): return e, 0.0
    eps = 0.0
    for p in params(e):
        if p == 'mu':                ep = eps_mu
        elif p in ('F_bear', 'k'):   ep = contact_mechanics_bound(p, e.D, phi_target)
        else:                        ep = INF          # 非可移植参数
        if ep > eps_tol:
            M.quarantine[e.region].hold(e); return None, ep
        eps = max(eps, ep)
    return transported(e, phi_target, eps), eps
```

### IP-136 SEC（Safe Excitation Control / 双控制）

```python
def safe_excitation(x, M, u_task, sigma):
    U = [u for u in excitation_basis
         if robust_viable(x, u_task + u, M.b[x.region])
         and force(u_task + u) <= F_abs
         and track_err(u) <= e_max]
    if not U: return u_task, 'no_excitation'
    u = argmax(U, key=lambda v: info_gain(v, M) - lam_s*risk(v) - lam_t*track_err(v))
    return u_task + u, tag_do(u)                     # 本步证据记为 do 类
```

### IP-135 RBT（Robust Belief Tube）

```python
def robust_belief_tube(M, x, sigma, horizon):
    B = posterior_reachable(M.b[x.region])
    for _ in range(horizon):
        B = inflate(B, rho_drift*dt, eps_est(dt))
        if not robust_viable(x, sigma, B):
            return Infeasible('tube_exceeded'), B
    return TubeCert(B, radius(B)), B

def should_reprobe(M, r, t):
    return tube_radius(M, r, t) > theta_tube[r]
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CVE | O(H_win·d_θ) | O(d_θ) | γ 上界诚实、PE/IV 条件可检 |
| ETL | O(\|D\|·d_p) | O(\|e\|) | 参数量纲正确、ε_T 不低估 |
| RBT | O(T_dyn·N_sc) | O(\|B\|) | 漂移界概率成立、管覆盖真实后验 |
| SEC | O(\|U_exc\|·C_info) | O(\|U_exc\|) | 激励不出不变量、力帽不破 |
| PEC | O(\|Φ\|·\|D\|) | O(\|Π\|) | 一致性与可满足性可检查 |
| CEC | O(\|σ\|·\|e\|) | O(\|σ\|) | 无 do 或 γ/ι/ε_T 超界即拒绝 |

**正确性定理（Causal-Conditioned Commitment Soundness, CCCS）** 在 A22–A36 基础上加 **(A37)** SCM 与控制器已知或可辨识，`γ` 上界诚实；**(A38)** 移植误差界 `ε_T` 诚实；**(A39)** 漂移界 `ρ_drift` 以概率 `1−δ_drift` 成立且管覆盖真实后验；**(A40)** 安全激励始终落在鲁棒不变量内；**(A41)** 用于升格的 obs 证据满足 PE/IV 条件。则：

1. **承诺健全性**：`P_fail ≤ δ_f + ε_cal + γ_max + ε_T + P(漂移越界) + ε_h(w_max)`；
2. **交互/激励单调性**：任何激励、探针或 L1/L2 路径只经有界信念更新或触发更保守动作影响系统，不存在升险路径；
3. **终止性**：PCE 的连续激励版在 `k_probes` 与激励窗预算内终止于 {承诺, 绕行, L2, 安全停}；
4. **部署界**：对检查点取联合界后，额外扣除 `P(tube miss)+P(transport 越界)+P(γ 低估)`。

关键：**观测证据不再自动等价于因果证据**；**证据的资格随身体与时间到期**，因此第 56 轮"坏证据长寿"被结构性缩短为"坏证据短命"。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| "每步皆探针"使非破坏不可保证，激励本身触发失效 | 高 | 激励严格限制在鲁棒不变量内 + 力帽 + 不可逆审计 + 激励预算上限 |
| 黑盒/学习的控制器使 `γ` 不可辨识 | 高 | do 证据优先 + 工具变量 + 无 γ 上界时强制降权/弃权 |
| 移植误差界 `ε_T` 低估，坏证据跨机队泄漏 | 高 | 接触力学缩放 + 上线一致性测试 + 跨本体证据默认限速/重探 |
| 信念管过保守导致活性崩塌（频繁停/重探） | 中 | 管半径按风险分级 + 只在关键参数上做鲁棒 + 保底吞吐实验 |
| PE/IV 在控制频率下计算过重 | 中 | 降采样辨识 + 增量 Fisher + 窗口化批量更新 |

## 6. 本轮最大风险

**一句话**：把安全赌注从"证据质量"再推到"证据的因果-条件有效性"，等于让**每一次运动都成为实验、每一条共享信念都成为超出其出生地的断言**——一旦激励-安全折衷、混杂间隙 γ、移植误差 ε_T 或漂移界 ρ_drift 中任一被低估，系统就会**自动、高频地制造假因果证据并把它扩散到整个本体族**，使第 56 轮的"坏证据长寿"升级为"坏证据量产"；因此必须以 do/obs 分型+IV、有效域+移植误差门、信念管+漂移界、能力格一致性测试四重护栏同时兜底，绝不让激励跑出不变量，绝不让移植跑出误差棒。

## 1. 符号体系增量（定义 133–140）

| 符号 | 含义 |
|---|---|
| `e=(...,φ,mode,D,ver)` | 结构化证据；`mode∈{obs,do}`；φ 本体；D 有效域 |
| `γ(e;π_c)` | 观测证据与干预证据的混杂间隙（对数似然上确界） |
| `ι(e)` | 闭环可辨识裕度（PE/IV/噪声独立性） |
| `w(e)=w_base·h(ι)·(1−γ)` | 证据权重随可辨识升、随混杂降 |
| `D(e)` | 有效域（本体/表面状态/压力速度工况/标定版本） |
| `T_{φ→φ'}, ε_T` | 参数级移植算子与误差界（`F_bear'=F_bear·(A'/A)^{β_F}`） |
| `𝓜^φ=(G,{b_{[D]}},prov,ver)` | 条件证据地图（按有效域等价类条件化） |
| `B(t), r(t), ρ_drift, θ_tube` | 信念可达集/半径/漂移界/重探阈值 |
| `viable_R` | 对 `∀θ∈B(t)` 成立的鲁棒可行 |
| `u_task⊕u_exc, U_exc(x)` | 任务输入与安全激励，及激励可行集 |
| `I(u)` | Fisher/后验信息增益 |
| `Φ,⪯, Π(φ)` | 本体能力格、证据契约 |
| `J_c` | 因果-条件证据证书 |
| `EV-do / EV-obs` | 证据门中 `EV-probe` 的因果细分 |

## 2. 关键算法伪代码

### IP-133 CVE（Causal-Validity Evidence）

```python
def causal_evidence_weight(e, phi, ctrl_model, window):
    if e.mode == 'do':
        gamma = 0.0
    else:
        gamma = confounding_gap(e, ctrl_model)       # obs 与 do 偏差上界
        if gamma > gamma_max: return 0.0             # 不可辨识，弃权
    iota = identifiability_margin(e, window)         # PE / 噪声独立性
    if iota < iota_min:
        e = iv_correct(e)                            # 工具变量/两阶段校正
        iota = identifiability_margin(e, window)
    return e.w_base * h(iota) * (1.0 - gamma)

def confounding_gap(e, ctrl):
    # 用已知/辨识出的 π_c 做反事实重加权，取对数似然 sup 差
    return sup_theta(abs(loglik_do(e, theta) - loglik_obs(e, theta, ctrl)))
```

### IP-134 ETL（Embodiment Transport Layer）

```python
def transport_evidence(e, phi_target, M):
    if domain_covers(e.D, phi_target): return e, 0.0
    eps = 0.0
    for p in params(e):
        if p == 'mu':                ep = eps_mu
        elif p in ('F_bear', 'k'):   ep = contact_mechanics_bound(p, e.D, phi_target)
        else:                        ep = INF          # 非可移植参数
        if ep > eps_tol:
            M.quarantine[e.region].hold(e); return None, ep
        eps = max(eps, ep)
    return transported(e, phi_target, eps), eps

def conformance_test(phi_new, M, spec):
    return (all(has_transport(p, phi_new) and eps_T(p, phi_new) <= spec.eps_tol
                for p in spec.critical_params)
            and constructible(U_exc, phi_new)
            and nonempty(robust_kernel(phi_new, M)))
```

### IP-135 RBT（Robust Belief Tube）

```python
def robust_belief_tube(M, x, sigma, horizon):
    B = posterior_reachable(M.b[x.region])
    for _ in range(horizon):
        B = inflate(B, rho_drift*dt, eps_est(dt))
        if not robust_viable(x, sigma, B):
            return Infeasible('tube_exceeded'), B
    return TubeCert(B, radius(B)), B

def robust_viable(x, sigma, B):
    return all(viable_b(x, sigma, theta) for theta in sample_cover(B))

def should_reprobe(M, r, t):
    return tube_radius(M, r, t) > theta_tube[r]
```

### IP-136 SEC（Safe Excitation Control / 双控制）

```python
def safe_excitation(x, M, u_task, sigma):
    U = [u for u in excitation_basis
         if robust_viable(x, u_task + u, M.b[x.region])
         and force(u_task + u) <= F_abs
         and track_err(u) <= e_max]
    if not U: return u_task, 'no_excitation'
    u = argmax(U, key=lambda v: info_gain(v, M) - lam_s*risk(v) - lam_t*track_err(v))
    return u_task + u, tag_do(u)                     # 本步证据记为 do 类

def info_gain(u, M):
    F = fisher_information(u, M.b[M.region])         # 对关键接触参数
    return 0.5 * log(det(posterior_cov(M) @ F + I))
```

### IP-137 PEC（Portable Evidence Contract）

```python
def evidence_contract(phi):
    return Contract(
        measurable = measured_params(phi),
        domains   = validity_domains(phi),
        errors    = {p: eps_bound(phi, p) for p in measured_params(phi)},

    )
```

### IP-138 CEC（Causal Evidence Certificate）

```python
def causal_conditioned_certificate(sched, log, M, phi, consent_log, tube):
    for c in contacts(sched):
        e = c.evidence
        if e is None: return reject('no_evidence', c)
        if e.mode != 'do' and (e.gamma > gamma_max or e.iota < iota_min):
            return reject('not_causal', c)           # obs 未升格
        if not domain_covers(e.D, phi):
            e2, eps = transport_evidence(e, phi, M)
            if e2 is None or eps > eps_tol: return reject('transport', c)
        if not tube.allows(c.region, t_now): return reject('tube_expired', c)
    if min(x.K_margin for x in sched) < budgets.theta_K: return reject('K_margin')
    if rho_sem(sched, M) < budgets.rho_min:              return reject('rho_sem')
    if semantic_perturbation(M.core) > budgets.Theta_s:  return reject('delta_s')
    if not all(l2.resolved for l2 in consent_log):       return reject('consent_open')
    return ok(J_c(M.core, sched, tube, log, consent_log))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CVE | O(H_win·d_θ) | O(d_θ) | γ 上界诚实、PE/IV 条件可检（A37/A41） |
| ETL | O(\|D\|·d_p) | O(\|e\|) | 量纲正确、ε_T 不低估（A38） |
| RBT | O(T_dyn·N_sc) | O(\|B\|) | 漂移界概率成立、管覆盖后验（A39） |
| SEC | O(\|U_exc\|·C_info) | O(\|U_exc\|) | 激励不出不变量、力帽不破（A40） |
| PEC | O(\|Φ\|·\|D\|) | O(\|Π\|) | 一致性与可满足性可检查 |
| CEC | O(\|σ\|·\|e\|) | O(\|σ\|) | 无 do 或 γ/ι/ε_T/tube 超界即拒绝 |

**正确性定理（Causal-Conditioned Commitment Soundness, CCCS）**
假设 A22–A28（第 53/54 轮）、A29–A36（第 55/56 轮）成立；**(A37)** SCM 与控制器已知或可辨识、`γ` 上界诚实；**(A38)** 移植误差界 `ε_T` 诚实；**(A39)** 漂移界 `ρ_drift` 以概率 `≥1−δ_drift` 成立且管覆盖真实后验；**(A40)** 安全激励始终落在鲁棒不变量内；**(A41)** 升格用的 obs 证据满足 PE/IV 条件。则：

1. **承诺健全性**：`P_fail ≤ δ_f + ε_cal + γ_max + ε_T + P(drift>ρ_drift·Δ) + ε_h(w_max)`；
2. **单调性**：激励/探针/L1/L2 只经有界信念更新或触发更保守动作影响系统，无升险路径；
3. **终止性**：连续激励版 PCE 在 `k_probes` 与激励窗预算内终止于 {承诺, 绕行, L2, 安全停}；
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_cal + γ_max + ε_T + ε_h)
             − P(𝓜 陈旧 > θ_tube 未检出) − P(漂移 > ρ_drift·Δ)
             − P(γ 低估) − P(ε_T 低估) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
```

关键：**obs 证据不再自动等于因果证据**（升格需 PE/IV）；**证据资格随身体与时间到期**（D/ε_T/tube 三重门）；**快环安全性由鲁棒不变量而非点估计保证**。第 56 轮"坏证据长寿"由此被结构性缩短。

## 6. 本轮最大风险

**一句话**：把安全赌注从"证据质量"再推到"证据的因果-条件有效性"，等于让每一次运动都成为实验、每一条共享信念都成为超出其出生地的断言——一旦激励-安全折衷、混杂间隙 γ、移植误差 ε_T 或漂移界 ρ_drift 中任一被低估，系统就会自动、高频地制造假因果证据并扩散到整个本体族，把第 56 轮的"坏证据长寿"升级为"坏证据量产"；必须以 do/obs 分型+IV、有效域+移植误差门、信念管+漂移界、能力格一致性测试四重护栏同时兜底，绝不让激励跑出不变量，绝不让移植跑出误差棒。
