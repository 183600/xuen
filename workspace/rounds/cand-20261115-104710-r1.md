# 第 5 轮（本轮灵感：「因果推理」×「位姿估计」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。InstructGauge 五不变式、CVC-闭环、严格退化链继续继承。
> 本轮纪律：**增量升级 + 严格退化**。因果推理与位姿估计各沿一条轴升级 InstructGauge-WR，任一环节不可用必须能一键退回关联规划器；因果层是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（位姿估计 = 因果变量的带噪测量，而不是「状态真值」）**
直觉：腕部相机/机械臂给出的永远是 `P̂`，而我们真正关心的是「把末端移到 p 会不会让盲区可见、并让后置条件成立」。位姿是因果图里的一个**处理变量（treatment）**，不是终点。把 `P̂` 当真值会犯两类错：(a) **误差变量衰减**——用 `P̂` 回归成功率，会把因果效应估计系统性地拉向 0；(b) 把「看得见」与「看清楚」混为一谈，位姿精度不足时定义 448 里的坐标变换链 `T ∈ SE(3)` 本身就成了混淆源。

**灵感 2（因果推理 = 把「修复成功」从相关升级为可干预效应）**
直觉：InstructGauge-WR 的 CVC 只保证「动作合法且后置漂移在界内」，但**合法 ≠ 有效**。材料反射率、环境光照、工件真实位姿同时在影响「可见性」与「是否成功」——这是典型混淆。该问的是 `P(S | do(a₁..a_j), P̂)`，而不是 `P(S | a₁..a_j, P̂)`。do-算子让我们把「因为挪了位置所以修好」与「因为光照变了所以看起来修好」拆开；只有前者才是可复用、可迁移的知识。

**灵感 3（耦合 = 位姿反馈回路把测量误差放大成因果误判）**
直觉：相机装在机械臂上，位姿既影响观测、又被观测驱动，形成闭环；再叠加动作分块的 K 步开环执行，「我看到的」与「我实际到达的」会沿 K 步累积偏差。于是位姿估计误差不再只是感知问题，而会通过反馈回路转成**内生性（endogeneity）**，让因果效应不可识别。解法不是关掉相机或禁止分块，而是三根结构支柱：**时间展开去环**（把反馈 DAG 按时序展成无环图）、**外生微抖动激励**（dither 充当工具变量）、**只对可识别的块下因果证书**，并叠加**位姿不确定性下界门控**（下界不过阈值就退回单步/关联规划）。

## 1. 研究问题（本轮要回答什么）

- **Q1（测量）**：位姿估计的协方差 `Σ` 如何进入因果效应估计？在什么条件下估计是可识别的，衰减偏差能被校正回来？
- **Q2（识别）**：在材料/光照混淆与机械臂反馈回路共存时，`P(S | do(C))` 能否被识别？需要哪些可观测后门集或前门集，缺失时如何检测并退回？
- **Q3（决策）**：如何用「因果效应 + 位姿不确定性下界」决定是否继续执行整块、在哪个前缀截断，并使收益可量化、可退化、可证伪？

## 2. 四条设计原则（雏形，正式化见产物区定义 468–483）

**P1 因果变量化位姿（Pose-as-Treatment）**
位姿 `P` 一律作为结构化因果模型中的一个处理变量，`P̂` 只是它的带协方差观测。任何用位姿做决策的下游估计都必须携带 `(P̂, Σ)`，禁止只传点估计。这样「位姿精度」直接进入因果效应的可信区间，而不是被默默忽略。

**P2 do-一致的块证书（do-Consistent Chunk Certificate）**
每个块 `C=(a₁…a_K)` 的提交边界不只要复核漂移与接地（第 4 轮 SpatialCert），还要给出**干预语义**下的前缀效应 `ACE_j = P(S | do(a₁..a_j)) − P(S | do(a₁..a_{j-1}))`。若继续执行到 `j` 的因果增量在低位区间内不显著，则按因果收益而非仅按漂移截断。块必须满足「do-一致」：其效应估计对纯观测分布漂移（光照变化等）保持不变，否则拒绝提交。

**P3 位姿不确定性门控（Uncertainty-Gated Commitment）**
把 `Σ` 经 SCM 传播成成功概率区间 `[S_lo, S_hi]`。只有当 `S_lo > τ_do` 且区间宽度可接受时才允许提交整块；`Σ` 过大则强制缩短块长直至 `K=1`。这把第 4 轮的「时空一致性阈值 ε_vis」升级为「因果下界阈值」，且保留了原来的 ε_vis 作为退化路径。

**P4 可识别性守卫（Identifiability Guard）**
在规划前先做结构可识别性检查：后门集是否可观测、反馈回路是否已被时间展开打断、混淆不变性检验（ICP 式）是否通过。任一不通过 ⇒ 不下因果结论，退回 InstructGauge-WR 的关联规划。**宁可不识别，也不要伪因果**——这是本轮的安全底线。

## 3. 与基线的接口（如何退化）

- `Σ` 超过阈值 / 位姿估计不可用 ⇒ 因果门控失效，退回第 4 轮 `ε_vis` 时空一致性路径；
- 后门集不可观测 / 前门不可用 / 可识别性检验失败 ⇒ 退回 InstructGauge-WR 关联规划（CVC 不变）；
- do-证书不可计算（SCM 结构校验失败）⇒ 退回第 3 轮前缀封闭分块 + 漂移截断；
- 因果截断与漂移截断冲突 ⇒ 取**更保守**者（更早截断），保证安全优先；
- 所有增强失效 ⇒ InstructGauge-WR ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「位姿 = 带噪处理变量 + Σ 传播」的口径，把位姿估计误差从被忽略的工程噪声提升为因果结论里的显式可信区间；
2. 一个 **do-一致的前缀因果证书**，把分块截断的依据从「漂移大不大」升级为「继续下去的因果增量是否显著」，同时保留漂移截断作为保守下界；
3. 一个 **反馈回路去环 + 工具变量校正** 的可识别性配方，明确回答「腕部相机在环时因果效应还能不能识别」；
4. 一条完整可证伪路径：E473–E488 覆盖位姿协方差校准、衰减校正、混淆迁移、去环、因果截断、不确定性门控、守卫退化、对抗与 sim-to-real。

## 5. 本轮最大风险

**一句话**：因果结论建立在 SCM 结构假设（无未观测混淆、正性、单调性）之上，而这些假设在真实工件与光照变化下最容易被悄悄违反——一旦结构错了，位姿 `Σ` 再小也只会得到一个「精确的错误」因果效应，而分块会把这个错误沿 K 步放大成已执行的物理动作。

## 2. 形式化定义（要点）

**定义 468（因果位姿 SCM）** `M=(U,V,F)`，`V={P_t,A_t,P̂_t,V_t,L,S}`，结构方程：
```
P_{t+1} = f_P(P_t, A_t, U_P)
V_t     = f_V(P_t, L, U_V)            # 可见性
S       = f_S(V_{1:T}, L, U_S)        # 真实成功，而非漂移代理
```
假设 `F` 在时间展开图 `G_T` 上无环（见定义 470）。

**定义 469（位姿观测模型，带异构协方差）**
```
P̂_t = g(P_t) + ε_t,   ε_t ~ (0, Σ_t),   Cov(ε_t, ε_{t'}) 允许非零
```
`Σ_t` 来自估计器（如 PnP 的协方差 / 位姿回归的头部分歧），必须随 `P̂_t` 一起传递。

**定义 470（时间展开去环）** 以历史 `H_t=(P̂_{≤t}, A_{<t})` 定义策略 `π(A_t | H_t)`。反馈边 `P_t → P̂_t → A_t → P_{t+1}` 在展开图里严格增时，故 `G_T` 无环；`A_t` 的父节点只含 `t` 时刻及之前变量，系统性内生性被时间顺序切断。若同一时刻存在 `A_t ↔ P_t` 同时决定，则用一步延迟或外生 dither `W_t` 打破。

**定义 471（干预块与前缀）**
```
do(C):  删除所有指向 A_{1:K} 的入边，固定 A_{1:K}=C
do(a₁..a_j):  同上，固定到前缀 j
```
块 `C` 的「do-一致」要求：`P(S | do(C), H)` 对仅改变 `L` 边缘分布的观测漂移保持不变。

**定义 472（可识别性条件）**
- 后门：`∃ Z_bd ⊆ 可观测量` 阻断 `P→S` 的所有后门路径，则
  `P(S | do(P=p)) = Σ_{z} P(S | P=p, Z_bd=z) P(z)`。
- 前门：若存在中介 `V` 满足前门判据（`P→V` 无未观测混淆、`V→S` 被 `P` 完全阻断），用前门公式。
- 二者皆不满足 ⇒ `identifiable(M)=False`，触发定义 477 守卫。

**定义 473（误差变量校正估计）** 设 `Cov(W_t, ε_t)=0`（工具变量 `W_t` 与测量误差正交），则
```
β_IV = Cov(W, S) / Cov(W, P̂),   Var(β_IV) 由 delta 法给出
```
在单处理线性近似下，`β_IV` 消除由 `Σ` 引起的衰减；非线性 SCM 用后门校正 + 测量误差的贝叶斯边缘化。

**定义 474（前缀因果效应）**
```
ACE_j = P(S | do(a₁..a_j), H) − P(S | do(a₁..a_{j−1}), H),   j=1..K
```
`ACE_j` 度量「多执行第 j 步」带来的因果增量，而非它与环境的普通相关。

**定义 475（因果块证书）**
```
CausalChunkCert(C) = (j*, ACE_{j*}, [S_lo, S_hi]_{Σ}, identifiable, Z_bd/Z_fd, do_consistent)
```
其中 `[S_lo,S_hi]_{Σ}` 为把 `Σ` 传播进 SCM 后成功概率的区间（定义 476）。

**定义 476（不确定性传播与门控）** 设 `f_S` 关于位姿 Lipschitz 常数为 `L_f`，则
```
|P̂(S|do(C)) − P(S|do(C))| ≤ L_f · (1+‖T‖) · sqrt(λ_max(Σ))
```
取保守下界 `S_lo = P̂(S|do(C)) − 上式`。提交规则：
```
commit full K   iff  identifiable ∧ do_consistent ∧ S_lo > τ_do ∧ (S_hi−S_lo) ≤ κ_id
else truncate   at  j* = max{ j : S_lo(a₁..a_j) > τ_do }  （单调性见引理 66）
else            K = 1（等价第 3 轮逐步执行）
```

**定义 477（可识别性守卫退化）**
```
IDGuard = identifiable(M) ∧ backdoor_observed ∨ frontdoor_valid ∧ invariance_test_pass
IDGuard=False ⇒ 禁用因果截断，退回 InstructGauge-WR 的漂移截断
```

**定义 478（混淆不变性检验）** 在多个环境 `e∈E`（材料/光照分层）上训练候选预测器 `ĥ_e`，若各环境残差分布不可合并（`∃e: E_e[res] ≠ E_{e'}[res]` 超过检验阈值），则该块非 do-一致，拒绝提交（ICP 式可证伪检验）。

## 3. 关键算法骨架

```python
# IP-335 CPG 因果位姿图 + IP-336 EIV 校正
class CausalPoseModel:
    def __init__(self, scm, instrument=None, env_strata=None):
        self.scm = scm                    # 结构方程 f_P, f_V, f_S
        self.instrument = instrument      # 外生 dither / 指令位姿 W
        self.env_strata = env_strata or []

    def correct_effect(self, records):
        """定义 473：工具变量校正位姿测量误差导致的衰减"""
        if self.instrument is None:
            return None                   # 无 IV ⇒ 交回守卫
        W = np.array([r.W for r in records])
        P = np.array([r.P_hat for r in records])
        S = np.array([r.S for r in records])
        num, den = np.cov(W, S)[0, 1], np.cov(W, P)[0, 1]
        if abs(den) < 1e-9:
            return None                   # 弱工具变量 ⇒ 不可识别
        return num / den

    def propagate_uncertainty(self, chunk, Sigma_seq, Lf):
        """定义 476：Σ 传播为成功概率下界"""
        point = self.scm.p_success_do(chunk)
        radius = Lf * (1.0 + chunk.transform_norm) * np.sqrt(
            max(np.linalg.eigvalsh(Sigma_seq[-1])))
        return point - radius, point + radius

# IP-337 干预块证书
def causal_chunk_cert(M, C, H, Sigmas, tau_do, kappa_id, Lf):
    """定义 474–476：逐前缀算 ACE，返回可提交的 j* 与区间"""
    best_j, best_ace, best_lo, best_hi = 0, 0.0, -np.inf, np.inf
    prev = 0.0
    for j in range(1, len(C.actions) + 1):
        post = M.scm.p_success_do(C.actions[:j], H)
        ace  = post - prev
        lo, hi = M.propagate_uncertainty(C.actions[:j], Sigmas, Lf)
        prev = post
        if lo > tau_do:
            best_j, best_ace, best_lo, best_hi = j, ace, lo, hi
        else:
            break                          # 单调性下更长的前缀只会更低
    return CausalChunkCert(
        j_star=best_j, ace=best_ace,
        S_lo=best_lo, S_hi=best_hi,
        identifiable=M.identifiable, do_consistent=M.invariance_ok(C))

# IP-339 可识别性守卫
def id_guard(M, C):
    if not M.identifiable:
        return False
    if M.backdoor_set is None and not M.frontdoor_valid:
        return False
    return M.invariance_test_pass(C)       # 定义 478

# IP-340 主闭环（增强 7C）
def causalgauge_p(M, s, ell=None):
    # 1–3. 继承 InstructGauge-WR：接地 / 假设 / 分块规划
    iota = M.nlib.ground(ell, M.scene, M.ontology) if ell else M.default_iota
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))

    # 4. 位姿处理化：取 (P̂, Σ) 序列
    P_hat, Sigmas = M.wristcam.pose_sequence_with_cov(C.duration())

    # 5. 可识别性守卫（定义 477）——失败即退回关联规划
    if not id_guard(M.cpm, C):
        return instructgauge_wr(M, s, ell)          # 第 4 轮原样

    # 6. 因果块证书（定义 474–476）
    cert = causal_chunk_cert(
        M.cpm, C, H, Sigmas, M.tau_do, M.kappa_id, M.Lf)

    # 7. 门控决策：整块 / 截断 / 单步
    if cert.j_star == len(C.actions) and (cert.S_hi - cert.S_lo) <= M.kappa_id:
        C_exec = C
    elif cert.j_star >= 1:
        C_exec = C.truncate(cert.j_star)
    else:
        C_exec = M.iac.plan_chunk(iota, H, M.tools, 1, M.drift_bound(s))

    # 8. 执行前仍走定义 448 时空一致性 + 定义 449 运动学前缀校验
    if not M.kloop.verify_prefix_closed(C_exec)[0]:
        C_exec = C.truncate(1)

    # 9. 执行（保留第 4 轮实时 TF 验证与提前截断）
    for t, a in enumerate(C_exec.actions):
        if not M.cvc.joint_pre(a) or not still_grounded(iota, M.env):
            break
        M.env.apply(a)
        if not M.ros_cvc.verify_tf_consistency(M.wristcam.latest_tf(), C_exec.psi_post):
            C_exec = C_exec.truncate(t)
            break

    # 10. 证书绑定与发布（CVC_Spec 增加 causal 字段）
    M.ros_cvc.publish_cvc(C_exec.id, len(C_exec.actions), C_exec.actions,
                          C_exec.pre_conditions, C_exec.post_conditions,
                          [cert], causal_fields=cert)
    return C_exec, cert, bind_claims(C_exec, iota, M.tcv.get_receipts())


def CausalGauge_P_round(M, obs, audio, tac, depth, det, ell=None):
    """50Hz 主路径不变；因果推理走异步旁路"""
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            spawn_async(causalgauge_p, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导（含明确假设）

**引理 63（测量误差可识别性）** 设 `Cov(W,ε)=0` 且 `Cov(W,P̂)` 非奇异，则单处理线性 SCM 下 `β_IV = Cov(W,S)/Cov(W,P̂)` 一致估计真实因果系数，且 `β_naive = Cov(P̂,S)/Var(P̂)` 的衰减因子为 `λ = Cov(W,P̂)/Var(P̂) ∈ (0,1]`。证明：把 `P̂=P+ε` 代入，`Cov(W,P̂)=Cov(W,P)`，噪声项由正交性消去；朴素回归的偏差沿 `λ` 收缩。假设：工具变量外生且相关。风险：弱工具变量下方差爆炸。

**引理 64（位姿不确定性传播界）** 若 `f_S` 关于位姿满足 Lipschitz 常数 `L_f`，则 `|P̂(S|do(C)) − P(S|do(C))| ≤ L_f·(1+‖T‖)·sqrt(λ_max(Σ))`。证明：一阶 Taylor + 算子范数；`T` 为定义 448 的坐标变换，放大因子来自 `SE(3)` 链式复合。假设：`Σ` 有界且 `f_S` 局部 Lipschitz。

**引理 65（反馈回路下的可识别性）** 在时间展开图 `G_T` 中，若策略只依赖 `H_t` 且存在外生 dither `W_t`，则 `P(S|do(A_{1:K}=C))` 可识别，当且仅当 `W_t` 对 `A_t` 有非零影响且 `W_t ⟂ U`。证明：展开去环使 `A_t` 的后门路径只剩经 `H_t` 的可观测部分；dither 充当随机化，恢复正性。假设：无同时刻因果。风险：dither 过小则弱识别。

**引理 66（单调截断最优性）** 若 `f_S` 对每个 `a_j` 单调不减，则 `ACE_j ≥ 0` 且 `S_lo(a₁..a_j)` 关于 `j` 单调不增的保守近似下，定义 476 的 `j*` 是满足下界约束的最大安全前缀，按因果收益截断不劣于按漂移截断。证明：单调性保证继续执行不会降低真实成功概率，故最大可行 `j*` 即最优；保守下界只会更早截断。假设：单调性——**这是最易被真实工件违反的假设**。

**引理 67（严格退化等价）** 若 `Σ` 超阈值或 `IDGuard=False`，则 `CausalGauge-P` 的决策与 InstructGauge-WR 完全相同（因果截断被禁用，仅剩 CVC 漂移 + 时空一致性）。证明：分支直接调用 `instructgauge_wr`，其证书字段为空，决策路径与第 4 轮逐行等价。

**引理 68（不变性检验的可证伪性）** 若块 `C` 非 do-一致（存在环境层 `e` 使残差均值偏移超阈），则定义 478 以概率 →1 拒绝提交；若 `C` 为 do-一致，拒绝率为名义显著性水平 `α`。证明：分层两样本检验的标准功效/水平结论。假设：环境分层可由可观测量构造。

## 8. 本轮最大风险

**一句话**：整套因果结论都押在 SCM 结构假设（无未观测混淆、正性、广义单调性）上，而真实材料与光照变化最容易悄悄违反它们——结构一旦错了，位姿 `Σ` 再小也只得到「精确的错误」效应，动作分块会把这个错误沿 K 步放大成已执行的物理动作；因此`IDGuard` 必须默认保守，宁可退回关联规划也不能伪因果。
