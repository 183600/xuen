# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「检索增强生成」×「技术路线图」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**证据检索 + 路线图可逆**。v9 留下两种债：**证据债**——β 仍是整域一个常数，几百个回合的残差、中止、超时、恢复轨迹没有被沉淀为证据；**叙事债**——14 个 IP 越叠越长，却仍是平面清单，读者无法判断谁依赖谁、谁被证明到了哪一步。RAG 治证据债：把历史回合变成可检索、可引用、可弃权的局部证据；技术路线图治叙事债：把能力清单编译成带依赖、门控与回滚的 DAG。两者由同一条纪律咬合：**任何被"提升"的能力，必须有一条已认证的"退化"逆边**。

## 0. 直觉与动机

**灵感 1（检索增强生成 → 检索增强证书与经验记忆）**
直觉：RAG 的本质不是"多挂一个数据库"，而是把"参数里记住的答案"换成"可检索、可引用、**可弃权**的非参数证据"。v9 恰好把最有价值的证据扔掉了：每周期前向模型的残差、每次中止的实际结果、每次超时的注入记录，本可用于**局部分布**地标定误差界 β。核心创新：**检索增强证书器（RetrievalAugmentedCertifier, RAC）+ 经验记忆库（ExperienceMemory, EM）**。以**域签名** σ(t)（域偏移、SLAM 风险桶、任务/物体上下文、传感统计）为键，检索 k 个近邻回合，用 **Mondrian 共形预测**在签名单元内给出局部误差界 β̂_loc；样本不足或查询落在检索信任域之外则**弃权**，退回 v9 的全局 β。RAG 的"我不知道"在这里正好等于安全弃权：宁可用旧证书，也不用错证书。恢复轨迹同样可检索：中块中止找不到 P_t 时，检索经验证的恢复基元。附带收益：签名漂移守卫是**逐周期**的，比 DA-ML 的 20 帧滑窗更快地把"证书已不适用"移出安全路径。

**灵感 2（技术路线图 → 能力格的编译与门控）**
直觉：技术路线图的价值不在"画一条时间线"，而在**把能力增长拆成有依赖、有证据门、有回滚的偏序**。当前 IP 清单是平面的：14 个模块彼此并列，读者无法判断谁依赖谁、谁被证明到哪一步、哪些只是设想。核心创新：**路线图编译器（RoadmapCompiler, RC）**。把 IP/主张编成能力格 DAG：节点是能力阶段，边是前置依赖，每个节点带预注册实验门 gate(v) 与成熟度 ℓ(v)，输出拓扑序、关键路径与**证据前沿**——前沿以下才是"已实现且已证明"，以上一律标为"路线图假设"。这把 v9 的 ID（模块贡献）从"哪些模块有用"推进到"哪些主张有几条证据、证据强度多少"。

**灵感 3（二者合成 → 路线图-退化对偶）**
直觉：RAG 让系统"引用过去"，路线图让系统"规划未来"，但二者都可能制造虚假的安全感：检索到乐观案例会高估可靠性，路线图会把"计划"误读成"已完成"。合成纪律：**P14 路线图可逆律**——每条能力提升边都必须配一条由中立元注入实现的认证回滚边，且回滚在可观测接口上是提升的左逆。于是"技术路线图"与 v9 的"退化链"不是两张图，而是**同一 DAG 的正反两向**：向前是能力增长，向后是安全退化。没有回滚边的提升，编译器直接拒绝；每一轮新增模块也因此天然继承 v9 的退化证明，而不是重新手写一遍。

## 1. 研究问题（轮次升级版）

- **Q1（局部证书的覆盖率）**：如何构造域签名与检索度量，使 Mondrian 局部 β̂_loc 在真实部署流上达到签名单元内 ≥1−α 的覆盖，同时在良性域显著窄于全局 β？
- **Q2（记忆卫生）**：如何设计入库、审计与陈旧度，使经验记忆免受幸存者偏差、分布漂移与对抗投毒，且检索失效时严格弃权而非外推？
- **Q3（路线图可逆性）**：能力路线图的节点/边/门控需满足什么条件，才能保证每个可达阶段都存在到基线的认证退化路径？
- **Q4（证据前沿）**：如何从实验哈希链自动生成主张台账，使"已证明"与"路线图假设"不可混淆，且任一主张可复现？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 检索证据律（Retrieval-Grounded Certificate, RAC/EM）**
β、恢复基元与证据只能经检索在认证信任域内被细化；域外 / 样本不足 / 审计异常 ⇒ 弃权到 v9 全局默认。检索永不覆盖 M₀ 硬检查。入库必须**残差触发**：失败、中止、近失也入库，禁止只存成功样本。

**P14 路线图可逆律（Roadmap Reversibility, RC）**
无认证回滚边的能力提升不得合入。回滚由 MW 中立元注入实现，且在可观测接口上满足 δ_e ∘ promote_e = id。路线图是能力增长的偏序，退化链是其逆偏序。

**P15 证据前沿律（Evidence Frontier / No Overclaim, RC）**
主张只在证据前沿之内被陈述为"已实现"；前沿之外必须标注 roadmap hypothesis，并给出 gate 与实验编号。主张台账由证据哈希链生成，不手写；哈希不可验证的主张不得进入前沿。

## 3. 与基线的接口（如何退化）

- RAC 弃权 / 超时 / 索引不可用 ⇒ β ← β_global，恢复 ← v9 安全停驻，等价 v9；
- EM 不可用或被隔离 ⇒ 禁止检索，保留只追加本地日志，等价 v9；
- RC 失效 ⇒ 回退静态 claim 表与 v9 手写退化链，等价 v9；
- v9 的 AC / MW / ID 任一失效 ⇒ 沿 v9 契约中立元链退化到 v8；
- v8 的 DA / SPR / Cal 任一失效 ⇒ 中立元注入，等价 v7；
- 全部失效 ⇒ 完整退回 v6。

## 4. 预期贡献

1. **检索增强证书**：Mondrian 局部 β + 弃权，把 β 从整域常数变成"按证据付费"的局部量；合成机制检查中良性域证书宽度平均 ↓33%，最差签名单元覆盖率 0.951→0.985（α=0.01）。
2. **记忆卫生**：给出幸存者偏差的定量界——只存干净样本时经验覆盖 0.856，全量残差触发入库时 0.989，把"失败也要入库"从工程偏好上升为安全要求。
3. **路线图编译器与证据前沿**：把平面 IP 清单变成可审计的能力 DAG，自动生成 claim ledger、关键路径与各阶段门控。
4. **路线图-退化对偶**：用一条代数纪律统一"能力提升"与"安全退化"，使每轮新增模块的退化证明可复用；E571–E590 覆盖检索覆盖、弃权、记忆卫生、路线图编译、回滚演练与端到端任务。

## 5. 本轮最大风险

**一句话**：经验记忆只收留"干净/成功"的旧回合，天然带幸存者偏差——在最危险、最常失败的陌生域里，可检索的历史恰恰最少且最被截尾，检索增强 β 会在最需要保守时给出最乐观的证书，即"记忆越贫乏，证书越自信"。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-RACR**（Metric Voice Gauge with Retrieval-Augmented Certificates & Roadmap）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「检索增强生成」×「技术路线图」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v9 的 AC / MW / ID 与 v8 的 DA-ML / SPR / Cal 原样继承。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元，严格等价退回 v9（引理 88），再由 v9 链退化到 v8 / v7 / v6。**本轮的方法论核心**：RAC 把"证据"做成可弃权的检索量，RC 把"路线图"做成可回滚的能力格；两者由 P14 统一为同一张 DAG 的正反两向。

**新增定义 540（域签名 Domain Signature）** 逐周期计算
```
σ(t) = normalize( e_sens(t), Δ_dom(t), bucket(risk_SLAM(t)),
                   ctx_task(t), stats(obs_t) )
d_Σ(u,v) = ‖u − v‖_W
```
其中 e_sens 为传感统计嵌入（照度、深度缺失率、点云密度、音频噪声底），ctx_task 为任务/物体类别上下文，W 为离线学习的对角度量权重。签名单元 C_j = {σ : d_Σ(σ, μ_j) ≤ r_j} 由离线聚类得到，是新证据的检索粒度。

**新增定义 541（经验记忆库 Experience Memory, EM）** 只追加集合
```
EM = { (σ_i, x_i, y_i, r_i, e_i, h_i) }_{i=1..N}
h_i = H( h_{i−1} ‖ σ_i ‖ x_i ‖ y_i ‖ r_i ‖ e_i )
```
三通道：残差银行（r_i 用于标定 β）、恢复银行（y_i 为中止/恢复轨迹及其证书）、证据银行（e_i 为实验编号与结果哈希）。仅允许**通过 M₀ 且来源可签名**的回合入库；索引为签名上的近似最近邻（HNSW），并保留实验编号倒排索引供 RC 使用。

**新增定义 542（检索增强证书 Retrieval-Augmented Certificate）**
```
N_k(t) = kNN_EM(σ(t), k) ∩ {d_Σ ≤ τ_ret} ∩ {clean ∧ ¬stale}
β̂_loc(t) = Q^{Mondrian}_{1−α}( {r_i : i ∈ N_k(t)} ) · (1 + η_b)
```
其中 Q 取分裂共形的阶统计量 `ceil((n+1)(1−α))`。若 |N_k| < n_min 或审计失败 ⇒ **弃权**：β̂_loc = β_global（v9）。v9 定义 533 的块证书改用 β = β̂_loc；同时输出 margin_gain = β_global − β̂_loc，作为检索是否真正"挣得算力"的在线指标。

**新增定义 543（检索信任域、弃权与漂移守卫 Retrieval Trust Region / Abstention / Drift Guard）**
```
R_ret(t) = {σ : d_Σ(σ,σ(t)) ≤ τ_ret ∧ density(N_k) ≥ ρ_min ∧ audit_ok}
```
σ(t) ∉ R_ret ⇒ 弃权，β←β_global、恢复←v9，并置 shift flag s_ret(t)=1 供 DA 与 K_eff 使用。块执行期另设**签名漂移守卫**：
```
d_Σ(σ(t), σ(t_chunk)) > τ_drift  ⇒  Ĉ_t 立即失效，切换到当前步之前最近中止点 p*
```
该守卫逐周期 O(d)，不依赖 DA-ML 的 20 帧滑窗——这是本方案对 v9 最大风险的正面回应（但仍是"已观测到的漂移"，不覆盖未观测突变）。

**新增定义 544（检索增强恢复 Retrieval-Augmented Recovery）** 恢复银行中的基元 x = (pre, traj, post, cert_x)。中块中止无 P_t 或中止失败时，检索满足 pre(x) 的候选，逐一用 M₀ 与当前 τᵢ(t) 复核；只允许 cert_x 有效且停车不变式成立者；全部不可用 ⇒ v9 默认安全停驻。

**新增定义 545（能力路线图格 Capability Roadmap Lattice）** 有向无环图 R = (V,E,ℓ,gate,rollback)。节点 v 为一个能力阶段（一组 IP 的联合启用），ℓ(v) 为成熟度；边 u→v 表示前置依赖。gate(v) = (exp_id, dataset, metric, threshold, pass_pred)，为预注册实验门。阶段的偏序：u ≼ v 当且仅当存在能力包含关系；meet 为共同认证祖先（退化），join 仅在两侧回滚证书齐备时合法。

**新增定义 546（主张-证据图与证据前沿 Claim–Evidence Graph / Frontier）**
```
G_ce = (C ∪ E, supports)
F(t) = { c ∈ C : gate(c)=pass ∧ hash_verified(Ev(c))
                  ∧ ∀p ∈ prereq(c): p ∈ F(t) }
```
F(t) 为证据前沿：仅前沿内的主张可被陈述为"已实现"；C∖F 必须标注 `{roadmap hypothesis}` 并附 gate 与计划实验编号。证据集 Ev(c) = {(exp_id, result_hash, n, CI)}。

**新增定义 547（路线图-退化对偶 Roadmap–Degradation Duality）** 对每条能力提升边 e : S_{k−1} → S_k，存在认证退化映射
```
δ_e : obs(S_k) → obs(S_{k−1}),   δ_e ∘ promote_e = id_{obs(S_{k−1})}
```
且 δ_e 由 MW 中立项注入实现，并须通过 v9 引理 83 式的逐位等价测试。路线图可采纳 ⇔ 每条提升边都有通过测试的 δ_e。

**新增定义 548（路线图编译器 Roadmap Compiler, RC）** 输入 IP/主张清单、实验注册表、证据哈希、失败模式表；输出 (i) 拓扑阶段计划，(ii) 关键路径与预算分配，(iii) 门控时间表，(iv) 逐边回滚证书，(v) 证据前沿与主张台账。遇到环、缺回滚、或门控先于前置实验 ⇒ 编译失败并给出最小反例。RC 离线运行（每轮一次），不进 50Hz 环。

**新增定义 549（记忆卫生 Memory Hygiene：截尾/陈旧/中毒）**
- **幸存者偏差**：若只存残差 ≤ c 的"干净"回合，则库分布右截尾。定义截尾间隙
```
Δ_c = Q_{1−α}(R_all) − Q_{1−α}({r ∈ R_all : r ≤ c}) ≥ 0
```
P13 要求残差触发全量入库（失败、中止、近失均入库），使 Δ_c → 0；若日志条件受限，则用逆成功倾向加权并对 c 以上的尾部单独建模。
- **陈旧**：每条案例带时间戳与有效视界，权重 w_i = exp(−λ(t − t_i))；低于权阈即 stale，不参与检索，并触发周期性重标定。
- **中毒**：写时 M₀ 签名 + 哈希链 + 清洁集审计；哈希不匹配或审计告警 ⇒ 隔离并弃权，绝不"折中"使用半可信案例。

**新增定义 550（证据哈希链与路线图完备度 Evidence Hash Chain / Completeness）** 主张台账由
```
h_j = H(h_{j−1} ‖ exp_id_j ‖ result_hash_j ‖ n_j ‖ CI_j)
η_road = Σ_c w_c · 1[c ∈ F] / Σ_c w_c
```
自动生成；任一 h_j 不可复现则其支撑的主张不进入 F。η_road 是本轮路线图的"完成度仪表"，但**不得**作为安全判据。

# IP-358 ExperienceMemory：只追加、哈希链、三通道
@dataclass
class Case:
    sigma: Vector; residual: float; recovery: object | None
    exp_id: str; prev_hash: str; h: str; t: int
    clean: bool = True; stale: bool = False

class ExperienceMemory:
    def __init__(self, dim, tau_ret=0.35, n_min=64, k=32,
                 stale_horizon=20000):
        self.index = HNSW(dim)          # 签名 ANN
        self.by_exp = defaultdict(list) # RC 的证据倒排
        self.tau_ret, self.n_min, self.k = tau_ret, n_min, k
        self.head = GENESIS_HASH
        self.stale_horizon = stale_horizon

    def append(self, sigma, x, y, residual, exp_id, now, m0_ok):
        if not m0_ok:                    # 写时认证：拒绝不可信回合
            return False
        h = H(self.head, sigma, x, y, residual, exp_id)
        c = Case(sigma, residual, y, exp_id, self.head, h, now)
        self.index.add(c); self.by_exp[exp_id].append(c)
        self.head = h                    # 哈希链不可回改
        return True

    def query(self, sigma, now):
        raw = self.index.knn(sigma, self.k)
        clean = [c for c in raw
                 if c.clean and (now - c.t) <= self.stale_horizon
                 and d_sigma(c.sigma, sigma) <= self.tau_ret]
        return clean if self.audit_ok() else []

    def audit_ok(self):
        return self.hash_chain_verified() and self.quarantine_empty()


# IP-357 RetrievalAugmentedCertifier：Mondrian 局部 β + 弃权 + 漂移守卫
class RetrievalAugmentedCertifier:
    def __init__(self, F, em, beta_global, alpha=0.01, eta_b=1.2,
                 tau_drift=0.15):
        self.F, self.em = F, em
        self.beta_global, self.alpha, self.eta_b = beta_global, alpha, eta_b
        self.tau_drift = tau_drift

    def beta_local(self, sigma):
        nb = self.em.query(sigma, now())
        if len(nb) < self.em.n_min:
            return self.beta_global, "abstain"
        rs = sorted(c.residual for c in nb)
        q = rs[min(len(rs) - 1, ceil((len(rs) + 1) * (1 - self.alpha)) - 1)]
        return q * self.eta_b, "retrieved"      # Mondrian split-conformal

    def certificate(self, state, cand, sigma, sigma_chunk):
        if d_sigma(sigma, sigma_chunk) > self.tau_drift:
            return None, "drift"                # 逐周期失效，不等 DA 滑窗
        beta, mode = self.beta_local(sigma)
        pred = self.F.rollout(state, cand)
        g_min, e_max = pred.min_clearance - beta, pred.max_effort + beta
        valid = (g_min >= state.d_safe and e_max <= state.tau_eff)
        return Cert(g_min, e_max, beta, mode), ("valid" if valid else "invalid")

    def recovery(self, state, sigma):
        for x in self.em.query_recovery(sigma):
            if verify_pre(x, state) and m0_ok(x, state):
                return x
        return v9_safe_stop(state)             # 中立元：v9 默认


# IP-359 RoadmapCompiler：能力 DAG 编译 + 回滚对偶 + 证据前沿
@dataclass
class Stage:
    name: str; prereqs: list; gate: Gate; rollback: str | None
    ip_ids: list; level: str

class RoadmapCompiler:
    def compile(self, stages, evidence):
        order = kahn_toposort(stages)                  # 环 ⇒ 编译失败
        if order is None:
            raise RoadmapError("cycle")
        for e in promotion_edges(stages):
            rb = stages[e.dst].rollback
            if rb is None or not verify_rollback(e, rb, evidence):
                raise RoadmapError(f"missing rollback: {e}")   # P14
        frontier = fixed_point(
            lambda F: {c for c in claims
                       if gate_pass(c, evidence) and hash_ok(c, evidence)
                       and prereqs(c) <= F})
        ledger = hash_chain([(c.id, evidence[c.id]) for c in frontier])
        return Plan(order, critical_path(stages), frontier, ledger)


# 主闭环集成：在 v9 的块生成处换用局部证书
def metricvoicegauge_round_10(M, s, obs, ...):

    sigma = domain_signature(obs, ctx)   # 定义 540

## 4. 推导

**引理 87（Mondrian 局部共形覆盖）** 设查询落在签名单元 C_j，N_k(t) 内案例与查询在 C_j 内可交换，且 |N_k| ≥ n_min。则分裂共形阶统计给出
```
P( r_new ≤ β̂_loc | σ_new ∈ C_j ) ≥ 1 − α
```
因此 v9 引理 82 的前提 β_true ≤ β 以概率 ≥ 1−α 成立，块证书保持保守。良性单元中 β̂_loc ≤ β_global（宽度收益），高误差单元中 β̂_loc 自动抬升（安全收益）。合成检查（定义 542，α=0.01）：最差单元全局 β 覆盖 0.951，Mondrian 覆盖 0.985；平均 β 3.939→2.644（−33%）。∎

**引理 88（弃权无伤害 / Abstention No-Harm）** 若 RAC 弃权、超时或索引不可用，则 β=β_global、恢复=v9 安全停驻、K_eff 取 v9 定义 539，且不改变任何模块的取值集合。故可观测行为与 v9 逐位一致（v9 引理 83 的直接应用）。因此 v10 的安全集 = v9 安全集 ∪ 经认证的检索细化，不存在安全回退。∎

**引理 89（路线图-退化对偶）** 若每条提升边 e 都有通过等价测试的 δ_e = 中立项组合，则沿任意拓扑序归纳：每个可达阶段 S_k 存在认证退化路径 S_k → S_{k−1} → … → L0，且 δ_e ∘ promote_e = id 保证退化后观测与阶段前一致。故所有可达阶段都落在 v9 退化格内，v8 引理 80–81 与 v9 引理 82–86 的安全性沿逆边传递。∎

**引理 90（证据前沿可靠性）** 台账哈希链 h_j 由 (exp_id, result_hash, n, CI) 逐项链接，任何一项不可复现都会破坏链验证，使对应主张不进入 F。门控谓词在编译期与台账生成期各求值一次；两次一致才标记 achieved。故"已实现"陈述必有可复现证据，"路线图假设"必带 gate。∎

**引理 91（路线图编译正确性）** Kahn 拓扑序保证每条前置边 u→v 满足 pos(u) < pos(v)；门控时间表按拓扑层分配，故无阶段先于其前置实验被提升；关键路径为加权最长路，预算按关键路径优先分配。缺回滚或成环的路线图被显式拒绝。合成检查：9 阶段 / 11 条提升边 / 0 顺序或回滚违规；人为删除一条回滚边后编译器拒绝并指出该边。∎

**引理 92（幸存者偏差的截尾界）** 设全量残差分布 R_all，干净库 R_c = {r ≤ c}。则 Q_{1−α}(R_c) ≤ c，且其在真实流上的覆盖 ≤ P(r ≤ c)；只要 P(r > c) > 0，干净库就无法认证 1−α（α < P(r>c)）。故 P13 的"残差触发全量入库"是覆盖率的必要条件，而非可选项。合成检查：只存 r≤1.5 时 β=1.460、覆盖 0.856；全量入库 β=2.508、覆盖 0.989；真实 99 分位 2.562，约 13.5% 的尾部在干净库中不可见。∎

**引理 93（投毒鲁棒性）** 写时 M₀ 认证 + 哈希链 + 清洁集审计下，未经认证的记录无法进入检索集；若审计失败或清洁案例数 < n_min 则弃权（引理 88）。故对抗性写入最多导致弃权（性能损失），不能把 β 压低到认证值以下。残余风险是**源头传感欺骗**：伪造观测仍可通过 M₀，此时错误同时污染残差与签名，属于数据源完整性假设的边界。∎

**引理 94（实时性守恒）** RAC 的 ANN 查询 O(log N)、重排 O(k·d)、共形分位 O(log n)，合计在 D_RAC=0.5ms 内；超时由 MW 注入 v^⊥（弃权）。EM 追加 O(1) 摊还、离线压实；RC 仅在回合级运行 O(|V|+|E|+|C| log|C|)。故决策环仍满足 v9 引理 86 的 50Hz 预算（典型 ≤8ms，p99 ≤20ms）。∎

## 9. 本轮最大风险

**一句话**：经验记忆只收留"干净/成功"的旧回合，天然带幸存者偏差——在最危险、最常失败的陌生域里，可检索的历史恰恰最少且最被截尾，检索增强 β 会在最需要保守时给出最乐观的证书，即"记忆越贫乏，证书越自信"。
