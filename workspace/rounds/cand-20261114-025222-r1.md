# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环第 1 轮；本轮灵感：「点云配准」×「流匹配策略」）

> R70 把 R69 的动作模态 epistemic 升级成世界状态后验 b_t(s)，并用三分解观测模型 p(o|s) = p_flow·p_interact·p_calib 把「行为自洽」「人类回答」「传感器残差」接进贝叶斯滤波。但它留下一个没有被追问的缺口：**b_t(s) 的几何分量究竟从哪来？** p_calib 只修正传感器残差，p_flow 只判断动作像不像策略会做的动作，二者都不提供「我在世界里的位姿是否真的正确」这一度量证据。一辆在重复走廊里自信地走错分叉的车，流似然可以完全正常，标定残差也可以完全正常——**行为自洽与几何正确是两件事**。
>
> 本轮两个灵感正好补上这条「几何之脚」：
> - **点云配准**给出度量级的几何证据，而且它不应被压成一个位姿：对称结构、重复纹理、部分重叠、平面/走廊退化都会让配准产生**多峰后验**；
> - **流匹配策略**给出两件工具：其一，在 SE(3) 流形上做生成式配准，把噪声分布传输到位姿后验（摊还多假设配准）；其二，用同一套速度场生成**条件于位姿假设的动作轨迹**，让几何误差以前向可微的方式传播到动作空间。
>
> 核心命题：**把配准歧义一路传播到动作空间，并且只把「会改变动作」的那部分歧义当作 epistemic；在对称环境下，与任务无关的配准歧义应显式降级为任务 aleatoric（不可约但无害），而不是盲目收紧。** 命名 **ALIGN-RAS**（Amortized Lie-group registration & Interactive Geometric uncertainty Navigation for RAS）。
>
> 一句话定位：R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「世界状态是什么」，R71 问「**我在哪里这件事，错了会不会让我做错；如果会，我该看哪里、怎么动才看得清**」。

## 0. 直觉与动机

**灵感 1（点云配准 → 位姿不是点，是后验）**
直觉：ICP/GICP 一类方法给出的是单个位姿和协方差，但真实场景里「最优解」经常不唯一：两条一模一样的走廊、四个对称的货架、一个只露出一半的物体、一段沿墙方向几乎无约束的几何。此时把多峰后验用高斯近似拍平，均值位姿可能落在两个模态之间——**一个从未存在过的位置**。正确的对象不是 T̂，而是 π(T,C|P,Q)：位姿 × 对应关系的联合后验，以及它在 SE(3) 上的模态结构。

**灵感 2（流匹配策略 → 一个速度场，两条流形）**
直觉：R69/R70 的流匹配用在动作块上；但流匹配本质是「学会把简单分布搬运到复杂分布的速度场」。同一条思路可以同时搬运两样东西：把噪声搬到 **SE(3) 位姿后验**，以及把噪声搬到**条件于该位姿的动作轨迹**。若两股流共享同一个几何编码器/trunk，则动作假设天然继承了位姿假设；采样得到的是成对的 (T^{(j)}, ξ^{(j)})，而不是「先配准再规划」这种把不确定性丢掉两次的串行管线。SE(3) 是李群，必须用测地线插值 T_s = T_0 exp(s·log(T_0^{-1}T_1)) 与切空间速度场，否则直线插值会离开流形，制造假的「旋转不确定」。

**灵感 3（关键转折 → 歧义不是风险，决策相关歧义才是）**
直觉：如果两个位姿假设导致**同一个动作**，那这个歧义对任务完全无害。对称走廊里「以为自己在第 3 个门」还是「第 5 个门」，只要任务只是「沿走廊直行」，两种信念下动作一模一样——此时继续收紧 λ 是纯浪费，去主动扫描也是纯浪费。反过来，在岔路口，两个位姿假设只差 10 cm，却会导致「左转/右转」两个完全不同的动作，这 10 cm 就是致命的。**所以不确定性的正确度量不在状态空间，而在「状态 → 最优动作」的映射像空间里。** 形式化地，用 U_task = E_{T,T'~π}[d_task(a*(T), a*(T'))] 代替 H[b_t] 作为 epistemic 的决策投影。

**灵感 4（退化几何 → 稀疏的各向异性，而不是一个标量 λ）**
直觉：走廊场景中，配准沿走廊方向几乎无信息（信息矩阵最小特征值趋零），沿横向却很清楚。R68–R70 的 λ_floor 是一个标量，一旦触发就**所有方向一起变慢**——既过度保守又没抓对方向。正确做法是把配准信息矩阵的特征子空间投影到任务雅可比上：只有「退化方向 ∩ 任务敏感方向」才需要收紧，其余方向保持原速。这把标量刹车升级成**方向性屏蔽**（directional shielding），是对 R68 保守主义最实质的效率改进。

**灵感 5（主动消歧 → 下一最佳视角是几何版的「问一句」）**
直觉：R69 的问/看/触是信息动作；在几何语境下，最自然的信息动作就是**动一下、换个视角、多扫一遍**。选择依据仍是 VoI：当前配准后验熵减去「扫描后」的期望后验熵。但候选动作必须受运动学可达、时间窗、安全包络约束，而且扫描本身不能把机器人带进更危险的退化区。特别地，若环境对称且任务对称，扫描永远无法消除轨道内的歧义——**此时 VoI 应诚实报零，系统不该假装能问出答案**。

**灵感 6（第三条证据通道 → 循环一致性，以及它的边界）**
直觉：R70 有两条通道——传感器残差 r_res 测「传感器自洽」，流似然 Δa 测「行为自洽」。二者都可能被自洽地骗过。几何提供第三条：**配准—动作循环一致性** e_cyc = d_SE3(T_{t+1}^{reg}, T_t^{reg} ⊗ ΔT_{t→t+1})。你以为自己在哪、你实际怎么动了、下一帧又配到哪，三者必须闭环。重复结构下的「全局错误但局部自洽」可以同时骗过 r_res 和 Δa，却会在「运动前后位姿复合」处留下痕迹。**但必须诚实：如果环境严格对称且运动也落在对称群内，e_cyc 也会自洽——此时不是检测失败，而是该歧义对任务真的无害（灵感 3 的任务商）。** 把「检测不到」与「无需检测」区分开，是本轮理论上的关键自律。

**灵感 7（新攻击面 → 配准证书可以被伪造）**
直觉：一旦几何成为安全证据，攻击者就可以投毒点云：动态物体遮挡制造错误对应、重复结构诱导假模态、对抗点注入把后验推向攻击者选定的位姿、LiDAR 欺骗制造自洽的假扫描。**配准证书只证明「在这批点上自洽」，不证明「在世界里正确」。** 因此几何证据只能是证据集中的一个源，不能单独定案；这与 R69 的 k-源一致纪律、R70 的基线纪律必须叠加，而不是替代。

## 1. 形式化定义（增量：定义 326–343）

**定义 326（ALIGN-RAS 总览）** ALIGN-RAS = (SE3-FM, GRC, GAD, GAP, DGR, NBV†, CAC, BSE†, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R70 定义 277-i）；
(ii) **几何预算硬约束**：单控制周期 SE3-FM 采样 K ≤ 8、N_step ≤ 4、配准总延迟 ≤ 2ms、NBV 扫描 ≤ 1 次且位移/时间窗不越安全包络；
(iii) **几何证据纪律**：配准证据不得单独改写 b_t 的语义分量；必须与至少一个正交证据源（运动学/流似然/标定残差）一致，或 GRC 与共形覆盖率同时通过。

**定义 327（点云几何状态）** 源点云 P_t、目标/地图点云 Q_t，位姿 T ∈ SE(3)，对应关系 C，重叠率 Ω ∈ [0,1]。几何状态 s_geo = (T, C, Ω)，几何后验 π(T,C|P_t,Q_t)。配准不是求 argmax，而是保留完整后验及其模态。

**定义 328（SE(3) 流匹配配准器 SE3-FM）** 基分布 T_0 ~ p_0（宽高斯在恒等附近 + 均匀朝向），数据 T_1 ~ q(T|P,Q)（离线由 ICP/TEASER/位姿图融合或多假设标注给出）。测地路径 T_s = T_0 exp(s·log(T_0^{-1}T_1))，速度 u_θ(T_s,s|P,Q) ∈ T_{T_s}SE(3)。损失 L_SE3 = E‖u_θ(T_s,s|P,Q) − d/ds T_s‖²_{g}（g 为 SE(3) 双不变度量）。采样用流形上的 Heun 积分；K 条样本即摊还后验样本。

**定义 329（配准后验与模态）** 由 K 条样本在 SE(3) 上做测地 k-medoids 聚类，得模态 {m_k}、权重 ŵ_k、Fréchet 均值 T̄_k、李代数协方差 Σ_k。模态熵 H_reg = −Σ ŵ_k log ŵ_k；模态间距 Δ_reg = min_{i≠j} d_SE3(T̄_i,T̄_j)/√(tr Σ_max)。这是 R69 定义 296 的几何实例。

**定义 330（几何配准证书 GRC）** GRC = (Ω, ρ_in, κ, e_cyc, s_sym, ECE_reg)，其中 Ω 重叠率，ρ_in 内点率，κ = λ_min(Λ_reg)/λ_max(Λ_reg) 退化条件数，e_cyc 循环残差，s_sym 对称性得分，ECE_reg 后验校准误差。**Trusted ⇔ Ω≥Ω_min ∧ ρ_in≥ρ_min ∧ κ≥κ_min ∧ e_cyc≤e_max ∧ ECE_reg≤τ_ece。** GRC 不通过时，几何证据降权或失效，系统退回 R70 行为。

**定义 331（配准信息矩阵与退化谱）** 对点到面残差，Λ_reg = Σ_i J_i^T Σ_i^{-1} J_i（6×6）。特征分解 {(λ_i,v_i)}。退化子空间 D_deg = span{v_i : λ_i < τ_deg}。**注意：退化不是「噪声大」，而是「这些方向上的数据根本不约束位姿」。**

**定义 332（几何不确定性四分）** 
- U_sensor = E_{T∼π}[tr Σ_T^{sensor}]：传感器噪声，aleatoric；
- U_corr = I(C; T | P,Q)：对应关系歧义，epistemic 且可约；
- U_geom = Σ_{λ_i<τ_deg} (τ_deg − λ_i)/τ_deg：退化几何造成的不可辨识，epistemic 但**只能靠运动/新视角**约减；
- U_mode = H_reg·g(Δ_reg)：多峰假设歧义，epistemic 且可约（看/动/问）。
四者语义不同，禁止简单加和；分别进入不同通道（定义 336）。

**定义 333（决策相关不确定性）** 设流策略在模态 m_k 下诱导动作分布 p(a|m_k,o)。定义
U_task = E_{m_i,m_j∼ŵ} [ d_task(p(a|m_i,o), p(a|m_j,o)) ]，
其中 d_task 为任务代价度量（如基于代价函数 ℓ 的遗憾差）。等价形式：U_task = I(M; A*|o)，A* 为最优动作。**U_task = 0 ⇔ 任意两个配准模态导出同一动作分布。** 决策相关不确定性是 epistemic 的「任务投影」，而不是状态熵本身。

**定义 334（几何条件动作流 GAP）** 联合速度场 (u_T, u_ξ)，条件编码 z_geo = Enc(P,Q,T_s)，u_ξ(ξ_s,s|z_geo) 生成增广动作 ξ=(a,g)。联合训练损失 L_GAP = L_SE3 + L_FM(ξ) + λ_c·L_couple，其中 L_couple 约束「给定 T 时动作的条件分布」与「边缘动作分布」一致（条件-边缘一致性）。采样得到成对样本 {(T^{(j)},ξ^{(j)})}；ξ 的边缘即几何感知的动作后验，ξ|T 即条件策略。

**定义 335（位姿—动作误差传播）** 令 J_T = ∂ξ/∂T 由 GAP 的 ODE 隐式微分得到。则 Σ_ξ ≈ J_T Σ_T J_T^T + Σ_{ξ|T}。这是把「我在哪不确定」翻译成「我会怎么动不确定」的可计算桥；R70 的抽象 p_flow 在此获得几何锚点。

**定义 336（方向性风险缩放 DGR）** 把标量 λ 升级为算子：Λ_λ = I + λ·P_{D_deg∩D_task}，其中 P 为正交投影，D_task = row(J_T)。速度约束按 Λ_λ 的各向异性范数施加；**当 D_deg∩D_task = {0} 时 λ 不生效**（退化但与任务无关），当退化方向正好是任务敏感方向时恢复为标量全保守。消解成功后给予 resolution bonus，安全侧不弱于 R68–R70。

**定义 337（对称—任务商 STQ）** 设环境对称群 G_s 作用在 SE(3) 与观测上。若任务代价与安全约束在 G_s 下不变（ℓ(ρ(g)a, s)=ℓ(a,g^{-1}s)），则最优动作只依赖轨道 [T]=G_s·T。定义商后验 π_G([T])。**轨道内熵 H(T|[T]) 是任务 aleatoric：不可约、但无害；不应触发收紧，也不应触发无效扫描。** 当任务本身破坏对称（如「去 3 号门」），任务商退化为原始后验，歧义重新变为 epistemic。

**定义 338（下一最佳视角 NBV†）** 候选扫描动作 g_scan（平移/旋转/停留/多视角），VoI(g) = H_reg − E_{y∼p(·|g)}[H_reg']，其中期望后验由 SE3-FM 在预测观测上重采样。g* = argmax_g [VoI(g) − c(g)]，s.t. 运动学可达、时间窗、安全认证、扫描后不进入更差退化区。max[VoI−c] ≤ 0 或歧义在 G_s 轨道内 ⇒ 不扫描，退回 R70。

**定义 339（配准—动作循环一致性 CAC）** e_cyc = d_SE3(T_{t+1}^{reg}, T_t^{reg} ⊗ ΔT_{t→t+1}^{odom/action})。任务投影版本 e_cyc^task = ‖P_{D_task}·log(e_cyc)‖。CAC 作为第三条证据通道，与 R70 的 r_res、Δa 并列；三者构成 (传感器自洽, 行为自洽, 几何-运动自洽) 的正交三角。

**定义 340（几何对抗干扰集 ℰ_GEO）** 动态物体遮挡与错误对应、重复结构陷阱（假模态）、对抗点注入、LiDAR/深度欺骗、退化场景（长走廊/大平面/圆柱）、标定耦合偏置。并入证据集：ℰ_ALIGN = ℰ_BELIEF × ℰ_GEO。

**定义 341（证书 J_ALIGN）** J_ALIGN = (J_BELIEF, GRC, ECE_reg, U_task_before, U_task_after, e_cyc^task, nbv_log_hash, coverage_α, align_ver)。Valid ⇔ Valid(J_BELIEF) ∧ GRC.Trusted ∧ ECE_reg≤τ_ece ∧ 共形覆盖率达标 ∧ 证据纪律满足 ∧ 几何预算未越界。

**定义 342（几何校准门与共形覆盖 MCG-GEO）** 用共形预测给出位姿置信集 C_α(P,Q)，要求 P(T*∈C_α) ≥ 1−α；同时校准模态权重（ECE_reg）。覆盖率不足或 ECE 越界 ⇒ 禁用 U_task 驱动的方向性缩放与 NBV，退回 R70 的纯保守——**不让不可信的后验驱动几何层，正如 R69 不让未校准模态驱动交互**。

**定义 343（预算与自适应 K）** 默认 K=1（GRC 可信且廉价 mode_head 预测 U_task 低）；GRC 报退化/多峰或 ECE 接近阈值时升 K=8；N_step 按退化程度自适应。K 的切换本身消耗预算，必须由 P99 实时约束反推，不允许「歧义时无限采样」。

class SE3FlowMatcher:
    def __init__(self, encoder, velocity_net, N_step=4):
        self.enc, self.v, self.N_step = encoder, velocity_net, N_step

    def sample(self, P, Q, K):
        z = self.enc(P, Q)
        T = sample_base_se3(K)                       # 宽基分布
        for i in range(self.N_step):                 # 流形 Heun 积分
            s  = i / self.N_step
            u  = self.v(T, s, z)                     # 切空间速度
            T  = se3_exp(T, (1.0/self.N_step) * u)   # 测地更新，保持在 SE(3)
        return T, z                                  # K 个位姿假设

# IP-276 GRC：几何配准证书（自洽 ≠ 正确）
def geometric_certificate(T_hat, P, Q, info, cfg):
    omega  = overlap_ratio(T_hat, P, Q)
    rho    = inlier_ratio(T_hat, P, Q)
    lam    = eigvalsh(info)                          # 6 维信息矩阵
    kappa  = lam.min() / lam.max()
    e_cyc  = cycle_residual(T_hat, cfg.T_prev, cfg.dT_odom)
    s_sym  = symmetry_score(T_hat, P, Q)
    return all([omega >= cfg.Omega, rho >= cfg.rho, kappa >= cfg.kappa,
                e_cyc <= cfg.e_max, cfg.ECE_reg <= cfg.tau_ece])

class GeometryConditionedPolicy:
    def __init__(self, se3fm, action_velocity_net, task_jacobian):
        self.fm, self.v_a, self.J = se3fm, action_velocity_net, task_jacobian

    def sample_joint(self, P, Q, o, K):
        T, z = self.fm.sample(P, Q, K)
        xi   = []
        for Tk in T:
            x = randn(D); s = 0.0
            for _ in range(2):
                x = x + 0.5 * self.v_a(x, s, z, Tk, o)
            xi.append(decode(x))
        return T, xi

    def task_uncertainty(self, T, xi, w):
        # 决策相关：比较不同位姿假设诱导的动作分布，而非位姿差本身
        return sum(w[i]*w[j]*task_distance(xi[i], xi[j])
                   for i in range(len(xi)) for j in range(len(xi)))

def choose_scan(T_samples, w, P, Q, budget, c_ras_wm, symmetry_group):
    if ambiguity_within_orbit(T_samples, symmetry_group):   # 轨道内、任务无关
        return None                                          # 诚实报零，不假扫描
    best = None
    for g in scan_candidates(T_samples, P, Q):
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi = entropy(w) - expected_reg_entropy(T_samples, g, P, Q)
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-281 CAC：配准—动作循环一致性（第三条证据通道）
def cycle_consistency(T_now, T_prev, dT_odom, task_proj):
    e = se3_log(se3_inv(T_prev) @ T_now @ se3_inv(dT_odom))
    return norm(task_proj @ e)                            # 只在任务敏感子空间报警

# IP-288 主闭环（继承 BELIEF-RAS，仅把几何层插入观测与风险缩放之间）
def ALIGN_RAS_round(M, obs):
    P, Q = obs.points_src, obs.points_map
    T, z = M.se3fm.sample(P, Q, K=1 if M.fast_gate(z_prev) else 8)
    grc_ok = M.grc(T[0], P, Q, obs.info, M.cfg)
    U, modes, w = M.gad.decompose_geometric(T, z, obs.point_stats)
    # 1) 几何锚定 R70 状态后验（不覆盖语义，只收紧/放松几何分量）
    b_t = M.bse.step_geo(M.b_prev, obs, T, U, grc_ok)
    # 2) 决策相关不确定性：把配准歧义投影到动作
    Tj, xij = M.gap.sample_joint(P, Q, obs, K=len(modes))
    U_task = M.gap.task_uncertainty(Tj, xij, w)
    # 3) 第三条证据：几何-运动循环一致性
    e_cyc = M.cac.cycle_consistency(T[0], M.T_prev, obs.dT_odom, M.task_proj)
    # 4) 校准门：证书不过则几何层失效，退回 R70
    if not grc_ok or not M.mcg_geo.coverage_ok(T, obs):
        return M.belief_ras_round(obs)                    # R70 行为，逐指令不变
    # 5) 只对决策相关歧义且非轨道内者主动消歧
    g = (M.nbv.choose_scan(modes, w, P, Q, M.budget, M.wm, M.G_sym)
         if (U_task > TAU_TASK and e_cyc > TAU_CYC) else None)
    if g is not None:
        y = M.execute_scan(g); P = merge(P, y)
        T, z = M.se3fm.resample(P, Q); U_task = M.gap.reestimate(T, obs)
    # 6) 方向性风险缩放 + 安全认证
    Lam = M.gap.registrations(obs.info, U_task)
    A   = M.ach.propose(obs.x_prime, H=M.vista.H)
    k   = M.c_ras_wm.certified_prefix(A, Lam, M.wm_preds)
    lam = M.efs.risk_scale(...) if U_task <= TAU_TASK else M.lam_floor(U_task)
    mode = M.gap.select_modes(modes, w, U_task, Lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_iii.submit_async(g, grc_ok, U_task, e_cyc, T)
    M.T_prev = T[0]
    return k, lam, mode, U

## 3. 推导

**引理 23（SE3-FM 是配准后验的摊销采样器）** 设真实后验 q(T|P,Q) 在 SE(3) 上绝对连续、速度场类 L-Lipschitz。则流匹配目标的最优解给出与 q 同边缘的传输映射；K 条样本的模态权重 ŵ_k 是后验模态概率的 √(K)-相合估计，误差 O(√(log K / K))。系：**配准不必每次解优化，采样即可得到后验**——这是实时多假设的前提；但样本只能逼近训练分布内的后验，分布外必须由 GRC 拦截。

**引理 24（决策相关不确定性是风险的可乘因子）** 在 A102（任务代价对动作 L_ℓ-Lipschitz、动作对位姿 J_T-Lipschitz）下，任意策略相对后验最优策略的期望遗憾满足
Regret(π) ≤ L_ℓ·( J_T·E‖T−T̄‖ + U_task ) + U_sensor。
且 U_task ≤ J_T²·(U_geom+U_corr+U_mode) 的适当缩放。系：**U_task 把「状态不确定性」与「任务风险」之间的常数因子显式化；对称任务下该因子为零，故 U_mode 再大也不该收紧**。这解释了为什么 R70 的 H[b_t] 会高估风险。

**引理 25（退化方向的条件放大）** 设 Λ_reg 在方向 v 上特征值 λ_v→0，则后验方差在 v 方向 ≥ σ²/λ_v；经 J_T 传播后，动作方差下界 ≥ ‖J_T v‖²·σ²/λ_v。**当 J_T v = 0（任务对该退化方向不敏感）时，动作方差不受影响；当 v 落在任务敏感方向时，方差发散。** 系：方向性屏蔽（定义 336）既不牺牲任务关键方向的安全，又避免了对无关方向的过度保守——这是对 R68 标量 λ 的严格改进。

**引理 26（循环一致性的判别性与对称边界）** 设配准误差 δ_t、里程计/动作模型偏差 b_t，则任务投影循环残差
e_cyc^task = ‖P_task(δ_{t+1} − δ_t + b_t)‖ + O(‖δ‖²)。
- 若 δ 为「恒定全局偏移」（重复结构导致的一致错位），δ_{t+1}=δ_t，则 e_cyc^task ≈ ‖P_task b_t‖：**当运动模型正确时它确实检测不到恒定偏移**；
- 但若该恒定偏移落在 G_s 轨道内且任务不变，则 P_task δ = 0，**检测不到恰好等于无害**（定义 337）；
- 若任务破坏对称（P_task δ ≠ 0），则即使 δ 恒定，e_cyc^task 通过 b_t 或跨帧任务投影暴露。
系：**CAC 的盲区与任务无关性精确重合；它不是万能的真相检测器，而是任务相关的自洽检测器——这比假装全能更可信。**

**定理 20（严格包含链）** 在 A102–A104 下，ALIGN-RAS 的期望风险 ≤ BELIEF-RAS ≤ FLUID-RAS ≤ R68；当 GRC 不可信、U_task ≤ τ_task、歧义在对称轨道内、或几何预算耗尽时，ALIGN 与 BELIEF **逐指令相同**。因此 R68 是「永不交互、永不几何消歧」边界，R70 是「无几何后验」边界，ALIGN 只在决策相关、可消解的几何歧义上买效率，安全侧层层不让步。

**定理 21（方向性安全与无突变）** 若 C-RAS-WM 认证在 Λ_λ 诱导的各向异性范数下通过，则任务关键方向的安全包络不变，非关键方向的速度上限不被 λ 压低；扫描动作 g 经认证且其位移/时间窗在包络内，则交互不引入突变。扫描失败/超时/证书失效时 Λ 单调退化为 R70 的标量保守，控制器连续。

**定理 22（NBV 的贪心近似与诚实报零）** 若最优扫描的 VoI 关于观测集单调子模，则贪心在预算约束下达 (1−1/e) 近似最优；若歧义全在 G_s 轨道内，则任意扫描的 VoI=0，NBV 返回 None，系统不产生无效运动。系：**主动几何消歧不会为了「看起来很主动」而浪费预算**。

## 6. 本轮最大风险

**一句话**：ALIGN-RAS 的全部收益押在「SE(3) 流匹配后验与 GRC 在退化/对称/动态场景下仍然校准」这一前提上——**但几何可以是「自洽却全局错误」的（重复结构 + 动态遮挡 + 对抗点注入可以联合制造一个通过 GRC、循环残差很小、流似然也正常的假位姿），此时 U_task 被低估，系统恰好在最该犹豫的退化方向上自信地动起来；配准证书只证明自洽，不证明正确，这是把「我在哪」交给几何层后无法完全消除的信任债。**

**次级风险与缓解**：
1. **SE(3) 流形实现错误**（插值离开流形、切空间搬运出错）→ 严格测地 exp/log + 双不变度量单元测试 + E323/E324；

4. **对称性误判**（把任务相关歧义当轨道内无害）→ 对称性得分 s_sym 必须由任务侧独立验证 + 默认「不确定即非对称」；
5. **实时预算被 K=8 击穿** → 廉价门控 + 自适应 K + 全歧义路径限一次性预算 + E333。

## 2. 形式化定义（要点版）

**定义 326（总览与三不变式）** ALIGN-RAS 继承 BELIEF-RAS 全部组件，新增 SE3-FM、GRC、GAD、GAP、DGR、NBV†、CAC、STQ。三不变式：(i) 零学习写操作；(ii) 几何预算（K≤8、N_step≤4、配准≤2ms、NBV≤1 次/周期）；(iii) 几何证据不得单独改写语义后验，须与至少一个正交源一致。

**定义 327（点云几何状态）** s_geo = (T, C, Ω)，后验 π(T,C|P,Q)。配准输出后验而非 argmax。

**定义 328（SE3-FM）** 基分布 T_0~p_0，数据 T_1~q(T|P,Q)；测地路径 T_s；切空间速度 u_θ(T_s,s|P,Q)；L_SE3 = E‖u_θ − dT_s/ds‖²_g；流形 Heun 采样。K 样本即摊还后验样本。

**定义 329（配准后验与模态）** 测地 k-medoids 聚类得 {m_k}、ŵ_k、T̄_k、Σ_k；H_reg = −Σŵ_k log ŵ_k；Δ_reg = min_{i≠j} d_SE3(T̄_i,T̄_j)/√(tr Σ_max)。

**定义 330（GRC）** 六元组 (Ω, ρ_in, κ, e_cyc, s_sym, ECE_reg)。Trusted ⇔ Ω≥Ω_min ∧ ρ_in≥ρ_min ∧ κ≥κ_min ∧ e_cyc≤e_max ∧ ECE_reg≤τ_ece。**证书只证明局部自洽，不证明全局正确。**

**定义 331（退化谱）** 对 Λ_reg 特征分解；D_deg = span{v_i: λ_i<τ_deg}。退化 = 数据不约束该方向，而非噪声大。

**定义 332（四分）** U_sensor = E[tr Σ_T^sensor]（aleatoric）；U_corr = I(C;T|P,Q)（epistemic 可约）；U_geom = Σ_{λ_i<τ}(τ−λ_i)/τ（epistemic，仅靠新视角/运动约减）；U_mode = H_reg·g(Δ_reg)（epistemic 可约）。四通道分别进入 SE3-FM 采样、NBV、DGR、GAP，不做算术相加。

**定义 333（决策相关不确定性）** U_task = E_{m_i,m_j∼ŵ}[d_task(p(a|m_i,o),p(a|m_j,o))] = I(M;A*|o)。U_task=0 ⇔ 任意两模态导出同一动作分布。它是 epistemic 的任务投影，替代 R70 的 H[b_t] 作为风险缩放输入。

**定义 334（GAP）** 联合速度场 (u_T,u_ξ)，z_geo = Enc(P,Q,T_s)；L_GAP = L_SE3 + L_FM(ξ) + λ_c L_couple。采样得 {(T^{(j)},ξ^{(j)})}；ξ 边缘为几何感知动作后验，ξ|T 为条件策略。

**定义 335（误差传播）** J_T = ∂ξ/∂T（GAP ODE 隐式微分）；Σ_ξ ≈ J_T Σ_T J_T^T + Σ_{ξ|T}。把位姿后验翻译为动作后验，替换 R70 未锚定的 p_flow。

**定义 336（DGR）** Λ_λ = I + λ·P_{D_deg∩D_task}；速度约束按各向异性范数施加。D_deg∩D_task={0} 时 λ 不生效；退化方向命中任务敏感方向时恢复标量全保守。消解成功给 resolution bonus。

**定义 337（STQ）** 若任务代价与安全约束在 G_s 下不变，最优动作只依赖轨道 [T]；轨道内熵 H(T|[T]) 为任务 aleatoric（不可约但无害），不触发收紧、不触发扫描。任务破坏对称时商退化，歧义重新 epistemic。

**定义 338（NBV†）** VoI(g)=H_reg−E[H_reg']；g*=argmax[VoI−c]，s.t. 可达/时间窗/安全认证/不进入更差退化区。轨道内歧义 ⇒ VoI=0 ⇒ 不扫描。

**定义 339（CAC）** e_cyc = d_SE3(T_{t+1}^{reg}, T_t^{reg}⊗ΔT^{odom/action})；e_cyc^task = ‖P_{D_task} log(e_cyc)‖。与 r_res、Δa 构成三角证据。

**定义 340（ℰ_GEO）** 动态遮挡/错误对应、重复结构陷阱、对抗点注入、LiDAR/深度欺骗、退化场景、标定耦合偏置。ℰ_ALIGN = ℰ_BELIEF × ℰ_GEO。

**定义 341（J_ALIGN）** 见符号表；Valid ⇔ J_BELIEF 有效 ∧ GRC.Trusted ∧ ECE_reg≤τ ∧ 共形覆盖达标 ∧ 证据纪律 ∧ 预算未越界。

**定义 342（MCG-GEO）** 共形置信集 C_α 满足 P(T*∈C_α)≥1−α；ECE_reg 校准模态权重。任一越界 ⇒ 禁用 U_task 驱动的 DGR/NBV，退回 R70。

**定义 343（预算与自适应 K）** 默认 K=1；GRC 报退化/多峰或 ECE_reg 接近阈值时 K=8；N_step 自适应；切换成本计入 P99。

# IP-275 SE3-FM：测地流匹配配准（摊还多假设后验）
class SE3FlowMatcher:
    def __init__(self, encoder, velocity_net, N_step=4):
        self.enc, self.v, self.N_step = encoder, velocity_net, N_step

    def sample(self, P, Q, K):
        z = self.enc(P, Q)
        T = sample_base_se3(K)
        for i in range(self.N_step):
            s = i / self.N_step
            u = self.v(T, s, z)                       # 切空间速度
            T = se3_exp(T, (1.0 / self.N_step) * u)   # 保持流形
        return T, z

    def log_likelihood(self, T, P, Q):                # 可选：行为侧第二意见
        z = self.enc(P, Q)
        return -hutchinson_divergence_se3(self.v, T, z)

# IP-276 GRC：六元几何证书
def geometric_certificate(T_hat, P, Q, info, prev, odom, cfg):
    omega = overlap_ratio(T_hat, P, Q)
    rho   = inlier_ratio(T_hat, P, Q)
    lam   = eigvalsh(info)
    kappa = lam.min() / max(lam.max(), 1e-9)
    e_cyc = se3_distance(T_hat, compose(prev, odom))
    s_sym = symmetry_score(T_hat, P, Q)
    trusted = (omega >= cfg.Omega and rho >= cfg.rho
               and kappa >= cfg.kappa and e_cyc <= cfg.e_max
               and cfg.ECE_reg <= cfg.tau_ece)
    return dict(omega=omega, rho=rho, kappa=kappa, e_cyc=e_cyc,
                s_sym=s_sym, trusted=trusted)

# IP-277 GAD：四通道分解
def decompose_geometric(T_samples, z, stats):
    modes  = geodesic_kmedoids(T_samples, k=auto_k(T_samples))
    w      = mode_weights(modes)
    U_sens = mean([trace(sensor_cov(m)) for m in modes])
    U_corr = correspondence_mi(modes, stats)
    U_geom = sum(max(0.0, stats.tau_deg - l) / stats.tau_deg
                 for l in stats.eigvals if l < stats.tau_deg)
    U_mode = entropy(w) * sep_factor(modes)
    return dict(U_sens=U_sens, U_corr=U_corr, U_geom=U_geom, U_mode=U_mode), modes, w

# IP-278 / IP-279 GAP + DGR
class GeometryConditionedPolicy:
    def __init__(self, se3fm, action_net, task_jac, lam_floor):
        self.fm, self.va, self.J, self.lam_floor = se3fm, action_net, task_jac, lam_floor

    def sample_joint(self, P, Q, o, K):
        T, z = self.fm.sample(P, Q, K)
        xi = [self._rollout(z, Tk, o) for Tk in T]
        return T, xi

    def _rollout(self, z, Tk, o, steps=2):
        x = randn(D); s = 0.0
        for _ in range(steps):
            x = x + (1.0 / steps) * self.va(x, s, z, Tk, o)
        return decode(x)

    def task_uncertainty(self, T, xi, w):
        return sum(w[i] * w[j] * task_distance(xi[i], xi[j])
                   for i in range(len(xi)) for j in range(len(xi)))

    def risk_operator(self, info, U_task):
        lam = eigvalsh(info)
        D_deg = degenerate_subspace(lam)
        crit = project(D_deg, rowspace(self.J))       # 只取任务敏感退化
        return identity() + self.lam_floor(U_task) * crit

# IP-280 NBV†：对称感知扫描
def choose_scan(T_samples, w, P, Q, budget, wm, G_sym):
    if ambiguity_within_orbit(T_samples, G_sym):
        return None                                   # 诚实报零
    best = None
    for g in scan_candidates(T_samples, P, Q):
        if not budget.allow(g) or not wm.certify_info(g):
            continue
        voi = entropy(w) - expected_reg_entropy(T_samples, g, P, Q)
        score = voi - cost(g)
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None

# IP-281 CAC：任务投影循环一致性
def cycle_consistency(T_now, T_prev, dT_odom, task_proj):
    e = se3_log(se3_inv(T_prev) @ T_now @ se3_inv(dT_odom))
    return norm(task_proj @ e)

## 4. 推导

**假设 A102–A104**
- A102（任务光滑性）：任务代价 ℓ(a,s) 对 a 为 L_ℓ-Lipschitz；动作对位姿的雅可比 J_T 有界，且可由 GAP ODE 隐式微分估计。
- A103（生成后验可学）：配准后验 q(T|P,Q) 绝对连续，速度场 L-Lipschitz；训练覆盖部署分布。
- A104（对称可判）：G_s 可由几何/语义先验估计，任务不变性可由独立的任务侧检查验证。

**引理 23（SE3-FM 的摊销后验一致性）** 在 A103 下，流匹配最优速度场诱导的样本分布与 q(T|P,Q) 的边缘一致；K 样本的模态权重估计误差 O(√(log K/K))。系：实时多假设配准可由采样完成，但只能在训练分布内；OOD 必须由 GRC 与共形覆盖拦截。

**引理 24（决策相关不确定性的遗憾界）** 在 A102 下，任意策略相对后验最优策略的遗憾满足
Regret(π) ≤ L_ℓ·(J_T·E‖T−T̄‖ + U_task) + U_sensor。
且 U_task ≤ J_T²·κ_task·(U_geom+U_corr+U_mode)。系：**H[b_t] 与风险之间差的正是任务投影因子；对称任务该因子为零，故 R70 的保守在此可安全解除。**

**引理 25（退化方向的条件放大）** 若 Λ_reg v = λ_v v 且 λ_v→0，则后验方差在 v 方向 ≥ σ²/λ_v；传播到动作的方差下界 ≥ ‖J_T v‖²σ²/λ_v。若 J_T v=0，动作方差不受影响。系：DGR 的方向性屏蔽在任务关键方向保持与标量 λ 同等安全，在无关方向严格更高效。

**引理 26（CAC 的判别性与对称盲区）** 设配准误差 δ_t、运动偏差 b_t，则
e_cyc^task = ‖P_task(δ_{t+1}−δ_t+b_t)‖ + O(‖δ‖²)。
恒定全局偏移（δ_{t+1}=δ_t）在运动模型正确时 e_cyc^task≈0；但若该偏移在 G_s 轨道内且任务不变，则 P_taskδ=0，检测不到恰等于无害；若任务破坏对称，则跨帧任务投影或 b_t 暴露之。系：CAC 的盲区与「任务无关」精确重合，不是全能真相检测器。

**定理 20（严格包含链）** 在 A102–A104 下：
Risk(ALIGN) ≤ Risk(BELIEF) ≤ Risk(FLUID) ≤ Risk(R68)。
当 GRC 不可信、U_task≤τ_task、歧义在 G_s 轨道内、或几何预算耗尽时，ALIGN 与 BELIEF 逐指令相同。R68 是「永不交互、永不几何消歧」边界，R70 是「无几何后验」边界；ALIGN 只在决策相关、可消解的几何歧义上获得效率，安全侧不让步。

**定理 21（方向性安全与无突变）** 若 C-RAS-WM 在 Λ_λ 的各向异性范数下认证通过，则任务关键方向的安全包络不变，非关键方向速度不被无关退化压低；扫描动作经认证且在时间/位移包络内，则不引入突变。证书失效/超时/投毒时 Λ 单调退化为 R70 的标量保守，控制器连续。

**定理 22（NBV 近似最优与诚实报零）** 若扫描 VoI 对观测集单调子模，则预算约束下贪心达 (1−1/e) 近似最优；若歧义全在 G_s 轨道内，任意扫描 VoI=0，NBV 返回 None。系：主动几何消歧不会为「显得主动」而浪费运动预算。

**定理 23（原型工程一致性）** RAS-Baselines v2 / Proto-Val v2 全项通过 ⇒ 部署环境 P99<3.5ms、零几何诱发违规、共形覆盖率偏差<4%、ECE_reg<0.05、非对称静默错位 AUC≥0.9、端到端 Pareto 优于 R68/R70。A102–A104 的光滑性/可学性/可判性在原型上可测，而非仅存于证明。

| E341 成本—收益 | 扫描预算拐点 | 给出 VoI/成本曲线与最优扫描频率 |
| E342 机理验证 | 大 H[b_t] 但 U_task=0 | 构造用例，验证零收紧、零误扫 |

## 7. 本轮最大风险

**一句话**：ALIGN-RAS 的全部收益押在「SE(3) 流匹配后验与 GRC 在退化/对称/动态场景下仍然校准」这一前提上——**但几何可以是「自洽却全局错误」的（重复结构 + 动态遮挡 + 对抗点注入可以联合制造一个通过 GRC、循环残差很小、流似然也正常的假位姿），此时 U_task 被低估，系统恰好在最该犹豫的退化方向上自信地动起来；配准证书只证明自洽，不证明正确，这是把「我在哪」交给几何层后无法完全消除的信任债。**
