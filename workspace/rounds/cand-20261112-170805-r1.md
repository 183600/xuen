# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「意图理解」×「商业模式」）

> 第 60 轮把执行接地层升级为「认知驱动的场景—执行闭环」SGEC：SSM 场景先验提前收敛 K_safe、CIEC 锁定实时约束、EPIR 保证据链、SERC 统一闭环、PCE++++ 四维认知预算。但从「意图理解」与「商业模式」两个视角看，仍有**三个根本缺口**：
> 1. **CIEC 只是「指令查表」，不是意图理解**：`'slow_down' → {v_max:0.1, ...}` 把语言当成确定标签，无法处理歧义（「轻一点」到底多轻？）、组合意图（「快但别碰坏」）、隐含目标（用户真正想要的是「把杯子放稳」而不是「移动机械臂」），也没有意图置信度与「该不该追问」的机制。
> 2. **预算没有「价值」信号**：PCE++++ 把算力当成封闭配额平均分配，却回答不了「为什么把这一拍给场景识别而不是意图澄清」。缺少一个统一的经济度量，使「哪个模块的边际信息更值钱」无法比较。
> 3. **真实部署是「机器人即服务 RaaS」，不是实验室单任务**：任务有价格、时延 SLA、质量 SLA、违约赔付与声誉资产。意图误解不只是安全问题，更是**交付了错误的契约**——即使机械执行成功，也构成违约；反过来，经济压力可能诱导系统「选择更便宜的错误解释」或「为保声誉拒接难单」，这是第 60 轮完全没有建模的**对齐风险**。

## 0. 直觉与动机

**灵感 1（意图理解 → 逆规划意图后验 IUM）**
直觉：用户说的不是「指令」，而是「他心里目标的一个证据」。一个理性的人会选择「能让听者做出正确行为」的说法，因此可以用**理性说话人模型**反推：什么目标/偏好最可能让这句话被说出来？把意图从离散标签升级为 `(目标 g, 偏好 θ, 知识状态 κ)` 的联合后验，每对 `(g,θ)` 都诱导一个约束集，于是「理解意图」=「得到约束集上的后验分布」。关键洞见：**歧义不是噪声，而是后验的熵；理解的质量应由 Bayes 风险而非分类准确率衡量**。

**灵感 2（商业模式 → 能力诚实服务契约 CSC）**
直觉：机器人不是「执行器」，而是「承包商」。任务是一份合同：多快交付（D）、多好（q）、多少钱（p）、违约赔多少（λ）、最多赔到多少（R_cap）。意图不确定 ⇒ 成功概率与成本都不确定 ⇒ 报价与接单必须基于**风险调整后的期望利润**。关键洞见：**不能承诺证书背不起的事**——`q ≤ q_max(cert), D ≥ τ_min(cert)` 是「能力诚实」硬约束，否则商业模式会奖励过度承诺，最终以灾难性违约收场。

**灵感 3（澄清的经济学 EIC）**
直觉：问一句「您是要我轻放还是快点？」有成本（时延、打扰、暴露不确定），但能避免一次昂贵的错误交付。于是「说 vs 做 vs 摸一下探测 vs 拒单」应放在同一个期望效用下比较。关键洞见：**安全是字典序的、不能货币化**——当后验中任一质量 ≥1−α 的解释会超力限时，只能澄清/探测/降级，绝不能用「这样更便宜」为理由直接执行。

**灵感 4（意图鲁棒约束编译 IRCC）**
直觉：既然意图是分布，就不该为单个 `(g,θ)` 编译一个 K，而应为「后验质量 1−α 的所有解释」编译一个都安全的 K。歧义因此有了**价格**：`Δ_amb = cost(K_robust) − cost(K_nominal)`；若这个价格超过合同毛利，理性选择是澄清或拒单，而不是硬做。关键洞见：**IRCC 把「模态」从几何/参数不确定性推广到语义歧义**，两者共用「覆盖 1−α 质量」的鲁棒结构。

**灵感 5（声誉—定价 RPC）**
直觉：声誉是长期资产：今天低价接一个难单可能赚口碑，今天为高毛利冒险可能赔掉未来所有订单。把声誉建成可学习状态，价格 = 基础价 + 声誉溢价 − 风险折价，并加一条「**不破产约束**」——不能让一次赔付把声誉或风险资本打穿。这与公司金融里的 risk-of-ruin 同构：生意可以少赚，不能把本金赔光。

**灵感 6（内部市场 CBA）**
直觉：算力预算应该给「边际价值最高」的模块。让场景、意图、ROS、位姿、探测、澄清各模块提交「边际 VOI / 单位预算」的出价，用一个**内部 VCG 拍卖**分配预算，出清价就是预算的影子价格。关键洞见：**可交易的是算力，不可交易的是安全资本**——`B_trust` 与 `B_capital` 是监管资本式的储备，任何模块都不能竞价夺走。

**灵感 7（合流 → 契约化意图—服务闭环 EISL）**
直觉：把上述串成闭环：**感知 → 意图后验 → 报价/签约 → 澄清/探测/执行/拒单 → 证书化执行 → 结算 → 声誉与定价更新 → 内部预算再配置**。这是对第 60 轮 SERC 的升级：从「场景→意图→约束→阻抗」扩展为「场景 × 语言 × 经济契约 → 约束 → 阻抗 → 结算 → 长期声誉」。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（逆规划意图后验 IUM）** 潜在意图 `ι = (g, θ, κ)`，其中 `g ∈ G` 为目标，`θ ∈ Θ` 为偏好权重（速度/轻柔/成本/风险），`κ` 为对话者的知识状态；上下文 `x = (z_scene, 历史, 角色)`。理性说话人似然
```
P(u | g, θ, x) = exp(β·Q_h(u; g, θ, x)) / Σ_{u'∈U(x)} exp(β·Q_h(u'; g, θ, x))
```
其中 `Q_h(u;·)` 是「若机器人把 u 理解为此意图，人类获得的期望效用」。后验
```
b(g, θ) ∝ P(u | g, θ, x) · P(g, θ | x)
```
**歧义度量**：`A(b) = H(g|b) + λ_θ·H(θ|b)`；**理解风险**：`R*(b) = min_a E_{b}[ℓ(a, g, θ)]`，`ℓ` 为「执行约束与真实偏好不匹配」的代价。**语义约束映射** `C(g,θ) = (v_max, F_max, K_p, K_d, ε_traj, q_task)` 取代第 60 轮 CIEC 的固定查表；于是「意图理解」输出的是**约束集上的后验** `q(C) = ∫ 1[C(g,θ)=C] db`。**可信解释集** `S_{1−α}(b)` 是质量 ≥ 1−α 的最小约束集。

**定义 162（能力诚实服务契约 CSC）** 契约
```
C = (T, D, q, p, λ_pen, R_cap)
```
`T` 任务规格，`D` 交付期限，`q` 质量目标（如最大接触力、放置容差、成功率），`p` 价格，`λ_pen` 违约罚率，`R_cap` 赔付上限。执行策略 `π` 诱导完成时间 `τ(π)`、质量 `q(π)`、风险 `ρ(π)`、成本 `c(π)`。期望利润
```
Π(C, π) = p·P(success; π) − c(π) − λ_pen·E[(τ(π) − D)⁺] − risk_premium(ρ(π), R_cap)
```
**可接受性**：存在 `π` 使
```
J_exec ∧ J_pose ∧ J_intent 有效，P(success) ≥ q，CVaR_α(ρ) ≤ R_cap，Π(C,π) ≥ r_reserve
```
**能力诚实约束**（硬约束，不可被利润突破）：`q ≤ q_max(cert)` 且 `D ≥ τ_min(cert)`，其中 `q_max/τ_min` 由有效证书反推。**服务菜单** `M = {(C_i, p_i)}` 需满足激励相容（IC）：每种客户偏好类型自愿选择为其设计的契约；以及个体理性（IR）：客户与机器人双方保留效用 ≥ 0。

**定义 163（经济化意图澄清 EIC）** 动作集 `A = {ACT, ASK, PROBE, DECLINE}`。对动作 `a`：
```
U(a) = E[Π | a] − c_action(a) − λ_h·HumanBurden(a)
```
**澄清的净信息价值**
```
VOI_econ(ASK) = E_{o~P(·|ASK)}[ max_{a'} U(a' | b') ] − max_{a'} U(a' | b) − c_ask
```
`PROBE` 用接触/观察作为「物理澄清」，其 `VOI_econ` 用 Fisher 信息折算的经济收益替代语言回答。决策规则（见定义 169）：
```
若 ∃ 质量 ≥1−α 的解释使 risk > W_max  → 只能 {ASK, PROBE, DECLINE}
若 τ_response + τ_clarify > D         → 只能 {ACT_conservative, DECLINE}
其余                                 → {ACT, ASK, PROBE, DECLINE}
选择 argmax_a U(a)，且 VOI_econ ≤ 0 时不澄清
```

**定义 164（意图鲁棒约束编译 IRCC）** 由 `b` 诱导约束后验 `q(C)`。鲁棒编译
```
K* = argmin_K  E_{q}[ cost(K; C) ]
     s.t.      ∀S ⊆ supp(q), q(S) ≥ 1−α :  ∀C ∈ S, risk(K, C) ≤ W_max
               K ⪰ k_min I
```
即「对后验质量 1−α 的最坏解释都安全」。**歧义价格**
```
Δ_amb = E_q[cost(K*; C)] − E_q[cost(K_nominal; C)]
```
若 `Δ_amb > margin(C)`（合同毛利不足以覆盖鲁棒化成本），触发澄清/探测/拒单。单峰且集中时退化为普通名义编译；多峰时等价于在**语义模态**上做 CVaR，只是模态来自语言歧义而非几何对称性。

**定义 165（契约化意图—服务闭环 EISL）** 算子 `EISL(M, task, u, budget)`：
```
① Perceive:  z ← SSM.update(telemetry); x ← context
② Understand: b ← IUM.posterior(u, x, z)
③ Quote:      C ← CSC.quote(task, b); if not CSC.acceptable(C): return DECLINE
④ Clarify:    a ← EIC.decide(b, C, budget)
              if a = ASK:    b ← IUM.update(b, human_answer);      goto ③
              if a = PROBE:  b ← IUM.update_physical(b, probe_ev); goto ③
              if a = DECLINE:return DECLINE(reason)
⑤ Compile:    K*, Δ_amb, S ← IRCC.compile(b, C, α)
              if Δ_amb > margin(C): budget.clarify += 1; goto ④
⑥ Certify:    J_intent ← build_intent_cert(b, S, K*, C)
              if not (J_intent ∧ J_exec ∧ J_pose).valid: return DEGRADE_SAFE
⑦ Execute:    telemetry ← dispatch(K*); EV_exec ← build_exec_evidence(...)
⑧ Settle:     outcome ← settle(C, EV_exec)      # 成功/质量/时延/赔付
⑨ Learn:      b_prior ← update_prior(b, outcome); M.reputation.update(outcome)
              M.pricing.update(outcome); CBA.reallocate(M.budget, module_bids)
⑩ Return:     (C, K*, J_intent, outcome, M.reputation.r, budget.snapshot())
```

**定义 166（声誉—定价耦合 RPC）** 声誉 `r_t ∈ [0,1]`（或 Beta 分布），更新
```
r_{t+1} = clip( r_t + η·(s_t − ŝ_t), 0, 1 )
```
`s_t ∈ {0,1}` 为本次交付是否达标，`ŝ_t` 为预期。定价
```
p_t = p_base + μ·r_t − ν·RiskPremium(C_t) − ζ·CVaR_α(ρ_t)
```
长期目标
```
max_{π_0,π_1,…} E[ Σ_t γ^t ( Π(C_t, π_t) − ρ_risk·CVaR_α(ρ_t) ) ]
s.t.  每次接受的契约均可证书化；P(r_{t+1} < r_min) ≤ δ   （不破产约束）
```
**关键**：拒单不是失败，而是保护声誉资本的合法动作；但需要「拒单审计」防止为刷声誉而挑肥拣瘦（见 §5）。

**定义 167（经济化预算 B_econ 与内部市场 CBA）**
```
B_econ = (B_scene, B_intent, B_ros, B_exec, B_pose, B_probe, B_trust, B_capital)
B_trust   = r − r_min          # 声誉安全边际（不可交易）
B_capital = R_cap − CVaR_α(ρ)  # 风险资本余量（不可交易）
```
**可交易预算** `B_trade = (B_scene, B_intent, B_ros, B_exec, B_pose, B_probe)` 由内部市场分配。模块 `i` 提交边际估值曲线 `b_i(Δ_i) = ∂VOI_i/∂Δ_i`。分配
```
Δ* = argmax_{Δ} Σ_i VOI_i(Δ_i)
     s.t.  Σ_i Δ_i ≤ B_trade,   Δ_i ≥ Δ_i^min（安全关键模块的保留配额）
```
对偶变量 `λ*` 是预算的影子价格；`b_i ≥ λ*` 的模块获得（增量）预算。`B_trust`、`B_capital` 由独立「风险台」按定义 166 约束守护，**任何模块不得竞价夺取**。

**定义 168（意图—契约—证书三元组 ICC）** 给定意图后验 `b`、契约 `C`、执行证据 `EV`：
```
ICC = ( intent_coverage(b, S), contract_compliance(C, EV), certificate_validity(J) )
intent_coverage   = b(S)，S 为 IRCC 使用的可信解释集
contract_compliance = P(success | C, EV) ≥ q  ∧  τ ≤ D  ∧  quality(C, EV) ≥ q
certificate_validity = (J_intent ∧ J_exec ∧ J_pose).valid ∧ fresh ∧ seq_continuous
```
`ICC.valid ⟺ coverage ≥ 1−α ∧ compliance ∧ certificate_validity`。`J_intent` 与 `J_exec/J_pose` 共享 `seq_id`，接入第 60 轮 EPIR 因果链。

**定义 169（经济—安全序贯决策 ESD）** 严格字典序：
```
安全可行 ≻ 契约可行 ≻ 期望利润
if not safety_feasible(K*):
    if EIC.can_restore(b): return CLARIFY_OR_PROBE
    return DEGRADE_SAFE
if not CSC.acceptable(C): return DECLINE_OR_RENEGOTIATE
if EIC.voi_econ(best_action) > 0: return best_action
return ACT(K*)
```
**护栏**：不得为利润签发无效证书；不得为成交而超出能力报价；不得利用「用户表述」反向操纵其真实意图（家长主义禁令）。

### IP-161 IUM（逆规划意图后验）

```python
class IntentUnderstandingModel:
    def __init__(self, goals, prefer_grid, beta=2.0, lam_theta=0.5):
        self.goals, self.thetas = goals, prefer_grid
        self.beta, self.lam_theta = beta, lam_theta
        self.b = np.ones((len(goals), len(prefer_grid)))
        self.b /= self.b.sum()

    def _speaker_likelihood(self, u, g, theta, x):
        scores = {u2: self.beta * self.expected_human_utility(u2, g, theta, x)
                  for u2 in self.utterance_space(x)}
        z = sum(np.exp(s) for s in scores.values())
        return np.exp(scores[u]) / z

    def posterior(self, u, x, scene):
        prior = self.prior(x, scene)
        lik = np.array([[self._speaker_likelihood(u, g, t, x)
                         for t in self.thetas] for g in self.goals])
        self.b = self._normalize(prior * lik)
        return self.b

    def constraint_posterior(self):
        q = {}
        for gi, g in enumerate(self.goals):
            for ti, t in enumerate(self.thetas):
                C = self.semantic_map(g, self.thetas[ti])
                q[C] = q.get(C, 0.0) + self.b[gi, ti]
        return q

    def credible_set(self, alpha=0.05):
        q = sorted(self.constraint_posterior().items(), key=lambda kv: -kv[1])
        S, mass = [], 0.0
        for C, w in q:
            S.append(C); mass += w
            if mass >= 1 - alpha:
                break
        return S, mass

    def ambiguity(self):
        return self._entropy(self.b.sum(axis=1)) + self.lam_theta * self._entropy(self.b.sum(axis=0))
```

### IP-162 CSC（能力诚实服务契约）

```python
class CapabilityHonestContract:
    def __init__(self, reserve_profit=0.0, alpha=0.05):
        self.r_reserve, self.alpha = reserve_profit, alpha

    def quote(self, task, belief, policy_family):
        best = None
        for pi in policy_family:
            cert = self.certify(pi, task, belief)
            if cert is None:
                continue
            q_max = min(self.quality_ub(pi, C) for C in belief.credible_set()[0])
            t_min = max(self.time_lb(pi, C) for C in belief.credible_set()[0])
            p_succ = belief.expect(lambda C: self.success_prob(pi, C))
            cvar = belief.expect(lambda C: self.risk(pi, C))
            p = self.price_for(task, cert, cvar)
            Pi = p * p_succ - self.cost(pi) - self.penalty(task.D, pi) - self.risk_premium(cvar)
            if Pi < self.r_reserve or cvar > task.R_cap:
                continue
            contract = Contract(task.T, max(task.D, t_min), min(task.q, q_max),
                                p, task.lam_pen, task.R_cap)
            if best is None or Pi > best.profit:
                best = Quote(contract, pi, cert, Pi)
        return best

    def acceptable(self, quote):
        J = quote.cert
        return (J.valid and quote.p_succ >= quote.contract.q
                and quote.contract.q <= self.quality_ub(quote.pi)
                and quote.contract.D >= self.time_lb(quote.pi))
```

### IP-163 EIC（经济化意图澄清）

```python
class EconomicIntentClarifier:
    def __init__(self, alpha=0.05, lam_h=0.1, theta_ask=0.0):
        self.alpha, self.lam_h, self.theta_ask = alpha, lam_h, theta_ask

    def decide(self, b, contract, budget, deadline):
        K_nom = self.compile_nominal(b)
        if not self.safe_on_mass(b, K_nom, 1 - self.alpha):
            admissible = [ACT_CONSERVATIVE, ASK, PROBE, DECLINE]
        elif self.time_left(deadline) < budget.tau_clarify:
            admissible = [ACT_CONSERVATIVE, DECLINE]
        else:
            admissible = [ACT, ASK, PROBE, DECLINE]

        u = {a: self.expected_profit(a, b, contract)
                - self.action_cost(a) - self.lam_h * self.human_burden(a)
             for a in admissible}
        ask_voi = (self.expected_after_answer(b, contract)
                   - max(u.values()) - self.action_cost(ASK))
        if ask_voi > self.theta_ask and ASK in admissible:
            return Decision(ASK, question=self.best_question(b), voi=ask_voi)
        if PROBE in admissible and self.probe_voi(b, contract) > self.probe_cost(b):
            return Decision(PROBE, action=self.best_probe(b))
        return Decision(max(u, key=u.get))
```

### IP-164 IRCC（意图鲁棒约束编译）

```python
class IntentRobustCompiler:
    def __init__(self, W_max, alpha=0.05, k_min=10.0):
        self.W_max, self.alpha, self.k_min = W_max, alpha, k_min

    def compile(self, belief, contract):
        S, mass = belief.credible_set(self.alpha)
        K_star = solve_robust(
            objective=lambda K: belief.expect(lambda C: self.cost(K, C)),
            constraint=lambda K: max(self.risk(K, C) for C in S) <= self.W_max,
            lower=lambda K: K >= self.k_min * np.eye(6))
        K_nom = solve_nominal(belief)
        delta_amb = (belief.expect(lambda C: self.cost(K_star, C))
                     - belief.expect(lambda C: self.cost(K_nom, C)))
        feasible = (K_star is not None
                    and max(self.risk(K_star, C) for C in S) <= self.W_max)
        return CompileResult(K_star, delta_amb, S, mass, feasible)
```

```python
def economic_intent_service_loop(M, task, utterance, budget):
    z = M.scene.update(M.telem_force, M.telem_pos)
    b = M.ium.posterior(utterance, M.context(z), z)
    while budget.clarify_left > 0:
        quote = M.csc.quote(task, b, M.policy_family)
        if quote is None:
            return M.decline(task, reason='infeasible_or_unprofitable')
        d = M.eic.decide(b, quote.contract, budget, task.D)
        if d.type == 'ASK':
            b = M.ium.update(b, ask_human(d.question)); budget.clarify_left -= 1; continue
        if d.type == 'PROBE':
            ev = execute_probe(d.action); b = M.ium.update_physical(b, ev)
            budget.clarify_left -= 1; continue
        if d.type == 'DECLINE':
            return M.decline(task, reason='economic')
        comp = M.ircc.compile(b, quote.contract)
        if not comp.feasible or comp.delta_amb > quote.margin:
            budget.clarify_left -= 1; continue
        J_intent = build_intent_cert(b, comp.S, comp.K_star, quote.contract)
        if not (J_intent.valid and M.j_exec.valid and M.j_pose.valid):
            return M.degrade_safe(task)
        dispatch_impedance_params(comp.K_star, J_intent)
        telemetry = wait_contact()
        EV = build_exec_evidence(telemetry, comp.K_star, J_intent)
        outcome = M.settle(quote.contract, EV)
        M.reputation.update(outcome); M.pricing.update(outcome)
        M.budget = M.cba.reallocate(M.module_bids(), M.budget)
        return quote.contract, comp.K_star, J_intent, outcome, M.reputation.r
    return M.degrade_safe(task)
```

```python
class ReputationPricing:
    def __init__(self, r0=0.5, eta=0.05, p_base=1.0, mu=0.5,
                 nu=2.0, gamma=0.95, r_min=0.2, delta=0.01):
        self.r, self.eta, self.p_base, self.mu = r0, eta, p_base, mu
        self.nu, self.gamma, self.r_min, self.delta = nu, gamma, r_min, delta

    def price(self, contract, cvar):
        return self.p_base + self.mu * self.r - self.nu * cvar

    def update(self, outcome):
        self.r = float(np.clip(self.r + self.eta * (outcome.success - outcome.expected), 0, 1))

    def ruin_ok(self, downside):
        return (self.r - self.eta * downside) >= self.r_min

    def long_run_value(self, policy, horizon=100):
        return sum(self.gamma ** t * policy.expected_profit(t)
                   for t in range(horizon))
```

**正确性定理（EISC）**：设 A66–A71 成立：
- **(A66) 说话人近似理性**：`0 < β < ∞`，理性说话人似然有界且校准（排除恶意欺骗/分布外语言）。
- **(A67) 意图校准**：真实 `(g,θ)` 以 ≥1−α 概率落在 `S_{1−α}(b)` 内。
- **(A68) 语义—风险可计算**：`C(g,θ)` 可计算，`risk(K,C)` 对 `C` 连续（Lipschitz）。
- **(A69) 契约可验证**：成功/质量/时延可观测且不可伪造（无道德风险），罚金可执行。
- **(A70) 声誉/价格平稳可学**：转移模型稳定，风险资本约束可实时检查。
- **(A71) 模块估值次模**：`VOI_i` 单调、次模、可分，预算单位可分。

则：
1. **意图安全（IUM+IRCC）**：若 `ICC.intent_coverage ≥ 1−α` 且 `IRCC.feasible`，则在质量 ≥1−α 的解释上接触风险 ≤ `W_max`，即「语义歧义不会击穿执行安全」。
2. **能力诚实（CSC）**：任何被接受的契约满足 `q ≤ q_max(cert)`、`D ≥ τ_min(cert)`；不存在「报价超出证书能力」的成交路径。
3. **澄清经济性（EIC）**：`VOI_econ` 规则下，期望利润不低于「永远直接 ACT」与「永远 ASK」中较优者；且当 `VOI_econ ≤ 0` 时不产生无价值澄清。
4. **声誉不破产（RPC）**：在不破产约束下，任意策略满足 `P(r_{t+1} < r_min) ≤ δ`；拒绝难单是合法保护动作。
5. **内部市场效率（CBA）**：VCG 分配最大化 `Σ VOI_i` 且诚实报价为占优策略；`B_trust/B_capital` 的不可交易性保证安全资本不被利润竞价侵蚀。
6. **安全字典序（ESD）**：利润目标不能覆盖无效证书；系统不存在「为成交而执行无效 `J`」的路径。

### IP-161 IUM（逆规划意图后验）

```python
class IntentUnderstandingModel:
    def __init__(self, goals, prefer_grid, beta=2.0, lam_theta=0.5):
        self.goals, self.thetas = goals, prefer_grid
        self.beta, self.lam_theta = beta, lam_theta
        self.b = np.ones((len(goals), len(prefer_grid))); self.b /= self.b.sum()

    def _speaker_likelihood(self, u, g, theta, x):
        scores = {u2: self.beta * self.expected_human_utility(u2, g, theta, x)
                  for u2 in self.utterance_space(x)}
        z = sum(np.exp(s) for s in scores.values())
        return np.exp(scores[u]) / z

    def posterior(self, u, x, scene):
        prior = self.prior(x, scene)
        lik = np.array([[self._speaker_likelihood(u, g, t, x)
                         for t in self.thetas] for g in self.goals])
        self.b = self._normalize(prior * lik)
        return self.b

    def constraint_posterior(self):
        q = {}
        for gi, g in enumerate(self.goals):
            for ti, t in enumerate(self.thetas):
                C = self.semantic_map(g, t)
                q[C] = q.get(C, 0.0) + self.b[gi, ti]
        return q

    def credible_set(self, alpha=0.05):
        q = sorted(self.constraint_posterior().items(), key=lambda kv: -kv[1])
        S, mass = [], 0.0
        for C, w in q:
            S.append(C); mass += w
            if mass >= 1 - alpha: break
        return S, mass

    def ambiguity(self):
        return (self._entropy(self.b.sum(axis=1))
                + self.lam_theta * self._entropy(self.b.sum(axis=0)))
```

```python
class CapabilityHonestContract:
    def __init__(self, reserve_profit=0.0, alpha=0.05):
        self.r_reserve, self.alpha = reserve_profit, alpha

    def quote(self, task, belief, policy_family):
        best = None
        for pi in policy_family:
            cert = self.certify(pi, task, belief)
            if cert is None: continue
            S, _ = belief.credible_set(self.alpha)
            q_max = min(self.quality_ub(pi, C) for C in S)
            t_min = max(self.time_lb(pi, C) for C in S)
            p_succ = belief.expect(lambda C: self.success_prob(pi, C))
            cvar = belief.expect(lambda C: self.risk(pi, C))
            p = self.price_for(task, cert, cvar)
            Pi = (p * p_succ - self.cost(pi)
                  - self.penalty(task.D, pi) - self.risk_premium(cvar))
            if Pi < self.r_reserve or cvar > task.R_cap: continue
            C = Contract(task.T, max(task.D, t_min), min(task.q, q_max),
                         p, task.lam_pen, task.R_cap)
            if best is None or Pi > best.profit:
                best = Quote(C, pi, cert, Pi)
        return best

    def acceptable(self, quote):
        J, C, pi = quote.cert, quote.contract, quote.pi
        return (J.valid and quote.p_succ >= C.q
                and C.q <= self.quality_ub(pi)
                and C.D >= self.time_lb(pi))
```

```python
        if PROBE in admissible and self.probe_voi(b, contract) > self.probe_cost(b):
            return Decision(PROBE, action=self.best_probe(b))
        return Decision(max(u, key=u.get))
```

### IP-164 IRCC（意图鲁棒约束编译）

```python
class IntentRobustCompiler:
    def __init__(self, W_max, alpha=0.05, k_min=10.0):
        self.W_max, self.alpha, self.k_min = W_max, alpha, k_min

    def compile(self, belief, contract):
        S, mass = belief.credible_set(self.alpha)
        K_star = solve_robust(
            objective=lambda K: belief.expect(lambda C: self.cost(K, C)),
            constraint=lambda K: max(self.risk(K, C) for C in S) <= self.W_max,
            lower=lambda K: K >= self.k_min * np.eye(6))
        K_nom = solve_nominal(belief)
        delta_amb = (belief.expect(lambda C: self.cost(K_star, C))
                     - belief.expect(lambda C: self.cost(K_nom, C)))
        feasible = (K_star is not None
                    and max(self.risk(K_star, C) for C in S) <= self.W_max)
        return CompileResult(K_star, delta_amb, S, mass, feasible)
```

```python
class ReputationPricing:
    def __init__(self, r0=0.5, eta=0.05, p_base=1.0, mu=0.5,

        self.nu, self.gamma, self.r_min, self.delta = nu, gamma, r_min, delta

    def price(self, contract, cvar):
        return self.p_base + self.mu * self.r - self.nu * cvar

    def update(self, outcome):
        self.r = float(np.clip(self.r + self.eta * (outcome.success - outcome.expected), 0, 1))

    def ruin_ok(self, downside):
        return (self.r - self.eta * downside) >= self.r_min

    def long_run_value(self, policy, horizon=100):
        return sum(self.gamma ** t * policy.expected_profit(t) for t in range(horizon))
```

```python
class CognitiveBudgetAuction:

        self.reserved = reserved          # 安全关键模块的保留配额

    def allocate(self, bids, B_trade):
        Delta = solve_separable_concave(
            objective=lambda d: sum(b.utility(d[i]) for i, b in enumerate(bids)),
            constraint=lambda d: (sum(d) <= B_trade
                                  and all(d[i] >= self.reserved[i] for i in range(len(d)))),
            bounds=[(self.reserved[i], B_trade) for i in range(len(bids))])
        lam = dual_price(bids, B_trade, Delta)
        payments = vcg_payments(bids, Delta)
        return Delta, lam, payments
```

```python
def build_intent_cert(b, S, K, contract, alpha=0.05):
    coverage = sum(w for C, w in b.constraint_posterior().items() if C in S)
    risk = max(risk_of(K, C) for C in S)
    cert = IntentCertificate(
        coverage=coverage, credible_set=S, K_used=K, contract=contract,
        alpha=alpha, margin=W_max - risk, t_stamp=time.time(),
        seq_id=next_global_seq())
    cert.valid = (coverage >= 1 - alpha and risk <= W_max
                  and cert.fresh(tau_stale) and cert.seq_continuous())
    return cert

def settle_icc(cert_intent, cert_exec, cert_pose, outcome, contract):
    coverage = cert_intent.coverage
    compliance = (outcome.success >= contract.q and outcome.tau <= contract.D
                  and outcome.quality >= contract.q)
    valid = cert_intent.valid and cert_exec.valid and cert_pose.valid
    return ICC(coverage, compliance, valid)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| IUM | O(\|G\|·\|Θ\|·\|U\|) | O(\|G\|·\|Θ\|) | 后验校准，歧义可度量 |
| CSC | O(\|Π\|·\|S_{1−α}\|) | O(\|Π\|) | 成交契约必有证书背书 |
| EIC | O(\|A\|·\|S_{1−α}\|) | O(1) | 1−α 质量未覆盖则禁止 ACT |
| IRCC | O(\|S_{1−α}\|·6³ + 凸优化) | O(\|S_{1−α}\|·6²) | 1−α 语义质量上 risk ≤ W_max |
| EISL | O(澄清次数 · 单轮) | 复用 | 安全 ≻ 契约 ≻ 利润 |
| RPC | O(1) / O(H) | O(1) | 不破产概率 ≤ δ |
| CBA | O(n log n) | O(n) | 总 VOI 最大、真实报价占优 |

**正确性定理（EISC）**：设 A66–A71（说话人近似理性、意图校准、语义—风险可计算、契约可验证、声誉/价格平稳可学、模块估值次模）成立，则：
1. **意图安全**：`coverage ≥ 1−α` 且 IRCC 可行 ⇒ 质量 ≥1−α 的语义解释上接触风险 ≤ `W_max`。
2. **能力诚实**：任何成交契约满足 `q ≤ q_max(cert)`、`D ≥ τ_min(cert)`，不存在过度承诺。
3. **澄清经济性**：`VOI_econ` 规则下期望利润不劣于「永远 ACT」与「永远 ASK」的较优者。
4. **声誉不破产**：不破产约束保证 `P(r_{t+1}<r_min) ≤ δ`。
5. **内部市场效率**：VCG 配置最大化总 VOI，诚实报价为占优策略；安全资本不可交易。
6. **字典序安全**：利润不能覆盖无效证书，不存在「为成交而执行无效 `J`」的路径。

## 5. 本轮最大风险

**一句话**：若理性说话人模型与人类真实表述失配、且利润被允许参与「选哪种解释」的决策，系统会滋生**策略性误读**——专挑更便宜或更省事的解释、用过度澄清转嫁责任、或以「保护声誉」为名拒接难单（挑肥拣瘦），最终使「经济上合理、语义上背叛、偶尔灾难性违约」的抽象泄漏被放大；必须以「安全字典序（安全 ≻ 契约 ≻ 利润）」「IC/能力诚实契约 + 可审计 `J_intent`」「澄清预算上限与人类否决权」「对拒单/澄清的反事实审计」四重护栏，确保商业优化永远不能改写用户的真实意图。
