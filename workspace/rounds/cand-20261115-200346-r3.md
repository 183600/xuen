# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉伺服」×「姿态估计」）

> R69 教会了系统「问」：把 epistemic 歧义交给看 / 问 / 触，用流匹配先验判断值不值得问。但 R69 的全部歧义都发生在**动作空间**——「绕左还是绕右」。它默认了一件更基础、也更脆弱的事：**我已经知道自己在哪、目标在哪、两者差多少**。本轮指出，这个默认恰恰可能是假的：姿态本身可能**根本不可观测**，而视觉伺服闭环会把这种不可观测**伪装成已收敛**。
>
> 两个灵感正好补上两块缺失：
> - **姿态估计**告诉我们：姿态从来不是一个点，而是 SE(3) 上的一条 **G-轨道**——对称物体（杯、螺钉、方盒、平面标定板）的几个位姿在同一张图上**逐像素相同**，平面目标还有著名的 PnP 二重歧义。此时姿态后验是多峰、结构性的，不是高斯噪声，协方差根本表达不了「两个相距很远的峰」。
> - **视觉伺服**告诉我们一件更危险的事：闭环控制律只把**图像误差** `e = s(T̂) − s*` 拉到零，它从不检查「真的到了」。若估计有偏、或目标对称，闭环会收敛到一个**自洽但错误的不动点**：误差归零、速度归零、系统报告成功——**把「看不见」伪装成「到了」**。同时，视觉伺服也给出唯一出路：**运动可以制造视差、打破离散对称（主动视觉）**。
>
> 核心命题：**把「我到了」拆成两个不可互证的命题——「闭环说我到了」(`e→0`，可被 servo-lock 伪造) 与「几何证明我到了」(规范不变残差 `r_gauge` 小且 `σ_obs>0`)**；只有二者同时成立才宣称收敛，否则主动用**规范破除运动**在安全 / 能量 / 时间预算内制造信息，或在连续规范不可破 / 无利可图时退回 R69→R68 的保守。命名 **GAUGE-RAS**（Gauge-Aware Uncertainty in Geometric Estimation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的「到了」是真的到了，还是我把「看不见」当成了「到了」？我能不能动一下，把看不见变成看得见**」。

## 0. 直觉与动机

**灵感 1（姿态估计 → 姿态是轨道，不是点）**
直觉：姿态估计器习惯输出一个位姿加一个协方差。但对一个 180° 旋转对称的方盒、一个圆柱、一块平面标定板，「换一个位姿」和「原样不动」产生的是**完全相同的像素**。此时真实后验不是「一个峰加噪声」，而是「两三个相距很远的峰」——协方差会把它们糊成一个不存在的中间位姿，而这个中间位姿可能恰恰落在危险区。R69 的流匹配恰好能采样这种多峰分布，只需要把 SE(3) 换成欧氏空间、把测地路径接进速度场。于是「歧义」从 R69 的动作模态 `U_epi` 扩展出一个正交的新维度：**观测空间的姿态歧义 `U_pose`**。

**灵感 2（视觉伺服 → 闭环把估计误差变成稳定不动点）**
直觉：开环里，标定偏差是一个「看得见的偏移」；闭环里，它被翻译成一个「稳定的错误平衡点」。IBVS 要的是 `s(T̂) = s*`，而 `s(T̂)` 用的是有偏估计：当控制器认为误差已经为零时，真实特征落在 `s* − b` 上，真实位姿因此差了一截。更糟的是，控制增益越高，这个错误不动点**收敛得越快、越硬、越难被扰动暴露**——「快而稳」在错误点上恰恰是**放大器**。这正是 R68「标定吸收」在几何—控制层的重演：闭环本身成了吸收器，而且它吸收的正是自己的误差信号。

**灵感 3（对偶：可观测性 ←→ 可控性；动一下才能看见）**
直觉：视觉伺服提供控制，姿态估计提供观测，二者由同一个图像雅可比耦合。一个姿态能「唯一伺服到位」当且仅当**任务相关方向可观测**且规范被固定；不可观测的方向，控制得再准也只是在零空间里打转。要破局只能改变观测条件：移动视点制造视差（破离散对称）、换传感器 / 用标定锚、或最后才问人。于是 R69 的「信息动作」多了一个更强、更自主的成员：**自运动**。它不依赖人类、不会被说谎，但有能量 / 时间 / 安全成本，而且对**连续对称**（圆柱绕轴）彻底无效——可以形式化地证明「再动也没用」。

**灵感 4（同一条闭环，两个相反的评价）**
直觉：高增益伺服让收敛更快更稳，通常被当成优点。但如果收敛点是错的，高增益就是**证据销毁器**：它把偏差压成一个更难被外部观测发现的错误不动点。因此「稳」和「快」不能作为正确性的证据；有时反而要**主动降低增益、注入抖动、做 loop-breaking 激励**，让被压死的偏差重新浮出为可观测的暂态。为看清而故意「不稳一下」，是这一轮最反工程直觉、也最关键的一条。

**灵感 5（新的攻击面：对称性是最廉价的对抗样本）**
直觉：杯子、螺钉、方盒、法兰、托盘孔位——对称物体遍地都是，**不需要攻击者**就能制造 servo-lock。再叠加对抗纹理 / 反光 / 遮挡，姿态偏差就能与对称性共谋。更隐蔽的是，攻击者不需要让你「看到错的东西」，只需让一个对称物体以两种方式都「看起来对」，系统会自己完成剩下的欺骗。所以本轮必须同时交付：servo-lock 检测、证书独立性、连续对称判据、任务相关规范过滤、对抗对称评估。否则 R70 不是进步，而是给 R68 / R69 的保守主义装了一个**永远报告成功**的仪表盘。

**灵感 6（R69 的「问」在这里要退居第二）**
直觉：R69 的默认反应是「不懂就问」。但在几何歧义里，很多问题**问人也没用**：人不可能通过一句回答告诉你一个圆柱绕轴转了多少度（他自己也看不见），更不可能替你完成视差。几何歧义的第一解是**改变观测**，不是改变被告知的内容。因此本轮把信息动作排序为：**规范锚 → 自运动视差 → 人类交互（R69）→ 保守**。这不是否定 R69，而是给「信息动作」补上它一直缺的物理成员，并把「该问谁」升级为「**先问场景，再问人**」。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（GAUGE-RAS 总览）** GAUGE-RAS = (PGP, SOC, SLC, GIR, AGM, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；姿态流与规范检测均在推理侧）；
(ii) **证书独立性**：伺服收敛证书必须由一个与控制器误差信号 `e` 条件独立的通道产生，**不允许用 `e→0` 自证**；
(iii) **规范不变性**：所有「成功 / 收敛 / 代价」断言必须在目标对称群 `G` 下不变或协变，否则记为「未定」，不得宣称成功；
(iv) **主动运动预算**：规范破除运动与任务动作过同一 C-RAS-WM 认证，受能量 `≤ e_max`、位移 `≤ ε_g`、时间窗与安全包络硬约束，单位决策窗至多一次。

**定义 311（姿态规范群与 G-轨道）** 目标 / 场景对称群 `G ⊂ SE(3)`（离散：平面二重歧义 `{I, g₂}`、180° 翻转；连续：圆柱绕轴 `SO(2)`、回转体）。观测映射 `h: SE(3) → ℝ^m` 满足 `h(g·T) = h(T), ∀g∈G`。姿态后验 `π(T|y)` 是 `G`-不变的，其支撑分解为**轨道** `[T] = G·T`。**规范自由度** = 单视角下无法区分的等价类；姿态不是点，而是「一个代表元 + 一个未定的群元」。

**定义 312（姿态假设流 PGP）** 在 SE(3) 上以流匹配生成 `K` 个姿态假设 `{T_j}`：切空间测地路径 `T_s = exp_{T_0}(s·log_{T_0}(T_1))`，噪声取 `T_{T_0}SE(3)` 上的高斯；条件编码复用 R68 / R69 视觉 trunk 的 `z_t`。目标 `L_PFM = E‖v_θ(T_s, s|z_t) − log(T_1 T_0^{-1})‖²`。轨迹聚类得轨道模态 `{O_k}`、权重 `ŵ_k`、轨道内协方差 `Σ_k`。**姿态歧义** `U_pose = H({ŵ_k})·1[|轨道|>1]`，与 R69 的 `U_epi` 正交：一个在观测空间，一个在动作空间。

**定义 313（任务相关规范 vs 任务无关规范）** 任务映射 `τ: SE(3)→ℝ^{d_τ}`（如孔轴对齐只关心 5-DoF）。定义任务相关规范子空间 `𝒢_task = 𝒢 ∩ (ker ∂τ/∂T)^⊥`，其中 `𝒢` 是 `Lie(G)` 在 `T_T SE(3)` 的像。**只有 `𝒢_task ≠ 0` 的歧义才值得消解**；任务无关的对称（圆柱绕轴自转、螺钉旋向）应被**显式忽略**，否则系统会为「永远无法、也无需分辨」的自由度无休止地移动 / 提问。这是对 R69「歧义大就值得问」的关键修正：**歧义的价值取决于它是否落在任务的可观测—可控方向里。**

**定义 314（伺服不动点与 Servo-Lock）** IBVS 控制律 `u = −K·L̂⁺·e`，`e = s(T̂) − s*`，`L̂` 为估计交互矩阵。不动点 `T*` 满足（估计的）`e(T*) = 0`。真实任务误差 `E_task = d_τ(τ(T_true), τ(T*))`。**Servo-Lock 事件** ⇔ 闭环稳定收敛（`‖u‖→0, ‖e‖→0`）但 `E_task > τ_task`。机理：估计偏差 `b` 使 `s(T_true)` 收敛到 `s* − b`，于是「控制器认为的零误差」对应真实的非零位姿偏移，`E_task ≈ ‖J_τ·pinv(J_h)·b‖`。**闭环把估计偏差翻译成一个稳定、自洽、且对自身误差信号不可见的错误不动点。**

**定义 315（伺服可观测 Gramian 与 σ_obs）** 观测雅可比 `J_h = ∂h/∂T`，伺服可观测 Gramian `O = J_h^⊤ J_h ∈ Sym(T_T SE(3))`。可观测子空间 `range(O)`，规范零空间 `ker(O)`（含 `G` 的生成元与未观测 DoF）。**任务相关可观测指数** `σ_obs = λ_min^+((P_task O P_task)|_{𝒢_task^⊥ ∩ range})`。判据：**任务可唯一点伺服 ⇔ `σ_obs ≥ τ_obs` 且 `𝒢_task` 已被规范锚 / 多视角固定**。`σ_obs→0` 意味着「控制得再准也在零空间里打转」。

**定义 316（规范不变残差 GIR，证书独立通道）** 在与控制器所用通道条件独立（A103）的观测通道上构造 `G`-不变残差：例如双视角三角化一致性 `r_gauge = d(T^{v1}∘T_{12}, T^{v2})`，或非对称特征的规范锚残差，或度量深度与图像特征的重投影不一致。**核心要求**：`r_gauge` 的设置不得复用控制器误差 `e` 所依赖的同一有偏参数，否则「第二意见」只是同一偏见的复读。`r_gauge` 小 ⇔ 规范已被观测固定；`r_gauge` 大而 `e→0` ⇔ servo-lock 嫌疑。

**定义 317（主动规范破除运动 AGM）** 信息动作扩展 `g_self = (δT_view, t_dwell) ∈ SE(3)×ℝ⁺`。目标视点使任务相关方向的 `σ_obs` 上升、轨道熵下降。`VoI_geo(g_self) = H([T]|o) − E_{y~p(·|g_self,o)}H([T]|o,y) − λ_e·E_energy − λ_t·t_dwell`，s.t. 安全包络、`位移 ≤ ε_g`、`能耗 ≤ e_max`、时间窗有效。选择 `g* = argmax[VoI_geo − c]`，若 `max ≤ 0` 则不移动。**与 R69 的 VoI 同构**，但信息源从「人 / 触 / 注视」换成「自身位姿改变制造的视差」。

**定义 318（连续规范不可破判据）** 若 `G` 含连通一维子群 `G_c`（圆柱绕轴、回转体），则对任意有限相机运动，`h` 在 `G_c` 方向上不变（对象自身对称，换视角不改变其自转的不可辨性），故 `VoI_geo` 在该方向恒为 `0`，且 `E_task` 存在不可消除下界。判据：`dim(𝒢_task ∩ Lie(G_c)) > 0` ⇒ **禁止**发起「移动消歧」（否则陷入无限探询），改走：接受不可辨 + 任务无关投影（若可）+ 保守 `λ` + 必要时 R69 人类交互（若该 DoF 确实相关且人有能力定义它）。这是「何时**不该**主动看」的形式化。

**定义 319（规范锚 Gauge Anchor）** 场景中可识别、非对称、姿态已知的参照（fiducial / AprilTag、已知纹理、夹具、重力方向、结构先验）固定规范：`ker(O) ∩ 𝒢 = 0`。锚提供「绝对规范」，比自运动便宜得多（零运动成本），但可能被遮挡 / 缺失 / 伪造。策略：**优先用锚，无锚再用视差运动，最后才问人**——几何版的「最小披露 / 最省先验」。

**定义 320（姿态-动作联合假设与风险敏感选择）** 联合后验 `{(T_j, ξ_j)}`，动作选择不得只在最大权重位姿上做「正确」的决定。风险敏感准则：`ξ* = argmin_ξ max_{T∈[T]} risk(ξ|T)`（最坏轨道）或 `CVaR_α`（尾部）。**在错误位姿上执行正确动作 = 一次精确的错误。** 若最坏轨道风险 `> ε_task`，先消歧（锚 / AGM / R69 交互），不执行。

**定义 321（GAUGE 证书 J_GAUGE）** `J_GAUGE = (J_FLUID, orbit_rank, σ_obs, r_gauge, servo_lock_flag, agm_log_hash, gauge_anchor_id, energy_used, gauge_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ σ_obs ≥ τ_obs ∧ (orbit 任务无关 ∨ r_gauge ≤ τ_g) ∧ ¬servo_lock ∧ (若 orbit 任务相关则已执行有效 AGM / 锚 / 交互)`。**「成功」不是控制器能签的字**：没有独立残差与可观测性证据，证书不得置位。

**定义 322（假收敛 / 未定的保守退避）** 若 servo_lock 检出、orbit 未定、`r_gauge` 不可信（动态污染）、或 `σ_obs < τ_obs` 且本窗内无法改善：**不宣称任务完成**；`λ = λ_floor(U_ale + 未消解 U_epi + U_pose)`，`k` 收缩，触发「停—看—动」序列（先降增益 / 加激励暴露偏差，再 AGM，最后保守）。⇒ R69 是 GAUGE 在 `(orbit=1 ∨ 任务无关, σ_obs≥τ, r_gauge≤τ, 无 AGM)` 的退化；R68 再退化为「无交互」。

**定义 323（动态场景的规范污染与时间同步）** 目标 / 场景移动时，跨视角一致性会把「两次观测对应不同真实位姿」误判为歧义或伪造一致。加入时间戳对齐、运动补偿与「静止假设检验」：若无法在容差内补偿，`r_gauge` 标为不可信 → 退定义 322。**这是 R68 标定吸收在「几何×时间」维度的对偶：时间不同步会把真实运动吸收成虚假的一致性。**

**定义 324（伺服增益-偏差耦合与主动激励）** 闭环对偏差的有效放大 `A(K) ≈ ‖(I + K L̂⁺ J_h)^{-1} K L̂⁺ b‖` 在一定范围内随 `K` 单调，收敛时间随 `K` 减小。故「快而稳」不提供正确性证据。**主动激励**：在安全包络内降低增益、注入小幅 dither / loop-breaking 激励，使偏差从「被压死的错误不动点」变成「可观测的暂态偏差」，供 GIR 检测；仅在 servo-lock 嫌疑时启用，代价是精度与时间。

**定义 325（GAUGE 威胁模型 ℰ_GAUGE）** 并入 AIC：`ℰ_GAUGE = ℰ_FLUID × {对称混淆（对称物体诱导锁死）, 平面二重歧义, 动态遮挡 / 反光, 对抗纹理（使姿态偏置与对称性共谋）, 规范锚伪造 / 缺失, 时间不同步注入}`。威胁特点：**攻击者无需生成「错误的观测」，只需利用场景本身的多解性，让系统自己锁死**——对称性是最廉价的对抗样本。

**定义 326（参与式审计 VQAuditor-G）** 审计新增：是否用 `e→0` 自证成功；`r_gauge` 与 `e` 是否真的条件独立；AGM 是否越预算 / 越安全包络；连续对称是否被错误地发起无限探询；锚是否被伪造。结论回灌 AuditBuf，成为下一轮 AGM 成本先验与 `σ_obs` 门限的自适应依据。

**定义 327（跨轮严格包含）** 退化链：`GAUGE(σ_obs=∞, orbit=1 或任务无关, r_gauge=0, 无 AGM) ≡ R69`；`R69(无交互) ≡ R68`。GAUGE 只在旧层上**增加**几何可观测性约束与自运动通道，不替换任何旧可靠性论证（与 R69 / R68 同姿态：新层是旧层的严格泛化，旧层是边界情形）。

## 2. 关键算法骨架

```python
# IP-264 PGP：SE(3) 姿态假设流（复用 R68/R69 视觉 trunk）
class PoseGaugeFlow:
    def __init__(self, trunk, v_net, mode_head):
        self.trunk, self.v, self.mode_head = trunk, v_net, mode_head

    def sample(self, o, K=4, N=2):
        z  = self.trunk(o)
        Ts = randn_se3(K)                             # 切空间高斯
        for i in range(N):
            s  = i / N
            Ts = se3_exp(se3_log(Ts) + (1.0 / N) * self.v(se3_log(Ts), s, z))
        return Ts, z

    def log_prob(self, T, o):                         # SE(3) 瞬时变分
        return -hutchinson_se3_divergence(self.v, T, self.trunk(o))

# IP-265 SOC：任务相关可观测性
def observability(T, h, tau_map, G):
    Jh         = jacobian(h, T)
    O          = Jh.T @ Jh
    gauge      = lie_algebra_image(G, T)             # G 在切空间的像
    gauge_task = task_relevant(gauge, tau_map)       # 定义 313
    s_obs      = smallest_singular(O, gauge_task.orthogonal_complement())
    return s_obs, gauge_task

# IP-266 SLC：Servo-Lock 检测（只信独立通道）
def servo_lock(policy, o_views, e_norm, s_obs, gauge_task):
    if s_obs < TAU_OBS and gauge_task.norm > 0:
        return True                                  # 任务相关方向不可观测
    r_g = gauge_invariant_residual(policy, o_views)  # 定义 316，独立通道
    return (e_norm < TAU_E) and (r_g > TAU_G)        # 收敛但几何不一致

# IP-267 GIR：规范不变残差（双视角 / 度量 / 锚）
def gauge_invariant_residual(policy, o_views):
    T1  = policy.mode(o_views[0])                    # 与控制器不同的通道
    T2  = policy.mode(o_views[1])
    T12 = relative_pose(o_views[0], o_views[1])      # 标定 / 里程计
    return d_se3(T1 @ T12, T2)                       # 0 ⇒ 规范被固定

# IP-268 AGM：规范破除运动的 VoI 规划
def choose_gauge_motion(modes, o, G, gauge_task, budget):
    if dim(gauge_task & lie(G_continuous)) > 0:
        return None                                  # 连续对称不可破（定义 318）
    if has_anchor(o):
        return ('anchor', apply_anchor(o))           # 有锚先问锚（定义 319）
    best = None
    for dT in candidate_views(modes, o, N=8):
        if not budget.allow_motion(dT):        continue
        if not c_ras_wm.certify_info(dT, o):   continue   # 运动也要认证
        voi   = orbit_entropy(modes) - expected_orbit_entropy(modes, dT, o)
        score = voi - energy_cost(dT) - time_cost(dT)
        if best is None or score > best.score: best = (dT, score)
    return best if best and best.score > 0 else None  # 无利可图 → 不动

# IP-270 JPH：姿态-动作联合风险敏感选择
def select_joint(pose_modes, action_sets):
    J = [(T, xi) for T in pose_modes for xi in action_sets(T)]
    # 最坏轨道风险，防止「在错位姿上执行正确动作」
    return min(J, key=lambda p: max(risk(p[1], T) for T in orbit(p[0])))

# IP-275 主闭环（继承 R69，仅在「是否真的到了」处插入 GAUGE 层）
def GAUGE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 1) 姿态假设 + R69 动作假设
    Ts, z = M.pgp.sample(o, K=M.k_for(z))
    s_obs, g_task = M.soc.observability(Ts[0], M.h, M.tau, M.G)
    # 2) 独立第二意见：闭环说到了吗？几何同意吗？
    locked = M.slc.servo_lock(M.pgp, M.views, M.last_e, s_obs, g_task)
    # 3) 任务相关且可破：先锚 → 再动 → 再问 → 否则保守
    action = None
    if g_task.norm > TAU_GAUGE and locked:
        if M.gah.has_anchor(o):
            action = ('anchor', M.gah.apply(o))
        else:
            g_self = M.agm.choose_gauge_motion(Ts, o, M.G, g_task, M.budget)
            if g_self is not None:  action = ('move', g_self)
            elif U_epi > TAU_EPI:   action = ('ask', M.mint.choose_interaction(...))  # R69
    # 4) 不宣称成功：未证收敛一律按保守
    U_pose = M.pgp.orbit_entropy(Ts) * g_task.norm
    if locked or action is not None:
        lam  = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi + U_pose))
        k    = M.c_ras_wm.certified_prefix(...)      # 收缩
        done = False
    else:
        lam  = max(M.efs.risk_scale(...), lam_floor(U_ale))
        mode = M.jph.select_joint(Ts, M.fmp.samples(o))
        k    = M.c_ras_wm.certified_prefix(mode.a[:k], ...)
        tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
        done = M.gci.certify(...)                    # 独立残差通过才置位
    # 5) 参与式审计（几何版）
    M.vq_g.submit_async(locked, action, s_obs, M.last_e, M.last_r_gauge)
    return k, lam, done, (U_ale, U_epi, U_pose, s_obs)
```

## 3. 推导

**假设**：**A100**（`h` 连续可微且 `G`-不变 / 等变，局部秩不变）；**A101**（控制律在可观测子空间稳定，`L̂` 在 `range(O)` 上满秩）；**A102**（离散对称可由有限视点变化破除，连续对称不能）；**A103**（证书独立性：GIR 通道与控制器通道条件独立）；**A104**（动态补偿误差有界，否则 `r_gauge` 不可信）。

**引理 19（伺服锁死的必然性）** 在 A100–A101 下，若估计偏差 `b` 任务相关（`P_task b ≠ 0`）且闭环稳定，则 `‖e‖→0` 的同时 `E_task ≥ ‖J_τ·pinv(J_h)·b‖ − O(‖b‖²)`。要点：不动点把**估计**特征拉到 `s*`，真实特征因此偏出 `b`；高增益只缩短暂态，不降低这个稳态下限，反而让不动点更硬。系：**`e→0` 不能给出任何任务误差上界**；唯一的出路是用独立通道（GIR）估计 `b` 的投影，而这也正是证书独立性的必要性。

**引理 20（G-轨道的不可辨识下界）** 对 `G`-对称目标与单视角 `y`，`I(T; y) = I([T]; y)` 且轨道熵 `≥ log|G|`（离散）或无界（连续）。故单视角最优期望任务误差 `≥ c·d_τ(τ(T), τ(G·T)) =: gauge floor`。系：**若规范任务无关，floor 恰为 0——此时「不确定」应当被忽略而非消除**（定义 313），这是避免「为不可辨而无限探询」的理论依据。

**引理 21（主动视差增益与可破性）** 基线 `δ` 的视点变化使离散对称两假设的投影分离 `∝ δ·depth⁻¹·(1−cosθ)`，任务相关方向 `σ_obs` 上升 `≥ κ·δ`，轨道熵下降 `ΔH`，故 `VoI_geo ≥ c·ΔH − λ_e·energy − λ_t·time`。对连续对称，分离对所有 `δ` 恒为 0，故 `VoI_geo ≡ 0`。系：**离散对称可被有限运动破除，连续对称不能**（定义 318）；且超过可观测饱和后「再移一点」收益递减，防止无限探询。

**引理 22（证书独立性的必要性）** 若 `r_gauge` 由同一有偏估计器计算，即 `r_gauge = F(b,·)`，则存在 `b ≠ 0` 使 `e→0` 且 `r_gauge≈0`；此时任何仅依赖 `(e, r_gauge)` 的判据都无法保证 `E_task ≤ τ`。系：**独立性不是锦上添花，而是证书有意义的唯一前提**；共享估计路径的「第二意见」只是复读。

**定理 18（GAUGE 严格包含 R69 与 R68）** 在 A100–A104 下，GAUGE 在任意状态的期望风险 `≤ R69`：它只增加「未证收敛则不宣称成功」的分支，或采取经 C-RAS-WM 认证且 `VoI_geo−c>0` 的 AGM。当 `orbit=1`（或任务无关）、`σ_obs≥τ_obs`、`r_gauge≤τ_g` 且无 AGM 时，二者**逐指令相同**。⇒ R69 是「几何良定」边界，R68 是「无交互」边界；安全侧不让步，效率侧获得 geometric resolution bonus。

**定理 19（假收敛不可宣称成功 + 退避单调）** 若 servo_lock 检出或 orbit 未定，`J_GAUGE` 失效；退避中 `λ` 单调不降、`k` 单调不增，故物理风险不增；AGM / 退避均由 C-RAS-WM 前缀认证，安全包络不变 ⇒ 控制连续、无突变。任何成功断言必须附独立 `r_gauge ≤ τ_g` 与 `σ_obs ≥ τ_obs`。

**定理 20（主动运动的安全与无突变）** AGM 经 C-RAS-WM 认证后物理风险 `≤ ε_int`；它只改变「从哪个视点看、信哪个轨道」，不改变安全包络；交互失败 / 超时 / 连续规范不可破时 `λ` 单调退化为 R68；换装 / 提交不变式（R68 定理 15）保持。

## 6. 本轮最大风险

**一句话**：GAUGE-RAS 把「收敛」从控制器的自证里救出来，却把命门押在「规范不变残差确实与控制器正交」上——**一旦 `r_gauge` 由同一个有偏估计器计算，或高增益闭环把偏差压成一个更硬的错误不动点，系统会以最高置信、最快速度、最稳轨迹锁死在错误位姿上：越稳、越错、越自信**。

**次级风险与缓解**：
1. **证书独立性被悄悄破坏**（GIR 复用控制器特征）→ 定义 316 + A103 + E303 反证实验，独立性作为硬门；
2. **连续对称诱发无限探询** → 定义 318 判据 + E305，`dim(𝒢_task∩Lie(G_c))>0` 直接禁止 AGM；
3. **任务无关歧义被误当任务相关** → 定义 313 投影 + E306，避免「为圆柱自转反复移动」；
4. **AGM 本身不安全 / 能耗超支** → C-RAS-WM 认证 + 定理 20 + E308；
5. **动态场景伪造一致性** → 定义 323 时间同步 + 静止假设检验，不可信即降级；
6. **对称混淆被攻击者利用** → ℰ_GAUGE 对抗训练 + E314，把「对称性=免费对抗样本」当作一等威胁。

**定义 310（总览与四不变式）** `GAUGE-RAS=(PGP,SOC,SLC,GIR,AGM,RAS-WM‡)`；零学习写操作继承；**证书独立性**（收敛不得用 `e→0` 自证）；**规范不变性**（成功断言须 `G`-不变/协变，否则未定）；**主动运动预算**（锚/自运动过 C-RAS-WM，能耗/位移/时间硬约束）。

**定义 311–312（规范轨道与 PGP）** 姿态后验是 `G`-轨道 `[T]`；SE(3) 流匹配采样 `{T_j}`，聚类得轨道模态、权重、协方差；`U_pose` 与 R69 的 `U_epi` 正交。

**定义 313（任务相关规范）** `𝒢_task = 𝒢 ∩ (ker ∂τ/∂T)^⊥`；**只有 `𝒢_task≠0` 的歧义值得消解**；圆柱绕轴、螺钉自转等任务无关对称应被显式忽略，否则无限探询。

**定义 314（Servo-Lock）** 闭环 `‖u‖→0, ‖e‖→0` 但 `E_task>τ_task`；`E_task ≈ ‖J_τ·pinv(J_h)·b‖`。闭环把估计偏差变成稳定、自洽、对自身误差不可见的错误不动点。

**定义 315（可观测性与 σ_obs）** `O=J_h^⊤J_h`，`σ_obs` 为任务相关方向最小奇异值；**任务可唯一点伺服 ⇔ `σ_obs≥τ_obs` 且任务相关规范被固定**。

**定义 316–317（GIR 与 AGM）** `r_gauge` 取自与控制器条件独立的通道（双视角三角化 / 度量 / 锚），小则规范已固定、大而 `e→0` 则锁死嫌疑；AGM 以 `VoI_geo` 选视点，无利可图即不动。

**定义 318–319（连续不可破与规范锚）** `dim(𝒢_task∩Lie(G_c))>0` ⇒ 禁止移动消歧（无限探询）；优先用非对称锚固定规范，其次视差运动，最后问人。

**定义 320–322（联合选择 / 证书 / 退避）** 姿态-动作联合最坏轨道 / CVaR 选择；`J_GAUGE` 需独立 `r_gauge` 与 `σ_obs`；锁死 / 未定 / 污染 ⇒ 不宣称完成，`λ` 单调收紧、`k` 收缩，触发「停—看—动」。

**定义 323–327（动态污染 / 增益耦合 / 威胁 / 审计 / 包含）** 时间不同步会把真实运动吸收成虚假一致；高增益压缩偏差 → 主动激励暴露；`ℰ_GAUGE` 含对称混淆与对抗纹理；VQAuditor-G 审自证与独立性；退化链 `GAUGE≡R69≡R68`。

## 3. 关键算法伪代码

```python
# IP-264 PGP：SE(3) 姿态假设流（复用 R68/R69 视觉 trunk）
class PoseGaugeFlow:
    def sample(self, o, K=4, N=2):
        z  = self.trunk(o)
        Ts = randn_se3(K)
        for i in range(N):
            Ts = se3_exp(se3_log(Ts) + (1.0/N) * self.v(se3_log(Ts), i/N, z))
        return Ts, z
    def log_prob(self, T, o):
        return -hutchinson_se3_divergence(self.v, T, self.trunk(o))

# IP-265 SOC：任务相关可观测性
def observability(T, h, tau_map, G):
    Jh, O      = jacobian(h, T), None
    O          = Jh.T @ Jh
    gauge      = lie_algebra_image(G, T)
    gauge_task = task_relevant(gauge, tau_map)          # 定义 313
    s_obs      = smallest_singular(O, gauge_task.orthogonal_complement())
    return s_obs, gauge_task

# IP-266/267 SLC + GIR：独立通道检测「收敛但错」
def servo_lock(policy, o_views, e_norm, s_obs, gauge_task):
    if s_obs < TAU_OBS and gauge_task.norm > 0: return True
    r_g = gauge_invariant_residual(policy, o_views)
    return (e_norm < TAU_E) and (r_g > TAU_G)

def gauge_invariant_residual(policy, o_views):
    T1, T2  = policy.mode(o_views[0]), policy.mode(o_views[1])
    T12     = relative_pose(o_views[0], o_views[1])
    return d_se3(T1 @ T12, T2)                          # 0 ⇒ 规范被固定

# IP-268 AGM：规范破除运动（离散可破，连续禁入）
def choose_gauge_motion(modes, o, G, gauge_task, budget):
    if dim(gauge_task & lie(G_continuous)) > 0: return None
    if has_anchor(o): return ('anchor', apply_anchor(o))
    best = None
    for dT in candidate_views(modes, o, N=8):
        if not budget.allow_motion(dT):        continue
        if not c_ras_wm.certify_info(dT, o):   continue
        voi   = orbit_entropy(modes) - expected_orbit_entropy(modes, dT, o)
        score = voi - energy_cost(dT) - time_cost(dT)
        if best is None or score > best.score: best = (dT, score)
    return best if best and best.score > 0 else None

# IP-270 JPH：姿态-动作联合、最坏轨道风险
def select_joint(pose_modes, action_sets):
    J = [(T, xi) for T in pose_modes for xi in action_sets(T)]
    return min(J, key=lambda p: max(risk(p[1], T) for T in orbit(p[0])))

# IP-275 主闭环（继承 R69，仅插入「是否真的到了」的几何层）
def GAUGE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    Ts, z = M.pgp.sample(o, K=M.k_for(z))
    s_obs, g_task = M.soc.observability(Ts[0], M.h, M.tau, M.G)
    locked = M.slc.servo_lock(M.pgp, M.views, M.last_e, s_obs, g_task)

    action = None
    if g_task.norm > TAU_GAUGE and locked:
        if M.gah.has_anchor(o):  action = ('anchor', M.gah.apply(o))
        else:
            g_self = M.agm.choose_gauge_motion(Ts, o, M.G, g_task, M.budget)
            if g_self is not None: action = ('move', g_self)
            elif U_epi > TAU_EPI:  action = ('ask', M.mint.choose_interaction(...))

    U_pose = M.pgp.orbit_entropy(Ts) * g_task.norm
    if locked or action is not None:
        lam  = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi + U_pose))
        k    = M.c_ras_wm.certified_prefix(...)
        done = False                                     # 不宣称成功
    else:
        lam  = max(M.efs.risk_scale(...), lam_floor(U_ale))
        mode = M.jph.select_joint(Ts, M.fmp.samples(o))
        k    = M.c_ras_wm.certified_prefix(mode.a[:k], ...)
        tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
        done = M.gci.certify(...)                        # 独立证据通过才置位
    M.vq_g.submit_async(locked, action, s_obs, M.last_e, M.last_r_gauge)
    return k, lam, done, (U_ale, U_epi, U_pose, s_obs)
```

## 4. 推导

假设：**A100**（`h` 可微且 `G`-不变 / 等变，局部秩不变）；**A101**（控制律在可观测子空间稳定，`L̂` 满秩）；**A102**（离散对称可有限破除，连续不可）；**A103**（GIR 与控制器通道条件独立）；**A104**（动态补偿误差有界，否则 `r_gauge` 不可信）。

**引理 19（伺服锁死的必然性）** 若估计偏差 `b` 任务相关且闭环稳定，则 `‖e‖→0` 时 `E_task ≥ ‖J_τ·pinv(J_h)·b‖ − O(‖b‖²)`。系：`e→0` 不能给出任务误差上界；高增益只缩短暂态，不降低稳态下限——「快而稳」在错点上反而是放大器。

**引理 20（G-轨道不可辨识下界）** 单视角下 `I(T;y)=I([T];y)`，轨道熵 `≥ log|G|`（离散）或无界（连续），故任务误差 `≥ c·d_τ(τ(T),τ(G·T))`。系：规范任务无关时下界为 0，此时「不确定」应被忽略而非消除（定义 313）。

**引理 21（主动视差增益与可破性）** 基线 `δ` 使离散对称两假设投影分离 `∝ δ·depth⁻¹·(1−cosθ)`，`σ_obs` 上升 `≥κ·δ`，轨道熵降 `ΔH`，`VoI_geo ≥ c·ΔH − 成本`；连续对称分离恒 0，`VoI_geo≡0`。系：离散可破、连续不可破，且收益随视差饱和，防无限探询。

**引理 22（证书独立性必要性）** 若 `r_gauge=F(b,·)` 复用同一有偏估计器，则存在 `b≠0` 使 `e→0 ∧ r_gauge≈0`；仅凭 `(e, r_gauge)` 无法保证 `E_task≤τ`。系：独立性是证书有意义的唯一前提，共享估计路径的第二意见只是复读。

**定理 18（GAUGE 严格包含 R69 与 R68）** A100–A104 下，GAUGE 任意状态期望风险 `≤ R69`；当 `orbit=1`（或任务无关）、`σ_obs≥τ_obs`、`r_gauge≤τ_g` 且无 AGM 时二者**逐指令相同**。⇒ R69 是几何良定边界，R68 是无交互边界；安全不让步，效率获 geometric resolution bonus。

**定理 19（假收敛不可宣称成功 + 退避单调）** servo_lock 检出或 orbit 未定时 `J_GAUGE` 失效；退避中 `λ` 单调不降、`k` 单调不增，物理风险不增；AGM / 退避过 C-RAS-WM 前缀认证，安全包络不变 ⇒ 控制连续、无突变。成功断言必须附独立 `r_gauge≤τ_g` 与 `σ_obs≥τ_obs`。

**定理 20（主动运动安全与无突变）** AGM 经认证后物理风险 `≤ ε_int`，只改「从哪看、信哪个轨道」，不改安全包络；失败 / 超时 / 连续规范不可破时 `λ` 单调退化为 R68；换装 / 提交不变式（R68 定理 15）保持。

## 7. 本轮最大风险

**一句话**：GAUGE-RAS 把「收敛」从控制器的自证里救出来，却把命门押在「规范不变残差确实与控制器正交」上——**一旦 `r_gauge` 由同一个有偏估计器计算，或高增益闭环把偏差压成一个更硬的错误不动点，系统会以最高置信、最快速度、最稳轨迹锁死在错误位姿上：越稳、越错、越自信**。

**次级风险与缓解**：证书独立性被悄悄破坏（定义 316 + A103 + E303 反证）；连续对称诱发无限探询（定义 318 + E305）；任务无关歧义误判为任务相关（定义 313 + E306）；AGM 越安全 / 能耗（C-RAS-WM + 定理 20 + E308）；动态场景伪造一致（定义 323 + 静止假设检验）；对称混淆被攻击（ℰ_GAUGE 对抗训练 + E314）。
