# 第 10 轮（本轮灵感：「可靠性」×「机器人竞赛」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**可靠度作为一等目标 + 竞赛效用序**。v9 已把“失效”变成可组合的中立元，但其安全论证仍以“信任域内前向模型误差 ≤ β”这一**模型假设**为前提；机器人竞赛却是**有限轮次、单样本、场地/光照/对手/裁判共同扰动**的对抗性部署，平均分不等于夺冠可靠度。本轮把可靠度从“模型假设”升级为**分布无关的在线证书**，并把退化台阶按竞赛效用（安全 > 合规 > 完赛 > 得分）重排。

## 0. 直觉与动机

**灵感 1（可靠性 → 从模型假设到在线校准的失效预算）**
直觉：可靠性工程不问“平均表现”，而问“一次任务在给定置信度下不失效的概率”；它用故障树把系统可靠度拆成模块预算，用冗余与重启换取尾部概率。v9 的 MW 已经提供了可组合的失效原子（中立元 v^⊥），但只完成了“失效如何传播”，没有回答“失效概率从哪来、如何分配、如何被经验验证”。核心创新有两条：
其一，**自适应保形可靠控制器（Adaptive Conformal Reliability Controller, ACRC）**：选一个单调影响风险的“攻击性参数” λ_t（例如 AC 的块长门控强度、速度上限或风险阈值），用自适应保形推断（Adaptive Conformal Inference, ACI）在线更新 λ_t，使**长期灾难率**逼近赛会目标 α；该保证分布无关、不需要 exchangeability，也不依赖前向模型误差界 β。它正好补上 v9 最大的风险缺口：当 Δ_dom 滞后时，λ_t 会根据真实发生的灾难事件自行收缩，而不是相信一个已经失效的模型证书。
其二，**可靠度预算分配器（Reliability Budget Allocator, RBA）**：由 v9 的契约表构造可靠度块图（RBD），把赛会总灾难预算 ε_tot 按轮次拆成 ε_run、再按故障树拆成模块预算 q_m；冗余（N-版本/双通道）与检查点-重启只投给“每单位算力带来的系统可靠度增益”最高的模块，并对共同原因失效做保守折减。

**灵感 2（机器人竞赛 → 效用序与得分保持退化）**
直觉：竞赛不是奖励最大化，而是**带硬约束的字典序优化**：撞人/撞物/越界=DQ（F0），任务不可恢复=F1，可重试失败=F2，只是慢或分少=F3。v9 的五级退化链只保证“安全不崩”，完全不保证“退化之后还在拿分”。同一套安全行为，在竞赛里可能从“拿 60 分”退成“0 分但没撞”，后者在积分制下同样是失败。核心创新：
**竞赛效用治理器（Competition Utility Governor, CUG）**：定义失效分类学与竞赛效用格，把每个中立元 v^⊥ 映射到其竞赛失效类；引入**得分保持回退（Score-Preserving Fallback, SPF）**——主任务链失效时，从任务组合中选一个能在剩余时间预算内以高置信度拿到部分分的备用行为（抓取失败→推箱入区；精细放置失败→粗放置），并证明退化在字典序上**不劣于** v9 的对应退化级。目标函数也从 E[score] 改为下尾可靠分 CVaR_α(score)。
**轮次预算调度（Round Budget Scheduler, RBS）**：资格赛/决赛是有限轮次，单轮 DQ 可能直接淘汰；把 ε_tot 按剩余轮次与当前名次动态分配，可重试失败用检查点-重启在剩余时间 T_run 内兑换完赛概率——这是竞赛制特有的“用时间换可靠度”。

## 1. 研究问题（轮次升级版）

- **Q1（分布无关的可靠证书）**：在场地、光照、对手行为非平稳变化下，如何给出“每轮灾难率 ≤ α”的有限样本、分布无关保证？ACI 的自适应步长 γ 与饱和界能否在“决赛 = 最不代表性的一轮”时仍不被击穿？
- **Q2（可靠预算与冗余）**：如何由契约表自动构造可靠度块图，把 ε_tot 拆成 q_m，并使冗余/重启的边际可靠度收益最大化？N-版本冗余的共同原因失效如何保守折减，避免“纸面可靠度”？
- **Q3（竞赛效用退化）**：如何定义失效分类与效用格，使任意 v^⊥ 组合路径的竞赛失效类不高于 v9 对应退化级，同时最大化 CVaR 可靠分？得分保持回退在什么条件下触发，如何证明它不引入新的失效类？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 可靠预算律（Reliability-Budget Law, RBA）**
系统由契约模块的可靠度块图给出，令 q_m 为模块 m 在一轮内的失效概率预算。保守设计满足
```
Σ_m q_m ≤ ε_run,     K_rounds · ε_run ≤ ε_tot,
```
即赛会级灾难概率 ≤ ε_tot（联合界）。冗余把串联可靠度 R_m 提升为并联 R_m^{(N)} = 1 − (1 − R_m)^N，但必须扣除共同原因失效概率 c_m：
```
R_m^{true} = (1 − c_m) · (1 − (1 − R_m)^N).
```
冗余只投向可靠性杠杆 L_m = (∂R_sys/∂R_m) · (ΔR_m / cost_m) 最大的模块；检查点-重启视为用时间预算购买可靠度。

**P14 在线可靠校准律（Adaptive-Conformal Reliability, ACRC）**
令 λ_t ∈ [λ_min, λ_max] 为单调影响风险的攻击性参数，e_t = 1{本轮（或本控制窗口）发生 F0/F1 失效}。按 ACI 更新
```
λ_{t+1} = Π_[λ_min, λ_max] ( λ_t + γ (α − e_t) ),
```
并用 λ_t 门控 v9 的分块攻击性（K_eff、速度、风险阈值）。该律不假设数据可交换、不依赖前向模型误差 β；任意序列下长期失效率的偏差被 O(1/(γT)) 控制（引理 88）。可把它理解为“用真实失效事件反向调参的在线保险丝”。

**P15 竞赛效用退化律（Competition-Utility Degradation, CUG）**
定义失效类 F0（灾难/DQ）≺ F1（不可恢复）≺ F2（可重试）≺ F3（性能损失），以及效用向量
```
U(e) = ( 1{F0 未发生}, 1{F1 未发生}, 1{F2 未发生}, score(e) )
```
按字典序比较。任一退化算子 D 必须满足**效用不劣性**：
```
U(D_v10(s)) ⪰_lex U(D_v9(s)),
```
其中 D_v9 是 v9 的中立元退化。构造上通过“可选回退集是 v9 动作集的超集 + 安全类处于字典序最高优先级”得到（引理 91）。F0 是硬约束：任何用得分交换 F0 风险的候选一律拒绝；SPF 只在 F2/F3 触发。

## 3. 与基线的接口（如何退化）

- **ACRC 失效**（校准数据耗尽 / λ 触及边界且无解）⇒ λ_t 冻结为 v9 门控常数，可靠证书降级为 v9 的 β 假设；
- **RBA 失效**（故障树不完整 / 求解超时）⇒ q_m 均分、冗余关闭，退化为 v9 单版本契约表；
- **CUG 失效**（效用表缺失 / 分类器不可信）⇒ 目标退回 E[score]，失效分类退化为 v9 的“安全/非安全”二分；
- **v9 AC 失效** ⇒ K_eff ← 1，逐步执行，等价 v8 决策粒度；
- **v9 MW 失效** ⇒ 切换 v8 手写网关路径，等价 v8 集成方式；
- **v9 ID 失效** ⇒ 全模块 active、归因冻结，等价 v8 全模块常开；
- **v8 的 DA/SPR/Cal 失效** ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；
- **全部失效** ⇒ 完整退回 v6。

## 4. 预期贡献

1. **分布无关的竞赛可靠证书**：ACRC 用 ACI 把“平均安全”升级为“长期灾难率 ≤ α”，并在非平稳赛程下给出 O(1/(γT)) 的有限时间偏差界，直接替换 v9 对前向模型误差 β 的依赖；
2. **可靠度预算与共同原因感知的冗余**：RBD 化的契约表 + 杠杆贪心分配 + 共同原因折减，使“多加一个 N-版本”是否值得变成一个可计算的边际收益问题；
3. **竞赛效用格与得分保持回退**：把退化从“安全不崩”推进到“退化仍拿分”，并给出相对 v9 的字典序不劣性证明；
4. **轮次级时间-可靠度兑换**：RBS 把赛会预算、剩余时间与检查点-重启统一进一个约束优化，覆盖资格赛/决赛的不同风险偏好；
5. **实验 E571–E590**：覆盖 ACI 校准、分布漂移、共同原因、冗余扫描、得分保持回退、轮次预算、CVaR 与端到端锦标赛。

## 5. 本轮最大风险

**一句话**：所有可靠性证书都以“校准回合与竞赛回合来自同一或慢变分布”为隐含前提，而竞赛的决赛按设计就是最不代表性、对手最强、场地最陌生的一轮——若 ACI 的步长 γ 追不上这次跳变，系统会在最需要保守的时刻仍带着上一轮校准出的乐观 λ，即“可靠证书在最关键的决赛上最不可信”。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| e ~ P_arena | 竞赛回合；P_arena 为含光照、布局、对手策略、裁判时序的隐藏元分布 |
| F0 ≺ F1 ≺ F2 ≺ F3 | 失效分类：灾难/DQ、不可恢复、可重试、仅性能损失（效用递增） |
| U(e) = (¬F0, ¬F1, ¬F2, score(e)) | 回合效用向量，按字典序比较 |
| CRS_α(π) | 竞赛可靠分：约束 P(F0∪F1) ≤ α 下的 CVaR_α(score) |
| ε_tot, ε_run, q_m | 赛会/单轮/模块灾难概率预算，Σ_m q_m ≤ ε_run，K_rounds·ε_run ≤ ε_tot |
| R_m, R_sys | 模块与系统可靠度；RBD 串联 Π、并联 1−Π(1−·) 组合 |
| c_m | 模块共同原因失效概率（N-版本同时失效） |
| L_m | 可靠性杠杆：(∂R_sys/∂R_m)·(ΔR_m/cost_m) |
| λ_t ∈ [λ_min, λ_max] | ACRC 攻击性参数，单调影响 K_eff/速度/风险阈值 |
| γ, α, e_t | ACI 步长、目标灾难率、观测失效指示 |
| T = {τ_i} | 任务组合（得分保持回退的候选集） |
| T_run, Δ_cp | 单轮时间预算、检查点周期 |

**新增定义 540（竞赛回合与元分布 CompetitionEpisode）** 回合 e 由隐藏参数 θ_e ~ P_arena 生成（场地纹理、光照、障碍布局、对手策略、裁判容差）。竞赛可靠度 R(π) = P_{e~P_arena}(e 内无 F0/F1)。**注意 P_arena 跨轮可漂移**，且资格赛/决赛的分布不同；本轮不假设回合可交换。

**新增定义 541（失效分类学 FailureTaxonomy）** 对回合内事件流定义最坏类：
```
class(e) = min_{ev ∈ e} rank(ev),   rank(F0)=0, rank(F1)=1, rank(F2)=2, rank(F3)=3.
```
rank 越大越好；F0 为撞人/撞物/越界/超时导致 DQ，F1 为不可恢复任务终止，F2 为可重试失败（掉物、定位丢失但可重定位），F3 为仅变慢/少分。

**新增定义 542（竞赛效用与可靠分 CompetitionUtility）**
```
U(e) = ( 1{class(e) ≥ 0}, 1{class(e) ≥ 1}, 1{class(e) ≥ 2}, score(e) ),
```
按字典序 ⪰_lex 比较。竞赛可靠分
```
CRS_α(π) = CVaR_α( score ),   s.t. P(F0) ≤ ε_tot 且 P(F1) ≤ α_major,
```
即先满足安全/完赛硬约束，再最大化下尾得分，而非 E[score]。

**新增定义 543（赛会可靠性预算 ReliabilityBudget）** 给定 K_rounds 轮，取
```
ε_run = ε_tot / K_rounds,     Σ_m q_m ≤ ε_run.
```
联合界给出 P(赛会任一 F0) ≤ K_rounds·ε_run = ε_tot。若不同轮风险不同（决赛更高），RBS 可重分配 ε_run^(r)，但始终保持 Σ_r ε_run^(r) ≤ ε_tot。

**新增定义 544（可靠度块图 ReliabilityBlockDiagram）** 节点为契约模块，边分串联/并联：
```
R_sys = Π_{m∈series} R_m · Π_{p∈parallel} (1 − Π_{v∈p}(1 − R_v)).
```
每模块多版本冗余 N_m 且共同原因概率 c_m 时，采用保守式
```
R_m^{true} = (1 − c_m) · (1 − (1 − R_m)^{N_m}).
```
RBD 由契约表自动生成：同一输出端口的多个候选实现为并联，跨端口依赖为串联。

**新增定义 545（可靠性杠杆 ReliabilityLeverage）** 在预算约束 Σ cost_m·N_m ≤ B 下，
```
L_m = (∂R_sys/∂R_m) · (ΔR_m^{(N)} / cost_m),
```
RBA 每步把下一单位预算投给 L_m 最大的模块（引理 92 给出贪心质量界）。

**新增定义 546（自适应保形可靠控制器 AdaptiveConformalReliability）**
```
e_t = 1{ 第 t 个校准窗口出现 F0 或 F1 }
λ_{t+1} = clip( λ_t + γ (α − e_t), λ_min, λ_max )
K_eff(t) = max(1, ⌊ K_max · λ_t · (1 − min(1, Δ_dom(t)/τ_dom)) ⌋)
```
λ 越大越激进（块更长、速度更高、风险阈值更松）。用 (λ_t, e_t) 的历史可在任意非平稳序列上给出长期率控制（引理 88）。初始 λ_0 可用校准集 D_cal 的 PAC 上界选择（引理 89）。

**新增定义 547（竞赛效用格与退化不劣性 CompetitionUtilityLattice）** 设 O_v9(s) 为 v9 在状态 s 的中立元退化可选动作集，O_v10(s) 为 v10 的回退集，构造上保证 **O_v9(s) ⊆ O_v10(s)**，且 F0 作为硬约束过滤：
```
O_feas(s) = { o ∈ O_v10(s) : ¬causes_F0(o, s) }.
D(s) = lexmax_{o ∈ O_feas(s)} U(o).
```
定义 D 相对 v9 **效用不劣**：U(D_v10(s)) ⪰_lex U(D_v9(s))。

**新增定义 548（得分保持回退 ScorePreservingFallback）** 任务组合 T 中每个备用行为 τ 带剩余时间可行域与下置信得分
```
V_τ^{LCB}(t_rem) = μ̂_τ(t_rem) − z_δ · σ̂_τ / √n_τ.
```
SPF 触发条件：主任务链失效且 class(e) ∈ {F2, F3}，且存在 τ 满足
```
V_τ^{LCB} > 0,  class(τ) ⪰ class(e),  time_needed(τ) ≤ T_run − t.
```
SPF 选 V_τ^{LCB} 最大者；F0/F1 不触发 SPF，直接安全停驻或按 RBS 重启。

**新增定义 549（轮次预算与检查点 RoundBudgetCheckpoint）** 给定剩余轮次 R、剩余时间 T_run、单次重启代价 c_r，检查点间隔
```
Δ_cp* = argmax_{Δ_cp} P( finish within T_run ; Δ_cp, c_r, 失效强度 μ̂ ).
```
在几何失效假设下闭式解 Δ_cp* = √(2 c_r / μ̂)（经典检查点最优解），RBS 用 μ̂ 的滑窗估计在线更新，并按当前名次在“保完赛”与“争高分”之间选择 ε_run^(r)。

**定义 493–539**（六层指标、MetaWeight、DA-OTL、软证书、AC/MW/ID）全部继承 v9，语义不变。

# IP-357 AdaptiveConformalReliabilityController：分布无关的在线可靠校准
class AdaptiveConformalReliabilityController:
    def __init__(self, alpha=0.01, gamma=0.02, lam_min=0.2, lam_max=1.0,
                 lam0=0.8):
        self.alpha, self.gamma = alpha, gamma
        self.lam_min, self.lam_max = lam_min, lam_max
        self.lam = lam0
        self.history = []                       # (lam, e) 供审计/离线复算

    def gate(self):
        return self.lam                          # 供 K_eff / 速度 / 风险阈值使用

    def observe(self, catastrophe_or_major_failure):
        e = 1.0 if catastrophe_or_major_failure else 0.0
        self.lam = min(self.lam_max,
                       max(self.lam_min,
                           self.lam + self.gamma * (self.alpha - e)))
        self.history.append((self.lam, e))

    def certified(self):
        # 引理 88：|平均失效率 − α| ≤ (λ_max−λ_min)/(γT)
        T = len(self.history)
        if T == 0:
            return float('inf')
        return (self.lam_max - self.lam_min) / (self.gamma * T)


# IP-358 ReliabilityBudgetAllocator：故障树 → 预算 → 冗余/重启
class ReliabilityBudgetAllocator:
    def __init__(self, contracts, eps_tot, rounds, cm, cost_ms):
        self.contracts, self.eps_tot, self.rounds = contracts, eps_tot, rounds
        self.cm = cm                             # 共同原因因子 c_m
        self.cost_ms = cost_ms
        self.rbd = self._build_rbd_from_contracts()

    def _build_rbd_from_contracts(self):
        # 同输出端口候选 → 并联；跨端口依赖 → 串联
        return build_rbd(self.contracts)

    def per_run_budget(self, remaining_rounds):
        return self.eps_tot / max(1, remaining_rounds)

    def allocate(self, eps_run):
        w = fault_tree_cutset_weights(self.rbd)   # 最小割集权重
        z = sum(w.values())
        q = {m: eps_run * w[m] / z for m in w}
        return q

    def effective_reliability(self, m, N):
        R = 1.0 - self.q[m]
        return (1.0 - self.cm.get(m, 0.0)) * (1.0 - (1.0 - R) ** N)

    def add_redundancy(self, q, budget_ms):
        self.q = q
        N = {m: 1 for m in q}
        while budget_ms > 0:
            gains = {}
            for m in q:
                dR = (self.effective_reliability(m, N[m] + 1)
                      - self.effective_reliability(m, N[m]))
                gains[m] = dR / self.cost_ms[m]
            m = max(gains, key=gains.get)
            if gains[m] <= 0 or self.cost_ms[m] > budget_ms:
                break
            N[m] += 1
            budget_ms -= self.cost_ms[m]
        return N


# IP-359 CompetitionUtilityGovernor：效用格 + 得分保持回退
class CompetitionUtilityGovernor:
    RANK = {'F0': 0, 'F1': 1, 'F2': 2, 'F3': 3}

    def __init__(self, portfolio, delta=0.05):
        self.portfolio, self.delta = portfolio, delta

    def classify(self, events):
        return min((self.RANK[ev] for ev in events), default=3)

    def utility(self, cls, score):
        return (int(cls >= 0), int(cls >= 1), int(cls >= 2), score)

    def select(self, state, failed_module, t_rem):
        options = v9_degradation_options(state, failed_module)  # 保证 v9 ⊆ v10
        cls_now = self.classify(state.recent_events)
        if cls_now in (2, 3):                                     # F2/F3 才可 SPF
            options += self._spf_options(state, cls_now, t_rem)
        options = [o for o in options if not o.causes_F0(state)]  # F0 硬约束
        return max(options, key=lambda o: self.utility(o.cls, o.score))

    def _spf_options(self, state, cls_now, t_rem):
        out = []
        for tau in self.portfolio:
            lcb = tau.mean_score(t_rem) - self._z() * tau.std_score(t_rem)
            if (lcb > 0 and self.RANK[tau.cls] >= cls_now
                    and tau.time_needed() <= t_rem):
                out.append(tau.as_option(lcb))
        return out

    @staticmethod
    def _z():
        return 1.645                                            # 95% 单侧


# IP-360 RoundBudgetScheduler：轮次预算 + 检查点
class RoundBudgetScheduler:
    def __init__(self, eps_tot, rounds_left, restart_cost_s, mu_hat):
        self.eps_tot, self.rounds_left = eps_tot, rounds_left
        self.c_r, self.mu_hat = restart_cost_s, mu_hat

    def eps_run(self, rank_pressure):
        # 名次压力高 → 本轮略放宽（仍满足 Σ ε_run ≤ ε_tot 的总账）
        base = self.eps_tot / max(1, self.rounds_left)
        return min(0.5 * self.eps_tot, base * (1.0 + 0.5 * rank_pressure))

    def checkpoint_interval(self):
        return (2.0 * self.c_r / max(self.mu_hat, 1e-6)) ** 0.5

## 4. 推导

**引理 87（赛会可靠性联合界）** 设第 r 轮灾难事件 E_r，模块失效事件 E_{r,m}，且 E_r ⊆ ∪_m E_{r,m}。若 P(E_{r,m}) ≤ q_m 且 Σ_m q_m ≤ ε_run，则
```
P(∪_{r=1}^{K} E_r) ≤ Σ_r Σ_m q_m = K·Σ_m q_m ≤ K·ε_run ≤ ε_tot.
```
证明：布尔不等式逐层展开。∎
*注*：共同原因事件不满足“单模块失效”分解，必须显式计入 q_m 或用 RBD 并联式（引理 90）扣除，否则联合界乐观。

**引理 88（ACI 长期灾难率控制）** 在定义 546 的更新下（暂不考虑 clip），有恒等式
```
λ_{T+1} = λ_1 + γ Σ_{t=1}^{T} (α − e_t)
⇒ (1/T) Σ_{t=1}^{T} e_t = α + (λ_1 − λ_{T+1}) / (γT).
```
故若 λ_t 始终落在 [λ_min, λ_max]，则
```
| (1/T)Σ e_t − α | ≤ (λ_max − λ_min) / (γT) = O(1/(γT)).
```
证明：对更新式求和并移项；有界性给出分子上界。clip 只减小 λ 的移动幅度，故在未触界区间结论不变；触界时用饱和 ACI 的修正界（把 O(1/(γT)) 替换为 O(1/(γT) + 触界时长/T)）。∎
该引理**不要求回合可交换**，这正是竞赛跨轮分布漂移所需。

**引理 89（有限样本校准）** 设 n 个校准回合可交换，经验灾难率 R̂_n。则对任意 δ ∈ (0,1)，
```
P( R > R̂_n + sqrt( log(1/δ) / (2n) ) ) ≤ δ.
```
证明：Hoeffding 不等式。∎
该式给出 λ_0 的保守初值；一旦 exchangeability 在赛程中失效，就交给引理 88 的在线机制接管。二者组合：**离线 PAC 冷启动 + 在线 ACI 兜底**。

**引理 90（共同原因下的冗余保守界）** 若模块 m 的 N 个版本各自可靠度 R_m，共同原因失效概率 c_m（发生时所有版本同时失效），则真实可靠度
```
R_m^{true} = (1 − c_m)(1 − (1 − R_m)^N) ≤ 1 − (1 − R_m)^N,
```
朴素并联式高估量为 `c_m · (1 − (1 − R_m)^N)`。证明：按全概率对共同原因事件分解；共同原因发生时并联结构不提供任何冗余。∎
**推论**：当 `c_m ≥ 1 − R_m` 时，增加版本数的边际增益可能为负，RBA 必须把这些边的增益截断为 0。

**引理 91（效用不劣性）** 若 v10 的可行回退集是 v9 的超集（O_v9(s) ⊆ O_v10(s)），且 F0 作为硬约束在两者的可行集上一致过滤，则
```
U(D_v10(s)) ⪰_lex U(D_v9(s)).
```
证明：字典序最大化是保序的：对任意集合 S ⊆ T，`max_lex(T) ⪰_lex max_lex(S)`。硬约束过滤对 S、T 同步施加，故包含关系保持。∎
这是 v9“中立元严格退化”思想在竞赛效用维度的推广：**新增模块只能扩大可选集，不能强迫选择更差的退化**。

**引理 92（可靠度分配的贪心质量界）** 令 `log R_sys(N) = Σ_m log R_m(N_m)`，其中 `R_m(N)` 关于 N 单调递增且边际递减（由引理 90 的 (1−(1−R)^N) 形式给出，扣 c_m 后仍成立）。则 log R_sys 是单调子模函数；在基数约束下，按边际增益贪心分配冗余达到 (1−1/e) 近似；在一般背包（任意 cost_ms）下达到 1/2 近似。证明：每个 `log R_m` 是递增凹函数，离散边际递减 ⇒ 子模；和保持子模；套用子模最大化贪心界。∎
