# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「单模型多任务」×「通用机器人平台」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**单模型多任务 + 通用平台**。v9 已把“模块”契约化、把“执行”分块化，但仍留下三种债：
> - **模型债**：14 个 IP 模块与多个学习器各自持有参数，任务一多就复制整套栈；
> - **平台债**：换一台机器人就要重做标定、重训模型、重签安全证书；
> - **证书债**：安全证书按“任务×平台”逐格签发，组合爆炸且无法复用。
> 本轮必须用**认证格 + 干扰预算 + 具身护照**把这三债变成可类型检查、可证明迁移、可拒绝执行的工程对象；任何新组件失效时必须退回 v9 的 (τ,E) 专用模型，而不是让共享模型“自由发挥”。

## 0. 直觉与动机

**灵感 1（单模型多任务 → 共享骨干 + 任务隔离膜）**
直觉：既然视觉编码、动力学常识、抓取先验在不同任务间大量共享，就不该为每个任务复制一套网络。一个共享骨干 f_θ 加小适配器 φ_τ，条件化于任务 token，理论上能用一份参数服务全部任务，还能零样本组合。但“共享”会引入新的安全敌人：**负迁移/任务干扰**——任务 A 的梯度可能把任务 B 的安全裕度吃掉。核心创新：**任务隔离膜（Task Interference Membrane, TIM）**——在线估计任务对干扰 I_{τ,τ'}，只在组内累计干扰 I_G(τ) ≤ η 的兼容任务间共享；一旦超预算就把隔离级别从“共享骨干+适配器”升级到“冻结骨干+独立适配器”再到“独立模型（≡v9）”。任务切换只允许发生在 v9 动作块的边界或中止点，绝不中块切任务——**P13 干扰预算律**。

**灵感 2（通用机器人平台 → 具身护照 + 能力类型）**
直觉：通用平台不是“一个网络直接输出所有机器人的关节命令”，而是“一个受约束的模型在具身护照允许的范围内实例化”。不同具身的动作空间、动力学、传感器、安全包络都不同；把轮式底盘的任务直接搬到人形上，最先失效的不是策略而是**能力假设**。核心创新：**具身护照（Embodiment Passport, EP）** E=(A_E, f_E, C_E, Ω_E, L_E, Σ_E)，把“能做什么、动力学多快、安全包络多大、延迟多少”写成可检查的元数据；**能力类型检查** C_τ ⊆ C_E ∧ Ω_τ ⊆ Ω_E 在执行前失败即**拒绝**（fail-closed），而不是让模型“尽力而为”。跨具身复用证书需要**迁移误差界** ε_E ≤ 剩余证书余量；否则退回该具身的 v9 专用控制器——**P14 护照与能力类型律**。

**灵感 3（合成 → 任务×具身认证格）**
直觉：把上面两者相乘，就得到一张二维认证格 L = T × E。真实系统只可能在少数格子上有数据；单模型多任务的泛化能力恰恰会诱导我们“从邻居格子外推”。核心创新：**认证格（Certification Lattice, CL）**——每个格子 (τ,E) 有独立状态 {certified, transferable, unverified}；只有 certified 或满足迁移界的 transferable 格子才允许执行，unverified 格子一律 fail-closed 或退回 v9 专用模型。这把 v9 的“五级退化链”升级为**偏序格上的安全下降**，也把“通用机器人平台”从一句口号变成“可拒绝的证书集合”——**P15 认证格不推定律**。

## 1. 研究问题（轮次升级版）

- **Q1（单模型多任务的安全共享）**：在共享骨干下，如何用在线干扰估计与隔离膜，使任意任务组合都满足逐任务安全不变式？任务切换与 v9 块证书/中止点如何对齐才能不出现“中块换任务”的安全空洞？
- **Q2（通用平台的可移植安全）**：一个任务证书在什么具身护照、能力类型与迁移误差界下可以从具身 E 迁移到 E'？能力缺失时如何 fail-closed 而不是性能漂移？
- **Q3（认证格的稀疏外推边界）**：在任务×具身二维格上，如何只从已认证/可证明迁移的格子安全外推？什么条件下必须拒绝执行，而不是用“最近邻泛化”填补空格？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 干扰预算律（Task Interference Budget, TIM）**
对共享同一骨干的任务组 G，在线估计组内累计干扰 I_G(τ)=Σ_{τ'∈G\{τ}} I_{τ,τ'}；只有 I_G(τ) ≤ η 且 τ 在具身 E 上均有有效证书时才允许共享。超预算 ⇒ 隔离级别升级：L0 共享骨干+独立适配器 → L1 冻结骨干+独立适配器 → L2 独立模型（≡v9）。任务切换只允许在块边界或中止点之后；中块切换被 M₀ 硬检查拒绝。

**P14 具身护照与能力类型律（Embodiment Passport & Capability Typing, EPC）**
平台为每台具身签发护照 E=(A_E, f_E, C_E, Ω_E, L_E, Σ_E)；任务 τ 声明需求 (C_τ, Ω_τ, K_τ)。执行前置条件：
```
elig(τ,E) ⇔ C_τ ⊆ C_E ∧ Ω_τ ⊆ Ω_E ∧ L_E ≤ L_max(τ) ∧ A* ∩ A_E ≠ ∅
```
不满足即拒绝或降级到该具身可执行的子任务；能力检查器失效时默认“能力不存在”（fail-closed），绝不默认通过。

**P15 认证格不推定律（Certification-Lattice No-Extrapolation, CLN）**
安全信用只授予 certified 格子，或满足跨具身迁移条件 ε_E ≤ β − β_true 的 transferable 格子。unverified 格子：禁止执行原任务，只允许执行“保守影子策略”（v9 的 K=1 逐步 + 具身专用证书）或安全停驻。禁止用最近邻/插值把邻居格子的证书复制到空格子。

## 3. 与基线的接口（如何退化）

- 共享骨干 SPB 失效/超时 ⇒ 退回该 (τ,E) 的 v9 独立模型（隔离级别 L2），行为等价 v9；
- 任务适配器 φ_τ 失效 ⇒ 注入任务中立元（identity adapter / 任务专用头），等价 v9 该任务模型；
- 具身适配器/护照失效 ⇒ 停用跨具身迁移，退回该具身 v9 专用控制器；能力检查器失效 ⇒ fail-closed（不执行未显式认证能力）；
- 干扰估计失效 ⇒ I≡∞（所有任务视为不兼容），自动隔离到 L2，等价 v9；
- 认证格失效 ⇒ 全部格子标 unverified，退回 v9 逐格认证流程；
- 全失效 ⇒ 完整退回 v9 ACMD → v8 → v7 → v6。

## 4. 预期贡献

1. **任务干扰预算 + 隔离膜**：把“共享多少”从工程直觉变成可在线估计、可证明切换的连续旋钮，共享与隔离之间没有安全断崖；
2. **具身护照与能力类型**：把平台移植从“重训重签”变成“类型检查 + 有界迁移”，并给出 fail-closed 的能力缺失语义；
3. **认证格**：把 v9 的一维退化链升级为任务×具身二维偏序格，明确“只认证不推理”的安全边界；
4. **实验 E571–E590**：覆盖干扰矩阵、负迁移、任务切换、能力类型、跨具身迁移、遗忘门、未认证格拒绝、车队与长跑。

## 5. 本轮最大风险

**一句话**：单模型多任务 + 通用平台最大的诱惑是“从稀疏认证格外推”——干扰界 I_{τ,τ'} 和迁移界 ε_E 都只能由有限数据估计，而共享骨干在未见 (τ,E) 格子上输出的恰是“最流畅”而非“最保守”的动作；认证格最稀疏的地方，正是模型泛化最自信的地方，安全证书可能被“看起来合理”的跨格外推静默腐化。

**新增定义 540（任务契约 TaskContract）** τ=(S_τ,C_τ,Ω_τ,D_τ,Φ_τ,K_τ)。S_τ 为该任务的安全不变式（继承 v9 六层指标 M_τ，但跨任务只要求 M₀/M₁ 可比）；C_τ⊆𝒞 为能力需求；Ω_τ 为包络需求；D_τ 为任务分布；Φ_τ 为成功谓词；K_τ 为任务允许的最大块长（与 v9 K_max 取 min）。任务 τ 的 v9 块证书记 Ĉ_{t,τ}。

**新增定义 541（具身护照 EmbodimentPassport）** E=(A_E,f_E,C_E,Ω_E,L_E,Σ_E)：A_E 动作空间及关节/轮速限幅；f_E 动力学（用于迁移界）；C_E 能力集合；Ω_E 安全包络；L_E 端到端控制延迟；Σ_E 传感器套件与标定版本。护照由平台侧签发、版本化、只读；运行期篡改由护照校验和检测（E588）。

**新增定义 542（单模型多任务策略 SharedPolicy）**
```
π_θ(a | s, τ, E) = h_{φ_τ, ψ_E}( f_θ(s, e_E) ),   e_E = EmbToken(E)
```
f_θ 为共享视觉-本体感受骨干；φ_τ 为任务适配器（LoRA/Adapter，参数量 ≤3% 骨干）；ψ_E 为具身适配器（把规范动作 A* 投影到 A_E）；h 为任务头。整栈只有一份 f_θ，任务/具身各一份小适配器；相对“每任务×每具身一套模型”，参数内存约降 (N_T·N_E)/(N_T+N_E) 倍（见复杂度表）。

**新增定义 543（能力类型与可执行性 CapabilityTyping）**
```
elig(τ,E) ⇔ C_τ ⊆ C_E ∧ Ω_τ ⊆ Ω_E ∧ L_E ≤ L_max(τ) ∧ A* ∩ A_E ≠ ∅
```
`elig=false` ⇒ 拒绝执行原任务（可执行声明过的降级子任务 τ↓），不得由策略“尽力而为”。检查器自身失效时返回 false（fail-closed）。

**新增定义 544（任务干扰量 TaskInterference）** 对共享骨干的任务对 (τ,τ')：
```
I_{τ,τ'} = E_{s~D_τ}[ max(0, m_τ(s; θ) − m_τ(s; θ_{¬τ'}) ) ] / m̄_τ
```
其中 m_τ 为任务 τ 的安全裕度（v9 的 min(σ−τ_safe, ĝ_min−d_safe)），θ_{¬τ'} 为去掉 τ' 适配器/梯度贡献后的骨干。在线用配对消融回合估计（每 T_int 周期、H_int 回合，复用 ID 消融机制），只取上界；估计不确定时取 I=∞。组内累计干扰 I_G(τ)=Σ_{τ'∈G\{τ}} I_{τ,τ'}。

**新增定义 545（隔离膜 IsolationMembrane）** 隔离级别 L(τ,E)：
- L0：共享 f_θ + φ_τ + ψ_E；
- L1：共享 f_θ 冻结（不接收该任务梯度）+ 独立 φ_τ + ψ_E；
- L2：完全独立模型 π_{θ_{τ,E}}，即 v9 的 (τ,E) 专用模型。
升级规则：若 I_G(τ) > η 且 τ 仍在共享组，则把较弱者/新加入者升一级；降级需连续 H_iso 个消融回合 I_G ≤ η/2（迟滞防抖）。L0→L1→L2 是单调安全下降（引理 92）。

**新增定义 546（任务切换屏障 TaskSwitchBarrier）** 任务切换仅允许在以下时刻：
1. 当前 v9 动作块执行完毕（k=K_eff）；或
2. 当前块到达中止点 p* 并完成安全停驻；或
3. M₀ 硬检查触发紧急停驻。
切换时新任务必须满足 elig(τ',E) 且 CL(τ',E) ∈ {certified,transferable}，否则保持停驻。禁止中块切换；M₀ 硬检查拒绝任何 k<K_eff 且未停驻的切换请求。

**新增定义 547（跨具身迁移误差 TransferGap）**
```
ε_E = sup_{s∈S, a∈A*} || f_E(Proj_E(a), s) − f_{E0}(a, s) || + λ_L·|L_E − L_{E0}|
```
其中 E0 为证书签发具身，Proj_E 为规范动作投影。**迁移可行** ⇔ ε_E ≤ β − β_true（v9 证书剩余余量）∧ elig(τ,E) ∧ Ω_τ ⊆ Ω_E。不满足则 CL=unverified，需在该具身重新签发证书。

**新增定义 548（认证格 CertificationLattice）** CL: T×E → {certified, transferable, unverified}：
- certified：在该格子上有 v9 块证书且通过 v9 E566 类形式化检查；
- transferable：源格子 certified 且定义 547 迁移可行，迁移界随证书一起存证；
- unverified：其余一切（含迁移界未知、护照过期、能力元数据缺失）。
执行许可：Permit(τ,E) ⇔ elig(τ,E) ∧ CL(τ,E)∈{certified,transferable}。unverified 只允许“影子执行”：K=1、v9 具身专用证书，或安全停驻。

**新增定义 549（遗忘回归门 ForgettingGate）** 共享骨干的在线更新 Δθ 被接受 ⇔ 对所有已 certified 格子 (τ,E) 的验证裕度满足
```
m_τ(E; θ+Δθ) ≥ m_τ(E; θ) − δ_τ
```
否则回滚 Δθ（或只更新该任务适配器 φ_τ 进入 L1）。δ_τ 由任务风险等级给定（安全关键 δ=0）。该门把“持续学习”限制为“不降低任何已认证格子的安全下界”。

## 2. 形式化定义（要点与升级）

- 定义 493/495/521/524 继承 v9 不变；任务 τ 的指标层级记 M_τ，跨任务只要求 M₀/M₁ 可比。
- **升级定义 496（v10 软证书）** δ_trigger 增加四项：
```
elig(τ,E) ∧ CL(τ,E)∈{certified,transferable} ∧ I_G(τ)≤η ∧ ε_E ≤ β−β_true
```

## 4. 推导

**引理 87（能力类型可靠性 / fail-closed 安全）**
若 elig(τ,E)=true，则执行 τ 所需的能力与包络均被 E 的护照覆盖；若 elig=false 且系统按定义 543 拒绝执行，则不存在“能力幻觉”导致的不安全动作。证明：elig 是 C_τ⊆C_E、Ω_τ⊆Ω_E、L_E≤L_max、A*∩A_E≠∅ 的合取；执行许可 Permit 还要求 CL 非 unverified；检查器异常返回 false，故拒绝对所有不确定情形单调成立。∎

**引理 88（干扰预算下的多任务安全）**
设共享组 G 内对每个 τ 有 I_G(τ)=Σ_{τ'∈G\{τ}} I_{τ,τ'} ≤ η，且 τ 在 E 上持有 v9 块证书，其安全裕度 m_τ ≥ η。则共享骨干下执行 τ 的真实安全裕度 m_τ^shared ≥ m_τ − η ≥ 0。证明：由定义 544，I_{τ,τ'} 直接上界“移除 τ' 后 τ 裕度的相对变化”；从 G 逐个移除其他任务到单任务，最多累计 I_G(τ) 的裕度损失，故 |m_τ^shared − m_τ| ≤ Σ_{τ'≠τ} I_{τ,τ'} ≤ η；v9 证书保证 m_τ≥0，故 m_τ^shared≥0。∎

**引理 89（跨具身证书迁移）**
设源具身 E0 上 v9 证书在信任域内成立，真实前向误差 ≤β_true；若 ε_E ≤ β−β_true，且 elig(τ,E)、Ω_τ⊆Ω_E，则同一块证书在 E 上仍保守有效（ĝ_min 向下、ê_max 向上各修正 ε_E）。证明：复合误差 ≤β_true+ε_E≤β；把 ε_E 吸收进证书余量后逐项复引理 82；包络包含保证停车不变式的距离/力上界在 E 内可执行。∎

**引理 90（切换屏障无中块安全空洞）**
若任务切换仅在块边界/中止点/紧急停驻发生，则任一执行中的块只属于单一 (τ,E) 格；块内安全由引理 82（及 88/89）保证；切换点处系统已停驻或块已耗尽，不存在“半块属于 τ、半块属于 τ'”的混合动作。证明：定义 546 的守卫是 M₀ 硬检查的一部分；中块切换请求被拒并触发停驻。∎

**引理 91（遗忘门的安全单调性）**
设初始所有 certified 格子的安全裕度 m_τ(E;θ_0)≥0。若每次共享更新 Δθ 仅在满足定义 549 的回归容差时被接受，否则回滚/隔离，则对任意已 certified 格子，裕度下降不超过累计 δ_τ；特别地 δ_τ=0 的安全关键任务裕度序列单调不降。证明：对更新次数归纳；接受时 m_n≥m_{n-1}−δ_τ，拒绝时 m_n=m_{n-1}；δ_τ=0 时接受步也不降。∎

**引理 92（隔离梯度的等价与安全序）**
L2 隔离策略与 v9 的 (τ,E) 专用模型逐位等价（同一权重与代码路径）；L1 冻结共享骨干、只改变表征而不改变 v9 证书的输入-输出契约，若干扰界成立则安全裕度损失 ≤η；L0 在 L1 基础上再加有界干扰。故 L0≽L1≽L2 在“共享收益”上递减，在“安全保证”上递增；L2 即 v9，任意隔离级别都不劣于 v9。∎

**引理 93（OMNI 的严格退化等价）**
按退化链 Level-0→5，每次失效映射为：任务干扰超预算→该任务 L2（引理 92）；护照/迁移失效→该格 v9 专用控制器（引理 89 的逆否）；认证格/能力检查失效→fail-closed 影子执行（定义 548）；SPB/TIM 失效→全任务 L2；v9 内部失效→v9 五级链（引理 83）。故 OMNI 最坏行为与 v9 逐位等价，绝不出现“共享模型自行降级”的未定义行为。∎
