# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「评测指标」×「语义地图」）

> 第 59 轮把执行层物理接进了安全论证链：BUQ 修正似然、ERTC 契约守界、EEIS 编译阻抗、CLEP 双向闭环、PCE+++ 四预算。但整个体系仍默认一个未经审视的前提：**「我们能评测它」**。所有 δ_f、ECE、证据门、证书，最终都要落在「成功率」「最差组风险」「力跟踪分位数」这些**评测指标**上；而评测指标目前是**离线、全局、标量**的——它在某个固定测试集上取平均，既回答不了「语义地图的哪一个区域、哪一类语义、样本是否足够」，也回答不了「指标本身是否被优化过程反向腐蚀」。**语义地图**恰好提供了缺失的那根坐标轴：它把「哪里」与「什么」结构化，使评测从「一个数」变成「一张可审计的场」。本轮核心命题：**「把评测指标空间化、分层化、可归因、反腐蚀——让『证据承诺』同时成为『评测承诺』」**。

核心矛盾：
- **H32（聚合谬误·语义分层缺失）**：全局 ECE / 成功率是**按评测分布加权平均**的标量。安全关键语义（玻璃幕墙、湿滑地面、台阶边缘）在任务分布中稀有，但在失败代价中占主导；全局指标看起来很好，恰恰因为它把稀有高危语义的失败**平均掉了**。没有语义分层，δ_f 的联合界无法落到「哪一类语义」上，部署认证形同虚设。
- **H33（归因混淆·语义地图标签噪声）**：指标要按语义归因，必须依赖语义地图的标签。但地图本身是不完美的：把「台阶」误标为「地面」、把「玻璃」误标为「墙面」，会把某类失败**记到错误的语义类头上**。若忽略混淆矩阵，分层指标是真实指标的**有偏卷积**——去纠正它既可能是「洗白」，也可能是「冤枉」，必须给出**部分识别区间**而非点估计。
- **H34（Goodhart 腐蚀·评测与行动未分离）**：一旦在线系统能同时决定「做什么」与「在哪里被评测」，它就会学会**优化指标而非优化任务**：多采样容易得分的地形、回避高风险的评测区域、选择对自己有利的日志时机。评测指标不是免费的观测，而是一个**可被策略反作用的目标**；没有「协议冻结 + 采样/评分分离 + 变形审计」，越先进的证据层越会自欺。

## 0. 直觉与动机

**灵感 1（语义地图 → 指标场 SMA）**
直觉：语义地图不应只是「哪里是什么」的标签图，而应成为**「哪里、对什么语义、我们测得怎样」的指标账本**。在语义区域的每个节点 r 上，除了语义信念 b_r，再挂载一个**指标画像** M_r =（ECE_r、成功率 SR_r、力 99% 分位数、跟踪误差 99% 分位数、时延、有效样本量 n_r^eff、置信区间宽度 κ_r）。于是「全局成功率」不再是独立的一个数，而是任务分布 p_task 对指标场的**回拉（pullback）**：M_glob(p_task)=Σ_r p_task(r)·M_r。关键洞见：**评测指标与语义地图是对偶的**——没有指标场的地图只是「画得像」；没有空间归因的指标只是「平均出来的幻觉」。回拉立刻暴露聚合偏差：当评测分布 p_eval≠任务分布 p_task，全局指标的偏差被有界地量化为 B·TV(p_task,p_eval) + 未覆盖质量。

**灵感 2（评测指标 → 语义分层最差组风险 WGES）**
直觉：安全部署不该问「平均失败率多少」，而该问「**在每一类我们会在意的语义上，最坏的那一类失败率是多少**」。定义语义分层风险 R_c=P(fail | 真实语义=c)，评测目标从 E[R] 换成 **R_wg=max_{c:p_task(c)≥p_min} R_c**。每类用 Clopper–Pearson/经验 Bernstein 给有限样本上界，多重比较用分层 Holm/Bonferroni 控制族错误率；某类样本不足 n_min 则记**覆盖债务（coverage debt）**，该语义类不得进入承诺。于是「我们又在一个新语义类上成功了」不再靠嘴说，而是靠**该类别的置信上界**说话。

**灵感 3（语义地图标签噪声 → 归因去卷积 SARA）**
直觉：设地图报告类 ĉ、真实类 c，混淆矩阵 C_{ĉc}=P(ĉ|c)。若指标以真实类为条件、且与报告误差条件独立，则**报告出的分层指标是真实指标的线性像**：m_obs=C·m_true。直接反解 C 逆矩阵在病态时会把噪声放大成谎言，正确做法是**部分识别**：求集合 M={m∈[0,1]^|C| : ‖C·m−m_obs‖_∞≤ε_map}，报告每类的区间 [m_c^-,m_c^+]。区间过宽 ⇒ 归因不可判定 ⇒ 必须**加标注探针**或**合并语义类（coarsening）**。这把「地图不准导致指标不可信」从定性担忧变成了可计算的区间与可执行的动作。

**灵感 4（合流 → 评测-行动分离 PEP 与影子评测）**
直觉：反 Goodhart 的唯一可靠办法不是「更聪明的指标」，而是**制度性分离**。评测协议 Π_eval=（指标定义、测试分布、标注规则、版本）**冻结且版本化**；执行策略 π 只能：① 从任务驱动动作的日志做 off-policy evaluation；② 发起显式「校准探针」，其数据走**影子通道**、绝不进入任务奖励与规划目标；③ 查询「去哪里评测」，但永不改变「如何评分」。**双钥匙规则**：指标更新需要（观测证据 ∧ Π_eval 版本匹配）同时成立，否则标记 provisional。再加**变形审计**：扰动无关变量不应改变得分、改善真实状态不应降低得分、重标语义类应按混淆矩阵一致地改变分层指标——违反即判「指标被腐蚀」。

**灵感 5（预算耦合 → B_eval 与 PCE++++）**
直觉：评测不是免费的：校准探针消耗接触、标注消耗人力、指标计算消耗算力、覆盖不足积累「债务」。第 59 轮已有 B_probe/B_ft/B_ux/B_exec，本轮新增 **B_eval=(N_calib, Coverage_debt, Label_budget, Eval_compute)**。VOI 中显式加入**评测价值** voi_eval(r)=E[ΔU_atlas(r)]·p_task(r)−cost_eval(r)，但它**只决定「校准探针采样在哪里」**，动作仍由任务 VOI 决定（评测影子）。预算耗尽 ⇒ 指标转 provisional、未覆盖语义类强制保守——**不允许用「没测过」冒充「没问题」**。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（语义指标图谱 SMA）** 语义地图 S=(V,E,{b_r},{g_r})，b_r∈Δ(C) 为语义类信念、g_r 为几何。指标图谱 A=(S,{M_r},{κ_r})，其中 M_r=(ECE_r, SR_r, Q_{0.99}(F)_r, Q_{0.99}(e)_r, L_r, n_r^eff)，κ_r 为由 n_r^eff 与 bootstrap 区间宽度给出的置信度。部署全局指标定义为任务分布下的回拉：M_glob(p_task)=Σ_{r∈V} p_task(r)·M_r。**聚合偏差界**：若每个 M_r∈[0,B]，则
```
|M_glob(p_task) − M_glob(p_eval)| ≤ B·( TV(p_task,p_eval) + p_task(V_uncovered) )
```
其中 TV(p,q)=½Σ_r|p(r)−q(r)|。因此「全局指标涨了」必须同时报告 p_task、p_eval 与覆盖集，否则不可解读。

**定义 154（语义分层最差组风险 WGES）** 对语义类 c∈C，R_c=P(fail|真实语义=c)。评测目标为 R_wg=max_{c:p_task(c)≥p_min} R_c，而非 E_{c~p_task}[R_c]。给定每类 n_c 个 i.i.d. 样本与经验风险 R̂_c，取单侧上界 U_c(α/(2m))（Clopper–Pearson 精确界或经验 Bernstein 界，m=|C|），要求对每个 c：U_c≤δ_c。若存在 p_task(c)≥p_min 但 n_c<n_min，则该类记为**覆盖债务**，认证结果只能是「未认证」。分层 Holm 用于在「声称所有类达标」时控制族错误率 ≤α。

**定义 155（指标有效性证书 MVC）** 指标 μ 的证书 MVC_μ=(construct, operationalization, Π_eval, label_rules, I, D_audit, ε_tol, version, expiry)。其中 I 为一组**变形不变式**：
```
(I1) 无关扰动不变：T_nuisance(x)（光照/传感器噪声/无关物体）⇒ |μ(T_nuisance(x))−μ(x)| ≤ ε_tol
(I2) 单调性：真实状态变好 ⇒ μ 不应变差（允许 ε_tol 容差）
(I3) 标签敏感一致：语义类重标 c→c' ⇒ 分层指标变化与混淆矩阵 C 一致
(I4) 反事实不变：与任务决策无关的日志裁剪/重排不改变 μ
```
在 D_audit 上全部满足才判 valid；否则指标为 **provisional**，禁止进入证据门（同第 57 轮 EV 门禁精神）。

**定义 156（语义归因去卷积 SARA）** 设真实类 c、地图报告类 ĉ，混淆矩阵 C_{ĉc}=P(ĉ|c)（由地图模块在标注校准集上估计并版本化）。若指标条件于真实类、且与报告误差条件独立，则报告分层指标 m_obs=C·m_true。**部分识别集合**：
```
M(C,m_obs,ε_map) = { m∈[0,1]^|C| : ‖C·m − m_obs‖_∞ ≤ ε_map }
m_c^- = min_{m∈M} m_c ,   m_c^+ = max_{m∈M} m_c
```
每类区间由线性规划在 O(|C|³) 内求出。规则：(S1) 区间宽度 >w_max ⇒ 归因不可判定，触发加标注探针或 coarsening；(S2) 认证只使用区间上界 m_c^+ 参与风险界（保守）；(S3) C 的估计误差本身以 ε_map 吸收，C 版本变更即回溯历史指标。

**定义 157（评测-行动分离 PEP 与影子评测）** 评测协议 Π_eval 一旦登记即冻结（版本哈希化），执行策略 π 的动作选择函数只依赖任务 VOI，不依赖任何 Π_eval 的评分结果。显式校准探针数据写入 **Shadow(Π_eval) 通道**，该通道对奖励/规划**不可见**。**双钥匙规则**：update_metric(r,ev) 成立当且仅当 `ev.protocol_hash == Π_eval.hash ∧ MVC_μ.valid ∧ ev.channel∈{task-log, shadow}`；否则标记 provisional 并记录污染审计。**污染检测**：若 π 对 Π_eval 的查询频率、采样区域分布与任务 VOI 的可解释预测偏离 >θ_pollute，或变形不变式在某审计批上失效 ⇒ 触发「指标腐蚀」警报，回滚该指标至上一 valid 版本。

**定义 158（评测预算 B_eval 与 PCE++++）** B_eval=(N_calib, Coverage_debt, Label_budget, Eval_compute)。评测价值：
```
voi_eval(r) = E[ΔU_atlas(r)]·p_task(r) − cost_eval(r)
ΔU_atlas(r) = U(κ_r) − U(κ_r^+)     # 置信区间收窄带来的下游决策效用增益
cost_eval(r) = λ_calib·1[r 需校准探针] + λ_label·1[r 需人工标注] + λ_comp·compute(r)
```
约束：voi_eval 只用于在**已由任务 VOI 判定可执行的探针集合**内选择校准采样位置；不得改变动作类型、接触力度或承诺时机。B_eval 耗尽 ⇒ 对应区域指标转 provisional，证据门对未认证语义类返回 `reject(coverage_debt)`。

**定义 159（评测证书 J_eval 与 JCPS+++）** J_eval=(Π_eval_version, A_hash, {U_c, m_c^-, m_c^+}_{c∈C}, coverage_map, C_hash, MVC_set, pollution_log, drift_log, provisional_flags)。JCPS+++ 在 JCPS++ 末尾追加 J_eval 摘要与 coverage_debt 标量。

**定义 160（联邦语义指标对齐 CEB+++++）** 跨站点/跨本体评测只在**语义类与地图配准对齐**后进行：要求类覆盖重叠 ≥ρ_min、混淆矩阵可估、且只比较「同类同语义」的分层指标（附覆盖债务）。禁止直接比较原始全局指标；跨域迁移需给出 confusion-aware 的校准映射 T_{A→B}: m^A_true ↦ m^B_true 及其不确定区间。

### IP-152 SMA（语义指标图谱）

```python
class SemanticMetricAtlas:
    def __init__(self, semantic_map, protocol, classes):
        self.S = semantic_map              # V, E, b_r, g_r
        self.Pi = protocol                 # frozen, versioned
        self.C = classes
        self.M = {r: MetricProfile.empty() for r in semantic_map.V}
        self.n_eff = {r: 0 for r in semantic_map.V}

    def update(self, region, ev):
        # 双钥匙：协议版本匹配 + MVC 有效 + 通道合法
        if ev.protocol_hash != self.Pi.hash:
            return mark_provisional(region, "protocol_mismatch")
        if not self.Pi.mvc[ev.metric].valid:
            return mark_provisional(region, "mvc_invalid")
        p = self.M[region]
        # 指数遗忘的有效样本量（非平稳环境）
        self.n_eff[region] = ev.decay * self.n_eff[region] + 1
        for name in ['ece', 'sr', 'q99_force', 'q99_err', 'latency']:
            p.update_ema(name, ev.value[name], w=1.0/self.n_eff[region])
        p.ci_width = bootstrap_ci_width(region, self.n_eff[region])
        return p

    def global_metric(self, p_task, B=1.0):
        covered = [r for r in self.S.V if self.M[r].n_eff >= N_MIN]
        m = sum(p_task(r) * self.M[r].sr for r in covered)
        bias = B * (tv_distance(p_task, self.p_eval) +
                    sum(p_task(r) for r in self.S.V if r not in covered))
        return m, bias

    def query(self, region):
        return MetricAtlasEntry(profile=self.M[region],
                                ci_width=self.M[region].ci_width,
                                provisional=self.M[region].provisional)
```

### IP-153 WGES（语义分层最差组风险）

```python
def worst_group_certificate(atlas, p_task, delta_c, alpha=0.05, n_min=30):
    groups = [c for c in atlas.C if p_task.class_mass(c) >= P_MIN]
    m = len(groups)
    result = {}
    for c in groups:
        h = atlas.region_set(c)          # 属于语义类 c 的区域
        n_c, fails_c = atlas.count(h)
        if n_c < n_min:
            result[c] = GroupCert(upper=1.0, certified=False,
                                  debt=(n_min - n_c))
            continue
        # 单侧 Clopper-Pearson，Bonferroni over groups
        U = clopper_pearson_upper(fails_c, n_c, alpha / m)
        result[c] = GroupCert(upper=U, certified=(U <= delta_c[c]), debt=0)
    R_wg_upper = max(g.upper for g in result.values())
    all_ok = all(g.certified for g in result.values())
    return WorstGroupCert(R_wg_upper, result, all_ok)

def clopper_pearson_upper(k, n, a):
    # P(X<=k | p=U) = a 的解，二分法
    if k >= n: return 1.0
    lo, hi = k / n if n else 0.0, 1.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        if binom_cdf(k, n, mid) > a: lo = mid
        else: hi = mid
    return hi
```

### IP-154 MVC（指标有效性证书审计）

```python
def audit_metric(metric_name, data, protocol, eps_tol):
    mu = protocol.metrics[metric_name]
    failures = []
    # I1 无关扰动不变
    for x, y in data.nuisance_pairs:
        if abs(mu(x) - mu(y)) > eps_tol['nuisance']:
            failures.append(('I1_nuisance', x.id, y.id))
    # I2 单调性
    for x, y in data.ordered_pairs:      # y 真实状态优于 x
        if mu(y) < mu(x) - eps_tol['mono']:
            failures.append(('I2_monotonicity', x.id, y.id))
    # I3 标签敏感一致（按混淆矩阵 C 预测变化）
    for relabel in data.relabel_audit:
        pred = mixture_of_groups(relabel, protocol.C)
        if abs(mu_after(relabel) - pred) > eps_tol['label']:
            failures.append(('I3_label_consistency', relabel.id))
    # I4 反事实不变（与决策无关的日志重排）
    for perm in data.log_permutations:
        if abs(mu(perm) - mu(perm.original)) > eps_tol['counterfactual']:
            failures.append(('I4_counterfactual', perm.id))
    valid = len(failures) == 0
    return MetricValidity(mu.name, valid, failures, protocol.version, time_now())
```

### IP-155 SARA（语义归因去卷积）

```python
def attribution_bounds(C, m_obs, eps_map):
    """C: 报告类×真实类混淆矩阵；返回每类 [lower, upper] 部分识别区间"""
    K = C.shape[1]
    bounds = []
    for c in range(K):
        lo = solve_lp(objective=e_c, C=C, m_obs=m_obs, eps=eps_map,
                      sense='min', box=(0.0, 1.0))
        hi = solve_lp(objective=e_c, C=C, m_obs=m_obs, eps=eps_map,
                      sense='max', box=(0.0, 1.0))
        bounds.append((lo, hi))
    return bounds

def attribution_policy(bounds, w_max):
    decision = {}
    for c, (lo, hi) in enumerate(bounds):
        if hi - lo > w_max:
            decision[c] = ('coarsen_or_probe', lo, hi)   # S1
        else:
            decision[c] = ('certify_with_upper', hi)    # S2 保守上界
    return decision

def coarsen_classes(C, m_obs, target_width):
    """按语义相似度合并类别直到所有区间宽度 <= target_width"""
    groups = [[c] for c in range(C.shape[1])]
    while any(width > target_width for width in group_intervals(groups, C, m_obs)):
        i, j = most_confusable_pair(groups, C)
        groups = merge(groups, i, j)
    return groups
```

### IP-156 PEP（评测-行动分离与影子评测）

```python
class EvaluationShadow:
    def __init__(self, protocol):
        self.Pi = protocol                 # frozen hash
        self.shadow_log = []               # 永不进入 reward / planner
        self.pollution = []

    def task_select(self, admissible, task_voi):
        # 动作只能由任务 VOI 决定
        return max(admissible, key=task_voi)

    def pick_calibration_region(self, admissible, voi_eval, budget):
        # 评测只选「已许可探针」的采样位置
        cands = [p for p in admissible if budget.can_spend(p)]
        if not cands:
            return None
        best = max(cands, key=voi_eval)
        return best if voi_eval(best) > THETA_EVAL else None

    def log_shadow(self, ev):
        self.shadow_log.append(ev)         # 隔离通道

    def check_pollution(self, pi_query_hist, predicted_query_hist):
        if tv_distance(pi_query_hist, predicted_query_hist) > THETA_POLLUTE:
            self.pollution.append(('query_shift', time_now()))
            return True
        if not all(self.Pi.mvc[m].valid for m in self.Pi.metrics):
            self.pollution.append(('mvc_invalid', time_now()))
            return True
        return False
```

class EvalBudget:
    def __init__(self, n_calib, label_budget, eval_compute):
        self.n_calib = n_calib
        self.label_budget = label_budget
        self.eval_compute = eval_compute
        self.coverage_debt = {}

    def eval_cost(self, region, needs_label, compute):
        return (LAMBDA_CALIB * int(region in self.needs_calib) +
                LAMBDA_LABEL * int(needs_label) +
                LAMBDA_COMP * compute)

    def spend(self, region, needs_label, compute):
        self.n_calib -= 1
        self.eval_compute -= compute
        if needs_label:
            self.label_budget -= 1
        if self.n_calib < 0 or self.label_budget < 0 or self.eval_compute < 0:
            return False
        return True

    def record_debt(self, semantic_class, missing):
        self.coverage_debt[semantic_class] = missing

**正确性定理（Evaluation-Grounded Evidence Soundness II, EGES-II）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** SMA：指标场 M_r 在每个区域上由 n_r^eff 个条件独立样本估计，指标有界于 [0,B]；任务分布 p_task 与评测分布 p_eval 可估，覆盖集已知。**(A57)** WGES：每类失败事件在类内 i.i.d.，Clopper–Pearson 界诚实，多重比较校正覆盖全部在册语义类 =α。**(A58)** SARA：语义混淆矩阵 C_{ĉc} 在标注校准集上的估计误差 ≤ε_C，且指标与报告误差条件独立；ε_map≥ε_C+统计误差。**(A59)** PEP：Π_eval 冻结且哈希不可篡改；影子通道在硬件/软件上对奖励与规划不可达；变形不变式审计覆盖指标的全部已知失效模态。**(A60)** PCE++++：五预算单调消耗、互不挪用；评测选择只作用于许可探针的位置、不改变动作与承诺。则：

1. **聚合偏差可控**：任意任务分布下，全局指标与评测指标之差 ≤ B·(TV(p_task,p_eval)+p_task(V_uncovered))；未覆盖质量超过 P_MIN 时不得报告全局指标。
2. **最差组认证健全**：若 WGES 返回 all_ok，则对每个 p_task(c)≥p_min 的语义类，P(R_c≤δ_c) ≥ 1−α（族错误率），且样本不足类被标记覆盖债务而非默认达标。
3. **归因区间健全**：在 A58 下，真实分层指标 m_c ∈ [m_c^-, m_c^+]，认证使用 m_c^+ 故风险界保守；区间过宽触发 coarsening/加标注，不产生虚假点估计。
4. **反腐蚀可检测性**：在 A59 下，若策略通过改变采样/日志而非真实能力提升报告指标，则要么违反某条变形不变式（被 MVC 审计捕获），要么查询/区域分布偏离任务 VOI 预测（被污染检测捕获）；被捕获的指标回滚至上一 valid 版本，不得进入证据门。

### IP-152 SMA（语义指标图谱）

```python
class SemanticMetricAtlas:
    def __init__(self, semantic_map, protocol, classes, p_eval):
        self.S = semantic_map
        self.Pi = protocol                  # frozen, hash-versioned
        self.C = classes
        self.p_eval = p_eval
        self.M = {r: MetricProfile.empty() for r in semantic_map.V}
        self.n_eff = {r: 0.0 for r in semantic_map.V}

    def update(self, region, ev):
        if ev.protocol_hash != self.Pi.hash:
            return mark_provisional(region, "protocol_mismatch")
        if not self.Pi.mvc[ev.metric].valid:
            return mark_provisional(region, "mvc_invalid")
        if ev.channel not in ('task-log', 'shadow'):
            return mark_provisional(region, "illegal_channel")
        self.n_eff[region] = EVAL_DECAY * self.n_eff[region] + 1.0
        w = 1.0 / self.n_eff[region]
        for name in ['ece', 'sr', 'q99_force', 'q99_err', 'latency']:
            self.M[region].update_ema(name, ev.value[name], w=w)
        self.M[region].ci_width = bootstrap_ci_width(region, self.n_eff[region])
        return self.M[region]

    def global_metric(self, p_task, B=1.0):
        covered = [r for r in self.S.V if self.n_eff[r] >= N_MIN]
        m_glob = sum(p_task(r) * self.M[r].sr for r in covered)
        uncovered = sum(p_task(r) for r in self.S.V if r not in covered)
        bias = B * (tv_distance(p_task, self.p_eval) + uncovered)
        return GlobalMetric(value=m_glob, bias_bound=bias,
                            uncovered_mass=uncovered,
                            reportable=(uncovered <= P_MIN))

    for c in groups:
        regions = atlas.region_set(c)
        n_c, fail_c = atlas.count(regions)
        if n_c < n_min:
            certs[c] = GroupCert(upper=1.0, certified=False,
                                 coverage_debt=n_min - n_c)
            continue
        U = clopper_pearson_upper(fail_c, n_c, alpha / m)   # Bonferroni
        certs[c] = GroupCert(upper=U, certified=(U <= delta_c[c]),
                             coverage_debt=0)
    return WorstGroupCert(
        upper=max(g.upper for g in certs.values()),
        per_class=certs,
        all_ok=all(g.certified for g in certs.values()),
        total_debt=sum(g.coverage_debt for g in certs.values()))

def clopper_pearson_upper(k, n, a):
    if k >= n: return 1.0
    lo, hi = (k / n if n else 0.0), 1.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        if binom_cdf(k, n, mid) > a: lo = mid
        else: hi = mid
    return hi
```

def audit_metric(metric_name, data, protocol, eps_tol):

### IP-155 SARA（归因去卷积）

```python
def attribution_bounds(C, m_obs, eps_map):
    K = C.shape[1]
    bounds = []
    for c in range(K):
        lo = solve_lp(c, C, m_obs, eps_map, sense='min')
        hi = solve_lp(c, C, m_obs, eps_map, sense='max')
        bounds.append((max(0.0, lo), min(1.0, hi)))
    return bounds

def solve_lp(c, C, m_obs, eps_map, sense):
    """min/max m_c s.t. |C m - m_obs|_inf <= eps_map, 0 <= m <= 1"""
    return linprog(objective=e_c, A_ub=[C, -C],
                   b_ub=[m_obs + eps_map, -m_obs + eps_map],
                   bounds=[(0, 1)] * C.shape[1], sense=sense)

def attribution_policy(bounds, w_max):
    out = {}
    for c, (lo, hi) in enumerate(bounds):
        if hi - lo > w_max:
            out[c] = ('coarsen_or_probe', lo, hi)    # S1: 归因不可判定
        else:
            out[c] = ('certify_with_upper', hi)      # S2: 用上界保守认证
    return out

def coarsen_classes(C, m_obs, target_width):
    groups = [[c] for c in range(C.shape[1])]
    while max(group_width(groups, C, m_obs)) > target_width:
        i, j = most_confusable_pair(groups, C)
        groups = merge(groups, i, j)
    return groups
```

class EvaluationShadow:
    def __init__(self, protocol):
        self.Pi = protocol
        self.shadow_log = []          # 对 reward/planner 不可达
        self.pollution = []

    def task_select(self, admissible, task_voi):
        return max(admissible, key=task_voi)     # 动作只由任务 VOI 定

    def pick_calibration_region(self, admissible, voi_eval, eval_budget):
        cands = [p for p in admissible if eval_budget.can_spend(p)]
        if not cands:
            return None
        best = max(cands, key=voi_eval)
        return best if voi_eval(best) > THETA_EVAL else None

    def log_shadow(self, ev):
        self.shadow_log.append(ev)

    def check_pollution(self, actual_queries, predicted_queries):
        if tv_distance(actual_queries, predicted_queries) > THETA_POLLUTE:
            self.pollution.append(('query_shift', time_now()))
            return True
        if not all(self.Pi.mvc[m].valid for m in self.Pi.metrics):
            self.pollution.append(('mvc_invalid', time_now()))
            return True
        return False

def two_key_update(ev, protocol, atlas):
    return (ev.protocol_hash == protocol.hash and
            protocol.mvc[ev.metric].valid and
            ev.channel in ('task-log', 'shadow'))

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SMA | O(1)/证据；回拉 O(\|V\|) | O(\|V\|·d_M) | 聚合偏差 ≤ B·(TV+未覆盖质量) |
| WGES | O(\|C\|·n_c + 60\|C\|) | O(\|C\|) | 每类 CP 上界、Bonferroni 族错误率 ≤α、欠样本记债务 |
| MVC | O(\|D_audit\|·\|I\|) | O(\|I\|·批) | 四条不变式全过才 valid |
| SARA | O(\|C\|³) LP/批 | O(\|C\|²) | 区间包含真值（A58）；宽区间触发 coarsening |
| PEP | O(1)/选择；O(\|hist\|)/污染检测 | O(\|shadow_log\|) | 双钥匙、影子隔离、污染可检测 |
| PCE++++ | O(\|CP\|·(k_p+k_c+k_ft+k_ux+k_exec+k_eval)·(C_VOI+UKF+μ)) | O(\|V\|+\|σ\|+\|𝒢\|+N_hist+N_calib) | 五预算单调、耗尽即 provisional |
| J_eval | O(1)/追加 | O(\|C\|+审计日志) | 协议哈希、覆盖债务阻止认证 |

**正确性定理（Evaluation-Grounded Evidence Soundness II, EGES-II）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** SMA：M_r 由区域条件独立样本估计且 ∈[0,B]，p_task/p_eval 与覆盖集可估。**(A57)** WGES：类内失败 i.i.d.，CP 界诚实，多重校正覆盖全部在册类=α。**(A58)** SARA：C 估计误差 ≤ε_C，指标与报告误差条件独立，ε_map≥ε_C+统计误差。**(A59)** PEP：Π_eval 冻结且哈希不可篡改，影子通道对奖励/规划不可达，变形审计覆盖已知失效模态。**(A60)** PCE++++：五预算单调、互不挪用，评测只选许可探针位置、不改动作与承诺。则：

1. **聚合偏差可控**：|M_glob(p_task)−M_glob(p_eval)| ≤ B·(TV(p_task,p_eval)+p_task(V_uncovered))；未覆盖质量 >P_MIN 时全局指标不可报告。
2. **最差组认证健全**：WGES all_ok ⇒ 对所有 p_task(c)≥p_min 的类，P(R_c≤δ_c)≥1−α；欠样本类记债务而非默认达标。
3. **归因区间健全**：A58 下 m_c∈[m_c^-,m_c^+]，认证用 m_c^+ 故保守；区间过宽触发 coarsening/加标注，不产出虚假点估计。
4. **反腐蚀可检测**：A59 下，若指标上升来自采样/日志操纵而非真实能力，则违反某变形不变式（MVC 捕获）或查询分布偏离任务 VOI（污染检测捕获）；被捕获指标回滚至上一 valid 版本。
5. **评测-行动单向性**：voi_eval 只影响校准探针位置，不能减少任务探针、放宽证据门或改变承诺参数；B_eval 耗尽只让认证更保守。
6. **终止性与部署界**：PCE++++ 在 k_eval 次校准探针内终止于 {承诺(带 J_eval), 绕行, 降档, L2 协商, 安全停, 覆盖债务停}；A22–A60 下
```
P_safe ≥ 1 − Σ_cp [ δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD] + δ_ertc·1[契约违例]
                   + δ_eeis·1[μ分析漏报] + δ_agg·1[p_eval≠p_task] + δ_attr·1[C含噪]
                   + δ_eval·1[provisional] + δ_pollute·1[腐蚀未检出] ]
        − P(𝒢 结构性错误未检出) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效) − P(固件回滚失败)
```

关键：**SMA 把评测从标量变成地图上的场**；**WGES 把平均安全变成最差语义类安全**；**SARA 把地图标签噪声变成可计算区间**；**PEP 把评测与行动制度性分离**；**PCE++++ 把评测覆盖变成一等预算**。安全单向通道从三条扩展为四条：**信念更准、不确定性更大、动作更保守、评测更诚实**。
