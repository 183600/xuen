# 第 3 轮（灵感循环第 3 轮；本轮灵感：「碰撞避免」×「大语言模型」）

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（PCA/CTS/CFC/HPC/CFCtrl）。
> **本轮纪律**：**LLM 只做「收缩提议者 / 证伪者 / 采样先验」，证明器做「守门员」；几何证书是唯一授权来源，语义只加锁、不开锁。** v20 的感知层、v19 的 DCM/OGCC/CCV/DRS/OGC、v17 的 CLP/S2C/HCG/PSV/APS/AMC 全部保留。本轮只做一件事：**把自然语言中的碰撞意图，安全地编译成可验证的参数域收缩。**

## 0. 直觉与动机

### 灵感 1（碰撞避免 → 几何碰撞之外还有「功能性碰撞」）

**直觉**：v19/v20 的 CCV 把“碰撞”定义为 SDF 穿透或间隙 < margin——这是**几何碰撞**。但人在说“小心别碰到”时，往往指更广的**功能性碰撞**：碰倒高堆叠、勾住线缆、把杯子推到桌沿、遮挡传感器视野、交接时撞到人手。这些事件在几何上穿透可能为 0，却造成任务失败甚至危险；纯几何证书对此**结构性地看不见**。

**严谨化**：设场景 S、参数 θ，接触事件集合 C(θ)，穿透谓词 Pen(n, o, θ)。v20 的硬约束是 ¬Pen(θ)。定义**功能性失效谓词** F(x, θ)，x 为环境状态：F = Topple ∨ Snag ∨ Drop ∨ Occlusion ∨ HumanContact。v21 的目标是避免 F，但**只把 F 中可被确定性验证的部分**并入证书，绝不把“未被证伪”误当作“已被证明”。

**核心创新**：**语义碰撞契约编译器（Semantic Collision Contract Compiler, SCCC）**。用 LLM 把自然语言任务编译成一组**带类型、带单位、可接地**的谓词（保持某物可达、远离某物、从上方接近、保持直立、禁止勾挂），再交给确定性接地器转成参数域约束，与几何安全域**求交**。

**关键反直觉**：**LLM 不判断“会不会碰撞”，它只提出“人类会关心的碰撞假设”。** 判真值的是 SDF / 物理验证器，不是语言模型。

### 灵感 2（大语言模型 → 证明携带的收缩提议者，而非安全裁判）

**直觉**：把 LLM 直接放进控制回路是危险的——幻觉、提示注入、分布漂移、单位错误、指代歧义。但 LLM 的强项恰恰是“从含混的自然语言里抽取意图与约束”。因此把它放在**证书外环**：LLM 输出的是**候选约束 / 候选危险 / 候选采样点**，每一条都必须携带**证明对象**（类型 + 单位 + 区间模型 + 原文出处），由独立检查器验证；通过者只能以**交集**方式收窄安全域。

**严谨化**：引入**证明携带语言证书（Proof-Carrying Language Certificate, PCLC）** 与 **收缩单调守卫（Contraction Monotonicity Guard, CMG）**。PCLC 定义 `π_α = (τ, u, I, src)` 与判定 `⊢ π_α`；CMG 在运行时独立复核 `Θ_n^21 ⊆ Θ_n^20`，一旦发现反例立刻回退。

**核心创新**：**证明携带 + 双钥合取**。授权 = 几何钥 ∧ 语义钥；语义钥只能进一步关小门，不能打开几何钥关上的门。

**关键反直觉**：**LLM 犯错只会伤“活性 / 语义完备性”，不会伤“几何安全性”**——因为授权是 `几何 ∧ 语义`，不是 `几何 ∨ 语义`；语义没有否决几何的权限。

### 灵感 3（语言作为红队与跨物体泛化的先验）

**直觉**：v20 的 CTS 用几何谱系判断“两个物体能否迁移”，会犯两类错：(a) **几何相似但语义不同**（勺子 vs 刀，都细长，但接触后果不同）；(b) **几何不同但语义同类**（杯子 vs 马克杯）。LLM 的语义嵌入能补上 (a) 的**假阳性**。另一方面，LLM 可以扮演**红队**：主动生成“碰倒 / 勾挂 / 滑落”的危险参数区域，交给 CCV 去伪证。

**严谨化**：引入**语言红队采样器（Language Red-Team Sampler, LRS）** 与 **语义–几何谱系融合（Semantic-Geometric Spectrum Fusion, SGSF）**。二者都只**收缩**：LRS 只从域里删点（`Θ ← Θ \ B(θ_fail, δ)`），SGSF 只把“几何相似”收紧为“几何相似 **且** 语义相似”（AND 门）。

**关键反直觉**：**用 LLM 提升安全性，不是让它多放行，而是让它多怀疑。** LLM 的正确用法是“提出更坏的假设”，而不是“给出更好的答案”。

### 两者如何统一

统一为 **v20 证书体系之上的语义外环**：

- v20 回答：“几何上是否零碰撞？”
- v21 回答：“给定语言任务，哪些几何安全动作仍不制造功能性碰撞？”

SCCC/PCLC 是编译侧（语言 → 可验证约束），CMG 是守门侧（只许收缩），LRS 是证伪侧（找反例），SGSF 是迁移侧（语义–几何双门）。共享状态 `ζ_lang = (contract, sem_domain, proof_ledger, hazard_hypotheses, cmg_verdict, mode_lang)`。

统一接口：

> **只有 `θ ∈ Θ_n^20 ∧ G_sem(θ)=1 ∧ CMG=OK` 才进入 CCV 的窄相位；任一缺失都退回 v20（更保守）。**

## 1. 研究问题（轮次升级版）

- **Q1（语义接地的保守性）**：如何把自然语言谓词接地为参数域集合 `⟦α⟧`，使得任何接地误差都不会扩域？接地器应满足什么“过近似 / 欠近似”条件，才能保证 `Θ_n^21 ⊆ Θ_n^20`？当接地集合无法用凸集精确表示时，如何用保守外包（interval / octagon / SMT）保证子集关系？

- **Q2（证明携带与可审计）**：如何定义语言证书的证明对象 `π_α`，使类型、单位、区间、原文出处可机械检查？对歧义、复合句、指代、否定、条件句、提示注入如何处理？检查通过只保证“可执行且一致”，如何向使用者明确它**不**保证语义完备？

- **Q3（红队采样的有效性与单调性）**：LLM 生成的危险假设如何转成可验证的监视器与测试生成器，使证伪只删点不加点？监视器本身依赖物理模型（倾倒阈值、摩擦、堆叠稳定性），模型误差如何进入保守裕度？覆盖率与活性如何权衡？

- **Q4（语义–几何分离与失效回退）**：当 LLM 不可用 / 超时 / 输出不可解析时，如何无缝退化为 v20？如何与 v20 的 CFCtrl/APS 新鲜度阶梯对齐，保证 50Hz 控制环时限？语义要求与几何不可行冲突时，如何给出可解释的“拒绝原因”而不是静默失败？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 语义收缩律（Semantic Contraction）**
任何语言来源的约束 α 只能通过交集并入：`Θ_n^21(o) = Θ_n^20(o) ∩ ⟦α_1⟧ ∩ … ∩ ⟦α_m⟧`。系统不存在“语义放行”算子：LLM 无写权限把任何 θ 加入域；所有新增权限必须来自 v20 几何钥。

**P35 证明携带律（Proof-Carrying Language）**
每个 α 必须携带 `π_α = (τ, u, I, src)`，且 `⊢ π_α` 通过类型 / 单位 / 区间 / 出处检查；不通过者不得进入交集，标记 `sem_uncovered` 并告警。**无证明，不授权。** 检查通过只声明“该约束可执行、量纲一致、区间有界”，**不**声明其语义完备。

**P36 双钥合取律（Dual-Key Conjunction）**
授权 = 几何钥 ∧ 语义钥；语义钥缺失或未知 → 只用几何钥（即精确等价 v20）；几何钥拒绝 → 语义钥无否决权，一律拒绝。禁止任何 OR 组合。形式化：`G_v21(θ) = G_geo^v20(θ) ∧ G_sem(θ)`，且 `G_sem` 单调（多一个约束只会更小）。

## 3. 与基线的接口（如何退化）

- **LLM 超时 / 不可解析 / 供应商故障** ⇒ `mode_lang=GEO_ONLY` ⇒ 等价 v20；
- **证明检查失败** ⇒ 丢掉该谓词并标记 `sem_uncovered` ⇒ 等价 v20 + 告警；
- **CMG 发现扩域反例** ⇒ 立即回退 v20 并写入审计账本；
- **SGSF 语义门缺失** ⇒ 退化 v20 CTS 的纯几何迁移；
- **LRS 失效** ⇒ 退化 v20 采样，仅失去额外证伪，安全性不降；
- **SCCC 全部失败** ⇒ 完全回退 v20 的 OGCC/CCV ⇒ 等价 v20；
- **安全继承**：任意子模块失效都使约束集合更小或不变，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19`，由引理 157 / 163 保证。

## 4. 预期贡献

1. **功能性碰撞的可编译化**：首次把“碰撞避免”从几何穿透扩展到**可编译、可验证的功能性碰撞**，并给出“语言只收缩”的形式化安全边界；
2. **证明携带语言证书**：把 LLM 输出变成可审计的约束证明对象，而非不可解释的“安全判断”，并明确其“操作健全 / 语义不完备”的边界；
3. **双钥合取结构**：从架构上消除“LLM 越过几何”的可能，给出 `Exec_v21 ⊆ Exec_v20` 的构造性证明链与运行时审计；
4. **红队证伪与语义–几何谱系融合**：把 LLM 的作用方向统一为“更怀疑、更保守”，并用语义门修正 v20 CTS 的“几何相似但语义危险”假阳性；
5. **可退化、可审计、可复现的闭环**：给 v21 的退化矩阵、复杂度、实验与预注册判据，形成“语言 → 语义约束 → 几何证书 → 执行”的闭环。

## 5. 本轮最大风险

**一句话**：LLM 只能提出“语义碰撞假设”，而“哪些语义碰撞值得防”本身没有完备规格；一旦团队把 v21 的“语义碰撞避免”误读为**可证明的保证**，就会在“几何合法但功能失效”的区域形成系统性盲区——即**证书证明了一个并不覆盖真实危险的命题**。

```python
# IP-425 Semantic Collision Contract Compiler
@dataclass
class SemanticContract:
    keep: list            # list[GroundedPredicate]
    avoid: list           # list[GroundedPredicate]
    hazards: list         # list[HazardHypothesis]
    uncovered: list       # 证明失败 / 不可接地的原始子句
    ledger_root: str | None
    mode: str             # "SEM" | "GEO_ONLY" | "ABSTAIN"

class SemanticCollisionContractCompiler:
    def __init__(self, llm, grounder, checker, ledger, timeout_ms=30):
        self.llm = llm                # 只读结构化抽取，不持有执行权限
        self.grounder = grounder      # 语义谓词 -> 参数域集合（保守外包）
        self.checker = checker        # PCLC 证明检查器
        self.ledger = ledger          # Merkle 证明账本
        self.timeout_ms = timeout_ms

    def compile(self, instruction, scene, node, obj, theta20):
        # 1. 结构化抽取；失败即退化为纯几何（等价 v20）
        try:
            raw = self.llm.extract(instruction, scene,
                                   schema=CONTRACT_SCHEMA,
                                   timeout_ms=self.timeout_ms)
        except (TimeoutError, ParseError):
            return SemanticContract([], [], [], [], None, "GEO_ONLY")

        # 2. 结构校验（字段、类型、是否出现未知谓词）
        contract = self.typecheck_schema(raw)
        if contract is None:
            return SemanticContract([], [], [], [], None, "GEO_ONLY")

        sem_dom = theta20            # 关键：永远从 v20 域出发，只做交集
        keep, avoid, uncovered = [], [], []

        for clause in contract.predicates:
            # 3. 接地：语义 -> 参数域集合（含保守外包）
            g = self.grounder.ground(clause.pred, clause.args, scene, obj)
            if g is None:
                uncovered.append(clause)      # 不可接地：丢弃并标记
                continue

            # 4. 证明携带：类型 / 单位 / 区间 / 出处
            if not self.checker.proves(g.proof()):
                uncovered.append(clause)      # 无证明，不授权
                continue

            # 5. 只收缩：intersect，绝无 union / expand
            sem_dom = sem_dom.intersect(g.admissible_set(theta20))
            (keep if clause.kind == "KEEP" else avoid).append(g)

        # 6. 双保险：任何实现异常导致的扩域都回退几何模式
        if not sem_dom.subset_of(theta20):
            return SemanticContract([], [], [], uncovered, None, "GEO_ONLY")

        root = self.ledger.commit(keep + avoid, uncovered)
        return SemanticContract(keep, avoid, contract.hazards,
                                uncovered, root, "SEM")


# IP-426 Proof-Carrying Language Certificate
class ProofCarryingLanguageCertificate:
    def __init__(self, ontology, units, trust_policy):
        self.ontology = ontology          # 类型本体：pred, arg-typing
        self.units = units                # 量纲系统：length/time/mass...
        self.trust_policy = trust_policy  # 原文出处 / 注入片段策略

    def proves(self, pi) -> bool:
        # (a) 类型：谓词与参数在 ontolgy 中良型
        if not self.ontology.well_typed(pi.term):
            return False
        # (b) 单位：所有长度/角度量纲一致并可归一（mm vs m 自动换算）
        if not self.units.consistent(pi.term):
            return False
        # (c) 区间：接地集合有界可计算（interval / half-space / octagon）
        if not pi.I.is_bounded_and_computable():
            return False
        # (d) 出处：src 指向 ℓ 的可信片段，未命中注入黑名单
        if not self.trust_policy.trusted(pi.src):
            return False
        return True

    def audit(self, ledger_root, records):
        # 独立复核：账本叶 = (clause, proof_hash, grounded_bounds)
        return self.ledger.verify(ledger_root, records)


# IP-427 Contraction Monotonicity Guard
class ContractionMonotonicityGuard:
    def __init__(self, sampler, boundary_checker, k=4096):
        self.sampler = sampler
        self.boundary_checker = boundary_checker
        self.k = k

    def audit(self, theta21, theta20):
        # 1. 构造不变量：合法域必须来自 INTERSECT 链
        if not theta21.construction_tag.startswith("INTERSECT"):
            return "VIOLATION"

        # 2. 反例搜索：寻找 theta21 内、theta20 外的点
        for x in self.sampler.uniform(theta21, self.k):
            if not theta20.contains(x):
                return "EXPANDED_WITNESS"

        # 3. 边界区间检查：外包边界不得越出 theta20 的保守外包
        if self.boundary_checker.exceeds(theta21, theta20):
            return "EXPANDED_BOUNDS"

        return "OK"

        self.llm = llm
        self.checker = checker
        self.ccv = ccv            # 复用 v20 CCV 作为确定性判真器
        self.delta = delta

    def hypothesize(self, instruction, scene):
        # LLM 只生成“危险假设”，不生成“安全结论”
        try:
            raw = self.llm.redteam(instruction, scene,
                                   schema=HAZARD_SCHEMA)
        except (TimeoutError, ParseError):
            return []
        out = []
        for h in raw:
            monitor = self.checker.build_monitor(h)     # 可执行物理谓词
            tau = self.checker.build_generator(h)       # θ 采样器
            if monitor is not None and tau is not None:
                out.append(HazardHypothesis(h, monitor, tau))
        return out

    def falsify(self, domain, hypotheses, node, obj):
        # 只删点、不加点：保证 Exec 单调不增
        for h in hypotheses:
            for theta in h.tau.sample(domain, budget=64):
                if not h.monitor(theta, self.scene):
                    continue
                if self.ccv(node, obj, theta) != "SAFE":
                    domain = domain.subtract(theta.ball(self.delta))
        return domain


# IP-429 Semantic-Geometric Spectrum Fusion
class SemanticGeometricSpectrumFusion:
    def __init__(self, cts, sem_encoder, gamma_thr=0.85, s_thr=0.80):
        self.cts = cts                # v20 CrossTopologySpectrum
        self.sem_encoder = sem_encoder
        self.gamma_thr = gamma_thr
        self.s_thr = s_thr

    def sem_sim(self, o1, o2):
        e1, e2 = self.sem_encoder(o1), self.sem_encoder(o2)
        return dot(e1, e2) / (norm(e1) * norm(e2))

    def transferable(self, o1, o2):
        # AND 门：几何相似 且 语义相似；任一不满足即拒绝
        g = self.cts.similarity(o1, o2)
        if g < self.gamma_thr:
            return False, "GEO_MISMATCH"
        if self.sem_sim(o1, o2) < self.s_thr:
            return False, "SEM_MISMATCH"    # 例：knife vs spoon
        return True, "OK"
```

## 3. 推导

**引理 157（语义收缩与安全继承）**
SCCC 的 `Θ_n^21 = Θ_n^20 ∩ ⋂_α ⟦α⟧`。交集运算满足 `A ∩ B ⊆ A`，故 `Θ_n^21 ⊆ Θ_n^20`。执行集合取自已认证域，故 `Exec_v21 ⊆ Exec_v20`。LLM 在系统中没有 union / expand 算子，也没有直接写域的接口。∎

**引理 158（双钥否定律）**
授权定义为 `G_v21 = G_geo^v20 ∧ G_sem`。若 `G_geo^v20(θ)=0`，则对任意 `G_sem` 取值都有 `G_v21(θ)=0`。故语义层不能复活被几何层拒绝的 θ；语义层无否决权。∎

**引理 159（证明携带的操作健全性）**
若 `⊢ π_α`，则 α 的类型良型、量纲一致、接地集合有界可计算、出处可追溯。该定理只保证**可执行与可审计**；它不保证 `⟦α⟧` 精确等于人类意图的外延。故称“操作健全、语义不完备”。未通过检查的 α 不进入交集，只能使域不变或更小（此处表现为“不收缩”而非“扩域”）。∎

**引理 160（红队单调性）**
LRS 的更新仅为 `Θ ← Θ \ B(θ_fail, δ)`，即集合差。集合差满足 `Θ \ B ⊆ Θ`，故每一步都使执行集合单调不增；LRS 不可能引入新动作。∎

**引理 161（语义–几何谱系保守性）**
SGSF 将 v20 CTS 的可迁移判定 `T_geo` 收紧为 `T_fused = T_geo ∧ (γ_sem ≥ s_thr)`。因 `T_fused ⇒ T_geo`，可迁移集合是子集，进而 `Θ_n^21 ⊆ Θ_n^20`。它只能消除“几何相似但语义危险”的假阳性，不能新增迁移。∎

**引理 162（CMG 的单向检测与构造保证）**
CMG 的采样反例搜索是**单向健全**的：报 `EXPANDED_WITNESS` 必有反例，报 `OK` 不构成完整证明。真正的子集保证来自 SCCC 的 `INTERSECT` 构造标签与引理 157；CMG 用于捕获实现 bug、提示注入触发的非预期路径与数值外包误差。∎

**引理 163（v21 整体安全继承）**
在同一几何快照、同一机器人集合、同一 v20 证书下，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。证明：SCCC 交集、PCLC 只删不增、CMG 只做回退、LRS 只做集合差、SGSF 只收紧迁移——五者叠加只能产生子集。∎

**推论 164（语义失效不破坏几何安全）**
若 LLM 输出任意错误（幻觉、注入、单位错、指代错），最坏结果是某些 KEEP/AVOID 未被纳入（`sem_uncovered` 增加）或域被过度收缩；几何钥仍独立生效，故 `Exec_v21 ⊆ Θ_n^20` 恒成立。失效表现为**活性下降或语义覆盖缺口**，而非几何碰撞。∎

## 7. 已知风险与失效模式

1. **语义完备性缺口（根本风险）**：LLM 提出的危险假设集合不保证覆盖真实功能失效。缓解：红队库 + 领域本体 + 运行时监视器，并始终声明“几何安全可证、语义安全尽力”。

2. **接地保守性 vs 活性**：为保证 `Θ^21 ⊆ Θ^20`，接地集合采用保守外包，可能过度收缩导致动作不可行。缓解：外包精度分级（interval → octagon → SMT）、活性反馈闭环、可解释拒绝原因。

3. **提示注入与工具链越权**：恶意指令可能诱导 LLM 输出“扩大许可”的子句。缓解：P36 双钥合取 + CMG 构造标签 + 出处信任策略；LLM 无写域接口，只有谓词提议权。

4. **监视器物理模型误差**：topple/snag 的监视器依赖简化物理（摩擦、质心、堆叠稳定性），模型误差会漏报。缓解：模型误差进入 δ 裕度、与真实传感器交叉验证、在线参数辨识。

5. **分布漂移**：新物体、新说法、新环境使语义谓词过时。缓解：契约版本化、语义嵌入漂移监测、周期性重编译与回归。

6. **延迟抖动**：LLM 调用 30ms–2s 不等，可能破坏 50Hz 控制。缓解：异步预编译、契约缓存、`mode_lang=GEO_ONLY` 快速回退、与 v20 CFCtrl/APS 时限对齐。

7. **语义–几何冲突死锁**：语义要求（远离某物）与几何可行域交集为空，导致任务无法执行。缓解：冲突检测 + 分层松弛（软语义 vs 硬几何）+ 向用户澄清。

8. **账本与审计膨胀**：每轮谓词与证明对象写入 Merkle 账本，长期运行会增大存储与校验开销。缓解：滚动窗口 + 周期性快照 + 增量校验。

## 8. 本轮最大风险

**一句话**：LLM 只能提出“语义碰撞假设”，而“哪些语义碰撞值得防”本身没有完备规格；一旦把 v21 的“语义碰撞避免”误读为可证明的保证，就会在“几何合法但功能失效”的区域形成系统性盲区——即**证书证明了一个并不覆盖真实危险的命题**。
