# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「最优控制」×「机器人竞赛」）

> 第 54 轮把技能组合从“能力匹配”推进到“动作-鲁棒性联合证书 J”。但 J 仍是**静态、平均意义、固定环境**的证书：它回答“通常能不能成”，却没有回答“在最坏对手/扰动下、在有限时间与能量预算内，从当前状态出发还能不能安全到达”。本轮用最优控制把证书变成状态空间上的**值函数与生存核**，用机器人竞赛把“最坏扰动”具体化为**零和对抗与锦标赛协议**。核心矛盾：H22 证书的可部署域在对抗下会收缩，静态 J 会给出“假安全”；H23 云边“最低成本”组合不等于竞赛“最优”策略，路径最优与 minimax 最优在对抗下分离。

## 0. 直觉与动机

**灵感 1（证书不是标签，而是值函数）**
最优控制的直觉：不要说“这个技能平均成功率 90%”，而要说“对每个初始状态 x，采取最优策略后最坏情况下的剩余代价 V(x) 是多少”。于是部署判定从“J 有没有签发”变为“`x0 ∈ K(J)` 且 `V_J(x0) ≤ B`”，其中 K 是**生存核（viability kernel）**、B 是竞赛预算。这把第 54 轮的概率拼贴 `1-Σ(1-ρ)` 升级为**最坏情况可达性**问题，天然适配“宁可保守，不可假安全”。

**灵感 2（技能组合是切换系统的最优调度）**
技能不是连续控制律，而是一个个**离散模态**；技能内部是连续动力学，切换有代价 `c_trans`。于是第 54 轮的技能组合图 G_S 只是切换系统的一阶近似，真正的组合是**混合最优控制**：在模态序列与切换时刻上最小化 cost-to-go。`cost_align`（对齐成本）应被解释为 HJB 值函数的一个可计算代理，而不是目标本身。这样“何时切换技能”有了最优性条件，而不只是阈值 `compat ≥ θ_a`。

**灵感 3（云边协同 = 双时间尺度分层最优控制；Explain = 协态）**
云端慢时间尺度做 MPC，输出粗计划与**上界值函数 V_c**；边端快时间尺度做 CBF-QP 安全滤波与跟踪，得到**下界值函数 V_e**。二者一致的判据是 `V_e(x) ≤ V_c(x) + ε_ce`（边端没有比云端承诺差太多）。最漂亮的一点：庞特里亚金最大值原理里，协态 `λ = ∂V/∂x` 正是“价值对状态的敏感度”——第 53/54 轮的**反向解释 Explain 信道，本质就是协态/对偶变量回传**：边端把“哪个约束最紧、价值梯度指向哪”传回云端，云端据此重规划。这把解释从启发式叙事变成有数学对象的伴随（adjoint）信道。

**灵感 4（机器人竞赛 = 零和微分博弈 + 锦标赛）**
竞赛的“对手”不是随机扰动，而是**有策略的 d**。固定环境里的鲁棒性谱 ρ 应扩展为**博弈值 ρ_game**：`min_u max_σ`。竞赛排名看重的是对强对手的 minimax 表现，不是平均成功率；因此证书必须附带**可被利用性（exploitability）**与**锦标赛 regret**。一个在自博弈里很稳的策略，可能在对手分布外被一招打穿——这正是“假安全”的竞赛版本。

**灵感 5（预算与时限是一等约束）**
竞赛是有限时间 T、有限能量/算力 B 的。证书应携带 **resource-to-go `B_go(x)`**：不是“能不能赢”，而是“用剩余预算还能不能守住可行域”。这把 cost-to-go 与竞赛的资源约束统一起来，也解释了为什么“无限算力的云端规划”在边端会失效。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（证书生存核）**
给定联合证书 J、扰动/对手类 `D`、时域 `[0,T]` 与安全集 `S_safe`，
```
K(J) = { x0 | ∃策略 π, ∀d(·)∈D, ∀t∈[0,T]: x(t)∈S_safe ∩ A_cert, x(T)∈G }。
```
`K(J)` 为**鲁棒受控不变集（robust controlled invariant set）**；`x0∉K(J)` 时 J 不得签发。

**定义 122（证书值函数与 HJI）**
`V_J(x,t) = inf_{π} sup_{d∈D} { ∫_t^T ℓ(x,u,d) ds + g(x(T)) }`，满足 Hamilton–Jacobi–Isaacs 方程
```
-∂_t V = min_{u∈U} max_{d∈D} { ℓ(x,u,d) + ∇_x V · f(x,u,d) },   V(x,T)=g(x).
```
部署可容许当且仅当 `V_J(x0,0) ≤ B`，B 为竞赛预算。

**定义 123（切换组合的 HJB-QVI）**
技能为模态 `i∈S`，模态内动力学 `ẋ=f_i(x,u)`，切换代价 `c_{ij}=c_trans(S_i,S_j)`。组合值函数 `{V_i}` 满足拟变分不等式
```
min { -∂_t V_i - H_i(x,∇V_i),  min_{j≠i}(V_j - V_i + c_{ij}) } = 0.
```
第 54 轮的最短路径组合是 `c_{ij}→∞` 离散化下的特例。

**定义 124（云边值一致性）**
云端值 `V_c`、边端值 `V_e`、跟踪误差 `ε_tr`。**一致性条件**：
```
V_e(x) ≤ V_c(x) + ε_ce,   ||x_e - x_c|| ≤ ε_tr,
```
且边端策略 `π_e` 满足 `V^{π_e}_c(x) ≤ V_c(x) + δ`（δ-次优）。仅当两式同时成立，云端粗动作承诺才对边端有效。

**定义 125（博弈鲁棒性证书）**
`J_game = (K_game, V_game, Expl, B_go, Σ_model)`：`K_game` 为对手类 `Σ_model` 下的生存核，`V_game = inf_π sup_σ`，`Expl` 为可被利用性，`B_go` 为剩余预算，`Σ_model` 为建模对手类。

**定义 126（可被利用性与锦标赛 regret）**
零和收益 `U(σ,π)`：
```
Expl(π) = sup_{σ∈Σ} [ U(σ,π) - U(π,σ) ],
Reg_T   = (1/T) Σ_{t=1}^T [ max_σ U(σ,π_t) - U(π_t,π_t) ].
```
竞赛证书要求 `Expl(π) ≤ Θ_expl`，而不仅是自博弈胜率高。

**定义 127（竞争性 soundness）**
在对手类 `Σ_model`、时域 T、预算 B 下，若 `x0∈K_game`、`V_game(x0,0) ≤ B`、`Expl ≤ Θ_expl`，则称 `J_game` **竞争性 sound**；否则必须降级为“仅对 `Σ_model` 内对手有效”的受限声明。

## 2. 关键算法 伪代码

### IP-121 OVC（Optimal-Control Viability Certificate）

```python
def viability_kernel(f, S_safe, G, D, T, grid):
    # HJ 可达性：反向时间迭代，直到不动点
    V = terminal_cost(G, grid)            # 0 in G, +inf outside
    for t in reversed(time_grid(T)):
        V = hji_step(V, f, D, dt, S_safe) # min_u max_d
    K = {x for x in grid if V[x] < INF and in_safe(x, S_safe)}
    return K, V
```

### IP-122 SHS（Switched Hybrid Scheduling）

```python
def switched_schedule(x0, modes, T, c_trans, B):
    V = {i: terminal_value(i, x0, T) for i in modes}
    for t in reversed(time_grid(T)):
        for i in modes:
            cont = hji_step(V[i], dynamics[i], D, dt)      # 模态内最优
            switch = min(V[j] + c_trans(i, j) for j in modes if j != i)
            V[i] = min(cont, switch)                       # HJB-QVI
    return extract_mode_schedule(V, x0, T, c_trans)
```

### IP-123 HOC（Hierarchical Optimal Coordination）

```python
def cloud_mpc(x, V_c, horizon, B):
    plan = solve_mpc(cost_to_go=V_c, horizon=horizon, budget=B)
    return plan, value_upper_bound(plan)     # 云端对边端的承诺上界

def edge_cbf_qp(x, plan, h, alpha, d_max):
    u_ref = track(plan, x)
    # 鲁棒 CBF-QP：含扰动裕度，保证 h 不越界
    u = solve_qp(min ||u - u_ref||**2,
                 s.t. Lf_h + Lg_h*u + alpha(h) + ||Ld_h||*d_max >= 0)
    return u, value_estimate(x, u), adjoint(x, u)   # adjoint 即 Explain
```

### IP-124 ADJ-Explain（Adjoint Explain Channel）

```python
def adjoint_explain(V_e, V_c, x, constraints):
    lam = grad(V_e, x) - grad(V_c, x)        # 价值梯度差 = 协态失配
    tight = active_constraints(constraints, x)
    if norm(lam) > eps_ce:
        return ('reprofile', tight, lam)     # 回传云端触发重规划
    return ('consistent', None, lam)
```

### IP-125 CGC（Competitive Game Certificate）

```python
def game_certificate(policy, opponent_class, B, T, expl_budget):
    K = robust_viability(policy.dynamics, opponent_class, T)
    V = game_value(policy, opponent_class, T)
    Expl = estimate_exploitability(policy, opponent_class)
    B_go = B - V
    if Expl > expl_budget or B_go < 0:
        return ('restricted', K, V, Expl, B_go)   # 仅对 Σ_model 声明
    return ('sound', K, V, Expl, B_go)
```

### IP-126 EXPL（Tournament Exploitability Audit）

```python
def tournament(policy, opponents, matches, B, T):
    results = [play(policy, opp, B, T)
               for opp in opponents for _ in range(matches)]
    win  = mean(r.win for r in results)
    reg  = empirical_regret(results)
    expl = max(opp.best_response_value(policy) for opp in opponents) - win
    return ParetoReport(win, reg, expl, cert_violations(results))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OVC | O(N_x·N_u·N_d·N_t) | O(N_x) | HJI 离散一致、边界处理 |
| SHS | O(|S|·N_x·N_u·N_d·N_t) | O(|S|·N_x) | QVI 不动点、切换代价单调 |
| HOC | O(H·N_mpc + N_qp) | O(N_c+N_e) | V_e≤V_c+ε、CBF 可行 |
| CGC | O(N_x·N_σ) | O(N_x) | 对手类覆盖、Expl 上界 |
| EXPL | O(|Opp|·M·T_ep) | O(|Opp|) | 对手池代表性、best response 收敛 |

**正确性定理（Game-Viability Certificate Soundness）**
假设 (A22)-(A28) 承接第 53/54 轮；**(A29)** `f` 对 x Lipschitz、`D` 紧；**(A30)** 值近似误差 `||V̂-V||∞ ≤ ε_V`，生存核按 `ε_K` 膨胀计算；**(A31)** 边端 CBF-QP 保证 `h(x)≥0` 且 `||x_e-x_c||≤ε_tr`；**(A32)** 实际对手 `σ∈Σ_model`。
则当 `V̂(x0) ≤ B - ε_V - L_f ε_tr T` 时，
```
P_success ≥ 1 - (ε_V + L_f ε_tr T)/B - Expl(π) - P(σ∉Σ_model).
```
在 `σ∈Σ_model` 且无近似误差时退化为确定性保证 `P_success = 1`——这正是“生存核优先于概率”的收益。

## 6. 本轮最大风险

**一句话**：把证书升级为“生存核 + 博弈值”在理论上把假安全压到最低，但其 soundness 同时押注于**值函数近似误差可控、对手类 Σ_model 覆盖真实强对手、以及云边值一致性在线成立**；一旦近似误差把生存核算大、或竞赛对手落在建模分布之外，系统会以“看起来可证”的证书进入真实对局并被系统性击穿，故必须以 **CBF 硬安全约束 + ε-膨胀的保守生存核 + 独立 exploitability 审计** 三重护栏，任何一项失守都必须把“竞争性 sound”降级为受限声明。

## 2. 关键算法 伪代码

### IP-121 OVC（生存核 + 值函数）

```python
import numpy as np

def hji_step(V, f, dist, dt, safe):
    # 一阶迎风/半拉格朗日近似：min_u max_d
    dV = np.full_like(V, np.inf)
    for idx in np.ndindex(V.shape):
        x = index_to_state(idx)
        if not in_safe(x, safe):
            continue
        best = np.inf
        for u in control_set(x):
            worst = -np.inf
            for d in dist.sample(x):
                xp = x + dt * f(x, u, d)
                val = V[state_to_index(xp)]
                worst = max(worst, val)
            best = min(best, stage_cost(x, u) * dt + worst)
        dV[idx] = best
    return dV

def viability_kernel(f, safe, goal, dist, T, grid):
    V = terminal_cost(goal, grid)          # 0 in goal, +inf outside
    for _ in reversed(range(T)):
        V = hji_step(V, f, dist, dt=1, safe=safe)
    K = {x for x in grid if np.isfinite(V[x]) and in_safe(x, safe)}
    return K, V

def deployable(J, x0, B):
    return x0 in J.K and J.V[x0] <= B
```

### IP-122 SHS（切换系统 HJB-QVI）

```python
def switched_schedule(x0, modes, T, c_trans, B):
    V = {i: terminal_value(i, x0, T) for i in modes}
    policy = {i: None for i in modes}
    for t in reversed(range(T)):
        for i in modes:
            cont = hji_step(V[i], dynamics[i], dist, 1, safe)
            j_best, sw_best = None, np.inf
            for j in modes:
                if j == i:
                    continue
                cand = V[j] + c_trans(i, j)
                if cand < sw_best:
                    j_best, sw_best = j, cand
            if sw_best < cont:
                V[i], policy[i] = sw_best, ('switch', j_best)
            else:
                V[i], policy[i] = cont, ('continue', i)
    return extract_schedule(policy, x0, T), V
```

### IP-124 ADJ（协态 Explain）

```python
def adjoint_explain(V_e, V_c, x, constraints):
    lam = grad(V_e, x) - grad(V_c, x)
    tight = [c for c in constraints if is_active(c, x)]
    return ExplainPacket(
        severity=norm(lam),
        tight_constraints=tight,
        costate=lam,
        reprofile=norm(lam) > eps_ce,
    )
```

### IP-125 CGC（博弈证书）

```python
def game_certificate(policy, opponents, B, T, expl_budget, eps_K):
    Sigma = opponents.model_class()
    K = inflate(robust_viability(policy.f, Sigma, T), eps_K)
    V = game_value(policy, Sigma, T)         # inf_pi sup_sigma
    Expl = estimate_exploitability(policy, Sigma)
    B_go = B - V
    if Expl > expl_budget or B_go < 0:
        return ('restricted', K, V, Expl, B_go, Sigma)
    return ('sound', K, V, Expl, B_go, Sigma)
```

### IP-126 EXPL（锦标赛审计）

```python
def exploitability_audit(policy, opponent_pool, matches, B, T):
    rows = []
    for opp in opponent_pool:
        for _ in range(matches):
            r = play(policy, opp, B, T)
            rows.append((opp.id, r.win, r.cert_violated, r.budget_used))
    win = mean(w for _, w, _, _ in rows)
    reg = empirical_regret(rows)
    br_values = [opp.best_response_value(policy) for opp in opponent_pool]
    expl = max(br_values) - win
    return ExplReport(win, reg, expl, sum(v for *_, v in rows))
```

### IP-127 PCR（Pareto 竞赛报表）

```python
def competition_pareto(certificates, opponent_pool, B, T):
    pts = []
    for J in certificates:
        rep = exploitability_audit(J.policy, opponent_pool, m, B, T)
        conservatism = 1.0 - volume(J.K) / volume(J.K_max)
        pts.append((conservatism, rep.win, rep.expl, J))
    front = pareto_max(pts, keys=(lambda p: p[1], lambda p: -p[2]))
    return front   # 选“保守度适中 + 胜率高 + Expl 低”的拐点部署
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OVC | O(N_x·N_u·N_d·N_t) | O(N_x) | HJI 离散一致；`K` 对扰动鲁棒 |
| SHS | O(|S|·N_x·N_u·N_d·N_t) | O(|S|·N_x) | QVI 不动点；切换代价单调 |
| HOC | O(H·N_mpc + N_qp) | O(N_c+N_e) | CBF 硬约束；`V_e≤V_c+ε_ce` |
| ADJ | O(N_x + N_c) | O(N_x) | 梯度存在；协态可解释 |
| CGC | O(N_x·N_σ) | O(N_x) | 对手类覆盖；`Expl` 上界 |
| EXPL | O(|Opp|·M·T_ep) | O(|Opp|) | best-response 收敛；对手池代表性 |
| PCR | O(|Cert|·|Opp|·M) | O(|Cert|) | Pareto 非支配排序 |

**正确性定理（Game-Viability Certificate Soundness，v17）**
假设第 53/54 轮 (A22)-(A28) 成立；**(A29)** `f` 对 x 满足 Lipschitz 常数 `L_f`，扰动/对手集 `D` 紧；**(A30)** 值近似误差 `||V̂-V||∞ ≤ ε_V`，生存核按 `ε_K` 膨胀；**(A31)** 边端 CBF-QP 保证 `h(x)≥0` 且 `||x_e-x_c||≤ε_tr`；**(A32)** 实际对手 `σ∈Σ_model`。
则当 `V̂(x0) ≤ B - ε_V - L_f ε_tr T` 时：
```
P_success ≥ 1 - (ε_V + L_f ε_tr T)/B - Expl(π) - P(σ∉Σ_model)
```
推论：
1. `σ∈Σ_model`、误差为 0 时 `P_success = 1`（生存核的确定性保证）；
2. `Expl=0` 且 `Σ_model` 覆盖真实对手时，证书可跨竞赛场地迁移；
3. 若 `Expl > Θ_expl`，证书必须降级为 “restricted”，仅声明对 `Σ_model` 有效。

## 6. 与 UniBot 竞赛的落地映射

- **赛道即 `S_safe ∩ G`**：把规则约束写成 CBF `h(x)≥0`，使“违规动作”在 QP 层不可行，而非事后惩罚；
- **对手即扰动类 `D`**：把对手行为纳入 `Σ_model`，用 best-response 生成强对手，避免自博弈过拟合；
- **预算即 `B_go`**：把算力/能量/时间显式进证书，解释“云端最优、边端跑不动”的失败；
- **排名即 minimax**：交付物不是单场最高分，而是“对强对手的稳定下限 + 低 Expl”；
- **可解释申诉**：ADJ 信道给出“哪个约束最紧、梯度指向哪”，可作为竞赛复核证据。

## 7. 本轮最大风险

**一句话**：把证书升级为“生存核 + 博弈值”在理论上把假安全压到最低，但其 soundness 同时押注于**值函数近似误差可控、对手类 Σ_model 覆盖真实强对手、以及云边值一致性在线成立**；一旦近似误差把生存核算大、或竞赛对手落在建模分布之外，系统会以“看起来可证”的证书进入真实对局并被系统性击穿，故必须以 **CBF 硬安全约束 + ε-膨胀的保守生存核 + 独立 exploitability 审计** 三重护栏，任何一项失守都必须把“竞争性 sound”降级为受限声明。
