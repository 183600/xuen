# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「异常检测」×「手势识别」）

> R69 把不确定性一分为二，并且学会了「问」：注视、探针、问句都是可生成、可认证的信息动作。但它留下了一个被自己写进公式、却从未兑现的承诺——定义 298 的 VoI 里写着 `E_{y~p(·|g,o)}`，**这个「回答分布」从未被定义，更从未被验证**。R69 只造了「提问的嘴」，没有造「听懂回答的耳」：它默认人一定会回答、回答一定能被识别、识别结果一定是在回答**这个问题**。现实中这三个「一定」都会失效。
>
> - **手势识别**补上的正是「回答侧的物理载体」：在噪声、距离、隐私受限的场景里，指向、点头/摇头、比划、手语、示教动作是最自然的回答；它也是少数能同时携带「语义 + 空间指涉 + 力度意图」的低带宽通道。
> - **异常检测**补上的则是「回答侧的语法」：手势识别有三个固有失效点——**在哪切（spotting）、是不是我会的词（open-set）、是不是在对我做（addressee）**——它们恰好是三种粒度不同、本质都是「偏离正常流形」的异常。异常检测在这里不是外挂的故障报警，而是**证据准入（evidence admission）的判据**：只有落在「交际的、在词表内的、指向我的」这条流形上的动作，才有资格进入后验。
>
> 核心命题：**把 R69 的「提问侧」补成完整的「提问—回答—复述」闭环；回答侧用三层异常检测（时间/类别/相关性）+ 受话人门做证据准入，未准入的回答一律视为「未观测」而非「未知类别」；准入失败时用二阶 VoI 触发修复（复述/放慢/缩减词表/换模态/调整站位），修复无望则通道降级并严格退回 R69/R68。** 命名 **SIGN-RAS**（Spotting × Intent-attribution × Gating × Negotiated repair）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**对方真的回答了我吗，还是我把自己想听的塞进了他的动作里**」——证据不只是「被采到」，还必须「被准入」。

## 0. 直觉与动机

**灵感 1（R69 的 VoI 悬空 → 需要一个真正的回答模型）**
直觉：VoI 是一个关于「如果我问了，会得到什么」的期望。R69 直接把这个期望写成 `E_{y~p(·|g,o)}`，却把 `p(·|g,o)` 当作理所当然。可「人会用怎样的手势回答这个具体问题」本身就是一个可学习的分布；不学它，VoI 就是空中楼阁。手势识别提供了这个分布的观测载体：问题→回答手势的配对数据可以训练一个**问题条件化的回答模型（QRM）**，于是 R69 的期望第一次可算、可校准、可证伪。

**灵感 2（手势识别的三大难题 = 三种粒度的异常）**
直觉：连续手势流里大部分动作不是交际（静息、过渡连读、自我适应动作），这是**时间异常**；用户做的可能是词表外的新手势，这是**类别异常**；同一动作可能是对旁边人做的，或只是无意识地整理头发，这是**相关性/受话人异常**。把它们硬塞进一个 softmax，就是 R69「幻影模态」在回答侧的翻版：**把不认识的东西强行认成认识的**。正确的姿态不是「分类」，而是「先判定它是否落在我的证据流形上」。

**灵感 3（异常检测不是报警器，而是准入门）**
直觉：工况监控里的异常检测问「系统坏了吗」；这里问的是「这个动作配当证据吗」。二者数学结构相同（密度/能量/重构误差），但语义相反：前者触发停机，后者决定**是否允许一次贝叶斯更新**。因此准入门必须**宁可漏纳，不可错纳**，并为「漏纳」付出显式代价（功能性失聪）——这正是修复层存在的理由。

**灵感 4（修复：把「听不懂」变成一个可执行的动作）**
直觉：日常对话听不清时，人会说「什么？」「慢点」「写下来」。这类 **other-initiated repair** 是通信协议的一部分。R69 只会「继续问新问题」，不会「修当前这次回答」。修复是一阶交互之上的**二阶交互（meta-interaction）**：它不改变世界，只改变信道。关键是修复必须按失败模式分派——遮挡应「调整站位/等待」，词表外应「缩减词表/要求示范」，没在对我做应「重建共同注意」，乱修等于在错误的通道上烧预算。

**灵感 5（对偶：R69 的最大风险在这里有了镜像）**
直觉：R69 最怕「流模型幻觉模态 → 自信地追问一个幻影 → 把误导回答盖章为已验证」。R70 的回答模型同样是生成模型，于是有完全对偶的风险：**问题条件化的回答模型会「听成自己想听的」**——它用机器人自己的问句去预测人的回答；问句一旦含诱导性，模型就把期望答案当成最可能答案，把真实的、不合期望的手势判为异常并反复要求复述。系统不是聋，而是**只听得见自己想听的**。因此本轮必须交付：准入门分布无关校准、QRM 的确认偏置检测、修复疲劳硬约束与审计。

**灵感 6（严格包含：新增的是「信道卫生层」，不是新的安全承诺）**
直觉：异常检测与修复都发生在**证据进入后验之前**与**动作进入执行之前**，不改变 R69 的风险缩放与认证路径。通道不可用/全拒绝/修复超预算时，系统必须逐指令退化为 R69，再退化为 R68。新层只增加「证据卫生」，不稀释「安全下界」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SIGN-RAS 总览）** SIGN-RAS = (GSP, ACR, GAD, OSG, QRM, ARG, RPR) 嵌入 R69 的 FLUID-RAS†。四不变式：
(i) 零学习写操作继承（R68 定义 276-i）；
(ii) **准入不可绕过**：任何人类手势证据必须先经 ARG 准入，才能进入 CIA / 贝叶斯更新；
(iii) **拒绝≠类别**：准入失败记为「未观测（∅）」，禁止映射为开放集哨兵 ⊥ 后再当作一个类别使用；
(iv) **修复安全且单调**：RPR 的动作与任务动作同过 C-RAS-WM 认证；修复失败时 λ 单调不降，并严格退化 R69（进而 R68）。

**定义 311（手势流、手势单元与非交际片段）** 连续骨架流 `H=(h_1,…,h_T)`，`h_t∈ℝ^{J×3}`（关节位置/速度）。Spotting 将其切分为手势单元 `u_i=h_{s_i:e_i}` 与非交际片段（静息位、过渡/连读、自我适应动作 self-adaptor）。输出边界集合 `{(s_i,e_i)}` 与每段交际性概率 `comm(u_i)`。

**定义 312（三层异常分数）**
- 时间异常 `a_seg = −log p_seg(s_i,e_i | H)`（边界越不像真的手势边界越高）；
- 类别异常 `s_ood = −log p_prior(u_i)` 或 `energy(u_i)`（越偏离已知手势流形越高）；
- 相关性异常 `a_sem = [−log p_φ(u_i | q, o)] − baseline(q,o)`（越不像「对这个问题的回答」越高）。
三者分通道门控，**不做加权求和**：量纲与语义不同，求和会让一种异常的高分掩盖另一种。

**定义 313（手势词表与开放集解码 OSG）** 回答词表 `𝒱={v_1,…,v_N}∪{⊥}`。OSG 输出 `(p(v|u), s_ood(u))`。规定：当 `s_ood>τ_ood` 时**禁止**输出 `argmax_v`（禁止把词表外手势强行归类），只能输出「不可识别」。这是与标准开放集识别（把 ⊥ 当作一个可预测类）的关键区别。

**定义 314（受话人/交际意图门 ACR）** `P(addr(u)=robot | u, x_robot)` 由联合注意线索决定：机器人处于人的注视锥/手势空间、手势发生在提问后的响应窗内、身体与手形朝向机器人、收势回落方向指向机器人、以及是否与机器人当前动作存在交替（turn-taking）。受话人门：`P(addr) ≥ τ_addr`。

**定义 315（问题条件化回答模型 QRM）** `p_φ(h_{t:t+T} | q, o)` 用流匹配建模「给定问题 q 时人以手势作答」的轨迹分布，训练于 `(q, 回答手势)` 配对。它把 R69 定义 298 的 `E_{y~p(·|g,o)}` 显式化为 `E_{y~p_φ(·|Decode(g_ask),o)}`。回答似然 `ℓ_ans = −log p_φ(u | q, o)`。

**定义 316（证据准入 ARG）** `Admit(u) = [comm≥τ_comm] ∧ [a_seg≤τ_seg] ∧ [P(addr)≥τ_addr] ∧ [s_ood≤τ_ood] ∧ [a_sem≤τ_sem] ∧ [多源一致 ∨ 双重低异常豁免]`。
「多源一致」= 手势与语音/表情/指向中至少 `k=2` 个正交源给出相容答案；「双重低异常豁免」= 单源但 `s_ood` 与 `a_sem` 同时低于各自的高置信阈。阈值用 **split-conformal** 在标定集上取分位数，得到分布无关的假准入率上界。

**定义 317（修复动作空间 RPR）** `r ∈ ℛ = {repeat, slow, reduce_vocab, demonstrate, switch_modality, reposition, wait}`，每个 `r` 有成本 `c(r)`（时间/社交/物理）与预期可解码增益。

**定义 318（二阶 VoI / 修复决策）** `VoI_repair(r) = H(Admit | o) − E_{o'~p(·|r,o)}[H(Admit | o')]`。选 `r* = argmax_r [VoI_repair(r) − c(r)]`，s.t. C-RAS-WM 认证、修复预算与 `R_max` 未超。仅当一阶回答未准入且 `VoI_repair(r*)>0` 时修复；否则「放弃本次回答」，退回 R69（继续任务或按 R69 兜底）。

**定义 319（失败模式分派与豁免）** 由 `(comm, a_seg, s_ood, a_sem, P(addr))` 诊断失败模式 `f∈{occluded, ood, unaddressed, silent, contradictory}`，映射候选修复：`occluded→{reposition,wait}`；`ood→{reduce_vocab,demonstrate,switch_modality}`；`unaddressed→{reposition,repeat}`；`silent→{wait,switch_modality}`；`contradictory→{demonstrate,repeat}`。**错误分派是禁止的**：在遮挡上做 `reduce_vocab` 只会更听不见。

**定义 320（准入后的后验更新与证据纪律）** 只有 `Admit` 的 `u` 进入 `M` 的后验：`M ← Bayes(M, {decode(u)})`；仍需 R69 定义 293-iii 的证据纪律；手势只是新增一个证据源，不豁免「不得单源定案」，除非满足双重低异常豁免（定义 316）。

**定义 321（跨模态手势异常 / 表演性手势）** 手势与语音/韵律/表情矛盾（点头+"不"、挥手+"过来"、微笑+后退）→ 判为 `contradictory`；这既可能是诚实的手势-语言失配，也可能是**表演性/反讽/共谋欺骗**，交由 R69 的 CIA 主动选判别对，并降权该证据。

**定义 322（SIGN 证书 J_SIGN）** `J_SIGN = (J_FLUID, admission_rate, false_admit_rate, addressee_auc, ood_auroc, a_sem_ece, repair_success_rate, repair_cost, gesture_log_hash, sign_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ `false_admit_rate ≤ τ_fa` ∧ `a_sem_ece ≤ τ_ece` ∧ 修复预算未越 ∧ 无错误分派。

**定义 323（手势威胁模型 ℰ_gesture）** 骨架对抗扰动、手势重放（replay）、表演性/反讽手势、受话人欺骗（朝机器人做手势以声东击西/干扰第三方）、遮挡与半身出画、方言/个体差异造成的 OOD、以及**教学式投毒**（人反复把错误手势示范成"标准词"）。并入 AIC：`ℰ_SIGN = ℰ_FLUID × ℰ_gesture`。

**定义 324（缺失机制：MAR vs MNAR）** 手部不可见时准入默认为否。区分可忽略缺失（MAR：随机遮挡，等待即可）与不可忽略缺失（MNAR：遮挡本身与意图相关，如背手藏物/拒绝交互）——后者触发 `reposition` 或安全升级，而不是 `wait`。

**定义 325（修复收敛、通道降级与严格包含）** 修复序列长度 ≤ `R_max`；同一问题修复成功率低于 `τ_repair` 或超过 `R_max` ⇒ 判「手势通道不可用」，永久降级该通道（类比 R69 的 ECE 门）；此时 SIGN-RAS 逐指令退化为 FLUID-RAS（后者已严格包含 CALM-RAS）。安全侧三级嵌套，效率侧仅在「有已准入证据」时获益。

**定义 326（时序预算）** 骨架编码+spotting < 0.8ms、ACR < 0.05ms、GAD < 0.3ms、OSG < 0.1ms、QRM 轨迹似然（Hutchinson 1 次回放）< 0.4ms、ARG < 0.02ms、RPR 枚举 < 0.1ms；总增量 < 1.8ms，且只在「等待回答窗口」内计费、与任务环异步；任务环仍保持 R69 的 P99 < 2.6ms。

# IP-264 GSP：连续手势流切分（流密度变化点 + 交际性判别）
def spot_gestures(H, encoder):
    z = encoder(H)                                  # 复用 CALM/R68 视觉 trunk + 轻量骨骼分支
    bounds = change_points(z)                       # 边界来自 p_seg 的局部极大
    units = [(H[s:e], comm_prob(H[s:e])) for s, e in bounds]
    return [(u, c) for u, c in units if c >= TAU_COMM]

# IP-265 ACR：受话人 / 共同注意
def addressee(u, robot, t_since_query):
    return p_addressed(joint_attention_features(u, robot, t_since_query))

# IP-266/267 GAD+OSG：三层异常（不合并）+ 开放集解码（禁强行归类）
def anomaly_and_decode(u, q, o, prior, qrm, osg):
    a_seg = -boundary_loglik(u)
    s_ood = prior.ood_score(u)                      # energy / NLL / Mahalanobis
    a_sem = -qrm.log_likelihood(u, q, o) - qrm.baseline(q, o)
    if s_ood > TAU_OOD:
        return (a_seg, s_ood, a_sem), None          # 词表外：不输出类别
    return (a_seg, s_ood, a_sem), osg.decode(u)

# IP-269 ARG：证据准入（conformal 阈值；未准入 = 未观测）
def admit(u, scores, srcs, robot, t_q):
    a_seg, s_ood, a_sem = scores
    checks = [a_seg <= T_SEG, s_ood <= T_OOD, a_sem <= T_SEM,
              addressee(u, robot, t_q) >= T_ADDR]
    multi = orthogonal_agree(srcs, k=2)
    double_low = (s_ood <= T_OOD_HI) and (a_sem <= T_SEM_HI)
    return all(checks) and (multi or double_low)

# IP-270 RPR：二阶 VoI 修复（按失败模式分派，不跨模式乱修）
def choose_repair(q, failure_mode, budget):
    cand = {'occluded':['reposition','wait'],
            'ood':['reduce_vocab','demonstrate','switch_modality'],
            'unaddressed':['reposition','repeat'],
            'silent':['wait','switch_modality'],
            'contradictory':['demonstrate','repeat']}[failure_mode]
    best = None
    for r in cand:
        if not budget.allow_repair(r) or not c_ras_wm.certify_repair(r): continue
        score = voi_repair(r, q) - cost(r)
        if best is None or score > best.score: best = (r, score)
    return best if best and best.score > 0 else None

# IP-274 主闭环（提问侧完全继承 R69，回答侧新增准入/修复）
def SIGN_RAS_round(M, obs, H_human):
    # 1) 提问侧 = R69：分解 U_ale/U_epi，MINT 选 g*（问什么）
    g = R69_choose_question(M, obs)
    M.execute_info_action(g)                         # 看/问/触，已过认证
    # 2) 回答侧：定位 + 准入
    admitted = []
    for u, comm in M.gsp.spot_gestures(H_human):
        scores, ans = M.gad.anomaly_and_decode(u, M.query(g), obs, M.prior, M.qrm, M.osg)
        if ans is not None and M.arg.admit(u, scores, M.srcs, M.robot, M.t_q):
            admitted.append(ans)
    # 3) 无准入证据 → 诊断失败模式 → 二阶修复 或 通道降级
    if not admitted:
        fm = diagnose(M.last_scores, M.last_comm, M.last_addr)
        r  = M.rpr.choose_repair(M.query(g), fm, M.budget2)
        if r is not None:
            M.rpr.execute(r)                         # 过 C-RAS-WM，失败则 λ 不降
            return None                              # 本拍不更新后验，等下一次回答
        M.chm.degrade('gesture')                     # 修复无望：永久降级（定义 325）
    else:
        M.cia.update_belief(M.modes, admitted)       # 仅准入证据进后验（k 源一致）
    # 4) 后续完全回到 R69：λ、认证、执行（严格包含）
    return FLUID_RAS_tail(M, admitted)

## 3. 推导

**引理 19（准入的假证据上界）** 设准入门由 `m` 项近似独立的检查组成，第 `i` 项假准入率为 `α_i`（把非证据动作误判为可准入），则单源假证据进入后验的概率 ≤ `∏_i α_i + ε_cal`，其中 `ε_cal ≤ 1/(n+1)` 为 split-conformal 在标定集大小 `n`、覆盖 `1−δ` 下的校准松弛。对照 R69：无准入门时，任何被解码的回答都以概率 1 进入后验。系：准入门把「回答是默认」改为「回答需证明」；代价是漏纳率 `1−∏_i(1−β_i)`（功能性失聪），必须由 RPR 显式补偿。

**引理 20（QRM 使 VoI 可计算，且偏差有方向）** R69 的 VoI 依赖未定义的 `p(y|g,o)`。以 `p_φ` 替代后，若 `‖p_φ − p_true‖_TV ≤ ε_q`，则 `|VoÎ − VoI| ≤ L_H·ε_q`（`L_H` 为熵的 Lipschitz 常数）。更关键的是偏差方向：若 `p_φ` 在问句含诱导性时系统性低估回答熵（把期望答案当高概率），则 `VoÎ` **系统性高估**，系统会过度交互、过度信任。系：**回答模型越自信越危险**；必须做确认偏置检测（用反事实问句对 `p_φ` 做一致性检验）。

**引理 21（修复的适用域）** 记可解码熵 `H_dec`。对 `reduce_vocab`（词表 `N→N'`）：`ΔH ≥ log(N/N') − δ`；对 `demonstrate`：`ΔH` 更大但 `c(r)` 更高；对 `reposition`：当且仅当受话人/遮挡是主因时 `ΔH>0`，否则 ≈0。故修复收益是失败模式的函数，跨模式分派会使 `VoI_repair ≤ 0`。系：**「先诊断、后修复」不是工程细节，而是修复值得做的充要条件**。

**定理 18（严格包含与安全三级嵌套）** 在 A95–A99 下，SIGN-RAS 的期望风险 ≤ FLUID-RAS ≤ CALM-RAS；当手势通道禁用、全部回答未准入、修复预算耗尽或 `J_SIGN` 无效时，SIGN-RAS 与 FLUID-RAS **逐指令相同**；而 FLUID 在「永不交互」边界上等于 R68。故安全侧三级嵌套、不做任何让步；效率侧仅在存在已准入证据时获得收益。

**定理 19（修复安全与无突变）** 修复动作经 C-RAS-WM 认证（定义 317），其物理/社交风险 ≤ `ε_repair`；修复只改变「是否以及如何等待/重问」，不改变安全包络；修复失败/超时/超预算时 `λ` 单调不降地退回 R69；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。修复期间的「延迟更新」等价于 R69 的 `wait` 分支，不会放宽任何安全约束。

## 6. 本轮最大风险

**一句话**：SIGN-RAS 的全部收益押在「问题条件化的回答模型 `p_φ` 是可信的」这一前提上——但 `p_φ` 是用机器人**自己的问句**去预测人的回答；问句一旦有诱导性、或训练数据只覆盖合作场景，`p_φ` 就会把「我期望他怎么答」当成「他实际怎么答」，于是把真实的、不合期望的手势判为异常、把符合期望的误读判为正常，**系统不是听不见，而是只听得见自己想听的**——这比 R69 的「问错」更隐蔽，因为它会以「复述」「再确认」的礼貌姿态，把确认偏置一步步固化成"已验证的事实"。

**次级风险与缓解**：
1. **准入门过严 → 功能性失聪**（真实回答被反复拒绝）→ 漏纳代价显式建模 + RPR 补偿 + E305 漏纳率上限；
2. **准入门过松 → 声东击西/表演性手势被采纳** → 引理 19 假准入上界 + 受话人门 + 跨模态矛盾检测；
3. **错误修复分派**（在遮挡上缩减词表）→ 定义 319 强制按失败模式分派 + E309；
4. **修复疲劳与社交成本**（反复"啊？"）→ 预算硬约束 + 修复成功率降级 + E314；
5. **教学式投毒/词表漂移** → 词表更新必须过审计与证据纪律，VQAuditor-G + E311；修复无望即通道降级、严格退回 R69/R68。

## 3. 关键算法伪代码

```python
# IP-264 GSP：连续流切分（变化点 + 交际性）
def spot_gestures(H, encoder):
    z = encoder(H); bounds = change_points(z)
    return [(H[s:e], comm_prob(H[s:e])) for s, e in bounds
            if comm_prob(H[s:e]) >= TAU_COMM]

# IP-266/267 GAD+OSG：三层异常 + 开放集（禁强行归类）
def anomaly_and_decode(u, q, o, prior, qrm, osg):
    a_seg = -boundary_loglik(u)
    s_ood = prior.ood_score(u)
    a_sem = -qrm.log_likelihood(u, q, o) - qrm.baseline(q, o)
    if s_ood > TAU_OOD: return (a_seg, s_ood, a_sem), None
    return (a_seg, s_ood, a_sem), osg.decode(u)

# IP-269 ARG：conformal 准入（未准入 = 未观测 ∅）
def admit(u, scores, srcs, robot, t_q):
    a_seg, s_ood, a_sem = scores
    checks = [a_seg <= T_SEG, s_ood <= T_OOD, a_sem <= T_SEM,
              addressee(u, robot, t_q) >= T_ADDR]
    return all(checks) and (orthogonal_agree(srcs, k=2)
                            or (s_ood <= T_OOD_HI and a_sem <= T_SEM_HI))

# IP-270 RPR：按失败模式分派的二阶 VoI 修复
def choose_repair(q, failure_mode, budget):
    cand = {'occluded':['reposition','wait'],
            'ood':['reduce_vocab','demonstrate','switch_modality'],
            'unaddressed':['reposition','repeat'],
            'silent':['wait','switch_modality'],
            'contradictory':['demonstrate','repeat']}[failure_mode]
    best = None
    for r in cand:
        if not budget.allow_repair(r) or not c_ras_wm.certify_repair(r): continue
        s = voi_repair(r, q) - cost(r)
        if best is None or s > best.score: best = (r, s)
    return best if best and best.score > 0 else None

# IP-274 主闭环（提问侧继承 R69；回答侧新增准入/修复）
def SIGN_RAS_round(M, obs, H_human):
    g = R69_choose_question(M, obs); M.execute_info_action(g)
    admitted = []
    for u, comm in M.gsp.spot_gestures(H_human):
        scores, ans = M.gad.anomaly_and_decode(u, M.query(g), obs, M.prior, M.qrm, M.osg)
        if ans is not None and M.arg.admit(u, scores, M.srcs, M.robot, M.t_q):
            admitted.append(ans)
    if not admitted:
        fm = diagnose(M.last_scores, M.last_comm, M.last_addr)
        r  = M.rpr.choose_repair(M.query(g), fm, M.budget2)
        if r is not None:
            M.rpr.execute(r); return None            # 延迟更新，等下一次回答
        M.chm.degrade('gesture')                     # 修复无望：通道降级
    else:
        M.cia.update_belief(M.modes, admitted)       # 仅准入证据进后验
    return FLUID_RAS_tail(M, admitted)               # 之后完全回到 R69
```

## 4. 推导

**引理 19（准入的假证据上界）** `m` 项近似独立检查、假准入率 `α_i`，则单源假证据进后验概率 ≤ `∏_i α_i + ε_cal`（`ε_cal ≤ 1/(n+1)`，conformal）。无准入门时该概率 = 1。系：准入门把「回答是默认」变「回答需证明」；漏纳率 `1−∏_i(1−β_i)` 是显式代价，需 RPR 补偿。

**引理 20（QRM 使 VoI 可计算，偏差有方向）** 以 `p_φ` 替代未定义的 `p(y|g,o)`，`‖p_φ−p_true‖_TV≤ε_q ⇒ |VoÎ−VoI|≤L_H·ε_q`。若 `p_φ` 对诱导性问句系统性低估回答熵，则 `VoÎ` **系统性高估**：回答模型越自信越危险，须用反事实问句做确认偏置检测。

**引理 21（修复的适用域）** `reduce_vocab` 给 `ΔH ≥ log(N/N')−δ`；`demonstrate` 增益更大但成本更高；`reposition` 仅在受话人/遮挡为主因时 `ΔH>0`。跨模式分派使 `VoI_repair≤0`——「先诊断、后修复」是修复值得做的充要条件。

**定理 18（严格包含与安全三级嵌套）** SIGN-RAS 期望风险 ≤ FLUID-RAS ≤ CALM-RAS；通道禁用/全拒绝/超预算/`J_SIGN` 无效时与 FLUID-RAS 逐指令相同；FLUID 在「永不交互」边界等于 R68。安全不让步，效率仅在已准入证据时获益。

**定理 19（修复安全与无突变）** 修复动作过 C-RAS-WM，风险 ≤ `ε_repair`；只改「是否/如何等待重问」，不改安全包络；失败/超时/超预算时 `λ` 单调不降退回 R69；提交/换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：SIGN-RAS 的收益全押在「问题条件化回答模型 `p_φ` 可信」上——但 `p_φ` 是用机器人**自己的问句**去预测人的回答，问句有诱导性时它会把「我期望他怎么答」当成「他实际怎么答」，于是把真实但不合期望的手势判为异常、把符合期望的误读判为正常；**系统不是听不见，而是只听得见自己想听的**，还可能以「复述/再确认」的礼貌姿态把这种确认偏置逐步固化成"已验证的事实"。

**次级风险与缓解**：准入门过严→功能性失聪（漏纳代价显式建模 + RPR + E305）；过松→声东击西被采纳（引理 19 + 受话人门 + 跨模态矛盾检测）；错误修复分派（定义 319 强制分派 + E309）；修复疲劳（预算硬约束 + 成功率降级 + E314）；教学式投毒/词表漂移（审计 + 证据纪律 + E311，修复无望即通道降级并严格退回 R69/R68）。
