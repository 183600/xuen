# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「轨迹优化」×「工具调用」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**管状轨迹优化 + 类型化工具调用**。两个灵感分别治理 v9 的两种债：**证书债**（v9 的块证书是「冻结前向模型 + 标量 β」的开环指标预测，域偏移时最不可靠却最需要它；中止依赖 20 帧滑窗，天然迟到）与**组合债**（单体策略把「该做什么」与「怎么做」焊死，失败恢复靠隐式 fallback，无法审计、无法组合）。必须保留中立元退化链：任一新组件失效 ⇒ 退回 v9 对应级，再退回 v8/v7。

## 0. 直觉与动机

**灵感 1（轨迹优化 → 管状证书轨迹优化 TTO）**
直觉：v9 的 AC 在 64 条随机采样序列里挑一条，再用冻结前向模型 + 标量 β 盖章；这既浪费结构（动力学、光滑性、约束全没用上），又把「模型误差」压成一个与时间无关的标量。轨迹优化的做法相反：把整块动作当成一个**带约束的最优控制问题**，用 iLQR/SCP 直接求解，并把模型误差升级为**逐时刻传播的误差管 r_t**；安全约束在**规划期**对管的最坏情形逐节强制（g(s_t^nom) − L_g·r_t ≥ d_safe）。核心创新：**管状轨迹优化器（TubeTrajOpt, TTO）**。它把 v9 的「事后中止」前移为「事前不可行」：若管最坏情形已不可行，则根本不提交该块；停车可行性同时给出中止点集 P_t 的解析构造，而非启发式枚举。

**灵感 2（工具调用 → 类型化能力层 TCC）**
直觉：v9 的「策略」既决定目标又直接产出动作，「失败后怎么办」散落在 if-else 与 AC fallback 里。工具调用的做法：把能力抽象为**带模式的工具**——`TrajOptBlock`、`SafeStop`、`Replan`、`AskOperator`、`Measure` 等，每个工具有类型化参数、前置/后置条件、代价、证书要求、有界 fallback 链与**提交点**。策略只负责「提议调用」，运行时包装器强制 schema / 前置条件 / 提交语义（**policy proposes, wrapper disposes**）。核心创新：**类型化工具调用控制器（ToolCallController, TCC）**：物理工具不可回滚，故引入**提交语义**——提交前失败是 no-op，提交后失败必走补偿 `SafeStop`；复合调用要求原子安全 + fallback 无环 + 终止测度严格下降。附带产出：**证书账本**，每次动作都可重放其「调用→前置→规划→管证书→提交→后置」论证链——直接偿还 v9 的叙事债。

**对偶（本轮思想核心）**：轨迹优化让工具**可被认证**（每个运动工具携带管证书），工具调用让轨迹优化**可被组合与恢复**（优化不可行只是一个类型化失败码，触发有界 fallback）。二者不是拼接，而是同一枚硬币：**优化-调用对偶**。

## 1. 研究问题（轮次升级版）

- **Q1（管证书）**：如何由模型误差与扰动界传播逐时刻管半径 r_t，使「管证书有效」既充分（⇒ 真实安全）又不过保守（⇒ 可行率可接受）？Nowcast 前瞻膨胀能否把 v9 的 20 帧滞后压到 1 个控制周期？
- **Q2（工具原子性）**：在不可回滚的物理动作上，如何定义提交语义、有界 fallback 与终止测度，使任意工具调用序列要么 no-op、要么到达认证 Post、要么认证 SafeStop，而绝不留下未监视的部分效果？
- **Q3（规格鸿沟）**：如何在能力契约 Pre/Post 上界定「设计意图」，使优化器不能在谓词缝隙里做 spec gaming？两层契约精化能否把工具语义完全钉死在已认证模块端口上？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 管状证书律（Tube-Certified Trajectory Optimization, TTO）**
5Hz 求解离散管状最优控制：min J = ℓ_task + Σ(ℓ_run + λ_s‖Δa‖²)，s.t. 名义动力学、逐节管间隙 g(s_t) − L_g·r_t ≥ d_safe、停车可行性、控制与状态约束。误差管 r_{t+1} = L_f·r_t + ρ_model(t) + ρ_dist，其中 ρ_model 随 Δ_dom 与 Nowcast 前瞻膨胀。解不可行 ⇒ 类型化返回 `Infeasible`，**不提交**；50Hz 守卫只查 innovation containment（‖s^true − s^nom‖ ≤ r_t）与停车不变式。

**P14 类型化工具调用律（Typed Tool Calling, TCC）**
注册表 T = {τ_j}，τ_j = (Name, Args, Pre, Post, Cost, Cert, Fallback, Commit)。策略只提议 c = ⟨j, a⟩，包装器校验 a ⊨ Args、Pre、预算与证书，返回类型化 ρ ∈ {Success, Fail(code)}。工具**原子安全**：提交点前失败 no-op，提交点后失败必补偿 SafeStop。fallback 有界、无环且终止测度严格下降。所有调用写入证书账本。

**P15 两层契约精化律（Two-Level Contract Refinement）**
v9 模块契约 κ_m（定义 535）为底层；能力契约 γ_j = (Pre, Post, Inv, Uses_m) 为上层。要求 γ_j ⪯ {κ_m}_{m∈Uses_j}：Pre/Post/Inv 可由 Uses_m 的端口词表表达、Cost.WCET ≤ Σ D_m 且落在预算内、Post ⇒ Inv，且对 Uses_m 的任一**允许中立元组合**（v9 定义 536）Post ⇒ Inv 仍成立。部署期静态检查，防止工具层引入未认证语义。

## 3. 与基线的接口（如何退化）

- TTO 超时 / 不可行 / 管证书不可信 ⇒ 退回 v9 AC 采样 + 标量 β 证书（K_eff 同 v9）；
- TCC 不可用 / 注册表校验失败 ⇒ 退回 v9 固定流水线（chunker 直连，无类型化工具）；
- DA-Nowcast 失效 ⇒ r_inflate ≡ 0（中立元），等价 v9 无前瞻管；
- AC 证书失效 / 信任域破坏 ⇒ K_eff ← 1，逐步执行（等价 v8 决策粒度）；
- MW 失效 ⇒ v8 手写网关；DA/SPR/Cal 失效 ⇒ 中立元注入（等价 v7）；全失效 ⇒ v6。

## 4. 预期贡献

1. **管状证书轨迹优化**：把块安全从「标量 β 盖章」升级为「逐时刻误差管 + 规划期硬约束」，并让 infeasibility 成为事前证书信号；
2. **提交语义的类型化工具层**：不可回滚物理动作上的原子安全、有界 fallback 与终止性，把失败恢复从隐式分支变成可审计的调用链；
3. **优化-调用对偶**：轨迹优化提供证书、工具调用提供组合与恢复，两层契约精化把能力语义钉死在已认证端口上；
4. **证书账本**：每个动作可离线重放其安全论证链，直接偿还 v9 的叙事债；E571–E590 覆盖管标定、提前不可行、Nowcast 去滞后、工具原子性/终止性、规格鸿沟红队与端到端。

## 5. 本轮最大风险

**一句话**：轨迹优化器本质是一个「规格黑客」——它会在能力契约 Pre/Post 的谓词缝隙里找到既满足所有已声明约束、又违背设计意图的可行解，而工具调用层会忠实地把这种解当作 `Success` 提交，于是 v9 的「迟中止」风险被转化为更隐蔽的「合法越界」（specification gaming），且运行时监视只检查已写下的不变量，无法发现「没写下的意图」。

## 1. 符号体系增量（定义 540–548）

| 符号 | 含义 |
|---|---|
| OCP(s₀, goal, K) | 离散管状最优控制问题：目标 + 运行代价 + 光滑项，逐节管间隙/停车/控制约束 |
| r_t | 误差管半径：∀t, ‖s_t^true − s_t^nom‖ ≤ r_t |
| L_f, L_g, L_v | f̂ 的 Lipschitz 常数、间隙函数 g 的 Lipschitz 常数、速度不确定界 |
| ρ_model(t), ρ_dist | 模型误差上界（随 Δ_dom 与 TN 膨胀）、外部扰动上界 |
| Ĉ^tube = (s^{1:K}_nom, r^{1:K}, m^{1:K}, P) | 管证书：名义状态、管半径、逐节裕度、中止点集 |
| m_t = g(s_t^nom) − L_g·r_t − d_safe | 逐节管间隙裕度（m_t ≥ 0 ⇔ 该节管安全） |
| P_t | 管余量下满足停车不变式的中止点集（定义 542） |
| τ_j = (Name, Args, Pre, Post, Cost, Cert, Fallback, Commit) | 工具模式（定义 543） |
| γ_j = (Pre, Post, Inv, Uses_m) | 能力契约（定义 546） |
| ρ ∈ {Success, Fail(code)} | 类型化调用结果；code ∈ {ARG, PRECOND, INFEASIBLE, TIMEOUT, CERT, POST, BUDGET} |
| κ_j = commit | 提交点：首个不可逆副作用边界（定义 545） |
| E = (t, j, a, witness, Ĉ^tube, fallback, ρ) | 证书账本条目（定义 547） |
| r_inflate(t) | Nowcast 前瞻膨胀量（定义 548） |

**新增定义 540（离散管状最优控制问题 TubeOCP）** 给定名义动力学 s_{t+1}=f̂(s_t,a_t)、初始状态 s₀、时域 K、目标 ℓ_task、运行代价 ℓ_run、约束集，求解
```
min_{a^{1:K}}  J = ℓ_task(s_K) + Σ_{t=1}^{K} [ ℓ_run(s_t, a_t) + λ_s·‖a_t − a_{t−1}‖² ]
s.t.  s_{t+1} = f̂(s_t, a_t)
      g(s_t) − L_g·r_t ≥ d_safe                      ∀t      (逐节管间隙)
      d_brake(v_t) + L_v·r_t ≤ g(s_t) − L_g·r_t − d_safe − |traj_{t:K}|   (停车可行性)
      a_t ∈ A,  s_t ∈ S_feas
```
用 SCP 外层 + iLQR 内层求解；解不可行则返回 `Fail(INFEASIBLE, where=argmin_t m_t)`，**不产生可提交动作**。热启动沿用上一块尾段，使 5Hz 求解摊销到 50Hz。

**新增定义 541（误差管 Error Tube）** 由感知不确定 r_obs、模型 Lipschitz 常数 L_f、扰动界 ρ_dist 递推：
```
r_0 = r_obs,    r_{t+1} = L_f·r_t + ρ_model(t) + ρ_dist,
ρ_model(t) = ρ_0 + α_dom·Δ_dom(t) + r_inflate(t)          (定义 548)
```
不变式（**管包含**）：若真实扰动与模型误差均在界定内，则 ‖s_t^true − s_t^nom‖ ≤ r_t ∀t。管半径是**逐时刻**的，故 v9 的标量 β 是它在稳态、无域偏移下的特例。

**新增定义 542（管证书与中止点 TubeCertificate）** 一次 5Hz 求解的输出：
```
Ĉ^tube = ( s^{1:K}_nom,  r^{1:K},  m^{1:K},  P_t )
m_t      = g(s_t^nom) − L_g·r_t − d_safe
P_t      = { p : d_brake(v_p) + L_v·r_p + d_safe + |traj_{p:K}| ≤ g(s_p^nom) − L_g·r_p }
```
证书有效 ⇔ min_t m_t ≥ 0 ∧ P_t ≠ ∅ ∧ 最近一次 innovation containment 成立。P_t 由停车不变式**解析**给出，取代 v9 的启发式枚举；"无点可退"仅出现在 K=1 fallback（等价 v8 逐步语义）。

**新增定义 543（工具模式 ToolSchema）** 能力层的一等公民：
```
τ_j = ( Name_j,                                   # 工具名
        Args_j,                                   # 类型化参数模式：类型 + 值域 + 单位
        Pre_j,                                    # 前置条件：世界状态 × 账本 → Bool
        Post_j,                                   # 后置条件：结果 × 管证书 → Bool
        Cost_j = (WCET_j, E[cost]_j),             # 时间与期望代价
        Cert_j ∈ {required, optional},            # 是否强制携带管证书
        Fallback_j,                               # 有序、有界、无环的后备工具元组
        Commit_j )                                # 提交点在参数化步序中的位置（None=纯观测）
```
默认注册表（能力层，位于 MW 之上）：
| 工具 | Args | Pre | Post | Commit | Fallback |
|---|---|---|---|---|---|
| `TrajOptBlock` | goal, K, ρ_model, warm | 信任域内 ∧ 预算足 | 管证书有效 | 块首步 | `Replan(K↓)` → `SafeStop` |
| `SafeStop` | — | 有可行停车轨迹 | 速度=0 ∧ 间隙≥d_safe | 立即 | ∅（终局） |
| `Replan` | K', goal | 新预算可用 | 新管证书有效 | 块首步 | `SafeStop` |
| `AskOperator` | question, timeout | 人机通道在线 | 答复或超时码 | 无（纯交互） | `SafeStop` |
| `Measure` | target | 传感器在线 | 读数 + 置信度 | 无（纯观测） | ∅ |

**新增定义 544（工具调用与类型化结果 ToolCall）** 调用 c = ⟨j, a⟩，要求 a ⊨ Args_j。包装器返回
```
ρ ∈ { Success(Post_j ∧ Cert_j.valid),
      Fail(code, ctx) },  code ∈ {ARG, PRECOND, INFEASIBLE, TIMEOUT, CERT, POST, BUDGET}
```
纪律：**策略只能提议，包装器负责处置**——策略无法绕过 schema、前置条件、预算与提交语义。失败码是可被高层消费的一等信号（如 `INFEASIBLE` ⇒ 调 `Replan(K↓)`），而不是异常文本。

**新增定义 545（提交语义 Commit Semantics）** 每个物理工具声明提交点 κ_j（首个不可逆副作用的边界）。工具**原子安全** ⇔
```
(提交前失败)  ⇒ 世界状态不变（no-op）；
(提交后失败)  ⇒ 必须调用补偿 SafeStop 到达认证安全态。
```
复合调用 c₁;c₂;… 安全 ⇔ 每步原子安全 ∧ fallback 链有界无环 ∧ 终止测度 μ（剩余安全裕度或剩余 fallback 计数）沿每次 fallback 严格下降。

**新增定义 546（能力契约与两层精化 CapabilityContract / Refinement）** 能力契约 γ_j=(Pre_j, Post_j, Inv_j, Uses_m) 声明该工具使用的模块集合与不变量。精化关系
```
γ_j ⪯ {κ_m}_{m∈Uses_j}  当且仅当
 (i)   Pre_j / Post_j / Inv_j 的谓词可由 Uses_j 的输出端口词表表达；
 (ii)  Cost_j.WCET ≤ Σ_{m∈Uses_j} D_m 且 ≤ 剩余预算 B_dec；
 (iii) Post_j ⇒ Inv_j；
 (iv)  对 Uses_m 的任一允许中立元组合（v9 定义 536），(iii) 仍成立。
```
(i)–(iv) 在部署期静态检查。这是 v9 模块契约之上的**能力层契约**：工具不引入任何无法由已认证端口观测的新语义，且其在任何退化组合下都不会把越界伪装成成功。

**新增定义 547（工具组合与证书账本 ToolComposition & CertificateLedger）** 组合图 G_T：节点为工具，边 j→j′ 允许当 Post_j ⇒ Pre_{j′}。每次调用写入账本条目
```
E = ( t, j, a, pre-witness, Ĉ^tube, fallback-trace, ρ )
```
账本不变式：每条 `Success` 的 E 必含有效管证书；每条 `Fail` 必指向 fallback 或 SafeStop。账本支持离线重放：给定 (s₀, E_{1:n}) 可逐步复核每个谓词与每条管约束，形成**可审计的安全论证链**。

**新增定义 548（DA 管预膨胀 TubeNowcast）** 用变化点检测（CUSUM / 滑窗 KL）+ 短时外推预测前瞻域偏移：
```
Δ̂_dom(t+h) = Δ_dom(t) + h·δ̂(t),   r_inflate(t) = α_nc·max(0, Δ̂_dom − Δ_dom)
```
前瞻膨胀先于 v9 的 20 帧滑窗触发；置信度低时取保守上界。TN 失效 ⇒ r_inflate ≡ 0（中立元），退回 v9 无前瞻管。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v8 不变。
**定义 521（DA-OTL）** 继承 v8 不变。
**升级定义 532（动作块，v10）** 块不再只是 K 步动作，而是 `ζ_t = (TrajNom^{1:K}, Ĉ^tube, P_t, tool-trace)`：名义轨迹、管证书、中止点集与产生它的工具调用链。5Hz 由 `TrajOptBlock`（TTO）生成；TTO 不可用则退回 v9 的 `(a^{1:K}, Ĉ, P)` 采样块。
**升级定义 533（块证书，v10）** 标量 β 证书升级为管证书（定义 542）：`Ĉ^tube` 对误差管最坏情形给出逐节保守界，取代 v9 的 `ĝ_min = min F̂ − β`。
**升级定义 534（中止点，v10）** P_t 由管余量下的停车不变式解析给出（定义 542），并在每步计入速度不确定 `L_v·r_p`；不再依赖采样枚举。
**升级定义 535（中间件契约，v10）** κ_m 不变；新增其上层能力契约 γ_j（定义 546），两者构成两层契约。MW 仍负责模块级 EDF 与中立元注入；TCC 只调用通过精化的工具。
**升级定义 539（有效块长，v10）** K_eff 公式不变；另受 TTO 可行域约束，`K_eff^TTO = min(K_eff, K_feasible)`，K_feasible 为管约束可解的最大时域。

# IP-357 TubeTrajOpt：管状证书轨迹优化器
class TubeTrajOpt:
    def __init__(self, f_hat, g_clear, L_f, L_g, L_v, rho_dist,
                 d_safe=0.15, K_max=10, dt=0.02, iters=8, lam_s=0.1):
        self.f, self.g = f_hat, g_clear
        self.Lf, self.Lg, self.Lv = L_f, L_g, L_v
        self.rho_d, self.d_safe = rho_dist, d_safe
        self.K_max, self.iters, self.lam_s = K_max, iters, lam_s
        self.d_brake = lambda v: 0.5 * v * v / 2.0

    def tube_radius(self, r0, rho_model, K):
        r = [r0]
        for t in range(K):
            r.append(self.Lf * r[-1] + rho_model[t] + self.rho_d)
        return r

    def solve(self, s0, goal, K, rho_model, r_obs, warm=None):
        K = min(K, self.K_max)
        r = self.tube_radius(r_obs, rho_model, K)
        x = warm or self._warm_start(s0, goal, K)
        for _ in range(self.iters):                          # SCP 外层
            x = self._ilqr(x, s0, goal, K, r)                # iLQR 内层
            m = [self.g(s) - self.Lg * rt - self.d_safe
                 for s, rt in zip(x.states, r)]
            if min(m) < 0:                                   # 逐节管间隙
                return ToolResult.fail('INFEASIBLE', where=argmin(m))
        P = self._abort_points(x, r)                         # 解析停车可行性
        if not P:
            return ToolResult.fail('INFEASIBLE', code='NO_ABORT_POINT')
        return ToolResult.success(TubeCertificate(x.nominal, r, m, P))

    def _abort_points(self, x, r):
        pts = []
        for p in range(1, len(x.actions)):
            lhs = (self.d_brake(x.speed[p]) + self.Lv * r[p]
                   + self.d_safe + x.remaining_len(p))
            rhs = self.g(x.states[p]) - self.Lg * r[p]
            if lhs <= rhs:                                   # 管余量停车不变式
                pts.append(p)
        return pts

    def guard(self, cert, k_exec, live):
        """50Hz 廉价守卫：containment + 停车，O(1)"""
        if live.innovation > cert.r[k_exec]:                 # 管包含被破坏
            return ('abort', cert.nearest_abort(k_exec))
        lhs = (self.d_brake(live.v) + self.Lv * cert.r[k_exec]
               + self.d_safe + cert.remaining_len(k_exec))
        if lhs > self.g(live.s) - self.Lg * cert.r[k_exec]:
            return ('abort', cert.nearest_abort(k_exec))
        return ('continue', k_exec + 1)


# IP-358 ToolCallController：类型化工具调用控制器
@dataclass
class ToolSchema:
    name: str; args: dict; pre: Callable; post: Callable
    wcet_ms: float; cert_required: bool
    fallback: tuple; commit_at: int | None; uses_modules: tuple

class ToolCallController:
    def __init__(self, registry, refiner, ledger, budget_ms=20.0):
        self.T, self.refiner, self.ledger = registry, refiner, ledger
        self.budget_ms = budget_ms
        for j, tau in registry.items():                      # 部署期静态检查
            assert refiner.refines(tau), f'{j} 未通过 γ⪯κ 精化'
            assert refiner.fallback_acyclic(tau.fallback)

    def call(self, j, args, world, deadline_ms):
        tau = self.T[j]
        if not self._validate(tau, args):
            return self._recover(tau, 'ARG', world, committed=False)
        if not tau.pre(world, self.ledger):
            return self._recover(tau, 'PRECOND', world, committed=False)
        if tau.wcet_ms > deadline_ms:
            return self._recover(tau, 'BUDGET', world, committed=False)
        committed = False
        try:
            with deadline_guard(tau.wcet_ms):
                result = tau.run(args)                       # 工具内部标记提交
                committed = result.committed
            if tau.cert_required and not result.cert.valid(world):
                raise CertificateInvalid()
            if not tau.post(result):
                raise PostconditionViolation()
        except DeadlineOverrun:
            return self._recover(tau, 'TIMEOUT', world, committed)
        except CertificateInvalid:
            return self._recover(tau, 'CERT', world, committed)
        except PostconditionViolation:
            return self._recover(tau, 'POST', world, committed)
        self.ledger.append(j, args, result.cert)             # 证书账本
        return ToolResult.success(result)

    def _recover(self, tau, code, world, committed):
        if not committed:                                    # 提交前 ⇒ no-op
            self.ledger.append(tau.name, code=code, committed=False)
            return self._fallback(tau, code, world)
        # 提交后 ⇒ 必须补偿到认证安全态（P14 原子安全）
        return self.call('SafeStop', {}, world, deadline_ms=self.budget_ms)

    def _fallback(self, tau, code, world):
        for nxt in tau.fallback:                             # 有界、无环、μ↓
            r = self.call(nxt, self._args_for(nxt, world), world,
                          deadline_ms=self.budget_ms)
            if r.ok:
                return r
        return self.call('SafeStop', {}, world, deadline_ms=self.budget_ms)

## 4. 推导

**引理 87（管证书可靠性 / Tube Soundness）** 设 (a) 管包含不变式成立：∀t, ‖s_t^true − s_t^nom‖ ≤ r_t；(b) 间隙函数 g 为 L_g-Lipschitz；(c) 管证书有效，即 min_t m_t ≥ 0 且 P_t ≠ ∅。则对任意在界定内的真实扰动，真实轨迹满足 g(s_t^true) ≥ d_safe ∀t；且中块任一时刻存在 p* ∈ P_t 使带管余量的停车不变式成立，可安全停驻。
证明：(i) g(s_t^true) ≥ g(s_t^nom) − L_g‖s_t^true − s_t^nom‖ ≥ g(s_t^nom) − L_g·r_t = m_t + d_safe ≥ d_safe。(ii) 对 p ∈ P_t，由定义 542 的 lhs ≤ rhs 得刹停终点距障碍 ≥ d_safe；骨架保证 P_t 非空才接受块。∎
与 v9 引理 82 的区别：v9 只假设标量一致误差 ‖F̂−F‖∞ ≤ β 并给出**预测指标**的保守界；此处是**逐时刻状态管**，容错更细，且约束在规划期强制，不依赖运行时才发现。

**引理 88（管包含下无迟中止 / No Late Abort under Containment）** 若管包含不变式成立且真实误差在 ρ_model(t) 内，则管证书在规划期有效 ⇔ 执行期安全；特别地，若某时刻真实间隙将跌破 d_safe 而计划仍被提交，则管包含必在规划期或执行**首周期**被违反，50Hz 守卫的 innovation containment 检测（‖s^true−s^nom‖ > r_t）在 ≤1 周期内触发中止。故不存在「证书已失效但 K_eff 仍大」的跨窗口迟到。
证明：由 87 反向；innovation e_t = ‖s^true − s^nom‖，e_t > r_t 即 containment 破坏被守卫直接观测；在 e_t ≤ r_t 期间由 87 保证安全。剩余滞后仅来自 ρ_model 被低估，由定义 548 的前瞻膨胀降低其概率。∎

**引理 89（工具原子安全与组合终止）** 若注册表 T 中每个工具原子安全（定义 545），fallback 链有界且无环，终止测度 μ 沿 fallback 严格下降，则任意工具调用序列在 ≤ Σ_j |Fallback_j| 步内终止，且每一步世界状态 ∈ {提交前不变, 认证 Post, 认证 SafeStop}；不存在未监视的部分效果。
证明：对调用步数归纳；提交前失败由 no-op 保持状态，提交后失败由 SafeStop 到达安全态；有界 + 无环 + μ 良基给出终止上界。∎

**引理 90（两层契约精化保语义）** 若 γ_j ⪯ {κ_m}（定义 546 的 (i)–(iv)），则工具 j 的可观测输入输出与不变量完全由已认证模块端口决定，工具层不引入新语义；且 Cost_j.WCET 落在模块截止期之和与预算内，不破坏 v9 引理 86 的 50Hz 守恒。
证明：(i) 谓词可表达性把工具语义嵌入模块端口；(iii)+(iv) 保证任意退化组合下 Post ⇒ Inv；(ii) 的 WCET 不等式与三角不等式给出周期总执行上界。∎
注意：本引理只保证**已写下**的语义；「未写下的意图」不在精化覆盖内——这正是第 8 节风险。

**引理 91（退化等价 / v10 → v9 → v8）** TTO 超时/不可行/管证书不可信 ⇒ 使用 v9 AC 采样 + 标量 β 证书，K_eff 与 v9 相同，块决策逐位等价 v9；TCC 不可用 ⇒ 直接 chunker 流水线，等价 v9 主闭环；TN 失效 ⇒ r_inflate ≡ 0，等价 v9 无前瞻管。故任一 v10 组件失效均退回 v9 对应级，安全性由引理 82–86 传递；v9 再按原链退回 v8/v7/v6。∎

## 8. 本轮最大风险

**一句话**：轨迹优化器本质是一个「规格黑客」——它会在能力契约 Pre/Post 的谓词缝隙里找到既满足所有已声明约束、又违背设计意图的可行解，而工具调用层会忠实地把这种解当作 `Success` 提交，于是 v9 的「迟中止」风险被转化为更隐蔽的「合法越界」（specification gaming），且运行时监视只检查已写下的不变量，无法发现「没写下的意图」。
