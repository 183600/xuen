**本轮最重要的核实结论**：在这场考试里，「共情表达」**不可能**指情感/表情/语音——F25 根本没有这类通道；硬套情感计算会立刻脱离计分轴。它能成立的唯一严谨解释是两条：**认知共情**（从演示与干扰备注中读出人类对"任务状态"的心智模型）与**行为表达**（用平滑、可预测、可回退的动作把机器人的意图/把握/让位表达出来，且不违反 F21 的动作规律性）。这正好把两个灵感词接上：**演示数据是人类教师写的"正向语句"，人为干扰备注是人类观察者写的"反向语句"，共情就是读懂这两句话背后的同一个部件状态心智模型。**

## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（演示数据 → 演示不是 (s,a) 数据集，而是一段"有语用的对话"）**
直觉：标准 LfD 把 32k 条轨迹当成状态-动作对，用流匹配平均掉一切"与任务无关"的东西。但人是**一边做一边教**的：在接触前几毫米会放慢、会先对准再插入、会在易碎物前停顿、会在不确定时回退重对。这些**慢、停、对、退**不推进任务状态，却是演示者在对"未来的学习者"表达"这里重要、这里危险、这里我没把握"。大多数队伍把它们当噪声平滑掉了。**反直觉点：演示数据里最有价值的监督信号，恰恰是任务进度解释不了的那部分残差；而它之所以可学，是因为它在同一任务的不同演示者/场次里系统性地出现在同样的关键相位。** 这就是「共情」的内向一半：读懂教师的用心。

**灵感 2（共情表达 → 人类干扰者其实在展示任务的可逆状态图，机器人应把"把握/让位"表达出来）**
直觉：官方 `human_1/human_4` 备注（F23）暴露了一件被普遍忽略的事——人类干扰者不是随机加噪，而是精确地**撤销已完成子目标**（拉链拉开、盖子拧回、插头拔起、毛巾翻开）。这说明人类心里有一张"部件状态 + 哪些边可逆"的图。机器人若只学正向轨迹，就会假设进度单调递增，被撤销时只能从头再来。**共情的外向一半**是：机器人也应维护这张可逆图，并在动作里**表达**三件事——(a) 我现在要做哪个子目标（可读性/legibility，让人类不必猜、少干预）；(b) 这一步一旦做了就难撤销，所以我要先对准（承诺调度/deference）；(c) 我此刻没把握，所以我平滑地减速重对而不是硬做（诚实的不确定性表达）。**反直觉点：在人为干扰轴上，最好的恢复不是"更快地重试"，而是"少做不可逆承诺 + 让人类看得懂你在做什么"——恢复能力有一部分是"不制造需要恢复的局面"。**

**两者统一（本轮核心论点）**：演示数据与干扰备注是同一个**部件状态图**的正反两面。演示给出正向边（怎么做成），备注给出反向边（怎么被撤销）与扰动边（怎么被移动/拿走）。「共情」就是围绕这张图的两件事：**读**——从演示残差里挖出人类在哪些相位"在意"，从备注里读出哪些状态可逆、人类会从哪里下手；**写**——把部件状态信念、承诺时机、把握程度用平滑动作表达出来，既降低被干预概率，也让被干预后的修复只针对被撤销的那一个子目标。**本轮结论：中期胜负手从"数据引擎"再往前推一格——是"带语用结构与可逆状态的数据引擎"；演示数据不只教动作，还教"人类怎么想这个任务"。**

## 2. 严谨定义（先直觉，后形式）

**定义 1（部件状态谓词与可逆图）**：设 \(\mathcal P=\{p_1,\dots,p_K\}\) 为布尔部件状态谓词（如 `zip_closed`、`cap_on`、`plug_inserted`、`towel_folded`、`bowl2_stacked`、`phone_in_case`），任务目标为 \(G\subseteq\mathcal P\)。由演示诱导正向边集 \(E^+\)（含每条边的转移动作策略），由 `human_1/human_4` 备注诱导反向边集 \(E^-\)（撤销）与扰动边集 \(E^\sim\)（移动/移除/遮挡），得**可逆部件状态图** \(\mathcal G=(\mathcal P,E^+\cup E^-\cup E^\sim,w)\)，\(w\) 为观测频率/代价。它不是 DAG：撤销制造环；进度不是单调势函数，而是带回退的信念轨迹。

**定义 2（部件状态信念）**：\(b_t(k)=\Pr(p_k=\text{true}\mid o_{1:t},a_{1:t-1})\)，由轻量部件检测/分割维护。任务进度 \( \Phi(b_t)=\sum_k w_k b_t(k)\) 允许下降。**人类心智模型**用**干预风险场**近似：\(h_t(k)=\Pr(\text{人类在 }t\text{ 撤销/移动 }p_k\mid o_{1:t})\)，从备注先验 + 人手/部件邻近度估计。认知共情 = 维护 \(h_t\) 并用它决定"保护哪个状态、先做哪一步"。

**定义 3（可逆代价与承诺门）**：对一次不可逆转移（插入、封口、叠最后一个、拉合），设 \(p\) 为前置条件（对准）的后验、\(\Delta s\) 为该里程碑步骤分增量、\(F\) 为失败/需撤销的代价、\(c\) 为延后对准的时间成本、\(\rho\) 为人类干预导致撤销的期望概率。则**承诺当且仅当**
\[
p\cdot\Delta s-(1-p)\,F(1+\rho)\;\ge\;-c+\mathbb E[V_{\text{next}}(p')],
\]
近似给出承诺阈值
\[
p^\*(F,\rho)\approx\frac{F(1+\rho)+c}{\Delta s+F(1+\rho)} .
\]
它随不可逆代价 \(F\) 与干预概率 \(\rho\) 单调上升：**人在场时，机器人对不可逆步骤更保守**——这就是"让位/共情"的可计算版本，而不是礼貌口号。关键是它**只改变承诺时机，不改变动作统计形态**，因此不触碰 F21。

**定义 4（可读性）**：对动作段 \(\xi\) 与真实子目标 \(g\)，可读性 \(L(\xi)=\Pr_{g'\ne g}\big[g=\arg\max_g \Pr(g\mid \xi_{1:t})\big]\) 在尽可能小的 \(t\) 成立（Dragan 式早推断）。工程代理：用**进度头/部件检测器当"影子观察者"**，其推断子目标与策略意图一致所需的时间越短，可读性越高。表达 = 在时间预算内最大化 \(L\)，且动作平滑（F21）。

**定义 5（示教语用残差）**：用进度条件动作模型 \(f(a\mid o,\Phi)\) 拟合全部演示，残差 \(r_t=a_t-f(o_t,\Phi_t)\)。把 \(r_t\) 投影到"用心特征"（速度下凹、朝向对准、回退重对）得显著度 \(s_t\)。**判据（可证伪）**：只有**跨演示者/跨场次一致**的 \(s_t\) 才是"教学信号"；若换一个演示者就消失，则只是个体习惯/硬件噪声，必须丢弃。这条判据把"共情"从文学修辞变成可做消融的假设。

## 3. 对前两轮痛点的增量修订

- P1（弱任务支配均分）补充：弱任务里有一部分是**可逆步骤多、承诺点密**的任务（T10/T14/T16/T19/T27）；它们的分数损失常发生在"撤销后从头再来"，而非"从未学会"。I10 的定向修复比再加数据更省。
- P3（人为干扰）细化：从"检测人手→停持"升级为"预测**哪个子目标**会被撤销→保护/延后承诺/定向修复"；干扰不是噪声，是有结构的反向操作。
- P5（时间压力）补充：承诺门会花时间对准，但省下撤销后重跑的时间；净收益要用 L0 的"修复时间 vs 对准时间"算，不能默认慢就是亏。
- P8（示教质量）升级：质量不只"平滑/效率"，还有"**语用信息量**"——在关键相位有清晰减速/对准的演示，比一路匀速的演示更值钱。
- 新增 P9（表达-可信度张力）：F21 要求动作统计规律，而"表达"天然想改变节奏；两者会打架。缓解：表达只允许**平滑的速度/接近轨迹调制**，禁止抖动、突变、离群动作；把"动作统计正常性"作为表达的硬约束而非事后检查。

## 4. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（可逆图与干预先验）**：如何从 32k 正向演示 + 32 条 `human_1/human_4` 文字备注，半自动构建每任务的可逆部件状态图与干预热点？备注文本到谓词/边的映射误差如何界定？
- **Q10（语用残差的辨识）**：示教残差中哪一部分是跨演示者一致的"教学信号"、哪一部分是个体噪声？用什么留出协议（留演示者/留场次/留时段）与统计量把二者分开？
- **Q11（表达的约束优化）**：在步骤分/时间预算与 F21 动作规律性双重约束下，承诺门与可读性调制能否净提升人为干扰轴成功率，而不伤标称场景与可信度？

## 5. 设计原则（新增 PR6–PR8，其余保留）

- **PR6 状态可逆律**：任何"完成"都要问"人类能不能、会不会把它撤销"；不可逆承诺越晚越好，除非证据充分。与 PR1（计分轴对齐）互补：PR1 管做对，PR6 管别白做。
- **PR7 表达即约束优化**：表达不是风格，是在时间/步骤分/动作规律性约束下最大化可读性与让位收益的解；无约束的"表演"一律否决。
- **PR8 跨人验证**：任何从演示里读出的"共情/用心"信号，必须在**留出演示者**上复现才允许进入训练权重；否则视为个体噪声。与 PR5 数据杠杆律互补：PR5 问"教什么"，PR8 问"这是不是真的在教"。
- PR1–PR5 保留（第 1–2 轮）。

## 7. 本轮最大风险

**一句话**：I10/I11 把演示里的"慢/停/对/退"读成跨人一致的"用心信号"，但若它主要来自个别演示者习惯、遥操作设备延迟或任务本身的速度分布，那么按显著度加权会把数据引擎带向**对演示者过拟合**——这是必须先过「留出演示者」L0 验证、再放量的点。

## 8. 下轮迭代计划（深化与修剪，不推倒）

- **深化**：I10（把 32 条 `human_1/human_4` 文本编译成谓词/反向边的最小 schema，先做 T10/T14/T16/T19 四任务原型）；I11（承诺门的阈值公式在离线回放上标定 \(F,\rho,c\)，并用影子观察者测可读性）。
- **修剪**：若 I10 的跨演示者一致性检验失败，则 I10 降级为「仅用备注做状态机先验」，不进入训练权重；I11 若在 L0 上出现动作统计异常（F21 冲突），只保留"延后不可逆承诺"、砍掉可读性调制。
- **待核实**：人为干扰是脚本化还是自适应、发生时序；N 值；步骤分是否只在成功时计；影子观察者（进度头）与真人观察者的可读性相关性。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 可逆部件状态图 + 人类干预心智模型（读共情）★★★★★（新）

- **动机**：人为干扰轴（F23/F24）占每任务 2/10 次，且官方干扰主要是**撤销已完成子目标**；但 32k 演示全成功、无失败、无干预（F26），模型默认进度单调，被撤销时只能从头重跑。人类干扰者的 `human_1/human_4` 备注其实是一份**人类写的"任务可逆性说明书"**，目前完全没被利用。
- **与现有方案差异**：多数队伍把干扰当噪声/异常，做"检测人手→停一下"（I4 v1）；本点把干扰当**有结构的反向操作**，显式建图：正向边来自演示，反向/扰动边来自官方备注，据此预测"人类会从哪下手"，并只修复被撤销的那一个子目标。
- **技术可行性**：高。图与谓词是轻量符号层；备注仅 32×2 条，可人工校对。部件检测/分割可用开放词汇模型零训练起步；与 I3 的关键点伺服共享检测器。
- **所需资源**：标注/编译 1 人周；检测器复用 I3；无需额外大模型。
- **落地步骤**：
  1. 定义谓词 schema（例：`zip_closed`、`cap_on`、`plug_inserted`、`towel_folded`、`bowl2_stacked`、`note_pinned`、`phone_in_case`）；
  2. 用演示的终态/关键帧半自动生成正向边；用 `human_1/human_4` 文本编译反向/扰动边（先 T10/T14/T16/T19 四任务）；
  3. 训练/接一个部件状态信念头 \(b_t\)（可用进度头 + 谓词分类器）；
  4. 由备注分布 + 人手/部件邻近度得干预风险场 \(h_t(k)\)；
  5. 定向修复策略：撤销检测 → 在可逆图上找被破坏的最早谓词 → 只重做该子目标；
  6. 把反向边交给 I5 生成「撤销增广」示教。
- **风险**：备注文本到谓词的映射有歧义（"锁向左移动"是扰动还是撤销？）→ 人工校对 + 保守归为扰动；谓词检测误报导致误修复 → 置信门控 + 迟滞（沿用 I4）。**最大风险是 I10 若只靠备注、不靠演示，可能退化为一张脆弱的规则表。**

### I11 表达性承诺调度（写共情）★★★★（新）

- **动机**：F21 把"动作统计规律性"纳入可信度；人为干扰轴的失败多发生在**不可逆承诺被撤销**之后。人类演示天然展示了"何时该慢、何时该对准、何时该做"（承诺时机），而流匹配把它平均掉了。
- **与现有方案差异**：直接 SFT 输出"平均动作"；本点学两样东西——(a) **承诺调度**：对不可逆步骤，用后验对准度 \(p\) 与干预风险 \(\rho\) 决定"现在做还是再对一下"；(b) **可读性调制**：用影子观察者（进度头）当代理人类，若它推断的子目标与策略意图不一致，就平滑减速/重对，让"意图"更早可读。表达只在**时间/步骤分预算内**、且**只做平滑速度/接近轨迹调制**，以满足 F21。
- **与 I10 的关系**：I10 提供"哪些是承诺点、人类会从哪撤销、当前信念 \(b_t\)"；I11 用这些量做在线决策与动作调制。二者共享同一张可逆图与同一个部件状态头。
- **技术可行性**：中-高。承诺门是 O(1) 后处理；可读性调制复用 I6 的 chunk 后处理；影子观察者复用进度头。无需新增前向。
- **所需资源**：离线标定 1 人周 + 单任务通道抽测；推理零额外模型。
- **落地步骤**：
  1. 从演示残差学"关键相位/承诺点"（见 §1.1）；
  2. 在离线回放上标定承诺阈值 \(p^\*\) 的三个量 \(F,\rho,c\)；
  3. 实现影子观察者可读性代理；
  4. 实现平滑速度/接近调制（限幅、限加速度，保证统计规律）；
  5. 在 T10/T14/T16/T19 的 `human_1/human_4` 脚本上做 L0/L2。
- **风险**：表达改变动作节奏，可能触发 F21 的"异常/不规则"判定 → 严格限幅 + 只做低频平滑调制 + L0 动作健康度门禁；承诺门可能过度保守拖垮时间分 → 用净收益（省下的重跑时间 vs 对准时间）做准入，不默认慢就是好。

def commitment_gate(p_align, ds, F, rho, c, V_next):
    # 不可逆转移的期望收益比较（§2 推导）
    return p_align * ds - (1 - p_align) * F * (1 + rho) >= -c + V_next

def expressive_chunk(policy, obs, b, hazard, budget):
    chunk = policy.propose_chunk(obs)              # 基线动作
    if is_irreversible_step(obs, b):
        p = align_confidence(obs, b)               # 关键点/位姿对准度
        if not commitment_gate(p, *params(obs, hazard)):

## 2. 推导：为什么"共情"在人为干扰轴上能提分

**承诺门的收益比较。** 在一次不可逆转移处：
- 现在做：以 \(p\) 成功得 \(\Delta s\)，以 \(1-p\) 失败并需撤销/修复，代价 \(F(1+\rho)\)（\(\rho\) 为人类干预导致撤销的期望概率）；
- 再对一下：付出时间成本 \(c\)（可能损失步骤分/逼近超时），换来后验 \(p'\) 与后续价值 \(\mathbb E[V_{\text{next}}(p')]\)。

比较两者得承诺条件
\[
p\,\Delta s-(1-p)F(1+\rho)\;\ge\;-c+\mathbb E[V_{\text{next}}(p')].
\]
在 \(\mathbb E[V_{\text{next}}]\) 随 \(p\) 单调的温和假设下，存在阈值
\[
p^\*\approx\frac{F(1+\rho)+c}{\Delta s+F(1+\rho)} .
\]
三条可检验推论：
1. \(\partial p^\*/\partial F>0\)：越不可逆（插头、封口、叠最后一个）越该先对准；
2. \(\partial p^\*/\partial \rho>0\)：**人在场/干预风险高时更保守**——"让位"不是礼貌，是期望收益；
3. \(\partial p^\*/\partial \Delta s<0\)：高步骤分里程碑值得更早承诺。

**与 F21 的相容性。** 承诺门只改变**在哪个 \(p\) 上做**，不改变动作的统计形态；可读性调制只允许平滑减速/接近（限幅、限加速度），因此不制造 F21 所说的"异常离群/不规则交互"。这是 I11 能同时服务"表达"与"可信度"的关键。

**为什么"撤销增广"是数据问题而非模块问题。** 官方干扰是反向边（F23）。没有失败/撤销数据的策略，只能靠运行时脚本硬编码恢复；而把反向边作用在成功演示终态上，就得到分布内的"撤销→修复"轨迹，直接训练恢复行为。这与第 2 轮"恢复能力只能靠合成失败示教获得"的判断一致，本轮把它从"随机扰动"精确到"沿人类实际会用的反向边扰动"。
