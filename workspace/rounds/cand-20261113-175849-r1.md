# 第 67 轮（新灵感驱动研究循环 第 2 轮；本轮灵感词：「文化适应性」×「视觉伺服」）

> 承接第 66 轮 UniBot 参赛清单 v1（IP-C01~C10）。本轮不换赛道，只做一次「风险结构改写」：上轮把身家押在 TwinCal 的物理保真上，头号风险是柔性/插拔任务的数字孪生不达标、仿真预算沉没。两个新灵感词恰好提供两条**与物理保真度正交**的补偿通道——文化适应性负责「把目标定对」，视觉伺服负责「把轨迹收敛对」。据此把 v1 的「仿真即真值源」降级为「仿真只是先验」，清单升到 v2（新增 IP-C11/C12，升级 C01/C02/C06/C08）。

## 0. 本轮检索与事实边界（检索日期 2026-11-13）

- **经典视觉伺服（已核对）**：Chaumette & Hutchinson, *Visual Servo Control Part I: Basic Approaches*, IEEE RAM 13(4):82–90, 2006；Part II, IEEE RAM 14(1), 2007。核心式：`ṡ = L_s v_c`（L_s 为交互矩阵/图像雅可比，含深度 Z）、`e = s − s*`、IBVS 律 `v_c = −λ L̂_e^+ e`；PBVS 在 3D 位姿空间闭环；Espiau/Chaumette/Rives 1992 提出 interaction matrix；Hutchinson/Hager/Corke 1996 为教程。
- **「文化适应性」的语义转译（必须明说）**：HRI 里的 cultural adaptability 通常指社会规范/价值差异。**本轮不做那个语义**，而做一次显式隐喻转译：把评测环境的「家庭惯例」——有什么物品、怎么摆放、桌面什么风格、人怎么打断——当作潜在生成因子 c，称「场景文化」。这是本轮最大的语义跳跃，论文里不能冒充社会文化适应。
- **在线适配的近期证据（检索到，未逐篇精读，记为 R1）**：ContextFlow（ECCV 2026，in-context flow matching，单条 test-time 演示适配未见配置，接近 π0 单演示微调）；Behavior Prompting（arXiv 2606.30457，2026-10，任务多样性而非每任务演示数决定 in-context 能力）；Retrieve-then-Steer（arXiv 2605.10094，2026-05，用在线成功记忆做非参数 TTA）；Self-Adaptive VLA（arXiv 2609.30092，2026-09，用失败 rollout 作 context 适配硬件漂移）。结论：「测试时少样本/上下文适配」在 2026 已可落地；但它们多针对任务配置/硬件漂移，**没有把「场景文化」显式低维化，也没有与视觉伺服闭环结合**——这是本轮的空位。
- 接口约束沿用第 66 轮核实结论（4 路 RGB 480×640、chunk、8765 起 N 端口、逐步延迟与动作统计计入可信度），不重复检索。

## 1. 直觉解释（先直觉）

**直觉 A：评测其实在换「家庭文化」。** 五类泛化里，位置/干扰物/背景/未见物品都是在换一个家庭的家当与陈设；人为干扰是换「这家人怎么插手」。训练集是若干已知家庭，评测是没见过的家庭。人类进新家不是从零学抓取，而是**先扫一眼形成「这家人怎么摆东西」的低维假设**，再按假设做事、边做边改。→ 慢环：开场 m 帧推断一张低维「文化卡」（物品清单/布局惯例/风格/人扰倾向/目标假设），条件化 VLA。

**直觉 B：人抓杯子不是算完 20 步关节轨迹再闭眼执行。** 人盯着目标，边走边修。→ 快环：在图像特征空间闭环收缩 `e = s − s*`，而不是开环执行长动作块。妙处在于：**伺服不需要知道 sim-real gap 是多少，它只需要看见误差并把它减小**——这正好补上 TwinCal 建不出的那部分物理。

**直觉 C（本轮最关键的一句）：文化决定「伺服到哪个 s\*」，伺服只保证「收敛到给定的 s\*」。** 目标错，伺服越好越糟；目标对，没有伺服则执行漂移无人纠正。两环职责不能混，也不能互相替代。这直接改写第 66 轮的风险结构：TwinCal 的物理保真只需支撑「目标图像/感知先验」，不再需要支撑「开环长程重放」。

## 2. 严谨定义（再严谨）

**定义 1（场景文化 c）** 评测 episode 由潜在变量 c ∈ C 生成：c 含物体集合与属性、布局惯例、背景/光照风格、人扰策略、任务目标的合法变体。评测从 p(c) 采样，训练只覆盖 C_train ⊊ C。策略在 episode 开始获得上下文 D_m（前 m 帧 + 语言指令），输出文化估计 ĉ 与目标假设 ĝ。定义**文化适应遗憾** `Regret = E_c[ f(π; c) − f(π_ĉ(c); c) ]`，f 为成功率/步骤分。

**定义 2（图像伺服）** 图像特征 `s(o) ∈ R^k`，目标 `s*`，误差 `e = s − s*`。`ṡ = L_s v_c`，L_s 依赖深度 Z；离散执行下每步收缩因子 `ρ = ||I − λ L̂_e^+ L_e||_2`。**接口约束**：一次返回一个动作块并开环执行，块内不能重算；因此「逐步闭环」只能把块长压到 k=1，这是 C08 与伺服的根本张力。

**定义 3（双环误差分解）** 相对真实目标的特征误差分解为 `e_true = e_goal ⊕ e_exec`：`e_goal` 由文化/目标识别错误（选错 s*）引起，`e_exec` 由 sim-real 偏差、标定误差与随机扰动引起。慢环压 e_goal，快环压 e_exec。

## 3. 三条命题（推导要点）

**命题 3（开环块长的视觉误差上界）** 记 `A = ∂f/∂s`（标称图像动力学）、`b_t` 为模型偏差（含 sim-real/文化漂移）。块长 k 的末端误差满足
`||e_{t+k}|| ≤ ||A||^k ||e_t|| + b_max · Σ_{j=0}^{k−1} ||A||^j`
`= ||A||^k ||e_t|| + b_max · (||A||^k − 1)/(||A|| − 1)`（`||A|| ≠ 1`）。
给定任务容差 ε，安全块长 `k_safe = max{ k : 右端 ≤ ε }`。**推论**：b_max↑（文化/物理迁移越大）或 `||e_t||`↑ ⇒ k_safe↓；`||A||<1`（稳定收敛区）才敢放长块，`||A||≥1` 时 v1 的「长块摊薄延迟」直接失效。这把第 66 轮 C08 的经验式 `P_dist` 触发升级为可计算误差门，也解释为何只有接近目标时才敢长块。

**命题 4（文化可识别性与低维设计原则）** 设成功函数对文化参数 L-Lipschitz，估计误差 `δ = ||c − ĉ||`，则适应后期望成功 `≥ E[f(π_ĉ)] − L·E[δ]`。用 m 个样本估 d 维 c：正则参数情形 `E[δ] = O(m^{−1/2})`；标准非参数速率（启发式引用）`E[δ] = O(m^{−1/(2+d)})`。**推论**：m 只有几十帧时，只有**低维/离散化**文化卡可识别；把文化卡做成连续高维场景参数会把方差吃光，此时最优点是退回先验（不猜）。这为 C11「离散卡片」而非「隐变量回归」提供依据，也解释了 R1 中 in-context 工作强调「任务多样性」而非「每任务样本量」。

**命题 5（双环不可替代性）** 设真实目标特征 `s*_true` 与被选目标 `s*_hat` 的距离 δ_g，伺服把实际特征收敛到 `s*_hat` 的容差 ε_s：`||s − s*_hat|| ≤ ε_s`。由三角不等式
`||s − s*_true|| ≥ δ_g − ε_s`。
故 δ_g > ε_s 时，**任何伺服精度都无法把真目标误差压到 δ_g − ε_s 以下**；反之 δ_g=0 时误差仍受 ε_s 与执行噪声限制。**推论 1（预算配比）**：把伺服精度做到远超目标精度是浪费，最优在 δ_g ≈ ε_s 处平衡。**推论 2（对 C02 的解放）**：TwinCal 只需保证「目标图像/感知先验」可信（δ_g 小），不必保证接触动力学可信（e_exec 交给伺服）——第 66 轮的头号风险被部分解除。**推论 3（步数）**：标量收缩 ρ≈1−λ 时到容差 ε 的步数 `n = ln(ε/||e0||)/ln ρ`；λ 越大步数越少但过冲/失稳风险越大，这正是步骤分与稳定性的显式权衡。

## 4. 对 v1 清单的改写（增量，不重开）

- **新增 IP-C11 CultureCard（慢环）**：开场 m 帧 → 低维离散文化卡（物品清单、布局惯例、风格桶、人扰先验、目标假设排序）→ 作为文本/视觉 token 条件化 VLA；带「不猜」回退（低置信时用训练先验）。
- **新增 IP-C12 VisuoServo Gate（快环）**：用命题 3 的 `k_safe` 决定块长；误差大/模型漂移大 → k=1 逐步 IBVS（C06 立体深度提供 Z，C01/C02 提供目标图 s*）；误差小/进入运输段 → 交回 VLA 长块。C08 的扰动触发并入为其中一个输入。
- **升级 C02 TwinCal**：trust 从「物理保真硬门」拆成 `t_render`（目标图/外观）与 `t_dyn`（动力学）；t_render 决定能否生成 s*，t_dyn 决定能否长块/增广；在线再用伺服残差更新 trust 后验（软先验，不再一刀切禁用）。
- **升级 C01**：SceneSpec 增加 culture 维度，编译器按文化采样，而非全空间随机。
- **升级 C06**：立体深度从「辅助特征」升为「伺服交互矩阵的深度来源」——没有 Z，IBVS 的 L_s 不可算或不准。
- **并入 C03/C04/C05**：课程增加 culture 轴；人扰按文化先验采样；学生额外吃文化卡条件。
- **修剪**：删去「全空间均匀随机化」（命题 4 反例）与「TwinCal 硬禁用」（命题 5 表明只需目标可信）；C07/C09 保留不动。

## 5. 本轮最大风险（一句话）

**文化卡只有几十帧证据却可能「自信地猜错目标」，而伺服会忠实地把机器人收敛到错误目标上——双环把执行误差压小的同时，也把目标错误放大成确定性失败；若没有可验证的「语义一致性检查/不猜回退」，双环架构在最需要它的未见家庭上反而最危险。**

## 2. 新增与升级方案

### IP-C11 CultureCard：低维场景文化卡（慢环）
- **动机**：五轴泛化=换家庭；离线把所有家庭编进训练分布既贵又不可能穷尽。人类靠一次快速「文化假设」+ 在线修正。
- **机制**：开场 m≈30 帧 → 开放词表检测（物体+属性）→ 布局/风格离散分类 → 语言落地得到目标假设排序与 s* 候选；压成一张几十 token 的卡，条件化 VLA（in-context，不更新权重）。置信度低于 τ 时**不猜**，退回训练先验目标。
- **差异**：R1 的 in-context/TTA 多针对任务配置或硬件漂移，且用整条演示/成功记忆作 context；本方案把「评测分布」显式压成**低维离散文化卡**（命题 4 要求），并把它接到视觉伺服的目标选择上。
- **可行性**：高。开放词表检测 + 小分类头；每 episode 一次，不进入逐步环路。风险是检测器本身对未见物品失效。
- **资源**：1 人周；复用仿真渲染做卡分类器的弱监督。
- **步骤**：①在官方 32 任务演示上统计布局/风格/目标变体，聚类成离散桶 → 文化先验库；②卡生成器 + 置信度校准；③条件化方式（文本 token vs 视觉 token）消融；④与 C12 联调「目标重估」触发。
- **风险**：文化卡在未见物品上高置信错误（见第 8 节头号风险）。

### IP-C12 VisuoServo Gate：图像空间误差门与块长调度（快环）
- **动机**：sim-real gap 无法精确建模，但可被「看见误差→减小误差」的闭环吸收；长块则牺牲反应性。需要可计算的切换规则。
- **机制**：由命题 3 算 `k_safe`。误差大/漂移大 → k=1，用腕部 eye-in-hand IBVS 做精细对准（头部立体 eye-to-hand 提供深度与粗定位）；误差小/运输段 → VLA 返回长块。双通道推理：重 VLA 只负责长块，轻量伺服头（<10ms）负责 k=1，避免把大模型拖进 30Hz 环路。目标图 s* 由 C01 渲染或演示末帧原型提供。
- **差异**：经典视觉伺服是连续控制，未考虑「动作块开环执行 + 网络调用延迟」这一接口约束；本方案把伺服做成**块长调度器**，把「何时闭环」变成命题 3 的可计算决策。与 C08 的区别：C08 用扰动检测触发，C12 用图像误差增长上界触发，扰动检测只是其中一个输入。
- **可行性**：中高。IBVS/SGBM 有成熟实现；难点是目标特征选择（抓取点/孔位）与遮挡。
- **资源**：伺服头单卡数天；仿真渲染立体对（C06 复用）。
- **步骤**：①定义每任务的特征集与 s*（孔位/杯沿/夹爪-物体相对位姿）；②实现 `k_safe` 估计器（A、b 用仿真+演示标定）；③双通道服务（VLA/伺服）；④消融：固定块 vs 命题 3 门。
- **风险**：特征在遮挡/弱纹理下丢失 → 必须能静默回退到 VLA 长块与 C08 恢复库。

### IP-C02 v2：TwinCal 从「物理硬门」改为「双信任 + 在线后验」
- **动机**：命题 5 表明伺服只弥补执行误差，目标误差仍需可信的目标图/感知先验；因此物理保真与渲染保真要分开评价。
- **机制**：`t_render`（目标图/外观/相机外参对齐）决定该任务能否提供 s*；`t_dyn`（开环重放误差）只决定能否长块与仿真增广。运行时用伺服残差对 trust 做贝叶斯更新，trust 变低时自动缩块并提高重估频率，而不是离线一刀切禁用。
- **差异**：v1 用一个 trust 标量卡所有用途，导致「物理不准但渲染准」的任务被误杀；v2 让这类任务仍可用仿真出目标图/课程，只是不要用它开环跑长程。
- **步骤**：①分别定义 t_render、t_dyn 的验收指标；②用 32 任务演示重放标定；③在线后验更新规则；④接入 C12 的块长与 C11 的重估频率。

### IP-C06 v2：立体深度 = 伺服的深度通道
- **变更**：从「可选辅助特征」升为「IBVS 交互矩阵的必要输入」。交互矩阵的平移项含 `−λ/Z`，Z 错则增益错、收敛慢甚至发散；头部已矫正立体对（第 66 轮已核实）是免费 Z 源。

```python
# IP-C12：误差门 + 块长调度（快环，每步调用）
class VisuoServoGate:
    def __init__(self, A_hat, b_max, eps, K_MAX=24):
        self.A, self.b, self.eps, self.K_MAX = A_hat, b_max, eps, K_MAX

    def bound(self, e, k):                     # 命题3的误差上界
        Ak = matrix_power(self.A, k)
        if abs(norm(self.A) - 1.0) < 1e-3:
            geom = k * I
        else:
            geom = (Ak - I) @ inv(self.A - I)
        return norm(Ak @ e) + self.b * norm(geom)

    def k_safe(self, e):
        k = 1
        while k < self.K_MAX and self.bound(e, k) > self.eps:
            k += 1
        return max(1, k - 1)

    def act(self, obs, card, vla):
        g = card.goals[0]
        Z = stereo_depth(obs)                  # C06：头部立体
        s = features(obs, g, Z)
        e = s - g.s_star
        k = self.k_safe(e)
        if k <= K_SERVO:                       # 误差大/漂移大：逐步闭环
            a = ibvs_step(e, interaction(s, Z), lam=0.6)
            return a, 1                        # 下次调用重算
        return vla.propose(obs, card, H=k), k   # 运输/接近：长块
```

## 5. 推导（命题 3/4/5）

**命题 3 全文.** 离散特征动力学 `s_{t+1} = f(s_t, a_t) + b_t`，`b_t` 为模型偏差。线性化 `A = ∂f/∂s`，误差 `e_t = s_t − s*`，则
`e_{t+k} = A^k e_t + Σ_{j=0}^{k−1} A^{k−1−j} b_{t+j}`。
取范数并用 `||b_t|| ≤ b_max`：
`||e_{t+k}|| ≤ ||A||^k ||e_t|| + b_max Σ_{j=0}^{k−1} ||A||^j`
`= ||A||^k ||e_t|| + b_max (||A||^k − 1)/(||A|| − 1)`（`||A|| ≠ 1`；`||A||=1` 时第二项为 `k·b_max`）。
于是 `k_safe(ε) = max{k : 右端 ≤ ε}`。对 k 的单调性给出：`∂/∂b_max > 0`、`∂/∂||e_t|| > 0`，故 b_max↑ 或 ||e_t||↑ ⇒ k_safe↓；`||A||<1` 时第二项有界，长块可行；`||A||≥1` 时误差随 k 增长，长块必越界。**工程含义**：C12 的切换不是启发式，而是「用先验误差上界买反应性」。

**命题 4 全文.** 成功函数 f 对 c 为 L-Lipschitz：`|f(ĉ) − f(c)| ≤ L||ĉ − c||`，取期望得 `E[f(c)] ≥ E[f(ĉ)] − L E[δ]`。m 个样本估 d 维参数：正则参数模型 `δ = O_p(m^{−1/2})`；标准非参数速率（Lipschitz 类，启发式）`δ = O_p(m^{−1/(2+d)})`。**设计含义**：在 m≈30 时，d 必须很小（个位数离散状态）；否则 `E[δ]` 不随 m 有效下降，适应收益被估计方差吞掉。故 C11 只输出「物品清单 + 离散布局/风格桶 + 目标排序」，不回归连续场景参数；并保留「不猜」动作，使最坏情况退回先验而非赌错。

**命题 5 全文.** `s` 为实际特征，`s*_hat` 为被选目标，`s*_true` 为真实目标，`δ_g = ||s*_true − s*_hat||`。伺服收敛 `||s − s*_hat|| ≤ ε_s`。三角不等式：
`||s − s*_true|| ≥ ||s*_true − s*_hat|| − ||s − s*_hat|| ≥ δ_g − ε_s`。
上界为 `δ_g + ε_s`。**含义**：δ_g 是伺服无法消除的「目标偏置」；ε_s 是目标正确时也无法归零的「执行容差」。两环的误差不可互换，资源应在 `δ_g ≈ ε_s` 处平衡（拉格朗日视角：单位成本边际降幅相等）。**对 TwinCal**：只要求 `t_render` 使 δ_g 小；`t_dyn` 只影响 e_exec 中可由伺服收缩的部分与长块可行性。

**命题 5 推论（步数-稳定性）.** 标量 IBVS 每步 `e_{t+1} = (1−λ)e_t`（ρ=1−λ），到容差 ε 的步数 `n = ln(ε/||e0||)/ln(1−λ)`；λ↑ ⇒ n↓，但过冲/失稳风险↑（`|1−λ|≥1` 时发散）。步骤分奖励进展，故 λ 的选择是「少走步」与「不过冲」的显式权衡，可作为 C12 的调参目标。
