# 第 41 轮 · 双灵感落地 v8：力矩级认证执行 × 动态避障时空证书 × 安全裕度账本（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「力矩控制、动态避障」刺中 v17 证书体系的两个盲区：证书证明了「生成了什么动作」（运动学）与「在哪儿安全」（静态几何），却没有证明「身体能不能按这个动作出力」以及「安全承诺在移动障碍物逼近时还能活多久」。本轮把证书从「运动学 + 静态几何」推进到「动力学 + 时空」：用收缩管给跟踪误差上保险，用力矩级 HOCBF 把安全约束翻译成力矩可行性，用预测证书给动态障碍物标上不确定球与有限保质期，最终用「安全裕度账本」把分散的证书残差合成一个非负预算。

## 0. 直觉与动机

**灵感 1（力矩控制 → 证书必须在力矩层兑现）**：v17 的流匹配执行器输出动作块，但 CertFlow、C_ms、h_min 全部活在前向运动学世界：它承诺「参考轨迹离障碍 ≥ h_min」「采样误差 ≤ ε_tol」，而真实机器人靠关节力矩驱动——力矩饱和、摩擦、接触切换会让实际轨迹偏离参考。证书与执行之间隔着一条无人认证的「跟踪鸿沟」。力矩控制把这条鸿沟暴露出来：安全不是「参考轨迹离障碍多远」，而是「在力矩预算内，闭环实际状态离障碍多远」。于是补两层证书：a) **收缩管证书**——若闭环跟踪误差动力学关于某度量 M(q) 以速率 λ_c 收缩，则在饱和/模型残差 δ_d 下，实际轨迹被包在半径 ρ_track = e^{−λ_c t}ρ₀ + δ_d/λ_c 的管子里；b) **执行器可行性证书**——把安全约束写成力矩的线性不等式（二阶 HOCBF），与力矩盒 τ∈[τ_min,τ_max] 求交，得到可行性裕度 φ_feas；一旦不可行必须提前降级，而不是到最后一步才发现刹不住。附带一个结构性收益：韵律 s 不再只是速度场条件，而成为**阻抗参数**（刚度 K_p、阻尼 K_d）——「韵律即阻抗调度」，且证书反过来约束哪些韵律是可执行的。

**灵感 2（动态避障 → 安全是时空性质，证书有保质期）**：v17 的 ESDF 是静态快照，CBF 默认障碍物不动；面对走动的人、另一台机器人、被推动的箱子，h_min≥0 毫无意义。动态避障要求把安全函数写成 h(x,t)，并回答三个新问题：a) **障碍物会去哪**——给预测证书（速度估计 + 预测协方差球 B_pred(Δ)，随预测时域增长）；b) **本体现在能多快反应**——这正是灵感 1 的力矩预算：刹车距离 d_stop(v)=v²/(2a_max)+v·t_react 是扭矩极限的函数，动态避障的可行性与力矩控制直接耦合，绝非装饰；c) **承诺还能维持多久**——由于 B_pred(Δ) 单调增大，裕度 β(t+Δ) 最终穿零，于是证书具有**有限保质期 T_cert**；总线必须在到期前重新观测/重规划，证书从「永久文档」变成「需续期的通行证」。

**灵感 3（两灵感合流 → 安全裕度账本 SML）**：把 v17 以来所有保守项——状态漂移 B_t、流采样误差 ε_ode、跟踪管 ρ_track、预测不确定 B_pred、遮挡膨胀 ε_occ、刹车预留 d_stop——统一记为一本**安全裕度账本**：
β(x,t) = h_clear(x,t) − [B_t + ε_ode + ρ_track + B_pred(t) + ε_occ + d_stop(v)]。
每一项带「由哪个 IP 认证、置信度多少、能否在线收紧」的来源标签。安全 ⟺ β≥0；组合技能 ⟺ 账本取 min（min-plus 代数）；预算为负时按「谁能最快回血」调度降级：减速（降 d_stop、ρ_track）→ 增刚（降 ρ_track 但升力矩需求）→ 重观测（降 B_pred、B_t）→ 重规划 → 被动安全姿态（IP-38）。这让「可认证」第一次覆盖从力矩到时空的完整执行闭环。

**与前序轮次的边界**：v17 回答「动作怎么生成、静态几何是否安全」；本轮回答「闭环能否在力矩约束下跟踪、移动障碍下承诺能活多久」。它与「计划级本体可行性」不同：那是派发前的静态可行性，本轮是执行中的动态可维持性。

## 1. 形式化定义

**定义 27（收缩跟踪管 CertTrack）**：机器人状态 x=(q,q̇)，力矩 τ∈R^n，IP-48 给出参考 r(t)。误差 e=x−r，取度量 M(q)≻0。若沿参考的闭环雅可比 A=∂f/∂x 满足收缩条件
Ṁ + AᵀM + MA ⪯ −2λ_c M，
且饱和/模型/摩擦合成残差满足 ‖d(t)‖≤δ_d，则
‖e(t)‖_M ≤ e^{−λ_c(t−t₀)}‖e(t₀)‖_M + δ_d/λ_c。
CertTrack = {M, λ_c, δ_d, ρ_track}，其中欧氏管半径 ρ_track = √cond(M)·e^{−λ_c(t−t₀)}ρ₀ + √cond(M)·δ_d/λ_c。δ_d 由饱和场景下的残差 (1−δ_q) 分位标定（conformal），而非手调。

**定义 28（执行器可行性 / 力矩级 HOCBF）**：对相对阶为 2 的安全函数 h_k(x,t)，定义
ψ_k = ḧ_k + α₁ḣ_k + α₂h_k ≥ 0。
在刚体动力学下 ψ_k 关于 τ 仿射：a_kᵀτ ≤ b_k。定义**可行性裕度**
φ_k = b_k − min_{τ∈[τ_min,τ_max]} a_kᵀτ，
其中盒上最小值逐分量取 min(a_{k,i}τ_i^min, a_{k,i}τ_i^max)。CertTau = {a_k, b_k, φ_feas=min_k φ_k}。φ_feas≥0 ⟺ CBF-QP 可行。另定义有效最大减速度 a_max(q)（由 τ_max、摩擦锥、接触构型认证的下界）与刹车距离 d_stop(v)=v²/(2a_max)+v·t_react。

**定义 29（预测证书 CertPred）**：对障碍物 k，用 Kalman/交互多模型估计 (p,v) 及协方差；预测均值 p̂_k(t+Δ)、协方差 Σ_k(Δ)。定义
B_pred,k(Δ) = c_δ√tr(Σ_k(Δ)) + ½·a_max^obs·Δ²，
第二项是对非合作障碍物的可达集膨胀（加速度上界 a_max^obs）。CertPred = {p̂_k(·), Σ_k(·), B_pred,k(·), T_pred}，仅在 Δ≤T_pred 内有效。

**定义 30（时空安全函数与时空有效域）**：h_k(x,t) = ‖p(x)−p̂_k(t)‖ − r_robot − r_k − B_pred,k(t) − ε_occ。用定义 28 的 HOCBF 约束。**时空有效域**
ValidRegion_ST(C) = {(x,t) : 覆盖成立 ∧ β(x,t) ≥ 0}。
**证书保质期** T_cert = sup{Δ≥0 : 在无新观测下 β(x,t+Δ)≥0}。因 B_pred(Δ) 单调增，T_cert 通常有限；无动态障碍时退化为受 B_t 增长约束的续期问题。

**定义 31（安全裕度账本 SML）**：β(x,t) = h_clear(x,t) − [B_t + ε_ode + ρ_track + B_pred(t) + ε_occ + d_stop(v)]，每个加项是带来源标签的账本条目 ℓ_i=(值, 置信度, 认证 IP, 可在线收紧?)。组合规则：合取 β = min_i β_i；顺序技能 a⪢b 沿跟踪管取 min_t min(β_a, β_b)。赤字 Δβ = max(0,−β)。降级算子 D 在动作集 {减速, 增刚, 重观测, 重规划, 被动安全} 中按代价最小选动作 u，使 β(u)≥0。

**定义 32（证书条件化韵律/阻抗）**：韵律 s=(s_v, K_p, K_d)，ρ_track 与 φ_feas 均依赖 s。可执行韵律集
S_cert(x,t) = {s : β(x,t;s) ≥ 0 ∧ φ_feas(s) ≥ 0}。
在线选 s* = argmax_{s∈S_cert} U_task(s)（任务速度/平滑度）。存在非单调权衡：↑K_p 收缩管变细但力矩需求上升、φ_feas 下降，故 S_cert 可能非凸，用 1-D 柔顺参数扫描 + 局部 QP 求解。

**定理（时空安全）**：若 (i) CertTrack 成立，(ii) 每个 h_k 的 HOCBF 在 τ 盒上可行，(iii) 在时域 [t, t+T_cert] 内 β≥0，则真实碰撞概率 ≤ δ（δ 为 B_t、B_pred 的置信水平之和，union bound）。证明由管包含（三角不等式）与障碍函数单调性直接推出。

**定理（证书续期下界）**：只要存在非零相对速度或非零加速度上界，T_cert 有限；总线的重观测/重规划速率必须 ≥ 1/T_cert^min，否则「证书空窗期」内一切安全声明无效。

## 2. 三大产出设计

### 2.1 IP-51 CERTIFIED-TORQUE-EXECUTOR（力矩级认证执行）
1. 力矩适配器：操作空间逆动力学 + 阻抗控制，输出盒约束 τ，自碰撞/关节限位进零空间。
2. 收缩管：按接触模式分片求 LQR/SoS 度量 M(q)、λ_c；在线计算 ρ_track；δ_d 用饱和残差 conformal 标定。
3. 力矩 HOCBF-QP：每个静态/动态障碍一条二阶约束，盒约束 QP；求 φ_feas；不可行 → 参考调速器先减速 → 再被动安全。
4. 参考调速器（reference governor）：对 IP-48 速度场输出的参考做速度整形，使跟踪管留在自由空间内、且 d_stop 不超过可用间隙。
5. 韵律→阻抗调度：用定义 32 在线选 s*，把「韵律」落到 K_p/K_d。
6. 重认证：在线监测 δ_d、λ_c 漂移，越界 → RCA 重颁 → 契约热更新。

### 2.2 IP-52 DYNAMIC-OBSTACLE-CERT（动态避障时空证书）
1. 动态层：移动障碍物跟踪（KF/IMM）单独维护，绝不污染静态 ESDF；静态地图保持 v17 语义。
2. 预测证书：协方差传播 + 非合作可达集膨胀，输出 B_pred(Δ)、T_pred。
3. 时空 HOCBF：静态 h_esdf 与动态 h_k 取 min，统一进 IP-51 的力矩 QP。
4. 时空有效域与保质期：计算 T_cert，上报 Registry；总线到期即要求重观测/重规划。
5. 非合作策略：默认有界加速度；观测到超界 → 立刻转保守（低速 + 大 margin + 请求让行）。

### 2.3 IP-53 SAFETY-MARGIN-LEDGER（安全裕度账本）
1. 账本条目：六类残差带来源标签与置信度，统一单位（米/等效米）。
2. 组合代数：合取取 min、顺序沿管取 min；与 IP-47 任务代数对接。
3. 实时裕度治理器：赤字分级触发降级阶梯，按代价排序，避免过激降级。
4. 总线集成：按 β 与 T_cert 路由；新增「预算赤字」「证书到期」「时空资源冲突」三类熔断触发器。
5. 训练闭环：IP-50 难度增「障碍动态轴」与「力矩/跟踪赤字」；回放按账本赤字加权。
6. 审计输出：每个技能给出一份「裕度对账单」，可解释、可追责。

## 3. 四层架构 v6

```
L1: TRI-FUSE + IP-49 LIO/语义 + IP-52 动态层/预测证书 → C_ms + B_t + B_pred + T_pred
L2: CTC + VLM + IP-35 仲裁 → R_φ + IP-52 时空约束与风险
L3: IP-47 任务代数（时空资源/账本组合）→ IP-39 规划（刹车感知速度限 + 动态 CBF）
    → IP-45 总线（时空路由 / 到期与赤字熔断）
    → IP-51 力矩认证执行 + IP-43 阻抗韵律 → IP-53 账本监控 → RCA
L4: IP-44 蒸馏 + IP-50 课程（任务×步数×障碍动态三轴）→ RCA 重颁 → 契约热更新
运行期：技能总线 + 区域化 RCA + 自适应步数流采样 + LIO/ESDF + 动态层 + 收缩管 + 力矩 HOCBF-QP + 账本治理器
```

## 4. 实验设计（E73-E78 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 跟踪管紧致性 | 认证 ρ_track / 实测最大跟踪误差；越界率 | 比值≤2；越界≤0.5% |
| E74 力矩级 CBF | 跌倒/近碰撞率 vs 运动学 CBF（含力矩饱和场景） | 下降≥50%；不可行率<1% 且全部安全降级 |
| E75 动态避障安全 | 交叉/迎面场景碰撞率 vs 静态 ESDF 基线 | 下降≥60%；全程 β>0 |
| E76 预测证书与保质期 | B_pred 覆盖率；首次违约时刻 vs T_cert | 覆盖≥99%；违约≤1% 且不早于 T_cert |
| E77 证书条件化韵律 | 任务速度/平滑度 vs 固定韵律（零预算违约） | 提速≥15% 或力矩峰值降≥20% |
| E78 端到端账本 | 长程任务成功率、证书违约率、降级正确率 | ≥80%、<0.5%、≥95% |

回退路径：E73 或 E74 不达标 → 关闭力矩级证书，退回 v17 的「运动学证书 + 保守速度限」，仅保留 T_cert 作监控告警；E75/E76 不达标 → 动态障碍一律按静态膨胀处理，禁用非合作可达集承诺。

## 5. 本轮最大风险

**一句话**：整套设计把「证书可证」押在「闭环存在一个可认证的收缩度量 + 力矩 HOCBF 在接触切换间连续可行」上——若接触/混合动力学让 M(q)、λ_c 只能分片成立且切换瞬间管子「漏气」，则 ρ_track 与 β 的承诺在步态落地/抓取接触的离散事件上全部失效，必须以 E73（越界率）作为第一守门实验，并把「分片收缩 + 切换守卫」作为不可省略的工程前提。

## 1. 符号体系（承接定义 27-32）

| 符号 | 含义 | 定义 |
|---|---|---|
| e = x − r | 跟踪误差 | 状态 x=(q,q̇) 与 IP-48 参考 r 之差 |
| M(q) / λ_c | 收缩度量 / 收缩率 | Ṁ+AᵀM+MA ⪯ −2λ_c M（A=∂f/∂x） |
| δ_d | 有界残差 | 饱和+模型+摩擦合成，conformal (1−δ_q) 分位 |
| ρ_track | 跟踪管半径 | √cond(M)(e^{−λ_c(t−t₀)}ρ₀ + δ_d/λ_c) |
| a_k, b_k | HOCBF 力矩约束系数 | ψ_k=ḧ_k+α₁ḣ_k+α₂h_k≥0 ⟺ a_kᵀτ≤b_k |
| φ_feas | 执行器可行性裕度 | min_k [b_k − min_{τ∈盒} a_kᵀτ]；≥0 则 QP 可行 |
| a_max / d_stop | 有效最大减速度 / 刹车距离 | a_max 由 τ_max/摩擦认证；d_stop=v²/(2a_max)+v·t_react |
| p̂_k, Σ_k(Δ) | 障碍物预测均值/协方差 | Kalman/IMM 预测 |
| B_pred,k(Δ) | 预测不确定球 | c_δ√tr(Σ_k(Δ)) + ½ a_max^obs Δ² |
| h_k(x,t) | 时空安全函数 | ‖p−p̂_k(t)‖−r_robot−r_k−B_pred−ε_occ |
| T_cert | 证书保质期 | sup{Δ: β(x,t+Δ)≥0}，B_pred 单调增故通常有限 |
| ValidRegion_ST | 时空有效域 | {(x,t): 覆盖 ∧ β≥0} |
| β(x,t) | 安全裕度账本 | h_clear − (B_t+ε_ode+ρ_track+B_pred+ε_occ+d_stop) |
| S_cert | 可执行韵律集 | {s: β(s)≥0 ∧ φ_feas(s)≥0} |
| Δβ | 账本赤字 | max(0, −β)，驱动降级阶梯 |

## 2. 关键算法（伪代码）

### IP-51 力矩级认证执行
```
def certify_tracking_tube(ctrl, contact_modes, delta_q=0.01):
    for mode in contact_modes:                      # 分片，切换有守卫
        M, lam = lqr_or_sos_metric(ctrl, mode)      # 收缩度量与收缩率
        d_hat  = conformal_quantile(sat_residual(ctrl, mode), delta_q)
        tube[mode] = CertTrack(M, lam, d_hat)
    return TubeCert(tube, guard=switch_guard(contact_modes))

def torque_hocbf_qp(x, u_ref, obstacles, tube):
    rows = []
    for k, h in obstacles:                          # h 相对阶 2
        a_k, b_k = hocbf_affine_in_tau(h, x, alpha=(a1,a2))
        rows.append((a_k, b_k))
    phi = min(b - min_over_box(a, TAU_MIN, TAU_MAX) for a, b in rows)
    if phi < 0:
        return reference_governor(x, u_ref)         # 先减速降 d_stop/rho
    tau = solve_box_qp(H, f, rows, TAU_MIN, TAU_MAX) # min ||tau-u_ref||^2 s.t. a_k^T tau<=b_k
    return saturate(tau, TAU_MIN, TAU_MAX)

def adaptive_stream_execute(flow_ref, x, obstacles):
    r = flow_ref.next_block()                       # IP-48 参考块
    r = reference_governor.shape(r, beta=ledger(x, obstacles))
    for t in control_ticks(r):
        tau = torque_hocbf_qp(x, impedance(r, s_star), obstacles, tube)
        x = robot.step(tau)
        if beta(x, obstacles) < 0: return degrade_ladder(x, obstacles)
        yield x
```

### IP-52 动态避障时空证书
```
def predict_certificate(track, Delta, obstacle_model):
    p_hat, Sigma = obstacle_model.predict(track, Delta)
    B_pred = c_delta * sqrt(trace(Sigma)) + 0.5 * a_obs_max * Delta**2
    return PredCert(p_hat, Sigma, B_pred, T_pred=horizon(Sigma, B_pred_max))

def space_time_h(x, tracks, static_esdf):
    h = static_esdf.clearance(x) - margin - B_t
    for k, tr in tracks.items():
        h = min(h, norm(pos(x)-tr.p_hat(t)) - r_robot - r_k
                       - tr.B_pred(t) - epsilon_occ)
    return h

def certificate_lifetime(x, tracks, ledger):
    Deltas = linspace(0, T_pred, M)
    alive = [d for d in Deltas if ledger.beta(x, t+d) >= 0]
    return max(alive) if alive else 0.0             # 上报 Registry，到期前必须续期

def noncooperative_guard(track):
    if track.accel_est > a_obs_max:
        return conservative_mode(low_speed=True, margin_scale=2.0, yield_request=True)
    return nominal(track)
```

### IP-53 安全裕度账本与降级
```
def ledger(x, obstacles):
    terms = {
        "B_state": (B_t(x), conf), "eps_ode": (eps_ode, conf),
        "rho_track": (tube.radius(x), conf), "B_pred": (pred_ball(x), conf),
        "eps_occ": (occlusion(x), conf), "d_stop": (braking(x.vel, a_max(x)), conf),
    }
    beta = static_clearance(x) - sum(v for v, _ in terms.values())
    return Ledger(beta=beta, terms=terms, deficit=max(0.0, -beta))

def degrade_ladder(x, obstacles):
    for action in ["slow", "stiffen", "reobserve", "replan", "passive_safe"]:
        x2, obs2 = apply(action, x, obstacles)
        if ledger(x2, obs2).beta >= 0:
            return commit(action, x2)               # 最小代价优先
    return passive_safe_controller(x)               # IP-38 兜底

def select_prosody(x, obstacles, task_utility):
    best = None
    for s in candidate_prosody(lambda_c=..., Kp_grid=...):
        if ledger(x, obstacles, s).beta >= 0 and phi_feas(x, s) >= 0:
            if best is None or task_utility(s) > task_utility(best): best = s
    return best if best else safe_prosody()
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 收缩度量认证 | 离线 LQR/SoS，按接触模式一次性；在线 ρ_track O(n²) | **定理**：‖e‖_M 指数收缩 + 残差稳态界 |
| 力矩 HOCBF-QP | O(n³)（盒约束 QP，n≤数十），每控制拍 | φ_feas≥0 ⟺ 可行；可行 ⟹ h(x,t) 前向不变 |
| 预测/时空安全 | KF O(Kn²)，每障碍 O(K) | **定理**：P(‖p−p̂‖>B_pred)≤δ（协方差界） |
| 证书保质期 | 闭式/一次扫描 O(M) | **定理**：T_cert 有限；续期速率≥1/T_cert^min |
| 账本与降级 | O(K+|动作|)，按代价排序 | 降级阶梯单调（β 不减），失败则被动安全 |
| 韵律选择 | 1-D 扫描 + 局部 QP，O(|grid|·n³) | 返回 s 必在 S_cert 内，否则 safe_prosody |
| 组合/时空预留 | O(|V|+|E|+冲突对数) | min-plus 账本组合 + 管道重叠检测 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 接触/混合动力学使收缩度量只能分片成立，切换瞬间管「漏气」 | 高 | 按接触模式分片 + 切换守卫 + 保守切换管膨胀；E73 第一守门 |
| 高维人形/leg 上收缩度量 LMI/SoS 不可解 | 高 | 只在任务相关子空间（CoM/末端）做收缩认证，关节层用经验残差 + conformal 放宽 |
| δ_d 随负载/地形漂移，管子低估误差 | 中 | 在线残差监测 + 自适应 conformal + RCA 重颁 |
| 预测证书对非合作障碍物失效 | 中 | 有界加速度可达集膨胀；超界即转保守/让行 |
| T_cert 过短导致重规划抖动 | 中 | 双时间尺度续期 + 滞回；优先重观测而非全重规划 |
| 账本过度保守 → β 恒负、系统瘫痪 | 高 | 项级来源审计 + 只对任务相关项严格；E78 守门「降级正确率」 |
| 力矩 HOCBF-QP 实时性不足 | 中 | 盒约束 QP 暖启动 + 障碍数截断（最近 K 个）+ 控制周期预算 |

## 6. 本轮最大风险

**一句话**：整套体系押在「闭环存在可认证的收缩度量、且力矩 HOCBF 在接触切换间连续可行」这一条假设上——若混合/接触动力学让 M(q)、λ_c 只能分片成立、切换瞬间跟踪管与安全裕度同时「漏气」，则 ρ_track 与 β 的承诺在每次落地/抓取接触上都会失效，故 E73（越界率）必须作为第一守门实验，且「分片收缩 + 切换守卫」是不可省略的前置条件。
