# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「灵巧操作」×「协同控制」）

> R69 让闭环学会了「问」——注视、探针、问句，用 VoI 决定值不值得求证，把 aleatoric 留给刹车、把 epistemic 交给交互。但它默认了一个**只有一个身体、一个大脑**的智能体：信息动作可以是抽象的「看/问/触」，团队只是被动融合的传感器阵列。
>
> 灵巧操作与协同控制恰好拆掉这两个默认：
> - **灵巧操作**把「身体」变成多指/多接触的团队：物体一旦被手合拢就遮挡接触点、局部曲率、摩擦系数与是否滑动，而接触状态（黏/滑、接触斑位置、摩擦锥）才是主导的 epistemic 不确定性。同时抓取映射把动作空间天然劈成「会动物体的任务空间」与「不动物体的内空间」——后者是一条约零成本的信息通道。
> - **协同控制**把「大脑」变成多个有信息差与权限差的智能体：分歧不再只是噪声，而是一个有方向、可测量的量；传统一致性把所有信念平均成一个，正是 R69 批判的「高斯均值糊掉模态」，而且共享传感器的智能体会**自信地在一场共模幻觉上达成一致**。
>
> 核心命题：**把 R69 的单智能体信息动作升级为有物理根、分布式的版本——(1) 用抓取零空间作为「epistemic 通道」，在任务空间一阶零扰动下探接触；(2) 把跨智能体分歧当作有向的 epistemic 量，分解为「互补（信息差→共享）」与「冲突（模型差/拜占庭→权限仲裁）」，绝不平均；(3) 把控制权限当作按校准胜任度分配的稀缺资源，校准失门则彻底出局。R69 是本轮 N=1、零空间为空时的严格退化。** 命名 **DEXCO-RAS**（DEXterous COoperative contact-mode RAS）。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们谁该抓、抓哪里、用多大力——而我们的分歧本身是不是一条信息**」。

## 0. 直觉与动机

**灵感 1（灵巧操作 → 接触是被手自己遮挡的潜变量）**
直觉：桌面抓取时视觉能看清物体，多指手一旦合拢，接触点、局部曲率、摩擦系数、是否滑动全被手指挡住；而这些恰是决定「能不能抬起、会不会掉」的量。它们是**离散-连续混合的接触模式** c（每指接触/悬空、黏/滑、接触斑位置、摩擦档、物体相对位姿），不是高斯噪声。R69 的流匹配恰好能表达这种多峰：同一视觉观测下，「稳稳捏住」「滑到指尖再兜住」「换抓点」是三个模态。于是灵巧操作的 epistemic 不确定性有了具体对象：不是「动作有多模糊」，而是「**到底是哪种接触模式**」。

**灵感 2（协同控制 → 抓取零空间是免费的信息通道）**
直觉：抓取映射 w = G f_c 把手指力分成「合成物体力旋量」与「内力量」；内力量落在 null(G)，按定义不改变物体运动（一阶）。传统上内空间只用来优化姿态/内力分配，属于白送的冗余。本轮把它当**探针通道**：轻捏（法向调力）、微拧/微搓（切向）、微抬（接触检测）都在零空间里做，任务空间一阶零扰动。R69 的「探针安全」靠事后 CBF 认证，本轮靠**结构本身**（G·N=0）先给出安全，再用 CBF 处理二阶项与接触跳变。这是把信息动作从「额外风险」变成「利用冗余」。

**灵感 3（协同控制 → 一致不是真理，分歧才有方向）**
直觉：多指、双臂、人机共抬时，每个智能体有自己的流策略与模态。标准协同控制用一致性把信念平均（或加权平均），这会：(a) 抹掉多模态——正是 R69 要避免的均值化；(b) 让共享同一相机/同一物体的智能体**高度相关**，于是它们「一致地错」时，一致性反而给出虚假的高置信。正确做法是保留各智能体的模态，做**跨智能体模态匹配**，并问：分歧是「你看得到我看不到」造成的（互补，值得共享），还是「我们模型/标定不一样」造成的（冲突，得仲裁或排除）。判据很物理：**交换观测后分歧是否消失**。

**灵感 4（协同控制 → 权限是资源，按校准胜任度分配）**
直觉：人机共抬、双臂交接的关键决策不只是「做什么」，而是「**谁说了算**」——谁主导任务空间、谁的力占优、谁可以否决。若按固定权重或平均分配，弱/坏/被投毒的一方会把错误意见稀释进命令。把权限 α 当作概率单纯形上的分配，按各智能体在**当前接触模式**下的校准胜任度分配，并设校准门（ECE 越界 → 权限直接归零而非降低）。这与 R69 的模态校准门（MCG）同构：不可信的信念不许驱动交互，不可信的智能体不许拿权限。

**灵感 5（合流 → 三级不确定性，三级退避）**
直觉：R69 的两级（ale → 铁律，epi → 交互）在多体接触下不够，因为「我们不一致」既不是纯噪声，也不是单体能自己消解的歧义。DEXCO 扩成三级：
- U_ale（模态内噪声，不可约）→ R68 λ_floor；
- U_epi（单体内模态间歧义，可约）→ R69 看/问 + 本轮零空间探针；
- U_coop（跨体分歧中不可由交换观测消除的部分）→ 共享/交接/让权 + 权限仲裁。
安全侧仍是单调退避：探针失败/接触跳变 → 回 R69；R69 不可信 → 回 R68；权限仲裁失败 → 单机保守。层级越加越安全，绝不越加越激进。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DEXCO-RAS 总览）** DEXCO-RAS = (DCP, NSI, COD, CAT, CSC, RAS-WM††)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **零空间信息纯度**：一切接触探针必须落在 null(G) 或其认证近似内，‖f_int‖ ≤ f_probe，且满足摩擦锥/力封闭裕度；探针不得改变任务空间一阶运动；
(iii) **权限证据纪律**：权限转移需「校准胜任度通过 + ≥2 个正交证据源一致」；共享同一物理传感器的智能体只计为一个证据源（相关性折扣，定义 317、引理 21）。

**定义 311（接触模式潜变量）** c_t = (κ_t, σ_t, π_t, μ_t, g_t)：κ 为逐指接触指示，σ 为黏/滑指示，π 为接触斑位置（流形坐标），μ 为摩擦档（离散类别或连续下界），g 为物体相对手的位姿。c 是离散-连续混合潜变量，由触觉 + 本体 + 视觉后验 p(c|o) 维护。

**定义 312（任务/内空间动作分解）** 抓取映射 G(q) ∈ ℝ^{6×m}，手指接触力 f_c ∈ ℝ^{m}，物体旋量 w = G f_c。动作 ξ = (x_task, f_int)，f_int = N z，N = null(G)（正交投影 P_N = I − G⁺G）。R69 的 ξ=(a,g) 是本定义在 N={0} 时的投影。

**定义 313（接触条件流匹配 DCP）** 速度场 v_θ(x_s, s | o_t, c)，x_1 = ξ_{t:t+H}；对 c 边缘化：p(ξ|o) = Σ_c p(c|o) p_θ(ξ|o,c)。同时输出接触模式头 p_φ(c|o)。训练损失 L_DCP = L_FM + λ_c·CE(p_φ(c|o), c)，接触标签来自触觉/仿真真值（半监督）。

**定义 314（零空间信息探针 NSI）** 信息动作 g_probe = N z ∈ null(G)，类型：
- 捏（squeeze）：法向力调制 δf_n，估刚度/接触面积；
- 搓（micro-twist）：切向微旋，估摩擦锥边界；
- 滑（micro-slide）：受控微滑，估 μ 与滑动方向；
- 抬（lift-off）：微抬，做接触检测。
信息增益按「单位任务扰动风险」归一：VoI_probe = I(c; y | g_probe) / (c_task(g_probe) + ε)。

**定义 315（接触不确定性二分）** 对 K 个模态 {m_k}：
U_ale^c = Σ_k ŵ_k tr(Σ_k)（模态内、含触觉噪声）；
U_epi^c = H_mode · g(Δ_min) · 1[Δ_min ≥ 3σ_in]（模态间可约，A95 分离条件下）；
另定义滑移裕度不确定 U_slip = Var(μ̂ − μ_need)（接触安全侧）。
三者分通道：U_ale^c → λ，U_epi^c → 探针，U_slip → CSC 硬约束。

**定义 316（跨智能体模态匹配）** 智能体 i∈{1..N} 采样得 {m_k^i, ŵ_k^i, ξ̄_k^i}。以 Fréchet 距离做跨体最优传输，得匹配 M_{ij}:k↦l 与一致性张量 A_{ij}^{kl}=exp(−W₂(ξ̄_k^i, ξ̄_l^j)/τ_m)。**按模态做专家乘积**融合已匹配模态，未匹配模态原样保留为候选假设——不做加权平均。

**定义 317（协同分歧分解 COD）** 分歧 D_{ij} 为两体模态后验的 JS 散度。分解：
D_{ij} = D_{ij}^info + D_{ij}^conflict，
其中 D_{ij}^info 为观测交换后可消除的部分（信息不对称），D_{ij}^conflict 为交换后残余（模型/标定/拜占庭）。操作性判据（观测交换测试）：
D_ij^info := D(beliefs before) − E_{share}[D(beliefs after shared obs)]；
D_ij^conflict := D(beliefs after full exchange)。
- D^info 主导 ⇒ 互补，执行 g_share，VoI > 0；
- D^conflict 主导 ⇒ 冲突，执行 g_handoff / g_yield，进入权限仲裁。
相关性折扣：若两体共享同一传感器源 s，则其证据相关系数 ρ_s>0，独立证据数 k_eff = k/(1+(k−1)ρ̄)（定义 326、引理 21）。

**定义 318（协同信息动作空间）** 在 R69 的 (g_gaze, g_probe, g_ask) 上增广：
- g_share：交换压缩模态后验/潜变量/触觉摘要（带宽 ≤ b_comm，带时戳）；
- g_handoff：转移任务空间主导权（谁领）；
- g_yield：降低自身刚度/内力或主动顺从，让队友估计主导。
增广动作 ξ̃ = (a, g, g_coop) ∈ 𝒜_task × 𝒜_info × 𝒜_coop。

**定义 319（协同权威分配 CAT）** 权限 α ∈ Δ^{N−1}，合成命令 u = Σ_i α_i u_i（或力分配）。分配规则：
α = softmax(κ_a · R_i^{cal}(c))，R_i^{cal} 为智能体 i 在当前模式下的校准胜任度；
约束：R_i^{cal} < r_min ⇒ α_i = 0（排除，而非稀释）。平局 ⇒ 均权；无校准 ⇒ 退化为单机/均权保守。

**定义 320（权威校准门 ACG）** 每个智能体的「我这一票对不对」预测必须校准（ECE ≤ τ_acg）。越界 ⇒ 该体权限直接置 0 并退出本轮协作，而不是继续参与再被平均——与 R69 MCG 同构：不可信者不许拿权限。

**定义 321（接触安全证书 CSC）** 接触感知 CBF：h_c = min{ 摩擦锥裕度 h_fric，力封闭裕度 h_fc，法向力上下界 h_fn，关节力矩界 h_τ，滑移速度裕度 h_slip }。探针 f_int 必须满足 ḣ_c + α_c h_c ≥ 0；滑移/接触跳变检测触发即时中止并单调退避。探针物理风险 ≤ ε_probe。

**定义 322（协同证书 J_DEXCO）** J_DEXCO = (J_FLUID, contact_mode_ece, nullspace_purity_residual, agreement_tensor_hash, authority_cert, slip_events, comm_latency_p99, dexco_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_c ≤ τ ∧ 残余零空间扰动 ≤ δ_G ∧ 权限证据纪律满足 ∧ h_c ≥ 0。

**定义 323（干扰集 ℰ_DEXCO）** ℰ_DEXCO = ℰ_FLUID × ℰ_contact × ℰ_coop：
ℰ_contact = {接触模型失配、摩擦误辨、触觉饱和、遮挡幻影接触、接触跳变}；
ℰ_coop = {拜占庭队友、陈旧/伪造消息、共模传感失效（相关体一致地错）、权限死锁/抖动、共谋欺骗、通信延迟引发的内力对抗}。

**定义 324（分级退化与严格包含）** 若 N=1 且 null(G)={0}（或探针/共享/交接全禁用、权限恒等），DEXCO = FLUID-RAS；若探针不可信/接触跳变 → 回 R69；若 R69 亦不可信 → 回 R68；若权限仲裁失败 → 单机保守。安全侧风险单调：R_DEXCO ≤ R_FLUID ≤ R_R68。

**定义 325（频率分层与预算）** 高频接触伺服（1 kHz）只跑 CSC + 阻抗控制；中频流策略（30–60 Hz）跑 DCP + 模态分解 + 探针选择；低频协商（5–10 Hz）跑 COD + CAT。自适应 K 只在歧义路径升采样；共享/交接受 c_comm 与社交成本约束。

**定义 326（协同对偶观测）** 接触歧义有两条独立通道：局部触觉残差（快、局部）与全局物体旋量一致性（慢、全局）。R69 的 (r_res, Δa) 对偶在此升级为 (滑移/触觉残差，物体旋迹残差)；慢变接触属性漂移可能被一条通道吸收，却在另一条上保留。

# IP-264 DCP：接触条件流匹配（复用 R69 FMP trunk）
class ContactFlowPolicy:
    def __init__(self, trunk, v, contact_head, K=4):
        self.trunk, self.v, self.contact_head = trunk, v, contact_head

    def sample(self, o, K, N_step=2):
        z = self.trunk(o)
        c = self.contact_head(z)                  # p(c|o) 接触模式头
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0 / N_step) * self.v(xs, i / N_step, z, c)
        return [self.decode(x) for x in xs], c

# IP-266 NSI：零空间信息探针
def nullspace_probe(G, c_post, budget):
    N = null_space(G)
    best = None
    for kind in ("squeeze", "twist", "slide", "lift"):
        z = probe_direction(kind, c_post)
        f_int = N @ z
        if norm(f_int) > F_PROBE or not budget.allow(kind):
            continue
        voi = mutual_info(c_post, tactile_y, cond=f_int) / (task_risk(f_int) + 1e-6)
        if best is None or voi > best.voi:
            best = Probe(f_int, voi)
    return best if best and best.voi > TAU_VOI else None

# IP-267 COD：跨体模态匹配 + 观测交换分解
def coop_disagreement(beliefs, obs_exchange):
    match = optimal_transport_modes(beliefs)          # Fréchet 最优传输
    D_before = js_divergence(beliefs)
    D_after = js_divergence(beliefs, exchange=obs_exchange)
    D_info = max(0.0, D_before - D_after)             # 互补：交换后消失
    D_conf = D_after                                  # 冲突：交换后仍在
    return D_info, D_conf, match

# IP-268/269 CAT + ACG：校准权限分配（不可信者直接出局）
def allocate_authority(agents, mode):
    agents = [a for a in agents if a.ece <= TAU_ACG]  # ACG 硬门
    if not agents:
        return uniform_policy_fallback()
    R = array([a.calibrated_competence(mode) for a in agents])
    alpha = softmax(KAPPA_A * R)
    alpha[R < R_MIN] = 0.0                            # 排除而非稀释
    return normalize(alpha) if alpha.sum() > 0 else uniform_policy_fallback()

# IP-270 CSC：接触安全 CBF + 中止
def contact_safety_filter(f_int, h_c, dt):
    if h_c < 0 or slip_detected():                    # 接触跳变
        return None                                   # 中止 → 回 R69
    return qp_project(f_int, grad_h_c, alpha_c, h_c)  # ḣ + αh ≥ 0

# IP-274 主闭环（继承 R69，插入零空间探针与协同层）
def DEXCO_round(M, obs, teammates):
    z, c = M.dcp.trunk_and_contact(obs)
    K = 1 if M.mode_head(z) < TAU_MODE else 4
    samples, c_post = M.dcp.sample(obs, K)
    U_ale, U_epi, modes = M.aud.decompose(samples)
    # 1) 单体内歧义：R69 看/问 + 本轮零空间探针
    g = None
    if U_epi > TAU_EPI:
        g = M.nsi.choose_probe(M.G, c_post, M.budget) or M.mint.choose(modes)
    # 2) 跨体分歧：分解后决定共享还是仲裁
    D_info, D_conf, _ = M.cod.decompose(teammates, M.comm)
    if D_info > D_conf:
        M.cat.share(M.comm.compress(c_post))           # 互补 → 共享
    elif D_conf > TAU_CONF:
        alpha = M.cat.allocate(teammates, c_post)      # 冲突 → 权限仲裁
    # 3) 安全过滤：探针/命令都在零空间 + CSC 内
    if g is not None:
        g = M.csc.filter(g, M.h_c, M.dt)
        if g is None:                                  # 探针不安全 → 回 R69
            return M.fluid_round(obs)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 4) 执行 + 参与式审计 + 证书
    M.vqa_d.submit_async(g, c_post, D_info, D_conf)
    return M.execute(g, lam), (U_ale, U_epi, D_conf)

## 3. 推导

**引理 19（零空间信息纯度）** 设 G 行满秩、N=null(G) 为其正交补。对探针 f_int=Nz，物体旋量变化 Δw = G f_int = 0（一阶精确）；含位形变化时 Δw = (∂G/∂q·δq) f_int + O(‖f_int‖²)，故任务空间扰动 ≤ L_G‖N z‖²·‖δq‖。取 ‖z‖ ≤ f_probe 可使任务扰动 ≤ ε_task，探针因此可在**不进入任务风险预算**的前提下采集接触信息。（A99：G 行满秩；A100：准静态、小力线性化。）

**引理 20（分歧分解的可辨识性）** 在 A101（给定 c 后各体观测条件独立、共享源被显式标记）下，JS 分歧可分解为信息项与冲突项；观测交换测试给出 D^info 的无偏估计：交换充分统计量后仍存的分歧恰为 D^conflict。当 D^info ≫ D^conflict 时，共享动作的 VoI ≥ D^info − c_comm；当 D^conflict ≫ D^info 时，继续共享的边际收益 → 0，必须转入权限仲裁（否则只是在错误信念上达成共识）。

**引理 21（相关体的一致不是独立证据）** 若 N 个体共享相关系数 ρ̄ 的共模误差源，则等效独立证据数 k_eff = N/(1+(N−1)ρ̄) ≤ N；当 ρ̄→1 时 k_eff→1，一致性再高也不降低错误率。故 R69 的「k 个正交证据」必须按证据源（而非智能体数）计数——这是把 R69 的交互投毒上界（引理 18）扩展到「队友即投毒者」的关键。

**定理 18（DEXCO 严格包含 FLUID/R68）** 在 A99–A101 下，DEXCO 在任意状态的期望风险 ≤ FLUID ≤ R68；当 N=1、null(G)={0}、COD/CAT 关闭时逐指令相同（定义 324）。安全侧不做让步：探针/共享/权限任一不可信，均单调退化为 R69 再退 R68。

**定理 19（校准权限的占优性）** 设各体胜任度 R_i(c) 有界、校准门 ACG 通过。按 α^cal ∝ softmax(κ R_i) 分配权限的期望任务风险 ≤ 任意固定分配 α^fix；当且仅当胜任度方差 > 0 时严格更优。若 ACG 失败或某体被排除，α 退化为均权/单机保守，风险 ≤ R69。直觉：权限是「专家组合」权重，校准是组合不亏的充分条件（与 R69 MCG 同构）。

**定理 20（探针-接触安全无突变）** 经 CSC 认证的零空间探针保持摩擦锥与力封闭裕度；滑移/接触跳变触发单调退避；探针切换经混叠（blending）保证指令连续。结合定理 18 的退化链，控制量在 R69↔DEXCO 之间无跳变（继承 R68 定理 15、R69 定理 17）。

## 6. 本轮最大风险

**一句话**：DEXCO 的探针假设「零空间在接触处一阶解耦」，但灵巧操作的接触是**不连续、强非线性**的——一次为测摩擦而做的微滑，可能正把物体推过摩擦锥边界，**探针改变了它要测量的接触模式**（观察者效应），而线性化证书恰在接触跳变处失效；此时「安全的信息动作」会变成「用安全证书包装的失手」。

**次级风险与缓解**：
1. **相关体虚假共识**（共享相机/物体导致一致地错）→ 定义 317 相关性折扣 + 引理 21 + E309，按证据源而非智能体数计数；
2. **权限抖动/死锁**（交接振荡、双方都不接）→ 滞回 + 死锁超时 → 单机保守（定理 19 退化支）；
3. **通信延迟引发内力对抗**（两体同时加力）→ 时戳丢弃 + 力变化率限幅 + CSC 硬约束（定理 20）；
4. **接触模式标签稀缺**（真值难采）→ 半监督 + 仿真真值 + 触觉自监督，E301 报告标注依赖；
5. **零空间近似误差**（冗余不足/奇异位形）→ 残余扰动监控（J_DEXCO 的 nullspace_purity_residual），超界即禁用探针回 R69。

## 7. 本轮最大风险

**一句话**：DEXCO 的探针假设「零空间在接触处一阶解耦」，但灵巧操作的接触不连续且强非线性——一次为测摩擦的微滑可能正把物体推过摩擦锥边界，**探针改变了它要测量的接触模式**（观察者效应），而线性化证书恰在接触跳变处失效；「安全的信息动作」会变成「用安全证书包装的失手」。

**次级风险与缓解**：相关体虚假共识（相关性折扣 + 引理 21 + E309）；权限抖动/死锁（滞回 + 超时 → 单机保守）；通信延迟引发内力对抗（时戳丢弃 + 力变化率限幅 + CSC）；接触模式标签稀缺（半监督 + 仿真 + 触觉自监督）；零空间近似误差（nullspace_purity_residual 监控，超界禁用探针回 R69）。
