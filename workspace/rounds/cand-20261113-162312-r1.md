# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 1 轮（新循环）；本轮灵感：「遥操作」×「视觉编码器」）

> 前四轮（VISTA→RAS→SimRAS）有一个从未被挑战的共同前提：**感知是机器自己的**。视觉要么喂给机器人做故障归因（VISTA），要么喂给机器人读人的表情（RAS），要么喂给世界模型预演未来（SimRAS）。但真实的高风险机器人系统往往是**遥操作**的：人不在现场，只能通过一条**带宽受限、时延抖动、会丢包**的链路，看机器人编码回来的视频来做安全决策。此时「视觉编码器」不只是感知前端，而是**人与机器共享的唯一观测通道**——它决定了人能看到什么、看多快，从而决定了人还能不能救得回来。
>
> 本轮命题：
>
> **把视觉编码器当作遥操作的「安全信道」来设计：编码器不再是「保真度」问题，而是「在时延预算内，把人做安全干预所必需的信息送达」的联合率-失真-时延问题。**
>
> 命名 **TELOS（Teleoperation-Encoded Latency-aware Oversight System）**。它把 VISTA 的「故障可归因」、RAS 的「意图可协商」、SimRAS 的「未来可预演」串成一条新链路：**编码器 → 时延信道 → 人 → 回传指令**，并首次让认证前缀显式依赖于这条链路的时延与人因。

## 0. 直觉与动机

**灵感 1（遥操作 → 人是一个「带延迟的控制器」，不是一个标签）**
直觉：RAS 把人的情绪当作风险信号，但只把「人」当作被动观测对象。遥操作则把人放回控制回路：人看到画面、判断、出手，指令经上行链路回来。问题在于人有**反应时延**（约 200–500ms）且链路有**往返时延** `δ_rt`。因此「人能救」不是一句定性的话，而是一个可计算条件：机器人必须在 `δ_rt` 这段时间内保持安全，否则人的指令还没到，事故已经发生。这把控制论的「时滞系统」与「共享控制」直接接进来。

**灵感 2（视觉编码器 → 编码器是「共同瓶颈」，不是「预处理」）**
直觉：传统视觉编码器只优化机器任务的失真（检测/分割），或者只优化人眼观感（PSNR/VMAF）。但在遥操作里，同一个码流有**两个消费者**：机器（做故障归因）和人（做干预判断）。二者关心的特征不同：机器可能需要全局几何一致，人则需要**即将失效的细微高频线索**（线缆将断、夹爪微滑、液体将溢）。码率一受限，编码器最先丢的恰恰是这些高频异常——于是出现一种危险的不对称：**机器知道有故障，但人看不见；或者人看见了，但机器已按「正常」执行。**

**灵感 3（交点 → 「不可传输的故障」）**
直觉：把香农率失真与故障归因拼起来，会得到一个全新的安全概念。要让人的后验越过判断阈值，需要传输至少 `R_min(H_k)` 比特（率失真下界）；而链路为了满足时延预算，最多只能给 `R_max(δ_rt)` 比特。若 `R_min(H_k) > R_max`，则该故障**在物理上无法在干预窗口内被传达**——不是算法不好，而是信息论意义上的不可达。TELOS 把这类故障单独标为「不可传输故障」，并对它采取**不依赖人**的独立兜底。

**灵感 4（率越高越安全？→ 保真度-安全悖论）**
直觉：通常认为画质越高越安全。但遥操作里码率越高 → 编码时延 `L_enc(R)` 越大 → 往返时延越大 → 留给人的干预窗口越短。因此存在一个**内点最优码率** `R*`：再往上加码，画质改善带来的收益抵不过时延增加带来的损失。极端情况下，最高画质反而是最不安全的。这是本轮最反直觉、也最值得写进理论的结论。

**灵感 5（TELOS 对前三轮的升级点）**
- **VISTA 的认证前缀** → 增加「干预可达性」约束：`k* = min(k_VISTA, k_emo, k_wm, k_tele)`，其中 `k_tele` 由 `δ_rt(R)` 与自主安全视界共同决定；
- **RAS 的 λ_risk** → 增加信道项：`λ_risk` 再乘 `λ_chan(D_perc, δ_rt)`，信道越差越保守；
- **SimRAS 的世界模型** → 增加 `operator_head`，把人建模为「带时延+噪声+饱和」的控制器，离线仿真「人-机-信道」三方闭环；
- **VQAuditor** → 增加「可传输性审计」：不仅问「发生了什么」，还问「这段信息能否在预算内让人看懂」；
- **证书 J** → 增加 `encoder_hash / rate_used / D_perc / intervention_deadline / operator_model_ver`，使「人是否来得及、看得见」可审计。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（TELOS 总览）**：`TELOS = (JRD-VEnc, TCA, IRG, PDC, RAO, OWM, C-TEL, SAA)`。定位：把 VISTA/RAS/SimRAS 的「物理-情绪-未来」闭环，扩展为「编码-时延-人因」闭环。不变式：编码器参数、`D_perc` 估计、OWM、证书构建只在语义流；实时流只做 ROI 掩码、时延估计、前缀布尔判定，零学习写操作。
- **定义 267（视觉编码器作为率-失真映射）**：编码器 `E_θ: X → {0,1}^B`，码率 `R = B`（bit/frame）。双解码：机器头 `D_m` 恢复任务特征 `f(x)`，人端 `D_h` 恢复用于干预判断的线索 `g(x)`。编码时延 `L_enc(R)` 单调递增、凸。
- **定义 268（双消费者失真）**：`d_m = E[ℓ_m(f(x), f(D_m(E(x))))]`，`d_h = E[ℓ_h(g(x), g(D_h(E(x))))]`；联合损失 `L = d_m + μ·d_h + β·R + γ·L_enc(R)`。
- **定义 269（安全加权失真）**：`D_safe = E_x[w(x)·ℓ_h(x)]`，`w(x) = ∂P(detect H_k | fidelity)/∂fidelity`，在故障萌发处（细微高频偏差）取大值。
- **定义 270（率-时延剖面）**：`L_enc(R) = L_0 + aR`（工程近似；凸的一般形式见定理 14），`a > 0`。
- **定义 271（往返时延分解）**：`δ_rt(R) = δ_up + δ_down + L_enc(R) + δ̄_net`，`δ̄_net` 为网络均值时延，抖动 `J_net` 用于最坏情形；有效时延 `δ_eff = δ_rt + q_loss·T_retrans`。
- **定义 272（遥操作信道模型）**：`Ch = (δ̄_net, J_net, p_loss, Gilbert)`。丢包用 Gilbert-Elliott 两态模型；可见帧到达概率 `p_arrive`，人端看到的是「最多 `⌈δ_eff/Δt⌉` 步之前」的陈旧画面。
- **定义 273（感知分歧）**：`D_perc(R) = D_KL(p_h(g | D_h(E(x))) || p_m(g | D_m(E(x))))`，工程上取 `D_perc(R) = D_0·2^{-αR}`。
- **定义 274（不可传输故障集）**：`H_untx = {H_k : R_min(H_k) > R_max(δ_rt)}`，其中 `R_min(H_k) = R(D_perc ≤ ε_int)` 为率失真下界，`R_max = L_enc^{-1}(k_auto·Δt - δ_up - δ_down - δ̄_net)`。
- **定义 275（干预可达集）**：`S_int(R) = {s : ∃u_h, 使指令在 t+δ_rt(R) 到达时闭环仍能回到安全集 S_safe}`。只有落在 `S_int` 内的状态，人的延迟指令才「救得回来」。
- **定义 276（遥操作认证前缀）**：`k_tele(R) = min(k_auto, n(R) + k_rec)`，`n(R)=⌈δ_rt(R)/Δt⌉`，`k_rec` 为指令到达后仍可认证的步数；当 `n(R) > k_auto` 时 `k_tele = k_auto` 并强制末端安全保持。
- **定义 277（干预缺口）**：`G(R) = n(R) - k_auto`。`G>0` 表示自主安全视界撑不到人的指令到达，必须降速/降码率/安全停机。
- **定义 278（风险感知码率分配）**：`R*(t) = argmax_{R∈[R_min,R_max]} p_int(R)·1[G(R) ≤ 0]`；ROI 掩码 `Ω_t = sal_fault(ρ_t) ∪ gaze_t`，对 `Ω_t` 分配码率 `R_Ω = R + ΔR_roi`，背景降码。
- **定义 279（注视/注意力 ROI）**：`gaze_t` 由头眼跟踪或人端点击热图估计；与 `sal_fault` 取并集，保证「机器觉得危险」与「人正在关注」两块都不被压掉。
- **定义 280（操作员世界模型）**：人建模为延迟饱和随机控制器 `u_h(t) = sat(K_h·e(t-δ_rt) + n_h(t))`，`n_h ~ N(0, σ_h^2)`；OWM 由 SimEngine 离线标定 `(K_h, δ_h, σ_h, u_max)`。
- **定义 281（共享权威仲裁）**：`τ_cmd = (1-κ)·τ_auto + κ·τ_human`，`κ = σ(w_1·D_perc + w_2·δ_rt - w_3·J_risk)`；信道差 → 降 κ（自主接管），信道好 → 升 κ（人主导）。
- **定义 282（TELOS 认证前缀）**：`k*TEL = min(k_VISTA, k_emo, k_wm, k_tele, m_ras, m_chan)`。
- **定义 283（编码器混叠故障）**：故障假设集新增 `H_enc`（压缩伪影导致漏检）与 `H_chan`（丢包/抖动导致人端看到旧画面），并入 `ℋ_RAS`。
- **定义 284（AIC-TEL 干扰集）**：`ℰ_TEL = ℰ_SimRAS × ℰ_codec × ℰ_net × ℰ_operator × ℰ_alias`，其中 `ℰ_codec={量化过强, ROI漏配, 码率震荡}`，`ℰ_net={抖动, 丢包突发, 重传风暴}`，`ℰ_operator={疏忽, 误操作, 反应慢}`，`ℰ_alias={机器-人感知错位}`。
- **定义 285（J_TEL 证书）**：`J_TEL = (J_SimRAS, encoder_hash, rate_used, D_perc, intervention_deadline, G, operator_model_ver, untx_set)`。Valid ⇔ `Valid(J_SimRAS) ∧ G ≤ 0 ∧ (D_perc ≤ ε_int ∨ untx_set 已被独立兜底覆盖)`。

```python
# JRD-VEnc：双消费者联合率失真编码器
class JointRateDistortionEncoder:
    def __init__(self, enc, dec_machine, dec_human, rate_latency):
        self.enc, self.dm, self.dh = enc, dec_machine, dec_human
        self.rate_latency = rate_latency          # R -> L_enc(R)

    def encode(self, img, fault_sal, gaze, R_target):
        roi = union_mask(fault_sal, gaze)          # Ω_t
        bits = self.enc(img, roi_mask=roi, rate=R_target)
        D_m = self.task_distortion(bits, img)      # 机器任务失真
        D_h = self.human_proxy_distortion(bits, img)  # 人端干预线索失真（VLM/显著性代理）
        D_perc = kl_div(self.dh(bits), self.dm(bits))
        return {'bits': bits, 'R': R_target, 'roi': roi,
                'D_m': D_m, 'D_h': D_h, 'D_perc': D_perc,
                'L_enc': self.rate_latency(R_target)}


# TCA：遥操作信道适配器（时延/抖动/丢包）
class TeleopChannelAdapter:
    def __init__(self, delta_up, delta_down, net, retrans_s):
        self.up, self.down, self.net = delta_up, delta_down, net
        self.T_retrans = retrans_s

    def estimate(self, R, k_auto, dt):
        L_enc = self.net.rate_latency(R)
        delta_rt = self.up + self.down + L_enc + self.net.mean_delay
        delta_eff = delta_rt + self.net.loss_prob * self.T_retrans
        n = math.ceil(delta_eff / dt)
        return {'delta_rt': delta_rt, 'delta_eff': delta_eff,
                'n': n, 'G': n - k_auto}


# IRG：干预可达性守卫
class InterventionReachabilityGuard:
    def __init__(self, reach_fn, tau_G=0.0):
        self.reach = reach_fn                     # 由 SimEngine 离线标定的可达性布尔函数
        self.tau_G = tau_G

    def check(self, s, R, channel_est, k_auto):
        n, G = channel_est['n'], channel_est['G']
        if G > self.tau_G:                        # 自主撑不到人到达 → 干预缺口
            return {'k_tele': k_auto, 'safe_hold': True, 'gap': G}
        if not self.reach(s, channel_est['delta_eff']):
            return {'k_tele': 0, 'safe_hold': True, 'gap': G}
        return {'k_tele': min(k_auto, n + self.k_rec(s)), 'safe_hold': False, 'gap': G}


# RAO：风险感知码率/ROI 优化
class RiskAwareRateOptimizer:
    def __init__(self, R_min, R_max, alpha=0.5, beta=1.0):
        self.R_min, self.R_max = R_min, R_max
        self.alpha, self.beta = alpha, beta

    def choose_rate(self, fault_post, D0, channel, k_auto, dt):
        best = (self.R_min, -1.0)
        for R in np.linspace(self.R_min, self.R_max, 16):
            D_perc = D0 * 2 ** (-self.alpha * R)
            p_int = sigmoid(self.beta * (1 - D_perc) - channel['delta_eff'] / 0.2)
            G = math.ceil(channel['delta_rt'] / dt) - k_auto
            score = p_int if G <= 0 else -1.0      # 硬约束：有缺口则不可行
            if score > best[1]:
                best = (R, score)
        return best[0]


# OWM：操作员世界模型（离线标定，在线前向）
class OperatorWorldModel:
    def __init__(self, K_h, delta_h, sigma_h, u_max):
        self.K_h, self.delta_h = K_h, delta_h
        self.sigma_h, self.u_max = sigma_h, u_max

    def predict_intervention(self, error_seq, delta_rt):
        # 延迟 + 噪声 + 饱和的人端响应
        delayed = error_seq[-math.ceil(delta_rt / DT):]
        u = self.K_h * np.mean(delayed) + np.random.normal(0, self.sigma_h)
        return np.clip(u, -self.u_max, self.u_max)


# SAA：共享权威仲裁
def shared_authority(tau_auto, tau_human, D_perc, delta_rt, J_risk,
                     w1=2.0, w2=1.0, w3=3.0):
    kappa = sigmoid(w1 * D_perc + w2 * delta_rt - w3 * J_risk)
    return (1 - kappa) * tau_auto + kappa * tau_human, kappa


# 主循环
def TELOS_round(M, obs, k_auto):
    V, T, P, L, Pc, W, tac, img, depth, flow = obs
    M.lsf.update_geometry(Pc)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    M.f_vis(img, depth, flow)

    # 1) 故障后验 + 情绪门（承接 RAS / SimRAS）
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    face_gate = M.erg_wm.recognize(img, x_prime, act_seq=[])
    joint_post, _ = M.efs_wm.synthesize(rho, face_gate, x_prime, [])

    # 2) 先验码率 + 信道估计
    fault_sal = M.rao.saliency(rho)
    gaze = M.gaze.estimate(img)
    R0 = M.rao.choose_rate(joint_post, M.D0, M.tca.estimate_rt0(), k_auto, DT)

    # 3) 编码 + 时延/干涉缺口
    enc = M.jrd.encode(img, fault_sal, gaze, R0)
    chan = M.tca.estimate(enc['R'], k_auto, DT)
    irg = M.irg.check(x_prime, enc['R'], chan, k_auto)

    # 4) 不可传输故障检测
    untx = M.pdc.untransmittable(joint_post, enc, chan)
    if untx and not M.fallback.covers(untx):
        # 独立兜底：不依赖人，直接降速/停机
        return M.safe_hold(x_prime, reason='untransmittable', untx=untx)

    # 5) C-TEL：认证前缀
    k_tel = min(k_auto, irg['k_tele'])
    k_tel = min(k_tel, M.csc.certified_prefix(joint_post, m_chan=M.m_chan(chan)))
    lam_chan = lam_risk_channel(enc['D_perc'], chan['delta_eff'])
    lam = M.efs.risk_scale(joint_post) * lam_chan

    # 6) 共享权威 + 指令
    tau_auto = M.vista.pi_sigma.prefix_dispatch(M.vista.ach.propose(x_prime)[:k_tel])
    tau_h = M.human_buffer.latest(DT * chan['n'])   # 陈旧的人端指令
    tau_cmd, kappa = shared_authority(tau_auto, tau_h, enc['D_perc'],
                                      chan['delta_eff'], joint_post_risk(joint_post))
    tau_cmd *= lam

    # 7) 证书 + 异步审计
    cert = M.make_cert(enc, chan, irg, lam, kappa, untx)
    M.vqa.submit_async(enc['bits'], cert)
    return {'k_tel': k_tel, 'R': enc['R'], 'D_perc': enc['D_perc'],
            'G': chan['G'], 'lam': lam, 'kappa': kappa, 'cert': cert}

## 3. 推导

**引理 13（率-时延-失真三角）** 在定义 270、273 下，`D_perc(R)` 随 `R` 单调递减、`L_enc(R)` 随 `R` 单调递增。因此「降低感知分歧」与「缩短干预时延」在码率维度上**方向相反**，不存在同时最优的单一码率。

**引理 14（干预缺口的单调性）** `G(R) = ⌈(δ_up+δ_down+δ̄_net+L_enc(R))/Δt⌉ - k_auto` 关于 `R` 单调不减。故存在阈值 `R_max`，当 `R > R_max` 时 `G > 0`，即无论画质多好，人的指令都不可能及时到达。

**定理 14（保真度-安全悖论）** 设 `p_int(R) = σ(β(1 - D_0·2^{-αR}) - η·δ_rt(R)/δ_0)`，可行域 `[R_min, R_max]`。若 `α`（失真随码率下降速度）相对 `η·a/δ_0`（时延惩罚）较小，则 `p_int` 在可行域内下降，最优码率取**下边界** `R_min`；反之取**内点** `R* = (1/α)·log2(α·D_0·β / (η·a/δ_0))`。即：**更高保真度不必然更安全，最高画质可能最不安全**。

**定理 15（干预可行性 = 率窗口非空）** 对故障类 `H_k`，存在可执行的人端干预当且仅当 `R_min(H_k) ≤ R_max`。若 `R_min(H_k) > R_max`，则 `H_k ∈ H_untx`，任何编码策略都无法在 `δ_rt` 内让人以 `≥ ε_int` 的置信度识别该故障。此时安全性必须由**不依赖人**的自主兜底保证（降速/停机/力限），而不能记入「人可干预」的证书。

**定理 16（TELOS 端到端风险一致性）** 在 A87–A91 及引理 13–14 下，TELOS 输出满足：
1. `P(|τ_cmd - τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_enc + α_net + α_op`；
2. `G(R) ≤ 0 ∧ D_perc(R) ≤ ε_int ⇒` 人端在 `δ_rt(R)` 内以 `≥ 1-ε_int` 概率做出正确干预判断；
3. `H_untx ≠ ∅ ⇒` 证书强制 `k*TEL` 收缩、`λ_risk` 上调，且禁止把「人可救」写入安全论证；
4. `κ` 随 `D_perc`、`δ_eff` 单调下降，故信道劣化时自主权威自动上升，避免「人凭旧画面误操作」。

**定理 17（时滞共享控制的保守稳定性）** 以 Gilbert-Elliott 丢包 + 常值时延建模信道，若 `κ·K_h·δ_eff < π/2`（小增益/相位裕度条件），则仲裁后闭环在安全集内不发散；超出时须将 `κ→0` 并切入波变量/被动性兜底。这给出了「何时应收回人的权威」的定量边界。

## 2. 形式化定义（完整版）

**定义 266（TELOS 总览）** TELOS 是 SimRAS 的「编码-时延-人因」增强层：
```
TELOS = (JRD-VEnc, TCA, IRG, PDC, RAO, OWM, C-TEL, SAA)
```
不变式：编码器参数、`D_perc` 估计、OWM、证书构建只在语义流；实时流只做 ROI 掩码、时延估计、前缀布尔判定，零学习写操作。编码在独立采集线程完成，控制环消费已编码的陈旧帧并按 `δ_eff` 显式补偿。

**定义 267（视觉编码器作为率-失真映射）** 编码器 `E_θ: X → {0,1}^B`，码率 `R=B`（bit/frame）。双解码：机器头 `D_m` 恢复任务特征 `f(x)`，人端 `D_h` 恢复干预线索 `g(x)`。编码时延 `L_enc(R)` 单调递增、凸。

**定义 268（双消费者失真）**
```
d_m = E[ℓ_m(f(x), f(D_m(E(x))))]
d_h = E[ℓ_h(g(x), g(D_h(E(x))))]
L   = d_m + μ·d_h + β·R + γ·L_enc(R)
```

**定义 269（安全加权失真）**
```
D_safe = E_x[w(x)·ℓ_h(x)],  w(x)=∂P(detect H_k|fidelity)/∂fidelity
```
在故障萌发处（细微高频偏差）取大值，纠正「平均失真」对安全线索的系统性低估。

**定义 270（率-时延剖面）** `L_enc(R)=L_0+aR`（`a>0`，凸的一般形式见定理 14）。

**定义 271（往返时延分解）**
```
δ_rt(R) = δ_up + δ_down + L_enc(R) + δ̄_net
δ_eff   = δ_rt(R) + q_loss·T_retrans
```

**定义 272（遥操作信道模型）** `Ch=(δ̄_net,J_net,p_loss,Gilbert)`。丢包用 Gilbert-Elliott 两态模型；人端看到的是最多 `⌈δ_eff/Δt⌉` 步之前的陈旧画面。

**定义 273（感知分歧）**
```
D_perc(R) = D_KL(p_h(g|D_h(E(x))) ‖ p_m(g|D_m(E(x)))) = D_0·2^{-αR}
```

**定义 274（不可传输故障集）**
```
H_untx = {H_k : R_min(H_k) > R_max(δ_rt)}
R_min(H_k) = R(D_perc ≤ ε_int)
R_max      = L_enc^{-1}(k_auto·Δt - δ_up - δ_down - δ̄_net)
```

**定义 275（干预可达集）**
```
S_int(R) = {s : ∃u_h, 使指令在 t+δ_rt(R) 到达时闭环仍能回到 S_safe}
```

**定义 276（遥操作认证前缀）**
```
k_tele(R) = min(k_auto, n(R)+k_rec),  n(R)=⌈δ_rt(R)/Δt⌉
```
当 `n(R)>k_auto` 时 `k_tele=k_auto` 并强制末端安全保持。

**定义 277（干预缺口）** `G(R)=n(R)-k_auto`；`G>0` 表示自主安全视界撑不到人的指令到达，必须降速/降码率/安全停机。

**定义 278（风险感知码率分配）**
```
R*(t) = argmax_{R∈[R_min,R_max]} p_int(R)·1[G(R) ≤ 0]
Ω_t   = sal_fault(ρ_t) ∪ gaze_t,  R_Ω = R + ΔR_roi
```

**定义 279（注视/注意力 ROI）** `gaze_t` 由头眼跟踪或人端点击热图估计；与 `sal_fault` 取并集，保证「机器觉得危险」与「人正在关注」两块都不被压掉。

**定义 280（操作员世界模型）** 人建模为延迟饱和随机控制器：
```
u_h(t) = sat(K_h·e(t-δ_rt) + n_h(t)),  n_h ~ N(0, σ_h²)
```
OWM 由 SimEngine 离线标定 `(K_h, δ_h, σ_h, u_max)`，在线前向预测干预时刻与幅度。

**定义 281（共享权威仲裁）**
```
τ_cmd = (1-κ)·τ_auto + κ·τ_human
κ = σ(w₁·D_perc + w₂·δ_eff - w₃·J_risk)
```
信道差 → 降 κ（自主接管），信道好 → 升 κ（人主导）。

**定义 282（TELOS 认证前缀）**

k*TEL = min(k_VISTA, k_emo, k_wm, k_tele, m_ras, m_chan)

class JointRateDistortionEncoder:
    def __init__(self, enc, dec_machine, dec_human, rate_latency):
        self.enc, self.dm, self.dh = enc, dec_machine, dec_human
        self.rate_latency = rate_latency

    def encode(self, img, fault_sal, gaze, R_target):
        roi = union_mask(fault_sal, gaze)
        bits = self.enc(img, roi_mask=roi, rate=R_target)
        D_m = self.task_distortion(bits, img)
        D_h = self.human_proxy_distortion(bits, img)
        D_perc = kl_div(self.dh(bits), self.dm(bits))
        return {'bits': bits, 'R': R_target, 'roi': roi, 'D_m': D_m,
                'D_h': D_h, 'D_perc': D_perc,
                'L_enc': self.rate_latency(R_target)}


# IP-244 TCA
class TeleopChannelAdapter:
    def __init__(self, delta_up, delta_down, net, retrans_s):
        self.up, self.down, self.net = delta_up, delta_down, net
        self.T_retrans = retrans_s

    def estimate(self, R, k_auto, dt):
        L_enc = self.net.rate_latency(R)
        delta_rt = self.up + self.down + L_enc + self.net.mean_delay
        delta_eff = delta_rt + self.net.loss_prob * self.T_retrans
        n = math.ceil(delta_eff / dt)
        return {'delta_rt': delta_rt, 'delta_eff': delta_eff,
                'n': n, 'G': n - k_auto}


# IP-245 IRG
class InterventionReachabilityGuard:
    def __init__(self, reach_fn, k_rec_fn):
        self.reach, self.k_rec = reach_fn, k_rec_fn

    def check(self, s, R, chan, k_auto):
        n, G = chan['n'], chan['G']
        if G > 0:
            return {'k_tele': k_auto, 'safe_hold': True, 'gap': G}
        if not self.reach(s, chan['delta_eff']):
            return {'k_tele': 0, 'safe_hold': True, 'gap': G}
        return {'k_tele': min(k_auto, n + self.k_rec(s)),

# IP-247 RAO
class RiskAwareRateOptimizer:
    def __init__(self, R_min, R_max, alpha=0.5, beta=1.0):
        self.R_min, self.R_max = R_min, R_max
        self.alpha, self.beta = alpha, beta

    def saliency(self, rho):
        return fault_signature_saliency(rho)

    def choose_rate(self, joint_post, D0, chan0, k_auto, dt):
        best = (self.R_min, -1.0)
        for R in np.linspace(self.R_min, self.R_max, 16):
            D_perc = D0 * 2 ** (-self.alpha * R)
            p_int = sigmoid(self.beta * (1 - D_perc) - chan0['delta_eff'] / 0.2)
            G = math.ceil(chan0['delta_rt'] / dt) - k_auto
            score = p_int if G <= 0 else -1.0
            if score > best[1]:
                best = (R, score)
        return best[0]


# IP-248 OWM
class OperatorWorldModel:
    def __init__(self, K_h, delta_h, sigma_h, u_max):
        self.K_h, self.delta_h = K_h, delta_h
        self.sigma_h, self.u_max = sigma_h, u_max

    def predict_intervention(self, error_seq, delta_rt, dt):
        k = max(1, math.ceil(delta_rt / dt))
        delayed = error_seq[-k:]
        u = self.K_h * float(np.mean(delayed)) + np.random.normal(0, self.sigma_h)
        return float(np.clip(u, -self.u_max, self.u_max))


# IP-250 SAA
def shared_authority(tau_auto, tau_human, D_perc, delta_eff, J_risk,
                     w1=2.0, w2=1.0, w3=3.0):
    kappa = sigmoid(w1 * D_perc + w2 * delta_eff - w3 * J_risk)
    return (1 - kappa) * tau_auto + kappa * tau_human, kappa

    gaze = M.gaze.estimate(img)
    R0 = M.rao.choose_rate(joint_post, M.D0, M.tca.estimate_rt0(), k_auto, DT)

    enc = M.jrd.encode(img, fault_sal, gaze, R0)
    chan = M.tca.estimate(enc['R'], k_auto, DT)
    irg = M.irg.check(x_prime, enc['R'], chan, k_auto)

    untx = M.pdc.untransmittable(joint_post, enc, chan)
    if untx and not M.fallback.covers(untx):
        return M.safe_hold(x_prime, reason='untransmittable', untx=untx)

    k_tel = min(k_auto, irg['k_tele'])
    k_tel = min(k_tel, M.csc.certified_prefix(joint_post,
                                              m_chan=M.m_chan(chan)))
    lam_chan = lam_risk_channel(enc['D_perc'], chan['delta_eff'])
    lam = M.efs.risk_scale(joint_post) * lam_chan

    tau_auto = M.vista.pi_sigma.prefix_dispatch(
        M.vista.ach.propose(x_prime)[:k_tel])
    tau_h = M.human_buffer.latest(DT * chan['n'])
    tau_cmd, kappa = shared_authority(tau_auto, tau_h, enc['D_perc'],
                                      chan['delta_eff'],
                                      joint_post_risk(joint_post))
    tau_cmd *= lam

    cert = M.make_cert(enc, chan, irg, lam, kappa, untx)
    M.vqa.submit_async(enc['bits'], cert)
    return {'k_tel': k_tel, 'R': enc['R'], 'D_perc': enc['D_perc'],
            'G': chan['G'], 'lam': lam, 'kappa': kappa, 'cert': cert}
```

## 4. 推导

**引理 13（率-时延-失真三角）** 在定义 270、273 下，`D_perc(R)` 随 `R` 单调递减、`L_enc(R)` 随 `R` 单调递增。故「降低感知分歧」与「缩短干预时延」在码率维度方向相反，不存在同时最优的单一码率。

**引理 14（干预缺口单调性）** `G(R)=⌈(δ_up+δ_down+δ̄_net+L_enc(R))/Δt⌉-k_auto` 关于 `R` 单调不减。故存在阈值 `R_max`，当 `R>R_max` 时 `G>0`：无论画质多好，人的指令都不可能及时到达。

**定理 14（保真度-安全悖论）** 设 `p_int(R)=σ(β(1-D_0·2^{-αR}) - η·δ_rt(R)/δ_0)`，可行域 `[R_min,R_max]`。若 `α` 相对 `η·a/δ_0` 较小，则 `p_int` 在可行域内下降，最优码率取下边界 `R_min`；反之取内点
```
R* = (1/α)·log2( α·D_0·β / (η·a/δ_0) )
```
即：更高保真度不必然更安全，最高画质可能最不安全。

**定理 15（干预可行性 = 率窗口非空）** 对故障类 `H_k`，存在可执行的人端干预当且仅当 `R_min(H_k) ≤ R_max`。若 `R_min(H_k) > R_max`，则 `H_k ∈ H_untx`，任何编码策略都无法在 `δ_rt` 内让人以 `≥ ε_int` 的置信度识别该故障；此时安全性必须由不依赖人的自主兜底保证，禁止把「人可干预」写入证书。

**定理 16（TELOS 端到端风险一致性）** 在 A87–A91 及引理 13–14 下：
1. `P(|τ_cmd-τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_enc+α_net+α_op`；
2. `G(R)≤0 ∧ D_perc(R)≤ε_int ⇒` 人端在 `δ_rt(R)` 内以 `≥1-ε_int` 概率做出正确干预判断；
3. `H_untx≠∅ ⇒` 证书强制收缩 `k*TEL`、上调 `λ_risk`，且禁止把「人可救」写入安全论证；
4. `κ` 随 `D_perc, δ_eff` 单调下降，信道劣化时自主权威自动上升，避免「人凭旧画面误操作」。

**定理 17（时滞共享控制的保守稳定性）** 以 Gilbert-Elliott 丢包 + 常值时延建模信道，若 `κ·K_h·δ_eff < π/2`（小增益/相位裕度条件），则仲裁后闭环在安全集内不发散；超出时须 `κ→0` 并切入波变量/被动性兜底。这给出「何时应收回人的权威」的定量边界。

## 7. 本轮最大风险

**一句话**：TELOS 的全部安全论证都建立在「人能在 `δ_rt` 内看懂并正确出手」这一假设上，而 `D_perc` 只是用代理模型估计的「人可能怎么看」，一旦真实操作员的感知/反应分布偏离代理（疲劳、分心、被压缩伪影误导），证书会给出**看似成立、实则空洞的「人可干预」保证**——把遥操作的安全责任，错误地外包给了一个并不存在的、理想化的人。

**次级风险与缓解**：
1. **代理模型失配**：`D_perc` 用 VLM/显著性代理估计，可能与真人分布偏移 → 定期用真人标定集校准，并设「代理置信度」阈值，低于阈值时按 `H_untx` 处理；
2. **码率-时延标定漂移**：`L_enc(R)` 随设备/负载漂移 → 在线滑动估计 `L_enc` 与抖动，证书中记录实测 `rate_used` 与 `L_enc`；
3. **共享权威振荡**：`κ` 在信道劣化边界反复切换 → 对 `κ` 加迟滞与速率限制；
4. **不可传输故障的兜底成本**：安全停机可能牺牲任务成功率 → 分级兜底（降速 > 换低风险策略 > 停机），并把兜底成本纳入优化；
5. **编码器混叠共因**：同一压缩事件同时降低机器与人端可辨识度 → 用 AIC-TEL 的 `ℰ_alias` 建模共因，证书要求至少一个消费者仍可检出；
6. **安全与隐私**：遥操作视频常含人脸/工位信息 → ROI 编码与端侧脱敏，避免为「可读性」泄露敏感信息。
