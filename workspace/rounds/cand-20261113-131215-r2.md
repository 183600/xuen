# 第 66 轮（承接第 65 轮「VISTA 视觉知情的安全时序归因闭环」IP-214~223；灵感循环第 2 轮；本轮灵感：「强化学习」×「续航能力」）

> 第 65 轮把“几何可证伪”升级为“故障可归因”，其自述的最大风险是：**归因依赖有限故障假设集与视觉/几何失效独立；真实世界会出现未知的复合故障与共因失效，系统可能把未知故障强行归入最近假设、只膨胀错误的球，并因“已经归因”而更自信地继续执行。** 本轮不再增加故障假设、也不再加模态，而是换一个更底层的问题：**前面所有证书都默认“能量、算力、时间是免费的”——但真实机器人一次任务只有一块电池，证书、探测、思考本身都要耗电，而且电耗尽不可逆。** 于是本轮核心命题是：
>
> **把安全从「状态约束」升级为「资源约束下的不变式」：用离线强化学习负责长视界的“怎么走得更远”，用能量储备控制屏障负责实时的“永远回得来”，用 anytime 证书把“思考”也纳入能量预算；任何学习、探索、归因、规划都只能在返航储备之外进行。**

## 0. 直觉与动机

**灵感 1（强化学习 → 长视界决策，但在线探索本身是负债）**
直觉：前几轮解决的是“给定策略/计划，如何证明它安全”；RL 能解决“策略本身怎么变好、如何做长视界的信用分配”。但 RL 的在线探索对续航机器人是致命的：每一次试错都花焦耳，且可能把机器人带到回不来的地方。于是 RL 的角色要从“在线试错者”改成“离线提议者”：从已记录的证书/故障/执行数据里离线学习，在线只做被盾允许的提议；探索改在模型、日志、仿真里做，不花真机电量。**RL 负责“怎么走得更远”，盾负责“永远回得来”。**

**灵感 2（续航能力 → 单调、不可再生、与安全耦合的资源）**
直觉：续航不是奖励里的一个惩罚项。电量低会同时降低最大力、速度、散热余量、传感器信噪比，并缩短可恢复距离；也就是说 **E 越低，安全动作集越小**。更关键：证书计算、视觉世界模型、AFA 探针、WCV-V 尾部采样都要耗电/耗算力。前几轮把这些当作“免费 oracle”，本轮要把“思考成本”显式纳入。低电量时正确的反应不是“降低安全”，而是“**降低思考精度并更早返航**”。

**灵感 3（合流 → ENDURE：把证书变成能量不变式）**
闭环：离线约束 RL 学长视界提议 → 能量储备函数与认证返航策略 → 能量 CBF 盾做最小干预投影 → 低电量时 anytime 证书降级（缩短 H、减少 n_cert、优先视觉/零力探针）→ 比特/焦耳归一化的主动故障归因 → 能量可行的块级任务规划 → 能量对抗认证（电池模型错、低温掉电、低电感知退化、共因失效）→ J_endure 证书。整条链只有一个不可谈判的硬不变式：**E_t ≥ R(x_t) + δ_ret**。RL 只优化 R 之外的“可支配能量”。

**灵感 4（与 VISTA 的关系：不是替代，而是给证书加“能量维度”）**
- VISTA 的 FIR/AFA/WCV/CSC 全部保留，但增加能量约束与“每焦耳信息”选择。
- VISTA 的“故障可归因”扩展为“**故障可归因 + 能量可归因**”：低电量下出错时，首先要问是几何/力/视觉故障，还是“电量低导致安全集收缩、感知退化、计算降级”。
- 第 65 轮的 common-cause 风险在本轮有了新形态：**低电量会同时削弱感知、执行、计算与返航能力**，这是一种天然的共因故障；因此 ENDURE 不要求归因正确，而要求在共因下仍维持“返航储备”这条硬底线。

**灵感 5（组件原位升级）**
- **ERL → 离线约束 RL**：只从日志/仿真学习，支持域外与悲观值不达标即回退认证基线 π_ref。
- **ERS/ECBF → 能量储备 + 认证返航策略**：把 R(x) 变成可实时检查的不变式，而不是 reward 惩罚。
- **EAS → 能量感知盾**：把 RL 动作最小干预地投影到 A_safe∩A_safe^E；为空则执行 π_ret。
- **ERC → anytime 证书**：证书精度 q 的边际价值要与计算耗能 λ_E·c_comp(q) 比较，低电量自动降级。
- **EIG-AFA → 比特/焦耳**：探针从“最大互信息”升级为“每焦耳最大互信息”，易损物体先走零接触探针。
- **ETP → 能量可行块规划**：每条块边都要满足前缀能量约束，充电/返航作为一等技能。
- **EVC → 值校准**：用悲观值下界与能量审计防止 RL 利用电池模型误差“刷奖励”。
- **E-AIC → 能量对抗认证**：电池老化、低温掉电、电压回弹、充电站不可用、低电感知退化、共因失效。
- **J_endure → 续航证书**：在 J_vista 上增加 E_lo、R、h_min、q_cert、bits_per_joule、rtb_policy_ver、value_lb、energy_audit。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（ENDURE 闭环）**：ENDURE = (VISTA, ERL, ERS/ECBF, EAS, ERC, EIG-AFA, ETP, EVC, E-AIC, J_endure)。定位：VISTA 的“资源约束 + 长视界决策”升级。不变式：**能量储备不变式只在实时流强制；RL 训练、值校准、证书预算、任务规划只在语义流；实时流零学习写操作，任何动作必须通过能量盾；能量不可透支。**
- **定义 234（能量状态与消耗模型）**：E_t∈[0,E_max]，电池健康 b_t∈[0,1]。消耗 c(s_t,a_t,q_t,ξ_t)=c_act+c_sense+c_comp+c_comm≥0，E_{t+1}=E_t−c。电池状态用区间 [E_t^lo,E_t^hi] 或 conformal 估计；安全决策只用下界 E_lo，规划可用估计值。可支配能量 E_t^work=E_t^lo−R(x_t)−δ_ret。
- **定义 235（能量储备与认证返航策略）**：安全回收集 S_ret（充电座/停机位/稳定姿态），认证返航策略 π_ret∈Π_cert。R(x)=在 π_ret 下、对消耗取最坏上界时到达 S_ret 并安全停止所需能量。h(x,E)=E−R(x)−δ_ret；h≥0 称“续航安全”。若 x 不在可返航域，则进入最小风险停机模式，不承诺返航。
- **定义 236（能量控制屏障 ECBF）**：对动作 a，令 E'=E−c̄(s,a,q)。A_safe^E(x,E)={a∈A: h(x',E')≥0}。ECBF 条件：h(x',E')≥0。若 A_safe^E 为空，执行 π_ret。单调性：E1≤E2 ⇒ A_safe^E(x,E1)⊆A_safe^E(x,E2)。
- **定义 237（ENDURE 约束 MDP）**：状态 s̃=(x,E,b)，动作 a，奖励 r，安全代价 c_safe，能量代价 c_E。目标 max E[Σγ^t r_t]，s.t. 全程安全、E_T≥E_min、每步 h≥0。硬约束由盾在线强制；RL 只在这个盾内优化。
- **定义 238（离线约束 RL 与认证基线）**：数据 D 来自 VISTA 日志与仿真；行为策略 π_b。学习 Q_r、Q_c 的悲观下界。认证基线 π_ref=VISTA 策略。支持域 U_δ={s: d_D(s)≥δ_s}。仅当 s∈U_δ 且优势下界 A^-=Q_r^-(s,a)−V^{π_ref}(s)≥0 时部署 π_RL，否则回退 π_ref。
- **定义 239（能量感知盾 EAS）**：a_t=argmin_{a∈A_safe(x,E)∩A_safe^E(x,E)} ‖a−a_RL‖²；集合为空则 a_t=π_ret。称此为最小干预投影；记录干预率 ν 与盾致任务损失。
- **定义 240（anytime 证书与计算能量）**：证书档位 q∈Q（如 H、n_cert、n_worst、probe_set），计算耗能 c_comp(q)。证书价值 V_cert(q;x) 表示质量 q 带来的期望任务价值/风险降低。选择 q*=argmax_q [V_cert(q;x)−λ_E(x)c_comp(q)]，s.t. E−c_comp(q)≥R(x)+δ_ret。λ_E 为能量影子价格；低电量时 λ_E↑，q*↓。
- **定义 241（EIG-AFA：比特/焦耳主动故障归因）**：探针 a 的信息增益 I(ℋ;ρ(a)|past)，耗能 c(a)=c_act+c_sense+c_comp。选择 a*=argmax_a I/c，s.t. ECBF、f_n≤f_safe、形变≤ε_strain。边际比特/焦耳<λ_E 或故障熵<δ 即停止；易损物体只允许 visual_probe/null_test。
- **定义 242（ETP：能量可行块级任务规划）**：技能/块 σ 带能量消耗分布与奖励。计划 π=(σ_1,…,σ_n) 能量可行 ⇔ 对每个前缀 j，E_0−Σ_{i≤j} c̄(σ_i)≥R(x_j)+δ_ret。用能量条件 A* 在状态 (x,E_lo) 上搜索；充电/返航技能与任务技能同等入图。
- **定义 243（能量-安全耦合与单调安全集）**：安全集 S(E) 随 E 参数化：f_lim(E)、v_max(E)、Σ_sensor(E)、热限。假设 E1≤E2 ⇒ S(E1)⊆S(E2)。沿计划取 E_min=min_t E_t^lo，只在 S(E_min) 上认证，得到能量鲁棒安全。
- **定义 244（E-AIC：能量对抗与共因失效）**：干扰集 ℰ_E 含电池老化/容量衰减、低温掉电、电压回弹、最坏消耗、低电感知退化、充电站不可用、能量奖励黑客。共因故障 ℰ_common^E：低电量同时削弱感知、执行、计算与返航；此时不要求归因正确，只要求维持 h≥0 并安全停机/返航。
- **定义 245（EVC：续航值校准与奖励黑客防护）**：学习值下界 V^-，悲观选择策略；定义能量审计 gap=|ĉ_realized−ĉ_predicted|/ĉ_predicted。gap>δ_audit 即冻结 RL、回退 π_ref。joule-normalized advantage 只用于排序，不进入硬约束。
- **定义 246（J_endure 续航证书）**：J_endure=(J_vista, E_lo, R(x), h_min, q_cert, λ_E, bits_per_joule, rtb_policy_ver, battery_model_ver, value_lb, energy_audit)。Valid ⇔ Valid(J_vista) ∧ 计划全程 h≥0 ∧ q_cert≥q_min(E) ∧ π_ret 已认证 ∧ value_lb≥baseline−ε ∧ energy_audit≤δ_audit。
- **定义 247（多回合持久自治）**：充电/换电技能、电池健康演化 b_{k+1}=f_b(b_k, cycles)、跨回合任务调度；目标是在“服务率-电池寿命-安全”三者间做约束优化，而不是单回合刷任务数。
- **定义 248（ENDURE 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG→ACH→VCV→FIR→EIG-AFA→WCV-V→ETP/块规划→CSC→Shield→执行 k* 步→EV_exec→RSC-V→OLP→DIR→E-AIC→EVC]；实时流 [锚点读→能量积分→E_lo 更新→阶段判定→ECBF 检查→EAS 投影→CSC 早停→π_σ 派发→J_endure 构建]。

## 2. 关键算法骨架

```python
# 实时：能量盾（每步都跑，零学习）
E_lo = battery.interval_lower()                 # 最坏情况可用能量
h    = E_lo - reserve.R(x) - DELTA_RET          # 返航储备裕度
if h < 0:                                       # 已越过安全边界
    a = return_policy.pi_ret(x)                 # 认证返航 / 最小风险停机
else:
    A_safe = [a for a in A if safety_ok(x, a) and
              E_lo - cost_upper(x, a) - reserve.R(next_x(x, a)) >= DELTA_RET]
    a = project(a_rl, A_safe) if A_safe else return_policy.pi_ret(x)

# 语义流：离线 RL 提议 + 支持域/悲观优势检查
if s in support(D) and adv_lower_bound(s, a_rl) >= 0:
    a_rl = policy_rl(s)
else:
    a_rl = baseline_vista(s)                    # π_ref

# 语义流：anytime 证书（低电量降级“思考”，不降级“返航”）
q_star = argmax_q (V_cert(q, x) - lambda_E(x) * comp_energy(q))
cert   = vista.certify(x, q_star)               # H、n_cert、AFA、WCV 尾部随 q 缩放

# 语义流：EIG-AFA（比特 / 焦耳）
if fault_entropy > DELTA_FI and not object_fragile:
    a_probe = argmax_a mutual_info(a) / probe_energy(a)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（能量不变式）**：若初始 h≥0，且每步要么选 A_safe^E 内动作、要么执行认证 π_ret，则在最坏消耗上界成立时 h_t≥0 直至到达 S_ret。故“续航安全”是可归纳维持的硬不变式，而不是软惩罚。
- **引理 10（盾的最小干预）**：A_safe 凸且非空时，欧氏投影唯一且最小化偏离；任务损失 ≤ L_a·dist(a_RL,A_safe)。集合为空时回退 π_ret，安全性不依赖 RL 的正确性。
- **定理 9（ENDURE 端到端）**：在 A94–A99（能量模型上界、认证返航策略、单调安全集、盾、离线支持域）下，Valid(J_endure) ⇒ 全程 h≥0 ∧ 能量可行 ∧ 任务性能不低于基线（高概率）∧ 低电优雅降级 ∧ 共因故障下安全停机/返航。
- **定理 10（anytime 证书的单调降级）**：V_cert 凹、c_comp 凸时，q*(λ_E) 关于 λ_E 单调不增；把 q 降到 q_min 的价值损失 ≤ λ_E·Δc_comp+O(Δq²)，且因 q_min 仍满足 J 的有效条件，安全不被降级。
- **定理 11（比特/焦耳探针的近似最优性）**：互信息对探针集合次模；能量预算下的贪心选择达到 (1−1/e) 近似；探针独立时退化为分数背包的精确解。
- **定理 12（离线 RL 的安全改进分离）**：安全由盾保证、与 RL 误差无关；在支持域与悲观值条件下，盾内策略值以高概率不低于 π_ref−ε。于是“性能提升”和“安全保证”第一次被解耦。
- **实时性**：能量积分 <0.01ms、ECBF 检查 <0.02ms、EAS 投影 <0.05ms；VISTA 2.5ms + ENDURE ≈ **<2.6ms**（A100 修订契约，能量模型与盾共享实时线程）。

## 2. 形式化定义（完整版）

**定义 233（ENDURE 闭环）** ENDURE 是 VISTA 的“资源约束 + 长视界决策”升级：在 VISTA 的“语义流 ∘ 实时流”骨架上挂载 ERL（离线约束 RL）、ERS/ECBF（能量储备控制屏障）、EAS（能量感知盾）、ERC（anytime 证书）、EIG-AFA（比特/焦耳主动归因）、ETP（能量可行块规划）、EVC（值校准）、E-AIC（能量对抗认证），并把 J_vista 升级为 J_endure。不变式：
1. **能量不可透支**：实时流每一步都必须满足 h_t=E_t^lo−R(x_t)−δ_ret≥0；
2. **实时流零学习写操作**：RL 训练、值校准、证书预算、任务规划只在语义流；
3. **任何动作先过盾**：π_RL 只产生提议，EAS 负责投影或回退 π_ret；
4. **思考有价**：证书精度 q 的选择必须计入 c_comp(q) 与 λ_E(x)。

**定义 234（能量状态与消耗模型）** 电池状态 E_t∈[0,E_max]，健康度 b_t∈[0,1]（容量衰减、内阻上升）。单步消耗
c(s_t,a_t,q_t,ξ_t)=c_act(s_t,a_t)+c_sense(s_t)+c_comp(q_t)+c_comm(s_t)+ξ_t，
其中各项非负，ξ_t 为未建模波动。能量转移
E_{t+1}=E_t−c(s_t,a_t,q_t,ξ_t)。
由于电池模型存在老化、温度、电压回弹与估计误差，维护区间 [E_t^lo,E_t^hi]。**安全决策只使用 E_t^lo；规划与 RL 可使用区间中点或上界。** 可支配能量定义为
E_t^work=E_t^lo−R(x_t)−δ_ret。
若 E_t^work<0，系统进入最小风险停机/返航模式，不再接受任务动作。

**定义 235（能量储备与认证返航策略）** 设安全回收集 S_ret（充电座、停机位、稳定姿态或已知安全区）。认证返航策略 π_ret∈Π_cert 满足：从任意可达状态 x 出发，π_ret 能在不违反 VISTA 安全约束的前提下到达 S_ret 并安全停止。定义
R(x)=max_{ξ_{0:T}} Σ_{t=0}^{T−1} c(x_t,π_ret(x_t),q_min,ξ_t)
为最坏消耗上界（q_min 为维持最低有效证书的计算档位）。储备裕度
h(x,E)=E−R(x)−δ_ret。
h≥0 称状态 (x,E) **续航安全**。若 x 不在可返航域（R(x)=∞），则不承诺返航，只承诺“最小风险停机”，并把该状态标为 `unrecoverable` 写入 J_endure。**关键工程含义：不是所有状态都能被救回；盾的第一职责是阻止进入不可返航域。**

**定义 236（能量控制屏障 ECBF）** 对动作 a∈A，令 x'=f(x,a)，E'=E−c̄(s,a,q)。能量安全动作集
A_safe^E(x,E)={a∈A: h(x',E')≥0}。
ECBF 条件即 h(x',E')≥0。若 A_safe^E(x,E)=∅，执行 π_ret；若 π_ret 也不可行，执行最小风险停机（最大减速、支撑、断电保护）。单调性：
E_1≤E_2 ⇒ A_safe^E(x,E_1)⊆A_safe^E(x,E_2)，
即低电量只会让安全动作集更小，不会更大。这是“续航是安全资源”而不是“续航是奖励项”的形式化表达。

**定义 237（ENDURE 约束 MDP）** 状态 s̃=(x,E,b)，动作 a∈A，转移 P(s̃'|s̃,a)，奖励 r(s̃,a)，安全代价 c_safe∈{0,1}（越界/滑移/碰撞），能量代价 c_E=c(s,a,q,ξ)。优化目标
max_π E_π[Σ_{t=0}^{T−1} γ^t r(s̃_t,a_t)]
s.t. 全程 c_safe=0，E_t≥R(x_t)+δ_ret ∀t，E_T≥E_min。
硬约束由 EAS 在线强制；RL 只在这个盾内优化“可支配能量”的长期回报。定义**续航价值**
V_E^π(s̃)=E_π[Σ γ^t r | s̃, π, 盾],
以及**焦耳归一化回报** R_J=E[return]/E[spent]（只用于排序与审计，不进入硬约束）。

**定义 238（离线约束 RL 与认证基线）** 数据 D={(s̃_t,a_t,r_t,c_t,s̃_{t+1})} 来自 VISTA 日志、故障注入与仿真；行为策略 π_b。学习奖励 Q_r 与代价 Q_c 的悲观估计：
Q_r^-(s,a)=Q_r(s,a)−β_r·U_r(s,a)，Q_c^-(s,a)=Q_c(s,a)−β_c·U_c(s,a)，
其中 U 为集成方差/密度不确定性。认证基线 π_ref 为第 65 轮 VISTA 策略。支持域
U_δ={s̃: d_D(s̃)≥δ_s}。
定义优势下界
A^-(s,a)=Q_r^-(s,a)−V^{π_ref}(s)−β_a·U_a(s,a)。
部署规则：
π_RL(s)=a 仅当 s∈U_δ ∧ A^-(s,a)≥0；否则 π_RL(s)=π_ref(s)。
即 **RL 只能在“有数据、且下界仍优于基线”的地方提议**；其余地方由认证基线接管。离线训练不消耗真机电量，在线也不做探索性写操作。

**定义 239（能量感知盾 EAS）** 给定 RL 提议 a_RL，定义
a_t=Π_{A_safe(x,E)∩A_safe^E(x,E)}(a_RL)
=argmin_{a∈A_safe∩A_safe^E} ‖a−a_RL‖_M²，
其中 M 为动作度量（关节空间/任务空间加权）。若交集为空，a_t=π_ret(x)。称 a_t 为**最小干预投影**。记录：
- 干预率 ν=P(a_RL∉A_safe∩A_safe^E)；
- 盾致任务损失 ℓ_shield=r(a_RL)−r(a_t)（仅统计，不用于在线学习写操作）；
- 回退次数 n_ret（π_ret 触发次数）。
**盾的正确性不依赖 RL 的正确性**：即使 Q 完全错误，只要 A_safe^E 与 π_ret 正确，h≥0 仍成立。

**定义 240（anytime 证书与计算能量）** 证书档位
q=(H,n_cert,n_worst,n_probe,res_world_model)∈Q，
对应 VISTA 的预测视界、AIC 认证样本数、WCV 尾部样本数、AFA 探针预算、世界模型分辨率。计算耗能
c_comp(q)=α_H·H+α_c·n_cert+α_w·n_worst+α_p·n_probe+α_r·res_world_model，
各项系数由离线功耗标定。证书价值 V_cert(q;x) 表示档位 q 对任务价值/风险降低的贡献，假设关于 q 单调递增且凹。能量影子价格 λ_E(x)=−∂V^*/∂E（由值函数差分或对偶变量得到）。选择
q*(x)=argmax_{q∈Q} [V_cert(q;x)−λ_E(x)·c_comp(q)]
s.t. E_t^lo−c_comp(q)≥R(x)+δ_ret。
**低电量时 λ_E 上升，q* 单调下降**：系统会缩短 H、减少 n_cert、减少 AFA 探针、降低世界模型分辨率，但绝不把 q 降到 q_min(E) 以下；若连 q_min 都付不起，则由盾强制 π_ret/安全停机。于是“低电时少思考”是**性能降级**，不是**安全降级**。

**定义 241（EIG-AFA：比特/焦耳主动故障归因）** 令 ℋ 为第 65 轮故障假设集，ρ(a) 为探针 a 产生的阶段化证据。探针的信息增益
I(a)=I(ℋ;ρ(a)|ρ_past)，
总耗能
c(a)=E[c_act(a)]+E[c_sense(a)]+E[c_comp(a)]。
选择
a*=argmax_{a∈A_probe} I(a)/c(a)
s.t. (1) a 满足 ECBF 与 f_n≤f_safe(φ̂,f̂_vis)；(2) 预测形变≤ε_strain；(3) 易损物体时 A_probe⊆{visual_probe,null_test}。
停止规则：若边际 I/c<λ_E(x) 或故障熵 H(ℋ|ρ)<δ_fi，停止探测，进入保守处置。
**理论依据**：互信息对观测集合单调次模；能量预算下的探针选择是背包约束下的次模最大化，密度贪心 + 单元素枚举可达 (1−1/e−ε) 近似；探针等成本时退化为基数贪心的 (1−1/e)。

**定义 242（ETP：能量可行块级任务规划）** 技能/块 σ 带能量消耗分布 c(σ)、奖励 r(σ) 与前置条件。计划 π=(σ_1,…,σ_n)。**能量可行**定义为：对每个前缀 j∈{1,…,n}，
E_0^lo−Σ_{i=1}^{j} c̄(σ_i) ≥ R(x_j)+δ_ret。
在能量条件 A* 上搜索：状态 (x,E_lo)，边 σ 的代价 c̄(σ)，启发式为剩余任务奖励上界；支配关系：
(x,E_1) ≻ (x,E_2) ⇔ E_1≥E_2 ∧ g_1≤g_2，
其中 g 为已用能量/时间。被支配状态剪枝。充电/换电技能 σ_recharge 与任务技能同等入图；规划器必须显式决定“现在充电”还是“再做一个任务”。目标：
max_π Σ r(σ) s.t. 能量可行 ∧ Valid(J_endure)。
这使 CSP-V 从“几何/技能可行性”升级为“几何/技能/能量三重可行性”。

**定义 243（能量-安全耦合与单调安全集）** 安全集随能量参数化：
S(E)={x: f_lim(E), v_max(E), Σ_sensor(E), T_thermal(E) 均满足}。
假设**单调性**：E_1≤E_2 ⇒ S(E_1)⊆S(E_2)（低电量绝不会让机器人更安全、更敏捷、更准）。沿计划取
E_min=min_{t≤T} E_t^lo，
并只在 S(E_min) 上认证力限、速度、抓取与滑移裕度。若计划在 S(E_min) 上安全，则在更高电量处执行同样动作也安全（在单调性假设下）。这把电池对动力学的影响显式接入第 64/65 轮的 ρ_force/ρ_slip/ρ_rob 证书。

**定义 244（E-AIC：能量对抗与共因失效）** 干扰集
ℰ_E=ℰ_batt×ℰ_cons×ℰ_low×ℰ_charge×ℰ_hack，
其中：
- ℰ_batt：容量衰减、内阻上升、低温掉电、电压回弹、SOC 估计偏差；
- ℰ_cons：最坏消耗（摩擦、负载、风阻、通信重传）；
- ℰ_low：低电量导致的感知退化（曝光不足、帧率下降、噪声上升）与执行退化（力矩上限下降、关节迟滞）；
- ℰ_charge：充电站被占、充电失败、返航路径被堵；
- ℰ_hack：策略利用低估的能耗模型“刷奖励”。
并定义**能量共因故障** ℰ_common^E：同一低电量同时削弱感知、执行、计算与返航能力。E-AIC 的认证要求：
1. c̄ 与 E_lo 用 conformal/区间上界，且在最坏电池参数下重算；
2. ρ_dir 在 ℰ_E 上重算（n_cert 128→160，其中 32 给能量/低温/低电感知）；
3. 共因故障下**不要求归因正确**，只要求 h≥0、能安全停机/返航，并把 `energy_common_cause=True` 写入 J_endure；
4. 对“充电站不可用”增加 `dock_unavailable` 分支，规划器必须保留替代安全区。

**定义 245（EVC：续航值校准与奖励黑客防护）** 用悲观值下界 V^- 做策略选择；部署前检查能量审计：
gap_t=|ĉ_realized(t)−ĉ_predicted(t)|/max(ĉ_predicted(t),ε_E)。
若 gap_t>δ_audit（CUSUM 持续超限），立即：
1. 冻结 RL 提议，回退 π_ref；
2. 把该段数据标为 `energy_model_drift`，不进入在线学习；
3. 触发电池模型重标定或保守化 c̄。
定义**能量奖励黑客率** H_E=P(gap>δ_audit | RL 动作被选中)。EVC 的目标不是让 RL 更激进，而是让 RL 的“省电”声明可审计、可证伪。

**定义 246（J_endure 续航证书）** 
J_endure=(J_vista, E_lo, R(x), h_min, q_cert, λ_E, bits_per_joule, rtb_policy_ver, battery_model_ver, value_lb, energy_audit, energy_common_cause)。
验证规则：
Valid(J_endure) ⇔ Valid(J_vista)
∧ (∀t≤T: h_t≥0)
∧ q_cert≥q_min(E)
∧ rtb_policy_ver 为当前认证版本
∧ battery_model_ver 与当前电池/温度区间匹配
∧ value_lb≥baseline−ε_v
∧ energy_audit≤δ_audit
∧ (energy_common_cause ⇒ 已执行安全停机/返航而非强行归因)。
审计链新增：为什么选这个动作（RL 优势下界）、为什么选这个证书档位（λ_E）、为什么还有储备（R/h）、为什么相信电池模型（battery_model_ver）、这次探测每焦耳买到了多少比特（bits_per_joule）。

**定义 247（多回合持久自治）** 引入充电/换电技能与电池健康演化
b_{k+1}=f_b(b_k, cycles_k, T_k, depth_DOD)，
其中 k 为回合。跨回合目标：
max E[Σ_k service_k]
s.t. P(stranded)=0，b_k≥b_min，充电排队时间≤τ_q。
这使 ENDURE 从“单回合不搁浅”扩展到“长期服务率-电池寿命-安全”的三方约束。多回合规划可以把“现在多花一点电快速完成任务”与“省电延长电池寿命”做显式权衡，但任何权衡都不得突破单回合的 h≥0 硬约束。

**定义 248（ENDURE 闭环算子）** 语义流：
[LiDAR→LSF→USR/MEL→VPG 视觉前瞻→ACH 块生成→阶段切分→VCV→FIR 归因→EIG-AFA 探针→WCV-V 编译→ETP/块规划→CSC 认证前缀→Shield-Skill→OCB-Skill→执行 k* 步→EV_exec→RSC-V→OLP→DIR→E-AIC 认证→EVC 值校准]。
实时流：
[锚点读→能量积分/E_lo 更新→阶段判定→ECBF 检查→EAS 投影→CSC 早停→π_σ 前缀派发→J_endure 构建]。
两条流共享能量状态，但只有实时流拥有“拒动作”的否决权；语义流只能“建议”。

## 3. 关键算法伪代码

### IP-224 ERL（离线约束 RL + 认证基线）

```python
class EnduranceOfflineRL:
    """离线学习长视界提议；在线只提议，不探索、不写参数。"""
    def __init__(self, dataset, baseline, beta=1.0, delta_s=0.05):
        self.D = dataset                      # VISTA 日志 + 故障注入 + 仿真
        self.baseline = baseline              # pi_ref
        self.beta, self.delta_s = beta, delta_s
        self.Qr, self.Qc = self._train_pessimistic()

    def _train_pessimistic(self):
        # 集成 Q / CQL / IQL 均可；关键是给出 Q^- 与支持域
        Qr = train_ensemble(self.D, target='reward')
        Qc = train_ensemble(self.D, target='cost')
        return Qr, Qc

    def support(self, s):
        return density(self.D, s) >= self.delta_s

    def advantage_lb(self, s, a):
        q = self.Qr.lower(s, a) - self.beta * self.Qr.uncertainty(s, a)
        v_ref = self.Qr.lower(s, self.baseline.action(s))
        return q - v_ref

    def propose(self, s):
        if not self.support(s):
            return self.baseline.action(s)
        a = self.Qr.greedy(s)
        return a if self.advantage_lb(s, a) >= 0.0 else self.baseline.action(s)
```

### IP-225/226 ERS + EAS（能量储备与能量盾）

```python
class EnduranceShield:
    """实时：唯一有权否决动作的组件。零学习写操作。"""
    def __init__(self, reserve, return_policy, cost_upper, delta_ret=0.02):
        self.R = reserve              # R(x): 认证返航所需最坏能耗
        self.pi_ret = return_policy   # 已认证的返航策略
        self.c_bar = cost_upper       # c_bar(s,a,q)
        self.delta_ret = delta_ret

    def margin(self, x, E_lo):
        r = self.R(x)
        if not np.isfinite(r):
            return -np.inf, 'unrecoverable'
        return E_lo - r - self.delta_ret, 'ok'

    def filter(self, x, E_lo, a_rl, q, safety_ok):
        h, status = self.margin(x, E_lo)
        if status == 'unrecoverable':
            return self.pi_ret.stop_safely(x), 'stop'
        if h < 0.0:
            return self.pi_ret(x), 'return'
        safe = []
        for a in candidate_actions(a_rl):
            x2 = dynamics(x, a)
            E2 = E_lo - self.c_bar(x, a, q)
            h2, st2 = self.margin(x2, E2)
            if st2 == 'ok' and h2 >= 0.0 and safety_ok(x, a):
                safe.append(a)
        if not safe:
            return self.pi_ret(x), 'return'
        a = project_l2(a_rl, safe)
        return a, ('pass' if a is a_rl else 'project')
```

def energy_conditioned_astar(x0, E0, goal, skills, R, c_bar, delta_ret):
    open_set = PriorityQueue()
    open_set.push((h(x0, E0, goal), 0.0, x0, E0, []))
    best = {}
    while open_set:
        f, g, x, E, plan = open_set.pop()
        key = (x, E)
        if key in best and best[key] <= g:
            continue
        best[key] = g
        if goal(x) and E >= R(x) + delta_ret:
            return plan
        for sigma in skills:
            if not precond(sigma, x):
                continue
            x2 = apply_skill(x, sigma)
            E2 = E - c_bar(sigma, x)
            if E2 < R(x2) + delta_ret:
                continue
            plan2 = plan + [sigma]
            g2 = g + c_bar(sigma, x)
            open_set.push((g2 + h(x2, E2, goal), g2, x2, E2, plan2))
    return None

## 4. 推导

**引理 9（能量不变式）** 假设初始 h(x_0,E_0)≥0；每步要么选择 a∈A_safe^E(x,E)（即 h(x',E')≥0），要么执行认证 π_ret；且 c̄ 是真实消耗的上界。则对所有 t≥0，h(x_t,E_t)≥0，直到到达 S_ret。归纳：t=0 成立；若 h_t≥0 且选择 A_safe^E 内动作，则 h_{t+1}≥0；若选择 π_ret，则由 R 的定义，π_ret 在到达 S_ret 前每步保持 h≥0。故机器人始终保留 δ_ret 的返航储备，且一定能到达 S_ret。∎

**引理 10（盾的最小干预）** 若 A_safe∩A_safe^E 为非空闭凸集，则欧氏投影 a_t=Π(a_RL) 存在唯一，且是所有安全动作中 ‖a−a_RL‖ 最小者。若 a_RL 本身安全，则 a_t=a_RL，干预为零。任务奖励 Lipschitz 为 L_r 时，
r(a_RL)−r(a_t)≤L_r·‖a_RL−a_t‖=L_r·dist(a_RL,A_safe)。
故盾的代价可由“RL 提议离安全集的距离”界定；当 RL 学会留在安全集内，干预率 ν→0。∎

**引理 11（能量-安全单调性）** 若 S(E) 满足单调性 E_1≤E_2 ⇒ S(E_1)⊆S(E_2)，且计划在 E_min=min_t E_t^lo 处认证安全，则计划在所有 t 处安全。证明：对任意 t，E_t^lo≥E_min ⇒ S(E_min)⊆S(E_t^lo)，故在 S(E_t^lo) 中的安全条件成立。∎
**注**：单调性是强假设；低温掉电、电压回弹、负载突变都可能破坏它，因此 E-AIC 必须对“非单调电池”做最坏参数枚举，或把单调性作为可证伪的运行假设（在线检验）。

**定理 9（ENDURE 端到端安全）** 在 A94–A99 下：
1. **能量安全**：引理 9 给出全程 h≥0，故机器人不会因任务动作耗尽返航储备；
2. **任务安全**：EAS 的交集包含 VISTA 的安全动作集，故第 64/65 轮的力/滑移/几何约束仍成立；
3. **性能不劣于基线**：离线 RL 仅在支持域且优势下界≥0 处提议，其余回退 π_ref；由悲观值标准结果，以高概率 V^{π_σ}≥V^{π_ref}−ε；
4. **低电优雅降级**：ERC 把 q 降到 q_min 而非 0，证书仍有效；若 q_min 也付不起，盾强制 π_ret/停机；
5. **共因故障**：E-AIC 不要求归因正确，只要求 h≥0 与安全停机/返航；`energy_common_cause` 显式标注；
6. **可审计**：J_endure 记录 E_lo、R、h_min、q_cert、λ_E、bits_per_joule、value_lb、energy_audit。
故 Valid(J_endure) ⇒ 几何/技能/干扰/接触/归因/资源六层安全链同时有效。∎

**定理 10（anytime 证书的单调降级）** 设 V_cert(q;x) 关于 q 单调递增且凹，c_comp(q) 关于 q 单调递增且凸。则
q*(λ)=argmax_q [V_cert(q;x)−λ c_comp(q)]
关于 λ 单调不增。证明：目标函数对 q 的交叉偏导 ∂²/∂q∂λ=−c'_comp(q)≤0，故最优 q 随 λ 上升而下降（Topkis 单调性）。若强制 q≥q_min，则 q*(λ)=max(q_min,q_uncon(λ))，仍单调不增。价值损失满足
V_cert(q_uncon)−V_cert(q_min)≤λ·(c_comp(q_min)−c_comp(q_uncon))+O((q_min−q_uncon)²)，
即“少思考”的损失被能量影子价格显式定价；而 q_min 由 J 的有效性定义，故安全不被降级。∎

**定理 11（比特/焦耳探针的近似最优性）** 互信息 I(ℋ;ρ(S)) 对观测集合 S 单调次模（信息增益的经典次模性）。能量预算 Σ_{a∈S}c(a)≤B 下的探针选择是背包约束的单调次模最大化。Sviridenko 的密度贪心 + 单元素枚举达到 (1−1/e) 近似；若所有探针等成本，退化为基数约束的 (1−1/e) 标准贪心。因此 EIG-AFA 在“每焦耳信息”意义下接近最优，且比纯互信息贪心更省电。∎

**定理 12（安全与性能的分离）** 盾的安全性只依赖 A_safe^E、c̄、π_ret 的正确性，不依赖 Q_r/Q_c；因此即使 RL 值函数完全错误，h≥0 仍成立。性能侧：在支持域 U_δ 与悲观值下，π_σ 的期望回报以高概率不低于 π_ref−ε；在支持域外，π_σ=π_ref。故“安全由盾保证、性能由 RL 改进”被解耦，RL 的最坏情况退化为“无改进”，而不是“不安全”。∎

**命题（续航感知优于奖励惩罚）** 设基线用 reward 惩罚 c_E 来“鼓励省电”。由于惩罚是软的，策略可能在高价值任务前透支储备；ENDURE 把 h≥0 作为硬约束，故在任意 reward 权重下都不会搁浅。形式化地，若存在动作序列使 E_t<R(x_t)+δ_ret，则惩罚基线可能选择它（当任务奖励足够大），而 ENDURE 的 EAS 必然拒绝或回退 π_ret。∎

| E248 | 低电共因下不强行归因，安全返航率 100% | 若误归因>20%，需移除“低电=视觉故障”的捷径 |
| E249 | 相对 VISTA：成功率 +15~25%，能耗 −20% | 若成功率下降，说明盾过度保守 |
| E250 | 未知电池动态下安全率 100%，恢复≤2s | 若恢复>5s，语义流预算不足 |

## 8. 已知风险

**一句话**：ENDURE 的全部硬保证都建立在“能量模型与认证返航策略可信”上；电池老化、低温掉电、电压回弹、路径被堵、充电站不可用都会让 R(x) 被低估，盾在错误的储备上放行，机器人会在“看起来还有余量”时被搁浅——这比第 65 轮的归因错误更底层，因为归因错误至少还有机会被 later 的证据纠正，而搁浅是不可逆的。

**次级风险与缓解**：
1. **电池模型误差**：SOC 估计、容量衰减、内阻、温度都会让 c̄ 与 E_lo 失准；缓解：区间估计 + conformal + E-AIC 最坏参数枚举 + 在线重标定；无法保证时降级为“保守 c̄ + 更早返航”。
2. **认证返航策略不存在**：路径被堵、充电站被占、地形变化会让 R(x)=∞；缓解：ETP 保留替代安全区；进入 `unrecoverable` 时只承诺最小风险停机；规划器把“充电站可用性”作为一等约束。
3. **RL 利用能量模型刷奖励**：低估能耗的 RL 会选“看起来省电”的动作；缓解：EVC 能量审计 + 悲观值 + 冻结回退；把能耗预测误差纳入 AIC-V 的对抗集。
4. **离线数据覆盖不足**：π_b 没去过的状态无法安全提议；缓解：支持域约束 + 回退 π_ref + 仿真/模型数据增广；把“数据覆盖”作为部署门槛。
5. **盾过度保守**：h 的保守估计会让机器人频繁返航/停机，任务吞吐下降；缓解：自适应 δ_ret、分层安全集、只在必要时用最坏 c̄；用 E241 测“任务成功率不降”。
6. **低电感知退化**：低电量下相机曝光/帧率/噪声变化会让 VCV/VPG 失效；缓解：E-AIC 显式建模低电感知退化，VCV 的 `visual_unobservable` 在低电时更易触发，退回 F/T 与保守动作。
7. **共因故障**：低电同时削弱感知、执行、计算与返航，归因会失效；缓解：不要求归因正确，只要求 h≥0 与安全停机/返航；`energy_common_cause` 显式标注。
8. **计算耗能占比小**：若 c_comp≪c_act，ERC 的收益有限；缓解：把 ERC 重点放在“低电时减少世界模型/认证开销以保返航”，而不是指望它显著省电；用实测功耗标定。
9. **多回合电池健康**：长期浅充浅放/深放策略影响寿命；缓解：把 b_k 纳入约束，限制 DOD 与循环次数；E250 测健康衰减。
10. **实时预算**：ECBF+EAS+证书切换逼近 2.6ms；缓解：能量积分与 LSF 共享编码、ECBF 用解析上界、EAS 用采样投影、把 RL/ERC/E-AIC 全部留在语义流。
