# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「任务分解」×「开源生态」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**可组合证书 + 可溯源供应链**。两个灵感分别治理 v10 的两种债：**组合债**（v10 只证块级/单任务证书，块证书如何沿长程任务组合成任务级保证从未被证明；且 τ_sem 是单一全局标定面，一处被穿透则全任务失守）、**来源债**（规范表/类原型/量化模型/地标图/标定参数都被当作"自研可信常量"，真实部署是从生态装配的第三方制品，来源、版本兼容、恶意贡献与"活体标定"皆无机制）。必须保持 v10 铁律：任一新模块失效 ⇒ 注入声明中立元，行为严格**等价**（TDC 失效 ⇒ 退化单任务 v10）或**支配**（SCP 失效 ⇒ 隔离/回滚到已知良版本，动作集只缩不扩）于 v10。

## 0. 直觉与动机

**灵感 1（任务分解 → 从块证书到可组合任务证书）**
直觉：v10 的证书单位是"块"，它证明了"这一块安全"，却从未证明"很多块与很多子任务拼起来仍安全"——组合正确性被默认了。更糟的是，v10 的 τ_sem 是一个**全局单一标定面**：只要一个对抗样本在 ν≤τ_sem 下穿透，整个任务都失去领先指标。任务分解给出的不是又一层模块，而是**结构**：把任务写成显式的分解 DAG，每个子任务带接口契约（入口集/出口集/不变量/子证书/残差），子任务边界天然是**独立于语义嵌入的校验点**（子目标谓词 γ_i、下一子任务入口前置条件、不变量）。核心创新：**任务分解证书（TaskDecompositionCertificate, TDC）**——组合定理把子证书拼成任务级证书，并显式记账**组合残差** ρ_comp；核心理论动作：把"全局标定面被穿透"改写为"穿透必须在某个子任务边界再次通过一次与嵌入无关的检查"，用纵深把单点失效变成多点独立检查（独立性是假设，必须实测，见 E593）。

**灵感 2（开源生态 → 从自研常量到可溯源供应链）**
直觉：v10 把 F̂_q、类原型 e_c、规范表 N、地标图 G_LM、甚至 τ_sem/β 都当作可信常量。真实系统是**装配**出来的：预训练模型、社区规范包、共享地图、他人标定包。生态带来**供应链债**：来源伪造、版本漂移、依赖不兼容、恶意/低质贡献；但也带来关键机会——标定面可以变成**活体制品**：社区持续红队、可复现评测、回归门禁。核心创新：**模块供应链（SupplyChainProvenance, SCP）**——每个制品成为带 semver、内容哈希、签名、SBOM 条目与兼容区间的**版本化包**；部署**锁文件**在启动期静态校验签名/哈希/依赖闭包/兼容；规范包须过 **CI 门禁**（静态 lint + 动态场景套件）否则隔离；**活体标定包**把 τ_sem/β 从常数变成带红队回归门的版本化制品，更新不得使留出对抗集的显著召回跌破预注册下限。原则 P17：来源不明或版本不兼容的制品不得进入控制路径（隔离 ⇒ Π_r）。

三者（含 v10 LS 的配额）咬合：TDC 出**任务级证书与组合残差**，SCP 出**制品来源与版本证据**，活体标定出**可审计的局部 τ_sem/β**——共同把 v10 的"单一经验标定面"改造成"分层的、版本化、签名、独立校验的局部标定面"，并把残余风险显式写进 ρ_comp 与供应链审计面。

## 1. 研究问题（轮次升级版）

- **Q1（可组合安全）**：如何把 v10 的块证书沿显式分解 DAG 组合为任务级证书，使组合残差 ρ_comp 可加有界，并使"局部 τ_sem 被穿透"必须在子任务边界被一个与嵌入独立的检查再次拦截（边界独立拦截率可测）？
- **Q2（可溯源生态）**：模型/规范/地图/标定如何成为带签名、版本兼容与回归门的供应链制品，使篡改/替换/版本偏斜在进入控制路径前被检出（≥1−2^-κ），未过 CI 的贡献被隔离，且标定更新不退化？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P17）

**P16 分解可组合律（Decomposition Composability, TDC）**
任务级证书只能由子任务证书经显式接口契约与有界组合残差组装，禁止"整体信任"跳过组合证明；分解边界必须是独立校验点（子目标谓词 + 入口前置 + 不变量），不得只是标签；组合残差必须显式计入证书余量。

**P17 来源可溯律（Provenance Traceability, SCP）**
凡进入控制路径的制品（模型/规范/地图/标定）必须携带有效来源记录（哈希+签名+版本+兼容区间）并出现在部署锁文件中；无来源/不兼容制品只能隔离（Π_r）或回滚到锁定的已知良版本；标定制品更新须过红队回归门。

## 3. 与基线的接口（如何退化）

- TDC 失效（分解不可用/规划失效/接口契约缺失/超规模）⇒ 任务折叠为单子任务、ρ_comp=0，严格等价 v10 单任务行为；
- SCP 失效（签名服务不可用/锁文件缺失）⇒ 仅允许使用锁定的已知良版本，且 Π_r（动作集只缩不扩），支配于 v10；
- 规范包未过 CI / 兼容冲突 ⇒ 隔离该包并回退 v10 内置规范表（行为等价 v10）；
- 标定包未过回归门 ⇒ 冻结在上一良版本（不更新），行为等价 v10；
- STF/NRB/LS/台账失效 ⇒ 沿 v10 既有退化链（Level-1..6）；
- 全部新模块失效 ⇒ 严格 v10。

## 4. 预期贡献

1. **可组合任务证书**：首次把 v10 块证书沿分解 DAG 组合并给出可加残差界，把"单一全局 τ_sem 穿透即全任务失守"改造成"边界独立拦截 + 局部标定"，降低单点失效概率（引理 92–93）；
2. **可溯源供应链**：签名+SBOM+锁文件+兼容区间使第三方制品可审计、可回滚、可隔离，并让标定面成为活体回归门禁制品（引理 94–95）；
3. **退化保证**：TDC 失效严格等价 v10，SCP 失效只缩不扩（引理 96）；
4. **E591–E608** 覆盖分解粒度、组合残差、边界独立性、来源篡改、版本偏斜、CI 门禁、活体标定、组合对抗与预算。

## 5. 本轮最大风险

**一句话**：纵深防御依赖"边界检查与语义嵌入独立"这一假设——若对抗者能同时骗过局部 ν≤τ_sem 与子目标谓词 γ_i（例如伪造"已到达"或让长尾新物体落在子任务出口集内），两层会一起失守，而分解带来的更多检查点反而制造虚假安全感；更危险的是开源生态本身成为新攻击面：一个通过 CI 门禁的恶意规范包或投毒标定包会被全机群共同信任，其传染性远超 v10 的本地标定失效。

**新增定义 549（任务分解 DAG）** T_D=(V_D,E_D) 满足无环、单根、叶为 v10 块级单元、|V_D|≤M_D=64（在线可证规模）。分解可由 HTN/LLM 规划器产生，但**规划器输出不可信**，须过边界一致性检查（定义 552）与证书重验。

**新增定义 550（子任务接口契约）** κ_i=(E_i,X_i,I_i,Ĉ_i,ρ_i)。子任务证书 valid ⇔ ∀块 Ĉ_t⁺ valid ∧ 出口可达（存在满足 γ_i 的执行）∧ I_i 沿执行保持 ∧ ρ_i 计入组合。

**新增定义 551（组合残差与任务证书）** 如符号表。任务证书 Ĉ_T valid ⇔ ∀i Ĉ_i valid ∧ ∀(i,j)∈E_D: X_i ⊆ E_j（接口包含）∧ I_root 保持 ∧ ρ_comp ≤ ρ_budget ∧ provenance(L) 全通过。

**新增定义 552（边界校验点）** 子任务 i 的边界校验 = (γ_i(x) 子目标谓词, x∈E_j 入口前置, I_i 保持)。三者在边界一帧内求值，**不读取语义嵌入 ν**（独立性来源）；任一失败 ⇒ 拒绝跨界、停在边界（收缩，不扩权）。边界校验是 P16 的独立第二道检查，与 STF 检 3 形成纵深。

**新增定义 553（模块清单与 SBOM）** μ=(name, semver, hash_256, sig, deps[], compat)。compat 为与其它制品的版本区间约束（模型↔规范↔地图↔标定），如 F̂_q 2.x 兼容 N 1.3–1.6、G_LM ≤3.x。

**新增定义 554（部署锁文件与来源校验）** L = 所有 μ 的精确版本+哈希+签名集合。启动期校验：签名有效 ∧ 哈希匹配 ∧ 依赖闭包完整 ∧ compat 全部满足；任一失败 ⇒ 隔离该制品并回滚到 L 中已知良版本，否则 Π_r。运行期 5Hz 增量校验 O(#deps)。

**新增定义 555（活体标定包）** P_cal=(τ_sem, τ_emb, β, corpus_hash, sig, semver)。更新须过回归门 G_reg：在留出对抗语料上显著召回 ≥ R_min=0.99、非显著误报 ≤ F_max=0.05，且 (recall, −fpr) 不劣于上一版；未过 ⇒ 冻结上一良版本。不同子任务类型可持有分片 P_cal[i]，得到局部 τ_sem^i、β_STF^i（收紧 v10 全局标定面）。

**新增定义 556（规范包门禁）** 社区规范包 N_pack 须过：静态 lint（谓词可判定、scope 合法、无副作用、规模 ≤12）+ 动态场景套件（E597）；未过 ⇒ 隔离，回退 v10 内置 N。

**新增定义 557（供应链契约与中立元）** κ_SCP=(D_check=0.3ms, v^⊥=隔离+回滚, 缺失⇒Π_r)。P17：未溯源制品不得进入控制路径；SCP 失效时动作集只缩不扩。

**新增定义 558（联合任务证书）** Ĉ_T⁺=(Ĉ_T, prov_vector, cal_version, n_t)。valid ⇔ Ĉ_T valid ∧ prov_vector 全 1 ∧ cal_version 与模型/规范 compat 一致 ∧ n_t 全通过。

## 3. 关键算法骨架

```python
# IP-361 TaskDecompositionCertificate：任务分解证书（组合定理的运行时实现）
class TaskDecompositionCertificate:
    def __init__(self, M_D=64, rho_budget=0.05, lam_c=1.0):
        self.M_D, self.rho_budget, self.lam_c = M_D, rho_budget, lam_c

    def build(self, task, planner, stf, scp):
        dag = planner.decompose(task)              # 规划器输出不可信
        if not self._acyclic(dag) or len(dag.nodes) > self.M_D:
            return None                            # ⇒ 折叠单任务（v10 等价）
        for i in dag.nodes:
            i.cert = self._certify_subtask(i, stf, scp)   # v10 块证书集合
            if i.cert is None:
                return None
            i.rho = self._subtask_residual(i)
        for (i, j) in dag.edges:
            if not self._interface_included(i, j):        # X_i ⊆ E_j
                return None
        rho = (sum(i.rho for i in dag.nodes)
               + sum(self._edge_residual(i, j, stf) for i, j in dag.edges))
        if rho > self.rho_budget:
            return None
        return TaskCert(dag, rho, prov=scp.lock_vector(), cal=self._cal_versions(dag))

    def _edge_residual(self, i, j, stf):
        gap = max(dist(x, j.E) for x in i.X)
        return gap + self.lam_c * (stf.beta_local(i) + stf.beta_local(j))


# IP-361 边界守卫：独立于语义嵌入的第二道检查（P16）
class BoundaryGuard:
    def check(self, x, i, j, invariants):
        return (i.gamma(x)                      # 子目标谓词
                and j.entry_ok(x)               # 下一子任务入口前置
                and all(inv.holds(x) for inv in invariants))   # 不变量保持
    # 任一失败 ⇒ 拒绝跨界、停在边界（收缩）；不读取 ν


# IP-362 SupplyChainProvenance：来源校验（签名+哈希+SBOM+兼容）
class SupplyChainProvenance:
    def __init__(self, lockfile, kappa=256):
        self.lock, self.kappa = lockfile, kappa

    def verify_boot(self):
        for mu in self.lock.modules:
            if not (mu.sig_ok() and mu.hash_ok()
                    and self._deps_closed(mu) and self._compat_ok(mu)):
                return ('quarantine', mu)      # 回滚已知良版本，否则 Π_r
        return ('ok', None)

    def verify_incremental(self, mu):          # 5Hz 增量，O(#deps)
        return (mu.sig_ok() and mu.hash_ok()
                and self._deps_closed(mu) and self._compat_ok(mu))

    def lock_vector(self):                     # prov_vector ∈ {0,1}^{|modules|}
        return [self.verify_incremental(mu) for mu in self.lock.modules]


# IP-363 LivingCalibration：活体标定包 + 红队回归门（非退化）
class LivingCalibration:
    def __init__(self, R_min=0.99, F_max=0.05):
        self.R_min, self.F_max = R_min, F_max

    def admit(self, new_pack, heldout_adv, prev):
        r = eval_recall(new_pack, heldout_adv)     # 显著召回
        f = eval_fpr(new_pack, heldout_adv)        # 非显著误报
        if r < self.R_min or f > self.F_max or (r, -f) < (prev.r, -prev.f):
            return prev                            # 冻结上一良版本（等价 v10）
        return new_pack
```

## 4. 推导

**引理 92（任务证书组合定理）** 设 (i) ∀i∈V_D 子任务证书 Ĉ_i valid（v10 定义 543）；(ii) ∀(i,j)∈E_D 接口包含 X_i ⊆ E_j；(iii) 根不变量 I_root 在每步保持；(iv) ρ_comp ≤ ρ_budget。则按 T_D 拓扑序执行的任务满足任务级安全证书 Ĉ_T valid，且任一时刻实际间隙 g(t) ≥ ĝ_min − ρ_comp（保守余量被组合残差吸收）。证明：沿拓扑序归纳。基础：首子任务由 (i)。归纳步：由 (ii) 出口落入下一入口，(iii) 不变量传递；间隙在边界的退化由 ρ_{i→j} 覆盖（dist 三角不等式），子任务内由 ρ_i 覆盖；ρ_comp 为各项之和，故总退化 ≤ ρ_comp；由 (iv) 仍在预算内。∎

**引理 93（分解降低单点穿透概率——边界独立性的正面使用与诚实边界）** 设 (A4) 显著事件由 STF 检 3 捕获的召回为 1−ε_s（v10 A2）；(A5) 边界检查与语义嵌入的条件独立近似：P(对抗样本通过边界 | 通过局部 ν≤τ_sem) ≤ δ_b，δ_b 经 E593 实测。则显著事件同时穿透两层且不被拦截的概率 ≤ ε_s·δ_b（v10 为 ε_s），即乘性下降；当 δ_b≪1 时单点标定面被拆成"多点独立检查"。进一步 (ii) 子任务域更小 ⇒ 由 v10 引理 88 局部性，β_STF^i 更紧、τ_sem^i 面更窄。**诚实边界**：独立性是假设而非定理；若对抗者可联合欺骗（相关攻击），(A5) 失效并退回 ε_s——此即本轮最大风险，须由 E603 攻击联合性量化。∎

**引理 94（来源完整性）** κ_h=256 位哈希 + 签名 + 锁文件 L ⇒ 对任一制品的替换/篡改/未列依赖以 ≥1−2^-256 概率在进入控制路径前被检出；依赖闭包 + compat 校验在启动期拒绝版本偏斜（定义 554）。运行期增量校验 O(#deps) 且不改变控制律（只读审计面），故不引入行为发散。∎

**引理 95（活体标定非退化）** 回归门 G_reg 保证被准入的 P_cal 满足显著召回 ≥R_min、非显著误报 ≤F_max，且在留出对抗语料上 (recall,−fpr) 不劣于上一版；因此标定更新不会使 v10 引理 87 的 (A2)/(A3) 在本语料上变差。**注记**：语料外泛化仍是假设，须由 E599/E603 的分布外对抗测试约束；此即"活体"仍需红队生态持续供给的原因。∎

**引理 96（退化等价/支配）** (i) TDC 失效 ⇒ build 返回 None ⇒ 折叠单任务、ρ_comp=0、无边界检查，逐位复用 v10 路径 ⇒ 行为严格等价 v10；(ii) SCP 失效 ⇒ 只允许锁定良版本 + Π_r（K_eff≤2、d_eth↑、禁触清单）⇒ 可执行动作集 ⊆ v10 ⇒ 支配；(iii) 规范包/标定包未过门禁 ⇒ 回退 v10 内置 N/P_cal ⇒ 与 v10 逐位一致；(iv) 全失效 ⇒ v10。∎

## 8. 本轮最大风险

**一句话**：纵深防御依赖"边界检查与语义嵌入独立"这一假设——若对抗者能同时骗过局部 ν≤τ_sem 与子目标谓词 γ_i（例如伪造"已到达"或让长尾新物体落在子任务出口集内），两层会一起失守，而分解带来的更多检查点反而制造虚假安全感；更危险的是开源生态本身成为新攻击面：一个通过 CI 门禁的恶意规范包或投毒标定包会被全机群共同信任，其传染性远超 v10 的本地标定失效。
