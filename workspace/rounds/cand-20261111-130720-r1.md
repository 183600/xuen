# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「数据集」×「视觉问答」）

> 第 54 轮把技能组合提升为动作空间剖面 + 云边协同 + 动作-鲁棒性联合证书。但所有这些证书都隐含一个未言明的前提：**它们是在某个数据分布上被校准和验证的**。本轮以「数据集」与「视觉问答」为透镜，把证书从“世界真值”降格为“数据条件真值”：引入数据集覆盖测度、证书支撑域、VQA 探针信道、主动数据获取，形成 **数据-探针-证书闭环**。核心矛盾：H22：证书的支撑域与数据集的实际覆盖之间存在支撑缺口，部署时的分布漂移会让证书“在训练集上为真、在部署中失效”；H23：VQA 看似是廉价可组合的语义探针，但 VLM 与策略共享感知先验时，探针错误与策略错误相关，导致“自我确认式”的假证书。

## 0. 直觉与动机

**灵感 1（数据集不是基准，是环境的采样测度）**
直觉：一个数据集 D 不是一堆样本，而是场景-动作空间 X×A 上的一个经验测度 μ_D。证书 C 只在它的支撑域 dom(C) 上有意义；若 dom(C) 中有一部分从未被 D 覆盖，那部分证书就是“悬空承诺”。于是我们要问的不是“证书对不对”，而是“**这张证书在 D 的支撑上有多少是可兑现的**”。这把数据集从评测工具变成证书的**定义域来源**。

**灵感 2（视觉问答 = 语言索引的因子探针）**
直觉：自然语言问题 q（“杯子在盘子的左边吗？”）本质上是在查询场景的一个低维因子 f_q(x)。VQA 模型回答 a=π(x,q) 是对 f_q 的一次含噪测量。把一类问题组织成 **探针电池 Q**，不同的 q 覆盖不同的失败维度（物体、空间、时序、属性）。这样，VQA 不是拿来做排行榜的，而是拿来做 **失败定位与证书抽检** 的：问那些答案已由任务状态确定的题，答错即定位。关键诚实之处：VLM 本身有混淆矩阵 ε_q，必须先在标定集上标定，不能把 VQA 当 ground truth。

**灵感 3（证书-数据适配度 → 数据条件 soundness）**
直觉：第 54 轮的 `P_success` 应该改写为 `P_success | D`。证书成立的概率受三项拖累：支撑缺口（dom(C) 未被 D 覆盖）+ 探针误差（VLM 误判）+ 漂移（部署分布超出 D 的 Wasserstein 半径）。这是把“绝对正确”换成“**在数据覆盖范围内可兑现**”，是更诚实也更可工程化的保证。

**灵感 4（主动数据获取 → 让数据集追着证书的不确定性长）**
直觉：证书在支撑缺口处最不确定。用贝叶斯实验设计，在“证书不确定性高 × 探针信息量大 × 采集成本低”的区域生成场景与问题，把新样本并入 D 并升版。数据集因此**活起来**，且每个证书都钉在一个数据集版本上，形成 **证书-数据共同演化**。

**灵感 5（数据血缘与污染 → 迁移证书的新前提）**
直觉：视觉问答数据集常与预训练语料重叠。若证书验证集与策略/VLM 预训练集同源，证书会因“见过”而虚高。因此联合证书必须携带 **数据血缘与污染标记**，污染率超阈值即拒绝迁移。这补齐了第 54 轮 JTC 缺失的数据侧前提。

**灵感 6（金字塔扩展）**
在第 54 轮的动作-鲁棒性金字塔上再叠 **数据-探针层 𝔻**：`𝔻_0` 原始场景流，`𝔻_1` 数据集测度 μ_D，`𝔻_2` VQA 探针电池 Q，`𝔻_3` 证书支撑域 dom(C)。跨层证书从 `(ρ,A_cert)` 升级为 `(ρ,A_cert,D_cert,Q_cert,lineage)`。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（数据集测度与覆盖谱）**
场景-动作空间 `X×A`，数据集 `D = {(x_i,a_i,y_i)}_{i=1}^N` 诱导经验测度 `μ_D`。给定因子分解 `X = X_1×...×X_k`，覆盖谱 `c_D = (c_D^1,...,c_D^k)`，其中 `c_D^j` 为 `D` 在第 j 个因子维上的有效覆盖（分箱占据率或核密度质量）。整体覆盖 `cov_D(Ω) = μ_D(Ω)`。

**定义 122（证书支撑域与支撑缺口）**
证书 `C` 的支撑域 `dom(C) ⊆ X×A` 为其有效范围。数据-证书适配度
```
fit_D(C) = μ_D(dom(C) ∩ supp(D)) / μ_D(dom(C))
```
支撑缺口 `gap_D(C) = 1 - fit_D(C)`。部署分布 `P_deploy` 与 `μ_D` 的漂移 `δ_W = W_1(P_deploy, μ_D)`。

**定义 123（VQA 探针信道）**
问题族 `Q = {q_1,...,q_m}`，每个 `q` 对应因子映射 `f_q : X → Y_q`。探针 `π` 给出 `a = π(x,q)`。在独立标定集上测得错误率 `ε_q = P(π(x,q) ≠ f_q(x))`。认证探针集 `Q_cert = {(q, ε_q, w_q)}`，`w_q` 为问题对失败维度的判别权重。仅当 `ε_q ≤ ε_max` 时 `q` 才可入证。

**定义 124（VQA 失败定位）**
给定失败样本 `x_fail` 与探针电池 `Q_cert`，定位器输出失败维度分布 `ℓ = Localize(x_fail, Q_cert)`，`ℓ ∈ Δ(𝔇_fail)`。定位置信度 `conf(ℓ) = 1 - H(ℓ)/log|𝔇_fail|`（归一化熵）。高 `conf` 才允许把 `ℓ` 作为 Explain 的根因输入，低 `conf` 则回落人工锚点。

**定义 125（主动数据获取目标）**
采集函数 `α(x,q) = I(C; y_{x,q} | D) - λ·cost(x,q)`，其中 `I` 为证书参数与新增观测间的互信息。每轮选取 `(x*,q*) = argmax α`，并入 `D ← D ∪ {(x*,q*,y*)}` 并升版 `D_{t+1}`。

**定义 126（数据-探针-动作联合证书）**
`J' = (J, D_cert, Q_cert, lineage)`：
- `J` 为第 54 轮联合证书 `(ρ,A_cert,γ_ce,δ_a)`；
- `D_cert = (μ_D, c_D, fit_D, gap_D, δ_W)`；
- `Q_cert = {(q,ε_q,w_q)}`；
- `lineage` 记录数据来源与污染率 `κ_contam`。
部署条件：`fit_D(C) ≥ 1-ε_fit ∧ δ_W ≤ δ_max ∧ max_q ε_q ≤ ε_max ∧ κ_contam ≤ κ_max`。

## 2. 关键算法 伪代码

### IP-121 DCM（Dataset Coverage Measure）

```python
def coverage_spectrum(D, factors, bins):
    mu = empirical_measure(D)
    c = {}
    for j, f in enumerate(factors):
        hist = bin_counts([f(x) for x in D], bins[j])
        c[j] = occupied_mass(hist) / mass(hist)   # 非均匀性校正后的有效覆盖
    return mu, c

def fit_dataset_certificate(C, mu, support):
    dom = C.domain
    covered = mu(dom & support)
    total = mu(dom)
    return covered / total if total > 0 else 0.0
```

### IP-122 CSC（Certificate-Support Compatibility）

```python
def certificate_support_check(C, D, eps_fit, delta_max):
    mu, c = coverage_spectrum(D, C.factors, C.bins)
    fit = fit_dataset_certificate(C, mu, support_of(D))
    delta_w = wasserstein1(deploy_dist_estimate(C), mu)
    if fit < 1 - eps_fit:
        return ('reject', 'support_gap', 1 - fit)
    if delta_w > delta_max:
        return ('reject', 'distribution_shift', delta_w)
    return ('ok', DCert(mu, c, fit, delta_w))
```

### IP-123 VQP（VQA Probe）

```python
def calibrate_probes(Q, calib_set):
    cert = []
    for q in Q:
        errs = [pi(x, q) != f_q(x) for x in calib_set]
        eps = mean(errs)
        if eps <= eps_max:
            cert.append((q, eps, discriminative_weight(q)))
    return ProbeBattery(cert)

def probe_localize(x_fail, battery):
    scores = {dim: 0.0 for dim in FAILURE_DIMS}
    for q, eps, w in battery.items:
        ans = pi(x_fail, q)
        for dim, expected in q.dimension_answers.items():
            if ans != expected:
                scores[dim] += w * (1 - eps)
    l = softmax_normalize(scores)
    return l, normalized_confidence(l)
```

### IP-124 ADE（Active Dataset Elicitation）

```python
def active_acquire(D, C, budget):
    while budget > 0:
        candidates = propose_scenes_and_questions(C.uncertain_region)
        best = max(candidates, key=lambda xq: mutual_info(C, xq) - lam * cost(xq))
        y = oracle_or_human(best)          # 独立于策略与探针
        D = D.merge(best, y)               # 版本 +1，lineage 追加
        C = update_certificate(C, D)
        budget -= cost(best)
    return D, C
```

### IP-125 VDQ（VQA Data Quarantine）

```python
def contamination_gate(D, pretrain_corpus, kappa_max):
    overlap = estimate_overlap(D, pretrain_corpus)   # 近重复 / 哈希 / 嵌入
    if overlap > kappa_max:
        return ('reject', 'contamination', overlap)
    return ('ok', Lineage(D, overlap))
```

### IP-126 JDC（Joint Data-Probe Certificate）

```python
def joint_data_certificate(J, D, Q, lineage, budgets):
    dcheck = certificate_support_check(J, D, budgets.eps_fit, budgets.delta_max)
    if dcheck[0] != 'ok':
        return dcheck
    battery = calibrate_probes(Q, D.calib)
    if max(eps for _, eps, _ in battery.items) > budgets.eps_max:
        return ('reject', 'probe_uncalibrated')
    gcheck = contamination_gate(D, budgets.pretrain_corpus, budgets.kappa_max)
    if gcheck[0] != 'ok':
        return gcheck
    return ('ok', JointDataCert(J, dcheck[1], battery, gcheck[1]))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DCM | O(N·k + Πbins) | O(Πbins) | 分箱/核密度估计偏差有界 |
| CSC | O(N·|dom|) | O(|dom|) | 支撑域可判定、W1 估计收敛 |
| VQP | O(|Q|·N_calib) | O(|Q|) | 标定集独立、ε_q 上界可信 |
| ADE | O(T·|X|·|Q|) | O(N+T) | 互信息估计无偏、oracle 无污染 |
| VDQ | O(N·log N) | O(N) | 近重复检测召回 ≥ 95% |
| JDC | O(DCM+CSC+VQP+VDQ) | 同左 | 四项门控全部闭合 |

**正确性定理（Data-Conditional Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `μ_D` 的覆盖估计与真实测度的 TV 误差 ≤ η；**(A30)** 探针在独立标定集上错误率上界 `ε_q` 可证；**(A31)** 部署漂移 `δ_W` 可在线估计。
则对证书所记载的部署条件：
```
P_fail | D ≤ gap_D(C) + Σ_q w_q·ε_q + P(δ_W > δ_max) + κ_contam + β_E + η
```
直观：**证书只兑现到数据的支撑边界；探针只兑现到它的标定误差；漂移超过半径则整张证书作废**。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 覆盖谱估计 | 覆盖估计 vs 留出真值 TV 误差 | ≤ 0.05 |
| E163 VQA 探针定位 | 与人工根因标注的 Top-1 一致率 | ≥ 80% |
| E164 数据条件证书有效性 | 不同 `fit_D` 分箱下部署成功率 | 单调且可预测（R² ≥ 0.9） |
| E165 主动获取效率 | 达到同证书强度所需样本数 vs 随机采样 | 减少 ≥ 40% |
| E166 污染检测 | 注入 10% 近重复后的检出率 | ≥ 95%，误报 ≤ 3% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| VLM 与策略感知同源，探针错误与策略错误相关 | 高 | 异构探针（多模型/多模态）+ 因果去相关 + 人审抽样 |
| 高维覆盖谱估计偏差 | 高 | 因子化分箱 + 核密度 + 留出校准 |
| 主动获取过拟合探针而非世界（Goodhart） | 高 | 独立审计集 + 采集预算上限 + 分布约束 |
| 数据污染检测漏检 | 中 | 向量近重复 + 语义哈希 + 血缘审计 |
| 证书因数据升版频繁失效 | 中 | 证书版本锁定 + 增量重验证 |

## 6. 本轮最大风险

**一句话**：把证书降格为“数据条件证书”虽然更诚实，但最致命的不是覆盖不足，而是 **VQA 探针与策略共享感知先验导致的错误相关**——探针会在策略出错的地方一起出错，从而给出“自我确认”的假安全证书；因此必须以异构探针、独立人审锚点和污染门控打破相关性，否则整条数据-探针-证书闭环只是在同一个错误流形上自我循环。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（DCM×CSC×VQP×ADE×VDQ×JDC）

> 承接第 54 轮产物 v31。本轮把证书体系从“世界真值”降格为“数据条件真值”，新增 **数据集覆盖测度、证书支撑域、VQA 探针、主动数据获取、污染门控** 五大算子，形成数据-探针-证书闭环：
> - **DCM（Dataset Coverage Measure）**：数据集作为场景-动作空间上的经验测度 `μ_D` 与覆盖谱 `c_D`；
> - **CSC（Certificate-Support Compatibility）**：证书支撑域与数据的适配度 `fit_D`、支撑缺口 `gap_D` 与漂移 `δ_W`；
> - **VQP（VQA Probe）**：把视觉问答组织为经标定的因子探针电池 `Q_cert`；
> - **ADE（Active Dataset Elicitation）**：以互信息驱动的主动采集让数据集追着证书不确定性长；
> - **VDQ（VQA Data Quarantine）**：数据血缘与污染率门控 `κ_contam`；
> - **JDC（Joint Data-Probe Certificate）**：`J'=(J,D_cert,Q_cert,lineage)` 数据-探针-动作联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-118（AEC）与 IP-120（JTC）以纳入数据侧前提。

| DCM | O(N·k + Πbins) | O(Πbins) | 覆盖估计 TV 误差 ≤ η |
| CSC | O(N·|dom|) | O(|dom|) | 支撑域可判定、W1 收敛 |
| VQP | O(|Q|·N_calib) | O(|Q|) | 标定集独立、ε_q 上界可信 |
| ADE | O(T·|X|·|Q|) | O(N+T) | 互信息无偏、oracle 独立 |
| VDQ | O(N·log N) | O(N) | 近重复召回 ≥ 95% |
| JDC | O(DCM+CSC+VQP+VDQ) | 同左 | 四项门控闭合 |

**正确性定理（Data-Conditional Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 覆盖估计与真实测度 TV 误差 ≤ η；**(A30)** 探针在独立标定集上错误率上界 `ε_q` 可证；**(A31)** 部署漂移 `δ_W` 可在线估计。
则：
```
P_fail | D ≤ gap_D(C) + Σ_q w_q·ε_q + P(δ_W > δ_max) + κ_contam + β_E + η
```
关键：**证书只兑现到数据支撑边界，探针只兑现到标定误差，漂移超半径即整张证书作废**。

## 5. 本轮最大风险

**一句话**：把证书降格为“数据条件证书”虽然更诚实，但最致命的不是覆盖不足，而是 **VQA 探针与策略共享感知先验导致的错误相关**——探针会在策略出错的地方一起出错，从而给出“自我确认”的假安全证书；因此必须以异构探针、独立人审锚点和污染门控打破相关性，否则整条数据-探针-证书闭环只是在同一个错误流形上自我循环。
