# 第 72 轮（承接第 71 轮「GAUGE-RAS 计量审计层」IP-275~286；灵感循环第 2 轮；本轮灵感：「技能学习」×「惯性测量单元」）

> R71 把每一个在线指标升级为「带构造效度、不确定度预算、有效性域、追溯链与反指标」的测量结果，并把安全做成不可补偿的否决项。但它有一个隐含的时间假设：**一次审计通过，就一直有效。** 指标是快照，证书是静态的；Goodhart 间隙 D>τ_D 只在「当下」检查，H[b_t] 只在「当下」估计，学习技能只在「当下」被假定在能力域内。现实里最危险的失效不是「某一刻读数错了」，而是**每一刻都只错一点点、且方向一致，于是任何单点阈值都抓不住，直到积少成多越过安全边界**——这正是惯性测量单元（IMU）教给导航的第一课：一个 0.01°/s 的陀螺零偏单看微不足道，积分一小时就是 36° 的姿态误差；而加速度计零偏带来的是**二次**增长的位置误差。IMU 因此从不承诺「永远准」，它承诺的是**「在锚点之间、在有限时域内漂移有界」**。这恰好补上 R71 缺的那一维：**有效性不是一个二值状态，而是一条会过期的租约。**
>
> 技能学习补上另一半：R71 把「技能」当成已经认证、永远可用的控制器，只审它的指标、不审它的**能力包络会不会随时间/环境/负载漂移**。但学习得到的策略只在训练分布附近有效；小幅的每步误差会在技能链上**复合放大**（compounding error）；离线评测的成功率是滞后指标，可能被「利用一个已经漂移的感知」骗过去；而在线学习又与 R71 不变式 (i)「实时流零学习写操作」直接冲突。技能学习研究的教训是：**能力不是属性，而是「在哪个包络里、还能维持多久」的关系；技能库不是静态资产，而是需要持续校准和锚定的负债。**
>
> 于是本轮把 R71 的「静态审计」升级为**「带漂移预算与认证时域的动态审计」**：
> - **惯性测量单元**：为状态、标定、指标本身建立**漂移台账**（噪声/零偏/坐标系/模型四类漂移分离），把 R71 的「有效/无效」二值判断变成 **Δ(t) ≤ ε 的认证时域 T_cert**；引入**锚点**作为绝对参考，并证明「自锚定」不能减小真实误差、只会减小*估计到的*误差——这正是「自信地错」的数学形式。
> - **技能学习**：为每个学习技能附上**能力包络 Ω_k**、每步残差界 ε_k、复合漂移预算，引入**技能里程计**与**慢漂移检测**，以及**离线固化协议**（在线只选择、不写入；候选技能经密封审计 + 回归守卫后原子替换）。学习被允许，但必须发生在控制回路之外、且不能缩小已认证的安全集。
>
> 核心命题：**不再只问「我的读数现在准不准、这把尺子可不可信」，而问「它还能准多久、漂到哪儿、我用什么独立参考把它拉回来，以及我学会的新技能有没有悄悄把安全边界改小」。** 命名 **STRIDE-RAS**（Skill-Trajectory, Residual-drift, Inertial-frame, Drift-budgeted, Envelope-certified RAS：技能轨迹 × 惯性漂移 × 能力包络 × 锚定闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证」，R70 问「该信哪个状态」，R71 问「我的尺子可不可信、我是否改变了被测量的人」，R72 问「**这把尺子还能信多久；我自己的运动和技能是不是正在把误差悄悄积分起来；我学会的本领，有没有把我不知道的安全边界越改越小**」——可信不是一个状态，而是一段**有限、被锚点重置、且必须偿还漂移债务**的时程。

## 0. 直觉与动机

**灵感 1（IMU → 「准」不是标量，而是「漂移率 × 未锚定时长」）**
直觉：同一只 IMU，静止标定时精度可以很高，但一旦开始积分，误差就沿未观测方向单调增长。决定可用性的不是单帧噪声 σ，而是**零偏沿不可观测方向的投影 β 与距上次绝对参考的时间 τ**。工程上常说「IMU 不能单独用」，真正的原因不是它「差」，而是**它与真值之间缺少一个绝对参考的自由度**：航向、位置、以及部分零偏组合，在纯惯性下根本不可观测。于是 R71 的「有效性域 D」必须再加一维：**时间**。一个指标在 t=0 有效，不代表在 t=3600s 仍有效；证书应写成「在 [t, t+T_cert] 内、漂移预算内有效」。

**灵感 2（技能学习 → 误差沿技能链复合，成功率是滞后指标）**
直觉：一个每步误差 1% 的技能，在单集里几乎完美，但串联 100 步后误差可能放大到不可接受；如果闭环动力学把偏差放大（Lipschitz L>1），误差按 L^m 增长。更麻烦的是：**离线成功率会骗人**——策略可能学会利用某个已经漂移的感知通道来「刷」成功，而真实状态早已偏离。因此技能的证书不能只写「成功率 95%」，必须写「**在包络 Ω_k 内、链长 ≤ m*、每步残差 ≤ ε_k 时，端到端误差有界**」。技能库需要一本**里程计**：累计每个技能自上次认证以来的执行量、残差与域移证据，像 IMU 的漂移台账一样滚动记账。

**灵感 3（慢漂移 → 单点阈值会被「温水煮青蛙」击穿）**
直觉：R71 的 Goodhart 间隙 D>τ_D、ECE>τ_ece 都是**瞬时高通滤波**：只要每步把偏差压在阈值下，就能无限累积而不触发。IMU 的零偏正是这个攻击的物理原型——每帧都「合格」，一小时后彻底偏航。指标系统里对应的是**慢速 reward hacking / 渐进式分布漂移 / 标定缓慢失效**。要抓住它，必须把「瞬时值」换成**累计统计量**（CUSUM / 漂移预算 / 认证时域），并周期性用独立锚点重置。**没有任何纯瞬时指标能界定长时程误差**——这是本轮要证明的负面结论。

**灵感 4（自锚定 → 最危险的参考系是你自己的估计）**
直觉：IMU 的「零速修正（ZUPT）」之所以有效，是因为「脚着地时速度为零」是一个**独立于积分结果**的物理事实；而如果系统用「我预测自己没动」去当锚点，那就是循环论证。R71 的 SEAL 已经在防「自己批改自己」，R72 要把这条原则推广到所有参考：**锚点必须与它要纠正的漂移源在误差上不相关**。自锚定（self-anchoring / 用自己的估计做回环闭合）不会减小真实误差，却会让滤波器**误以为**误差减小了——「自信地错」的精确机制。

**灵感 5（学习隔离 → 允许学习，但只允许「加固」，不允许「悄悄改边界」）**
直觉：完全禁止学习会让系统永远停在出厂能力；完全在线学习则破坏 R71 的安全不变式。折中不是「调小学习率」，而是**分频与原子性**：在线只有「选择已认证技能」的自由；学习发生在离线/睡眠期，候选技能必须通过密封审计、包络估计与**回归守卫**（在旧包络上不劣化、且不缩小已认证安全集），然后原子替换并写入谱系哈希。技能可以变强，但**安全集只能单调不减**。锚点则是跨时间的「再认证触发器」：不是学得越久越可信，而是越久越需要重新证明。

## 1. 形式化定义（增量：定义 349–364）

**定义 349（STRIDE-RAS 总览）** STRIDE-RAS = (IMU-P, DRIFT, ANCHOR, ENV, SCOM, SODO, STRIDE-GATE, A-VOI, CONSOL, AIC-STRIDE, J_STRIDE, GAUGE-RAS†)。六不变式：
(i) **实时流零学习写操作**（继承 R71 定义 331-i）：在线只做估计、选择与门控，权重/策略/标定参数的写入一律在离线固化协议中原子完成；
(ii) **漂移有界**：凡参与决策的状态、标定与能力估计，必须携带漂移台账 Δ_t 与认证时域 T_cert(ε)；超出时域即降级；
(iii) **能力包络约束**：学习技能只在已认证包络 Ω_k 内执行；包络外一律回退安全控制器；
(iv) **锚点独立性**：用于纠正漂移的锚点，其误差必须与待纠正估计的误差不相关；**自锚定与循环闭合一律判为无效锚点**；
(v) **学习单调性**：任何被接纳的技能更新不得缩小已认证安全集、不得提高密封分布上的风险；
(vi) **非补偿性安全**（继承 R71 定义 331-iii）：否决项不可被性能补偿。

**定义 350（惯性测量模型）** 惯性单元输出角速度 ω_m 与比力 a_m：
ω_m(t) = ω(t) + b_g(t) + n_g(t)，a_m(t) = R(t)^T(a(t) − g) + b_a(t) + n_a(t)，
其中零偏服从随机游走 ḃ_g = n_{bg}、ḃ_a = n_{ba}；n_g、n_a 为白噪声，R 为姿态旋转。**关键不是噪声，而是零偏与不可观测方向**：纯惯性下 (状态, 零偏) 存在不可观测子空间 𝒩（典型含绝对航向、绝对位置及若干零偏组合），任何因果滤波器都只能把误差在 𝒩 内重新分配，不能消除其沿 𝒩 的分量。

**定义 351（航位推算与漂移状态）** 令 Π 为把惯性增量映射为相对位姿的积分算子；真实误差 Δ_t = x̂_t − x_t 分解为
Δ_t = Δ_noise + Δ_bias + Δ_frame + Δ_model，
分别对应随机噪声积分、零偏积分、外参/坐标系失配、模型失配。基线增长率：姿态误差 ∼ ‖b_g‖·t；速度误差 ∼ ‖b_a‖·t；位置误差 ∼ ½‖b_a‖·t²（加速度零偏在位置上是二次增长）。定义**漂移时钟** τ_d(t) = t − t_last_anchor，以及漂移范数 D_t = ‖Δ_t‖。

**定义 352（漂移预算与认证时域）** 漂移预算
D(t) ≤ D_0 + ρ_n·√t + ρ_b·t + ρ_f·t + ρ_m·t（位置型零偏项取 t² 形式），其中 ρ_* 由标定件与模型给出（继承 R71 定义 332 的不确定度预算）。对安全阈值 ε，**认证时域**
T_cert(ε) = sup{ T ≥ 0 : D(T) ≤ ε }。
证书不再写「有效」，而写「**在 [t, t+T_cert] 内有效**」。**这是对 R71「静态有效性」的时间化：有效性是一条会过期的租约，不是一枚永久的印章。**

**定义 353（锚点）** 锚点 a = (z_a, Σ_a, s_a, ι_a, t_a)：观测 z_a、误差协方差 Σ_a、来源 s_a（外部绝对参考/接触事件/已知地图/人确认/已知安全复位）、独立性指标 ι_a ∈ [0,1]（与待纠正估计误差的相关系数上界）、时间戳。合法锚点须满足：
(a) ι_a ≥ ι_min；
(b) s_a 不在被纠正估计的因果后代集合内（禁止自锚定与循环闭合）；
(c) 在有效期内（否则按定义 352 降级）。
**锚点是 R71 交互的推广**：问人、看地标、触觉接触、进入已知区域，都是把累积漂移拉回绝对参考的「绝对修正」；因此 R71 的可信度 c(ψ) 与信任预算，直接成为「人锚点」的代价与可靠性。

**定义 354（技能与能力包络）** 学习技能 σ_k = (pre_k, π_k, β_k, Ω_k, ε_k, H_k, ℓ_k)：前置条件、策略、终止条件、**能力包络** Ω_k ⊆ 𝒮×𝒜×𝒯、包络内每步跟踪残差界 ε_k、认证时域 H_k、谱系 ℓ_k（数据/模型哈希/种子）。包络用**保形预测 / 分位数回归**在密封数据上估计：Ω_k = {x : q_{1−α}(r | x) ≤ ε_k}，给出有限样本覆盖保证，而不是「训练集上看着行」。**包络外执行 = 未认证技能，禁止。**

**定义 355（惯性残差与包络越界检测）** 执行技能时，比较惯性预测与实测：
r_t = ‖o_imu(t) − ĝ_σ(x̂_t, a_t)‖_{Σ^{-1}}。
残差既可能来自技能失效，也可能来自传感器故障、外参漂移或环境变化。用多通道一致性（视觉/触觉/历史行为 + R71 定义 343）区分归因。**包络越界不是「残差大就停」，而是「残差偏离包络内标定分布到统计显著」**：以包络内数据的经验分布为零假设，用 CUSUM 检测均值/方差漂移。

**定义 356（技能链与复合漂移）** 技能链 σ_{k1}→…→σ_{km}。设第 i 段后的误差满足 e_i ≤ L·e_{i−1} + ε_{k_i}（L 为闭环 Lipschitz 放大因子），则
e_m ≤ L^m e_0 + Σ_{i=1}^m L^{m−i} ε_{k_i}。
定义**最大认证链长** m*(ε_max) = max{ m : 上式右端 ≤ ε_max }。当 L>1 且 ε 均匀时 e_m ≤ ε(L^m−1)/(L−1)，故 m* 随 ε 对数增长、随 L 急剧收缩。**锚点/复位把 e→0，从而把一条长链切成长度 ≤ m* 的若干段**——这就是「技能航位推算」与「技能锚定」的对应关系。

**定义 357（能力后验与慢漂移）** 维护能力后验 q_t(κ_k)（技能在 Ω_k 内达标的概率），随 τ_d（距上次认证）与域移证据衰减、在锚点处重置。定义**慢漂移 Goodhart 间隙**：
D_slow(t) = |Σ_{s≤t} (m_s − m⊥_s)| / t，
与 R71 的瞬时间隙 D(t) 并列。**慢漂移攻击**指每步偏差 < τ_D、但方向一致，使 D(t) 永不过阈而 D_slow 线性增长（灵感 3）。对 D_slow 设累计阈值 τ_slow，并配 CUSUM 统计量。

**定义 358（锚定式技能选择）** 每个决策选择技能 σ 最大化任务进度，s.t.
Ω_k 含当前状态、链长余量 > 0、漂移预算余量 > 0、锚点可用性满足、R71 的 veto 全过。若可行集为空：**不学习、不硬闯**，改为执行安全控制器 + 触发锚点寻求（定义 359）。**在线学到的东西不能改变这个可行集，只能由离线固化（定义 360）扩大它。**

**定义 359（锚点价值与调度 A-VOI）** 锚点不是免费的：外部锚点有感知/通信成本，人锚点有 R71 的 c(ψ) 与信任预算成本，内部复位有任务中断成本。定义
VoI^A(a) = E[ΔD_removed(a)] − c_anchor(a) − λ_e·E[anchor_error(a)]，
其中最后一项惩罚不可靠锚点（尤其自锚定）。选 a* = argmax VoI^A > 0；无正收益则仅靠漂移预算硬上限兜底。对线性漂移率 β、锚点成本 c_a、单位漂移暴露风险 λ，最优间距 T* = √(2c_a/(λβ))；对二次位置漂移 T* = (3c_a/(2λβ))^{1/3}。**漂移越快，锚点要越密，且密度对漂移率的敏感度是非线性的。**

**定义 360（学习固化协议 CONSOL）** 仅在离线/低负载期执行：
(1) 候选技能 π_k' 由离线数据训练；
(2) 在密封集上估计包络 Ω_k' 与残差界 ε_k'（保形/分位数，含覆盖率报告）；
(3) **回归守卫**：在旧包络 Ω_k 上，新技能不得劣化（性能与安全指标非劣）；不得缩小已认证安全集；不得提高密封分布风险；
(4) 通过后写入谱系 ℓ_k'，**原子替换**；失败则丢弃并记录。
**在线回路永远看不到梯度，只看到「已认证/未认证」与包络版本号。** 这把「学习」从控制系统里的一个连续扰动，变成离散、可审计、可回滚的版本升级。

**定义 361（STRIDE 门）** 若任一成立：D_t > τ_D、T_cert 过期、包络越界（CUSUM 告警）、锚点独立性失效、非独立锚点被使用、能力后验低于阈值、固化未审计——则 STRIDE-GATE 冻结对应技能/指标，回退 R71/R70 安全模式，并触发锚点寻求或离线再认证。**语义：不是「把漂移调小」，而是「租约到期就停止使用」。**

**定义 362（威胁模型 AIC-STRIDE）** ℰ_STRIDE = ℰ_GAUGE × ℰ_inertial × ℰ_skill：
ℰ_inertial = {IMU 欺骗/振动注入、零偏注入、磁干扰、外参缓慢漂移、锚点欺骗、回环绑架（kidnapped robot）、不可观测方向偏置}；
ℰ_skill = {技能投毒/后门、包络过度声明、分布移出、灾难性遗忘、慢速退化、能力指标 gaming、危险技能复合}。

**定义 363（证书 J_STRIDE）** J_STRIDE = (J_GAUGE, drift_trajectory, T_cert, anchor_log, envelope_certs, competence_posterior, residual_statistic, frame_calib_hash, skill_lineage, consolidation_audit, stride_ver)。
Valid ⇔ Valid(J_GAUGE) ∧ 漂移在时域内不超预算 ∧ 锚点独立且间距合规 ∧ 技能在包络内且链长 ≤ m* ∧ 固化审计通过。

**定义 364（退化与包含）** 当 IMU 理想（零偏=0、噪声=0）、锚点连续可用、Ω_k = 𝒮、ε_k = 0、能力=1、无固化更新时，STRIDE-RAS 逐指令等于 GAUGE-RAS；再按 R71 定义 348 退化为 BELIEF→FLUID→R68。**安全侧只增不减，效率侧只在「漂移有界且锚点独立」时获得收益。**

## 3. 推导

**引理 28（不可观测偏置的漂移下界与有限认证时域）** 设零偏在不可观测子空间 𝒩 上的投影为 β>0。纯惯性下，任何因果估计器都无法从输出中区分「零偏」与「真实运动」的 𝒩 分量；故误差沿 𝒩 至少以 β·t 增长（姿态/速度型）或以 ½β·t² 增长（位置型）。于是 D(t) ≥ β t，T_cert(ε) ≤ ε/β（位置型 ≤ √(2ε/β)）。系：**IMU 不存在「永久有效的证书」；R71 的静态有效性判断必须被替换为 T_cert 与周期锚定。** 锚点不是提高精度的手段，而是**让有限时域重新开始的唯一方式**。

**引理 29（技能链复合误差界与最大认证链长）** 在 e_i ≤ L e_{i−1} + ε_{k_i} 下，归纳得 e_m ≤ L^m e_0 + Σ_{i=1}^m L^{m−i} ε_{k_i}。若 ε 均匀，则 e_m ≤ L^m e_0 + ε(L^m−1)/(L−1)。令其 ≤ ε_max 得 m* = ⌊log_L(1 + (ε_max − ε)(L−1)/ε)⌋（L>1）。系：**单集成功率不构成链路安全证明**；当 L>1 时，再小的 ε 也会被指数放大。**技能必须被锚点/复位切段，每段长度 ≤ m*；「技能库越大越强」是错觉，链越长越需要重新绝对定位。**

**引理 30（慢漂移对瞬时阈值的不可检测性）** 设攻击每步使指标偏移 δ，且 δ<τ（瞬时阈值），方向一致。则任意只检查瞬时值的门控在所有 n 步都通过，而累计偏差 nδ → ∞。因此**任何形如「m_t ≤ τ」的瞬时证书都不能给出长时程误差界**。反之，对残差序列用 CUSUM S_t = max(0, S_{t−1} + (r_t − k))，当漂移均值 μ>k 时，告警延迟期望 ≈ h/(μ−k)，有限。系：**R71 的 D>τ_D 是一个高通滤波器；慢速 Goodhart / 渐进标定失效会从其通带漏过。STRIDE 的累计统计量与漂移预算不是「更严的阈值」，而是「不同频率的检测器」。**

**引理 31（自锚定的无效性与虚假置信）** 设真值为 x，估计误差 e=x̂−x。若「锚点」满足 z = x̂ + η（即锚点由估计自身派生，η 与 e 相关），则 E[z−x | x̂] = E[e]，更新后真实误差的期望不减小。更糟：若滤波器错误地假设 η 与 e 独立，它会用 z 的「信息」缩小自身协方差，制造**估计误差下降而真实误差不变**的假象；极端情形 z=x̂ 时更新量恒为 0，而内部不确定性却可被压到任意小。系：**自锚定 / 循环闭合是把「自信地错」制度化的最短路径；定义 353 的独立性条件不是工程洁癖，而是锚点能起作用的充要条件（在二阶意义下）。**

**引理 32（锚点调度的最优间距）** 设线性漂移率 β、锚点成本 c_a、单位漂移暴露风险 λ，则平均代价 J(T)=c_a/T + λβT/2，最小化得 T*=√(2c_a/(λβ))；若为二次位置漂移，J(T)=c_a/T + λβT²/3，T*=(3c_a/(2λβ))^{1/3}。系：**锚点频率不是拍脑袋的固定周期，而是漂移率、锚点成本与风险的单调解；漂移率翻倍时二次情形只需增加约 26% 频率，但线性情形需增加 41%——不同漂移类型的调度律不同。** 该 T* 与 R71 引理 25 的停止点同构：都是「边际收益 = 边际成本」的有限停止。

**定理 23（严格包含链）** 在 A106–A109（漂移模型对真实零偏上界成立、锚点独立且 T_cert 内、包络保形覆盖率成立、固化回归守卫生效）下：STRIDE 在理想退化条件（定义 364）逐指令等于 GAUGE；而 GAUGE ⊂ BELIEF 链的反向包含由 R71 定理 20 给出。故安全侧永不弱于 R71，效率侧只在「漂移有界且锚点独立」时获得收益。

**定理 24（漂移有界 ⇒ 长时程风险界）** 若一次执行满足：D_t ≤ ε_d 且 T_cert 未过期、所用锚点 ι≥ι_min 且间距 ≤ T*、技能在 Ω_k 内且链长 ≤ m*，则由引理 28–29，端到端状态/能力误差 ≤ ε；否则 STRIDE-GATE 强制回退 R71/R70，风险由 R71 定理 21 保证。故 STRIDE 的长时程期望风险 ≤ R71。**证明的全部重量落在「漂移模型上界正确」与「锚点真正独立」上**——这正是 DRIFT/ANCHOR/ENV 存在的理由，也是本轮最大风险。

**定理 25（学习隔离下的安全单调性）** 在定义 349(v) 与定义 360 下，在线回路无参数写入；候选技能只有通过密封审计与回归守卫（旧包络非劣、安全集不缩小、密封风险不升高）才被原子接纳。因此每次固化后，已认证安全集单调不减、密封分布上风险单调不增（在密封分布代表性成立时）。**这把「学习」从潜在的连续安全扰动，变成离散、可回滚、可审计的版本升级；但若密封分布本身漂移，单调性只相对于一个过期的分布成立——由定义 352 的时域与 ENV 的域移检测兜底。**

**定理 26（瞬时指标的长时程不完备性）** 对任意每步阈值 τ>0，存在方向一致的漂移攻击 δ∈(0,τ)，使所有瞬时指标恒过而累计误差无界（引理 30）。因此**任何仅由瞬时指标构成的证书，都不能给出与部署时长无关的误差界**；要获得长时程保证，证书必须包含累计统计量（漂移预算/CUSUM）与独立锚点，或显式限制认证时域 T_cert。**这是对 R71 的负面结论，也是 STRIDE 存在的必要性证明：不是 R71 做得不够严，而是它的证书缺少时间维度。**

## 6. 本轮最大风险

**一句话**：STRIDE-RAS 把「我现在准不准」升级为「我还能准多久」，但**漂移模型本身也会漂**——如果零偏上界被低估、锚点被同一个隐藏混杂因子污染（两把尺子一起歪），或者包络在离线密封集上乐观而在部署中系统性失效，那么系统会用一份「有界、可审计、带认证时域」的漂移预算，**把「我不知道自己漂了多少」包装成「我的漂移已经被证明有界」——漂移仪表本身在漂，锚点还接着自己，证书上盖着到期日，却没人检查到期日是不是也被伪造了。**

**次级风险与缓解**：
1. **漂移模型失配（真上界被低估）** → 用保守上界（分布无关的 Lipschitz/物理界）+ 在线残差监测触发 IVG 回退 + E343 专测覆盖率；宁可比真实更保守。
2. **自锚定 / 回环绑架** → 定义 353 的因果后代禁止 + 独立性检验 + 多源交叉锚定 + E345/E346；无法证明独立即按「无效锚点」处理。
3. **包络乐观 / 密封集泄漏** → 保形覆盖 + 密封审计 + 域移检测 + E347/E354；包络外一律回退，不做「大模型应该没问题」的推断。
4. **固化引入回归/遗忘** → 回归守卫 + 安全集单调性 + 原子回滚 + E353/E355；任何「性能更好但安全集变小」的更新一律拒绝。
5. **学习重新进入在线回路** → 结构上把 CONSOL 放在离线/睡眠期，在线只读版本号；E360 消融验证在线零写操作；代码层可审计（无梯度路径）。
6. **慢漂移检测被对抗性规避** → 累计统计量 + 随机化锚点时刻 + 多统计量（均值/方差/谱）+ E351；检测器参数不在线可观测，防止被优化。
7. **实时预算被惯性/审计层击穿** → 分频：IMU 高频但极轻、技能门控中频、固化离线；E359 守时，审计不进控制快路径。

## 2. 形式化定义（要点版）

**定义 349（总览与六不变式）** STRIDE 继承 GAUGE 全部组件（† 升级），新增惯性漂移层（IMU-P/DRIFT/ANCHOR）与技能层（ENV/SCOM/SODO/CONSOL）。六不变式：(i) 实时零学习写操作；(ii) 漂移有界且带 T_cert；(iii) 技能只在包络内；(iv) 锚点必须独立，自锚定无效；(v) 学习只经离线原子固化且安全集单调不减；(vi) 非补偿性安全。

**定义 350（惯性测量模型）** `ω_m=ω+b_g+n_g`，`a_m=R^T(a−g)+b_a+n_a`，`ḃ_g=n_bg, ḃ_a=n_ba`。纯惯性下 `(状态,零偏)` 存在不可观测子空间 𝒩：因果滤波器只能重分配误差，不能消除其 𝒩 分量。

**定义 351（漂移状态）** `Δ_t=Δ_noise+Δ_bias+Δ_frame+Δ_model`；姿态 ∼`‖b_g‖t`、速度 ∼`‖b_a‖t`、位置 ∼`½‖b_a‖t²`。`τ_d=t−t_last_anchor`，`D_t=‖Δ_t‖`。

**定义 352（漂移预算与认证时域）** `D(t)≤D_0+ρ_n√t+(ρ_b+ρ_f+ρ_m)t`（位置型零偏项取 `t²`）。`T_cert(ε)=sup{T:D(T)≤ε}`。证书写「在 [t,t+T_cert] 内有效」，不写「永久有效」。**有效性是可过期的租约。**

**定义 353（锚点）** `a=(z_a,Σ_a,s_a,ι_a,t_a)`，要求 `ι_a≥ι_min`、来源 `s_a` 不在被纠正估计的因果后代中（禁自锚定/回环）、在有效期内。**锚点是 R71 交互的推广：问人/看地标/接触/已知安全复位都是绝对修正；人锚点继承 c(ψ) 与信任预算。**

**定义 354（技能与保形包络）** `σ_k=(pre_k,π_k,β_k,Ω_k,ε_k,H_k,ℓ_k)`；`Ω_k={x:q_{1−α}(r|x)≤ε_k}` 由密封数据上的保形/分位数估计，给有限样本覆盖。**包络外执行 = 未认证技能，禁止。**

**定义 355（惯性残差与越界检测）** `r_t=‖o_imu−ĝ_σ‖_{Σ^{-1}}`；用多通道一致性（视觉/触觉/历史 + R71 定义 343）区分技能失效、传感器故障、外参漂移、环境变化。越界判据是「相对包络内标定分布统计显著」，用 CUSUM 检测，而非单点阈值。

**定义 356（技能链与复合漂移）** `e_i≤L e_{i−1}+ε_{k_i}` ⇒ `e_m≤L^m e_0+ΣL^{m−i}ε_{k_i}`；`m*=max{m:右端≤ε_max}`。均匀 ε、L>1 时 `e_m≤ε(L^m−1)/(L−1)`。**锚点/复位把 e→0，把长链切成若干 ≤m* 的段。**

**定义 357（能力后验与慢漂移）** `q_t(κ_k)` 随 τ_d 与域移证据衰减、在锚点重置；`D_slow(t)=|Σ(m_s−m⊥_s)|/t`。慢漂移攻击：每步偏差 <τ_D 但方向一致，使 D(t) 永不过阈而 D_slow 线性增长。对 D_slow 设累计阈值与 CUSUM。

**定义 358（锚定式技能选择）** 选 σ 最大化任务进度，s.t. 状态∈Ω_k、链长余量>0、漂移预算余量>0、锚点可用、R71 veto 全过；不可行则执行安全控制器 + 触发锚点寻求。**在线学习不能改变可行集，只能由离线固化扩大它。**

**定义 359（锚点价值 A-VOI）** `VoI^A=E[ΔD_removed]−c_anchor−λ_eE[anchor_error]`；选正收益最大者。线性漂移 `T*=√(2c_a/(λβ))`，二次位置漂移 `T*=(3c_a/(2λβ))^{1/3}`。**漂移越快锚点越密，且密度对漂移率非线性敏感。**

**定义 360（离线固化 CONSOL）** 候选技能 → 密封集保形包络 → 密封审计 → 回归守卫（旧包络非劣、安全集不缩小、密封风险不升）→ 谱系写入与原子替换；失败丢弃并记录。**在线只看到版本号与「已认证/未认证」，看不到梯度。**

**定义 361（STRIDE 门）** `D_t>τ_D`、T_cert 过期、包络越界、锚点独立性失效、非独立锚点被用、能力后验过低、固化未审计——任一成立即冻结对应技能/指标，回退 R71/R70，触发锚点寻求或离线再认证。

**定义 362（AIC-STRIDE）** `ℰ_STRIDE=ℰ_GAUGE×ℰ_inertial×ℰ_skill`；`ℰ_inertial`={IMU 欺骗/振动注入、零偏注入、磁干扰、外参缓慢漂移、锚点欺骗、回环绑架、不可观测方向偏置}；`ℰ_skill`={技能投毒/后门、包络过度声明、分布移出、灾难性遗忘、慢速退化、能力指标 gaming、危险技能复合}。

**定义 363（J_STRIDE）** 见符号表；Valid ⇔ Valid(J_GAUGE) ∧ 漂移在时域内不超预算 ∧ 锚点独立且间距合规 ∧ 技能在包络内且链长 ≤m* ∧ 固化审计通过。

**定义 364（退化与包含）** IMU 理想、锚点连续、`Ω_k=𝒮`、`ε_k=0`、能力=1、无固化 ⇒ 逐指令等于 GAUGE；再按 R71 定义 348 退化 BELIEF→FLUID→R68。安全侧只增不减。

## 3. 关键算法伪代码

```python
# IP-287 IMU-P：惯性流（200–1000Hz，零偏随机游走；在线不学）
class InertialPipeline:
    def step(self, frame, dt):
        w = frame.gyro - self.b_g; a = frame.acc - self.b_a
        self.b_g += self.n_bg * sqrt(dt)
        self.b_a += self.n_ba * sqrt(dt)
        return integrate(w, a, dt)                  # Π: 增量 -> 相对位姿

# IP-288 DRIFT：漂移台账（四类分离 + 有限认证时域）
def drift_bound(model, T):
    return (model.noise*sqrt(T) + model.gyro_bias*T
            + 0.5*model.acc_bias*T**2           # 位置：二次项
            + model.frame_drift*T + model.model_mismatch*T)

def cert_horizon(model, eps):
    return invert(lambda T: drift_bound(model, T), eps)   # 有限，不承诺永久

# IP-289 ANCHOR：锚点注册与独立性检验（禁止自锚定）
def anchor_valid(a, est):
    return (a.t > est.last_anchor_t and a.independence >= IOTA_MIN
            and a.source not in est.causal_descendants and within_validity(a))

# IP-290 ENV：保形能力包络（有限样本覆盖）
def fit_envelope(residuals_by_x, alpha):
    return lambda x: quantile(residuals_by_x(x), 1 - alpha)

def in_envelope(sigma, x):
    return sigma.omega.contains(x) and sigma.q_res(x) <= sigma.eps

# IP-291 SCOM：技能链复合漂移预算
def chain_bound(eps_list, L, e0):
    e, out = e0, []
    for eps in eps_list:
        e = L*e + eps; out.append(e)
    return out

def max_chain(L, eps, eps_max):
    return floor(log(1 + (eps_max - eps)*(L - 1)/eps, L)) if L > 1 else INF

# IP-292 SODO：技能里程计 + 慢漂移 CUSUM
class SkillOdometer:
    def update(self, r, k, h):
        self.S = max(0.0, self.S + (r - k))         # 双侧可另开负向统计量
        return self.S > h                           # 累计告警，而非单点阈值

# IP-293 STRIDE-GATE：租约/包络/锚点/漂移 联合门
def stride_gate(m, state, a, sigma):
    bad = []
    if m.drift(state) > TAU_DRIFT:      bad.append('drift')
    if not m.cert.valid_at(now()):      bad.append('lease_expired')
    if not in_envelope(sigma, state):   bad.append('envelope')
    if not anchor_valid(a, m.est):      bad.append('anchor')
    if m.odo.alarm():                   bad.append('slow_drift')
    return Gate(valid=not bad, reason=bad, fallback='R71')

# IP-294 A-VOI：锚点价值与调度
def anchor_voi(candidates, est, drift_model):
    best = None
    for a in candidates:
        if not anchor_valid(a, est): continue
        score = (expected_drift_reduction(est, a, drift_model)
                 - a.cost - LAM_E*expected_anchor_error(a))
        if best is None or score > best.score: best = (a, score)
    return best if best and best.score > 0 else None

# IP-295 CONSOL：离线固化（密封审计 + 回归守卫 + 原子替换）
def consolidate(old, cand, sealed):
    env = fit_envelope(cand.residuals, sealed.alpha)
    if not sealed.pass_(cand):                  return old, 'seal_fail'
    if not noninferior(cand, old, env.omega):   return old, 'regression'
    if shrinks_safe_set(env, old):              return old, 'safe_set_shrink'
    return atomic_swap(old, cand, lineage(cand)), 'ok'

# IP-297 STRIDE 主闭环：控制/技能/审计/固化 分频
def STRIDE_round(M, obs, imu, audio):
    x = M.imu.step(imu, M.dt)                                # 高频 200–1000Hz
    b = M.bse.step(M.b_prev, obs, x, M.last_action)          # R70/R71 估计
    if M.clock.due_skill():                                  # 中频 50–100Hz
        g = M.stride_gate.check(M, x, M.last_anchor, M.sigma)
        if not g.valid: M.mode = 'R71'
        k = M.select_skill(b, M.sigma, M.drift) if g.valid else None
    if M.clock.due_anchor():                                 # 低频/事件触发
        a = M.avoi.choose(M.anchor_candidates(), M.est, M.drift_model)
        if a:
            M.est = M.est.update_with_anchor(a)
            M.odo.reset(); M.anchor_log.add(a)
    if M.clock.due_consolidation():                          # 离线/睡眠期
        M.skills, status = M.consol.step(M.skills, M.pending, M.seal)
    A = M.ach.propose(b, k); kk = M.c_ras_wm.certified_prefix(A, ...)
    M.drift.update(x, A[:kk]); M.odo.update_from_exec(A[:kk])
    return kk, (M.drift, M.cert_horizon()), J_STRIDE(M)
```

## 4. 推导

**引理 28（不可观测偏置的漂移下界与有限认证时域）** 零偏在不可观测子空间 𝒩 上的投影 β>0 时，纯惯性下任何因果估计器都无法区分「零偏」与「真实运动的 𝒩 分量」，故误差沿 𝒩 至少以 βt（姿态/速度）或 ½βt²（位置）增长；D(t)≥βt，`T_cert(ε)≤ε/β`（位置型 ≤√(2ε/β)）。系：**IMU 没有永久证书；R71 的静态有效性必须换成有限 T_cert + 周期锚定。锚点是让有限时域重新开始的唯一方式。**

**引理 29（技能链复合误差与最大认证链长）** `e_i≤L e_{i−1}+ε_i` ⇒ `e_m≤L^m e_0+ΣL^{m−i}ε_i`。均匀 ε 时 `e_m≤L^m e_0+ε(L^m−1)/(L−1)`，令其 ≤ε_max 得 `m*=⌊log_L(1+(ε_max−ε)(L−1)/ε)⌋`（L>1）。系：**单集成功率不证明链路安全；L>1 时任何小 ε 都会被指数放大；技能必须被锚点/复位切段，链越长越需要绝对定位。**

**引理 30（慢漂移对瞬时阈值的不可检测性）** 若每步偏移 δ<τ 且方向一致，则任意「瞬时值 ≤τ」的门控在 n 步全通过，而累计偏差 nδ→∞。故**任何瞬时指标证书都不能给出长时程误差界**。CUSUM `S_t=max(0,S_{t−1}+r_t−k)` 在漂移均值 μ>k 时期望延迟 ≈h/(μ−k)，有限。系：**R71 的 D>τ_D 是高通滤波器，慢速 Goodhart / 渐进标定失效从通带漏过；STRIDE 的累计统计量不是「更严的阈值」，而是「不同频率的检测器」。**

**引理 31（自锚定的无效性与虚假置信）** 若锚点由估计自身派生 `z=x̂+η`，则 `E[z−x|x̂]=E[e]`，更新不减小真实误差的期望。若滤波器错误假设 η 与 e 独立，它会用 z 的「信息」缩小自身协方差，制造**误差下降而真实误差不变**的假象；极端 `z=x̂` 时更新恒为 0，内部不确定性却可被压到任意小。系：**自锚定/循环闭合是把「自信地错」制度化的最短路径；定义 353 的独立性是锚点起作用的（二阶）必要条件。**

**引理 32（锚点调度的最优间距）** 线性漂移：`J(T)=c_a/T+λβT/2` ⇒ `T*=√(2c_a/(λβ))`；二次位置漂移：`J(T)=c_a/T+λβT²/3` ⇒ `T*=(3c_a/(2λβ))^{1/3}`。系：**锚点频率是漂移率、锚点成本与风险的单调解，不是固定周期；不同漂移类型的调度律不同。与 R71 引理 25 的停止点同构：边际收益 = 边际成本。**

**定理 23（严格包含链）** 在 A106–A109（漂移上界成立、锚点独立且在 T_cert 内、包络保形覆盖成立、固化回归守卫生效）下：STRIDE 在定义 364 的退化条件逐指令等于 GAUGE；GAUGE ⊂ BELIEF 链由 R71 定理 20 给出。故安全侧不弱于 R71，效率侧只在「漂移有界且锚点独立」时获得收益。

**定理 24（漂移有界 ⇒ 长时程风险界）** 若 `D_t≤ε_d` 且 T_cert 未过期、锚点 `ι≥ι_min` 且间距 ≤T*、技能在 Ω_k 内且链长 ≤m*，则由引理 28–29 端到端误差 ≤ε；否则 STRIDE-GATE 回退 R71/R70，风险由 R71 定理 21 保证。故长时程期望风险 ≤R71。**证明重量落在「漂移模型上界正确」与「锚点真正独立」上。**

**定理 25（学习隔离下的安全单调性）** 在线无参数写入；候选技能只有通过密封审计与回归守卫（旧包络非劣、安全集不缩小、密封风险不升）才原子接纳。因此每次固化后已认证安全集单调不减、密封分布风险单调不增（当密封分布有代表性）。**学习从连续安全扰动变为离散、可回滚、可审计的版本升级；若密封分布本身漂移，单调性只相对于过期分布成立，由 T_cert 与 ENV 域移检测兜底。**

**定理 26（瞬时指标的长时程不完备性）** 对任意 τ>0，存在 δ∈(0,τ) 的方向一致漂移，使所有瞬时指标恒过而累计误差无界（引理 30）。故**任何仅由瞬时指标构成的证书都不能给出与部署时长无关的误差界**；长时程保证必须包含累计统计量（漂移预算/CUSUM）与独立锚点，或显式限制认证时域 T_cert。**这是对 R71 的负面结论，也是 STRIDE 的必要性证明：不是 R71 不够严，而是它的证书缺少时间维度。**

## 7. 本轮最大风险

**一句话**：STRIDE-RAS 把「我现在准不准」升级为「我还能准多久」，但**漂移模型本身也会漂**——若零偏上界被低估、锚点被同一隐藏混杂因子污染（两把尺子一起歪），或包络在离线密封集上乐观而部署中系统性失效，系统就会用一份「有界、可审计、带认证时域」的漂移预算，**把「我不知道自己漂了多少」包装成「我的漂移已被证明有界」——漂移仪表自己在漂，锚点还接着自己，证书盖着到期日，却没人检查到期日是否也被伪造。**

**次级风险与缓解**：
1. **漂移模型失配** → 分布无关的保守物理/Lipschitz 上界 + 在线残差监测 + E343 覆盖率专测；宁可比真实更保守。
2. **自锚定 / 回环绑架** → 因果后代禁止 + 独立性检验 + 多源交叉锚定 + E345/E346；无法证明独立即判无效锚点。
3. **包络乐观 / 密封集泄漏** → 保形覆盖 + 密封审计 + 域移检测 + E347/E354；包络外一律回退，不做「大模型应该没问题」的推断。
4. **固化引入回归/遗忘** → 回归守卫 + 安全集单调性 + 原子回滚 + E353/E355；「性能更好但安全集变小」一律拒绝。
5. **学习重新进入在线回路** → CONSOL 结构性放在离线/睡眠期，在线只读版本号；E360 消融验证零写操作；代码层无梯度路径可审计。
6. **慢漂移检测被对抗规避** → 累计统计量 + 随机化锚点时刻 + 多统计量（均值/方差/谱）+ E351；检测器参数在线不可观测。
7. **实时预算被击穿** → 四频分离：IMU 高频极轻、技能门控中频、固化离线；E359 守时，审计不进控制快路径。
