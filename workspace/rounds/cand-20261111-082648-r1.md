# 第 55 轮（承接第 54 轮 v16++ Action-Aware Cloud-Edge；灵感循环第 6 轮；本轮灵感：「对话管理」×「通用操作」）

> 第 54 轮把技能组合提升为「动作空间剖面 + 云边协同 + 动作-鲁棒性双证书」。但整条链仍默认**任务指令完整、无歧义、一次给定**：动作空间再精确，也只能执行一个已被正确理解的任务。本轮用「对话管理」重写「通用操作」的入口，把语言指令看作**多轮、可澄清、可修复的信念过程**，让"理解"本身成为一件可验证、带证书的事。核心矛盾：H24：通用操作面对开放世界指令天然欠定，静默采用最可能解释会在动作空间中产生系统性错误执行；H25：失败后的重规划只改动作、不改理解，导致"反复犯同一个理解错误"。

## 0. 思考轨迹与直觉

**思考轨迹（可见）**
我先问：前 54 轮缺的到底是哪一块？把链条摊开——感知/几何（L1/L2）、技能组合（SCOM）、动作空间（ACS）、云边协同（CEC）、鲁棒性（ρ）、证据（EIG/SRC）、动作-鲁棒联合证书（J）。这条链非常"硬"，却有一个隐藏前提：**输入的任务已经被正确且唯一地理解**。一旦任务来自自然语言、且面向开放世界（"把那边那个收拾一下"），这个前提立刻崩塌。于是问题不是"怎么执行得更好"，而是"**在执行之前，如何把'要执行什么'也变成一件可验证的事**"。
再问：「对话管理」能提供什么别人没拿来做机器人的东西？对话管理最成熟的资产恰恰是**欠定处理**：信念状态、指代接地、澄清提问、混合主动、修复。它不是"加一个语音界面"，而是给"理解"配上一套**不确定性代数**。
最后问：「通用操作」意味着什么？不是"更多技能"，而是**任务模式的开放组合**：新任务往往能分解成已知操作模式的实例，只是槽位未填、指代未定、约束未明。于是本轮主线浮现：**对话管理 = 通用操作的"理解层证书"**，每次澄清都是对证书不确定性的定向削减，每次失败修复都必须同时修订"理解"与"动作"。下面五条灵感按"状态→接地→提问→模式→修复"展开。

**灵感 1（对话管理 → 理解是带熵的信念状态，而非一次性解析）**
直觉：把"用户想要什么"表示成联合信念 `B_t=(b_g,b_r,b_p,b_c,b_e)`（目标/指代/参数/约束/执行），每轮话语或观察都是贝叶斯更新。这样"理解得够不够"可量化为熵 `H(B_t)`，执行前必须满足 `H(B_t) ≤ H_max`，否则不许把"最可能解释"当成事实。对话管理由此从"交互外壳"变成**执行的前置条件**。

**灵感 2（通用操作 → 指令诱导程序集合，欠定=集合的证书分歧）**
直觉：一条指令 `u` 不应解析成单个程序，而应解析成候选程序集合 `Π(u)`。欠定不是 bug 而是常态；真正危险的是 `Π(u)` 内部**证书结论不一致**（一个成员可部署、另一个越界）。因此"歧义"要重新定义为**证书相关欠定**：只有当不同解释会导致不同部署结论时，才值得澄清；否则取默认即可。这把"要不要问"从经验直觉变成可判定问题。

**灵感 3（澄清是价值决策 → 只问"能改变证书结论"的问题）**
直觉：不要"有歧义就问"，也不要"从不问"。定义澄清价值 `VoC(q)` = 该问题预期降低的证书风险 − 交互成本 − 时延。只有当 `VoC` 超过阈值且不存在安全默认时才提问。这把对话管理从"礼貌交互"变成**信息经济学的证书优化**，天然接上第 54 轮的 `insufficient` 与证据预算：问问题也是一种"取证据"。

**灵感 4（通用操作模式 → 槽位化 schema + 指代接地证书）**
直觉：通用操作的最小可复用单元不是轨迹，而是**带类型槽位的操作模式** `O=(name,slots,pre,post,afford,decomp,cert_template)`。"抓取→放置→清理"都是模式实例。新任务 = 在模式库中找可实例化的装配：槽位由对话填、指代由场景图接地、证书由模板生成。每个接地都给证书 `G=(x,E,A_ref,conf,ev)`，接地不达标就不许执行——理解层第一次有了 sound 门槛。

**灵感 5（失败即"理解修复"，不只是动作修复）**
直觉：第 54 轮的 Explain 回传只驱动动作空间重剖分；但如果根因其实是"我把'那个'指错了"，再剖分动作空间也没用。混合主动修复 `R=(report,question,options,commit)` 让边端用自然语言报告失败并请求消歧，云端据此同时修订 `B_t` 与计划，并用"无重复提问 + 熵单调下降"保证收敛。最终把"说了什么—理解成什么—做了什么"绑成一张**对话-操作联合证书** `D`，补上 say-do 一致性这一长期缺口。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（对话-操作联合信念状态）**
`B_t=(b_g,b_r,b_p,b_c,b_e)`，分别定义在目标空间 `Θ_g`、指代空间 `Θ_r`、参数空间 `Θ_p`、约束空间 `Θ_c`、执行状态 `Θ_e` 上。因子化联合熵 `H(B_t)=Σ_i H(b_i)`，`H(b_i)=-Σ_θ b_i(θ)log b_i(θ)`。更新算子 `B_{t+1}=update(B_t,o_t)`，`o_t` 为一句用户话语或一次执行观察，按贝叶斯规则对相应因子边缘化更新。

**定义 122（指代接地证书）**
对指代片段 `x`，接地结果为 `G=(x,E,A_ref,conf,ev)`：`E⊆ℰ` 为场景实体集，`A_ref⊆A` 为该指代在当前上下文允许触发的动作引用集，`conf∈[0,1]` 为校准置信度，`ev` 为证据（场景图节点、共指链、视觉检测框）。接地有效当且仅当 `conf≥θ_g` 且 `E` 与 `A_ref` 在场景图中可达、无实体冲突。

**定义 123（证书相关欠定）**
指令 `u` 诱导候选任务程序集 `Π(u)={π_1,…,π_n}`（满足语用与场景约束的程序）。若 `∃π_i,π_j∈Π(u)` 使 `deploy(D(π_i))≠deploy(D(π_j))`，称 `u` 存在**证书相关欠定**，程度 `U_c(u)=H(deploy(D(π))|u)`（部署结论的熵）。否则称**证书无关欠定**，可安全取默认。注意：`U_c=0` 不代表无歧义，只代表歧义不影响可部署性。

**定义 124（澄清价值）**
对候选问题 `q`（答案空间 `Ans(q)`）：
```
VoC(q)      = E_{a~p(a|q)}[H(B_t)-H(B_t|a)] - λ_c·c(q) - λ_d·τ(q)
VoC_risk(q) = E_{a~p(a|q)}[R(B_t)-R(B_t|a)]
```
`R(B)` 为当前信念下"已选程序违反联合证书"的风险。澄清策略：
```
ask(q*) iff VoC_risk(q*)>τ_ask ∧ ¬∃π_safe
```
其中 `π_safe` 是在所有候选解释下均满足 `dom(D)=in` 的鲁棒程序；只要存在 `π_safe` 就**取安全默认而不打扰用户**。

**定义 125（通用操作模式）**
`O=(name,slots,pre,post,afford,decomp,cert_template)`：`slots` 为带类型槽位；`pre/post` 为槽位实例化后的前后条件；`afford:slots→Pred` 把槽位约束到可供性谓词；`decomp` 递归分解为子模式；`cert_template` 规定该模式需携带的证书字段。任务 `T` 可被通用操作执行，当且仅当存在实例化 `O[σ]` 使 `pre[σ]∧post[σ]` 可满足、所有槽位接地有效、且 `cert_template` 可被现有证据填充。

**定义 126（混合主动修复协议）**
失败事件 `f` 触发修复 `R=(report,question,options,commit)`，满足：(i) `report` 由 `Explain` 回传根因生成；(ii) `question` 满足 `VoC_risk>τ_ask`；(iii) `options` 有限且每个都能在当前动作空间内验证；(iv) `turns(R)≤T_repair`；(v) **无循环**：同一 `(B_t,q)` 不得重复提问，且 `H(B_{t+1})≤H(B_t)`。

**定义 127（对话-操作联合证书）**
`D=(B,G,Π*,ρ,A_cert,Explain,turns)`，`Π*` 为最终承诺执行、且在 `B` 下模证书等价唯一确定的程序。部署条件：
```
dom(D)=in ∧ valid(G) ∧ H(B)≤H_max ∧ turns≤T_max
∧ say_do_consistent(Π*,executed)=true
```
其中 `say_do_consistent` 要求实际执行程序落在"被澄清后理解"的证书等价类内，且其 `ρ`、`A_cert` 与承诺一致（防止"说一套、做一套"的证书漂移）。

## 2. 关键算法 伪代码

### IP-121 DMB（Dialogue-Managed Belief）

```python
def update_belief(B, obs, nlu, scene_graph):
    o = nlu.parse(obs)                      # intent / refs / params / constraints
    B.g = bayes(B.g, o.intent_prior)
    B.r = ground_update(B.r, o.refs, scene_graph)
    B.p = bayes(B.p, o.param_likelihood)
    B.c = bayes(B.c, o.constraint_likelihood)
    if o.exec_observation is not None:
        B.e = bayes(B.e, o.exec_observation)
    return normalize(B)
```

### IP-122 GRC（Grounding Certificate）

```python
def ground_reference(span, scene_graph, context, theta_g=0.9, alpha=0.05):
    cands = scene_graph.entities_by_mention(span)
    cands = filter_by_context(cands, context)       # 共指链 / 时近性 / 可见性
    E, conf, ev = conformal_select(cands, coverage=1-alpha)
    A_ref = reachable_actions(E, scene_graph)
    G = Grounding(span, E, A_ref, conf, ev)
    if conf < theta_g or has_entity_conflict(E) or not all_reachable(A_ref):
        return None                                  # 接地失败 → 触发澄清
    return G
```

### IP-123 CLQ（Clarification Value）

```python
def select_clarification(B, Pi, question_lib, tau_ask):
    safe = find_safe_default(Pi, B)                  # 所有解释下都可部署的程序
    if safe is not None:
        return ('default', safe)
    scored = [(q, VoC_risk(q, B, Pi)) for q in question_lib]
    q_best, v_best = max(scored, key=lambda t: t[1])
    if v_best <= tau_ask:
        return ('defer', 'insufficient')             # 问也不改变结论 → 不猜
    return ('ask', q_best)
```

### IP-124 GOS（General Operation Schema）

```python
def instantiate_schema(task, schemas, B, scene_graph):
    for O in rank_schemas(task, schemas):
        sigma = fill_slots(O, B)
        if not all_slots_grounded(sigma):
            continue
        if not satisfies(O.pre[sigma]) or not afford_ok(O, sigma, scene_graph):
            continue
        sub = [instantiate_schema(t, schemas, B, scene_graph) for t in O.decomp[sigma]]
        if any(s is None for s in sub):
            continue
        return O[sigma].with_decomposition(sub)
    return None
```

### IP-125 MIR（Mixed-Initiative Repair）

```python
def mixed_initiative_repair(f, B, D, sim, T_repair=3):
    asked = set()
    for _ in range(T_repair):
        exp = explain_failure(sim.failure, sim)      # 复用第 53/54 轮 Explain
        q = select_repair_question(exp, B, exclude=asked)
        if q is None:
            return ('abort', 'understanding_irreparable')
        B2 = update_belief(B, ask_user(q), nlu, sim.scene)
        if H(B2) > H(B):                             # 熵必须单调不增
            return ('abort', 'belief_not_converging')
        B, asked = B2, asked | {(belief_key(B2), q)}
        D = rebuild_certificate(B, sim)
        if dom(D) == 'in':
            return ('ok', D)
    return ('defer', 'turns_exhausted')
```

### IP-126 DOC（Dialogue-Operation Certificate）

```python
def dialogue_operation_certificate(B, G, Pi_star, executed, H_max, T_max):
    if H(B) > H_max:                    return ('reject', 'underdescribed')
    if not valid_grounding(G):          return ('reject', 'grounding_invalid')
    if not unique_mod_cert(Pi_star,B):  return ('reject', 'cert_dissonant_ambiguity')
    if not say_do_consistent(Pi_star, executed):
        return ('reject', 'say_do_gap')
    J = compose_joint_cert(Pi_star)     # 第 54 轮 J=(ρ,A_cert,γ_ce,δ_a)
    return ('ok', D(B, G, Pi_star, J, turns=B.turns))
```

### IP-127 GOA（General Operation Analogy）

```python
def operation_analogy(new_task, memory, B, scene_graph):
    for O_src, D_src in memory.rank_by_similarity(new_task):
        phi = match_slots(O_src, new_task, B)         # 槽位/可供性对齐
        if phi is None:
            continue
        O_tgt = retarget(O_src, phi)                  # 保留结构，重绑定实体
        D = certify_general_operation(O_tgt, B, scene_graph)
        if dom(D) == 'in':

```

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |

| GRC | O(|ℰ|·|x|) | O(|ℰ|) | conformal 覆盖、无实体冲突 |

| GOA | O(|O|·|slots|) | O(|O|) | 槽位对齐 sound、目标场景重认证 |

**正确性定理（Dialogue-Operation Say-Do Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `G` 由 conformal 预测构造，覆盖 `≥1-α`；**(A30)** `VoC_risk` 校准误差 `≤ε_v`，且 `π_safe` 判定是保守的；**(A31)** 修复每轮使 `H` 严格下降或终止，`(B,q)` 不重复；**(A32)** 模式库 `cert_template` 与 `pre/post` 保守，`decomp` 保持证书单调。则：
```
P(executed ∈ Π_understood ∧ dom(D)=in)
  ≥ 1 - α - ε_v - P(H(B)>H_max) - P(turns>T_max) - P(say_do_gap)
```
进一步，执行成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - α - P(δ_a>Θ_a) - P(say_do_gap)
```
关键：**理解先于执行且可被证书否决**；**澄清只在能改变部署结论时发生**；**修复同时作用于信念与动作**；**说做一致被显式校验**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 指代错误却高置信（误接地） | 高 | conformal 下界 + 多模态交叉验证 + 执行前复述确认 |
| VoC 误估导致过度/不足提问 | 高 | 在线校准 + 安全默认证 + 用户负担预算 |
| 对话状态维数爆炸与长程漂移 | 中 | 因子化信念 + 周期重锚 + 对话摘要 |
| ASR/NLU 误差传播到动作 | 高 | 关键槽位复述确认 + 置信门 + 可回滚执行 |
| 模式过度泛化致不安全装配 | 高 | `cert_template` 硬门 + 类型/可供性约束 + 保守 `pre` |
| 说做间隙（理解≠执行） | 高 | say-do 校验 + 执行前 dry-run 证书 + 运行时绊线 |
| 修复循环/对话震荡 | 中 | 无重复提问 + 熵单调 + 轮数上限 + hysteresis |

## 6. 本轮最大风险

**一句话**：对话管理把"理解"从黑箱解析升级为带熵、带接地证书、带 say-do 校验的前置门，使通用操作第一次能对"要做什么"负可验证的责任，但其 soundness 同时依赖**接地证书的校准覆盖、澄清价值模型的风险估计准确、以及修复过程与信念更新的收敛**；一旦误接地以高置信通过、或 VoC 系统性低估某个冷门解释的风险，系统会"自信地执行错误理解"并在多轮修复中反复确认同一错误，因此必须以 **conformal 接地下界 + 安全默认证 + 说做一致性绊线** 三重护栏，宁可显式判 `insufficient` 并多问一句，也绝不把"听起来最合理"当成"已经理解"。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（DMB×GRC×CLQ×GOS×MIR×DOC×GOA）

> 承接第 54 轮产物 v31。本轮在"动作-鲁棒双证书 + 云边协同"之上，把**理解层**纳入同一套可验证体系，新增七项算子：

## 0. 核心 IP 设计

## 2. 关键算法 伪代码

### IP-121 DMB

```python
def update_belief(B, obs, nlu, scene_graph):
    o = nlu.parse(obs)
    B.g = bayes(B.g, o.intent_prior)
    B.r = ground_update(B.r, o.refs, scene_graph)
    B.p = bayes(B.p, o.param_likelihood)
    B.c = bayes(B.c, o.constraint_likelihood)
    if o.exec_observation is not None:
        B.e = bayes(B.e, o.exec_observation)
    return normalize(B)

def understanding_gate(B, H_max):
    return H(B) <= H_max
```

### IP-122 GRC

```python
def ground_reference(span, scene_graph, context, theta_g=0.9, alpha=0.05):
    cands = filter_by_context(scene_graph.entities_by_mention(span), context)
    E, conf, ev = conformal_select(cands, coverage=1-alpha)
    A_ref = reachable_actions(E, scene_graph)
    G = Grounding(span, E, A_ref, conf, ev)
    if conf < theta_g or has_entity_conflict(E) or not all_reachable(A_ref):
        return None
    return G
```

### IP-123 CLQ

```python
def select_clarification(B, Pi, question_lib, tau_ask):
    safe = find_safe_default(Pi, B)
    if safe is not None:
        return ('default', safe)
    q_best, v_best = max(((q, VoC_risk(q, B, Pi)) for q in question_lib),
                         key=lambda t: t[1])
    if v_best <= tau_ask:
        return ('defer', 'insufficient')
    return ('ask', q_best)
```

### IP-124 GOS

```python
def instantiate_schema(task, schemas, B, scene_graph):
    for O in rank_schemas(task, schemas):
        sigma = fill_slots(O, B)
        if not all_slots_grounded(sigma):            continue
        if not satisfies(O.pre[sigma]):               continue
        if not afford_ok(O, sigma, scene_graph):      continue
        sub = [instantiate_schema(t, schemas, B, scene_graph) for t in O.decomp[sigma]]
        if any(s is None for s in sub):               continue
        return O[sigma].with_decomposition(sub)
    return None
```

### IP-125 MIR

```python
def mixed_initiative_repair(f, B, D, sim, T_repair=3):
    asked = set()
    for _ in range(T_repair):
        exp = explain_failure(sim.failure, sim)
        q = select_repair_question(exp, B, exclude=asked)
        if q is None:
            return ('abort', 'understanding_irreparable')
        B2 = update_belief(B, ask_user(q), nlu, sim.scene)
        if H(B2) > H(B):
            return ('abort', 'belief_not_converging')
        B, asked = B2, asked | {(belief_key(B2), q)}
        D = rebuild_certificate(B, sim)
        if dom(D) == 'in':
            return ('ok', D)
    return ('defer', 'turns_exhausted')
```

### IP-126 DOC

```python
def dialogue_operation_certificate(B, G, Pi_star, executed, H_max, T_max):
    if H(B) > H_max:                      return ('reject','underdescribed')
    if not valid_grounding(G):            return ('reject','grounding_invalid')
    if not unique_mod_cert(Pi_star, B):   return ('reject','cert_dissonant_ambiguity')
    if not say_do_consistent(Pi_star, executed):
        return ('reject','say_do_gap')
    J = compose_joint_cert(Pi_star)       # 复用第 54 轮 J=(ρ,A_cert,γ_ce,δ_a)
    return ('ok', D(B, G, Pi_star, J, turns=B.turns))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DMB | O(|Θ|·|o|) | O(|Θ|) | 更新归一、因子独立假设可审计 |
| GRC | O(|ℰ|·|x|) | O(|ℰ|) | conformal 覆盖 `≥1-α`、无实体冲突 |
| CLQ | O(|Q|·|Ans|·|Θ|) | O(|Θ|) | VoC 校准、安全默认优先、无安全默认才问 |
| GOS | O(|O|·|slots|·|A|) | O(|O|) | schema 前后条件 sound、槽位类型安全 |
| MIR | O(T_repair·|Explain|) | O(T_repair) | 熵单调、无重复提问、轮数有界 |
| DOC | O(|Π|·|cert|) | O(|cert|) | say-do 一致、证书等价类唯一 |
| GOA | O(|O|·|slots|) | O(|O|) | 槽位对齐 sound、目标场景重认证 |

**正确性定理（Dialogue-Operation Say-Do Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `G` 由 conformal 预测构造，覆盖 `≥1-α`；**(A30)** `VoC_risk` 校准误差 `≤ε_v`，且 `π_safe` 判定保守；**(A31)** 修复每轮使 `H` 严格下降或终止，`(B,q)` 不重复；**(A32)** 模式库 `cert_template` 与 `pre/post` 保守、`decomp` 保持证书单调。则：
```
P(executed ∈ Π_understood ∧ dom(D)=in)
  ≥ 1 - α - ε_v - P(H(B)>H_max) - P(turns>T_max) - P(say_do_gap)
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - α - P(δ_a>Θ_a) - P(say_do_gap)
```
要点：**理解先于执行且可被证书否决**，**澄清只在能改变部署结论时发生**，**修复同时作用于信念与动作**，**说做一致被显式校验**。

**理解层位于动作层之前**：`DMB→GRC→CLQ` 决定"要执行什么"，`GOS→G_S(J)→CEC` 决定"怎么执行"，`MIR` 在失败时回到理解层。JCPS 输出扩展为：
`(v,a,m,q,ι,κ,g,λ,τ,σ,ρ,Explain,RUR_state,α_S,A_cert,γ_ce,δ_a,B,G,Π*,VoC,turns)`

其中新增：
- `B` 联合信念与熵；
- `G` 指代接地证书；
- `Π*` 被承诺的证书等价类；
- `VoC` 最近一次澄清价值与决策；
- `turns` 对话/修复轮数。

## 5. 与前几轮的接口约定

- **DMB/GRC 是 SCOM/ACS 的前置门**：接地无效或 `H(B)>H_max` 时，禁止进入技能组合图搜索，返回 `insufficient` 而非默认解释。
- **CLQ 与 EIG/SRC 共享证据预算**：澄清提问视为一次"人类证据获取"，其 `VoC` 与仿真补证的成本可比，统一在证据预算下分配。
- **GOS 的 `cert_template` 必须能落到第 54 轮 `J`**：模式证书与动作-鲁棒联合证书字段对齐，缺字段即判不可部署。
- **MIR 复用 Explain/RUR**：修复问题由失败根因生成，修复后的证书必须重新走 `DOC` 校验；不允许只改 `B` 不改 `ρ/A_cert`。
- **GOA 禁止源证书直接搬运**：跨任务只迁移槽位结构，力封闭/鲁棒性/动作剖面必须在目标场景重算（与 `MTA` 的"禁止刚体变换源证书"一致）。
- **DOC 是部署总门**：`J` 可部署不再充分，必须 `J ∧ DOC` 同时为 `in`；`say_do_gap` 为一等拒因。

## 6. 本轮最大风险

**一句话**：对话管理把"理解"从黑箱解析升级为带熵、带接地证书、带 say-do 校验的前置门，使通用操作第一次能对"要做什么"负可验证的责任，但其 soundness 同时依赖**接地证书的校准覆盖、澄清价值模型的风险估计准确、以及修复过程与信念更新的收敛**；一旦误接地以高置信通过、或 VoC 系统性低估某个冷门解释的风险，系统会"自信地执行错误理解"并在多轮修复中反复确认同一错误，因此必须以 **conformal 接地下界 + 安全默认证 + 说做一致性绊线** 三重护栏，宁可显式判 `insufficient` 并多问一句，也绝不把"听起来最合理"当成"已经理解"。
