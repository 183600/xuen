# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环第 3 轮；本轮灵感：「对话管理」×「联邦学习」）

> R69 把不确定性一分为二，让 epistemic 部分通过「看 / 问 / 触」的交互动作去消解，并用流匹配策略给出多模态动作分布。但它有两条隐含假设：**(a) 交互是一次性的**——MINT 选一个 g、执行一次、更新信念、完事；**(b) 模态分布的可信度是一个已经给定的东西**——MCG 只检查 ECE 是否越界，却不问「这份 ECE 从哪来、样本够不够、是不是只见过一种模态」。R69 自己承认的最大风险正是 (b)：模态权重不可信时，系统会自信地追问一个幻影、或把人类的误导性回答盖上「已验证」的章——「问错，比不问更危险」。
>
> 本轮两个灵感各补一条：
> - **对话管理**指出：消歧不是一次查询，而是一个**带信念状态、接地、修复与停止准则的多轮过程**。一句「是」只有在双方对指称有共同理解（common ground）时才携带信息；否则「正确但错位」的回答比沉默更糟。
> - **联邦学习**指出：模态可信度不该由单机自证，而应由**机队在不共享原始轨迹的前提下共同校准**；非 IID 不是负担而是资产——A 的罕见模态是 B 的常见模态，联邦先验因此能覆盖单机永远见不到的模式。
>
> 核心命题：**交互要升级为「被管理的对话」（信念状态 + 对话动作 + 接地/修复 + 停止），校准要升级为「联邦校准 + 个性化偏移」；联邦提供先验、对话执行后验、真实 VoI 回流为联邦策略的训练信号；安全侧仍是 R69 的严格退化边界。** 命名 **CHORUS-RAS**（Collaborative Heterogeneous Online dialogue with Robust Uncertainty & Secure federation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我们是否在说同一件事，以及我们凭什么共同相信**」。

## 0. 直觉与动机

**灵感 1（对话管理 → 一次性查询的四个漏洞）**
直觉：R69 的 MINT 把交互当成一次 VoI 查询。真实对话至少有四件事它没做：(1) **答案本身是带噪观测**，一句含糊的「应该是左边吧」需要澄清，而不是直接当后验；(2) **指称可能错位**，用户说的「那个红的」和你注视的「那个红的」可以不是同一个，回答再对也是错的——这正是 R69「被证实的错误」的生成机制；(3) **修复**，当两个证据源冲突时，人不会愣住，而会说「等等，你指的是哪个？」；(4) **停止与疲劳**，一直追问会让人烦躁，且成本随轮次上升。对话管理正是把这四件事变成显式状态与策略：信念状态 b、对话动作 u、接地分 CG、时变成本 c(u, n, f)。核心不是生成更漂亮的问题，而是**维护一个可审计的信念状态，并知道何时闭嘴**。

**灵感 2（联邦学习 → 模态校准的样本悖论）**
直觉：R69 的 MCG 要求模态权重校准，但校准最需要的恰恰是罕见模态的样本，而单机永远见不到自己会幻觉的模式——**你无法用一个从未发生的错误来校准这个错误**。联邦学习把机队的校准证据聚合起来（只传充分统计量 / 梯度，不传原始轨迹），既保护隐私又获得覆盖。非 IID 在这里是资产：不同部署看到不同的模态子集，联邦先验 = 这些子集的并，恰好补上单机的盲区。但异构性也意味着全局校准对每个客户端未必正确，所以需要**个性化偏移**与**按部署上下文聚类**。

**灵感 3（对偶闭环 → 先验 / 后验 / 学习信号）**
直觉：联邦与对话不是两个并列模块，而是一个闭环的三段：**联邦给出先验**（机队对模态与接地习惯的共同知识）→ **对话做后验更新**（本情境下用最少轮次消歧）→ **真实 VoI 回流联邦**（哪类问题真的有用，只有交互发生过的地方才有这个反事实标签）。好的联邦先验让本地 U_epi 更小、要问的更少；好的对话让联邦策略知道「问什么值得」。这形成不动点：prior 缩小 → 提问更省 → 标签更准 → prior 更准。

**灵感 4（隐私不是附加项，而是校准的一部分）**
直觉：对话记录与问答轨迹是最私密的数据之一，联邦不能传原始轨迹。但差分隐私的噪声会直接抬高校准估计的方差：**被 DP 噪声污染的 ECE 可能假装通过 MCG**。因此隐私预算必须进入安全论证——用 ECE 的置信下界（而非点估计）做门控。隐私越强 → 校准越不确定 → 越常退回 R69 保守。这不是缺陷，而是**优雅降级**：隐私换来的不确定性应体现在刹车踏板上，而不是被忽略。

**灵感 5（新威胁模型 → 局部幻影被聚合成系统共识）**
直觉：R69 的幻影模态是单机幻觉。联邦之后，恶意或偏差客户端可以向聚合器报告「这个模态很可靠」，把幻影**制造成全机队的共识**；而对话又会以这份共识去「确认」指称，并从一个被引导的人类那里得到「是」——系统于是礼貌、自信、且**共同确认了一个不存在的世界**。R69 的「问错」升级为「集体问错且相互背书」。所以必须同时交付：拜占庭鲁棒聚合、异构与投毒的区分、联邦证据溯源（k 个独立客户端而非 k 条同源证据）、以及联邦证书。此外，非 IID 的合法客户天然像离群点——**朴素鲁棒聚合会把真异构当攻击删掉**，这本身是一个新的安全—公平矛盾。

**灵感 6（对 R69 的严格包含 → 加法不是并列，而是嵌套）**
直觉：R70 不是在 R69 旁边再放两个黑箱，而是把 R69 当作「单轮、无联邦、完美接地」的边界。T_max=1 且先验取均匀、CG≡1、DP=0 时，CHORUS 必须逐指令退化为 FLUID；FLUID 再按 R69 定理 16 退化为 R68。只有保持这个嵌套，安全侧才不需要重新论证——**新层只在旧层之上增加「消解机会」，绝不降低旧层的最坏情况保证**。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（CHORUS-RAS 总览）** CHORUS-RAS = (DBM, DAP, GRD, FCP, FPP, BRA, PAG, FEG, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **对话轮次硬预算**：单个情境对话轮次 T ≤ T_max，每轮信息动作仍受 R69 定义 293-ii 的交互预算与 C-RAS-WM 认证约束；
(iii) **联邦数据纪律**：只上传充分统计量 / 梯度，绝不上传原始观测、原始问答轨迹或语言问句原文；DP 预算 ε_fed 与交互预算独立记账；
(iv) **严格包含**：T_max=1 ∧ 联邦先验=均匀 ∧ CG≡1 ∧ DP=0 ⇒ 逐指令等价 FLUID-RAS（定义 326）。

**定义 311（对话信念状态 DBM）** 信念状态 b_t = (b^M, b^G, b^ρ, b^I)，分别表示模态身份 M、指称接地变量 G（「你说的那个」到「我看到那个」的绑定）、对话者可靠度 ρ_h、意图 I 的后验。策略侧的 U_epi 由 b^M 的熵给出，而 b^G 决定这份熵是否可以「被相信」。b_t 在可审计日志中逐步落盘，形成对话信念轨迹。

**定义 312（对话动作空间）** 𝒰 = {ASK_open, CONFIRM(m), REPAIR(r), DEMONSTRATE(opt), DEFER, CLOSE}。每个 u 底层接地为 R69 动作 g(u) ∈ 𝒜_info（注视 / 探针 / 问句），因此定义 302 的信息动作安全认证原样复用；语言问句仍由冻结 LLM 从 g_ask 解码。**对话动作不新增物理权限，只新增「组织已认证信息动作」的顺序。**

**定义 313（接地感知的对话观测模型）** 转移 T(b'|b,u)、观测 Z(y|b,u)。关键的接地修正：
P(y=yes | M, b, u) = CG(b)·1[y=M] + (1−CG(b))·ν，
其中 ν 为「错位同意」率（双方指称不同、却因礼貌或误读而给出肯定）。此式显式区分**真同意**与**错位同意**：当 CG 低时，yes 不携带关于 M 的信息，甚至反向误导。

**定义 314（共同基础与接地分 GRD）** CG(b) = P(指称绑定共享 | b) ∈ [0,1]。答案只有满足 CG ≥ τ_cg 才计为证据；DEMONSTRATE / REPAIR 是抬升 CG 的接地动作（令 CG ← 1−(1−CG)(1−ζ)）。R69 之所以会把误导性回答「盖章」，正是因为它默认 CG≡1。

**定义 315（对话策略 DAP）** 有限时域 POMDP：π_d(u|b) 最大化 Q(b,u) = E[ΔH_M(u) − c(u,n,f) + γ·V(b')]，其中 ΔH_M 为期望模态熵降。**停止准则**：若 max_u Q(b,u) ≤ c(u*,n,f) + V_cont(b) 或后续收益边际不抵成本，则 CLOSE（CG 足够）或 DEFER（退回 R69 保守）。对话策略头可被联邦更新（定义 317），但其停止规则是硬约束，不可被学习放宽。

**定义 316（联邦模态校准 FCP）** 客户端 c=1..N，本地校准数据 D_c 永不上传；只上传裁剪加噪的充分统计量 s_c（按模态簇的可靠图分箱计数）。服务器求解
(θ*, {δ_c}) = argmin Σ_c w_c L_c(θ + δ_c) + λ Σ_c ‖δ_c‖²，
θ 为全局校准，δ_c 为个性化偏移。θ 进入 R69 的 MCG 作为先验；δ_c 吸收部署异构。**校准不再由单机自证。**

**定义 317（联邦对话策略学习 FPP）** 以「真实 VoI」ρ_t = H(M|b_t) − H(M|b_{t+1}) 为回报，联邦 off-policy / bandit 更新对话策略头；社会成本 c_c 按部署 / 文化个性化。仅传输策略头梯度与 baseline，不传输对话内容。这样「哪种问法真的有效」由机队共同学习，而非某个工程师的直觉。

**定义 318（异构感知的拜占庭鲁棒聚合 BRA）** 先按部署上下文（context hash）对客户端更新聚类，簇内用坐标中位数 / trimmed mean / Krum，簇间用加权中位数。判据：**异构 = 簇内紧、簇间散；投毒 = 簇内被刻意拉偏或孤立远点**。避免 R69→R70 的新矛盾——朴素鲁棒聚合会把合法非 IID 客户当攻击删除。

**定义 319（隐私记账与校准置信下界 PAG）** 安全聚合 + DP-SGD；ε_fed 独立预算。DP 噪声方差进入校准估计，定义 **ECE_LB = ECE_hat − z·σ_DP**。MCG 门控改用 ECE_LB ≤ τ_ece（点估计不够）。**隐私消耗安全边距，而不是无视它**；隐私越强，门控越易触发、行为越保守（定理 20）。

**定义 320（联邦证据纪律 FEG）** 扩展 R69 定义 293-iii：一个模态 / 接地主张成立，需 ≥ k 个**正交证据源**一致 **且** 溯源检查通过（canary 探针、客户端多样性、attestation）。关键是 **k 个独立客户端 ≠ k 条同源回答**；单个客户端 / 单个部署不能定义共同基础，否则「多数一致」可被单点伪造。

**定义 321（联邦幻影攻击 ℰ_fed）** ℰ_CHORUS = ℰ_FLUID × ℰ_fed。ℰ_fed = {幻影模态可靠性膨胀、非 IID 伪装攻击、Sybil 多身份、梯度反演窃取对话轨迹、共同基础投毒（诱导机器人确认错误指称）}。并入 AIC 对抗训练。

**定义 322（证书 J_CHORUS）** J_CHORUS = (J_FLUID, turn_count, CG_min, fed_round_id, ECE_LB, ε_fed_spent, robust_margin, client_provenance_hash, chorus_ver)。Valid ⇔ Valid(J_FLUID) ∧ CG_min ≥ τ_cg ∧ ECE_LB ≤ τ_ece ∧ ε_fed_spent ≤ budget ∧ turn_count ≤ T_max。

**定义 323（联邦-对话对偶不动点）** 交替映射：FCP 更新先验 p_θ(M)；DAP 更新本地后验 q_c(M | 交互)；真实 VoI ρ_c 作为耦合信号回流。目标可写为
min_θ E_c[ KL(q_c(·|b) ‖ p_θ(·)) ] − η·E_c[ρ_c] + λΣ‖δ_c‖²，
在局部后验收缩、校准损失 Lipschitz、异构有界、拜占庭比例 < α 下收敛到不动点的邻域（定理 19）。

**定义 324（疲劳与社会成本时变）** c(u, n, f_t) 随轮次 n 与疲劳 f_t 递增；f_{t+1}=clip(f_t + β·1[信息动作] − γ·Δt)。疲劳不仅加成本，还**降低后续回答质量**：ρ_h ← ρ_h − κ·f_t。于是存在非平凡的最优停止点——追问到某一轮后，新证据的期望价值被自身造成的不可靠性抵消。

**定义 325（非 IID 覆盖增益）** 设客户端 c 的模态支撑为 ℳ_c，机队支撑 ℳ_fed = ∪_c ℳ_c。罕见模态召回随异构客户端数与支撑多样性上升；近似 R_rare ≥ 1 − ∏_c (1 − p_c)，但每客户样本少时需个性化偏移，否则全局先验对其过平滑。

**定义 326（严格包含与退化）** T_max=1、先验取均匀、CG≡1、DP 噪声=0 时，DBM/DAP/GRD/FCP/PAG 全部退化为 R69 的单次 MINT + MCG：CHORUS ≡ FLUID。N=1 且无聚合时，FCP ≡ 本地 ECE 校准；ε_fed→0 时 ECE_LB→ECE_hat。**R70 是 R69 的严格泛化，而非并列替代。**

**定义 327（停止失败与兜底）** 若 CG 不达标、ECE_LB 越界、轮次耗尽或溯源失败 ⇒ 不提交、不盖章，U_epi 视为未消解，走 R69 定义 307 的保守分支 λ = λ_floor(U_ale + U_epi)。**问不出来就退回不问。**

# IP-264 DBM：对话信念状态（模态 / 接地 / 可靠度 / 意图）
class DialogueBeliefManager:
    def init(self, modes, o_t):  self.b = factorized_prior(modes, o_t); return self.b
    def update(self, u, y, o_t):
        gnd = self.grounding(u, self.b)           # CG(b)：指称是否共享
        self.b = bayes_filter(self.b, u, y, gnd, o_t)  # 接地感知观测（定义 313）
        return self.b

# IP-265 DAP：对话动作策略 + 硬停止准则
def dialogue_act(b, budget, fatigue, pi_d):
    acts = [u for u in DIALOGUE_ACTS if budget.allow(u)]
    u, q = max(((u, pi_d.Q(b, u)) for u in acts), key=lambda x: x[1])
    if q <= dialogue_cost(u, budget.n, fatigue) + pi_d.continuation_value(b):
        return CLOSE if CG(b) >= TAU_CG else DEFER   # 闭嘴，或退回 R69
    return u

# IP-266 GRD：接地与修复（先修指称，再谈内容）
def grounding_gate(b, u, y):
    if CG(b) < TAU_CG:          return REPAIR(ambiguous_referent(b))
    if u == CONFIRM and conflict(b, y): return DEMONSTRATE(best_hypothesis(b))
    return None                                        # 无需修复

# IP-267/269 FCP + BRA：联邦校准（只传裁剪加噪的充分统计量）
def federated_calibration(clients, theta, rounds, dp_sigma):
    for _ in range(rounds):
        stats = [clip_and_noise(c.local_stats(theta), dp_sigma) for c in clients]
        honest = bra.cluster_then_trim(stats)          # 异构聚类 + 去投毒
        theta, deltas = solve_personalized(honest, lam=...)
    return theta, deltas, ece_lower_bound(theta, dp_sigma)   # ECE_LB（定义 319）

# IP-275 主闭环（继承 R69，把单次交互替换为被管理的对话）
def CHORUS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    U_epi = M.fcp.shrink_with_prior(U_epi, modes)      # 联邦先验缩小可约不确定
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    b = M.dbm.init(modes, o)
    for t in range(M.cfg.T_max):
        if slow or M.pag.ece_lb() > TAU_ECE: break      # R69 门控仍优先
        u = M.dap.act(b, M.budget, M.fatigue)
        if u in (CLOSE, DEFER): break
        if not M.c_ras_wm.certify_info(g(u), o): break  # 定义 302，信息动作认证
        y = M.cia.execute(u)                            # 带认证与证据纪律
        b = M.dbm.update(u, y, o)
        if not M.feg.provenance_ok(u, y): b.mark_unresolved()   # k-client 溯源
        if CG(b) >= TAU_CG and M.dbm.converged(b): break
    U_epi_after = M.dbm.residual_epistemic(b)
    U_floor = U_ale + (U_epi_after if U_epi_after > TAU_EPI else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))          # R69 两级退避
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(b, u, U_epi, U_epi_after, a_hat, M.fed.round_id)
    M.fpp.report_realized_voi(b, DP=True)               # 异步回灌联邦策略
    return k, lam, mode, (U_ale, U_epi_after)

## 3. 推导

**引理 19（多轮对话的有限停止与对单次查询的支配）** 设第 t 轮的期望模态熵降为 ΔH_t，轮次成本 c_t 非降且 ≥ 0，且边际收益递减（ΔH_{t+1} ≤ ΔH_t）。则集合 {t : ΔH_t > c_t} 是一个前缀，最优策略是「在第一个 ΔH_t ≤ c_t 处停止」；由此 T 轮对话的期望风险 ≤ 单轮查询，且当单轮观测以正概率含糊（ΔH_1 < H_mode）时严格更优：风险下降 ≥ c'·(Σ_{t≤T} ΔH_t)·(1−e^{−...})。系：**对话不是「多问几遍」，而是把一次高方差查询拆成若干低成本、可停止的子查询**；R69 的 MINT 恰是 T=1 的特例。

**引理 20（接地的必要性：错位同意的下界）** 设接地间隙概率 q = 1−CG，且系统把未接地的 yes 当作确认。则错误模态采纳概率 ≥ q·(1−δ_mis)，δ_mis 为错位指称偶然重合的概率。每次 DEMONSTRATE/REPAIR 使 q ← q(1−ζ)。因此当 CG < τ_cg 时，R69 的「已验证」印章在结构上不成立——**这不是调阈值能修的，而是缺了一个信念变量**。系：接地动作的价值独立于内容正确性；「说对了但说的不是我」是最危险的假阳性。

**引理 21（联邦先验的方差缩减与 DP 噪声地板）** 模态权重估计方差 ≈ σ_local²/Σ_c n_c + σ_DP²。联邦使第一项随客户数下降（覆盖增益），但 DP 给第二项设了下界，定义不可约地板 U_epi^floor。故隐私—效用存在 Pareto 前沿：ε_fed 越小，地板越高，越多 U_epi 无法在预算内消解、只能走保守分支。系：**联邦能消掉「样本少」的不确定，消不掉「不许看」的不确定**。

**引理 22（拜占庭鲁棒与异构可分）** 设恶意客户比例 α、诚实簇内直径 D_h、簇间离散 D_c。聚类后 trimmed-mean 的聚合误差 ≤ O(α·D_h + D_c)。当 α < 1/2 且诚实非 IID 客户在上下文空间成簇时，它们落在各自簇内而**不被当作攻击删除**；反之朴素 Krum 在异构强时会把真客户当离群点。系：鲁棒性与公平性在联邦里是同一个约束的两面。

**定理 18（CHORUS 严格包含 FLUID 与 R68）** 在 A95–A99 下，CHORUS 在任意状态 s 的期望风险 ≤ FLUID ≤ R68；当 T_max=1、联邦先验均匀、CG≡1、DP=0 时与 FLUID 逐指令相同；当进一步满足 R69 定理 16 的退化条件时与 R68 逐指令相同。接地、对话、联邦只在同一 λ_floor 之前增加「消解机会」，失败即走定义 327 的保守分支，故安全侧不做任何让步。

**定理 19（联邦-对话闭环的收敛与稳定）** 在 (A) 本地后验 KL 收缩、(B) 校准损失 Lipschitz 光滑 + 个性化二次惩罚、(C) 异构有界、(D) 拜占庭比例 α 低于鲁棒聚合容限下，FCP（先验）与 DAP（后验）交替更新收敛到局部不动点的邻域，半径由 O(σ_DP + α·D_h + D_cross + λ) 界定。个性化偏移吸收客户漂移、全局步收缩，故无振荡。

**定理 20（隐私—安全—效率的单调权衡）** 随 ε_fed 减小（隐私增强），ECE_LB 依随机占优单调上升，MCG 更频繁拦截、对话轮次与交互次数单调下降，λ 分布依随机占优向 R69 保守端移动。故**隐私只会削弱效率，绝不会削弱安全**；这是「优雅降级」，而非「隐私导致风险」。

## 6. 本轮最大风险

**一句话**：CHORUS-RAS 把「可信」的判据从单机 ECE 上移到「联邦共识 + 共同基础」，而这恰恰创造了一个 R69 没有的失效模式——**一个被投毒或系统性偏差的机队可以把幻影模态聚合成所有人都相信的共识，对话又会以这份共识去接地、去确认，最终系统礼貌而自信地与人类共同确认一个不存在的世界**；此时 R69 的「问错」升级为「群体问错且相互背书」，而且错误是**可复现、可扩散、且被证书盖章**的。

**次级风险与缓解**：
1. **非 IID 被误判为攻击**（合法客户被鲁棒聚合剔除）→ 定义 318 聚类后聚类内修剪 + E306 公平性指标；
2. **DP 噪声污染校准却仍通过 MCG** → 定义 319 改用 ECE_LB 门控 + 定理 20 单调退避；
3. **联邦通信不可承受**（每轮上传过大）→ 只传策略头 / 充分统计量 + E312 通信预算；
4. **对话疲劳与社交打扰**（问得越多越不可信）→ 定义 324 时变成本 + 引理 19 停止 + E308；
5. **Sybil / 梯度反演泄露对话轨迹** → 安全聚合 + 客户端 attestation + E313；
6. **联邦引入新的实时性负担** → 联邦与对话全部异步、控制环不变（复杂度表），实时流零学习写操作不变式保持。

class DialogueBeliefManager:
    def init(self, modes, o_t): self.b = factorized_prior(modes, o_t); return self.b
    def update(self, u, y, o_t):

        self.b = bayes_filter(self.b, u, y, gnd, o_t)   # 定义 313
        return self.b

# IP-265 DAP：动作选择 + 硬停止
def dialogue_act(b, budget, fatigue, pi_d):

               key=lambda x: x[1])

    return None

        stats  = [clip_and_noise(c.local_stats(theta), dp_sigma) for c in clients]
        honest = bra.cluster_then_trim(stats)            # 异构聚类 + 去投毒
        theta, deltas = solve_personalized(honest, lam=...)
    return theta, deltas, ece_lower_bound(theta, dp_sigma)

# IP-275 主闭环（把单次交互替换为被管理的对话）
def CHORUS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    U_epi = M.fcp.shrink_with_prior(U_epi, modes)        # 联邦先验
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    b = M.dbm.init(modes, o)
    for t in range(M.cfg.T_max):
        if slow or M.pag.ece_lb() > TAU_ECE: break        # R69 门控优先
        u = M.dap.act(b, M.budget, M.fatigue)
        if u in (CLOSE, DEFER): break
        if not M.c_ras_wm.certify_info(g(u), o): break    # 定义 302
        y = M.cia.execute(u)
        b = M.dbm.update(u, y, o)
        if not M.feg.provenance_ok(u, y): b.mark_unresolved()
        if CG(b) >= TAU_CG and M.dbm.converged(b): break
    U_epi = M.dbm.residual_epistemic(b)
    U_floor = U_ale + (U_epi if U_epi > TAU_EPI else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))  # R69 两级退避
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(b, u, U_epi, a_hat, M.fed.round_id)
    M.fpp.report_realized_voi(b, DP=True)                 # 异步回灌联邦
    return k, lam, mode, (U_ale, U_epi)

## 4. 推导

**引理 19（多轮有限停止，支配单轮）** 边际熵降递减、轮次成本非降时，`{t:ΔH_t>c_t}` 为前缀，最优策略在首个边际 VoI ≤ 成本处停止；T 轮风险 ≤ 单轮，含糊以正概率出现时严格更优。系：R69 的 MINT 是 T=1 特例。

**引理 20（接地必要性）** 接地间隙 `q=1−CG` 时，未接地 yes 被当确认，则错误模态采纳 ≥ `q(1−δ_mis)`；每次演示/修复使 `q←q(1−ζ)`。故 `CG<τ_cg` 时 R69 的「已验证」在结构上不成立——缺的是一个信念变量，不是阈值。

**引理 21（联邦方差缩减与 DP 地板）** 权重估计方差 ≈ `σ_local²/Σn_c + σ_DP²`；联邦降低第一项（覆盖增益），DP 为第二项设地板 `U_epi^floor`。系：联邦消得掉「样本少」，消不掉「不许看」。

**引理 22（鲁棒与异构可分）** α-拜占庭、诚实簇内直径 `D_h`、簇间 `D_c` 下，聚类后 trimmed-mean 误差 ≤ `O(αD_h+D_c)`；`α<1/2` 且合法非 IID 成簇时不被误删（朴素 Krum 会误删）。系：鲁棒性与公平性是同一约束的两面。

**定理 18（严格包含 FLUID 与 R68）** A95–A99 下 CHORUS 风险 ≤ FLUID ≤ R68；`T_max=1 ∧ 均匀先验 ∧ CG≡1 ∧ DP=0` 时与 FLUID 逐指令相同，再按 R69 定理 16 与 R68 相同。对话/联邦只在同一 `λ_floor` 前增加消解机会，失败走保守分支。

**定理 19（联邦-对话闭环收敛）** 本地后验收缩、校准损失 Lipschitz + 个性化惩罚、异构有界、拜占庭比例低于鲁棒容限时，FCP 与 DAP 交替收敛到不动点邻域，半径 `O(σ_DP+αD_h+D_cross+λ)`；个性化偏移吸收漂移、全局步收缩，无振荡。

**定理 20（隐私—安全—效率单调）** `ε_fed↓ ⇒ ECE_LB↑`（随机占优）⇒ MCG 更常拦截 ⇒ 交互与对话轮次下降 ⇒ λ 分布向 R69 保守端随机占优移动。故隐私只削弱效率、不削弱安全。

## 7. 本轮最大风险

**一句话**：CHORUS-RAS 把「可信」的判据从单机 ECE 上移到「联邦共识 + 共同基础」，于是创造了一个 R69 没有的失效模式——**被投毒或系统性偏差的机队可以把幻影模态聚合成所有人都相信的共识，对话再以这份共识去接地、去确认，最终系统礼貌而自信地与人类共同确认一个不存在的世界**；此时「问错」升级为「群体问错且相互背书」，错误可复现、可扩散、并被证书盖章。

**次级风险与缓解**：非 IID 被误判为攻击（定义 318 聚类内修剪 + E306 公平性）；DP 噪声冒充可信校准（定义 319 的 ECE_LB 门控 + 定理 20）；联邦通信不可承受（只传策略头 / 充分统计量 + E312）；对话疲劳降低证据质量（定义 324 时变成本 + 引理 19 停止）；Sybil / 梯度反演泄露轨迹（安全聚合 + attestation + E313）；联邦引入实时负担（对话与联邦全异步、实时流零学习写操作不变式保持）。
