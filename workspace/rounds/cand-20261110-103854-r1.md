# 第 43 轮（新循环第 3 轮） · 目证飞轮：把腕部相机变成「可主动查询的证书传感器」，用快速原型把重认证压到小时级（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」，两者其实是同一件事的两面：证书的感知输入是**被动的、第三人称的、外参固定的**，证书的维护是**全量的、慢的**。本轮灵感词「腕部相机」「快速原型」从两端撬动：腕部相机把视点变成**可控决策变量**，让证书在最危险处「凑近看、换个角度证伪」，把感知从风险源改造为证书执行器；快速原型让硬件每周变一次，倒逼证书从「一次性制品」变成**可 diff、可增量编译、可带洞上线**的软件资产。核心转变：证书自变量从 x 升级为 (x, v, Σ_ce)——**状态 × 视点 × 标定不确定度**；证书生命周期从「签发—使用—过期」升级为「原型 diff → 假设 diff → 增量重验 → 带洞运行 → 回填」。

## 0. 直觉与动机

**灵感 1（腕部相机 → 视点从「外参」变成「决策变量」）**：第 42 轮把感知当成一个固定的、只能被动接受的观测源：外参离线标定，L_m 全局放大，W_1 兜住仿真偏差。腕部相机打破这个前提：它装在手腕上，**看哪里、离多近、从什么角度，都是机器人自己可以决定的**。这意味着证书不再只问「状态 x 安全吗」，而要问「在视点 v 下，我能把 x 证到多安全」——定义视点条件边际 m(x; v, Σ_ce)。更妙的是，腕部相机天然贴近证据：装配间隙、线缆走向、透明物体反光、夹爪与目标的相对位姿，这些正是证书最容易过保守的地方，近距离高分辨率观测可以把局部 L_m 收紧，而不是靠全局最坏值。直觉上，这是把「感知不确定性」从一个要被动支付的税，变成一个可以主动投资的资产：花 200ms 动一下手腕，可能换来一整段 Nominal 运行。

但腕部相机有三条自带病理，必须显式入证书，否则会「看着安全」：**自遮挡**（手爪/工件挡住目标表面）、**运动模糊**（曝光时间 × 角速度导致有效分辨率骤降）、**外参漂移**（快速原型反复拆装相机支架，手眼标定必然漂移）。第 42 轮的证书框架里没有这三个变量，直接搬过来用会得到一个「静态视角下成立、一动就失效」的假证书。

**灵感 2（快速原型 → 证书必须可增量编译，而不是每次重签）**：快速原型的真实含义不是「做个粗糙东西」，而是**迭代周期短于验证周期**：3D 打印夹爪三天一版、相机支架一周一换、走线一改动力学就变。如果每次硬件改动都触发全量重认证（重跑仿真、重标 L_m、重训 INT8 监控器），证书永远落后于硬件——这就是**证书滞后（certificate lag）**：用旧硬件的证书给新硬件签字。真正该做的是把证书编译成一张**假设—义务—证据依赖图**：硬件 diff 只映射到假设 diff，只有依赖被改假设的「义务」需要重验，其余分支继承。这等价于把「证书」从一份文档变成一份**可增量构建的代码**。而且快速原型给了我们一个额外杠杆：既然零件是打印的，就可以在打印件里内嵌版本 fiducial/二维码、在相机支架上用运动学定位销——腕部相机开机自检时顺手读出版本号与重复定位误差，**自动生成原型 diff 并触发重认证**。硬件自己做自己的版本管理。

**灵感 3（两者耦合 → 目证飞轮）**：腕部相机是快速原型的「眼睛」：每次改硬件，用腕部相机对已知几何（标定板、工件、自身夹爪）做自标定，把标定不确定度写进证书；反过来，快速原型让相机支架频繁变化，必须把标定证书与视点证书做成「可重编译」的。两者咬合成 **Prototype → 自标定 → 选视点 → 条件证书 → 硬件 diff → 下一原型** 的「目证飞轮」（eye-cert flywheel）。它与第 42 轮的 Sim→RAG→Edge→Sim 飞轮**正交**：后者管「环境/仿真偏了，证书怎么进化」，前者管「硬件变了，证书怎么快速跟上」。两个飞轮共享同一套证据账本与知识库，却回答两个不同的问题：**数值偏不偏** 与 **结构变没变**。

**关键的严谨性防线（先立规矩）**：主动选视点、自标定、带洞上线都只是**提高可证性/降低维护成本**的手段，**绝不能替代已证性**。因此本轮坚持一条铁律：用于排序视点的信息价值只是启发式；放行与否永远由独立的、保守的、sound 的下界 m_lo 决定。否则主动观察会退化为「只去看能证明自己安全的地方」的确认偏误。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（视点条件证书 VCC）**：设机器人状态 x、环境几何 e。腕部相机位姿 v ∈ SE(3)，可达视点集 V_adm(x) = {v : 逆运动学可行 ∧ 无碰撞 ∧ 移动时延 ≤ T_gaze}。视点条件边际 m_lo(x, e; v, Σ_ce) 为在视点 v 观测、并计入标定不确定度 Σ_ce 后的证书边际下界。**视点条件证书** C_v = {(x, v) : m_lo(x; v, Σ_ce) ≥ θ}。运行时须携带**视点策略** π_v: x ↦ V_adm(x)，并满足可执行一致性：m_lo(x; π_v(x), Σ_ce) ≥ θ。直觉：证书从「状态谓词」升级为「状态×视点谓词 + 一个选择视点的策略」，只对策略闭合的视点集才算数。

**定义 39（视点信息价值 CVV 与主动观察）**：维护关于证书边际的信念 b，定义不安全概率 p_unsafe(b) = P_{m∼b}(m < θ)。视点 v 的观测 z ∼ O_v(z | x, e)，则
CVV(v | b) = p_unsafe(b) − E_z[ p_unsafe(b ⊕ z) ]。
视点选择 v* = argmax_{v∈V_adm} [ CVV(v|b) − λ_r·R_move(v) − λ_t·T_move(v) ]，并施加**自证约束**（定义 40）。**铁律**：CVV 仅用于排序候选视点（性能启发式），放行判定必须使用与信念无关的保守下界 m_lo；主动观察只能把「未证」变成「可证」，不能把「未证」直接判成「安全」。

**定义 40（目证安全 / self-certifying gaze）**：观看动作 a_v 的规划轨迹 ξ_v(t)。称 a_v 自证安全，若对轨迹上每个时刻 t，使用**移动前**的证书与证据仍满足
m_lo(x(t); v_old, Σ_ce) ≥ θ + ε_gaze，
其中 ε_gaze 为观察预留裕度。直觉：不能先用「看了之后觉得安全」为「移动到能看的位置」背书；观察本身必须由旧证书保护。这是防止「看得见的幻觉」的第一道闸。

**定义 41（手眼标定证书 HEC）**：手眼变换 T_ce ∈ SE(3) 及其**硬不确定度** Σ_ce（区间盒或椭球）。任一在相机系下计算的几何量 g，用对偶数/区间传播得到灵敏度 J_g = ∂g/∂ξ（ξ ∈ se(3)），则投影误差界
|g_world − Ad(T_ce) g_cam| ≤ ||J_g||_2 · ρ_ce，ρ_ce = ||Σ_ce^{1/2}||_F。
**标定感知边际** m_lo(x; Σ_ce) = m_lo^cam(x) − Σ_g ||J_g||_2 · ρ_ce。自标定：观测已知标定物 F 稳健更新 (T_ce, Σ_ce)。漂移统计量 D_t 若超 τ_cal 或证书年龄超 T_exp，则收缩证书或触发重标定。直觉：外参不是「配置项」，而是一个**会漂移、必须被监控、带证书的状态量**。

**定义 42（原型差异 → 假设差异 → 义务差异）**：原型 P = (URDF, CAD, 相机型号/支架, 标定 T_ce, 末端执行器, 控制器参数)。证书 C = (A, O, E, dep)，A 为假设集（如「标定 24h 内漂移 ≤ δ」「夹爪不遮挡目标上表面」「相机基线已知」），O 为义务集（每条义务是可验证谓词），dep: O → 2^A 为依赖映射，E 为证据集。硬件差异 ΔP 诱导假设差异 ΔA = A(P⊕ΔP) Δ A(P)。**受影响义务** O_impact = {o ∈ O : dep(o) ∩ ΔA ≠ ∅}。**增量重认证定理**：若未受影响义务的不变式仍成立，且 O_impact 全部重验通过，则新证书 C′ 对 P⊕ΔP 仍然 sound。证明思路：证书正确性可分解为「假设 ⇒ 义务 ⇒ 证据」的 AND-OR 树；未被触碰的子树保持归纳不变式，被触碰的叶子重验后重新组合。**保守规则**：解析器无法识别的硬件实体一律视为「影响所有义务」，宁可全量重认证，绝不漏检。

**定义 43（证书原型 Proto-Cert 与洞）**：证书原型 C° = (A°, O°, E°, H, fallback)，H ⊆ O° 为**未闭合义务（洞）**，每个洞绑定保守替代策略 fallback(o)（降速、禁边、收紧阈值、缩短有效期）。覆盖率 cov(C°) = 1 − Σ_{o∈H} w_o / Σ_o w_o。**受控上线规则**：cov(C°) ≥ γ，且 ∀o∈H，fallback(o) 自身必须是已证安全的（把洞映射到已被证书覆盖的受限动作集）。直觉：快速原型不是「先跑起来再说」，而是「带着明确标注的未证区域，用可证的保守策略兜住」——这是可审计的「带洞证书」，而不是无标注的乐观。

**定义 44（目证飞轮与证书滞后）**：一轮原型迭代时间
T_iter = T_diff + T_impact + T_reverify(O_impact) + T_cal + T_viewval + T_validate，
全量重认证为 T_full，加速比 S = T_full / T_iter。**证书滞后** L_cert(t) = d_H(P(t), P_cert(t))，即当前硬件版本与最近一次证书签发版本的语义硬件距离。治理红线：**L_cert ≤ 1 个原型版本**，且证书有效期 T_exp = min(标定有效期, 证据新鲜度)，过期即拒绝 Nominal。直觉：快速原型最危险的不是硬件坏，而是证书永远落后一代——用旧证书给新硬件签字。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-51/52/53/54/55/56/49/50/47/45）

### 2.1 IP-57 ACV（Active Certificate View，主动证书观察）
1. **视点—证据可观测性模型**：对每条义务 o 学习 (v, 上下文) → 预期不确定度下降。训练数据来自 IP-54 的腕部相机渲染（遮挡、模糊、光照）与真实日志；模型只做排序，不做放行。
2. **自证安全过滤器**：所有候选视点先过定义 40；被手爪遮挡锥、关节限位、碰撞体排除；只保留「去看的这段路本身在旧证书内」的视点。
3. **看—动预算调度**：在 IP-52 的 anytime 预算中新增 gaze budget。当前边际不足且 CVV 超过阈值时，先花 T_gaze 观察；若「看一眼也推不过 θ」，则不看，直接保守降级——观察必须与 SafeStop 在经济上竞争。
4. **遮挡/模糊显式建模**：手爪自遮挡用 URDF 渲染遮挡掩码；运动模糊用曝光时间 × 角速度给出有效分辨率；二者作为证据权重 w_z 进入更新，并把「有效证据窗口」写进证书。
5. **证伪优先的视点**：候选集固定包含一组**证伪视点**（侧掠、掠射反光、遮挡边界），专门用来找反例，而不是只找高分视角。CVV 排序中保留一定比例的探索配额。

### 2.2 IP-58 PCC（Prototype-to-Certificate Compiler，原型到证书编译器）
1. **原型即数据**：解析 URDF/CAD/相机支架/末端执行器/控制器配置为结构化原型描述；打印件内嵌版本 fiducial/QR，相机支架用运动学定位销，腕部相机开机自检即读版本与重复定位误差，自动生成 ΔP。
2. **假设—义务依赖图**：把既有证书编译为显式 AND-OR 依赖图；每条义务标注依赖假设、所用证据、失效 fallback。dΔP 通过规则库 + 敏感性分析映射到 ΔA。
3. **增量重认证编排**：计算 O_impact，优先从 IP-55 CKB 检索相似原型的证据/模板，只对受影响义务跑 SCV/CEGAR/实机小样本；未受影响分支继承。识别不了的实体一律全量重验。
4. **证书脚手架生成**：新原型从 CKB 检索最相似原型证书 → 生成带洞的 C° → 为每个洞选择已证 fallback → 给出「第一天可安全运行」的最小义务集。
5. **证书滞后看门狗**：硬件版本哈希与证书签发哈希绑定；不一致或超 L_cert 红线则拒绝 Nominal，并输出「需补验清单」。

### 2.3 IP-59 HEC（Hand-Eye Certificate，手眼标定证书）
1. **标定即状态**：T_ce, Σ_ce 进入运行时估计器；拆装后自动重标定；标定物可以是标定板、打印件 fiducial、或任务中已知几何的工件。
2. **敏感度传播**：对每个证书量 g（间隙、接触位姿、边界距离、可见率）用对偶数/区间传播 J_g，得到 L_cal(g) 与标定感知边际。
3. **漂移监控与重颁**：在线统计 D_t（重投影误差、工件位姿一致性、指尖点云配准残差）；超阈值 → 收缩证书 / 重标定 / 降级；证书年龄超 T_exp 强制重颁。
4. **任务驱动自标定**：装配/抓取本身提供标定证据（已知工件几何），把「干活」变成持续的标定观测；证据入账后可回填 HEC 并触发重颁。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO + 腕部相机前端(遮挡/模糊/曝光估计)
    → 局部几何证据 + 标定残差 D_t + 视点条件 L_m + 证据新鲜度
L2: CTC + VLM + IP-35 仲裁 → 语义/几何残差 → IP-57 ACV(候选视点 → CVV → 自证过滤 → 证伪视点)
    → 视点条件证书 + 证据账本(视点/标定 provenance) → CKB 指纹 (φ, ψ, P)
L3: IP-51 CAR(Gazing/Recalibrating + 守卫 m_lo(x;v,Σ)) ← IP-56 ECR(L0查表 + INT8监控 + 新鲜度门控)
    + IP-59 HEC(标定即状态 + 敏感度传播 + 漂移重颁)
    → IP-47(视点/标定契约检查) → IP-39(CBF margin=视点条件 m_lo) → IP-45(目证心跳)
    → IP-48 认证流匹配(N*=L0 j_star, 含 gaze 预算) + IP-43 韵律调度
    → IP-53 CMC(看门狗 = 证据新鲜度 + 标定有效期 + 证书滞后)
L4: IP-58 PCC(原型 diff → 假设 diff → 增量重验 / 带洞证书)
    + IP-55 CKB(视点/标定/原型指纹) ← IP-54 SCV(腕部相机渲染 + 外参扰动)
    → IP-44 蒸馏(QAT→INT8) + IP-50 课程(先看后动) → RCA 重颁(含视点策略/标定证书/版本哈希)
    → 契约热更新
运行期：L0 查表(5μs) + L1 INT8(100μs) + [必要时 T_gaze 观察]
        → 标定漂移/硬件 diff/证书过期 → 重认证 → 重颁 → 热更新
```

## 5. 本轮最大风险

**一句话**：主动观察把「可观测性」误当成「真实性」——视点规划器、边际估计器、证书签发器若共享同一个感知模型，就会系统性地只去看「能证明自己安全」的地方（确认偏误/Goodhart）；而快速原型让证书滞后成为常态，两者叠加时，「带洞证书 + 主动补证」会退化成「用看起来安全的视角给未验证的新硬件签字」——证书飞轮转得越快，自我欺骗越顺滑。因此 E89（增量重认证零漏检）与 E91（目证安全零违反）必须作为红线实验，任一不达标即全链路熔断，退回固定视角 + 全量重认证。

def select_view(x, cert_obj, belief, budget_us):
    # 候选视点：球面采样 + 任务相关关键面
    cands = sphere_views(target_geo, r_min=0.15, r_max=0.5, n=64)
    # 证伪视点配额：侧掠/掠射反光/遮挡边界（专找反例）
    cands += falsification_views(target_geo, n=8)
    cands = [v for v in cands
             if ik_feasible(x, v) and not in_collision(v)
             and occlusion_mask(v).visible_ratio >= r_min]

    best, best_score = None, 0.0
    for v in cands:
        if not self_certifying(x, v, cert_obj):      # 定义 40 硬约束
            continue
        cvv  = expected_cert_gain(belief, v, cert_obj)  # 定义 39，仅排序
        cost = w_t*travel_time(x, v) + w_r*occlusion_risk(v) + w_b*blur_cost(v)
        score = cvv / (cost + 1e-6)
        if score > best_score:
            best, best_score = v, score
    if best is None or best_score < tau_gaze:
        return None       # 看一眼不划算 → 直接保守降级 / SafeStop
    return best

def self_certifying(x0, v_target, cert_obj):
    xi = plan_to_view(x0, v_target)      # 已知控制器，可预测
    for xt in xi:                        # 轨迹上每一拍
        # 用【移动前】的证书与证据评估，绝不用新视角的估计
        if cert_obj.margin(xt) < cert_obj.theta + EPS_GAZE:
            return False
    return True

def expected_cert_gain(belief, v, cert_obj):
    p0 = belief.p_unsafe(cert_obj.theta)
    zs, pz = belief.observation_model(v, cert_obj)   # 遮挡/模糊 → 有效证据权重 w_z
    p1 = 0.0
    for z, p in zip(zs, pz):
        p1 += p * belief.updated(z, v, w_z=evidence_weight(v)).p_unsafe(cert_obj.theta)
    return p0 - p1

def execute_gaze(v, cert_obj, ledger):
    z, meta = capture_wrist_camera(v)     # meta: 曝光、角速度、遮挡掩码哈希、标定版本
    ledger.append(ViewEvidence(v=v, z=z, meta=meta,
                               calib_hash=cert_obj.calib_hash,
                               timestamp=now()))
    # 观测只更新“可证性”，放行仍由保守下界完成
    return conservative_update(cert_obj.m_lo, z, meta)

def evidence_weight(v):
    # 有效分辨率 = f(曝光×角速度, 遮挡可见率, 光照信噪比)
    return resolve_factor(v) * occlusion_mask(v).visible_ratio * snr_factor(v)

### IP-58 PCC：原型差异编译与增量重认证

def prototype_diff(P_old, P_new):
    a, b = parse_prototype(P_old), parse_prototype(P_new)
    dP = {}
    for k in set(a) | set(b):
        if a.get(k) != b.get(k):
            dP[k] = (a.get(k), b.get(k))
    # 打印件自描述：腕部相机读版本 fiducial/QR + 重复定位误差
    dP.update(read_embedded_version_tags(P_new))
    return dP

def map_diff_to_assumptions(dP, assumptions):
    if unknown_entities(dP):           # 认不出 → 保守
        return ALL_ASSUMPTIONS
    dA = set()
    for k, (old, new) in dP.items():
        for a in assumptions:
            if k in a.entities:        # 规则库 + 敏感性：假设触及该实体
                dA.add(a)
    return dA

def certify_incrementally(P_old, P_new, C_old, KB):
    dP = prototype_diff(P_old, P_new)
    dA = map_diff_to_assumptions(dP, C_old.assumptions)
    if dA == ALL_ASSUMPTIONS:
        return full_recertify(P_new, KB), 'conservative_full'

    impacted = [o for o in C_old.obligations if C_old.dep[o] & dA]
    intact   = [o for o in C_old.obligations if not (C_old.dep[o] & dA)]

    new_E = {}
    for o in impacted:
        tpl = KB.retrieve_obligation(o, P_new)          # IP-55 复用
        new_E[o] = (tpl.reuse_and_reverify(P_new) if tpl
                    else verify_from_scratch(o, P_new))
    return Certificate(
        assumptions=recheck(dA, P_new),
        obligations=C_old.obligations,
        evidence=merge({o: C_old.evidence[o] for o in intact}, new_E),
        dep=C_old.dep,
        hardware_hash=hash(P_new)
    ), 'incremental'

def build_proto_cert(P_new, KB, gamma=0.9):
    C_base = KB.retrieve_similar_prototype(P_new)
    C_deg  = degrade_to_proto(C_base, P_new)    # 与新原型不一致处标为洞
    for o in C_deg.holes:
        C_deg.fallback[o] = choose_fallback(o, P_new)  # 降速/禁边/收紧阈值
        assert is_certified(C_deg.fallback[o])          # fallback 必须已证
    assert cov(C_deg) >= gamma
    return C_deg

def cert_lag_watchdog(P_now, cert, max_versions=1):
    if cert.hardware_hash != hash(P_now):
        lag = hardware_semantic_distance(P_now, cert.hardware_version)
        if lag > max_versions or is_expired(cert):

def calibrate_hand_eye(images, fiducials, prior_T, prior_Sigma):
    T, Sigma, res = robust_hand_eye(images, fiducials, prior_T, prior_Sigma)
    D = max_reproj_residual(res) / sigma_meas

def calib_aware_margin(m_cam, cert_quantities, T_ce, Sigma_ce):
    rho = frobenius_norm(sqrt_psd(Sigma_ce))
    m = m_cam
    for g in cert_quantities:
        Jg = jacobian_dual_numbers(g, T_ce)   # 对偶数/区间传播
        m -= norm2(Jg) * rho
    return m

回退：E87 视点不增益 → 关闭主动观察，退回固定视角 + 全局保守 L_m；E88 标定界失效 → 提高 ε_gaze 与安全裕度，退回离线标定 + 固定证书；E89 漏检任一受影响义务 → 该原型类别强制全量重认证，收紧依赖图；E90 带洞上线不安全 → 禁用受控模式，只有全证通过才允许非 SafeStop；E91 观察破坏节拍 → 仅保留「危急时看一眼」的单一视点，其余固定；E93 静默失效 → 关闭腕部相机作为证书证据源，仅作辅助感知。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 主动观察确认偏误：只去看能证明自己安全的地方（Goodhart） | 高 | CVV 只排序不放行；证伪视点配额；独立 verifier 用未参与选视点的数据复核；E91 红线 |
| 手眼标定硬界失效：打印件蠕变/温漂/负载弯曲使区间包络过窄 | 高 | 硬区间 + 温度/负载相关膨胀项；定期重标定；Σ_ce 随任务负载自适应放大；E88 红线 |
| 增量重认证漏检受影响义务：依赖图不完整 | 高 | 未知实体一律全量；dep 保守过近似；diff fuzzing 注入 20 类变更；E89 红线 |
| 证书滞后：硬件迭代快于验证 | 高 | 硬件版本哈希绑定；L_cert ≤ 1 版本；过期拒绝 Nominal；带洞受控模式 |
| 遮挡/透明/反光使视觉证据不可靠 | 中-高 | 遮挡掩码 + 有效证据权重；证伪视点；多模态（接触）交叉验证；E93 |
| 带洞证书 fallback 组合出现死角 | 中 | fallback 必须自身已证；组合后重跑局部验证；洞权重大者优先补 |
| gaze 破坏节拍/能耗 | 中 | gaze budget + CVV/成本门控；与 SafeStop 经济竞争；p99 开销监控 |
| 视点策略与证书绑定后难以热更新 | 中 | 策略与证书同版本、原子热更新；灰度 + 回滚；旧视点策略保留只读 |

## 6. 本轮最大风险

**一句话**：主动观察把「可观测性」误当成「真实性」——视点规划器、边际估计器、证书签发器若共享同一个感知模型，就会系统性地只去看「能证明自己安全」的地方（确认偏误/Goodhart）；而快速原型让证书滞后成为常态，两者叠加时，「带洞证书 + 主动补证」会退化成「用看起来安全的视角给未验证的新硬件签字」——证书飞轮转得越快，自我欺骗越顺滑。因此 E89（增量重认证零漏检）与 E91（目证安全零违反）必须作为红线实验，任一不达标即全链路熔断，退回固定视角 + 全量重认证。
