### 第 7 轮灵感驱动研究记录

**灵感词**：面部表情识别、动力学

**继承关系**：第 6 轮 CADVS-v6（IP-497~500）在「七硬门 fail-closed 不变」前提下，用 GGC（抓取几何）、MCTM（空间拓扑）、STM（语义-轨迹映射）与软因子链，把生成式提议约束到「物理可达、空间连通、意图一致」的亚族。本轮不新增任何硬门，而是把 v6 中两个被当作「静态量」的东西重新解释为**动力学过程**：其一是面部表情（FER 从逐帧分类变为表情轨迹的状态估计），其二是调制/执行回路本身（从反应式阈值调整变为带 ISS-Lyapunov 证书的受控动力系统）。一句话：v6 让提议「符合物理/空间/意图」，v7 让调制「符合时间」。

**直觉与动机**：

1. **面部表情识别 → 从「快照标签」到「表情动力学状态」**。v6 的 FAMK 把每帧 FER 结果当作独立观测，得到瞬时 s_emo=(p_distress, σ)。但真实表情是一条 onset→apex→offset 的轨迹：痛苦往往在上升沿就被面部肌肉动力学「预告」，而单帧分类在低强度、遮挡、个体差异下噪声极大。引入「面部表情动力学跟踪器」（Facial Expression Dynamics Tracker, FEDT）：用潜在状态空间/神经 ODE 建模表情演化 dz/dt=f_θ(z,u)，用滤波得到后验 z_t、速度 ż_t 与可预测性 ρ_t。**关键洞见**：情绪不是标签而是轨迹；与其等 apex 才收紧，不如在上升沿按 ṗ_distress 预判 apex 并提前收紧，在 offset 阶段平滑放松，从结构上缓解 v6 的「反应式抖动」。

2. **动力学 → 从「反应式调制」到「预测式 + 稳定性证书」**。v6 用 Δτ≤0.1 与 κ_max 经验性地防抖动（R58），但没有证明。引入「Lyapunov 调制动力学」（Lyapunov Modulation Dynamics, LMD）：把阈值 τ(t) 视为受控状态，用一阶滤波 τ(t+1)=(1−α)τ(t)+ατ*(t) 追踪瞬时目标 τ*(t)，并给出 ISS-Lyapunov 证书 V(t+1)≤(1−α)²(1+γ)V(t)+c‖Δτ*‖²。**关键洞见**：只要目标变化率有界（由 FER 动力学速度界给出），阈值就指数收敛到目标邻域，既不振荡也不塌缩。

3. **动力学 → 从「终点安全」到「轨迹动力学不变量」**。v6 的硬门逐点检查候选轨迹，可能接受「每点都合规、但正高速逼近边界」的轨迹。引入「预测式安全认证器」（Predictive Safety Certifier, PSC）：在视界 H 上预测门分数，计算离散时间控制屏障函数（CBF）条件 h(x_{k+1})≥(1−α_cbf)h(x_k) 的亏欠量，转化为**只收紧不放松**的软因子 η_psc≥1。**关键洞见**：安全不是终点约束，而是轨迹沿时间必须保持的动力学不变量；但为守住「硬门不增」，CBF 只调制既有阈值，不新增门。

4. **动力学 → 从「空间/语义相似」到「时间动力学相似」的记忆**。v6 的 LMEM-v2 检索只看轨迹嵌入与语义向量，可能召回「到得了但抖得厉害/太快」的历史轨迹。引入「时间动力学记忆」（Temporal Dynamics Memory, TDM）：e_τ 扩展时间嵌入 ψ_τ 与动力学签名（v_max, jerk_rms, curvature_max），检索距离加入 DTW 与签名差。**关键洞见**：可复用性不仅是「去过哪」，还是「怎么去」。

**关键洞见**：v6 回答「提议如何符合物理/空间/意图」；v7 回答「当情绪与执行都是动力学过程时，如何在不新增硬门的前提下，让调制既预测式又稳定」。七硬门 kc_evidence_forged_v5 记号原样复用；本轮新增：
- IP-501 FEDT（表情动力学状态估计，η_dyn），
- IP-502 LMD（ISS-Lyapunov 阈值动力学），
- IP-503 PSC（CBF 预测式软因子，η_psc），
- IP-504 TDM（时间动力学记忆，η_τdyn），
- IP-505 EFA-v7（软因子链 + 投影修正）。

**形式化目标（增量）**：

1. **FEDT（Facial Expression Dynamics Tracker）**：<br>
   - 潜在动力学 dz/dt=f_θ(z,u)，观测 e_t=g_φ(z_t)+v_t，v_t~N(0,Σ_v)；滤波给出后验 (z_t,P_t)<br>
   - 情绪状态 s_t=(p_distress,σ_t)，速度 ṗ_t，可预测性 ρ_t=exp(−½·innovᵀS⁻¹innov)∈(0,1]<br>
   - 动力学软因子 η_dyn=clip(1+κ_ρ(1−ρ_t)+κ_σ σ_t+κ_ṗ max(0,ṗ_t)Δt, 1, 1+ε_d)<br>
   - 语义：不可预测/高不确定/痛苦上升 ⇒ η_dyn↑ ⇒ 阈值↑（更保守）

2. **LMD（Lyapunov Modulation Dynamics）**：<br>
   - 瞬时目标 τ*(t)=γ(t)·τ^v5·Πη(t)，Πη=clip(∏_j η_j, 1, 1+ε_total)<br>
   - 应用阈值 τ(t+1)=(1−α)τ(t)+ατ*(t)，再 clip 到 [τ_min,τ_max]<br>
   - ISS-Lyapunov：e(t)=τ(t)−τ*(t−1)，V=½‖e‖²，V(t+1)≤(1−α)²(1+γ)V(t)+c‖Δτ*(t)‖²<br>
   - 硬约束：每个 η_j 先投影到 [1,1+ε_j]，**杜绝 v6 诚实声明中 η<1 破坏 fail-closed 的漏洞**

3. **PSC（Predictive Safety Certifier）**：<br>
   - 视界 H 上 h_i(x_k)=s_i(x_k)−τ_i，CBF 条件 h_i(x_{k+1})≥(1−α_cbf)h_i(x_k)<br>
   - 亏欠 worst=max_{i,k}[(1−α_cbf)h_i(x_k)−h_i(x_{k+1})]⁺<br>
   - η_psc=clip(1+κ_p·worst, 1, 1+ε_p)，无亏欠时 η_psc=1（恢复 v6）

4. **TDM（Temporal Dynamics Memory）**：<br>
   - e_τ=(emb_traj, label_grasp, η_safety, src, ψ_τ, dyn_sig)<br>
   - d_dyn=w_1(1−cos(ψ_x,ψ_m))+w_2·DTW(x,m)/L+w_3‖sig_x−sig_m‖<br>
   - η_τdyn=clip(1+κ_t·min_m d_dyn, 1, 1+ε_t)

5. **EFA-v7 软评分**：ECS_v7=ECS_v6·η_dyn·η_psc·η_τdyn；τ_i^v7=γ_i(t)·τ_i^v5·Π_factor_i^v6·η_dyn·η_psc·η_τdyn，且 Π_factor_i^v7=clip(·,1,1+ε_total)，ε_total=0.4≥v6 的 0.3，保证 Exec_v7⊆Exec_v6⊆Exec_v5。

6. **形式化定义**：给定指令 L、目标 ρ_target、记忆 M、表情帧序列 F：<br>
   - s_dyn=FEDT(F)；γ=γ(s_dyn.s)；<br>
   - q_L=STM(L)；m_topk=Top-k(Retr_M(q_L, ∪ d_dyn), K=4)；<br>
   - c_ctx=(obj, g_emb, θ_fp, task, s_dyn.s, m_{1:k}, ρ_target, t_topo, q_L, ψ_{m})；<br>
   - cands=FMPP.propose(c_ctx, K=8)；<br>
   - 对 x∈cands：η=(η_g,η_topo,η_interp,η_cmd,η_dyn,η_psc,η_τdyn)，τ=LMD.step(τ_prev,γ,τ^v5,η)；<br>
   - surv=[x : GGC(x)∧MCTM(x)∧¬Ψ_novel(x)∧∧_i kc_i(x;τ_i^v7)=1]；<br>
   - Exec_CADVS-v7=surv，并记录 Lyapunov 残差 V_t 与 CBF 亏欠 worst_t。

**本轮最大风险**：**面部表情动力学的模型误设**——FER 的潜在 ODE 与滤波协方差若与实际情绪演化不符，ISS-Lyapunov 证书只在名义模型下成立；系统可能「稳定地」收敛到一个被证明安全、实际却错误的平衡点，且这种错误不会以振荡或塌缩的形式暴露。

## 2. 关键算法骨架

### IP-501 FEDT：面部表情动力学跟踪器

```python
@dataclass
class FacialExpressionDynamicsTracker:
    """FEDT：把逐帧 FER 变成表情轨迹状态估计。
    红线：滤波与 ODE 只在准入时域运行；控制环只消费预计算的 eta_dyn。"""
    f_ode: LatentODEField
    g_dec: ExpressionDecoder
    filt: Filter                  # EKF 或粒子滤波
    kappa_rho: float = 0.15
    kappa_sigma: float = 0.20
    kappa_dot: float = 0.25
    eps_d: float = 0.10
    dt: float = 1.0 / 30.0

    def observe(self, frames: list[FaceCrop], t_now) -> SDyn:
        e = [self.g_face.encode(f) for f in frames]
        z, P, innov = self.filt.run(self.f_ode, e, self.dt)
        s = self.g_dec(z[-1])                        # (p_distress, sigma)
        rho = self.predictability(P[-1], innov[-1])  # ∈ (0, 1]
        p_dot = (s[-1].p_distress - s[-2].p_distress) / self.dt
        eta = (1.0
               + self.kappa_rho * (1.0 - rho)
               + self.kappa_sigma * s[-1].sigma
               + self.kappa_dot * max(0.0, p_dot) * self.dt)
        return SDyn(s=s[-1], p_dot=p_dot, rho=rho,
                    eta_dyn=float(np.clip(eta, 1.0, 1.0 + self.eps_d)))

    def predictability(self, P, innov) -> float:
        S = self.g_dec.H @ P @ self.g_dec.H.T + self.g_dec.R
        m = float(innov @ np.linalg.solve(S, innov))
        return float(np.exp(-0.5 * m))               # 马氏距离越小越可预测
```

### IP-502 LMD：Lyapunov 调制动力学

```python
@dataclass
class LyapunovModulationDynamics:
    """LMD：把阈值当作受控状态，给出 ISS-Lyapunov 证书。
    红线：所有 eta 先投影到 [1,1+eps]，从构造上排除 v6 的 eta<1 扩张漏洞。"""
    alpha: float = 0.35
    eps_total: float = 0.40        # v7 全局上限 ≥ v6 的 0.30
    tau_min: float = 0.50
    tau_max: float = 2.00

    def project(self, eta_vec, eps_vec) -> np.ndarray:
        return np.clip(np.asarray(eta_vec), 1.0, 1.0 + np.asarray(eps_vec))

    def step(self, tau_prev, gamma, tau_v5, eta_vec, eps_vec):
        eta = self.project(eta_vec, eps_vec)
        prod = float(np.prod(eta))
        prod = float(np.clip(prod, 1.0, 1.0 + self.eps_total))
        tau_star = gamma * tau_v5 * prod
        tau_next = (1.0 - self.alpha) * tau_prev + self.alpha * tau_star
        tau_next = np.clip(tau_next, self.tau_min * tau_v5, self.tau_max * tau_v5)
        V = 0.5 * float(np.sum((tau_next - tau_star) ** 2))
        return tau_next, tau_star, V
```

### IP-503 PSC：预测式安全认证器（软因子，不是门）

```python
@dataclass
class PredictiveSafetyCertifier:
    """PSC：视界 H 上的离散 CBF 亏欠 → 只收紧软因子。
    注意：PSC 不改变七硬门的数量与标签，只参与阈值乘子。"""
    alpha_cbf: float = 0.30
    kappa_p: float = 0.25
    eps_p: float = 0.10
    H: int = 8

    def factor(self, gate_scores_H, tau_now) -> tuple[float, float]:
        # gate_scores_H[k][i] = s_i(x_k)
        worst = 0.0
        for i in range(len(tau_now)):
            h = [gate_scores_H[k][i] - tau_now[i] for k in range(self.H)]
            for k in range(self.H - 1):
                deficit = (1.0 - self.alpha_cbf) * h[k] - h[k + 1]
                worst = max(worst, deficit)
        worst = max(0.0, worst)
        eta = 1.0 + self.kappa_p * worst
        return float(np.clip(eta, 1.0, 1.0 + self.eps_p)), worst
```

### IP-504 TDM：时间动力学记忆

```python
@dataclass
class TemporalDynamicsMemory:
    """TDM：检索不仅看空间/语义，还看「怎么动」。"""
    psi_enc: TemporalEncoder
    w_time: float = 0.4
    w_dtw: float = 0.4
    w_sig: float = 0.2
    kappa_t: float = 0.20
    eps_t: float = 0.10

    def signature(self, x) -> DynSig:
        return DynSig(v_max=max_speed(x),
                      jerk_rms=rms(jerk(x)),
                      curvature_max=max_curvature(x))

    def distance(self, x, m) -> float:
        return (self.w_time * (1.0 - cosine(self.psi_enc(x), m.psi))
                + self.w_dtw * dtw(x, m.traj) / max(1, len(x))
                + self.w_sig * l2(self.signature(x), m.dyn_sig))

    def factor(self, x, m_topk) -> float:
        d = min(self.distance(x, m) for m in m_topk)
        return float(np.clip(1.0 + self.kappa_t * d, 1.0, 1.0 + self.eps_t))
```

### IP-505 EFA-v7：七硬门 + 动力学软因子链

```python
@dataclass
class EvidenceForgingAssemblerV7:
    """EFA-v7：七硬门不变；软因子链新增 eta_dyn/eta_psc/eta_taudyn，
    并由 LMD 统一投影与平滑。"""
    v6: EvidenceForgingAssemblerV6
    fedt: FacialExpressionDynamicsTracker
    lmd: LyapunovModulationDynamics
    psc: PredictiveSafetyCertifier
    tdm: TemporalDynamicsMemory
    tau_prev: np.ndarray
    eps_vec: np.ndarray = field(default_factory=lambda: np.array(
        [0.05, 0.05, 0.05, 0.05, 0.10, 0.10, 0.10]))

    def select(self, L, t_now, context):
        # 1. 表情动力学状态（替代 v6 单帧 s_emo）
        s_dyn = self.fedt.observe(context.face_frames, t_now)
        gamma = self.v6.famk.gamma(s_dyn.s)

        # 2. 语义/几何/空间条件（沿用 v6）
        q_L = self.v6.stm.forward(L) if L is not None else None
        m_topk = self.v6._retrieve(context, q_L)
        t_topo = self.v6.mctm.token(context.pose)
        eta_topo = self.v6.mctm.query(context.pose)
        eta_interp = self.v6._interp(q_L, m_topk)
        eta_cmd = self.v6._cmd(q_L)
        c = build_ctx_v7(context, s_dyn, m_topk, t_topo, q_L)
        cands = self.v6.fmpp.propose(c, K=self.v6.fmpp.K)

        # 3. 逐候选计算软因子 → LMD 生成阈值 → 七硬门原样判定
        surv = []
        for x in cands:
            if not self.v6.ggc.filter(x):
                continue
            eta_g = self.v6.ggc.quality_factor(x)
            eta_td = self.tdm.factor(x, m_topk)
            scores = self.v6._gate_scores_horizon(x, self.psc.H)
            eta_psc, worst = self.psc.factor(scores, self.tau_prev)
            eta_vec = np.array([eta_g, eta_topo, eta_interp, eta_cmd,
                                s_dyn.eta_dyn, eta_psc, eta_td])
            tau, tau_star, V = self.lmd.step(
                self.tau_prev, gamma, self.v6.tau_v5, eta_vec, self.eps_vec)
            if self.v6._seven_gates(x, tau) and not self.v6._novel(x):
                surv.append((x, float(np.prod(eta_vec)), V, worst))

        if not surv:
            self.tau_prev = tau          # 保持调制状态连续
            return self.v6._fallback_rule_proposal(gamma)

        self.tau_prev = tau
        best = max(surv, key=lambda r: (self.v6._margin(r[0]), -r[2]))
        return True, best[0], 'FORGED_CADVS_V7'

    def ecs_v7(self, x, eta_factors, V, worst) -> float:
        eta_dyn = eta_factors['dyn']
        eta_psc = eta_factors['psc']
        eta_td = eta_factors['taudyn']
        return (self.v6.ecs_v6(x, eta_factors['v6'])
                * eta_dyn * eta_psc * eta_td
                * float(np.exp(-V)) * float(np.exp(-worst)))
```

## 4. 正确性论证（增量更新）

### 定理 11（调制动力学的 ISS-Lyapunov 稳定性）

**陈述**：设应用阈值按 τ(t+1)=(1−α)τ(t)+ατ*(t) 更新（未触发 clip 的内点区域），e(t)=τ(t)−τ*(t−1)，V(t)=½‖e(t)‖²。若目标变化率有界 ‖Δτ*(t)‖≤δ，则对任意 γ>0：
V(t+1) ≤ (1−α)²(1+γ)·V(t) + (1−α)²(1+1/γ)·½‖Δτ*(t)‖²。
取 α=0.35、γ<1/(1−α)²−1≈1.37，则收缩因子 (1−α)²(1+γ)<1，V(t) 指数收敛到半径 O(δ) 的邻域（输入-状态稳定，ISS）。

**证明**：由更新式，
e(t+1)=τ(t+1)−τ*(t)=(1−α)(τ(t)−τ*(t))=(1−α)(e(t)−Δτ*(t))。
故 ‖e(t+1)‖²≤(1−α)²(1+γ)‖e(t)‖²+(1−α)²(1+1/γ)‖Δτ*(t)‖²（Young 不等式）。乘以 ½ 即得 V 的递推。收缩条件 (1−α)²(1+γ)<1 可解，δ 有界由 FEDT 的速度界与 γ、η 的 Lipschitz 性给出。clip 是凸集上的非扩张投影，内点结论在边界处以非扩张方式延拓。∎

### 定理 12（软因子投影的单调收紧与预测保守性）

**陈述**：设每个 η_j 经 project 投影到 [1,1+ε_j]，且 Π_factor_i^v7=clip(·,1,1+ε_total)，ε_total≥v6 的 0.3。则：
- 对所有 i：τ_i^v7 ≥ τ_i^v6 ≥ τ_i^v5，故 Exec_v7 ⊆ Exec_v6 ⊆ Exec_v5（七硬门判定随阈值单调收紧）；
- PSC 无亏欠（worst=0）时 η_psc=1，v7 在预测安全维度上精确恢复 v6；
- v6 中「若 η_j<1 则执行集扩张」的漏洞被投影消除：投影后恒有 η_j≥1。

**证明**：投影保证 η_j≥1；clip 下界 1 保证乘积≥1；v6 的 Π_factor_i^v6≥1 且 ≤1.3，而 v7 的 cap 1.4≥1.3，故 τ_i^v7=γτ^v5·Π^v7 ≥ γτ^v5·Π^v6=τ_i^v6。硬门 kc_i(x;τ)=1[s_i≥τ]，τ 上升时判定集合单调收缩。PSC 部分由定义直接得到。∎

### 定理 13（时间动力学检索的一致性，条件性）

**陈述**：若历史轨迹流形假设成立——即存在 Lipschitz 映射把「任务意图 + 动力学签名」映到轨迹空间，且 DTW 距离与时间嵌入余弦在流形局部等价——则对同一意图簇，TDM 检索召回的轨迹满足 d_dyn ≤ ε_dyn，且 η_τdyn 的排序与真实可复用性排序一致。

**证明（条件性）**：在流形局部，DTW 与 ψ 余弦均是该 Lipschitz 映射的度量等价近似，故簇内 d_dyn 有界；排序一致性由距离的保序性给出。**注意**：该定理不覆盖流形外（新任务/异常动力学）情形，此时 η_τdyn 只保证保守收紧，不保证召回正确。∎

### 诚实声明

- FEDT 的潜在 ODE 与滤波协方差是**模型**；表情的非平稳性、遮挡、个体差异会造成模型误设，ISS-Lyapunov 证书只在名义模型下成立（见 R67）。
- PSC 的 CBF 亏欠依赖候选轨迹的门分数预测；rollout 若乐观，η_psc 可能低估真实风险。
- TDM 的 DTW 在长轨迹上代价高，实现须下采样或快 DTW，否则会拖慢准入时域。
- 时序 FER 比单帧更易被用于身份/状态推断，隐私风险高于 v6；必须端侧即用即弃并做 DP。
- 全局 cap 1.4 可能被多个因子饱和，导致新增因子「形式上存在、实际无效」；需因子预算与监控。
