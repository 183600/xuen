> **基线**：上一轮产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（HPC-E 物理接地能量证书、PGEV 分层能量可行、ACSC 机械臂配空间、DCSC 深度 conformal、CFC++ 层级模态共识；其上承 v21 语义-规范层与 v20 联邦感知证书）。
> 本轮纪律：**不推倒 v22**，HPC-E/PGEV/ACSC/DCSC/CFC++ 全部保留。本轮只做一件事：**给证书体系补上"知识的边界"与"边界的闭环"——用研究空白的形式化（认知缺口证书）承认"未被证明安全"与"被证明安全"不是一回事，再用视觉伺服把"缺口"变成可主动缩小、但绝不越权扩张的闭环反馈**。

## 0. 直觉与动机

**灵感 1（研究空白 → 认知缺口是一等公民，"没有反例"≠"已证明"）**
直觉：科学里最危险的错误不是算错，而是**把"没找到反例"偷换成"已证明成立"**（absence of evidence ≠ evidence of absence）。有意思的是，v22 恰好犯了同构的错误：RGC 用 `W_sim = ∅`（找不到反例见证）就发放"现实差距仿真信用"，而 v21 的缺席证书又是同一枚硬币的另一面。研究空白不是"什么都还没做"，而是一个**有结构、可审计、需主动搜寻的负知识对象**：它同时含"已知的未知"（标定过、确认无证据的格子）与"未知的未知"（尚未标定、只能默认保守的格子）。核心创新：**认知缺口证书 (Epistemic Gap Certificate, EGC)**——把证据状态提升为四值双格（Belnap 双格）：**T 已证安全 / F 已证危险 / B 证据冲突 / N 缺口**，准入只认 T；N 必须显式落账、可被 gap-reduction 定向攻击，绝不允许静默地当作 T。关键反直觉点：**承认"我们不知道"会先让可执行集变小；但只有一张诚实的缺口地图，主动感知才知道该去哪里补证据——严谨先损失活性，再靠闭环把活性挣回来**。

**灵感 2（视觉伺服 → 图像特征直接闭环，但只在已认证的管子里有权限）**
直觉：v22 的证书体系是"感知 → 证书 → 规划 → 控制"的离散门控：证书一签发，控制就在几何控制器上近似开环地执行到下一个快照。视觉伺服 (IBVS) 是另一种气质：直接在图像特征误差 `e = s - s*` 上闭环，`v_c = -λ L_s^+ e`，不重建完整世界模型，误差连续收敛。但它名声不佳：交互矩阵奇异、特征遮挡、局部极小、目标出视野——**在安全认证架构里，视觉伺服绝不能用来扩张操作包络，只能用来在已认证的安全管内做更精细的跟踪**。核心创新：**受限权限视觉伺服层 (Certified Visual Servo Layer, CVSL)**：把伺服速度投影到 HPC-E 签发安全管的切空间；伺服证书 (ServoCert) 要求特征落在 conformal 校准的可见集内、交互矩阵条件数 `κ(L Lᵀ) ≤ κ_max`、特征与位姿误差在界内；任一条件破坏 → 伺服权限立刻归零、无缝退化为几何控制器。关键反直觉点：**"图像里有目标"与"这些特征可用于安全闭环"是两回事——特征空间本身就有一张缺口地图（奇异区、遮挡区、标定失效区），视觉伺服的合法域正是这张缺口地图的补集**。

**两者如何统一（缺口与闭环的对偶）**
研究空白给出**缺口的静态地图**，视觉伺服给出**缩小缺口的动态手段**。统一为 **v22 之上的"认知闭环层"**：EGC 回答"哪些格子我们其实不知道"，CVSL 回答"在已知部分如何更稳地贴边走"，二者再由 **缺口驱动主动感知 (Gap-Driven Active Perception, GDAP)** 缝合——机器人用**当前已认证安全集内**的运动，把目标特征从奇异/遮挡缺口推进良态区，从而**只缩小未来的缺口、绝不扩张当前的可执行集**。共享状态扩展为 `ζ_epi = ζ_pgev ∪ (e_map, G_t, κ_map, servo_cert, gap_budget)`。统一准入门 **HPC-EG = HPC-E ∧ (任务相关格 ⊆ T) ∧ (ServoCert ∨ 退化几何控制)**。安全继承：`Exec_v23 = Exec_v22 ∩ Adm_EGC ⊆ Exec_v22 ⊆ Exec_v21 ⊆ ...`——伺服只改"怎么走"，不改"能走哪些"，故集合关系不破。这也把"研究空白"从一句口号变成可被机器人自己检测、记账、并**用受限运动去消解**的一等对象。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P45）

**P43 认知诚实律（Epistemic Honesty）**
证据状态取值于四值双格 `{T, F, B, N}`，`e: C → {T,F,B,N}`。准入仅接受 `T`；`F` 拒绝、`B` 拒绝并升级、`N` 回落最严默认。信息序 `⊑_k` 下 `N` 最缺信息；任何失效/过期/撤销只允许把 `T` 降为 `N`（信息减少），**永不允许 `N ↦ T` 在无新有效证据时发生**。故"准入集 `A(e) = {π : ∀ 必需格 c, e(c)=T}` 在证据衰减下单调不增"。一句话：**不知道就说不知道，且说不知道本身要被记账**。

**P44 伺服权限有界律（Bounded Servo Authority）**
CVSL 输出 `v = Π_tube(v_srv)`，其中 `Π_tube` 是到 HPC-E 安全管切空间/可行速度集的投影，未投影分量被裁剪为 `v_geo` 方向。仅当 ServoCert 三联条件成立（`s ∈ V_vis`、`κ(LLᵀ) ≤ κ_max`、`‖ε_feat‖≤ε̂_feat ∧ ‖ε_pose‖≤ε̂_pose`）才允许 `v_srv` 生效；任一破坏 → 权限 0、`v := v_geo`。**CVSL 只改变轨迹跟踪，不改变准入计划集**，故 `Exec` 关系不变。

**P45 缺口收缩单调律（Gap-Contraction Monotonicity）**
GDAP 的每个探视动作必须属于当前 `Exec_v23`；其唯一许可的外部效应是**减少未来时刻的缺口集** `G_{t+Δ}`，不得增大当前 `A_t`。补证据必须从 `E_res` 扣除能量并按 PGEV 预算结算；证据收益只有在**重新签发**证书后才可被消费（禁止"边补证据边即时扩权"的悬空信用）。一句话：**可以用安全动作去买知识，但不能用知识去偷安全**。

## 3. 与基线的接口（如何退化）

- EGC 失效（四值账本崩溃）⇒ 退回 v22 的"缺省即保守但无显式地图" ⇒ 等价 v22（更弱，但仍保守）；
- G-RGC 失效 ⇒ 仿真信用退回 v22 的 `W_sim=∅` 逻辑并**叠加**最严默认 ⇒ 比 v22 更保守；
- CVSL 失效 / 特征丢失 / `L` 近奇异 ⇒ 伺服权限 0 ⇒ 几何控制器 ⇒ 等价 v22 跟踪，集合不变；
- ServoCert 标定失效（κ/可见不可信）⇒ 全域视为特征缺口 ⇒ 只走几何控制；
- GDAP 失效 ⇒ 不主动补证据 ⇒ 活性退回 v22（缺口仍在，但不冒险）；
- 全部失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20`。
- **安全继承总结**：EGC 只做"加法之外的诚实标注"（把 T 降为 N、绝不静默升 T）；G-RGC 只在更细的格上收紧；CVSL 只在管内做投影、失效即退化几何；GDAP 只花安全集内的运动去减少未来缺口；任意失效都向更保守方向退化，且**没有任何模块能单方面把 N 变 T**。

```python
from enum import Enum

class Ev(Enum):
    T = "T"   # 已证安全
    F = "F"   # 已证危险（有 witness）
    B = "B"   # 证据冲突
    N = "N"   # 缺口 / 未覆盖

# 信息序：N 最缺信息；T/F/B 均"有信息"。
INFO = {Ev.N: 0, Ev.T: 1, Ev.F: 1, Ev.B: 1}
SAFE = {Ev.T}  # 准入仅 T

# IP-436 认知缺口证书
class EpistemicGapCertificate:
    def __init__(self, decay_ttl):
        self.e = {}                 # cell -> Ev
        self.stamp = {}             # cell -> t
        self.decay_ttl = decay_ttl  # 每条证书的新鲜度窗

    def decay(self, now):
        """任何失效/过期只降为 N；绝不静默升 T。"""
        for c, t in self.stamp.items():
            if now - t > self.decay_ttl[c]:
                if self.e[c] is Ev.T:
                    self.e[c] = Ev.N          # T -> N（信息减少，安全序不上行）
                # F/B 保留，但不得转成 T
        return self

    def assert_safe(self, c):
        # 只认 T；N/F/B 一律保守
        return self.e.get(c, Ev.N) in SAFE

    def gap_map(self, cells):
        return {c for c in cells if self.e.get(c, Ev.N) is Ev.N}

    def merge_witness(self, c, witness, valid):
        if not valid:
            return
        old = self.e.get(c, Ev.N)
        self.e[c] = (Ev.B if old is Ev.T else Ev.F)
        # N->F 或 T->B：只增信息与冲突，不允许 N->T

# IP-437 Gap-Aware RGC（修正 W_sim=∅ 的缺席推理）
class GapAwareRGC:
    def __init__(self, egc, meta_gap):
        self.egc, self.meta_gap = egc, meta_gap

    def admits_sim_credit(self, plan, required_cells, w_sim):
        # 1) 反例存在 -> 直接拒绝（F）
        if w_sim:
            return False
        # 2) 空 witness 集不等于证明：必须每个必需格都是 T
        if not all(self.egc.assert_safe(c) for c in required_cells):
            return False
        # 3) 元缺口封顶：缺口检测器覆盖不足 -> 保守
        if any(c in self.meta_gap for c in required_cells):
            return False
        return True

# IP-438 受限权限视觉伺服
class CertifiedVisualServoLayer:
    def __init__(self, kappa_max, lam=0.8):
        self.kappa_max, self.lam = kappa_max, lam

    def servo_cert(self, s, L_hat, V_vis, eps_feat, eps_pose):
        visible = all(feat in V_vis for feat in s)
        kappa = condition_number(L_hat @ L_hat.T)
        bounded = (norm(eps_feat) <= eps_feat.bound and
                   norm(eps_pose) <= eps_pose.bound)
        return visible and kappa <= self.kappa_max and bounded

    def step(self, s, s_star, L_hat, v_geo, cert, tube):
        if not cert:
            return v_geo                       # 权限 0：几何退化
        v_srv = -self.lam * pinv(L_hat) @ (s - s_star)
        return project_to_tangent(v_srv, v_geo, tube)  # Π_tube，绝不越管

# IP-439 缺口驱动主动感知
class GapDrivenActivePerception:
    def __init__(self, egc, exec_set, energy):
        self.egc, self.exec_set, self.energy = egc, exec_set, energy

    def propose(self, target_cells, gap_budget):
        best = None
        for motion in self.exec_set.candidates():     # 只挑 Exec 内动作
            gain = self.egc.expected_coverage_gain(target_cells, motion)
            cost = self.energy.cost(motion)
            if cost > gap_budget:
                continue
            r = gain / max(cost, 1e-9)
            if best is None or r > best[0]:
                best = (r, motion)
        return best[1] if best else None

    def commit(self, motion):
        # 探视动作只允许缩小未来缺口；当前 Exec 不变
        self.energy.charge(motion)
        self.egc.project_future_gap(motion)      # G_{t+Δ} ⊆ G_t
        return "GAP_REDUCTION_PENDING_RECERT"

    def admits(self, plan, required_cells, servo_cert):
        hpce_ok = self.hpce.admits(plan, *plan.energy_ctx)
        cells_ok = all(self.egc.assert_safe(c) for c in required_cells)
        ctrl_ok = servo_cert or self.cvsl_enabled_and_valid(plan)
        return hpce_ok and cells_ok and ctrl_ok
```

## 2. 关键引理（安全继承的机械复核）

**引理 1（子集性）**：`Exec_v23 = Exec_v22 ∩ Adm_EGC ⊆ Exec_v22`。
证明：`Adm_EGC` 只在 `HPCEG.admits` 上追加合取项（格级 T、`ServoCert ∨ 退化`），合取只减不增可满足集。∎

**引理 2（无静默升格 / decay 单调）**：设 `e' = ↓τ e`，则 `A(e') ⊆ A(e)`。
证明：衰减只允许 `T ↦ N`，`F/B` 不转 `T`；`A` 只认 `T`，故丧失 T 的格只会使 `A` 收缩。∎

**引理 3（伺服不越管）**：`v = Π_tube(v_srv)` 属于 HPC-E 安全管的可行速度集，故由 `v` 积分所得轨迹仍在管内；当 `Ω` 为管内点集时 `Ω(t+dt) ⊆ Ω(t) ⊕ Tube`，准入计划集不变。∎

**引理 4（诚实-活性不动点）**：GDAP 的每个候选动作 `m ∈ Exec_v23`，故探视本身安全；且 `commit(m)` 只更新 `G_{t+Δ}`，需重新签发证书才可能扩大 `A`，因此不存在"边补证据边即时扩权"的悬空信用。∎

## 3. 实验设计（消融与压力测试）

**平台**：移动底座 + 6-DoF 机械臂；RGB-D 感知；50Hz 控制环，10Hz 证书刷新。

**数据集/漂移**：常规成年人 / 儿童 / 轮椅 / 蹲姿 / 强逆光 / 非常规衣着；用受控协变量漂移检验"缺口被误判为已覆盖"。

**指标**：
- `FSR`（false-safe rate）：本应保守却判安全的格占比（**主指标，目标→0**）；
- `GCov`：可证缺口地图对真实盲区的召回（缺口是否被找全）；
- `Liveness`：任务成功率 / 平均完成时间 / 停机时长；
- `SDR`：伺服退化率与退化时延（应由 `Cert` 失效在 ≤1 周期内触发）；
- `E_gap`：每单位缺口收缩所耗能量（与 `B_gap` 对照）。

**消融**：v22 / +EGC / +EGC+G-RGC / +CVSL / +GDAP（全量）。

**压力测试**：目标遮挡与出视野、`L` 近奇异、特征掉点、标定漂移、探视诱发的局部振荡、`gap_budget` 饥饿。

**预期结果（模板）**：

| 配置 | FSR↓ | GCov↑ | Liveness↑ | SDR↓ | E_gap↓ |
|---|---|---|---|---|---|
| v22 | 基准偏高 | 无地图 | 高（可能虚高） | — | — |
| +EGC | 显著↓ | 中 | ↓（诚实代价） | — | — |
| +EGC+G-RGC | ↓↓ | 中 | ↓ | — | — |
| +CVSL | 持平 | 中 | ↑（跟踪更稳） | 低 | — |
| +GDAP（全量） | ↓↓ | ↑↑ | ↑（活性挣回） | 低 | 可控 |

**判据**：全量配置需同时满足 `FSR` 不高于 +EGC 配置、`Liveness` 不低于 v22，且 `E_gap ≤ gap_budget`——即**诚实的缺口地图没有被闭环偷换成假安全，活性也确实被挣回**。
