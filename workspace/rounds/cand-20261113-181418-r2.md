# 第 67 轮（新灵感驱动研究循环 第 2 轮；本轮灵感词：「电池管理」×「语音合成」）

> 承接第 66 轮 UniBot 参赛清单 v1（IP-C01~C10）。本轮不重开清单，只做两件事：把两个灵感词各自的成熟工程范式移植成两个**运行时**组件（SoC-π 完成度滤波、StreamChunk 流式分块），并用它们去升级 v1 中「只有直觉、缺机制」的三个点（C08 分块、C03 课程、C04 扰动恢复）。产物区更新为 v2。

## 0. 本轮检索核实（检索日期 2026-11-13）

1. **电池 SoC 估计的工程范式结构清晰、可直接借用**：`coulomb counting`（电流积分/航位推算）便宜连续但会漂移；`OCV`（开路电压）绝对但稀疏，且 OCV–SoC 曲线随老化改变；工业标准是**EKF/非线性滤波融合两者**（MDPI Energies 2021, 14(14):4074；Analog Devices 2023 综述；ScienceDirect S2352152X17300658 明确 OCV–SoC 关系随退化漂移）。PLOS One 2026 给出关键细节：**用新息残差在线调过程噪声协方差 Q**——残差大时减小 Q、更信测量。
2. **流式 TTS 的延迟–质量折衷已有精确变量**：S5-TTS（arXiv:2606.21882）用 lookahead-causal mask，并在相邻 codec chunk 间**重叠 2 帧 + Hanning 窗 crossfade**，把 First-Chunk Latency (FCL) 作为一等指标；边界感知流式 TTS（arXiv:2603.06444）实测 chunk 大小 k 与 lookahead f 的二维折衷——上下文太小 WER 爆炸（k=1 时 33%），f 过大反而伤害长文本（k=10、f=6 时 WER 3%→13%）；VoXtream（arXiv:2509.15969）用动态 lookahead 把首包延迟压到 102 ms；连续文本流 TTS（arXiv:2410.00767）明确提出「**输出要追上文本流的领先边缘**」的 catch-up 约束与平滑过渡问题。
3. **动作分块侧的对应问题已被独立提出**：Real-Time Chunking（RTC, arXiv:2506.07339）指出分块造成边界「跳变/策略切换」，用 freeze 前缀 + inpainting + soft mask 保连续性，并警告**朴素平均对旋转表示无效**；SEAM（arXiv:2607.04609）量化了相邻 chunk 在 overlap 区不一致；ACT/时序集成（Zhao 2023 / Chi 2025）用重叠预测加权平均降噪但引入滞后。→ 这说明第 66 轮 C08 的「自适应块长」只处理了 k，**漏掉了 overlap/跨块连续性与 FCL 两个独立变量**。
4. **动作 tokenizer 已是独立研究线**：VQ-VLA（ICCV 2025）、FASTer（arXiv:2512.04952）、OmniSAT（arXiv:2510.09667）、CARP 都把动作块离散成 coarse-to-fine token 以缩短序列。→ 与「不发明新模型」原则冲突，本轮只作**观察项**并设决策门，不投入主线。
5. 赛题侧事实沿用第 66 轮已核实项（32 任务 / 32000 演示 / 五轴 / 8765 起 N 端口 / 逐步延迟与动作统计计入可信度）；榜单仍 Coming Soon，工作假设 A0 不变。

## 1. 直觉：两个灵感词各自给了什么

**电池管理给的是「隐状态 + 漂移校正 + 预算配平 + 失效前兆」。** 机器人执行任务时有一个没人直接观测的量——「还剩多少没做完 / 还能不能做成」（完成度 p）。它与 SoC 同构：
- 便宜的连续估计 = 把策略的「进度速率」积分起来（航位推算），会漂移；
- 昂贵的绝对校正 = 在停顿/子目标处用验证器看一眼真实完成度（OCV），稀疏但绝对；
- 两者用 EKF 融合，残差大就多信绝对量——这正好把第 66 轮「conformal 残差门」从启发式升级为**有增益的滤波**；
- SoC 低时电池进入省电模式保命；对应「**完成度低/时间将尽时，策略切到保步骤分的保守模式**」——直接对着评分函数（平均成功率 + 步骤分）设计；
- 电池组「单体均衡」把电荷从高电位单体流向低电位单体；对应**训练预算水填充（water-filling）**：边际净收益相等时停止，可替换 C03 的 Thompson bandit 启发式；
- 热失控前兆（电压/温度微异常先于灾难）对应**操作失败前兆**（接触力尖峰/滑移/动作饱和/延迟尖峰先于可见失败）。

**语音合成给的是「流式生成 + lookahead + 重叠交叉淡化 + barge-in」。** 动作分块本质就是流式生成，而 TTS 已把变量拆干净：
- 生成块长 H、执行前缀 K、**重叠 L=H−K 是三个独立旋钮**，不是第 66 轮里的一个 k；
- 块边界用 **Hanning 窗 crossfade** 而非硬切换（S5-TTS 做法），且只在「线性可平均」的动作空间做（RTC 的旋转警告）；
- **First-Chunk Latency** 才是可信度条款真正记录的「逐步响应延迟」，应作一等指标；
- 人为干扰 = 对话里的 **barge-in**：不是「继续念完旧稿」，而是「停下—确认—用新上下文重新起播」，并要求输出**追上**当前真实状态（catch-up/resync）。

## 2. 严谨定义（把直觉写成可计算对象）

**定义 1（完成度状态与观测）。** 单集离散时间 t=0..T，隐完成度 `p_t ∈ [0,1]`（任务相关势，允许扰动导致负跳变）。两类观测：
- 速率观测：`r_t = g_φ(o_t, a_{t-1}) ∈ ℝ`，`p_t = p_{t-1} + r_t + w_t`，`w_t ~ N(0,Q)`（「电流」）；
- 绝对观测：每 M 步或子目标边界 `y_t = h_ψ(o_t) = p_t + v_t`，`v_t ~ N(0,R)`（「OCV」）。

标量 EKF：
```
p̂_t^- = p̂_{t-1} + r_t,     P_t^- = P_{t-1} + Q_t
ν_t   = y_t - p̂_t^-                          # 新息
K_t   = P_t^- / (P_t^- + R)
p̂_t   = p̂_t^- + K_t ν_t,   P_t = (1-K_t) P_t^-
Q_t   = Q_0 · exp(-|ν_{t-1}| / τ)            # 残差大→更信绝对观测
```
稳态方差闭式 `P_ss = (sqrt(Q²+4QR) − Q)/2`，给「完成度不确定性」一个可报告标量。

**定义 2（风险驱动块长）。** 每步扰动风险 `λ_t = λ_0 + α|ν_t| + β sqrt(P_t)`。第 66 轮命题 2 的 `P_dist` 从此不靠拍脑袋：取 `P_dist(t) ≈ 1 − e^{−λ_t}` 代入得
`k*_t = sqrt( (c2·T·C_inf + c3·σ_π²) / (c1·(1−e^{−λ_t})/2) )`，即 `k* ∝ 1/sqrt(1−e^{−λ})`。C11 因此成为 C08 命题 2 缺失的输入。

**定义 3（低完成度保守模式）。** 剩余机会 `ĉ_t = 1 − p̂_t`，单位步期望推进 `r̄`，剩余步预算 `T−t`。当 `P(p_T < 1 | p̂_t, P_t) > θ`（高斯近似）时切换目标：从「最大化成功率」切到「最大化期望步骤分」，在「继续冲终点（可能全失）」与「先做保底子目标（保证部分分）」间按期望分选择。这是省电模式的严格版本。

**定义 4（流式分块算子）。** 块预测 `A^{(j)} ∈ ℝ^{H×d}`，执行前 K 步，重叠 `L=H−K`。重叠区 Hanning 交叉淡化：
`w(s)=½(1−cos(πs/L))`，`a_{t+s}=(1−w(s))A^{(j)}_{K+s}+w(s)A^{(j+1)}_{s}`，s=0..L−1。
因 `w'(0)=w'(L)=0`，混合轨迹在两端分别继承旧/新块端点导数 → **C¹ 连续**。约束：仅在 joint / ee-rot6d 等线性可平均空间启用；两块策略分歧 `‖A^{(j)}_{K:}−A^{(j+1)}_{:L}‖` 超阈则不做淡化，转入重同步（否则插值出非法中间动作，RTC 已警告）。

**定义 5（barge-in 重同步）。** 块在 t 规划、t+δ 被扰动打断。旧尾 `A^{(j)}_{δ:H}` 基于过时状态，标为无效。新块 `A'` 需满足：①前缀与最后执行动作 C⁰/C¹ 对齐（freeze 前缀）；②长度 `K'=min(K,H−δ)`；③若扰动改变子目标则重规划而非追赶。指标：无效步数、恢复时间、恢复后成功率。

**定义 6（预算水填充）。** 任务×轴单元 i，预算 b_i，凹增益 g_i，退化（遗忘）代价 d_i（凸）。`max Σ(g_i(b_i)−d_i(b_i)) s.t. Σb_i≤B`。KKT：`g_i'(b_i*)−d_i'(b_i*)=λ`（活跃），`g_i'(0)−d_i'(0)≤λ`（b_i*=0）。「均衡」= 边际净收益相等，即电池单体均衡在训练预算上的严格对应。

## 3. 对第 66 轮清单的手术（升级 / 合并 / 修剪）

- **C08 → 升级为 C12 StreamChunk**：原 C08 只有一个块长 k；现拆成 (H,K,L) 三旋钮 + 交叉淡化 + lookahead-causal 训练 + FCL 指标 + barge-in 重同步。C08 的残差门由 C11 提供增益。
- **C03 → 升级为 C13 BalanceAlloc**：Thompson bandit 换成「水填充 + 退化代价」，bandit 保留为非凹/信息不足时的回退。
- **C04 → 与 C14 PreCursor 合并**：扰动预演负责「造数据」，前兆检测负责「何时触发恢复」；barge-in 协议是二者共用的运行时。
- **C11 SoC-π 新增（本轮押注）**：完成度滤波 + 低完成度保守模式。它是 C12 的输入、C14 的触发源、C10 预演门的步骤分预测器。
- **C01/C02/C05/C06/C07/C09/C10 保留**，其中 C06/C07 降为「低优先、按需」；C10 预演门复用 C11 的 p̂ 作步骤分预测器。
- **修剪/观察**：动作 tokenizer（VQ-VLA/FASTer 线）不进主线，设决策门；C07 双引擎只在 3–5 个高价值任务上开。
- **明确不做**：形式化安全证书、FIR 归因（沿用第 66 轮结论）；不新造 VLA 架构。

## 4. 本轮最大风险

**一句话**：电池类比的核心前提——「完成度是可积分、且存在稳定 OCV↔完成度映射的守恒量」——对操作任务并不成立（完成度会因扰动倒退、会因场景改变而重标定），因此 SoC-π 可能在最需要它的扰动段漂移，而「低完成度保守模式」会在评分权重未知时过早放弃本可成功的任务，用成功率换步骤分反而净亏。

（次级风险：lookahead-causal 训练若与部署 mask 不一致会制造新的 train-test gap；交叉淡化在策略分歧大时插值出非法动作；水填充的 g_i 只能从稀缺评测槽估计，凹性假设未必成立。）

**本轮押注：C11 SoC-π——它把「还剩多少能做」变成可估计、可报告、可驱动决策的标量；若它成立，块长、恢复触发、步骤分预测、预算分配四个下游都获得同一个免费信号。**

## 1. 本轮核心 IP（C11~C14）

### IP-C11 SoC-π：完成度滤波与低完成度保守模式（★ 押注）
- **动机**：策略不知道自己「还剩多少能做」。块长、是否恢复、要不要保步骤分，都隐含一个完成度估计。
- **差异**：把 BMS 的「coulomb counting（连续便宜、会漂移）+ OCV（稀疏绝对）+ EKF 融合 + 残差自适应 Q」整套搬到策略运行时；它同时是**估计器**和**控制器**——同一个新息 `ν_t` 既校正完成度，又当 barge-in/恢复的触发器。区别于把进度当人工 reward-shaping 的做法。
- **可行性**：中高。速率头可用轻量时序模型；绝对验证器可直接复用 VLM/价值 critics；无需新数据。
- **资源**：1 人周；推理 <3 ms/步。
- **落地步骤**：①在仿真（有真值完成度）上训速率头 g_φ 与验证器 h_ψ；②标定 Q,R,τ，使报告的 P 与实际误差一致（校准图）；③接 C12 提供 hazard；④低完成度模式用期望分规则切换。
- **风险**：完成度非守恒（见 §6 头号风险）；缓解：把负跳变显式建模为「事件」，用 ν 触发重标定而非硬积分。
- **验收线**：仿真 |p̂−p| MAE ≤0.08；P 校准误差 ≤20%；扰动跳变检测延迟 ≤8 步。

### IP-C12 StreamChunk：三旋钮流式分块 + 交叉淡化 + barge-in 重同步
- **动机**：v1 的 C08 只调 k；TTS 与 RTC 都表明块长、执行前缀、重叠是三个独立变量，且边界不连续与首包延迟各自计分。
- **差异**：①(H,K,L) 三旋钮，`k*` 由 C11 的 hazard 给出（定义 2）；②重叠区 Hanning 交叉淡化，C¹ 连续，仅在线性可平均空间启用（rot6d/quaternion 走 SLERP 或禁用）；③**lookahead-causal mask 训练**，让训练与部署的可见未来一致；④FCL（首包延迟）作一等指标；⑤barge-in 状态机 `GENERATE→HOLD→ACK→RESYNC`。
- **可行性**：高。交叉淡化与 RTC inpainting 可叠加，不改基座。
- **资源**：1–2 人周；复用 C05 管线。
- **落地步骤**：①实现三旋钮运行时；②训练时加 lookahead mask；③接 C11 hazard；④接 C14 前兆触发重同步；⑤与 hard-switch / 时序集成 / RTC 三条基线做 A/B。
- **风险**：策略分歧大时淡化插值出非法动作；缓解：分歧超阈直接重同步，不淡化。
- **验收线**：边界 jerk −40%；FCL p50 ≤100 ms；扰动下无效步 −50%。

### IP-C13 BalanceAlloc：预算水填充 + 退化代价
- **动机**：评分是任务平均，预算有限且各轴边际收益递减；bandit 的探索在「评测槽稀缺」时几乎不可用。
- **差异**：把「单体均衡 = 等边际电位」严格映射为「等边际净收益」：`g_i'−d_i'=λ`；显式建退化代价 d_i（对某任务过拟合导致其他任务遗忘），即「快充伤寿命」的训练版。bandit 仅作非凹/信息不足回退。
- **可行性**：高（离线可用仿真 DryRun 估 g_i）。
- **资源**：可忽略；依赖 C10 的 DryRun 套件估边际增益。
- **落地步骤**：①用 DryRun 拟合各 (任务,轴) 的凹增益；②用连续微调测遗忘曲线估 d_i；③解 KKT 得分配；④真机槽后更新 g_i，非凹则切 bandit。
- **风险**：g_i 凹性/可估性不足；缓解：保底均匀 + 信赖域。
- **验收线**：同预算下平均分 ≥ bandit（+3pp）且遗忘 ≤2pp。

### IP-C14 PreCursor：失效前兆检测器（与 C04 合并）
- **动机**：灾难性失败前通常有便宜可测的前兆（接触力尖峰、滑移、动作饱和、夹爪异常、延迟尖峰、`ν` 持续为正偏差）；在这些信号上提前恢复，比等可见失败再抢救便宜。
- **差异**：借用「热失控早期预警」思想，把前兆当**多变量异常分数**，输出 lead time；与 C11 新息、C12 barge-in 共用触发总线；C04 的拟人扰动预演负责造「前兆→恢复」配对数据。
- **可行性**：中高；前兆特征全在接口可观测范围内或仿真特权可得。

```python
# IP-C11：完成度 EKF（coulomb counting + 稀疏 OCV 校正 + 残差自适应 Q）
class SoCPi:
    def __init__(self, rate_head, verifier, M=15, Q0=1e-3, R=1e-2, tau=0.1):
        self.rate, self.verify, self.M = rate_head, verifier, M
        self.Q0, self.R, self.tau = Q0, R, tau
        self.p, self.P, self.nu, self.k = 0.0, 0.25, 0.0, 0

    def step(self, obs, prev_action):
        r = self.rate(obs, prev_action)                 # 连续、便宜（“电流”）
        p_pred = self.p + r
        Q = self.Q0 * math.exp(-abs(self.nu) / self.tau) # 残差大→更信绝对量
        P_pred = self.P + Q
        self.k += 1
        if self.k % self.M == 0 or is_subgoal_boundary(obs):
            y = self.verify(obs)                         # 稀疏、绝对（“OCV”）
            nu = y - p_pred
            K = P_pred / (P_pred + self.R)
            self.p, self.P, self.nu = p_pred + K * nu, (1 - K) * P_pred, nu
        else:
            self.p, self.P = p_pred, P_pred
        return self.p, self.P

    def hazard(self):
        lam = LAM0 + ALPHA * abs(self.nu) + BETA * math.sqrt(self.P)
        return 1.0 - math.exp(-lam)

    def low_soc(self, steps_left, r_bar):
        mu = self.p + r_bar * steps_left
        sd = math.sqrt(self.P + Q_RATE * steps_left)
        return norm_cdf((1.0 - mu) / sd) > self.theta   # 切保步骤分模式
```

```python
# IP-C12：三旋钮流式分块 + Hanning 交叉淡化 + barge-in 重同步
def plan_next(old, new, d, H):
    """old: 旧块(H,d); new: 新块(H,d); d: 旧块已执行步数"""
    L = H - d                                  # 重叠区 = 旧块未执行尾
    out = new.copy()
    if L > 0 and linear_blendable(old):
        s = np.arange(L)
        w = 0.5 * (1 - np.cos(np.pi * s / L))  # w(0)=0, w(L)=1 → C¹ 两端
        out[:L] = (1 - w)[:, None] * old[d:H] + w[:, None] * new[:L]
    return out                                 # 之后从 new[L:] 继续执行

class StreamChunkPolicy:
    def get_action(self, obs, t):
        p, P = self.soc.step(obs, self.last_action)
        if self.precursor.score(obs) > TAU_PRE or self.soc.hazard() > TAU_HAZ:
            self.state = "RESYNC"              # barge-in：不追旧尾
            new = self.recovery.resync(obs, last=self.last_action)
        else:
            new = self.base.propose(obs, H=self.H)   # lookahead-causal 训练
        k = int(self.K / math.sqrt(max(self.soc.hazard(), EPS)))  # 定义 2
        k = clamp(k, K_MIN, self.K)
        out = plan_next(self.buf, new, self.executed, self.H)[:k]
        self.buf, self.executed, self.last_action = new, k, out[0]
        return format_actions(out), {"p": p, "P": P, "fcl": self.fcl}
```

```python
def balance_alloc(g, d, B, n):
    # g_i' 递减、d_i' 递增；解 g_i'(b)-d_i'(b)=lambda s.t. sum b = B
    lo, hi = 0.0, max(g.grad(0, i) - d.grad(0, i) for i in range(n))
    for _ in range(60):
        lam = 0.5 * (lo + hi)
        b = [max(0.0, inv_net_grad(lam, i)) for i in range(n)]  # 截断到 0
        if sum(b) > B: lo = lam
        else:          hi = lam
    return rescale_to_budget(b, B)
```

## 4. 小命题（可证部分）

**命题 3（完成度误差与检测延迟）。** 无校正时误差 `e_t = e_0 − Σw_s + ΣJ_s`（J 为扰动跳变）。在跳变 J 后单步新息 `ν≈J`、误差变为 `(1−K)J`，随后按 `(1−K)^n J` 衰减；故从跳变到「误差<ε」的检测延迟
`d_det ≈ ln(ε/|J|) / ln(1−K)`。
推论：K 越大检测越快，但 K 由 `P/(P+R)` 决定，R 越大（绝对观测越噪）K 越小、检测越慢——**检测延迟与误报率是同一个 K 的两端**。这为 C11 的 Q,R 标定给出明确折衷。

**命题 4（交叉淡化的 jerk–滞后折衷）。** 设重叠区长 L、两块的策略分歧 `D=‖A_new−A_old‖` 在重叠区近似常数。Hanning 权 `w''(s)=(π²/(2L²))cos(πs/L)`，故混合轨迹的附加 jerk 上界 `≈ (π²/(2L²))·D`；同时混合输出相对新块的平均滞后 `≈ L/2` 步。→ **jerk 随 L 二次下降，滞后随 L 线性上升**；存在最优 L* 使「jerk 惩罚 + 滞后惩罚」最小。这量化了 TTS 的 overlap 与 ACT 时序集成的滞后。

**命题 5（水填充 = 单体均衡）。** 对 `max Σ(g_i(b_i)−d_i(b_i)) s.t. Σb_i=B`，拉格朗日一阶条件给出 `g_i'(b_i*)−d_i'(b_i*)=λ`（活跃）、`≤λ`（零）。把「电位」解释为边际净收益、「电荷」解释为预算，则最优分配就是「把预算流向边际净收益最高的单元直到相等」——与电池单体均衡同构。推论：若忽略 d_i（遗忘），会系统性高估窄任务的最优预算。

**命题 6（重同步的无效步收益）。** 扰动后若「念完旧尾」剩余 R 步，则无效步 ≈R；若在检测延迟 d_det 处重同步，则无效步 ≈min(R, d_det)。故提前检测的收益 `= R − min(R,d_det)`，由命题 3 的 d_det 控制。→ C11 的新息门与 C14 的前兆分数是在压缩 d_det，直接换步骤分。

## 7. 一句话押注与最大风险

**押注：C11 SoC-π。** 它是唯一一个同时喂给「块长（C12）、恢复触发（C14）、步骤分预测（C10）、预算分配（C13）」四个下游的隐状态；它若成立，其余三项是它的不同读出。
