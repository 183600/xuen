# 第 43 轮（新循环第 3 轮） · 竞评证书（EvalCert）：把机器人竞赛的「隐藏评测分布」变成一等公民的分数/排名证书，并给评测指标建立类型代数与 Goodhart 防线（四层架构 v8 + 竞赛评测层 L5）

> 承接第 42 轮 v19（SCV × CKB × ECR 的 Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」。本轮灵感词「机器人竞赛」「评测指标」把问题从「证书是否 sound」推进到「证书对比赛是否有用」。竞赛的本质是四元组 C=(D_hidden, S, ρ, B)：**隐藏测试分布**、**不透明评分函数**、**排名聚合规则**、**有限实机/上场预算**。v19 的安全证书只回答「会不会撞」，不回答「能不能上榜」。本轮把 v19 的 W_1 迁移界从「边际安全」复用到「分数」，把 CEGAR 反例从「安全违例」扩展到「掉分反例」，把 RAG 知识库从「证书模板」扩展到「评分画像」，并新增**评测指标代数**与**对抗评审自博弈**，形成「安全证书 × 分数证书 × 排名证书」三证合一的竞赛闭环。

## 0. 直觉与动机

**灵感 1（机器人竞赛 → 隐藏评测分布与不透明评分）**
直觉：竞赛不是一道固定题，而是「从你看不见的题库里抽题 + 用你不完全掌握的评分细则打分 + 和一群你看不全的对手排名」。第 42 轮的 SCV 已经在仿真里做域随机化，但它的目标是「安全边际覆盖」，不是「分数覆盖」。竞赛直觉要求我们反过来问：**在 D_hidden 上，我的分数分布的 1−δ 下界是多少？我的名次落在哪个区间？** 这把「安全证书」升级为「分数证书 / 排名证书」——前者是 max-min 安全，后者是概率化的性能保证。关键洞察：安全证书里的 `m_real ≥ m_sim − L_m·ε_w` 可以逐字复用为 `S_real ≥ S_sim − L_S·ε_w`，因为二者都是「分布偏移 + Lipschitz 修正」的同一数学结构；区别只是把「边际 m」换成「分数 S」、把 Lipschitz 常数 L_m 换成分数敏感度 L_S。严谨定义见定义 38–39。

**灵感 2（评测指标 → 指标代数与 Goodhart 防线）**
直觉：指标是研究的「传感器」，但排行榜指标是**有损、可博弈、会被优化压力扭曲**的代理（Goodhart's law）。竞赛里最危险的不是「指标低」，而是「把代理指标刷高了、真实分数却掉了」。所以「评测指标」本身应该像第 42 轮的技能一样**可组合、可类型检查、可证书化**：给它一个类型系统（取值范围、单调方向、可分解性、抗博弈等级），给它一个编译流程（表达式 → 估计器 + 置信区间传播器 + 博弈审计），再给它一个 Goodhart 界（代理与真值的最大系统性差距 γ）。这样，任何复合指标（如「完成率 × (1 − 碰撞率) / 用时」）都能从叶子指标的证书**推导**出复合证书，而不是靠人肉拍脑袋。严谨定义见定义 40–41。

**灵感 3（竞赛自博弈 → 对抗评审与评测预算分配）**
直觉：真正的竞赛有「出题人」，他会设计让你掉分的场景。我们可以把这个出题人显式建模成一个**对抗评审 J**：它生成「不撞但掉分」的测试实例（例如把目标物放在遮挡后、把时限压到临界、把摩擦调到打滑边缘），逼我们的策略暴露弱点。这与 v19 的 CEGAR 反例机器同构，但反例的判定谓词从「安全违例」变成「分数低于证书下界」。同时，实机/上场次数 B 是稀缺的，应该像第 42 轮的证书预算 Γ 一样被**主动分配**：把有限的真机试验花在「最能收窄分数证书区间」或「最能区分两个候选策略」的场景上，而不是均匀刷题。严谨定义见定义 42–44。

**耦合升级**：安全证书负责「不熔断」，分数证书负责「有下限」，排名证书负责「上榜概率」，指标代数保证「复合不出错」，对抗评审负责「找掉分反例」，主动评测负责「预算最优」。六者共享 v19 的 SCV/CKB/ECR 基础设施，形成 **Sim(安全+分数) → CKB(证书+评分画像+对手名人堂) → 实机(主动试验) → 反馈** 的竞赛飞轮。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（竞赛评测四元组）**：竞赛 C = (D_hidden, S, ρ, B)。D_hidden 为隐藏测试实例分布（初始条件、地图、动态障碍、任务变体）；S: (π, ξ) ↦ R^m 为子分数向量（安全、完成度、用时、能耗、风格）；ρ: R^m × R^{m×N} ↦ R 为排名聚合（依赖其他 N−1 个对手的分数）；B 为实机/上场试验预算。选手最终名次 rank(π) = 1 + Σ_{j≠π} 1[ρ(S(π)) < ρ(S(j))]。

**定义 39（分数证书 ScoreCert 与排名证书 RankCert）**：
- **分数证书**：ScoreCert(π) = (s_lo, δ, A)，A 为假设（校准集与隐藏测试集可交换、或偏移 ≤ ε_w），使得 P_{ξ∼D_hidden}[S(π,ξ) ≥ s_lo] ≥ 1−δ。构造采用带偏移修正的分裂共形：s_lo = ŝ_cal − q_{1−δ}(非一致性分数) − L_S·ε_w，其中 L_S 为分数对实例特征的 Lipschitz 敏感度，ε_w 复用 IP-54 的 W_1 估计。
- **排名证书**：RankCert(π) = (r_hi, δ)，使得 P[rank(π) ≤ r_hi] ≥ 1−δ。由两两胜率 p_{ij} 的下界 + 多重比较校正（Bonferroni / bootstrap over score samples）得到；对手分数分布由公开榜单或历史数据估计，显式标注模型误设风险。

**定义 40（Goodhart 差距与 γ-真实性）**：设 Ŝ 为用于优化的代理指标，S 为真值。在策略类 Π 上定义 Goodhart 差距 G(Π) = sup_{π∈Π} [E_{D_hidden}[S(π)] − E_{D_hidden}[Ŝ(π)]]。若 G(Π) ≤ γ，称 Ŝ 在 Π 上 **γ-真实**。γ 由一个独立的「审计集」+ 代理-真值不一致模型给出；优化压力越大、Π 越大，γ 越应保守。**命题**：若 Ŝ 为 γ-真实且 ScoreCert_Ŝ(π) 成立，则 S 的证书下界为 s_lo − γ（单调保守性）。

**定义 41（评测指标代数）**：指标类型 M = (range, direction, decomposability, robustness, variance_model)。算子：加权和 ⊕_w、乘积/组合 ⊗、阈值 ↑_τ、取极值 max/min、排名 argrank。每个表达式 e 有指称 ⟦e⟧ 与**证书变换器** T_e：叶子证书 → 复合证书。类型系统拒绝三类错误：(1) 不可分解却按可分解传播；(2) 抗博弈等级不足却被置于优化目标；(3) 量纲/方向不一致。**分数组合定理**：若 e = e_1 ⊕ e_2 且交互惩罚有界为 ι，则 s_lo(e) ≥ s_lo(e_1) + s_lo(e_2) − ι；对 ⊗（乘法型如完成率×安全率）用对数域加法传播。

**定义 42（主动评测预算分配）**：给定实机预算 B，自适应选择 ξ_1..ξ_B。目标：min E[width(ScoreCert)] 或 max P(正确识别最优策略)，约束：每次试验必须通过 IP-51 安全守卫（不拿安全换信息）。单次试验价值定义为信息增益 IG(ξ) = H(分数差距变量) − H(分数差距变量 | 试验结果)，贪心近似具子模性，给出 (1−1/e) 近似保证。

**定义 43（对抗评审与 minimax 分数证书）**：对抗评审 J: Ξ → Ξ_adv 生成使掉分 Δ(ξ) = S(π*,ξ) − S(π,ξ) 最大、或使 ScoreCert 违反概率最大的实例。自博弈：π ← best_response(J)，J ← best_response(π)。**对抗分数证书**：s_adv(π) = min_{ξ∈Ξ_adv} S(π,ξ)，其中 Ξ_adv 随自博弈扩张；minimax 目标 max_π min_J E[S]。Ξ_adv 中的实例（「不撞但掉分」）作为新反例类入 CKB。

**定义 44（评测的评测 / 元覆盖）**：定义元覆盖指标 MC = P_{ξ∼D_hidden}[ξ 落入校准集支撑的 ε-邻域]。若 MC < 1−δ_meta，则 ScoreCert 的可交换性假设可疑，证书自动加宽或拒绝签发（fail-closed）。MC 用两样本检验 + 支撑覆盖审计估计。

## 2. 五大产出设计（新增 IP-57/58/59/60 + 升级 IP-54/55/56/51/52/50/47/45）

### 2.1 IP-57 EVALCERT（竞赛评测证书引擎）
1. **双证书签发**：安全证书（沿用 v19）+ 分数证书（带偏移修正的共形）+ 排名证书（两两胜率 + 多重校正）。
2. **共享校准基础设施**：W_1 估计器、Lipschitz 敏感度 L_S/L_m、校准集切分全部与 IP-54 复用，避免两套标定。
3. **fail-closed 元覆盖**：MC 不达标 → 拒绝签发或加宽，绝不给「虚假自信」。
4. **提交决策图**：给定候选策略集，输出「该提交哪个」的期望分数-风险前沿（提交策略选择本身是一个带证书的决策）。

### 2.2 IP-58 METRIC-ALGEBRA（评测指标代数与编译器）
1. **类型化 DSL**：`metric = completion ⊗ safety^{-1} ⊕_w time^{-1}` 之类表达式，编译为估计器 + 置信传播 + 博弈审计。
2. **证书变换器库**：为每个算子实现保守的区间传播规则，保证复合证书 sound。
3. **Goodhart 审计**：对每个被优化的指标，自动生成「代理-真值分歧探针」（在审计集上做对抗扰动），估计 γ。
4. **指标指纹**：ρ 的结构化编码，用于 CKB 检索（同一任务、不同评分细则 → 不同模板）。

### 2.3 IP-59 ACTIVE-BENCH（主动评测与预算分配器）
1. **信息增益选择器**：优先跑「最能收窄分数证书」或「最能区分候选策略」的场景。
2. **安全门控**：所有主动试验先过 CAR 守卫，禁止「用安全换信息」。
3. **元覆盖审计**：持续估计 MC，触发证书加宽/重校准。
4. **预算账本**：把实机试验、仿真试验、人工评审统一记为可审计的预算流。

### 2.4 IP-60 ADV-JUDGE（对抗评审竞技场）
1. **掉分场景生成器**：梯度-free 搜索 + 场景变异（遮挡、时限、摩擦、光照）+ LLM 生成语义化「刁钻题」。
2. **自博弈循环**：策略与评审互为 best response，维护对手名人堂（Hall of Fame）入 CKB。
3. **掉分反例类**：与安全反例并列，带「根因标签」（遮挡、时限、打滑、评分细则歧义）。
4. **minimax 分数证书**：对已发现对抗集取最坏情形，作为 ScoreCert 的保守下界。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |

| E94 真实演练 | 真实/彩排竞赛：分数证书成立、安全、提交决策 | 证书成立；0 安全事件；提交决策正确 |

回退：E87 覆盖不达标 → 加宽证书并拒绝提交，退回纯安全策略；E88 排名模型误设 → 只用分数证书、放弃排名预测；E89 Goodhart 超界 → 冻结代理优化，转人工指标审计；E90 代数违例 → 禁用复合、退化为单指标；E91 无增益 → 退回均匀评测；E92 自博弈崩溃 → 固定对抗集；E93/94 名次落空 → 提交「安全+保守分数」双策略。

## 5. 本轮最大风险

**一句话**：评测证书的核心假设是「校准集与隐藏测试集可交换、且偏移可由 ε_w 界住」，而真实竞赛的隐藏题库与评审细则恰恰是不可观测、可能被出题人主动对抗的——一旦元覆盖 MC 被高估或偏移越界，分数/排名证书会同时失去 soundness 与决策价值（要么过宽到没用，要么过窄而虚假自信），这比单纯的安全证书失效更难在赛前发现。

| C = (D_hidden, S, ρ, B) | 竞赛评测四元组 | 隐藏测试分布、子分数函数、排名聚合、上场预算 |
| S(π, ξ) ∈ R^m | 子分数向量 | 安全/完成度/用时/能耗/风格等分量 |
| rank(π) = 1 + Σ 1[ρ_π < ρ_j] | 竞赛名次 | 依赖对手分数，非仅自身 |
| ScoreCert = (s_lo, δ, A) | 分数证书 | P_{ξ∼D_hidden}[S(π,ξ) ≥ s_lo] ≥ 1−δ |
| s_lo = ŝ_cal − q_{1−δ} − L_S·ε_w | 共形下界 | 校准均值 − 共形分位 − 偏移修正 |
| L_S | 分数敏感度 | 分数对实例特征的 Lipschitz 常数 |
| RankCert = (r_hi, δ) | 排名证书 | P[rank(π) ≤ r_hi] ≥ 1−δ |
| G(Π) = sup_π [E[S] − E[Ŝ]] | Goodhart 差距 | 代理与真值的最大系统性偏差 |
| M = (range, direction, decomp, robustness, var) | 指标类型 | 类型系统用于拒绝错误复合 |
| ι | 交互惩罚界 | 分数组合定理中的非可加项上界 |
| IG(ξ) | 单次试验信息增益 | 分数差距变量熵的期望下降 |
| Ξ_adv, s_adv | 对抗集 / 对抗分数证书 | s_adv = min_{ξ∈Ξ_adv} S(π,ξ) |
| MC | 元覆盖 | P_{D_hidden}[ξ 落在校准支撑 ε-邻域] |

## 2. 关键算法（伪代码）

### IP-57 EVALCERT：分数证书与排名证书
```
def issue_score_cert(policy, calib_set, D_sim, delta=0.05):
    # 1. 安全证书沿用 v19（保证不熔断）
    safe_cert = issue_safety_cert(policy, calib_set, D_sim, delta)
    # 2. 分裂共形：校准偏差的非一致性分数
    cal, test = split(calib_set)
    scores = [S(policy, xi) for xi in cal]
    nonconf = [s_hat(xi) - S(policy, xi) for xi in cal]
    q = conformal_quantile(nonconf, 1 - delta)
    # 3. 偏移修正：复用 W_1 估计与分数敏感度 L_S
    W1 = estimate_wasserstein(test, D_sim)
    L_S = estimate_score_lipschitz(cal)
    s_lo = mean(scores) - q - L_S * W1
    # 4. 元覆盖 fail-closed
    mc = meta_coverage(cal, D_sim)
    if mc < 1 - delta:
        return ScoreCert(s_lo=WIDEN(s_lo, mc), status='WIDENED')
    return ScoreCert(s_lo=s_lo, delta=delta, status='VALID')

def issue_rank_cert(policy, candidates, score_cert, delta=0.05):
    # 两两胜率下界 + Bonferroni 多重校正
    m = len(candidates)
    d = delta / max(1, m * (m - 1) // 2)
    stronger_ub = 0
    for j in candidates:
        if j is policy: continue
        p_ij = lower_bound_win_prob(policy, j, d)  # bootstrap / 共形
        if p_ij < 0.5 + margin:
            stronger_ub += 1  # 保守认为可能强于我
    r_hi = 1 + stronger_ub
    return RankCert(r_hi=r_hi, delta=delta)
```

### IP-58 METRIC-ALGEBRA：指标编译与证书传播
```
def compile_metric(expr, leaf_certs, audit_set):
    ty = type_check(expr)  # range/direction/decomposability/robustness
    if not ty.ok:
        raise MetricTypeError(ty.errors)  # 拒绝不可靠复合

    def visit(node):
        if node.is_leaf:
            return leaf_certs[node.name], node.estimator
        lc, le = visit(node.left)
        rc, re = visit(node.right)
        if node.op == 'add':
            lo = lc.s_lo + rc.s_lo - node.interaction_penalty  # 交互惩罚 ι
            est = lambda x: le(x) + re(x)
        elif node.op == 'mul':
            lo = exp(log(max(lc.s_lo, EPS)) + log(max(rc.s_lo, EPS)))  # 对数域
            est = lambda x: le(x) * re(x)
        elif node.op == 'min':
            lo = min(lc.s_lo, rc.s_lo)
            est = lambda x: min(le(x), re(x))
        elif node.op == 'threshold':
            lo = 1.0 if lc.s_lo >= node.tau else 0.0
            est = lambda x: float(le(x) >= node.tau)
        return Cert(lo), est

    cert, est = visit(expr.root)
    gamma = audit_goodhart(est, expr, audit_set)  # 代理-真值差距
    # 单调保守：扣掉 Goodhart 差距
    return CompiledMetric(estimator=est, cert=Cert(cert.s_lo - gamma), gamma=gamma)
```

### IP-59 ACTIVE-BENCH：主动评测与预算分配
```
def active_bench(policy_set, budget_B, safety_guard, design_space, delta=0.05):
    ledger = []
    certs = {p: issue_score_cert(p, calib_set, D_sim, delta) for p in policy_set}
    for t in range(budget_B):
        # 安全门控：禁止拿安全换信息
        candidates = [xi for xi in design_space if safety_guard.allows(xi)]
        if not candidates:
            break
        # 选信息增益最大 / 最能区分候选策略的实例
        xi = max(candidates, key=lambda x: IG(x, policy_set, certs))
        outcome = run_real_trial(xi)
        ledger.append((xi, outcome))
        certs = update_certs(certs, xi, outcome)  # 收窄区间
        if meta_coverage(certs) < 1 - delta:
            return fail_closed(certs)  # 加宽或拒绝提交
    return certs, ledger
```

### IP-60 ADV-JUDGE：对抗评审自博弈
```
def adversarial_judge(policy, seed_pool, iters=100):
    adv_set = list(seed_pool)
    best_drop = 0.0
    for it in range(iters):
        # 场景变异：遮挡/时限/摩擦/光照/评分细则歧义
        base = max(adv_set, key=lambda x: score_drop(policy, x))
        xi = local_search(mutate(base), objective=lambda x: score_drop(policy, x))
        drop = score_drop(policy, xi)
        if drop > best_drop:
            best_drop = drop
            adv_set.append(xi)  # 掉分反例入名人堂
        # 策略 best response（交给课程/训练）
        policy = improve(policy, adv_set)
    s_adv = min(S(policy, xi) for xi in adv_set)  # minimax 分数下界
    return s_adv, adv_set
```

### IP-51 升级：提交门（安全 × 分数 × 排名）
```
def submit_gate(candidates, delta=0.05):
    # 1. 安全硬门槛：只允许 VALID 安全证书的策略上场
    feasible = [p for p in candidates
                if issue_safety_cert(p, calib_set, D_sim, delta).status == 'VALID']
    if not feasible:
        return safe_fallback()  # 纯安全策略，宁可低分不可熔断
    # 2. 双证书评估
    scored = []
    for p in feasible:
        sc = issue_score_cert(p, calib_set, D_sim, delta)
        rc = issue_rank_cert(p, candidates, sc, delta)
        scored.append((p, sc, rc))
    # 3. 期望分数-风险前沿：最大化 s_lo，约束 rank_hi
    best = max(scored, key=lambda t: (t[1].s_lo, -t[2].r_hi))
    return best[0]
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 可交换性/偏移越界：隐藏题库与校准集分布不符，共形覆盖失效 | 高 | 元覆盖 MC fail-closed；在线偏移监控；偏移超界即加宽或拒绝提交 |
| Goodhart 优化扭曲：代理指标刷高、真实分数下降 | 高 | IP-58 自动 Goodhart 审计；γ 扣减；冻结代理优化转人工复核 |
| 分数证书过宽无决策价值 | 高 | IP-59 主动评测收窄；仍宽则降级为相对比较/分档决策 |
| 排名证书对手模型误设：公开榜单不代表隐藏对手 | 中-高 | 只用分数证书兜底；名次区间显式加宽；标注模型假设 |
| 对抗评审过拟合 / 自博弈崩溃 | 中 | 固定种子集 + 多样性正则；留出最坏情形验证；名人堂冻结回退 |
| 主动评测拿安全换信息 | 中 | 安全门控硬约束；不安全试验直接拒绝；预算账本审计 |
| 指标代数传播过保守，复合证书失去紧致性 | 中 | E90 紧致度门槛；必要时用采样替代区间传播 |
| 评测的评测无穷回归 | 低-中 | 元覆盖只做一层，用外部独立审计集终止回归 |

## 6. 本轮最大风险

**一句话**：评测证书的核心假设是「校准集与隐藏测试集可交换、且偏移可由 ε_w 界住」，而真实竞赛的隐藏题库与评审细则恰恰是不可观测、可能被出题人主动对抗的——一旦元覆盖 MC 被高估或偏移越界，分数/排名证书会同时失去 soundness 与决策价值（要么过宽到没用，要么过窄而虚假自信），这比单纯的安全证书失效更难在赛前发现。
