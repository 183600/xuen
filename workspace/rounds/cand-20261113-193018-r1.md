# 第 69 轮（承接第 68 轮「CALM-RAS 自标定·自监督·单模型多任务风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「社会影响」×「材料选型」）

> 第 68 轮 CALM-RAS 的自陈死穴是一句话：**「标定能力越强，缓变故障越隐形」**。它把「测量可信度」建模成一个纯算法的在线潜变量 c_t 与不确定度 U(ĉ)，仿佛漂移的频谱、故障的方向、证据的来源都是给定的、与物理和社会无关的外生量。但 c_t 能否被辨识，恰恰由两件**算法之外**的事情决定：
>
> - **材料选型固定了漂移子空间 𝒟**：热膨胀、黏弹蠕变、磨损、吸湿这些漂移模态是否存在、时间常数多大、在标定空间里指向哪个方向，都是材料属性。若某材料的温漂方向恰好与「关节编码器慢零偏」这一故障方向重合，则**再好的滤波器也无法把二者分开**——这是线性代数意义上的结构性不可辨识，不是估计精度问题。材料选型因此是一次**先于标定的计量决策**，而不是采购清单上的成本项。
> - **社会影响固定了证据网络**：部署中的人、旁观者、同 fleet 的机器人本是一个分布式传感网，可提供独立于机器自身的第二观测。但从众、权威、信任这类社会影响会让报告**相关**，并制造信息级联；更隐蔽的是，机器人表现得越自信，人越信任、越少报告异常——**信任越强，故障越不被上报**。
>
> 两者是同一个「可辨识性破坏」反馈环的物理面与认知面：R68 说强标定在物理上吞掉慢故障，本轮补上：强信任在社会上吞掉慢故障。核心命题：
>
> **把「标定」从在线估计问题升级为「物理底座 × 证据网络」的联合可辨识性问题：材料选型决定漂移子空间（物理可辨识性），社会证据决定独立观测方向（认知可辨识性）；SMC-RAS 用「材料签名护照 + 材料集选型 + 社会证据去牧群 + 级联免疫 + 联合可辨识证书」让缓变故障至少被两扇相互独立的门之一挡住，并在两扇门同源时诚实降级。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我的测量凭什么可辨识、谁在替我作证**」。

## 0. 直觉与动机

**灵感 1（材料选型 → 漂移是材料的指纹，不是算法的残差）**
直觉：R68 把 Q_cal 当作一个可调标量，用热时间常数 τ_thermal≈10³ s 一笔带过。但不同材料的漂移机制截然不同：铝支架热膨胀系数约 23 ppm/K，碳纤维约 −0.5~2 ppm/K，工程塑料吸湿膨胀，软硅胶有对数蠕变，金属接触件会磨耗。它们不是同一种噪声，而是**方向各异、时间常数各异的结构化模态**。把材料漂移写成基矩阵 B_m（列＝模态，附时间常数），则「标定」就变成对**已知模态**的系数辨识，而非在无结构残差里盲压。更关键的是**材料多样性**：若两路冗余传感用热膨胀方向相反或正交的材料，共同环境（升温）在两者上留下的漂移方向不同 → 差分即可消掉；这与 R68 的算法级「同源共模抵消」（引理 15）同构，却发生在**物理层**，且不依赖网络是否训练充分。材料选型因此是设计期就能买到的可辨识性。

**灵感 2（材料选型 → 软硬材料同时是安全与社会的旋钮）**
直觉：材料不只是计量参数。软材料/柔顺外壳吸收冲击，直接决定人机接触的伤害下限；材料的质感、温度、外观又决定人的信任与接受度（「恐怖谷」不只发生在脸上，也发生在触感上：过冷、过硬、过亮都会降信任）。所以材料选型是一个**三目标**问题：计量可辨识性、物理安全、社会接受度——三者常常冲突（软材料安全但蠕变大、漂移强；硬材料干净但伤人风险高）。这正好与「社会影响」接上：材料既决定证据的物理质量，也决定人愿不愿意给证据。

**灵感 3（社会影响 → 社会是计量网络，也是牧群与级联）**
直觉：部署中，人会说「这机器今天手劲不对」「热了以后老往一边偏」。这些是机器自身测不到的**外部证据**，是免费的第二把尺。但社会影响有两张脸：
- **从众/权威**：一个人的报告会被周围人的报告拉偏（Asch 从众、Milgram 权威），于是 N 份报告的有效独立样本量远小于 N——Kish 设计效应 N_eff = N/(1+(N−1)ρ̄)；
- **信息级联**：若一个 fleet 共享标定更新，一台机器率先「宣布」某个标定值，其余机器照单全收，一个坏标定会像传言一样级联扩散。**社会网络把独立证据变成相关证据，把第二把尺悄悄变成第一把尺的复制品。**
- **信任的反身性**：机器人越自信，人越少质疑、越少报告异常 → 机器人越收不到纠错信号 → 越确信自己没错。这是「标定吞掉慢故障」的社会版：**信任吞掉慢故障**。

**灵感 4（两灵感合流 → 两扇独立的门与「同源失败」）**
直觉：缓变故障要被检出，必须至少有一路观测不与漂移子空间共线。物理门（材料多样性）给一个方向，社会门（独立社会证据）给另一个方向。若两扇门真的独立，检出概率是 1−(1−p_mat)(1−p_soc)，任何一扇打开即可；但若两扇门被**同一环境**驱动（一次热浪同时让所有材料按热膨胀漂移、一条共通传言同时污染所有人的报告），两扇门实为一扇——联合证书会在最需要它的时候高估可辨识性。这是本轮方案的原罪，也是必须诚实标注的结构性盲区。

**灵感 5（合流 → SMC-RAS 组件与对 R68 的对症）**
1. **MSP 材料签名护照**：每材料 → 漂移基 B_m、时间常数、Q_cal 先验、漂移/故障可分离证书；
2. **MSS 材料集选型**：多目标（可辨识性/安全/社会接受/成本）Pareto 选材，显式权衡「漂移秩 vs 故障可分离」；
3. **SEN 社会证据网络**：把人/旁观者/同 fleet 报告建成带社会影响项的测量模型；
4. **DHD 去牧群与来源聚类**：估计认知相关 ρ̄，按「来源簇」而非「报告数」计有效样本；
5. **CIA 级联免疫聚合**：带来源溯源与鲁棒聚合的 fleet 标定共享，阻断信息级联；
6. **JIC 联合可辨识证书**：材料可分离 × 社会独立的联合判定，三值（可辨识/部分/不可辨识），不可辨识即登记结构性盲区并保守降级；
7. **CAC† 校准式自信与审计下限**：机器人输出**校准过的**置信，并强制最小独立审计抽样，打破「越信任越瞎」的不动点；
8. **SDR 社会展示规则情绪头**：把 R66 的假笑问题升级为 P(表情 | 情绪, 社会情境) 的展示规则模型；
9. **SMC-RAS† 继承核**：CALM-RAS / RAS-WM† 全保留，COF/CFA 条件于材料护照，阈值再参数化增加材料与社会两项。

对 R68 风险对症：
- 「慢故障被标定吸收」→ 引理 16 把 R68 的「频率可分」升级为「子空间可分」：只要故障方向不在材料漂移张成的子空间内，**任意慢**的故障都留下 σ_min(P_{𝒟^⊥}A_f)‖f‖ 的残余；材料多样性可主动把 𝒟 塑形；
- 「标定越强故障越隐形」→ 材料选型在设计期就把「故障方向 ∩ 漂移子空间」压小，MSS 直接把可分离性写进目标；
- 「任务空间带病运行」→ JIC 三值证书：结构性不可辨识时不允许高置信放行，退回 λ 下限与硬降级；
- R66「情绪被社会展示规则伪装」→ SDR 显式建模社会情境，假笑 = 情境与表情的不一致。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（SMC-RAS 总览与三不变式）** SMC-RAS = (MSP, MSS, SEN, DHD, CIA, JIC, CAC†, SDR, CALM-RAS†)。三不变式：
(i) **材料护照冻结**：物理材料/装配变更必须换发新护照 B_m 与 Q_m，旧护照的标定状态禁止跨版本沿用（防止「用错材质的模型解释新机器」）；
(ii) **社会证据只进影子**：外部报告只参与影子流归因与证书，实时控制流不直接吃单条报告，须经 DHD/CIA 聚合、JIC 判决后才可影响 λ；
(iii) **结构性盲区显式化**：任何落在 `span(B_m)` 内、且无独立社会方向支撑的故障，不得被静默吸收，必须在盲区登记表（定义 310）中留痕并强制 λ 下限。

**定义 294（材料签名护照 MSP）** 对材料 m，𝒫_m = (B_m, τ_m, Q_m, 𝒮_m)。B_m ∈ ℝ^{d_r×k_m} 的列是漂移模态方向（热膨胀、蠕变、磨耗、吸湿、磁滞等），τ_m ∈ ℝ^{k_m} 为对应时间常数，Q_m 为过程噪声先验，𝒮_m 为可分离证书。物理先验：热模态方向 ∝ α_m·L·ΔT 在几何标定参数上的投影；蠕变服从对数时间律 log(1+t/τ)；磨耗单调（不可逆，与「可标定漂移」的准静态假设区隔：磨耗只可补偿不可回退）。材料先验来自数据手册 + 加速老化实验（假设 A95：τ_m 在服役温区内缓变，可由 Arrhenius 外推）。

**定义 295（材料集选型 MSS）** 设候选材料集 ℳ，传感冗余拓扑 T，选出的材料组 m⃗=(m_1,…,m_n)，联合漂移基 B(m⃗)=[B_{m_1};…;B_{m_n}]，故障灵敏度矩阵 A_f。选型是多目标优化：
max_{m⃗,T} [ ρ_drift(m⃗), κ_sep(m⃗), S_safe(m⃗), A_soc(m⃗) ] s.t. 质量/刚度/成本约束，
其中 ρ_drift = rank(B(m⃗))/dim(θ_drift)（漂移可辨识度），κ_sep 见定义 296，S_safe 为接触伤害包络（软材料↑），A_soc 为社会接受度（质感/温度/外观）。**关键取舍**：材料多样性越大，B(m⃗) 秩越高、漂移越好估；但 span(B) 也越大，可能把故障方向一并吞掉 → κ_sep 下降。选型即在「漂移秩」与「故障可分离」之间取 Pareto 前沿。

**定义 296（漂移/故障可分离指数）** 设残差生成模型 r = B(m⃗) d + A_f f + ε。标定后的算子是把 r 投影到 𝒟=span(B) 上并减去，故标定后残差
r_res = P_{𝒟^⊥} r = P_{𝒟^⊥} A_f f + P_{𝒟^⊥} ε。
定义 κ_sep(𝒟,ℱ) = σ_min(P_{𝒟^⊥} A_f) / σ_max(A_f) ∈ [0,1]。κ_sep = 0 ⇔ 存在非零故障方向完全落在漂移子空间内 ⇔ **结构性不可辨识**（与故障多慢无关）。

**定义 297（社会证据模型 SEN）** 有 J 个来源 j（人、旁观者、同 fleet 机器人），对某可测潜量（标定状态或故障指标）报告 y_j：
y_j = H_m c + s_j + b_j + η_j，
其中 H_m 由材料护照给出（同一物理量的观测矩阵），s_j 为社会影响项，b_j 为系统性偏差（社会期许：不愿说「信任的机器」坏话），η_j 为独立噪声。社会影响项：
s_j = β_c·Σ_{k∈N(j)} w_{jk}(y_k − H_m c) + β_a·(ȳ_auth − H_m c)，
β_c 为从众系数，β_a 为权威系数，ȳ_auth 为高地位来源的均值。β_c=β_a=0 即「独立观测」理想。

**定义 298（认知相关与有效样本量）** 报告对之间的平均认知相关系数 ρ̄ 由来源共享的传播路径（同家庭/同团队/同文化/同一次传言）估计。有效独立样本量按 Kish 设计效应：
N_eff = J / (1 + (J−1)ρ̄)，
社会证据的信息量 ≈ ½·log(1 + N_eff/σ_η²)。**报告数 J 不能代替来源数 N_eff**；ρ̄→1 时 N_eff→1，一千份转发等于一份。

**定义 299（来源聚类与去牧群 DHD）** 将来源按溯源图划分为簇 g，簇内相关 ρ̄_g、规模 n_g。去牧群估计先回归掉定义 297 的社会项得「独立意见」残差，再按来源簇加权：
w_j ∝ 1 / (n_{g(j)}·ρ̄_{g(j)})，
即每个来源簇总计权 ≈ 1，簇内相关越高、人数越多，单条报告权重越低。输出是聚合社会证据 ŷ_soc 及其协方差 Σ_soc。

**定义 300（级联免疫聚合 CIA）** fleet 标定更新 u_1,…,u_F 带来源证书。鲁棒聚合器
R(u) = CoordinateWiseMedian_trim(u_1,…,u_F; q)（截尾比例 q），其中来源相近的更新先按溯源聚簇去重、每簇只投一票。断点性质：单一坏来源对 R(u) 的影响 ≤ 1/k（k 为独立来源簇数）；级联被「来源去重 + 截尾中位数」双重阻断。

**定义 301（联合可辨识证书 JIC）** 记物理门检出能力 p_mat = 1[κ_sep ≥ κ_min]·h_mat(κ_sep)，社会门 p_soc = 1[N_eff ≥ N_min]·h_soc(N_eff)，两门有效相关 ρ_ms ∈ [0,1]（由环境共因与共同传言估计）。联合检出
p_joint = 1 − (1−p_mat)(1−p_soc) − ρ_ms·p_mat·p_soc，
三值判定：
- **Identifiable**：p_joint ≥ p_min ∧ ρ_ms ≤ ρ_max；
- **Partial**：仅一门有效，或 p_joint ∈ [p_low, p_min)；
- **Unidentifiable**：p_joint < p_low 或 ρ_ms ≥ ρ_max（两门同源，退化为一门），此时故障类进入盲区登记并强制 λ_floor 抬升。

**定义 302（校准式自信与审计下限 CAC†）** 机器对外置信 q̂ 须**校准**：对任意名义置信 a，实测可靠度 ≈ a（ECE ≤ ε）。设人信任 T 由 q̂ 与历史正确率驱动，异常报告概率 p_report = p_0·(1−T) + a_audit，其中 a_audit 为**强制独立审计抽样率**。纪律：a_audit ≥ a_min > 0，与 T 无关。故即使 T→1，仍至少以 a_min 的概率触发独立核查，打破「越信任越瞎」的不动点。

**定义 303（社会展示规则情绪头 SDR）** R66 的 π_face 观测升级为
π_face(expr) = Σ_e P(expr | e, social_ctx)·P(e)，
social_ctx 含观众在场、权力位势、文化规范；假笑即 P(expr | e, ctx) 与 P(expr | e, ctx=∅) 的系统偏离。归因时先除展示规则再判断情绪，避免把「礼貌性微笑」当成真实正情绪而放宽。

**定义 304（SMC 阈值再参数化）** 在 R68 定义 284 基础上叠加材料与社会两项：
τ_temporal = τ⁰_temporal·(1+κ_T·U)·(1+κ_κ·(1−κ_sep))；
τ_wm = τ⁰_wm·(1+κ_w·U)·(1+κ_s·(1−ι_soc))；
τ_risk = τ⁰_risk·(1−κ_r·U)·(1−κ_m·(1−p_mat))·(1−κ_n·(1−p_soc))；
λ_floor = max(0.6, 0.8·1[U>τ_cal ∨ κ_sep<κ_min ∨ ι_soc<ι_min ∨ JIC=Unidentifiable])。
语义：任一扇门失守（材料或社会）都只导向更保守，绝不放宽。

**定义 305（SMC-RAS 联合目标）** 在 L_ssl + L_MT 上增加：
- L_soc = Σ_j w_j·‖y_j − H_m ĉ‖²_{Σ_j}（去牧群后的社会一致性，权重来自 DHD）；
- L_disp = KL(π_face ‖ π_disp(e, ctx))（展示规则解耦）；
- L_pass = Σ_m ‖B_m − B̂_m‖²（护照与实测漂移基的一致性，防护照错配）。
材料选型目标见定义 295，与学习目标解耦（前者离线、后者在线）。

**定义 306（级联动力学）** 设来源信念 b_i(t)∈ℝ，影响矩阵 W（行随机），更新 b(t+1)=αWb(t)+(1−α)b_prior+noise。级联阈值：当谱半径 α·ρ(W) 与从众 β_c 使「私人信号权重」被压到 0 时，社会进入信息级联，公共信念与真相脱钩。CIA 的溯源去重等价于把 W 降秩为「每簇一票」，将 ρ(W) 压回 1 附近。

**定义 307（SMC-AIC 干扰集）** ℰ_SMC = ℰ_CALM × ℰ_mat × ℰ_soc × ℰ_casc；
ℰ_mat = {护照错配, 材料多样性不足, 未建模老化模态}；
ℰ_soc = {从众污染, 权威操控, 信任塌缩}；
ℰ_casc = {坏源级联, 来源伪独立（同源伪装成多源）}。

**定义 308（J_SMC 证书）** J_SMC = (J_CALM, material_set_hash, B_m_version, κ_sep, provenance_graph_hash, N_eff, ρ̂_ms, a_audit, jic_verdict)。Valid ⇔ Valid(J_CALM) ∧ B_m 版本匹配 ∧ jic_verdict ≠ Unidentifiable（或已登记盲区并 λ 抬升）∧ a_audit ≥ a_min。

## 3. 推导

**引理 16（材料可分离界——慢故障的残余下界）** 设标定算子将残差投影到材料漂移子空间 𝒟=span(B(m⃗)) 上并减去。则对任意故障幅度 f，标定后残差 r_res = P_{𝒟^⊥}A_f f + P_{𝒟^⊥}ε，故 ‖r_res‖ ≥ σ_min(P_{𝒟^⊥}A_f)·‖f‖ − ‖P_{𝒟^⊥}ε‖。若 κ_sep = σ_min(P_{𝒟^⊥}A_f)/σ_max(A_f) > τ_det/‖f‖，则**无论故障多慢**都被检出。系：R68 的引理 13 用「频率可分（ω_f ≥ 3ω_cal）」排除慢故障，本引理改用「子空间可分」，**把 R68 的结构性盲区从『慢』移到『方向』**——方向可分离的慢故障不再隐形；反之方向重合的快故障依旧隐形，须靠社会门/绝对溯源。

**引理 17（社会证据设计效应）** 在定义 297 模型下，若报告间平均认知相关为 ρ̄，则聚合估计的方差 ∝ σ_η²·(1+(J−1)ρ̄)/J，有效样本量 N_eff = J/(1+(J−1)ρ̄)。故社会证据的信息增益 ≈ ½log(1+N_eff/σ_η²)，随 J 饱和于 ≈½log(1+1/(ρ̄σ_η²))。系：**增加报告数而不降低 ρ̄（来源多样性）是无效的**；去牧群/RHD 的本质是把 ρ̄ 压回来源簇间的真实相关。

**引理 18（两扇门的联合检出与同源退化）** 设物理门、社会门各自以概率 p_mat、p_soc 给出独立于漂移子空间的观测方向，二者有效相关 ρ_ms。则联合检出
p_joint = 1 − (1−p_mat)(1−p_soc) − ρ_ms·p_mat·p_soc。
ρ_ms=0 时 p_joint = 1−(1−p_mat)(1−p_soc)（任一扇即可）；ρ_ms→1 时 p_joint→max(p_mat,p_soc)，**第二扇门完全失效**。系：JIC 必须在 ρ_ms 高时报 Unidentifiable，而不是在 p_mat/p_soc 单看都还好时报 Identifiable。

**定理 16（信任—可观测不动点与审计下限）** 设人信任 T 随机器人置信 q̂ 单调上升，异常报告概率 p_report = p_0(1−T)+a_audit。若 a_audit=0，则映射 T↦p_report↦T 存在稳定不动点 T*=1、p_report*=0：系统在「越自信→越被信任→越无报告」中收敛到「自以为正确却无人纠错」的静默失效。若 a_audit ≥ a_min>0，则 p_report ≥ a_min 对所有 T 成立，不存在 p_report=0 的不动点；只要 a_min ≥ 1−(1−ε_det)^{1/n_fault}，慢故障在 n_fault 个审计周期内被独立核出的概率 ≥ ε_det。**强制审计是打破社会静默的唯一结构性手段。**

**定理 17（级联免疫界）** 在定义 306 的信念动力学下，若来源被正确聚为 k 个独立簇、CIA 每簇一票且采用截尾中位数，则任意单一被污染来源簇对聚合标定更新的影响 ≤ 1/k；当 k ≥ k_min 时，坏标定被接受的概率 ≤ 1−(1−r_det)^k（r_det 为单簇检出率），信息级联被阻断。反之，若「来源伪独立」（同源伪装为多源），有效 k 被高估，界失效——这直接呼应定义 307 的 ℰ_casc，是 CIA 的死穴。

**定理 18（SMC-RAS 端到端风险一致性）** 在 R68 A87–A94 与新增 A95–A97（材料护照可信、来源溯源可信、社会影响项可估）下，输出 τ_cmd 满足：
1. P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+**α_mat+α_soc+α_casc**，其中 α_mat 由引理 16 限制（κ_sep 高则小），α_soc 由引理 17 限制（N_eff 高则小），α_casc 由定理 17 限制（k 高则小）；
2. JIC=Unidentifiable ⇒ λ_floor=0.8 ∧ τ_risk 收紧 ∧ k 收缩 ∧ 盲区登记——测量与证据都不可辨识时永远收缩；
3. κ_sep ≥ κ_min 时，任意慢故障的检出概率不随「标定强度」下降（引理 16），R68 的「标定越强故障越隐形」在可分离子空间内被结构性阻断；
4. a_audit ≥ a_min ⇒ 社会静默失效概率 ≤ (1−ε_det)^{⌊T/a_min⌋}（定理 16）。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** SMC-RAS = (MSP, MSS, SEN, DHD, CIA, JIC, CAC†, SDR, CALM-RAS†)。不变式：材料护照冻结（换护照即作废旧标定）；社会证据只进影子；结构性盲区显式登记、禁止静默吸收。

**定义 294（材料签名护照 MSP）** `𝒫_m=(B_m,τ_m,Q_m,𝒮_m)`；热模态 ∝ α_m·L·ΔT 在几何参数上的投影，蠕变对数时间律，磨耗单调不可逆。先验来自手册 + 加速老化（A95：τ 可用 Arrhenius 外推）。

**定义 295（材料集选型 MSS）** `max_{m⃗,T}[ρ_drift, κ_sep, S_safe, A_soc]` s.t. 质量/刚度/成本。核心取舍：材料多样性↑⇒B 秩↑（漂移好估）但 span(B)↑（可能吞掉故障）⇒κ_sep↓。选型取 Pareto 前沿。

**定义 296（可分离指数）** 残差 `r=B(m⃗)d+A_f f+ε`；标定后 `r_res=P_{𝒟^⊥}A_f f+P_{𝒟^⊥}ε`；`κ_sep=σ_min(P_{𝒟^⊥}A_f)/σ_max(A_f)`。`κ_sep=0` ⇔ 故障方向完全落入 𝒟 ⇔ 结构性不可辨识（与故障多慢无关）。

**定义 297（社会证据模型 SEN）** `y_j=H_m c+s_j+b_j+η_j`，`s_j=β_cΣ_{k∈N(j)}w_{jk}(y_k−H_m c)+β_a(ȳ_auth−H_m c)`。β_c=β_a=0 即独立观测理想。

**定义 298（认知相关与有效样本）** `N_eff=J/(1+(J−1)ρ̄)`；信息量 ≈½log(1+N_eff/σ_η²)。报告数不能代替来源数。

**定义 299（去牧群 DHD）** 溯源聚簇 g，权重 `w_j∝1/(n_{g(j)}·ρ̄_{g(j)})`，每簇总权≈1；输出 ŷ_soc 与 Σ_soc。

**定义 300（级联免疫 CIA）** 每簇一票 + 截尾中位数 `R=CoordMedian_trim(u;q)`；单一坏源影响 ≤1/k，断点性质由截尾比例 q 给出。

**定义 301（联合可辨识 JIC）** `p_mat=1[κ_sep≥κ_min]·h_mat`，`p_soc=1[N_eff≥N_min]·h_soc`，`p_joint=1−(1−p_mat)(1−p_soc)−ρ_ms·p_mat·p_soc`；Identifiable（p_joint≥p_min∧ρ_ms≤ρ_max）/ Partial / Unidentifiable（p_joint<p_low∨ρ_ms≥ρ_max→登记盲区+λ floor）。

**定义 302（校准式自信 + 审计下限 CAC†）** 对外置信 q̂ 校准（ECE≤ε）；`p_report=p_0(1−T)+a_audit`，`a_audit≥a_min>0` 且与 T 无关 ⇒ 无 p_report=0 不动点。

**定义 303（社会展示规则 SDR）** `π_face(expr)=Σ_e P(expr|e,social_ctx)P(e)`；假笑 = 情境与表情的系统偏离，先除展示规则再判情绪。

**定义 304（SMC 阈值再参数化）** 在 CAR 上叠加材料/社会项：`τ_temporal=τ⁰(1+κ_T U)(1+κ_κ(1−κ_sep))`、`τ_wm=τ⁰_wm(1+κ_wU)(1+κ_s(1−ι_soc))`、`τ_risk=τ⁰_r(1−κ_rU)(1−κ_m(1−p_mat))(1−κ_n(1−p_soc))`、`λ_floor=max(0.6,0.8·1[U>τ_cal∨κ_sep<κ_min∨ι_soc<ι_min∨JIC=Unidentifiable])`。

**定义 305–306（联合目标 / 级联动力学）** L_soc 去牧群一致性 + L_disp 展示规则解耦 + L_pass 护照一致性；级联 `b(t+1)=αWb(t)+(1−α)b_prior+noise`，谱半径与私人信号权重归零即进入级联，CIA 溯源去重把 W 降秩。

**定义 307–310（干扰集 / 证书 / 管线 / 盲区表）** `ℰ_SMC=ℰ_CALM×ℰ_mat×ℰ_soc×ℰ_casc`；`J_SMC=(J_CALM,material_set_hash,B_m_version,κ_sep,provenance_hash,N_eff,ρ̂_ms,a_audit,jic_verdict)`；离线护照/选型→在线标定/去牧群/判决/审计；盲区表 `blind(m⃗,h)` 随版本链冻结，仅绝对溯源或主动探针可消解。

class MaterialPassport:
    def __init__(self, material):
        self.B   = self._drift_basis(material)        # 热/蠕变/磨耗/吸湿 模态
        self.tau = self._time_constants(material)
        self.Q   = self._process_prior(material)
    def separability(self, fault_basis):
        return sigma_min(null_space(self.B) @ fault_basis) / sigma_max(fault_basis)

def select_material_set(candidates, faults, constraints):
    front = []
    for combo in subsets(candidates):
        B, obj = vstack([m.B for m in combo]), None
        if feasible(combo, constraints):
            obj = (rank(B)/dim_theta, MaterialPassport.separability_of(B, faults),
                   safety(combo), social_accept(combo))
            front = pareto_insert(front, obj, combo)
    return front      # 交设计者按任务风险挑点；盲区随组合签发

# IP-255/256 SEN + DHD（异步）
class SocialEvidenceNetwork:
    def deherd(self, reports, provenance, beta_c, beta_a):
        y = np.array([r.value for r in reports])
        groups = cluster_by_provenance(provenance)
        y_ind = residualize_social(y, beta_c, beta_a)       # 回归掉从众/权威
        rho_bar = estimate_epistemic_corr(y, groups)
        w = {j: 1.0/(len(groups[g(j)]) * rho_bar[g(j)]) for j in range(len(y))}
        N_eff = len(y) / (1 + (len(y)-1)*mean(rho_bar.values()))
        return weighted_mean(y_ind, w), N_eff, rho_bar

# IP-257 CIA（异步，fleet 共享标定）
def cascade_immune_aggregate(updates):
    updates = one_vote_per_provenance_cluster(updates)      # 同源只投一票
    return coordinatewise_trimmed_median(updates, q=0.25)   # 坏源影响 <= 1/k

# IP-258 JIC（三值判定）
def joint_identifiability(passport, faults, soc):
    p_mat = 1.0 if passport.separability(faults) >= KAPPA_MIN else 0.0
    p_soc = 1.0 if soc.N_eff >= N_MIN else 0.0
    rho_ms = estimate_common_cause(passport.env_trace, soc.provenance_graph)
    p_joint = 1 - (1-p_mat)*(1-p_soc) - rho_ms*p_mat*p_soc
    if p_joint >= P_MIN and rho_ms <= RHO_MAX: return 'Identifiable', p_joint
    if p_joint >= P_LOW:                        return 'Partial', p_joint
    return 'Unidentifiable', p_joint            # -> register_blindspot + lambda floor

# IP-259 CAC†：校准式自信 + 审计下限
class CalibratedConfidenceAuditor:
    def step(self, q_hat, reliability, trust_T, dt):
        q_hat = conformal_calibrate(q_hat, reliability)          # ECE <= eps
        a = max(A_MIN, self.base_audit)                          # 与 trust 无关
        if self.rng.rand() < a: self.request_audit_probe()       # 强制独立核查

## 4. 推导

**引理 16（材料可分离界——慢故障残余下界）** 标定算子把残差投影到 𝒟=span(B) 上并减去，故 `r_res=P_{𝒟^⊥}A_f f+P_{𝒟^⊥}ε`，`‖r_res‖≥σ_min(P_{𝒟^⊥}A_f)‖f‖−‖P_{𝒟^⊥}ε‖`。κ_sep 足够大时**任意慢**故障均被检出。系：R68 引理 13 依赖「频率可分（ω_f≥3ω_cal）」，本引理改用「子空间可分」，把 R68 的结构性盲区从「慢」移到「方向」——方向可分的慢故障不再隐形；方向重合的快故障仍隐形，须靠社会门/绝对溯源。

**引理 17（社会设计效应）** `Var(ŷ_soc)∝σ_η²(1+(J−1)ρ̄)/J`，`N_eff=J/(1+(J−1)ρ̄)`；信息增益 ≈½log(1+N_eff/σ_η²)，随 J 饱和。系：不降 ρ̄ 而加报告数无效；去牧群本质是把 ρ̄ 压回来源簇间真实相关。

**引理 18（两门联合检出与同源退化）** `p_joint=1−(1−p_mat)(1−p_soc)−ρ_ms·p_mat·p_soc`。ρ_ms=0 时任一门即可；ρ_ms→1 时 p_joint→max(p_mat,p_soc)，第二门失效。系：JIC 必须在 ρ_ms 高时报 Unidentifiable，而非只看 p_mat/p_soc。

**定理 16（信任—可观测不动点与审计下限）** `p_report=p_0(1−T)+a_audit`。a_audit=0 时存在稳定不动点 T*=1、p_report*=0（越自信→越被信任→越无报告→越确信），静默失效。a_audit≥a_min>0 ⇒ p_report≥a_min，无 p_report=0 不动点；a_min 足够大时慢故障在有限审计周期内被独立核出概率 ≥ ε_det。**强制审计是打破社会静默的唯一结构性手段。**

**定理 17（级联免疫界）** 定义 306 信念动力学下，正确聚为 k 个独立来源簇、每簇一票、截尾中位数聚合 ⇒ 单一坏源簇对标定更新影响 ≤1/k；k≥k_min 时坏标定接受概率 ≤1−(1−r_det)^k，级联被阻断。「来源伪独立」高估 k 则界失效（ℰ_casc 死穴）。

**定理 18（SMC-RAS 端到端风险一致性）** A87–A94 + A95–A97 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_mat+α_soc+α_casc`（分别由引理 16/17/定理 17 限制）；
2. `JIC=Unidentifiable ⇒ λ_floor=0.8 ∧ τ_risk 收紧 ∧ k 收缩 ∧ 盲区登记`；
3. `κ_sep≥κ_min ⇒ 任意慢故障检出概率不随标定强度下降`——R68「标定越强故障越隐形」在可分离子空间内被结构性阻断；
4. `a_audit≥a_min ⇒ 社会静默失效概率 ≤ (1−ε_det)^{⌊T/a_min⌋}`。

## 7. 本轮最大风险

**一句话**：材料多样性与社会独立性都可能被同一环境同源驱动（一次热浪让所有材料按热膨胀方向漂移、一条共通传言让所有报告趋同），使设计中的「两扇独立的门」退化为同一扇——联合可辨识证书会在最危险的环境里给出最乐观的判定，让系统带着「我已双重验证」的确信失去对缓变故障的最后感知。

**次级风险与缓解**：
1. **护照错配/老化模态未建模** → B_m 版本冻结 + L_pass 实测一致性 + 换护照作废旧标定；
2. **材料多样性吞掉故障方向** → MSS 显式 Pareto（ρ_drift vs κ_sep），盲区随组合签发；
3. **来源伪独立高估 k** → 溯源图审计 + JIC 的 ρ_ms 估计 + 可疑聚类降权；
4. **审计下限的隐私/成本代价** → a_min 按风险分级（高风险任务高 a_min），抽样而非全量；
5. **展示规则估计的文化偏差** → 分域校准 + 归因时保留 context-agnostic 上界，只收紧不放宽。
