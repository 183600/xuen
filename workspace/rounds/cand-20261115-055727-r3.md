# 第 4 轮（灵感循环第 4 轮；本轮灵感：「群体智能」×「行为克隆」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。群体与模仿各沿一条轴升级 InstructGauge，且任一环节不可用都必须能逐级退回；群体和 BC 是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（群体智能 → 并行的「证伪」，而不是并行的「投票」）**
直觉：单个探测器会被遮挡、反光、盲区卡住；多个视角、多种模态能互相补盲。但「多」本身不产生真理：若所有探测器看到的是同一个伪影，它们会一致地错。群体智能真正有用的机制不是把信念平均，而是**从不同方向尝试证伪同一批假设**——信息素（stigmergy）式地只把「环境锚定的回执」留在共享场里，后来者据此排除假设。共识应是**未被证伪的假设交集**，不是信念的多数票。直觉口号：**共享观测，不共享结论。**

**灵感 2（行为克隆 → 廉价的提议先验，不是权威）**
直觉：人类示范能把「先看哪里、先动哪个工具」的先验一次性灌进来，省掉大量探索。但 BC 学的是「专家怎么做」，不是「为什么对」；它无法自报 OOD，离线误差还会随步数二次累积（`O(T²ε)`），在高斯偏移下会自信地走进专家从未去过的状态。因此 BC 的正确位置是**候选生成器**：它只改变「先试什么」，绝不进入「什么算被证实」的判定。直觉口号：**模仿只改提议，不改证据。**

**灵感 3（两者耦合 → 克隆单文化是最危险的失效）**
直觉：把一群行为克隆代理放进群体，看似既有并行又有先验，实际它们共享同一份示范、同一个解释器、同一批盲区：**错误从独立变成相关**。独立误差可被证伪/投票压小，相关误差却有不可消除的地板 `ρ`——加再多同源克隆，也只是把同一个错误复述 n 遍。更隐蔽的是「共同沉默」：专家从未探测过的判别特征，所有克隆都不会去测，于是错误假设因**没被检验**而存活，系统把「无证据」误读成「有证据」。解法不是禁用群体或克隆，而是三根结构支柱：**克隆商**（按独立来源而非代理数计票）、**证伪共识 + 否决法定人数**（淘汰假设需要多个独立见证类）、**检验严酷性**（只有通过一个本可以证伪它的测试才允许接受），再叠加 **BC 信任域**、**多样性下限** 与 **分工覆盖**。

## 1. 研究问题（本轮要回答什么）

- **Q1（模仿的安全性）**：BC 能否只作提议先验而不成为裁决权威？在什么条件下它不扩张能力、也不制造「未测即真」的虚假确证？
- **Q2（群体的真理性）**：增加代理何时真正降低错误？错误削减取决于代理数量，还是**独立见证类数 / 有效多样性**？共识何时退化为相关性的复述？
- **Q3（耦合的放大效应）**：BC 造成的克隆单文化是否会同时相关化「提议」与「探测选择」，从而击穿群体误差削减？结构（克隆商、否决法定人数、严酷性、信任域、多样性下限、分工覆盖）能否把误差重新压回有界，并优雅退化？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P1 提议–裁决分离（Proposal–Adjudication Separation）**
BC（以及第 3 轮的自然语言）只能生成候选、重排先验；接受谓词只读**环境锚定回执**与硬约束。形式化方向：`Accept ⫫ π_BC | (F, T₀, M_phys)`，且 `Plan_BC ⊆ Plan_ToolGauge`。这把「模仿」关进类型系统，与第 3 轮「语言只改偏好、不改能力」同构。

**P2 独立见证与克隆商（Independent Witness & Clone Quotient）**
计票单位是**见证类**而不是代理：共享数据源/种子/解释器/提议分布的代理归为同一类，`n_eff = |S/~_cl|`。群体只在 `n_eff` 足够且多样性 `Div ≥ D_min` 时才允许提交，否则退化为单代理。信息素回执场只追加可复核观测——**共享观测，不共享结论**。

**P3 证伪式共识与检验严酷性（Falsification Consensus & Test Severity）**
共识 = 未被证伪的假设交集 `H_∩`，不是信念多数；淘汰假设需 `q ≥ f+1` 个独立见证类的否决（抗 `f` 个拜占庭类）。只有 `|H_∩| = 1` 且该假设通过过「本可证伪它」的严酷检验（`Sev ≥ 1-β`）才提交；否则弃权并主动探测。**弃权是安全动作，不是失败。**

## 3. 与基线的接口（如何退化）

- BC 在信任域外 / OOD / 无示范 ⇒ 关闭 BC，退回第 3 轮 InstructGauge 的主动探测提议；
- 克隆商 `n_eff < q` / 多样性 `Div < D_min` / 独立性证书不足 ⇒ 禁止群体提交，退化单代理 InstructGauge；
- 否决法定人数不足 ⇒ 弃权并主动探测（不猜）；预算耗尽 ⇒ 退回 ToolGauge 逐步；
- 群体块证书 SCC 不通过 / 跨不可逆屏障缺独立见证 ⇒ 强制 `K=1` 逐步；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样；新组件全部为可选增强。

## 4. 预期贡献

1. 一个「模仿只提议、回执才裁决」的接口，把 BC 从策略权威降为候选先验，并给出能力不扩张的证明；
2. 一个以**克隆商 + 否决法定人数 + 证伪交集**为核心的群体共识口径，显式给出相关误差地板，说明「更多同源克隆不产生更多真理」；
3. 一个**检验严酷性 + 分工覆盖**机制，堵住「共同沉默 / 未测即真」这一 BC×群体最隐蔽的失效；
4. 一条完整可证伪路径：E457–E472 覆盖信任域、克隆相关地板、拜占庭回执、共识健全性、多样性拒绝、分工覆盖、严酷性、不可逆屏障、异步时序与 sim→real。

## 5. 本轮最大风险

**一句话**：行为克隆会让群体「一致」而不是「知道」——克隆单文化同时相关化提议与探测选择，使系统可以既自信又错误（或自信地一无所知），而每个个体看上去都校准良好；结构只能缓解，无法从根上消除「用于检测相关性的多样性估计本身也可能被同一单文化污染」这一循环依赖。

## 2. 形式化定义（要点）

**定义 448（见证群体 S）** `S = {(π_i, ω_i, m_i)}_{i=1}^{n}`：`π_i` 为局部探测/提议策略，`ω_i` 为见证身份（数据源、随机种子、解释器版本），`m_i` 为模态-工具签名。群体允许异步增删，但增删**只在 `q_quiesce`（定义 439）生效**，避免任一块观察到混合群体契约。

**定义 449（BC 提议先验与仅提议公理 PA）** `π_BC(·|s;D)` 为由示范集 `D` 训练的候选分布。**PA**：候选集可含 `supp π_BC`，但接受谓词只依赖回执场与硬约束，且 `Accept ⫫ π_BC | (F, T₀, M_phys)`。能力闭包：`tools(supp π_BC) ⊆ T₀`、`mag(supp π_BC) ⊆ M_phys`。BC 不产生回执，也不参与证伪。

**定义 450（克隆等价与有效见证类）** `i ~_cl j` 当且仅当 `src_i ∩ src_j ≠ ∅`（共享数据/种子/架构/解释器）或 `TV(π_i, π_j) ≤ ε_cl`。`n_eff = |S/~_cl|`。计票与独立性检查一律以类为单位；同类成员的多条回执**不增加**独立信息。

**定义 451（信息素回执场 F）** 只追加有序集合 `F`，`r = (id, ω, m, t, pose, meas, hash, sig, src)`。写约束 `write(F) ⊆ Receipt`，即**禁止写入 belief / score / conclusion**；读端在本地重算信念。`F` 可被任意第三方沿 hash 链复核。这是「共享观测，不共享结论」的机制化。

**定义 452（证伪算子与生存集）** `Ref(r,h) ∈ {0,1}` 表示回执 `r` 与假设 `h` 是否不相容（由可测谓词判定，非自然语言）。`H_∩(F) = {h ∈ H₀ : ∀r∈F, Ref(r,h)=0}`。共识是**保守交集**：加回执只会缩小，不会扩大。

**定义 453（否决法定人数 q 与容错生存集）** `veto_q(h) = |{ [i] ∈ S/~_cl : ∃r ∈ F_{[i]}, IC(r) ∧ Ref(r,h)=1 }|`；`H_∩^{(q)}(F) = {h ∈ H₀ : veto_q(h) < q}`。淘汰 `h` 需至少 `q` 个**独立见证类**的证伪；单个代理、或同一克隆群说「假」不足以淘汰。

**定义 454（独立性证书 IC）** `IC(r)` 断言：`src(r)` 与本轮计票的其它回执不共享数据源、模态伪影、克隆解释器，且 `hash/sig` 可复算。`IC` 把「独立性」变成**可审计属性**而非隐含假设；缺证回执可留作解释，但不计否决票。

**定义 455（检验严酷性 Sev）** `Sev(h,F) = 1 - β̂(h,F)`，`β̂` 为「当 `h` 为假时 `F` 仍未证伪 `h`」的估计概率（检验功效之补）。接受要求 `Sev(h,F) ≥ 1-β`：必须存在一个在 `h` 为假时以 `≥1-β` 概率将其证伪的检验，而 `h` 通过了它。这是「无证据」与「证据表明无」的分界。

**定义 456（BC 信任域 T_BC）** `T_BC = {s : d_OOD(s;D) ≤ δ_bc ∧ mismatch(s) ≤ γ}`，其中 `mismatch` 为学习策略与示范策略的占用分布 TV 距离。仅当 `s ∈ T_BC` 时 BC 提议可入候选；否则关闭 BC，转主动探测。理由：BC 复合误差 `O(T²ε)`，主动探测 `O(Tε)`（引理 64）。

**定义 457（有效多样性 Div）** `Div(S) = 1 - (2/(n(n-1))) Σ_{i<j} agreeProbe(π_i, π_j)`，`agreeProbe` 为在同一判别特征对上的探测选择一致率（按见证类加权）。`Div` 度量**探测选择**的多样性，不是动作噪声；`Div < D_min` ⇒ 禁止群体提交。

**定义 458（分工覆盖 DoL）** 判别特征集 `D_feat = {d_1…d_m}`；`Cov([i]) ⊆ D_feat` 为见证类 `[i]` 可执行的判别测试。分工 `σ ⊆ S/~_cl` 满足 `∪_{[i]∈σ} Cov([i]) = D_feat`（或加权覆盖 `≥ 1-ε_cov`）。**未被覆盖的判别特征不得计入「已排除」**——它正是「共同沉默」的入口。

**定义 459（群体块证书 SCC）** `SCC(C,F) = (CVC(C), H_before, H_after, W, Sev, σ)`，要求：(i) 每步 CVC（定义 435）通过；(ii) `H_after ⊆ H_before` 且 `H_after = H_∩^{(q)}(F_after)`；(iii) `W` 含 `≥2` 个不同模态且带 `IC` 的见证类；(iv) 跨不可逆动作时另有 `q_irr` 个独立见证类的**事前**回执；(v) `σ` 覆盖无空洞。

**定义 460（自适应否决人数）** `q(ρ̂,f) = f + 1 + ⌈g(ρ̂)⌉`，`g` 单调不减且 `0 ≤ g(ρ̂) ≤ n_eff - f - 1`。`ρ̂` 为共同模式相关估计（定义 461）。若 `q > n_eff` ⇒ 无可行群体提交，降级/弃权。

**定义 461（共同模式相关模型）** 隐变量 `Z ∈ {0,1}`，`P(Z=1)=ρ`；`Z=1` 时同源见证类共同犯错（共享盲区/先验错误），`Z=0` 时各见证类独立犯错。`ρ̂` 的可测代理 = 克隆群内「提议选择 + 证伪选择」一致率超出独立基线的部分。该模型给出误差地板（引理 62）。

**定义 462（单点提交规则）** 提交 `ĥ` 当且仅当 `H_∩^{(q)}(F) = {ĥ}` 且 `Sev(ĥ,F) ≥ 1-β` 且 `σ` 覆盖完整 且 `SCC` 通过 且 `Div ≥ D_min`。否则**弃权并请求主动探测**。弃权是安全动作，不是失败。

**定义 463（群体审计证书）** `SwarmCert(s) = (S/~_cl, F|_s, σ, q, ρ̂, H_before, H_after, Sev, SCC, claims)`；把第 3 轮 `RepairCert′` 的「指令→块→回执→主张」四级链扩展为「群体→见证类→独立回执→证伪交集→单点提交」。

    uf = UnionFind(len(S))
    for i, j in itertools.combinations(range(len(S)), 2):
        if shares_source(S[i], S[j]) or tv(S[i].pi, S[j].pi) <= EPS_CL:
            uf.union(i, j)
    return uf.groups()                                 # n_eff = len(groups)

# IP-330 STIG：只追加环境锚定的回执，禁止写结论
def stig_write(F, r):
    assert r.hash == recompute_hash(r) and verify_sig(r)
    assert not has_field(r, "belief")                  # 共享观测，不共享结论
    F.append(r)

# IP-331 FQA：证伪式否决仲裁
def survive(F, H0, q):
    H = set(H0)
    for h in list(H):
        classes = {r.omega_class for r in F if IC(r) and Ref(r, h)}
        if len(classes) >= q:                          # 仅独立见证类计票
            H.discard(h)
    return H

# IP-332 DoL：判别特征覆盖（贪心 H(m) ≤ ln m + 1）
def division_of_labor(classes, D_feat):
    chosen, covered = set(), set()
    while covered != D_feat:
        best = max(classes, key=lambda c: len(c.cover - covered))
        if not (best.cover - covered):
            return None                                # 覆盖有空洞 ⇒ 不可提交
        chosen.add(best); covered |= best.cover
    return chosen

# IP-334 DG：多样性守卫 + 自适应法定人数
def quorum_gate(S, f, rho_hat):
    n_eff = len(witness_classes(S))
    q = f + 1 + adaptive_margin(rho_hat)               # 定义 460
    div = effective_diversity(S)                       # 定义 457
    if n_eff < q or div < DIV_MIN:
        return None                                    # 无群体提交 ⇒ 降级单代理
    return q, div

# IP-333 SCC：群体块证书（在 CVC 之上）
def swarm_commit(C, env, F, q, q_irr):
    cvc = CVC().commit(C, env, iota=None)              # 第 3 轮定义 435
    if crosses_irreversible(cvc) and distinct_witnesses(F, cvc) < q_irr:
        return ABSTAIN
    H_before = current_surviving(F)
    H_after = survive(F, H_before, q)
    if not H_after <= H_before:                        # 必须单调收缩
        return ABSTAIN
    if not (cross_modal(F, k=2) and coverage_complete(F)):
        return ABSTAIN
    return SCC(cvc, H_before, H_after, witnesses(F), severity(H_after, F))

# IP-335 SwarmGauge-8C 闭环
def swarmgauge_8c(M, s):
    iota = M.nlib.ground(M.ell, M.scene, M.ontology) or M.default_iota
    props = M.bcp.propose(s, M.H[s], M.budget_left(s)) # 仅候选
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota, props)
    C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
    if M.mreg.is_quiescent(s):
        gate = quorum_gate(M.swarm, M.f, M.rho_hat)
        if gate is None:
            return M.instructgauge_7c(M, s, M.ell)     # 降级单代理
        q, _ = gate
        cert = swarm_commit(C, M.env, M.field, q, M.q_irr)
        if cert is ABSTAIN:
            return request_active_probe(s)             # 弃权，不猜
    else:
        q = M.default_q
        cert = M.cvc.commit(C, M.env)                  # 块边界外沿用第 3 轮
    for r in cert.receipts:
        stig_write(M.field, r)                         # 只共享回执
    H_after = survive(M.field, H, q)
    if len(H_after) == 1 and severity_ok(H_after, M.field):
        commit(singleton(H_after))
    else:
        request_active_probe(s)
    M.swarm.retire_at_quiescence()                     # 增删代理只在静默点
    return True

# IP-335 主闭环（50Hz 路径不变）
def SwarmGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(swarmgauge_8c, M, s)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 59（仅提议公理与能力不扩张）** 在 PA（定义 449）与能力闭包下，`Plan_BC ⊆ Plan_ToolGauge`，且 BC 不能直接触发执行器。*证明*：接受谓词只依赖 `(F, T₀, M_phys)`，与 `π_BC` 条件独立；候选先经 `tools ⊆ T₀, mag ⊆ M_phys` 过滤；故被接受计划必属 ToolGauge 可行集。直接触发需绕过 `Accept`，与 PA 矛盾。

**引理 60（证伪健全性 / 真假设不被误杀）** 若所有回执真实（`∀r, Ref(r,h*)=0`），则 `h* ∈ H_∩(F)`；若至多 `f` 个见证类为拜占庭且 `q ≥ f+1`，则 `h* ∈ H_∩^{(q)}(F)`。*证明*：真实回执不证伪 `h*`；伪回执只能来自 `≤f` 个类，贡献 `< q` 张否决票；故 `veto_q(h*) < q`。

**引理 61（单点提交正确性）** 若 (i) `q ≥ f+1`；(ii) 对每个 `h ≠ h*`，存在 `≥q` 个真实独立见证类最终将其证伪；则只要 `|H_∩^{(q)}(F)| = 1`，该唯一元素就是 `h*`。*证明*：由引理 60，`h*` 始终存活；其余假设按 (ii) 被剔除；故唯一幸存者必为 `h*`。这给出「共识=真理」的充分条件——它要求的是**独立证伪的覆盖**，而非代理数量。

**引理 62（克隆相关地板 / 更多克隆 ≠ 更多真理）** 在定义 461 的共同模式模型下，设独立见证类数为 `n_eff`、共同模式概率为 `ρ`。对任何仅基于回执的对称聚合，错误概率满足 `P(err) ≥ ρ·1[聚合不能区分 Z] + (1-ρ)·BinomTail(n_eff, p')`；当 `n_eff → ∞` 时地板为 `ρ`。若把同源克隆拆成 `n` 个代理但 `n_eff` 不变，则误差不减；克隆回执的边际否决信息为 0。*证明*：`Z=1` 时所有同源类同时错，回执无法区分；`Z=0` 时独立项随 `n_eff` 下降；克隆共享同一 `Z` 与同一 `Ref` 结果，故不改变任何 `veto_q`。推论：**降低 `ρ` 与提高 `n_eff` 是仅有的两条降错路径**——这正是克隆商与多样性守卫的动机。

**引理 63（交集单调性与覆盖代价）** 对 `F ⊆ F'`，`H_∩(F') ⊆ H_∩(F)` 且 `H_∩^{(q)}(F') ⊆ H_∩^{(q)}(F)`。故真实回执越多，误提交风险单调不增；但弃权率单调不减（集合收缩到单点更难）。独立判别回执的边际收缩 `> 0`，克隆回执的边际收缩 `= 0`。*证明*：交集对集合包含单调；克隆回执的 `Ref(·,h)` 与已有同类回执相同，不改变任何 `veto_q`。

**引理 64（BC 协变量漂移界与信任域）** 设单步模仿误差 `ε`、TV 占用失配 `γ`、时域 `T`。在线/主动修正下期望代价 `O(Tε)`；纯离线 BC 的复合误差 `O(T²ε)`。在 `T_BC` 内 `γ ≤ γ₀` 时代价 `≤ T(ε + γ₀)`；一旦 `s ∉ T_BC` 立即切主动探测，可把二次项截断在信任域边界。*证明*：标准 DAgger 占用测度 telescoping；每步失配以 `γ` 累积，离线不修正则乘 `T`；信任域外关闭 BC 使 `γ` 不进入后继步。

**引理 65（严酷性阻止「未测即真」）** 若不要求 `Sev`，存在无判别力的回执集使任意 `h` 留在 `H_∩`，误接受概率可任意高。若要求 `Sev(ĥ,F) ≥ 1-β`，则在真实回执与 PA 下，误提交概率 `≤ β`（对每个被检验的伪假设最多 `β`）。*证明*：伪假设 `ĥ` 通过检验的概率 `≤ 1-Sev ≤ β`；单点提交只对幸存者发生；对候选集取并界即得（或以先验加权）。这是「无证据 ≠ 证据表明无」的形式化。

**引理 66（分工覆盖的贪心近似）** 判别特征覆盖函数 `Cov(·)` 单调子模；以最小见证类数覆盖 `D_feat` 是集合覆盖，贪心解满足 `|σ_greedy| ≤ H(m)·|σ*| ≤ (ln m + 1)|σ*|`；若改为预算约束下最大化覆盖，贪心达 `1-1/e`。*证明*：标准集合覆盖 / 子模最大化结论。故 DoL 可异步、近似最优，且覆盖空洞可被显式检测。

**引理 67（异步时序、不可逆屏障与退化链）** 信息素写入/读取、否决法定人数与 SCC 复核都发生在块边界或 `q_quiesce`，不进入 50Hz 内联路径；新增周期开销 `< 0.2ms`。跨不可逆动作时 `K=1` 且需 `q_irr` 个独立见证类的事前回执（定义 459(iv)）。若 `n_eff < q` 或 `Div < D_min` 或 BC 在域外且无主动探测预算，则按 `SwarmGauge → InstructGauge → ToolGauge → LeanGauge → MODGAUGE` 逐级退化；在回退子图上与对应基线逐指令等价（shadowing）。*证明*：异步离载与第 3 轮引理 58 同构；退化链每级只关闭新增组件，接受谓词退化为上级谓词；等价性由逐指令 shadow 归纳。

## 8. 本轮最大风险

**一句话**：`BCP` 与 `WQ/FQA` 的接口处存在**相关性的自指**——行为克隆让代理的提议与探测选择高度同源，克隆单文化把独立误差压成共同模式误差，于是「群体一致」可能只是「同一错误被复述 n 遍」；更危险的是，用来估计 `ρ̂`、`Div` 与独立性的样本本身也来自这同一批克隆，系统可能自信地弃权或自信地错提交，而所有个体指标仍显示校准良好。
