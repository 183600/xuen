# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「演示数据」×「模块化设计」）

> 第 54 轮把技能组合提升为动作空间剖面 `α_S` + 云边联合证书 `J`。本轮把视角从"组合算子"下移到组合的**材料**与**结构单元**：**演示数据是技能与动作剖面的证据来源，模块化设计是组合的结构约束**。核心矛盾——H22：演示数据稀疏、有偏、不可直接当覆盖证据，naive 模仿会在动作空间留下静默空洞，使第 54 轮的 `α_S` 看似完备、实为 demo 分布外推；H23：模块化承诺"可替换可重组"，但真实模块是共同适配（co-adapted）的，接口契约隐含在权重里，换模块即破坏隐式接口，第 54 轮的组合证书在模块边界处失效。

## 0. 直觉与动机

**灵感 1（演示数据 → 证据账本，而不是数据集）**
直觉：一段 demo 不是"一条轨迹"，而是"对动作空间某片区域的一次带来源的观测"。把 demo 记成证据 `e=(τ, κ, μ, ω, λ)`：`τ` 轨迹、`κ` 覆盖区域、`μ` 来源（采集者/本体/传感器/本体论版本）、`ω` 质量、`λ` 数据类别。数据集回答"有多少条"，证据账本回答"覆盖了哪片动作空间、以多高可信度、能否追溯"。第 54 轮 `α_S` 采样不足的本质，是账本覆盖 `κ_D` 与目标覆盖 `α_target` 的缺口没有被显式度量。

**灵感 2（覆盖缺口 → 主动采集的驱动信号）**
直觉：定义缺口 `gap(a)=max(0, α_target(a)-κ_D(a))`。于是采集不再是"再多录几条"，而是"去补 `gap` 最大的区域"。这把演示采集从经验行为变成可优化的**覆盖问题**，并与第 54 轮的动作剖面、第 53 轮的鲁棒性维度联动：缺口既可能是动作覆盖缺口，也可能是某个鲁棒性维度 `d` 的证据缺口。

**灵感 3（模块化设计 → 接口契约显式化）**
直觉：模块不应是黑箱 checkpoint，而应是 `M=(π_M, I_M, G_M, ρ_M, D_M)`：策略 + 接口 `I_M=(O_M, A_M, sync_M, frame_M, unit_M)` + 保证 `G_M` + 鲁棒谱 `ρ_M` + 证据账本 `D_M`。模块化真正可组合的前提，是接口能被**机器检查**（观测约定、动作语义、时序节拍、坐标系、单位），而不是"文档里说兼容"。

**灵感 4（演示驱动模块化 → 从轨迹里长出差点复用单元）**
直觉：把 demo 按动作剖面的变点切段，聚类成运动基元，再为每个基元拟合接口。这样模块不是人凭直觉切的，而是 demo 证据里"反复出现、可跨任务复用"的片段。切分目标 = 复用性（跨任务出现频次）× 可覆盖性（`κ` 覆盖）× 接口稳定度（边界条件方差小）。

**灵感 5（模块替换的可验证性 → 替换证书）**
直觉：换模块 `M→M'` 时要证明三件事：接口可对接（`I` 兼容）、保证不退化（`G'/ρ'` 在容差内不弱于 `G/ρ`）、证据不被稀释（`κ_{M'}` 不在任务动作区引入未验证空洞）。这给模块化一个**可回归测试**的证书，而不是"跑一遍 benchmark 没崩"。

**灵感 6（模块化演示增广 → 用模块先验补缺口，但必须与人类证据隔离）**
直觉：覆盖缺口处可以用已有模块做组合式合成 demo 来补，但合成 demo **不能直接计入人类证据账本**，否则形成自我确认闭环。必须走"合成 → 独立验证 → 重新标注入账"三段式，并给每条数据保留 `synthetic` 与 `verified_by` 标签。模块化在这里既是**结构先验**，也是**风险源**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（演示证据账本）**
演示证据账本 `D = {e_i}_{i=1}^{N}`，`e_i = (τ_i, κ_i, μ_i, ω_i, λ_i)`：
- `τ_i = {(s_t, a_t)}_{t=1}^{T_i}` 轨迹；
- `κ_i : A → [0,1]` 该轨迹在动作空间上的覆盖置信；
- `μ_i = (operator, embodiment, sensor, ontology_ver)` 来源元组；
- `ω_i ∈ [0,1]` 质量分（噪声、标注置信、复现性）；
- `λ_i ∈ {human, teleop, synthetic, verified}` 数据类别。

账本覆盖用 noisy-OR 聚合（只计入非合成证据）：
```
κ_D(a) = 1 - ∏_{i: λ_i ≠ synthetic} (1 - ω_i·κ_i(a))
```
**证据充分性**：`suf_D(a) = 1[κ_D(a) ≥ θ_ev ∧ prov_ok(a)]`，其中 `prov_ok` 要求来源元组完整且与当前本体版本可映射。

**定义 122（覆盖缺口与证据充分度）**
动作覆盖缺口 `gap_D(a) = max(0, α_target(a) - κ_D(a))`，聚合缺口
```
G_D = ∫_A gap_D(a)·w(a) da / ∫_A w(a) da
```
鲁棒维度证据缺口 `gap_ρ(d) = max(0, ρ_target(d) - inf_{e∈D} ρ_e(d))`。任务 `T` 的**证据充分**当且仅当 `G_D ≤ ε_g` 且 `∀d∈𝔇_T: gap_ρ(d)=0`。

**定义 123（模块接口契约）**
模块 `M = (π_M, I_M, G_M, ρ_M, D_M)`，接口
```
I_M = (O_M, A_M, sync_M, frame_M, unit_M)
```
其中 `O_M` 观测空间、`A_M` 动作空间、`sync_M` 时序节拍/延迟预算、`frame_M` 坐标系约定、`unit_M` 物理单位。接口检查 `check_interface(M, M')` 需要存在可验的观测嵌入 `φ: O_M→O_{M'}`、动作语义映射 `ψ: A_M→A_{M'}`，且 `sync_M` 整除 `sync_{M'}`、`frame/unit` 可无歧义转换。

**定义 124（模块可替换性）**
在任务 `T`、容差 `δ=(δ_ρ, δ_reg, δ_cov)` 下，`M'` 可替换 `M`（记 `M ≼_δ M'`）当且仅当：
1. `ψ(A_M) ⊆ A_{M'}`，且 `sync/frame/unit` 对接无歧义；
2. `∀d: ρ_{M'}(d) ≥ ρ_M(d) - δ_ρ`；
3. `κ_{D_{M'}}(a) ≥ κ_{D_M}(a) - δ_cov`，`∀a ∈ A_T`（证据不稀释）；
4. 替换回归套件 `R_sub` 的失败率 `≤ δ_reg`。

**定义 125（演示驱动模块化）**
切分映射 `σ: τ → (m_{i1},…,m_{ik})`，基元库 `P={p}`。模块化目标为
```
max_P  Σ_p reuse(p)·cover(p)·iface_stable(p) - λ_mod·|P|
```
其中 `reuse(p)` 为跨任务出现频次、`cover(p)` 为 `κ` 覆盖质量、`iface_stable(p)` 为接口边界条件方差之倒数。

**定义 126（模块化演示增广证书）**
`MDAC = (G_D^{before}, A_syn, κ_syn, ver_rate, G_D^{after})`。合成条目必须满足：
- `λ_i = synthetic` 且带 `verified_by` 指针；
- 独立验证覆盖 `ver_rate ≥ θ_v`；
- 只有重新标注为 `verified` 后才进入 `κ_D`；
- 入账后 `G_D^{after} ≤ ε_g` 才签发证书。

## 2. 关键算法 伪代码

### IP-121 DEL（Demo Evidence Ledger）

```python
def build_ledger(trajectories, annotate):
    D = []
    for tau in trajectories:
        D.append(Evidence(
            tau=tau,
            kappa=coverage_from_trajectory(tau),
            mu=annotate.provenance(tau),
            omega=annotate.quality(tau),
            lam=annotate.source(tau),   # human|teleop|synthetic|verified
        ))
    return D

def ledger_coverage(D, A):
    out = {}
    for a in A:
        miss = 1.0
        for e in D:
            if e.lam == 'synthetic':
                continue                 # 合成证据不进入被承认的覆盖
            miss *= (1.0 - e.omega * e.kappa.get(a, 0.0))
        out[a] = 1.0 - miss
    return out
```

### IP-122 CDG（Coverage Deficit Guided collection）

```python
def coverage_deficit(kD, alpha_target, w):
    gap = {a: max(0.0, alpha_target[a] - kD.get(a, 0.0))
           for a in alpha_target}
    total = sum(w.get(a, 1.0) for a in gap)
    G = sum(gap[a] * w.get(a, 1.0) for a in gap) / max(total, 1e-9)
    return gap, G

def select_targets(gap, budget, cost, rho_gap):
    # 先满足鲁棒维度证据缺口，再按 gap/成本 贪心覆盖
    forced = [d for d, g in rho_gap.items() if g > 0]
    return greedy_max_cover(gap, budget, cost, forced_dims=forced)
```

### IP-123 MIC（Module Interface Contract）

```python
def check_interface(M, M2, task):
    psi = action_semantic_map(M.I.A, M2.I.A)
    if psi is None or not subset(psi.image(M.I.A), M2.I.A):
        return Reject('action_semantics')
    if not divides(M.I.sync, M2.I.sync):
        return Reject('timing')
    if not frame_unit_compatible(M.I.frame, M.I.unit,
                                 M2.I.frame, M2.I.unit, task):
        return Reject('frame_unit')
    return Accept(psi)
```

### IP-124 MSV（Module Substitution Verification）

```python
def substitution_cert(M, M2, T, delta, suite):
    psi = check_interface(M, M2, T)
    if isinstance(psi, Reject):
        return psi
    for d in T.rho_dims:
        if M2.rho[d] < M.rho[d] - delta.rho:
            return Reject('robustness_regression', d)
    if not evidence_covers(M2.D, M.D, T.actions, delta.cov):
        return Reject('evidence_dilution')
    rep = suite.run(M2, T)
    if rep.fail_rate > delta.reg:
        return Reject('regression', rep)
    return Accept(SubCert(M, M2, psi, delta, rep))
```

### IP-125 DDM（Demo-Driven Modularization）

```python
def demo_driven_modularization(D, A, theta_cp, theta_p, lam_mod):
    segments = []
    for e in D:
        cps = change_points(e.tau, A, theta_cp)   # 动作剖面变点
        segments += split(e.tau, cps)
    clusters = cluster(segments,
                       key=interface_condition_distance)
    P = []
    for c in clusters:
        score = reuse(c) * coverage(c) * iface_stability(c)
        if score >= theta_p:
            P.append(fit_module(c))
    return argmax_subset(P, lambda Ps:
        sum(reuse(p)*coverage(p)*iface_stability(p) for p in Ps)
        - lam_mod*len(Ps))
```

### IP-126 MDA（Modular Demo Augmentation）

```python
def modular_augmentation(D, gap, P, verifier, theta_v, eps_g):
    G_before = coverage_deficit(ledger_coverage(D, gap.keys()),
                                gap.keys())[1]
    syn = []
    for region in gap_regions(gap):
        for plan in compose_modules(P, region):
            traj = simulate(plan, region)
            syn.append(Evidence(traj,
                                coverage_from_trajectory(traj),
                                mu=('synthetic', plan.id),
                                omega=synth_confidence(plan),
                                lam='synthetic'))
    verified = [e.retag('verified', by=verifier.id)
                for e in syn if verifier.independent_check(e) >= theta_v]
    D2 = D + verified
    G_after = coverage_deficit(ledger_coverage(D2, gap.keys()),
                               gap.keys())[1]
    if G_after > eps_g:
        return Reject('gap_not_closed', G_before, G_after)
    return Accept(MDAC(G_before, gap_regions(gap), verified,
                       len(verified)/max(len(syn),1), G_after))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DEL | O(N·|τ|·|A|) | O(N·|A|) | κ 校准、来源可追溯 |
| CDG | O(|A|·log|A|) | O(|A|) | gap 单调、采集成本可估 |
| MIC | O(|O|+|A|+|sync|) | O(1) | 语义映射 sound、时序可除 |
| MSV | O(|𝔇_ρ|+|A_T|+reg) | O(|𝔇_ρ|) | 替换证书 sound、回归充分 |
| DDM | O(N·|τ| + |seg|² + |P|·|A|) | O(|seg|·|A|) | 变点稳定、基元可分 |
| MDA | O(|gap|·|P|²·sim) | O(|syn|) | 合成与人类证据隔离、独立验证 |

**正确性定理（Demo-Evidence & Modular Composition Soundness）**
承接第 54 轮 (A22)–(A28)；新增 **(A29)** `κ_D` 经结构化校准、`μ` 来源不可伪造且与当前本体可映射；**(A30)** 接口检查器与替换证书 sound（`M ≼_δ M'` 的四个条件均被真实执行）；**(A31)** 合成证据一律 `λ=synthetic`，只有独立验证后才重标 `verified` 并计入 `κ_D`。则对由模块库组合出的计划 `P_e`：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - L_gap·G_D - P(substitution_regression) - P(synthetic_false_accept)
```
其中 `L_gap` 为任务成功率对覆盖缺口 `G_D` 的 Lipschitz 常数，`P(substitution_regression)` 由 `R_sub` 的统计保证界定，`P(synthetic_false_accept)` 由独立验证覆盖率 `θ_v` 界定。

关键：**覆盖缺口是显式失败项**、**模块替换必须过证书**、**合成证据必须与人类证据隔离**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 演示证据来源被伪造/漂移 | 高 | 来源签名 + 本体版本锁 + 抽样复现 |
| 覆盖缺口估计失真 | 高 | 校准集 + 主动探测 + 缺口上界保守化 |
| 模块接口"表面兼容" | 高 | 可执行契约测试 + 边界对抗用例 |
| 合成数据自我确认 | 极高 | 合成/人类账本物理隔离 + 独立验证 + 重标才入账 |
| 模块碎片化、组合爆炸 | 中 | 复用性剪枝 + 接口哈希索引 + 基元层级化 |

## 6. 本轮最大风险

**一句话**：模块化合成能以极低成本"填平"演示覆盖缺口，但一旦合成证据未被独立验证就被计入证据账本，`κ_D` 会在纸面上闭合、`G_D` 会虚假下降，系统将带着"已覆盖"的证书进入真实动作空间，并在最需要证据的区域静默失效——因此必须把合成证据与人类证据在账本层面硬隔离、以独立验证率为入账闸门，宁可让缺口长期可见，也绝不允许模块先验冒充人类经验。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（DEL×CDG×MIC×MSV×DDM×MDA）

> 承接第 54 轮产物 v31。本轮把"组合算子"下移到"组合材料与结构单元"，新增 **演示证据账本、覆盖缺口驱动采集、模块接口契约、模块替换验证、演示驱动模块化、模块化演示增广** 六个算子：

> - **MDA（Modular Demo Augmentation）**：模块组合补覆盖缺口，但合成与人类证据硬隔离。

## 3. 关键算法 伪代码

### IP-121 DEL

```python
def build_ledger(trajectories, annotate):
    D = []
    for tau in trajectories:
        D.append(Evidence(
            tau=tau,
            kappa=coverage_from_trajectory(tau),
            mu=annotate.provenance(tau),
            omega=annotate.quality(tau),
            lam=annotate.source(tau)))
    return D

def ledger_coverage(D, A):
    out = {}
    for a in A:
        miss = 1.0
        for e in D:
            if e.lam == 'synthetic':
                continue
            miss *= (1.0 - e.omega * e.kappa.get(a, 0.0))
        out[a] = 1.0 - miss
    return out
```

### IP-122 CDG

```python
def coverage_deficit(kD, alpha_target, w):
    gap = {a: max(0.0, alpha_target[a]-kD.get(a,0.0)) for a in alpha_target}
    total = sum(w.get(a,1.0) for a in gap)
    G = sum(gap[a]*w.get(a,1.0) for a in gap)/max(total,1e-9)
    return gap, G

def select_targets(gap, budget, cost, rho_gap):

    return greedy_max_cover(gap, budget, cost, forced_dims=forced)
```

### IP-124 MSV

```python
def substitution_cert(M, M2, T, delta, suite):
    psi = check_interface(M, M2, T)
    if isinstance(psi, Reject):
        return psi
    for d in T.rho_dims:
        if M2.rho[d] < M.rho[d] - delta.rho:
            return Reject('robustness_regression', d)
    if not evidence_covers(M2.D, M.D, T.actions, delta.cov):
        return Reject('evidence_dilution')
    rep = suite.run(M2, T)
    if rep.fail_rate > delta.reg:
        return Reject('regression', rep)
    return Accept(SubCert(M, M2, psi, delta, rep))
```

### IP-125 DDM

```python
def demo_driven_modularization(D, A, theta_cp, theta_p, lam_mod):
    segments = []
    for e in D:
        cps = change_points(e.tau, A, theta_cp)
        segments += split(e.tau, cps)
    clusters = cluster(segments, key=interface_condition_distance)
    P = [fit_module(c) for c in clusters
         if reuse(c)*coverage(c)*iface_stability(c) >= theta_p]
    return argmax_subset(P, lambda Ps:
        sum(reuse(p)*coverage(p)*iface_stability(p) for p in Ps)
        - lam_mod*len(Ps))
```

### IP-126 MDA

```python
def modular_augmentation(D, gap, P, verifier, theta_v, eps_g):
    G_before = coverage_deficit(ledger_coverage(D, gap), gap)[1]
    syn = []
    for region in gap_regions(gap):
        for plan in compose_modules(P, region):
            traj = simulate(plan, region)
            syn.append(Evidence(traj, coverage_from_trajectory(traj),
                                mu=('synthetic', plan.id),
                                omega=synth_confidence(plan),
                                lam='synthetic'))
    verified = [e.retag('verified', by=verifier.id)
                for e in syn if verifier.independent_check(e) >= theta_v]
    G_after = coverage_deficit(ledger_coverage(D+verified, gap), gap)[1]
    if G_after > eps_g:
        return Reject('gap_not_closed', G_before, G_after)
    return Accept(MDAC(G_before, gap_regions(gap), verified,
                       len(verified)/max(len(syn),1), G_after))
```

## 4. 推导与数值演示（覆盖账本演算）

设 6 个动作单元 `a1..a6`，`α_target ≡ 1`。三条人类/遥操证据：
`e1: ω=0.9, κ={a1,a2,a3}`，`e2: ω=0.8, κ={a2,a3,a4}`，`e3: ω=0.7, κ={a1,a4}`。

按 noisy-OR：`κ_D(a1)=1-(0.1)(0.3)=0.97`，`κ_D(a2)=κ_D(a3)=1-(0.1)(0.2)=0.98`，`κ_D(a4)=1-(0.2)(0.3)=0.94`，`κ_D(a5)=κ_D(a6)=0`。

| 单元 | a1 | a2 | a3 | a4 | a5 | a6 |
|---|---|---|---|---|---|---|
| `κ_D` | 0.97 | 0.98 | 0.98 | 0.94 | 0.00 | 0.00 |
| `gap_D` | 0.03 | 0.02 | 0.02 | 0.06 | 1.00 | 1.00 |

`G_D = (0.03+0.02+0.02+0.06+1+1)/6 = 0.355`，缺口由 `a5,a6` 主导，采集目标随之确定。

若用模块组合对 `a5,a6` 合成两条 `λ=synthetic` 证据，**在未重标前** `κ_D(a5)=κ_D(a6)=0`、`G_D` 不变——账本层面缺口保持可见。经独立验证并重标 `verified` 后，设 `κ=0.9`，则 `κ_D(a5)=κ_D(a6)=0.9`，`G_D=(0.03+0.02+0.02+0.06+0.1+0.1)/6=0.055`，满足 `ε_g=0.06`，签发 `MDAC`。该演示验证了"合成本身不闭合缺口，验证重标才闭合"这一账本语义。

**正确性定理（Demo-Evidence & Modular Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `κ_D` 经结构化校准、`μ` 不可伪造且与当前本体可映射；**(A30)** 接口检查器与替换证书 sound；**(A31)** 合成证据一律隔离、独立验证后才重标入账。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - L_gap·G_D - P(substitution_regression) - P(synthetic_false_accept)
```
关键：**覆盖缺口显式进入失败项**，**模块替换必须过证书**，**合成证据不得伪造覆盖**。

## 8. 本轮最大风险

**一句话**：模块化合成能以极低成本"填平"演示覆盖缺口，但一旦合成证据未被独立验证就被计入证据账本，`κ_D` 会在纸面上闭合、`G_D` 会虚假下降，系统将带着"已覆盖"的证书进入真实动作空间，并在最需要证据的区域静默失效——因此必须把合成证据与人类证据在账本层面硬隔离、以独立验证率为入账闸门，宁可让缺口长期可见，也绝不允许模块先验冒充人类经验。
