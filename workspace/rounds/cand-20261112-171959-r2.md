# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「分布外泛化」×「语义分割」）

> 第 60 轮的 SGEC 建起了「场景→阻抗先验→执行→证据」闭环：SSM 用 Kalman 把场景识别成阻抗先验、CIEC 把意图锁成实时约束、EPIR 保证 ROS 证据链、SERC 串起闭环、PCE++++ 管认知预算。但它留下了**三个结构性隐患**：
> 1. **场景集合是闭集，先验会「自信地错」**：Z_scene 固定为 10 类，Kalman 后验对所有观测都归一化收敛。遇到新材质、透明/反光桌面、可变形织物时，它不会说「不知道」，而是把新观测硬投影到最近邻类别——**场景置信度虚高、K_safe 提前收窄到错误邻域**。这正是「分布外泛化」缺位。
> 2. **场景粒度是全局标量，阻抗却是空间场**：一次接触只落在工作面的某个局部；桌面边缘、织物褶皱、湿滑斑块、玻璃区域对阻抗的要求各不相同。用一个场景标签给整张桌面配一个 K_safe，**既过度约束（把刚性区当软区）又欠约束（把湿滑斑当干燥区）**。需要「语义分割」把场景变成逐像素/逐区域的语义与阻抗场。
> 3. **「知道自己不知道」没有进入安全链路**：第 60 轮的 SIC 只用 `scene_conf·exp(−D⁺)`，但 scene_conf 本身在 OOD 下不可信；不确定性没有被传导为**承诺宽度**，一旦 OOD，窄安全集照旧被签发。
>
> 本轮核心主张：**把「闭集场景分类 → 窄阻抗承诺」换成「开放集语义分割 → 不确定性场 → 分布鲁棒承诺」，让「不知道」显式地变宽安全集、触发局部探测，而不是被归一化成高置信的错误。**

## 0. 直觉与动机

**灵感 1（分布外泛化 → 先验的「不变内核」而非「标签外推」）**
直觉：阻抗并不真的由「这是桌子还是楼梯」决定，而由少数**因果接触属性**决定——有效刚度 k_eff、阻尼 c_eff、摩擦 μ、接触柔顺度 χ。场景标签只是这些属性的「别名」。只要学到跨场景**不变**的因果表征 z_causal，遇到新场景就不是在标签空间外推，而是在因果参数空间内插值。
关键洞见：**分布外泛化的正确对象是因果参数，不是场景标签**。用不变风险最小化（IRM/V-REx）在多个已知域上学习 z_causal，则 `K = g(z_causal)` 对「未见过但物理上在域覆盖内」的新材质可泛化；对真正超出因果覆盖的样本，马氏距离会升高——这正好成为 OOD 信号。

**灵感 2（语义分割 → 把场景变成「阻抗场 + 不确定性场」）**
直觉：语义分割给每个像素一个类别和置信度：桌面刚性区、织物软区、湿滑斑块、玻璃透明区、边界、未知（void）。既然接触点是局部的，阻抗就该是**定义在表面上的场 K(x)**，而不是场景标量。
关键洞见：分割的**逐像素熵 H(x)** 与 **void 类概率**天然就是分布外不确定性的空间定位器——它把「这个场景整体是否 OOD」变成「工作面上哪一块 OOD、边界在哪」。于是探测与保守化可以**只在不确定区域局部执行**，代价从 O(W·H) 降到 O(不确定面积)。

**灵感 3（合流 → 不确定性场驱动的分布鲁棒阻抗编译 URIC）**
直觉：把三种 OOD 证据合流成一个评分场 s_ood(x)：分割熵（语义陌生度）+ 因果表征马氏距离（物理陌生度）+ 保形非一致性（校准后的统计陌生度）。然后按「不确定度分档承诺」：
- 低 s_ood：沿用第 60 轮窄先验（快、准）；
- 中 s_ood：在**因果参数模糊球** Θ_ε 上做最坏-case 编译（K_safe^DR），并安排一次小力探测；
- 高 s_ood：全局保守先验 + 弃权/降级。
关键洞见：**安全集的宽度应当是不确定性的单调函数**——不确定性越高，承诺越宽；而不是置信度越高，承诺越窄。

**灵感 4（分布鲁棒 + 保形 → 有有限样本保证的「宽承诺」）**
直觉：模糊球半径 ε 不能拍脑袋。用保形预测在已知域校准非一致性分数，得到在**协变量偏移下**仍成立的覆盖率下界；再用 Wasserstein/KL 模糊球做最坏-case CVaR。这样「宽承诺」不是拍脑袋保守，而是**有统计保证的保守**。
关键洞见：**把 OOD 检测的 FPR 与安全承诺的违反率解耦控制**：保形管「漏报」，DRO 管「漏报之后仍然安全」。

**灵感 5（PCE+++++ → 五维预算与「探测的 VOI」）**
直觉：OOD 处理要花算力（分割、距离、校准）和物理代价（探测接触）。新增 B_ood 维度：评分算力、注册次数、探测预算、校准频率。只有当 `VOI_probe = 预期不确定性下降 / (探测成本 + 风险)` 为正时才探测；B_ood 耗尽就退回「全局保守 + 禁扩张 + OOD 区域一律弃权」。
关键洞见：**「不确定性」本身有价格，探测是买信息，不能无条件买**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（开放集语义分割映射 OSSM）** 设工作面域 Ω，类别集 C = {table_rigid, cloth_soft, wood, metal, glass_transparent, wet_patch, deformable, void}。映射 S_seg: (I, P) → (M, H, E, s_ood)：
- **语义场**：M_c(x) = p(c|x)，逐像素类别概率；
- **语义熵场**：H(x) = −Σ_{c∈C} M_c(x)·log M_c(x)；
- **边界场**：E(x) = ||∇_x argmax_c M_c(x)||；
- **OOD 评分场**：s_ood(x) = clip(α·H(x)/H_max + β·d_φ(z(x))/(1+d_φ(z(x))) + γ·(1−max_c M_c(x)), 0, 1)；
- **保形阈值**：τ_ood = Quantile_{1−α}({s_ood(x_i)} 在分割验证集上)，控制闭集误报率 ≤ α。

**定义 162（因果不变表征 CIR）** 编码器 φ_ψ: o(x) → z_causal ∈ R^d（o 为局部视觉块 + 接触频谱/力-位移片段）。设已知域集 D = {D_1, …, D_m}（已知场景）。不变风险：
```
R_inv(ψ) = Σ_{d∈D} R_d(ψ) + λ·Σ_{d∈D} ||∇_{w=1} R_d(w ⊙ φ_ψ)||²      （IRMv1）
或      = Σ_{d∈D} R_d(ψ) + λ·Var_{d∈D}(R_d(ψ))                        （V-REx）
```
不变性目标：P^d(K | φ(o)) = P^{d'}(K | φ(o))，∀d,d'∈D。
OOD 物理距离：d_φ(z) = sqrt((z−μ_z)^T Σ_z^{-1} (z−μ_z))，μ_z、Σ_z 由已知域因果特征估计。

**定义 163（分布鲁棒安全集 DRSS）** 设阻抗先验参数 θ = (μ, Σ)，估计 θ̂ 与模糊球 Θ_ε = {θ : ||θ−θ̂||_{Σ_θ^{-1}} ≤ ε}。设安全损失 ℓ(K;θ)（力超限/跟踪误差/滑移）。分布鲁棒安全集：
```
K_safe^DR = { K ∈ K_phys : max_{θ∈Θ_ε} CVaR_δ(ℓ(K;θ)) ≤ 0 }
          = { K : min_{θ∈Θ_ε} P_θ(ℓ(K;θ) ≤ 0) ≥ 1−δ }
```
模糊球半径由保形校准给出：ε = Quantile_{1−α}({||θ_i−θ̂||_{Σ_θ^{-1}}} 在标定域上)，并计入协变量偏移导致的覆盖损失（见定义 168 的预算与定理 2）。

**定义 164（稠密阻抗场 DIF）** 给定分割 (M, H) 与类先验 {π_c = N(μ_c, Σ_c)}：
```
K_field(x) = Σ_{c∈C} M_c(x)·π_c
K_field(R) = Σ_{x∈R} w(x)·K_field(x) / Σ_{x∈R} w(x)      （按接触面积加权）
K_safe(R)  = compile(K_field(R), δ_f_req) ∩ K_safe^base
```
OOD 区域（s_ood(x) > τ_ood）改用 K_safe^DR(R)。性质：K_field 的空间梯度 ∇_x K_field 对应刚度突变边界；当它与分割边界 E(x) 一致时，跨边界承诺错误显著下降。

**定义 165（开放集记忆扩张 OSME）** 新颖区域注册规则，区域 R 需同时满足：
1. s_ood(R) > τ_ood 连续 K_c 次；
2. 探测后验收敛：tr(Σ_new) ≤ σ²_new；
3. 与既有类可分：min_c d_W(π_new, π_c) > d_min；
4. SPRT 对数似然比 Λ(R) ≥ log((1−β)/α_nov)。
满足则注册 z_new：Z_scene ← Z_scene ∪ {z_new}，π_new 以探测数据为共轭先验更新。误注册率 ≤ β。

**定义 166（不确定性定向探测 APO）** 候选探测点集 X_p。探测价值：
```
VOI_probe(x) = E[ΔH(s_ood(x))] / (c_probe(x) + λ_r·Risk_probe(x))
s.t.  Risk_probe(x) = P(F_probe(x) > F_safe) ≤ r_max
x* = argmax_{x∈X_p} VOI_probe(x),  F_probe ≤ F_safe
```
探测得到 `k_est = dF/dx`，以贝叶斯线性回归更新 π_new 的后验。

**定义 167（OOD 感知决策 OSG-Decision）** 对每个接触区域 R：
```
if s_ood(R) ≤ τ_ood and SIC_valid(R, K_safe(R)):
    K(R) ← CESC_narrow(R)                      # 第 60 轮窄承诺
elif B_ood.probe > 0 and Risk_probe(R) ≤ r_max:
    x* ← APO(R); π(R) ← probe_update(x*)
    K(R) ← DRSS(R)                             # 宽承诺 + 探测
else:
    K(R) ← generic_conservative(R)             # 全局保守
    ABSTAIN(R) = True
if ABSTAIN ∩ critical_regions ≠ ∅:
    DEGRADE_EXEC  or  request_human(CIEC)
```
**铁律：OOD 区域永不签发窄 K_safe，无论 scene_conf 多高。**

**定义 168（PCE+++++ 五维预算）** B_σ = (B_scene, B_intent, B_ros, B_exec, B_ood)，其中
```
B_ood = (OOD_scoring_ops, Novelty_registration_limit, Probe_budget, Calibration_freq)
voi_σ(π) = VOI_cog(π) − cost_cog(π) − cost_exec(π) − cost_ood(π)

```
若 B_ood < θ_ood：全局通用先验、禁 OSME 扩张、OOD 区域一律弃权；若 B_ood.probe = 0：跳过 APO，直接 conservative。

```python
class OpenSetSemanticMapper:
    def __init__(self, classes, encoder, alpha=0.4, beta=0.4, gamma=0.2):
        self.C = classes
        self.encoder = encoder
        self.alpha, self.beta, self.gamma = alpha, beta, gamma
        self.tau_ood = None

    def segment(self, image, points):
        logits = self.backbone(image)              # [C+1, H, W]
        M = softmax(logits, dim=0)
        H = -(M * log(M + 1e-8)).sum(0)            # 语义熵场
        boundary = boundary_map(M)
        z = self.encoder(image, points)            # 因果表征场 (IP-162)
        d = self.encoder.mahalanobis(z)            # 物理距离场
        s = clip(self.alpha * H / H_MAX
                 + self.beta * d / (1 + d)
                 + self.gamma * (1 - M.max(0)), 0, 1)
        return M, H, boundary, s

    def calibrate(self, scores_in):
        self.tau_ood = np.quantile(scores_in, 1 - ALPHA)   # 保形阈值

    def is_ood(self, s_region):
        return float(s_region.max()) > self.tau_ood
```

### IP-162 CIR（因果不变表征 + 马氏 OOD）

```python
class CausalInvariantEncoder:
    def __init__(self, phi, lam=1.0):
        self.phi, self.lam = phi, lam
        self.mu, self.Sigma_inv = None, None

    def invariance_penalty(self, domains):
        risks = [self.domain_risk(d) for d in domains]
        mean = sum(risks) / len(risks)
        # V-REx：域风险方差作为不变性惩罚；IRMv1 可换成梯度惩罚
        return self.lam * sum((r - mean) ** 2 for r in risks) / len(risks)

    def fit_ood_stats(self, z_in):
        self.mu = z_in.mean(0)
        cov = np.cov(z_in.T) + 1e-6 * np.eye(z_in.shape[1])
        self.Sigma_inv = np.linalg.inv(cov)

    def mahalanobis(self, z):
        d2 = ((z - self.mu) @ self.Sigma_inv * (z - self.mu)).sum(-1)
        return np.sqrt(np.maximum(d2, 0.0))
```

### IP-163 / IP-164 DRSS + DIF（分布鲁棒安全集 + 稠密阻抗场）

```python
class RobustImpedanceCompiler:
    def __init__(self, safety_loss, delta=0.1, n_ball=64):
        self.loss, self.delta, self.n_ball = safety_loss, delta, n_ball
        self.eps = None

    def calibrate_eps(self, theta_calib, theta_hat, Sigma_theta):
        d = [sqrt((t - theta_hat) @ inv(Sigma_theta) @ (t - theta_hat))
             for t in theta_calib]
        self.eps = np.quantile(d, 1 - ALPHA)       # 保形模糊球半径

    def worst_case_cvar(self, K, theta_hat, Sigma_theta):
        balls = sample_ellipsoid(theta_hat, Sigma_theta, self.eps, self.n_ball)
        losses = np.sort([self.loss(K, th) for th in balls])
        k = max(1, int(self.delta * len(losses)))
        return losses[-k:].mean()                  # 最坏 δ 尾部均值

    def compile(self, K_candidates, theta_hat, Sigma_theta):
        feasible = [K for K in K_candidates
                    if self.worst_case_cvar(K, theta_hat, Sigma_theta) <= 0]
        return min(feasible, key=self.cost) if feasible else None


class DenseImpedanceField:
    def __init__(self, class_priors):
        self.priors = class_priors                  # {c: N(mu_c, Sigma_c)}

    def field(self, M):
        return sum(M[c] * self.priors[c].mu for c in self.priors)

    def region_prior(self, M, R):
        return self.field(M)[R].mean(), self.field(M)[R].var()

    def update_prior(self, R, pi_new):
        self.priors[R] = pi_new
```

```python
class OpenSetMemory:
    def __init__(self, scenes, d_min=0.5, k_c=3, beta=0.05):
        self.scenes, self.d_min, self.k_c = scenes, d_min, k_c
        self.streak, self.sprt = defaultdict(int), defaultdict(float)

    def maybe_register(self, R, pi_R, s_R):
        self.streak[R] += 1
        if self.streak[R] < self.k_c:
            return None
        self.sprt[R] += log_likelihood_ratio(pi_R, self.scenes)
        separable = min(wasserstein(pi_R, p) for p in self.scenes.values()) > self.d_min

                  self.sprt[R] >= log((1 - self.beta) / ALPHA_NOV)):
            z_new = self.scenes.register(pi_R)
            self.streak[R], self.sprt[R] = 0, 0.0
            return z_new
        return None
```

```python
def sigma_loop(M, image, points, intent, delta_f_req):
    Mseg, Hseg, Eseg, s_ood = M.osm.segment(image, points)   # ① OSSM
    K_field = M.dif.field(Mseg)                               # ② DIF

    actions = {}
    for R in dense_regions(Mseg, Eseg):                       # ③ 逐区域决策
        s_R = float(s_ood[R].max())
        if (not M.osm.is_ood(s_R)) and M.sic.valid(R, K_field[R]):
            actions[R] = ('narrow', M.cesc.narrow(R))
        elif M.budget.B_ood.probe_left() > 0 and M.probe.risk(R) <= R_MAX:
            x = M.probe.select(R, s_ood[R])                   # ④ APO
            pi_R = M.probe.execute(x)
            M.dif.update_prior(R, pi_R)
            actions[R] = ('robust', M.drss.compile(M.dif.candidates(R), pi_R))
        else:
            M.abstain.add(R)                                  # ⑤ 弃权/保守
            actions[R] = ('conservative', M.drss.generic_conservative(R))

    if M.abstain & M.critical_regions:
        return 'DEGRADE_EXEC'

    if intent:
        M.intent_ctrl.receive_intent(intent)                  # 第 60 轮 CIEC

    M = dispatch_region_impedances(actions, M.current_cp)     # ⑥ 分发
    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe( # 第 60 轮 SERC
        M, M.current_cp, delta_f_req, M.budget)

    for R in M.last_contacted_regions:                        # ⑦ OSME
        if M.osm.is_ood(float(s_ood[R].max())):
            M.memory.maybe_register(R, M.dif.prior(R), s_ood[R])

    M.epir.append(EV_exec.__dict__)                            # 第 60 轮 EPIR
    return M, K_field, actions, EV_exec
```

```python
class SigmaBudget:
    def __init__(self, scene, intent, ros, exec_budget, ood):
        self.B_scene, self.B_intent, self.B_ros = scene, intent, ros
        self.B_exec, self.B_ood = exec_budget, ood

    def ood_exhausted(self):
        return self.B_ood.ops >= self.B_ood.max_ops or self.B_ood.probe_left() <= 0

    def fallback(self):
        if self.ood_exhausted():
            return dict(global_prior=True, allow_register=False, ood_abstain=True)
        return dict(global_prior=False, allow_register=True, ood_abstain=False)

def cost_ood(action):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OSSM | O(H·W·(|C|+d)) / 帧 | O(H·W) | 闭集 FPR ≤ α；OOD AUROC ≥ 0.90 |
| CIR | O(d·|D|) 训练；O(d²) 推理 | O(d²) | 跨域不变性；OOD 物理距离单调 |
| DRSS | O(|K|·n_ball·d) | O(d²) | 最坏-case 违反率 ≤ δ |
| DIF | O(|R|·compile) | O(H·W) | 区域刚度 MAE 下降 ≥ 30% |
| OSME | O(log N_scene) 摊销 | O(N_scene) | 误注册率 ≤ β（SPRT） |
| APO | O(|X_p|) 选点 + O(1) 探测 | O(1) | 探测力 ≤ F_safe；≤ 3 次达 SIC |
| SIGMA | O(区域数) | 复用 | OOD 区域零窄承诺 |

**正确性定理（SIGMA）**：

```python
class OpenSetSemanticMapper:
    def __init__(self, classes, encoder, alpha=0.4, beta=0.4, gamma=0.2):
        self.C, self.encoder = classes, encoder
        self.alpha, self.beta, self.gamma = alpha, beta, gamma
        self.tau_ood = None

    def segment(self, image, points):
        logits = self.backbone(image)
        M = softmax(logits, dim=0)
        H = -(M * log(M + 1e-8)).sum(0)
        E = boundary_map(M)
        z = self.encoder(image, points)
        d = self.encoder.mahalanobis(z)
        s = clip(self.alpha * H / H_MAX
                 + self.beta * d / (1 + d)
                 + self.gamma * (1 - M.max(0)), 0, 1)
        return M, H, E, s

    def calibrate(self, scores_in):
        self.tau_ood = np.quantile(scores_in, 1 - ALPHA)

    def is_ood(self, s_region):
        return float(s_region.max()) > self.tau_ood
```

### IP-162 CIR（因果不变表征）

```python
class CausalInvariantEncoder:
    def __init__(self, phi, lam=1.0):
        self.phi, self.lam = phi, lam
        self.mu, self.Sigma_inv = None, None

    def invariance_penalty(self, domains):
        risks = [self.domain_risk(d) for d in domains]
        mean = sum(risks) / len(risks)
        return self.lam * sum((r - mean) ** 2 for r in risks) / len(risks)

    def fit_ood_stats(self, z_in):
        self.mu = z_in.mean(0)
        cov = np.cov(z_in.T) + 1e-6 * np.eye(z_in.shape[1])
        self.Sigma_inv = np.linalg.inv(cov)

    def mahalanobis(self, z):
        d2 = ((z - self.mu) @ self.Sigma_inv * (z - self.mu)).sum(-1)
        return np.sqrt(np.maximum(d2, 0.0))
```

```python
class RobustImpedanceCompiler:
    def __init__(self, safety_loss, delta=0.1, n_ball=64):
        self.loss, self.delta, self.n_ball = safety_loss, delta, n_ball
        self.eps = None

    def calibrate_eps(self, theta_calib, theta_hat, Sigma_theta):
        d = [sqrt((t - theta_hat) @ inv(Sigma_theta) @ (t - theta_hat))
             for t in theta_calib]
        self.eps = np.quantile(d, 1 - ALPHA)

    def worst_case_cvar(self, K, theta_hat, Sigma_theta):
        balls = sample_ellipsoid(theta_hat, Sigma_theta, self.eps, self.n_ball)
        losses = np.sort([self.loss(K, th) for th in balls])
        k = max(1, int(self.delta * len(losses)))
        return losses[-k:].mean()

    def compile(self, K_candidates, theta_hat, Sigma_theta):
        feasible = [K for K in K_candidates
                    if self.worst_case_cvar(K, theta_hat, Sigma_theta) <= 0]
        return min(feasible, key=self.cost) if feasible else None


class DenseImpedanceField:
    def __init__(self, class_priors):
        self.priors = class_priors

    def field(self, M):
        return sum(M[c] * self.priors[c].mu for c in self.priors)

    def region_prior(self, M, R):
        f = self.field(M)
        return f[R].mean(), f[R].var()

    def update_prior(self, R, pi_new):
        self.priors[R] = pi_new
```

```python
def sigma_loop(M, image, points, intent, delta_f_req):

    K_field = M.dif.field(Mseg)

    actions = {}

        if (not M.osm.is_ood(s_R)) and M.sic.valid(R, K_field[R]):

        elif M.budget.B_ood.probe_left() > 0 and M.probe.risk(R) <= R_MAX:
            x = M.probe.select(R, s_ood[R])
            pi_R = M.probe.execute(x)
            M.dif.update_prior(R, pi_R)
            actions[R] = ('robust', M.drss.compile(M.dif.candidates(R), pi_R))

    if M.abstain & M.critical_regions:

    if intent:

            M.memory.maybe_register(R, M.dif.prior(R), s_ood[R])

    M.epir.append(EV_exec.__dict__)
```
