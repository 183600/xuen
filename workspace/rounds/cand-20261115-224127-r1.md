# 第 9 轮（新灵感循环第 1 轮；本轮灵感：「创新点提炼」×「中间件」×「动作分块」）
> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–531；引理 69–81；实验 E531–E550）。
> 本轮纪律：**分块执行 + 契约中间件 + 创新提炼**。三个灵感分别治理 v8 的三种债：算力债（50Hz 逐步重计算无余量）、集成债（手写退化网关靠约定不靠机制）、叙事债（14 个 IP 无实证机制）。必须通过**中立元契约退化链**保证任一新模块失效时注入恒等元、严格等价退回 v8，而非行为漂移。

## 0. 直觉与动机

**灵感 1（创新点提炼 → 模块贡献归因与蒸馏）**
直觉：系统已堆叠 14 个 IP 模块，严谨的研究者必须回答"哪些组件真正挣得它们的算力"。核心创新：**创新点蒸馏器（InnovationDistiller, ID）**：滑窗消融归因产出贡献向量 c_m(t)，Schmitt 双阈把模块置入 active/dormant/frozen 状态机。关键安全设计：dormant 行为严格等价于 v8 对应退化级（注入中立元），故"提炼"只是计算再分配、不是功能删除——**P12 提炼不删码律**。附带产出：IP 清单从论文叙事升级为带消融证据的活文档（每项 IP 附 c_m 曲线）。

**灵感 2（中间件 → 退化链的声明化）**
直觉：v8 主闭环中模块接线与退化逻辑是手写 if-else 网关，模块越多越脆。中间件思想：把"接线、时限、失效语义"升级为一等公民。核心创新：**实时契约中间件（ContractMiddleware, MW）**：每模块声明契约 κ_m=(In, Out, D_m, Ŵ_m, v_m^⊥, π_m, φ_m^elig)；每周期 EDF 调度，超时即注入中立元 v_m^⊥（该端口聚合算子的恒等元）。v8 的四级退化链由此变成契约表的一个**数据实例**（引理 83 证明逐位等价复现）。退化从"代码"变成"配置"，组合正确性从人工验证变成代数性质。

**灵感 3（动作分块 → 分块证书执行）**
直觉：50Hz 逐步决策让重模块每周期全额燃烧算力，预算利用率近 1.0，正是 v8 抖动风险的根源。ACT 思想：一次生成 K 步动作块 ζ=(a^{1:K}, Ĉ, P)——Ĉ 为块证书（前向模型预测的块内指标最坏界，留余量 β），P 为满足停车不变式的中止点集。5Hz 生成块，50Hz 只跑廉价守卫；违规时切换到最近中止点安全停驻。核心创新：**分块证书执行器（ActionChunkCertifier, AC）**；且有效块长 K_eff 由 Δ_dom、risk_SLAM 连续门控——域越陌生块越短，极端时 K=1 退回 v8 逐步模式。分块使决策预算利用率从 ~1.0 降至 ~0.3，直接给 v8 的"抖动→虚假退化风暴"风险上保险。

## 1. 研究问题（轮次升级版）

- **Q1（分块证书可靠性）**：如何设计块证书与中止点集，使「信任域内前向模型误差 ≤ β」假设下，中块突变的安全性与逐步执行统计等价？信任域门控能否消除模型误差与域偏移的相关性风险？
- **Q2（契约化退化）**：如何将 v8 四级退化链编码为中立元代数，使"模块失效（超时）"与"显式退化"在可观测日志层面逐位不可区分？
- **Q3（提炼安全边界）**：消融归因与状态机在什么资格谓词 φ^elig 下保证蒸馏永不触碰安全不变式？双阈迟滞能否根除休眠-唤醒抖振？

## 2. 设计原则（在 P7–P9 基础上新增 P10–P12）

**P10 分块证书律（Chunked-Certificate Execution, AC）**
决策以块为单位：ζ_t = (a^{1:K}, Ĉ_t, P_t)。证书 Ĉ_t 携带前向模型误差余量 β；中止点 p ∈ P_t 满足停车不变式 d_stop(p)。50Hz 守卫只做廉价检查（证书失效检测 + 停车不变式），重规划只在块边界发生。有效块长受信任域门控：K_eff(t) = 1 若 Δ_dom ≥ τ_dom 或 risk_SLAM ≥ τ_SLAM，否则 K_eff = max(1, ⌊K_max·(1−Δ_dom/τ_dom)⌋)。

**P11 中立元退化律（Neutral-Element Degradation, MW）**
每模块输出端口定义聚合算子 ⊕ 与中立元 v^⊥（恒等元：x ⊕ v^⊥ = x）。模块在截止期内完成则输出 x_m(t)，超时/失效则注入 v^⊥。系统退化行为 = 中立元组合，由契约表声明，不再手写分支。

**P12 提炼不删码律（Distill-Not-Delete, ID）**
蒸馏只改变调度（计算分配），不改变代码可达性：dormant/frozen 模块保留在契约表中，其 v^⊥ 路径随时可用；φ^elig=false 的安全关键模块（M₀ 硬检查、SpatialCert、FaultCert、MW 自身、AC 证书检查）永不消融；Δ_dom 越阈强制全模块唤醒。

## 3. 与基线的接口（如何退化）

- AC 失效（前向模型超差 / 证书连续失效）⇒ K_eff ← 1，逐步执行，等价 v8 决策粒度；
- MW 失效 ⇒ 切换 v8 手写网关代码路径（代码保留、非契约驱动），等价 v8 集成方式；
- ID 失效 ⇒ 全模块 active、c_m 冻结不再更新，等价 v8（全模块常开）；
- v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 4. 预期贡献

1. **分块证书执行**框架：块级证书 + 中止点集 + 信任域门控块长，在保持安全论证局部化的同时将决策算力利用率降一个量级；
2. **契约中间件**：退化链的代数化——中立元恒等性使组合退化正确性从枚举验证变为代数性质（v9 引理 83）；
3. **创新点蒸馏器**：IP 清单的实证化与算力的自适应再分配，附"陌生域强制唤醒"反脆弱设计；
4. **预算-安全-自省三闭环**：分块释放的算力反哺 DA/SPR/Cal 的余量；E551–E570 覆盖块长扫描、中止功效、契约等价、归因精度、抖振抑制、陌生域唤醒与端到端任务。

## 5. 本轮最大风险

**一句话**：块证书的可靠性以「信任域内前向模型误差 ≤ β」为前提，而 DA-ML 检测到的域偏移恰恰是模型误差最大化的时刻——若 Δ_dom 的 20 帧滑窗滞后于真实分布跳变，K_eff 会在一个证书已失效的块上仍取大值，中块中止可能迟到，即「分块执行在最需要安全的时刻暴露最不可靠的证书」。

**新增定义 540（柔顺动作块 Compliance ActionChunk）**
一次决策的输出单元升级为：
```
ζ^Z_t = (a_t^{1:K}, Z_t^{1:K}, Ĉ^E_t, P^Z_t)
a_t^k = (x_r^k, ẋ_r^k, ẍ_r^k),  Z_t^k = (M_d^k, B_d^k, K_d^k, F_ff^k)
```
其中 K = K_eff^I(t) ≤ K_max = 10（50Hz 下 200ms 时域）。块在 5Hz 节拍生成，逐周期执行第 k 步；Z^k 由接触信念与风险信号连续调度（定义 541）。

**新增定义 541（阻抗目标动力学与容许集 ImpedanceTarget）**
末端目标行为定义为：
```
M_d(ẍ − ẍ_r) + B_d(ẋ − ẋ_r) + K_d(x − x_r) = F_ext + F_ff
```
容许集：
```
Z_adm = {M_d ⪰ 0, B_d ⪰ B_min I, 0 ⪯ K_d ⪯ K_max I,
         ‖τ‖∞ ≤ τ_max, ‖F_cmd‖ ≤ F_max}
```
接触信念 χ_k∈[0,1] 由 ITS 的接触模式与残差给出，阻抗按
```
χ_k = σ(λ_s s_k + λ_α 1[α_k=contact] + λ_φ φ_k)
K_d^k = (1−χ_k)K_free + χ_k K_contact,   K_contact < K_free
B_d^k = (1−χ_k)B_free + χ_k B_contact,   B_contact > B_free
```
自由空间用高刚度保跟踪；接近/进入接触时降低刚度、提高阻尼以吸收冲击。χ_k 的变化率受 |χ_{k+1}−χ_k| ≤ Δχ_max 限制，避免增益突变诱发的极限环。

**新增定义 542（能量罐与无源控制 EnergyTank）**
端口功率 P_r=τ^T q̇，能量罐按
```
E_{t+1} = clip(E_t − Δt·P_r − Δt·P_diss + Δt·P_in, 0, E_max)
```
更新。无源观测器（PO）：
```
W_obs(t) = ∫_0^t τ^T q̇ ds
E_t = E_0 − W_obs(t) + ∫_0^t P_in ds   （按上式 clip）
```
无源控制器（PC）在 E_t ≤ E_min+ε_E 时注入阻尼：
```
β_t = max(0, −P_r(t−1) / max(ε, ‖q̇(t−1)‖²))
τ ← clip(τ − β_t q̇, τ_max)
```
其含义：环境对机器人做功时把能量存进罐；机器人对做正功时从罐支出；罐见底就只耗散、不主动注入。硬安全由 E_t≥0 保证，不依赖前向模型是否准确。

**新增定义 543（惯性残差与动量观测器 InertialResidual）**
以关节空间动量 p=M(q)q̇ 构造动量观测器：
```
r_t = K_o ( p_t − ∫_0^t (τ + C^T q̇ − g(q) + r_s) ds )
```
r_t 为外部关节力矩估计。为区分“接触”与“基座运动/振动”，用本体感受估计基座加速度 â_base，并做白化：
```
r̃_t = r_t − H_t â_base − b_t
s_t = ‖r̃_t‖²_{Σ_r^{-1}} + λ_F ‖J^{-T} r̃_t‖²_{Σ_F^{-1}}
H_osc(t) = ∫_{t−T_o}^t ‖BP_{8–20Hz}(ω(τ))‖² dτ
```
H_t 为基座加速度到关节残差的回归矩阵（固定基座时 H_t=0），b_t 为慢漂移偏置。全局一致的残差优先归因于基座运动，局部关节残差优先归因于接触；该分解是降低 IMU 误报的关键。

**新增定义 544（惯性信任域与快速否决 InertialTrustVeto）**
```
U^I_t = U_t ∧ (s_t ≤ τ_s) ∧ (H_osc(t) ≤ τ_osc) ∧ (IMU healthy)
K_eff^I(t) = 1                 若 ¬U^I_t
           = K_eff(t)（v9）    否则
```
否决时延上界：
```
T_veto ≤ N_d/f_s + T_c + T_a
```
取 f_s=1kHz、N_d=3、T_c≤0.2ms、T_a≤2ms，则 T_veto≤5.2ms；相对 v9 的 Δ_dom 窗口 T_Δdom=20/50=400ms，覆盖比 ρ_gap=1−T_veto/T_Δdom≥98.7%。**注意：这只覆盖接触/失稳后的信任撤销，不覆盖首次接触的几何预测。**

**新增定义 545（三速率反射层级 ThreeRateHierarchy）**
| 层 | 组件 | 频率 | 截止期 | WCET | 权限 |
|---|---|---|---|---|---|
| L0 | ITS + ICS 反射 | 1kHz | 1ms | ≤0.3ms | 可抢占，只能降速/柔顺/停驻 |
| L1 | AC 中块守卫 + 阻抗包络 | 50Hz | 20ms | ≤0.5ms | 可中止到 P^Z |
| L2 | AC 块生成 + 阻抗调度 | 5Hz | 200ms | ≤12ms | 只提议，不可否决 L0/L1 |

仲裁：
```
c_out = Π_0(Π_1(Π_2(c_plan)))
```
每个 Π_i 幂等、单调，且只与安全集 S 求交（定义 550）；L0 不可被 L1/L2 覆盖，L1 不可被 L2 覆盖。

**新增定义 546（接触模式状态机 ContactFSM）**
```
free        → contact      : s_t > τ_on^c 连续 N_c 个样本
contact     → free         : s_t < τ_off^c 连续 M_c 个样本，τ_off^c < τ_on^c
contact     → post_impact  : ‖F̂_ext‖ > F_imp 或 s_t 出现单峰冲击
post_impact → contact      : 冲击衰减且 s_t 回落到 τ_on^c 以下
any         → unstable     : H_osc > τ_osc 连续 N_o 个样本
any         → fault        : IMU 掉线/饱和/NaN/时间戳跳变
unstable    → contact/free : H_osc < τ_osc−Δτ 且驻留 T_dwell
fault       → post_impact  : 仅允许保守柔顺，需人工/离线复位
```
输出接触信念 χ_k 与安全阻抗 Z_stop；双阈+驻留保证无抖振（引理 92）。

**新增定义 547（能量证书 EnergyCertificate）**
```
Ê_cost(k) = Δt·( ‖τ̂_k‖·‖q̇̂_k‖ + c_x‖Δx_k‖² + c_b‖q̇̂_k‖² )
Ĉ^E_t valid ⇔ E_t − Σ_{k=1}^K Ê_cost(k) ≥ E_min
            ∧ F̂_max ≤ F_max
            ∧ ∀k: Z^k ∈ Z_adm
```
若证书无效，优先缩短 K_eff；若 K_eff 已为 1，则进入保守柔顺保持（Z_stop）而不是继续执行。证书只用于“接受块”的充分条件；硬安全由能量罐 clip 与 PC 兜底（引理 91）。

**新增定义 548（柔顺中止点与回撤原语 ComplianceAbort）**
```
P^Z_t = { p ∈ {1..K} :
          d_brake(v_p) + d_safe ≤ dist(s_p, O) − |traj_{p:K}| }
```
在 p*∈P^Z 触发：
```
Z_stop = (M_d, B_max, K_min, 0)
v_retreat = −v_max·n̂,   n̂ = normalize(Ĵ^{-T} r̃_{p*}) 或运动反向
```
回撤期间持续监测 E_t 与 s_t；若 E_t<E_min，则切换纯阻尼保持。P^Z 为空仅允许 K=1 fallback（等价 v9 逐步语义）。

**新增定义 549（v10 中立元表 NeutralElementTable）**
| 模块 | v^⊥ | 等价分支 |
|---|---|---|
| ICS 柔顺壳 | bypass：a_out=a_in，Z_out=Z_v9 | v9 AC |
| ITS 惯性哨兵 | no-event：s≡0, α=free, U^I=U（非接触任务） | v9 |
| ITS 惯性哨兵 | conservative：K_eff=1, Z_stop（接触任务谓词 ψ_contact=true） | v9 Level-1 |
| 能量罐 | pure damping：β=β_max, K_d=K_min | v9 安全停驻（无源保守） |
| RA 仲裁器 | passthrough：c_out=c_plan | v9 |
| AC-Z | v9 AC（ζ^Z→ζ） | v9 |
| MW | v8 手写网关 | v8 |
| ID | 全模块 active、归因冻结 | v9 全模块常开 |

ITS 采用**两级中立元**：功能中立（no-event）保证非接触任务逐位退回 v9；安全中立（conservative）保证接触任务不会因“假装没有接触”而失去柔顺保护。两者由任务谓词 ψ_contact 选择，不允许运行时静默切换。

**新增定义 550（安全包络与耦合不变式 SafetyEnvelope）**
```
S = { ‖τ‖∞ ≤ τ_max, ‖F_cmd‖ ≤ F_max, ‖q̇‖∞ ≤ q̇_max,
      E_t ≥ E_min, d_stop(t) ≥ 0 }
```
块被接受当且仅当：
```
∀k≤K: 预测状态 ∈ S  ∧  ∃T_reflex≤T_max: Π_0 可把当前命令投影回 S
```
该不变式把“块长—能量—反射时延”耦合在一起：任何一条不满足，K_eff 必须缩短或进入保守柔顺。

## 2. 形式化定义（要点与升级）

**升级定义 496（软证书，v10）**
```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
             ∧ risk_SLAM < τ_SLAM ∧ Ĉ_t valid
             ∧ Ĉ^E_t valid ∧ U^I_t}
```
新增两个条件：能量证书有效、惯性信任域成立。块证书失效、能量证书失效、惯性否决三者任一触发 M₀ 硬检查；不存在“块内软通过、接触后硬失效”的空洞（引理 87+88+91 联合）。

**升级定义 531（软硬约束衔接，v10）**
M₀ 判据增加三条入口：中块守卫违规 ⇒ 立即切换 p*；能量罐低于 E_min ⇒ 立即 Z_stop；ITS 否决 ⇒ 立即 K_eff=1 并柔顺停驻。三者均不等块边界。

**升级定义 539（有效块长，v10）**
```
K_eff^I(t) = 1                                          若 ¬U^I_t
           = max(1, ⌊K_max·(1−min(1, Δ_dom/τ_dom))⌋)    否则
```
其中 U^I_t 替代 v9 的 U_t；惯性否决可在 Δ_dom 尚未反应时先把 K_eff 压到 1。

# IP-358 InertialTrustSentinel：1kHz 惯性信任哨兵
class InertialTrustSentinel:
    def __init__(self, fs=1000, N_d=3, tau_s=3.0, tau_osc=0.8,
                 tau_on=3.0, tau_off=2.0, T_o=0.2):
        self.fs, self.N_d = fs, N_d
        self.tau_s, self.tau_osc = tau_s, tau_osc
        self.tau_on, self.tau_off = tau_on, tau_off
        self.T_o = T_o
        self.r = 0.0                  # 动量观测器残差
        self.bias = 0.0               # 慢漂移偏置
        self.fsm = ContactFSM(tau_on, tau_off, N_c=3, M_c=5, T_dwell=0.05)

    def observe(self, imu, q, qd, tau_cmd, dt):
        p = M(q) @ qd
        r = self.r + dt * (tau_cmd + C(q, qd) @ qd - g(q) + self.r)
        self.r = Ko * (p - r)                      # 简化动量观测器
        a_base = imu.a - R(q).T @ GRAVITY
        r_w = self.r - self.H(q) @ a_base - self.bias
        s = mahalanobis(r_w, SIGMA_R) + \
            LAM_F * mahalanobis(J_inv(q).T @ r_w, SIGMA_F)
        h_osc = self._band_energy(imu.omega, 8.0, 20.0, self.T_o)
        alpha = self.fsm.step(s, h_osc, imu.healthy)
        trust = (s <= self.tau_s and h_osc <= self.tau_osc
                 and imu.healthy and self.fsm.state != 'fault')
        return InertialState(s, h_osc, alpha, r_w, trust,
                             contact_normal(r_w, q))


# IP-357 ImpedanceComplianceShell：柔顺壳 + 能量罐
class ImpedanceComplianceShell:
    def __init__(self, E0=2.0, E_max=4.0, E_min=0.2, dt=0.001):
        self.E, self.E_max, self.E_min, self.dt = E0, E_max, E_min, dt

    def command(self, a, Z, q, qd, F_ext_hat):
        x, xd = forward_kinematics(q, qd)
        e, ed = x - a.x_r, xd - a.xd_r
        F_cmd = (Z.M @ a.xdd_r + Z.B @ ed + Z.K @ e + F_ext_hat)
        F_cmd = clip_norm(F_cmd, F_MAX)
        tau = J(q).T @ F_cmd + g(q) + C(q, qd) @ qd
        tau = clip_abs(tau, TAU_MAX)
        P_r = tau @ qd
        self.E = clip(self.E - self.dt * P_r
                      - self.dt * P_diss + self.dt * P_in, 0, self.E_max)
        if self.E <= self.E_min + EPS_E:
            beta = max(0.0, -P_r / max(EPS, qd @ qd))
            tau = clip_abs(tau - beta * qd, TAU_MAX)
        return tau, self.E


# IP-359 ReflexArbiter：三速率单调仲裁
class ReflexArbiter:
    def arbitrate(self, c_plan, c_guard, inertial, tank):
        c = self.Pi2(c_plan)                   # L2 只提议
        c = self.Pi1(c, c_guard)               # L1 可中止到 P^Z
        c = self.Pi0(c, inertial, tank)        # L0 最高优先，只收缩
        return c

    def Pi0(self, c, inertial, tank):
        if not inertial.trust or tank.E <= tank.E_min:
            return SafeCompliance(K_eff=1, Z=Z_STOP)   # 柔顺停驻
        if inertial.alpha == 'post_impact':
            return ComplianceRetreat(c, inertial.n_hat)  # CAP
        return c

    def Pi1(self, c, guard):
        return guard.abort_or_project(c)       # 停车不变式 / 能量包络


# IP-354 ActionChunkCertifier-Z：柔顺分块证书
class ActionChunkCertifierZ:
    def generate_chunk(self, state, inertial, delta_dom, tau_dom):
        trust = inertial.trust and delta_dom < tau_dom and \
                state.risk_slam < state.tau_slam
        K = 1 if not trust else effective_K(delta_dom, tau_dom)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            Z = self.scheduler.schedule(cand, inertial.contact_belief)
            pred = self.F.rollout(state, cand, Z)
            cost = self.energy_cost(pred, Z)
            if not self.cert_valid(state.E, cost, pred, Z):
                continue
            pts = self.abort_points_Z(state, cand, pred, Z)
            if not pts:
                continue
            score = self.policy.score(cand, pred, Z)
            if best is None or score > best.score:
                best = ChunkZ(cand, Z, EnergyCert(cost, pred.F_max, pts), score)
        return best or self.single_step_fallback(state)


# 主闭环集成：MetricVoiceGauge-ACMD-I²
def metricvoicegauge_round_10(M, s, obs, imu, q, qd, tau_cmd, ...):

    istate = its.observe(imu, q, qd, tau_cmd, dt=0.001)

    # ---- 50Hz 感知侧契约（v9 继承；超时注入 v^⊥）----

    distiller.step(cycle_idx, ctx)

## 4. 推导

**引理 87（柔顺壳的无源性）**
设 Z∈Z_adm、执行器饱和 ‖τ‖∞≤τ_max、能量罐按定义 542 更新且 E_t≥0。则对任意 T：
```
−∫_0^T τ^T q̇ dt ≤ E_0 + ∫_0^T P_in dt
```
即柔顺壳对任意无源环境无源；由 Colgate–Hogan 无源互联定理，耦合系统稳定。
证明：由 E_T≥0 与更新式，
```
∫_0^T τ^T q̇ dt = E_0 + ∫P_in − E_T − ∫P_diss ≤ E_0 + ∫P_in
```
移项即得。PC 在 E≤E_min+ε_E 时取 β_t=max(0,−P_r/‖q̇‖²)，保证下一步不出现负能量；clip 是硬兜底。∎

**引理 88（惯性否决的时延覆盖）**
取 f_s=1kHz、N_d=3、T_c≤0.2ms、T_a≤2ms，则
```
T_veto ≤ 3/1000 + 0.0002 + 0.002 = 5.2ms
```
v9 的 Δ_dom 窗口 T_Δdom=20/50=400ms，故覆盖比
```
ρ_gap = 1 − T_veto/T_Δdom ≥ 0.987
```
在 v=0.5m/s 时，信任撤销前的位移从 ≤200mm 降到 ≤2.6mm（未计刹车距离）。**该引理只覆盖接触/失稳后的信任撤销，不覆盖首次接触的几何预测；首次接触仍需 v9 的距离/证书链。**∎

**引理 89（三速率单调安全）**
设 S 为安全集，Π_i（i=0,1,2）幂等、单调且 Π_i(A)⊆A。则
```
c_out = Π_0(Π_1(Π_2(c_plan))) ∈ S
```
且增加任何新层 Π_new 只会使可达命令集收缩，不会扩张。
证明：由 Π_i(A)⊆A 逐层包含；单调性保证低层不能把高层已排除的命令重新引入；幂等性保证重复投影不改变结果。∎

**引理 90（v10→v9→v8 退化等价）**
退化分两条路径，不能混用：
- **名义等价路径**：ICS bypass、ITS no-event（非接触任务）、RA passthrough、AC-Z→v9 AC、MW 保持契约、ID 全 active。此时能量罐不在回路中，非接触任务的可观测端口读数逐位等于 v9。
- **安全退化路径**：ITS conservative（接触任务）⇒ 等价 v9 Level-1 安全分支；能量罐单独失效 ⇒ 纯阻尼（无源保守，等价 v9 安全停驻而非名义路径）；RA 失效 ⇒ passthrough；MW 失效 ⇒ v8 网关；ID 失效 ⇒ 全 active。全部关闭时逐级退回 v8/v7/v6。
证明：对端口图归纳。bypass 是函数复合的恒等元；no-event 使 U^I=U 且 s≡0；conservative 是 v9 Level-1 的保守实例；纯阻尼只会在能量罐不可用时替换 ICS 的内部策略，不会与 bypass 同时启用；其余同 v9 引理 83。∎

**引理 91（能量证书的模型误差鲁棒性）**
若前向模型单步能量预测误差 ≤β_E，则
```
E_{t+K} ≥ E_t − Σ_{k=1}^K Ê_cost(k) − K·β_E·Δt
```
证书预留 K·β_E·Δt 与 E_min 时罐不枯竭。即使 β_E 被低估，PO 的 clip 仍保证 E_t≥0，PC 在 E≤E_min 时耗散；**硬安全不依赖 β_E 正确，β_E 只影响任务可行性**（证书可能误拒/误收，误收由在线 PO 兜底）。∎

**引理 92（接触 FSM 无抖振/无 Zeno）**
双阈 τ_off<τ_on、连续样本 N_c、驻留 T_dwell ⇒ 每次迁移需一次独立阈值穿越且驻留至少 T_dwell；有限时间 T 内迁移次数 ≤ T/T_dwell，故无 Zeno。∎

**引理 93（柔顺中止的力/冲量界）**
中止时 Z_stop=(M_d,B_max,K_min,0)，回撤速度 ‖v_retreat‖≤v_max，执行器 ‖τ‖∞≤τ_max。接触冲量保守界
```
J ≤ sqrt(2·m_eff·E_stop) + F_max·T_stop
```
其中 E_stop≤E_t+∫P_in≤E_max；故冲量由 E_max、τ_max、v_max 共同界定，不依赖环境刚度估计。∎

**引理 94（块长—能量耦合可行性）**
若 K_eff>1 且 Ĉ^E 有效，则存在一条块执行使 S 在 Π_0 投影下不变；若 E_t < E_min+ΣÊ_cost，则 Ĉ^E 无效，K_eff 降为 1 或进入柔顺保持。故不存在“块太长把能量罐抽干”的接受路径。∎

## 8. 本轮最大风险

**一句话**：无源阻抗与惯性快反射只能保证“接触后”的稳定与能量有界，不能保证“第一次接触”不发生——若把柔顺误当成碰撞避免，系统会在几何风险上留下论证空洞，而域偏移恰恰让几何预测最不可靠。
