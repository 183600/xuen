## 0. 直觉与动机

**灵感 1（社会规范理解 → 规范是第二类风险，且不可直接观测）**
直觉：RAS 的整个风险体系默认「危险 = 世界进入了坏状态」。但人形/通用机器人在人群与赛场里的多数失败不是撞坏东西，而是**物理上安全、社会性上越界**：插队、贴身、盯着人看、在对手发言时抢动作、把「让行」让成「被欺负」。这类失败的共同结构是：
1. **不可直接观测**：规范不写在像素里，只写在他人对行为的反应里；
2. **关系性**：同一动作在不同对象（儿童/老人/裁判/对手）、不同阶段（准备/执行/申诉）下合规性不同；
3. **分层**：硬规则（赛事规则、法律与安全红线）不可交易，软惯例（礼貌、个人空间、轮流）可协商，偏好（风格）可放弃；
4. **可争议**：规范本身有歧义、会漂移、会被强者解释。
因此规范风险必须建模为**潜变量 + 部分可观测的制裁反馈**，而不是一组 if-else。

**灵感 2（UniBot 世界挑战赛 → 规范被制度化的天然实验台）**
直觉：把「UniBot 世界挑战赛」这类通用机器人赛事抽象出来，它恰好提供了规范研究的理想受控结构：
- **规则书 = 部分规范**：明文但歧义，是规范的先验而非全貌（→ 契约解析 + 保形歧义集）；
- **裁判 = 制裁神谕**：稀疏、延迟、带噪声，且不同裁判宽严不一（→ 延迟制裁归因 + 裁判可靠性建模）；
- **多赛项 = 规范先验迁移**：共享「不碰撞/不越界/尊重对手」，但个人空间、节奏、交互礼节各异（→ 分层贝叶斯迁移）；
- **对手 = 关系性规范**：对手会利用你的合规（合法占位逼你让行）——规范既是约束也是被武器化的攻击面（→ 对手类型推断 + 可被利用性预算）；
- **公开榜单 = 声誉**：合规不是没有成本的，过度保守会输掉比赛（→ 合规 vs 任务的显式权衡，而非「越合规越好」）；
- **未知赛项与 Sim2Real = 规范与观测的双重漂移**（→ 与 R68 的标定层/分布界联动）。
赛事把「社会规范」从哲学概念压成了一个可测量、可失败、可对抗的工程问题。

**灵感 3（两灵感合流 → NORM-RAS 七组件）**
规范理解给出表示/推断/监控，赛事给出制度化反馈与对抗压力，合成闭环：
1. **NCL Normative Contract Layer**：规则书 → 可执行 STL 契约集（保形歧义集，而非单一解析）；
2. **NIO Norm Inference Observer**：规范潜状态 n_t（激活规范集 + 参数 + 社会语境）的贝叶斯滤波，硬规范只许被动观测；
3. **NCM Norm Compliance Monitor**：STL 鲁棒度 ρ_k 的在线分级监控（有裕度，不是二值）；
4. **NSA Normative Shield & Arbitration**：可行动集 A_adm 上的最小干预盾 + 词典序回退（硬物理 > 硬规范 > 任务 > 软规范）；
5. **OAM Opponent Norm Modeling**：对手规范类型推断、可被利用性预算、合法强硬模式；
6. **RCL Referee-in-the-Loop**：延迟稀疏制裁的反事实归因，只更新软规范与裁判可靠性；
7. **NCT Norm-Curriculum Transfer + CALM-RAS†**：跨赛项的规范先验迁移；R68 的标定、自监督、认证提交全部保留。

**灵感 4（对 R68 风险的对症下药，以及规范版「原罪」的提前防守）**
- R68 的「标定吸收缓变故障」在规范域有精确同构：**规范吸收**——机器人会把对手持续的越界（合法占位、语言施压）慢慢吸收成「我本就应该让」，从而在合规的名义下不断退让。对策：**硬规范不可学习（norm non-erosion）** + 让行代价记账 + 可被利用性预算触发「合法强硬」。
- R68 的 U(ĉ) 高则收缩，升级为 **U_norm 高则收缩且只向保守侧**：规范不确定时禁止任何「赌一把更高效」的探索性动作（定义 293-iii），因为规范探索本身就是越界。
- R68 的 canary 不可修复，升级为 **硬规范红线不可被在线反馈软化**：制裁只能更新软规范参数与裁判可靠性，硬规范修改必须人工批准并写入证书版本链——这直接封死「靠裁判漏判学会违规」的奖励黑客通道。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（NORM-RAS 总览）** NORM-RAS = (NCL, NIO, NCM, NSA, OAM, RCL, NCT, CALM-RAS†)。三条不变式：
(i) **规范不可侵蚀（norm non-erosion）**：所有 h_k = 1 的硬规范在在线更新中只可收紧、不可放宽；任何放宽必须经人工批准并写入 J_NORM 版本链；
(ii) **词典序安全**：动作选择顺序为「硬物理安全 ≻ 硬规范 ≻ 任务收益 ≻ 软规范舒适度」；前一层的可行集为空时才允许进入下一层，且必须记录例外并要求裁决；
(iii) **被动规范学习**：禁止以故意越界作为规范探索手段；硬规范参数只能从规则文本、示范、第三方行为与已发生的制裁中被动估计。

**定义 294（规范契约）** 单条规范 φ_k = (id, scope_k, precond_k, ψ_k, θ_k, s_k, h_k, prov_k)。其中 ψ_k 为可观测谓词（相对距离、进入区域、注视时长、接触力、动作时序、占用与轮次）上的 STL 公式；θ_k 为可调参数（如个人空间半径、近人限速、轮流等待上限）；s_k ∈ ℝ⁺ 为严重度；h_k ∈ {0,1} 为硬度；prov_k 为来源（规则条款 / 人类指令 / 示范 / 默认惯例）。契约集 Φ = {φ_k}。

**定义 295（规则文本到契约的保形歧义集）** NCL 把规则文本 R 与人类补注解析为候选契约集 S_R = {Φ^(1), …, Φ^(m)}，并给出保形保证 P(Φ* ∈ S_R) ≥ 1 − α_conf，其中 Φ* 为真实生效规范。解析链 = LLM 结构化抽取 → 符号合法性校验（谓词可观测、参数可执行）→ 人工抽检；歧义不做单选，而是保留整个 S_R 作为鲁棒约束集。

**定义 296（规范潜状态）** n_t = (A_t, θ_t, c_t^soc)：A_t ⊆ {1..K} 为当前激活规范集，θ_t 为参数向量，c_t^soc 为社会语境（对象身份、角色、空间、任务阶段）。分段平稳：P(n_{t+1}=n_t) = 1 − ε_switch，否则按语境先验重采样（A95：规范在每个交互回合内平稳，跨回合可漂移）。

**定义 297（制裁观测模型）** 制裁 y_t ∈ ({0,1}^K ∪ {∅}) 表示「某规范是否被判定越界」，具有三重劣化：
- 延迟：在事件后 d ≤ d_max 才到达；
- 稀疏：只有部分越界被制裁（P(sanction | violation) = q_k < 1）；
- 有偏：裁判类型 r ∈ ℛ 决定宽严与噪声 p_r(y | violation)。
隐式信号（人的回避、皱眉、迟疑、对手让行/抢占）作为弱标签并入观测，权重 w_imp ≪ w_ref。

**定义 298（规范监控 NCM）** 对轨迹片段 τ，STL 鲁棒度 ρ_{ψ_k(θ_k)}(τ) 为分级裕度（ρ ≥ 0 满足，ρ < 0 越界，|ρ| 为距离边界的程度）。监控器在线增量计算，输出逐规范裕度向量 ρ_t = (ρ_{k,t}) 及时刻的「即将越界预警」ρ̇ < 0。

**定义 299（规范风险）** R_norm(π) = Σ_{h_k=1} s_k·P_π(ρ_k < 0) + λ_s·Σ_{h_k=0} s_k·softplus(−ρ_k)。硬规范用**违规概率**（机会约束），软规范用**裕度惩罚**；二者不可互相折算，防止用「多让一步」抵消一次硬规则违规。

**定义 300（可行动集与规范盾 NSA）** A_adm(s) = { a ∈ A : R_phys(s,a) ≤ ε_phys 且 ∀Φ ∈ S_R, ∀h_k=1: ρ_k(s,a) ≥ 0 }。规范盾：
a_out = a*_task 若 a*_task ∈ A_adm；否则 a_out = Π_{A_adm}(a*_task) = argmin_{a∈A_adm} ‖a − a*_task‖²。
若 A_adm = ∅，进入词典序回退（定义 301）。Distortion = ‖a_out − a*_task‖。

**定义 301（词典序回退与最小越界）** 序 ≻：硬物理 > 硬规范 > 任务 > 软规范。A_adm 为空时按该序逐层放松约束。若必须违反硬规范才能保住硬物理安全，则选最小越界动作 argmin_{a} max_{h_k=1} s_k·(−ρ_k(a))_+，同时写入「规则例外」日志并立即升级人类/裁判裁决；若硬物理安全与硬规范同时不可满足，则进入安全停驻并请求人工接管。**禁止系统自行解释哪条硬规范可以被牺牲。**

**定义 302（NIO 规范推断滤波器）** 维护后验 b_t(n_t, r) = P(A_t, θ_t, r | 观测 1:t)。predict 步用切换模型（定义 296+裁判类型转移）；update 步融合三类证据：语境先验 P(A_t | c^soc)、已到达的延迟制裁（经定义 305 归因后才有资格更新）、被动示范与第三方行为。硬规范参数仅做**截断更新**（只允许向更严格方向移动超出认证边界），软规范参数正常贝叶斯更新。输出 (Â_t, θ̂_t, Σ_θ, U_norm)。

**定义 303（规范不确定度与收缩方向）** U_norm = H(A_t)/log K + tr(Σ_θ)/tr(Σ_θ^max)。高不确定时系统不得「取期望最优」，而必须做**分布鲁棒选择**：a_out = argmax_a min_{n ∈ CVaR_β(b_t)} ρ_min(a; n)，即对后验最坏 β 分位的规范配置最大化最小裕度。统一纪律：
λ_norm_floor(U_norm) = max(0.6, 0.8·1[U_norm > τ_norm])，速度与动作幅度上限同步下调；**不确定只许更保守**。

**定义 304（对手规范类型与可被利用性）** 对手类型 θ_o ∈ Θ = {协作, 竞争, 规则利用, 谨慎}，转移先验由赛项与历史给出。观察到对手动作后做贝叶斯类型更新。定义**可被利用性缺口** G_exp = R_task(合规策略) − R_task(对 θ_o 的最优反应)。系统维护任务性能下限 R_floor：若 G_exp > β·R_task^ref，判定「合规陷阱」，切换到**合法强硬模式**（仍严格满足硬规范，但按最优反应行动、拒绝额外让行、必要时呼叫裁判）；合规是约束而非目标，因此不存在「越让越好」的单调性。

**定义 305（RCL 延迟制裁反事实归因）** 制裁事件在 t_e 到达时，回看窗口 W 内的候选动作集 {a_i}。用世界模型对每个候选做反事实重放，计算 Δρ_k^{(i)} = ρ_k(执行 a_i) − ρ_k(执行实际动作)，责任度 ℓ_i = softmax(Δρ_k^{(i)}/T)。若唯一主因（最大 Δρ 比次大者高 margin m）则更新对应软规范参数/严重度与裁判可靠性；若多因并列，则**冻结软规范更新**并把该事件当作硬规范不确定证据（加严而非放宽）。

**定义 306（规范 POMDP，N-POMDP）** N-POMDP = (S, A, O, N, T, Z, R_task, {φ_k}, Y)。信念 b(s, n, θ_o, r)；目标是受约束 POMDP：
max_π E[Σ γ^t R_task] s.t. Σ_k P(ρ_k < 0) ≤ δ_hard，用机会约束拉格朗日 + 规范盾在线实现。该形式化显式拒绝把规范并入单一奖励——那是规范退化为可交易项的第一步。

**定义 307（跨赛项规范迁移 NCT）** 规范先验分解为「赛事无关基底」与「赛项特异偏移」：p(Φ_event) = p(Φ_base)·p(ΔΦ_event | event)。基底来自通用社会规范与规则书共性，偏移用分层贝叶斯少样本更新（≤ 3 个交互回合）。课程从低对抗赛项到高对抗赛项，先学规范结构再学利用关系。

**定义 308（J_NORM 证书）** J_NORM = (J_CALM, contract_hash, α_conf, coverage_emp, Â_t, θ̂_t, U_norm, min_{Φ∈S_R} min_k ρ_k, attribution_log, G_exp, norm_ver)。Valid ⇔ Valid(J_CALM) ∧ 经验覆盖 ≥ 1 − α_conf − ε_cov ∧ 在所有候选契约下硬规范裕度 min ≥ 0 ∧ 无规范侵蚀记录 ∧ 无未裁决的规则例外。

**定义 309（E_NORM 干扰集）** E_NORM = E_CALM × E_contract × E_infer × E_sanction × E_opp。
- E_contract = {规则文本歧义、条款缺失、解析错误、规则版本漂移}；
- E_infer = {规范误推断、语境错配、跨文化误迁移}；
- E_sanction = {制裁延迟/稀疏/噪声、裁判宽严漂移、漏判诱导的奖励黑客}；
- E_opp = {合规陷阱、合法占位、规范武器化、声誉操纵}。

**定义 310（管线）** 离线：规则书 → NCL 保形契约集 → 人工核验 → 在示范/仿真上预训练 NCM 与 OAM → 跨赛项元训练 NCT。在线：CALM-RAS 主环路内嵌 NCM 监控 + NSA 盾；NIO 被动更新；RCL 对延迟制裁做反事实归因（只动软规范）；每回合结束刷新 J_NORM 与可被利用性缺口。

# IP-253 NCL：规则文本 → 保形契约集（保留歧义，不强行单选）
class NormativeContractLayer:
    def parse(self, rulebook, annotations, alpha_conf=0.1):
        cands = [self.llm_to_stl(r, annotations) for r in self.split_rules(rulebook)]
        cands = [c for c in cands if self.symbolic_check(c)]      # 谓词可观测、参数可执行
        self.human_spot_check(cands)
        return ConformalSet(cands, alpha_conf)                     # P(Φ* ∈ S_R) ≥ 1-α

    def hard_norms(self, S_R):
        # 鲁棒口径：任一候选下的硬规范都生效，取交集而非投票
        return [phi for Phi in S_R for phi in Phi if phi.h == 1]


# IP-254/255 NIO + NCM：被动规范滤波 + 在线 STL 分级监控
class NormInferenceObserver:
    def update(self, ctx, sanctions, demonstrations, wm):
        self.predict(switch_model=EPS_SWITCH, referee_type_prior=self.r_prior)
        attrs = [resolve_delayed_y(y, wm) for y in sanctions if y.arrived]  # 经 RCL 归因
        self.bayes_update(ctx_prior=P_A_given_ctx(ctx), y=attrs, demos=demonstrations)
        self.truncate_hard_norms()          # 硬规范只许更严，不许放宽（定义 302）
        return self.belief                      # (Â, θ̂, Σ_θ, U_norm)


class NormComplianceMonitor:
    def robustness(self, traj, phi, theta):
        return stl_robustness(phi.psi, traj, phi.scope, phi.precond)  # ρ>0 满足，|ρ| 为裕度

    def alert(self, rho, rho_dot):
        return {k: ('warn' if rho[k] < WARN_MARGIN and rho_dot[k] < 0 else
                    'viol' if rho[k] < 0 else 'ok') for k in rho}


# IP-256 NSA：词典序规范盾（最小干预 + 空集回退）
def normative_shield(a_task, state, S_R, belief, wm, eps_phys):
    A_adm = [a for a in candidate_actions(a_task)
             if wm.risk(state, a) <= eps_phys
             and all(mtm_calibrated_rho(state, a, phi) >= 0
                     for phi in hard_norms(S_R))]
    if a_task in A_adm:
        return a_task, 0.0                      # 合规零成本（引理 18）
    if A_adm:
        a_out = project_to(A_adm, a_task)       # 最小欧氏干预
        return a_out, norm(a_out - a_task)
    return lexicographic_fallback(a_task, state, S_R, belief)   # 定义 301，+ 人工裁决

## 3. 推导

**引理 16（歧义鲁棒性）** 若规范盾对 S_R 中每个候选契约的硬规范都满足 ρ_k ≥ 0，且 S_R 以概率 ≥ 1 − α_conf 覆盖真实契约 Φ*，则对任意策略轨迹，真实硬规范违规概率 ≤ α_conf + δ_monitor，其中 δ_monitor 为 STL 监控器自身的漏检率。证明：违规只可能发生在「Φ* ∉ S_R」（概率 ≤ α_conf）或「Φ* ∈ S_R 但监控器给出 ρ ≥ 0 而实际 ρ < 0」（概率 ≤ δ_monitor）两种事件之一，取并集界即得。系：把规则歧义显式保留成集合，比强行选一个解析更安全；歧义越大，S_R 越大、可行动集越小，代价是任务收益而非合规性。

**引理 17（延迟稀疏制裁的可归因性）** 设窗口内至多一个动作使某硬规范鲁棒度穿零，且其反事实 Δρ 比次大者大 margin m > 0；制裁以延迟 d ≤ d_max 到达。则 RCL 以概率 ≥ 1 − δ_attr 恢复正确主因，δ_attr 随 m 与 d_max 增大而增大。若多因并列（top2 差 < m），归因集不可分，系统冻结软规范更新并加严——**宁可不学，不可学错而软化**。证明：反事实重放误差有界（世界模型在 R68 的 J_CALM 有效域内），在间隔 m 下正确主因的 Δρ 排序稳定；并列时任何点估计都有一半以上概率错，故只能保守处理。

**引理 18（规范盾最小干预）** 若任务最优动作 a* ∈ A_adm，盾保持不变（零失真）；否则投影 a_out = Π_{A_adm}(a*) 是到可行动集的欧氏最小干预，失真 = dist(a*, A_adm)。当 A_adm 由 STL 约束给出而可能非凸时，用序列凸近似或采样投影，附加误差 ≤ ε_qp 且不改变可行性。系：合规不必然牺牲任务——只要安全集非空且任务最优点未越界，规范层对性能是「零成本」的。

**定理 16（NORM-RAS 端到端规范安全）** 在 A95–A99 下，输出动作满足：
1. 任一硬规范违规概率 ≤ α_conf + δ_attr + δ_monitor + δ_opp，其中 δ_opp 来自对手类型误判导致的语境错配；
2. 硬物理安全继承定理 14（CALM-RAS 的 α 链），且词典序保证「宁犯规不撞人、宁降速不越界、宁请示不猜测」；
3. 规范不可侵蚀：任意在线更新后硬规范约束集单调不放松，故长期运行不会出现「越跑越随便」的规范漂移；
4. 软规范只消耗剩余自由度，且其舒适度预算有上界，不会以软合规为名无限让行。

**定理 17（可被利用性与性能下界）** 对规范武器化对手（合法占位/逼让行），若系统无条件最大化合规裕度，任务收益随对手施压单调下降，可被无限利用；NORM-RAS 以可被利用性缺口 G_exp 为触发器，当 G_exp > β·R_ref 时切换合法强硬模式，故最坏类型下任务收益损失有界：R_task ≥ R_task^compliant − G_exp_max，且硬规范始终满足。系：**合规不是目标函数而是约束**；「越礼貌越好」在对抗环境中是错的，且会被对手当成可优化的攻击面。

**定理 18（硬规范的被动可辨识性极限——本方案的原罪）** 在禁止主动越界探索（定义 293-iii）且制裁稀疏延迟（A96：q_k < 1）下，硬规范的某些参数方向在有限交互内 Fisher 信息奇异或恒为零，因而不可辨识。故任何有限的 J_NORM 只能证明「在 S_R 与已观测制裁下合规」，不能证明「在真实规范下合规」；且 U_norm 可能因缺少激励而**长期低估**这种不可辨识性。推论：过度自信的规范化最危险之处不是算错某条规则，而是把「没被制裁过」误当成「已经学会且合规」。

## 6. 本轮最大风险

**一句话**：NORM-RAS 的全部安全性押在「保形契约集覆盖真规范 + 被动制裁归因」这条单一防线上——而社会规范本质上是**欠定且可争议**的：若真实规范落在 S_R 之外、或硬规范参数在稀疏延迟制裁下不可辨识（定理 18），系统会把「没被制裁过」误当成「已学会且合规」，于是要么把一条错误或过时的规范硬化成不可侵蚀的红线而变得过度保守、输掉比赛，要么在对手的合法占位与规则套利下把「让行」学成美德，**在合规的自我叙事中系统性地丧失竞争力与真正的社会判断力**——这是「规范可被形式化并认证」这一前提的原罪：能被证书证明的合规，永远只是被写下来的那部分规范。

**次级风险与缓解**：
1. **规则歧义被过度硬化**：S_R 过大会导致可行动集收缩 → 保形集只对硬规范做交集、软规范分层放宽，定期人工复核并版本化；
2. **制裁归因错误导致软规范漂移** → 多因并列即冻结、只更新软规范、硬规范永不因制裁放宽（定理 16-3）；
3. **对手类型误判** → 类型后验置信不足时退回默认合规模式并降速，G_exp 触发需连续多回合证据；
4. **跨文化/个体差异误迁移** → 个人空间等参数个体化 + 保守先验 + 主动被动观察（不主动试探）；
5. **规范审计的形式化盲区**：VQAuditor-N 只能审计「已写下的规范」→ 将「未被任何契约覆盖的异常社交反馈」列为待人工标注的新规范候选，避免审计即正义的错觉。

**定义 293（总览与三不变式）** (i) **规范不可侵蚀**：硬规范在线只可收紧，放宽须人工批准并进版本链；(ii) **词典序安全**：硬物理 ≻ 硬规范 ≻ 任务 ≻ 软规范，前层可行集为空才进入后层并记录例外；(iii) **被动规范学习**：禁止故意越界探索，硬规范只从文本/示范/第三方行为/已发生制裁被动估计。

**定义 294–295（契约与保形歧义集）** φ_k 为带参数 STL；NCL 把规则书解析为候选契约集 S_R 并保证 P(Φ*∈S_R) ≥ 1−α_conf；歧义不做单选，硬规范取所有候选的交集（鲁棒口径）。

**定义 296–297（规范潜状态与制裁）** n_t=(A_t,θ_t,c^soc) 分段平稳（切换率 ε_switch）；制裁 y 具延迟、稀疏、按裁判类型有偏三重劣化，隐式社交信号作弱标签。

**定义 298–299（规范监控与风险）** 在线 STL 鲁棒度 ρ_k 分级监控 + 趋势预警；R_norm = 硬规范违规概率（机会约束）+ 软规范裕度惩罚，二者不可互相折算。

**定义 300–301（规范盾与词典序回退）** A_adm = {a: 物理风险 ≤ ε ∧ 所有候选硬规范 ρ ≥ 0}；任务动作合规则零干预，否则最小欧氏投影；A_adm 为空时按词典序回退，必须牺牲硬规范时选最小越界并强制人工/裁判裁决，禁止系统自行解释规则。

**定义 302–303（NIO 与收缩方向）** n_t 的贝叶斯滤波：语境先验 + 延迟制裁 + 被动示范；硬规范截断更新、软规范正常更新；U_norm 高时不取期望最优而做 CVaR 分布鲁棒选择（最大化最坏分位最小裕度），λ_norm_floor 抬升且限速。

**定义 304（对手规范类型与可被利用性）** θ_o ∈ {协作,竞争,规则利用,谨慎} 贝叶斯推断；G_exp 超阈触发合法强硬模式（仍满足硬规范）；合规是约束不是目标，拒绝无限让行。

**定义 305（RCL 延迟制裁归因）** 制裁到达时在窗口 W 内用 WM 反事实重放算 Δρ，责任度 softmax；唯一主因（领先 margin m）才更新软规范/裁判可靠性；多因并列冻结更新并加严。

**定义 306–307（N-POMDP 与跨赛项迁移）** 受约束 POMDP：max 任务收益 s.t. 硬规范违规概率 ≤ δ_hard（机会约束 + 盾实现），显式拒绝把规范并入单一奖励；规范先验 = 赛事无关基底 × 赛项特异偏移，分层贝叶斯少样本适配。

**定义 308–310（证书 / 干扰集 / 管线）** J_NORM Valid ⇔ J_CALM 有效 ∧ 覆盖达标 ∧ 所有候选契约下硬规范裕度 ≥0 ∧ 无侵蚀 ∧ 无未裁决例外；E_NORM = E_CALM × E_contract × E_infer × E_sanction × E_opp；离线解析契约与元训练，在线主环嵌监控/盾/推断/归因。

def normative_shield(a_task, s, S_R, belief, wm, eps_phys):
    A_adm = [a for a in candidate_actions(a_task)
             if wm.risk(s, a) <= eps_phys
             and all(stl_rho(s, a, phi) >= 0 for phi in hard_norms(S_R))]
    if a_task in A_adm: return a_task, 0.0              # 合规零成本（引理 18）

    return lexicographic_fallback(a_task, s, S_R, belief)   # 定义 301 + 人工裁决

# IP-257/258 OAM + RCL：对手类型与延迟制裁反事实归因
class RefereeCreditAssigner:
    def on_sanction(self, event, window, wm, state):
        delta = {a: wm.counterfactual_drho(a, event.k) for a in window.actions}
        top2 = sorted(delta.values(), reverse=True)[:2]
        if top2[0] - top2[1] < MARGIN: return 'AMBIGUOUS', None   # 宁可不学不软化
        return 'ATTRIBUTED', update_soft_norm_only(state, argmax(delta))

    if mode == 'FIRM_LEGAL': a_out = firm_legal_play(a_out, type_post, M.S_R)

## 4. 推导

**引理 16（歧义鲁棒性）** 若盾对 S_R 中每个候选契约的硬规范均满足 ρ ≥ 0，且 S_R 以概率 ≥ 1−α_conf 覆盖真契约 Φ*，则真实硬规范违规概率 ≤ α_conf + δ_monitor。系：把规则歧义保留成集合比强行单选更安全；歧义越大可行动集越小，代价落在任务收益而非合规性上。

**引理 17（延迟稀疏制裁可归因性）** 窗口内唯一主因且 Δρ 领先 margin m 时，RCL 以 ≥ 1−δ_attr 恢复主因；多因并列则冻结软规范更新并加严——宁可不学，不可学错而软化。

**引理 18（规范盾最小干预）** a* ∈ A_adm 时零失真；否则投影是欧氏最小干预，失真 = dist(a*, A_adm)，非凸 STL 下附加误差 ≤ ε_qp 且不破坏可行性。系：安全集非空且任务最优点不越界时，合规对性能零成本。

**定理 16（端到端规范安全）** A95–A99 下：(1) 硬规范违规概率 ≤ α_conf + δ_attr + δ_monitor + δ_opp；(2) 硬物理安全继承定理 14，词典序保证「宁犯规不撞人、宁降速不越界、宁请示不猜测」；(3) 规范不可侵蚀 ⇒ 硬约束集单调不放松，长期运行不出现「越跑越随便」；(4) 软规范只消耗剩余自由度且舒适度预算有上界。

**定理 17（可被利用性与性能下界）** 无条件最大化合规裕度会被合法占位无限利用；NORM-RAS 以 G_exp > β·R_ref 触发合法强硬模式，最坏类型下任务损失有界且硬规范始终满足。系：合规是约束不是目标函数，「越礼貌越好」在对抗环境中是错的。

**定理 18（硬规范被动可辨识性极限——本方案的原罪）** 禁止主动越界探索 + 制裁稀疏延迟 ⇒ 硬规范某些参数方向 Fisher 信息奇异或恒为零，不可辨识；J_NORM 只能证明「在 S_R 与已观测制裁下合规」，不能证明「在真实规范下合规」，且 U_norm 可能因缺少激励而长期低估不可辨识性。推论：最危险的不是算错规则，而是把「没被制裁过」误当成「已学会且合规」。

## 7. 本轮最大风险

**一句话**：NORM-RAS 的全部安全性押在「保形契约集覆盖真规范 + 被动制裁归因」这条单一防线上——而社会规范本质上是**欠定且可争议**的：若真实规范落在 S_R 之外、或硬规范参数在稀疏延迟制裁下不可辨识（定理 18），系统会把「没被制裁过」误当成「已学会且合规」，于是要么把一条错误或过时的规范硬化成不可侵蚀的红线而过度保守、输掉比赛，要么在对手的合法占位与规则套利下把「让行」学成美德，**在合规的自我叙事中系统性丧失竞争力与真正的社会判断力**——这是「规范可被形式化并认证」这一前提的原罪：能被证书证明的合规，永远只是被写下来的那部分规范。

**次级风险与缓解**：规则歧义被过度硬化（硬规范只取交集、软规范分层放宽、人工复核版本化）；制裁归因错误致软规范漂移（多因冻结、只动软规范、硬规范不因制裁放宽）；对手类型误判（置信不足退回默认合规并降速，G_exp 需连续多回合证据）；跨文化误迁移（个体化参数 + 保守先验 + 被动观察）；规范审计的形式化盲区（未被契约覆盖的异常社交反馈列为人工标注候选，避免「审计即正义」的错觉）。
