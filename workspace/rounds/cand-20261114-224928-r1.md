# 第 3 轮（灵感循环；本轮灵感：「评测指标」×「应用落地」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**继续在前人基础上改进，而不是推倒重来**——ToolGauge 解决了「盲区如何被语义理解、契约化探测、摊销校准」，
> 但其全部安全结论都建立在三个未言明的实验室假设上：① **评估是一次性、iid 的**；② **部署是单设备、平稳的**；
> ③ **修复的收益/风险不进入组织与法规闭环**。第 3 轮沿两条灵感轴把 ToolGauge 升级为
> 「可部署、可认证、可召回」的场域系统 **FieldGauge**，并把 ToolGauge 作为其平稳单机退化特例完整保留。

## 三位一体映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 评测指标 | E426–E440 的一次性 benchmark / 固定置信区间 | **E-Box：指标契约 MC + EvalReceipt + 评估契约校验器 ECV** | 指标本身就是计量仪器：必须预注册、误差可控、可审计、抗 Goodhart；否则「测出来的安全」只是可被反复窥探与优化的幻觉 |
| 应用落地（治理） | 单机 6C 修复闭环 | **D-Loop：8C + 灰度发布 + 错误预算 + 归因选择性召回** | 修复不是终点，**持续证明「仍在安全包络内」**才是；落地要求爆炸半径可控、可回滚、可对监管交代 |
| 应用落地（规模化） | 单机 AP-Cal / 单机 P-Quarantine | **F-Box：分层联邦校准 + 舰队风险账本 + 共模污染检测** | **单机安全不蕴含舰队安全**；共享先验一旦偏移，会在同一时刻让万台设备相关失效——相关失效才是落地杀手 |

**核心命题**：把 ToolGauge 的「局部修复安全」升级为「**舰队级、持续有效、可认证的部署安全**」：
评估从一次性点估计升级为 **anytime-valid 置信序列 / e-process**（任意时刻偷看都保持错误率控制）；
部署从单机热替换升级为 **灰度 → 监控 → 归因 → 召回**的闭环（错误预算约束累计曝光）；
指标从标量 benchmark 升级为「**安全约束优先的词典序指标向量 + 可机检部署证据图**」。
ToolGauge 的数值真值独占、VLA 降格审计、严格退化链全部保留。

**不变式保持声明**：
- MODGAUGE 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）全部保留；
- 新增第六条「**部署可认证性不变式**」：任何对外声称的安全结论，必须在部署证据图 DEG 中存在一条从「五+一不变式」到「部署契约 DC 条款」、且只由有效回执支撑的路径；缺失即降级为「未认证（UNVERIFIED）」（部署层扩展，不改变任何数值语义）；
- **严格退化链延长**：FieldGauge 失效（监控/账本/证书不可用）⇒ 冻结在最后认证 EC、退回 ToolGauge 单机模式 ⇒ 再退回 LeanGauge 数值探测 ⇒ 再退回 MODGAUGE。评测与部署层是增强项，不是新依赖项。

## 0. 直觉与动机

**灵感 1（评测指标 → 把「评估」本身当作计量仪器）**
直觉：ToolGauge 的 E426–E440 是「一次性实验 + 看均值/看 p 值」的评测。可是现场工程师、审计员、监管者会**反复偷看**指标并据此扩大发布——经典置信区间在可选停止（optional stopping）下失效，等于给了一个「越看越宽松」的假保证。更糟的是，指标一旦成为 KPI 就被 Goodhart 游戏化：优化「修复成功率」会诱导系统只修容易的盲区、把难盲区一律标 UNKNOWN；优化「覆盖率」会诱导无差别乱探测。
解药：对**评估**施加与 ToolGauge 对**探测**施加的同一套计量纪律——每个指标是一台仪器，必须声明被估量、零假设、误差保证类型、最小可检测效应、成本、以及**游戏面清单**；评估计划由 **ECV** 校验（预注册、多重比较预算、数据泄漏、污染上界、捷径覆盖）；核心统计对象从「点估计 ± 一次性 CI」升级为 **e-process / 置信序列**：任意时刻偷看都保持族错误率，多个指标用 e-value 合并与 alpha-spending 控制。

**灵感 2（应用落地 → 部署是长时程非平稳过程，不是一次上线）**
直觉：实验室里设备平稳、样本 iid、后果有限；现场里材质轮换、温漂、磨损、传感器与软件老化让分布持续漂移，而且**单机安全不蕴含舰队安全**：若一万台设备共享同一错误的 AP-Cal 先验（第 2 轮最大风险），失效率会**强相关地同时爆发**，恰好击穿所有基于独立同分布的统计兜底。落地还需要灰度（先 1% 再 100%）、错误预算（允许的累计风险曝光）、自动召回（事故时缩小爆炸半径）、人工审计与法规证据链。
解药：把 6C 扩成 **8C**（+M 持续监控 +R 归因召回）；用**错误预算**约束累计曝光；用**分层/联邦校准**把单机后验与舰队先验分离；用**平均 e-value** 处理设备间任意相关（尤其正相关）而不假设独立——有效性不破，只是功效下降（保守而非反保守）。

**灵感 3（评测 × 落地的交叉 → 标量化是 Goodhart 放大器，安全-活性必须词典序）**
直觉：组织天然把复杂目标压成一个标量 KPI，而标量化正是 Goodhart 的放大器：只要权重可见，对手就能在**完全不改善真实安全**的情况下抬高综合分。安全（认证风险上界 CRUB）与活性（修复成功率/覆盖率/效率）在 Pareto 意义上是冲突的；固定权重求和会把「看起来安全」卖成「安全」。
解药：**词典序验收 LO-Accept**——安全约束是硬约束，活性/效率只在可行域内最大化；同时给出**游戏化鲁棒估计**（median-of-means / 截尾，带 breakdown point）与**污染比例上界**；任何标量化排名都必须附带 Pareto 前沿与其与「真实安全方向」的夹角，禁止单独作为验收依据。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（指标契约 MC）** 评测指标 M = (name, θ_M, H0_M, guar_M, δ_M, sens_M, G_M, c_M, ν_M)：
- θ_M：被估量（如「盲区修复后 30 天误动作率」「certified repair success」「误修复率」）；
- H0_M：零假设与方向；guar_M ∈ {point, CI, anytime, e-process}：保证类型；δ_M：名义错误率；
- sens_M：最小可检测效应（power 设计）；G_M：**游戏面清单**（可被哪些捷径操纵，如「只修易盲区」）；
- c_M：采集/标注/计算成本；ν_M：刷新频率。
**可再生性**：M 必须绑定数据快照哈希与预注册分析计划；任一缺失即指标无效，其回执不得进入证据图。

**定义 433（评估回执 EvalReceipt）** r_E = (M, data_hash, n, θ̂, cert, sig, ts, seq)，cert 为 CI 或 e-process 序列；
valid(r_E) ⇔ 预注册 ∧ 数据未复用 ∧ Verify(sig) ∧ seq 单调 ∧ 族错误预算未超支。
与定义 417 同构：**无效评估回执永不进入决策**（不因「看起来显著」而例外）。

**定义 434（评估契约校验器 ECV）** 对评估计划 Π_E 逐条检查：
① 预注册（指标 / 停止规则 / 分析脚本三哈希一致）；
② 多重比较与 alpha-spending 预算 Σδ ≤ δ_family；
③ 数据切分与泄漏检测（训练 / 校准 / 评估三者独立，含设备与时间泄漏）；
④ 污染上界 ε_contam 已声明（见定义 441）；
⑤ 游戏面清单覆盖所有已知捷径。
任一失败 ⇒ 该评估回执不得进入证据图；**ECV 拒绝不产生任何发布副作用**（与 TCV 的零副作用对偶）。

**定义 435（anytime-valid 风险过程）** 对逐条到达的单元结果 X_t ∈ [0,1]（如「该次修复是否发生危险事件」），
对每个预注册网格点 θ_0 ∈ Θ_grid（权重 w(θ_0)）构造 e-process
E_t(θ_0) = ∏_{i≤t} (1 + λ_i (X_i − θ_0))，λ_i 预注册且保证因子非负。
在 H0: θ* ≥ θ_0 下，E_t(θ_0) 为非负上鞅（E_0=1）。由 Ville 不等式与网格 union bound：
P(∃t: θ* > CRUB_t) ≤ Σ_{θ_0} w(θ_0)·P(sup_t E_t(θ_0) ≥ 1/(δ w(θ_0))) ≤ δ。
**认证风险上界** CRUB_t = min{θ_0 ∈ Θ_grid : E_t(θ_0) ≥ 1/(δ w(θ_0))}（无则取 1）。
**任意停时有效**：可无限次偷看、可数据依赖地决定是否扩大发布，仍保持 type-I 控制——这是对 ToolGauge「一次性 CI」的实质升级。

**定义 436（舰队风险账本 FRL）** 设备 d ∈ D 各自维护 E_t^{(d)}(θ_0)；舰队级证据取**平均 e-value**
Ē_t(θ_0) = (1/|D|) Σ_d E_t^{(d)}(θ_0)。
由线性期望，**e-value 的凸组合仍是 e-value**（Vovk–Wang），故 Ē_t 对 H0: (1/|D|)Σ_d θ_d ≥ θ_0 有效，**无需设备独立假设**。
设备正相关时功效下降但**有效性不破**（保守）；独立性已知时可改用乘积 e-value 提升功效。
**风险预算 B_fleet**：允许的累计期望危险曝光；发布/召回决策受其约束（错误预算思想）。

**定义 437（F-Box 分层联邦校准）** 设备 d 的契约参数 u_{s,d} ~ 𝒩(μ_shared + a_d, Σ_shared + Σ_d)，a_d 为设备随机效应：
共享层由 MP-Φ 摊销先验给出，设备层用本机回执做**部分池化**；联邦更新只上传充分统计量 / 加噪梯度（隐私与带宽）。
共享层后验收缩残差跨设备**同向** ⇒ 触发**舰队级 P-Quarantine**（缩写定义 428，从单机监控扩为共模监控）。
退化：令 a_d=0、Σ_d=0、D={1} ⇒ 精确退化为 ToolGauge 的 AP-Cal。

**定义 438（部署契约 DC）** DC = (B_fleet, R_max, SLO, stages, rollback_policy, audit_SLA, reg_envelope)：
B_fleet 累计风险曝光预算；R_max 可接受认证风险上界；SLO 时延/可用性/成本；stages = {(n_k, δ_k)} 灰度阶段与 gate；
rollback_policy 召回触发/范围/迟滞；audit_SLA 人工审计响应时限；reg_envelope 法规标准条款映射。
**可行性谓词** Feasible(DC) ⇔ 存在策略使 P(∀t: CRUB_t ≤ R_max) ≥ 1−δ_family 且 SLO 与预算满足。
DC 是 TB-Contract（424）与 IV-Contract（407）的部署层细化，时序结论继承引理 45/50。

**定义 439（灰度发布与 alpha-spending）** 阶段 k 在 n_k 个新设备/新 EC 上部署，Gate_k 用预注册 δ_k（Σδ_k ≤ δ_family）判定是否扩大。
总 type-I 曝光 ≤ Σδ_k（group-sequential 思想）；canary 爆炸半径上界为 n_k·c_fail。
**fail-closed**：Gate 未过不进入下一阶段；已部署子集按 rollback_policy 回滚。

**定义 440（归因与选择性召回）** 召回前先做**归因**：把违规证据分解到（设备子集 × 盲区 × 材质/环境 × EC 版本），
用似然比 / e-value 贡献度定位**共模**（多设备同向，指向共享先验或 EC 版本）还是**局部**（单设备硬件/安装）。
召回集合 S_recall ⊆ D × EC，遵循**最小充分召回**（覆盖所有被证据支持的风险源）与**防振荡迟滞**（连续 q 窗超限才召回，连续 q′ 窗恢复才复部署）。
共模证据 ⇒ 召回整个共享先验 / EC 版本；局部证据 ⇒ 只召回单设备子集。

**定义 441（Goodhart 鲁棒聚合）** 给定污染比例上界 ε_contam，用 median-of-means / 截尾均值聚合设备级结果，
要求估计器 breakdown point > ε_contam（定义 432④ 的落地）。
对任何标量化 S = Σ_k w_k M_k，定义**游戏放大因子** κ(S) = ‖w‖₂ / ‖w‖₁ 与安全-得分夹角 cos∠(w, u)（u 为真实安全方向）：
κ 越小、夹角越大，越容易被「不影响 u 的捷径」抬高 S。验收禁止仅用 S（定义 442）。

**定义 442（词典序验收 LO-Accept）** 验收按 lexicographic：
① 硬约束 CRUB ≤ R_max（安全）；
② 在可行域内最大化活性 U（修复成功率 / 覆盖率）与效率（cost / energy）；
③ 最后才比较标量分数。
**安全优先**：任何以牺牲 ① 换取 ② 或 ③ 的策略一律拒绝，即使综合分更高。

**定义 443（8C 部署闭环）** H→C→E→C→V→U→M→R：
前 6 段继承 6C（定义 421）；M：E-Box 持续产出 anytime-valid 风险过程并更新 FRL；R：CRUB 越限 / 共模告警 ⇒ 归因（440）⇒ 选择性召回（440）⇒ 冻结或重校准；复部署需满足 DC 的 re-deploy gate。
**离散状态机**：CERTIFIED → CANARY → DEPLOYED → SUSPECT → RECALLED → RECERTIFYING，全部转移携带回执与签名（可审计）。

**定义 444（部署证据图 DEG）** 有向图 G_E：节点 = 主张（claim）/ 指标契约 / 评估回执 / 盲区 / EC 版本 / 法规条款；
边 = 「支持 / 反驳 / 绑定」。
**可认证性**（部署可认证性不变式）：一份证书机器可检地有效 ⇔ 从「系统仍满足五+一不变式」到「DC 条款」存在只由 valid 回执支撑的路径。
DEG 把定义 423 的「语言主张-回执绑定」从句子级推广到**组织级与法规级主张**：审计从「读报告」变为「查图」。

**定义 445（非平稳在线校准）** 用 ACI（adaptive conformal inference）在线更新覆盖水平 α_{t+1} = α_t + η(α − err_t)，
用 CUSUM 检测共享层后验收缩残差的均值漂移；漂移告警与 P-Quarantine（428）级联。
ACI 的长期覆盖误差 O(η) 与 CUSUM 的平均检测延迟 ARL 都写进 SLO，成为**可承诺的运维指标**。

**定义 446（成本-能量-审计联合核算）** 部署代价 J = c_probe + c_energy + c_audit + c_recall + λ_risk·E[损失]；
FieldGauge 在 DC 约束下最小化 J。
**关键**：把人工审计时间、召回停机、合规罚金显式计入——否则系统会在实验室里「便宜」、在现场「昂贵」，形成落地错觉。

**定义 447（继承与编号约定）** 未被重定义的记号沿用 416–431 与 398–415；
FieldGauge 以「单设备 D={1}、平稳、一次性评估、无灰度、无召回」为退化参数 ⇒ 严格退化为 ToolGauge（再退化为 LeanGauge / MODGAUGE）。

```python
# IP-321 E-Box：指标契约 + 评估回执 + ECV
@dataclass
class MetricContract:
    name: str
    estimand: str
    null: str
    guarantee: Literal["point", "ci", "anytime", "eprocess"]
    delta: float
    min_effect: float
    gaming_surface: list[str]
    cost: float
    refresh_s: float

class ECV:
    def verify_plan(self, plan, family_budget):
        if not plan.preregistered:                     return False, "unpreregistered"
        if plan.delta_sum > family_budget:             return False, "alpha_budget"
        if leaks(plan.split):                          return False, "data_leak"
        if plan.contam_bound is None:                  return False, "contam_undeclared"
        if not covers_surface(plan.metric, plan.checks): return False, "goodhart"
        return True, "ok"

# IP-322 R-Box：anytime-valid 风险过程（e-process + 网格反演）
class EProcessRisk:
    def __init__(self, theta_grid, delta, weights, bettor):
        self.grid, self.delta, self.w = theta_grid, delta, weights
        self.logE = {th: 0.0 for th in theta_grid}
        self.bettor = bettor
    def update(self, x):                     # x in [0,1]
        lam = self.bettor(x)
        for th in self.grid:                 # 预注册网格，union bound 已计入
            logf = log1p(lam * (x - th))
            if logf > -700: self.logE[th] += logf
        return self
    def crub(self):                          # 认证风险上界（任意停时有效）
        rej = [th for th in self.grid
               if self.logE[th] >= log(1.0 / (self.delta * self.w[th]))]
        return min(rej) if rej else 1.0

# IP-323 F-Box：分层联邦校准 + 舰队风险账本
class FleetLedger:
    def __init__(self, devices, theta_grid, delta, weights):
        self.per = {d: EProcessRisk(theta_grid, delta, weights, bettor) for d in devices}
    def fleet_evalue(self, th):
        # e-value 的凸组合仍是 e-value：无需设备独立假设
        return sum(e.exp_log(th) for e in self.per.values()) / len(self.per)
    def crub_fleet(self):
        rej = [th for th in self.grid if self.fleet_evalue(th) >= log(1.0 / self.delta)]
        return min(rej) if rej else 1.0

# IP-324 D-Loop：灰度 gate + 归因 + 选择性召回
def deploy_gate(ledger, stage, dc):
    if ledger.crub_fleet() > dc.R_max:            return "RECALL"
    if not stage_passed(stage, ledger, dc.delta[stage]): return "FREEZE"
    return "PROMOTE"

def attribute_and_recall(M, violation):
    support = decompose(violation)                # 设备子集 × 盲区 × 材质 × EC 版本
    if is_common_mode(support, M.ledger):         # 多设备同向 ⇒ 共享先验/EC
        S = M.fleet.ec_versions(violation.ec)
    else:
        S = M.fleet.localize(support)             # 最小充分召回
    M.recall(S, policy=M.dc.rollback_policy)      # 迟滞：避免召回/复部署振荡

# IP-325 8C 闭环
def fieldgauge_8c(M, s):
    if not toolgauge_6c(M, s):                    # 继承 6C（H C E C V U）
        return False
    for x in M.monitor.stream(s):                 # M：持续证据（异步）
        M.ledger.per[s.device].update(x)
        M.ebox.record(EvalReceipt(metric=M.metric(s), x=x, ts=now(), seq=M.seq()))
    if M.ledger.crub_fleet() > M.dc.R_max:        # R：越限 ⇒ 归因 + 召回
        attribute_and_recall(M, M.ledger.last_violation())
        M.state = "SUSPECT"
    return M.state in ("CANARY", "DEPLOYED")

# IP-326 部署主循环（50Hz 主控完全不变）
def FieldGauge_round(M, obs, audio, tac, depth, det):
    M.state = advance_state(M.state, M.ledger, M.dc)   # CERTIFIED→…→DEPLOYED
    if M.state == "SUSPECT":
        M.freeze_probing()                             # 冻结探测，缩小爆炸半径
        M.alert_auditor(M.dc.audit_SLA)
    return ToolGauge_round(M, obs, audio, tac, depth, det)   # 主控不变
```

## 3. 推导

**引理 51（anytime-valid 认证风险）** 设 θ* 为真实危险事件率，X_t ∈ [0,1]。对预注册网格 Θ_grid 与权重 w，
若 E_t(θ_0) 在 H0: θ* ≥ θ_0 下为非负上鞅，则定义 435 的 CRUB_t 满足
P(∀t ≥ 1: θ* ≤ CRUB_t) ≥ 1 − δ。
证明：对每个 θ_0，Ville 不等式给 P(∃t: E_t(θ_0) ≥ 1/(δ w(θ_0))) ≤ δ w(θ_0)；对网格 union bound 得总失败概率 ≤ δ。
系 51.1（可选停止/持续监控）：任意数据依赖的停时与偷看次数均不破坏该界——直接替代 ToolGauge 的一次性 CI（E441）。
系 51.2（决策规则）：当 CRUB_t > R_max 时可停并告警；误报率（对「系统仍安全」的假阳性）≤ δ。

**引理 52（舰队 e-value 合并与相关失效）** 设设备 d 的 E_t^{(d)}(θ_0) 是 H0: θ_d ≥ θ_0 下的 e-value，则平均
Ē_t = (1/|D|)Σ_d E_t^{(d)} 是 H0: (1/|D|)Σ_d θ_d ≥ θ_0 下的 e-value，**无需独立性**（线性期望）。
因此定义 436 的舰队 CRUB 对任意设备相关结构有效。
系 52.1：正相关（共模先验）下 Ē_t 的功效下降但绝不反保守——这正是第 2 轮最大风险（跨盲区/跨设备相关偏差）所需的性质；
若已知独立，改用乘积 e-value ∏_d E_t^{(d)} 可提升功效。
系 52.2：单台异常设备证据极强时平均仍可超阈 ⇒ 对「局部事故」敏感；广泛轻度偏移则较迟钝 ⇒ 需 M 阶段 CUSUM 辅助。

**引理 53（Goodhart 鲁棒界与标量化可游戏性）** 设观测含 ε ≤ ε_contam < 1/2 的任意污染，取值 [0,1]。
median-of-means（k = ⌈8 log(1/δ)⌉ 块）估计满足 |θ̂ − θ| ≤ 2√(log(1/δ)/n) + ε/(1−2ε)（以 1−δ 成立），breakdown point 1/2。
对标量化 S = Σ_k w_k M_k，令 u 为真实安全方向、v 为单位游戏方向：若存在 v ⟂ u 且 w·v > 0，
则对手可在真实安全不变（u 分量不变）时把 S 抬高 (w·v)/(w·u) 倍——**唯一不被游戏的标量化是 w ∥ u，而 u 未知**。
系 53.1：故验收必须用定义 442 的词典序（安全硬约束 + Pareto），标量分数只能作展示，不能作决策。

**引理 54（灰度发布的风险曝光）** 采用定义 439 的 alpha-spending（Σ_k δ_k ≤ δ_family），则在 H0「系统不安全」下
P(任何阶段被错误提升) ≤ Σ_k δ_k ≤ δ_family。
期望曝光 E[exposure] ≤ Σ_k n_k · P(到达阶段 k 且失败) ≤ Σ_k n_k δ_{<k}。
系 54.1：canary 把首次失败的最坏爆炸半径从 N 压到 n_1（n_1 ≪ N）；这是「先小规模证明，再大规模承诺」。

**引理 55（召回正确性与严格退化）** 设上次认证 EC 为 EC_last。选择性召回 S_recall 把 S_recall 内设备回滚到 EC_last，
不影响 S_recall 外设备。则：① 未召回子集的认证性质保持（单调性）；② 召回子集恢复到已知认证点（正确性）；
③ 迟滞 q/q′ > 0 排除有限时间内的召回-复部署振荡。对共模违规召回整个 EC 版本，等价于把退化链机制提升到舰队级。

**引理 56（词典序验收的 Pareto 安全性）** 在定义 442 下，任何被接受的策略满足 CRUB ≤ R_max（硬约束不可交换）；
在可行域内最大化 U 得 Pareto 前沿上的一点。由引理 53，任何有限权重标量化存在非空游戏方向，
故词典序在「不可被安全-得分替代所游戏」意义上严格优于标量化验收。
系 56.1：安全-活性前沿可绘制为 (R_max, max U) 曲线；DC 的 R_max 本质是在该前沿上选点，选点权应交由监管/责任方，而非算法。

## 6. 本轮最大风险（一句话）

**一句话**：指标契约与部署认证层会把「安全」压缩成**可被单点污染的度量**——一旦某个指标定义错误、被 Goodhart 游戏化、或评估数据被污染，舰队级 anytime-valid 证书与自动召回就会把局部评估误差放大成**全局误认证 / 误召回**，形成「**认证剧场**」：系统获得了组织与法规背书，却失去了真实的物理安全。

**次级风险与缓解**：
1. **共模相关失效**（共享先验全舰队同向偏移）→ F-Box 部分池化 + 平均 e-value 有效但保守 + 舰队级 P-Quarantine（引理 52）；
2. **指标游戏化** → MC 游戏面清单 + 鲁棒聚合 breakdown point + 词典序（定义 432/441/442、引理 53）；
3. **anytime-valid 功效损失**（持续监控比一次性检验更保守）→ 预注册网格 + 乘积 e-value（已知独立时）+ 联合指标 e-value 合并；
4. **误召回 / 召回振荡** → 最小充分召回 + 归因 + 迟滞 q/q′（定义 440、引理 55）；
5. **认证剧场** → DEG 只接受 valid 回执路径 + 第三方可机检 + 定期对抗审计（定义 444、E449）；
6. **灰度 gate 被政治压力绕过** → alpha-spending 预注册 + fail-closed 状态机 + 审计留痕；
7. **法规条款映射过时** → reg_envelope 版本化 + 条款到期自动触发 UNVERIFIED（定义 438/444）。

## 2. 形式化定义（要点）

**定义 432（MC）/ 433（EvalReceipt）/ 434（ECV）** 指标是可审计仪器：声明被估量、零假设、误差保证类型、最小可检测效应、成本与游戏面；评估回执带数据哈希、样本量、证书、签名与单调 seq；ECV 拒绝未预注册、超 alpha 预算、数据泄漏、未声明污染上界、未覆盖已知捷径的评估计划，且**拒绝无发布副作用**。

**定义 435（anytime-valid 风险过程）** 对 X_t∈[0,1] 与网格 θ_0，E_t(θ_0)=∏(1+λ_i(X_i−θ_0)) 在 H0:θ*≥θ_0 下为非负上鞅；Ville + 网格 union bound 得 P(∀t: θ*≤CRUB_t) ≥ 1−δ；CRUB_t = min{θ_0: E_t(θ_0) ≥ 1/(δ w(θ_0))}。任意停时有效。

**定义 436（FRL）** Ē_t = mean_d E_t^{(d)}；e-value 的凸组合仍是 e-value（线性期望），故对 (1/|D|)Σθ_d 有效，**无需独立**。正相关下功效降、有效性不破；独立已知时用乘积提升功效。

**定义 437（F-Box）** u_{s,d} ~ 𝒩(μ_shared + a_d, Σ_shared + Σ_d)；共享层来自 MP-Φ，设备层用本机回执部分池化；联邦只传充分统计量/加噪梯度；共享层残差跨设备同向 ⇒ 舰队级 P-Quarantine。a_d=0,Σ_d=0,D={1} ⇒ 退化为 AP-Cal。

**定义 438（DC）** Feasible(DC) ⇔ 存在策略使 P(∀t: CRUB_t ≤ R_max) ≥ 1−δ_family 且 SLO/预算满足；是 TB-Contract/IV-Contract 的部署细化。

**定义 439（灰度 + alpha-spending）** Σδ_k ≤ δ_family；失败即冻结（fail-closed）；canary 爆炸半径 ≤ n_k·c_fail。

**定义 440（归因 + 选择性召回）** 证据分解到（设备 × 盲区 × 材质 × EC 版本）；共模 ⇒ 召回共享 EC/先验；局部 ⇒ 单设备；最小充分 + 迟滞 q/q′。

**定义 441（Goodhart 鲁棒聚合）** ε_contam 下用 median-of-means/截尾，要求 breakdown point > ε_contam；标量化 S 的游戏放大因子 κ(S)=‖w‖₂/‖w‖₁ 与安全-得分夹角 cos∠(w,u)。

**定义 442（LO-Accept）** 安全硬约束 → 活性/效率 → 标量分，lexicographic；牺牲安全换综合分一律拒绝。

**定义 443（8C）** 6C + M（anytime-valid 监控）+ R（越限⇒归因⇒召回⇒冻结/重校准）；状态机 CERTIFIED→CANARY→DEPLOYED→SUSPECT→RECALLED→RECERTIFYING，全部转移带签名回执。

**定义 444（DEG）** 节点=主张/指标契约/评估回执/盲区/EC/法规条款，边=支持/反驳/绑定；证书有效 ⇔ 存在只由 valid 回执支撑的路径（部署可认证性不变式）；把定义 423 推广到组织/法规级。

**定义 445（非平稳在线校准）** ACI: α_{t+1}=α_t+η(α−err_t)；CUSUM 检测共享层残差漂移；长期覆盖误差 O(η) 与 ARL 写入 SLO。

**定义 446（联合核算）** J=c_probe+c_energy+c_audit+c_recall+λ_risk·E[loss]，在 DC 约束下最小化；显式计入审计、停机、合规罚金。

**定义 447（退化约定）** 单设备/平稳/一次性评估/无灰度/无召回 ⇒ 精确退化为 ToolGauge，再退化 LeanGauge/MODGAUGE。

## 3. 关键算法骨架

# IP-321 E-Box：指标契约 + ECV
@dataclass
class MetricContract:
    name: str; estimand: str; null: str
    guarantee: str                 # point | ci | anytime | eprocess
    delta: float; min_effect: float
    gaming_surface: list[str]
    cost: float; refresh_s: float

class ECV:
    def verify_plan(self, plan, family_budget):
        if not plan.preregistered:                    return False, "unpreregistered"
        if plan.delta_sum > family_budget:            return False, "alpha_budget"
        if leaks(plan.split):                         return False, "data_leak"
        if plan.contam_bound is None:                 return False, "contam_undeclared"
        if not covers_surface(plan.metric, plan.checks): return False, "goodhart"
        return True, "ok"

# IP-322 R-Box：e-process + CRUB
class EProcessRisk:
    def __init__(self, grid, delta, weights, bettor):
        self.grid, self.delta, self.w = grid, delta, weights
        self.logE = {th: 0.0 for th in grid}; self.bettor = bettor
    def update(self, x):                        # x in [0,1]
        lam = self.bettor(x)
        for th in self.grid:
            self.logE[th] += log1p(lam * (x - th))
        return self
    def crub(self):
        rej = [th for th in self.grid
               if self.logE[th] >= log(1.0 / (self.delta * self.w[th]))]
        return min(rej) if rej else 1.0

# IP-323 F-Box：舰队账本（平均 e-value，无需独立）
class FleetLedger:
    def __init__(self, devices, grid, delta, weights):
        self.per = {d: EProcessRisk(grid, delta, weights, bettor) for d in devices}
        self.grid, self.delta = grid, delta
    def crub_fleet(self):
        rej = []
        for th in self.grid:
            avg = sum(e.logE[th] for e in self.per.values()) / len(self.per)
            if avg >= log(1.0 / self.delta): rej.append(th)
        return min(rej) if rej else 1.0

# IP-324 D-Loop：灰度 gate + 归因 + 选择性召回
def deploy_gate(ledger, stage, dc):
    if ledger.crub_fleet() > dc.R_max:                    return "RECALL"
    if not stage_passed(stage, ledger, dc.delta[stage]):  return "FREEZE"
    return "PROMOTE"

def attribute_and_recall(M, violation):
    support = decompose(violation)            # 设备子集 × 盲区 × 材质 × EC 版本
    S = (M.fleet.ec_versions(violation.ec) if is_common_mode(support, M.ledger)
         else M.fleet.localize(support))      # 共模全部；局部最小充分
    M.recall(S, policy=M.dc.rollback_policy)  # 迟滞防振荡

# IP-325 8C 闭环
def fieldgauge_8c(M, s):
    if not toolgauge_6c(M, s): return False            # 继承 6C
    for x in M.monitor.stream(s):                      # M：持续证据（异步）
        M.ledger.per[s.device].update(x)
        M.ebox.record(EvalReceipt(M.metric(s), x, now(), M.seq()))
    if M.ledger.crub_fleet() > M.dc.R_max:             # R：越限 ⇒ 归因召回
        attribute_and_recall(M, M.ledger.last_violation()); M.state = "SUSPECT"
    return M.state in ("CANARY", "DEPLOYED")

# IP-326 部署主循环（50Hz 主控不变）
def FieldGauge_round(M, obs, audio, tac, depth, det):

## 4. 推导

**引理 51（anytime-valid 认证风险）** E_t(θ_0) 在 H0:θ*≥θ_0 下为非负上鞅；Ville + 网格 union bound ⇒ P(∀t: θ*≤CRUB_t) ≥ 1−δ。
系 51.1：任意停时/无限偷看不破坏界（替代一次性 CI）。系 51.2：CRUB_t>R_max 时告警，误报率 ≤ δ。
**引理 52（舰队 e-value 合并）** Ē_t=(1/|D|)Σ_d E_t^{(d)} 是 H0:(1/|D|)Σ_d θ_d≥θ_0 的 e-value，**无需独立**（线性期望）；
正相关下功效降但绝不反保守；独立已知时用乘积提升功效；单台强证据仍可触发（局部敏感）。
**引理 53（Goodhart 鲁棒界）** ε<breakdown 时 median-of-means 误差 ≤ 2√(log(1/δ)/n)+ε/(1−2ε)，以 1−δ 成立；
标量化 S=Σw_k M_k 存在 v⟂u 且 w·v>0 时可按 (w·v)/(w·u) 抬高而真实安全不变 ⇒ 唯一免疫是 w∥u（u 未知）⇒ 必须词典序。
**引理 54（灰度曝光）** Σδ_k≤δ_family ⇒ P(任何错误提升) ≤ δ_family；期望曝光 ≤ Σ n_k δ_{<k}；canary 把最坏半径从 N 压到 n_1。
**引理 55（召回正确性/严格退化）** 选择性召回回滚到 EC_last：未召回子集性质保持（单调）、召回子集恢复已知认证点（正确）、迟滞排除振荡。
**引理 56（词典序 Pareto 安全）** 接受策略必满足 CRUB≤R_max；可行域内最大化 U；任何有限权重标量化存在游戏方向，故词典序严格更安全。
系 56.1：安全-活性前沿 (R_max, max U) 上的选点权应交监管/责任方，而非算法。

## 8. 本轮最大风险

**一句话**：指标契约与部署认证层会把「安全」压缩成**可被单点污染的度量**——一旦某个指标定义错误、被 Goodhart 游戏化、或评估数据被污染，舰队级 anytime-valid 证书与自动召回就会把局部评估误差放大成**全局误认证 / 误召回**，形成「**认证剧场**」：系统获得了组织与法规背书，却失去了真实的物理安全。
