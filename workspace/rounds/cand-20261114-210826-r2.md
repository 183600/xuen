# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「大语言模型」×「协同控制」）

> R69 给了闭环一张嘴：会看、会问、会摸，并立下「k 个正交证据源一致」的纪律。但它默认了两件在真实具身系统里几乎从不成立的事：**(1) 提问者是孤独的**——问题只服务于一个 agent 自己的信念；**(2) 证据源是正交的**——只要 `k` 份回答「一致」，就当作 `k` 份独立信息相加。
>
> 当系统从「一个机器人 + 一个人」扩展为「多个机器人 + 人 + 语言模型助手」时，这两条同时崩塌：共享的传感器、共享的预训练模型、共享的 LLM 先验，使「k 份独立证词」高度相关；每个人都只想消自己的疑，于是重复提问、遗漏关键问题；而 LLM 一旦从「生成问句的嘴」升级为「全队共享的语义总线」，它既提供了共同语言，也制造了**单一文化**——所有 agent 通过同一副眼镜看世界，错得整整齐齐。
>
> 核心命题：**R69 的「我该向谁求证」必须升格为「我们如何共同确信」——把单 agent 的 epistemic 消歧，提升为团队层面的共同信息构建。** 大语言模型提供**共享语义账本**（把异构模态/agent 的主张归一成带来源与可验证轨迹的结构化命题），协同控制提供**共同信息格、团队价值 of information、弹性共识与联合安全**。命名 **CONCORD-RAS**（Common-ground Orchestrated Network with Correlated-evidence, Optimal and Resilient Disambiguation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们凭什么叫作知道**」——共识不是把很多「我觉得」加在一起，而是把可验证的东西放进同一个格子里。

## 0. 直觉与动机

**灵感 1（LLM → 从「嘴」到「共享语义账本」）**
直觉：R69 的 LLM 只做 `g_ask` 解码，语言是输出端。但在团队里，语言的真正功能是**建立共同指称**：把「我看到左边那个红色的东西在动」「我这边压力读数涨了」「人类说没事」翻译成同一种可比较的命题。关键是 LLM 不应被当作真理源，而应被当作**翻译器 + 账本维护者**。于是主张被写成 `claim = (命题 φ, 来源 i, 溯源 π, 可验证等级 v, 时间戳 t)`；语言层把「证词」与「证据」分开：能落到可验证轨迹（哈希、量测、回放指针）的才升级为证据，纯语言永远是证词且权重有上限。一个只追加、带哈希链的 claim 图，就是团队的共同信息载体——可审计、可回放、可追责。

**灵感 2（协同控制 → 团队 VoI 与共同信息格）**
直觉：协同控制里真正重要的不是「每个 agent 各自最优」，而是**团队目标 + 信息结构**。R69 的 VoI 是个体的：我这一问对我自己值多少。团队里应换成 TVoI：这一组信息动作对联合目标值多少，并且要减去**冗余**（别人已经会问）、**相关**（我们其实共用同一个传感器）与**通信成本**。更深刻的是共同信息格：每个 agent 有自己的信息划分（σ-代数），只有当一条命题落进所有 agent 都能验证的 **meet**（共同知识）里，它才算「我们共同知道」；而 **join** 只是「池化」，并不等于共同知识。R69 的「k 源一致」实际上把 join 误当成了 meet——大家各说各的，然后把并集当成了共识。

**灵感 3（相关证据 → 「k 源一致」是一个 ρ=0 的幻觉）**
直觉：R69 的证据纪律假设正交。若各源误差相关系数 ρ>0，独立融合会把方差压到 σ²/k，而真值是 σ²(1+(k−1)ρ)/k；有效独立源 `k_eff = k/(1+(k−1)ρ)`。当 ρ=1（同一个 LLM 或同一个传感器），k_eff=1——「十个人异口同声」可能只是「一个人说了十遍」。这不是数值细节，而是**把安全纪律变成了过度自信的放大器**。解决不是「少信一点」，而是**部分信息分解（PID）**：把信息拆成 unique / redundant / synergistic，冗余只计一次，unique 全额计入，synergy 作为联合项计入。R69 恰是 ρ=0、Red=Syn=0 的特例。

**灵感 4（弹性共识 → 会撒谎的不只人，还有共享的裁判）**
直觉：团队里最危险的攻击不是「给错答案」，而是**模棱两可**（对 A 说左、对 B 说右）：它专门制造「永久分歧」或「假共识」。R69 的投毒集是单源视角。协同控制有成熟的 w-MSR 弹性共识：只要 Byzantine 数 f < n/3 且图足够连通，正确 agent 能达成一致并排除离群值。再叠加溯源纪律：语言主张必须带可验证轨迹才能进入共同知识，LLM 裁判只能「提出」不能「certify」。于是攻击面从「回答是否真」扩展为「**共识本身是否被制造**」。

**灵感 5（联合安全 → 个体安全不可组合）**
直觉：R69 给每个信息动作单独过 C-RAS-WM。但协同系统里，两个各自安全的动作可以联合不安全：两台机器人同时「礼貌让行」导致死锁；两台同时「探同一脆弱物体」导致超力；两个都「等对方先走」导致时间窗过期。安全必须是**联合的**：需要联合安全集/协同 CBF，还要有一条**活性（liveness）**条件，否则「永远安全地停着」也是一种失败。R69 的认证是本轮 n=1 的退化。

**灵感 6（双时间尺度 → LLM 不在硬实时回路里）**
直觉：LLM 推理是 10²–10³ ms 量级，而控制回路是 ms 量级。把 LLM 放进 2.6ms 闭环是自欺。正确姿态是**时间尺度分离**：LLM 维护慢速语义账本（~1 Hz），实时层在已提交的结构化 claim 上做数值共识与安全认证，并显式处理**陈旧主张**（stale claim 的置信随时间衰减）。这也让「LLM 掉线」成为可定义的安全事件，而不是隐藏故障。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CONCORD-RAS 总览）** CONCORD-RAS = (SLL, CIL, PID-D, TVoI/CAP, LCP, BRC, JSC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **时间尺度分离**：SLL/LLM 只在慢时间尺度提交 claim；实时回路只读「已提交且带时间戳」的 claim，LLM 永不进入硬实时认证路径；
(iii) **共同知识纪律**：任何主张单独立案前必须落入 CIL 的 meet（可验证溯源）并通过 BRC，join 不得冒充 meet；
(iv) **安全单调性**：团队层任何不确定/分歧/通信失效/裁判不可信 → 沿 CONCORD→FLUID→R68 单调退避，安全侧永不弱于 R69。

**定义 311（团队信息结构与共同信息格 CIL）** 每个 agent i 有信息 σ-代数 ℐ_i（其历史观测能区分的状态集合）。**join** ∨_i ℐ_i = 池化信息；**meet** ∧_i ℐ_i = 共同知识（Aumann）。命题 φ 在状态处为共同知识 ⇔ 包含该状态的 meet 原子 ⊆ [φ]。记共同地 ℂ = meet。只有可验证 claim 可以「升格」进 ℂ；池化信息记为 ℙ = join，仅供个体参考。

**定义 312（共享语言账本 SLL）** 账本 L 是带来源的 claim 图。`claim c = (φ, i, π, v, t, h)`：φ 为结构化命题（主体/谓词/值/置信），π 为溯源（传感器哈希、量测 ID、回放指针、模型版本），v∈{testimony, traceable, verified}，t 时间戳，h 前序哈希（防篡改链）。归一化算子 N_LLM: utterance → c，但 N_LLM **不得**设置 v=verified；verified 只能由独立 verifier 依据可复算轨迹给出。

**定义 313（两通道纪律）** 证据通道 E（可回放/可复算）与证词通道 T（自然语言、人类回答、LLM 总结）。T 的似然权重上限 w_T ≤ w_T^max(t)，随陈旧程度衰减；E 无固定上限但必须通过溯源校验。LLM 只能生成/翻译 T 与提出 E 的候选，不能自证。单条 T 永远不得单独定案（继承 R69 定义 293-iii），且 T 之间不得相互「印证」以凑够 k。

**定义 314（证据冗余格与 PID）** 对源集合 S，把 `I(M; Y_S)` 分解为 unique `U_i`、redundant `Red`、synergistic `Syn`（Williams–Beer 冗余格）。定义有效独立源数
`k_eff = k / (1 + (k−1)ρ̄)`，或由 PID 直接给出 `k_eff = (Σ_i U_i + Syn) / I_total · k`。冗余比 `r = Red / I_total`。

**定义 315（去重融合算子 ⊕_PID）** 后验 `p(M|Y_S) ∝ p(M) Π_i [p(y_i|M)]^{α_i} · Ψ_syn(Y_S|M)`，其中唯一性份额给出 Σ_i α_i = k_eff，冗余只以一次联合项计入，`Ψ_syn` 为 synergy 修正项。当 ρ=0 且 Red=Syn=0 ⇒ α_i≡1，退化为朴素贝叶斯（即 R69 的融合）。

**定义 316（团队 VoI：TVoI）** 团队联合目标 `J(a_1..a_n; M)`。对信息动作组 G，
`TVoI(G) = H(M|ℂ) − E_{y_G}[H(M|ℂ, y_G)]`，在 PID 原子化的条件独立表示上计算；净收益 `TVoI(G) − c(G)`，c 含通信、社交、位移与冗余惩罚。个体 VoI（R69 定义 298）是 n=1 的特例。

**定义 317（协同指派问题 CAP）** 给定候选信息动作池 𝒢 与 agent 集 [n]，选分配 `σ: G→[n]` 与子集 `G⊆𝒢`，最大化 `TVoI(G) − c(G)`，s.t. 每 agent 预算、单位时间 ≤ 1 次、JSC 通过。在 A100（PID 原子给定 M 条件独立）下 TVoI 子模 ⇒ 贪心达 `(1−1/e)` 近似。

**定义 318（语言共识协议 LCP）** 轮次 `propose → cross-verify → commit`。每个 agent 对 claim 投 verify/reject/abstain，并附**独立**溯源；当且仅当 (a) 溯源可复算且一致，(b) verify 集合未被 BRC 删减排除，claim 进入 ℂ；否则留在 T 通道并标记 pending。共识有提交截止时间，超时按「未消解」处理，绝不无限重试。

**定义 319（语言对手模型）** 在 R69 的 ℰ_poison 上新增拜占庭行为：**模棱两可**（对不同 agent 发不同 claim）、**共谋**（多 agent 同步伪造共享的「独立」溯源）、**LLM 单一文化**（所有 agent 复用同一模型 ⇒ 相关幻觉 ρ_LLM>0）、**提问注入**（恶意 claim 诱导团队去验证一个幻影、消耗交互预算）。攻击不止改答案，还改「谁被问、问什么、何时达成共识」。

**定义 320（弹性共识 BRC）** 在 claim 图上运行 w-MSR 或加权中值：每 agent 丢弃与其邻居值最远的至多 f 个（或按残差阈值），再按溯源一致性过滤。安全性条件：`n ≥ 3f+1` 且图 `2f+1`-robust ⇒ 正确 agent 达成一致且排除伪造 claim；否则降级为「仅 verified 通道」的保守共识（可能不收敛，但绝不让假共识定案）。

**定义 321（联合安全证书 JSC）** 联合动作 `(a_1..a_n, g_1..g_n)` 通过 JSC ⇔ (i) 联合状态在协同安全集 𝒮_joint（含成对/成组约束：距离、力、资源互斥）；(ii) 每个 agent 的备份策略 π_i^backup 兼容（组合后仍递归可行）；(iii) **活性**：存在良基势函数 Φ 在协调等待/让行下严格下降（无死锁、无饥饿）；(iv) 信息动作也不越包络。任一不满足 ⇒ 联合动作不可执行。

**定义 322（团队证书 J_CONCORD）** `J_CONCORD = (J_FLUID_i, k_eff, redundancy_ratio, common_ground_margin, consensus_rounds, byzantine_bound_ok, joint_safety_margin, liveness_potential, claim_ledger_hash, concord_ver)`。Valid ⇔ 所有 i 的 J_FLUID 有效 ∧ k_eff 落在置信区间内 ∧ 假共识概率 ≤ δ ∧ JSC 通过。

**定义 323（两级团队退避）** 若 ℂ 可信（BRC 通过 ∧ CICG 校准通过 ∧ JSC 通过）⇒ 用去重后验选模态并获得 resolution bonus；若分歧/通信失效/拜占庭越界/LLM 不可用/陈旧超时 ⇒ 每个 agent 逐指令退回 FLUID-RAS（U_epi 未消解，`λ=λ_floor(U_ale+U_epi)`）；若连 FLUID 的模态校准也不可信 ⇒ 退回 R68。退避链 CONCORD→FLUID→R68，λ 单调不降。

**定义 324（共同信息校准门 CICG）** 用可验证 claim 的历史命中率校准 ℂ 的可靠图与 ECE；若 `ECE(ℂ) > τ_cicg`，禁用团队融合，退回个体 FLUID。对应 R69 的 MCG，但校准对象是「共识」而不是「模态」。

**定义 325（通信预算与事件触发 EVT）** 通信预算 b（字节/秒/跳数）。仅当 agent 间后验分歧度 `D_ij > δ` 或溯源冲突时触发交换；设最小驻留时间 τ_d 防 Zeno；拓扑自适应：优先连向能最大化 TVoI 的邻居。

**定义 326（双时间尺度与陈旧主张）** 控制周期 τ_c，语义周期 τ_s ≫ τ_c。claim 置信按 `exp(−(t−t_c)/τ_stale)` 衰减，超过 τ_expire 移出 ℂ。LLM 可用性 `u_LLM` 是显式状态；`u_LLM=0` 时团队只用 E 通道与本地 claim，行为等价于「无语言」的 FLUID 退化。

# IP-264 SLL：LLM 只做翻译与账本维护，不认证
class SharedLanguageLedger:
    def __init__(self, llm, verifier, tau_stale, w_T_max):
        self.llm, self.verifier, self.tau_stale, self.w_T_max = ...
        self.claims, self.head = [], GENESIS

    def ingest(self, utterance, source, provenance):        # 慢层，异步 ~1Hz
        phi = self.llm.normalize(utterance)                 # 结构化命题
        v   = self.verifier.grade(phi, provenance)          # testimony/traceable/verified
        if v == 'verified' and not self.verifier.recomputable(phi, provenance):
            v = 'traceable'                                 # LLM 无权自证
        c = Claim(phi, source, provenance, v, now(), self.head)
        self.claims.append(c); self.head = hash(c)
        return c

    def evidence_weight(self, c):
        if c.v == 'testimony': return self.w_T_max * exp(-(now()-c.t)/self.tau_stale)
        return 1.0

# IP-265 CIL：meet 是共同知识，join 只是池化
def common_ground(ledgers, agents):
    verified = [ {c for c in ledgers[i].claims if c.v == 'verified'} for i in agents ]
    meet = set.intersection(*verified) if verified else set()   # 共同知识
    join = set.union(*[{c for c in l.claims} for l in ledgers]) # 池化，仅供参考
    return meet, join

# IP-266 PID-D：相关证据去重，修 R69 的“k 正交”幻觉
def pid_deconflict(observations, M):
    U, Red, Syn = estimate_pid(M, observations)         # Williams–Beer 冗余格
    I_total = sum(U) + Red + Syn
    k_eff   = max(1.0, (sum(U) + Syn) / I_total * len(observations))
    alphas  = {i: U[i] / max(sum(U), eps) * k_eff for i in observations}
    return alphas, k_eff, Red / max(I_total, eps)

def fuse(modes, observations, alphas):
    post = mode_prior(modes)
    for i, y in observations.items():
        post = post * lik(y, modes) ** alphas[i]        # 冗余已折进 alphas
    return normalize(post)

# IP-267/268 TVoI + CAP：团队级“问什么、谁去问、别重复问”
def assign_info_actions(candidates, agents, budget, jsc, states):
    atoms, S = pid_atoms(candidates), []
    while True:
        best, best_gain = None, 0.0
        for (g, i) in candidate_assignments(candidates, agents):
            if g in S or not budget.allow(g, i): continue
            gain = (tv_oi(S + [g], atoms) - tv_oi(S, atoms)) - cost(g, i)
            if gain > best_gain: best, best_gain = (g, i), gain
        if best is None: break
        if not jsc.joint_ok(joint_action_with(best, S), states): continue
        S.append(best)
    return S                                             # A100 下 (1-1/e) 近似

# IP-269/270 LCP + BRC：可验证共同知识，防模棱两可/假共识
def language_consensus(ledgers, agents, f, n):
    if n < 3*f + 1:
        return verified_only(ledgers)                    # 保守：只认可复算证据
    graph = build_claim_graph(ledgers, agents)
    for _ in range(MAX_ROUNDS):
        votes = {i: w_msr(neighbors(i, graph), f, graph) for i in agents}
        if converged(votes): break
    committed = {c for c in graph.claims
                 if c.v == 'verified' and consensus_margin(c, votes) > 0}
    return committed                                     # 只提交 meet 内的 verified

# IP-271 JSC：联合安全 + 活性（个体安全不可组合）
def joint_certify(joint_action, states, wm, phi):
    return (in_joint_safe_set(joint_action, states) and
            backups_compatible(joint_action, states) and
            well_founded_decrease(phi, joint_action) and      # 无死锁/无饥饿
            all(info_envelope_ok(g) for g in joint_action.info))

    lam = [max(team[i].efs.risk_scale(...), lam_floor(U_ale[i]))
           for i in team.ids]                                          # resolution bonus
    return joint, lam, (k_eff, r)
```

## 3. 推导

**引理 19（相关证据的双计数与过度自信）** 设 k 个源在目标 M 给定下误差等相关：`y_i = M + e_i`，`Cov(e)=σ²[(1−ρ)I+ρ11ᵀ]`。朴素独立融合给出 `V_naive=σ²/k`；真后验方差为 `V_true=σ²(1+(k−1)ρ)/k`。故过度自信比 `V_naive/V_true = 1/(1+(k−1)ρ)`，有效独立源 `k_eff = k/(1+(k−1)ρ)`。ρ=1 ⇒ k_eff=1（十次重复=一次）；ρ=0 ⇒ R69 的纪律成立。系：**R69 的「k 正交一致」是 ρ=0 的隐式假设；共享 LLM 使 ρ_LLM>0，一致性投票会系统性低估 U_epi**——冗余被计了 k 次。

**引理 20（PID 去重融合的校准界）** 在冗余格分解 `I(M;Y_S)=Σ_i U_i+Red+Syn` 下，若按 `α_i=U_i/I_total` 加权（冗余只计一次），则融合的有效源数等于 k_eff，且未校准偏差满足 `|ECE_fused − ECE*| ≤ c·r·(1−e^{−H(M)})`（A99：PID 估计无偏、有界方差）。系：即使拿不到精确 ρ，也可由冗余比 r 直接给出安全折扣；当只有相关性上界 ρ̄_max 时，用最坏情况保守融合，保证不劣于 R68 的纯保守。

**引理 21（TVoI 子模性与贪心保证）** 在 A100（PID 原子在 M 给定下条件独立）下，`f(S)=I(M;Y_S^{atoms})` 单调子模；减去非负成本后仍子模，故贪心指派达 `(1−1/e)OPT`。冗余惩罚已折进原子化（原子不重复），因此不会出现「两支队伍都去问同一件事」的虚高收益。系：团队越异构（atomic 越分散），贪心越接近最优；越同质（原子坍缩成一个），TVoI 越接近个体 VoI 且冗余惩罚自动抬升。

**引理 22（弹性共同信息的收敛）** 当 `n≥3f+1` 且 claim 图 `2f+1`-robust 时，w-MSR 使全体正确 agent 在有限轮内就「可验证 claim 集合」达成一致，且任何仅由 Byzantine 提出、无独立溯源的 claim 不进入 ℂ。若模棱两可导致某 agent 收到两个互斥 claim，交叉验证阶段至少一方溯源冲突被检出，概率界 `1−(1−q)^m`（q 为可验证比例，m 为独立验证次数）。系：LLM 裁判无权把 T 通道升格为 verified，因此「共享裁判被攻陷」不能单独制造共识。

**定理 18（CONCORD 严格包含 FLUID-RAS）** 取 n=1、关闭通信、ρ=0（PID 退化为 unique）、JSC 退化为 R69 定义 302 的单体认证、CICG 关闭，则 CONCORD 的每一步与 FLUID-RAS 逐指令相同；且当 CICG/BRC/JSC 任一失败时走退避链 CONCORD→FLUID→R68，λ 单调不降。故安全侧不弱于 R69，效率侧仅在「可信共识」时获得 resolution bonus。**R69 是「团队大小为 1 且无通信」的边界。**

**定理 19（协同安全与活性）** 在 A101（𝒮_joint 前向不变、各备份策略为收缩、良基势 Φ 在等待/让行下严格下降）下，JSC 通过的联合执行保持 𝒮_joint 且无死锁/无饥饿；个体认证（R69）是 𝒮_joint 的 n=1 截面。反例：两台机器人各自「安全地让行」可联合死锁，故无 JSC 时个体安全不组合。

**定理 20（错误共识上界）** 设可验证比例 q、独立验证次数 m、Byzantine 上界 f<n/3，则团队把伪命题提交为共同知识的概率
`P(false consensus) ≤ ε_σ + (1−q)^m + P(BRC-fail)`，
且该界随 k_eff 下降而收紧（相关证据不再放大假共识）。系：**共识的置信不应由「同意的人数」决定，而应由「独立可验证的次数」决定**——这正是 k_eff 相对 k 的修正。

**定理 21（双时间尺度与通信 Pareto）** 在事件触发阈值 δ>0、最小驻留 τ_d>0 下，LCP 无 Zeno；通信量与分歧势 D 成正比有上界；当 `u_LLM=0` 时退化为仅 E 通道，信息损失 ≤ `H(M|ℂ_E) − H(M|ℂ_E,T)`，但控制与安全不变（仍走 FLUID 兜底）。因此 **LLM 的可用性只影响效率，不影响安全**。

## 6. 本轮最大风险

**一句话**：CONCORD-RAS 的校准与安全全部押在「相关/冗余结构可估、溯源可验」这一前提上——**但共享 LLM 造成的相关误差恰恰是团队从内部观测不到的**（所有 agent 只有同一副眼镜，没有第二副去校准它）；一旦 ρ 或 PID 估计错误，去重可能把真实的 synergy 当冗余丢掉，或仍把冗余当独立证据，于是团队**一致且自信地错在同一个盲点上**——共识放大了错误而不是纠正错误，**「大家一起错」比「一个人犹豫」更危险**。

**次级风险与缓解**：
1. LLM 单一文化与共同裁判被攻陷 → 两通道纪律（T 不得自证）+ 引理 22 + E307/E315；
2. 溯源被伪造/共谋 → 哈希链 + 独立可复算 + 拜占庭预算 f<n/3，越界即退 FLUID；
3. 联合安全的活性条件难证 → 良基势函数 + 保守等待策略 + E309/E310；
4. 相关结构不可辨识（ρ 不可估） → 用最坏 ρ̄_max 保守融合，保证不劣于 R68；
5. LLM 延迟/掉线侵入实时环 → 双时间尺度 + 陈旧衰减 + `u_LLM` 显式降级，安全路径不依赖 LLM。

def ingest(llm, verifier, utterance, source, prov, head):
    phi = llm.normalize(utterance)                     # 慢层，异步 ~1Hz
    v = verifier.grade(phi, prov)                      # testimony/traceable/verified
    if v == 'verified' and not verifier.recomputable(phi, prov):
        v = 'traceable'                                # 禁止 LLM 自证
    return Claim(phi, source, prov, v, now(), head)

# IP-265/266 CIL + PID-D：共同知识 + 去重
def common_ground(ledgers):
    meet = set.intersection(*[{c for c in l if c.v == 'verified'} for l in ledgers])
    join = set.union(*[set(l) for l in ledgers])       # 仅供参考，不等于共识
    return meet, join

def pid_deconflict(obs, M):
    U, Red, Syn = estimate_pid(M, obs)
    I = sum(U) + Red + Syn
    k_eff = max(1.0, (sum(U) + Syn) / I * len(obs))
    alphas = {i: U[i] / max(sum(U), eps) * k_eff for i in obs}
    return alphas, k_eff, Red / max(I, eps)

def fuse(modes, obs, alphas):
    post = mode_prior(modes)
    for i, y in obs.items(): post = post * lik(y, modes) ** alphas[i]
    return normalize(post)

# IP-267/268 TVoI + CAP：团队 VoI，子模贪心
def assign_info_actions(cands, agents, budget, jsc):

    while True:

        for (g, i) in candidate_assignments(cands, agents):

            d = (tv_oi(S+[g]) - tv_oi(S)) - cost(g, i)
            if d > gain and jsc.joint_ok(joint_with(g, S)): best, gain = (g, i), d
        if best is None: break
        S.append(best)
    return S                                           # (1-1/e) 近似

# IP-274 主闭环：慢语义 + 快控制，失败单调退化
def CONCORD_round(team, obs):
    for i in team.ids: team[i].sll.ingest(team[i].pending, i, team[i].prov)
    meet, _ = common_ground([team[i].sll for i in team.ids])
    if team.cicg.ece(meet) > TAU_CICG or not team.brc.ok(meet):
        return [FLUID_RAS_round(team[i], obs[i]) for i in team.ids]
    U_ale, U_epi, modes = {}, {}, {}
    for i in team.ids: U_ale[i], U_epi[i], modes[i] = team[i].aud.decompose(...)
    G = team.cap.assign(modes, team.budget, team.jsc, team.states)
    ans = team.lcp.execute(G)                          # 提议→交叉验证→提交
    alphas, k_eff, r = pid_deconflict(ans.obs, modes)
    fused, U_epi_after = fuse(modes, ans.obs, alphas), post_entropy(fused)
    joint = select_team_mode(fused, team.states)
    if not team.jsc.joint_ok(joint, team.states, team.wm, team.phi):
        return [FLUID_RAS_round(team[i], obs[i]) for i in team.ids]
    for i in team.ids: team[i].vqa_t.submit_async(G, k_eff, r, ans.hash)
    lam = [max(team[i].efs.risk_scale(...), lam_floor(U_ale[i])) for i in team.ids]
    return joint, lam, (k_eff, r)
```

## 4. 推导

**引理 19（相关证据的双计数与过度自信）** k 个源等相关（ρ）时，朴素独立融合方差 `σ²/k`，真值 `σ²(1+(k−1)ρ)/k`；过度自信比 `1/(1+(k−1)ρ)`，有效独立源 `k_eff=k/(1+(k−1)ρ)`。ρ=1 ⇒ k_eff=1。系：R69 的「k 正交一致」是 ρ=0 的隐式假设；共享 LLM 使 ρ_LLM>0，会系统性低估 U_epi。

**引理 20（PID 去重融合的校准界）** 冗余只计一次时有效源数等于 k_eff，未校准偏差 `|ECE_fused−ECE*| ≤ c·r·(1−e^{−H(M)})`（A99）。系：只有相关性上界 ρ̄_max 时用最坏保守融合，保证不劣于 R68。

**引理 21（TVoI 子模性与贪心）** A100 下 `f(S)=I(M;Y_S^{atoms})` 单调子模，减非负成本仍子模，贪心达 `(1−1/e)OPT`；冗余惩罚折进原子化，避免重复提问的虚高收益。

**引理 22（弹性共同信息的收敛）** `n≥3f+1`、图 `2f+1`-robust 时，w-MSR 使正确 agent 有限轮内就可验证 claim 集合一致，且唯一由 Byzantine 提出且无独立溯源的 claim 不进 ℂ；模棱两可检出概率 `1−(1−q)^m`。系：LLM 无权把 T 升格为 verified，故共享裁判被攻陷不能单独制造共识。

**定理 18（CONCORD 严格包含 FLUID-RAS）** n=1、无通信、ρ=0、JSC 退化为 R69 单体认证、CICG 关闭时，CONCORD 与 FLUID 逐指令相同；任一失败走 CONCORD→FLUID→R68 且 λ 单调不降。R69 是「团队大小为 1 且无通信」边界；安全不让步，效率获 resolution bonus。

**定理 19（协同安全与活性）** A101 下，JSC 通过的联合执行保持 𝒮_joint 且无死锁/无饥饿；R69 个体认证是 𝒮_joint 的 n=1 截面。反例：各自安全的让行动作可联合死锁，故个体安全不可组合。

**定理 20（错误共识上界）** `P(false consensus) ≤ ε_σ+(1−q)^m+P(BRC-fail)`，随 k_eff 下降收紧。系：共识置信由「独立可验证次数」而非「同意人数」决定。

**定理 21（双时间尺度与通信 Pareto）** δ>0、τ_d>0 时 LCP 无 Zeno；通信量与分歧势成正比有界；`u_LLM=0` 时仅 E 通道，信息损失有界但控制与安全不变——**LLM 可用性只影响效率，不影响安全**。

## 7. 本轮最大风险

**一句话**：CONCORD-RAS 的校准与安全全部押在「相关/冗余结构可估、溯源可验」上——**但共享 LLM 造成的相关误差恰恰是团队从内部观测不到的**（所有 agent 只有同一副眼镜）；一旦 ρ 或 PID 估计错误，去重可能把真实 synergy 当冗余丢掉，或仍把冗余当独立证据，团队就会**一致且自信地错在同一个盲点上**——共识放大错误而非纠正错误，**「大家一起错」比「一个人犹豫」更危险**。

**次级风险与缓解**：LLM 单一文化/共享裁判被攻陷（两通道纪律 + 引理 22 + E307/E315）；溯源伪造/共谋（哈希链 + 独立可复算 + f<n/3，越界退 FLUID）；活性难证（良基势 + 保守等待 + E309/E310）；ρ 不可辨识（用最坏 ρ̄_max 保守融合，不劣于 R68）；LLM 延迟/掉线侵入实时环（双时间尺度 + 陈旧衰减 + `u_LLM` 显式降级）。
