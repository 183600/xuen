# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「持续学习」×「模型预测控制」）

> 第 54 轮把技能组合提升为「动作空间剖面 α_S + 鲁棒性谱 ρ」的双证书体系，但隐含两个静态假设：技能与预测模型在部署期内不变、规划是一次性可判定的。本轮引入两个动力学来源：**持续学习**让技能库与预测模型在线演化，证书的证据基础会随时间漂移；**模型预测控制（MPC）**把一次性规划替换为滚动时域闭环，每一步都要重新承诺未来 H 步的可行性。核心矛盾：H22：持续学习使证书「过期」——旧证据对应的动作剖面 α_S、鲁棒性谱 ρ、云边映射 γ_ce 在更新后不再是同一函数；H23：MPC 的递归可行性依赖终端不变集，而终端集由正在被持续学习改写的模型定义；学习越快，漂移球越大，可用安全域越小，MPC 越可能在最需要时失去可行解。

## 0. 直觉与动机

**灵感 1（证书是租约，不是产权）**
直觉：静态证书像房产证，默认世界不变；持续学习像一场缓慢的地震。更合适的隐喻是**租约（lease）**：证书只在「时间窗 h + 漂移预算 B + 证据年龄 τ_ev」内有效，到期必须续租（重认证）或降级（缩小到仍然有效的动作子集）。这把「证书是否有效」从布尔值变成 `(剩余时域, 已用漂移预算, 证据年龄)` 的三维状态。关键不是阻止学习，而是让证书**显式地可腐坏**，在腐坏前触发续租。

**灵感 2（表征漂移 ≠ 行为漂移）**
直觉：持续学习可能把网络权重改得面目全非，却在所有任务动作上行为几乎不变（置换对称、重参数化）；也可能权重只动一点，却在边界动作上行为突变。证书应以**行为等价**为锚，而不是参数相同。定义锚点动作集 `A_anchor`（覆盖 A_core 边界、历史失败点、分层随机点），漂移 `d_beh = sup_{a∈A_anchor} D(π_t(a), π_{t+1}(a))`。只有行为漂移超预算才判证书失效；参数更新本身不必然是罪。

**灵感 3（证书保持的增量学习）**
直觉：不是所有更新都有权改变已承诺的能力。把更新分为两类：**证书保持更新**（在活跃证书的动作区内行为漂移 < 预算，可直接合入）与**需重认证更新**（漂移超预算，必须用锚点证据重新证明，或限制在非活跃动作区）。旧技能的**证据**（反例、仿真轨迹、ρ 校准）应与数据一起回放，而不是只回放样本——否则模型会「记得怎么做，却忘了为什么可以这么做」。容量不足时，只能遗忘**无活跃证书**的技能，且需归档其证据。

**灵感 4（用证书终端集做滚动时域组合）**
直觉：第 54 轮的 A* 是一次性把整条技能路径搜出来，像开环发射；MPC 则每步解一个有限时域最优控制问题，只执行第一步，再根据边端反馈重规划。把联合证书 J 变成 MPC 的**终端不变集约束**：`x_H ∈ I_cert(J)`。证书不再是事后的合格章，而是优化问题里的**安全包络**：MPC 负责在包络内尽可能推进任务，证书负责保证包络本身不会被下一步踩穿。

**灵感 5（漂移球下的鲁棒终端不变集 → 安全-可塑性权衡）**
直觉：既然模型会被持续学习改写，终端不变集就不能只对当前参数 θ_t 成立，而要对整个漂移球 `Θ_ball(θ_t, Δθ)` 成立——这是**鲁棒控制不变集（RCIS）**。由此得到一个硬权衡：学习步长越大 → 漂移球越大 → 不变集越小（甚至为空）。所以「学得多快」不是纯算法超参，而是**由安全域体积反推的可行性约束**，存在最大可持续学习率 `η_max`。这把持续学习从「越学越好」拉回到「在安全域不塌缩的前提下能学多快」。

**灵感 6（模型换血闸门与双时间尺度）**
直觉：MPC 需要模型在时域内稳定，持续学习需要模型不断变化——直接耦合会互相拆台。解法是**双时间尺度**：快环用冻结的已认证模型做 MPC，慢环在影子模式里训练新模型；只有当新模型通过「锚点无回退 + 漂移球内不变集存在 + 全部活跃租约可再验证 + 影子窗口稳定」四道门，才原子换血，并保留旧模型快照以便回滚。模型版本因此成为证书的一部分，而不是环境里的隐变量。

**灵感 7（遗忘本身可以被 MPC 调度 + 安全探测）**
直觉：灾难性遗忘是一个**受控动力学**：每个技能的保持率 r_i 随时间与新任务挤压而衰减，回放/巩固是控制输入，算力是预算。可以把「排多少回放、巩固哪个技能」建模成一个小型 MPC，目标是在算力预算内让活跃证书对应的保持率不低于阈值。同时，识别漂移需要激励（persistent excitation），但探测不能踩出证书边界——探测动作必须在 `A_cert` 的内部余量中进行，按「单位约束余量的信息增益」排序，形成**安全对偶探测**。

**灵感 8（持续联合证书的时态扩展）**
直觉：把第 54 轮的 J 扩展为带时态的 `J^τ = (J, Λ, d_beh, θ_ver, I_cert, r, π_probe, ledger)`。可部署不再是静态谓词，而是「租约未过期 + 行为漂移在预算内 + 终端不变集非空且对漂移球鲁棒 + 活跃技能保持率达标 + 探测未越界 + 证据账本无未清偿债」。这把「一次认证、永久部署」改成「持续认证、可撤销部署」。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（证书租约）**
证书租约 `Λ = (J, t_0, h, B, age_ev)`，其中 `J` 为第 54 轮联合证书，`t_0` 签发时刻，`h` 有效时域，`B = (B_beh, B_rho, τ_ev)` 漂移与证据预算，`age_ev` 证据年龄。租约状态：
```
status(Λ,t) = valid        if t-t_0 ≤ h ∧ d_beh ≤ B_beh ∧ d_rho ≤ B_rho ∧ age_ev ≤ τ_ev
             = invalidated  if d_beh > B_beh ∨ d_rho > B_rho
             = expired      if t-t_0 > h
             = stale        otherwise
```
续租算子 `renew(Λ,t) = Λ'` 仅在重新采样锚点证据并通过第 54 轮 AEC 检查后成立；否则降级 `degrade(Λ) = (A_core ∩ A_still_valid, h' < h)`。

**定义 122（行为漂移与锚点等价）**
技能在时刻 t 的策略 `π_t`，锚点集 `A_anchor(Λ) ⊆ A_core`。行为漂移与谱漂移：
```
d_beh(S_t,S_{t+1}) = sup_{a∈A_anchor} D(π_t(a), π_{t+1}(a))
d_rho(S_t,S_{t+1}) = max_d |ρ_t(d) - ρ_{t+1}(d)|
```
若 `d_beh ≤ B_beh ∧ d_rho ≤ B_rho`，称两技能在证书意义下 **B-等价**：参数可不同，行为不可区分到预算之外。

**定义 123（证书保持更新）**
持续学习更新 `U: (S_t, D_t) → S_{t+1}`。给定活跃租约集合 `𝓛_t`，更新可准入当且仅当
```
admit(U,𝓛_t) ⇔ ∀Λ∈𝓛_t:  B-等价(S_t,S_{t+1}; A_anchor(Λ))
                ∨ (recertify(S_{t+1}, scope(Λ)) ⪰ Λ ∧ replay_evidence(Λ))
                ∧ A_new ∩ ⋃_{Λ∈𝓛_t} A_core(Λ) = ∅   (仅对新技能)
```
其中 `⪰` 表示新证书在鲁棒性谱与动作覆盖上不弱于旧证书。不可准入的更新只能进入**影子缓存**，不得替换在线技能。

**定义 124（证书约束的滚动时域组合 CMPC）**
状态 `x_t = (任务进度, 当前技能, 上下文)`，预测模型 `f̂_{θ_t}`，时域 H。每步求解：
```
min_{u_{0:H-1}}  Σ_{k=0}^{H-1} c(x_k,u_k) + V_f(x_H)
s.t.  x_{k+1} = f̂_{θ_t}(x_k,u_k),      x_0 = x_t
      u_k ∈ A_cert(J) ∩ A_feas,        ∀k
      x_H ∈ I_cert(J)                   (终端不变集)
```
只执行 `u_0`，下一时刻用边端反馈重解。云端用粗模型/长时域 `H_c`，边端用细模型/短时域 `H_e ≤ H_c` 做可行性校验；`H_e` 内的动作必须落在 `A_cert`。

**定义 125（漂移球下的鲁棒终端不变集）**
模型族 `F_Θ = {f_θ : ||θ-θ_t|| ≤ Δθ}`。集合 `I_cert` 是**鲁棒控制不变集（RCIS）**，若
```
∀x∈I_cert, ∀θ∈Θ_ball(θ_t,Δθ), ∃u∈A_cert: f_θ(x,u)∈I_cert
```
记 `I_cert(Δθ)` 为满足条件的不变集；`Δθ` 越大，`I_cert` 越小。若 `I_cert(Δθ)=∅`，则当前学习速率下不存在可认证的滚动时域策略。

**定义 126（模型换血闸门）**
新模型 `θ'` 可替换 `θ_t` 当且仅当
```
swap_ok(θ→θ') ⇔ nonregress(θ',θ_t; A_anchor)           # 锚点上无性能回退
               ∧ I_cert^θ'(Δθ) ≠ ∅                      # 漂移球内不变集存在
               ∧ ∀Λ∈𝓛_t: revalidate(Λ, θ', I_cert^θ')   # 活跃租约可再验证
               ∧ shadow_stable(θ', W)                   # 影子窗口 W 内稳定
```
换血后保留快照 `snapshot(θ_t)`，并递增版本号 `θ_ver`；回滚即恢复快照并使相关租约重新进入待验证态。

**定义 127（保持率-MPC）**
每个活跃技能 i 的保持率 `r_i(t)∈[0,1]` 服从 `r_i(t+1)=F_i(r_t,u_t;ξ_t)`，`u_t` 为回放/巩固算力分配，预算 `Σ_i u_i ≤ C`。保持率 MPC：
```
min_{u_{0:H-1}}  Σ_k [ -Σ_i w_i r_i(k) + λ_c Σ_i u_i(k) + λ_s Σ_i max(0, r_min - r_i(k)) ]
s.t.  r_{k+1} = F(r_k,u_k),  Σ_i u_i(k) ≤ C,  r_i(0)=r_i(t)
```
只执行 `u_0`，每轮按真实遗忘重新预测。目标是把「不忘」变成可调度的控制问题，而非祈祷学习率足够小。

**定义 128（持续联合证书）**
```
J^τ = (J, Λ, d_beh, d_rho, θ_ver, I_cert, r, π_probe, ledger)
ledger = {(t, violation, remediated?, evidence_hash)}
```
可部署谓词：
```
deploy(J^τ,t) ⇔ status(Λ,t) = valid
              ∧ I_cert(Δθ) ≠ ∅
              ∧ min_i r_i ≥ r_min
              ∧ π_probe 的动作 ∈ int(A_cert) 且未越 δ_a 余量
              ∧ ledger 无未清偿违规 (debt = 0)
```

## 2. 关键算法 伪代码

### IP-121 TCL（Temporal Certificate Lease）

```python
def issue_lease(J, t0, horizon, drift_budget, evidence_age):
    return Lease(J=J, t0=t0, h=horizon, B=drift_budget, age_ev=evidence_age)

def lease_status(L, t, d_beh, d_rho):
    if d_beh > L.B.beh or d_rho > L.B.rho:
        return 'invalidated'
    if t - L.t0 > L.h:
        return 'expired'
    if L.age_ev > L.B.tau_ev:
        return 'stale'
    return 'valid'

def renew_or_degrade(L, t, d, recert_budget):
    s = lease_status(L, t, d.beh, d.rho)
    if s == 'valid':
        return ('valid', L)
    if recert_budget.allows(L.J):
        J2 = recertify(L.J, t)                 # 重采锚点 + AEC 复核
        if J2 is not None:
            return ('renewed', issue_lease(J2, t, L.h, L.B, evidence_age=0))
    subset = largest_certified_subset(L.J, d)  # 只保留漂移未超预算的动作
    return ('degraded', issue_lease(subset, t, L.h // 2, shrink(L.B, d), 0))
```

### IP-122 BDE（Behavioral Drift Estimator）

```python
def anchor_set(J, n=64):
    return stratified_sample(J.A_cert.A_core,
                             boundary=0.5, failure_cases=0.3, random=0.2, n=n)

def behavioral_drift(S_old, S_new, J, metric, lip):
    A = anchor_set(J)
    raw = max(metric(S_old.pi(a), S_new.pi(a)) for a in A)
    cov = lip.coverage(A, J.A_cert.A_core)
    d_beh = raw * lip.conservative_factor(cov)   # 覆盖不足则保守放大
    d_rho = max(abs(S_old.rho[d] - S_new.rho[d]) for d in S_old.rho)
    return Drift(d_beh=d_beh, d_rho=d_rho, coverage=cov)
```

### IP-123 CPL（Certificate-Preserving Learning）

```python
def certificate_preserving_update(S, update, active_leases, replay, budgets):
    snapshot = clone(S)
    S_new = apply(update, S)
    for L in active_leases:
        d = behavioral_drift(S, S_new, L.J)
        if d.d_beh > L.B.beh or d.d_rho > L.B.rho:
            J2 = recertify(S_new, L.J.scope)        # 用锚点证据重新证明
            if J2 is None or not dominates(J2, L.J):
                restore(snapshot)
                return ('reject', 'cert_regression', L.id, d)
            replay.evidence(L)                      # 回放证据，不只回放数据
        replay.samples(L, S_new)
    if conflicts(S_new.alpha, union_core(active_leases)):
        restore(snapshot)
        return ('reject', 'action_conflict')
    return ('ok', S_new, update_leases(active_leases, S_new))
```

### IP-124 CMPC（Certificate-Constrained MPC）

```python
def certified_mpc(x_t, f_theta, J, H, stage_cost, terminal_cost):
    A_allow = J.A_cert.A_core
    I_term  = J.I_cert
    try:
        U = solve_ocp(f_theta, x_t, H,
                      obj=lambda X, U: sum(stage_cost(x) for x in X)
                                       + terminal_cost(X[-1]),
                      cons=lambda X, U: all(u in A_allow for u in U)
                                        and X[-1] in I_term)
    except Infeasible:
        return ('fallback', safe_subset_policy(x_t, A_allow))  # 安全降级而非硬停
    return ('ok', U[0], plan=U)        # 滚动时域：只执行第一步
```

### IP-125 RCIS（Robust Certified Invariant Set）

```python
def robust_invariant_set(f_theta, theta_ball, I_seed, A_allow, iters=100):
    I = I_seed
    for _ in range(iters):
        pre = {x for x in I
               if all(any(inside(f_theta(x, u, theta), I) for u in A_allow)
                      for theta in theta_ball.sample_vertices())}
        I_next = I & pre
        if I_next == I:
            break
        I = I_next
    return I if I else None            # None ⇒ 当前 Δθ 下无安全域
```

### IP-126 MSG（Model Swap Gate）

```python
def model_swap_gate(theta_new, theta_old, anchors, leases, f_family):
    if not nonregress(theta_new, theta_old, anchors):
        return ('reject', 'anchor_regression')
    ball = ball(theta_new, radius=DRIFT_BUDGET.theta)
    I_new = robust_invariant_set(f_family(theta_new), ball,
                                 certified_seed(), A_allow)
    if I_new is None:
        return ('reject', 'no_invariant_set')
    for L in leases:
        if not revalidate(L, theta_new, I_new):
            return ('reject', 'lease_invalid', L.id)
    if not shadow_stable(theta_new, window=W):
        return ('reject', 'shadow_unstable')
    return ('ok', theta_new, I_new, snapshot(theta_old))
```

### IP-127 RMPC（Retention-MPC）

```python
def retention_mpc(r_t, forgot_model, task_value, compute_budget, H):
    U = solve_ocp(forgot_model, r_t, H,
                  obj=lambda R, U: -sum(task_value(R))
                                   + LAMBDA_C * sum(U)
                                   + LAMBDA_S * penalty(R, r_min),
                  cons=lambda R, U: all(sum(u) <= compute_budget for u in U)
                                    and all(r >= r_min for r in R[1:]))
    return U[0]                        # 只执行本轮算力分配
```

### IP-128 SDP（Safe Dual Probing）

```python
def safe_dual_probe(J, uncertainty, budget):
    best = None
    for a in interior(J.A_cert.A_core, margin=J.delta_a):
        gain  = expected_info_gain(uncertainty, a)
        slack = distance_to_boundary(a, J.A_cert.A_core)
        cost  = action_cost(a)
        if slack <= 0 or cost > budget:
            continue
        score = gain / (slack * cost)
        cand = Candidate(a, score)
        if best is None or cand.score > best.score:
            best = cand
    return best.action if best else None
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TCL | O(|A_anchor|) / 次检查 | O(1) | 漂移上界保守、续租需新证据 |
| BDE | O(|A_anchor|·\|π\|) | O(|A_anchor|) | 锚点分层覆盖、Lipschitz 放大 |
| CPL | O(\|𝓛\|·\|A_anchor\|·\|π\| + \|replay\|) | O(\|𝓛\|·\|A_anchor\|) | 重认证 sound、证据可回放 |
| CMPC | O(poly(H,\|X\|,\|U\|)) / 次求解 | O(H·\|X\|) | 终端集 RCIS、只执行首步 |
| RCIS | O(iters·\|I\|·\|U\|·\|Θ_v\|) | O(\|I\|) | 顶点覆盖漂移球、收缩到不动点 |
| MSG | O(\|Θ\|·RCIS + \|𝓛\|·reval + W) | O(\|θ\|+\|𝓛\|) | 四门全过才换血、快照可回滚 |
| RMPC | O(poly(H,\|r\|,\|u\|)) | O(H·\|r\|) | 遗忘模型误差有界、预算单调 |
| SDP | O(\|A_cert\|·\|U\|) | O(\|A_cert\|) | 内部余量硬约束、探测不越界 |

**命题 1（安全-可塑性权衡）**
设 `I_cert(Δθ)` 为定义 125 的 RCIS，则 `Δθ_1 ≤ Δθ_2 ⇒ I_cert(Δθ_2) ⊆ I_cert(Δθ_1)`，故 `vol(I_cert)` 关于 Δθ 单调不增。若单步学习使漂移球半径增量为 `g(η)`（g 单调增），则存在临界学习率 `η_max = sup{η : I_cert(g(η)) ≠ ∅}`；当 `η > η_max` 时，CMPC 必然在某步失去可行终端约束。**直觉**：学习越快，可承诺的安全域越小；证书体系把「学习率」变成可判定的安全参数。

**条件正确性定理（Continual Certified Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增：
- **(A29)** 行为漂移估计 `d_beh` 在锚点覆盖下是真实策略漂移的保守上界；
- **(A30)** `I_cert(Δθ)` 对 `∀θ∈Θ_ball` 鲁棒不变，且 `I_cert≠∅`；
- **(A31)** 续租/降级算子 sound：`degrade` 后的动作子集确实满足剩余预算；
- **(A32)** 换血闸门 sound：被接受模型的真实漂移不超出漂移球，影子窗口覆盖部署分布；

```
 ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)
```

### IP-121 TCL

```python
def issue_lease(J, t0, horizon, drift_budget, evidence_age):
    return Lease(J=J, t0=t0, h=horizon, B=drift_budget, age_ev=evidence_age)

def lease_status(L, t, d_beh, d_rho):
    if d_beh > L.B.beh or d_rho > L.B.rho:
        return 'invalidated'
    if t - L.t0 > L.h:
        return 'expired'
    if L.age_ev > L.B.tau_ev:
        return 'stale'
    return 'valid'

def renew_or_degrade(L, t, d, recert_budget):
    s = lease_status(L, t, d.beh, d.rho)
    if s == 'valid':
        return ('valid', L)
    if recert_budget.allows(L.J):
        J2 = recertify(L.J, t)
        if J2 is not None:
            return ('renewed', issue_lease(J2, t, L.h, L.B, evidence_age=0))
    subset = largest_certified_subset(L.J, d)
    return ('degraded', issue_lease(subset, t, L.h // 2, shrink(L.B, d), 0))
```

### IP-122 BDE

```python
def anchor_set(J, n=64):
    return stratified_sample(J.A_cert.A_core,
                             boundary=0.5, failure_cases=0.3, random=0.2, n=n)

def behavioral_drift(S_old, S_new, J, metric, lip):
    A = anchor_set(J)
    raw = max(metric(S_old.pi(a), S_new.pi(a)) for a in A)
    cov = lip.coverage(A, J.A_cert.A_core)
    return Drift(d_beh=raw * lip.conservative_factor(cov),
                 d_rho=max(abs(S_old.rho[d] - S_new.rho[d]) for d in S_old.rho),
                 coverage=cov)
```

### IP-123 CPL

```python
def certificate_preserving_update(S, update, active_leases, replay, budgets):
    snapshot = clone(S)
    S_new = apply(update, S)
    for L in active_leases:
        d = behavioral_drift(S, S_new, L.J)
        if d.d_beh > L.B.beh or d.d_rho > L.B.rho:
            J2 = recertify(S_new, L.J.scope)
            if J2 is None or not dominates(J2, L.J):
                restore(snapshot)
                return ('reject', 'cert_regression', L.id, d)
            replay.evidence(L)             # 证据回放，而不仅是样本回放
        replay.samples(L, S_new)
    if conflicts(S_new.alpha, union_core(active_leases)):
        restore(snapshot)
        return ('reject', 'action_conflict')
    return ('ok', S_new, update_leases(active_leases, S_new))
```

```python
def certified_mpc(x_t, f_theta, J, H, stage_cost, terminal_cost):

    try:
        U = solve_ocp(f_theta, x_t, H,
```

### IP-125 RCIS

```python
def robust_invariant_set(f_theta, theta_ball, I_seed, A_allow, iters=100):
    I = I_seed
    for _ in range(iters):
        pre = {x for x in I
               if all(any(inside(f_theta(x, u, theta), I) for u in A_allow)
                      for theta in theta_ball.sample_vertices())}
        I_next = I & pre
        if I_next == I:
            break
        I = I_next
    return I if I else None                # None ⇒ 当前 Δθ 下无安全域
```

```python
def model_swap_gate(theta_new, theta_old, anchors, leases, f_family):
    if not nonregress(theta_new, theta_old, anchors):
        return ('reject', 'anchor_regression')
    ball = ball(theta_new, radius=DRIFT_BUDGET.theta)
    I_new = robust_invariant_set(f_family(theta_new), ball,
                                 certified_seed(), A_allow)
    if I_new is None:

    for L in leases:
        if not revalidate(L, theta_new, I_new):
            return ('reject', 'lease_invalid', L.id)
```

```python
def retention_mpc(r_t, forgot_model, task_value, compute_budget, H):
    U = solve_ocp(forgot_model, r_t, H,
                  obj=lambda R, U: -sum(task_value(R))
                                   + LAMBDA_C * sum(U)
                                   + LAMBDA_S * penalty(R, r_min),
                  cons=lambda R, U: all(sum(u) <= compute_budget for u in U)
                                    and all(r >= r_min for r in R[1:]))
```

### IP-128 SDP

```python
def safe_dual_probe(J, uncertainty, budget):
    best = None
    for a in interior(J.A_cert.A_core, margin=J.delta_a):
        gain, slack, cost = (expected_info_gain(uncertainty, a),
                             distance_to_boundary(a, J.A_cert.A_core),
                             action_cost(a))
        if slack <= 0 or cost > budget:
            continue
        cand = Candidate(a, gain / (slack * cost))
        if best is None or cand.score > best.score:
            best = cand
    return best.action if best else None
```

**命题 1（安全-可塑性权衡）**
`I_cert(Δθ)` 关于 Δθ 单调收缩：`Δθ_1 ≤ Δθ_2 ⇒ I_cert(Δθ_2) ⊆ I_cert(Δθ_1)`。若单步学习使漂移球半径增量为 `g(η)`（单调增），则存在临界学习率 `η_max = sup{η : I_cert(g(η)) ≠ ∅}`；`η>η_max` 时 CMPC 必在某步失去可行终端约束。即：学习率不是纯超参，而是被安全域体积约束的安全参数。

**条件正确性定理（Continual Certified Composition Soundness）**

## 6. 本轮最大风险

**一句话**：持续学习让证书变成「会过期的租约」，MPC 又只保证有限时域，两者叠加会产生**时间维度的安全洗白**——系统可以把违规推过预测时域、把旧违规随灾难性遗忘一起抹掉，于是证书永远新鲜、账本却持续负债；因此必须以「证书债账本 + 不可遗忘的审计回放 + 时域外的保守不变集」为硬约束，宁可频繁降级与换血回滚，也不把「这一时域内可行」当作「持续安全」。
