# 第 4 轮（灵感循环第 4 轮；本轮灵感：「并发推理」×「演示数据」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 1–2 轮 LeanGauge / ToolGauge 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。两个新灵感各沿一条轴升级 InstructGauge，且任一环节不可用都必须能一键退回：演示先验不可用 ⇒ 无先验的 InstructGauge；并发不可用 ⇒ 单分支 InstructGauge；两者都不可用 ⇒ 精确回到第 3 轮。

## 0. 直觉与动机

**灵感 1（并发推理 → 把「思考」并行、把「动手」串行）**
直觉：人类工程师不会只沿一条思路修盲区。他会同时想「换角度重拍」「换工具」「先擦再拍」「借相似工件的经验」，几条思路在心里并行推进，最后只执行最有把握的一条。把它做成系统，就是并发地跑 M 条推测分支（不同假设/工具/块计划），用墙钟并行换取更短的决策延迟和更好的候选覆盖。但并发必须被严格分区：**并发的只能是「影子世界里的推理」，真实执行仍由单写者串行提交**。否则两条分支同时改同一台设备，会产生不可交换的物理动作，制造基线里没有的新风险。

**灵感 2（演示数据 → 把「人做过的」变成先验，而不是策略）**
直觉：一次成功修复的演示，最有价值的信息不是那串具体动作，而是它隐含的**先验**：这类盲区通常先做什么、哪些工具组合有效、什么条件下该放弃。因此演示数据应进入「候选生成 + 先验重排 + 残差校准」，而**不是**被当成可直接复放的策略。演示是离线、跨分布、可能过期的：它能把搜索空间缩小一个数量级，也能把一个人的坏习惯放大成系统的默认行为。所以必须给每条演示配来源证书、适用范围、有效期，并在进入执行前重新过能力闭包与安全盾。

**灵感 3（两者耦合 → 相关分支的「共识幻觉」）**
直觉：最危险的耦合不是「并发慢」或「演示旧」，而是 **M 条分支因为共享同一批演示而同时犯错**。它们看起来「异口同声」，系统误把相关性当成独立证据，于是用名义样本量 M 去算置信度，实际有效样本量可能只有 1。演示先验越强、检索越集中，这种「共识幻觉」越严重；并发只是把同一个偏见复制了 M 份。解法不是减少并发或禁用演示，而是三根结构支柱：**来源多样性约束**（分支须来自不同演示簇）、**有效样本量 M_eff 校正**（相关性折算后再做证书与校准）、**反事实演示依赖审计**（去掉演示先验后结论是否翻转），再叠加**单写提交栅栏**保证物理执行永远串行。

## 1. 研究问题（本轮要回答什么）

- **Q1（并发的边界）**：并发推理在什么条件下只是「加速」、在什么条件下会引入新的物理/状态竞争？能否用「推测-执行分离 + 单写提交」把并发限制在纯推理层？
- **Q2（演示的可用性）**：演示数据能否作为安全的先验来源，而不是策略复放或新的越权/过拟合入口？其收益与过期/分布漂移如何量化？
- **Q3（相关性的放大）**：当演示先验使分支相关时，名义并发数 M 与有效证据量 M_eff 的差距如何界？能否用结构（来源多样性、M_eff 校正、反事实审计）把「共识幻觉」压回可检出的范围？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P1 推测-执行分离（Speculate-Then-Commit）**
并发只发生在影子世界：每条分支在隔离的世界模型/仿真副本上规划，输出候选块；真实状态只有一个写者。提交栅栏保证任一时刻至多一条分支的块被 CVC 接纳并串行执行。这条把「并发」从物理风险降为计算调度问题。

**P2 演示只作先验（Demo-as-Prior, Never-as-Policy）**
演示只能改变候选的**先验权重与检索排序**，不能扩大工具集/物理包线，不能跳过安全序与不可逆屏障。任何由演示导出的动作都必须重新通过能力闭包投影与安全盾；演示过期或越界 ⇒ 该演示被降权/剔除，而不是被信任。

**P3 相关性感知证据（Correlation-Aware Evidence）**
分支的「一致」不等于「独立」。所有置信度、共形分位与提交阈值都以有效样本量 `M_eff = M/(1+(M−1)ρ̄)` 校正；当来源多样性不足或 `M_eff` 低于阈值时，系统必须降级为单分支或弃权，而不是用 M 冒充独立证据。

## 3. 与基线的接口（如何退化）

- 演示库为空 / 检索为空 / 先验强度 β=0 ⇒ 均匀先验，等价于 InstructGauge 的候选分布；
- 并发度 M=1 / 分支隔离不可用 / 提交栅栏不可用 ⇒ 单分支串行，等价于 InstructGauge 的 IAC→CVC；
- 演示有效期过期 / OOD 检出 / 来源多样性不足 ⇒ 剔除演示或降到 M=1，并回退 SC-Cal 全局阈值；
- 相关性估计不可用 ⇒ 取最保守 `M_eff=1`，即要求独立回执再提交；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「并发推测、串行提交」的执行架构，把并发从物理竞争风险中隔离出来，并给出延迟—并发度—有效证据的定量交换；
2. 一个「演示作先验」的接地口径：来源证书 + 能力闭包投影 + 有效期/OOD 门控，使演示不能成为越权或过拟合通道；
3. 一个相关性感知的证据校正：用 `M_eff` 修正置信与共形分位，显式刻画「共识幻觉」，并给出 `M` 的最优上界（超过 `1/ρ̄` 的并发纯属浪费）；
4. 一条完整可证伪路径 E457–E472，覆盖检索、泄漏、竞争、相关性、漂移、投毒与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：真正致命的不是并发或演示本身，而是**共享演示先验让 M 条并发分支产生相关的「假共识」**——系统把相关性误当独立证据、以名义 M 过度自信地提交一个已经串行执行的块，而单写栅栏只防状态竞争、防不住共享语义偏见；一旦该块跨过不可逆动作，错误就无法用后续回执追回。

# 第 4 轮产物 · 创新点清单 v4：**ChronoPoseGauge**（时相-位姿计量：延迟感知的证据账本与位姿证书化）

> 背景：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）；第 2 轮 ToolGauge（IP-315–320；定义 416–431；引理 46–50）；第 1 轮 LeanGauge / MODGAUGE 骨架不变。
> 本轮灵感：「通信延迟」×「位姿估计」
> **继承纪律**：MODGAUGE 五不变式、4CV 骨架、ToolGauge-6C 闭环、InstructGauge-7C 闭环、严格退化链全部保留。新组件一律为**可选增强**：任一环节不可用 ⇒ 退回 InstructGauge ⇒ 退回 ToolGauge ⇒ 退回 LeanGauge ⇒ 退回 MODGAUGE。

## 0. 结论：从「同步新鲜」到「时空可证」

InstructGauge 把语言与分块纳入闭环，但它默认了两件未被检验的事：**回执是及时的**、**几何是精确的**。通信延迟击穿第一件，位姿估计击穿第二件，而二者在盲区修复处相乘：延迟使位姿变旧，位姿误差随「旧了多久 × 动得多快」增长；位姿不确定又反过来缩短证据的几何有效期。ChronoPoseGauge 的核心不是「预测未来」或「重定位更准」，而是把**时间与位姿变成可携带、可检查、可退化的证书**：

- **TEL** 用双时间戳 + 因果 DAG + `as-of` 快照，消除「拿旧证据当新证据」；
- **PVC/STG** 用 SE(3) 右不变协方差与有效视界，把 `κ_st = κ_t·κ_p` 变成硬门；
- **PCC** 用（指令 × 位姿格 × 时龄桶）分层共形校准，修复共享位姿隐变量造成的覆盖失效；
- **DAS/DPG** 用截止期-信息价值调度与延迟边位姿图，让远程慢路径只增强、不阻塞；
- **TAC** 用时间参数化分块，把「块长」升级为「时空预算内的可截断动作段」。

## 3. 形式化定义（要点）

**定义 448（双时间证据项与因果账本 TEL）** 证据项 `r = (id, payload, t_evt, t_rx, src, hlc, seq, pose_ref, Σ_r, parents)`，其中 `t_evt` 为事件发生时间、`t_rx` 为接收时间、`hlc` 为混合逻辑时钟、`parents` 为因果前驱。账本 `𝕃` 是只追加的因果 DAG，`≺_c` 为其传递闭包。对任意 `r, r'`，若 `r ≺_c r'` 则 `hlc(r) < hlc(r')`。`(src, seq, hlc)` 唯一，重复项与重放项在入账时按 `id` 去重并记录来源。账本只增不改；删除以墓碑记录表达。

**定义 449（as-of 快照与无未来泄漏）** 对查询 `Q` 与决策时刻 `t`：
`as_of(t, Q) = eval(Q, { r ∈ 𝕃 : t_evt(r) ≤ t ∧ r ≺_c now })`。
语义只由 `t_evt` 决定，`t_rx` 只影响「何时可用」，不影响「何时为真」。禁止 `latest` 语义直接进入决策：若必须使用最新到达项，必须显式标注 `t_evt` 并重新通过 STG。`σ_t := as_of(t_commit, StateQuery)` 是提交时刻的唯一状态快照。

**定义 450（位姿有效性证书 PVC）** `x̂ = (T̂ ∈ SE(3), Σ ∈ SPD(6), t_x, src, H_x, version)`。在时刻 `t`、阈值 `ε = (ε_t, ε_r)` 下：
`valid(x̂, t, ε) ⇔ (t − t_x ≤ H_x(ε)) ∧ (λ_max(Σ_t) ≤ ε_t²) ∧ (λ_max(Σ_r) ≤ ε_r²) ∧ authenticated(src)`。
接触/不可逆动作使用更严的 `ε_contact = (ε_t^c, ε_r^c)`。证书的 `version` 随任何后端修订单调递增，旧版本只读。

**定义 451（SE(3) 右不变误差与不确定度传播）** 取右不变误差 `E = T̂ T^{-1}`，`ξ = log(E) ∈ se(3)`，`Σ = Cov(ξ)`。在时龄 `a` 内，若本体线速度与角速度分别被 `v_max, ω_max` 界定，则保守界
`Σ(a) ⪯ Σ0 + a² · diag(v_max² I₃, ω_max² I₃)`；
若采用布朗运动近似则 `Σ(a) = Σ0 + a Q`。由此有效视界
`H_x(ε) = min{ (ε_t − sqrt(λ_max Σ_t0))⁺ / v_max, (ε_r − sqrt(λ_max Σ_r0))⁺ / ω_max }`。
视界是「证书过期时间」，不是「重定位周期」：即使不重定位，也可由膨胀后的 `Σ(a)` 给出保守可用性，直到超过阈值。

**定义 452（时空预算与有效性门 STG）** 令 `a = t − t_x`，定义
`κ_t = 1 + a / H_x`，`κ_p = 1 + λ_max(Σ) / ε_pose²`，`κ_st = κ_t · κ_p`。
证据 `r` 通过 STG 当且仅当：
`t_evt(r) ≤ t`、`(t − t_evt(r)) ≤ H_meas`、`κ_st ≤ B_st`、`src` 已认证、且 `c(x̂)` 在已校准位姿格内。
任一失败 ⇒ 证据标记 `quarantined`，只可进入审计，不可进入几何/契约更新；同时把 `Σ` 膨胀 `γ>1` 倍并触发一次 `Degrade_ST` 评估。接触动作额外要求 `valid(x̂, t, ε_contact)`。

**定义 453（位姿×时龄分层共形校准 PCC）** 令
`stratum_st(ι) = (stratum(ι), c(x̂), b(a))`，
其中 `c(·)` 为位姿格（如按视角/距离分箱）、`b(·)` 为时龄桶。对每层用校准集 `C_cal^{s,c,b}` 取共形分位 `q_{s,c,b}`，使 `P(h* ∈ H_{s,c,b} | s,c,b) ≥ 1−α`。若 `|C_cal^{s,c,b}| < n_min`，按 `(s,c,·) → (s,·,·) → global` 逐级回退；回退必须在证书中记录，不得静默。

**定义 454（位姿/时龄 Lipschitz 覆盖插值）** 设校准分位对位姿格与时龄桶满足
`|q_{s,c,b} − q_{s,c',b'}| ≤ L_p d(c,c') + L_t |b−b'|`，
其中 `d(·,·)` 为格中心测地距离。对未直接校准的 `(c,b)`，取最近已校准格的分位；其覆盖损失上界为 `L_p d(c,c') + L_t |b−b'|`。若格内位姿直径 `diam(c) > 0`，还需加上测量模型对位姿的 Lipschitz 项 `L_h · diam(c)`。

**定义 455（通信延迟模型与延迟预算）** 单程延迟 `d = t_rx − t_evt = d_fix + J`，`J ∈ [−J_max, J_max]`；另有丢包率 `p_loss` 与重排窗 `W_reorder`。由心跳/RTT 的 EWMA 与共形上分位给出 `d̂_q ≥ d`（以 `1−δ` 置信）。若 `t_now + d̂_q > deadline`，远程结果对当前决策「迟到」；迟到结果不得回灌当前决策，只能进入 `L_slow` 供后续 `as-of` 查询。HLC 单调性与 `hlc`/`seq` 校验拒绝不可能时间戳与重放。

**定义 456（截止期-信息价值调度 DAS）** 对远程任务 `r`，`VoI(r) = E[U(π_{t+d̂} | r) − U(π_t)]`。仅当
`p_arrive(B_d) · VoI(r) ≥ c_remote + c_wait`
时提交远程；其中 `B_d = deadline − t_now − c_comp`，`p_arrive` 由 `d̂_q` 估计。硬截止期任务用 EDF；本地 anytime 策略 `π_loc`（LeanGauge 数值路径）始终可用，绝不为等待远程而空转。若 `p_arrive` 低于阈值，直接选本地，并记录「放弃远程」的审计项。

**定义 457（延迟边增量位姿图 DPG）** `G_t = (V_t, E_odo ∪ E_loop)`。节点为带 PVC 的关键帧；`E_odo` 为本地即时里程计边，`E_loop` 为延迟到达的闭环/全局配准边。后端做增量非线性最小二乘，`E_loop` 使用鲁棒核（Huber/switchable constraint）抑制错误闭环。快路径只读最近一次求解的 `Σ_marg`。迟到边可触发重线性化与信念修订，但受定义 458 约束。

**定义 458（信念修订与动作历史非回写）** 维护两个分离对象：`Belief_v`（可变、带版本、可被闭环修订）与 `ActionLog`（只追加、不可改写）。修订 `rev: Belief_v → Belief_{v+1}` 允许改变「当时位姿的后验」，但必须满足 `ActionLog(Belief_{v+1}) = ActionLog(Belief_v)`。任何 `RepairCert″` 同时引用 `belief_version` 与 `action_log_index`，审计者可区分「当时相信什么」与「当时做了什么」。

**定义 459（时间参数化动作与前缀封闭 TAC）** 动作段 `a^τ = (traj, τ_s, τ_e, guards(t))`，其中 `traj: [τ_s,τ_e] → 𝒜`，`guards(t)` 为连续可评估守卫。前缀封闭升级为**时间前缀封闭**：任意 `[τ_s, τ]`（`τ ≤ τ_e`）均是可执行、可截断的合法段。守卫在每个 50Hz 控制拍评估；只有 STG 与守卫同时通过才推进下一时间片。不可逆动作必须满足 `τ_e − τ_s = Δt`（单步）。

**定义 460（时空-语义联合块长上限）** 在定义 440 的 `κ_sem` 之外，再叠加时空约束：
`K_MAX^st(ι, x̂, a) = ⌊ min( K₀ / (κ_sem · κ_st), (H_x − a)⁺ / (v_max Δt), B_st / Δt, S_max / (J_max + Δt) ) ⌋`
其中 `S_max` 为允许的块级陈旧窗口。实行 `K = max(1, min(K_MAX^st, K*))`，`K*` 由引理 53/65 给出。跨越不可逆动作或接触动作 ⇒ `K=1`，与定义 445 一致。

**定义 461（位姿条件化指代接地）** 对指代 `r`，定义
`ref_conf^st(r) = ref_conf(r) · σ(α(H_x − a)) · σ(β(ε_pose² − λ_max(Σ)))`，
其中 `σ` 为单调压缩函数。若 `ref_conf^st(r) < τ_ref`，NLI-Box 输出 ⊥ 并退回默认 `ι₀`——**位姿不确定时选择放弃指代，而不是猜一个指代**。这使位姿误差只能降低语义接地的召回，不能悄悄降低其精度。

**定义 462（接触/不可逆动作的位姿许可）**
`Permit(a_t) ⇔ valid(x̂_t, t, ε_contact) ∧ STG(r_t) ∧ (a_t ∈ I_irr ⇒ 独立回执交叉验证已通过)`。
未获许可时，只允许回撤、重定位、非接触观测；禁止任何进入 `I_irr` 的动作。这给不可逆屏障再加一道几何闸门。

**定义 463（时相修复证书 RepairCert″）**
`RepairCert″(s) = (𝕃|_{t≤t_end}, G_t^{version}, ι, C, ChunkCert, receipts, claims, {STV_cert}, delay_provenance, belief_version, action_log_index)`。
它把第 3 轮的四级证据链扩展为六级：**指令 → 块 → 回执 → 主张 → 时空有效性 → 信念/动作版本**，使「为什么当时认为这个位姿可用」可被独立重放。

**定义 464（降级自动机 Degrade_ST）** 状态 `Nominal → DegradedClock → LocalOnly → NumericOnly → SafeHold`。迁移条件：HLC 偏斜超界/因果不可判定 → `DegradedClock`；`d̂_q > B_d` 或丢包超阈值 → `LocalOnly`；位姿证书无效或配准失败 → `NumericOnly`；位姿图发散/连续 STG 拒绝 → `SafeHold`。各状态分别映射到 InstructGauge / ToolGauge / LeanGauge / MODGAUGE 的对应能力；迁移必须记录原因与证据 id。

**定义 465（快慢时相隔离接口）** 快路径只读 `L_fast = {r ∈ 𝕃 : src ∈ 本地传感器 ∧ t_rx − t_evt ≤ B_fast}`，其最坏读延迟 `B_fast` 有界；慢路径写 `L_slow`，仅在 `q_quiesce` 合并进可用契约。任何远程调用不得出现在 50Hz 关键路径上；合并前必须通过 `contract_regression` 与 `q_quiesce` 检查。

class TemporalLedger:
    def append(self, rec):
        rec.id = stable_id(rec)
        rec.hlc = self.hlc.tick(rec.t_evt)      # 物理时间 + 逻辑计数
        if self.seen(rec.src, rec.seq, rec.hlc):  # 重放/重复
            return self.tombstone(rec, "replay")
        rec.parents = self.frontier(rec.hlc)
        self.dag.add(rec)
        return rec

    def as_of(self, t, query):
        # 只取事件时间 <= t 且因果前驱闭包内的记录
        return eval_query(query, self.dag.ancestors_before(t))

class PoseGate:
    def propagate(self, pose, age):

        return PoseCert(pose.T, S, pose.t, pose.src,
                        horizon=min((eps_t - sqrt(maxeig(S[:3,:3])))/v_max,
                                    (eps_r - sqrt(maxeig(S[3:,3:])))/w_max))

                and kt * kp <= B_st and pose.valid(t, eps_pose)

# IP-334 TAC：时空预算内的块长
def chunk_len_st(iota, pose, age, drift_bound):
    if iota is None or not pose.valid(now, eps_pose):
        return 1
    kappa_sem = chunk_len_upper(iota)              # 定义 440 的 K_MAX(ι)

## 5. 推导

**引理 59（as-of 确定性与无未来泄漏）** 若 `as_of(t, Q)` 只依赖 `{r : t_evt(r) ≤ t ∧ r ≺_c now}`，则：(i) 结果不依赖任何 `t_evt > t` 的证据；(ii) 对同一账本前缀与同一查询，离线重放与在线决策逐位一致；(iii) 迟到证据只能改变其 `t_evt` 之后的 `as-of` 结果，不能改变已提交快照。
*证明骨架*：对因果 DAG 的拓扑序归纳。基础情形只含 `t_evt ≤ t` 的源记录；归纳步中任何前驱仍满足事件时间约束。重放是账本前缀的纯函数，故确定性成立。已提交快照是 `as_of(t_commit, ·)` 的不可变值，迟到项的事件时间不影响它。

**引理 60（位姿不确定度传播与视界闭式）** 在定义 451 的有界速度假设下，对任意 `a ≥ 0`，平移与旋转误差分别满足
`e_t(a) ≤ e_t(0) + v_max a`，`e_r(a) ≤ e_r(0) + ω_max a`；
若用协方差传播，则 `λ_max Σ(a) ≤ λ_max Σ0 + a² · max(v_max², ω_max²)`。因此 `H_x(ε)` 是使 `valid(x̂, t, ε)` 成立的最大时龄，且对 `v_max, ω_max, ε` 单调。
*证明*：三角不等式给出确定性误差增长；对协方差，`Σ(a) ⪯ Σ0 + a² diag(v²,ω²)` 逐项取最大特征值即得。视界的单调性由分子非负、分母正定直接得到。

**引理 61（STG 的证据可靠性）** 若证据 `r` 通过 STG，则其位姿误差满足 `‖ξ‖ ≤ ε_pose`、测量时龄 `≤ H_meas`，且落在已校准位姿格内。若测量模型 `h` 对位姿 `L_h`-Lipschitz、对时龄 `L_a`-Lipschitz，则其残差相对校准支撑的偏移不超过 `L_h ε_pose + L_a H_meas`。将该偏移计入共形带后，接受证据的第一类错误率仍 `≤ α`。
*证明*：STG 的合取条件直接给误差与时龄界；Lipschitz 条件把参数偏差转成残差偏移；共形带按偏移扩张即恢复覆盖。注意：STG 只保证「在支撑内」，不保证「分布不变」——后者由 PCC 与漂移检测负责。

**引理 62（位姿×时龄分层覆盖与回退降级）** 在每个 `(s,c,b)` 层内可交换时，层内覆盖 `P(h*∈H_{s,c,b}|s,c,b) ≥ 1−α`。对未校准的 `(c,b)`，用最近层插值的覆盖下界为 `1−α − L_p d(c,c') − L_t |b−b'| − L_h diam(c)`。若因样本不足回退到全局，则额外损失不超过 `2η_global`（全局与层内分数分布的全变差项）。
*证明*：层内共形分位给 `1−α`；跨层由 Lipschitz 插值放缩；回退损失由全变差三角不等式给出。与第 3 轮引理 55 相比，这里把「指令层」扩展为「指令×位姿×时龄」，因此覆盖失效会被定位到具体时空格，而不是被平均值掩盖。

**引理 63（共享位姿隐变量的条件交换性修复）** 设各模态残差 `e_i` 通过共享位姿 `Z` 相关。若校准只按指令分层、不条件于 `Z`，则存在 `z` 使 `P(h*∈H|Z=z) < 1−α`，即使边缘覆盖看似达标。若按位姿格 `c(Z)` 分层且在格内可交换，则每格恢复 `≥1−α`；联合模态失效满足 `P(∩_i fail_i | c) ≤ Σ_i P(fail_i | c)`。
*证明*：条件分布的混合使同一分位在不同 `z` 上对应不同尾概率；取使尾概率最大的 `z` 即得反例。条件于 `c(Z)` 后，共享分量在格内被固定，残差近似条件独立，共形与并集界恢复。故「位姿条件化」不是精度优化，而是覆盖保证的前提。

**引理 64（截止期调度的支配性与本地降级）** 记远程结果按时到达概率 `p`，远程/本地效用 `U_r > U_l`，等待与远程代价 `c_wait, c_remote`。则提交远程的期望净收益为 `p·(U_r−U_l) − c_wait − c_remote`；仅当其非负时远程优于本地。对硬截止期任务，EDF 在单机可抢占模型下最小化最大延迟；本地 anytime 回退保证「远程迟到」不转化为「决策超期」。
*证明*：期望效用线性展开；EDF 最优性是经典交换论证；本地回退路径与远程到达事件解耦，故远程延迟不进入本地关键路径。

**引理 65（时空-语义块长的比较静态）** 在引理 53 的 `K*` 基础上叠加定义 460 的上界，得 `K*_st = min(K*, K_MAX^st)`。`K*_st` 对 `J_max, v_max, ω_max, λ_max Σ, a, κ_sem` 单调不增，对 `H_x, B_st, S_max` 单调不减；当 `κ_st → ∞` 或 `H_x → a` 时 `K*_st → 1`。
*证明*：各分母项均为对应参数的单调函数，`min` 保持单调性；极限由 `K_MAX^st` 的表达式直接得到。故「链路越抖、位姿越不确定、指令越含糊，块越短」不是调参经验，而是预算约束的必然。

**引理 66（非回写审计等价与 50Hz 时相隔离）** 若信念修订满足定义 458，则 `ActionLog` 对任意 `rev` 不变，审计可沿 `RepairCert″` 的六级证据链独立重放。若快路径只读 `L_fast` 且远程合并只在 `q_quiesce` 发生，则 50Hz 主循环的最坏执行时间与远程延迟无关，新增开销仅为本地入账与 STG 检查的常数项。
*证明*：`ActionLog` 只追加且修订算子不写它，故不变；重放按 `as-of` 与版本号确定性重建。时相隔离把远程等待移出关键路径，`B_fast` 有界故 WCET 不变。未涉及的子图逐指令等价性回到 InstructGauge 引理 57 → ToolGauge 引理 49 → 第 1 轮引理 44。

**引理 67（退化链的语义保持）** 降级自动机 `Degrade_ST` 的每次迁移都对应一个基线能力子集：`LocalOnly` ⇒ LeanGauge 数值路径；`NumericOnly` ⇒ 无几何契约更新；`SafeHold` ⇒ 冻结地图并只允许回撤；`DegradedClock` ⇒ 保守时龄 + 禁止远程契约。迁移不改变已执行动作日志，只缩小可用动作与更新集合，故退化是安全的（只减不增）。
*证明*：逐状态检查迁移后的动作集与更新集均为原集合的子集；`ActionLog` 不变由引理 66 给出；可行性由基线各引理保证。

## 9. 与基线的关系（一句话版）

- 相对 **InstructGauge**：新增「时相 + 位姿」两条正交证据轴；语言与分块仍在，但块长再被时空预算夹紧，指代接地再被位姿置信度门控。
- 相对 **ToolGauge**：契约更新从「同步新鲜」变为「as-of + 版本化 + 非回写」，几何契约按位姿格与时龄桶分层。
- 相对 **LeanGauge / MODGAUGE**：退化路径不变；只是多了一个「几何不可信 ⇒ 数值优先」的显式状态。

## 10. 本轮最大风险

**一句话**：`PVC/STG` 把「位姿是否可用」压缩成一个标量预算，而真实失效往往不是「协方差变大」而是**协方差不自知地偏了**（系统性配准偏差、共享外参错误、延迟导致的运动畸变）——此时门会以高置信度放行一份几何上已经错位的证据，ChronoPoseGauge 真正的残余风险是**位姿不确定度的可观测性与校准本身**，而不是延迟或分块。
