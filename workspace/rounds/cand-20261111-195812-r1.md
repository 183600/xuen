# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「数据质量」×「用户测试」）

> 第 54 轮把技能组合推进为「动作空间剖面 α_S + 云边协同 γ_ce + 动作-鲁棒性联合证书 J」的可判定体系。本轮回头质问整条证书链最不起眼、却最先失效的底座：**证据本身可信吗**。核心矛盾：H22：所有 ρ、α_S、J 都是**数据条件证书**，证书 soundness 只在「数据集 𝔇 与真实部署分布同分布」时成立，而这一前提从未被度量，于是出现「认证很漂亮、上线就崩」的**证书膨胀**；H23：用户测试被当作上线前的一次性终审，既未被视为**带测量误差的外部证据采样**，也未反哺数据质量，导致仿真-现实差距只能靠运气收敛。

## 0. 直觉与动机

**灵感 1（证书的证据断层 → 数据质量是证书链的隐性公理）**
直觉：第 54 轮的 `J = (ρ, A_cert, γ_ce, δ_a, evidence)` 里，`evidence` 是最弱的一环却决定了全部结论。一个在 99% 干净数据上算出的 `ρ=0.95`，遇到 20% 标注噪声或长尾动作缺失时，可能只剩 0.6。**数据质量不是实验的准备工作，而是证书的一等维度**：证书必须写成 `C(𝔇)` 而不是 `C`，并附带「该证书对 𝔇 的依赖有多强」的显式声明。

**灵感 2（用户测试 → 不是终审，而是独立的外部证据采样）**
直觉：用户测试之所以重要，不是因为它“最后做”，而是因为它是**唯一不被仿真器与训练数据共同偏置**的观测通道。但它本身也是采样：任务是否代表真实分布（代表性）、评分者是否一致（κ 信度）、样本量是否足够（有效样本量）、测试场景是否生态有效（ecological validity）。把用户测试当成“真值”是错的，把它当成**带偏差与方差的第二个估计器**才是对的。

**灵感 3（数据质量剖面 → 数据条件鲁棒性与有效样本量）**
直觉：给数据集定义质量剖面 `q_𝔇 = (覆盖、平衡、标注一致、时序新鲜、仿真-现实差距)`，并把标称样本量折算为**有效样本量** `n_eff = n / (1 + (k-1)ρ_intra)`（设计效应，k 为簇大小，ρ_intra 为簇内相关）。证书的置信半径随 `n_eff` 而非 `n` 收缩——重复采集同一角落的相似样本，不会让证书更可信，只会让它更自信地错。

**灵感 4（证书膨胀监测 Δ_cert → 把“认证与现实之差”当作一等公民）**
直觉：定义 **证书膨胀** `Δ_cert(d) = |ρ_𝔇(d) - ρ_U(d)|`，即训练/仿真数据集上的认证值与用户测试上的经验值之差。Δ_cert 超过预算即判定证书**失效**，无论 ρ_𝔇 多高。这把第 54 轮“证书 sound”从“证明成立”降级为“在证据质量 budget 内成立”，反而更诚实、更可运维。

**灵感 5（质量加权主动补采 → 用最少的样本买最大的证书收紧）**
直觉：数据质量缺口不是均匀的，而是集中在「动作剖面覆盖低 × 鲁棒性谱低 × 用户测试失败率高」的三重难区。主动补采策略 `π_q` 的目标不是最大化样本量，而是最大化**单位成本下 Δ_cert 的收缩**，即 `max E[Δ_cert↓] / cost`。这把数据采集从“堆量”变成“买证书精度”。

**灵感 6（双闭环：数据→证书→用户测试→重资格）**
直觉：形成 `𝔇 → 仿真/训练 → 证书 C → 用户测试 U → Δ_cert → 数据修复/补采 → 重资格 RQ(C)` 的闭环。关键不是“测试发现问题就改模型”，而是**测试结果先被归因为数据缺陷还是模型缺陷**（沿用第 53 轮 Explain），再决定是补数据、改剖面还是收窄动作域。用户测试因此成为数据质量治理的驱动器，而非上线闸门的装饰。

**灵感 7（证据层 𝔼：在鲁棒性金字塔 𝕃 与动作层 𝔸 之下再垫一层）**
直觉：`𝔼_0` 原始观测与标注，`𝔼_1` 数据质量剖面 q_𝔇，`𝔼_2` 数据条件证书 C(𝔇)，`𝔼_3` 用户测试外部证据与 Δ_cert。跨层证书必须携带「证据溯源链」`provenance`，否则上层越精致，底层越脆弱——**没有证据层的证书体系是沙上建塔**。

## 1. 形式化定义（增量：定义 121–127）

展开说明：设数据集 `𝔇 = {(x_i, y_i, a_i)}_{i=1}^n`，`a_i` 为动作/上下文标签，部署分布为 `P`，用户测试集为 `U`。

**定义 121（数据质量剖面 DQP）**
质量剖面 `q_𝔇 : Q → [0,1]`，`Q = {cov, bal, agr, fresh, gap}`：
- `q_cov`：对部署分布 `P` 的覆盖度，`q_cov = 1 - sup_{x} (dP/d𝔇 - 1)_+`；
- `q_bal`：类别/动作长尾平衡度，`q_bal = 1 - TV(𝔇_label, U_label)`；
- `q_agr`：标注一致性，`q_agr = κ_multi`（多标注者 Fleiss κ）；
- `q_fresh`：时序新鲜度，`q_fresh = exp(-Δt/τ_fresh)`；
- `q_gap`：仿真-现实差距代理，`q_gap = 1 - Δ̂_gap`。
标量质量 `Q(𝔇) = min_{d∈Q} q_𝔇(d)`（木桶原则，最弱维度决定证书上界）。

**定义 122（有效样本量与数据可信证书 DTC）**
有效样本量 `n_eff = n / (1 + (k-1)ρ_intra)`。数据可信证书
```
D_cert = (q_𝔇, n_eff, provenance, drift_witness)
```
其中 `provenance` 为采集-清洗-标注的溯源链，`drift_witness` 为分布漂移见证（MMD/KS 检验 p 值）。`trust(𝔇) = F(Q(𝔇), n_eff, drift_witness)` 单调不减。

**定义 123（用户测试证据对象 UTE）**
用户测试 `U = {(τ_j, s_j, r_j)}_{j=1}^{m}`，`τ_j` 为任务，`s_j∈{0,1}` 为成败，`r_j` 为主观评分。
- 任务代表权重 `w(τ)`，满足 `∫_T w(τ)dτ = 1`；
- 证据积分 `UTE(S) = ∫_T w(τ) · p̂_succ(τ | S) dτ`；
- 有效测试量 `m_eff = m / (1+(k_U-1)ρ_U)`；
- 评分信度 `κ_U`（评分者间一致性），任务覆盖 `cov_U(𝔇)`。

**定义 124（用户测试质量剖面 UTQ）**
```
u_U = (cov_U, m_eff, κ_U, eco_U)
```
`eco_U` 为生态有效性（测试环境与部署环境的任务/动作分布重叠度）。`Q_U(U) = min(cov_U, m_eff/m_*, κ_U, eco_U)`，`m_*` 为统计功效所需样本量。

**定义 125（数据条件证书与证书膨胀）**
数据条件鲁棒性 `ρ(d | 𝔇)`。证书膨胀
```
Δ_cert(d) = |ρ_𝔇(d) - ρ_U(d)|,
Δ_cert^max = max_d Δ_cert(d)
```
其置信上界 `Δ_cert^+ = Δ_cert^max + z_{1-δ/2}·sqrt((1/2m_eff)ln(2/δ))`。

**定义 126（质量加权证书有效性）**
联合证书 `J` **有效**当且仅当
```
valid(J) ⇔ sound(J | 𝔇) ∧ Q(𝔇) ≥ θ_q ∧ Q_U(U) ≥ θ_u ∧ Δ_cert^+ ≤ Θ_Δ
```
即：证书不仅要“对 𝔇 成立”，还要满足数据质量门槛、测试质量门槛，且认证与外部证据之差在预算内。

**定义 127（重资格认证闭环 RQ）**
重资格算子 `RQ : (J, U) → J'`：
```
RQ(J,U) = 
  if Δ_cert^+(d) > Θ_Δ:
      root = Explain(ρ_𝔇(d) - ρ_U(d))
      action ∈ {补采(π_q), 重标注, 收窄 A_core, 下调 ρ_min}
  else: J
```
并强制 `provenance(J') = provenance(J) ∪ {U, 修复动作}`，形成可审计的证据链。

## 2. 关键算法 伪代码

### IP-121 DQP（Data Quality Profiling）

```python
def data_quality_profile(dataset, deploy_ref, task_ref, tau_fresh):
    q_cov  = coverage_score(dataset, deploy_ref)          # 1 - sup density deficit
    q_bal  = 1 - total_variation(label_dist(dataset), label_dist(task_ref))
    q_agr  = fleiss_kappa(dataset.annotation) if dataset.multirater else krippendorff_alpha(dataset.annotation)
    q_fresh = math.exp(-time_since(dataset) / tau_fresh)
    q_gap  = 1 - sim_real_gap(dataset, deploy_ref)
    q = dict(cov=q_cov, bal=q_bal, agr=q_agr, fresh=q_fresh, gap=q_gap)
    q["Q"] = min(q.values())
    return q

def effective_n(n, cluster_sizes, rho_intra):
    k = mean(cluster_sizes)
    return n / (1 + (k - 1) * rho_intra)
```

### IP-122 DTC（Data Trust Certificate）

```python
def data_trust_certificate(dataset, deploy_ref, task_ref, delta=0.05):
    q = data_quality_profile(dataset, deploy_ref, task_ref, tau_fresh)
    n_eff = effective_n(len(dataset), dataset.cluster_sizes, dataset.rho_intra)
    drift_p = mmd_test(dataset, deploy_ref)
    prov = provenance_chain(dataset)            # 采集→清洗→标注→版本
    D = DTC(q=q, n_eff=n_eff, provenance=prov,
            drift_witness=drift_p, alpha=delta)
    D.trust = monotone_trust(q["Q"], n_eff, drift_p)
    return D
```

### IP-123 UTE（User Test Evidence Integral）

```python
def user_test_evidence(U, task_weights, delta=0.05):
    p_succ = {tau: wilson_interval(U.success[tau]) for tau in U.tasks}
    ute = sum(task_weights[t] * p_succ[t].mean for t in U.tasks)
    m_eff = effective_n(len(U), U.session_sizes, U.rho_intra)
    u = dict(cov_U=U.task_coverage,
             m_eff=m_eff,
             kappa=cohen_or_fleiss_kappa(U.ratings),
             eco_U=U.ecological_overlap)
    u["Q_U"] = min(u["cov_U"], m_eff / required_power(U), u["kappa"], u["eco_U"])
    # bootstrap 置信区间 + 任务代表性
    ci = bootstrap_ci(U, task_weights, B=2000, alpha=delta)
    return UTE(score=ute, ci=ci, quality=u, n_eff=m_eff)
```

### IP-124 CIM（Certificate Inflation Monitor）

```python
def certificate_inflation(rho_D, rho_U, m_eff, delta=0.05):
    delta_cert = {d: abs(rho_D[d] - rho_U[d]) for d in rho_D}
    radius = math.sqrt((1/(2*max(m_eff,1))) * math.log(2/delta))
    delta_plus = max(delta_cert.values()) + 1.96 * radius
    return CIM(delta_cert=delta_cert,
               delta_plus=delta_plus,
               verdict="invalid" if delta_plus > THETA_DELTA else "valid")
```

### IP-125 ADP（Active Data Procurement，质量加权补采）

```python
def active_data_procurement(pool, cert, U, budget, pi_q):
    # 难区 = 低覆盖 ∩ 低鲁棒 ∩ 用户测试高失败
    hard = []
    for tau in U.tasks:
        for a in tau.action_region:
            score = (1 - cert.q["cov"](a)) * (1 - cert.rho.get(a, 0)) * U.fail_rate(tau, a)
            hard.append((score, tau, a))
    gains = []
    for score, tau, a in top_k(hard, budget):
        x = pi_q.acquire(tau, a)
        est_gain = expected_delta_cert_reduction(x, cert)
        gains.append((est_gain / pi_q.cost(x), x))
    return select_under_budget(gains, budget)
```

### IP-126 RQL（Requalification Loop）

```python
def requalify(J, U, cert_model, data_pool, budget):
    cim = certificate_inflation(J.rho, U.rho, U.n_eff)
    if cim.verdict == "valid":
        return J
    root = explain_gap(J.rho, U.rho, U)       # 数据缺陷 or 模型缺陷
    if root.type == "data":
        new = active_data_procurement(data_pool, J, U, budget, pi_q)
        D_new = J.data + new
        J_new = recertify(cert_model, D_new)  # 重跑 ρ, α_S, J
    elif root.type == "action_shift":
        J_new = narrow_action_domain(J, root.actions)   # 收窄 A_core / 下调 ρ_min
    else:
        J_new = tighten_rho_min(J)                        # 保守部署
    J_new.provenance = J.provenance + [U, root, J_new.data.version]
    return J_new
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DQP | O(n·|Q| + n log n) | O(|Q|·bins) | 覆盖估计、κ 估计无偏 |
| DTC | O(n + n_eff) | O(|Q| + \|provenance\|) | n_eff 折算、漂移检验 |
| UTE | O(m·|T| + B·m) | O(m) | 任务权重归一、CI 校准 |
| CIM | O(|𝔇_ρ|) | O(|𝔇_ρ|) | Δ_cert 上界 sound |
| ADP | O(|hard| log |hard| + budget) | O(budget) | 增益估计不乐观 |
| RQL | O(recertify + ADP) | O(data) | 根因分类 sound、溯源闭合 |

**正确性定理（Data-Conditional Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `n_eff` 按设计效应折算且簇内相关 `ρ_intra` 可估；**(A30)** 用户测试任务权重覆盖部署分布，`cov_U ≥ 1-ε_U`；**(A31)** 证书膨胀 `Δ_cert` 可由 `U` 一致估计。
则对任意维度 `d`，以概率 `≥ 1-δ`：
```
ρ_deploy(d) ≥ ρ_𝔇(d) - Δ_cert(d)
            - sqrt( ln(2/δ) / (2·n_eff) )      # 有限样本估计误差
            - (1 - q_cov)                       # 覆盖不足导致的分布偏移
            - (1 - eco_U)                       # 测试生态有效性缺口
            - β_E - P(δ_a > Θ_a) - P(compat < θ_a)
```
当 `Δ_cert^+ ≤ Θ_Δ` 且 `Q(𝔇) ≥ θ_q, Q_U(U) ≥ θ_u` 时，数据条件证书 `J` 可部署；否则 `RQ` 必须触发补采或收窄动作域。
关键：**证书的可信度不可能高于其证据的可信度**；`ρ_𝔇` 再高，也必须先扣掉 `Δ_cert + (1-q_cov) + (1-eco_U)` 三项“证据折价”。

| 实验 | 指标 | 目标 |

| E164 有效样本量校准 | `n_eff` 预测 CI 覆盖率的 nominal coverage | 92%–98%（目标 95%） |

**消融**：去掉 DQP（用 n 代替 n_eff）、去掉 CIM（只看 ρ_𝔇）、去掉 UTE（不做用户测试）三组对照，验证“证据折价”三项各自贡献。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 用户测试代表性不足（只测好用户/好场景） | 高 | 分层抽样 + 任务权重 + 生态有效性审计 |
| `ρ_intra` 低估导致 `n_eff` 虚高 | 高 | 簇 bootstrap + 设计效应敏感性分析 |
| 覆盖度 `q_cov` 不可估（高维密度比） | 高 | 分类器两样本检验 + 保守下界 |
| Δ_cert 阈值 `Θ_Δ` 拍脑袋 | 中 | 按部署风险分级 + 历史失效率校准 |
| 主动补采陷入局部难区、加剧长尾偏置 | 中 | 探索项 + 分布匹配约束 + 红队任务 |
| 重资格循环震荡（补采→证书变→再补采） | 中 | 单调预算 + hysteresis + 收敛判据 |
| 用户测试成本高、周期长 | 中 | 序贯检验 + 代理用户模型预筛 + 小样本高信息任务 |

## 6. 本轮最大风险

**一句话**：把数据质量与用户测试提升为证书的证据层，虽然修补了第 54 轮“证书 sound 但证据可疑”的断层，却引入了**证据自指风险**——用户测试本身是被 `q_𝔇` 与 `u_U` 度量的数据，而 `Δ_cert` 的判定又依赖用户测试，一旦 `m_eff`、`q_cov`、`eco_U` 被系统性低估或高估，整条“证据折价”公式可能变成把偏差洗白的合法化装置；因此必须以**独立双盲用户测试 + 簇 bootstrap 下界 + 第三方证据审计**做硬约束，宁可承认证书“证据不足、暂不可部署”，也绝不让一个漂亮但自证的 Δ_cert 成为上线通行证。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（DQP×DTC×UTE×CIM×ADP×RQL×EAC）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书 J」之下再垫一层**证据层 𝔼**，把证书从 `C` 改写为 `C(𝔇)`，新增七大算子：
> - **DQP（Data Quality Profiling）**：数据集质量剖面 `q_𝔇`，木桶标量 `Q(𝔇)`；
> - **DTC（Data Trust Certificate）**：有效样本量 `n_eff` + 溯源链的数据可信证书 `D_cert`；
> - **UTE（User Test Evidence Integral）**：用户测试作为带偏差/方差的外部证据积分 `UTE`；
> - **CIM（Certificate Inflation Monitor）**：证书膨胀 `Δ_cert` 与置信上界 `Δ_cert^+`；
> - **ADP（Active Data Procurement）**：质量加权主动补采，买证书精度而非堆样本量；
> - **RQL（Requalification Loop）**：数据→证书→用户测试→重资格的闭环；
> - **EAC（Evidence Audit Chain）**：证据溯源与第三方审计链，防自证。
>
> IP 编号：IP-121~IP-127（共 7 个新增）；升级 IP-118/120，使联合证书与迁移证书强制携带 `D_cert` 与 `Δ_cert^+`。

## 2. 关键算法 伪代码

### IP-121 DQP

```python
def data_quality_profile(dataset, deploy_ref, task_ref, tau_fresh):
    q_cov  = coverage_score(dataset, deploy_ref)          # 1 - sup density deficit
    q_bal  = 1 - total_variation(label_dist(dataset), label_dist(task_ref))
    q_agr  = (fleiss_kappa(dataset.annotation)
              if dataset.multirater else krippendorff_alpha(dataset.annotation))
    q_fresh = math.exp(-time_since(dataset) / tau_fresh)
    q_gap  = 1 - sim_real_gap(dataset, deploy_ref)
    q = dict(cov=q_cov, bal=q_bal, agr=q_agr, fresh=q_fresh, gap=q_gap)
    q["Q"] = min(q.values())                              # 木桶原则
    return q

def effective_n(n, cluster_sizes, rho_intra):
    k = mean(cluster_sizes)                               # 平均簇大小
    return n / (1 + (k - 1) * rho_intra)                  # 设计效应
```

### IP-122 DTC

```python
def data_trust_certificate(dataset, deploy_ref, task_ref, delta=0.05):
    q     = data_quality_profile(dataset, deploy_ref, task_ref, TAU_FRESH)
    n_eff = effective_n(len(dataset), dataset.cluster_sizes, dataset.rho_intra)
    p_drift = mmd_test(dataset, deploy_ref)               # 分布漂移见证
    prov  = provenance_chain(dataset)                     # 采集→清洗→标注→版本
    D = DTC(q=q, n_eff=n_eff, provenance=prov,
            drift_witness=p_drift, alpha=delta)
    D.trust = monotone_trust(q["Q"], n_eff, p_drift)      # 对三者单调不减
    return D
```

### IP-123 UTE

```python
def user_test_evidence(U, task_weights, delta=0.05):
    p_succ = {t: wilson_interval(U.success[t]) for t in U.tasks}
    ute    = sum(task_weights[t] * p_succ[t].mean for t in U.tasks)
    m_eff  = effective_n(len(U), U.session_sizes, U.rho_intra)
    u = dict(cov_U=U.task_coverage,
             m_eff=m_eff,
             kappa=cohen_or_fleiss_kappa(U.ratings),
             eco_U=U.ecological_overlap)
    u["Q_U"] = min(u["cov_U"], m_eff / required_power(U),
                   u["kappa"], u["eco_U"])
    ci = bootstrap_ci(U, task_weights, B=2000, alpha=delta)
    return UTE(score=ute, ci=ci, quality=u, n_eff=m_eff)
```

### IP-124 CIM

```python
def certificate_inflation(rho_D, rho_U, m_eff, delta=0.05):
    delta_cert = {d: abs(rho_D[d] - rho_U[d]) for d in rho_D}
    radius = math.sqrt((1 / (2 * max(m_eff, 1))) * math.log(2 / delta))
    delta_plus = max(delta_cert.values()) + 1.96 * radius
    return CIM(delta_cert=delta_cert, delta_plus=delta_plus,
               verdict=("invalid" if delta_plus > THETA_DELTA else "valid"))
```

### IP-125 ADP

```python
def active_data_procurement(pool, J, U, budget, pi_q):
    hard = []
    for tau in U.tasks:
        for a in tau.action_region:
            score = ((1 - J.q["cov"](a)) *
                     (1 - J.rho.get(a, 0.0)) *
                     U.fail_rate(tau, a))                 # 三重难区
            hard.append((score, tau, a))
    gains = []
    for score, tau, a in top_k(hard, budget):
        x = pi_q.acquire(tau, a)
        est_gain = expected_delta_cert_reduction(x, J)    # 悲观估计
        gains.append((est_gain / pi_q.cost(x), x))
    return select_under_budget(gains, budget)             # 含探索项
```

### IP-126 RQL

```python
def requalify(J, U, cert_model, data_pool, budget):
    cim = certificate_inflation(J.rho, U.rho, U.n_eff)
    if cim.verdict == "valid":
        return J
    root = explain_gap(J.rho, U.rho, U)                   # 复用第 53 轮 Explain
    if root.type == "data":
        new  = active_data_procurement(data_pool, J, U, budget, pi_q)
        J_new = recertify(cert_model, J.data + new)       # 重跑 ρ, α_S, J
    elif root.type == "action_shift":
        J_new = narrow_action_domain(J, root.actions)     # 收窄 A_core
    else:
        J_new = tighten_rho_min(J)                        # 保守部署
    J_new.provenance = J.provenance + [U, root, J_new.data.version]
    return J_new
```

### IP-127 EAC

```python
def evidence_audit_chain(J_hist, third_party_key):
    chain = []
    prev = GENESIS
    for J, U, action in J_hist:
        payload = hash_json({
            "data": J.data.version, "q": J.q, "n_eff": J.n_eff,
            "rho": J.rho, "U": U.summary, "action": action,
        })
        h = sha256(prev + payload).hexdigest()
        sig = sign(h, third_party_key)                    # 第三方审计签名
        chain.append(EvidenceBlock(prev=prev, hash=h, sig=sig,
                                   payload=payload))
        prev = h
    return EvidenceChain(chain, verified=verify_chain(chain))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DQP | O(n·\|Q\| + n log n) | O(\|Q\|·bins) | 覆盖/κ/漂移估计一致 |
| DTC | O(n + n_eff) | O(\|Q\| + \|prov\|) | `n_eff` 设计效应正确折算 |
| UTE | O(m·\|T\| + B·m) | O(m) | 任务权重归一、CI 精确覆盖 |
| CIM | O(\|𝔇_ρ\|) | O(\|𝔇_ρ\|) | `Δ_cert^+` 上界 sound |
| ADP | O(\|hard\| log\|hard\| + budget) | O(budget) | 增益悲观估计、预算闭合 |
| RQL | O(recertify + ADP) | O(data) | 根因分类 sound、溯源闭合 |
| EAC | O(\|J_hist\|) | O(\|J_hist\|) | 哈希链防篡改、签名可验证 |

**正确性定理（Data-Conditional Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `n_eff` 按设计效应折算且 `ρ_intra` 可估；**(A30)** 用户测试任务权重覆盖部署分布，`cov_U ≥ 1-ε_U`；**(A31)** `Δ_cert` 可由 `U` 一致估计。
则对任意维度 `d`，以概率 `≥ 1-δ`：
```
ρ_deploy(d) ≥ ρ_𝔇(d)
            - Δ_cert(d)                            # 认证-外部证据差
            - sqrt( ln(2/δ) / (2·n_eff) )          # 有限样本误差
            - (1 - q_cov)                           # 覆盖缺口导致的分布偏移
            - (1 - eco_U)                           # 测试生态有效性缺口
            - β_E - P(δ_a > Θ_a) - P(compat < θ_a)
```
部署判据：
```
valid(J) ⇔ sound(J|𝔇) ∧ Q(𝔇)≥θ_q ∧ Q_U(U)≥θ_u ∧ Δ_cert^+≤Θ_Δ
```
**推论（证据折价）**：证书可信度不超过证据可信度；`ρ_𝔇` 必须先扣除 `Δ_cert + (1-q_cov) + (1-eco_U)` 三项，才可与第 54 轮的动作/鲁棒性预算相加。

## 6. 本轮最大风险

**一句话**：把数据质量与用户测试提升为证书的证据层，虽然修补了第 54 轮“证书 sound 但证据可疑”的断层，却引入了**证据自指风险**——用户测试本身是被 `q_𝔇` 与 `u_U` 度量的数据，而 `Δ_cert` 的判定又依赖用户测试，一旦 `m_eff`、`q_cov`、`eco_U` 被系统性低估或高估，整条“证据折价”公式可能变成把偏差洗白的合法化装置；因此必须以**独立双盲用户测试 + 簇 bootstrap 下界 + 第三方证据审计（EAC）**做硬约束，宁可承认证书“证据不足、暂不可部署”，也绝不让一个漂亮但自证的 Δ_cert 成为上线通行证。
