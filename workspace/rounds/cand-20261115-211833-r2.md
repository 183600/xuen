# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「隐私保护」×「虚实迁移」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**把隐私从「加密补丁」升级为「可耗尽的出域契约」，把虚实迁移从「离线常数 β」升级为「可证伪的共形证书」**。两个灵感各治 v9 一处软肋：隐私治「OTL/DA/ID 的学习回路无数据出域纪律」的合规债；虚实迁移治「β 是常数、信任域假设不可检验」的安全论证债。铁律：任一新组件失效 ⇒ 注入中立元，退回 v9（β 常数 + 本地学习 + Δ_dom 门控），严格等价，而非行为漂移。

## 0. 直觉与动机

**灵感 1（隐私保护 → 出域预算契约，而非加密补丁）**
直觉：机器人系统的隐私泄露点不在静态数据库，而在**学习回路**——OTL 更新阈值、DA-ML 更新域统计、ID 做消融归因，每一路都在把操作员情感、语音、轨迹蒸馏成梯度、统计量或“哪个模块重要”的元信息。成员推断、属性推断、梯度反演都从这里发生。因此隐私保护的正确形态不是“加一层 AES”，而是把**数据出域本身变成一等资源**：每个消费者端口声明 `(ε, δ)` 预算与出域数据类，出域前必须过隐私门并记账；预算会耗尽，耗尽即注入“不共享”中立元 `v^⊥_share`，系统退回本地学习。另一个关键区分：碰撞证据（M0 原始日志）不应为隐私而消失，而应**最小化出域、加密托管于本地**（安全托管），因为事故复盘不可让渡；隐私保护的是“人”（情感/语音/身份），不是“碰撞事实”。

**灵感 2（虚实迁移 → 可证伪的共形证书，而非更真的仿真）**
直觉：v9 的块证书 β 是离线标定的常数，且假设“信任域内前向模型误差 ≤ β”。但“检测到域偏移（Δ_dom）”不等于“虚实 gap 有界”；仿真训练的前向模型到真实世界的误差恰恰在接触/抓取切换处爆炸。正确姿势是：**用真实残差给 β 一个分布无关的有限样本覆盖保证**（共形预测），再用自适应共形（ACI）使域偏移下长期覆盖不崩；虚实迁移不是“把仿真模型搬过去”，而是“让仿真模型持续可证伪”——影子仿真 + 真实残差交换性检验 + 真实锚定回合。β 从常数变成随时间收缩/扩张的 `β(t)`。

**灵感合流（本轮真正的洞见）**
隐私保护让真实标定样本**变少且带噪**，共形区间因此变宽；这不是缺陷，而是**保守性的可计算来源**。把 DP 噪声显式计入 β 的膨胀项 `Δ_DP`，并让“预算耗尽/样本不足”单调地触发保守退化（β↑、K_eff↓），而不是静默自信。反之，若不做这一步，隐私就会成为**伪保证的温床**：系统用更少的真实数据，却声称同样的安全覆盖。本轮把这条张力形式化为“隐私饥饿单调性”（P16）。

## 1. 研究问题（轮次升级版）

- **Q1（私有共形证书）**：DP 噪声如何进入非一致性分数与分位数？覆盖保证如何从 `1−α` 折减为 `1−α−δ_priv`？联邦/安全聚合能否在 ε 约束下恢复样本效率，且不引入新的信任假设？
- **Q2（隐私预算契约）**：如何把 RDP 组合、出域门与 v9 的 MW/EDF/中立元统一？预算耗尽时的退化能否逐位等价 v9 的“本地学习”路径？安全关键日志的加密托管与出域最小化如何证明不破坏 M0？
- **Q3（虚实锚定与可证伪性）**：交换性假设在域偏移下失效时，如何检测并把证书退回 `β_global`？隐私饥饿导致的标定不足，如何单调转化为保守性（而非伪保证）？影子仿真的分歧能否作为“仿真被证伪”的充分证据？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 隐私预算契约律（Privacy Budget Contract, PBC）**
每个出域端口声明 `κ^priv_m=(D_m, ε_m, δ_m, T_m, Mech_m, v^⊥_share)`：允许的数据类、滑动窗口 `T_m` 内的 `(ε,δ)` 上限、机制与失效中立元。出域必须经隐私门并做 RDP 组合记账；`ε_remaining < ε_min` 或机制不可用 ⇒ 注入 `v^⊥_share`（不共享），退回本地学习。隐私操作全部在 5Hz/异步路径，**绝不进入 50Hz 硬环**。

**P14 共形虚实证书律（Conformal SimReal Certificate, C-SRC）**
前向模型误差不再用常数 β，而用单侧安全残差 `r_t=ĝ_pred−g_true` 的经验共形分位：`β(t)=max(0, q̂_{1−α}(r)+Δ_DP+β_starve)`。`q̂` 在真实校准样本上计算，`Δ_DP` 是隐私噪声导致的保守膨胀，`β_starve` 是样本不足的保守项。证书检查用 `ĝ_min−β(t) ≥ d_safe` 替代 v9 的 `ĝ_min−β ≥ d_safe`。

**P15 可证伪锚定律（Falsifiable Reality Anchor, FRA）**
维护影子仿真：从真实状态滚动 H 步，比较仿真预测与真实观测的分歧 `a_t`。用滑动窗口的交换性/漂移检验判断“标定集与当前残差是否同分布”；拒绝 ⇒ 证书作废、`β(t)←β_global`、`K_eff←1`，并请求真实锚定回合。锚定回合受隐私预算约束，但**“无法采集”只能增加保守性，不能维持旧覆盖声称**。

**P16 隐私饥饿单调律（Privacy-Starvation Monotonicity, PSM）**
定义有效标定样本量 `n_eff` 与饥饿度 `σ=max(0,1−n_eff/n_min)`。要求保守映射单调：`∂β/∂n_eff ≤ 0`、`∂K_eff/∂n_eff ≥ 0`，且 `σ=1` 时 `K_eff=1`、`β=β_max`（等价 v9 fallback）。任何“样本减少但证书不变”的实现都视为违反 P16。

## 3. 与基线的接口（如何退化）

- PBC 失效 / 预算耗尽 ⇒ 出域端口注入 `v^⊥_share`（不共享），本地训练照常，等价 v9 的本地学习；
- C-SRC 失效（样本不足 / 交换性拒绝 / 分位不可算）⇒ `β(t)←β_global`，`K_eff` 退回 v9 的 `Δ_dom` 门控；
- FRA 失效（影子仿真不可用 / 分歧检验不可信）⇒ 禁用仿真前馈，直接 `K_eff=1`，等价 v9 单步 fallback；
- 安全侧隐私机制失效（LDP 通道异常）⇒ 冻结该非安全学习端口，安全阈值改由本地原始数据重算，等价 v9；
- 全部失效 ⇒ 完整退回 v9 MetricVoiceGauge-ACMD ⇒ v8 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **隐私预算契约中间件**：把 `(ε,δ)` 做成 MW 的一等资源与中立元，出域即记账、耗尽即退化，把合规从“策略文件”变成“可执行代数”；
2. **私有共形虚实证书**：分布无关覆盖 + DP 膨胀项 + ACI 漂移恢复，替换 v9 的常数 β，使“虚实 gap”第一次有可检验的安全语义；
3. **可证伪虚实锚定**：影子仿真 + 残差交换性检验 + 真实锚定回合，把“相信仿真”变成“持续检验仿真”；
4. **隐私饥饿单调退化**：明确“样本少/噪声大 ⇒ 更保守”的可证方向，堵住“用更少数据声称更强安全”的伪保证；
5. **实验 E571–E590** 覆盖共形覆盖性、DP 膨胀、成员推断、联邦样本效率、域偏移恢复、预算耗尽、端到端与 8h 长跑。

## 5. 本轮最大风险

**一句话**：隐私预算与共形交换性假设会在域偏移时**同时失效**——真实标定样本因隐私无法出域、DP 噪声又抬高共形分位，系统可能把“标定不足”误判为“证书仍有效”，即「用更少的数据换取更强的安全声称」的隐私-安全伪保证。

**新增定义 540（隐私数据类与出域图 Privacy Egress Graph）**
数据按敏感度与安全角色分为四类：`D_safe`（M0 原始证据、碰撞轨迹、证书日志）、`D_affect`（语音、5 维情感 MetaWeight、操作员身份）、`D_rep`（梯度、隐表示、ID 归因向量）、`D_stat`（阈值、直方图、共形分位数）。出域图 `G=(V,E)`：`V` 为进程/机器人/云节点，`E⊆V×V×D` 标注机制与预算。**硬约束**：不存在标注 `D_safe` 的出域边；`D_safe` 只允许本地加密托管与哈希承诺出域。

**新增定义 541（隐私预算契约 Privacy Budget Contract）**
每出域端口 `m` 声明 `κ^priv_m=(D_m, ε_m, δ_m, T_m, Mech_m, v^⊥_share)`，要求在任意长度 `T_m` 的滑窗内 RDP 组合满足 `ε_total ≤ ε_m`。隐私门 `gate_m(x)`：
```
gate_m(x) = Mech_m(x)          若 ε_proj(ρ_m + ρ_step) ≤ ε_m
          = v^⊥_share          否则（预算耗尽/机制不可用）
```
记账用 RDP：`ρ_total ← compose(ρ_total, ρ_step)`，再按 `(ε,δ)` 转换判定。中立元满足聚合恒等：加权平均中权重为 0、直方图不计数、联邦分位聚合跳过该样本。

**新增定义 542（本地差分隐私情感通道 LDP Affect Channel）**
情感向量的出域版本为 `x̃=clip(x,−C,C)+η`，`η~Lap(0, 2C/ε_aff)`（或高斯机制），敏感度 `Δ_aff=2C`。**本地 ER 使用原始 `x`，`x̃` 只用于出域/联邦聚合**；因此 ER 行为与 v9 逐位一致，隐私只限制“别人能学到什么”。失效中立元 `v^⊥_dp` = 冻结出域通道。

**新增定义 543（私有共形虚实证书 Private Conformal SimReal Certificate）**
真实校准样本 `Z_i=(s_i,a_i,g_i)` 上的单侧残差 `r_i=ĝ_pred(s_i,a_i)−g_i`（`g` 取 clearance 等安全指标）。取 `q̂_{1−α}` 为 `{r_i}` 的 `⌈(n+1)(1−α)⌉` 次序统计量，则
```
β(t) = max(0, q̂_{1−α} + Δ_DP(ε,δ,n) + β_starve(n_eff))
```
证书检查改为 `ĝ_min − β(t) ≥ d_safe`。在交换性下 `P(g_new ≥ ĝ_pred−q̂) ≥ 1−α`；含 DP 噪声时覆盖折减见引理 89。

**新增定义 544（共形分位与隐私膨胀 Conformal Quantile & DP Inflation）**
若残差在出域前被局部加噪 `r̃=r+η`，则分位数在 `{r̃_i}` 上计算，并取
```
Δ_DP = b_η · ln(1/δ'),   b_η = 2C_r/ε_r（Laplace）
```
其中 `δ'` 为噪声尾概率预算。若改用 DP 直方图/指数机制直接发布分位，则 `Δ_DP=O(log|grid|/ε_r)`。膨胀项永远**只增不减**，禁止用“噪声抵消”解释掉保守性。

**新增定义 545（自适应共形与交换性检验 ACI & Exchangeability Monitor）**
设 `err_t=1{r_t>q̂_t}`，按 `α_{t+1}=clip(α_t+γ(α_0−err_t), α_min, α_max)` 更新，使长期覆盖在分布漂移下仍趋于 `1−α_0`（ACI）。同时维护参考窗口与最近窗口的残差分布检验（DP-MMD 或 DP 分位漂移）；在水平 `ζ` 拒绝“同分布” ⇒ 证书作废，`β←β_global`、`K_eff←1`，请求真实锚定回合。

**新增定义 546（影子仿真锚定 Shadow-Sim Reality Anchor）**
从真实状态 `s_t` 用仿真器滚动 `H` 步得 `ŝ_{t+1:t+H}`，与真实观测比较分歧
```
a_t = w_p·‖p̂−p‖ + w_g·|ĝ_sim−g_real| + w_c·1{接触状态不一致}
```
滑动窗口 `{a_t}` 上做漂移检验；若分歧中位数 `> τ_anchor` 或检验拒绝 ⇒ 判定“仿真被证伪”，证书作废并请求 `W_anchor` 个真实锚定回合（受 PBC 预算约束）。

**新增定义 547（隐私饥饿度与保守映射 Privacy Starvation & Conservatism Map）**
有效样本量 `n_eff = n·v̂_r²/(v̂_r²+σ_DP²)`（`v̂_r²` 为残差经验方差，`σ_DP²` 为注入噪声方差），饥饿度
```
σ = clip(1 − n_eff/n_min, 0, 1)
β_starve = σ·β_max,   K_starve = max(1, ⌊K_max·(1−σ)⌋)
K_eff = min(v9 的 K_eff, K_starve)
```
要求 `∂β/∂n_eff ≤ 0`、`∂K_eff/∂n_eff ≥ 0`；`σ=1` 时 `K=1, β=β_max`（等价 v9 单步 fallback）。

**新增定义 548（联邦共形聚合 Federated Conformal Aggregation）**
各机对本地残差做 DP 直方图 `h_j`（Laplace/高斯），经安全聚合得 `H=Σ_j h_j`（服务器只见总和），由 `H` 估计 `q̂_priv`。正确性要求各机分桶边界一致；隐私由每机本地 DP + 安全聚合共同保证，不额外假设中心可信。任一分片失败 ⇒ 该片注入 `v^⊥_share`，用剩余片重算（`n_eff` 相应下降，触发 P16 保守映射）。

**新增定义 549（隐私-安全-效用三元调度 PSU Allocator）**
把有限日预算按“覆盖增益/ε”分配：安全校准（C-SRC）> 安全相关归因（ID）> 域统计（DA-ML）> 情感出域（ER）。形式化为
```
max_{ε_i}  Σ_i U_i(ε_i)   s.t.  Σ_i ε_i ≤ ε_day,  覆盖约束 P(g≥ĝ−β) ≥ 1−α
```
其中 `U_i` 为该端口的效用（覆盖紧致度或任务收益）。**安全校准预算不可被情感/叙事端口挤占**（硬优先级）。

**新增定义 550（加密安全托管与回放等价 Encrypted Safety Escrow）**
`D_safe` 在本地以密钥加密存储，并维护哈希链承诺 `H_t=Hash(H_{t−1}‖ct_t)`。回放审计器只需承诺与加密包即可验证消息顺序与完整性（同输入逐位复现门控/退化序列），明文永不出域。密钥丢失视为 `D_safe` 不可用 ⇒ 仅影响事后审计，不影响在线安全闭环。

# IP-357 PrivacyBudgetBroker：出域门 + RDP 记账 + 中立元
class PrivacyBudgetBroker:
    def __init__(self, contracts, delta=1e-5):
        self.c = {m.name: m for m in contracts}     # 定义 541
        self.rdp = defaultdict(float)               # 各端口累计 rho
        self.audit = []

    def gate(self, m, value, rho_step, mech):
        c = self.c[m]
        eps_proj, _ = rdp_to_dp(self.rdp[m] + rho_step, c.delta)
        if eps_proj > c.eps_max or not mech.available():
            self.audit.append(("blocked", m, now_ms()))
            return c.neutral                        # v^⊥_share：不共享
        noisy = mech.apply(value, c)                # 机制只在出域前作用
        self.rdp[m] += rho_step
        self.audit.append(("egress", m, rho_step, now_ms()))
        return noisy


# IP-358 PrivateAffectChannel：LDP 只用于出域，本地 ER 用原值
class PrivateAffectChannel:
    def __init__(self, eps=0.5, clip=1.0):
        self.eps, self.clip = eps, clip

    def egress(self, x):
        x = np.clip(x, -self.clip, self.clip)       # 敏感度 2C
        b = 2.0 * self.clip / self.eps
        return x + np.random.laplace(0.0, b, x.shape)


# IP-359 ConformalSimRealCertifier：共形 β(t) + ACI + 饥饿保守映射
class ConformalSimRealCertifier:
    def __init__(self, F, alpha0=0.1, gamma=0.01, n_min=50,
                 beta_global=0.02, beta_max=0.10, K_max=10):
        self.F, self.alpha0, self.alpha, self.gamma = F, alpha0, alpha0, gamma
        self.n_min, self.beta_global, self.beta_max = n_min, beta_global, beta_max
        self.K_max = K_max
        self.buf = deque(maxlen=4096)               # 本地真实残差
        self.invalid = False

    def residual(self, s, a, g_true):
        return self.F.predict_clearance(s, a) - g_true

    def update(self, r, noise_var, delta_prime=1e-3, lap_scale=0.0):
        self.buf.append(r)
        n = len(self.buf)
        k = math.ceil((n + 1) * (1.0 - self.alpha))
        q = sorted(self.buf)[k - 1] if k <= n else math.inf
        d_dp = lap_scale * math.log(1.0 / delta_prime) if lap_scale > 0 else 0.0
        var = float(np.var(self.buf)) if n > 1 else 0.0
        n_eff = n * var / (var + noise_var) if (var + noise_var) > 0 else 0.0
        starve = min(1.0, max(0.0, 1.0 - n_eff / self.n_min))   # 定义 547
        beta = min(self.beta_max, max(0.0, q + d_dp) + starve * self.beta_max)
        K_cap = max(1, int(self.K_max * (1.0 - starve)))
        return beta, K_cap, starve

    def aci_step(self, covered):
        self.alpha += self.gamma * (self.alpha0 - (0.0 if covered else 1.0))
        self.alpha = float(np.clip(self.alpha, 1e-3, 0.5))

    def invalidate(self):                            # FRA 触发
        self.invalid = True

    def current(self, beta_global):
        return (beta_global, 1) if self.invalid else self.last_beta_K


# IP-360 RealityAnchor：影子仿真分歧 + 漂移检验
class RealityAnchor:
    def __init__(self, sim, certifier, H=3, tau_anchor=0.05, W=20):
        self.sim, self.certifier = sim, certifier
        self.H, self.tau_anchor, self.W = H, tau_anchor, W
        self.window = deque(maxlen=W)

    def divergence(self, s, real):
        pred = self.sim.rollout(s, self.H)
        return (0.6 * abs(pred.clearance - real.clearance)
                + 0.3 * np.linalg.norm(pred.pose - real.pose)
                + 0.1 * (pred.contact != real.contact))

    def step(self, s, real):
        self.window.append(self.divergence(s, real))
        if len(self.window) >= self.W and (
                np.median(self.window) > self.tau_anchor
                or drift_test(self.window)):
            self.certifier.invalidate()             # 仿真被证伪
            return "request_anchor_episodes"
        return "ok"

## 4. 推导

**引理 87（隐私-安全分离）** 若所有 M₀ 硬检查、`d_safe`、`τ_safe`、`dist(s,O)` 均由本地原始数据计算，且 DP/LDP 只作用于 `D_affect/D_rep/D_stat` 的出域副本，则任意 `(ε,δ)` 下的隐私噪声不改变 M₀ 判定与停车不变式，v9 引理 80–81 的安全结论原样成立。证明：M₀ 判据的输入不经过任何 `Mech_m`；隐私机制只改变“其他节点能学到的参数”，不改变本地证书验证所读的值。对于确实进入软阈值的私有统计量，部署期强制 `τ_i ∈ [τ_i^min, τ_i^max]` 的本地安全区间，并保留 v9 的 margin 复核；越界即回退 `β_global`。∎

**引理 88（共形覆盖）** 若校准样本与下一个样本可交换，`q̂` 为 `⌈(n+1)(1−α)⌉` 次序统计量，则 `P(r_new ≤ q̂) ≥ 1−α`。证明：标准 split-conformal 秩论证；`r_new` 在 `n+1` 个可交换分数中的秩均匀分布，`P(rank > ⌈(n+1)(1−α)⌉) ≤ α`。取 `β=q̂` 即得 `g_new ≥ ĝ_pred−β`。∎

**引理 89（私有共形膨胀）** 若出域残差为 `r̃=r+η`、`η` 独立对称且 `P(|η|≤b_η) ≥ 1−δ'`，则在 `{r̃_i}` 上算得的 `q̂_priv` 满足
```
P(r_new ≤ q̂_priv + b_η) ≥ 1 − α − δ'
```
证明：`P(r_new ≤ q̂_priv+b_η) ≥ P(r̃_new ≤ q̂_priv ∧ |η_new|≤b_η) ≥ P(r̃_new≤q̂_priv) − P(|η_new|>b_η) ≥ 1−α−δ'`（引理 88 + 联合界）。Laplace 机制取 `b_η=(2C_r/ε_r)ln(1/δ')`。∎

**引理 90（退化等价与饥饿单调）** (i) C-SRC 失效 ⇒ `β=β_global`、`K_eff=K_v9`，与 v9 逐位一致；(ii) PBC 耗尽 ⇒ 出域端口输出 `v^⊥_share`，本地学习路径不读取共享量，等价 v9；(iii) `n_eff` 下降时 `β_starve` 单调不减、`K_starve` 单调不增，`σ=1` 时 `K=1`，故不存在“证据变少而证书变强”的路径。证明：(i)(ii) 由定义 541/543 与 MW 中立元恒等性直接得到；(iii) 对 `n_eff` 求偏导：`∂β_starve/∂n_eff = −β_max/n_min ≤ 0`，`∂K_starve/∂n_eff = K_max/n_min ≥ 0`；`σ=1` 代入得 `K_starve=1`。∎

**引理 91（联邦聚合正确性与隐私）** 若各机分桶一致、安全聚合诚实执行“只发布总和”，则 `H=Σ_j h_j` 与中心化 DP 直方图的期望一致，分位估计误差由 `Σ_j` 的 Laplace 噪声方差与桶宽决定；任一诚实分片不泄露超过其本地 `(ε_j,δ_j)` 的信息。证明：安全聚合的加法掩码在至少一个诚实节点下统计不可区分；本地 DP 的后处理不变性保证聚合结果不增加单机泄露。分片缺失时 `n_eff` 下降，由引理 90(iii) 自动转保守。∎

**引理 92（锚定可证伪性）** 设影子分歧在漂移后中位数超过 `τ_anchor`，且检验在 `W` 个样本上的功效 `≥1−β_test`。则证书在漂移发生后至多 `W` 个锚定周期内被作废（`β←β_global, K←1`），不存在“仿真已失效但证书长期有效”的静默路径；隐私导致的锚定样本不足只会延长 `K=1` 的保守期，不会恢复旧 `β`。证明：由定义 546 的作废规则与定义 547 的单调映射；作废后 `β` 只能经新的真实校准样本下降，而样本不足使 `σ` 保持高位。∎
