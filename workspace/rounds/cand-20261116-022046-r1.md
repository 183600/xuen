# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「Gazebo」×「机器人」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**仿真只做否决者、具身写进证书、滞后用孪生残差补偿**。v9 的最大风险是"最需要安全的时刻证书最不可靠"：DA-ML 的 20 帧滑窗滞后，而前向模型误差恰在域偏移处最大化。Gazebo 提供与学习模型独立的物理预测，机器人提供形态与执行器约束。关键纪律：数字孪生**只能收紧、不能放行**；其超时/失效注入"无否决"中立元，严格退回 v9（引理 87/92）。

## 0. 直觉与动机

**灵感 1（Gazebo → 数字孪生影子守卫，GDSG）**
直觉：v9 的块证书是"学出来的自信"（LSTM-MPC 代理），Gazebo 则是"算出来的物理"。我们不需要仿真来决定动作，只需要让它**否决**那些学习模型过于乐观的候选块——一个只能投反对票的评审员，永远不会因为自己的偏见而让系统更危险。更关键的是：影子可以在不等待 20 帧分布统计的情况下，用**单步物理残差** r^G_t 发现动力学突变，正好插进 v9 的检测滞后窗口。影子在独立线程异步审计，不占 20ms 决策预算；晚到的否决仍可触发最近中止点，因此"单向"不牺牲实时性。

**灵感 2（机器人 → 具身条件证书，ECC）**
直觉：同一个"安全间隙"对 Fetch、Tiago、PR2 不是同一件事——轮距、臂展、最大减速度、反应延迟都不同。v9 的 d_brake(v) 把机器人当成同质质点。把具身描述子 θ 写进证书类型：停车不变式用执行器极限与扫掠体积计算，证书只在 Θ_cal 内有效；跨机器人共享必须使用 θ_max 保守包络。这样 Gazebo 的跨机器人实验就不再是"再调一组参数"，而是证书有效性的直接检验。

**灵感 3（Gazebo → 证书误差图册，CEA）**
直觉：β 不应是一个手调常数，而应是"场景 × 具身 × 域偏移"的可查表上界。离线用 Gazebo 随机化生成 (θ, scene, Δ_dom, risk_SLAM) 网格上的经验误差分位数，在线只做**单调插值**；未覆盖格点直接 β_max + K_eff=1。这把 β 从"假设"变成"预注册的覆盖声明"，同时为影子否决提供先验。

## 1. 研究问题（轮次升级版）

- **Q1（单向仿真增益）**：如何让独立物理仿真在不成为新单点故障的前提下，为学习型证书提供**可证明的单向安全增益**？即：影子失效时严格退回 v9，影子生效时只能收紧证书。
- **Q2（具身证书）**：具身参数如何进入证书与中止点，使跨机器人部署不产生"借来的安全"？θ 的保守包络与失效回退如何定义？
- **Q3（滞后补偿）**：在 DA-ML 检测滞后期间，如何用孪生单步残差构造保守信任域，并把"检测延迟上界"从 20 帧压到 1 个控制周期，同时保证无影子时逐位退回 v9？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 单向影子否决律（Shadow-Veto-Only, GDSG）**
数字孪生只拥有否决权：它只能增大 β、缩短 K、扩充中止点集 P，或拒绝候选块；**永远不能放行任何 v9 证书未放行的块**。影子的超时、崩溃、不可用、覆盖不足一律注入中立元 v_G^⊥="无否决"，此时系统逐位退回 v9（引理 92）。因此安全性不依赖仿真保真度，保真度只影响可用性（误否决率）。

**P14 具身条件证书律（Embodiment-Conditioned Certificate, ECC）**
每张证书以 θ=(r_sweep, b_max, τ_react, v_max, q_arm, m_payload) 定型。停车不变式 d_stop^θ(p) 使用执行器限制减速度、反应延迟与当前臂构型扫掠半径；证书仅在 Θ_cal 内有效；跨机器人共享用需求向量 δ(θ) 的分量上确界 θ_max 包络，θ 越界即 K_eff=1。

**P15 滞后补偿信任域律（Lag-Compensated Trust Domain, LCT）**
信任域与 β 不使用点估计 Δ_dom(t)，而使用单向上包络 Δ̃(t)=max(Δ_dom(t), γΔ̃(t−1), u_t·1)，其中 u_t 是孪生单步残差告警。取 γ ≥ τ_dom^{1/L_dom} 可保证一次告警让 Δ̃ 在整整 L_dom 个周期内不低于 τ_dom，直接覆盖 DA-ML 的 20 帧窗口。无影子时 γ=0、u≡0 ⇒ Δ̃=Δ_dom，逐位退回 v9。

## 3. 与基线的接口（如何退化）

- GDSG 超时/崩溃/不可用/δ_gap 越界 ⇒ v_G^⊥="无否决"，LCT γ=0、u≡0 ⇒ 严格 v9 证书与 K_eff（引理 92）；
- CEA 不可用或格点未覆盖 ⇒ β←β_max、K_eff←1（比 v9 更保守，最多退到 v8 粒度）；
- ECC 的 θ 越出 Θ_cal ⇒ θ←θ_max 保守包络，仍越界则 K_eff←1；
- v9 的 AC 失效 ⇒ K_eff←1（等价 v8 决策粒度）；
- v9 的 MW 失效 ⇒ v8 手写网关；ID 失效 ⇒ 全模块 active；
- v8 的 DA/SPR/Cal 失效 ⇒ 中立元注入，等价 v7；全失效 ⇒ v7 → v6。

## 4. 预期贡献

1. **单向影子否决**框架：把仿真从"权威"降级为"反证者"，用安全序（定义 549）证明 GEM 在任意影子失效下仍安全支配 v9，且仿真保真度只在可用性维度付费；
2. **具身条件证书**：把机器人形态与执行器极限写进停车不变式与证书类型，给出跨机器人 θ_max 包络与误用回退；
3. **滞后补偿信任域**：用孪生单步残差把域偏移检测延迟从 20 帧压到 1 周期，并给出 γ 的可证保持时间条件（引理 88）；
4. **证书误差图册**：离线 Gazebo 随机化把 β 变成带覆盖声明的查表上界，E571–E590 覆盖保真度、否决功效、跨具身、滞后桥接、饥饿可观测与真机 sim-to-real。

## 5. 本轮最大风险

**一句话**：单向设计让影子失效"安全但静默"——如果在线计算竞争使审计长期超时，系统会表面挂着数字孪生、实际逐位退回最脆弱的 v9 滞后证书；即"最危险的失败不是影子否决错了，而是影子根本没在否决却没人发现"。

## 1. 符号体系增量（定义 540–549）

**新增定义 540（具身描述子 EmbodimentDescriptor）** 机器人形态与执行器能力：
```
θ = (r_sweep, b_max, τ_react, v_max, q_arm, m_payload)
δ(θ) = (r_sweep, 1/b_max, τ_react, v_max, |q_arm|, m_payload)
θ' ⪯_θ θ  ⇔  δ(θ') ≤ δ(θ)（逐分量）
```
r_sweep(θ,q_p) 为臂构型 q_p 下的扫掠半径，b_max 为限制减速度，τ_react 为感知-执行反应延迟。Θ_cal 为已标定具身集合，θ_max 为 δ 的逐分量上确界（更小的 b_max、更大的延迟/半径——最苛刻）。

**新增定义 541（具身停车不变式 EmbodiedStopInvariant）** 前缀 p 合法当且仅当：
```
d_stop^θ(p) = v_p·τ_react(θ) + v_p²/(2·b_max(θ)) + r_sweep(θ, q_p) + d_safe
d_stop^θ(p) ≤ dist(s_p, O) − |traj_{p:K}|
```
当 θ=θ_ref=(0,b_ref,0,…) 时退化为 v9 定义 534。ECC 只接受满足上式的前缀为中止点。

**新增定义 542（具身证书 EmbodiedCertificate）** 由冻结前向模型 F̂ 与图册共同给出：
```
ĝ_min^θ = min_{k≤K} F̂_clearance(s,a^{1:k}) − β_eff(θ,Δ̃,risk̃) − r_sweep(θ,q_k)
ê_max^θ = max_{k≤K} F̂_effort(s,a^{1:k}) + β_eff(θ,Δ̃,risk̃)
β_eff   = β_A(θ, scene, Δ̃, risk̃) + δ_gap
```
证书有效 ⇔ ĝ_min^θ ≥ d_safe ∧ ê_max^θ ≤ τ_eff ∧ γ̂_grasp^θ=valid ∧ δ(θ) ≤ δ(θ_cal)（具身定型）。δ_gap 为预注册的 sim-to-real 可观测偏差上界（E571 标定），**不是**可在线证明的量。

**新增定义 543（数字孪生影子与单步残差 DigitalTwinShadow）** 给定候选块 ζ 与状态 s_t：
```
ŷ^G = G_θ(s_t, a^{1:K}),   y^G_k = (g^G_k, e^G_k, s^G_k)
r^G_t = d_obs( φ(s_{t+1}), φ(G_θ(s_t, a_t)) )
u_t   = 1[ r^G_t > τ_res ]
```
G_θ 采用固定随机种子、确定性物理步长 Δt_G ≤ Δt/2。r^G_t 只用一步预测，50Hz 可负担；K 步滚动在独立线程异步执行（定义 548）。

**新增定义 544（否决谓词 ShadowVeto）** 三值而非二值，避免把"影子不知道"误当成"影子同意"：
```
V(ζ,s,θ) = VETO   若 min_k g^G_k < d_safe + r_sweep(θ,q_k) + δ_gap
                 ∨ max_k e^G_k > τ_eff
                 ∨ P^G = ∅
                 ∨ rollout 发散/数值异常
V(ζ,s,θ) = NEUTRAL 若超时、崩溃、不可用、或被饥饿
V(ζ,s,θ) = NO_VETO 否则
```
**NO_VETO 不等于 PERMIT**：它只表示"无反对"，候选块仍只享有 v9 证书提供的可信度。

**新增定义 545（收紧算子 TighteningOperator）** 对计划 π=(ζ,Ĉ,K,P)：
```
T_G(π) = 拒绝并按 K←max(1,⌊K/2⌋) 重生成（或 K=1 fallback）  若 VETO
       = (ζ, Ĉ, min(K,K_G), P ∪ P^G, max(β,β_A))            若 NO_VETO
       = π                                                   若 NEUTRAL
K_G = max{ k : min_{j≤k} g^G_j ≥ d_safe + r_sweep(θ,q_j) + δ_gap }
```
其中 K_G 是影子能背书的时域；P^G 是影子轨迹上的合法中止点。T_G 是**收缩（deflationary）**算子：输出在安全序下不超过输入。

**新增定义 546（滞后补偿信任域 LagCompensatedTrust）**
```
Δ̃(t)    = max( Δ_dom(t), γ·Δ̃(t−1), u_t·1 )
risk̃(t) = max( risk_SLAM(t), γ·risk̃(t−1), u_t·1 )
γ ∈ [ τ_dom^{1/L_dom}, 1 ),  L_dom = 20
```
信任域 Ũ_t = {Δ̃(t) < τ_dom ∧ risk̃(t) < τ_SLAM}；v9 的 K_eff 公式（定义 539）与 β 分箱改用 Δ̃/risk̃。无 GDSG 时 u_t≡0、γ=0 ⇒ Δ̃=Δ_dom、risk̃=risk_SLAM，逐位退回 v9。

**新增定义 547（证书误差图册 CertificateErrorAtlas）** 离线有限格点分解：
```
C = Θ_bin × Scene_bin × Δ̃_bin × risk̃_bin
β_A(c) = κ_safe · Quantile_{1−α}( { |F̂−G| 的 N 次 Gazebo 随机化滚动 } )
cov(c) = 1[ N ≥ N_min ∧ 置信区间半宽 ≤ w_max ]
β_A(θ,scene,Δ̃,risk̃) = β_max   若最近格点 ¬cov
```
β_A 在每个不确定维度上单调不减；在线只做查表/插值，不更新。N_min=200，α=0.01，κ_safe=1.2，w_max=0.1·β_max。

**新增定义 548（影子契约 ShadowContract）**
```
κ_G = (In=计划, Out=V, D_G=180ms, Ŵ_G≤150ms, v_G^⊥=NEUTRAL, π_G=低, φ^elig=false)
κ_R = (In=单步观测, Out=r^G, D_R=0.5ms, Ŵ_R≤0.3ms, v_R^⊥=0 ⇒ u≡0, φ^elig=false)
```
审计在 5Hz 块生成时提交、下一周期轮询，**不阻塞** 50Hz 执行；晚到的 VETO 仍触发最近中止点。连续 W_starve=5 次超时置 AUDIT_STARVED，并在日志中与 NO_VETO 严格区分。φ^elig=false：ID 永不蒸馏影子（与 P12 一致）。

**新增定义 549（安全序 SafetyOrder）** 对 π=(ζ,Ĉ,K,P)：
```
π ⪯_S π'  ⇔  β(π) ≥ β(π') ∧ K(π) ≤ K(π') ∧ P(π) ⊇ P(π') ∧ VetoSet(π) ⊇ VetoSet(π')
```
引理 87 证明 v9 的安全性对该序单调；引理 87 还证明 T_G(π) ⪯_S π 对任意影子结果成立。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8/v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变。
**定义 521（DA-OTL）** 继承 v9；τᵢ(t) 的复核同时使用 Δ̃/risk̃ 与 θ，块证书按定义 542 计算。
**升级定义 496（软证书，v10）** 触发条件改为六条件：
```
δ_trigger = { σ < τ_safe ∧ γ_grasp valid ∧ Δ̃ < τ_dom ∧ risk̃ < τ_SLAM
              ∧ Ĉ_t(θ) valid ∧ V(ζ) ≠ VETO }
```
NEUTRAL 不阻断 v9 路径（因为它就是 v9）；只有 VETO 立即触发 M₀ 硬检查或中止。
**升级定义 531（软硬约束衔接）** 中块守卫增加两条入口：残差告警 u_t=1 与晚到 VETO；任一成立 ⇒ 立即切换最近 p* ∈ P 或安全停驻，不等块边界。影子不改变 v9 守卫的其余逻辑。
**升级定义 533/534/539** 分别在 θ=θ_ref、无影子、γ=0 时逐项退化为 v9 原式（引理 92）。

## 3. 关键算法骨架

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Embodiment:
    r_sweep: float; b_max: float; tau_react: float
    v_max: float; q_arm: tuple; m_payload: float
    def demand(self):
        return (self.r_sweep, 1.0 / self.b_max, self.tau_react,
                self.v_max, abs(self.q_arm[0] - self.q_arm[1]), self.m_payload)
    def __le__(self, other):           # θ ⪯_θ other
        return all(a <= b for a, b in zip(self.demand(), other.demand()))

def d_stop(theta, v, q_p, d_safe):
    return (v * theta.tau_react + v * v / (2.0 * theta.b_max)
            + r_sweep(theta, q_p) + d_safe)


class CertificateErrorAtlas:                    # IP-358
    def __init__(self, beta_max, delta_gap):
        self.table, self.beta_max, self.delta_gap = {}, beta_max, delta_gap

    def lookup(self, theta, scene, delta_tilde, risk_tilde):
        c = self._cell(theta, scene, delta_tilde, risk_tilde)
        if not self.table.get(c, {}).get("covered", False):
            return self.beta_max          # 未覆盖 ⇒ 最保守
        return self.table[c]["beta_A"]    # 单调插值，不在线更新

    def beta_eff(self, *args):
        return self.lookup(*args) + self.delta_gap   # 定义 542


class EmbodimentConditionedCertifier:           # IP-359
    def __init__(self, theta_cal, atlas, d_safe):
        self.theta_cal, self.atlas, self.d_safe = theta_cal, atlas, d_safe

    def certify(self, F, state, chunk, theta, delta_tilde, risk_tilde):
        if not (theta <= self.theta_cal):           # 具身越界 ⇒ θ_max 包络
            theta = self.theta_cal
        beta = self.atlas.beta_eff(theta, state.scene, delta_tilde, risk_tilde)
        g_min = min(F.clearance(state, chunk.actions[:k]) for k in range(1, chunk.K + 1))
        g_min -= beta
        g_min -= max(r_sweep(theta, q) for q in chunk.arm_configs)
        if g_min < self.d_safe:
            return None
        pts = [p for p in range(1, chunk.K)
               if d_stop(theta, chunk.speed[p], chunk.arm_configs[p], self.d_safe)
                  <= chunk.clearance[p] - chunk.remaining_len(p)]
        return Certificate(g_min, beta, pts, theta)


class DigitalTwinShadowGuard:                   # IP-357
    NEUTRAL, NO_VETO, VETO = "neutral", "no_veto", "veto"

    def __init__(self, G, theta, D_G=180.0, wcet=150.0,
                 delta_gap=0.02, tau_res=0.01, d_safe=0.15, W_starve=5):
        self.G, self.theta, self.D_G, self.wcet = G, theta, D_G, wcet
        self.delta_gap, self.tau_res, self.d_safe = delta_gap, tau_res, d_safe
        self.W_starve, self.misses, self.available = W_starve, 0, True

    def residual(self, s, a, s_next):           # 50Hz，O(1)
        if not self.available:
            return 0.0
        return self.G.obs_dist(s_next, self.G.predict_next(s, a))

    def submit_audit(self, chunk, state):        # 非阻塞，5Hz
        if not self.available:
            return self.NEUTRAL
        self._pending = self.G.rollout_async(state, chunk.actions, self.theta)

    def poll(self):                              # 下一周期轮询
        if not self.available:
            return self.NEUTRAL
        traj = self._pending.try_get(self.D_G)
        if traj is None:                         # 超时/饥饿
            self.misses += 1
            if self.misses >= self.W_starve:
                log("AUDIT_STARVED"); self.available = False
            return self.NEUTRAL                  # 关键：超时=无否决=v9
        self.misses = 0
        if traj.diverged:
            return self.VETO
        if min(traj.g) < self.d_safe + r_sweep(self.theta, traj.q) + self.delta_gap:
            return self.VETO
        if max(traj.e) > traj.tau_eff or not traj.abort_points:
            return self.VETO
        return self.NO_VETO                      # 仅"无反对"，非"放行"


def tighten(plan, verdict, shadow_certified_K):  # 定义 545，收缩算子
    if verdict == DigitalTwinShadowGuard.VETO:
        return regenerate(plan, K=max(1, plan.K // 2))   # 或 K=1 fallback
    if verdict == DigitalTwinShadowGuard.NO_VETO:
        plan.K = min(plan.K, shadow_certified_K)
        plan.beta = max(plan.beta, plan.atlas_beta)       # 只增不减
    return plan                                            # NEUTRAL ⇒ v9


def update_trust(prev, delta_dom, risk_slam, u_t, gamma):
    d = max(delta_dom, gamma * prev[0], 1.0 if u_t else 0.0)
    r = max(risk_slam, gamma * prev[1], 1.0 if u_t else 0.0)
    return d, r
```

## 4. 推导

**引理 87（单向收紧的安全支配）** 设 v9 在证书 (β,K,P) 下满足引理 82 的安全条件。对任意影子结果 V∈{VETO,NO_VETO,NEUTRAL}，有 T_G(π) ⪯_S π，且引理 82 的安全结论对 (β'≥β, K'≤K, P'⊇P) 单调成立：β 增大使 ĝ_min 更保守；K 缩短使需覆盖的预测时域更短；P 扩大使可中止点更多。因此 T_G 的任何输出至少与 π 一样安全。特别地：NEUTRAL 返回原 π，逐位等于 v9；VETO 回退到 K=1 单步（v9 定义 533 的 fallback）；NO_VETO 只可能增大 β、缩短 K、扩充 P。**故 GEM 的安全性不依赖影子保真度 δ_gap；δ_gap 只影响可用性（误否决率）。** ∎

**引理 88（滞后桥接）** 设 L_dom=20、τ_dom∈(0,1)、γ ≥ τ_dom^{1/L_dom}。若某周期 u_t=1，则 Δ̃(t)=max(Δ_dom(t), γΔ̃(t−1), 1) = 1；对 0≤j≤L_dom 有 Δ̃(t+j) ≥ γ^j·1 ≥ γ^{L_dom} ≥ τ_dom。故信任域在至少 L_dom 个周期（400ms）内保持破坏，K_eff=1、β 处于高位，覆盖 DA-ML 从真实跳变到统计量越阈的整个窗口。孪生残差通道把检测延迟从 L_dom·Δt=400ms 降到 1·Δt=20ms。无影子时 γ=0、u≡0 ⇒ Δ̃=Δ_dom，逐位退回 v9。∎

**引理 89（具身证书单调性与跨机器人包络）** 若 δ(θ')≤δ(θ)，则 r_sweep^{θ'}≤r_sweep^θ、v·τ_react^{θ'}≤v·τ_react^θ、v²/(2b_max^{θ'})≤v²/(2b_max^θ)，于是 d_stop^{θ'}(p)≤d_stop^θ(p)：在 θ 下合法的 p 在 θ' 下仍合法，且 ĝ_min^{θ'}≥ĝ_min^θ（更小半径与 β 需求）。因此 θ_max（δ 的分量上确界）有效的证书对整个 Θ_cal 机队有效；对 θ 有效但 δ(θ')≰δ(θ) 的证书不得用于 θ'，必须重证或退到 θ_max / K_eff=1。∎

**引理 90（图册覆盖与 sim-to-real 裕度）** 对格点 c，若 cov(c)=1、β_A(c) ≥ κ_safe·sup_{i∈c}|F̂−G_i|，且预注册界 δ_gap ≥ sup_{i∈c}|G_i−F_i|（仅限证书使用的间隙/能耗/抓取可观测），则真实误差 |F̂−F| ≤ |F̂−G| + |G−F| ≤ β_eff=β_A+δ_gap，由引理 82 得证书保守有效。若 cov(c)=0，或在线残差监控发现 δ_gap 越界，则 β←β_max、K_eff←1，回到 v9/v8 安全路径。δ_gap 是不可在线证明的假设，只能由 E571/E584 的 HIL 实验预注册并持续监控。∎

**引理 91（审计时限、无 Zeno 与饥饿可观测）** 影子契约 D_G=180ms、Ŵ_G≤150ms，审计在独立线程、非决策关键路径；每块至多一次审计（5Hz），否决在块级锁存，不会同一块内反复翻转；残差监控 O(1) 50Hz。若连续 W_starve=5 次审计超时，AUDIT_STARVED 必被置位；日志中 NEUTRAL 与 NO_VETO 严格可区分（沿用引理 83 的日志可区分性），故"影子存在但静默失效"在日志层面不可伪装成"影子通过"。审计成功率因此是可观测的一等指标（E581）。∎

**引理 92（GEM→v9 的逐位退化）** 令 GDSG 输出 NEUTRAL（u≡0）、LCT 取 γ=0、CEA 返回 v9 的 β、ECC 取 θ=θ_ref（r_sweep=0、τ_react=0、b_max=b_ref）。则 Δ̃=Δ_dom、risk̃=risk_SLAM、d_stop^{θ_ref}=d_stop^{v9}、Ĉ^{θ_ref}=Ĉ^{v9}，T_G 为恒等，主闭环的证书、K_eff、P 与 δ_trigger 与 v9 逐位一致。故 v10 的退化链严格包含 v9，再由引理 83 退回 v8。∎
