# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「放置」×「视觉定位」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S` 与云边协同，但动作空间只回答了"能不能动"，没有回答"放得准不准、看不看得清"。本轮聚焦 **放置的几何容差、视觉定位的不确定性、以及二者的对偶与协同**。核心矛盾：H22：放置成功由"定位不确定集是否被放置容差流形包含"决定，名义位姿精度是糟糕的代理指标；H23：容差 `T` 与定位协方差 `Σ` 通过视角和场景结构耦合，只优化放置不优化可观测性会得到"看似精准、实则贴边"的脆弱放置；H24：部分放置动作是信息投资（放锚点、摆参照物），会改变未来的 `Σ`，使第 54 轮静态边权的技能组合图 `G_S` 失效。

## 0. 直觉与动机

**灵感 1（放置 = 容差流形的成员判定，而非坐标回归）**
直觉：把杯子放进杯垫，成功的判据不是"杯底中心与杯垫中心距离 < 1mm"，而是"整个接触构型落在一个允许的姿态带内"。杯垫越大、杯底越小，容差越宽。视觉定位给出的也不是一个点，而是一个误差椭球。于是放置是否成功，本质上是一个 **集合包含问题**：定位不确定集 `E` 是否被放置容差流形 `T` 包含，并且留有余量。名义精度再高，若误差椭球贴着 `T` 的边界，一次扰动就失败；反之误差稍大但 `T` 宽容，反而稳。这把"放置"从回归问题变成可行性判定问题。

**灵感 2（视角也是一种"放置"：可观测性进入可行域）**
直觉：同一个物体，正面近距离看深度误差小，侧面远距离看切向误差大。视点本身是被"放置"在空间中的一个资源。若把视点 `v` 也当作决策变量，则可行解不是 `p`，而是 `(p,v)`；定位协方差 `Σ_v(p)` 随 `v` 变化。由此得到 **可放-可观测联合域** `F = {(p,v) : p ∈ T ⊖ E_v(p)}`。放置规划应直接在 `F` 上搜索，而不是"先定位再放置"的串行流水线；这同时把主动视觉（active perception）纳入同一个优化目标。

**灵感 3（锚点放置 = 信息投资，打破静态边权）**
直觉：在桌面放一个已知尺寸的标定块、或先把某个物体摆正作为视觉基准，会显著降低后续定位的不确定性。这类动作当前不产生任务收益，却"购买"了未来的定位精度。把它形式化为 **定位资本** `K_loc = log det(FIM)`，则技能组合的边权应从静态 `c_trans` 变为 `c_trans - λ·ΔK_loc`，图的搜索空间变成 `(技能节点, K_loc)` 的乘积状态。第 54 轮的 `G_S` 在此被动态化，组合规划从最短路变为"资源受限最短路"。

**灵感 4（放置-验证-重放回环：用定位反过来验收放置）**
直觉：放完之后再"看一眼"，用视觉重新定位物体与承接物的相对位姿；若残余误差在某个自由度（常见是绕竖直轴的偏航）超限，则 `Explain` 给出越界自由度与修正量，执行微小的重放（reposition）。这把第 53 轮的 `Explain` 从"鲁棒性根因"扩展到"几何残差根因"，并把放置从开环执行变成闭环收敛。

**灵感 5（云边位姿契约与金字塔扩展）**
直觉：云端有全局语义与粗位姿 `p_c`，边端有新鲜视图与细定位 `p_e`。云端承诺"容差 `T_c` 与余量 `δ_c`"，边端必须在映射 `γ_pose` 后仍满足 `T_c ⊖ E_e`。若边端定位发现 `p_e` 落在容差边界之外，则回传"违反的自由度 + 建议重定位视点"。在第 54 轮动作金字塔 `𝔸` 之上叠加 **几何放置-定位层 `𝔾`**：`𝔾_0` 物理稳定极限，`𝔾_1` 放置容差流形，`𝔾_2` 视角-定位协方差，`𝔾_3` 云边位姿契约。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（放置容差流形）**
对物体 `o` 与承接物 `r`，稳定裕度函数 `s_{o,r} : SE(3) → ℝ` 由支撑多边形、质心投影、释放动力学与接触力闭合共同定义。容差流形
```
T_{o,r}(s_min) = { p ∈ SE(3) : s_{o,r}(p) ≥ s_min },
μ_{o,r}(p) = s_{o,r}(p) - s_min.
```
`μ` 为边界裕度，假设在 `∂T` 邻域内 `L_μ`-Lipschitz。`T` 允许**多连通**（例如正放与倒放都稳定），不假设凸性或单连通。

**定义 122（视觉定位不确定性域）**
定位器 `L : (I, v) → (p̂, E)`，其中 `I` 为图像、`v` 为视点。两种口径：
```
有界：     E_v(p)   = { p' : d_SE3(p', p) ≤ ε_v }
概率：     E_v^α(p) = { p' : log(p^{-1}p')^T Σ_v(p)^{-1} log(p^{-1}p') ≤ χ²_α }
```
`Σ_v(p)` 由视点、表面法向、纹理与遮挡决定，故 `E` 是 `v` 与 `p` 的函数，而非固定噪声。

**定义 123（认证放置 / 腐蚀包含）**
放置 `p̂` 在置信水平 `α` 下**认证可行**，当且仅当
```
p̂ ∈ T ⊖ E_v^α := { p : p·E_v^α(p) ⊆ T },
```
等价地 `β_place(p̂, v) := inf_{e∈E_v^α} μ(p̂·e) ≥ 0`。称 `β_place` 为**放置认证裕度**。有界口径下的充分条件：若 `||e|| ≤ ε_v` 且 `μ(p̂) ≥ L_μ·ε_v + δ`，则 `β_place ≥ δ`。

**定义 124（可放-可观测联合域）**
```
F_{o,r} = { (p, v) : p ∈ T_{o,r} ⊖ E_v^α(p), v ∈ V_rob },
```
`V_rob` 为机器人可达且无碰撞的视点集。放置规划目标为在 `F` 上最大化 `β_place`，同时满足时间预算 `Σ τ_view ≤ τ_task`。若 `F = ∅`，则任务不可认证，而非"尽力而为"。

**定义 125（定位资本与信息投资动作）**
设定位观测的 Fisher 信息矩阵 `FIM = Σ_i J_i^T Σ_i^{-1} J_i`，**定位资本**
```
K_loc = log det(FIM)   （或等价地用负熵）
```
放置动作 `a` 若改变锚点集 `A` 或参照物布局，则 `K_loc → K_loc + ΔK_loc(a)`。技能组合边权动态化为
```
c_dyn(S_i,S_j | K_loc) = c_trans(S_i,S_j) - λ·ΔK_loc(S_j | K_loc),
```
组合规划在乘积图 `G_S × 𝒦` 上求解，`𝒦` 为 `K_loc` 的离散化桶。信息投资动作的收益不确定，故须用风险敏感版本（见风险缓解）。

**定义 126（放置-定位联合证书与云边位姿契约）**
联合证书
```
J_place = (T, μ, Σ_v, v, β_place, ρ, α_S, evidence),
```
`ρ` 与 `α_S` 承接第 53/54 轮。云边位姿契约
```
C_pose = (p_c, T_c, δ_c, γ_pose, E_e, Explain_pose),
```
其中 `γ_pose : SE(3)_c → SE(3)_e` 满足 `dist(γ(p), γ(q)) ≤ L_g·dist(p,q)`。要求边端细化后 `β_place(p_e, v_e) ≥ δ_c`；否则 `Explain_pose` 回传违反的自由度与建议重定位视点。

## 2. 关键算法 伪代码

### IP-121 PTC（Placement Tolerance Characterization）

```python
def tolerance_manifold(obj, recep, sim, s_min, grid):
    T, mu = {}, {}
    for p in sample_se3(grid):
        if not collision_free(p, obj, recep):
            continue
        s = sim.stability(obj, recep, p)
        T[p] = (s >= s_min)
        mu[p] = s - s_min
    # 分量级保拓扑：不要用一个全局线性拟合抹平多连通结构
    comps = connected_components(T)
    lips = {c: fit_boundary_lipschitz(mu, c) for c in comps}
    return T, mu, comps, lips
```

### IP-122 CLP（Certified Localization-aware Placement）

```python
def certified_place(obj, recep, loc, viewpoints, T, mu, alpha, delta):
    best = None
    for v in viewpoints:
        p_hat, Sigma = loc.estimate(obj, v)
        E = uncertainty_set(p_hat, Sigma, alpha)
        beta = margin_inf(p_hat, E, mu)       # inf_{e in E} mu(p_hat * e)
        if containment_ok(p_hat, E, T) and beta >= delta:
            cand = (beta, v, p_hat, Sigma)
            best = cand if best is None or cand > best else best
    if best is not None:
        return ('certified', best)
    # 没有可认证视点：优先换视点，而不是硬放
    return ('reposition', suggest_viewpoint(T, mu, alpha, viewpoints))
```

### IP-123 APO（Anchor / Viewpoint Placement Optimization）

```python
def anchor_placement(candidates, FIM0, budget, task_dist, risk_lambda):
    A, FIM = set(), FIM0
    for _ in range(budget):
        def gain(a):
            dK = logdet(FIM + info(a)) - logdet(FIM)
            return dK - risk_lambda * uncertainty_of_gain(a) - cost(a, task_dist)
        best = max(candidates - A, key=gain)
        A.add(best)
        FIM = FIM + info(best)
    return A, logdet(FIM) - logdet(FIM0)      # Delta K_loc
```

### IP-124 PVR（Place-Verify-Reposition）

```python
def place_verify_reposition(plan, loc, execute, T, mu, max_iter=3):
    p = plan.p_hat
    for k in range(max_iter):
        execute(p)
        p2, Sigma = loc.relocalize(plan.obj, plan.v)
        E = uncertainty_set(p2, Sigma, plan.alpha)
        if containment_ok(p2, E, T) and margin_inf(p2, E, mu) >= plan.delta:
            return ('success', k, residual_evidence(p2, Sigma))
        dof, step = explain_pose(log_se3(inv(plan.p_target) @ p2))
        p = p @ exp_se3(damp(step))            # 阻尼，防重放震荡
    return ('fail', max_iter, explain_pose(log_se3(inv(plan.p_target) @ p2)))
```

### IP-125 UDC（Uncertainty-Duality Certificate）

```python
def place_localization_certificate(p_hat, E, T, mu, rho, alpha_s, delta):
    if not containment_ok(p_hat, E, T):
        return ('reject', 'not_eroded')
    beta = margin_inf(p_hat, E, mu)
    if beta < delta:
        return ('reject', 'margin', beta)
    return ('ok', JPlace(T, mu, E.sigma, E.view, beta, rho, alpha_s))
```

### IP-126 CEP（Cloud-Edge Pose Contract）

```python
def cloud_edge_pose_contract(p_c, T_c, gamma_pose, loc_e, delta_c):
    p_e, Sigma_e = loc_e.refine(p_c)
    drift = dist_se3(p_c, gamma_pose(p_e))
    if drift > delta_c:
        return ('reject', ExplainPose(dof=dominant_dof(drift),
                                      suggest=reselect_view(T_c)))
    E = uncertainty_set(p_e, Sigma_e, alpha=0.05)
    if not containment_ok(p_e, E, T_c):
        return ('reject', ExplainPose(dof=boundary_dof(p_e, T_c),
                                      suggest=reselect_view(T_c)))
    return ('ok', JPlace(T_c, margin_of(T_c), Sigma_e, p_e.view,
                         margin_inf(p_e, E, margin_of(T_c)), ...))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PTC | O(\|G_SE3\|·C_sim) | O(\|T\|) | 网格分辨率 + `μ` 的 Lipschitz 界 + 分量保拓扑 |
| CLP | O(\|V\|·(\|E\|+C_T)) | O(\|E\|) | `E` 校准、`T⊖E` 精确或保守外近似 |
| APO | O(budget·\|C\|) | O(\|C\|) | log-det 次模性（贪心 1-1/e） |
| PVR | O(max_iter·(T_exec+T_loc)) | O(1) | 阻尼收敛、重放有界 |
| UDC | O(\|E\|) | O(\|J_place\|) | 联合证书 sound、`δ` 闭合 |
| CEP | O(\|P\|·(\|E\|+1)) | O(\|V\|+\|E\|) | `γ_pose` Lipschitz、漂移界 |

**引理 1（腐蚀包含 ⇒ 稳定）**：若 `p_true = p̂·e` 且 `e ∈ E`，则 `p̂ ∈ T ⊖ E ⇒ p_true ∈ T ⇒ s(p_true) ≥ s_min`。

**引理 2（Lipschitz 充分条件）**：若 `μ` 在 `T` 邻域 `L_μ`-Lipschitz、有界误差 `||e|| ≤ ε`，则 `μ(p̂) ≥ L_μ·ε + δ ⇒ β_place ≥ δ`。故无需逐点枚举 `E`。

**定理（认证放置可靠性 / Tolerance-Uncertainty Duality）**
假设 **(A29)** `μ` 在 `∂T` 邻域 `L_μ`-Lipschitz；**(A30)** 定位误差以概率 `≥ 1-α` 落入 `E^α` 且 `Σ` 已校准；**(A31)** `T` 的估计误差不超过 `η_T`，且腐蚀按连通分量计算；**(A32)** `γ_pose` 为 `L_g`-Lipschitz 且云边漂移 `≤ Δ`。若规划在 `δ > η_T` 的裕度下通过认证，则对 `m` 步放置链：
```
P(全部稳定) ≥ 1 - Σ_{k=1}^m α_k - P(drift > Δ) - P(模型误差 > η_T) - β_E.
```
关键前提是 **`Σ` 校准 + `T` 完备 + 分量级腐蚀**；三者任一失效，证书即失去意义，而不是"稍微不准"。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 容差流形估计 | 预测 `T` 与真实稳定集 IoU / 边界裕度误差 | IoU ≥ 0.85，`μ` MAE ≤ 0.02 rad / 2mm |
| E163 认证放置有效性 | 认证通过条件下真实成功率 vs 名义位姿法 | 成功率 ≥ 98%，误认证 ≤ 2% |
| E164 主动视点选择 | `trace(Σ)` 与放置成功率提升 | `trace(Σ)` 降 ≥ 30%，成功率 +10% |
| E165 锚点信息投资 | 后续任务精度/成功率 vs 前期成本 | 净收益 ≥ 10% |
| E166 放置-验证-重放 | 首次成功率、平均重放次数、收敛率 | 重放 ≤ 2 次，成功率 ≥ 95% |
| E167 云边位姿漂移 | `drift` 分布、误拒率/漏拒率 | P95 ≤ 3mm / 0.5°，漏拒 ≤ 1% |

**消融**：去掉视点选择、去掉锚点投资、去掉分量级腐蚀、用名义位姿替代腐蚀包含，分别观察误认证率与真实成功率的裂口；该裂口是本轮最核心的可证伪信号。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 容差流形受仿真-现实差距影响 | 高 | 真机标定 + 保守腐蚀 + 模型误差膨胀 `η_T` |
| 定位协方差欠估（过度自信） | 高 | 共形预测 / χ² 校核 / 在线分布校验 |
| `T` 非凸、多连通导致腐蚀失效 | 高 | 分量级处理 + 拓扑证伪 + 边界主动采样 |
| 视点/锚点动作碰撞或干扰任务 | 中 | 可达视点约束 + 安全壳 + 动作预算 |
| 信息投资回报不确定 | 中 | 风险敏感 D-optimal + 预算上限 + 可回滚 |
| `Explain_pose` 重放震荡 | 中 | 阻尼 + 最大迭代 + 回滚锚点 |

## 6. 本轮最大风险

**一句话**：容差-不确定性对偶的 soundness **完全继承自定位不确定集 `E` 的校准性与容差流形 `T` 的完备性**；一旦 `Σ` 在真实场景被欠估（过度自信），或 `T` 在仿真中漏掉一个稳定连通分量，认证放置会把"误差椭球恰好贴边"的脆弱姿态判为安全，且多连通流形上的腐蚀条件不可微、易被局部采样掩盖，故必须以 **共形校准的 `E` + 分量级拓扑证伪 + 保守裕度膨胀** 三重护栏，宁可名义上多留 20% 余量，也不发布未标定的"认证放置"。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（PTC×CLP×APO×PVR×UDC×CEP）

> 承接第 54 轮产物 v31 动作-协同层。本轮增加 **放置容差流形、视觉定位不确定性、信息投资型放置、放置-验证闭环** 四大算子，把"动作可行"升级为"几何可认证"：
> - **PTC（Placement Tolerance Characterization）**：稳定裕度 `s`、容差流形 `T`、边界裕度 `μ`；

> - **APO（Anchor/Viewpoint Placement Optimization）**：视点与锚点作为决策，定位资本 `K_loc`；
> - **PVR（Place-Verify-Reposition）**：用视觉重定位验收放置，`Explain_pose` 回传自由度；
> - **UDC（Uncertainty-Duality Certificate）**：`J_place = (T,μ,Σ_v,v,β_place,ρ,α_S)`；
> - **CEP（Cloud-Edge Pose Contract）**：`γ_pose`、位姿漂移界、边端 `Explain_pose`。

| `F_{o,r}` | 可放-可观测联合域 `{(p,v): p∈T⊖E_v^α(p)}` |
| `K_loc` | 定位资本 `log det(FIM)` |
| `ΔK_loc(a)` | 信息投资动作带来的定位资本增量 |
| `c_dyn` | 定位资本条件下的动态组合边权 |
| `γ_pose` | 云边位姿映射 `SE(3)_c → SE(3)_e`，`L_g`-Lipschitz |
| `J_place` | 放置-定位联合证书 |
| `C_pose` | 云边位姿契约 `(p_c,T_c,δ_c,γ_pose,E_e,Explain_pose)` |

### IP-121 PTC

def tolerance_manifold(obj, recep, sim, s_min, grid):
    T, mu = {}, {}
    for p in sample_se3(grid):
        if not collision_free(p, obj, recep):
            continue
        s = sim.stability(obj, recep, p)
        T[p] = (s >= s_min)
        mu[p] = s - s_min
    comps = connected_components(T)           # 保留多连通结构

### IP-122 CLP

```python
def certified_place(obj, recep, loc, viewpoints, T, mu, alpha, delta):
    best = None
    for v in viewpoints:
        p_hat, Sigma = loc.estimate(obj, v)
        E = uncertainty_set(p_hat, Sigma, alpha)
        beta = margin_inf(p_hat, E, mu)
        if containment_ok(p_hat, E, T) and beta >= delta:
            cand = (beta, v, p_hat, Sigma)
            best = cand if best is None or cand > best else best
    if best is not None:
        return ('certified', best)
    return ('reposition', suggest_viewpoint(T, mu, alpha, viewpoints))
```

### IP-123 APO

```python
def anchor_placement(candidates, FIM0, budget, task_dist, risk_lambda):
    A, FIM = set(), FIM0
    for _ in range(budget):
        def gain(a):
            dK = logdet(FIM + info(a)) - logdet(FIM)
            return dK - risk_lambda * uncertainty_of_gain(a) - cost(a, task_dist)
        best = max(candidates - A, key=gain)
        A.add(best)
        FIM = FIM + info(best)
    return A, logdet(FIM) - logdet(FIM0)      # Delta K_loc
```

### IP-124 PVR

```python
def place_verify_reposition(plan, loc, execute, T, mu, max_iter=3):
    p = plan.p_hat
    for k in range(max_iter):
        execute(p)
        p2, Sigma = loc.relocalize(plan.obj, plan.v)
        E = uncertainty_set(p2, Sigma, plan.alpha)
        if containment_ok(p2, E, T) and margin_inf(p2, E, mu) >= plan.delta:
            return ('success', k, residual_evidence(p2, Sigma))
        dof, step = explain_pose(log_se3(inv(plan.p_target) @ p2))
        p = p @ exp_se3(damp(step))
    return ('fail', max_iter, explain_pose(log_se3(inv(plan.p_target) @ p2)))
```

def place_localization_certificate(p_hat, E, T, mu, rho, alpha_s, delta):

## 3. 关键推导

**引理 1（腐蚀包含 ⇒ 稳定）**
`p_true = p̂·e, e∈E`。若 `p̂ ∈ T⊖E = {p : p·E ⊆ T}`，则 `p_true ∈ T`，故 `s(p_true) ≥ s_min`。

**引理 2（Lipschitz 充分条件）**
`μ` 在 `T` 邻域 `L_μ`-Lipschitz，有界误差 `||e|| ≤ ε`：
```
μ(p̂·e) ≥ μ(p̂) - L_μ·||e|| ≥ μ(p̂) - L_μ·ε.
```
故 `μ(p̂) ≥ L_μ·ε + δ ⇒ β_place ≥ δ`，避免逐点枚举不确定集。

**引理 3（分量级腐蚀）**
若 `T = ⊔_j T_j`，则 `T⊖E = ⊔_j (T_j⊖E)`。证书须逐分量签发；跨分量的"平均裕度"无意义，因为分量之间可能被不可行姿态隔开。

**定理（认证放置可靠性 / Tolerance-Uncertainty Duality）**
假设第 54 轮 (A26)-(A28) 成立，并新增：**(A29)** `μ` 在 `∂T` 邻域 `L_μ`-Lipschitz；**(A30)** 定位误差以概率 `≥ 1-α` 落入 `E^α` 且 `Σ` 已校准；**(A31)** `T` 估计误差 `≤ η_T`，腐蚀按分量计算；**(A32)** `γ_pose` 为 `L_g`-Lipschitz 且云边漂移 `≤ Δ`。若 `m` 步放置链均在 `δ > η_T` 下认证通过，则
```
P(全部稳定) ≥ 1 - Σ_{k=1}^m α_k - P(drift > Δ) - P(模型误差 > η_T) - β_E.
```
证：引理 1 给出单步在给定 `E` 下的确定性稳定；对 `m` 步用联合界扣掉各步的 `α_k`；云边漂移与仿真-现实模型误差各扣一项；`β_E` 为第 53 轮已有的仿真证据误差项。

**推论（认证的边界）**：若 `Σ` 欠估或 `T` 漏分量，则 `E` 或 `T` 的集合本身出错，定理前提失效——此时"认证"不保证任何概率，且误差不可加性修正。认证系统的价值取决于**标定质量**，而非算法本身。

## 6. 本轮最大风险

**一句话**：容差-不确定性对偶的 soundness **完全继承自定位不确定集 `E` 的校准性与容差流形 `T` 的完备性**；一旦 `Σ` 在真实场景被欠估（过度自信），或 `T` 在仿真中漏掉一个稳定连通分量，认证放置会把"误差椭球恰好贴边"的脆弱姿态判为安全，且多连通流形上的腐蚀条件不可微、易被局部采样掩盖，故必须以 **共形校准的 `E` + 分量级拓扑证伪 + 保守裕度膨胀** 三重护栏，宁可名义上多留 20% 余量，也不发布未标定的"认证放置"。
