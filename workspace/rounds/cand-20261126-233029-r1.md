> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23（其上承 v22 的 PGEV/HDL/ACSC/DCSC/CFC++，v21 的语义-规范层 SDC/CAC/DCL/GIC，及 v20/v19/v18 全部模块与 IP-420–439）。
> 本轮纪律：**自主导航 = 位姿条件化 + 时程有效性 + 全局可达；触觉感知 = 无假设在场见证 + 证书可证伪 + 接触力硬安全底**。不推倒 v23：CESC/FSVC/IPAM/HPC-E+ 全部保留。本轮只做一件事：**给整套证书体系补上它一直缺失的两个闭环——空间-时程闭环（位姿漂移与长时程可达）与接触-证伪闭环（物理世界对证书的否证），把"开环签发、永不失效、不可否证"的证书升级为"位姿条件化、会过期、可被触觉证伪、在线只收紧、离线才学习"的闭环可证伪证书体系**。

## 0. 直觉与动机

**灵感 1（自主导航 → 证书必须"带着位姿与保质期签发"）**
直觉：此前所有证书都默认 `x` 精确已知，且在签发那一刻之后永远成立。但自主导航里，机器人靠 SLAM/里程计估计自身位姿 ξ，位姿误差随行进累积、随回环检测跳变；同一张"障碍在 0.8m 外"的证书，在十米外的位姿漂移后可能已错位数厘米，在回环闭合瞬间甚至整体平移。更要命的是：证书是"现在"签的，而计划是"未来"执行的——机器人到达路标 w_i 时，那张证书可能早已过期。核心创新：**位姿条件化证书 (Pose-Conditional Certificate, PUC) + 导航可达性证书 (Navigation Reachability Certificate, NRC)**。三条反直觉点：(1) 位姿不确定性必须**做进几何**而非事后加安全距离——用 SE(3) 雅可比把位姿协方差传播到世界系障碍框，得到随距离线性增长的杠杆臂膨胀 `ε_pose·(1+‖p‖/L₀)`（L₀=平移/旋转不确定度之比）；(2) 覆盖图要被位姿不确定性**腐蚀** `Cov ⊖ Σ_ξ`，位姿越飘、能签发缺席证书的自由空间越小；(3) 证书必须有**保质期** `τ_cert=(ε_max-ε_pose)/v_drift`，且导航必须保证"到达每个路标时那张证书仍然有效"——这是**时程组合**，不是快照组合。

**灵感 2（触觉感知 → 唯一"无假设"的在场见证与证书否证器）**
直觉：此前 AbsCert 的全部可靠性押在检测器召回率下界 κ_c 这一经验假设上——这正是上一轮点名的"合规的缺席幻觉"。触觉（接触 + 近场预触）是整套感知链里**唯一不依赖召回率假设**的模态：碰到了，就一定有东西在那里；预触皮肤在厘米级就感知到近场存在。它天然是 AbsCert 的**否证器 (falsifier)**：若某区域签发了缺席证书，随后在那里发生触觉事件，则该证书被物理世界直接否证。更关键的是——触觉的错误模式与视觉/激光**相互独立**（不受遮挡、光照、儿童/轮椅/逆光漏检影响），所以它是真正独立的冗余见证。核心创新：**触觉证伪证书 (Tactile Falsification Certificate, TFC) + 证伪驱动重校准 (Falsification-Driven Recalibration, FDR)**。三条反直觉点：(1) 触觉不是用来"避障"的（碰到已经晚了），而是用来**否证证书、强制降级 κ̂_c、并做接触力硬安全底**；(2) 在线触觉只能**收紧**（撤销 AbsCert、加障碍、降 κ̂_c、限力），绝不在线放宽——学习被隔离到离线；(3) 触觉标签是**假设无关的 ground truth**，因而是校准检测器 ε_loc 与 κ_c 的最强锚点，但改善只能通过版本升级（v25）回来，不能在线赎回。

**三者如何统一（两个闭环咬合）**
自主导航补的是**空间-时程闭环**（位姿→几何→保质期→可达），触觉补的是**接触-证伪闭环**（执行→接触→否证→降级→离线重校准）。此前整条链是"感知→证书→执行"的**开环**，签出去的证书永不失效、不可否证——这在认识论上是教条。本轮把它闭合成"感知→证书→执行→接触→否证→（离线）重校准→新版本→证书"。共享状态扩展为 `ζ_cl = ζ_ce ∪ (b_t(ξ), Σ_ξ, τ_cert, epoch, G_NRC, tac_ledger, κ̂_c)`。统一准入门升级为 **HPC-F = HPC-E+ ∧ PUC ∧ NRC ∧ TFC-一致 ∧ 未过期 ∧ 无未决否证**。核心不变式：**在线只收紧、离线才学习**，故 `Exec_v24 ⊆ Exec_v23` 严格成立，且证书首次具备"可被物理世界否证"的性质。

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 位姿条件化证书律（Pose-Conditional Certificate）**
所有几何证书以位姿信念 `b_t(ξ)` 为条件签发：
- `CertBox_k^{⊕} = inflate(b_k, ε_loc(s_k) + ε_pose(t)·(1+‖p_k‖/L₀))`，其中 `ε_pose(t)=√λ_max(Σ_ξ)`，`L₀=ε_t/ε_r` 为平移/旋转不确定度之比；
- `Cov_t^{⊖} = erode(Cov_t, ε_pose(t))`，AbsCert 仅在腐蚀后的覆盖域内可签发；
- 证书携带纪元标签 `epoch(ξ)` 与保质期 `τ_cert=(ε_max-ε_pose(t₀))/v_drift`；
- 膨胀与腐蚀都只会使障碍更多、自由空间更少 ⇒ `Fil_pose` 只收缩。

**P44 时程有效与导航可达律（Temporal Validity & Reachability）**
计划 `π=(w_0..w_n, t_0..t_n)` 必须满足 NRC：`∀i, t_i ≤ t_issue(w_i)+τ_cert ∧ CertBox^{⊕}(w_i) 有效 ∧ E_res(t_i)≥E_fallback+E_margin ∧ ¬Deadlock(s_i)`，且 `w_n∈Goal ∨ w_n∈SafeFallback`。证书必须在"机器人到达该路标的时刻"有效，而非"签发时刻"。无证书路径 → 降级为最近安全态（保活性）；商状态图检测死锁/活锁 → 模式升级而非停机。

**P45 触觉证伪律（Tactile Falsification）**
触觉（接触 + 近场预触）是**无假设在场见证**：`Witness(e) ⇒ R_e 内存在实体`，置信 ≥1-β_tac，且与 κ_c 无关。任何与已签发 AbsCert 区域相交的 `Witness(e)`：
- 立即撤销该 AbsCert、记入证伪账本 (merkle)、触发限力/SafeStop；
- 将该类检测器的 `κ̂_c` **单调下调**（只会使未来 AbsCert 更难签发）；
- 触觉事件只会使 `Obs_t` 增加，绝不减少 ⇒ `Fil_tac` 在线只收缩。

**P46 学习隔离律（Learning Quarantine）**
在线阶段触觉只允许保守更新（撤销/加障碍/降 κ̂_c/限力）；任何可能**放宽**证书的统计改善（ε_loc↓、κ_c↑）只能在**离线**由 FDR 在触觉增强语料上重算，并经 CESC 原子切换（验签、双轨、回滚）作为**新版本** `v_next` 上线。故在线 `Exec_v24 ⊆ Exec_v23` 严格成立；改善以版本为粒度、全程可审计、可回滚。触觉主动探测仅在指定低力区 `f_probe ≪ f_safe` 内允许，用于打破证伪饥饿，且其接触仍受 TFC 力上限约束。

## 3. 与基线的接口（如何退化）

- 位姿估计失效（`Σ_ξ→∞`）⇒ `ε_pose→∞` ⇒ 所有 CertBox 膨胀至全域、Cov 腐蚀至空 ⇒ 全域保守、只走已认证区域 ⇒ ⊆ v23；
- 导航图不可解（NRC 失败）⇒ 降级最近安全态 ⇒ ⊆ v23；
- 触觉失效（传感器掉线）⇒ 无否证源，AbsCert 退回 v23 的 κ_c 假设 ⇒ 等价 v23（更危险但不变宽）；
- 回环跳变 ⇒ epoch 失效 ⇒ 强制重认证 ⇒ 短期收缩后恢复，绝不扩张；
- CESC 断联 ⇒ 离线模式冻结 `V_last`（引理 1）⇒ FDR 不生效，在线仍只收紧 ⇒ ⊆ v23；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。

## 4. 预期贡献

1. **位姿条件化证书**：首次把 SLAM 位姿协方差经 SE(3) 雅可比做进几何证书（含杠杆臂膨胀与覆盖腐蚀），并给出证书保质期 `τ_cert`，使"证书会过期"成为一等公民；
2. **导航可达性证书**：时程组合（到达时刻证书有效）而非快照组合，给出无证书路径的活性保持退化与死锁/活锁的模式升级检测；
3. **触觉证伪证书**：首次把触觉作为无假设在场见证与 AbsCert 的物理否证器，用独立错误模式封堵"合规的缺席幻觉"，并以接触力硬上限作为不可被任何证书覆盖的最后防线；
4. **证伪驱动重校准与学习隔离**：在线只收紧、离线才学习，把统计改善隔离到可审计、可回滚的版本升级（经 CESC），既打破经验假设的教条性又不破坏安全单调；
5. **闭环可证伪证书体系**：空间-时程闭环 + 接触-证伪闭环，使证书首次可被物理世界否证，`Exec_v24 ⊆ Exec_v23` 严格成立。

## 5. 本轮最大风险

**一句话**：触觉证伪只在"机器人实际到达过、且真的发生接触/预触"的稀疏区域提供迟到标签——越保守越不敢靠近、越不敢靠近越没有否证样本、越没有样本 κ_c 越无法被修正，形成"越安全越无知、越无知越保守"的**证伪饥饿死锁**；而位姿漂移又让同一张证书在长时程上"形式未过期、事实已错位"——闭环唯一的 ground truth 源（触觉）恰好是闭环自己最不愿触发的那个事件。

## 1. 关键算法骨架（在 IP-439 骨架上扩展）

```python
# ============================================================
# IP-440 Pose-Conditional Certificate Inflation (PCCI)
# ============================================================
@dataclass
class PoseBelief:
    xi_hat: np.ndarray      # (6,) SE(3) 切空间估计
    Sigma: np.ndarray       # (6,6) 协方差
    epoch: int
    t: float
    eps_t: float            # 平移不确定度分量
    eps_r: float            # 旋转不确定度分量

    def eps_pose(self) -> float:
        return float(math.sqrt(np.linalg.eigvalsh(self.Sigma).max()))

    def L0(self) -> float:
        return self.eps_t / max(self.eps_r, 1e-9)

    def eps_pose_at(self, dt: float, v_drift: float) -> float:
        return self.eps_pose() + v_drift * dt


class PoseConditionalCertificate:
    """把位姿协方差做进几何：膨胀障碍框、腐蚀覆盖域、签发保质期。"""
    def __init__(self, eps_loc_fn, eps_max: float, v_drift: float):
        self.eps_loc_fn = eps_loc_fn     # score -> 定位误差界（来自 v23 FSVC conformal）
        self.eps_max = eps_max           # 位姿误差上限（conformal 位姿标定）
        self.v_drift = v_drift

    def world_uncertainty(self, box, belief: PoseBelief) -> float:
        # 保守上界：三角不等式 + 旋转杠杆臂
        #   ‖δx_world‖ ≤ ‖δt‖ + ‖δθ‖·‖p‖
        #   取 ε_t=ε_pose, ε_r=ε_pose/L0  =>  ε_pose·(1+‖p‖/L0)
        p_norm = float(np.linalg.norm(box.center))
        lever = belief.eps_pose() * (1.0 + p_norm / belief.L0())
        return self.eps_loc_fn(box.score) + lever

    def inflate_box(self, box, belief: PoseBelief):
        return box.inflate(self.world_uncertainty(box, belief))

    def erode_coverage(self, cov_mask, belief: PoseBelief):
        # 只有整颗位姿不确定球都落在覆盖域内的点才可签发 AbsCert
        return morphology_erode(cov_mask, radius=belief.eps_pose())

    def ttl(self, belief: PoseBelief) -> float:
        remain = self.eps_max - belief.eps_pose()
        return 0.0 if remain <= 0 else remain / self.v_drift

    def certify(self, boxes, cov_mask, belief: PoseBelief) -> "PoseCertSet":
        certs = [self.inflate_box(b, belief) for b in boxes]
        cov = self.erode_coverage(cov_mask, belief)
        return PoseCertSet(boxes=certs, coverage=cov,
                           epoch=belief.epoch, ttl=self.ttl(belief))

# IP-441 Certificate Epoch & TTL Manager (CETM)
# ============================================================
class CertificateEpochManager:
    def __init__(self, delta_rc: float = 0.05, t_epoch_debounce: float = 0.3):
        self.epoch = 0
        self.delta_rc = delta_rc
        self.t_epoch_debounce = t_epoch_debounce
        self.last_epoch_change = -1e9
        self.live: dict[str, "Cert"] = {}

    def on_loop_closure(self, belief: PoseBelief, delta_xi: float, t_now: float):
        # 回环跳变超过阈值 => 旧证书几何内容相对世界已错位，纪元失效
        if delta_xi > self.delta_rc and t_now - self.last_epoch_change > self.t_epoch_debounce:
            self.epoch += 1
            self.last_epoch_change = t_now
            self.live.clear()            # 强制重认证（短期收缩，绝不扩张）

    def register(self, cert):
        self.live[cert.id] = cert

    def valid(self, cert, t_now: float) -> bool:
        return (cert.epoch == self.epoch) and (t_now <= cert.t_issue + cert.ttl)

# IP-442 Navigation Reachability Certificate (NRC)
# ============================================================
class NavigationReachability:
    def __init__(self, E_fallback, E_margin, cert_lookup):
        self.E_fallback = E_fallback
        self.E_margin = E_margin
        self.cert_lookup = cert_lookup   # region -> PoseCert / AbsCert

    def certify(self, waypoints, times, energy_at, quotient):
        # 时程组合：到达 w_i 的时刻 t_i，证书必须仍有效
        for w, t in zip(waypoints, times):
            c = self.cert_lookup(w)
            if c is None or not c.valid_at(t):
                return False, "expired"
            if energy_at(t) < self.E_fallback + self.E_margin:
                return False, "energy"
            if quotient.deadlocked(w):
                return False, "deadlock"
        last = waypoints[-1]
        if not (is_goal(last) or is_safe_fallback(last)):
            return False, "goal_unreachable"
        return True, "ok"

    def fallback_plan(self, safe_states, cert_lookup):
        # 无证书路径时不 SafeStop，退化为最近安全态（保活性）
        certified = [s for s in safe_states if cert_lookup(s) is not None
                     and cert_lookup(s).valid_at(now())]
        return nearest(certified, key=distance_from_current)

# IP-445 Tactile Exploration Scheduler (TES) — 打破证伪饥饿
# ============================================================
class TactileExplorationScheduler:
    def __init__(self, f_probe: float, kappa_min: float):
        self.f_probe = f_probe
        self.kappa_min = kappa_min

    def schedule(self, explore_zones, kappa_hat):
        # 仅在低力区（f_max ≤ f_probe）主动探测；优先补 κ̂ 缺口最大处
        cand = [z for z in explore_zones if z.f_max <= self.f_probe]
        if not cand:
            return None
        return max(cand, key=lambda z: (self.kappa_min - kappa_hat[z.cls])
                   * z.info_gain)

@dataclass
class HPCF:
    hpc_e_plus: "HPCEPlus"
    pcci: PoseConditionalCertificate
    cetm: CertificateEpochManager
    nrc: NavigationReachability
    tfc: TactileFalsificationCertificate

    def admits(self, plan, belief, certs, energy_at, quotient, tac_state) -> bool:
        # 1. v23 四证（物理接地/云边/少样本/IP）
        if not self.hpc_e_plus.admits(
                plan, plan.x, plan.v, plan.z, plan.E_res, plan.margin,
                plan.modules):
            return False
        # 2. 位姿条件化：所有障碍框按当前位姿膨胀，覆盖按位姿腐蚀
        if not self.pcci.plan_pose_ok(plan, belief, certs):
            return False
        # 3. 时程有效：到达每个路标时证书未过期、纪元一致
        if not all(self.cetm.valid(c, t) for c, t in plan.cert_time_pairs()):
            return False
        # 4. 导航可达（时程组合）
        ok, _ = self.nrc.certify(plan.waypoints, plan.times, energy_at, quotient)
        if not ok:
            return False
        # 5. 无未决否证：相关区域若存在未复核的触觉否证，暂停 AbsCert 特权
        if tac_state.open_falsification(plan.region):
            return False
        return True

# 端到端：闭环证书流水线（在线只收紧，离线才学习）
# ============================================================
class ClosedLoopCertificatePipeline(PerceptionComplianceEnergyPipeline):
    def __init__(self, config):
        super().__init__(config)
        self.pcci = PoseConditionalCertificate(config["eps_loc_fn"],
                                               config["eps_max"], config["v_drift"])
        self.cetm = CertificateEpochManager(config["delta_rc"])
        self.nrc = NavigationReachability(config["E_fallback"], config["E_margin"],
                                          config["cert_lookup"])
        self.tfc = TactileFalsificationCertificate(config["beta_tac"],
                                                   config["f_safe_fn"],
                                                   config["kappa_min"],
                                                   config["delta_kappa"],
                                                   config["ledger"])
        self.fdr = FalsificationDrivenRecalibrator(config["alpha"], config["delta"])
        self.tes = TactileExplorationScheduler(config["f_probe"], config["kappa_min"])
        self.hpc_f = HPCF(self.hpc_e_plus, self.pcci, self.cetm,
                          self.nrc, self.tfc)
        self.kappa_hat = dict(config["kappa_prior"])

    def step(self, sensor_data, cloud_update=None, tactile_events=()):
        # A. 触觉在线只收紧（不学习）
        for e in tactile_events:
            self.tfc.on_event(e, sensor_data["abs_certs"],
                              self.kappa_hat, self.cetm)
        # B. 位姿条件化证书 + 保质期
        belief = sensor_data["pose_belief"]
        certs = self.pcci.certify(sensor_data["detections"],
                                  sensor_data["coverage"], belief)
        # C. 回环纪元处理
        if sensor_data.get("loop_closure"):
            self.cetm.on_loop_closure(belief, sensor_data["delta_xi"], now())
        # D. 低力主动探测（打破证伪饥饿）
        probe = self.tes.schedule(sensor_data.get("explore_zones", []),
                                  self.kappa_hat)
        # E. 准入（HPC-F）
        admitted = self.hpc_f.admits(sensor_data["plan"], belief, certs,
                                     sensor_data["energy_at"],
                                     sensor_data["quotient"],
                                     sensor_data["tac_state"])
        # F. 离线：仅在云端可用时，把证伪账本交给 FDR 重校准 -> CESC 上线
        if cloud_update and sensor_data.get("allow_offline_recal"):
            upd = self.fdr.recalibrate(sensor_data["tac_ledger"],
                                       sensor_data["D_calib"],
                                       sensor_data["D_holdout"],
                                       self.kappa_hat)
            if upd is not None:
                self.cesc.receive_cloud_update(upd.to_version(), upd.artifacts)
        return admitted, {"certs": certs, "probe": probe,
                          "kappa_hat": dict(self.kappa_hat),
                          "epoch": self.cetm.epoch}
```

## 3. 正确性论证

### 引理 5（位姿膨胀的保守包含）
**陈述**：设定位误差 `‖δx_loc‖ ≤ ε_loc(s)` 以概率 ≥1-δ 成立，位姿误差 `‖δt‖≤ε_pose`、`‖δθ‖≤ε_pose/L₀` 以概率 ≥1-δ_pose 成立，则 `p* ∈ CertBox^{⊕}` 以概率 ≥1-δ-δ_pose 成立。

**证明**：
1. 世界点误差 `δx_w = δx_loc + δt + δθ × (Rp)`，三角不等式得 `‖δx_w‖ ≤ ε_loc + ‖δt‖ + ‖δθ‖·‖p‖`。
2. 代入 `‖δt‖≤ε_pose`、`‖δθ‖≤ε_pose/L₀`，得 `‖δx_w‖ ≤ ε_loc + ε_pose(1+‖p‖/L₀) = ε_k^{⊕}`。
3. 故以 `ε_k^{⊕}` 膨胀的框以 ≥1-(δ+δ_pose) 概率（并集界）包含真物。杠杆臂项对 `‖p‖` 线性增长，正好刻画"远处障碍受旋转误差影响更大"。
∎

### 引理 6（保质期的必要与充分）
**陈述**：若漂移界 `‖ξ(t)-ξ(t₀)‖ ≤ v_drift(t-t₀)` 成立，则当 `t-t₀ ≤ τ_cert=(ε_max-ε_pose(t₀))/v_drift` 时，证书假设的位姿误差上界 `ε_max` 仍成立；超过 `τ_cert` 证书保证失效。

**证明**：由漂移界 `ε_pose(t) ≤ ε_pose(t₀)+v_drift(t-t₀)`。若 `t-t₀≤τ_cert`，则 `ε_pose(t)≤ε_max`，conformal 位姿标定在 `ε_max` 处的 ≥1-α 覆盖仍成立，引理 5 的位姿项有效。反之 `t-t₀>τ_cert` 时 `ε_pose(t)>ε_max`，超出标定域，保证不再成立，必须重认证。∎

### 引理 7（触觉见证的假设无关性与独立否证）
**陈述**：在"区域无人"假设 `H₀` 下，触觉见证 `Witness(e)` 仅由假阳性产生，故 `P(Witness(e)|H₀) ≤ β_tac`；因此在 `Witness(e)` 观测下以显著性 `β_tac` 拒绝 `H₀`。该检验与检测器召回率 `κ_c` **无关**，且触觉错误机制（传感器噪声/碎屑/镜面）与检测器错误机制（遮挡/光照/异常体态漏检）相互独立。

**证明**：`H₀` 下无实体，`Witness(e)` 只能是接触/预触的假阳性，其上界为标定的 `β_tac`。AbsCert 的正确性依赖 `κ_c`（未漏检），而触觉不依赖任何召回假设，仅依赖传感器本身的 `β_tac`。因两类错误源在物理与统计上独立，触觉构成对 AbsCert 的**独立否证检验**，不会被 AbsCert 的覆盖假设"屏蔽"。∎

### 引理 8（在线保守单调 + 离线学习隔离）
**陈述**：在任意在线时刻，`Exec_v24 ⊆ Exec_v23`；所有统计改善仅经离线 FDR + CESC 原子切换以新版本上线，且该切换保持版本单调（引理 1）。

**证明**：
- `Fil_pose`：膨胀只增障碍、腐蚀只减覆盖、TTL 只删有效性 ⇒ 单调收缩；
- `Fil_nav`：NRC 只增加可达性约束 ⇒ 单调收缩；
- `Fil_tac`：触觉只增障碍、撤销 AbsCert、单调下调 `κ̂_c`、施加力上限 ⇒ 单调收缩；
- `FDR`：离线运行，结果经 CESC（验签、双轨、回滚）作为 `v_next` 上线，在线路径不调用任何放宽操作。
故在线 `Exec_v24 = Exec_v23 ∩ Fil_pose ∩ Fil_nav ∩ Fil_tac ⊆ Exec_v23`。∎

### 定理（HPC-F 闭环体系的安全—可证伪—活性）
**陈述**：对任意计划 π，`HPCF.admits(π)=True` 蕴含：
(1) **安全**：物理执行满足 v23 保证，且位姿条件化几何以 ≥1-δ-δ_pose 包含真物、接触力 ≤ f_safe；
(2) **可证伪**：若 π 使用的任一 AbsCert 事实为假，则在"被访问且发生接触/预触"的区域，触觉见证以每次暴露 ≥1-β_tac 的概率出现，出现即撤销证书并单调下调 `κ̂_c`，错误无法静默持续；
(3) **单调**：在线 `Exec_v24 ⊆ Exec_v23`，学习仅经离线版本切换；
(4) **活性**：NRC 无解时退化为最近安全态而非停机；已认证区域可继续运行；TES 低力探测与离线升级共同缓解证伪饥饿。

**证明**：(1) 由引理 5–6 与 TFC 力上限；(2) 由引理 7 与 `TFC.on_event` 的撤销/降级逻辑；(3) 由引理 8；(4) 由 `NRC.fallback_plan`、`TES.schedule` 与 CESC 版本节奏。∎

**注**（诚实的边界）：(2) 的保证限于"被访问且接触"的区域——这正是本轮最大风险的来源，见 §6。

## 6. 本轮最大风险（最终确认）

**一句话**：触觉证伪只在"机器人实际到达过、且真的发生接触/预触"的稀疏区域提供迟到标签——越保守越不敢靠近、越不敢靠近越没有否证样本、越没有样本 κ_c 越无法被修正，形成"越安全越无知、越无知越保守"的**证伪饥饿死锁**；而位姿漂移又让同一张证书在长时程上"形式未过期、事实已错位"——闭环唯一的 ground truth 源（触觉）恰好是闭环自己最不愿触发的那个事件。
