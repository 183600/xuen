# 第 1 轮（灵感驱动研究循环·新灵感三元组第 1 轮；本轮灵感：「决策规划」×「研究空白」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21+IP-425–430（SDC/CAC/DCL/GIC/HPC+/CFC+），其上承 v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）、v19 证书体系与 v17 感知链。
> 本轮纪律：**规划是证书的消费者，也是证据的生产者；研究空白不是免责声明，而是带支撑域、验证状态与决策相关性的一等可计算对象**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 全部保留。本轮只做一件事：**把 v21 的"证书事后过滤器"升级为"缺口感知的决策规划"——让规划器在证书下行动、并主动制造证据去关闭对它真正重要的空白；把 v21 最大风险（κ_c 全局经验假设）降级为带支撑域的局部断言**。

## 0. 直觉与动机

**灵感 1（决策规划 → 证书不是终点，而是规划器的输入与目标）**
直觉：v21 把证书当"事后过滤器"（HPC+ 准入门、DCL 计划过滤）。但真正决定安全的不是证书本身，而是**规划器如何在证书下行动**：它可以选择一条根本不需要 AbsCert 的绕行路线（用几何安全换掉对召回假设的依赖），也可以选择**主动去制造证据**（换个视角、降速多看几帧、靠近确认、请求手势），把"没证据"变成"有证据"。决策规划补上的正是这块：**证书条件化的信念空间规划 + 显式的信息行动**。关键反直觉点：**规划不只是消费安全，它还能生产安全**——覆盖不是传感器"给定"的，而是可以被规划出来的（主动覆盖 / next-best-view）；一个信息行动的价值，恰好等于它把某张证书从"失效"翻成"有效"后所解锁的活性。核心创新：**证书条件化信念规划器 (CCBP)** + **认知行动与研究价值规划 (VoR)** + **模型预测护盾 (MPS-G)**。

**灵感 2（研究空白 → 假设有支撑域，证书只在支撑域内有效）**
直觉：v21 的最大风险（κ_c 是经验假设）本质是一个**研究空白**：我们知道"检测器在常规成人上召回 ≥κ_c"，却不知道"在儿童/轮椅/蹲姿/强逆光下"。v21 把这条假设当**全局常量**，于是空白被静默地当成"已成立"。正确做法是把它降级为**带支撑域的局部断言**：每个证书挂一张**假设台账 (Assumption Ledger)**，每条假设有支撑域 D_a（人群×姿态×光照×距离×场景）、验证状态 s_a（已验证/部分/未验证）与依赖 DAG；证书只在 `Act(Cert) = ⋂_{a∈deps} D_a ∧ s_a=已验证` 上生效，域外自动失效、回落保守。于是"研究空白"变成可计算的**缺口前沿 (Gap Frontier)**：当前决策上下文里，哪些被依赖的假设尚未在该上下文被验证。再按**决策相关性**给缺口排序——只在"补上它就会改变当前计划"的地方付出保守或研究成本。关键反直觉点：**不是所有空白都值得填**；一个只影响从未经过区域的缺口，对当前决策价值为零。

**灵感 3（缺口分类 → 不同缺口对应不同决策响应）**
直觉：缺口不是同质的。**认知缺口 (epistemic)** 可靠数据/实验关闭（→ 信息行动）；**规范缺口 (specification)** 是规则库根本没覆盖的情形，运行期无法靠数据关闭（→ 必须 SafeStop + 规则修订请求）；**偶然缺口 (aleatoric)** 是已验证域内不可约的噪声（→ 只能靠鲁棒裕度界住，不能"研究掉"）。把三者混为一谈，是"用更多数据去解决一个其实是规范缺失的问题"这类系统性错误的根源。关键反直觉点：**有些空白永远不该被规划器"绕过"**——规范缺口若被信息行动掩盖，就会把"规则没写"伪装成"证据不足"，从而在审计上把一个真实的规范缺陷洗白成一次成功的感知努力。

**三者如何统一**
统一为 **v21 之上的"缺口感知决策规划层 (Gap-Aware Decision Planning Layer, GADPL)"**：AL 回答"这张证书凭什么成立、在哪成立"，GF 回答"当前决策撞上了哪些未验证假设、哪个最要紧"，CCBP+VoR+MPS-G 回答"在缺口下该怎么规划、何时该去研究、如何保证探索不破坏安全"，GL 回答"缺口如何被关闭并反哺证书"。共享状态扩展为 **ζ_plan = ζ_sem ∪ (A, s_A, G, b_cert, ED, r_log)**。统一准入门升级为 **HPC++ = (HPC+, Act(Cert), G_resolved)**：只有"几何 SAFE ∧ 规范允许 ∧ 负信息在其支撑域内有效 ∧ 所有被依赖假设在本地已声明"才进入快速执行；否则进入**缺口感知的保守/研究子策略**。安全继承 `Exec_v22 ⊆ Exec_v21`（同一信息态下），而**信息随闭环增长**，故 v22 的实测活性可以高于 v21 的被动活性——**研究在护盾之下是活性的单调来源**。

## 1. 研究问题（轮次升级版）

- **Q1（假设台账与支撑域）**：如何让每个证书机械地声明其假设依赖而不靠人工遗漏？支撑域如何表达、如何相交、如何在上下文漂移时快速求值？"未声明假设"该按开世界还是闭世界处理（残余风险预算 ρ_res 如何定）？假设失效如何触发证书级联失效而非静默沿用？

- **Q2（缺口前沿与决策相关性）**：缺口如何按"翻转该假设是否改变当前最优计划"排序（decision-relevant gap）？认知负债 ED 如何量化并与活性损失对齐？规范缺口如何与认知缺口区分，使信息行动无法把它"研究掉"？

- **Q3（缺口感知规划与探索安全）**：如何在有限的证书状态抽象上做信念规划而不爆算力（依赖 DAG 剪枝后 |W| 能压到多小）？信息行动如何被 v21 证书**逐动作**认证，使探索永不越界？护盾的悲观回退如何保证始终可行（fallback 的空集风险）？

- **Q4（研究闭环与单调性）**：运行期缺口如何转化为实验请求并回填支撑域？证书升级如何保证"只扩不缩"且不使既有安全论证失效？未入账的假设（未知未知）如何被异常看门狗捕获，而不是被默认成已验证？

## 2. 设计原则（在 P34–P36 基础上新增 P37–P39）

**P37 假设显式律（Assumption Explicitness）**
任何进入执行的证书必须携带假设台账条目与依赖 DAG，证书只在 `Act(Cert) = ⋂_{a∈deps(Cert)} {c ∈ D_a : s_a = 已验证}` 上生效。未声明假设**不得默认为已验证**：必须落入**残余风险预算 ρ_res**，并由异常看门狗监控；看门狗报警即降级为规范缺口处理（SafeStop/最保守）。假设失效沿 DAG **级联**使下游证书失效，绝不静默沿用。

**P38 缺口-决策相关律（Decision-Relevant Gap）**
保守与研究的投入只投向**决策相关缺口**：缺口按"翻转该假设是否改变当前计划"排序（相关性 R(a|b)）；相关性为零的缺口不付出额外保守、也不触发研究。缺口按类型响应：`G_epi → 信息行动（可关闭）`、`G_spec → SafeStop + 规则修订请求（运行期不可关闭）`、`G_ale → 鲁棒裕度（只能界住）`。**规范缺口不得由信息行动"解决"**。

**P39 探索护盾律（Shielded Epistemic Action）**
每个信息行动在执行前必须通过 v21 HPC+ 认证，且必须存在一条**悲观回退** π_pess；模型预测护盾保证乐观探索的任何一步都可即时退回悲观策略。信息只增不减，故支撑域单调扩张、可行集单调不缩；证书升级是**单调帕累托改进**（安全不降、活性不降）。

## 3. 与基线的接口（如何退化）

- **AL 缺失/损坏** ⇒ 所有证书按"无支撑域"处理 ⇒ 退回 v21 最保守模式（比 v21 更保守）；
- **GF 失效** ⇒ 无法区分缺口类型 ⇒ 一律按规范缺口处理 ⇒ SafeStop/最保守；
- **CCBP/VoR 失效** ⇒ 退回 v21 固定规划器（不再主动研究）⇒ 等价 v21；
- **MPS-G 失效** ⇒ 只执行悲观策略 ⇒ 等价 v21 保守模式；
- **GL 失效** ⇒ 不影响执行，只丢审计与升级闭环；
- **全部失效** ⇒ 完全回退 v21 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v19 ⊆ Exec_v18`（引理 168）。
- **安全继承**：AL 只收缩证书激活域、GF 只加保守/排序、CCBP 在 v21 可行集内选、VoR 的每个动作经 v21 认证、MPS-G 只切换不扩张。信息增长只会让更多 v21 证书在**同一信息态**下可用，故闭环轨迹逐点仍是 v21 可容许的。

## 4. 预期贡献

1. **假设台账**：把 v21 的全局经验假设 κ_c 降级为带支撑域 D_a 与验证状态 s_a 的局部断言，给出证书级联失效的形式化与"未声明假设"的残余风险处理；
2. **缺口前沿与决策相关缺口**：把"研究空白"变成可排序、可度量、可审计的一等对象，并区分认知/规范/偶然三类缺口及其不可互换的响应；
3. **证书条件化信念规划 + 信息行动**：把覆盖从"被动给定"变成"主动规划"，给出护盾下探索安全性的证明（每个信息行动先经 v21 认证）；
4. **"研究是活性的单调来源"**：在 `Exec_v22 ⊆ Exec_v21`（同信息态）下，闭环信息增长带来活性提升，打破 v21"保守性叠加导致活性坍缩"的宿命；
5. **研究闭环工程化**：缺口台账→实验请求→支撑域回填→证书升级→回归验证的可审计闭环，把"灵感驱动研究循环"本身变成系统的一个可回放部件；
6. **HPC++ 准入门与 v22 整体安全继承**，`Exec_v22 ⊆ Exec_v21` 闭环。

## 5. 本轮最大风险

**一句话**：假设台账只能登记"我们想得到的假设"——一个从未被写下的研究空白（未知未知）会被默认为已验证，缺口感知系统因此对"缺口的缺口"系统性失明，规划器会以最高置信度穿过它。

# IP-431 Assumption Ledger：证书只在假设支撑域内生效
class AssumptionLedger:
    def __init__(self, ledger):
        self.A = ledger            # a -> (D_a, s_a, deps)
        self.spec_gaps = set()     # 规范缺口（无规则覆盖，运行期不可关闭）

    def deps_closure(self, cert):
        return transitive_closure(cert.assumptions, self.A)

    def activate(self, cert, ctx):
        """Act(Cert) = 依赖假设在 ctx 上已验证的支撑域之交；任一缺失即失效"""
        doms = []
        for a in self.deps_closure(cert):
            D_a, s_a, _ = self.A[a]
            if s_a != "V" or ctx not in D_a:
                return None, f"ASSUMPTION_GAP:{a}"
            doms.append(D_a)
        return intersect_all(doms), "OK"

    def cascade(self, failed):
        """假设失效 → 依赖它的证书级联失效，绝不静默沿用"""
        return {c for c in self.certs if failed in self.deps_closure(c)}

    def undeclared_risk(self, cert):
        """未声明假设不默认已验证：记入残余风险预算，交由看门狗"""
        return ResidualRisk(cert, budget=RHO_RES)


# IP-432 Gap Frontier：缺口分类 + 决策相关性 + 认知负债
class GapFrontier:
    def __init__(self, ledger, planner):
        self.al = ledger
        self.planner = planner

    def gaps(self, ctx, certs):
        G = set()
        for c in certs:
            _, status = self.al.activate(c, ctx)
            if status != "OK":
                G.add(status.split(":")[1])
        return G

    def classify(self, a):
        if a in self.al.spec_gaps:
            return "G_spec"        # 规则缺失 → SafeStop，信息行动不得掩盖
        if self.al.is_aleatoric(a):
            return "G_ale"         # 不可约噪声 → 只能靠裕度界住
        return "G_epi"             # 数据/实验可关闭 → 信息行动

    def relevance(self, a, belief):
        """决策相关性：翻转 a 后最优计划价值的变化"""
        u0 = self.planner.value(belief)
        u1 = self.planner.value(flip(belief, a))
        return abs(u0 - u1)

    def epistemic_debt(self, belief, ctx):
        return sum(self.relevance(a, belief) * exposure(a, belief)
                   for a in self.gaps(ctx, belief.certs)
                   if not self.al.validated(a, ctx))

    def decision_relevant(self, gaps, belief):
        """只保留能改变当前计划的缺口，按 R 降序"""
        return sorted((g for g in gaps if self.relevance(g, belief) > EPS_R),
                      key=lambda g: -self.relevance(g, belief))


# IP-433 Certificate-Conditioned Belief Planner：有限证书世界上的双策略
class CertificateConditionedBeliefPlanner:
    def __init__(self, v21_planner, horizon=8):
        self.base = v21_planner
        self.H = horizon

    def solve(self, belief):
        # 只枚举"依赖假设有效/失效"的组合，按 DAG 剪枝后 m≤16
        worlds = enumerate_certificate_worlds(belief, self.base.ledger)
        pi_pess = self.base.plan(belief, mode="PESSIMISTIC", worlds=worlds)
        pi_task = self.base.plan(belief, mode="OPTIMISTIC", worlds=worlds)
        return PolicyPair(pi_pess, pi_task)

    def value(self, belief):
        return self.base.expected_return(belief)

                + gesture_request_actions(belief)
                + active_coverage_actions(belief))

    def vor(self, a_e, belief):
        """研究价值 = 决策相关期望信息增益（非相关缺口贡献为 0）"""
        return expected_decision_relevant_entropy_reduction(a_e, belief)

    def select(self, belief, gaps):
        best, best_v = None, self.eps
        for a_e in self.candidate_actions(belief):
            # 探索护盾：信息行动本身必须 v21 认证且存在悲观回退
            if not self.shield.fallback_feasible(belief, a_e):
                continue
            v = self.vor(a_e, belief)
            if v > best_v:
                best, best_v = a_e, v
        return best   # None ⇒ 不值得研究，改走悲观/绕行


# IP-435 Model-Predictive Shield：乐观动作前向检查悲观回退
class ModelPredictiveShield:
    def __init__(self, planner, v21_hpc, horizon=1):
        self.planner = planner
        self.hpc = v21_hpc
        self.H = horizon

    def fallback_feasible(self, belief, action):
        b2 = predict(belief, action)
        return (self.hpc.certifies(self.planner.pi_pess.action(b2))
                and self.planner.pi_pess.feasible(b2))

    def act(self, belief):
        a_opt = self.planner.pi_task.action(belief)
        if self.hpc.certifies(a_opt) and self.fallback_feasible(belief, a_opt):
            return a_opt
        return self.planner.pi_pess.action(belief)   # 悲观回退


# IP-436 Gap Ledger & Upgrade Loop：缺口→实验→支撑域回填→证书升级
class GapLedger:
    def __init__(self, ledger):
        self.log = []
        self.al = ledger

    def record(self, ctx, gap, gtype, response, outcome):
        self.log.append(dict(ctx=ctx, gap=gap, type=gtype,
                             response=response, outcome=outcome, t=now()))

    def to_experiment_requests(self):
        """反复出现且高决策相关性的认知缺口 → 实验请求"""
        return [g for g in group_by(self.log, "gap")
                if freq(g) >= F_MIN and max_relevance(g) >= R_MIN
                and type(g) == "G_epi"]

    def upgrade(self, gap, new_domain, evidence):
        """只在证据覆盖 new_domain 时扩支撑域：只扩不缩"""
        assert covers(evidence, new_domain)
        self.al.A[gap].D_a |= new_domain
        self.al.A[gap].s_a = "V"
        assert regression_tests_pass(self.al)   # 升级不得使既有论证失效

## 3. 推导

**引理 163（假设支撑域与激活单调性）** 证书激活域 `Act(Cert) = ⋂_{a∈deps} {c∈D_a : s_a=V}`。收缩任一 D_a、把 s_a 由 V 降级、或使某依赖假设失效，都只会缩小 Act(Cert)，绝不扩大。证书失效即回落 v21 的保守默认（AbsCert 无效 → 假设有人）。故证书集合随信息增长单调不减，可行集单调不缩。∎

**引理 164（缺口三分类响应的可靠性）** `G_epi` 只能被证据关闭；`G_spec` 在运行期不可被任何数据关闭，必须 SafeStop 升级；`G_ale` 不可被"研究掉"，只能靠鲁棒裕度界住。若把 `G_spec` 当 `G_epi` 用信息行动处理，则"规则未覆盖"会被伪装成"证据不足"，破坏审计可靠性。故响应映射必须按类型分派，且 `G_spec` 不得进入 VoR 候选。∎

**引理 165（护盾下的探索安全性）** 信息行动 a_e 执行前须经 v21 HPC+ 认证且 `fallback_feasible(b, a_e)`；悲观策略 π_pess 在"所有缺口恶化"世界安全；MPS-G 的一步前向检查保证任意乐观动作之后 π_pess 仍可行。故闭环轨迹逐点 ∈ v21 可容许集，乐观探索不会移除回退。∎

**引理 166（研究价值的决策相关性界）** `VoR(a_e) ≤` 决策相关熵减；仅对 `R(a|b) > EPS_R` 的缺口计算非零价值，非相关缺口贡献 0。故研究预算不会浪费在不影响当前计划的空白上（在相关性估计准确的条件下）。∎

**引理 167（信息单调性：研究是活性单调来源）** 若某假设 s_a 由 U/P 升到 V 或 D_a 扩张，则 Act(Cert) 单调扩张、可行集单调不缩，既有安全计划不失效。故证书升级是单调帕累托改进：安全不降、活性不降。结合引理 165，v22 在同信息态下 `Exec_v22 ⊆ Exec_v21`，而闭环信息增长只扩张后续可行集，故实测活性可高于 v21 的被动活性。∎

**引理 168（v22 整体安全继承）** 同一信息态下：AL 只收缩证书激活域（163）、GF 只加保守与排序（164）、CCBP 只在 v21 可行集内选择、VoR 的每个动作经 v21 认证（165）、MPS-G 只回退不扩张（165）。故 `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v19 ⊆ Exec_v18`。信息增长只扩张后续可行集，不改变路径逐点的 v21 可容许性。∎

## 7. 已知风险与失效模式

1. **未知未知（未入账假设）**（最大风险，见第 8 节）：假设台账只能登记已知假设；未声明的空白被默认成已验证。缓解：残余风险预算 ρ_res、异常看门狗（分布外检测、预测残差、行为异常）报警即降级为 `G_spec`、红队式对抗审计（E812）、定期台账增补。
2. **相关性估计偏差**：VoR/R(a|b) 估计不准会低估关键缺口、过度研究无关缺口。缓解：oracle 对齐（E806）、在线校准、保守下界。
3. **规范缺口被信息行动洗白**：把 `G_spec` 误判为 `G_epi` 会导致"用数据掩盖规则缺失"。缓解：类型分派硬门（引理 164）、`G_spec` 禁止进入 VoR（E814）。
4. **护盾回退空集**：极端场景下悲观策略无可行回退。缓解：回退集前置检查（E808）、收缩乐观域、最短视界兜底 SafeStop。
5. **算力与延迟**：信念规划 + VoR 可能挤占控制预算。缓解：证书世界 DAG 剪枝（m≤16）、规划 5–10Hz 事件化、控制路径只查护盾（E827）。
6. **研究闭环过拟合**：支撑域回填若只按已见样本扩张，会低估尾部。缓解：保守扩张、留出集、分布漂移监控（E819）、升级回归门禁（E817）。
7. **保守性叠加的活性坍缩**：AL+GF+护盾叠加可能过度保守。缓解：决策相关缺口只对"影响当前计划"的缺口付费，研究行动主动赎回活性（E809, E813）。

## 8. 本轮最大风险

**一句话**：假设台账只能登记"我们想得到的假设"——一个从未被写下的研究空白（未知未知）会被默认为已验证，缺口感知系统因此对"缺口的缺口"系统性失明，规划器会以最高置信度穿过它。
