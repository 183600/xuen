# 第 16 轮·V-LAM-Adapt：视觉-语言-动作自适应泛化框架

> 检索/复核日期：**2026-11-03（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本轮三个词是「视觉语言动作模型」「跨任务泛化」「无刷电机」。**不推倒**第 15 轮 ZEST-VLA，将其作为「执行者胜任力层」的底座，在此之上构建**跨任务自适应泛化框架**：用 VLAM 的跨模态特征推理，动态适配任务特征嵌入，约束无刷电机动力学，形成从「单任务专家」向「跨任务通才」的平滑跃迁。

## 0. 先给直觉：第 15 轮解决了「如何不信任」，本轮要解决「如何像一个懂所有任务的人一样思考」

第 15 轮的 ZEST-VLA 已经学会在零样本任务上「不自信地退后」。但如果把机器人想象成一个刚转业的机器人学员，它的问题不是「我会不会做错」，而是「我怎么知道这个任务要怎么做」——尤其当它从「抓杯子」直接跳转到「压按钮」时，VLA 的动作块可能在形式上平滑，却因为缺失了「按钮需要轻压」的先经验，陷入重复的「试错-被惩罚」循环。

> **直觉核心**：把「所有任务的经验」压成一个可迁移的「特征-动作-动力学约束」结构，用 VLAM 的视觉-语言共嵌接入 ZEST-VLA 的残差计算，借助无刷电机的动力学等式约束跨任务知识，从而在任务跳转时获得「正确的方向指引」，而不仅是「及时撤退」的保护。

### 视觉语言动作模型 = 3 条共嵌

- **视觉特征**：用双目视觉的对齐点匹配，提取「相对物体运动」的尺度无关特征；
- **语言特征**：用指令中的关键词/动作动词构建「语义动作原语」的稀疏指纹；
- **动作先验**：用历史经验中「同一原语在不同物体上的分布」建立「特征-动作核」，它是无刷电机可达性的先验。

### 跨任务泛化 = 动态自适应

传统 PT 或 LoRA 给模型一个「新任务提示词」，但它的控制空间会发生漂移。V-LAM-Adapt 引入「任务特征嵌入」`z_u`：一个在 128 维特征上维护的「任务上下文」，它随指令变化，却由 VLAM 的共嵌量化（quantize）给出。这样：

```
z_u = Σ_i w_i(v_i, l_i) · φ_i
```

其中 `v_i` 是视觉匹配分数、`l_i` 是语言匹配分数，`φ_i` 是该原语在经验库中的「动作核」。这个嵌入不改变 VLA 的权重；它只是在**残差计算前**把「当前任务应该如何动」的先验加进去。

### 无刷电机 = 动力学等式约束

G1 的七自由度臂靠三相无刷电机驱动。它们的运动满足：

```
τ = M(q) q̈ + C(q, q̇) q̇ + G(q) + τ_friction
```

其中 `τ_friction` 是不可逆的粘性摩擦。我们把这个约束写成「可执行动作的先验」：

> 在任何 5 步块结束时，若 commanded motion 违反惯性/摩擦边界，就算视觉上「对得上」，实际执行也会卡住。

于是我们在残差里加一个「动力学可行性」check：

```
r_dyn ≈ max(τ_commanded - τ_dynamically_feasible, 0)
```

这不是硬代码，而是用第 11 轮的 edit/slip 检测+关节电流观测，做一个「动力学残差」的上界估计。

### 合成想法

把 VLAM 的「特征-动作核」和 ZEST 的「执行残差」拼成一个双环：

1. **外环**：VLA 给出 30 步动作块；
2. **中环**：ZEST-VLA 计算残差，触发时退回几何原语；
3. **内环**：V-LAM-Adapt 把「当前指令对应的任务特征」映射到「几何原语的可达动作集合」；
4. **闭环**：当 ZEST 触发 FALLBACK 时，V-LAM-Adapt 计算「几何原语的任务特征是否匹配」，决定是「用最接近的已见原语」还是「干脆 HOLD」。

这样，跨任务的「先经验」不再是 VLA 权重里的一小块，而是跌跌撞撞的「几何原语语法」加上「特征匹配度」形成的软约束。

## 1. 形式化：从 VLAM 共嵌到任务特征约束

### 1.1 VLAM 架构草图

```
观测 o_t → VisionEncoder ψ_v → {v_k}  (k=1..K, 点匹配特征)
指令 u → LangEncoder ψ_l → {l_i}      (i=1..V, 动作动词指纹)

双目匹配得分：m_kij = cos(v_k^i, v_k^j) / (||v_k^i||·||v_k^j|| + ε)
语言匹配得分：n_il = cos(l_i, l_action) / (||l_i||·||l_action|| + ε)

特征池化：f_k = mean_j(m_kj)；f = [f_1,...,f_K, n_i1,...,n_iV]
```

### 1.2 任务特征嵌入

经验库 `ℰ = {(u^m, orig_primitive, q^m, τ^m)}` 包含历史任务。定义「动作核」：

```
φ_i = mean{(q - q_prev) | primitive = i in ℰ}    ∈ R^d
w_i(v,l) = softmax(n_il × exp(-λ_d·d_dyn(q)))     ∈ Δ^V
```

其中 `d_dyn(q)` 来自关节电流估计的动力学偏差。量化层把 `f` 投影到低维「任务特征」：

```
z_u = quantize(W_f · f + b_f)    ∈ {0,1}^d_z
z_u ∈ [0,1]^d_z    （Gumbel-softmax 软量化）
```

### 1.3 几何原语的可达动作集

给定 `z_u`，原语库 `prim_i` 的「可达集合」：

```
Γ_i(z_u) = {Δq | Δq = φ_i + ε,  ε ~ N(0, Σ_i),  w_i(v,l) > τ_w}
```

其中 `Σ_i` 来自该原语的历史轨迹协方差。若 `|w_i|` 过低，原语被降为「不可达」。

### 1.4 步进调度器

第 15 轮的 ZEST 仍负责信任门；但在 FALLBACK 模式时：

```
原语候选 = {i | dom_check(i) ∧ w_i > τ_w ∧ Γ_i(z_u) 可达}
若无候选：→ HOLD；
若单选 → FALLBACK_i；
若多选 → VoI = max_i {b_max · g_i · f_geo(p+δ) - c_i}
```

其中 `g_i = E[w_i]` 是该原语的「语言匹配经验」，`b_max` 继承 VOI-MAP。

## 3. 算法

### 3.1 主循环增量（在 ZEST 基础上）

```python
class VLAmAdaptPolicy(ZestPolicy):
    def __init__(self, calib_scores, experience_memory):
        super().__init__(calib_scores)
        self.ℰ = experience_memory           # {(u, prim, q, τ)}
        self.vlam = VLAMFeatureExtractor()
        self.φ, self.Σ, self.w_hist = self._build_primitive_kernels()
        self.q_z = 128                       # 量化维度

    def _build_primitive_kernels(self):
        kernels, vars, weights = {}, {}, {}
        for prim in primitives:
            trajs = [t.q for t in self.ℰ if t.prim == prim]
            if trajs:
                diffs = np.diff(trajs, axis=1)
                kernels[prim] = diffs.mean(axis=0)
                vars[prim] = np.cov(diffs.T)
                weights[prim] = np.mean([t.w_lang for t in self.ℰ if t.prim == prim])
            else:
                kernels[prim] = np.zeros(d_q)
                vars[prim] = np.eye(d_q) * 0.01
                weights[prim] = 0.1
        return kernels, vars, weights

    def get_zu(self, obs, instruction):
        v = self.vlam.vision_features(obs)
        l = self.vlam.lang_features(instruction)
        f = np.concatenate([v, l])
        z = self.vlam.quantize(f)           # Gumbel-softmax quantizer
        return z

    def fallback_candidates(self, z_u):
        candidates = []
        scores = self.vlam.match_primitives(z_u)    # w_i(v,l)
        for prim, w in scores.items():
            if w < self.τ_w:
                continue
            dom = domain_check(prim, self.M, self.phase)
            if dom != "geometric":
                continue
            Γ = self._action_set(prim, z_u)
            if len(Γ) > 0:
                candidates.append((prim, w, Γ))
        return candidates

    def select_action(self, obs):
        if self.mode == "TRUST":
            return super().select_action(obs)

        # FALLBACK mode: use V-LAM-Adapt
        z_u = self.get_zu(obs, self.instruction)
        candidates = self.fallback_candidates(z_u)
        if not candidates:
            return "HOLD"

        # Greedy VoI over candidates
        best = max(candidates, key=lambda c: self._voifallback(c[0], c[1]))
        self.current_fallback_prim = best[0]
        return f"FALLBACK_{best[0]}"

    def _voifallback(self, prim, w_match):
        g = self.g_prim.get(prim, 0.5) * w_match
        gain = self.b_max * g * (f_geo(self.progress + DELTA) - f_geo(self.progress))
        return gain / C_FALLBACK
```

### 3.2 VLAM 的残差计算增量

在 `compute_residuals` 后，若模式是 `FALLBACK_prim`，计算：

```python
def compute_fallback_residuals(obs0, obs1, prim, z_u):
    φ_pred = kernels[prim]
    τ_cmd = M(q1) - M(q0)
    τ_feas = dynamics_feasible(q0, q1)
    r_dyn = max(τ_cmd - τ_feas, 0)
    r_geo = norm(δx_obs - δx_cmd)
    r_match = 1 - w_match(prim, z_u)        # 逆匹配度
    return {"dyn": r_dyn, "geo": r_geo, "match": r_match}
```

### 3.3 动力学可行性估计

利用关节电流 `I_j` 估算剪力：

```
τ_est,j ≈ k_t · I_j
τ_friction,j ≈ b_f × sign(q̇_j) + b_v × q̇_j
```

若 `τ_cmd - τ_est + τ_friction > τ_margin`，记作 `r_dyn` 高。

## 4. 复杂度与计算 budgets

| 模块 | 复杂度 | 延迟（估计） |
|---|---|---|
| VLAM 视觉特征（224×224） | O(N_p N_k) | ~8 ms (移动核) |
| VLAM 语言特征 | O(|tokens| d) | ~2 ms (轻量 BERT) |
| 量化层 | O(d_f d_z) | <1 ms |
| 任务特征匹配 | O(V d_z) | <1 ms |
| 动力学残差 | O(d_q) | <0.5 ms |
| **总计增量** | — | **~12 ms** |

ZEST 的残差和 CUSUM 仍在 0.6 ms 内；VLAM 增量不进入关键路径（提前计算/缓存 `z_u`）。真机 p99 仍可能在 150ms 以内，除非 VLAM 过大——此时只保留「语言特征+量化」两支路。

## 5. 当前方案最大的风险

**分布漂移的特征嵌入**：如果新任务的视觉/语言分布显著偏离经验库（例如「把透明水龙头当成石灯泡」），`z_u` 可能映射到错误的「开关」原语，导致 FALLBACK 失败。这不是残差的问题，而是「特征先验」的问题；第 15 轮的 ZEST 无法检测，因为 FALLBACK 的动作在几何上「可行」——它只是在语义上错误。

## 2. 形式化

### 2.1 任务特征嵌入的定义

**定义 1（VLAM 共嵌）**：给定观测 `o` 和指令 `u`，定义视觉特征 `ψ_v(o) ∈ R^d_v`（8192 维 CNN 输出的点匹配池化），语言特征 `ψ_l(u) ∈ R^d_l`（轻量 BERT 的 [CLS]），以及交叉注意力匹配矩阵 `M ∈ R^{d_v × d_l}`。

**定义 2（任务特征）**：令 `z_u = Quantize(W·[ψ_v; ψ_l] + b)` 为 `d_z` 维离散嵌入。量化层用 Gumbel-softmax 实现软离散，使得梯度可穿透。

### 2.2 动作核

**定义 3（原语动作核）**：设经验库 `ℰ` 包含历史 `(u, prim_i, q_traj, τ)`。令

```
φ_i = 𝔼_{ℰ}[Δq | prim = i]
Σ_i = Cov_{ℰ}[Δq | prim = i]
w_i = 𝔼_{ℰ}[match_lang(u, prim_i)]
```

其中 `match_lang` 用指令中动作动词的 TF-IDF 向量与原语关键词匹配。

### 2.3 可达动作集合

**定义 4（Γ(z_u, prim_i)）**：

```
Γ_i(z_u) = {Δq ∈ R^d_q | Δq = φ_i + ε, ε ~ N(0, Σ_i),  sim(z_u, φ_i) > τ}
```

其中 `sim` 用余弦相似性。

### 2.4 动力学残差

**定义 5**：

```
r_dyn = max(τ_commanded - τ_estimated - τ_friction, 0)
```

其中 `τ_estimated` 用当前关节状态的惯性模型推算，`τ_friction` 用经验的粘性摩擦系数估计。

## 3. 算法

### 3.1 主流程（增量）

```
INIT:
  1. 加载 ZEST-VLA 权重
  2. 加载经验库 ℰ，构建 φ_i、Σ_i、w_i
  3. 校准阈值：q_α, τ_w, τ, τ_dyn

PER BLOCK:
  1. VLA 生成 30 步计划 → 按 5 步切片 → SERVO/LOOK/VLA/COMMIT
  2. ZEST 计算 s_b → 决定 TRUST/FALLBACK/HOLD
  3. 若 TRUST: 执行 ZEST 的动作
  4. 若 FALLBACK:
       a. 计算 z_u ← VLAM(obs, instruction)
       b. 计算可行原语候选 Γ_i(z_u)
       c. 选 VoI 最大者 → FALLBACK_prim
       d. 执行几何原语
  5. 计算残差：若 SERVO → 用 ZEST；若 FALLBACK_prim → 用 §3.2
  6. 更新 CUSUM，切换模式
```

### 3.2 FALLBACK 残差伪代码

```python
def compute_fallback_residuals(obs0, obs1, prim, z_u, M):
    φ_pred = φ[prim]
    dx_cmd = φ_pred @ M[prim]            # 通过 Jacobian 投到笛卡尔
    dx_obs = fk(obs1.q) - fk(obs0.q)
    r_geo = norm(dx_obs - dx_cmd) / (norm(dx_cmd) + EPS)

    r_dyn = compute_dyn_residual(obs0, obs1, φ_pred)
    r_match = 1.0 - cosine_sim(z_u, φ_pred)

    z_dyn = r_dyn / (σ_dyn + EPS)
    z_geo = r_geo / (σ_geo + EPS)
    z_match = r_match / (σ_match + EPS)

    s = w_dyn * z_dyn + w_geo * z_geo + w_match * z_match
    return s, {"dyn": r_dyn, "geo": r_geo, "match": r_match}
```

### 3.3 动力학残差计算

```python
def compute_dyn_residual(obs0, obs1, φ_cmd):
    q0, q1 = obs0.q, obs1.q
    q̇ = (q1 - q0) / dt
    τ_inertial = M(q0) @ (q1 - q0) / dt + C(q0, q̇) @ q̇ + G(q0)
    τ_fric_est = B_f * np.sign(q̇) + B_v * q̇
    τ_meas = k_t * obs1.currents           # 用电流反推电机力矩
    τ_feasible = τ_inertial + τ_fric_est
    r_dyn = max(np.linalg.norm(τ_meas - τ_feasible), 0)
    return r_dyn / (σ_dyn + 1e-3)
```

## 5. 风险与边界

| 风险 | 影响 | 缓解 |
|---|---|---|
| **特征嵌入分布漂移**（本轮最大风险） | 新任务的 z_u 映射到错误原语，FALLBACK 失败 | 量化层加入 KL 限制；若相似度低则 HOLD；G16 验证 |
| VLA 动作块不兼容 φ_i 的尺度 | FALLBACK 执行后仍偏差 | φ 核在 5 步块尺度上训练，或按比例缩放 |
| 电流测距误差 | r_dyn 误判 | 用滑动均值平滑；若连续 2 块都高，才触发 |
| 经验库偏差 | φ_i 代表旧任务，新任务差异大 | 定期用最新成功 episode 更新 ℰ（不写权重） |

## 6. 本轮最大的风险

**分布漂移的特征嵌入**：如果新任务的视觉/语言特征显著偏离经验库，`z_u` 可能错误地匹配到「错误的几何原语」，导致 FALLBACK 执行一个在形式上可行但在语义上错误的动作。这不是残差可检测的，因为动作在几何上「可达」——它只是在「目标错了」。ZEST 的 OOD-G 检测仍然失效，这需要额外的语义一致性检查。
