# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「检索增强生成」×「任务规划」）

> 第 65 轮把"可证伪"升级为"可归因"，其自述的最大风险是**有限假设集 + 失效独立性**：真实故障常是未知类型的组合，透明/镜面/对抗 patch 又会让视觉与几何共享同一个分布外失效源；于是 FIR 会把未知复合故障强行塞进最近假设、只膨胀错误的球，而系统因"已经归因"更自信地继续执行。本轮不叠加新传感器，而是换一个提问方式：第 65 轮问"**六个假设里是哪一个坏了**"，RECAP 问"**这些假设是从哪来的、够不够、记错没有**"。本轮核心命题是：
>
> **把「参数化有限假设集的归因」升级为「记忆接地的归因 + 主动取证的任务规划」：用检索增强从经验库借来未知复合故障的假设与修复算子，但把"检索"本身当作一种可错、可投毒、且可能与当前证据同源的证据来认证；用任务规划不仅达成目标，还主动把系统搬到"检索有效"的上下文里、把模糊故障变成可辨识。**

## 0. 直觉与动机

**灵感 1（检索增强生成 → 假设空间的非参数扩展）**
直觉：VISTA 的 ℋ 是六个写死的类别。一个"力偏置 + 软接触模型错 + 某类透明物体"的复合故障，在 ℋ 里没有位置，FIR 只能把它投影到最近的单故障上。但"未知"只是相对参数化先验而言——**相对经验，它常常是见过的**。检索增强（RAG / 案例推理）从带标签的历史情节中取回相似签名与当时的真实原因、修复动作与结局，等于把"假设空间"从固定类别扩展为"当前证据邻域内的案例原型 + 一个新奇类 H_novel"。关键不是"检索到答案"，而是"检索到**候选原因与可复用算子**"，再交给可证伪的流程去检验。

**灵感 2（RAG 的暗面 → 检索不是独立证据）**
直觉：检索有三重污染，且都指向"假自信"。(i) **同源回声**：记忆由同一批传感器、同一标定、同一环境产生，若当前证据也来自它们，则记忆与当前证据**共享潜在误差源**，把它俩当独立证据相乘会重复计数、虚增置信；(ii) **时效/漂移**：换过力传感器、重标定、环境变了，旧记忆的似然已失效；(iii) **投毒/对抗**：记忆库可被错误示教或恶意写入，而"来源哈希"也可能被伪造。因此本轮的核心转变是：**检索到的不是真值，是与视觉同等级、甚至更危险的"可错证据"——必须给检索本身发证书，且在记忆不可信时明确标记 `memory_unobservable`，退回 VISTA 的有限集。**

**灵感 3（任务规划 → 把取证从"一次性探针"升级为"规划目标"）**
直觉：VISTA 的 AFA 是单步/短程探针，只问"下一个动作取什么信息"。任务规划把视野拉长：**整个任务计划本身就可以是实验**——在通往目标的分解里插入诊断子目标，使得完成任务的路径同时把模糊故障分离开。这是主动学习/对偶控制（dual control）在任务层的形式：目标达成 + 安全 + 信息增益三者联合优化。更进一步，既然检索的**有效性依赖上下文**（某条记忆只在特定姿态/光照/标定版本下成立），规划就可以主动执行 `memory_probe`——把系统搬到"该记忆重新可认证"的上下文，或反过来搬离它、以证伪它。**检索不再是被动查询，而是可以被规划主动创造条件的对象。**

**灵感 4（三灵感合流 → RECAP：Retrieval-Certified Attribution & Planning，检索认证的归因-规划闭环）**
闭环：CML 认证记忆库 → RCR 检索认证（相关性/可迁移性/独立性/来源）→ CBA 案例归因（固定假设 ∪ 检索原型 ∪ H_novel，含回声校正）→ IDP 信息导向任务规划（目标 + 安全 + 信息增益，含 memory_probe）→ PRR 检索式计划修复 → 计划在支持集上认证 → CSC-R 认证前缀执行 → 执行后回写**带来源与有效期的**新情节。第 65 轮把接触拆成"前/中/后"，RECAP 把归因的证据来源拆成"**当前观测 / 历史经验 / 新奇**"三种，并为每种配一个独立的失效模型。

**灵感 5（VISTA 组件的原位升级）**
- **CML（新增）**：认证记忆库，每条情节带来源 DAG、内容哈希、有效区间、标定版本、独立源键。
- **RCR（新增）**：检索认证门，输出 accept/reject/`memory_unobservable`；被拒记忆不得参与归因。
- **FIR → CBA**：从六假设后验升级为"六假设 + 检索原型 + H_novel"的开放世界后验，并用有效样本量对同源证据降权。
- **AFA → IDP + memory_probe**：探针从"最大化故障假设互信息"升级为"在任务计划里联合优化目标/安全/信息增益"，并新增主动构造检索有效上下文的操作。
- **CSP-V → CSP-R**：层级规划同时检索计划骨架与修复算子；块边需携带检索可迁移性证书。
- **CSC → CSC-R**：认证前缀在所有支持假设（含检索原型与 H_novel 的最坏情形）下验证。
- **RSC-V → RSC-R**：新增 r_mem（记忆不确定半径）与 w_mem（记忆信任权重），只膨胀被归因者；`memory_unobservable` 时 w_mem↓ 并回退。
- **WCV-V → WCV-R**：搜索域增记忆一致性约束 ℳ；归因模糊时按后验 × 检索覆盖边缘化。
- **AIC-V → AIC-R**：干扰集增投毒、陈旧、回声、记忆重放/时序错位；**共因/投毒下只要求检测并降级，不要求归因正确。**
- **J_vista → J_recap**：证书增 retrieval_provenance_hash、transfer_risk、memory_coverage、H_novel_mass、info_gain、repair_lineage。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（RECAP 闭环）**：RECAP=(VISTA, CML, RCR, CBA, IDP, PRR, MPS, AIC-R, J_recap)。不变式：**检索、案例归因、任务规划、计划修复、证书只在语义流；实时流只执行认证前缀、采集证据、早停；实时流零检索、零记忆写。**
- **定义 234（认证记忆库 CML）**：情节 e=(ctx, ρ, H*, A, outcome, prov, [t0,t1], calib_ver, sens_trust, κ_ind)。prov 为来源 DAG，κ_ind 为独立源键（传感器/物体族/环境族），用于共因检测；有效谓词 V_e(s) 仅在时间、标定、信任、环境族均匹配时为真。
- **定义 235（检索查询与相关性/可迁移性）**：q=(ρ_q,ctx_q)；相关性 r(e,q)=−d_{Σ_q}(ρ_q,ρ_e)；可迁移风险 τ_tr(e,q) 用上下文分布间的域分类器 AUC 与其 conformal p 值度量。返回候选集仅含 V_e 为真者。
- **定义 236（检索认证 RCR）**：判定 Accept/Reject/`memory_unobservable`。接受需同时满足：相关性、τ_tr≤τ_max、独立源键不与当前证据共因、来源校验通过、覆盖非空。若全部拒绝但查询在分布内→`memory_unobservable`；**该标记不得被用来否认任何一个现有假设**（同 `visual_unobservable` 原则）。
- **定义 237（回声校正与有效样本量）**：检索证据的相关矩阵 C（按 κ_ind 与潜在源估计）；有效样本量 n_eff=1ᵀC⁻¹1；回火指数 τ_r=n_ret/max(n_eff,1)≥1。同源后验 P(H|ρ,M)∝p(ρ|H)∏_i p(e_i|H)^{1/τ_r}。**τ_r 的作用是把"n 条同源记忆"折回"n_eff 条独立证据"。**
- **定义 238（案例归因 CBA）**：开放世界假设 ℋ_R=ℋ_VISTA∪ℋ_ret∪{H_novel}。ℋ_ret 由认证检索情节的成因聚类/原型给出（含复合故障原型）；p(ρ|H_ret,k) 由核密度或小流模型给出；新奇度 s_novel(ρ_q) 为到认证记忆的 conformal 距离，p 值≤α_nov 时把质量分配给 H_novel，其先验质量由记忆覆盖缺口决定。
- **定义 239（案例覆盖保证）**：在有效分区内可交换时，split-conformal 给出可信集 C_α，满足 P(H_true∈C_α)≥1−α−β_poison−β_stale，β 为 RCR 漏检投毒/陈旧的保守上界（A94）。若 RCR 失败→`memory_unobservable`，退化为 VISTA 的有限集保证，**不劣于第 65 轮**。
- **定义 240（任务计划库与检索式规划）**：计划库存层级计划骨架 τ=(技能序列, 子目标, 前置/效果, 修复算子, prov)。按目标+上下文检索骨架，其前置必须在支持假设集下成立；代价含检索可迁移风险 λ_mem·τ_tr。
- **定义 241（信息导向任务规划 IDP）**：在信念 (x,b(H),θ_mem) 上求解 min_π E[Σcost + λ_risk·risk + λ_mem·τ_tr − λ_info·I(H,θ_mem; 观测)]，s.t. 风险≤预算。即对偶控制：目标、安全、信息三者联合；诊断子目标作为元技能插入。
- **定义 242（记忆探针 memory_probe）**：选择动作序列 a 把上下文搬到使某条目标记忆的 V_e 为真且 τ_tr 最小、同时观测对目标假设有正 Fisher 信息的区域；若不存在这样的可达安全区域，则该探针为空操作、禁止执行。
- **定义 243（检索式计划修复 PRR）**：修复算子 ρ_op 带 pre/eff 与来源；仅当 pre 在支持集所有 H 下成立、且 eff 的 conformal 误差界内不破坏安全时应用；否则拒绝并从头重规划。修复血缘写入证书。
- **定义 244（来源与投毒防御 MPS）**：来源 DAG + 内容哈希 + 独立物理不变量（能量/力平衡/因果时序）+ 跨源一致性四重校验；校验失败者隔离。**无法排除来源被伪造，故只把投毒检测当作概率证据而非真值。**
- **定义 245（AIC-R 检索对抗认证）**：ℰ_R=ℰ_V×ℰ_poison×ℰ_stale×ℰ_echo×ℰ_replay，含投毒示教、陈旧标定、同源回声、记忆重放/时序错位、对抗查询；ρ_dir 在 ℰ_R 上重算（n_cert 128→160，32 给记忆类）；**共因/投毒下只要求判 ambiguous 并安全降级，不要求归因正确。**
- **定义 246（RECAP 证书 J_recap）**：J_recap=(J_vista, retrieval_provenance_hash, certified_support, transfer_risk, memory_coverage, H_novel_mass, info_gain_achieved, repair_lineage, aic_r_ver)。Valid ⇔ Valid(J_vista) ∧ (检索已认证 ∨ `memory_unobservable`) ∧ H_novel 质量被显式记账 ∧ 修复已校验 ∧ 证书与执行前缀一致。
- **定义 247（记忆写入规则）**：只有通过执行后验证、且来源完整的情节可写回 CML；实时流禁止写；写入须带 calib_ver 与 κ_ind；同一情节的多份同源拷贝合并计权，避免库被回声灌水。
- **定义 248（RECAP 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG→ACH→VCV→CBA（RCR 检索+CBA 归因）→IDP（信息导向规划+memory_probe）→PRR→WCV-R→CSP-R→CSC-R→Shield→执行 k*→EV_exec→RSC-R→OLP→DIR→MPS→AIC-R→CML 写入]；实时流 [锚点读→残差采集→阶段判定→CSC-R 早停→WCV-R 编译→π_σ 前缀派发→J_recap 构建]。

## 2. 关键算法骨架

```python
# RCR + CBA：认证检索 → 开放世界归因（语义流）
cand = cml.query(rho_q, ctx_q, valid_only=True)
cert = rcr.certify(cand, ctx_q)                 # relevance / transfer / independence / provenance
if cert.accepted:
    n_eff, tau_r = effective_n(cert.support)    # 回声校正
    post = cba.attribute(rho_q, cert.support, tau_r,
                         H_fixed=H_VISTA, alpha_nov=0.1)
else:
    cert = cert.with_flag('memory_unobservable')
    post = vista_fir.attribute(rho_q)           # 退回第 65 轮，保证不劣化

# IDP：任务层的目标-安全-信息联合规划
best, best_obj = None, inf
for plan in csp_r.retrieve_and_expand(goal, post, cert):
    obj = (plan.risk - lam_info * info_gain(plan, post, cert)
           + lam_mem * cert.transfer_risk(plan))
    if plan.risk <= risk_budget and obj < best_obj:
        best, best_obj = plan, obj
k_star = csc_r.certified_prefix(best.A, post.support(top=2), m, alpha_chunk)

# memory_probe：主动构造"检索有效"的上下文
if cert.ambiguous and not object_fragile:
    a = idp.memory_probe(post, cml, reachable_safe_regions)
    if a is not None:
        execute(a)                               # 搬到目标记忆可认证的上下文

# PRR：检索式修复
if exec_deviation(best):
    op = prr.retrieve_operator(post, ctx)
    if op and op.pre_holds(post.support) and op.eff_bounded(op.conformal):
        plan = op.apply(best)
    else:
        plan = csp_r.replan(goal, post)          # 拒绝修复，从头规划
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（检索证据的同源依赖）**：若检索证据间及与当前观测共享潜在误差源，则朴素乘积把信息量高估至多 √(n_ret/n_eff)。用回火指数 τ_r=n_ret/n_eff 后，后验曲率（Fisher 信息）不超过 n_eff 条独立证据，后验收缩速率由 n_eff 而非 n_ret 支配；等相条件下 n_eff=n/(1+(n−1)ρ̄)。
- **引理 10（认证检索的覆盖不退化）**：有效分区内可交换且 RCR 漏检投毒/陈旧质量≤β 时，P(H_true∈C_α)≥1−α−β；RCR 失败→`memory_unobservable`→退回 VISTA，覆盖回到第 65 轮水平，**最坏情形严格不劣于 VISTA**。
- **引理 11（memory_probe 的条件与无害性）**：当且仅当存在可达、风险可行且使目标记忆 V_e 成立的上下文、且该上下文观测对目标假设正信息时，探针才降低 τ_tr；否则为空操作，必须禁止执行，避免"为了检索而多走一段危险路"。
- **定理 9（RECAP 端到端开放世界安全）**：在 A88–A98 下，Valid(J_recap) ⇒ 真实原因属于可信集（或显式 ambiguous/新奇）、同源证据不制造假自信、计划安全不劣于 VISTA、检索修复保持有效性、记忆失效时优雅退回第 65 轮。
- **定理 10（信息导向规划的近优性）**：在标准观测模型下，信息增益对诊断子目标是自适应次模的，贪心选择达到 (1−1/e) 近似；带风险约束用拉格朗日松弛，约束违反有界。纯目标规划的信息增益可为 0，因此 IDP 在模糊故障下严格优于目标规划。
- **命题（记忆规模的驼峰）**：新增记忆既提高覆盖也提高同源相关与检索歧义，校准后的净收益在某个库规模处达到单峰；"记忆越多越好"被回声与陈旧推翻。

## 5. 本轮最大风险

**一句话**：RECAP 把"有限假设集"换成了"记忆集"，但记忆本身可能被投毒、陈旧、或被同一批传感器灌成回声，而"认证"给人的安全感会掩盖一个事实——**来源哈希可以伪造、独立源可以伪装、H_novel 的覆盖质量取决于记忆缺口估计是否诚实**；一旦记忆系统性错误，CBA 会自信地把新故障归到某个错误的历史案例，计划修复也会复用错误的经验，**第 65 轮"归因错误的复合故障"由此升级为"有证书背书的、可复现的错误经验"，且系统因为"检索已认证"而更不会停下来**——这是全轮覆盖保证（引理 10、定理 9）共同依赖的隐藏假设（A94）。

## 2. 形式化定义（完整版）

**定义 233（RECAP 闭环）** RECAP 是 VISTA 的"开放世界归因 + 主动取证规划"升级：在 VISTA 的语义流/实时流骨架上新增 CML（认证记忆库）、RCR（检索认证）、CBA（案例归因）、IDP（信息导向规划）、MPR（记忆探针）、PRR（计划修复）、MPS（来源防御），并原位升级 CSP-V→CSP-R、CSC-V→CSC-R、RSC-V→RSC-R、WCV-V→WCV-R、AIC-V→AIC-R、J_vista→J_recap。不变式：**检索、案例归因、任务规划、计划修复、证书构建只在语义流；实时路径只执行认证前缀、采集残差、早停与派发，零检索、零记忆写。**

**定义 234（认证记忆库 CML）** 一条情节
e=(ctx, ρ, H*, A, outcome, prov, [t0,t1], calib_ver, sens_trust, κ_ind)。
prov 是来源 DAG（示教者、传感器批次、标定记录、执行轨迹的父子关系），并带内容哈希；κ_ind 是独立源键，用于判定两条记忆是否共享潜在误差源（同传感器/同物体族/同环境族）。有效谓词
V_e(s)=1[t∈[t0,t1]]·1[calib_ver=calib(s)]·1[sens_trust≥τ_tr_trust]·1[env_family(ctx_e)=env_family(s)]。
只有 V_e 为真的情节才进入检索候选。CML 支持"合并同源副本"：κ_ind 相同且签名一致的多条记忆按一条计权，防止回声灌水。

**定义 235（检索查询、相关性与可迁移风险）** 查询 q=(ρ_q,ctx_q)。相关性
r(e,q)=−d_{Σ_q}(ρ_q,ρ_e)，
其中 Σ_q 是当前证据的协方差（沿用第 65 轮阶段化签名）。可迁移风险 τ_tr(e,q) 由一个在"记忆标定分布"与"当前上下文分布"上训练的域分类器给出：τ_tr=2·AUC−1（0 表示不可分、1 表示完全可分），并用 split-conformal 校准其 p 值，使"τ_tr≤τ_max"具有显式覆盖含义。候选集仅含 V_e 为真者。

**定义 236（检索认证 RCR）** RCR 对候选集输出三态：
- **Accept**：存在 e 使 r(e,q) 足够大、τ_tr(e,q)≤τ_max、κ_ind(e) 与当前主导证据源不共因、prov(e) 校验通过，且认证支持集覆盖非空；
- **Reject**：候选均不满足上述任一条件；
- **`memory_unobservable`**：查询在分布内、但所有候选都被拒或库为空。
`memory_unobservable` 是**安全退化标记**：它不得被用来否认任何一个现有假设（同第 65 轮 `visual_unobservable` 原则），只能触发"退回 VISTA 有限集 + 降低 w_mem"。

**定义 237（回声校正与有效样本量）** 设认证支持集有 n_ret 条记忆，其证据相关矩阵 C（由 κ_ind 分组、并用历史残差估计组内相关 ρ̄）。定义
n_eff=1ᵀC⁻¹1，τ_r=n_ret/max(n_eff,1)≥1。
同源后验
P(H|ρ,M) ∝ p(ρ|H) ∏_{i=1}^{n_ret} p(e_i|H)^{1/τ_r}。
当记忆等相相关为 ρ̄ 时，C=(1−ρ̄)I+ρ̄11ᵀ，直接算得 n_eff=n_ret/(1+(n_ret−1)ρ̄)，故 τ_r=1+(n_ret−1)ρ̄。**回火的作用：把 n_ret 条同源记忆折回 n_eff 条独立证据，避免"复制同一段经验 100 次得到 100 倍自信"。**

**定义 238（案例归因 CBA）** 开放世界假设
ℋ_R=ℋ_VISTA∪ℋ_ret∪{H_novel}，
其中 ℋ_ret 由认证检索情节的成因聚类给出，允许**复合故障原型**（如 H_force×H_model、H_geo×H_vis）；p(ρ|H_ret,k) 用核密度或小归一化流在原型邻域估计。新奇度 s_novel(ρ_q) 为 ρ_q 到认证记忆的最小 conformal 距离，p 值≤α_nov 时把质量分配给 H_novel：
P(H_novel|ρ)=max(π_gap, 1−coverage(S_q))，
π_gap 为记忆覆盖缺口先验。后验按定义 237 回火，再做定向处置（沿用定义 221），**H_novel 不触发任何定向膨胀，只触发保守联合膨胀 + ambiguous。**

**定义 239（案例覆盖保证）** 在每个有效分区（同一 calib_ver、env_family）内假设可交换，以"到最近同成因认证原型的距离"为非一致性分数做 split-conformal，得可信集 C_α。若 RCR 漏检的投毒质量≤β_poison、陈旧质量≤β_stale，则由联合界
P(H_true∈C_α) ≥ 1−α−β_poison−β_stale。
RCR 失败时走 `memory_unobservable`，C_α 退化为 VISTA 的有限集可信集，故**最坏情形不劣于第 65 轮**。

**定义 240（任务计划库与检索式规划）** 计划库存层级计划骨架
τ=(技能序列, 子目标, pre, eff, repair_ops, prov)。
按目标+上下文检索骨架，并要求 pre 在支持假设集 supp_δ(post) 下全部成立。骨架代价含检索可迁移风险 λ_mem·τ_tr(τ,q)，迫使规划器优先选择"在当前上下文更可能成立"的经验。

**定义 241（信息导向任务规划 IDP）** 在信念 (x,b(H),θ_mem) 上求解
π*=argmin_π E[Σ_t cost(s_t,a_t) + λ_risk·risk(π) + λ_mem·τ_tr(π) − λ_info·I(H,θ_mem; o_{1:T}(π))]，
s.t. risk(π)≤B_risk。
即任务层的对偶控制：计划同时追求目标、安全与"把模糊故障分清楚"。诊断子目标（null_test/visual_probe/fi_probe/memory_probe）是可插入的元技能；I 为对故障假设与记忆相关性 θ_mem 的互信息。

**定义 242（记忆探针 memory_probe）** 选择动作序列 a_mp，把上下文搬到满足
V_e(s')=1，τ_tr(e,q')≤τ_min，且 I(H;o(a_mp))>0
的可达安全区域。若不存在这样的区域、或搬运风险超过预算、或物体易损，则 a_mp=∅、禁止执行。**该定义把"检索有效性"从被动词查询变成可控状态量。**

**定义 243（检索式计划修复 PRR）** 修复算子 ρ_op=(pre,eff,prov) 从 CML 检索。仅当
(i) pre 在 supp_δ(post) 的每个 H 下成立；
(ii) eff 的 conformal 误差界内仍满足 ρ_safe≥0（力/滑移/几何）；
(iii) prov 校验通过
时应用，得到计划 π⊕ρ_op；否则拒绝并调用 CSP-R 从头重规划。修复血缘写入 J_recap。

**定义 244（来源与投毒防御 MPS）** 对每条记忆做四重校验：
(i) 来源 DAG 完整且哈希链一致；
(ii) 内容与独立物理不变量一致（能量/力平衡、因果时序、接触几何可行性）；
(iii) 跨源一致（不同 κ_ind 的独立记忆给出一致成因）；
(iv) 与在线标定残差一致。
任一项失败即隔离并降权。**定理层面只承诺"投毒检测是概率证据"，不承诺"来源不可伪造"。**

**定义 245（AIC-R 检索对抗认证）** 干扰集
ℰ_R=ℰ_V×ℰ_poison×ℰ_stale×ℰ_echo×ℰ_replay，
ℰ_poison 含错误示教/伪造来源/标签翻转；ℰ_stale 含硬件更换、重标定、环境漂移；ℰ_echo 含同源重复灌库；ℰ_replay 含记忆重放/时序错位/对抗查询。ρ_dir 在 ℰ_R 上重算（n_cert 128→160，其中 32 给检索类），并在最坏投毒与最坏回声下取最坏；J_dir 增 retrieval_calib_ver、memory_sync_ver。**投毒/回声下不要求归因正确，只要求能被判 ambiguous 并安全降级。**

**定义 246（RECAP 证书 J_recap）** J_recap=(J_vista, retrieval_provenance_hash, certified_support, transfer_risk, memory_coverage, H_novel_mass, info_gain_achieved, repair_lineage, aic_r_ver)。验证规则：
Valid(J_recap) ⇔ Valid(J_vista)
∧ (memory_unobservable ∨ 认证支持集非空且 τ_tr≤τ_max)
∧ H_novel_mass 已显式记账（当 s_novel≤α_nov）
∧ (应用了修复 ⇒ 修复已校验且血缘完整)
∧ 块签名与执行前缀一致 ∧ aic_r_ver 为当前版本。
审计链新增：为何检索这条经验（provenance/support）、为何相信它（transfer_risk/independence）、为何不用记忆（memory_unobservable）、用哪条经验修复（repair_lineage）。

**定义 247（记忆写入规则）** 仅当 (i) 情节通过执行后验证（结果与预测在 conformal 界内）、(ii) prov 完整、(iii) 归因后验在事后被证实或至少未被证伪时，才写回 CML。实时流禁止写；写入必带 calib_ver 与 κ_ind；同源同签名情节按一条计权（与定义 234 的合并规则一致），防止库被"成功但同源"的样本回声灌水。

**定义 248（RECAP 闭环算子）** 语义流：[LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→VCV→**RCR 检索认证→CBA 开放世界归因**→**IDP 信息导向规划（含 memory_probe）**→**PRR 计划修复**→WCV-R→CSP-R→CSC-R→Shield→执行 k*→EV_exec→RSC-R→OLP→DIR→**MPS 来源校验**→AIC-R→**CML 写入**]；实时流：[锚点读→视觉/力残差采集→阶段判定→CSC-R 早停→WCV-R 编译→π_σ 前缀派发→J_recap 构建]。实时流不含检索与记忆写，仅可读缓存的认证支持集句柄。

### IP-224/225 CML + RCR（认证检索）

```python
class CertifiedMemory:
    """每条情节带来源、有效期、独立源键；只有 valid 才可检索。"""
    def query(self, rho_q, ctx_q, valid_only=True, topk=16):
        cand = [e for e in self.episodes
                if (not valid_only) or self.valid(e, ctx_q)]
        cand.sort(key=lambda e: -self.relevance(e, rho_q, ctx_q))
        return cand[:topk]

    def valid(self, e, ctx):
        return (e.t0 <= ctx.t <= e.t1
                and e.calib_ver == ctx.calib_ver
                and e.sens_trust >= TAU_TRUST
                and e.env_family == ctx.env_family)

    def relevance(self, e, rho_q, ctx):
        return -mahalanobis(rho_q, e.rho, ctx.Sigma_q)


class RetrievalCertifier:
    """相关性 / 可迁移 / 独立性 / 来源 四关；失败→memory_unobservable。"""
    def certify(self, cand, ctx):
        if not cand:
            return Cert(accepted=False, flag='memory_unobservable')
        support, poison_mass = [], 0.0
        for e in cand:
            if self.relevance_ok(e, ctx) and \
               self.transfer_risk(e, ctx) <= self.tau_max and \
               not self.common_cause(e, ctx) and \
               self.provenance_ok(e):
                support.append(e)
            else:
                poison_mass += self.weight(e)
        if not support:
            return Cert(accepted=False, flag='memory_unobservable',
                        beta_poison=poison_mass)
        return Cert(accepted=True, support=support,
                    beta_poison=poison_mass, n_ret=len(support))

    def common_cause(self, e, ctx):
        # 与当前主导证据共享独立源键 → 判为共因，不得当独立证据
        return e.kappa_ind in ctx.dominant_source_keys
```

### IP-226 CBA（开放世界 + 回声校正）

```python
class CaseBasedAttribution:
    def attribute(self, rho_q, support, tau_r, H_fixed, alpha_nov=0.10):
        n_eff = effective_sample_size(support)          # 1ᵀ C⁻¹ 1
        tau_r = max(tau_r, len(support) / max(n_eff, 1e-9))
        logp = {h: np.log(prior(h) + 1e-12) + loglik_fixed(h, rho_q)
                for h in H_fixed}
        for k, proto in enumerate(clusters(support)):
            h = f'H_ret_{k}'
            logp[h] = (np.log(prior_ret(k) + 1e-12)
                       + kde_loglik(proto, rho_q) / tau_r)   # 同源降权
        p_nov = conformal_pvalue(rho_q, support)
        if p_nov <= alpha_nov:
            logp['H_novel'] = np.log(max(1 - coverage(support), PI_GAP))
        post = softmax(logp)
        return post, conformal_set(post, support, alpha=0.10)
```

### IP-227/228 IDP + memory_probe（信息导向规划）

class InfoDirectedPlanner:
    def plan(self, goal, post, cert, risk_budget):
        best, best_obj = None, np.inf
        for skeleton in self.plan_library.retrieve(goal, post, cert):
            if not pre_holds(skeleton.pre, support(post)):
                continue
            for plan in self.expand(skeleton, post):
                if plan.risk > risk_budget:
                    continue
                obj = (plan.cost
                       + LAM_RISK * plan.risk
                       + LAM_MEM * cert.transfer_risk(plan)
                       - LAM_INFO * expected_info_gain(plan, post, cert))
                if obj < best_obj:
                    best, best_obj = plan, obj
        return best

    def memory_probe(self, post, cml, reachable):
        if entropy(post) < DELTA_FI:
            return None
        for e in cml.valid_but_unrelated(post):
            for region in reachable():
                if (region.safe and cml.valid(e, region.ctx)
                        and cml.transfer_risk(e, region.ctx) <= TAU_MIN
                        and info_gain_of(region.obs, post) > 0):
                    return region.action        # 搬到"该记忆可认证"的上下文
        return None                              # 空操作：禁止为了检索而冒险
```

### IP-229 PRR（检索式修复）

class PlanRepair:
    def repair(self, plan, post, ctx):
        op = self.memory.retrieve_operator(post, ctx)
        if op is None:
            return None
        if not all(pre_holds(op.pre, h) for h in support(post)):
            return None
        if not eff_safe(op.eff, op.conformal, post):
            return None
        return op.apply(plan)                    # 血缘: plan.id -> op.id
```

def RECAP_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流 ————
    M.lsf.update_geometry(P_cloud)

    f_vis, k_hat, _ = M.vfp.estimate(visual['flow'], M.dt, visual['valid'])
    phases = M.stage.split(M.residual_log, visual)

    cand = M.cml.query(rho_q_of(phases), ctx_of(M))

    # 3) memory_probe：主动构造可认证上下文
    if cert.ambiguous and not M.object_fragile:
        a_mp = M.idp.memory_probe(post, M.cml, M.reachable_safe_regions)
        if a_mp is not None:
            M.execute(a_mp)
            post, credible = M.cba.attribute(*M.reacquire())

    # 4) 认证前缀与执行
    k_star = M.csc_r.certified_prefix(tau.A, support(post), M.m, M.alpha_chunk)
    K_safe, EV_exec, cert_exec = realtime_step_recap(
        M, delta_f_req, tau, k_star, x_prime, f_vis)

    # 5) 计划修复
    if exec_deviation(EV_exec, tau):
        tau_fix = M.prr.repair(tau, post, ctx_of(M))
        tau = tau_fix if tau_fix is not None else M.csp_r.replan(goal, post)

    # 6) 在线更新 + 记忆回写（语义流）
    M.olp.online_step(M.olp.fuse_evidence(x_prime, W_meas, tactile, visual, post),
                      execution_loss_grad(K_safe, EV_exec, M.balls))
    M.rsc_r.update(EV_exec, W_meas, phi_hat_geo, post, cert, M.balls)
    if M.mps.verify(EV_exec, M.last_episode):

                    kappa_ind=M.source_key())
    M.dir.update(sample_batch_from_history(32))
    M.aic_r.certify(tau, x_prime, phi_hat_geo, M.balls, post, cert)
    return M, K_safe, build_j_recap(cert_exec, post, cert, tau, k_star)

## 4. 推导

**引理 9（检索证据的同源依赖）** 设 n_ret 条检索证据与当前观测共享潜在误差源，等价于每个"独立信息单元"被重复观测。设证据相关矩阵为 C、等相相关为 ρ̄。朴素独立乘积的 Fisher 信息为 n_ret/σ²，而正确信息为
I_eff=1ᵀC⁻¹1/σ²=n_eff/σ²。
等相时 C=(1−ρ̄)I+ρ̄11ᵀ，C⁻¹=(1/(1−ρ̄))(I−(ρ̄/(1+(n_ret−1)ρ̄))11ᵀ)，故 n_eff=n_ret/(1+(n_ret−1)ρ̄)。于是朴素后验的标准差被低估至多
√(n_ret/n_eff)=√(1+(n_ret−1)ρ̄)，
即后验"看起来"比真实确定得多。取 τ_r=n_ret/n_eff 回火后，后验曲率恰为 n_eff 条独立证据的曲率，Laplace 后验集中速率由 n_eff 支配。∎

**引理 10（认证检索的覆盖不退化）** 在有效分区内可交换，且 RCR 接受集与真实成因的联合分布满足：被接受但为投毒/陈旧的总概率质量≤β=β_poison+β_stale。对认证支持集做 split-conformal，若不计污染，覆盖率为 1−α；计入污染质量，由全概率公式与联合界，真实成因落入可信集的概率≥1−α−β。若 RCR 拒绝全部候选，则 `memory_unobservable`，CBA 不使用任何记忆证据，post 由 VISTA 的 FIR 给出，覆盖回到第 65 轮保证。故对任意 β∈[0,1]，RECAP 的覆盖下界≥min(1−α−β, VISTA 覆盖率)，**最坏情形不劣于 VISTA**。∎

**引理 11（memory_probe 的条件与无害性）** memory_probe 有意义的充要条件是存在可达上下文 s' 使 V_e(s')=1、τ_tr(e,q')≤τ_min、且观测 o(a_mp) 对目标假设的 Fisher 信息为正。若不存在，则任何搬运动作只增加风险而不增加信息，故最优为 a_mp=∅。由 IDP 的约束优化，若把空操作视为可行解，则非空探针只在目标函数严格下降时被选中，因此探针不会降低安全性。∎

**定理 9（RECAP 端到端开放世界安全）** 在 A88–A98 下：
1. **开放世界覆盖**：由引理 10，真实成因以≥1−α−β 落入 C_α；未知复合故障要么被检索原型表示，要么落入 H_novel（s_novel≤α_nov），要么使后验不集中而判 ambiguous——**不会像第 65 轮那样被强行塞进最近单故障**。
2. **无回声假自信**：由引理 9，同源记忆经 τ_r 回火后信息量不超过 n_eff 条独立证据，后验不会因"复制经验"而虚增；定向膨胀只依据回火后后验。
3. **计划安全不劣于 VISTA**：CSC-R 在 supp_δ(post)（含检索原型与 H_novel 最坏）上验证 k*，且 k*≤m；由引理 8 的联合界，单块越界概率≤α_chunk+δ_fi+α_vis+α_mem。
4. **修复有效**：PRR 仅在 pre 对所有支持假设成立、eff 在 conformal 界内安全时应用（定义 243），故修复不破坏 Valid(J_recap)；否则从头重规划。
5. **优雅退化**：记忆失效→`memory_unobservable`→w_mem↓、退回 VISTA；记忆与视觉同时失效→ambiguous→safe_idle+compliant retreat；未知故障→H_novel 或 ambiguous，绝不强行归因。
6. **实时性**：检索/归因/规划/修复全在语义流；实时流只多一个缓存支持集句柄读取，目标≤2.5ms（A97）。∎

**定理 10（信息导向规划的近优性）** 设诊断子目标的期望信息增益 I 对已选子目标集是自适应次模的（A96：标准观测模型下的互信息满足收益递减）。则带基数约束的信息增益最大化可由贪心达到 (1−1/e)·OPT；加入风险预算 B_risk 后，用拉格朗日松弛 L=信息增益−μ·风险，对固定 μ 贪心，若风险函数对子目标也是次模的，则约束违反量≤(1/μ)·(OPT_L−L_greedy) 有界。特别地，纯目标规划不选择任何零即时收益的诊断子目标，其信息增益为 0；当 posterior 熵>δ_fi 时，IDP 以正信息增益严格优于纯目标规划。∎

**命题（记忆规模的驼峰）** 设库规模为 n，覆盖收益 B(n) 为凹增函数（新记忆补充覆盖缺口，边际递减），同源相关/检索歧义成本 C(n) 为凸增函数（n 越大，近邻越密、κ_ind 重叠越多、τ_r 越大）。校准后的净收益 N(n)=B(n)−C(n) 在 B'(n)=C'(n) 处取极大，呈单峰；超过该点，新增记忆主要增加回声与陈旧风险而非覆盖。故"记忆越多越好"不成立，存在最优库规模 n*。∎

**命题（修复 vs 重规划的阈值）** 设从头重规划代价 c_replan，检索修复代价 c_rep（含检索与校验），修复失败概率 p_fail(τ_tr) 随可迁移风险递增。则修复的期望代价为 c_rep+p_fail(τ_tr)·c_replan，修复优于重规划当且仅当
p_fail(τ_tr) < 1−c_rep/c_replan。
由于 p_fail 随 τ_tr 单调增，存在阈值 τ*：τ_tr<τ* 时修复，τ_tr≥τ* 时重规划。这给出 PRR 的一个可直接标定的选用规则。∎

## 7. 已知风险

**一句话**：RECAP 把"有限假设集"换成了"记忆集"，但记忆本身可能被投毒、陈旧、或被同一批传感器灌成回声，而"认证"给人的安全感会掩盖一个事实——**来源哈希可以伪造、独立源可以伪装、H_novel 的覆盖质量取决于记忆缺口估计是否诚实**；一旦记忆系统性错误，CBA 会自信地把新故障归到某个错误的历史案例，计划修复也会复用错误的经验，**第 65 轮"归因错误的复合故障"由此升级为"有证书背书的、可复现的错误经验"，且系统因为"检索已认证"而更不会停下来**——这是全轮覆盖保证（引理 10、定理 9）共同依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **来源可伪造 / 投毒检测非真值**：MPS 只能给概率证据；缓解：四重独立校验 + 隔离区 + 证书显式标注 β_poison，不承诺绝对安全；高风险场景禁用外部记忆写入。
2. **回声灌库**：同源副本抬高 n_rep 压低置信区间；缓解：κ_ind 去重、τ_r 回火、库内多样性配额、写入时强制保存来源分组。
3. **陈旧记忆**：换硬件/重标定后旧似然失效；缓解：V_e 的 calib_ver 硬门 + 漂移检测 + 分区间 conformal。
4. **记忆规模驼峰**：库过大反而检索歧义与相关成本上升；缓解：按命题选 n*、主动遗忘低质量/高冗余情节。
5. **H_novel 覆盖名不副实**：新奇度依赖距离度量与记忆缺口先验；缓解：分视界/分故障族校准 α_nov，online 重校准，熵过高直接 safe_idle。
6. **IDP 探索风险**：诊断子目标可能增加接触/运动；缓解：风险预算硬约束、易损物体禁用物理探针、仅允许 memory_probe/null_test/visual_probe。
7. **memory_probe 可达性与代价**：为检索绕路可能得不偿失；缓解：引理 11 的空操作条件 + 代价项 λ_mem；只在熵高且风险预算内启用。
8. **计划修复的转移风险**：retrieved operator 在旧上下文有效、新上下文失效；缓解：pre 在支持集全验证 + eff conformal 界 + τ* 阈值，宁可重规划。
9. **实时预算**：检索与规划若误入实时环会击穿 2.5ms；缓解：实时流只读缓存句柄，A97 硬隔离，事件触发异步刷新。
10. **conformal 在分布漂移下失准**：有效分区可交换假设被破坏；缓解：分区内校准 + 漂移检测 + 覆盖率在线监控，覆盖率跌破阈值即 `memory_unobservable`。

**假设 A94–A98（本轮新增）**：
- A94：RCR 漏检的投毒/陈旧质量有可计算上界 β（由来源校验覆盖率与独立物理不变量给出）。
- A95：在每个有效分区（calib_ver × env_family）内，记忆与当前观测可交换。
- A96：诊断子目标的期望信息增益对已选子目标自适应次模。
- A97：检索、记忆写、规划、修复全部在语义流；实时流无检索、无记忆写。
- A98：修复算子效果误差可由 conformal 界给出，且界在有效分区内有效。
