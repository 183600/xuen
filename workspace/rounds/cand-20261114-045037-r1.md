> R69 把不确定性一分为二，并让系统学会了「问」——看、问、触。但它有一个从未言明的前提：**证据源是可比的、独立的、同等可信的**。定义 293-iii 的「k 个正交证据源一致」默认每个源都是「一个诚实的传感器」；然而真实的源是**人**——有能力差异、有知识边界、有立场、会疲惫、会撒谎、会随时间改变。谁在回答、这条证据该加权多少、我对他的判断本身准不准，R69 统统没有建模。

> - **用户画像**把「源」从一个匿名索引升级为一个**被估计的隐状态** θ_u（能力、知识、意图、诚实度、注意力），并明确它是慢变的、有冷启动的、会被自我实现的；
> - **无刷电机**给出一套成熟的控制论模板来处理「估计一个看不见的状态并据此决策」：**无感观测器（反电动势）→ 强迫换相启动 → 迟滞交接 → 磁场定向 d/q 解耦 → 弱磁防锁死 → Hall/缺相/退磁/换相误差的故障分离 → 抗积分饱和 → 过流热保护**。

> 核心命题：**把用户画像当作「转子位置」——一个必须被间接观测、会失锁、会发散、需要启动与故障保护的隐状态；把交互当作「换相」——依据估计位置在正确时刻切换证据源/问句/任务假设；用 d/q 解耦让「了解你」不污染「把事做成」；用弱磁让画像永远锁不住一个正在改变的人。** 命名 **PERSONA-FOC**（Persona Field-Oriented Control）。

## 0. 直觉与动机

**灵感 1（用户画像 → 源不是索引，是隐状态）**
直觉：R69 的证据集 ℰ 里每个源只有一个名字，权重是常数或校准后的先验。但「谁在回答」决定了这条证据的一切：同一个「是」，专家说是强证据，外行说是弱证据，敌手说可能是反证据。用户画像的本质不是贴标签，而是**估计一个隐状态 θ_u 并用它给证据加权**。一旦承认这一点，R69 的「k 源一致」就松动了——因为「源之间是否正交」本身取决于 θ_u：两个共享同一偏见的人并不正交，他们的「一致」是相关噪声，不是独立确认。

**灵感 2（无刷电机的观测器 → 画像只能被间接地「无感」估计）**
直觉：无刷电机最漂亮的地方是**无位置传感器**——它不测量转子在哪，而是从反电动势（back-EMF）间接**观测**出位置。反电动势幅度正比转速：**转子转得越慢，信号越弱，估计越不可靠；静止时完全失明。** 这与用户画像一模一样：用户的「信号」（回答、纠正、反应、行为）越少越被动（低转速），画像估计越不可靠；冷启动时系统对用户一无所知（静止）。于是无刷电机的「强迫换相启动 → 反电动势足够后交接到无感闭环」直接映射为：**冷启动用不带画像的保守默认（强迫换相），在累积到足够激励并跨过置信门后才交接到画像驱动的闭环。**

**灵感 3（磁场定向 d/q 解耦 → 「了解你」与「把事做成」必须正交）**
直觉：FOC 把电流分解成 d 轴（励磁，不产生转矩）与 q 轴（转矩，做有用功），并独立控制，避免励磁污染转矩。用户画像也有两个轴：**d 轴 = 稳定身份/能力/偏好（了解你是谁，本身不推进任务）**，**q 轴 = 任务相关当前状态（你现在知道什么、想要什么、能不能做，直接产生任务收益）**。若不分轴，系统会把大量交互花在「了解你」（d 轴励磁）却误以为在推进任务（产生转矩）——这正是「画像很丰满、任务没进展」的病。R69 的 VoI 只算了任务收益，从未区分这两股「电流」。

**灵感 4（级联控制 → 画像在慢环，任务在快环，互不侵占实时预算）**
直觉：无刷电机是级联控制：电流环最快、速度环居中、位置环最慢，带宽严格分离，慢环永不拖垮快环。同理，用户画像应在**最外层慢环**（秒/分钟级），任务控制在快环（毫秒级）。这样 R69 最担心的实时预算被彻底解耦：画像更新再贵也不进实时路径。这同时是一条安全论证：**慢环不能在线改写快环的安全包络。**

**灵感 5（故障分离与弱磁 → 画像的五类死法与一个解药）**
直觉：无刷电机的故障有签名、可分离：**Hall 失效**（完全丢位置信号）↔ 用户沉默/掉线；**缺相**（某一路驱动不通）↔ 某条交互通道被封；**退磁**（磁铁变弱，输出扭矩下降）↔ 用户能力/可靠性下降（疲劳、过载）；**换相误差**（换相时刻错了，产生转矩脉动）↔ 画像用错时机/对象，表现为交互质量周期性抖动。还有漂亮的对应：**过流/热保护** ↔ R69 的交互预算——问太多会把「社交热度」烧穿。而最危险的不是这些，是**无感观测器发散**：估计值与真实转子越差越远，但置信度报告却很高——**画像-真实差距在扩大，而系统越来越自信**。解药是**弱磁**：当证据与画像冲突、或任务紧迫度（转速）超过画像先验能支撑的范围时，主动削弱画像的「磁场」（先验精度），让新证据有机会主导——**画像永远不能锁死一个正在改变的人**。

**灵感 6（抗积分饱和 → 人回来时不能「踹」他一脚）**
直觉：用户离开（通道饱和）时若继续累积关于他的证据（积分项），一旦他回来，画像会突然「踢」一下——把离开期间累积的错误信念一次性施加。无刷电机的抗积分饱和（anti-windup）直接对应：**通道阻断期间冻结画像积分，重连时有界斜坡恢复。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PERSONA-FOC 总览）** PERSONA-FOC = (UPO, DQO, CAS, SHO/SIPD, CTG, FDM, FWG, AWS, PCG/PEA, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **快慢环带宽分离**：画像更新只发生在慢环（≤ f_slow），不得进入实时快环；慢环永不改写快环安全包络；
(iii) **故障优先降级**：任一度量故障（沉默/缺相/退磁/换相误差/过热）→ 先把画像对证据的权重退回均匀（等价 R69），再谈优化；
(iv) **反锁死纪律**：任何画像不得单独否决 k 个正交证据源的一致结论；画像的证据权重上界被弱磁调度钳制在 w_max<1。

**定义 311（用户画像状态）** θ_u = (θ_d, θ_q)：θ_d ∈ ℝ^{d_d} 为稳定轴（领域专长、语言/生理能力、基线诚实度、偏好），慢变；θ_q ∈ ℝ^{d_q} 为任务轴（当前意图、当前对情境的知识、注意力/参与度、当前话题可靠度），可快变。两个先验分开：p(θ_d) 慢更新、p(θ_q|θ_d) 快更新。

**定义 312（用户画像观测器 UPO / 反电动势）** 观测模型 y_t = h(θ_u, ξ_t) + n_t，y_t 为交互响应签名（回答内容、延迟、纠正、注视/姿态）。定义「反电动势/激励强度」 E_t = ‖∂h/∂θ_q‖_Σ · u_t，u_t 为用户主动响应幅度。慢环用带遗忘的 EKF/粒子滤波估计 θ̂_u。关键：**E_t→0（用户被动/沉默）时观测器无法改善估计，误差协方差退化为先验**——冷启动盲区（对应电机静止无 back-EMF）。

**定义 313（d/q 解耦算子 DQO）** 把交互动作/证据投影到 d 轴（画像刻画动作 a_d）与 q 轴（任务动作 a_q）：a = Π_d a + Π_q a，Π_d Π_q = 0。只有 a_q 收益进入任务目标；a_d 成本进入「励磁预算」而不计任务收益。证据加权 w_i(θ_u) 同样做 dq 分解，避免 d 轴「了解你」的置信泄漏到 q 轴「能不能做」的推断。

**定义 314（级联架构 CAS）** 三环：任务快环（继承 R69，>100Hz）、画像中环（θ_q，~1–10Hz）、画像慢环（θ_d，≪1Hz）。带宽满足 ω_fast ≫ ω_mid ≫ ω_slow；每环只读上一环的**已发布快照**（带版本号），不反向写。

**定义 315（启动与交接 SHO / 强迫换相）** 冷启动/失锁后进入 open-loop 模式：用**无画像的均匀先验 + R69/R68 保守策略**（强迫换相）；同时注入**显著性初始探测 SIPD**（定义 320），使 E_t 尽快超过交接门限。交接条件（带迟滞与最小驻留）：E_t ≥ E_hand 且画像 ECE ≤ τ_ece 且连续 m 个慢环周期稳定 → 切 closed-loop。回切条件对称（E_t < E_hand − δ_h 或 ECE 越界）。**迟滞+驻留 = 防抖（无 Zeno 切换）。**

**定义 316（换相时刻 CTG）** 给定 θ̂_u 与任务假设集合，换相 = 在正确时刻切换证据源/问句/任务假设。定义换相表 T: (θ̂_u, s) → τ_switch 与换相守则：仅当 (a) 估计已更新且版本一致、(b) 安全包络允许、(c) 预期收益增益 > 抖动/切换成本 才换相。六步离散换相是 T 取离散值的特例；R69 的「按模态选源」是 T 的静态版。

**定义 317（故障检测与分离 FDM）** 残差 e = (e_Hall, e_phase, e_demag, e_comm, e_therm)：e_Hall 非响应/掉线（无信号）；e_phase 某交互通道被阻断；e_demag 能力/可靠度下降（同激励下响应质量系统性下降）；e_comm 换相误差（交互质量出现与换相周期同频的脉动）；e_therm 交互过热（单位时间交互量×成本超热预算）。在 A100–A104 下五类签名在残差空间可分；降级：e_Hall→退回强迫换相；e_phase→屏蔽该通道并重算 VoI；e_demag→对 θ̂ 做可靠度降额；e_comm→校正换相表并回退最近一次换相；e_therm→强制冷却（限流），把 R69 交互预算升级为带热积分的热保护。

**定义 318（弱磁反锁死 FWG）** 画像证据权重上界 w_profile = clamp(w_0·(1 − ψ(contradiction, urgency)), w_min, w_max)，ψ 随「证据-画像矛盾度」与「任务紧迫度」单调增。⇒ 冲突/高压时画像被主动弱化，新证据可主导；这是「画像不得单独否决 k 源一致」的连续版本。

**定义 319（抗积分饱和 AWS）** 画像积分项 I_θ 在通道饱和（e_Hall/e_phase）期间冻结，重连后以斜坡 r_aw 有界恢复：‖Δθ̂‖ ≤ r_aw·Δt，防止「恢复踢」。

**定义 320（显著初始探测 SIPD）** 与 R69 的 VoI 不同，SIPD 收益按**画像后验熵**算：g_sipd* = argmax_g [I(θ_u; y|g) − c(g)]，s.t. 安全 + 最小激励原则（不得为省事而拷问用户）。这是定义 298 在 θ_u 维度上的对偶。

**定义 321（画像校准门 PCG）** 在 R69 的 MCG 基础上增加源维度校准：画像各条件（分领域/话题/人群）的 ECE 与可靠图需过门；越界 ⇒ 该条件退化为均匀先验（等价 R69），绝不让未校准画像驱动加权。**这是 MCG 的「源维度」升级。**

**定义 322（画像证据审计 PEA / VQAuditor-P）** 审计：画像是否被用于自我确认（循环论证）、单次交互是否越权更新了画像、是否发生刻板超范围推断、隐私最小化是否满足（存了什么、留多久）、故障期间是否仍用旧画像。结论回灌 AuditBuf，成为下一轮 FWG/CTG 先验。

**定义 323（画像投毒与干扰集 ℰ_profile）** 画像漂移（人变了画像不跟）、画像自确认（只问符合画像的问题）、冒充/共谋（他人代答、跨会话串扰）、故意沉默（模拟 Hall 失效诱使系统退回易攻击的强迫换相）、迟到证据（过期信息回灌）。并入 AIC：ℰ_PERSONA = ℰ_FLUID × ℰ_profile。

**定义 324（证书 J_PROFILE）** J_PROFILE = (J_FLUID, profile_ece_by_ctx, handover_state, e-vector, w_profile_max_used, thermal_integral, profile_log_hash, privacy_minimality_flag, persona_ver)。Valid ⇔ Valid(J_FLUID) ∧ 画像 ECE 过门 ∧ 未被单源越权更新 ∧ 热预算未越界 ∧ 隐私最小化满足。

**定义 325（时序耦合）** 画像慢环周期 T_slow 与交接驻留 m 共同决定「失锁恢复时间」；T_slow 太大则画像陈旧，太小则违反带宽分离。约束 T_slow ≥ c/ω_fast。

**定义 326（严格包含关系）** 当 θ_u 均匀（无画像信息）、交接未完成（始终强迫换相）、无故障时，PERSONA-FOC 逐指令退化为 FLUID-RAS（R69）；再叠加「永不交互」退化为 CALM-RAS（R68）。⇒ 三层是同一控制器的分辨率递增，而非并列黑箱。

# IP-264 UPO：无感观测器（反电动势=激励强度；低激励不失明就乱估）
class UserProfileObserver:
    def __init__(self, ekf, forget=0.98):
        self.ekf, self.forget = ekf, forget            # θ = (θ_d, θ_q)
    def excitation(self, dhdq, u):                     # E_t ∝ 作用量×响应
        return norm(dhdq @ self.P @ dhdq.T) * norm(u)
    def update(self, y, xi, dt):
        E = self.excitation(self.ekf.jac_theta(xi), u=responsiveness(y))
        if E < E_BLIND:                                # 反电动势过低 → 不更新(等同无感失明)
            return self.ekf.snapshot(), E
        self.ekf.predict(dt); self.ekf.update(y, xi, forget=self.forget)
        return self.ekf.snapshot(), E

# IP-265 DQO：d/q 解耦，了解你 ≠ 把事做成
def dq_project(a, theta_hat):
    a_d = Pi_d(a)          # 画像刻画动作：只花励磁预算
    a_q = Pi_q(a)          # 任务动作：产生任务收益
    return a_d, a_q

# 每环只读上一环已发布快照(带版本号)，慢环永不写快环安全包络

class StartupHandover:

        self.state, self.dwell = 'OPEN_LOOP', 0
    def step(self, E, ece_ok):
        if self.state == 'OPEN_LOOP':
            self.dwell = self.dwell + 1 if (E >= self.E_hand and ece_ok) else 0
            if self.dwell >= self.m_dwell: self.state = 'CLOSED_LOOP'
            else: return 'OPEN_LOOP', sipd_probe()    # 均匀先验+R69保守 + 主动激励
        else:
            if E < self.E_hand - self.delta_h or not ece_ok:
                self.state, self.dwell = 'OPEN_LOOP', 0
        return self.state, None

# IP-269 CTG：换相时刻（何时切换源/问句/假设）
def commutation_table(theta_hat, s, gain_pred):
    tau = T_lookup(theta_hat, s)
    return tau if gain_pred(tau) > chatter_cost(theta_hat, s) else None

# IP-270 FDM：五类故障残差分离 + 对应降级
def fault_detect(e, tau):                                # A100-A104 可分离
    flags = {name: (res > tau[name]) for name, res in e.items()}
    if flags['Hall']:  return 'OPEN_LOOP'                # 退回强迫换相
    if flags['phase']: drop_channel(flags['phase']); recompute_voi()
    if flags['demag']: de_rate_profile(flags['demag'])   # 可靠度降额
    if flags['comm']:  rollback_last_commutation()
    if flags['therm']: throttle_interaction()            # 热保护=交互预算升级
    return 'OK'

# IP-271 FWG：弱磁反锁死
def field_weakening(w0, contradiction, urgency):
    return clamp(w0 * (1 - psi(contradiction, urgency)), W_MIN, W_MAX)  # W_MAX<1

# IP-272 AWS：抗积分饱和（防恢复踢）
def anti_windup(I_theta, saturated, dt, r_aw):
    return I_theta if saturated else I_theta + clamp(delta, -r_aw*dt, r_aw*dt)

    # ---- 快环：R69 的 FLUID 闭环，仅把证据加权换成 per-source ----
    U_ale, U_epi, modes = M.fluid.decompose(M.fmp.sample(obs, M.K(obs)))
    if probe is not None:                                # SIPD：主动激励补冷启动
        M.cia.execute(probe, target='theta_u')
    pair = M.cia.select_pair(modes, weights=w_prof)      # 源按画像加权
    g    = M.mint.choose(pair, modes, budget=M.budget)
    if g is not None: U_epi = M.fluid.update(modes, M.cia.execute(g), w_prof)
    # ---- 决策沿用 R69/R68 退避（安全侧不让步）----
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0)))
    k_cert = M.c_ras_wm.certified_prefix(...)
    if mode_deg == 'OPEN_LOOP': lam, k_cert = max(lam, 0.8), min(k_cert, k_cal_shrink(...))
    M.pea.submit(theta_hat, w_prof, e, g)                # 画像审计 + 隐私最小化
    return k_cert, lam, select_mode(modes, U_epi, lam), (theta_hat, state, w_prof)
```

## 3. 推导

**引理 19（无感观测器的持续激励条件）** 画像估计误差的 Fisher 信息 J(θ_u)=Σ_t E_t²/σ²。若 E_t 在 θ 各维上持续激励（PE），则 ‖θ̂−θ‖²→O(1/J)；若 E_t=0（用户静止/沉默），协方差保持先验、估计不可改善。系：**冷启动必须由显著性初始探测（SIPD）注入激励**，被动等待等于永远失明——这解释了为什么「不问就永远不懂你」。

**引理 20（dq 正交性保护任务信号）** 若 Π_d Π_q=0 且权重满足 w=w_d⊕w_q 的可分结构，则 d 轴画像更新对 q 轴任务推断的一阶影响为 0；画像「励磁」的交互成本只进励磁预算，不进任务收益。⇒ 「了解你」的投入不会伪装成「推进任务」的产出——直接补 R69 无法区分二者的缺陷。

**引理 21（迟滞交接的无抖性）** 带迟滞 δ_h≥0 与最小驻留 m≥1 的 SHO 状态机不存在有限时间内的无限次切换（排除 Zeno）；交接完成后闭环误差 ≤ 开环误差，交接瞬间的指令跳变被驻留+斜坡界住。⇒ 强迫换相到无感闭环是**连续且可证无突变**的。

**引理 22（弱磁的反锁死界）** 若 w_profile ≤ w_max<1 且随矛盾度/紧迫度单调不增，则对任意持续有信息的证据流，错误画像假设不能成为吸收态：其最大后验权重被 1−w_max 的证据通道持续挑战，画像-真实差距被弱磁调度界住。⇒ 只要人还在给信号，系统就不能把他永久锁进一张错画像。

**引理 23（故障签名可分性）** 在 A100–A104（五类残差在不同方向/频带上占优）下，e_Hall/e_phase/e_demag/e_comm/e_therm 可由 LDA/频带分离；任一故障的降级不掩盖另一故障。⇒ R69 的「k 源一致」可以在**逐源**层面安全降额，而不是整包作废。

**引理 24（抗饱和有界跳动）** 饱和期间冻结积分、重连后斜坡限制使 ‖θ̂(t_reconnect+) − θ̂(t_reconnect−)‖ ≤ r_aw·Δt_reconnect，恢复瞬态不发散、不「踢」。⇒ 沉默/掉线不会在回来时造成画像突变。

**定理 18（PERSONA-FOC 严格包含 FLUID-RAS / CALM-RAS）** 在均匀画像、交接未完成（恒强迫换相）、无故障时，PERSONA-FOC 快环与 R69 逐指令相同，慢环输出退化为常数均匀权重；再叠加「永不交互」退化为 R68。故三层为分辨率递增：安全侧永不弱于 R69/R68。

**定理 19（无锁死与有界画像差）** 在引理 19–24 与「周期性显著性重探测」（每 ≥ T_reprobe 至少一次 SIPD）下，对任意有界漂移的用户 θ_u(t)，画像误差与画像对证据的偏置均保持有界；系统不存在「高置信度、大画像差」的稳定吸收态。⇒ 否定本轮最大风险的**结构性**可能（但概率性的观测器发散仍见 §6）。

**定理 20（交互热安全与快环隔离）** 热保护把单位时间交互量钳制在 ∫q dt ≤ Q_max；慢/中环的任何更新不进入快环，故 R69/R68 的实时预算与安全包络不变；换装/提交不变式（R68 定理 15、R69 定理 17）保持。⇒ 画像层是「外挂慢器官」，不会拖垮或越权控制快环。

## 6. 本轮最大风险

**一句话**：PERSONA-FOC 的全部收益押在「画像观测器不在低激励下发散、且其置信度诚实」这一前提上——一旦观测器在低激励、高紧迫（弱磁被紧迫度绕开）或人为沉默/冒充下**发散却自信**，d/q 解耦与弱磁都只是把错误包装得更精致：系统会把一个正在改变的人永久锁进一张错误画像，还会用这张画像去选问题、解读回答、塑造他，并声称「这是他自己说的」——**画像错，不是问错，是把一个人看错，而且让他慢慢变成你看到的那个样子。**

**次级风险与缓解**：
1. **冷启动盲区**（低激励无法估计）→ SIPD 主动注入激励 + SHO 迟滞交接，绝不带着未验证画像进闭环；
2. **画像自确认/刻板锁死** → FWG 上界 w_max<1 + 周期性重探测 + 「画像不得单独否决 k 源一致」纪律；
3. **观测器发散但高置信** → FDM 残差（尤其 e_comm 脉动）+ PCG 分上下文 ECE 门 + PEA 循环论证审计，越界即退回均匀先验；
4. **掉线恢复「踢」** → AWS 冻结积分 + 斜坡恢复（引理 24）；
5. **画像被武器化（个性化操纵）与隐私侵犯** → 隐私最小化不变式 + 审计 + 禁止以画像优化「说服力」，只允许优化「证据加权与任务效率」；
6. **假沉默/冒充诱退强迫换相** → e_Hall 需与跨会话、生理/上下文证据交叉验证，单一沉默不得触发降级（证据纪律的最小版）。

# IP-264 UPO：无感观测器（反电动势=激励强度）
class UserProfileObserver:
    def excitation(self, dhdq, u): return norm(dhdq @ self.P @ dhdq.T) * norm(u)
    def update(self, y, xi, dt):
        E = self.excitation(self.ekf.jac_theta(xi), u=responsiveness(y))
        if E < E_BLIND: return self.ekf.snapshot(), E       # 低激励：等同无感失明
        self.ekf.predict(dt); self.ekf.update(y, xi, forget=0.98)
        return self.ekf.snapshot(), E

# IP-265 DQO：了解你 ≠ 把事做成
def dq_project(a):
    return Pi_d(a), Pi_q(a)                                 # d=励磁预算, q=任务收益

# IP-267 SHO + IP-268 SIPD：强迫换相 → 无感闭环（迟滞防抖）
def handover_step(st, E, ece_ok, E_hand, delta_h, m_dwell):
    if st.state == 'OPEN':
        st.dwell = st.dwell + 1 if (E >= E_hand and ece_ok) else 0
        if st.dwell >= m_dwell: st.state = 'CLOSED'; return 'CLOSED', None
        return 'OPEN', sipd_probe()                         # 均匀先验+R69保守+主动激励
    if E < E_hand - delta_h or not ece_ok: st.state, st.dwell = 'OPEN', 0
    return st.state, None

def commutation_table(theta_hat, s, gain_pred):
    tau = T_lookup(theta_hat, s)
    return tau if gain_pred(tau) > chatter_cost(theta_hat, s) else None

def fault_detect(e, tau):
    if e['Hall']  > tau['Hall']:  return 'OPEN'             # 退回强迫换相
    if e['phase'] > tau['phase']: drop_channel(); recompute_voi()
    if e['demag'] > tau['demag']: de_rate_profile()         # 可靠度降额
    if e['comm']  > tau['comm']:  rollback_last_commutation()
    if e['therm'] > tau['therm']: throttle_interaction()    # 热保护
    return 'OK'

# IP-271 FWG / IP-272 AWS
def field_weakening(w0, contra, urgency):
    return clamp(w0 * (1 - psi(contra, urgency)), W_MIN, W_MAX)   # W_MAX < 1
def anti_windup(I, saturated, dt, r_aw):
    return I if saturated else I + clamp(delta, -r_aw*dt, r_aw*dt)

# IP-275 主闭环（慢环画像 / 快环继承 R69；严格包含 R68/R69）
def PERSONA_FOC_round(M, obs):
    theta_hat, E = M.upo.update(obs.y, obs.xi, dt)          # 慢/中环，不进快环
    e = M.fdm.residuals(obs, theta_hat)
    mode_deg = M.fdm.detect_and_mitigate(e)                 # 故障优先降级
    state, probe = handover_step(M.sho, E, M.pcg.ece_ok(theta_hat), M.E_hand, M.delta_h, M.m)
    w_prof = (field_weakening(M.base_w, contradiction(e), urgency(obs))
              if state == 'CLOSED' else W_UNIFORM)          # 强迫换相=均匀先验
    U_ale, U_epi, modes = M.fluid.decompose(M.fmp.sample(obs, M.K(obs)))
    if probe is not None: M.cia.execute(probe, target='theta_u')
    pair = M.cia.select_pair(modes, weights=w_prof)         # 源按画像加权
    g    = M.mint.choose(pair, modes, budget=M.budget)
    if g is not None: U_epi = M.fluid.update(modes, M.cia.execute(g), w_prof)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0)))
    k_cert = M.c_ras_wm.certified_prefix(...)
    if mode_deg == 'OPEN': lam, k_cert = max(lam, 0.8), min(k_cert, k_cal_shrink(...))
    M.pea.submit(theta_hat, w_prof, e, g)
    return k_cert, lam, select_mode(modes, U_epi, lam), (theta_hat, state, w_prof)
```

## 4. 推导

**引理 19（无感观测器的持续激励条件）** Fisher 信息 `J(θ_u)=Σ_t E_t²/σ²`。若 `E_t` 在 θ 各维持续激励（PE），则 `‖θ̂−θ‖²→O(1/J)`；若 `E_t=0`（沉默/静止），协方差保持先验、估计不可改善。系：冷启动必须由 SIPD 注入激励，被动等待等于永远失明——「不问就永远不懂你」。

**引理 20（dq 正交性保护任务信号）** 若 `Π_dΠ_q=0` 且 `w=w_d⊕w_q` 可分，则 d 轴画像更新对 q 轴任务推断的一阶影响为 0；励磁成本只进励磁预算，不进任务收益。⇒ 杜绝「画像很丰满、任务没进展」。

**引理 21（迟滞交接无抖性）** 带迟滞 `δ_h≥0` 与最小驻留 `m≥1` 的 SHO 状态机无有限时间无限切换（排除 Zeno）；交接后闭环误差 ≤ 开环误差，跳变被驻留+斜坡界住。⇒ 强迫换相→无感闭环连续、无突变。

**引理 22（弱磁反锁死界）** 若 `w_profile≤w_max<1` 且随矛盾度/紧迫度单调不增，则对任意持续有信息的证据流，错误画像假设不能成为吸收态：其最大权重被 `1−w_max` 的证据通道持续挑战，画像-真实差距被弱磁调度界住。⇒ 只要人还在给信号，就不能被永久锁进错画像。

**引理 23（故障签名可分性）** 在 A100–A104（五类残差在不同方向/频带占优）下五类故障可分离，任一降级不掩盖另一故障。⇒ R69 的「k 源一致」可按源安全降额，而非整包作废。

**引理 24（抗饱和有界跳动）** 饱和期冻结积分 + 重连斜坡 ⇒ `‖θ̂(t+) − θ̂(t−)‖ ≤ r_aw·Δt`，恢复瞬态不发散、不「踢」。⇒ 沉默/掉线不造成画像突变。

**定理 18（PERSONA-FOC 严格包含 FLUID-RAS / CALM-RAS）** 均匀画像、恒强迫换相、无故障时，快环与 R69 逐指令相同，慢环退化为常数均匀权重；再叠加「永不交互」退化为 R68。⇒ 三层是同一控制器分辨率递增，安全侧永不弱于旧层。

**定理 19（无锁死与有界画像差）** 在引理 19–24 与周期性显著性重探测下，对任意有界漂移的 `θ_u(t)`，画像误差与对证据的偏置均保持有界；系统不存在「高置信度、大画像差」的稳定吸收态。⇒ 结构性否定本轮最大风险（概率性观测器发散仍见 §7）。

**定理 20（交互热安全与快环隔离）** 热保护钳制 `∫q dt ≤ Q_max`；慢/中环不进入快环，故 R69/R68 实时预算与安全包络不变；换装/提交不变式（R68 定理 15、R69 定理 17）保持。⇒ 画像层是「外挂慢器官」，不拖垮、不越权。

## 7. 本轮最大风险

**一句话**：PERSONA-FOC 的全部收益押在「画像观测器不在低激励下发散、且其置信度诚实」这一前提上——一旦观测器在低激励、高紧迫（弱磁被绕开）或人为沉默/冒充下**发散却自信**，d/q 解耦与弱磁都只是把错误包装得更精致：系统会把一个正在改变的人永久锁进一张错误画像，还会用这张画像去选问题、解读回答、塑造他，并声称「这是他自己说的」——**画像错，不是问错，是把一个人看错，而且让他慢慢变成你看到的那个样子**。

**次级风险与缓解**：冷启动盲区（SIPD 主动激励 + SHO 迟滞交接）；画像自确认/刻板锁死（FWG 上界 w_max<1 + 周期重探测 + 画像不得单独否决 k 源一致）；观测器发散但高置信（FDM 残差 + PCG 分上下文 ECE + PEA 循环论证审计，越界即退均匀先验）；掉线恢复「踢」（AWS 冻结积分 + 斜坡）；画像被武器化与隐私（隐私最小化不变式 + 审计 + 只允许画像优化证据加权/任务效率，禁止优化说服力）；假沉默/冒充诱退（e_Hall 需跨会话与上下文交叉验证，单一沉默不得触发降级）。
