# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感驱动研究循环第 1 轮（新循环）；本轮灵感：「视觉定位」×「桌面操作」）

> 第 59 轮把证据承诺一路钉到执行层物理：BUQ 在线辨识电机不确定性、ERTC 契约化嵌入式实时性、EEIS 把 δ_f 编译成阻抗参数、CLEP 让执行实测回流证据层。但它仍默认了三个更深的前提：**其一，任务帧是给定的**——`cp.region`、`b_r`、抓取位姿仿佛天然与观测同坐标系；**其二，视觉定位是一次性的、被动的**——先看清、再行动，看清的结果在行动期间保持有效；**其三，视觉证据与物理接触证据可以互相替代**——「看起来能抓」和「力上确实抓住了」被混为一谈。桌面操作恰好把这三个前提同时击穿：**视觉定位**在桌面尺度上是**各向异性、多假设、易受重复纹理/透明反光/自遮挡影响**的，真正的对象不是全局 6-DoF 位姿，而是「接触帧/抓取帧/放置帧是否足以做决定」；**桌面操作**是**视觉-动作强耦合**的——机械臂自身遮挡、物体被推动、桌面反光随视角变化，动作会改变视觉证据，而接触又能反过来为定位提供最硬的物理约束。本轮核心命题：**「把视觉定位从『全局位姿点估计』降维为『任务帧可辨识性 + 支撑面锚定』；把接触从『污染视觉的干扰』升级为『合法的定位探针』；并用非对称律钉死：视觉定位只能收紧安全约束，绝不能替代接触/力证据去放松约束。」**

核心矛盾：
- **H38（任务帧错配·各向异性安全）**：桌面任务的安全不取决于对象质心的毫米级精度，而取决于**接触点相对于对象表面/边缘/支撑面的关系**。视觉定位的协方差在深度方向、绕光轴方向、以及沿弱纹理平面方向高度各向异性；一个在全局坐标系里「很小」的旋转误差，经过 10~20 cm 的臂端杠杆会被放大成厘米级接触点偏移。更严重的是**感知别名**：重复木纹、瓷砖缝、透明杯壁、镜面托盘会让多个位姿假设同时高分且彼此一致地错。若继续用「位姿点估计 + 各向同性误差球」喂给证据层，安全论证建立在一个**高置信的错误帧**上。
- **H39（视觉-动作闭环·接触既是污染也是探针）**：桌面操作不是「先感知后执行」的开环序列。机械臂接近会遮挡目标，夹爪进入视野会改变深度图，接触会推动/旋转/压缩物体，透明物体的视觉边缘随背景变化——**视觉证据的分布依赖于已执行的动作**。把动作前的视觉位姿当成静止真值，等价于忽略「动作诱导的场景变化」。反过来，接触/力/本体感觉提供了**介入式（interventional）**的定位约束：轻触一下表面，能比多看十帧更有效地消解深度与法向歧义。关键是把「接触诱导位移」建成状态，而不是噪声。
- **H40（定位证据越权·先验放松）**：视觉定位天然带有强先验——曼哈顿世界、水平桌面、物体直立、支撑面平面。这些先验在大多数桌面成立，但在**倾斜桌面、软垫、非平面堆叠、透明/反光、被遮挡边缘**处会系统性失效。若系统用「视觉先验说这里是空的」去放宽 EEIS 的力限幅，或用「视觉帧看起来稳定」去替代接触证据满足不可逆动作的安全门，就是用**感知先验**冒充**物理事实**。必须执行单向安全律：视觉帧证据只能**收紧**可行动作集，不能**放松**力/稳定性/不可逆门。

## 0. 直觉与动机

**灵感 1（视觉定位 → 任务帧可辨识性 TFI）**
直觉：桌面操作真正需要的不是「物体在 base 系下的 6-DoF 位姿」，而是**任务帧**：抓取帧（夹爪接近方向、闭合方向、抓取宽度）、推触帧（接触点、表面法向、摩擦锥）、放置帧（支撑面、放置中心、朝向）。这些帧只需要**决策充分**，不需要**数值精确**：如果任务帧信念集合里的每一个候选帧都让「抓/不抓」「碰/不碰」「放/不放」给出同一个安全符号，并且离决策边界有足够裕度，那么再高的位姿精度对本次决策也没有信息量；反之，若两个候选帧分别落在「抓得住」和「抓空/撞桌」两侧，即使全局位姿误差只有几毫米，任务帧也**不可辨识**。这把第 42 轮「决策等价证书」从「位姿误差球」平移到「任务帧决策划分」：核心量从 `‖pose−pose*‖` 变成**歧义度 A**（信念集合中与多数决策不一致的质量）与**帧裕度 m**（到决策边界的最小距离）。实现上用多假设/粒子 + 共形校准得到带覆盖保证的帧集合，用可微的几何/碰撞/支撑谓词计算决策符号，输出**帧充分性证书 Cert_frame**，而不是再报一个「平均位姿误差」。

**灵感 2（桌面操作 → 支撑面锚定 SSA）**
直觉：桌面是机器人视野里**最大、最刚性、最容易反复观测的标定板**，而且重力给了它一个绝对方向。把支撑面识别出来，等于免费获得三个强约束：桌面法向 ≈ 重力反方向、物体必须「坐在」平面上、相机外参与桌面坐标系之间存在可在线校准的关系。于是 6-DoF 对象位姿可以降维为「桌面平面内的 (x, y, yaw) + 高度 h + 可选倾斜」，深度方向与滚转/俯仰由支撑面锚定，视觉只需解决平面内平移/旋转与少量形变。更关键的是可以构造**物理似然残差**：物体点云穿过桌面（穿透）、悬空、尺度与已知类别不一致、支撑接触面积过小——这些是纯视觉置信度无法发现的**物理不合理性**。SSA 用 `(多视角深度 + 重力 + 腕部位姿)` 联合在线校准桌面-相机-手眼变换，并用 `r_phys` 对视觉帧进行**物理否决**：先验再自信，只要物体在物理上「飘着/穿模」，就必须拒绝该帧。桌面操作的特殊性还在于透明/反光表面：深度大面积缺失时，SSA 应输出「支撑面不可信」而不是硬猜一个平面。

**灵感 3（接触耦合定位 CCL）**
直觉：在桌面操作里，**接触不是定位的敌人，而是最后的裁判**。视觉可以告诉你「杯子大概在这里」，但只有轻触才能告诉你「杯壁的法向朝哪、边缘在哪、它是不是已经滑动、桌面是不是真的水平」。把接触当成一次**干预实验**：在 EEIS 的阻抗/力限幅保护下，用一个受控的轻触动作去最大化关于任务帧的信息，同时把「接触导致的物体位移/形变」显式建成状态 `d_t`，而不是当成观测噪声。这样，帧估计就有两个时相：**接触前视觉帧**（用于规划接近与选择探针）与**接触后物理锚定帧**（用于不可逆抓取/下压/放置）。两者必须带**帧版本号 κ**：一旦接触改变物体状态，旧视觉帧立即作废，任何用旧帧背书的动作都必须重新过门。CCL 的更新不是普通贝叶斯 `p(x|y)`，而是干预感知的 `p(x|do(touch), y)`——因为动作改变了状态分布本身。

**灵感 4（主动帧辨识 AFI + 定位预算 B_loc）**
直觉：如果帧不充分，最蠢的做法是「硬着头皮抓」，次蠢的做法是「无限看下去」。正确做法是把「换视角、转腕、改变照明、轻推一下」当成**有成本的定位动作**，用信息增益与风险的比值来选：`VOI_loc(a) = IG_frame(a) − λ_t·t(a) − λ_e·energy(a) − λ_r·risk(a)`。在桌面场景，挪动腕部相机 10 cm 往往比换一个全局视角更能消解深度歧义；一次 2 N 的轻触往往比 20 帧图像更能确定表面法向。于是第 59 轮的 PCE+++ 四预算扩展为 PCE++++：新增 **B_loc**（视角数、定位时长、标定新鲜度、运动模糊预算），并规定它与其他预算**硬隔离、不可挪用**：不能为了多看几眼而挤占执行安全余量，也不能为了赶时间而跳过必要的接触锚定。若 B_loc 耗尽且帧仍不充分，系统必须退化为「带阻抗保护的试探性接触」或协商/停，而不是盲抓。

**灵感 5（五者合流 → 帧接地操作闭环 FGML）**
直觉：TFI 回答「帧够不够做决定」，SSA 回答「支撑面/重力/物理合理性是否把帧钉住」，CCL 回答「接触如何作探针、如何作废旧帧」，AFI 回答「下一步看哪里/碰哪里最值」，FEG 回答「帧证据能不能过门」。合起来是一个**帧接地操作闭环**：先锚定支撑面 → 建立任务帧信念集合 → 若歧义大则主动获取视角/轻触 → 接触后更新帧版本 → 过帧证据门 → 再交给第 59 轮的 EEIS 编译阻抗参数 → 执行 → 用 EV-exec 与 EV-frame 双证据回流。关键安全结构是**非对称**的：视觉帧证据可以把「可行动作集」缩小，可以把风险上界抬高，可以触发更多探针；但它不能把力限幅放宽，不能把不可逆动作从「需要接触证据」降级为「视觉看起来可以」，也不能用「帧一致」去抵消「力/接触矛盾」。

## 1. 形式化定义（增量：定义 153–161）

**定义 153（任务帧与可辨识性 TFI）** 任务帧 `F = (R_F ∈ SO(3), t_F ∈ R³, s_F > 0, Π_F)`，其中 `Π_F` 是任务相关轴（接近轴、闭合轴、支撑法向、摩擦锥轴）。帧信念集合 `B_F = {F : s_Frame(F; D_vis, D_kin) ≤ r̂_F}`，`s_Frame` 为共形非一致性分数（重投影 + 支撑面残差 + 物理残差 + 多假设一致性），`r̂_F` 为在标定场景上按覆盖率 `1−α_F` 校准的阈值。对候选动作族 `A` 与 `F∈B_F`，定义决策谓词 `g_a(F) ∈ {−1,0,+1}`（危险/可弃权/安全）与到决策边界的符号距离 `m_a(F)`。定义帧歧义度 `A_a(B_F) = ∫ 1[g_a(F) ≠ majority_g] dB_F`，帧裕度 `m_a(B_F) = min_{F∈B_F} m_a(F)`。若 `A_a ≤ θ_A`、`m_a ≥ m_min`、`B_F` 覆盖率 `≥1−α_F`，称任务帧对动作 `a` **充分**，输出证书 `Cert_frame = (region_id, a, κ, model_version, A_a, m_a, coverage, r_phys, calib_version, τ_frame)`。注意：`Cert_frame` 只证明「决策充分」，不证明「位姿精确」。

**定义 154（支撑面锚定 SSA)** 由重力 `g`（IMU）与多视角深度得到支撑面 `π_s = (n_s, d_s)`，`n_s ≈ −g/‖g‖`。联合在线标定 `T_table←sensor` 与手眼 `T_sensor←ee`，目标：
```
min_{T_table←sensor, T_sensor←ee} Σ_i ρ_Huber( n_sᵀ(T_table←sensor T_sensor←ee T_ee←wrist(i) p_i) + d_s )
      + λ_rep Σ_j ‖π( T_table←sensor x_j ) − u_j‖²
s.t.  ‖n_s‖=1,  n_sᵀ g < 0
```
对象位姿降维为 `(x, y, yaw, h, tilt_opt)`，其中 `h` 由支撑面与对象高度先验约束。定义物理似然残差 `r_phys = λ_pen·penetration + λ_float·floating + λ_scale·scale_inconsistency + λ_support·support_area_deficit`。若 `r_phys > θ_phys` 或支撑面内点率 `< θ_inlier`，则 SSA 输出 `anchored=false`，`B_F` 不得使用支撑面先验，且不得据此放宽任何力约束。

**定义 155（接触耦合定位 CCL）** 联合状态 `x_t = (F_{o,t}, d_t, c_t)`，`F_o` 为对象/接触任务帧，`d_t ∈ R³` 为自上次接触快照以来的对象位移，`c_t ∈ {free, contact, slip, deform}`。观测模型：
```
y_vis = h_vis(F_o, d; o_t) + v_vis,      o_t 为自遮挡/缺失掩码
y_kin = h_kin(F_o, d, c; u_t) + v_kin,   u_t 为关节/力/阻抗指令
```
接触干预模型：`d_{t+1} = d_t + 1[c_t=contact]·(J(q)Δq + w_slip) + 1[c_t=deform]·Δ_deform`。更新采用干预感知形式 `p(x_t | do(a_t), y_t) ∝ p(y_t | x_t, do(a_t)) p(x_t | do(a_t))`。每次状态转移 `free→contact` 或检测到 `slip/deform` 时，帧版本 `κ ← κ+1`，旧 `Cert_frame` 标记 `stale`。定义接触探针 `a_touch = (p_contact, n_approach, F_touch, K_imp, t_dur)`，其可行域由第 59 轮 EEIS 的 `K_safe` 与力限幅给出；接触后帧证书 `Cert_frame^post` 必须携带 `κ_post` 与力/位移残差。

**定义 156（主动帧辨识 AFI）** 定位动作集合 `A_loc = {换视角, 转腕, 改变曝光/结构光, 受控轻触, 小幅推动}`。期望信息增益 `IG(a) = H(B_F) − E_{y~p(·|do(a))}[H(B_F | y)]`，可用粒子熵/Fisher 信息近似；定位成本 `cost_loc(a) = λ_t t(a) + λ_e energy(a) + λ_r risk(a)`。选择 `a* = argmax_{a∈A_loc^safe} [IG(a) − cost_loc(a)]`，仅当 `> θ_loc` 时执行。`A_loc^safe` 由「不违反 EEIS 稳定性/力约束、不进入未认证接触区、不使 B_loc 为负」定义。若 `B_F` 仍不充分且 `A_loc^safe` 中无正 VOI 动作，返回 `FRAME_INSUFFICIENT`。

**定义 157（帧证据门 FEG / EV-frame）** `EV-frame = (Cert_frame, κ, A_a, m_a, coverage, r_phys, τ_frame, stale, contact_probe_log, calib_version)`。证据门规则：
```
L0（仅接近，无接触）: Cert_frame.sufficient ∧ ¬stale
L1（可逆接触/试探）  : Cert_frame.sufficient ∧ m_a ≥ 0 ∧ r_phys ≤ θ_phys ∧ ¬stale
L2（不可逆抓取/下压/放置）:
    必须 Cert_frame^post.valid ∧ κ = κ_current ∧ 接触/力证据满足
    ∧ EV-frame 仅作一致性检查，绝不单独授权
```
非对称律：`EV-frame` 只能通过 `A_safe ← A_safe ∩ A_safe^frame` 缩小动作集，或通过抬高风险上界增加探针需求；不得用于增大 `F_max`、放宽 `δ_force`、降低 `m_min`、替代 `EV-exec`/`EV-xmodal` 佐证。若视觉帧与力/接触证据矛盾，**力/接触证据优先用于安全判定**，视觉帧只能触发复观测或标记 OOD。

**定义 158（帧约束跨模态对账 XMC++）** 帧不是独立观测模态，而是**约束模态**。定义帧诱导决策 `δ_frame(a) ∈ {safe, unsafe, abstain}` 与融合决策 `δ_fused(a)`；帧分歧
```
D_frame(r) = Σ_a w_a · 1[δ_frame(a)=unsafe ∧ δ_fused(a)=safe] · margin_gap(a)
```
只统计「帧说危险、融合说安全」的方向（保守方向），反向不计入放松；总对账 `D++ = D⁺ + w_frame·D_frame`。规则：(R1++) `D++ > θ_D++` ⇒ 后验加宽/增加探针；(R2++) `EV-frame` 不得进入 `EV-xmodal/EV-human` 佐证集；(R3++) 若 `κ` 不匹配或 `τ_frame > T_frame_renewal`，`EV-frame` 权重置零并触发复观测。

**定义 159（定位预算 B_loc 与 PCE++++）** `B_loc = (n_views_left, t_loc_left, calib_freshness, blur_budget, contact_probe_left)`。PCE++++ VOI：
```
voi_loc(π) = VOI_meta_pessimistic(π) − cost_exec(π) − cost_loc(π)
cost_loc(π) = λ_view·n_views(π) + λ_time·t_loc(π) + λ_calib·max(0, T_calib_max−calib_freshness)
              + λ_blur·max(0, blur(π)−blur_budget)
```
五预算 `B_probe/B_ft/B_ux/B_exec/B_loc` 单调消耗、硬隔离、不可挪用；任一耗尽 ⇒ 保守降级（缩小动作集/带保护轻触/绕行/协商/停）。`B_loc` 的消耗必须显式记账，且「多看」不得挤占「执行安全余量」。

**定义 160（帧证书 J_frame）** `J_frame = (Cert_frame_chain, κ_log, SSA_calib_log, view_probe_log, contact_intervention_log, conformal_thresholds, physical_residual_log, version, timestamp)`。验证条件：`κ` 单调不减；每个不可逆动作引用的 `Cert_frame^post` 的 `κ` 等于当前版本；`coverage ≥ 1−α_F`；`r_phys ≤ θ_phys`；标定版本未过期；`EV-frame` 与 `EV-exec` 时戳对齐。

**定义 161（帧接地操作闭环 FGML）** 算子 `FGML(M, task, δ_f^req)`：
```
① SSA:  π_s, T_table←sensor, r_phys ← anchor(gravity, depth, wrist_poses)
        if r_phys > θ_phys ∨ inlier < θ_inlier: anchored ← false
② TFI:  B_F, A_a, m_a ← frame_belief(obs, π_s, anchored)
③ AFI:  while (A_a > θ_A ∨ m_a < m_min) ∧ B_loc.viable():
             a ← argmax_{a∈A_loc^safe} [IG(a) − cost_loc(a)]
             if a is None or VOI ≤ θ_loc: break
             y ← execute_localization_action(a)      # 视角/轻触，受 EEIS 保护
             x, κ ← CCL.update(x, y, do(a))
             B_F, A_a, m_a ← TFI.update(x, y)
             B_loc.spend(a)
④ FEG:  EV-frame ← build_frame_evidence(B_F, A_a, m_a, r_phys, κ, τ_frame)
        gate ← frame_gate(EV-frame, contact_level)
        if gate = reject:
             if irreversible: return DEGRADE_FRAME / negotiate / stop
             else: enter guarded-touch branch with Cert_eeis
⑤ XMC++: M, fused, D++ ← reconcile_frame(M, EV-frame, other modalities)
⑥ EEIS:  K_safe, Cert_eeis ← compile_impedance(δ_f^req, fused, ξ_exec, b_r | frame)
        if K_safe = ∅: return DEGRADE_EXEC
⑦ CLEP:  dispatch / execute / collect EV-exec
⑧ Return: (M, fused, D++, EV-frame, EV-exec, Cert_eeis, Cert_frame)
```

### IP-152 TFI（任务帧可辨识性）

```python
class TaskFrameIdentifiability:
    def __init__(self, alpha_F=0.05, theta_A=0.05, m_min=0.01):
        self.alpha_F = alpha_F
        self.theta_A = theta_A
        self.m_min = m_min
        self.r_hat_F = None  # 共形阈值，标定场景上校准

    def build_frame_belief(self, obs, table_anchor):
        # 多假设：点云配准 + 平面/边缘 + 类别形状先验 + 深度补全
        hypotheses = self.multi_hypothesis_frames(obs, table_anchor)
        particles = []
        for F in hypotheses:
            s = self.nonconformity(F, obs, table_anchor)
            particles.append(Particle(F=F, w=s))
        # 归一化权重，截断到 s <= r_hat_F
        particles = self.truncate_by_conformal(particles, self.r_hat_F)
        return FrameBelief(particles)

    def nonconformity(self, F, obs, table_anchor):
        e_rep = self.reprojection_residual(F, obs)
        e_plane = self.support_plane_residual(F, table_anchor)
        e_phys = self.physical_residual(F, obs)   # 穿透/悬空/尺度
        e_hyp = self.hypothesis_consistency(F, obs)
        return self.w_rep*e_rep + self.w_plane*e_plane + self.w_phys*e_phys + self.w_hyp*e_hyp

    def decision_partition(self, B_F, action_family):
        # g_a(F) ∈ {-1, 0, +1}; m_a(F) 为到决策边界的符号距离
        return {a: [self.decision_predicate(F, a) for F in B_F] for a in action_family}

    def ambiguity_and_margin(self, B_F, a):
        signs = [self.decision_predicate(F, a) for F in B_F]
        maj = self.majority_sign(signs)
        A = sum(F.w for F, s in zip(B_F, signs) if s != maj)
        m = min(self.signed_margin(F, a) for F in B_F)
        return A, m

    def certificate(self, B_F, a, r_phys, kappa, calib_version, tau):
        A, m = self.ambiguity_and_margin(B_F, a)
        coverage = self.conformal_coverage(B_F)
        sufficient = (A <= self.theta_A and m >= self.m_min and
                      coverage >= 1 - self.alpha_F and r_phys <= self.theta_phys)
        return FrameCertificate(
            action=a, kappa=kappa, ambiguity=A, margin=m, coverage=coverage,
            r_phys=r_phys, calib_version=calib_version, tau=tau,
            sufficient=sufficient, model_version=self.model_version
        )
```

```python
class SupportSurfaceAnchor:
    def anchor(self, gravity, depth_views, wrist_poses, calib):
        # 1) 重力对齐粗筛平面
        n_grav = -normalize(gravity)
        planes = []
        for d in depth_views:
            planes += self.ransac_planes(d, normal_hint=n_grav)
        # 2) 平面与手眼联合鲁棒优化

        inlier = self.support_inlier_ratio(planes)
        anchored = (r_phys <= self.theta_phys and inlier >= self.theta_inlier)
        # 4) 降维任务帧：x,y,yaw,h(,tilt)
        reduced_dof = self.reduce_frame_dof(T_ts, planes)
        return TableAnchor(T_ts, T_se, planes, r_phys, inlier, anchored, reduced_dof)

    def physical_residual(self, planes, T_ts, depth_views):

        flt = self.floating_height(planes, T_ts, depth_views)
        scl = self.scale_inconsistency(planes, T_ts, depth_views)
```

### IP-155 AFI（主动帧辨识）

```python
class ActiveFrameIdentifier:
    def __init__(self, loc_budget, safety_envelope):
        self.B_loc = loc_budget
        self.env = safety_envelope

    def select(self, B_F, action_family):
        if not self.B_loc.viable():
            return None
        cands = []
        for a in self.action_family(action_family):
            if not self.env.permits(a):
                continue
            ig = self.expected_information_gain(B_F, a)
            cost = self.cost_loc(a)
            cands.append((a, ig - cost))
        if not cands:
            return None
        a, voi = max(cands, key=lambda x: x[1])
        return a if voi > self.theta_loc else None

    def expected_information_gain(self, B_F, a):
        # 粒子熵近似
        H0 = self.particle_entropy(B_F)
        H1 = self.expected_entropy_after(B_F, a)
        return H0 - H1

    def cost_loc(self, a):
        return (self.l_view*a.n_views + self.l_time*a.duration +
                self.l_calib*max(0, self.T_calib_max - a.calib_freshness) +
                self.l_blur*max(0, a.predicted_blur - self.B_loc.blur_budget))
```

**正确性定理（Frame-Grounded Manipulation Soundness, FGMS）**
假设 A51–A55（第 59 轮）成立；**(A56)** TFI：`B_F` 的共形覆盖 `≥1−α_F`，非一致性分数诚实，歧义/裕度估计不低报风险；**(A57)** SSA：支撑面内点率与物理残差能检出穿透/悬空/尺度不一致/非平面，漏检率 `≤δ_phys`；**(A58)** CCL：接触干预模型诚实，`κ` 在 `free→contact`、`slip`、`deform` 时正确递增，力/运动学观测误差有界；**(A59)** AFI：期望信息增益是真实增益的上界（不乐观），所有定位动作在 `A_loc^safe` 内；**(A60)** FEG：门规则音完备，`EV-frame` 不得放松 `F_max/δ_force/m_min`，stale 帧必被拒绝。则：

1. **帧充分性健全性**：若 `Cert_frame.sufficient=true`，则对 `B_F` 中所有帧，动作 `a` 的安全符号一致且裕度 `≥m_min` 的概率 `≥1−α_F−δ_TFI`；若 `A_a>θ_A` 或 `m_a<m_min`，系统必须继续获取证据或降级，不得直接承诺。
2. **接触锚定不可替代性**：任何 L2 不可逆动作的提交都引用 `κ` 当前的接触后证书，且 `EV-frame` 未单独授权；若视觉帧与力/接触证据矛盾，安全判定以力/接触证据为准，视觉帧只能触发复观测/标记 OOD。
3. **非对称安全**：加入视觉帧证据后可行动作集单调收缩，`A_safe(FGML) ⊆ A_safe(无帧)`；视觉帧不能增大 `F_max`、不能降低 `δ_force`/`m_min`、不能替代 `EV-exec/EV-xmodal/EV-human`。
4. **终止性**：`B_loc` 有限且每个定位动作消耗预算，FGML 在 `n_views+t_loc+contact_probe+k_probes+k_cons+k_ft+k_ux+k_exec` 内终止于 `{承诺(带 Cert_frame+Cert_eeis), 带保护轻触, 绕行, 协商, 安全停, FRAME_INSUFFICIENT}`。
5. **部署界**（在式 (第 59 轮部署界) 上增加帧相关项）：

```python
@dataclass
class FrameCertificate:
    action: str
    kappa: int
    ambiguity: float       # A_a
    margin: float          # m_a
    coverage: float        # B_F 共形覆盖
    r_phys: float
    calib_version: int
    tau: float             # 帧证据年龄
    sufficient: bool
    model_version: int

class TaskFrameIdentifiability:
    def __init__(self, alpha_F=0.05, theta_A=0.05, m_min=0.01,
                 theta_phys=0.02, model_version=1):
        self.alpha_F = alpha_F
        self.theta_A = theta_A
        self.m_min = m_min
        self.theta_phys = theta_phys
        self.model_version = model_version
        self.r_hat_F = self.calibrate_conformal_threshold()

    def calibrate_conformal_threshold(self):
        # 在标定场景上：对每个真实帧 F* 计算 nonconformity
        # r_hat_F = Quantile(1-alpha_F) of {s_Frame(F*, obs)}
        return self._conformal_quantile(self.calib_scores, 1 - self.alpha_F)

    def multi_hypothesis_frames(self, obs, table_anchor):
        # 多假设来源：点到面/点到边配准、类别形状先验、深度补全、
        # 漂移/多视角融合；每个假设带权重
        H = []
        H += self.registration_hypotheses(obs.pointcloud, obs.edges)
        H += self.category_shape_hypotheses(obs.rgb, obs.depth)
        H += self.depth_completion_hypotheses(obs.depth, obs.mask)
        if table_anchor.anchored:
            H = self.anchor_to_table(H, table_anchor)  # 降维/约束
        return H

    def nonconformity(self, F, obs, table_anchor):
        e_rep = self.reprojection_residual(F, obs)
        e_plane = self.support_plane_residual(F, table_anchor)
        e_phys = self.physical_residual(F, obs)
        e_hyp = self.hypothesis_consistency(F, obs)
        return (self.w_rep * e_rep + self.w_plane * e_plane +
                self.w_phys * e_phys + self.w_hyp * e_hyp)

    def build_frame_belief(self, obs, table_anchor):
        hypotheses = self.multi_hypothesis_frames(obs, table_anchor)
        particles = []
        for F in hypotheses:
            s = self.nonconformity(F, obs, table_anchor)
            particles.append(Particle(F=F, weight=self.score_to_weight(s)))
        particles = [p for p in particles
                     if self.nonconformity(p.F, obs, table_anchor) <= self.r_hat_F]
        return FrameBelief(self.normalize(particles))

    def decision_predicate(self, F, action):
        # 抓取：运动学可达 ∧ 夹爪不撞桌 ∧ 闭合点在对象内 ∧ 摩擦锥可行
        # 推触：接触点/法向/摩擦锥/力限幅可行
        # 放置：支撑面稳定 ∧ 不穿透 ∧ 可达
        return self.geometric_feasibility_sign(F, action)  # -1/0/+1

    def signed_margin(self, F, action):
        # 到最近决策边界的符号距离（可达性/碰撞/摩擦锥/支撑）
        return self.min_constraint_margin(F, action)

    def ambiguity_and_margin(self, B_F, action):
        signs = [(p.F, self.decision_predicate(p.F, action), p.weight)
                 for p in B_F.particles]
        majority = self.weighted_majority([s for _, s, _ in signs])
        A = sum(w for _, s, w in signs if s != majority)
        m = min(self.signed_margin(F, action) for F, _, _ in signs)
        return A, m

    def certificate(self, B_F, action, r_phys, kappa, calib_version, tau):
        A, m = self.ambiguity_and_margin(B_F, action)
        coverage = self.empirical_coverage(B_F)
        sufficient = (A <= self.theta_A and m >= self.m_min and
                      coverage >= 1 - self.alpha_F and r_phys <= self.theta_phys)
        return FrameCertificate(
            action=action, kappa=kappa, ambiguity=A, margin=m,
            coverage=coverage, r_phys=r_phys, calib_version=calib_version,
            tau=tau, sufficient=sufficient, model_version=self.model_version
        )
```

```python
                 l_pen=10.0, l_float=5.0, l_scale=2.0, l_support=3.0):
        self.theta_phys = theta_phys

        self.l_pen, self.l_float = l_pen, l_float

    def anchor(self, gravity, depth_views, wrist_poses, calib):
        n_grav = -normalize(gravity)
        planes = []
        for d in depth_views:
            planes += self.ransac_planes(d, normal_hint=n_grav,
                                         min_inlier=self.theta_inlier)
        if not planes:
            return TableAnchor(None, None, [], inf, 0.0, False, {})

        T_ts, T_se = self.joint_plane_handeye_opt(
            planes, wrist_poses, calib, loss='huber'
        )
        r_phys = self.physical_residual(planes, T_ts, depth_views)
        inlier = self.support_inlier_ratio(planes)
        anchored = (r_phys <= self.theta_phys and inlier >= self.theta_inlier)
        reduced_dof = self.reduce_frame_dof(T_ts, planes) if anchored else {}
        return TableAnchor(T_ts, T_se, planes, r_phys, inlier, anchored, reduced_dof)

        flt = self.floating_height(planes, T_ts, depth_views)
        scl = self.scale_inconsistency(planes, T_ts, depth_views)
        sup = self.support_area_deficit(planes, T_ts, depth_views)
        return self.l_pen*pen + self.l_float*flt + self.l_scale*scl + self.l_support*sup

        return {'dof': 4, 'x': None, 'y': None, 'yaw': None, 'h': None}
```

```python
@dataclass
class JointState:
    F_o: np.ndarray        # 对象/接触任务帧
    d: np.ndarray          # 接触诱导位移
    c: str                 # free/contact/slip/deform
    kappa: int

class ContactCoupledLocalizer:
    def __init__(self, eeis, ertc, n_particles=512):
        self.eeis = eeis
        self.ertc = ertc
        self.state = JointState(F_o=None, d=np.zeros(3), c='free', kappa=0)
        self.U = ParticleFilter(dim=9, n=n_particles)  # F_o(6)+d(3)

    def predict(self, a, dt):
        if self.state.c in ('contact', 'slip', 'deform') or a.is_contact:
            self.U.predict(lambda x: self.contact_displacement_model(x, a, dt))
        else:
            self.U.predict(lambda x: x)  # 自由空间慢漂移

    def contact_displacement_model(self, x, a, dt):
        F_o, d = x[:6], x[6:]
        # stick-slip：接触时随末端运动，超过摩擦锥则滑动
        d_next = d + a.delta_ee if self.within_friction_cone(a) else d + a.slip_delta
        if a.deforms_object:
            d_next = d_next + a.deform_delta
        return concat(F_o, d_next)

    def update(self, y_vis, y_kin, do_action):
        # 干预感知：似然以 do(a) 为条件，避免把动作诱导变化当噪声
        if y_vis is not None:
            self.U.update(y_vis, h=lambda x: self.h_vis(x, do_action))
        if y_kin is not None:
            self.U.update(y_kin, h=lambda x: self.h_kin(x, do_action))
        if self.detect_transition(do_action):
            self.state.kappa += 1
            self.invalidate_certificates_before(self.state.kappa)

    def select_contact_probe(self, B_F, delta_f_req):
        cands = self.guarded_touch_candidates(B_F)
        best, best_score = None, -inf
        for a in cands:
            if not self.eeis.feasible(a.K_imp, a.F_touch, delta_f_req):
                continue
            ig = self.expected_frame_information(a)
            risk = self.eeis.force_violation_prob(a.K_imp, a.F_touch)
            score = ig / (risk + 1e-9)
            if score > best_score:
                best, best_score = a, score
        return best

    def build_post_contact_certificate(self, B_F, kappa, force_residual):
        return FrameCertificate(
            action='contact_anchor', kappa=kappa,
            ambiguity=B_F.ambiguity, margin=B_F.margin,
            coverage=B_F.coverage, r_phys=force_residual,
            calib_version=self.calib.version, tau=now(),
            sufficient=force_residual <= THETA_FORCE_RESIDUAL,
            model_version=self.model_version
        )
```

### IP-155 AFI（主动帧辨识）

```python
class ActiveFrameIdentifier:
    def __init__(self, loc_budget, safety_envelope, theta_loc=0.05):
        self.B_loc = loc_budget
        self.env = safety_envelope
        self.theta_loc = theta_loc

    def select(self, B_F, action_family):
        if not self.B_loc.viable():
            return None
        scored = []
        for a in self.action_family(action_family):
            if not self.env.permits(a):
                continue
            ig = self.expected_information_gain(B_F, a)
            cost = self.cost_loc(a)
            scored.append((a, ig - cost))
        if not scored:
            return None
        a, voi = max(scored, key=lambda x: x[1])
        return a if voi > self.theta_loc else None

    def expected_information_gain(self, B_F, a):
        H0 = self.particle_entropy(B_F)
        H1 = self.expected_entropy_after(B_F, a)
        return max(0.0, H0 - H1)

    def expected_entropy_after(self, B_F, a):
        # 对候选动作采样预期观测 y ~ p(y|do(a),B_F)，更新后取熵的期望
        ys = self.sample_expected_observations(B_F, a, n=32)
        return float(np.mean([self.particle_entropy(self.update(B_F, y)) for y in ys]))

    def cost_loc(self, a):
        return (L_VIEW*a.n_views + L_TIME*a.duration +
                L_CALIB*max(0, T_CALIB_MAX - a.calib_freshness) +
                L_BLUR*max(0, a.predicted_blur - self.B_loc.blur_budget))
```

```python
def frame_gate(EV_frame, contact_level, action):
    if EV_frame.stale or EV_frame.tau > T_FRAME_RENEWAL:
        return ('reject', 'stale_frame')

    cert = EV_frame.cert
    if contact_level == 'L0':
        ok = cert.sufficient
    elif contact_level == 'L1':
        ok = (cert.sufficient and cert.margin >= 0 and
              cert.r_phys <= THETA_PHYS)
    elif contact_level == 'L2':
        # 不可逆：必须接触后证书，视觉帧不能单独授权
        ok = (cert.kappa == EV_frame.current_kappa and
              cert.contact_anchored and
              EV_frame.exec_evidence_ok and
              cert.r_phys <= THETA_FORCE_RESIDUAL)
    else:
        return ('reject', 'unknown_contact_level')

    if not ok:
        return ('reject', 'frame_insufficient')

    # 非对称律：视觉帧不能放宽力/不可逆约束
    if action.relaxes_force_limit:
        return ('reject', 'visual_frame_cannot_relax_force')
    if action.irreversible and not cert.contact_anchored:
        return ('reject', 'irreversible_requires_contact_anchor')
    return ('ok', 'frame_sufficient')
```

### IP-157 XMC++（帧约束对账）

```python
def reconcile_frame(M, EV_frame, other_evidence):
    # 1) 帧只作为约束模态：单向收缩可行动作集
    frame_constraints = derive_action_constraints(EV_frame)  # A_safe 的子集
    M.A_safe = M.A_safe.intersect(frame_constraints)

    # 2) 保守方向分歧：帧说 unsafe、融合说 safe 才算风险
    D_frame = 0.0
    for a in M.action_family:
        if EV_frame.says_unsafe(a) and M.fused_says_safe(a):
            D_frame += M.w_a[a] * margin_gap(EV_frame, M, a)
        # 反向（帧说 safe、融合说 unsafe）不用于放松，只记录
    D_pp = M.D_plus + W_FRAME * D_frame

    if D_pp > THETA_D_PP:
        M = widen_posterior(M, reason='frame_conflict')
        M = request_additional_probe(M, modality='frame')

    # 3) stale / κ 不匹配：权重置零
    if EV_frame.stale or EV_frame.cert.kappa != M.current_kappa:
        M.rho_frame = 0.0
        M = request_additional_probe(M, modality='frame')

    return M, D_pp, frame_constraints
```

### IP-158 PCE++++（定位预算耦合）

```python
class FrameBudget:
    def __init__(self, ertc, thermal, n_views=6, t_loc=8.0,
                 contact_probes=2, blur_budget=1.0):
        self.ertc = ertc
        self.thermal = thermal
        self.n_views_left = n_views
        self.t_loc_left = t_loc
        self.contact_probe_left = contact_probes
        self.blur_budget = blur_budget
        self.calib_freshness = 0.0

    def viable(self):
        return self.n_views_left > 0 and self.t_loc_left > 0

    def spend(self, a):
        self.n_views_left -= a.n_views
        self.t_loc_left -= a.duration
        self.calib_freshness += a.duration
        if a.is_contact:
            self.contact_probe_left -= 1

    def cost_loc(self, a):
        return (L_VIEW*a.n_views + L_TIME*a.duration +
                L_CALIB*max(0, T_CALIB_MAX - self.calib_freshness) +
                L_BLUR*max(0, a.predicted_blur - self.blur_budget))

    def exec_cost_pppp(self, pi):
        return self.ertc.exec_cost(pi) + self.cost_loc(pi)

def probe_commit_evolve_pppp(x0, M, task, budget, consent, operators):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []

    for cp in route.checkpoints:
        if not budget.is_viable_for_contact():
            return negotiate_or_stop(cp, M, 'exec_budget_exhausted')

        # ① SSA
        anchor = M.ssa.anchor(M.gravity, M.depth_views, M.wrist_poses, M.calib)
        if not anchor.anchored:
            log.append(EvidenceRecord(ev='EV-frame', anchored=False, cp=cp))

        # ② TFI
        B_F = M.tfi.build_frame_belief(M.obs[cp.region], anchor)
        A, m = M.tfi.ambiguity_and_margin(B_F, cp.action)

        # ③ AFI：主动定位直到充分或预算耗尽
        while (A > M.tfi.theta_A or m < M.tfi.m_min) and budget.viable():
            a = M.afi.select(B_F, cp.action_family)
            if a is None:
                break
            y = execute_localization_action(a, M.eeis)  # 受 EEIS 保护
            M.ccl.update(y.vis, y.kin, do_action=a)
            B_F = M.tfi.build_frame_belief(M.obs[cp.region], anchor)
            A, m = M.tfi.ambiguity_and_margin(B_F, cp.action)
            budget.spend(a)

        # ④ FEG
        EV_frame = build_frame_evidence(
            M.tfi.certificate(B_F, cp.action, anchor.r_phys,
                              M.ccl.state.kappa, M.calib.version, now()),
            r_phys=anchor.r_phys, kappa=M.ccl.state.kappa,
            contact_probe_log=M.ccl.probe_log
        )
        gate, why = frame_gate(EV_frame, cp.contact_level, cp.action)
        if gate == 'reject':
            if cp.irreversible:
                return degrade_frame_mode(M, cp, why)
            # 可逆：进入带保护的试探性接触分支
            probe = M.ccl.select_contact_probe(B_F, risk_model.delta_f(cp))
            M, EV_frame = guarded_touch_branch(M, cp, probe, budget)

        # ⑤ XMC++：帧约束对账
        M, D_pp, frame_constraints = reconcile_frame(M, EV_frame, M.evidence)

        # ⑥ EEIS：帧条件化的阻抗编译
        delta_f_req = risk_model.delta_f(cp)
        K_safe, cert_eeis = M.eeis.compile(
            delta_f_req, M.fused, M.buq.ukf.x,
            M.b_r[cp.region], frame_constraints
        )
        if K_safe is None:
            return degrade_exec_mode(M, cp, 'EEIS_infeasible')

        # ⑦ CLEP：执行与回流
        M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(
            M, cp, delta_f_req, budget
        )
        M.EV_frame_log.append(EV_frame)
        M.J_frame.append(EV_frame, M.ccl.kappa_log, M.ssa.calib_log)

        # ⑧ 承诺/降级
        if (select_gait(schedule_risk(foothold_schedule(x0, cp, M), M)) != 'halt'
                and evidence_gate_pppp(EV_frame, EV_exec, M) == 'ok'):
            sched.append(commit(cp.action, cert_eeis, EV_frame.cert))
        else:
            alt = reroute(M, cp, risk_model)
            if alt:
                route = alt
            else:
                return negotiate_or_stop_pppp(cp, M, consent, operators)

    return sched, log, M
```

### IP-159 J_frame（帧证书链）

```python
@dataclass
class FrameCertificateChain:
    cert_chain: list
    kappa_log: list
    ssa_calib_log: list
    view_probe_log: list
    contact_intervention_log: list
    conformal_thresholds: dict
    physical_residual_log: list
    commit_log: list
    version: int
    timestamp: float

    def verify(self):
        # 1) κ 单调不减
        if any(b < a for a, b in zip(self.kappa_log, self.kappa_log[1:])):
            return False
        # 2) 不可逆提交必须引用当前 κ 的接触后证书
        for commit in self.commit_log:
            if not commit.irreversible:
                continue
            cert = self.cert_chain[commit.cert_idx]
            if cert.kappa != commit.kappa or not cert.contact_anchored:
                return False
        # 3) 共形覆盖与物理残差
        if any(c.coverage < 1 - ALPHA_F for c in self.cert_chain):
            return False
        if any(c.r_phys > THETA_PHYS for c in self.cert_chain):
            return False
        # 4) 标定新鲜度
        if self.version - self.ssa_calib_log[-1].version > MAX_CALIB_LAG:
            return False
        # 5) 帧证书与执行证据时戳对齐
        if any(abs(c.tau - e.tau) > T_ALIGN for c, e in
               zip(self.cert_chain, self.exec_evidence_log)):
            return False
        return True
```

**正确性定理（Frame-Grounded Manipulation Soundness, FGMS）**
假设 A51–A55（第 59 轮）成立；**(A56)** TFI：`B_F` 的共形覆盖 `≥1−α_F`，非一致性分数诚实，歧义/裕度估计不低报风险；**(A57)** SSA：支撑面内点率与物理残差能检出穿透/悬空/尺度不一致/非平面，漏检率 `≤δ_phys`；**(A58)** CCL：接触干预模型诚实，`κ` 在 `free→contact`、`slip`、`deform` 时正确递增，力/运动学观测误差有界；**(A59)** AFI：期望信息增益是真实增益的上界（不乐观），所有定位动作在 `A_loc^safe` 内；**(A60)** FEG：门规则音完备，`EV-frame` 不得放松 `F_max/δ_force/m_min`，stale 帧必被拒绝。则：

1. **帧充分性健全性**：若 `Cert_frame.sufficient=true`，则对 `B_F` 中所有帧，动作 `a` 的安全符号一致且裕度 `≥m_min` 的概率 `≥1−α_F−δ_TFI`；若 `A_a>θ_A` 或 `m_a<m_min`，系统必须继续获取证据或降级，不得直接承诺。
2. **接触锚定不可替代性**：任何 L2 不可逆动作的提交都引用 `κ` 当前的接触后证书，且 `EV-frame` 未单独授权；若视觉帧与力/接触证据矛盾，安全判定以力/接触证据为准，视觉帧只能触发复观测/标记 OOD。
3. **非对称安全**：加入视觉帧证据后可行动作集单调收缩，`A_safe(FGML) ⊆ A_safe(无帧)`；视觉帧不能增大 `F_max`、不能降低 `δ_force`/`m_min`、不能替代 `EV-exec/EV-xmodal/EV-human`。
4. **终止性**：`B_loc` 有限且每个定位动作消耗预算，FGML 在 `n_views+t_loc+contact_probe+k_probes+k_cons+k_ft+k_ux+k_exec` 内终止于 `{承诺(带 Cert_frame+Cert_eeis), 带保护轻触, 绕行, 协商, 安全停, FRAME_INSUFFICIENT}`。
