# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC；灵感驱动研究循环第 1 轮；本轮灵感：「动力学」×「地形适应」）

> 第 61 轮把场景-执行闭环推进为 ESEC：USR 让场景/意图/阻抗/证据进入共享语义空间，MEL 提供零样本物理属性推断，DMS 实现执行反馈接地，SRT-Dual 解耦语义与实时流，PCE+++++ 做六维预算兜底。但一旦把机器人放到真实地形上，**四个物理层面的断点**立即暴露：
> 1. **语义嵌入没有动力学约束**：USR 的对齐损失只是向量 MSE，能区分「看起来不同」的地形，却不能区分「看起来相同、摩擦/刚度/接触模式不同」的地形；语义相似不等于动力学等价。
> 2. **地形被当成静态材质标签**：MEL 输出 (μ,k,η,σ) 后便固定使用，缺少坡度、粗糙度、可变形层、空间非平稳性、足端滑移与下陷的在线演化；真实地形是**带不确定性的接触动力学场**，不是一次性分类结果。
> 3. **接触模式切换没有安全理论**：EEIS 编译的是连续阻抗，但脚/手与地形的接触是**混合动力学**（腾空/触地/粘着/滑移/下陷/蹬离）；在模式切换处直接插值刚度/阻尼可能向系统注入能量，导致颤振、打滑甚至失稳。
> 4. **适应缺少主动信息获取与可验证性**：现有闭环被动等待观测，未回答「该用哪一次落脚/探测来最快识别地形」「辨识不确定性如何传播到 CBF 与证书」「预算耗尽时如何安全降级」。

## 0. 直觉与动机

**灵感 1（动力学 → 动力学锚定语义空间 D-USR）**
直觉：语义空间若只对齐外观，就会把「冰面」和「湿瓷砖」编码得很近，却给出完全不同的安全阻抗。应给每个语义锚点附加一个**动力学 token** d_t = (质量/惯量估计、接触点、摩擦锥、地形刚度/阻尼、坡度/粗糙度、接触模式、后验协方差)。USR 的对齐不再只最小化 embedding MSE，而要求「由语义锚点解码出的动力学模型能重放真实接触轨迹」——即**物理一致性损失**。这样，语义距离被动力学可区分性约束，场景嵌入必须解释力/力矩与能量流。

**灵感 2（地形适应 → 地形动力学指纹 TDF 与在线辨识）**
直觉：地形适应不是「识别草地/沙地/冰面」的标签任务，而是「用最短接触探测估计这一块地面的接触参数」。定义地形指纹 ψ(x) = (μ, k_t, c_t, 坡度 α, 粗糙度 ρ, 下陷 z_sink, 可变形层参数)。一次轻踏/微滑/重心转移就能产生力-位移-滑移响应；用递归贝叶斯/粒子滤波更新 ψ 的后验，MEL 只提供先验，真实接触负责修正。地形图不再是语义栅格，而是**带协方差的动力学场**。

**灵感 3（动力学 × 地形 → 接触模式混合自动机 CHA）**
直觉：地形适应的本质是「在正确的时间进入正确的接触模式」。把足/手接触建模为混合自动机：腾空 → 触地 → 粘着 → （滑移/下陷）→ 蹬离。每个模式有独立的动力学、阻抗与守卫条件；模式切换必须满足**驻留时间 + 能量罐 + CBF** 三重条件。这样「地形适应」从调增益升级为**离散接触决策 + 连续阻抗控制的联合问题**。

**灵感 4（三灵感合流 → 动力学-地形三环适应架构 DTAL）**
直觉：语义推理（~10Hz）、地形辨识（~100Hz）、接触控制（~1kHz）不在同一时间尺度。构建三环：慢环用 MEL/语义地图给出地形先验与任务约束；中环用 TDI/CHA 估计 ψ、选择模式与落脚；快环用 RACBF 执行并保证安全。三环通过**动力学锚点**（d_t, ψ, mode, version, covariance）同步；慢环失效时中环回退先验，中环失效时快环回退保守被动控制。

**灵感 5（主动探测 → 信息增益驱动的地形探测 IGTP）**
直觉：被动适应会被最坏地形「教做人」。应允许机器人用**安全的微动作**主动提问：轻踏测刚度、微滑测摩擦、重心偏移测坡度。选择动作时最大化「单位代价的信息增益」：u* = argmax IG(ψ;y|u) - λ c(u)，并受 CBF/力限/能量罐约束。探测预算耗尽则退回 TDM 检索到的地形先验。

**灵感 6（安全 → 鲁棒-自适应 CBF 与能量罐 RACBF-ET）**
直觉：地形辨识一定有误差，若把点估计直接当真实参数，CBF 会在模型误差下失效。用不确定性感知的鲁棒 CBF：ḣ ≥ -αh + β||Σ_ψ||，其中 β 覆盖辨识误差；同时用能量罐约束模式切换，禁止刚度突变向系统注入能量。安全不是「辨识得更准」，而是「即使辨识错了也不失稳」。

**灵感 7（预算 → 动力学-地形预算 PCE+D）**
直觉：探测、辨识、CBF、模式切换都要花时间和能量。把第 61 轮六维预算扩展为 B_cog+D = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_id, B_probe, B_cbf, B_mode, B_map)。VOI 统一为「信息增益/任务收益 − 辨识成本 − 探测风险 − CBF 计算成本」。任一预算耗尽只降低性能，不降低安全。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（动力学锚定语义空间 D-USR）** D-USR = (U, D, E_dyn, Φ_phys, Π_d, L_phys)。其中：
- 语义空间 U 继承定义 161；动力学 token d_t ∈ D ⊆ ℝ^{d_d}，d_d = 16（可配置）：
  d_t = (m̂, Î_c, μ̂, k̂_t, ĉ_t, α̂, ρ̂, ẑ_sink, q_mode, Σ_d)
  其中 m̂/Î_c 为质量/惯量估计，μ̂ 为摩擦系数，k̂_t/ĉ_t 为地形法向刚度/阻尼，α̂/ρ̂ 为坡度/粗糙度，ẑ_sink 为下陷，q_mode 为接触模式，Σ_d 为动力学后验协方差。
- 动力学编码器：E_dyn: (x_t, u_t, x_{t+1}, W_t) → d_t，W_t 为接触力/力矩观测。
- 物理重放：Φ_phys(x_t, u_t; d_t) → x̂_{t+1}，可为可微刚体/接触模型或学习残差模型。
- 投影头：Π_d: (scene_emb, intent_emb, d_t) → (K_p, K_d, F_max, foothold)。
- 物理一致性损失：
  ```
  L_phys = ||Φ_phys(x_t,u_t;d_t) - x_{t+1}||²_W
         + λ_c Σ_j (min(0, λ_{n,j})² + min(0, μ̂λ_{n,j} - ||λ_{t,j}||)²)
         + λ_e (E_{t+1} - E_t - W_ext + D_diss)²
         + λ_s ||d_t - E_dyn(...)||²_{Σ_d^{-1}}
  ```
  即：轨迹残差 + 接触互补/摩擦锥残差 + 能量残差 + 后验正则。
- 动力学锚点：DAnchor_t = (scene_emb, intent_emb, d_t, Σ_d, q_mode, version, timestamp, checksum)。

**定义 174（地形动力学指纹 TDF 与后验）** 对地形位置 x 的局部块，指纹
```
ψ(x) = (μ, k_t, c_t, α, ρ, z_sink, θ_bekker)
```
其中 θ_bekker = (k_c, k_φ, n, K, c_coh, φ_int) 为可变形地形 Bekker/Wong 参数（刚性地面时退化）。短时探测轨迹 τ_probe 产生响应 y = (f_n(·), f_t(·), v_slip(·), z_foot(·), IMU(·))。后验
```
p(ψ | y_{1:N}, u_{1:N}) ∝ p(ψ) Π_{i=1}^N p(y_i | ψ, u_i)
```
用粒子滤波/递归高斯近似维护 (ψ̂, Σ_ψ)。地形动力学图 M_dyn: X → (ψ̂, Σ_ψ) 是带不确定性的高斯过程/栅格场。

**定义 175（接触模式混合自动机 CHA）** CHA = (Q, X, U, E, Guard, Reset, Inv, K_q)。其中：
- Q = {flight, strike, stick, slip, sink, push_off, stumble}；
- 连续状态 X ∋ (p, v, f_contact, z_sink, E_tank)；
- 每个模式 q 的流映射 f_q 与阻抗 K_q = (K_p^q, K_d^q, F_max^q)；
- 守卫 Guard(q→q') 基于力/滑移/下陷/地形后验，带滞回与最小驻留 τ_dwell；
- 复位 Reset 处理接触冲量与能量记账；
- 安全切换条件：
  ```
  Guard_safe(q→q') ⇔ Guard(q→q')
                    ∧ (E_tank ≥ max(0, ΔE_switch(q,q')))
                    ∧ CBF_q'(x) ≥ 0
  ```
- 反颤振：同一对模式在窗口 T_chat 内切换次数 ≤ N_chat；否则锁定保守模式并降低 F_max。

**定义 176（地形自适应阻抗-落脚策略 TAI）** 策略 π_tai: (ψ̂, Σ_ψ, d_t, q_mode, task) → (K_p, K_d, F_max, p_foot, gait)。由约束优化生成：
```
min_{K,F,p_foot}  J_track + λ_e E_mech + λ_s E[slip] + λ_i E[impact] + λ_c ||u||²
s.t.  K_min ≤ K_p ≤ K_max(ψ̂, Σ_ψ)
      F_n ≤ F_max(ψ̂) = μ̂_safe · N_normal · margin
      p_foot ∈ F_safe(ρ̂, α̂, M_dyn)
      CBF_q(x) ≥ 0,  能量罐约束,  接触互补残差 ≤ ε_c
```
其中 μ̂_safe = μ̂ - κ√(Σ_ψ,μμ) 为置信下界；K_max 随 Σ_ψ 增大而收缩（不确定性越大越保守）。

**定义 177（动力学-地形三环适应架构 DTAL）** 三环异步流水线：
- **慢环**（~10Hz）：MEL + 语义地图 + 任务规划，输出地形先验 ψ_prior、任务约束、候选落脚区域；
- **中环**（~100Hz）：TDI 更新 (ψ̂,Σ_ψ)，CHA 选择接触模式，TAI 生成 (K, p_foot)，写入动力学锚点；
- **快环**（~1kHz）：RACBF 安全滤波 + 全身/关节控制 + 接触力跟踪，读取最新动力学锚点；
- **同步协议**：版本号单调递增；快环读非阻塞；若中环超时 > τ_dyn_max（默认 100ms）或锚点过期，快环切换到「保守增益 + 最小力 + 被动阻尼」；
- **跨环一致性**：慢环的语义先验必须通过 L_phys 的物理可解释性检查，否则中环拒绝该先验并回退 TDM。

**定义 178（信息增益驱动的地形探测 IGTP）** 探测动作 u ∈ U_probe = {light_tap, micro_slip, weight_shift, short_step, toe_press}。选择
```
u* = argmax_{u∈U_safe} [ IG(ψ; y | u, ψ̂, Σ_ψ) - λ_c c(u) - λ_r R_probe(u) ]
```
其中 IG 用线性高斯近似：
```
IG ≈ 1/2 log det(I + Σ_ψ^{1/2} Φ_u^T Σ_y^{-1} Φ_u Σ_ψ^{1/2})
```
Φ_u 为探测轨迹对 ψ 的敏感度矩阵。安全约束 u ∈ U_safe ⇔ CBF_probe ≥ 0 ∧ F ≤ F_probe_max ∧ E_tank ≥ E_probe_min。停止条件：H(ψ) ≤ H_stop 或 B_probe 耗尽。贪心自适应探测在自适应子模条件下具 (1-1/e) 近似。

**定义 179（鲁棒-自适应 CBF 与能量罐 RACBF-ET）** 安全集 C = {x | h(x) ≥ 0}。在模型误差 ||Δf|| ≤ β(Σ_ψ) 下，约束
```
ḣ(x,u) ≥ -α h(x) + β(Σ_ψ)
```
保证 C 的鲁棒前向不变性（初始 h(x_0) ≥ β/α）。能量罐：
```
E_tank(t+1) = E_tank(t) + η_in P_in Δt - P_out Δt,   E_tank ≥ E_min
```
模式切换 q→q' 允许当且仅当 E_tank ≥ max(0, ΔE_switch)，其中（1-DoF 示例）
```
ΔE_switch = 1/2 (K_p^{q'} - K_p^q) x² + 1/2 (1/m^{q'} - 1/m^q) p²
```
若不足，则投影到最大允许刚度 K_p^safe = K_p^q + 2 E_tank / x²（x≠0），并降低 F_max。

**定义 180（动力学一致性证书 J_dyn）**
```
J_dyn = (J_sem_exec, ψ̂, Σ_ψ, d̂, Σ_d, q_mode, τ_dwell,
         r_phys, r_energy, m_cbf, E_tank, probe_count,
         map_version, dyn_anchor_version, hash)
Valid(J_dyn) ⇔ Valid(J_sem_exec)
             ∧ r_phys ≤ ε_phys
             ∧ |r_energy| ≤ ε_E
             ∧ m_cbf ≥ m_min
             ∧ E_tank ≥ E_min
             ∧ H(ψ) ≤ H_max
             ∧ P(q_mode | y) ≥ p_mode_min
             ∧ dyn_anchor_fresh
```

**定义 181（动力学-地形预算 PCE+D）** B_cog+D = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_id, B_probe, B_cbf, B_mode, B_map)。其中：
- B_id = (粒子数 N_p, 更新频率 f_id, 最大后验熵 H_max)
- B_probe = (探测次数, 探测能量, 最小安全裕度)
- B_cbf = (QP 求解频率, 最大求解时间, 可行解回退次数)
- B_mode = (窗口内最大切换次数 N_chat, 最小驻留 τ_dwell, 模式锁定时长)
- B_map = (动力学图分辨率, 覆盖面积, 更新带宽)

成本：
```
cost_cogD = cost_cog5 + λ_id·(N_p/N_p^max + f_id/f_id^max)
          + λ_probe·(n_probe/n_probe^max + E_probe/E_probe^max)
          + λ_cbf·(t_qp/t_qp^max + n_infeasible/n_infeasible^max)
          + λ_mode·(n_switch/N_chat + τ_dwell_min/τ_dwell)
```
降级顺序：B_probe 耗尽→用 TDM 先验；B_id 耗尽→冻结 ψ̂，扩大 Σ_ψ；B_cbf 耗尽→切换被动阻尼控制器；B_mode 耗尽→锁定保守模式；**安全层永不降级**。

**定义 182（地形动力学记忆 TDM）** 记忆项 m = (ψ_sig, ψ̂, Σ_ψ, K*, gait*, q_schedule*, outcome, map_patch)。检索：
```
m* = argmin_m ||ψ_sig - ψ̂||²_{Σ_ψ^{-1}} + λ_o·outcome_penalty(m)
```
检索到的 m* 作为 ψ 的先验、K 的热启动、CHA 的模式先验；若检索距离 ≤ δ_mem，则减少探测次数 N_probe。TDM 覆盖度 cov(TDM) 用于决定是否探索新地形。

**定义 183（动力学-地形-语义闭环 DTA-ESEC）**
```
DTA-ESEC(M, x_t):
  慢环: ψ_prior, C_task ← MEL/SemanticMap(x_t, M)
  中环: ψ̂, Σ_ψ ← TDI(M, x_t, u_probe, ψ_prior)
        q_mode ← CHA.update(ψ̂, Σ_ψ)
        K, p_foot ← TAI(ψ̂, Σ_ψ, q_mode, C_task)
        DAnchor ← commit(K, ψ̂, q_mode, Σ_ψ, version)
  快环: (K_safe, u) ← RACBF(DAnchor, x_t)
        x_{t+1} ← execute(u)
        W_t ← contact_evidence()
  update: L_phys, TDM, M, J_dyn
```

**定义 184（动力学可辨识性与安全裕度）** 对探测集合 {u_i}，回归矩阵 Φ = [Φ_{u_1};...;Φ_{u_N}]。若 rank(Φ) = dim(ψ) 且最小奇异值 σ_min(Φ) ≥ σ_req，则 ψ 局部可辨识；安全裕度定义为
```
m_safe = min( m_cbf, E_tank - E_min, μ̂_safe - μ_req,
              F_max - F_req, (H_max - H(ψ))/H_max )
```
m_safe ≥ 0 是 J_dyn 通过的必要条件。

## 2. 关键推导与 mini sanity check

**(a) 模式切换的能量跳变.** 1-DoF 虚拟弹簧-质量系统 E = 1/2 m v² + 1/2 k x²。在 (x,v) 不变的瞬间把刚度 k 切到 k'，则
```
ΔE = E' - E = 1/2 (k' - k) x²
```
若 k' > k 且能量罐无余额，则系统被动性被破坏。例如 m=1kg, x=0.05m, k=1000N/m, E_tank=0.8J，则允许的最大刚度
```
k'_max = k + 2E_tank/x² = 1000 + 2×0.8/0.0025 = 1640 N/m
```
这给出一个可直接嵌入 CHA 的「刚度切换预算」，比事后调参更可证。

**(b) 地形参数可辨识性.** 刚性地面法向接触近似 f_n = k_t z + c_t ż。写成线性回归 y = Φθ + ε，θ=(k_t,c_t)^T，Φ 的第 i 行为 (z_i, ż_i)。只要探测轨迹包含至少两个线性无关的 (z,ż) 组合，rank(Φ)=2，最小二乘可辨识；切向滑移阶段同理用 f_t = μ f_n sign(v_slip) + c_t^t v_slip 回归 (μ,c_t^t)。这提醒我们：**探测动作设计比模型容量更重要**。

**(c) 不确定性到 CBF.** 若 ψ 的后验标准差为 σ_ψ，接触模型对 ψ 的 Lipschitz 常数为 L_f，则力预测误差界 β ≈ L_f σ_ψ。RACBF 的约束右端应减去 β，而不是用点估计；否则「辨识越自信」反而会让安全约束更激进，形成危险的自信偏差。

**(d) 探测的贪心近似.** 线性高斯下 IG 是后验精度矩阵行列式的对数，具有自适应子模性；在基数预算 B_probe 下贪心达到 (1-1/e) 的近似最优。因此 IGTP 可以以很低的在线计算实现接近最优的探测序列。

## 3. 本轮最大风险

**一句话**：最大风险是地形动力学后验在接触模式误判或分布外地形上过度自信，使 RACBF 的误差界 β 被低估、能量罐在刚度/模式切换处被绕过，最终出现「辨识越准、摔得越狠」的复合失稳；必须以「后验校准 + 分布外检测 + 能量罐硬约束 + 模式切换驻留/反颤振 + 被动控制兜底」把安全从辨识精度中解耦。

### IP-183 D-USR（动力学锚定语义空间）

```python
class DynamicsAnchoredUSR:
    def __init__(self, d_us=256, d_dyn=16):
        self.d_us, self.d_dyn = d_us, d_dyn
        self.dyn_encoder = DynamicsEncoder(d_dyn)          # E_dyn
        self.cov_head = CovarianceHead(d_dyn)             # Σ_d = LL^T
        self.phys_replay = DifferentiableContactModel()   # Φ_phys
        self.projector = DynamicsProjector(d_us, d_dyn)   # Π_d
        self.anchor_buffer = SharedMemoryAnchor(d_us, d_dyn)

    def encode(self, x_t, u_t, x_next, wrench):
        d_hat = self.dyn_encoder(x_t, u_t, x_next, wrench)
        L = self.cov_head(d_hat)
        return d_hat, L @ L.T + 1e-6 * torch.eye(self.d_dyn)

    def physics_residual(self, x_t, u_t, x_next, d_hat, wrench):
        x_pred = self.phys_replay(x_t, u_t, d_hat)
        r_traj = weighted_mse(x_pred, x_next)
        r_contact = contact_cone_penalty(wrench, d_hat)   # 互补 + 摩擦锥
        r_energy = energy_residual(x_t, x_next, u_t, d_hat)
        return r_traj + self.lc * r_contact + self.le * r_energy

    def commit(self, scene_emb, intent_emb, d_hat, Sigma_d, q_mode):
        anchor = DAnchor(
            version=self.anchor_buffer.next_version(),
            scene_emb=scene_emb, intent_emb=intent_emb,
            d_hat=d_hat, Sigma_d=Sigma_d, q_mode=q_mode,
            timestamp=time.time(),
            checksum=hash((scene_emb, intent_emb, d_hat, q_mode)))
        self.anchor_buffer.write_cas(anchor)
        return anchor

    def project(self, anchor):
        K, Fmax, p_foot = self.projector(
            anchor.scene_emb, anchor.intent_emb, anchor.d_hat,
            anchor.Sigma_d, anchor.q_mode)
        return K, Fmax, p_foot
```

### IP-184 TDF/TDI（地形动力学指纹与在辨识）

```python
class TerrainDynamicsIdentifier:
    def __init__(self, n_particles=256, d_psi=8):
        self.N, self.d_psi = n_particles, d_psi
        self.particles = sample_prior(n_particles, d_psi)   # ψ_i
        self.weights = np.ones(n_particles) / n_particles
        self.process_noise = ProcessNoise(d_psi)

    def predict(self, dt):
        self.particles += self.process_noise.sample(dt)

    def update(self, y, u):
        # y: (f_n, f_t, v_slip, z_foot, imu)；u: 探测动作
        for i in range(self.N):
            self.weights[i] *= self.likelihood(y, self.particles[i], u)
        self.weights /= self.weights.sum() + 1e-12
        ess = 1.0 / np.sum(self.weights ** 2)
        if ess < self.N / 2:
            idx = systematic_resample(self.weights)
            self.particles = self.particles[idx]
            self.weights = np.ones(self.N) / self.N

    def posterior(self):
        psi_hat = np.average(self.particles, axis=0, weights=self.weights)
        diff = self.particles - psi_hat
        Sigma = (diff * self.weights[:, None]).T @ diff
        H = entropy(self.weights)
        return psi_hat, Sigma, H

    def regressor(self, u):
        # 法向 f_n = k_t z + c_t zdot；切向 f_t = mu f_n sign(v) + c_t^t v
        return sensitivity_matrix(u, self.d_psi)
```

### IP-188 IGTP（信息增益驱动主动探测）

```python
def select_probe(candidates, psi_hat, Sigma, budget):
    best_u, best_score = None, -np.inf
    for u in candidates:                      # light_tap / micro_slip / ...
        if not safe_probe(u, budget):         # CBF + 力限 + 能量罐
            continue
        Phi = regressor(u)
        Sigma_y = probe_noise_cov(u)
        S = sqrtm_psd(Sigma)
        IG = 0.5 * logdet(np.eye(len(psi_hat))
                          + S @ Phi.T @ inv(Sigma_y) @ Phi @ S)
        score = IG - lam_c * cost(u) - lam_r * risk(u)
        if score > best_score:
            best_u, best_score = u, score
    return best_u
```

### IP-185 CHA（接触模式混合自动机）

```python
class HybridContactAutomaton:
    def __init__(self, tau_dwell=0.05, N_chat=3, T_chat=0.5, E_min=0.2):
        self.q = 'flight'
        self.dwell = defaultdict(float)
        self.switch_log = deque(maxlen=200)
        self.E_tank = 1.0
        self.tau_dwell, self.N_chat, self.T_chat, self.E_min = tau_dwell, N_chat, T_chat, E_min

    def step(self, x, psi_hat, Sigma_psi, dt):
        for q_next, guard in self.guards[self.q]:
            if not guard(x, psi_hat, Sigma_psi):
                continue
            if self.dwell[self.q] < self.tau_dwell:
                continue
            if self.recent_switches(self.q, q_next) >= self.N_chat:
                continue
            dE = self.energy_jump(self.q, q_next, x)
            if self.E_tank < max(0.0, dE):
                # 不允许注入能量：投影到最大安全刚度并降力
                self.K_safe = self.project_stiffness(self.q, q_next, x, self.E_tank)
                self.F_max *= 0.8
                continue
            self.E_tank -= max(0.0, dE)       # 提取/耗散记账
            self.q = q_next
            self.dwell[q_next] = 0.0
            self.switch_log.append((time.time(), self.q))
            break
        self.dwell[self.q] += dt
        self.E_tank = max(self.E_min, self.E_tank)
        return self.q, self.K_safe
```

class TerrainAdaptivePolicy:

### IP-189 RACBF-ET（鲁棒 CBF + 能量罐安全滤波）

```python
def racbf_filter(x, u_nom, h, beta, alpha, E_tank):
    # min ||u - u_nom||^2
    # s.t. Lf h(x) + Lg h(x) u + alpha * h(x) - beta >= 0,  u in U
    u_safe = solve_qp(x, u_nom, h, beta, alpha)
    feasible = u_safe is not None
    if not feasible:
        u_safe = passive_fallback(x)      # 被动阻尼/最小力/缓停
    E_tank = update_energy_tank(E_tank, x, u_safe)
    if E_tank < E_min:
        u_safe = passive_fallback(x)
    return u_safe, E_tank, feasible
```

### IP-187/193 DTAL + DTA-ESEC（三环闭环）

```python
class DTAESEC:
    def __init__(self, mel, tdi, cha, tai, racbf, usr, tdm, budget, map):
        self.mel, self.tdi, self.cha, self.tai = mel, tdi, cha, tai
        self.racbf, self.usr, self.tdm, self.budget, self.map = racbf, usr, tdm, budget, map
        self.E_tank = 1.0

    def slow_loop(self, obs):
        psi_prior, task = self.mel.scene_prior(obs)
        self.map.update_semantic(obs, psi_prior)
        return psi_prior, task

    def mid_loop(self, x, obs, psi_prior, task):
        self.tdi.predict(dt=0.01)
        psi_hat, Sigma_psi, H = self.tdi.posterior()
        if H > self.budget.H_max and self.budget.can_probe():
            u_probe = select_probe(PROBES, psi_hat, Sigma_psi, self.budget)
            y = self.execute_probe(u_probe)          # 受 CBF/力限/能量约束
            self.tdi.update(y, u_probe)
            psi_hat, Sigma_psi, H = self.tdi.posterior()
        q_mode, K_q = self.cha.step(x, psi_hat, Sigma_psi, dt=0.01)
        K, F_max, p_foot = self.tai.act(psi_hat, Sigma_psi, q_mode, task)
        anchor = self.usr.commit(obs.scene_emb, obs.intent_emb,
                                 (psi_hat, K, q_mode), Sigma_psi, q_mode)
        self.map.update_dynamics(x, psi_hat, Sigma_psi)
        self.tdm.maybe_store(psi_hat, Sigma_psi, K, q_mode)
        return anchor, H

    def fast_loop(self, x, u_nom):
        anchor = self.usr.read_latest_anchor()
        if anchor is None or not anchor.fresh:
            u_safe, feasible = passive_fallback(x), False
        else:
            beta = contact_lipschitz() * sqrt_trace(anchor.Sigma_psi)
            u_safe, self.E_tank, feasible = racbf_filter(
                x, u_nom, h=contact_safety(anchor),
                beta=beta, alpha=ALPHA, E_tank=self.E_tank)
        return u_safe, feasible

    def certificate(self, anchor, r_phys, r_energy, m_cbf, H):
        return JDyn(
            J_sem_exec=self.usr.build_sem_exec_cert(anchor),
            psi_hat=anchor.d_hat, Sigma_psi=anchor.Sigma_d,
            q_mode=anchor.q_mode, r_phys=r_phys, r_energy=r_energy,
            m_cbf=m_cbf, E_tank=self.E_tank, H=H,
            dyn_anchor_version=anchor.version,
            hash=hash_anchor(anchor))
```

| PCE+D | O(1)/预算检查 | O(1) | 任一预算耗尽性能降级、安全不降级 |

**正确性定理（DTA-ESEC-Complete）**：
假设 A61–A70、A71–A76：
- **(A71)** ψ 属于紧集 Θ；探测集合满足持续激励 rank(Φ)=dim(ψ) 且 σ_min(Φ) ≥ σ_req。
- **(A72)** CHA 良定：守卫带滞回、最小驻留 τ_dwell，模式切换能量记账精确。
- **(A73)** 接触模型误差 ||Δf|| ≤ β(Σ_ψ)，学习残差有界。
- **(A74)** D-USR 的 Φ_phys 对 d_t Lipschitz，L_phys 最小化到 ε_phys。
- **(A75)** RACBF 每步可行，或被动兜底控制器属于安全集 C。
- **(A76)** 预算单调消耗，降级顺序不削弱安全层。

则：
1. **物理一致性**：若 J_dyn 有效，则 r_phys ≤ ε_phys、|r_energy| ≤ ε_E，且接触力预测误差 ≤ L_f ε_phys；语义锚点在动力学上是可解释的。
2. **地形可辨识与后验收缩**：在 A71 下，E||ψ̂−ψ||² ≤ tr((N·J_F + Σ_0^{-1})^{-1}) + bias；当 N ≥ N_min 时 H(ψ) ≤ H_max，模式误判概率 ≤ δ。
3. **接触安全**：若 h(x_0) ≥ β/α 且 RACBF 每步可行，则 h(x_t) ≥ 0 ∀t；能量罐非负且切换满足 E_tank ≥ ΔE_switch ⇒ 切换系统被动，无能量注入；不可行时被动兜底保持安全。
4. **实时性**：快环最坏计算 O(n³)（n≤40）且不依赖 N_p/慢环；锚点过期立即回退，因此实时抖动有界。
5. **适应效率**：TDM 检索距离 ≤δ_mem 时，后验先验方差下降，达到 H_max 所需探测数减少；若检索失败则退回 IGTP，不降低安全性。
6. **预算安全性**：任一 B_cog+D 维度耗尽触发对应性能降级（先验替代、冻结后验、被动控制、锁定模式），J_dyn 的安全项仍必须满足。

## 5. 本轮最大风险

**一句话**：最大风险是地形动力学后验在接触模式误判或分布外地形上过度自信，使 RACBF 的误差界 β 被低估、能量罐在刚度/模式切换处被绕过，最终出现「辨识越准、摔得越狠」的复合失稳；必须以「后验校准 + 分布外检测 + 能量罐硬约束 + 模式切换驻留/反颤振 + 被动控制兜底」把安全从辨识精度中解耦。
