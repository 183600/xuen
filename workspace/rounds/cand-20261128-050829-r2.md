### 第 6 轮灵感驱动研究记录（本轮为循环第 2 轮）

**灵感词**：成功率、演示数据

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配（FMPP）、记忆升级为嵌入+固化（LMEM-v2）、人因升级为情感调制（FAMK），并以定理 6（证书不变性）把框架从「规则系统」推广为「任意生成器 + 认证边界」，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。但 v5 留了两个结构性缺口：(a) 证书是**逐轨迹**的——单条轨迹过七门只说明「这条被盖章」，并不给出**部署分布上的任务成功率**下界，「每条都合格」≠「整体成功率达到承诺」；(b) 固化的训练标签来自策略自己铸证的片段，R57 的自指回路缺**外部真值**。两个灵感词合成主题「**认证成功率与演示锚定**」（Certified Success Rate with Demonstration Anchoring, CSRDA），形成 CADVS-v6（IP-497~500）。本轮继续自律：**七硬门数量不增、锚点不增**——成功率证书是执行集之上的「证书之证书」（统计外层），演示数据只进入提议先验、校准与主动采集，不新增硬门。执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **成功率 → 从「逐轨迹盖章」升级为「分布级、无分布假设的成功率下界」**。直觉：安全员不会因为每张工单都盖了章就相信产线良率，他要看的是**抽样统计的良率区间**。v5 的七门是**谓词**（这条轨迹行不行），缺的是**统计量**（部署中成功率至少是多少、置信度多少）。引入成功率证书核 SRCK：用**外生审计标签**（人工复核/独立传感器判定的任务结局 Y∈{0,1}）在审计集上构造 Clopper–Pearson 单侧下界 LCB_{1−δ}(k,n)=Beta^{-1}(δ; k+1, n−k)；当 LCB ≥ 1−α 才对外宣称「成功率 ≥ 1−α（置信 1−δ）」。关键严谨化：审计集与部署采纳集必须**可交换**，否则 CP 保证失效；因此再加**任意时有效的 e-process**（下注/似然比）做在线漂移监控，H0: SR≥1−α 被 Ville 不等式控制在 δ 以内拒绝。证书不通过时执行**弃权（abstention）**：该上下文进入弃权集 A_abs，回退到演示回放/人工接管——这是 fail-closed 在**分布层**的对应物，且弃权只删上下文、只抬阈值，绝不扩大执行集。

2. **演示数据 → 用人类演示做「外部锚」，同时修 R57 自指回路**。直觉：让策略在自己盖过章的作业上继续学习，等于让考生自己出题自己判卷；人类演示与独立审计才是「外部答案」。引入演示锚定核 DAPC：(a) **提议先验**：检索最近演示轨迹 x_ref(c)，对 FMPP 做有界乘积专家倾斜 π̃(x|c) ∝ π_FM(x|c)·exp(−‖x−x_ref(c)‖²/2σ²)，演示只**塑形提议**、不改门；(b) **演示覆盖度** κ(c)=exp(−d_kNN(c,Dem)/h)，作为「这个上下文离人类经验有多远」的**外部 OOD 锚**——比 v5 的密度新颖度更接近人类语义，且不依赖策略自身；(c) **主动采集**：κ(c) 低或成功率区间过宽时，用 DAgger 式查询请人类补演示/纠错，把「不确定性」转成「采集动作」；(d) **外部标签**：演示与审计标签均为外生，固化只用外生标签 + 倾向性加权 w=1/π_audit 去偏，策略的价值模型**永不给自己的训练数据打标签**。这从结构上切断 v5-R57 的「铸证→学习→再铸证」自指回路：证书在**留出的外生审计集**上计算，策略即便博弈七门，也抬不动外部成功率。

3. **合流 → 「证书的正确性」与「证书的外部锚」缺一不可**。v5 证明了「换提议不换边界」（定理 6）；v6 追问「边界内的成功率有没有统计保证、保证所依据的真值从哪来」。成功率提供**统计层**（无分布假设下界 + 任意时有效监控 + 弃权），演示数据提供**外部层**（提议先验 + 覆盖度 OOD + 外生标签）。二者结合，把 CADVS 从「逐条可认证」推进到「**分布级可认证且可外部核验**」，并顺带偿还 R57 与 v5 的密度型 OOD 盲区（用演示覆盖度作第二外部锚，与 n_flow OR 合成）。

**关键洞见**：v4 回答「提议=规则时七门是否足够」；v5 回答「提议=任意生成器时证书边界是否不变」；v6 回答「证书边界不变还不够——**部署成功率是否被统计保证、保证依赖的外部真值是否独立于策略**」。七硬门与七锚原样复用；本轮新增只有：SRCK（成功率证书核）、DAPC（演示锚定先验与覆盖核）、ACP（审计式固化与溯源核）、EFA-v6（集成）。执行集从 v5 的「同门 + 阈值只紧 + 提议支撑受限」三重收缩，升级为四重收缩：再加**弃权/外生审计约束**。

**形式化目标（增量）**：
1. 成功率证书：审计集 S_audit={(c_i,Y_i)}，Y_i 外生；LCB_{1−δ}(k,n)=Beta^{-1}(δ;k+1,n−k)；若 LCB≥1−α 则认证 SR(D;π)≥1−α。上下文按校准后 ECS_v6 分桶，桶内 LCB 不足即入弃权集。
2. 任意时有效监控：e-process E_t=∏_s(1+λ_s(Y_s−(1−α)))，Ville 不等式 P(∃t:E_t≥1/δ)≤δ（H0 下）；漂移检测延迟由 KL 界。
3. 演示锚定：κ(c)=exp(−d_kNN(c,Dem)/h)；π̃∝π_FM·exp(−‖x−x_ref‖²/2σ²)（有界倾斜，KL(π̃‖π_FM)≤ε_tilt）；DAgger 查询准则 q(c)=1[κ(c)<κ0 ∨ width(LCB(c))>w_max]。
4. 审计式固化：训练集仅取「认证 ∧ 外生审计通过 ∧ 演示覆盖 ∧ 溯源完整」片段；倾向性加权 w=1/π_audit；策略价值模型不参与打标；固化后证书在留出审计集上重算，不过则回滚。
5. ECS_v6=Calib_iso(ECS_v5)·η_cov：Calib_iso 把 v5 软评分单调映射为**校准成功概率** p̂_succ∈[0,1]，η_cov=κ(c)^β 为覆盖折扣；ECE 目标 < 0.05。
6. 定理 9（成功率证书有效性）、定理 10（弃权/收紧单调与嵌套）、定理 11（任意时有效漂移检测）、定理 12（演示锚定切断自指：外生标签下博弈不能抬升认证成功率）。
7. Exec_CADVS-v6 = {x∈Exec_v5 : A_abs(c)=0 且阈值取 γ_SR·τ^5}，γ_SR≥1、A_abs 只增 ⇒ Exec_v6⊆Exec_v5。

**本轮最大风险**：**外部真值本身有偏/不可交换**——成功率证书保证的是「相对于审计分布与演示覆盖」的成功率，一旦部署分布漂移超出可交换假设、或审计/演示标签系统性有偏，证书会以形式正确的统计保证背书一个错误目标（garbage-in, certified-out），弃权只能限损、无法识别目标本身错位。

## 2. 关键算法骨架

### IP-497 SRCK：成功率证书核（离线/异步，统计外层，不在 1 kHz 环）

```python
@dataclass
class SuccessRateCertificateKernel:
    """SRCK：分布级成功率证书（证书之证书）。
    七硬门不变；SRCK 只做统计外层：弃权 + 全局收紧，二者都只缩执行集"""
    alpha: float = 0.10          # 目标 SR >= 1-alpha
    delta: float = 0.05          # 置信 1-delta
    kappa0: float = 0.35         # 演示覆盖下限
    w_max: float = 0.12          # LCB 区间宽度上限
    gamma_sr: float = 1.0        # 只增不减
    e_proc: float = 1.0          # e-process 状态
    eta_sr: float = 0.05         # 触发后单次收紧步长
    gamma_sr_max: float = 1.10   # 收紧上限（防执行集塌缩）

    def lcb(self, k: int, n: int) -> float:
        # Clopper-Pearson 单侧下界（k=成功数, n=审计样本）
        return beta_ppf(self.delta, k + 1, n - k) if n > k else 0.0

    def certify(self, audit: AuditSet) -> Certificate:
        k, n = audit.successes, audit.n
        lcb = self.lcb(k, n)
        # 按校准 ECS_v6 分层，给上下文条件界（避免辛普森悖论式的全局掩盖）
        buckets = stratify(audit, key=lambda e: e.ecs_v6)
        local = {b.id: self.lcb(b.k, b.n) for b in buckets}
        widths = {b.id: b.width for b in buckets}
        return Certificate(global_lcb=lcb, local_lcb=local, local_width=widths,
                           pass_global=(lcb >= 1 - self.alpha))

    def abstain(self, c, cert: Certificate, kappa_c: float) -> bool:
        # fail-closed：任一条件不满足即弃权（回退演示回放/人工）
        b = bucket_of(c)
        return (not cert.pass_global
                or cert.local_lcb.get(b, 0.0) < 1 - self.alpha
                or kappa_c < self.kappa0
                or cert.local_width.get(b, 1.0) > self.w_max)

    def update_eprocess(self, y: int) -> bool:
        """任意时有效漂移监控：H0: SR>=1-alpha。返回 True=拒绝 H0（触发收紧）"""
        lam = self._bet(y)                      # 预注册下注分数 λ_t（有界）
        self.e_proc *= (1.0 + lam * (y - (1.0 - self.alpha)))
        if self.e_proc >= 1.0 / self.delta:     # Ville 不等式
            self.e_proc = 1.0                   # 重置，继续监控下一段
            self.gamma_sr = min(self.gamma_sr * (1.0 + self.eta_sr),
                                self.gamma_sr_max)
            return True
        return False
```

```python
        ...  # v5 七门级联原样，用 gamma 作为最终阈值
        if self.dapc.query_needed(context, cert, kappa_c):
            self._schedule_dagger(context)              # 异步采集，不阻塞本周期
        return ...

    def ecs_v6(self, ecs_v5: float, kappa_c: float) -> float:
        p = self.iso_calib.predict(ecs_v5)              # 等渗校准成功概率
        return p * (kappa_c ** self.beta_cov)           # 覆盖折扣
```

```
       ──▶ 留出外生审计集重算 SRCK 证书 ──▶ 通过才上线（否则回滚旧 θ_FM）
```

## 4. 正确性论证（增量更新）

### 引理 45（Clopper–Pearson 下界有效性）

**陈述**：设 Y_1..Y_n ~ iid Bernoulli(p)，k=ΣY_i，则单侧下界 LCB_{1−δ}(k,n)=Beta^{-1}(δ;k+1,n−k) 满足 P_p(LCB_{1−δ}(k,n) ≤ p) ≥ 1−δ。∎

**证明**：由 beta–二项对偶性，P_p(Beta(k+1,n−k) ≤ p)=P_p(Bin(n,p) ≥ k+1)，取 δ 分位即得单侧覆盖。∎

### 引理 46（Ville 不等式 / e-process 假警报控制）

**陈述**：若非负超鞅 (E_t) 满足 E_0=1，则 P(∃t:E_t≥1/δ) ≤ δ。∎

**证明**：Ville 不等式 + 可选停时。∎

### 引理 47（覆盖度–Lipschitz 局部界，条件性）

**陈述**：若成功率函数 SR(·) 在上下文嵌入上 L-Lipschitz，且 c 的 1-NN 演示距离为 d(c)=−h·ln κ(c)，则 |SR(c)−SR(c_ref)| ≤ L·d(c)。因此当 κ(c)≥κ0 时，局部成功率估计的不确定带宽被 L·h·(−ln κ0) 约束。∎

**诚实边界**：L-Lipschitz 是强假设，跨物体/跨任务通常不成立；不成立时该界仅作经验启发，κ(c) 仍作为外部 OOD 信号使用，但**不宣称形式保证**。

### 定理 9（成功率证书有效性）

**陈述**：在 (A1) 审计集与部署采纳集可交换（同一 D、同一选择策略）；(A2) 结局标签 Y 外生（独立于策略价值模型）下，若 LCB_{1−δ}(k,n)≥1−α，则 P(SR(D;π)≥1−α) ≥ 1−δ。

**证明**：由 (A1) 审计样本 ~ 部署采纳分布，(A2) 标签不随策略漂移；引理 45 直接给出单侧覆盖。∎

**诚实边界**：(A1) 在分布漂移下不成立时，CP 的固定样本保证失效；此时只能依赖 e-process 的任意时有效监控（定理 11），其 H0 假警报受控，但**不提供固定时点覆盖率**。

### 定理 10（弃权/收紧单调性与执行集嵌套）

**陈述**：SRCK 的两类动作——(i) 将上下文移入弃权集 A_abs；(ii) 以 γ_SR≥1 乘现有阈值——都是对逐上下文执行集的**单调收缩**操作。故 ∀c：Exec_v6(c) ⊆ Exec_v5(c)，进而 Exec_CADVS-v6 ⊆ Exec_CADVS-v5。当 A_abs=∅ 且 γ_SR=1 时精确退化为 v5。

**证明**：阈值单调升 ⇒ 各门通过集单调缩；移除上下文 ⇒ 该上下文执行集为空；交集保持包含。∎

### 定理 11（任意时有效漂移检测）

**陈述**：H0: SR≥1−α 下，e-process 的假警报概率 ≤ δ（Ville）。在 H1 真成功率 p_1<1−α 下，最优下注 e-process 的期望检测延迟满足 E[τ] ≤ log(1/δ)/KL(p_1‖p_0)（相差常数）。

**证明**：引理 46 给假警报；Wald/可选停时 + Gibbs 不等式给延迟界。∎

**诚实边界**：延迟界依赖 p_1 已知或可估；漂移是渐变且 p_1 未知时，只能给经验检测延迟，无先验上界。

### 定理 12（演示锚定切断自指）

**陈述**：若 (C1) 固化标签外生（来自审计/演示，非策略价值模型）；(C2) 审计倾向 π_audit(c)≥p_min>0 且已知/可估；(C3) 证书在**留出的外生审计集**上重算，则 (i) 倾向性加权策略更新收敛到真实部署成功目标，而非策略自评分；(ii) 认证成功率不能因门博弈被抬高，因为度量标签独立于策略；(iii) 残余偏差由重要性权重方差/有效样本量界定；若 (C2) 误设，则保证失效。

**证明**：重要性采样恒等式 E_{c~D}[f(c)]=E_{c~π_audit}[f(c)/π_audit(c)]；标签与策略独立 ⇒ 博弈只改采纳分布、不改外生标签；对留出集应用定理 9。∎

**诚实边界**：该定理界定但不根除——审计预算有限、标签有噪、倾向模型可能误设；R57 从「结构性无解」降为「可由审计设计控制的偏差」。

### 定理 v6（执行集四重收缩与成功率可认证，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 审计可交换/外生 下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（严格：A_abs 与 γ_SR 非恒真）；
(ii) 成功率可认证：LCB≥1−α 时 SR≥1−α 以置信 1−δ（定理 9）；
(iii) 弃权/收紧单调（定理 10），γ_SR=1 且 A_abs=∅ 时精确退化 v5；
(iv) 漂移监控任意时有效（定理 11）；
(v) 演示锚定 + 外生审计切断自指（定理 12）；
(vi) 七硬门与七锚完备性保持（v5 定理 8 原样）。

**证明**：(i) 由定理 10 + v5 三重收缩；(ii) 定理 9；(iii) 定理 10；(iv) 定理 11；(v) 定理 12；(vi) 锚点集合不变。∎

**诚实声明**：(B8) 在真实部署中常被漂移/审计偏差破坏；(ii) 的覆盖率是相对审计分布而言；(iii) 弃权会牺牲可用性（安全–可用权衡）；(iv) 渐变未知漂移的检测延迟无先验上界；(v) 审计标签噪声与演示偏差仍是开放问题；加性价值假设 (B4) 仍继承未解。

## 5. 实验设计与初步结果（仿真，单机；舰队/实机列入下一轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX；演示数据 = 500 条成功 + 100 条失败的人类遥操作演示（含新物体/逆光子集）；审计集 = 对部署采纳片段随机抽样的人工/独立传感器外生标签；漂移注入 = 执行器增益渐变退化。

## 7. 本轮最大风险（最终确认）

**一句话**：**外部真值本身有偏/不可交换**——成功率证书保证的是「相对于审计分布与演示覆盖」的成功率，一旦部署分布漂移超出可交换假设、或审计/演示标签系统性有偏，证书会以形式正确的统计保证背书一个错误目标（garbage-in, certified-out），弃权只能限损、无法识别目标本身错位。
