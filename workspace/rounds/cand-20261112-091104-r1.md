# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「灵巧手」×「演示数据」）

> 第 59 轮把证据链一路下沉到执行物理：BUQ 辨识 BLDC 结构性不确定性、ERTC 把嵌入式时序契约化、EEIS 把 δ_f 编译成带证书的阻抗参数、CLEP 让执行实测回传为第 5 模态。但它仍默认两个更深的元假设：**(i) 接触是「单点、单模态、连续」的**——一个末端执行器的阻抗 (K_p,K_d,F_max) 就足以刻画一次承诺；**(ii) 证据只能来自机器人自己的探针**——「他证」（人类演示、他机演示、视频）要么被当作离线训练的免费原料，要么被当作与本体观测同质的证据。**灵巧手**击穿 (i)：真正的接触是**离散接触模式 × 连续力/位混合 × 欠驱动腱耦合**的混合状态，抓取失败的主因是「哪个手指在何时以何种方式接触、滑移、切换」这一离散模式坍缩，而不是某个标量阻抗偏了 10%。**演示数据**击穿 (ii)：演示是**他身（foreign embodiment）的、被操作员删失的、相关而非干预的观测**——它带来技能，也带来演示者的运动学、触觉分布、摩擦习惯与偏置；把它当「免费先验」或「独立佐证」，等于把别人的身体假设偷偷搬进自己的安全证明。

核心命题：**「演示只买效率，绝不买安全；转导必须带不变式证书，先验必须可隔离、可撤销、可过期。」** 具体地：(a) 把灵巧手接触从标量阻抗还原为**接触模式代数 DGCA + 抓取证书 Cert_grasp**；(b) 把演示从「i.i.d. 技能样本」还原为**跨具身转导 CRT + 来源回执 DSA + 支撑认证**，只有通过「任务不变式保持 + 支撑内 + 质量回执完整」的片段才可进入先验；(c) 演示**只能改变动作先验与提议分布，绝不进入场景似然、绝不充当证据门的独立佐证**（先验从属原则）；(d) 执行实测与演示预测的冲突触发**立即隔离与单向下调 DQR**，撤销可回溯；(e) 演示的可信度由**第五重预算 B_demo（采集/标注/转导/重探/注意力）**抵押，形成「演示负债」——用低质量演示跳过探针，必须在未来用重验证偿还。

核心矛盾：

- **H38（接触模式坍缩）**：把一个 n_f 指灵巧手的状态压成 (K_p,K_d,F_max) 会丢失离散接触模式 m（哪些指节接触、点/软/线接触、滚动/滑移）及其切换概率；δ_f 被错误地当作连续参数误差，而真实失效主要来自**模式误判与切换未授权**。若不显式建模 m 的混合状态，任何「力跟踪达标」都可能发生在错误模式上。
- **H39（跨具身泄漏）**：人类演示的成功依赖人手的 21+ DoF、皮肤触觉、指尖摩擦与臂腕协同；直接行为克隆/轨迹重定向会把**演示者可达但机器人不可达**的动作、**人类摩擦锥但机器人腱耦合**的力分布、**人眼但非机载触觉**的接触判据一并移植。跨具身差距不是「加噪声」，而是**支撑/动力学/接触语义的系统性错位**。
- **H40（演示证据越权）**：演示是相关观测，且被操作员的选择、任务设置、物体摆放**删失（censoring）**。把它当「场景证据」或「独立佐证」，会短路探针-证据链；更隐蔽的是**用演示先验降低后验熵**，使系统在没有任何物理观测的情况下「自信」。
- **H41（支撑外推）**：行为克隆在演示支撑集外会平滑外推到「看起来合理」的动作，且置信度往往不降反升。灵巧手的高维动作空间使外推更频繁、更危险——必须用**共形支撑证书**界定「可以信先验」的边界，边界外强制探针或停。
- **H42（演示负债）**：演示不是免费资源：采集、标注、转导、验证、操作员注意力都消耗预算；低质量演示买到的「少探几次」是向未来借安全。必须把演示收益与演示风险、重验证成本一起进入 VOI，形成**五重预算耦合**。

## 0. 直觉与动机

**灵感 1（灵巧手 → 接触模式代数 DGCA）**
直觉：灵巧手不是「更灵活的单点」，而是「一台会切换接触拓扑的混合系统」。抓杯子的瞬间，接触模式可能是「拇指+食指+中指三点硬接触」，滑一下变成「三点+无名指滚动」，再调整成「包络软接触」。每一种模式有自己的抓取矩阵 G(m)、摩擦锥、腱张力可行域、可操作度与滑移裕度。关键洞见：**承诺的最小单位不是阻抗，而是「接触模式 m + 模式内阻抗/力分配 + 切换守卫」**。因此 δ_f 应分解为 Σ_m P(m)[δ_mode+δ_force+δ_slip]+δ_switch，并对每个模式签发 Cert_grasp；模式切换必须由显式守卫（力/滑移/触觉）授权，而不是由策略隐式穿越。

**灵感 2（演示数据 → 跨具身转导 CRT + 来源回执 DSA）**
直觉：演示是「用别人的身体写的程序」。要让它在本体上运行，必须先做**语义转导**而非**轨迹复制**：保留任务相关不变式（物体位姿轨迹、接触力廓形、抓取扳手空间签名、接触点相对物体的位置），放弃演示者特异的关节轨迹。转导算子 R 输出候选动作，并附带证书：运动学可行、动力学/腱张力可行、接触不变式误差 ≤ ε_I。与此同时，每条演示要有**来源回执**：演示者身份与同意、具身指纹、任务/ODD 标签、时间、质量向量 q_d、哈希。没有回执的演示只是「数据」，不是「证据」。

**灵感 3（演示先验的从属性 SPD）**
直觉：演示最有价值的不是「模仿动作」，而是「缩小搜索」——它给出**动作提议分布**与**接触模式先验**，让探针/规划少走弯路。但它**不能替代观测**。因此把演示蒸馏为 π_demo(a|x,m) 与 b_demo(m)，以可信权重 w_demo 进入「提议」和「先验」两个端口；**绝不进入任何场景似然 L(o|z)**。这条「先验从属」是单向安全通道的延伸：演示只能让系统**更会找证据**，不能让它**更少要证据**（除非支撑证书+转导证书+无冲突同时成立，且减少的探针由 B_demo 抵押）。

**灵感 4（冲突即隔离 DQR）**
直觉：演示预测的接触廓形与执行实测的 EV-exec/触觉一旦冲突，说明「演示在本体/本场景不成立」。此时不能平滑调权重，而要**立即隔离**：该技能-区域-模式三元组降级，历史演示先验回溯标记，重探针，必要时撤销并遗忘（KG 回滚）。安全相关冲突（滑移、超力、模式跳变）零容忍单向降级；恢复必须靠 N_verify 次独立影子执行 + 新证书。

**灵感 5（合流 → 演示-探针-承诺闭环 DCL + 五重预算）**
直觉：把 DGCA 的模式证书、CRT 的转导证书、DSA 的支撑证书、SPD 的先验，接入第 59 轮 CLEP/PCE+++：在检查点先问「演示能否在此支撑内提出候选模式与动作」，能则用其做提议并省探针（记入 B_demo 负债），不能则回到物理探针；执行后用 EV-exec/触觉核对，冲突即 DQR。VOI 显式含**信任演示的期望风险**与**重验证成本**：voi_demo = E[省下的探针/执行成本] − R_demo(withdraw) − cost_verify − λ_debt·D_debt。

## 1. 形式化定义（增量：定义 153–162）

**定义 153（灵巧手接触模式代数 DGCA）** 灵巧手 h=(n_f,{q_i},腱耦合 A_t)。接触模式 m=(S_m,{c_i}_{i∈S_m},F_m)，其中 S_m⊆指节-物体接触对，c_i∈{点、软、线、滚动、滑移}，F_m 为接触坐标系。抓取矩阵 G(m)=[B_i]_{i∈S_m}，手雅可比 J_h(m)，摩擦锥 K_i(μ_i)，腱张力可行域 T(m)={τ | τ=J_h^T f+τ_bias, A_t τ_t=τ, τ_t∈[τ_min,τ_max]}。模式 m 的力闭合裕度：
```
ε_fc(m) = max{ε≥0 : B_6(ε) ⊆ G(m)·F(m)},
F(m) = {f : f_i∈K_i(μ_i), τ∈T(m), G(m)f=−w_ext, w_ext∈B_6(w_max)}
```
可操作度与滑移裕度：ε_man(m)=σ_min(J_h(m))，ε_slip(m)=min_i(1−‖f_i,t‖/(μ_i f_i,n))。抓取证书 Cert_grasp(m)=(ε_fc, ε_man, ε_slip, 腱张力裕度, 关节/热裕度, mode_hash, version)。模式转移图 T_M：边 (m→m') 由守卫 g(m,m')=(力/滑移/触觉/位姿阈值) 授权，转移代价与风险 δ_switch(m,m')。总接触风险分解：
```
δ_contact ≤ Σ_m b(m)[δ_mode(m)+δ_force(m)+δ_slip(m)]
          + Σ_{(m,m')} P_π(m→m')·δ_switch(m,m')
```

**定义 154（跨具身转导 CRT）** 演示 D={(o_t^H,a_t^H,contact_t^H)}_{t=1..T}，演示具身 H，目标具身 R。任务相关不变式 I(τ)=(物体位姿轨迹, 接触力廓形, 抓取扳手空间签名, 接触点相对物体位置)。转导算子：
```
R_H→R(a^H) = argmin_{q_R,τ_t} Σ_i w_i‖p_i^R(q_R)−T(p_i^H)‖² + λ_s‖σ(q_R)−σ_H‖²
s.t. q_R∈Q_R, 自碰撞自由, ‖τ‖≤τ_max, τ_t∈[τ_min,τ_max]
```
跨具身差距 gap(D,R)=sup_t[d_I(I(a_t^H),I(R(a_t^H)))+λ_c·viol(q_R,τ_t)]。转导证书 Cert_rt：运动学可行 ∧ 动力学/腱可行 ∧ gap≤ε_I ∧ 触觉映射标定通过；否则该片段判「不可转导」，不得进入先验。

**定义 155（演示来源回执与质量向量 DSA）** 回执 receipt_d=(provenance, embodiment_fp, consent, time, task/ODD, operator, hash, q_d)，质量向量 q_d=(coverage, correctness, timeliness, uniqueness, smoothness, contact_richness, label_conf)。演示先验的支撑：
```
s(x) = max( u_ens(x)/τ_u, −log ρ̂(x)/τ_ρ, d_nn(x)/τ_d )
λ_α = Quantile_{1−α}(s(D_cal)),  S_α = {x : s(x) ≤ λ_α}
```
在演示分布内可交换假设下 P(x∈S_α)≥1−α；支撑是「可信先验」的**必要条件**，不是安全充分条件。支撑外强制探针/停，禁止静默外推。

**定义 156（演示先验与从属原则 SPD）** 演示蒸馏为 π_demo(a|x,m)、b_demo(m)，以权重 w_demo(r)=clip(φ(coverage, gap, q_d, freshness, conflict_history), 0, w_max) 进入提议分布 q(a) 与模式先验 b_0(m)。**从属原则**：对任意场景状态 z，
```
P(z|o) ∝ P(z) ∏_k L_k(o_k|z),  任意 L_k 都不含 demo
```
demo 只改变 P(a|z) 与采样提议。形式化：demo 不得降低「获得物理证据前」的后验熵下界，不得用于减少证据门所需的独立模态数；违反即记 δ_emb 并以隔离撤销。

**定义 157（演示-探针-承诺闭环 DCL）** 在 CLEP 的检查点 cp 上插入演示通道：
```
① DSA: 若 x_cp ∉ S_α 或 Cert_rt 无效 ⇒ 关闭 demo 通道，走第 59 轮纯物理 CLEP
② DGCA: 用 b_demo(m)∪b_tact(m) 采模式候选 m，逐个签 Cert_grasp
③ SPD: 用 π_demo 生成候选动作/阻抗，进入 PCE++++ 的提议集
④ 预算: 若 demo 使探针数下降 k，则 B_demo 记演示负债 D_debt += k·c_probe，
        并预留 k_verify 次重验证（不得挪用 B_exec 安全余量）
⑤ 执行: 走 CLEP/EEIS（模式内阻抗编译）+ 触觉 EV-tact
⑥ 对账: 比较 EV-exec/EV-tact 与 demo 预测廓形，冲突 ⇒ DQR 隔离、回溯、重探
⑦ 证据门: demo 不产生 EV 类；只允许「减少提议搜索」，不允许「减少证据」
```

**定义 158（演示隔离与撤销 DQR）** 每个「技能 s × 区域 r × 模式 m」维护状态 q∈{Trusted, Probation, Quarantined, Revoked}。转移：
- Trusted→Probation：轻微力跟踪偏差但已恢复；
- 任意→Quarantined：安全相关冲突（滑移、超力、未授权模式跳变、触觉与先验矛盾）；
- Quarantined→Probation：N_verify 次独立影子执行成功 + 新证书；
- 任意→Revoked：重复冲突、来源回执失效、跨具身差距超界；
- Revoked 只能由「新演示 + 全量重认证」重新进入。

安全相关转移**零容忍单向降级**；提升需证据；撤销触发 KG 回滚与历史 EV 标记。

**定义 159（接触模态证据与 XMC++）** 模态集扩展 ℳ++=ℳ+∪{tact}，tact 为触觉/接触模式观测（接触位置、法向力、滑移、模式标签）。demo **不是模态**，而是先验通道：单独维护先验一致性 C_demo=KL(b_prior‖b_post)+|μ_F^demo−μ_F^obs|/μ_scale。规则：(R1) tact 可参与 D⁺ 分歧与证据门；(R2) C_demo>θ_C ⇒ 后验加宽 + DQR 隔离；(R3) demo 一致性**永远不能减少探针/佐证需求**（单向）。

**定义 160（演示预算 B_demo 与五重预算耦合 PCE++++）** B_demo=(N_demo, B_label, B_rt, B_reprobe, B_attn)。VOI 扩展：
```
voi_demo(π) = E[VOI_probe_saved + VOI_exec_saved] − R_demo − cost_verify − λ_debt·D_debt
R_demo = δ_support + δ_rt + δ_emb + δ_drift
```
D_debt 随「用演示跳过探针」累积、随重验证偿还。选择条件：w_demo≥w_min ∧ 支撑/转导证书有效 ∧ 无冲突 ∧ voi_demo>θ_voi；否则探针。五重预算单调、互不挪用；B_reprobe 与 B_exec 安全余量硬隔离。

**定义 161（演示证书 J_demo 与 J_all）** J_demo=(receipt 链, Cert_rt 链, Cert_grasp 链, S_α 校准记录, π_demo 版本/校准, w_demo 轨迹, DQR 状态转移日志, 撤销/回滚记录, B_demo 快照)。J_all=(J_exec, J_demo, 跨具身哈希链)。验证：回执哈希链完整、证书版本单增、撤销不可复活（除非新版本）。

**定义 162（云边协同 CEB+++++：演示联邦）** 云端聚合各站点演示 → 训练候选 π_demo/模式先验 → 边端隔离区：先做来源回执与具身指纹核验，再影子执行 N_shadow 做转导/支撑/抓取证书审计；通过才热加载；失败回滚并上报。只上传**技能卡**（π_demo 摘要 + 证书 + 支撑描述），不上传原始演示，除非明确同意；撤销通过哈希链广播。

## 2. 关键算法（要点）

```python
def demo_probe_commit(M, cp, delta_f_req, budget):
    # A. 演示通道准入：回执 + 转导 + 支撑 + 新鲜度
    demo_ok, cert_rt, S_alpha = M.dsa.admit(cp, M.demo_store, M.embodiment_fp)
    if not demo_ok:
        return closed_loop_exec_probe(M, cp, delta_f_req, budget)  # 纯物理

    # B. 接触模式：先验 + 触觉后验 → 候选模式
    modes = M.dgca.sample_modes(M.spd.b_demo(cp), M.tact.belief(cp))
    certs = {m: M.dgca.certify(m, M.robot_hand) for m in modes}
    modes = [m for m in modes if certs[m].feasible]

    # C. 提议（仅提议，不进似然）
    proposals = M.spd.propose(cp, modes, w_demo=M.spd.weight(cp))
    k_saved = estimate_probe_saved(proposals)
    budget.b_demo.borrow(k_saved * C_PROBE)   # 演示负债 + 重验证预留

    # D. 走 CLEP/EEIS 执行 + 触觉证据
    M, out = clep_with_mode(M, cp, delta_f_req, modes[0], proposals, budget)

    # E. 对账：demo 预测 vs EV-exec/EV-tact
    conflict = M.dqr.detect(out.ev_exec, out.ev_tact, M.spd.predict(cp))
    if conflict:
        budget.b_demo.repay_verify()
        M.dqr.demote(cp.skill, cp.region, out.mode, conflict)
        return clep_with_mode(M, cp, delta_f_req,
                              M.dgca.most_conservative_mode(cp), None, budget)
    return M, out
```

**正确性要点**：演示只进入 `b_demo` 与 `propose`，不进入 `bayes_update` 的任何 `likelihood`；`k_saved` 需由 `B_demo` 抵押并预留 `k_verify` 次重验证；任何安全冲突使 DQR 状态单向降级。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DGCA | O(\|M\|·(k·d)³) 证书预计算；在线 O(\|M_cand\|) 校验 | O(\|M\|·k·d) | 力闭合裕度、滑移裕度、腱/关节可行域；模式守卫覆盖 |
| CRT | O(T·N_retarget·iter) | O(T·d_o+d_q) | 通过证书 ⇒ 运动学/动力学可行且任务不变式误差 ≤ε_I |
| DSA | O(N_cal log N_cal) 校准；O(1) 查询 | O(N_cal) | 支撑覆盖率 ≥1−α（可交换下）；支撑外禁止外推 |
| SPD | 蒸馏离线；在线 O(ensemble) | O(π 参数) | 先验从属：不进似然；w_demo 有界且冲突下单调不增 |
| DCL | O(CLEP + 模式 + 对账) | 复用 CLEP/DGCA/DSA | 演示只省提议搜索，不省证据；冲突即隔离重探 |

### IP-152 DGCA（接触模式代数与抓取证书）

```python
@dataclass
class ContactMode:
    contacts: list          # [(finger, phalanx, type, frame)]，type∈{point,soft,line,roll,slip}
    G: np.ndarray           # 6 x sum(d_i) 抓取矩阵
    J_h: np.ndarray         # 手雅可比
    mu: list                # 每个接触的摩擦系数
    tendon_feasible: Callable

@dataclass
class GraspCertificate:
    mode_hash: int
    eps_fc: float           # 力闭合裕度
    eps_man: float          # 可操作度 sigma_min(J_h)
    eps_slip: float         # min_i (1 - ||f_t||/(mu f_n))
    tendon_margin: float
    joint_margin: float
    thermal_margin: float
    feasible: bool
    version: int

class DexterousGraspAlgebra:
    def __init__(self, hand, object_model, w_max):
        self.hand = hand
        self.obj = object_model
        self.w_max = w_max
        self.mode_graph = self._build_mode_graph()  # T_M + guards

    def enumerate_modes(self, cp):
        # 由对象-指节几何 + 触觉先验生成候选模式（禁止无接触的伪模式）
        cand = []
        for subset in self._contact_subsets(cp):
            for types in self._contact_types(subset):
                cand.append(ContactMode(subset, *self._kinematics(subset, types)))
        return cand

    def force_closure_margin(self, m):
        # 最大 eps，使半径 eps 的扳手球可被模式 m 的可行接触力平衡
        # 线性化摩擦锥 + 腱约束后求 Chebyshev 中心（LP）
        A, b = self._wrench_force_polytope(m)
        return solve_chebyshev_ball(A, b)   # max eps s.t. eps*B6 ⊆ G*F

    def certify(self, m):
        eps_fc = self.force_closure_margin(m)
        eps_man = np.linalg.svd(m.J_h, compute_uv=False)[-1]
        eps_slip = self._slip_margin(m)
        tm = self._tendon_margin(m)
        jm = self._joint_margin(m)
        th = self._thermal_margin(m)
        ok = (eps_fc > EPS_FC_MIN and eps_man > EPS_MAN_MIN and
              eps_slip > EPS_SLIP_MIN and tm > 0 and jm > 0 and th > 0)
        return GraspCertificate(hash_mode(m), eps_fc, eps_man, eps_slip,
                                tm, jm, th, ok, self.version)

    def authorize_switch(self, m, m2, telemetry):
        guard = self.mode_graph.guard(m, m2)
        return (guard.check(telemetry) and
                self.certify(m2).feasible and
                self.mode_graph.risk(m, m2) <= DELTA_SWITCH_MAX)

    def decompose_risk(self, b_modes, P_switch):
        return (sum(b_modes[m] * (self.delta_mode[m] + self.delta_force[m]
                                  + self.delta_slip[m]) for m in b_modes)
                + sum(P_switch[(m, mp)] * self.delta_switch[(m, mp)]
                      for (m, mp) in P_switch))
```

### IP-153 CRT（跨具身转导与不变式证书）

```python
@dataclass
class RetargetCertificate:
    demo_id: str
    invariant_err: float       # sup_t d_I
    kinematically_feasible: bool
    dynamically_feasible: bool
    self_collision_free: bool
    tactile_mapped: bool
    gap: float
    version: int

class CrossEmbodimentTransducer:
    def __init__(self, source_fp, target_hand, invariant_weights, eps_I):
        self.src = source_fp
        self.hand = target_hand
        self.w = invariant_weights       # (pose, force, GWS, contact_loc)
        self.eps_I = eps_I

    def invariants(self, traj, embodiment):
        return dict(
            obj_pose=traj.object_pose,
            force_profile=traj.contact_force,
            gws_sig=grasp_wrench_space_signature(traj.contacts, embodiment),
            contact_loc=relative_contact_positions(traj.contacts, traj.object_pose),
        )

    def retarget(self, demo):
        q_R, tau_t = solve(
            minimize=lambda q, t: (
                self.w['pose'] * kin_cost(q, demo.fingertips)
                + self.w['syn'] * synergy_cost(q, demo.synergies)),
            constraints=[joint_limits(self.hand), self_collision(self.hand),
                         tendon_limits(self.hand), torque_limits(self.hand)],
        )
        inv_src = self.invariants(demo, self.src)
        inv_dst = self.invariants(self.to_traj(q_R, tau_t), self.hand)
        err = max(self.w[k] * d(k, inv_src, inv_dst) for k in inv_src)
        cert = RetargetCertificate(
            demo.id, err,
            kinematically_feasible=check_joint_limits(q_R),
            dynamically_feasible=check_torque(tau_t),
            self_collision_free=check_self_collision(q_R),
            tactile_mapped=self._map_tactile(demo),
            gap=err + LAMBDA_C * constraint_violation(q_R, tau_t),
            version=self.version,
        )
        return q_R, cert

    def admissible(self, cert):
        return (cert.kinematically_feasible and cert.dynamically_feasible
                and cert.self_collision_free and cert.tactile_mapped
                and cert.invariant_err <= self.eps_I)
```

### IP-154 DSA（来源回执与支撑认证）

```python
class DemonstrationSupportAuthenticator:
    def __init__(self, ensemble, density_model, calib_demos, alpha=0.05):
        self.ens = ensemble
        self.rho = density_model
        self.alpha = alpha
        self.lambda_alpha = self._calibrate(calib_demos)

        return max(u / TAU_U, -rho / TAU_RHO, dnn / TAU_DNN)

    def _calibrate(self, demos):
        scores = [self._score(x) for x in demos]
        return np.quantile(scores, 1 - self.alpha)

    def admit(self, demo, embodiment_fp, now):
        r = self.receipts.get(demo.id)
        if r is None or not verify_hash(r) or r.embodiment_fp != embodiment_fp:
            return False, None, None
        if now - r.time > DEMO_FRESHNESS_MAX:
            return False, None, None
        if r.quality.timeliness < Q_MIN or r.quality.correctness < Q_MIN:
            return False, None, None
        return True, r, self.lambda_alpha

    def support(self, x):
        return self._score(x) <= self.lambda_alpha

    def certify_support(self, x, q_d):
        if not self.support(x):
            return SupportVerdict(False, "out_of_support", 0.0)
        # 支撑内失败率上界（选择性预测风险-覆盖曲线）
        risk = self._risk_upper(x, q_d, delta=0.01)
        return SupportVerdict(True, "in_support", risk)
```

### IP-155 SPD（演示先验与从属原则）

```python
class SkillPriorDistiller:
    def __init__(self, ensemble_policies, calibrator):
        self.policies = ensemble_policies
        self.cal = calibrator

    def prior(self, x):
        actions = np.stack([p.mean(x) for p in self.policies])
        mode_logits = np.mean([p.mode_logits(x) for p in self.policies], axis=0)
        return (Gaussian(actions.mean(0), actions.var(0) + self.cal.epi(x)),
                softmax(mode_logits))

    def weight(self, x, cert_rt, support, q_d, conflict_hist, age):
        base = min(support.coverage, 1.0) * exp(-cert_rt.gap / EPS_GAP)
        qual = prod(q_d[k] ** BETA[k] for k in q_d)
        fresh = exp(-age / TAU_DEMO)
        penalty = CONFLICT_DECAY ** conflict_hist
        return float(np.clip(base * qual * fresh * penalty, 0.0, W_DEMO_MAX))

    def propose(self, x, modes, w):
        """只返回提议；绝不返回似然、绝不更新场景后验"""
        prior, mode_prior = self.prior(x)
        candidates = sample(prior, n=N_PROPOSAL) + modes
        return ProposalSet(candidates, mode_prior, w=w)

    def assert_not_likelihood(self):
        # 结构性约束：SPD 对象不暴露任何 likelihood 接口
        assert not hasattr(self, 'log_likelihood')
```

```python
                              M.dgca.most_conservative_mode(cp), None, budget), \
               DemoOutcome.quarantined(conflict)
    if conflict.minor:

        k_saved=k_saved, w=w, cert_rt=cert_rt, support=S_alpha)
```

### IP-157 DQR（隔离与撤销自动机）

```python
class DemoQuarantineRegistry:
    STATES = ('Trusted', 'Probation', 'Quarantined', 'Revoked')

    def __init__(self):
        self.state = {}       # (skill, region, mode) -> q
        self.transitions = [] # (time, key, from, to, reason)

    def detect(self, ev_exec, ev_tact, pred, cert_rt):
        err_force = abs(ev_exec.force_tracking_q99 - pred.force_q99) / F_SCALE
        mode_mismatch = ev_tact.mode != pred.mode
        slip = ev_tact.slip_prob > SLIP_THRESH
        overforce = ev_exec.force_tracking_q99 > FORCE_TRACK_THRESH
        conflict = Conflict(err_force, mode_mismatch, slip, overforce)
        conflict.safety_relevant = (slip or overforce or mode_mismatch)
        conflict.minor = (not conflict.safety_relevant and err_force > ERR_MIN)
        return conflict

    def demote(self, skill, region, mode, conflict):
        key = (skill, region, mode)
        old = self.state.get(key, 'Trusted')
        new = 'Revoked' if self._repeat_or_invalid(key) else 'Quarantined'
        self.state[key] = new
        self.transitions.append((time_now(), key, old, new, conflict))
        self._rollback_prior(key)     # 回溯标记历史先验 + KG 回滚

    def demote_minor(self, skill, region, mode, conflict):
        key = (skill, region, mode)
        if self.state.get(key, 'Trusted') == 'Trusted':
            self.state[key] = 'Probation'
            self.transitions.append((time_now(), key, 'Trusted', 'Probation', conflict))

    def try_promote(self, key, n_verify_ok, new_cert):
        if self.state.get(key) == 'Quarantined' and n_verify_ok >= N_VERIFY and new_cert:
            self.state[key] = 'Probation'
            self.transitions.append((time_now(), key, 'Quarantined', 'Probation', 'verified'))

    def can_use(self, key):
        return self.state.get(key, 'Trusted') in ('Trusted', 'Probation')
```

### IP-159 PCE++++（五重预算与演示负债）

```python
class DemoBudget:
    def __init__(self, n_demo, label, rt, reprobe, attn):
        self.remaining = dict(N_demo=n_demo, B_label=label, B_rt=rt,
                              B_reprobe=reprobe, B_attn=attn)
        self.debt = 0.0

    def can_borrow(self, amount):
        return self.remaining['B_reprobe'] >= amount * REPROBE_RESERVE_RATIO

    def borrow(self, amount):
        self.debt += amount

    def reserve_reverify(self, k_verify):
        self.remaining['B_reprobe'] -= k_verify * C_PROBE

    def repay_verify(self, k_verify, success):
        spend = k_verify * C_PROBE
        self.remaining['B_reprobe'] -= spend
        if success:
            self.debt = max(0.0, self.debt - spend)

    def force_repay_verify(self):
        self.debt *= 2.0   # 安全冲突：债务利息

    def voi_demo(self, voI_saved, R_demo, cost_verify):
        return voI_saved - R_demo - cost_verify - LAMBDA_DEBT * self.debt
```

**正确性定理（Cross-Embodiment Demonstration Grounded Soundness, CEDGS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** DGCA：安全相关模式漏检 ≤δ_mode；Cert_grasp 裕度诚实；模式守卫覆盖所有不安全转移。**(A57)** CRT：转导证书音完备——通过 ⇒ 目标具身运动学/动力学可行且任务不变式误差 ≤ε_I。**(A58)** DSA：回执不可伪造；支撑校准在演示分布内可交换，支撑内误纳率 ≤α。**(A59)** SPD：demo 只进提议/先验，绝不进任何场景似然；w_demo 有界且冲突下不增。**(A60)** DCL：demo 只减少提议搜索，不减少证据门要求；演示负债由 B_demo 抵押并预留重验证。**(A61)** DQR：安全相关冲突在一个接触内触发隔离；撤销无新证书不可复活。**(A62)** XMC++：tact 与 demo 独立；demo 一致性不能减少独立佐证需求。**(A63)** PCE++++：五预算单调、互不挪用；B_reprobe 与 B_exec 安全余量硬隔离。则：

1. **接触模式安全性**：若所有采纳模式满足 Cert_grasp 且切换由守卫授权，则滑移/失稳概率 ≤Σ_m b(m)[δ_mode+δ_force+δ_slip]+Σ P_π(m→m')δ_switch。
2. **跨具身转导健全性**：通过 Cert_rt 的片段在本体执行时运动学/动力学可行且不变式误差 ≤ε_I；未过证书片段不得进入先验。
3. **先验从属性**：demo 不改变任何物理似然，故物理模态的校准/覆盖保证不变；demo 只能通过提议降低期望探针数，不能降低证据门阈值或独立模态数。
4. **支撑健全性**：S_α 内使用 demo 先验的失败率受共形覆盖约束；S_α 外系统必探针或停，无静默外推。
5. **隔离健全性**：任何安全相关 demo-执行冲突在一个接触内使状态单向降级；被撤销先验不参与后续提议。
6. **预算单调性**：五重预算互不挪用；演示负债只增不减，除非完成重验证偿还。
7. **终止性**：DCL 在 k_probes+k_cons+k_demo 内终止于 {承诺(带 Cert_grasp/Cert_rt), 绕行, 降档, L2 协商, 安全停, 演示隔离停}。
