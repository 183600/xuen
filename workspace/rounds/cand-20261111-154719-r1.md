# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「碰撞避免」×「轮足机器人」）

> 第 54 轮已把技能组合升级为「动作剖面 α_S + 组合图 G_S + 云边映射 γ_ce + 联合证书 J」的可判定体系，但该体系把碰撞当作一个二值、静态、与形态无关的外生约束。轮足机器人打破这三个默认：它的碰撞几何随关节构型与运动模式变化，它的腿必须**主动与地面碰撞（支撑接触）**才能运动，而同一几何接触在不同模式下既是「必需」又是「危险」。本轮把「碰撞避免」重写为**接触语义分类 + 构型依赖扫掠 + 模式条件速度障碍**的三层问题，并给出与 ρ 并列的碰撞谱 χ。核心矛盾：H22 **语义错位**——支撑接触 C_sup 与禁止接触 C_forb 在几何上同构，若不做接触语义划分，避碰证书会把必要接触误判为碰撞、或把障碍接触误判为支撑；H23 **模式跳变**——逐模式无碰撞 + 切换瞬间无建模 ≠ 整个模式调度无碰撞，扫掠体在轮/腿切换处发生跳变，经典 VO 在模式边界失效。

## 0. 直觉与动机

**灵感 1（碰撞的语义分裂 → 从「避碰」到「接触分类与调度」）**
直觉：对纯轮式机器人，碰撞几乎总是坏事；对轮足机器人，轮底/足端与地面的接触是运动的前提。因此碰撞避免不能只定义在几何上，必须定义在**接触语义**上：支撑接触 `C_sup`（需要）、禁止接触 `C_forb`（要避开）、中性接触 `C_neu`（可擦碰但不承载）。碰撞问题的第一性问题不是「两集合是否相交」，而是「相交的**类型**是否被当前模式允许」。这解释了一个常见失败：越障时足端必须踩上台阶（与障碍物相交），若统一按「避开障碍物」处理，机器人反而无法完成任务。

**灵感 2（碰撞几何随形态变化 → 构型依赖的扫掠体）**
直觉：轮足机器人的腿会伸缩、摆动，轮会转向，机身会升降；其占据体积 `B(ξ)` 随关节 `q` 与模式 `m` 改变，而不是位姿 `(p,R)` 的函数。腿抬高时扫掠包络变大，可能越过低矮障碍却撞上高处横杆；压低重心能过窄道却丧失越障能力。于是避碰必须在**形态构型空间** `Ξ = SE(3)×Q×M` 上定义，经典 `SE(3)` 碰撞锥只是它在 `q,m` 固定时的切片。

**灵感 3（模式切换的碰撞风险尖峰 → 过渡走廊证书）**
直觉：轮→腿切换时轮锁死、腿抬升，扫掠体在 `τ_sw` 内连续变化。两端模式都无碰撞，不代表过渡走廊无碰撞；更危险的是，切换瞬间支撑多边形尚未建立，机器人既不能靠轮滚动也不能靠腿蹬地。定义过渡走廊 `Corridor(ξ,m→m') = ∪_{t∈[0,τ_sw]} B(ξ_t)`，要求 `Corridor ∩ C_forb = ∅` 且承载力在走廊内不为零。这把模式切换从「控制细节」提升为**可验证的证书边界**，并解释了为什么把两个模式的 VO 简单拼接会漏掉切换瞬间的碰撞。

**灵感 4（碰撞谱 → 与鲁棒性谱 ρ 同构的第二谱系）**
直觉：类比第 53 轮的鲁棒性谱 `ρ(d)`，定义碰撞谱 `χ(κ)`，维度 `κ` 覆盖静态净空、动态 TTC、自碰撞、地形支撑、模式过渡。组合时 `ρ` 与 `χ` **同构传递**：常规维度取逐维 min，过渡维度沿走廊取 min。碰撞安全与鲁棒性、动作覆盖一起，构成**三重可行性**：动作可行（α）∩ 碰撞可行（χ）∩ 鲁棒可行（ρ）。这样第 54 轮的组合证书只需增加一个字段，而不是推翻重来。

**灵感 5（碰撞可行域裁剪动作剖面 → 接触安全的组合自动机）**
直觉：第 54 轮的动作剖面 `α_S` 描述「能力」，本轮用碰撞谱与 MCVO 把它裁剪为 `α^safe_S = α_S · 1[安全]`。组合图 `G_S` 再与模式自动机 `A_M` 做**乘积**，节点是（技能, 模式），边要求动作交集、模式可达、过渡走廊无碰撞、碰撞谱达标。技能组合于是在「技能 × 模式」的乘积空间做可达性搜索，而非在技能图上启发式拼接；同时 `α^safe` 的收缩天然为组合提供了保守性。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（混态形态构型空间）**
轮足机器人构型 `ξ = (p, R, q, m) ∈ Ξ = SE(3) × Q × M`：`p,R` 为基座位姿，`q∈Q` 为关节角（腿长、髋/膝、轮转向），`m∈M={W,L,WL}` 为运动模式（纯轮、纯腿、轮腿协同）。混态动作空间
```
A = ⊔_{m∈M} {m} × U_m
```
是**不交并**（不同模式维数、动力学不同），模式间只能经切换流形 `∂M` 转移。形态体积 `B(ξ) ⊂ ℝ³`（含连杆扫掠包络与轮/足接触几何）。关键：`B(ξ)` 随 `q,m` 变化，即**碰撞几何是构型依赖的**。

**定义 122（接触语义划分与带符号净空）**
对机器人表面 `∂B(ξ)` 与环境的接触点集 `C = ∂B(ξ) ∩ ∂E`，划分
```
C = C_sup ∪ C_forb ∪ C_neu
```
- `C_sup`：支撑接触（足端/轮底与地面），运动所必需；
- `C_forb`：禁止接触（障碍物、自碰撞、高危地形），即通常意义的碰撞；
- `C_neu`：中性接触（可擦碰但不承载，如软性植被、浅水）。
接触安全谓词
```
Safe(ξ) ⇔ (C ∩ C_forb = ∅) ∧ (C ∩ C_sup ⊆ 𝒮) ∧ (C ∩ C_neu ⊆ 𝒩)
```
其中 `𝒮,𝒩` 为允许的支撑面/中性面。带符号净空 `d_c(ξ) = min_{x∈∂B(ξ)} dist(x, C_forb)`（负值表示穿透深度）。

**定义 123（模式条件形态速度障碍 MCVO）**
对动态障碍 `O_j`（速度上界 `v_j`）与模式 `m`，形态扫掠体 `S_m(ξ,Δt) = ∪_{t∈[0,Δt]} B(ξ_t)`。模式条件速度障碍
```
VO_m(ξ) = { v | ∃ t∈[0,τ], p + v t ∈ O_j ⊕ (−S_m(ξ,t)) }
```
安全速度集 `SV_m(ξ) = R_m(ξ) \ ⋃_j VO_m(ξ)`，`R_m(ξ)` 为模式 `m` 的可达速度集（轮式含非完整约束与滚动无滑移，腿式含支撑多边形约束）。因 `S_m` 随 `m,q` 不连续变化，`VO_m` 在切换点可能跳变，定义跳变幅度
```
ΔVO(m→m') = Hausdorff(VO_m(ξ), VO_{m'}(ξ'))
```
只有对**整个模式调度** `m(t)` 均满足 `v(t) ∉ ⋃_j VO_{m(t)}(ξ_t)` 才算安全，逐模式静态检查不足以证明。

**定义 124（碰撞谱）**
技能 S 的碰撞谱 `χ_S : 𝔎 × Ξ → [0,1]`，维度 `𝔎 = {static, dynamic, self, terrain, transition}`：
- `χ_static`：静态障碍净空裕度，`clamp01(d_c / d_ref)`；
- `χ_dynamic`：动态障碍最小 TTC 裕度，`clamp01(TTC / τ)`；
- `χ_self`：自碰撞净空裕度（腿-轮-身），`clamp01(d_self / d_self_ref)`；
- `χ_terrain`：地形可支撑置信度（含滑移/塌陷风险）；
- `χ_transition`：模式切换扫掠净空裕度，沿走廊取 min。
`χ=1` 表示该维度完全安全。碰撞安全谓词 `CollSafe(S,ξ) ⇔ ∀κ, χ_S(κ|ξ) ≥ χ_min(κ)`。组合：
```
χ_{S1⊗S2}(κ) = min(χ_{S1}(κ), χ_{S2}(κ))            κ ≠ transition
χ_{S1⊗S2}(transition) = min_{t∈Corridor} χ_{trans}(ξ_t)
```

**定义 125（接触安全动作剖面）**
在第 54 轮 `α_S(a)` 上定义
```
α^safe_S(m,u | ξ) = α_S(m,u|ξ) · 1[v(m,u) ∈ SV_m(ξ)] · 1[SafeSweep(ξ,u)]
```
其中 `SafeSweep(ξ,u)` 要求执行 `u` 的整段扫掠 `{B(ξ_t)}` 只与 `C_sup ∪ C_neu` 接触，且 `d_c(ξ_t) ≥ d_min`。技能能力因此被**碰撞可行域裁剪**；组合只发生在 `α^safe` 的交集上。定义 `cover^safe(S,A_T) = 1 ⇔ ∀a∈A_T: α^safe_S(a) ≥ θ_cov`。

**定义 126（模式调度证书 / 乘积自动机）**
技能组合图 `G_S` 与模式自动机 `A_M=(M, δ_M, m_0, Inv)` 做乘积 `G_S × A_M`，节点 `(S_i,m)`，边 `((i,m),(j,m'))` 有效当且仅当
```
compat^safe(S_i,S_j) ≥ θ_a
∧ c_trans(S_i,S_j) ≤ τ_e
∧ m' ∈ δ_M(m)
∧ CollFree(Corridor(ξ, m→m'))
∧ CollSafe(S_i⊗S_j, ξ)
```
切换走廊 `Corridor(ξ,m→m') = ∪_{t∈[0,τ_sw]} B(ξ_t)` 必须满足 `Corridor ∩ C_forb = ∅` 且走廊内承载力 `λ(t) ≥ λ_min`。证书 `C_mode = (schedule, Corridor, ΔVO, δ_sw, λ_min)`，其中 `δ_sw` 为切换时序误差上界。

**定义 127（接触-碰撞联合证书）**
在第 54 轮 `J=(ρ,A_cert,γ_ce,δ_a,evidence)` 上扩展
```
J^c = (ρ, α^safe, χ, C_mode, C_cert, γ_ce, δ_a, δ_c, evidence)
```
- `C_cert = (C_sup, C_forb, d_min)` 为接触语义证书；
- `δ_c` 为碰撞谱预测与实测偏差上界；
- 其余沿用第 54 轮定义。
部署可判定条件：
```
dom_{J^c}(T)=in
∧ δ_a < Θ_a
∧ δ_c < Θ_c
∧ ρ(d) ≥ ρ_min(d) ∀d
∧ χ(κ) ≥ χ_min(κ) ∀κ
∧ C_mode 的走廊无禁止接触
```

## 2. 关键算法 伪代码

### IP-121 HAS（Hybrid Action Space Profiling）

```python
def hybrid_action_profile(skill, modes, U, xi_grid, sampler):
    alpha = {}
    for xi in xi_grid:
        for m in modes:
            if not mode_reachable(xi, m):
                continue
            for u in U[m]:
                feas, conf = sampler.query(skill, xi, m, u)
                alpha[(xi.key, m, u)] = conf if feas else 0.0
    return alpha
```

### IP-122 CSL（Contact Semantics Labeling）

```python
def label_contacts(xi, env, terrain):
    C = surface_contacts(body_volume(xi), env)
    labels = {}
    for x in C:
        if on_support_surface(x, env) and terrain.bearing_ok(x):
            labels[x] = 'sup'
        elif in_forbidden_region(x, env) or self_contact(x, xi):
            labels[x] = 'forb'
        else:
            labels[x] = 'neu'
    d_c = min_signed_distance(body_volume(xi), forbidden_region(env))
    return labels, d_c
```

### IP-123 CCSP（Contact-Collision Spectrum Profiling）

```python
def collision_spectrum(xi, skill, env, tau):
    chi = {}
    d_static = min_signed_distance(body_volume(xi), env.forbidden.static)
    chi['static'] = clamp01(d_static / D_REF)
    v = skill.velocity(xi)
    ttc = min_time_to_collision(xi, v, env.forbidden.dynamic, horizon=tau)
    chi['dynamic'] = clamp01(ttc / tau)
    d_self = min_self_distance(link_volumes(xi))
    chi['self'] = clamp01(d_self / D_SELF_REF)
    chi['terrain'] = terrain_support_confidence(xi, env.terrain)
    chi['transition'] = clamp01(
        min_clearance(transition_corridor(xi, skill.mode_schedule), env.forbidden) / D_REF)
    return chi
```

### IP-124 MCVO（Mode-Conditioned Velocity Obstacle）

```python
def safe_velocity_set(xi, mode, env, tau):
    all_v = reachable_velocities(xi, mode)
    forbidden = []
    for oj in env.forbidden.dynamic:
        for t in sample_times(tau):
            swept = swept_volume(xi, mode, t)
            forbidden += minkowski_cone(oj, swept, t)
    return [v for v in all_v if not any(in_cone(v, c) for c in forbidden)]

def check_schedule(velocity_traj, mode_sched, env):
```

### IP-125 CACC（Contact-Aware Composition Certificate）

```python
def contact_aware_compose(skill_seq, mode_sched, xi0, env, K):
    xi, records = xi0, []
    for si, sj, mi, mj in pair_with_modes(skill_seq, mode_sched):
        overlap = jaccard(si.alpha_safe, sj.alpha_safe)
        if overlap < THETA_A:
            return ('reject', 'action_incompatible', overlap)
        corr = transition_corridor(xi, mi, mj, TAU_SW)
        if not collision_free(corr, env.forbidden):
            return ('reject', 'transition_collision', corr)
        if min_load_bearing(corr) < LAMBDA_MIN:
            return ('reject', 'transition_unstable', corr)
        chi = compose_spectra(si.chi, sj.chi, corr)
        if min(chi.values()) < min(CHI_MIN.values()):
            return ('reject', 'collision_unsafe', chi)
        rho = compose_robustness(si.rho, sj.rho, K)
        records.append(CompositionEdge(si.id, sj.id, mi, mj,
                                       overlap, chi, rho, corr))
        xi = advance(xi, si, mi)
    return ('ok', JointContactCert(records))
```

### IP-126 MSTC（Mode Switch Transition Corridor）

```python
def transition_certificate(xi, m_from, m_to, env, taus):
    traj = interpolate_mode(xi, m_from, m_to)
    corridor = union(body_volume(x) for x in traj)
    margin = min_signed_distance(corridor, env.forbidden)
    load = min_bearing_capacity(traj, env.terrain)
    dv = hausdorff(velocity_obstacle(xi, m_from),
                   velocity_obstacle(xi, m_to))
    if margin < D_MIN or load < LAMBDA_MIN:
        return ('reject', 'transition_unsafe', margin, load)
    return ('ok', ModeCert(traj, corridor, margin, load, dv))
```

### IP-127 FSC（Foothold Safety Certificate）

```python
def foothold_certificate(f, xi, terrain, env, mu):
    support = static_stability_margin(xi, footholds=xi.footholds | {f})
    friction = friction_cone_margin(f, terrain, mu)
    swing = min_swing_clearance(xi, f, env.forbidden)
    sem = terrain_semantic_confidence(f, terrain)
    if support < S_MIN or friction <= 0 or swing < D_MIN or sem < S_THR:
        return ('reject', dict(support=support, friction=friction,
                               swing=swing, sem=sem))
    return ('ok', FootholdCert(f, support, friction, swing, sem))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| HAS | O(\|Ξ_grid\|·\|M\|·\|U\|·q) | O(\|Ξ_grid\|·\|A\|) | 模式可达性完备、采样覆盖 |
| CSL/CCSP | O(\|∂B\|·\|O\|) | O(\|C\|) | 接触标定 sound、扫掠体保守 |
| MCVO | O(\|R_m\|·\|O_dyn\|·T/Δt) | O(\|VO_m\|) | 相对速度界 sound、TTC 采样细 |
| CACC | O(\|P\|·(\|A\|+\|O\|)) | O(\|P\|+\|E\|) | 走廊证书与碰撞谱逐维传递 |
| MSTC | O(T/Δt·\|∂B\|) | O(\|Corridor\|) | 插值含真实切换瞬态 |
| FSC | O(\|F\|·\|contacts\|) | O(\|F\|) | 支撑/摩擦/摆动三条件合取 |

**正确性定理（Contact-Collision-Aware Composition Soundness）**
在承接第 53–54 轮 (A22)–(A28) 的基础上，假设：
- **(A29) 扫掠保守性**：对任意 `ξ_t`，`B(ξ_t) ⊆ B̂_m(t)`，且切换到下一模式前的 `Δt` 内 `B̂` 覆盖真实体积；
- **(A30) 模式自动机完备**：`A_M` 包含所有可能被调度器触发的模式，未建模模式一律拒绝；
- **(A31) 动态障碍有界**：`||v_j|| ≤ v_j^max`，MCVO 使用该上界构造；
- **(A32) 接触语义可靠**：`C_sup/C_forb/C_neu` 标注错误率 ≤ `ε_c`，且 `ε_c ≤ Θ_c`。
则对满足 `dom_{J^c}(T)=in` 的组合计划：
```
P(success) ≥ 1 − Σ_d(1−ρ_min(d)) − β_E
             − P(δ_a>Θ_a) − P(δ_c>Θ_c)
             − P(transition collision) − P(mode_sched infeasible)
             − ε_c
```
其中 `P(transition collision)` 由 `C_mode` 的走廊证书与实际瞬态的偏差给出。关键：**碰撞谱与鲁棒性谱同构传递**、**过渡走廊显式建模**、**接触语义把「必要接触」从碰撞中豁免**；三者缺一，证书即不 sound。

```python
def hybrid_action_profile(skill, modes, U, xi_grid, sampler):
    alpha = {}
    for xi in xi_grid:
        for m in modes:
            if not mode_reachable(xi, m):
                continue
            for u in U[m]:
                feas, conf = sampler.query(skill, xi, m, u)
                alpha[(xi.key, m, u)] = conf if feas else 0.0
    return alpha
```

### IP-122 CSL

```python
def label_contacts(xi, env, terrain):
    C = surface_contacts(body_volume(xi), env)
    labels = {}
    for x in C:
        if on_support_surface(x, env) and terrain.bearing_ok(x):
            labels[x] = 'sup'
        elif in_forbidden_region(x, env) or self_contact(x, xi):
            labels[x] = 'forb'
        else:
            labels[x] = 'neu'
    d_c = min_signed_distance(body_volume(xi), forbidden_region(env))
    return labels, d_c

def contact_safe(xi, env, terrain, d_min):
    labels, d_c = label_contacts(xi, env, terrain)
    return (all(v != 'forb' for v in labels.values())
            and d_c >= d_min)
```

### IP-124 CCSP

```python
def collision_spectrum(xi, skill, env, tau):
    chi = {}
    d_static = min_signed_distance(body_volume(xi), env.forbidden.static)
    chi['static'] = clamp01(d_static / D_REF)
    v = skill.velocity(xi)
    ttc = min_time_to_collision(xi, v, env.forbidden.dynamic, horizon=tau)
    chi['dynamic'] = clamp01(ttc / tau)
    d_self = min_self_distance(link_volumes(xi))
    chi['self'] = clamp01(d_self / D_SELF_REF)
    chi['terrain'] = terrain_support_confidence(xi, env.terrain)
    chi['transition'] = clamp01(
        min_clearance(transition_corridor(xi, skill.mode_schedule),
                      env.forbidden) / D_REF)
    return chi
```

**正确性定理（Contact-Collision-Aware Composition Soundness）**
假设第 53–54 轮 (A22)–(A28) 成立，并新增：
- **(A29) 扫掠保守性**：`B(ξ_t) ⊆ B̂_m(t)`，且切换前的 `Δt` 内 `B̂` 覆盖真实体积；
- **(A30) 模式自动机完备**：`A_M` 覆盖所有可被触发的模式，未建模模式默认拒绝；
- **(A31) 动态障碍有界**：`||v_j|| ≤ v_j^max`，MCVO 用该上界构造；
- **(A32) 接触语义可靠**：`C_sup/C_forb/C_neu` 标注错误率 `ε_c ≤ Θ_c`。
则对满足 `dom_{J^c}(T)=in` 的组合计划：
```
P(success) ≥ 1 − Σ_d(1−ρ_min(d)) − β_E
             − P(δ_a>Θ_a) − P(δ_c>Θ_c)
             − P(transition collision) − P(mode_sched infeasible)
             − ε_c
```
关键：**碰撞谱与鲁棒性谱同构传递**，**过渡走廊显式建模并计入承载力**，**接触语义把必要支撑接触从碰撞中豁免**。任一假设失效，`J^c` 不再 sound。
