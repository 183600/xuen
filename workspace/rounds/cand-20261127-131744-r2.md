## 1. 直觉与动机（两个灵感的碰撞 + 一次事实纠偏）

**灵感 1（手眼标定 → 不是"抗相机变化"，而是"像素到 base 系的度量桥"）**
- 直觉（先给一个会被事实推翻的版本）：看到"手眼标定"，最自然的联想是"评测会换相机位姿，所以要标外参做位姿鲁棒"。**F21 直接否定了这个前提**——5 条泛化轴里没有相机位姿。所以本轮不能照搬经典动机，必须重新定位。
- 重新定位后的直觉：真正的缺口是**几何**。策略吃 RGB、吐 base 系 ee 位姿（F20），中间隔着一条"2D 像素→3D base 坐标"的桥；没有深度通道，这条桥只能由**标定 + 多视图/运动视差**搭出来。位置（轴1）、未见物品（轴4）本质是"物体在 base 系的度量位置/朝向/尺度变了"；干扰物（轴2）、人为干扰（轴5）本质是"场景几何在变"。手眼标定的价值不是抗相机变化，而是把语言条件策略的"看起来对"升级为"算出来对"的**几何接地**。
- 严格化：设腕相机↔ee 刚体变换 `T_ee_cam`、高相机↔base `T_base_cam`。检测像素 `u` 反投影为相机射线，配合深度 `d`（单目估计 / 多视图三角化 / 运动视差）得 base 系 3D 点 `X = T_base_cam · π^{-1}(u, d; K)`。策略动作 `a=(x,R,g)` 本就在 base 系，与 `X` 同系 → 可定义**几何一致性约束**：预测抓取点应落在检测物体 3D 包围盒表面、接近方向应穿过物体主轴、插入深度应可达。这把"端到端隐式学几何"变成"显式可校验几何"。

**灵感 2（决策规划 → chunk 是动作原语，得分点是子目标自动机）**
- 直觉：VLA 每 `T_a` 步吐一个 chunk，本质是"开环执行约 1 秒"。但 32 个任务都是多阶段（接近→抓→移→放/插），而官方步骤分（F17）本就是**有序里程碑**。于是"决策规划"有了一个极具体的抓手：**把得分点清单编译成子目标自动机（subgoal automaton），chunk 是自动机状态约束下选的"动作原语"**。这一下同时解决三个老问题：I5 的恢复何时触发（自动机卡住）、I4 的 chunk 该多长（子目标粒度）、I8 的消融该测什么（规划器开/关）。
- 严格化：任务 `i` 的得分点序列 `g_1 ≺ g_2 ≺ … ≺ g_k`（满分 100）定义单调进度 `φ_t ∈ {0..k}`，由 I5 进度头给出状态后验 `P(g_j | obs_t)`。决策问题＝在每个决策时刻 `τ`（chunk 边界）选 chunk `c ∈ C` 最大化
  `J(c) = E[Δφ(c)] + λ·P_succ(c) − μ·cost(c) − ν·budget_risk(c)`，
  其中 `Δφ` 由进度头/轻量 critic 估计，`cost` 含限位/碰撞/平滑度，`budget_risk` 含 180s 超时风险（F21）。`C` 由策略多次采样（best-of-N）给出。**这是"用学到的进度价值做 chunk 级 MPC"，比 I7 的视频世界模型 rollout 便宜一个数量级。**

**灵感 3（两者交叉 → 外部扰动下的"重定位—重规划"闭环）**
- 直觉：人为干扰（轴5）会**在任务中途移动物体**——此时"计划失效"与"几何失效"同时发生：自动机子目标的前提（物体在旧位置）被打破，必须**重新检测→重新接地到 base 系→重新选子目标**。这正是两个灵感词的交点：手眼标定回答"新位置在哪"，决策规划回答"接下来做什么"。单独任一都不够——只有规划没几何，干扰后不知往哪抓；只有几何没规划，不知该继续、回退还是放弃。
- 严格化：干扰事件 `e_t`（I4 手部/运动异常检测）触发 `REPLAN`：`X_new = triangulate(detect(obs_t), T)`；若 `‖X_new − X_plan‖ > δ`，作废当前 chunk 队列与子目标前提，重算 `φ` 与 `J(c)`。把"抗干扰"从被动停持（I4）升级为**主动重规划**。

**三者统一（本轮论点）**：第 2 轮把胜负手押在**数据引擎**（让策略"知道什么"）；本轮补上两条被忽略的正交轴——**手眼标定决定它"在哪个坐标系里动"，决策规划决定它"按什么顺序动"**。数据解决分布覆盖，几何解决像素↔度量接地，规划解决多阶段与外部扰动。**本轮结论：数据引擎之后，剩余的分数洼地是"几何接地 + 时序决策"，不是模型容量。**

## 2. 对上一轮痛点的增量修订

- P2（泛化缺口）再细化：5 轴中位置/干扰物/背景/未见物品 4 轴都可用"几何一致性"部分吸收；**人为干扰是唯一必须靠"检测→重规划"闭环的轴**，不能被增广吃掉。

- 新增 P9（几何不可观）：无深度 + 接口不提供内参/外参 → 3D 只能靠估计，误差会直接进动作；必须"误差感知"，否则几何桥把噪声放大成动作抖动。

## 3. 研究问题（本轮立项 Q9–Q12，Q1–Q8 保留）

- **Q9（标定可解性与误差传播）**：从 32 任务示教能否稳定解出腕相机↔ee、高相机↔base 外参？内参缺失时误差如何传播到 base 系抓取点（`∂X/∂K, ∂X/∂T`）？多大误差会超过任务容差（插网线/放杯的毫米级）？
- **Q10（最小充分几何表示）**：无深度、4 视图下，哪种表示最省且够用——3D 关键点、物体 6D 位姿、单目深度、还是"腕相机近距相对位姿"？它对未见物品轴（轴4）的迁移性如何？
- **Q11（自动机 + chunk-MPC 的收益/预算）**：把 F17 得分点编译成自动机后，best-of-N chunk 选择 + 卡住重规划相对纯反应式策略，成功率增益多大？在 `T_a×周期` 预算内 N 能取多大（延迟 vs 增益）？
- **Q12（干扰重规划闭环）**：人为干扰（轴5）下"重定位→重规划"能否把"干扰后必败"转为"可恢复"？重规划延迟（检测+三角化+重采样）是否吃掉剩余 180s 预算？

## 6. 本轮最大风险

**一句话**：I10 的全部价值建立在"能从数据稳定解出 4 路相机外参、并在无深度条件下得到毫米级 3D"这一假设上；但接口不提供内参、高相机是否随 `pivot`/`lower_body` 运动未知，一旦标定误差超过接触任务容差，几何桥不仅无益，还会把误差注入动作、伤到原本能靠端到端学会的任务——因此 I10 必须先用"标定残差 + 误差传播 vs 任务容差"的 L0 可解性验证决定是否接入动作，而不是先写桥。

## 7. 下轮迭代计划

- **深化**：I10（可解性验证先行：用示教数据跑 AX=XB + 机械臂自标定 PnP，量化残差与误差传播，再定 3D 表示）；I11（把 F17 得分点逆向成自动机 schema；实现 chunk best-of-N + deadline 预算的离线回放评估）。
- **修剪**：I7 正式并入 I11（推理路径移除，WMA 资产转数据）；若 I10 可解性验证失败，I10 降级为"仅训练时几何辅助监督"（几何一致性作 aux loss，推理纯端到端），不阻塞主链。
- **待核实**：每任务得分点 JSON（挑战页 JS 数据端点，本轮尝试未果：页面为反爬渲染，需另找接口）；数据集是否附带相机内参/外参标定文件；高相机是否随 `pivot`/`lower_body` 运动；挑战真实控制频率 `f`（F23 预算公式需要它）；"单模型"是否允许内部多组件（I3/I9/I10/I11 共用确认）。

# UniBot-V1 参赛创新点清单（第 3 轮 v1.2）

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 v3 考纲校准五轴增广引擎 + 几何一致性过滤 ★★★★★
- **动机**：同 v1.1（五轴泛化是全局乘性损失）；**新增**：v1.0/v1.1 最大未解风险是"位置重拼接物理不可行（物体悬空/穿模）"。
- **本轮深化（手眼标定）**：用 I10 标定 + 深度把 2D 重拼接升级为 **3D 一致校验**——物体平移后检查 (a) 落在支撑面、(b) 在夹爪可达域、(c) 遮挡/阴影一致；不满足的样本前置丢弃。把"不可行动作占比 >5% 才降级"的被动判据，变成**生成时过滤**。
- **与现有差异**：盲目增广只改像素；本点要求每个增广样本在 base 系 3D 自洽（PR6）。
- **技术可行性**：中-高（依赖 I10；退化方案：单目深度 + 平面拟合做粗校验，不需精确外参）。
- **所需资源**：1×24GB GPU；增广输出磁盘同 v1.1。
- **落地步骤**：①I10 标定/深度就绪；②3D 一致性过滤器；③五轴增广接过滤器；④L0 剂量-响应复测（对比 v1.1 无过滤器）。
- **风险**：过滤过严导致增广多样性下降（缓解：过滤率与增益一起进 I8 注册表）；依赖 I10。

### I2 v2 数据引擎 2.0（维持 v1.1，不重复展开）
- 孪生语料 + 官方 loader 加权 patch + 示教质量加权。本轮仅一处接口变更：I10 的"物体 3D 特征"可作为 I9 检索库的键，减少重复嵌入。

### I3 v2 接触任务族 base 系 3D 视觉伺服回退 ★★★★
- **动机**：同 v1.1；接触任务（插网线/插充电器/放置）对毫米级对齐敏感，图像空间伺服受视角影响。
- **本轮深化（手眼标定）**：用 I10 解出的腕相机↔ee 外参，把关键点从**图像空间**提升到**base 系 3D**：`X = T_base_ee · T_ee_cam · π^{-1}(u, d)`；伺服误差 `e = X_target − X_current` 直接是 base 系米制，与 `ee` 动作同系。腕相机近距 → 深度不确定性更小。
- **与现有差异**：v1.1 图像伺服需按视角调增益；3D 伺服增益与视角解耦，且能直接加"插入深度"约束。
- **技术可行性**：中（依赖标定精度；退化方案 I3'：几何作训练辅助监督，推理端到端）。
- **所需资源**：标定 1 人周；无额外大模型。
- **落地步骤**：①标定残差 < 任务容差 1/3 才启用；②6–8 接触任务选 3 个试点；③3D 伺服 vs 图像伺服 L0 + 单任务 A/B；④不达标即走 I3'。
- **风险**：标定误差在接触段被放大（缓解：腕相机近距 + 触发滞回 + 退化为纯位置控制）。

### I4 v2 干扰事件检测 + 自适应 chunk ★★★★
- 维持 v1.1 的手部检测与状态机；本轮接口：把"检测到人手/物体被移动"输出为 `interference_event`，**交给 I11 触发 REPLAN**（而非只停持）。chunk 长度由 I11 的子目标粒度决定。
- **风险**：误检触发无谓重规划（缓解：置信门控 + 仅当 3D 位置差 > δ 才重规划）。

### I5 v2.1 非标称示教合成 + 自动机进度头 ★★★★
- 维持 v1.1 的扰动重放/跨段缝合/得分点过滤；本轮升级：进度头从标量 `φ` 改为**自动机状态后验** `P(g_j | obs)`，并加单调性约束（不能回退子目标，除非 REPLAN）。该后验直接是 I11 的 `Δφ` 估计器。
- **风险**：自动机状态标注依赖 F17 逆向（未完成前用伪里程碑 + 人工抽检）。

### I6 确定性低延迟部署服务（维持，预算模型修正）
- **关键修正**：预算按 **chunk 级** `T_a/f`（F23），而非单步 66ms。以 `T_a=16, f=15Hz` 量级参照 ≈1.07s/决策；best-of-N（N=4–8）在此预算内可行。p99 目标改为"单次 `get_action` p99 < 0.8·T_a/f"。
- 其余（共享 backend、端口隔离、量化、CUDA Graph、断线重连）同 v1.1。

### I7 世界模型测试时前瞻 → 并入 I11（修剪）
- **推理路径移除**：视频 rollout 的"择优"由 I11 的"进度 critic + best-of-N chunk"以更低成本实现；WMA-0 仅保留为 I5 数据引擎。若 I11 L0 显示 critic 不足，再考虑恢复极小规模 rollout。

### I8 v2.1 评测运营闭环 + 分级消融注册表
- 维持 v1.1 的 L0/L1/L2 与相关性注册表；新增两组 L0 因子：`I10 标定开/关`（几何是否伤标称）、`I11 规划开/关`（best-of-N/重规划增益）。**关键**：因排名以成功率为主（F22），消融主指标改为**成功率**，步骤分只作平局/次级。

### I9 reset 期检索类比迁移（维持）
- 维持；复用 I10 的物体 3D/几何特征作检索键，增强"同类不同外观"（轴4）区分。

### I10 手眼标定坐标桥（新） ★★★★
- **动机**：策略吃 RGB、吐 base 系动作（F20），中间缺"像素→base 3D"的桥；无深度（F20）；位置/干扰物/未见物品三轴本质是几何变化（F21）。手眼标定是把"端到端隐式几何"变成"可校验显式几何"的最低成本路径。
- **与现有差异**：端到端 VLA 让网络自己学几何，样本效率低、误差不可诊断；本点从数据解外参 + 多视图/运动视差补深度，提供度量桥与误差界。**注意**：不是"抗相机位姿变化"（相机不是泛化轴，F21），而是"几何接地"。
- **技术可行性**：中-高。
  1. **腕相机↔ee**：刚性连接，数据每帧有 ee 位姿 → 经典 AX=XB（Tsai-Lenz/对偶四元数）可解；相机相对运动由视觉里程计/特征跟踪估计；残差可交叉验证。
  2. **高相机↔base**：**用机械臂自身作标定物**——关节角 + 正运动学给出连杆 3D 点，高相机观测到机械臂 → PnP 解外参（无需外部标定板）。若高相机随 `pivot` 运动（F20 提示躯干可动），则把关节角纳入外参模型，**先核实**。
  3. **深度**：单目深度估计（Depth Anything 类）或 4 视图三角化；腕相机近距优先。
  4. **误差传播**：`Σ_X = J Σ_calib J^T`，`J = ∂X/∂(K,T,d)`；给出每任务"可容忍标定误差"，超容差即门控关闭几何通道。
- **所需资源**：1×GPU 日（深度/标定）+ 1 人周工程；无额外训练大模型。
- **落地步骤**：①**可解性验证先行**（AX=XB 残差、自标定 PnP 残差、误差传播 vs 任务容差）；②通过才接入 I3/I1/I11；③不通过降级为"训练时几何辅助监督"（几何一致性作 aux loss，推理端到端）。
- **风险**：内参缺失/高相机随动 → 标定误差超容差（缓解：可解性验证前置、腕相机近距、误差感知门控、降级方案）；误差注入动作伤标称任务（缓解：L0"标定开/关"，标称 Δ成功率 ≥ 0 才启用）。

### I11 得分点驱动分层决策规划（新） ★★★★
- **动机**：任务多阶段、步骤分＝有序里程碑（F17）；排名以成功率为主（F22）；chunk 开环执行（F23）→ 需要"选哪个 chunk、何时重规划、预算怎么花"的决策层；人为干扰（轴5）使计划中途失效。
- **与现有差异**：纯反应式 chunk 策略无显式计划、易卡局部极小、干扰后不知回退；I7 用昂贵视频 rollout。本点用**学到的进度 critic 做 chunk 级 MPC**，成本低一个数量级。
- **技术可行性**：中-高。
  - **子目标自动机**：`g_1≺…≺g_k`，状态后验 `P(g_j|obs)` 来自 I5 进度头；单调约束。
  - **chunk 选择**：每个决策时刻采样 `N` 个 chunk，按 `J(c)=E[Δφ]+λP_succ−μcost−νbudget` 选优；`cost` 用限位/碰撞/平滑度近似。
  - **deadline-aware**：180s 预算按子目标点值/难度分配；某子目标耗预算 >ρ 且 `Δφ≈0` → 触发重抓/回退/放弃。
  - **干扰重规划**：I4 事件 + I10 重定位 → 位置差 >δ 则作废队列、重算 `φ`、重选 chunk。
- **所需资源**：critic 训练 1–2 GPU 日；离线回放环境（在示教状态上评估 `J`）；1–2 人周。
- **落地步骤**：①F17 逆向 → 自动机 schema；②离线回放实现 chunk-MPC（评估"所选 chunk 与真值下一 chunk"的一致性）；③deadline 策略仿真；④N/λ/μ/ρ 的 L0 剂量-响应；⑤单任务通道 A/B（成功率、平均步数、超时率）。
- **风险**：进度 critic 误差导致选错 chunk（缓解：仅在 critic 高置信时启用 best-of-N，低置信退回单样本）；重规划延迟吃预算（缓解：检测+三角化 <200ms，仅在必要时触发）；多组件触碰"单模型"边界（缓解：全部封装进同一 PolicyService + 书面确认）。

### 1.2 子目标自动机 + chunk-MPC（I11）

```python
class SubgoalAutomaton:                    # 由 F17 得分点逆向：g_1≺…≺g_k
    def advance(self, j, obs):             # I5 进度头给状态后验
        p = self.progress_head(obs)        # p[j] = P(已达 g_j)
        return j + 1 if (p[j + 1] > 0.7 and self.monotone_ok(j + 1)) else j

class ChunkMPC:
    def select(self, obs, j, budget_left):
        cands = [self.policy.sample_chunk(obs) for _ in range(self.N)]
        best = None
        for c in cands:
            dphi = self.progress_head.expected_delta(obs, c, j)
            ps   = self.success_critic(obs, c, j)
            cost = self.cost(obs, c)                 # 限位/碰撞/平滑
            risk = self.budget_risk(budget_left, j)  # 180s 超时风险
            score = dphi + self.lam * ps - self.mu * cost - self.nu * risk
            best = max(best, (score, c), key=lambda t: t[0])
        return best[1]

    def step(self, obs, state, budget_left):
        if self.interference_detected(obs):          # I4 事件
            X_new = pixel_to_base(self.detect(obs), "wrist", obs, self.calib)
            if norm(X_new - state.X_plan) > DELTA:   # I10 重定位
                state = self.replan(obs, X_new)
        j = self.automaton.advance(state.j, obs)
        if self.stalled(j, budget_left):             # Δφ≈0 且耗预算>ρ
            state = self.recover_or_abandon(j, budget_left)
        return self.select(obs, j, budget_left), state
```

## 7. 本轮结论与最值得押注

**结论**：第 2 轮把分数洼地归因于"数据"；本轮补上两条正交轴——**几何接地（I10）** 与 **时序决策（I11）**。数据解决"见过没有"，几何解决"在 base 系哪里"，规划解决"先做什么、被干扰后怎么办"。三者不重叠，且都落在推理期低成本计算上。

**最值得押注（一句话）**：**押 I11（得分点自动机 + chunk 级 best-of-N MPC）作为"数据引擎之后"的第二增长曲线**——它直接对齐排名主序（成功率，F22）、复用 F23 的 chunk 预算、且不依赖尚待验证的标定精度；I10 作为并行高风险高回报项，先过可解性验证再决定是否接入动作。
