# 第 11 轮（本轮灵感：「推理延迟」×「流匹配策略」；接续 v10）

> **基线**：第 10 轮 MetricVoiceGauge-SHIELD（定义 540–547；引理 87–91；实验 E571–E590）。
> 本轮纪律：**把推理延迟从"要隐藏的抖动"升级为"可分配、可证书化的一等资源"**。流匹配只负责提案，v10 盾与 v9 证书仍能否决；延迟预算只影响"走几步"，不影响"能不能做"。三个新模块全部可选：失效即注入中立元，严格等价退回 v10。

## 0. 直觉与动机

**灵感 1（流匹配策略 → 连续时间动作块生成）**
直觉：v9 的 MPC 采样（n=64）与 v10 的残差 actor 都是"一次性"生成，质量被固定候选数与固定预算锁死；流匹配把策略学成一个速度场，从噪声积分到动作块，天然支持多步细化与随时停机。核心创新 **FlowChunkPolicy（FCP）**：用 rectified flow 学习动作块 ζ 的速度场 v_θ(x_τ, τ | s, c)，条件 c 含证书余量、K_eff、Δ_dom/risk_SLAM 与人类意图嵌入；生成结果仍只进入 v9 认证集与 v10 盾的**候选层**——流只负责"想"，证书负责"准"。

**灵感 2（推理延迟 → anytime 生成与截断证书）**
直觉：流生成的"质量—延迟"曲线不是二元的，NFE 越多截断误差越小；但"少走几步"必须显式进入安全证书，否则会出现在证书算完之后动作又被细化的"先证后改"漏洞。核心创新 **AnytimeFlowIntegrator（AFI）**：在任意 NFE n 输出 (a^{(n)}, ε_n)，把截断误差 ε_n 经证书灵敏度 κ_F 折算进 v9 的 β；并强制**先认证、后执行**的原子性——只执行已认证前缀，细化只发生在未提交后缀。**更少 NFE ⇒ 更大证书膨胀 ⇒ 更短 K_eff**，安全性随延迟自动收缩，而不是随时间表默默失效。

**灵感 3（尾延迟 → 保形预算与弹性 NFE 分配）**
直觉：平均延迟达标不等于 50Hz 达标；真正的敌人是 p99 尾延迟、硬件争用与热降频。核心创新 **LatencyConformalScheduler（LCS）**：用保形预测校准每级 NFE 的 (1−α) 尾延迟上界，在 MW 契约的块生成预算内按"每毫秒安全增益"做弹性 NFE 分配；若连 n=1 都不可行，直接拒绝流路径、注入中立元退回 v10。于是"按时"本身成为一个可证明的概率命题，而不是乐观假设。

## 1. 研究问题（轮次升级版）

- **Q1（截断—证书耦合）**：如何把流积分截断误差严格折算进块证书，使任意 NFE 下**被执行的动作就是被认证的那个动作**（无"先证后改"）？复用旧证书与重算证书的边界在哪里？
- **Q2（延迟—安全分配）**：在 p99 尾延迟约束下，弹性 NFE 分配能否同时保证 50Hz 与 v9/v10 的安全不变量？何时应主动放弃流路径而不是压缩积分步数？
- **Q3（偏移—误差相关）**：域偏移同时放大速度场误差、前向模型误差与硬件延迟；Δ_dom 门控能否解耦"更慢"与"更不安全"，避免在最需要安全时过度保守（K_eff→1，无收益）或过度乐观（κ_F 低估）？

## 2. 设计原则（P16–P18）

**P16 流提案律（Flow-as-Proposal, FCP）**
动作块由速度场 ODE 生成，生成结果不自动获得执行资格：必须经 v9 块证书、中止点集、v10 盾 S_C 与 M₀。流模块的失效/超时/拒绝 ⇒ 注入中立元（v10 采样块 + 残差基准），决策流逐位等价 v10。流只改变"候选从哪来"，不改变"哪些候选能执行"。

**P17 截断证书律（Truncation-Certified Anytime, AFI）**
对任意 n 输出 (a^{(n)}, ε_n)，证书使用 β_total(n)=β_model+κ_F·ε_n（复用模式）或 β_model（在发出动作上重算的 emit 模式）；认证与执行原子化：认证后不再改动已提交前缀。ε_n 单调不增；n 增大只能扩大认证集，不能缩小。M₀ 硬检查永远用 emit 模式。

**P18 保形延迟律（Conformal Latency Budget, LCS）**
每级 NFE 的尾延迟上界由保形分位数给出，覆盖率 ≥1−α（非平稳下用 ACI 维持长期覆盖率）；分配器在 Σ 预算内最大化 Σ 安全增益，分配不可行或预测失配 ⇒ 降级 NFE，最终退回 n=1/中立元。延迟预测器只影响分配，不进入证书 claim。

## 3. 与基线的接口（如何退化）

- FCP 失效/超时/输出越界 ⇒ 用 v10 的 MPC 采样与 SRPI 残差提案，严格等价 v10；
- AFI 失效 ⇒ 固定 n=1 且按 emit 模式重算证书，等价 v9 的短块/单步语义；
- LCS 失效 ⇒ 保守固定 NFE 与静态预算（取历史最大值），等价 v10 时序；
- n=1、流路径被拒绝或 deadline_guard 触发 ⇒ 中立元注入，严格 v10 决策流；
- 以上任意组合失效 ⇒ 按 v10 六轴退化链退回 v9→v8→v7→v6。

## 4. 预期贡献

1. **流匹配动作块生成**及其与 v9 块证书的耦合：提案质量随 NFE 细化，安全性不随提案变化；
2. **anytime 截断证书 + 先证后执行原子性**：把推理延迟变成安全裕度的单调收缩量，堵住"先证后改"漏洞；
3. **保形 p99 延迟预算与弹性 NFE 分配**：把"按时"从工程假设变成带覆盖率的概率保证；
4. **延迟—安全—偏移三账本**：E591–E610 覆盖 NFE 曲线、证书紧致性、保形覆盖、尾延迟、偏移耦合、退化等价与端到端任务。

## 5. 本轮最大风险

**一句话**：流匹配的 anytime 截断把"延迟"变成可分配资源，但截断误差与域偏移/模型误差在证书里相加——若 κ_F 在陌生域被低估，系统会在"按时"执行一个证书已失效的动作，即**最危险的失败不是超时，而是准时地不安全**。

# 第 11 轮产物 · 创新点清单 v11：**MetricVoiceGauge-FLOW**

> 背景：第 10 轮 MetricVoiceGauge-SHIELD（定义 540–547；引理 87–91；实验 E571–E590）。
> 本轮灵感：「推理延迟」×「流匹配策略」
> **继承纪律**：v10 的 SRPI/MIA/TCE/PRA 与 v9 的 AC/MW/ID、九不变式全部保留；FCP/AFI/LCS 一律为**可选增强**，且只位于提案层与块生成时序层：任一环节不可用 ⇒ 注入中立元，严格等价退回 v10（引理 96），而非行为漂移。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 MetricVoiceGauge-SHIELD v10） |
|---|---|---|---|
| IP-340–360 | v10 全部模块 | 继承 | 语义不变；流模块只替换块生成/残差提案的"生成器"，不改变认证与仲裁 |
| IP-361 | FlowChunkPolicy 流匹配动作块策略 | 新增核心模块 | rectified-flow 速度场 v_θ(x_τ,τ\|s,c) 生成动作块；条件含证书余量、K_eff、Δ_dom/risk_SLAM 与人类意图嵌入；仍受 v9 证书 + v10 盾筛选 |

| IP-363 | LatencyConformalScheduler 保形延迟调度器 | 新增核心模块 | 每级 NFE 的 (1−α) 尾延迟上界；块生成预算内按"每毫秒安全增益"弹性分配 NFE；不可行即拒绝流路径 |

**退化链声明（v11 契约化七轴）：**
- Level-0（新增）：FCP 失效/超时/输出越界 ⇒ 用 v10 的 MPC 采样与 SRPI 残差提案；AFI 失效 ⇒ 固定 n=1 且 emit 模式重算证书；LCS 失效 ⇒ 静态保守 NFE；三者互不耦合，任一失效均不改变 v10 决策流；
- Level-1：SRPI 失效/回滚 ⇒ Δa≡0，执行 v10 认证块；MIA 失效/超时 ⇒ 弃权；TCE 失效 ⇒ 静态摘要；PRA 失效 ⇒ 冻结 v9 权重；
- Level-2：AC 证书失效或信任域破坏（Δ_dom ≥ τ_dom ∨ risk_SLAM ≥ τ_SLAM）⇒ K_eff←1，等价 v9 决策粒度；
- Level-3：MW 失效 ⇒ 切换 v8 手写网关代码路径，等价 v8 集成方式；
- Level-4：ID 失效 ⇒ 全模块 active、归因冻结，等价 v8 全模块常开；
- Level-5：v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；
- Level-6：全失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

**安全不变量（v11 新增，叠加于 v10 之上）：**
- **I-E（anytime 可靠性）**：∀t，被执行的动作就是被证书覆盖的动作；已提交前缀在认证后不可变，不存在"证书算在 A、执行 B"的窗口；
- **I-F（延迟可行性）**：每块生成以概率 ≥1−α 在预算内完成；否则 deadline_guard 注入中立元退回 v10，绝不延长 50Hz 周期；
- **I-G（流不扩权）**：流只改变候选来源，不扩大可执行集合；a_exec ∈ C_t 与 I-A/I-B 原样成立；
- **I-H（单调降级）**：NFE 越少 ⇒ 证书膨胀越大 ⇒ K_eff 越小；延迟压力只能收缩安全边界，不能扩张。

**新增定义 548（流匹配动作块生成 FlowChunkPolicy）** 设专家动作块分布 p_1、噪声 p_0=N(0,I)，rectified flow 以回归目标训练速度场：
```
L(θ) = E_{x_0∼p_0, x_1∼p_1, τ∼U[0,1]} ‖ v_θ(x_τ, τ | s, c) − (x_1 − x_0) ‖²
x_τ = (1−τ)x_0 + τ x_1
```
采样用 Euler：x^{(0)}=x_0，x^{(i+1)}=x^{(i)}+h·v_θ(x^{(i)}, ih|s,c)，a^{(n)}=x^{(n)}。条件 c=(m_1,m_2,m_3,K_eff,Δ_dom,risk_SLAM,e_intent)，其中 m_· 为 v9 证书的归一化余量，e_intent 为 MIA 的意图嵌入（仅作条件，不赋权）。**FCP 的输出只进入 v9 `generate_chunk` 的候选池，替换 `policy.sample_sequences`；`_abort_points`、证书判据、δ_trigger 与盾判定全部复用 v9/v10 原实现。**

**新增定义 549（任意时刻截断包络 Anytime Envelope）** 设 v_θ 关于 x 为 L_v-Lipschitz 且沿轨迹二阶导有界，Euler 全局误差满足
```
‖a^(n) − a^∞‖∞ ≤ C_v / n，  C_v := (e^{L_v} − 1)/(2 L_v) · sup_{x,τ} ‖D²v_θ‖
```
并取 ε_n := C_v/n（乘 1.2 安全系数，E592 标定）。对 n_ref > m：
```
‖a^(m) − a^(n_ref)‖∞ ≤ ε_{m|n_ref} := C_v(1/m − 1/n_ref)
```
ε_n 关于 n 单调不增；n=1 时退化为"单步欧拉"，由 v9 单步 fallback 接管语义。

**新增定义 550（截断感知证书 Truncation-Aware Certificate）** 证书有两种模式：
```
emit：Ĉ 在 a^(n) 本身上计算，β_total = β_model；
reuse：Ĉ 在 a^(n_ref) 上计算、执行 a^(m)（m<n_ref），β_total = β_model + κ_F·ε_{m|n_ref}。
```
其中 κ_F 为连续指标（间隙 g、能耗 e）对动作的联合 Lipschitz 常数；γ_grasp 为离散谓词，只能走 emit，或使用其连续稳定裕度代理。认证规则：
```
g_min = min_k F̂_g(s, a^{1:k}) − β_total ≥ d_safe
e_max = max_k F̂_e(s, a^{1:k}) + β_total ≤ τ_eff
γ̂_grasp = valid；P_t ≠ ∅；M₀ = pass
```
**M₀ 硬检查与 K_eff 相关的全部软层一律用 emit；reuse 只允许用于非安全关键的候选排序/预筛。** 若 β_total 使 g_min < d_safe，则不得复用，必须重算或退回 v10。

**新增定义 551（前缀冻结与原子认证 Prefix Commitment）** 块生成时取 m = min(K_eff, m_commit)，对 a^{1:m} 以 emit 模式独立认证并计算 P_t；冻结 `(a^{1:m}, Ĉ_prefix, P_t)`，执行期逐周期只读该前缀。后缀 a^{m+1:K} 可在下一个 5Hz 边界继续细化，但不得回写前缀；若后缀改变导致某中止点失效，只重算后缀的中止点并在解冻前重新认证。若积分在预算内未完成，执行**最后已认证前缀**并在其最后一个中止点安全停驻（与 v9 K=1 fallback 同构）。

**新增定义 552（保形延迟预算 Conformal Latency Budget）** 对每级 n 维护校准集 D_n={(c_i,L_i)}，非一致性分数取延迟 L_i；保形上界
```
q_{1−α}(n) = Quantile_{⌈(N_n+1)(1−α)⌉/N_n}(D_n)
```
在可交换性下 P(L_n ≤ q_{1−α}(n)) ≥ 1−α。非平稳硬件/热降频下用 ACI：
```
q_{t+1}(n) = q_t(n) + γ_aci·(α − 1{L_t > q_t(n)})
```
块生成可行 ⇔ q_{1−α}(n)+rsv ≤ B_flow。**选择性偏差控制**：n 由 q 选择会破坏同分布覆盖，故按上下文分箱（Δ_dom 档 × 负载档）做条件保形，或使用 ACI + 预注册的 E594 覆盖率审计。

**新增定义 553（弹性 NFE 分配 Elastic Allocation）** 候选级别 N={1,2,4,8,16,32}。安全增益 G(n) 由证书余量与历史成功率估计（单调非减、经验上凹），成本 t(n)=q_{1−α}(n)。单块生成预算下：
```
n* = argmax_{n∈N, t(n)+rsv ≤ B_flow} G(n)
若 N_feasible=∅：返回 ⊥（中立元，走 v10 路径）
若剩余预算 ≥ t(n_min)：可在 n* 之外再生成 r 个低 NFE 候选，按边际增益/毫秒贪心
```
安全单调性：n 增大使 ε_n 不增、β_total 不增，故认证集与 K_eff 单调不缩。

**新增定义 554（deadline 条件化流 Deadline-Conditioned Flow）** 可选升级：v_θ 额外条件于 ρ=τ_rem/B_flow 与 n，训练时随机丢弃积分步/随机 n，加入轨迹一致性损失
```
L_con = E_{m<n} ‖ a^(m) − SG(a^(n)) ‖²
```
（SG 为 stop-gradient）。它改善低 NFE 质量，但**不改变安全性**：证书永远在发出的 a^(n) 上算，不依赖 L_con 是否收敛。

**新增定义 555（流模块中立元表 NeutralElementTable）** 每行：失效源 → v^⊥ → 等价 v10 级：

| 失效源 | 中立元 v^⊥ | 等价行为 |
|---|---|---|
| FCP（速度场/网络） | v10 MPC 候选池 + SRPI 残差 | 精确 v10 |
| AFI（积分器/证书） | n=1 的 emit 证书 + v9 单步 fallback | v9 短块语义 |
| LCS（延迟调度） | 静态 NFE₀ 与历史最大预算 | v10 时序 |
| 流路径被拒绝（无可行 n / 证书失效） | 不注入流动作，直接 v10 块 | 精确 v10 |
| deadline_guard 触发 | 执行最后已认证前缀并安全停驻 | v9 K=1 fallback |

# IP-361 FlowChunkPolicy：流匹配动作块策略
class FlowChunkPolicy:
    def __init__(self, velocity, C_v, kappa_F, n_levels=(1, 2, 4, 8, 16, 32)):
        self.v = velocity            # v_theta(x, tau, state, cond)
        self.C_v, self.kappa_F = C_v, kappa_F
        self.n_levels = n_levels

    def field(self, x, tau, state, cond):
        return self.v(x, tau, state, cond)

    def sample(self, state, cond, n, rng):
        x = rng.standard_normal(state.chunk_shape)
        h = 1.0 / n
        for i in range(n):
            x = x + h * self.field(x, i * h, state, cond)
        return x, self.C_v / n                 # (a^(n), ε_n)

    def context(self, state, cert, delta_dom, risk_slam, intent_emb):
        return dict(m=cert.normalized_margins, K_eff=state.K_eff,
                    ddom=delta_dom, rslam=risk_slam, intent=intent_emb)


# IP-362 AnytimeFlowIntegrator：任意时刻积分与截断证书
class AnytimeFlowIntegrator:
    def __init__(self, policy, forward_model, beta_model, kappa_F,
                 d_safe=0.15, m_commit=3):
        self.p, self.F = policy, forward_model
        self.beta_model, self.kappa_F = beta_model, kappa_F
        self.d_safe, self.m_commit = d_safe, m_commit

    def integrate(self, state, cond, n, rng):
        return self.p.sample(state, cond, n, rng)    # 委托，返回 (a, ε_n)

    def certificate(self, state, a, n, mode="emit",
                    a_ref=None, n_ref=None):
        pred = self.F.rollout(state, a)              # 指标轨迹
        if mode == "reuse":
            assert n_ref is not None and n_ref > n
            eps = self.p.C_v * (1.0 / n - 1.0 / n_ref)
            beta_total = self.beta_model + self.kappa_F * eps
        else:                                        # emit：在 a 本身上算
            beta_total = self.beta_model
        g_min = pred.min_clearance - beta_total
        e_max = pred.max_effort + beta_total
        valid = (g_min >= self.d_safe
                 and e_max <= state.tau_eff
                 and pred.grasp_valid
                 and len(pred.abort_points) > 0
                 and state.m0_pass)
        return Cert(g_min, e_max, beta_total, valid, pred.abort_points)

    def commit_prefix(self, state, a, n):
        m = min(self.m_commit, len(a), state.K_eff)
        a_pre = a[:m]
        cert = self.certificate(state, a_pre, n, mode="emit")   # M0 必 emit
        if not cert.valid:
            return None                              # 中立元：退回 v10
        return FrozenPrefix(a_pre, cert, cert.abort_points)


# IP-363 LatencyConformalScheduler：保形延迟预算与弹性 NFE 分配
class LatencyConformalScheduler:
    def __init__(self, n_levels, alpha=0.01, B_flow=12.0, reserve=1.0,
                 gamma_aci=0.01, min_calib=30):
        self.n_levels = n_levels
        self.alpha, self.B_flow, self.rsv = alpha, B_flow, reserve
        self.gamma, self.min_calib = gamma_aci, min_calib
        self.calib = {n: [] for n in n_levels}
        self.q = {n: float("inf") for n in n_levels}     # 未标定前不可行

    def update(self, n, latency):
        self.calib[n].append(latency)
        if len(self.calib[n]) >= self.min_calib:
            self.q[n] = conformal_quantile(self.calib[n], self.alpha)
        if self.q[n] < float("inf"):                     # ACI 防漂移
            self.q[n] += self.gamma * (self.alpha
                                       - float(latency > self.q[n]))

    def feasible(self, n):
        return self.q[n] + self.rsv <= self.B_flow

    def allocate(self, gain_fn, state, cond):
        best = None
        for n in self.n_levels:
            if not self.feasible(n):
                continue
            g = gain_fn(n, state, cond)                  # 单调非减/凹
            if best is None or g > best[1]:
                best = (n, g)
        return None if best is None else best[0]         # None ⇒ 中立元

## 4. 推导

**引理 92（anytime 截断包络与复用证书的可靠性）**
设 v_θ 满足定义 549 的光滑性假设，Euler 全局误差 ‖a^(n)−a^∞‖∞ ≤ C_v/n，证书功能对动作的 Lipschitz 常数为 κ_F。则：
(i) ε_n=C_v/n 关于 n 单调不增；
(ii) 对 n_ref>m，‖a^(m)−a^(n_ref)‖∞ ≤ ε_{m|n_ref}；
(iii) 在 reuse 模式下取 β_total=β_model+κ_F·ε_{m|n_ref} 时，若 ĝ_min−β_total ≥ d_safe，则真实间隙 g(a^(m)) ≥ d_safe（能耗侧同理）。
证明：(i)(ii) 由 Euler 误差界与三角不等式直接得到；(iii) 设证书在 a^(n_ref) 上给出 ĝ−β_model，执行 a^(m)，则真实 g(a^(m)) ≥ ĝ(a^(n_ref))−β_model−κ_F‖a^(m)−a^(n_ref)‖ ≥ ĝ_min−β_model−κ_F ε_{m|n_ref} = ĝ_min−β_total ≥ d_safe。∎
**推论 92.1**：emit 模式等价于 ε=0，故 M₀ 在发出的动作上重算时无需任何截断膨胀；截断膨胀只是"复用旧证书"的代价，不是流本身的固有缺陷。

**引理 93（先证后执行的原子性）**
在定义 551 下，已提交前缀在执行期间不可变，任何后缀细化都不改变前缀动作、前缀证书与基于前缀的中止点。若积分在预算内未完成，执行最后已认证前缀并在其最后一个中止点安全停驻。故"I-E（被执行=被认证）"成立，"先证后改"窗口不存在。
证明：前缀以 `FrozenPrefix` 结构只读冻结；证书字段只引用冻结动作；中止点在冻结前缀上按定义 534 重算；超时路径与 v9 K=1 fallback 同构。后缀细化若改变中止点，只影响未提交部分，且在解冻前重新认证。∎

**引理 94（保形延迟覆盖与 50Hz 概率保持）**
在上下文分箱内可交换（或 ACI 的长期意义下），q_{1−α}(n) 满足 P(L_n ≤ q_{1−α}(n)) ≥ 1−α。若 LCS 只选择 q_{1−α}(n)+rsv ≤ B_flow 的 n，则每块生成在预算内完成的概率 ≥1−α；否则返回 ⊥，执行 v10 路径且不延长周期。故 50Hz 以概率 ≥1−α 保持，残余 1−α 由 deadline_guard + 中立元吸收，而非以超时换周期。非平稳下 ACI 使长期超限率 ≤α+o(1)。
证明：保形分位数的边际覆盖定理给出单级覆盖；按 Δ_dom/负载分箱后逐箱成立。选择偏差由"先分箱、后校准、再选择"的顺序与 ACI 反馈控制消除；E594 对覆盖率做独立审计。周期不延长由 deadline_guard 的硬语义保证。∎

**引理 95（弹性分配的单调性与近最优）**
若 G(n) 非减凹、t(n)=q_{1−α}(n) 非减，则：
(i) 更少 NFE 不会带来更大的认证集：n↓ ⇒ ε_n↑ ⇒ β_total↑ ⇒ K_eff 与可认证候选单调不增（I-H）；
(ii) 分数背包的边际增益/毫秒贪心最优，整数枚举（|N|=6）精确；
(iii) 当某级 n 的边际安全增益低于阈值时，把预算让给其他模块（或直接 v10 fallback）不劣于强行多用 NFE。
证明：(i) 由引理 92 的单调性与定义 550 的证书判据；(ii) 标准凹背包结论；(iii) 边际分析。∎

**引理 96（流模块失效的 v10 逐位等价）**
对 FCP/AFI/LCS 的任一失效组合，按定义 555 注入中立元后：提案集合、证书判据、盾 S_C、MIA 仲裁与 M₀ 输入均与 v10 相同；流模块只位于候选生成侧，不改变 v10 任何过滤器的取值集合。故在同随机种子下可观测决策流与 v10 逐位等价；I-A/I-B/I-C/I-D 由 v10 引理 87–91 传递成立。
证明：逐一核对中立元表；FCP 失效时调用 v10 chunker 与 SRPI 原路径；AFI/LCS 失效时只改变 n 与证书模式，emit 模式下证书字段与 v10 同构；n=1 且无流时执行 v9 单步 fallback，即 v10 已定义的退化级。∎

**引理 97（偏移—截断耦合的保守性条件）**
设域偏移使速度场误差与证书灵敏度同时放大：‖v_θ−v*‖ ≤ δ_v(Δ_dom)，κ_F ≤ κ̄_F(Δ_dom)。若部署期用 κ̄_F 与 δ_v 的**上界**计算 β_total，并在 Δ_dom ≥ τ_dom 时强制 n=1/emit，则引理 92 的可靠性在陌生域仍成立；否则若用源域 κ_F 而实际 κ_F 更大，复用证书可能低估膨胀。故 κ_F 必须按域分档标定，且 Δ_dom 越阈时禁止 reuse。
证明：由 Lipschitz 复合与误差上界的单调性；Δ_dom 越阈强制 emit + n=1 时 ε=0，截断项消失，可靠性退化为 v9 的 β_model 条件。∎

## 8. 本轮最大风险

**一句话**：流匹配的 anytime 截断把"延迟"变成可分配资源，但截断误差与域偏移/模型误差在证书里相加——若 κ_F 在陌生域被低估，系统会在"按时"执行一个证书已失效的动作，即**最危险的失败不是超时，而是准时地不安全**。
