# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「同步定位与建图」×「技术融合」）

> R69 问出了「我该向谁求证、还能问什么」，把不确定性拆成 aleatoric / epistemic，并让系统主动看、问、触。但 R69 有一个从未被质疑的隐含前提：**世界地图是给定的、静止的、可信的**。它的模态、似然、安全包络全部条件在一个「坐标系 + 地图」上。现实中这个前提最先崩：位姿漂移、地图过期、动态障碍、语义地标改名。地图一旦错了，R69 再会提问，也只是「在一个错的世界里礼貌地提问」。
>
> 本轮两个灵感正好补上这块地基：
> - **SLAM** 给出「状态与地图联合估计」的范式——不确定性不止在动作模态，还在**参考系本身**；回环（loop closure）是一次「发现矛盾并追溯改写过去」的机会；
> - **技术融合** 给出「异质因子紧耦合」的范式——视觉/惯性/触觉/语言/他机不是松散投票，而是同一个因子图里带鲁棒核与可开关变量的因子。
>
> 核心命题：**把 R69 的「交互消歧」下沉到「地图-位姿联合估计」上；信息动作扩展为「查询动作 + 建图动作」；把回环闭合当作一次必须独立验证的「矛盾发现」，用技术融合的鲁棒因子图做证据仲裁；当回环不可信或全局不一致时，冻结地图写、回滚到最后一致快照，并退化为 R69 的保守交互。** 命名 **WEAVE-RAS**（World-Estimation with Active Verification and Evidence-fused SLAM；weave 兼指「把异质因子编织成图」与「在地图上走出路径」）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量准吗」，R69 问「我该向谁求证」，R70 问「**我在哪、这张地图还算数吗**」——所有求证都发生在某个坐标系里，而坐标系本身也会撒谎。

## 0. 直觉与动机

**灵感 1（SLAM → 不确定性的第三个来源是地图本身）**
直觉：R69 的 U_ale / U_epi 都在「给定地图 m」的条件下计算。但 m 是估计出来的，它自带漂移、过期与数据关联错误。把 U 再拆一层：U = f(U_ale, U_epi, U_map)。U_map 又分两半：U_map_ale（传感器噪声导致的地标位置抖动，不可约，收紧）与 U_map_epi（数据关联歧义、未探索区域、语义标签不确定，可约，靠**建图动作**消解）。后者是 R69 VoI 框架的天然推广——只是「问一句」换成了「走过去再看一眼、回访一次闭合」。地图不是背景，是一个需要被主动改善的状态。

**灵感 2（回环 → 一次可追溯的矛盾发现）**
直觉：回环闭合最迷人的不是「认出旧地方」，而是它**追溯地改写过去**：一旦确认「此刻位姿 = 300 步前位姿」，中间整段轨迹与地图都要全局重优化。这等价于 R69 收到一个超高信息量回答，但更危险——R69 答错只是选错一个模态，回环错则是**整张地图与整段历史一起错**。所以回环必须继承并强化 R69 的证据纪律：单源、单次回环不得定案。

**灵感 3（技术融合 → 把抽象证据纪律变成可计算的几何）**
直觉：R69 的「k 个正交证据源一致」是抽象纪律；技术融合把它变成可计算、可微、可审计的东西：把视觉、惯性、触觉、语言地标、他机观测写进同一因子图，每个因子带鲁棒核（Cauchy / Geman-McClure）与可开关变量 sᵢ；不一致的因子被 sᵢ→0 连续降权，而不是硬投票。融合的目标不是「堆更多传感器」，而是**改善因子图条件数、补可观测性退化方向**——这才是「技术融合」的严谨含义。

**灵感 4（严格包含 R69 = 静态完美地图边界）**
直觉：当地图静止、完美、无漂移（U_map=0）、禁用建图动作、回环候选为空时，WEAVE 的因子图退化为 R69 的单帧条件，闭环检测无事可做，整体逐指令等于 FLUID-RAS。于是 R69 = WEAVE 在「地图可信且不许探索」边界上的退化。这是本系列一以贯之的理论姿态：新层必须严格包含旧层，安全侧不让步。

**灵感 5（回环是双刃剑 → 感知别名攻击）**
直觉：回环的天敌是**感知别名**（perceptual aliasing）——两条一模一样的走廊、两个相同货架。恶意者还能故意布置假地标，诱导一次错误回环，一次就足以把地图拽偏几个房间。因此本轮必须同时交付：回环独立验证（PCM / RANSAC + 多模态一致）、全局一致性监控（χ² / NEES）、地图版本化与回滚、「单次回环不得单独定案」。回环把「诚实的不知道」升级为「追溯性的自信错误」——**闭合错，比不闭合更危险**。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（WEAVE-RAS 总览）** WEAVE-RAS = (ACG, RFG, ASLAM, LCV, TOF, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i，只更新图状态，不更新网络权重）；
(ii) **因子来源可追溯**：每个因子携带来源模态、时间戳、协方差与版本；地图是可审计、可版本化的产物；
(iii) **回环证据纪律**：单源/单次回环不得定案，需几何一致性（PCM）+ ≥2 个正交模态一致；
(iv) **一致性优先**：全局一致性检验失败即冻结地图写、回滚到最后一致快照，退回 R68/R69 保守处置。

**定义 311（状态-地图联合后验）** p(x_{0:t}, m | z_{0:t}, u_{0:t}, ℓ) ∝ Π_i φ_i。x 为位姿/速度，m = (地标集合 L, 拓扑 T)，z 观测，u 控制，ℓ 语言/语义锚点。这是 SLAM 的联合后验；R69 的 p(ξ|o) 是它在「m 已知」时的条件切片。

**定义 312（动作条件因子图 ACG）** 节点 = 位姿节点 x_i、地标节点 l_j、模式/语义节点；因子 = 本体里程计因子、外感受观测因子、R69 交互因子（注视/探针/问句）、任务因子、语言锚点因子、他机相对观测因子。动作 u 决定哪些因子被「看见」（可见性/可观测性门控），故**图结构本身是动作条件的**——这是与普通 SLAM 的关键区别：图不只随观测长，还随动作变形。

**定义 313（鲁棒后端 RFG）** MAP：min_{x,m} Σ_i ρ_i(‖r_i(x,m)‖²_{Σ_i})，ρ_i 为鲁棒核，配可开关变量 s_i∈[0,1]、先验 Beta(a,b)。用增量平滑（iSAM2 / Bayes tree）维护，边缘协方差由 Schur 补给出。R69 的被动环一致性 = s_i≡1、ρ 为二次的特例。

**定义 314（地图不确定性三分）** U_map ≈ H(m | z_{0:t})。拆为 U_map_ale（地标位置协方差迹，噪声、不可约）与 U_map_epi（数据关联后验熵 / 未探索体积 / 语义标签熵，可约）。进入通道：U_ale^tot = U_ale + U_map_ale；U_epi^tot = U_epi + U_map_epi。

**定义 315（建图动作与统一 VoI：ASLAM）** 建图动作 g_map（移动以观测、回访指定区域以闭合、主动重定位）与 R69 的查询动作 g_query 合并为统一信息动作 g = (g_query, g_map)。统一信息增益 VoI(g) = IG(M_task, m ; y | g, o)；选 g* = argmax_g [VoI(g) − c(g)]，s.t. 安全认证与统一信息预算。R69 定义 298 是 g_map=∅ 的特例。

**定义 316（回环闭合与验证 LCV）** 候选回环 c = (i,j)。验证三条：(a) **几何一致性**：PCM / 成对一致测量集，内点率 ≥ τ_pcm；(b) **多模态独立一致**：外观、结构、惯性/里程计漂移方向至少两源一致；(c) **可观测性**：闭合方向不落在退化子空间（长走廊轴向）。任一不过则拒绝，U_map_epi 保持未消解。

**定义 317（技术融合因子分类 TOF）** 紧耦合：视觉-惯性预积分因子、触觉接触因子、语义地标因子（语言锚点 l^ℓ，带语义标签熵）、他机因子。每类配鲁棒核与时间同步容差；松耦合仅作回退。融合目标 = 降低总 Fisher 信息的条件数、补退化方向（见引理 22）。

**定义 318（一致性监控与地图投毒检测）** 全局检验：残差卡方 χ²、NEES、因子开关率 s̄。统计量越界 ⇒ 判「图不一致」，触发定义 310-iv 的冻结-回滚；并把 (r_res, Δa, χ², s̄) 联合分布用于区分「真回环」与「投毒回环」（延续 R69 引理 17 的对偶判据）。

**定义 319（地图版本化与回滚）** 地图 = 版本链 {v_k}，每次接受的回环生成新版本并记录证据哈希（loop_evidence_hash）。回滚到最后一致版本是一等操作。满足实时零学习写：只改图状态，不动网络权重。

**定义 320（回溯修正的安全包络）** 全局优化会突变地图/位姿。约束：单周期位姿修正 ≤ δ_pose；修正与安全包络检查串行；重规划前用认证前缀（R68 定理 15 换装不变式）；修正导致控制不连续时按 R68 限幅。

**定义 321（两级→三级保守退避）** λ = λ_floor(U_ale + U_map_ale + [未消解](U_epi + U_map_epi))。交互/建图在预算内消解则只用 aleatoric 项（resolution + exploration bonus）；地图不一致或回环被拒时，未消解项全部视同 aleatoric。R69 为 U_map≡0 的退化。

**定义 322（建图预算）** 单位时间位移 ≤ ε_map；探索信息增益/能耗比达标；回环尝试频率 ≤ 1/τ_loop；社交/任务打扰成本 ≤ c_max。与 R69 交互预算合并为统一信息预算。

**定义 323（证书 J_WEAVE）** J_WEAVE = (J_FLUID, map_version_hash, loop_evidence_hash, χ²_p95, U_map_before/after, drift_bound, consistency_ok, weave_ver)。Valid ⇔ Valid(J_FLUID) ∧ consistency_ok ∧ 回环证据纪律满足 ∧ 修正限幅未越界。

**定义 324（威胁模型 ℰ_WEAVE）** ℰ_WEAVE = ℰ_FLUID × ℰ_map：假地标/别名攻击、回环注入、动态物体伪装静止地标、语义标签投毒、他机恶意协同定位。并入 AIC 对抗训练。

**定义 325（审计 VQAuditor-M 与模式-地图耦合）** 审计地图编辑与回环决策：回环是否单源、开关变量是否被滥用、修正是否越限。模式-地图耦合：U_map 高时，R69 的模态权重也应条件在地图后验上，二者联合消歧而非串行。

## 2. 关键算法骨架

```python
# IP-264 ACG：动作条件因子图前端（图随动作变形，不只随观测增长）
def build_factors(graph, x_prev, u, z, lang, interaction_factors):
    fs = [odom_factor(x_prev, u)]
    fs += [obs_factor(x_prev, lm, z[m]) for m in visible(z, u)]
    fs += [lang_factor(lm, l) for l in lang.new]          # 语义地标因子
    fs += interaction_factors                             # R69 的看/问/触也入图
    return graph.add(fs)

# IP-265 RFG：鲁棒增量后端（鲁棒核 + 可开关变量）
def solve_rfg(graph):
    for _ in range(N_iter):
        r, J = linearize(graph)
        s     = switch_prior(graph)                        # s_i ~ Beta(a,b)
        W     = robust_weight(r, s)                        # Cauchy / GMM
        dx    = solve(J.T @ W @ J, -J.T @ W @ r)
        graph = retract(graph, dx)
    return graph, schur_marginals(graph)                   # 边缘协方差

# IP-266 ASLAM：统一 VoI（查询动作 + 建图动作）
def unified_voi(modes, map_belief, o, budget):
    best = None
    for g in candidates(modes, map_belief):                # 看/问/触/走/回访
        if not budget.allow(g) or not c_ras_wm.certify(g, o): continue
        score = (ig_task(modes, g) + ig_map(map_belief, g)) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None       # 无利可图 → 不动作

# IP-267 LCV：回环独立验证（几何 + 多模态 + 可观测性）
def verify_loop(cand, graph, modalities):
    if pcm_inlier_ratio(cand, graph) < TAU_PCM: return False
    if degenerate(cand, graph):                 return False   # 走廊轴向
    agree = sum(m.consistent(cand) for m in modalities)
    return agree >= 2                                          # 单源不定案

# IP-268 一致性监控与回滚
def consistency_gate(graph, stats, versions):
    if stats.chi2 > TAU_CHI2 or stats.nees > TAU_NEES:
        return versions.rollback()                             # 定义 310-iv
    return graph

# IP-275 主闭环（继承 R69，在「世界模型」处插入 WEAVE 层）
def WEAVE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    graph = M.acg.build(M.graph, M.x_prev, M.u, z, M.lang, M.r69_factors)
    graph, cov = M.rfg.solve(graph)                            # 增量平滑
    U_map_ale, U_map_epi = M.map.uncertainty(graph, cov)
    cons = M.monitor.check(graph)
    if not cons.ok:                                            # 图不一致 → 冻结回滚
        graph = M.map.rollback()
        return M.r68_round(o, lam_floor(U_ale + U_epi + U_map_ale + U_map_epi))
    K     = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes, U_ale, U_epi = M.aud.decompose(M.fmp.sample(o, K), z)
    g = M.aslam.unified_voi(modes, graph, o, M.budget)         # 查询 + 建图
    if g is not None:
        y = M.cia.execute(g)                                   # 看/问/触/走过去
        if g.is_map:
            cand = M.lcv.detect(graph, y)
            if M.lcv.verify(cand, graph, y.modalities):        # 回环证据纪律
                M.map.commit(cand)                             # 版本化 +1
                graph = M.rfg.solve(graph)                     # 追溯修正
                graph = M.safety.clamp_correction(graph, DELTA)  # 限幅
        else:
            U_epi = M.cia.update_belief(modes, y)
    U_floor = U_ale + U_map_ale + ((U_epi + U_map_epi) if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_m.submit_async(g, M.map.diff(), cons, U_map_epi)
    return k, lam, mode, (U_ale + U_map_ale, U_epi + U_map_epi)
```

## 3. 推导

**引理 19（回环的信息增益与漂移衰减）** 长度 L 的轨迹上，一次通过验证的回环使末端位置协方差沿闭合方向由 O(L·σ_odom²) 降至 O(σ_loop²)，期望位置误差下降 ≥ c·√L·σ_odom − σ_loop。系：回环收益随漂移累积（√L）增长，故**长轨迹上回环更值钱**；而误回环注入的误差与 L 无关（见引理 20），故验证阈值必须随 L 收紧。

**引理 20（误回环的误差注入下界与验证阈值）** 若把位姿 i 与 j 错误关联，相对位移误差 e_ij 被注入图并经全局优化传播，至少使闭合方向产生 ‖e_ij‖/2 的偏差（两半分担）。故误回环损失 ≥ κ‖e_ij‖；为使期望损失不高于「不闭合」，需后验误回环率 p_fp ≤ p* = σ_loop / (κ‖e_ij‖ + σ_loop)。系：验证强度（模态数 k）应使 p_fp ≤ p*，与引理 21 联立给出所需 k*。

**引理 21（多模态验证下的误回环上界）** k 个验证模态、各误接受率 α、相关性 ρ<1，要求 ≥2 源一致时，误回环率 ≤ k²α²/(1−ρ) + ε_σ（相对单源的 α 是二次压低）。系：允许以「多验证一次」的固定成本换取回环错误的平方级抑制——正是 R69 引理 18 在几何侧的镜像。

**定理 18（WEAVE 严格包含 R69）** 当 U_map=0、禁用 g_map、回环候选为空时，ACG 退化为 R69 单帧条件，RFG 的 s≡1、ρ 为二次，ASLAM 退化为 MINT，故 WEAVE 与 FLUID-RAS **逐指令相同**；一般情形下，纳入正确的地图因子只会减少 U_epi^tot，建图动作只降低 U_map_epi，故事故风险不高于 R69。安全侧不让步，效率侧获 resolution + exploration bonus。

**定理 19（回溯修正的无突变性）** 在单周期修正限幅 δ_pose 与认证前缀重规划下，全局优化引起的位姿/地图跳变被限幅并被安全包络串行检查，控制输出满足 Lipschitz 连续性；回滚是一等操作且总可用。故回溯修正不引入高于 R68/R69 的事故风险，换装不变式（R68 定理 15）保持。

**引理 22（技术融合的可观测性增益）** 在退化方向 d（如长走廊轴向），单模态 Fisher 信息 I_d^(m) 近奇异；加入惯性/触觉/他机因子后 I_d^tot = Σ_m I_d^(m)，条件数下降，故定位可观测性提升：cond(I^tot) ≤ min_m cond(I^(m)) 的调和平均上界。系：技术融合的价值可被量化为「退化方向 Fisher 信息的补全」，而非传感器数量。

        W = robust_weight(r, s)

## 4. 推导

**引理 19（回环增益与漂移衰减）** 长 L 轨迹上，一次通过验证的回环把末端协方差沿闭合方向由 `O(Lσ²_odom)` 降至 `O(σ²_loop)`，期望误差降 ≥ `c√L·σ_odom − σ_loop`。系：长轨迹上回环更值钱；验证阈值需随 L 收紧。

**引理 20（误回环误差注入与阈值）** 错误关联把 `e_ij` 注入图，经全局传播使闭合方向偏差 ≥ `‖e_ij‖/2`；为使期望损失不高于不闭合，需 `p_fp ≤ σ_loop/(κ‖e_ij‖+σ_loop)`。系：验证强度 k 应满足此阈值。

**引理 21（多模态验证误回环上界）** k 模态、误接受率 α、相关 ρ<1、要求 ≥2 源一致时，误回环率 ≤ `k²α²/(1−ρ)+ε_σ`（相对单源二次压低）。系：R69 引理 18 的几何镜像。

**引理 22（技术融合可观测性增益）** 退化方向 d 上 `I_d^tot = Σ_m I_d^(m)`，故 `cond(I^tot)` 下降；融合价值 = 退化方向 Fisher 信息补全，而非传感器数量。

**定理 18（WEAVE 严格包含 R69）** 当 `U_map=0`、禁 `g_map`、无回环候选时，ACG→R69 单帧、RFG→`s≡1,ρ 二次`、ASLAM→MINT，二者逐指令相同；一般情形纳入正确地图因子只减 `U_epi^tot`，事故风险不高于 R69。

**定理 19（回溯修正无突变）** `δ_pose` 限幅 + 认证前缀重规划 ⇒ 位姿/地图跳变被限幅且受安全包络串行检查，控制输出 Lipschitz 连续；回滚为一等操作；换装不变式（R68 定理 15）保持。
