# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「云边协同」×「模仿学习」）

> 前 54 轮解决了"能力如何刻画、如何组合、如何跨云边对齐"，本轮追问更上游的问题：**技能与策略本身从何而来**。核心矛盾：H22：模仿学习的目标不是"拟合示范动作"，而是"匹配示范的占据测度"；第 54 轮的动作剖面 `α_S` 只是占据测度在动作轴上的边缘投影，示范覆盖不足处的 BC 会外推出自信但错误的技能。H23：云端有大规模示范与全局仿真，边端有真实动力学与实时安全约束，云边动作粒度与动力学不一致，直接部署云端策略会把"云端示范偏差"放大为边端复合误差。

## 0. 直觉与动机

**灵感 1（示范 = 动作空间上的占据测度，而非样本集）**
直觉：第 54 轮把技能刻画为动作剖面 `α_S(a)`，但 `α_S` 只是策略占据测度 `μ_π(s,a)` 在动作轴上的边缘：`α(a)=∫_S μ(s,a)ds/Z`。示范集同样诱导示范剖面 `α_D`。模仿的本质不是"在示范状态上拟合动作"，而是让 `π` 的占据测度 `μ_π` 逼近示范 `μ_D`。于是 **示范覆盖 `cov_D(A_T)=inf_{a∈A_T} α_D(a)`** 成为模仿能否外推的第一性判据：`α_D` 在任务动作上稀疏处，BC 不是在模仿，而是在做未经验证的插值。一个直接推论是 **支撑集不可能性**：对 `A_T \ support(D)` 中的动作，任何仅依赖 `D` 的学习器都无法给出有界误差保证，除非引入动力学先验或主动探索。

**灵感 2（云边协同 = 粗到细的分层模仿 + 边端触发查询）**
直觉：云端拥有大规模、跨场景示范 `D_c`，学到粗动作策略 `π_c`；边端拥有真实动力学与少量本地示范 `D_e`，需要把 `π_c` 经 `γ_ce` 细化并本地校正。关键不是"云端训练、边端部署"的开环蒸馏，而是 **边端触发的双向模仿回路**：只有当边端检测到占据差距、覆盖不足或高不确定性时，才向云端发出解释式查询，云端用全局仿真返回修正粗动作与近邻示范片段。这把 DAgger 的在线专家查询搬到云边，用通信预算换复合误差下降：BC 最坏 `O(εT²)`，无遗憾 DAgger 可降到 `O(εT)`，云边回路的目标是在 `q_budget ≪ T` 下逼近后者。

**灵感 3（反向解释 = 查询压缩器）**
直觉：第 54 轮的 `Explain` 通道只回传失败动作 `a_e`。对模仿学习，应回传 **反事实三元组** `(s, a_c, Δeffect)`：云端看到的是"若执行 `a_c` 会产生什么与边端不同的效果"，而不是原始高维状态轨迹。解释成了查询的压缩编码，既降低带宽，也把"标签"升级为"因果纠正"，使云端能生成 **反事实示范片段** 而非单步标签。这里有一个重要区别：标签给出"专家会做什么"，反事实解释给出"为什么云端示范在边端失效"，后者才是跨域校正所需的监督信号。

**灵感 4（护盾 = 模仿的运行时证书）**
直觉：模仿学习在示范分布外没有保证。与其追求一个全局 RL 式最优性证明，不如承认分布外风险并加 **安全护盾**：当预测动作落在 `α_D` 低覆盖区或 `ρ_e` 低于阈值时，护盾介入到安全兜底动作，并记录干预率 `ν_shield`。部署证书从"模仿误差小"变成"模仿误差 + 干预率 + 恢复率"三元的可运行时验证量。这实际上把第 54 轮的鲁棒性谱 `ρ` 与动作剖面 `α` 复用为护盾的触发条件，避免另建一套安全评估。

**灵感 5（从示范到技能再到组合）**
直觉：把长程示范按起止谓词切分为技能片段，学习技能级动作块（action chunk），再接入第 54 轮的技能组合图 `G_S`。这样"模仿 → 技能 → 组合 → 云边部署"形成完整链路：示范占据测度决定技能剖面，技能组合图决定任务可达性，云边契约决定部署可行性。第 54 轮的 `J=(ρ,A_cert,γ_ce,δ_a)` 因此获得来源层的补充：`A_cert` 不再是被给定技能的经验统计，而是由示范覆盖与护盾干预共同支撑的可追溯量。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（示范占据测度与示范动作覆盖）**
示范集 `D={(s_t,a_t)}_{t=1..N}` 诱导占据测度 `μ_D(s,a)`。动作边缘剖面 `α_D(a)=∫_S μ_D(s,a)ds/Z`。任务动作集 `A_T` 上的覆盖 `cov_D(A_T)=inf_{a∈A_T} α_D(a)`。示范覆盖证书 `C_D=(α_D, cov_D, support, n_D)`，其中 `support={a: α_D(a)≥θ_sup}`。若 `cov_D(A_T) ≥ 1-δ_cov`，称 `D` 对 `A_T` 是 `δ_cov`-覆盖的。

**定义 122（模仿占据差距 OMD）**
对策略 `π` 与示范 `μ_D`，占据匹配差距 `D_occ(π,D)=sup_{f∈F}|E_{μ_π}[f]-E_{μ_D}[f]|`，`F` 为有界评论家函数类（TV、MMD 均为特例）。经验估计 `ε̂_occ` 附 bootstrap 置信上界 `ε_occ^+`。动作条件差距 `D_A(π,D)=sup_{a∈A_T}|π(a|s)-π_D(a|s)|·α_D(a)`。后者用于定位"差距集中在哪些动作上"，是解释式查询的触发依据。

**定义 123（云边模仿契约）**
`C_IL=(D_c, π_c, D_e, γ_ce, q_budget, τ_q)`：
- `D_c` 云端大规模示范（粗动作 `A_c`）；
- `π_c` 云端粗策略先验；
- `D_e` 边端本地示范（细动作 `A_e`）；
- `γ_ce:A_c→A_e` 动作映射（承接第 54 轮）；
- `q_budget` 每回合云端查询预算；
- `τ_q` 标签最大允许时延。

契约的 soundness 要求：`D_c` 在 `γ_ce^{-1}(support(D_e))` 上有支撑，且任何查询返回满足 `t_now-t_label ≤ τ_q`。

**定义 124（解释式边端触发查询 EDAX）**
触发函数
```
trigger(s)=1[ H(π_e(·|s))>θ_u ∨ α_D(π_e(s))<θ_cov ∨ D_occ^loc(s)>θ_occ ]
```
查询包含反事实解释 `q=(s, a_c=γ_ce^{-1}(a_e), Δeffect, evidence)`，云端返回 `(a_c^*, {demo snippets}, t_label)`。标签新鲜度 `fresh=1-((t_now-t_label)/τ_q)_+`，有效标签误差 `ε_q(τ)≤ε_q0+L_q·τ_q`。查询的目的不是最大化标签量，而是最小化"单位通信成本下的占据差距下降"。

**定义 125（安全护盾与干预证书）**
安全动作集 `A_safe(s)={a: α_D(a)≥θ_cov ∧ ρ_e(a)≥ρ_min}`。护盾
```
σ(a,s)= a        if a∈A_safe(s)
         fallback(s)  otherwise
```
干预率 `ν_shield=E[1(a∉A_safe)]`。干预证书 `S_cert=(A_safe, ν_shield, recovery, evidence)`；若 `ν_shield≤ν_max` 且 `recovery≥γ_min`，称策略是运行时安全的。注意 `A_safe` 同时依赖示范覆盖与鲁棒性谱，任一项缺失都会使护盾退化为纯几何约束。

**定义 126（跨域模仿迁移证书）**
源域 `D_s`、目标域 `D_t`，动作对齐漂移 `δ_a=sup_{a∈support(π_s)} ||γ_ce(a)-a||`，动力学差距 `ε_dyn=sup_{s,a} W_1(P_s(·|s,a), P_t(·|s,γ_ce(a)))`。迁移证书 `I_cert=(D_occ^s, ε_dyn, δ_a, ρ, S_cert)`。若 `D_occ^s + L·ε_dyn + δ_a ≤ Θ_IL` 且 `S_cert` 通过，则允许跨域部署；否则只能作为云端先验，禁止直接边端执行。

## 2. 关键算法 伪代码

### IP-121 DAC（Demonstration Action Coverage）

```python
def demo_profile(D, bins):
    alpha_D, n = defaultdict(float), len(D)
    for (s, a) in D:
        alpha_D[discretize(a, bins)] += 1.0 / n
    support = {a for a, v in alpha_D.items() if v >= THETA_SUP}
    return DemoCoverage(alpha_D, support, n)

def coverage_gate(cert, A_T, theta_cov=0.8):
    cov = min(cert.alpha_D.get(a, 0.0) for a in A_T)
    return cov >= theta_cov, cov

def unsupported_actions(cert, A_T):
    # 支撑集不可能性检查：这些动作上禁止给出有界误差承诺
    return [a for a in A_T if a not in cert.support]
```

### IP-122 OMD（Occupancy-Matching Discrepancy）

```python
def occupancy_discrepancy(pi, D, critic_class, n_rollout=64):
    mu_pi = rollout_occupancy(pi, n_rollout)
    mu_D = empirical_occupancy(D)
    eps = max(abs(expect(mu_pi, f) - expect(mu_D, f)) for f in critic_class)
    return eps, bootstrap_upper(eps, n_rollout)

def compounding_bound(eps_bc, T, mode='bc', beta=1.0):
    # BC 最坏 O(T^2 eps)；无遗憾 DAgger O(T eps)
    order = T * T if mode == 'bc' else T
    return beta * order * eps_bc
```

### IP-123 CEIL（Cloud-Edge Imitation Loop）

```python
def cloud_pretrain(D_c):
    pi_c = behavior_clone(D_c)          # 粗动作 A_c
    return pi_c

def edge_finetune(pi_c, D_e, gamma_ce, sim, q_budget):
    pi_e = init_from(gamma_ce, pi_c)    # 用 γ_ce 把粗策略投影到 A_e
    queries = []
    for epoch in range(E):
        states = rollout(pi_e, sim)
        for s in select_by_trigger(states, pi_e, q_budget):
            q = explain_query(s, pi_e, gamma_ce)
            label = cloud_answer(q)     # 可能带时延
            queries.append(label)
        D_aug = D_e + [q for q in queries if q.fresh > 0]
        pi_e = behavior_clone(D_aug, init=pi_e)  # 在合并数据上微调
    return pi_e, queries
```

### IP-124 EDAX（Edge-initiated DAgger with eXplanation）

```python
def trigger(s, pi_e, cov, rho, theta):
    a = pi_e(s)
    return (entropy(pi_e, s) > theta.u
            or cov.alpha_D.get(a, 0.0) < theta.cov
            or local_omd(s, pi_e) > theta.occ)

def explain_query(s, pi_e, gamma_ce):
    a_e = pi_e(s)
    a_c = gamma_ce.inverse(a_e)
    exp = explain(s, a_e)               # 复用第 54 轮 Explain
    return Query(s, a_c, exp.counterfactual_effect, exp.evidence)

def cloud_answer(q, D_c, sim_c, tau_q):
    a_c_star = sim_c.optimal_action(q.s)
    neighbors = nearest_demos(D_c, q.s, k=5)
    # 返回"反事实示范片段"，而非孤立标签
    snippets = [segment(n) for n in neighbors
                if effect_matches(n, q.delta_effect)]
    return Label(q.s, a_c_star, snippets, staleness=now() - q.t)
```

### IP-125 SIC（Shielded Imitation Certificate）

```python
def shielded_act(pi_e, s, alpha_D, rho_e, fallback, theta_cov, rho_min):
    a = pi_e(s)
    safe = alpha_D.get(a, 0.0) >= theta_cov and rho_e.get(a, 0.0) >= rho_min
    return (a, 0) if safe else (fallback(s), 1)

def shield_certificate(episodes, nu_max, gamma_min):
    nu = mean(flag for _, _, flag in episodes)
    rec = mean(recovered for _, recovered, _ in episodes)
    if nu > nu_max or rec < gamma_min:
        return reject('unsafe_imitation', nu, rec)
    return ShieldCert(nu, rec)
```

### IP-126 XIC（Cross-domain Imitation Certificate）

```python
def imitation_transfer_cert(pi_s, D_t, gamma_ce, delta_a_budget, Theta_IL):
    eps_dyn = estimate_dynamics_gap(sim_s, sim_t, gamma_ce)
    delta_a = action_alignment_drift(gamma_ce, support(pi_s))
    occ_s, _ = occupancy_discrepancy(pi_s, D_t, critic_class)
    score = occ_s + L_LIP * eps_dyn + delta_a
    if score > Theta_IL or delta_a > delta_a_budget:
        return reject('il_transfer_gap', score, delta_a)
    return CrossDomainCert(occ_s, eps_dyn, delta_a, score)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DAC | O(\|D\| + \|A\|) | O(\|A\|) | 剖面完备、`θ_sup` 校准 |
| OMD | O(N_rollout·T·\|F\|) | O(\|F\|) | 评论家类足够富、bootstrap 覆盖 |
| CEIL | O(E·(T·\|π\| + q_budget·log\|D_c\|)) | O(\|D_e\|+\|queries\|) | 合并数据无偏、标签新鲜 |
| EDAX | O(q_budget·log\|D_c\|) | O(q_budget) | 触发 sound、反事实对齐 |
| SIC | O(T·(\|A\|+\|𝔇_ρ\|)) | O(\|A\|) | 兜底动作 ρ-安全、干预可观测 |
| XIC | O(N_s·T + \|A\|) | O(\|A\|) | 动力学差距可估、γ_ce Lipschitz |

**条件性命题（Imitation-Robust Cloud-Edge Deployment Soundness）**
假设：
- **(A29)** `cov_D(A_T) ≥ 1-δ_cov`，`support(D_c)` 覆盖 `γ_ce^{-1}(support(D_e))`；
- **(A30)** 在 `support(D_e)` 上 `D_occ(π_e,D) ≤ ε_occ`，BC 单步误差 `≤ ε_bc`；
- **(A31)** 查询采用无遗憾更新，标签误差 `≤ ε_q0+L_q·τ_q`，`q_budget` 支撑触发分布；
- **(A32)** 护盾兜底动作满足 `ρ_e ≥ ρ_min`，`ν_shield≤ν_max`，`recovery≥γ_min`；
- **(A33)** `γ_ce` 在 `support` 上 `L`-Lipschitz，跨域动力学差距 `≤ ε_dyn`。

则（以折扣回报上界 `R_max/(1-γ)` 表示）：
```
J(π*) - J(π_e) ≤ R_max/(1-γ) · [ ε_occ + ν_shield·(ε_q0 + L_q·τ_q) ] + O(δ_cov)
P(violation)   ≤ ν_shield·(1-ρ_min) + (1-ν_shield)·P(shield_fail)
```
并在无遗憾 DAgger 条件下，复合误差从 BC 的 `O(ε_bc·T²)` 降为 `O(ε_bc·T + q_budget·(ε_q0+L_q·τ_q))`。

**诚实边界**：这不是无条件定理，而是"证书模式"的条件性命题。`O(δ_cov)` 项依赖未覆盖动作上的最坏差距，实际上界可能远大于线性项；`ε_occ` 的估计也依赖评论家类。E162–E166 的任务之一就是检验这些假设是否被违例、并校准常数，而不是把公式当作已证结论。

| 风险 | 等级 | 缓解 |

| 云端标签过时/非平稳 | 高 | `τ_q` 硬约束 + 新鲜度加权 + 信任衰减 + 过期回滚 |

| 解释式查询语义不对齐 | 高 | 共享动作本体 + 查询 schema 校验 + 反事实一致性测试 |
| 技能切分错误污染组合图 | 中 | 起止谓词可验证 + 切分证书 + 组合前 overlap 检查 |

## 6. 本轮最大风险

**一句话**：云边模仿体系把"技能从哪来"补成"示范占据测度 → 技能 → 组合 → 护盾部署"的闭环，但其 soundness **自指地依赖示范覆盖的完备性与云端标签的新鲜度**——一旦云端示范本身有偏，覆盖证书会用同一批有偏示范证明自己有覆盖，边端查询又因时延拿到过时纠正，系统会"自信地"把云端动作空间偏差固化为技能，并在支撑外区域以低干预率掩盖系统性错误；故必须以 **覆盖驱动的主动示范采集 + 过期标签硬熔断 + 支撑外动作零信任护盾** 三重护栏，宁可承认"不会"，绝不让示范分布自己给自己发合格证。

# 第 55 轮产物 · 创新点清单 v32：CloudEdge-Imitation++（DAC×OMD×CEIL×EDAX×SIC×XIC）

> 承接第 54 轮产物 v31。上一版解决"技能如何被动作空间剖面化、如何组合、如何云边对齐"，本轮补上更上游的 **策略/技能来源层**，新增六个算子：
> - **DAC（Demonstration Action Coverage）**：示范动作占据剖面与覆盖证书 `C_D`；
> - **OMD（Occupancy-Matching Discrepancy）**：模仿占据差距估计与复合误差界；
> - **CEIL（Cloud-Edge Imitation Loop）**：云端粗策略先验 + 边端细化的分层模仿回路；
> - **EDAX（Edge-initiated DAgger with eXplanation）**：边端触发的解释式反事实查询；
> - **SIC（Shielded Imitation Certificate）**：运行时安全护盾与干预证书；
> - **XIC（Cross-domain Imitation Certificate）**：动作对齐的跨域模仿迁移证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/117/120，把"示范来源"纳入动作剖面、技能组合、云边回路与联合证书。

def demo_profile(D, bins):
    alpha_D, n = defaultdict(float), len(D)
    for (s, a) in D:
        alpha_D[discretize(a, bins)] += 1.0 / n
    support = {a for a, v in alpha_D.items() if v >= THETA_SUP}

def coverage_gate(cert, A_T, theta_cov=0.8):
    cov = min(cert.alpha_D.get(a, 0.0) for a in A_T)
    return cov >= theta_cov, cov

def unsupported_actions(cert, A_T):
    return [a for a in A_T if a not in cert.support]

### IP-122 OMD

```python
def occupancy_discrepancy(pi, D, critic_class, n_rollout=64):
    mu_pi = rollout_occupancy(pi, n_rollout)
    mu_D = empirical_occupancy(D)
    eps = max(abs(expect(mu_pi, f) - expect(mu_D, f)) for f in critic_class)
    return eps, bootstrap_upper(eps, n_rollout)

def compounding_bound(eps_bc, T, mode='bc', beta=1.0):
    order = T * T if mode == 'bc' else T
    return beta * order * eps_bc
```

def trigger(s, pi_e, cov, rho, theta):
    a = pi_e(s)
    return (entropy(pi_e, s) > theta.u
            or cov.alpha_D.get(a, 0.0) < theta.cov

def explain_query(s, pi_e, gamma_ce):
    a_e = pi_e(s)
    a_c = gamma_ce.inverse(a_e)

def cloud_answer(q, D_c, sim_c, tau_q):

### IP-125 SIC

```python
def shielded_act(pi_e, s, alpha_D, rho_e, fallback, theta_cov, rho_min):
    a = pi_e(s)
    safe = alpha_D.get(a, 0.0) >= theta_cov and rho_e.get(a, 0.0) >= rho_min
    return (a, 0) if safe else (fallback(s), 1)

def shield_certificate(episodes, nu_max, gamma_min):
    nu = mean(flag for _, _, flag in episodes)
    rec = mean(recovered for _, recovered, _ in episodes)
    if nu > nu_max or rec < gamma_min:
        return reject('unsafe_imitation', nu, rec)
    return ShieldCert(nu, rec)
```

### IP-126 XIC

```python
def imitation_transfer_cert(pi_s, D_t, gamma_ce, delta_a_budget, Theta_IL):
    eps_dyn = estimate_dynamics_gap(sim_s, sim_t, gamma_ce)
    delta_a = action_alignment_drift(gamma_ce, support(pi_s))
    occ_s, _ = occupancy_discrepancy(pi_s, D_t, critic_class)
    score = occ_s + L_LIP * eps_dyn + delta_a
    if score > Theta_IL or delta_a > delta_a_budget:
        return reject('il_transfer_gap', score, delta_a)
    return CrossDomainCert(occ_s, eps_dyn, delta_a, score)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DAC | O(N + \|A\|) | O(\|A\|) | 剖面完备，`θ_sup` 校准 |
| OMD | O(N_rollout·T·\|F\|) | O(\|F\|) | 评论家类富，bootstrap 覆盖 |
| CEIL | O(E·(T·\|π\| + q_budget·log\|D_c\|)) | O(\|D_e\|+\|queries\|) | 合并数据无偏，标签新鲜 |
| EDAX | O(q_budget·log\|D_c\|) | O(q_budget) | 触发 sound，反事实对齐 |
| SIC | O(T·(\|A\|+\|𝔇_ρ\|)) | O(\|A\|) | 兜底 ρ-安全，干预可观测 |
| XIC | O(N_s·T + \|A\|) | O(\|A\|) | 动力学差距可估，γ_ce Lipschitz |

**条件性命题（Imitation-Robust Cloud-Edge Deployment Soundness）**
假设 (A29)–(A33) 同想法区。则：
```
J(π*) - J(π_e) ≤ R_max/(1-γ)·[ε_occ + ν_shield·(ε_q0+L_q·τ_q)] + O(δ_cov)
P(violation)   ≤ ν_shield·(1-ρ_min) + (1-ν_shield)·P(shield_fail)
```
无遗憾 DAgger 下复合误差由 `O(ε_bc·T²)` 降到 `O(ε_bc·T + q_budget·(ε_q0+L_q·τ_q))`。

**证伪条件（本轮明确列出，防止自证）**：
1. 若 E162 显示 `cov≥0.8` 时支撑外误差未爆炸，则"支撑集不可能性"的强形式被削弱；
2. 若 E164 中 `ε̂_occ` 与真实误差相关性 <0.4，则 OMD 不能作为部署判据；
3. 若 E165 护盾干预率 >15% 且性能仍显著下降，则"护盾保安全不保性能"的折中被证伪；
4. 若 E166 证书通过组与拒绝组成功率无显著差异，则 XIC 的 `Θ_IL` 阈值无判别力。

## 6. 本轮最大风险

**一句话**：云边模仿体系把"技能从哪来"补成"示范占据测度 → 技能 → 组合 → 护盾部署"的闭环，但其 soundness **自指地依赖示范覆盖的完备性与云端标签的新鲜度**——一旦云端示范本身有偏，覆盖证书会用同一批有偏示范证明自己有覆盖，边端查询又因时延拿到过时纠正，系统会"自信地"把云端动作空间偏差固化为技能，并在支撑外区域以低干预率掩盖系统性错误；故必须以 **覆盖驱动的主动示范采集 + 过期标签硬熔断 + 支撑外动作零信任护盾** 三重护栏，宁可承认"不会"，绝不让示范分布自己给自己发合格证。
