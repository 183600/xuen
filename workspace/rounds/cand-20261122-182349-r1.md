# 第 3 轮（新灵感循环第 3 轮；本轮灵感：「末端执行器控制」×「行为树」）

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v20+IP-420–424（PCA/CTS/CFC/HPC/CFCtrl）。
> 本轮纪律：**证书必须从"指令空间"提升到"可达空间"，且必须沿行为树结构可组合**。不推倒 v20：v20 的 DCM/OGCC/CCV/DRS/OGC 与 PCA/CTS/CFC/HPC/CFCtrl 全部保留。本轮只做一件事：**给末端执行器控制的叶子动作颁发"控制权限证书"，再用行为树的契约代数把叶子证书组合成整树证书**。

## 0. 直觉与动机

**灵感 1（末端执行器控制 → 证书的论域错了：证书说的是指令，执行的是可达集）**
直觉：v20 的证书在参数 θ 上断言"该指令位姿零碰撞"。但末端执行器实际到达的是 `x_act = θ + e`，`e` 由控制器刚度/阻尼、力矩饱和、伺服延迟、接触柔顺共同决定。指令安全不等于可达集安全：高刚度控制器在自由空间跟得准，接触瞬间却可能过冲；柔顺控制器过冲小，但接触后位姿被环境反推。核心创新：**末端执行器权限证书 (End-Effector Authority Certificate, EEAC)**。定义控制权限包络 `A_e(θ, mode)`——在给定增益、力矩上限、延迟、环境刚度下实际可达位姿的**保守外近似**——证书提升为 `Cert_ee(θ, mode) = Cert_col(θ) ∧ [A_e(θ, mode) ⊆ FreeSpace]`。关键反直觉点：**"更温柔"的控制不等于更安全**——降低刚度会扩大权限包络（柔顺 = 可达集变大），从而收缩证书；安全性必须按**控制模式**（自由/接触/抓取）分别认证，而不是按单一位置环认证。

**灵感 2（行为树 → 证书是可组合的契约代数，而不是单体大证明）**
直觉：行为树把任务拆成 Sequence / Fallback / Decorator 的组合，天然是"安全证明的组合结构"。v20 的证书是"每节点一个大证明"，任务一变就要重证。核心创新：**行为树证书代数 (Behavior-Tree Certificate Algebra, BTCA)**。每个 BT 节点携带契约 `C = (Pre, Post, Inv, S)`：Pre 是允许进入的状态集，Post 是正常完成后保证的状态集，Inv 是执行期间必须保持的不变式，S 是该子树认证过的参数集。组合律：Sequence 要求 `Post_i ⊆ Pre_{i+1}`；Fallback 要求每个分支在"前一分支失败后"的前置条件成立；Decorator（Retry/Timeout）只允许收缩有效期与预算，不允许扩张 S。关键反直觉点：**BT 组合唯一可靠的证书运算是"保证求交 + 不变式保持"，任何"取平均/取并"的证书合并都会破坏可靠性**——组合只能收缩，这与 v20 的 `Exec ⊆` 纪律同构。

**灵感 3（两者统一 → 叶子由控制权限定，树由契约代数组合）**
直觉：BT 的叶子动作就是末端执行器指令。因此证书天然是两层：**叶子层**用 EEAC 把指令集提升为可达集并认证；**树层**用 BTCA 把叶子证书组合为整树契约。真正危险的不是自由运动，而是 **Fallback/恢复分支**：主分支失败时的恢复动作必须自身被认证，并且必须能把系统恢复到不变式 Inv。核心创新：**反应式末端执行器证书 (Reactive End-Effector Certificate, REEC)**：`REEC(T) = BTCA( { EEAC(leaf) : leaf ∈ T } )`，并要求每次 tick 切换都满足 `Pre(new_leaf) ∧ Inv`。关键反直觉点：**行为树的活性（fallback 一定能救回来）与安全性是同一枚硬币**——一个"总能恢复"的 fallback 如果没有被证书覆盖，反而会把系统从"已认证的安全区"推进"未认证的恢复区"，因此恢复分支必须比主分支更保守。

**三者如何统一**
统一为 **v20 证书体系之上的"执行语义层"**：v20 回答"在参数 θ 下是否零碰撞（感知/几何意义）"，v21 回答"给定末端执行器控制器与行为树，指令 θ 是否能在可达集内被安全执行、并在整树组合下保持不变式"。EEAC 是**叶子语义**（指令→可达集），BTCA 是**组合语义**（子树→整树），REEC 是**反应语义**（tick 切换→证书转移）。共享状态 `ζ_bt = (mode_ee, authority_envelope, bt_contracts, invariant, tick_trace, τ_tick)`。统一接口：**若叶子 EEAC 与整树 BTCA 都通过、且 tick 转移保持 Inv，则该 BT 执行计划进入 `Exec_v21`；否则回退到 v20 的单体证书路径（更保守）**。

## 1. 研究问题（轮次升级版）

- **Q1（控制权限包络的保守性）**：如何在仅有控制器标称模型（阻抗增益、力矩上限、伺服延迟）的情况下，给出 `A_e(θ, mode)` 的**保守外近似**而不是乐观内近似？接触模式下环境刚度未知，包络如何随接触力自适应且保持可靠？过冲瞬态如何用**峰值包络**而非稳态包络描述？

- **Q2（契约代数的可靠性）**：Sequence 的 `Post_i ⊆ Pre_{i+1}` 在连续状态/数值误差下如何可判定？Fallback 的分支前置条件如何定义——"前一分支失败"是一个**状态谓词**还是**轨迹谓词**？Retry/Timeout 等装饰器如何在不扩张 S 的前提下保持 Inv？

- **Q3（反应式 tick 的一致性）**：行为树每个 tick 可能切换活动叶子；如何保证 tick 边界的证书转移是安全的（`Inv ∧ Pre(new_leaf)`）？抢占（preemption）与异步取消如何不破坏 `Post_i ⊆ Pre_{i+1}`？上一个 tick 缓存的证书何时失效？

- **Q4（与 v20 感知/共识层的叠加）**：EEAC 的可达集与 v20 的 `ColDom_fed` 如何求交？CFCtrl 的 `τ_consensus` 与 tick 周期 `τ_tick` 如何共同决定证书新鲜度？当感知共识过期但 BT 仍在运行时，如何安全降级？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 控制权限保守律（Control-Authority Conservatism）**
对末端执行器控制模式 `m ∈ {FREE, CONTACT, GRASP}`，定义权限包络 `A_e(θ, m) = { x : ||x − θ||_{M_e} ≤ β_m(θ) }`，其中 `β_m` 由控制器模型给出**保守上界**：自由模式 `β_FREE = e_ss + v_max·δ + ½·a_max·δ²`；接触模式 `β_CONTACT = β_FREE + ||F_ext||/K_eff`；抓取模式 `β_GRASP = β_FREE + r_grip`（抓取偏移半径）。证书提升：`Cert_ee(θ, m) = Cert_col(θ) ∧ [A_e(θ, m) ⊆ FreeSpace]`。**`A_e` 必须是可达集的外近似**；若只能得到内近似，则按内近似**收缩** θ 的认证集。**EEAC 只能收缩 v20 证书，不能扩张**。

**P35 契约组合律（Contract Composition Law）**
每个 BT 节点携带 `C = (Pre, Post, Inv, S)`。组合规则：
- `Sequence(C₁, C₂)`：要求 `Post₁ ⊆ Pre₂`；`Pre = Pre₁`，`Post = Post₂`，`Inv = Inv₁ ∩ Inv₂`，`S = S₁ ∩ S₂`。
- `Fallback(C₁, C₂)`：`Pre = Pre₁`，且要求 `Fail₁ ⊆ Pre₂`（分支 1 失败的状态集包含于分支 2 的前置条件）；`Inv = Inv₁ ∩ Inv₂`；`S = S₁ ∪ (S₂ ∩ Reach(Fail₁))`（仅在分支 1 失败可达的区域内接受分支 2 的参数）。
- `Retry(k, C)`：`S` 不变（或按预算收缩），`Inv` 保持，`Post` 弱化为"k 次内某次成功"。
- `Timeout(τ, C)`：`S` 仅在 `[t, t+τ]` 内有效，过期即 `S = ∅`。
**契约代数的唯一合法证书运算是交与受限并；任何未验证的并/平均都视为不可靠**。

**P36 反应式 tick 安全律（Reactive Tick Safety）**
设 tick 序列 `t₀ < t₁ < …`，活动叶子 `leaf(t_k)`。要求每次切换满足转移条件：`Inv(t_k) ∧ Pre(leaf(t_{k+1}))`；且若发生抢占，则被抢占的子树必须以**安全中止**（safe abort）退出，`SafeAbort(C) ⊆ Inv`。证书缓存 `cache(leaf)` 在 `τ_tick` 内复用，超过 `τ_tick` 或 `τ_consensus` 任一过期即失效并回退 v20。**整树证书 `REEC(T) ⊆ v20 单体证书`**。

## 3. 与基线的接口（如何退化）

- EEAC 失效（控制器模型不可用）⇒ 退回 v20 的指令空间证书，但额外用固定 `β_max` 收缩 ⇒ `Exec ⊆ v20`；
- BTCA 失效（契约不可判定）⇒ 整树退化为"逐叶单独认证 + 无组合保证" ⇒ 只执行已单独认证的叶子 ⇒ `Exec ⊆ v20`；
- Fallback 分支未认证 ⇒ 禁用该 fallback，主分支失败即安全停机 ⇒ `Exec ⊆ v20`；
- tick 缓存过期 ⇒ 逐 tick 重新认证 ⇒ 活性下降但安全；
- 全部失效 ⇒ 完全回退 v20 ⇒ `Exec_v21 ⊆ Exec_v20`。

## 4. 预期贡献

1. **控制权限证书**：首次把碰撞证书从"指令空间"提升到"末端执行器可达空间"，用保守权限包络覆盖跟踪误差、力矩饱和、延迟与接触柔顺，填补"指令安全 ≠ 执行安全"的鸿沟；
2. **行为树证书代数**：给出 BT 节点契约 `(Pre, Post, Inv, S)` 与 Sequence/Fallback/Decorator 的可靠组合律，使安全证明可随任务结构复用，而非每次重证；
3. **反应式证书转移**：给出 tick 边界与抢占下的证书转移条件，使行为树的活性与安全性统一到同一个不变式框架；
4. **恢复分支保守性**：证明 fallback/恢复分支必须比主分支更保守，否则会把系统从已认证安全区推入未认证恢复区；
5. **两层证书结构**：叶子 EEAC + 树 BTCA + 反应 REEC，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19`。

## 5. 本轮最大风险

**一句话**：EEAC 的权限包络 `A_e` 依赖控制器标称模型，而真实末端执行器在**接触瞬态**（未建模的碰撞、摩擦、物体变形、执行器饱和）下会短暂越出标称包络；BTCA 又默认执行是"名义顺序语义"，而真实行为树是**抢占式反应执行**——两者叠加会让证书在"从自由到接触"的切换瞬间**形式上成立、实际上失效**，即"证书追不上执行"。

# IP-425 End-Effector Authority Certificate
class EndEffectorAuthorityCertificate:
    def __init__(self, ccv, controller_model, metric):
        self.ccv = ccv                    # 复用 v20 CCV 作为几何/感知验证器
        self.model = controller_model     # (e_ss, v_max, a_max, delta, K_eff, r_grip)
        self.metric = metric              # 保守距离度量（L∞ 或 Mahalanobis）

    def authority_envelope(self, theta, mode, contact_force=0.0):
        """返回可达位姿的保守外近似 A_e(θ, mode)"""
        beta_free = (self.model.e_ss
                     + self.model.v_max * self.model.delta
                     + 0.5 * self.model.a_max * self.model.delta ** 2)
        if mode == "FREE":
            beta = beta_free
        elif mode == "CONTACT":
            # 未知环境刚度：用最小可信 K_eff 放大（保守）
            beta = beta_free + contact_force / max(self.model.K_eff, 1e-6)
        elif mode == "GRASP":
            beta = beta_free + self.model.r_grip
        else:
            raise ValueError(f"unknown mode {mode}")
        # 关键：取峰值包络而非稳态包络
        return Ball(center=theta, radius=beta, metric=self.metric)

    def certify(self, theta, mode, free_space, contact_force=0.0):
        # 1) 必须先通过 v20 证书（感知/几何层）
        if not self.ccv.cert_col(theta):
            return Cert(False, "V20_COLLISION")
        # 2) 可达集必须整体落在自由空间内（对障碍做 beta 膨胀后检查）
        A = self.authority_envelope(theta, mode, contact_force)
        if not free_space.contains_all(A):        # A ⊆ FreeSpace，保守判据
            return Cert(False, "AUTHORITY_ESCAPES_FREESPACE")
        return Cert(True, "OK", envelope=A)

    def certify_region(self, theta_set, mode, free_space, contact_force=0.0):
        """区域认证：逐点外近似取并，任一失败即整区失败"""
        out = []
        for theta in theta_set.sample_conservative():
            c = self.certify(theta, mode, free_space, contact_force)
            if not c.ok:
                return Cert(False, c.reason)
            out.append(c.envelope)
        return Cert(True, "OK", envelopes=out)


# IP-426 Behavior-Tree Certificate Algebra
@dataclass(frozen=True)
class Contract:
    pre: Predicate          # 状态 -> bool
    post: Predicate
    inv: Predicate
    S: ParamSet             # 认证参数集

    @staticmethod
    def sequence(a: "Contract", b: "Contract") -> "Contract":
        if not implies(a.post, b.pre):
            raise ContractError("SEQ_POST_PRE_MISMATCH")
        return Contract(
            pre=a.pre,
            post=b.post,
            inv=And(a.inv, b.inv),
            S=a.S.intersect(b.S),          # 组合只收缩
        )

    @staticmethod
    def fallback(a: "Contract", b: "Contract") -> "Contract":
        # 分支 1 失败的状态必须满足分支 2 的前置条件
        if not implies(a.fail_pred, b.pre):
            raise ContractError("FALLBACK_PRE_MISMATCH")
        return Contract(
            pre=a.pre,
            post=Or(a.post, b.post),
            inv=And(a.inv, b.inv),
            S=a.S.union(b.S.intersect(a.fail_reachable)),  # 受限并
        )

    @staticmethod
    def retry(k: int, c: "Contract") -> "Contract":
        # retry 不扩张 S；Post 弱化为 k 次内某次成功
        return Contract(
            pre=c.pre,
            post=c.post.within_attempts(k),
            inv=c.inv,
            S=c.S,                          # 不变，或按预算收缩
        )

    @staticmethod
    def timeout(tau: float, c: "Contract", now: float) -> "Contract":
        alive = (now - c.t0) <= tau
        return Contract(
            pre=c.pre,
            post=c.post,
            inv=c.inv,
            S=c.S if alive else ParamSet.empty(),   # 过期即 ∅
        )


class BehaviorTreeCertificateAlgebra:
    def __init__(self, eeac, free_space):
        self.eeac = eeac
        self.free_space = free_space

    def certify_leaf(self, leaf, mode, contact_force=0.0):
        cert = self.eeac.certify_region(
            leaf.theta_set, mode, self.free_space, contact_force)
        if not cert.ok:
            return None
        return Contract(
            pre=leaf.pre, post=leaf.post, inv=leaf.inv,
            S=leaf.theta_set, fail_pred=leaf.fail,
            fail_reachable=leaf.fail_reachable,
        )

    def compose(self, node):
        """后序遍历：叶子 -> EEAC；内部节点 -> BTCA 组合律"""
        if node.is_leaf:
            return self.certify_leaf(node, node.mode, node.contact_force)
        child_contracts = [self.compose(ch) for ch in node.children]
        if any(c is None for c in child_contracts):
            return None
        if node.kind == "sequence":
            acc = child_contracts[0]
            for c in child_contracts[1:]:
                acc = Contract.sequence(acc, c)
            return acc
        if node.kind == "fallback":
            acc = child_contracts[0]
            for c in child_contracts[1:]:
                acc = Contract.fallback(acc, c)
            return acc
        if node.kind == "retry":
            return Contract.retry(node.k, child_contracts[0])
        if node.kind == "timeout":
            return Contract.timeout(node.tau, child_contracts[0], node.now)
        raise ValueError(node.kind)


# IP-427 Invariant-Preserving Fallback
class InvariantPreservingFallback:
    def __init__(self, invariant):
        self.invariant = invariant

    def safe_abort(self, contract, state):
        """抢占/取消时，被中断子树必须能安全中止且不破坏 Inv"""
        abort_states = contract.safe_abort_set()   # 子树显式声明的安全中止集
        if not implies(abort_states, self.invariant):
            return False, "UNSAFE_ABORT_SET"
        return self.invariant(state), "OK"

    def recovery_guard(self, main_c, recovery_c):
        """恢复分支必须比主分支更保守：S_recovery ⊆ S_main 的保守包络内"""
        if not recovery_c.S.is_subset_of(main_c.S.conservative_closure()):
            return None, "RECOVERY_TOO_OPTIMISTIC"
        return Contract.fallback(main_c, recovery_c), "OK"


# IP-428 Tick-Consistent Certificate
class TickConsistentCertificate:
    def __init__(self, ttl_tick, ttl_consensus):
        self.ttl_tick = ttl_tick
        self.ttl_consensus = ttl_consensus
        self.cache = {}

    def tick_transition(self, prev_leaf, next_leaf, state, now):
        if not state.inv:
            return False, "INV_VIOLATED"
        if not next_leaf.contract.pre(state):
            return False, "PRE_VIOLATED"
        if prev_leaf is not None:
            ok, why = self._safe_abort(prev_leaf, state)
            if not ok:
                return False, why
        if self._expired(next_leaf, now):
            return False, "CERT_EXPIRED"
        return True, "OK"

    def _expired(self, leaf, now):
        age = now - leaf.cert_timestamp
        return age > self.ttl_tick or age > self.ttl_consensus

    def _safe_abort(self, leaf, state):
        return leaf.contract.safe_abort(state)


# IP-429 Reactive End-Effector Certificate
class ReactiveEndEffectorCertificate:
    def __init__(self, btca, ipf, tcc):
        self.btca = btca
        self.ipf = ipf
        self.tcc = tcc

    def build(self, tree, mode):
        # 1) 叶子层：EEAC 认证
        root_contract = self.btca.compose(tree)
        if root_contract is None:
            return None, "LEAF_CERT_FAIL"
        # 2) 树层：BTCA 组合 + 不变式保持
        if not implies(root_contract.inv, self.ipf.invariant):
            return None, "INVARIANT_NOT_PRESERVED"
        # 3) 恢复分支：必须比主分支保守
        for fb in tree.fallback_nodes():
            ok, why = self.ipf.recovery_guard(fb.main_contract, fb.recovery_contract)
            if ok is None:
                return None, why
        return REEC(tree=tree, contract=root_contract,
                    invariant=self.ipf.invariant, mode=mode)

    def execute_tick(self, reec, prev_leaf, next_leaf, state, now):
        return self.tcc.tick_transition(prev_leaf, next_leaf, state, now)

## 2. 推导

**引理 157（控制权限保守性）** 若 `A_e(θ,m)` 是可达集 `Reach(θ,m)` 的外近似，即 `Reach(θ,m) ⊆ A_e(θ,m)`，则 `Cert_ee(θ,m) = Cert_col(θ) ∧ [A_e(θ,m) ⊆ FreeSpace]` 蕴含 `Reach(θ,m) ⊆ FreeSpace`。故 `Cert_ee` 不会把碰撞指令误判为安全，且 `Cert_ee ⊆ Cert_col`。∎ 推论：**EEAC 只能收缩 v20 证书，不能扩张**。

**引理 158（契约组合可靠性）** 对树结构归纳：叶子由 EEAC 认证且契约成立；若子契约成立，则 `Sequence` 因 `Post₁ ⊆ Pre₂` 保证衔接、`Fallback` 因 `Fail₁ ⊆ Pre₂` 保证失败后分支可安全启动、装饰器只收缩 S 或保持 Inv，故组合契约成立。归纳假设传递到根，整树契约成立。∎

**引理 159（恢复分支保守性）** 若 `S_recovery ⊄ S_main.conservative_closure()`，则存在 `θ ∈ S_recovery \ S_main`，恢复动作会把系统从已认证区推入未认证区；`recovery_guard` 显式拒绝此情形。故被接受的 fallback 满足 `S_recovery ⊆ S_main` 的保守包络，恢复不扩张认证域。∎

**引理 160（tick 转移安全性）** 若每次 tick 满足 `Inv(t_k) ∧ Pre(leaf(t_{k+1}))` 且抢占满足 `SafeAbort ⊆ Inv`，则对任意 tick 序列，活动叶子始终处于 `Pre ∧ Inv` 内，且被抢占子树不破坏 Inv。故反应式执行不进入未认证区域。∎

**引理 161（反应式证书保守性）** `REEC(T) = BTCA({EEAC(leaf)})`：EEAC 收缩叶子证书（引理 157），BTCA 组合只交/受限并（引理 158），IPF 拒绝过度乐观的恢复分支（引理 159）。故 `REEC(T).S ⊆ ∩_leaf Cert_col(leaf) ⊆ v20 单体证书`。∎

**引理 162（v21 整体安全继承）** 在同一几何快照、同一机器人集合、同一控制器模型下，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。证明：EEAC 提升只收缩、BTCA 组合只交/受限并、IPF 拒绝不保守恢复、TCC 过期即 ∅，四者叠加只能产生子集。∎

## 6. 已知风险与失效模式

1. **接触瞬态的包络失配**：`A_e` 基于标称阻抗/力矩模型，真实接触的摩擦、变形、饱和会让瞬态短暂越出包络，而证书恰在接触瞬间最重要。缓解：峰值+超调双包络、在线辨识 K_eff、接触前主动降速。
2. **名义顺序语义 vs 抢占式反应语义**：BTCA 的组合律假设名义顺序，真实 BT 的抢占/异步取消可能让 `Post_i ⊆ Pre_{i+1}` 在时间上不成立。缓解：TCC 的 tick 转移断言、显式 SafeAbort、回滚到上一个已认证 tick。
3. **连续状态谓词不可判定**：`Post ⊆ Pre`、`Fail ⊆ Pre` 在连续/数值误差下可能只能近似判定。缓解：区间算术、保守采样+证书、容差显式化。
4. **包络过度保守扼杀活性**：外近似过大会使证书体积骤减，任务成功率下降。缓解：分模式包络、按风险分级、活性反馈闭环。
5. **双重保守叠加**：v20 的 `ColDom_fed` 与 EEAC 的 `A_e` 同时膨胀，可能把可行域压到接近空。缓解：联合膨胀一次、避免重复计入同一误差源。
6. **tick 抖动与延迟**：控制周期抖动使 `τ_tick` 失效判定不准。缓解：时间戳单调化、延迟补偿、保守 TTL。
7. **恢复分支的隐性乐观**：开发者可能把"总能恢复"当作安全，而恢复动作本身未被认证。缓解：IPF 强制 `S_recovery ⊆ S_main` 的保守包络，未认证即禁用。

## 7. 本轮最大风险

**一句话**：EEAC 的权限包络 `A_e` 依赖控制器标称模型，而真实末端执行器在**接触瞬态**（未建模的碰撞、摩擦、物体变形、执行器饱和）下会短暂越出标称包络；BTCA 又默认执行是"名义顺序语义"，而真实行为树是**抢占式反应执行**——两者叠加会让证书在"从自由到接触"的切换瞬间**形式上成立、实际上失效**，即"证书追不上执行"。
