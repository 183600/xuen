# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「主动交互」×「多机器人协作」）

> R69 把不确定性一分为二，并给 epistemic 歧义配了一张「嘴」：看、问、触。但它默认只有**一个**提问者、**一个**被问者，且证据彼此独立。真实部署中，机器人很少独行：3–30 台同型号机器人共享同一个预训练模型、同一套标定流程、同一条产线数据、甚至同一个疲惫的人类操作员。此时 R69 最核心的证据纪律——「k 个正交证据源一致才定案」——会悄悄失效：十台机器人异口同声，可能只是**同一个错误被复制了十次**。这是多机器人协作最危险的盲点：**共识（consensus）看起来像证据，实际上可能只是回声（echo）**。
>
> 本轮两个灵感正好把这层窗户纸捅破：
> - **多机器人协作**：把「证据源」从一个抽象集合变成一张**带相关性的交互图**。机器人不是独立同分布的投票者，而是共享隐变量 C（模型 / 标定 / 传感器族 / 数据 / 人类）的相关观测器；关键量从「源数 k」变成「**有效独立源数 k_eff**」。
> - **主动交互**：交互不再只是「我拉取（pull）一条信息」，还包括「我主动推送（push）我的判断」。而**最高效的推送恰恰是最污染独立性的**：广播结论会让所有接收者瞬间相关，制造虚假共识。
>
> 核心命题：**把 R69 的单智能体主动消歧，升级为多机器人团队的「相关性感知主动交互」：主动交互的目标不是让团队更快达成一致，而是让团队在不确定时维持「可校准的分歧」（calibrated dissensus）；VoI 换成按相关性折扣的独立信息价值 IVoI；证据纪律从「k 源一致」换成「k_eff 足够」；独立性不是给定的，而是通过异构视角 / 模态 / 问法主动制造出来的；并且严格保持 R69 在其 N=1 边界上的逐指令退化。** 命名 **CHORUS-RAS**（Correlated-evidence-aware, Heterogeneous, Orchestrated, Robust, Uncertainty-split Swarm）——**合唱不是回声**。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**当所有同伴都同意我时，我凭什么相信这不是一场回声**」。

## 0. 直觉与动机

**灵感 1（多机器人 → 共识是相关随机变量，不是独立选票）**
直觉：单机器人问人类，证据源（视觉 / 听觉 / 触觉 / 人类回答）大致独立。但一支同构机器人队伍不是：它们用同一个模型训练、同一套标定、同一批传感器、同一个操作员。若每台的错误率都是 δ、错误之间相关系数 ρ，则多数投票的错误率不是 δ^k 那样指数下降，而是被一个**地板 ρδ** 卡住：再增加一百台同型号机器人，也只能把「独立的那部分」压到零，压不掉「一起错的那部分」。用有效样本量看更直白：交换对称时 k_eff = N / (1 + (N−1)ρ)。ρ=0.3 时，16 台机器人只有约 2.9 个「真正独立的声音」。**机器人数量是线性增长的，独立性不是。** 更阴险的是：相关性往往**不可见**——它们分歧很小、置信很高、日志漂亮，系统会把「大家一致」当成强证据，实际上只是把同一个先验错误放大。

**灵感 2（主动交互 → push 与 pull 的不对称；传证据，不传结论）**
直觉：R69 的交互是 pull（问一句、看一眼）。但团队里更自然的是 push（主动广播、示教、提醒）。push 的效率极高——一次广播替代 N−1 次询问；但它也极危险：广播**结论**时，所有接收者的证据立刻被同一个源「短路」，后验相关性趋近 1，团队判断退化为广播者的判断。广播**原始证据**（我看的角度、我测到的值、我的不确定性）时，接收者才能形成条件独立的判断。于是得到一条设计律：**传证据，不传结论（broadcast evidence, not conclusions）**；以及一个可证明的权衡：结论型 push 的信息增益为零（结论是证据的函数，接收者本可自行计算），却把 ρ 推到 1——**它买到的只有虚假的自信**。

**灵感 3（VoI → IVoI；独立性是被制造出来的）**
直觉：R69 的 VoI 问「这条信息能降低多少熵」。在团队里，正确的问题是「这条信息在**已有证据条件下**还能降低多少熵」——条件互信息 I(M; Y_g | ℱ_t) 天然排除冗余；再按与现有证据的相关性 ρ_eff 折扣，得到**独立信息价值** IVoI = (1−ρ_eff)·I(M; Y_g | ℱ_t)。由此推出两个反直觉结论：(a) 最该问的不是「谁最权威」，而是「谁的误差和我最不相关」；(b) 当现有证据已经高度相关时，**主动制造**一个真正独立的证据（换个视角、换种模态、换个人问）比再问一个「可靠但同源」的同伴值钱得多。独立性和信息一样，是一项可以被**设计**出来的资源。

**灵感 4（共识 → 校准分歧；不确定时不要急着达成一致）**
直觉：分布式系统默认「收敛到一致」是好事。但当共同原因 C 可能出错时，**收敛恰恰是危险的**：所有人收敛到同一个错误，团队就失去了纠错能力。正确目标不是 consensus，而是 **calibrated dissensus**——保留多个假设、用相关性感知的权重维护它们、只在 k_eff 足够且后验足够尖时才坍缩为单一决策；否则选择一个**对假设集鲁棒**的动作（如保持选项、减速、派一台去看），而不是对均值下注。一句话：**团队的价值不在于更快地同意，而在于不同意时仍然安全。**

**灵感 5（交互是公共品 → 预算机制与查询风暴）**
直觉：一台机器人问出的信息，全队受益；但成本由提问者承担。这就是典型的公共品：不设计机制就会**搭便车**（都不问，等别人问）或**查询风暴**（都抢着问，重复问同一件事）。R69 的「≤1 次/单位时间」是单机硬上限，团队里必须变成**可分配、可计价、可退还的信用账户**：谁问、问谁、问几次由一次轻量拍卖决定，冗余查询按「与已有证据的重叠度」额外收费，从而在机制层面保证查询次数有界。

**灵感 6（包含性 → R69 是 N=1 的边界；安全是硬约束）**
直觉：任何新层都必须能退化回旧层，否则每加一层就多一个需要独立信任的黑箱。CHORUS 在 N=1、ρ=0、无通信时**必须逐指令等于 FLUID-RAS**；团队层只允许在「更独立的信息」和「更鲁棒的动作」上获得收益，绝不允许降低安全。通信带来延迟、丢包、欺骗，因此「问不问」之前先问「来不来得及刹车」——**ask-or-brake**。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（CHORUS-RAS 总览）** CHORUS-RAS = (TAN, CAD, IVoI, IMI, CDE, TBM, PBT, CAS, DWM, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 276-i）；
(ii) **团队交互/通信预算硬约束**：单位时间总信息动作 ≤ B_t、单机 ≤ b_i、总通信时延 ≤ d_max，所有信息动作与通信动作都必须通过与任务动作相同的 C-RAS-WM 认证；
(iii) **相关性感知证据纪律**：任何「一致性」只能按有效独立源数 k_eff 计入，绝不按参与机器人数量 N 计入；k_eff < k_min 时禁止坍缩为单一模态（定义 319）。

**定义 311（团队与交互图）** 团队 𝒩={1,…,N}；t 时刻智能体 i 的局部观测 o_t^i、局部信念 b_t^i、任务动作 a_t^i、信息动作 g_t^i。交互图 G_t=(𝒩,E_t)，边 (i,j)∈E_t 表示存在可用通信信道。联合观测 o_t^𝒩=(o_t^1,…,o_t^N)，联合动作 ξ_t^𝒩∈𝒜_+^N。R69 的单机状态是 N=1 的退化。

**定义 312（增广团队动作）** 在 R69 定义 294 的基础上，信息动作扩为 g=(g_gaze, g_probe, g_ask, g_pull, g_push, g_move)：
- g_pull（pull）：向同伴或人类索取证据或判断；
- g_push（push）：主动广播，载荷 payload∈{evidence, conclusion}（定义 317）；
- g_move：为获得新视角而移动（主动感知 / 下一最佳视角）；
- g_phys：物理协助（扶住、遮挡、共同搬运）以改变可观测量。
ξ_i=(a_i,g_i)，ξ^𝒩=(ξ_1,…,ξ_N)。

**定义 313（误差相关性与有效独立源数）** 设模态身份 M，智能体 i 的证据误差 e_i。两两误差相关系数 ρ_ij=corr(e_i,e_j|M)，R=[ρ_ij]（ρ_ii=1）。对权重 w 的证据融合，**有效独立源数** k_eff=(Σ_i w_i)²/(wᵀRw)。交换对称、等权时 k_eff=N/(1+(N−1)ρ̄)（ρ̄ 为平均相关）。定义**独立性赤字** κ=N/k_eff≥1；κ 越小越接近独立。

**定义 314（共同原因分类）** 隐变量 C=(C_model, C_cal, C_sensor, C_data, C_human)，分别表示共享模型、共享标定、共享传感器族、共享训练数据、共享人类信息源。假设 A99：给定 (M,C)，各智能体观测条件独立；所有互相关都由 C 解释。ρ_ij 可按共同原因做方差分解 ρ_ij=Σ_c s_ic s_jc，s 为对应原因的相关负载。

**定义 315（相关性感知融合）** 在 A99 与高斯近似下，最优线性融合权重为广义最小二乘 w=R^{-1}1/(1ᵀR^{-1}1)（ρ=0 时退化为等权平均）；后验 log-odds 为 ℓ=ℓ_prior+Σ_i w_i ℓ_i。当 R 未知时用其估计 R̂，并以 ε_ρ 给出后验的保守膨胀（定义 326 证书记录 ε_ρ）。

**定义 316（独立信息价值 IVoI）** 对候选信息动作 g，
IVoI(g)=(1−ρ_eff(g))·I(M;Y_g|ℱ_t)，
其中 ℱ_t 为团队已有证据，ρ_eff(g) 为 g 所产生证据与 ℱ_t 的期望相关（由定义 314 的共同原因分解估计；严格版本用条件互信息 I(M;Y_g|ℱ_t,C) 再对 p(C|ℱ_t) 取期望）。选择
g*=argmax_g [IVoI(g)−c_phys(g)−c_comm(g)−c_social(g)−λ_r·redundancy(g)]，
s.t. 预算未越界、C-RAS-WM 认证通过。IVoI−成本 ≤ 0 时不交互，逐指令退化为 R69。

**定义 317（push–pull 不对称 / 证据-结论二分）** push 载荷分为 evidence（原始观测、局部似然、不确定性）与 conclusion（后验模态 / 判断）。结论型 push 使接收者证据与广播者共享同一共同原因，ρ_eff→1，独立信息增益→0；证据型 push 保留接收者的条件独立性。**设计律：传证据，不传结论。**

**定义 318（独立性制造 IMI）** 在候选信息动作中主动选择使期望 ρ_eff 最小（或使 k_eff 最大）者：换视角（g_move）、换模态（g_gaze/g_probe 的模态选择）、换问法（g_ask 的表述避免引导）、换信息源（换同伴 / 换人类）。定义**多样性指数** D=1−ρ̄_after；独立制造收益 Δk_eff=k_eff(after)−k_eff(before)。

**定义 319（校准分歧引擎 CDE）** 维护模态假设集 ℋ_t={m_k,ŵ_k} 及其相关结构。坍缩判据：
Collapse ⇔ k_eff≥k_min ∧ H(M|ℱ_t)≤τ_H ∧ ECE≤τ_ece。
不满足时保持分歧，并选择**鲁棒动作** a*=argmin_a max_{m∈ℋ_t^ε} E[cost(a,m)]（或 CVaR_α），其中 ℋ_t^ε 为后验质量 ≥1−ε 的模态集。**「一致」是输出，不是证据**；不得用一致性本身反过来加强后验。

**定义 320（团队预算机制 TBM）** 每个智能体持有信用账户 q_i；总预算 B_t。查询权通过轻量拍卖分配：出价=预期 IVoI 的私人估值；付费=c(g)+λ_r·redundancy(g)。冗余度按与已有证据的重叠估计 redundancy(g)=I(Y_g;ℱ_t)/I(Y_g;M)。机制保证：单位时间信息动作总数 ≤B_t、单机 ≤b_i；冗余查询因净值为负而自然退出；搭便车由「提出者获 credit 返还 / 非提出者分摊通信成本」修正。

**定义 321（同伴拜占庭容错 PBT）** 对每个同伴维护信任 τ_ij 与历史验证记录。聚合采用鲁棒统计（加权中位数 / 截尾均值 / Huber），而非均值。**共谋检测**：若一个子集内部「主张高度一致」但「其主张与独立物理复核的一致率持续偏低」，则判定为共谋 / 共同故障，整体降权。信任更新：τ_ij←(1−η)τ_ij+η·1[验证通过]。

**定义 322（通信感知安全 CAS）** 通信往返时延 d_ij≤d_max，丢包率 p_loss。查询 / 广播前必须验证：在最坏时延 d_max 内，已认证前缀仍能保持安全（存在 hold/brake 动作使风险 ≤ε）。否则不查询，执行本地安全动作（ask-or-brake）。通信动作本身也过 C-RAS-WM 认证，禁止越出安全包络。

**定义 323（分布式世界模型一致性 DWM）** 每个智能体维护 b_t^i 与共享一致性残差 r_cons=max_{i,j} d(b_t^i,b_t^j)。融合算子 ⊙ 采用定义 315 的相关性感知融合，禁止朴素平均（朴素平均会抹掉分歧并制造虚假共识）。一致性是**目标之一**，不是正确性的证据：r_cons→0 而 k_eff→1 是**危险信号**而非成功信号。

**定义 324（参与式团队审计 VQAuditor-T）** 审计对象新增：谁向谁问了什么、冗余率、回声室指数（团队一致性与独立物理复核的一致率之差）、搭便车率、独立制造是否真实执行、Byzantine 投票边际。结论回灌 AuditBuf，作为下一轮 TBM 的成本先验与 PBT 的信任先验。

**定义 325（团队威胁模型 AIC-CHORUS）** ℰ_CHORUS=ℰ_FLUID×ℰ_corr×ℰ_byz×ℰ_comm×ℰ_groupthink：共同原因相关误差（同模型 / 同标定 / 同数据污染）、拜占庭同伴与共谋、通信欺骗 / 重放 / 延迟 / 丢包、群体思维（所有人互相引用导致 ρ→1）。

**定义 326（证书 J_CHORUS）** J_CHORUS=(J_FLUID, k_eff, ρ_eff, ε_ρ, IVoI_ratio, independence_gain, interaction_graph_hash, diversity_index D, comm_delay_p95, loss_p95, byzantine_margin, chorus_ver)。Valid ⇔ Valid(J_FLUID) ∧ k_eff 与 ρ̂ 在置信区间内 ∧ 证据纪律满足 ∧ 团队预算与通信预算未越界。

**定义 327（严格包含与退化）** 当 N=1、E_t=∅、ρ=0 时，CHORUS 的每个决策与 FLUID-RAS 逐指令相同；团队层只允许通过「更独立的证据」获得 resolution bonus，不允许降低安全下界。故 R69 = CHORUS 在「无同伴」边界上的退化。

**定义 328（自适应团队调度）** 采样数 K、通信轮数 R_comm、单轮查询数 m 由廉价门控 mode_head(z_t^𝒩) 与 k_eff 预报共同决定：常规 K=1、R_comm=0；歧义且 k_eff 低时升 K=4、R_comm≤1；并保证 P99 时延预算。通信采用异步 gossip，避免同步屏障。

## 2. 关键算法骨架

```python
# IP-264 TAN + IP-265 CAD：团队相关性估计与有效独立源数
class CorrelationAwareDecomposer:
    def __init__(self, common_cause_prior):
        self.C = common_cause_prior          # (model, cal, sensor, data, human)
        self.R_hat = {}                      # 两两相关估计

    def update(self, team_evidence):
        # 用共同原因分解 + 残差经验相关估计 rho_ij（定义 313-314）
        for (i, j) in pairs(team_evidence):
            self.R_hat[(i, j)] = estimate_rho(team_evidence[i], team_evidence[j], self.C)
        return self.R_hat

    def effective_sources(self, w, R):
        return (w.sum() ** 2) / (w @ R @ w)   # k_eff（定义 313）

# IP-266 IVoI：独立信息价值（按相关性折扣的 VoI）
def independent_voi(g, M, F_t, R_hat, C):
    cond_mi = conditional_mutual_info(M, g, given=F_t)   # I(M;Y_g|F_t)
    rho_eff = expected_correlation(g, F_t, R_hat, C)     # 定义 316
    return (1.0 - rho_eff) * cond_mi

# IP-267 IMI + IP-268 CDE：制造独立性并把分歧进行到底
def plan_interaction(team, modes, F_t, budget):
    best = None
    for g in team.info_action_candidates(modes):        # pull/push/move/phys
        if not budget.allow(g) or not c_ras_wm.certify_info(g, team): continue
        score = independent_voi(g, modes, F_t, team.R_hat, team.C) - team.cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None    # 无利可图 → R69

def calibrated_decide(modes, w, R, k_min, tau_H):
    k_eff = effective_sources(w, R)
    if k_eff >= k_min and entropy(w) <= tau_H and ece_ok():
        return collapse(modes, w)                        # 允许坍缩
    return robust_action(modes, w, alpha=0.95)          # 保持分歧，鲁棒动作

# IP-270 PBT + IP-271 CAS：鲁棒聚合 + ask-or-brake
def robust_peer_fuse(claims, trust):
    return weighted_median_or_trimmed(claims, trust)     # 非均值，抗共谋

def ask_or_brake(candidate_g, state, d_max):
    if not safe_under_delay(state, d_max):                # 最坏时延下仍能安全
        return None                                      # 不查询，本地安全动作
    return candidate_g

# IP-276 CHORUS 主闭环（继承 R69，仅在团队处插入 CHORUS 层）
def CHORUS_round(team, obs, F_t):
    # 1) 本地快层：与 R69 完全一致（保证包含性）
    local = [FLUID_RAS_local(agent, o) for agent, o in zip(team, obs)]
    # 2) 团队层：估计相关性与有效独立源数
    R_hat = team.cad.update(local)
    k_eff = team.cad.effective_sources(local_weights(local), R_hat)
    # 3) 主动交互：可负担且来及时才问/广播；结论型 push 被禁止
    g = plan_interaction(team, local_modes(local), F_t, team.budget)
    g = ask_or_brake(g, team.state, d_max=team.d_max) if g else None
    if g is not None:
        payload = gather_evidence(g)                     # 只传证据
        team.cia.distribute(payload, trust=team.pbt.trust)
        team.tbm.charge(g)                               # 预算记账
    # 4) 相关性感知融合 + 校准分歧决策
    fused = team.cad.fuse(local, R_hat)
    a = calibrated_decide(fused.modes, fused.w, R_hat, k_min, tau_H)
    # 5) 安全认证（团队动作也过 C-RAS-WM；通信延迟已计入）
    k = team.c_ras_wm.certified_prefix(a, ..., wm_preds)
    if team.byzantine_margin < 0:                        # 共谋/故障可疑
        a = team.local_safe_action(); k = min(k, team.k_safe)
    team.vqa_t.submit_async(g, k_eff, R_hat, fused)
    return k, a, (k_eff, fused.dispersion)
```

## 3. 推导

**引理 19（相关共识的置信膨胀与 k_eff 饱和）** 设 N 个等权证据源，每个错误率 δ，错误两两相关 ρ̄；以概率 ρ̄ 发生共同错误、否则独立出错。则多数表决错误率
P_err(N)=ρ̄·δ+(1−ρ̄)·P[Bin(N,δ)≥⌈N/2⌉]，
其下界为 ρ̄·δ，且不随 N→∞ 消失；有效独立源数 k_eff=N/(1+(N−1)ρ̄) 饱和到 1/ρ̄。系：R69 引理 18 的「k 个正交源一致」只在 ρ=0 时成立；一旦 ρ>0，**增加同构机器人会把后验置信推高，却不把错误率压低**。这解释了为什么「团队一致」可能是最危险的时刻。

**引理 20（独立信息价值 / 新源折扣）** 设已有证据 ℱ_t，新证据 Y_g 关于 M 的最大信息为 I_max=H(M)。若 Y_g 与 ℱ_t 在给定 M 下的相关为 ρ_eff，则其**增量**信息满足 I(M;Y_g|ℱ_t)≤(1−ρ_eff)·H(M)；ρ_eff=1 时增量为 0。系：最优信息源不是「最准的」，而是「在已知证据条件下最不冗余的」；当 ℱ_t 已高度相关时，制造异构视角（降低 ρ_eff）比提高单源精度更划算。

**引理 21（push 的证据-结论二分）** 广播结论 c=φ(ℱ) 是已有证据的确定性函数，对已知 ℱ 的接收者不提供关于 M 的新信息（I(M;c|ℱ)=0），但使接收者证据与广播者共享共同原因，ρ_eff→1；广播原始证据则保留条件独立性。故在 A99 下，**结论型 push 只增加相关性、不增加信息**；证据型 push 才能提高 k_eff。系：R69 的「k 源一致」在结论型广播下等价于「1 源被复制 k 次」。

**引理 22（ask-or-brake 安全边界）** 设查询最坏往返时延 d_max，智能体在时延窗口内的安全保持前缀长度为 L(d_max)。若 L(d_max) 大于可用安全裕度 s_safe，则任何查询都存在不可接受风险；此时唯一安全策略是不查询并执行已认证的本地 hold/brake。故存在一个**时延-安全可行域**，超出即自动退化为 R69 的无交互路径。

**定理 18（CHORUS 严格包含 FLUID-RAS）** 在 A99–A104 下，CHORUS 在任意团队状态上的期望风险 ≤ 对应的 R69 单机策略在所有相同的退化条件下；且当 N=1、E_t=∅、ρ=0、无交互收益时，两者逐指令相同（定义 327）。安全侧不做让步，效率侧获得团队 resolution bonus。

**定理 19（校准分歧不劣于强制共识）** 在共同原因可能出错的 A99 下，若后验多峰且共同原因方差 σ_C²>0，则「强制坍缩到融合均值」的贝叶斯风险严格不小于「保留后验质量 ≥1−ε 的模态集并取鲁棒动作」的风险；当 ε 覆盖共同原因导致的系统性偏移时等号成立。直觉：把分歧平均掉，等于假设共同原因一定对；一旦它错，团队没有 Plan B。

**定理 20（团队预算有界性与容错边界）** 在 TBM 的冗余计价与拍卖下，任何单位时间的信息动作总数 ≤B_t（查询风暴不可能），且存在纯策略均衡；在多样性 D 与 Byzantine 比例 f 下，鲁棒融合错误率满足 ε_team≤g(D,f,k_eff)，当 f<(D·N−1)/2 时可抑制到阈值以下（A102）。

## 6. 本轮最大风险

**一句话**：CHORUS-RAS 的全部安全保障押在「能把 ρ 估准」上——一旦相关性被**低估**（共享模型 / 标定 / 数据 / 人类形成一条看不见的共同原因），系统就会把一群相关的回声当成多个独立证词，机器人越多、置信越高、一起错得越自信；**团队规模于是从安全冗余变成了错误放大器**。

**次级风险与缓解**：
1. **相关性估计偏差** → 用共同原因结构化分解 + ε_ρ 保守膨胀 + E316 对抗投毒；

## 3. 关键算法伪代码

```python
# IP-265 CAD：相关性估计与有效独立源数
def cad_update(team_evidence, C):
    R = {(i, j): estimate_rho(team_evidence[i], team_evidence[j], C)
         for (i, j) in pairs(team_evidence)}
    return R

def effective_sources(w, R):
    return (w.sum() ** 2) / (w @ R @ w)        # k_eff = (Σw)²/(wᵀRw)

# IP-266 IVoI：按相关性折扣的独立信息价值
def independent_voi(g, M, F_t, R, C):
    return (1 - expected_correlation(g, F_t, R, C)) * conditional_mutual_info(M, g, F_t)

# IP-267 IMI + IP-269 TBM：主动交互选择（含预算与冗余计价）
def plan_interaction(team, modes, F_t, budget):
    best = None
    for g in team.info_action_candidates(modes):          # pull/push/move/phys
        if not budget.allow(g) or not c_ras_wm.certify_info(g, team): continue
        score = independent_voi(g, modes, F_t, team.R, team.C) - budget.price(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 无利可图 → R69

# IP-268 CDE：校准分歧决策
def calibrated_decide(modes, w, R, k_min, tau_H):
    if effective_sources(w, R) >= k_min and entropy(w) <= tau_H and ece_ok():
        return collapse(modes, w)                          # 仅在 k_eff 足够时坍缩
    return robust_action(modes, w, alpha=0.95)            # 保留分歧，鲁棒动作

# IP-270 PBT + IP-271 CAS：鲁棒聚合 + ask-or-brake
def robust_peer_fuse(claims, trust):
    return weighted_median_or_trimmed(claims, trust)

def ask_or_brake(g, state, d_max):
    return g if safe_under_delay(state, d_max) else None   # 来不及时不干，先刹车

# IP-276 CHORUS 主闭环
def CHORUS_round(team, obs, F_t):
    local = [FLUID_RAS_local(agent, o) for agent, o in zip(team, obs)]   # 继承 R69
    R = cad_update(local, team.C)
    k_eff = effective_sources(local_weights(local), R)
    g = plan_interaction(team, local_modes(local), F_t, team.budget)
    g = ask_or_brake(g, team.state, team.d_max) if g else None
    if g is not None:
        team.cia.distribute(gather_evidence(g), trust=team.pbt.trust)    # 只传证据
        team.tbm.charge(g)
    fused = team.cad.fuse(local, R)                       # 相关性感知融合
    a = calibrated_decide(fused.modes, fused.w, R, k_min, tau_H)
    k = team.c_ras_wm.certified_prefix(a, ..., wm_preds)
    if team.byzantine_margin < 0:
        a = team.local_safe_action(); k = min(k, team.k_safe)
    team.vqa_t.submit_async(g, k_eff, R, fused)
    return k, a, (k_eff, fused.dispersion)
```

## 4. 推导

**引理 19（相关共识的置信膨胀与 k_eff 饱和）** N 个等权源，错误率 δ，两两相关 ρ̄；以概率 ρ̄ 共同出错、否则独立出错。则
`P_err(N)=ρ̄δ+(1−ρ̄)·P[Bin(N,δ)≥⌈N/2⌉]`，下界 `ρ̄δ` 不随 N 消失；`k_eff=N/(1+(N−1)ρ̄)→1/ρ̄`。系：R69 引理 18 的「k 正交源一致」只在 ρ=0 成立；ρ>0 时增加同构机器人只推高置信、不压低错误。

**解析示例（δ=0.1，非实测）**

| N | k_eff (ρ=0) | P_err (ρ=0) | k_eff (ρ=0.3) | P_err (ρ=0.3) | k_eff (ρ=0.7) | P_err (ρ=0.7) |
|---|---|---|---|---|---|---|
| 1 | 1.00 | 0.1000 | 1.00 | 0.1000 | 1.00 | 0.1000 |
| 2 | 2.00 | 0.0100 | 1.54 | 0.0370 | 1.18 | 0.0730 |
| 4 | 4.00 | 0.0037 | 2.11 | 0.0326 | 1.29 | 0.0711 |
| 8 | 8.00 | 0.0004 | 2.58 | 0.0303 | 1.36 | 0.0701 |
| 16 | 16.00 | ~0 | 2.91 | 0.0300 | 1.39 | 0.0700 |

读法：ρ=0.3 时，机器人从 2 台增到 16 台，P_err 仅从 3.70% 降到 3.00%，k_eff 卡在约 2.9；ρ=0.7 时几乎无收益。**规模不是独立性，一致性不是正确性。**

**引理 20（独立信息价值 / 新源折扣）** `I(M;Y_g|ℱ_t)≤(1−ρ_eff)·H(M)`；ρ_eff=1 时增量为 0。系：最优信息源是「条件最不冗余」而非「单源最准」；制造异构视角比提高单源精度更划算。

**引理 21（push 的证据-结论二分）** 结论 `c=φ(ℱ)` 对已知 ℱ 的接收者 `I(M;c|ℱ)=0`，却令 ρ_eff→1；证据型 push 保留条件独立。故结论型 push 只买来虚假自信；R69 的「k 源一致」在结论型广播下等于「1 源复制 k 次」。

**引理 22（ask-or-brake 安全边界）** 若时延窗口所需安全保持前缀 `L(d_max)` 超过安全裕度 `s_safe`，任何查询都不可接受，唯一安全策略是不查询并执行已认证 hold/brake；存在时延-安全可行域，越界自动退化到 R69 无交互路径。

**定理 18（严格包含 FLUID-RAS）** A99–A104 下，CHORUS 期望风险 ≤ 对应 R69 策略；N=1、E_t=∅、ρ=0、无交互收益时逐指令相同。安全不让步，效率获团队 resolution bonus。

**定理 19（校准分歧不劣于强制共识）** 后验多峰且共同原因方差 `σ_C²>0` 时，强制坍缩到融合均值的贝叶斯风险不小于保留质量 ≥1−ε 模态集并取鲁棒动作；ε 覆盖共同原因系统性偏移时取等号。把分歧平均掉 = 假设共同原因一定对。

**定理 20（团队预算有界性与容错边界）** TBM 的冗余计价 + 拍卖保证单位时间信息动作 ≤B_t（无查询风暴）且存在纯策略均衡；多样性 D、Byzantine 比例 f 下 `ε_team≤g(D,f,k_eff)`，当 `f<(D·N−1)/2` 时可抑制到阈值以下。

## 7. 本轮最大风险

**一句话**：CHORUS-RAS 的全部安全保障押在「能把 ρ 估准」上——一旦相关性被**低估**（共享模型 / 标定 / 数据 / 人类构成一条看不见的共同原因），系统就会把一群相关的回声当成多个独立证词，机器人越多、置信越高、一起错得越自信；**团队规模从安全冗余变成错误放大器**。

**次级风险与缓解**：相关性估计偏差（共同原因结构化分解 + ε_ρ 保守膨胀 + E316）；通信延迟/丢包击穿安全（ask-or-brake + d_max 认证 + 本地 hold/brake）；Byzantine 同伴与共谋（鲁棒聚合 + 主张-错误一致性检测 + 信任更新）；校准分歧导致决策迟滞（仅后验多峰时启用 + 时延预算）；预算机制被博弈（冗余计价 + credit 返还 + 审计）；N=1 退化不严格（定义 327 + E310）。
