# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；本轮灵感：「开放词汇」×「跌倒恢复」）

> R69 的 FLUID-RAS 把不确定性一分为二，并给系统装上了一张嘴：拿不准就去问、去看、去摸。但它有一个从未被检验的隐含前提——**系统还在「正常区」里**：还能减速、还能暂停、还能求救、还有下一次。现实里最危险的一类状态恰恰相反：**已经跌倒了**。在恢复区，R68/R69 那套「不确定就收紧」的铁律不是次优，而是**方向错误**——躺在地上时，最保守的动作（不动）等于放弃；而任何能起身的动作都必然承受局部风险、进入标定与训练分布之外。
>
> 两个灵感正好补上两块：
> - **开放词汇**告诉我们：跌倒与「能扶什么」是**长尾、开放式**的——滑倒、被推、被家具卡住、假肢锁死……无法预先枚举；能跨类别泛化的不是新分类头，而是**语言语义**这个开放索引。系统必须能说出「我从没见过这种东西」，也必须能把没见过的「沙发扶手」当成可借力的支撑。
> - **跌倒恢复**告诉我们：存在一类**风险单调性崩塌**的状态——在这里「少做/不做」的风险严格大于「做一个受控风险动作」的风险。安全不再是「守住正常包络」，而是「在损伤有界的前提下，主动离开失败吸引域」。
>
> 核心命题：**把闭环扩成两区制（nominal / recovery）。正常区严格退化为 FLUID-RAS；恢复区把目标从「最小化即时约束违反」换成「最小化损伤积分 + 起身时间 + 再次跌倒概率」，用开放词汇把长尾跌倒/支撑/地形命名成可检索的语义键，用触觉探针把「看来的支撑」验证成「扛得住的支撑」，并坚持一条架构铁律——语义只负责提议，物理只负责否决（semantics proposes, physics disposes），开放词汇永远不为安全背书。** 命名 **RISE-RAS**（Recovery-aware, open-vocabulary Semantic Estimation for rising from incapacitating states）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**没人可问、而且我已经倒下时，怎么办**」——不确定性不只可以变成问题，也可以变成一次**受控的冒险**。

## 0. 直觉与动机

**灵感 1（开放词汇 → 长尾跌倒无法枚举，语义是唯一可泛化的索引）**
直觉：闭集分类器认识 12 种跌倒，第 13 种就变成「其他」。但恢复恰恰要为「其他」负责。开放词汇（vision-language grounding）给出一个**开放概念集**上的打分函数 s(o,c)，对任意文本概念 c 都能给分——于是「被数据线绊倒」「卡在床与墙之间」「假肢膝关节锁死」这些训练中从未出现的组合，仍可被命名、被聚类、被检索到相近的恢复技能。**语义不是分类，是索引**：它把无限的跌倒映射到有限的、可组合的技能库上。代价是：开放词汇对未见概念天生欠校准，还会受候选标签集影响（同一画面，换个候选表就换个答案）——所以本轮必须把「弃权（abstain）」做成一等公民。

**灵感 2（跌倒恢复 → 风险单调性在恢复区崩塌）**
直觉：R66–R69 的所有安全机制都默认一个单调性：**动作越少、越慢、越保守 ⇒ 风险越低**。这在正常区成立，因为它假设「安全的静止不动」总是可行。可一旦跌倒，这个假设被打破：不动 = 永久失败 + 可能的二次伤害；而起身必然要转移重心、离开支撑、承受冲击。**此时「零风险的不动」的累积代价是无穷大，而「有界风险的起身」的累积代价是有限的。** 这不是调参能救的，是目标函数在该区域换了形状。所以必须显式建模**两区制**，并在恢复区把风险重新定义为「相对当前坏状态的损伤增量」而非「相对名义状态的偏差」。

**灵感 3（安全过滤的不可行性 → 需要恢复安全集）**
直觉：控制屏障函数（CBF）/安全过滤器的教科书前提是「安全集非空、且存在安全动作」。跌倒状态正是这个前提失效的地方：名义约束（保持平衡、避免接触、别撞）在该状态下**无解**，于是安全过滤器要么让系统冻结（deadlock），要么被迫违反约束。正确做法不是删掉约束，而是换一套**恢复不变量**：允许离开名义安全集，但把「头颈不受冲击、关节力矩不超损伤阈、始终有受控支撑或受控下降、任一时刻可中止」作为新的、可验证的安全集 S_rec。**安全的定义随状态改变，但「安全必须是可验证的」这条不变。**

**灵感 4（语义提议、物理否决 → 开放词汇永不为安全背书）**
直觉：开放词汇最危险的地方不是它会错，而是它会**自信地错**：把一块松动的木板叫「稳固台阶」，把一条垂下的电线叫「可抓扶手」。如果恢复动作的安全性依赖这些标签，系统就会被一句幻觉送上二次伤害。架构上的解法是**解耦**：语义只用来*提议*候选技能与候选支撑；真正的执行轨迹交给一个**与标签无关**的物理认证层（力/力矩/头颈净空/支撑/可中止）。即使标签全错，损伤上界仍由物理层守住；标签只影响「恢复得快不快、省不省力」，不影响「安不安全」。这条铁律把开放词汇的校准误差从「安全风险」降级为「效率风险」。

**灵感 5（交互的降级与升级 → 无人可问就自我触探，有人可问则求助但要防社工）**
直觉：R69 的 MINT 假设「可以问人」。跌倒场景里这个假设经常不成立：可能独居、可能人就是致跌原因、可能伤者无法应答。于是交互必须能**降级为自我探询**：用触/力探针轻推候选支撑，测柔顺与滑移，把「看来的支撑」变成「扛得住的支撑」——这恰好是 R69 信息动作 g_probe 在恢复区的自然延续，代价是时间和一点点风险。反过来，若有人在场，交互会**升级**为求助/远程汇报（把开放词汇命名的现场描述成可审计的语言报告），但求助本身有信任与社工程风险，需要沿用 R69 的证据纪律并新增「伤者/旁观者陈述不可单独定案」。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（RISE-RAS 总览与两区制不变式）** RISE-RAS = (RSM, OVG, OSC, RDL, RSS, SRL, SAG, HPV, RCF, RFD, RAS-WM†)。三不变式：
(i) **正常区严格继承**：当 RSM = nominal 时，RISE 逐指令等价于 FLUID-RAS（R69 定义 293）；
(ii) **恢复区损伤有界**：当 RSM = recovery 时，任何执行轨迹必须满足恢复不变量（定义 316），且语义标签不得作为安全的必要条件（定义 327-iii）；
(iii) **可中止性**：恢复区任一时刻存在一个可执行的「受控下降/止损」动作，且其到执行的延迟 ≤ τ_abort。

**定义 311（恢复区判定与迟滞）** 状态被划入失效吸引域 ℬ 的判据为多通道证据：physical_fall = 1[tilt > θ_f ∨ contact_ground = 1 ∨ CoM 越出支撑多边形]；semantic_fall = 1[OVG 以高置信输出 {prone/supine/fallen/stuck} 之一]；flow_fall = 1[R69 FMA 的 a_score 超阈]。进入 recovery 的条件 R_enter = physical_fall ∧ (semantic_fall ∨ flow_fall)（物理为主、语义/似然为辅）；退出 R_exit = upright ∧ 支撑稳定 ∧ 连续 T_up 秒。切换带迟滞与最小驻留时间 τ_dwell，防止抖振。

**定义 312（开放词汇接地 OVG）** 概念空间 𝒞 开放（可随语言动态扩展）。接地器 G_φ 对任意概念文本 c 与观测 o 输出**逐点**得分 s(o,c) = σ(⟨f_φ(o), g_φ(c)⟩/τ)，而非在候选表上做 softmax——逐点定义保证**标签集独立性**（换候选表不改变同一概念的绝对可信度）。候选概念由语言侧按场景生成（如「可借力的家具边缘」「湿滑瓷砖」「垂落的线缆」），但 G 只给逐点分。输出标签集 L(o) = {c : s(o,c) ≥ τ_lab}。

**定义 313（弃权与开集校准 OSC）** 弃权算子 ⊥：若 max_c s(o,c) < τ_abs 或候选集为空，输出 ⊥（「我不知道这是什么」）。OSC 维护按概念/语义邻域的校准：对概念 c，令 d(c) 为到最近已校准概念的语义距离，校准误差上界 ÊCE(c) 关于 d(c) 单调不降。阈值取 τ_abs(c) = min{ t : precision_{s≥t}(c) ≥ 1 − ε_abs }。当 ÊCE(c) > τ_ece 时，禁止该概念参与**任何**非安全相关决策，仅可触发触觉复核。

**定义 314（恢复目标与损伤账本 RDL）** 恢复被建模为半马尔可夫选项（option）：o_rec = (I_o, π_o, β_o)，β_o ∈ {upright, abort, unrecoverable}。恢复价值 V_R(s) = E[∫_0^{τ} γ^t dD_t + γ^τ (R_up·1[upright] − C_abort·1[abort])]，其中损伤率 dD_t = w_1·impact_t + w_2·max(0, |τ_joint|−τ_safe) + w_3·1[head_risk_t]（损伤账本）。策略选 o* = argmax_{o ∈ 𝒪_adm(s)} V_R(s; o)，𝒪_adm 由 RCF（定义 320）保证非空。

**定义 315（风险单调性崩塌与恢复可采风险）** 正常区假设：C(π_cons) ≤ C(π) 对任意 π（保守占优）。定义**恢复可采风险**：在 s ∈ ℬ 上，若 𝒮_nom(s) = ∅ 或「不动作」使系统停留在吸收态，则称该状态下单调性崩塌。此时允许执行 a ∉ 𝒮_nom(s) 但 a ∈ 𝒮_rec(s)（定义 316），并以**损伤增量**而非名义偏差计量风险。形式判据：∃a 使 E[∫ dD|a] + K_fail·P(未起身) < K_fail（保守的失败代价），即受控冒险严格优于不动。

**定义 316（恢复安全集与不变量 RSS）** 𝒮_rec(s) = { a : Φ_dmg(s,a) ≤ D_max, |τ_joint| ≤ τ_inj, head_clearance ≥ h_min, support_condition(s,a) ∈ {受控支撑, 受控下降}, abort_latency(a) ≤ τ_abort }。设计假设 A_rec：对 ℬ 内任意 s，𝒮_rec(s) ≠ ∅；若不满足（真不可恢复），进入 `help/immobilize` 分支而非盲目动作。关键：𝒮_rec 是**标签无关**的纯物理约束——它不引用任何 OVG 标签，因此开放词汇的错误无法污染安全集。

**定义 317（分阶段恢复技能库 SRL）** 恢复分解为可组合阶段（以四足/人形为例）：{brace（撑住）, roll_to_sternal/prone（翻到俯卧）, prop_up（撑起上身）, kneel/squat（跪/蹲）, stand（起立）, stabilize（站稳）}。每个技能 σ_j 是一个闭环运动原语，带前/后置条件（支撑多边形、关节限位、终止判据）。技能以**语义键**索引：κ(σ_j) 为其适用条件的语言描述嵌入。

**定义 318（支撑可借力性接地 SAG）** 对候选支撑体 b（由 OVG 命名），估计可借力性 ℓ(b) = P(可承受载荷 F_r 而不滑移/倾覆)。输出 ℓ 与不确定性；ℓ 高且校准可信才允许「承重式借力」，否则只允许「轻触探询」（定义 319）。SAG 与 OVG 共享编码但**独立校准**：名字对 ≠ 扛得住。

**定义 319（触觉探针复核 HPV：MINT 的恢复区退化）** 信息动作 g_probe 在恢复区的形式化：以递增力 F_1<…<F_m 轻推候选支撑，观测位移/滑移/柔顺，得到后验 ℓ(b)。VoI_probe = H(ℓ) − E[H(ℓ|y)]，成本 c = 时间 + 探询本身风险（≤ ε_probe ≤ ε_d）。无人可问时，这是唯一的「交互」；有人可问时，它与语言问询并联（定义 325）。

**定义 320（恢复认证过滤 RCF）** 扩展 R69 的 C-RAS-WM：对候选技能 σ_j 生成的前缀轨迹做四项认证——(a) 损伤账本上界 Φ_dmg ≤ D_max；(b) 头颈净空 ≥ h_min；(c) 支撑/下降条件；(d) 可中止性（任一时刻存在止损动作且延迟 ≤ τ_abort）。同时施加**不可逆动作门控**：一旦某动作使系统进入不可中止子状态（如无支撑的单腿腾空），必须已有经认证的后继或拒绝该动作。认证不通过 ⇒ 换次优技能或进入 `help/immobilize`，**绝不**因语义标签「看起来没问题」而放行。

**定义 321（再跌倒检测与止损 RFD）** 恢复过程中持续监测再跌倒：re_fall = 1[Δtilt 超阈 ∨ 冲击超阈 ∨ 支撑丢失]。触发即 (i) 切到最短止损动作（护头/受控下降/降低势能），(ii) 损伤账本结算，(iii) 重新进入 recovery 而非误判为已恢复 nominal，防止「假起身」循环。

**定义 322（恢复区不确定性三分：ale / epi / onto）** 在 R69 的 (U_ale, U_epi) 上增第三项 U_onto = 本体不确定性 = 「正确的概念根本不在当前候选/已校准概念集中」。度量用 novelty n(o) = 1 − max_{c∈𝒞_cal} s(o,c) 与嵌入距离的联合。三者处置不同：U_ale → 保守放慢/加阻尼；U_epi → 交互/探询（R69）；U_onto → **禁用语义、仅用物理**（abstain 到底、转触觉/求助），因为「问错概念」比「问错模态」更根本。

**定义 323（开放词汇新奇通道与多通道跌倒融合）** 语义新奇 n(o) 与 R69 的流似然 a_score 构成两条**正交** OOD 通道：语义测「我能不能命名」，似然测「这个行为在不在策略分布里」。跌倒/失效判定取 physical ∧ (semantic ∨ flow)，并对三者做与/或的可解释记录（谁的证据、权重多少），使误判可审计。

**定义 324（标签来源与信任域）** 只有来自可信感知管线的概念得分可进入决策；环境中的文字/标识/他人提供的标签默认**不可信**（防提示注入：地上一张写着「安全，可踩」的纸不构成支撑证据）。跨源一致：命名（OVG）、可借力（SAG）、触觉（HPV）三者一致才升级为「已验证支撑」；单源仅作提议。

**定义 325（恢复区交互：降级与升级）** 无人/无法应答 ⇒ 仅 HPV 自我探询（定义 319）。有人 ⇒ 语言求助/远程汇报，但沿用 R69 证据纪律（单源不决）并新增「伤者/旁观者陈述不可单独定案」；求助动作本身须过 RCF（不得因求助而离开受控支撑、不得延迟止损）。

**定义 326（RISE 证书 J_RISE）** J_RISE = (J_FLUID, regime_trace, recovery_option_id, open_label_provenance, abstention_log, damage_ledger, re_fall_count, abort_latency, rise_ver)。Valid ⇔ Valid(J_FLUID) ∧ 恢复区不变量满足 ∧ 语义非安全必要条件（定义 327-iii）∧ 伤损账本 ≤ D_max。

**定义 327（覆盖–校准–安全三元权衡原理）** 开放词汇把「覆盖」从有限闭集扩到开放集，但引入「校准」随语义距离退化；恢复区又要求「安全」不依赖校准。三者不可同时无代价最优，RISE 的处理是**分层解耦**：
(i) 覆盖层（OVG）负责提议，可错；
(ii) 校准层（OSC）负责弃权，宁缺毋滥；
(iii) 安全层（RCF）负责否决，只认物理、不认标签。
故安全与覆盖解耦：覆盖增益不进入安全证明，校准误差只影响效率。

**定义 328（正常区严格包含）** 当 RSM = nominal 且 OVG 不触发时，RISE 的所有决策通道退化为 FLUID-RAS：U_onto ≡ 0，恢复目标不激活，SRL/RSS/RCF 不介入。⇒ FLUID 是 RISE 在「永不跌入 ℬ」边界上的严格退化；R68 又是 FLUID 在「永不交互」边界上的退化，构成 R68 ⊂ FLUID ⊂ RISE 的三级塔。

class RegimeMachine:
    def step(self, o, z, phys, sem, flo, dt):
        fall  = phys.fallen(o) and (sem.semantic_fall(o) or flo.anomalous(z))
        enter = fall and self.dwell.get('nominal', 1e9) > TAU_DWELL
        exit_ = phys.upright(o) and sem.stable_support(o) and self.t_up > T_UP
        if self.regime == 'nominal' and enter:
            self.regime, self.t_up = 'recovery', 0.0
        if self.regime == 'recovery' and exit_:
            self.regime, self.dwell['nominal'] = 'nominal', 0.0
        return self.regime

# IP-265/266 OVG + OSC：开放词汇接地 + 开集校准弃权
def ground(o, concept_cands, osc):

            if s >= max(osc.tau_abs(c), TAU_LAB) and osc.ece(c) <= TAU_ECE}
    return kept if kept else BOTTOM                                   # ⊥ = 弃权

    return (damage_bound(a_traj) <= D_MAX
            and max_abs_joint_torque(a_traj) <= TAU_INJ
            and head_clearance(a_traj) >= H_MIN
            and support_or_descent(s, a_traj)
            and abort_latency(a_traj) <= TAU_ABORT)      # 不引用任何 OVG 标签

# IP-269/270/271 SRL + SAG + HPV：语义检索、支撑度量、触觉复核
def plan_recovery(s, labels, srl, sag, hpv):
    cands = []
    for sigma in srl.retrieve(labels):                    # 语义键检索，可组合
        if not recovery_admissible(s, sigma.preview(s)):  # 先物理认证
            continue
        for b in sag.supports(labels):
            if sag.loadability(b) < TAU_LOAD:
                continue                                  # 名字对≠扛得住
            ok, d = hpv.verify(b)                         # 承重前先轻触探询
            if ok:
                cands.append((sigma.bind_support(b), d))
    if not cands:
        return HELP_IMMOBILIZE
    return max(cands, key=lambda od: recovery_value(s, od[0]) - od[1])

# IP-276 RISE 主闭环（正常区逐指令走 FLUID；恢复区换目标、语义只提议）
def RISE_round(M, obs):
    z, o = M.mtm.forward(obs)
    flu  = M.fluid_round(z, o)                            # R69 全部逻辑
    regime = M.rsm.step(o, z, M.phys, M.sem, M.flo, M.dt)
    if regime == 'nominal':
        return flu                                       # 严格包含 FLUID-RAS
    # ---- recovery regime ----
    labels = M.ovg.ground(o, M.lang.concepts(o), M.osc)  # 开放词汇 + 弃权
    if labels is BOTTOM:                                 # U_onto 高：禁用语义
        labels = {}                                      # 只用物理/触觉/求助
    option = M.srl.plan(o, labels, M.sag, M.hpv)         # 语义提议 + 物理否决
    if option is HELP_IMMOBILIZE:
        return M.help.request_or_immobilize(o)
    if not M.rcf.certify(option.preview(o)):             # 认证失败 → 次优/求助
        option = M.srl.fallback(o, M.sag)
    traj = option.execute(o)
    if M.rfd.re_fall(traj):                              # 再跌倒 → 止损并重进 recovery
        traj = M.rfd.damage_limiting(o)
    M.damage_ledger.add(option, traj)
    M.vqa.submit_async(regime, labels, option, M.damage_ledger)
    return traj, M.damage_ledger, option

## 3. 推导

**引理 19（风险单调性崩塌）** 在失效吸引域 ℬ 内，若名义安全集 𝒮_nom(s) = ∅ 或保守策略 π_cons 使系统停留于吸收态，则存在恢复策略 π_rise 使 E[C(π_rise)] < C(π_cons)。取 π_rise 以概率 p>0 在时间 T 内起身、期望损伤 D ≤ D_max：E[C(π_rise)] ≤ D_max + (1−p)K_fail；只要 D_max < p·K_fail 即严格优于 C(π_cons) ≥ K_fail。**系：在恢复区，R68/R69 的「不确定就收紧」不再是安全策略，而是失败策略。** 这不是否定保守主义，而是划定它的适用域——保守只对「还能待着」的状态有意义。

**引理 20（开放词汇的覆盖–校准权衡）** 对未见概念 c，令 d(c) 为其到已校准概念集的语义距离。逐点接地 + 邻域校准下，标签可靠度的期望误差上界为 ÊCE(c) = ε_r(d) + δ_abs，其中 ε_r 随 d 单调不降，δ_abs 为弃权带来的覆盖损失。因此开放词汇以「随新奇度增长的校准误差」换取覆盖；不做弃权时，误差可无界（会为任意文本概念给出自信分）。**系：开放词汇必须配弃权，否则覆盖越大、错得越自信。**

**引理 21（弃权门控的语义安全解耦）** 若恢复动作仅由满足 s(o,c) ≥ τ_abs(c) 的概念提议，且执行前必经标签无关的 RCF（定义 316/320）认证，则损伤满足 P(Φ_dmg > D_max) ≤ δ_phys，**与标签正确性无关**；标签错误只改变选中的技能/支撑，从而只影响 V_R（效率），不影响安全上界。这是「语义提议、物理否决」的形式化：安全证明不引用 OVG。

**引理 22（触觉复核把错误支撑的伤害变为可弃权）** 若候选支撑 b 的真实可借力性 ℓ_true < F_r，则递增力探针在加载到 F_r 前以概率 ≥ 1−δ_s 观测到滑移/倾覆信号（A99：探针能测出失效前兆），从而在承重前弃权；额外风险 ≤ ε_probe。系：HPV 把「看错支撑」从灾难性错误降级为「浪费一次探询」——恢复区里，**摸一下比信一眼便宜**。

**引理 23（语义/似然 OOD 通道的正交性）** 若语义新奇 n(o) 与流似然 a_score 的条件分布不退化相关（A100：二者由不同表征与不同数据支撑），则融合检测的漏检率 ≤ 两通道漏检的并集界；语义通道被投毒时，物理+似然通道仍独立报警。故三通道（physical / semantic / flow）应「与/或」记录，而非简单加权平均——**平均会稀释一致证据，也会掩盖单通道被攻破。**

**定理 18（两区制安全与严格包含）** 在 A_rec、A99–A100 下：nominal 区 RISE ≡ FLUID-RAS（定义 328），安全与效率均不退步；recovery 区由引理 19 严格优于保守、由引理 21 得损伤有界、由迟滞 + 最小驻留保证切换有限（无 Zeno）。故 R68 ⊂ FLUID ⊂ RISE，且 RISE 在恢复区的安全上界独立于开放词汇正确性。

**定理 19（恢复的损伤有界与再跌倒上界）** 若每个恢复选项经 RCF 认证且 RFD 可中止，则单次恢复的期望损伤 ≤ D_max；多阶段恢复的起身概率 ≥ ∏_j p_j − P(abort)，再跌倒后的二次损伤 ≤ D_max（因止损动作亦在 𝒮_rec 内）。系：恢复过程是「有界损伤的多次尝试」，而不是「一锤子买卖」——但**次数受限于生理/机械状态，不能假设无限重试**（见第 6 节风险）。

**定理 20（恢复可采风险的占优）** 在 ℬ 内，若存在 a ∈ 𝒮_rec 使 E[∫dD|a] + K_fail·P(未起身) < K_fail，则选择受控冒险的累积代价严格低于任何停留在吸收态的保守策略；且该占优不依赖对 ℬ 形状的精确建模，只需 K_fail 与 D_max 的有界性与大小关系。⇒「有时必须冒险」不是口号，而是一个可检验的不等式条件。

## 6. 本轮最大风险

**一句话**：RISE 把「安全」锁在标签无关的物理不变量上，却把「**选哪个技能、借哪个支撑、值不值得冒险**」交给了开放词汇——而跌倒恢复是**低频、不可逆、无法靠重复试验平均掉误差**的一次性事件：一旦开放词汇在分布外系统性错标（把松动家具叫「稳固支撑」、把「被卡住」叫「可翻身」），系统会用一个**物理上安全、语义上错误**的恢复动作，稳稳地、可认证地、反复地做错；更糟的是「恢复可采风险」这条授权本身意味着**错误不再被保守主义兜底**，而跌倒是「一次机会」。这就是 R69「问错比不问更危险」在恢复区的升级版——**起错，比不起更危险**。

**次级风险与缓解**：
1. **区制误判**（把正常当跌倒 → 无谓冒险；把跌倒当正常 → 冻结死锁）→ 多通道物理为主 + 语义/似然为辅 + 迟滞与最小驻留 + E308 专项；
2. **开放词汇幻觉/欠校准** → 逐点接地 + 开集弃权 + U_onto 触发「禁用语义、仅用物理」 + E301/E302；
3. **语义投毒/提示注入**（环境文字、旁观者误导）→ 标签来源信任域（定义 324）+ 三源一致 + E310；
4. **触觉探询本身致险** → 递增力、探询风险 ≤ ε_probe、探询动作也过 RCF + 引理 22；
5. **恢复不可行被误当可行** → A_rec 校验 𝒮_rec ≠ ∅，否则显式进入 `help/immobilize`，绝不盲目动作；
6. **一次性/低重试** → 损伤账本 + 再跌倒止损 + 把「保守地少试」作为最后兜底，但明确它不保证成功（这是无法用工程完全消除的残余风险，必须如实写入证书 J_RISE）。

**定义 311（区制判定与迟滞）** physical_fall 为主，semantic/flow 为辅；`R_enter = physical ∧ (semantic ∨ flow)`；退出需 upright ∧ 稳定支撑 ∧ 连续 T_up；迟滞 + 最小驻留防抖振。

**定义 312–313（OVG 与 OSC）** 开放概念集上**逐点**打分 `s(o,c)`（非 softmax，保证标签集独立）；低于 `τ_abs` 输出 ⊥；按语义距离 `d(c)` 做开集校准，`ÊCE(c)` 随 d 单调不降。

**定义 314–315（RDL 与单调性崩塌）** 恢复 = 半马尔可夫选项，目标 `V_R = E[∫γ^t dD_t + γ^τ(...)]`；在 ℬ 内若名义安全集为空或不动使系统停留吸收态，则风险单调性崩塌，允许「恢复可采风险」：`E[∫dD|a] + K_fail·P(未起身) < K_fail`。

**定义 316（RSS）** `𝒮_rec = {a : Φ_dmg ≤ D_max, |τ_joint| ≤ τ_inj, head_clearance ≥ h_min, 受控支撑/下降, abort_latency ≤ τ_abort}`；A_rec 要求 `𝒮_rec ≠ ∅`，否则进入 `help/immobilize`。**不引用任何 OVG 标签。**

**定义 317–319（SRL / SAG / HPV）** 分阶段技能以语义键索引；支撑可借力性 `ℓ(b)` 独立校准；触觉探针以递增力验证支撑，`VoI_probe = H(ℓ) − E[H(ℓ|y)]`，探询风险 ≤ ε_probe。

**定义 320–321（RCF 与 RFD）** 恢复认证四项：损伤上界、头颈净空、支撑/下降、可中止性；不可逆动作门控；再跌倒即止损并重进 recovery。

**定义 322–323（不确定性三分与新奇通道）** 在 (U_ale, U_epi) 上增 `U_onto`；U_onto 高 ⇒ 禁用语义、仅用物理。语义新奇 n(o) 与流似然 a_score 正交融合，physical ∧ (semantic ∨ flow)。

**定义 324–325（标签信任域与交互）** 环境文字/他人标签默认不可信；命名+可借力+触觉三源一致才升级为「已验证支撑」。无人 → 仅 HPV；有人 → 求助/远程汇报，但须过 RCF，陈述不单独定案。

**定义 326–328（证书与严格包含）** J_RISE 并入 regime、标签来源、弃权、损伤账本、再跌倒；覆盖/校准/安全三层解耦；normal 区 RISE ≡ FLUID ⇒ R68 ⊂ FLUID ⊂ RISE。

## 3. 关键算法伪代码

```python
# IP-264 RSM：两区制状态机（迟滞 + 最小驻留）
def regime_step(M, o, z):
    fall  = M.phys.fallen(o) and (M.sem.semantic_fall(o) or M.flo.anomalous(z))
    if M.regime == 'nominal' and fall and M.dwell_nominal > TAU_DWELL:
        M.regime, M.t_up = 'recovery', 0.0
    elif M.regime == 'recovery' and M.phys.upright(o) and M.sem.stable(o) and M.t_up > T_UP:
        M.regime, M.dwell_nominal = 'nominal', 0.0
    return M.regime

# IP-265/266 OVG + OSC：逐点接地 + 开集弃权
def ground(o, concept_cands, osc):
    scores = {c: sigmoid(dot(f(o), g(c)) / tau) for c in concept_cands}   # 非 softmax
    kept = {c: s for c, s in scores.items()
            if s >= max(osc.tau_abs(c), TAU_LAB) and osc.ece(c) <= TAU_ECE}
    return kept if kept else BOTTOM                                       # ⊥

# IP-268/320 RSS + RCF：标签无关的恢复认证
def recovery_admissible(s, traj):
    return (damage_bound(traj) <= D_MAX and max_abs_joint_torque(traj) <= TAU_INJ
            and head_clearance(traj) >= H_MIN and support_or_descent(s, traj)
            and abort_latency(traj) <= TAU_ABORT)                         # 不引用 OVG

# IP-269/270/271 SRL + SAG + HPV：语义提议、触觉验证、物理否决
def plan_recovery(s, labels, srl, sag, hpv):
    cands = []
    for sigma in srl.retrieve(labels):                    # 语义键检索，可组合
        if not recovery_admissible(s, sigma.preview(s)):
            continue
        for b in sag.supports(labels):
            if sag.loadability(b) < TAU_LOAD:
                continue                                  # 名字对≠扛得住
            ok, d = hpv.verify(b)                         # 承重前先轻触探询
            if ok:
                cands.append((sigma.bind_support(b), d))
    if not cands:
        return HELP_IMMOBILIZE
    return max(cands, key=lambda od: recovery_value(s, od[0]) - od[1])

# IP-276 RISE 主闭环
def RISE_round(M, obs):
    z, o = M.mtm.forward(obs)
    flu  = M.fluid_round(z, o)                            # R69 全部逻辑
    if regime_step(M, o, z) == 'nominal':
        return flu                                        # 严格包含 FLUID-RAS
    labels = M.ovg.ground(o, M.lang.concepts(o), M.osc)   # 开放词汇 + 弃权
    if labels is BOTTOM:
        labels = {}                                       # U_onto 高：禁用语义
    option = M.srl.plan(o, labels, M.sag, M.hpv)          # 语义提议 + 物理否决
    if option is HELP_IMMOBILIZE:
        return M.help.request_or_immobilize(o)
    if not M.rcf.certify(option.preview(o)):
        option = M.srl.fallback(o, M.sag)                 # 认证失败 → 次优/求助
    traj = option.execute(o)
    if M.rfd.re_fall(traj):                               # 再跌倒 → 止损并重进 recovery
        traj = M.rfd.damage_limiting(o)
    M.damage_ledger.add(option, traj)
    M.vqa.submit_async(M.regime, labels, option, M.damage_ledger)
    return traj, M.damage_ledger, option
```

## 4. 推导

**引理 19（风险单调性崩塌）** 若 `𝒮_nom(s)=∅` 或保守使系统停留吸收态，则存在恢复策略使 `E[C(π_rise)] < C(π_cons)`：`E[C(π_rise)] ≤ D_max + (1−p)K_fail`，只要 `D_max < p·K_fail` 即严格占优。系：恢复区里「不确定就收紧」不是安全策略，而是失败策略——保守只对「还能待着」的状态有意义。

**引理 20（覆盖–校准权衡）** 未见概念 c 的标签误差上界 `ÊCE(c) = ε_r(d(c)) + δ_abs`，`ε_r` 随语义距离单调不降；不弃权时误差可无界。系：开放词汇必须配弃权，否则覆盖越大、错得越自信。

**引理 21（语义安全解耦）** 恢复动作仅由过 `τ_abs` 的概念提议，且执行前必经标签无关 RCF，则 `P(Φ_dmg > D_max) ≤ δ_phys`，**与标签正确性无关**；标签错误只影响效率 V_R，不影响安全上界。

**引理 22（触觉复核降险）** 若真实可借力性 `ℓ_true < F_r`，递增力探针在承重前以概率 ≥ `1−δ_s` 观测到滑移/倾覆前兆并弃权，额外风险 ≤ `ε_probe`。系：恢复区里「摸一下比信一眼便宜」。

**引理 23（OOD 通道正交）** 语义新奇 n(o) 与流似然 a_score 条件分布不退化相关时，融合漏检 ≤ 两通道漏检并集界；语义被投毒时物理+似然仍独立报警。故三通道「与/或」记录，勿简单加权平均。

**定理 18（两区制安全与严格包含）** A_rec、A99–A100 下：normal 区 RISE ≡ FLUID；recovery 区由引理 19 严格优于保守、由引理 21 损伤有界、由迟滞 + 驻留保证无 Zeno。故 `R68 ⊂ FLUID ⊂ RISE`，且恢复区安全上界独立于开放词汇正确性。

**定理 19（损伤有界与再跌倒上界）** 每选项经 RCF 认证且 RFD 可中止 ⇒ 单次恢复期望损伤 ≤ `D_max`；多阶段起身概率 ≥ `∏ p_j − P(abort)`，再跌倒二次损伤 ≤ `D_max`。系：恢复是「有界损伤的多次尝试」，但次数受生理/机械状态限制，不能假设无限重试。

**定理 20（恢复可采风险占优）** ℬ 内若存在 `a ∈ 𝒮_rec` 使 `E[∫dD|a] + K_fail·P(未起身) < K_fail`，则受控冒险的累积代价严格低于任何停留吸收态的保守策略；该占优只需 K_fail 与 D_max 的有界性，不依赖 ℬ 的精确形状。⇒「有时必须冒险」是可检验的不等式。

## 7. 本轮最大风险

**一句话**：RISE 把「安全」锁在标签无关的物理不变量上，却把「**选哪个技能、借哪个支撑、值不值得冒险**」交给了开放词汇——而跌倒恢复是**低频、不可逆、无法靠重复试验平均掉误差**的一次性事件：一旦开放词汇在分布外系统性错标（把松动家具叫「稳固支撑」、把「被卡住」叫「可翻身」），系统会用一个**物理上安全、语义上错误**的恢复动作，稳稳地、可认证地、反复地做错；更糟的是「恢复可采风险」这条授权本身意味着**错误不再被保守主义兜底**，而跌倒是「一次机会」——**起错，比不起更危险**。

**次级风险与缓解**：区制误判（多通道物理为主 + 迟滞/驻留 + E308）；开放词汇幻觉/欠校准（逐点接地 + 开集弃权 + U_onto 触发「禁用语义」 + E301/E302）；语义投毒/提示注入（标签信任域 + 三源一致 + E310）；触觉探询致险（递增力 + 风险 ≤ ε_probe + 探询也过 RCF + 引理 22）；恢复不可行误判可行（A_rec 校验，否则 `help/immobilize`）；一次性/低重试（损伤账本 + 再跌倒止损 + 保守少试兜底，但如实写入 J_RISE，残余风险不可完全消除）。
