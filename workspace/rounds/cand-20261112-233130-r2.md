# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「机器人」×「域随机化」）

> 第 62 轮用 ROSE 把 ESEC 从「静态语义-执行闭环」推进为「学习-鲁棒-场景」的动态闭环：OLP 有遗憾界、WCV/RSC 有偏差免疫、SBR/SHC 有场景课程、Shield 有机制安全。但 ROSE 的自述最大风险是**单点**：整套鲁棒性论证压在 RSC 的残差可观测性上（A72：J_φ 良态、真实偏差体现在残差中）。这一单点又牵出四个结构性盲区：
> 1. **被动观测 ≠ 可辨识**：RSC 只被动等待执行残差。若机器人沿一条使某些物理参数（各向异性摩擦、抓取点刚度、倾覆惯量）不进入接触动力学的轨迹运动，J_φ 在这些方向近乎奇异，r_t 只能覆盖「已被激励的子空间」——「没看见」被误当成「不存在」。
> 2. **点被球包住 ≠ 参数被确定性覆盖**：WCV 用半径 r_t、球心 φ̂_t 的球包住 φ*，但球心是 MEL 点估计、半径是 EWMA 启发式，覆盖只是概率性的（1−α_cal）；最坏 φ 还只靠 16 个随机候选近似（Monte Carlo），既非确定、也可能漏掉真正的顶点。
> 3. **域随机化是离线固定分布**：第 61 轮的训练分布 P_DR 是离线拍定的；部署后机器人**不知道真实域落在分布的哪里**。DR 的「鲁棒」只在未经验证的假设「φ*∈supp(P_DR)」下成立——随机化越猛，越是在为一个不被验证的支撑集买单。
> 4. **机器人自身也是域，且模型可能根本不「像」机器人**：负载、工具、关节磨损、执行器增益漂移都会改变本体动力学 ψ，ROSE 只对世界 φ 建模，把「机器人自己」当成不变的；更严重的是，J_rose 能说「在这个物理模型下安全」，却没有一条能证伪「这个物理模型是不是这台机器人」的证据链。

## 0. 直觉与动机

**灵感 1（机器人 → SP：机器人当自己的实验设计者）**
直觉：与其被动等残差，不如让机器人在安全前提下**主动施加微小探测激励**（dither / probe），主动激发那些平时不进入动力学的参数方向。探测不是瞎抖，而是**实验设计**：用 D-最优准则选择激励，最大化信息矩阵 J^T J 的行列式 / 最小化其条件数——把第 62 轮「J_φ 病态」从被动接受的运气，变成主动设计消除的变量。再用控制屏障函数（CBF）把探针轨迹约束在已验证安全集内。

**灵感 2（域随机化 → CDR：把域随机化「反过来」做）**
直觉：标准 DR 是「先随机化，再祈祷真实域落在支撑集里」。我们反过来做——先用带界噪声下的一致观测构造**认证可行参数集 FPS**（set-membership identification），再让 DR 的分布**只在 FPS 上取支撑**。于是 DR 的核心假设从「φ*∈supp(P_DR)」变成「φ*∈FPS」，而后者由构造确定性保证（在模型类正确时）。随观测增多 FPS 单调收缩，DR 从「盲目大范围随机」变成「围绕真实域的精确定向随机」——保守性随信息量下降。**随机化第一次同时是「稳健化手段」和「辨识手段」。**

**灵感 3（域随机化 → ADR：对抗式域随机化替代 Monte Carlo 最坏情形）**
直觉：WCV 的 n_worst=16 随机候选是「用采样估最坏」。但 FPS 若是多面体，凸损失的最坏情形必在顶点，且线性约束下可由 LP 精确求解。把「均匀撒 16 个点」升级为「在 FPS 内向最痛处定向随机 / 精确取顶点」——域随机化从「均匀随机」变为「对抗随机」，堵住 Monte Carlo 的漏检缝隙。

**灵感 4（机器人 → SDR：机器人把自己也随机化）**
直觉：机器人不只要适应世界，还要适应**自己**。把本体参数 ψ（负载、质心、执行器增益、通信时延）纳入同一个带界辨识框架，用本体感知（关节力矩 / 电流 / 编码器）区分「世界变了」还是「我变了」。联合认证集 FPS^{φ,ψ} 让证书同时覆盖环境与本体。

**灵感 5（合流 → 探针-辨识-随机化正反馈，带安全阀）**
直觉：探针越准，FPS 越小；FPS 越小，CDR 支撑越紧、安全编译越不保守；越不保守，越有性能余量去做更有信息量的探针。这是一个正反馈。但正反馈必须先装安全阀：**探针权限 a_t 随 FPS 收缩而单调放开**（先保守、后激进），并用 CBF 保证每一步探测都在当前已认证安全集内，从而打破「为辨识而冒险」的循环依赖。

**灵感 6（机器人 → SCDR：每个场景一台不同的「机器人」）**
直觉：不同材质 / 地形 / 工具下物理参数不同。全局一个 FPS 会被最坏场景撑大。用 SBR 的场景簇给每个簇维护独立 FPS_c，DR 在簇的并集上按 Hedge 权重混合采样——把「域随机化」从全局单分布升级为**场景条件混合分布**，与第 62 轮的遗憾课程天然咬合。

**灵感 7（合流 → DROID：Domain-Randomized Online Identification & Deployment）**
直觉：DROID = ROSE + [主动安全探针 SP] + [认证可行集 FPS-SMI] + [认证 / 对抗域随机化 CDR-ADR] + [本体随机化 SDR] + [场景条件 DR] + [模型类证伪 MCF]。ROSE 回答「学错时怎么办」；DROID 回答「怎么让『学错』可被发现、可被排除、并主动变小」。一句话：**机器人从「域的被动受害者」变成「域的实验设计者」；域随机化从「离线固定分布」变成「在线认证支撑集」。** 与 ROSE 的接口完全兼容：RSC 不删除，退化为「模型类失效时的兜底 EWMA」；FPS 一旦为空或证伪，系统显式撤销安全声明并回退保守基线。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（DROID 自随机化辨识-部署闭环）**：DROID = (ROSE, SP, FPS-SMI, CDR, ADR, SDR, SCDR, PSG, MCF, FPSA, J_droid)。定位：ROSE 的「可辨识 × 可认证 × 可证伪」升级；所有辨识 / 随机化 / 训练写操作只在语义流与低频线程，实时流零学习写。
- **定义 186（安全探针 SP）**：探针输入 u_probe ∈ 𝒰_safe(FPS_t) 为一段短时激励；𝒰_safe = {u : CBF 离散约束 h(x_{k+1}) ≥ (1−α)h(x_k) 成立 ∧ 接触力 ≤ F_max ∧ 任务进展损失 ≤ ε_task}。
- **定义 187（认证可行参数集 FPS-SMI）**：观测 y_i = g(u_i,φ) + w_i，|w_i| ≤ δ_i。FPS_t = {φ∈Φ : |y_i − g(u_i,φ)| ≤ δ_i, i=1..t}；在局部仿射 g 下为多面体（或 zonotope / 椭球外包），且 φ*∈FPS_t（A77+A78 下确定性，见引理 1）。
- **定义 188（信息最优探针与持续激励）**：u_probe* = argmax_{u∈𝒰_safe} logdet(Σ_i J(u_i)ᵀΣ_w⁻¹J(u_i) + λI)。持续激励条件 A81：λ_min(Σ_{i≤H} J(u_i)ᵀJ(u_i)) ≥ σ_pe² > 0。
- **定义 189（认证域随机化 CDR）**：P_t 为 FPS_t 上的最大熵 / D-最优分布，supp(P_t)=FPS_t。训练目标 E_{φ~P_t}[ℓ(K;φ)]，编译目标 sup_{φ∈FPS_t}CVaR_ε[ℓ]。支撑集随 FPS 收缩，故 DR 保守性单调不增。
- **定义 190（对抗域随机化 ADR）**：FPS 为多面体 {φ:Aφ≤b} 且损失对 φ 凸 / 约束仿射时，最坏 φ*_adv = argmax_{φ∈FPS}ℓ(K;φ) 取于顶点，由 LP / 顶点枚举精确求出；非凸时用分支定界给认证区间 [ℓ_lo,ℓ_hi]。
- **定义 191（本体随机化 SDR 与联合 FPS）**：本体参数 ψ=(负载, 质心, 执行器增益, 时延)；本体感知观测 y^p_i = g^p(u_i,φ,ψ)+w_i。联合集 FPS^{φ,ψ}_t = FPS_t ∩ {ψ : |y^p_i−g^p_i|≤δ_i, ∀i}。
- **定义 192（场景条件 DR / SCDR）**：每簇 c 维护 FPS_c；P_t(φ) = Σ_c w_c·P_{t,c}(φ)，w_c 为 SHC Hedge 权重，supp(P_t)=∪_c FPS_c。
- **定义 193（探针权限调度 PSG）**：a_t = clip(κ_a·(1 − r_t/r_0), a_min, a_max)，r_t = FPS_t 最小包围球半径；a_t 关于 t 单调不减（FPS 单调收缩），激励幅度 δ_u(t)=a_t·δ_{u,max}，由 CBF 逐点验证安全。
- **定义 194（模型类证伪 MCF）**：对留出观测，若不存在 φ∈FPS_t 使其全部落在噪声带内，则 FPS 与数据「不一致」。用 CUSUM 顺序检验：不一致率 > τ 且无参数跳变解释 ⇒ 模型类违规；若短窗重辨识可解释 ⇒ 参数跳变（重置 FPS）。
- **定义 195（FPS 锚点 FPSA）**：Anchor_t = (x_t, φ̂_t, FPS_t 生成元, r_t, R̂_c, version, checksum)；实时流原子读 FPS_t 并直接做最坏情形编译，实时路径仍零学习写。
- **定义 196（DROID 闭环算子与证书 J_droid）**：J_droid = (J_rose, FPS 摘要/体积, r_t, probe_authority, adr_gap, model_class_status∈{OK,PARAM_JUMP,MODEL_CLASS_VIOLATION}, dr_support_ver, self_fps_ver)。Valid ⇔ Valid(J_rose) ∧ φ 一致 ∧ status=OK ∧ probe_safe；status≠OK 时**显式撤销安全声明**并回退保守基线。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# 1) 主动安全探针：在 FPS 内最大化信息量，CBF 保证安全
u_p = argmax_{u∈𝒰_safe(FPS)} logdet(Σ J(u)ᵀΣ_w⁻¹J(u));  a_t = clip(κ_a(1 − r_t/r_0))
# 2) 带界集合辨识：用观测切片收缩 FPS（确定性、单调）
FPS_{t+1} = FPS_t ∩ {φ : |y_t − g(u_t,φ)| ≤ δ_t};  r_t = MinEnclosingBallRadius(FPS_t)
# 3) 认证/对抗域随机化：DR 只落在 FPS 上，最坏情形取顶点
P_t = MaxEnt(FPS_t);  φ_adv = argmax_{φ∈Vert(FPS_t)} CVaR_ε[ℓ(K;φ)]
# 4) 模型类证伪：FPS 解释不了 ≠ 参数漂移，可能是「模型根本不是这台机器人」
status = CUSUM_consistent(FPS_t, heldout);  if status: revoke_certificate()
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（确定性成员）**：A77（带界噪声）+ A78（真实动力学在模型类内）⇒ 对每个真实观测 |y_i−g(u_i,φ*)| ≤ δ_i，故 φ* 满足 FPS_t 的全部切片约束 ⇒ φ*∈FPS_t，且 FPS_{t+1}⊆FPS_t。覆盖从「概率 1−α_cal」升级为「确定性 1」。
- **引理 2（可辨识 / 条件数）**：A81 持续激励下 Σ_{i≤H}J_iᵀJ_i ⪰ σ_pe²I ⇒ J_φ⁺ 范数 ≤ 1/σ_pe、FPS 直径有界；D-最优设计最大化 det(I_H)，从而最小化最坏情形 FPS 体积。第 62 轮「J_φ 病态」单点被主动设计消除。
- **引理 3（r_t 的确定性定义）**：r_t ≜ FPS_t 的最小包围球半径 = max_{φ∈FPS_t}‖φ−φ̂_t‖；因 φ*∈FPS_t ⇒ ‖φ*−φ̂_t‖≤r_t 恒成立。用确定性半径替换 RSC 的 EWMA 半径，覆盖失效不再是隐藏假设。
- **定理 1（CDR 迁移）**：若 φ*∈FPS_t 且 K_safe 对 FPS_t 内全部 φ 安全，则对 φ* 安全（确定性）。保守性用 Vol(FPS_t) 度量，随 t 单调不增。
- **定理 2（ADR 精确性）**：多面体 FPS + 仿射约束下最坏情形在顶点，LP / 顶点枚举精确；凸损失亦取极值点；非凸分支定界给认证上下界。随机 16 点采样在 ε-尾部上漏检概率 ≥ 1−(1−ε)^16，故 ADR 严格占优。
- **定理 3（DROID-Complete）**：在 A61–A76 与 A77–A82 下，覆盖确定性、辨识良态、CDR 迁移、ADR 精确、实时不变均成立；**A78 失效时 MCF 在有限延迟内报警并撤销证书**——安全声明不再可能「静默失效」。
- **证伪命题**：若真实动力学在某个被激励方向上偏离模型类超过噪声带 δ_w，则顺序检验以 ≤β 的虚警率在有限步内检出；若偏离**始终隐藏在噪声带内**，则不可检出——这正是本轮最大风险。

## 2. 形式化定义（完整版）

**定义 185（DROID 闭环）** DROID 在 ROSE 骨架上挂载五个辨识/随机化组件（SP、FPS-SMI、CDR/ADR、SDR、SCDR）与一个安全/审计组件（PSG、MCF）。不变式沿用 ROSE 并加强：**全部辨识、随机化、训练写操作只在语义流与低频线程；实时路径只做 [FPS 锚点原子读 → ADR 取最坏顶点 → WCV/CVaR 编译 → 派发]，零学习写。**

**定义 186（安全探针 SP）** 一次探针为短时激励序列 u_probe=(u_1..u_H)。𝒰_safe 由三项交集定义：① 离散控制屏障约束 h(x_{k+1}) ≥ (1−α)h(x_k)（h 为对 FPS 最坏动态成立的 CBF）；② 接触力 ‖F_k‖∞ ≤ F_max；③ 任务进展损失 ℓ_task(u_probe) ≤ ε_task。探针不得改变任务目标，只提供可辨识信息。

**定义 187（认证可行参数集 FPS-SMI）** 观测方程 y_i = g(u_i,φ)+w_i，噪声仅假设带界 |w_i|≤δ_i（不假设分布）。FPS_t 为所有与观测一致的参数集合。对局部仿射 g(u,φ)=a(u)ᵀφ+c(u)，每条观测贡献两片半空间 aᵀφ≤y−c+δ、−aᵀφ≤−(y−c)+δ，FPS_t 为多面体。非仿射时用区间/zonotope 外包，保持「外近似」语义（宁可保守，不可漏真值）。关键性质：FPS_{t+1}=FPS_t∩S_{t+1}⊆FPS_t。

**定义 188（信息最优探针）** 在 𝒰_safe(FPS_t) 上最大化 Fisher 信息行列式：u* = argmax logdet(I_H+λI)，I_H=Σ_{i≤H}J(u_i)ᵀΣ_w⁻¹J(u_i)。λI 为正则，避免未激励方向的退化。持续激励条件 A81 保证 I_H 一致正定。

**定义 189（认证域随机化 CDR）** P_t 为 FPS_t 上的最大熵分布（多面体用均匀 / Dirichlet 顶点混合；椭球用均匀）。训练 θ←θ−η·E_{φ~P_t}∇ℓ(θ;φ)；编译 K_safe 用 sup_{φ∈FPS_t}CVaR_ε。与标准 DR 的唯一区别是 **supp(P_t) 由认证集决定且随 t 收缩**；因此「DR 鲁棒」的假设从「真实域在离线支撑集内」变为可检验的「φ*∈FPS_t」。

**定义 190（对抗域随机化 ADR）** 对多面体 FPS={φ:Aφ≤b}：若 ℓ(K;φ) 对 φ 凸，则 max 在顶点；若安全约束仿射，则最坏顶点可由 LP（顶点枚举或单纯形）精确求得。非凸时用分支定界给认证上下界 [ℓ_lo,ℓ_hi]，并令 adr_gap=ℓ_hi−ℓ_lo 写入证书；adr_gap>τ_gap 时退回保守基线。ADR 取代 WCV 的 16 点随机候选，把最坏情形从「采样估计」变为「集合内精确/带界」。

**定义 191（本体随机化 SDR）** 本体参数 ψ=(payload, com, k_act, τ_delay)。本体感知观测 y^p_i = g^p(u_i,φ,ψ)+w_i^p（关节力矩、电流、编码器差分）。联合集 FPS^{φ,ψ}_t 同时约束环境与本体；辨识时用「世界-本体可分离性」：一段探针只改变 ψ 的效应（如慢速举起）与只改变 φ 的效应（如不同接触面）交替，避免 φ/ψ 混叠。

**定义 192（场景条件 DR / SCDR）** 场景银行簇 c 维护独立 FPS_c。DR 分布 P_t=Σ_c w_c P_{t,c}，w_c 为 SHC 的 Hedge 权重。采样时按 w_c 选簇、再在 FPS_c 内采样；最坏情形计算对并集取 max（等价于对各簇顶点取 max）。全局 FPS 仅用于安全兜底，避免最坏场景污染所有簇的保守度。

**定义 193（探针权限调度 PSG）** 权限 a_t 随 FPS 收缩单调增加：a_t=clip(κ_a(1−r_t/r_0),a_min,a_max)，r_t 为 FPS 半径。由于 FPS 单调收缩 ⇒ r_t 单调不增 ⇒ a_t 单调不减。每次探针前由 CBF 用 FPS_t 的最坏 φ 验证：探索能走多远由「已经知道多少」决定，而不是由「想学多少」决定。安全阀的不动点：a_min 时的保守 FPS_0 必须已足以保证最小激励安全（A79）。

**定义 194（模型类证伪 MCF）** 留出观测批 {u_j,y_j}（不参与该批 FPS 更新）。一致性判定：∃φ∈FPS_t 使全部 |y_j−g(u_j,φ)|≤δ_j。用 CUSUM 累计不一致率：g_k=max(0,g_{k−1}+(𝟙_ inconsistent−τ))，g_k>h 触发。触发后先尝试用新数据从宽先验**重辨识**：若存在紧集解释 ⇒ status=PARAM_JUMP（重置 FPS）；否则 status=MODEL_CLASS_VIOLATION（撤销 J_droid 的安全声明，回退 K_baseline + RSC 兜底）。虚警率由 h 控制 ≤β。

**定义 195（FPS 锚点 FPSA）** Anchor_t=(x_t,φ̂_t,FPS_t 生成元(A,b 或 zonotope 生成元),r_t,R̂_c,version,checksum)。CAS 原子写（继承 SACP）；实时流读 FPS 生成元后直接在集合上做 ADR 顶点枚举与 WCV 编译，不需要访问语义流。

**定义 196（DROID 闭环算子与证书）** 见伪代码 IP-202。J_droid=(J_rose,FPS 摘要与体积,r_t,a_t,adr_gap,status,dr_support_ver,self_fps_ver)。Valid(J_droid) ⇔ Valid(J_rose) ∧ φ*∈FPS_t（一致性检查）∧ status=OK ∧ probe_safe ∧ adr_gap≤τ_gap ∧ anchor_fresh。**关键设计：status≠OK 时 Valid 直接为 false，且证书里保留「为什么 false」——安全从不静默失效，只会显式降级。**

### IP-193/188 SP（安全探针设计，语义流低频）

```python
class SafeProbeDesigner:
    """在 FPS 上做 D-最优实验设计；只产出激励，不直接改变任务动作。"""
    def __init__(self, cbf, delta_u_max=0.15, horizon=8, lam=1e-3):
        self.cbf, self.H, self.lam = cbf, horizon, lam
        self.delta_u_max = delta_u_max

    def authority(self, fps, kappa_a=2.0, r0=None, a_min=0.05, a_max=1.0):
        r = fps.radius()
        r0 = r0 if r0 is not None else fps.r0
        return float(np.clip(kappa_a * (1.0 - r / max(r0, 1e-9)), a_min, a_max))

    def info_matrix(self, traj, model, sigma_w=1.0):
        I = self.lam * np.eye(model.dim_phi)
        for u in traj:
            J = model.sens_jacobian(u)             # ∂g/∂φ
            I += J.T @ J / (sigma_w ** 2)
        return I

    def design(self, fps, x0, model, n_cand=32, rng=None):
        rng = rng or np.random.default_rng(0)
        a = self.authority(fps)                    # 定义 193：权限随 FPS 收缩放开
        phi_wc = fps.worst_case(lambda p: model.risk(p))
        best_u, best_info = None, -np.inf
        for _ in range(n_cand):
            u = rng.uniform(-1, 1, size=(self.H, model.dim_u)) * a * self.delta_u_max
            traj = model.rollout(x0, u, phi_wc)
            if not self.cbf.certified_safe(traj, fps):   # A79: 逐点 CBF 验证
                continue
            info = np.linalg.slogdet(self.info_matrix(traj, model) + 1e-12*np.eye(model.dim_phi))[1]
            if info > best_info:
                best_u, best_info = u, info
        return best_u, a                          # 无可行探针时返回 None（本轮不探测）
```

### IP-194 FPS-SMI（带界集合辨识，语义流）

```python
class FeasibleParameterSet:
    """多面体外近似 FPS={phi: A phi <= b}；外近似语义：只可更保守，不可漏真值。"""
    def __init__(self, A, b, r0=1.0, eps=1e-9):
        self.A, self.b, self.r0, self.eps = A, b, r0, eps
        self._verts = None

    def update(self, u, y, model, delta):
        a, c = model.affine(u)                    # g(u,phi) ≈ a^T phi + c
        hi, lo = y - c + delta, y - c - delta     # |g - y| <= delta
        A2 = np.vstack([self.A, a[None, :], -a[None, :]])
        b2 = np.concatenate([self.b, [hi, -lo]])
        self._verts = None
        return FeasibleParameterSet(A2, b2, self.r0)

    def empty(self):
        return not feasible(self.A, self.b, self.eps)   # 空集检测（LP）

    def contains(self, phi):
        return bool(np.all(self.A @ phi <= self.b + self.eps))

    def vertices(self):
        if self._verts is None:
            self._verts = enumerate_vertices(self.A, self.b)
        return self._verts

    def radius(self):                             # 确定性 r_t = 最小包围球半径
        V = self.vertices()
        return min_enclosing_ball_radius(V)

    def volume(self):
        return polytope_volume(self.vertices())

    def worst_case(self, loss):
        return max(self.vertices(), key=loss)     # 多面体 + 凸损失：最坏在顶点

    def summary(self):
        return dict(n_constraints=len(self.b), radius=self.radius(),
                    volume=self.volume(), checksum=hash_matrix(self.A, self.b))
```

def cdr_sample(fps, n, rng):
    """supp(P_t)=FPS_t 的近似均匀采样：顶点混合 + 凸组合。"""
    V = np.array(fps.vertices())
    lam = rng.dirichlet(np.ones(len(V)), size=n)
    return lam @ V                                # 落在 FPS 内（凸性）

def adr_worst_case(fps, K, eps=0.05, tau_gap=0.02):
    """多面体顶点精确最坏；非凸时用分支定界给认证上下界。"""
    if fps.is_polytope and loss_is_convex_in_phi:

def joint_fps_update(fps_env, fps_self, u, y_env, y_prop, model, delta_env, delta_prop):
    """交替探针使 φ 与 ψ 可分离：慢速举起（ψ 主导）与多接触面（φ 主导）交替。"""
    fps_env = fps_env.update(u, y_env, model.env, delta_env)
    a_p, c_p = model.self_affine(u, fps_env.center())   # 给定 φ 后对 ψ 仿射
    hi, lo = y_prop - c_p + delta_prop, y_prop - c_p - delta_prop
    A2 = np.vstack([fps_self.A, a_p[None, :], -a_p[None, :]])
    b2 = np.concatenate([fps_self.b, [hi, -lo]])
    return fps_env, FeasibleParameterSet(A2, b2, fps_self.r0)
```

class SceneConditionalDR:

class ModelClassFalsifier:
    def __init__(self, tau=0.2, h=5.0, beta=0.01, reset_window=20):
        self.tau, self.h, self.beta = tau, h, beta
        self.g = 0.0
        self.reset_window = reset_window

    def _explained(self, fps, u, y, model, delta):
        # 存在 phi in FPS 使 |y - g(u,phi)| <= delta
        lo = min(model.g(u, phi) for phi in fps.vertices())
        hi = max(model.g(u, phi) for phi in fps.vertices())
        if model.g_monotone_ok:                  # 顶点极值包围全部取值（线性时精确）
            return (lo - delta) <= y <= (hi + delta)
        return fps.intersects_slab(model, u, y, delta)

    def test(self, fps, heldout, model, dt):
        bad = sum(not self._explained(fps, u, y, model, d)
                  for (u, y, d) in heldout) / max(len(heldout), 1)
        self.g = max(0.0, self.g + (bad - self.tau))
        if self.g <= self.h:
            return 'OK'
        # 先区分「参数跳变」与「模型类错」：用短窗从宽先验重辨识
        fresh = reidentify(heldout[-self.reset_window:], model)
        if fresh is not None and not fresh.empty():
            self.g = 0.0
            return 'PARAM_JUMP'                  # 重置 FPS，安全声明可恢复
        return 'MODEL_CLASS_VIOLATION'           # 撤销安全声明，回退 K_baseline
```

## 4. 推导

**引理 1（确定性成员 / 覆盖）** 设 A77（|w_i|≤δ_i 对每个真实观测成立）与 A78（g(·,·) 正确刻画真实动力学，φ*∈Φ）。则对每个用于辨识的观测，|y_i−g(u_i,φ*)|=|w_i|≤δ_i，故 φ* 满足 FPS_t 定义中的每一条切片约束，即 φ*∈FPS_t。又 FPS_{t+1}=FPS_t∩S_{t+1}，故单调收缩。于是 P[φ*∈FPS_t]=1，覆盖不需要 α_cal。∎

**引理 2（可辨识性与条件数）** 探针序列满足 A81：I_H=Σ_{i≤H}J_iᵀΣ_w⁻¹J_i ⪰ σ_pe²I（Σ_w=I 归一化时）。则对仿射 g，FPS 在任何方向上的宽度 ≤ 2δ_max√(aᵀ(σ_pe²I)⁻¹a) ≤ 2δ_max‖a‖/σ_pe，故直径有界；伪逆满足 ‖J_φ⁺‖ ≤ 1/σ_min(J) ≤ 1/σ_pe。D-最优目标 logdet(I_H) 关于 I_H 单调增，最大化它等价于在可行激励集内最小化最坏方向上的 FPS 体积（Hadamard 不等式下界）。因此第 62 轮「J_φ 病态 ⇒ r_t 低估」不再是运气，而是被探针设计的优化目标直接压制。∎

**引理 3（确定性半径）** 定义 r_t=max_{φ∈FPS_t}‖φ−φ̂_t‖（最小包围球半径）。由引理 1，φ*∈FPS_t，故 ‖φ*−φ̂_t‖≤r_t 恒成立。ROSE 的 RSC 半径 r_t^{EWMA} 只是在「残差可观测且噪声次高斯」下的估计；FPS 半径是在「A77+A78」下的确定性上界。二者可在 OK 状态下互为监控：若 r_t^{EWMA} 持续小于 r_t^{FPS}，说明 RSC 低估，报警。∎

**引理 4（探针安全的不动点）** 设 FPS_0 由先验/数据手册给出且满足 A79（在 a_min 激励下 CBF 对 FPS_0 最坏动态可证安全）。归纳：每步探针在 FPS_t 最坏 φ 下经 CBF 验证 ⇒ 轨迹进入安全集；FPS_{t+1}⊆FPS_t ⇒ 最坏情形只会变轻 ⇒ 下一步可证范围不缩。故全程安全，且 a_t 单调放开。循环依赖（要安全需知 FPS、要知 FPS 需探针）由「保守 FPS_0 + 单调放开」打破。∎

**定理 1（认证 DR 迁移）** 若 (i) φ*∈FPS_t（引理 1），(ii) K_safe=argmin_K sup_{φ∈FPS_t}CVaR_ε[ℓ(K;φ)] 且对 ∀φ∈FPS_t 满足安全约束，则 K_safe 对 φ* 满足安全约束——确定性，无概率项。保守性：Vol(FPS_{t+1})≤Vol(FPS_t)，且 P_{t+1} 的支撑更紧，故存在最优 K 的可行域单调扩大（或至少不缩）。这就是「认证域随机化」相对固定 DR 的全部收益来源。∎

**定理 2（ADR 精确性与占优）** 设 FPS={φ:Aφ≤b} 为有界多面体，ℓ(K;·) 凸。凸函数在多面体上的最大值在某一顶点取得，故 max_{φ∈FPS}ℓ(K;φ)=max_{v∈Vert(FPS)}ℓ(K;v)；对 CVaR（凸且关于样本逐点凸），同理。顶点枚举 / LP 给出精确值，adr_gap=0。对照 WCV 的 n=16 独立随机采样：若最坏 ε-尾部集合测度为 ε，则漏采概率为 (1−ε)^16；ε=0.05 时约 0.44，即近一半周期完全没碰到尾部。ADR 严格消除该漏检。∎

**定理 3（DROID-Complete）** 在 A61–A76（ROSE 继承）与下 A77–A82 下：
1. 覆盖确定性：A77+A78 ⇒ φ*∈FPS_t，∀t（引理 1），覆盖概率 1；
2. 辨识良态：A79+A81 ⇒ r_t 有界、J_φ⁺ 有界（引理 2/3）；
3. 认证迁移：φ*∈FPS_t 且对 FPS_t 编译 ⇒ 对 φ* 安全（定理 1）；
4. 对抗精确：多面体 + 凸损失 ⇒ 最坏在顶点，ADR 精确（定理 2）；
5. 探测安全：A79 ⇒ 探针轨迹恒在安全集，权限单调（引理 4）；
6. 诚实失败：A78 失效且偏离可观测 ⇒ MCF 在有限延迟内报 MODEL_CLASS_VIOLATION，J_droid.Valid=false 并回退基线；偏离不可观测（落在噪声带内）⇒ 不可检出（见风险节）；
7. 实时不变：实时路径零学习写，≤1ms 与锚点新鲜度契约保持（A82）。∎

**命题（证伪延迟 / 虚警）** 设每步「不一致」指示变量在模型类失效后以概率 p_bad≥τ+Δ 取 1。CUSUM 在漂移 Δ 下的平均检测延迟 ≈ h/Δ，虚警率随 h 指数下降（≤e^{−c h}）。因此给定 β 可反解 h，得到有限 T_falsify。该界说明：证伪能力取决于「离群信号是否超过噪声带」，而非探针数量——这再次指向本轮最大风险。∎

**命题（本体-环境可分离）** 若两类探针的信息矩阵在 (φ,ψ) 联合空间中的列空间近似正交（交替激励设计），则联合 FPS 的直径满足 d²(FPS^{φ,ψ}) ≲ d²(FPS^φ)+d²(FPS^ψ)，φ 与 ψ 的估计误差不相互放大。若可分离性差（如只有慢速举起无法区分负载与摩擦），联合集沿耦合方向变长——此时 SDR 只会让证书更保守，不会更危险（外近似语义）。∎

## 7. 已知风险

**一句话**：FPS 是「假设模型类」的外近似而非「真实机器人」的外近似——若真实接触动力学含未建模的回滞、齿隙、摩擦各向异性或执行器饱和，而其对可观测量的一阶影响始终小于噪声带 δ_w，则主动探针只是在收紧一个错误集合，MCF 也永远等不到「不一致」的证据，整套确定性证书会以「已被认证」的姿态静默地保护一台并不存在的机器人。

**次级风险与缓解**：
1. **噪声带 δ_w 低估**：若 δ_w 设小，FPS 可能不含 φ* 或为空。→ 用残差经验分位数做保守上界，并在 FPS 频繁空集时自动放大 δ_w 重辨识；空集本身触发 MCF。
2. **探针与任务冲突**：主动激励可能降低任务进度或磨损接触面。→ PSG 的 ε_task 预算 + 按集群遗憾分配探针预算（SHC）；任务关键窗口禁止探针。
3. **高维 FPS 顶点爆炸**：d_φ>12 时顶点枚举指数增长。→ 用 zonotope / 椭球外包 + 支持函数优化（O(d) 在线性目标下），ADR 用 LP 而非顶点枚举。
4. **φ/ψ 混叠**：本体参数与环境参数在部分探针下不可分离。→ 交替可分离探针 + 若联合集沿耦合方向持续变长则显式标记 ambiguity（证书降级，而非假装可分离）。
5. **CDR 与 OLP/MEL-OA 双学习耦合**：分布随 FPS 移动，在线学习目标非平稳。→ 复用 ROSE 奇偶步交替 + FPS 版本固定时快照训练目标；dr_support_ver 变化过快时冻结 OLP 一步。
6. **证伪虚警导致抖动**：PARAM_JUMP 与 MODEL_CLASS_VIOLATION 误判。→ CUSUM 滞回 + 重辨识确认 + 状态需连续 k 次才切换；证书保留 status 历史供审计。
