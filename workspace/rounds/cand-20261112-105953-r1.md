# 第 61 轮（承接第 60 轮 IP-153~160；灵感循环第 7 轮；本轮灵感：「数据配比」×「预训练」）

> 第 60 轮把闭环升级为「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的认知驱动场景落地（SSM×CIEC×EPIR×SERC×PCE++++）。但**三个更深的局限**被暴露：
> 1. **先验来源不可见**：π_scene(K|z) 与 ϕ_intent→constraint(I) 在第 60 轮被当作「给定」，但真实机器人没有无限场景数据；这些先验其实是从**真实遥操作、仿真、对话日志、失败回放**等异质数据中预训练出来的，其可信度取决于「喂了什么、各喂多少」。
> 2. **数据配比的隐式偏置**：如果预训练语料 80% 是平滑桌面、湿滑楼梯只占 2%，则 SSM 在湿滑场景上的先验又窄又错——Kalman 后验仍会给出高置信度，因为置信度只反映**观测一致性**，不反映**数据支持度**。这是「高置信的错误先验」。
> 3. **先验强度与证据强度混淆**：第 60 轮的 SIC 用 scene_conf 与 K_certainty 做门槛，却没区分「数据多所以确定」和「数据少但噪声小所以确定」；后者在分布外场景会系统性高估安全。

## 0. 直觉与动机

**灵感 1（数据配比 → 先验强度即数据支持度 DML）**
直觉：预训练数据配方 r=(w,τ,s,m) 不是训练细节，而是**先验的有效样本量**。同样一个湿滑场景，配方占比 15%、样本 2000 条，与占比 2%、样本 50 条，得到的先验协方差天差地别。关键洞见：**先验精度 γ 应与该场景的 Kish 有效样本量 n_eff(z) 成正比，而不是与训练轮数或损失下降成正比**——数据没覆盖的场景，模型再「自信」也只是过拟合。

**灵感 2（预训练溯源 → 先验溯证 PPT）**
直觉：每个派发给执行层的 K_safe 都应先问「你从哪来」：用了哪版配方、该场景有效样本多少、覆盖率多少、校准误差多少、OOD 距离多少。把这张「出生证明」随 K_safe 一起下发，使 EEIS 能在**先验不可信**时拒绝收窄边界，而不是盲目相信一个高置信先验。

**灵感 3（配比再平衡 → 执行残差驱动的 DCR）**
直觉：执行不是配方的终点，而是**配方的检验器**。CLEP 闭环产生的 K_obs 与先验 μ_r(z) 的残差 e=K_obs−μ_r(z)，若在湿滑场景系统性偏大，说明配方里湿滑数据不足，应提高湿滑数据权重并触发增量再训练/再校准；若残差只是零均值噪声，则不应动配方。关键洞见：**用「残差是否系统性」区分数据缺口与随机误差**。

**灵感 4（负迁移防护 → 熔断式配方更新 NTS）**
直觉：再平衡最危险的失败不是「没学好」，而是「学新忘旧」：把湿滑权重调高后，桌面先验被冲淡，原本稳定的抓取开始打滑。因此配方更新必须带**KL 锚 + 保留集验证**：新配方相对旧配方的偏移有上限，且在守护场景集 Z_guard 上不得劣化超过 ε，否则熔断回滚。

**灵感 5（数据预算 → PCE+++++）**
直觉：第 60 轮的认知预算 B_scene/B_intent/B_ros/B_exec 还应加入 **B_data = (B_storage, B_replay, B_retrain, B_label)**。再平衡不是免费的：存储回放数据、重训先验、人工标注都消耗预算。若 B_replay 耗尽 ⇒ 冻结配方只做在线校准；若 B_retrain 耗尽 ⇒ 用贝叶斯后验更新代替重训；若 B_storage 耗尽 ⇒ 只保留「高残差 + 关键场景」样本。

**灵感 6（合流 → 配方感知闭环 PREC）**
直觉：把上面串成双时间尺度闭环：**慢时间尺度**用配方 r 预训练 π_scene 与 ϕ；**快时间尺度**执行 SERC 并用 DDR 收集残差；残差累积到阈值后，DCR 在 KL 锚与 NTS 护栏下更新配方，再回到慢尺度。数据配比从「一次性训练超参」变成**可审计、可回滚、由执行证据驱动的状态变量**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（预训练数据配方台账 DML）** 台账 D = {(d_i, n_i, w_i, τ_i, s_i, m_i)}_{i=1}^{M}，其中 d_i 为数据分片，n_i 为样本数，w_i∈[0,1] 为配比权重且 Σw_i=1，τ_i∈{scene_recognize, intent_map, impedance_regress} 为预训练任务，s_i⊆Z_scene 为该分片覆盖的场景，m_i∈{real_teleop, sim, dialogue, failure_replay} 为模态来源。配方 r=(w,τ,s,m)。定义：
- **场景覆盖率**：cov(z;r) = Σ_{i: z∈s_i} w_i
- **Kish 有效样本量**：n_eff(z;r) = (Σ_{i:z∈s_i} w_i·n_i)² / (Σ_{i:z∈s_i} w_i²·n_i)，分母为 0 时取 0
- **关键支持条件**：supp(z;r) ⇔ n_eff(z;r) ≥ n_min ∧ cov(z;r) ≥ c_min
台账的意义是把「训练细节」提升为**可查询的一等状态**：任意先验都可追溯到具体分片、权重与覆盖。

**定义 162（配方感知先验 CPP）** 给定配方 r，场景-阻抗先验与意图映射为：
- π_scene(K|z;r) = N(K; μ_r(z), Σ_r(z)/γ(n_eff(z;r)))，其中 γ(n)=max(1, n/n₀) 为精度增益
- K_safe^scene(z;r) = {K | (K−μ_r(z))ᵀΣ_r(z)⁻¹(K−μ_r(z)) ≤ χ²_{1−α}(n_eff)} ∩ K_safe_base
- ϕ_r: I→C_intent，其支持集 S_I(r) 记录每个意图在配方中出现的样本量
关键约束：**α 随 n_eff 单调收紧，但置信椭球半径不得小于数据支持所能保证的下界**——即先验精度只能由数据「挣来」，不能由优化器「声称」。

**定义 163（预训练溯源证书 PPT）** 每个候选阻抗携带证书 Cert_data(z,K) = (r_hash, n_eff(z;r), cov(z;r), OOD(z), ECE(z), n_train)。有效性判定：
```
PPT_valid = supp(z;r) ∧ OOD(z) ≤ τ_ood ∧ ECE(z) ≤ τ_ece
```
若 PPT_valid=false，EEIS **禁止**把 K_safe 收窄到通用先验 π_general 之外；证书随 J_exec 一并入账，形成「先验可审计」。

**定义 164（数据-执行残差 DDR）** 第 t 次闭环的执行残差 e_t = K_obs,t − μ_r(z_t)。对场景 z 的最近 m 次样本定义：
- 系统偏差 E(z) = (1/m)Σ e_t
- 偏置显著性 B_stat(z) = ‖E(z)‖ / (σ_r(z)/√m)（Hotelling 型 z 分数）
- **数据缺口指示**：I_gap(z) = 1[ B_stat(z) ≥ κ ∧ m ≥ m_min ]
只有当残差**系统性偏置**时才判为数据缺口；零均值大方差只触发「提高观测频次」而非「改配方」。

**定义 165（配比再平衡 DCR）** 给定残差历史与数据预算，配方更新为约束优化：
```
w' = argmin_w  E_{z~p_task}[ D⁺(z; w) ]
              + λ_KL·KL(w ‖ w_anchor)
              + λ_c·Σ_{z∈Z_critical} max(0, c_min − cov(z;w))
     s.t.  C_data(w) ≤ B_data,  Σ_i w_i = 1,  w_i ≥ 0
```
其中 D⁺(z;w) 是配方 w 下该场景的期望证据分歧，w_anchor 为上一版配方。采用投影指数梯度增量更新（避免全量重训）：
```
w_i ← w_i · exp(−η·ℓ_i(z))；投影到单纯形；回滚超预算/违反支持的权重
```
关键：**再平衡是「增量调权 + 触发式重校准」，不是每轮全量预训练**。

**定义 166（配方感知闭环 PREC）** 双时间尺度算子：
```
慢尺度（Offline / 低频繁）:
  ① r ← DCR(r, DDR_history)                    # 配方再平衡
  ② π_r, ϕ_r ← Pretrain(D, r)                  # 按配方预训练先验
  ③ Cert_data ← PPT.build(r, π_r, ECE, OOD)
快尺度（Online / 每闭环）:
  ④ (z, K_safe, EV_exec, status) ← SERC(M, scene, intent, δ_f; π_r, ϕ_r)
  ⑤ DDR.update(EV_exec, π_r)                    # 收集残差
  ⑥ if I_gap(z): 标记 z 为优先采样场景（主动标注），而非立即改权
返回 (r, π_r, Cert_data, EV_exec, S_local.status)
```

**定义 167（数据预算 B_data 与 PCE+++++）** B_data = (B_storage, B_replay, B_retrain, B_label)，成本：
```
cost_data(π) = λ_s·Storage(π) + λ_r·Replay(π) + λ_t·Retrain(π) + λ_l·Label(π)
voi_data(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_data(π)
```
降级链：B_label 耗尽 ⇒ 只用自监督残差；B_retrain 耗尽 ⇒ 冻结配方、仅在线贝叶斯校准；B_replay 耗尽 ⇒ 只回放「高残差+关键场景」；B_storage 耗尽 ⇒ 先丢低残差冗余样本。

**定义 168（负迁移护栏 NTS）** 配方从 w_anchor 更新到 w' 的采纳条件：
```
NTS_accept(w') = KL(w'‖w_anchor) ≤ δ_KL
              ∧ ∀z∈Z_guard:   D⁺(z;w') ≤ D⁺(z;w_anchor) + ε_f
              ∧ ∀z∈Z_guard:   ViolRate(z;w') ≤ ViolRate(z;w_anchor) + ε_s
              ∧ ∀z∈Z_critical: supp(z;w')
```
任一不满足即熔断回滚，并把失败场景加入**优先采样队列**。注意：不能用「失败场景权重直接拉满」来修复，那会引入新的负迁移；正确动作是「加数据、验证、限幅更新」。

## 2. 关键算法伪代码

### IP-161 DML（数据配方台账）

```python
class DataMixtureLedger:
    def __init__(self, shards):
        self.shards = shards          # [{id, n, w, task, scenes, modality}]
        self.version = 0

    def coverage(self, z):
        return sum(s['w'] for s in self.shards if z in s['scenes'])

    def n_eff(self, z):
        num = sum(s['w'] * s['n'] for s in self.shards if z in s['scenes'])
        den = sum(s['w'] ** 2 * s['n'] for s in self.shards if z in s['scenes'])
        return 0.0 if den == 0 else (num ** 2) / den

    def supported(self, z, n_min=200, c_min=0.05):
        return self.n_eff(z) >= n_min and self.coverage(z) >= c_min
```

### IP-162 CPP（配方感知先验）

```python
class MixtureAwarePrior:
    def __init__(self, ledger, mu, sigma, n0=200):
        self.ledger, self.mu, self.sigma, self.n0 = ledger, mu, sigma, n0

    def gamma(self, z):
        return max(1.0, self.ledger.n_eff(z) / self.n0)

    def get(self, z):
        g = self.gamma(z)
        cov = self.sigma[z] / g           # 数据越多，先验越窄
        return {'mu': self.mu[z], 'cov': cov,
                'n_eff': self.ledger.n_eff(z),
                'supported': self.ledger.supported(z)}

    def safe_ellipsoid(self, z, chi2):
        p = self.get(z)
        return {'mu': p['mu'], 'cov': p['cov'], 'chi2': chi2,
                'tighten_allowed': p['supported']}   # 未支持场景禁止收窄
```

### IP-163 PPT（预训练溯源证书）

```python
class PretrainProvenance:
    def build(self, recipe_hash, prior, ece, ood):
        return {'r_hash': recipe_hash,
                'n_eff': prior['n_eff'],
                'cov': self.ledger.coverage(prior['scene']),
                'OOD': ood, 'ECE': ece}

    def valid(self, cert, tau_ood=3.0, tau_ece=0.05):
        return (cert['n_eff'] >= 200 and cert['cov'] >= 0.05
                and cert['OOD'] <= tau_ood and cert['ECE'] <= tau_ece)
```

### IP-164 DDR（数据-执行残差）

```python
class DataExecutionResidual:
    def __init__(self, window=30):
        self.buf = defaultdict(lambda: deque(maxlen=window))

    def update(self, z, k_obs, mu_r, sigma_r):
        self.buf[z].append(k_obs - mu_r)

    def gap_indicator(self, z, kappa=2.0, m_min=10):
        es = self.buf[z]
        if len(es) < m_min:
            return False, 0.0
        m = len(es)
        bias = np.mean(es, axis=0)
        stat = np.linalg.norm(bias) / (np.linalg.norm(sigma_r[z]) / np.sqrt(m))
        return stat >= kappa, stat
```

### IP-165 DCR（配比再平衡，投影指数梯度）

```python
def rebalance_recipe(ledger, ddr, task_weights, anchor, budget, eta=0.05):
    w = np.array([s['w'] for s in ledger.shards], dtype=float)
    loss = np.array([expected_dplus(s['scenes'], ddr) for s in ledger.shards])
    w = w * np.exp(-eta * loss)
    w = project_simplex(w)
    for i, s in enumerate(ledger.shards):        # 支持度护栏
        if ledger.n_eff_for(s, w) < N_MIN:
            w[i] = min(w[i], anchor[i] * 1.5)    # 限幅，避免权重拉满
    if cost_data(w) > budget:
        w = project_onto_budget(w, budget)
    return w
```

### IP-166 PREC（配方感知闭环）

```python
def pretrain_recipe_evolution_loop(M, scene, intent, delta_f_req):
    r = M.recipe
    if M.slow_tick_due():
        r = rebalance_recipe(M.ledger, M.ddr, M.task_weights,
                             M.anchor_recipe, M.budget.data)
        if not nts_accept(r, M.anchor_recipe, M.guard_suite):
            r = M.anchor_recipe                 # 熔断回滚
        M.prior = Pretrain(M.ledger, r, M.n0)
        M.cert_data = M.ppt.build(hash_recipe(r), M.prior, M.ece, M.ood)

    M, fused, D_plus, ev, status = scenario_perception_evolution_loop(
        M, scene, intent, delta_f_req,
        prior=M.prior, intent_map=M.phi_r)

    M.ddr.update(status.scene, status.K_obs, M.prior.mu[status.scene],
                 M.prior.sigma[status.scene])
    is_gap, stat = M.ddr.gap_indicator(status.scene)
    if is_gap:
        M.active_label_queue.push(status.scene, stat)
    return M, r, M.cert_data, ev, stat
```

### IP-167 DataBudget（数据预算）

```python
class DataBudget:
    def __init__(self, storage=1e9, replay=1e5, retrain=5, label=1e3):
        self.B = {'storage': storage, 'replay': replay,
                  'retrain': retrain, 'label': label}
        self.used = {k: 0 for k in self.B}

    def spend(self, kind, amount):
        if self.used[kind] + amount > self.B[kind]:
            return False
        self.used[kind] += amount
        return True

    def fallback_mode(self):
        if self.used['retrain'] >= self.B['retrain']:
            return 'freeze_recipe_online_calibrate'
        if self.used['replay'] >= self.B['replay']:
            return 'replay_critical_only'
        return 'normal'
```

### IP-168 NTS（负迁移熔断）

```python
def nts_accept(w_new, w_anchor, guard_suite, delta_kl=0.1,
               eps_f=0.02, eps_s=0.01):
    if kl_div(w_new, w_anchor) > delta_kl:
        return False
    for z in guard_suite.scenes:
        if dplus(z, w_new) > dplus(z, w_anchor) + eps_f:
            return False
        if viol_rate(z, w_new) > viol_rate(z, w_anchor) + eps_s:
            return False
    return all(ledger.supported(z, w_new) for z in guard_suite.critical)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DML | O(M) 查询/场景 | O(M) | 覆盖率与 n_eff 可审计，权重归一 |
| CPP | O(d²) 先验构造 | O(N·d²) | 先验精度随 n_eff 单调；未支持场景禁止收窄 |
| PPT | O(1) 证书组装 | O(1) | 证书可回溯到配方哈希 |
| DDR | O(d) 更新/闭环 | O(N·m) | 仅系统性偏置触发数据缺口 |
| DCR | O(M·N) / 再平衡 | O(M) | KL 锚 + 单纯形投影保证偏移有界 |
| PREC | 快尺度 O(SERC)，慢尺度 O(M·N) | 复用 | 双时间尺度解耦，慢尺度不阻塞执行 |
| NTS | O(|Z_guard|) | O(1) | 负迁移采纳拒绝 |

**正确性定理（DRPC）**：假设 A66–A70 成立：
- **(A66)** DML 完整：所有进入预训练的数据分片均登记，权重归一。
- **(A67)** CPP 校准：在 n_eff(z) ≥ n_min 的支持场景上，先验的 1−α 置信椭球覆盖真实阻抗的概率 ≥ 1−α−δ_cal；未支持场景不回退为「高置信」。
- **(A68)** DDR 判别：系统偏置与零均值噪声可区分，误报率 ≤ δ_fa。
- **(A69)** DCR 有界：每次再平衡满足 KL(w'‖w_anchor) ≤ δ_KL，且数据预算不超支。
- **(A70)** NTS 保序：采纳的配方在 Z_guard 上 D⁺ 与违规率不劣化超过 (ε_f, ε_s)。

则：
1. **先验可信性**：PPT_valid=false 的 K_safe 不得越过通用先验边界，杜绝「高置信错误先验」直接下发。
2. **数据-执行一致性**：若存在持续数据缺口，DDR 在有限闭环内检出并触发主动采样；若无系统性残差，配方保持稳定（不因噪声抖动）。
3. **再平衡安全性**：任何被采纳的配方都满足 KL 上界与守护场景不劣化；否则熔断回滚。
4. **预算可终止**：B_data 单调消耗，任一维度耗尽即进入对应降级模式，闭环仍可运行。

## 5. 本轮最大风险

## 2. 关键算法伪代码

### IP-161 DML（数据配方台账）

```python
class DataMixtureLedger:
    def __init__(self, shards):
        self.shards = shards          # [{id, n, w, task, scenes, modality}]
        self.version = 0

    def coverage(self, z):
        return sum(s['w'] for s in self.shards if z in s['scenes'])

    def n_eff(self, z):
        num = sum(s['w'] * s['n'] for s in self.shards if z in s['scenes'])
        den = sum(s['w'] ** 2 * s['n'] for s in self.shards if z in s['scenes'])
        return 0.0 if den == 0 else (num ** 2) / den

    def supported(self, z, n_min=200, c_min=0.05):
        return self.n_eff(z) >= n_min and self.coverage(z) >= c_min
```

### IP-162 CPP（配方感知先验）

```python
class MixtureAwarePrior:
    def __init__(self, ledger, mu, sigma, n0=200):
        self.ledger, self.mu, self.sigma, self.n0 = ledger, mu, sigma, n0

    def gamma(self, z):
        return max(1.0, self.ledger.n_eff(z) / self.n0)

    def get(self, z):
        g = self.gamma(z)
        cov = self.sigma[z] / g           # 数据越多，先验越窄
        return {'mu': self.mu[z], 'cov': cov,
                'n_eff': self.ledger.n_eff(z),
                'supported': self.ledger.supported(z)}

    def safe_ellipsoid(self, z, chi2):
        p = self.get(z)
        return {'mu': p['mu'], 'cov': p['cov'], 'chi2': chi2,
                'tighten_allowed': p['supported']}   # 未支持场景禁止收窄
```

### IP-163 PPT（预训练溯源证书）

```python
class PretrainProvenance:
    def build(self, ledger, recipe_hash, scene, ece, ood, prior):

                'scene': scene,
                'n_eff': prior['n_eff'],
```

### IP-164 DDR（数据-执行残差）

```python
class DataExecutionResidual:
    def __init__(self, window=30):
        self.buf = defaultdict(lambda: deque(maxlen=window))

    def update(self, z, k_obs, mu_r, sigma_r):
        self.buf[z].append(k_obs - mu_r)

    def gap_indicator(self, z, sigma_r, kappa=2.0, m_min=10):
        es = self.buf[z]
        if len(es) < m_min:
            return False, 0.0
        m = len(es)
        bias = np.mean(es, axis=0)
        stat = np.linalg.norm(bias) / (np.linalg.norm(sigma_r[z]) / np.sqrt(m))
        return stat >= kappa, stat
```

### IP-165 DCR（配比再平衡，投影指数梯度）

```python
def rebalance_recipe(ledger, ddr, anchor, budget, eta=0.05):
    w = np.array([s['w'] for s in ledger.shards], dtype=float)
    loss = np.array([expected_dplus(s['scenes'], ddr) for s in ledger.shards])
    w = project_simplex(w * np.exp(-eta * loss))
    for i, s in enumerate(ledger.shards):        # 支持度护栏
        if ledger.n_eff_under(s, w) < N_MIN:
            w[i] = min(w[i], anchor[i] * 1.5)    # 限幅，避免权重拉满
    if cost_data(w) > budget.data:
        w = project_onto_budget(w, budget.data)
    return w
```

### IP-166 PREC（配方感知闭环）

```python
def pretrain_recipe_evolution_loop(M, scene, intent, delta_f_req):
    r = M.recipe
    if M.slow_tick_due():
        r = rebalance_recipe(M.ledger, M.ddr, M.anchor_recipe, M.budget)
        if not nts_accept(r, M.anchor_recipe, M.guard_suite, M.ledger):
```

### IP-167 PCE+++++（数据预算）

```python
class DataBudget:
    def __init__(self, storage=1e9, replay=1e5, retrain=5, label=1e3):
        self.B = {'storage': storage, 'replay': replay,
                  'retrain': retrain, 'label': label}
        self.used = {k: 0 for k in self.B}

    def spend(self, kind, amount):
        if self.used[kind] + amount > self.B[kind]:
            return False
        self.used[kind] += amount
        return True

    def fallback_mode(self):
        if self.used['retrain'] >= self.B['retrain']:
            return 'freeze_recipe_online_calibrate'
        if self.used['replay'] >= self.B['replay']:
            return 'replay_critical_only'
        return 'normal'
```

### IP-168 NTS（负迁移熔断）

```python
def nts_accept(w_new, w_anchor, guard_suite, ledger,
               delta_kl=0.1, eps_f=0.02, eps_s=0.01):
    if kl_div(w_new, w_anchor) > delta_kl:
        return False
    for z in guard_suite.scenes:
        if dplus(z, w_new) > dplus(z, w_anchor) + eps_f:
            return False
        if viol_rate(z, w_new) > viol_rate(z, w_anchor) + eps_s:
            return False
    return all(ledger.supported(z, w_new) for z in guard_suite.critical)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| DML | O(M) / 场景查询 | O(M) | 权重归一、n_eff 按分片计 |
| CPP | O(d²) 构造 | O(N·d²) | 精度随 n_eff 单调，未支持禁止收窄 |
| PPT | O(1) 组装 | O(1) | 可回溯到配方哈希 |
| DDR | O(d) / 闭环 | O(N·m) | 仅系统偏置判为缺口 |
| DCR | O(M·N) / 再平衡 | O(M) | KL 锚 + 单纯形投影有界 |
| PREC | 快 O(SERC)，慢 O(M·N) | 复用 | 慢尺度不阻塞执行 |
| NTS | O(\|Z_guard\|) | O(1) | 劣化配方熔断 |

**正确性定理（DRPC）**：若 A66–A70 成立，则：
1. PPT 无效的 K_safe 不得越过通用先验边界，杜绝高置信错误先验下发。
2. 持续数据缺口在有限闭环内被 DDR 检出并触发主动采样；零均值噪声不扰动配方。
3. 被采纳配方满足 KL 上界且守护场景 D⁺/违规率不劣化；否则回滚。
4. B_data 单调消耗，任一维度耗尽触发对应降级，闭环仍可运行。
