# 第 44 轮（新循环第 4 轮） · GenManip-Cert × Disturb-Cert：把「通用操作」与「抗干扰」纳入组合证书与扰动语义闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖 + 多用户契约空集」，但它仍压着两个更底层的单点假设：**(H3) 任务集是可枚举的**——证书表、课程、指纹与阈值默认存在一份有限任务清单，所谓“通用”只是清单更长；**(H4) 扰动是小的、同分布的、与任务无关的**——鲁棒性被压成一个标量裕度，接触被当作噪声，而没有承认接触本身就是操作得以发生的媒介。本轮灵感词「通用操作」「抗干扰」精确命中这两个假设：**通用操作**迫使我们把证书从“查表”升级为“按语法组合已验证原语”，否则开放任务集永远证不完；**抗干扰**迫使我们把扰动从“标量噪声”升级为“类型化对象”，区分必须拒绝的外源对抗扰动与必须利用的任务耦合不确定性。二者耦合处才是真正的新问题：**同一个力信号既可能是预期接触，也可能是恶意推搡**——扰动语义一旦混淆，要么把有用接触当敌人（可用性崩塌），要么把对抗推搡当接触（静默不安全）。

## 0. 直觉与动机

**灵感 1（通用操作 → 证书必须“可组合”，而不是“可枚举”）**：如果每来一个新任务就补一张证书表，那么“通用”只是把长尾无限往后推，认证永远追不上任务。真正可扩展的做法是承认操作有语法：抓、推、倒、插、开、递这些**原语**各自持证，复杂任务由 `seq / par / branch / rep` 组合而成，证书随组合规则自动构造。这样通用性的边界不再是“任务清单有多长”，而是“原语库多完整、接口契约多严”。收缩到已验证原语的组合是免费的；但组合会带来两个新代价：接口假设可能不匹配，以及**扰动预算沿任务树传播时会被反复放大**。一句话：**通用不是多写表，而是少假设、可组合；组合的代价必须显式记账。**

**灵感 2（抗干扰 → 扰动不是一种东西，先分类再谈鲁棒）**：把一切扰动都当最坏情况，机器人会保守到无法完成接触任务；把一切扰动都当噪声，机器人会把推搡当摩擦、把攻击当手感。正确姿势是**给扰动做类型**：外源对抗扰动 \(w_{ext}\) 必须被拒绝/吸收/安全停机；任务耦合不确定 \(w_{task}\)（对象质量、摩擦、位姿、形变）必须被利用与辨识；模型误差 \(w_{model}\) 必须用集合上界吃掉。同一个观测力可能同时兼容两类解释，此时唯一 sound 的做法不是“赌分类”，而是**在候选扰动集上取并集做鲁棒证书**，并显式报告歧义度。一句话：**抗干扰不是把扰动压小，而是先回答“这是哪一种扰动”，答不清就按并集保守处理。**

**灵感 3（耦合 → 扰动预算代数与语义歧义是同一个问题的两面）**：通用操作是长时程任务树，抗干扰是任务树每个节点上的扰动集。若每个原语都“假设扰动有界”，组合后界会相加甚至相乘；若接口两侧对“这是什么扰动”理解不同，组合证书会在接缝处静默失效。于是必须同时做两件事：**(a) 扰动预算代数**——父任务把预算下推给子任务，子任务实测后回收未用预算，防止保守性指数爆炸；**(b) 扰动语义证书**——每个接口携带“允许的解释集合”，分类不确定时取并集，绝不单方面缩小扰动集。二者共同保证：组合不是把证明责任偷偷摊薄，而是把证明责任**显式分解并可在运行时回收**。

**耦合升级**：GOCA（通用操作证书代数）把开放任务编译成原语组合并构造组合证书；DCE（扰动证书引擎）提供类型化扰动、鲁棒管与预算回收；ADV（对抗扰动验证器）做最坏扰动搜索、语义混淆攻击与反例回灌。四层架构由此从 v8 的「仿真-检索-边缘 + 人格 + 并发」升级为 v9 的「仿真-检索-边缘 + 人格 + 并发 + 组合通用性 + 扰动语义」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（类型化操作原语与任务项）**：原语
\[
o=(\mathrm{Pre}_o,\mathrm{Eff}_o,\mathrm{Port}_o,C_o,\Delta_o,\kappa_o),
\]
其中 \(\mathrm{Port}_o\) 为类型化端口集合（对象槽、接触面、工具接口、可供性 affordance），端口类型 \(T\in\{\text{graspable},\text{pourable},\text{insertable},\text{openable},\dots\}\)；\(C_o\) 为原语证书模式（前置/后置/不变式/参数域）；\(\Delta_o\) 为端口上的**扰动契约**（外源扰动上界、对象参数不确定集、接触力/冲量界）；\(\kappa_o\) 为关键级。任务项语法
\[
\tau ::= o \mid \mathrm{seq}(\tau_1,\tau_2) \mid \mathrm{par}(\tau_1,\tau_2) \mid \mathrm{branch}(\phi,\tau_1,\tau_2) \mid \mathrm{rep}(\tau,\phi).
\]
**组合证书构造** \(C(\tau)\) 按 assume-guarantee 进行：`seq` 需 \(\mathrm{post}(\tau_1)\Rightarrow\mathrm{pre}(\tau_2)\) 且扰动契约沿时间可传播；`par` 需端口不相交或共享端口的写集互不干扰；`branch` 需守卫 \(\phi\) 可判定且两分支证书分别在 \(\phi\) 与 \(\neg\phi\) 下成立。**组合 soundness 命题**：若每个原语的 \(C_o\) 在其参数域与 \(\Delta_o\) 内 sound，且所有接口义务成立，则 \(C(\tau)\) sound。**推论**：通用操作的认证对象从“任务清单”变成“原语库 + 组合规则 + 接口契约”。

**定义 45（扰动语义与可辨识性）**：真实扰动分解为
\[
w=w_{task}+w_{ext}+w_{model},
\]
\(w_{task}\) 为任务耦合不确定（对象质量/摩擦/位姿/形变，是操作的媒介）；\(w_{ext}\) 为外源对抗扰动（推搡、碰撞、风、通信注入）；\(w_{model}\) 为模型误差。类型化扰动集 \(D=D_{task}\times D_{ext}\)。给定观测 \(y=h(w)+\eta\)，**扰动语义证书**
\[
S(y)=(\hat S,A),\quad \hat S\in\{\text{task},\text{ext},\text{ambiguous}\},\ A\subseteq D,
\]
\(A\) 为与观测一致的候选扰动集。**安全条件**：仅当 \(\forall w\in A\) 证书都 sound 才允许执行。**性能条件**：\(P(\hat S=\text{ext}\mid w\in D_{task})\le\zeta\)，即把有用接触误判为敌意扰动的比率有界。**可辨识性命题**：若 \(D_{task}\) 与 \(D_{ext}\) 在传感器模型下不可分离，则任何确定性分类器都存在不可约混淆；此时唯一 sound 的选择是 \(A=D_{task}\cup D_{ext}\)（取并集保守处理），不能赌分类正确。

**定义 46（抗干扰鲁棒证书与扰动管）**：对原语 \(o\) 与扰动集 \(D_o\)，**鲁棒控制不变集**
\[
\Omega_o(D_o)=\{x\mid \exists u\in U,\ \forall d\in D_o,\ f(x,u,d)\in\Omega_o\}.
\]
名义轨迹的**扰动管** \(\mathrm{Tube}(\rho_o)=\{x\mid \|x-x_{nom}\|\le\rho_o\}\)，\(\rho_o\) 由鲁棒不变性、扰动观测器误差与跟踪残差共同给出。**鲁棒证书**
\[
C_o^{\rho}=C_o\ominus\mathrm{Tube}(\rho_o).
\]
**抗干扰引理**：若 \(x(0)\in C_o^{\rho}\) 且 \(d(t)\in D_o\ \forall t\)，则 \(x(t)\in C_o\ \forall t\)。**注**：\(\rho_o\) 必须按集合包含意义取上界（物理 Lipschitz + 观测器误差界），经验分位数只能用于收紧，不能替代上界。

**定义 47（扰动预算代数与组合传播）**：任务树每节点分配扰动预算 \(\beta(\tau)\)（可理解为允许扰动管半径/能量）。叶子需 \(\rho_o\le\beta(o)\)；组合规则
\[
\beta(\mathrm{seq}(\tau_1,\tau_2))\ge\varphi_{seq}(\beta(\tau_1),\beta(\tau_2)),\quad
\beta(\mathrm{par})\ge\beta(\tau_1)+\beta(\tau_2)+\beta_{share},
\]
\[
\beta(\mathrm{branch}(\phi,\tau_1,\tau_2))\ge\max(\beta(\tau_1),\beta(\tau_2)).
\]
**预算组合定理**：若每个叶子在其预算内鲁棒 sound，且接口契约把父预算按上述规则下推，则整棵树 sound。**保守性命题**：\(\varphi_{seq}\) 的漂移放大与 \(\beta_{share}\) 的共享端口耦合是通用性的真实成本；组合深度增加时若不做预算回收，可用性会指数衰减。**推论（预算回收）**：运行时用扰动观测器实测 \(\hat D\subseteq D\)，回收未用预算，否则“通用操作”在证书层面不可用。

**定义 48（证书可接地性与新颖性门控）**：对开放任务集，新任务/新对象 \(\tau\) 需经**接地映射**
\[
g:\tau\mapsto(\hat\tau,\hat\theta,\text{端口绑定}),
\]
**可接地证书**存在当且仅当：(1) \(\hat\tau\) 由已验证原语构成；(2) 参数实例 \(\hat\theta\) 落在原语参数域内（含对象属性、工具几何、接触模式）；(3) 接口与扰动契约可满足。**新颖性分数** \(\nu(\tau)=\mathrm{dist}(\hat\theta,\text{已验证参数覆盖})\)。**门控规则**：\(\nu\le\nu_0\) 全速自主；\(\nu_0<\nu\le\nu_1\) 进入**受护探索**（限速/限力/人工确认/影子证书）；\(\nu>\nu_1\) 拒绝自主并请求示教。**命题**：门控把“未知即不安全”变成“未知即降级”，但绝不把未知当已知——这是通用操作可被认证的前提。

**定义 49（对抗扰动下的证书刷新与恢复契约）**：对扰动造成的状态偏移，**恢复契约**
\[
R=(S_{recover},T_r,\mathrm{guard})
\]
表示：从任意在 \(D\) 下可达的状态 \(x\)，存在恢复策略 \(\pi_r\) 在 \(T_r\) 内把状态驱回已认证集 \(C^{\rho}\)，且全程不违反硬安全约束（接触力/速度/区域）；否则触发安全停机。**刷新契约**：对抗验证器发现反例 \(c\) 后，证书模式 \(\Sigma\) 通过参数收缩或新增前置条件修复为 \(\Sigma'\)，且 \(C_{\Sigma'}\subseteq C_{\Sigma}\)；修复必须单调收紧，**不得通过放宽 \(\Delta\) 来“修复”**。**命题**：单调修复 + 恢复契约使“发现反例 → 变保守 → 再验证”循环收敛到 sound 证书，而不会用放宽扰动假设掩盖反例。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 GENERAL-OPERATION-CERT-ALGEBRA（通用操作证书代数 GOCA）
1. **原语库与类型端口**：把抓/推/倒/插/开/递等编译为带前置、后置、参数域与扰动契约的原语；端口类型化保证组合只在语义相容处发生。
2. **组合证书构造器**：按 `seq/par/branch/rep` 自动生成接口义务（pre/post、读写集、扰动预算约束），并调用 IP-47 组合代数做兼容检查。
3. **接地与新颖性门控**：新任务/新对象先做接地映射与 \(\nu\) 评分；OOD 一律降级为受护探索或拒绝自主，绝不静默套用最近邻原语。
4. **预算回收接口**：把运行时实测扰动集回灌任务树，回收未用预算；预算回收只能收紧证书，不能放松。

### 2.2 IP-61 DISTURBANCE-CERT-ENGINE（扰动证书引擎 DCE）
1. **扰动语义分类器**：基于力/触觉/视觉/本体感知与接触模型，输出 \((\hat S,A)\)；分类不确定时输出 \(A=D_{task}\cup D_{ext}\)，绝不单方面缩小候选集。
2. **鲁棒不变集与扰动管**：对每个原语离线算 \(\Omega_o(D_o)\)，在线用扰动观测器误差界更新 \(\rho_o\)；管半径进入守卫 margin。
3. **预算分配与回收**：维护任务树预算表，按定义 47 下推与回收；预算不足时单调降级（限速/限力/换保守原语），不降安全阈值。
4. **恢复契约执行**：大扰动后先判定是否可恢复，可恢复则执行 \(\pi_r\) 并重新签发租约，不可恢复则安全停机。

### 2.3 IP-62 ADVERSARIAL-DISTURBANCE-VALIDATOR（对抗扰动验证器 ADV）
1. **最坏扰动搜索**：在 \(D_{ext}\) 上做 CBF/可达性对抗搜索、场景优化与 sim-to-real 扰动注入，专门找“证书边界上的推搡”。
2. **语义混淆攻击**：构造与预期接触力轨迹不可分离的外源扰动，检验 \(P(\hat S=\text{task}\mid w\in D_{ext})\) 是否超限；这是本轮的红线攻击面。
3. **组合反例回灌**：把反例定位到具体原语/接口/预算节点，回灌 GOCA 与 CKB，驱动单调修复。
4. **恢复与长时程压测**：注入连续推搡、接触丢失、对象滑移、工具卡死，测恢复成功率、恢复时间与二次违例。

## 3. 四层架构 v9

```
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + 扰动观测器(D_hat, rho)
    触觉/力觉 → 扰动语义 S(y)=(S_hat, A) + 歧义度
L2: CTC + VLM + IP-35 仲裁 → 任务项 tau(由 IP-60 接地为原语组合)
L3: IP-51 CAR(margin=min(查表,租约,persona,扰动管,健康), DisturbMode)
    ← IP-58 CCR(租约/预算/关键级) ← IP-61 DCE(鲁棒管+预算回收)
    → IP-47 扰动契约组合 → IP-39 规划(鲁棒管约束)
    → IP-45 总线(disturb/ambiguity/budget/recovery) → IP-53 CMC(接触/力监控)
L4: IP-60 GOCA(原语库+组合证书+新颖性门控) + IP-55 CKB(指纹含原语/扰动)
    ← IP-62 ADV(最坏扰动+语义混淆+组合反例) + IP-54 SCV(开放任务+扰动仿真)
    → IP-44 蒸馏 + IP-50 对抗扰动课程 → RCA 重颁 → 证书/原语热更新
运行期：任务接地 → 组合证书 → 预算下推 → 查表+鲁棒管守卫 → 语义分类
        歧义 → 取并集保守/降级 → 大扰动 → 恢复契约或安全停机
        反例 → 单调修复 → 再验证（绝不放宽扰动假设）
```

```
    # 1) 语法接地：把开放任务拆成类型化原语组合
    term, ports = parse_and_bind(tau, primitive_lib)
    if term is None:
        return Gate.REFUSE, None          # 无法接地的任务绝不硬套最近邻
    theta = instantiate_params(term, tau)
    # 2) 参数覆盖：每个实例必须落在已验证参数域内
    if not all(in_domain(theta[p], primitive_lib[p]) for p in term.leaves):

    if nu <= NU0:
        return Gate.FULL, term
    if nu <= NU1:
        return Gate.GUARDED, term         # 受护探索：限速/限力/确认/影子证书
    return Gate.REFUSE, term

def compose_certificate(term):
    # 自底向上按 assume-guarantee 组合
    if is_leaf(term):
        return term.cert                          # 已验证原语证书
```

```
def classify_disturbance(y, contact_model):
    A_task = consistent_with(y, D_task, contact_model)
    A_ext  = consistent_with(y, D_ext,  contact_model)
    if A_task and A_ext:
        # 不可辨识：绝不赌分类，取并集保守
        return Semantic(tag='ambiguous', A=A_task | A_ext)
    if A_ext:
        return Semantic(tag='ext', A=A_ext)
    return Semantic(tag='task', A=A_task)

def robust_guard(x, o, semantic, t):
    # 候选扰动集上取最坏，而不是用分类结果缩小集合
    rho = max(tube_radius(d, o) for d in semantic.A)
    C_robust = erode(o.C, rho)
    if semantic.tag == 'ambiguous':
        return C_robust, Mode.CONSERVATIVE      # 并集 + 受护探索
    return C_robust, Mode.NOMINAL

def recycle_budget(task_tree, D_hat):
    # 运行时实测扰动集只能收紧，不能放宽
    for node in postorder(task_tree):
        node.beta_used = min(node.beta, push_through(D_hat, node))
        node.beta = node.beta_used              # 回收未用预算
    return task_tree

def recovery_contract(x, C_robust, D):
    if recoverable(x, C_robust, D):
        pi_r = synthesize_recovery(x, C_robust, D)
        return pi_r, within(x, pi_r, T_R, guard=hard_safety)
    return SAFE_STOP                            # 不可恢复则停机
```

### IP-62 ADV：最坏扰动与语义混淆攻击
```
def adversarial_disturbance_search(o, C_robust, D_ext):
    # 目标：找到仍被语义判为 task 的外源扰动，或击穿扰动管的最小能量扰动
    return optimize(
        objective=lambda d: (is_classified_task(d), -energy(d)),
        constraint=lambda d: violates(step(o, d), C_robust),
        domain=D_ext)

def semantic_confusion_attack(o, D_task, D_ext):
    # 构造与预期接触力轨迹不可分离的对抗扰动
    return min_norm(d_ext in D_ext) s.t. exists(d_task in D_task):
        observation(d_ext) == observation(d_task)

def repair_monotone(primitive, counterexample):
    Sigma2 = shrink_params(primitive.Sigma, counterexample)   # 只收紧
    assert subset(Sigma2.admissible, primitive.Sigma.admissible)
    assert Sigma2.Delta <= primitive.Sigma.Delta              # 不放宽扰动假设
    return primitive.with_mode(Sigma2)
```
