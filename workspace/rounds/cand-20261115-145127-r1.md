# 第 8 轮（灵感循环第 8 轮；本轮灵感：「痛点分析」×「协同控制」）
> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–525；引理 73–76；实验 E513–E525）。
> 本轮纪律：**痛点优先 + 协同仲裁**。第 7 轮回答了「系统能否在线适应」，本轮回答两个更靠前的问题：「应当优先适应哪个失效」与「由谁、在多大权限内执行适应」。三条约束不变：M₀ 不可交易、退化链只能向下兼容、任一新模块失效必须退回 v7（v7 内部再按原链退回 v6）。

## 0. 直觉与动机

### 灵感 1：痛点分析——把「全指标监控」改成「按痛点分配注意力」

直觉：第 7 轮的指标层级本质上是「平权监控」：M₁、M₂、M₃ 都在被检查，但系统没有回答「哪一个失效最值得先修」。真实部署里的痛点不是抽象的「安全性不足」，而是具体的、可复现的失效模式：嘈杂环境下的语音误识别、透明物体的抓取滑移、OTL 阈值与 ER 权重互相抵消、以及退化抖动本身。痛点分析的价值在于把日志里的失败聚成可排序的对象，用「每单位干预能减少多少痛」（痛点弹性）来分配有限的注意力与算力。

但朴素的痛点分析有三个陷阱，必须在定义层面堵死：
1. **幸存者偏差**：只统计已记录的失败，忽略「差一点失败」（near-miss）；后者往往才是低成本干预的最佳入口。
2. **确认偏误**：先有结论再找日志。因此痛点必须由预注册的聚类键与 held-out 校准检验，而不是事后讲故事。
3. **可恢复性混淆**：高频但可自愈的痛点，与低频但一旦发生就升级为 M₀ 的痛点，不应同权。故痛点强度必须乘上 $(1-\text{recoverability})$。

### 灵感 2：协同控制——不是「人选或机器人选」，而是「带证书的权限混合」

直觉：第 7 轮的 OTL/GCT/ER 是三个各自调节的模块，缺少一个「谁在什么时候说了算」的仲裁层。协同控制提供的正是这个层：人类操作员与自主策略各给出命令，系统按逐自由度权限 $a_j\in[0,1]$ 混合；但混合本身可能把两个各自安全的命令混成不安全的命令（安全集非凸时尤其如此）。因此协同必须带证书：CoopCert 保证任何被执行的混合命令仍满足 M₀，而不是假设「两个安全命令的凸组合必然安全」。

关键设计选择：**痛点只分配 M₁–M₃ 的注意力与可选的退化档位，M₀ 是约束而非目标。** 这一条把「按痛点优化」与「安全不可交易」分开，避免系统为了提高某个痛点指标而放松硬约束。

### 灵感 3（交叉）：痛点引导的协同——把「该退化多少」变成带切换预算的最优停时

直觉：第 7 轮的最大风险是「过度适应导致频繁软→硬退化」。痛点分析与协同控制交叉后，可以给出直接对治：退化不再是一旦违背就跳到 M₀，而是在退化格 $D$ 上选择「刚好足够恢复证书」的最小档位，并对切换本身收费 $\lambda_{sw}$。这样，痛点是目标，协同是执行，退化是带预算的停时决策。

## 1. 研究问题（轮次升级版）

- **Q1（痛点可辨识性）**：如何从稀疏、含 near-miss、分布会漂移的日志中稳定估计痛点强度 $J(p)$ 与弹性 $\varepsilon(p)$，并控制「痛点幻觉」（把噪声当痛点）？
- **Q2（协同安全性）**：如何定义人-机权限混合 $A$，使任意被执行命令在非凸安全集下仍满足 M₀，且与 OTL/GCT/ER 的在线调节兼容？
- **Q3（最小充分退化）**：如何在退化格上选择最小充分档位，使残余痛点不高于第 7 轮单跳规则，同时把切换频率压到可证明的上界内？
- **Q4（模块问责）**：当 ER 误识别或 OTL 过激时，如何用反事实信用 $\phi_k$ 识别并自动降权有害模块，而不是让它们继续污染协同回路？

## 2. 设计原则（P7–P9 上升级为 P10–P13）

**P10 痛点优先且 M₀ 不可交易（Pain-Point Priority, PPP）**
痛点向量 $\pi_t$ 只在 M₁–M₃ 与「可选增强模块」上分配权重；M₀ 永远作为可行性约束：
```
J(p) = freq̂(p) · sev(p) · (1 − reĉ(p)),   p ∈ M₁ ∪ M₂ ∪ M₃
π_t = softmax(J / T),                      M₀ ∉ supp(π_t)
```
near-miss 以权重 $0.25$ 计入 $\widehat{freq}$；频率与可恢复率均做指数遗忘 + Laplace 平滑。

**P11 协同权限包络（Cooperative Authority Envelope, CAE）**
逐自由度权限 $a_j\in[0,1]$，人-机命令的凸混合为：
```
u = A u_h + (I − A) u_r,    A = diag(a_1, …, a_n)
CoopCert(A) ⇔ ∀ u_h ∈ U_h, u_r ∈ U_r : h(A u_h + (I − A) u_r) ≤ 0
```
若安全集凸，端点安全 ⇒ 混合安全（引理 78）；否则用离散 CBF 投影把混合结果投回 $h(u)\le 0$，并以余量 $\rho$ 记录。

**P12 最小充分退化（Minimal Sufficient Degradation, MSD）**
退化格与选择规则：
```
D = { d₀: 不退化 ≺ d₁: 收紧 τ ≺ d₂: 关 OTL/ER ≺ d₃: 退回 v7 ≺ d₄: 仅 M₀ }
d*(s) = argmin_{d ⪰ d_req(s)} [ J_res(d) + λ_sw·1[d ≠ d_{t−1}] + λ_lat·ℓ(d) + λ_deg·rank(d) ]
```
$d_{req}(s)$ 是恢复 CoopCert 所需的最小档位；$d\succeq d_{req}$ 保证安全，目标函数保证「不过度」。只有改进超过滞回带 $H$ 才切换。

**P13 协同信用问责（Cooperative Credit, CC）**
对模块集合 $\mathcal{M}=\{\text{OTL},\text{GCT},\text{ER},\text{PPM},\text{CCA},\text{MSD},\text{CRA}\}$ 计算单位成本 Shapley 信用：
```
φ_k = (1/C_k) · Σ_{S ⊆ M\{k}} [ |S|!(|M|−|S|−1)!/|M|! ] · [ J(S) − J(S ∪ {k}) ]
```
$\phi_k<0$ 表示模块 $k$ 在当前痛点分布下净增痛，应降低 $\beta/\eta/$权限或直接旁路。

## 3. 与基线的接口（如何退化）

- PainPointMiner 失效 ⇒ $\pi$ 退回固定严重度先验 $\pi_0$（即第 7 轮的无优先注意力），控制命令不变；
- CooperativeControlArbiter / CoopCert 失效 ⇒ $A=I$，退化为纯自主控制，CoopCert 退化为第 7 轮 SpatialCert；
- MinimalSufficientDegradation 失效 ⇒ 退回第 7 轮「一旦软违背即单跳 M₀」规则；
- CooperativeCreditAllocator 失效 ⇒ 固定模块集合与固定 $\beta/\eta$（第 7 轮配置）；
- 以上均不修改 OTL/GCT/ER 的定义域；v7 内部仍可按原链退化到 v6。

## 4. 预期贡献

1. **痛点可辨识框架**：带 near-miss、可恢复性与弹性校准的痛点向量，给出「该先修什么」的可检验排序；
2. **协同控制证书**：逐自由度权限混合 + CoopCert/CBF 投影，把人类操作员纳入硬约束闭环；
3. **最小充分退化**：用带切换预算的退化格替代单跳规则，直接对治第 7 轮的退化抖动风险；
4. **模块问责**：Shapley 单位成本信用，让 ER/OTL 的有害调节可被自动识别与降权；
5. **v8 → v7 → v6 三级退化**：E526–E545 覆盖痛点辨识、协同安全、退化抖动、模块问责与端到端。

## 5. 本轮最大风险

**一句话**：痛点是从历史日志中学出来的，一旦部署分布漂移，系统可能锁死在「昨天的痛点」上，并把协同权限系统性地交给错误的智能体——形成自我强化的「痛点隧道」，越优化越看不见新失效。

**定义 526（痛点事件与痛点 PainEvent / PainPoint）** 事件与聚类：
```
e = (t, task, i, c, b, r, σ, ℓ),   i ∈ {1,2,3}, b ∈ {0,1}, r ∈ {0,1}, σ ∈ [1,5]
p = (i, c, context(e))
D_p(t) = { e_τ : τ ≤ t, key(e_τ) = p, e_τ ∉ M₀ }
```
M₀ 事件单独进入安全审计日志，永不进入 D_p，因此不会被「痛点优化」稀释。

**定义 527（痛点强度与优先级 PainIntensity / PainVector）** 带遗忘与平滑的估计：
```
N_p(t) = γ·N_p(t−1) + w(e_t),   w(e) = 0.25 if near_miss(e) else 1
freq̂(p) = (N_p(t) + α₀·π₀(p)) / (t + α₀)
reĉ(p) = (R_p(t) + 1) / (N_p(t) + 2)          # Laplace
J(p) = freq̂(p) · sev̂(p) · (1 − reĉ(p))
π_t(p) = exp(J(p)/T) / Σ_{p'} exp(J(p')/T)
```

**定义 528（痛点弹性 PainElasticity）** 只在安全回放缓存上做 A/B，不在在线 M₀ 上试探：
```
ε(p) = [ Ĵ(p | c(p)+Δ) − Ĵ(p | c(p)) ] / (Δ · unit_cost)
```
以 ε(p) 排序干预队列；ε 的估计用配对回放 + bootstrap 置信区间，置信区间跨 0 的痛点不进入自动干预。

**定义 529（协同权限包络 CooperativeAuthorityEnvelope）** 人-机命令的逐自由度混合：
```
u = A·u_h + (I − A)·u_r,   A = diag(a₁,…,aₙ), aⱼ ∈ [0,1]
E(A) = { A u_h + (I−A) u_r : u_h ∈ U_h, u_r ∈ U_r }
```

**定义 530（协同证书 CoopCertificate）** 包络内的硬约束不变式：
```
CoopCert(A) ⇔ ∀ u ∈ E(A) : h(u) ≤ 0
ρ(A) = −max_{u ∈ E(A)} h(u)                 # 安全余量
```
在线执行时只对**实际混合命令**验证并不够；证书要求对可达包络成立，或由 CBF 投影给出逐步不变式：
```
h(u_{k+1}) ≤ (1−η_cbf)·h(u_k),   u_{k+1} = Π_C(A u_h + (I−A) u_r)
```

**定义 531（最小充分退化 MinimalSufficientDegradation）** 带切换预算的选档：
```
d_req(s) = min { d ∈ D : CoopCert_d(A) }
d*(s) = argmin_{d ∈ D, d ⪰ d_req(s)}
         [ J_res(d) + λ_sw·1[d ≠ d_{t−1}] + λ_lat·ℓ(d) + λ_deg·rank(d) ]
```
执行规则：仅当 `cost(d*) + H < cost(d_{t−1})` 时切换，否则保持；且任何时刻不得选择低于 `d_req` 的档位。

**定义 532（协同信用 CooperativeCredit）** 单位成本 Shapley 值：
```
φ_k = (1/C_k) · Σ_{S ⊆ M\{k}} [ |S|!·(|M|−|S|−1)! / |M|! ] · [ J(S) − J(S∪{k}) ]
```
`J(S)` 是只启用模块子集 S 时的痛点强度（离线回放/反事实估计）。`φ_k<0` ⇒ 模块 k 净增痛。

**定义 533（v8 组合退化算子）** 新模块全失效时精确回到 v7：
```
Ψ_v8→v7 : (π, A, d, Φ) ↦ (π₀, I, hard_M0_if_required, Φ_v7)
```
其中 Φ_v7 为第 7 轮模块集合与参数。

## 2. 形式化定义（要点）

**定义 493–525** 全部保留，作为 v8 的底层语义；v8 不修改 MetricLadder、VoiceCommandTyping、RewardDecomposer、SoftCert、MetaWeight、OTL、GCT、ER 的定义域。

**定义 526–527（痛点）**：痛点只覆盖 M₁–M₃；M₀ 是审计对象而非优化对象。这是「M₀ 不可交易」在数据层的实现。

**定义 529–530（协同）**：A 是逐自由度对角阵，而非全局标量。理由是机器人不同关节的安全敏感度不同（腕部旋转与末端平移不应共享同一权限）。对角阵也让 CoopCert 的验证可分解到 DoF 或安全关键子空间。

**定义 531（退化）**：`d ⪰ d_req` 是硬约束，目标函数只决定「在安全档位中选多深」。因此 MSD 不会为了省切换成本而选一个不安全的浅档；这正是与「用痛点换安全」的界线。

**定义 532（信用）**：Shapley 效率性给出 `Σ_k C_k φ_k = J(∅) − J(M)`；因此信用是「痛的重新分配」而非又一个超参数。CRA 只做降权/旁路，不做「提权」——提权必须走人工审批，避免自动放大某模块。

# IP-351 PainPointMiner：痛点挖掘与优先级
class PainPointMiner:
    def __init__(self, gamma=0.97, near_miss_w=0.25, T=0.5, prior=None, alpha0=2.0):
        self.gamma = gamma          # 指数遗忘
        self.near_miss_w = near_miss_w
        self.T = T                  # softmax 温度
        self.prior = prior or {}    # p -> 先验质量
        self.alpha0 = alpha0
        self.count = {}             # p -> 加权频次 N_p
        self.sev = {}               # p -> 严重度 [1,5]
        self.rec_num = {}           # p -> 恢复次数 R_p
        self.time = 0

    @staticmethod
    def key(e):
        return (e["layer"], e["cause"], e.get("context", "default"))

    def update(self, e):
        # M0 事件只审计，不定价
        if e["layer"] == 0:
            return
        self.time += 1
        for p in self.count:                      # 指数遗忘
            self.count[p] *= self.gamma
            self.rec_num[p] *= self.gamma
        p = self.key(e)
        w = self.near_miss_w if e.get("near_miss", False) else 1.0
        self.count[p] = self.count.get(p, 0.0) + w
        self.sev[p] = 0.8 * self.sev.get(p, e["severity"]) + 0.2 * e["severity"]
        if e.get("recovered", False):
            self.rec_num[p] = self.rec_num.get(p, 0.0) + w

    def pain(self):
        out = {}
        for p, n in self.count.items():
            freq = (n + self.alpha0 * self.prior.get(p, 1e-3)) / (self.time + self.alpha0)
            rec = (self.rec_num.get(p, 0.0) + 1.0) / (n + 2.0)     # Laplace
            out[p] = freq * self.sev[p] * (1.0 - rec)
        return out

    def pi(self):
        J = self.pain()
        if not J:
            return {}
        keys = list(J)
        z = np.array([J[k] / self.T for k in keys])
        z -= z.max()
        w = np.exp(z)
        w /= w.sum()
        return dict(zip(keys, w))

    def elasticity(self, p, replay, intervention, cost):
        # 只在安全回放缓存上做干预 A/B；不在线试探 M0
        base = replay.pain(p)
        after = replay.pain(p, intervention=intervention)
        return (base - after) / max(cost, 1e-6)


# IP-352/353 CooperativeControlArbiter + CoopCertificate
class CooperativeControlArbiter:
    def __init__(self, n_dof, alpha=0.5, rho=0.02, eta_cbf=0.5):
        self.A = np.eye(n_dof) * alpha
        self.rho = rho
        self.eta_cbf = eta_cbf

    def blend(self, u_h, u_r):
        return self.A @ u_h + (np.eye(len(self.A)) - self.A) @ u_r

    def cbf_project(self, u_mix, h, grad_h):
        # 离散 CBF + 一阶投影：目标 h(u*) <= -rho
        if h(u_mix) <= -self.rho:
            return u_mix, True
        g = grad_h(u_mix)
        denom = float(g @ g) + 1e-9
        slack = h(u_mix) + self.rho
        u_safe = u_mix - max(0.0, slack / denom) * g
        ok = bool(h(u_safe) <= 0.0)
        return u_safe, ok

    def certify(self, U_h_samples, U_r_samples, h):
        # 凸安全集：只需端点；非凸：采样 + CBF 在线兜底
        for uh in U_h_samples:
            for ur in U_r_samples:
                if h(self.blend(uh, ur)) > 0.0:
                    return False
        return True


# IP-354 MinimalDegradationScheduler
class MinimalDegradationScheduler:
    LEVELS = ["none", "tighten_tau", "disable_otl_er", "fallback_v7", "hard_m0"]

    def __init__(self, lam_sw=0.30, lam_lat=0.10, lam_deg=0.05, H=0.05):
        self.lam_sw, self.lam_lat, self.lam_deg, self.H = lam_sw, lam_lat, lam_deg, H
        self.prev = 0

    def _cost(self, i, residual_pain, latency):
        return (residual_pain[self.LEVELS[i]]
                + self.lam_lat * latency[i]
                + self.lam_deg * i
                + self.lam_sw * (i != self.prev))

    def select(self, required, residual_pain, latency):
        required = max(0, min(required, len(self.LEVELS) - 1))
        best = min(range(required, len(self.LEVELS)),
                   key=lambda i: self._cost(i, residual_pain, latency))
        # 滞回：不比当前档位好 H 就不切；安全要求可强制加深
        cur = self._cost(self.prev, residual_pain, latency)
        chosen = best if (cur - self._cost(best, residual_pain, latency)) > self.H else self.prev
        self.prev = max(chosen, required)          # 不得回退到 d_req 之下
        return self.LEVELS[self.prev]


# IP-355 CooperativeCreditAllocator
class CooperativeCreditAllocator:
    def __init__(self, modules, costs):
        self.modules = list(modules)
        self.costs = dict(costs)

    def credit(self, pain_fn):
        n = len(self.modules)
        phi = {k: 0.0 for k in self.modules}
        for k in self.modules:
            rest = [m for m in self.modules if m != k]
            for r in range(len(rest) + 1):
                for S in combinations(rest, r):
                    S = frozenset(S)
                    w = factorial(len(S)) * factorial(n - len(S) - 1) / factorial(n)
                    phi[k] += w * (pain_fn(S) - pain_fn(S | {k}))
            phi[k] /= max(self.costs[k], 1e-6)
        return phi

    def demote(self, phi, eps=0.0):
        # 只降权/旁路，不自动提权
        return {k for k, v in phi.items() if v < -eps}


# IP-350（v7 主闭环）+ v8 组合入口
def metricvoicegauge_round_8(M, s, obs, audio_stream=None, ell=None,
                             ppm=None, cca=None, mds=None, cra=None):
    # (1) v7 前端：OTL 调节 τ、GCT 解析语音、ER 提取情感与权重
    tau_v7, iota_seq, emo, w_prime = M.v7_frontend(audio_stream, ell)

    # (2) 痛点：只统计 M1-M3
    if ppm is not None:
        for e in M.drain_pain_events(layers=(1, 2, 3)):
            ppm.update(e)
        pi = ppm.pi()
    else:
        pi = M.fixed_severity_prior()          # 退回 v7 注意力

    # (3) 协同混合 + 证书
    if cca is not None:
        u_mix = cca.blend(M.human_command(s), M.robot_command(s))
        u_cmd, ok = cca.cbf_project(u_mix, M.h, M.grad_h)
        required = 4 if not ok else M.required_level(s, u_cmd, pi)
    else:
        u_cmd, required = M.robot_command(s), 0   # A=I，纯自主

    # (5) v7 余下闭环：指标监控 / SpatialCert / 奖励 / 软校准 / ROS 发布
    return M.v7_tail(s, obs, u_cmd, tau_v7, iota_seq, w_prime, pi, level)

## 4. 推导

**引理 77（痛点向量的稳定性）** 设 `J_t` 为定义 527 的痛点估计，遗忘因子 $\gamma\in(0,1)$、Laplace 平滑常数 $\alpha_0>0$、near-miss 权重 $\le 1$。则每步有
```
‖J_t − J_{t−1}‖_∞ ≤ C·(1−γ) + C′/(t+α₀)
```
从而
```
‖π_t − π_{t−1}‖₁ ≤ (2/T)·‖J_t − J_{t−1}‖_∞
```
即优先级向量的变化被遗忘速率与样本量双重限制，不会因单条日志突变。**证明要点**：$J$ 是 $\widehat{freq}\cdot\widehat{sev}\cdot(1-\widehat{rec})$ 的乘积，三项各自对计数是 Lipschitz 的；softmax 对 logits 的 $\ell_1$ 敏感度不超过 $2\|\Delta z\|_\infty$。$\square$

**引理 78（协同证书的凸不变性）** 若安全集 $\mathcal{C}=\{u:h(u)\le0\}$ 凸、$U_h,U_r\subseteq\mathcal{C}$、$A=\mathrm{diag}(a_1,\dots,a_n)$ 且 $a_j\in[0,1]$，则
```
∀ u_h∈U_h, u_r∈U_r : A u_h + (I−A) u_r ∈ C
```
即 `CoopCert(A)` 成立。**证明**：逐坐标看，$u_j=a_j u_{h,j}+(1-a_j)u_{r,j}$ 是 $\mathcal{C}$ 中两点的凸组合；$\mathcal{C}$ 凸 ⇒ 该点属于 $\mathcal{C}$。$\square$

**推论 78′（非凸情形）** 当 $\mathcal{C}$ 非凸时，端点安全不保证混合安全。此时证书只在执行命令上成立：若 CBF 投影可行（$\nabla h\ne0$、步长满足 $h(u_{k+1})\le(1-\eta_{cbf})h(u_k)$），则 `h(u*) ≤ 0`，余量 $\rho>0$。因此工程实现必须区分「包络证书」（凸）与「轨迹证书」（非凸 + CBF），不能混用。

**引理 79（最小充分退化的抖动上界与残余最优性）**
(a) **残余最优性**：若 $\lambda_{sw}=\lambda_{lat}=\lambda_{deg}=0$ 且 v7 的单跳档 $d_{v7}\succeq d_{req}$，则 $J_{res}(d^*)\le J_{res}(d_{v7})$，因为 $d_{v7}$ 在可行域内。
(b) **抖动上界**：设痛点流平稳、单步 $J_{res}$ 波动幅度 $\le\delta$、滞回带 $H$。MSD 只在 `cost(d_prev) − cost(d) > H` 时切换，故单位时间切换次数
```
N_switch ≤ δ/H + O(λ_sw/H)
```
而 v7 单跳规则在每次软违背处切换，无滞回，$N^{v7}_{switch}=\Theta(\text{违背次数})$。取 $\delta<H$ 即可把抖动压到 0，而 v7 仍抖动。$\square$

**引理 80（协同信用的一致性与问责正确性）** Shapley 效率性给出
```
Σ_{k∈M} C_k·φ_k = J(∅) − J(M)
```
即信用总量等于「从空集到全模块」的总痛点下降。若 $\phi_k<0$，则从任意参考集合中移除 $k$ 不会增加痛点期望；因此 CRA 的「负信用即降权」是弱优的。特别地，当 v7 的 ER 误识别使 $J$ 的方差上升、而均值下降不足以抵消时，$\phi_{ER}<0$，CRA 会先降 $\beta$ 再旁路 ER，这正好覆盖第 7 轮点名的情感误识别风险。$\square$

**引理 81（组合退化到 v7）** 若 PPM、CCA/CoopCert、MSD、CRA 全部失效，按定义 533 代入默认值：
```
π←π₀, A←I, d←hard_M0 if required else none, Φ←Φ_v7
```
与第 7 轮的行为逐项相同；再叠加 v7 自身声明，任一 v7 模块失效退回 v6。故 v8 的退化链是「v8 ⇒ v7 ⇒ v6」的偏序，不存在跳跃或旁路。$\square$

**引理 82（M₀ 不可交易）** 定义 527 中 $\mathrm{supp}(\pi_t)\subseteq M_1\cup M_2\cup M_3$，定义 531 的目标函数不含任何奖励 $h(u)>0$ 的项，约束为 $d\succeq d_{req}$ 且 $d_{req}$ 由 `CoopCert` 定义。因此对任意有限痛点改进，优化器都不能以违反 M₀ 作为交换；M₀ 违反只能是估计/执行故障，而不是最优解。$\square$
