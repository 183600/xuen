# 第 1 轮（UniBot 线 · WBC×虚实迁移 子线；本轮灵感：「全身控制」×「虚实迁移」）

> **基线声明**：本文件上一版为 UniBot-SAGE 线（抓取确认 / 技能路由 / 推理期适应）。本轮在其事实与结论之上新开 **BRIDGE 子线**，专注「全身控制 × 虚实迁移」；SAGE 的 U/L/E 编号保留为历史引用，本轮启用新编号 W1–W12、L1–L8、E701–E718。数据事实沿用 2026-11-17 的核实结果；`action.pivot` 语义等未验证项一律标注为「待探测」。

## 0. 本轮一句话

把桌面操作从「手臂在固定基座上的问题」改写为「身体可达性 + 接触动力学」的联合问题：先用虚拟人体与官方真机数据构造身体姿态先验和可校准数字孪生，再给仿真签发「可信证书」，最后部署为「慢身体宏动作 + 快手臂动作 + 安全壳 + 固定基座回退」。

## 1. 直觉解释

### 灵感 1 ·「全身控制」→ 桌面任务的隐藏变量是「身体站在哪里」

人类做桌面任务从来不是只动胳膊：够高处会踮脚或前倾，够侧面会转肩或移步，拧紧会借助身体重量，插入会调整视线与力臂。G1 是有腰、腿、基座的人形机器人，官方接口又暴露了 `action.pivot` 与 `observation.state.lower_body`，官方 WBT 数据还提供了 SMPL 人体全身动作。多数 VLA 只输出 arm + gripper，等于把一个可用的「慢自由度」冻结了。

但全身动作不是手臂动作的简单扩展：它慢、危险、难学。移动基座可能撞桌、失去支撑、打断视觉闭环，而且评测端是否真的跟踪 pivot 仍未知。因此本文不把全身控制做成端到端大动作，而把它当成**宏观决策**：只有当身体动作能扩大任务相关可行集、改善视线或增加力臂，且安全裕度足够时才执行；否则保持固定基座。

### 灵感 2 ·「虚实迁移」→ 不是「sim 训练再上真机」，而是「双向校准 + 可信域」

真实数据只有 32 个任务、约 32k episodes / 169 h，真机时段稀缺，纯真机试错不可行。纯仿真训练又会在接触丰富任务上过拟合仿真伪影：摩擦、间隙、质量、相机、延迟、物体网格。正确的形态是双向的：

- **实 → 虚**：用官方真机数据标定仿真参数（摩擦、质量、阻尼、延迟、相机外参），得到参数后验，而不是一个拍脑袋的仿真。
- **虚 → 实**：在标定后的仿真中训练、筛选、做消融，再用少量真机锚点校正，并给仿真签发「现实差距证书」。
- 另一层「虚实」是**虚拟人 → 真实机器人**：SMPL 人体动作是「虚拟人」，G1 是「实机」。人体先验用来补足机器人数据中罕见的全身姿态，而不是直接模仿人体动作。

### 合成：UniBot-BRIDGE

**BRIDGE = Body-aware Reachability + Identified Digital-twin Gap Estimation**（身体感知可达性 + 可辨识数字孪生差距估计）。

1. 先探测 `action.pivot` 是否真的被执行（零成本，决定整条线是否成立）；
2. 离线构建任务条件化的身体可达性 / 可操作度 / 可见性地图；
3. 用 SMPL 人体数据学习「手部目标 → 身体姿态」先验；
4. 用官方真机数据标定数字孪生，输出参数后验；
5. 用「现实差距证书」决定仿真能否参与训练与选型；
6. 部署为「慢身体宏动作 + 快手臂动作」的分层策略，带安全壳与固定基座回退。

## 2. 事实与不确定性

沿用上一轮已核实的事实：

1. UniBot-V1 为通才模型赛道，基于 Unitree G1 真机，32 项桌面操作任务，按平均成功率 + 平均步骤分排名，覆盖 5 类泛化场景；选手自行部署策略服务，评测端通过标准化 API 远程接入。
2. 提交接口暴露 `control_space ∈ {joint, ee}`、`action_chunk_size`、`obs_delta_indices`、`image_resize`；`action.pivot`（7 维）与 `observation.state.lower_body`（15 维）存在；token 在 `metadata` 与每步 `meta.token` 两处校验；评测在 N 台真机上随机顺序执行，必须暴露连续端口。
3. 官方明确会采集 per-step 延迟及其波动、返回动作的统计规律性，并可能据此评估结果可信度。
4. 官方数据集是 32 个 LeRobot v3.0 数据集，约 32k episodes、169 h，G1 + Dex1，4 路 480×640@30fps 相机；另有 WBT SMPL 全身遥操数据。
5. 榜单 `leaderboard_data.json` 是 teaser / 占位表（`gen_leaderboard.py` 随机生成、官方尚未正式发布），其字段结构与任务名可作规格参考，但**不能当作官方终稿数字**。

本轮必须先补齐的不确定性（按优先级）：

| 编号 | 不确定性 | 为什么致命 |
|---|---|---|
| U1 | `action.pivot` 的量纲、符号、死区、跟踪延迟、是否被评测端使用；`lower_body` 是关节角还是别的表示 | 若 pivot 不被跟踪，全身控制主线退化为上半身姿态 |
| U2 | 评测器是否允许移动基座；移动后 `reset()` 是否复位；多端口是否共享同一物理场景 | 直接决定动作空间与安全边界 |
| U3 | WBT 数据与 32 任务的重叠程度；SMPL → G1 的自由度映射与手型差异 | 决定人体先验能否迁移 |
| U4 | 官方数据中身体运动的激励是否充分（若 90% 时间基座不动，先验价值要打折） | 决定 W4 是否值得投入 |
| U5 | MuJoCo / Isaac 与真实 G1 的接触参数可辨识性；官方是否提供 URDF / 场景 | 决定数字孪生能否签发证书 |

**结论：本轮必须先做「零成本探测 + 离线可达性分析」，再决定是否训练全身策略。**

## 3. 瓶颈在哪里

- **瓶颈 A · 固定基座浪费可达性**：桌面边缘、高处、低处、侧面目标可能不在手臂舒适工作空间内；插入类任务还需要更好的视线与力臂。固定基座策略把这些任务都当成「手臂够不够长」的问题，而人形机器人本来有腰腿。
- **瓶颈 B · 全身动作的安全与信用**：移动基座会改变支撑多边形，带来摔倒与碰撞风险；评测端是否跟踪 pivot 未知；动作太大还可能被判定为不规则交互。
- **瓶颈 C · 仿真的接触差距**：插入、旋转、抓取释放对摩擦、间隙、延迟极敏感；未标定仿真的策略排序可能与真机不一致，导致「在 sim 里涨点、在真机上掉点」。
- **瓶颈 D · 数据中的身体运动稀疏**：若官方数据以固定基座为主，人体先验只能作为正则项，不能作为主监督；否则会学到与任务无关的姿态。
- **瓶颈 E · 延迟与并发**：全身策略增加计算与通信；N 端口并发下必须保持 p99 预算，否则可信度受损。

## 4. 研究问题

- **Q1（身体到底值多少）**：在 32 个任务中，允许 pivot / 腰腿运动相对固定基座，能扩大多少「任务相关可达集」与可操作度？哪些任务簇收益最大？
- **Q2（虚拟人先验能否迁移）**：SMPL 人体全身姿态能否经运动学重定向，成为 G1 的「手部目标 → 身体姿态」先验？其收益是否超过随机姿态或固定姿态？
- **Q3（数字孪生是否可信）**：仅用官方真机数据，能否标定出足以做「策略排序」的仿真？需要多少锚点数据？如何给出可信证书？
- **Q4（sim2real 的兑现率）**：在标定仿真中训练 / 筛选的全身策略，迁到真机能兑现多少？相对真机-only 微调的样本效率如何？
- **Q5（安全与合规）**：pivot 是否被允许 / 跟踪？如何保证不摔倒、不撞桌、不违反「单模型单 API」？固定基座回退的代价是多少？

## 5. 设计原则

- **P1 身体是慢执行器**：身体宏动作只在 chunk 边界更新，频率 ≤ 手臂的 1/K；手臂策略以身体状态为条件。
- **P2 可达性优先**：只有当身体动作扩大任务相关可行集、改善视线 / 力臂，且安全裕度足够时才执行；否则不动。
- **P3 双向迁移**：任何仿真结论必须带真实锚点与差距证书；没有证书的仿真只能做机制测试，不能做调参依据。
- **P4 安全壳优先**：支撑多边形、CoM/ZMP、关节 / 速度 / 加速度限幅、碰撞禁区；违反即回退。
- **P5 固定基座是合法特例**：`b = b0` 始终在假设空间内；探测失败或置信度低时自动退回。
- **P6 合规与可审计**：单 checkpoint、单 API、不读评测侧私有信息；pivot 使用有日志、可关闭、可回滚。

## 6. 最小可提交闭环（MVP）与退化链

**MVP = W1（pivot 探测） + W2（任务相关可达性地图） + W5（真机数据标定数字孪生） + W6（现实差距证书） + 固定基座基线。**

理由：W1 决定整条线是否成立；W2 给出「值不值得动身体」的离线上界；W5/W6 决定仿真能否参与迭代；固定基座基线保证永远有可提交形态。

**严格退化链（任一环节不可用 ⇒ 行为回退而非漂移）：**

- L0：pivot 不被跟踪或语义不明 ⇒ 只做上半身 / 腰部姿态（若可用），否则固定基座；
- L1：可达性预测置信度低 ⇒ 不移动身体，退回固定基座；
- L2：数字孪生标定失败或证书不通过 ⇒ 禁用仿真选型，只用真机 A/B；
- L3：安全壳触发（CoM / 碰撞 / 关节极限）⇒ 立即回到最近安全姿态并冻结身体动作；
- L4：全身链路整体失效 ⇒ 提交纯固定基座基线，保证能跑通、可信度合规。

## 7. 预期贡献（可验收）

1. **首个把「身体可达性」显式写进 UniBot 桌面操作策略的研究**：给出任务条件化可达性地图与「身体宏动作」触发准则，量化固定基座 vs 全身控制的收益差。
2. **一个虚拟人 → 真实人形机器人的姿态先验迁移方法**：用 SMPL WBT 数据学习姿态先验，并量化形态差异、手型差异带来的损失。
3. **一个「实 → 虚 → 实」的可信迁移协议**：参数后验、锚点标定、现实差距证书，明确仿真可用于什么、不可用于什么。
4. **全身安全壳与固定基座回退**：让全身控制从「高风险炫技」变成「可提交的增量」。
5. **可复用的探针与审计工具**：pivot 响应矩阵、延迟 / 平滑 / 稳定性报告、N 端口并发与状态隔离自检。

## 8. 下一轮迭代计划

- **深化**：先做 W1 探针与 W2 可达性地图；用官方 WBT 数据统计身体运动分布，决定 W4 是否值得投入；W5 先做单任务数字孪生，验证参数可辨识性。
- **修剪预案**：若 W1 显示 pivot 无效，砍掉 WBC 主线，把资源转到 W5/W6 的仿真评测与 SAGE 的抓取 / 技能线；若 W5 标定后差距证书仍不通过，仿真只保留机制测试功能。
- **保留项**：W1（信息价值最高）、W2（决定全身控制是否有意义）、W5/W6（决定仿真能否参与迭代）在任何情况下不砍。

## 9. 本轮最大风险

**一句话**：如果 `action.pivot` 在评测端根本不被跟踪，或移动身体带来的摔倒 / 碰撞风险超过可达性收益，那么整条「全身控制」主线会退化为一个昂贵的上半身姿态先验；而「虚实迁移」的可信证书又可能因为真机锚点太少而无法签发。

## 0. 本轮结论摘要

**一句话路线**：先用零成本探针确认 `action.pivot` 是否真的可执行；再用离线可达性地图回答「身体值多少」；用官方真机数据把仿真标定成「数字孪生」，并用现实差距证书规定它只能在可信域内参与决策；最后部署「慢身体宏动作 + 快手臂动作 + 安全壳 + 固定基座回退」。

**三条待验证的量化假设（预注册）**：

| 假设 | 内容 | 预注册门槛 |
|---|---|---|
| H1 | 对边缘 / 高 / 低 / 遮挡任务，允许身体宏动作能显著扩大任务相关可达集 | 任务相关可达体积 ≥ +20%，成功率相对提升 ≥ +10% |
| H2 | SMPL 人体姿态先验相对随机 / 固定姿态，能降低少样本身体动作的 IK 失败率 | IK 失败率相对下降 ≥ 30%，且不增加关节极限违规 |
| H3 | 用官方真机数据标定后的仿真，其策略排序与真机一致 | 锚点任务上 Spearman ≥ 0.6；未标定仿真 < 0.3 |

**合规红线**：单 checkpoint、单 API；不读评测侧私有信息；pivot 可关闭；所有身体动作有安全壳；仿真只作训练与内部评测，不替代真机结论。

## 2. 创新点详述

### W1 · BodyProbe 全身动作语义探针（P0）

- **动机**：官方 README 暴露 `action.pivot` 与 `observation.state.lower_body`，但未说明 pivot 的量纲、符号、死区、跟踪延迟、是否被评测端执行、reset 是否复位。**在不知道这些语义前训练全身策略，等于在未知动作空间里做盲优化。**
- **与现有方案的差异**：多数队伍要么假设 pivot 可用并直接输出，要么完全忽略它；本文先做**系统辨识式探针**，把「动作是否被跟踪」变成可测事件。
- **技术可行性**：高。只需官方 client + 一个安全真机时段，发送小幅、慢速、限幅的 pivot 指令，观察 `lower_body`、EE 位姿、基座姿态与相机视角是否随之变化。
- **所需资源**：无训练；一个真机探测时段；脚本与日志。
- **落地步骤**：
  1. 读取 `metadata` 与观测 schema，确认 `action.pivot`、`lower_body` 的维度与键名；
  2. 在 `reset()` 后保持手臂不动，逐轴发送 ±ε 的 pivot 阶跃与斜坡；
  3. 记录响应矩阵 `A_p = ∂observed_body / ∂commanded_pivot`、死区、饱和、延迟、回差；
  4. 测试 `reset()` 是否把身体复位；测试不同端口是否独立；
  5. 若响应矩阵秩不足或全零，判定 pivot 不可用，冻结 WBC 主线；
  6. 输出《pivot 语义报告》，作为 W2/W3/W8 的输入。
- **风险**：探针本身可能扰动场景或被判为不规则交互 ⇒ 幅度极小、单次、预注册；若赛制不允许主动探测，则退化为被动观测统计。

### W2 · ReachMap 任务相关可达性地图（P0）

- **动机**：全身控制的收益不能靠直觉，必须离线量化「身体移动后，目标点是否进入可达 / 可操作 / 可见区域」。这是决定 W3 是否值得做的上界分析。
- **与现有方案的差异**：常见做法是给机器人一个通用工作空间图；本文做**任务条件化**：目标点来自官方数据中每个任务的实际物体位置与操作方向，效用函数同时考虑可达、可操作度、相机可见性与安全裕度。
- **技术可行性**：高。G1 URDF + 数值 IK + 官方数据中的物体 / 末端轨迹即可完成；不需要真机。
- **所需资源**：CPU 集群数小时到数天；无 GPU 训练也可先做规则版。
- **落地步骤**：
  1. 解析 G1 URDF，确认腰 / 腿 / 基座自由度与关节限位；
  2. 从官方 episodes 提取每个任务的目标点云、末端轨迹、相机外参；
  3. 在身体姿态网格 `b` 上做蒙特卡洛 IK，统计可达目标比例、可操作度、可见性、碰撞与稳定性；
  4. 定义任务相关效用 `U_task(b)`，训练轻量预测器 `Û(o_task, b)`；
  5. 用留出 episodes 与任务簇交叉验证，输出「哪些任务值得动身体」的排序；
  6. 把地图与 W1 的 pivot 响应矩阵结合，得到**可执行**而非理想化的可达性。
- **风险**：URDF 与真机不一致；目标点提取噪声；可达 ≠ 成功 ⇒ 用真机 A/B 校准代理，不把地图当终局结论。

### W3 · BodyMacro 慢身体宏动作策略（P1）

- **动机**：全身动作慢且危险，不适合和手臂动作同频端到端输出；应作为**慢执行器**，在 chunk 边界改变身体构型，让手臂策略在更好的工作空间里做快速闭环。
- **与现有方案的差异**：不是「一个更大的全身 VLA」，而是「离散身体宏动作库 + 任务条件化选择 + 手臂条件策略」；宏动作可解释、可限幅、可回退。
- **技术可行性**：中。需要 W1 确认 pivot 可用、W2 给出效用、W8 提供安全壳。
- **所需资源**：轻量选择器（小 MLP / 决策树）+ 官方数据伪标 + 少量真机 A/B。
- **落地步骤**：
  1. 定义宏动作库 `M = {stay, lean_forward, lean_back, shift_left, shift_right, lower, raise, rotate_left, rotate_right}`；
  2. 用 W2 的效用与 W8 的安全裕度给每个宏动作打伪标签；
  3. 训练选择器 `π_b(m|o, ℓ)`，只在 `U` 增益超过阈值且安全时允许非 `stay`；
  4. 在 chunk 边界执行宏动作，保持 K 步不变；手臂策略以 `(b, m)` 为条件；
  5. 加入驻留时间与迟滞，防止身体来回抖动；
  6. 真机 A/B：固定基座 vs 宏动作，按任务簇分层。
- **风险**：宏动作太粗，收益被离散化吃掉；身体动作延迟导致错过操作窗口；评测端忽略 pivot ⇒ 由 W1 提前拦截。

### W4 · Human2G1 虚拟人姿态先验（P1）

- **动机**：官方 WBT 数据提供 SMPL 24 节点人体全身动作，包含机器人数据中罕见的弯腰、侧身、踮脚、转身等姿态。直接模仿人体动作不可行，但可以学习「给定手部目标与任务，人体通常把身体放在哪里」的先验。
- **与现有方案的差异**：不是 human motion imitation，而是**跨具身姿态先验**：SMPL → G1 的运动学重定向 + 残差学习；人体数据只作为正则 / 初始化，不作为动作标签。
- **技术可行性**：中。需要处理 SMPL 与 G1 的自由度、肢体长度、手型差异；Dex1 与人体手差异大，故只迁移身体姿态，不迁移手指。
- **所需资源**：小映射网络；官方 WBT 数据；无额外真机。
- **落地步骤**：
  1. 解析 SMPL 轴角与全局位移，筛选与桌面操作相关的片段；
  2. 用 IK 把人体手部目标重定向到 G1 末端，求解身体姿态，记录残差；
  3. 训练 `p_h(b | hand_target, task_cluster)`，输出姿态分布而非单点；
  4. 在 W3 的选择器中作为先验 / 正则，低置信时退回均匀或 `stay`；
  5. 消融：人体先验 vs 随机姿态 vs 固定姿态 vs 纯数据先验。
- **风险**：形态差异导致负迁移；WBT 任务与 32 任务不重叠；人体姿态在机器人上不可行 ⇒ 必须用可行性与安全壳过滤。

### W5 · Real2Sim 数字孪生标定（P0）

- **动机**：真机时段稀缺，仿真必须参与迭代；但未标定的仿真会给出错误排序。官方 32 个数据集提供了真实轨迹、相机与接触结果，足以做**数据驱动的系统辨识**。
- **与现有方案的差异**：不是「建一个看起来像的仿真」，而是「从真机数据反推参数后验」，并明确哪些参数可辨识、哪些不可辨识。
- **技术可行性**：中–高。MuJoCo / Isaac 均可；难点是物体网格、接触模型与相机对齐。
- **所需资源**：GPU / CPU 优化；官方数据；仿真环境。
- **落地步骤**：
  1. 搭建 G1 + 桌面 + 物体的仿真场景，优先选 3–5 个接触特征明显的任务；
  2. 从官方数据提取初始状态、动作序列、物体位姿、相机图像；
  3. 选择待标定参数 `θ`：摩擦系数、物体质量、阻尼、关节摩擦、控制延迟、相机外参；
  4. 用贝叶斯优化 / CMA-ES / 可微仿真最小化轨迹与接触时序误差；
  5. 输出后验 `p(θ|D_real)`，报告可辨识性与参数相关性；
  6. 在留出 episodes 上验证，不通过则标记「仅机制测试」。
- **风险**：物体网格不可得；接触模型本身错误；参数不可辨识 ⇒ 用后验而非点估计，并降低仿真结论的权重。

### W6 · GapCert 现实差距证书（P0）

- **动机**：仿真最大的风险不是「不准」，而是「不知道自己不准」。需要一个显式机制决定仿真能否参与训练 / 选型。
- **与现有方案的差异**：把「sim-to-real gap」从一个模糊口号变成**可签发、可拒绝、可审计**的证书；没有证书的仿真不允许用于调参。
- **技术可行性**：中。需要一组真机锚点任务与指标，计算仿真与真实的排序一致性。
- **所需资源**：少量真机锚点；W5 的后验；统计工具。
- **落地步骤**：
  1. 定义锚点任务簇与指标（成功率、接触时序、物体位移、插入深度）；
  2. 在参数后验下多次评估候选策略，得到仿真指标的分布；
  3. 用真机锚点估计真实指标与排序；
  4. 计算 Spearman / Kendall 相关与置信区间，签发「可信 / 仅机制测试 / 不可用」三档证书；
  5. 证书随任务簇、策略族、参数后验变化，定期复检。
- **风险**：锚点太少导致证书无统计功效；分布偏移使证书过期 ⇒ 证书只覆盖已测任务簇，不跨簇外推。

### W7 · Sim2Real 标定域内鲁棒迁移（P1）

- **动机**：有了标定仿真与证书，仍需把策略迁到真机；纯 sim 策略会在未建模接触上失败。
- **与现有方案的差异**：随机化不是「越大越好」，而是**在参数后验内随机化**；真机数据只用于小适配器与残差校正，避免破坏仿真学到的结构。
- **技术可行性**：中。需要 W5/W6 通过。
- **所需资源**：GPU 训练；少量真机微调。
- **落地步骤**：
  1. 在 W5 后验内采样 `θ` 做域随机化，视觉侧另加相机 / 光照 / 背景扰动；
  2. 用 privileged teacher（仿真中的物体位姿 / 接触力）蒸馏 student（仅用部署观测）；
  3. 真机上只更新小型适配器（≤1% 参数），带 trust-region 与回滚；
  4. 用 W6 证书筛选超参，禁止用未认证的仿真指标做终选；
  5. 与真机-only 微调做样本效率对比。
- **风险**：仿真过拟合；真机适配过拟合；负迁移 ⇒ 保留固定基座 / 纯真机基线作为回退。

### W8 · SafetyShell 全身安全壳（P0）

- **动机**：全身动作一旦摔倒或撞桌，代价远高于手臂动作；安全不能只靠策略学习。
- **与现有方案的差异**：显式安全层，独立于策略；所有身体宏动作必须通过安全掩码。
- **技术可行性**：高。基于支撑多边形、CoM、关节限位、碰撞距离与速度 / 加速度约束即可做规则版。
- **所需资源**：极小；可在线运行。
- **落地步骤**：
  1. 从 URDF 与观测估计 CoM、支撑多边形、ZMP 近似；
  2. 定义安全裕度 `S(b) = min(CoM 到支撑边界距离, 关节限位裕度, 碰撞距离, 速度裕度)`；
  3. 对每个宏动作做前向安全检查，不通过则替换为 `stay`；
  4. 在线监测摔倒 / 大加速度 / 关节异常，触发即回退到最近安全姿态；
  5. 记录所有触发事件，进入审计。
- **风险**：安全壳过保守导致完全不移动身体；模型误差导致误判 ⇒ 先用仿真 + 小幅度真机验证，逐步放开。

### W9 · AuditBody 全身可审计层（P2）

- **动机**：官方会看延迟、动作统计规律性与可信度；全身控制引入新的风险面（pivot 使用、回退、抖动），需要可导出证据。
- **与现有方案的差异**：把可信度要求变成工程产物，而不是赛后解释。
- **技术可行性**：高（工程活）。
- **所需资源**：极小。
- **落地步骤**：延迟直方图、pivot 使用率、宏动作切换次数、安全触发次数、chunk 边界 jerk、N 端口并发与 `reset()` 隔离报告；支持一键导出。

## 3. 符号与定义（W1–W12）

| 符号 | 含义 |
|---|---|
| `b` | 身体构型：基座位姿 + 腰 / 腿 / 下身关节的子集 |
| `b0` | 固定基座 / 安全默认构型 |
| `m` | 身体宏动作，`m ∈ M` |
| `K` | 身体宏动作的更新周期（每 K 个手臂步） |
| `U_task(b)` | 任务相关身体效用（可达 / 可操作 / 可见 / 安全） |
| `A(o, b)` | 身体可负担性：是否可行 + 效用 |
| `π_b` | 身体宏动作选择器 |
| `π_a` | 以身体为条件的手臂策略 |
| `T(·)` | SMPL → G1 的姿态重定向映射 |
| `p_h` | 人体姿态先验 |
| `θ` | 仿真物理 / 传感参数 |
| `p(θ|D_real)` | 由真机数据得到的参数后验 |
| `G(π, C)` | 策略 `π` 在任务簇 `C` 上的现实差距证书 |
| `S(b)` | 安全裕度 |

**定义 W1（身体构型）** `b_t = (p_base, R_base, q_torso, q_lower) ∈ R^{d_b}`，其中 `p_base, R_base` 为基座位姿，`q_torso, q_lower` 为腰 / 下身关节；`b` 是 `action.pivot` 与 `observation.state.lower_body` 中可执行部分的子集。

**定义 W2（身体宏动作）** `m_k ∈ M` 是离散、慢速、可限幅的身体动作原语，在时间区间 `[kK, (k+1)K)` 内保持不变；`K ≥ 1` 且受最小驻留时间约束。

**定义 W3（任务相关身体效用）**
`U_task(b) = w1·V_reach(b) + w2·M_manip(b) + w3·V_vis(b) − w4·C_collision(b) − w5·C_stability(b)`，
其中 `V_reach` 为目标点可达比例，`M_manip` 为可操作度，`V_vis` 为相机可见性，`C_collision` 与 `C_stability` 为碰撞与失稳惩罚；权重由任务簇校准。

**定义 W4（身体可负担性）** `A(o, b) = (feasible(o,b), U_task(b))`，`feasible` 由关节限位、碰撞、支撑多边形与 W1 的 pivot 响应模型共同判定。

**定义 W5（身体宏动作策略）** `π_b(m | o, ℓ) = softmax(Q(o, m; ℓ) / τ)`，且 `m ≠ stay` 仅当 `U_task(b_m) − U_task(b0) > Δ_U` 且 `S(b_m) > S_min`。

**定义 W6（条件手臂策略）** `π_a(a_{t:t+T_a} | o, ℓ, b, m)`：手臂 / 夹爪动作块以身体构型与宏动作为条件，不直接输出全身关节。

**定义 W7（跨具身重定向）** `T: (SMPL pose, hand target) → (b, residual)`，残差表示人体与 G1 在肢体长度、关节限位、手型上的不可消除差异。

**定义 W8（人体姿态先验）** `p_h(b | hand_target, task_cluster)`：从 WBT 数据经 `T` 得到的身体构型分布，用作 W3 的初始化或正则。

**定义 W9（仿真参数后验）** `p(θ | D_real) ∝ p(D_real | θ) p(θ)`，`θ` 包含摩擦、质量、阻尼、延迟、相机外参等；后验而非点估计是 W6 的基础。

**定义 W10（现实差距证书）** 对策略 `π` 与任务簇 `C`，
`G(π, C) = P_{θ ~ p(θ|D_real)}( rank_sim(π; θ) = rank_real(π) on anchors )`；
当 `G ≥ 1 − δ` 时签发「可信」，当 `G` 处于中间区间签发「仅机制测试」，否则「不可用」。

**定义 W11（安全裕度）** `S(b) = min( d_CoM(b), d_joint(b), d_collision(b), d_vel(b) )`，各分量归一化到 `[0,1]`；`S(b) < S_min` 的动作被安全壳拒绝。

**定义 W12（回退规则）** 若 `A(o,b)` 不可行、`S(b) < S_min`、或 W1 判定 pivot 不可用，则令 `b = b0`，`m = stay`，并记录一次回退；回退不改变手臂策略的基线行为。

# ===== UniBot-BRIDGE 策略服务：单 checkpoint、单 API、每端口隔离 =====
class UniBotBRIDGEPolicy:
    def __init__(self, ckpt, tau_budget_ms=105, K=8):
        self.model = load_single_checkpoint(ckpt)   # 手臂/夹爪主干 + 身体条件头
        self.reach = ReachMap.load("reachmap.pt")   # W2: U_task(b)
        self.body = BodyMacroSelector()             # W3: π_b(m|o,ℓ)
        self.human = HumanPrior.load("human2g1.pt") # W4: p_h(b|hand,task)
        self.safety = SafetyShell()                 # W8: S(b)
        self.audit = AuditBody()                    # W9
        self.sessions = {}                          # 每端口一份状态
        self.pivot_ok = None                        # W1 探针结果：None/True/False
        self.K = K

    @property
    def metadata(self):
        return {
            "control_space": "joint",
            "obs_delta_indices": {
                "observation.language": [0],
                "observation.images.cam_left_high": [0],
                "observation.images.cam_right_high": [0],
                "observation.images.cam_left_wrist": [-2, 0],
                "observation.images.cam_right_wrist": [-2, 0],
                "observation.state.left_arm": [-4, -2, 0],
                "observation.state.right_arm": [-4, -2, 0],
                "observation.state.left_ee_pose_gripper_base": [-2, 0],
                "observation.state.right_ee_pose_gripper_base": [-2, 0],
                "observation.state.left_gripper": [-2, 0],
                "observation.state.right_gripper": [-2, 0],
                "observation.state.lower_body": [-2, 0],
            },
            "image_resize": {
                "observation.images.cam_left_high": [240, 320],
                "observation.images.cam_right_high": [240, 320],
                "observation.images.cam_left_wrist": [240, 320],
                "observation.images.cam_right_wrist": [240, 320],
            },
            "action_chunk_size": 8,
            "token": os.environ["UNIBOT_SUBMISSION_TOKEN"],
        }

    def reset(self, port=None):
        self.sessions.setdefault(port, Session()).reset()

    def get_action(self, obs, port=None):
        s = self.sessions[port]
        t0 = time.perf_counter()

        # W1: 未通过探针时，绝不输出身体动作
        if self.pivot_ok is not True:
            return self.arm_only(obs, s, t0)

        # 身体宏动作只在 chunk 边界更新（慢执行器）
        if s.step % self.K == 0:
            m = self.body.select(obs, self.reach, self.human, self.safety)
            b = self.body.to_config(obs, m)
            if not self.safety.passes(b) or not self.reach.feasible(obs, b):
                m, b = "stay", self.body.default_config(obs)
                self.audit.mark_fallback("unsafe_macro")
            s.macro, s.body = m, b
        s.step += 1

        # W6: 仅使用通过证书的任务簇；否则退回固定基座
        task = self.task_cluster(obs["observation.language"])
        if not self.gap_certified(task):
            s.macro, s.body = "stay", self.body.default_config(obs)

        # W6: 条件手臂策略
        a = self.model.act(obs, task=task, body=s.body, macro=s.macro,
                           chunk=self.chunk_len(obs))
        a = self.safety.clamp_arm(a, obs)
        a = self.audit.log_and_pack(a, obs, t0, self.tau_budget_ms)
        return a

    def arm_only(self, obs, s, t0):
        a = self.model.act(obs, task=self.task_cluster(obs["observation.language"]),
                           body=self.body.default_config(obs), macro="stay",
                           chunk=self.chunk_len(obs))
        a = self.safety.clamp_arm(a, obs)
        return self.audit.log_and_pack(a, obs, t0, self.tau_budget_ms)

# ===== W1: pivot 语义探针（离线脚本，不进入在线策略）=====
def probe_pivot(client, eps=0.02, steps=20):
    report = {}
    for axis in range(7):
        for sign in (+1, -1):
            client.reset()
            base = client.observe()
            for _ in range(steps):
                cmd = np.zeros(7, dtype=np.float32)
                cmd[axis] = sign * eps
                obs = client.step({"action.pivot": cmd[None]})
            after = obs
            report[(axis, sign)] = {
                "d_body": delta_lower_body(base, after),
                "d_ee": delta_ee(base, after),
                "d_img": delta_image(base, after),
            }

def calibrate_and_certify(real_episodes, sim_factory, anchors):
    # 1) 先验与参数空间
    prior = default_physics_prior()
    # 2) 贝叶斯优化 / CMA-ES，最小化轨迹与接触时序误差
    posterior = fit_posterior(sim_factory, real_episodes, prior)
    # 3) 在锚点任务上比较策略排序
    sim_scores = []
    for theta in sample(posterior, n=64):
        sim = sim_factory(theta)
        sim_scores.append([evaluate(sim, p, anchors) for p in policies])
    sim_rank = aggregate_rank(sim_scores)
    real_rank = real_anchor_rank(anchors, policies)
    rho = spearman(sim_rank, real_rank)
    if rho >= 0.6:
        return "trusted", rho, posterior
    if rho >= 0.3:
        return "mechanism_only", rho, posterior
    return "untrusted", rho, posterior

## 5. 推导（引理 L1–L8）

**引理 L1（可达性单调性）** 设 `b'` 相对 `b` 不缩小任务相关可达集、不降低可见性与安全裕度、且不增加碰撞惩罚，则 `U_task(b') ≥ U_task(b)`；在「目标可达是成功必要条件」的假设下，`P(success|b') ≥ P(success|b) − ε_cost`，其中 `ε_cost` 为身体运动本身的执行误差。若 `ε_cost` 可忽略，则身体扩展不会伤害成功率；若不可忽略，必须先满足 `ΔU > ε_cost` 才切换。∎

**引理 L2（时间尺度分离的稳定性）** 若身体宏动作每 `K` 步更新一次，`K > τ_body / τ_arm`（`τ_body, τ_arm` 分别为身体与手臂闭环时间常数），且每一步 `S(b) ≥ S_min`，则在有界扰动下，耦合系统的 CoM 偏差上界由 `S_min` 与最坏扰动决定，不随 `K` 增大而发散。反之，若 `K` 太小，身体与手臂闭环相互激励，可能出现抖动。∎

**引理 L3（跨具身误差分解）** 对任意人体姿态到 G1 的重定向，误差可分解为 `e ≤ e_kin + e_dyn + e_contact`：`e_kin` 来自肢体长度 / 关节限位 / 手型差异，`e_dyn` 来自质量 / 惯量差异，`e_contact` 来自接触刚度与摩擦差异。由于 `e_kin` 在重定向时可直接测量，故人体先验只能作为正则项，且其权重应随 `e_kin` 增大而减小。∎

**引理 L4（仿真参数可辨识性）** 设真机数据对参数的 Fisher 信息矩阵为 `I(θ)`。若 `I(θ)` 满秩且激励持续，则 `θ` 局部可辨识，后验收缩到点；若 `I(θ)` 亏秩（例如物体从未被推动、摩擦从未被激励），则只能得到某些方向上的预测分布，不能声称「标定完成」。因此 W5 必须报告可辨识方向，W6 必须把不可辨识方向纳入证书。∎

**引理 L5（差距证书的排序保证）** 若在锚点任务上，对任意候选策略 `π` 有 `|metric_sim(π) − metric_real(π)| ≤ ε`，且真实前两名之间的间隔 `Δ > 2ε`，则仿真排序与真实排序一致。若只要求概率保证，则用参数后验对 `ε` 积分，得到 `P(rank 一致) ≥ 1 − δ`，即 W10 的证书定义。∎

**引理 L6（固定基座回退不劣于基线）** 若 `b0` 始终在假设空间内、选择器仅在 `U_task(b_m) − U_task(b0) > Δ_U` 且 `S(b_m) > S_min` 时切换、并且切换失败可立即回退，则最坏情况下系统等价于固定基座基线，额外代价仅为选择器与安全壳的推理开销；估计误差可能造成有限损失，故需 `Δ_U` 大于估计误差上界。∎

**引理 L7（延迟摊销）** 身体宏动作每 `K` 步计算一次，若单次身体推理耗时为 `C_body`，则摊到每步的平均开销为 `C_body / K`；只要 `C_body / K + C_arm ≤ B`（`B` 为每步预算），p99 延迟不会被身体模块显著推高。对于 `K = 8`，身体开销被摊薄一个数量级。∎

**引理 L8（人体先验的收益上界）** 设人体姿态分布与 G1 可行姿态分布的重叠为 `Ω`，则人体先验带来的期望收益上界与 `Ω` 成正比，负迁移风险与 `1 − Ω` 成正比。若 WBT 数据与目标任务的身体运动分布重叠不足（例如官方数据几乎不移动基座），则 W4 的收益上界很低，应降级为正则项或直接砍掉。∎
