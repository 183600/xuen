# 第 8 轮（灵感循环第 2 轮；本轮灵感：「传感器标定」×「具身智能大模型」）
> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> **本轮纪律**：**标定即证据 + 提案非权威 + 双层校准接地**。不把“更大的模型”当作免费能力，也不把“标定过”当作一次性事实；任何来自具身大模型的计划，都必须先通过由标定协方差与标定有效期给出的物理契约，才能进入指标层级与安全证书。

## 0. 直觉与动机

**灵感 1（传感器标定 → 把“我有多信自己的传感器”变成一等证据）**
直觉：v7 把 τᵢ、SpatialCert、GCT 都建立在“观测是对的”之上，但标定从来不是一个布尔值：外参有协方差，时间同步有偏移，温度与负载会让零点漂移，某些自由度在当前场景下根本不可观。标定更像一张**有适用范围、有有效期、有不确定度的许可证**，而不是一个永久为真的常量。于是我们把标定状态提升为证书：κ 携带参数、协方差、标定时刻、有效域、漂移模型与可观性掩码；所有空间判据都按 κ 的保守半径膨胀，标定过期/越域/不可观时**冻结自适应并弃权**，而不是继续自信输出。

**灵感 2（具身智能大模型 → 会提计划，但不是权威）**
直觉：VLA/LLM 能把“把红色积木放进左边的盒子”分解成抓取—移动—放置，并给出参数与置信度。但大模型的输出是**语义提案**，不是物理事实：它可能引用标定地图里不存在的物体，可能把不可观自由度当成已知，可能给出类型不合法的技能序列。正确的定位是：大模型只负责**提议**，系统负责**判定**。每个技能都带类型契约（前置/后置条件、所需标定自由度、参数 schema、安全包络、证书义务）；计划只有在所有义务被逐条清偿后才可执行。

**两者合流：双层校准接地（Two-Level Calibration Grounding, TCG）**
物理标定回答“传感器值离真值多远”，语义标定回答“大模型的话离真值多远”。两者共享同一套数学：协方差/区间 + 覆盖率保证 + 保守膨胀 + 弃权。于是我们把 v7 的“价值—行动—反馈—情感”闭环升级为“**标定—提案—义务—证书**”闭环：大模型给出计划，标定给出可信半径，义务给出可检查的中间条件，证书给出可审计的执行许可。目标不是让大模型更聪明，而是让**任何聪明或愚蠢的提案都不能越过 M₀ 硬约束**。

## 1. 研究问题（轮次升级版）

- **Q1（标定传播）**：如何把 Σ_cal、时间同步误差、漂移与可观性，统一传播为指标阈值与空间证书的保守半径，并保证多级组合后仍然 sound？
- **Q2（契约接地）**：如何把开放语义计划编译为可类型检查、可逐条清偿的证书义务，并在不可清偿时确定性修复或弃权？
- **Q3（语义校准）**：如何让大模型的置信度可比较、可覆盖（conformal），避免“高置信但错”的提案进入执行？
- **Q4（冻结与退化）**：标定失效或大模型离线时，如何冻结在线学习、切回脚本技能，并严格退回 v7？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P13）

**P10 标定许可证（Calibration Credential）**
每个传感器/标定链输出许可证而不是常量：
```
κ_m = (θ_m, Σ_m^cal, t_m^cal, D_m, g_m, O_m)
κ_m.valid(t) ⇔ t − t_m^cal ≤ T_life ∧ env(t) ∈ D_m ∧ O_m ⊇ dof_req(skill)
```
其中 D_m 为有效域（温度/负载/距离），O_m 为可观自由度掩码。许可证失效时，依赖它的技能不可准入，而不是“降一点置信度”。

**P11 标定感知膨胀（Calibration-Aware Inflation, CAI）**
把标定不确定度变成安全半径，并显式计入漂移与时间同步：
```
r_cal,m(t) = sqrt(χ²_{d,1−δ}) · sqrt(λ_max(Σ_m^cal))
           + d_m(t − t_m^cal) + v_max · σ_sync,m
τ_i^cal(t) = clip( τ_i + s_i · r_cal,sys(t), ε_min,i, ε_max,i )
C^cal = inflate(C_spatial, r_cal,sys)
```
`s_i = +1` 表示“数值越大越安全”，`−1` 反之。膨胀是保守的、可审计的，且随标定变旧单调变紧。

**P12 类型化技能契约（Typed Skill Contract, TSC）**
大模型输出计划 `π = (s_1,…,s_n)`；每个 `s_k` 必须匹配注册表契约：
```
σ = (name, arg_schema, pre, post, dof_req, envelope, obligations)
```
契约把“语义上说得通”翻译成“物理与类型上可检查”；未匹配、参数越界、前置不满足都直接拒绝或进入修复。

**P13 语义校准与准入闸（Semantic Calibration & Admission Gate）**
用 split conformal 给大模型输出一个带覆盖保证的标签集 `C_α(x)`；准入闸是唯一执行入口：
```
Admit(π, s) ⇔ type_ok ∧ grounded ∧ κ valid ∧ |C_α| = 1（或歧义可解析）
              ∧ obligations_discharged ∧ WCET_est ≤ B_cycle ∧ M₀_preview ok
```
它同时完成三件事：拒绝幻觉、拒绝过期标定、拒绝必然超时/越界的计划。

## 3. 与基线 v7 的接口（如何退化）

- **标定模块失效** ⇒ 冻结 τ 在最后有效值（无有效历史则用 τ(0)），SpatialCert 改用固定安全余量，OTL 停止调节；行为退化为 v7 的固定阈值模式；
- **具身大模型失效** ⇒ 直接使用脚本技能库 `π_script`，等价于 v7 的默认指令序列；
- **语义校准失效** ⇒ 只接受规则/模板的确定性解析，拒绝自由文本提案；
- **三者全部失效** ⇒ 严格等价 MetricVoiceGauge-OTL-GC-ER v7（C3 档）。

## 4. 预期贡献

1. **标定许可证与标定感知膨胀**：把标定不确定度、时效、漂移与可观性统一为可传播的安全半径；
2. **类型化技能契约与计划义务**：把开放语义计划变成可检查、可清偿、可拒绝的证书对象；
3. **语义 conformal 准入闸**：给大模型输出提供边际覆盖率保证与显式弃权机制；
4. **标定触发的 C0–C3 降级阶梯**：标定失效时冻结 OTL，模型失效时切回脚本技能；
5. **实验 E526–E545**：覆盖标定漂移/失步/越域、不可观自由度、幻觉提案、语义覆盖、端到端任务与形式化验证。

## 5. 本轮最大风险

**一句话**：若标定协方差被低估或语义 conformal 的交换性假设被分布漂移破坏，系统可能对“过期标定 + 高置信幻觉”同时给出 certified，把最危险的一类提案恰好放行。

**定义 530（标定许可证 CalibrationCredential）** 标定不是常量，而是带有效性的许可证：
```
κ_m = (θ_m, Σ_m^cal, t_m^cal, D_m, g_m, O_m)
κ_m.valid(t, skill) ⇔ (t − t_m^cal ≤ T_life)
                    ∧ (env(t) ∈ D_m)
                    ∧ (O_m ⊇ dof_req(skill))
```
`θ_m` 可含内外参、手眼变换与时间偏移；`Σ_m^cal` 为其协方差；`O_m` 标记当前场景下可观的自由度。任一条件不满足，依赖该 DoF 的技能即不可准入。

**定义 531（漂移包络 DriftEnvelope）** 用可验证的单调上界覆盖慢漂移：
```
Δ = t − t_m^cal
d_m(Δ) = min( d_max, a_m·Δ + b_m·Δ² )
```
`a_m, b_m, d_max` 由标定实验的置信上界给出，因此 `d_m` 对年龄单调非减。若漂移模型未知，取 `d_m(Δ)=d_max`（最保守）。

**定义 532（标定感知膨胀 CalibrationInflation）** 单模态与系统级保守半径：
```
r_cal,m(t) = sqrt(χ²_{d,1−δ}) · sqrt(λ_max(Σ_m^cal))
           + d_m(t − t_m^cal)
           + v_max · σ_sync,m
r_cal,sys(t) = Σ_{m ∈ chain} r_cal,m(t)          # 最坏链路，三角不等式
```
用 `χ²` 分位数而不是逐维 `z` 分数，直接给出 d 维椭球包含概率 ≥ 1−δ。链路组合对半径求和而非对方差求和，保证未知相关下仍保守。

**定义 533（标定感知阈值 Calibration-Aware Threshold）** 把半径折算为更严格的判据：
```
τ_i^cal(t) = clip( τ_i + s_i · r_cal,sys(t), ε_min,i, ε_max,i )
```
`x ≥ τ_i` 且“越大越安全”时取 `s_i=+1`，要求 `x ≥ τ_i + r_cal`；`x ≤ τ_i` 且“越小越安全”时取 `s_i=−1`，要求 `x ≤ τ_i − r_cal`。两者统一写作 `τ_i^cal = τ_i + s_i r_cal`。

**定义 534（标定感知空间证书 CalibratedSpatialCert）** 空间证书按同一半径膨胀：
```
C^cal = ( inflate(region, r_cal,sys), τ^cal, κ_id, t_cert, δ )
sound(C^cal) ⇔ P( true_target ∈ inflate(region, r_cal,sys) ) ≥ 1 − δ
```
证书必须携带 `κ_id` 与 `t_cert`，使“用哪次标定、在什么时刻得出”可审计；无来源的空间断言不得标为 certified。

**定义 535（类型化技能契约 SkillContract）** 每个可执行技能注册为：
```
σ = (name, arg_schema, pre, post, dof_req, envelope, obligations)
```
`arg_schema` 规定参数类型与范围；`pre/post` 是前置/后置条件谓词；`dof_req` 是执行所需标定自由度；`envelope` 是安全包络；`obligations` 是执行前必须清偿的证书义务集合。

**定义 536（具身大模型计划 FoundationPlan）** 大模型只产生提案：
```
π = (s_1, …, s_n, conf_π, prov)
s_k = (σ_k, args_k, conf_k, prov_k)
```
`prov` 记录模型版本、提示与生成种子（用于审计与回放）。计划不携带任何“可直接执行”的权限。

**定义 537（接地谓词 Grounded）** 语义引用必须在标定地图中落地：
```
grounded(s) ⇔ ∀ ref ∈ refs(s):
    ref ∈ Map_cal ∧ type_match(ref, s) ∧
    region_uncertainty(ref) ≤ r_cal,sys ∧
    region(ref) ⊆ known_free_space
```
`region_uncertainty` 由地图与标定协方差共同给出；不满足则不是“置信度低”，而是**未接地**。

**定义 538（语义 conformal 校准 SemanticConformalCalibration）** 给大模型的标签输出以覆盖保证：
```
E(x, y) = 1 − p_θ(y | x)                      # 非一致性分数
q̂_α = Quantile_{⌈(n+1)(1−α)⌉/n}( {E(x_i, y_i)}_{i=1..n} )
C_α(x) = { y : E(x, y) ≤ q̂_α }
```
在样本可交换假设下 `P(y ∈ C_α(x)) ≥ 1−α`（有限样本、分布无关）。仅当 `|C_α(x)| = 1` 或歧义可由类型/几何约束唯一消解时才允许用于执行。

**定义 539（计划准入闸 PlanAdmissionGate）** 唯一执行入口：
```
Admit(π, s) ⇔ type_ok(π)
            ∧ (∀k: grounded(s_k) ∧ κ.valid(t, s_k))
            ∧ (∀k: |C_α(ref_k)| = 1 或歧义可解)
            ∧ obligations_discharged(π)
            ∧ M₀_preview_ok(π)
            ∧ WCET_est(π) ≤ B_cycle
```
`M₀_preview_ok` 是对计划前向可达集的保守过近似检查；`WCET_est` 含 ASR、编译、准入与执行的最坏估计。准入是必要且充分条件：未准入的计划没有执行路径。

**定义 540（义务清偿与有界修复 ObligationRepair）** 义务与修复动作：
```
Obl(s) = { post_cond, cal_dof, semantic_set, safety_envelope }
Repair(π) ∈ { narrow_args, re_observe, substitute_scripted, abort }
```
每次修复必须严格减小一个良基测度（剩余歧义数 / 可行参数体积），或消耗一次 `K_repair` 预算；因此修复循环有限步终止。

**定义 541（标定降级阶梯 CalibrationDegradationLadder）** 四档运行模式：
```
C0: 标定有效 + 计划被准入（全功能）
C1: 某段计划不可准入 → 该段替换为脚本技能，其余保持
C2: 标定过期/越域/关键 DoF 不可观 → 冻结 OTL，使用 r_cal 膨胀，请求重标定
C3: 标定或语义校准或大模型整体不可用 → v7 单源模式
```
降级立即生效；升级需连续 `N_ok` 个周期满足准入，且 `c_rung` 每次只降一档。

**定义 542（主动重标定 ActiveRecalibration，可选）** 用可观性驱动标定动作：
```
a* = argmax_{a ∈ A_safe} log det( I + Σ_cal^{-1} F(a) )
s.t.  safety_envelope(a) ∧ latency(a) ≤ B_cal
```
`F(a)` 为动作 a 下的 Fisher 信息矩阵。该模块只影响 `Σ_cal` 与 `O_m`，不改变主闭环语义。

**定义 543（标定感知 OTL CalibrationAwareOTL）** 标定无效时冻结自适应：
```
τ_i(t+1) = τ_i(t)                                  if ¬κ.valid
τ_i(t+1) = v7_OTL( τ_i^cal(t), p_robust(t) )       otherwise
```
重标定成功后，以信任斜坡 `ρ_trust(t)` 在 `N_ramp` 周期内从 0 恢复到 1，避免阈值因新标定跳变。

**定义 544（v8 闭环标识 Calibration-Aware Grounding Loop）**：
```
Φ_CAG = ( Φ_v7, κ, r_cal, π, Admit, C_α, c_rung )
c_rung = 3 且 κ/π/C_α 全关时，Φ_CAG ≡ Φ_v7
```

**定义 545（八不变式映射 InvariantMap）** 各档责任：
```
I1 CVC-闭环        : C0–C3 全部保持
I2 SpatialCert     : C0–C3 全部保持；C2 额外按 r_cal 膨胀
I3 RT-CVC 任务模型 : C0–C3 全部保持
I4 FaultCert 闭环  : C0–C2 额外接收 “标定失效/未接地/语义歧义” 归因；C3 复用 v7
I5 PrimitiveGraph  : C0–C3 全部保持
I6 严格退化链      : c_rung 单调降级直至迟滞恢复；C3 逐项等价 v7
I7 提案非权威      : 任何 π 都必须经过 Admit 才能执行，无旁路
I8 标定因果性      : 无有效 κ 时不得输出 certified；结论必须携带 κ_id 与 t_cert
```

## 2. 接口与降级语义

**定义 493–529（v7 继承）** MetricLadder、VoiceCommandTyping、RewardDecomposer、SoftCert、MetaWeight、OTL、GCT、ER 全部保留。CAG 不改变这些模块的接口，只把它们的输入从“点观测 + 固定阈值”替换为“带许可证的观测 + 膨胀阈值”，并新增一个计划准入层。

**C0（全功能）**：`Admit` 通过的计划交给 v7 主路径执行；v7 的 OTL 使用 `τ^cal` 更新，SpatialCert 使用 `C^cal`。语义上等价于“v7 + 标定膨胀 + 计划门”。

**C1（局部脚本化）**：仅把不可准入的技能段替换为 `π_script` 中同后置条件的脚本技能；其余段仍由大模型提案。C1 是 C0 的保守细化，不改变硬约束。

**C2（冻结）**：`κ` 失效但系统仍需运行。OTL 冻结在最后有效阈值（无历史则 `τ(0)`），空间证书使用固定安全余量或最后一次有效 `r_cal`，大模型计划只允许脚本技能。C2 在安全上**保守占优**于 v7，而非等价。

**C3（严格退化）**：关闭 CalibrationCredential、FoundationPlanCompiler、SemanticConformalCalibrator，`τ=τ(0)`，`ι_seq=[ι₀]`，直接调用 v7 主函数。C3 与 v7 逐项等价，是退化链的最终锚点。

import numpy as np

# IP-351/352/353 标定许可证、漂移包络与标定感知膨胀
class CalibrationLedger:
    def __init__(self, z_delta, v_max, delta=0.05):
        self.z_delta = z_delta          # sqrt(chi2_{d,1-delta})
        self.v_max = v_max
        self.delta = delta
        self.creds = {}

    def register(self, m, theta, cov, t_cal, domain, drift, obs_mask):
        self.creds[m] = {
            "theta": np.asarray(theta, dtype=float),
            "cov": np.asarray(cov, dtype=float),
            "t_cal": float(t_cal),
            "domain": dict(domain),
            "drift": dict(drift),       # a, b, d_max
            "obs_mask": set(obs_mask),
        }

    def drift(self, m, now):
        c = self.creds[m]
        age = max(0.0, now - c["t_cal"])
        return min(c["drift"]["d_max"],
                   c["drift"]["a"] * age + c["drift"]["b"] * age * age)

    def valid(self, m, now, env, dof_req, t_life):
        if m not in self.creds:
            return False
        c = self.creds[m]
        if now - c["t_cal"] > t_life:
            return False
        if not self._in_domain(c["domain"], env):
            return False
        return set(dof_req).issubset(c["obs_mask"])

    def inflation(self, m, now, sigma_sync):
        c = self.creds[m]
        lam = float(np.linalg.eigvalsh(c["cov"]).max())
        return (self.z_delta * np.sqrt(max(lam, 0.0))
                + self.drift(m, now)
                + self.v_max * sigma_sync)

    @staticmethod
    def _in_domain(domain, env):
        return all(lo <= env.get(k, lo) <= hi for k, (lo, hi) in domain.items())


# IP-354/533 标定感知阈值与空间证书
class CalibrationAwareLadder:
    def __init__(self, base_thresholds, relax_sign, eps_min, eps_max):
        self.tau0 = dict(base_thresholds)
        self.sign = dict(relax_sign)
        self.eps_min = dict(eps_min)
        self.eps_max = dict(eps_max)

    def thresholds(self, r_cal_sys):
        return {
            i: float(np.clip(self.tau0[i] + self.sign[i] * r_cal_sys,
                             self.eps_min[i], self.eps_max[i]))
            for i in self.tau0
        }

    @staticmethod
    def inflate_region(region, r_cal_sys):
        return {"center": region["center"],
                "radius": region["radius"] + r_cal_sys,
                "source": region.get("source", "spatial_cert")}


# IP-355 类型化技能契约注册表
class SkillContractRegistry:
    def __init__(self):
        self.contracts = {}

    def register(self, name, arg_schema, pre, post, dof_req, envelope, obligations):
        self.contracts[name] = {
            "arg_schema": arg_schema, "pre": pre, "post": post,
            "dof_req": set(dof_req), "envelope": envelope,
            "obligations": set(obligations),
        }

    def type_ok(self, skill):
        c = self.contracts.get(skill["name"])
        if c is None:
            return False
        return self._schema_ok(c["arg_schema"], skill.get("args", {}))

    @staticmethod
    def _schema_ok(schema, args):
        for key, spec in schema.items():
            if key not in args:
                return False
            if "min" in spec and args[key] < spec["min"]:
                return False
            if "max" in spec and args[key] > spec["max"]:
                return False
        return True


# IP-357 语义 conformal 校准
class SplitConformalCalibrator:
    def __init__(self, alpha=0.05):
        self.alpha = alpha
        self.qhat = None

    def calibrate(self, scores):
        scores = np.asarray(scores, dtype=float)
        n = len(scores)
        k = int(np.ceil((n + 1) * (1.0 - self.alpha)))
        self.qhat = float(np.sort(scores)[min(k, n) - 1])
        return self.qhat

    def prediction_set(self, probs, labels):
        if self.qhat is None:
            return set(labels)           # 未校准则全量弃权式返回
        return {y for y, p in zip(labels, probs)
                if (1.0 - p) <= self.qhat}


# IP-358/359 计划准入闸与有界修复
class PlanAdmissionGate:
    def __init__(self, registry, ledger, calibrator, env, t_life,
                 wcet_budget, k_repair=3):
        self.registry = registry
        self.ledger = ledger
        self.calibrator = calibrator
        self.env = env
        self.t_life = t_life
        self.wcet_budget = wcet_budget
        self.k_repair = k_repair

    def admit(self, plan, now, spatial_cert):
        if not plan or len(plan["skills"]) == 0:
            return False, "empty_plan"
        if not all(self.registry.type_ok(s) for s in plan["skills"]):
            return False, "type"
        for s in plan["skills"]:
            if not self._grounded(s, spatial_cert):
                return False, "ungrounded"
            c = self.registry.contracts[s["name"]]
            for m in c["dof_req"]:
                if not self.ledger.valid(m, now, self.env,
                                         c["dof_req"], self.t_life):
                    return False, f"calibration:{m}"
            if not self._semantics_ok(s):
                return False, "semantic_ambiguity"
            if not self._obligations_ok(s, spatial_cert):
                return False, "obligation"
        if not self._m0_preview_ok(plan):
            return False, "m0_preview"
        if self._wcet_est(plan) > self.wcet_budget:
            return False, "wcet"
        return True, "admitted"

    def _grounded(self, s, spatial_cert):
        for ref in s.get("refs", []):
            if ref.get("object_id") not in spatial_cert.get("objects", {}):
                return False
            if ref.get("uncertainty", np.inf) > spatial_cert["r_cal_sys"]:
                return False
        return True

    def _semantics_ok(self, s):
        labels = s.get("labels", [])
        for label in labels:
            cset = self.calibrator.prediction_set(
                label["probs"], label["candidates"])
            if len(cset) != 1:
                return False
        return True

    def _obligations_ok(self, s, spatial_cert):
        c = self.registry.contracts[s["name"]]
        discharged = set(s.get("discharged", []))
        return c["obligations"].issubset(discharged)

    def _m0_preview_ok(self, plan):
        return bool(plan.get("m0_preview_ok", False))

    def _wcet_est(self, plan):
        return float(plan.get("wcet_est_ms", 0.0))

    def repair(self, plan, now, spatial_cert, script_library):
        for _ in range(self.k_repair):
            ok, why = self.admit(plan, now, spatial_cert)
            if ok:
                return plan, "admitted"
            if why == "semantic_ambiguity":
                plan = self._narrow_args(plan)
            elif why == "ungrounded":
                plan = self._re_observe(plan)
            elif why.startswith("calibration") or why == "m0_preview":
                return self._substitute_scripted(plan, script_library), "scripted"
            else:
                return None, why
        return None, "repair_budget_exhausted"

    def _narrow_args(self, plan):
        return plan                    # 缩小参数区间，严格减小可行体积

    def _re_observe(self, plan):
        return plan                    # 增加一次预算内观测，消耗一次修复预算

    def _substitute_scripted(self, plan, script_library):
        return script_library.get(plan.get("goal"), None)


# IP-360 标定降级阶梯
class CalibrationDegradationLadder:
    def __init__(self, recover_cycles=10):
        self.rung = 0
        self.good = 0
        self.recover_cycles = recover_cycles

    def step(self, calibration_ok, plan_status):
        if not calibration_ok and plan_status == "scripted":
            self.rung = max(self.rung, 2)
        elif plan_status == "scripted":
            self.rung = max(self.rung, 1)
        elif plan_status == "v7":
            self.rung = 3
        elif plan_status == "admitted":
            self.good += 1
            if self.rung > 0 and self.good >= self.recover_cycles:
                self.rung -= 1
                self.good = 0
        return self.rung


# IP-362 标定感知 OTL：无效即冻结
class CalibrationAwareOTL:
    def __init__(self, otl, n_ramp=20):
        self.otl = otl
        self.n_ramp = n_ramp
        self.ramp = n_ramp

    def update(self, metrics, layer, calibration_ok):
        if not calibration_ok:
            return self.otl.get_thresholds()
        tau = self.otl.update(metrics, layer)
        if self.ramp < self.n_ramp:
            self.ramp += 1
            trust = self.ramp / self.n_ramp
            base = self.otl.base_thresholds[layer]
            return base + trust * (tau - base)
        return tau


# IP-363 主闭环关键片段：CAG 包裹 v7
def metricvoicegauge_round8(M, s, obs, now, audio_stream=None, ell=None,
                            fm_plan=None, modules=None):
    modules = modules or {}
    ledger = modules.get("ledger")
    ladder = modules.get("cal_ladder")
    registry = modules.get("registry")
    conformal = modules.get("conformal")
    otl = modules.get("cal_otl")
    script_lib = modules.get("script_lib", {})
    rung_ladder = modules.get("rung_ladder", CalibrationDegradationLadder())

    # 1. 标定许可证与系统半径
    if ledger is None or ladder is None:
        return M.metricvoicegauge_round_7(s, obs, audio_stream, ell=ell)  # C3

    r_cal = {}
    for m in obs:
        if m in ledger.creds:
            r_cal[m] = ledger.inflation(m, now, obs[m].get("sigma_sync", 0.0))
    cal_ok = bool(r_cal)
    r_sys = sum(r_cal.values()) if cal_ok else float("inf")

    # 2. 标定感知阈值与空间证书
    if cal_ok:
        tau = ladder.thresholds(r_sys)
        spatial = dict(obs.get("spatial_cert", {}))
        spatial["r_cal_sys"] = r_sys
        spatial["region"] = ladder.inflate_region(
            spatial.get("region", {"center": [0, 0, 0], "radius": 0.0}), r_sys)
    else:
        tau = dict(ladder.tau0)
        spatial = {"r_cal_sys": 0.0, "objects": {}}

    # 3. 大模型计划 → 编译 → 准入 → 有界修复
    plan_status, plan = "v7", None
    if fm_plan is not None and registry is not None and conformal is not None:
        gate = PlanAdmissionGate(registry, ledger, conformal, {}, 1e9,
                                 M.wcet_budget)
        plan, plan_status = gate.repair(fm_plan, now, spatial, script_lib)
        if plan is None:
            plan_status = "scripted"

    # 4. 阶梯与 OTL 冻结
    rung = rung_ladder.step(cal_ok, plan_status)
    if rung >= 3:
        return M.metricvoicegauge_round_7(s, obs, audio_stream, ell=ell)  # C3

    if otl is not None:
        for layer in (1, 2, 3):
            otl.update(obs, layer, calibration_ok=(rung <= 1))
        tau = otl.otl.get_thresholds()

    # 5. 交给 v7 主路径；CAG 只替换观测、阈值与计划
    C, spatial_cert, claims, metrics, rewards = M.metricvoicegauge_round_7(
        s, obs, audio_stream, ell=ell, tau_override=tau,
        plan=plan if rung <= 1 else None)

    return C, spatial_cert, claims, metrics, rewards, {
        "rung": rung, "r_cal": r_cal, "r_cal_sys": r_sys,
        "plan_status": plan_status, "calibration_ok": cal_ok,
    }

## 4. 推导

**引理 77（标定膨胀的可靠性）** 设真实标定误差落在椭球内 `e^T Σ_cal^{-1} e ≤ χ²_{d,1−δ}`，则以 `r_cal,m = sqrt(χ²_{d,1−δ})·sqrt(λ_max(Σ_cal))` 膨胀的单模态证书以概率 ≥ 1−δ 包含真值；沿长度 k 的变换链使用半径求和 `r_cal,sys=Σ r_cal,m` 时，由三角不等式，只要每个单环包含真值，合成证书也包含真值。证明：`||e||₂ ≤ sqrt(λ_max)||Σ^{-1/2}e||₂`，而 `||Σ^{-1/2}e||₂² ≤ χ²_{d,1−δ}` 的概率为 1−δ；链路误差逐段相加，半径也逐段相加即覆盖。

**引理 78（退化单调性）** `d_m(Δ)` 对年龄 Δ 单调非减，故 `r_cal,sys(t)` 非减；`τ_i^cal` 随 `s_i r_cal` 单调收紧，`C^cal` 随半径膨胀而只增不减；准入集合是这些约束的交，因此随标定变差**单调收缩**。证明：漂移包络按定义非减，clip 保序，交点集对参数单调；故不存在“忽略老化反而更安全”的路径。

**引理 79（语义 conformal 的边际覆盖率）** 在可交换样本下 `P(y ∈ C_α(x)) ≥ 1−α`。若准入闸只执行 `C_α(x)` 为单例的计划，则该计划引用标签出错的边际概率不超过 α。证明：出错意味着 `y ≠ ŷ` 且 `C_α={ŷ}`，故 `y ∉ C_α`，其概率 ≤ α；单例限制把“集合覆盖”转化为“点执行”的风险界。

**引理 80（提案非权威与硬约束保持）** 假设 `M₀_preview_ok` 是前向可达集的 sound 过近似。对任意大模型输出 π（含对抗性错误），若执行路径必须经过 `Admit` 且 `Admit` 要求 `M₀_preview_ok(π)`，则被执行计划不违反 M₀。若大模型离线，脚本计划 `π_script` 不依赖大模型即可通过准入。证明：执行入口唯一性（I7）给出旁路不存在；M₀ 预览的必要条件给出硬约束保持；脚本路径与 fm 变量无关。

**引理 81（修复终止与延迟有界）** 每次非放弃修复要么严格减小良基测度 `μ = (剩余歧义数, 可行参数体积)`，要么消耗一次 `K_repair` 预算；`K_repair` 有限，故修复在至多 `K_repair` 步内返回准入或放弃。附加延迟 ≤ `K_repair·(T_gate + T_observe)`。证明：收窄参数严格缩小可行域，重观测消耗预算，脚本替代直接返回；不存在无限循环。

**引理 82（降级语义）** C3 逐项等价 v7：`τ=τ(0)`、`ι_seq=[ι₀]`、无标定膨胀、无大模型计划，直接调用 v7 主函数。C2 在安全上保守占优 v7（阈值更紧、证书更大），C1 仅在计划层把不可准入段替换为同后置脚本技能、不放松任何硬约束。证明：按定义逐项比对；C2 的膨胀与冻结只会收紧准入；C1 的脚本替换保持 post 条件与 envelope。

**定理 1（八不变式保持）** 在 C0–C3 任一档，v7 的六不变式与新增 I7/I8 均成立。证明：由 InvariantMap（定义 545）逐项检查；C0–C2 的所有新增检查都位于执行入口之前，C3 直接复用 v7；I7 由唯一入口保证，I8 由 `C^cal` 必须携带 `κ_id/t_cert` 且失效即不得 certified 保证。

## 9. 本轮最大风险

**一句话**：若标定协方差被低估或语义 conformal 的交换性假设被分布漂移破坏，系统可能对“过期标定 + 高置信幻觉”同时给出 certified，把最危险的一类提案恰好放行。
