# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；本轮灵感：「面部表情识别」×「语言指令」）

> 第 54 轮已把技能组合推进到动作空间剖面 `α_S` 与云边联合证书 `J`，但所有约束仍来自机器人内部。本轮引入人这一侧的两个异质通道：**语言指令**（符号、离散、可组合）与**面部表情**（连续、模糊、具身）。核心矛盾：语言回答“做什么”，表情回答“是否理解 / 是否舒适 / 是否抗拒”；二者可能冲突，且表情只是**弱证据**而非读心。若把表情硬标签直接接到动作空间，会在跨文化、遮挡与个体差异下产生误读、过度降额，甚至让表情错误覆盖语言安全指令。核心假设：H22：`p(act,ref|L)` 与表情隐含的 manner/comfort 可能矛盾，无仲裁的晚融合会产出“语义正确但社交不安全”的动作；H23：面部表情的置信度、基线与文化先验决定其可用性，未校准的表情调制会负迁移；H24：云端语言解析慢、边端表情感知快，若证书不同步，边端会拿“过期情感状态”去配“地基计划”。

## 0. 直觉与动机

**灵感 1（因子化社交接地 → 语言定合同，表情只改语气）**
直觉：语言指令是一份**合同**，至少包含 `(act, ref, manner, safety)` 四个槽位；面部表情是**语气与舒适度**，可以影响“怎么做、多快、是否需要解释”，但不应该改变“做什么”和安全条款。把二者做成联合意图分布 `p(G|L,F,C)` 会让表情悄悄改写任务，风险不可控；更稳妥的是**因子化**：`p(act,ref|L)` 只由语言决定，`p(manner|L,F,C)` 才允许表情介入，`safety` 是硬约束且语言绝对优先。这样表情的贡献被限制在一个可审计的子空间里。

**灵感 2（表情即“只收缩”的降额器 → 永不扩张权限）**
直觉：看到用户皱眉、后退或紧张，机器人应放慢速度、减小幅度、增加解释，这是“降额”；但表情不能反过来解锁更大的力、更快的速度或更近的距离。于是把表情建模为动作剖面的**非扩张调制** `α_S(a|e)=α_S(a)·m(e,a)`，其中 `m(e,a)∈[0,1]`。该性质保证 `supp(α_S(·|e)) ⊆ supp(α_S)`：表情只能收缩动作空间，不能扩张权限。这和第 54 轮的 `A_core ⊆ A_e` 天然衔接，也给出一条可测试的安全不变量。

**灵感 3（理解监控与澄清修复 → 不确定就问，不要猜）**
直觉：用户说“那个”，同时表情困惑，正确反应不是猜一个物体，而是确认“你是指左边那个吗？”；执行后用户仍困惑，则应复述、演示或放慢，而不是继续。把表情当作**隐式反馈通道**，维护“预期情感”与“观测情感”的偏差 `d_t`，当偏差超过阈值时触发语言侧修复 `r_t ∈ {clarify, rephrase, demonstrate, slow, handoff}`，并限制每步修复次数以防循环骚扰。

**灵感 4（弃权优先的校准证书 → 读不懂就不读）**
直觉：面部表情受文化、个体基线、遮挡、光照和异常表情影响极大；“无法可靠读出”本身是一个合法状态，而不是必须硬分到某个情绪类。只有在个人基线、文化先验、图像质量与置信度都达标时才启用表情通道，否则**弃权**：退回纯语言计划并显式询问。把弃权写进证书，才能避免“低置信度表情驱动高影响动作”的负迁移。

**灵感 5（云边社交契约 → 语义在云、表情在边、只传 token）**
直觉：语言解析与任务规划适合云端大模型，面部表情识别适合边端低延迟与隐私保护。边端本地完成表情推断，只上传离散 affect token、置信度与校准 id，**原始人脸不出端**；云端据此重新接地语言指令并生成方式约束。这扩展第 54 轮的 CEC：从“粗-细动作映射”升级为“语义-情感-动作”三通道契约，并显式规定语言安全指令的最高优先级。

**灵感 6（金字塔扩展 → 社交接地层 𝕊）**
直觉：在第 54 轮动作协同层 `𝔸` 之上叠加社交接地层 `𝕊`：`𝕊_0` 语言语义槽位，`𝕊_1` 表情弱证据，`𝕊_2` 因子化社交接地，`𝕊_3` 社交-动作-鲁棒联合证书。跨层传递时必须同时携带 `J`、`C_g`、`C_e` 与优先级标记 `precedence`，形成**可解释的社交执行证书**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（多模态指令状态与类型化语言指令）**
多模态指令 `I=(L,F,C)`。语言指令是类型化四元组 `L=(act, ref, manner, safety)`：`act` 为动作类型，`ref` 为指代对象，`manner` 为方式/速度/力度/解释量，`safety` 为停止、禁止、距离等硬约束。面部表情给出 affect 证据分布 `F ∈ Δ(E)`，`E={valence, arousal, confusion, engagement, discomfort}`。`C` 为上下文（场景、用户基线 id、文化先验、图像质量）。

**定义 122（因子化社交接地）**
社交接地分布分解为
```
p(G|I) = p(act,ref|L) · p(manner|L,F,C) · 1[safety(L)]
```
其中 `act,ref,safety` **不允许**被 `F` 改写。语言侧方式先验与表情条件方式之间的冲突度为
```
conf_LF = JS( p(manner|L) || p(manner|L,F,C) )
```
当 `conf_LF > Θ_s` 时进入确认/澄清，而不是直接执行。接地证书 `C_g=(G, conf_LF, e, conf_F, cal_id, precedence)`，且恒有 `precedence=language_safety_first`。

**定义 123（表情条件动作剖面与舒适包络）**
在第 54 轮 `α_S` 上定义非扩张调制 `m(e,a)∈[0,1]`：
```
α_S(a|e) = α_S(a) · m(e,a),   supp(α_S(·|e)) ⊆ supp(α_S)
A_comf(e) = { a | α_S(a|e) ≥ θ_m }
```
`A_comf(e)` 为舒适包络。**单调安全不变量**：对任意 `e` 与 `a`，`α_S(a|e) ≤ α_S(a)`；表情不授予任何新动作权限。

**定义 124（表情感知修复回路 EIL）**
```
EIL_t = (F_t, \hat F_t, d_t, r_t)
d_t = D(F_t, \hat F_t)                     # 预期情感与观测情感偏差
r_t ∈ {continue, slow, clarify, rephrase, demonstrate, handoff}
```
修复策略满足收缩条件 `d_{t+1} ≤ γ·d_t + η` 且每步最多 `k_r` 次修复；否则升级为 handoff，避免无限澄清。

**定义 125（社交校准与弃权证书）**
个人基线相对表情 `e_rel = normalize(F; b_u, c_u)`，其中 `b_u` 为用户基线、`c_u` 为文化先验。校准证书
```
C_e = (b_u, c_u, coverage, conf_F, ece, privacy, abstain)
```
若 `conf_F < θ_f` 或 `coverage < θ_cov` 或图像质量不足或文化未知，则 `abstain=1`，表情通道关闭，退回纯语言计划并询问；不允许用低置信度表情做高影响调制。

**定义 126（社交-动作-鲁棒联合证书）**
```
SJ = (J, C_g, C_e, κ_s, precedence)
```
其中 `J` 为第 54 轮动作-鲁棒联合证书，`κ_s` 为过度调制预算。可部署条件：
```
J.ok ∧ C_g.ok ∧ C_e.abstain=0 ∧ conf_LF ≤ Θ_s
∧ manner_delta ≤ κ_s ∧ precedence=language_safety_first
```
若任一条件不满足，则降级为“纯语言执行 + 显式澄清”，而不是强行社交化。

## 2. 关键算法 伪代码

### IP-121 SG（Social Grounding）

```python
def social_ground(L, F, C, theta_s, theta_f):
    sem = parse_instruction(L)           # (act, ref, manner, safety)
    e, conf_f = affect_infer(F, C)       # affect 证据与置信度
    cal = calibration_cert(C)
    if conf_f < theta_f or not cal.valid:
        return Abstain('affect_unreliable', ask_clarify(sem))
    manner_l = sem.manner
    manner_lf = reweight_manner(manner_l, e, C)   # 只调方式/紧急度
    conf_lf = js_divergence(manner_l, manner_lf)
    if conf_lf > theta_s:
        return Conflict('manner_conflict',
                        keep=language_safety(sem),
                        ask=confirm(sem))
    G = Intent(sem.act, sem.ref, manner_lf, sem.safety)
    return Ok(GroundingCert(G, conf_lf, e, conf_f, cal.id,
                            precedence='language_safety_first'))
```

### IP-122 AEM（Affect-conditioned Execution Modulation）

```python
def affect_modulate(alpha_S, e, m_table, theta_m):
    m = {a: clamp(m_table(e, a), 0.0, 1.0) for a in alpha_S}
    alpha_e = {a: alpha_S[a] * m[a] for a in alpha_S}
    assert all(alpha_e[a] <= alpha_S[a] for a in alpha_S)   # 只收缩
    A_comf = {a for a in alpha_e if alpha_e[a] >= theta_m}
    return alpha_e, A_comf
```

### IP-123 EIL（Expression-Instructed Loop）

```python
def expression_loop(F_expected, F_obs, state, gamma=0.5, k_r=1):
    d = affect_discrepancy(F_obs, F_expected)
    if d < tau_lo:
        return ('continue', None)
    if state.repairs >= k_r:
        return ('handoff', None)
    if d >= tau_hi:
        r = choose_repair(d, state)   # clarify/rephrase/demonstrate
        return ('repair', r)
    return ('slow', None)
```

### IP-124 SCC（Social Calibration Certificate）

```python
def social_calibration(user, culture, face_quality, model):
    b = estimate_baseline(user, model)
    if b.coverage < theta_cov or face_quality < theta_q \
       or not culture_known(culture):
        return CalCert(valid=False, abstain=True,
                       reason='low_coverage_or_culture')
    return CalCert(valid=True, abstain=False, baseline=b,
                   ece=estimate_ece(b), id=hash_cert(b, culture))
```

### IP-125 JSC（Joint Social Certificate）

```python
def joint_social_certificate(J, C_g, C_e, Theta_s, kappa_s):
    if not (J.ok and C_g.ok and not C_e.abstain):
        return ('reject', 'missing_component')
    if C_g.conf_lf > Theta_s:
        return ('reject', 'semantic_affective_conflict')
    if C_g.manner_delta > kappa_s:
        return ('reject', 'over_modulation')
    if C_g.precedence != 'language_safety_first':
        return ('reject', 'precedence_violation')
    return ('ok', SocialJointCert(J, C_g, C_e, kappa_s))
```

### IP-126 LSP（Language Safety Precedence）

```python
def arbitrate(L_safety, F, C_g):
    # 停止/禁止/安全距离等硬约束永远由语言与安全策略决定
    if L_safety.is_hard:
        return L_safety.command
    return C_g.manner        # 表情仅影响非安全的方式维度
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SG | O(|G|·|E| + parse(L)) | O(|G|+|E|) | 因子化：表情不改 act/ref/safety |
| AEM | O(|A|) | O(|A|) | 非扩张：`m≤1`，只收缩 |
| EIL | O(T·|E|) | O(|E|) | 收缩条件 `γ<1`、修复次数有界 |
| SCC | O(N_cal·|F|) | O(|F|) | 低覆盖/文化未知必须弃权 |
| JSC | O(|A|+|E|) | O(|A|+|E|) | 联合证书 sound、优先级不可绕 |

**正确性定理（Socially Grounded Execution Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 类型化语言解析在覆盖文法上 sound；**(A30)** 表情推断由个人基线与文化先验校准，低覆盖时弃权；**(A31)** 调制非扩张且语言安全优先序不可被表情改写；**(A32)** EIL 满足 `d_{t+1}≤γd_t+η` 且修复轮数有界；**(A33)** 云边 affect token 时间戳误差 ≤ τ_s 且证书单调。

则在 `SJ` 可部署条件下：
```
P(success ∧ social_ok | deploy)
≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a)
    - P(conf_LF>Θ_s) - β_E - β_F
```
其中 `β_F` 为表情误读在已校准覆盖域内的残余风险。注意：**弃权不计入成功率分母**，而应单独报告 `coverage-success` 前沿；对弃权样本，系统只承诺“安全澄清”，不承诺自主完成。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 表情跨文化/遮挡误读 | 高 | 个人基线 + 文化先验 + 弃权 + 负迁移绊线 |
| 语义-情感冲突被表情覆盖 | 高 | 语言安全优先序 + 显式确认 + 硬约束不可改写 |
| 过度降额导致“家长式”机器人 | 高 | 降额有界 `κ_s` + 用户偏好学习 + hysteresis |
| 语言指令歧义/否定解析错误 | 高 | 类型化槽位 + top-k + 槽位回问 + 安全硬编码 |
| 澄清循环骚扰 | 中 | 每步最多 `k_r` 次 + 升级 handoff |
| 人脸隐私泄露 | 高 | 边端本地推断、只传离散 token、原始人脸不出端 |

## 6. 本轮最大风险

**一句话**：最大风险是把面部表情当作可靠的意图或情绪真值，在未校准、跨文化或遮挡场景下误读表情，并让表情错误地覆盖语言指令或过度降额；因此必须坚持“表情只能收缩动作空间、永不扩张权限，语言安全指令绝对优先，低置信度必须弃权并澄清”。

```python
    e, conf_f = affect_infer(F, C)
    cal = calibration_cert(C)
    if conf_f < theta_f or not cal.valid:
        return Abstain('affect_unreliable', ask_clarify(sem))
    manner_l = sem.manner
    manner_lf = reweight_manner(manner_l, e, C)   # 仅方式/紧急度
    conf_lf = js_divergence(manner_l, manner_lf)
    if conf_lf > theta_s:
        return Conflict('manner_conflict',
                        keep=language_safety(sem), ask=confirm(sem))
    G = Intent(sem.act, sem.ref, manner_lf, sem.safety)
    return Ok(GroundingCert(G, conf_lf, e, conf_f, cal.id,
                            precedence='language_safety_first'))
```

### IP-122 AEM

```python
def affect_modulate(alpha_S, e, m_table, theta_m):
    m = {a: clamp(m_table(e, a), 0.0, 1.0) for a in alpha_S}
    alpha_e = {a: alpha_S[a] * m[a] for a in alpha_S}
    assert all(alpha_e[a] <= alpha_S[a] for a in alpha_S)   # 只收缩
    A_comf = {a for a in alpha_e if alpha_e[a] >= theta_m}
    return alpha_e, A_comf
```

```python
def joint_social_certificate(J, C_g, C_e, Theta_s, kappa_s):
    if not (J.ok and C_g.ok and not C_e.abstain):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SG | O(|G|·|E| + parse(L)) | O(|G|+|E|) | 因子化：表情不改 act/ref/safety |
| AEM | O(|A|) | O(|A|) | 非扩张 `m≤1`，动作空间只收缩 |
| EIL | O(T·|E|) | O(|E|) | `d_{t+1}≤γd_t+η`，修复轮数有界 |
| SCC | O(N_cal·|F|) | O(|F|) | 低覆盖/文化未知必须弃权 |
| JSC | O(|A|+|E|) | O(|A|+|E|) | 联合证书 sound，优先级不可绕 |
| LSP | O(1) | O(1) | 硬安全约束不可被表情改写 |

**正确性定理（Socially Grounded Execution Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 类型化语言解析在覆盖文法上 sound；**(A30)** 表情推断由个人基线与文化先验校准，低覆盖时弃权；**(A31)** 调制非扩张且语言安全优先序不可被表情改写；**(A32)** EIL 满足 `d_{t+1}≤γd_t+η` 且修复轮数有界；**(A33)** 云边 affect token 时间戳误差 ≤ τ_s 且证书单调。
则在 `SJ` 可部署条件下：
```
P(success ∧ social_ok | deploy)
≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a)
    - P(conf_LF>Θ_s) - β_E - β_F
```
其中 `β_F` 为已校准覆盖域内表情误读的残余风险。**弃权不计入条件成功率分母**：对弃权样本，系统只承诺“安全澄清”，不承诺自主完成；需单独报告 `coverage-success` 前沿。

| 风险 | 等级 | 缓解 |

## 7. 本轮最大风险

**一句话**：最大风险是把面部表情当作可靠的意图或情绪真值，在未校准、跨文化或遮挡场景下误读表情，并让表情错误地覆盖语言指令或过度降额；因此必须坚持“表情只能收缩动作空间、永不扩张权限，语言安全指令绝对优先，低置信度必须弃权并澄清”。
