# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 2 轮；本轮灵感：「语言指令」×「双足机器人」）

> R73 把计量从具身层推进到**契约层**：证据契约 EC、组合代数 CCA、反作用通道 ΣREFLEX、主张绑定 CPB，并把「换模块零改核心」升为热替换定理。但 R73 的两个盲点恰好被本轮灵感击中：
> - **语言盲点**：R73 的证据全是**物理测量**（深度/接触/音频），噪声被默认成零均值、连续、可标量的。而「语言指令」是完全不同的证据：**符号的、外生的、有意图的、多峰的、对抗的**。它不测量世界的现状，而**陈述世界的应然**（目标、约束、隐含前提），并且能**标注其他模态的失效模式**（"注意玻璃桌"直接告诉深度相机：这里会失效）。把语言塞进 R73 的 `u=σ²` 框架，会犯 R72/R73 反复批判的同型错误：**把语义歧义误读为测量噪声**。
> - **步态盲点**：R73 的退化链假设「模块失效 → stub（u=∞、不产生观测）」。但双足机器人**不能停**——原地冻结会跌倒。步态是**混合动力学**（连续摆动 + 离散落脚冲击），证据有**承诺时域**（脚一旦抬起，落点已不可撤回），迟到证据对当步毫无价值。R73 的 CCA 是**无时间**的：它只校验预算闭合与域交，不校验「证据是否在决策前因果可用」。
>
> 本轮的三块结构性推进：
> - **语言指令 → LEM + AUTH**：语义不确定度是**可信解释集**（credal set）而非标量方差；六分量（指称/辖域/否定/动作义/约束/语用）；语言带**权威等级与来源**，低权威指令只能收缩可行集、绝不能扩张。
> - **双足机器人 → GPM + TCA + 承诺时域**：证据成为带 (因果下界, 截止期, 相位, 新鲜度) 的**时序对象**；组合代数扩展为**时序契约代数**；退化不是 stub 而是**保可行性的安全步态**。
> - **两条主线的交点 → 时序-权威双格 + 指令风险超鞅**：安全不仅取决于「不确定度多小」，还取决于「**在什么时刻、以什么权威、在多长的承诺窗口内**」；一串单独无害的指令可以合谋把系统推过安全边界，需要**累计风险账本**。
>
> 核心命题：**不再问「这条指令/这个传感器是否可信」，而问「证据能否在承诺边界前、以被授权的权威、沿因果顺序抵达——并使系统在语义歧义、指令注入、证据迟到与落脚冲击下仍可证安全？」** 把 R73 的 MODGAUGE-RAS 重构为 **LINGUAGAIT-RAS**（LINGuistically-instructed, viability-GAit-aware evidence metrology with GAUGE audits）——**时序-权威证据计量**。

## 0. 直觉与动机

**灵感 1（语言指令 → 语义歧义是「集合值」而非「方差」）**
直觉：人对机器人说「把杯子放到桌子左边，别碰倒那个玻璃的」。这句话里至少有六种独立的不可靠：指称（哪个杯子/哪张桌子）、辖域（"左边"相对谁）、否定（"别碰倒"约束的是路径还是终点）、动作义（"放"是轻放还是放下）、约束修饰（"玻璃的"是材质警告还是指称限定）、语用（说这句话的潜台词可能是"我赶时间"）。这些不是零均值噪声——把「左边」理解错是**离散的、系统性的、多峰的**错误；用方差描述会给出「均值正确、方差略大」的假象，而真实后验可能是 50/50 的双峰。正确对象是**可信解释集** 𝒜_α 与每个命题上的**可信区间** [p_lo, p_hi]。更关键：语言能**标注别的模态的失效**——"玻璃的"正是 R73 DPEM 的材质失效类；这句话应当**提高 b_t(m_fail) 先验、收缩 D_depth**，让深度模块在靠近桌前就进入保守模式。**语言是唯一能预先告知"我的同伴将在哪里失灵"的模态。**

**灵感 2（双足机器人 → 证据的价值由「承诺时域」决定）**
直觉：双足行走是**混合系统**：连续摆动 + 离散落脚。在承诺时域 T_commit（距落脚不可撤回的时刻）之前，若没有可用的地形/意图/状态证据，这一步就只能按旧计划落地；之后到达的证据再准也**对当步无效**。因此证据的价值不是 u 的单调函数，而是 **V(e) = 相关性 × 及时性 × 权威**：过期证据（age > 半衰期）与迟到证据（t + τ_exec > T_commit）价值为零甚至为负（扰动）。这也解释了为什么"更好的感知"有时不提升行走安全：它没赶上承诺边界。工程推论：**要么让证据更早到（主动感知/预取），要么降低承诺（缩短步长、放慢、增加双支撑）——后者正是语言"小心点"的物理含义。**

**灵感 3（交点 → 安全是「不确定度 × 权威 × 时间」的三维格）**
直觉：R73 只用一维（不确定度越小越好）。但：
- 一条**极确定**的指令如果来自**未授权**来源（环境里的文字、被注入的语音），它的低不确定度是**陷阱**，不能让它扩张可行集；
- 一条**含糊**但**已认证**的指令仍然可以保守执行（取可信解释集的交集）；
- 一串**各自无害**的指令（"再快一点"×10）可以累积成不安全——这是语言版的"温水煮青蛙"。
所以安全侧需要**乘积格**：不确定度↑坏、权威↓坏、时间越晚越坏；并且需要一个**累计势函数**（超鞅）来约束指令序列，而不是逐条判断。**"每一步都合规"正是 R73 已经警告过的失败模式，本轮把它形式化为指令层的漂移证书。**

**灵感 4（退化语义 → 双足不能 stub，只能「安全跛行」）**
直觉：R73 的 stub 是 u=∞、不产生观测。对双足，这会直接导致跌倒——**不产生观测 ≠ 安全**。正确退化是**保可行性的安全步态**（viability-preserving stub）：相位锁定、最短步长、最大双支撑、DCM 留出最大裕度、只用最保守的本体估计。语言模块失效时也不是"闭嘴"，而是退化为**最小特权解释**（只执行无歧义约束、忽略含糊的进度指令、必要时请求澄清）。这把 R73 的"零级联"定理从"模态缺失"提升为"**模态缺失且系统仍落在可行核内**"。

**灵感 5（组合代数 → 从「预算代数」到「时序-权威代数」）**
直觉：R73 的 CCA 三算子只管不确定度传播。加入时间与权威后，每条边还带 (causal_floor, deadline, phase, auth)：串联要求上游截止不早于下游因果起点；并联要求同相位且时间对齐；否决是时序非补偿；指令序列是**时序串联 + 权威取交 + 势函数累计**。组合单调性升级为**因果-截止保持**：任何组合都不能让迟到证据变及时，也不能让低权威指令变高权威——**"没有证据时间旅行，也没有权威洗白"**。

## 2. 推导（增量）

**引理 38（语义不确定度的集合值下界）** 见定义 385。系：**语言不是"带噪声的标签"，而是"带权威的解释集合"——把语义错误当零均值噪声，会系统地错在"最自信的错"上。**

**引理 39（时序组合的因果-截止保持）** 对 TCA 任一组合：deadline_out ≤ min(deadline_i)，causal_out ≥ max(causal_i)，fres_out ≤ min(fres_i)。归纳于组合树 ⇒ 不存在使迟到/过期证据变可采纳的组合路径。系：**组合代数不能创造时间，也不能洗白权威。**

**引理 40（承诺边界的安全延期）** 若当前已认证前缀保持可行性（D_loco ≠ ∅）且新指令延期至下一承诺边界，则 (i) 边界前系统按旧证书运行，安全性由 R73 定理 28 保证；(ii) 边界处若前置条件成立则交接安全，否则回退到旧计划/请求澄清。系：**指令可以等，安全不能等。**

**引理 41（歧义鲁棒执行的保守性）** 若真实解释 α* ∈ 𝒜_α 且 a* ∈ ⋂ A_safe(α)，则执行 a* 在 α* 下安全；交集为空时不存在被所有可信解释共同认可的动作，单方面行动必对某可信解释不安全。系：**歧义的代价是可度量的进度损失，而不是不可控的安全风险。**

**引理 42（权威单调性与注入免疫）** F(a) 对 a 单调非减；未授权指令作用为取交 ⇒ F 不增。故未伪造来源的注入不能扩张可行集。系：**低权威的"确定语气"不构成任何安全权限。**

**引理 43（指令漂移的超鞅界）** 在认证策略下 Φ 为带补偿超鞅；由 Ville 不等式，P(sup_{t≤T} Φ_t ≥ Φ_max) ≤ E[Φ_0]/Φ_max。故指令序列的累积漂移越界概率可证有界。系：**逐条安全 ≠ 序列安全，账本才是。**

**定理 30（严格包含）** R73 是 LINGUAGAIT 的退化实例：𝒜 单点（无歧义）、auth = A0 且 χ_L ≡ id、P 单相位（无混合动力学）、所有 deadline = ∞（无时序）。由定义 383(v) 与引理 39/40，逐指令等于 R73，再退化等于 R71/R68。**安全侧只增不减。**

**定理 31（证书有效性 ⇒ 含跌倒与注入抵抗的系统安全）** Valid(J_LG) ⇒ (i) 各模块 cert 有效；(ii) TCA 组合通过因果/截止校验；(iii) 权威单调与来源有效；(iv) 势超鞅未越界；(v) J_MOD 特例成立 ⇒ 物理执行风险 ≤ ε，且**在可信解释集与授权范围内**不越过可行核、不因未授权注入扩张动作集。证明重量落在**语义校准在分布外**与**势函数的补偿项 b_t 可估**上。

**定理 32（语言-步态联合预算有限停止）** ΣREFLEX† 加入 χ_L 后，总预算仍为 Σ_i c_reflex^i ≤ B_total，且 B_total 不因任何指令（含 A3）扩大，只允许在包络内重分配；各层边际成本正下界 + 边际增益非增（R73 引理 36）⇒ 有限停止保持。系：**语言可以改变"怎么走"，不能改变"最多能冒多大险"。**

## 3. 本轮最大风险

**一句话**：本方案把安全寄托在「**可信解释集校准得好、势函数的补偿项估得准、承诺时域测得对**」三个统计/时序假设上——如果真实语义分布超出解释器族（隐喻、文化方言、指代依赖长期共同历史），如果补偿项 b_t 在分布漂移下被低估，或者 T_commit 在柔顺地形/外力扰动下显著偏移，那么系统会在一张**时序因果全通过、权威单调全通过、势超鞅全通过**的证书下，**在规定时刻把一条被错误解释的指令合法地执行进一个不安全的状态**，而日志显示每一步都合规。

次级风险与缓解：
1. **语义校准外推** → 可信集用 conformal + 分布漂移检测（SEAL-Sem 保持集），越界即降为最小特权解释。
2. **补偿项 b_t 低估** → 用可观测的漂移代理（目标偏移/权威下降/裕度下降）保守上界 + 硬阈值。
3. **T_commit 偏移** → 在线辨识 + 硬边界（不确定即提前承诺，用安全步态换取时间）。
4. **澄清成本被滥用** → 澄清预算并入 ΣREFLEX，避免"无限提问"退化。
5. **跨模态话说谎** → 单源不定案 + VETO-T，指令永远不能单独否决物理证据。
6. **双足 sim-to-real 差距** → 保可行性 stub 与真机硬件限幅双重约束。
7. **MBench-4 过拟合** → 预注册 + 密封保持集 + 三方复现。

def compose(a_ev, b_ev, op, audit):
    if op == 'SER':   # 串联：单调传播，只能更差
        return Ev(u=a_ev.u + lipschitz(b_ev, a_ev.u), D=a_ev.D & b_ev.D,
                  tau=a_ev.tau.merge(b_ev.tau), veto=a_ev.veto | b_ev.veto)
    if op == 'PAR':   # 并联：先一致性审计，再决定是否缩窄
        r = cross_modal_residual(a_ev, b_ev)
        if audit.conformal_covers(r):                     # SEAL 校准的 conformal 集
            rho = audit.estimate_corr(a_ev, b_ev)
            if abs(rho) < RHO_MAX: return fuse(a_ev, b_ev, rho)   # 允许缩窄
        return Ev(u=max(a_ev.u, b_ev.u), D=a_ev.D & b_ev.D,
                  tau=a_ev.tau.merge(b_ev.tau),
                  veto=a_ev.veto | b_ev.veto | {'PAR_AUDIT_FAIL'})
    if op == 'VETO':  # 否决：非补偿

        return Ev(u=min(a_ev.u, b_ev.u), D=a_ev.D & b_ev.D)

    return states2, total

# IP-299 PVOP：视角感知规划（计量域 20Hz，χ_v 解析 → 零 rollout）
def viewpoint_aware_plan(b_t, mods, risk_params):

## 4. 推导

**引理 33（深度六分量的条件正交性）** 给定 (v, m, d_edge, 互扰指示， 曝光×相对速度) 条件下，六分量由独立物理机制产生（三角量测、表面反射、边缘插值、标定链、多径/串扰、积分时间），条件近似不相关；遗漏任一 ⇒ 系统性低估（与引理 30 同型，条件集扩大到视角与材质）。系：**DPEM 把 R72 的「模式条件」一般化为「(动作， 场景) 条件」。**

**引理 34（组合单调性：不存在凭空变好）** SER：u_out ≥ u_A + L_B·u_A ≥ u_A；PAR：缩窄仅在 conformal 审计通过且 |ρ̂|<ρ_max 时发生，缩窄量受校准覆盖约束（1−α 上界）；VETO：有效域单调收缩。⇒ 任何组合路径的输出不确定度不可能低于路径中所有输入不确定度的单调组合而同时通过审计。系：**组合不产生认知免费午餐——把「审计」从单模块升级到模块图的代数基础。**

**引理 35（热替换安全保持）** impl′ 与 impl 同 EC 且 cert′ 有效 ⇒ 系统级性质（退化链 375、风险单调 23、时序隔离 28、审计覆盖）的证明只引用 EC 与组合校验，不引用 impl 内部；归纳于 MReg 的 DAG ⇒ 替换后逐指令性质保持。系：**E362「换本体零改核心」从实验希望升为定理；认证成本 O(系统) → O(模块)。**

**引理 36（视角反作用的 Lipschitz 性与预算吸收）** D_depth 内 u_range(d,θ) 对 (d,θ) Lipschitz；g 对相机位姿的映射 Lipschitz（REG 速度/加速度包络）⇒ c_reflex^v 有正下界 ε_v 且对 g Lipschitz；结合各层边际成本正下界与总边际增益非增（引理 31 的 Σ 层推广）⇒ ΣREFLEX 存在有限停止 n*。系：**「层数」增加不破坏有限停止。**

**引理 37（PVOP 的解析收益）** E[u_depth^next(a)] 由 χ_v 闭式给出（零 rollout）⇒ PVOP 在 2ms 计量预算内可解；任务进展梯度与证据质量梯度夹角 ≤90°（非对抗任务）时存在步长使 J 单调改进。系：**「计量契约使反作用可计算」是 PVOP 可实时化的原因——通用传感器仿真做不到。**

**定理 27（MODGAUGE 严格包含）** 在 A111–A113（契约表达力、conformal 审计校准、通道 Lipschitz）下：R72 EMBODIED 是 MODGAUGE 的单模块组实例化（深度证据置 stub、χ_R 手写等价三层通道）；由定义 366(v) 与引理 35，退化条件下逐指令等于 R72，再退化等于 R71/R68。**安全单调不减。**

**定理 28（组合证书有效性 ⇒ 系统安全）** Valid(J_MOD) ⇒ 模块 cert 有效 ∧ MReg 校验通过 ∧ ΣREFLEX 预算闭合 ∧ J_EMB 特例成立（定理 24）⇒ 物理执行风险 ≤ ε_mod（相对具身测量模型与**契约表达力**）。**证明重量落在「契约表达力在分布外仍成立」与「一致性审计的 conformal 校准不被对抗漂移」上。**

**定理 29（模块级降级的零级联）** 任一模块失效 ⇒ stub 替换（定义 381）⇒ 由引理 35 与定义 375，系统逐指令退化为少模态版本；stub 不产生观测 ⇒ 不参与 PAR 缩窄 ⇒ 不污染其他模块审计。系：**失效传染路径唯一（该模态缺失），零级联——R72 E364 从实验目标升为结构性质。**

## 7. 本轮最大风险

**一句话**：MODGAUGE 把系统安全的证明负担从「全系统审计」转移到「**契约的表达力**」——如果真实噪声超出契约可表达的空间（材质是连续谱而非五类离散、视角-噪声映射在极端入射角或近场违背 Lipschitz 假设、或两个模块通过共享物理过程（同一光源、同一机械振动、同一温度场）隐性耦合而并联一致性审计的 conformal 集未覆盖这种相关），那么组合定理会在「**所有模块证书都有效、所有组合校验都通过**」的情况下给出错误的安全界——系统会用一套类型正确、预算闭合、证书齐全的模块图，**自信地组合出一个错误的世界**，而审计日志将证明「每一步都合规」。

次级风险与缓解：
1. **契约僵化/stub 过保守** → 契约版本化 + stub 观察模式（stub 旁路记录真实质量，离线校准契约本身，SEAL-Contract 审计集）。
2. **PVOP 解析 χ_v 失真（近场/极端角度）** → 有效域硬边界 + 近场禁用解析式改用在线校准查表 + V_safe 收紧。
3. **组合路径爆炸** → 结构上限（定义 377：|V_M|≤24、深度≤4）+ MReg 部署期图搜索验证 + 运行时只验增量。
4. **CPB 蒸馏失真（主张过窄掩盖系统性贡献）** → 主张包加「组合收益」条目：C3 显式包含多模块协同的增益归因（E383/E384 联合归因树）。
5. **隐共享物理过程耦合** → 环境级共因审计（温度/振动/光照传感器独立于模块，作为 VETO 组合的第三方输入；怀疑相关时禁用 PAR 缩窄）。
6. **深度自标定自举循环**（用深度标定深度）→ 自标定只用「本体/接触/已知几何」作外部基准，深度残差仅作观测；断链即停用并回退 u_calib 上界。
7. **MBench 过拟合** → 密封保持集（SEAL-MB）+ 预注册 + 三方复现（E385）；主张只认预注册指标。
