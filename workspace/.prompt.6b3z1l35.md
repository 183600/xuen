# 第 48 轮（承接第 47 轮 v11；本轮灵感：任务分解 × 动作空间） · TaskCert-Compose：证书契约式任务分解与抽象感知动作空间（六层架构 v12）

> 承接第 47 轮 v11 JointCert-Eval。v11 把单决策周期的姿态证书运输到关节空间，并用真机序贯评测签发证书，但隐含假设 H6：**任务可被当作单个原始动作的一次性决策，动作空间固定且粒度无关；证书只需在当前 epoch 内 soundness 成立**。UniBot 的真实任务是长程的（抓取→搬运→对准→插入→交接），动作空间本身是分层的（关节基元、技能、宏动作），而现有 P_t/Q̂_t 只覆盖一个 epoch，子任务边界处「上一子任务的输出证书是否蕴含下一子任务的输入证书」从未被定义；动作抽象越粗，执行越快越省能，但其后置证书越宽、越容易在边界处断裂。两个灵感词精确命中 H6：**任务分解**要求把长程目标展开为带证书契约的子任务 DAG，并让端到端 soundness 可组合；**动作空间**要求把抽象层级当作证书宽度的旋钮，在「粗而快」与「细而稳」之间做证书感知的选择。耦合出的新问题：**如何让证书跨子任务边界可组合、如何联合选择分解节点与动作抽象层级，并在执行漂移导致边界蕴含失效时安全地再分解，而不是让每个子任务单独 sound、端到端却静默断裂**。

## 0. 直觉与动机

**灵感 1（任务分解 → 证书契约代数，而非符号前置条件）**
直觉：传统 HTN 的前置/后置条件是符号谓词（"已抓取"），它不携带不确定性，也无法回答「这个后置状态是否足以支撑下一个子任务」。在证书框架下，每个子任务应是一个证书契约 `(Pre, Post, f, α)`：输入是一组证书约束（关节证书 + 三条租约 + 感知层），输出是新的证书集合，`f` 是证书变换器；边 `u→v` 要求 `Post_u ⊨_γ Pre_v`，即在把执行/测量误差与不确定半径计入后，`Post_u` 仍被 `Pre_v` 包含，且裕度 ≥ γ_min。这样"任务分解正确性"就变成"证书蕴含链可传递"。

**灵感 2（动作空间 → 抽象层级即证书宽度旋钮）**
直觉：同一个子任务可以用关节基元慢慢做，也可以用技能/宏动作快速做。粗动作时间/能耗低，但后置证书半径大、对感知与标定误差更敏感；细动作安全但慢且耗能。因此动作空间不是固定的，而是分层格 `A=⊔_l A_l`，每层动作带自己的证书变换器与不确定增长 `ρ(a)`。选择原则：**在仍能蕴含下一子任务前置证书的前提下，选最粗（最省）的动作**；一旦抽象 gap 过大，就细化到基元。

**灵感 3（耦合 → 运行时边界守卫与只追加台账）**
直觉：分解可以离线/在线规划，但执行必然漂移；子任务边界是新的信任脆弱点。必须做两件事：(i) 运行时**边界守卫 CBG** 在实际状态上重新检查 `Post_i ⊨ Pre_{i+1}`，不通过则 hold/再分解，绝不"先执行再补证"；(ii) **证书组合台账 CCL** 以哈希链只追加地记录每次边界交接，任何"修复性重写"都可被审计发现，避免已发出的安全承诺被静默放宽。

**耦合升级**：在 v11 五层上新增 **L2 任务分解层 HTD-Cert** 与 **L4 边界守卫 CBG**，并把动作空间抽象并入 L3 的联合决策。六层 v12：根信任（ℓ_p, ℓ_e, ℓ_k）+ L1 几何感知 + L2 任务分解/上下文/记忆/语音 + L3 关节证书/动作空间抽象 + L4 CAR/Shield/边界守卫 + L5 DCL/真机序贯评测。JCPS 升级为联合输出 `(v_t^*, a_t^*, m_t^*, q_t^*)`（分解节点、动作抽象、模态、构型），DCL 采集边界 gap 样本，CCA 新增抽象 gap/接口利用/台账篡改/非法捷径分解红队。

## 1. 形式化定义（增量：定义 65–70）

**定义 65（证书契约技能与分解 DAG）**
技能 `s=(id, Pre_s, Post_s, f_s, α_s, cost_s)`，其中 Pre_s、Post_s 是证书集合（关节证书、姿态证书、ℓ_p/ℓ_e/ℓ_k 有效性约束、感知层 ω）。任务分解为 DAG `G_T=(V,E)`，节点 v 对应技能，边 `u→v` 需满足证书蕴含
`Post_u ⊨_{γ_e} Pre_v  ⇔  inflate(Post_u, γ_e) ⊆ Pre_v`，
其中 γ_e 计入跟踪误差、标定误差、测量延迟与再观测间隔。根节点要求 `C_0 ⊨ Pre_root`，末节点要求 `Post_last ⊆ Goal`。若找不到满足蕴含链的分解，则分解失败（升级技能合成或 fail-closed），不得用符号谓词替代证书契约。

**定义 66（动作空间抽象格与证书变换 soundness）**
动作空间 `A = ⊔_{l∈L} A_l`，`L={primitive, skill, macro}`，带细化偏序 `⪯`。每个动作 `a` 有证书变换 `f_a: C → C'`、不确定增长 `ρ(a)`、能耗/时间成本 `cost_e(a), cost_t(a)`。Soundness：若入口证书 `C_pre` 有效、三条租约在 `[t, t+Δ_a]` 全程有效，且执行 `a`，则出口证书 `C_post=f_a(C_pre)` 成立的概率 ≥ `1−α_a`。粗动作满足 `ρ(a_coarse) ≥ ρ(a_fine)`；因此粗动作只能在 `Post` 仍能蕴含下一 `Pre` 时使用。

**定义 67（组合 soundness 与交接残差）**
对分解路径 `v_1…v_k` 与动作 `a_i∈A_{l_i}`，定义交接残差 `ε_hand,i` 吸收边界交接时的时序/测量/物体状态更新误差。若每个子任务契约 sound、每条边在线检查 `Post_{v_i} ⊨_{γ_i} Pre_{v_{i+1}}`（γ_i≥γ_min）、租约全程有效，则
`P(X_end ∈ Post_{v_k}) ≥ 1 − Σ_{i=1}^k α_i − Σ_{i=1}^{k−1} ε_hand,i − α_lease`。
这是**条件组合保证**：它不宣称契约库本身正确，只把端到端失效上界归约为子任务与边界的可审计项。

**定义 68（抽象感知的分解-动作联合效用）**
当前前沿节点 v 与后继 `next(v)`，决策
`U(v,a)= Prog(v,a) / (cost_e(a)+cost_t(a)+c_abs·ρ(a))`
约束 `f_a(Pre_v) ⊨_{γ_min} Pre_{next(v)}`、`Pre_v` 当前有效、三条租约有效、能量可行。选择
`a^* = argmax_{a∈A_v feasible} U(v,a)`，即**最粗可行抽象**；若所有粗层不可行，则按 `⪯` 细化，最终回退 primitive。抽象层级只影响效率与 α_a/ρ(a)，不破坏 soundness，因为可行性门槛本身就是证书蕴含。

**定义 69（证书组合台账与单调性）**
台账 `L=[e_1…e_m]`，每条 `e_i=(t_i, v_i, a_i, C_in, C_out, γ_i, h_{i−1}, h_i)`，`h_i=H(h_{i−1}, t_i, v_i, a_i, digest(C_in), digest(C_out), γ_i)`。**单调性不变量**：已签发的边界证书不得被追溯放宽或删除；再分解只能追加新子图与新条目，并以当前实际证书作为新根。审计检查哈希链、租约时窗与每条边蕴含；任何篡改/漏记/越过边界执行都判为违约并 fail-closed。

**定义 70（分解失败归因与再分解触发）**
设实际出口证书 `Ĉ_out`。若 `Ĉ_out ⊄ inflate(C_out, γ_i)` 或 `C_out ⊭ Pre_{next}`，定义边界 gap `g_i = dist(Ĉ_out, Pre_{next})`。用反事实替换 `v_i` 的契约/抽象/感知模态估计归因得分 `A(v_i)=g_i·sensitivity(v_i)`，取最大者为 culprit，从**最早可安全再分解的节点**（通常是 culprit 或其前一安全 hold 点）重新展开剩余目标；已执行前缀与台账保持，绝不回滚或重写。

## 3. 算法骨架

每个宏周期（子任务级）：
1. 读目标、当前证书 `C_t`、三条租约、台账 `L`；若租约失效直接 fail-closed。
2. HTD-Cert 展开/复用证书标注 DAG；对当前前沿 v 求 `Pre_v` 与 `Pre_next`。
3. ASC 从粗到细枚举抽象 a，计算 `f_a(Pre_v)` 并检查 `⊨_{γ_min} Pre_next`；JCPS 同时选模态 m 与构型 q，校验能量/标定/关节可行性。
4. 选中 `(v,a,m,q)` 后由 CBG 在真实状态复核边界；通过则签发并执行，完成时追加台账条目。
5. 若实测出口不满足边界蕴含：DDA 归因并选最早安全点再分解，追加新子图与新台账条目，保留已执行前缀。
6. RRP 按任务模板/边界/感知层累积分层 e-process；任一 lease 失效、gap 无法修复或边界守卫拒绝即撤销证书。
7. 全部抽象与分解均不可行 → 请求技能合成 / 重新抓取 / fail-closed，绝不绕过边界。

## 4. 本轮最大风险

**一句话**：任务分解会引入"接口证书"这一新的隐式信任假设——每个子任务单独 sound、但 `Post_i ⊨ Pre_{i+1}` 可能只在离线规划状态成立，执行漂移、接触模式变化或感知陈旧会让边界蕴含在线失效；若边界守卫被绕过或台账被"修复性重写"，端到端 soundness 会静默断裂，因此边界蕴含必须在同周期在线复核、台账只能追加不可改写、任何 gap 必须触发再分解或 fail-closed。

### IP-74 HTD-Cert
```
def contract_implies(C_out, Pre_next, gamma_min):
    # 证书集合用区间/盒表示，包含判定 sound；无法判定即视为不蕴含
    return inflate(C_out, gamma_min).subset(Pre_next)

def htd_cert(goal, C_cur, contracts, leases, depth=0):
    if goal.satisfied_by(C_cur) and goal.cert_sufficient(C_cur):
        return DAG.singleton(Leaf(goal))              # 当前证书已满足目标
    for method in contracts.methods_for(goal):
        dag, cur, prev, ok = DAG(), C_cur, None, True
        for v in method.ordered_subtasks():            # 方法给出的偏序
            s = contracts.get(v)                       # (Pre,Post,f,alpha,cost)
            if not contract_implies(cur, s.Pre, gamma_min):
                ok = False
                break                                  # 该边不可蕴含，换方法
            Cpost = s.f(cur)                           # 证书变换
            dag.add_node(v, C_in=cur, C_out=Cpost)
            if prev is not None:
                dag.add_edge(prev, v, gamma=implied_margin(cur, s.Pre))
            cur, prev = Cpost, v
        if ok and goal.satisfied_by(cur) and goal.cert_sufficient(cur):
            return dag                                 # 找到证书化分解
    return None                                        # 分解失败：技能合成/升级
```

### IP-75 ASC
```
def actions_at(v, level):
    return [a for a in ACTION_LIB if a.skill == v and a.level == level]

def choose_abstraction(v, C_pre, C_pre_next, leases, energy, q_prev, omega):
    if not leases_valid(leases):
        return None
    best = None
    for lvl in LEVELS_COARSE_TO_FINE:                  # macro -> skill -> primitive
        if not energy.affordable(lvl):
            continue
        for a in actions_at(v, lvl):
            if not a.applicable(C_pre, q_prev, omega):  # OOD/适用域检查
                continue
            C_post = a.f(C_pre)
            if not contract_implies(C_post, C_pre_next, gamma_min):
                continue                               # 粗抽象在此不安全
            val = progress(a) * min(1.0, margin(a)/margin_min) \
                  / (a.cost_e + a.cost_t + c_abs*a.rho)
            if best is None or val > best.val:
                best = (a, C_post, val)
        if best is not None:
            return best                                # 最粗可行层即返回
    return None                                        # 需细化/技能合成
```

```
    h = H(prev_h, t, v.id, a.id, digest(C_in), digest(C_out), gamma)
    e = Entry(t, v, a, C_in, C_out, gamma, h_prev=prev_h, h=h)
    L.append(e)                                        # 只追加；禁止修改历史
    return e

def ledger_audit(L, leases, contracts):
    for i, e in enumerate(L):
        if e.h_prev != (L[i-1].h if i else GENESIS):
            return ('tamper', i)                       # 哈希链断裂
        if not leases.valid_at(e.t):
            return ('lease_gap', i)                    # 签发时租约已失效
        nxt = contracts.next_of(e.v)
        if nxt is not None and not contract_implies(e.C_out,
                                                     contracts.get(nxt).Pre, 0.0):
            return ('boundary_gap', i)                 # 历史边界不蕴含
    return ('ok', len(L))
```

### IP-77 DDA
```
def attribute_gap(L, C_actual, contracts, omega):
    e = L[-1]
    if C_actual.subset(inflate(e.C_out, e.gamma)):
        return None                                    # 出口仍在承诺内
    scores = {}
    for vi, ai, Ci_in, Ci_out in trace(L):
        g = cert_distance(C_actual, contracts.get(vi).Post)
        scores[vi] = g * sensitivity(vi, omega)        # 感知退化层敏感度
    culprit = max(scores, key=scores.get)
    return culprit, scores[culprit]

def redecompose_remaining(rem_goal, C_actual, L, contracts, leases, omega):
    culprit, _ = attribute_gap(L, C_actual, contracts, omega)
    anchor = earliest_safe_hold(culprit, L)            # 不破坏已执行前缀
    new_dag = htd_cert(rem_goal, C_actual, contracts, leases, frontier=anchor)
    if new_dag is None:
        return 'fail_closed'
    ledger_append(L, now(), anchor, HOLD, C_actual, C_actual, 0.0)
    return new_dag
```

### IP-78 CBG
```
def boundary_guard(next_v, C_out_actual, L, contracts, leases, energy):
    if not leases_valid(leases) or not energy.valid():
        return ('fail_closed', 'lease')
    status, _ = ledger_audit(L, leases, contracts)
    if status != 'ok':
        return ('fail_closed', 'ledger')
    Pre_next = contracts.get(next_v).Pre
    if not contract_implies(C_out_actual, Pre_next, gamma_min):
        return ('refuse', gap(C_out_actual, Pre_next))  # hold / 触发 DDA
    ledger_append(L, now(), next_v, PENDING, C_out_actual, Pre_next, gamma_min)
    return ('allow', None)
```

### IP-73 JCPS（升级后）
```
def joint_decompose_schedule(goal, C_t, leases, energy, q_prev, omega):
    dag = htd_cert(goal, C_t, contracts, leases)
    if dag is None:
        return ('synthesize_or_fail_closed', None)
    v = dag.frontier()
    nxt = dag.next(v)
    best = None
    for m in MODALITIES:
        P = pose_certificate(C_t, omega, m)            # L1 PSE
        if P is None:
            continue
        Jc = joint_certify(P, q_prev, m, leases.k, leases.e)   # L3 JSC
        if Jc is None:
            continue
        pick = choose_abstraction(v, Jc, contracts.get(nxt).Pre,
                                  leases, energy, q_prev, omega)
        if pick is None:
            continue
        a, C_post, val = pick
        if best is None or val > best[3]:
            best = (v, a, Jc, val)
    return best
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HTD-Cert | O(|V|·|Methods|·cost(⊨)) | O(|V|) | 只接受证书蕴含链；无链则失败，绝不降级为符号谓词 |
| ASC | O(|A_v|·(cost(f)+cost(⊨))) 每节点 | O(|A_v|) | 只选最粗可行抽象；抽象不改变 soundness 门槛 |
| CCL | append O(1)，audit O(|L|) | O(|L|) | 哈希链+只追加 ⇒ 篡改/重写/漏记可检 |
| DDA | O(|L|·cost(dist)) | O(|L|) | 归因只选再分解点，不改写历史 |
| CBG | O(cost(⊨)) 每边界 | O(1) | 拒绝不蕴含边界，端到端无静默断裂 |

**正确性定理（Certificate-Compositional Soundness）**
假设：(A1) 每个技能/抽象 `a` 满足契约 soundness：在 `Pre` 有效且 `ℓ_p,ℓ_e,ℓ_k` 全程有效时，执行后 `Post=f_a(Pre)` 成立概率 ≥ `1−α_a`；(A2) 每个边界由 CBG 在**真实当前状态**上复核 `Post_{v_i} ⊨_{γ_i} Pre_{v_{i+1}}` 且 `γ_i≥γ_min`；(A3) 租约在全程有效；(A4) 初始证书 `C_0 ⊨ Pre_root`；(A5) 台账只追加且审计通过。则沿路径 `v_1…v_k` 归纳可得
`P(X_end∈Post_{v_k}) ≥ 1 − Σ_{i=1}^k α_i − Σ_{i=1}^{k−1} ε_hand,i − α_lease`；
且由于 CBG 只放行蕴含成立的边界，**不存在"单步 sound、边界断裂"却被执行的路径**。抽象层级仅改变 `α_a` 与 `ρ(a)`，由于可行性门槛是证书蕴含，细化/粗化都不会引入新的不 sound 性。注意这是条件保证：它依赖证书契约库的标定正确性，契约库本身的偏差由 DDA/DCL/CCA 的独立审计负责，不在定理覆盖范围内。

## 4. 实验设计 E121–E126

| 实验 | 指标 | 门槛 |

| E121 分解证书契约 | 边蕴含率；边界 gap 分布；γ 覆盖率 | 标称蕴含 ≥ 98%，难层 ≥ 85%；γ 上界覆盖 ≥ 99% |

| E124 台账完整性 | 篡改检测率；漏记率；重写检测率 | 检测 100%；漏记 0；重写 100% 拒绝 |

| E126 100h 长程真机 | 长程任务成功率；边界拒绝率；组合塌缩；安全违例 | 成功 ≥ 95%；拒绝 ≤ 5%；塌缩 < 2%；违例 0 |

回退策略：E121 蕴含率不足 → 收紧契约库、增大 γ_min、对难层强制 primitive；E122 粗层误用 > 1% → 关闭 macro 层、只保留 skill/primitive；E123 假 soundness > 0 → 立即停机并回放台账，禁止在修复前扩大抽象层；E124 检测失败 → 停止签发并重建台账锚点；E125 归因不准 → 退回固定保守再分解点（上一 hold 点）而非猜 culprit；E126 塌缩 ≥ 2% → 强制近奇异/透明层走 primitive + 深度开启。

| 风险 | 等级 | 缓解 |
|---|---|---|
| 契约库 α_a/ρ(a) 标定偏低，组合上界失真 | 高 | 独立审计集按技能×抽象层校准；保守 α_a；CCA 注入分布外样本 |
| 边界隐式假设（物体状态、接触模式、感知陈旧） | 高 | CBG 同周期在线复核；handoff 显式携带物体/接触状态证书；DDA 触发再分解 |

| 台账被"修复性重写"以掩盖越界 | 高 | 哈希链 + 只追加 + 定期外部锚定；审计失败直接 fail-closed |
| 再分解时机械臂仍在运动，切换不安全 | 高 | 仅在安全 hold 点再分解；保留已执行前缀；路径可行性由 JCMP 复核 |
| 分解规划组合爆炸 / 超时 | 中 | 契约方法缓存 + anytime 展开；超时回退 primitive 分解 |
| 台账无限增长与存储上限 | 中 | 分片归档并锚定根哈希；在线只保留近期窗口 + 全局锚 |
| 记忆/语音指令映射到非法技能 | 中 | MVR/VAD 输出必须通过 HTD-Cert 合法性检查；否则安全队列 |

## 6. 本轮最大风险

**一句话**：任务分解把"单步证书 sound"升级为"证书蕴含链 sound"，但真正的脆弱点从感知/关节转移到了**边界契约库**——一旦 `Post_i ⊨ Pre_{i+1}` 只在离线规划状态成立，而执行漂移、接触模式切换或感知陈旧让它在线失效，且边界守卫/台账被绕过或重写，系统会在每个子任务都"成功"的表象下发生端到端安全违例；因此边界蕴含必须同周期在线复核、台账只追加不可改写、任何 gap 必须触发再分解或 fail-closed。
