# 想法区 · 第 8 轮（本循环第 2 轮）：从 X-DUB/AG* 到 X-DUB/RO*

**灵感词**：博弈树搜索 / FPTAS / online algorithm  
**起点**：v0.5「X-DUB/AG*」。它有 A* 一致性、focal、DOM、THRESH、证明 DAG；本轮不推翻其中任何一条定理，只改两件事：**初始上界从哪里来**，以及**把"找解"与"证明"明确分居**。

## 一句话直觉：v0.5 的瓶颈不是"选哪个节点"，而是"没有一个足够好的完成值"

我先把三个灵感词按最直白的方式各试了一遍，结果三堵墙。随后实验把我推到一个更简单的重新表述：**在困难实例上，L0 几乎总是严格小于 OPT，而一旦 U=OPT，很多实例的前沿一步就闭合；真正贵的是把 U0 从 1–8 降到 0（precedence-tight 的实例除外，它们仍要完整反驳）。** 于是本轮的主角不是 PNS，也不是 null-window，而是博弈树里的 **rollout**：用一次 playout 评估每个动作，宽度 1 就能把 U0 打到 OPT。精确搜索则退回它真正擅长的事——在 U-1 上做反驳。

## 1. 我先撞上的三堵墙（都有数）

### 1.1 Null-window / MTD：拆成判定就丢了 optimization 支配

我把精确搜索改写成 `H=U-1` 的判定序列：`REFUTE(σ,H)` 做 DFS，带 refutation memo（`ref[σ]` = 已反驳的最大 H）、失败状态支配表和 AVAIL(H)。17 个困难实例上总扩展 **3,354**，而 v0.5 的 AG 是 **913**，慢 3.7 倍。最差的一个从 302 涨到 1,349。

主要原因不是常数：**"未反驳状态的支配"是 optimization 特有的剪枝**。在优化搜索里，若 `σ⪯τ`，即使 σ 还没被展开，也可以把 τ 丢掉，因为 σ 会替它被探索；在固定 H 的判定搜索里，只有"σ 已被反驳"才能推出 τ 被反驳，支配表弱了一个量级。拆成 decision，等于把 v0.5 最锋利的刀收起来。

### 1.2 PNS：纯 AND 树的证明数会爆炸

我实现了 proof-number search：叶子的 pn=1，状态节点 `pn=Σ pn(child)`、`dn=min dn(child)`，按最小 pn 下降。17 个实例总扩展 **1,231,417**，约 913 的 1,348 倍（而且 PNS 只做 `H=OPT-1` 的反驳，不做找解）。部分原因是这个搜索树是"纯 AND"（要反驳一个状态，必须反驳它的所有动作），`pn=Σ` 在高分支下迅速膨胀；没有图级 transposition 的 PNS 不适合这个状态空间。

### 1.3 Beam：不是宽度不够，是评估函数太弱

宽度 B、按 `max(A)` 打分的 beam，在 17 个实例上的上界平均超出 OPT：B=2 时 **5.00**，B=4 时 **4.76**，B=8 时 **4.24**，B=16 时仍 **3.94**。而宽度 1、用"贪心完成"做评估的 rollout，平均超出 **0.00**。这组对比是决定性的：**评估函数的质量比搜索宽度重要一个数量级**。

三堵墙共同指向一句话：**搜索的瓶颈在"完成值"，不在"节点选择"。**

## 2. 数据把我推向的重新表述

在 17 个困难实例（AG 扩展数 ≥12、且已证完）上：

- `L0` 严格小于 `OPT` 的有 **17/17**，gap 在 1–6 之间；
- 用 CP 贪心做初始上界，`U0=OPT` 的只有 **2/17**；
- 但 302 步的那个实例，`U0=OPT=46`，302 步全部花在反驳 45 上。

所以"找解"与"证明"是两个独立瓶颈，而 v0.5 的 anytime 差主要差在 U0：25 次扩展内 29/30 找到 OPT，说明 focal 的**选点**并不差，差的是**起点**。如果 U0 已经是 OPT，搜索就只剩端局。

本轮的目标因此变成：

```text
用博弈树的 rollout 把 U0 打到 OPT；
用 online 的 LST 规则做 playout；
用 FPTAS 的视角回答"为什么近似救不了端局"——并证明它确实救不了。
```

## 3. ROLLOUT-PV：宽度 1 的博弈树，加一条 policy-improvement 定理

对状态 σ、动作 `a=(i,k)`、内层策略 π，定义 playout 值

```text
V_π(σ,a) = Cmax( Greedy(σ·a, π) )
```

ROLLOUT 选

```text
a* = argmin_a min_{π∈Π} V_π(σ,a),   U_R(σ) = min_a min_π V_π(σ,a).
```

它每一步都重新评估、重新选择，返回一条完整调度 PV。关键定理（§3.3 给出证明）：

```text
U_R^π(σ) ≤ Cmax(Greedy(σ,π))   对任意 π∈Π
```

因为 π 自己的第一个动作就在候选集里，rollout 取 min 不可能更差。于是 `U_R ≤ U_Π`，**rollout 弱支配整个基策略族**。这不是近似比，但它是一个无条件的改进保证；实验上它把 45/45 个实例的 U0 直接打到 OPT（未筛选的新样本 27/28）。

## 4. ONLINE-LST：playout 里那条真正起作用的规则

内层 playout 我用四条表调度规则做消融（45 个实例，命中 OPT 数 / 平均超出）：

| 内层规则 | 命中 | 平均超出 |
|---|---:|---:|
| CP（`q_i` 最大） | 32/45 | 0.422 |
| LPT（`p_i` 最大） | 35/45 | 0.600 |
| MWKR（剩余后代总工时） | 31/45 | 0.467 |
| **LST（`p_i+q_i` 最大）** | **42/45** | **0.067** |
| min-of-4 rollout | **45/45** | **0.000** |

LST 是"含自身的剩余关键路径"，也是带截止期的在线表调度：它每一步只根据当前 `est/q/A` 承诺一个任务，不看未来。它比只看 tail 的 CP 好得多，因为 `p_i` 把"这个任务本身有多长"算进了紧迫度。

在线算法还给我一个免费的下界：任何表调度都有 Graham 比 `ρ=2-1/m`，所以

```text
L_CR = ceil(U_R / ρ) ≤ OPT.
```

它是可采纳的、可检查的，但在本轮 17 个实例上 **0/17** 超过 L0（平均还低 12.2），所以只作为"L0 失效时的兜底"，不当作主卖点。

## 5. FPTAS：一个负定理，而不是一个新算法

我本来想用 scaling 做"便宜的强下界"：把 `p_i` 向下取整到 Δ 的网格，若松弛实例在 H 上不可行，则原实例也不可行。方向是对的，但有一个结构性的天花板：

> **Last-Δ 定理**：设 R 是原问题的一个松弛，且 `OPT(R) ≤ OPT`。若 R 的证书反驳了 `H=OPT-1`，则必有 `OPT(R) ≥ OPT`，结合 `OPT(R) ≤ OPT` 得 `OPT(R)=OPT`。也就是说，**任何严格松弛都不能认证最后一单位；只有当它在最优点上恰好紧时才可能。**

实验完全吻合：Δ=1,2,3,4 下，17 个实例中保持 `OPT(↓)=OPT` 的有 **0/17**，平均分别掉 4.29、7.47、7.24、10.47。Δ=1 就已经掉 4.3，因为把每个 `p_i` 减 1 等于把总工时减了 n。

所以 FPTAS 在本轮的角色不是算法，而是**分工定理**：

```text
round-up   可行  ⇒ 原实例可行     （近似只能造解）
round-down 不可行 ⇒ 原实例不可行   （松弛只能反驳严格低于 OPT 的阈值）
最后一单位：两者都够不到，只能靠精确搜索。
```

这也解释了 v0.5 的 THRESH 为什么在 precedence-heavy 实例上无效：它也是一个松弛，端局本来就不在它的射程内。

## 6. 与 v0.5 的关系：只换起点，不动刀

- **不动**：动作空间、A* 一致性、`F` 继承、focal、DOM、THRESH、证明 DAG 的 `TERMINAL/PRUNED/PACK-CORE/INHERIT/DOMINATED`。
- **换掉**：`U0` 从"CP 贪心"换成"4 条规则 × 4 次 rollout 的最小值"；`GUIDE` 从 3 条规则换成含 LST 的 4 条规则。
- **新增**：`ROLLOUT-WITNESS`、`SCALE-CERT`、`CR-BOUND` 三种可检查节点；`L_CR` 与 `L_SCALE` 两个可选下界。
- **可恢复**：关掉 rollout，用 4 条贪心初始化，就退回 v0.5 的 AG*（多一条 LST 规则）。

组合下界与主循环完全保留：

```text
L(σ) = max( L0, L_D, L_AV, L_TH, L_CR, L_SCALE )
F(σ) = 路径最大下界
f(σ) = max( C(σ), F(σ) )
```

## 7. 本轮要验证的命题

1. **Policy improvement**：`U_R^π ≤ Cmax(Greedy(·,π))`，故 `U_R ≤ U_Π`；rollout 不劣于任何基策略。
2. **可行性**：每条 rollout 调度都合法，故 `OPT ≤ U_R`。
3. **Graham 继承**：`U_R ≤ U_Π ≤ (2-1/m)OPT`；`L_CR=ceil(U_R/ρ)≤OPT`。
4. **Last-Δ**：严格松弛不能认证 `OPT-1`；scaling 只能跳过严格低于 OPT 的阈值。
5. **SCALE 双向可靠性**：round-up 造解、round-down 反驳；反方向各给反例。
6. **Anytime 区间**：任意时刻 `L≤OPT≤U`；`t=0` 就能输出 PV 与区间。
7. **精确性不变**：rollout 只改初始 U；搜索的剪枝仍只用可采纳下界；所有变体返回同一 OPT。
8. **节点与 anytime 收益**：45 个实例上总扩展 1226→994（−18.9%）；困难 17 个 854→632（−26.0%）；`t=0` 平均 gap 1.588→0.000。
9. **端局不动**：302 步的实例仍是 302 步；rollout 不改变最后一单位的 refutation 成本。
10. **负结果可复现**：PNS/null-window/beam/energetic/conflict 的数字都能用仓库里的原型重跑。

## 8. 本轮的一句话最大风险

**ROLLOUT 把 n≤10 随机 DAG 的"找解"压到零搜索、把 anytime 的 t=0 gap 打到 0，却完全没有动最后的 refutation（302 步的实例仍是 302 步）；而它的 O(n³m|Π|(n+|E|)) 成本，在"基线上界本来就等于 OPT"的大实例上纯属开销——本轮收益集中在中小时延、基线上界差 1–8 的实例，真正的 NP-hard 端局仍在原地。**
