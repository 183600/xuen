# 第 3 轮（承接 v9 MetricVoiceGauge-ACMD 基线；本轮灵感：「异常检测」×「Gazebo」）

> **基线**：v9 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**异常检测 + 仿真校准**。v9 的最大风险是「块证书在最需要安全的时刻最不可靠」：Δ_dom 的 20 帧滑窗滞后于真实分布跳变。异常检测提供**逐步、随时有效（anytime-valid）**的证书失效证据；Gazebo 提供**异常注入基准 + 中止点蒙特卡洛证书 + 仿真-现实差距审计**。三者的共同纪律：任何证据不足时**膨胀 β_eff**、收缩 K_eff，最终严格退回 v9/v8，不新增行为分支。

## 0. 直觉与动机

**灵感 1（异常检测 → 证书残差哨兵 CRS）**
v9 的证书失效判断依赖 Δ_dom，而 Δ_dom 是 20 帧滑窗的分布级统计：它对**持续偏移**灵敏，对**突然跳变**迟钝。直觉：前向模型 F̂ 每执行一步都会留下“预测 vs 实测”的残差 r_t；如果块证书仍然可信，r_t 应服从标定分布；一旦真实世界跳变，r_t 会**在跳变后的第 1–2 步**先于任何滑窗统计爆表。因此把 r_t 做成一个 **e-process（检验鞅）**：在“仍在信任域”的原假设下，Ville 不等式给出 `P(∃t: E_t ≥ 1/α) ≤ α` —— 这是**随时有效（anytime-valid）**的，允许我们每周期都看、都做停止决策，而不会像固定显著性检验那样因反复检验而虚警爆炸。双时间尺度：快哨兵盯单步残差（突发异常），慢哨兵盯 W 步块均值（缓慢漂移）。核心创新：**证书残差哨兵（CertificateResidualSentinel, CRS）**。

**灵感 2（Gazebo → 异常注入基准 GAIB + 中止点蒙特卡洛证书 AMC）**
引理 82 的安全结论建立在“信任域内 ‖F̂−F‖≤β”这个**假设**上，而 v9 只用 E554 的经验标定。直觉：Gazebo 是可控的**反事实机器**——可以精确注入 A1 传感器尖峰、A2 卡死、A3 慢漂移、A4 时延、A5 障碍突现、A6 打滑，从而 (a) 标定 CRS 的 μ₀、分位数与检测延迟-虚警 Pareto；(b) 对每个候选中止点 p 做 N_mc 次扰动 rollout，用 Clopper–Pearson 上界给出 `P_coll(p) ≤ ε` 的**分布无关置信证书**，使中止点的安全性不再只依赖前向模型。Gazebo 的可复现种子与场景库同时充当**预注册测试集**，杜绝“在测试场景上调参”。核心创新：**Gazebo 异常注入基准（GAIB）** 与 **中止点蒙特卡洛证书（AMC）**。

**灵感 3（联合 → 仿真-现实差距审计 TGA 与 β 的诚实膨胀）**
Gazebo 标定的 β_sim 只在仿真里成立；真实残差分布可能更重尾。直觉：把“仿真结论能否迁移”本身做成一个**双样本异常检测**问题——在重叠工况下比较 D_sim 与 D_real 的残差分位数，用 e-process/MMD 给出差距上界 Γ（置信 1−δ_gap）。于是真实侧取 `β_eff = β_sim + Γ`。这不是又一个可调参数：**Γ 越大，证书越保守、K_eff 越小；Γ 无法被认证时 β_eff 自动顶到 β_max，K_eff≡1，系统退回 v9 单步**。安全裕度因此是“证据的函数”，而不是拍脑袋的常数。核心创新：**孪生差距审计器（TwinGapAuditor, TGA）**。

## 1. 研究问题（本轮升级版）

- **Q1（随时有效哨兵）**：如何在**不假设平稳性、允许每周期可选停止**的条件下，给出证书失效的虚警率保证与检测延迟上界？双时间尺度能否覆盖“突发跳变/缓慢漂移”两类异常而不互相污染？
- **Q2（仿真证据的效力边界）**：Gazebo 注入的异常分布与真实异常分布差多远时，标定仍可迁移？如何用一个可审计的差距量 Γ 把仿真证书“打折”成真实证书？
- **Q3（中止点证书）**：能否用蒙特卡洛 + 单侧置信上界，构造与 F̂ 无关、可逐点验证的停车安全证书，并与 v9 的停车不变式兼容？
- **Q4（证据融合）**：CRS、Δ_dom、Γ 三种异质证据如何在同一个信任门里融合，使“任一证据失效 ⇒ 单调退化”，而不引入新的行为分支？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 随时有效残差律（Anytime-Valid Residual, CRS）**
每步计算特征残差 r_t；维护快 e-process E_t^fast（单步）与慢 e-process E_b^slow（W 步块均值）。任一被拒（E ≥ 1/α）即判“信任域失效”，**当周期**令 K_eff←1 并以最近中止点 p* 停驻；不等待 Δ_dom 滑窗。快、慢检验各自独立分配 α，互不借用显著性预算。

**P14 仿真证据律（Gazebo Evidence, GAIB/AMC）**
凡进入证书的常数（β_sim、μ₀、分位 q、中止点 P_t）必须能追溯到可复现的 Gazebo「场景 × 注入 × 种子」三元组；中止点须通过 N_mc 蒙特卡洛与 Clopper–Pearson 上界 `U(k,N,δ) ≤ ε_coll`；测试场景与标定场景按种子/房间严格不相交。

**P15 差距诚实律（Gap-Honest Calibration, TGA）**
真实侧一律使用 `β_eff = β_sim + Γ_{1−δ_gap}`；Γ 由双样本检验给出。若 Γ 不可认证或 `β_eff ≥ β_max`，则 `K_eff≡1`。**宁可在陌生域退回 v9 逐步，也不携带一张未打折的仿真证书。**

## 3. 与 v9 基线的接口（如何退化）

- CRS 拒绝 ⇒ K_eff←1 + 切换 p* 停驻，行为逐位等价 v9 Level-1（引理 89）；
- CRS/GAIB 失效 ⇒ 关闭哨兵，信任判断退回 Δ_dom 单一证据，等价 v9；
- TGA 失效 ⇒ Γ←Γ_max（离线最坏静态值），β_eff 保守但不失效；
- AMC 失效 ⇒ P_t 退回 v9 定义 534 的前向模型构造（更保守的 K_max）；
- 全部失效 ⇒ 完整退回 v9 ACMD，再退回 v8。

**关键：本轮不新增退化级。** 哨兵只是把同一张门（trust_ok）的证据来源从 1 个变成 3 个，门的语义仍是 v9 的 Level-1；因此 v9 引理 83 的“逐位等价”性质继续成立。

## 4. 预期贡献

1. 首次把**随时有效 e-process** 用于动作分块的前向模型证书监控，给出可在 50Hz 每周期可选停止的虚警保证与检测延迟上界；
2. **Gazebo 异常注入基准 + 中止点蒙特卡洛证书**，把 v9 中“假设的 β”和“构造的 P_t”升级为“可复现、带置信上界的实验事实”；
3. **仿真-现实差距的诚实膨胀**：安全裕度随证据质量自动变化，证据不足时单调退化到 v9；
4. E571–E590：覆盖检测延迟、虚警、注入分类、孪生保真、中止点覆盖、迁移有效性、慢漂移盲区与端到端任务。

## 5. 本轮最大风险

**一句话**：双时间尺度哨兵仍以“信任域内残差与标定分布可比（近似可交换/有界）”为数学前提，而最危险的异常恰是**缓慢、协同的分布漂移**——单步残差始终像正常噪声，慢哨兵的 W 步块又可能被标定集中的同类漂移“合理吸收”；此时快、慢哨兵与 Δ_dom 三者可能同时沉默，系统仍会在大 K_eff 块上暴露失效证书。
